# 耶鲁大学：死亡哲学（26 讲）

耶鲁大学公开课以“死亡”为入口，系统追问身体死亡之后人是否仍然存在、个人同一性如何跨越时间，以及死亡为何构成伤害。课程先比较二元论与物理主义，再检视灵魂论、柏拉图的不朽论证和复制—分裂难题，最后转向死亡之害、永生价值、死亡恐惧与自杀的理性和道德评价。

## 怎么学

**先建立全课问题地图**。从“死亡是否真的伤害我”出发，依次理解灵魂、身体、人格和未来自我之间的关系，不要一上来就接受灵魂不朽的结论。

**系统理解灵魂论时抓住论证链**。重点分辨“心灵或灵魂是否存在”与“灵魂是否不朽”是两个问题，并对照笛卡尔式论证、行为主义解释、机器论困境与相关思想实验。

**学习柏拉图论证要同时追问前提**。课程会拆解对立物、回忆说与灵魂单纯性论证，阅读时同步记录每一环依赖什么假设，以及反方从哪里攻击。

**理解人格同一性时用忒修斯、复制和分裂案例交叉比较**。肉体理论、人格理论、心理连续性与整体生命连续性各有代价，笔记适合做横向对照。

**讨论死亡之害时先问“谁被剥夺了什么”**。未来状态、整体生命形状、不朽性、生命价值与死亡恐惧不是同一个问题，避免把所有不适都笼统称为“怕死”。

**进入自杀专题时保持哲学分析的边界**。课程讨论理性选择、犹豫不决、后果、权利和同意；现实中的危机判断不能由哲学论证替代，遇到即时危险应优先联系当地急救与专业支持。
