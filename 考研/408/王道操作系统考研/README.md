# 王道计算机考研-操作系统（86 讲）

王道考研操作系统全程课，与王道单科书配套：按教材五章体系（绪论 → 进程 → 内存 → 文件 → I/O）完整推进，从进程状态转换、调度算法、信号量与经典同步问题、死锁四件套，到分页分段与虚拟内存、文件物理结构与 FCB，再到 I/O 层次结构与磁盘调度，每个考点都配王道风格的图解与真题演练。概念推导贴合教材、例题直指 408 命题套路，适合一轮复习打底与强化阶段速查。

- **原视频**：[王道计算机考研 操作系统](https://www.bilibili.com/video/BV1YE411D7nH) — Bilibili，BV1YE411D7nH
- **全 86 集**，已产出 4 册模块全书、12 篇复习笔记、34 份逐字稿

## 怎么学

- **跟教材章节走** → 34 个知识块按王道教材五章顺序装箱，教材 4 册与书的章节一一呼应，适合边看书边对照
- **进程部分抓「状态转换 + 同步互斥」两大主线** → 笔记 02（进程与线程）与笔记 04（进程同步与互斥）覆盖 8 个块，是本章考分最重的地方；生产者-消费者、哲学家进餐、读者写者的信号量写法要能默写
- **内存部分抓「分页 + 虚拟内存」** → 笔记 07（分页分段）与笔记 08（虚拟内存与页面置换）覆盖地址变换、两级页表、OPT/FIFO/LRU/CLOCK 与银行家算法的完整计算流程，计算题按步骤练
- **文件与 I/O 靠对比记忆** → 笔记 09-10 把逻辑结构/物理结构、FCB/索引结点、文件保护放在一起；笔记 11-12 把 I/O 层次、SPOOLing、缓冲区与磁盘调度算法收成速查表
- **逐字稿核对原话** → 例题推导卡住时，去 `subtitles/` 按块定位讲师的原讲解
