# 计算机 408 真题逐题精讲（2009-2025）

计算机学科专业基础综合（408）09-25 年真题的逐题精讲课程，共 188 集。课程不按知识点而是按年份推进，从 2009-2011 年一直讲到 2022-2025 年，把数据结构、计算机组成原理、操作系统与计算机网络四门放在同一道真题里逐题拆解，用「命题人怎么出、考场怎么选」的方式把真题吃透，并借年份跨度呈现 408 命题风格与难度本身的演变。

- **原视频**：https://www.bilibili.com/video/BV1icaxz8EXN — Bilibili，BV1icaxz8EXN
- **188 集**，已产出 9 册模块全书、16 篇复习笔记、74 份逐字稿

## 怎么学

- **先按年份整套刷** → 9 册教材是按 2009-2025 年份分卷的，建议从最新一年往前做，手感最接近考场
- **再回查学科短板** → 16 篇笔记是按**学科主题**重组的（数据结构→组成原理→操作系统→网络），做完一套真题发现哪一门失分多，就直接跳到对应学科的笔记补，而不是从头再看一遍年份卷
- **组成原理重计算** → 笔记 05~08 覆盖数值表示、存储系统、指令系统、总线与 IO，地址变换与 CPI 计算是全科最容易算错也最容易提分的地方，务必动笔算完整流程
- **操作系统重模型** → 笔记 09~11 讲进程调度、虚拟内存与文件系统，配合笔记 16 的 PV 操作与经典同步模型，把「并发」这一科的选择题与综合题一起拿下
- **网络重协议栈** → 笔记 12、13 讲网络体系结构、数据链路层与 TCP，结合真题里反复出现的计算题（子网划分、滑动窗口、时延）形成条件反射
- **复盘** → 笔记 14 专门整理历年命题分布与趋势，考前用它确认复习重心有没有押偏
