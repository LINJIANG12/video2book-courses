# 现代之思：人生的意义与哲学是什么

## 人生意义的根据

* **人生意义问题**

    * > **定义**：人生意义不是可以一次性给出答案的知识问题，而是活到老要想到老、思考一辈子也未必能够决定的问题。

    * 不是青春期多愁善感才有的幼稚问题，五六十岁的成年人同样无法回避。

    * 与"智慧的痛苦"同源：亚当夏娃偷吃禁果，不是因为有了智慧人才有死，而是因为有了智慧，人才意识到人有生死。

    * 智慧一出现，人就面临有限与无限、相对与绝对、暂时与永恒、此岸与彼岸、现实与理想之间的冲突，两者之间横着一道不可逾越的鸿沟。

* **意义源于有限性**

    * > **定义**：人生之所以有意义的追问，恰恰因为人是有限的存在。

    * 反证：假如人是无限的，就有足够乃至无限的时间去实现想要实现的一切，什么都不着急，也就无所谓取舍，意义问题根本无从出现。

    * 现实：人同样面对各种各样的可能性，却不可能把全部可能性都实现，只能选择一部分，再加上其他条件限制，必须有取有舍。

    * 中国人讲的"舍得"——有舍才有得；怎么舍、怎么得，人生的意义由此开始。

* **泰勒斯式的关注**

    * 人这种有理性的生物不仅关注眼前，甚至眼前的东西还没搞清楚，就已经去关注无限、永恒的东西；哲学与宗教都由此而生。

    * 最初古人并没有多少带永恒、无限色彩的抽象概念，靠仰观天象来体现人生境界、超越小我的有限性。

    * 面对浩瀚无垠的星空，感受到的不只是人生的渺小，还有某种从中体现出来、提升人生境界的东西。

* **如何活与为什么活**

    * 人生在世无非面对两方面：如何活、如何活得更好；为什么活。

    * 吃穿住是生活的前提而不是生活的目的（历史唯物主义的前提）。

    * 生存的需要之外还有"为什么"的需要，真正与人生意义相关的是后者。

* **问题与难题**

    * > **定义**：可以有答案、甚至可以有标准答案的，叫"问题"；没有终极答案、没有标准答案，只有各式各样不同选择方式的，叫"难题"。

    * 人生的问题恰恰是难题。

| | 问题 | 难题 |
| :--- | :--- | :--- |
| 答案 | 有答案，甚至有标准答案 | 没有终极答案，没有标准答案 |
| 出路 | 所有人照着答案去做即可 | 只有各式各样不同的选择方式 |

* **世界本无意义**

    * 一个没有人的世界不是意义的世界；世界本身就是一个盲目的物质循环的盲目活动。

    * 意义与人的目的、人的需要相关；人不能忍受一个没有意义的世界，需要意义作为生存的根基。

    * 人有了理性与智慧，不满足于只做单纯的自然存在物，于是才有意义问题。

    * 人生需要有意义，源于人对虚无主义的一种恐惧。

* **虚无主义（Nihilism）**

    * > **定义**：尼采的定义——绝对价值的丧失；人生没有意义，就是虚无主义。

    * 人生原本的确没有意义，人生的意义需要我们自己赋予自己的人生。

* **意义追问的两条路径**

    * 客观发现式：认为人生本身就有意义，像一种客观存在的东西摆在那里，我们试图去发现它。以往的哲学多取此路——以看待宇宙万物的方式看待人，把人看作像物一样有某种先在本质，发现它然后按本质去做。

    * 行动赋予式：认为人生原本无所谓意义，意义是我们通过自己的行动赋予人生的。19世纪下半叶以后西方哲学发生转向，走的是这条路。

    * 困境所在：我们以为通过研究自然就能发现人的意义像自然法则一样写在那里，追根溯源最终发现的不过是物的意义——没有人，这个世界照样运转。

    * 人与物的不同就在于人为意义而活；而人为意义而活，却又没有一种像自然法则一样客观摆在那里的意义。

## 冒险、无上帝与相对主义

* **人生是一场冒险**

    * 人带有很强的惰性：希望一切被发现的东西都是必然的、都是规律，即使受规律支配也感到安全；一旦面对未知的、充满危险、没有规律可循的世界，就陷入困境。

    * 确定人生目标与意义时，人生有限，这种意义究竟是否合适其实并不知道；只有走到最后，也许才发现路走错了。

    * 想退回来重走一遍没有可能性——"一失足成千古恨，再回首已百年身"。

    * 正因为如此，人经常放弃对意义的追问、放弃这种创造性的活动，希望人像物一样有一定之规。

    * 多数人是自然而然地、按本能的方式生活，对很多问题没有真正思考——不是没有面对，往往是主动逃避，因为面对这些问题没有答案，而且痛苦。

* **无上帝之后的困境**

    * 陀思妥耶夫斯基《群魔》的逻辑：这个世界是丑恶的，所以应该有一个惩恶扬善的上帝；但又没法证明上帝存在；上帝不存在，那么除了自杀还有什么出路。

    * 三种情形对照：世界丑恶、无上帝、而心甘情愿与丑恶世界同流合污——不会自杀；世界丑恶、坚信有上帝——不会自杀；世界丑恶、又没办法相信上帝存在——这才是困境。

    * 现代人自19世纪下半叶以来面临的正是第三种：近代哲学、启蒙主义的科学高歌猛进，最后带来的就是这个结果。

    * 由此逼出的追问：假如没有惩恶扬善的上帝、没有天堂等着善人、没有地狱等着恶人，为什么要做好事、不做坏事？

* **价值多元化与道德相对主义**

    * 现代社会善恶是非、黑白曲直都是模糊的、相对的、没有一定之规，人生的问题因此更加凸显。

    * 物质生活条件在改善，人的精神方面的问题并没有真正得到改善。

    * 不能设想存在某种带有绝对真理、可以以长官意志颁布的道德律条或人生意义，然后要求所有人按照这种人生观去做；过去在道德、伦理学方面的失败就失败在这里。

    * 没有人有资格教育别人：这些问题是永恒没有答案的、开放的，每个人都有权发表自己的意见，但没有人有权利把它强加给所有人。

    * 需要的是每个人自觉的思考。

## 自由与必然

* **萨特（Jean-Paul Sartre）论人性**

    * 演讲《存在主义是一种人道主义》，被授予诺贝尔文学奖而公开谢绝。

    * 人和物不一样：假如没有上帝，人就没有本质；人没有本质，就意味着人的本质由人自己赋予自己。

    * 人的本性在于自由，自由就在于筹划和选择。

    * 如果认为人生的意义是客观存在的，就不会有自由的问题——本质已经规定好了，照着做即可。

    * 如果认为意义需要自己赋予，则每个人都是自由的；这是人生之为人生的前提条件。

* **自由作为人生前提**

    * > **结论**：如果没有自由，就没有人生的问题。没有自由，一切东西都是必然的，照着做就行了，用不着思考，也用不着困惑。

    * 在人生哲学这个层面不争论自由有无：不以人生为前提，就不必探讨人生的问题。

    * 人生一定是自觉自主的人生活动的过程；若像动物、像自然存在物那样由自然规律或本性驱动，就不由自己自主，也就无所谓人生。

* **自由与自由的实现**

    * 每个人都有面对诸种可能性、筹划选择哪一种可能性的自由。

    * 选择某一方面并让它实现出去，都是有条件的。

| | 自由本身 | 自由的实现 |
| :--- | :--- | :--- |
| 是否有条件 | 无条件，是人生的前提，不争论 | 有条件，需要种种现实条件 |
| 能否剥夺或赋予 | 无法剥夺、无法赋予，只能限制 | 受条件限制，条件具备才能实现 |

    * 判刑十年八年在口语中叫"剥夺了他的自由"、刑满叫"重新获得自由"，这两种说法都不对。

    * > **易错点**：坐牢不是"剥夺自由"，只是"限制自由"；自由本身剥夺不了也赋予不了，需要条件的是自由的实现。

* **从命运到规律**

    * 哲学脱胎于神话，走的是一条从命运、到必然性、再到规律的路。

    * 希腊人不满足于神话用命运解释世界，希望认识自然、以自然去解释自然，哲学思考由此诞生。

    * 自由的问题不在希腊人的视野里：他们追问的是命运、必然性、规律，探讨的恰恰是必然性的东西。

    * 哲学与科学同源，共同根源于一种科学思维方式；科学描述这个世界，哲学要解释这个世界的意义。

    * 描述自然所能得到的只是物的属性、物的本质规定、物的规律，其中没有人的本质、人的规律——否则人和物就混为一谈了。

* **被抛入可能性**

    * 每个人都是被抛入可能性的境域之中来的，都面对各种可能性。

    * 有些东西无法选择：父母没法选择，出生没有经过自己的同意，没有人商量过"这时候出生合适不合适""出生在什么地方合适不合适"。

    * 但在这样的环境之下、在这种种必然性的因素之下，人是面对可能性来塑造自己的人生的。

* **人生的变数**

    * 人生可以看作一个因果链条——种瓜得瓜、种豆得豆，回首往事能找到"我为什么这么过来"的原因。

    * 但每一个环节都是可变的，绝不是这个环节一定产生那个结果；是那些偶然因素综合起来才产生这样一个结果。

    * 例子：本来成绩很好却马失前蹄，没上成重点大学；专业选择带有偶然性；换一个学校、换一个专业，人生会不一样。

    * 把人生看作完全由必然性构成，等于把它变成一个不由自己决定、于是用不着自己负责的过程。

    * 选择会有其后果，但选择可以改变后果。

* **个体性的完善**

    * 自然的进化以个体化的完善作为很大标志；人类社会的历史发展也一样，个体性越成熟、越完善，越标志着这个社会的发展。

    * 原始社会中人只是部落众多组成部分里的一个分子，不能决定社会如何，只是一个构造部分。

    * 人需要以社会的方式、分工合作的方式生存：力量、速度、感官的敏锐都不如动物。

    * 动物群体中个体不起作用，以群体的方式延续种群；人的社会进化却伴随着个体的完善，去打破原有的社会规范。

    * 传统维系着社会的存在，但到一定程度就成了阻碍；个体性完善与觉醒去冲破传统的坚冰，重新变革，新的传统过时后再被打破。

    * 结论：我们每个人是可以作为一个自我来存在的。

## 大家与逃避自由

* **大家（Das Man）**

    * 海德格尔《存在与时间》从存在论角度探讨，其中很多分析可以当作对人生观的探讨来看。

    * 现实生活中，我们每个人都不是作为我自己，而是作为"大家"而生存的：以大家为榜样、向公众看齐。

    * 大家喜欢什么我们就喜欢什么，大家讨厌什么我们就讨厌什么。

    * 甚至追求个性化，也是因为大家追求个性化——个性化本来是我自己的事，但它流行。

    * "大家"拿走了我们的存在，替我们去做选择：不是我，而是"大家"，在主持着我们每个人的人生。

* **按书本活一辈子**

    * 生育、喂养、早教、升学、求职、恋爱、应对上司、临终，全都有书可依。

    * 大学生谈恋爱不再自己写情书，网上找一个改一改；号称有一万多种说爱的方式。

    * 连怎样最少痛苦地结束生命，都有手册可查。

    * 反问：从生到死都可以按照书去做，但是我在哪呢？

* **大家是谁，查无此人**

    * 需要有人站出来负责时才发现：大家都这样，我也这样——现在出问题了，那好，大家负责。大家在哪？没有。

    * 把存在与选择交给了"大家"，一旦出问题、需要承担后果时，是找不到大家的。

    * 并不是没有"大家"：我们每个人都是"大家"；但说"大家如何如何"时，从来是把自己排除在外的。

    * 按"大家"去做，其实是在逃避人生的责任；意识到"我就是大家"，才能成为自己人生的主人，以负责任的方式展开人生。

* **逃避自由**

    * 自由是人类历史上少数非常美好的字眼——"生命诚可贵，爱情价更高；若为自由故，两者皆可抛"。

    * 但当自由真的落在每个人身上，感到的不是美好而是负担：需要在诸多可能性中去筹划选择，必须为选择负责、自己承担后果，没有人可以分担。

    * 这就造就了20世纪一讲自由就叫做"逃避自由"。

* **生命中不能承受之轻**

    * 借米兰·昆德拉的小说名：自由就是生命中不能承受之轻——自由没有分量，但筹划选择并为之承担责任，这种负担承受不起。

    * 按"大家"的方式生存，有安全感、有家园感；真让自己面对未知的人生与未知的世界，感到的是一种不在家的状态。

    * 海德格尔揭示的悖论：不作为自己生活的时候反而觉得在家，真正作为自己的时候反而感觉自己不在家——你在逃避你自己。

    * 逃避自由的根，归根结底是逃避死亡。

## 生死观的对立

* **未知生，焉知死**

    * 《论语》记载学生问死，孔子答"未知生，焉知死"。

    * 能否代表孔子的生死观不敢断言，但完全可以作为对生死态度的一种典型：生的事情还没弄明白，死管它干什么；生的问题永远搞不明白，死的问题根本不用想。

* **未知死，焉知生**

    * 基督教或宗教的观念：对死后的东西不弄明白，这个生的意义在哪？

    * 追问的是人生究竟有没有归宿、有没有来生来世、有没有天堂地狱。

* **死亡禁忌**

    * 中国世俗的生死观对死亡采取的方式是死亡禁忌：通常人们不愿意提这两个字。

    * 电话号码、手机号码、车牌号码后边带 4 都不好听，好像和它沾边就不吉利。

    * 只想生的问题，不想死的问题。

* **伊凡·伊里奇之死**

    * 托尔斯泰的小说；伊凡·伊里奇是个小文官，比上不足比下有余，就是庸庸碌碌。

    * 病后住院，医生、亲戚朋友、家人都说他会好起来，他自己也相信；过了一段时间终于发现这次好不了了。

    * 立刻感觉到死亡是个非常严肃的问题，而大家都模糊过去、不去面对它。

    * 他开始考虑：假如让我再来一遍，我会不会还这么过这一辈子。

* **逃避死即逃避生**

    * > **结论**：你在逃避对死亡的思考，在某种意义上就是在逃避对生的思考。

    * 人没有充分意识到人生的有限性，每个人都认为自己会无限地生存下去，谁也不会成天想到"明天我会死"。

    * 年轻时想学什么马上就去学，不考虑后来还有没有时间；而时间的限制确确实实存在。

    * 讲哲学不能讲宗教那一套：人终有一死，而且很可能只此一生；意义之所以凸显，就在于怎么在这仅有一次的人生里让它过得有意义。

* **通常的死亡观**

    * 活着是"存在"，存在到头、最后面对死亡是"不存在"。

    * 于是尽量让自己存在下去，把那个不存在的事情推得越远越好，不去思考它。

    * 后果：拖延对死的思考，也就意味着拖延对生的思考——因为没有考虑人生意义的问题。

## 海德格尔的死亡概念

* **死亡（Tod）**

    * > **定义**：死亡是人之最本己的、无所关联的、确知而不确定的、超不过的可能性。

    * 关键是把死亡看作**可能性**，而不是一个从存在到不存在的过程。

    * 一切可能性都不一定可能，而这种可能性生下来就注定了，是最大的可能性。

    * 人一步一步走向死亡，要考虑的是人始终在**面向可能性**、面向可能性筹划自己的人生。

    * 无所关联的：面对死亡，一切都解脱了，一切关系都不起作用。

| 特征 | 要点 |
| :--- | :--- |
| 最本己的 | 只能自己去死，谁也替代不了，死一丝一毫也拿不走 |
| 无所关联的 | 面对死亡，一切解脱，一切关系都不起作用 |
| 确知而不确定的 | 确知人终有一死，却不知道哪一天来临 |
| 超不过的 | 死亡是人生之大限 |

* **可能性：满月酒的故事**

    * 一家人生了个大胖小子办满月酒：第一个客人说这孩子将来一定做大官，主人很高兴请他喝酒；第二个说将来一定发财。

    * 第三个是傻子，说这孩子以后一定会死，被一顿乱棒打了出去。

    * 能不能当官、能不能发财，不一定；但他会死，这是确定无疑的可能性。

* **最本己的**

    * 每个人只能自己去死，自己面对自己的死亡，没有别人能够代替。

    * "烈士替别人去死了""大学生下河救人自己淹死了，是替别人去死"这类说法不规范：可以替别人承担危险、付出生命的代价，但死亡是替不了的。

    * 替我承担了危险、失去了生命，我该死还是要死；死是一丝一毫也拿不走的。

    * 临终时没有人能帮你，只有你自己，抓任何稻草都没有用。

* **确知而不确定的**

    * 人终有一死，逻辑上都知道：亚里士多德是形式逻辑的奠基人，"人是有死的，苏格拉底是人，所以苏格拉底是有死的"，三段论把这个东西放在那儿了。

    * 但"人是有死的"这句话一听就过去了，并没有真的去思考它。

    * 确知终有一死，但不确定究竟哪一天来临：地震、海啸、车祸、各种污染，不确定因素太多。

    * 死亡就像悬在人头顶上的一把利剑，哪天落下来，你不知道。

* **超不过的**

    * 死亡是人生之大限。

## 向死而在与倒计时

* **向死而在**

    * 海德格尔强调"提前到死中去"，也就是"向死而在"。

    * > **提示**：提前到死中去，不是让你去自杀；它恰恰类似中国人所说的——置之死地而后生。

    * 不要等到七老八十才想"我这一辈子过得真不值，让我重新来一遍"；为了防止那个时候说后悔话，现在就想：我怎么应该做的事做不了，前怕狼后怕虎、庸庸碌碌。

    * 人都要面临终有一死，有什么事情不能去做、不能去尝试？

* **两种时间观**

    * 通常的时间观：时间是从过去到现在到将来，均匀的一个无限的绵延；现在由过去决定，将来由现在决定，归根结底由过去决定——这是向后看的时间观。

    * 海德格尔的时间观：人永远面对可能性，最大的可能性就是死亡，始终面向可能性筹划、选择自己的人生——这是向前看的时间观。

| | 通常的时间观 | 海德格尔的时间观 |
| :--- | :--- | :--- |
| 方向 | 向后看 | 向前看 |
| 链条 | 过去决定现在，现在决定将来 | 始终面对可能性，筹划、选择人生 |
| 依托 | 过去 | 明天、未来 |
| 结果 | 什么都可以不做了 | 对将来永远可以有所作为 |

* **倒计时的人生**

    * "赤条条来去无牵挂"通常用来劝人对财富名利看开；反过来想：来之后、去之前，恰恰是你有牵挂的人生，何不去牵挂一把。

    * 人其实是生活在明天的动物，总觉得会有明天，就像歌里唱的"明天会更好"；但终有一死意味着终有一天会没有明天，明天是有限的。

    * 假如相信有来生来世，用不着往下想；假如没有来生来世的保证，明天就是有数的——像被判了死刑，在数着一天一天过日子。

    * 不是过一天多一天，而是过一天少一天。

    * 意义与价值并没有非得有一个客观标准：财富积累到什么程度、公司办到多大程度才叫成功，没有标准；只要自己达到了自我完善、实现自己的程度，就足够了。

## 人生坐标与境界

* **人生坐标**

    * 横坐标代表时间：祖先、父母在先，然后是孩子，是生命延续的过程。

    * 纵坐标从自己的身体出发——身体就是物质、元素等等——往上依次是家庭、社会、国家、世界、宇宙。

    * 每个人就生活在这样一个人生坐标的交点上。

    ```text
                      宇宙
                       ↑
                      世界
                       ↑
                      国家
                       ↑
                      社会
                       ↑
                      家庭
                       ↑
              身体（物质、元素……）
                       ↑
     祖先 ——— 父母 ———— ● ———— 孩子 ———→ 时间
                  （你在这里）
    ```

    * 这个坐标是弹性的，也是开放的——因为它向上是开放的。

* **长度与厚度**

    * 生命当然可以通过各种方式延续：平均寿命已经比过去长得多；还可以设想克隆技术、基因技术，让人活两百岁、五百岁、一千岁。

    * 但只要解决不了人终有一死的问题，活一千年和活一百年其实没有区别。

    * 已经过去的时间就没了：二十年过去了，二十年在哪儿？没有了；人面对的永远只是现在和明天。

    * 有部电视剧里说，人生不过就活了三天：昨天、今天和明天；李白说"弃我去者，昨日之日不可留，乱我心者，今日之日多烦忧"。

    * 活得长和活得短，不过是五十步和百步的区别，在这上面做文章意义不大。

    * 与其去延长人生的长度，更应该加强人生的厚度。

    * 站在个人、家庭、社会、世界、宇宙的角度看人生，视野不一样；人生在于超越自我，就在于在自我之中超越自己、提升人生境界。

* **觉解**

    * 出自冯友兰上世纪 40 年代的短文《人生的境界》。

    * > **定义**：人和动物不同，在于人做某事的时候，他了解他在做什么，并且自觉地在做；这种自觉就是"觉解"（用今天的话说即自觉、觉悟，"觉悟"本是宗教、佛教的概念）。

    * 觉解使他正在做的事对他有了意义；各种意义合成一个整体，就构成他的人生境界。

    * 不同的人可以做相同的事，但觉解程度不一样，所做的事情对他的意义就不一样。

* **四种境界**

    * 从自然境界到天地境界，是一个从自然到自觉、也就是从不自觉到自觉的过程。

| 境界 | 觉解到什么 | 做事的意义 |
| :--- | :--- | :--- |
| 自然境界 | 无觉解，按自然存在物的本能趋势行事 | 不是自主去做，谈不上意义 |
| 功利境界 | 意识到自己，是为自己而活 | 有功利意义 |
| 道德境界 | 意识到社会的存在，自己是社会的一员 | 为社会利益做事，正其义不谋其利 |
| 天地境界 | 意识到自己是宇宙的一员，与整个宇宙融为一体 | 超越功利的天地意义 |

    * 功利境界并不意味着一定不道德、不见得做坏事：主观上为自己，客观上可能也为别人服务了。

    * 天地境界太高，可以做理想去想它，但它并不是可望而不可即的。

* **从心所欲不逾矩**

    * 孔子自述：十五志于学，三十而立，四十而不惑，五十而知天命，六十而耳顺，七十而从心所欲，不逾矩。

    * 要解什么叫天地境界，就在这里：到这个境界，怎么做都不会离开规矩，因为我和规矩是融为一体的。

    * > **易错点**：这句话常被说成成语"随心所欲"，好像想干吗就干吗；孔子讲的不是这个意思，而是规矩与己合一。

* **未完成的交响乐**

    * 交响乐在贝多芬的年代确定了基本四个乐章的完整结构，舒伯特只写两个乐章，所以叫《未完成交响乐》。

    * 人生也是一曲未完成的交响乐：说一个人"完了"，完了并不等于完满、完成。

    * 没有人在终老之时能想：我该说的话都说了，该做的事都做了，可以心安理得地闭上眼睛。

    * 人生有限，不可能把理想全都实现，只能实现很小很小的一部分。

    * 所以不要奢望事业做多大、做多完满，关键在于找到对自己最有意义的事情去做。

* **找到自我与超越自我**

    * 类似马斯洛需要层次里最高的需要——自我完善、自我实现的需要。

    * 自我实现不分小人物与国家元首、多大的老板，区别只在于能不能在任何地方达到自我完善。

    * 死亡面前人人平等：做多大事业，最后也逃不过一死。

    * 实现自我是一个不断超越自我的过程；站在自己、社会、世界、宇宙的角度看人生，每提升一个层次都在超越自己。

    * 人生问题归结起来是两个：找到自我，超越自我。

* **禅宗二病**

    * 人只有两种病：一是骑驴觅驴，二是骑上了驴不肯下。

    * 山僧说"不要觅"：除去觅的病，狂心遂息——你找不到自己，其实你自己就是驴。

    * 山僧说"不要骑，你便是驴，有什么好骑"：若骑，病不去；若不骑，十方世界空旷清净，二病同时除去，心下无一，名为道人——平常心是道。

    * 套用到人生哲学：一个就是找到你自己，一个是超越你自己。

    * > **提示**：按"大家"的方式、本能的方式生存，对自己的人生没有自觉的认识，就是还没有找到自己——做的所有事，意义何在和你是没有关系的；找到自己之后假如一切固执在这上面，对名利地位又会生出无尽的烦恼，所以要不断超越自我。

## 哲学的终极关怀

* **亚里士多德式的终极关怀**

    * 亚里士多德的神学提出了一种从哲学上面对终极关怀的方式：哲学的最高层次，就是人的思想对宇宙理性的一种思考。

    * 当你思考这个神圣理性的时候，你就是理性，他也是理性，你便把自己和他融为一体，去分享对象的生命。

    * 这就是人生最高的境界；亚里士多德说哪怕有一次就足够了，想多次达到那是奇迹。

    * 哲学所能提供的是：让有限的生命在思考宇宙万物时与宇宙万物融为一体，在消除了主体客体差异时达到那种喜悦——朝闻道，夕死可矣。

* **哲学不允诺来生**

    * 学哲学不可能允诺一个来生来世。

    * 人生的意义不要在人生之外去寻找；思考问题总有一个基点——你是在自己的人生里边思考这个问题。

    * 上帝存在不存在，科学不能证明也不能证伪，那是另外一个世界的事情。

    * 宗教的世界观意味着人生没有意义、意义在另一个世界，这一辈子是为另一个世界、为下辈子在活；对虔诚信仰者可能不成问题，但若信错了呢。

* **帕斯卡的赌注**

    * 帕斯卡与笛卡尔基本同时代，是数学家、概率论的创始人；他因为考虑赌博而考虑概率，继而由此考虑信仰问题。

    * 赌注论证：信上帝，要真有上帝就赚了、信对了；没上帝也没失去什么——仿佛是一场只赢不输的赌博。

    * 反驳：信上帝不是没有代价的，代价是你的所有人生——把一生押上去赌有上帝存在、有来生来世，你是为了那个去活。

    * 这不是只赢不输，恐怕是输的时候比较多的一场人生豪赌。

    * 反讽：如果我是上帝，绝对不收这样的人——你赌一把，赌我在？

* **元朝宫廷的五尊神像**

    * 马可·波罗在元大都宫廷里发现，元朝皇帝供着五尊神像：老子、孔子、释迦牟尼、耶稣、穆罕默德。

    * 对一个虔诚的基督徒来说这是不可想象的：怎么可能信这么多。

    * 皇帝的回答很实在：你知道天上那位是谁呀？我都放在这儿，也许就碰上了；我只放一个，放错了呢。

    * 反讽：这份绝对的不虔诚，假如我是上帝，怎么收你。

* **有限无界**

    * 人生可比作爱因斯坦的宇宙——有限无界。

    * 面对的可能性是永远无穷尽的，只不过需要在其中去选择有限的可能性。

    * 人生始终向着未来：哪怕走到人生的最后一步，仍然在朝向着未来。

* **哲学是启发而非说教**

    * 哲学不应该说教，不应该提供一种所谓规范的世界观和人生观，它应该启发人们思考。

    * 学完哲学史会发现：哪个哲学家讲的都有道理，但他们相互之间的思想都是不一样的。

    * 学哲学史的好处：不再迷信，树立一种问题意识和批判意识。

## 哲学与科学的分野

* **抽象思维**

    * > **定义**：所谓抽象思维，就是从众多事物中抽象出共性，来把握它们共同的本质。

    * 例：从牡丹、玫瑰、菊花等各种花抽象出"花"的概念，概括世上所有的花；再向上抽象出"植物"，说明花草树木。

    * 抽象的程度越高，所说明的事物就越多。

    * 形式逻辑的表述：概念的内涵与外延成反比——内涵越少，外延越广；内涵越多、越具体，指称的事物越少。

    * 科学的理想是抽象到最高的那个概念、用它说明宇宙万物；这是理想，无法预期它终归可以实现。

* **哲学抽象的方向相反**

    * 哲学家也要把握对世界最普遍、最一般的说明，找到能说明宇宙万物的东西——比如"存在"，比如"绝对"。

    * 但哲学家不可能等科学家把这个工作做完再去做；哲学家试图直接把握那个最普遍、最一般的东西。

    * 因此总在找第一原理：笛卡尔要从那个不证自明、无可置疑的第一原理出发，推演出整个知识大厦。

    * 柏拉图要找到"理念"；理念绝不是从感觉经验出发概括出来的结果，相反，它倒是感觉经验的东西的根据。

    * > **结论**：科学从经验观察出发逐级向上抽象，向着那个永远到不了的理想进展；哲学家反其道而行，试图一步直接把握第一原理，再从它推演出一切。

* **哲学的理想性**

    * 哲学家要直接把第一原理拿到手，根据何在？它是一个理想境界。

    * 希腊人认识宇宙、自然，背后很重要的原因是要给人找到安身立命的根据；认识宇宙的合理性，无非是要证明人的合理性。

    * 对宇宙合理性的认识确实促进了各门自然科学的发展，但哲学家的这个理想没有办法得到充分的实现。

* **没有胜利者的战场**

    * 每一位哲学家都试图通达智慧的顶点，每一位哲学家的运思之路都是一条指向智慧终点的独特道路。

    * 没有哪一条道路真的能够通达那个顶点；在每一条哲学道路的终点，总会竖起一个牌子，上面写着：此路不通。

    * 后来的哲学家换一条路去走，总是在不断地否定前面的哲学家，因为他没有解决问题。

    * 从这个角度看，哲学史留给我们的无非是失败的记录，一个只有失败者、没有胜利者的战场。

    * 意义要从哲学问题的本性里找：这些问题永恒无解、没有终极答案，但人不可能不去追问——它们关涉根本的生存，不是如何生存、生存得更好，而是为什么生存。

    * 没有人能够在有生之年跨越有限与无限之间那道鸿沟；但人不甘心于作为一个有限的存在，总是要试图超越自己的有限性。

    * 没有人不希望永生，这是人有理性的一个结果、一个理想；尽管不可能最终实现，这个理想始终激励人们去探索，哲学就是这样一种探索。

* **哲学不是科学**

    * 哲学不是科学，恰恰不是它的缺陷，而是它存身立足的地方。

    * 它不是对自然的研究，它体现的是一种理想的东西。

    * 哲学史最根本的东西：哲学家要证明宇宙的合理性，连带背后是要证明人生存的合理性。

    * 康德之后、19 世纪下半叶之后，再去证明宇宙万物自身的合理性已不现实；于是转为证明人的世界的合理性——仍然还在证明合理性。

* **两类哲学问题**

    * 最高的问题：终极关怀——人究竟从何而来、归于何处，对宇宙之所以存在感到惊讶、感到好奇（希腊人的好奇）；通常叫本体论或形而上学。

    * 最基本的问题：看起来容易回答，其实也不容易。例：$1+1=2$ 被认为是自明的，因为没有人可以提出反例；但要从理论上证明它为什么成立，其实很难。

    * 越基本、越简单的问题，因为它构成了前提和基础，它也是最难的问题。

    * 康德的比喻：人类有一种爱好，把一座塔建起来，会把它拆掉，看一看那个塔基是不是坚固，然后再盖起来，然后又拆掉。

    * 哲学史就是人们不断地拆建的过程；因为它在追问基础的问题，而基础的问题会不断地深入。

    * 学习方式的差别：科学知识在发展，最新的成果不断把旧的"往下压"，中学的知识可能降到小学去学；哲学没有谁高谁低、谁对谁错的判断。

* **每个哲学家都是一座里程碑**

    * 每一个哲学家的思想都可以看作历史上的一座里程碑，标志着解决哲学问题的一个独特方式。

    * 哲学思考最根本的问题，思到根本之处，就会以非常极端的、根本的方式把一条路走到黑，一直推到极致；每一条哲学道路都是一个代表。

    * 既然问题没有得到最终解决，就不能说柏拉图解决的方式高于亚里士多德，也不能说有了康德就可以不要黑格尔。

    * 大哲学家或者带有思想转折的意义，或者把一种哲学思想推到极致，总而言之都是一种代表，具有不可替代的意义。

    * 这样去学，我们也就进入到这条思考哲学问题的道路之中，也就参与其中。

## 哲学的定义与人的本性

* **定义之难**

    * 越学下去越会发现：没办法给哲学下一个非常准确的定义。

    * 教科书式的定义——"哲学是对自然科学、社会科学、人类思维最一般规律的概括和总结"——是很古典的定义，放在 100 多年前也许可以，放在今天绝对不可以。

    * 今天没有人能够对整个哲学史、对整个人类知识做概括和总结；某一个学科想做到都做不到。

    * 例：陈景润一辈子研究哥德巴赫猜想，哥德巴赫猜想当然算数学，但他一辈子研究的只是哥德巴赫猜想；称之为数学家，其实只是在某个分支的某个问题上有所建树。

    * 一个学科都没有可能有人去精通，遑论把所有学科、所有人类知识概括和总结。

    * 黑格尔之后，人们也不去做这个工作：19 世纪下半叶发生哲学转向，建立恢弘庞大哲学体系的热情不再有了，哲学的功能发生了变化。

* **追问植根于人的本性**

    * 人区别于其他存在，很重要的一点是：它是一个非现成的、非凝固的、永远指向未来的、永远面对可能性的一种存在。

    * 以往的追问方式像追问物质：桌子有桌子的本质，找到本质就能说明桌子；于是以为有先天存在的人的本质规范着人——"这就叫人"。

    * 这其实是以看待物的方式来看待人。

    * > **易错点**：人不是桌子。无论人受到多大限制，人总是具有某种程度意义上的自由，总是在面对可能性；用一套现成的"人的本质"去规范所有人，恰恰漏掉了人之为人的根本。

    * 实现可能性会受到各种条件制约，制约在不同人那里表现不一样，但人总有选择的余地和可能性。

    * 假如一切由必然性决定，人其实可以不去努力、不去探索、不去追求；但人的本性恰恰在探索。

    * 人生的意义不是先天规定在那儿的，而是人在自己塑造自己的人生，它是指向未来的。

    * 未来是一个开放的理想目标，在任何时代、对任何人都有，但它的具体体现不同——要由我们把相对比较具体的内容填充进去。

* **哲学的定义**

    * > **定义**：哲学是过去、现在乃至将来，人类理性围绕哲学问题所做的永恒的探索。

    * 这与其说是一个定义，不如说是一个说明，而且只能如此，没有办法再给出更精确的说明。

## 哲学史观

* **哲学就是哲学史**

    * 哲学史作为一门学科，严格说来是从黑格尔开始的；在他之前有零星的哲学史著作，如今已淹没在历史之中。

    * 黑格尔的观点：哲学史上看似互不相干或者相互冲突的哲学思想，实际上是哲学在不同的历史时期、在不同的哲学家那里的一种表现。

    * 哲学是对宇宙万物最根本的东西的认识和把握，黑格尔把它叫做**绝对精神**。

    * 历史上的哲学家都需要去认识这个绝对精神，他们的体系各自把握到绝对精神的某一个环节、某一个要素、某一个方面。

    * 最晚出的那个哲学体系，作为对以往所有哲学中合理因素的整体把握，就是"科学"。

    * 辩证法：任何东西只要存在，总有其存在的价值，但也有其局限性。

    * 整个哲学史是对绝对精神的认识过程，而且不是一个代替一个，而是所有合理因素通过辩证关系最终保存下来。

    * 因此只有一种哲学，它在不同哲学家那里表现为一个特殊的形态；只有站在哲学史上，才能对哲学有完整的把握。

    * 黑格尔号称发现了哲学发展过程的一个内在规律，哲学史由此成为学科。

* **谦虚的一面**

    * 黑格尔从来不认为"我黑格尔的哲学体系是我的独创、我的首创"。

    * 他说自己的哲学是整个哲学史发展下来的一个结果，他做的工作无非是通过某种方法让它们连接成一个有机的体系。

    * 前人都探索了、都有合理的因素，但都没有完成；他无非是把所有合理因素构成一个有机体系。

    * 德国哲学家带有非常浓厚的历史感，黑格尔尤其如此：他从来是站在哲学史的角度，而不是站在"我是对的、前人全错了"的角度。

* **狂妄的一面**

    * 他居然想终结人类的整个探索——讲哲学的终结、讲完成。

    * 这个完成就体现为让哲学成为科学。

    * 根源在于他秉承西方哲学的核心观念——科学的观念，千方百计要使哲学成为科学。

* **过时的答案，不过时的方式**

    * 哲学史上所有哲学家那些具体的答案内容其实都过时了：泰勒斯第一个讲"大地浮在水上"，今天没有人认为这是一条真理。

    * 但泰勒斯提出本源的问题、试图以自然去说明自然、以水作为宇宙万物的本源——这种方式作为一个典型，依然有意义和价值。

    * 哲学家留给我们的是他面对哲学问题所提出来的、他所特有的解决问题的方式。

    * 要确定一个哲学家在哲学史上的地位，就看他面对哲学问题提出了什么独特的解决方式。

    * 思想当然有继承，后人总是在前人基础上往下思考；但在根本问题上，如果不变换解决问题的角度，就没有办法继续走下去。

    * 例：亚里士多德如果按照柏拉图的理念论走下去，绝不会有后世亚里士多德的地位；柏拉图学园存在几百年，学生中没有能与亚里士多德比肩的大哲学家。

    * 亚里士多德显然看出柏拉图那种解决方式——理念和事物的分离问题——是要害，所以他的解决方式与柏拉图不同；康德、黑格尔也是这样。

* **哲学史是哲学**

    * 反其意而用之：不是只有一种哲学，而是有很多种哲学，哲学永远是开放的。

    * 黑格尔的合理因素在于：哲学史不是死人的战场、失败的战场，不是放古董的仓库，而是一个活生生的发展的过程。

    * 哲学家的思想永远不会过时：他既活在他那个时代，也活在我们今天。

    * 学哲学史就是让他们的思想得到复活；这个复活不是简单的复古，而是在我们今天的环境、我们这个时代里的新生。

    * 经典之所以"常读常新"，意就在这儿：它是活的，永远活在我们的思想里面，我们不过是把这个思想再往前推进。

* **思想的自我反思**

    * 分开来说：哲学家的思想是他的思想，我在思考他，他是对象。

    * 往高的层次讲：你和哲学家都是人类思想的发展；你对哲学家思想的思考，就可以看作是人类精神自己在思考自己的思想。

    * 不是把哲学家的思想看作一个外在的对象：你和他都是人、都是思想——思想在思考，思想是思想的自我反思。

    * 正是在这种思想反思的活动之中，哲学家的思想获得新的意义。

## 读哲学的门径

* **学哲学就是读书**

    * 学哲学史不是看教科书；教科书只是一个基础，需要你往前深入。

    * 学哲学其实就是读书，就是读哲学家的著作。

    * 四条要领：了解哲学家的问题；熟悉哲学家的术语；遵循哲学家的思路；透过他之所说，体会他想说的东西。

* **问题意识**

    * 第一条是核心：了解哲学家的问题。哲学是哲学史，哲学史是问题史。

    * 把它当作知识学没有意义；只有把哲学家的问题当作自己的问题，或者把我们的问题上升到哲学的问题，才能与哲学家产生共鸣，知道他是为什么要这么说。

    * "知其然，还要知其所以然"：知道他说的，还要知道他为什么这么说、因为什么要说这些。

* **术语**

    * 每个哲学家都要使用日常语言，但都会改造日常语言、为他所用。

    * 同一个概念，在日常生活中和在哲学中意义不一样——日常也说"存在"，但与哲学中的"存在"肯定不同。

    * 甚至同一个术语在不同哲学家那里含义也不一样："存在""实体""本质"都是如此。

    * 要了解一个哲学家的思想，就必须知道他这一套术语在他那里的含义；抓住这一点，才能知道他要干什么、说的是什么。

* **遵循思路，盯住前提**

    * 哲学家都是有论证的，都有一套自己的逻辑，思想往往能够自圆其说，尽管里面会有漏洞。

    * 批评一个哲学家无非两个方面：论证有问题，论证错了他体系就被推翻；或者出发点就错了，那个大前提、哲学第一原理有问题。

    * > **结论**：大哲学家的体系通常能自圆其说，致命的毛病多半藏在前提里，而不在论证的推演中。

    * **二律背反**：追问超出经验范围的宇宙万物时，对同一个对象可以有两种各自自圆其说、但相互冲突的理论——"自己能自圆其说、理论与理论之间却彼此冲突"，原因就出在大前提上。

    * 只知道这个人的思想、基本定性、大原则，顶多算入门；真正有启发性的东西在具体论证过程里，学哲学家的思想不能忽略细节。

    * 理解哲学家的思想，说到底是透过他之所说去体会他想说的东西；读哲学著作有时像猜谜。

* **晦涩的根源**

    * 哲学著作翻译成汉语，每个字都认识，但就是不知道他在讲什么。

    * 不是故弄玄虚：哲学家都愿意把发现的真理说出来让大家知道，但苦于找不到合适的表达方式。

    * 表达思想只有一种语言——自然语言、日常语言；并没有一套专属哲学的语言。

    * 日常语言在人与人之间具体的交流、描述、表达事物中有效，那是有限的具体的东西；现在要用它表现的，是那种无限的东西。

    * 例：巴门尼德"存在存在，非存在不存在"，不知所云，原因就在这儿。

    * 类似戏剧《一仆二主》：只有一套语言，具体生活中可以使用，哲学也要用它来表现，没有办法。

    * 读哲学著作不能认为通过直接的字面意义就能理解，必须通过字面含义去体会它想要表达的东西。

    * "道可道，非常道；名可名，非常名"——你说出来了，就离开那个东西了。

* **视域融合**

    * 古典解释学强调客观地、按照哲学家原来的样子去理解他；在那种范式里，你没有办法有自己的思想，提新思想叫"离经叛道"。

    * 经典意味着典范；假如后世只知道有经典、只知道解经释典，就永远不会有新思想出现。

    * 现代哲学解释学由伽达默尔的《真理与方法》建立（20 世纪 60 年代）。

    * 以往的假定：哲学家的思想保存在著作里，一本著作就是一个文本，文本的意义客观地存在在那儿，学习只是把意义再现出来。

    * 质疑之一：任何哲学著作都在不同的历史时期、文化背景、个人背景下写作，要了解它必须还原到那个背景，而我们无法把自己变成一张白纸、像复印机一样复制那个环境。

    * 质疑之二：我们自己也生活在不同的历史时期、文化、时代、个人环境之下，同样不可能变成一张白纸。

    * > **定义**：视域融合——哲学家总在他自己的视域里写作、表达思想，我们则在我们的视域里看待他们的思想；两种不同的视域围绕同样的问题相互交融。

    * 文本的含义不是不可改变的、客观摆在那儿的东西；它是活的，有一个生成的过程，在我们的阅读过程中获得新的生命。

    * 中世纪、近代、现代对柏拉图的理解会不同，而他写出来的对话是一样的；更重要的是柏拉图的问题是永恒的问题，在不同背景下表现形式不同，就有了新的意义。

    * 我们也参与到这个文本含义的生成之中；历史和现实是一个内在的关系。

    * > **易错点**：这并不意味着失去客观性。视域融合不是"怎么读都行"——你的视域必须和古人的视域真正交融，客观性就守在这个交融的要求里。

    * "有一千个人就有一千个哈姆雷特"，是同一个意思。

* **对话的条件**

    * 学哲学史、读哲学家著作的方法叫**对话**——思想和思想之间的对话。

    * 要件一：要有问题。对话总要围绕共同的问题展开；不在同一个平台上，你发挥你的、我走我的，就没法对话。

    * 要件二：哲学家说什么你就记住什么，没有用，这样入不了门；要做的是就共同的问题向哲学家求教。

    * 哲学家的书不可能由他本人再作修改，但在视域交融之中，哲学家的著作其实也在回应我们。

    * 对话最根本之处，在于最后你要理解对方。

    * 讲哲学史、讲德国哲学不过是一个入门、一个导论，为的是引导你直接和哲学家对话。

    * > **提示**：在这一点上外语一定要学好：读哲学家的书，恐怕最终要读原文原著，翻译过来的东西总有各式各样的问题。

* **思想在思想思想**

    * 哲学家思想里那个活的东西，在于历史性和现实性之间有一种有机的内在张力。

    * 我们的思想（动词）去思想哲学家的思想（名词）；站得更高一点，从整个人类精神来看，这应该看作思想的自我反思。

    * 学哲学不能像学自然科学那样老师讲什么是什么；我们不是一张白纸。

    * 哲学家有哲学家的问题，这个问题尽管可能变形，对我们现在来说仍然是问题；我们和哲学家其实是围绕共同的问题在进行思想的交流。

    * 把哲学家讲的复制过来，不起作用的。

## 德国哲学的位置

* **思想体系的时代**

    * 康德 1724 年出生、1804 年去世；黑格尔 1831 年去世。

    * 康德、费希特、谢林、黑格尔这几位德国古典哲学的主要代表，处在 18 世纪末 19 世纪初，这段时期被称为"思想体系的时代"。

    * 每个人都建立了非常庞大的哲学体系，其中最大的是黑格尔的体系。

    * 哲学要想成为科学，靠的是体系、靠的是论证：没有办法用经验去验证、没有办法做实验，只能靠体系；一个科学体系才表现它是科学。

* **前无古人，后无来者**

    * 前无古人：到黑格尔才算集大成。

    * 后无来者的含义之一：后人再没有这种可能性了——黑格尔那个年代还敢说"我对人类知识做一次概括和总结"，今天的知识量之下这是笑谈。

    * 后无来者的含义之二，也是更重要的一点：哲学家不再做这个工作了，黑格尔是最后一位；柏格森等个别人还想建体系，但已不是西方哲学的主流。

    * 黑格尔把整个西方哲学史、古典哲学内在的潜力都激发出来了，一切尘埃落定；后世发现此路不通，必须整个哲学发生转向才有可能。

    * 哲学的对象、方法各个方面都发生了转向。

* **两大潮流**

    * 19 世纪尤其上半叶，德国哲学是主宰、是主流；此后还有叔本华、尼采这样的大哲学家。

    * 20 世纪西方哲学通常说两大潮流：英美分析哲学与大陆哲学，各占半壁江山。

    * 大陆哲学主要是德国哲学：弗雷格、胡塞尔、海德格尔、伽达默尔。

    * 英美分析哲学、语言哲学的发端者弗雷格就是德国哲学家；其主将、影响极大的维特根斯坦是奥地利人，但用德语思考和写作。

    * 上世纪七八十年代之后，西方哲学尤其在大陆，法国哲学取代了德国的位置：存在主义已经过时，主要是后结构主义和后现代主义，还有列维纳斯、德里达等；但法国哲学深受德国哲学影响，尼采、胡塞尔、海德格尔都在它背后。

* **四位哲学家的选取**

    * 康德是现代哲学的开端，黑格尔是古典哲学的终结——都是比喻，不是严格的规范判断。

    * 了解了康德，你知道现代西方哲学从何而来；了解了黑格尔，你知道古典哲学归于何处；由此抓住西方哲学来龙去脉的枢纽。

    * 维特根斯坦体现了德国思想：奥地利人、用德语思考和写作，代表英美分析哲学这一脉。

    * 海德格尔从现象学到他自己的存在哲学，讲海德格尔就不可能不讲他的老师胡塞尔的现象学。

    * 从康德到黑格尔中间还有费希特、谢林；关于康德讲的内容会比其他几位多一点。

## 康德哲学的起点

* **生平与分期**

    * 1724 年出生，1804 年去世，活了 80 岁。

    * 哲学思想分为**前批判时期**与**批判时期**，因为他成熟的著作都以"批判"为名：《纯粹理性批判》《实践理性批判》《判断力批判》，三者构成批判哲学体系。

    * > **提示**：批判哲学有一个很长的形成过程。1781 年《纯粹理性批判》出版才真正标志其形成，那一年康德已经 57 岁；此后大约 10 年，他写出了主要的哲学著作。

* **反传统时代的康德热度**

    * 西方哲学本来就以反传统著称，后来的哲学总要推翻前面的、提出自己的新思想。

    * 19 世纪下半叶，叔本华、尼采、克尔凯郭尔等非理性主义登上历史舞台；20 世纪初，逻辑实证主义、分析哲学、现象学等思潮都以反传统、反黑格尔的名义出现。

    * 黑格尔以前的统称西方**古典哲学**，黑格尔之后尤其 20 世纪称为**现代哲学**。

    * 就在这种反传统的气候里，作为古典哲学家的康德受到极强烈的关注：进入 21 世纪，西方学界出版的专门以康德哲学为研究对象的著作有 963 种，相当于每天都有两三部研究康德的著作出版。

    * 研究的三条标准：把哲学家的思想弄懂、著作读懂；最经典的二手资料读到、读懂；掌握国际学科前沿最新成果——就康德研究而言极难达到。

    * 康德之所以影响持久，很重要的原因是：他所面临并且试图解答的是哲学的核心问题，而且这些问题也是我们所面临的问题。

    * 哲学问题可以看作一个**问题域**，相互关联；大哲学家一定会回应核心问题，而核心问题往往牵一发而动全身，一个问题的变化会导致所有观念的变化。

* **面临的三类问题**

    * 理性的危机：经验论与唯理论关于科学知识的证明陷入困境。

    * 自由的失落。

    * 形而上学陷入困境。

    * "理性的危机"这个说法可能显得夸大，但为了突出它带来的后果，不妨把话说重一点。

* **经院哲学的类比**

    * 中世纪的哲学是在神学的前提下进行哲学思考的，哲学为神学服务；围绕共相与殊相的争论分出唯实论与唯名论。

    * 安瑟尔谟、托马斯·阿奎那做的都是上帝存在的证明，都需要证明理性和信仰能够调和、理性能够为信仰服务。

    * 若无法调和理性和信仰，可能导致两个结果：不能从理性上证明信仰，导致信仰的危机；或者人们对哲学感到失望。

    * 实际结果是后者——文艺复兴人文主义，其特点是全面转向感性：人们对经院哲学繁琐的抽象推理厌烦透了。

    * 文艺复兴在文学艺术上大艺术家比比皆是（拉斐尔、达·芬奇、米开朗基罗，但丁《神曲》、莎士比亚戏剧、塞万提斯《堂吉诃德》、拉伯雷《巨人传》），但在哲学上却拿不出与之相称的一流成果。

| | 中世纪：理性为信仰服务 | 近代：哲学为科学知识辩护 |
| :--- | :--- | :--- |
| 思考的前提 | 在神学前提下做哲学，哲学为神学服务 | 经验论与唯理论要为科学知识提供证明 |
| 面临的僵局 | 无法调和理性与信仰 | 经验之路被休谟的怀疑论堵死；唯理论则立刻撞上心物关系问题 |
| 失败后的两种可能 | 信仰的危机，或人们对哲学失望 | 科学知识其实没有普遍必然性，或科学有而我们无能证明 |
| 实际的走向 | 人们对哲学失望，文艺复兴人文主义全面转向感性 | 显然是后者，这正是康德出场的起点 |

* **休谟的怀疑论**

    * 经验论一路下来：洛克、贝克莱，到休谟最后导致怀疑论；罗素称他为"英国经验论的逻辑终局"。

    * 休谟强调：一切经验都是相对的、个别的、偶然的经验，重复一万次仍然是经验。

    * 经验只对过去、现在已经经验到的东西有效，对没有经验的东西无效；由经验给出的不过是**或然的知识**。

    * 从经验论出发，就已经杜绝了证明科学知识普遍必然性的道路。

* **唯理论的困境**

    * 唯理论坚持从头脑中的**天赋观念**出发，马上要面临心与物之间的关系问题。

    * 笛卡尔的二元论：两个实体，一个是思想实体，一个是广延实体。

| | 关于观念关系的知识 | 关于事实的知识 |
| :--- | :--- | :--- |
| 典型 | 逻辑学、数学（如毕达哥拉斯定理） | 面对经验、面对自然的最大多数知识 |
| 性质 | 普遍必然，可称为先天的知识 | 或然的知识 |
| 局限 | 范围狭小，与经验无关 | 经验相对、个别、偶然，只对已经验者有效 |

    * 休谟设下的两难：先天知识虽然普遍必然，却与经验无关、范围狭小；面对经验的最大多数知识又统统只能是或然的——"既普遍必然、又关于经验世界"的科学知识，两栏里都找不到位置。

    * 休谟还讲：即使宇宙中不存在三角形，毕达哥拉斯定理也应该是真理，因为它自身是逻辑成立的。

* **康德的出发点**

    * 不能证明科学知识的普遍必然性，会导致两个结果：科学知识本来就没有普遍必然性；或者科学知识有，而哲学无能、没办法证明。

    * 显然是后者。

    * > **结论**：事实上我们具有普遍必然性的科学知识，比如欧几里得的几何学和牛顿物理学，这是事实；问题在于哲学（经验论、唯理论）没有办法证明它的科学性。

    * 18 世纪康德登上中心舞台时，哲学舞台上是怀疑主义、唯物论；尤其在法国，那是经验论的天下。

* **经验与理性之争的谱系**

    * 这场争论古已有之：赫拉克利特与巴门尼德代表两种不同观念；柏拉图区分两个世界；柏拉图与亚里士多德之争；中世纪唯实论与唯名论之争，都涉及理性和经验之争。

    * 到近代哲学有了新的表现形式，这要从哥白尼讲起。

    * 15 世纪是世界史、欧洲史上非常重要的时期：大航海、新航路开辟、海上贸易发展，也是自然科学发生巨大变化的时期。

    * 我们今天所谓科学知识的整个**范式**，是 15 世纪这个时期奠定起来的，与以往完全不同。

    * 哥白尼提出日心说的假说：地球并不是原来理解的宇宙中心，它不过是围绕太阳转的一颗普通行星，不是太阳围绕地球转。

    * 日心说被证明后，人们对自然、对宇宙的深刻研究被激发起来，开拓了从伽利略到牛顿的道路。

    * 地球失去了那个神圣的地位，不再是神学核心的东西，而变成了科学可以研究的一个自然对象。

    * 这就是康德登场时的思想地形：一门已经站稳脚跟的自然科学摆在面前，而哲学却还拿不出对它的证明。
