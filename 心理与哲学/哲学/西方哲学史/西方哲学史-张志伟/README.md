# 西方哲学史（张志伟·人大公开课）（131 讲）

中国人民大学张志伟教授的《西方哲学史》公开课全 64 讲，另附「德国哲学选读」与「茶点」专题讲座共 67 个分 P，合计 131 讲。主课沿哲学史主线走：从希腊文明的哲学诞生、苏格拉底/柏拉图/亚里士多德，经中世纪教父哲学与近代曙光、笛卡尔、斯宾诺莎与经验论、霍布斯与卢梭，到康德的哥白尼式革命、黑格尔与人生的意义；选读部分是对德国哲学的重笔深挖——康德十讲、费希特、黑格尔十三讲、维特根斯坦、胡塞尔、海德格尔十一讲；茶点部分收尼采解读、哲学的危机、启蒙的自我调适与「物自身/显象/现象与本体」概念辨析。131 讲整编为 10 册模块全书与 12 篇主题复习笔记。

## 怎么学

- **主课与选读分开读**：主课（模块 01–05）是通史速览，选读（模块 06–08）是对康德、黑格尔、海德格尔的专题深挖，先通史立框架、再选读补纵深。
- **古希腊是地基**：柏拉图的两个世界与亚里士多德的实体学说，是后面一切「实在与现象」争论的源头，笔记 02 值得细读。
- **康德是分水岭**：哥白尼式革命、理论理性、先验辩证论、实践理性、判断力批判五段，主课与选读各讲一遍，对照着看能看出难度梯度。
- **德国观念论连成线**：康德 → 费希特 → 黑格尔是同一个问题的三次回答，笔记 06/08/09 连读效果最好。
- **茶点专题当「复盘」用**：尼采解读、哲学的危机、启蒙的自我调适，都是对主线的回望，放在最后读。
- **考前只看 `notes/`**：12 篇笔记按哲学史阶段重组，人物—问题—论证结构并排放置。
