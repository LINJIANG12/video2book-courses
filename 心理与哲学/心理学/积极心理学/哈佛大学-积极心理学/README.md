# 哈佛大学：积极心理学（23 讲）

Tal Ben Shahar 的哈佛公开课从幸福与积极心理学的基本问题出发，解释环境、期待、乐观、感激、习惯、压力、完美主义、亲密关系、自尊与幽默如何共同塑造人的幸福与成长。课程不把积极简单化为永远快乐，而是讨论如何看见可能性、承受现实、主动改变，并把积极体验转化为日常生活中的练习。

- **原视频**：[【哈佛大学】积极心理学 Talben Shahar（全23讲）](https://www.bilibili.com/video/BV1Ka411w7qd/) — Bilibili，BV1Ka411w7qd
- **全 23 集**，已产出 21 册模块全书、7 篇复习笔记、46 份逐字稿

## 怎么学

**先抓住课程的总问题：幸福感究竟来自什么**。先读模块 01~03，理解积极心理学的研究边界、解释框架和幸福观，再进入具体练习。

**把环境、期待和解释方式串成一条链**。模块 04~08 讨论环境力量、乐观、逆境、感激和积极情绪，重点不是盲目乐观，而是观察事实、选择解释并采取行动。

**用模块 09~14理解改变如何落地**。把高峰体验、习惯、压力、写日记、完美主义和享受过程联系起来，区分短暂的情绪提升与能够持续的行为改变。

**把身体和关系当作幸福的基础设施**。模块 15~20 讨论运动、冥想、睡眠、触摸、爱情、自尊与幽默，既关注个人练习，也关注关系中的看见、接纳和共同成长。

**复习时优先读 7 篇笔记**。笔记按主题归并了整套课程，适合考前速查、知识回顾和导入 Markmap / XMind；需要核对讲师原话时再查 46 份逐字稿。
