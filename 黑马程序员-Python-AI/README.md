# 黑马程序员：Python + AI 零基础入门

零起点 Python 课程，从装解释器开始，讲到面向对象、模块化与异常处理。全 87 集，节奏适合完全没有编程基础的人跟学，也适合有其它语言经验的人快速过一遍 Python 语法。

- **原视频**：[黑马程序员 Python+AI 零基础入门到大神全套视频课程](https://www.bilibili.com/video/BV1sHU9BmEne) — Bilibili，BV1sHU9BmEne
- **全 87 集**，已产出 16 册模块全书、8 篇复习笔记、87 份逐字稿

## 怎么学

如果你是第一次学编程，**一定要边读边敲**——这门课大量内容是环境操作与语法细节，光看记不住：

- **按顺序学** → `textbooks/` 从模块 01 顺读到模块 16，模块 01~02 讲路线与环境，别跳，装不好环境后面全卡
- **写代码时查语法** → 打开 `notes/`，速查粒度比模块全书更直接，查完就能接着写
- **遇到报错** → 模块 16 讲异常处理，模块 10~11 讲函数传参，这两个模块覆盖了新手最常见的困惑点
- **想确认老师原话** → `subtitles/` 有全部 87 份逐字稿

学完模块 09（数据容器）和模块 14~15（面向对象）后，可以接着读本仓库的 [AI 大模型 NLP 课程](../黑马程序员-AI大模型NLP/)，那条线从词向量开始，需要 Python 基础。
