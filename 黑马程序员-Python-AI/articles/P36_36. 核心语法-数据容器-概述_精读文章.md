# 数据容器概述

前面已经走完了 Python 核心语法的两个部分：一部分是数据的存储与运算，另一部分是数据的逻辑处理，也就是流程控制语句。接下来进入第三个部分——数据存储容器。

第一个问题自然是：什么是数据存储容器？

## 一、为什么需要数据容器

容器是用来存东西的，数据存储容器顾名思义就是用来存储数据的。

在讲数据的存储与运算时已经讲过，Python 中可以通过变量来存储数据。既然有变量了，为什么还要数据容器？

原因在于：所定义的这些普通变量，**一个变量只能存储一项数据**。

如果现在需要存储多项数据，就得定义多个变量；如果要存储大量的数据，就需要定义大量的变量来分别存放。这件事非常繁琐，也非常臃肿。

```text
普通变量的做法:
    a = 数据1
    b = 数据2
    c = 数据3
    ...            -> 存 N 项数据就要写 N 个变量, 冗长且难维护

数据容器的做法:
    变量 = 数据容器( 数据1, 数据2, 数据3, ... )
                   -> 一个变量装下多项数据, 简洁且优雅
```

读图要点：两种做法的差别不在能不能存下数据，而在变量个数——普通变量随数据量线性增长，容器只需要一个变量。

为了解决这个问题，Python 提供了数据容器：需要存储大量数据时，定义一个变量，让这个变量的类型是一种数据容器，然后在这个容器当中存放大量的数据。基于数据容器来存储这些数据，会更加简洁，也更加优雅。

> **定义**：数据容器是一种可以容纳多份数据的数据类型。因为它可以容纳多份数据，所以也把它叫做一个容器。

## 二、容器与元素

容器里的每一份数据，都称之为一个**元素**。比如一个容器当中有多份数据，每一项数据就叫一个元素。

每一个元素可以是任意类型，这不是一句宽容话，而是实实在在的规则：里面存放的元素可以是字符串类型，可以是数字类型，也可以是布尔类型。同一个容器里的元素不必类型统一。

> **提示**：元素类型任意，指的是存入时不受限制。真正按类型取值、运算时，仍然要保证用法与该元素的类型匹配。

## 三、五种常见数据容器的分类

Python 当中的数据容器比较多，通常根据三个特征来把它们分类：

1. 是否支持重复元素；
2. 是否可以修改；
3. 是否有序。

按这三个特征划分下来，常见的有以下五类：

| 序号 | 数据容器 | 英文 | 说明 |
| --- | --- | --- | --- |
| 1 | 列表 | list | 最常用的数据容器 |
| 2 | 字符串 | string | 就是前面讲过的字符串，它同样是一种数据容器 |
| 3 | 元组 | tuple | 常见的数据容器之一 |
| 4 | 集合 | set | 常见的数据容器之一 |
| 5 | 字典 | dict | 常见的数据容器之一 |

字符串出现在这张表里，可能是最容易让人意外的一点——它不是"新知识"，而是在讲字符串定义和拼接的时候就已经在用的一种数据容器。
