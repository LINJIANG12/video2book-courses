# 邮箱格式校验：字符串查找与统计方法的实战

## 1 案例需求与判定规则

字符串的基本操作和常用方法学完之后，得找个东西把它们串起来用一遍，否则那些 `find`、`count` 之类的名字过两天就只剩一个模糊印象。这个案例就是干这个的：把前面讲过的字符串方法放进一个真实需求里，看它们各自该在什么位置出现。

需求本身很朴素：用户输入一个邮箱，程序验证邮箱的格式是否正确——正确就输出「邮箱格式正确」，否则输出「邮箱格式错误」。

这里的关键在于「格式正确」到底指什么。一个邮箱地址不能是任意一个字符串，它有自己的格式要求。这一讲采用的判定规则有两条：

1. 邮箱地址中必须有一个 `@` 符，而且**只能有一个**（必须得有一个，且不能多）；
2. 邮箱地址中**至少得有一个点**。

第二条规则看例子最清楚：

| 邮箱示例 | 点的个数 | 是否符合规则 |
| --- | --- | --- |
| `@163.com` | 1 | 符合 |
| `@mail.itcast.cn` | 2 | 符合 |

> **结论**：`@` 符只能有一个；点可以有多个，但至少得有一个。

## 2 实现思路与代码

需求拆开来看，只有两步操作：

1. 接收用户输入的邮箱；
2. 判断邮箱的格式。

第一步用 `input` 拿输入，变量名取 `mail`，见名知意。第二步要做判断，自然就用 `if` 语句。

真正需要动脑筋的是：用什么方法判断「邮箱里有且只有一个 `@`」和「邮箱里至少有一个点」？前面演示字符串方法时，有两个方法都是用来做查找和统计的——一个是 `find`，另一个是 `count`。

> **提示**：这两条规则都对「出现几次」敏感，所以该用 `count`，而不是 `find`。`find` 只解决「在不在、在哪儿」，解决不了「有几个」。

```python
# 接收用户输入的邮箱
mail = input("请输入邮箱：")

# 判断邮箱格式：@ 符只能有一个，点至少有一个
if mail.count("@") == 1 and mail.count(".") >= 1:
    print(f"{mail} 是合法的邮箱")
else:
    print(f"{mail} 是非法的邮箱")
```

`mail.count("@")` 统计 `@` 这个字符串在 `mail` 中出现的次数，等于 `1` 就说明恰好出现了一次；`mail.count(".")` 统计点的次数，大于等于 `1` 就说明至少有一个点。两条规则是并且的关系——两个都得成立——所以中间用 `and` 连接。

判断成立走 `if` 分支输出「是合法的邮箱」，否则走 `else` 分支输出「是非法的邮箱」，两个分支输出的都是格式化字符串，把用户输入的邮箱原样带回输出里。

## 3 测试验证

写完就跑，用几个不同形态的输入把两条分支都走一遍。

| 输入 | `count("@")` | `count(".")` | 输出 |
| --- | --- | --- | --- |
| `涛哥@163.com` | 1 | 1 | 合法的邮箱 |
| `邓163.com` | 0 | 1 | 非法的邮箱 |
| `邓.涛哥@163.com` | 1 | 2 | 合法的邮箱 |

第二组输入里没有 `@` 符，`count("@")` 返回 `0`，条件不成立，于是输出非法。第三组输入点在 `@` 前面，整个邮箱有两个点、一个 `@` 符，完全符合规则，输出合法。

那如果输入一个后面完全不带点的邮箱呢？整个字符串里一个点也没有，`count(".")` 是 `0`，`>= 1` 不成立，同样判为非法邮箱。

## 4 方式二：用 in 运算符判断子串

上面这种写法并不是唯一解。第二种方式换一个运算符，代码更短。

这个运算符叫 `in`，判断指定的子串是否存在于字符串之中——存在返回 `True`，不存在返回 `False`。列表那部分已经用过它来判断某个元素是否在列表之中，放到字符串上，判断的就是子串。

```text
子串 in 字符串
    ├── 子串出现在字符串中  → True
    └── 子串没有出现        → False
```

读图说明：`in` 只回答「有没有」这一个问题，不回答「有几个」。

> **易错点**：`in` 没法用在 `@` 这一条规则上。它只判断存在不存在，判定不出数量，而 `@` 的要求是**只能有一个**。要准确判断出现了几个，必须用 `count`。反过来，点的那一条规则只要求「存在不存在」，用 `in` 就够了。

按这个分工改一改条件：

```python
if mail.count("@") == 1 and "." in mail:
    print(f"{mail} 是合法的邮箱")
else:
    print(f"{mail} 是非法的邮箱")
```

`.` 的位置放前面或后面都可以，条件表达的意思不变：判断点这个子串是否在 `mail` 里存在。存在就是 `True`，不存在就是 `False`。

再跑一遍测试：`邓@163.com` 输出合法；`邓.涛哥@163.com` 有两个点，`in` 依然返回 `True`，输出合法；`涛哥@163.com` 没有点，输出非法邮箱。

## 5 实现边界与后续方向

这个判断方式并不严谨，只是做了一个简单的格式判断。原因在于目前的工具只有 `count` 和 `in` 这一类「数一数、找一找」的方法，能表达的规则也就仅限于「某个字符出现了几次」「某个子串在不在」这个层次。

真正严谨的邮箱校验要靠**正则表达式**，后面的课程会专门讲。到那时候，邮箱的完整格式规则——用户名的合法字符集、域名各段的约束、顶级域名的长度——都能写进一条模式里一次匹配完。

> **结论**：判断指定的子字符串是否出现在字符串之中，用 `in` 运算符，存在返回 `True`，不存在返回 `False`。

## 本讲提到的题目

### 题目一：判断字符串是否为回文字符串

**题干**：接收用户输入的一个字符串，判断这个字符串是否是回文字符串。

所谓回文字符串，指的是两边是对称的字符串。例如：

- `黄山落叶松，叶落山黄`
- `上海自来水，来自海上`

无论从前面往后读，还是从后面往前读，这两个字符串都是一样的，这种就叫回文字符串。

**解析**：判断对称，需要把字符串倒过来和原串比一比。字符串自带反向步长的切片写法，切片语法与前面列表切片一致，只是把步长写成 `-1`：

```python
s = input("请输入一个字符串：")

# 切片写上 -1 步长，得到的就是反转后的字符串
if s == s[::-1]:
    print(f"{s} 是回文字符串")
else:
    print(f"{s} 不是回文字符串")
```

`s[::-1]` 从字符串末尾往开头逐个取字符，取出来的是一个新字符串，原串不受影响。两个字符串相等就是回文；不相等就不是。

> **提示**：题目里给出的两个例子都带标点，比较时得保证正读反读的是同一串字符——像「黄山落叶松，叶落山黄」这样标点在中间、两侧完全对称的写法，才可以直接比。如果标点只出现一次，反读出来的字符序列就和原串对不上，那是题目给的例子本身的对称性，不是判断方法出了问题。

### 题目二：翻转并转大写后存入列表再遍历输出

**题干**：让用户输入十个字符串，将字符串统一翻转之后，再转化为大写，然后把转化为大写的字符串保存在列表当中，最后将列表当中的字符串遍历输出出来。

**解析**：这条需求可以拆成四步——收输入、翻转、转大写、存列表、遍历输出。翻转用 `[::-1]`，转大写用字符串方法 `upper`，存列表用 `append` 或列表推导式，遍历输出用 `for` 循环。把收集输入和逐项处理合在一起写：

```python
# 收集十个字符串，逐个翻转、转大写，逐个存入列表
result = []
for _ in range(10):
    s = input("请输入字符串：")
    result.append(s[::-1].upper())

# 遍历输出列表中的字符串
for item in result:
    print(item)
```

`s[::-1]` 先得到翻转结果，`.upper()` 再把翻转结果整体转成大写，两个方法连着写就是「先翻转、再转大写」的顺序，顺序反过来结果一样，但按题干描述的顺序写更贴合需求。最后用 `for` 循环把列表里的每一项打印出来即可。
