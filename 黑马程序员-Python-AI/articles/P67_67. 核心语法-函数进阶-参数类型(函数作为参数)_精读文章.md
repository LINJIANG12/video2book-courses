# 函数作为参数传递

前面三节把函数的传参方式、默认参数、不定长参数都过了一遍，这一节来收尾：参数到底可以是哪些类型。

先回想一下前面写过的函数都收过什么参数。算圆面积的函数，传进去的是半径——数字类型；统计全班分数的最低分、最高分、平均分的函数，传进去的是那批分数——列表类型。除此之外，字符串、元组、集合、字典，前面学过的数据类型全都能当参数用。这些统称为**普通参数**。

但 Python 的特别之处在于：参数不限于普通类型，**函数本身也可以作为一个参数直接传进来**。调用一个函数的时候，把另一个函数传进去，这是合法的。

「调用函数的时候怎么还能把一个函数传进来？」——光这么说是有点懵，得看具体写法。

## 从 calc 与 oper 说起

先定义三个函数，前两个是具体的运算，第三个负责调度：

```python
def add(x, y):
    return x + y


def subtract(x, y):
    return x - y


def calc(x, y, oper):
    return oper(x, y)
```

`calc` 收了三个参数：`x`、`y`、`oper`。函数体里做的事只有一件——写了 `oper`，后面跟一对小括号。`oper` 后面跟小括号是什么语法？这是**函数调用**的语法，它去调用了 `oper`，并且把 `x` 和 `y` 当参数传了进去。

能对一个参数名加括号调用，那这个 `oper` 就不再是普通参数了——它必须是一个**函数**。所以 `calc` 的逻辑读起来就是：调用传进来的 `oper`，把传进来的 `x`、`y` 交给它。

那么调用 `calc` 的时候怎么传？

```python
print(calc(10, 20, add))
```

三个实参各有归宿：`10` 传递给 `x`，`20` 传递给 `y`，`add` 传递给 `oper`。此时 `oper` 就是函数类型，值就是上面定义的那个 `add` 函数，最终去调用的就是 `add`，而传进 `add` 的又正是 `10` 和 `20`。

> **易错点**：这里的 `add` **没有加引号**，它不是字符串 `"add"`，而是那个函数对象本身。写引号传进去的是文本，不加引号传进去的才是函数。

由此得到两类参数的差别：`x`、`y` 是普通参数，传递的是**数据本身**，也就是这次要算的实际数字；`add` 不是普通参数，传递的是**函数的执行逻辑**——你把这个函数交出去，等于把「怎么算」这件事交了出去。第三个参数换成 `subtract`，同一句 `calc` 执行时就会去调 `subtract`。

## 用 Debug 看清 oper 的值

回到编辑器里把四个运算函数都定义好：分别做加、减、乘、除，每个都接收 `x` 和 `y` 两个普通参数——只有数字才能做加减乘除，这两个参数就是两个数字。再定义 `calc`，收 `x`、`y`、`oper`，函数体里调用 `oper(x, y)`，再把它的返回值 `return` 出去。

第三个参数如果传的不是函数，会怎样？先拿 `30` 试一次。

```python
print(calc(10, 20, 30))
```

`30` 最终传递给 `oper`，而这个位置后面会写成调用语法 `oper(x, y)`，`30` 是函数吗？不是，运行直接报错：第三个参数传进来的是一个 `int`，`int` 类型的参数不能被调用。

```text
TypeError: 'int' object is not callable
```

改成传函数名 `add`，在 `calc` 调用处和 `add` 里面各打一个断点，用 Debug 模式走：

- 停到调用行，`F8` 往下走一步，进入 `calc` 函数体。鼠标放在 `oper` 上看类型，显示 `function`——函数类型；再看它的值，是 `add` 这个函数。第三个参数传进来的确实是函数。
- 再往前走一步，执行流进入 `add`。`add` 算完，把结果返回给 `calc`，`calc` 再把结果往后返回。

这其实就是前面讲过的**函数的嵌套调用**：在一个函数当中调用另一个函数。只不过这里调用的那个函数，是通过参数传进来的。放行程序，结果 30 拿到了。

```text
calc(10, 20, add)
      │   │    │
      ▼   ▼    ▼
      x   y   oper = add        ← 传进来的是函数本身（函数类型）
              │
              ▼
        oper(x, y)  →  add(10, 20)  →  30
                        └─ 返回值原样 return 回 calc
```

读图说明：`oper` 是个函数类型的形参，`oper(x, y)` 这次调用发生在 `calc` 内部，实参 `10`、`20` 由 `calc` 自己的两个普通参数转发过去。

## 同一个 calc 换不同的运算

把第三个参数换成 `multiply`，`calc` 一行都不用改——它内部还是调 `oper`，只是这次 `oper` 指向的是乘法函数，最终算出来的是两数相乘的结果，运行得到 200。

> **结论**：Python 中函数的参数类型除了普通参数之外，还可以把函数作为参数直接传进来；传进来的是函数，实际传进来的是它的运算逻辑。`calc` 这类函数的职责从「怎么算」里解脱出来，只负责「什么时候算、拿谁算」。
