# PyCharm 的获取、安装与首次全局配置

装好 Python 解释器之后，我们在命令行和记事本里写过几行 Python 代码。试过就知道，那种体验有三个绕不过去的毛病：**没有任何提示**，写错了它不告诉你；**效率很低**，一个字母一个字母地敲；**容易出错**。企业里开发 Python 项目，绝不可能这么干。取代命令行和记事本的，就是高级的开发工具。

Python 开发中最常见的工具有两款：VS Code 和 PyCharm。这里用的是 PyCharm——在 Python 开发领域，它的市场占有率最高，也是我们这门课全程使用的专业工具。

## IDE 的定义与 PyCharm 的定位

这里冒出来一个词：IDE。它是三个英文单词的缩写，翻译过来叫**集成开发环境**。

> **定义**：集成开发环境（Integrated Development Environment，IDE）指把 Python 程序开发所需要的各种环境都集成到一个软件里，包括代码编写、程序分析、程序测试与调试，也就是基于这门语言开发，用这一个软件就够了。

PyCharm 出自捷克的一家软件公司 JetBrains。这家公司旗下一整排开发工具都是各自语言里的主流：Java 的 IDEA、Python 的 PyCharm、数据库连接工具 DataGrip、前端开发工具 WebStorm，还有面向 .NET、C、C++ 的开发工具——基本各个语言的开发工具它都有。对 Python 来说，使用 JetBrains 旗下这款专业工具就足够了。

## 下载与安装包获取

安装 PyCharm，先访问它的官方网站下载对应的安装包。站点会按你的操作系统给出版本：Windows、Mac、Linux，选中对应的包点下载即可。

点进下载页之后，因为当前机器是 Windows 系统，页面就自动选中了 Windows。英文界面看着不习惯的话，点右上角可以切换语言，从默认的英文切到简体中文，翻译之后看起来更直观。

页面上会显示下载入口，并标注**永久免费**——PyCharm 升级之后这一块是永久免费的，另外还附带一个月的 Pro 版本，也就是 Pro 的完整功能可以免费试用一个月。对我们当前阶段来说，免费功能已经完全够用。

点开下载按钮旁的小箭头要选具体哪个包：

| 你的处理器架构 | 该选的安装包 |
| --- | --- |
| ARM 架构 | 下面那个 ARM 版 |
| x64 架构 | 上面那个默认的 x64 版 |

怎么查看自己的架构？进「系统」信息，找到「系统类型」：如果提示"基于 ARM 的处理器"，就选第二个；如果和我这台一样是"基于 x64 的处理器"，选默认的第一个。绝大部分同学都是 x64，直接点下载按钮就行。

不过这个安装包比较大——所以不用自己等下载了，配套资料的第一章课程资料里已经放好 **PyCharm 2025.2**，大小一个多 G，直接用这份就行。

## 安装向导的逐步操作

资料里是一个 `.exe` 文件，双击运行安装程序，弹出用户账户控制时点「是」。接下来是官方安装向导，界面本身就是中文的，非常友好。

**第一步：安装目录。** 点「下一步」之后要选 PyCharm 的安装目录。还记得所有与开发相关的软件都建议装在什么样的目录下吗？——装在没有中文、不带空格的目录下。点「浏览」，我把它放在 `D:\develop` 下。

那要不要在 `develop` 下面再新建一个目录？点「确定」之后看一眼路径框就知道：你选的是 `D:\develop`，但它自动在后面补了一级路径——也就是说它会把 PyCharm 装到 `develop\PyCharm 2025.2` 这个目录下，会自动再建一层文件夹。

> **提示**：判断某款软件会不会自动建目录，办法就一个——选中目录、点确定，看路径后面有没有多带一级。会自动补的，就不用手动建；有些软件不会自动建，那就得自己先建好目录。这次它会自动创建，我们不用手动建。

**第二步：安装选项。** 这一步有四个复选框：

| 选项 | 作用 | 我的选择 |
| --- | --- | --- |
| 创建桌面快捷方式 | 装完后桌面出现 PyCharm 图标 | 勾选 |
| 将 PyCharm 加入 PATH 环境变量 | 命令行可直接调起 | 勾选 |
| 更新上下文菜单 | 右键菜单里出现 PyCharm 选项 | 不勾 |
| `.py` 文件关联 PyCharm | `.py` 文件默认由 PyCharm 打开 | 不勾 |

前两项我都勾上了：有桌面图标双击就能启动，加入 PATH 也无妨（不加也能双击图标运行）。后面两项我不需要——上下文菜单我不用，`.py` 文件我习惯用记事本打开，所以都不勾。这两项勾不勾看自己的需要，都行。

**第三步：开始安装。** 再点两次「下一步」就进入正式安装界面，点「安装」，然后查看详情。安装过程大概要几十秒，等一会儿就好。

几十秒之后，PyCharm 安装成功。桌面上出现了 PyCharm 图标——因为刚才勾选了创建桌面快捷方式。这时可以勾上下方那个选项让它自动运行 PyCharm，再点「完成」。

## 首次启动的引导选项与全局配置

PyCharm 启动后的引导会问几件事。

先是数据共享选择：问是否发送本地的统计数据，我直接选**不发送**。

接着问是否需要导入配置：因为本机已经装过 VS Code、Cursor 这类编辑工具，它想问问要不要从那些工具导入配置。我也不需要——为了模拟大家本地的环境（大家机器上可能并没有别的开发工具），这里直接点跳过。

进入主界面之后，把下方的弹窗用「Close」关掉，就代表 PyCharm 已经装好、可以用了。

用之前先做几项全局配置：

- **主题颜色**：默认是黑色（Dark）主题，我喜欢白色、看起来更清晰。点「自定义」选项，选择对应主题（亮色）；也可以勾选后面那一项，从操作系统同步主题颜色——我的系统用的是亮色，同步之后展示的就是亮色。按自己的习惯调整即可。
- **语言**：默认是 English，勾选简体中文。选完它会问要不要重启，我这里选 `Not now`，等会儿再重启。
- **区域**：选择「中国大陆」。
- **界面字体大小**：IDE 界面字号可以自己控制。我试着调到 14 号，觉得太大，还是调回 12 号。这块随个人习惯。

配置完之后，我把 PyCharm 关掉再重新打开，确认语言已经变成中文——确实变了。到这里 PyCharm 的安装就完成了。
