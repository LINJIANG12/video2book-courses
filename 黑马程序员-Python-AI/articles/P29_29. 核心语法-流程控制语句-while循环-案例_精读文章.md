# while 循环案例：1 到 100 之间所有偶数的累加之和

`while` 的基本语法结构我们已经学完了。但语法会写，不等于会用——所以接下来用一个小案例，把 `while` 的用法真正落到手上。

需求很短：**计算 1 到 100 之间所有偶数的累加之和**。

先说「累加」是什么意思。就是把 1 到 100 之间的偶数全部加到一块，求它们的总和，这件事就叫累加。

需求虽然一句话，真动手之前得先想清楚两个问题。

## 动手前的两个问题

第一个问题：怎么获取到 1 到 100 之间的所有偶数？换句话说，怎么判断一个数是不是偶数？

第二个问题：累加这一步，要用到什么运算符？

先把第一个问题解决掉。判断一个数是不是偶数，可以用一种运算符——**求模运算符**（`%`）。一个数模于 2 等于 0，那它就是偶数；否则它就是奇数。

> **定义**：求模运算符 `%` 用来求两个数相除之后的余数。`i % 2 == 0` 说明 `i` 能被 2 整除，是偶数；余数不为 0，说明是奇数。

第二个问题：累加需要在**前一个数的基础上再加一个数**，所以要用到 `+=`。这个符号就是做累加计算时该用的东西。

> **提示**：`+=` 是赋值运算符里的复合用法，`total += i` 等价于 `total = total + i`。累加场景里它是最顺手的一个，一次就写清「拿原来的值再加上新值，再存回原变量」。

两个问题都有答案了，剩下的就是把它写成代码。

## 案例的完整实现

先把变量准备好。要计算累加之和，并且最终要把它输出出来，所以先定义一个变量 `total` 等于 0，让它来记录这个累加之和。

接着要解决「从 1 开始一直循环到 100」这件事。前面那个 `while` 循环是从 0 开始、条件是 `i < 10`；这里要从 1 开始，范围是 1 到 100 之间的所有数。所以再定义一个变量 `i`，初始值设为 1，它就是循环开始的这个数字。

然后是循环条件。要计算的是 1 到 100 之间所有偶数的累加之和，**既包含 1，也包含 100**，所以这里要用 `<=`，也就是 `i <= 100`。

循环体里要做两件事：判断这个数是不是偶数，是偶数就累加。循环体里的判断用前面讲过的 `if` 条件判断就能完成。

```python
# 计算1到100之间所有偶数的累加之和

# 记录累加之和
total = 0

# 循环开始的数字
i = 1

while i <= 100:
    # 判断是否为偶数
    if i % 2 == 0:
        # 累加
        total += i
    i += 1

# 输出累加之和
print(f"1到100之间所有偶数的累加之和是：{total}")
```

逐段看这段代码。

`total = 0` 是累加器的起点。累加必须从 0 开始，这样第一次 `total += i` 的结果才正好是第一个偶数本身。

`while i <= 100:` 决定循环跑多久。这里为什么是 `<=` 而不是 `<`？因为我们要的范围包含 100。写成 `i < 100` 就把 100 漏在外面了。

循环体里先判断再累加，顺序不能反。`i % 2 == 0` 成立就执行 `total += i`，不成立就什么也不做，直接去处理下一个数字。

再看 `i += 1` 的位置。每一次循环出来的数其实就是 `i`：第一次是 1，第二次变成 2，第三次变成 3……所以 `i` 就是我们遍历出来的每一个数。而 `i += 1` 必须在**判断和累加之后**执行——它是把计数器往上推一格，推完进入下一轮。

最后那句 `print` 是**顶格对齐**的，它前面没有缩进，所以它并不属于 `while` 的循环体。`while` 循环执行完了之后，才会执行这个 `print` 语句，把最终结果打印出来。别忘了在字符串前面加上 `f` 做格式化。

> **易错点**：`print` 写在哪里，决定了它输出几次。如果它被缩进到循环体里，就会在每一轮循环里都打印一次；只有顶格写在 `while` 外面，它才在循环结束后只打印一次最终结果。

## 用 Debug 跟踪执行过程

代码写完了，打个断点看一下程序的执行过程，一轮一轮往下走。

第一轮，`i` 的值是 1——1 是奇数，判断不成立，不做累加。

第二轮，`i` 变成 2。2 是偶数，执行累加，`total` 的值就变成了 2。紧接着 `i` 自增到 3。数字就这样一个一个往上走，判断、累加、判断、累加。

再往后看：累计的结果已经是 12，此时 `i` 到了 7。下一次该累加的是 8——8 是偶数，累加之后 `total` 变成 20。

把这条线索整理成一张表，`i` 与 `total` 的对应关系一目了然：

| 轮次 | `i` | `i % 2 == 0` | `total` |
| --- | --- | --- | --- |
| 1 | 1 | False | 0 |
| 2 | 2 | True | 2 |
| 3 | 3 | False | 2 |
| 4 | 4 | True | 6 |
| 5 | 5 | False | 6 |
| 6 | 6 | True | 12 |
| 7 | 7 | False | 12 |
| 8 | 8 | True | 20 |

一直走到 `i` 变成 101，条件 `i <= 100` 不再成立，循环退出，最终输出累加之和。

不想再一步一步跟踪的时候，把断点在那一行再点一下就可以取消，然后按 `F9` 让程序恢复运行、直接跑到结束。

最终结果是：1 到 100 之间所有偶数的累加之和是 **2550**。

## 把整个流程画出来

```text
total = 0
i = 1
   |
   v
i <= 100 ? --False--> 退出循环 --> print(total)
   |
 True
   |
   v

   |                             |

```

读图说明：判断条件不成立时，`i` 自增后回到条件判断那一步，形成循环；只有条件变成 `False` 的那一次，才跳出循环去执行顶格的 `print`。

## 案例要点

这个需求里，`while` 循环体的语句中就用到了前面讲过的 `if` 条件判断。所以这个案例真正的价值，是把已经学过的两件事拼在了一起：`while` 负责「反复做」，`if` 负责「这次要不要做」，`+=` 负责「把要做的结果攒起来」。

> **结论**：写循环类案例，先想清楚三件事——循环从哪开始、循环到哪结束、每一轮循环体里做什么。这个案例里分别对应 `i = 1`、`i <= 100`、以及「判断偶数并累加，最后让 `i` 自增」。
