# 购物车系统：字典数据的增删改查案例

字典的特点、定义、常用操作，前面两节都已经过了一遍。这一节换个方式加深理解：动手做一个案例——**购物车系统**，把商品信息的增、修、删、查真正写出来。

## 1 需求说明

案例要开发的这个购物车系统，功能就四件事：在购物车中实现商品信息的增加、修改、删除和查询，说白了就是商品信息的增删改查。有两条硬性要求：

- 使用字典结构来存储商品数据；
- 通过控制台菜单与用户进行交互。

所谓「控制台菜单与用户交互」，就是程序运行之后，控制台上先出现一个购物车系统菜单，菜单一共五个选项：添加购物车、修改购物车、删除购物车、查询购物车、退出购物车。然后把菜单打印给用户，让用户输入要执行的操作编号——你这次到底是要添加、删除，还是退出——输入不同编号就执行不同操作。

五个功能各自的输入要求：

- **添加购物车**：让用户录入商品的名称、商品的价格、商品的数量，一共三项，然后把录入的信息保存到购物车里。想想我们平时在电商网站上添加购物车，要填的是不是就是这几项。
- **修改购物车**：先让用户输入要修改的是哪个商品，也就是商品名称；名称输入完，再提示他输入这个商品最新的价格和最新的数量，然后据此修改购物车数据。
- **删除购物车**：让用户输入要删除的商品名称，再根据名称把对应的商品删掉。
- **查询购物车**：把购物车里的数据展示出来，展示成「商品名称是什么、商品价格是多少、商品数量是多少」。

> **提示**：注意「修改」和「删除」这两个操作的共同点——它们都是**先根据商品名称找到这件商品的信息**，再执行操作。这一点直接决定了数据该怎么存，下一页就会用到。

## 2 数据结构设计

需求里提示了用字典来存，但字典具体怎么设计，得先想清楚，再动手写代码。

### 2.1 方案一：单个商品的三项信息

第一种结构，是用字典直接存一个商品的信息：`name` 代表商品名称，`price` 代表商品价格，`number` 代表商品数量。

```python
{'name': 'Mate 80', 'price': 6999, 'number': 2}
```

这么存行不行？不行。

原因在于，一个购物车里会包含多个商品。而 `name` 这个 key 在字典里只能存在一个，所以这样设计出来的字典只能存一个商品的购物车数据，别的商品再也加不进来。

### 2.2 方案二：列表里放商品字典

那在列表里放多个字典呢？列表有多个元素，每个元素是一个字典，字典里存的是这个商品的购物车信息，包括名称、价格、数量：

```python
[{'name': 'Mate 80', 'price': 6999, 'number': 2}]
```

乍一看好像是能满足需求：购物车里添多个商品，每个商品就是列表中的一个元素，元素内部用字典存就行了。

但前面已经点出来过：修改购物车要根据商品名称找到这件商品的信息，删除购物车也要先输入商品名称。这个结构方不方便做修改和删除？

不方便。原因很关键——**你把商品名称设计成了字典的 value，而不是字典的 key**。

字典的删除也好、修改也好、添加也好，都是根据 key 来操作的，删除尤其如此，必须根据 key 才能删掉指定的键值对。把商品名称放进 value 里，我们在操作时就失去了一按名称直达的入口。

> **易错点**：判断一个字典结构好不好用，就看操作时**靠哪个字段定位**。定位字段必须放在 key 的位置上，放在 value 里就只能遍历着找。

### 2.3 方案三：商品名称作 key 的嵌套字典

第三种结构完全不同：整个数据结构就是一个字典，里面全是键值对。

- key 设计为商品名称，比如 `Mate 80`、`鼠标`；
- value 又是一个字典，这个字典里有两个 key：`price` 代表商品的价格，`number` 代表商品的数量。

```python
{'Mate 80': {'price': 6999, 'number': 2},
 '鼠标': {'price': 199, 'number': 1}}
```

如果 key 是「鼠标」，那后面的字典里存的就是鼠标对应的价格和数量。

再回头看修改和删除：我们的 key 就是商品名称，删除时直接输入一个商品名称，就能直接根据这个 key 把购物车的数据删掉；修改同理。

```text
shopping_cart
 |
 +-- 'Mate 80' --> { 'price': 6999, 'number': 2 }   <- 该商品的价格与数量
 |
 +-- '鼠标'    --> { 'price': 199,  'number': 1 }
      ^
      |
   外层字典的 key 就是商品名称，操作时用它直接定位
```

这张图画的是最终采用的结构：外层字典的每一个键值对代表一种商品，键是商品名称，值是那件商品的价格和数量组成的字典。

数据结构的分析到这儿就结束了，接下来直接开 PyCharm 把需求实现出来。写代码之前把这个结构再确认一遍：商品名称作为字典的 key，它的值又是一个字典，那个字典里有两个 key，`price` 是价格，`number` 是数量——外层字典里的每一个键值对，就代表一种商品。

## 3 菜单制作与操作选择

菜单其实就是 `print` 语句打印出来的一段字符串。所以顺序是：先做菜单，再让用户输入要执行的操作，然后根据输入的 1 到 5 判断执行哪个功能。

### 3.1 初始化购物车与菜单字符串

购物车目前初始化为一个空字典，里面什么都没有，随着用户的输入再往里面添加数据。

菜单内容是多行字符串，用三引号定义，交给一个变量保存：

```python
print('欢迎使用购物车管理系统')

menu = '''################################################
##            购物车系统                        ##
##            1. 添加购物车                     ##
##            2. 修改购物车                     ##
##            3. 删除购物车                     ##
##            4. 查询购物车                     ##
##            5. 退出购物车                     ##
################################################'''

print(menu)

shopping_cart = {}
```

构造菜单时用到了一个提效的动作：五行的行首、行尾都要加井号，一行一行地改太慢，可以直接用**列编辑**。按住键盘上的 `Alt` 加 `Shift` 不放，鼠标点住第一行往下拖动，五行前面就同时出现光标，此时输入一次「井号 + 空格」，五行一起加上；再同样操作一次，给行尾补上井号。这样菜单字符串就构建好了，运行打印出来看一眼，效果差不多。

> **提示**：菜单变量在后面不会再被修改，所以直接定义在上面，不必放在循环里反复构造。

### 3.2 用 match 做等值匹配

接着提示用户输入要执行的操作，用一个变量接收，就叫 `choice`：

```python
choice = input('请选择要执行的操作(1-5): ')
```

拿到 1 到 5 之后就要分支执行。如果写成 `if` 加一串 `elif`，每个条件都得重复写 `choice == 数字`，这块的等值匹配用模式匹配更合适，也就是前面学过的 `match`：

```python
match choice:
    case '1':
        # 添加购物车
        pass
    case '2':
        # 修改购物车
        pass
    case '3':
        # 删除购物车
        pass
    case '4':
        # 查询购物车
        pass
    case '5':
        # 退出购物车
        pass
    case _:
        # 匹配其他所有情况
        print('非法操作，不支持')
```

> **易错点**：在结构模式匹配的语法里，匹配其他情况用下划线 `_`，**不要加引号**。写成 `case '_'` 就变成了「匹配字符串下划线」，那才是真的错。

架子搭好，接下来往每个分支里填具体的操作。先从最简单的填起：输入的数不在 1 到 5 之间时，输出一句提示信息「非法操作，不支持」。

## 4 添加购物车

按需求，添加时要录入商品的名称、价格、数量，再把商品保存到购物车中，所以这个分支里要接收三次键盘录入：

```python
goods_name = input('请输入商品的名称：')
goods_price = float(input('请输入商品的价格：'))
goods_number = int(input('请输入商品的数量：'))
```

商品的名称就是字符串，直接接收；商品的价格不是字符串，是 `float`，也就是小数类型——商品价格不一定是整数，可能是小数，所以要调用 `float` 把输入的字符串转成小数；商品的数量更明确，用 `int` 把字符串转成整数类型。

录入完成，接着做添加，也就是往 `shopping_cart` 这个字典里存数据。这里有个前提要处理：**得确保购物车中这件商品之前不存在，才能添加**。如果已经存在了，就给个提示，让他重新选择要执行的操作。

那怎么判断这个商品名称在购物车里存不存在？用前面讲列表、集合时用过的 `in` 运算符：

```python
if goods_name in shopping_cart:
    print('该商品已存在，请重新选择要执行的操作')
else:
    shopping_cart[goods_name] = {'price': goods_price, 'number': goods_number}
    print('商品添加完毕')
```

`goods_name in shopping_cart` 执行完，商品在购物车里就返回 `True`，否则返回 `False`。

不存在时走 `else`，往购物车里添加：方括号里写的 key 就是商品名称 `goods_name`，等号后面是这个 key 对应的值——注意这个值本身又是一个字典，所以直接写一对大括号，里面装 `price` 和 `number` 两项，分别对应录入进来的价格和数量。

到这里第一个功能就完成了。

## 5 修改购物车

修改购物车同样需要输入商品名称、商品的价格、商品的数量，所以接收录入的三行代码直接从上面复制下来，只把提示语改清楚：要修改的商品名称、商品最新的价格、商品最新的数量。

修改的操作逻辑和添加类似，但判断方向正好相反：如果用户输入的商品名称在购物车中**不存在**，那根本不用修改，说明他输入的名称有问题，直接提示即可。所以这里用的是 `not in`：

```python
if goods_name not in shopping_cart:
    print('商品不存在，请重新选择')
else:
    shopping_cart[goods_name] = {'price': goods_price, 'number': goods_number}
    print('商品修改完毕')
```

商品不存在就提示「商品不存在，请重新选择」——你都不存在，我修改什么？存在则进入 `else`，把商品的信息直接改掉。

> **结论**：新增和修改这两块代码是一模一样的，区别只在于 key 到底存在不存在——key 不存在就是新增，key 存在就是修改。所以添加分支判断「已存在」，修改分支判断「不存在」，只是入口条件不同。

## 6 删除购物车

删除只需要输入商品的名称，然后根据名称把购物车里的信息删除，键盘录入这一句从上面拷过来即可：

```python
goods_name = input('请输入要删除的商品名称：')
```

删除同样有前提：你得先有，我才能删。随便输一个商品名称，而这个名称在购物车里不存在，那就不需要执行删除，所以判断逻辑和修改那块一样——不存在就提示错误信息让他重新选择，存在才真正删除：

```python
if goods_name not in shopping_cart:
    print('商品不存在，请重新选择')
else:
    del shopping_cart[goods_name]
    print('商品删除完毕')
```

删除的方式有两种：用关键字 `del`，或者调用 `pop` 方法，两者都能按商品名称把对应的商品信息删掉。

## 7 查询购物车

查询就是把购物车里的数据展示出来，相对简单，用一个 `for` 循环取到所有的 key——而所有的 key 其实就是所有的商品名称：

```python
for goods_name in shopping_cart.keys():
    goods_info = shopping_cart[goods_name]
    print(f"商品名称：{goods_name}，商品的价格：{goods_info['price']}，商品的数量：{goods_info['number']}")
```

循环变量 `goods_name` 只是 key，打印时还要拿到里面对应的值。做法是 `shopping_cart[goods_name]`，按商品名称取出里面那个由 `price` 和 `number` 组成的字典，交给变量 `goods_info`。

接着按需求里定的格式输出：商品名称直接用 `goods_name`；商品的价格到 `goods_info` 里取，它是一个字典，按 key 取 value 就行，也就是 `goods_info['price']`；商品的数量同理，取的是 `goods_info['number']`。

> **提示**：怎么存的就怎么取。存的时候值是 `{'price': ..., 'number': ...}`，取的时候就用这两个 key 去拿。

## 8 退出购物车与循环结构

代码写完先运行一把。菜单展示出来了，输入 1，匹配到 `case '1'`，于是提示录入商品名称、价格、数量，然后是「商品添加完毕」。

但问题也来了：提示完之后**程序直接结束了**。这合理吗？不合理。既然是一个系统，添加完了很可能还要继续执行其他操作；只有选到 5 的时候，才应该退出购物车系统。

也就是说，现在的程序只能选一次。怎么解决？把下面的这段代码放进循环里，选到 5 时才退出循环；上面那句欢迎信息不必放进循环。

循环用 `while`，因为我们并不知道要循环多少次：

```python
print('欢迎使用购物车管理系统')
menu = '''...'''
shopping_cart = {}

while True:
    print(menu)
    choice = input('请选择要执行的操作(1-5): ')
    match choice:
        case '1':
            # 添加购物车
            pass
        case '2':
            # 修改购物车
            pass
        case '3':
            # 删除购物车
            pass
        case '4':
            # 查询购物车
            pass
        case '5':
            print('拜拜')
            break
        case _:
            print('非法操作，不支持')
```

这个系统要一直运行，直到用户选择退出购物车为止。所以在 `case '5'` 里先输出一句「拜拜」，再执行关键字 `break` 退出循环。

这样整个案例的代码就搞定了：添加购物车、修改购物车、删除购物车、查询购物车这四个需求都实现了。代码的测试放到下一节进行。
