# Python 字符串的定义方式与转义字符

上一小节把五种基础数据类型过了一遍：整数、浮点数、字符串、布尔和空值。认识了这一圈之后，接下来就该挑其中一个细细剖析——这次是字符串。

我们从入门程序打印 Hello World 开始，到讲字面量，再到上一小节讲基础数据类型，一直挂在嘴上的一句话是：字符串需要用引号引起，所有以引号引起的数据都是字符串。可 Python 里字符串的表现形式并不止一种，现在就把它们逐个剖开。

## 1. 三种字符串定义方式

关于字符串的定义方式，一共有三种。

第一种是入门程序里打印 Hello World 时用的双引号，双引号引起来的就是字符串；第二种是把双引号换成单引号，也就是单引号定义法；第三种是三引号定义法——三个引号作为开始，三个引号作为结束，中间放的就是字符串的具体内容。

```python
s1 = "Hello"       # 双引号定义方式
s2 = 'Python'      # 单引号定义方式
s3 = """Hello
欢迎大家进入到Python课程的学习
	一键三连哟~
"""                # 三引号定义法，可定义多行字符串
```

前两种方式敲法上有个小差别：敲双引号要按住 Shift 再按引号键，敲单引号直接按引号键就行，不按 Shift 敲出来的就是单引号。

真正拉开差距的是换行能力。三引号定义的字符串支持换行，可以定义多行字符串；而单引号和双引号定义的字符串不能直接换行。

> **易错点**：双引号或单引号定义的字符串，写在一行里就必须在一行里结束。想让它跨行显示，只能靠字符串拼接（下一小节讲）或者用三引号。

如果在双引号里硬按回车换行，PyCharm 这个开发工具会很智能地处理：它并不是让这一个字符串换了行，而是把它变成了两个字符串，再把两个字符串拼接在一起。回头看引号就能明白——开始引号和结束引号之间的内容是不允许断行的。

三引号这一点上要注意选哪种引号：单引号凑三个也行，但建议用双引号凑三引号，因为这是官方推荐的方式。

## 2. 字符是组成字符串的基本单位

字符串里每一个字，我们都称之为一个字符。

字符是文本世界当中的基本单位，也是组成字符串的基本单位。为什么叫“字符串”？把多个字符连在一起，就组成一个字符串。所以在字符串里看到的每一个字母、每一个汉字、每一个符号，包括每一个数字，其实都是一个字符。

> **定义**：字符是文本世界中的基本单位，也是组成字符串的基本单位。

## 3. 三引号定义字符串的格式保留

三引号定义字符串时，写进去什么样，输出就原封不动是什么样——包括里面的换行，也包括用 Tab 键做出来的缩进，都会照样输出。

```python
s3 = """Hello
欢迎大家进入到Python课程的学习
	一键三连哟~
"""
print(s3)
```

这段字符串会分三行输出：Hello 一行，欢迎那句一行，最后一行一行。第一行位置是一个空行，里面并没有内容；Hello 是顶着最前面写的；“欢迎大家进入到 Python 课程的学习”前面有缩进，那是编写时按下的 Tab 键，原封不动地输出了；下面那行同样原封不动。

```text
"""Hello                      <- 开始的三引号之后立刻回车，形成开头空行
Welcome to the Python course  <- 顶格书写，输出也顶格
<Tab>keep going~              <- 编写时的 Tab 缩进被原样保留
"""                           <- 结束的三引号
```

读图看三引号的两条规则：起止引号之间的换行全部保留，行首的 Tab 缩进也全部保留，解释器不会自动整理格式。

顺便把三个变量都用 `type` 查一遍，确认它们到底是不是字符串类型：

```python
print(type(s1))
print(type(s2))
print(type(s3))
```

运行结果是 s1、s2、s3 全都是 string 类型，都是字符串。顺带一个提效小技巧：写完 `print(s1)` 之后编辑器会提示你要不要接着输出 s2 和 s3，按 Tab 键就能补全，这个键在 PyCharm 里就是补全键。

> **易错点**：三引号字符串结尾的那行说明，别顺手挪到字符串内部去。写在开始引号和结束引号之间，它就是字符串内容的一部分，不再是注释；要写成注释，必须放在这一行代码的结尾。

## 4. 引号嵌套冲突与转义字符

前面定义的字符串内容都比较简单，换一段稍微特殊的：内容是英文，而英文里经常有缩写，比如 `It's very good`。

这句里的单引号是 It is 缩写之后加上的。如果用单引号定义法，把它往里一放就出问题了：这个单引号会和最开始的引号配成一对，于是 `'It'` 成为一个字符串，后面的内容成了多余的部分，程序报错。

```python
msg = 'It's very good'      # 报错：内层单引号与起始单引号提前配对
```

结论是：用单引号定义字符串时，字符串里不能再出现单引号。

解决办法是转义字符，写法就是在前面加一个反斜线。加上反斜线之后，这个单引号就只是字符串本身的单引号，不再是字符串的开始或结束引号——它表示引号本身。

```python
msg = 'It\'s very good'
print(msg)      # It's very good
```

常见的转义字符一共四个：

| 转义字符 | 含义 | 效果 |
| --- | --- | --- |
| `\'` | 单引号本身 | 对单引号转义，使它可以出现在字符串里 |
| `\"` | 双引号本身 | 对双引号转义，使它可以出现在双引号字符串里 |
| `\n` | 换行符 | 走到这里就执行换行操作 |
| `\t` | 制表符 | 相当于按下键盘上的 Tab 键，产生缩进效果 |

遇到这类问题还有第二种解法，也是更省事的解法：字符串里有单引号，那定义时就不用单引号，改用双引号。外层换成双引号之后，内层的单引号走到那儿并不能和起始引号配对，它就表示单引号本身，问题同样解决。

```python
msg = "It's very good"
```

双引号这边是同样的道理，只是方向反过来：

```python
msg3 = "Hello的意思就是\"您好\""
```

双引号定义的字符串里如果还想出现双引号，一样得转义，否则内层双引号会和起始双引号提前闭合。对称的替代方案同样存在：外层别用双引号，改用单引号，内层的双引号就能正常出现了。

```python
message4 = 'Hello的意思就是"您好"'
```

> **提示**：遇到引号冲突，两条路选一条就够——要么给内层引号加反斜线转义，要么换一种外层引号。两者不要叠加使用，也不必写两份。

## 5. 换行符与制表符的验证

剩下两个转义字符在单引号、双引号字符串里才有存在感，因为这两种字符串本身不能写多行，要换行只能靠 `\n`。

把前面用三引号写的那几行内容复制下来，合并成一行写进双引号里——反正双引号和单引号都定义不了多行字符串，只能写成一行。

```python
print("Hello 欢迎大家进入到Python课程的学习 一键三连哟~")
```

这样写出来，所有内容就挤在同一行里了。现在的需求是：走到叹号之后换个行再输出。

```python
print("Hello 欢迎大家进入到Python课程的学习 一键三连哟~\n")
```

在叹号后面写上 `\n`，运行后叹号之后确实换行了。这里要留意 `\n` 生效的时机——它是在输出的时候执行换行操作。

`\t` 则是增加缩进，相当于按了一下键盘上的 Tab 键。现在想让“欢迎”和“大家”这两句前面都带上一个缩进，就在它们前面各加一个 `\t`：

```python
print("Hello\n\t欢迎大家进入到Python课程的学习\n\t一键三连哟~")
```

运行后，“欢迎”前面有了缩进，“一键三连”前面也有缩进。注意区分：`\t` 写在字符串里控制的是输出内容的缩进；而代码本身现在都得顶格写，代码不能缩进。

> **易错点**：`\n` 和 `\t` 是“字符串内容里的转义序列”，影响的是打印出来的排版；它们不是代码缩进，别把两者混成一件事。

## 6. 三种方式的取舍原则

现在手里有三种定义字符串的方式，项目开发里到底用哪种？

单引号和双引号定义出来的字符串其实是一样的，只是写法不同。所以项目开发当中只需要守住一个原则：同一个项目里，要么都用双引号，要么都用单引号，保持一种写法就够了。

至于三引号字符串，它的主要应用场景是定义多行字符串——有大段内容要写进去的时候用它。三引号还有另一个用途，就是书写文档注释时也会用到，这个后面再详细讲。
