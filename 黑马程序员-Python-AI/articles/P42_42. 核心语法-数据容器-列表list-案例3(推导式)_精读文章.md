# 列表推导式：按规则快速生成列表

列表这一块的最后一个案例里，其实有两个小需求：

1. 生成一个 1 到 20 的平方列表；
2. 从给定的数字列表里提取出所有偶数，计算这些偶数的平方，再组成一个新的列表。

两个需求都是"由一个序列构造出一个新列表"，但第二个需求必须先筛选，正是这个差别把列表推导式的两套语法格式都带了出来。

## 1 需求一：生成 1 到 20 的平方列表

目标很明确：列表里有 20 个元素，值依次是 1 到 20 的平方。

### 1.1 传统方式：range 序列 + for + append

先解决一半的问题：怎么生成一个装着 1 到 20 这 20 个数的列表？for 循环那一节讲过，`range` 用来生成一个指定的数字序列。

`range` 有三种用法，这里关键看括号里传几项数据：

- 只传一个值，例如 `range(20)`，生成的是从 0 开始、到 20 之前的 20 个数——起点是 0，不是 1；
- 传两个值，例如 `range(1, 20)`，第一个值是开始，第二个值是结束，规则是**包含开始、不包含结束**。

我们需要的是 1 到 20，而且要包含 20，所以第二个值得写 21：`range(1, 21)`。

```python
number_list = []
for i in range(1, 21):
    number_list.append(i ** 2)

print(number_list)
```

先定义一个空列表；`for i in range(1, 21)` 把序列里的值挨个遍历出来，`i` 就是本次取到的元素；`i ** 2` 是幂指数运算——两个星号后面跟一个 2，就是求平方；`append` 把算出来的平方追加到列表末尾。

运行输出：一共 20 个元素，从 1、4、9、16、25、36、49 一路到 400，正是 1 到 20 的平方。

> **提示**：这种方式就是遍历每一个元素、再逐个追加到新列表里。功能上没问题，但写起来繁琐一些。

### 1.2 列表推导式：一行构造

同样的需求换一种语法来写：

```python
number_list2 = [i ** 2 for i in range(1, 21)]
print(number_list2)
```

这就是列表推导式。名字听着抽象，做的事很具体：**按照一定的规则快速生成一个列表**。

写法可以从头读一遍：外层是一对中括号，因为要构造的是列表；中括号里是一个 `for` 循环，用来遍历另外一个列表或者序列；`for` 关键字**前面**写的是循环过程中要插入新列表的值——它可以是变量，比如 `i`，也可以是一个表达式，这里写的就是 `i ** 2`。

> **易错点**：只写后半段 `for i in range(1, 21)` 会直接报错。"从哪儿取数据"和"往新列表里插什么"两件事都得写全，缺了前面那一部分就不是一个合法的表达式。

运行之后两个列表的元素一模一样，而推导式只写了一行——哪个更简洁一眼就能看出来。

## 2 列表推导式的两种语法格式

### 2.1 语法格式一：不带条件

```python
[要插入的值 for i in 序列或列表]
```

把前面那段代码对应进来：要插入的值是 `i ** 2`，序列是 `range(1, 21)` 生成的数字序列。要插入的值可以是一个变量，也可以是一个表达式，这是这一格式里唯一需要自己拿主意的部分。

### 2.2 语法格式二：带条件

在 `for` 的后面再加一个 `if` 和判断条件：

```python
[要插入的值 for i in 序列或列表 if 条件]
```

含义是：生成新列表的时候先做条件判断，**条件成立才把这个值加入新列表，条件不成立就什么都不做**。`if` 这一段是可选的——需要筛选用它，不需要就不加。

## 3 需求二：从数字列表中提取偶数并计算平方

第二个需求是：从给定的数字列表里挑出所有的偶数，计算这些偶数的平方，组成一个新的列表。

> **提示**：只要看到"由一个列表再组成另外一个列表"，就可以先想想能不能用推导式来解决。

### 3.1 先按不带条件的写法套一遍

给定的数字列表大致是这么一组数据：12、45、77、80、92、33、57、97、98，后面又补了一个 122。

按格式一直接套：

```python
new_list = [i ** 2 for i in number_list]
print(new_list)
```

运行输出的是列表里**每一个**元素的平方。需求里"提取出所有的偶数"这一步根本没做到——所有元素都被计算、被插入了，奇数也在里面。

### 3.2 补上 if 条件，只留偶数

判断一个数是不是偶数，看它和 2 取模的结果：`i % 2 == 0` 成立就是偶数，否则是奇数。

```python
new_list = [i ** 2 for i in number_list if i % 2 == 0]
print(new_list)
```

条件加在 `for` 后面：只有遍历出来的 `i` 满足 `i % 2 == 0`，才去计算它的平方并插入新列表；不满足的直接放过。

```text
元素            判断 i % 2 == 0      平方结果        进入新列表
45（奇数）      不成立               不计算          否
12（偶数）      成立                 144             是
77（奇数）      不成立               不计算          否
80（偶数）      成立                 6400            是
```

读图说明：判断这一步排在计算之前，条件不成立时连平方都不会去算，元素更不会进新列表。

运行结果正好印证：12 是偶数，144 是它的平方；80 是偶数，6400 是它的平方；45、77 是奇数，它们的平方没有被计算，也没有出现在结果里。

## 4 两种格式的选用

| 需求 | 语法格式 | 写法 |
| --- | --- | --- |
| 由序列按规则构造列表 | 格式一（不带条件） | `[表达式 for i in 序列或列表]` |
| 只保留满足条件的元素 | 格式二（带条件） | `[表达式 for i in 序列或列表 if 条件]` |

两个需求都用推导式实现完之后对比一下：传统方式要遍历、要追加，好几行；推导式一行搞定，更简洁、更优雅。所以凡是"由一个列表生成另一个列表"的场合，推荐直接用列表推导式。
