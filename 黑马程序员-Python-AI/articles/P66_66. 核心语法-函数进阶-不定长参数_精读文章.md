# 不定长参数：位置不定长与关键字不定长

先看一个需求：定义一个函数，根据传入的这批数据算出其中的最小值、最大值和平均值。乍一看不难——接收几个参数，算三个结果就完了。可只要参数个数换一下，问题立刻冒出来：按固定形参去定义，比如写上四个形参，调用时传四个没问题，传六个、传九个要报错，传两三个也要报错。而需求里说的是「传入的这批数据」，这批数据到底有几个，压根不确定。

前面讲的函数定义方式，形参列表都是**固定**的：定义了四个形参，调用就必须给四个，多一个不行，少一个也不行。参数个数不确定的场景，要用这一节的不定长参数来解决。

> **定义**：不定长参数也叫**可变参数**，指参数列表是可变化的、不固定的，用于函数定义及调用时参数个数不确定的情况。

不定长参数分两类：一类接收**基于位置传递**的不定长参数，一类接收**基于关键字传递**的不定长参数。下面分别说定义怎么写、调用怎么传。

## 位置不定长参数：形参前加一个星

在形参名称前面加**一个星号**，表示这是一个基于位置传递的不定长参数：

```python
def calc_data(*args):
    ...
```

`args` 是 `arguments`（参数）的缩写。调用时在括号里写多少个数据都行，一次传十个可以，传二十个、三十个也行，下一次传五个照样可以——这些数据都会被合并封装到 `args` 里面。

多个数据封装成什么？**一个元组**。因为元组本身就能装多项数据，所以 `args` 的类型就是元组，进来之后可以完全按元组的方式操作它。

> **易错点**：只带一个星号的 `args` **只接收位置参数**。调用时如果用的是关键字形式传参，那些键值对不会进 `args`，它会漏掉——关键字传参要交给带两个星号的那个形参。

> **提示**：`args` 只是一个形参名、一个变量名，不是关键字。写成 `*data`、`*a`、`*b`、`*c` 都合法，只不过 `args` 是约定俗成的规范写法，建议就这么用。

既然 `args` 是元组，取最小值、最大值、平均值就可以直接借内置函数：`min` 取最小值，`max` 取最大值，平均值则是把所有元素累加求和再除以元素个数。

## 把平均值需求实现出来

按这个思路定义函数：函数名叫 `calc_data`，用一个星号加 `args` 接收这批不定长的数据；函数体里 `min_data` 用 `min(args)`，`max_data` 用 `max(args)`，`avg_data` 用 `sum(args)` 除以元素个数；最后把这三项 `return` 回去。

```python
def calc_data(*args):
    min_data = min(args)
    max_data = max(args)
    avg_data = sum(args) / len(args)
    return min_data, max_data, avg_data


print(calc_data(2, 7, 9, 10, 45))
```

第一次调用传了五项数据，就是算这五项的最小值、最大值和平均值。为了看清 `args` 到底是什么类型，在调用处打了断点、用 Debug 模式走：走进 `calc_data` 之后，`args` 值外面是小括号括起来的——就是元组。放行程序，结果是：最小值 2，最大值 45，平均值 14.6。

再传一批：在原来的数据后面继续加 73、37、93、92、111、222，一次十几项。运行结果最小值仍是 2，最大值 222，平均值是 `63.72727272...`。

平均值这块要停一下。之所以出现这么长的一串，是因为平均值要做除法，除法就可能除不尽，得到的是浮点数。

> **提示**：要控制小数位数就用内置函数 `round(数值, 位数)`。把平均值放进去、后面写 1，表示四舍五入保留一位小数：`round(avg_data, 1)`。加上之后再运行，结果就只保留一位小数了。

以上就是位置不定长参数的全部写法：形参前一个星号，多个位置参数封装成一个元组。

## 关键字不定长参数：形参前加两个星

关键字传参的不定长参数，写法是形参前面加**两个星号**：

```python
def calc_data(*args, **kwargs):
    ...
```

沿用上面的函数：前面那个 `*args` 接收位置传进来的数据，封装成元组；后面这个 `**kwargs` 接收关键字传进来的键值对。

`kwargs` 可以随意命名，`**options`、`**data` 都行。`kw` 是 `keyword`（关键字）的缩写，`kwargs` 同样是约定俗成的名字。

封装的结果是**一个字典**。原因也顺理成章：关键字实参写的就是 `key=value` 的形式，前面的 `key` 就是字典的键，后面的 `value` 就是键对应的值。既然是字典，取数据就按字典的方式——用键取对应的值。

### 用选项控制函数行为

改造刚才的函数，加两个可选的选项：

- `round`：平均值保留的小数位个数。传 `round=1` 就保留一位，传 `round=3` 就保留三位。
- `print`：是否打印输出。传 `print=True` 就在函数里把最小值、最大值、平均值直接打印出来；不传就不打印。

把函数文档注释也补上：位置不定长参数 `args` 代表需要计算的这批数据，关键字不定长参数 `kwargs` 里可能传来 `round`（保留的小数位个数）和 `print`（是否打印输出），返回值是三项——最小值、最大值、平均值。

```python
def calc_data(*args, **kwargs):
    """
    根据传入的这批数据，计算这批数据的最小值、最大值及平均值
    :param args: 不定长位置参数，代表需要计算的这批数据
    :param kwargs: 不定长关键字参数，可能传入 round（保留的小数位个数）、print（是否打印输出）
    :return: 返回最小值、最大值、平均值这三项
    """
    min_data = min(args)
    max_data = max(args)
    avg_data = sum(args) / len(args)

    round_num = kwargs.get("round")
    if round_num is not None:
        avg_data = round(avg_data, round_num)

    if kwargs.get("print"):
        print(f"最小值：{min_data}，最大值：{max_data}，平均值：{avg_data}")

    return min_data, max_data, avg_data


print(calc_data(2, 7, 9, 10, 45, round=3, print=True))
print(calc_data(2, 7, 9, 10, 45))
```

算最小值、最大值、平均值的逻辑不用动，新增的只是后半段两个判断。

小数位的判断这样写：从 `kwargs` 里用 `get` 方法取出 `round` 这个键对应的值，如果这个值 `is not None`，说明调用方传了，就对算出来的平均值做四舍五入、保留指定位数；如果取不到值，原始结果是多少就是多少。

打印的判断不用那么绕。`print` 的键值本身就是布尔类型，直接把 `kwargs.get("print")` 当条件用即可；条件成立才打印。注意一个连带影响：一旦打印在函数里做掉了，返回的时候就不用再返回三项了，直接 `return avg_data` 就行。

### 验证与调节

先确认封装行为。在函数里临时输出一下 `kwargs`：第一次调用传了 `round` 和 `print` 两个关键字参数，字典里两个键都在；第二次调用一个关键字参数都没传，打印出来就是个**空字典**。所以后面的逻辑从字典取键取值来分支，是对路的。

再逐项调节。调用时一共给七个参数：前面五个是位置参数，进 `args` 元组；后面两个是关键字参数，进 `kwargs` 字典。

- 传 `round=3`、`print=True`：结果打印出来了。小数位只显示一位，不是三位——因为这五个数算平均值能除得尽，`14.6` 是精确结果，不是四舍五入的产物；`round=3` 管的是「除不尽或小数位超过三位时保留三位」。
- 两个关键字参数都不传：`kwargs` 是空字典，两个条件都不成立，直接返回最小值、最大值、平均值，既不打印也不保留位数。运行下来确实没打印，平均值还是一长串没除尽的样子。
- 只传 `round=2`：保留两位小数；改成 `round=3`，保留三位；改成 `round=4`，保留四位。通过末尾的关键字传参，就能灵活控制函数内部这段逻辑。
- 再叠加 `print=True`：结果被打印出来；把这个关键字参数去掉，或者写成 `print=False`，输出就没有了。

```text
调用形式                                           args           kwargs
calc_data(2, 7, 9, 10, 45)                        (2,7,9,10,45)  {}
calc_data(2, 7, 9, 10, 45, round=3)               (2,7,9,10,45)  {'round': 3}
calc_data(2, 7, 9, 10, 45, round=3, print=True)   (2,7,9,10,45)  {'round': 3, 'print': True}
```

读图说明：同一批数据走位置传参进元组，跟在后面的键值对走关键字传参进字典，两条通道互不干扰——这正是「数据」与「选项」两种职责在参数层面的分工。

## 两类不定长参数的适用场景

两者的分工可以用一句话概括：**位置不定长处理数量不确定的数据，关键字不定长处理数量不确定的选项**。

数据与选项的区别，拿奶茶店点单来比：

```text
珍珠奶茶      甜度少糖   冰度去冰   加料布丁   大杯中杯    →  后面的都是选项
────────      ────────────────────────────────────────
核心数据      为前面这个数据服务的各种可调项
```

读图说明：「珍珠奶茶」是核心数据，是要处理的东西本身；甜度、冰度、加料、杯型是为它服务的一组可调项，选不选、选几个都不影响主体是什么。

对照到函数上：`calc_data(2, 7, 9, 10, 45, ...)` 里那五个数就是数据，数量的多少只取决于要算多少个数；而 `round`、`print` 是选项，它们不参与计算，只决定这次调用怎么表现。

> **结论**：需要接收数量不定的「要处理的东西」，用 `*args`；需要接收数量不定的「调节开关」，用 `**kwargs`。

最后一条顺序要求：两类不定长参数同时存在时，**先写位置不定长参数，再写关键字不定长参数**。这跟传参方式那一节的规则是一回事——位置参数和关键字参数同时出现时，位置参数在前，关键字参数在后，函数定义处也照这个顺序排。
