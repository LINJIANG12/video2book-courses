# 学生成绩单的存储与统计分析

## 1 案例需求

数据容器学到元组，需要一个案例把列表、元组和字符串格式化串起来用一遍。这个案例的输入是一张学生成绩单，形式类似一张表：第一列是学号，第二列是姓名，第三列到第五列是三科成绩——语文、数学、英语，全表一共 10 条学生记录。

基于这份成绩单要做三件事：

1. 计算每个学生的总分、各科的平均分，连同学生的基本信息与各科成绩一并输出；
2. 统计各科成绩的最低分、最高分、平均分并输出——语文的最高分、最低分、平均分，数学和英语同样各算一遍；
3. 查找成绩比较优秀的学生：平均分大于 90 分的学生，把其信息输出出来。

> **提示**：第三个需求里的标准是「大于 90」，不是「大于等于 90」，判断条件写的时候要照需求来。

## 2 数据该用什么容器存

要程序处理这份数据，先得解决怎么存的问题。

像字符串、`int`、`float` 这些普通数据类型，一个变量只能存一个值，而这张表里的数据很多，所以必须用数据容器。

再往下想一层：容器里装的到底是什么？看这张表会发现，它是一条一条的数据，一条数据就是一个学生的信息，包含学号、姓名、三科成绩，一共 10 条。那么外层容器的每一个元素就是一个学生的信息，共 10 个元素。

那么外层用列表还是元组？还是拿可变性判断：数据可变就用列表，数据只能查询、不能修改就用元组。学生的成绩信息一旦录入完毕、确认完毕之后是不应该再被修改的，所以外层直接用元组来存。

再看每个学生的信息本身：学号、姓名、三科成绩，这几项也是固定的一组数据，于是每条学生信息同样用一个元组来存。两层都是元组，结构就是**元组里面套元组**。

```python
students = (
    ("S001", "王林", 85, 92, 78),
    ("S002", "李木宛", 92, 88, 95),
    # ...其余 8 位学生的信息
)
```

内层元组的 5 个元素依次是学号、姓名、语文、数学、英语。第一个学生的信息描述完，用逗号分隔，接着描述第二个学生，依此类推。剩下的 8 位学生信息同样是这个结构。

```text
students ── tuple
 ├── 0 ── ("S001", "王林",   85, 92, 78)   ← 学号 姓名 语文 数学 英语
 ├── 1 ── ("S002", "李木宛", 92, 88, 95)
 ├── ...
 └── 9 ── 第 10 位学生的信息
```

读图说明：外层是一个 10 个元素的元组，每个元素本身又是一个 5 元素的元组，按固定的列序存放这个学生的学号、姓名和三科成绩。

这种一条条罗列的数据初次编写时可以手动敲一遍，目的是熟悉结构。等到后面做案例时，这类体力活完全可以交给 AI 来生成，但现在还在打基础，建议先自己敲，把基本语法结构摸熟，之后再谈用 AI 提效。

> **提示**：从别处粘进来的代码常常带着多余缩进。选中之后按 `Shift` + `Tab` 可以整体往前顶格，按 `Tab` 是往后缩进，这段代码需要顶到最左边。

## 3 每个学生的总分与平均分

第一个需求要算每个学生的总分和平均分，还得把学生信息一并输出。要算每一个学生的数据，就得从容器里把每一个元素依次拿出来，这就需要循环。

```python
for s in students:
    # s 本身也是一个元组，即一位学生的信息
    total = s[2] + s[3] + s[4]
    avg = total / 3
```

`for s in students` 遍历出来的 `s` 就是外层元组里的每一个元素，而每个元素本身又是一个元组。所以要拿三科成绩，就按索引把内层元组的第 3、4、5 个元素取出来相加——`s[2]` 是语文，`s[3]` 是数学，`s[4]` 是英语。加完就是总分。

> **易错点**：算平均分要除以 `3`，也就是科目数。这里的 `3` 是写死的常数，**不是** `len(students)`——`len(students)` 是学生人数，除它会得到毫无意义的数字。

拿到总分和平均分就可以输出。用格式化字符串把学号、姓名、三科成绩、总分、平均分依次排好：

```python
for s in students:
    total = s[2] + s[3] + s[4]
    avg = total / 3
    print(f"{s[0]} {s[1]} {s[2]} {s[3]} {s[4]} {total} {avg}")
```

`s[0]` 是学号，`s[1]` 是姓名，后面三个是语数外成绩，最后是总分和平均分。

### 3.1 让平均分保留一位小数

跑一遍会发现输出很凌乱，主要问题出在平均分上。计算平均分涉及除法，除法结果可能是浮点数，存在除不尽的情况，所以平均值会拖出一长串小数。

解决办法是在格式化时指定这个变量的显示格式。在格式化字符串的大括号里，变量名后面加一个冒号，冒号后面的内容就是对这个变量的格式说明；要保留一位小数就写 `.1`；又因为 `avg` 是浮点数，还要说明按浮点数形式处理，所以再加上一个 `f`——`f` 代表 float。

```python
print(f"{s[0]} {s[1]} {s[2]} {s[3]} {s[4]} {total} {avg:.1f}")
```

> **定义**：格式化字符串中 `{变量:.1f}` 表示按浮点数处理并保留一位小数。冒号后面是格式说明，`.1` 是小数位数，`f` 是 float。

改完再跑，所有浮点数都缩成一位小数，输出立刻整齐了很多。

### 3.2 表头与制表符对齐

整齐之后还有两个问题：内容太密挤在一起，而且光看 `85`、`92` 不知道哪个数是哪一科。所以要在循环之前先输出一行表头。

```python
print("学号\t\t姓名\t\t语文\t\t数学\t\t英语\t\t总分\t\t平均分")
```

`\t` 是转义字符，输出的是一个制表符。每一列之间用两个制表符分割，表头里依次是学号、姓名、语文、数学、英语、总分、平均分。

下面逐行输出的数据也得用制表符来分隔，否则列对不上表头：

```python
for s in students:
    total = s[2] + s[3] + s[4]
    avg = total / 3
    print(f"{s[0]}\t{s[1]}\t{s[2]}\t{s[3]}\t{s[4]}\t{total}\t{avg:.1f}")
```

制表符用几个需要试一下：数据行里用两个制表符会太宽，改成每处只留一个制表符就正好。跑出来的效果是学号、姓名、语文、数学、英语、总分、平均分七列清清楚楚，跟表头一一对齐。

## 4 各科成绩的最低分、最高分、平均分

第二个需求换了一个统计角度：不再是每个学生的纵切，而是每一科的横切。要算语文的最低分、最高分、平均分，就必须先把所有学生的语文成绩集中到一起。

这一步拆成两小步：先取到各科的成绩列表，再基于列表算最小值、最大值、平均分。

### 4.1 用列表推导式取各科成绩

取语文成绩列表，需要遍历 `students`，把每个学生元组的第三个元素取出来。这正是列表推导式该出场的地方：

```python
chinese_scores = [s[2] for s in students]
```

推导式里先写循环 `for s in students`，前面写要往列表里放的表达式。要放的不是 `s` 本身，而是这个元组的第 3 个元素，也就是 `s[2]`。

> **易错点**：推导式里放进列表的表达式必须是具体的列，写成 `[s for s in students]` 得到的是一个个学生元组，不是成绩。

先把这个列表输出出来核对一遍，确认取到的是所有学生的语文分数，然后照猫画虎改两个索引位置就得到数学和英语的成绩列表：

```python
chinese_scores = [s[2] for s in students]   # 语文成绩
math_scores    = [s[3] for s in students]   # 数学成绩
english_scores = [s[4] for s in students]   # 英语成绩
```

变量名做到见名知意，语文用 `chinese_scores`，数学用 `math_scores`，英语用 `english_scores`。

### 4.2 计算最低分、最高分与平均分

有了单科成绩列表，统计就简单了。最低分用 `min`，最高分用 `max`，平均分用 `sum` 除以 `len`：

```python
print(f"语文最低分：{min(chinese_scores)}，最高分：{max(chinese_scores)}，平均分：{sum(chinese_scores) / len(chinese_scores)}")
```

`min(chinese_scores)` 取列表里的最小值，也就是最低分；`max` 换成最大值，也就是最高分；平均分需要先累加求和，再除以列表的长度，`len(chinese_scores)` 算的就是这个列表的元素个数。

> **提示**：最低分和最高分也可以用另一种方式拿——先把列表排序，排序后的第一个元素就是最小值，最后一个元素就是最大值。

语文这一组写好后，复制两份，把里面的列表换掉即可：

```python
print(f"语文最低分：{min(chinese_scores)}，最高分：{max(chinese_scores)}，平均分：{sum(chinese_scores) / len(chinese_scores)}")
print(f"数学最低分：{min(math_scores)}，最高分：{max(math_scores)}，平均分：{sum(math_scores) / len(math_scores)}")
print(f"英语最低分：{min(english_scores)}，最高分：{max(english_scores)}，平均分：{sum(english_scores) / len(english_scores)}")
```

跑起来核对一下结果是否可信：语文最低分是 `66`，对应的是成绩单里第 3 个元素那一列；语文最高分是 `95`，是学生周毅的分数，都对得上。

## 5 查找优秀学生

第三个需求最简单，思路也直接：遍历 `students`，算出每个学生的平均分，判断是否大于 90，满足就把这个学生的信息输出出来。

```python
print("优秀学生名单如下：")
for s in students:
    total = s[2] + s[3] + s[4]
    avg = total / 3
    if avg > 90:
        print(f"{s[0]} {s[1]} 平均分：{avg}")
```

平均分的算法和第一个需求一致，先拿总分再除以 3。判断条件写成 `avg > 90`，大于 90 就是优秀学生，于是把他的学号 `s[0]`、姓名 `s[1]` 和平均分 `avg` 一起输出。跑出来的结果是 4 位优秀学生，平均分都在 90 以上，学号和姓名一并列出。

输出里那个平均分同样是浮点数，用 `.1f` 处理一下就只保留一位小数。

```python
print(f"{s[0]} {s[1]} 平均分：{avg:.1f}")
```

## 6 输出分隔

三个需求的结果连着打印，中间没有任何分隔，读起来容易混在一起。最容易的处理方式是在每块结果之间各打印一个空行：

```python
print()
```

加上空行之后，三块输出的边界清楚了，整体结构也就清晰了。

## 7 案例小结

这个案例里用到的东西分三类：数据的存储靠列表与元组——外层用元组装 10 条学生记录，内层再用元组装每个学生的学号、姓名和三科成绩；数据的提取靠循环遍历、列表推导式与索引访问；数据的呈现靠字符串的格式化处理，包括 `{变量:.1f}` 控制小数位数、`\t` 制表符对齐列。

> **结论**：面对一张表格式的数据，先定容器、再定结构——按「数据会不会变」选可变或不可变容器，按「一行是一条记录」决定容器是否嵌套，后面的统计与筛选都是从这套结构上取数计算。
