# Python 列表的常用方法

前面已经认识过列表，也知道它怎么定义、有哪些特点。接下来要处理的是一整套操作：往列表里加元素、删元素、给元素排序。这些都不需要我们自己动手实现，列表这种数据类型本身就内置了这些功能。要学的只是这些功能怎么用、怎么调用。

## 1. 什么是方法

这里冒出来一个词——方法。什么是方法？

方法就类似于日常生活当中物品具备的能力或者说功能。买一部手机，它可以拍照、可以打电话、也可以发短信，打电话、发短信、拍照这些都属于手机的功能；买一台空调，它可以制冷、可以制热、也可以通风，这些功能都属于空调的功能。日常生活当中是"物品 + 对应功能"。

在 Python 程序开发当中，方法是比较类似的东西，只是说法换了两处：那些功能称之为方法，而那个"物品"称之为对象，方法归属于这些对象。

> **定义**：方法是对象当中所提供的功能，它归属于对象，通过"对象.方法名"的形式调用。

在 Python、Java 这类语言当中有一句话——一切皆是对象。我们之前写程序时定义过的布尔类型的值、字符串类型的值、数字类型的值（包括整型 int、浮点数 float）以及空值类型，这些数据也都称为对象。所以有时候也会说字符串对象、布尔类型的对象、数字类型的对象，因为一切都是对象。

不同的对象有着不同的方法，不同的方法又实现不同的功能。方法归属于对象这件事，后面讲面向对象编程时会详细展开，现在只需要有一个认知：方法就是对象当中所提供的那个功能。

> **提示**：这一节要学的"列表的常见方法"，其实就是 list 这种数据类型内置的常见功能——往列表中添加元素、删除元素、对元素排序。它们都是内置的，不需要我们自己实现，我们学的是怎么调用。

## 2. 六个常用方法

列表的方法比较多，常用的有六个。它们的调用形式是统一的：通过列表对象调用它里面的方法，写成 `对象.方法名`，需要数据的方法再在后面跟上要处理的数据。

### 2.1 append：在尾部追加元素

`append` 的作用就是在列表的尾部追加元素，或者说在列表的尾部添加元素，元素会加到列表的最后。

```python
s.append(10086)
```

这里的 `s` 是一个变量名，这个变量就是一个列表，所以也叫一个列表对象；通过它调用 `append`，后面指定要添加哪个元素，这里添加的是 10086。

### 2.2 insert：在指定索引之前插入元素

`insert` 翻译过来就是插入的意思，作用是在指定索引之前插入元素。

```python
s.insert(0, 92)
```

调用形式仍然是 `s.` 加上方法名。`insert` 里面传递了两项数据，也就是两个参数，两个参数之间用逗号分割：第一个参数代表要在哪个索引之前插入，第二个参数代表要插入的是哪项数据。

上面的写法代表在 0 号索引前面插入一个元素 92。既然插在了原 0 号元素前面，这个 92 的索引就变成 0，而原有的 0 号元素索引变成 1——因为它的前面又插入了一个元素。

```text
插入前:   [ 56 , 90 , 88 , 65 ]        索引 0 1 2 3
              ^
              |  在索引 0 之前插入 92
插入后:   [ 92 , 56 , 90 , 88 , 65 ]   索引 0 1 2 3 4
           ^
        新元素占住 0 号位，原有元素整体后移一位
```

读图看插入点两侧：`insert` 的第一个参数指的是"插到谁的前面"，而不是"插成第几个"。插入点之后的元素索引全部往后挪一位。

### 2.3 remove：移除第一个匹配到的元素

`remove` 用来移除列表当中第一个匹配到的元素，它是按元素值删的。

```python
s.remove(75)
```

如果列表当中有两个 75，删哪个？删匹配到的第一个值：匹配是从头到尾进行的，所以删掉的是靠前的那个 75。

### 2.4 pop：按索引位置删除元素

`pop` 也是用来删除的，但它和 `remove` 的定位方式不同：`remove` 要指定具体的元素，删掉第一个匹配到的；`pop` 要指定索引位置，是按位置来删的。

```python
s.pop(2)
```

这代表删除 2 号索引位置的元素。如果不指定索引，`pop` 默认删除最后一个元素。

`pop` 在删除元素的时候，会把删掉的这个元素返回给我们，所以可以在前面用一个变量接收它，接收到的就是被删除的那个元素。

```python
value = s.pop(2)    # value 就是被删掉的那个元素
s.pop()             # 不传参数，删掉最后一个元素
```

> **易错点**：`remove` 按值删、`pop` 按位置删，两者不能互换着用。想删"那个值为 75 的元素"用 `remove`，想删"索引为 2 的那个元素"用 `pop`。

### 2.5 sort：排序

`sort` 就是排序。列表中的元素要想排序，必须得是同样的数据类型——列表里的元素数据类型一致才可以排序。如果列表里既有数字类型又有布尔类型，那就没办法准确地排序了。

```python
s.sort()
```

对应的调用方式就是直接 `s.sort()`，它会对列表当中的元素进行排序。

### 2.6 reverse：反转列表元素

`reverse` 是反转列表元素。把列表翻转一下会是什么情况？想象对一张图做水平翻转，结果就是：原列表里的最后一个元素变成第一个，倒数第二个变成第二个，倒数第三个变成第三个，倒数第四个变成第四个，依次类推。

```python
s.reverse()
```

调用的方法就是 `reverse`，它把列表的尾部变成头部、头部变成尾部。

### 2.7 六个方法对照

| 方法 | 作用 | 参数 | 备注 |
| --- | --- | --- | --- |
| `append` | 在列表尾部追加元素 | 要添加的元素 | 元素落在列表最后 |
| `insert` | 在指定索引之前插入元素 | 索引、要插入的元素 | 插入点之后元素索引整体后移 |
| `remove` | 移除第一个匹配到的元素 | 要删除的元素值 | 按值删，只删第一个匹配 |
| `pop` | 按索引位置删除元素 | 索引（可省略，默认最后一个） | 会返回被删除的元素 |
| `sort` | 对列表元素排序 | 无 | 元素类型必须一致 |
| `reverse` | 反转列表元素 | 无 | 首尾对调 |

## 3. 运行演示：添加、删除与排序

这些方法的调用形式都是固定的，准备一个列表逐个走一遍。先定义一个名为 `s` 的列表，里面大概有九项数据；定义好之后先输出一遍，后面每调用一个方法再看一次效果。

```python
s = [56, 90, 88, 65, 90, 72, 209, 100, 145]
print(s)

s.append(188)
print(s)
```

调试时在这几行上打一个断点，用 debug 调试模式运行，一块一块地看。追加 188 之后，输出里 188 正好加在末尾那个元素之后，也就是列表的尾部。这就是 `append`。

接着走 `insert`：

```python
s.insert(2, 80)
print(s)
```

这一步代表在索引为 2 的位置前面插入元素 80。插入之后再看列表，80 出现在 88 与 90 相邻的那一处中间位置上。这就是 `insert`：在指定位置之前插入元素。

再往下是 `remove`：

```python
s.remove(90)
print(s)
```

现在要移除的是 90，而列表里有两个 90。按前面的规则删第一个：从头到尾匹配，靠前的那个 90 被删掉了，后面那个 90 仍然留在列表里。

> **提示**：这一步再次说明 `remove` 删的是"指定元素"，不是"指定索引位置"，而且它只删第一个匹配到的。要按索引位置删，就得换 `pop`。

`pop` 的演示：

```python
removed = s.pop(1)
print(removed)
print(s)
```

`s.pop(1)` 删除索引为 1 位置的元素。删完之后把返回的元素打印出来，正是删掉的那个元素——这里拿到的是 80，也就是上一步 `insert` 插进来的那个元素，因为插入之后它的索引正好是 1。如果不指定索引，直接调用 `s.pop()`，删的就是最后一个元素，也就是刚追加进来的 188。

再往后走，最后把整个列表输出一遍，对照前面几次输出看删掉了哪些元素。接着排序：

```python
s.sort()
print(s)
```

`sort` 之前列表里的元素是无序的；调用 `sort` 之后再看输出，元素已经从小到大排好：56、65、72、88、90、100、145、209。`sort` 一旦调用，就会对列表当中的元素进行排序，默认是从小到大。

```python
s.reverse()
print(s)
```

反转之后，209 变成第一个元素，145 变成第二个，100 变成第三个，90 变成第四个——正好是排序结果的逆序。

```text
sort 之后:      56   65   72   88   90  100  145  209
reverse 之后:  209  145  100   90   88   72   65   56
                 ^                        ^
              原末尾变成首位          原首位变成末位
```

读图看两行之间的对应关系：`reverse` 只做首尾对调，它不排序，所以反转后的序列一定是逐位递减的逆序。

## 4. 方法名不用死记

调用这些方法时，方法名不需要硬敲。在编辑器里敲一个 `s.`——`s` 就是这个列表对象——再敲一个点，后面会自动列出这个方法可以调用的东西。

想追加一个元素，敲 `a`，以 a 开头的方法就会提示出来；继续敲 `app`，`append` 就出现了；鼠标双击一下确认，然后指定要添加的元素即可。

> **结论**：方法名不必死记硬背。先敲 `s.` 看提示列表，再根据需求选择要调用哪个方法，选中后双击补全即可。

## 5. 四类操作与统一调用形式

列表的常见方法覆盖了四类动作：添加元素、删除元素、排序、以及反转列表元素。这些方法都是 list 这种数据类型所提供的功能，调用形式统一是"列表对象.方法名"，需要数据的方法在后面跟上参数。

练习的方式很直接：打开自己的 PyCharm 把这些方法逐个敲一遍，熟悉它们各自的作用。
