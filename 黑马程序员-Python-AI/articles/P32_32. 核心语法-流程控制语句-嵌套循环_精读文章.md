# 嵌套循环的语法结构与执行流程

`while` 循环和 `for` 循环的核心语法都讲完了，接下来进入循环的高级用法——**嵌套循环**。

所谓嵌套循环，指的是在循环语句的循环体当中，又编写了一个循环语句。

这在日常里其实很常见，只是以前没有名字叫它。下面先看它的语法结构，再用一组案例把写法演示清楚。

## 嵌套循环的语法结构

这里以 `for` 循环为例。

外层写一个 `for` 循环，它要去遍历数据集一当中所有的元素。冒号下面那部分，就是这个 `for` 循环的循环体。

而在循环体当中，除了代码一、代码二这样的逻辑之外，下面**又套了一个 `for` 循环**。注意——这个内层的 `for` 循环，本身就是外层 `for` 循环的循环体当中的代码。循环体里套循环，这就是嵌套循环。

```python
for 元素一 in 数据集一:
    代码一
    代码二
    for 元素二 in 数据集二:
        内层循环体
```

> **定义**：嵌套循环（nested loop）就是在循环语句的循环体当中再编写一个循环语句；外面的叫外层循环，被套在里面的叫内层循环。

## 嵌套循环的执行流程

剖析执行流程时，有一个好用的办法：**先忽略掉外面的循环，聚焦于内部的循环**。

只盯着内层循环看，它就是一个普普通通的 `for` 循环——遍历数据集二当中的数据，把数据集二当中的元素一个一个拿出来，再对每个元素做进一步处理。内层循环到底要循环多少次，取决于数据集二当中到底有多少个元素。

再把外层循环引入进来。外层循环要遍历的是数据集一当中的数据。它每遍历出来一个数据，就会去执行这一块循环体里的代码：代码一、代码二执行完毕之后，接下来就要执行内层循环，而内层循环要完整地循环一整次。假设数据集二里面有 $n$ 个元素，那么外层循环循环一次，内层循环就得循环 $n$ 次。

内层循环循环完毕之后，再回到外层循环：外层循环去获取第二个遍历出来的元素，处理这个元素，然后内层循环**再循环 $n$ 次**。

> **结论**：外层循环循环一次，内层循环就完整地循环 $n$ 次，而这个 $n$ 取决于待处理的数据集二当中元素的个数。

```text
外层循环取第一个元素
    |
    +-- 代码一、代码二
    +-- 内层循环: 元素1 -> 元素2 -> 元素3 -> ... -> 元素n   (完整一轮)
    |
外层循环取第二个元素
    |
    +-- 代码一、代码二
    +-- 内层循环: 元素1 -> 元素2 -> 元素3 -> ... -> 元素n   (再完整一轮)
    |
   ... 直到数据集一取完
```

读图说明：竖着的两条分支属于同一次外层循环；内层循环每次都必须跑完整整 $n$ 个元素，跑完之后外层才往下走一个元素。

嵌套循环的这套流程，跟日常生活当中的钟表比较类似。

钟表上有时针、分针和秒针。单看分针和秒针：分针转动一小格，秒针是不是得转动一圈？然后分针再转动一小格，秒针又得转动一圈。

分针就相当于外层循环，秒针就相当于内层循环。内层循环一圈一圈地跑，外层循环一小格一小格地走——嵌套循环的执行节奏就是这个样子。

## 案例需求：打印由星号组成的长方形

接下来以一个小需求为例演示嵌套循环的写法：**根据用户输入的长度 m 和宽度 n，打印一个长度为 m、宽度为 n 的长方形**。

这里的 `m` 和 `n` 不是固定的，是由用户键盘录入的。长方形使用星号来表示：长度为 m，就打印 m 个星号；宽度为 n，纵向就打印 n 行。

比如输出一个长度为 10、宽度为 5 的长方形，那一行当中有 10 个星号，纵向一共有 5 行，也就是 5 排星号。

对这个需求做个拆分就清楚了：这不就是输出一行一行的星号吗？

先看一行。这一行当中有多少个星号，取决于长方形的长度 m —— 也就是说，**一行怎么输出**是可以单独搞定的。

一行搞定之后，具体有多少行，取决于宽度 n，那循环输出 n 次就行了。

所以整个需求是两件事：先解决「一行怎么写」，再解决「写多少行」。而这两件事刚好对应外层循环与内层循环。

## 代码实现

第一步，接收键盘录入。需要接收两个数：`m` 是长度，`n` 是宽度。

```python
# 接收键盘录入
m = int(input("请输入长方形的长度："))     # 长度
n = int(input("请输入长方形的宽度："))     # 宽度
```

所输入的数据都是字符串，所以用 `int` 把它转成整型，再把 `input` 语句传递进去。

> **提示**：在 PyCharm 里写这两行时，如果光标停在行中间想直接另起一行，按 `Shift + 回车` 就能在任意位置快速创建一个新行；直接按回车会把光标后面的内容顶到下一行去。

第二步，先只解决「一行」。这一行当中有多少个星号，取决于录入的 `m`：`m` 是 10 就有 10 个星号，`m` 是 20 就有 20 个星号。

这里就可以用 `for` 循环，配合 `range` 构造一个数字序列。`range` 只传一个数据时，代表从 0 开始到 `m` 结束、不包含 `m`，对应的个数刚好是 **m 个**。而 `i` 代表的就是遍历出来的元素。

```python
for i in range(m):
    print("*")
```

`i` 遍历出来的元素现在没什么用——这里并不需要对这个 `i` 做任何处理，只是想「遍历多次」，每遍历一次输出一个星号。先运行测一把：输入长度 10、宽度 5，得到了一串星号，确实是 10 个。

但是——这 10 个星号**每一个都占了一行**：第一个星号是一行，第二个星号是第二行，第三个是第三行。这和预期有差异：我们要的是 10 个星号输出在**同一行**当中。

### print 的 end 参数

为什么会出现 10 行？回到代码看：每一次循环都调用了一个 `print` 语句输出了一个星号，而 `print` 语句**默认自带换行效果**，每一次执行都会输出到新的一行中。循环了 10 次，输出了 10 个星号，而这 10 个星号分别落在 10 行里。

想让它不换行，就要在调用 `print` 的时候后面加上一个逗号，再指定 `end` 等于一个空字符串。

```python
for i in range(m):
    print("*", end="")
```

`end` 表示的是这个输出语句**以什么结束**。它的默认值是 `\n`——反斜杠 n，也就是前面讲字符串时讲过的转义字符，代表换行。不想换行，就把 `end` 设置为一个空字符串。

再测一次：输入 10、宽度 5，输出果然变成了 10 个星号，而且这 10 个星号在同一行当中，没有换行。

`end` 设为空串，意思就是每一次输出以「什么都不加」结束。既然它是可配置的，那就能让它干点别的：比如每一次输出完毕之后想加两个空格，直接在 `end` 里敲两个空格即可。运行之后会发现，每个星号后面都跟着两个空格，然后才输出第二个星号，再两个空格——每一次输出完都会加上两个空格。

> **定义**：`print` 函数的 `end` 参数指定这一次输出以什么内容结尾，默认值是 `\n`（换行）。把它设为空字符串 `""` 表示不换行，设为两个空格则表示每次输出后追加两个空格。

### 加上外层循环控制行数

一行搞定了，接下来是「到底有多少排星号」——这取决于宽度。

做法就是再循环一次：让 `for` 循环循环 `n` 次，`n` 就是宽度。所以在外面再写一个循环 `for i in range(n)`，然后把它里面的逻辑写成「输出这么一排星号」，也就是把刚才那个 `for` 循环放到这个 `for` 循环的里面。

这样一来会出现两个 `i`，把里面的变量名换掉就行，换成 `j`：

```python
for j in range(n):
    for i in range(m):
        print("*", end="  ")
```

现在两个循环各管什么？外层 `for` 循环遍历的是 `range(n)`，而 `n` 代表宽度，所以**外层循环控制的是行**——要输出多少行；内层 `for` 循环它遍历的是 `m`，代表要输出多少列——`m` 是 10 就代表输出 10 列。一个控制行，一个控制列。

> **易错点**：两层的循环变量别用同一个名字。外层用 `j`、内层用 `i` 是最省事的做法；两层都写 `i` 的话，内层会把外层的变量值覆盖掉，循环次数立刻错乱。

再运行一次：输入长度 10、宽度 5，结果和预期还是不一样——所有的星号全部输出到了一行当中。原因就在 `print` 的 `end` 上：`end` 设置的是两个空格，**并没有换行**。

那要不要换行？需要。**什么时候换行？外层循环每循环一次，就需要换一行。**

所以在外层循环这一层，循环体结束之后去换一行。怎么换？调用一次 `print` 语句就行，它默认自带换行效果；里面不用输出任何内容，因为我们只想让它完成换行这个动作。

```python
# 接收键盘录入长方形的长度m和宽度n
m = int(input("请输入长方形的长度："))
n = int(input("请输入长方形的宽度："))

# 打印长方形：外层循环控制行，内层循环控制列
for j in range(n):
    for i in range(m):
        print("*", end="")
    print()     # 外层循环每执行一次换一行
```

再测一次：输入 15，回车，再输入 5——输出的就是一个长度为 15、宽度为 5 的长方形。

## 用调试跟踪嵌套循环

效果实现完毕之后，用调试模式再跟踪一遍执行流程。断点就打在外层 `for` 循环这一行，选择调试模式运行，输入长度 6、宽度 3。

接下来看它怎么走：先进行外层循环，外层循环循环出一个元素之后，紧接着执行内层循环。外层循环循环一次，内层循环就得循环 `m` 次，`m` 是 6，所以内层循环要循环 6 次——内层第一次、第二次、第三次、第四次、第五次、第六次。

内层循环循环完毕之后，继续外层循环：外层循环第二次。在第二次的过程当中，内层循环又要循环 6 次。接着外层循环再循环第三个元素，内层循环继续执行 6 次。当外层循环循环完毕之后，整个循环结束。

是不是就像日常生活当中的那个时钟？分针转一小格，秒针就得转一圈；回来分针再转一小格，秒针再转一圈。

整个流程用一张图收尾：

```text
j = 0 : i = 0 1 2 3 4 5   -> 换行
j = 1 : i = 0 1 2 3 4 5   -> 换行
j = 2 : i = 0 1 2 3 4 5   -> 换行
```

读图说明：`j` 每取一次值，`i` 都完整地走完 0 到 5 这 6 个值；`j` 走完 3 个值，内层总共执行了 $3 \times 6 = 18$ 次。这就是「外层一次、内层 n 次」在具体数字上的样子。
