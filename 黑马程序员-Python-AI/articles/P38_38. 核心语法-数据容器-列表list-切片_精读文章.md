# Python 列表切片操作

上一小节把列表是什么、怎么定义、有哪些特点讲完了。接着要处理一个新动作：列表里已经存好了数据，但我现在只想要其中一部分。比如一个列表里堆着七个元素，我只想把前面三个挑出来用——这个"截取其中一部分"的动作，就是切片。

切片不只是列表能用。字符串、元组也支持切片。再往大一点说，Python 当中序列类型都是支持切片的。

## 1. 切片的前提与定义

> **定义**：切片（slice）指的是针对要操作的数据，截取其中一部分的操作。列表支持切片，字符串、元组同样支持，凡序列类型都支持切片。

"序列类型"这个词前面已经给过定义：元素是有序的、并且可以通过索引访问容器当中元素的那些数据容器，我们称之为序列类型。列表正好两条都满足——元素有顺序，元素又能用索引访问——所以它是序列。

既然切片靠索引来划定范围，就得先把列表上的两套索引摆清楚。列表里每个元素都有两种索引：正向索引从 0 开始，是 `0、1、2、3、4、5、6`；反向索引从列表尾部开始编号，从 -1 开始，是 `-1、-2、-3、-4、-5`。

## 2. 切片的基本语法

切片的写法是在序列数据类型的后面跟上一对方括号，方括号当中写三个参数，三个参数之间用两个冒号分隔。

```python
序列[开始索引:结束索引:步长]
```

三个参数各管一事：第一个参数是开始索引，代表从哪开始截取；冒号之后第二个参数是结束索引，代表截取到哪；第三个参数是步长，代表截取的间隔，也就是每几个元素截取一个元素。

### 2.1 三条注意事项

第一，指定了开始索引和结束索引之后，截取时包含开始索引，但不包含结束索引对应的元素。举例来说，开始索引写 0、结束索引写 2，看起来范围是 0、1、2，但因为不包含结束索引，最终截取出来的是两个元素。

开始索引可以不指定，不指定时默认是 0，代表从第一个元素开始截取。结束索引也可以不指定，不指定时默认是列表的长度，简单说就是截取到列表最后的位置，包含列表的最后一个元素。步长如果不指定，默认是 1，代表挨个截取。

第二，索引既可以使用正向索引，也可以使用反向索引。正向索引从 0 开始，反向索引从后往前从 -1 开始，两种都支持。

第三，步长指的就是选取间隔，默认是 1。

> **易错点**：切片是"左闭右开"——包含开始索引，不包含结束索引。想要前 5 个元素，结束索引要写 5 而不是 4；写成 4 只会拿到 4 个元素。

### 2.2 两个样例推演

假设 `s` 列表里的元素依次是 a、b、c、h、k、l，正向索引 0 到 5。写 `s[0:5:1]` 的含义是：从索引 0 开始截取，截取到索引 5 的位置，包含 0 不包含 5，步长为 1 表示挨个截取。索引 5 上的元素不会被截到，最终拿到前面 5 个元素。

```text
索引:      0    1    2    3    4    5
元素:      a    b    c    h    k    l
           |----|----|----|----|
           包含                    不包含
s[0:5:1] -> a  b  c  h  k        (5 个元素)
```

读图看两端：左端"包含"落在索引 0 上，右端"不包含"落在索引 5 上，所以索引 5 的元素被切在结果之外。

第二个样例 `s[0:5:2]`，步长是 2，代表每两个元素截取一个。从索引 0 开始，a 被截取，c 跳过；e（索引 4）被截取，中间的 b（索引 3）跳过；然后再截一个 d。结果就是 a、e、d。

```text
索引:      0    1    2    3    4    5
元素:      a    b    c    h    k    l
截取:      ^         ^         ^
           a         c         k
s[0:5:2] -> a  c  k
```

读图看箭头的落点：步长 2 就是从起点起、每隔一个取一个，被跳过的那些元素仍然留在原列表里，只是不进结果。

## 3. 运行演示：切片与结果类型

在 PyCharm 里准备一个名为 `s` 的列表，里面大概十个元素，直接输出切片结果来观察。

需求是把前面 5 个元素截取出来，从头开始截，所以开始索引写 0。结束索引写几？因为不包含结束索引，而我们要前 5 个，所以结束索引写 5；索引为 5 的其实是第 6 个元素，它不会被包含进来。步长一个一个截取，写 1。

```python
print(s[0:5:1])
```

运行输出的就是这个列表从头开始的 5 个元素，它们刚好构成 `['a', 'c', 'h', 'k', 'l']`。切片结果本身也是列表，也就是说，这是从一个大的列表当中截取了一个小的列表出来。

```python
print(type(s[0:5:1]))
```

类型是 list。切片不改变元素的类型，也不产生新的类型，它产出的仍然是列表。

> **提示**：PyCharm 在这类写法上偶尔会给出黄色提示（大意是类型别名、非泛化之类），这只是开发工具的提示，语法本身没有问题，可以先不管它。

## 4. 省略规则与冒号的边界

上面那个完整写法可以逐步简化。

既然开始索引是从头开始，0 可以省略：`s[:5:1]` 运行结果与 `s[0:5:1]` 一致。

既然步长是 1，步长也可以不写：`s[:5:]` 效果仍然一样。

再进一步，后面的那个冒号也能省略——步长为 1 时后面已经不需要写东西了：`s[:5]` 效果还是一样。

那第一个冒号能不能也省略？把 `s[:5]` 写成 `s[5]` 行不行？不行。第一个冒号一旦省略，含义就变了：`s[5]` 不再是切片，而是获取列表中索引为 5 的那个元素，也就是第 6 个元素。运行一下会发现拿到的是单个元素，不是列表。

> **易错点**：`s[:5]` 是切片，取前 5 个元素，结果是列表；`s[5]` 是索引取值，取索引为 5 的那一个元素，结果是元素本身。这一对只差一个冒号，含义完全不同。

把省略规则整理成一张对照表：

| 写法 | 含义 | 说明 |
| --- | --- | --- |
| `s[0:5:1]` | 索引 0 到 4 的元素 | 三个参数写全 |
| `s[:5:1]` | 同上 | 开始索引省略，默认 0 |
| `s[:5:]` | 同上 | 开始索引、步长都省略 |
| `s[:5]` | 同上 | 第二个冒号一并省略 |
| `s[5]` | 索引为 5 的那一个元素 | 不是切片，是索引取值 |

## 5. 步长与反向索引的用法

接着看怎么截取 a、h、l 这三个元素。从 a 开始截，起点仍是索引 0；要截到 l（索引 4）的位置，而结束索引不包含在内，所以结束索引写 5——这样刚好避开索引 5 上的元素。索引 0 与索引 2 之间空一个，步长就不能是 1，得设成 2。

```python
print(s[0:5:2])
```

结果正是 a、h、l 这三个。步长为 3 的话，中间就会跳过两个元素，这类取值可以自己一个一个测过去。

反向索引同样可以参与切片。写成 `s[0:-2:1]`，含义是从头开始截，到索引为 -2 的位置结束。反向索引里 -1 是最后一个元素、-2 是倒数第二个元素，所以这是截取到末尾之前的一个位置为止。

```python
print(s[0:-2:1])
```

结果是原列表中索引 0 到索引 7 的元素，也就是到索引 -3 那个元素为止，最后一个元素与倒数第二个元素都被排除在外。

> **结论**：切片的三个索引参数既能用正向索引也能用反向索引，混用也可以。`s[0:-2:1]` 与 `s[0:8:1]` 在长度为 10 的列表上指向同一个范围。

## 7. 切片语法的参数与默认值

需要明确的只有一件事：列表切片的语法。切片就是截取列表的一部分，语法是列表名称后面跟一对方括号，方括号当中三个参数用两个冒号分隔，三个参数分别是 `start`（开始索引）、`end`（结束索引）、`step`（步长）。

`start` 不指定默认为 0，代表从列表第一个元素开始截取；`end` 不指定默认为列表的长度，简单说就是截取到列表末尾，包含最后一个元素；`step` 代表每间隔几个元素截取一个，不指定默认为 1。

```text
序列[start:end:step]
     |     |     |
     |     |     +-- 每几个取一个，默认 1
     |     +-------- 截到哪（不包含），默认列表长度
     +-------------- 从哪开始，默认 0
```

读图注意右侧注释里两个"包含/不包含"的差别：起点是包含的，终点是不包含的，这是切片最容易写错的地方。
