# Python 字符串拼接：字面量合并与加号拼接

字符串的三种定义方式掌握之后，接下来剖析字符串的使用细节，这一小节专讲拼接。

现实里经常要把多个字符串合并成一个：一句话由姓名、年龄、专业、爱好几段拼出来，每个部分还得不一样。这就是字符串拼接要解决的问题。

## 1. 多个字符串字面量的自动合并

如果拼接的对象都是字符串字面量，那最简单：直接把它们挨着写在一起就行。

```python
s1 = "黑马程序员" "成就每一个IT人"
print(s1)      # 黑马程序员成就每一个IT人
```

Python 解释器在执行时会自动把多个字符串合并成一个。前提是这些部分都得是字符串字面量，它才会自动合并。

中间要不要加东西？可以加空格，也可以不加；加一两个、四五个空格都没问题，解释器照单全收。

```python
s1 = "人生苦短" "我用Python" "OK"
print(s1)      # 人生苦短我用PythonOK
```

三个字面量直接写在一起，解释器一样自动拼好。要是想在“人生苦短”和“我用 Python”之间留一个空格，就在第一个字符串里面写好那个空格——合并动作本身不会替你插入任何分隔。

> **提示**：相邻字面量的自动合并是悄悄发生的，中间不会补空格。所以“黑马程序员”和“成就每一个 IT 人”直接挨着写，输出就是“黑马程序员成就每一个 IT 人”。想要空格，就把空格写进前一个字符串的引号里面。

> **结论**：这种写法了解即可。既然都是字面量、内容又是写死的，那不如直接写成一个字符串来得干脆。

## 2. 加号拼接

第二种方式是使用加号拼接：第一个字符串和第二个字符串之间，用加号把多个字符串合并成一个。

```python
print("黑马程序员" + "成就每一个IT人")
```

但项目开发当中，拼接往往不是把两个字面量接到一起——真要是那样，直接写成一个字符串就行了。更多时候是字符串字面量与变量拼在一起。

举个例子，要输出一句话：Python 之父吉多·范罗苏姆说“人生苦短，我用 Python”。其中“人生苦短”是一个变量 s1，“我用 Python”是另一个变量 s2，而 s1 和 s2 之间还需要一个逗号分隔。要把这句话完整输出，就必须把这几部分拼起来。

```python
s1 = "人生苦短"
s2 = "我用Python"
print("吉多·范罗苏姆说：" + s1 + "，" + s2)
```

拆开看拼接顺序：先是字面量“吉多·范罗苏姆说：”，接着用加号接上变量 s1，s1 后面还得接一个逗号——逗号也是字符串字面量，同样用加号拼上；逗号之后的 s2 继续用加号接。也就是说，只要涉及字符串各个部分的拼接，就写一个加号把它们连起来。

想在逗号前后加个空格，在对应位置补一个空格字符串就行。

> **易错点**：加号只能拼接两个字符串，没法把非字符串和字符串直接拼起来。像 int 这样的整数类型不能直接和字符串相加；非字符串类型必须先转成字符串类型，才可以拼接。

## 3. 实战：拼出一句自我介绍

需求是：根据自己的实际情况输出一条个人信息，结构形如“大家好，我是涛哥，今年18岁，学习的专业是软件工程，爱好Python、Java”。

这句话里名字、年龄、专业、爱好对每个人都不一样，都是动态变化的，所以先把这些容易变动的信息用变量记下来，再通过字符串拼接把整句话输出。

```python
name = "涛哥"
age = 18
pro = "软件工程"
hobby = "Python、Java"
print("大家好，我是" + name + "，今年" + age + "岁，学习的专业是" + pro + "，爱好" + hobby)
```

这段代码运行不起来，`age` 那一处的拼接就是原因——字符串和整数没法用加号接上。

变量名起得有语义一些，方便自己看懂：name 是名字，age 是年龄，pro 是专业的简写，hobby 是爱好。年龄在这里写 18，它就是个整数。

这段代码写完，PyCharm 里 `age` 那一处会出现黄色背景色。

> **提示**：PyCharm 里出现黄色背景色就是一条警告，代表这块代码可能有问题。鼠标移上去会说明原因：意外的类型——当前 age 是 18，属于整数类型，提示里“意外的类型是 int”，而“可能的类型是 str”。一句话说，这里需要一个 str 类型，却给了一个 int 类型。

警告到底会不会真的拦住程序？直接运行看看：报错了。报错信息说的正是这件事——字符串拼接仅仅能够拼接 str 类型、字符串类型，而不能拼接 int 类型。这就印证了前面那条规则：加号只能拼接字符串，没法把字符串和非字符串拼接起来。

解决办法是类型转换。新介绍一个工具 `str`，把括号里 int 类型的数字转成字符串：

```python
print("大家好，我是" + name + "，今年" + str(age) + "岁，学习的专业是" + pro + "，爱好" + hobby)
```

`str` 也是个函数，写法是 `str` 后面跟一对小括号，括号里写上要转换的对象。这里把 `age` 传进去，它就会把 age 这个数字类型转成字符串类型，再参与拼接。

再次执行，姓名、年龄、专业、爱好全部拼接成功，那条自我介绍正常输出了。

```text
"大家好，我是" + name + "，今年" + str(age) + "岁，学习的专业是" + pro + ...
      |            |          |          |           |
    字符串       字符串     字符串    int -> str    字符串
      |            |          |          |           |
      +------------+----------+----------+-----------+
              加号两侧必须都是字符串，类型转换要在拼接前完成
```

读图看两个要点：加号两侧必须都是字符串；遇到 int 这类非字符串数据，先在它所在的位置用 `str()` 转换好，再交给加号。
