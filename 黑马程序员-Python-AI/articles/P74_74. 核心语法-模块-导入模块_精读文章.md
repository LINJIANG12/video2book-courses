# Python 导入模块：五类语法与调用方式

要把 Python 官方提供的内置模块用起来，或者用别人已经开发好的模块，绕不开一个前置动作：**先导入，再使用**。这一节只做一件事——把导入模块的语法讲完，并当场验证每一种写法。

先说个好消息：Python 的导入语法相当灵活，它允许导入完整的一整个模块，也允许只导入这个模块当中我们要用到的那几个功能。这里说的“功能”范围很宽，可以是一个变量、一个函数，也可以是一个类或者一个方法，后面讲面向对象时会详细展开。

## 语法的两大类与五小类

五种写法其实归为两大类：

- **第一类：导入整个模块**。包括 `import 模块名` 和 `import 模块名 as 别名` 两种写法。模块整体进来，之后用“模块名.功能名”取用里面的东西。
- **第二类：从模块中导入指定功能**。包括 `from 模块名 import 功能名`、`from 模块名 import 功能名 as 别名`、`from 模块名 import *` 三种写法。只有指定的功能进来，调用时直接写功能名。

| 写法 | 语法 | 调用方式 |
| --- | --- | --- |
| 导入整个模块 | `import 模块名` | `模块名.功能名` |
| 导入整个模块并起别名 | `import 模块名 as 别名` | `别名.功能名` |
| 导入模块中的指定功能 | `from 模块名 import 功能名` | `功能名` |
| 导入模块中的指定功能并起别名 | `from 模块名 import 功能名 as 别名` | `别名` |
| 导入模块中的全部功能 | `from 模块名 import *` | `功能名` |

> **结论**：判断怎么调用，只看 `import` 后面写的是模块还是功能——写的是模块，调用就得带模块名（或别名）；写的是功能，调用就直接写功能名。

## 导入整个模块

第一种语法最短：`import` 后面跟上模块名。`import` 就是导入的意思。如果想一次性导入多个模块，多个模块名之间用逗号分隔：

```python
import random, os
```

这一句就把随机数模块和操作系统模块都导进来了，之后要用哪个功能，就写“模块名.功能名”。为什么要带这个模块名？因为进来的是整个模块，点号后面的功能名才是告诉 Python 我们到底要调这个模块里的哪一个功能。

## 用 as 给模块起别名

模块名有时很长，写起来不方便，于是可以在 `as` 后面给它起个别名：

```python
import random as rd
```

这句代码的含义是：导入的仍然是 `random` 这个模块，但导入之后它的名字变了，变成 `rd`。名字一旦改了，后面的调用就必须走别名——`rd.randint(1, 100)`，写成 `random.randint(...)` 反而不对了。

```python
import random as rd

print(rd.randint(1, 100))
```

## 从模块中导入指定功能

下面三种写法都用来导入模块中具体的功能。既然只要其中一两个功能，那就没必要把整个模块搬进来。它的语法是 `from 模块名 import 功能名`——`from` 翻译过来就是“从哪儿来”，`from` 后面是功能的出处，`import` 后面才是功能本身：

```python
from random import randint, choice
```

这行代码读作：从 `random` 这个模块当中导入两个功能，一个是 `randint`，一个是 `choice`。要导入多个功能时，功能名之间用逗号分隔。

> **易错点**：`from 模块名 import 功能名` 之后，调用时**不能**再在前面加模块名。因为进来的是功能本身，模块名在调用处已经没有意义——写成 `random.randint(...)` 会报错。

功能名太长、太复杂时，同样可以用 `as` 起别名。一旦起了别名，之后调用就只能用别名：

```python
from random import randint as rint

print(rint(1, 100))
```

## 用星号导入模块中的全部功能

在 Python 中，也可以一次性把整个模块的功能全部导入进来，写法是在 `import` 后面直接写一个 `*`：

```python
from random import *

print(randint(1, 100))
```

这个星号是**通配符**，代表这个模块里的所有功能。全部导入之后，调用时直接写功能名即可。

> **提示**：星号写起来省事，但“导入所有功能”并不等于“这个模块的所有功能都会进来”。自定义模块时可以通过一个特殊变量控制星号的范围，`random` 这类标准库模块自己也做了同样的控制，后面的小节会把这层机制讲透。

### 导入整个模块的调用形式

第一件事是演示导入整个模块，拿生成随机数的 `random` 模块做例子。敲 `im` 会弹出提示，双击选中 `import`；紧接着敲模块名，双击选中 `random`，这句 `import random` 就写好了。`random` 属于 Python 标准库，也就是官方的内置模块，导入进来就能用。

```python
import random

for i in range(100):
    print(random.randint(1, 100))
```

这里的 `randint` 用来生成一个 `int` 类型的随机数，括号里要指定起点 `start` 和终点 `end`——写 `1, 100` 就表示随机数落在 1 到 100 之间。有一点必须记住：**这个区间是两端都包含的**，1 和 100 都可能被取到。循环 100 次，运行后就得到 100 个随机数，其中确实能见到 1，也能见到 100。

导入模块时还有一个细节：如果某句 `import` 写完之后发现它是灰色的，说明这个模块导入进来了却没有被使用，PyCharm 用颜色提醒你。

调用形式也在这里定下来：`random` 是模块名，`randint` 是它里面的一个功能（本质上是一个方法），所以写成 `random.randint(...)`。现在把 `import random` 改成 `import random as rd`，调用处换成 `rd.randint(1, 100)`——注意后面的功能名不用动，只把模块名换成别名。再运行一次，效果完全一样：

```python
import random as rd

for i in range(100):
    print(rd.randint(1, 100))
```

### 只导入指定功能时的调用形式

把上面的代码注释掉，换成第二类写法。只用到 `randint`，那就只导入 `randint`：

```python
from random import randint

for i in range(100):
    print(randint(1, 100))
```

调用方式随之改变：前面不再需要模块名，直接写 `randint(1, 100)`。运行结果和前面毫无差别——因为调用的本来就是同一个功能，只是取用方式变了。

这个功能名同样可以起别名。给它一个 `rint`：

```python
from random import randint as rint

for i in range(100):
    print(rint(1, 100))
```

名字一旦起了别名，就必须用别名调用，原来的 `randint` 不能再用了。再次运行，结果一致。

### 通配导入的形式

最后一种写法是把 `random` 里的所有功能一次性导入：

```python
from random import *

for i in range(100):
    print(randint(1, 100))
```

星号代表模块中的所有功能，调用时当然也是直接用功能名——`random` 里有 `randint`，那就写 `randint(1, 100)`。运行，效果依旧一样。

## 导入语句的位置

语句写完之后，还有一个必须养成的习惯：**`import` 导入语句一般写在整个 Python 文件的最上面**，具体可执行的代码写在导入语句下面。

理由有两条。第一，打开一个 Python 文件，一眼就能看清它到底用到了哪些模块，不用翻到文件中间去找。第二，模块操作一定是先导入、再使用，导入语句放在最上面，下面的代码自然就能直接用。

> **提示**：这条位置约定不是语法强制，而是可读性约定。真把导入写到文件中间，程序多半还能跑，但读代码的人就得自己去找依赖了。
