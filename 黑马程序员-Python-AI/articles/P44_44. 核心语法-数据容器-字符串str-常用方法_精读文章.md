# 字符串常用方法：查找、大小写、切割、清理与替换

字符串这种数据容器和它的三个特点都清楚了，接下来看它的常用方法。字符串的方法比较多，这里只挑常用的讲。

在列方法之前先强调一点：字符串是不可变的、无法修改，所以下面这些方法**都不会改动字符串本身的内容**。它们做的事是"读着原来的字符串，算出一个结果返回给你"。

## 1 方法速览

| 方法 | 作用 | 返回值 |
| --- | --- | --- |
| `find` | 在字符串中查找指定的子串，返回它第一次出现的索引位置，找不到返回 `-1` | 索引值或 `-1` |
| `count` | 统计子串在字符串中出现的次数 | 出现次数 |
| `upper` | 把字符串转成大写 | 转换后的新字符串 |
| `lower` | 把字符串转成小写 | 转换后的新字符串 |
| `split` | 按指定的字符串把字符串切割成多个部分 | 列表 |
| `strip` | 去掉字符串左右两端的空白字符，不传参时默认去空格 | 处理后的新字符串 |
| `replace` | 把指定的字符串替换成新的字符串 | 替换后的新字符串 |
| `startswith` | 判断字符串是否以指定的子串开头 | `True` 或 `False` |
| `endswith` | 判断字符串是否以指定的子串结尾 | `True` 或 `False` |

> **定义**：子串就是子字符串，指的是字符串的一部分，也就是从整串里截出来的那一段。

下面逐个走一遍，每一条都实际调一次看结果。

## 2 查找与统计：find 与 count

`find` 用来在字符串当中查找指定的子串，返回它**第一次**出现的索引位置，注意是从前往后找；如果找不到，返回 `-1`。

```python
print(s.find("-"))      # 5
```

索引 0 到 4 是 hello，索引 5 恰好就是这个横杠，所以返回 5——拿到的就是第一次出现的位置。

`count` 用来统计某个子串在字符串中出现的次数：

```python
print(s.count("o"))     # 4
```

`o` 在这段字符串里一共出现了 4 次。

## 3 大小写转换：upper 与 lower

`upper` 把字符串转成大写，`lower` 把字符串转成小写。要注意的是：它们不会修改字符串本身，而是把转换后的结果作为新字符串返回，所以得用一个新变量接住。

```python
s_upper = s.upper()
s_lower = s.lower()
print(s_upper)
print(s_lower)
```

输出一个全部字母大写、一个全部字母小写，而原来的 `s` 还是原来的样子。

## 4 切割与清理：split 与 strip

`split` 按指定的字符串把字符串切割成多个部分，返回值是一个列表，切出来的每一段就是列表里的一个元素。

```python
parts = s.split("-")
print(parts)
```

这里按横杠切割，字符串里本来就有三个横杠，切开之后的多个部分被封装进了一个列表。

> **易错点**：`s.split(" ")` 括号里的 `" "` 是一个空格，不是空字符串。按空格切割和按空字符串切割完全是两件事，写的时候别把那个空格漏掉。

`strip` 用来去掉字符串左右两端的空白字符（也就是空格）；如果传了参数，就去掉指定的字符——例如 `strip("*")` 表示去掉字符串左右两侧的星号。

```python
s2 = "  hello-python  "
print(s2.strip())
```

给字符串两端各加一些空格再看效果：直接输出时左右两侧的空格都在，调用 `strip` 之后两端的空格就没有了。

> **提示**：如果字符串两端本来就没有空格，直接调 `strip` 是看不出任何变化的——它去掉的是本来就存在的那部分空白，不会凭空多删字符。

## 5 替换：replace

`replace` 用来替换字符串，它接收两个参数：第一个是 `old`，即要被替换掉的老字符串；第二个是 `new`，即替换成的新字符串。替换的结果同样是一个新字符串。

```python
s_new = s.replace("-", "_")
print(s_new)
```

这句的意思是拿一个下划线去替换字符串当中的横杠，运行之后原来的横杠都变成了下划线。

## 6 首尾判断：startswith 与 endswith

这两个方法的执行结果都是布尔值，用来判断字符串是否以指定的子串开始和结束：`startswith` 管开始，`endswith` 管结束。

```python
print(s.startswith("hello"))    # True
print(s.endswith("Python"))     # False
```

这段字符串确实以 hello 开头，所以第一个结果是 `True`；它并不是以 `Python` 结尾，所以第二个结果是 `False`。

## 7 一串操作之后，原字符串没有变

把上面这些方法连着用一遍——转大写、转小写，再切割、去空格，最后重新输出一次原始的 `s`，和最开始的样子对比：

```text
s  ──►  find / count / upper / lower / split / strip / replace  ──►  各自返回的新字符串或列表
                     （s 自身始终不变）
```

读图说明：每个方法都是"读 `s`、算出结果返回"，中间没有任何一步改到了 `s`；一轮操作走完，原始字符串的内容一个字符都没变。
