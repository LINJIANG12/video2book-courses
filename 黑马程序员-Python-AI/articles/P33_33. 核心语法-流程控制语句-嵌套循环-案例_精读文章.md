# 用嵌套循环打印九九乘法表

嵌套循环的语法和执行流程我们已经清楚了，接下来要把它用在一个真正的案例上。这道题很经典：打印九九乘法表，就是我们小学天天背的那张表。

看最终要输出的效果。第一行是 `一一得一`；第二行是 `一二得二、二二得四`；第三行是 `一三得三、二三得六、三三得九`；第四行是 `一四得四、二四得八、三四十二、四四十六`。一行一行读下来，就是那张熟悉的表。

问题是，这张表怎么用代码把它一行一行吐出来？

## 一、把乘法表看成表格

先换个眼光看它：这其实是一张表格。每个乘法表达式占据一个单元格，因此每一行读出来就是表格的第一行、第二行、第三行……结构一下子就清晰了。

```text
第1行:  1x1=1
第2行:  1x2=2   2x2=4
第3行:  1x3=3   2x3=6   3x3=9
第4行:  1x4=4   2x4=8   3x4=12  4x4=16
...                                   -> 一直到第9行

列方向: 第1列的被乘数全是1, 第2列全是2, 第3列全是3, 第4列全是4
行方向: 第1行的乘数是1,     第2行是2,     第3行是3,     第4行是4
```

既然它是表格，那么"一行有几格、一共几行"就不再是感觉问题，而是可以数出来的数量关系。

### 1.1 乘数就是行号

盯着乘法表达式里的第二个数字看，也就是乘数。

第一行的乘数是 1，第二行的乘数是 2，第三行的乘数是 3，第四行的乘数是 4，第五行就是 5。所以在这个表里，**表达式的第二个数字就是当前所处的行号**。

### 1.2 被乘数就是列号

再盯第一个数字，被乘数。

竖着看：第一列的表达式，被乘数全是 1；第二列的被乘数全是 2；第三列全是 3；第四列全是 4。所以**表达式的第一个数字就是当前所处的列号**。

### 1.3 一共九行九列

行数是九行，列数也是九列——从 `一一得一` 一直排到 `九九八十一`。

> **结论**：在九九乘法表里，第一个数代表列，第二个数代表行。行号和列号一定下来，表里每一个单元格的内容就唯一确定了。

## 二、输出顺序决定循环结构

接下来要问一个关键问题：输出的时候，是一列一列地输出，还是一行一行地输出？

答案是一行一行。先输出第一行，第一行完了再输出第二行，第二行完了再输出第三行，一路往下。打印这件事本身就是一行一行往外走的。

这一下就把嵌套循环的分工定死了：外层循环控制行，内层循环控制列。

- 外层循环对应表达式里的第二个数字，也就是行。它负责"第一行输出完，去做第二行，第二行输出完，去做第三行"。
- 内层循环对应表达式里的第一个数字，也就是列。因为一行里面还有若干个单元格——第三行有三个格子，第四行有四个格子——这些格子必须一个一个输出。

```text
外层循环 (行 i)
  |
  |-- i = 1  -> 内层循环输出 1 个格子
  |-- i = 2  -> 内层循环输出 2 个格子
  |-- i = 3  -> 内层循环输出 3 个格子
  |                          ...
  |-- i = 9  -> 内层循环输出 9 个格子
  |
  +-- 每跑完一轮内层循环, 补一次换行, 再进下一行
```

读这张图要注意一点：内层循环每完整跑完一轮，才轮到外层循环往前走一步；换行发生在两者之间。

## 三、把分析写成代码

分析清楚了，直接在 PyCharm 里落代码。既然循环次数明确，就用 for 循环，两层。

### 3.1 外层循环的范围不能是 range(10)

先写外层：

```python
for i in range(1, 10):
```

写 `range` 的时候，开发工具默认提示的是 `range(10)`。这个提示不能直接用。`range(10)` 生成的数字序列是从 0 开始的：0、1、2……9。而我们要的序列是从 1 开始。

所以写成 `range(1, 10)`：从 1 开始，到 10 结束但不包含 10，实际取到 9。九行，正好。

> **易错点**：`range` 的结束值是开区间，不包含在序列里。想要 1 到 9，必须写 `range(1, 10)`，写 `range(1, 9)` 会少一行。

### 3.2 内层循环的上限由行号决定

内层循环的循环变量换个名字，跟外层错开，不要也叫 `i`：

```python
for j in range(1, i + 1):
```

这里也有个坑。开发工具提示的是 `range(1, 10)`，但那意味着每一行都要输出十列。回头看表：第一行只有 1 个表达式，第二行有 2 个，第三行有 3 个，第四行有 4 个——每行的列数是随行号变化的。

那这个列数由谁决定？由 `i` 决定。`i` 是 1 就输出一列，`i` 是 2 就输出两列，`i` 是 3 就输出三列。

所以上限应该写成 `i`。但 `range` 的结束值不含在内，如果直接写 `range(1, i)`，第一行 `i` 是 1，`range(1, 1)` 一个元素都不产生，一行就空了。所以要写成 `i + 1`：`i = 1` 时取到 1 列，`i = 2` 时取到 1、2 两列。

### 3.3 内层循环体的输出格式

循环体要做的事就是输出单元格内容。用格式化字符串来拼：

```python
print(f"{j}x{i}={j * i}", end="\t")
```

- 第一个数用 `j`，它是内层循环遍历出来的元素，也就是被乘数（列号）；
- 乘号这里用字母 `x` 代替。想要真正的 `×` 符号，可以在输入法上点右键，打开符号大全，在里面挑对应的符号；
- 第二个数用 `i`，也就是乘数（行号）；
- 后面接等号，结果是 `j * i`。

`print` 默认自带换行，而内层循环控制的是列，列与列之间不能换行，只能拉开一点间距。所以给 `end` 参数赋一个制表符：

```python
end="\t"
```

`\t` 是转义字符，代表制表符，也就是一个 tab 的距离。这样每输出一个表达式，结尾都补一个制表符宽度。

### 3.4 每行结束补一次换行

内层循环跑完之后，在它下面调用一次不带参数的 `print`，利用它自带的换行效果起一个空行，把行与行分开。

完整代码如下：

```python
# 打印九九乘法表
for i in range(1, 10):          # 外层循环: 控制行
    for j in range(1, i + 1):   # 内层循环: 控制列
        print(f"{j}x{i}={j * i}", end="\t")
    print()                     # 一行输出完毕, 换行
```

## 四、运行结果与对齐

右键运行，九九乘法表就出来了。对照样例：`一一得一`，`一二得二、二二得四`，`一三得三、二三得六、三三得九`，`一四得四、二四得八、三四十二、四四十六`，完全一致。

为什么列会排得这么整齐？因为每输出一个表达式，都是以 `\t` 结束的。那个位置就是一个制表符的空格。

把 `end="\t"` 去掉再跑一次试试，所有表达式会挤到一块儿，读起来就很难看了。

> **提示**：`\t` 决定的是对齐效果，而不是内容正确性。去掉它表还是对的，但不再是"表格"的样子。
