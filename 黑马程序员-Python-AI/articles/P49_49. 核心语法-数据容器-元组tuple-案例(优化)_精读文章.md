# 元组解包：把索引取值改成按名字取值

学生成绩统计那个案例，功能我们已经全做完了。做完了先别急着往下走，回过头看一眼那段代码——我在取元组里的元素时，用的全是索引。

那我就问一句：`s[2]` 取到的是学生的什么信息？`s[4]` 呢？`s[3]` 呢？

> **结论**：索引取值没有任何问题，能实现需求。问题在于它**要求读代码的人同时记住这套数据结构每一位存的是什么**。

现在这门课只有三个科目，索引和内容的对应关系还勉强记得住。可要是七八个科目呢？一堆裸下标摆在面前，读起来就吃力了。索引没错，但它把「这个位置是什么」的负担全部推给了读者。

这一节就演示这段代码的第二种写法。

---

## 1. 索引取值的可读性问题

先把两种写法的差异摆出来。

```python
students = [
    ('1001', '王林', 90, 95, 88),
    ('1002', '韩立', 88, 92, 90),
    ('1003', '李慕婉', 76, 85, 79),
]

# 方式一：全靠索引
for s in students:
    total = s[2] + s[3] + s[4]
    print(f'学号是{s[0]}, 姓名是{s[1]}, 语文是{s[2]}, 数学是{s[3]}, 英语是{s[4]}, 总分是{total}')
```

`s` 是遍历出来的那个元素，它本身就是一个元组，里面一共五个元素，依次是学号、姓名、语文、数学、英语。`s[0]` 到 `s[4]` 能取到值，但光看这一行代码，你**说不出来** `s[2]` 到底是语文还是数学——必须回头翻那条元组的定义。

### 1.1 要读的数据结构越大越费劲

> **提示**：真正的成本不在敲代码的时候，而在**回读**的时候。写的时候你知道每个位置代表什么，隔一周再看，就只剩下一串数字。

三个科目时这个问题还不算致命；科目一多，索引法就从「能用」变成「难维护」。

### 1.2 方式二：元组解包

既然 `s` 是一个五元素的元组，那就可以把元组里的元素**一个一个解开**，分别赋给五个变量。

```python
for s in students:
    id, name, chinese, math, english = s
    total = chinese + math + english
    print(f'学号是{id}, 姓名是{name}, 语文是{chinese}, 数学是{math}, 英语是{english}, 总分是{total}')
```

`s` 里就是五个元素，那就在这个位置写五个变量：学号叫 `id`，姓名叫 `name`，语文叫 `chinese`，数学叫 `math`，英语叫 `english`。

> **提示**：`id` 在程序开发里叫**唯一标识**，含义是「这个东西是唯一的」。学号恰好就是唯一的，所以这个位置用 `id` 命名很合适。

原来那一行只有一个 `s`，现在把 `s` 这个元组解包出来，把其中的元素赋值给了这五个变量。下面再操作时，就不用每次都通过索引一个个取了。

### 1.3 两种写法的取舍

| 变量 | 代表的字段 | 方式一取值 | 方式二取值 |
| --- | --- | --- | --- |
| `id` | 学号 | `s[0]` | 解包变量 |
| `name` | 姓名 | `s[1]` | 解包变量 |
| `chinese` | 语文 | `s[2]` | 解包变量 |
| `math` | 数学 | `s[3]` | 解包变量 |
| `english` | 英语 | `s[4]` | 解包变量 |

改完之后右键运行，效果完全一样，这就是元组解包的应用。

> **结论**：两种方式**哪种都可以**，方式二的优势只在可读性——输出时更直观。引出元组解包，是为了让大家知道它在这种场景下怎么用。

## 2. 用解包改写第二个需求

紧接着的第二个需求，我没有替换。原因很直接：那里的代码只需要取其中**一个**元素（第三个元素，也就是索引为 2 的那个）。

真要为了取一个元素去写解包，就得再定义五个变量，反而更麻烦了。

> **易错点**：解包不是「越用越高级」的语法，覆盖不到全部元素时硬解包，只会引入五个用不上的变量。

所以这个需求保持索引写法即可。

---

## 3. 用解包改写第三个需求

再往下那一块属于同一类情况，可以照样用元组解包改写。

```python
for s in students:
    id, name, chinese, math, english = s
    total = chinese + math + english
    print(f'学号是{id}, 姓名是{name}, 总分是{total}')
```

做法就是把已经定义好的那五个变量直接拿到这里，把 `s` 这个元组换掉，再计算就直接写 `chinese + math + english`、`id`、`name`。右键运行，效果同样一样。

```text
   元组 s = ('1001', '王林', 90, 95, 88)
                |      |     |   |   |
                v      v     v   v   v
   解包后    id    name  chinese math english
                |      |     |   |   |
                +------+-----+---+---+--> f-string 输出
```

图意：`s` 里的五个元素按位置一一落到五个变量上，后续代码只跟变量名打交道，不再出现裸下标。
