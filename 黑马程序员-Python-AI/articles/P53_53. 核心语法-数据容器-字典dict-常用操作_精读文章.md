# 字典 dict 的增删改查与遍历

字典这种数据类型的特点我们已经清楚了，接下来要解决的是一件更实际的事：**里面存的那些键值对，怎么操作？**

答案就是数据操作逃不掉的那四件事——增、删、改、查。

## 1 数据结构与数据修改

先把要操作的对象摆清楚，它长这样：

```python
dict1 = {'小智': 90, '李四': 80, '李奇': 70, '小黑': 60, '温涛': 50}
```

五个键值对。要往这个字典里加数据、改数据、删数据、查数据，就分别对应下面四类操作。

## 2 新增与修改数据

### 2.1 语法

新增数据的写法，是字典名后面跟一对方括号，方括号里写指定的 `key`，等号后面指定对应的 `value`：

```python
字典名[key] = value
```

### 2.2 按 key 是否存在判定

比如现在这个字典里没有一个叫 `Tao哥` 的 key，我想增加一个「Tao哥 688 分」的键值对，那就直接这么写：

```python
dict1['Tao哥'] = 688
```

写完你就会发现一件事：**新增和修改的语法是一样的**。

那什么时候是新增、什么时候是修改？判断依据只有一条：看这个 key 在字典里存在不存在。

- key 不存在 → 执行添加操作；
- key 存在 → 执行修改操作。

比如 `小智` 这个 key，在字典里本来是存在的，给它重新赋值，动到的是原来那条数据，也就是修改。

| 指定的 key | 在字典中是否存在 | 实际执行的操作 |
| --- | --- | --- |
| `Tao哥` | 不存在 | 添加一条新键值对 |
| `小智` | 存在 | 修改该 key 原来的 value |

> **结论**：一句话就能背下来——key 不存在就是添加，key 存在就是修改。同一个语法承担两种语义，所以判断完全落在 key 上。

### 2.3 代码演示

先在 PyCharm 里准备一个字典，先把它整个打印出来做对照：

```python
dict1 = {'小智': 90, '李四': 80, '李奇': 70, '小黑': 60, '温涛': 50}
print(dict1)
```

运行后输出的是这四组键值对。

在断点处往下走一步，执行到给 `Tao哥` 赋值那一行。因为字典里原本没有 `Tao哥` 这个 key，所以执行的就是新增，执行完之后字典里多出了 `Tao哥: 550`。

继续往下，此时字典里已经有了 `Tao哥` 这个 key，再给它赋值，执行的就是修改：

```python
dict1['Tao哥'] = 550
dict1['Tao哥'] = 620
```

走完第二步，`Tao哥` 的成绩从 550 分变成了 620 分——从学渣一跃成为学霸。

## 3 删除数据

删除有两条路，效果都是按指定的 key 把整个键值对删掉。

### 3.1 del 关键字

`del` 是我们前面学过的关键字，直接删掉指定的键值对：

```python
del dict1['韩立']
```

删除时只需要指定 key，这个 key 以及它对应的 value，一整个键值对一起被删掉。

### 3.2 pop 方法

另一种方式是调用字典对象提供的 `pop` 方法：

```python
dict1.pop('许利果')
```

`pop` 同样是删除指定的 key，但多做了一件事：**把删掉的那个值返回回来**。执行删除「许利果」时，返回的就是它对应的 580 分。

> **易错点**：`del` 和 `pop` 都能按 key 删除键值对，区别只有一个——`pop` 能拿到被删除的值，`del` 拿不到。需要用到被删掉的那个值，就只能走 `pop`。

删完之后再看字典，「许利果: 580」「韩立: ...」这两个键值对就都没有了。

## 4 查询数据

查询涉及的方法比较多，分两类。

### 4.1 按 key 取 value：方括号与 get

第一种写法是直接写方括号，里面写 key：

```python
print(dict1['Tao哥'])
```

第二种是调用字典对象的 `get` 方法，传入一个 key：

```python
print(dict1.get('Tao哥'))
```

两种方式效果一样，取到的都是 `620`——正是刚才把 `Tao哥` 改上去的那个成绩。

### 4.2 keys、values、items

另外三个方法用来一次性取出一批数据。

`.keys()` 获取字典里所有的 key。以小智、李四、李奇、小黑、温涛这个字典为例，这些 key 都会被取出来，并被封装到一个容器里。封装出来的类型叫做 `dict_keys`，`dict_keys` 代表的就是「所有的 key」，里面装的看起来就像是一个一个元素的列表。

`.values()` 获取所有的 value，封装成 `dict_values` 类型，里面是一个一个的值。

`.items()` 获取所有的键值对。item 翻译过来叫「项」，简单说就是键值对。它封装成 `dict_items` 类型，里面装的是一个一个的键值对。

| 方法 | 取出的内容 | 封装后的类型 |
| --- | --- | --- |
| `keys()` | 所有的 key | `dict_keys` |
| `values()` | 所有的 value | `dict_values` |
| `items()` | 所有的键值对 | `dict_items` |

## 5 遍历字典

字典怎么遍历？方式有多种，因为拿到数据的入口不止一个：能用 `keys()` 拿到所有 key，再遍历这些 key；也能用 `items()` 直接拿到所有键值对。下面三种写法效果完全一致。

### 5.1 按 key 遍历

先拿到所有的 key，再遍历它，就能一个一个拿到 key，然后按 key 取到对应的 value：

```python
for key in dict1.keys():
    print(f'{key}: {dict1[key]}')
```

运行输出：

```text
王林: 670
李慕婉: 608
Tao哥: 620
```

三个键值对都遍历出来了。

### 5.2 按 items 遍历

第二种方式是用 `items()` 拿到所有的键值对，循环变量 `item` 代表其中的一个键值对：

```python
for item in dict1.items():
    print(item)
```

这里的 `item` 里面封装的是一个元组：小括号括起来，第一个元素是 key，第二个元素是 value。所以取第一个元素用方括号加 `0`，取第二个元素用方括号加 `1`：

```python
for item in dict1.items():
    print(item[0], item[1])
```

效果和第一种一样。

### 5.3 解包遍历

既然 `item` 里就是两个元素，那就可以直接解包：写两个变量，一个是 key，一个是 value。循环时，`item` 的第一个元素赋给 key，第二个元素赋给 value，输出这两个变量即可：

```python
for key, value in dict1.items():
    print(f'{key}: {value}')
```

执行结果还是那份数据。同一个字典，多种方式都能遍历输出，活学活用就行。

## 6 小结

这一节要明确的就是两件事：字典增删改查涉及哪些方法，以及字典怎么遍历。

- 添加和修改：语法完全相同，靠 key 在不在字典里来区分。key 不存在就是新增，key 存在就是修改。
- 删除：`del` 关键字，或者 `pop` 方法。区别是 `pop` 能拿到被删除的值，`del` 拿不到。
- 查询：可以按 key 取 value，也可以取出所有的 key、所有的 value、所有的键值对。
- 遍历：用 `for` 循环即可——先用 `keys()`、`values()` 或 `items()` 拿到数据，再用 `for` 循环遍历拿到的这些数据。
