# 集合 set 的特点、定义与常用操作

前面三种数据容器——列表、字符串、元组——已经学完了。接下来是第四种：`set` 集合。

列表、元组、集合都能存多项数据，那我为什么还要再学一个集合？它到底解决什么问题？

## 1. 集合的应用场景

假设我在做业务系统开发，现在需要定义一个变量，存储一批用户的手机号。

手机号、身份证号、银行卡号这类信息，会不会重复？不会重复。

那问题来了：这种数据能不能用列表或者元组来存？

不能。因为列表和元组里**可以存重复元素**——用它俩来存手机号，里面就可能出现重复的手机号、重复的身份证号、重复的银行卡号，这就不满足需求了。

这种场景就该用 `set` 集合来存。集合会自动去重：即使你往里面存了重复的元素，它也会自动去掉，不会存在重复元素。

> **结论**：需要存储一批**不重复、唯一**的数据时，就用 `set` 集合。

集合这块我们分两部分讲：先讲基本操作，再一起完成一个案例。

## 2. 集合的三个特点

> **定义**：`set` 集合是一种**无序的、不可重复的、可修改的**数据容器。一句话就描述了它的三个特点。

### 2.1 无序

集合是无序的，没有顺序。这一点跟前三种数据容器都不一样——列表、元组、字符串都是有序的。

有序的容器可以通过索引访问指定元素，集合无序，那就**没法通过索引访问元素**。

> **易错点**：不要依赖控制台打印出来的顺序。它这次是 `0 64 2 3 5`，下次可能是别的次序，那不是 bug。

### 2.2 不可重复

集合里存储的元素不会重复，即使存了重复元素，它也会自动去重。

### 2.3 可修改

集合里的元素是可以修改的：我们可以往集合里添加元素，也可以从集合里删除元素。

## 3. 集合的定义

定义集合用的符号是**花括号（大括号）**。回头看前面的容器：列表用方括号，元组用小括号，集合用大括号。括号里罗列一个个元素，元素之间用逗号分割。

```python
s1 = {5, 3, 2, 0, 9, 12, 43, 64, 22, 5, 0}
print(s1)
print(type(s1))
```

我在里面专门存了两个 `5`、两个 `0`，就是要看它能不能自动去重。右键运行，输出是这样的：

```text
{0, 64, 2, 3, 5, 9, 12, 43, 22}
<class 'set'>
```

两点对上了：定义时写的是 `5 3 2 0 9 …`，输出却从 `0` 开始——没有顺序；定义了两个 `5`、两个 `0`，输出里只剩一个 `0`、一个 `5`——自动去重。类型输出为 `set`，说明定义出来的确实是集合。

### 3.1 空集合的写法

要定义空集合，就得注意了：这里需要调用 `set()` 这个语句，它本身是个函数，直接调用 `set()` 就能定义一个空集合。

> **易错点**：空大括号定义出来的**不是集合，而是字典**。字典是最后一种数据容器，后面会讲。所以空集合不可以用大括号来定义。

```python
s2 = set()
print(s2)
print(type(s2))
```

输出就是 `set()`：

```text
set()
<class 'set'>
```

空集合打印出来是 `set()`，而不是那个空花括号，再强调一次。

### 3.2 不支持索引访问

因为集合无序，所以它不支持索引访问。这跟列表、元组、字符串都不一样。

## 4. 集合的常用方法

集合常用的方法主要列了七个，先快速过一遍它们的语义。

| 方法 | 作用 | 备注 |
| --- | --- | --- |
| `add` | 添加元素 | 往集合里加一个元素 |
| `remove` | 删除指定元素 | 元素不存在时会报错 |
| `pop` | 随机删除一个元素并返回 | 不能指定索引，因为无序 |
| `clear` | 清空集合 | 清空后留下一个空集合 |
| `difference` | 求两个集合的差集 | 结果与前后顺序有关 |
| `union` | 求两个集合的并集 | 结果与前后顺序无关 |
| `intersection` | 求两个集合的交集 | 结果与前后顺序无关 |

### 4.1 add、remove、pop、clear 的实测

我打上断点一步步 Debug，每个方法走一步看一眼集合的变化。

```python
s1 = {100, 200, 300, 400, 500, 600, 700, 800}
print(s1)

s1.add(1200)
print(s1)

s1.remove(200)
print(s1)

e = s1.pop()
print('本次删掉的是:', e)
print(s1)

s1.clear()
print(s1)
```

逐个看效果：

- `add`：添加 `1200`。往下走一步，`1200` 落在了 `400` 到 `500` 之间——因为无序，它就会插在这个位置。
- `remove`：删除指定的 `200`。再输出一次，`200` 没了。注意，如果这个元素不存在，`remove` 将会报错。
- `pop`：随机删除集合中的元素并返回。不一定删谁，随机删的；删除的元素会返回回来，用一个变量就能接住。这一次删掉的是 `800`。
- `clear`：清空集合。清空之后集合里没有元素了。空集合的表示方式就是 `set()`，不是那个空花括号。

### 4.2 差集、并集、交集

剩下这三个方法是针对**两个集合**做运算的，涉及的是初中数学里的概念。

假设这是 `s1`，这是 `s2`，两个集合中间有一部分是**重叠**的：重叠的部分叫交集；包含在第一个集合、但不包含在第二个集合里的元素叫差集；两个集合的全部元素加在一起叫并集。

```text
       s1                          s2
  ┌─────────────┐             ┌─────────────┐
  │   a   b     │             │             │
  │         ┌───┼─────────────┼───┐         │
  │      d  │ x │   c     e   │ y │   z     │
  │         └───┼─────────────┼───┘         │
  │             │             │             │
  └─────────────┘             └─────────────┘
                └─ 交集：两个集合共有的元素

  差集 s1 - s2：在 s1 中、不在 s2 中     差集 s2 - s1：在 s2 中、不在 s1 中
  并集 s1 | s2：整个区域，包含共有部分
```

图意：中间重叠部分是交集；只在左边一侧出现的是 `s1 - s2` 的差集，只在右边一侧出现的是 `s2 - s1` 的差集；把整个区域合起来就是并集。

求差集调用的是 `difference`，写成 `s1.difference(s2)`，含义是「包含在第一个集合当中、但不包含在第二个集合当中的元素」。

```python
s2 = {'a', 'b', 'd', 'x'}
s3 = {'c', 'e', 'y', 'z'}

print(s2.difference(s3))
print(s3.difference(s2))
print(s2.union(s3))
print(s3.union(s2))
print(s2.intersection(s3))
```

结果如下：

```text
{'a', 'b', 'd', 'x'}        # s2.difference(s3)：只在 s2 中
{'z'}                       # s3.difference(s2)：只在 s3 中
{'a', 'b', 'd', 'x', 'c', 'e', 'y', 'z'}   # 并集
{'a', 'b', 'd', 'x', 'c', 'e', 'y', 'z'}   # 并集，前后调换结果相同
{'c', 'e', 'y'}             # 交集
```

差集是有方向的：`s2` 在前、`s3` 在后，求的是「在 `s2` 中有、在 `s3` 中没有」的元素，结果是 `a b d x`；反过来把 `s3` 放前面，结果就变成 `z`。

并集和交集则跟顺序无关。并集我特意输出了两次，把 `s2`、`s3` 前后调换，结果一样；交集也再输出一次对比，两次内容一致。

> **结论**：差集区分前后顺序，并集和交集不区分。

### 4.3 可修改性的验证

跑完这些方法，也就验证了集合的第三个特点：它确实可以修改——能往里加元素，也能从里面删元素。

## 5. 小结与练习

回来明确两个问题。

一是集合的特点：**无序、不可重复、可修改**。因为它无序，操作时就不要依赖控制台输出的顺序。

二是集合的定义与常见操作。定义用大括号把元素括起来，多个元素之间逗号分割；要定义空的集合，不能直接写花括号，得写 `set()`，直接调用这个语句定义出来的才是空集合。常用方法分三类：添加是 `add`；删除是 `remove`、`pop`、`clear`；集合运算是求交集、并集、差集。

最后，集合的应用场景就是存储不会重复、唯一的数据——手机号、银行卡号、身份证号，还有学号，都可以用集合来存。
