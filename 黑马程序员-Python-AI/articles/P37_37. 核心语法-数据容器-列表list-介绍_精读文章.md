# Python 列表 list 的定义、索引与增删改查

数据容器我们前面已经见过一个轮廓，现在要正式进入第一类。先说说为什么第一步就挑它：程序里迟早会遇到"一批数据"，比如一次录入的十个数、一个班的成绩、一串商品名。如果每份数据都单独起一个变量名，变量会多到自己都记不住，而列表就是把这些数据装进同一个容器里一起管理的那种数据类型。

## 1. 什么是列表

列表（list）就是数据容器当中的一种。数据容器有很多，列表只是其中之一，它最直接的价值是可以一次性存储多个数据，而里面存进去的每一项数据，我们都称之为一个元素。

后面对列表的学习会分三块推进：先认识什么是列表、列表怎么定义、有哪些特点；再讲列表提供的常见方法；最后用一个案例把理解落到实处。这篇只把第一块讲透。

### 1.1 定义语法

定义列表的语法，前半截是列表名称（本质上就是一个变量名），后半截是为这个变量赋值，赋的值就是一个列表。

列表用方括号括起来——注意，两侧都是方括号。方括号当中罗列这个列表要存储哪些数据，每两项数据之间用逗号分隔。

```python
s = [54, 15, 75, 108, 23, 78, 75]
```

这里的 `s` 就是列表名称，右侧方括号里是列表的值，里面存了七个元素：54、15、75、108、23、78、75，每两个元素之间逗号分割。

```text
列表名称  赋值号   方括号开始            逗号分隔每一项元素            方括号结束
   |         |          |                        |                        |
   s     =   [     54 , 15 , 75 , 108 , 23 , 78 , 75    ]
                    |                                  |
              第 1 项元素                          第 7 项元素
```

读这张图只看三处标记：等号左边是变量名，方括号划定了列表的边界，逗号是元素之间的分隔符。只要这三处语法写对，列表就能一次装下多个数据。

### 1.2 列表的三个特点

列表的特点归纳起来是三条。

第一，它可以存储不同类型的元素。上面那个案例存的都是相同类型，全是 int，但对列表来说这不是限制：一个列表当中可以存 int 类型的数值、float 类型的浮点数、string 类型的字符串、bool 类型的布尔值，都可以，都没有限制。

> **提示**：语法层面列表允许混装类型，但真正在项目里存储数据时，一个列表基本上存的是同一类型的数据。类型统一，后面排序、求和这类操作才有意义。

第二，列表的元素是有序的，也是可以重复的。所谓有序，是指定义的时候元素是什么顺序，存储的时候就按什么顺序存，最终我们操作列表里的元素时也可以按指定的顺序去操作。所谓可以重复，是指列表当中允许存在重复的元素——上面那个列表里的 75 就出现了两次，这是合法的。

第三，元素是可以修改的。比如把列表中的 108 改成 208，可以直接改，因为我们能指定要修改的是哪一个元素。

> **结论**：列表 = 可一次性存多个数据 + 元素有顺序 + 元素可重复 + 元素可修改。这三条特点正是它和后面元组、集合、字典的区别所在。

## 2. 索引与元素访问

一个列表里那么多元素，要操作或修改其中某一个，怎么告诉 Python 你要动的是哪一个？列表会给每一个元素都定义一个索引，也叫下标，用索引就能精确指定要操作的元素。

正向索引从 0 开始：头部的第一个元素下标是 0，第二个元素下标是 1，第三个元素下标是 2，依次类推。操作列表元素时，把索引写进方括号即可。

```python
s = [54, 15, 75, 108, 23, 78, 75]

print(s[0])   # 第一个元素  54
print(s[1])   # 第二个元素  15
print(s[2])   # 第三个元素  75
```

> **易错点**：索引从 0 开始，所以"第 n 个元素"的索引是 n - 1，不是 n。`s[0]` 才是第一个元素。

Python 针对列表索引还提供了另一种写法：反向索引，从列表的最后一个元素开始编号。最后一个元素的反向索引是 -1，倒数第二个是 -2，倒数第三个是 -3，倒数第四个是 -4。

```python
print(s[-1])   # 最后一个元素
print(s[-2])   # 倒数第二个元素
print(s[-3])   # 倒数第三个元素
```

> **提示**：索引只要写成负数，就代表它是反向索引。`-1` 永远指向最后一个元素，不需要先去数列表有几个元素，这一点在长度不确定时特别好用。

把两种索引并排看，就是同一批元素的两种编号方式：

```text
元素            54     15     75    108     23     78     75
正向索引         0      1      2      3      4      5      6
反向索引        -7     -6     -5     -4     -3     -2     -1
```

读图从两端往中间看：正向索引从左边头部开始编号，反向索引从右边尾部开始编号，同一个元素有两个索引值，取哪个都指向同一个元素。

这两种索引都有名称：一种是从列表头部到尾部的正向索引，索引值从 0 开始；另一种是从尾部到头部的反向索引，索引值从 -1 开始。

Python 把"元素有序、并且可以通过索引访问元素"的容器称为序列类型（sequence），而列表就是序列的一种：它的元素有顺序，元素又可以通过索引访问，所以列表属于序列类型。

> **定义**：序列类型指的是元素有序、且可以通过索引访问其中元素的数据容器类型。列表是序列类型的一种，后面要学的字符串、元组同样是序列类型。

## 3. 运行演示：定义列表与查看类型

打开 PyCharm 走一遍最基础的操作。先定义列表：用一个方括号把元素括起来，方括号当中一个元素一个元素地写。

```python
s = [56, 90, 88, 65, 90, "a", "hello", True]
```

这里故意把类型混着放：56、90、88、65、90 是 int，`"a"` 和 `"hello"` 是字符串，`True` 是布尔值。既然列表可以存储不同的数据类型，这么写就没有问题。

> **易错点**：如果只写 `[56, 90, 88]` 而不赋值给任何变量，编辑器会给这行加一个黄色背景，悬浮提示的意思是"这条语句似乎不起任何作用"。原因很简单——这个列表定义出来没人用。想操作它，就得用一个变量把它接收下来，于是写成 `s = [...]`。

定义好之后可以确认它的类型：

```python
print(type(s))
```

运行结果是 `list`。

> **结论**：列表的数据类型就是 list 类型。用 `type()` 查看变量当前所存数据的类型，得到的输出就是这一类型。

## 4. 获取、修改与删除元素

对列表元素的访问分三种动作：获取、修改、删除。

### 4.1 获取元素

获取元素直接通过索引。拿第一个元素（56）来说，两种索引都指向它：

```python
print(s[0])    # 正向索引：0 就是第一个元素，输出 56
print(s[-8])   # 反向索引：从 -1 数到 -8，同样是第一个元素，输出 56
```

这个列表一共八个元素，所以反向索引从 -1 一路排到 -8。运行后两个 print 都输出 56，说明正向、反向两种方式都能拿到同一个元素。

再取第三个元素（88）：正向索引数过来是 `s[2]`，反向索引从尾部数是 `s[-6]`。

```python
print(s[2])    # 88
print(s[-6])   # 88
```

> **提示**：写反向索引之前先在纸上（或在列表上）从右往左数一遍编号，比心算更稳。元素个数一变，同一个元素的反向索引就会变，正向索引不会。

### 4.2 修改元素

修改元素的做法是：先根据索引定位到那个元素，再为它重新赋值。

想把 `"a"` 改成 `"ABC"`。`"a"` 前面有五个元素，所以它是第六个元素；索引从 0 开始，第六个元素的索引就是 5。

```python
s[5] = "ABC"
print(s)
```

运行后输出整个列表，第六个位置的元素确实变成了 `"ABC"`。因为列表的元素可以修改，直接为指定索引位置的元素赋一个新值，这个位置的元素就被替换掉了。

> **易错点**：如果指定的索引超出列表范围，就会报错。比如给 `s[10]` 赋值，编译器运行时报 `list index out of range`，含义是列表分配的索引已经超出范围。索引必须落在列表真实的索引区间内。

### 4.3 删除元素

删除列表当中指定的元素需要用到关键字 `del`，它是一个删除关键字，`del` 就是 delete 的简写。用法是 `del` 加上要删除的元素，元素仍然通过索引指定。

```python
del s[6]
```

`"hello"` 前面有六个元素，它是第七个元素，索引为 6，所以 `del s[6]` 删掉的就是它。删除后再把整个列表输出一遍，`"hello"` 已经不在了。

```text
s[0]  s[1]  s[2]  s[3]  s[4]  s[5]   s[6]     s[7]
 56    90    88    65    90   "ABC"  "hello"   True
                                      |
                                 del s[6] 删除
```

读图看删除的落点：`del` 后面跟的是索引，索引指向哪个位置，删掉的就是哪个元素，与元素的值无关。

## 5. 用 for 循环验证列表的有序性

前面演示下来，列表确实可以存储不同类型元素，元素也可以重复、可以被修改，而且是有序的。有序这一点怎么验证？

最直接的证据是输出顺序：存进去是什么顺序，输出出来就是什么顺序。更彻底的验证是把元素挨个取出来，一个一个地打印，这就要用到前面学过的 for 循环——for 循环本来就是用来遍历数据集的，列表当然也可以用 for 遍历。

```python
s = [56, 90, 88, 65, 90, "ABC", True]

for item in s:
    print(item)
```

`in` 后面跟的 `s` 就是要遍历的数据集（也就是我们定义的这个列表）；`item` 是一个变量，变量名叫什么都可以，它代表每一次遍历出来的那个元素。把 `item` 直接打印出来，运行结果依次是 `56`、`90`、`88`、`65`、`90`、`ABC`、`True`，和我们存储的顺序完全一致。

> **结论**：列表是有序的，这个"有序"可以用 for 循环遍历输出的顺序来验证。想遍历列表里的每一个元素，直接用 for 循环即可。

## 6. 三个需要明确的结论

列表这一部分有三个问题需要明确。

第一，列表的定义方式：多个元素使用中括号（方括号）括起来，多个元素之间用逗号分割。

第二，列表的索引：一类是从列表头部到尾部的正向索引，从 0 开始；另一类是从尾部到头部的反向索引，从 -1 开始。

第三，列表元素的获取、修改与删除：查看就直接写列表名，方括号里写对应元素的索引；修改就为指定元素重新赋一个值，列表里指定位置的元素就被改掉；删除用关键字 `del`，删掉列表当中指定位置的元素。

外加一条必须记住的注意事项：指定列表的索引或下标时不能超出列表的索引范围，一旦超出就会报错。
