# Python 列表案例：用户输入十个数字的最小值、最大值与平均值

列表是什么、有哪些常见方法都已经讲完了。这时候需要一个案例把这些东西串起来用一遍，看它们在真实需求里怎么落地。

## 1. 案例需求

需求是这样的：让用户输入 10 个数字，把这 10 个数字存入一个列表，然后对列表当中的数字进行排序；排序之后，输出其中的最小值、最大值以及平均值。

拆开看，这里面藏着四处以前学过的东西：

- 用户要输入 10 个数字，也就是同一个动作要重复执行 10 次；
- 10 个数字要装进同一个容器，容器就是列表；
- 排序要靠列表的方法；
- 最小值、最大值、平均值要从排好序的列表里算出来。

> **提示**：重复性地去执行一个操作，就该用循环。这里循环次数是固定的 10 次，所以直接用 for 循环就够，不必用 while。

## 2. 四步实现

### 2.1 第一步：定义空列表

既然 10 个数字要存储到一个列表当中，先定义一个列表。这个列表叫 `number_list`——两个单词之间用下划线分割。

```python
number_list = []
```

目前它里面没有元素，因为元素需要用户一个一个录入。空列表的定义方式很直接：一对中括号，里面什么元素都不写。

> **提示**：有元素的列表是"中括号里面写上对应的元素"，空列表就是"一对空的中括号"。这两种写法是同一个语法，区别只在括号里有没有内容。

### 2.2 第二步：把用户输入的 10 个数字存入列表

这一步要执行 10 次 `input` 语句，让用户输入数字并接收录入的结果。重复执行固定次数，用 for 循环，循环 10 次就写 `range(10)`，它会生成一个含 10 个元素的数字序列供循环使用。

```python
for i in range(10):
    number = input("请输入一个有效的数字：")
    number = int(number)
    number_list.append(number)
```

循环体里做了三件事：

1. `input` 接收用户输入的数据，提示信息是"请输入一个有效的数字"；
2. 由于输入内容是数字，当前认为是整型，所以用 `int` 把它转换成整型——`input` 接收到的其实是字符串，不转换的话存进列表的就是字符串；
3. 往列表里添加元素，调用的是列表的 `append` 方法，把 `number` 追加进去。

经过 10 次循环，10 个数字就都存进了 `number_list`。循环结束之后可以把整个列表输出出来看一眼：

```python
print("数字列表：", number_list)
```

### 2.3 第三步：对列表排序

排序要调用 list 列表当中的一个方法，叫做 `sort`。

```python
number_list.sort()
print("排序后的数字列表：", number_list)
```

`sort` 方法就是进行排序操作，默认从小到大。排完序之后输出一遍便于观察和测试。

### 2.4 第四步：输出最小值、最大值与平均值

既然第三步已经把数字列表排好序，那么列表当中的第一个元素就是最小值，最后一个元素就是最大值。

```python
print("最小值：", number_list[0])
print("最大值：", number_list[-1])
```

最小值直接取索引 0。最大值取最后一个元素：这个列表一共 10 个元素，最后一个元素的索引就是 9——因为索引从 0 开始。也可以不去数，直接写 -1 就是最后一个元素。

平均值的算法是：把列表当中所有的元素加起来求和，再除以列表元素的个数。

> **结论**：平均值 = 所有元素之和 ÷ 元素个数。这里个数是 10，所以除以 10。

求和这件事可以自己循环遍历列表累加，也可以直接用 Python 提供的 `sum`。`sum` 本质是一个函数，后面会专门讲，它会对传入进来的列表当中所有元素进行累加操作，累加就是求和。

```python
total = sum(number_list)
count = len(number_list)
print("平均值：", total / count)
```

求元素个数用的是另一个语句 `len`。`len` 代表 length，就是长度，把 `number_list` 直接传进去就得到列表当中元素的个数，或者说列表的长度。

```python
print("平均值：", sum(number_list) / len(number_list))
```

这里的写法值得留意：分母用的是 `len(number_list)` 而不是硬写的 10。个数由列表自己报出来，需求变化时这一行不必再改。

```text
                     number_list
                          |
        +-----------------+------------------+
        |                 |                  |
   number_list[0]    number_list[-1]    全量元素
        |                 |                  |
      最小值            最大值        sum() 求和  →  ÷ len() 个数
                                             |
                                          平均值
```

读图看三条取值路径：两端各取一个元素得到最小值和最大值，整份列表走 `sum` 与 `len` 得到平均值。三条路径都以"已经排好序"为共同前提。

## 3. 运行测试

直接运行，程序开始循环，提示"请输入一个有效的数字"，接着要连续输入 10 个数字。这几个数字会被依次存进 `number_list`。

输入测试数据：56、45、76、23、43、65、109、232、232、65。

10 个数字输入完毕之后，列表里就存好了这 10 个数字。走到第三步，列表执行了排序操作，元素按照从小到大的顺序排好了。

第四步取排序后列表的第一个元素，得到最小值；取最后一个元素，得到最大值；再对列表里这 10 个元素用 `sum` 求和、用 `len` 取元素个数，两个一除就得到平均值 94.6。

```text
输入:   56   45   76   23   43   65  109  232  232   65
排序后: 23   43   45   56   65   65   76  109  232  232
        ^                                        ^
     最小值 23                                最大值 232
求和: 23+43+45+56+65+65+76+109+232+232 = 946
平均值: 946 / 10 = 94.6
```

读图顺着流程走一遍：输入顺序是乱的，排序把它整理成递增序列，两端的元素直接就是最小值与最大值，中间的和再除以个数得到平均值。

这个案例把列表的定义和常见方法的应用都用上了：定义空列表、用 `append` 往里加元素、用 `sort` 排序、用索引取值。

## 4. 数据统计相关的四个语句

案例里用到了两个语句：`sum` 用来求和，`len` 用来获取列表当中元素的个数。

除此之外，Python 还提供了另外两个语句分别用来获取最小值和最大值，一个是 `min`，一个是 `max`。这个案例里没有用到它们，但顺手认识一下：

| 语句 | 作用 | 传入 | 返回 |
| --- | --- | --- | --- |
| `sum` | 求和 | 列表 | 所有元素累加的结果 |
| `len` | 获取元素个数（列表长度） | 列表 | 元素个数 |
| `min` | 获取最小值 | 列表 | 最小的那个元素 |
| `max` | 获取最大值 | 列表 | 最大的那个元素 |

> **提示**：案例里的最小值和最大值是用索引取的（`number_list[0]` 与 `number_list[-1]`），这依赖列表已经排好序；`min` 与 `max` 不依赖排序，直接给列表就能拿到最大最小。两条路都能走通，选用哪条看场景。

## 5. 实现要点归纳

案例的四步是固定的：定义列表、循环录入 10 个数字存入列表、排序、输出最小值最大值和平均值。

实现上的关键点只有三处：循环次数固定所以用 for 配 `range(10)`；往列表里加元素用 `append`；排序用 `sort`，排好序之后两端就是最小值和最大值，平均值用 `sum` 除以 `len`。

这个案例可以自己独立实现一遍，把这几处关键点敲熟。
