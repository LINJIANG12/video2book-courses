# 集合运算与集合推导式：四道选课统计需求

基本操作学完之后，我们用案例再走一遍集合。这一节要解决的需求，来自一份班级学生的选课情况。

数据是四个集合，分别记录选修足球、篮球、法语、艺术的学生名单：

```python
Football_set = {'天运子', '韩立', '厉飞雨', '紫灵', '遁天', '徐笠果', '乌醜', '江老道', '虎刨', '红蝶'}
Basketball_set = {'天运子', '韩立', '厉飞雨', '江老道', '虎刨', '红蝶'}
French_set = {'天运子', '韩立', '江老道', '虎刨', '王林', '李慕婉'}
Arts_set = {'天运子', '韩立', '江老道', '虎刨', '紫灵', '遁天'}
```

> **提示**：这些基础数据在配套课程讲义里也提供了，在讲义最后一栏「课程案例数据」里可以直接复制，当然也可以自己构造一组。

需求一共四个：找出同时选修了法语和艺术的学生；找出同时选修了所有四门课程的学生；找出选修了足球但没有选修篮球的学生；统计每一个学生选修课程的数量。

## 1. 需求一：同时选修法语与艺术

既选修了法语、又选修了艺术，那关联的就是法语和艺术这两个集合。要求的元素是这两个集合共有的那部分，也就是**交集**。

上一节讲过集合的三种运算：并集、交集、差集。求交集对应的方法是 `intersection`，把第二个集合传进去即可。

```python
# 方式一：调用 intersection 方法求交集
fa_set = French_set.intersection(Arts_set)
print(f'同时选修了法语和艺术的课程的学生是: {fa_set}')
```

拿到交集之后用一个变量接收，变量名就叫 `fa_set`——`fa` 是 `French` 和 `Arts` 两个单词的首字母简写。输出用的是格式化字符串，前面加上 `f`。

为了跟方式二对比，这个方式二不覆盖原来的值，另起一个变量：

```python
# 方式二：使用 & 运算符求交集
fa_set2 = French_set & Arts_set
print(f'同时选修了法语和艺术的课程的学生是: {fa_set2}')
```

方式二也是求交集，只是写法略有差异：在 Python 里，集合求交集可以直接用一个**运算符**，这个运算符叫 **and 符**，也就是键盘上数字 `7` 上面的那个符号，读作「与」。

> **易错点**：这个符号在编辑器里因为字体原因会显示得很像 `and` 三个字母，它并不是关键字 `and`，而是 `&`。也可以通过复制代码的方式确认它到底是什么字符。

```text
&    求交集（与）
|    求并集（竖线）
-    求差集（减号）
```

> **提示**：`|` 是**竖线**，不是斜杠。因为写在注释里会跟着注释一起倾斜，容易看错。

两种方式运行结果一模一样，同时选修法语和艺术的学生有四个：江老道、韩立、天运子、虎刨。逐个对上，这四个人在两份名单里都出现了。

```text
同时选修了法语和艺术的课程的学生是: {'天运子', '韩立', '江老道', '虎刨'}
```

> **结论**：下面那种写法明显更简洁。

## 2. 需求二：同时选修四门课程

四门课程都选了，那求的就是这四个集合的交集。这次直接使用「与」符号把四个集合串起来。

```python
# 求四个集合的交集
all_set = Football_set & Basketball_set & French_set & Arts_set
print(f'同时选修了四门课程的学生是: {all_set}')
```

第一种写法是调用方法，比如 `Football_set.intersection(Basketball_set)` 得到一个结果集合，再继续往后 `.intersection(French_set)`、`.intersection(Arts_set)`，这样写也没问题；第二种就是现在这样直接用运算符。这里我用了运算符。

```text
Football  ∩  Basketball  ∩  French  ∩  Arts
   │            │            │         │
   └────────────┴────────────┴─────────┘
                    │
                    v
          同时选修四门课程的学生
```

图意：四个集合逐层求交集，最后剩下的元素必须在四份名单里都存在。

运行结果是两位：天运子和韩立。验证的办法很直接——在编辑器里双击「天运子」这个学生名字，四个集合里是不是都高亮选中了？是的；再双击「韩立」，四门课程同样都选了。看其他的学生，都没有把四门课程全选中，结果没问题。

## 3. 需求三：选修足球但没选篮球

这个需求说的是：在足球的集合当中存在，但是在篮球的集合当中**不存在**。这正是集合的差集能解决的场景。差集同样有多种方式。

### 3.1 方式一：difference 方法

```python
# 方式一：调用 difference 方法求差集
fb_set = Football_set.difference(Basketball_set)
print(f'选修了足球但没有选修篮球的学生是: {fb_set}')
```

求差集要调用的方法是 `difference`，后面把 `Basketball_set` 传进去——这是选修篮球课程的学生名单。运算结果就是在第一个集合中存在、但在第二个集合中不存在的学生。

结果是四个元素：紫灵、遁天、徐笠果、乌醜。逐个验证：紫灵选的是足球，在篮球名单里没有；遁天没有；徐笠果没有；乌醜也没有。而像厉飞雨、天运子这些学生，既选了足球又选了篮球，所以不会出现在差集里。

### 3.2 方式二：减号运算符

差集也有简化的运算符写法，那就是**减号**。

```python
# 方式二：使用 - 运算符求差集
fb_set2 = Football_set - Basketball_set
print(f'选修了足球但没有选修篮球的学生是: {fb_set2}')
```

不用再调方法，一个运算符就解决：`Football_set - Basketball_set`，求取的就是在 `Football_set` 中存在、在 `Basketball_set` 中不存在的元素。右键运行，两个结果一模一样。

### 3.3 方式三：集合推导式

这个需求还有第三种方式——用**集合推导式**实现。

这个名字应该似曾相识：讲列表的时候我们讲过列表推导式，而集合推导式是用来**快速构建一个集合**的。

先看语法：它构建的是一个集合，所以外层是一对大括号；里面可以做正常的循环操作；如果要加条件判断，就在后面接 `if` 带上条件，只有条件成立，才会把这个数据加入到集合当中。

```python
# 方式三：集合推导式
fb_set3 = {s for s in Football_set if s not in Basketball_set}
print(f'选修了足球但没有选修篮球的学生是: {fb_set3}')
```

一步一步拆开看。最终要构造的集合，里存的元素是「在 `Football_set` 中存在、但在 `Basketball_set` 中不存在的」学生，所以先写 `for s in Football_set`，把足球集合里的元素循环出来。

那集合里要存的是什么？后面加条件判断：判断一个元素在某个集合里是否存在，用的是前面讲过的 `in` 操作符，集合同样适用，所以写 `s in Basketball_set`。

但这样写的含义是「在 `Football_set` 中存在（`s` 本来就是从它里面遍历出来的），并且在 `Basketball_set` 中也存在」——因为 `in` 判断元素是否存在，存在就返回 `True`。而我们要的恰恰是**不存在**，所以在前面加上 `not`，写成 `if s not in Basketball_set`。符合这个条件的，就把遍历出来的 `s`（学生名字）加入集合，所以「要添加的元素」就是 `s`。

```text
{   s            for s in Football_set        if s not in Basketball_set   }
    │             │                              │
    │             │                              └─ 过滤：不在篮球名单里
    │             └─ 循环：从足球名单里逐个取出
    └─ 往新集合里放的元素
```

图意：大括号内的三个部分依次是「放什么元素」「从哪里取」「满足什么条件」。

三种方式的结果完全一致。

> **结论**：就这个需求来说，**第二种方式最简单**——`Football_set - Basketball_set` 一行就够。

## 4. 需求四：统计每人选修的课程数量

最后一个需求要统计每一个学生选修了多少门课程，然后把数量输出出来。

已知条件就是那四个集合。要算每个学生选了几门课，得先想清楚两件事：能不能先拿到所有学生的名单？怎么知道某个名字出现了多少次？

### 4.1 第一步：求四个集合的并集拿到名单

所有学生的名单，等于这四个集合的并集——并集之后会自动去重，正好就是一份不重复的名单。

```python
# 方式一：调用 union 方法求并集
all_set = Football_set.union(Basketball_set).union(French_set).union(Arts_set)

# 方式二：使用 | 运算符求并集
all_set = Football_set | Basketball_set | French_set | Arts_set

print(f'所有学生的名单是: {all_set}')
```

`union` 就是求并集的方法，`Football_set.union(Basketball_set)` 先得到一个新集合，后面继续 `.union(French_set)`、`.union(Arts_set)`，这样写没问题。

当然还有简化写法：既然求交集、差集都有对应的运算符，求并集也有——就是**竖线** `|`。写成四个集合用竖线串起来，求的就是这四个集合的并集。

输出验证，学生名单拿到了，而且一定是去重之后的结果——并集运算得到的结果本身也是一个 `set` 集合，会自动去重。

### 4.2 第二步：用一个列表统计出现次数

`all_set` 已经是去重后的结果，可它只给出了名单，我并不知道某个学生的名字出现了多少次。要知道每个学生选了几门课，就得知道这个名字在四个集合当中一共出现过几次。

问题在于：集合里不允许存在重复元素。那反过来想，谁的里面**可以**存在重复元素？列表。

所以再定义一个列表 `all_list`，用来存储所有学生选课的记录——把四个集合里的数据汇总到这一个列表里。

```python
all_list = [*Football_set, *Basketball_set, *French_set, *Arts_set]
```

这里在四个集合前面各加了一个星号。这是**解包**语法：把集合一个个拆开，把里面的元素一个个取出来，再合并到列表当中。这样合并出来的列表里就允许存在重复元素了。

```text
Football_set     Basketball_set     French_set     Arts_set
     │                  │               │             │
     └── * 解包 ────────┴───────────────┴─────────────┘
                          │
                          v
      all_list = [名字, 名字, 名字, ...]   ← 同一名字会重复出现
```

图意：星号把每个集合的元素摊平，全部塞进同一个列表，重复的名字在这里被完整保留下来。

### 4.3 第三步：循环名单并统计

有了名单和完整记录，就可以循环 `all_set` 拿到每一个学生的名字，再输出他选了几门课。

```python
for s in all_set:
    print(f'{s} 选修了 {all_list.count(s)} 门课程')
```

某个学生具体选了多少门课，就看 `all_list` 当中这个名字出现了多少次。列表里统计元素出现次数的方法是 `count`，把 `s` 传进去，它就会去统计这个学生的名字在 `all_list` 里出现了几次——出现几次，就代表选了几门课程。

运行效果：红蝶选修了一门课程，天运子选修了四门课程，紫灵选修了两门课程，每个学生的选课数量都输出了。

```text
红蝶 选修了 1 门课程
天运子 选修了 4 门课程
紫灵 选修了 2 门课程
...
```

> **提示**：结果对不对可以这样验证——在编辑器里双击某个名字，看它在四个集合里被选中几次。红蝶只有一个选中，天运子有四个，紫灵有两个，跟输出的数字完全对应，说明统计逻辑没问题。

## 5. 小结与练习

这个案例里涉及两块新知识。

第一块是集合运算的运算符：`&`（与）求交集，`|`（竖线）求并集，`-`（减号）求差集。

第二块是集合推导式的写法。集合推导式和列表推导式的语法结构完全一致，唯一的区别就是外层括号不一样——列表用方括号，集合用大括号。

```text
                     求交集      求并集      求差集
运算符                 &           |           -
方法                intersection  union    difference
顺序是否影响结果        否          否          是
```

> **结论**：如果这几个需求你都能独立完成，集合这块的内容就算掌握了。掌握之后，就可以进入最后一种数据容器的学习——字典。
