# 用 PyCharm 创建项目并写出第一个 Python 程序

Python 解释器和 PyCharm 都装好、测通了，环境准备这一关就算过完。接下来就用 PyCharm 亲手写出第一个 Python 程序——顺便把这款工具的基本用法摸一遍。

整个操作只有两步：**第一步打开 PyCharm、创建一个项目；第二步在项目里创建一个 Python 文件，然后在文件里写代码。**

## 创建 Python 项目

### 新建项目时需要填写的信息

打开 PyCharm，聚焦到第一栏的项目菜单，点击中间的「新建项目」，弹出新建项目页面。这个页面上要填的信息不多，一项一项看。

**第一项：项目的存放位置。** 项目里会存放很多 Python 文件和代码，这些文件最终是落在磁盘上的，所以这一项指定的就是项目放在磁盘的哪个目录里。C 盘、D 盘下的某个文件夹都可以，最后那一级文件夹就是项目的名字——路径和名字都可以按自己的需要定义。

我把它放在 D 盘下而不是默认的 C 盘：在 D 盘根目录下新建一个文件夹 `python_project`，把项目放在这里面。以后可能会创建很多个 Python 项目，那就统一都放在这个文件夹下。选定文件夹之后，再在末尾指定项目名 `py_project01`。

**第二项：解释器类型。** 保持默认的「项目 venv」，也就是使用虚拟环境——虚拟环境后面会详细讲。

**第三项：Python 版本。** PyCharm 装好之后，启动时会自动加载本地已安装的 Python 解释器信息，这里确认无误即可。

确认之后点「创建」，项目就建出来了，顺手把窗口最大化。

### 主界面的四个区域

进入主界面，先熟悉一下各区域的分工：

| 区域 | 内容 |
| --- | --- |
| 顶部菜单栏 | 右侧是最小化／最大化／关闭与设置，还有运行、调试运行的快捷操作；点击可展开主菜单——这些菜单功能后面随着课程推进会陆续用到，用到时再细讲 |
| 左侧功能栏 | 后续代码运行时的 Python 控制台、命令行终端、运行的服务，都在这里查看 |
| 项目区 | 当前项目的名字与磁盘路径，点一下「项目」可以折叠，再点一下又展开 |
| 右侧编辑区域 | 打开文件后，文件内容在这里显示 |

我的项目区里显示的是 `py_project01`，它放在 `D:\python_project` 下。项目创建好之后，工具还自动生成了一个目录（就是一个文件夹），里面存放的是这个 Python 项目的运行环境信息，这部分后面还会再讲。

## 创建 Python 文件与编写代码

### 新建章节目录与 .py 文件

回到第二步。在项目上右键，选择「新建」（英文版是 `New`），后面可以指定要新建目录还是新建 Python 文件。

先建一个目录：现在讲的是第一章的内容，所以目录名就写「第一章」，回车。然后在「第一章」目录下右键新建，选择「Python 文件」，文件名写 `01 入门程序`。

> **提示**：之前用记事本写代码，得自己补上 `.py` 后缀；现在用了 PyCharm，创建 Python 文件时不用加后缀，它会自动加上。建完之后看文件名——后缀就是 `.py`，代表这是一个 Python 文件。

文件建好会自动打开，右侧编辑区里光标闪动，等着输入内容。

### 用注释写下需求

需求很简单：往控制台里输出 `Hello World, Hello Python`。

我先把这句需求写进文件里。但要注意：这行文字本身**不是 Python 代码**，它是需求描述。我们并不想让 Python 解释器去运行它——它只起说明作用，给开发人员看，让人知道我们的需求是什么。所以要把这行文字注释掉。

> **定义**：注释是写给我们开发人员看的说明性文字，作用是解释说明代码、让开发人员更容易看懂需求与代码；Python 解释器在执行代码时会忽略注释。

注释的写法是在这一行最前面加一个井号 `#`，也就是「井号 + 往控制台输出 Hello World, Hello Python」。加上井号之后，这行文字就变成注释，解释器在执行这个文件时不会执行它。

手动敲井号当然可以，但有更快的办法：**光标停在这一行的任意位置，按下 `Ctrl + /`**，这行立刻被注释；再按一次 `Ctrl + /` 就取消注释。快捷键就是 `Ctrl + /`，记牢它。

写代码时还会发现一个问题：字体太小。PyCharm 默认字体偏小，可以临时用快捷键调大——按 `Shift + Alt + .`（句号）调大字体，按 `Shift + Alt + ,`（逗号）调小。我把它调到 16 号。字体的详细配置下一节会专门讲。

### print 语句与自动补全

需求是往控制台输出内容，这一步之前在命令行里已经做过。现在直接写代码：

```python
print("Hello World")
print("Hello Python")
print("------------------------------")
```

在 PyCharm 里敲代码的感受和记事本完全不同——**有提示了**。敲一个 `p`，所有 `p` 开头的候选就都列出来了，问你是不是要输出，第一个就是 `print`。想让它自动补全，双击一下或者直接按回车，`print` 就生成了，括号也一起生成，光标停在括号中间等着输入要输出的内容。输入 `Hello World`，第一行完成。

第二行继续写 `print`，输出内容写上 `Hello Python`。

第三行我输出一条长横线，用来做分隔。

### 换行与分号

这里有一条 Python 的规矩要讲清楚：**多行代码之间不用加分号**。

Python 里一行代码写完直接换行就行，通过换行符标识这行代码到这里就结束了，结尾不需要分号。但反过来，如果你想把两行代码写到同一行里，那就必须用分号把它们隔开。

> **易错点**：分号在 Python 里不是行尾结束符。绝大多数情况下我们都让一行代码占据一行，行尾那个分号不用加；只有把多条语句挤到一行时，才需要分号作分隔。

## 运行文件与查看结果

代码写完就可以执行了。在 PyCharm 里执行一个 Python 文件非常简单：在文件上右键，找到「运行 01 入门程序」，点击这一项，它就会自动运行这个文件。

有意思的是运行方式本身：PyCharm 这类集成开发环境在运行 Python 文件时，底层依旧是 `python` 加上空格、再跟上要运行的文件名——和我们在命令行里手敲的一模一样，只不过它替我们做了。

```bash
python 01 入门程序.py
```

上面这条就是工具在背后执行的命令：`python` 解释器加上要运行的文件路径。运行之后，下方区域能看到输出结果——`Hello World`、`Hello Python` 和那行分隔横线，三行内容都输出了。

## 小结与注意事项

把这一节需要明确的东西收拢成几条：

| 要点 | 内容 |
| --- | --- |
| Python 文件后缀 | `.py` |
| 什么是注释 | 对代码起解释说明作用的文字，给开发人员看；Python 解释器执行代码时会忽略注释 |
| 注释的写法 | 在行首加一个井号 `#`，井号开头的就是注释 |
| 注释的快捷键 | `Ctrl + /`，同时按下即可注释当前行，再按一次取消注释 |

最后两条注意事项，请一定记住：

- **编写代码时，所有的符号都要使用英文符号。** 再强调一次：中文全角符号是新手代码报错的头号来源。
- **Python 每一行结尾不需要加分号**，直接换行就代表这行代码结束；只有需要把多行代码合并到一行时，才用分号作分隔符。而绝大部分情况下我们都会让一行代码占一行，不会把多行合并，所以结尾的分号就不用加。
