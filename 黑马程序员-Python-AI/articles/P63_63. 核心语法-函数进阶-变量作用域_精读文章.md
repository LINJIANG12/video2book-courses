# 函数的变量作用域与 global 关键字

函数的基础打完，就进入函数的进阶部分。进阶要讲四块：变量的作用域、参数的详解（传参方式和高级参数写法）、匿名函数的定义语法、再用一组案例把函数这一整块内容巩固一遍。前面定义的函数都是有名字的函数，到了匿名函数那一节就来讲没有名字的函数怎么定义。这一节先解决第一块——变量在函数里到底能在哪儿用、不能在哪儿用。

## 从一个圆面积函数说起

先看函数进阶文件里的这段代码：

```python
number = 100
count = 5
c_area = 0


def circle_area(r):
    pi = 3.14
    area = pi * r * r
    return area
```

这里研究的问题是：这些变量分别在什么范围里可以使用。

**变量的作用域**，指的就是定义函数的时候，函数当中所涉及到的这些变量的作用范围；所谓作用范围，就是这些变量**在哪可以用、在哪不可以使用**。

按作用范围，变量分成两类：一类叫**全局变量**，一类叫**局部变量**。

> **定义**：在函数之外定义的变量叫**全局变量**，在当前这个 Python 文件当中的任意位置都可以访问，包括函数的内部。在函数内部定义的变量叫**局部变量**，只能在函数内部访问，外部无法访问。

上面那段代码里，`number`、`count`、`c_area` 都是在函数外部定义的，所以都是全局变量；函数体里的 `pi`、`area` 是函数内部定义的，是局部变量。另外要留神一个容易漏的点：函数上面那个形参 `r`，本质上也是一个变量，而且它也是局部变量。

> **提示**：全局变量通常定义在 Python 文件的顶部，这样一眼就能看清这个文件依赖哪些外部状态。

局部变量还有一条性质：当函数执行完毕之后，它会自动销毁内部的这些局部变量。所以在函数外面去访问它们，不仅此时访问不到，而且在函数跑完之后它们也早就没了。

## 全局变量：函数内外都能访问

先在函数外部验证全局变量。在没有学函数之前定义的那些变量，其实都是全局变量，函数外部当然可以访问。

```python
number = 100
print("number =", number)
```

运行，输出 `number = 100`，说明函数外部可以访问这个全局变量。

接着把同一句代码搬进函数内部，看看能不能访问：

```python
number = 100


def circle_area(r):
    pi = 3.14
    print("number =", number)
    area = pi * r * r
    return area


print(circle_area(10))
```

调用这个函数时传入半径 10，函数内部会输出 `number` 的值，最后把圆面积返回并输出。运行结果是 `number = 100` 照样输出了——说明 `number` 确实是全局变量，在函数外部可以访问，在函数内部也可以访问。

## 局部变量：越界访问直接报错

再来验证局部变量。`pi`、`area`，以及那个形参 `r`，都是这个函数内部定义或声明的局部变量，只能在函数里面访问。那就在外面试着访问它们：

```python
print("pi =", pi)
print("area =", area)
print("r =", r)
```

> **易错点**：此时 PyCharm 已经报错了——鼠标放到 `pi` 上会提示这是「未解析的引用 pi」，意思就是没有解析到这个变量。如果直接运行，走到这一行就会报错：名字为 `pi` 的变量未定义（`is not defined`）。而这行一旦报错，下面的代码就不会再运行了。

局部变量的作用范围就一句话：**只能在函数内部使用**。

## 局部变量遮蔽全局变量

接下来演示一个现象，这个现象是这一节最重要的一处坑。

```python
number = 100


def circle_area(r):
    pi = 3.14
    area = pi * r * r
    number = 10000
    print("number =", number)
    return area


print(circle_area(10))
print("number =", number)
```

全局变量 `number` 的值是 100。而在这个函数的里面，为 `number` 重新赋了一个值 10000，紧接着输出了这个 `number`，然后返回圆的面积；函数调用完之后，在最后一行又输出了最新的 `number`。

现在的问题是：这两次输出都是打印 `number`，它们的值到底是多少？先自己推测一下。

实际上，输出顺序是：函数内部先输出 `number` 为 10000，接着输出圆的面积 314.0，最后那一行输出的 `number` 又变回了 100。

> **易错点**：这里有个反直觉的地方——在函数内部，对 `number` 的赋值必须**写在打印之前**。如果在函数里先 `print("number =", number)`、后面才写 `number = 10000`，Python 会直接抛 `UnboundLocalError`。原因是只要函数体里出现过对某个名字的赋值，这个名字在整个函数内就按局部变量处理，于是那句打印读的是一个「还没被赋值的局部变量」，而不是外面的全局变量。

为什么会发生这个现象？原因在于：上面那个是全局变量 `number`，值是 100；而函数里被赋值的那个 `number` **并不是**同一个 `number`，它是一个**局部变量** `number`。这两个 `number` 不是同一个变量——函数里的 `number` 是局部变量，赋值为 10000，输出出来就是 10000；而在函数外部输出 `number` 的时候，由于在函数外部无法访问函数内部的局部变量，它访问的依然是全局变量的 `number`，值依然是 100。

```text
模块（全局）作用域                  函数（局部）作用域
┌────────────────────┐            ┌────────────────────┐
│  number = 100      │            │  number = 10000    │
│  （全局变量）       │            │  （局部变量）       │
│                    │  赋值语句   │                    │
│                    │ ─────────► │  函数结束即销毁     │
│  函数外访问 → 100   │            │  函数内访问 → 10000 │
└────────────────────┘            └────────────────────┘
```

图中两个 `number` 各占一格：函数内一旦对 `number` 赋值，就在局部作用域里生成了一个同名的新变量，跟全局那个互不影响。

> **结论**：在函数内部对同名变量进行赋值，不会修改全局变量，而是新建了一个局部变量。函数执行完毕后这个局部变量被销毁，全局变量的值原封不动。

## global 关键字

那如果本意就是想在调用函数的时候操作那个全局变量 `number`，该怎么办？

Python 提供了一个关键字来解决这件事，叫 `global`。

> **定义**：`global` 关键字用于明确告诉 Python 解释器，函数当中要使用的是全局变量而不是局部变量。一旦指定为全局变量，就可以在函数内部修改全局变量的值。

用法就是在变量名前面加上 `global` 关键字。这代表告诉 Python 解释器：接下来我要用到的这个 `number` 不再是局部变量的 `number`，而是全局变量的 `number`。这样就能在函数内部修改全局变量的值了。

```python
number = 100


def circle_area(r):
    global number
    pi = 3.14
    area = pi * r * r
    number = 10000
    print("number =", number)
    return area


print(circle_area(10))
print("number =", number)
```

> **易错点**：基于 `global` 声明要使用全局变量的时候，一定是**先声明再使用**。上面那个 `global number` 是声明，下面出现的 `number` 才是使用。声明必须写在前面。

改了之后，函数里用到的 `number` 全都是全局变量 `number`，也就是说把全局变量的值改成了 10000。那么函数调用完毕后，全局变量 `number` 的值会不会变？会。运行结果：函数调用时输出 `number` 是 10000，而且函数调用完毕之后全局变量 `number` 也变成了 10000。

## 使用建议与应用场景

`global` 虽然好用，但建议在做项目开发的时候**尽量避免**在函数当中使用全局变量，或者去修改全局变量的值，这会让代码变得难以维护和调整。道理很直白：如果函数里修改了全局变量的值，那调用一次这个全局变量可能就改一次，再调用一次又改一次，代码就难以维护和调试了。

第二个建议是：如果函数调用的过程当中需要操作数据，一般建议通过**传参或者返回值**来传递这些数据，而不是去修改全局变量。

那 `global` 到底什么时候用？它主要用在记录程序的状态、配置以及程序计数器这类场景。举两个例子：

**调试开关**。定义一个程序调试的开关 `debug_mode = False`，默认这个开关是关着的。这个全局变量记录的就是程序的状态或配置——要不要进入调试模式。想开启调试模式，就调用以 `enable` 开头的方法，把 `debug_mode` 置为 `True`；想关闭调试模式，就调用 `disable` 方法，把 `debug_mode` 改为 `False`。这里通过全局变量记录的是程序当中的调试状态，调用函数时就是在改这个调试状态，所以就需要在函数当中操作全局变量，此时要用 `global` 来指定操作的是全局变量。

**程序计数器**。想记录函数调用的次数，可以定义一个全局变量来记录，每一次调用都让这个全局变量加一。这也需要操作全局变量。
