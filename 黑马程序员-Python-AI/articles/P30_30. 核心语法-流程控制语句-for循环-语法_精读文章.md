# for 循环的语法与执行流程

`while` 循环的基本语法学完了，接下来看循环当中的第二类——`for` 循环。

`while` 和 `for` 都是用来定义循环结构的。既然都能定义循环，它们之间到底有什么差异？这是这一节首先要回答的问题。

## while 循环的控制方式

`while` 循环是**通过条件表达式来控制是否要进入下一次循环**的。这个条件表达式运算的结果就是一个布尔值：结果为 `True`，就代表条件成立，成立就进行下一次循环，继续执行循环体当中的语句；结果为 `False`，就代表该退出循环了，循环结束。

顺着这个机制往下推一步，就会看出 `while` 的一个特点：如果条件表达式运算的结果**一直都是 `True`**，那它就相当于进入了无限循环，会一直循环下去，永远不退出。

再看 `for` 循环。

## for 循环是一种轮询遍历机制

`for` 循环本质上属于一种**轮询遍历机制**——它会对一批内容进行逐个处理，这批内容处理完了，`for` 循环也就结束了。

所以 `for` 循环具体要循环多少次，取决于这批数据里面到底有多少个数据。数据多就多循环几次，数据少就少循环几次，数据没了循环就停。

拿一个例子来说。假设这里有一个容器，就是一个箱子，箱子里面装的是一箱乒乓球。现在的需求是：把箱子里面的乒乓球逐个编号。

那就从箱子当中拿出一个乒乓球，进行编号处理，编完号之后把它放到外面来。再从里面取一个、编号、放到外面来……一个取一个，这不就是在对这批内容做逐个处理吗？直到把箱子里面的乒乓球全部取完，这个任务也就结束了，循环也就结束了。

> **定义**：`for` 循环（for statement）是一种轮询遍历机制，它对一个数据集中的元素逐个处理，数据集遍历完毕则循环自动结束。

## for 循环的执行流程

`for` 循环开始之后，第一步是**判断容器当中是否还有要处理的元素**。如果有，就取出一个元素——注意每一次只取其中的一个元素——取出之后对这个元素进行处理。而取出这一个元素之后，容器里面就少了一个元素。

处理完这一个元素，紧接着再到容器当中去获取第二个元素、下一个要处理的元素。当然在获取之前，它会先判断容器里面还有没有元素：有，就再取出一个、再处理；处理完再回到容器里看还有没有。

如果容器里面的元素都已经取完了，没有元素了，那这个时候循环也就结束了。

```text
         +---------------------------+
         |                           |
         v                           |
判断容器中是否还有元素? --有--> 取出一个元素 --> 处理该元素 --+
         |                                                   |
        无                                                   |
         |                                                   |
         v                                                   |
     循环结束 <------------------------------------------------+
```

读图说明：判断与取出构成一个闭环，每处理完一个元素就回到容器再问一次「还有吗」，只要容器里还有元素就继续，直到问出「没有」才退出循环。

## for 循环的语法结构

基本结构里 `for` 和 `in` 是固定的两个字，写成 `for ... in ...`。

```python
for 元素 in 待处理的数据集:
    循环体语句
else:
    循环正常结束时执行的语句
```

先看 `in` 后面的**待处理的数据集**。刚才说了，`for` 循环本质是一种轮询遍历机制，会对一批内容逐个处理；这里的「集」指的就是集合，就是一个大的容器，而容器里面装的就是一项一项待处理的数据。这一部分代表的就是 `for` 循环需要轮询遍历的是哪一个数据集。

`for` 循环在遍历的时候，**一次只会从这个数据集当中取出一项数据**。`in` 前面那一位，就是所取出来的数据——它其实是一个变量名，这个变量代表的就是每次从数据集当中取出来的那个元素。

拿到这个元素之后，接下来就可以在循环体里对这个元素做进一步处理。冒号下面那一段代码就是循环体。第一个元素处理完毕之后，它会再到数据集当中取第二个元素、处理第二个元素；第二个处理完再处理第三个，第三个处理完再处理第四个，直到数据集当中所有的元素都处理完，循环结束。

结尾还可以加一个可选的 `else` 结构。这个 `else` 可有可无，它会在循环**正常结束时**执行里面的逻辑。

> **提示**：这里的 `else` 挂在 `for` 上，不是「否则」的意思。它的触发条件是「循环正常跑完」，而不是「条件不成立」。

## 遍历一个字符串

看一个小案例：遍历 `Hello Python` 这个字符串。

为什么要拿字符串来遍历？因为字符串其实也是一种数据集，或者说数据容器。这个字符串里面存储的就是一个一个的字符：`H`、`e`、`l`、`l`、`o`、`-`……每一个都是一个字符。所以字符串本质上也是一种数据集，里面存储的就是一个一个的字符。

那么基于 `for` 循环如何遍历字符串当中的一个一个字符？其实每一个字符也都是一个子字符串。

```python
for i in msg:
    print(i)
```

字符串 `msg` 是由一个一个字符组成的。遍历的时候，它会把这个字符串当中的字符一个一个遍历出来，前面的 `i` 就是一个变量，代表遍历出来的元素。第一个拿出来的是 `H`，把 `H` 输出出来——注意 `print` 默认输出是会换行的；然后第二个 `e`，第三个 `l`，第四个 `l`，第五个 `o`，到这里遍历是不是五次了？接着一个字符一个字符地输出，直到最后一个字符遍历输出完毕。

对 `msg` 来说遍历完了没有？完了，因为里面的字符我们已经一个一个全部获取出来了。这时候再执行下去，`msg` 当中已经没有需要遍历的元素，整个循环就结束了。循环正常结束，就会执行 `else` 结构当中的逻辑——当然 `else` 里的逻辑是可选的。

## 完整代码：遍历键盘录入的字符串

看一段完整可运行的代码。这个需求是遍历**手动输入**的字符串：输入什么字符串，就遍历什么字符串。

```python
# 接收键盘录入的字符串
msg = input("请输入需要遍历的字符串：")

for s in msg:   # s 表示遍历出来的元素，msg 表示需要遍历的数据
    print(f"遍历出来的元素是：{s}")
else:
    print("遍历结束")
```

写法上要注意几个点。首先定一个变量来接收所输入的字符串，提示信息写「请输入需要遍历的字符串」。然后是 `for` 循环结构：关键字 `for`，`for` 之后跟一个空格，空格之后跟上遍历出来的元素的名字——这个名字随便写都可以，就是一个变量名；接着加关键字 `in`，`in` 之后跟上要遍历的那个数据集，这里就是 `msg`；最后跟上冒号。回车之后进入循环体，`s` 代表的就是遍历出来的元素。

不加 `else` 也可以；如果要加，它代表的就是遍历结束后执行的操作。

不妨输入一句「人生苦短，我用 Python」，后面再补一个波浪线，然后回车，用调试模式一步一步看。

`msg` 的值有了之后就可以开始遍历。控制台一步一步走下来：

- 第一个元素是 `人`——「人生苦短」的第一个字就是「人」；
- 接着 `生`；
- 第三个 `苦`；
- 第四个 `短`；
- 再往下走是逗号 `，`；
- 然后是 `我`、空格、`P`、`y`、`t`、`h`、`o`、`n`；
- 最后一个字符是那个波浪线 `~`。

波浪线输出出来之后，数据容器当中已经没有需要遍历的元素了，遍历完了，所以退出循环，执行 `else` 当中的逻辑，最终输出「遍历结束」。

> **提示**：字符串里的空格、逗号、波浪线都是字符，都会被 `for` 一个不落地遍历出来。字符的个数就是循环的次数，一个都不能跳。

这就是 `for` 循环的语法：它把指定的数据集合当中的元素遍历完了，就会自动退出循环。

## for 与 while 的应用场景对比

回到开头那个问题：是不是有了 `for` 循环，`while` 循环就不用了？并不是，它们各自有各自的应用场景。

`while` 循环是通过条件来控制循环的。在满足某个条件的情况下，它其实可以做到一直循环，**循环的次数是未知的**——它只知道循环和结束的条件是什么。我们关注的是那个条件：达到条件就循环，条件不成立就退出。

`for` 循环主要是针对一个**已知的数据集**进行遍历，或者说是循环次数已经明确知道的循环。它的关键点是遍历数据集当中的每一个元素。

| 对比项 | `while` 循环 | `for` 循环 |
| --- | --- | --- |
| 控制依据 | 条件表达式 | 数据集中的元素 |
| 循环次数 | 未知，只知道开始与结束的条件 | 已知，取决于数据集里的元素个数 |
| 退出方式 | 条件表达式结果为 `False` | 数据集元素被取完 |
| 典型场景 | 满足条件就一直循环 | 遍历数据集、已知次数的循环 |

> **结论**：要去遍历一个数据集，或者循环次数已经明确，就用 `for`；只知道循环开始和结束的条件、次数事先说不准，就用 `while`。

最后补一句实际开发中的判断：`else` 这个结构在项目开发当中用得比较少，知道它在那儿就行，不必刻意去用。
