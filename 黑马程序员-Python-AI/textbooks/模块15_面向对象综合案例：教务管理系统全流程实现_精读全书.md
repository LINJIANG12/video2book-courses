## 第 1 章：核心语法-面向对象基础-案例(教务系统-准备)
> 对应分集：P82 | 原始标题：《82. 核心语法-面向对象基础-案例(教务系统-准备)》

面向对象基础的语法到这里就全部讲完了。语法学完总得找个地方用一用，所以接下来用一个完整的案例把它们串起来——教务管理系统。这个系统要管理在校学生的成绩信息，通过控制台菜单与用户交互，能添加、修改、删除、查询学生成绩，也能把系统里所有学生的成绩一次性展示出来。需求里明确要求：用面向对象的编程思想完成。

这一节做两件事：先把需求读透、想清楚该设计哪几个类；再打开 PyCharm，把第一个类——学生类——写出来并测通。

### 1.1 五个功能

需求一共五个功能：

1. 添加学生成绩：根据输入的姓名以及对应的语文、数学、英语成绩，把学生和成绩记录到系统当中；
2. 修改学生成绩：输入学生姓名，按姓名修改这个学生的成绩；
3. 删除学生成绩：按学生姓名删除对应的成绩；
4. 查询指定学生的成绩：按输入的姓名查找对应成绩并输出到控制台；
5. 展示系统当中所有学生的成绩。

需求描述本身只说了"要做什么"，没说过"要设计哪些类"。而面向对象的第一道工序，恰恰就是把这份描述翻译成类。

### 1.2 从需求里找业务实体

遇到这类业务需求，先根据需求描述提炼梳理：这个需求里到底涉及哪些业务实体？

> **定义**：业务实体指的是需求当中涉及的具体事物或者参与者。明确了有哪些业务实体，就能知道完成这个需求要设计哪些类，以及类当中涉及哪些属性和方法。

先花十秒自己想一想：如果让你来设计，需要设计哪些类？

一个一个参与者往下数。需求里让开发的是一个教务管理系统，而添加学生、修改学生、删除学生、查询学生这一堆功能，是谁的功能？是教务管理系统提供的功能。所以第一个参与者就是**教务管理系统**。

教务管理系统管理的是什么信息？管理的是在校学生的成绩信息。再看下面那些具体功能：添加学生成绩要求输入学生的姓名、语文成绩、数学成绩、英语成绩，最终把这些成绩记录到系统当中——也就是说，一个学生的信息里包含姓名、语文成绩、数学成绩、英语成绩这四样，而教务管理系统就是来管理这些学生信息的。所以**学生**也是这个系统当中的参与者。

> **结论**：这个需求当中有两个非常重要的参与者——学生和教务系统。按面向对象的思想做功能开发，至少可以定义两个类：学生类 `Students`，教务系统类 `EduManagement`。`Edu` 是教育，`Management` 是管理。

### 1.3 两个类的属性与方法

类定下来了，接着回答：这两个类里各有哪些属性、各有哪些方法？

学生的信息里要输入姓名和成绩，成绩又分语文、数学、英语三科——这些信息都属于学生。所以姓名、语文成绩、数学成绩、英语成绩都是**学生类的实例属性**。

学生类有哪些方法？这一块要小心。五个功能看上去都跟学生有关，但添加学生、删除学生、查询学生这类操作其实不属于学生，而是属于教务系统。学生自己的功能，主要是操作自己那几科成绩，比如"修改成绩"——修改成绩这个动作作用在自己的分数上，它属于学生。

再看教务系统类。它是用来管理在校学生成绩信息的，那么它里面就应该有一个属性：在校学生的信息。方法呢？上面列的那五个功能都是教务系统的功能，它们就是这个类当中的方法。另外，系统运行起来之后还要有一套控制台菜单和用户打交道，这部分留到后面处理。

```text
教务管理系统案例的类结构
  Students 学生类
    ├─ 实例属性：name / chinese / math / english
    └─ 方法：修改自己的成绩
  EduManagement 教务系统类
    ├─ 属性：在校学生的信息（学生列表）
    └─ 方法：添加学生成绩 / 修改学生成绩 / 删除学生成绩
              / 查询指定学生成绩 / 展示全部学生成绩
```

读图看第一层：两个类各自承担一件事——学生负责装自己的数据、管自己的分数，教务系统负责提供五个操作入口。功能都长在教务系统上，数据都长在学生上，这个分工决定了后面每一段代码该写在哪个类里。

### 2.1 建文件与第一个类

打开 PyCharm，新建一个 Python 文件，文件里已经放好上面这份需求，界面交互的规则也描述清楚了。

按分析，这里要定义两个类。先写第一个——学生类：

```python
class Students:
```

类名就叫 `Students`。

学生类里包含哪些属性？回到前面梳理的结论：将来添加学生成绩时要输入学生的姓名、语文成绩、数学成绩、英语成绩，这些信息都要记录到系统当中，而它们全都属于学生的信息；并且每一个学生的名字、三科成绩都不一样。既然各对象特有，就应该在这个类当中定义对应的**实例属性**。

定义实例属性就是定义 `__init__` 这个魔法方法。在编辑器里敲下函数名，按 Tab 键采纳它的建议，补上完整的初始化方法，参数列表先只留一个 `self`：

```python
class Students:
    def __init__(self):
        pass
```

然后依次把四个参数加进去：学生姓名是 `name`，语文成绩是 `chinese`，数学成绩是 `math`，英语成绩是 `english`：

```python
    def __init__(self, name, chinese, math, english):
```

这就是将来构造 `Students` 对象时要传进来的四个参数。参数传进来之后，为实例对象对应的四个属性赋上值：

```python
        self.name = name
        self.chinese = chinese
        self.math = math
        self.english = english
```

这样我们就为实例设置了四个属性：`name` 姓名、`chinese` 语文成绩、`math` 数学成绩、`english` 英语成绩。

> **易错点**：`self.name` 里的 `name` 是**实例属性的属性名**，赋值号右边的 `name` 是**参数名**。这两处虽然重名，身份完全不同——属性名前面必须带 `self.`，漏掉它，等号左边就只是给一个局部变量赋值，实例身上什么也不会留下。

### 2.2 用 `__str__` 定好输出格式

初始化方法之外，学生类还要再来一个魔法方法：`__str__`。

它的作用是把实例对象转成一个字符串。以后输出 `Students` 的学生对象时，它就会以字符串的形式输出出来。方法里要 `return` 一个字符串，那这个字符串长什么样？需求第四点说了，要"查询指定学生的成绩并输出"，输出格式是：

```text
姓名: 张三 | 语文: 85 | 数学: 90 | 英语: 95 | 总分: 270
```

那就把一个学生对象直接转成这种格式的字符串。用格式化字符串，大括号里取属性值：

```python
    def __str__(self):
        return f'姓名: {self.name} | 语文: {self.chinese} | 数学: {self.math} | 英语: {self.english} | 总分: {self.chinese + self.math + self.english}'
```

姓名写 `self.name`，横线之后写 `self.chinese`，再往下是 `self.math`，然后是 `self.english`。最后一项是总分——总分不就是三科成绩加起来吗，所以直接在大括号里做 `self.chinese + self.math + self.english` 这个加法。

定好之后，后面完成第四个查询功能时，要输出学生信息就直接输出这个对象，它会自动按这个格式转成字符串打出来。

### 2.3 修改成绩的方法

学生类还差一个方法：修改当前学生的分数。

为什么这个方法放在学生类里？添加学生的信息，本质是把这些信息封装成一个学生对象再添加进去；而修改学生的成绩信息，是去改这个学生对象当中的属性。改的是自己的属性，所以这个动作属于学生。

定义一个方法，名字叫 `update` 加 `score`：

```python
    def update_score(self, chinese, math, english):
```

要修改成绩，就得把成绩信息传进来：第一个 `chinese`，第二个 `math`，第三个 `english`。

方法体的逻辑用条件判断来做。如果传进来的 `chinese` 有值，就修改当前对象的语文成绩。怎么判断"有值"？和 `None` 比较：

```python
    def update_score(self, chinese, math, english):
        if chinese is not None:
            self.chinese = chinese
        if math is not None:
            self.math = math
        if english is not None:
            self.english = english
```

`None` 就是空，`chinese is not None` 表示它不是空的。是"不是空的"，才把当前对象的 `chinese` 改成传进来的 `chinese`。剩下两科照猫画虎：传进来的 `math` 不是空就改数学成绩，传进来的 `english` 不是空就改英语成绩。

为了让方法更灵活，给这三个参数都设上默认值 `None`：

```python
    def update_score(self, chinese=None, math=None, english=None):
        if chinese is not None:
            self.chinese = chinese
        if math is not None:
            self.math = math
        if english is not None:
            self.english = english
```

这么写有什么好处？将来要修改成绩时，想改哪一科就传哪一科，而且可以直接用关键字参数传。比如只想改英语成绩，就传一个 `english=95`；只想改数学成绩，就传一个 `math=...`，另外两科有默认值不用传。

> **提示**：参数默认值 `None` 与条件判断 `is not None` 是一对搭档——默认值负责"允许不传"，判断负责"没传的就不动"。少了判断这一步，不传的那一科会被 `None` 直接覆盖掉。

到这儿学生类的基本功能就定义好了。如果哪一块不符合需求，等完成后面那些功能时再回来调整。

### 2.4 测试学生类

类写完先测一遍。在下面写一个 `main`，先做一个判断：直接运行当前这个模块，就执行 `if` 里面的代码；如果是被外部导入这个模块，里面的代码就不运行。

```python
if __name__ == '__main__':
    s1 = Students('王玲', 90, 88, 92)
    print(s1)
```

`if` 里面创建一个学生对象 `s1`：姓名传"王玲"，语文成绩 90，数学成绩 88，英语成绩 92，然后直接把 `s1` 输出出来看看效果。

右键运行，输出的是：

```text
姓名: 王玲 | 语文: 90 | 数学: 88 | 英语: 92 | 总分: 270
```

和我们指定的输出格式一致。

接着更新王玲的英语成绩，改成 95。直接让 `s1` 调用里面的 `update_score` 方法；因为那几个参数都有默认值，只想改英语，就用关键字参数传参：

```python
    s1.update_score(english=95)
    print(s1)
```

再运行，英语成绩变成了 95，另外两科没变。之所以没被改掉，正是因为我们设了默认值，并且在方法里做了条件判断——只有不是 `None` 才会去改这个对象的属性。

```text
s1.update_score(english=95) 的执行结果
  chinese 未传 -> 默认 None -> is not None 为假 -> 语文成绩保持 90
  math    未传 -> 默认 None -> is not None 为假 -> 数学成绩保持 88
  english = 95 -> is not None 为真 -> 英语成绩 92 改为 95
```

读图看三行的差别：传入的那一科走通判断被改写，没传的两科在判断处就被拦住，值原样保留。

学生类到此定义完成。接下来要完成教务管理系统这个类的定义，以及这个类当中那些功能方法的定义。

## 第 2 章：核心语法-面向对象基础-案例(教务系统-添加学生信息)
> 对应分集：P83 | 原始标题：《83. 核心语法-面向对象基础-案例(教务系统-添加学生信息)》

学生类完成之后，接着定义第二个类——教务管理系统类 `EduManagement`。

先在类定义的上方加上注释，把需求原文贴到编辑器右侧对照着看，下面那段测试代码先注释掉，再空几行，把注意力集中到教务管理系统这个类上。

### 1 教务系统类的属性与五个方法

#### 1.1 两个类属性

先在这个类当中定义两个**类属性**。为什么是类属性？因为基于这个类创建出来的所有实例都会共享这两个属性。

```python
class EduManagement:
    # 系统版本，所有实例对象共享
    SYSTEM_VERSION = '1.0'
    # 系统名称，所有实例对象共享
    SYSTEM_NAME = '教务管理系统'
```

一个是当前开发的这套教务管理系统的**系统版本**，都是 1.0 版本；另一个是**系统的名字**，就设置为"教务管理系统"。无论基于这个类创建出多少个实例，版本信息和系统名字都是一样的、共享的，这正是类属性的适用场景。

#### 1.2 一个实例属性：学生列表

类属性之外，这个类里还有哪些实例属性？教务管理系统需要管理在校学生的成绩信息，它里面维护的学生有很多，那么"在校学生的信息"就是教务管理系统的一个属性。

于是给它定义一个初始化方法，在初始化方法当中设置实例属性：

```python
    def __init__(self):
        # 在校学生的成绩信息
        self.student_list = []
```

这个实例属性有点特殊，它里面记录的是在校学生的信息，就叫 `student_list`，赋的值是一对中括号——中括号是列表，这个列表里记录的就是在校学生的成绩信息。

走到这里很多同学会有疑问：前面构建对象的时候，属性对应的属性值不是直接传递进来、直接赋上就行了吗？这里怎么设了一个空列表——创建对象的时候为什么没有把列表的值直接传进来？

> **提示**：学生列表里的数据**不是**构建对象时传递进来的。我们要通过调用系统里的功能来填充它：每调用一次添加学生成绩的功能，就往列表中添加一条数据；再添加一次，就再往列表里加一条。所以后续这些功能都要操作这个学生列表，而不是在构建对象时把整个列表传进来。这一点要特别注意。

类当中还有哪些实例方法？实例方法就是这个系统当中的功能。系统里的功能有：添加学生成绩、修改学生成绩、删除学生成绩、查询指定学生成绩，再加上展示全部学生的成绩。这就是这个类所涉及的五个实例方法。

先把结构定义好，五个方法的框架一次摆齐：

```python
    # 添加学生成绩

    def update_student(self):
        pass

    # 删除学生成绩
    def delete_student(self):
        pass

    # 查询指定学生的成绩
    def query_student(self):
        pass

    # 展示全部学生的成绩
    def list_student(self):
        pass
```

接下来一个方法一个方法地实现，先做第一个：添加学生成绩。

### 2 添加学生成绩

#### 2.1 需求里的三步逻辑

添加学生这个方法叫 `add_student`。它的逻辑在需求描述里已经写清楚了：根据输入的学生姓名、语文成绩、数学成绩、英语成绩，把学生信息记录到系统当中。

具体分三步：

1. 第一步，输入学生的姓名，以及语文成绩、数学成绩、英语成绩；
2. 第二步，检查这个学生姓名是否已经存在——不存在才添加，存在则不添加，避免重复；
3. 第三步，验证成绩的范围是否在 0 到 100 之间，在范围内就创建学生对象并添加到系统当中。

#### 2.2 接收键盘输入

第一步是接收键盘输入，用 `input` 函数。先让用户输入学生姓名，用一个变量 `name` 接收：

```python
        # 请输入学生的姓名
        name = input('请输入学生的姓名：')
```

接着还要接收语文、数学、英语三科成绩，按同样的写法把这行代码快速复制三份，提示语分别改成语文成绩、数学成绩、英语成绩，接收的变量分别是 `chinese`、`math`、`english`。

姓名本身就是字符串，但后面三科成绩不是字符串——从键盘接收进来的数据都是字符串，所以要转换。用 `int` 函数把它们都包一层，转成整型：

```python
        # 接收学生的成绩
        chinese = int(input('请输入学生的语文成绩：'))
        math = int(input('请输入学生的数学成绩：'))
        english = int(input('请输入学生的英语成绩：'))
```

到这儿姓名、语文成绩、数学成绩、英语成绩就都拿到了。

#### 2.3 判断姓名是否重复

接下来按需求判断这个学生的姓名在系统当中是否已经存在：已经存在就不能再添加，不能重复添加；不存在才继续。

`student_list` 这个列表里存的就是一个一个的学生信息，所以判断的方式是看这个姓名在列表当中存在不存在。循环这个列表，逐个比对：

```python
        # 判断学生的姓名是否存在，如果存在则添加失败（不能重复添加）
        for s in self.student_list:
            if s.name == name:
                print('该学生已经存在，添加失败！')
                return
```

注意遍历出来的 `s` 是列表当中的一个元素，而列表里将来存放的是学生的信息，学生的信息最终又是封装到学生对象当中的，所以遍历出来的 `s` 就是学生对象。拿 `s.name` 和我们输入的 `name` 一比，如果相同，就说明这个学生在系统里已经存在，输出一句"该学生已经存在，添加失败！"。

紧接着要问一句：学生已经存在、添加已经失败了，代码还能继续往下运行吗？不能。怎么阻止代码往下走？方式比较多，这里用最直截了当的一种——直接 `return`。

> **定义**：`return` 代表返回，代码走到 `return` 这里，当前方法就执行结束了，它下面的代码不会再运行。这里只写一个 `return`，后面不跟任何内容，就是返回一个空值。

只有学生姓名在列表当中不存在，才继续让用户输入语文、数学、英语成绩。

#### 2.4 校验成绩范围并封装对象

输入完毕之后，还要验证成绩范围：在范围内就创建一个学生对象，添加到系统当中。

做一个条件判断，三科成绩都要同时满足在 0 到 100 之间：

```python
        # 验证成绩的范围是否在 0 到 100 之间
        if 0 <= chinese <= 100 and 0 <= math <= 100 and 0 <= english <= 100:
            # 创建学生对象
            stu = Students(name, chinese, math, english)
            # 添加到系统当中
            self.student_list.append(stu)
            print('学生信息添加成功！')
        else:
            print('各科成绩必须在 0 到 100 之间！')
```

第一个判断是"0 小于等于 `chinese`，并且 `chinese` 小于等于 100"，后面用 `and` 接上 `math` 的判定，再接上 `english` 的判定，写法完全一样。三个条件同时成立，才说明分数是合法的。

分数合法，就构建一个学生对象 `stu`，把接收到的姓名、语文成绩、数学成绩、英语成绩四个值依次传进去——这样就把输入的数据封装到一个对象里了。再把 `stu` 添加到 `student_list` 这个列表当中：调用列表的 `append` 方法，把 `stu` 添加进去，然后输出一句"学生信息添加成功！"。

不满足范围条件就走 `else`，说明分数超出了范围，给出提示："各科成绩必须在 0 到 100 之间！"

完整的 `add_student` 方法：

```python
    # 添加学生成绩
    def add_student(self):
        # 请输入学生的姓名
        name = input('请输入学生的姓名：')
        # 接收学生的成绩
        chinese = int(input('请输入学生的语文成绩：'))
        math = int(input('请输入学生的数学成绩：'))
        english = int(input('请输入学生的英语成绩：'))

        # 判断学生的姓名是否存在，如果存在则添加失败（不能重复添加）
        for s in self.student_list:
            if s.name == name:
                print('该学生已经存在，添加失败！')
                return

        # 验证成绩的范围是否在 0 到 100 之间
        if 0 <= chinese <= 100 and 0 <= math <= 100 and 0 <= english <= 100:
            # 创建学生对象
            stu = Students(name, chinese, math, english)
            # 添加到系统当中
            self.student_list.append(stu)
            print('学生信息添加成功！')
        else:
            print('各科成绩必须在 0 到 100 之间！')
```

#### 2.5 逻辑梳理

- 添加学生成绩时，首先输入学生的姓名；
- 然后判断这个姓名在教务系统当中是否已经存在：存在，就告诉用户已存在、不能再添加，并用 `return` 直接结束方法；
- 不存在，再让用户输入对应的语文、数学、英语成绩；
- 然后对成绩的合法性做判断：三科都在 0 到 100 之间，就构建一个学生对象，把这个对象存进 `student_list` 列表；
- 存完之后提示一条信息。成绩不合法，就提示让用户输入 0 到 100 之间的成绩。

要强调一点：现在 `student_list` 这个列表当中存储的就是一个一个的学生对象，里面的每一个元素都是一个学生对象。

```text
add_student 的执行流程
  输入姓名 name
      |
      +-- 遍历 student_list，存在 s.name == name ？
      |        是 -> 提示"该学生已经存在，添加失败！" -> return（方法结束）
      |        否
      v
  输入语文 / 数学 / 英语成绩
      |
      +-- 三科都在 0~100 之间 ？
               是 -> Students(name, chinese, math, english) -> student_list.append(stu) -> 提示添加成功
               否 -> 提示"各科成绩必须在 0 到 100 之间！"
```

读图看两个分叉：第一个分叉是"重名拦截"，走到 `return` 就直接出方法；第二个分叉是"范围校验"，只有三科全部落在 0 到 100 之间，才会走到构建对象并 `append` 的那一步。

### 3 关于方法的参数

仔细想一下：这个方法需要从外面接收一个学生参数吗？不需要。因为最终要添加哪个学生，是方法内部自己构建了一个学生对象、再添加到列表当中的——数据是方法里现攒出来的，不是外面递进来的。

> **结论**：调用 `add_student` 方法时，里面不需要传递任何参数。

添加学生成绩做完之后，剩下的几个功能相对来说就比较简单了——因为"按姓名在列表里找学生"这套动作已经写过一遍，后面几个方法大体都是它的变形。

这一节把剩下的四个方法补齐：修改学生成绩、删除学生成绩、查询指定学生的成绩、展示全部学生的成绩。

### 2 修改学生成绩

#### 2.1 先输入姓名并找到学生

定义方法 `update_student`，参数是 `self`。修改学生成绩时，依然需要让用户输入要修改的学生姓名，这段代码和添加学生时几乎一样，直接复制过来改提示语：

```python
    # 修改学生成绩
    def update_student(self):
        # 请输入要修改的学生姓名
        name = input('请输入要修改的学生姓名：')
```

拿到姓名之后要做判断：这个学生姓名到底在不在列表当中？在，才去修改；不在，就得告诉用户"该学生未找到"。判断方式还是循环列表逐个比对：

```python
        # 根据学生姓名找到该学生的信息
        for s in self.student_list:
            if s.name == name:
```

遍历 `student_list` 获取到每一个学生，拿 `s.name` 和输入进来的 `name` 对比；一致就说明找到了。

#### 2.2 输出修改前的成绩

找到之后不能马上就改。按需求，修改学生成绩之前要先把该学生当前的成绩显示出来，让用户清楚现在是什么状况。直接把学生对象 `s` 输出出来就行：

```python
                # 输出当前学生的成绩
                print(f'当前成绩：{s}')
```

为什么输出 `s` 就够了？因为 `s` 是一个学生对象，输出它的时候会自动调用 `__str__` 这个魔法方法，而 `__str__` 里已经把三科成绩和总分拼成了字符串。

#### 2.3 输入新成绩并更新

接着让用户输入新的语文、数学、英语成绩，接收的方式与添加学生时相同，只把提示语换成"修改后的"：

```python
                chinese = int(input('请输入修改后的语文成绩：'))
                math = int(input('请输入修改后的数学成绩：'))
                english = int(input('请输入修改后的英语成绩：'))
```

> **易错点**：写 Python 一定要盯住缩进。这一段必须放在 `if s.name == name:` 这个分支内部——缩进跑偏一层，就变成了循环体外或者别的代码块里的语句，逻辑全变。

接收到三科成绩之后，同样要对范围做判断：三科都落在 0 到 100 之间，说明输入没问题，就去更新这个学生对应的三科成绩。怎么更新？学生类里已经定义过 `update_score` 了，直接拿遍历出来的学生对象 `s` 去调用：

```python
                # 验证成绩的范围是否在 0 到 100 之间
                if 0 <= chinese <= 100 and 0 <= math <= 100 and 0 <= english <= 100:
                    # 更新学生的成绩
                    s.update_score(chinese, math, english)
                    print('成绩修改成功！')
                    # 输出修改后的成绩
                    print(f'修改后的成绩：{s}')
                    return
                else:
                    print('各科成绩必须在 0 到 100 之间！')
                    return
```

`s` 是学生对象，调用它身上的 `update_score`，把 `chinese`、`math`、`english` 三个值依次传进去，三科成绩就都更新了。

为了让体验更好，修改成功之后再把修改后的成绩输出一遍——这里复用的是同一句输出语句，修改之前看一眼当前信息，修改之后再看一眼。成绩已经改完，代码走到这里就不用再往下执行了，补一个 `return` 结束方法。成绩超出范围的分支同样提示一句，然后 `return`。

#### 2.4 没找到学生怎么办

上面是找到的情况。如果循环了一圈还是没找到呢？在 `for` 循环的**外面**、与 `for` 平齐的位置输出一句提示：

```python
        print('未找到该学生，修改失败！')
```

为什么写在循环外面、而不是写在循环里的 `else` 上？看代码的走向：循环里一旦进了那个 `if` 分支，走到末尾就 `return` 了，下面的代码根本执行不到；能执行到循环外这一句，说明它自始至终没有进到 `if` 里——也就说明它把列表遍历了一遍，都没找到这个学生姓名。既然不存在，就提示"未找到该学生，修改失败！"。

```text
update_student 的三条出口
  遍历 student_list
    ├─ 找到（s.name == name）
    │    └─ 输出当前成绩 -> 输入三科新成绩
    │         ├─ 三科都在 0~100 -> s.update_score(...) -> 提示成功 -> 输出新成绩 -> return
    │         └─ 有成绩超范围    -> 提示成绩范围   -> return
    └─ 遍历一圈没找到 -> 循环外提示"未找到该学生，修改失败！"
```

读图看出口的层级：两条出口在循环体内，靠 `return` 提前结束；第三条在循环体外，只有前两条都没走成才会执行到。

### 3 删除学生成绩：按姓名找到并移除

第三个功能是删除学生成绩，方法名 `delete_student`。删除同样要按学生姓名来做，前面几行还是复制过来，把提示语改成"请输入要删除的学生姓名"：

```python
    # 删除学生成绩
    def delete_student(self):
        # 请输入要删除的学生姓名
        name = input('请输入要删除的学生姓名：')
```

拿到姓名之后依然要循环列表，看一下这个姓名在列表当中存不存在：存在就删掉，不存在就提示一条信息。

```python
        # 根据学生姓名找到该学生的信息
        for s in self.student_list:
            if s.name == name:
                # 从列表中删除该学生对象
                self.student_list.remove(s)
                print('学生信息删除成功！')
                return
        # 循环结束后仍未找到
        print('未找到该学生，删除失败！')
```

遍历列表拿到每一个学生对象，再对比姓名。当前这个学生的姓名和要删除的姓名一致，就说明 `s` 这个对象正是要删除的那一个。删除的方式就是从 `student_list` 这个列表当中把当前这个 `s` 对象删掉——调用列表的 `remove` 方法把它移除即可。删除之后输出"学生信息删除成功！"，然后 `return`，代码走到这里就不再往下执行。循环走完仍然没找到，就在 `for` 外面输出"未找到该学生，删除失败！"，与上面修改功能采用同一种写法。

### 4 查询指定学生的成绩：找到就输出，找不到就提示

下面两个功能都是查询。第四个是查询指定学生的成绩，方法名 `query_student`，依然按输入的姓名来查对应的成绩，前面几行照旧复制过来，提示语改成"请输入要查询的学生姓名"：

```python
    # 查询指定学生的成绩
    def query_student(self):
        # 请输入要查询的学生姓名
        name = input('请输入要查询的学生姓名：')
```

然后循环列表，根据姓名找当前的学生。找到了，这就是要查询的学生信息，直接把它输出出来就行：

```python
        # 根据学生姓名找到该学生的信息
        for s in self.student_list:
            if s.name == name:
                print(f'学生信息：{s}')
                return
        # 循环结束后仍未找到
        print('未找到该学生！')
```

输出时写成格式化字符串、大括号里放 `s`，学生对象会按 `__str__` 定义好的格式转成字符串打出来。找到了并输出信息之后直接 `return`。如果循环一圈没找到，代码会继续往下运行，于是提示"未找到该学生！"。

### 5 展示全部学生的成绩

最后一个功能相对更简单：遍历列表当中所有的学生成绩，把它们输出出来。定义方法 `list_student`，循环一遍，输出每一个学生的信息即可：

```python
    # 展示全部学生的成绩
    def list_student(self):
        for s in self.student_list:
            print(s)
```

这样就把列表当中所有学生的信息直接输出到控制台了。

### 6 五个方法的形态对比

到这儿，教务管理系统当中涉及的五个功能对应的方法就都定义好了。把它们放在一起看，能看出很强的同构性：

| 方法 | 输入的姓名用途 | 循环内找到后 | 循环外兜底 |
| --- | --- | --- | --- |
| `add_student` | 重复性检查 | 提示已存在并 `return` | 无（直接往下走录入流程） |
| `update_student` | 定位要改的学生 | 输出原成绩、录入新成绩、校验范围、更新并 `return` | 提示"未找到该学生，修改失败！" |
| `delete_student` | 定位要删的学生 | 从列表 `remove` 并 `return` | 提示"未找到该学生，删除失败！" |
| `query_student` | 定位要查的学生 | 输出学生信息并 `return` | 提示"未找到该学生！" |
| `list_student` | 不使用姓名 | 无 | 无（遍历全部直接输出） |

> **结论**：四个方法共用同一套骨架——"输入姓名 → 循环 `student_list` 比对 `s.name` → 找到就干活并 `return` → 循环外兜底提示"。这也是前面把查找逻辑写成循环、把结果处理写进分支的好处：功能不同，骨架不动。

### 1 运行系统的方法

想一想：教务管理系统除了能添加学生、修改学生、查询学生，是不是还应该有一个"运行"的功能？所以在这个类当中再增加一个方法，就是**运行系统的方法**，名字叫 `run`：

```python
    # 运行系统
    def run(self):
```

运行方法里要做的事就是制作控制台菜单，与用户交互。

#### 1.1 欢迎语与版本号

系统跑起来先打一句欢迎语，用格式化字符串，把版本号也带上：

```python
        print(f'欢迎使用教务管理系统，当前版本：{EduManagement.SYSTEM_VERSION}')
```

版本从哪来？定义教务系统这个类的时候，我们在里面定义过类属性 `SYSTEM_VERSION`，值是 1.0。在字符串里用大括号写出 `EduManagement.SYSTEM_VERSION`，就拿到了这个类属性，也就是系统的版本。输出形式是"欢迎使用教务管理系统，当前版本：1.0"。

#### 1.2 菜单与输入

欢迎语之后要制作菜单。菜单不能一锤子买卖——用户做完一件事还得能接着做下一件，所以外面套一个 `while True`；用户想退出时，再用 `break` 跳出这个死循环。

先输出一个空行，再输出一串井号作为分隔线，接着是各个菜单项：

```python
        while True:
            print()
            print('#' * 40)
            # 1 添加学生  2 修改学生  3 删除学生
            # 4 查询指定学生  5 查询所有学生  6 退出系统
            print('# 1 添加学生        #')
            print('# 2 修改学生        #')
            print('# 3 删除学生        #')
            print('# 4 查询指定学生    #')
            print('# 5 查询所有学生    #')
            print('# 6 退出系统        #')
            print('#' * 40)
```

前五项对应系统里已经写好的五个功能，第六项是"退出系统"——不做任何操作、想走的时候用。在每一行菜单文本的前后各加一个井号，与上下的分隔线保持一致，这样菜单就被两条分隔线包裹起来，相对好看一些。当然这个样式可以自由调整。

菜单打出来之后，让用户选择要做什么操作，用 `input` 接收，提示语是"请选择要执行的操作，输入 1 到 6："，用一个变量 `choice` 接收：

```python
            choice = input('请选择要执行的操作，输入 1 到 6：')
```

#### 1.3 用 match 分派功能

拿到 `choice` 之后，就根据它的值判断用户到底想添加、修改、删除还是查询学生。这里用之前学过的 `match` 语句：

```python
            match choice:
                case '1':
                    self.add_student()
                case '2':
                    self.update_student()
                case '3':
                    self.delete_student()
                case '4':
                    self.query_student()
                case '5':
                    self.list_student()
                case '6':
                    print('拜拜')
                    break
                case _:
                    print('输入错误，请选择 1 到 6 之间的菜单功能！')
```

用户输入 1，说明他想添加学生，那就调用添加学生；输入 2 是修改学生，调用 `update_student`；输入 3 是删除学生，调用 `delete_student`；输入 4 查询指定学生；输入 5 查询所有学生。

这里有一个写法上的关键点：在 `run` 方法当中想调用当前这个实例的其他方法，要通过 `self` 来调用，所以每一行都是 `self.` 加上方法名。这几个分支的写法完全一样，对齐着往下复制即可。

输入 6 代表退出系统。退出系统不需要再去调用实例对象里的哪个方法，直接 `break` 跳出当前循环就退出了系统；退出之前先输出一句"拜拜"。

如果用户输入的不在 1 到 6 之间——比如输入 0，或者输入 789——那就是其他情况。`case _` 覆盖的正是"其他情况"：输出一句"输入错误，请选择 1 到 6 之间的菜单功能！"。

> **易错点**：`case` 后面比对的必须是字符串。`input` 拿回来的永远是字符串，所以写 `case '1':` 而不是 `case 1:`——写成数字就是拿字符串和整数比较，永远匹配不上，五个功能会全部落到 `case _` 里。

```text
run 方法的循环与分派
  while True
    ├─ 输出空行 + 上下分隔线 + 六项菜单
    ├─ choice = input('请选择要执行的操作，输入 1 到 6：')
    └─ match choice
         ├─ '1' -> self.add_student()
         ├─ '2' -> self.update_student()
         ├─ '3' -> self.delete_student()
         ├─ '4' -> self.query_student()
         ├─ '5' -> self.list_student()
         ├─ '6' -> 输出"拜拜" -> break（跳出循环，系统结束）
         └─  _  -> 提示输入错误，请选择 1 到 6 之间的菜单功能
```

读图看循环体：六个 `case` 里有五个是"调用方法后回到循环顶部继续显示菜单"，只有 `case '6'` 会 `break` 跳出——所以系统能一直服务到用户主动选择退出为止。

### 5 本讲提到的题目

课程案例做完之后留了一道练习：**用面向对象的编程思想实现购物车管理系统**。

这道练习和刚做完的案例非常类似，而且此前做过——在数据容器那一章里做过一次，只不过那时还没学面向对象，用的是面向过程的编程思想；这一次要求换成面向对象的编程思想来完成。

练习包含的功能有：购物车当中商品信息的添加、修改、删除、查询，以及退出购物车。和教务管理系统对照一下就能看出对应关系：教务系统里保存的是学生信息，购物车里保存的是商品信息；商品信息包括商品的名称、商品的价格、商品的数量。

**解析**：按前面的分析方法先找业务实体——购物车里的功能（添加、修改、删除、查询、退出）属于购物车系统，而购物车里管理的是商品信息，所以参与者是商品和购物车系统，对应两个类：商品类 `Goods`，购物车类 `ShoppingCart`。

- `Goods` 是实体数据，商品名称、价格、数量都是各商品特有的数据，作为实例属性放进 `__init__`；修改自己的信息属于商品自己，可按学生类的做法提供修改方法；输出格式用 `__str__` 定好，供查询功能直接输出对象使用。
- `ShoppingCart` 对应教务系统类：保存商品的数据需要一个列表型的实例属性（类似 `student_list`），添加、修改、删除、查询、退出这五个功能作为实例方法，再加上一个 `run` 方法用 `while True` + `match` 做菜单分派。

**答案**：设计上得到 `Goods` 与 `ShoppingCart` 两个类，属性与方法的分工与教务管理系统逐一对应，把五个功能方法写完后，在 `if __name__ == '__main__':` 里创建 `ShoppingCart` 实例并调用其 `run` 方法即可运行。
