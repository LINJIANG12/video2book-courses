## 核心语法-函数基础-介绍
> 对应分集：P57 | 原始标题：《57. 核心语法-函数基础-介绍》

核心语法的前三部分已经走完：数据的存储与运算、数据的逻辑处理（流程控制语句）、数据存储容器。接下来进入第四部分——函数。

"函数"这个词在前面出现过很多次，但一直没有专门讲清楚。所以先从最基础的问题开始：到底什么是函数。

### 一、函数的定义与可复用性

> **定义**：函数是组织好的、可以重复使用的、用来实现特定功能的代码片段。

拆开来看就是三件事：它就是一段代码；这段代码实现了某个特定功能；并且它可以被重复使用。

"组织好"这三个字是关键：功能已经被提前写成一段固定的代码放在那里，不会因为用了几次而变化；"可以重复使用"则是它存在的意义——组织一次，之后用多少次都行，不必每次重新实现。

一个最直观的类比是手机。买来的手机里已经集成好了很多功能，比如打电话、发短信、拍照。想打电话，打开手机、输入对应的手机号，双方就能通话；下一次还要打电话，再输入一次手机号就行。打电话这个功能是提前组织好的，也是可以重复使用的。函数和它非常类似：功能提前组织好放在那里，需要的时候反复取用。

> **结论**：判断一段代码是不是函数，看两点就够了——它是否实现了一个特定功能，以及它是否能被重复使用。

> **易错点**：函数不是某种"高级写法"。前面写过的 `input()`、`print()` 就是函数调用，自定义函数和内置函数在使用形式上完全一致，区别只在于这段功能是谁写好的。

### 二、已在使用中的内置函数

在写入门程序、操作数据容器的时候，其实一直在使用函数：

- 要接收键盘录入，直接调用 `input`；
- 要往控制台输出数据，直接调用 `print`。

`input` 和 `print` 就是两个函数。它们要实现的功能、内部是怎么组织的，都不是我们自己写的——它们是 Python 的**内置函数**（built-in function）。

> **定义**：内置函数是 Python 底层已经提供好、在 Python 源代码中提前定义好的函数，可以重复使用，用来实现特定功能。

`input` 实现输入功能，`print` 实现输出功能：要输入就直接调用 `input`，要输出就直接调用 `print`。做数据容器操作时还用到了不少内置函数：

| 内置函数 | 作用 |
| --- | --- |
| `input` | 接收键盘录入 |
| `print` | 向控制台输出 |
| `max` | 求最大值 |
| `min` | 求最小值 |
| `len` | 获取元素个数 |
| `sum` | 求和 |

想用这些内置函数提供的功能，直接调用它们就可以了。

> **提示**：内置函数不需要自己实现，只要知道它叫什么名字、需要传什么参数、会得到什么结果，就可以直接拿来用。

从使用方式上看，内置函数和后面要自己写的函数没有区别：都是写函数名、后面跟一对小括号。真正需要花力气搞清楚的是——这些功能是怎么被"组织"到一段代码里的，以及组织好之后怎么把它取出来用。

### 三、自定义函数的必要性

回头看看前面写过的代码：接收键盘录入、向控制台输出、求最大值、求最小值、求元素个数、求和，这些动作都不是我们自己实现的，而是通过调用一个个函数完成的。也就是说，"使用函数"这件事早就在做了，只是这些函数是 Python 提前准备好的。

这一章要补上的是另外一半能力——把功能自己组织进一个函数。两者的区别可以对照着看：

| 对比项 | 内置函数 | 自定义函数 |
| --- | --- | --- |
| 来源 | Python 底层已经提供好，在源代码中提前定义 | 由我们自己编写 |
| 使用前要做的事 | 直接调用即可 | 先定义，再调用 |
| 典型例子 | `input`、`print`、`max`、`min`、`len`、`sum` | 为实现自己的功能而编写的函数 |

内置函数覆盖的是通用需求。如果要实现的是一个自定义的功能，而这个功能还想重复使用，就必须自己定义函数了。

这里有两个必须回答的问题：

1. 怎么把实现某个功能的这段代码片段封装到一个函数里；
2. 封装好之后，怎么调用这个函数。

这两个问题就是函数这一部分要解决的核心内容：先学会把一个功能装进函数，再学会把它取出来用。

## 核心语法-函数基础-函数定义
> 对应分集：P58 | 原始标题：《58. 核心语法-函数基础-函数定义》

了解了函数是什么之后，就正式进入函数这一章。函数基础要从四个方面讲，第一个问题是：如何定义一个函数。

前面课程里用过的 `input`、`print`、`max`、`min`，都是 Python 提供好的函数，拿来直接用就可以。如果要实现一个自定义的功能，而且这个功能还要重复使用，那就得自己来定义函数了。

### 一、函数定义的语法结构

定义函数要用到一个关键字 `def`，它后面依次跟上函数名、参数列表、冒号，冒号下面通过缩进书写函数体；如果函数执行完需要返回结果，就在函数体里用 `return` 指定返回值。

```python
def 函数名(参数列表):
    函数体
    return 返回值
```

各个组成部分的作用：

- **函数名**：命名规则和前面讲的标识符一致，也与变量名的规范一致——只能由数字、字母、下划线组成，数字不能开头。
- **参数列表**：指将来调用这个函数时，可以往里面传入哪些数据，就在参数列表这一处定义。
- **冒号与缩进**：冒号之后的部分是函数体逻辑，这个函数要实现什么功能，具体代码就写在函数体里；函数体前面要有缩进，用缩进来描述归属关系，告诉 Python 这些代码属于这个函数。
- **`return`**：代表函数的返回值。函数执行完如果需要把结果返回出去，就用 `return` 指定要返回的数据。

把语法拆成一张表看：

| 组成部分 | 是否必须 | 说明 |
| --- | --- | --- |
| `def` | 必须 | 定义函数的关键字 |
| 函数名 | 必须 | 遵循标识符的命名规则 |
| 参数列表 | 可选 | 说明调用时可以传入哪些数据 |
| `:` 与缩进 | 必须 | 用缩进描述函数体的归属关系 |
| `return` | 可选 | 指定函数要返回的数据 |

> **结论**：定义函数时，参数列表和返回值都是可有可无的，写不写由具体需求决定。需要就写上，不需要就不写——`return` 这句也可以完全没有。

### 二、函数调用的语法

调用函数直接写上函数名，后面跟一对小括号，括号里传入对应的参数就可以了。

```python
函数名(参数)
```

前面调用 `input`、调用 `print`，都是这样写的：直接写函数名，后面跟上对应的参数。`input` 和 `print` 就是这两个函数的名字。

先看一个最简单的例子。定义一个函数，名字叫 `out_line`，作用是输出一条分隔线（一串横线）：

```python
def out_line():
    print('------------------')
    print('------------------')
```

这里括号里没有传任何参数——这一节先不研究参数和返回值，所以没有参数就直接写一对小括号，里面什么都不写。冒号之后写函数体：这个函数要输出的横线，就是函数体里的逻辑。

> **提示**：函数体里调用 `print`，而 `print` 本身也是一个函数——在一个函数里调用另一个函数是完全正常的。

调用它只需要写函数名加一对小括号：

```python
out_line()
```

这一对小括号和定义时的那一对是对应的。因为定义时没有参数，调用时也直接跟一对空括号。这就是函数调用的语法，调用一次，函数体里的逻辑就执行一次。

```text
def out_line():                    <- 定义: 只是登记这个函数, 函数体不执行
    print('------------------')    <- 有缩进 -> 属于函数体
    print('------------------')    <- 有缩进 -> 属于函数体

out_line()                          <- 调用: 函数体执行, 输出两行横线
```

读图要点：函数体是靠缩进圈定的。如果第二行 `print` 没有缩进，那它就不属于这个函数，函数体只有一行，第二行变成独立的代码。

### 三、只定义不调用，函数不会执行

先猜一个结果：只写 `def out_line():` 加上函数体，然后运行这个文件，控制台会不会输出那两行横线？

直接运行的结果是：控制台没有任何输出。文件确实运行了，但什么也没打印出来。

原因在于：函数光定义是不会执行的。

> **结论**：函数定义的时候并不会运行；只有在调用函数的时候，函数体里的逻辑才会执行。

在定义下面写上调用语句，再次运行，横线才输出出来：

```python
def out_line():
    print('------------------')
    print('------------------')

out_line()      # 调用之后, 函数体执行
```

### 四、必须先定义后调用

函数的使用顺序是固定的：必须先定义，后调用。

原因在 Python 解释器的工作方式上——它从上往下解释执行代码。如果把调用的代码写到定义前面：

```text
out_line()                <- 解释器走到这里, 当前还没有 out_line 这个函数 -> 立即报错

def out_line():
    print('------------------')
```

编辑工具会提示"未解析出引用"，运行时会报名字 `out_line` is not defined，也就是未定义：走到调用那一行时，这个函数还不存在。

把调用挪到定义之后，问题就消失了：上面已经把函数定义好了，下面再调用就是理所当然的事。

> **易错点**：不要指望解释器先扫一遍整个文件再执行。函数一定是先定义、后调用。

### 五、把重复的逻辑封装起来

函数一旦定义好，以后想用就直接调用，想调用几次就调用几次。比如连续调用三次：

```python
def out_line():
    print('------------------')
    print('------------------')

out_line()
out_line()
out_line()
```

运行结果是六行横线——因为每调用一次 `out_line`，就会输出两行横线。

这就是把重复性逻辑封装到函数里的意义：重复的代码只写一遍，放在函数体里；以后要用这段逻辑，直接调用函数就行，不必把那段代码再抄一遍。

### 六、函数定义与调用的三条要点

1. **先定义，后调用**。顺序颠倒会直接报错，因为解释器从上往下执行。
2. **定义时不执行**。只写定义、不写调用，函数体里的 `print` 不会输出；函数只有在被调用时，函数体里的逻辑才会执行。
3. **缩进描述归属关系**。函数体有多行逻辑时，每一行前面都要有对应的缩进，这样它们才属于这个函数。

语法上要记住的只有两件事：定义用 `def` 关键字，`def` 后面跟函数名，函数名的命名规则就是标识符的命名规则；调用则直接通过函数名加一对小括号完成。

## 核心语法-函数基础-函数参数与返回值
> 对应分集：P59 | 原始标题：《59. 核心语法-函数基础-函数参数与返回值》

掌握了函数定义的基础语法之后，接下来要弄清楚的是：定义函数时涉及的参数与返回值。

定义函数时可以完全按业务需求来指定这两样东西——需要从外面接收数据，就在括号里写参数列表；执行完需要把结果交出去，就在函数体末尾写 `return`。

### 一、参数与返回值的声明位置

```python
def 函数名(参数列表):
    函数体
    return 返回值
```

- 要设置参数：在定义函数时，在括号里跟上对应的参数列表；
- 要设置返回值：函数执行完如果有返回结果，就在函数体里跟上一个语句 `return`，后面跟上具体的返回值。

> **易错点**：`return` 语句必须出现在函数体的最后一行。一旦执行到 `return`，就代表这个函数走到这里结束了、已经返回了，`return` 之后的函数体代码不会被执行。

所以写 `return` 的时候要确认：它下面已经没有任何还需要执行的逻辑了。

### 二、单参数、单返回值：圆的面积

要做一个"根据半径计算圆的面积"的函数。面积和半径有关系，所以计算时得把半径传进来——把半径作为参数接收。

```python
def circle_area(r):
    area = 3.14 * r ** 2
    return area
```

- 括号里的 `r` 就类似于定义了一个变量，它接收到的就是圆的半径；
- 函数体里计算 $\pi r^2$，也就是 `3.14 * r ** 2`；写成 `3.14 * r * r` 效果一样，都是半径的平方乘以 π；
- 算完之后要把结果返回回去，所以写上 `return area`。也可以不声明中间变量，直接 `return 3.14 * r ** 2`，效果相同。

调用它，计算半径为 10 的圆的面积：

```python
area = circle_area(10)
print(area)
```

调用时传入的 10 就是实参，它会按位置传递给形参 `r`，于是 `r` 的值变成 10。函数体里算出 $3.14 \times 10^2 = 3.14 \times 100 = 314.0$，再把这个面积返回。

函数调用的结果是有返回值的，所以可以用一个变量接到它，再打印出来：

```text
调用:  circle_area(10)
              |
              |  10 按位置传给形参 r
              v
定义:  def circle_area(r):
            area = 3.14 * r ** 2     <- 此时 r 的值是 10
            return area              <- 把计算结果返回给调用处

调用处:  area = circle_area(10)      <- 用变量接住返回值
```

读图要点：数据从调用处的括号进、从 `return` 出，形参 `r` 是函数内部接收这个值的入口。

> **易错点**：如果只写 `circle_area(10)` 而不接收、不打印，控制台不会出现任何输出。`return` 只负责把结果返回，不负责打印。

### 三、多个参数：长方形的面积

再定义一个计算长方形面积的函数。长方形的面积要由长和宽决定——长是一个数据，宽是一个数据，所以涉及两个参数。

```python
def rectangle_area(l, w):
    return l * w
```

- 多个参数之间用**逗号分割**，这里 `l` 代表长、`w` 代表宽，中间用逗号隔开；
- 函数体里用长乘宽，就得到了长方形的面积。

调用时同样要按顺序把长和宽传进去：

```python
print(rectangle_area(20, 10))
```

长 20、宽 10，结果是 200。

接收返回值有两种写法：既可以在前面用一个变量接住返回值再输出，也可以直接把函数调用的结果放进 `print` 里输出——因为这个函数是有返回值的，返回值可以直接参与打印。

> **提示**：函数名和变量名建议起得专业一些，做到见名知意，一般用英文单词，多个单词之间用下划线分割。`circle_area` 就是"圆的面积"，`rectangle_area` 就是"长方形的面积"。遇到不确定的英文单词，查一下翻译工具再命名，这在项目开发中是值得推荐的做法。

### 四、return 与 print 的分工

调用上面这些函数时，控制台一开始什么都没有，原因很简单：代码里根本没有 `print`。

> **结论**：`return` 只有返回的功能，没有打印的功能。要把结果输出到控制台，必须自己调用 `print`。

判断一段代码会不会有输出，就看有没有 `print` 语句。想看到计算结果，就先用变量接收执行结果，再调用 `print` 把结果输出出来。这两件事一定要区分开：返回是返回，打印是打印。

### 五、形参与实参

参数其实有两种身份，分别出现在定义处和调用处。

> **定义**：定义函数时在括号里指定的参数叫**形参**（形式参数，简称形参）；调用函数时实际传入的参数叫**实参**。

形参 `r`、`l`、`w` 其实就相当于变量名，而且它们只能在函数内部使用。出了这个函数，就不能再用 `l`、`w` 了——这种只能在函数内部使用的变量叫**局部变量**，变量的作用域后面会详细展开，这里先记住：形参的作用范围仅限于函数内部。

实参则决定了函数的运算结果：实际传进去什么值，函数就用什么值去计算。

| 对比项 | 形参 | 实参 |
| --- | --- | --- |
| 出现位置 | 函数定义的括号内 | 函数调用的括号内 |
| 别名 | 形式参数 | 实际传入的参数 |
| 作用 | 接收调用时传入的数据 | 提供实际参与运算的数据 |
| 生效范围 | 只在函数内部，属于局部变量 | 在调用处按位置一一对应 |
| 个数与顺序 | 决定调用时必须传几个、按什么顺序传 | 必须与形参的数量、顺序一致 |

> **易错点**：调用时实参的顺序必须和形参的顺序保持一致。形参第一个是长、第二个是宽，实参第一个也得是长、第二个也得是宽。传参时第一个值给第一个形参，第二个值给第二个形参。

### 六、多个返回值与元组封装

函数可以有多个参数，也可以有多个返回值。

以"计算圆的面积和周长"为例：圆的面积和圆的周长都只依赖一个参数——半径。面积是 $\pi r^2$，周长是 $2\pi r$，要同时把这两个结果返回，用逗号分割就行。

```python
def circle_area_len(r):
    return 3.14 * r * r, 2 * 3.14 * r
```

返回值有多个时，多个返回值之间用逗号分割，前面加上 `return` 直接返回即可——不需要先在函数体里定义两个变量接收计算结果、再把两个变量返回。

调用它并用一个变量接收结果：

```python
result = circle_area_len(10)
print(result)
```

得到的是被一对小括号括起来的两个值。括号括起来的多个元素是什么？就是前面讲过的**元组**。用 `type` 确认一下：

```python
print(type(result))
```

输出 `<class 'tuple'>`。

> **结论**：函数返回多个值时，多个返回值会一起封装到一个元组（tuple）之中。

```text
return 3.14 * r * r, 2 * 3.14 * r
          |              |
       第一个值        第二个值
          |              |
          +------+-------+
                 v
        自动封装成元组 (面积, 周长)
```

读图要点：逗号把两个返回值拼成了一个元组，所以调用处只用一个变量就能接住全部结果。

由于涉及小数的运算，结果可能存在精度损失。想一次就分别拿到面积和周长，不需要自己去元组里一个一个取元素——直接用前面讲过的**解包**：

```python
area, perimeter = circle_area_len(10)
print(area, perimeter)
```

函数调用的结果封装在元组里，元组里有两个元素，第一个是面积、第二个是周长。赋值时第一个元素赋给 `area`，第二个赋给 `perimeter`，这就完成了解包。

> **提示**：接收周长的变量不要起名 `len`——`len` 是 Python 内置函数的名字，同名会把内置函数遮蔽掉。写成 `perimeter` 或 `c` 更清楚。

### 七、用 round 控制小数位数

小数运算带来的精度损失，可以用保留小数位数的方式解决。

`round` 是 Python 的内置函数，可以直接使用，它做的是四舍五入：

```python
round(数字, 小数位数)
```

- 第一个参数：要对哪个数字做四舍五入；
- 第二个参数：保留几位小数。

把它套在计算结果外面，就得到保留一位小数的返回值：

```python
def circle_area_len(r):
    return round(3.14 * r * r, 1), round(2 * 3.14 * r, 1)


area, perimeter = circle_area_len(10)
print(area, perimeter)
```

两个返回值都保留了一位小数，面积输出 314.0，周长输出 62.8。

> **结论**：有参数、有返回值的函数，参数写在定义时的括号里，多个参数用逗号分割；调用时按顺序把实参传进去，并且要记得接收返回值。函数可以有多个返回值，多个返回值之间用逗号分割，最终会自动封装成一个元组，也可以用解包的方式分别接收。这些知识要活学活用。

## 核心语法-函数基础-函数说明文档
> 对应分集：P60 | 原始标题：《60. 核心语法-函数基础-函数说明文档》

前面已经定义了几个函数：一个用来计算长方形的面积，一个用来计算圆的面积和周长。

现在反过来看这些函数：`l` 代表什么意思？`w` 代表什么意思？返回值代表什么意思？`r` 和那两个返回值又分别代表什么意思？刚刚讲完十多分钟，这些还能答得上来。

但如果这个函数不是自己写的，而是项目开发中别人定义好的，代码就是那么几行、里面没有任何解释说明，你还能清楚地知道每个参数是什么意思、两个返回值分别代表什么吗？其实并不能。这样的代码对使用者非常不友好：难以理解，也难以维护。

要解决这个问题，让函数的参数、返回值以及它到底实现什么功能都一目了然，就要靠函数的**说明文档**。

### 一、说明文档的位置与内容

> **定义**：函数的说明文档写在函数体的最前面，用三引号包裹，用来解释这个函数的功能、它涉及到的参数以及它的返回值。

- **位置**：定义函数时，写在函数体的最开头，也就是函数体的第一行；
- **写法**：使用三引号包裹——前面讲多行注释用的就是三引号，写在函数里的三引号就是对这个函数的解释说明，所以叫函数的说明文档；
- **内容**：三部分，函数的功能是什么、参数的含义是什么、返回值的含义是什么。

以"根据圆的半径计算圆的面积和周长"为例：

- 最上面这句话描述函数的功能——根据圆的半径来计算圆的面积和周长；
- 下面的 `:param` 是对参数做解释说明，后面跟参数名。`:param r:` 说明 `r` 这个参数指的是圆的半径；
- 再下面的 `:return:` 用来描述返回值。这个函数有两个返回值，第一个是圆的面积，第二个是圆的周长。

```text
函数说明文档的三段内容:

    <功能描述>             <- 第一行, 说明这个函数做什么
    :param <形参名>: 说明   <- 有几个形参就写几段
    :return: 说明           <- 有 return 才写, 描述返回值含义
```

读图要点：功能在最上面一句话写完；参数和返回值各用带冒号的关键字开头，一个参数一段，多个返回值在 `:return:` 后面依次说清。

### 二、在 PyCharm 中写说明文档

在函数体的第一行直接敲三个引号，回车之后开发工具会自动生成模板：

- 上面先留一个空行，让你编写这个函数的作用，也就是函数实现了什么样的功能；
- 接着生成 `:param <参数名>`——为什么这里有两个 `:param`？因为这个函数有两个参数 `l` 和 `w`，一个参数一段，分别说明它们代表什么含义；
- 由于这个函数里有 `return`，所以还会生成一段 `:return`，让你说明返回值代表什么意思。

按生成的模板填完，长方形的面积函数就成了这样：

```python
def rectangle_area(l, w):
    """
    根据长方形的长度和宽度计算长方形的面积
    :param l: 长方形的长度
    :param w: 长方形的宽度
    :return: 长方形的面积
    """
    return l * w
```

再用同样的步骤给圆的面积与周长函数加上说明文档：

```python
def circle_area_len(r):
    """
    根据圆的半径计算圆的面积和周长
    :param r: 圆的半径
    :return: 第一个值是圆的面积, 第二个值是圆的周长
    """
    return 3.14 * r * r, 2 * 3.14 * r
```

这个函数只有一个参数，所以生成的 `:param` 只有一段；返回值有两个，就在 `:return:` 里把两个值的含义分别写清楚。

> **提示**：自动生成的模板只负责摆好格式，真正有价值的是里面写的文字。参数的含义、返回值的含义要写得具体，写"半径""长度""宽度"这种准确的说法，而不是重复一遍参数名。

### 三、查看说明文档的三种方式

别人要调用这个函数时，想知道它的功能和参数、返回值的含义，可以用以下几种方式：

| 方式 | 操作 | 说明 |
| --- | --- | --- |
| 直接看源码 | 找到函数定义的那段代码 | 最直接，说明文档全文就在里面 |
| `help` 函数 | `help(rectangle_area)` | Python 提供的内置函数，用来查看函数的帮助文档、说明文档 |
| 编辑工具悬浮提示 | 把鼠标放在函数名上 | 开发工具自动弹出这个函数的作用以及参数、返回值的含义，最常用 |

`help` 的用法是把函数名传进去：

```python
help(rectangle_area)
```

执行后会输出这个函数的说明文档，于是就能清楚地知道这个函数实现了什么功能、每一个参数和每一个返回值代表什么含义。

> **易错点**：`help` 后面传入函数名时不要加括号。加括号就是调用函数了；只是想查看说明文档，直接把函数名放进去执行 `help` 就行。

不过 `help` 这种查看方式并不常用。更常用的是鼠标悬浮：在调用这个函数的地方把鼠标往函数名上一放，开发工具就会显示函数实现的功能、形参代表什么意思、返回值代表什么意思——显示的就是写在说明文档里的那几条信息，由 IDE 自动提示出来。

### 四、说明文档与项目维护

如果每个函数都按规范写上对应的说明文档，项目后期维护起来会容易得多，别人调用这些函数时也很容易理解、容易读懂，是非常友好的做法。

> **结论**：好的文档一定让代码更容易理解、更容易使用，也更便于后期的维护。

所以在进行项目开发时，自己定义的函数要尽可能都加上详细的说明文档，这既方便别人，也方便过一段时间之后的自己。

### 五、内置函数的说明文档

Python 底层定义的内置函数同样带说明文档，可以直接去看。

按住键盘上的 Ctrl 键，把鼠标放在 `print` 上点一下，就进入了 `print` 作为内置函数的定义处，能清楚地看到它里面用三引号写着的说明文档。在这个位置还能看到很多其它的内置函数，它们也都有对应的说明文档。

> **提示**：看不准某个内置函数怎么用的时候，按住 Ctrl 点进去读它的说明文档，比凭印象猜参数可靠得多。

## 核心语法-函数基础-函数嵌套调用
> 对应分集：P61 | 原始标题：《61. 核心语法-函数基础-函数嵌套调用》

函数的定义和调用的基本语法讲完之后，下一个问题是：一个函数里面能不能再调用另一个函数？当然可以，而且这件事一发生，代码的执行顺序就不再是「从上往下、一行接一行」那么简单了。这一节要解决的就是：A 调用 B、B 又调用 C 的时候，代码到底按什么顺序跑，跑完之后又怎么回到原来的位置。

> **定义**：在一个函数的函数体当中调用另外一个函数，这种写法就叫**嵌套调用**。

### 嵌套调用的结构

先看一段最简单的例子：定义三个函数 `function_a`、`function_b`、`function_c`，然后在 `function_a` 里面调用 `function_b`，在 `function_b` 里面调用 `function_c`。

```python
def function_a():
    print("a before")
    function_b()
    print("a after")


def function_b():
    print("b before")
    function_c()
    print("b after")


def function_c():
    print("c...")


function_a()
print("函数调用完毕")
```

先说一件最容易被忽略的事：这三个函数**定义的时候都不会执行**，函数体里的逻辑只有在被调用的时候才会跑。所以真正决定执行顺序的，是最后那两行——先是 `function_a()`，再是 `print("函数调用完毕")`。

一旦调用了 `function_a`，就进入它的函数体：先输出 `a before`，紧接着调用了 `function_b`，那么执行流就走到 `function_b` 里去执行它的函数体。`function_b` 里先输出 `b before`，紧接着又调用了 `function_c`，执行流再走到 `function_c` 里，输出 `c...`。

A 里面调用 B，B 里面调用 C——这就是嵌套调用。这一节要研究的核心，就是这种结构下代码的执行顺序和函数的执行流程。

### 函数调用遵循栈结构

函数调用的过程遵循**栈（stack）结构**。栈本身是一种数据结构，它最大的特点就是 LIFO。

> **定义**：LIFO 是 **Last In First Out** 的缩写，即**后进先出**；换个说法就是**先进的后出**。

栈的另一个特点是：操作只能从一端进行，也就是从栈的**顶部**这一端。往栈里存一个数据的操作叫**入栈**，从栈里删除一个元素的操作叫**出栈**。入栈只从顶部进，出栈也只从顶部出，所以最后进来的元素会最先出去。

```text
        ┌──────────────┐
 入栈 → │              │ ← 栈顶（只能在这一端操作）
        │              │
        │              │
        │              │
        └──────────────┘
             栈底
```

图中标出的是栈的两个关键位置：数据只能从栈顶进出，栈底那一端动不了，这决定了「后进先出」这个性质。

### 嵌套调用的执行流程

以刚才那段代码为例，把每一步的栈状态拆开看。

**第一步**：调用 `function_a`，`function_a` 入栈，位于栈顶。程序在执行的时候，永远执行的是栈顶这块的代码，所以接下来执行的就是 `function_a` 里的逻辑：先输出 `a before`，紧接着调用 `function_b`。

```text
   ┌──────────────┐
   │  function_a  │ ← 栈顶：正在执行的函数
   └──────────────┘
```

**第二步**：调用 `function_b`，`function_b` 入栈，进到栈的顶端，压住了 `function_a`。于是转而执行 `function_b` 的逻辑：输出 `b before`，紧接着调用 `function_c`。

```text
   ┌──────────────┐
   │  function_b  │ ← 栈顶：正在执行的函数
   ├──────────────┤
   │  function_a  │
   └──────────────┘
```

**第三步**：调用 `function_c`，`function_c` 入栈并处于栈顶，执行它的逻辑。`function_c` 里面很简单，就是输出 `c...`。

```text
   ┌──────────────┐
   │  function_c  │ ← 栈顶：正在执行的函数
   ├──────────────┤
   │  function_b  │
   ├──────────────┤
   │  function_a  │
   └──────────────┘
```

**第四步**：`c...` 打印完，`function_c` 的逻辑就执行完了，这次函数调用结束，`function_c` **出栈**。出栈之后，`function_b` 重新变成栈顶元素。

这里要特别留意：回到 `function_b` 之后，执行的**不是** `function_b` 的第一行，而是刚才调用 `function_c` 那一行**之后**的部分，也就是输出 `b after`。`function_b` 执行完毕——如果有返回值就把返回值返回，没有返回值就走到这里结束——然后 `function_b` 出栈，`function_a` 变成栈顶。

**第五步**：继续执行 `function_b` 之后的 `function_a` 的部分，输出 `a after`。如果 `function_a` 有返回值就把返回值返回，没有就结束，然后 `function_a` 出栈。整个函数调用完毕，这块栈空间也就释放了。

```text
   ┌──────────────┐
   │              │
   ├──────────────┤
   │              │
   ├──────────────┤
   │              │
   └──────────────┘
     栈空间释放
```

> **结论**：嵌套调用遵循栈结构，最大的特点就是后进先出。完整输出顺序是 `a before` → `b before` → `c...` → `b after` → `a after` → `函数调用完毕`。

### 弹夹类比

栈结构跟日常生活里的弹夹非常像。手枪弹夹只能从一端操作：要往里压子弹，以及从里面弹出子弹，都只能在这一端进行。而且最先压进去的那颗子弹最后才会打出来，最后压进去的那颗子弹最先打出来——这就是弹夹和栈结构类似的地方。

> **提示**：调试「执行到哪一行、栈里有什么」这类问题时，在函数体第一行打断点比反复按 `F7` 更稳妥，尤其是函数调用层级比较深的时候。

断点打好后，在左侧点击线程和变量，那个面板展示的正是刚才说的栈结构。

| 步骤 | 操作 | 栈状态（自顶向下） | 控制台输出 |
| --- | --- | --- | --- |
| 0 | 停在第 70 行断点 | `70 行代码`（还没有函数入栈） | 空 |
| 1 | 按 `F8` 走一步 | `function_a` → `70 行代码` | 空 |
| 2 | 按 `F8` 走一步 | `function_a`（正执行 `a before`） | `a before` |
| 3 | 按 `F8` 走一步 | `function_b` → `function_a` → `70 行` | `a before` |
| 4 | 按 `F8` 走一步 | `function_b`（正执行 `b before`） | `a before`、`b before` |
| 5 | 按 `F8` 走一步 | `function_c` → `function_b` → `function_a` → `70 行` | `a before`、`b before` |
| 6 | 取消 `function_c` 里的断点再走一步 | `function_c` 出栈，`function_b` 回到栈顶 | 追加 `c...` |
| 7 | 按 `F8` 走一步 | `function_b` 出栈，`function_a` 回到栈顶 | 追加 `b after` |
| 8 | 按 `F8` 走一步 | `function_a` 出栈，回到第 70 行代码 | 追加 `a after` |
| 9 | 继续执行 | 栈空，函数调用完毕 | 追加 `函数调用完毕` |

第一次停在断点时，栈顶显示的是第 70 行这一块代码，因为是在这里调用的 `function_a`。往下走一步之后，`function_a` 就进入栈顶——栈顶的函数就是正在执行的函数。再走一步，`a before` 输出到控制台；紧接着要调用 `function_b`，`function_b` 入栈位于栈顶，`function_a` 就被压到了下面。

`function_b` 里先输出 `b before`，再调用 `function_c`，`function_c` 入栈来到栈顶。往下走一步 `function_c` 的逻辑就执行完了，它出栈——注意看，`function_c` 出栈之后，紧接着执行的是后面那一行代码，那一行执行完 `function_b` 也就出栈了。`function_b` 执行完，再往下走就是 `function_a` 里 `function_b` 调用之后的代码，执行完 `function_a` 也出栈，最后执行下面那一块的逻辑，整个函数调用完毕。

左侧栈面板里看到的入栈、出栈、栈顶切换，跟我们前面推导的流程完全一致。

把断点全部取消，再直接运行一次，结果就一目了然：先执行 `a before`；`a before` 执行完去调用 `function_b`，于是输出 `b before`；`b before` 执行完去调用 `function_c`，输出 `c...`；`c` 执行完回来执行 `function_b` 里剩下的部分，输出 `b after`；`function_b` 整个执行完，再执行 `function_a` 后面的部分，输出 `a after`；整个 `function_a` 调用完，最后继续往下运行，输出 `函数调用完毕`。

```text
控制台输出
────────────────
a before
b before
c...
b after
a after
函数调用完毕
```

> **易错点**：嵌套调用里最容易搞错的就是「回来以后从哪继续」。函数出栈后，执行的是**调用点在上一层函数里的下一行**，而不是上一层函数的第一行。调试时对照栈面板，一眼就能看出当前该执行谁的代码。

## 核心语法-函数基础-案例
> 对应分集：P62 | 原始标题：《62. 核心语法-函数基础-案例》

函数的定义、参数和返回值这些基础语法讲完之后，接下来要做的就是动手。这一节用三个案例来巩固函数的基础语法：一个练「传参 + 返回值」，一个练「循环 + 条件判断 + 返回位置」，一个练「多返回值」。三个需求都不难，但每个都埋着一个值得记住的点。

### 三个需求

需求一是定义一个函数，根据传入的底和高计算三角形的面积。三角形面积的计算公式是底乘以高再除以 2。这个需求跟前面写的计算圆面积、计算长方形面积是同一类思路。

需求二是定义一个函数，根据传入的字符串统计其中元音字母的个数。元音字母一共五个：`a`、`e`、`i`、`o`、`u`。这里有个前提不要漏掉——小写的元音字母要统计，**大写的元音字母也要统计**。

需求三是定义一个函数，根据传入的班级学员高考成绩的列表计算最高分、最低分和平均分。注意传进来的是一个**列表**。另外要求里明确说了：平均分可能算出小数，只保留一位小数。

在 PyCharm 里新建一个单独的 Python 文件，把这三个需求写在文件顶部，然后一个一个实现。

### 需求一：计算三角形面积

#### 函数名与形参的确定

先得给这个函数起名字。三角形用英文怎么说？直接打开百度翻译查一下：三角形是 `triangle`。

函数名就定为 `triangle_area`，用 `def` 定义。接下来指定形参：需要传入的是三角形的底和高，底用 `b` 表示，高用 `h` 表示（`h` 就是 height 的意思，代表高度）。形参名你随便写，只要自己认得就行。

函数体里要做的就是按公式算面积并返回，所以来一个 `return`：底乘以高再除以 2。

#### 说明文档

顺手把这个函数的说明文档补上。在函数体第一行写三个引号然后回车，结构就自动出来了。

```python
def triangle_area(b, h):
    """
    根据传入的底和高来计算三角形的面积
    :param b: 三角形的底长
    :param h: 三角形的高
    :return: 三角形的面积
    """
    return b * h / 2


print("底长为 30，高度为 20 的三角形面积为：", triangle_area(30, 20))
```

说明文档里三行描述分别是：这个函数根据传入的底和高来计算三角形的面积；`b` 是三角形的底长，`h` 是三角形的高；`return` 返回回来的就是三角形的面积。

#### 调用与结果

下面调用 `triangle_area`，传入底 30、高 20，把返回值直接输出出来。运行结果是 300。第一个需求搞定——按公式 $S = \frac{1}{2}bh$ 算，$30 \times 20 \div 2 = 300$，没问题。

### 需求二：统计字符串中的元音字母个数

#### 函数名与思路

第二个函数是统计元音字母个数。要获取的是元音字母的个数，所以叫 `count_aeiou` 比较直观——`count` 是统计，后面跟上那五个元音字母。参数就是传入的字符串，命名为 `s`。

在写代码之前先想清楚思路：要统计一个字符串里元音字母出现的次数，就得把字符串里一个一个的字符都取出来，再判断这个字符是否出现在 `aeiou` 里面。因为大小写都要统计，所以判断用的候选集合应该是 `aeiouAEIOU` 这 10 个字符。

要逐个取出字符，就得在这个函数里**循环遍历**这个字符串。

#### 函数体实现

```python
def count_aeiou(s):
    """
    统计字符串中元音字母的个数
    :param s: 具体的字符串
    :return: 元音字母的个数
    """
    number = 0
    for w in s:
        if w in "aeiouAEIOU":
            number += 1
    return number


print(count_aeiou("hello python hello world OK"))
```

用 `for w in s` 循环遍历字符串，每轮拿到的 `w` 就是字符串里的一个字母。

在循环之前先定义一个变量记录数量，初始值为 0。循环里判断 `w in "aeiouAEIOU"`：如果遍历出来的元素在这个集合里，说明这个 `w` 就是元音字母，让 `number` 加 1；如果不是元音字母，就继续遍历下一个元素再判断，直到遍历结束。遍历结束后再把 `number` 返回。

#### return 的位置与缩进

这里有一个非常容易写错的地方，要单独拎出来说。

```python
def count_aeiou(s):
    number = 0
    for w in s:
        if w in "aeiouAEIOU":
            number += 1
            return number     # 缩进进了 if：统计到第一个元音字母就返回了
```

> **易错点**：`return` 不能写在 `if` 里面。写成上面那样，只要统计到一个元音字母、进入了 `if` 判断，函数就立刻返回了，后面的元素还没遍历完。`return` 必须写在**循环全部结束之后**，并且缩进要和 `for` 循环**平级**——也就是回到 `for` 那一层的缩进，紧跟在循环体之后。

#### 验证结果

定义好函数后补上说明文档，然后调用 `count_aeiou`，传入 `hello python hello world`。程序算出来的个数可以跟人肉数出来的对照一下：`hello` 里有 `e`、`o` 两个，`python` 里有 `o` 一个，`hello` 再两个，`world` 里 `o` 一个，合起来 6 个。

再往字符串后面追加一个 `OK`，这个 `O` 是大写，但它同样属于元音字母，所以总数应该是 7。运行程序，输出 7，对上了。

### 需求三：统计成绩的最高分、最低分与平均分

#### 形参与返回值设计

第三个函数计算高考分数，命名为 `calc_score`。需求已经明确要传入班级学员高考成绩的列表，所以形参就是这个列表，叫 `score_list`。

这里面要统计最低分、最高分以及平均分，并且返回。数一数有几个返回结果——三个。多个返回值之间用逗号分割就行。

#### 三个值的算法

```python
def calc_score(score_list):
    """
    计算成绩的最高分、最低分以及平均分
    :param score_list: 分数列表
    :return: 最高分、最低分、平均分
    """
    max_s = max(score_list)
    min_s = min(score_list)
    avg_s = round(sum(score_list) / len(score_list), 1)
    return max_s, min_s, avg_s


s_list = [589, 609, 605, 643, 677, 455, 477, 489, 503]
max_score, min_score, avg_score = calc_score(s_list)
print("最高分：", max_score)
print("最低分：", min_score)
print("平均分：", avg_score)
```

最高分就是列表当中元素的最大值，可以调用 Python 内置的函数 `max` 获取。最低分同理，调用内置函数 `min`。

平均分是把列表当中的分数累加起来，再除以列表当中元素的个数。要保留一位小数，可以调用内置函数 `round`，后面写 1，就代表保留一位小数。

这三个值想返回，用逗号分割就 OK。当然，如果不想定义中间的变量，也可以把表达式直接写进 `return` 里；这里分开写是为了读起来清楚。

> **提示**：在 PyCharm 里按住 `Ctrl` 键点击 `max`，会进入它的源码，可以看到里面确实是一个 `def` 定义的函数，具体作用在它的说明文档里写得清清楚楚，只不过文档是英文的。而函数体看起来是空的——因为 Python 底层的这些内置函数并不是用 Python 语言开发的，而是用 C 语言开发的，所以在 Python 源码里看不到具体实现。

#### 多返回值与元组解包

定义好之后做一个测试，先把班级的学员成绩列表准备好：589、609、605、643、677、455、477、489、503。这份成绩单里还有个学渣——455 分。

```python
s_list = [589, 609, 605, 643, 677, 455, 477, 489, 503]
```

调用 `calc_score` 把这个列表传进去。函数调用完毕之后有三个返回值，而这多个返回值会自动封装到一个**元组**当中，所以可以用三个变量来接收、进行解包：`max_score`、`min_score`、`avg_score`，分别对应最高分、最低分、平均分，顺序要跟 `return` 里的顺序对应上——第一个是最高分，第二个是最低分，第三个是平均分，元组里就这三个元素。

然后分别输出：最高分是多少、最低分是多少、平均分是多少。

#### 运行结果

运行结果：最高分 677 分，没问题；最低分 455 分，也没问题；平均分 560.8——保留了一位小数。

> **提示**：`round` 的保留是指定位数的舍入，无论除得尽还是除不尽，最终都会保留这一位小数。平均值的数学定义是 $\bar{x} = \frac{1}{n}\sum_{i=1}^{n} x_i$，这里 $n=9$、总分 5047，所以是 560.8。
