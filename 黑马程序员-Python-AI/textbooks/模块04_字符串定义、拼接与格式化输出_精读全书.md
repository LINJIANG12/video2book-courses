## 第 1 章：核心语法-数据存储与运算-字符串定义
> 对应分集：P14 | 原始标题：《14. 核心语法-数据存储与运算-字符串定义》

上一小节把五种基础数据类型过了一遍：整数、浮点数、字符串、布尔和空值。认识了这一圈之后，接下来就该挑其中一个细细剖析——这次是字符串。

我们从入门程序打印 Hello World 开始，到讲字面量，再到上一小节讲基础数据类型，一直挂在嘴上的一句话是：字符串需要用引号引起，所有以引号引起的数据都是字符串。可 Python 里字符串的表现形式并不止一种，现在就把它们逐个剖开。

### 1. 三种字符串定义方式

关于字符串的定义方式，一共有三种。

第一种是入门程序里打印 Hello World 时用的双引号，双引号引起来的就是字符串；第二种是把双引号换成单引号，也就是单引号定义法；第三种是三引号定义法——三个引号作为开始，三个引号作为结束，中间放的就是字符串的具体内容。

```python
s1 = "Hello"       # 双引号定义方式
s2 = 'Python'      # 单引号定义方式
s3 = """Hello
欢迎大家进入到Python课程的学习
	一键三连哟~
"""                # 三引号定义法，可定义多行字符串
```

前两种方式敲法上有个小差别：敲双引号要按住 Shift 再按引号键，敲单引号直接按引号键就行，不按 Shift 敲出来的就是单引号。

真正拉开差距的是换行能力。三引号定义的字符串支持换行，可以定义多行字符串；而单引号和双引号定义的字符串不能直接换行。

> **易错点**：双引号或单引号定义的字符串，写在一行里就必须在一行里结束。想让它跨行显示，只能靠字符串拼接（下一小节讲）或者用三引号。

如果在双引号里硬按回车换行，PyCharm 这个开发工具会很智能地处理：它并不是让这一个字符串换了行，而是把它变成了两个字符串，再把两个字符串拼接在一起。回头看引号就能明白——开始引号和结束引号之间的内容是不允许断行的。

三引号这一点上要注意选哪种引号：单引号凑三个也行，但建议用双引号凑三引号，因为这是官方推荐的方式。

### 2. 字符是组成字符串的基本单位

字符串里每一个字，我们都称之为一个字符。

字符是文本世界当中的基本单位，也是组成字符串的基本单位。为什么叫“字符串”？把多个字符连在一起，就组成一个字符串。所以在字符串里看到的每一个字母、每一个汉字、每一个符号，包括每一个数字，其实都是一个字符。

> **定义**：字符是文本世界中的基本单位，也是组成字符串的基本单位。

### 3. 三引号定义字符串的格式保留

三引号定义字符串时，写进去什么样，输出就原封不动是什么样——包括里面的换行，也包括用 Tab 键做出来的缩进，都会照样输出。

```python
s3 = """Hello
欢迎大家进入到Python课程的学习
	一键三连哟~
"""
print(s3)
```

这段字符串会分三行输出：Hello 一行，欢迎那句一行，最后一行一行。第一行位置是一个空行，里面并没有内容；Hello 是顶着最前面写的；“欢迎大家进入到 Python 课程的学习”前面有缩进，那是编写时按下的 Tab 键，原封不动地输出了；下面那行同样原封不动。

```text
"""Hello                      <- 开始的三引号之后立刻回车，形成开头空行
Welcome to the Python course  <- 顶格书写，输出也顶格
<Tab>keep going~              <- 编写时的 Tab 缩进被原样保留
"""                           <- 结束的三引号
```

读图看三引号的两条规则：起止引号之间的换行全部保留，行首的 Tab 缩进也全部保留，解释器不会自动整理格式。

顺便把三个变量都用 `type` 查一遍，确认它们到底是不是字符串类型：

```python
print(type(s1))
print(type(s2))
print(type(s3))
```

运行结果是 s1、s2、s3 全都是 string 类型，都是字符串。顺带一个提效小技巧：写完 `print(s1)` 之后编辑器会提示你要不要接着输出 s2 和 s3，按 Tab 键就能补全，这个键在 PyCharm 里就是补全键。

> **易错点**：三引号字符串结尾的那行说明，别顺手挪到字符串内部去。写在开始引号和结束引号之间，它就是字符串内容的一部分，不再是注释；要写成注释，必须放在这一行代码的结尾。

### 4. 引号嵌套冲突与转义字符

前面定义的字符串内容都比较简单，换一段稍微特殊的：内容是英文，而英文里经常有缩写，比如 `It's very good`。

这句里的单引号是 It is 缩写之后加上的。如果用单引号定义法，把它往里一放就出问题了：这个单引号会和最开始的引号配成一对，于是 `'It'` 成为一个字符串，后面的内容成了多余的部分，程序报错。

```python
msg = 'It's very good'      # 报错：内层单引号与起始单引号提前配对
```

结论是：用单引号定义字符串时，字符串里不能再出现单引号。

解决办法是转义字符，写法就是在前面加一个反斜线。加上反斜线之后，这个单引号就只是字符串本身的单引号，不再是字符串的开始或结束引号——它表示引号本身。

```python
msg = 'It\'s very good'
print(msg)      # It's very good
```

常见的转义字符一共四个：

| 转义字符 | 含义 | 效果 |
| --- | --- | --- |
| `\'` | 单引号本身 | 对单引号转义，使它可以出现在字符串里 |
| `\"` | 双引号本身 | 对双引号转义，使它可以出现在双引号字符串里 |
| `
` | 换行符 | 走到这里就执行换行操作 |
| `\t` | 制表符 | 相当于按下键盘上的 Tab 键，产生缩进效果 |

遇到这类问题还有第二种解法，也是更省事的解法：字符串里有单引号，那定义时就不用单引号，改用双引号。外层换成双引号之后，内层的单引号走到那儿并不能和起始引号配对，它就表示单引号本身，问题同样解决。

```python
msg = "It's very good"
```

双引号这边是同样的道理，只是方向反过来：

```python
msg3 = "Hello的意思就是\"您好\""
```

双引号定义的字符串里如果还想出现双引号，一样得转义，否则内层双引号会和起始双引号提前闭合。对称的替代方案同样存在：外层别用双引号，改用单引号，内层的双引号就能正常出现了。

```python
message4 = 'Hello的意思就是"您好"'
```

> **提示**：遇到引号冲突，两条路选一条就够——要么给内层引号加反斜线转义，要么换一种外层引号。两者不要叠加使用，也不必写两份。

### 5. 换行符与制表符的验证

剩下两个转义字符在单引号、双引号字符串里才有存在感，因为这两种字符串本身不能写多行，要换行只能靠 `
`。

把前面用三引号写的那几行内容复制下来，合并成一行写进双引号里——反正双引号和单引号都定义不了多行字符串，只能写成一行。

```python
print("Hello 欢迎大家进入到Python课程的学习 一键三连哟~")
```

这样写出来，所有内容就挤在同一行里了。现在的需求是：走到叹号之后换个行再输出。

```python
print("Hello 欢迎大家进入到Python课程的学习 一键三连哟~\n")
```

在叹号后面写上 `
`，运行后叹号之后确实换行了。这里要留意 `
` 生效的时机——它是在输出的时候执行换行操作。

`\t` 则是增加缩进，相当于按了一下键盘上的 Tab 键。现在想让“欢迎”和“大家”这两句前面都带上一个缩进，就在它们前面各加一个 `\t`：

```python
print("Hello\n\t欢迎大家进入到Python课程的学习\n\t一键三连哟~")
```

运行后，“欢迎”前面有了缩进，“一键三连”前面也有缩进。注意区分：`\t` 写在字符串里控制的是输出内容的缩进；而代码本身现在都得顶格写，代码不能缩进。

> **易错点**：`
` 和 `\t` 是“字符串内容里的转义序列”，影响的是打印出来的排版；它们不是代码缩进，别把两者混成一件事。

### 6. 三种方式的取舍原则

现在手里有三种定义字符串的方式，项目开发里到底用哪种？

单引号和双引号定义出来的字符串其实是一样的，只是写法不同。所以项目开发当中只需要守住一个原则：同一个项目里，要么都用双引号，要么都用单引号，保持一种写法就够了。

至于三引号字符串，它的主要应用场景是定义多行字符串——有大段内容要写进去的时候用它。三引号还有另一个用途，就是书写文档注释时也会用到，这个后面再详细讲。

## 第 2 章：核心语法-数据存储与运算-字符串拼接
> 对应分集：P15 | 原始标题：《15. 核心语法-数据存储与运算-字符串拼接》

字符串的三种定义方式掌握之后，接下来剖析字符串的使用细节，这一小节专讲拼接。

现实里经常要把多个字符串合并成一个：一句话由姓名、年龄、专业、爱好几段拼出来，每个部分还得不一样。这就是字符串拼接要解决的问题。

### 1. 多个字符串字面量的自动合并

如果拼接的对象都是字符串字面量，那最简单：直接把它们挨着写在一起就行。

```python
s1 = "黑马程序员" "成就每一个IT人"
print(s1)      # 黑马程序员成就每一个IT人
```

Python 解释器在执行时会自动把多个字符串合并成一个。前提是这些部分都得是字符串字面量，它才会自动合并。

中间要不要加东西？可以加空格，也可以不加；加一两个、四五个空格都没问题，解释器照单全收。

```python
s1 = "人生苦短" "我用Python" "OK"
print(s1)      # 人生苦短我用PythonOK
```

三个字面量直接写在一起，解释器一样自动拼好。要是想在“人生苦短”和“我用 Python”之间留一个空格，就在第一个字符串里面写好那个空格——合并动作本身不会替你插入任何分隔。

> **提示**：相邻字面量的自动合并是悄悄发生的，中间不会补空格。所以“黑马程序员”和“成就每一个 IT 人”直接挨着写，输出就是“黑马程序员成就每一个 IT 人”。想要空格，就把空格写进前一个字符串的引号里面。

> **结论**：这种写法了解即可。既然都是字面量、内容又是写死的，那不如直接写成一个字符串来得干脆。

### 2. 加号拼接

第二种方式是使用加号拼接：第一个字符串和第二个字符串之间，用加号把多个字符串合并成一个。

```python
print("黑马程序员" + "成就每一个IT人")
```

但项目开发当中，拼接往往不是把两个字面量接到一起——真要是那样，直接写成一个字符串就行了。更多时候是字符串字面量与变量拼在一起。

举个例子，要输出一句话：Python 之父吉多·范罗苏姆说“人生苦短，我用 Python”。其中“人生苦短”是一个变量 s1，“我用 Python”是另一个变量 s2，而 s1 和 s2 之间还需要一个逗号分隔。要把这句话完整输出，就必须把这几部分拼起来。

```python
s1 = "人生苦短"
s2 = "我用Python"
print("吉多·范罗苏姆说：" + s1 + "，" + s2)
```

拆开看拼接顺序：先是字面量“吉多·范罗苏姆说：”，接着用加号接上变量 s1，s1 后面还得接一个逗号——逗号也是字符串字面量，同样用加号拼上；逗号之后的 s2 继续用加号接。也就是说，只要涉及字符串各个部分的拼接，就写一个加号把它们连起来。

想在逗号前后加个空格，在对应位置补一个空格字符串就行。

> **易错点**：加号只能拼接两个字符串，没法把非字符串和字符串直接拼起来。像 int 这样的整数类型不能直接和字符串相加；非字符串类型必须先转成字符串类型，才可以拼接。

### 3. 实战：拼出一句自我介绍

需求是：根据自己的实际情况输出一条个人信息，结构形如“大家好，我是涛哥，今年18岁，学习的专业是软件工程，爱好Python、Java”。

这句话里名字、年龄、专业、爱好对每个人都不一样，都是动态变化的，所以先把这些容易变动的信息用变量记下来，再通过字符串拼接把整句话输出。

```python
name = "涛哥"
age = 18
pro = "软件工程"
hobby = "Python、Java"
print("大家好，我是" + name + "，今年" + age + "岁，学习的专业是" + pro + "，爱好" + hobby)
```

这段代码运行不起来，`age` 那一处的拼接就是原因——字符串和整数没法用加号接上。

变量名起得有语义一些，方便自己看懂：name 是名字，age 是年龄，pro 是专业的简写，hobby 是爱好。年龄在这里写 18，它就是个整数。

这段代码写完，PyCharm 里 `age` 那一处会出现黄色背景色。

> **提示**：PyCharm 里出现黄色背景色就是一条警告，代表这块代码可能有问题。鼠标移上去会说明原因：意外的类型——当前 age 是 18，属于整数类型，提示里“意外的类型是 int”，而“可能的类型是 str”。一句话说，这里需要一个 str 类型，却给了一个 int 类型。

警告到底会不会真的拦住程序？直接运行看看：报错了。报错信息说的正是这件事——字符串拼接仅仅能够拼接 str 类型、字符串类型，而不能拼接 int 类型。这就印证了前面那条规则：加号只能拼接字符串，没法把字符串和非字符串拼接起来。

解决办法是类型转换。新介绍一个工具 `str`，把括号里 int 类型的数字转成字符串：

```python
print("大家好，我是" + name + "，今年" + str(age) + "岁，学习的专业是" + pro + "，爱好" + hobby)
```

`str` 也是个函数，写法是 `str` 后面跟一对小括号，括号里写上要转换的对象。这里把 `age` 传进去，它就会把 age 这个数字类型转成字符串类型，再参与拼接。

再次执行，姓名、年龄、专业、爱好全部拼接成功，那条自我介绍正常输出了。

```text
"大家好，我是" + name + "，今年" + str(age) + "岁，学习的专业是" + pro + ...
      |            |          |          |           |
    字符串       字符串     字符串    int -> str    字符串
      |            |          |          |           |
      +------------+----------+----------+-----------+
              加号两侧必须都是字符串，类型转换要在拼接前完成
```

读图看两个要点：加号两侧必须都是字符串；遇到 int 这类非字符串数据，先在它所在的位置用 `str()` 转换好，再交给加号。

## 第 3 章：核心语法-数据存储与运算-字符串格式化
> 对应分集：P16 | 原始标题：《16. 核心语法-数据存储与运算-字符串格式化》

上一小节的练习完成得怎么样了？多个字符串用加号来拼接，代码敲起来爽不爽——这一问出来，答案基本也就有了。

真要把多个字符串和多个变量拼凑成一句完整的话，用加号拼还是相当麻烦，麻烦在三个地方。

### 1. 加号拼接的三点问题

**第一，拼接比较繁琐。** 只要涉及两个部分的拼接，就得补一个加号把它们连起来。一句话里有几段内容，就得写几个加号。

**第二，会破坏字符串的完整性。** 所谓破坏完整性，指的是在代码里看不到这个字符串的全貌。代码里散落的引号、加号、变量名把原句切成了碎片，扫一眼读不出这句到底是一句什么话，也看不清它完整的结构。

**第三，还要做类型转换。** 字符串与非字符串拼接时，必须先把非字符串转成字符串才能拼，于是代码里又要插进一层转换调用。

> **结论**：加号拼接在“少量、固定”的场景还能忍，一旦变量多起来，繁琐、不易读、强制转换三件事会同时压上来。

解决办法是字符串格式化。它同样在做拼接这件事，却把加号和类型转换都省掉了，写出来的字符串还是一句完整的话。

### 2. 百分号占位符格式化

字符串格式化本质上也是用来做字符串拼接的，只是不再用加号去连，而是使用占位符。通过 `%` 引出的占位写法，就能快速完成字符串与变量之间的拼接。

```python
s1 = "涛哥"
print("大家好，我是%s，欢迎大家进入到Python课程的学习" % s1)
```

语法要按两部分来读。字符串里的 `%` 表示“这里要占位了”，后面紧跟的 `s` 表示这个位置最终要放入一份转换成字符串类型的数据，然后填充进来；`s` 可以理解为 string 的简写，所以 `%s` 就是把字符串填充到这个位置。

注意 `%` 和 `s` 要挨着写，中间不留空格。

填充谁呢？在字符串后面、百分号之后指定一个变量，这个变量就是最终用来替代 `%s` 的变量。它会先被转换成字符串类型，然后替换掉 `%s` 的位置。

多个变量时，前面就写多个 `%s`：两个占位符，字符串结尾的百分号之后就要跟上两项数据。最终第一个变量替换掉第一个占位符，第二个变量替换掉第二个占位符。

```python
name = "涛哥"
age = 18
print("大家好，我是%s，今年%s岁" % (name, age))
```

百分号后面有多项数据时，需要用括号把它们括起来，并用逗号分隔。

> **易错点**：占位符数量与后面数据的数量必须一致——前面字符串里有几个占位符，百分号后面就要传几个变量或数据。另外顺序也有要求：第一个变量替换第一个占位符，第二个替换第二个，位置对应不能错。

### 3. 实战：把加号拼接改写成百分号格式化

回到上面自我介绍那段代码，把它改造成百分号格式化的写法。改造动作很机械：得占位的地方，把加号和引号删掉，直接写 `%s`。

原本拼出来的句子是“大家好，我是涛哥，今年18岁，学习的专业是软件工程，爱好Python、Java”。改造后，“我是”后面那个位置要占位，最终用 name 来填，就写 `%s`；“今年”后面那个位置填年龄 age，同样写 `%s`；学习的专业那里，把引号和中间的两个加号都删掉，换上 `%s`；爱好那里也是 `%s`。

```python
name = "涛哥"
age = 18
pro = "软件工程"
hobby = "Python、Java"
print("大家好，我是%s，今年%s岁，学习的专业是%s，爱好%s" % (name, age, pro, hobby))
```

数一数字符串里有几个 `%s`：四个。那字符串结尾的百分号后面就要跟上四项数据。数据多于一项，用括号括起来，按 name、age、pro、hobby 的顺序写进去——顺序不能颠倒，因为第一个变量替换第一个占位符。

运行后拼接完成，输出与加号方案完全一致，但代码简洁了很多：字符串是一个完整的结构，变量的值在运行时替换掉对应占位符，读代码时一眼能看出这句话长什么样。

还有一点好处——不用再做类型转换。age 是整数，`%s` 一样能成功替代。原因是 `%s` 会把它后面的数据自动转成字符串，再替换掉前面的占位符。

### 4. f-string 格式化

字符串格式化还有第二种方式：在字符串前面加一个 `f`，标识要对这个字符串做格式化；字符串里面用大括号作为占位符，大括号里写上具体的变量名或者表达式。

```python
name = "涛哥"
print(f"大家好，我是{name}")
```

这种方式不再需要在字符串里排一串固定的 `%s`，而是把变量名直接写进大括号里。变量名与前面定义的变量保持一致，输出时它就会自动把这个变量的值拼接到这个位置。大括号同样是一个占位符，区别在于：后面不用再单独指定“第一个占位符用哪个变量替代”，因为变量名已经写在括号里了。

多个变量就用多个大括号：

```python
print(f"大家好，我是{name}，今年{age}岁，学习的专业是{pro}，爱好{hobby}")
```

把上面的案例按这种方式改造，动作同样机械：`%s` 全部删掉，在字符串前面直接写一个 `f`，然后在四个对应位置各写一对大括号，括号里依次填 name、age、pro、hobby。

改造完和上面的百分号方案上下对比一下，哪种更简洁？答案是 f-string 这种方式。

> **易错点**：字符串前面那个 `f` 可不能少。少了它，大括号不会被当成占位符，而是被当成普通的字符串内容原样输出——`{name}` 就真的打印成 `{name}`。

加上 `f` 之后，运行结果逐项验证：name 替代了第一个位置；age 输出 18，没问题；pro 输出软件工程；hobby 输出 Python、Java，也没毛病。

```text
print("大家好，我是%s，今年%s岁" % (name, age))      <- 占位符 + 尾部数据，两处要数清、要对齐
print(f"大家好，我是{name}，今年{age}岁")             <- 变量名写在括号里，前缀 f 不能少
```

读图看两种写法的分工差别：百分号方案的占位符与数据分居字符串两端，靠顺序和数量对应；f-string 方案把变量名直接嵌进占位符内部，省掉了尾部那一串数据。

这种方式是现在企业开发中的推荐方式，以后用得更会多一些。

### 5. 三种拼接手段的分工

| 手段 | 写法特征 | 类型转换 | 适用场景 |
| --- | --- | --- | --- |
| 相邻字面量自动合并 | 字面量挨着写，无加号 | 不涉及 | 内容全部写死，了解即可 |
| 加号拼接 | 各部分用 `+` 相连 | 非字符串须先 `str()` 转换 | 部分极少、结构极简 |
| `%s` 占位符 | 字符串内占位，尾部 `%` 传数据 | 自动转为字符串 | 变量较多、需要明确对应关系 |
| f-string | 前缀 `f`，括号内写变量名或表达式 | 自动转为字符串 | 企业开发推荐，日常首选 |

拿加号拼接和格式化对比，加号的三个短板恰好被逐一对掉：不再需要为每一处拼接补一个加号，字符串在代码里保持完整结构，非字符串数据也不用自己先做类型转换。
