## 核心语法-数据存储与运算-输入与输出
> 对应分集：P17 | 原始标题：《17. 核心语法-数据存储与运算-输入与输出》

前面把 Python 里常见的数据类型和使用细节过了一遍。现在回过头看我们自己写过的那些代码，会发现一个现象：里面所有的数据都是直接写死在代码里的——姓名、年龄、专业、爱好，一个不落。

练习的时候这样写没什么，但真要用起来就不方便、也不灵活。手边自然就会冒出一个问题：有没有办法让程序直接拿到我在键盘上录入的数据？比如我在键盘上敲了一个 `9`，程序能不能把这个 `9` 抓过来，赋值给我指定的变量？如果能，程序立刻灵活一大截。答案是能，靠的就是 Python 的输入与输出。

输入与输出干两件事：拿到键盘上输入的数据，以及把数据输出到控制台。输出这一块在入门程序里已经用过了——`print` 直接输出就行，不用再展开。重点落在输入上：怎么拿到键盘录入的数据。

### 获取键盘输入的 `input` 语句

Python 内置了获取键盘输入的功能，用到的语句是 `input`。

> **定义**：`input` 本质是一个函数，而且是 Python 内置的功能，不需要自己定义就能直接调用。自定义函数的做法后面会专门讲。

它的语法是 `input` 后面跟一对括号，括号里放对应的提示信息：

```python
input("提示信息")
```

括号里的这段提示信息，会在代码执行时显示在控制台里给用户看，让用户知道该输入什么。提示信息显示出来之后，用户就可以通过键盘录入数据，录入完成后的结果会被赋值给变量。

```python
s = input("提示信息")
```

这样在后面的代码里，就能通过变量 `s` 拿到键盘上录入的数据。而 `print` 负责另一半——把数据输出到控制台。

#### 一个录入姓名与年龄的例子

假设代码里写了这么一句：

```python
name = input("请输入您的姓名：")
```

这句一旦执行，控制台里就会先输出 `请输入您的姓名：` 这个提示信息，然后光标停在后面闪动，等待输入。当我们输入 `涛哥` 并敲下回车，这个字符串就被赋值给变量 `name`，程序后面就能拿它用了。

年龄同理，把提示信息换一下：

```python
age = input("请输入您的年龄：")
```

输入 `18` 之后回车，`18` 被赋值给变量 `age`。最后把两个变量输出出来。

> **提示**：`input` 的执行是"阻塞"式的。第一个 `input` 执行完，它不会立即执行第二句代码，而是停在那里等你输入；你输入完并回车，它才把内容赋值给变量，然后继续往下走、执行第二个 `input`。

#### 输出时用 f-string 拼接

把 `name` 和 `age` 输出到控制台用 `print`。字符串拼接的老办法是用加号把一段一段接起来，这样写又长又容易漏空格。更省事的做法是在字符串前面加一个 `f`，让字符串自己带占位能力。

```python
print(f"您的姓名是{name}，年龄为{age}")
```

这里用大括号占位，括号里写具体的变量名：先写 `{name}`，再写年龄 `{age}`。前面那几集讲过，大括号这种占位符里不仅能写变量，也能写表达式。

跑起来的完整效果是这样的：

```text
请输入您的姓名：涛哥
请输入您的年龄：18
您的姓名是涛哥，年龄为18
```

控制台里先出现 `请输入您的姓名：`，光标闪动等待输入；敲 `涛哥` 回车之后，第二句 `input` 又提示 `请输入您的年龄：`——提示信息后面那个冒号就是我们自己写在提示信息里的；输入 `18` 回车，它把 `18` 赋值给 `age`，最后一行把整句话输出出来。

#### 键盘录入的数据永远是字符串

这一条必须单独强调：**不管你在键盘上输入的是什么类型的数据，最终拿到的永远是字符串。**

即使输入的是 `18`，拿到的也是字符串类型的 `"18"`，而不是整数类型的 `18`。第二条 `input` 的提示信息叫"请输入您的年龄"，看起来像是要一个整数，但实际拿到手的仍然是字符串。所有键盘录入的数据都是字符串类型——这一点后面会反复用到，尤其是要拿它参与运算的时候。

### 案例练习：模拟银行卡 ATM 取款

需求是这样的：小智的银行卡里有 1 万元，现在到 ATM 机进行取钱操作，请根据输入的金额进行取钱，取钱完毕后展示银行卡余额。

真去银行取钱，把卡插进去之后要先输密码，再输入取款金额，最后机器告诉你卡里还剩多少。插卡这个动作不模拟，所以整个需求拆成三步：

1. 模拟输入密码；
2. 输入取款金额；
3. 计算余额并输出。

#### 第一步 输入密码

第一步就是获取键盘输入，直接上 `input`，给一句提示信息，再用变量接住：

```python
password = input("请输入您的银行卡密码：")
```

现在还不需要判断密码是否正确，因为程序里的逻辑操作还没学到。所以这一步只是把收到的密码打印出来：

```python
print(f"密码正确，密码是{password}")
```

这里的占位符同样需要字符串前面加 `f`。跑起来输入 `666888`，回车后输出 `密码正确，密码是666888`。

#### 第二步 输入取款金额

取款金额这一步的操作和输入密码完全一样，照抄一份，把变量名和提示信息换掉：

```python
number = input("请输入您的取款金额：")
```

到这一步为止只做了两件事：定义总金额，收两个键盘输入。

#### 第三步 计算余额并输出

余额怎么算？银行卡上的总金额减去本次的取款金额，就是这个余额。所以先要用一个变量记录总金额：

```python
total = 10000
```

然后输出余额，占位符里直接写表达式：

```python
print(f"取款后，银行卡的余额为{total - number}")
```

#### 字符串不能和整数相减

这么写，编辑器会在 `number` 那里给出黄色背景的警告，鼠标悬浮上去能看到的提示是：这里期望 `int` 类型，实际是 `str` 类型。

回想前面那条注意事项：键盘录入拿到的所有数据都是字符串类型。也就是说 `number` 现在是字符串，而 `total` 是整数，两者类型不匹配，不能进行运算。要参与运算，就得把 `number` 转成整数。

Python 内置的 `int` 就干这件事——把其他类型转成整数类型：

```python
print(f"取款后，银行卡的余额为{total - int(number)}")
```

这一小段的意思是把 `number` 这个字符串类型转成整数类型。转换之后两个都是整数，运算就没有问题了。

#### 案例运行结果

实际运行一遍：先提示输入银行卡密码，输入 `666888`，回车，输出 `密码正确，密码是666888`；接着提示输入取款金额，输入 `1000`，回车——此时 `number` 的值就是字符串形式的 `1000`；再往下执行输出语句，用 `total` 减去 `int(number)` 得到余额。

```text
请输入您的银行卡密码：666888
密码正确，密码是666888
请输入您的取款金额：1000
取款后，银行卡的余额为9000
```

余额 9000 元，计算正确。整段代码合起来是：

```python
# 案例：模拟银行卡 ATM 取款
# 总金额
total = 10000

# 第一步：输入密码
password = input("请输入您的银行卡密码：")
print(f"密码正确，密码是{password}")

# 第二步：输入取款金额
number = input("请输入您的取款金额：")

# 第三步：计算余额并输出
print(f"取款后，银行卡的余额为{total - int(number)}")
```

### 数据类型转换工具

这一讲收尾的两个问题，第一个已经答完：获取键盘输入用 `input`，括号里指定提示信息。

第二个问题是数据类型转换。到目前位置已经接触到两个方向的转换：数字类型转字符串，以及字符串转数字。它们分别靠两个内置工具完成：

| 内置工具 | 作用 | 典型用法 |
| --- | --- | --- |
| `int` | 将其他类型转换为整数类型 | `int("1000")` 得到整数 `1000` |
| `str` | 将其他类型转换为字符串类型 | `str(100)` 得到字符串 `"100"` |

除了这两个，还有两个内置工具目前没有实际用到，先认识一下：

| 内置工具 | 作用 |
| --- | --- |
| `float` | 将指定数据转换为浮点数类型 |
| `bool` | 将其他类型转换为布尔类型 |

这四个里面，当下用得最多的是 `int` 和 `str`；`float` 在后面处理小数输入时会立刻派上用场。

### 练习

**题目**：根据用户输入的两个数字，计算两个数之和，然后将其输出到控制台。

**解析**：这道题和上面的取款案例是同一套路子。用 `input` 分别接收两个数字，两次拿到手的都是字符串，直接相加只会把两段文本拼在一起，所以参与加法之前要先用 `int`（或 `float`）转成数字类型，最后用 `print` 把结果输出到控制台。自己写完可以对照给定的参考答案核一遍。

## 核心语法-数据存储与运算-运算符-算术运算符
> 对应分集：P18 | 原始标题：《18. 核心语法-数据存储与运算-运算符-算术运算符》

前面几节把数据怎么写、怎么存讲完了，接下来的问题是：数据存下来之后要进行运算，怎么算？数据要运算就离不开运算符。运算符本身不陌生，小学课本里就学过加减乘除，此外还有大于、小于、大于等于、小于等于、等于、不等于，再往深还有并且、或者这类做逻辑处理的符号。数量确实不少，所以学的时候先归类，再一类一类往下走。

### 运算符的四类划分

按作用划分，运算符一共分成四类：

1. **算术运算符**：加减乘除这一类专门做算术运算的符号；
2. **赋值运算符**：为某个变量赋值的运算符。定义变量时给变量赋一个值用的那个等号，就属于赋值运算符；
3. **比较运算符**：用于比较两个数的符号，比如大于、小于、大于等于、小于等于；
4. **逻辑运算符**：做逻辑处理时用到的运算符，比如并且、或者。

这一节只看第一类。围绕算术运算符要弄清两件事：Python 里有哪些算术运算符，以及它们的写法和作用分别是什么。

> **定义**：算术运算符是数学运算的基本符号，作用于一个或多个参与运算的数字上，然后产生一个结果。

### 七种算术运算符的写法与含义

最基本的四则运算是加减乘除，写法上分两类情况：加法和减法，写法与小学课本上完全一致；乘法和除法，写法与数学里的习惯有差异。

| 运算符 | 名称 | 示例 | 结果 | 说明 |
| --- | --- | --- | --- | --- |
| `+` | 加 | `10 + 4` | `14` | 与数学写法一致 |
| `-` | 减 | `10 - 4` | `6` | 与数学写法一致 |
| `*` | 乘 | `10 * 4` | `40` | 用星号表示乘法 |
| `/` | 除 | `10 / 4` | `2.5` | 结果一定是浮点数 |
| `//` | 整除 | `10 // 4` | `2` | 只保留整数部分 |
| `%` | 取余（求模） | `10 % 4` | `2` | 取除法之后的余数 |
| `**` | 幂指数 | `10 ** 4` | `10000` | 求一个数的多少次方 |

#### 乘法用星号

`*` 表示乘法，比如 `3 * 8`，中间那个星号就代表乘法。

#### 除法结果是浮点数

除法在编程语言里用斜杠 `/` 表示，比如 `10 / 5` 直接写一个斜杠。

> **易错点**：除法运算的结果是浮点数，也就是小数。`10 / 5` 的结果不是 `2`，而是 `2.0`；`10 / 4` 的结果是 `2.5`。只要用了单斜杠，结果就带小数点。

#### 整除只保留整数部分

单斜杠是正常除法，双斜杠 `//` 是整除。

> **结论**：整除的结果一定是一个整数。

`10 / 3` 除不尽，是 `3.333…`；而 `10 // 3` 的结果是 `3`，整除只保留整数部分，不做四舍五入。

#### 取余取的是余数

百分号 `%` 代表取余，也叫求模运算。它做的事情是取除法之后的余数。

`10 % 3` 的结果是 `1`，因为 $10 \div 3$ 的余数是 1。也可以把它读成"10 模与 3"，含义完全一样：先做除法，再看余几。

#### 幂指数求的是多少次方

幂指数用两个星号 `**`。一个星号是乘法，两个星号就是幂指数。

`10 ** 3` 代表 10 的 3 次方，`10 ** 2` 代表 10 的 2 次方。想求 4 的 2 次方，前面写 4，后面写两个星号加 2，也就是 `4 ** 2`，就是 4 的平方。

#### 这些符号在键盘上的位置

| 运算符 | 键盘位置 |
| --- | --- |
| `+` | 等号键的上档字符，需要按住 `Shift` 再按 |
| `-` | 数字 `0` 右侧的减号键 |
| `*` | 数字 `8` 键的上档字符，按住 `Shift` 再按 |
| `/` | 问号键下方的斜杠，直接按 |
| `//` | 连按两下斜杠键 |
| `%` | 数字 `5` 键的上档字符 |
| `**` | 连按两下星号键，也就是数字 `8` 的上档字符按两下 |

见到两个斜杠或两个星号，就是同一个键按两下，不必去找额外的按键。

### 逐行运行七种运算符

把七种运算符各写一行打印出来，直接看结果：

```python
print(10 + 4)
print(10 - 4)
print(10 * 4)
print(10 / 4)
print(10 // 4)
print(10 % 4)
print(10 ** 4)
```

运行结果：

```text
14
6
40
2.5
2
2
10000
```

对每一行的预期是这样的：加减乘这三行不必多说；第四行 `10 / 4` 因为除法的结果会出现小数，所以是 `2.5`；第五行 `10 // 4` 是整除，结果一定是整数，是 `2`；第六行求模就是取余，`10 / 4` 整除之后余 `2`，所以结果也是 `2`；第七行 `10 ** 4` 是 10 的 4 次方，2 次方是 100，3 次方是 1000，4 次方就是 10000。

### 算术运算符的优先级

一个表达式里同时出现多种运算符，谁先算谁后算是有规定的。以 `0.1 + 10 / 4 ** 2` 为例，这里面同时用到了加号、除法和幂指数。

优先级从高到低分三档：

1. **幂指数** `**` 最优先；
2. **乘法、除法、整除、求模** 这四个排在第二档；
3. **加号、减号** 优先级最低。

```text
优先级高  ──►  **                    幂指数
            ──►  *  /  //  %          乘、除、整除、取余
优先级低  ──►  +  -                  加、减
```

所以 `0.1 + 10 / 4 ** 2` 的计算顺序是：

1. 先算 $4^2 = 16$；
2. 再算 $10 \div 16 = 0.625$；
3. 最后算 $0.1 + 0.625 = 0.725$。

实际运行输出正是 `0.725`。

> **提示**：想提高某个部分的优先级，就在那里加括号把它括起来，这一点和数学里一样。括号的优先级是最高的。

### 案例练习：输入两个数并计算和与差

案例需求：在键盘上随意录入两个数，分别赋值给 `x` 和 `y`，然后分别输出 $x+y$ 的结果和 $x-y$ 的结果。

第一步必须先接收键盘输入，用 `input` 加提示信息：

```python
x = input("请输入x的值：")
y = input("请输入y的值：")
```

第二步计算并输出两个结果，占位符里直接写表达式：

```python
print(f"x + y 的结果是{x + y}")
print(f"x - y 的结果是{x - y}")
```

#### 两个字符串相加得到拼接结果

运行程序，输入 `x` 的值 `10`，`y` 的值 `5`，结果出问题了：`x + y` 那行输出了 `105`，而 `x - y` 那行直接报错。

原因在前面讲键盘输入时提过：从键盘上接收到的所有数据都是字符串。这里 `x` 是字符串 `"10"`，`y` 是字符串 `"5"`，两个字符串相加做的是字符串拼接，拼出来就是 `"105"`——这是一个字符串，不是数字。而减号没有拼接这层含义，两个字符串相减直接报错。

> **结论**：键盘输入拿到的永远是字符串，要参与算术运算，必须先转成数字类型。

转换用内置的 `int`，把输入的内容直接转成整数类型：

```python
x = int(input("请输入x的值："))
y = int(input("请输入y的值："))

print(f"x + y 的结果是{x + y}")
print(f"x - y 的结果是{x - y}")
```

再运行一次，输入 `10` 和 `5`，输出分别是 `15` 和 `5`，问题解决。

#### 换成小数输入就报错

需求里说的是"两个数"，并没有限定必须是整数。所以再测一次，输入第一个数 `0.5`：

程序又报错了。原因在于 `int` 代表把字符串转成整数类型，而 `0.5` 不是整数，转不过去。既然输入不一定是整数还是小数，那就统一按小数来处理，把转换工具换成 `float`：

```python
x = float(input("请输入x的值："))
y = float(input("请输入y的值："))

print(f"x + y 的结果是{x + y}")
print(f"x - y 的结果是{x - y}")
```

`float` 的作用是把其他类型——比如字符串类型——转成浮点数类型，也就是小数类型。换成 `float` 之后，整数输入也照样能用：输入 `10` 和 `5`，转换时 `10` 变成 `10.0`，`5` 变成 `5.0`，两个都是浮点数，计算结果是 `15.0` 和 `5.0`，没有问题。

#### 浮点数运算的精度损失

再运行一次，输入 `0.5` 和 `0.4`：

```text
x + y 的结果是0.9
x - y 的结果是0.09999999999999998
```

两个数的和是 `0.9`，看着正常；可 $0.5-0.4$ 的结果不是 `0.1`，而是 `0.09999999999999998`。差值大约 $2 \times 10^{-6}$ 量级，明显不对——但这不是计算机算错了。

这和算术运算中的精度损失有关。

> **结论**：计算机底层基于二进制进行数据的存储与处理，而二进制无法准确表示所有的小数。因此涉及浮点数的运算可能会损失精度。

有些小数用二进制根本表示不准确，这是计算机做算术运算时的正常情况，不属于异常情况。换句话说，凡是用到浮点数参与运算，就要有"结果可能带一点微小误差"的心理准备，别拿浮点数结果去和"精确值"直接比大小。

## 核心语法-数据存储与运算-运算符-赋值运算符
> 对应分集：P19 | 原始标题：《19. 核心语法-数据存储与运算-运算符-赋值运算符》

算术运算符学完，第二类运算符是赋值运算符。顾名思义，它就是给变量做赋值操作的。

这类运算符数量不少，但源头只有一个：定义变量时用的那个等号。等号是最简单、也是用得最多的赋值运算符，把下面这一族全部搞清楚了，剩下的都是同一套逻辑换个符号。

### 基本赋值运算符

> **定义**：赋值运算符把等号右侧的结果赋值给左侧的变量。

```python
number = 1 + 2
```

这一句会先算出 $1+2$ 的结果，再把结果赋值给左侧的变量 `number`，于是 `number` 的值就是 `3`。

### 复合赋值运算符

下面这些赋值运算符都是以等号为基础变来的：加等、减等、乘等、除等，还有取模、整除以及幂指数的写法。搞清楚其中一个，其余的规律完全一致。

#### 加法赋值运算符

以加法赋值运算符为例：

```python
number += 2
```

这一句等效于：

```python
number = number + 2
```

也就是说，`number` 这个变量要在原来数据的基础上再加 `2`，再把结果赋回给 `number`。如果 `number` 初始值是 `3`，执行完之后 `number` 的值就变成 `5`。

#### 其余复合赋值运算符

其余的按同样方式理解：

| 运算符 | 名称 | 等效写法 |
| --- | --- | --- |
| `+=` | 加法赋值 | `number = number + 2` |
| `-=` | 减法赋值 | `number = number - 2` |
| `*=` | 乘法赋值 | `number = number * 2` |
| `/=` | 除法赋值 | `number = number / 2` |
| `//=` | 整除赋值 | `number = number // 2` |
| `%=` | 取模赋值 | `number = number % 2` |
| `**=` | 幂指数赋值 | `number = number ** 2` |

幂指数的写法单独看一眼：

```python
number **= 2
```

等效于 `number = number ** 2`，两个星号就是幂指数运算，所以这一句相当于 `number` 等于 `number` 的二次方。如果后面那个数字写 `3`，那就是 `number` 等于 `number` 的三次方。

> **易错点**：加法赋值、减法赋值、除法赋值这些符号，虽然是两个符号拼在一起的，但它**本质是一个符号**。所以中间不要加任何其他字符，也不要加空格，必须连着一块写。

### 逐个运行复合赋值运算符

定义一个变量 `number = 85`，先用最基本的赋值运算符给它一个初始值，然后依次用各族运算符操作它，看看值怎么变：

```python
number = 85
print(number)      # 85

number += 10
print(number)      # 95

number -= 10
print(number)      # 85

number *= 10
print(number)      # 850

number /= 10
print(number)      # 85.0

number //= 10
print(number)      # 8.0

number %= 3
print(number)      # 2.0

number **= 3
print(number)      # 8.0
```

每一步的变化都可以先自己推一遍：

1. `number = 85`，变量 `number` 的值就是 `85`；
2. `number += 10` 等效于 `number = number + 10`，$85+10=95$，`number` 变成 `95`；
3. `number -= 10` 等效于 `number = number - 10`，此时 `number` 已经是 `95`，$95-10=85$，又回到 `85`；
4. `number *= 10` 等效于 `number = number * 10`，$85 \times 10 = 850$；
5. `number /= 10` 等效于 `number = number / 10`，$850 \div 10 = 85$——但除法运算的结果是小数，所以这个 `85` 要用浮点数表示，是 `85.0`；
6. `number //= 10` 等效于 `number = number // 10`，$85 \div 10$ 的整除结果是 `8`；由于此时 `number` 是 `85.0`，浮点数参与了运算，所以结果也是浮点数 `8.0`；
7. `number %= 3` 等效于 `number = number % 3`，`8.0` 模与 3 的余数是 `2`，同样是浮点数，写作 `2.0`；
8. `number **= 3` 等效于 `number = number ** 3`，也就是 2 的 3 次方，结果是 `8`，因为参与运算的是浮点数，所以是 `8.0`。

实际运行的结果是 `95`、`85`、`850`、`85.0`、`8.0`、`2.0`、`8.0`，和逐步推导完全一致。

后面这几行结果都带着 `.0`，原因只有一条：`number` 从第 5 步开始就是浮点数了，**一旦有浮点数参与算术运算，计算的结果就是浮点数**，所以后面每一步的结果都保留小数形式。

把第 5 行那句 `/=` 去掉，情况立刻变了：没有除法运算，`number` 就一直是整数，后面整除的结果也是整数，整个计算过程的结果都是整数，而不是小数。

> **结论**：结果是不是浮点数，看参与运算的操作数里有没有浮点数、有没有除法，而运算符本身并不改变这一点。

| 步骤 | 运算 | 运算前 `number` | 运算后 `number` |
| --- | --- | --- | --- |
| 1 | `number = 85` | 未定义 | `85` |
| 2 | `number += 10` | `85` | `95` |
| 3 | `number -= 10` | `95` | `85` |
| 4 | `number *= 10` | `85` | `850` |
| 5 | `number /= 10` | `850` | `85.0` |
| 6 | `number //= 10` | `85.0` | `8.0` |
| 7 | `number %= 3` | `8.0` | `2.0` |
| 8 | `number **= 3` | `2.0` | `8.0` |

## 核心语法-数据存储与运算-运算符-比较运算符
> 对应分集：P20 | 原始标题：《20. 核心语法-数据存储与运算-运算符-比较运算符》

算术运算符和赋值运算符都过了一遍，第三类是比较运算符。顾名思义，它用来比较两个值之间的关系。

这一类运算符有个和前面两类都不同的特点：它不产出数字，也不改变变量的值，它产出一个布尔值。

### 比较运算符的定义与返回值

比较运算符也叫关系运算符。

> **定义**：比较运算符用于比较两个值之间的关系。它会自动计算运算符左右两边的表达式——两边可能是两个变量，也可能是两个表达式——然后返回一个布尔值作为结果。

布尔值只有两种：`True` 和 `False`。

- 结果为 `True`，表示这个比较关系**成立**（为真）；
- 结果为 `False`，表示这个比较关系**不成立**（为假）。

### 六种比较运算符

常见的比较运算符一共六种：

| 运算符 | 名称 | 示例 | 含义 |
| --- | --- | --- | --- |
| `==` | 等于 | `a == b` | 判断 `a` 和 `b` 的值是否相等 |
| `!=` | 不等于 | `a != b` | 判断 `a` 是否不等于 `b` |
| `>` | 大于 | `a > b` | 判断 `a` 的值是否比 `b` 大 |
| `>=` | 大于等于 | `a >= b` | 判断 `a` 是否大于或等于 `b` |
| `<` | 小于 | `a < b` | 判断 `a` 的值是否比 `b` 小 |
| `<=` | 小于等于 | `a <= b` | 判断 `a` 是否小于或等于 `b` |

#### 等于运算符

等于用的是**两个等号**。一个等号在 Python 里是赋值运算符，用来给变量赋值；两个等号连在一块写，才是比较运算符。

```python
a == b
```

这一句判断 `a` 和 `b` 的值是否相等：相等就返回 `True`，表示比较关系成立；不相等就返回 `False`，表示比较关系不成立。

> **易错点**：两个等号中间不要写空格，必须连着一块写。

#### 不等于运算符

不等于的写法是在等号前面加一个叹号：

```python
a != b
```

判断 `a` 是否不等于 `b`。如果 `a` 确实不等于 `b`，返回 `True`，否则返回 `False`。同样，叹号和等号中间不能有任何其他字符，也没有空格。

#### 大于与小于

大于号的写法和数学里一样，`a > b` 就是判断 `a` 的值是否比 `b` 大、这个条件是否成立。小于号同理。

#### 大于等于与小于等于的写法差异

这里的写法需要专门记一下。数学里的大于等于是大于号下面画一道横线，小于等于是小于号下面画一道横线。但编程语言里的大于等于是两个符号写在一起——前面一个大于号，后面一个等于号；小于等于则是一个小于号加一个等于号。

```text
名称      数学写法      编程写法
大于等于  大于号加下划线    >=
小于等于  小于号加下划线    <=
```

数学里的大于等于是大于号下面画一道横线，小于等于是小于号下面画一道横线；键盘上没有这两个现成的字符，所以编程语言把它们拆成两个符号拼起来写。

#### 这些符号在键盘上的位置

- 小于号 `<`：键盘上标注的那个小于号键；
- 大于号 `>`：键盘上标注的那个大于号键；
- 叹号 `!`：不等于要用到的那个叹号键。

### 一组表达式的输出结果

先看一串比较表达式的写法，重点在后面的表达式部分：

```python
print(100 == 100)
print("100" == "100")
print(100 != 100)
print(100 < 100)
print(100 <= 100)
print(100 > 100)
print(100 >= 100)
```

逐个预判：

1. `100 == 100`：判断两个值是否相等，两个都是 `100`，而且都是数字类型，结果是 `True`；
2. `"100" == "100"`：两个字符串类型的 `100` 是否相等，两个值完全一致，结果也是 `True`；
3. `100 != 100`：`100` 和 `100` 必然相等，所以"不等于"不成立，结果是 `False`；
4. `100 < 100`：`100` 必然不小于 `100`，结果是 `False`；
5. `100 <= 100`：小于等于包含了等于，结果是 `True`；
6. `100 > 100`：`100` 必然不大于 `100`，结果是 `False`；
7. `100 >= 100`：大于等于包含了等号，结果是 `True`。

实际运行输出依次是 `True`、`True`、`False`、`False`、`True`、`False`、`True`，与预判一致。

> **提示**：写比较表达式时留意两边数据类型的搭配。`100 == 100` 和 `"100" == "100"` 之所以都成立，是因为每一组两边的值完全一致；这里的 `"100"` 是字符串，不是数字。

### 四个需求对应的比较运算符

最后通过四个需求加深理解，重点是想清楚每个需求该用哪种比较运算符。

#### 判断一个数是否为偶数

第一个需求：在数学计算当中，判断一个数是否为偶数，要使用哪个比较运算符？

先想数学上怎么判断奇偶。拿 `1`、`2`、`3`、`4` 这几个数来看：`1`、`3` 是奇数，除以 `2` 之后会余 `1`；能整除、余 `0` 的是偶数。判断过程一直在问"除以 2 余几"，这就是取余操作，用取模运算符 `%` 对上 `2`：

```text
数据 % 2 == 0  ->  偶数
数据 % 2 == 1  ->  奇数
```

这里想清楚一问：既然是在判断"是否等于 0""是否等于 1"，那要不要用比较运算符？要，用的是 `==`。

#### 判断银行卡余额是否充足

第二个需求：在电商项目的支付功能业务当中，需要判断银行卡的余额是否充足，要用哪个运算符？

余额要够付款，条件就是余额大于或等于商品金额，所以用 `>=`。

#### 判断商品库存是否足够

第三个需求：在电商项目当中购买商品，要判断商品的货物库存是否足够，用哪个运算符？

同样是比较"库存"与"购买数量"，库存要够就得大于或等于购买数量，用 `>=`。

#### 筛选不超过某个价格的商品

第四个需求：在点餐项目当中筛选商品，需要点不超过 100 元的菜品，用哪个关系运算符？

"不超过 100 元"，也就是价格小于或等于 100，用 `<=`。

> **结论**：四个需求里出现的运算符一共两个——一个是 `==`，用在"除以 2 的余数等于几"这类判断上；另一个是 `>=` 和 `<=`，用在"够不够""是否超过"这类边界比较上。

## 核心语法-数据存储与运算-运算符-逻辑运算符
> 对应分集：P21 | 原始标题：《21. 核心语法-数据存储与运算-运算符-逻辑运算符》

前面三类运算符，算术运算符、赋值运算符和比较运算符，跟我们数学课上的运算符长得很像，看一眼就知道是干什么的。今天要说的这一类不一样，逻辑运算符多半是你们第一次接触，所以先不急着讲语法，我们从一个买东西的场景说起。

假设我现在要去京东上买一台电脑。我的需求有三条：价格在 1 万块钱以内；得是大品牌；还得是高配置。你们想一下，这三条之间是什么关系——是随便满足一条我就能下单，还是必须同时都成立？

必须同时成立。价格得在 1 万以内，而且得是大品牌，并且还得是高配置，少一条这台电脑都不符合我的要求。这三个条件之间，是**并且**的关系。

现在换个场景。我要点外卖，我的需求是：要么评分最高的餐厅，要么配送最快的餐厅。这回是两个条件同时成立才行吗？不是了，只要满足其中一个就算符合我的需求——评分最高的那家可以，配送最快的那家也可以。这时候两个条件之间是**或者**的关系。

> **定义**：逻辑运算符（logical operator）就是用来连接多个条件表达式的运算符。在 Python 里，上面说的「并且」写作 `and`，「或者」写作 `or`，它们都是逻辑运算符中的一种。

所以逻辑运算符的定位很清楚：它自己不产生条件，只负责把已经写好的多个条件接到一起。

### 逻辑运算符的运算结果

逻辑运算符连接的叫条件表达式，而条件表达式的结果本身就是一个布尔值（boolean），要么真要么假，真就是 `True`，假就是 `False`。

需要特别记住的是，逻辑运算符运算之后返回的结果**也是布尔值**。这一点和我一开始的直觉不太一样：我以为把两个条件连起来，得到的是「合并后的条件」，其实得到的是一个确定的值——`True` 或者 `False`，它回答的是「这多个条件整体上到底成立还是不成立」。

> **结论**：`True` / `False` 进出，`True` / `False` 出来。两端都是布尔值，中间那段才是逻辑运算符在做的连接工作。

### 三类逻辑运算符及其判定规则

逻辑运算符一共三个：`and`、`or`、`not`。

#### 逻辑与 and

`and` 就是我们说的并且，术语叫逻辑与。「与」就是「并且」，含义是必须同时成立才算符合条件。

比如有两个条件表达式，中间用 `and` 连起来。它的判定规则是：

- 只有 `and` 左右两侧都是 `True`，整个表达式的结果才是 `True`；
- 只要左边或者右边有任何一个是 `False`，整体结果就是 `False`。

写出来就是 `a < b and b < c` 这种形式，意思是「你得满足第一个，并且还得满足第二个」。

#### 逻辑或 or

`or` 代表逻辑或，就是或者的意思，只要多个条件里有一个符合就可以了。

判定规则正好和 `and` 相反：

- 有一个条件成立，结果就是 `True`——左侧成立得到 `True`，右侧成立得到 `True`，两侧都成立同样得到 `True`；
- 只有左右两个表达式的结果**都是** `False`，结果才是 `False`。

#### 逻辑非 not

`not` 叫逻辑非，「非」就是取反。`True` 取反变成 `False`，`False` 取反变成 `True`，就是一个取反操作。

这一节里 `not` 只讲了含义，具体的写法后面用到的时候再展开。

三个运算符放在一起看，判定规则可以对照着记：

| 运算符 | 名称 | 含义 | 结果为 `True` 的条件 |
| --- | --- | --- | --- |
| `and` | 逻辑与 | 并且 | 左右两侧同时为 `True` |
| `or` | 逻辑或 | 或者 | 至少有一侧为 `True` |
| `not` | 逻辑非 | 取反 | 操作数为 `False` |

> **易错点**：`and` 和 `or` 记反是这一段最常见的翻车方式。可以这样抓：`and` 要求苛刻，两边全 `True` 才给 `True`；`or` 要求宽松，有一个 `True` 就放行。苛刻的那个对应「并且」，宽松的那个对应「或者」。

### 案例一：判断一个整数是否落在 10 到 20 之间

需求是：在键盘上录入一个整数，判断这个数字是否在 10 到 20 之间，在就输出 `True`，不在就输出 `False`。

先把条件拆出来。一个数字要落在 10 到 20 之间，它得大于等于 10，并且还得小于等于 20。两个条件之间是 `and` 还是 `or`？是 `and`——「大于等于 10」和「小于等于 20」这两条必须同时成立，这个数字才在区间内。

代码写出来是这样：

```python
# 从键盘录入一个整数
number = int(input('请输入一个整数：'))

# 判断这个数字是否在 10 到 20 之间
print(f'{number}在10到20之间：', number >= 10 and number <= 20)

# and 连接的条件是并且的关系：左右两侧的运算结果都是 True，结果才是 True
# 左右两侧有任何一个不成立，结果就是 False
```

这里有个必须交代清楚的点：`input` 从键盘接收到的数据**都是字符串类型**。要做数字之间的大小比较，就得先把字符串转成数字，所以外面套了一层 `int()`。字符串转数字用的是内置工具 `int`，把 `input` 的结果传进去，拿到的就是数字类型。

写法上还能再省一步。既然 `input` 的结果马上要交给 `int` 处理，中间就不必先用一个变量接住字符串再转换——直接把 `int(input(...))` 连起来写，变量 `number` 接到的就已经是数字类型了。上面代码用的就是这种写法。

现在跑几个值验证一下整条判定链：

- 输入 `5`：`5 >= 10` 吗？不大于。第一个条件不成立，只要有一个不成立结果就是 `False`，输出 `False`。
- 输入 `15`：`15 >= 10` 成立，`15 <= 20` 也成立，两侧同时成立，输出 `True`。
- 输入 `60`：`60 >= 10` 成立，但 `60 <= 20` 不成立，这个条件运算的结果是 `False`，整体也就是 `False`，输出 `False`。

`and` 的行为在这里看得很直白：两侧都成立才是 `True`，否则一律 `False`。

> **提示**：整段代码下面那条波浪线是 IDE 给的提示，说这里有「简化链式比较」。点一下它给的按钮，`number >= 10 and number <= 20` 会被自动改写成 `10 <= number <= 20`，效果完全一样。这种连续比较是 Python 特有的写法，知道它存在就行；这一段我们为了看清 `and` 的连接作用，仍然用两侧分别写条件的写法。

### 案例二：判断一个整数是否不在 10 到 20 之间

第二个需求：从键盘输入一个整数，判断这个数字是否**不在** 10 到 20 之间。

先想清楚「不在 10 到 20 之间」意味着什么。这个数字要么小于 10，要么大于 20，两种情况占其一，它就落在区间外面。

那么这两个条件之间用 `and` 还是 `or`？这次是 `or`。因为它不需要同时满足——小于 10 的满足第一条，大于 20 的满足第二条，只要满足其中一个，这个数就不在区间里。

```python
# 从键盘录入一个整数
number = int(input('请输入一个整数：'))

# 判断这个数字是否不在 10 到 20 之间
print(f'{number}不在10到20之间：', number < 10 or number > 20)

# or 连接的条件是或者的关系：只要其中有一个成立，结果就是 True
# 全部不成立，结果才是 False
```

结构上和第一个案例几乎一样，`input` 加 `int()` 的输入部分不用动，只把后半段的判定条件从「大于等于 10 且小于等于 20」换成「小于 10 或大于 20」。

同样试几个值：

- 输入 `1`：`1 < 10` 成立，有一个条件成立结果就是 `True`，输出 `True`。
- 输入 `15`：第一个条件不成立，第二个条件也不成立，两个都是 `False`。所有条件都不成立，结果才是 `False`，输出 `False`。
- 输入 `56`：第一个条件不成立，但第二个条件 `56 > 20` 成立，结果同样是 `True`，输出 `True`。

一个数在区间里，两个案例给出的结论正好相反，这也顺便说明了「在区间内」和「不在区间内」的判断为什么各用一个运算符：前者要求两个边界条件**都**守住，后者只要求突破**任一**边界。

### 实际开发中的应用场景：登录条件

逻辑运算符在真实项目里到处都是，拿 B 站登录页面举两个例子就够了。

登录要输入用户名和密码。点下登录按钮之后，程序要校验用户名是否正确、密码是否正确。那么什么时候才算登录成功？这两个条件之间是 `and` 还是 `or`？

是 `and`。用户名必须正确**并且**密码也必须正确，缺一个都进不去，两者之间是并且的关系。

再看另一个场景：登录方式有好几种，可以扫左侧的二维码登录，可以基于密码登录，也可以用短信方式登录。这三种方式之间又是什么关系？

是 `or`。你采用其中任意一种方式登录就可以了，不需要三样同时来一遍，所以这里用或者连接。

> **结论**：判断逻辑运算符该用哪个，不必背规则，问自己一句——这些条件得**全部**满足，还是**满足一个就行**。全部满足用 `and`，满足一个就行用 `or`。

应用场景远不止这些，这里只是开个头。真正要拿到手的是 `and` 和 `or` 的区别，以及看到需求时能判断出该用哪一个。

### 要点回顾

两个问题清楚了，这一段就过关了。

第一，什么是逻辑运算符。它就是把多个条件表达式连接起来的运算符，最终运算结果是一个布尔值。

第二，逻辑运算符有哪些。一共三个：`and` 代表并且，`or` 代表或者，`not` 代表非、是取反操作。其中 `and` 连接的条件必须同时成立结果才是 `True`，`or` 连接的条件只要其中一个成立结果就是 `True`，而 `not` 就是取反。
