## 第 1 章：核心语法-数据存储与运算-字面量
> 对应分集：P09 | 原始标题：《09. 核心语法-数据存储与运算-字面量》

第一章节的收尾是给 Python 开发环境做完准备，并用专业的开发工具 PyCharm 体验了一把 Python 程序的开发。从这一节开始进入第二章节——Python 当中的核心语法。核心语法内容比较多，我们分成五个部分推进：第一部分是数据的存储与运算，第二部分是数据的逻辑处理，第三部分是数据存储容器，第四部分是函数，最后一部分是面向对象编程。

第一部分的"数据的存储与运算"里装着字面量、变量和运算符，它自己又拆成四小节：字面量与变量、常见的数据类型、输入与输出、各种各样的运算符。这里先把两个词分开——**字面量决定数据在代码当中是怎么写的，变量决定数据在代码当中是如何存储的**。先解决"怎么写"这件事。

### 1. 什么是字面量

字面量指的是在程序当中直接书写的一些固定值，也就是写在代码里的那些数据。

比如程序当中的一些数字：18、8.5、3.1415926、-5，这些是不是都是数字？再比如 Python 这样一段文本，或者 HelloWorld 这样一段文本。这些写在代码里的固定数据、固定值，都叫做字面量。

> **定义**：字面量（literal）是在代码中直接书写出来的固定值。

回想一下第一章节写 Python 入门程序的时候，我们往控制台输出了对应的值，输出了 HelloWorld 以及 Hello Python。写出来的这段文本，其实就是字面量的写法。而不同的数据类型，字面量的写法也会有差异。

所以学字面量只需要盯住两件事：第一件，字面量有哪些种类；第二件，不同种类的字面量具体的书写格式。

### 2. 常见类型与字面量写法

把 Python 当中常见的类型，以及这些类型对应的字面量写法罗列在一起，就是这样一张表：

| 类型 | 类型名 | 字面量示例 | 书写方式 |
| --- | --- | --- | --- |
| 整数 | int | 10、18、-5、0 | 直接写 |
| 浮点数（小数） | float | 8.5、3.14、1.0、-3.5 | 直接写 |
| 布尔 | bool | True、False | 首字母必须大写 |
| 字符串 | string | "Hello Python" | 必须用引号引起来 |
| 空值 | NoneType | None | 直接写 None |
| 数据容器 | list、tuple、dict、set 等 | —— | 后面课程展开 |

最后一行是一个大类，里面还涉及列表、元组、字典、集合等好些容器类型，后面课程会详细讲，现在不用关注它。眼下把这五类常见字面量的写法记住就够了。

#### 2.1 数字类型：整数 int 与浮点数 float

数字类型当中又分为整数和小数，小数也叫浮点数。整数在 Python 当中就是 int，浮点数就是 float。

看表里那一列示例就能发现：10、18、-5、0 都是整数；8.5、3.14、1.0、-3.5 都是浮点数，都是小数。

> **结论**：数字类型的写法和日常的写法完全一样，整数该怎么写就怎么写，小数该怎么写还怎么写，直接写就行。

#### 2.2 布尔类型 bool 与 True/False

布尔类型是用来表达生活当中的一些逻辑的。

举个例子：10 大于 0。这个判断结果是对的还是错的？10 确实大于 0，所以逻辑判断的结果是**真**，真在布尔类型里用 `True` 来表示。再举一个：0 大于 5。0 并不大于 5，这个判断是不正确的、是不对的，逻辑判断称之为**假**，假用 `False` 来表示。

所以布尔值就只有两个取值，要么真、要么假：条件成立就是真，条件不成立就是假。

> **易错点**：`True` 和 `False` 的首字母必须大写。写成 `true`、`false` 不是布尔字面量。

还有一点要认识清楚：布尔类型本质上也是属于数字类型的，属于数字类型当中的整型。在涉及一些数学运算的时候，它会自动把 `True` 转换为 1，把 `False` 转换为 0。

#### 2.3 字符串类型 string 与引号

字符串就是用来描述文本的一种格式，也叫文本字符串。像"人生苦短我用 Python"、像入门程序里写过的 Hello Python、HelloWorld，这些都是文本，都是字符串类型。

字面量当中的字符串需要**使用引号将其引起来**。

> **结论**：所有被引号引起来的内容，都是字符串。

字符串不一定非得用双引号，单引号也可以，这一点后面会详细讲到。

#### 2.4 空值类型 NoneType 与 None

空值类型是一个比较特殊的类型，叫做 NoneType。这个空值表示这个值是空的、或者说没有值。它里面只包含一个字面量，就是 `None`。

> **定义**：`None` 表示没有值或者说是空值，是空值类型里唯一的字面量。

#### 3.2 各类字面量的书写与运行结果

先把数字写出来。单独写一个数字，运行之后是没有任何效果的——代码只是被解释器读到，并没有输出这个动作。把数字交给 `print`，才能看到结果。

```python

```

100 是整数，3.14 是小数，也就是浮点数。

接着写布尔类型。布尔类型里面就两个值，一个 `True`，一个 `False`。这里有个坑：直接写成小写的 `true`，这一行马上就报错了，原因就是布尔字面量的首字母必须大写。

```python

```

```python

print(False)
```

再往下是字符串类型。字符串必须使用引号将其引起来，一段文本不引起来这块就报错了。

```

最后一种是空值，写法就是 `None`，代表没有值或者说是空值。

```

右键选择运行，控制台里输出的就是 100、3.14、True、False、Hello Python、None——上面写的这些字面量全都输出出来了。

#### 3.3 布尔值参与算术运算

前面说过布尔类型本质上也属于整型 int，那么在涉及算术运算的时候，它会自动转换为 int 类型。看一个现象：

```python
print(True + 1)
print(False - 1)
```

按刚才那条转换规则推一遍：`True` 转成 1，1 加 1 等于 2；`False` 转成 0，0 减 1 等于 -1。运行之后控制台上正是 2 和 -1。

> **结论**：布尔值不只是一个逻辑标记。做加法减法这类算术运算时，`True` 会自动变成 1，`False` 会自动变成 0。

### 4. 两组字面量对比题

题干：下面这两组字面量的写法，各自有没有差异？

- 第一组：`"10010"` 与 `10010`
- 第二组：`"True"` 与 `True`

解析：判据只有一条——**所有以引号引起来的都是字符串**。

第一组里，带引号的 `"10010"` 是字符串，不带引号的 `10010` 是整数类型 int，两者有差异。

第二组里，带引号的 `"True"` 是一个普通的字符串，不带引号的 `True` 才是布尔类型当中的真，两者也有差异。

答案：两组都有差异。类型一旦被引号改变，后面参与拼接、运算时的行为也就跟着变了。

## 第 2 章：核心语法-数据存储与运算-变量
> 对应分集：P10 | 原始标题：《10. 核心语法-数据存储与运算-变量》

通过字面量的学习，我们已经掌握了这些数据在程序当中是如何编写的。接下来换一个问题：这些数据在程序当中又是如何存储的？答案就是变量。

### 1. 变量是存储单个数据的容器

变量指的是在程序当中用来存储**单个数据**的容器。

> **定义**：变量是程序当中用来存储单个数据的容器，一个变量只能存储一个数据。

变量就是一个容器，容器就是用来存东西的，只不过在程序当中这个容器存的是数据。

通常在程序开发当中，我们会把容易变化的数据存储在变量当中。变量、变量，是容易变化的量，所以容易变化的数据就交给它来记。平时上网的时候，哪些数据是容易发生变化的？比如 B 站上这门课程的页面，播放量、弹幕数量、正在观看的人数，这些数据是不是都一直在变？播放量随着时间推移一直在往上增，弹幕数量也会持续发生变化，正在观看的人数一会儿高一会儿低。还有点赞数、投币数、收藏数、转发的数量，以及这门课程对应的笔记数量，都会在这个界面呈现出来，而这些都是会实时发生变化的数据。开发这样的系统时，就可以把这些数据直接记录在变量当中。

拿播放量举例，假设这个数据是 1114.1 万，就把这个数据存进变量里，这就是一个容器：

```text
变量 number（容器）
+----------------+
|     1114.1     |
+----------------+
```

随着时间推移，容器里的数据会持续发生变化，这正是变量存在的意义。

> **易错点**：变量指的是数据存储的**容器**，而不是里面所存储的数据。当然，通过变量这个容器，是可以找到它当前存放的那个数据的。

### 2. 变量的定义语法

Python 当中定义变量的语法格式比较简单：**前面写变量名，等号之后写变量值**。

```python
number = 1114.1
```

这行代码定义了变量 `number`，`number` 就是变量的名字。变量名其实就相当于给容器起了一个名字——定义了一个叫 `number` 的变量，就相当于定义了一个容器，容器的名字叫 `number`。

后面这个等号是一个**赋值操作**，它把等号右侧的值赋给左侧的变量，所以它是一个赋值运算符。而等号右侧写的是要往这个变量对应的容器当中存储的数据是什么，这里写 1114.1，就代表 `number` 这个容器里面存储的值是 1114.1。

既然它是变量，这个值就可能发生变化。值要变的时候，只需要给 `number` 重新赋一个值：

```python
number = 1114.2
```

这一行执行完，`number` 里存储的值就变成 1114.2 了。

> **提示**：Python 官方的代码风格建议，赋值运算符的前面和后面各留一个空格。这是规范不是规定，你可以不遵守，但写的时候最好按规范来。

### 3. 动态类型语言：一个变量可以接收不同类型的数据

Python 是动态类型语言。定义变量的时候不需要指定这个变量的类型，它在运行的时候，解释器会自动进行类型检查。而且变量的类型在程序运行的过程当中也是可以变化的。

简单说就是：一个变量既可以接收整数类型 int，也可以接收小数类型，也可以接收字符串类型，它是动态类型的。

> **结论**：动态类型语言允许一个变量先后装着不同类型的数据，但这不代表应该这么用。

在项目开发当中，定义变量的时候一般一个变量只会接收一种类型的值。语言层面它确实可以接收不同类型的值，这个特性知道一下就行。

### 4. 在 PyCharm 中演示变量的定义

#### 4.1 定义变量并输出

先加上一行注释，标明下面演示的是变量。

```python
# 下面演示的是变量
number = 1114.1
print(number)
```

右键运行，这个变量的值就直接输出出来了——输出 `number`，最终输出的是 `number` 这个变量对应的值 1114.1。

运行的时候会连上面那些字面量的代码一起执行，因为右键运行跑的是整个 Python 文件，前面的代码都会执行。如果不需要前面的代码执行，把它们全部选中，按 `Ctrl + /` 批量注释掉就行；想取消注释，再按一次 `Ctrl + /`。

#### 4.2 重新赋值

播放量是会发生变化的。假设它现在增加了 1 万，也就是在原有 `number` 的基础上增加 1，那就让原有的变量参与到运算当中来：

```python
number = number + 1
print(number)
```

这就是给 `number` 赋了一个新值，新值是原来的 `number` 再加 1。运行之后，播放量就变成了 1115.1。这里写的 `1`，对应的就是"1 万"。

#### 4.3 让同一个变量改存其他类型的数据

上面的 `number` 是数字类型，具体说是浮点数。现在给它重新赋一个值——赋一个 `"OK"`，这是一个字符串：

```python
number = "OK"
print(number)
```

运行之后 `number` 的值就是 `"OK"`，此时这个变量装的是一个字符串。

除了字符串，还可以再赋一个 `True`：

```python
number = True
print(number)
```

运行之后 `number` 的值就是 `True`。一个变量前后装着三种不同类型的数据，整个变化过程是这样的：

```text
number = 1114.1   -->   number = number + 1   -->   number = "OK"   -->   number = True
   1114.1                   1115.1                     "OK"                 True
```

所以这里要加一行注释记清楚这条特性：

```python
# Python 是动态类型语言，一个变量可以存储不同类型的数据
# 但是项目开发中我们推荐变量只存储一种类型的数据
```

> **提示**：如果一个变量在定义的时候就规划它存浮点数，就不要一会儿存浮点数、一会儿存字符串、一会儿又存布尔类型。确实还有存字符串、存布尔类型的需求，那就再定义一个变量：

```python
a = True
```

### 5. 案例：未来两个月的播放量输出

需求是这样的：B 站播放量的基础播放量是 20.7 万，每月新增播放量 50 万，请输出未来两个月每个月的播放量。

#### 5.1 用两个变量承接基础量与新增量

基础播放量是 20.7 万，每月新增播放量是 50 万，那就定义两个变量来存这两个数据：

```python
base = 20.7   # 基础播放量
incr = 50     # 每月新增播放量
```

未来第一个月的播放总量，就应该是基础播放量加上每一个月的新增播放量：

```python
print("未来第一个月的播放量", base + incr)
```

`print` 语句当中想一次性输出多项数据，多项数据之间用逗号分隔就可以了。运行结果是 70.7，也就是 70.7 万，没有问题。

> **提示**：`print` 的多项数据之间用逗号分隔，最终会把这几项数据拼接成一行输出。

#### 5.2 第二个月的输出与一次性定义多个变量

未来第二个月的播放总量，就是 `base` 加上 `incr` 之后再加上一个 `incr`：

```python
print("未来第二个月的播放量", base + incr + incr)
```

在 PyCharm 里想快速复制一行，按快捷键 `Ctrl + D` 就行，复制过来改一下字符串描述即可。运行之后，未来第一个月、未来第二个月两个播放总量都输出出来了，第一个是 70.7，第二个是 120.7。

这个案例里一共定义了两个变量。如果一次性想定义多个变量，还有一种简化的写法，可以把两行合并成一行：

```python
base, incr = 20.7, 50
```

> **结论**：一条语句定义多个变量时，多个变量名之间用逗号分隔，等号之后多个值之间也用逗号分隔；第一个值赋给第一个变量，第二个值赋给第二个变量。

最后还有一条使用上的硬要求：**变量必须在赋值之后才能使用**。只声明一个名字、没有给它赋值就去用它，程序会直接报错。

## 第 3 章：核心语法-数据存储与运算-标识符
> 对应分集：P11 | 原始标题：《11. 核心语法-数据存储与运算-标识符》

定义变量的时候，我们需要为每一个变量起个名字，比如 `number`、`a`，这些都是变量的名字。那变量名除了 `number`、`a` 这样的小写字母，能不能用中文？名字当中能不能引入一些特殊的符号？能不能使用大写字母？

这一连串问题，Python 当中的**标识符**就是用来回答的：它告诉我们如何为变量起一个符合规则的名字。

### 1. 标识符是什么

> **定义**：标识符（identifier）指的是开发人员在代码当中为变量、为函数、为类等元素所起的名字。

目前直接接触到的只是变量，函数和类在后面课程当中会详细学习，眼下只要知道标识符就是我们为变量所起的名字就够了。而 Python 当中，标识符是有严格的定义规则的。

### 2. 标识符的四条命名规则

这里说的是命名的**规则**，也就是**规定**——规定是我们必须要遵守的，必须按照这个来。

| 命名规则 | 具体要求 |
| --- | --- |
| 字符范围 | 只能包含字母、数字、下划线。字母包括大写 A 到大写 Z、小写 a 到小写 z，数字就是 0 到 9 |
| 首字符 | 不能以数字开头，但下划线可以开头，而且不限个数 |
| 关键字 | 不能使用 Python 当中的关键字作为标识符 |
| 大小写 | 严格区分大小写 |

第一条规则里藏着一个细节：标识符当中唯一能包含的符号，就只有下划线这一个。

第三条规则里的关键字，是 Python 内部已经占用的名字。先认识几个：学字面量时见过的布尔类型那两个字面量 `True` 和 `False`，它们就是关键字，不能作为变量名；`None` 也是关键字。后面还要学到的 `and`、`or`、`if`、`else`、`elif`、`for`、`while`，这些统统都是 Python 当中的关键字，都不能作为标识符、也就是不能作为变量名。

第四条规则说的是严格区分大小写。`age`、`Age`、`AGE` 由于字母的大小写不同，其实是三个变量。

### 3. 合法与非法标识符的判定

对照这四条规则，逐个看一批候选名字：

| 候选名字 | 判定 | 依据 |
| --- | --- | --- |
| `name` | 合法 | 只有小写字母，不以数字开头，也不是关键字 |
| `Name` | 合法 | 大写字母同样属于字母，字母开头即可 |
| `_name` | 合法 | 数字不能开头，但下划线可以开头 |
| `__name` | 合法 | 下划线的个数没有限制，任意多个都可以 |
| `my_name` | 合法 | 下划线可以出现在名字中间 |
| `name_` | 合法 | 下划线也可以出现在名字末尾 |
| `name6` | 合法 | 名字里可以包含数字，只要不打头 |
| `true` | 合法 | 小写的 `true` 不是关键字，大写的 `True` 才是 |
| `na$me` | 非法 | 标识符里不能使用美元符号 |
| `and`、`or` | 非法 | 关键字不能作为标识符 |
| `False` | 非法 | 关键字不能作为标识符 |
| `6name` | 非法 | 数字不能开头 |

判定一个标识符是合法还是非法，办法很直接：把它敲出来运行一把看效果。能正常运行，就说明是合法的标识符；不能正常运行，就说明是非法的标识符。

先拿 `true` 试：

```python
true = 1
print(true)
```

这段代码能正常输出结果，说明 `true` 是一个合法的标识符。

再把首字母换成大写：

```python
True = 1
print(True)
```

这时候输出的就不是正常结果了，出现了语法错误，意思是不能为 `True` 分配一个值。原因就是 `True` 是布尔类型的字面量，表示真，它是一个关键字，不能作为标识符使用。

再看 `6name`，这一条更省事：

```python
6name = 1
```

代码敲出来甚至不用运行，就已经报错了，因为数字不能开头。

> **提示**：判断依据始终是那四条规则，运行只是最快的一种验证手段。

### 4. 变量名的三条命名规范

规则讲完了，接下来是变量名的命名**规范**。注意，前面讲的是命名规则，规则也就是规定，规定必须遵守；而这里要讲的是规范——**规范不是规定，你可以不遵守**，但是 Python 官方建议我们在编写代码的时候尽量按照规范来。

> **结论**：规定不遵守，程序直接跑不起来；规范不遵守，程序能跑，但代码会变难维护。

这三条规范出自 Python 官方的文档，这份文档叫 PEP 8。PEP 是 Python 社区的一个技术文档和标准化的机制，PEP 8 里面描述了 Python 的代码风格以及编码规范。

| 命名规范 | 具体要求 | 符合规范 | 不符合规范 |
| --- | --- | --- | --- |
| 见名知意 | 名字要能看出里面存的是什么 | `name`、`age`、`color` | `a`、`a1`、`a2` |
| 多词用下划线连接 | 涉及多个单词时，单词之间用下划线分隔 | `update_time`、`my_name`、`user_first_name` | `updatetime`、`myname` |
| 英文字母全小写 | 变量名里的英文字母一律小写 | `my_name` | `My_Name` |

**见名知意**说的是变量名要起得有一定意义。`name`、`age`、`color` 这三个名字就比较有意义：看到 `name` 就知道这是名字，看到 `age` 就知道是年龄，看到 `color` 就知道是颜色。再看 `a`、`a1`、`a2`，如果有需要还会有 `a3`、`a4`、`a5`、`a6`——通过名字根本看不出里面存的是什么数据。如果所有变量都这么定义，去开发一个大型项目，后期维护起来就会比较难。所谓维护难，指的是过了几个月、一两年之后再回来看这段代码，可能就不太清楚 `a` 里面存的是什么、`a2` 里面存的是什么了。

> **易错点**：`a`、`a1`、`a2` 从标识符的命名规则层面来说也是合法的，只是不符合项目开发的规范，别把"合法"和"规范"当成一回事。

**多个部分用下划线连接**，就是如果一个变量名涉及多个单词，单词之间用下划线分割。`update_time` 里 `update` 是更新、`time` 是时间，两个单词中间用下划线连接；`my_name` 里 `my` 和 `name` 是两个单词，两部分之间下划线分割；`user_first_name` 里 `user`、`first`、`name` 是三个单词，每两个相邻单词之间都用下划线分割。而 `updatetime`、`myname` 没有使用下划线连接，就不符合规范。这一条规范也叫**蛇形命名法**（snake case）。

**英文字母全小写**，指的是变量名当中出现的英文字母全部用小写。

刚开始有个印象就行。后面随着课程推进，定义变量的时候都会按照这个规范来定义，写得多了自然也就记住了。

## 第 4 章：核心语法-数据存储与运算-变量案例(变量交换)
> 对应分集：P12 | 原始标题：《12. 核心语法-数据存储与运算-变量案例(变量交换)》

关于变量的定义以及变量名的命名规范，这一块内容已经全部讲完了。最后来完成一个案例，通过这个案例加深对变量的理解。

### 1. 案例需求与直接赋值的失败

需求是这样的：现在有两个变量分别是 `a` 和 `b`，`a` 的值是 10，`b` 的值是 20。要求把 `a` 的值赋给 `b`，`b` 的值再赋给 `a`，也就是将两个变量的值交换一下，然后再将这两个变量输出到控制台当中。

这个需求看起来还是比较简单的，先顺着直觉猜一种做法：既然是要把 `b` 的值赋给 `a`、把 `a` 的值赋给 `b`，那可不可以直接写成 `a = b`，然后 `b = a`？

```python
a = 10
b = 20
a = b
b = a
```

这么写其实是有问题的。分析一下：`b` 的值是 20，`a` 的值是 10，执行 `a = b` 这一句，就相当于把 `b` 的值也就是 20 赋给了 `a`。这一步操作完毕之后，`a` 的值变成多少了？变成 20 了——注意，`a` 原来的 10 已经被覆盖掉了。

紧接着再执行第二行 `b = a`。第一步执行完之后 `a` 的值已经变成 20 了，所以 `b = a` 就相当于把这个 20 又赋给了 `b`。两行走完，`a` 和 `b` 的值都变成了 20，明显跟需求不符。

```text
初始              a = b             b = a
a = 10            a = 20            a = 20
b = 20            b = 20            b = 20
```

读图：第一列是初始状态，第二列是执行 `a = b` 之后，`a` 被 `b` 的值覆盖；第三列是执行 `b = a` 之后，`b` 拿到的是已经被覆盖过的 `a`。原来的 10 在中途丢掉了，所以这种解题思路是错误的。

> **易错点**：赋值是"覆盖"，不是"记住"。一旦某个变量被重新赋值，它原来的取值就再也找不回来了。

### 2. 用两个杯子的类比找思路

那该怎么实现呢？这时候要回到最根本的问题上：变量是不是就是存储数据的容器？现在的情况就相当于两个容器，一个 `a` 一个 `b`，`a` 这个容器里存了 10，`b` 这个容器里存了 20。想把 `a` 的值赋给 `b`、`b` 的值再赋给 `a`，也就是把两个容器里的数据换过来。

拿日常生活里的例子类比一下：这里有两个杯子，一个杯子里装满雪碧，另一个杯子里装满可乐。需求是要将两个杯子里面的饮料交换——把第一个杯子里的雪碧装到第二个杯子里，把第二个杯子里的可乐装到第一个杯子里。

日常生活当中遇到这件事，马上就会想到：再拿一个空杯子过来。拿过来之后，先把第一杯里面的雪碧倒进这个空杯子，第一个杯子就空了；再把第二杯里面的可乐倒入第一个杯子，此时第二个杯子也空了；最后一步，把第三个杯子当中的雪碧倒进第二个杯子。这样雪碧和可乐就换过来了。

```text
        A 杯        B 杯        C 杯
初始    雪碧        可乐        空杯
一步    空杯        可乐        雪碧
二步    可乐        空杯        雪碧
三步    可乐        雪碧        空杯
```

读图：A、B 是要交换的两个杯子，C 是临时借来的空杯。每一步只动一个杯子，而 C 的存在保证了任何一份饮料在被倒入新杯子之前都有一个落脚点。

所以日常生活当中解决这个需求，是要借助于第三个杯子的。回到需求本身：每一个变量都是一个容器，只不过这个容器里装的是数据。那么想让 `a` 和 `b` 这两个容器里存储的数据交换过来，同样需要借助于第三个变量。

> **结论**：容器里的东西要互换，必须有一个额外的空容器周转；变量里的值要互换，就必须有一个额外的临时变量周转。

### 3. 借助临时变量完成交换

先定义出两个变量，然后引入第三个变量 `c`，用它先把 `a` 的值记录下来：

```python
a = 10
b = 20

c = a     # 用临时变量记下 a 的原始值
a = b     # a 换成 b 的值
b = c     # b 换成临时变量里记着的原 a 值

print(a, b)
```

逐行走一遍：执行 `c = a`，此时 `a` 的值是 10，所以 `c` 的值就是 10，`a` 的原始值被记录下来了。执行 `a = b`，走到这一步 `b` 的值还是 20，`a` 的值就变成了 20。执行 `b = c`，此时 `b` 取到的是 `c` 里存着的 10，`b` 的值就变成了 10。

```text
初始           c = a          a = b          b = c
a = 10         a = 10         a = 20         a = 20
b = 20         b = 20         b = 20         b = 10
c = --         c = 10         c = 10         c = 10
```

读图：四列分别是初始状态和三次赋值之后的状态。`c = a` 把 `a` 的原始值 10 备份出来；`a = b` 完成 `a` 的替换；`b = c` 把备份的 10 交给 `b`。最后 `a` 是 20，`b` 是 10，两个变量的值成功交换。

> **易错点**：第三步 `b = c` 不能写成 `b = a`。因为执行 `a = b` 之后 `a` 已经是 20 了，再写 `b = a` 就又把 20 赋给 `b`，回到失败方案的老路上去了。

这里的 `c` 可以理解为一个临时变量：它并不是需求当中需要的变量，作用只是临时记录一下 `a` 的值。

运行之后，`a` 的值变成了 20，`b` 的值变成了 10，符合需求。

### 4. 三个变量的取值轮换练习

难度略微提升一点的练习：现在有三个变量分别是 `a`、`b`、`c`，`a` 是 100，`b` 是 200，`c` 是 300。需要将三个变量的值交换，把 `a`、`b`、`c` 的值分别赋值给 `c`、`a`、`b`，然后输出到控制台。

这个需求跟上面的案例基本上是一致的，只不过现在是三个变量。

解析：先把"谁拿谁的值"拆开。按题目的对应关系，`c` 拿 `a` 的值、`a` 拿 `b` 的值、`b` 拿 `c` 的值，三个变量互为数据来源，本质上是一次轮换。难点和两变量交换是同一个——三个赋值语句必须有一条先执行，而它一执行，被赋值的那个变量的旧值就没了。所以动手之前要先敲定执行顺序，并把第一个被覆盖掉的旧值提前记进一个临时变量，剩下的两次赋值才有旧值可用。

答案：三个变量最终的取值是 `a = 200`，`b = 300`，`c = 100`。

## 第 5 章：核心语法-数据存储与运算-数据类型
> 对应分集：P13 | 原始标题：《13. 核心语法-数据存储与运算-数据类型》

先把话说明白：数据类型这件事，其实我们在讲字面量的时候已经见过一遍了。当时一笔带过，现在把它单独拎出来讲清楚——一来它是后面所有运算符、判断与格式化的地基，二来它顺手能回答一个大家心里一直犯嘀咕的问题：我们定义变量的时候压根没写类型，那变量到底有没有类型？

### 1. 五种常见基础数据类型

Python 的数据类型比较多，现在只要求掌握最常用、最基础的五种；更高级的数据类型在后面课程里会专门展开。这五类分别描述的是：整数、小数、文本、真假、空值。

```text
int       整数        正数、负数、零          10   -100   0
float     浮点数      小数（含负小数）        8.5  3.14  -3.5
string    字符串      文本（须用引号引起）    "Hello"  "Python"
bool      布尔        真假两个值              True     False
NoneType  空值类型    只有一个值              None
```

读图时只需记住右侧那一列：类型名后面跟的就是该类型能写出来的样子。下面逐条说清边界。

**int（整数类型）**：只要是整数，无论正数、负数还是零，都用 int 表示。

**float（浮点数类型）**：也就是小数。8.5、3.14、-3.5 都是 float，正负都算，判定的唯一依据是“它是不是小数”。

**string（字符串类型）**：用来描述文本。这里有一条铁律——所有字符串都必须用引号引起，凡是用引号括起来的数据就是字符串。这一小节我们一直用双引号，字符串的多种表现形式下一小节详细讲。

**bool（布尔类型）**：表示真或假，里面只有两个选项：真就是 True，假就是 False。

**NoneType（空值类型）**：用来描述空值。这个类型比较特殊，它里面只包含一个值，就是 None；None 代表这个值为空，或者说没有值。

> **易错点**：NoneType 只装得下 None 一个值。它不是“零”，也不是空字符串，而是“没有值”这个状态本身。

### 2. 变量本身没有类型

紧接着就是那个设问：前面定义变量的时候，我们指定过这五种类型吗？

没有。`a = 10`，a 就是变量名；`name = "Python"`，name 也是变量名——两处都没写任何类型说明。

那这个变量它到底有没有类型？它有。

> **结论**：变量本身没有类型，变量里面所存储的数据才有类型。

这句话要拆到“变量是存储数据的容器”上理解：容器自身不区分自己装什么，而 type 时拿到的是容器里那份数据的类型。

`type()` 里如果传的是一个变量，输出的就是这个变量所对应的值的类型。比如定义 `number = 5.0`，`type(number)` 查出来的就是 `5.0` 的类型，也就是 float。变量虽然没有类型，但变量里面所存储的数据它是有类型的。

> **提示**：说“变量的类型”，只是“变量当前所存数据的类型”的口语简写。正因为如此，同一个变量先后存不同类型的值是允许的——只要写 `number = -100`，它此刻的类型就变成 int。

### 3. 用 type 查看字面量或变量的类型

想查看一个字面量或者一个变量的类型，借助 Python 提供的一个内置工具即可，它就是 `type`。写法是：`type` 后面跟一对小括号，括号里写上要查看类型的数据。

```python
type(数据)
```

`type` 本质上是 Python 内置的一个函数，目前就先把它当成 Python 内置的一个工具来用，后面会有专门章节详细介绍函数。

把结果打印出来，靠的还是 `print`：先让 `type` 查类型，再让 `print` 把 `type` 的调用结果打印出来。查看字面量时，括号里写的就是字面量本身，比如 `type("hello")`、`type(10)`、`type(3.14)`。

```python
print(type("hello"))    # 字符串字面量
print(type(10))         # 整数字面量
print(type(3.14))       # 浮点数字面量
print(type(True))       # 布尔字面量
print(type(None))       # 空值
```

> **易错点**：想查 `"hello"` 的类型，括号里就不能只写 `hello`。写成 `type(hello)` 时 Python 会把它当成一个名叫 hello 的变量去找，而这个变量并不存在；`type("hello")` 查的才是那份字符串数据本身。

查看变量时，括号里换成变量名，`type(number)` 得到的就是这个变量所存数据的类型：

```python
number = 5.0
print(type(number))
```

### 4. type 的运行结果与逐个验证

在课程工程里再建一个专门记录常见数据类型的脚本文件，把上面这几行调用依次写进去，运行前先自己预判一遍每行会输出什么：

| 传入 type 的数据 | 预判类型 | 实际输出 |
| --- | --- | --- |
| `"hello"` | string | `<class 'str'>` |
| `10` | int | `<class 'int'>` |
| `3.14` | float | `<class 'float'>` |
| `True` / `False` | bool | `<class 'bool'>` |
| `None` | NoneType | `<class 'NoneType'>` |

运行结果与预判逐一对应，一个都没错。输出里的 `class` 可以简单理解为“类型”的意思，后面那个 `str` 就是 string 类型，代表字符串类型；`int`、`float`、`bool` 同理。None 则属于 NoneType 这个类型，而 NoneType 当中只有一个值，就是 None，表示为空值，或者说没有值。

接着把“传变量”这条路径也验证掉，再补一段代码：

```python
number = -100
print(type(number))
```

按前面的说法，这里输出的是 number 所对应的值的类型，也就是 int。运行确认：`<class 'int'>`。

> **结论**：`type` 的作用就是获取指定字面量或变量的类型；传入变量时，得到的是该变量所存数据的类型。

### 5. 用 isinstance 判定数据类型

除了查看类型，Python 还提供了另一个内置工具用来判定类型，它叫 `isinstance`，作用是检查指定的数据是否属于特定的类型。凡是工具或者说函数调用，后面都会跟一对小括号，括号里传对应的数据——`isinstance` 需要传递两项：一项是数据，另一项是类型，表示“判定这个数据是不是后面指定的类型”。

```python
isinstance(数据, 类型)
```

判定结果会以布尔值的形式返回：是就返回 True，不是就返回 False。

```python
number = -100
print(isinstance(number, int))     # 判定 number 的值是不是 int 类型
print(isinstance(number, float))   # 判定 number 的值是不是 float 类型
print(isinstance(number, bool))    # 判定 number 的值是不是布尔类型
```

运行之前自己先推一遍：number 的值是 -100，那它就是 int 类型，所以第一行返回 True；既然是布尔值，就直接把这个 True 打印出来了。后面两行呢？都不是，所以返回 False。

运行结果正是 `True`、`False`、`False`。这就是 `isinstance` 的作用——用来判定指定的数据是否属于指定类型，是就返回 True，不是就返回 False。

> **提示**：敲 `is` 开头的东西时要看清楚再回车。编辑器里以 `is` 开头的候选不止一个，别选错；输入时也可以双击候选或按补全键确认。

```text
                 data stored in a literal or a variable
                                  |
        +-------------------------+-------------------------+
        |                                                   |
   type(data)                                  isinstance(data, type)
        |                                                   |
   the type itself                            "is it this type or not"
   <class 'str'> / <class 'int'>                        True / False
```

读图看两个工具的分工：左边回答的是该数据属于什么类型，右边回答的是该数据是不是某个指定类型。左边的结果是类型对象，右边的结果是布尔值。
