# 输入输出与运算符运算体系
## 键盘输入与输出通路


* **输入输出（Input / Output）**
    * > **定义**：程序与键盘、控制台之间的数据通路，负责拿到键盘上录入的数据，以及把数据输出到控制台。
    * 输出一侧由 `print` 承担，把数据输出到控制台；输入一侧由 `input` 承担，负责取回键盘录入的数据。
    * 价值：程序里的数据不再只能写死在代码里，写死的姓名、年龄、专业、爱好不便于灵活使用。

* **键盘输入语句（`input`）**
    * > **定义**：`input` 本质是一个函数，属于 Python 内置功能，不需要自己定义就能直接调用。
    * 语法为 `input("提示信息")`：`input` 后面跟一对括号，括号里放对应的提示信息。
    * 提示信息在代码执行时显示到控制台给用户看，让用户知道该输入什么；用户录入完成后的结果需要赋给变量，写法为 `s = input("提示信息")`。
    * 提示信息里的冒号等内容由使用者自己写进提示信息内部。
    * `input` 的执行是**阻塞式**的：第一句 `input` 执行完不会立即执行第二句代码，而是停在那里等输入；输入并回车后才把内容赋给变量，再继续往下执行第二个 `input`。

* **键盘数据的数据类型**
    * 不管在键盘上输入的是什么类型的数据，最终拿到的**永远是字符串**。
    * 输入 `18` 拿到的是字符串类型的 `"18"`，不是整数类型的 `18`；提示信息写成"请输入您的年龄"也一样，实际拿到手的仍是字符串。
    * 要参与运算就必须先转换类型，这是后续所有涉及键盘输入运算的前提。
    * > **易错点**：`input` 拿到的数据参与算术运算前必须转成数字类型，否则加号变成拼接、减号直接报错。

* **内置类型转换工具**
    * `int` 将其他类型转换为整数类型，典型用法 `int("1000")` 得到整数 `1000`。
    * `str` 将其他类型转换为字符串类型，典型用法 `str(100)` 得到字符串 `"100"`。
    * `float` 将指定数据转换为浮点数类型，也就是小数类型；处理小数输入时会用到。
    * `bool` 将其他类型转换为布尔类型。
    * 当下用得最多的是 `int` 与 `str` 两个。

* **f-string 输出拼接**
    * 老办法用加号把一段一段字符串接起来，写起来又长又容易漏空格。
    * 省事的做法是在字符串前面加一个 `f`，字符串自带占位能力，用大括号占位、括号里写变量名，写法如 `print(f"您的姓名是{name}，年龄为{age}")`。
    * 大括号这种占位符里不仅能写变量，也能写表达式；案例里直接在占位符中写 `total - int(number)` 就能算出余额。

* **案例：模拟银行卡 ATM 取款**
    * 需求：银行卡里有 1 万元，根据输入的金额取钱，取钱完毕后展示余额；插卡动作不模拟。
    * 三步拆解：第一步模拟输入密码，第二步输入取款金额，第三步计算余额并输出。
    * 密码一步只做接收与打印，此时程序逻辑判断还没学到，不校验密码是否正确。
    * 总金额用变量记录，写法 `total = 10000`；余额由总金额减去本次取款金额得到。
    * 直接把字符串与整数相减时，编辑器会在字符串变量处给出黄色背景警告，悬浮提示为：这里期望 `int` 类型，实际是 `str` 类型。
    * 修正写法为 `print(f"取款后，银行卡的余额为{total - int(number)}")`，把字符串转成整数后两侧类型一致，运算成立。
    * 运行示例：输入密码 `666888` 输出 `密码正确，密码是666888`；输入取款金额 `1000` 后输出 `取款后，银行卡的余额为9000`。
    * > **易错点**：编辑器给出黄色背景警告的位置就是类型不匹配的位置，提示文本写明"期望 int 类型，实际是 str 类型"。

## 运算符的四类划分


### 按作用划分的四类运算符

* **运算符（Operator）**
    * > **定义**：对数据做运算时使用的符号，按作用一共分成四类。
    * **算术运算符**：加减乘除这一类专门做算术运算的符号。
    * **赋值运算符**：为某个变量赋值的运算符，定义变量时给变量赋值的那个等号就属于这一类。
    * **比较运算符**：用于比较两个数的符号，比如大于、小于、大于等于、小于等于。
    * **逻辑运算符**：做逻辑处理时用到的运算符，比如并且、或者。
    * 运算符数量不少，学法上是先归类、再一类一类往下走。

* **四类运算符的职责差异**
    * 算术运算符产出数字结果；赋值运算符改变变量的值，本身不产出可用的运算结果。
    * 比较运算符既不产出数字、也不改变变量的值，它产出布尔值。
    * 逻辑运算符自己不产生条件，只负责把已经写好的多个条件接到一起，运算结果也是布尔值。

### 四类运算符对比

* **四类运算符的符号数量**
    * 算术运算符七种、赋值运算符八种（含基本等号那一个）、比较运算符六种、逻辑运算符三种。
    * 四类在写法上都用键盘上现成的字符拼成，多字符符号一律连着写、中间不留空格。

* **四类运算符的结果形态**
    * 算术运算符给数字结果，赋值运算符给变量一个新值，比较运算符与逻辑运算符都给布尔值。
    * 只有赋值运算符会改变变量的值，其余三类都不改变参与运算的变量本身。

| 类别 | 全部符号 | 作用 | 返回值 | 典型示例 |
| :--- | :--- | :--- | :--- | :--- |
| 算术运算符 | `+` `-` `*` `/` `//` `%` `**` | 对数字做数学运算 | 数字（单斜杠除法必为浮点数，整除以整数为操作数时得整数） | `10 // 4` 得 `2`；`10 ** 4` 得 `10000` |
| 赋值运算符 | `=` `+=` `-=` `*=` `/=` `//=` `%=` `**=` | 把等号右侧的结果赋给左侧变量 | 不产出独立结果，只改变变量存储的值 | `number = 1 + 2` 后 `number` 为 `3`；`number += 2` 等效 `number = number + 2` |
| 比较运算符 | `==` `!=` `>` `>=` `<` `<=` | 比较两个值之间的关系 | 布尔值 `True` / `False` | `100 <= 100` 得 `True`；`100 != 100` 得 `False` |
| 逻辑运算符 | `and` `or` `not` | 连接多个条件表达式 | 布尔值 `True` / `False` | `number >= 10 and number <= 20` 得 `True` 或 `False` |

### 优先级与括号改写

* **算术优先级档位**
    * 优先级从高到低分三档：`**` 最优先；`*` `/` `//` `%` 排第二档；`+` `-` 最低。
    * 三档顺序在高到低的方向上依次排下来，同档内按表达式书写顺序参与计算。

* **括号提升优先级**
    * 想提高某个部分的优先级，就在那里加括号把它括起来，这一点和数学里一样。
    * 括号的优先级是最高的。

```text
优先级高  ──►  **                    幂指数
            ──►  *  /  //  %          乘、除、整除、取余
优先级低  ──►  +  -                  加、减
```

## 算术运算符


### 七种符号的写法与结果

* **算术运算符（Arithmetic Operator）**
    * > **定义**：数学运算的基本符号，作用于一个或多个参与运算的数字上，然后产生一个结果。
    * 写法分两类情况：加法和减法与小学课本完全一致；乘法和除法与数学里的习惯有差异。
    * 乘法用 `*`（星号）；除法用 `/`（斜杠）；整除用 `//`；取余用 `%`；幂指数用 `**` 两个星号。
    * `%` 也叫求模运算，取的是除法之后的余数，读作"10 模与 3"含义完全一样：先做除法，再看余几。
    * 幂指数求的是一个数的多少次方：`10 ** 3` 代表 10 的 3 次方，`4 ** 2` 就是 4 的平方。

| 运算符 | 名称 | 示例 | 结果 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| `+` | 加 | `10 + 4` | `14` | 与数学写法一致 |
| `-` | 减 | `10 - 4` | `6` | 与数学写法一致 |
| `*` | 乘 | `10 * 4` | `40` | 用星号表示乘法 |
| `/` | 除 | `10 / 4` | `2.5` | 结果一定是浮点数 |
| `//` | 整除 | `10 // 4` | `2` | 只保留整数部分 |
| `%` | 取余（求模） | `10 % 4` | `2` | 取除法之后的余数 |
| `**` | 幂指数 | `10 ** 4` | `10000` | 求一个数的多少次方 |

* **七种符号在键盘上的位置**
    * `+` 是等号键的上档字符，需要按住 `Shift` 再按。
    * `-` 是数字 `0` 右侧的减号键。
    * `*` 是数字 `8` 键的上档字符，按住 `Shift` 再按。
    * `/` 是问号键下方的斜杠，直接按；`//` 就是连按两下斜杠键。
    * `%` 是数字 `5` 键的上档字符。
    * `**` 是连按两下星号键，也就是数字 `8` 的上档字符按两下。
    * 见到两个斜杠或两个星号，就是同一个键按两下，不必去找额外的按键。

### 结果类型与精度损失

* **除法结果一定是浮点数**
    * 除法在编程语言里用单斜杠 `/` 表示。
    * `10 / 5` 的结果不是 `2`，而是 `2.0`；`10 / 4` 的结果是 `2.5`；只要用了单斜杠，结果就带小数点。
    * > **易错点**：除法运算的结果是浮点数，也就是小数，不是把所有除法结果都当成整数看。

* **整除只保留整数部分**
    * 双斜杠 `//` 是整除，结果一定是一个整数。
    * `10 / 3` 除不尽是 `3.333…`，而 `10 // 3` 的结果是 `3`。
    * 整除只保留整数部分，**不做四舍五入**。

* **浮点数精度损失（Floating-Point Precision Loss）**
    * > **定义**：计算机底层基于二进制进行数据的存储与处理，而二进制无法准确表示所有的小数，因此涉及浮点数的运算可能会损失精度。
    * 实测：`0.5 + 0.4` 输出 `0.9`；`0.5 - 0.4` 输出 `0.09999999999999998`，差值约 $2 \times 10^{-6}$ 量级。
    * 有些小数用二进制根本表示不准确，这是做算术运算时的正常情况，不属于异常情况。
    * 凡是用到浮点数参与运算，就要有"结果可能带一点微小误差"的心理准备，别拿浮点数结果去和精确值直接比大小。
    * > **易错点**：`0.5 - 0.4` 不等于 `0.1` 不是计算机算错了，是浮点数精度损失，判断相等时要留意这一点。

* **混合运算的优先级实测**
    * 表达式 `0.1 + 10 / 4 ** 2` 同时用到加号、除法和幂指数，计算顺序为：先算 $4^2 = 16$，再算 $10 \div 16 = 0.625$，最后算 $0.1 + 0.625 = 0.725$。
    * 实际运行输出正是 `0.725`。

### 输入数字并计算和与差

* **案例需求与初版写法**
    * 需求：在键盘上随意录入两个数分别赋给 `x` 和 `y`，然后分别输出 $x+y$ 的结果和 $x-y$ 的结果。
    * 第一步用 `input` 加提示信息接收键盘输入，`x = input("请输入x的值：")`、`y = input("请输入y的值：")`。
    * 第二步在占位符里直接写表达式输出两个结果。
    * 实际运行输入 `10` 与 `5` 时出问题：`x + y` 那行输出 `105`，`x - y` 那行直接报错。

* **字符串相加与相减的差异**
    * 键盘接收到的所有数据都是字符串，这里 `x` 是字符串 `"10"`、`y` 是字符串 `"5"`。
    * 两个字符串相加做的是字符串拼接，拼出来是 `"105"`，这是一个字符串而不是数字。
    * 减号没有拼接这层含义，两个字符串相减直接报错。
    * 修正方式是把输入内容直接转成数字类型，写成 `x = int(input("请输入x的值："))`；再运行输入 `10` 和 `5`，输出分别是 `15` 和 `5`。

* **整数转换工具与小数输入**
    * 需求里的"两个数"并没有限定必须是整数，输入第一个数 `0.5` 时程序又报错。
    * 报错原因是 `int` 代表把字符串转成整数类型，而 `0.5` 不是整数，转不过去。
    * 输入不一定是整数还是小数，就统一按小数处理，把转换工具换成 `float`：`x = float(input("请输入x的值："))`。
    * 换成 `float` 后整数输入照样能用：输入 `10` 和 `5`，转换时 `10` 变成 `10.0`、`5` 变成 `5.0`，两个都是浮点数，计算结果是 `15.0` 和 `5.0`。
    * > **易错点**：需求只写"数字"时不能用 `int` 收输入，遇到 `0.5` 这类小数会直接转换失败。

## 赋值运算符


### 基本赋值与赋值方向

* **赋值运算符（Assignment Operator）**
    * > **定义**：赋值运算符把等号右侧的结果赋值给左侧的变量。
    * 写法 `number = 1 + 2` 会先算出 $1+2$ 的结果，再把结果赋给左侧变量 `number`，于是 `number` 的值就是 `3`。
    * 等号是最简单、也是用得最多的赋值运算符；定义变量时给变量赋一个值用的那个等号就属于赋值运算符。
    * 复合赋值运算符都是以等号为基础变来的，搞清楚其中一个，其余的规律完全一致。

* **复合赋值运算符的书写要求**
    * 加法赋值、减法赋值、除法赋值这些符号虽然是两个符号拼在一起的，但它**本质是一个符号**。
    * 中间不要加任何其他字符，也不要加空格，必须连着一块写。
    * > **易错点**：`+ =` 中间留空格、或写成 `=+` 都不成立，复合赋值运算符必须连着写。

### 七种复合赋值运算符

* **复合赋值运算符（Compound Assignment Operator）**
    * > **定义**：在基本赋值运算符的等号前再拼一个算术运算符构成的写法，等效于"用变量自身参与该算术运算后再赋回自身"。
    * `number += 2` 等效于 `number = number + 2`，含义是 `number` 在原来数据的基础上再加 `2`，再把结果赋回给 `number`。
    * 若 `number` 初始值是 `3`，执行完 `number += 2` 之后 `number` 的值变成 `5`。
    * 幂指数写法单独看一眼：`number **= 2` 等效于 `number = number ** 2`，相当于 `number` 等于 `number` 的二次方；后面那个数字写 `3` 就是三次方。

| 运算符 | 名称 | 等效写法 |
| :--- | :--- | :--- |
| `+=` | 加法赋值 | `number = number + 2` |
| `-=` | 减法赋值 | `number = number - 2` |
| `*=` | 乘法赋值 | `number = number * 2` |
| `/=` | 除法赋值 | `number = number / 2` |
| `//=` | 整除赋值 | `number = number // 2` |
| `%=` | 取模赋值 | `number = number % 2` |
| `**=` | 幂指数赋值 | `number = number ** 2` |

* **复合赋值的适用写法**
    * 复合赋值运算符左侧必须是一个变量，右侧放参与运算的另一个操作数。
    * 换一个符号只换运算方式，等效写法的形状完全不变，都是"变量 = 变量 该运算 右侧操作数"。

### 复合赋值的执行轨迹

* **八步执行轨迹**
    * 起点 `number = 85`：`number += 10` 得 `95`；`number -= 10` 回到 `85`；`number *= 10` 得 `850`。
    * `number /= 10` 等效于 `850 / 10`，除法结果是小数，所以用浮点数表示成 `85.0`。
    * `number //= 10` 等效于 `85.0 // 10` 的整除结果 `8`，因浮点数参与运算所以结果是 `8.0`。
    * `number %= 3` 等效于 `8.0 % 3`，`8.0` 模与 3 的余数是 `2`，同样是浮点数写作 `2.0`。
    * `number **= 3` 等效于 `2.0 ** 3`，即 2 的 3 次方，结果是 `8.0`。
    * 实际运行结果依次是 `95`、`85`、`850`、`85.0`、`8.0`、`2.0`、`8.0`，与逐步推导一致。

| 步骤 | 运算 | 运算前 `number` | 运算后 `number` |
| :--- | :--- | :--- | :--- |
| 1 | `number = 85` | 未定义 | `85` |
| 2 | `number += 10` | `85` | `95` |
| 3 | `number -= 10` | `95` | `85` |
| 4 | `number *= 10` | `85` | `850` |
| 5 | `number /= 10` | `850` | `85.0` |
| 6 | `number //= 10` | `85.0` | `8.0` |
| 7 | `number %= 3` | `8.0` | `2.0` |
| 8 | `number **= 3` | `2.0` | `8.0` |

* **结果类型的决定因素**
    * 从第 5 步起 `number` 就是浮点数，后续每一步结果都带着 `.0`。
    * 把第 5 行那句 `/=` 去掉，没有除法运算，`number` 就一直是整数，后面整除的结果也是整数，整个计算过程的结果都是整数。
    * 一旦有浮点数参与算术运算，计算的结果就是浮点数。
    * 结果是不是浮点数，看参与运算的操作数里有没有浮点数、有没有除法，而运算符本身并不改变这一点。

## 比较运算符


### 布尔返回值与六种符号

* **比较运算符（Comparison Operator）**
    * > **定义**：比较运算符也叫关系运算符，用于比较两个值之间的关系；它会自动计算运算符左右两边的表达式，然后返回一个布尔值作为结果。
    * 左右两边可能是两个变量，也可能是两个表达式。
    * 这一类运算符不产出数字，也不改变变量的值，只产出一个布尔值。
    * 布尔值只有两种：结果为 `True` 表示这个比较关系成立（为真），结果为 `False` 表示这个比较关系不成立（为假）。

| 运算符 | 名称 | 示例 | 含义 |
| :--- | :--- | :--- | :--- |
| `==` | 等于 | `a == b` | 判断 `a` 和 `b` 的值是否相等 |
| `!=` | 不等于 | `a != b` | 判断 `a` 是否不等于 `b` |
| `>` | 大于 | `a > b` | 判断 `a` 的值是否比 `b` 大 |
| `>=` | 大于等于 | `a >= b` | 判断 `a` 是否大于或等于 `b` |
| `<` | 小于 | `a < b` | 判断 `a` 的值是否比 `b` 小 |
| `<=` | 小于等于 | `a <= b` | 判断 `a` 是否小于或等于 `b` |

* **等于与不等于的写法**
    * 等于用的是**两个等号**：一个等号在 Python 里是赋值运算符，用来给变量赋值；两个等号连在一块写才是比较运算符。
    * `a == b` 判断 `a` 和 `b` 的值是否相等：相等返回 `True`，不相等返回 `False`。
    * 不等于的写法是在等号前面加一个叹号：`a != b` 判断 `a` 是否不等于 `b`，确实不等于返回 `True`，否则返回 `False`。
    * > **易错点**：两个等号中间不要写空格，必须连着一块写；`!=` 的叹号和等号中间同样不能有任何其他字符，也没有空格。

* **含等号比较运算符的写法差异**
    * 大于号、小于号的写法和数学里一样。
    * 数学里的大于等于是大于号下面画一道横线，小于等于是小于号下面画一道横线；键盘上没有这两个现成的字符。
    * 编程语言把它们拆成两个符号拼起来写：大于等于写成前面一个大于号、后面一个等于号 `>=`，小于等于写成一个小于号加一个等于号 `<=`。

* **这些符号在键盘上的位置**
    * 小于号 `<` 用键盘上标注的那个小于号键。
    * 大于号 `>` 用键盘上标注的那个大于号键。
    * 叹号 `!` 是不等于要用到的那个叹号键。

### 一组比较表达式的判定

* **七条表达式的逐条预判**
    * `100 == 100` 两个值都是 `100` 且都是数字类型，结果是 `True`。
    * `"100" == "100"` 两个字符串类型的 `100` 值完全一致，结果是 `True`；这里的 `"100"` 是字符串，不是数字。
    * `100 != 100`：`100` 和 `100` 必然相等，"不等于"不成立，结果是 `False`。
    * `100 < 100` 和 `100 > 100` 都不成立，结果是 `False`。
    * `100 <= 100` 和 `100 >= 100` 都包含等于，结果是 `True`。
    * 实际运行输出依次是 `True`、`True`、`False`、`False`、`True`、`False`、`True`，与预判一致。
    * > **易错点**：写比较表达式时留意两边数据类型的搭配，`100 == 100` 与 `"100" == "100"` 都成立是因为每组两边值完全一致，不代表字符串和数字相等。

* **含等号比较运算符的判定要点**
    * `<=` 与 `>=` 都包含了等于这一种情况，所以拿两边相等的值去比，这两个都返回 `True`。
    * 单纯的 `<` 与 `>` 不包含等于，两边相等时一律返回 `False`。

### 四类业务需求的运算符选型

* **判断奇偶用取模加等于**
    * `1`、`3` 是奇数，除以 `2` 之后余 `1`；能整除、余 `0` 的是偶数。
    * 判断过程一直在问"除以 2 余几"，这就是取余操作，用取模运算符 `%` 对上 `2`。
    * 结论写法：`数据 % 2 == 0` 判为偶数，`数据 % 2 == 1` 判为奇数。
    * 既然是在判断"是否等于 0""是否等于 1"，就要用比较运算符 `==`。

* **边界充足类判断用大于等于**
    * 判断银行卡余额是否充足：余额要够付款，条件是余额大于或等于商品金额，用 `>=`。
    * 判断商品库存是否足够：比较"库存"与"购买数量"，库存要够就得大于或等于购买数量，用 `>=`。

* **上限限制类判断用小于等于**
    * 筛选不超过 100 元的菜品："不超过 100 元"就是价格小于或等于 100，用 `<=`。
    * 四类需求里出现的比较运算符一共两个：`==` 用在"除以 2 的余数等于几"这类判断上；`>=` 与 `<=` 用在"够不够""是否超过"这类边界比较上。

## 逻辑运算符


### 三个运算符及其判定规则

* **逻辑运算符（Logical Operator）**
    * > **定义**：逻辑运算符就是用来连接多个条件表达式的运算符；它自己不产生条件，只负责把已经写好的多个条件接到一起。
    * Python 里"并且"写作 `and`，"或者"写作 `or`，"非"写作 `not`，它们都是逻辑运算符中的一种。
    * 被连接的叫条件表达式，而条件表达式的结果本身就是一个布尔值，要么真要么假，真就是 `True`，假就是 `False`。
    * 逻辑运算符运算之后返回的结果**也是布尔值**，它回答的是"这多个条件整体上到底成立还是不成立"。
    * 整体形态是 `True` / `False` 进出：两端都是布尔值，中间那段才是逻辑运算符在做的连接工作。

| 运算符 | 名称 | 含义 | 结果为 `True` 的条件 |
| :--- | :--- | :--- | :--- |
| `and` | 逻辑与 | 并且 | 左右两侧同时为 `True` |
| `or` | 逻辑或 | 或者 | 至少有一侧为 `True` |
| `not` | 逻辑非 | 取反 | 操作数为 `False` |

* **逻辑与 `and` 的判定规则**
    * 「与」就是「并且」，含义是必须同时成立才算符合条件。
    * 只有 `and` 左右两侧都是 `True`，整个表达式的结果才是 `True`。
    * 只要左边或者右边有任何一个是 `False`，整体结果就是 `False`。
    * 形式写作 `a < b and b < c`，意思是"你得满足第一个，并且还得满足第二个"。

* **逻辑或 `or` 的判定规则**
    * `or` 代表逻辑或，就是或者的意思，只要多个条件里有一个符合就可以了。
    * 判定规则正好和 `and` 相反：有一个条件成立结果就是 `True`，左侧成立、右侧成立、两侧都成立都得到 `True`。
    * 只有左右两个表达式的结果**都是** `False`，结果才是 `False`。

* **逻辑非 `not` 的判定规则**
    * `not` 叫逻辑非，「非」就是取反。
    * `True` 取反变成 `False`，`False` 取反变成 `True`，就是一个取反操作。
    * > **易错点**：`and` 和 `or` 记反是最常见的翻车方式；`and` 要求苛刻，两边全 `True` 才给 `True`；`or` 要求宽松，有一个 `True` 就放行。苛刻的那个对应「并且」，宽松的那个对应「或者」。

### 区间内外的条件连接方式

* **区间内判断用 `and`**
    * 需求：在键盘上录入一个整数，判断这个数字是否在 10 到 20 之间，在就输出 `True`，不在就输出 `False`。
    * 条件拆解：一个数字要落在 10 到 20 之间，它得大于等于 10，并且还得小于等于 20，两条必须同时成立，因此用 `and`。
    * 输入部分可以直接连写成 `number = int(input('请输入一个整数：'))`，变量 `number` 接到的就已经是数字类型。
    * 校验链：输入 `5` 时 `5 >= 10` 不成立，输出 `False`；输入 `15` 时两侧同时成立，输出 `True`；输入 `60` 时 `60 <= 20` 不成立，输出 `False`。
    * > **提示**：IDE 会给出"简化链式比较"的波浪线提示，点它的按钮可把 `number >= 10 and number <= 20` 自动改写成 `10 <= number <= 20`，效果完全一样；连续比较是 Python 特有的写法。

* **区间外判断用 `or`**
    * 需求：从键盘输入一个整数，判断这个数字是否**不在** 10 到 20 之间。
    * 条件拆解：这个数字要么小于 10、要么大于 20，两种情况占其一就落在区间外面，不需要同时满足，因此用 `or`。
    * 结构上与区间内判断几乎一样，输入部分 `input` 加 `int()` 不用动，只把判定条件换成 `number < 10 or number > 20`。
    * 校验链：输入 `1` 时 `1 < 10` 成立，输出 `True`；输入 `15` 时两个条件都不成立，输出 `False`；输入 `56` 时 `56 > 20` 成立，输出 `True`。
    * 「在区间内」要求两个边界条件**都**守住，「不在区间内」只要求突破**任一**边界，这就是两者各用一个运算符的原因。

* **键盘输入的转换前置**
    * `input` 从键盘接收到的数据都是字符串类型，要做数字之间的大小比较，就得先把字符串转成数字。
    * 转换方式是外面套一层 `int()`：把 `input` 的结果传进去，拿到的就是数字类型。
    * 写法上还可以再省一步：既然 `input` 的结果马上要交给 `int` 处理，中间不必先用一个变量接住字符串再转换。

### 真实业务里的和与或

* **多个条件同时成立的场景用 `and`**
    * 登录要输入用户名和密码，点下登录按钮之后程序要校验用户名是否正确、密码是否正确。
    * 只有用户名必须正确**并且**密码也必须正确才算登录成功，缺一个都进不去，两者之间是并且的关系，用 `and`。

* **多个条件满足其一即可的场景用 `or`**
    * 登录方式有好几种：可以扫左侧的二维码登录，可以基于密码登录，也可以用短信方式登录。
    * 采用其中任意一种方式登录就可以了，不需要三样同时来一遍，所以这里用或者连接，用 `or`。

* **运算符选型的判定问句**
    * 判断逻辑运算符该用哪个，不必背规则，问一句：这些条件得**全部**满足，还是**满足一个就行**。
    * 全部满足用 `and`，满足一个就行用 `or`。
