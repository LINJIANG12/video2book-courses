# 浙江大学：软件工程（陈越）

这门课站在很高的抽象层次俯瞰整个软件工程领域——讲师用「站在月球上看地球」来比喻：先看清有哪些板块，而不是钻进每一种技术的细节。它是一门**管理型**学科课，重点回答「要做好这件事得完成哪几件工作」，而不是「用哪一行代码实现」。

- **原视频**：[【公开课】浙江大学：软件工程 陈越（全33讲）](https://www.bilibili.com/video/BV16g411M7r2) — Bilibili，BV16g411M7r2
- **全 34 集**，已产出 34 篇精读长文、14 册模块全书、35 份逐字稿

## 怎么学

课程原话里给过学法建议：每天上完课花五分钟把课后自测题过一遍，一学期下来不会觉得是负担；堆到考前再刷五百多道题，会很痛苦。这里的资料按同一思路组织：

- **跟着课程进度走** → `articles/` 里按 `PXX_` 编号顺序读，一集一篇，与课堂节奏一致
- **考前或复习** → `textbooks/` 按模块通读，14 册的顺序就是课程讲授顺序
- **核对原话** → `subtitles/` 里同编号的 `_clean.txt` 是分集逐字转录

这门课偏概念与流程，几乎没有代码，因此长文里的重点是讲师的类比与管理方法的来龙去脉。B 站视频本身带自测题，配合使用效果更好。
