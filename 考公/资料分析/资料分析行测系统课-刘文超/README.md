# 资料分析《行测》系统课

刘文超老师的资料分析系统课。课程围绕增长率、比重、平均数、倍数等核心考点展开，配套速算技巧与真题演练，强调在有限时间内快速完成资料分析题组。

- **原视频**：https://www.bilibili.com/video/BV1f4411C7z5 — Bilibili，BV1f4411C7z5
- **17 集**，已产出 11 册模块全书、16 篇复习笔记、29 份逐字稿

## 怎么学

- **核心概念** → 增长率、比重、平均数、倍数的定义与相互关系必须张口就来
- **速算技巧** → 课程配套多种速算方法，是资料分析拿高分的关键
- **真题演练** → 按真题套题限时训练，养成时间分配习惯
- **速查** → `notes/` 下的笔记汇总公式与易错点
