今天咱们的第七讲，第七讲是倒数第三节课。第七讲的内容讲一些什么？我们会把逻辑填空题剩下的一个部分给大家讲完，讲完之后我们会有一些时间跟大家来进入细节点判断题。明天的课程安排是语句排序题。最后一天，如果认为你要考的事没有篇章阅读你不想听，最后这节课你可以选学；如果考试当中涉及了篇章阅读，你可以来学，基本这就是咱们最后几节课的安排。今天先学逻辑填空，中间休息时间会给大家送一首歌，最后会把细节判断题给大家讲一讲，这就是今天的一个学习计划。

上节课咱们已经聊到了合理假设、小心求证当中的关联关系。关联关系当中我们学习了转折，转折是有两个知识点的：第一个就是和前面相反；第二个就是提出新的话题，但是倾向性是相反的。第二个叫做并列，并列可能是同义，可能是反义。第三个叫做递进，递进要保证前轻后重。第四和第五叫做因果与条件，有什么样的原因就有什么样的结果，这些大家都比较清楚。

今天我们要来学习的就是小心求证的环节。小心求证的环节要放到合理假设之后，也就是说拿到一道题，先看一看这个空的搭配能不能排除一些选项，搭配找完之后再找一找解释，如果解释类对应能够找到，这道题也可以做出来。如果遇到了一些关联关系，看看能不能通过关联关系做题，这是合理假设的范畴。当我们发现合理假设做完了，还是有几个选项还在纠结怎么办？这时候咱们把注意力放到选项当中，在选项当中进行细抠，抠哪些要点？比如说程度轻重，比如说感情色彩，比如说形象化表达以及语法搭配。所有的流程如果都做出来了，都操作过一遍，这道逻辑填空题应该就可以做出来了。我们继续跟大家一起来探讨小心求证当中的这四个环节。

第一个环节叫做程度的轻重，也就是所选的词语的程度要和文段的意思的轻重保持一致，这就需要我们进行二级辨析。给大家两个例子：第一个例子，“缺陷”、“缺点”、“瑕疵”好像都是有一些毛病，只不过这个毛病有大有小，“缺陷”看来毛病非常大，“缺点”是介于中间的，而这个“瑕疵”，我们知道瑕不掩瑜，看来就是小毛病，所以这就叫做程度上的一个对比。它们的意思大概都是倾向性是一致的，但是程度上有区别。

这里的“迥然不同”和“截然不同”，大家知道谁的程度更重一些吗？“迥然不同”的意思是很不相同。“截然不同”的意思就是完完全全不一样，完全不同。

“迥然不同”是很不一样，而“截然不同”是完全不一样。可以想象一下，如果我拿一把刀把它一刀两断，这里的“截”就是把它截开的意思，剩下的两截之间就没有任何的联系了，所以它是完完全全不一样的意思。而“迥然不同”是很不一样，在程度上“截然不同”是更重的，完全不一样。理解了这一点之后，我们来看一看题目。

首先来到咱们的第一道题。第一道题：人工智能促进了社会的发展，但是——这里有一个转折词——不少人对于人工智能的，人对于人工智能怎么样，这多半来源于其高速发展所带来的未知。读到这里，我发现这里有一个转折，转折之前有“促进了社会的巨大发展”，之后肯定是一个消极的内容，而且它肯定不会说没有促进社会的巨大发展，不是完全相反，而是提出的另外一个新话题，但是新话题的倾向性是消极的意味。看下“忧心忡忡”、“谈虎色变”、“心存戒蒂”、“半信半疑”，我感觉让我去判断的话好像有一些难。我们知道逻辑填空就是有这样一个性质，第一空往往会比较难，在第一空往往比较难的时候咱们先跳过，看看第二空能不能轻松解决。说与生物技术、核技术相比，现在咱们的监管对于人工智能是空白的，怎么样去做一件事情，保证人工智能良性有序发展，让我们的人类社会尽快适应，已经被提上日程。好了，这里有一个“已经被提上日程”，也就是说我的结果是提上了日程，那么结果之前是不是还没有提上日程？这里有一个逻辑上的指引。之前是还没有提上日程，我很显然发现有两个可爱的成语：“未雨绸缪”、“防患未然”，我上节课也说过，是不是特别好的两个成语？这两个成语就是事情还没有发生之前就去做一些事情。而“先发制人”好不好？其实先发制人的意思是什么？就是争取主动先动手，先打别人，先去制服对方。这里对于人工智能肯定不需要先发制人，不需要去攻击它，同学们可以排除 A 选项。立挽狂澜对不对？立挽狂澜就是在危急的关头，在危险的局势下我尽力去挽回。这里没有什么危急危险的情形，所以 4D 选项也排除，而我们 B 和 C 留下了。

接下来现在咱们再翻过头，再去看 B 选项和 C 选项的第一空，是不是比四选一就好多了？因为现在咱们是二选一。你告诉我“谈虎色变”什么意思？一提到老虎，脸唰一下马上就变了，是不是程度很重？而我们的“心存芥蒂”，芥蒂是什么？芥蒂就是阻塞物，就是我心中稍微对它有一些芥蒂，通常这么说，也就是心中稍微对它有一些忌惮，这里程度就轻一些。程度轻重我们来聊一聊，这里应该填的是重的还是轻的？既然都已经促进了社会的巨大发展了，你怎么可能是谈虎色变？不可能是一谈虎色变，如果它一出现我就很怕的话，那我怎么利用它对于社会带来一些发展？因此 B 选项程度过重了，所以最后同学们选对了，正确答案就是 C 选项，这道题正确答案就是 C 选项。

整个这道题我们给大家梳理一遍。一开始我觉得意思上我把握不出来，没关系，先看你能把握出来意思上正确的，排除 A 和 D 之后，接下来咱们再看 B 和 C。这个时候你再从一些细节出发，比如说程度，你就可以很好的把这道题做出来了，一开始不用直接去想程度，这是我们上节课提过的一个内容。

我们来看一看上节课讲过：居安思危、未雨绸缪、防患未然、防微杜渐、亡羊补牢，以及斗而铸兵这几个成语给大家讲过。如果上节课没有截图的话，这节课可以把这个图截一下。这几组成语前面都是相同的这种意思，但是在细微的区别上会有。比如说“居安思危”只有思，“未雨绸缪”、“防患未然”、“防微杜渐”、“亡羊补牢”都是做什么事情。而在事情发生之前和之后，“居安思危”、“未雨绸缪”、“防患未然”是在事前，而“防微杜渐”、“亡羊补牢”在事后，这个大家都知道。

好，接下来咱们看一下第二题。第二题说：部分的网店用所谓的——来，这里有一个“所谓的”，然后加了个引号——所谓的实物图、细节图来吸引消费者的眼球，并发布了一些生产车间的这些实拍图，还有荣誉证书来博取信任。到这里为止，我觉得它好像想损这些内容，为什么？因为它说是所谓的，而且加了引号，我有这种预感。果然接下来一个“而”，而消费者收到的实物却——来，这里的“却”就是转折——却和网上图片所显示的怎么样。既然你前面说的是实物图细节图，后面我收到的内容应该跟你网上的就不一样了。这里我合理假设是不一样，所以我们要买月饼的时候一定要谨防山寨，这是我想到的，应该是谨防山寨。

理解了这两点之后再看一下选项。选项当中我要填不一样，那我第一感觉“殊途同归”就是不对的，为什么？因为走不一样的路最后走到了一起，我们的归宿是一样的，最后到了一样，我要的是不一样，D 选项把它删掉。接下来 ABC 当中到底应该选哪一个？“南辕北辙”首先被我们排除了，因为上节课我们也说过，南辕北辙的主体针对的是同一个，也就是同一个主体，它的目的和行动是相反的。我今天特别想早睡，但是我却熬了夜，这就是南辕北辙。这里有两个主体，那么 A 选项删掉。哪两个主体？一个是自己收到的，还有一个是网上照片挂出来的。接下来我要做的就是在 BC 当中选一个。有些同学说：“老师第二空我觉得‘谨防’对，所以我选了 C。”其实还有一个辨析角度，我给大家说一说。

当你在网上看到了一个所谓的苹果，结果你就说：“我这段时间正好想吃苹果，我要买苹果。”结果却给你寄来了一支铅笔，而且这只铅笔是 2B 铅笔，好像在讽刺你。你有没有发现，你想买的东西和你收到的货物完完全全不一样？这种完完全全不一样，我们称之为“截然不同”。而你在网上如果想要买一个香蕉，你看到了这个香蕉，结果你收到的货物是一个烂香蕉，这时候这个香蕉和这个烂香蕉，你有没有发现它是不是很不一样的，但是终究它都是香蕉，因此我们可以说它很不一样，对应的就是“大相径庭”。同学们“截然不同”和“大相径庭”你会区别了吧？所以既然你买的是月饼，你收到的也是山寨的月饼，都是月饼，咱们就不能选“截然不同”，而应该选“大相径庭”了。

这样的话 C 选项就选出来了，正确答案是 C。不妨再给大家说一下后面的几个“防范”、“提防”、“警惕”和“防备”。“堤防”和“谨防”，我给大家说一句话，你就能记住它们的区别了：你一定要堤防你那个好色的上司，谨防职场性骚扰。你一定要堤防那个人，谨防一些事发生。你知道了吗？原来“堤防”对应的是人，“谨防”对应的是事。“老师，那‘防范’和‘防备’怎么办？”“防范”和“防备”既可以指人，也可以指事。这道题剩下的几个内容大家也会辨析了吧？这样的话我们这个环节就结束了，这道题选 C。

第三题我们来看一看。第三题说：散布谣言者抓住了人们宁可信其有不可信其无的心里，散布了什么样的网络谣言。首先找搭配，它是网络上的谣言，谣言是虚假的，捕风捉影的谣言，我觉得捕风捉影就是虚假的，可以；骇人听闻，很可怕是不是；耸人听闻很可怕，危言耸听好可怕，BCD 暂时你可能觉得都是可怕，但是我要给你区别一下。耸人听闻和危言耸听当中是不是都有“耸”？成语当中出现了这个“耸”字大家要记住，“耸”是虚假的意思。所以既然是谣言，这里的内容就对应了，所以 C 选项和 D 选项是可以保留的。而我们的 B 选项其实是不好的，为什么？因为“骇人听闻”说的就是这个社会上一些不好的事情很吓人，你听到了一些社会上发生的一些恶性案件，骇人听闻。所以从这层道理来说，我们的 B 选项应该不选。

当然了，也许你一开始没有辨析的这么深，我们不妨再看第二空。第二空说这些谣言误导了公共舆论，怎么样的社会秩序？既然是社会的秩序的话，我说“扰乱秩序”是不是很正确？而我们的“干扰秩序”有这么说的吗？没有这么说的。“妨碍了我们的社会秩序”好像也可以，因此你会发现在第二空当中，我们 B 选项好像也有点不想选它。

咱们再来看一下第三空。第三空说：有的时候还会给我们的行业带来巨大的损失，也会让一些好政策遭到误解，严重影响政府的公信力，因此民众对于这类事件怎么样呢？民众对于这类事件肯定是很恨、很不喜欢、很讨厌。在“嗤之以鼻”、“莫衷一是”、“不屑一顾”、“深恶痛疾”当中，我觉得“深恶痛疾”的程度是最深的，这是我的第一感觉。第二感觉是“莫衷一是”好像不对，“莫衷一是”的意思就是大家没有统一的、没有唯一的这样一个意见，所以大家有人觉得好有人觉得坏，肯定不对，“莫衷一是”不对，所以看来 B 选项完全就不选了。“深恶痛疾”程度很深，“不屑一顾”和“嗤之以鼻”就是我瞧不起他、看不上他。你觉得谁的程度能匹配文段？既然答案只有一个的话，那自然是 4D 选项是最好的。为什么？这里的损失是巨大的，这里的影响力是严重的。

说到了“嗤之以鼻”、“不屑一顾”，我还想给大家补充一下。我们老祖宗对于成语的创造是非常形象生动的，很多成语其实可以用我们的形象去记忆。比如说你要瞧不起别人，你怎么说呢？如果你用眉毛瞧不起别人——横眉冷对；如果你用鼻子瞧不起别人——哼，嗤之以鼻；如果你用眼睛瞧不起别人——不屑一顾；如果你用耳朵瞧不起别人——我不听我不听，充耳不闻；如果你用言语去嘲讽别人、瞧不起别人，你就可以对他冷嘲热讽；如果你要手口并用怎么办——口诛笔伐。你看我们的老祖宗特别善于瞧不起别人，所以这几个成语你是不是可以统一来记？我觉得记成语是非常快乐的一件事情，希望大家也能在积累当中给自己找一个比较适合的方式。

接下来第四题。我们是有着五千年文明传统的东方大国，儒家的人义礼智信思想怎么样于民族的精髓之中。这里对应的是民族的精髓，精髓——扎根精髓、孕育精髓、深藏精髓、深植精髓、蕴藏精髓，我又觉得第一空好难，没关系，他总是把第一空给你设置的好难，你没有什么思路咱们就跳。第二空，社会主义核心价值观正是在什么样的传统思想精华的基础上应运而生。既然这里要应运而生，它是在什么样的搭配呢？这个横线搭配的是不是传统思想？这里如果你认为它搭配的是传统思想，你是不是觉得“继承”就好？因为我要继承传统思想。但偏偏你看错了，我们这个横线要搭配的是不是“精华”？如果你能找准精华，那“继承精华”就错了，“吸取精华”就对了，“汲取精华”就对了，“提炼精华”就对了。所以你看，从第二空我们通过了合理假设当中的搭配，是不是把 B 选项删掉了？说的非常好。接下来咱们再继续看第三句话。第三句话说的是：当下改革释放出来的红利推动了我们中国迅猛发展，与此同时——一个并列——物欲膨胀带来的拜金主义、享乐主义、个人主义等一系列的负面影响，也怎么样着咱们的底线。来，它对应的是底线，“触碰底线”好像可以，“冲击底线”好像可以，“腐蚀底线”——老师没有这么说话的，非常好，“腐蚀底线”搭配不当。

那么要选“触碰”还是“冲击”呢？同学们说的非常好，“冲击”更好。为什么，老师？“触碰”就是我碰一碰你，碰一碰你，一碰碰出酒窝是不是？碰一碰是不是比较浅了？而我这里的“冲击”是要打一拳，我打我自己，冲击就能体现出我们这类的负面影响。对不对？所以对我们的这种发展带来了一系列的危害，所以 C 选项。原来最后“触碰”和“冲击”，咱们在搭配一致的情况下，咱们比对的是啥？是程度，原来是这么做的，我就明白了，对不对？所以同学们一步一步按着理论来，一定不会出错的。接下来我们就把程度的这几个内容学完了。

学完了程度之后，咱们再来看一看感情色彩。其实感情色彩是特别棒的一个能够在你一筹莫展的情况下，帮助你解答我们的选项到底该选什么的一个利器。感情色彩很重要哦，感情色彩很重要。来，我们看看：所填的语句的感情色彩和我们文段的感情色彩要保持一致，也就是文段是积极的，咱们填个积极的会更好；文段是消极的，咱们填一个消极的会更好，对吧？

举两个例子：“成果”、“结果”、“后果”。“黎叔很生气，后果很严重”，这是我们《天下无贼》当中葛优的一个台词。不对，应该是葛优手下的一个人的台词。意思就是黎叔生气了，生气之后带来的结果就是不好的，所以这里的结果叫做“后果”，它是消极的。而我们刚刚说了“结果”，“结果”有好有坏，所以它称之为中性，是不是？后面的“后果”叫做消极。那“成果”是什么？作品、成果，这里应该是好的，对不对？所以它应该叫做积极的。

赵公子指出了我的错误，就是黎叔自己说的，这个年代有点久远，忘却了。

好，第二个例子：“不胜枚举”。“不胜枚举”是啥意思？例子很多，我可以给你罗列好多好多好多都罗列不完，是不是？所以“不胜枚举”的意思就是好多，多的东西是好是坏呢？不知道，所以咱们是中性的。而“罄竹难书”，是不是你的内容很多，我写都写不下，那么什么内容呢？就是你犯的罪过、你的过错、你的罪行。那你犯的过错、你的罪行我们称之为贬义，是不是？所以它们都蕴含着“多”这样一层意思，但一个是中性的，一个是你的罪、你犯下的罪过非常多，所以它是贬义的。明白了这点之后，咱们来看看题目当中怎么去运用会更好一些。

首先，VIP 在咱们的重要会议上说了：深刻分析我们今天所面临的风险与挑战。好了，那么后面既然是个冒号，就要展开说我们的风险，展开说我们的挑战。你读到这里，你就感觉后面应该是消极的内容吧？告诉自己这样一件事情。接下来我们来读：当今世界的霸权主义和强权政治怎么样存在？看一下选项，“依旧存在”、“依然存在”，我区分不出来，第一空又区分不出来，咱们看第二空。这里的一个分号讲第二件事情，各种传统和非传统的安全威胁不断的怎么样？估计是不断的出现吧。果然，“不断地显现”、“不断地出现”、“不断地涌现”、“不断地浮现”，都是现，但这里的“浮现”好像不太好，为什么？因为“浮现”说的虽然是一些事情出现了，但它出现在哪？出现在脑海当中，也就是一个回忆的过程，过去经历的事情在脑海中显现，所以用在这里是不太好，不是说在你的脑海当中，所以我们就此把 4D 选项给排除了。

那么接下来第二空我们要看一看了，第二空说，社会秩序的大厦，读到大厦一定要敏感一些，大厦不就是高楼大厦吗？怎么社会秩序变成大厦了呢？你小子先用比喻是吧，那我作为你的老子我也要用比喻。来，大厦是法律和道德共同支撑的，我给你画一下，这是一个大厦。这个社会秩序的大厦有法这根柱子，有道德这根柱子，两根柱子支撑。如果道德不力了，一个支撑不了了，那么法律这边怎么办呢？法律这边孤立无援行不行？有些同学说老师我觉得行。那么这里的孤立是不是可以呀？好。接下来，老师独木难支特别好，独木和孤立是不是差不多呀？但这里是难支呀，难支对应我支撑不下去，而无援对应的是没人帮我，我觉得这里独木难支更好，是不是啊？所以C选项我们发现是特别好的。

而力所不逮是什么意思呀？力所不逮的意思就是，给你举一个例子，我向上帝许愿，我说上帝上帝，祈求你听我这个直播课的同学，他们逻辑填空都能考满分吧。上帝说我力所不逮呀，上帝的意思是啥？我力量达不到。那么接下来上帝就说，这个愿望我实现不了，要不然你再许个愿望吧。这时候我就给上帝说，那刚刚那个愿望你实现不了，能不能赐给我一个女朋友呀？然后上帝这时候说，你刚说第一个愿望是啥来着？是吧？好，力所不逮的意思就是力量达不到的意思，明白了吗？通过这个简单的冷笑话你应该明白力所不逮的意思了。好，所以力所不逮肯定就不对了，力量达不到是不对的。那么独木难支当中有个木，所以对应了我们刚刚所谓的比喻，所以C选项有比喻，它是最好的答案。

那么讲完这道题答案选C了吧？我再给你讲另外一件事，就是这里“显得爱莫能助”，它的用法是错的，我们在语法当中不会说“显得爱莫能助”，这是一个小考点，待会儿会考。我们说现在，老师，我的这个逻辑填空，我既不想学习又想拿满分，老师有没有这样的一些方法呢？我会说什么？我爱莫能助，对不对？我不会说我显得爱莫能助，我会说我爱莫能助。所以这时候大家明白了吧？其实B选项这里还有一个语法的错误。当然第二空你是不是根据我们的独木难支最后锁定了答案，依然能选出来，对不对？依然答案可以选出来。
