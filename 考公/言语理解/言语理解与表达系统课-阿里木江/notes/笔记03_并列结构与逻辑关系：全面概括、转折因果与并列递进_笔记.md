# 并列结构与逻辑关系：全面概括、转折因果与并列递进

## 三个前置判断

* **内容大于形式**

    * > **定义**：两个选项形式上都是"应该怎么怎么样"的样子时，真正决定取舍的是内容对不对、是否针对文段话题说的。

    * 主题词在文段中可能反复出现，也可能被出题人变形处理。

    * 沿用死板的技巧做机械匹配，很可能一脚踩进出题人布置的陷阱。

* **反面论证的服务员身份**

    * 提观点时反面论证也能反推出观点，但没必要再反推，因为观点已经给出。

    * 提问题加反面论证时，反面论证当中的那个观点反过来正好就是对策。

    * 对策和问题同时出现，对策更重要。

## 提对策类的三种排法

* **文段直接给对策**

    * 看见"有问题、有对策"，就选对策。

    * 形式上像问题、实质上是对策的，仍然选对策，因为它最重要。

* **反面论证**

    * 直接给对策时，作者改用"你不照做的后果"来施压。

    * 由"不照做就不好"可以反推出对策，反推出来的对策不必长得像对策句。

* **文段只抛问题加一通分析，没给对策**

    * 在答案中优先去找有没有针对性的对策。

    * 针对性的对策指内容上的针对性，即基于文段话题说的，而不是形式上出现"应该"二字。

    * 找到了针对性对策，这道题就可以结束，不再往下找。

```text
  文段直接给对策 ─────────────────────►  选对策
                                          （哪怕它形式上像问题）

  文段只给反面论证（吓唬你）──────────►  由"不照做就不好"反推对策 ──►  选对策

  文段只抛问题 + 分析，没给对策  ★重点
        │
        └─►  选项里有没有针对性对策？
                 │
                 ├─ 有，且对得上文段话题 ─────►  选它（内容大于形式）
                 │
                 └─ 没有 / 十分错误 ─────────►  退而求其次：选问题本身
```

## 选问题本身这条退路

* **触发条件**

    * 选项里根本没有针对性对策。

    * 或者有对策，但这个对策十分错误、十分不靠谱。

* **处理方式**

    * 退而求其次选择文段本身，相当于对文段作一个概括。

    * 形式正确但内容错误的问题项要排除，即使这一轮只剩它和那个错误的对策。

    * ⚠️ 对策内容错误不能连带把正确的问题概括也否掉，选项是对比出来的，正确答案一定是对比出来的。

* **引申的适用范围**

    * 在中心理解部分，只有提出对策类的题目可以进行"引申"。

    * 文段给了问题，找到引申出来的正确对策就选对策；找不到这样的对策，就把问题原原本本地概括出来，选问题本身。

* **两类退路实例**

    * 女朋友说"隔壁老王给他女朋友买了限量"：能解决问题的选项优先于只说"多喝水"这类无效对策；错误对策被删掉后，问题本身的概括仍然可选。

    * 领导说"我区空气污染严重，主要在于汽车尾气的排放"：如果选项里有"加强汽车尾气排放的管理"就必须选它；没有这个选项，也不能说问题概括错了，无对策选项时选问题本身。

## 互联网热身题

* **形状筛选**

    * A、B、D 都长成对策的样子，只有 C 是问题的样子；既然总对策已经给出，就不必再哭诉问题，C 先排除。

    * B 说需要"法制的约束"，而整套对策从头到尾没提法治、没提约束，属于扯淡。

    * A 含有"管理"，只是缺了"建设"，属于瑕疵，先放着。

* **主体比较定胜负**

    * 文段的主体是"网络"；A 说网络需要被管理，D 说网络的使用需要加强引导，即上网的人要怎么做。

    * "引导"只能对应"正面宣传"这一层，是片面的。

    * "网络的使用"与"网络"相比离原文主体更远。

* **不完美的答案**

    * 这个世界上不会出现百分之百完美的答案。

    * 省略"建设"是为了保持表述的一致性，让答案显得工整。

    * 在两个都像对的选项之间纠结时，回到主体这类可比较的维度做对比择优。

| 选项 | 形状 | 判断 |
| :--- | :--- | :--- |
| A 网络需要……管理 | 对策 | 原文总对策就是"建设和管理"，同义；缺"建设"只是瑕疵 |
| B 需要法制的约束 | 对策 | 整套对策里没提法治、没提约束，扯淡 |
| C ……还会带来网络犯罪 | 问题 | 已经有对策了，不必再哭诉问题 |
| D 网络的使用需要加强引导 | 对策 | "引导"只对应宣传这一层；主体也偏成了"网络的使用" |

## 针对性对策的识别

* **内容优先于形式**

    * A 是"应该怎么怎么样"，D 也是"应该怎么怎么样"，形式上无法区分时看内容。

    * 正确对策不会简单地长成"咱们应该、应当、必须"这么简单，出题人会换词儿。

    * 形式不重要，内容才重要；理解比机械套句式更关键。

* **找问题的核心**

    * 一个人把家里弄得一团糟：不叠被子、不洗脏衣服、到处乱扔，问题的核心不是其中某个具体毛病，而是"我缺一个人管着"。

    * 多个问题并列出现时，要追问它们是不是由同一个原因造成的；如果是，那个原因就是核心，谁对应了它就选谁。

* **带情绪不等于就是重点**

    * 文段结尾作者带着情绪反问，只说明他认为问题确实存在，不能因此就改选问题类表述。

    * 理论要前后连贯：既然这一类题优选针对性对策，就不能在"带情绪"处停下来满足于问题概括。

## 政府采购：把问题读到谁监督这一层

* **逐句分工**

    * 第一句引入话题"政府采购"。

    * 第二句说采购部门没从价格上把关会"违背制度初衷"，消极词一出，抛出问题。

    * 第三句中科院数据（近八成商品高于市场价格）是举例，服务于问题本身。

    * 第四句"这反映了两个问题"是指代，说明前面那段数据是服务员的服务员，可以略看。

    * 第五句没给对策，但把问题明确到了"谁来监督""在阳光的空间下操作"这一层。

* **选项取舍**

    * 答案定位到"政府采购主体没问题，需要在相关监督下进行"这一有针对性的对策。

    * 讲制度初衷、给"政府采购"下定义的选项属于引入话题，不选。

    * 停留在问题本身的表述（存在某个问题、大量违规行为）不选，因为明明有更好的针对性对策。

* **结构还原**

```text
  ①  今天咱们来聊政府采购
  ②  政府采购有问题（违背制度初衷）
  ③  举个例子：近八成商品高于市场价格
  ④  伺候一下这个例子：反映了两个方面的问题
  ⑤  问题明确到——"谁来监督"、"在阳光下操作"
        │
        └─► 谁提到了"我应该被监督"、谁提到了"阳光"，我就选谁
```

## 土壤污染：引出话题的不能与主题并提

* **聚焦句的判定**

    * 第一句带下定义（聊空气、水、土地），属于引入话题。

    * 第二句"然而"一转，作者真正聚焦的是土壤污染：公众不够重视、防治意识很弱。

    * 前两句谈空气和水只作引子，到此退出，不能与主题并提。

    * 第三句"很大程度上是由于"是原因；第四句是隐蔽性；第五句是滞后性，三句都属解释说明。

* **选项取舍**

    * 选同时对应"不够重视"与"提升防治意识"的那个选项。

    * 讲土壤污染与其他污染有哪些不同，属于引出话题时的内容，绝对不选。

    * 只解释滞后的选项落在解释说明里且特别片面，排掉。

    * 主体是土壤污染、形式上也有"应该"，但内容是"投时间投财力"，没有针对性，内容不过关。

* **篇章布局的预判**

    * 后面还有同样数量的句子时，可以预判作者会一条讲隐蔽、一条讲滞后。

    * 聪明的作者往往按聪明读者的思路铺文章，读懂这种谋篇布局就能提前定位重点句。

## 中小企业税负：题干一样答案不一定一样

* **文段落点**

    * 第一句引出话题并肯定中小企业。

    * 第二句国家给了政策，"但是"之后说中小企业税负依然不清，问题出现。

    * 后文"税收会削减能力"是影响性分析，用"也"引出"拉大差距"是第二点，影响还没分析完。

    * 重点落在"中小企业的税负不清"这一句上。

* **降征税点与提高征税点**

    * > **易错点**：要降低税负，该降的是**税率**、该**提高**征税点；降低征税点只会让更多低收入的人进入征税范围，是加重而不是减轻。

    * ⚠️ 原文第一句已经给出"国家出台了一些提高他们征税点的政策，但是还是不够的"，这句话本身就否掉了降低征税点。

    * 讲中小企业有积极作用的内容方向就不对，而且它只是影响性分析的一个片面部分。

* **同题干两问的答案差异**

    * 问"概括最准确"时，那个形式上像对策的选项内容是错的，正确的针对性对策找不到，只能退选问题本身。

    * 问"概括最恰当"时，"进一步减轻中小企业的税负"针对性很强：已有降税政策但不够，所以要进一步减轻。

    * 提问方式一视同仁，题干与提问方式完全相同，上一问选问题本身、这一问就不选。

    * 正确答案不是直接选出来的，而是通过对比判断出来的。

| 对比 | 概括最准确 | 概括最恰当 |
| :--- | :--- | :--- |
| 对策项表述 | 国家应该降低征税点 | 减轻中小企业的税负 |
| 形式上 | 是对策 | 是对策 |
| 内容上 | 错，降征税点只会加重税负 | 对，已有降税政策但不够，须进一步减轻 |
| 能否找到针对性对策 | 找不到 | 正是它 |
| 答案 | 问题本身 | 对策项 |

## 概括最准确这种问法还考不考

* **国考数据**

    * 2008 年到 2021 年共 14 年国考，出了 167 道中心理解题。

    * "概括最准确"2008 年考过 3 次，2009 年 3 次，2010、2011 年共 3 次，2014 年考了 1 次之后再没考过。

* **主流问法与应对**

    * 现在的主流问法是"意在说明""一再强调"。

    * 即使问法改变，答案仍按提出对策类的规则走：只有问题就优选针对性对策，有对策也选对策。

    * 概括题问的是概括时，对策是对的照样选。

## 历史研究的空白：对策不会长得像对策

* **预设答案的做法**

    * 做这类题先不看答案，先按"优选针对性对策"预设自己应该选到的形态。

    * 预设成"咱们应该去研究"之后把手拿开，优先去找符合这个形态的选项，A、B 这类问题类表述先放到一边。

* **选项排查**

    * "亟需加强历史研究方法的探讨"隐含"现在方法有误"，而文段讲的是有些领域被忽略，不是方法对错，形式像对策但内容错。

    * "历史研究依然大有可为"形式上不像对策，但内容就是"还有很多领域可以继续研究"，它是答案。

    * "人们对于历史存在认识上的误区"把"我忽略了"偷换成"我错了"，没去听直播不等于听课听错了。

    * "我们的研究成果太少了"是无中生有，文段只说存在空白，没说已有成果的多少。

## 并列结构：无重点即全重点

* **核心判断**

    * 既然是并列，那就是一个无重点；既然是一个无重点，那就意味着全重点。

    * 既然都不是重点，就全都要说，因此正确答案一定要全面概括。

    * 文段里的点很多时全面概括会非常难，答案会长得不像答案，所以出题人会提取共性、把它高度凝练。

* **全面概括的操作**

    * 相同句式出现时，前一部分的内容和后一部分的内容缺一不可。

    * 答案过长时不必逐项展开，直接回指共性主体即可，这就是高度概括。

    * 六个对策一个主体，概括不出来时就去找共性主体。

* **并列题的真正难点**

    * 难点一是片面，它是并列题目中一定会出现的干扰项；判断片面要靠从文段分析它只覆盖了并列中的某一部分。

    * 难点二是形式上像片面的选项：如果它覆盖的内容在文段每一句里都能找到，那就是全篇概括，不能因为长得像第二句就排除。

    * 破解并列结构不要从"我一定要概括出来"下手，而要从选项下手，用对比择优解决纠结。

    * 遇到没见过的概念、其高度概括自己又不了解时，机械排除法容易误判，此时对比选择更可靠。

| 错误类型 | 怎么知道它是这一类 | 结论 |
| :--- | :--- | :--- |
| 表述片面 | 从文段分析：只覆盖并列中的某一部分 | 一定错 |
| 无中生有 | 从文段分析，或对比选项发现文段从未说过 | 一定错 |

## 并列结构的识别标志

### 明面上的并列标志

* **此外**：出现"如此外""比如此外"就知道第一点没说完，还有第二点。

* **另外**：意味着除了这一点，还有另外一点，需要一起概括。

* **同时**：前面要有，后面也要有。

* **以及**：前面要有，后面也有。

* **分号**：整篇文段由三个分句构成，必须全面概括。

### 工整的排比与工整的时间

* 排比句式非常工整，时间顺序（以前、现在、未来）也很工整。

* 出现排比句式或时间顺序时，脑海中要立刻引起"这可能是并列"的判断。

* 核心话题在第一段就印出来，后面几段各带一个时间线索，层次整齐得像对仗工整的对联。

* 全面概括本应涵盖各个时间的同一件事，但答案不会那么长，会提取共性，题目就是那个共性。

```text
  小时候   →  乡愁是一枚小小的邮票   ·  我在这头，母亲在那头
  后来     →  乡愁是一方矮矮的坟墓   ·  我在外头，母亲在里头
  长大之后 →  乡愁是一张窄窄的船票   ·  我在这头，新娘在那头
  而现在   →  乡愁是一个海峡         ·  我在这头，大陆在那头
                 └────────────────────────────────┘
                        时间在变  ·  乡愁不变
```

### 连标志都没有就去找共性

* 没有并列标志、排列也不特别整齐时，先看文段里有没有转折、因果、对策。

* 这些都没有时，那几句话大概率是一层层的堆砌，各层作用一样，所以它们就是并列。

* 同一主体的不同点出现时，要找同一主体。

* 不同主体的共同点出现时，要找共同点和核心。

> **提示**：《爱我中华》第一句不是"56 个民族"，而是"56 个星座"，这是个冷知识。

## 祭拜先祖：三个问题背后的核心

* **问题的排布**

    * 第二句"越走越远了，缺乏引导和规范"是问题一。

    * 第三句"开始攀比"是问题二。

    * 第四句"对象变得五花八门"是问题三。

    * 结尾带情绪的反问说明作者认为祭拜先祖确实已经出了问题，但三个问题摆在前面是要引出核心。

* **核心与选项**

    * 三个问题若都是由同一个原因造成的，那个原因就是核心；"缺乏引导和规范"正是这个核心。

    * "适当适度""应该加强""应该避免"都是对策的表示方式，"引导规范"刚好对应缺乏引导、缺乏规范。

* **排除理由**

    * 选"已经丧失了这种文化意味"是停留在问题表述上，理论没有连贯下来。

    * 猜测问题是并列而去找并列项：出题人按 ABCD 摆放选项时已经在潜意识里说明今天不给并列项，看不出是不是并列没关系。

    * 不用原词原句是一条排除理由；力度偏弱也是一条，"适当适度"只是稍微调一调，与文段的情绪和力度不匹配。

* **题目设计的自觉**

    * 选项按 ABCD 排列本身就是一种信息，出题人已经替你排除了某些可能性。

    * 不要满足于"这道题我选对了"，基础阶段要把文段吃透。

## 史记的生命力：三个服务员和一个冒号

* **句子的层级**

    * 第一句"《史记》的生命力"是核心话题。

    * 第二句"有传播、有接受、有研究，历代不绝形成一门学问"是核心话题的服务员。

    * 第三句"这门学问"是指代，服务员的服务员，可以略看；后面的"六朝""汉魏"仍在举例，依然是服务员。

    * 一句话带出了三个服务员。

* **并列与冒号**

    * "生命力来源于……"后面接"一边……一边"，是并列结构；随后又给出"世界性的传播和研究"。

    * 冒号表示具体解释说明，看到它就赶紧略看，俄语、法语、英语指向的就是世界范围。

* **答案与选项**

    * 答案取"世界性传播"即可，连后面的"一""二"都不必展开，这就是高度概括。

    * 只写"传播"而不写接受、研究，属于把并列项漏掉。

    * "史学"在后面并没有被提到，写进答案就是片面。

    * 取自最后一句"越来越受到重视"的选项与"生命力的来源"这一话题不一致，那是给误以为末句是重点的人准备的。

```text
  《史记》的生命力来源于 ─┬─ 国内：（一边……一边）
                        └─ 冒号 → 具体解释说明
                                俄语、法语、英语……＝世界范围
```

## 工匠精神培育：六个对策只留一个主语

* **并列的识别**

    * 第一句一上来就给了四个对策：要立足、要开展、要建构、还得强化。

    * 第二句"从协同发展的视角来看"与前文构成相同句式，因为工整就提示这里是一个并列。

    * 后面主体一直是"我国工匠精神的培育"，对策不断加码。

* **答案与选项**

    * 概括不出那么多对策就去找共性，共性就是"我国工匠精神的培育"。

    * 选项"我国工匠精神的培育主要策略"直接回指主体即可，不必罗列后面那串对策。

    * 落到"工作的管理"是片面，"管理"被放在了片面的位置上。

    * 落到"搭建协同平台""保障协同平台"同样是片面。

* **同类启示**

    * "从什么什么看"往往意味着相同句式，前后两块内容都要提到，缺一不可。

    * 出现第三个"从 z 看"时，z 当中的内容也不要放过。

## 青霉素被发现之前：展开的预判

* **预判并列**

    * 第一句"青霉素被发现之前……"的主体是细菌，开场用下定义说明青霉素出现之前的细菌。

    * 第二句"50 多年前……"又出现"在什么什么以前"的相同句式，隐约提示可能存在时间并列。

    * 这种预判要继续读下去验证，看它是否还有这个共性，读的时候始终带着"会不会是并列"的提示。

## 概括与对策的收束

* **提对策类的收束**

    * 提出问题、分析问题但没给对策的这一类：优选针对性对策，在选项中作对比；没有针对性对策就选问题本身。

    * 判断阶梯搭起来之后，后面的分析就顺着往下走。

* **宏观脉络的收束**

    * 提对策类搞定之后，宏观上的行文脉络分析只剩下并列结构这一块。

    * 并列结构难在点难找全、答案难凝练，靠标志识别加对比择优来突破。

## 并列结构总纲

### 识别信号的三级路径

* **显性标志词**
    * > **定义**：句中直接出现分号，或出现此外、另外、另一方面、有同时这类并列标志。
    * 读题第一眼先扫标点：分号连着出现、中间夹着句号，就是分号句，直接按并列思路处理。
* **整齐形态**
    * > **定义**：没有标志词时，表现为格式非常整齐、层次非常分明。
    * 典型形态：排比句；时间的先后顺序；从 X 怎么看、从 Y 怎么看。
* **兜底判断**
    * > **定义**：既无标志词又无整齐格式时，用排除法锁定。
    * 中间没有转折、句与句之间没有因果、也不是提出问题再解决问题，三条同时成立即可断定是并列。

### 判定为并列之后找什么

* **共性**
    * > **定义**：找同一主体的不同点，或不同主体的共同点。
    * 两条取向：主体一直没变，说的就是同一件事；主体换了，就抓它们共同落在哪一点上。
* **穷尽**
    * > **提示**：并列结构的所有内容一个都不能漏，答案必须覆盖全部分句。
* **正确与错误的分野**
    * > **结论**：正确答案全面概括、提取共性；错误答案一定片面或者无中生有。

    * 全面概括项对齐共性。
    * 片面项只取全部分句中的一瓣。
    * 无中生有项在文段里找不到对应内容。

    * 判别动作：逐个排除片面项与无中生有项，剩下的全面概括项即为答案。

### 并列判断与选项比对流程

* 三步链条：识别并列 → 找共性 → 比对选项。
* 第一步的三类信号：分号与标志词、整齐层次、无信号时的兜底排除法。
* 第二步的判断对象：主体有没有变、是不是在说同一件事。
* 第三步的三种落点：全面概括取，片面与无中生有弃。

```text
   ① 识别并列
      分号 / 此外、另外、另一方面 / 格式整齐、层次分明
      / 中间没有转折、没有因果、没有问题—解决
                            │
                            ▼
   ② 找共性
      主体变没变？是不是在说同一件事？
                            │
                            ▼
   ③ 对比选项
      全面概括 ✔      片面 ✘      无中生有 ✘
```

## 分号句拆解

### 主题词变形后的摊平

* 并列各分句的主题词常换说法，换了说法仍看得出归属的才算同一主体的分瓣。
* "幼儿教师队伍建设"是"学前教育"的变形，"农村幼儿园"是又一次变形。
* 主题词变形不是排除理由，真正的排除理由是覆盖面不够。
* 摊平办法：把各分句排开，一行一个，主体与问题各占一列，再横向取共性。

```text
   ①  结论主体：我国学前教育资源      →  短缺（优质幼儿园一位难求）
   ②  学前教育                       →  普及率不高，各地发展不均衡
   ③  幼儿教师队伍建设（主题词变形）  →  存在师资梯队建设上的困难
   ④  农村幼儿园（主题词又变形）     →  城乡差距大
   ─────────────────────────────────────────────────────────
   共性：全是"我国学前教育"这个主体身上出的问题
```

### 首句与后文的轻重

* 首句给出总括性结论时，结论的主体是核心，问题词是落在它身上的定性，后面的分句是不重要的具体表现。
* 由"由于……等因素的影响和制约"领起的内容属于首句里不重要的部分，片面，不选。
* 主体到问题要一层层扣：资源短缺对应一位难求，教师队伍困难对应师资梯队建设，农村幼儿园对应城乡差距大。
* "失衡"与"短缺"不能互换：失衡指有的地方好、有的地方差，短缺指大家都少；大家都少就不存在失衡。
* 出现的词多不等于并列项多，先把不重要的修饰成分剔掉，剩下的才算分瓣。

## 共性词的覆盖检验

* **覆盖检验**
    * > **定义**：被提为共性的词，必须同时能代表全部分句的主体。
    * 反例：蜜蜂的眼睛可以算生物的构造，蜂巢是房子、不是生物，所以"生物的构造"盖不住蜂巢。
* **只说相似不给意义**
    * 指出相似性而不说人们拿它做了什么，概括不到位；概括要看人们利用它做出的东西。
* **单说某一瓣**
    * 对某一个分句单独定性，无法统领全部分句。
    * 例：说"多年来认识一直存在误区"，若该方向已是顶尖学术方向就讲不通，误区只能存在于过去。
* **各咬住一种成分**
    * 概括只列一种成分、丢掉另一种，判为片面。
    * 例：只说可可碱不说咖啡因，或只说咖啡因不说可可碱，都不成立。

## 概括的措辞升降

### 低阶定位与高阶替换

* 先用最朴素的措辞把正确答案概括出来，保证内容找对，例如"我们不一样"。
* 再对照选项里的书面表述做替换，"我们不一样"对应"战略的差异化"。
* "巴塞罗那有好多大神的作品"对应"巴塞罗那是一个绘画艺术的圣殿"。
* "能够刺激你的脑子"对应"具有促进神经兴奋的作用"。
* 两步法的价值：表达时先有低阶版本打底，落笔时直接调用高阶词汇。

### 范围的收窄与放大

* **范围放大**
    * 把文段主体向外扩张，如从"身边的事物"扩到"日常生活"，读前根本想不到这种表述，看似合理但不精准。
* **范围收窄**
    * 两个选项范围都偏大时，取相对收窄的那个。
    * 比较标准是范围与文段主体的贴合度，不是读起来是否顺口。
* 概括范围确定后，选项若与之不匹配，按贴合度而非文采取舍。

## 排除法与选项辨析

### 错误的三个来源

* **本身就错**
    * 选项内容在文段里找不到任何对应。
    * 例：谈"领导的决断力"，而文中从未出现领导作出决断的情形。
* **对但不够好**
    * 选项本身能对上文段，但同段存在更全面的选项。
    * 例：谈"内部的执行力"能对上每次都成功，但与更全面的选项同场时让位。
* **片面**
    * 选项只对应分号句中的一瓣，其余分瓣被丢掉。
    * 例：只取"连亏 5 年仍未放弃"这一块，得出"不言败的精神"。
* 选定答案之后仍要把其余选项的错因逐一归类，才算把选项吃完。

### 借来的关键词要看定义域

* 多个词单看都像文段里的东西，其中某个却只覆盖部分主体。
* 看到"生物"就以为是蜜蜂、看到"构造"就以为是房子，落差正在定义域。
* 判定动作：把候选共性词逐个代回全部分句，代入不上的立即排除。

## 扫读与跳读

### 不能直接跳读的信号

* 看到"由于""因为"一类因果标志，不能上来就跳读。
* 处理方式：眼睛扫读一遍，大致留一点印象，再判断它是核心论点还是修饰成分。
* 句法位置只是线索，决定权在内容；标志词后面接的是核心论点就跳不掉。

### 可以完全不看的情形

* 前面已经出现一个观点，后面用"比如"引出。
* 前提是那个观点已经吃透，此时"比如"之后的举例可以整段略读。
* 两者合起来的原则：内容是活的，不能见到标志词就机械套用。

## 找不到重点时的自检

* 读不出重点时先怀疑文本没读全，而不是先怀疑自己的理解力。
* 第二个层面出现时，把两个层面叠加起来看能否构成完整过程：先说怎么拍、再说怎么放映和发行，合起来就是全过程。
* 全过程里贯穿的那一个词就是主题词。
* 主题词概括得出、范围概括得全，选项基本可定。

```text
   第一个层面：电影的表现技术层面    ——  数字技术已成主流
   第二个层面：电影的发行和放映环节  ——  胶片、放映机、金属盒成为历史
   ───────────────────────────────────────────────────────
   两个层面一叠加 = 电影的全过程（先说怎么拍，再说怎么放映和发行）
   全过程里贯穿的那一个词：数字技术
```

* 层次没有抬上去的选项都停在第一层、只谈电影表现，判为片面。
* 定不下时选相对最完整的那个，不必在措辞是否绝对化上纠缠。
* 顺序上先定内容再抠细节，细节上觉得行就选它。

## 选项翻译成人话

* 把选项先翻成白话再决定取舍，可避免被生造的名词牵着走。
* 四个常用维度各自对应的白话问法如下表。

| 选项维度 | 白话问法 |
| :--- | :--- |
| 盈利模式 | 怎么赚钱 |
| 应用场景 | 用在哪儿 |
| 销售策略 | 怎么卖 |
| 市场前景 | 未来好不好 |

* 前景 = 盈利 + 有场景：既讲得清怎么赚钱，又有适用的条件，两者合流才叫前景。
* 只说"能赚钱"或只说"5G 时代可用"，各占一半，都属片面。
* 完全没提的维度判为无中生有。
* "或将"不是"或者"而是"可能"，其中"将"取"将来"义，指向市场前景，不代表只覆盖后半分句。
* > **易错点**：⚠️一看到"将"字就判定它只对应转折后的半句，会把合流概括拆掉。

## 题目复盘

| 话题 | 答案 | 关键排除点 |
| :--- | :--- | :--- |
| 对细菌的认识一步步变化 | d | a 只对应最后一句；b 说的"作用"在共性里根本没提；c 说"一直存在误区"站不住 |
| 珠三角 / 手机 / LCD 三句并列 | c | a 无中生有（文中没有"领导"）；b 正确但不如 c 全面；d 只取"不言败"这一块 |
| 学前教育的四个短板 | b | a 用"失衡"盖不住"大家都少"的"短缺"；c 只覆盖第一点；d 出自第一句不重要的部分，片面 |
| 共享充电 | d | a、c 各取一半，片面；b 无中生有；"市场前景"是"能赚钱 + 有适用条件"的合流 |
| 蜂巢与蜜蜂眼睛的仿生利用 | c | d 错在"生物的构造"盖不住蜂巢，且只说相似不说用途；b 范围过大 |
| 巴塞罗那与三位大师 | a | b 片面且"学生"不等于"艺术家"；c、d 相互矛盾，两个都不对 |
| 数字技术与电影的两个层面 | a | b、c、d 全都停在第一层，片面 |
| 巧克力里的可可碱与咖啡因 | a | b 引入了原文没有的成分；c、d 各只咬住一种，片面 |

* 时间线并列的识别：以前、后来、再后来这类时间线索加在一起即并列，共同落在同一对象上。
* 主题转场并列的识别：人物换了就看有没有不变的东西，如高迪换毕加索，毕加索换达利，作品都在同一座城市。
* 分析时的注意力不放在最终选了哪个，而放在其余选项各自错在哪一层、范围偏在哪一侧。

## 宏观先于微观

* 文段分三类：有总分结构、提出对策、并列结构。
* 先在宏观层面解决文段归类，再进入词句层面的关联关系。
* 反对先抓"转折是重点""因果是重点"这类微观要点，容易以局部定全文。

## 微观关联关系

### 关系清单

* 微观五类：转折、因果、必要条件、并列、递进。
* 处理法：把句子之间的关联关系拎出来逐个判断。
* 转折、因果、并列属于已经讲透的几类，必要条件是新引入的一类。
* 判断顺序：先宏观归类，再微观定关联，最后回到选项层面做对比。

### 必要条件

* **必要条件**
    * > **定义**：必要就是必须，必须就是一定。
    * 判定标准：没它就不行，缺了这个条件整件事不成立。
* **推导链**
    * > **定义**：由"必要"字面出发逐级换词：必要 → 必须 → 一定 → 没它是不行的。
    * 先从字面理解入手，再落到可判定的形式上。

## 转折关系

### 转折标志词

* **强转折**
    * 主结构为"虽然……但是"。
    * 同类词：尽管、固然、不过、虽说、然而、却、其实。
    * 强转折的前半段可以省略，只需知道话题是什么，后半句逐字逐句读清楚。
* **弱转折**
    * 标志词：事实上、实际上、殊不知。
    * 弱转折有时表示转折，有时只是进一步解释说明。
    * 考试阶段先把弱转折一律当转折标志处理，遇到特殊情形再细分。

### 重点的两种落点

* **推翻旧话题**
    * 转折之后与之前相反，后句是对前句的否定或修正。
* **另起新话题**
    * 后句与前句的词不构成严格反义关系，只在倾向性上一正一反。
    * 例：前句说"丑"，后句说"温柔"；"丑"的反义是"美"而非"温柔"，"温柔"的对立面是"粗暴"。
    * 所以转折后不一定非去找前句的反义词，倾向性不一致同样算转折。

### 隐藏的转折标志

* 一句里可以叠出四个转折标志。
* 拆法依次是：转折连词"但"、转折副词"却"、含比较意味的"最新的研究"（"最"本身暗含比较）、成语"截然相反"。
* 转折不一定要靠连词词面触发，形容与比较词同样可以起标记作用。

### 内容大于形式

* 只看残缺选项容易被位置误导：看到"传统科学家"落在转折前就随手排除。
* 判断依据是选项说了什么，不是它出现在转折前还是转折后。
* 把答案盖住只读只言片语时尤其容易误判，必须以完整内容比对。
* > **注意**：⚠️"有失偏颇""其实不然"这类表述要看它否定的对象，不能凭字面熟悉感接受。

## 因果关系

### 结论的标志词

* **引导结论**：因为、所以；由于、因此；可见、故、于是、由此观之、据此可知。
* **引导小结果**：导致、使得、造成，这类后面大概率是分项小结果。
* 引导结论的词与引导小结果的词要区别对待，不能一律当重点。

### 倒装形式

* 之所以……是因为……：把"因为"后置，前面的"之所以"分句即为重点。
* 识别到"之所以"就要意识到重点落在它前面。

### 结果优先的升级链

* 判定基线：结论即结果，比原因重要。
* 例子：昨晚酒局老张喝多是原因，今天上班头痛欲裂是结果。
* **a 只有原因** → 错，原因不如结果重要。
* **b 只有结果** → 对，但还能更好。
* **c 原因与结果同现** → 比 b 全面。
* **d 明确点出"原因"二字** → 比 c 更明确。
* **e 照原文措辞写"昨晚喝多"** → 最贴近原文，优于只写"喝酒"的 d。
* **f 再补回"上班头疼"** → 单选题会继续沿这条链升级。
* 外部因素会影响判断，但单选题只需在现有选项里比出更优者。
* 出题人刻意让最优项不完美是为了拉开区分度，做题时要坚持选项之间作对比。

```text
   a  只有原因                     错：原因不如结果重要
   b  只有结果                     对，但还能更好
   c  原因 + 结果                  比 b 全面
   d  明确点出"原因"              比 c 更明确
   e  照原文说"昨晚喝多"           最贴近原文，最优
   f  再补上"上班头疼"             单选题会继续这样升级
```

### 结论句之后又跟话题

* **接解释说明**（如"脑子嗡嗡的"）：后句是服务结论的，重点 = 结论 + 后句。
* **接转折**（如"但是他还是坚持去上班了"）：重点转到后句，前文被后句的转折统摄。
* **接并列**（如"此外，它的尾椎骨也不舒服"）：前句要带出后句的"也"，重点 = 结论 + 后句。

```text
   x = 结论句：老张今天上班头痛欲裂

   【x 后面跟 w】脑子嗡嗡的
        w 是服务员，作用是把 x 讲细         →  重点 = x + w

   【x 后面跟 z】但是他还是坚持去上班了
        后面冒出一个转折                      →  重点 = z

   【x 后面跟 y】此外，它的尾椎骨也不舒服
        并列，前一句要把"也"带上            →  重点 = x + y
```

* 三种情形都要把前句重读一遍，句式可以自然改写成"虽然……但是……"。
* > **易错点**：⚠️不能因为看到"导致"就断定该处是重点，关联词只是线索。

## 必要条件的识别与落点

* **必要条件（necessary condition）**

    * > **定义**：文段设定的一个假设状态；这个假设不成立，后面那串东西统统落空

    * 条件就是一种假设的状态：假设不成立，后面那串结论全部落空

    * 读到"只有""除非"要立刻告诉自己：重点来了

* **"只有……才……"与"除非……才……"**

    * 两者说的是同一套正反论证，逻辑完全一致

    * 真正要选的答案落在"只有"后面那个条件上

    * "才"后面那截是条件成立后产生的影响，往往还是好影响

    * 条件是那个"不这么做，一切免谈"的关口；"才"后面是白送的结果，不需要专门去论证它

    * 答案要选的是被论证的那一头

    ```text
    只有  [ 条件 ]  才  [ 结果 / 影响 ]
              ▲                ▲
            重点在这         别落在这
          前提不成立，       前提成立后
           就不成立        白送的结果
    ```

## 条件的形变与同义替换

* **"只有"的省略形变**

    * "只有"可以整个省略，省略后剩下"通过××××才能×××"

    * 省略之后，重点从"只有"后面挪到了"通过"上

    * 落到这里，答案就变成了对策、措施、途径、方法，在题干里往往呈现为一种做法

    * > **提示**：不要管什么前推后、推后推，那些术语先放一边；只记住一件事——前面的条件很重要

* **条件的一词多形**

    * 同一个必要条件可以换说法：关键、前提、基础、保障、必须

    * 例：赡养老人是子女的义务——义务就是必须，就是关键；往下换成"遵守规则"一样成立

    * 以下表述在答案里全都对：遵守规则是获得成功的前提；遵守规则是必要条件；通过遵守规则才能获得成功

    * 三者本质都是对策

    * 做法还能换成做法关键词：应当遵守、务必遵守、需要遵守、离不开遵守

* **必要条件与对策的绑定**

    * 必要条件基本上就是出对策的

    * 对策是重要的，所以必要条件也是重要的

## 两类一见面就能砍的错项

* **落脚点掉到"才"后面**

    * 表现为答案直接陈述条件成立之后的那个后果

    * 例："获得成功是关键"绝对不能选

    * 凡是这么写的，答案里出现了就一定不能选

* **把假设变成现实**

    * 文段说"遵守规则"是假设；一旦变成"你已经遵守了规则"，内容看着一样，但已经不是假设了，直接错

    * "你已经获得了成功"同样错，后半截也不能变现实

    * 前面变现实不行，后面变现实也不行

## 并列与递进

* > **定义**：并列，是把若干内容平行摆开，地位平等，要全面概括、提取共性；递进，是后面那句比前面那句更重要一层

| | 并列 | 递进 |
| :--- | :--- | :--- |
| 关系 | 地位平等，全面概括、提取共性 | 后一句更重要 |
| 常见标志 | 同时、另外、此外、而且、还来源于 | 更、甚至、特别、尤其 |
| 选点 | 内容要全部概括进答案 | 落点在最后一句 |
| 判断依据 | 句子之间没有轻重之分 | 前后有轻重之分 |

* **好认的标志词**

    * "而且"是并列

    * "还来源于"是并列

    * "更""甚至""特别""尤其"是递进，后面那句更重要

* **难认的标志：不但、不仅、不光**

    * 难点在"不但、不仅、不光……还／也／而且还"

    * 认定"没有'而且'就一定是并列、有'而且'就一定是递进"是机械的、形而上学的读法

    * "不但""不仅""不光"都是可以被省略的标志

    * > **提示**：凡是能被省略的标志就不能当判据，判据只能是文段本身

    ```text
    看到「不仅 / 不但 / 不光 …… 还 / 也 / 而且还」
    │
    └─ 先问：这些标志能不能被省略？
       ├─ 能（不但、不仅、不光都可省）→ 不能当判据
       └─ 别在这打转，往下走
          │
          ├─ ① 看选项：C 与 D 是不是「同构」？
          │     ├─ 同构 → 单选里一起被排除 → 只能按并列读
          │     └─ 不同构 → 记下来，继续往下
          │
          ├─ ② 问文段：问题出在谁身上，对策就落在谁身上
          │
          └─ ③ 读例子：后半段有没有绕回第一个分句的话题？
                ├─ 绕回去了（又提"传统"）→ 并列
                └─ 一直没绕回，一直在讲新话题 → 递进
    ```

## 同构选项

* **同构选项（isomorphic options）**

    * > **定义**：两个选项的表述完全一致

    * 自己做的是单项选择题，同构的两项会一起被排除

* **同构选项的用法**

    * 两个同构选项一起出局，等于反证了文段里那个标志的读法

    * 例：C 与 D 长得一模一样，表述一致，于是一起出局；文段里的"不仅"只能读成并列

## 选项取舍

* **对策永远优先**

    * 对策一定是针对着问题提出来的：文段拿什么当办法，问题就必须是什么

    * 有对策的选项先入围，再比具体程度

    * 例：B"传统相声真的应该改改了"与 D"只有……重返舞台……才能……"都是对策；D 能回答 B，B 回答不了 D，B 不明确被排除

* **"讲得通"**

    * 核心话题对了、讲得通，即使它是一个影响而不是一个做法，在没有更好选项时也必须选它

    * 例：核心技术那题若没有 D，A（核心技术的突破是国家科技的彰显）必须选，因为其他几个的核心话题直接错了。

    * A 与 D 都有"核心技术"这个点时，就比落脚点，优选更贴近文段的对策

* **想它出身**

    * 遇到主题词似乎同义转化时，追问这个表述是从文段哪一句来的

    * 出自"之后的影响"的一律不选

    * 例："主动权"出自"中国必须掌握核心技术"——掌握核心技术才掌握主动权，它属于之后的影响，砍掉

* **细节上的克制**

    * 不要一开始就钻进"书籍为什么不能算新闻工作者"这种细节里，先宏观把握；实在把握不出来再回去抠细节

    * 抠出来的那些细节很可能本来就是可以避免的纠结

    * 不要因为一个选项看着少了一块就不选它，只要讲得通就可以

    * "重返舞台"和"与观众交流"本来就不矛盾：有了这种舞台，在舞台上自然就可以跟观众交流

### 垃圾分类：不只是并列还是递进

* **题面**

    * 文段一再强调：我国的垃圾主要是厨余垃圾，占比很大

    * 问题出现了，有问题就该有对策，所以重点是对策，文段给的全是"应该怎么样"

    * 答案的句式是：不仅应该怎么样，还应该怎么样，此外应该怎么样，也应该怎么样

* **选项比对**

    * A：要从宣传教育**和制度**层面加以规范，宣传教育、建立制度、做好规范四个全齐

    * B：只说了宣传教育，漏了后面"制定法律和规范"

    * C：说这是培养文明的重要场所、是学校和家庭，却不说法律、制度、规范，片面

    * D：只提到法律和制度，没提前面的，还把"应该"改成了"国家要强迫"

    * 结论：这道题里的"不仅"是并列，选 A

    * > **提示**：选完要告诉自己——根据行文脉络的分析和最终的答案，这道题里的标志还是按并列读

### 精神病人：语感来自吃透文段

* **题面**

    * 谈精神分裂患者时，人们会恐惧、不可思议、排斥、歧视、很难理解，而精神病人又多，问题依然在。

    * 文段给的对策是：他们**不仅**需要医生的关注，**还需要**大众的认可和支持

* **分析**

    * 文段是提出问题、解决问题，解决问题一定要强调针对性的解决

    * 问题出在哪儿？出在大众不理解、不支持；那么针对性的对策一定也在大众身上，医生的部分先放一边

    * 这里的"不仅"是递进，落点在后半句；选项把递进前和递进后拆成了 B 和 D 两个，B 是递进后

* **落选原因**

    * C 是问题项：文段已经给了对策，不该再去选问题

    * 把医生、心理工作者、大众统称为"人们"的全面选项有三个瑕疵：B 已经精准抓住了递进后的原文原句，全面表述反而退了回去；它只说"不应该歧视"，恐惧、不可思议、排斥、不理解为什么不说，只说了一点，很片面；文段说的是"我需要什么"，它倒过来说"不需要什么"，不明确

    * > **提示**：要带走的不是"这题选 B"，而是"我遇到文段要怎么分析"；语感往往是已经吃透文段之后自己长出来的，只是你还不知道它为什么在那儿

### 语言不规范：让选项来定

* **文段拆解**

    * 第一句：好多语言不规范的现象，**不只出现在学生笔下，而且也出现在报刊书籍当中**

    * 第二句：读者的讹误——还是语言不规范

    * 整段只做一件事，就是提出问题，问题就是语言不规范

* **选项比对**

    * A：语言不规范的问题很普遍——把"不仅"当成了并列，保留

    * B：语言不规范的现象非纠正不可了——同样当并列，而且太重，文段并没有到"非纠正不可"的地步，好比把"本次航班飞往东京"说成"本次航班飞往南京"，砍掉

    * C、D：都在说新闻工作者很重要、新闻工作者要担负责任；报刊书籍不就是新闻工作者那儿吗，但文段是问题、是提出问题，压根儿没给对策，谈不上谁该担责

* **同构定调**

    * C 和 D 长得一模一样，属同构选项，单选中一起出局

    * 同构出局反证文段里的"不仅"只能读成并列，这道题选 A

### 核心技术："只有"换成"必须"

* **文段拆解**

    * 中国接入互联网以来在很多领域有突破、有成就，创新很强，但我们和世界先进还存在差距

    * 末句果然是对策：我们**必须**掌握核心技术，这样才……

    * "这样才"就是"只有……才……"里的"才"，出题人把"只有"两个字改成了"必须"

* **选项比对**

    * B：还存在差距——那是问题，表述没错，但问题不是答案

    * C：主动权应该掌握在自己手中——"主动权"出自掌握核心技术之后的影响，想它出身后砍掉

    * A：核心技术的突破是国家科技的彰显——说的是一个"好"、说的是影响，不是一个做法

    * D：掌握核心技术——最贴近文段的对策

    * > **提示**："只有"和"必须"往往跟对策一起考

### 徽州商帮：并列优先用排除法

* **文段主体**

    * 第一句的主体是徽州商帮：徽商很有钱，有钱之后回家造了很多房子、办了很多书院

    * 第二句的主体还是徽商：徽商有文化品质、追求艺术品位，那么造的房子一定要体现出艺术性

    * 第三句里没有"徽商"了：讲的是徽州本地的一些画派对砖雕有深远影响

    * 三个主体天然分成了两拨

* **定位与排除**

    * 共性是"徽州""建筑"；不能选"徽商"，因为徽商在第三句没有出现

    * A 和 B 都说徽商，瞬间就排除了两个选项

    * C 落在"绘画"上，绘画是第三点才提出来的，第一句第二句没有绘画，排除

    * D 说建筑：盖房子就是建筑，砖雕就是往你盖房子的那个砖头上刻点东西，它还是跟建筑有关

    * > **提示**：并列的文段最好用排除法做，因为并列的共性经常藏在个别句子的交集里，读是读不出来的，排除法反而快

### 春节与文化：例句替你拍板

* **文段拆解**

    * 第一句：文化的本质是让人有一种处变不惊的力量，不仅让人依恋传统，也鼓励人们接受新的可能。

    * 第二句"就像"（just like）明说后面全是例子：春节回家挺好、不回家错峰回去也挺好、换个地方旅游过节也挺好、时代变了年味儿远了但心在一起也挺好

    * 后半段没有再提"传统"，一直在讲"新的也挺好"，所以这里的"也"是递进

    * 落点是"文化也鼓励我们接受新的可能"，选 B

    * 现代汉语词典里"也"有十来条解释，第十条就是也可以表递进，但这个结论是分析出来的，不是背出来的。

* **两个提问**

    * 能不能用"心在一起"后面的内容去排除？不可以，"只要心在一起……才……"的"才"后面那截是影响，是不能拿来当理由砍掉的；真正该用的判别方式是——这条讨论的是过年的事儿，而过年只是例子

    * 怎么判断第一句是背景句还是总括句？第一句读完暂时不知道就往下看，第二句 just like 已经明明白白告诉你"老子是例子"了，那第一句还能是例子吗，它当然是总括句

* **落选原因**

    * A 的"春节"是举例子

    * C 的"家人团聚"也是例子当中的一部分

    * D 落在"年味"这种例子粒度上，这种选项是给竞争对手准备的

### 老龄化：服务员数据与结论

* **文段拆解**

    * 劳动总量大，但现在人口结构变了，优势就没了，我们的优势正在逐渐逐渐地没有

    * 接着罗列数据：按联合国标准，65 岁超过 7% 就是老龄化社会，超过 10% 就是老龄社会；中国实际上已经进入老龄化社会；近年来东南沿海用工荒已经凸显了这个问题

    * 前两条数据是一个组合的服务员，一起用；第三条也为结论服务

* **结论与选项**

    * 结论是"近年来东南沿海用工荒已经凸显了这个问题"——人口结构变化正在把我们的优势拖垮

    * 话题锁定"人口结构变化"；但 A、B、C、D 都不是对策，就把这个问题自己概括一遍

    * A、C 说的是老龄化社会、老龄社会怎么界定，这就在那些当服务员的数据里，最后一句的服务员、例子肯定不能选

    * B 太贼了：说"老龄化社会将导致中国劳动力供给不足"，而文段说的是"这一优势正在不断消减"；他的"将导致"是 will be，咱们的"正在不断消减"是 ing

### 中华文化：因果选果

* **文段拆解**

    * 中国文化之所以有如此强劲的生命力，就在于我们有民族特征

    * 接着"同时……同时……"罗列好多个原因，比如为什么古巴比伦消亡了而我们长盛不衰

    * 这是因果文段，结果更重要；结果就是中华文化有强劲的生命力

* **选项比对**

    * B 特别好——既有果，又把"原因"两个字带上了，所以答案是 B，它只错在时态

    * A 说"只有不断改善自身才能经久不衰"，文段的结论是"生命力要强劲"，不是没有问题；而且"经久不衰""缺乏民族特征""吸收文化"都是片面的。

    * C 提古巴比伦，一看就是例子

    * D 说中华民族要吸收别人的文化，这是原因当中的一项内容

    * > **提示**：因果文段选果；如果选项既带果又带原因，那个就最好

### 古代诗歌：主体不是朝代也不是诗人

* **文段拆解**

    * 中国历代君主的政治哲学和历史哲学早就告诉我们：王朝崩溃了，不可能有办法用法律去约束他

    * 这些人憋得慌，只能选择一种代偿的方式，通过写诗把自己心里的不平、想说的话表达出来

    * 文段点出两件事：会带来严重的灾难；这种事情不能用法律去制约，所以他们只能用文学的形式来吐槽、感慨

    * 文段里出现了"因此""所以"，是因果类文段，只要关注后面就行了。

* **主体定位**

    * 主体不是"中晚唐"，那是一个时间状语

    * 主体也不是"李商隐"，他只是一个例子、一个代表

    * 真正的主体是**诗歌之作本身**，所以一定要找咏史之作

* **选项比对**

    * A 对应第一句的前半部分——政治哲学和历史哲学，话说半截，不选

    * B 说法律可以制约统治力量，而文段明说法律根本难以进入这个层面去制约，不选

    * C 说要以史为鉴：作者说的是"根本就没办法做到"，所以我只能写写诗、吐槽吐槽，作者绝不会让世人以史为鉴，他反过来是告诉你别瞎操心了，反正你的意见也不会进入法律层面

    * D 有瑕疵，文段明明说的是"日益庞大、逐渐繁荣"，这里才"诞生"，但仍要用它去概括它所代表的日益庞大、日益繁荣；而且 D 说的"社会政治背景的原因"正好把前面一堆内容给总结出来了。

    * > **提示**：因果文段当中带着原因的结果，是最好的答案

    * > **易错点**：⚠️ 读不懂正确答案就怀疑答案有瑕疵，最后选一个"读得懂但方向反了"的选项，这是最贵的一种错。放下纠结，往作者写这句话时想干什么上靠

### 相声俱乐部：对策永远优先

* **文段拆解**

    * 周末相声俱乐部非常火爆，很让人耐人寻味；同一批"相声"，传统的却冷清

    * 第二句：在民众中诞生和成长，**只有回到群众才能有生命力**——必要条件就是对策

    * 第三句：没有观众面对面的交流、失去了舞台的切磋就不行——也是对策

* **问题定位**

    * 对策一定是针对着问题提出来的；既然文段拿"回到群众""重返舞台"当办法，问题就必须是"传统相声的冷清怎么解决"

    * 周末俱乐部火爆这件事是**引子**，不是重点

* **选项比对**

    * B：传统相声真的应该改改了、急需改变——是对策，但只说"要改"

    * D：只有……重返舞台……才能……——也是对策，直接告诉你怎么改；D 能回答 B，B 回答不了 D，对比择优选 D

    * C 错在"相声俱乐部火爆"，它里面的"回归群众"反倒是对的

    * A 说生活实践是相声的创作源泉，讲的是"相声创作的源泉"，而文段讲的是怎么把相声拎起来、重归观众、重返民间舞台、跟观众交流，一下就放到十万八千里外

    * 文段还说没有观众心领神会的捧腹大笑和理解；上舞台不就是为了逗观众笑、给观众表演，所以"重返舞台"就是相声回到舞台上演出

    * > **提示**："讲得通"就再复习一遍——你可能觉得这个选项少了一块、好像也无所谓，讲得通就行

## 答疑与作业

* **答疑一：文段最后说这些东西永远难以进入法律层面、成为统治力量，纳入法律不就成为统治力量了吗？**

    * 你看到的是"统治力量"这四个字，但你把它当成了主体

    * 它出现在"所以"之前，所以之前做的是原因；它也出现在"因此"之前，因此之前也叫原因

    * 既然是原因，那它就不是答案

* **答疑二：讲周末俱乐部，是不是就说明周末俱乐部是正确答案？**

    * 不应该提周末俱乐部的事情，它只是个引子

    * 类比推理：我的粉丝很少，刘文超的粉丝很多；我发现了——只有好好讲课、坚持讲课才会有粉丝

    * 刘文超只是用来说明"人家是在做的"这一个例子，跟要讲的结论没有任何关系

    * 人家现在已经开始指挥我了，他都快百万 V 了，我还操心他的粉丝

* **作业**

    * 题目形式：态度理解题、道理启示题、词句理解题、提炼关键词、语句填空题

    * 中心理解只要一突破，剩下的题型迎刃而解
