# 细节判断题：与中心理解的分野、错项类型与阅读顺序

## 细节判断题型

   * **细节判断题**

       * > **定义**：从原文某一部分表述中抽离出来做同义替换（不一定是原词原句了），问对还是错；或者就抽离出来的那块内容做一个非常简单的推断，问对还是错。

       * 提问方式只有两类：找出正确的、找出错误的；拿到题先确认问的是哪一类。

       * 题目给出的推断都是特别简单的，不需要复杂推理；看到"合理推断"四个字不必畏惧。

       * 细节判断题量总体不大，可以在其他题型上省下来的时间多分给它，做对没有时间问题。

       * > **易错点**：细节判断本身没有难度门槛，它只有一个特点——较真，特别烦人；它真正要的是"在鸡蛋里挑骨头"。

---

## 与中心理解的分野

   * **评判轴**

       * > **结论**：细节判断不管什么转折、因果、并列，我只管对和错。

       * 中心理解去找中心句、分述句不选；细节判断不追问谁是重点，只找对的那一项。

       * "今天上班我起晚了，但是我没迟到"——按中心理解会着重后面而选"没迟到"，按细节判断"我起晚了"同样正确。

       * 位于转折之前的选项仍可能正确，只要与文意相符；"我熬夜了"在文段里找不到依据，就不能选，哪怕它在转折之前。

   * **考察范围**

       * 中心理解始终围着中心打转，它只会考中心那一个；细节判断是满地跑，中心到边角人物一个都不放过。

```text
                 ┌────────────────┐
                 │      普京      │  ← 中心
                 │   ┌────────┐   │
                 │   │  中心  │   │
                 │   └────────┘   │
                 └────────────────┘
     蚂蚁  蟑螂  路人  警察  司机  小喽啰  卖报少年  遛狗大爷
        ↑ 细节判断挨个点名：普京也考，这些小喽啰、蚂蚁、蟑螂，一个都不放过
```

   * **取项逻辑**

       * A"普京抵达莫斯科"错：只看到飞机场，不能推出是莫斯科，他老巢在莫斯科，但谁告诉你这里是莫斯科，也可能是别处机场。

       * B"戴墨镜的人可能拿着对讲机"对：手里像大哥大，可能是对讲机也可能是电话，"可能"这个词让它站得住。

       * C"左下角背对我们的人一定不近视"错：没有眼镜腿不等于不近视，还可能戴隐形眼镜，或者近视但不戴眼镜。

       * > **提示**：提前知道"骨头"一共有几种，"鸡蛋里挑骨头"就好挑多了。

## 错项的四大骨头

| 骨头 | 一句话理解 | 例子 |
| :--- | :--- | :--- |
| 无中生有 | 原文根本没提，凭空造出来 | 我明明没有老婆，选项说"我有老婆" |
| 概念偷换 | 概念被替换、被混淆，或逻辑关系被换掉 | 阿里木江 → 阿里巴巴；并列 → 因果 |
| 偷换时态 | 时间轴上的位置被换掉了 | "你还爱我吗" vs "爱过" |
| 偷换语气 | 肯定的程度被抬高或压低 | 可能 → 一定 |

   * **识别动作**：错项不是靠"读着别扭"判定，而是逐条核对——原文有没有这个点、概念指向有没有换、时间位置有没有挪、语气程度有没有升降。

---

### 无中生有

   * **判定**

       * 原文没有任何依据，选项凭空多出一个事实。

       * 例：说"我没发工资"，老婆偏说"发了"；说"我明明没有老婆"，选项却写"我有老婆"。

       * 这类错项几乎不需要推理，只需回原文确认该信息从未出现。

---

### 概念偷换

   * **三种偷换形态**

       * **概念被替换**：文段说"阿里木江"，选项说"阿里巴巴"——前两字相同、后两字不同，整个概念被换掉了。

       * **概念被混淆**：文段说"阿里木江和李维蒙"是并列关系，选项说"阿里木江爱李维蒙"，把并列偷换成了"相爱"。

       * **逻辑关系被换**：选项说"因为有阿里木江，所以有李维蒙"，把并列换成"先有的我、后有的他"的父与子。

       * > **注意**：前两个字相似不足以判定为同一概念，判定标准是整个概念指向是否一致。

---

### 偷换时态

   * **判定**

       * 句子所处的时间点被挪到了时间轴的另一个位置。

       * "你还爱我吗"是进行时（"-ing"，此刻正在发生），"我爱过了"是过去时（"-ed"，早已结束），时态错位就产生了误会。

```text
        过去 ──────────  现在  ────────── 将来
          │                │                │
      did love       do/does love       will love
      -ed 已结束        -ing 正在进行

      "你还爱我吗" ──►  -ing  进行时（此刻正在发生）
      "我爱过了"   ──►  -ed   过去时（早已结束）

      纵向：-ing  ⇄ -ed    千万不可能替换
      横向：will  ⇄ 将来要   可以替换
```

       * > **结论**：横向的时间表述可以直接替换，纵向的进行时与过去时千万不可能替换，做题时一定要仔细看清时态。

---

### 偷换语气

   * **判定**

       * 肯定的程度被抬高或压低。

       * 文段说"可能"，选项变成"一定"；文段说"最可能跟代谢有关"，选项把"最可能"删掉、换成了一个"是"。

       * 由此衍生出考试当中的一个重要考点：绝对化的表达。

       * > **易错点**：把"最可能""大概"删掉换成"是""一定"，语气被抬高，这就是偷换语气；不要死板地只找原词对应。

---

## 绝对化与温和化表达

| 类型 | 常见表述 | 与文意的关系 |
| :--- | :--- | :--- |
| 绝对化 | 最、均、都、全部、所有、唯一、完全、一定、必然、只要……就……、无论……都…… | 通常不符合文意 |
| 温和化 | 可能、也许、大概、通常、一般、尽量、容易、往往 | 通常符合文意 |

   * **用法**

       * 绝对化选项大多数情况下是错的，温和中庸的表述大多数是对的。

       * > **注意**：这里"通常"两个字很关键——绝对化表述"通常"不符合文意，除非文段本身也那么决绝。

       * 由此得到一个小技巧"优先验证"：答案要找错的，就优先验证特别绝对的那一项；答案要找对的，就优先验证带"可能"的那一项。

---

## 阅读顺序决策

   * **通用原则**

       * 先看提问方式，确认问的是对的还是错的。

       * 文段与选项谁先读因题而异、因人而异，取决于两者各自的特征。

       * 读的时候不要管"转折之后是重点""因果之后是重点"，只需大概理一遍、留下印象。

   * **按文段特征定顺序**

       * 文段又臭又长、选项短 → 先看选项。

       * 文段较短、选项较长 → 先看文段。

       * "长"是相对感受：文段短的不一定你觉得短，文段长的也不一定你觉得长，这只是一条小建议。

   * **按选项特征定顺序**

       * **字数极少**：少到只有四个字、三个字、六个字。

       * **容易定位的信息**：数字、时间、人名、地名、特殊标点（书名号、引号）、英文字母（如 NPC、UP 主）；外国人名字中间带点的要优先定位。

       * **"一定"或"可能"**：绝对化相对易错、"可能"相对易对，可以优先验证。

```text
  文段又臭又长、选项短  ──────────────►  先看选项
  文段短、选项长        ──────────────►  先读文段

  选项里有下面信号之一  ──────────────►  先看选项，优先验证
    · 数字 / 时间 / 人名 / 地名
    · 书名号 / 引号 / 英文字母
    · 字数极少（三四个字、六个字）
    · "一定" 或 "可能"
```

## 讲义八题的切入策略

### 算法决策

   * **切入**

       * 问的是哪个是错的；选项里 A、B 谈算法决策，C、D 谈算法歧视，原文又长又臭。

       * 优先看选项：先把"C 和 D 说的是反话"这个印象拿到，再带着印象回文段验证。

   * **验证**

       * "算法的模型和输入决定着预测的结果" → A 正确，但本题找错项，A 保留。

       * "它们是主观的选择" → B"不能完全客观"有出处，B 正确。

       * 用有偏数据训练出来的也会带来歧视 → C"能够有效避免"错，答案选 C。

       * 跳读的判断依据是"取决于谁、客观、避免"这几个词有没有出现；没出现就快速扫读，出现再停下来细读。

### 宇宙再电离

   * **切入**

       * 文段短、选项乱（紫外线、明亮、再电离、掌握与否混在一起），选择先读文段。

       * 文段链条：宇宙大爆炸后约 30 万年 → 没有恒星、没有星系、被中性氢充满，是黑色的黑暗期 → 末期恒星与星系产生辐射、射出中性氢 → 宇宙变亮，这一过程叫再电离。

   * **取舍**

       * A"光辐射是形成恒星和星系的必要条件"错：紫外线是恒星形成之后才发出来的，等于先有紫外线后有恒星。

       * C"再电离发生在黑暗时代之前"错：发生在黑暗时代的末期。

       * D"我们已经充分掌握"错：原文说这是极具挑战性的一个问题。

       * 答案选 B；C、D 靠印象即可排除，不必逐字验证。

---

### 超级老年人

   * **切入**

       * 引号定位失效（"超级机器""超级老年人"前面有、中间有、后面有），只能回去读原文。

       * 文段主干：超级老年人衰老中仍有好记忆，并维持住大脑皮层厚度；核磁共振发现他们工作能力上脑子与年轻人差不多；衰老中被保护的是默认模式网络与突显网络；这两个网络的厚度与其记忆力有关。

   * **取舍**

       * B"两个网络对记忆力有很大的影响"对应末句，正确，答案选 B。

       * C 错在把两个并列事实（好记忆、大脑皮层厚度）说成因果"决定因素"，且原文只说"这两个区域的厚度"，没说它就是皮层。

       * D 错在"并未出现衰老"：原文明确说他们处在衰老的过程当中，只是这两个网络不缩水。

       * A 错在没有做比较，原文只说与年轻人差不多、媲美，从未说他比年轻人好。

       * > **易错点**：常考陷阱是"A 比 B 怎么样、A 高于怎么样、利大于弊"——文段当中没有对比，就不要对比。

---

### 石墨烯充放电

   * **切入**

       * 选项里只有 A 出现"脱离"这一个可定位词，而且只对应文段第一句话，直接验证 A。

       * 文段说充放电过程是"嵌镶和脱离"，所以充电是嵌镶、放电是脱离；A 说"充电是脱离"，错，答案在 A。

       * > **结论**：一个选项里只出现一个可定位词时，最省事的就是直接验证它——对了走人，错了答案也已经在手里。

   * **其余选项**

       * B"孔洞越多，充放电速度越快"、C"网状结构使它成为理想的电极"都能在原文直接对应，都对。

       * D"石墨烯在微观上可以无限接近二维结构"：二维是平面，三维是立体，石墨烯由碳原子构成、薄到极限，只剩一个原子的厚度。

```text
  三维（立体）  ┌───┐  ┌───┐  ┌───┐
                │   │  │   │  │   │   有高、有厚度
  二维（平面）  ═══════════════════   没有厚度
                       ↑
                    无限接近
                       ↑
  石墨烯          ┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄   只剩一个原子的厚度
```

       * > **提示**：做细节题不要想主题词，只判断这句话本身对不对；找到 A 错了就不必再纠结"二维结构"是什么意思。

---

### 人脸的光

   * **切入**

       * 文段与选项都短，读哪边都行，答案选 A。

       * 文段：人发出的微弱光，其强度在不同时间段会变，与生物钟有关、与代谢的波动有关；脸比其他部位发光更多，因为脸当中有更多的荧光。

   * **陷阱**

       * B"光的强度起伏"、C"生物钟"都能在文段找到出处，D"比其他部位更多"也对应得上，正因为没注重语气才选不出答案。

       * 关键在于文段说的是"最可能跟代谢有关"，选项却把"可能"变成了"是"。

---

### 不用手术的新疗法

   * **切入**

       * 选项极短，先看选项并预先排布考点：适用病症、主要手段、突出优势、应用局限；前三个都是优点，预判 D（局限）概率最高，但一定要回文段确认。

   * **验证**

       * 适用病症：神经传播途径出错，与癫痫、帕金森、强迫症有关，后面还扩展到神经精神类疾病。

       * 突出优势：用超声波、基因疗法、合成药物，所以不需要做手术。

       * 主要手段：超声波、基因、合成药物。

       * 三项都有出处，只有 D 找不到，答案选 D。

   * **易误读的词**

       * 文段说这个治疗过程是"可逆的"，有些同学觉得可逆就不好——刚治好病又逆回去。

       * > **结论**：这里的"可逆"是大好事；类比化疗，它把好坏细胞一起杀死所以特别痛苦，而可逆意味着好的细胞能活过来，被关闭的神经细胞随推移重新开启。

### 职能淡化

   * **切入**

       * 先看冒号：D 选项的冒号在文段里只出现一次，直接验证它。

       * 文段说已经没有这个东西了，但说它的职能已经淡化；职能淡化不等于没有，所以 D 错，答案选 D。

   * **其余选项**

       * 受到楚文化的影响；制作方法和楚俑类似、延续了它的制作方法；外形上存在明显差异，指的是发式和服饰，都没有争议。

### 建地下长廊

   * **切入**

       * 问的是"不能得知"，选项满屏都是建地下长廊、建地下管廊，先看选项。

       * A 避免反复开挖、B 更安全稳定、C"完全取代"、D 可以保证水电网络；C 的"完全取代"最绝对化，没时间就直接选 C 走人。

   * **验证**

       * A 对应：有了地下综合管廊后，人员只需要进去维修，避免了反复开挖。

       * B 对应：它多了一层保护罩，可以抵御侵蚀、提高抗震，使它更安全稳定。

       * D 错在把"大幅度减少"说成"保证"：原文只说电、水、网断掉的问题可以大幅度减少。

       * 答案选 C。

## 实战四题的切入策略

### 胜于诗者的他们

   * **切入**

       * 问杜甫为什么被宋代学者称为"胜于诗者"，先把"他们"指代谁搞清楚——指宋代学者。

       * 称他为"胜于诗者"的人把他看作集大成的人，都认为他"无体不工、无美不备"，答案选 B。

   * **排除**

       * A"诗歌史上"、C"他的地位"只是复述题干，落到"忧国忧民"文段一句没说；D"充满了儒学思想"文段也没有。

       * A、C、D 都是把自己觉得合理的说法往选项上套，不是文段给的。

       * 遇到指代词"他们/它们"时把指代对象还原成名词，就能看清选项说的到底是谁的评价。

---

### 满屏月球的撞击

   * **切入**

       * 四个选项都含"月球"，先看选项留下四个印象：月球采矿、月球有没有金矿、月球有没有被撞、月球有没有引力。

   * **验证**

       * 文段：月球是个矿区；月球上没有大气、没有构造活动，所以小行星撞上来会直接撞在月球上。

       * 有大气和构造活动的地球会把小行星弹开，月球则留下撞击痕迹，因此月球受到小行星撞击成立，答案选 C。

---

### 打引号的希腊人

   * **切入**

       * 选项里"希腊人"打引号，是共性特征，先看带引号的 B。

       * 文段：发现的特征表明这个"希腊人"可能是前人类、也就是原始人类——由"可能"推出"有人的特征"成立，答案选 B。

   * **排除**

       * A 错在主体偷换：转折之后句子的主体变成了"关于人类起源的这一新假说"，假说未必为真。

       * C 错在"只"字：研究人员可能找到的是一堆东西，不只是牙根。

       * D 错在"准确地测出来"：文段既定位不到 X 光，也给不出年代，只说"可能是前人类"。

---

### 高秆水稻

   * **切入**

       * 问题问高秆水稻种植得怎么样，而"高秆"到文中段才出现，前面说的是水田是养殖场、传统方式如何——直接从"高秆"开始读。

   * **文段链条**

       * 高秆株型很高、叶子很茂、层次很高 → 间距很稀疏 → 好多动物可以在此生活、提供了场地 → 形成"种养结合"的优势 → 解决过密导致上方空气不流通的问题；与常见稻田综合种植相比经济效益好、农民积极性高。

   * **取舍**

       * D"为稻田养殖动物"与原文"提供了良好的栖息环境"一一对应，答案选 D。

       * A"克服了传统的弊端"、B"催生了新的模式"、C"将成为未来的种植方向"都只是自己觉得文段会这么说，不能马上判对，也不能马上判错。
