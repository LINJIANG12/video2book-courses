# 中心理解收网：标题填入、态度理解、道理启示与词句理解

## 转折之后的对策

* **三层意思的文段**

    * > **定义**：看着只有两句的文段，答案藏在转折之后的对策上。

    * 第一层，问题：知识分子不敢把自己的思想讲出来。

    * 第二层，原因：过去搞怕了，或者胆小。

    * 第三层，对策：转折之后的反面论证给出的做法——敢于表达自己的思想，才能做好学术。

    * > **易错点**：觉得"逗号后面全是原因"就直接略读，省掉的恰好就是这道题的答案。

* **必要条件形式即对策**

    * "敢于表达自己的思想，才能做好学术"省略了"只有"，是必要条件形式。

    * 必要条件与对策互通。

* **干扰项的出身**

    * "做学问要敢于挑战权威"：由"生怕得罪什么人"脑补出"权威"，原文没有这个词，也没扣住"敢于表达自己的思想"。

    * "学术环境是影响学术成就的重要因素"：学术环境只是原文开头的背景，属无中生有。

    * "没有骨气的人成不了学术大家"：把"敢不敢讲"偷换成"有没有骨气"，范围扩大且不精准。

## 言语理解的三条底子

* **还原省略**

    * 把文段里省略的内容还原出来，知道最终重点落在哪儿，然后生成自己的预判。

* **看懂答案**

    * 就算正确答案里省略了一些东西、替换了一些东西，也能看懂它为什么讲得通；能看懂就说明对言语理解已经有领悟。

* **对比择优**

    * 正确答案不是直接选出来的，是对比择优出来的；没有最好，只有更好。

* **针对性的对策与直击问题的核心**

    * 对策要么是为了解决问题而出现，要么是为了实现目的而出现，它一定有一个核心，要把这个核心的点找到。

    * "传统相声俱乐部"母题：后文明明说要重返舞台、重新面对观众，是因为现在冷清了、情况有点冷清，所以得到这个对策；"周末相声俱乐部火爆"只是为了把这个对策引出来——你现在冷清了该怎么办，学它呀。

    * > **提示**：对策永远带着一个具体的主体和一个具体的问题，主体一换，对策就变。

## 关联词的省略义

### 并列的三种伪装

* **互联网加金融与支付宝**

    * "5G 时代来临了，互联网加金融很好地结合在了一起，支付宝也就应运而生了"不是并列。

    * 前面的互联网时代、金融、互联网加金融、5G 时代明显是一段背景，今天真正要谈的是互联网、是支付宝。

    * 它省略了"因此"，所以是顺承还是因果都无所谓，重点落在后面那个"也"上，强调后者。

* **语文老师与班主任**

    * "我是你的语文老师，也是你的班主任"不是并列而是强调，强调的仍然是后者。

    * 语文老师只是一个科目的授课老师；班主任不仅要教你上课，还要管纪律、跟家长联系、管考勤、安排值日、管你的个人情绪，比一个语文老师更重要。

    * 这里的"也"其实叫"更"，是递进；两个成分不能随意调换先后顺序，没人会先说班主任再说语文老师。

* **精细化管理与流浪犬**

    * "城市的管理需要下绣花针的功夫，治理流浪犬同样需要精细化管理"下意识读会觉得是并列，其实是递进。

    * 后文全在说狗的事：追踪的是狗，还要同时做好舆论引导、倡导对宠物负责。

* > **结论**：言语的灵活性不在于你背了多少关系词，而在于能不能把一个单独的关联词拎出来，想清楚它到底省略了什么。

### 一个"也"，四种省略

* "也"不能单一、机械地想当然成并列。

| 关系 | 语料里的例子 | 省略的意味 |
| :--- | :--- | :--- |
| 转折 | 学而不思则罔 | 然而 |
| 递进 | 君子博学而日参省乎己 | 进而 |
| 并列 | 敏而好学，不耻下问 | 并且 |
| 因果 | 表恶其能而不用也 | 恶其能是因，不用是果 |

* "学而不思则罔"：只学习不思考就会迷惘、迷惑。

* "君子博学而日参省乎己"：重点不在"学东西"，而在把学到的用起来——用来检查自身的言行。

* "敏而好学，不耻下问"：敏是聪明、好学、勤奋；又聪明又勤奋的人是不耻于下问的，这里的"也"叫"并且"。

* "表恶其能而不用也"：表指刘表，三国时期荆州的老大；刘表特别厌恶刘备的才能、嫉妒刘备，所以不任用他，出自鲁肃向孙权分析荆州该怎么办时提到的话。

### 一个"或"，三种省略

* "或"的第一反应往往是选择关系，但不完全是。

| 关系 | 语料里的例子 | 省略的意味 |
| :--- | :--- | :--- |
| 选择 | 叫我一声爷，或疯子，或郑涛 | 或者 |
| 可能 | 征服或将取代诸葛村夫的位置 | 有可能 |
| 并列 | 或坐着或躺着或站着 | 有的人……有的人…… |

* 选择：三者满足其一即可。

* 可能："征服或将取代诸葛村夫的位置，成为鬼畜素材之王"里的"或"是"有可能"。

* 并列：听直播课的人有的人坐着、有的人躺着、有的人站着，这才叫并列。

### 双重否定未必表肯定

* "你不能不关注公考阿里木江的 B 站账号"：双重否定表肯定，去掉双重否定就是求关注。

* "我没有不高兴哈"：双重否定表否定，她想强调的恰恰是"我不高兴"。

* > **易错点**：双重否定不恒等于肯定，要看被否定的那个词本身是什么。

## 标题填入

### 定位与两层标准

* **本质**

    * 标题填入题就是中心理解题，提问方式是"最适合做该文段标题的是……"，最适合做文段标题的正是总句的内容。

    * 考情：整张卷子里要么不考，最多最多考两道，考得不是很多。

* **中性凝练（第一层）**

    * 一定要囊括文段的中心；有中心就凝练出来，没中心就要全面提取共性、给高度概括。

* **生动凝练（第二层）**

    * 在保证中心正确的前提下，如果两个选项都符合中心，选更生动、更凝练、更能让它添彩的——读起来更高大上一点、更艺术化、更形象化、更有趣味性。

* > **提示**：现阶段的头条题其实只停留在第一层，理论讲到位，做题先按第一层走。

* **同中心的两种标题**

    * 《我的父亲李大钊》与《背影》讲的中心都是"我爸"。

    * 主人公不是鲁迅：鲁迅个子矮，坐到高凳上头可能只到凳子那么高；鲁迅的爱好绝不可能是高雅的艺术；鲁迅的胡子不是一字胡（《觉醒年代》里的卡通形象是八字胡，李大钊是一字胡）。

    * 小学阶段直白命名"我的父亲李大钊"，是先把大概意思搞懂；高中阶段有了文学素养，把父亲爬月台时触景生情的背影形象化表达，同一中心做了艺术性的升华。

* > **结论**：囊括中心是"前"，生动凝练是"天才"。

### 观点与服务员

* **技巧**：读完一个句子就找它的观点和它的服务员——观点通常出现在第一个没有服务员的句子后面；所有伺候观点的句子全是服务员，全是服务员就不读。

* 讲评开头"科学的发展给我们带来了一些崭新的思维方式"，后面四句不管换什么连接词，都是为它服务的展开或例子：

        ```text
        [观点] 科学的发展给我们带来了一些崭新的思维方式
           │
           ├── 服务员①  科技怎么发展，带来什么样的思维方式
           ├── 服务员②  从这个角度上来说，人类的行为……
           ├── 服务员③  在这张数据大网当中……（数据大网 = 前面的互联网）
           └── 服务员④  再比如……（与前面那个"比如"并列，仍服务于观点）
        ```

* 选出要点：整个文段就是一句话——科学的发展带来了新的思维方式，谁有"科学"、谁有"思维方式"、谁有"带来了"就选谁；"给人类带来了"比"无所不在"更贴切，"无所不在"只说哪儿都有。

* 讲评开头"蚁巢的防御策略有哪些"是主题，后面是服务员：

        ```text
        [主题] 蚁巢的防御策略有哪些
           │
           ├── "尽管……"  →  铠甲 / 锋利 / 让捕食者难以下咽（并列的个体手段，跳读）
           └── "但是"     →  重点：巢穴是最后一道防线，一旦被突破就"绝对不好"
        ```

* 选出要点：谁有"蚁巢"、谁有"防御问题"就优先选谁；"全民皆兵的蚂蚁"没有巢，排除；"蚂蚁的防御策略"意思对却不点明巢穴——"A 可以回答 C"，A 更明确所以 C 出局；"你所不知道的蚂蚁世界"是网文式标题，而这里要找中心，何况"我所不知道的"范围太大。

### 引子式话题与反推排除

* **引子式话题（"与 X 不同"）**

    * 文段在讲正式话题时常用"与 X 不同，Y 怎么怎么样"，而后面整篇再也没说过 X，干扰项常常是 X 与 Y 的不同点或把两者并列的说法。

    * > **易错点**：⚠️ 此时 X 只有一个作用，就是一个引子，千万不要选跟 X 有关的任何答案。

    * 讲评开头"与专门的科研游戏不同，一些科研项目和游戏合作了，搞数据分析"：观点出来之后，游戏和这个计划的组合就是例子；后面"探索计划""本来以为"都是例子当中的下半句，虽然有"蛋"但整个属于例子，不管不看。

    * 正确项要同时体现"科研项目和游戏合作完成数据分析"；把两个例子并列出来是错的；"游戏的新变革"方向对但不够明确；"公众科学""嵌入游戏"把科研项目说成了巧妙变形，比"游戏的新变革"更明确。

    * 另一处干扰项把"多种"藏在第一句一个不重要的地方，看到"多种"就以为是概括；⚠️ 做错都是因为关注错了它的出身。

* **反推排除（预判找不到的时候）**

    * 预判在答案中不容易找到时用排除法：选项第一眼"长得对"没用，读完文段反推一遍，对不上就出局。

    * 讲评开头以"染色食品曝光了"设问、说"事实并非如此"，因果断言是颜色会改变你对食物的体验，进而影响你的食物选择；后文举例成分和加工过程一模一样、只因颜色不一样评价就不一样，属分述。

        ```text
        如果"染色技术"正确，文段该长这样：

           现代食品制作当中的染色技术            ← 总起
           ├── A 型染色技术：……
           ├── B 型染色技术：……
           └── C 型染色技术：……

        但文段实际讲的是：

           成分和加工过程一模一样 → 颜色不一样 → 评价不一样
        ```

    * 排除过程：食品添加剂范围太大；"哪些因素会影响食物的味道"错在文段讲的是选择而不是味道变了；"现代食物制作当中的染色技术"说的是我们怎么去制作，反推对不上；剩"食物色素"。

    * 反过来印证心理学线索：总句是总起、分句服务于总句，分句中有心理学的思路和线索就能证明"食物色素"讲得通。

### 对策落点与总分总

* **对策落点**

    * 讲评开头"很多人对甜味和吃糖感到排斥和恐惧"→"其实"转折，真正让你发胖的不是糖也不是甜味，而是摄入的能量（能量守恒：摄入低于基础代谢就会瘦）→"淀粉在体内所释放出来的热量和蔗糖没区别"是能量的具体展开 → 最后一句的"要"字省略了"需要"，"需要"是对策标志。

        ```text
        问题：很多人怕甜、怕糖，以为会发胖
           │  转折（其实）
           ▼
        原因：真正让你发胖的是摄入的能量，不是糖也不是甜味
           │  "要……" ＝ "需要……"（对策标志）
           ▼
        对策：要控制发胖，主要就是控制你的热量，不管它甜还是不甜
        ```

    * > **易错点**："X 与 Y"并列式标题要反推出文段应同讲 X 和 Y；"吃糖与发胖"都在转折前，"淀粉与发胖"里淀粉是服务员，都不成立。这段文段前轻后重、有侧重，不是并列。

    * "发胖的真凶"是原因不是对策——如果只想说谁让发胖，就不会告诉读者怎么控制。

* **总分总与"这一切"**

    * 讲评开头"中国的 FAST"引起热烈关注，原因有三：看得远、很灵活、高精度；但最后一句是"这一切意味着，我们将倾听这样的声音、这样的奥秘"。

        ```text
        首句   中国的 FAST 引起热烈关注，原因有三：看得远 / 很灵活 / 高精度
                        │
                        ├── 分述：FAST 好在哪（"原因有三"）
                        │
                        └─── 总结：这一切意味着，我们可以听到宇宙深处的声音、
                             可以观测更神秘的宇宙        ← 波浪线在这里
        ```

    * "这一切"把三点甚至更前面的内容全包了进去，范围比只讲第三点大得多；若是"这意味着"才有可能只指第三点。

    * 没有这个波浪线时才可以选"中国的 FAST"；有了它文段就形成类似总分总的结构，必须既选主体"中国的 FAST"，又选结尾结论"FAST 可以更深入地观测宇宙"。

    * ⚠️ "一起倾听来自宇宙的声音"只有结论没有主体（听谁的？我拿耳朵听吗）；"中国的 FAST"只有前半段、没说 FAST 能干什么；"走进中国 FAST"兼有主体与结论。

* **六题套路总表**

    * 错误选项各有出身，看穿出身比反复纠结更省时；正确项则一律由对比择优产生。

| 题 | 文段主题 | 答案 | 陷阱在哪 |
| :--- | :--- | :--- | :--- |
| 一 | 科学的发展带来新的思维方式 | D | C"无所不在"没体现"给人类带来" |
| 二 | 蚁巢的防御 | A | C 意思对却不点明巢穴；D 是网文式标题 |
| 三 | 科研项目与游戏合作做数据分析 | C | A 选了两个例子；D 的"多种"藏在第一句不重要处 |
| 四 | 食物色素的心理暗示 | B | A 范围太大；C 说"味道"；D 要靠反推排除 |
| 五 | 控制摄入总量才能不发胖 | D | C 是原因不是对策；A、B 是"X 与 Y"并列式 |
| 六 | 中国的 FAST 及其结论 | B | C 只有前半段；D 只有结论没有主体 |

### 对策的优先级

* 对策的优先级是最高的，但分三种文段结构：

        ```text
        文段结构                     优先级
          │
          ├── 提出问题 + 给出对策   ──→  对策（唯一优先级）
          ├── 提出问题 + 反面论证   ──→  反面论证推出的对策（唯一优先级）
          └── 只有问题、没有对策   ──→  有对策选对策；选项里根本没有对策，才选问题
        ```

* > **易错点**：片面理解成"对策永远优先"，在"只有问题、没有对策"的情况下就会翻车。

## 态度理解

### 提问方式与定位规则

* **本质**

    * 态度理解就是中心理解换个问法：提问有"这段文字可知作者的观点是什么""某人支持的观点""某人的态度是什么""看法是什么"，问的还是观点。

    * 唯一的小细节：问的是作者就找文段的中心；问的是具体某个人，就去找那某一个人。

* **观点的可见性**

    * 观点有可能明明白白出现，也有可能隐约出现。

    * 文段中作者根本没有提观点、没有表达（等于他关了朋友圈、没有评论）时，选项就选"作者没有看法"。

### 赞同、反对与没表态

* 观点题会用赞同、反对、不置可否三类来呈现。

* > **定义**：**不置可否**——"置"是放置的意思，不置是不把手放到任何按钮上，"可否"是不发表观点、谁都不选；它等同于无观点，"没说"就等于"没有"。

* 马大帅说"岳云鹏帅？你开玩笑呢吧"：问马大帅的态度，答案是岳云鹏在马大帅心中是不帅的。

* 吴德荣说"很多人都说他帅，小翠儿也觉得岳云鹏帅，但是我觉得刚子帅"：问的是对岳云鹏的态度，而"很多人说他帅""小翠儿说他帅"跟吴德荣没关系，跟他有关的是刚子，所以这道题没有观点——绝不是"不帅"。

* 范德彪说"很帅"：这里"很帅"指的就是岳云鹏很帅，问范德彪态度要找到的就是这一条。

* 把吴德荣那句"我觉得刚子帅"删掉也不影响答案，因为它与这道题的话题不一致。

### 文物的看法

* 第一句是作者印象中的看法：文物很神秘、很枯燥、遥不可及，和其他没什么两样，有隔阂。

* 转折后态度改变：逐渐听到一些收藏家的回忆、看到一些文物之后，发现文物或充满人情世故，或有彼此坚守，或有一些情感，或有一些历史的点滴；"我便开始对于文物有了新鲜的认识"——"我"就是作者。

        ```text
        印象     文物很神秘、很枯燥、遥不可及，和其他没什么两样，有隔阂
                    │  后来（听到一些收藏家的回忆，看到一些文物）
                    ▼
        新认识   文物或充满人情世故，或有彼此坚守，或有一些情感，
                 或有一些历史的点滴
                    │  "我便开始对于文物有了新鲜的认识"
                    ▼
        作者的态度：文物是有温度的、可以"寄情于物"的
        ```

* 正确项"寄情于物"：它不只指东西，其中包含很多情感，与"充满人情世故""有历史的点滴""有好多小故事"对得上，是把自己的情寄托于物上。

* 后面的分述（原来文史中的文物是载体，里面可以传播内容）可以快速读或直接不读。

* > **结论**：态度题里的观点往往不在开头那一句，而在"印象 → 新认识"这个转折之后；问"谁"就找"谁"，剩下的活儿全交给中心理解。

## 中心理解题的选项取舍

### 成语义与适用主体

* **成语记牢的依据**

    * > **定义**：想把一个成语记牢，办法是记它的适用主体和典型语境，而不是记它的字面拆解。

    * 字面拆得再对，主语用错，一样是错选项。

    * 判断一道成语选项时，先问这句话里的主体是谁，再看成语能不能挂在这个主体上。

* **超然物外**

    * > **定义**：指人超出世俗生活之外，置身于世外。

    * 它的主体是人。

    * > **易错点**：看到"超然物外"里有"物"字，就认为主体是物，这是按字面拆成语拆出来的错误。

* **文物案例的排除路径**

    * A 选项很容易排除，一眼就知道不对。

    * B 选项"物尽其用"讲的是把这个东西用到极致、充分利用，但文段里根本没有提到"利用"这层意思。

    * 排除 A、B 后只剩 C"超然物外"，而 C 仍要败在两点上：其一，超然物外通常是指人的；其二，它所描述的对象出现在**转折之前**，而这个文物的出身也正在转折之前。

    * 转折之前呈现的是一种高冷的、遥不可及的样子，所以"超然物外""超脱世俗"说的是那个文物，不是作者对文物的看法。

    * 题目真正的主体是**作者对文物的看法**，所以不能选 C。

### 态度的归属主体

* **虚拟技术题的推进链**

    * 第一句"中国人面对虚拟技术……他说兴趣远远超过西方人"单独拎出来，ABCD 一个都选不出来。

    * 这一句是背景，不是答案，A 选项"欢欣鼓舞"正是被这句话铺出来的。

    * 整段真正在问的是"我的体验"：中国人特别喜欢破坏自己原有的逻辑，特别义无反顾地和原来的东西决裂。

    * 虚拟技术给我们带来的是冲击，是一种幻象；面对这些东西如果一味去享受，我们会头晕、会恶心，这恐怕比它本身更令人惊惧。

    * 所以作者的态度是**消极**的，A、B 可以删掉，剩下 C、D 都是消极的，还要再辨词义。

    * C"忧心忡忡"是很担心，D"嗤之以鼻"是不屑，答案是 **C**。

        ```text
          现象：中国人对虚拟技术兴趣远超西方人      ← 只是背景，不是答案
                │
                ▼
          作者追问：我的体验呢？
                │
                ▼
          中国人特别爱打破原有逻辑、与旧东西决裂
                │
                ▼
          虚拟技术给我们的只是冲击和幻象
                │
                ▼
          一味享受 → 头晕、恶心，"比它本身更令人惊惧"
                │
                ▼
          作者态度是消极的 → 在"消极"里再辨词义 → 忧心忡忡
        ```

    * 确定情绪极性之后还要在同为消极的选项里辨析词义，"嗤之以鼻"与"忧心忡忡"不是一个东西，只判断出"消极"还不够。

* **干扰项的来路**

    * 想真正学会言语，要去想一想命题人为什么会设置"欢欣鼓舞"这个选项，它对应文段的哪一句话。

    * 想明白了这一层，才明白一道题的干扰项是怎么铺出来的。

### 作者立场的缺位

* **网友的担心不是作者的立场**

    * 第一句写 IBM 研发出沃森战胜了两个人类，"好一时间网友担心"，是原句，肯定表达的是担心。

    * 第二句只有"担心。"两个字，带问号，是追问句。

    * 第三句"担忧？还是担心？还是'有人认为……'"，仍在追问，怀疑对象依然是网友。

    * 这些担心都是**网友**的，"有人认为"的内容也已经说完，作者并没有表态。

* **观点缺位时的取舍**

    * 作者的观点根本没有出现，所以这道题直接选 B。

    * 至于其他选项，不做分析，因为作者的观点根本没有出现。

    * > **结论**：一个选项和文段有"话题上的关联"，不等于它就是答案。作者的观点没出现，任何"我觉得作者应该是……"的推断都是自己加戏。

## 道理启示题

### 题型特征与提问方式

* **题型定位**

    * 它考得很少很少，题量只有 0~1 道。

    * 2019 年的江苏考到了，山西也考到了。

* **提问方式**

    * 通常问"启示是什么""这段文字告诉我们什么""告诉我们什么道理"。

    * 它往往是以一个**故事**呈现的。

    * 只要发现文段是一个故事，就明白肯定要抓它的道理，而绝对不要就事论事。

    * 如果文段根本不是故事，那本题就不是道理启示题，别硬往上套。

### 就事论事的两种错解

* **碰撞实验**

    * 实验内容是：限速 50 的时候车撞上去了，70 的时候前面撞毁了，90 的时候前面两座都毁了，180 直接就飞出去了。

    * 就事论事会得出"只要你够快，电线杆子都拦不住你"，因为 180 之后电线杆子都没了。

    * 就事论事还会得出"不要买红色的车"，因为买红色的车就会撞。

    * 这两种都不对，正常人的理解就能得出：他想说的是安全驾驶、禁止超速。

* **农夫与蛇**

    * 农夫好心救了蛇，蛇花言巧语地求他救了命，可真被救之后蛇反而出来要害农夫。

    * 就事论事是说"我们的这个农夫好傻"，或者说"蛇真的是狡猾的动物"，这两种都要避免。

    * 正确的道理是：我们要谨防那些狡猾的人来欺骗我们，善良的人千万不要上当受骗。

### 故事题的三步切入

* **操作顺序**

    * ① 找结果：最后谁得到了什么、谁怎么样了。

    * ② 找原因：为什么会是这个结果。

    * ③ 抽掉具体的人和物，只谈道理，不谈这件事。

        ```text
           读到文段
              │
              ├─ 读到的是一个故事吗？
              │     │
              │     ├─ 不是 ──► 本题不是道理启示题，别硬往上套
              │     │
              │     ├─ ① 找结果：最后谁得到了什么、谁怎么样了
              │     ├─ ② 找原因：为什么会是这个结果
              │     └─ ③ 抽掉具体的人和物 ──► 只谈道理，不谈这件事
        ```

* **第三步的作用**

    * 第 ③ 步最要紧：故事讲完了，答案才刚开始。

    * 要把"农夫""蛇""老奶奶""抑郁症"这些具体的东西替换成"人""欺骗""孤独""人际"，选项里才可能出现你要的那个词。

## 道理启示题实战

### 老钟与小钟的摆钟

* **故事与选项**

    * 提问方式是"这段文字给我们的启示是什么"。

    * 老钟对小钟说，他一年要摆 31536000 下；小钟说这么多下怎么可能完成得了，老钟说不要怕、并不难，只要坚持每秒摆一下就可以了，还说 Just try it，just do it。

    * 读故事时不需要划斜线，小钟最终终于摆完了这么多下。

* **逐项排除**

    * D"圆梦"首先被排除，因为文段的结果里并没有"圆梦"这一层。

    * C"不忘初心"被排除：文中没有念念不忘的表述，小钟甚至说"哎呀，怎么可能呢，我怎么可能完成呢"，他根本没有什么所谓的初心。

    * A"坚持"与 B"化整为零"都出自原文，但答案是 **B**。原因是"坚持"是老钟说的，小钟最后是很轻松地就摆了一下，不知不觉一年就过去了，并没有坚持。

    * "很轻松地就摆了一下"里的"一下"和"每秒摆一下"对应上的正是化整为零。

    * "千里之行始于足下"里的足下对应的也是很轻松的摆了一下，答案 B 覆盖得更全。

* > **易错点**：故事题的干扰项常常和正确项只差几个字。"坚持"和"化整为零"都出自原文，但只有真正照应到**结果**的那一个才是答案。判断的唯一办法是回到原文逐句读全，别凭印象。

### 分号与省略号的分总信号

* **结构信号**

    * 读的时候发现两个扎眼的东西：有分号，有省略号。

    * 由这两个信号猜测它大概率是个分总结构，这只是一个假设。

    * 看到它们先在心里画一道斜线，把总分界线画出来，再决定哪个是总。

    * 猜错了不要紧，猜的时候心里要留着"这只是个假设"。

* **三个分述与总句**

    * 中科院的"蝌蚪"（科普抖音小视频）累计发布了很多，播放量很多。

    * 西安交大二院有个医生把"心电图之歌"做成了视频，下载的人很多。

    * 林业大学这个人用新媒体传播知识，让公众读懂了绿色。

    * 一和二的共性是搞科普视频然后很多点击量，第三个也是一样的。

    * 结尾用省略号说"正是这些……"，"正是"是表强调，"这些"指前面三者，既是强调又是总结。

    * 前面这些被称作"科普力量"：科普力量架起了桥梁，催生了科普的春天。

* **选项归属**

    * 答案 D"众人拾柴火焰高"：众人指中科院之声、西安交大二院的医生、林业大学的学生，柴指他们去播科普视频，每个人添火焰，火焰高，科普的春天因此被催生。

    * A"打铁还需自身硬"说的是做事情要强调自己有实力，根本没有对应上。

    * B"金子总会发光"证明的是一个人是人才，选它的人是把注意力放在分述句上，而聪明的同学会把注意力放在总句。

    * C"功夫不负有心人"说的是努力之后的结果，好像就是"他点击量很多"，依然没抓住点子。

### 电影产业的学与行

* **文段脉络**

    * 导演、监制都是复杂的工种，其中最重要的一个是经验的积累。

    * 接下来展开这个观点：没有经历过片场的摸爬滚打、没有执行能力，就会有问题。

    * 结论是一些国家的电影产业成熟，这些人从学校毕业之后当学徒、写剧本、副导演、执行导演，才能当导演，最后"导而优则兼做监制"，而监制比导演要难多了。

    * 所以真正要强调的是：一定要在逐个逐个的过程当中摸爬滚打，积累经验。

* **选项区分**

    * A"纸上得来终觉浅"是完美答案：新人毕业前后在学校学习对应"纸上"，后半部分在实践当中积累经验对应"得来"，前面也有后面也有。

    * B"书山有路勤为径，学海无涯苦作舟"说的是读书勤奋、学习刻苦，但分不清是在学校学习，还是在工作实践当中学习。

    * C"天才是 1% 的天赋加 99% 的努力"强调的是努力，但分不清想强调的是在学校学习努力还是在片场努力。

    * D"不想当将军的士兵不是好士兵"是拿破仑说的，讲一定要有雄心壮志，与文段无关。

* > **结论**：A、B、C 讲的都是勤奋、努力这类好话，差别只在于谁在做、在哪里做。A 把"学"和"行"都锁死在文段里，所以它赢。道理题要选覆盖全、指向准的那一个，不要选"听起来最正确"的那一个。

### 晚归场景的针对性对策

* **文段的客观与主观**

    * 客观层面是作者加班晚归，被家人用不耐烦的腔调说了一句"你咋才回来，是吧？"。

    * 主观层面是作者的态度：累了一天还要小心翼翼承受"暴力"，觉得承受了暴力，而妈妈却吃惊地说自己是在关心你。

    * 最后的转折引出了重点，也就是作者的苦恼——为什么一个不耐烦的腔调，会把关心听成嫌弃的感觉。

        ```text
          ① 客观：作者加班晚归，被家人一句不耐烦的"你咋才回来"
          ② 主观：作者态度 —— 这让我压力很大，像承受了"暴力"
          ③ 提问：为什么一句关心，被我听成了嫌弃？
          ④ 对策：好意还需要好好表达            ← 转折之后是重点，答案 B
        ```

    * 概括重点时，① 是客观的，② ③ 是主观的，注意力要放在后两个上。

* **对策的选定**

    * 这属于"提出问题类"文段，理论要点是优选针对性的对策。

    * 问题的症结是"不耐烦的腔调"，办法是好好说话，跟"及时沟通"没有半毛钱关系，所以答案是 **B"好意还需要好好表达"**。

    * 不能就事论事落到"你妈妈应该好好说话"，应该上升为"我们人都应该好好说话"。

* **其余选项的问题**

    * A"及时沟通"错在这里的问题是及不及时，而问题实际是不耐烦的腔调。

    * C"恶语良言自带冷暖"出自"良言一句三冬暖，恶语伤人六月寒"，它是在帮你分析好话和不好的话自带冷暖；一是文段最后落到了问题，对比 B 不如 B，二是恶语指粗鄙之语，这里只是不耐烦的腔调，"你怎么才回来呀"正常去听不算恶语，程度被加深了。

    * D"有些情感的伤害来自于不经意间"的"不经意间"范围扩大了，不只是不经意说错话，而且是问题表述，比 B 少了具体和对策。

* > **结论**：对策类选项的排序永远是三条——优选针对性的对策 > 优选更具体的那一个 > 才轮到意思相近的泛化表述。

### 米尔顿的玫瑰花处方

* **故事与提问方式**

    * 提问方式是给文字加一个合适的标题，虽然形式上是标题，但内容讲了一个故事，所以仍以故事类的道理启示为切入点。

    * 心理大师米尔顿治疗过一位患极度抑郁症的老太太，发现她喜欢种花，于是激她说，你这么喜欢种花，有本事就把你种的花送给城里的每一个人，他们结婚了你送花，他们生子了你送花，他们过生日你送花。

    * 老太太说那我就试一试，最后这位极度抑郁症患者变成了城里最受欢迎的人。

    * 文段最后有个"因此"是重点结论：只要你按照这个处方去做，你的孤独抑郁就会得到痊愈，而这个处方就是多去给别人送花、像老奶奶一样送花。

* **抽离与排除**

    * 不能停留在老奶奶送花，要抽离成主动分享、付出关爱、分享与付出。

    * B"做有意义的事情"范围太大，课间唱首歌、路上扶人过马路都是有意义的事情，而我不一定要送你玫瑰。

    * 剩下的 A、C、D 里，"改变人生"这种说法范围也太大，中 500 万同样可以改变人生。

    * A 与 D 纠结时，切入点是你应该做的事情是什么，也就是"反推"。

* > **定义**：人际藩篱就是人际交往当中由猜忌、由怀疑、由疏远产生的障碍。

* **D 胜出的理由**

    * 老奶奶压根儿是个独居的人，她根本就不跟别人说话，所以她跟别人之间根本就没有人际藩篱这回事。

    * 她被治好的病是孤独，抑郁症就是孤独，只说"孤独"是不完整的，没有点出孤独的真正成因。

    * 所以 A 片面，D"打破人际藩篱"才是答案。

* > **易错点**：故事里的具体名词必须抽离成抽象概念。农夫不能说农夫、蛇不能说蛇，要说人和欺骗；老奶奶不能说老奶奶、抑郁症不能说抑郁症，要说人和孤独。在选项里看到"抑郁症""送花""老奶奶"这种照抄故事的词，基本可以直接排除。

## 词句理解题

### 借中心理解的解题思路

* **题型特征**

    * 它考的也不是很多了，2017 年考得多，2021 年之后就考得少一些。

    * 提问方式是"这段文字当中 ××× 指的是什么"，××× 可能是词语，也可能是短句子。

    * 解题思路是定位原文以及详细理解，定位原文谁都会做，重点在详细理解的过程。

* **核心方法**

    * 词句理解题不是直接找中心理解，而是**借助**中心理解。

    * 如果直接找中心理解，你要找的是"好学"，但把这三个字直接放到句子里显然不对。

    * 正确的说法是：因为他好学，所以这里的"墨水"就是知识，不是直接拿过来用，而是要借助中心理解。

    * 它依然是中心理解题当中的一个小变形，只不过借的是中心理解的思维。

### 陈毅吃墨水的两个墨水

* **课文情节**

    * 陈毅非常好学、非常勤奋好学，家里来了客人，他稍微见了一下、问了好，说没啥事儿就去读书了。

    * 妈妈一边照看客人一边过来看他，给了他两个饼子吃；过一会儿又过来问他怎么不吃，是不是觉得太干巴巴了，再给他拿了个蘸酱让他蘸着吃。

    * 妈妈再一次过来倒水时震惊地发现，他的嘴巴全是墨水。

    * 原来他读书聚精会神，本该去蘸酱却蘸到了墨汁，丝毫没有感觉到有什么区别，说明他学习非常专心。

    * 最后陈毅心平气和、平静、诙谐地说：吃点墨水没关系，我正觉得肚子里的墨水太少了。

* **两道"墨水"的理解**

    * 前一个"墨水"指真正的墨水，是他读书时不小心蘸到嘴里的墨汁。

    * 后一个"墨水"指知识。

    * 之所以能判断后一个是知识，是因为整篇文段的中心是陈毅是一个好学的人，既然他好学，他需要墨水，所以好学的人需要的就是知识。

    * 靠上下文就近去猜会得到"墨水"或"墨汁"，正确的路径必须借助中心理解。

### 指示代词的就近抓取

* **就近原则**

    * 指示代词会简单一些，既然是指示代词，就往前看。

    * 指示代词往前看，一般情况下**就近**就可以了，不需要往前全部的内容都看，数上一句就可以。

* **只抓主谓宾**

    * 重点抓的是句子的主谓宾，千万千万不要受到状语的迷惑。

    * 例句是"星期六下午七点，在好朋友的资助下，我在八一老爷吃饭了"。

    * 只让你抓主谓宾时，应该抓"我、吃饭了"。

        | 句子成分 | 例子中的内容 | 作用 |
        | :--- | :--- | :--- |
        | 时间状语 | 星期六下午七点 | 表示你在哪一个时间状态下 |
        | 条件状语 | 在好朋友的资助下 | 表示你在什么条件下才吃得到这顿饭 |
        | 地点状语 | 在八一老爷 | 表示你在哪儿吃的 |
        | 主谓宾 | 我 吃饭了 | 真正要抓的部分，其余一律不管 |

    * 巴依老爷是北京的一个新疆餐厅，在老师工作那段时间只有三家店，现在已经有 20 多家了。

### 一般词句的解释说明优先

* **优先找解释说明**

    * 一般词句要重点看被问词句的**附近**内容，看有没有明显的表示解释说明的标记。

    * 有解释说明就直接读这个解释说明的部分，比如冒号、破折号。

* **没有解释说明时**

    * 先通篇理解，把中心找出来。

    * 找到中心之后，再借助这个中心去分析这个词句到底是什么意思。

    * 词句出现在段首时，如果读不清楚，整篇文章都得读；出现在段尾时，前面没读明白、后面模棱两可，还是得全读。

* **两条路的共同终点**

    * 指示代词是往前看一句、就近抓主谓宾；一般词句是先看附近有无冒号破折号，没有就通篇理解。

        ```text
          定位被问的词句
                │
                ├── 是指示代词 ──► 往前看一句（就近即可）──► 只抓主谓宾，状语全部忽略
                │
                └── 是一般词句 ──► 看附近有无冒号、破折号
                                      ├── 有 ──► 直接读解释说明的部分
                                      └── 无 ──► 通篇理解 ──► 先找中心 ──► 借助中心反推含义
        ```

    * 两条路只有一个终点：都是回到"中心"上去定词句的含义，指示代词是中心在句子里，一般词句是中心在全文里。

## 词句理解题实战

### 未来与短期转折

* **转折定位**

    * "未来"出现在这里，而整个文段只有一句话，由"但是"之前和"但是"之后两部分组成，而"但是"之后是重点。

    * "但是"之后说短期的上涨速率是放慢的，这种趋势是可以预见的，也就是转折之后是短期的趋势。

* **由转折反推**

    * 转折表前后应该相反，既然转折之后是短期趋势，那"未来"就是**长期的趋势**。

    * 所以答案直接锁定 C。

    * 其他选项不读的话都还差不多，无法判断是即将到来的以后还是马上的以后；这里有一个"但是"之后是短期的上涨趋势，所以这里一定是长期的上涨趋势。

    * 这道题用的正是借助中心的思路，也就是中心理解的思路。

### 新机制的保障与市场

* **冒号后的四条**

    * "新机制"前面被打了一个冒号，冒号意味着后面的内容就解释了新机制。

    * ① 公交承担低收入者、环保人士的公益服务职能，由政府购买提供，落在**保障**。

    * ② 个体自行车出行依然纳入政府购买体系，落在**保障**。

    * ③ 出租车价格高低不影响需求，所以开放市场来竞争，落在**市场**。

    * ④ 小汽车的使用可以征收费用，把交通拥堵的外部性内化，落在**市场**。

        ```text
           "新机制"（冒号后面的内容就是解释）
                  │
                  ├─ ① 公交承担低收入者、环保人士的公益服务职能，由政府购买提供 ──► 保障
                  ├─ ② 个体自行车出行，依然纳入政府购买体系                   ──► 保障
                  ├─ ③ 出租车价格高低不影响需求，所以开放市场来竞争         ──► 市场
                  └─ ④ 小汽车的使用可以征收费用，交通拥堵的外部性内化       ──► 市场
        ```

    * 一二是保障，三四是市场，三四都通过收费的方式实现。

* **排除配套与绿色**

    * 后面（波浪线部分）说"这种新机制的实施还要有一些配套"，说明新机制本身已经讲完了，答案不可能有"配套"，所以把 A 删掉。

    * 后面的内容着重说的是绿色出行，所以谁提到绿色环保，它绝对不可能是答案，把 B 也删掉。

    * C 和 D 之间，"公平高效"从来没出现过，答案是 **C 保障和市场**。

* > **易错点**：选 A 的同学切记，我们是在**借助中心理解**，而不能把它**当作中心理解**。后面的配套措施是为了它的实施，不是机制本身。

## 政府保障

* **政府保障**

    * > **定义**：政府掏钱去购买、去提供这类带有公益性的低价服务，就叫政府保障。

## 提示词划定答案范围

* **提示词与答案范围**

    * > **提示**：看到"强调了"加冒号，要找的东西马上就来。

    * 冒号、破折号、"强调了"、"更为重要的是"这类提示词一出现，答案范围基本就圈在它后面。

    * 破折号一出来，答案范围基本圈在后面，从哪儿往后找不用怀疑。

    * 首句、尾句、别处都冒出同一个关键词时，说明答案不在首尾，必须读全文。

    * 顺着提示词可以直接跳过纯观点句、过渡句，落到真正有货的句子。

* **选项的"出身"**

    * 正确项抄的就是被提示词标出来的那个重点句本身。

    * 错误项抄的是重点句之后的展开、举例、分析。

    * 选项读着顺不顺是次要的，抄没抄对地方才是决定项。

    * > **易错点**：只读到关键词就停下、不往下读，正好落进"抄了重点句之后展开"这条坑。

* **设问对象：含义不是意义**

    * 题目问"传统文化的正确打开方式"，问的是它的含义；"我能干嘛""我实现了什么"属于意义，不选。

    * 破折号后面的整段话里才藏着真正的设问答案，划线处本身不是。

    * 面对并列的几项，前面明明白白挂着"更为重要的是"的那一项就是最重要的。

* **故宫例题的干扰项**

| 选项 | 它在暗示什么 | 为什么会选错 |
| :--- | :--- | :--- |
| 拓宽了传统文化的宣传渠道 | 以前比较尴尬，现在华丽转身、内容丰富再造了；在云端、在博物馆，那不就是互联网嘛，互联网就是一种宣传方式 | 脑补太多。云端和数字只是故宫所在的位置，不是它的"打开方式" |
| 实现了丰富和再造 | 对传统进行了解读，丰富再造不就是一种全新的解读吗 | 找错地方了，把手段当成了含义 |
| 利用网络、利用数字技术 | 云端不是网络吗，数字不就是网络吗 | 又是把手段当答案 |

* **正确项的落点**

    * 从皇家私藏到国家所有，人人可看、人人共享——这就是"正确打开方式"的真实含义：跟大众走到了一起。

    * 前三项分别落在云端、数字博物馆、创意用品之中，都是位置，不是打开方式。

## 代词指代：划线只看前面

* **方法**

    * > **提示**：划线部分指代什么，只看它的**前面**，后面一概不管；往前找不到主谓宾，就再往前找一句，直到把这句的主语锁定为止。

    * 前面若干行可能是一整句话而不是若干句，找答案时以"一整句话"为单位。

    * 划线问什么就找什么，不要顺着划线往回扫一整段。

    * 后文出现的新塔、新例子与划线无关，不看。

### 砧板与塔身

* **木质砧板：重点在"但是"后面的内部结构**

    * 前面三行合起来是**一整句话**，答案就在这一句里。

    * "与谁相比"不重要，"木质砧板是今天的话题"也不重要；重要的是"但是"后面的内部结构。

    * 谁提到了"内部结构有空隙"，谁就是答案——正确项是"结构特点"。

    * 干扰项来自开场看到的石头、金属、木头，是给"看见东西就急着选"的人留的。

    * 另一干扰项来自砧板是木头做的，被顺手当成"制作工艺"。

    * > **易错点**：外形和材料来源都是干扰，"内部结构有空隙"才是划线真正问的那件事。

* **塔身：往前找到的那一座才算数**

    * 先找前一段的主谓宾，主语是塔身；哪座塔不知道。再往前一句，主语还是一个塔身，还是不知道。

    * 再往前才找到：最早现存的那一个密檐塔，建于嵩山，称之为嵩岳寺塔。

    * "密檐塔"是统称，是从好多塔里挑出来的类；这里要选的是单独的那一个。

    * 所以第一句话里的主体是嵩岳寺塔，不是密檐塔；答案必须写成"现存最早的密檐塔"，光说"密檐塔"不够。

    * 小雁塔和后面乱七八糟的塔都在划线之后，代词题一概不看。

### 逗号之后的"这"

* **状语的识别与排除**

    * 状语是在某种状态下、某种时间下、某种地点下。

    * "在盟军登陆诺曼底、攻占欧洲大陆的情况下"是一串条件限定，是状语，不可能被选中，直接排除该选项。

    * 答案回上一句的主谓宾：前一句"这种情况"指英美关系紧张。

* **同型自测与干扰项排查**

    * "我买了彩票，中了 100 万，在我失业半年多的情况下，这是个天大的好消息"——消息是"我中了彩票 100 万"，不是"我失业半年多了"，因为后者是状语，所以不重要。

    * 若题目问的是"这种情况是指什么"，选指责英美的内容一点问题没有；但本题问的不是这个。

    * 离划线太远、在开篇出现的内容，排除。

    * > **易错点**：文段里有两个"这"，人家问的是这一个；拿另一个去答是中心理解的答法，别串台。

## 提炼关键词：重点和话题都要找

* **提炼关键词要做的两件事**

    * > **提示**：先把文段划分成几个层次，然后一层一层看。

    * **重点**你本来就会找：转折之后是对策、是结论。

    * **话题（主体）**要找那些反复出现的名词。

    * 考情：江苏考得多，其他地方考得非常少，国考偶尔蹦出来。

### 一个关键词：结尾的新说法

* **"憧憬"与"幸福感"**

    * 文段由 50 年代、60 年代、70 年代、80 年代、90 年代一串分述句组成，各年代各说各的，这就是文段的共性。

    * 最后一句突然换说法：前面写"憧憬"，最后写"幸福感"，多出来的"感"字说明对幸福的憧憬 = 幸福感。

    * 关键词是"幸福感"。

    * 错误项之一只覆盖了最后那一个年代的内容，片面。

    * 另一错误项比原文少一个字，缺的正是这个"感"字——不能只说"幸福"。

    * "幸福的内容一直在变"这种说法不能作为答案。

    * > **易错点**："对……的憧憬"里，重点在"憧憬"后面那个被憧憬的东西，不是"憧憬"这个行为本身。

### 两个关键词：话题和重点各一个

* **"关键在于放到阳光下"**

    * "不仅有整体的要求，还有细化的细节"后面由"比如"展开，展开部分不必细看。

    * 真正抓到的是"但是"后那句：只靠规定，力度有限，关键在于放到阳光下。

    * "放到阳光下"就是监督，这是**重点**。

    * "连接"是**话题**，提到主题；"监督"提到重点；两者分落不同选项时，按组合成句判断。

### 三个关键词：谁、为什么事、做了什么

* **三要素的含义**

    * 三要素就是主体、问题、对策。

    * 能找到谁、为什么事、做了什么，三要素就齐了，选项根本不用看。

    * 掌握主体法尤其适合概括全文失败的文段：概括不出来没关系，主体总能理出来。

* **智慧与哲学例**

    * 第一句主体是智慧，本身是确定的；虽提了"以知识为前提"，重点仍是智慧。

    * 第二句"知识可以怎么怎么样，智慧则可以怎么怎么样"，"则"是转折，转折之后是重点——智慧更重要。

    * 第三句"然而哲学……，哲学是智慧的结晶"，着重说的是哲学。

    * 智慧、哲学都齐了；"知识"虽被提到，但不是重点，可以不管。

* **政务数据例**

    * 一看到"应"字就跳起来，这是对策。

    * 主体是政务数据，要解决的问题是数据整合，对策是标准规范。

    * 往后走时"采集、处理、提供、修改"都不是重点，落在"等各类的标准规范"上；后文"标准化的处理""规范化的分类"是对这个对策的展开。

    * 抓住"标准规范"四个字，就能在两个候选里直接选。

    * > **易错点**：拿并列出现的"数据采集"或"分类管理"当重点——出题人就是用并列关系钓人，不要只取弟弟。

    * 还有错误项只说"数据交换"，既不靠要解决的问题也不靠对策，两头不靠。

### 主题加对策

* **刑事证据规则例**

    * 第一处：鉴定材料的真实性和同一性已成为一个前提条件——谁是前提谁就很重要，因为它是对策，第一个框出来的必须选。

    * 第二处：我国刑事证据**制度**发生了一个变化，这是今天要谈的主题。

    * 第三处：透过这个变化发现一个新的理论认识——实物证据鉴真是前提和基础。

    * 第四处：不鉴真就没有法律意义，真实性和同一性不存在就不具备那个资格——后面几段全是顺着前面展开的。

    * 主题至少找到两个：实物证据鉴真（鉴定材料的真实性和同一性）、刑事证据制度。

    * 只有把两个主题都装进去的选项扛得住；正确答案还要同时装下主题（刑事证据）、对策（鉴真）、要解决的问题（定案依据）。

* **排除法：抄哪儿比选项读着顺更重要**

    * 抄关键词前先确认它在原文里的位置关系。

    ```text
    实物证据鉴真  ──是"前提和基础"──▶  司法鉴定程序
    ```

    * 谁是前提谁就重要，所以该抄实物证据鉴真，抄司法鉴定程序就是抄错地方。

    * 司法改革出现在文中不重要，属于小喽啰当中的小喽啰。

    * 司法鉴定意见出现在"不好的影响"当中，处在否定的一面，靠排除。

    * > **易错点**：靠位置关系判断重要性，不能因为某个词"看起来更专业"就选它。

## 语句填空：横线在结尾等同于中心理解

* **题型三分与优先级**

    * 语句填空分三大类：空在前、空在后、空在中间。

    * 考得最高的是**空在最后**，先学这一类。

    * 横线出现的位置不一样，对策就不一样。

* **结尾必须是总句**

    * > **注意**：横线在结尾一定是总句。

    * 分句里既可以摆事实、可以讲道理、还可以说名人名言、还可以分析原因，角度太多，填进去答案就不唯一。

    * 这是单项选择题，答案必须为一，所以最后一句话空了，那一定得是总句。

    * 既然是总句，不就是把前面概括出来吗——等同于中心理解题；记住"等同于"三个字即可，不用把它写出来。

* **例外：前文只提了问题**

    * 前文是提出问题类、分析问题类文段时，结尾可以写一个针对性的对策。

    * 形态上带"应该……""最有效策略是……"的是针对性对策，只描述现象的是问题表述。

    * 两者并存时选对策，只存在问题时选问题表述。

    ```text
    提出问题类 / 分析问题类文段  +  横线在结尾
                        │
            ┌───────────┴───────────┐
            │                       │
        有针对性对策            没有针对性对策
            │                       │
       选对策：有 A 选 A      选问题表述：无 A 选 B
    ```

* **更明确的选项优先**

    * 两个选项都成立时，选表达更明确、更直接给出做法的那一个。

    * 一个说"我别咋办"，一个说"我要咋办"——选后者。

### 结尾是半句话：往前找缺的那个话题

* **睡眠偏好例**

    * 最后一句是半句话，只能往前整理。

    * 主题词有两个：特质、睡眠。

    * 责任心水平低、内向、难以入睡等例子都框在"例如"下，反复说的还是人格特质和睡眠。

    * 最后一句已经把"睡眠"说了，还缺人格特质，所以选含人格特质的项。

    * 正确项与原文构成同义替换。

    * 谈改变身体状况、谈评价标准的选项根本没提人格特质。

* **平凡与不凡例**

    * "一个人在平凡当中书写不凡"是半句话，往前找特质。

    * "人贵有恒"，恒是恒心；"有恒心、有毅力"是总观点。

    * 一以贯之、久久为功、坚持不懈、成就事业，仍然在说"人贵有恒"。

    * 例子一李保国，例子二古人言。

    * 错误项要么没有"坚持"，要么后半截落在原文没有展开的词上。

    * > **易错点**：认为李保国重要就选他所在的选项——例子可有可无，优先排除，剩下那个通篇说坚持的才是。

### 提出问题类文段：先形式后内容

* **海洋塑料例**

    * 开篇就是提出问题：塑料对海洋生物、对人类都有影响。

    * 塑料碎片分化成小颗粒，被海洋里的一些东西吃掉，难以溯源、难以清除——这是进一步分析这个问题。

    * 四个选项里三个是对策、一个是哭诉问题，形式上先排掉哭诉问题的。

    * 内容上再品：把话题域缩小的、把"塑料"换成"一次性塑料"的、说"根治"而与原文相悖的、凭空归因的都要再排。

    * 正确项覆盖了塑料与海洋两个话题域，并从源头减少排放，直击问题核心。

* **三个常见瑕疵**

    * 话题域缩小：说海洋只取其一。

    * 偷换主体：说塑料变成一次性塑料，那脸盆怎么办。

    * 违背以人为本：要限制什么得先做宣传、设置回收点、给一段过渡期，不能一步到位。

## 分述句里的陷阱

* **翻译工作例**

    * 第一句有两层意思：翻译工作是什么；翻译工作必须像劳动工作一样具备严谨的工匠精神，力求一丝不苟。

    * 横线在最后，是总句，必须把前面概括一下——本质上就是中心理解。

    * 第二句由"由于"领起，解释为什么要工匠精神：市场发展后出现了快餐式翻译、人工智能式翻译。

    * 第三句代指前两种翻译，依然框在"由于"里面，是分述句：翻译是市场需要的一种新事物，市场有需要就允许它存在。

    * "但是这种翻译"指的就是快餐式翻译加人工智能式翻译。

    * "但是"后面那句话仍在分析"由于"领起的那些分述项，没有跳出分述块。

    * 所以结尾横线仍是"翻译工作必须严谨、精益求精"这个总观点。

    ```text
    第一句（观点句／总）
      翻译工作必须严谨、必须具备工匠精神
            │
            │  "由于" 领起一个分述块
            ▼
    第二句 → 第三句 → "但是这种翻译……"
      快餐式翻译 / 人工智能式翻译出现，市场有需求，允许它存在  ← 全在分述里
            │
            │  "但是" 只能否定它们的"替代性"，不能否定它们的存在
            ▼
    结尾横线（总句）
      翻译工作必须严谨、精益求精                            ← 正确答案
    ```

* **陷阱成因与排查**

    * 陷阱选项只摘取了"但是"那一句的上半段——否定替代性，被当成了否定分述项本身。

    * "但"能否定被"由于"领起的一整块分述的某个属性，否定不了这些分述项的存在本身。

    * 谈"市场和技术"的、谈"不同翻译类型满足市场需求"的，都还在分述句里。

    * > **易错点**：只把最后倒数第二句当成上文，就落入了陷阱——格局不能只锁在一句上。
