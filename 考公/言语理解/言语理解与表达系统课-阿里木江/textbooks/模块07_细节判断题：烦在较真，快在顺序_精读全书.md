## 细节判断题：烦在较真，快在顺序
> 对应块：BLK20 | 覆盖分集：P07下 | 块标题（分集名）：《言语理解与表达系统课第7节--阿里木江》

细节判断是言语里最烦人的题型，没有之一。题干一摆上来，它就那么直勾勾地问你：这段话里，下面哪句是对的，哪句是错的。有的同学做细节判断要一个个选项比对，耗掉大把时间，做完还心里发虚——"我刚才那题到底选对没有？"

我特别理解这种烦躁。而且我得先说一句公道话：细节判断确实需要时间，它可以稍微多要一点、慢一点。细节判断的题量总体来说不大，你在别的地方省下来的时间给它，做对是没问题的。

但今天我不想只讲"它需要时间"。我想聊的是另一件事：**有没有办法在细节判断上提速。** 今天整套的东西，都是围绕这一件事。

> **定义**：细节判断题——它可能从原文的一部分表述当中给你抽离出来，然后给你同义替换，不一定是原词原句了，问你对还是错呀；或者根据它抽离出来的这块内容，给你进行一个非常非常简单的推断，然后让你判断对还是错。

再给你吃一颗定心丸：同学们不要看到"合理推断"就吓得要死，还要推理呀？不需要。题目给的推断都是特别特别简单的。

### 细节判断和中心理解，是两道完全不同的题

我要给大家再三强调：**细节判断和中心理解，有天大的区别。**

提问方式刚刚已经聊过了。细节判断考的是什么？问的是对还是错。中心理解去找中心啊，分述句不选，选中心句。于是解题的动作也就彻底不一样了。

我举个例子。今天上班我起晚了，但是我没迟到。

如果按照中心理解的思维，我着重放到后面——"我没有迟到呀"，答案选 B。

但是细节判断不管谁是重点，只管对与错。以下文段当中理解正确的，我只要找对的。选项 A 说"我起晚了"——对呀，起晚了，所以 A 正确。选项 B 说"我熬夜了"——我怎么知道他熬没熬夜呢？我不知道，所以我不能选，虽然它在转折之前。

所以答案是 A。

> **结论**：细节题不管什么转折、因果、并列，我只管对和错。

### 画里的普京和蚂蚁

再说得形象化一点。如果一幅画就是我们的文段，那细节判断和中心理解在这幅画上的考察方式，是完全不一样的。

```text
                 ┌────────────────┐
                 │      普京      │  ← 中心
                 │   ┌────────┐   │
                 │   │  中心  │   │
                 │   └────────┘   │
                 └────────────────┘
     蚂蚁  蟑螂  路人  警察  司机  小喽啰  卖报少年  遛狗大爷
        ↑ 细节判断挨个点名：普京也考，这些小喽啰、蚂蚁、蟑螂，一个都不放过
```

读图就是一句话：中心理解始终围绕着中心，它只会考普京，因为普京是老大嘛；而细节判断是满地跑，上到普京，下到蚂蚁蟑螂，全都会考。

既然这些"小喽啰"都可能出题，那我来给你们出一道题：下列三个选项当中，正确的是谁？

**A：普京抵达莫斯科。** A 错。有同学说"对呀，普京下飞机了，那肯定抵达莫斯科了呀"——不一定。你只看到了飞机场，就认为他是总统，总统要回到他的老巢，他老巢在莫斯科。谁告诉你这里是莫斯科呢？也有可能是别的地方的机场呀，所以 A 错，我不知道。

**B：戴墨镜的人可能拿着对讲机。** B 对。戴墨镜的这个小喽啰我们圈出来，他好像手里拿着类似大哥大的一个东西，对不对？所以这个大哥大有可能是对讲机，也有可能是电话。这里有一个非常可爱的词叫做"可能"，所以我们觉得这个词加上去了就很好，所以 B 选项是可以选择的。

**C：左下角背对着我们的这个人一定不近视。** C 错。他的理由是什么呢？你看，他这都没有眼镜腿儿，所以他不近视。可有可能他戴隐形眼镜呀，有可能近视他不戴眼镜呀，还有很多很多种可能性，所以你不能说"一定"啊。

答案选 B。

现在你应该发现细节判断题为什么很烦了：**因为它就希望我们在鸡蛋里面挑骨头。**

> **提示**：在鸡蛋里挑骨头，我要是提前知道有哪些骨头，是不是好挑多了？四大骨头，我现在就告诉你。

### 四大骨头：错项是怎么造出来的

| 骨头 | 一句话理解 | 本节课的例子 |
|---|---|---|
| 无中生有 | 原文根本没提，凭空造出来 | 我明明没有老婆，选项说"我有老婆" |
| 概念偷换 | 概念被替换、被混淆，或逻辑关系被换掉 | 阿里木江 → 阿里巴巴；并列 → 因果 |
| 偷换时态 | 时间轴上的位置被换掉了 | "你还爱我吗" vs "爱过" |
| 偷换语气 | 肯定的程度被抬高或压低 | 可能 → 一定 |

#### 无中生有

这个非常好理解。今天我说我发工资了，我老婆却说……我说我没发工资，但是我老婆偏说我发工资了。我说没钱，她偏偏说我有钱。所以这就叫无中生有。

就比如刚刚我举的那个例子，我明明没有老婆，选项里却说我有老婆，所以也是无中生有。这个理解起来非常简单。

#### 概念偷换

概念可能被替换，概念可能被混淆，或者是逻辑上给你偷换。我们来看三个例子。

第一个，文段说的是**阿里木江**，选项说的是**阿里巴巴**。你有没有发现？突然这里面两个概念进行了一个偷换。虽然前两个字是差不多的，但后两个字是错的，所以他概念偷换了，我们不能选。

B，文段说的是阿里木江和李维蒙，说的是并列的事情——我和他。结果选项说"阿里木江爱李维蒙"，变成了我爱他。这是不是概念混淆了呀？把并列的概念变成了一个"爱"的概念、"相爱"的概念。所以这里错了，我跟他是比较纯粹的关系。

接下来这个更绝，甚至选项当中还会这么说：**因为有阿里木江，所以有李维蒙**。把我变成了父与子的概念，是"先有的我，后有的他"。

所以这些都叫概念的替换、逻辑的混淆，大家一定要搞清楚。

#### 偷换时态

偷换时态，我就想到了我以前的一个小故事。

当我给我最后一任女朋友说"你还爱我吗"这几个字的时候，她已经给我打了一个字，她说：**"爱过"**。

为什么呢？因为我们把时态搞错了。因为"你还爱我吗"是不是一个进行时？Do you still love me? 是不是啊？你还爱不爱我呀？Are you loving me? 是不是啊？是 -ing 的形式对不对？而这时候她说"我爱过了"，是不是 -ed 的形式啊？所以我们俩把时态搞错了，当然就产生了误会。

```text
        过去 ──────────  现在  ────────── 将来
          │                │                │
      did love       do/does love       will love
      -ed 已结束        -ing 正在进行

      "你还爱我吗" ──►  -ing  进行时（此刻正在发生）
      "我爱过了"   ──►  -ed   过去时（早已结束）

      纵向：-ing  ⇄  -ed    千万不可能替换
      横向：will  ⇄ 将来要   可以替换
```

读图：横向的时间可以替换——"以后会怎么样"我说"将要怎么样"，可不可以呀？可以。纵向的时间不能替换，进行时和过去时，那是错了一个维度。

> **结论**：横向的能不能替换？可以直接替换。纵向的千万是不可能替换的。所以做题的时候一定要仔细看清楚时态。

#### 偷换语气

我刚刚言之凿凿地说了一些话，那也有同学说：有些时候我遇到的是，文段当中说的是"可能"，但选项当中就变成了"一定"。这种语气上的这种肯定，就叫偷换语气。

而偷换语气衍生出来考试当中的一个重要考点，那就是**绝对化的表达**——它大多数情况下是错误的；而那种温和中庸的表达，大多数是对的。

| 类型 | 常见表述 | 与文意的关系 |
|---|---|---|
| 绝对化 | 最、均、都、全部、所有、唯一、完全、一定、必然、只要……就……、无论……都…… | 通常不符合文意 |
| 温和化 | 可能、也许、大概、通常、一般、尽量、容易、往往 | 通常符合文意 |

> **注意**：这里"通常"两个字很关键。绝对化的表述"通常"不符合文意——除非文段本身也那么绝决。

所以这就给了我们一个小技巧：**优先验证**。

> **提示**：它不是告诉你直接去选，它是告诉你优先验证。如果这道题我要选错的，我突然看到有个选项当中有一个特别绝对的，我是不是优先验证它呀？如果我要选一个对的，我发现有个选项当中有"可能"，我是不是优先验证它呀？

好，到这里理论铺垫完了。我们今天来聊一聊细节判断到底怎么样做才能提速。

### 先读文段，还是先读选项

#### 做题注意事项

细节判断做题，先记住三件事。

第一，先看提问方式，问的是对的还是错的。

第二，如果我们纠结老是先看文段呢还是先看选项呢？我告诉你因题而异、因人而异。今天的八道题，咱们每一道都谈一谈怎么应该先看文段好还是先看选项好。今天整个题目的梳理，我会跟大家谈策略。

第三，就是我们不管读文段也好、读选项也好，千万不要管什么"转折之后重点""因果之后重点"，都不要管。你只需要大概地理一遍、留下印象就可以了，好吗？

理清楚这些事情，我们今天就聊一聊八道题。可能跟其他老师讲法不一样，其他老师可能直接给你讲怎么做，我来给你聊怎么做会更好，我们探讨探讨。

#### 文段给的一刀：长还是短

从文段的特征来说，如果文段又臭又长，而选项短，那我这里肯定建议先看一看选项喽。如果文段较短、选项较长，我建议大家先看文段。

这里是因人而异的，为什么呢？因为我觉得文段短，不一定你觉得短；我觉得文段长，不一定你觉得文段长。所以这里是一个小建议，你想听也可以，不想听也行。

#### 选项给的三种信号

从选项的特征来说，出现了下面这三种情况，我个人建议大家先读选项。

**第一种，字数极少。** 什么叫做字数极少？也就是字数少到那种只有四个字的、三个字的、只有六个字的，这才叫字数极少。那肯定优先先去看看这个选项呀，我们今天也有这样的题。

**第二种，出现容易定位的信息。** 比如说选项当中出现了 1996，而文段当中就有一个地方 1996，那假如我直接定位到这个 1996，这道题做完了，我是不是赚到了呀？所以我个人建议你，发现了数字、时间，发现了特殊的标点符号，比如说书名号、比如说引号，你能够比较轻松地对应，这道题做出来你就赚到了。

还有就是人名、地名。这里的人名不能简单的是那种"某某某"——比如我的名字就很长；而且还有一些外国人的名字中间带点，你应该优先去定位一下这些内容。还有英文字母，比如 NPC，比如 UP 主之类的。你可以先定位，这是我的一个小建议。

**第三种，出现"一定"或者"可能"。** 相对易错的不是绝对的吗？相对易对的不是"可能"的吗？你是不是可以优先验证呀？

```text
  文段又臭又长、选项短  ──────────────►  先看选项
  文段短、选项长        ──────────────►  先看文段

  选项里有下面信号之一  ──────────────►  先看选项，优先验证
    · 数字 / 时间 / 人名 / 地名
    · 书名号 / 引号 / 英文字母
    · 字数极少（三四个字、六个字）
    · "一定" 或 "可能"
```

### 八道题，八种招

#### 找错的：分成两组的算法决策题

第一题。它问的是哪个是错的，对不对？那么请问你想先看我们的文段还是想先看我们的选项？

好，我发现想先看选项的稍微多一点点。那么这道题——首先我知道了它问的是错的；其次你有没有发现，选项当中 A 和 B 都是问你决策的事情，而 C 和 D 都是问你歧视的事情，而原文是又长又臭，而且算法、决策这个事情我觉得我压根就不懂。有没有这种体会啊？如果你有这种体会的话，你是不是想着先看看选项，然后带着印象去读题呢？这是我的想法。所以我选择优先看选项。来，我操作一遍。

**A：算法决策的结果取决于模型、输入。** 好，我明白了。

**B：算法决策不能完全客观。** 好，我明白了。

**C：算法歧视能够有效避免。** **D：算法歧视难以避免。** 太好了，C 和 D 说的是反话呀，那答案多半就是在 C 和 D 嘛，对不对？

带着这样的一个印象，我们来看文段。

首先第一句话"算法决策"，那跟 A 和 B 有关。他说"是用过去预测将来"，跟我 A、B 没关系，继续往后走。**"算法的模型和输入决定着预测的结果"**——太好了，A 选项出来了没有？形容得对不对？对呀，所以 A 选项是正确的。可是我要找的是错的，所以 A 保留。

继续往后走。"这两个也是歧视的来源"，好，答案应该往 B 和 C 走了吧？他说"一方面算法怎么怎么怎么样，包括什么什么"——你看我在跳读，我为什么跳读？因为没有出现我要找的"取决于谁、客观、避免"这几个词，没出现，所以我就快速扫读。但是，我读到这里，**"它们是主观的选择"**，我有印象——你不是"不能完全客观"吗？所以 B 选项也有出处呀，B 正确。

接下来再往后走，他说"数据的有效、真实会影响决策的准确性"。影响它的准确性，那要不要读？肯定要读呀。继续读，"用这样数据训练出来的也会带来歧视"。你告诉我，避免了还是没避免？是不是没避免呀？所以 C 选项错。这道题找的就是错，**答案选 C**。

那大家觉得这样作细节判断怎么样呀？当然，你也有可能是这么做的：先把文段读一遍，读完之后再一个个看 A、B、C、D。当然这取决于你的习惯。我只是把我的想法告诉你，这只是我的一家之言，这是我的做题方式。如果你觉得认同，你可以试一试；如果你觉得得心应手，你以后就可以这么做；如果你试了试觉得"哎呀不行，这样方法我理解不了、掌握不了"，那你就按你自己的方法。

> **易错点**：细节判断根本就没有什么难度，它只有一个特点：较真，特别烦人。

#### 文段短、选项乱：宇宙再电离

第二题。这一道题文段就比较短了吧——这是第一印象；其次，选项当中一会儿说紫外线，一会儿说明亮，一会儿说再电离，一会儿问我掌握没有，是不是很乱呐？所以我干脆先去读一下文段，然后带着印象去选 A、B、C、D。换一个思路，咱们试一试嘛，多种思路试一试。

我来读。宇宙大爆炸之后大概 30 万年，整个宇宙是黑的。好，了解它是黑的就行了。在那段时间就是黑色的时间，宇宙没有恒星、没有星系，被中性氢所充满。好，明白了：第一句话说它很黑，第二句话说有什么中性氢。第三句话说，你不是没有恒星吗？最后在末期的时候有恒星了、有星系了，而且它们发出了这种辐射，射出来了中性氢，最后就亮了。整个这个过程就叫做再电离的过程。但是呀，再电离的这个过程，星系何时形成？这是一个问题。

好了，我有印象了，我看 A、B、C、D。

**A：形成恒星和星系的必要条件是光辐射。** 找呗，对应回来。找到哪里了？宇宙第一代恒星是不是形成了？形成之后才发出来的紫外线吧？所以紫外线是不是在形成之后才有的呀？因为是它们发出来的，对不对？但你却说紫外线辐射是形成它的必要条件，也就是先有紫外线，后有恒星。错了。A 错。

**B：这个使宇宙明亮起来的过程就是再电离过程。** 多半就是对的。为什么呢？因为你看，使整个宇宙明亮起来，这个过程就叫做再电离。所以这道题如果在考场上，选 B 走人就可以了。

**C：宇宙再电离发生在黑暗时代之前。** 胡说！再电离发生在这个黑暗时代的末期，不是之前。所以有印象就可以做出来。

**D：我们已经充分掌握了。** 明明说的是"极具挑战性的一个问题"，它还是一个讨论的问题呢，怎么可能已经充分掌握呢？

所以 C、D 是不是不需要验证呀？**答案选 B。** 这道题其实做起来很快吧？

#### 引号定位失效：超级老年人

第三题的第一反应：这里有引号——"超级机器""超级老年人"，本想用引号定位。失效了。为什么呢？我刚想定位，结果这儿也有、前面有、中间有、后面有，全都出现了。

怎么办呢？那我们只能去看一看原文吧。因为这个"老年人记忆力"话题好像研究得没有那么深，而且这里一会儿说老年人，一会儿说网络，一会儿说记忆力，一会儿说大脑。所以这道题你先读文段也行，或者先看选项再读文段也行。

```text
  二维（平面）  ═══════════════════   没有厚度

```

我们不能马上说它对，不能马上说它错。

但是 D 选项：为稻田养殖动物。是不是可以为青蛙、鱼、泥鳅——这是不是稻田养殖动物啊？一一对应吧：提供了，提供；良好的，良好；栖息地，栖息环境。是不是完全一一对应呀？那你觉得这道题选哪个最好呢？选 D。

> **结论**：我并不是说 A、B、C 到底是对的还是错的，因为我根本不在乎 A、B、C 到底对还是错。我只知道 D 选项一定对，所以这道题我做完了。如果你想较真 A、B、C 到底谁对到底谁错，那你的时间就浪费了。我就是来做题的、我就是来把题目做对走人就完事的人，就可以战成功了；而剩下你一直在这苦海里面挣扎的人，你就是比别人做得慢，听懂了吗？

### 一家之言，用不用你定

今天的四道题讲完了，辛苦大家了。

我今天创新了一下我的讲课模式，我不知道大家喜不喜欢这种模式。就是你要知道，最后细节判断我到底要干个啥？我学了半天，跟人聊了半天策略，我到底要用在哪？所以我希望你觉得，如果这个策略可以，你就用；如果你觉得策略不行，你就不用。

大家商量着来，这全都是一家之言。你觉得可以你就用，你觉得不行你就不用。因为我不敢说是教你们做什么事情，咱们是一个学术的良性探讨，言语是很灵活的嘛，这需要我们不断地碰撞，说不定你有一些好的东西我也可以借鉴。

下节课咱们学排序。下下节课是我们的篇章阅读。然后，我们这言语就告一段落了。
