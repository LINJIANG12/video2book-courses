# 言语理解与表达系统课

阿里木江老师的言语理解与表达系统课。课程覆盖片段阅读、逻辑填空、语句表达与篇章阅读，按题型讲解判断依据与解题顺序，并配套真题演练，适合系统性建立言语部分的作答能力。

- **原视频**：https://www.bilibili.com/video/BV1oA411c7Eh — Bilibili，BV1oA411c7Eh
- **11 集**，已产出 11 册模块全书、11 篇复习笔记、27 份逐字稿

## 怎么学

- **片段阅读** → 掌握中心理解题的行文脉络分析方法
- **逻辑填空** → 语境分析与词语辨析两手并用
- **语句表达** → 语句排序、填入与衔接三类题型分治
- **篇章阅读** → 综合运用，训练长文本的快速定位能力
- **速查** → `notes/` 下的笔记按题型整理，便于考前回顾
