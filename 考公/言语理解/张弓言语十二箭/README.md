# 张弓言语·十二箭（22 讲）

一门专注行测言语理解与表达的方法课：把言语题收敛成「中心理解、语句表达、逻辑填空」三大题型，用「文段怎么读、选项从哪来、干扰项长什么样」这三件事贯穿全程；后半部分是 115 道选词填空真题的逐题精讲，每道题都落到「词语辨析—文段提示—选项排除」的具体打法上。适合已学完系统课想集中刷题提速，或方法懂了但正确率上不去的备考者。

## 怎么学

- **先建读法再刷题** → 前 3 册是方法主体：中心理解（笔记 01-02）、语句表达（笔记 03）、逻辑填空（笔记 04-06），方法没吃透前不要急着进真题册
- **真题册当题典用** → 第 4-6 册把 115 道选词填空真题逐题拆解，做题卡住时按题号查对应讲解，比回看视频快
- **逻辑填空抓「对应」** → 笔记 05 的并列关系与两空对应、笔记 06 的选项来路与干扰项识别，是这套课最容易被忽略但提分最快的两篇
- **逐字稿按半集粒度查** → 逐字稿是块级产物（每集切成上下两半），40 份对应 22 集，核对讲师原话时按 `PXX上/PXX下` 定位
