### 题型再多，根上只有两个

先带大家正确认识一下各个题型的思路逻辑。今天重点是中心理解，但在讲它之前，得先解决一个问题：为什么要把重心压在中心理解上？

大家回忆一下，言语理解与表达各个题型大概考什么。片段阅读这边有中心理解、细节判断、标题、词句理解；语句表达这边有语句填空、接语与排序，还有大家的老大难逻辑填空；江苏、北京、国考副省级甚至还要考篇章阅读。是不是感觉言语的题型特别多？特别是一刚接触的时候，很容易冒出"老师，言语题怎么这么多"的念头。

在这儿我给大家的三观做一个改变：你别看他这么多题型，但在我看来，他就考察两个题型，或者说一个半。有同学在公屏上已经答得非常好了——就是中心理解。我一个一个给大家解释，这就是为什么我们要花大力气解决中心理解。

| 题型 | 根上在考什么 |
| :--- | :--- |
| 标题题 | 填一个标题、把握主旨，本质上就是中心理解。标题就是中心，中心就是标题，这两个题型没有任何区别 |
| 词句理解题 | 要理解某个词、某句话在文段里的意思，你得先对整个文段有所了解，所以它是中心理解或者细节判断的变形 |
| 细节判断题 | 主要就是查找信息，是个比较小的题型 |
| 语句填空题 | 要抓住横线的核心意思、知道这句话填什么，就得把握上下文，而上下文的把握还是中心理解 |
| 接语选择题 | 接下来想说什么，后文不能偏题，后文的内容要跟前文保持一致，所以你还是得知道前面在干嘛——中心理解的变形 |
| 语句排序题 | 考的是句子和句子的关系，而句子和句子的关系，从根上来讲也是你的中心理解理解得到位（这个后面会详细讲） |
| 逻辑填空题 | 分为文段加选项。文段的理解本质上是中心理解，只不过在文段理解之外，还要考察词语的积累 |
| 篇章阅读 | 各个题型的综合，更不用说 |

所以你看，整个片段阅读，除了细节可能差点意思之外，考的就是你对文段的理解能力——这个文章在干嘛。整个语句表达这个模块，本质上也是考察中心理解。

那逻辑填空为什么我说是两个题型？因为它难。大家发现没有，逻辑填空分为文段加选项：文段的理解，选项的（词语的）理解。文段的理解本质上又是什么？又是中心理解，只不过在文段理解的基础上，你要考察词语的积累。所以我说这个题型难就难在，它既考察中心理解，又考察词语的理解。

> **结论**：言语理解与表达题型虽然非常多，但根本上就两个题型——第一个是中心理解，第二个是逻辑填空当中词的辨析。

这就是为什么课程设置上，前五节都是中心理解，这是有原因的。有同学会问，为什么语句表达只讲两节课？它没有那么重要——因为你前面学好了，后面自然就好了。中心理解这个题型学好了，后面的题型一通百通，所以大家一定要把重心放在这块上。

### 三步走：找重点、同义替换、排除干扰

既然这个题这么重要，咱们就言归正传：中心理解题怎么做？

有同学说找中心句、理解主旨，有道理。但通过这节课，我希望咱们以后统一路径——中心理解题就三步，所有的考点都围绕这三步展开：

```text
一个文段
   │
   ▼
┌───────────────────────────────────┐
│ 第一步  通读全文，找重点           │ → 中心句 / 主旨句
│          （七类句子关系）           │
├───────────────────────────────────┤
│ 第二步  同义替换                   │ → 主题词是依据
│          （找一个最像的选项）       │
├───────────────────────────────────┤
│ 第三步  排除干扰选项               │
└───────────────────────────────────┘
```

今天你所有的内容都可以忘掉，但这三点得记住：第一步找重点，第二步同义替换，第三步排除干扰选项。就算你听完整节课说"老师我听不懂"，没关系，这三步请你牢牢嵌在自己的大脑当中，我们这节课就围绕这三点展开。

先说一下行业现状：市面上绝大多数的言语教学体系，关于中心理解这一块，都是围绕"怎么找"展开的，而且只讲了怎么找，没有第二步、第三步。咱们也不例外，但我会给大家归纳一个小的方法——你只用把握句子与句子的关系，积累几组常见的关系，也就够了。

### 第一步找重点：七类句子关系

#### 七类关系逐条过一遍

什么叫找重点？一个文段虽然有很多话，但很多时候某一句话就能概括中心，我们经常把它叫做中心句或者主旨句，本质是一样的。所以第一步就是在这么多句子当中，找到那个最重要的那一个——摄人心魄。

问题就来了：怎么找？怎么知道哪个句子重要、哪个句子不重要？我帮你归纳出来了，用得最多的就是下面这七类关系。有些老师可能总结得更多，那也没问题，但关键比较多的就是这七种。

| 关系 | 重要的一半 | 他的例子 |
| :--- | :--- | :--- |
| 转折关系 | 转折后 | 虽然我生病了，但是我还在上学——上学重要 |
| 因果关系 | 结论、结果 | 开始学英语，后来学化学，又学数学，最后发现物理才是我最喜欢的——物理是重点，前面的过程、原因没那么重要 |
| 必要条件关系（对策） | 对策 | 我不舒服，我需要吃一些药——解决问题比问题本身、比意义都更重要（这个后面几节课会专门展开） |
| 解释关系 | 前面明确直接的观点、论点 | 老李是一位慈祥的老人，每天都会笑嘻嘻地和同学打招呼——"慈祥"是观点，后面是为了论证它的。学判断的同学都知道，论点比论据重要 |
| 强调关系 | 被强调的内容 | 我们班同学大家都非常不错，特别是小红非常好——重点是小红 |
| 新旧关系 | 后文出现的新话题 | 过去的深圳一片萧条，今天的深圳非常繁华——新的重要 |
| 并列关系 | 没有谁更重要 | 小黄喜欢华山，小红喜欢黄山，小明喜欢嵩山——哪座山都重要，分不出主次 |

我讲题的时候有个习惯：打绿色的是不重要的，打红色的是重要的。你在做题的时候，就想想这个文段符合哪种关系，就能判断谁轻谁重。

#### 庖丁解牛：文段在你眼里是一段一段的

作为一个高手，你要达到的目的是学会庖丁解牛。一个文段在你看来，已经不是一个单纯的文段了，而是一个一个的结构——提出问题、分析问题、解决问题。我们古人说目无全牛，它在你看就不是一头完整的牛，而是一段一段的，这就是对文段理解清楚了。

再往上一层：你题做多了就会发现，常见的作用就那么些，绝大多数题目就是这些东西的排列组合。可能是已知话题加观点加举例，可能是背景加观点加举例，也可能是提出问题加分析加解说。所以学的时候，你就要把原文在脑子里翻译成这样的文段——在你脑海里面，它就应该是一个一个的骨架和结构。这是最精华的，是本质。

#### 拿一道四川真题练手

我们拿一道最新的四川真题来举例子。前面先说：在莫高窟的考古中可以找到外来的文化元素，有些宗教相互排斥，但是斗争后逐渐融合，也就和平共处、一起发展——提炼一下，强调的是莫高窟它是一起融合发展的，啥玩意都有。

然后呢，再往后面看，开始举例子：佛教和道教、儒家有斗争，也在改变，也在融合；举佛教这个典型，是说它不是单一的，是互相融合的。所以前面这一堆都在讲"融合"这件事情。如果你有基础就会发现，前面又是莫高窟，又是佛家、儒家、道家这些非常具体的东西，特别像什么？像例子。

```text
分  例/解释  莫高窟考古中可以找到外来文化元素：宗教相互排斥，
             斗争之后逐渐融合、和平共处、一起发展
             再举一例：佛教与道教、儒家有斗争，也在改变、也在融合，
             佛教不是单一的，是互相融合的
总  观  点  这些发现足以证明中华文化包容、没有排斥外来，
             而是不断吸收、不断融合                    ← 中心句
分  解  释  尾句 call back 了一下敦煌石窟，看似来了新话题，
             其实还是在说融合，观点没有变，仍是解释关系
```

这个时候注意，"这些发现足以证明中华文化包容、没有排斥外来，而是不断吸收"——这句话是什么关系？你可以把前面理解为对它的解释，它是对前面的总结、结论，这句话就是观点。

说完观点还没完，尾句又跟你 call back 了一下敦煌石窟。但你要问自己：敦煌石窟在这儿是新话题吗？它还不是在说共同融合——虽然又提到敦煌了，但依然在说融合的事情，观点没有变，那它依然是什么关系？解释关系，依然在解释你。咱俩话说的是一个意思。

所以这个题在你眼里就应该是这样的模式：前面一堆例子或者解释，中间这一句话是总结、是观点，后面这一堆又是解释。你如果非要说结构，就是分总分结构，中间这句话是重点就可以了。

这就是第一步。至于选什么答案，那是第二步、第三步的事——我现在不是让你做题，是让你明白你要干嘛：你的第一步是把这句话找到。当然答案也可以先告诉你：哪个选项跟这句话最像？"中华文明包容"——那不就 D 吗。

### 两次认知提升

#### 关联词是拐杖，不是腿

刚才那是基础，接下来进阶。第一个要打破的认知，是怎么正确看待关联词。

学过的同学多半觉得关联词很重要：老师今天不舒服，但是我还是赴约了——转折，后面是重点；今天我不舒服，所以我没有赴约——结论是我没有赴约，结论重要；老师今天我不是很舒服，我应该吃药——对策是重点。感觉关联词挺重要的，对不对？

来，打破一下三观：这些词真的有那么重要吗？答案是——有点重要，但没你想象中的那么重要，还行。

给大家一道思考：把下面几句的关联词删掉，影响句意吗？

- 今天不舒服，我还是来了
- 今天不舒服，我没来
- 今天不舒服，我吃药

本质上不影响，有没有一种思维打开的感觉？

所以我是怎么看待关联词的？它应该是初学者学习的一根拐杖。你刚开始学走路，说老师我抓一些关键词——没问题，但你不能老抓它。不能说我活了二十岁，我还拄着拐杖，不合适。

再举个反例，一个字：`而`。大家总爱问我"而"表什么，这个字有那么重要吗？它有很多的意义——"学而不思则罔"表转折；"学而时习之"是学习然后不断地练习，表顺承；"意义重大而深远"的"而"肯定不表转折，它表同时，重大同时也很深远；"青出于蓝而胜于蓝"表递进。你看，同一个字四种关系。

> **结论**：句子和句子的关系并不完全由关联词决定；关联词的存在与否，不能完全构成我们选择的依据。

这话记住了没有？张老师说过，关联词没有那么重要，它是表象，句子的内容才是本质。

#### 局部的关系不代表整体

第二个进阶：中心理解看的是句子和句子的关系，所以部分内容的关联关系不一定代表整体。因为关联词可能只是某一句话——这句话，难道是整个文段的重点吗？这就不一定了。

举个例子。这次考试老师特别提到过，看似狠心，其实难度不高。读到这儿，重点是什么？是转折之后的"难度不高"。这时候假如有个 B 项正好对应"难度不高"，你选了 B——完了，可能做错了。为什么？因为也许后面有惊喜。

再加几句话：很多同学对此表示，难道我就可以放松警惕了吗？有问有答，重在回答、重在观点。之前有同学就因为这个原因没有准备，因此没考好，所以我们还是要认真对待。

```text
局部  看似狠心，其实难度不高                 → 局部重点：难度不高（转折）
      很多同学问：难道我可以放松警惕了吗？  → 有问有答，重在回答
      之前有同学因此没准备，没考好           → 归因
整体  所以我们还是要认真对待                 → 整体重点：认真对待
```

问大家，这个时候文段重点变成什么了？从"难度不高"变成了"认真对待"。

那这个文段整体上还是个什么关系？我们从七大关系里面找。把这个文段读薄一点，分成两半：前面一半重点是难度不高，后面一半重点是"还是要认真对待"——它俩本质上是什么关系？难度不高，还是要认真对待，本质上还是一个转折关系：虽然难度不高，但是我们还是要认真对待。当然你说对策也可以，很多时候关系都是综合在一起的——转折之后起了个对策。

这块非常重要，所以大家一定要看完整。

还是拿真题来看。文段前面先给背景：现代化是多彩的、色彩纷呈的、多元的，第一部分强调的是世界是多元的。然后"从这个角度推进现代化，我们要摒弃以我为中心、唯我独尊的立场"——要摒弃，这是对策，怎么做。如果文段到这儿，"需要摒弃"就是重点。

```text
背景  现代化是多彩的、色彩纷呈的、多元的
对策  从这个角度推进现代化，要摒弃以我为中心、唯我独尊的立场
       ↓ 若文段到此为止，"需要摒弃"就是重点（选 B 就错了）
转折  遗憾的是，当今西方的一些思想家心存偏颇
指代  "这样一种理论"回指前面那些偏颇的想法
对策  我们对于西方这些偏颇的思想应该有警醒    ← 重点在这里（选 C）
```

但是你别着急，后面又给了你一个遗憾的事：当今西方的一些思想家有偏颇，我（前面）说应该摒弃以我为中心，"但是"有些人是心存偏颇的。所以这个文段从整体上来讲是个转折关系，重点就是西方的思想家存在偏颇。

如果你原题你停在这，选了 B，完了，错了呀——因为这个题的原文还没有完，到这还没有结束，你就不能停，你得看一看它整体上这个关系是不是又变了。后面怎么说？对于他们而言，西方理性主义是他们的基本立场。"这样一种理论"是不是又指代前面这些所谓的西方思想家偏颇的想法？他最后又落脚在：我们对于西方这些偏颇的主义，应该有警醒。这就又变成了对策关系——对于这些西方的偏颇思想，我们应该有警醒。所以这个时候还能选 B 吗？选 C。

所以大家发现没有：一个文段不能只读一半，你得有整体思维，要看完整。

来，第一步咱们总结一下。基本思路是文段句子有很多，你要找到那个最关键的那一个。除此之外有三个注意点：

> **提示**：怎么判断谁重要谁不重要——重点是判断句子的逻辑关系，常用的就是七类关系；对于关联词的态度——把它当作学习的拐杖，辅助我们理解，但不能完全依赖，它是表象，内容才是本质；要把文段当成一个整体——某句话单独看可能重要，整体看它又变得没那么重要。

### 第二步同义替换：找一个最像的选项

#### 大意一致即可，别追求字面一样

第一步找完了，该第二步了。什么叫同义替换？就是你要找一个最像的选项，看哪个选项跟文段的重点部分最接近，把这个东西想清楚。

第一个要点：大多数情况下，不能要求中心句和正确答案表述完全一致，大意一致即可。我有时候放题，不是让大家重做题，是为了辅助我们理解。

来看一道题。前面说"而这个行动指南要依托程序文本"，到这好像是个对策；然后"在这个意义上"又做了个总结——表总结，以后有机会我专门用一节课详细讲——你可以把它理解为一种结论：一定要搞好程序文本这个东西，它是不可或缺的、基本保障。这就是提的一个观点。

那后面在干嘛？`一方面`、`另一方面`、`此外`：

```text
观点/结论  ……行动指南要依托程序文本；在这个意义上，
           程序文本是不可或缺的基本保障          ← 中心句（总分）
解释       一方面    要吸收他们的规则（规则即程序）
解释       另一方面  不能把程序当"飞来峰"，要找到有机的统一
解释       此外      还应该构建长效化的程序
```

我就问大家：后面有没有脱离"程序重要"这个核心观点？没有。既然没脱离，它本质上就是一种解释关系——我到底怎么样去抓这个程序，我到底怎么样强调这个程序的作用。所以这个文段整体上是总分结构，或者说观点加解释说明，前面那句话是中心句，因为整个后面"一方面、另一方面、此外"三个点都是为了论证它的。

那有同学说表并列，犯了个什么错误？你不能说它完全不对，但并列只是针对后半部分。如果这个题你没有前面这一堆，从"一方面"开始，那确实表并列；但整体的并列是为了论证前面的东西，所以它是总分，是观点加解释。

还有同学问：能不能把后面当重点？其实是可以的，只是这个你们一下子接受不了。因为有时候你不能完全看文段，还得结合选项——文段和选项要一起看。你单独看文段，很多时候它有多个解释、有多种情况，这就太复杂了，我们以后会讲。你现在先把它理解为总分结构就可以了。

#### 抓大放小，先把主题词抓住

第二个要点：抓大放小。听过我课的同学应该知道这四个字。抓大放小的"大"，就是核心内容——你找选项的时候，先看选项有没有核心内容。

很多同学中心理解做不好，是因为他是一个完美主义的人。但完美主义做不好题。我举个例子：有一家机构要招一个言语老师，招了十个人，包括我在内，结果这十个人里就我会言语。这时候 HR 就不同意了：张老师这个人身高不太行啊，一米七四点儿五，我们要找那种高大帅的，一米七八以上的，影响形象。又有人说：你还是处女座，性格有点难搞，我怕不能好好共事。还有人说性格重不重要？

同学们，招了十个人，就我会言语，你管我身高怎么样，你管我颜值怎么样，你管我什么星座？这就是抓大放小——别的有些缺点没关系，重点抓住就可以。你先抓主干，不要抓那些有的没的，要把最重要的东西抓住，这才能作为答案。

那"大"是什么？大就是主题词。什么叫主题词？一个文段当中最关键的内容、必不可少的核心话题，它就是主题词。通常是核心的动名词——谁要干什么事。这玩意儿你得抓住。

#### 主题词的三个找法

那怎么找主题词？很多老师可能有不同的讲法，我归纳的就是三点。

第一，中心句的核心话题。看这道题：文段前面出现"虽然……并不禁止通行"这样的表述，转折之后说的是"网络不开放"；后两句"原因显而易见"是在解释。所以前两句是转折关系，后两句是解释关系，那谁重要？中间重要——它既有转折关系，也有解释关系，前有引入、后有解释，这就是中心句，因为这句话前面也没它重要，后面也没它重要。这是复合句。

那这句话你应该抓哪个核心词？核心动名词是"网络"和"不开放"，整个文段就围绕这两个点来讲。

原理很简单：

```text
文段（很长）
   │  第一步：找重点
   ▼
中心句 / 主旨句（一句话）
   │  第二步：提炼核心动名词
   ▼
主题词（几个词：谁要干什么事）
```

从一个文段到中心句，再到主题词，其实就是你对重点不断凝练的过程。文段这么长，变成一句话，再变成几个词，你的理解是不是越来越深刻？所以中心句通常有核心动名词，找到中心句，再从中找核心主题词。

第二，每句话都围绕着相同话题，也就是高频词。这个大家应该都知道——你看完整个文段，感觉通篇全是某一个词，那它大概率就是主题词。

第三，也是最容易被忽略的：很多时候首句引出的话题，即为文段的主题。这一点非常重要，很多同学、甚至很多老师都忽视了。来看一道 2026 年的新题，你不用管这个题选什么，这不重要，看第一句话：生态保护修复工程建设周期一般是三到五年，而高寒地区群落完成自然演替往往需要几十年乃至更长时间。

通过第一句话，你得出一个什么信息？是不是这个工程它时间很长，不是你建完了就没了。你看，文段开篇就定了一个基调：我讨论的就是这个系统，它需要的时间长。那我后面干嘛？大概率——但不是一定要——还是会围绕这个来讲。

答案就选 A，"后期"。妙不妙？你看这四个选项，什么"充分发挥"、什么"恢复"，C 项虽然带着"周期"，可我哪知道你周期是长还是短——太阳东升西落不也是周期吗？只有"后期"对应"时间长"：不是建完就没了，你后面还需要几十年乃至更长时间。所以这个题答案大概率是 A。

当然，这不是正常的做题方法，我只是告诉你们一个点：首句引出的话题，很可能就是文段讨论的主题，所以你不要忽略首句。

三个方法用哪一个？说实话，我做题的时候有时候也看感觉——文段读完之后发现好多同一个词，你大概率也会认为它是主题词。我的想法是"以一为主"：以找到中心句为主，反正你是要找的嘛；同时综合高频词和首句来判断。这是最保险的。只靠一个，有点骗自己，你综合判断一下。

#### 主题词和转折，一个管第一步一个管第二步

我们这么重视主题词，是为了帮助同义替换。所以我希望你们学知识的时候，要知道自己为什么学。

之前有同学问我：老师，主题词跟转折什么关系？朋友们，你们想想这个问题——主题词和观点是什么关系？主题词和结论是什么关系？有没有人有过这个疑问？有，而且不止一个。但凡你问出这种问题，就说明你完全不知道你为什么要学主题词。

现在讲清楚了没？转折、结论是干嘛的？是解决第一步的，是帮你找重点的。主题词是第几步的？第二步的——当你重点找到之后，我到选项里会选哪一个呢？它帮你找答案。两个的作用不一样。所以你如果只找中心句，不用找主题词；你找主题词，是为了帮你找答案。

以后不要有人再问我"老师转折和主题词是什么关系"了。一个是帮你做第一步的，一个是帮你做第二步的。

所以抓大放小，就是你要把主题词找到，因为正确答案得有它，不能没有它。一般的操作手法：先找到重点，提炼主题词、提炼核心话题，这是同义替换的依据，你必须得有它；然后选项里先找有它的，没问题就可以直接锁定，其他的排除。

#### 优先原词，也允许放大缩小

当然凡事都有例外，有一些特殊情况：主题词优先考虑原词。比如主题词是"言语"，你尽量选"言语"。但有时候选项里可能没有，那你适当扩大、缩小的替换，也并非一定错——你得对比择优，脑袋瓜得 open 一点。

我此前举过例子：文段的意思是小明很帅，用的是"帅"，那我能不能说"小明颜值高"？可以，帅替换成颜值高没问题，这就是同义替换。

题做多了，你应该对这几种常见替换有印象：文化换成文明——你说有没有区别？当然有区别，但你真正做题的时候就发现，区别没那么大；技术换成技艺，也还行；音乐换成艺术，这个就稍微有点大了，需要斟酌——但凡有"音乐"就不选"艺术"，万一非没有的话，选个"艺术"也可以。

适当扩大、缩小的替换，不是不行。选项之间永远是比出来的，不是拿满分答案比出来的。

> **承前启后**：上一节讲完「中心理解题的思路逻辑：找重点、同义替换、排除干扰」，下一节接着讲「同义替换与对比排除：三步走后两步」。

## 同义替换与对比排除：三步走后两步
> 对应块：BLK02 | 覆盖分集：P01下 | 块标题（分集名）：《01【张弓言语·十二箭】-第一讲》

先说个由头。有道题是老题了，北京的，我估摸着你们都见过：

> 残破的物体总是不美的。但偏偏有那么些古建筑、雕塑乃至日用品的"残"，整体被认为是美的。可又该如何解释呢？

拿到这种题，先别急着读选项，问自己一句：这个文段的主题词是谁？通篇就一个字——`残`。残体嘛，残破嘛，主力词找到了，那第一步就很轻松：凡是身上没有"残"的，先干掉。A 围着古建筑说，D 围着世界遗产说，两个都没带"残"，直接出局。

这时候最怕的就是一种尴尬：我看到 C 带了个"残"字，啪，直接选残。别急。B 项里有个打了引号的"废墟"——废墟是什么？不完整嘛。不完整不就是残吗？他只是换了个表达方式。所以 B、C 都带着主力词，选哪一个？

看语气。`何以`是问原因，就是"为什么"；`何为`是问"是什么事"。文段最后一句摆得很清楚："可又该如何解释呢"——这是在问为什么，不是在问是什么事。所以选 B，不能选 C。顺便说一句，那个选项只圈了"建筑"，把雕塑、日用品丢了，属于片面，只是这个问题比较小，属于基本不能选，真正判它死刑的还是语气不对。

你看，主题词这一关，就是帮你在第二步里排雷的。

### 第二步同义替换：找那个"最像"的选项

同义替换的基本思路一句话：找一个和中心句最像的选项。听着像废话，所以有三个提升点，你拿笔记一下。

第一个，不求完全一致，大意相同即可。别拿着中心句跟选项逐字对暗号，意思对上就行。

第二个，抓大放小，先大后小。大是什么？就是主题词。这里要把关系捋清楚：主题词是帮我干第二步的，跟第一步没关系。第一步找重点靠的是句子之间的关系，主题词在第二步才上场。

第三个，主题词优先考虑原词，特别是一些专业名词。这个点比较高深，以后有机会我再展开。但它并非一定是原词——有的时候可以适当地扩大，也可以适当地缩小。

> **结论**：第二步的口诀就八个字——抓大放小，先大后小。大是主题词，小是细节表述；细节可以换，主题词不能丢。

### 第三步排除：把"对比则优"变成能操作的东西

第二步讲完，就是今天最后一步：排除。其实很多时候二和三是在一起的。举个极端的例子，你发现这个题只有 B 带主题词，A、C、D 都不带，那还犹豫什么？直接选 B。所以二三常常是合起来用的。

那我为什么还要单讲第三步？因为学言语的老师嘴边都挂着一句话——"对比则优"。这话你听了就上火：老师你让我对比，我怎么对比？我就觉得 C 好啊，我对比了呀，你也不告诉我怎么对比。这就是方法论没给齐。对比要有类别、要有差异，哪些优先考虑，哪些排第二、第三，你得给我一个依据，我做题的时候才知道拿什么跟什么比。

所以对比分三类，你记住这个次序。

| 类别 | 地位 | 典型表现 |
| :--- | :--- | :--- |
| 一定不能选 | 死罪，说破天也不行 | 语义相悖、无中生有、无关对策 |
| 基本不能选 | 九成不能选，有例外但不多 | 缺少主题词、非重点、片面 |
| 对比可选 | 可以选，但没那么完美 | 主题词扩大/缩小/替换、选项不明确 |

#### 一定不能选：这是原则性问题

第一种是语义相悖。文段往东你往西，我说你是好人，你非说我是坏人，这就叫相悖。

第二种是无中生有。文段里压根没说，你愣给编出来。比如说我饿了，你说"老师你跑步去吧"——跑步解决不了饿的问题，这就叫无关对策，是第三种。

> **结论**：相悖、无中生有、无关对策，这三个属于原则性问题，是死罪。你后面讲出花来也没用。

#### 基本不能选：九成要排掉

第二种叫基本不能选。注意"基本"两个字——有例外，但不多，你当它不能选也可以，除非极个别情况，我后面会讲到。

它有三种表现。一是没有主题词或缺少主题词，一般是不行的。二是我统称为"非重点"：我们做中心理解题是找重点、找重点的句子，你把不重要的句子给我，我一般是不选的。什么是非重点？转折前的、结论前的、程度前的、中心句前面的引入/背景/问题、中心句后面的解释/举例/意义/数据，这些一般都不重要。三是片面，就是只圈了半个范围。

> **易错点**："往往"不等于"绝对"。往往是大概率，绝对是百分之一百。选项把"往往"偷换成"绝对"，或者只挑材料里的一部分说事，都属于这一类。

#### 对比可选：可以选，但没那么完美

第三种叫对比可选，就是能选，但不完美。就跟张老师一样，也能做你们老师，虽然不完美，也是老师，对吧。

表现有两个。一个是主题词的范围被适当地扩大、缩小、替换了一下。音乐换成艺术，可以；音乐换成美术，不行。只要不换错行当，词儿是可以换的。

另一个是不明确选项，话没说清楚，通常带着否定词，或者过于笼统。考完试了，我说"我要出去玩"，这也不错；但另一个选项说"我要去东北玩"，那肯定是后者更明确。可如果没有那个更明确的，"我要出去玩"就是可以次选的。

> **结论**：对比的次序是——先把"一定不能选"和"基本不能选"尽量排掉，剩下的在"对比可选"里挑更好的；真有特殊情况，再特殊考虑。

### 一道题三个选项全被判死刑

拿道题练手。先说清楚，我不是让大家做题，题目没那么重要，我是让你看清每一步在干什么。

题目问的是作者可能赞同哪个观点。文段这么说：我国在改革开放之后意识到保护民间文学的重要性，并在 1990 年著作权法里规定"另行规定"——但是，时隔 30 余年，保护办法仍未出台。到这先断一下，这是个转折，重点就是"没有出台"。

接下来还有一堆：尽管如此，我们提出过多种方案，也有个别学者主张通过公法保护，讨论涉及客体、主体、内容、期限、权利限制，但因质疑声过大而夭折。

这里我要问大家一个很重要的问题：从文段整体结构来讲，第一个转折重要，还是第二个转折重要？一定是第一个。为什么？第一个转折之后提出了观点——没出台；后面那一整坨其实没有脱离这个话题，"因质疑声过大而夭折"不正是在再次论证"你没出台"吗？你只是转了前面那一句话，整体的观点还是在给前面那句话做注脚。所以整个文段是总分结构，核心就是"没出台"。

这个题答案选 D，但它有个特殊情况：文段提问题，选项提对策。既然没出台，那就尽快出台、急需改变——这是第三节课的内容，今天不用管 D 为什么对，你只用知道 ABC 为什么错。

ABC 犯的全是原则性错误，一个都不能选：

- A 说"通过公法保护民间文学艺术是最可行的路径"。"最可行"？谁说的？文段里只说有学者主张通过公法保护，没说它最可行。你顶多说张老师是优秀的老师，不能拐弯说某个人是最优秀的——这叫绝对化，也叫无中生有。
- B 说"围绕民间文学的争议流于表面"。流于表面了吗？人家把客体、主体、内容、期限、权利限制全讨论到了，等于两个人见面把十年后的事都想清楚了，你还说人家流于表面，这叫相反，与文意相悖。我已经很详细，你说我很简略，这不打我脸吗？
- C 最搞笑。文段说"因质疑声音过大而夭折"，选项说"还要倾听多方意见"。不是哥们，我但凡专制一点，早过了。我不就是因为听外界声音听得太多，才夭折的吗？你还让我倾听多方意见——这叫无关对策，解决不了问题。你要是还听，更通不过。

这是个很典型的题：三个选项一个都不能选，一定不能选。所以你哪怕不能直接选 D，排除也能选 D。

### 非重点不选：服从群体规范那道题

再看一个"基本不能选"的典型。题干大意是：有实验证明，即使是判断一个简单任务，人们的回答也会受到他人的影响，**进而**在**没有胁迫的情况下服从群体规范**。

很多同学没看到"进而"这个词的提示。"进而"表结论，后面才是结论：没有胁迫的情况下服从群体规范。说人话就是——我没逼你，你也这样做了。

后面那一堆有没有脱离这个观点？没有。第一处，"人们为什么会服从呢？可能是源于害怕被别人孤立"——解释关系，解释部分不重要。第二处，"这个行为在动物身上也能看见，比如挪威大鼠……"——举例子，例子的本质也是一种解释关系，依然不重要。所以整个文段是总分：第一段内部是因果，整体是拿后面的内容来解释"没有胁迫也服从群体"这句话。

四个选项哪句跟它最像？既要"没有胁迫"，又要"服从"，答案直接贴你脸上了——C。

这是什么意思？你们小时候老师说"大家有问题吗？有问题的请举手"。你有问题，但你看别人都没举手，你也不举手。老师没逼你，但你还是没举，因为你要服从群体规范。就这个意思。

再看 ABD，错得整整齐齐：

- A"容易受到他人影响"——在"进而"之前，是因果里的原因一方，不重要。而且它还不明确：到底是被威胁还是没威胁？你被威胁了也受影响，别人没威胁你，你也受影响，这算什么影响？
- B"离群之马"——片面。而且记住，"往往"不是"绝对"，往往是大概率。
- D"挪威大鼠"——有同学说大鼠引出新话题。我问你，大鼠的内核变没变？大鼠忽视自己爱吃花生米，看别人吃大米它也去吃大米，选择同伴偏爱的，这不就是服从群体吗？人这样，动物也这样，这就是举例子，只是这个例子一时间没看出来而已。

A、B、D 犯了同一个错误，三个字：非重点。要么是结论前，要么是解释，要么是例子。

### 例外：什么时候例子也能当选

"基本不能选"说明什么？说明有的时候可以选。我犹豫再三还是放这道题，毕竟思维要拔高。

这道题你看文段：有个很明显的提示，叫"以干细胞抗衰老疗法为例"，后面通篇是干细胞。而中心句是个转折句——"但目前没有合法批准的抗衰老的药物"。按理说，干细胞是例子，非重点不能选。结果 A、B、D 全带干细胞，你是不是只能看 C？

C 说"从古到今，人类为了延缓衰老进行了各种尝试"。它能选吗？不能。注意感情基调：文段对"长生不老"这件事是偏消极的，觉得现在没什么药真能达到效果；而 C 的态度是积极的，是"各种尝试"。你的意思不能违背文章的意思，这叫从根上违背文段意志，一定不能选。

那只能回头在带干细胞的里面挑，B 和 D 大多数人会纠结：

- B：干细胞治疗用于延缓衰老还有很多问题。
- D：当前干细胞抗衰老研究仍处于实验阶段。

两个点解决它。第一，谁跟中心句更近？中心句是"没有通过批准"。"没有批准"不就是还在实验过程当中吗？所以 D 的"实验阶段"跟"没有批准"更接近。第二，B 和 D 是什么关系？注意，不是 D 解释 B，反过来，是 B 解释 D，是因果关系。你在 B 前面加个"因为"，在 D 前面加个"所以"：因为你还有很多问题，所以你还只是一个实验阶段。豁然大明白了吧——有果选果。

> **提示**：例子和观点在本质上意思是一样的。大家成绩都很好，比如小张就很好——小张这个例子，论证的还是"成绩很好"这个观点。所以例子选项不是原罪，只要它能表达中心句的意思，就可以选。

这道题做错没关系，它纯粹是出题老头为难你们。你看他干了件什么恶心的事：原文是"目前绝大多数抗衰老研究都还在动物的实验阶段，也尚未有合法批准的药物和疗法"，出题人把中心句拆成两半，一半留给原文，一半搬进正确答案：

```text
原文中心句：
「绝大多数抗衰老研究还在动物实验阶段，也尚未有合法批准的药物和疗法」
          │
          ├─ 后半句「尚未有合法批准」→ 留在原文，继续当中心句
          │
          └─ 前半句「还在动物实验阶段」→ 被搬进正确选项 D
```

两句话的本质是一样的：没有通过正式批准。所以干细胞这个例子按道理不能选，但除了 C 之外全带干细胞，你只能选一个。

### 次选：主题词换了词，选项没说全

第三种情况是次选——主题词适当变化、选项不明确，没有更明确的，就可以选它。

山东有道题，第一句话引出话题：影视作品凝结的不仅是创意，还有意识。按主题词原则，主题词大概是影视作品。但这个点对我没用，因为选项全都有，这题比较恶心。

接着"一方面……另一方面……"。有同学说表并列，有同学说表解释。形式上它当然是并列，但它跟第一句话是解释关系还是新旧关系？不是解释。解释的前提是你得先把观点提出来——第一句话提到"重复"了吗？没有。所以整体来看它比第一句多了一个内容，这是新观点，属于七大关系里的新旧关系。

那两方面在说什么？一方面，对经典的重复呈现非常关键，是文化的延续和确认；另一方面，用新的视听、新的时代美学、新的演员将经典重新阐释。来，告诉我，都是要对经典干嘛？重新。所以这个题你理解为分总也行，理解为并列也行，反正把两者概括起来就是"重新"。

四个选项谁有"重新"的意思？D 的"翻拍"。新的技术、新的时代美学、新的演员，翻拍不就是重新吗？有同学问非得是翻拍吗，不能是重播吗？可以是重播，但选项里没有，不用管它。A 的"生命力"、C 的"文化的关系"，跟"重新"没关系，非重点。B"对待经典影视作品的正确态度"——从对错角度它不算错，但"正确态度"到底是翻拍还是不翻拍？太大，不明确，还不如 D。

标题题也是一样，标题就是中心理解，本质上是一回事，不用纠结。这道书法课：第一句"很多高校开设的书法课被认为是辅助课程、附属课程"，引出话题，选项全有书法；接着说"书法教学成为重要的一环，未能充分发挥"——学完第三节课你就知道了，这种不好的表述用两个字概括：问题。然后讲重要性，"不仅有助于……更有助于……"——重要性讲得再多，也只是再次证明问题严重：你越重要还越不发挥，越严重。尾句给对策：汉语国际推广下的书法课应该定位于独立于语言课、技能之外的核心课程。分总，重点在尾句的对策。

第二步抓主题词：书法大家都有；抓"定位"，那就只能选 D。A 的"传播"在前面，"尴尬地位"属于问题，问题和对策之间对策更重要。但 D 好吗？你单独看它，其实也不好——你到底定什么位？话说得不完整，很模糊。可没办法，人比人，总比 ABC 离题要好一些。这种不明确选项是可以次选的。不要说"老师他不明确"——跟其他几个比，它已经非常不错了。

### 三步走全景

今天的内容，任何东西都可以忘，三步走不能忘：

```text
第一步 找重点      ──→  第二步 同义替换   ──→  第三步 排除干扰项
看句子间的关系          找与中心句最像的      三类对比，有据可依
七大关系定主次          抓大放小：大＝主题词  ① 一定不能选
并列都重要                                 ② 基本不能选
文段要看完整                                ③ 对比可选

提示：第二、三步常常合在一起用。
      例：只有 B 带主题词，A/C/D 都不带 → 直接选 B。
```

第一步，找重点。句子和句子的关系是本质，七大关系我不一一展开，你记住：绿色是非重点，红色是重点；特殊情况是并列，并列就是都重要，没有明显侧重点，"一方面……另一方面……"就是并列关系；还有一条，文段要看完整。

第二步，同义替换。找和中心句最像的选项，抓大放小，大就是主题词，它是我们的依据。怎么找、怎么判断？三个方法：中心句的核心话题、每句话的相对话题、首句的话题，以一为主，结合着二、三去判断。而且有的时候并非一定是原词，可能会适当地变化。

第三步，排除干扰项。三类摆在这儿，对比择优的时候就按这个次序来：先把第一、第二类尽量排掉，有特殊情况再特殊考虑。

这套东西讲完，你再去听别的老师的课，就可以他山之石可以攻玉：他讲的那一段，到底是第一步、第二步还是第三步？补充的是我哪块内容？很清晰，能直接纳入你自己的体系。

### 最后两道小题

#### 生产性服务业：问题后面永远跟着对策

文段前面讲生产性服务业包括很多方面，什么强、活跃、高、显著，又说国外经验表明制造业发展到一定阶段，竞争的提升更多靠现代生产性服务的支撑——到这都在讲它太重要，算背景。然后"相较而言"来了，滞后、不足、不合理，两个字送给他：问题。再往后，"推动中国制造由到大强，需要……推动生产性服务业向专业化和价值链高端延伸，更好地服务制造业发展"，"需要"表对策。所以整体是分总：引出话题＋提出问题＋解决问题，主要关系是对策。

第二步抓主题词：生产性服务业大家都有，谁也别说谁；抓怎么做——向更高端延伸。选 A。

为什么不选另外三个？D"更好地服务制造业"对应原文那句"更好地服务制造业发展"，这是对策的意义效果。你只有上岸了才有工作，工作是意义效果——需要提升才更重要，所以 D 非重点。B"涉及到众多领域"，这不就是开头那一串"很多方面"吗？非重点。C"生产性服务业和制造业的发展息息相关"，对应"制造业竞争提升要靠生产性服务业支撑"，跟中心句没关系，非重点。它们都提到了，但不好意思，我只要主角，只要这个对策。

顺便提一句，"专业化和价值链高端"在选项里被同义替换掉了；别被那个"高质量"带偏，它是形容制造业的，不是形容生产性服务业的。同义替换的尺度问题，后面还会讲。

#### 诗与情感：新旧关系一冒头就要警惕

最后一道，你不用看懂每一句，把结构弄清楚就行。

"诗源于情感，但应该超越情感"，转折。后面说超越建立在基础之上，本身包含情感元素；又说诗不能等同于一般的情感抒发和宣泄，应该有更高的使命——"更高"表强调。这里我要再次重申七大关系里的新旧关系：你读文段，读着读着突然发现"这什么玩意儿"，冒出个前文没有的东西，尤其要注意，这是新话题。前面通篇在讲情感，怎么就多了个"志"？而且是"更高的"志。所以到这，"志"重要。

然后"总之"一类的总结来了：原型是基础，志才是超越，是要求，是标准。还是在讲志——超越、要求、标准，三个词都要志。再往后开始说些有的没的：道始于情，精神的源头是情感；情感不加控制就流于欲望本能，要经过疏导才能上升为道或者理。

尾句是在告诉你什么？情感在文段里地位高不高？不加控制就流于欲望，还要经过疏导——其实没那么高。最高的是道和理。这就是文段内部的同义替换：道和理，就是"志"的同义替换，都是那个"情"之上的、偏理性的东西。道也好，礼也好，志也好，在这个文段里是一个意思。

所以结构是分总：开篇引出话题（志），中间再次强调（生怕你没看到，出题人很善良），尾句用道和理再点一遍。第二步抓大放小，主题词就是志，你按道理就该先关注 C。

为什么不选 ABD？A 的"情感"不重要，刚讲过，诗不能等同于情感。B"生活实践"无中生有，跟志有什么关系？没关系。D"诗歌应该尽可能避免抒情"——偷换概念。没说避免抒情，只是不能只抒情、不能等同于一般的情感抒发。李白怎么写诗的？"李白乘舟将欲行，忽闻岸上踏歌声。桃花潭水深千尺，不及汪伦送我情。"抒情了没有？写了。只是不能只抒情。所以 D 表达有问题，排掉，答案选 C。

至于 C 后半句"精神的传道和弘扬"，对应的是你的使命——把更高级的东西传递给别人。

> **提示**：这题如果你先看后半句，肯定选不到 C。我做题看的就是"志"，根本没看后半部分。说白了，我是在帮出题人把这个 C 项圆回来——这个选项只要有道理、没那么大的问题，就可以选。这叫抓大放小。

今天的课到这儿。明天老时间不见不散，我们讲第二讲：重视首句——重视首句的提示作用，以及正确地理解例子。这门课还有十一节课，慢慢陪伴大家，下课。

## 首句那句话不重要，那个词很重要
> 对应块：BLK03 | 覆盖分集：P02上 | 块标题（分集名）：《02.【张弓言语·十二箭】-第二讲》

### 又见面了：三类回馈，和昨晚没忘的三步

又见面了，第二节课。开讲之前先把昨天大家的回馈捡出来说一说，大概三类。

第一类同学收获特别多，悟了很多言语的道理、本质和基础——这是我最大的动力，非常感谢。

第二类同学刚接触言语，基础没那么扎实，听起来有点懵懵的。说实话现在快二月了，三月就考试，我个人的初心还是以拔高为主，这个阶段再回头补基础有点来不及。所以这类同学别着急、放宽心，一步一步来：课上这些内容多听多体会，通过做题、通过后续的听课，慢慢去啃第一节课的干货。第一节课信息量非常大，别的都可以忘掉，只要把下面这三步记住，一切都好说：

1. **读文段，找重点**——怎么找？大概七个关系；
2. **同义替换**——在选项里找一个和中心句同义替换的，特别要把握好主题，主题词非常重要；
3. **排除干扰选项的三个类型**——其中"没有主题词的基本不能选"。

第三类同学最有意思：听完觉得"不过如此"，好像跟我想的没什么区别。这让我想起《世说新语》里的一个人——那时候别人都说庄子思想好，他翻开书看了一尺，说了句"了不异人意"：跟我想的没什么差别嘛。那要恭喜你，这说明你的思路和我是同频共振的，继续坚持自己那套正确路子就行。不管是哪一类，朝着正确的方向前进就好。

> **提示**：方向正确，比"感觉听懂了"重要得多。觉得"不过如此"有两种可能——真同频，或者还没意识到自己差在哪。用题目验证，别用感觉验证。

今晚两个目标：第一个，夯实对首句作用的认识，这个点极其重要；第二个，大家见得比较多的"例子""解释"到底该怎么正确对待——它到底重要还是不重要、怎么去辨别。我们先攻第一个。

### 首句的作用：先引出话题，再展开讲

#### 为什么首句引出的话题大概率是重点

先记住一句话，最好在心里默念一遍：

> **结论**：首句的句子可能并不重要，但首句引出的那个词可能很重要。

昨天那道"影视作品"的题就是证据：第一句并没有直接点出文段的重点，但它先告诉了你"我在讲影视作品"。后文不管展开什么内容，都没有脱离影视作品这个核心话题。这句话本身不重要，它引出的那个词很重要。

原理一句话就能说清。我们做排序题的时候，哪些句子适合当首句？下定义、引出话题、背景——统统是"先把话题引出来，再围绕它讲"的路数。中心理解的逻辑和这里是同源的：先引出，再详细展开。所以首句引出的话题，很可能是重点，这就是最基本的原理。

还要有一个必要的自觉：**在读完整个文段之前，单看第一句，你判断不了它是单纯引出话题，还是提出观点**。你顶多知道"他在讲这个事、他很顽强"。到底是哪种，取决于后文。所以千万别在前两句话上就盖棺定论。

#### 例子一：巴氏芽孢杆菌——不分轻重就是并列

拿一道很新的题练手。题虽然简单，但要把原理讲明白。

文段开篇：巴氏芽孢杆菌是一种很顽强的细菌，不管有氧无氧都能生存。第一句强的点就是"顽强"。按昨天的答疑口径，读到这儿你只知道它在讲一个"很顽强"的菌，至于是引出话题还是提观点，往后看。

第二句：在无氧环境中它会形成芽孢休眠，一旦遇到有氧就能重新萌发。到这里还是在讲"有氧无氧都能活"的问题，看上去很像总分——一个观点加一串解释。

但后面忽然出现了一个新东西：它还能产生制造水泥的原料方解石。注意，"水泥"在前文里根本没出现过。你前面只说菌很顽强，水泥从哪来的？这是**新话题**。七大关系里有一条新旧关系，昨天反复强调过——新话题一定要重点关注，这堂课不能白讲。

再往后看：这东西能够存活很久，因此添加了这种细菌的混凝土建筑物，即使在出现裂痕的情况下也能自愈。读到底你会发现，不管是水泥还是混凝土，它都跟建筑有关系。

那么这是什么结构？有同学看到"因此"说是因果。整体来看，我认为这是一个**并列**。道理很简单：尾句其实并不能总结整个前文——裂痕自愈和能制造水泥是两回事。我就问大家，中间这句话和最后这句话之间分轻重吗？你能说"能制造水泥"比"能自愈"更重要吗？不分。虽然不分轻重，但都跟建筑有关系。

> **结论**：并列的本质就是不分轻重。既然不分轻重，就需要全面概括，而这个全面概括的落点是"建筑"。

可选项常常都有"建筑相关"的意思，这时候怎么办？问一句：整篇文章在讲谁？在讲"这玩意儿"——巴氏芽孢杆菌。所以含有这个主题词的选项才留下，昨天讲的第二条"没有主题词基本不能选"在这里直接判死刑。

剩下的 A"细菌"、C"细菌"、B"新材料"，不能说完全不对，但相比 D 项的"巴氏芽孢杆菌"，犯了一个**范围扩大**（或者说表述不明确）的毛病——D 更具体、更明确。所以 D 更好。

这题的谜底，第一句话就已经告诉你了。主题词在首句就出现，这个地方没注意，就容易做错。

#### 例子二：县域错位发展——尾句没说"县域"，说的还是县域

2026 年国考这道题，首句的作用更典型："对于县域而言，错位发展首先必须植根于自身的家底。"开篇就给你画了个圈——我在说谁？不是城市，不是北上广深，也不是农村，是**县域**。他谈的是错位发展，但对象锁定在县域。

到这儿，如果你能举一反三，答案其实已经出来了。当然真正做题别带保险，原理归原理，文段还得往后看完——看他有没有脱离这个话题。

后面说：要做好土特产、要挖掘本土。本土、土特产，其实是在对"植根自身"做解释、做举例，所以到这都不太重要，核心是"县域错位发展要扎根自身"。同时表并列：新的机遇窗口也得加强——还是在对县域提对策，但都没有脱离错位发展这个点。

接下来是关键句："错位发展更需要……"这里必须重点关注，因为它提示得太明显了：一个"更"表强调，一个"需"提对策。注意，中心理解一般不讲递进，递进是逻辑填空讲的东西，所以这句话是"强调+对策"的叠加，着重看它：要秉持发展眼光思维，不要怎样，更要怎样。

很多同学知道这是分总结构、知道尾句是重点，但没发现出题人玩的花样：尾句虽然提了对策、强调了错位发展，**却没有出现"县域"两个字**。难道后面说的就不是县域了吗？

看尾句的细节："主动对接国家战略区域发展""城市功能疏解""乡村振兴需要和市场前沿"。把潜台词读出来——又要疏解城市的功能，又能够满足乡村全面振兴的需要，那意味着你既不是城市，也不是乡村；卡在城市和乡村之间的，不是县域是什么？说到底，说了这一堆，强调的是你要**错位发展**，而错位的主体是**县域**。

所以抓主题词：把没有"县域"的 A、D 干掉，在 B、C 里选；两项都带"错位"，最终锁定 C。

顺便说个很多同学纠结的问题：**结构不重要**。分总、总分、分总分，这些标签只是标记中心句的位置——中心句在中间就是分总分，在尾句就是分总。你真正要回答的只有一个问题：中心句在哪。

### "新话题更重要"和"开头话题很重要"，冲突吗

有同学听前面的内容会犯嘀咕：你一会儿说开头引出的话题挺重要，一会儿又在七大关系里强调新话题比老话题重要，这不是前后矛盾吗？

不冲突。分三种情况来讲：

```text
              开头引出话题（规定整个文段的探讨范畴）
                              │
              ┌───────────────┼───────────────┐
           情况一             情况二             情况三
      围着老话题的         另提新话题，         新话题把前文
      某个角度深入讲       但没有推翻前文        终结、反驳
              │                │                   │
      开篇话题仍是重点，     类似并列结构，        新话题更重要
      答案要"回扣开头"       全面概括，一个        （三种情况里
                             都不能少             最少见）
```

#### 情况一：围着老话题的新角度深入讲

开头引出本段讨论的话题，后面没有脱离它，只是围着这个话题的某个角度继续深入讨论——比如提对策，就像刚才的县域题。这时候，开篇引出的话题仍然是重点，结合新的角度选答案即可。**这是考得最多的一种情况。**

举例：开篇说"学校是……"，这是引出话题；接着说"学校应该加大青少年的安全教育"。"安全教育"这个词相比前面是个新东西，前面没提过安全，但我讲这个观点时，并没有脱离"学校"这个大范畴。这时候，不管是开篇引出的话题，还是后面的新角度，其实都重要。

回到"影视作品"那道题：第一句话引出话题，后面讲的是"重复呈现"（也就是翻拍），没有脱离影视作品，所以答案是"经典影视作品的重复呈现"，只是把"重复呈现"换成了"翻拍"。

#### 情况二：又提了新话题，但没有推翻前面

开头引出本段讨论的话题，后面没有一直围着它讲，而是又提出了新话题，但新话题没有反驳和推翻前面的观点。这时候文段类似并列结构——几个话题之间没有轻重关系，那就都重要，全面概括，一个都不能少。

比如先说学校是什么，再说家庭是什么，再说社会是什么，那就都上来，概括一下就是并列文段。这个原理很简单，不必展开。

#### 情况三：新话题把前文终结了

开头引出话题，后面没围着它讲，而是提出新话题，并且这个新话题某种意义上结束了、反驳了、推翻了前文的话题——此时后面的新话题更重要。

比如"以前的人们认为公务员很简单，其实大家发现公务员考试很难"，后面的话题就终结了前面的观点。这种题大家应该做过，但它是三种情况里最少的。而且要特别说明：话题被完全推翻其实很少见，**多数时候话题本身没有变，变的只是相关的某个态度和观点**。

举个例子判断一下："学校是青少年聚集地，但是家庭才是青少年的栖息地。"重点是学校还是家庭？家庭——"但是"之后是重点，"家庭"作为新话题，某种意义上推翻了"学校"的重要性。但你注意：它推翻了学校，却还在围着青少年讲。这就是情况三的真实面貌：很少百分之百地推翻前文，顶多针对前面的某个部分进行反驳和推翻。

把三种情况收成两句话，默念一遍：

> **结论**：后面若出现新话题、新角度，一定值得关注；开头引出的话题，只要后面没有进行全面反驳，通常也很重要——因为它规定了一个探讨的范畴。

### 国考出题人的小习惯：答案回扣开头

情况一里还藏着一个东西，就是大家想要的"秒杀"。但先把话说清楚：所谓秒杀、所谓技巧，是建立在你对本质的理解上的；不理解本质，技巧就是花架子。

这个本质就是：**为什么很多国考出题人的习惯，是正确答案回扣开头？** 我通过后面引出重点内容之后，再 call back 一下，回扣一下开头引出的话题。从 2021 年起，几乎年年都有：

| 年份 | 开篇引出的话题 | 后文的重点 | 答案怎么构成 |
| --- | --- | --- | --- |
| 2021 | 线上教学 | 要推动社会力量参与 | 在线教育需要引入社会力量 |
| 2022 | 传统基层治理 | 后文大篇幅讲区块链 | 回到"治理"的话题，选 B |
| 2023 | 社会治理 | 众包 | 公众参与社会治理的新方式 |
| 2023 | 统一市场、全国统一大市场 | 行政分割，规模不具竞争优势 | 规模还未转化为现实优势 |
| 2024 | 消费潜力 | "特别是更好、更充分" | 认消费潜力，不认长远发展 |
| 2024 | 现代公共法律服务体系 | 公共法律服务是全面依法治国的基础 | 离不开现代公共法律服务体系 |
| 2025 | 执法权限 | 足够的执法权限是必要条件 | 选 B（话题钉在"权限"上） |
| 2025 | 企业 | 企业比高校和科研机构更敏锐 | 先干掉没有"企业"的 A、C |

逐条说说门道。

2021 年那道题：开篇引出"线上教学"，中间省略，重点是"因此要推动社会力量参与"。答案怎么构成？在线教育需要引入社会力量——在这个话题底下，没有脱离首句话题，同时把重点保留，再 call back 一下开头。

2022 年那道题当时正确率很低。文段后面全在讲区块链，很多同学就在 B、C 里纠结，还有人选"提升政府公信力"。但开篇是"在传统基层治理中……"——我们探讨的是怎么解决治理的问题，答案得 back 回治理的话题，所以选 B。顺带一提，这道题我当时说 C 不对，详情留到年后的刷题课，我会把一些非常经典的国考、联考题放进去细讲。

2023 年那道题：后面强调"众包"，答案里得有众包；可众包要干嘛？社会治理形势复杂，你还是要治理。所以答案是"公众参与社会治理的新方式"——回扣治理。

2023 年还有一道题问法很新颖："这段文字针对的主要问题是什么？"问题在转折之后：市场呈现行政分割，因此只是潜在规模大，实际规模并不具有竞争优势。两种解法。解法一用昨天讲的因果关系——"因此"之后重要，它强调的是规模不具有竞争优势，所以选 C"规模还未转化为现实优势"。解法二就是今天的原理：这个文段在讲什么？讲市场、讲统一市场体系、讲全国统一大市场，所以答案里必须有"市场"二字——"我国市场的优势还没有转化成现实优势"，选 C 而不是 A。有同学觉得"问题要从根上找"，根子是行政分割，于是纠结；但首句提示的核心话题会告诉你，出题人要的是"市场"。

2024 年有道争议题，据说不同机构答案不一样，很多同学会选 C，但我认定是 A。理由有二：其一，这道题的核心话题"现代公共法律服务体系"是一个专有词汇，"现代"两个字不能省；其二，开篇讲"公共法律服务是全面依法治国的基础"，所以答案怎么写？——离不开现代公共法律服务体系。这种答案，太符合出题人的一贯原则了。

2024 年还有一道"加强法律体系协同"的题，是我自己举的例子，讲义上没有，讲义上对应的是练习题：前面说"在数字经济时代"，答案里也有"在数字经济时代"。

2025 年那道在"执法目录"和"精准赋权"之间纠结的题，开篇一句"足够的执法权限是必要条件"就把话题钉死在"权限"上，所以选 B。同年还有一道：看完第一句"相比高校和科研机构，企业更敏锐、站在最前沿"，没有"企业"的 A、C 直接干掉，在 B、D 里再选就行。

### 拿两道题练手

讲完这些，做题会舒爽很多。来练两道。

#### 同样的研究，不同的结果

第一道：开篇"在科学研究中，同样的研究得到不同的结果，很正常，很普遍"——抛出话题：同样的研究会有不同结果。接着说，生命科学目前在实验阶段，由于各种各样的不同而得到完全不同的结果，也不意外。中间这段是在解释为什么会有不同的结果。

正中间一句是重点："如果遇到这种情况，互相指责、争论、漠不关心，都是错误且缺乏远见的。"这叫**反面提对策**，本质上是在提一个做法，是对策的一种特殊情况，后面的课程会专门讲。就像你妈妈说"再不回家就别回家了"，她其实想让你赶紧回家。所以这句真正想说的是：遇到这种不同结果的情况，不要指责、不要争论、不要漠不关心，这样是不行的。

后面"从个人事业看……误导学生的未来""对社会资源的浪费"，是在解释你为什么缺乏远见——属于解释说明。

```text
第1句   同样的研究得到不同结果，很正常          ← 引出话题
 中间   生命科学在实验阶段结果不同也不意外        ← 解释"为什么会有不同"
 对策   互相指责、争论、漠不关心是错误且缺乏远见的  ← 反面提对策（重点）
 解释   误导学生未来、浪费社会资源               ← 解释"为什么缺乏远见"
→ 分总分：前面提出问题，中间提对策，后面作说明
```

所以重点就是中间那句对策。换一个说法就是同义替换：遇到不同结果的情况，你要以某种正确的态度去对待——对应 C 项"用正确态度与方法面对学术争议"。

那 A、B、D 为什么不选？学完之后理由很简单，不用想那么复杂：我就问大家，这个文段在讨论什么话题？是不是就第一句话——在科学研究中，同样的研究得到了不同的结果？注意，是"科学研究"，不一定是生命科学。所以它讨论的一定是学术上的争议、结果不一样。四个选项里只有 C 体现"结果不同"这个争议点。选 A、B、D，说明你文都没看懂：什么"特殊"，这个词太宽泛；什么"严谨求实"；什么"实验流程"——跟"争议"有什么关系？没关系。这个题不难，慢慢理解，关键是抓住文段的话题。

#### 阿尔茨海默病：家族性与散发性

这道反而难一些，2025 年浙江题，问"主要介绍"。

开篇：阿尔茨海默病分为家族性和散发性两种，各有各的特征；前者和蛋白质的积累有关；而在更普遍的散发性阿尔茨海默症中，有毒蛋白质积累的触发机制尚不清楚。

读完这句话，得到两个信息：第一，你在讲阿尔茨海默病；第二，它分为家族性和散发性。那么根据第一句话的表述，哪个"性"会更重要一些？——散发。理由有两个：

1. "更普遍"是强调，矛头指向散发；
2. 前者（家族性）的原理我已经弄明白了——不就是和什么什么有关吗；而散发性的机制尚不清楚。也就是说，这段话是对"散发"提出了问题。

那么问题就来了：既然是对散发提出了问题，你说研究员接下来该干嘛？

## 例子与解释说明：让"非重点"替你选出答案
> 对应块：BLK04 | 覆盖分集：P02下 | 块标题（分集名）：《02.【张弓言语·十二箭】-第二讲》

### 先把上节课的两道遗留题收个尾

上节课讲完"首句引出主题"这个点，有同学当场就没兜住——你跑来问我：关于"散发"，我不清楚。我说我不清楚。

那你自己想想，我接下来会怎么写？我是不是就得解决呀，是不是得想办法弄清楚、弄明白？于是我就开始假设了，然后验证了。中间不重要，说过多少次了，因果、结果重要，中间过程不重要。结果是什么？结果表明，该系统对于什么有重要作用。反正流程就是我提出一个假设，提出这个假设的目的，就是要去搞清楚这个触发机制。

所以这道题它确实是一个分总结构，但最终的结果表明：我对这个散发性的阿尔兹海默症有了新的研究成果，我在某种意义上搞清楚了他的一些机制。答案选 D。

而如果你学过刚才讲的"首句引出主题"，这道题是不是异常简单？因为第一句话加第二句话，就是围绕着阿尔兹海默病、对于散发性的阿尔兹海默症，我不明白。那我不明白，我就要了解一下；我接下来做的这一系列工作，都在解决这个问题——到底散发是干嘛的。

到这里就听懂了。听懂了就不要再回头去看 B、C 了。你还要看 B、C，说明你没有完全接受。不用看，知道吧，不用看。

```text
首句：对散发性的阿尔兹海默症，我不明白        ← 引出主题（观点）
中段：提出假设 → 设计实验 → 验证              ← 过程，非重点
尾句：结果表明……对散发性阿尔兹海默症有新认识  ← 结果，重点
```

读图说明：分总结构的"总"在尾句，但主题词在首句就已经露出来了；首句给范围，尾句给结论，两头一夹，中间的过程段落读快一点完全不耽误做题。

### 标题即中心：主题词先砍掉两个选项

再说一道标题题。标题说过等于中心理解，第一句就是干嘛的。我在说谁呀？我在说体育文化。这是不是典型的下定义？我在说体育文化是重要的；而且随着科技革命的不断深入，体育文化他生怕你还注意不到——这个出题人贴心地给你说了两次：体育文化迎来了新的机遇。说了两次。

所以这道题大概率跟体育文化有关系。好，那等你验证一下，确实后面跟体育文化有关：数字科技带来了什么新的体育文化的平台，数字体育通过什么技术创新，不断推出数字化的体育文化产品。所以这个文段一定有体育文化。

到这一步，你甚至都不用搞清楚结构。你先把哪两个干掉？A 有没有体育文化？有。C 有没有？有。B、D 干掉。能不能干脆一点，能不能快刀斩乱麻？除非 A 有严重硬伤，否则肯定不能选 B、D。到这一步，不是说 A、C 就一定是答案之一，而是大概率是了。好，A、C 再对比一下找差异。

他俩什么差异？一个是数字技术加体育文化，一个只有体育文化。A 比 C 多了一个数字技术。数字技术重不重要？重要啊。不管是第一句的科技革命，还是后面的数字科技、数据平台、数字，这不都是数字吗？所以答案选 A。

这不就可以了吗？所以这就是建立在你对这个原理理解得很透彻的基础上。首句它不能白印出来呀。

还有同学在问 B 和 D 为啥不行。第一节课讲过没有：主题词基本不能选。这个题第一句话的"文化"两个字，它就是主题词。就好比你得招一个言语老师，你得会言语吧；这个题你得有文化吧。就这个意思。

#### 对比择优的常识：有肯德基就不吃华莱士

顺便记住一个对比的思路。文段白纸黑字（其实是白纸蓝字）都告诉你是"自动驾驶"了，你放着自动驾驶不选，非要放一个"智能技术"，应不应该？扪心自问一下，该不该这样？

就好比我更喜欢吃肯德基，你说没有肯德基了，我吃个华莱士吃一吃。你有肯德基就不吃华莱士了吗？这就是对比。咱有自动驾驶，为啥不选自动驾驶呢？很简单的道理。

> **结论**：选项之间有包含、大小、明确与笼统的关系时，永远选更贴近文段原词、更明确的那一个。

### 什么叫"解释"

这是我们第二个部分：正确地理解例子、或者说解释说明。

首先要知道什么叫解释。它就是七大关系里的解释关系。解释关系明确的直接论点，一边是观点，一边是详细的解释展开。一般情况下，越详细越展开越不重要——它是为了论证那个明确的直接的观点。前后内容保持一个一致性，而且内容详细的部分，就是对内容简略的解释。

所以解释关系有两个点，这两个点你要一起记：

```text
观点  ── 一致性 ──  解释 / 例子
（短）              （长）

短的一般就是观点，长的一般就是解释或者例子
```

- 第一个，前后意思保持一致；
- 第二个，一般解释的东西会长一点。

就这么简单。一个这么短，一个这么长，那短的一般就是观点，长的一般就是解释或者例子。越简短越是观点，一般是这样子的。

### 明显的举例标志：看到"比如"先松一口气

思维拔高一下，第一个大家都理解的：有比较明显的标志，一般是例子，例子内容一般不作为答案。什么意思？就是你但凡出现了"比如"这种明显的标志，比如、例如的，一般就可以 pass 掉，一般啊。

比如说：很多疾病与心理因素相关，比如人紧张就可能引发胃痉挛。这个时候胃痉挛、紧张就不重要，疾病和心理的关系更重要。一般是这样子的。

为什么我一直要说"一般"？凡事有例外。记不记得昨天那个题，干细胞那个题。按道理干细胞是例子，不能作为答案，但是他作为答案了。为什么那个题比较特殊？所以我说一般——言语没有绝对。

#### "比如"的范围到哪儿为止

来看那道熟悉的标题题。如今文艺工作者深入挖掘绘画、舞蹈的关系，将它们融成一体，形成新的什么表达，比如……开始举例子了。

这里我强调一下。你看到"比如"，第一反应是后面不重要，对不对？第二个问题：你能不能读到中间看到一个"比如"，后面就全部看了？行不行？不行。为什么？因为你不知道这个比如到哪为止。它可能到结尾，也可能只是到中间。

那你怎么知道它到哪为止？就看它的内容有没有变化。他比如之后还在讲具体的画和舞蹈，什么水墨入诗画，那肯定是例子；只此青绿，那肯定也是例子；千里江山图，这明显是具体的东西。所以起码到这儿是例子。

可能有争议的是尾句：这个尾句是总结还是例子之中？其实不影响你做题。有同学认为是总结，那总结的话就是总分总——因为你开头讲的也是绘画和舞蹈，尾句也是绘画舞蹈融合，意思是一样的。我更加倾向于：这些作品是对例子的总结。对例子的总结依然是例子。这是我的观点，当然你认为总分总也行。反正不管怎么理解，要么总分，要么总分总，观点是一样的：他俩怎么样融合了。舞蹈绘画融合，答案选 D。

那为什么不选别的？B 肯定不行，主题词是舞蹈、绘画。什么"青绿人在画中游"重不重要？这就是我刚才讲的，你但凡有明显的举例标志，"人在画中游"是不是例子之一，"只此青绿"是不是例子之一，直接干掉，不用犹豫。只要有一个更好的观点，直接选他就可以了。而且"跨界融合、激发艺术新活力"对应一下，替出题人圆一下，这个新活力对应的就是新的审美表达，没问题。

所以这个题：A、C 非重点例子；B 项没有主题词，排掉；答案选 D。

> **提示**：看到"比如""例如"先给后面贴一个"待定"标签，然后拿后面的内容跟观点对照——内容一旦从观点层掉到具体人、具体作品、具体数字，例子区就开始了，一直延续到话题切换为止。

#### 顺带记住的那道题：通篇讲它，它就是观点

举个例子。肠胃是一个脆弱的器官，有的人紧张就可能引发胃痉挛。这个题如果给你 A、B 两个选项，你优先选谁？有肠胃肯定选肠胃嘛。你没有他，你再考虑 B 的问题。因为他整个文段全在讲他。你说老师如果没有，那再说——因为它没有，"肠胃"本身就是观点，因为他没有一个前置的观点了，他就是观点。

整个文段都在讲一件事，那他就是观点本身。你不要因为它看起来像，它就一定是例子——不一定。这个地方明白没有？

### 没有"比如"也可能是例子：大小包含关系

第二个提升点：例子和解释前一般存在明显观点，前后思想保持一致，而且观点和例子之间大概存在大小包含关系。

这句话是承接第一点讲的。意思就是说，你并不是非得有明显的举例标志，你并不是非得"比如"一下，它才是例子。你没有比如、例如，只要你做到了思想保持一致，而且和观点有这个大小的包含关系，这也就是例子。你不用非得比如例如，不用那么死板。

比如说：很多疾病和心理因素息息相关，讲的是疾病和心理的关系。这个地方没有比如、例如吧？但是他说有的人紧张会引发胃痉挛——紧张对应心理因素，疾病对应到胃痉挛；还有的人长期抑郁——抑郁对应心理因素，食欲不振对应到疾病。它的意思跟前面保持一致，而且"疾病"是包含胃痉挛和食欲不振的，"心理因素"是包含紧张和抑郁的。那它也是一个例子。你不能说它没有比如就不是例子了。

```text
观点：很多疾病 与 心理因素 息息相关
        │              │
        ├─ 包含 ── 胃痉挛、食欲不振     （小：具体疾病）
        └─ 包含 ── 紧张、抑郁           （小：具体心理）

判断标准：思想一致 + 大小包含  →  没有"比如"也是例子
```

#### 江苏那道题：三个例子在论证第一句话

在江苏，自动驾驶已成为创新技术重塑物流的重要载体。

江苏出题人，那就得说江苏的事儿。说了个什么事呢？江苏的自动驾驶在重塑物流。那我就问大家，后面这么一堆，你就看一看它跟"自动驾驶+物流"的关系。

第一句话，智慧重型卡车、智能辅助——这就是自动驾驶，而且卡车是跟物流相关的，这就是例子。好在后面看，除了这个智慧重型卡车之外，还有什么自动驾驶集装箱卡车，也是自动驾驶加物流；还有行驶在物流园和制造企业的自动驾驶物流车，也是自动驾驶加物流。

所以后面这么一堆是不是例子？虽然它没有比如、例如，但是所有的车都是自动驾驶的，所有的运作环境都是物流相关的。那就是三个例子，三个例子就在论证第一句话的观点：在江苏，自动驾驶已成为重塑物流的重要载体。总分结构，抓住核心话题：自动驾驶加物流。答案选 C。

这个题你不用选 B、D——是不是得有自动驾驶啊？包括"物流车的智能技术应用"，这就有点太宽泛了，肯定没有自动驾驶好。你肯定在 A 和 C 里面选，因为 A 和 C 都有自动驾驶。然后再对比：A 的"应用场景"和 C 的"物流"，谁明确选谁。我讲的就是物流嘛，我没有讲别的范畴。所以选 C。

还有问 D 的。"智能技术的加持、应用范围"，同学你这个 D 问题是不是太多了？第一个，智能技术太多了——我装一个什么 GPS 是不是也是智能技术？就你得对比嘛。文段都告诉你自动驾驶了，你放着自动驾驶不选。

### 通篇都在讲它，它就不是例子而是主体

这是大家非常容易弄错的地方：若文段通篇都是某个对象，那么它可能并非例子，而是主体。

就是我整个文段全在讲这玩意儿，那就可能不是例子了。因为例子的前提是你得有观点。什么叫有关系？你不能整个问题都讲他对吧。整个文段都在讲一件事，那他就是观点本身。

#### 上海那道题：句句不提上海，句句不离上海

近代上海，不光是中国特大城市，还是外国人居住比例高的城市。

到这我知道讲上海了。那么接下来就有个问题：后面这么一堆，他再也没有出现过"上海"两个字。他在讲上海吗？大家先不用告诉我答案选谁。

我们按照刚才的逻辑讲：出题人引出上海，他是白引出的吗？他有没有可能引出上海讲湖北？感觉概率不太高。而且你在讲完第一句的时候，他讲到了上海两个特点：第一个是特大，第二个是外国人的居住比例高。

那这两个东西，是不是后面再讲的内容？你看：人口规模越大，交流机会变越多，在市场经济作用下，这必然导致分工密切，创造与创新的增长速率通常高于人口增长率。他是不是出现了一个新话题，叫创新与创造？那为什么他的创新创造能力强？因为他的人多，人多就可以分工。

所以通过第二句我们得出两个信息：第一个，有一个新话题创新；第二个，这个创新是建立在你人多的基础上。那人多就是什么？人多就是你是特大——话题没有变，本质其实没有变，他只是省略了而已。

再看第二句：城市人口抑制程度高，创新速率也大。所以他也在讲创新，而且两个应该是并列关系。但是他讲的一个人口抑制程度，这就需要你翻译翻译——什么叫人口抑制？就我俩不一样嘛，咱俩黄皮肤、白皮肤、黑皮肤嘛，这不就是对应到外国人居住比例高吗？

这就是句句不提，句句不离。我虽然后面再也没有出现上海了，但是我每句话都在讲上海。没有闲笔啊，没有闲笔。

```text
开篇：上海 = 特大城市 + 外国人居住比例高
                    │                │
                    ▼                ▼
        人口规模大 → 分工密切 → 创造与创新能力强
        人口抑制程度高 → 创新速率大
                    ▲                ▲
              （原因：人多）    （原因：外国人多）
                    └──── 并列 ────┘
                              ▼
                    结果：创造创新能力强
```

读图说明：这是并列结构，两个原因并列推出同一个结果；答案必须同时装下"人多"和"外国人多"两个原因，还要把"创新能力强"这个结果带出来。

所以这个题是一个并列结构：开篇引出上海的特点，正因为上海大，而且外国人多，所以这两个就带来了创新与创造的能力强。大和外国人多是原因，创造创新能力强是结果。

而且你整个文章都在讲上海，所以你肯定不能选 B 和 C。你光说 A 的话就片面了，而且它只是原因嘛，你得把这个果给带出来。所以答案选 D。

大家发现没有，这个 B、C 也片面了。为什么片面？B 只提到人口多，没有提到外国人多；C 只提到外国人多，没有提到人口多。外国人多和人口多，他是两码事，是两码事啊。

#### 长三角那道题：两个问题一问，答案就出来了

一样的道理。标题来看一看，开篇就说了：长三角地区知识产权创造、运用、保护等等等等，非常好。说白了就是夸你嘛。

要不说山东格局大呢，长三角跟山东好像没什么关系吧，不愧是考公大省。这自主命题就可以随便夸，你看联考就不好夸，大家一个大题库都不好夸，是不是？

那跟那个物流车一个道理。请问后面有没有脱离长三角的知识产权这个话题？虽然没有比如、例如，有脱离话题吗？没有。长三角地区知识产权优势企业很多，各种各样的一些领域，整个是知识产权运营，专利——抓住关键的词，专利融资多少多少钱，同比增长，国家级知识产权保护，知识产权纠纷调解多少多少家。这不都是知识产权吗？

所以抓住两个核心话题，这个题是一个总分结构。第一个，我在讲谁呀？我在说长三角的事。第二个，我在说长三角的什么事？我在说长三角的知识产权。

> **提示**：很多文段就是这两个问题——第一个我在讲谁，第二个我在讲他的什么。这句话很经典，我们后面讲对策类文段时还要再强调一遍。

还有同学问 C。"知识产权助力高"——哪儿哪儿哪儿的知识产权呢？是所有地方知识产权都能助力高质量吗？是所有地方的企业前景多可观吗？整个文段都在讲长三角，所以一定不能选 A 和 C。

### 例子是完成时，对策不是例子

第四个：例子一般是完成时，对策一般并非例子。

什么叫例子？例子既然想论证一个东西，他是不是得已经完成了？别说我们班成绩都很不错，比如小张就很好——那小张是不是已经考得很好了？就是例子他已经一定是已经完成了。你不能够画大饼吧，你说小张将来很好，那都不是例子。

第二个，对策一般并非例子。为什么？原理是什么？原理就是对策它还没发生。"对此的表达"——为什么一般不是例子？因为对策一般还没发生。比如我应该好好学，我学了吗？还没有。比如我们班成绩都很不错，小明你应该好好努力——那小明的"应该努力"是例子吗？他不是，为什么？他没努力呢，他没有变好呢。

```text
例句一：背诵是大道至简的。小王善于背诵，因此取得了较好的成绩。
        ↑ 观点                 ↑ 已完成 → 例子

例句二：背诵是大道至简的。作为备考公务员的同学，对关键知识点也应该善于背诵。
        ↑ 观点                                            ↑ 未发生 → 不是例子，是对策的对象
```

#### 古典名画：看起来是例子，其实是对象

我们通过题目来感受。这两个题出自同一个国考试卷，2023 年国考题，你们应该做过。

"一再强调作为经典的艺术门类，绘画并非独立发展。"告诉你绘画并非独立发展，讲绘画。然后中间说了一堆东西：什么三位一体、密不可分、互相吸收、相互依托、相互影响，之间吸收借鉴、配合结合是重要手段。中间讲了这么多，有没有脱离"并非独立发展"这个意思？没有，就一样的意思嘛。互相吸收借鉴、依托结合，这不就是要并非独立吗？咱俩得配合呀。

关键是尾句。古典名画——你看到这四个字，是不是感觉很像例子？一个"绘画"，一个"古典名画"，这不就是你说的包含关系吗？还挺像个例子。但是他怎么说的？古典名画是……很长一段时间深藏在博物馆中，名画想要活化，还需要跨界融合。

那当"还需要"这三个字出现了之后，它还是例子吗？注意这个古典名画，你如果只看到这儿，还真不能说它是一个新话题，因为古典名画跟绘画其实很接近。但是当你看到"还需要"三个字的时候，你就知道，哦，原来他是在提对策——古人就已经发现这个道理了，绘画是要互相结合、互相吸收的；那么我作为一个古典名画，我也应该吸收前人的经验、借鉴古人的经验，我也应该去跨界融合。这就是提对策。

所以答案选谁？既然提对策的话，主题词是不是就一定是古典名画？因为对策是重点，我没有针对别人提对策，我针对的是古典名画提对策。所以答案非常简单：你的答案当中一定得有古典名画，和怎么做——跨界融合。

> **易错点**：这个时候你就一定不能把古典名画当成例子排掉，因为它反而是真正想论述的观点。古典名画的作用，就相当于例句二里"作为备考公务员的同学"——它不是一个例子，而是作者想要解决问题的那个对象。

#### 京津冀那道题：一毛一样

下一道题一毛一样，没有任何区别。开篇说了高精尖产业很重要，反正到这全在讲高精尖。然后他还提到了京津冀——是不是新东西啊？新东西你不能忽略。然而转折了，转折后是重点：两地仅仅承接北京是不够的，还在围绕京津冀吗？天津、河北光承接北京这种一般的产业是不够的，迫切需要发展高精尖产业。"迫切需要"干嘛？提对策。

我完整说一遍：第一句话引出高精尖，第二句话引出京津冀。前面的作用就是我把你引出来，我要讲这两个东西。然后转折之后是重点：两地（天津加河北）承接北京不行，最后要发展高精尖。

所以还是抓住"我在说谁呀"——京津冀；"京津冀干嘛呀"——要承接高精尖产业。既要有京津冀，又要有高精尖，答案直接选 D。

这个题的京津冀，就相当于刚才那第十题的古典名画；这个题的"发展高精尖"，就相当于刚才的"跨界融合"。是不是一毛一样？所以你千万不要把这个对象当成例子排掉了。而 A、B、C 都没有这个对象——你连这个讨论的范畴都丢掉了，连个对象都丢掉了，怎么可能作为答案呢？

> **结论**：对策句出现时（"迫切需要""还需要""应当""这就必须"），它指向的那个名词短语往往不是例子，而是"对策的对象"，也就是真正的主题词。

### 例子并非没用：纠结时拿它反推观点

最后一个点：例子并非没有用，纠结时可以辅助理解观点。

很多人都知道，我强调一下：例子只是相对来讲非重点，非重点不代表没有用。它能够帮助你理解观点，因为例子和观点意思是一样的。所以当你拿不定观点到底是谁的时候，可以通过后面的例子和解释去判断一下。

#### 林徽因那道题：两个角度都指向同一个答案

比如这个题，我就告诉你第一句话是观点，因为后面都在举例子，什么林徽因呀，什么这啊那的。那么这句话他有一前一后两个分句：前半句对应的是"农业没影响"，是不是对应到 A 项；后半句对应到什么花草植物，是不是对应到 B 项。那么答案是选 A 还是选 B 呢？两个角度。

第一个角度：缘故是原因，后面就是结果。还是回到我们刚才那七大关系，原因、结果一般结果重要。所以后面花草植物的敏感更重要一些。

第二个角度：如果你说老师我判断不出来，那么整个后面都在讲谁？整个后面没有再出现"农业文明"了，都在讲花草植物。所以一定是围绕花草植物在讲。

所以选 B。

#### 传统旅游那道题：拿例子反推，反推出一个不完美的答案

最后一道题。前面先说了一个背景：传统旅游、冲动旅游。第二句话"这就要求"——是不是提对策？"这就"提什么对策呢？他讲了一个非常长的话。前半句说你要向消费场景过渡，后半句说你要提高你的服务能力。这就有点纠结了：我到底是我前面的这个向消费场景过渡重要，还是你这个软性硬件的服务能力重要？

这也导致你会在 C 和 D 里纠结：C 这个"消费新业态"可能对应到前半句，D 这个"服务升级"可能对应到后半句。其实 A 和 B 你不太纠结——需求日益多样，对应到前面北方有北方的冬季需求、夏季有需求，它不是一个对策，你提对策"这就要求"嘛；B 项"价值有待进一步挖掘"这个表述也很不明确。所以 A、B 不纠结，主要纠结 C 和 D。

那 C 和 D 纠结没关系，你看后面怎么说。后面他再讲消费场景的过渡，还是服务能力的提升？这个例子是怎么解释的呀——因需求旺盛，提升了以游客为导向的服务能级，服务更加主动热情有活力。那它就提升了哦。所以我在讲什么？我在讲服务。这个题答案应该选服务相关的，一定是服务要升级优化，答案选 D。

但是这个题的答案它也不完美。很多同学当时把这个题的主题词当成了"传统旅游"，因为它是传统旅游城市，就可能把 D 干掉了，就在 C 里面选了。我当年也是这样想的。所以这个题最完美的答案，应该是把 D 的"城市"改为"传统旅游城市"。

但是回到我们昨天的考点：他把"传统旅游城市"扩大成"城市"，它不好，但是算不算错？注意，我们昨天讲过，主题词可以适当地扩大、缩小。虽然"城市"肯定不好，我很想选传统旅游城市，但是 C 我不能选呀——你 C 讲的是开发消费新业态，你跟文段的重点没关系，文段的重点不是消费新业态，而是要服务，要升级一下。

所以只能勉强地接受：把传统旅游城市稍微扩大成城市，至少没有脱离大的范畴。一定要对比择优。

### 收个尾，说明天见

今天这一波三折，大家有收获就可以。关于例子和解释这五个提升点，拢总再过一遍：

| 提升点 | 判断标准 | 做题动作 |
| :--- | :--- | :--- |
| 明显的举例标志 | 出现"比如""例如"等标志 | 后面内容一般 pass，不当答案 |
| 无标志也可能是例子 | 思想一致 + 大小包含关系 | 拿观点与细节对照，不死板找"比如" |
| 通篇都是某个对象 | 全文只讲它，没有前置观点 | 它是主体本身，不是例子 |
| 时态判别 | 例子是完成时，对策尚未发生 | 出现"迫切需要""还需要"等，找对策的对象 |
| 例子并非没用 | 例子与观点意思一致 | 纠结时用例子反推观点到底在讲谁 |

## 对策类文段：优选对策，内容为王
> 对应块：BLK05 | 覆盖分集：P03上 | 块标题（分集名）：《03.【张弓言语·十二箭】-第三讲》

上课之前先唠一件事。大家实在太热情了，不管在上课当中还是下课之后，很多同学都给我发问题、回复我，说老师这个知识点或者这道题有点不太理解，或者"你虽然讲得很好，但我在某些地方还是有一些问题"。有没有这样的情况？有的话咱打个有。

这个时候大家可以怎么样呢？积极地在我各个直播账号底下去评论、去回复。因为我今天其实看到大家的一些评论，我觉得有些问题非常有价值、非常有代表性——不是你有这样的问题，是大家都有这样的问题。所以咱们集思广益，共同把这个事做好。这课程虽然我准备得比较充分，但还是可能会有遗漏的地方，大家心往一处想、劲往一处使，这个课程就会做得更好一些。咱们互相帮助，好不好。

下面正式进入今天的内容。

### 先把昨天的两个点拾起来

昨天主要讲两个点，今天讲第三讲，都是连着的，先花几分钟把它夯实一下。没听到昨天的课，记得去小破站补一下。

#### 首句到底干什么用

首句的作用是提示核心话题。核心话题就是主题词，而主题词对你选到答案非常关键，所以对首句一定要重视起来。其实大家平时更重视尾句一些，但首句也很重要，就是这个意思。

不过要注意：并不是说一个文段只有首句引出的话题重要。后面可能还会引出一些新的东西，这时候分三种情况。

| 后面的走向 | 重点在哪 |
| :--- | :--- |
| 围绕首句话题的某个角度讲 | 话题和角度都重要 |
| 后面讲的好几个话题一样重要 | 并列关系，话题并列都重要 |
| 后面的话题反驳、推翻了前面 | 前面那个可能就没那么重要 |

#### 例子和解说词，本质上是一回事

例子也好、解说词也好，它俩本质上是一样的，都是为了论证观点。昨天讲了五个要点：

| 要点 | 内容 |
| :--- | :--- |
| 有标志的 | 有标志的一般是例子，一般不作为答案 |
| 标志不是唯一判据 | 例子、解释前一般有明确的观点，前后思想保持一致，且一般存在大小包含关系——所以并不是非得有标志才是例子 |
| 通篇都是对象 | 那就不是例子，比如昨天的上海和长三角，它就不是例子 |
| 时态差别 | 例子一般是完成时（已经发生的事），对策一般并非例子——因为例子的本质是已经发生的事情去论证一个观点 |
| 也不是全无用处 | 纠结的时候可以辅助理解观点 |

> **提示**：例子和解释不是拿来当答案的，但纠结的时候它能帮你确认观点是什么。

### 对策类文段：先把它跟"只有才""必要条件"掰清楚

先表个态：对策类文段是我们公考言语的必考点。你但凡考言语，不管去哪个地方考，它都是必考的，非常非常重要。

什么叫对策的文段呢？我自己下了个定义：**考察对策的文段就叫对策的文段**。就是这个题目跟对策有关系，中心理解题它跟对策有关系的，这就叫对策类文段。

#### 三个概念在言语里是全等的

很多同学，特别是刚刚开始学的同学，这三个东西分不太清楚：只有才、必要条件、对策。它三个有什么关系呢？老师给一句话：

> **定义**：在言语的中心理解中，表达意思的时候，必要条件等于对策，等于只有才，等于"要"。它们三个是全等关系。

举例子就明白了：付出是取得回报的必要条件，就等于"只有付出才能有回报"——只有才就是必要条件嘛；也等于"想要回报就应该付出"——"应该"就是对策。所以三者是全等关系。

但是这个地方有三个限定语，一定要注意。

第一个限定：**只在言语中谈**。有同学说，老师我知道，必要条件后推前，充分条件前推后，我学得很好——出门左拐，这不是一家人。咱们说言语就说言语的话，说判断就说判断的话。这玩意在言语中跟前后没有关系，你那是知识学杂了。

第二个限定：**在中心理解当中，只有才就是对策，并不绝对**。有同学一看到"只有才"就反感，觉得表述太绝对。但我限定了一个范围：在中心理解中，只有才它就是对策。只有在别的题型里才可能有绝对化的嫌疑——比如我们在第五节课会讲的细节判断题，在那个题型当中如果出现"只有才"，确实有可能绝对化，比如"只有进士才能当宰相"，这话就说得有点绝对了。

所以同一个"只有才"，在不同题型、不同科目里，咱们对待的方式是不一样的：在中心理解就叫对策，在细节判断它可能就比较绝对。

第三个限定：**对策是重点，对策优先选**。对策的重要性比问题重要，比意义效果重要，比解释重要，比原因重要。其实你也不用记那么复杂，简而言之四个字：

> **结论**：优选对策。站在整体框架结构上来讲，文段但凡出现对策，它的重要性一定是最重要的。

所以七大关系里头的这个对策，大家一定要去留心，首先有个初步的印象：它非常的关键。

### 对策的三种考察形式

这部分是比较基础的内容，理论其实并不难，稍微一过你们就能想起来。

| 形式 | 识别方式 | 处理 |
| :--- | :--- | :--- |
| 直接提对策 | 对策标志词引导，文段正面提对策 | 直接抓标志词后面的内容（考得最多） |
| 间接提对策 | 假设的做法 + 不好的结果 | 把做法反过来即为对的 |
| 文段提问题 | 消极表述：挑战、瓶颈、软肋、难题、不足、缺陷、风险 | 选项给对策时，优选有针对性、能解决问题的 |

#### 直接提对策：考得最多的一种

别看老师把对策分了这么多情况，第一种情况是考得最多的——绝大部分题目就是直接告诉你应该怎么做，没有那么多弯弯绕绕，没有那么花里胡哨。所以这种最高频的考法一定要注意：我直接通过对策标志词引导，文段正面提对策。

那什么叫对策标志词呢？可能有的老师会让你记一大堆词，`应该`、`需要`、`必须`、`急需`、`亟待`，怎么怎么样。其实我觉得大家不要死记硬背，把它分成两种情况记就行：

- **能够表达"做、行动"这个意思的，都是对策。** 比如说这个事情势在必行——它没有用"应该"，但它也是对策，因为势在必行就是你赶紧得做、你必须得做了。
- **能够解决问题的就是对策**，甚至不需要"应该"这种引导词。比如说今天的雨下得好大，我都快淋湿了，另外一个人说"我带了一把伞"——带伞某种意义上它就可以是一个对策，因为带伞能解决你被淋湿的问题。他只要能把问题解决掉，它就叫对策。

举个例子：面对消费疲软的问题，我们需要加大人民群众的财产性收入。这时候重点就是`需要`引导的对策：加大人民群众的财产性收入。

再 call back 一下昨天的那道古典名画题——尾句说"名画想要活化，还需要跨界融合"，所以答案选的是 C，那就是典型的文段直接提对策。

#### 间接提对策：绕个弯，从反面说

它的格式就是**假设的做法 + 不好的结果**。这玩意看起来很虚，反正咱们记例子就可以了，做法反过来即为对的。

还是那个例子，换一种说法：咱们不直接说，绕个弯——"如果我们不加大财产性收入，消费疲软的问题就不能有效解决"。是不是对策？也是对策。它虽然没有那么直接，但表达的就是这个意思。

这个地方我经常举例子：就好比你们小时候，你妈妈跟你说"如果你再不回家，你就别回家了"，或者说"如果你再不好好学，你就出去"。什么意思？假设的做法——`如果`、`倘若`，加上不好的结果——意思就是你赶紧得回家嘛，你赶紧得好好学嘛。这就是用反面的方式提对策，它其实也是对策。

这就好比昨天那道题："如果遇到互相指责、漠不关心、争论，那都是错误的。"所以答案是要有正确的态度。它的意思就是你加个"不"字嘛：不能互相指责，不能争论，不能漠不关心——把这些概括一下，就是不能以错误的方式去对待学术争议，那换一种说法就是正确的态度。应该不太难理解。

#### 文段只提问题，选项给对策

什么叫问题？我也去下个定义：

> **定义**：很多时候我们说的问题，就是一些消极的、不好的东西——挑战、瓶颈、软肋、难题、不足、缺陷、风险，这种消极的表述就叫问题。

这个时候怎么办？**优选有针对性能解决问题的对策**；如果选项没有，则退而求其次选问题。

有同学会有疑问：老师，文段都没说怎么做，你就这么突兀地给对策，难道不叫无中生有吗？文的没说你要这样做呀，我只是提问题而已啊。

这个时候我就想举个例子。就好比你是哪个领导的秘书，领导跟你说："小张，最近这个交通很拥挤。"你说："对对对，很拥挤很拥挤。"又过了一天，领导跟你说："小张，最近这个物价上涨得很厉害。"你说："对对对，很厉害很厉害。"——你这不就是复读机吗？他要的肯定不是这个。我把问题给你，是你自己没点眼力劲嘛，我是让你解决问题的。

所以我们作为一个公务员考试，他考这个跟大家答面试一样，他大概率（不是一定）的初心是想让你解决问题。所以你但凡有针对性的、能够解决问题的对策，都要优先考虑；如果实在没有，那也不能逼着我选呀，这时候可以退而求其次选问题。

拿这道题问大家：人民群众财产性收入偏弱，影响了我国居民消费能力。A 是增加人民群众财产性收入，B 是人民群众财产性收入偏弱，C 是增加人民群众的劳动性收入。选哪个？

**有 A 选 A，没有 A 选 B。** A 就是能够针对性地解决问题，而 B 就是对问题的概括，B 没有 A 好。C 能不能选？一定不行——虽然它是对策，但它是劳动性收入，这个解决不了问题。所以对策题不能乱给，你得有针对性，得匹配，得契合。无关对策对不上，白搭。

再比如我们第一节课的那道题：不是说时隔 30 余年，保护办法仍未出台吗？看答案——"保护缺位状态急需改变"，它就是一个针对问题提对策。

### 拔高：选对策不是选"需要"两个字

讲完基础知识点，进入思维的拔高部分。这个问题很多同学学了好长时间都没搞明白，问我的人很多，所以我特意把它摘出来当成一个重点去讲。

> **结论**：选项选对策，并不是选包含`需要`这类标志词的选项，而是选涉及对策内容的选项。

有同学就记住"老师优选对策、老师需要就是对策"，那我就选"需要"呗——他是这样想问题的。举个例子：这次考试对我们来说非常重要，我们应该加倍努力。

单看文段，重点肯定是后面`应该`引导的对策：加倍努力。但"内容"指的是什么？指的是你到底具体怎么做，这个具体的东西、具体的内容。你不能给我一个"你应该嘛"——你应该干嘛呢？你得把干嘛说清楚，这才叫内容。

所以 A 和 B 选哪一个？选 B。为什么？**内容为王**。你选答案不是看中了"应该"两个字，"应该"只是帮你提示提示重点的地方，它还是让你把这个内容给看出来——哦，是要努力。所以努力很重要，努力才是主题词。

```text
   这次考试非常重要，我们应该加倍努力
                │
                ├── 形式：应该（引导词，只负责提示重点的位置）
                └── 内容：加倍努力（真正要选的，主题词）

   只有"应该"          → 形式上是对策，内容空洞，不选
   只有"努力"          → 有内容，没引导词，选它（内容为王）
   "应该" + "努力"     → 内容与形式都满足，完美答案
```

那么，如果内容和对策形式都存在呢？优先考虑形式上是对策的答案，这就是对比择优。还是这个文段，A 和 B 都有"努力"，咱都有这个主题词，谁也别说谁，这时候优选形式上是对策的那个。内容和形式两者都满足，那是完美答案；但如果只能选一个，一定要选内容。

### 两道江苏真题：形式像对策，不等于就是答案

#### 獬豸题：开头讲动物，讲的其实是公平正义

先说这两个字怎么读：獬（xiè）豸（zhì）。经常逛小破站的同学应该听过一句名言——"一群獬豸怎么能治理好国家呢"。獬豸是我国古代的法兽，能辨是非曲直。那他为什么要讲獬豸呢？这不可能这么无聊，不可能只讲一个动物，他肯定是为了引出某个东西。

什么东西？看到獬豸的雕像，象征着对公平正义的守护。来，但凡你昨天学好了，你就应该知道：第一句话它相当于引出什么话题？它看上去虽然引出的是獬豸，但它真正引出的是**公平正义**，因为獬豸是公平正义的化身。所以这个题大概率答案有谁？有公平正义。当然这只是第一句的猜测，咱们在现场往后看——公平正义是灵魂、是尺子，那不就是强调很重要吗，你能没有灵魂吗？再往后，推进全面依法治国，要紧紧围绕着保障社会公平正义进行，要把这一价值追求贯穿到什么全过程。

> **易错点**：在中心理解里看到指代词，一定要弄清楚它指代的对象。"这一价值追求"指的是公平正义。

所以这个题是分总结构，尾句就是重点，那句`要`就是划重点。我当时做的时候抓两个词：第一个是公平正义；第二个是，你不管是什么法，立法、执法、司法、守法，你肯定跟法有关系。所以这个题对我而言就是：谁要公平正义？法要公平正义。既要有法又要有公平正义，那就选 D——公平正义是法治的生命线。

D 的表述看上去好像没有"应该"，但是什么叫生命线？生命线其实就相当于必要条件、必须得有的东西。意思就是说法治必须、需要公平和正义，是不是很通透。

再看其他选项。A 项讲獬豸，直接干掉。C 项是易错项，"法治建设要贯穿法治全过程"——为什么大家会选 C？因为 C 看起来就是比别的答案更像对策。但是，那又如何呢？你再怎么像对策，你没有内容啊。法治和法治的关系不重要，因为我要的是公平正义。所以你再怎么"要"也没用，这是形式，形式没有用。最后 B 项叫"片面司法公平"，别人是立法、执法、司法、守法，B 表述片面，肯定就不太好。答案选 D。

#### 何尊铭文题：每个选项都够格，放一起才分高下

看文段：何尊的铭文……然后再介绍这个铭文。这里有一个考试技巧：

> **提示**：你看不懂的部分，可以不用太仔细看。很多时候看不懂的其实不重要，知道大概有个印象就可以了。

然后出现`表明`——`表明`、`表明`，你可以看，它表一个结果：德政这一政治理念业已出现，为我们理解中国政治传统提供了有益启示。读到这儿你要慢慢有这种感觉：只看了第一句话，你其实不太知道谁重要，可能重点是政治。读的时候要有这种猜测的感觉，但后面看好像不是——重点是**铭文**，因为后面讲的是不同时期青铜器之间怎么怎么样，要分析、重建、产地溯源，亟待破解的青铜密码还有很多。

"亟待破解的还有很多"相当于干嘛？相当于很多问题我还没有解决，两个字送给他：问题。有问题就需要提对策——我们要拓宽视野，运用多种研究方法手段进行综合的分析，进一步推动相关学科发展。干嘛呀？要研究分析。

所以这个题结构非常简单：开篇引出何尊的铭文（青铜器），他其实目的不是为了引出政治，他只是在讲青铜器的作用；引出铭文之后中间提问题；有问题就需要提对策，要多研究、多科研、多分析。分总结构。

我说一个暴论（不是悖论啊）：这个题从严说、手放松一点，每一个选项都可以成为答案。它们都够格，因为它们都点出了文段的主题——这个文段在讲青铜器，讲的又是它需要进一步的分析和研究，大的方向都是对的。当然这是我的想法，是我的一家之言，你们能接受就接受，不能接受我也不强求，因为有的题的答案它本来就不完美。但是当你把这四个选项放在一起，高下就立判了：

- B 项`亟待`是一个明显的对策表述；
- "研究领域广阔"是一个客观事实，它不是做法；
- "有益于""很重要"相当于什么？相当于意义效果——我们刚学过，意义效果肯定没有对策重要。

所以这个题你真正做的时候其实不纠结，选 B。注意 C 和 D 也有"研究""发现"，所以这个题跟上题不一样，它从内容上讲大家都有青铜器、也都有研究，大的方向都对，**重点就在形式上**——有内容就看形式。而`亟待`就是"需要"的意思。

### 对策类文段的命门：抓对策加对象

这个东西非常关键。你有了它，就知道做对策文段的大致方向：只要这个文段跟对策有关系，你应该抓的主题词就是**对策加对象**。

什么叫对策？就是你到底怎么做、具体的方式方法，这叫对策。什么叫对象？不是处对象那个对象——这个对象是谁去做，或者说为了谁去做。用语法来讲的话（虽然我不太擅长），你可以把对策理解为谓语、谓语动词，把对象理解为主语和宾语。所以我说核心话题要抓核心的主谓宾嘛。

| 做过的题 | 对策（怎么做） | 对象（谁做 / 为了谁） |
| :--- | :--- | :--- |
| 昨天那道学术争议 | 用正确的态度 | 学术争议 |
| 县域经济 | 把握错位 | 县域经济 |
| 獬豸那道题 | 要公平正义 | 法治 |
| 何尊铭文这道题 | 研究、分析 | 青铜器 |

你看，很多对策类的题都是这样出的：谁在干什么事情，或者说为了谁要去干一件什么事情。所以一定要抓对策和对象。

那它的本质是什么？把第二节课的知识点结合进来，道理都是通的——有没有一种脑袋天灵盖被掀起来的感觉？**对策和对象的本质，就是第二节课讲的主题词。** 对象就是文段很可能在首句就引出来的那个大的话题和范畴；对策呢，就是这个话题之下的某个角度。都串起来了。

所以你以后抓主题词，特别是对策的文段，就抓对策和对象，80% 的题都是这样的。当然不是每个题都全给，但他顶多会给你一个——至少会给你一个。

如果出题人比较"恶心"呢？A 项给你一个对策，B 项给你一个对象，AB 选哪一个？按我的经验，这个时候出题人会玩一种套路：他会让这两个选项当中的某一个变得不好。本来两个选项已经不完美了，他为了让你选出答案，会让其中一个另外有严重的问题，让你尽量不会无法抉择。只要是负责任的出题人，一般会在某种情况下帮你规避这个问题——要么两个都给你，要么给你一个，但尽量让你在别的选项上有明显的排除理由。只给你一个就已经很坏了，别以为都给你就很好，都给你你也不一定做得出来，很多题在别的方向设坑。

### 拿两道题练手

#### 传统文博展示：对象已经"分配"好了

传统文博展示，首句大概跟这个有关系。但这个题其实不需要我们操心这个事——为什么？因为别人已经帮你把对象在题干当中拎出来了，提示你了。所以这个题相当于把对象给你了，"国家分配对象了"，你得感恩一下是不是，然后你就找对策就行了：到底要怎么地？

看结构：开篇说受各种限制，很难满足——这是问题。`为此`引导对策：可善用纸媒、人工智能、虚拟现实等先进技术，搭建平台、运用新技术。然后`比如`，举例。分总分结构，已经不能再清楚了。

所以对策是谁？对策是技术。怎么办？**抓大放小。** 你需要纠结什么空间、文物、智慧、历史吗？对主题词保持该有的尊重——我不管你说什么，我就看谁有"技术"，A 有，选 A。当然你可能会在 C 上稍微纠结一下，那个"媒体"，但是文段好像也没怎么讲媒体啊，人家是虚拟现实和人工智能，所以排掉，选 A。

#### 智慧治理：从甲到乙，转向的那一方才重要

这道题的题型是：假如这是篇文章的摘要，那么这篇文章的标题可能是什么？摘要加标题叫中心理解——摘要就是主要内容嘛。如果这个摘要变成了序言、前言、引言这种东西，那它就是下文选择了，这个我们以后会讲到。他只是摘要的话，还是中心理解。

看文段：随着大数据、物联网、云计算等这些技术的发展，人类社会进入了智慧治理时代。我讲的内容还在 C 啊——不是选项 C，是 carry 那个 C，你们不打游戏吗，就是稳、到位的意思。这个题他肯定跟智慧治理有关系，所以你看每一个答案当中都有智慧治理，相当于也是把对象给你了。你只需要搞清楚对策是谁就可以了。

中间说智慧治理很重要，但是呢——有些人低下、不足、隐患、不够、过度依赖，导致什么风险、困境。两个字送给他：问题。做题做多了就知道，就这些东西。那么解决问题需要实现从人工智能技术赋能到技术融合的转变，而这些又是实现转变的重要路径。

这个题尾句肯定是重点：第一句引出话题，一般不重要；第二句是问题，一般不重要；尾句是对策，是重点。那就需要好好理解一下这句话——他给你提的对策就是：你得转一下。

那么从甲到乙、从前者到后者，是甲重要还是乙重要？**转向的那一方（后者）更重要。**

```text
   从「人工智能技术赋能」 ──────转变──────▶ 「技术融合」
        甲（起点）                          乙（终点）
     如果甲真的够棒                           转向的那一方
     就不需要转了                        ←──── 重点在这里
     正因为不行，才要转                     后文的融合过程、融合目标
                                              都在对它展开
```

原理是这样的：如果前面这个真的那么棒棒的话，你就不需要转了。你们要知其然，知其所以然——正是因为你不行，才需要转呀。给你机会你不中用，你才需要转；你行我就不转了呀。举个例子：从被动学习到主动学习的转变，主动学习是后者，肯定是主动学习更重要。

所以一定是技术融合，而且后面融合过程、融合目标都在对这个融合进行展开。告诉我，对策是什么？做法是什么？我作为一个智慧治理，到底要干嘛？四个字：**技术融合**。所以 A 项"迈向技术融合、对向智慧治理"，短短一个 A 项对策，非常全面。这个题正确率其实不高，大概只有一半——其实很简单，对策对象抓精准就不会做错。

B 和 D 排掉，希望大家不要问为什么不选 B、D，很简单：问题表述非重点。易错项是 C，原因跟刚才那道题很像——C 比 A 多了一个"治理的路径"，又看到尾句有一个"路径"，又看到一个"治理"，就感觉这个 C 特别像对策。两个理由：

1. 刚才我们分析过了，智能技术赋能到底重不重要？不重要。所以你如果选 C，说明你根本就分不清轻重；
2. 其实 C 项犯了一个**偷换概念**的错误。文段的意思是"实现从甲到乙的转变"，这些是**实现转变的路径**；而 C 的意思是"甲的路径"。换一组词来说：文段的意思是我要实现从甲到乙的转变，那我告诉你甲和乙的转变路径是什么；而 C 的意思是我甲的路径是什么。这个点大家一定要想明白。

> **承前启后**：上一节讲完「对策类文段：优选对策，内容为王」，下一节接着讲「对策类文段：宏观之后的具体对策，与何时不选对策」。

## 对策类文段：宏观之后的具体对策，与何时不选对策
> 对应块：BLK06 | 覆盖分集：P03下 | 块标题（分集名）：《03.【张弓言语·十二箭】-第三讲》

先把上一道题收个尾。有同学纠结某个选项为什么不能选——我不需要实现甲的路径，我需要的是从甲到乙的这个过程的路径，所以 C 他一定不对，怎么看都不对。当时有人喊"对象不对"，绕了一圈才发现，对象其实是有的，不对的是**对策**。这道题翻篇。

接下来这块有点复杂，建议大家洗把脸、清醒一下——就像当年决赛二比二平，得洗把脸才能打回来。因为我们要讨论的是：**对策之后，可能出现更加具体的对策。**

此时是前面的对策重要，还是后面的对策重要？先给结论：都有可能。答案可能是第一句，也可能是第二句。这就是言语灵活的地方。裂开没关系，下面一层一层捋。

> **提示**：对策类文段是行测言语里的必考考点，而"宏观对策＋具体对策"是它里面最灵活、最容易让人三观裂开的一类。

### 情况一：宏观对策之后，围绕具体的多方面展开

#### 先建立感觉：学英语的那两句话

举个例子。

> 第一句：我们应该努力学英语。
> 第二句：掌握一定词汇量是学习英语的基础，还要把握句子关联。

问：是第一句"学言语"重要，还是第二句"掌握词汇量"重要？

再换一个版本。

> 第一句：我们应该努力学英语。
> 第二句：掌握一定词汇量是基础，还要把握关联。

问：这次谁重要？

有人连着打了三个点——因为两个例子的答案可能不一样。不是"都重要"，是**都有可能**：答案可能是第一句，也可能是第二句。

先回顾我们在讨论什么：前面有了一个宏观对策，宏观对策之后不是并列，是这个宏观对策底下出现了具体的对策。"掌握词汇量"相比于"学英语"来讲，是不是一个更加具体的对策？对。所以宏观重要还是具体重要？都有可能。有同学说"对策要具体"，有道理，但不全面，听我说完。

#### 第一种形态：后面是并列的好几个具体对策

提出宏观对策之后，后面围绕具体的多方面展开，就像上面第二版例子：

```text
宏观对策：我们应该努力学英语
   ├─ 具体对策一：掌握一定词汇量是基础
   └─ 具体对策二：把握句子的关联
两个具体对策并列，解释"如何学英语"
```

这种情况，**前面的宏观对策**和**对后面各方面的概括**，均能作为答案。到底选哪一个？根据选项来定。

一个题不是只有文段，而是文段加选项，你得考虑出题人的意见。假设这个题有 A，把前面的宏观对策同义替换一下，我可以选 A；有 B，把后面的具体方面概括一下，我也能选 B。这两个都可以选，但他一般不会都给你——只给你一个。放心，一般不会都给你。

#### 回到第一节课那道例三

第一节课讲过的例三，当时就有同学想到了这一层，问题是这样的：

中心句是"科学、民主的程序文本是不可或缺的基本保证"，这是提出观点；后面"一方面……另一方面……此外……"当时说的是解释。那学生就问了：一方面可以借鉴他山之石，另一方面需要扎根实际，此外还应当建立相应的机制、夯实程序之基——老师，这不是你说的对策吗？按你的讲法，对策重要，那我是不是应该把后面当成重点，把后面的对策概括一下当作答案？

问得非常好。看一看那道题的答案项——"以程序内容之基筑牢……"，这个"内容之基"是哪儿来的？其实就是对这个对策的概括。

所以这个选项有两种理解，**两种都对**：

- 把它理解为第一句话的同义替换，没问题；
- 把它理解为对后面三个对策的概括，也没问题。

为什么？你看：为什么要借鉴他山之石？为什么要扎根实际？为什么不能简单？为什么应当建立相应的机制、夯实程序之基？"一方面""另一方面""此外"这一串，不就是在告诉你——我怎么样去把握这个程序的内容之基吗？

所以言语有多种理解方式：你既可以把它当成解释，也可以把它当成更加具体的对策。**两种理解不影响你选答案，因为两种都能选对。**

#### 适老化改造：一题两做，条条通罗马

再上一道非常经典的题。

> 要推动老旧小区的适老化改造和无障碍环境建设，关键是提升思想认识，实现适老化改造的心理无障碍。

开篇就给你提了个对策。讨论的话题是适老化改造——所以你看，每个答案当中都有"适老化改造"；而"我要怎么做"也给了你：实现心理无障碍。前面那个"思想认识"也是一个意思，都是心理上、观念上的一种无障碍。

后面在干嘛？说要通过多渠道转变他们的认知。转变认知，某种意义上就是在干嘛？在心理改造。可以理解为解释，也可以理解为具体对策。"同时"之后又表明，要通过各种各样的方式转变观念、养成这样的意识、提升主观能动性——还是在心理无障碍，还是转变你的大脑认知。

所以这道题可以像例三一样，**当成总分结构做**：

```text
中心句（对策＋对象）：推动老旧小区适老化改造……
                      关键是实现"心理无障碍"
   ├─ 多渠道转变认知               → 心理改造
   └─ 同时引导：打造样板房、
      强化直观感受                 → 宣传引导
总分结构先抓主题、抓中心句，扣住"心理无障碍"
```

先抓主题，抓中心句——第一句话，抓住"心理无障碍"，选到 D 是没问题的：ABC 跟这个心理没关系，文段没提"因地制宜"，也没提"品质效率"。你可能会稍微纠结一下"多元力量"，感觉力量特别多，但你没提主题词——主题词是心理无障碍，观念、思想、认知，都是心理。

这时候有同学不理解了：**你宣传引导在哪呢？**

其实 D 项还可以有第二种理解——把它理解为对"同时"引导的那两个对策的概括。有人立刻反驳：宣传引导不就是第一句话吗？后面没说宣传引导啊，你片面了。

其实不是。看后面：通过养老服务中心、居家养老服务中心的载体打造样板房、强化直观感受——这在干嘛？什么叫打造样板房？就像你买房，开发商带你看样板房；你买车，他们得让你看一下试驾车。让你去打造样板房是为什么？这不就是宣传引导吗？

**不能因为他没有"宣传引导"这四个字，你就不承认。** 它本质上不还是宣传引导吗？所以不管是"同时"前面的内容还是后面的内容，那都是宣传引导——这就是 D 项"加强宣传引导"的由来。悟了没有？彻底明白了没有？没懂就再体会体会，我们接着往下走。

### 情况二：对策之后只有一个更具体的对策

刚才是一对多：一个宏观对策，下面挂了好几个具体对策。现在是一对一：对策之后出现的是**一个**更加具体的对策。此时是前面对策重要还是后面重要？也要分情况。

#### 后文是例子、有重点词，还是什么都没有

三种形态，一张表：

| 后文形态 | 处理方式 | 重点在哪 |
| :--- | :--- | :--- |
| 有明显的举例子 | 按"观点＋解说"处理 | 前面的对策更大，例子不看 |
| 有重点词提示 | 层层递进 | 重点在后文 |
| 既没例子也没重点词 | 可前可后 | 看选项综合判断 |

**后面有例子，例子一律不看。** 比如这道题：先说需要改变单打独斗，要接纳企业的在线教育。他虽然给了具体做法，但那是"例如"——有"例如"在，那就不看，相当于还是前面的对策更大一些。这个好理解：观点加解说，解说是为观点服务的。

**后面有重点词提示，层层递进，重点在链条末端。** 什么叫层层递进？A 需要 B，B 又需要 C——那重点就是 C。

```text
复原力很重要
      └─ 需要我们不断地储蓄（存钱）
                 └─ 储蓄的关键在童年
重点落在链条最末端：复原力，关键在于童年
```

复原力很重要，它需要我们不断地储蓄——存钱。那怎么存呢？储蓄的关键在童年。所以这道题的答案就是"复原力关键在于童年"。类似层层递进的结构，重点词一提示（比如"更应该""关键"），重点就在后文。

**既没例子也没重点词，可前可后。** 这种情况出得不多。后面围绕单一的更具体方面展开，既没举例子，也没重点词提示，那就跟前面说过的一样——可前可后，看选项怎么出。比如：教育效果需要家长的亲身参与，这是第一句，是大的对策；放学后家长可以多一些和孩子的互动——家长参与什么呢？多一些和孩子的互动，这相当于一个小对策。那大和小谁重要？都有可能，不是都可以，是都有可能，看选项怎么出。选项一般不会都给你，放心；或者说，他会让某一个选项出现明显的硬伤。

再重复一遍这三条：后面是例子，不管它；后面有重点词提示，比如"更应该"怎么样，那就重点看后文；后面好像啥也没有，单纯看文段你不知道，得看选项来综合判断。

#### 烈士纪念设施：例子一直到结尾，总分结构抓对策和对象

第一句：烈士纪念设施是重要平台。哪个东西很重要？当你把第一句话看完，马上就能判断——哪个答案不太可能作为答案？你得有"烈士纪念设施"吧。

第二句：要在建设好管理好烈士纪念设施的基础上，将其教育作用发挥好，发挥教育的主阵地功能。这里别忘记了对策对象——对象是烈士纪念设施；对策呢？我要教育。然后后面给你一个"比如"，一直到结尾。

看到"比如"管到结尾，后面其实你可以不咋看——总分结构。抓住对策和对象：既要有烈士纪念设施，又要有教育，那就只能选 C。

排一排其他项：A 没有对象；B 和 D 没有真正的对策——B 背的是"管理"，不需要你管理；D 虽然有科技手段，但科技在这属于例子，非重点。C 项里的"如何"，指的就是科技手段——所以这个 C 项还可以更完美一些："运用科技手段，强化烈士纪念设施的教育"。但那样就太简单了，出题人不会把饭喂到嘴里。

有同学说：老师，那我总觉得这个例子不能白举啊，我举例子不也是为了论证观点吗？那科技就真的一点都不重要吗？

出题人也考虑到了这一点。他怎么处理的？他用一个"如何"，就把科技手段概括进来了。明白没有？

至于 B 为什么不行，就一句话：我的对策说得很清楚，就是教育；B 说的是如何保护、如何管理，没有教育。至于 D——谁让你看"比如"后面那两句话的？

#### 质检报告：尾句拆成"大对策＋小对策"，落点看选项

第七题，标题就是中心理解，我们今天讲对策，所以拿的都是对策类文段的题。

第一句：质检报告很重要。所以这个题大概跟质检报告有关系——大概率答案就在带"质检报告"的选项里，这时候可以先猜一个范围。

然后：一些商家为了提升销量伪造质检报告，一些电商平台也不怎么样。看到这，马上脑袋里蹦出一个词：**问题**。问题到"到这"为止。

接着说：问题存在，并不意味着我们不需要质检报告——你虽然有问题，但我还是需要你。人们的要求更高，加上网购的流行，所以质检报告成为人们的重要参考——再次告诉你，虽然有问题，但我还是需要，还是在强调重要性的问题。

"正因此"，表强调、表总结，大概率是中心句。再看这句话：全社会都应更重视质检报告，依法建立健全监管机制，确保整个行业……Buff 叠满了——又有对策，又有程度词，又有结论，这已经相当于把中心句的名牌告诉你了。

> **结论**："全社会都应更加重视质检报告，依法建立健全监管机制，确保整个行业……"就是这道题的中心句。

有意思的来了。看到这个尾句，先不看选项——它是不是就像我们刚刚讲的：**宏观对策＋具体对策**？大的方向是我要更重视质检报告；"依法建立健全监管机制"，可以理解为一个具体对策。大家说是不是？

一个对策、一个具体对策，而且好像没什么特别好的提示词——那怎么办？看选项嘛。答案有可能是前半句，也可能是后半句，也可能是"依法建立健全监管机制"重要。那看出题人有没有为难你：出题人有没有给你一个"依法建立健全监管机制"？没有。那就不用担心这事了，很爽，那把"重视质检报告"同义替换一下就行。

有"质检报告"的只有 C 和 D，而 C 说的是问题，那就只能选 D。

又有同学问：B 项不是对策吗？回到最开始那句话——对策类文段抓什么？对策和对象。这个题的对象是谁？质检报告。对策呢？让它变得更好，让它更进去检验。所以 A 和 B 连对象都没有，主题词都没有，不能作为答案。

### 什么时候不选对策：对策不万能

不是非得选对策。两种情况：

| 情形 | 特征 | 答案取向 |
| :--- | :--- | :--- |
| 文段不是对称的文段 | 既没问题，也没对策 | 没必要提对策 |
| 文段有问题，但选项没有好对策 | 没有针对性，或没法解决问题 | 选问题 |

第一种，文段不是对称的文段——既没问题也没有对策，那就没必要提。就像一个人一样：他啥病都没有，很健康，你跟我说"张老师你去医院吧"，我想锤死你。没什么问题，我为什么要去医院？不能无缘无故安一个对策。

第二种，文段出现了问题，但是选项中没有好的对策——比如没有针对性，或者没法解决问题，那就选一个问题嘛。

#### 新农人：唯一有对策的选项，偏偏不能选

第八题。近年来不少"新农人"跳回农门，带来了新技术、新模式、新理念，创造了新机会、新空间，丰富拓展了农村经济新业态——都是在讲新农人的好事，所以答案里大概也都有"新农人"这个词，不用管它。

然后话锋一转：新农人融入网络并没有那么容易；不少人虽然回来了，但是关系仍是"异乡人"。这两句话意思是一样的——强调什么？新农人好像不太适应，这叫问题。后面"正如"就是举例子了，不重要。

所以这道题是个分总分结构，重点就是中间这个问题。

按道理来讲，应该先找对策——四个选项中有对策的只有 B："新农人需要补短板，否则创业难成"。但 B 能选吗？两个问题：

1. 你说要补短板，得告诉短板是什么吧？文段没说；
2. 你说创业难成——难道我回乡非得创业吗？我踏踏实实当个农民不行吗？种田不行吗？"创业难成"是无中生有。

所以不是不尊重对策，是这个对策它不行。**我给你机会了，你不中用。** 你的思路不能变，不能因为这个题没选 B，就否认对策的重要性——是我给你机会了，你不中用。剩下 A、C、D 都在转折前，我们要选一个偏消极的、表述问题的选项，所以选 A：回得去，不等于容得下。

> **易错点**："短板是不会方言"那是你自己的理解，不能太强加自己的想象，要尊重文段。

#### 应对方法最有效：四个选项都是对策，挑有针对性的

第九题问的是"下列应对方法最有效的是"。这个题告诉你：**四个选项都是对策，你也不能乱选**，一定要选有针对性的，不能看到一个对策就冲。

文段先讲知识产权侵权有些跨区域的特点；"因此"之后转折——虽然侵权假冒不在同一个区域，但是知识产权侵权往往是销售一体化运作；"然而"在执法管辖上，只能就本区域内的侵权假冒行为进行查处，在执法调查取证上，需要跨区域调查取证。

转折之后提了个什么问题？**问题是全链条的，但治理的时候只能就某一个区域治理。** 要去别的区域治理，就得跨区域，就得联系一下同行、联系一下同事——问题就出在这：你的权限不太够，你得联合治理才行。

针对这个问题，优先找对策，而且找的对策得跟这个问题相匹配，不能乱选。

| 选项 | 大意 | 排除理由 |
| :--- | :--- | :--- |
| A | 要有技术 | 反推问题是"技术落后"，文段没说 |
| B | 要立法 | 反推问题是"法律不完善"，文段没说 |
| C | 建立多元化沟通机制，加强执法部门与权利人以及平台的沟通 | 偷换概念：文段的沟通合作是部门与部门之间 |
| D | 树立全链条办案理念，上下联动 | 与"全链条问题、跨区域治理"相匹配 |

A 和 B 好排——反推就行。C 和 D 会稍微纠结，特别是 C 有个"多元化沟通"，D 有个"全链条办案理念、上下联动"，乍一看好像都有合作的意思。为什么不选 C？**此沟通非彼沟通。** C 说的是加强执法部门与权利人以及平台的沟通，而文段里的沟通合作是谁和谁之间？是行政部门之间、部门和部门之间。C 把它变成部门和权利人之间，属于偷换概念。所以只能选 D。

又有同学眼睛冒光了：老师，这个题你咋不说知识产权呢？

可以承认知识产权很重要。但有"知识产权"的是不是只有 B？B 能选吗？对策对象不对。这个题如果你有一个选项写成"针对知识产权侵权案件，我们要树立全链条办案理念"，那它就串起来了——可惜没有，它相当于缺对象。唯一有对象的是 B，但 B 对策不对。**没有总比不对好，宁缺毋滥。** 你可以优先看知识产权，没问题；但对策不对，这个文段跟法律完不完善、健不健全没有关系。

### 对策和问题是一体两面

最后一个点：对策和问题的相关性，类似前面讲过的观点和解释的关系。对策和问题，很多时候是一体两面的。

我饿了，那肯定对应吃饭；我说要吃饭，就意味着我饿了。我喝水，就是我渴了；我渴了，就意味着我要喝水。我生病了要治病，那我要治病，是不是就是我生病了？

所以这就证明了：你要针对问题，也可以通过对策反推问题。**一定不要忽视问题。**

#### 权限题：只看对策会纠结，回到问题上就定了

第二节课讲首句引出主题词时用过的那道题。前面讲了一堆问题：权限不足也有问题，权限太多也有问题——这就是问题。从"因此"开始，一方面、另一方面提对策，所以分总结构肯定没跑。

概括对策的时候，同学会在 B 和 D 之间纠结，因为 A 和 C 比较好排：

- A"重视基层执法"——不是说你不对，但"重视"两个字太宽泛了，讲半天都不知道你到底重视啥；
- C"加快权限下放"——文段不是讨论快慢问题，不是让你三天之内下放。别人探讨的是够不够的问题。我们经常说"一管就死、一放就乱"，给太多了也不行，给太少了也不行，到底是给多少的问题，不是给得多快的问题。

那为什么纠结 D？因为"执法目录"这四个字，在后面"一方面""另一方面"当中都出现了，感觉该选目录。但理由不够充分：你 B 项是"精准"的，一方面也有精准，另一方面也精准——两方打平。**只看后半段文段，你可能不太知道是目录重要还是精准重要。**

但是，当你对策有点纠结的时候，看看问题是啥呀——这就是首句的重要作用，它帮你划定一个大概的范围：我们在讨论权限的问题。所以一定要围绕精准赋权去理解，去调整你的权属；没有权利是不行的。所以选 B。

> **提示**：有的题比较难，你只看对策部分有点纠结、不知道到底强调什么的时候，不要忘了"来时的路"——不要忘了你为什么提对策。你是因为权限的问题提对策，那就尽量选跟问题相关的对策。

#### 个人信息保护：尾句的"各侵权人"，其实是下游违法者

最后这道题出得非常好，但很多人没读懂。

第一句：个人信息保护案件涉及到很多环节，责任主体除了已经被追究责任的上一环节主体之外，还可能包括下游的违法信息处理者。"除了……还……"一般后面重要，所以基调定下来了：我们在讨论谁？讨论下游的违法者。

第二句：那么在这个案件办理中，是否可以连带追究下游违法者的责任呢？司法实践中存在争议。注意，不仅围绕下游违法者，而且讨论的问题是——我到底应不应该追究他的责任，不是别人，是下游违法者的责任。还是在这个大框框里讨论。

出题人提了一个"是否"的问题。那请问接下来这么一大堆，他应该干一件什么事情？是不是告诉你答案——到底是"是"还是"否"。

根据民法典的相关原则——它规定了共同处理的连带责任；"因此"，当不同侵权主体主观上具有共同过错、客观上实施了共同侵害的行为时，可以依法追究各侵权人的连带责任。

出题人这就有点"恶毒"了：你如果只看这个尾句，"因此"之后说的是"各侵权人"——他说的不是个侵权人吗？**但是你不能脱离整体了解局部。** 他这里的"各个侵权人"，难道想讨论已经被追究的那一方吗？难道想讨论上游吗？想讨论中游吗？不会。他是想解决"能不能连带追究下游"这个问题，而下游是包含在"各侵权人"当中的。所以对于这个尾句的"各侵权人"，不要真正看成"各侵权人"，要把它看成"下游违法者"。

举个例子。班主任王老师很喜欢我。有一天我犯了错，徐学伟就说：王老师，我们要批评张老师。但是他有点犯怵，因为他知道王老师喜欢我——那他到底应不应该批评我呢？他就去问王老师：张老师最近在课上犯了一些错误，我们到底应不应该提出批评呢？

这个时候王老师说了一句话：**任何老师在课堂上犯错误，都应该被批评。**

什么意思？这个"任何人"指的是任何人吗？不是，这个任何人指的就是我。

所以你"各侵权人都该追究"的意思，就是——你那个下游，就该追追吧。他看似回答的是各侵权人，其实回答的是下游的人。

所以答案是谁？对象是下游的违法者，该追究追究——应当依法追究下游违法者的赔偿责任。把没有"下游"的直接干掉：A 说的是犯罪者，C 说的是法定原则，D 说的是各侵权人；而且 D 的"明确"也不对——我早就明确了，我需要的是追究。这个题很容易纠结 C，C 更不对，法定原则在"因此"之前，非重点。

> **提示**：有人问"哪有谁 30 秒想这么细"。我讲得细，是因为我得把它说出来；这些思想在你大脑当中其实是很快的。一道题我可能讲五六分钟，你真正想，没有那么久。

### 最后，把对策的考点串成一条线

这部分内容到此告一段落，把整条线收一遍。

- **必考考点**：对策类文段。
- **必要条件和对策是一回事**："只有……才……"引出来的内容，就是对策。
- **优选对策**：但凡文段中出现对策，要优先考虑它的重要性——比问题、比意义、比效果、比解释、比原因都重要。
- **对策文的三种模式**：文段正面题（直接提对策）、文段反面题（只说问题）＋选项给对策、文段问题＋选项问题。其中**文段正面提对策是最高频的**。
- **内容大于形式**：除非内容都存在，否则内容大于形式；如果大家都有，你再考虑形式。
- **抓住主题词：对策＋对象**。对象就是谁去做、为了谁，也就是主语和宾语；对策就是你要干嘛、你要干啥。
- **宏观对策之后可能出现更加具体的对策**：可能是多方面的，也可能是单一的——这块比较杂，如果觉得乱，课后好好体会。
- **什么时候不选对策**：要么不是对策的文段；要么文段有问题，但选项没有好的对策（比如新农人那道题）。
- **对策与问题的相关性**：直接看对策有点纠结、甚至是陷阱的时候，尽量结合问题一起看。总原则就是——完整地看，把它们结合在一起看。

> **承前启后**：上一节讲完「对策类文段：宏观之后的具体对策，与何时不选对策」，下一节接着讲「转折与因果：看清句子与句子的关系」。

## 转折与因果：看清句子与句子的关系
> 对应块：BLK07 | 覆盖分集：P04上 | 块标题（分集名）：《04.【张弓言语·十二箭】-第四讲》

又见面了。十二节课，今天来到第四讲。能坚持半个星期的同学，我先给你们点个赞——别的不说，我身上这件衬衫就是见证。昨天有同学猜我还有几件衬衫，我在这儿表个态：一年四季一季一套，四季常服不过四套，所以「朕四季常服不过八套」那种话，也就听一乐。

上正式课之前还是老规矩，把昨天的内容简单回顾一遍。

昨天我们主要围绕对策讲，记住四句话就够了：

- 对策很重要；
- 「只有……才……」引导的对策、「应该」引导的对策、必要条件关系，三者的意思本质上是一样的；
- 优选对策——对策的重要性比问题、比意义都高；
- 对策有三种呈现方式，这个昨天讲透了，今天不重复。

这里我要更正一个地方。昨天发导图的时候我有点疏忽，思维题那一块直接粘贴下去了，应该是「多方面」：一种是先提一个宏观大对策，接下来给具体多方面的多个小对策；另一种是前面先提出大对策，后面围绕具体的单方面展开。一个多方面、一个单方面——这种结构选前面还是选后面，其实都有可能，你要分情况讨论。

昨天上完课，我从评论区捞了一批有难度、有代表性的题目。跟昨天一样，正课讲完之后我们把这些题拿出来一起看，看看这些题到底该用什么思路做，符不符合我给大家讲的这些情况。

今天的内容没有昨天那么复杂，看思维导图就知道，就两块：转折、因果。

### 转折：重点在整体转折之后

考点回顾我不多说。很多老师一上来讲言语就讲这个：转折的典型标志——虽然、但是、尽管、可是、不过、然而、却、还是；再往下还有一组——其实、事实上、实际上。要点就一条：转折之后是重点，转折前不能选。这些大家都很熟了。

但我还要强调一个点：**转折之后是重点，是站在整个文段的角度讲的**。不是一句话当中有一个「但是」，后面就一定是重点；而是这个文段整体上可能存在一个转折关系，那么这个文段整体转折后的内容才是重点。他一定不是只针对某句话。你一定得站在整体的角度看，看句子和句子之间的关系。我们之前举过例子：前后有一个转折关系，那转折之后是重点——但一定要完整地看，看的是句子和句子之间的关系，不是某一个词。

#### 「其实、事实上、实际上」引导的是事实，不一定是转折

今天要拔高的第一个点，就在这儿。很多同学在这个问题上学得很死板，千万不要。「其实」「事实上」「实际上」只是引导一种事实。

什么叫「其实」？什么叫「事实上」？就是这个事情的真相是——接着讲。那么问题来了：事实这个东西一定是转折的吗？不一定吧。它只是一个事实而已，谁说事实一定要转折了？

感受两组句子，哪句表转折：

- 第一组：大家都说老王是好人，事实上他是坏人。
- 第二组：大家都说老王是好人，实际上他确实如此。

第一句还是第二句？第一句。所以你们以后看到「事实上」「实际上」，能不能很武断地说：哦，转折了，转折之后是重点了？——一定不行。它跟「但是」还是有区别的。你看什么？看内容。它只是引导事实；**只有这个引导的事实和前文构成了矛盾关系**——你说好，我说不好——它才叫转折。

这跟我们第一节课讲的道理一模一样：你不能完全由关联词决定，不能完全由关键词决定。你不要管有没有「事实上」「实际上」，你看这两句话的关系。这一点，新来的同学可以回第一节课的录像对一下，逻辑是同一个。

#### 雅与俗：先讲个性再讲共性，「实际上」才是转折

第一道题主体给得很清楚：雅文化和俗文化。

文段说，雅文化是一种自觉的、典籍的、较高的文化，对社会影响深刻而狭窄；俗文化则是以世俗为中心的、民众的、民众自发的无意识的东西，肤浅而广泛。两者之间只有形式上的某些差别。到这儿就是在介绍两个东西——一个下定义、引出话题。

然后出现「实际上」。「实际上」能不能说一定转折？不知道，得看内容。前面强调的是相同点还是不同点？一个深刻而狭窄，一个肤浅而广泛，强调的一定是不同点，是个性。后面呢？雅中有俗、俗中有雅、由俗到雅、由雅到俗——这是相同点，是共性。前面是个性，这里是共性，所以这个地方的「实际上」表转折，这句话就是中心句。

没完，别着急。《论语》《孟子》被世俗传颂——第二节课我们讲过，这是例子；《诗经》原本是民谣、是俚曲，就是俗的东西，后来成了经典，经典就变成雅的了。所以他依然在讲俗雅关系，而且俗雅之间是可以互相转化的——还是在论证前面那句话：两者具有一种相似性。

所以这个题是分总分结构，重点就是「实际上」那句话。

```text
分（雅：深刻而狭窄）      总（实际上：雅中有俗、俗中有雅）
分（俗：肤浅而广泛）  →    分（举例：《论语》《孟子》由雅入俗，
                          《诗经》由俗俚而成经典）
```

读图：先分述雅与俗的个性差异，中间用「实际上」翻转到共性，后面再举例证明二者可以互相转化——答案要落在中间那句「相似性」上。

选项其实没有特别完美的，但还是那句话：抓大放小。谁能够表达「相似」这个意思？只有「互动关系」。你乍一看「互动关系」好像也不是特别好，但「对立」「有别」「不同」肯定不行——因为它们强调的都是转折之前的个性。

#### 城乡二元：尾句不反驳前文，就不是转折

下一道题，我先问大家一个问题：这个题有的老师是当转折讲的。大家先不要考虑选项，就从文段的角度讲——它是转折吗？仔细感受一下，我认为不是。为什么？

文段说，长期的二元城乡发展导致城乡二元分化，什么意思？城市和乡村不太一样，有农村户口、有城市户口。他说这导致出现了问题：不均衡，农村资源向城市集中，难以避免造成萎缩。昨天刚学过：看到消极词表问题。那有问题，后面大概就是怎么解决。「通过建立健全城乡融合发展机制」——昨天讲的什么？对策加对象。建立健全机制、推动交换、消除隔阂，这是对策；城乡，是对象；后面接效果，说这样才能真正形成某种良性格局。到这儿是重点。

但还没完，还有个尾句。很多人问我尾句是不是重要，这个题的尾句没有那么重要。为什么？前面说城乡融合很重要，尾句说「事实上，我国农村三产融合发展好的地方，往往也是城乡融合发展程度高的地方」——我就问你，他反驳前文了吗？他的观点难道跟前面不一样吗？是一样的。所以这句话当成例子更好理解：它作为例子在证明前面。你建立健全了城乡融合发展机制，融合程度高，那就很好。同意吧？

所以这个题中心句在中间。但你还是得抓大放小：别人都把对象给你拎出来了，你也不用关心对象是谁，你抓住对策本身——城乡融合。出题人也没有为难你，因为只有 C 项有「城乡融合」。

这儿我要说一句。有的老师看到「城乡发展水平」，觉得「发展水平」对应到「发展」，所以答案选 C。我个人不认同。你不能因为正确答案长得像，就认为文段是转折关系、重点在尾句——咱们要实事求是。这个题他就不是转折，他没有反驳前面，他凭什么是转折呢？

再看 A、B、D 为什么不行。昨天讲了对策加对象：你既然说了要建立健全城乡融合发展机制，没有「城乡融合」能行吗？第一个问题，对策、主题词没有。A 项是问题，也比较好排，优质资源在前面那儿。「应该解决城乡间资源配置不均的问题」除了没有「城乡融合」这个对策主题词，还犯了一个问题：不太明确。到底怎么样解决资源配置不均？通过建立健全城乡融合发展机制。所以答案选 C 而不是 D。

这时候弹幕有同学问：C 不是对策呀。问这个问题的同学，昨天大概没来听课。有没有昨天听课的同学告诉这些同学，C 为什么看起来不是对策的形式，但也要选？

不等式在这儿：**内容一定要大于形式**。我要找对策，是找「应该」这个词吗？难道选答案的时候，「优选对策」是选「应该」这个标志词吗？我选的是这个对策的内容——对策的内容就是城乡融合发展，「城乡融合」是对策的内容，我要的是这个内容。我选对策，不是选「应该」这个字，不是选那个虚词，我选的是谁能够更好地体现我文段当中对策的具体内容。我的内容就是城乡如何发展。悟了的同学，先把第三节课对策那一讲补一补，老师讲得非常详细。

#### 答案的两种写法：否定前文，还是阐述后文

第二个拔高点：**转折文段的答案，既可以是对转折前观点（关联）的否定，也可以是对转折后内容的阐述。**

举个例子。有人说公务员考试挺简单，其实公务员考试挺难。假设这是文段，答案可以怎么写？有点像昨天讲的大对策小对策：既可以把后面这个观点直接挪下来——把「挺难」讲清楚；也可以说我反驳了前面的观点——「公务员考试简单的说法是错的」。两种写法都成立。

那如果两个都出现了，选哪一个？是这样：出题人大概率不会让你陷入这样的两难境地。他一定会用某种手段，比如你在 A、B 之间纠结，他让某一个选项变得不好——把「公务员」改成「高考」，或者去掉某个限定成分，让它变得不那么稳妥。这是第一节课第三步「排除选项、对比择优」的内容。

如果你非要问极端情况下哪个更好——选阐述转折后内容的那一个。因为它表述比较明确、比较直接，看起来更具体一些。

| 答案写法 | 对应上文例子的表述 | 适用情形 |
| :--- | :--- | :--- |
| 否定转折前观点 | 「公务员考试简单的说法是错的」 | 前文确有错误论调、偏见可供否定 |
| 阐述转折后内容 | 「公务员考试挺难」 | 更直接、更明确，极端二选一时优先 |

下面两道题，一道选后面的写法，一道选前面的写法。放在一起看，缘分非常奇妙，这两道题对比着讲，比我单讲任何一道都值。

#### 喝酒题：「由此」不总结全文，转折引出新话题

第一道。「喝酒有害健康」早已成为共识，酒精对大脑的危害也引起了关注。开篇提观点，接下来开始举例子论证：喝酒会导致大脑体积减小；有研究指出，每周饮酒会导致海马体萎缩。「由此造成的后果」——有结论词，重点看结论：长期饮酒的人更易患上痴呆症。

慢慢来。如果文段到这就没了，答案选谁？妥妥的同义替换，选「长期饮酒的人更易患上痴呆症」那一项。所以这个题你要是选了这个选项，那就证明你错了——因为「由此」不是对整个全文的总结，他只是对前半部分的总结。这就是句子和句子的关系：整个文段不是结论关系，而是一个「不过」的转折。所以你一定要往后看。

「不过这些研究往往关注长期的，那如果只是偶尔喝一次呢？」前面说的是长期，你现在说的是短期、偶尔，相比于前面的「长」，「短」是一个新话题。某种意义上，它相当于转折之后引出了新的观点：我不再讨论长的了——天天喝肯定不行，这大家都知道。注意，这不是并列：并列式是都重要，转折只有后面重要，有本质区别。他的意思是：长的不长篇大论了，只讨论短的。短的呢？有研究指出，哪怕只是喝醉一次，造成的影响也会伴随终身。

所以这个题整体是分总结构，重点就是「哪怕你偶尔喝一次，确实也有伤害」。

```text
分：共识——喝酒有害健康（大脑体积减小、海马体萎缩）
   ↓ 「由此」只总结到这里：长期饮酒更易患痴呆症
转折：「不过」——这些研究关注长期，偶尔喝一次呢？（新话题）
总：哪怕喝醉一次，影响伴随终身
```

读图：「由此」的结论只管前半截，文段真正的落点在「不过」引出的短时、偶发饮酒上。

这个题像昨天第三节课哪个题？「下游违法者」——我到底应不应该针对下游违法者追究责任呢？应该追究。逻辑一模一样，是个问答结构。

如果不看答案，我自己归纳这句话的真正意思：偶尔或者说短期喝酒也有危害。但不好意思，选项里没有，没有「短期」「偶尔」这个词。那怎么办？退而求其次，看谁能够沾边就选谁。D 项「介绍关于饮酒危害健康的研究结论」——这个 D 其实非常不明确，非常莫名其妙，但这个「研究结论」可以概括最新的研究结论，虽然话没说清楚，已经是四项里最好的了。

其他项的问题在哪儿？选 A 的同学是最不应该的，因为前面在讲长期的。C 也不能选，「饮食」是不是太大了一些？文段不是在讲喝酒吗？问得最多的是 B「纠正人们对饮酒危害的错误认识」——很明显，纠正错误认识的前提是什么？你得先有错误认识。同学说「张老师，你应该改正你的错误」，那我是不是得先犯个错，你才让我改？就像当年一位哲人说的：既未曾拿起，又何曾放下。喝酒有害健康第一句话就是「早已成为共识」，没有人说喝酒没有危害，也没有人说喝酒其实没害——他没有错误认识，他只是可能之前不知道，顶多不知道。所以答案选 D。

A 可以说片面，但不重要——你都在转折之前了，我管你偏不片面？这是小问题，它犯的是原则性问题：转折前非重点不能选。

#### 灵活就业题：反推法，别给自己加戏

第二道，对比着看。一再强调：看文段。

在关于灵活就业的讨论中，有一种论调：技能要求不高，年轻人投入其中是短视行为，不利于个人和社会的积累。这是提出了某种比较消极的论调。「这种忧虑的初衷可以理解，但事实上……」——有个「但」字，大概率是转折。为了保险起见，看一看：前面是消极态度，后面呢——留存的门槛却并不低，也需要一定的技能支撑，不一定意味着低能。你看这个时候，整个后面就是一个整体了，这个「但」就是针对前面那段消极论调的转折。所以不管说留存门槛不低，还是说需要技能支撑，还是说不一定意味着低能，后面整体是积极的——你说低，我说并不低。所以这个「但」一定表转折，重点一定在后面。

跟刚才一样的情况：我要选一个答案，把后面的意思表达出来。刚才那个题，D 好歹通过某种方式概括了「不过」之后；这个题，我想选一个答案把后面的内容完美概括一下——有没有？四项一个一个看。

第一项，「并非所有灵活就业都是低门槛」。这其实有一定的干扰性。教大家一个方法，叫**反推法**：假设答案选它，那文段该怎么写？如果文段的中心是「并非所有」，那它一定要表达出「有的……有的……」的关系——有的门槛低，有的门槛高。而这个意思文段有体现吗？没有。文段说的是：反正但凡留存，你就需要技能支撑、有门槛。文段跟「有的有的」的关系是完全不同的两回事。

第三项，「灵活就业在职越久越要紧（技能傍身）」。这个题他喜欢加戏——你乍一看好像跟尾句很像，真相啊。但是「越久越要技能傍身」是这个意思吗？文段有没有讲：随着时间的延长，我对你的要求会越来越高？举个例子，我作为一名讲课的老师，待一年要求这么高，待两年这么高，待三年、五年、十年比天花板还高——请问文段有没有体现出你的技能一定要随着从业时间增加而增加？没有。他只是说你但凡留存，你就需要。你留一年还是十年不重要，反正但凡要留存就要。没有这个时间长短关系，这不给自己加戏吗？排掉。

第四项，「年轻人无需过度忧虑」。这个地方很有意思——怎么把这个选项改一改就对了？把「对」往前放：「对……无需过度忧虑」。因为年轻人是那些专家讨论的对象，不是说出这句话的人。是这些专家学者在讨论年轻人的就业，而不是年轻人去讨论就业——他们又没有这个权利，又没有发声的渠道，他们是一个被讨论的对象，不是讨论的主体。很细节，所以这个选项排掉。

那第二项属于转折文段的哪种情况？我没有给你把后面的内容直接说出来，但我帮你把前面给否定了——我能够反驳前文。听懂了吗：刚才那个题是概括转折之后，这个题是反对前文。

这两个题放一起非常经典。而且这个题它有偏见——它真的摆出了那么一种论调。所以为什么这个题可以（否定前文）？因为他真的有偏见、真的有所谓的错误论调，所以我可以把它摒弃掉。为什么刚才那个题不能选「纠正错误认识」？因为那个题没有错误认识——喝酒有害健康是共识，没有人说没害，他不是没有危害，是没有错误认识，所以不能纠正；而这个题确实有错误论调，所以能否定前文。

还能问「如果两个都存在呢」——你来晚了，一般不会都给你。你看这个题是不是这样？看似好像有个选项给了你后面，但他有问题啊。出题人一般不会都给你两个完美选项；真要给，他会让某一个选项变得有问题，让你能够放心把它排掉。这是一般出题人的手法。

转折这块其实很简单，两个点：第一，「其实、事实上、实际上」并不一定表转折；第二，转折文段的答案既可以是对转折前观点的否定，也可以是对转折后内容的阐述。如果你真的遇到极端情况两个都在，那就选后面那个——它看起来更具体一些。

### 因果：结论之后是重点

#### 结论词不止「所以」「因此」

考点回顾一下。因果标志词不说了：因为、由于、由、因此。结论标志词，大家这个地方稍微注意一下——很多人对于结论词只停留在第一种情况，「所以」「因此」，太狭隘了。除了这个，还有第二种：可见、看来。第三种情况它也是结论：换言之、对此、有鉴于此、总之、换句话说、简而言之。

第三种怎么理解？它只带了前文——他帮你把前文指代了一下。「换言之」就是指代前面嘛，「对此」「有鉴于此」也是，「总之」「换句话说」「简而言之」都是这个用法。只代了前面之后，大概率就顺势总结一下。所以某种意义上，它也能起到总结的作用。

| 类别 | 标志词 |
| :--- | :--- |
| 原因类 | 因为、由于、由 |
| 结论类（一） | 所以、因此 |
| 结论类（二） | 可见、看来 |
| 结论类（三：复指前文） | 换言之、对此、有鉴于此、总之、换句话说、简而言之 |

理论要点跟转折很像：结论之后是重点。除了这个，还有第二个要点——尾句出现结论词，要重点关注。你乍一看感觉平平无奇，其实内涵很深刻。

#### 尾句结论词：看不懂题时的抓手

考试的时候，你该正常做还是正常做，这个不变。但如果你说这个题我不太懂，看也看不懂——而好巧不巧，这个题的尾句有一个「因此」这样的结论词，那你就紧紧抓住尾句这个结论。它作为中心句、作为答案的概率高达百分之八十以上。不是所有情况，但很高很高。

原理是什么？首先，如果这个结论词是对整个前面做了总结，那自不必说，分总结构。那同学可能会问：你这个结论有可能只是一个部分的结论——对例子做的总结、对解释做的总结、对后面某一个地方做的总结，那你凭什么说它也是重点？

原理就在于：哪怕你是对例子做的总结，但例子的本质和观点其实是一样的。你不管怎么理解，都不影响你选答案。就像第二节课那道《只此青绿》的题——「人在画中游」，中间是例子，尾句做了个总结；这个总结你既可以理解为对整个前面的总结，也可以理解为对例子的总结，不管怎么理解，它其实不影响你选答案。回去把第二节课那道题翻出来对一下，一毛一样。

#### 非遗题：有问题就有对策，让选项提示重点

看题。由于历史上非物质文化遗产没有文字，而非遗最重要的是什么——大概跟非遗有关。接着：最重要的内容是记忆和技艺都保持在传承人身上。这带来了巨大的不确定性——敏感、消失。大脑转起来：「不确定」「消失」，两个字送给他：问题。那有问题就好说。

你知道为什么有同学做题会很快吗？他们养成下意识了。看到第一句大概就知道后面在干嘛——你都有问题了，那后面大概就是解决呗。

「只有通过传承人的口述记录，将这些记忆转化为文字才能保存」——「只有……才……」必要条件关系，或者说表对策。对策是什么？出现了一个新玩意：口述记录。注意，新话题——因为前面没有口述记录这码事。所以到这儿，重点就是口述记录。

尾句有个「故而」——尾句出现结论词嘛。故而民间文化遗产抢救工作和非遗档案建设就此展开：对传承人的口述调查变成了普遍采用的、不可或缺的、唯一的最可靠的方法。这个题不应该做错——出题人生怕你不知道谁重要，「不可或缺」「唯一」「最可靠」，谁最可靠？口述调查。

当时我做这个题，一开始没太注重传承人，说得很诚实。我的想法就是：你肯定得有口述调查，对非遗要口述调查、要保存，相当于对策。所以先把谁干掉？没有口述调查的那两个选项，先干掉。希望不要再有同学问我为啥不选那两个，好不好？

剩下两个都有这个对策，对象就是非遗。那怎么办？**对比选项，找差异**。你发现有一个比另一个多了一个「传承人」——那就回头看文章有没有：哦，有。不是对什么领导的口述调查，是对传承人的口述调查。所以选带「传承人」的那个。

我特别不喜欢上帝视角讲课。当时做这题，谁能够一上来就关注到传承人呢？一般人都只能关注到口述记录、口述调查。你让我一上来关注传承人，我也看不到，我也不太知道他到底重不重要。当时我就觉得：不管怎么样，口述肯定得有。所以一定要靠选项来给你提示——剩下两个选项就对比选项找差异，相当于他反问你：同学你看，一个没有传承人、一个有，那看看到底有没有呗。所以答案选 C，是因为 C 有传承人。

```text
问题：非遗无文字 → 记忆与技艺系于传承人一身 → 不确定性（消失）
   ↓ 「只有通过……才能保存」＝必要条件＝对策
对策：对传承人的口述记录／口述调查（新话题，前文未出现）
   ↓ 「故而」＝尾句结论词
结论：口述调查成为普遍采用、不可或缺、唯一最可靠的方法
```

读图：看到「不确定性」就下意识找对策，「只有……才……」把新话题「口述记录」顶成重点，尾句「故而」再补一刀确认。

还有人说：不选另一个是因为它有「最可靠」。大家觉得这个理由对不对？不要看到这种特别绝对的词就一味批判，你得看看文段。我稍微暴论一下：假设没有 C 项，我把 B 加上「传承人」——「对传承人的口述调查是非遗研究最可靠的方法」——选不选？那肯定选。

### 本讲提到的题目

- **雅文化与俗文化（分总分）**：文段先分述雅文化「深刻而狭窄」、俗文化「肤浅而广泛」的个性差异，再用「实际上」转到「雅中有俗、俗中有雅、由俗到雅、由雅到俗」的共性，后以《论语》《孟子》由雅入俗、《诗经》由俚曲成经典作例。答案落在表达「相似性」的「互动关系」上——「对立」「有别」「不同」强调的都是转折前的个性，不选。反推依据见「雅与俗」一节。
- **城乡二元（中心句在中间）**：长期城乡二元发展导致不均衡、农村资源向城市集中（问题），对策是「建立健全城乡融合发展机制，推动交换、消除隔堢」（对策加对象），尾句「事实上」讲农村三产融合与城乡融合的正相关，是例证而非转折。答案选含「城乡融合」的 C 项；缺主题词、把问题当主旨、对策不明确的项一律不选。解析见「城乡二元」一节。
- **饮酒危害（分总）**：共识与脑体积减小、海马体萎缩为分述，「由此」只总结到「长期饮酒更易患痴呆症」；「不过」转到「偶尔喝一次」这一新话题，落点在短时饮酒亦有伤害。没有「短期／偶尔」字样的选项就退而求其次选沾边的 D；B「纠正错误认识」不选，因为喝酒有害健康早已是共识，人们顶多是不知道，并没有错。解析见「喝酒题」一节。
- **灵活就业（否定前文式答案）**：先摆出「年轻人灵活就业是短视行为」的消极论调，「但事实上」以留存门槛不低、需要技能支撑反驳。用反推法排「并非所有」（文段没有「有的……有的」）、排「越久越要紧」（文段没有时间长短关系）、排「年轻人无需过度忧虑」（年轻人是被讨论的对象，不是立论主体）；选否定前文论调的 B 项。解析见「灵活就业题」一节。
- **非遗口述调查（问题→对策，尾句结论词）**：非遗无文字、记忆与技艺系于传承人一身带来不确定性（问题），「只有通过传承人的口述记录……才能保存」给出对策（新话题：口述记录），尾句「故而」确认口述调查不可或缺、唯一最可靠。先干掉没有「口述调查」的项，再在剩余两项间对比差异，按文中确有的「传承人」定夺。解析见「非遗题」一节。

## 因果文段与层层递进：抓结果、抓大放小
> 对应块：BLK08 | 覆盖分集：P04下 | 块标题（分集名）：《04.【张弓言语·十二箭】-第四讲》

做完上一题，我们把这句话立在这儿：文段是白纸黑字的，它就是最可靠的。别把自己的想法特别强地加进去，要忠于原文——你脑子里那套先入为主的判断，在文段面前什么都不是。

这一讲在中心理解题上继续做思维提升。第一个文段，就是因果文段。

### 因果文段的答案，为什么爱写成"因加果"

因果文段的选项有个很鲜明的偏好：当文段里出现很多原因、很多议论，最后落在一个结果上时，答案喜欢考"因加果"的结构——也就是正确选项里既有原因、也有结果。

为什么这么出？说白了是反套路。有的老师讲"因果关联词里，因不重要、果重要"，于是一些人养成了看到一个"因"就撒腿跑的习惯。出题人专门治这个，所以"因加果"的选项就多起来了。但你心里要清楚：这不是选项的必然特点，不是说因果文段的正确答案只能是"结论加原因"或者"原因加结论"，这只是概率偏好。

> **结论**：选这种选项，是因为它体现了"果"、表达了结果的意思。至于"因"有没有被带出来，不重要——你爱提不提，提也行、不提也行。

举个最简单的例子。我说"考试难度越来越高，因此应该认真听课刷题"——这是因果结构，"考试难度越来越高"是因，"应该认真听课刷题"是结果，也是中心句。这时候两个选项：一个是"考试难度越来越高，因此应该认真听课刷题"（因加果），另一个是"应该认真听课刷题"（只有果）。选哪个？都行。而且真到了考场上，一般不会两个都给你，要么给前者要么给后者，给哪个都无所谓——你只要抓住"应该认真听课刷题"这个结果，就及格了。

从出题人的习惯来讲，"只有果"这种出法概率上更多一些。原理归原理、理论归理论、概率归概率：我们都知道因不重要，但落到真题里，第二种写法确实更常见。

第一节课举过"废墟何以是美的"那个例子。选项里有没有"何以"这两个字，要不要也无所谓——我只需要它体现出"废墟"、那个"残体"是美的，这就够了，这就及格了。至于优不优秀，另说。

所以做中心理解题，脑子里要有"抓大放小"四个字。一道题摆在面前，要训练自己只看关键信息。比如我们讲过的那道"非遗和传承人口述"的题，在我眼里整道题就只有"非遗"和"传承人的口述"，别的只要没有大问题都无所谓。你纠结的那个词到底该怎么抠，这就是要补第一节课的内容。做中心理解题，抠字眼是做不好的。

这个思想一开始接受起来不太容易，但要慢慢去接受它：抓住关键的看，别盯着细枝末节较劲。

### 月球为什么有两副面孔

先看一道标题填入题。科学家早就知道月球有两面：面向地球的一面较为平坦，背向地球的一面凹凸不平、遍布撞击。那么，月球为何具有两种截然不同的面孔呢？这是谜团之一。

对象在开篇就给你了：月球、月球。整个题就是围绕月球来讲的。如果你听过我第二节课讲的首句，这道题根本不会在A上纠结——首句已经把话题钉死了，讲的肯定是月球。

再往后看，"两副面孔"就是"两面"的意思。然后科学家提出了一种解释，一个冒号打下来，后面全是过程：撞击产生的热量、融化、被带到对称的区域、最后产生表面的熔岩流，最终形成正面的火山平原。

画个图就清楚了：

```text
   ┌───────────────────────────────┐
   │   受撞击的一面：凹凸不平        │ ← 背向地球
   │    ▲   ▲   ▲   ▲   ▲   ▲      │
   │                                │
   │        力量沿球体内部传导 ──→   │
   │                                │
   │   较为平坦的一面                │ ← 面向地球
   └───────────────────────────────┘
```

读图说明：一侧受撞击打出凹凸不平的表面，力量传导到另一侧，把另一面"抹平"了。后面这一大堆撞击、热量、熔岩流，全是在介绍两面成因的过程。

这是一个非常典型的总分结构，或者说"观点加解释"：先抛出现象与疑问，后面解释原因与过程。抓大放小，我抓结果就行，结果就是五个字——月球有两面。所以答案选"双面月球"。

"一次撞击，两种结局"这种表述恰恰表明的是原因，它相当于"双面月球"的原因，跟正确答案是一个意思。

有同学说，这个选项没提到热元素。这重要吗？中间那一堆解释是过程，是噪音。剩下的选项更好排：A没有月球；B和D没有体现出"两面"——你答题总得有两面吧。你也可以认为B的熔岩流、D的放射性都属于中间过程，不重要，包括最后那句"最终形成正面的火山平原"，也是过程。

这个题不难，拿它讲理论。题目不重要，先把基础打扎实，往后难题有得是。

### 蜜蜂为什么单恋一枝花

这道题稍难一点。美国杂志的研究表明，咖啡因是让蜜蜂忠诚的物质，一句话就把咖啡因和蜜蜂的关系引出来了。正如咖啡因可以刺激人类大脑，它也可以刺激蜜蜂的大脑，特别是蕈形体的区域，这一区域跟气味有关系。咖啡因的摄入使得蜜蜂深刻地记住了某些花可以采集。

读到这里你可能觉得有点莫名其妙，什么记忆、什么区域，没关系——前面这一堆都是过程。表结论的地方在尾句：接下来很长一段时间，蜜蜂离不开花蜜。

尾句是果，那前文就是因。谁是谁的因？咖啡因就是因——正是因为咖啡因的作用，它作为一个诱因，带来了"蜜蜂离不开"这个结果。因和果谁重要？一定是果重要，就是那句广告语的味儿：用了就离不开它。

"蜜蜂为何单恋一枝花"是一个形象表述，意思跟"离不开"一样：单恋一枝花，对应的就是离不开这种味道的花蜜。所以选C。

很多同学第一次做选AB，理由是咖啡因在前面高频出现，首句也提到了。但AB是原因，不是主题词。主题词最主要的还是看结尾。有同学要问了：老师你讲过首句可能引导主题，这不是矛盾了吗？不矛盾——第一，首句引导只是大概率，不是绝对的；第二，它也确实引出来了，引出的是"蜜蜂"嘛。所以有时候你得看完整。我讲的所有东西都不是绝对化的，一定要灵活处置。

还有选D"蜜蜂学习和记忆的奥秘"的，这就有点莫名其妙了：你的重点是"离不开"啊，选项里得体现出蜜蜂的必需条件，跟它怎么学习、怎么记忆没关系。中心句找准，答案选C。

顺便回应一个语法问题：有同学问什么叫动名词。动词就是动作，名词就是名词嘛；真想抠语法，去报中文系出身的老师的课，让专业的人告诉你。

这个题的巧妙之处在于：它本质上也是一个因果结构，只不过出题人把"因"囊括到问句里去了。你可以把C理解为"蜜蜂单恋一枝花的原因"——这个问句指的不就是咖啡因吗？蜜蜂因为难以抗拒的咖啡因，所以单恋了一枝花。把结果抓准，这个题就通了。

### 春阳社为什么解散

2023年山东这道题，大家可能也做过。先回顾旧知识点：第一句又是"春阳社"，而且从开篇到结尾，整个文段都在讲春阳社。它是例子吗？不是。这就让我们想起之前的题——上海和长三角，还有京津冀。我在第二节课里特意把这两道放在"怎么正确理解例子"中讲过。如果你听过那节课，这道题你不可能选CD：整个文段都在讲春阳社，起码要做到能不选CD就不选，除非AB有别的问题。

前面那一大堆，说实话你们短时间内不一定看得懂，我第一次看快了也不太懂这是在干嘛。没关系，考场上你一定会遇到这种情况，有技巧就用一用。比如我们讲过尾句出现结论词，真看不懂你就看尾句——虽然不能保证百分之百做对，但做对概率很高。尾句说的是"春阳社解散的原因是……"，后面看不看、看不看。反正我知道它解散了。而且"因何解散"这个表述，不就是春阳社解散的原因吗？一样的道理。

两条腿走路：第一，整个文段再讲春阳社，不考虑CD；第二，尾句有结论词，结果是解散，后面分析的是原因，那就抓结果——原因带不带无所谓。答案选A。B说的"旧时代"跟解散有什么关系？没关系，干掉。

顺便把这个背景讲清楚。王钟声最初成立春阳社，初衷是好的：想救国、想改良社会、想开通民智。可成立完之后他发现失控了——那些演员干的事情跟他的初衷并不是一致的。于是他转换了思想：既然你们不能为我做事，那就互相利用，我趁你们演出的时候赚钱，单纯把它看成一个赚钱的行为，等钱赚够了，就把它解散掉。

这就是春阳社解散的来龙去脉。我希望大家以后做题，遇到不懂的词、不懂的议论，做的时候可以先放一边，但做完之后一定要花心思把它查明白，不管是词还是议论。不要偷懒，偷懒害的是你自己。做题归做题，理解归理解，这两个都得做到位。

### 层层递进：首尾兼顾，尤其是结果

什么叫层层递进？有些文段的层次比较复杂，过程的描述非常多。这时候记住：不要被中间这些过程干扰，首尾兼顾，抓重点，特别是结果很重要。

举个例子。"好的成绩需要好的心态，好的心态需要好的身体，身体需要好的休息，休息需要好的睡眠。"

```text
好的成绩 → 需要 → 好的心态 → 需要 → 好的身体 → 需要 → 好的休息 → 需要 → 好的睡眠
└───────────── 首 ─────────────┘                            └───────── 尾 ─────────┘
```

读图说明：中间那一串心态、身体、休息都是桥面，重点是两岸——所以这段文字在讲"好的成绩"和"好的睡眠"的关系，答案应该是"好的成绩需要好的睡眠"。这有点像判断推理里搭桥的感觉。过程多的时候不用太在意，一定要抓重点、抓结果。

### 从"二时"到"四时"：冬小麦是契机

这道题我认为有一定难度，讲两个思路，注意听。

先正常看。历史早期，季节体系和农事周期之间具有紧密联系。殷商最开始是"二时"——什么意思？以前人们不分春夏秋冬，可能觉得一年只有春季和秋季，大概是这个意思。然后殷商以来对冬小麦的推广，使它嵌入到周围的生产生活之中，推动了"四时"观念的产生和演进。有了冬小麦之后，人们对待一年时间的态度从二时变成了四时，四时就是春夏秋冬。

"四时观念的产生是在二时的基础上实现的"——也就是说，四时是由二时变过来的：

```text
        二 时（春、秋）
              │
              │  完成这次跨越需要什么？
              ▼
        四 时（春、夏、秋、冬）

   冬小麦的推广种植 = 这次跨越的"契机"（契机就是机会）
```

注意这个方向不要搞反：四时是"来自"二时，而不是先有了冬小麦、二时才顺带变成四时。没有冬小麦这个东西，你是不可能从二时变成四时的。它是观念的契机，是机会。所以尾句被"所以"引导、又被"而"强调：冬小麦的推广种植地位逐渐凸显，成为人们把二时观念细化成四时观念的契机。

于是第一个思路特别简单：答案里必须有冬小麦。跟我们前面讲的口述调查那道题一模一样，你得有冬小麦。A、B没有，先干掉，在C、D里选一个更好的，难度立刻降一半。

| 思路 | 做法 | 结论 |
| :--- | :--- | :--- |
| 思路一：抓主题词 | 尾句两次强调"冬小麦是契机"，答案必须出现冬小麦 | 排除A、B，在C、D中比 |
| 思路二：比范围 | C、D都有冬小麦，就看文段还讲了什么——还有时间 | "四时"有，比没有好 |
| 思路三：用首句 | 首句已划定探讨范围：季节体系和农事周期联系紧密 | 体现"季节与农事"关系的是D |

C说"冬小麦推广种植在农业生产中的重要地位"，D说"冬小麦和四时观念的产生"。文段肯定不是只讲冬小麦怎么种植，而是它跟人们对待时间的观念有关系，不管是二时还是四时，一定跟时间有关系。所以哪怕你对文段不是很了解，D作为答案的概率也比C高。答案选D。

还有同学纠结B"二时和四时的关系"——没有冬小麦肯定不行啊。如果说有个选项同时有"冬小麦"和"二时四时关系"让我选就好了，出题人有时候也会规避这个问题，不给你开这个开心门。

再补一个来自第二节课的思路：首句还在发挥作用。第一句话已经把这个文段的探讨范围告诉你了——"季节体系的发展和农事周期之间具有紧密联系"。我在讲谁和谁的关系？季节和农事。农事就可以理解为冬小麦，季节就是二时或者四时。那选项里能体现季节和农事关系的，不就是D吗？

所以你想提高，一定要有好的做题思维。我知道改变自己很难，这就像学英语很困难，因为你们有很多固有的、不太对的观念，我相当于在让你们否定过去的自己，这东西很难接受。但你想提高，只能这样提高。如果你觉得自己没问题，那分数又上不来，那肯定有原因的——说明之前的想法不太对。

### 西风带松了，冷空气就下来了

第十题，"意在说明"。看文段不想看，但也得看。前面讲西风带本来是一个稳定的纬向气流，当气流发生波动的时候叫做槽，向北的叫做脊。西风带槽的形成和冷空气南下有关，而脊的形成往往意味着别的。到这儿你知道几个东西就行了：西风带、有槽、有脊，大概这个意思。

往后看：当脊不断向北发展，南部与南方暖空气的联系被中高纬度冷空气截断之后，形成了一个闭合的暖中心，成为阻塞高压。阻塞高压稳定少动、持续时间长，破坏了西风带，有利于波动的形成，有利于南北气流发展。尾句出现结论词"从而"——给冷空气南下打开了通道。

```text
                北：冷空气（被西风带束缚在极地一侧）
                    ↗ 脊          ↘ 槽
   ═══════════════════════════════════════════  西风带：像一根绷紧的皮筋
                    ↘ 槽          ↗ 脊
                南：暖空气

   脊向北发展 → 暖中心被中高纬冷空气截断 → 闭合暖中心 = 阻塞高压
   阻塞高压稳定少动 → 破坏西风带 → 有利于波动 → 冷空气南下通道打开
```

读图说明：西风带像一根皮筋把冷暖空气隔开，槽脊波动一旦发展成稳定的阻塞高压，这根皮筋就被撑坏了，冷空气顺势南下。

前面讲这么多干嘛？就是为了这盘醋包的这顿饺子。我想解释冷空气为什么南下，不给你讲清楚西风带的槽脊，我是解释不清楚的。所以结果是冷空气南下，前面全可以当成原因或者过程。答案选B。

你要是想慢慢排，也可以：

| 选项方向 | 问题所在 |
| :--- | :--- |
| 西风带如何流动 | 第一句的陈述，非重点 |
| 阻塞高压如何形成 | 属于前文过程 |
| "在此以前"如何如何 | 指代前文，非重点 |
| 槽和脊怎么形成、怎么波动 | 槽脊在前文，尾句已无；文段也没讲它怎么波动 |

所以选B。

有同学问得好：此题为何首句没有话题呢？其实有。这是因果文段容易出现的特殊情况，"如何"两个字相当于概括了全段。答案里有没有第一句话的意思？其实有，你把B补完整就有了——冷空气南下是因为西风带不再稳定。只是没有说清楚而已。

精彩的地方来了。这道国考真题考完之后，小红书上特别热闹，好多人说要来给你分析解析，我看着就想笑：这题有那么难吗？都是一个道理。当我看到"西风带"、看到"降温"，那不就是前面那道题吗？此时此刻恰如彼时彼刻，有什么区别？

西风带像一根皮筋，把冷暖空气阻隔开，冷空气被束缚在极地。随着一些过程，西风带松了、不再紧绷了，就会出现波动，冷暖空气交汇，中纬度本来没那么冷，冷空气下来了，中纬度就会降温。还是抓结果：结果会使中纬度地区天气过程变得极端、急剧降温。你抓"变冷"就行了。所以选"为何中纬度地区会有极端的寒潮天气"。B、C跟冷没关系；"西风带南北温差"讲的是中纬度，不选。答案选A。

就像武汉一样，怎么最近这么冷？哦，因为西风带波动了、不再那么紧绷了，就行了。这个题我花了半分钟。

### 尾句有结论词，也不是万能钥匙

第三条思维提升：哪怕尾句有结论词，也不建议大家只看尾句，一定要结合上下文。

注意，我说的"尾句出现结论词，重点关注尾句"指的是特殊情况——这道题你正常做不会做、看不懂，看了也白看，那还不如只看尾句，这是没办法的办法。但如果你看得懂，尾句就算有结论词，你也不能只看尾句，一定要结合上下文。坑就是给你这么挖的。

举个例子。"所以赵老师，你真是太让我惊讶了。"这段文字强调的是赵老师很厉害，还是赵老师很差劲？我就告诉你尾句是这一句，你选哪个？不知道。我哪知道这个"惊讶"是什么意思？你凭什么觉得惊讶就是厉害？——我给你真题，你就选"很厉害"了。所以得看原文、看上下文、放在整体里看。如果我前面说"这么简单的题目你都做不对，张老师你是太让我惊讶了"，这是消极的，选"很差劲"；如果我前面说"这么难的题目你都可以做对，所以赵老师你太让我惊讶了"，那就选"很厉害"。

再拿一道题印证。这道题刚出来的时候，某机构给的答案是D，当时我正在上线下课，有学生过来问为什么不选B。我看了一会儿，说我坚持认为选B，我为这句话负责——我绝对干过这件事情。后来果然改答案了。

这道题讲的是慕课。你看"慕课"这个词高频出现，所以选"慕课的发展理念和现状"、选"从无到有、从小到大"的同学并不多，大家基本在B、D之间纠结。当时机构为什么定D？解析说"高校的作用在尾句有点片面"，因为尾句出现了"高校、学校、社会"三个主体，很多人就觉得应该是三者并列。

但如果你因为这个原因选D，非常不符合逻辑。我从第一句开始讲的是"现代性技术和高等教育融合"，中间讲教育、讲大众、讲共识——高等教育是主要供给者、主要推动者，要加快教育怎么样怎么样——通篇一定跟高等教育有关系。我前面讲了半天高等教育，结果你告诉我尾句高校不重要了，合理吗？一定不合理。所以它大概率得有高校。

至于"片面"，是断句断错了。这个句子应该这么断：

```text
   高校的参与和支持 ｜ 学校与社会的共同努力
   └───────────────┘   └──────────────────┘
        第一部分                第二部分
```

读图说明：这是两并列，不是三并列。"学校"指的就是高校——前面通篇讲高等教育，难道还能是小学、初中吗？只能是高校。所以B一点都不片面：重视高校在慕课里的分量，选B。

### 叙事医学：尾句里的"患方"不能丢

第11题。叙事医学是一种有叙事能力的实践，而叙事能力是能够被疾病的故事所感动，这种能力有助于临床医生在医疗活动中提升对患者的共情能力。叙事医学要求医生倾听病人的叙事，关注家属的社会关系的叙事。

看到这儿你该知道两件事：第一，主题词一定有"叙事医学"（选项里都有）；第二，它讲的是叙事医学跟谁的关系——一定要被疾病的故事所感染，也就是和病人、和患者的关系。把这个地方看懂，再去看尾句，你才会注意到"患方"这个词确实很重要：获得更多的决策信息，做出正确的诊断，提出适合病人的关键决策，最后和患方共同作出决策——首先保障病人的利益，又能平衡各方的选择。

如果不看前面，你很容易忽略尾句里对患者、对病人的重要性体察，很容易选到D"有利于医学实践"。但凡选D的同学，是觉得凭"医学实践"四个字就能非常好地概括这个尾句。可为什么不片面？因为整个文段从开头铺垫了半天，讲的就是你要和患者共情、要倾听病人的故事，所以尾句的重点也一定要继续围绕患方来讲，这才符合逻辑。所以答案一定要有"患方"而不选D——"有利于医学实践"相比于"医患"而言，范围扩大了。

至于"医患共同决策"这个说法，很多同学觉得不行，那可能只是社会阅历不太够。家里人要动手术，你要签什么？知情同意书。任何大的医疗决策都不是医生能够单独下的，一定是医生和患者共同决策。所以A没有问题。"化解医疗分歧"没讲，"技术至上"更没讲到。

还有同学问：叙事医学不是对策吗？不用管。先抓主题，不要管形式。第一个是叙事医学，第二个他强调的一定是病人，你把这个意思表达出来就可以了。你是不是觉得A像一个效果？那D不也是效果吗？关注内容，不要关注形式。

### 运动干预与脑衰老：出题人把主题词拆开讲了

第12题，一样的道理。这道题我就直接讲尾句——如果你只看尾句，其实不太容易做，这题挺恶心的。运动干预、运动疗法改善老龄人群慢性疾病，你很可能想选"脑健康"。

坏心思就在这儿：出题人恰恰在最重要的尾句，没有告诉你"脑衰老"三个字。但脑衰老重不重要？非常重要，因为它就是文段开篇提的话题——脑衰老共同构成衰老特征；该领域技术和方法的应用也使得它极大地丰富和发展，在对抗衰老的过程中维持脑健康；运动可以通过改善脑衰老的生物特征促进脑可塑性。所以尾句那句"改善老龄人群及相关慢性疾病患者脑健康"，只不过是把"脑衰老"三个字拆开讲了，意思肯定是一个意思。你不能让我前面讲了半天脑衰老，结果你告诉我它讲的不是脑衰老，这可能性太低了。

所以这个题一定要先抓主题词。答案选B：运动干预在改善老龄人群及相关慢性疾病患者脑健康上的新进展和再认识。至于什么认知、记忆、新挑战、有前景，抓大放小，都无所谓——你有这些新的技术方法，是不是"新进展"？你发现它可以作为补充策略去改善，是不是"再认识"？大方向对就行。

再看结构：尾句的结论词"运动干预"是原词，运动干预是对策，脑衰老是对象——通过运动干预可以解决、或者某种程度上缓解脑衰老的问题。而脑生长、脑结构、脑健康跟衰老没关系，别人讲的是衰老。别忘了主题词的三个方法：中心句、首句、高频词——不管走哪条，都得有"衰老"。

至于"运动干预行不行"，这本来就是尾句结论词的原词，答案里明明白白写着呢。

### 回顾：转折看后，因果看果

今天主体部分到这儿，内容不算多，就是转折和因果两条腿。

转折：转折之后是重点，前面不重要。两个思维提升——第一，"事实上""实际上"表的是事实，不一定表转折；第二，转折文的答案可以是对前面的否定，也可以是对后面的阐述。

因果：总结、指代，都叫结论词。结论后重要，结论前不重要。尾句出现结论词，可以重点关注；如果文段看不懂、又在尾句发现了结论词，可以特殊情况特殊考虑，只看尾句。三个思维提升——第一，因果文段的答案经常也是因果结构，但你要记住：是因为"果"选它，不是因为"因"选它；第二，层层递进、过程繁复的文段，重在开头和结果，特别是结果；第三，哪怕尾句有结论词，在你看得懂的情况下，也尽量看完整，结合上下文，不要只盯尾句。

## 晦涩文段与细节判断题
> 对应块：BLK09 | 覆盖分集：P05上 | 块标题（分集名）：《05.【张弓言语·十二箭】》

### 先把这个认知立住：言语是不确定中的确定性

又见面了。不知不觉过了五天，今天是第五节课。今天言语做崩了？没事，慢慢来，这门课要的是时间的积淀。但在开讲之前，有些关于言语的话我必须先交代清楚——不管将来你是学生还是老师，对这门课都要有一个顶层的、正确的认知。

第一句话送给你们，这是有人说过的一句名言：**不要对你所期待的事情抱有不切实际的幻想。**

放在言语这门课上，什么叫"不切实际的幻想"？我建议大家现在就认真想一想：言语这个科目，做全对的概率其实是很低的。它跟数学不一样，跟申论倒是很像——它是一门不确定的科目，因为主观性非常强。

所以言语老师做的事情，说到底就一件：**在不确定当中帮大家寻找确定性。**我们无法预知所有的情况，也没有任何一个老师敢拍胸脯说，只要你学了我的东西，市面上所有题目都能被完美概括——不可能，我也一样。我敢负责任地讲，我讲的东西绝大部分情况是没问题的，但架不住出题人乱来。有些出题人把题出完之后一看正确率，10%几、20多，那这道题出了也没什么意义。

所以你们要做的是把握大的部分、大的方向。不要因为"老师，我做了一道题，发现跟你讲得不一样"就跑来批判一番，要看大部分情况。学言语，追求的是不确定当中的那些确定性，抓住大的部分、大的方向，就够了。

> **提示**：考场上真遇到一道明显不合常理的题，别怀疑自己一整天——它的正确率可能本来就只有 10% 几。

### 先把昨天的东西捡回来

昨天内容不多，快速过一遍。我今天的思维导图忘放了，没关系，你们自己心里有数就行。

#### 转折：两个知识点

第一个，"事实上""实际上"这一类词不一定表转折，要根据前后意思去判断。第二个，转折文段的答案，既可以是对后面的概括，也可以是对前文的否定，还可以是全面否定——三种形态都要认得出。

#### 因果：三个知识点

第一个，结论词有哪些？结论之后是重点，这是老考点。第二个，文段里如果有比较多的原因论述，选项的构成可能是一个因果结构——有因、有果、有原因分析；但注意，选它不是因为"文段有因有果"所以选它，而是因为它是准确的概括。第三个，层层递进、或者过程比较繁复的，看结果。

最后还有一个叮嘱：哪怕尾句有结论词，你也不要只看尾句；在你看得懂的前提下，依然要忠于整个文段。

另外交代一个学习方法，是我高中老师教我的：每天躺在床上，闭上眼睛，把今天讲的课在脑子里过一遍——"张老师今天讲了什么？"能回忆起来多少，就说明你真正装进去了多少。学完了别只会说"老师讲得真好"，然后忘光。

### 什么叫晦涩文段

今天讲中心理解题的最后一个知识点：晦涩文段。这一块你们一定会遇到，特别是新同学，算是赶上了。

先说我客观上的理解。我认为晦涩文段分两种。第一种是有比较晦涩的词语，说白了就是专业术语很多的科技说明文——什么酸酯氧化还原酶、什么 LPOR，你看到第一句就感觉脑袋已经炸开了。第二种不是科技说明文，但泛泛而谈、比较虚，每一个字你都认识，连在一起就不认识了。有没有这种感觉？一定有。

当然，从主观上说，每个人对"晦涩"的理解是不一样的。理科生、或者文字阅读量很大的同学，可能觉得没什么文段算晦涩；而对很多同学来说，别人读着不难的文段，到你手上就已经是晦涩文段了。所以这条线是浮动的。

那么一旦你认为它晦涩了，你对这道题的期望就应该稍微放低一点：反正我不会，那就死马当活马医，别妄想着完全做对。我先把甲叠在这儿：**我的方法不能保证你以后遇到晦涩文段一定做对**——因为遇到这种文段本身就已经很难做对了，你做对是运气好，我只是让你的运气变得稍微好一点而已。别听完课发现"老师你说得不对，这题不是这样"，这只是一个概率问题。到了这个份上，已经是在猜了，我只是让你猜得更准一点。

### 看不懂就抓主题词：高频与首句

第一个方法：一定要重视主题词的作用，特别是高频词和首句。

主题词我们一共讲过三个方法：看高频词、看首句、看中心句。那为什么这时候不看中心句了？道理很直白——我读都读不懂，你还让我看中心句？所以文段读不懂的时候，抓主题词就两条路：哪个词出现的频率最高，以及首句到底引出了什么话题。不一定准，但概率上已经比较高了。

来看这道"意在说明"的题。有同学觉得还行，有同学觉得难，各说各话，我们按不会的同学的角度来。文段一上来就是"大模型赋能生成式人工智能，引发智能浪潮"——首句给出了"大模型"和"人工智能"两个词。再往下读：大模型增强人工智能的通用性，从电影到游戏；生成式人工智能加速进化；随着技术迭代，高效聪明的大模型将渗透更多领域，有望成为人工智能技术的基座，进而带来变革；人工智能大模型强大的创新潜能，使其成为全球竞争焦点之一。你看，"大模型""人工智能"这两个词反复出现，高频坐实。

这时候哪怕你说"老师我就是读不懂"，也可以猜一次：哪个答案作为正确答案的概率更高？哪个能把它俩都涵盖进去？A 项"人工智能在大模型赋能下正在快速发展"——这咱不保证一定对，但你选 A 的概率就是比选 B、C、D 高。为什么？因为 B、C、D 都只有人工智能。有老师这么直接的吗？有，因为这就是在猜嘛。你猜都猜了，干嘛猜这么复杂？你就猜简单点——你已经在赌了，这个时候思路要变，期望值要降低。

当然这道题正常分析也不难，我认为它是一个总分结构。第三节课我们讲过："大模型"你可以理解成对策，"人工智能"是对象——有了大模型的帮助，人工智能变得更好。整个文段脱离这个意思了吗？没有：大模型增强人工智能、大模型让人工智能加速演化、大模型让创新潜能更好地释放……都是一个意思。所以总分结构，答案选 A，B、C、D 缺失主题词"大模型"，直接排掉。

> **提示**："生成式"到底什么意思？说实话我也不太懂。做这种题不懂没关系，但课后做完自己查一查，别偷懒，别指望我帮你查。

### 看不懂就看关系：尽量选"多者"

第二个方法：晦涩文段要重视多者的关系。不仅要知其然，还要知其所以然。

道理很简单：一个文段想要写得复杂，如果只有一个对象，不太可能复杂到哪儿去。它为什么显得复杂？应该是多者的关系，至少是两者——"我"和"你"怎么怎么样，"你"对"我"怎么怎么样。大家仔细品一品，有没有道理。

回看刚做的两道题。例一里是"大模型"和"人工智能"，两方面；而 C、D 项只贴到"生成式人工智能"一个方面。例二的答案"基于工业互联网的制造与服务融合"，也是两方面。所以这个规律概率很大。

于是我们对付晦涩文段有了两种手段，要结合在一起用：一个从文段出发，抓首句、抓高频；一个从选项出发，尽量选讲两者或多者关系的选项。两者叠加，作为答案的概率就更高了。

```text
看不懂
  ├─ 从文段出发：首句引出了什么话题？哪个词最高频？
  └─ 从选项出发：优先选那个讲「两者 / 多者」关系的
```

#### 制造与服务融合：首句加高频的合体示范

这道题问法是"摘要加标题"，江苏就喜欢这样出。两种方法都能用。

先按看不懂的来。首句："制造与服务融合是智能制造的重要内容之一，渗透到各个环节形成生产性服务，即制造服务化。"首句大概率给出"制造与服务融合"，后面也反复出现"制造服务""制造与服务融合"，对上了。

再看高频。第二句突然冒出"工业互联网"——读到这儿你没法马上认定它重要，这句话词很多，你凭什么认为工业互联网重要？没有依据。但再往后："本文构建的制造服务融合体系，深化了工业互联网"——当这个词出现第二遍，你就得关注了。用最朴素的想法想：这个词如果不重要，作者凭什么反复说？这就是高频词容易作为主题词的原因——不是一定，而是"反复说"在某种意义上就意味着它有点重要。

而且注意这两个"本文"开头的句子，这是典型的相同句式表并列：两个"本文"都在讲工业互联网怎么样。并列结构要全面概括、提取共性。所以答案选 D：基于工业互联网的制造与服务融合技术。

正常分析一下：开篇引出"制造服务融合"这个话题，重点是后面两个"本文"的并列。除了工业互联网，还有一个词很重要——"技术"，文段一直在讲技术、讲方法，D 项的"技术"也照上了。

别的选项为什么不对？A 项说的是"机制"，机制就是原理，文段在分析技术，不在分析机制。B 项讲那四个"驱动"（生态驱动、服务驱动、大数据驱动、物联网驱动）——有同学选 B，这四个驱动一定不重要吗？它在第一个"本文"里面，只是其中一截；你要说它重要，那四个视角（商业视角、使用视角、功能视角、实践视角）也重要，它明显只是中间很平常的一部分，没有依据，直接排掉。

> **易错点**：判断一个词重不重要，依据是"后文有没有对它反复强调"，不是第一眼缘，也不是第一眼嫌。

#### 莲子芯的叶绿素与光：新话题要格外关注

这道题我跟你们说实在话：别说你们，我都不想看。你让我看，不看个三四分钟我也看不懂，真看不明白。我这个人天赋也一般。那怎么办？猜嘛。

第一句："莲子芯发育过程中，多数叶绿素生物的表达显著上调，和叶绿素的积累模式一致。"第一句话要重点关注——这是谁和谁？莲子芯发育和叶绿素。这是第一个线索。

然后看高频。"叶绿素"这个词确实非常高频，大概率有它。

还要找新话题。第一节课讲过：后面出现第一句没有的东西，新话题要格外关注。跟第一句乍一看没什么关系、明显多出来的是——"光"。从这儿开始，"光依赖的是什么关键反应""又不依赖光"，说了一堆，读不懂没关系，跳着看就行。那就算它高频，把"光"也画上。

这时候线头就有了：跟第一句的莲子芯、特别是叶绿素有关系，而且大概率还提到光，并且尽量选一个讲两者关系的选项。答案选 C：莲子芯的叶绿素合成需要光参与。

B 项也有叶绿素、也有光，但 C 有莲子芯——稍微对比一下就知道。哪怕你最后选了 B，也已经很接近答案了。其实刚才我跳了一步：你起码可以先把 A、D 干掉，概率从 25% 变成 50%；虽然做错更难受，但已经很近了。你要一条路走到黑，就信第一句的"莲子芯"，选 C。

这个题其他选项为什么错：A 项"两种模式"是对的，但它只对应第一句，跟后面的光没关系——后面这么多跟光相关的话题，答案里不提光不合适。B 项"裸子植物依赖光反应"与原文相悖，文段说得很清楚，裸子植物可以采用不依赖光的方式。D 项"裸子植物的两个编码基因"——莲子确实有编码基因，但莲子的编码基因是 LPOR，你稍微对一下：LPOR 不是裸子植物的，DPOR 恰恰是裸子植物当中才有的东西。说"莲子有裸子植物的编码基因"，不对。

不过说句实话，我不建议在考场上这么细抠，你没时间。这题就按方法猜，猜完就过。

#### PAM 与 CAS9：两者关系一眼定答案

最后一题。如果你听懂了我刚才讲的第二点，答案几乎立刻就出来了——要选讲两者关系的。A、B 只讲一个对象（PAM 的特点、CAS 的方法），C 是 CAS 对水稻，D 是 PAM 对 CAS9，起码两个。所以你顶多纠结 C、D。

区别在哪？看 PAM 重不重要——PAM 在文段里出现得不少，"极大地限制"什么的，好像也没什么问题。那水稻重不重要？水稻只在第一句话出现。第二节课我们讲过怎么判断第一句话的词重不重要：如果它真的重要，后文是不是得反复说一说、解释一下？话题得一致嘛。结果我整个后文全在谈基因的问题，跟水稻没什么关系了。所以这个题大概不选 C，答案选 D。

这道题的中心句其实就是那句：CAS9 需要……一个 DNA 末端的保守 NGG 序列，而这个 NGG 序列就被称为 PAM 序列。CAS9 和 PAM 是一回事——PAM 就是 NGG，NGG 就是 PAM。所以 CAS9 需要 PAM，反过来说就是 PAM 对它很重要、对它的影响很大，没毛病。

> **提示**：这道题刚好接上我们讲过的考点——对策提示词"需要"引导必要条件关系。中心句读得出来的时候，还是要读中心句；读不出来，才用猜的办法。

#### 两个方法合起来用

理论要点总结一下。考场上时间太紧张，看不懂就猜，错了就错了：第一，抓主题词，重点看高频和首句——中心句你反正也找不到；第二，重视多者的关系，选项尽量选讲两者或多者的。一个从文段出发，一个从选项出发，结合在一起用。

### 中心理解收尾：常听常新

到这里，中心理解题就全部结束了。前面的四节半课，特别是新来的同学，一定要认真听，而且是常听常新。很多同学第一次听没感觉，"这什么玩意儿"，但做了一些题之后再听，会有不一样的领悟。

我讲个亲身经历。2022 年有一道公考题，我印象非常深，那道题出得非常精彩，我年后一定会给大家讲到。我每次想起它都想拍案叫绝——太妙了。而且那道题我已经讲过很多遍了，讲到第八遍、第九遍的时候，发现还可以这样讲。题目是这样，课程也是这样，很多优秀的东西是常听常新的。以你现在的认知，有些东西你觉得并不重要、引不起你的注意，但过一段时间就发现：原来是这么回事。

所以中心理解题是基础，基础打好了，后面才走得越来越顺畅。

### 细节判断题到底考什么

接下来进入第二个题型：细节判断题。我把它需要注意的东西一步一步掰开了揉碎了讲给你：审题、做题顺序、干扰项，外加一个逃不掉的基本方法。

题量与节奏：国考、联考一般考两到四个题，一道题控制在 90 秒以内。

有同学不服气："一提 90 秒，这怎么做得完？"我在这里下个定论：**言语题怎么才能做得快，只能在逻辑填空挤时间。**为什么？因为文段的长短就决定了你的基本耗时。你说半分钟做细节判断题，这还有可能；你说半分钟做排序题，几乎不可能。逻辑填空难，不代表你要纠结——那个词你不认识，你再怎么纠结也没有意义，不如干脆一点，会就会，不会就猜。逻辑填空的文段短，你要理解这个原理。

再说本质。中心理解是找重点，细节判断是看对错、看有无。所以细节判断题对大家阅读的要求，跟中心理解比是降低了的：中心理解你不仅要对，而且还必须是重点；细节判断不用管你是不是重点，只判断你到底对不对、有没有就行。

它的本质有点像"大家来找茬"：一张图是文段的意思，一张图是选项的意思，本质上就是问你这个选项对不对。它考察的就是阅读查找能力，就是基本功。所以做这种题觉得烦躁很正常；但也因为它考的是基本功，不用特别训练——你中心理解好了，这个题自然就好了。

基本方法只有一条：选项与文段一一对应。就像找茬，小仙女没什么区别，手有区别、帽子有区别，那就一个一个找。不管用什么方法技巧，这一步都逃不过去。

```text
审题 ──► 是中心理解还是细节判断？
         选是还是选非？选非先在答案处打一个叉
   │
   ▼
定顺序 ──► 读得懂 / 人文社科＋选是题 ──► 先看文段
           读不懂 / 选项短 / 选项差异明显 ──► 先看选项
   │
   ▼
一一对应 ──► 选是：优先验证温和、符合常识的表述
                        选非：优先验证绝对、对比、反常的表述
   │
   ▼
回文段取证（任何技巧都替代不了这一步）
```

### 第一步永远是审题

第一，审什么题。别把每个题都当中心理解做，每年都有这样的同学，看都不看直接做，看到题就当中心理解——那不可能。先看它到底是中心理解还是细节判断。

第二，审选是还是选非。这是细节题的特点：中心理解题也有选非题，但不多；细节判断题特别多。选是还是选非，问的是"提了的"还是"没提的"。

很多同学会犯这个错：看到提问方式"以下说法错误的是"，当时也看到了，结果做着做着忘了，把一个正确答案填上去了。一定有。所以给你一个好习惯：在你经常写答案的地方（比如我经常在冒号后面写答案），但凡看到选非题，先在那儿打一个叉，让它对你进行二次提醒。

另外我个人不建议在 ABCD 上打勾。说个真事：有同学做数量关系，考场紧张，本来想选 B，结果勾打得有点靠中间，后来忘了，纠结是 B 还是 C；而且填答题卡的时候，你眼睛看的是勾在 B 身上，答题卡可能涂了 C——真有这事。所以好的习惯是直接写 ABCD，填卡的时候转化快一些。

> **注意**：选非题先在写答案的地方打叉；写字母，别打勾。

第三，国考有个创新考法要认一下："能够解释／无法解释"，联考目前没出过，国考出过一次，先不管它。

### 文段和选项，先看谁

第二步：确定做题顺序以及选项怎么看。这个地方灵活处理，跟中心理解不一样——中心理解一定要先看文段；细节判断题没有定论，先看文段还是先看选项、选项怎么看，总的原则很灵活，你自己去试，哪个适合你用哪个。

我给两个建议角度，但凡符合一条就可以定。

从文段特征看：越难读懂的，可以先看选项；读得懂的，可以先看文段。说人话就是看得懂就先看文段，看不懂就先看选项。但有一条我强烈建议记住：如果是人文社科类选是题，强烈建议先看文段。什么叫人文社科？不是科技说明文，是社会热点话题，什么医疗、教育、交通之类的；而且问的是"下列说法正确的是"这种选是题。至于为什么，待会儿你就明白了。反过来，像莲子芯那种理科类的科技说明文，不在这条里。

从选项特征看：选项比较短、选项有明显的差异（比如 ABCD 前几个字都一样，最后两个字不一样）、或者有下面要讲的明显优先验证点——这些都可以先看选项。

来练练手，只判断顺序，题放到最后才讲。第一题"关于微型机器人，下列说法与文段不相符的是"——细节判断题，选非题；文段里什么重叠鳞片、什么蛋白，你不想看，先看选项，可以。第二题"根据这段文字，下列说法正确的是"——细节判断题，选是题；文段是"现代社会、市场经济"，人文社科类，也不长，可以先看文段。第三题不管文段是什么都可以先看选项，因为它选项很短，"前景、保障、难题"稍微记一记就行——短就好记。

> **提示**：顺序没有定论，只是建议，不强求，你开心就好。但"人文社科＋选是题先看文段"这条，我强烈建议记住。

### 错误选项的几张脸

第三步：常见干扰项。常考的四类，外加一类容易忘的，我一起说。

**无中生有。**这一类一定要忠于原文，不要靠常识。考过一道题：文段说伯乐是一个人，《相马经》是一本书——只是说了"有个人、有本书"，选项说"《相马经》是伯乐写的"。这句话对不对？不对，文段没讲是他写的。哪怕在现实生活中这本书真是他写的，文段没有讲，那也不行。做细节题不能用常识做题。

还有一层，很多人搞错：所谓无中生有，不是说没有这个词，指的是话题。考过一道题，文段在讲南极动物，选项出现了"企鹅"——文段里没有"企鹅"这个词，这算无中生有吗？不算，因为企鹅并没有脱离"南极动物"这个范畴，这道题不选它是因为别的原因。但你要把这个企鹅改成"北极熊"，那就完了，那就是无中生有。所以无中生有指的是话题上的无中生有，不要求这个词在文段里原封不动出现，它可能只是换了一种表达方式。

**偷换逻辑。**三种考法。强加因果：文段客观描述"三星手机卖得不好，苹果手机卖得好"，选项说"三星卖得不好是因为苹果卖得好"——不行，文段只是客观描述，你不能自己理解出因果。因果倒置：今天因为下雨了，所以我打车了；你不能说"因为我打车了，所以下雨了"——你是上帝吗？你打车就下雨，不打车就晴天？这叫因果倒置。

并列偷换最难理解：文段里"言语、判断、数量都很重要"，三者构成并列关系，这个时候我能不能说"言语是最重要的"？不行。注意，这个不叫片面，叫并列偷换。细节判断题严格来讲不存在片面——它不需要你概括，只需要对。言语、判断、数量都重要，难道英语就不重要吗？你可以说英语重要，但不能说英语最重要。它只是芸芸众生的一环，你不能把它的地位拔高。

**语文相悖。**就是跟原文说反了，你往南我往北，你往东我往西，你说好我说不好。

**张冠李戴。**说白了就是换了个人、换了对象，"我上岸了"改成"你上岸了"。

| 干扰类型 | 文段给的 | 选项干的 | 问题在哪 |
| --- | --- | --- | --- |
| 无中生有 | 伯乐是一个人，《相马经》是一本书 | 《相马经》是伯乐写的 | 文段没讲，常识也不能补 |
| 无中生有（话题层面） | 南极动物 | 北极熊 | 脱离原文话题；"企鹅"不算 |
| 强加因果 | 三星卖得不好，苹果卖得好 | 三星卖得不好是因为苹果卖得好 | 客观描述被强加因果 |
| 因果倒置 | 因为下雨，所以打车 | 因为打车，所以下雨 | 因果对调 |
| 并列偷换 | 言语、判断、数量都重要 | 言语是最重要的 | 把并列中的一环拔高 |
| 语文相悖 | 裸子植物可以采用不依赖光的方式 | 裸子植物依赖光反应 | 与原文说反 |
| 张冠李戴 | 我上岸了 | 你上岸了 | 换了对象 |

### 优先验证：在选项上偷点懒

最后是快速解题技巧，它建立在一个前提上：有些选项可以优先验证。

先别跟前面学杂了。前面讲的是"先看文段还是先看选项"，这里讲的是——你已经来到 ABCD 了，但还想偷懒：ABCD 我不想按 A 再 B 再 C 再 D 的顺序看，能不能先看那些作为答案概率更大的？这叫优先验证原则。

第一条，相对绝对。这个地方才讲相对绝对，中心理解很少讲。绝对表述——一定、必定、必须、只有……才……——是说话不留余地，容易被打脸，作为错误表述的概率更高。比如"要想在所学专业有所建树，就一定要有高智商"，作为错误表述的概率更高。相对表述——可能、也许、往往、大概、之一、不完全、并非——给人的感觉就很温和。有人问"张老师，明天下雨吗？"我说"明天可能下雨"——那我无敌了，下也对，不下也对，反正"可能"嘛。真题里"人与人的关系发生对抗，可能和人与自然相关"，这种表述就很可能是对的。注意，"我会在明天出差"不叫绝对，绝对的标志是"一定、必须"这类引导词；而且这里的"必须"已经不是必要条件关系了，题型换了。

第二条，对比项。这个纯粹从考情出发：从统计概率上讲，对比项比较容易是错误表述。什么"A 高于 B""A 比 B 更好"。举个例子，让你选一个正确的表述：A"事实上有利于……"平平无奇，B"处理好人与人的关系比处理好人与自然更重要"是对比项。B 作为错误表述的概率更高——注意不是直接排掉，是先不看；反而应该先看 A。

第三条，表述与实际相符或不相符。这个多少可以有点常识，特别离谱的不用细想。选项说"吸烟有益健康"，这是"以下说法正确的是"，你敢选吗？不敢，它大概率不对。真题里 A 项"农业保险能预防天气"大概率不对，B 项"褪黑素有助于睡眠"大概率对。

总结一下：这个题要选正确答案的时候，优先验证温和的、符合常识的表述；要选错误答案的时候，优先验证绝对的、对比的、不符合常识的表述。但一定记住：**只是优先验证，并非直接锁定答案。**因为再怎么优先验证，它永远代替不了回到文段去对应这一步。你只是先看谁，该看到的还是得看到。

最后留一道题练这个思路："以下对文段理解最为准确的是"，A、B、C、D 优先看谁？A 有"只有……才……"，在细节题里算绝对；B"无法降低"，也很绝对。所以先看 C 和 D——它俩出答案的概率更大。注意只是概率：万一这个题就很恶心，C、D 就没答案，那你还是要老老实实把 A、B 再对一遍。C、D 其实都可以先看，D 更好一些——刚才说过，选项本身带有某些特殊标志的，可以优先验证它。

### 本讲提到的题目

**一、意在说明：大模型与人工智能**

文段大意：大模型赋能生成式人工智能、引发智能浪潮；大模型增强人工智能的通用性，从电影到游戏；生成式人工智能加速进化，高效聪明的大模型将渗透更多领域，有望成为人工智能技术的基座；人工智能大模型强大的创新潜能使其成为全球竞争焦点之一。选项：A 涵盖"人工智能"与"大模型"两个主题词，B、C、D 只讲人工智能（其中 C、D 只讲"生成式人工智能"）。

答案：A。依据：总分结构，"大模型"是对策、"人工智能"是对象；B、C、D 缺失主题词"大模型"。

**二、摘要加标题：制造与服务融合**

文段大意：制造与服务融合是智能制造的重要内容，渗透各环节形成生产性服务；随后两个"本文"开头的并列句都在讲工业互联网角度下的制造服务融合体系与技术。选项：A 讲"机制"，B 讲四个"驱动"，C 只有"智能制造"，D 为"基于工业互联网的制造与服务融合技术"。

答案：D。依据：首句给出"制造与服务融合"，高频词为"工业互联网"与"技术"；A 的"机制"与"技术"不符，B 的四个驱动只是其中一截。

**三、莲子芯发育中的叶绿素与光**

文段大意：莲子芯发育过程中多数叶绿素生物表达显著上调，与叶绿素积累模式一致；后文大量出现"光依赖／不依赖光"的论述，并涉及 LPOR、DPOR 等编码基因。选项：A 讲两种模式，B 讲裸子植物依赖光反应，C 讲莲子芯的叶绿素合成需要光参与，D 讲裸子植物的两个编码基因。

答案：C。依据：首句给"莲子芯／叶绿素"，高频词"叶绿素"，新话题"光"；B 与原文相悖（裸子植物可采用不依赖光的方式），D 张冠李戴（LPOR 属于莲子，DPOR 才是裸子植物的）。

**四、PAM 与 CAS9**

文段大意：文段从水稻起笔，后文全在谈基因；中心句为 CAS9 需要 DNA 末端保守的 NGG 序列，该 NGG 序列即被称为 PAM 序列。选项：A 只讲 PAM 的特点，B 只讲 CAS 的方法，C 讲 CAS 对水稻，D 讲 PAM 对 CAS9。

答案：D。依据："需要"引导必要条件关系，CAS9 需要 PAM；"水稻"只出现在首句，后文未再强调，重要性不足。

## 细节判断题的抓法、误区与取舍
> 对应块：BLK10 | 覆盖分集：P05下 | 块标题（分集名）：《05.【张弓言语·十二箭】》

可能文段里"淀粉样蛋白"这个地方有个 β，我打字打掉了，讲义上也没粘上——贝塔这种特殊字母，粘贴的时候就是容易粘掉，那是我的问题，不好意思，不影响，咱们接着来。

先拿手边这道"下列关于数字孪生的说法与文意不相符的是"练个手。ABCD 四个选项，按我们刚才讲的，你应该先看哪个？别的都还一般，但 B 项必有一个"最新"——是不是有点绝对？所以你可以先看 B。记住这个感觉，待会儿这道题还会回来。

### 优先验证只是"先看"，不是直接选

这是我今天要强调的第二块内容：关于选项的优先验证。能不能理解它不是直接选，只是优先看某个选项而已？能理解，咱敲个一。

有同学问得非常好：优先看的选项，如果你选出来了，其他答案还看不看？不看不看。**细节题是唯一一个——你但凡确定某个答案就是答案，别的你不用看了。**别的题型一般都得看完整。为什么？因为你做细节题很多时候就是先看选项的。大家把这个点记住。

当然，前提是"很确定"。不确定就再看一看，别拿这句话当偷懒的挡箭牌。

### 抓选项关键信息：只抓"别的选项没有的"

正常做的时候，他给了你四个选项，很多同学找的时候就感觉没有抓手。那我们做细节题有一个原则：**尽量抓某个选项中比较特殊的字词。**

举个例子。ABCD 四项摆在这儿，你要把选项拿到文段区一一对应。我抓"学业"这个词行不行？有同学说：我发现 A 项有个"学业负担"，所以老师我先抓"学业"行不行？那肯定不行——你 ABCD 不都是学业吗？那都没用。

所以你要尽量抓特殊的：A 项有个"主客观"，B 项有个"历史现实"，C 项有个"社会的各个层面"，D 项有个"基础教育"、有个"缓解"——就抓这些别的选项没有的。听懂了吧？这是个小的原则，但特别实用。

```text
拿到 ABCD 四个选项
  │
  ├─ 找特殊：只抓「别的选项没有的」字词
  │    学业（四项都有）              → 没抓手
  │    主客观 / 历史现实 / 基础教育   → 抓手
  │
```

### 常见误区与对比择优

#### 细节判断题，片面能不能选

我说过：细节题严格上不存在片面。**片面跟你这个答案能不能选，没有必然关系。**大家把这句话记住。它不需要你概括，只需要对。

一个一个看。文段是"既爱言语，也爱数字"，选项是"既爱言语"，行不行？行。文段说既爱言语也爱数字，选项是"我只爱言语""我最爱言语"，行不行？不行——这叫什么？这叫并列偷换。文段给了好几个并列的东西，你把其中一个拔高成"只""最"，那就死了。

#### 范围适度扩大、缩小能不能选

不一定。以后再不要跟我说什么"扩大可以、缩小不行"，你要很朴素地去看它到底成不成立，这有点儿像判断推理的思维。

文段说"张老师是湖北人"，选项说"张老师是中国人"——相比于湖北人，是不是稍微扩大了一些？对，这个可以。但反过来就不对了：文段说"张老师是中国人"，选项说"张老师是湖北人"，缩小就可能不行。于是有同学悟了："老师，扩大可以，缩小不行！"真的是这样吗？看下一题。

文段说"老师需要了解学生的心理"，选项说"言语老师需要了解学生的心理"——相比于"老师"，这是不是范围缩小了？那这个表述对不对？对。有同学喊"无中生有"——你们判断是跟谁学的？言语老师算不算老师？算。他既然算老师，那肯定不算无中生有啊，而且你言语老师也是老师嘛。很简单：我说"老师讲课要动嘴"，跟"言语老师讲课要动嘴"，不矛盾吧？所以这个方法的缩小就是可以的，因为你言语老师肯定属于老师。

但你要反着来就不行了：文段只说"言语老师需要了解学生心理"，你答案里能选"老师"吗？那就走远了。我说"言语老师得懂成语"，难道所有老师都得懂成语吗？数学老师得懂直除，难道所有老师都得懂直除吗？不管你是扩大还是缩小，都不一定，你得看具体情况——用判断的思维、属性集合去判断。这块你们应该比我懂，我就不解释了。

#### 适度联想的选项能不能选

文段说"张老师感冒了，很难受，难以专心上课"，选项说"张老师感冒了，对生活造成了极大困扰"。这个对还是不对？不一定。

因为这就是我想传达给大家的点：**言语是一个非常灵活的学科，对于一句话的理解，每个人是不一样的。**有同学说，你作为一个老师，你不能上课，那当然叫极大困扰；还有人觉得，你只是不能上课而已，你该玩玩、你该追电视剧，那好像也谈不上"极大"吧？我说的有没有道理？是不是很像你们做细节判断题的感觉——这个选项模棱两可，你说对吧也没那么对，你说不对吧也不是那么不对，反正就是很烦。

#### 对比择优：不要当完美主义

这种时候怎么办？对比择优。注意，思路一定要扭转：我们这个题让选正确，不是说这个答案就没有任何问题，而是说这个答案的问题最不明显，或者说它和文段最接近；如果他让你选有问题的，不是说只有他有问题，而是说他问题最明显、表述最不相符。

这个思维能不能扭转？就不要当完美主义。**完美主义永远做不好言语题**——其实任何事都是这样，这个社会也不完美，没有什么东西是完全完美的，只要是人出的题。就像刚才那个例子，你觉得他是错的，那就有人觉得是对的，所以我们只能取一个最大公约数。

### 一道数学题：约半数与三分之一

来，做道题。这道题问的是"以下概括不符合文意的是"，最后剩下 B、D 两个，你选谁？

先说 D。有很多同学觉得："老师，这个'约半数'是哪来的？我整个文段都不知道有多少个国家，我只知道全世界有 100 多个国家在勘探。你这玩意儿考我常识？文段也没告诉我全世界一共多少国家，我哪知道这 100 到底是不是一半。"OK，不重要。为什么？来看 B。

各位同学，请在脑袋里面召唤你的数学恩师。文段说：大陆架的石油储量超过世界储量的 1/3。我们做一个简单计算——海底石油储量 2500 亿，约等于 1/3 世界储量，也就是说 1/3 的世界石油大概是 2500 亿；那大陆架是多少呢？1400。这个 1400 能够超过 2500 吗？能够超过世界石油储量的 1/3 吗？

悟了没？这 B 能选吗？肯定要选 B——因为它是找不对的嘛。这是数学问题，没那么复杂：你 1/3 的世界储量是 2500，你大陆架是 1400，那大陆架怎么可能超过世界储量的 1/3？

所以：这个 D 我不知道对不对，你别问我，我不知道；但是我知道这个 B 一定不对。B 一定不对，那我就选 B，我管你 D 对不对呢。听懂了吧？

> **提示**：考场上一个选项能被算术直接证伪，就别再纠结另一个选项"好像也不对"——板上钉钉的那个就是答案。

### 细节判断题方法小结

第一个，审题——审题型和问法。第二个，顺序总的来讲比较灵活：看不懂就先看选项，看得懂就先看文段；或者说选项有一些明显的角度，也可以先看选项。第三个，选项怎么看：

- 找特殊：找别的选项没有的；
- 有些选项可以优先验证——对比项、绝对项、常识不符项，大概率是**表述错**。注意，不是"错误答案"，是表述错；万一这个题问的就是错的，那就选它了。大概率表示对的是相对象和常识相符项。只是优先验证，只是验证，不是选。

干扰项那一串再顺一遍：与文相悖不能选；偷换概念就是张冠李戴——我分手了，你不能变成我恋爱了，这不行；偷换逻辑，强加因果、因果倒置；并列偷换也不行。最后一个关于无中生有，一定要注意：**适度推断、适度联想、适度扩大缩小的选项，并不一定不对**，要对比择优。来，咱们敲个"悟了"。

我们今天的知识点就到此结束，接下来做题。说句实话，细分类其实题目没什么意思，老师也没放太多题，主要是讲方法。

### 真题演练

#### 穿山甲与微型机器人：选非题先抓特殊

第一题，"下列关于微型机器人的说法与文段不相符的是"——第一步审题，选非。这个题不想读，那就不读嘛，看选项，找特殊。第一个抓什么？鳞片和穿山甲都可以。在哪儿呢？第一句是穿山甲，第二句是鳞片——穿山甲能把鳞片组成重叠结构，工程师据此设计出了一个拥有重叠鳞片设计的微型机器人，相当于就是拟物嘛，学习穿山甲，好像是对的。

第二个抓什么？"灵活机动"——第一句没有，第二句有"灵活"，后面还有"可以到达人体难以触及的地方"，灵活机动好像也对。

第三个："治疗能力已在临床中得到验证"。在哪儿呢？前面都在讲原理，最后是"在概念验证实验中……未来可用于……"。概念验证实验说明什么？说明还没有落地。所以大概率选 C。

这时候 D 你看不看看不看？不看的——只有细节题可以这样，前提是你很确定 C。当然你说我不确定，那就再看一看：D 项是"可用在微创手术中进行止血"，稍微找一找，文中其实分两个部分讲了——用于在人体内的微创，还可以进行热疗和止血，别人提到了，所以选 C。

#### 现代社会与市场经济：先看文段的惊喜

还记得老师在这个地方埋的一个线索吗？这种题为什么我建议大家先看文段？这是人文社科的选是题。因为有的出题人呀，他可能也不知道怎么回事，出题比较乱。他有一种出法，叫做**细节主旨化**：你看起来好像是一个细节题的问法，什么正不正确；但是呢，你发现这题的答案不仅正确，而且符合中心。它给你惊喜——其实你光正确就够了，哎我不光正确，而且契合中心。

所以这种题，当你把文段看完之后，发现这个文段的中心句挺好找、挺好看的，你是不是可以先看一看有没有选项符合这个意思？

另外说一句：看细节判断题文段的时候，需要像看中心理解文段那样很仔细吗？不需要什么结构层次层层分析。你就算是先看文段，也只是先大概浏览。这道题前面讲了很多，说什么现代社会、陌生社会，可能不太一样；然后"因此"嘛，迫切需要；尾句有个结论——法律的作用远远超过熟人社会的习俗、礼节与乡规民约。你看完之后是不是感觉好像法律很重要？答案恰好是 D 项——它不仅对，而且还符合中心。就这么巧妙。

这里一定会有同学问：哪来的"现代社会的人际关系"？我闭着眼睛不用看弹幕都知道。意思就是：在古代是熟人社会，你可能一辈子都出不了这个村，你的人际关系是熟人的关系；而现代社会的人际关系，是一种陌生人的社会交往——比如你不认识我，这叫现代社会的人际关系。你说他不在讲交易吗？无所谓，交易也是社会的人际关系，难道交易不是关系吗？比如你们在这儿看我上课，或者你花了钱买我讲义，这就产生了人际关系，当然产生呀。

当然你要是不服气，没关系，你别的更不能选。A 项"插叙格局"——文段没有。想知道什么叫差序格局，可以去看费孝通的《乡土中国》：人的关系像一个同心圆一样，从近到远、由近到远，这叫差序格局。B 项"市场经济需要习俗、礼节和乡规民约"——这不是与文相悖吗？文段恰恰反驳了这个观点，他说法律的作用远远超过了习俗、礼节和乡规民约，说明这玩意儿在现在不重要。C 项"熟人社会是以家族亲属关系为主轴的"——别人在讲现代社会、讲陌生人社会，压根没有详细介绍熟人社会，排掉了。你还追着 D 吗？不纠结。

#### 贝塔淀粉样蛋白：先把 A、B 放一边

讲义上这道题，问"最为准确的是"。这个题是不是不想读？而且老师刚才分析过了：A 项有一个"只有……才……"，B 项有一个"无法"——你就先看 C、D 嘛。

C 项"大脑血液含量不足会导致人醒来后头脑昏沉"，对不对？什么时候会昏沉呢？看文段："之后大脑里没有那么多血液才能……"这也解释了为什么人一觉醒来会清爽，而熬夜会……所以这个文章告诉你，大脑里没有那么多血液，它是好还是不好？其实大脑的血液不太多，还挺好的——你太多了反而容易昏沉，就我们说太多容易"上头"嘛。所以 C 项与文相悖。

那看 D 项："大脑中贝塔淀粉样蛋白会影响人的状态"。这个 D 极有可能就是答案——就算我不看文段，也能知道它极有可能是答案。为什么？不是因为这个贝塔，是因为"影响"这个词太温和了。哪怕你只有 0.00001% 的影响，我是不是也能叫影响？我哪怕只有 0.0000001% 的影响，它也叫影响，那当然会影响了呀，什么都可以影响。而且文段确实也说了，它这个玩意儿是一个副产品，你把它清除之后，就会头脑清爽；它太多了就不好，太少了就好。所以 D 是对的。

这时候如果你确定了答案是 D，你就不用看 A、B；不确定你再看。这是考场思维。比如说 A 项"只有睡着后才会分泌吗"？别人是"随即进入"，不是"分泌"，偷换概念。B 项说大脑血量"无法降低"——文段讲的是，人醒着的时候，大脑不会让大脑血量降到足够低，不是"无法降低"，是"无法降到足够低"。而且它还违反常识：你清醒的时候去医院扎一针抽血，我拿根针在你大脑里抽一抽，那不就降低了吗？你肯定有办法嘛，怎么可能无法降低呢？所以答案选 D。

#### 数字孪生：板上钉钉的 B

第八题，"下列说法与文意不相符的是"。刚刚说过，先看哪个？先看 B——"最新"。是不是最新呢？不好意思，文段说了，数字孪生不是全新的事物，但它一定不能选"最新"。所以哪怕你纠结 A、C、D，这个 B 是不是一定错？这时候你就千万不要再纠结 A、C、D 了，就像刚才江苏那个石油题——这个 B 已经板上钉钉了，没得洗，洗不白了。考场上你完全不用纠结，直接选 B，其他不用看，别看，浪费时间。

讲课的时候稍微对一下：A 项"本质是真实物体的模型"，在这儿指的是虚拟空间的模型，对；C 项"与物理对象保持关联"，文段是该模型通过传感器获取真实数据，并随之一起变化——"随之一起"不就是关联吗？同义替换。最后一个，因模型和真实物体的关系得名——孪生兄弟嘛，所以也是对的。

#### 设施农业：答案为什么偏偏是 D

第九题，"与文段意思相符的是"。先看文段还是先看选项？其实都可以，这个文段也没那么难读。简单读：主要粮食供给充足，但是资源环境有约束；现在是农业，能够怎么怎么样；还可以利用现代技术、生物技术等方式突破限制、拓宽时空、规避风险。

我们举一反三：如果这个题是一道中心理解题，哪个词是主力词？它在讲谁的优点、围绕谁来讲？是不是"它"？是不是整个后面全在讲它的效果？所以答案选它（D）。当然真正做不需要这么做，比较麻烦，我只是讲原理。

验证一下 D："可以突破资源环境的制约"——是不是就在这儿，突破资源环境的限制？第一句讲粮食，你可以理解为问题；这句话你可以理解为对策。而且粮食也是一种资源嘛，虽然 D 没有明说，但这并不是中心理解，我只是讲原理。

A 项"应用广泛"有被讲到吗？他后半句"供给充足"确实有，但"应用广泛"没有——设施农业只能用在农业，你怎么"应用广泛"呢？B 项"向现代经营管理方式，构建了多元供给体系"——注意，这叫张冠李戴，概念的混搭：B 的前半句"现代经营管理方式"是一个点，"多元供给体系"是另一个点，这俩好像没什么关系，杂糅了，所以他也不行。C 项"解决育秧难问题，需建设工厂化育秧设施"——哪里提到了"育秧难"？别人只是说要包含育秧设施，没有说育秧难，这叫无中生有。

> **提示**：这道题恰好示范了"细节主旨化"的兜底用法——真在考场上遇到两个选项都觉得对，优先考虑契合文段中心主旨的那个。文段就是围绕现代设施农业的一系列优点来讲的，D 一定比 A、B、C 更重要。

#### 气压变化：一个"影响"直接走人

第十题，"下列说法正确的是"。文段看不看？好像不太想看。那有没有可以优先验证的？别的不知道，B 项"最先"我不想看——你是选正确，你如果选错误，那就看 B 了，所以可以先看 A、C、D。而且经过我们刚才的学习，咱们得吃一堑长一智：刚刚还做了一个"影响"是正确答案的选项，你又看到了一个"影响"，是不是得先看一看？尊重一下。所以大家可以把它补在自己的笔记里面：**"影响"这个词非常地温和。**

来看："气压变化通过下丘脑影响人的精神状态"。文段在这儿——下丘脑因气压变化受到刺激时，自主神经功能紊乱，导致精神不佳。有没有影响？那当然影响了，这就导致精神不佳了。行了，走走走，莫停留。有人问：反了吗？没有反，他只是稍微变化了一下——"我帮你提高成绩"和"你通过我提高成绩"，不是一个意思吗？

别的简单看一看。A 项"交感神经负责使人进入放松"——别人是"战斗"，不是放松，相悖了。B 项"气压变化时人最先感知的是前庭神经"——那不是半规管先感知吗？然后再传递给前庭神经，这也不对。C 项"副交感神经过度活跃，使人产生焦虑"——文段是交感神经过度活跃，身体处于紧张状态，产生焦虑感；C 项虽然说有个"使"字，但其实问题在这个"副"上，偷换概念。

#### 司法建议：谁最不像好人

第十一题，选非。这个题虽然是人文社科的文段，你看也没毛病，没有任何毛病；但它是选非题，所以不存在细节主旨化的情况。那这个题有没有"长得就不像好人的"？B 项有个"不会"，C 项有个"避免"，D 项有个"更"——说实在话，B、C、D 都不太好，都算不上什么好人。但是你让我找一个最离谱的，就是你不选 C 你觉得合理吗？

C 项"有效避免社会矛盾产生"。咱们是不是学过马克思主义？社会的进步就是矛盾产生的呀，你没有矛盾怎么进步呢？结果你告诉我可以有效避免社会矛盾——这简直就是违背规律，这就不行。

所以你可以先验证 C 项。当然你不是直接选，你先看 C 对不对。你说老师文段中好像有一个词叫"预防"——对，但是你看仔细了：对案件审理过程中发现的可能影响社会和谐的隐患或因素提出建议，以预防纠纷再次发生；预先找准，找出矛盾纠纷产生的原因。别人只是找出原因而已，不是"有效避免"；你如果非得说避免，顶多是避免"发生过的东西再次发生"——他顶多是你犯过的错不要再犯，是预防再次，而不是能够完全避免矛盾发生。这个就太宽泛了、太违背常识了，就是"吃一堑长一智"的意思。

那如果你不服气，就看一看 A、B、D。A"范围在扩大"，在文中，没问题；B"不会弱化权威"，别人说得很清楚，进一步提升权威，没毛病；D"是一种更柔性的"，"更彰显人文关怀"——都关怀你了、天天给你嘘寒问暖了，这不就是柔性吗？同义替换了一下。所以肯定是 C 项。

#### 额尔齐斯河：一道送分题

最后一个题，"提及了什么信息"。四川今年的题有点恶心，我也做了一做，正确率 80 刚出头，给大家报备一下——但不是说所有题都难，有的题其实很简单，这个就很简单。

这种题我把它称为"故事会"——我戏称这种题的文段叫故事会。你看一看没毛病，外力也不难，就当长见识了。然后选项呢：额尔齐斯河、阿拉别克河、乌伦古湖、哈巴河，明显都不一样，找就行嘛。

第一个"额尔齐斯河河流出国位置"——第一句只说它一路向西流出国境，有没有说具体位置？好像没有。你觉得拿不定就看第二个："阿拉别克河河流长度"——文中只说与他汇合，然后就再次西行，没有说长度，无中生有，排掉。第三个"乌伦古湖的气候"——提到了乌伦古湖，但只说了很多鱼，没说气候。那就选 D 嘛："哈巴河的发源地"——"其支流哈巴河发源于哈萨克斯坦境内"。答案选 D，这题就送分题。所以也不是所有题都那么难，有的题比较规矩。

### 答疑时间

说到答疑，让我想起了昨天那道下丘脑的题。有同学结课还问我：怎么答案是 D 呀？我感觉答案是 A。我按照 A 给你跟你去圆，我给你圆了半天，怎么我一看，有的机构答案是 D。所以那个题大家以后就不要纠结了，那是一道比较老的事业单位的题，机构答案不一样，可能是道争议题，不管它。来，我们接着来看今天的问题。

#### 首句到底是观点，还是引出话题

有同学问：为什么有时首句提观点是重点，有时候首句只是引出话题？根据什么判断？我建议你回顾我们第一节课和第二节课，特别是主题词的部分。首句引出话题这个技巧，老师一直强调——虽然我觉得方法很好用，但它不是所有情况，它只是个概率。那到底你首句提出的观点只是引出话题、一个平平无奇的话题，还是重点？取决于后文。如果你后文继续围绕首句话题讲，它就是观点。

所以老师讲过一句话：你在一个文章看完之前，能不能判断第一句话、或者说第一句话的某个词重要还是不重要？不行，你只能猜。因为本质是句子和句子之间的关系，你一定要看完之后才能做出最终决断。

#### 纠结与提速：时间只能从逻辑填空里省

有同学说言语套题特别纠结，今年模考 30 道题做了 37 分钟，83 分。这可以——30 题 35 到 40 分钟，这就是 80。至于后面题目时间不够，我讲过：首先我没时间做；其次，**言语快，只能在逻辑填空上快。**你想提速，你和后面非逻辑填空是提不了速的，因为文段的长短就决定了你的基本耗时。一定要在逻辑填空提速。我比较早的时候上过一些线下课，逻辑填空题，国考连考 15 道，8 到 10 分钟内做完是非常有可能的（说 8 分钟怕吓到你）。你如果想把言语多拿分，就剩下 20 分钟，你去做后面的 15 道题，这是有可能的。这是时间安排的问题。

#### 快与准：先求准，再求快

有同学问：将文段意思结构理清需要花 2 分钟，还不一定对；但如何快速扫读，又会忽略关键信息。如何培养考场思维，如何快速又准确？

这个点我其实今天想讲。快速和准确，在考场上来讲，它是一个鱼和熊掌的关系；但是对我们每位学习的同学而言，一定是先追求准确，再追求快速，否则就是"假快速"。所以你在平时做题的时候，一定不要偷懒，你哪怕多花时间，把结构和意思理清楚；当你见多识广了，你就一定能做快。有一句话叫"操千曲而后晓声，观千剑而后识器"——别人拿的是 1000 个呀。你的快速，一定是建立在见多识广的基础上。如果你没有建立在你懂了、有一定正确率的基础上，一味地求快，那就是乱做。

真正的高手是因为他见得太多。就像我上次讲的那样，他看完第一句大概知道第二句干嘛。就像我昨天讲的那个例子，我看到那道西风带的题，虽然是 2026 年的题，我马上就想到了 2022 年重庆那道题——那我怎么可能慢呢？那些做多了你自然就懂了，自然就快了。

#### 为什么低正确率的中心理解题不用看

有同学说最后那题他有不同想法。这个题我刚才讲过了，是一个争议题，后来查了一下，有的机构答案是 D；而且这是一道比较老的事业单位的题，不管它，不纠结。还有一道题答案是 B，有同学不理解，觉得 C、D 都是模棱两可的感觉——这个题我看了一下，正确率 25%，太低，不管。你能懂当然更好，你不懂不重要。

为什么正确率小于 30% 的中心理解题基本不用看？大家想象一个道理：一个文段写出来，让 70% 多的人都理解错了意思——这是出题的问题，还是你的问题？你不会写文章就别写，你不会出题就别出，你干嘛跟他纠结呢？而且是这样：我们公考是不公布答案的，所有你能看到的中心理解题的答案，是市面上所有的机构和老师自己写的。所以之前出现过一个很有意思的情况：当年有一道题，全国各个机构都说答案选 B，后来有一年出了一个公告，把这个题作为例题放在了公告上，结果公告的答案好像选的 D 还是 A，把所有的机构都打脸了——但那个题从我们理论来分析，确实不该选这个。

所以大家一定要记住：中心理解题确实是有争议的，可能我们不管是谁，包括我自己、包括其他老师，答案也不一定是真正那个答案，因为他不公布。但是逻辑填空也好，语句表达也好，答案一般是没什么问题的，因为这些题它有原文，是根据原文去挖的。

#### 第一反应，还是第二反应

有同学说：第一遍做题选正确，找到对应词了，一看其他选项就开始纠结。首先，纠结就意味着能力不够，就像刚才讲的，二选一纠结跟你四选一纠结没什么区别，肯定有问题——暴露问题是好事，正常总结提高就行。第二个，如果你非要老师给一个方法论：大家可以有意识地统计一下自己做题的情况——我的第一反应选的答案正确率更高一些，还是我纠结之后的第二反应选的答案正确率更高一些？每个人的情况可能不一样，因为每个人的语感是不一样的，有的人第一反应更好一些，有的人第二反应更好一些。统计一下，感受感受。

#### 血清钠那道题：一个理解 B 的思路

最后这道题，我先叠个甲：我没有看错答案，这个题正确率只有不到 20%，大概 16%。我不想让所有人都讲明白，我并不想达到这个目标，我只是合理地探讨一下。

文段第一句是"血清钠及血钠"——人体水分充足的时候，钠就会下降，反之就会上升。你看，第一句话不仅引出了钠，还有水。然后为了防止结果出现偏差，他就开始多次做实验。结果：血清钠处于正常范围内高位的人，与处于范围内中位的人相比，生物学衰老的迹象更加明显。什么意思？读不懂没关系，他用清晰易懂的话给你说了——他们的心血管更容易出现问题，更容易出现体内炎症。这个"他们"是谁？是高位还是中位？是高位。另外，在正常范围内，血清钠水平越高，越容易出现心衰、中风、房颤等等疾病，以及各种很高的风险。是不是一个意思？就是你钠的水平越高，我就越容易得病，身体就越不健康。

那这就可以把它理解为一个问题。怎么办呢？如果你的水分充足，你的钠的含量是不是会下降？所以这个题的逻辑就变成了：水喝得多 → 钠低 → 身体不生病、健康。根据我们第四节课讲的首尾关系：水是第一环，钠是第二环，身体健不健康是第三环。答案 B——"足量饮水有助于降低疾病风险"，首尾关系。D 是水和钠的关系，跟健康没关系，是第一环和第二环；而 C 和 A 跟水没关系。所以答案选 B。

为什么不选 A？因为水确实有关系，但你可以把文段理解为一个提出问题的结构——钠高了就是不行，而第一句话告诉你，水分充足，血钠含量就会下降，反之就会上去。你还可以把这个题理解为文段开篇提对策，它只是不是一个很典型的对策类形式：当你水喝得多，钠就会下降，然后再告诉你下降之后身体会变好。为什么只看首尾不看中间？建议你回顾一下我们第四节课。

再说一遍：**这个题我没有想说服你**，我只是给你一个理解 B 的思路。30% 以下正确率的中心理解题，你不用纠结，能接受就接受，不接受算了——16% 嘛，没有任何意义。
