## 选词填空（三）：分组思维、关系判定与搭配积累
> 对应块：BLK31 | 覆盖分集：P17上 | 块标题（分集名）：《第三节：2026选词填空（三）L~T（47-69》

这一讲的开场题就把人噎了一下：奶皮子和糖葫芦组了个组合，题目问这个组合精准______了（年轻人的）某种心理。四个候选词挨个试——契合、击中、捕捉、匹配——搭配都得当，意思都合理。这种第一空不是不好做，是根本没法做。

怎么办？把笔先放下，换个空。

这就是本讲的主线。从第55题一路讲到第62题，招式其实是一条链路：当常规突破口失灵时，你手里还有分组思维、转折与解释关系、固定搭配、形象表达这几张牌。下面一张一张说。

### 分组思维与排除法：第一空失灵时怎么办

第55题，第一空四个"精准+动词"的搭配全都通顺，与其在这里纠缠，不如去找意思差别大的空。第三空尤其好做，因为它摆明了是分组思维的菜。

先把四个选项按语义分两组：

```text
第一空：契合 / 击中 / 捕捉 / 匹配  ── 搭配都得当，意思都合理
                ↓  先放下，换空
第三空（分组思维）：
    A、B 组 → 随便、草率、单一、单纯  （核心：没想那么多）
    C、D 组 → 奢侈、高昂              （核心：很贵）
                ↓  回原文找线索
原文线索：「为此花费数十元」——又没有打双引号
                ↓
数十元称不上"奢侈"，更称不上"高昂" → 整组排除 C、D
```

数数看：你站在2026年的语境里，当然可以说它性价比低，但十块钱你跟我说"高昂"？换个说法——你听完课回家跟你爸说"给我十块钱我要买个东西"，你爸要是回你"十块钱这么多"，那你赢，我认输。我现在十块钱连一份黄焖鸡都买不了。我们不是说具体买什么东西，就单看这个金额，它一定称不上奢侈、称不上高昂。原文要改成"数百元"，那倒是可以商量；就"数十元"，还带着真情实感不打引号，C、D我真选不下去。

排除完还要验一遍关系，因为这个题A、B放在这儿是说得通的：注意分析它的意思，前后并不是顺着说，而是一个相反的关系——"不是一种简单的消费，而是犒劳自己的小确幸"。花钱已经不单纯是花钱，还带着犒劳、带着仪式感，有一些目的、有一些心思在里面。既然要表达的是"没那么单纯"，第三空就得取"随便、单一、单纯"这一组，A、B自然浮出来。

> **结论**：第一空全部说得通的时候，不要硬做，去找意思差别大的空；差别大就值得用排除法，一排一组地排。

### 负累与煎熬：词语是有轻重的

第三空排完了，回来看第二空，一对词摆在那儿：负累、煎熬。这组不用讲道理，你自己感受——快节奏的现代生活中，你排了三个小时的队，闭着眼睛，脑袋里蹦出来的第一个词是哪个？

"这三个小时我是怎么过的？"——是煎熬，不是负累。

负累是负担，这个词太重了，一定是承担了很大的、很重的任务才配用它。我每天晚上得上两节课、站六个小时，那可能算一种负累。而煎熬就是"熬"：这三个小时你其实什么都没干，就那么站着、坐着，大家都排过队，海底捞门口拿手机刷着，干等着——这种空转的等待才叫煎熬。

有同学问：那"浪费""虚耗"呢？我觉得这两个词也可以选。但还是那句话，第三空把"奢侈、高昂"整组排掉之后，能跟"单纯类"第三空搭档的，就是"煎熬"那一项，答案选B更好一些。

> **易错点**：意思接近的词不能只靠"都说得通"来选，要先比轻重（负累重、煎熬轻），再用别的空做交叉验证。

### 转折关系：两个空一起看，选"相反"最明显的那组

第56题，"南有上海滩，北有天津卫"这句话记录了天津的______。单看第一空，它其实没有线索——就像守株待兔那道题一样，只要你言之有理就行：盛名、辉煌、荣光、地位，填哪个都不算错。

可它后面跟着一个"但"：天津人的早点却非常______。

转折关系一出来，马上该反应过来——空隙关联。转折前是第一空，转折后是第二空，这两个空必须相反，才撑得起这个"但"。所以别只看第一空，也别只看第二空，两个空一起看，看哪一组词最适合"相反"。

```text
第56题（转折）：「但」字一横 ──────── 两空必须相反
      辉煌（顶点、鼎盛、康乾盛世）   ✕   平民（接地气、偏低、贴近群众）
                        谁相反最明显，就选谁

第61题（解释）：破折号一通 ────────── 两空必须一致
      价值观的对齐             ═══   与价值观相契合
                        横线修饰的是同一个东西，意思就得一样
```

最合适的是"辉煌"配"平民"：辉煌是顶点的感觉，鼎盛时期、康乾盛世，哇哇塞，很高大上；而"平民"这个词本身就是最接地气的，地位上没有皇帝那么高，偏低、贴近生活、贴近群众。这两个词摆在一起，相反的感觉最明显。

其他选项逐个过：地位的反义词难道是"本地"吗，肯定不是；荣光的反义词是"多元"吗，多元的反义词是"单一"，也不是。A项的盛名与辉煌差不多，可它配的"生活"不如"平民"好——生活化和平民化哪个更低？哪个更低选哪个，平民更低嘛。这里必须先说清楚：这不是批评谁，就题论题，没有任何拉踩，谁也不要上纲上线。"生活"这个词其实很中性，帝王将相有生活，《红楼梦》里贾宝玉、林黛玉、薛宝钗也有生活，王侯将相有生活，老百姓也有生活；单纯从地位性的角度讲，它的指向没那么明显。而基层相对于顶层就是偏下，这一切都是相对而言的——你明白这个意思就行。

所以前半段是极度的辉煌、高大上、漂亮范，后半段早点却很平民化，老百姓都吃得起，这个反差就出来了。

第三空还能再验一次，因为它内部也有个转折：前面说无论什么油、什么茶汤面，主材都是一样的，就是简单的面和水，在强调一致性；后面自然要落到不一样——最终口味迥然不同。"各有千秋"也有不同的意思，但那个"不同"没那么强烈，只能说尚可；"和而不同"一般形容人际关系，君子和而不同嘛；"别具一格"是形容某一种有独特风格，可这里的主体是三种。三种放在一起，就是迥然不同，答案选B。

### 阶段搭配：词语有自己的"出场时间"

第57题比较简单，基本第一空就能定。"2025年是巩固发展5年过渡期的最后一年，越是这个时候越要______"——"最后一年"对应的是最后关头，这就好比11月份参加国考，时间已经推到10月1号，快要进考场了，这时候要体现的就是"最后"的感觉。谁带"最后"的意思就选谁：慎终如始。甚至哪怕你不认识这个词，只看它有个"终"字，也只能选它。

有同学不服：你凭什么盯着"最后一年"看，你这是上帝视角、拿答案反推；我看的是"扛稳责任"，我觉得要稳，要稳就该步步为营、要稳就该行稳致远。

两个理由回敬这个质疑。第一，慎终如始本身就有稳的意思——他很谨慎，到了最后还很稳、还很谨慎，简直像韩老魔一样太稳了，谁说慎终的人不稳？第二，也是更要紧的：步步为营、行稳致远这类词，一般是什么时候用的？是大学同学刚准备备考的时候——"老师我参加明年国考""我参加明年联考""我刚开始学"——这种时候我才说同学们一定要步步为营、一定要行稳致远。你都快考试了，还跟我说要行稳致远，你远个啥呀。绵绵用力，指的是连续不断、长久的坚持。这三个词一般都用在做一件事情的起始阶段，放在"最后一年"这里就是不搭。

> **提示**：词语除了意思，还有"出场时间"。表长久、表进取、表铺垫的词多用于开局；表收尾、表坚持到最后的词才配终点。

顺便纠一个一知半解的误会。有同学以为"步步为营"是贬义词——你记错了，你以为的那个词是"按部就班"。按部就班确实带贬义色彩，指非常老套、非常守规矩、不灵活不变通；当然它也有中性的用法，中性起来跟步步为营差不多。为什么学不好？一半的原因就是一知半解，拿一个词的印象去套另一个词。

### 固定搭配：这类词记住就是分

第58题第一空，"勤劳智慧的黔东南人民始终______与大自然万物共生的传统"，几个词意思都差不多，共用一个字，考的是规范性——"信守"不行。信守一般搭配承诺、诺言，是忠诚地遵守的意思，它不搭配传统。

第二空则是纯粹考固定搭配。你如果在A、C之间纠结过，不用纠结，记住就行：看到水源，就直接"涵养水源"。

```text
涵养水源  ←→  不能说"滋养水源"
     │
     ├─ 涵养：作名词指有教养；作动词多指积蓄、保持水分，也能指控制情绪
     ├─ 好处：不光"存起来"，还有"为它好、对它好"的意思
     └─ 滋润：只能形容湿润，或形容日子过得舒服滋润——不能搭配水
```

2024年联考刚考过这个搭配：湿地在净化水质、涵养水源、调节气候、维护生物多样性方面有不可替代的价值。"积蓄"水分不是不可以，但它只是单纯存起来；"涵养"不光要存，还有一种为它好、有好处的意思，所以更恰当。"滋润"不能搭配水，它要么形容很湿润，要么形容日子过得很滋润。"滋养水源"更是说不通——水源全是水，还需要你滋养吗？滋养一般指增添水分，或者过得舒适，多用在让人享受舒服的语境里。

这题但凡做错或者纠结过，把`涵养水源`这个搭配记住就行。它就像`筚路蓝缕`配创业一样，只要别的空没问题，优先考虑它。答案选A。

### 时政热词搭配：没有线索，就只能靠记

第59题是那种我不太喜欢、可每年一定会有的题：热词搭配、时政热词，纯考积累，或者说是考你所谓的"正确的语感"——你知道就知道，不知道就不知道，没什么道理可言。现在本来就要考政治理论，那部分跟着小黑好好学；当然不是所有题都这样，只是个别的题会长成这样。

学两个点。

第一个点：内涵一般怎么变？往"多"里变。所以"理念内涵不断______"，丰富、扩展都可以；内涵不"升华"，内容怎么升华呢，一般不这么用；内涵也不太会"深化"——深化是朝着更深的方向发展，这个词最适合形容的是"改革"，也用于跟变化相关的某件事情持续深化，内容一般不用深化。

第二个点是本题最大的陷阱。"落实机制不断______，推进路径更加______"——有同学一看"路径"眼睛就亮了：路径不得变宽吗？老师你教的形象表达呢！我选C（宽阔）！

此路非彼路。这里的推进路径，指的不是现实的道路，指的是方式方法——我到底该怎么做、我怎么推进、我怎么采取行动。就像我的slogan：道路对了就不怕遥远。意思是你很清楚这条路该怎么走，不是你的路走宽了；咱们又不是玩人情世故，说什么"路走宽了"。举个身边的例子：听完我的课，你的学习路径怎么样了？你会说学习路径更宽阔了吗？宽什么宽，是更清晰了，知道该怎么学了。选词填空说到底就是两件事：意思的正确性和使用的规范性。所以这里是路径更清晰，不是变宽，没有这个意思。

有同学追问：那不是还有个"机制健全"吗，拿它当线索推不行吗？推不出来。这题靠记，不靠推理——机制是机制、内涵是内涵、路径是路径、合作是合作，几个部分各说各的，没有意思上的对应点，只能考虑搭配。不听课想上岸，该积累的还是要积累，政治常识、言语都得学。

第三空还有个非常好的词：______发展鸿沟。答案是弥合。这个词第一次见确实不容易想到，所以这体现的就是刷题的重要性——2025年天津考过"数字金融能够弥合区域群体间的数字鸿沟"，人民网也说过要弥合差异。弥合特别适合用来抹平差异，而所谓鸿沟，重点就在那个"距离感"上。

| 词语 | 用在"鸿沟"前的问题 |
| :--- | :--- |
| 跨越 | 说明沟还在，你只是跨过去了，事情做得不彻底 |
| 修补 | 一般搭配要修缮的对象，是把它变得更好的意思 |
| 消弭 | 指完全消失，没有"填"的感觉；多搭水患、怒气，消弭隔阂可以，但不搭鸿沟 |
| 弥合 | 有填补的感觉，正对"抹平差异"，是最佳搭档 |

把`内涵丰富`、`机制健全`、`路径清晰`、`弥合鸿沟`这四个搭配记住，当成时政文段去记。它们一定会反复考。另外提一句"通达"：选它，说白了还是把路径当成了具体道路，而这个地方说的是方式方法，不是具体的路。

### 形象表达：人才是苗，乡村是土

第60题第一空，人才振兴是乡村全面振兴的______。"加强乡村人才队伍建设是应有之义"这句话是对策，通过它就知道：人才对乡村振兴一定是非常重要的、非常关键的，把这份量表达出来就行——源头、核心、基础都带这份意思。A项"标杆"是榜样，学习标杆、行业标杆，我们说它不是榜样，是重要，排掉。

第二空，"聚焦引贤等关键环节，在引贤、留才、育苗上怎么发力"——精准发力、集中发力、气势发力、持续发力。这一空没有线索：文段给了一连串对策，你从其他地方找不到到底该怎么发力，没有意思的对应点，合理即可，几个词都说得通，不必强分高下。

好戏在第三空。高校培育人才，融入乡村全面振兴，激活动能、赋能乡村振兴，让现代化人才在全面振兴的______中建功立业。

问谁找谁。你问的是"全面振兴的______"，而文段翻来覆去就说一件事：要人才，要加强人才队伍建设——引贤、留才、育苗，要凝聚人才，人才还要扎根美丽乡村。这提示点已经非常明显了。它想表达的是：乡村振兴一定要培育人才。

这时候该想起我给你们讲过的六字真言了——水、路、药、房、土、看。这六个字是经常用来出形象表达的六个意象，不是说你见到它们一定考，而是见到要警惕，知己知彼：

| 意象 | 常一起出现的形象词 |
| :--- | :--- |
| 水 | 源源不断、千帆竞发 |
| 路 | 另辟蹊径 |
| 药 | 对症下药、药到病除 |
| 房 | 与建造、支撑相关，如独木难支 |
| 土 | 与植物相关，欣欣向荣、蓬勃发展、扎根 |
| 看 | 与眼睛相关，坐看、遥看、虎视眈眈 |

拿这个题对：它明显是要培育人才，人才就是苗；那苗在哪儿扎根？扎根美丽乡村——乡村不就是土吗？土才能育，土才能育苗。所以要在乡村全面振兴的沃土中建功立业。不是蓝图，不是画卷，更不可能是温床——温床是贬义色彩的，直接出局。

蓝图、画卷这类词其实更"聪明"，更强调未来的建设、比较美好的东西，意思上也不是不行，可它不形象：你都要扎根了，这东西就得是土。觉得牵强的同学，是题见少了。形象表达是我们专门的一个考点，不是随手那么一绕。

### 解释关系：破折号两边要一致

第61题不容易，而且它跟前面某道题隐隐相像，很多同学反应不过来——反应不过来的点，就在第二、三空必须一起看。

第一空：人工智能技术飞速发展，逐步向人类智能水平逼近，科学家们在研究过程中愈发清晰地意识到，许多棘手的问题并非单凭一家公司之力就能成功解决。"并非……就能解决"，说白了就是解决不了。那么"除了至今______的电车难题之外"，举的例子必须对应"无法解决"——第一空最好的词就是悬而未决。这题如果只有一个空，我也选悬而未决：前面主旨在论述的不就是这个问题没有解决吗，没解决就是悬而未决。"老生常谈"是经常说，可经常说不一定没解决；"束手无策"太重了，那是一点办法都没有，我们只是没有定下来，不代表完全没办法；"争论不休"起码跟不解决有关系，可以保留，但没有悬而未决直接。

第二、三空才是本题的真身。"日益重要的价值观的______"——修饰价值观；"又该如何确保这些AI的目标符合人类利益，与人类的价值观相______"——还是修饰价值观。两个横线修饰的是同一个东西，这是空隙关系；更妙的是，第二空和第三空之间有一个破折号，表解释。什么叫解释关系？十二经里讲过，前后内容要一致。所以第二空和第三空的意思应该一样。

这就跟天津那道题正好反过来了：那道题是转折，两空得相反；这道题是破折号解释，两空得一致。

哪一组词最能体现一致？就算把B和D都加上，也得是C：对齐、契合。契合就是符合，正好呼应前面的"符合人类利益"。其余的对都不上号：构建和吻合意思不一样；践行是做事情，另一个空说的是有偏差，也不一样；匹配作动词，是找到相对的事物相互配合，同样不是一致的意思；束手无策放在第一空也不对。答案只能选C。

顺便说一句，别觉得这道题比"路径"那道题容易——它的正确率其实并不高。

### 既要又要：不能分开的两者

第62题是这一讲的收尾，比较清爽。两者______：小将心态、大将风范。没有前者，容易因循守旧；没有后者，容易浅尝辄止。翻译翻译就是：你既要有前者，又要有后者；不能没有前者，也不能没有后者——既要又要，不能分开，不能单独存在。答案就是相辅相成。

弹幕里有人又选了C，我一看，怎么又选C了？正确答案是D项"相辅相成"；这两个词如果没有D，C倒也可以凑合，但有D就选D。

这题有没有让你想起另一道？"车之两轮""车之两翼"——两个轮子、两只翅膀，缺一个都转不起来、飞不起来。这类结构在200题里专门讲过，放在一起记：凡是文段说"没有前者就……没有后者就……"，那就是在告诉你两者缺一不可，选表达"相互配合、缺一不可"的那个词。

从第55题到第62题，这一讲的招式串起来就是一条链：先看哪个空的意思差别大，能分组就分组排除；排不掉就看关系，转折要相反、解释要一致；关系也看不出来，才轮到拼积累——固定搭配、时政热词、形象表达的六字真言，都是记下来就能反复拿分的东西。脑子里有这条链，考场上就不至于盯着第一空发半小时的呆。

## 选词填空的四个抓手：近义辨析、搭配对象、提示点与用法边界
> 对应块：BLK32 | 覆盖分集：P17下 | 块标题（分集名）：《第三节：2026选词填空（三）L~T（47-69》

如果给我一个"相辅相成"，我一定会选相辅相成——那为什么这道题选的是 D 呢？先别急着记答案。这道题卡住的人，问题几乎都一样：把一对近义词当成了同一个词。今天这一讲从第 62 题收尾开始，一路做到第 69 题，难题不少，64 题在隔壁题库的正确率只有两成多。把这些题摆在一起看，会发现选词填空的抓手其实就那么几个：近义词的分界在哪里、横线到底搭配谁、文段把提示点藏在哪、以及有些词根本不是意思不对而是用法不对。

### 一道"我肯定会选，但答案不是我选的那个"的题

先回到第 62 题。文段说得很清楚：没有前者也不行，没有后者也不行。两样东西都必不可少，这指向的就是"相辅相成"。

很多同学纠结的是它和"相得益彰"的区别。记住，这两个词首先是一对近义词，都强调互相配合，区别只在一个地方——能不能分开。

| 词语 | 关键区别 | 能不能分开 |
| :--- | :--- | :--- |
| 相得益彰 | 互相配合，效果更好，$1+1>2$ | 能，分开照样做事 |
| 相辅相成 | 互相配合，缺一不可 | 不能，少一个就不行 |
| 遥相呼应 | 远远地照应 | 能，都"遥"了自然分得开 |

男女搭配，干活不累，这叫相得益彰——两个人分开做事，照样行。可你考公务员，行测和申论是相得益彰还是相辅相成？一定是相辅相成，少考一门你就上不了岸，这就叫缺一不可。

至于"互为表里"，这个词要求极其苛刻：它说的是同一个事物的两方面，一表一里、一内一外。这么多年只有 2019 年联考考过一次，答案落在"互为表里"上（形式主义与官僚主义那一组）。本词还考过"内外关系"这一层意思。文段里这两样东西并不是同一个事物的表里，也不是远远照应的关系，所以只能选 D。

> **结论**：判断"相辅相成／相得益彰"，只问一句——这两样东西分得开吗？分得开是相得益彰，分不开是相辅相成。

### AI 选股与同质化交易：一道"疑似在金融市场跌过跟头"的题

第 63 题一读就觉得有意思：若投资者广泛采用相似的 AI 大模型选股，会导致投资策略趋同，容易出现同质化的交易行为。能出这种题，很难不怀疑作者在金融市场跌过跟头。

#### 第一空：三个词都能表达"做法趋同"

一哄而上、千人一面、趋之若鹜，这三个词都能表达做法的趋同：大家一起上，一千个人一个样，或者都去追热门、追热点、追涨杀跌。意思上都成立。

随声附和也有跟随的意思，大方向没错，但它重在言论——你形容的是交易行为，是做法，所以它不如前三个合适。这里没有别的意思，就是做法相同。

#### 第二空：囤积和集中可以，套牢不行

第二空说大量资金怎么样在同类资产当中。都在一个地方，你可以说囤积，也可以说集中。但"套牢"这个词不对。

套牢是专指买入之后股价持续下跌，导致被迫持有——我想卖，但怕割肉，不愿意卖，只能拿着。文段里没有价格下跌的意思，它只是单纯说资金都压在这一个资产上，所以套牢用在这里不成立。

#### 第三空：羊群效应放大的到底是什么

第三空最好做。文段说这不仅可能使原有策略因过度拥挤而失效，还会加剧市场的羊群效应。什么叫羊群效应？一窝蜂跟风，要买大家一起买，要卖大家一起卖。

这时候去看选项，正好有两项是相反的：追涨容易吹大泡沫，杀跌容易造成亏损。可羊群效应难道只能导致泡沫？难道只能导致亏损？两个都片面。泡沫和亏损，都只是波动的表现形式；它既可能放大泡沫，也可能放大亏损，所以最全面的是"波动"。大家都开心的时候是泡沫，都不买的时候是亏损，而这两件事都是波动。答案选放大波动那一项。（震荡其实也说得通，但选项摆在那里，只能选 B。）

> **易错点**：看到两个选项互为反面，不要急着二选一——先问文段有没有把范围砍掉一半。砍掉了，两个都不选，选那个能同时罩住两者的上位词。

### 声音权的侥幸心理：为什么正确答案率只有两成

第 64 题难度很高，第一空乍一看不好做，可以先看第二空。

#### 第二空：胆子是怎么大起来的

文段说声音无形，一些人便误以为有操作空间，这也成了部分商家通过 AI 训练伪造声音的心理诱因。

什么叫有操作空间？跟前面对应一下：肖像这东西大家比较敏感，谁用了我的脸，我一眼就看得出；可用某个人的声音，没那么明显，这就有了侥幸心理——觉得自己好像不会被抓。于是有人就明目张胆，有人投机取巧，有人堂而皇之，胆子大起来了。

巧立名目不行。这个词的重点在"名目"：为了达成一个目的，先虚构一个民意、找一块旗帜、找一个借口。文段里不需要立名目，所以排除。

#### 第一空：横线搭配的是肖像权，不是肖像

第一空是"肖像权因为肖像直观可见，而更容易被理解和____"。很多同学选"识别"，因为看到了"直观可见"。

这里要停一秒，问一句：这个横线到底搭配谁？前面我们已经反复强调过——分析的时候要同时看两件事，一是意思，二是搭配。找错了搭配对象，你对意思的把握也会跟着出问题。

直观可见的是肖像，肖像确实更容易被识别。可横线前面的主体是肖像权，权利不能直观可见，权利是能被理解、能被重视的。你不会说"识别权利"，也不会说"感知权利""维系权利"——维系一般维系关系、维系人际，权利无从维系。所以只能说"重视这个权"：我重视我的肖像权，也重视我的声音权，因为大家都知道这东西很重要。

> **提示**："问谁找谁"是选词填空里最省力的一条铁律：横线前后的修饰语是背景，真正的主语宾语才是搭配对象。把修饰语当成主语，是这题唯一的坑。

这道题的完整思路可以画成一张图：

```text
句内呼应：意思与搭配，两手都要看
                  │
        ┌─────────┴─────────┐
        ▼                   ▼
   这条横线            这条横线
   该表达什么意思      到底搭配谁
        │                   │
        └─────────┬─────────┘
                  ▼
        先锁定主体，再挑词
                  │
      ┌───────────┴───────────┐
      ▼                       ▼
 主体是"肖像"            主体是"肖像权"
 直观可见                权益可言
 → 可选"识别"            → 只能"理解／重视"
```

读图时抓住一条：词的意思再贴切，主体对不上也白搭。隔壁题库这道题的正确率只有 20% 多，错的人几乎都栽在把"肖像"当成了搭配对象。

### 破除三种心态：鸵鸟、看客与过关

第 65 题说，要破除三种心态，一空一种。这种题中规中矩，只要词的意思扎实就能做对。

#### 鸵鸟心态：自己骗自己，不是避重就轻

第一种是鸵鸟心态。不听不听，逃避，装作问题看不见，像鸵鸟一样把头埋起来，以为看不见就不存在——这是隐瞒、是掩饰、是自己骗自己。掩耳盗铃、讳疾忌医、自欺欺人都有这个意思，都能选。

避重就轻不行。文段里没有"重"和"轻"的区分：他连无关紧要的都没谈，全埋下去了，什么都不做，所以无所谓避重、无所谓就轻。

#### 看客心态：作壁上观、隔岸观火为何落选

第二种是看客心态。看客就是这事跟我没关系、跟我关系不大，把反面教材当成别人的事。

单看第二空，作壁上观和隔岸观火其实比"事不关己"更好——更形象。你看到一个"看"字，优先考虑"观"这个思路是对的。但这是个多空题：事不关己虽然不够形象，意思却是对的；而且那一项的第一空也已经被排掉了，所以只在剩下两项之间考虑。

敷衍了事也不行。这个词说明事还是做了，只是应付；而看客是啥也不做。

#### 过关心态：得过且过，不是听天由命

第三种是过关心态。过关就是只求赶紧过去、只求无过：错就改错，改完就翻篇，不考虑做得多优秀，也不指望得到表扬。这对应的就是得过且过——只要能过去就行，而且这里头有主观能动性，我还是想过的。

听天由命太消极：那是关都不想过了，爱咋地咋地。可文段起码还要过关，既然要过关，就说明你还得做点事。

把过关心态放进具体场景里更好懂：犯了错误，要深刻反省为什么犯错，要追问内心有没有把人民群众放在心上、有没有真正为人民服务；而不是写个检讨，等领导忘了这事就算完。后者就是过关心态。

> **提示**：如果这题只给第二空，我会挑作壁上观或隔岸观火；但多空题要整体看，答案选 C。单空择优和多空联排，思路不一样。

### 史诗类电视剧的"应有之义"

第 66 题第一空是"史诗类电视剧可以被作为一种文化的____"。后面确实在解释：它的目的不仅是呈现文本，还要向观众传递社会价值和思想观念。

第一空那几个词意思差不多——呈现、表现、展示、再现，都落在"表现"上，单纯辨意思不好做，那就先放一放，还有第二空这个成语。

第二空是：经由历史重现，向观众传递正确的社会价值和思想观念，是史诗类电视剧创作的____。还是那句话，问谁找谁——横线前面那一长串是修饰语，横线的主体是"这一做法"。这一做法是什么？往前找对应点，文段已经告诉你了："其目的不仅是呈现文本，而且是向观众传递社会价值和思想观念。"既然是我的目的，那就是我应该做的事情，就是应有之义。

不是金科玉律——那类词表示不可更改的准则法条；也不是不二之选——它的意思是优秀，是没有别的可以比得上。顺带记一个近义词"一时之选"：这不是"我临时的选择"，而是在这一时期当中最好的选择。文段强调的既不是优秀，也不是不可更改，而是目的，所以选 D。

### 既要立说立行，又要久久为功

第 67 题一读就很熟：树立正确的政绩观，既要以立说立行的锐气抢抓机遇，又要以久久为功的韧劲发展根基。典型的总分结构，开篇一个中心句，后面围绕两点展开，和国考题的路数很像。这种题做多了就有感觉——所谓熟读选词三百道，不会出题也会下笔。

#### 第一空：形容机遇的词与形容时间的词

立说立行，强调的是机遇要抢抓，赶紧的，别拖了，有一种紧迫感，要的是"快"。稍纵即逝、时不我待，都合适。

白驹过隙不行。这个词出自庄子，画面很浪漫：两堵墙中间夹着一条缝，像一线天，有人骑着白马"唰"地就过去了，你还没反应过来，马已经不见了——人生如白驹过隙，忽然而已。人到三十多岁再读这句，确实有点伤感。但它只能形容时间本身，你不能说"机遇白驹过隙"，搭配不当。

千载难逢也不行。它强调的是"难得"，是不容易遇到，跟快慢没有关系。

#### 第二空：安之若素与持之以恒，差在一个"久"

如果只看第二空，很容易在安之若素和持之以恒之间纠结，因为两个词都带点"定"的意思。但安之若素用在什么领域？是遇到困难、遇到危险的时候，内心没有慌乱——庄子那句"知其不可奈何而安之若命，德之至也"，说的就是这个境地。它跟快慢没关系，跟"久久为功"更没关系。

文段要的是久久为功，你不光要"定"，还要"久"，所以选持之以恒。

这里还藏着一个结构信号：这种"既要……又要……"的表述，两空之间往往存在相对或相反的关系。我们做过太多这类题——既要自信，又不能太自负。放到本题，就是既要快一点，也要慢一点：立说立行是快，久久为功是慢，快与慢正好对应。词与词之间是能看出空隙关联的。

> **易错点**：安之若素不是贬义词，它只是跟"慢"搭不上；判断它出局，靠的是"与上文对应不上"，不是感情色彩。

### 地理学科的外延：一个逻辑学概念救场

第 68 题也可以先看第二空，因为第一空不好做。

#### 第二空：外延就是外在表现形式

文段说，正是这门学科的外延如此____，地理的学习才成了一个复杂的系统工作。

单看"复杂"这个词不好做，因为它既可以理解为多，也可以理解为乱，几个选项都沾边。所以要往前看这门学科的特点：地理既可以指山川水文、地形走势、气候要素，也可能指行政区划、人口分布、风俗习惯。既可以这样又可以那样，那就是"多"，而且没有任何消极意味。所以第二空要表达的是"丰富"，"宽广"也可以。

不少同学在这里卡住，是因为不懂什么叫外延。做判断题的时候应该见过这对概念：

| 概念 | 是什么 | 三角形的例子 |
| :--- | :--- | :--- |
| 内涵 | 反映事物的本质，相当于下定义 | 由三条线段首尾相连围成的封闭图形 |
| 外延 | 所有具有这些属性的对象，即外在表现形式 | 等边三角形、直角三角形等所有三角形 |

外延是表现形式，当然可以用"丰富"来形容；抽象和模糊两个词偏消极，也不是"多"的意思，排除。

#### 第一空：转折关系，加上"不做副词"的用法禁区

第一空在"看似和地理关系不大，却____决定了地方发展模式的人文要素"这里。看似没关系，一个"却"字转折，后面就该是"有关系"——实实在在决定了那些要素，一无一有，正好相反。

那为什么不选不言而喻？意思其实是对的，都有"确定"的意思，问题出在用法。你把词带进去读一读："却又不言而喻地决定了""却又不容置疑地决定了"，是不是很怪？这两个词一般单独用、后置——"决定了地方发展模式的人文要素，是不言而喻的"，这样读才顺。它们一般不做副词，不去修饰一个动作。

潜移默化则是意思不对：它表示慢慢的、默默的、不怎么明显，跟前面的"关系不大"是同向的，根本构不成转折。

> **结论**：A、B 两项是用法不当，C 项是意思不对。分清楚这两类错误，排除时才有底气。

### 山水画的命名与阐释：线索藏在"最全面"三个字

第 69 题也挺难。唐代画家几乎不会用"行旅""早行"之类的词给山水画命名——在唐代乃至更早，没有真正意义上的山水画，一幅画里可能既有景色又有旅行又有山水，画家不会做那种特别直接的命名。

#### 第一空：直观不能用于命名

直接、准确、明确，放进去都说得通，不好判断。但"直观"是用法不当。直观是能直接感受到的意思，比如画一张图，大家看起来很直观；这个词不会用在命名上。你不能说"我命名的很直观"，也不能说"我对你进行直观的命名"——我爸妈给我取名，也不会说对我进行了直观的命名。所以第一空先排掉直观。

#### 第二空：深入浅出、身体力行、条分缕析

第二空是说《林泉高致集》《山水纯全集》这些著述____地阐释了山水画的要素。先把三个词的侧重弄准：

| 词语 | 意思侧重 | 能否入选 | 原因 |
| :--- | :--- | :--- | :--- |
| 深入浅出 | 浅显易懂 | 否 | 文段没有"易懂"的提示 |
| 身体力行 | 亲身体验 | 否 | 主体是两本书，不是人，书无法"力行" |
| 条分缕析 | 细致而有条理 | 是 | 对应前文"著述兴盛"与"最全面" |

身体力行最好排：横线的主体是两本书，它们又不是人，怎么能身体力行？有同学问"艺术实践"那一项——可主语是这两本书，说它们与艺术实践相关，指的是书里涵盖的画家实践很多，但"身体力行"的主体必须是人，书怎么实践呢？

剩下就在深入浅出和条分缕析之间。这题有线索，只是比较隐晦，要往前看：前文说宋代绘画著述的兴盛——兴盛就是画画的人很多；后文说这两本书是"最全面的教科书"。既然很全，就一定是该说的都说到位了，说得细，这才叫条分缕析。深入浅出是浅显易懂，跟"全"没有关系——光凭"深入浅出"，你怎么知道它到底是说得多还是说得少？

至于"分门别类"，它也有"多"的感觉，用来排第二空反而不好排；所以必须先把第一空的"直观"钉死，答案才能锁定 D。

#### 同源思路：2023 年国考那道农书题

这题的逻辑跟 2023 年国考一道题一模一样（那道题在 200 题里讲过）。那道题说：历代农书里涉及最多的就是施肥。什么意思？只要关于施肥的知识，我这里都有——在哪施、怎么施、该施什么、每个环节干什么，我全告诉你。这就是"完整"，也就是条分缕析。

反过来想那个题就更容易明白：如果你只看到"教科书"三个字，那符合书的词有一大堆；可文段从来没说那本书容易懂，它只说"全"。选词填空一定得依据文段本身的意思来做，不能靠脑补——谁说教科书就一定是通俗易懂的？每本书特点不一样，这本书的特点，文段写得很明白：最全面。

> **结论**：选词填空中心理解化。横线处填什么，答案往往不在横线附近，而在文段对主体的那几句定性里。

## 选词填空（三）：词语边界、搭配对象与文段结构
> 对应块：BLK33 | 覆盖分集：P18 | 块标题（分集名）：《第三节：2026选词填空（三）L~T（47-69》

### 评论区四问：先把词语的边界捋清楚

#### 落后、滞后，不等于"一定能赶上"

第46题的最后一空是"无法发展到更高级"，有同学盯着"落后""滞后"较劲：既然只是落后、滞后，那将来不是还能发展到高级吗？强调的不是"无法"吗？

这就是对这两个词有误解了。滞后、落后表达的只是一种"没有靠前的位置"——位置在后面。它并不蕴含"我一定能够赶上"的意思。我说我低级，不等于说我一定能发展到高级，这个逻辑不成立。

放回原文看：有人认为某些种族由于种族原因就更低劣，就只能停留在低级——你要把这个意思表达出来就行，别自己给它加一层"将来会赶上来"的戏。

另外，这道题第一空只能填"累进"。昨天最后也说过：除了"自然"不对，"加速""演变"也不对。"加速"是有快有慢的，文化发展不是加速的过程；"演变"是不断变化，像一条直线，意味着所有文化都是相同的轨迹，那也不是演变。所以第三空要是实在磕不下去，从第一空做，一样能把题做出来。

#### 彗星来过之后，警示还算不算警示

第32题第一空，有同学问：前面说彗星是不祥的，人们看到彗星联想到瘟疫战火，可瘟疫和战火还不知道来没来，这能算"警示"吗？

不能这么想问题。彗星肯定不是只来过一次。很可能之前彗星来过之后，正好发生了瘟疫和战火，这些事情被人记载下来、被人记住了；所以下一次再看到彗星，人们马上就会想到那些可怕的事情。警示就是来之前说的东西——正因为灾祸可能在后面，提前示警才叫警示。

而且这一空说白了就该取一个偏消极的词。"联想"本身是中性词，放进来也通。古人讲天人合一，认为彗星是上天给人类示警，这个说法放在这里是没毛病的。别往"还没来所以不算警示"上绕。

#### 如臂使指与如鱼得水：形神兼备，以神为先

第35题，有同学问：如果没有"如臂使指"，能不能考虑"如鱼得水"？

很多学员偏爱这两个词，原因是外形——都带个"如"字，看着就像答案。但选词要形神兼备，而且以神为先，形其实没那么重要。不能因为看到一个"如"字，就觉得这个词一定好。

"如鱼得水"形容的是进入了一个很舒服的状态，它跟"指挥"没什么关系。如果非要在几个词里挑一个，它勉强还行，但绝谈不上好；跟"指挥"能够对上的，肯定是"如臂使指"更好。正常情况下，这一空不选"如鱼得水"。

#### 公园搞创新：公益与商业不是地位相等

第28题，有同学问：文段说要在公益属性和商业开发之间达到平衡，那不就说明两者地位相等吗？既然地位相等，怎么会谈得上本末？

这个问题有代表性。关键在于：我们不是要新建一个公园，而是对公园的业态进行创新探索——公园本身就已经在那儿了。所以"平衡"这个动作只发生在"创新"这个环节：想玩点新花样的时候，才需要同时顾着公益和商业。

最能定性的是这一句——"挖掘商业价值而忽视了其原本的公益属性"。被忽视的只有"原本的公益属性"，没有"原本的商业属性"。公园最本质、最原本、最基本的属性就是公益：哪怕什么花样都不玩，它照样可以作为大家休闲娱乐的去处，这本身就发挥了公益属性。只不过架不住有的城市想创新、想与时俱进。

所以两者并不是地位相等的关系。公益是主要的、是初衷，只是在创新探索时才谈兼顾，不能背弃主要的去看次要的。答案选B。

### 入侵网络之后：没有对应点，就选一个更合理的

第47题。文段大意是：利用网络漏洞入侵，以窃取数据信息这种方式相当的隐蔽，而窃取往往会使数据的安全响应____。后面还有一层：网络中流转数据的规模很巨大，来源也非常复杂，攻击者一旦掌握网络漏洞、入侵网络之后就可以____，然后窃取数据。

第一空四个词——防不胜防、形同虚设、名存实亡、鞭长莫及——意思上都差不多，都能表达"没什么用"。所以这一空考的不是意思，是使用的规范性，也就是搭配。

| 备选词 | 判断 | 理由 |
| --- | --- | --- |
| 形同虚设 | 可用 | 有跟没有一样，与"响应"搭配没毛病 |
| 名存实亡 | 可用 | 同上 |
| 鞭长莫及 | 排除 | 本义管距离、长短，形容隔得太远、够不着；虽可引申为能力不足，但文段是"完全没有效果"，也没提距离 |
| 防不胜防 | 排除 | 使用对象一般是人，"让人防不胜防"；且"防"在事发之前，"安全响应"是事发之后发出的警报，让响应防不胜防，用法不当 |

"鞭长莫及"单独多说两句：这个词最适合形容"太远"。古代一些军阀、藩镇割据盘踞在王朝边疆地区，皇帝想管到他们，那才叫鞭长莫及。文段压根没提距离，说的就是"没用"，所以不选。第一空剩下"形同虚设""名存实亡"最好。

第二空是这道题最难的地方。这里要先立一个选词填空的择优公式：

```text
有对应点 ＞ 无对应点但合理 ＞ 无对应点且不合理
（照线索选）    （靠常理猜）      （先排除）
```

并不是所有题的文段里都有明显线索。有时考的就是这个词放进去讲不讲得通、合不合理——合理即可。回到这一空：文段只说攻击者掌握漏洞、入侵网络，然后窃取数据；至于入侵之后到底干嘛了，是守株待兔、偷天换日还是按图索骥，文段没有直接对应。那就选一个更合理、更符合基本事实的。

| 备选词 | 判断 | 理由 |
| --- | --- | --- |
| 偷天换日 | 排除 | 词义是暗中改变、篡改。攻击者是来窃取的，没有任何"改"的意思，与文段无关 |
| 按图索骥 | 排除 | 依给定线索寻找目标，强调目的性、方向性，必须先有一张"图"告诉你该怎么做；横线处已是"入侵网络之后"，此时手里没有图 |
| 守株待兔 | 选用 | 一是不积极主动、存着侥幸心理等猎物上钩，二是暗中等待机会；先进来、再蛰伏、看到机会再下手，讲得通 |

"按图索骥"为什么不行？有同学说"网络漏洞"不就是图吗？注意文段里那个"后"字——横线探讨的是已经入侵之后的动作。漏洞只是让你进来的前提，不是你的目标。打个比方：你好不容易进了别人家里，目标难道是那个洞吗？不可能。你肯定是什么值钱偷什么，遇到什么拿什么。

所以这题只能这么理解：攻击者像小偷强盗一样已经钻进别人家里，先藏起来蛰伏，观察主人在不在家，等一个合适的机会再下手窃取。这是脑补，但这题没有直接线索，靠的就是合理性。

```text
攻击者的动作链（对应第47题第二空）

  掌握漏洞     入侵网络     潜入后待机     看到机会     窃取数据
  （进门之前）   （破门）     （藏起来等）    （下手）     （得手）
                              ↑
                    横线就在这里：入侵"之后"
                    此时手里没有"图"，只有"等机会"
```

"守株待兔"这个用法有现实依据。人民网有篇报道讲间谍那条线：有人特意在目标家楼下的餐厅守株待兔，专挑他跟老婆闹矛盾的时候对他投怀送抱——先接近他，再等待机会，等好时机到了再下手。这事儿不宜多说，但那个路子跟本题"先进来、再蛰伏、看机会偷数据"是一模一样的。

再补一刀：第一空"防不胜防"已经确定不行（搭配不当），第二空"守株待兔"最合理，答案锁定B。这题并不牵强，只是这种没有线索的题大家见得少，感觉难而已。

### 方言为什么是点睛之笔：把选词当中心理解做

第48题。文段大意：灵动活泼的方言往往成为点睛之笔。鲁迅的作品中不乏源自绍兴方言的重叠词，"白丽丽""寒颤颤"，写的是事物性状模态的____；周立波在《山乡巨变》里写"他的脚力来不及，鞋子流水踢着路上的石头"，用的是湖南益阳方言，"流水"表示经常的、不间断的，可见方言的运用使表达更为精炼准确而____。（提醒一句：这个周立波不是那位上海滑稽戏演员，是写《山乡巨变》的那位作家。）

第一空："纤毫毕现"可以直接排掉。这个词强调每一个细节都完全暴露出来——"白丽丽""寒颤颤"只是形象的表述，你不会连那人的胳膊、腿、脸部肌肉、身上的汗珠都看清楚，它追求的是神似而不是形似。"惟妙惟肖"从大方向说没毛病，但肯定不如"跃然纸上""呼之欲出"：它常跟"栩栩如生"一起考，侧重在"相"，主要用在模仿的语境里。不想排它可以先留着。

第二空盯住那个"而"字：而字表转折、递进、并列都行，但不管表哪一种，前后的意思一般不一样。就像"这次会议的意义重大而深远"，你不会说"重大而重要"。前面已经有了"精炼准确"，后面再填"一语中的"（说到要害，本身就是精炼准确的感觉），前后重复，不成立。所以D项第二空也排掉了。

于是主要纠结A（不落窠臼）和B（妙趣横生）。选B的同学，心路历程基本是这样的：看到"灵动活泼的方言成为点睛之笔"，觉得"灵动活泼"就是有意思，答案选"妙趣横生"。

这个想法要仔细想。灵动活泼的本质意思是不死板、不教条、善于变化，跟"有趣"只沾一点边。更关键的是：难道"不落窠臼"就不灵动活泼吗？不落俗套就是不死板、不教条、善于变化。所以"灵动活泼"这四个字，构不成排除A的理由。

这道题必须理解文段的中心思想。假设它是一道中心理解题，主题词是什么？是方言。方言的本质是什么？是我跟一般的表达方式不一样。文段是总分结构：开篇说方言是点睛之笔，然后举鲁迅、周立波两个例子——别人表达这个意思用"白"，我用"白丽丽"；别人用"经常"，我用"流水"。这难道单纯是为了好玩吗？不是。是为了跟别人不一样：只有当地有，别的地方没有，这种独特的感觉。

这也解释了"不落窠臼"为什么最好：它有独创，最能体现方言的特征。反过来说，方言不都是好玩的。湖北人说"过早"就是吃早饭，这玩意儿没多有意思，放到别的地方人家还不知道是什么意思；广东那边叫"吃早茶"，我一开始还以为一定得喝茶，其实也未必。它就是一种方言、一种表达方式，体现的正是"只有我们这儿这么说"——不落窠臼。

第二个思路（略显薄弱，说难听点叫牵强，两个思路合起来看）：文段除了方言，还在写小说、写文章。"跃然纸上"和"呼之欲出"虽然都形象，但哪个更能体现写文章、跟作品相关？"跃然纸上"多形容跟纸有关系的——画画、写作，非常合适；"呼之欲出"不一样，凡是表现得非常明显的都能用，你的想法、你的欲望也可以呼之欲出。所以两个词都是A更好。答案选A。

这种题一下子听不懂没关系，下课之后慢慢琢磨、体会。

### 岭南盆景进盆：以小见大，还得是完整的以小见大

第49题。文段大意：岭南盆景注重自然美和人工美的和谐统一，通过修剪、攀扎嫁接等技法，将树木、山石这些本来是自然元素的东西融入盆中，创造出____的艺术效果。

先理解文段：山石树木本身是很大的，肯定装不进盆中；但我能通过技法让它们巧妙融入盆中——把一个大的东西装进一个小容器，这就是以小见大、小中见大，类似等比例放缩的微缩模型、微缩景观。有同学在弹幕里说"方寸之间表现千里山水"，说得非常准，申论都可以你来教。

先把"一日千里"干掉：文段根本没提时间，没提快慢。

剩下"一叶知秋""管中窥豹""咫尺千里"都有以小见大的感觉，那就抓侧重点，考的是使用的规范性：

| 备选词 | 侧重 | 为什么不合适 |
| --- | --- | --- |
| 一日千里 | 速度快 | 文段没提时间与快慢，先排除 |
| 一叶知秋 | 通过个别细微的迹象，看到整个形势的发展趋势 | 两个用法都不贴：一是对未来的预判（叶子落了知道秋天快来），文段不是预判；二是局部推知整体，而落叶只是秋天的一部分，本身不完整——文段是等比例放缩，大的有山有水有树，小的也有山有水有树，不存在不完整 |
| 管中窥豹 | 只看到一部分 | 无论取"所见不全"（贬义）还是"略有所得"，都只落到片面；文段压根不片面，它本身就是一个完整的微缩整体，只是变小了 |
| 咫尺千里 | 咫已是短距离，千里是长距离，用很小的范围表达很大的事情 | 正好对应等比例放缩，当选 |

所以选"咫尺千里"。注意它跟"一日千里"不是一回事：有人望文生义，以为"咫尺千里"是跑得快，那是跟"一日千里"搞混了。

再说考场思维。这道题的选项设置是个典型：里面赫然放着一个"一日千里"，正常人类基本不会选它，它出现在这儿显得莫名其妙。为什么会这样？大概率是因为它跟正确答案有某种关联——出题人是照着正确答案去设干扰项的。"一日千里"和"咫尺千里"长得很像，就是这个关联。所以哪怕文段没太看懂，只要确定"一日千里"一定不能选，又发现它跟某个选项神似，那选那个神似选项的概率就非常高。这是个小技巧，做一题记一题。

### 预见在先：预见性的词、敏锐，与不作解题点的三并列

第50题，终于让大家松一口气。文段大意：领导干部水平的高低，很重要的一点就是是否具有____、预见在先。第一空与"预见在先"用顿号并列，选一个带预见性的词就行，这纯粹考词语理解。

第一空："见微知著"跟"一叶知秋"几乎一模一样，以小见大，能预知未来；"未雨绸缪"也有预见性；"独具慧眼"是眼光敏锐，像伯乐一样能看到别人看不到的东西，但它不代表预见性，只是眼光毒辣；"胸有成竹"不用记那么多，记两个字——自信。"天生我材必有用""我对这次考试胸有成竹"，都这么用，跟预见没关系。

第二空：文段接着讲，窥一斑而知全豹，它依然是一种预判——看到一个斑点就知道有豹子，听见叶子响就知道有情况。一方面容易发觉，一方面你的神经绷得很紧、反应很快。所以填"敏锐"，不填"谨慎"（谨慎有点偏消极，而且这里只是单纯反应快）；"警示"也不行，它指的是密切注意、以免发生不利或不幸的事情，文段里没有明显的坏的意思。

第三空是"叠加、演变、升级"式的三并列。这里给一条经验：三并列情况比较复杂，一般不作解题点，从这儿做题没意义或者难度很大，放在这儿只要没毛病就行。而且它其实有种递进的感觉，但同样不是解题点。

有同学问"问题"和"演变"搭吗？当然搭。要知道"演变"是怎么来的：倾向性问题，就是有可能发生的问题，它慢慢变化、不断发展，就会变成另外一个东西。文段整段讲的不就是预判吗？你要知道它未来会怎么发展，"演变"正好有发展变化的意思。答案选D。

### 鲁迅与矿物：乐此不疲，搭配的是事不是物

第51题。文段大意：迅哥18岁考入矿物铁路学堂，到日本留学之后依然对矿物____，记了大量笔记，手抄、临摹过很多著作——那说明很感兴趣、很喜欢，把这个意思表达出来就行。

第一空四个词意思都对，都有喜欢、在意的感觉，那就考规范性。"乐此不疲"可以直接排掉：这个词一般搭配某件事情、某种做法。有人知道老打游戏不好，但他依然乐此不疲；有人知道喝酒有害健康，但他依然乐此不疲——一定是"乐此不疲地做""乐此不疲地干某件事"。而矿物是一个东西、一个物体，你不能对一个物体乐此不疲，总不能说"我对这个桌子乐此不疲"吧。弹幕里有人刷"我对张弓老师乐此不疲"，这就是用法错误。

第二空好做。文段说鲁迅读书的那个时代，地质学被称为地学，矿物学被称为金石学；那么什么样的人或许会以为，这两门功课探讨的仍是"地"与钟鼎碑刻这些古老学问？显然是理解错了的人。错从哪来？从不了解来。所以是"不明就里"。

"张冠李戴"为什么不行：它是故意弄错对象、把东西安到别人身上，而文段里这些人就是单纯的不了解，没有故意偷换概念的意思。"浅尝辄止"也不行：它只是了解得不够深入，没有"错"的意思，而文段说的是理解错了。

答案选A。

### 马一参与，规模就变：感情色彩与别让文段说废话

第52题。文段大意：马的移动能力强、速度快，有的马____人类；那么人类的畜牧规模必然会____。

第一空四个词摆出来：参与、介入、帮助、协助。看到选项就要有条件反射——分组思维。介入和参与是中性词（介入不是贬义词，就是参与的意思），帮助和协助是积极的褒义词。到底选哪组，结合文段：文段明明白白告诉你马"移动能力强、速度快"，那感情倾向当然是积极的。但凡有的选，就不选中性那组；除非积极那组的第二空出了毛病，才把它从垃圾桶里捡回来。这是思路的先后问题。

第二空就好办了：马能力强、跑得快，帮人类干活，那人能到的地方就更广泛。没有马的时候，人一天才走多少公里；有了马、有了骑兵，能去的地方完全不是一个量级。所以畜牧规模只会"扩大"，不可能"精简"。

容易错选A（参与加改变）的同学，是被后文这一句绊住了："位置以及聚落之间的距离也会随之出现一定程度的变化"——文段只说变化，那第一空就选个"参与"呗。

不能说A不对，但你要是不选C，这道文段基本就在说废话。"有了马的参与，人类的规模必然会有所改变"——话是对的，可"参与"和"改变"把"移动能力强、速度快"这句完全浪费了：既然填什么都行，那这句话为什么要给你？文段总共就一个句号一句话，它不是在暗示，是在明示：这个改变一定是积极的改变。选"协助"，选"扩大"。

再对"精简"补一刀：有了马，人活动的范围只会越来越大——就像人有了飞机、火车、汽车，你去的地方肯定越来越大，否则要马干嘛？要这么快的速度干嘛？总不能一辈子守着一亩三分地。所以"精简"不如"改变"，"改变"不如"扩大"，对比择优，选最恰当的C。

### 技术日新月异，响应必然滞后：找准横线的搭配对象

第53题。文段大意：面对技术突破催生的新产品、新服务日新月异，市场响应往往具有____；而且对于一些技术先进但应用前景不明朗的产品，企业、市场会选择放弃。那么从这个角度看，独角兽企业都是经受住市场____的胜出者。

第一空：技术这边快，每天都有新东西，层出不穷；但市场的选择很审慎、很挑剔，不是技术一出来就马上选，要先观察——先让子弹飞一会儿。所以市场的响应会慢半拍，需要一定的时间，最好的词就是"滞后"。

想选"差异""被动""模糊"的同学，搞错了对象。这些词是搭配"市场的选择"的：你的选择可以有差异，可以是主动还是被动，可以模糊。但横线处搭配的是"响应"。响应是什么？是反应的速度。响应只有快和慢，它不会差异、不会模糊、不会被动。找准搭配对象，这一空就选"滞后"。

顺便记一个常识：市场的反应具有滞后性，这是经济学里的常见原理——技术发展太快，规则就滞后，不是保守。前几天刚做过一道这个路子的题。

第二空："胜出者"三个字是钥匙。胜出说明一定存在筛选、存在竞争、存在考验——胜者为王，败者为寇，你得先有竞争。所以"大浪淘沙"更好：好的留下，坏的走掉，是一种内部的竞争。"优胜劣汰""千锤百炼"也说得过去；"精挑细选"不行，它体现不出内部的竞争，跟"胜出"没有关系——精挑细选是人为地挑，被挑中的不需要胜出。很多同学选"精挑细选"，就是被前面那个"很挑"绊住了。

答案选A。这题不难。

### 顶层还是基层：自上而下，与抽丝剥茧的分工

第54题，国考的出法，很见功力。文段大意：面对新的形势变化要求，要进一步全面深化、继续完善机制，因而制度建设的任务更为繁重，加强顶层设计更为重要。要真正做到胸中有数、层层系统设计，____；否则难免会____、顾此失彼。

先从第二空下手：横线处与"顾此失彼"用顿号并列。"顾此失彼"是顾了这个忘了那个，顾不过来的意思。它的老朋友"捉襟见肘""左支右绌"意思基本一样，都是顾不过来，可以保留。"得不偿失"排掉：它强调得与失的比较，是得到的抵不上失去的，而文段只是顾不过来。"进退维谷"也排掉：它的近义词是"骑虎难下"，强调的是做也不是、不做也不是，进退两难；而文段是想做、要做，但是做不完。

第一空是最容易找错对应点的地方。很多同学看到后面"层层系统设计"，立刻对到"抽丝剥茧"——一层一层剥开我的心，感觉跟"层层"太像了。可问题是，"自上而下"不也是一层一层的吗？从上面到下面，一层一层往下。光看这个词，两个都有道理，所以要找真正的点。

这就回到了那句老话：选词填空的中心理解化。把文段当中心理解题读，中心句是"加强顶层设计更为重要"。所以"层层系统设计"的重点不是一层一层，而是要从上层到下层；后面"如果不……就难免……"是反面论证，反面论证的是谁？是前面的"顶层设计"——不能做到顶层设计，就难免顾此失彼。所以横线一定要填出顶层设计、总体构想、全局视野、战略谋划这个层面的意思，只能选"自上而下"。

顺便把"抽丝剥茧"这个词的考点记牢：它的侧重点是"细"——抽的是丝，剥的是茧，都很细；它虽然也有层次分明的意思，但公考里考"细致"的时候多得多，考"层次"的时候少。这是要记笔记的点。

这道题是2026年的，如果做过2022年国考地市级和2024年国考那两道题，基本不会纠结：

```text
2022 国考地市级：从基层出发研究治理，从操作层面反观整个治理体系
        → 自下而上 → 顺藤摸瓜（藤不重要、瓜重要：从不重要到重要）
        → 基层责任轻，顶层责任重

2026 本题：  中心句是"加强顶层设计更为重要"
        → 自上而下 → 顶层设计、总体构想、战略谋划
        → 与 2022 那道互为镜像（一对反面）

2024 国考：  文段画风是包罗万象、千头万绪，要从小切口出发，打破盲区和局限
        → 基层工作事儿太多、纷繁复杂、细节太多，要直面各种细节才有更广阔的视野
        → 对应"千头万绪" → 抽丝剥茧（重点在"细"）
```

做一道题，会一类题：以后看到"基层"，就是自下而上；看到"顶层"，就是自上而下——重点在强调从哪儿出发的问题。

### 开篇答疑：留言里的四个问题

#### 瓮中捉鳖：进去的到底是谁

有同学问：第 47 题不看第一空，只看第二空，"瓮中捉鳖"能不能用？入侵者都已经进到网络里面来了，获取信息不就是瓮中捉鳖吗？

我想了想，它没有那么合适，两个原因。

第一，你要知道瓮中捉鳖是谁进去了——是"鳖"进去了，是被捉的那个人进去了。而文段里是谁进去了？是入侵者，是那个主动的人，是要窃取信息的人。用"瓮中捉鳖"就很奇怪。

第二，我觉得写这篇文章的人也不会用这个词。你说"入侵网络之后就可以在网上瓮中捉鳖"——你骂谁呢？意思是窃取信息的人是人，我们是鳖、是王八，等着你捉，这骂人太脏了。所以哪怕它意思上能说通，用在这儿也不恰当。我们以后会讲到一道题，说某个地方的新能源汽车"鹤立鸡群"——那你不是骂别人是鸡吗？一个道理。这两个词就算打了双引号，也不太恰当。

> **结论**：选词不能只对意思，还要看"谁吃亏、谁是鳖"，使用对象和感情色彩都要对得上。

#### 看见"实践"就要选"身体力行"吗

有同学问：第 69 题还是不太理解，前面既然有"实践"，为什么不选"身体力行"？不是先考虑意思的重要性，再考虑规范性吗？

顺序没错，我们确实要先考虑意思的正确性。但这个题的意思在哪里？在"最全面"。你要首先找准搭配对象，才知道我在说什么东西。你连自己在说什么都没搞清楚，找错了对象，那意思再对，也没有对到我要找的点上——就像中心理解里的"非重点"，你找的信息它不是我真正要找的。

所以你看这个"实践"是谁在实践？是宫廷画家在实践。而横线的主语不是宫廷画家，是"这两本书"：这两本书与画家的实践相关，进而阐释了青绿山水画的基本要素。实践和阐释没有必然的关系。如果你的横线要找的是画家，说"画家在什么样的阐释"，那你可以说有实践、选身体力行；可横线的主语是这两本书。所以不能看到"实践"就选那个"身体力行"，答案只能是"条分缕析"。

#### 堂而皇之是无中生有吗

有同学说：第 64 题选"堂而皇之"是过度脑补吧？英文段只写了一些手段，没写"做不好的事情"，没体现出他心里面是堂而皇之的，所以选"投机取巧"。

这个地方需要你理解一下、推断一下：他竟然以为自己有操作空间，觉得自己能操作，就会采取措施去规避法律、规避对你的审判——所以这个人胆子大。胆大，"堂而皇之"乃至"明目张胆"都是可以推断出来的，合情合理，不是无中生有。

退一步说，就算你觉得"操作空间"和"投机取巧"对应得特别好，第一空也不行：第一空从用法规范性、从文段搭配上讲，只能搭配肖像权，只能选"重视"。所以第一空锁死了，第二空放一个合理的词就 OK。

> **易错点**：当第一空能定生死时，别在第二空纠结——第二空只要"合理可推断"，能贴合"有侥幸心理、自以为别人发现不了"这条线就行。

#### 看见"聚焦"就要选"精准"吗

有同学问：第 60 题，B 选项"精准"不是对应到"聚焦关键环节"吗？我看到"聚焦引流域"，所以就要"精准发力"，精准能对应聚焦，为什么不选？

你要注意，"聚焦引流域"是第一阶段：我的环节特别多，我只取其中三个，只关注它们——这是"选"。等进入到下一步，在这三个环节上怎么发力，那是第二阶段。你不管填"集中发力""精准发力""切实发力"还是"持续发力"，都是在这三个方面发力，都达到了聚焦它们的效果——你填什么词都没有在别的方面发力，也就没有违背前面"聚焦"的前提。

所以第二空虽然前面有个"聚焦"，你也不能直接选"精准"，别的词跟聚焦也不矛盾。这题第二空确实是个强干扰项：如果这题只有第二空，优先考虑 B 也不是不可以；但你第三空不行——"扎根"和"玉"都跟土相关，第三空只能选"沃土"，答案只能选 D。

### 第70题：盲目自信会刺激人"怎么样"

这道国考题难度比较高。文段说：适用人工智能对于重大情报挖掘、精确预测、确认能够提高它的准确性，有利于减少误判；但是有的时候会使人类盲目自信，刺激其怎么样；而通过人工智能带来的进攻优势，会导致最佳防御就是什么。也有说法对此做了注解：这会打破进攻和防御的平衡，引发安全困境，反而增加了风险。

#### 第一空：孤注一掷和刚愎自用为什么不合适

先排"孤注一掷"。这个词的用法是在危急时用尽所有力量做最后一次冒险——"最后一舞"。用它的时候，潜台词是我现在面临着一个不太好的环境、不太好的状态：没办法了、没辙了，最后试一次，不行就拉倒，有种无奈的感觉。而文段里是什么？是有了 AI 在帮助我，我这个时候非常膨胀、非常自信，根本不存在什么危急状态。所以这个选项放在这儿不合适。

再排"刚愎自用"。很多同学反而选了这个词，因为看到了"自信"——"老师我很自信，不就刚愎自用吗？"但你要注意它的意思和用法：它表示非常固执自信，那是一种状态，不是一个动作。而"刺激"后面一定要跟一个做法：你被刺激了，你去把别人打了一顿；你受刺激了，你在这儿疯狂做题——被刺激之后你做了一件事情。你能说"它能使人类盲目自信，刺激其刚愎自用"吗？盲目自信刺激出"很自信"？这不是刺激，这是同义反复。某种意义上它是最差的：孤注一掷、轻举妄动、铤而走险，其实都是一种做法、一个动作——你觉得自己很牛，接下来要干一件事。

#### 第二空：以攻为守和先发制人难以分开

第一空剩下"轻举妄动"和"铤而走险"，去看第二空：剩下"以攻为守"和"先发制人"。

文段说通过人工智能带来进攻优势，导致最佳防御就是什么——AI 带来的是进攻优势，大家就更愿意进攻，正好对上了"这会打破进攻和防御的平衡"的说法。所以"以攻为守"放在这非常恰当。"先发制人"呢？我先发就攻，不要等别人来攻击我，我先攻击别人——放在这也还行。所以这一空两个词其实不好排，甚至比第一空还不好排。

顺便把另外两个词在第二空的问题说清："避实就虚"是攻击别人的薄弱环节，文段跟虚实没有关系；"攻其不备"一定要强调对方没有准备，可难道你提前进攻，对方就一定没准备吗？那不成偷袭了。文段的意思是"先下手为强，后下手遭殃"，就是我要比别人更早进攻——这是先发制人和以攻为守。

#### 回到第一空：轻举妄动与铤而走险的分野

那两个词两空都不好，这两个词第二空难分高下，只能回过神来看第一空：轻举妄动和铤而走险到底怎么对比？差别其实挺大，仔细想是能想明白的。

很多同学凭语感："刺激其铤而走险"读起来顺，"刺激其轻举妄动"怎么读怎么怪。为什么怪？因为"轻举妄动"我们一般这么用——"大家不要轻举妄动""千万不能乱来"，它指不经过慎重考虑，一般多用于否定句，很少会说"刺激你轻举妄动""你应该轻举妄动"。而"铤而走险"肯定、否定都能用：可以说我选择了铤而走险，也可以说我们不要铤而走险。从用法上，铤而走险就优于轻举妄动。

更关键的是侧重。"轻举妄动"的重点在"轻"、在"妄"、在"乱"——没有经过充分准备，不慎重，很轻率：我还没好好准备，我就干了。可文段说得清楚：我这个时候已经有了人工智能，能对情报挖掘、精确预测，方方面面，天时地利人和全站在我这儿，我已经非常膨胀了。这能叫轻举妄动吗？好比一个国家想侵略另一个国家，为此准备了十年，每一步都是深思熟虑的——那不能叫轻举妄动。

"铤而走险"的重点在"险"：你这个做法有风险。它跟准没准备好没有关系——你可能也想得很清楚、准备得很充分，但我就想搏一把，冒险试一试。文段里"险"在哪里？你要主动发起战争，就会带来爆发的风险，所以它非常冒险。当年日本对清朝发动甲午中日战争，日本是小国、清朝是大国，以小博大，你可以说它是铤而走险，但不能叫轻举妄动——它可能为这场战争准备了很长时间。

再各举几个例子感受一下。用"轻举妄动"的时候：调查研究要务实、要明确、要选好、要做好充分准备，切忌轻举妄动；企业到底是不怕，还是因为害怕所以不敢轻举妄动；掌握的证据还不够全，担心轻举妄动会打草惊蛇。这几个例子有两个共同点——强调没有准备好，而且都用在否定句里。用"铤而走险"的时候：为了卖相好看就减少运输损耗，他们铤而走险；为了谋取利益而铤而走险的案例，当事人未必准备不充分，只是想获取利益、想做一些高风险高收益的事。

| 维度 | 轻举妄动 | 铤而走险 |
| --- | --- | --- |
| 语义侧重 | 轻、妄、乱，没有充分准备 | 险，做法本身有风险 |
| 与准备的关系 | 强调没准备好 | 与准备无关，可能准备很久 |
| 常用句式 | 多用于否定句（切忌、不敢、担心） | 肯定、否定均可 |
| 典型语境 | 准备不足时的冲动 | 权衡之后仍要搏一把的冒险 |

答案选 D。这道题的主要区分点就在第一空，把这两个字弄清楚，题就拿下了。

### 第71题：托育服务是"基础"还是"补充"

文段第一句话其实是在给托育服务下定义：由三岁以下的婴幼儿的法定监护人之外的人或机构，在特定时间内进行的一种组织化、系统化的照顾服务。注意，一定是"法定监护人之外"。

第一空：现代社会里，外出就业带来的抚育困境愈发怎么样。要搭配"困境"，而且有"愈发、越来越"的意思——人越来越忙，没人看孩子，困境很突出、很明显、很普遍都可以。但"典型"这个词意思还行，用法不恰当：典型一般搭配具体的人、事、物，比如"张老师算是教言语的典型""树立典型"，都是非常具体的东西，而这里要修饰的是抽象的抚育困境；而且没人说"越发典型"——要么是典型，要么不是典型，总不能越来越典型吧。所以从规范性角度，这个选项先排掉。

第二空：家庭结构的小型化，造成了婴幼儿照顾的代际支持怎么样。这句话要看明白两点。家庭结构小型化，就是以前三代同堂，爸爸妈妈、爷爷奶奶、外公外婆，六个人带两个孩子；现在三口之家，爸爸妈妈带一个小孩——人少了。代际支持就是隔代的支持：不是爸爸妈妈带，而是爷爷奶奶、外公外婆带。既然小型化了，就没有隔代长辈帮带了，那就是"缺了、少了"，不是"弱了"。"短缺、不足"是数量上的问题，"薄弱"是能力上的问题。所以答案在"短缺、不足"这一组。有同学问"薄弱和不足是一组，不足不就是缺、不够的意思吗"——对，不足的反义词是足、是多；而弱的反义词是强，它俩不一样。这属于方法课（第 12 讲）里"三比一"原则的运用：几条线索同时指着一个方向，选"薄弱"的概率其实很低。

第三空：加之年轻父母对婴幼儿照顾要求的精细化，托育服务作为一种什么样的儿童福利，越来越成为工薪家庭的重要选择。"基础"是构成事物的根基、必要条件，选"基础"就意味着必须有——可很多家庭其实也没有托育服务，不能说它是工薪家庭的根基，所以只能选"补充性"：它是法定监护人之外的一种补充福利，而且和前面"短缺、欠缺"形成呼应——之前不完整，现在要补进来。

那如果没有"补充"这个选项，选"薄弱、辅助"行不行？说实话问题不大。但这个题最终选它，理由有两个半：第一，第二空重在数量，代际支持是没有上一代的人帮你，不是能力弱；第二，"补充"一方面扣住"监护人之外"这个语境，一方面体现补齐之前的缺失；还有半个——"辅助"的程度比"补充"轻，辅助往往是可有可无的，而补充是"你最好还是得有"：你之前不够、不完整，我要变得更完整，这才对应得上"重要选择"。就像身体缺维生素，你得补充维生素。

答案选 C。

### 第72题：这道题只考你认不认识"诱导"

这道题考积累，知之为知之，不知为不知，做错了没关系，下次不再错就行，心态放平。

第一空：为了适应不同的地域和气候条件，昆虫需要怎么样的季节性适应策略，以及合理的年度生活史。要选一个词搭配"策略"，而且是一种适应策略。文段只给了"合理"一个提示，那肯定是偏积极的，所以"复杂"这种偏消极的先排掉。剩下的"有效""灵活"都挺积极；"适宜"单看挺好，但放进去读一读——"昆虫需要适宜的季节性适应策略"，"适宜"和"适应"摆在一起，有语义重复的嫌疑。如果你想选"适宜"，就得把"适应"去掉，直接说"昆虫需要适宜的季节性策略"。语义重复在我们言语考试里考得不多，什么时候要稍微留心？在修饰关系、有"的"连接的时候。第一空"灵活"我没排，但这题的重点不在第一空，在第二空。

第二空：停滞发育或者滞后发育，是昆虫在特定时期或特定季节的信号怎么样下发生的发育停滞行为。有同学看到"信号"直接秒选"诱导"——可不可以？可以，这就是这个词语的用法。"诱导"是生物学专业的高频词，指外界环境的信号刺激能够触发生物体产生特定的生理反应。它的主语经常是信号、环境、条件：光照诱导、温度诱导、诱导激素、诱导毒素、诱导信号。它不一定是一种强迫的行为，就是外界刺激触发生理反应。推动、调控、影响，意思都没问题，但都不如"诱导"恰当。这题就像考一个法律专业术语一样，考的不是言语的逻辑推断，是搭配。你还可以顺手积累"调控"：诱导一般是外界去诱导，调控一般是内部的、自身的、内在的、人为的、系统的——基因调控、机体调控、政策调控、内分泌调控。

> **提示**：这道题的价值就在把"诱导"记住——信号、环境、条件作主语时，"诱导"是生物学语境里的首选搭配；每道题的价值在什么地方，要心里有数。

### 第73题：完备的产业链与"消解"错位

第一空：未来数字科技将会持续深度赋能文化产业，新模式、新业态更加丰富，产业链、生态链、价值链更为怎么样。要和"更为丰富"构成对应，就是变得更多、更齐全。完备、完善、完好都还凑合；"完美"不行——学言语的最怕表述很绝对，哪来百分之百、没有任何瑕疵的事？这个词先干掉。

"完备"放在这儿特别合适，因为它形容的是整个产业链"齐全"：大的结构、大的环节我们都得有。我们一般说"中国拥有世界上为数不多的完备的工业体系"，很少说完善的、完好的、完美的工业体系。"完善"这个词记住：它作结果用得比较少，一般做动词居多——"进一步完善""完善价值链、完善生态链、完善产业链"，很少说"更为完善"。"完好"强调没有破损——仪器完好、设备完好、房子完好。

第二空：应该着重培养市场主体，探索建构全产业链的文化供给和文化需求的错位怎么样。先说说"错位"这个词，它有两个意思：一个是位置、方位错了，贬义；一个是不匹配、有差异，比如"错位竞争"，比亚迪的王朝系列和仰望系列，受众群体不一样，就是这个意思。这里当然取"不匹配"。那能和"错位"搭配吗？"拉开"是解决你俩过于紧密、天天待在一起的问题，跟错位没关系——你错位了，拉开之后还是错位，反而更不匹配了，该做的是匹配、是扣上。"弥补"对应不足、缺失、填补——弥补缺点、弥补不足、弥补鸿沟，跟错位也不搭配。所以只能选"消解"：把错位当成一个问题，把它消除掉、解决掉。"消解"搭配问题都没毛病，比如你正在气头上，我劝你"别生气，人生就像一场戏"，你消解了怨气——它不存在绝不绝的问题。

答案选 A，两个空都是 A 最好。这题主要考搭配，也就是使用的规范性，难度并不大。

> **易错点**：看到"错位"别顺手选"拉开"——错位是不匹配，拉开是解决过近，方向正好相反。

### 第74题：釜底抽薪，不是反客为主

这又是一道难题。文段说：未来，力量可以通过各种各样的辅助，直接干扰或控制指挥系统，造成敌方思想混乱、心理受挫，甚至出现幻觉；或者伴随无人平台实施网络作战，篡改指挥系统指令和数据，实现什么，进而怎么样失去战斗力。

第一空先排"移花接木"，道理和"盲目自信"那道题一样：一个是做法，一个是结果。"篡改指挥系统"是做法，"实现怎么样"是结果，你不能说"我篡改指挥系统，就是为了实现移花接木"。

关键是找准"实现"要的结果。"实现"和"致使"都引导结果——问实现，就找致使。"经过一年的辛苦奋斗、不懈努力，终于实现目标，终于成为光荣的公务员"，你看，"成为""实现"都表结果。那你往后面看它最后的结果是什么：指挥失灵、协同失效、人员失能，失去了战斗力，不战而屈人之兵——丧失了、没有了。哪个词是"从根本上解决问题"？釜底抽薪：把你的战斗力、能源、人员的能力直接抽掉，指挥系统完全失灵、直接瘫痪。

"暗度陈仓"排掉：明修栈道、暗度陈仓，一定带点迷惑、欺骗、偷袭的味道，文段没这么花里胡哨——直接用网络作战，把你的指挥系统废掉。

"反客为主"也要排掉，很多同学就错在这。反客为主是主次颠倒的意思：我在这儿上课，你们是客；什么叫反客为主？你们来上课，我当学生。要用这个词，文章得写出"翻身做主人、变被动为主动、实现控制"。比如我侵入你的指挥系统，本来是你的上级指挥你，现在由我、由敌军来指挥你——这才叫反客为主。可文段干的是什么事？直接失灵、失效、失能。就好比两军在网络对垒，你过来控制我的电脑，那叫反客为主；文段是直接"咔嚓"一下把电源关了——我也懒得控制你，我直接让你用不成，变成一堆破铜烂铁。再说得直白点：你们在下面听课，突然有人说"老师你别讲了，你下去吧"，这是直接失去；反客为主是你们来上课、我当学生——事还得接着干，主人的作用还得发挥出来。敌方都失灵了，我方控不控制还有什么意义？它没有主客之别。"釜底抽薪"在这儿是形象化的表述（题里打了双引号）：指挥系统里不得有指挥的人吗，我把指挥的人直接干没了，不就从根本上解决问题了？就像锅底下没柴了，火烧不起来。

第二空验证一下：怎么样地失去战斗力。电子战、网络作战，不用放炮、不用真刀真枪，没什么声量、没什么动静，所以"无声无息"可以。"彻头彻尾""浑然不觉"我个人觉得也行（一家之言，重点不在第二空）；"潜移默化"不行——它是慢慢地使人受到环境的影响，听十天半个月课那叫潜移默化，不是一天两天能干成的事。

答案选 B。

### 第75题：文学批评家的"创造"是阐释

文段说：文学批评作为一种特别的文体具有主体性——主体性就是自己做主，"我的未来我做主"，别人劝没用、影响不了我；文学批评家作为文学的什么创造者，同样具有主体性。

第一空：建设者、参与者、阐释者都能体现一种主体性，起码你做了一些事情；"旁观"肯定不行——旁观算什么自己做主？所以这个选项先排掉。

第二空：这种主体性就表现在遵循文学批评的原则、规律、方法，怎么样来自社会市场人情方面的异化，准确深入、创造性地解读作家作品，发挥文学批评的功能和作用。你要真正明白文段的意思：文学批评是干嘛的？就好比我们看电影有影评人——别人好不容易拍了一部电影，不得找人帮帮场子、走个面儿，请几个水军吹一吹"拍得真好"？这个时候，如果你接受了来自社会、市场、人情的异化，你就不具有主体性。所谓主体性就是：碍于市场、碍于人情，该批评就批评，该锐评锐评，不要受外界的压力和影响。

所以这一空，规避、警惕、抵抗都可以；"摆脱"不行——摆脱的前提是你已经被异化了。我说"我要摆脱烦恼"，那我现在已经很烦恼了；"我要摆脱痛苦"，那我现在已经很痛苦了。你说"摆脱异化"，意思是你已经异化了，可文段是还没被异化呢，你要做的是防备，是和人情世故作斗争。

剩下"规避"和"抵抗"不好排，那就回到第一空：建设者、参与者、阐释者，到底选哪个？很多同学不理解"阐释者"怎么和"创造者"构成对应。你要问一句：文学批评家在创造什么？文学批评家不就是去批评别人、去解读作家作品的吗？对别人的文章作出解释、作出阐释，这就是他的创造、他的本职工作。所以读到后面"准确深入、创造性地去解读"，你就知道"阐释"对应的就是"解读"，它符合这个角色的定位。这跟"方言"那道题一个道理：一定要体现出文段的中心主题词思想——方言就要体现跟别人不一样，文学批评就要体现阐释。光看"什么、创造者"这个顿号并列，谁都觉得参与、建设更好；难题都这样，有同学想得到、有同学想不到，不然怎么拉开分差呢。要站在整体的角度讲：他创造的是新的解读。

答案选 D。

### 第76题：都是"多"的意思，看谁更规范

这道题可以从第二空入手，因为第一空那几个词意思都一样——都是"多"：不计其数、比比皆是、不乏其人、大有人在。任何选项放在这儿，大方向都是对的，所以它考的是谁用得更规范、更恰当。

先用选项思维（方法课讲过）分组：前两个是单纯的多；后两个多了一个"人"——不乏其人、大有人在。那就要考虑清楚：文段里是有人还是没人？文段说"认为非遗又老又土的不在少数"——谁才能"认为"？人才能认为。"认为"这个词就把主语暗下来了，是人；那"只见其形不见其神"的，当然也是人。所以不是前两个不对，而是后两个更好。

有同学会这么想：前面有个"更"，说明后面要比"不在少数"更重，所以选"不计其数"。这里要看出递进：觉得"又老又土"，这批评还算有点道理；而"连神都见不到"，问题犯得更严重——两个对象不一样，才有暗暗的递进。就像"考数学高分的人很多，考语文高分的人更多"，都是多，对象不同，照样递进。所以填"不在少数"这类词，也能有递进的感觉。

保留后两个之后，再看第一空就简单了：非遗是非物质文化遗产，它都不是物质，怎么可能"琳琅满目"？琳琅满目是能够看得见摸得着的、珍贵美好的事物很多，形容商品、工艺品。所以选"丰富多彩"。"五花八门"偏中性（有"乱"的意思），不如"异彩纷呈"积极。那没有"大有人在"能不能选"异彩纷呈"？可以，但它比"异彩纷呈"多一个"人"，更符合"认为"背后那个潜在的主语。

答案选 D。

### 第77题：互通有无不是只能形容说话

文段说：我国疆域辽阔，各地区资源禀赋各有特点，经济互补性强、依存度高，各民族始终保持怎么样的互利共赢的经济联系。要和"互利共赢"构成并列关系，讲的就是互相有往来——各有特点、经济互补，互相之间可以做生意、可以沟通。

最好的词是"互通有无"：把你有的东西给我，把我有的东西给你，来交换。很多同学没选它，是觉得"互通有无"只能形容说话、只能形容信息之间的沟通和交流——这是对词语理解不到位。只要是彼此之间"你有的我没有、我有的你没有"，交流交换，都可以叫互通有无。

"礼尚往来"只是礼节上、面子上的，太见外。咱们都是中华各民族，难道我从外地到四川走一趟，还得给四川人民礼尚往来一下吗？文段讲的是经济上的往来，不是礼节上的往来。

"守望相助"和"和衷共济"使用语境比较窄，只能用于共同面对问题、困难、灾祸——同舟共济嘛，"济""船""守望"，都暗含着危险、困难、敌人，要合作才能解决。文段没有解决问题的语境，就是单纯做生意、经济互补。

答案选 C。

### 第78题：人定胜天，不为瓦全

这道题第一空是词语，第二空是句子，某种意义上跟语句填空差不多——意思知道就对了，理解错了就不对。

第一空：我们生活在这个世界，碰撞声总是充斥耳边——碰撞声就是互相之间有矛盾的声音。俗话说怎么样，可是俗话说"天意难违"。"可是"表转折，前后意思要相反：后面说天意难违，天重要；那前面就得说天不重要、人重要——人定胜天、事在人为、谋事在人。不能选"成事在天"，那依然是天重要，跟后一句撞上了。所以先把它排掉。

第二空：俗话说怎么样，可是俗话又说"留得青山在，不怕没柴烧"。"留得青山在"就是先苟着、活着比什么都重要——人没了，就什么都没了，所谓"存地失人，人地皆失"。那反过来就是宁可玉碎：宁为玉碎，不为瓦全。

"捡了芝麻，丢了西瓜"是主次颠倒、因小失大，跟人存不存在没关系，排掉。很多同学选它，是因为里面也有个"青山"——可"青山不常在，绿水难长流"讲的是世事变化无常，不是强调人的生命在不在。这就是只知其表、不见其神。

有同学问："忍一时风平浪静，退一步海阔天空"放第二空行不行？不行——它和"留得青山在"是近义：忍一时、退一步，就是别冲动、先苟着。所以答案选 A。

## 选词填空真题精讲：从"为了依赖而独立"到"天道也可能有差错"
> 对应块：BLK35 | 覆盖分集：P20上 | 块标题（分集名）：《第四节：2026选词填空（四）T~Y（70-92》

这套 2026 年的选词填空真题一共 165 道，咱们一题一题往下抠。抠到第 79 题，题干先把我绕进去了——

> 我们一方面渴望独立自主，一方面也需要有所依靠，但是在人际关系中，我们只愿意偏向其中一方……

横线前后跟着两个说法：**为了依赖而独立**，又**为了独立而依赖**。什么感觉？"不是因为寂寞而想你，也不是因为想你而寂寞"，听着就很乱、很莫名、很麻烦，理不清谁对谁错。这一题就要求你填一个词，把这份"乱"给表达出来。

### 79 题：为了依赖而独立，为了独立而依赖

#### 第一空：读出"乱"，读不出"重要"和"可惜"

先把这句话带给你的感觉抓住：很复杂、很麻烦、很乱，没说谁一定对。所以横线上要的就是"麻烦"这一层意思。

有两个方向是读不出来的。一个是**可惜**——可惜就是遗憾、差一点，这句话里哪有遗憾？另一个是**重要**——很多同学选 C，我是不太理解的：你从这句话里哪看出重要来了？你读出的是很乱啊，又是为了独立而依赖，又是为了依赖而独立，到底谁正确谁不对，很让人头疼。它跟重要性、跟遗憾都没关系。

> **易错点**：题干给出一对互相矛盾的表述时，先问自己"它给了你什么感觉"，再把选项往这个感觉上靠；不要自己给文段升格出"很重要""很可惜"这类判断。

#### 第二空：有对应，优于没对应

第二空说的是"关于两种观点孰是孰非的讨论怎么样"。这里要用上我们以前讲过的那条优先级公式：

```text
选项优先级：有对应 ＞ 没对应 ＞ 与文段相冲突
```

**由来已久**属于"没对应"——文段压根没说这个讨论讨论了多久。选 D 的同学想一下：你通过这段话，知道它持续了多长时间吗？不知道，时间是没提到的。而**莫衷一是**属于"有对应"——题干说"孰是孰非"，本来就像说不清谁对谁错，再说这两种观点还在争论不休，有分歧，这就是莫衷一是。

顺带说一句，这一空的**见仁见智**、**悬而未决**，意思上其实也都说得通；但**由来已久**不行，因为它跟时间有关，而文段跟时间无关。

#### 第三空：龃龉是矛盾，纠缠是分不开

第三空很多同学没做对，是因为不认识那个词——**龃龉**（jǔ yǔ）。有同学看成了"龌龊"，这也能看错。

它的意思不难：有矛盾、有冲突、不和谐，可以形容意见不合、互相抵触，或者互相之间有点小冲突、小矛盾。比如你去上班，和同事之间有点小矛盾，也可以说你们俩之间有龃龉。这个词考得不多，记住意思就行。

放进这道题里：一个为了依赖而独立，一个为了独立而依赖，这不就是互相矛盾吗？所以填龃龉，跟"冲突""抵触"实际上是一个意思。

那**纠缠**为什么不行？我们以前讲过**交织**——爱恨交织。纠缠就是剪不断理还乱、缠在一起分不开。可文段里这两个人不是分不开，是互相矛盾：我说要往东，你说要往西，请问这叫纠缠还是叫龃龉？这叫龃龉。

> **结论**：这一题答案选 B——第一空取"复杂、麻烦"的意思，第二空莫衷一是，第三空龃龉。

### 80 题：五彩滩与"两重天"

#### 第一空：主题词藏在首句

第一空是形容泥岩、砂岩、沙粒的，选项里有**色彩斑斓**、**绚丽多姿**、**鳞次栉比**、**千姿百态**。看到"色彩斑斓""绚丽多姿"的时候，你应该先问自己一句：哪来的颜色？什么情况？再往前一看——哦，**五彩滩**。

颜色只能从"五彩"来，所以第一空必须选能跟"五彩"挂上钩的那个词。鳞次栉比是一个挨一个、很整齐，跟五彩没关系；千姿百态也不如紧扣"五彩"。这就在 call back 我们讲中心理解时那句话：很多题开篇就是在引出话题，**主题词就藏在首句**，一个道理。

这题是 2026 年的真题，我还半开玩笑：我要是考前就把它讲透了，那不成泄题了，得进"牢里"。

#### 第二空：一河隔两岸，胜似两重天

往后看：南岸有绿洲、沙漠，北岸则是另一种地貌，两种地貌遥相辉映——正所谓"一河隔两岸，胜似两重天"。两重天强调的一定是**差别非常大**，所以选**截然不同**。

**各有千秋**呢？这个词虽然也有"不同"的意思，但重点在有优点、各有各的好，跟优点关系不大，不合适。**大相径庭**其实也可以，也是说差别大。**别具一格**相当于一种独特的风格，用在这儿也不合适。

这一题的方法就两条：第一抓主题词，第二抓"两重天"。

### 81 题：理念根深蒂固，膨胀就是变多

#### 带顿号的那个空：横线要跟"膨胀"一样"由少到多"

这一题可以先看带顿号的那个空——有呼应、有线索的空优先考虑。题干说：这种所谓人类中心主义如果恶性膨胀、（横线）……顿号表示并列，横线词语就得跟"膨胀"构成对应关系。

那膨胀是什么意思？由少变多、由小到大、由少到大。所以横线也要填出"由少到多、由小到大"。

| 词语 | 核心义 | 跟"膨胀"同向吗 |
| :--- | :--- | :--- |
| 甚嚣尘上 | 议论纷纷、十分嚣张，说的人越来越多 | 是，重点在"多" |
| 泛滥成灾 | 变多了，多到成灾 | 是，重点在"多" |
| 有恃无恐 | 有所倚仗，所以不怕 | 否，重点在"狂"、在"不怕" |
| 肆无忌惮 | 毫无顾忌，不怕 | 否，重点在"狂"、在"不怕" |

这四个词都是贬义词，所以"恶性"帮不了你——看恶性没用，四个都恶性。真正能下手的是：甚嚣尘上、泛滥成灾的重点都在"多"，有恃无恐、肆无忌惮的重点都在"狂"、在"我不怕"。膨胀是由少到多，不是在怕不怕，所以把 A、D 排掉。

#### 第一空：能搭配"理念"的只有根深蒂固

再往前看第一空："这种理念既（　），又非全无所据"。

**非全无所据**是双重否定表肯定，强调的是"有依据"；而且这是个转折句，转折之后才是消极的，所以第一空得填一个中性词或者积极的词。这一空给的两个词光看意思都行，但要看搭配——横线后面是**理念**。

> **结论**：行之有效一般不能搭配"理念"——想法怎么能用行之有效呢？做法、对策、方法、途径才能搭配行之有效。所以看到"理念"这个词，只能选**根深蒂固**。

记住这个固定用法：要表达理念、观念、想法很确定、很稳固，优先考虑根深蒂固，它跟理念、观念、想法的搭配非常多。

顺便把第一空另外两个候选也排掉：**大行其道**一般多用于贬义，而这个位置在转折之前，不该填那么贬义的词，A 不太好；**牢不可破**意思上可以，但它跟根深蒂固意思其实一样，那肯定选根深蒂固，D 呢行，但没有 C 这么好。

#### 最后一个空："连续"形容不了道德关系

最后一个空说的是人与自然之间的道德关系。题干的意思很明白：西方传统否认人与自然有着任何直接的道德关系。这里**连续**是不能用的——"连续"怎么能形容道德关系呢？很奇怪。**固定**和**明确**才稍微好一点，所以答案选 C。

### 82 题：克服对获取，横线对劣势

#### 第二空：优势的反面是劣势，不是颓势

题干说：无论是传统孵化还是虚拟孵化，提供资源是孵化平台帮助创业企业克服（　）、获取竞争优势的重要方式。

"克服"对"获取"是相反的——克服就是不要，获取就是要。所以横线要对"优势"相反：优势反过来是什么？劣势，或者叫弱势。

选项里，**态势**是个中性词，谈不上克服；**颓势**虽然是贬义词，但放在这儿不合适——颓是指你曾经辉煌过、到达过顶峰，然后突然往下走。可创业企业是新生事物，你还没经过你的顶峰，怎么就颓了？

所以这一空只能选**弱势、劣势**这一类意思。

#### 第一空：聚合是空间，积聚是时间

第一空做错的同学，大多是不理解**聚合**。看字意嘛，聚合不就是汇聚的意思吗？差不多。

我讲过聚合和积聚的区别，这里再拎一遍：**汇聚、聚合偏空间**——四面八方各处的资源汇到一起；**积聚偏时间**——靠的是一点一点的时间积累。这道题说的是网络把人力资本和资本资源聚到一起，帮助企业实现什么，这一定是**空间上的集合**，不是它自己慢慢积累的，所以一定不能选积聚。

**汇聚**其实也可以；**聚拢**意思也对，但一般不这么用。

有同学问：为什么不把"积聚"理解成"帮助企业积累原始资源"？因为文段不是这个意思。你仔细看原文——是网络聚集了人力和资本资源，帮助企业实现了什么，它是空间上的，不是自己去慢慢积累的。不要自己给文段加戏。

这一题答案选 D。

### 83 题：史料不被史家关注，所以束之高阁

#### 断章取义与弃如敝履，为什么都不行

题干说：史料被挖掘，有赖于史家的证据意识；若是史家不认为某个史料可以作为证据，那么该史料可能（　）。后面跟了个例子帮你理解：甲骨文以前是入药的，所以就不被关注。横线要体现的就是"不被关注"。

| 选项 | 问题 |
| :--- | :--- |
| 断章取义 | 意思是不管不顾、孤立地取，跟"不被关注"没关系 |
| 弃如敝履 | 太重、太消极——像看到蟑螂老鼠一样，恶心地把它扔掉 |
| 视而不见 | 意思对，但搭配对象不如束之高阁专业 |
| 束之高阁 | 意思对，且专配"史料、文化遗产"这类语境 |

毕竟那是史料、是上千年前的东西，是历史的一部分。你作为一个历史学家，这东西虽然没用，也不可能把它完全丢掉、像扔破鞋一样扔掉——这个词有厌恶、讨厌的感觉，太重了。记住这条规律：**史料一定不会"弃之如敝履"**；史家不重视它，也不会扔，顶多是搁着先不用、暂时先存着。当个规律记就行。

#### 束之高阁：看到"史料"就该条件反射

从意思上讲，视而不见、束之高阁其实都对。但我们说过：要看**搭配对象**。文段搭配的是史料，凡是跟文化遗产、历史相关，表达"不被重用、不需要使用"的，只要别的空没问题，**优先考虑束之高阁**，这是个专业词汇。

就像看到旅游容易想到走马观花，看到创业想到筚路蓝缕一样。浙江考过一道题，说传统文化往往被束之高阁；还有一道题里排比："有的超越时空，有的古为今用，有的束之高阁"——把它当成一个专门形容这类语境的专业词记住就行。

这个词妙在哪儿？第一个字"高"——把你高高地供着，说明你的地位高，你是历史；第二个是"搁着"——放着不用。合起来就是：我尊敬你，但我不用你，有点敬而远之的感觉。比如古籍原件，要被传播，而不是束之高阁。

#### 现场答疑：别被"入药"的例子带跑偏

有同学当场问：都被当成龙骨入药了，这例子根本没有被尊重的感觉，怎么能说"敬而远之"？

我讲的是这个词为什么适合用在史料上，这是个原理问题。你要看清楚：入药是**医生**干的事，史家不会入药；横线要填的是**史家对它的态度**，只能体现出不被重视、不被关注。例子的重点在后几个字——"不被史家关注"，他又没被史家拿去做药。别被例子带跑偏了。

第二空的坚实、稳固、可靠其实都可以，这一空拉不开差距。答案选 D。

### 84 题：并驾齐驱与独具一格

#### 第一空：追赶追到一起，才叫并驾齐驱

题干说北斗系统从一片空白奋力追赶，再到和世界领先的全球导航系统（　）。

先排两个。**不期而遇**是意外的相遇——可你明明在追别人，那怎么会是意外？是你故意的。**并行不悖**是指同时进行、不相违背、不冲突，这个词一般用在**看似矛盾的双方其实并不矛盾**：有人说要守正，有人说要创新，那么守正与创新就要并行不悖；我们的市场经济既有公有制经济又有私有制经济，两者看似相反，其实并行不悖。文段可没说北斗跟别的国家的导航系统是矛盾的，所以排掉。

剩下不分伯仲和并驾齐驱，单纯看第一空也是并驾齐驱好。为什么？"从一片空白奋力追赶"是个**形象化表达**——你肯定有个追的对象：

```text
奋力追赶期                 并驾齐驱期

西方国家  ───────────▶    西方国家  ───────────▶
中国      ───────────▶    中国      ───────────▶
           （落在后面追）             （追着追着跑到一起）
```

本来就是中国在后面追西方国家，追着追着，两个人跑到一起了，这就是并驾齐驱，多形象。不然你追谁呀？你总要有个目标。

不分伯仲、并驾齐驱这两个词放在这儿其实都有"读"的意思，但用法上不太严谨——一般形容文学艺术局面的情况会更多一些。所以这一空选并驾齐驱。

#### 第二空：自主创新，就是跟别人不一样

第二空：一代代科研人员自立自强、自主创新、拼搏超越，趟出了一条（　）之路。

结合前面看：我们的北斗实现了星间通、星星通，这是科研人员**自主创新**的成果——我跟别人不太一样嘛。所以选的一定是"跟别人不一样"的意思：**独具一格**。**别无二致**是完全一样、没有区别，正好相反。

答案选 D。

### 85 题：不求形似求神似，天道也可能有差错

#### 第一空：严丝合缝重在"合"，不在"同"

这题我第一次看也没看懂——什么鬼东西。但看不懂不影响你做对。

题干说徐渭受王阳明哲学影响，主张从心上立根，讲一个"真我"；他认为绘画的关键不在于临摹、不在于给予客观物象（　），而在寄心——**不求形似，求神似**，你画的东西不用长得完全一样。

所以第一空四个词挨个看：

| 选项 | 意思 | 去留 |
| :--- | :--- | :--- |
| 不差毫厘 | 完全一样，一模一样 | 符合"完全一样" |
| 肤寸而合（fū cùn ér hé） | 字面上每一寸都是相合的，也有"不差毫厘"的意味 | 意思对；不认识就保留 |
| 寸积珠垒 | 积累，偏时间上的积攒 | 跟语境毫无关系，排掉 |
| 严丝合缝 | 重点不在完全一致，而在配合紧密、没有漏洞 | 排掉 |

严丝合缝为什么不行？它强调的是"合得好"，不是"一样"。非洲和美洲可以严丝合缝——可它俩其实长得不一样，只是拼在一起能很好地合；榫卯结构一个凹一个凸，也能严丝合缝，但它俩不是不差毫厘；拼图也一样，两块其实不一样，不能强调"一样"的意思。而文段要的是完全一样：我要画这只猫，它长什么样，我就画成什么样。

顺带说一句，**锱铢必较**在这个语境里就是"每一个点都跟对象一模一样、画得特别像"——它长这样，我就一定要画成这样。

#### 第二空：重点在"打乱"，不在"顺序"

第二空：在他看来，近来天道都颇有（　）。后面跟着解释——被打乱了季节顺序，将四时花草汇于一处。

别管"天道"说得多么神神叨叨，你抓住解释就够了：**打乱**。乱了、有错、有问题，那就选**差池**，而不是**轮换**——轮换强调的是春过了夏、夏过了秋、秋过了冬，是正常顺序的更替。

道理在哪儿？春有桃花，夏有荷花，秋有菊花，冬有梅花，这四种花草本来不该出现在同一个地方、同一个时候，他非要把它们汇到一处，这就是打乱了季节顺序，就是有差错。这个题的重点不在于顺序，而在于**打乱了顺序**。

而且在他的观念里，他故意画得跟事实不一样：既然天道都可能出差错，那我画错了怎么了？所以这在他那儿也是合理的存在。答案选 D。

#### 出题人的套路：离谱项常常是"长得像"凑出来的

这个题还有个有意思的做法，我们昨天讲过：看哪个选项特别离谱、最不可能当答案。第一空最好排的是哪个？**寸积珠垒**——这题跟积累一点关系都没有，它凭什么出现？

这就是出题人的套路。他手里拿到的原文是"肤寸而合"，要出干扰项，就看看哪个词跟答案长得像：从"肤寸而合"里取个"寸"，再从文段的"锱铢必较"里取个"锱"，凑出一个"寸积珠垒"。所以当你纠结的时候，就看哪个选项很离谱——昨天讲的"一日千里对咫尺千里"那道题，也是一个思路。

## 选词填空 T 到 Y：86–92 题的成语与实词语境精讲
> 对应块：BLK36 | 覆盖分集：P20下 | 块标题（分集名）：《第四节：2026选词填空（四）T~Y（70-92》

先把上一题的尾收掉。有同学问：那个看着很离谱的选项，跟正确答案能有关联吗？有关联。选项再离谱，也不是它跟正确答案之间隔着一道墙——它错，是因为它落不进语境。顺着这句话，把上一题那个词补完整：**锱铢必较**。锱、铢都是极小的重量单位，合起来就是连很小的分毫都要计较，说小气也行，说较真也行，说"每一个细节都不放过"也行。

然后进 86 题。这一题是很多同学的"翻车现场"，三个空各埋一个坑，尤其是第三空，错的人一大半是把词的意思理解偏了。

### 86 题：眼睛是十分"精密"的器官

题干大意：眼睛是一个十分（　）的器官，对它动刀要万分谨慎；任何一个环节的（　）都可能造成严重后果；互联网时代，千万不能通过网上的（　）去选择一家医院做近视手术。

#### 第一空："精密"站得住，"独特"要排除

第一空后面那句话是关键——"对它动刀要万分谨慎"。为什么动刀要谨慎？因为眼睛经不起折腾，每一个环节都可能出问题，环环相扣。所以填"精密"是贴的：精密就是精确、周密，方方面面都得顾到。

有同学一听"精密"就犯嘀咕：眼睛是个器官，又不是仪器，能说精密吗？能。器官本身就像一台仪器，何况还要对它动刀，把它比作一台精密的仪器，顺理成章。而且"精密"正好能反映出环节很多、环环相扣这层意思。

"独特"为什么不行？独特只说明它跟别处不一样，不一定非要谨慎——独特和"动刀要谨慎"之间没有必然关系，体现不出重要性，排除。

#### 第二空：差池、疏漏才够消极

第二空的依据在题干里那句"都可以造成严重的后果"。任何一个环节的问题，一旦被放大，就会变成严重后果。所以横线必须填一个很消极的词。

差池、疏漏、失误这一路，够消极；"松懈"就不行了——松懈是态度上的松劲，词本身没有那么重的消极意味，放在这里力度不够。

> **提示**：看到"严重后果"这种词，先给自己一个信号——横线处的感情色彩和程度必须跟上，不能填一个轻飘飘的词。

#### 第三空："一面之词"必须有"两面"

这一空是本题的胜负手。很多同学把"一面之词"当成了"只言片语"的意思，觉得都是"网上三言两语的话"，这是理解错了。

**一面之词的潜台词是：事情至少有两面，而我只说了一面。** 打个比方：我和邓静老师吵架，吵得不可开交，老板过来问你们俩谁错了。邓静老师在那边吧吧吧说一堆，我不出声。这时候旁边有人劝："老板，您不能只听邓静老师的一面之词。"——这才叫一面之词。用这个词，前提是得有双方或多方在争执、在争论，你只听其中一方。

```text
  甲方 ──┐
          ├──► 只听其中一方转述 = 一面之词（必须存在争执双方）
  乙方 ──┘

  单条信息 ────► 网上的只言片语（中性，未必存在双方）
```

读图说明：一面之词成立的前提是"有对立的两面"，而网上获取信息并没有形成两个人争执的语境——比如网上有人说早饭一定要吃、有人说早饭可以不吃，这时候你只听一边，才叫一面之词；题干里只是让你别轻信网上的碎片信息，没有"两面"，所以不能用。

所以横线只能填"只言片语"。剩下的两个为什么也不行？不经之谈、流言蜚语都太重了，等于给网上的话定性为"全错"。可互联网上的话不一定全错，只言片语是中性的——可能有道理，可能没道理，但你不能轻信。

> **结论**：86 题三个空的落点依次是"精密"、消极一档的词（差池／疏漏）、"只言片语"，整题选 C 项。

### 87 题：患得患失与瞻前顾后——"想不想干"和"做没做"是两道坎

题干大意：有的干部把自己看得很重，把事业往后排，信奉"干得越多、摔得越多"，宁可撂挑子不干，也不能出错，（　）；还有的干部面对突发事件，错失最佳处置时间，导致事态扩大，（　）。

#### 第一空：落在"不干"上的词

第一空前面那一串铺垫，指向很明确：不干了、不想干了。所以横线要的是"不干"的意思。

| 词语 | 核心语义 | 干不干 |
| :--- | :--- | :--- |
| 患得患失 | 每走一步都想得特别多，反复权衡利弊 | 犹豫着，下不了决心，等于不干 |
| 首鼠两端 | "首鼠"古时通"踌躇"，就是犹豫不决 | 犹豫多了，也不愿意下决定 |
| 阳奉阴违 | 表面遵从，暗中违背 | 还是做了，只是做法跟你说的不一样 |
| 裹足不前 | 主观上各种各样的原因不想去做，内心纠结、担惊受怕 | 不干 |

逐个说。**患得患失**是这个人过于计较，每走一步都想得特别多，反而不好去做事。举个例子：小明在体制内待着，你跟他说别待了出来跟我赚钱，包赚。他想——年纪也大了，虽然说包赚，可感觉不太信；再想想现在也挺好。想得越多，越不容易做决定，这就是患得患失。有同学问：文段里也没体现出"得失"啊？不用非得体现。患得患失在这里就是"这个人很纠结，在反复考量做这件事的利弊"，我做了能得到多少、不做能得到多少，权衡来权衡去。它不等于必须在字面上出现得和失。

**首鼠两端**就是犹豫，做还是不做，犹豫不决，犹豫多了同样下不了决心，所以也说得通。

**阳奉阴违**为什么排除？它只是暗中违背，事情还是做了，只是做法跟你的要求不一样，提不出"完全不干"的意思，排除。

**裹足不前**的适用场景：因为各种各样的原因、特别是主观上的不想做、不想干，内心纠结、犹犹豫豫、担惊受怕，都能用它。

D 项被一句话带过，直接排除，不占篇幅。

#### 第二空：错失最佳处置时间，说明"没做"

第二空的依据是最后一句话：面对突发事件，错失最佳处置时间，导致事态扩大。有同学想回头看开头找依据——不用，盯最后一句话就够了。

先过第一道筛：他做了没有？没做。错失了最佳时间嘛。

| 词语 | 核心语义 | 做没做 |
| :--- | :--- | :--- |
| 瞻前顾后 | 犹豫太久，机会没了 | 没做 |
| 顾虑重重 | 顾虑太多 | 没做 |
| 推脱躲闪 | 推卸逃避 | 没做 |
| 敷衍塞责 | 表面上应付了事 | 做了，只是不认真 |

**敷衍塞责**这类词最容易被"做了没有"这把尺子量出来：敷衍了事，你是做了的，只是不认真而已。而这里要填"没做"的意思，所以排除。

最后落在**瞻前顾后**：你犹豫着、犹豫着，机会就没了；等想通了，没机会了——错过这个村就没这个店了。犹豫和"错失最佳时间"之间是直接的因果，这一空选它。

#### 投鼠忌器为什么几乎不选

这个词确实也含"没做"的意思，但它的使用语境非常严格，考试里很少考，原因就在它的字面结构上。

投鼠忌器的典故：家里出现了老鼠，我本来想拿东西把它砸死，结果怕把家里的瓶瓶罐罐打碎，于是不敢扔了。所以这个词表达的是：我很想做，但碍于客观情况，我没法做、不敢做。

```text
  想干 ──► 老鼠（目标）
              │
              ├── 怕砸碎瓶瓶罐罐（"器"= 顾忌的对象）
              ▼
            不敢放手干 = 投鼠忌器
```

读图说明：投鼠忌器必须同时出现"想干的事"和"有所顾忌的对象"——那只"鼠"和那堆"器"都得有出处，缺一项这个词就悬空。

用这个词，一定要把"顾忌的那个东西"填出来。你不知道他在顾忌什么，就不能用。而题干里这个干部面对突发事件，只是单纯地犹豫——到底做还是不做——没有体现出他到底在顾忌什么。突发事件本身不是"顾忌的对象"，题干没有写他因为怕打碎什么、怕牵连什么而不敢动手，所以这个词放在这里不合适。

> **易错点**：投鼠忌器的核心是"有所顾忌而不敢放手干"，不是"犹豫不决"。文段只写了单纯犹豫、没写出顾忌的对象，再眼熟的词也不能选。

> **结论**：87 题第一空落在"患得患失"（首鼠两端、裹足不前也通，阳奉阴违因为"还是做了"被排除），第二空落在"瞻前顾后"，整题选 C 项。

### 88 题：整体与细致之间，隔着信息量

题干大意：一种能监测心脏手术后并发症的新设备，可以完成比传统起搏器更复杂的监测。起搏器只能提供完整的整体图像，但新设备可以提供更（　）的图像，具体显示出心脏哪些区域不正常，以便在（　）的时候解除房颤、恢复正常心率。

#### 第一空："完整"为什么不行

先抓转折。前面说"只能提供整体的"，后面就不能再填"整体"的意思——转折前后要相反。"完整"直接出局：前面整体、后面完整，前后一个意思，转折就废了。

而且完整不等于具体。我画一张中国地图，两个岛都在，轮廓是齐的，它也叫完整；但它完整只是"不缺"、只是轮廓齐，不一定很具体。所以横线要的不是"不缺"，是"又多又全"的信息量。

#### 清晰、直观与细致，差在"量"

后面那句"具体显示出哪些区域不正常"是定盘星：横线一定要填出"非常全、非常具体"的意思。

**细致**就是方方面面都考虑到了，精细、周密、全面——这跟昨天最后一道题的"条分缕析"是同一路：分析得很细、很全，既能对应前面的反面（只能提供整体轮廓，信息不够、不全），又能对应后面的"具体"。

清晰、直观为什么不行？它们只说明"看得清楚"。我画一颗爱心，说这是一颗爱心，它也很清晰、很直观啊；但它不够细致——内容太少。清晰的反义词是模糊，跟数量多少没关系。一个正方形画得清清楚楚，不模糊，你一眼看得见，但它不具体。

> **提示**：遇到"整体—具体""轮廓—细节"这类对照，先问自己：横线要的是"看得清"，还是"信息量大"？这两件事不是一回事。

这一空选"细致"。

#### 第二空：搭配的是"时候"，还有那个"此需非彼需"

第二空其实不难做，四个词搭配的都是"时候"：关键的、需要的、适当的、凶险的时候。判据只有一条——能体现出这个时候的重要性就行。"关键的时候"解除房颤、恢复正常心率，讲得通。

有同学选"需要"，理由是前面出现过"虚"（需）。这里要敲个警钟：**你找错对象了**。此"需"非彼"需"——前面那个"需"说的是刺激的需求量：病得重就多刺激一下，病得轻就少刺激一下，它搭配的是"需求量"；而横线这里搭配的是"时候"。两回事，没有任何关系。

> **结论**：88 题第一空选"细致"、第二空在"关键／需要／适当／凶险"里取能体现重要性的那个，整题选 B 项。

### 89 题：崭露头角与初见端倪——两空要的是意思接近

题干大意：宜宾通过发展智能终端、信息技术服务业，逐渐在数字经济领域（　），以它为代表的智慧城市（　）。

#### 时态先行："呼之欲出"是还没出

第一空后面有个时态标记：智慧城市"已经（　）"了。说明时态是完成时——某种意义上已经成了。而崭露头角、初试锋芒、小试牛刀，给人的感觉都是"才能已经表现出来"，时态对得上。

"呼之欲出"这个词有两个意思，两个都用不上：

1. 形容写作描写生动。比如写小说，曹操、关羽这些人物形象呼之欲出。这跟数字经济没关系。
2. 形容马上就要出来、即将揭晓——"欲出"就是还没出、就将出。华为马上要发布一款新车型，这时候才叫呼之欲出，因为还没出来呢。

题干问的是"已经"，时态对不上，直接排除。

#### 空与空照应：意思越接近越好

这道题的关键在两个空之间的关系。前面说宜宾在数字经济领域怎么样，后面说智慧城市怎么样——智慧城市不就是数字经济的一种形态吗？所以前后两个词的意思必须非常接近，这是一个典型的"两空关联"题：两个空之间要互相照应，意思差别要小。

第一空如果是"崭露头角"，第二空"初见端倪"就对得上——都是刚刚开始露出一点点。小荷才露尖尖角，就是这么个感觉。初见端倪也是中性词，只是刚刚表现了一点点。

那另外两组为什么不合适？因为它们组内两个词的意思并不接近：

| 选项组 | 第一空 | 第二空 | 问题 |
| :--- | :--- | :--- | :--- |
| A | 崭露头角（露出一点点） | 初见端倪（刚刚露头） | 意思非常接近，工整 |
| C | 初试锋芒（刚刚试一下） | 脱颖而出（完全展现） | 一个是一点点，一个是全部出来了，程度不一样 |
| D | 小试牛刀（试过了、做过了） | 欲遮还露（遮住了，看不见） | 一个要露，一个要遮，自相矛盾 |

> **结论**：两空关联题，选意思最接近的那一组。89 题答案是"崭露头角"配"初见端倪"，选 A 项。

### 90 题：小题大做与尊重——舆论质疑不是没事找事

题干大意：一些医疗机构出现"手术量创新高""开门大吉""手术室里全是钱"这类离谱的宣传标语，都曾引发舆论关注和质疑。可见，这并非公众敏感或（　）。公共服务宣传表达本质上是与公众的沟通对话，要坚守同理心原则，每一句标语都应体现对患者的（　）和关怀。

#### 第一空："并非"之后，要把"不重要"显出来

这一空有点绕，慢慢拆。

前面说"都曾引发舆论关注和质疑"——就是公众很重视。后面说"并非公众敏感或（　）"，前后意思差不多，都在讲公众的关注。而横线前面有个"并非"，双重否定表肯定，所以横线要表达的是"不太重视""不重要"这一路意思。

翻译一下：我们这么多人关注这些标语，不是公众过分关注，不是公众故意把不重要的事情变成重要的事情。而是这个事情本来就很大，本来就该让我们重视——不是没事找事，不是把小事故意放大。

所以横线要体现的是"把不重要变重要""故意找茬"这层意思。

| 词语 | 核心语义 | 能否体现"把不重要变重要" |
| :--- | :--- | :--- |
| 小题大做 | 把小事情当成大事情来办 | 能 |
| 吹毛求疵 | 故意挑剔毛病 | 能 |
| 捕风捉影 | 没有任何根据 | 不能，它讲的是"无根据" |
| 无事生非 | 完全没有事、无中生有 | 不能，跟"重不重要"无关 |
| 不依不饶 | 得不到满足就不肯罢休 | 不能，体现不出"不重要" |

小题大做、吹毛求疵留下，其余排除。也有老师主张从"敏感"的角度去对，觉得那样也能说通；但另一路解释怎么都讲不顺。更稳的做法是把前后文连起来看，抓住"不是公众故意找茬，而是这事本来就大"这一层。

#### 第二空：体谅、体恤、尊重的分寸

第二空的依据是"同理心"。什么是同理心？就是站在别人的角度想问题——所以它一定是一种平等关系，一定不是上位者对下位者的姿态。落在横线上，就是"尊重"。

| 词语 | 核心语义 | 为什么不用 |
| :--- | :--- | :--- |
| 尊重 | 平等相待 | 同理心要求的正是平等关系 |
| 体谅 | 包容别人的难处和过失 | 患者并没有犯错，"难处和过失"从何而来 |
| 体恤 | 替他人着想而怜悯帮助，侧重同情和照顾 | 体恤下属、体恤百姓、体恤民众、体恤民生，一般是上位者对下位者的关怀 |
| 理解 | 站在对方角度去想 | 意思上没问题，但不如"尊重"贴 |

"体恤"这个词尤其要留意：它是强者对弱者、上位者对下位者的同情与照顾。你对患者说"我体恤你们"，那姿态就是你高高在上、患者在下面——这与同理心要的平等关系正好相反。老师在这里顺口打了个趣：互相尊重，那是平等关系才有的词，医患之间也该是这么个位置。

"体谅"则是对方有难处、有过失时你的包容——患者犯了错你才体谅他，题干里没有这层意思，所以也不合适。

> **结论**：90 题第一空落在"小题大做"（或"吹毛求疵"那一路），第二空落在"尊重"，整题选 A 项。

### 91 题：渊薮对宝库——考的是对仗，不是认识不认识

这题说实话很无聊：文绉绉地摆一个生僻词，你认识就会做，不认识就不会做。但正因为它把很多人的正确率打得很低，更值得把里面的门道看清。

题干大意：《永乐大典》是最大的类书、最大的百科全书，收录典籍七八千种，被誉为"（　）"的艺术宝库。

#### 对仗：典籍对宝库，横线只负责"汇聚"

先找对应关系。题干并列的两截是"（　）典籍"和"艺术宝库"：典籍对的是"宝库"，都是"书的集合"这一层意思；横线要对的，就是"艺术"那一层位置。

但横线真正需要承担的任务，只有一个字——"汇"。它只要把"聚集、汇聚"这层意思递到位就够了，因为"典籍"本身就是"文"，文的对仗任务已经被"典籍"承担了。

文段的核心话题是"多"：最大的类书、最大的百科全书、七八千种。所以横线必须能体现"多"和"好"——好的人或物聚集的地方。本源、桂冠都不体现"多"，先排除。

#### 渊薮是什么，"文汇"差在哪

**渊薮**（yuān sǒu）：渊是鱼所居之处，薮是水边兽所居之处，两个字本义都是"聚集之所"，引申为好的人或物聚集的地方。它对应"宝库"再合适不过——又多又好。顺便说一句，有同学拿去问工具，回来说这个词含贬义。别全信，仅供参考；它在这里是中性偏积极的。

那"文汇"差在哪？文汇是文艺精华汇聚之所、文化荟萃，意思上也沾"多"。问题出在它多带了一个"文"字：

```text
  荟萃典籍 ， 艺术宝库     ← 工整：横线只承担"汇聚"，典籍对宝库
  文汇典籍 ， 艺术宝库     ← 不工整："文"与"典籍"的"文"撞车，构成重复
```

读图说明：把"文汇"换成"荟萃"，"荟萃典籍、艺术宝库"就是完美的对称关系；而"文汇典籍"让"文"的意思出现了两遍，对应关系反而不严谨。横线不需要你体现"文"，你的第二个字"汇（聚）"就够了。

> **结论**：91 题答案是"渊薮"，选 B 项。这题考得僵硬、正确率很低，做错了没关系，但"渊薮＝鱼兽所居、引申为聚集之所"这个义项要攒下来。

### 92 题：娓娓道来配按图索骥——收官题的对比择优

今天最后一道题，也是容易纠结的一道。

题干大意：优秀的文旅纪录片往往以更具真实性的镜头语言、平实的手法来浓缩精华，将当地的特色历史生活（　），展现小情趣、小美好，使游客循着纪录片中的线索（　）。

#### 第一空：和盘托出与平铺直叙都不合适

**条分缕析**第一个排除——"小情趣、小美好"是给人看的、给人感受的，不用分析它。

**和盘托出**也不行。我们什么时候用这个词？审人的时候，对方说供词，"坦白从宽、抗拒从严"——我没有保留地说出了秘密和实情。它骨子里带着一种"被迫交代"的感觉：没招了，没办法，只能说出来。你一个优秀的纪录片在讲故事，用不着这种腔调。更何况题干说的是"浓缩精华"——只讲精华，本来就不是和盘托出。

**平铺直叙**最具有迷惑性，因为题干里明明有"更具真实性""手法平实"。但你要分清：真实的是镜头语言，平实的是叙事手法，而你填的这个空评的是叙事带给人的那层感受。平铺直叙意味着不带任何感情——一个不带感情的叙述，体现不出小情趣、小美好。所以它也不合适。

剩下**娓娓道来**：给人感觉像在讲故事。纪录片讲故事，让人想起《舌尖上的中国》那个富有磁性的男声一出来，气氛就对了。这一空选它。

#### 第二空：按图索骥与顺藤摸瓜，差在"图全不全"

两个词都有"线索"的意思，区别在于线索给得全不全：

```text
  按图索骥：  [完整的一张图] ──► 照着图逐点去找（线索本身是全的）
  顺藤摸瓜：  [战争迷雾 …… 只露出一根藤 ……] ──► 从局部摸到整体（只给一线）
```

读图说明：按图索骥是先把完整的图给你，你拿着图照着找就行；顺藤摸瓜是四周全是战争迷雾，只露出小小的一根藤，你得顺着这个局部，去摸到那个整体、那个更关键的内容。

顺藤摸瓜在昨天讲的一道国考真题里出现过：那种"从基层往高层摸"的路子，类似自下而上，顺着某个线索找到它的根底。

回到题干：游客循着文旅纪录片中的线索去（　）。纪录片早就把人文底蕴、历史底蕴都呈现给你了——线索是完整的，不是只露一根藤。所以优先考虑"按图索骥"。

> **提示**：按图索骥也有"刻板、不知变通"的贬义用法，但它同时有单纯的中性义"按照线索去寻找"，这里取中性义。

#### 语义重复不是考点

有同学问："循着线索"和"按图索骥"有没有语义重复的嫌疑？没有。把这句话记住——**语义重复并不是言语理解的考察重点**，尤其是对成语。我们讲了四天、将近一百道题，很少出现靠语义重复来设陷的题。

重复一般在什么时候才考虑？修饰关系里。比如"的"字结构："忍俊不禁地笑了"——忍俊不禁本身就是笑，这就算重复。而"循着线索去按图索骥"不是修饰关系，这里取的就是"寻找"的意思，跟在举足轻重里取"关键要素"是一个道理：我跟着线索去找，而且我要填一个跟"找"相关的成语，那就只能填按图索骥。

> **结论**：92 题两空都是"娓娓道来"配"按图索骥"优于另一组，整题选 B 项。
