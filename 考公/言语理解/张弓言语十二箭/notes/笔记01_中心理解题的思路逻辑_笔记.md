# 中心理解题的思路逻辑

## 题型根源：中心理解与词的辨析

* **中心理解（Central Understanding）**

    * > **定义**：言语理解与表达各个题型共通的底层能力——判断一个文段在说什么、哪句话是重点。

    * 片段阅读除了细节判断可能差点意思之外，考的就是对文段的理解能力，也就是这个文章在干嘛；整个语句表达模块本质上也是考察中心理解。

    * 课程把前五节都压在中心理解上，原因是中心理解这个题型学好了，后面的题型一通百通。

* **词的辨析（Word Discrimination）**

    * > **定义**：逻辑填空在文段理解之外额外考察的另一半——对词语本身的辨析与积累。

    * 逻辑填空分为文段加选项，文段的理解本质上又是中心理解，只不过在文段理解的基础上还要考察词语的积累。

    * 这个题型难，就难在它既考察中心理解，又考察词语的理解。

* **题型与根上考点的对应**

    | 题型 | 根上在考什么 |
    | :--- | :--- |
    | 标题题 | 填一个标题、把握主旨，本质上就是中心理解；标题就是中心，中心就是标题，两个题型没有任何区别 |
    | 词句理解题 | 要理解某个词、某句话在文段里的意思，得先对整个文段有所了解，是中心理解或者细节判断的变形 |
    | 细节判断题 | 主要就是查找信息，是个比较小的题型 |
    | 语句填空题 | 要抓住横线的核心意思、知道这句话填什么，就得把握上下文，而上下文的把握还是中心理解 |
    | 接语选择题 | 接下来想说什么，后文不能偏题，后文的内容要跟前文保持一致，所以还是得知道前面在干嘛，是中心理解的变形 |
    | 语句排序题 | 考的是句子和句子的关系，从根上来讲也是中心理解理解得到位 |
    | 逻辑填空题 | 分为文段加选项，文段的理解本质上是中心理解，只不过还要考察词语的积累 |
    | 篇章阅读 | 各个题型的综合，更不用说 |

    * > **提示**：言语理解与表达的题型虽然非常多，但根本上就两个题型——第一个是中心理解，第二个是逻辑填空当中词的辨析。

## 中心理解三步走

* **第一步·找重点**

    * > **定义**：通读全文，在这么多句子当中找到那个最重要的一句，也就是中心句或者主旨句，两者本质一样。

    * 判定依据是句子的逻辑关系，常用的就是七类关系。

* **第二步·同义替换**

    * > **定义**：在选项里找一个最像的，看哪个选项跟文段的重点部分最接近。

    * 依据是主题词：先把主题词抓住，再在选项里找带它的。

* **第三步·排除干扰选项**

    * > **定义**：按三类对比的次序排除，剩下的挑更好的。

    * 第二、三步常常合在一起用：只有 B 带主题词、A/C/D 都不带时，直接选 B。

* **三步的可忘性**

    * 今天所有的内容都可以忘掉，但这三点得记住：第一步找重点，第二步同义替换，第三步排除干扰选项。

    * 市面上绝大多数的言语教学体系，关于中心理解这一块都是围绕"怎么找"展开的，而且只讲了怎么找，没有第二步、第三步。

```text
一个文段
   │
   ▼
┌───────────────────────────────────┐
│ 第一步  通读全文，找重点           │ → 中心句 / 主旨句
│          （七类句子关系）           │
├───────────────────────────────────┤
│ 第二步  同义替换                   │ → 主题词是依据
│          （找一个最像的选项）       │
├───────────────────────────────────┤
│ 第三步  排除干扰选项               │
└───────────────────────────────────┘
```

## 七类句子关系

* **转折关系（Transition）**

    * > **定义**：前后语义方向发生反转的句子关系，重要的一半是转折后。

    * 例：虽然我生病了，但是我还在上学——上学重要。

* **因果关系（Causality）**

    * > **定义**：由原因推出结果的句子关系，重要的一半是结论、结果。

    * 例：开始学英语，后来学化学，又学数学，最后发现物理才是我最喜欢的——物理是重点，前面的过程、原因没那么重要。

    * 中间的过程不重要，因果、结果重要。

* **必要条件关系·对策（Necessary Condition / Countermeasure）**

    * > **定义**：指出解决问题所需条件的句子关系，重要的一半是对策。

    * 例：我不舒服，我需要吃一些药——解决问题比问题本身、比意义都更重要。

* **解释关系（Explanation）**

    * > **定义**：一边是观点、一边是详细解释展开的句子关系，重要的一半是前面明确直接的观点、论点。

    * 例：老李是一位慈祥的老人，每天都会笑嘻嘻地和同学打招呼——"慈祥"是观点，后面是为了论证它的。

    * 判定要点有两个，要一起记：前后意思保持一致；一般解释的东西会长一点。

    * 一个这么短、一个这么长，短的一般就是观点，长的一般就是解释或者例子；越详细越展开越不重要。

    * 学判断的同学都知道，论点比论据重要。

* **强调关系（Emphasis）**

    * > **定义**：用程度或范围提示把某个内容提上来的句子关系，重要的一半是被强调的内容。

    * 例：我们班同学大家都非常不错，特别是小红非常好——重点是小红。

    * "更普遍""更高""特别是""更需要"都是强调信号。

* **新旧关系（Old-New）**

    * > **定义**：后文出现前文没有的新话题的句子关系，重要的一半是后文出现的新话题。

    * 例：过去的深圳一片萧条，今天的深圳非常繁华——新的重要。

    * 读文段时突然冒出"这什么玩意儿"、前文没有的东西，尤其要注意，这是新话题。

    * 例："诗源于情感，但应该超越情感"是转折；后文说超越建立在基础之上、诗不能等同于一般的情感抒发和宣泄、应该有更高的使命，"更高"表强调；前面通篇在讲情感，怎么就多了个"志"，而且是"更高的"志，所以到这"志"重要。

    * 同一条文段往后，"总之"一类的总结仍在讲志——超越、要求、标准；再往后"道始于情""精神的源头是情感""情感不加控制就流于欲望本能，要经过疏导才能上升为道或者理"，是在说情感在文段里地位并不高，最高的是道和理。

    * 道和理就是"志"的同义替换，都是那个"情"之上的、偏理性的东西；道也好、礼也好、志也好，在这个文段里是一个意思。

* **并列关系（Coordination）**

    * > **定义**：几个内容分量相当、分不出主次的句子关系，没有谁更重要。

    * 例：小黄喜欢华山，小红喜欢黄山，小明喜欢嵩山——哪座山都重要。

    * 并列的本质就是不分轻重；既然不分轻重，就需要全面概括，一个都不能少。

    * "一方面……另一方面……"就是并列关系。

* **七类关系的用法**

    * 判断谁重要谁不重要，重点是判断句子的逻辑关系，常用的就是这七类。

    * 做题时想想这个文段符合哪种关系，就能判断谁轻谁重；不重要的标绿色，重要的标红色。

### 庖丁解牛与结构标签

* **庖丁解牛（Decomposition）**

    * > **定义**：高手读文段时，看到的已经不是一个单纯的文段，而是一个一个的结构——提出问题、分析问题、解决问题。

    * 古人说的"目无全牛"：它在你看就不是一头完整的牛，而是一段一段的，这就是对文段理解清楚了。

    * 常见的作用就那么些，绝大多数题目就是这些东西的排列组合：已知话题加观点加举例、背景加观点加举例、提出问题加分析加解说。

    * 学习动作：把原文在脑子里翻译成这样的文段，让它成为一个一个的骨架和结构，这是最精华的、本质的部分。

* **结构标签（Structure Label）**

    * > **定义**：分总、总分、分总分这类标签，只是标记中心句的位置。

    * 中心句在中间就是分总分，在尾句就是分总。

    * 结构不重要，真正要回答的只有一个问题：中心句在哪。

## 对关联词的态度

* **关联词（Connective）**

    * > **定义**：标示句子关系的词语，是初学者学习的一根拐杖，不是腿。

    * 它有点重要，但没想象中那么重要；刚开始学走路抓一些关键词没问题，但不能老抓，不能活了二十岁还拄着拐杖。

* **删词试验（Deletion Test）**

    * > **定义**：把句子的关联词删掉，看句意是否受影响，用来检验关联词到底有多重要。

    * "今天不舒服，我还是来了""今天不舒服，我没来""今天不舒服，我吃药"——删掉关联词，本质上不影响句意。

    * > **提示**：句子和句子的关系并不完全由关联词决定；关联词的存在与否，不能完全构成我们选择的依据。关联词是表象，句子的内容才是本质。

* **"而"的多义性**

    * > **定义**：同一个字可以标示多种关系，可见单个字不能当选择的依据。

    * "学而不思则罔"表转折；"学而时习之"表顺承；"意义重大而深远"表同时；"青出于蓝而胜于蓝"表递进。

* **局部与整体（Local vs. Global）**

    * > **定义**：中心理解看的是句子和句子的关系，所以部分内容的关联关系不一定代表整体。

    * 关联词可能只是某一句话的，那一句话不一定是整个文段的重点。

    * 例：先说"看似狠心，其实难度不高"，局部重点是转折之后的"难度不高"；后面接"很多同学问：难道我可以放松警惕了吗""之前有同学因此没准备、没考好，所以我们还是要认真对待"，整体重点从"难度不高"变成"认真对待"。

    * 读薄成两半：难度不高 vs 还是要认真对待，本质上还是转折关系，转折之后起了个对策；很多时候关系都是综合在一起的。

    * 例：先给背景"现代化是多彩的、色彩纷呈的、多元的"，再提对策"从这个角度推进现代化，要摒弃以我为中心、唯我独尊的立场"，若文段到此为止"需要摒弃"就是重点；但后文接"遗憾的是，当今西方的一些思想家心存偏颇"，整体转为转折关系，重点变成西方思想家存在偏颇；尾句"这样一种理论"回指前文，落脚到"我们对于西方这些偏颇的思想应该有警醒"，又变成对策关系。

    * > ⚠️ **易错点**：一个文段不能只读一半，你得有整体思维，要看完整；停在半程就选，会漏掉后面整体关系的变化。

## 同义替换

### 大意一致与抓大放小

* **同义替换（Paraphrase）**

    * > **定义**：找一个和中心句最像的选项，大意一致即可。

    * 别拿着中心句跟选项逐字对暗号，意思对上就行；大多数情况下不能要求中心句和正确答案表述完全一致。

* **抓大放小（Big-First）**

    * > **定义**：找选项时先看有没有核心内容，先把最重要的东西抓住，这才能作为答案。

    * 完美主义做不好中心理解题。

    * 例：一家机构招十个言语老师只有会言语，身高、颜值、星座都属可以放掉的小；别的有些缺点没关系，重点抓住就可以。你先抓主干，不要抓那些有的没的。

    * > **提示**：第二步的口诀是"抓大放小，先大后小"——大是主题词，小是细节表述；细节可以换，主题词不能丢。

### 主题词及其三个找法

* **主题词（Topic Word）**

    * > **定义**：一个文段当中最关键的内容、必不可少的核心话题，通常是核心的动名词——谁要干什么事。

    * 正确答案得有主题词，不能没有它；主题词这一关，就是帮你在第二步里排雷的。

    * 一般操作手法：先找到重点，提炼主题词、提炼核心话题，这是同义替换的依据，必须有它；然后选项里先找有它的，没问题就可以直接锁定，其他的排除。

    * 找法一，中心句的核心话题。例：前两句"虽然……并不禁止通行"是转折、后两句"原因显而易见"是解释，中间那句既有转折关系又有解释关系、前有引入后有解释，就是中心句；从中提炼核心动名词，整个文段就围绕这两个点讲。

    * 找法二，高频词：每句话都围绕着相同话题，看完整个文段感觉通篇全是某一个词，那它大概率就是主题词。

    * 找法三，首句引出的话题：很多时候首句引出的话题即为文段的主题，这一点很多同学、甚至很多老师都忽视了。

    * 例：开篇"生态保护修复工程建设周期一般是三到五年，而高寒地区群落完成自然演替往往需要几十年乃至更长时间"，基调就定在这个工程需要的时间长；答案落在"后期"上，只有"后期"对应"时间长"——不是建完就没了，后面还需要几十年乃至更长时间。

    * 三个方法用以一为主：以找到中心句为主，同时综合高频词和首句来判断；只靠一个有点骗自己，综合判断最保险。

* **主题词与转折的分工**

    * > **定义**：转折、结论是解决第一步的，帮你找重点；主题词是第二步的，重点找到之后帮你到选项里选答案。

    * 只找中心句，可以不用找主题词；找主题词，是为了帮你找答案。

    * 两个的作用不一样，所以"转折和主题词是什么关系"这种问题本身就不成立。

### 替换的尺度

* **原词优先（Original Word First）**

    * > **定义**：主题词优先考虑原词，特别是一些专业名词。

    * 主题词是"言语"，尽量选"言语"；但它并非一定是原词，有的时候可以适当地扩大，也可以适当地缩小。

* **同义替换的常见尺度**

    * 帅替换成颜值高没问题；文化换成文明，真正做题的时候就发现区别没那么大；技术换成技艺，也还行。

    * 音乐换成艺术稍微有点大，需要斟酌——但凡有"音乐"就不选"艺术"，万一非没有的话，选个"艺术"也可以。

    * > **提示**：适当扩大、缩小的替换不是不行；选项之间永远是比出来的，不是拿满分答案比出来的。

    * 文段白纸黑字写着"自动驾驶"，放着自动驾驶不选而非要选"智能技术"，就是没做到更贴近原词；有肯德基就不吃华莱士。

    * 例：第一句引出"影视作品凝结的不仅是创意，还有意识"，接着"一方面……另一方面……"，形式上当然是并列，但第一句话提到"重复"了吗？没有，所以整体比第一句多了一个内容，是新观点，属于新旧关系；两方面概括起来就是"重新"，对应选项里的"翻拍"。

    * 同一个文段里，"对待经典影视作品的正确态度"从对错角度不算错，但"正确态度"到底是翻拍还是不翻拍？太大、不明确，还不如"翻拍"明确。

## 排除干扰的三类对比

* **对比则优（Compare and Pick）**

    * > **定义**：排除要有类别、要有差异，哪些优先考虑、哪些排第二第三，得有一个依据。

    * 对比的次序：先把"一定不能选"和"基本不能选"尽量排掉，剩下的在"对比可选"里挑更好的；真有特殊情况，再特殊考虑。

    | 类别 | 地位 | 典型表现 |
    | :--- | :--- | :--- |
    | 一定不能选 | 死罪，说破天也不行 | 语义相悖、无中生有、无关对策 |
    | 基本不能选 | 九成不能选，有例外但不多 | 缺少主题词、非重点、片面 |
    | 对比可选 | 可以选，但没那么完美 | 主题词扩大/缩小/替换、选项不明确 |

    * 二、三常常合起来用：只有 B 带主题词、A/C/D 都不带时，还犹豫什么，直接选 B。

### 一定不能选：原则性问题

* **语义相悖（Contradiction）**

    * > **定义**：选项意思和文段往相反方向走——文段往东你往西。

    * 例：文段把客体、主体、内容、期限、权利限制全讨论到了，选项说"争议流于表面"，这叫相反、与文意相悖。

* **无中生有（Unfounded）**

    * > **定义**：文段里压根没说，选项愣给编出来。

    * 例：文段只说有学者主张通过公法保护，选项说"通过公法保护民间文学艺术是最可行的路径"；顶多说某个人是优秀的老师，不能拐弯说某个人是最优秀的，这叫绝对化，也叫无中生有。

* **无关对策（Irrelevant Countermeasure）**

    * > **定义**：文段提问题，选项给的对策解决不了这个问题。

    * 例：文段说方案"因质疑声过大而夭折"，选项说"还要倾听多方意见"——越是倾听多方意见越通不过，这叫无关对策。

    * > **提示**：相悖、无中生有、无关对策，这三个属于原则性问题，是死罪，后面讲出花来也没用。

### 基本不能选：九成要排掉

* **非重点（Non-Key Content）**

    * > **定义**：做中心理解题是找重点的句子，把不重要的句子给我，一般是不选的。

    * 非重点包括：转折前的、结论前的、程度前的、中心句前面的引入/背景/问题、中心句后面的解释/举例/意义/数据。

    * 例：文段"进而"之后才是结论"没有胁迫的情况下服从群体规范"，"人们为什么会服从呢？可能是源于害怕被别人孤立"是解释关系，"挪威大鼠……"是举例子，例子的本质也是一种解释关系，所以整段是总分，重点只有那一句结论。

    * 选项"容易受到他人影响"在"进而"之前，是因果里的原因一方，而且不明确：到底是被威胁还是没威胁；选项"挪威大鼠"看着引出新话题，但大鼠的内核没变——忽视自己爱吃花生米、看别人吃大米也去吃大米，选择同伴偏爱的，就是服从群体，只是这个例子一时间没看出来。

    * 例：文段先说生产性服务业包括很多方面、又说国外经验表明制造业竞争提升更多靠现代生产性服务的支撑，这都在讲它太重要，算背景；"相较而言"来了，滞后、不足、不合理，两个字送给他：问题；"需要……推动生产性服务业向专业化和价值链高端延伸，更好地服务制造业发展"，"需要"表对策，整体是引出话题加提出问题加解决问题，主要关系是对策。

    * 同题的选项里，"更好地服务制造业"是对策的意义效果——只有上岸了才有工作，工作需要提升才更重要；"涉及到众多领域"对应开头那一串"很多方面"；"和制造业的发展息息相关"对应"制造业竞争提升要靠生产性服务业支撑"；三个都跟中心句没关系，全是非重点。

* **缺少主题词（Missing Topic Word）**

    * > **定义**：选项身上没有文段的核心话题，一般是不行的。

    * 例：通篇讲"残"的文段，围着古建筑说的、围着世界遗产说的两个选项都没带"残"，直接出局。

    * B 项里打了引号的"废墟"是不完整的意思，不完整就是残，只是换了个表达方式，所以两个选项都带着主力词；再看语气——"何以"是问原因、就是"为什么"，"何为"是问"是什么事"，文段最后一句"可又该如何解释呢"是在问为什么，所以选 B 不能选 C。

* **片面（One-Sided）**

    * > **定义**：只圈了半个范围。

    * 例：文段讲古建筑、雕塑乃至日用品的"残"，选项只圈了"建筑"，把雕塑、日用品丢了，属于片面；只是这个问题比较小，真正判它死刑的还是语气不对。

    * 例：并列结构里一个选项只提到人口多、没提到外国人多，另一个只提到外国人多、没提到人口多，外国人多和人口多是两码事，两个都片面。

    * > ⚠️ **易错点**："往往"不等于"绝对"——往往是大概率，绝对是百分之一百；选项把"往往"偷换成"绝对"，或者只挑材料里的一部分说事，都属这一类。

### 对比可选：可以选，但不完美

* **主题词扩大/缩小/替换**

    * > **定义**：选项把主题词的范围适当地扩大、缩小、替换了一下，不算错。

    * 音乐换成艺术可以，音乐换成美术不行——只要不换错行当，词儿是可以换的。

    * 例：主题词是"传统旅游城市"，选项扩大成"城市"，肯定不好，但至少没有脱离大的范畴，可以勉强接受。

* **不明确选项（Vague Option）**

    * > **定义**：话没说清楚的选项，通常带着否定词，或者过于笼统。

    * 例：考完试说"我要出去玩"也不错，但另一个选项说"我要去东北玩"肯定更明确；可如果没有那个更明确的，"我要出去玩"就是可以次选的。

    * 例：书法课那道题，首句"很多高校开设的书法课被认为是辅助课程、附属课程"引出话题，接着说"书法教学成为重要的一环，未能充分发挥"，这种不好的表述两个字概括：问题；然后"不仅有助于……更有助于……"，重要性讲得再多，也只是再次证明问题严重；尾句"汉语国际推广下的书法课应该定位于独立于语言课、技能之外的核心课程"是对策，分总，重点在尾句。

    * 同题第二步抓主题词：书法大家都有，抓"定位"才能选出带定位的那项；带"传播"的在前文、带"尴尬地位"的属于问题，问题和对策之间对策更重要；但那一项单独看也并不好——到底定什么位？话说得不完整、很模糊，可人比人，总比其他几个离题要好一些。

    * > **提示**：不明确选项是可以次选的，不要说"它不明确"——跟其他几个比，它已经非常不错了。

## 首句的作用

### 首句引出的话题大概率是重点

* **首句（Opening Sentence）**

    * > **定义**：首句的句子可能并不重要，但首句引出的那个词可能很重要。

    * 第一句并没有直接点出文段的重点，但它先告诉了你我在讲谁；后文不管展开什么内容，往往都没有脱离这个核心话题。

    * 原理与排序题同源：适合当首句的是下定义、引出话题、背景，统统是"先把话题引出来，再围绕它讲"的路数；中心理解的逻辑和这里是同源的——先引出，再详细展开。

    * > **注意**：在读完整个文段之前，单看第一句，判断不了它是单纯引出话题还是提出观点；到底是哪一种取决于后文，千万别在前两句话上就盖棺定论。

* **两个问题（Two Questions）**

    * > **定义**：很多文段就是两个问题——第一个我在讲谁，第二个我在讲他的什么。

    * 标题题同理：标题就是中心理解，本质上是一回事，第一句就是干嘛的。

    * 例：开篇"体育文化是重要的"，随着科技革命的不断深入又说了两次"体育文化迎来新的机遇"，后文数字科技、数据平台、数字化体育文化产品都没有脱离体育文化；先把没有体育文化的干掉，再对比——一个只有体育文化，一个多了一个数字技术，而数字技术在前文反复出现，所以选多一个数字技术的那一个。

### 开头话题与新话题的三种情况

* **情况一·围着老话题的新角度深入讲**

    * 开头引出本段讨论的话题，后面没有脱离它，只是围着这个话题的某个角度继续深入讨论，比如提对策。

    * 这时候开篇引出的话题仍然是重点，结合新的角度选答案即可，这是考得最多的一种情况。

    * 例：开篇说"学校是……"引出话题，接着说"学校应该加大青少年的安全教育"；"安全教育"相比前面是个新东西，前面没提过安全，但讲这个观点时并没有脱离"学校"这个大范畴，开篇话题和新角度都重要。

* **情况二·又提新话题但没推翻前面**

    * 开头引出本段讨论的话题，后面没一直围着它讲，而是又提出了新话题，但新话题没有反驳和推翻前面的观点。

    * 这时候文段类似并列结构，几个话题之间没有轻重关系，那就都重要，全面概括，一个都不能少。

    * 例：先说学校是什么，再说家庭是什么，再说社会是什么，概括一下就是并列文段。

* **情况三·新话题把前文终结了**

    * 后面提出新话题，并且这个新话题某种意义上结束了、反驳了、推翻了前文的话题，此时后面的新话题更重要。

    * 例："以前的人们认为公务员很简单，其实大家发现公务员考试很难"，后面的话题就终结了前面的观点；这种题是三种情况里最少的。

    * 例："学校是青少年聚集地，但是家庭才是青少年的栖息地"，重点是家庭；但它推翻了学校，却还在围着青少年讲。

    * 话题被完全推翻其实很少见：多数时候话题本身没有变，变的只是相关的某个态度和观点。

    * > **提示**：后面若出现新话题、新角度，一定值得关注；开头引出的话题，只要后面没有进行全面反驳，通常也很重要——因为它规定了一个探讨的范畴。

```text
              开头引出话题（规定整个文段的探讨范畴）
                              │
              ┌───────────────┼───────────────┐
           情况一             情况二             情况三
      围着老话题的         另提新话题，         新话题把前文
      某个角度深入讲       但没有推翻前文        终结、反驳
              │                │                   │
      开篇话题仍是重点，     类似并列结构，        新话题更重要
      答案要"回扣开头"       全面概括，一个        （三种情况里
                             都不能缺             最少见）
```

### 答案回扣开头

* **回扣开头（Callback to the Opening）**

    * > **定义**：国考出题人的常见习惯——在后文引出重点内容之后，再 call back 一下开头引出的话题；答案往往是"开头话题"加"后文重点"的合体。

    * 从 2021 年起，几乎年年都有。

    | 年份 | 开篇引出的话题 | 后文的重点 | 答案怎么构成 |
    | :--- | :--- | :--- | :--- |
    | 2021 | 线上教学 | 要推动社会力量参与 | 在线教育需要引入社会力量 |
    | 2022 | 传统基层治理 | 后文大篇幅讲区块链 | 回到"治理"的话题 |
    | 2023 | 社会治理 | 众包 | 公众参与社会治理的新方式 |
    | 2023 | 统一市场、全国统一大市场 | 行政分割，规模不具竞争优势 | 规模还未转化为现实优势 |
    | 2024 | 消费潜力 | "特别是更好、更充分" | 认消费潜力，不认长远发展 |
    | 2024 | 现代公共法律服务体系 | 公共法律服务是全面依法治国的基础 | 离不开现代公共法律服务体系 |
    | 2025 | 执法权限 | 足够的执法权限是必要条件 | 话题钉在"权限"上 |
    | 2025 | 企业 | 企业比高校和科研机构更敏锐 | 先干掉没有"企业"的选项 |

    * "现代公共法律服务体系"是一个专有词汇，"现代"两个字不能省。

    * 问法新颖的"这段文字针对的主要问题是什么"，解法有二：解法一用因果关系，"因此"之后重要，强调的是规模不具有竞争优势；解法二用首句原理，这个文段在讲市场、讲统一市场体系、讲全国统一大市场，所以答案里必须有"市场"二字。

* **技巧与本质（Trick vs. Essence）**

    * > **定义**：所谓秒杀、所谓技巧，是建立在对于本质的理解上的。

    * 不理解本质，技巧就是花架子。

### 首句题例

* **巴氏芽孢杆菌（并列的落点）**

    * 开篇"巴氏芽孢杆菌是一种很顽强的细菌，不管有氧无氧都能生存"引出话题，强的点是"顽强"；第二句"在无氧环境中它会形成芽孢休眠，一旦遇到有氧就能重新萌发"，到这还在讲有氧无氧都能活，看上去很像总分。

    * 后面忽然出现"制造水泥的原料方解石"，水泥在前文里根本没出现过，这是新话题；再往后"这东西能够存活很久，因此添加了这种细菌的混凝土建筑物，即使在出现裂痕的情况下也能自愈"，读到底会发现不管是水泥还是混凝土都跟建筑有关系。

    * 尾句并不能总结整个前文——裂痕自愈和能制造水泥是两回事，中间这句话和最后这句话之间不分轻重，所以整体是并列；并列的本质是不分轻重，需要全面概括，落点是"建筑"。

    * 再问一句"整篇文章在讲谁"，讲的是巴氏芽孢杆菌，所以含有这个主题词的选项才留下；"细菌""新材料"相比"巴氏芽孢杆菌"犯了范围扩大、表述不明确的毛病，更具体更明确的那个更好。

* **县域错位发展（尾句没说，说的还是）**

    * 开篇"对于县域而言，错位发展首先必须植根于自身的家底"，开篇就画了个圈：不是城市，不是北上广深，也不是农村，是县域；他谈的是错位发展，但对象锁定在县域。

    * 后面"要做好土特产、要挖掘本土"是在对"植根自身"做解释、做举例，核心是县域错位发展要扎根自身；"错位发展更需要……"一个"更"表强调、一个"需"提对策，是强调加对策的叠加，必须重点关注。

    * 中心理解一般不讲递进，递进是逻辑填空讲的东西。

    * 出题人的花样在于：尾句提了对策、强调了错位发展，却没有出现"县域"两个字；但"主动对接国家战略区域发展""城市功能疏解""乡村振兴需要和市场前沿"的潜台词是既不是城市、也不是乡村，卡在城市和乡村之间的不是县域是什么。

    * 抓主题词：把没有"县域"的干掉，在都带"错位"的两项里最终锁定带"县域"的那一个。

* **学术争议（反面提对策）**

    * 开篇"在科学研究中，同样的研究得到不同的结果，很正常，很普遍"抛出话题；中间"生命科学目前在实验阶段，由于各种各样的不同而得到完全不同的结果，也不意外"是解释为什么会有不同。

    * 正中间"如果遇到这种情况，互相指责、争论、漠不关心，都是错误且缺乏远见的"叫反面提对策，本质上是在提一个做法，是对策的一种特殊情况；就像妈妈说"再不回家就别回家了"，她其实想让你赶紧回家。

    * 后面"从个人事业看……误导学生的未来""对社会资源的浪费"是解释你为什么缺乏远见，属于解释说明。

    * 整体是分总分：前面提出问题，中间提对策，后面作说明；同义替换后对应"用正确态度与方法面对学术争议"。

    * 反推：这个文段在讨论什么话题？是不是就第一句话——在科学研究中，同样的研究得到了不同的结果？它讨论的一定是学术上的争议、结果不一样，只有体现"结果不同"这个争议点的选项才对。

* **阿尔茨海默病（首句给范围，尾句给结论）**

    * 开篇"阿尔茨海默病分为家族性和散发性两种，各有各的特征；前者和蛋白质的积累有关；而在更普遍的散发性阿尔茨海默症中，有毒蛋白质积累的触发机制尚不清楚"。

    * "更普遍"是强调，矛头指向散发；前者的原理已经弄明白了，而散发性的机制尚不清楚，也就是说这段话是对"散发"提出了问题。

    * 既然是对散发提出了问题，接下来就是提出假设、设计实验、验证——中间不重要，过程不重要，结果重要。

    * 尾句"结果表明……"意味着对于散发性的阿尔兹海默症有了新的研究成果，某种意义上搞清楚了一些机制。

    * 分总结构的"总"在尾句，但主题词在首句就已经露出来了；首句给范围，尾句给结论，两头一夹，中间的过程段落读快一点完全不耽误做题。

* **首句题例汇总**

    | 题目 | 答案 | 一句话依据 |
    | :--- | :--- | :--- |
    | 巴氏芽孢杆菌（有氧无氧生存、产方解石、混凝土自愈） | 含巴氏芽孢杆菌的那项 | 中间句与尾句不分轻重，是并列；主题词锁定主体，其余范围扩大 |
    | 县域错位发展 | 含"县域"的那项 | 尾句的潜台词是"既非城市也非乡村"，话题仍是县域 |
    | 学术争议（同样的研究不同结果） | 用正确态度与方法面对学术争议 | 反面提对策的同义替换；只有它体现"结果不同" |
    | 阿尔茨海默病家族性与散发性 | 对散发性有新认识 | "更普遍"表强调，前者机制已知、后者机制不清，故散发更重要 |

## 例子与解释说明

* **解释关系（Explanation）**

    * > **定义**：七大关系里的解释关系——解释关系明确的直接论点，一边是观点，一边是详细的解释展开。

    * 一般情况下越详细越展开越不重要，它是为了论证那个明确的直接的观点。

    * 前后内容保持一个一致性，而且内容详细的部分，就是对内容简略的解释。

    * 两个点要一起记：第一个，前后意思保持一致；第二个，一般解释的东西会长一点。就这么简单，一个这么短、一个这么长，短的一般就是观点，长的一般就是解释或者例子。

```text
观点  ── 一致性 ──  解释 / 例子
（短）              （长）

短的一般就是观点，长的一般就是解释或者例子
```

### 明显的举例标志

* **举例标志（Example Marker）**

    * > **定义**：出现"比如""例如"这类明显标志时，后面一般是例子，例子内容一般不作为答案。

    * 例：很多疾病与心理因素相关，比如人紧张就可能引发胃痉挛——胃痉挛、紧张不重要，疾病和心理的关系更重要。

    * 一直说"一般"是因为凡事有例外：干细胞那道题，按道理干细胞是例子、不能作为答案，但它作为答案了，所以言语没有绝对。

* **"比如"的范围（Scope of the Marker）**

    * > **定义**：看到"比如"第一反应是后面不重要，但不能读到一个"比如"就把后面全部划掉。

    * 因为这个"比如"可能到结尾，也可能只是到中间；判断方法是看它的内容有没有变化。

    * 他比如之后还在讲具体的画和舞蹈、水墨入诗画、只此青绿、千里江山图，这些明显是具体的东西，那肯定是例子，起码到这儿是例子。

    * 尾句是对例子的总结，对例子的总结依然是例子；认为它是总结也行，那样就是总分总，反正不管怎么理解，观点是一样的。

    * > ⚠️ **易错点**：看到"比如""例如"先给后面贴一个"待定"标签，然后拿后面的内容跟观点对照——内容一旦从观点层掉到具体人、具体作品、具体数字，例子区就开始了，一直延续到话题切换为止。

    * 例：绘画与舞蹈融成一体的题，主题词是舞蹈、绘画；"人在画中游""只此青绿"是例子之一，直接干掉，不用犹豫；只要有一个更好的观点，直接选他就可以了。

### 无标志也可能是例子

* **大小包含关系（Size-Inclusion）**

    * > **定义**：例子和解释前面一般存在明显观点，前后思想保持一致，而且观点和例子之间大概存在大小包含关系。

    * 并不是非得有明显的举例标志才是例子：没有"比如""例如"，只要做到了思想保持一致，而且和观点有大小包含关系，这也就是例子，不用那么死板。

    * 例：观点是"很多疾病和心理因素息息相关"，后接"有的人紧张会引发胃痉挛""有的人长期抑郁、食欲不振"——紧张、抑郁对应心理因素，胃痉挛、食欲不振对应疾病；疾病是包含胃痉挛和食欲不振的，心理因素是包含紧张和抑郁的，意思保持一致，所以它也是例子。

```text
观点：很多疾病 与 心理因素 息息相关
        │              │
        ├─ 包含 ── 胃痉挛、食欲不振     （小：具体疾病）
        └─ 包含 ── 紧张、抑郁           （小：具体心理）

判断标准：思想一致 + 大小包含  →  没有"比如"也是例子
```

* **三个例子论证一句话**

    * 例：开篇"在江苏，自动驾驶已成为创新技术重塑物流的重要载体"，后面智慧重型卡车、智能辅助是自动驾驶加物流，自动驾驶集装箱卡车也是，行驶在物流园和制造企业的自动驾驶物流车也是。

    * 虽然没有"比如""例如"，但所有的车都是自动驾驶的、所有的运作环境都是物流相关的，那就是三个例子，三个例子就在论证第一句话的观点，总分结构，抓住核心话题：自动驾驶加物流。

    * 对比："物流车的智能技术应用"太宽泛，肯定没有自动驾驶好；"应用场景"和"物流"之间，谁明确选谁，因为讲的就是物流，没有讲别的范畴。

### 通篇都是某个对象

* **主体与例子的区分（Subject vs. Example）**

    * > **定义**：若文段通篇都是某个对象，那么它可能并非例子，而是主体。

    * 例子的前提是你得有观点；整个文段都在讲一件事，那他就是观点本身。

    * 例："肠胃是一个脆弱的器官，有的人紧张就可能引发胃痉挛"——整个文段全在讲肠胃，肠胃本身就是观点，因为他没有一个前置的观点了；有肠胃的选项优先选，没有他再考虑别的。

    * 不要因为它看起来像，就一定是例子。

* **句句不提·句句不离（Implicit Topic）**

    * > **定义**：后面通篇不再出现首句的那个词，但每一句话都在讲它。

    * 例：开篇"近代上海，不光是中国特大城市，还是外国人居住比例高的城市"，后面再也没出现过"上海"两个字，但讲的是人口规模越大、交流机会变越多、在市场经济作用下分工密切、创造与创新的增长速率通常高于人口增长率，以及城市人口抑制程度高、创新速率也大。

    * "人口抑制程度"需要翻译：咱俩黄皮肤、白皮肤、黑皮肤不一样，这就对应到外国人居住比例高；人多对应特大城市，这就是句句不提、句句不离，没有闲笔。

    * 这是并列结构：开篇引出上海的特点，正因为上海大而且外国人多，所以这两个带来了创造与创新的能力强；大和外国人多是原因，创造创新能力强是结果。

    * 光说人多片面，光说外国人多也片面，外国人多和人口多是两码事；答案必须同时装下"人多"和"外国人多"两个原因，还要把"创新能力强"这个结果带出来。

    * 例：开篇"长三角地区知识产权创造、运用、保护等等等等非常好"，后面优势企业、专利融资、知识产权纠纷调解，都没有脱离长三角的知识产权这个话题；抓住两个核心话题——我在讲谁（长三角），我在讲他的什么（知识产权）。

### 时态判别：例子是完成时，对策不是例子

* **完成时（Perfect Aspect）**

    * > **定义**：例子既然是想要论证一个东西，它是不是得已经完成了。

    * 例："我们班成绩都很不错，比如小张就很好"——小张是不是已经考得很好了；不能够画大饼，说"小张将来很好"，那都不是例子。

* **对策的对象（Object of Countermeasure）**

    * > **定义**：对策一般并非例子，因为对策还没发生；对策句出现时，它指向的那个名词短语往往不是例子，而是"对策的对象"，也就是真正的主题词。

    * 原理：对策它还没发生——"我应该好好学"，学了吗？还没有；"作为备考公务员的同学，对关键知识点也应该善于背诵"，"应该努力"不是例子，因为他没努力、没有变好。

    * 例：尾句"古典名画……很长一段时间深藏在博物馆中，名画想要活化，还需要跨界融合"，古典名画看着像例子，但"还需要"三个字一出现，就知道是在提对策；答案里一定得有古典名画，和怎么做——跨界融合。

    * > ⚠️ **易错点**：这个时候一定不能把古典名画当成例子排掉，因为它反而是真正想论述的观点；它就相当于"作为备考公务员的同学"——不是一个例子，而是作者想要解决问题的那个对象。

    * 例：前面引出高精尖、后面引出京津冀，都是先把对象引出来；转折之后"两地仅仅承接北京是不够的，迫切需要发展高精尖产业"，"迫切需要"提对策；抓住"我在说谁"（京津冀）和"京津冀干嘛"（要承接高精尖产业），既要有京津冀又要有高精尖。

    * 对策句的信号词：迫切需要、还需要、应当、这就必须。

```text
例句一：背诵是大道至简的。小王善于背诵，因此取得了较好的成绩。
        ↑ 观点                 ↑ 已完成 → 例子

例句二：背诵是大道至简的。作为备考公务员的同学，对关键知识点也应该善于背诵。
        ↑ 观点                                            ↑ 未发生 → 不是例子，是对策的对象
```

### 例子并非没用

* **反推观点（Reverse Inference）**

    * > **定义**：例子只是相对来讲非重点，非重点不代表没有用；例子和观点意思是一样的，纠结时可以辅助理解观点。

    * 拿不定观点到底是谁的时候，可以通过后面的例子和解释去判断一下。

    * 例：观点句有一前一后两个分句，前半句对应"农业没影响"、后半句对应花草植物；第一个角度，缘故是原因、后面就是结果，原因结果一般结果重要；第二个角度，整个后面都没有再出现"农业文明"了，都在讲花草植物，所以一定是围绕花草植物在讲。

* **次选的接受（Accept the Second Best）**

    * > **定义**：答案不完美时，把主题词适当扩大也勉强接受，但一定要对比择优。

    * 例：前面"传统旅游、冲动旅游"是背景，第二句"这就要求"提对策，前半句向消费场景过渡、后半句提高服务能力；后面例子"因需求旺盛，提升了以游客为导向的服务能级，服务更加主动热情有活力"讲的是服务提升，所以选服务升级那一项。

    * 最完美的答案应该把"城市"改成"传统旅游城市"，但另一个选项讲的是开发消费新业态，跟文段的重点没关系，所以只能勉强地接受扩大，至少没有脱离大的范畴。

* **五个提升点**

    | 提升点 | 判断标准 | 做题动作 |
    | :--- | :--- | :--- |
    | 明显的举例标志 | 出现"比如""例如"等标志 | 后面内容一般 pass，不当答案 |
    | 无标志也可能是例子 | 思想一致 + 大小包含关系 | 拿观点与细节对照，不死板找"比如" |
    | 通篇都是某个对象 | 全文只讲它，没有前置观点 | 它是主体本身，不是例子 |
    | 时态判别 | 例子是完成时，对策尚未发生 | 出现"迫切需要""还需要"等，找对策的对象 |
    | 例子并非没用 | 例子与观点意思一致 | 纠结时用例子反推观点到底在讲谁 |
