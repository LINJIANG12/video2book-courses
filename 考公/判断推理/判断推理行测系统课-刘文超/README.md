# 判断推理《行测》系统课

刘文超老师的判断推理系统课，面向国考与省考。课程完整覆盖判断推理四大模块——图形推理、定义判断、类比推理与逻辑判断，按真题年份逐套精讲，配套大量真题演练与解题模型归纳。

- **原视频**：https://www.bilibili.com/video/BV12t4115735 — Bilibili，BV12t4115735
- **45 集**，已产出 27 册模块全书、33 篇复习笔记、106 份逐字稿

## 怎么学

- **图形推理** → 先建立位置、样式、属性、数量四大规律框架，再按真题套题巩固
- **定义判断** → 抓住主体、行为、客体三要素拆解
- **逻辑判断** → 重点掌握翻译推理、真假推理与分析推理的解题模型
- **套题演练** → 课程按真题年份组织，建议按年份顺序刷完整套
- **考前速查** → `notes/` 下的笔记按题型归类，适合最后冲刺
