## 类比推理的包容、交叉与对应
> 对应块：BLK28 | 覆盖分集：P15上 | 块标题（分集名）：《第八节——类比推理——刘文超》

昨天我们把并列关系里的反对、矛盾过完了，今天接着往下走——包容关系。

### “包含”两个字，藏着两种不一样的东西

什么叫包容？就是我包含你。

先随手举两个例子。**苹果和水果**：水果里面是不是包含了苹果？我包容你，你是“水果”这个类里的一员。**汽车和轮胎**：汽车里面是不是包含了轮胎？我包容你，你是它的一部分。

看起来都是“包含”，都是我在里面你在里面，但请各位同学看好了——**包含和包含是不一样的**。

| 关系 | 造句模板 | 例子 | 两词的关系 |
| --- | --- | --- | --- |
| 种属关系 | A 是 B 的一种 | 苹果是水果的一种 | 同类项，抽象层级不同 |
| 组成关系 | A 是 B 的组成部分 | 轮胎是汽车的组成部分 | 异类项，整体与部件 |

```text
   种属：苹果是水果的一种                组成：轮胎是汽车的组成部分

      ┌─────────────┐                     ┌─────────────┐
      │    水果      │                     │    汽车      │
      │   ┌─────┐   │                     │   ┌─────┐   │
      │   │ 苹果 │   │                     │   │ 轮胎 │   │
      │   └─────┘   │                     │   └─────┘   │
      │     ……      │                     │     ……      │
      └─────────────┘                     └─────────────┘
        苹果是水果这个类里的一个成员              轮胎是汽车上的一块零件
```

> **定义**：种属关系是“同类项之间的从属”，成员之间彼此平级、只是层级不同；组成关系是“整体与部件”，两者根本不是一类东西。

那考试的时候到底怎么区分？**其实很容易，你去造个句子就 OK 了。**

“苹果是水果的一种”——通顺。“轮胎是汽车的一种”——不通顺，你只能说轮胎是汽车的组成部分。就这么简单。你造个句子一试，关系就出来了。

> **易错点**：不要再去找什么“看外延”“看定义”的花招。造句子，通不通顺，一句话定生死。

### 例题里把两种关系钉死

#### 例一：快餐的分类

我们先整体看。中式快餐和日式快餐——它俩是不是都是快餐？看后两个，是并列关系。而且是并列里的**反对**：除了中式的、日式的，还有韩式的，还有等等。

那再看前面两个：中式快餐和日式快餐，跟“快餐”是什么关系？他俩跟快餐都是一种快餐，**这是种属关系**。造个句子就 OK 了。

选项一个个过：

- **A 队长∶队员 相对于 团队**。队长和队员，你能说是团队的一种吗？不对，你只能说队长和队员是团队的组成部分。错。
- **B 合法行为∶非法行为 相对于 行为**。他俩确实是并列，也都是一种行为——但你看他是并列里的什么？**矛盾关系**。不是合法的就是非法的，他俩把整体占满了。而题干里中式和日式是并列里的**反对**。矛盾对不上反对，所以不合理。
- **C 黑色∶白色 相对于 颜色**。黑、白之外还有别的颜色，他俩是并列里的反对；而且黑和白都是一种颜色，**是种属关系**。跟题干完全一致。
- **D 体育、音乐、英语**。这三个直接就是并列里的反对关系，连四字格那一对都套不上。

答案就是 C。

> **提示**：这个题不难，但我希望大家把里面涉及的知识点都梳理出来。反对和矛盾的区别，昨天讲过；今天这两种“包含”，就是新的。

#### 例二：衣领与衣袖

题干里的“衣服”和“衣领”是什么关系？这是衣服，这是衣领，这是衣袖，可能还有纽扣，乱七八糟很多。他俩后面两个是并列里的反对关系。

那衣领和衣袖跟衣服呢？衣领是衣服的什么？能组“一种”吗？不能，不通顺。只能说衣领是衣服的组成部分，衣领和衣袖都是衣服的组成部分。**这是一个组成关系。**

- **A 鱼头∶鱼尾 相对于 鱼**。鱼头和鱼尾是并列里的反对，没问题。那鱼头是鱼的什么？你能说鱼头是鱼的一种吗？不能，鱼头是鱼的组成部分，鱼尾也是。逻辑完全对得上。
- **B 刑警∶交警 相对于 警察**。他俩是警察里的反对——这是所有警察，刑警、交警之外还有缉毒警等等，非常多，这没问题。但刑警是警察的一种，交警也是警察的一种，**这是种属关系**，跟题干的组成不一样。选 B 的同学，自己去造一下句子：“刑警是警察的一种”，它叫种属关系。
- **C 古典音乐∶流行音乐 相对于 音乐**。古典音乐是音乐的一种，流行音乐也是音乐的一种，还是种属。
- **D 人民币、美元、韩币**。这三个是所有货币单位里的并列里的反对，跟题干逻辑关系不对。

答案就是 A。这里就把“刑警是警察的一种”和“衣领是衣服的组成部分”这两个点理清楚，就 OK 了。

#### 例三：针筒与注射器

针筒和注射器是什么关系？就是我们去医院打针用的那个东西。我画一下。

```text
              推进器
                │
        ╔═══════╧═══════╗
        ║               ║
      针头║     针筒     ║
        ║               ║
        ╚═══════════════╝
              注射器
```

这个画得有点抽象，大家自己脑补一下。

那针筒是注射器的什么？针筒是注射器的**组成部分**，不是注射器的一种。造句：“针筒是注射器的组成部分。”

再看后半截：注射器是医疗器械的一种——**种属关系**。

所以这道题就是“前面组成、后面种属”两个关系一起卡。确认好这两个关系，再看选项：组成那一栏，只有一个选项完全站得住——**齿条是千斤顶的组成部分**。

千斤顶大家有印象吧？车上是不是都配了一个千斤顶？千斤顶其实是一个**省力杠杆**，所以你才能翘起千斤来。它里面确实是一个一个的齿条，所以齿条是千斤顶的组成部分，没有问题。这个基本的常识要有。

后面那栏：千斤顶是起重设备的一种，没有问题。C 是完美契合。

至于 D：泳衣是比基尼的一种吗？反了。比基尼是泳衣的一种。这个不用科普了吧——我也不知道，我没见过。

> **提示**：这类题会顺带考常识，题干里出现的实物，你得知道它由什么组成、又属于哪一类。不会就去百度，别硬猜。

### 练习里的三处常识坑

#### 练习一：稻穗与稻谷，方向反了

题干考的是“音符∶乐谱”和“五线谱∶乐谱”。音符是一种乐谱吗？不是，**音符是乐谱的组成部分**，乐谱是由音符组成的。那五线谱是一种乐谱吗？**是**，所以后半截是种属关系。

答案 A：笔画是汉字的组成部分吗？汉字是由笔画组成的，没问题。**金文是汉字的一种吗？**也是一种。金文又叫铭文、钟鼎文，是古代写在钟鼎那种金属器物上的文字，殷商时期的那种。也是一种汉字。所以 A 的逻辑关系没有任何问题。

有疑问的是 C。什么叫稻穗？我画一下。

```text
              稻穗
               ╱│╲
              ╱ │ ╲
          ┌───┐ │ ┌───┐
          │稻谷│ │ │稻谷│     ← 每一颗稻谷，外面都包着一层壳
          └───┘ │ └───┘
                  │
                 大米            ← 去了壳，就叫大米
```

稻穗是什么？就是你去收割的时候把稻穗折下来，上面全是稻谷，一颗一颗全带着壳。没去壳的叫稻谷（也叫谷子），去了壳才叫大米。

所以你说稻穗是稻谷的组成部分吗？**错了，方向反了。**你得说稻谷是稻穗的组成部分——稻穗上全是包含着稻谷的。说“稻穗是稻谷的组成部分”一定是错的。

B 肯定没问题：树木、森林和自然，这三个之间绝对没有什么包含关系。答案是 A。

> **易错点**：组成关系不总是“小的在大的里面”。稻穗整体比稻谷大，稻谷才是被包含的那个。造句子之前，先在脑子里把结构想清楚。

#### 练习二：八卦、九族、七情与五音

八卦和乾坤是什么关系？八卦是乾、坤、坎、艮、震、巽、离、兑这八个方向，乾坤只是八卦中的两卦。这是个包含关系，详细来说是**组成关系**。

那一个个看：

- **A 九族∶师生**。九族是什么？你自己这一代算一族，往上四代——父、祖父、曾祖、高祖；往下四代——子、孙子、曾孙、玄孙，加起来正好九族。古代“株连九族”说的就是这个，它里面**不包含师生**。要灭十族，师生才进来。中国历史上唯一一个被灭十族的人是方孝孺，发生在明成祖朱棣那会儿。所以 A 错。
- **B 七情∶情志**。这里面的说法我们中国和佛家、中医确实有点不一样，简单说一下。佛教里的七情是喜怒忧惧爱嗔欲；我们儒家把“忧”换成“哀”、“嗔”换成“恶”，就是喜怒哀惧爱恶欲；中医又是另一套，叫喜怒忧思悲恐惊，而且中医会把每一种都叫作“**情志**”。所以你不能说七情里面包含情志。正确的理解是：喜是一种情志，怒是一种情志，忧是一种情志——是情志把喜怒忧思悲恐惊给装了，而不是七情把情志给装了。B 错。
- **C 五音∶宫、商、角、徵、羽**。宫商角徵羽，这五个字非常难写。宫商只是五音中的两个音，是**组成关系**，跟题干完全对上。
- **D 四书和五经**。它俩是并列关系。

答案 C。这一题的常识不算难，但确实要用到，所以还是那句话：多多少少你得有一些常识储备。

#### 练习三：麻雀、动物与生物链

麻雀是动物的一种——**种属**。那动物是生物链的什么？你能说动物是生物链的一种吗？不能。生物链里包含生产者、初级消费者、中级消费者、更高一级的消费者，还有分解者等等，太复杂了，**动物只能说是生物链中的一个组成部分**。

还有一层：麻雀本身也是生物链的一个组成部分。所以这道题是“种属 + 组成”两层关系。

- **A 豆浆∶早餐**。豆浆是早餐的一种，行。但早餐跟豆制品是什么关系？早餐是豆制品的组成吗？不对。错。
- **B 开水、纸杯 相对于 便利店**。开水是便利品的组成部分吗？纸杯是便利店的组成部分吗？都不对，这逻辑关系太差。
- **C 发卡∶首饰**。发卡是首饰的一种；首饰是装扮品的组成部分。没问题。而且发卡本身也是装扮品的组成部分。C 完全正确。
- **D 钢笔∶电脑**。钢笔是电脑的一种吗？这根本不用看了。

答案 C。

### 分不清种属还是组成？先只判“包含”

很多同学会跟我说：老师，这个题我确实分不清，我有时候分不清这个种属还是组成。

先拿练习四举例。**进士和状元是什么关系？**

我假设我先不去看它到底是组成还是种属——它首先一定是一个**包含关系**，对不对？你中了进士之后，进士里面第一名是状元，第二名是榜眼，第三名是探花（李寻欢就是探花）。所以进士里面是包含了状元、榜眼、探花的。这是包容关系。

那我现在就看这个包含关系，看能不能把题做出来。河水跟海水不是包含，银河跟天文不是包含，学位跟博士——学位包含了硕士学位，还有学士学位、博士学位，**这是包含**。答案就是 C。

你看，我通过“包含”这一层就确认了答案是 C。

> **结论**：如果包含关系这一层已经能帮你把题做出来，就**不要去纠结**它到底是种属还是组成。只有当包含这一层做不出来的时候，你才需要进一步往下区分，那时候也没办法，只能进一步去抠。

> **易错点**：练到这个阶段，考场上最忌讳的就是钻牛角尖。造句子觉得“好像也行，但好像也不太通顺”——这说明你其实已经判断出来了，不通顺就是答案。别在那儿反复横跳。

### 交叉关系：两个集合之间有交集

交叉关系相对来说就比较容易了。所谓交叉，就是两个集合中间有交叉的部分。

```text
        ┌───────────────┐   ┌───────────────┐
       ╱                 ╲ ╱                 ╲
      │     所有女士       │      公务员       │
      │                  │                  │
      │      ▓▓▓▓▓▓      │                  │
       ╲    女公务员     ╱                   │
        └───────────────┘   └───────────────┘

      女士 ∩ 公务员 = 女公务员
```

女士这个集合里，有一部分是公务员；公务员这个集合里，也有一部分是女士。两个集合之间有一个交叉的地带，这就是交叉关系。

> **定义**：交叉关系的判断口诀是——两边都能找到对方的一部分，且互不包含。

#### 例一：花瓶与瓷器

简单一看，花瓶这个集合里是不是有一部分是瓷器？瓷器里也有一部分是花瓶。交叉关系，很容易辨别。

- **A 电视机∶电器**。电视机是电器的一种，种属关系。
- **B 中药∶植物**。中药这个大集合里什么都有，什么植物、什么动物，太多了。中药里有一部分是植物，植物里也有一部分是中药——但不是所有植物都是中药。**交叉关系**，一模一样。
- **C 画作∶诗篇**。并列里的反对。
- **D 桌子∶八仙桌**。八仙桌是桌子的一种，种属关系。

答案 B。

#### 练习一：文物与建筑

文物这个集合里，有一部分是建筑。建筑里也有一部分是文物——比如故宫，很多建筑都是文物。交叉。

- **A 烹饪∶佐料**。烹饪的时候需要使用佐料，这不是一个交叉关系。
- **B 故宫∶楼房**。这一项别扭在哪儿？故宫中有一部分是楼房，这没问题；故宫里确实有楼房的，两层的、三层的都算，楼房这个概念在古代就有了，两层及以上叫楼房，跟平房做区分。但你说“楼房中有一部分是故宫”，读着就特别别扭，硬要说好像也行，但非常尴尬。**这一项你就先放这儿，不要去管它。**
- **C 诗人∶教授**。诗人中确实有一部分是教授，教授中确实有一部分是诗人。太完美了。

你还纠结 B 干嘛？我们的类比推理里说得非常清楚：**我们要找的是最好的、最贴近的选项**。B 你要是使劲钻牛角尖，可能也能说个“行”，但它读起来一点都不通顺，非常有问题。有 C 在，就不要去选 B。

答案 C。选最佳的，别纠结。

#### 练习：大学校长与教授

大学校长中有一部分是教授，教授中有一部分是校长，交叉关系。答案 A——**编剧与诗人**：编剧中有一部分是诗人，诗人中有一部分是编剧。

选 C 的同学，这应该是对应关系，你这话自己觉得对吗？选 D 的同学，刑警跟消防队员是两个完全不同的体系，白洋淀是白洋淀、衡水湖是衡水湖，这是**并列关系**。

这种基本常识请去百度，我就不要再去详细解释了。

### 对应关系：实在说不通时的万能口袋

对应关系里面就很多了。其实很多很多的题，如果你找不到一个特别合理的解释——不是什么全同，也不是组成、包容，也不是并列——有的时候就很难说，那这些里面有很大一部分，我们就认为它是个对应关系。

#### 四种高频对应

| 对应类型 | 例子 | 关系解读 |
| --- | --- | --- |
| 原材料对应 | 小麦 ∶ 馒头 | 馒头由小麦做成，小麦是馒头的原材料 |
| 工艺对应 | 白酒 ∶ 发酵 | 白酒由发酵而来，发酵是白酒的制作工艺 |
| 功能对应 | 银行卡 ∶ 支付 | 银行卡的功能叫支付 |
| 属性对应 | 盐 ∶ 咸 | 咸是盐的属性 / 特点 |

原材料好理解：小麦跟馒头，除了原材料你想不出别的解释。工艺也是，白酒是由发酵而来的。银行卡跟支付，他俩确实有关系，但关系该叫什么？有时候没办法，就说对应关系——这是一个非常典型的功能对应，**银行卡的功能叫支付**。

盐是咸的，一眼就看到。咸是盐的一种属性，或者说盐是“咸”的一种特点，两个说法都行。

#### 例一：小麦与馒头

小麦是馒头的原材料，标准的原材料对应。

那原材料这一栏，**A 选项麋鹿跟麝香**——错。这是基本的常识要有：麝香来自哪里？麝香**不是**来自麋鹿，它来自麝。这个字是真难写。它严格来说来自雄性麝的香腺囊的分泌物，雌性是没有的。所以麝香来自雄性麝，不来自麋鹿。

有常识的可以自己去查一查，雄性麝的腺囊到底是怎么回事，我就不给你们解释了。

> **提示**：对应关系虽然好找，但它是个“兜底口袋”——别一上来就往里面塞。先老老实实按全同、并列、包容、交叉挨个试一遍，试不通了再落到对应。

### 本讲提到的题目

> 以下题干与选项按课上口述还原，答案与解析依据均可在正文对应小节找到。

#### 包容关系：例题三道

**例一**（题干：中式快餐、日式快餐与“快餐”之间的类比）
选项：A 队长∶队员 相对于 团队；B 合法行为∶非法行为 相对于 行为；C 黑色∶白色 相对于 颜色；D 体育、音乐、英语
**答案：C**
解析：中式快餐与日式快餐是快餐这个类里的成员，构成种属关系；黑色与白色同为颜色的一种，同样是种属关系。A 是组成关系，B 的合法/非法是并列里的矛盾而非反对（题干中式/日式是反对），D 只是三项并列。

**例二**（题干：衣服与衣领、衣袖之间的类比）
选项：A 鱼头∶鱼尾 相对于 鱼；B 刑警∶交警 相对于 警察；C 古典音乐∶流行音乐 相对于 音乐；D 人民币、美元、韩币
**答案：A**
解析：题干中衣领、衣袖是并列里的反对，且二者都是衣服的组成部分，属组成关系。A 中鱼头、鱼尾同为并列反对，且都是鱼的组成部分，完全对应。B、C 后半截是种属关系，D 是三项并列。

**例三**（题干：针筒与注射器、注射器与医疗器械之间的类比）
选项：A 飞机∶螺旋桨；B 潜艇与核潜艇；C 齿条∶千斤顶；D 泳衣∶比基尼
**答案：C**
解析：题干前半截“针筒∶注射器”是组成关系，后半截“注射器∶医疗器械”是种属关系。C 中齿条是千斤顶的组成部分（千斤顶是省力杠杆，内有齿条），千斤顶又是起重设备的一种，两层全中。D 方向反了，应是比基尼是泳衣的一种。

#### 包容关系：练习四道

**练习一**（题干：音符∶乐谱、五线谱∶乐谱）
选项：A 笔画∶汉字、金文∶汉字；B 树木、森林与自然；C 稻穗∶稻谷；D 课上未展开
**答案：A**
解析：题干“音符∶乐谱”是组成，“五线谱∶乐谱”是种属。A 两层全对，金文即铭文、钟鼎文，是汉字的一种。C 方向反了，稻谷才是被稻穗包含的那个。

**练习二**（题干：八卦∶乾坤）
选项：A 九族∶师生；B 七情∶情志；C 五音∶宫商角徵羽；D 四书∶五经
**答案：C**
解析：乾坤只是八卦中的两卦，属组成关系；宫商只是五音中的两音，同样是组成关系。A 中株连九族不含师生（要灭十族才含），B 中情志是中医对喜怒忧思悲恐惊的统称，装的是七情而不是被七情装。

**练习三**（题干：麻雀∶动物、动物∶生物链）
选项：A 豆浆∶早餐、早餐∶豆制品；B 开水、纸杯 相对于 便利店；C 发卡∶首饰、首饰∶装扮品；D 钢笔∶电脑
**答案：C**
解析：题干“麻雀∶动物”是种属、“动物∶生物链”是组成。C 中发卡是首饰的一种（种属），首饰是装扮品的组成部分（组成），两层全对。

**练习四**（题干：进士∶状元）
选项：A 河水∶海水；B 银河∶天文；C 学位∶博士；D 课上未展开
**答案：C**
解析：进士包含状元、榜眼、探花，是包含关系；学位包含学士、硕士、博士学位。本题只需在“包含”这一层上做比较即可定出 C，不必纠结它是种属还是组成。

#### 交叉关系：一道例题加两道练习

**例题**（题干：花瓶∶瓷器）
选项：A 电视机∶电器；B 中药∶植物；C 画作∶诗篇；D 桌子∶八仙桌
**答案：B**
解析：花瓶中一部分是瓷器，瓷器中一部分是花瓶。B 中中药里有一部分是植物，植物里也有一部分是中药，互不包含，是标准交叉。A、D 是种属，C 是并列反对。

**练习一**（题干：文物∶建筑）
选项：A 烹饪∶佐料；B 故宫∶楼房；C 诗人∶教授；D 课上未展开
**答案：C**
解析：文物中一部分是建筑，建筑中一部分是文物。C 两向都成立，是最佳选项。B 虽能说通“故宫中有楼房”，但“楼房中有一部分是故宫”读着别扭，不如 C 干净，遇到这种情况直接排除即可。

**练习二**（题干：大学校长∶教授）
选项：A 编剧∶诗人；B 课上未展开；C 课上未展开（判为对应关系）；D 刑警与消防队员、白洋淀与衡水湖
**答案：A**
解析：校长中一部分是教授，教授中一部分是校长；A 中编剧与诗人互有交叉。D 是两个不同体系之间的并列关系，C 属于对应关系，都不符合。

**例题**（题干：小麦∶馒头，取原材料对应）

## 类比推理的对应关系：材料、工艺、功能与次序
> 对应块：BLK29 | 覆盖分集：P15中1 | 块标题（分集名）：《第八节——类比推理——刘文超》

做类比推理，真正卡住你的往往不是题干，而是四个选项里有两个、甚至三个都能说通，这时候就得往下再走一层。

这一整段我们就在反复练这一个动作：**先把明显不对的扔掉；剩下的比关系；关系比完还分不出来的，再比二级**。二级是什么、因题而异——工艺是物理变化还是化学变化，功能是主要的还是次要的，时间顺序里前后是不是同一个主体。记住这三层，你就不会再在两个"看起来都对"的选项之间纠结了。

### 原材料不等于组成部分，也不等于产物

"原材料"这个词看着简单，做题的时候特别容易被绕进去。三个例子一起看。

**叶绿体∶细胞**——不行。叶绿体是细胞的组成部分，不是细胞的"原材料"，方向反了。细胞里装着细胞核、线粒体、高尔基体、细胞质，乱七八糟一大堆，多着呢。而且更干脆的一条是：只有植物细胞才有叶绿体，动物细胞里根本没有。

**乌贼∶墨汁**——也不行。乌贼是往外喷射墨汁的，你能说乌贼是墨汁的原材料吗？它是**产出**墨汁的那一方，不是**由**墨汁做出来的那一方。因果方向一旦搞反，后面全废。

**棉花∶布鞋**——这个行。老北京布鞋是布做的，布是棉花纺成的棉布，棉布再做成一双布鞋。棉花确实是布鞋的一个原材料，说得通。

> **提示**：这里有人较真——"我觉得布鞋未必都是棉花呀，现在有些鞋底是橡胶的。"这类细节就别去纠结了。ABC 都是非常明显的错误，棉花确实是布鞋的原材料，答案就是 D。**纠结是没有意义的**，题目问的是关系，不是这双鞋里每一根线的成分表。

#### 工艺得是个真工艺

考"原材料 + 制作工艺"的时候，光把原材料说对还不够，第二格必须是一个真真正正能叫得上名字的工艺。

泥是陶瓷的原材料，烧制是陶瓷的制作工艺——这一组先把标准立住。

- **玉∶手镯**：原材料没问题，但工艺不行。手镯是"雕"出来的，不是"砸"出来的。"欲砸出手镯来"，这不合适。
- **鱼∶鸬鹚**：鸬鹚是吃鱼的，这是个对应关系（谁捕食谁），根本不叫原材料。
- **铁∶剑**：铁是剑的原材料，没有问题；工艺是**淬炼**——看过武侠片里打铁吧？把铁烧红，拿出来，砸、砸、砸，再丢进水里，这就叫淬火，淬完之后才是能用的剑。原材料和工艺两头都对上了。
- **树与土（树化石）**：材料说不圆，工艺也挂不上。

答案 C。整道题就一句话的功夫：**看第二格那个词，是不是一个真工艺。**

#### 物理变化还是化学变化

这一题是重头。四个选项全是"某某是某某的原材料 + 某某是制作工艺"，全是真话，你根本挑不出来。这就是他说的**二级辨析**上场的时候。

判据只有一条：**这个工艺，是物理变化还是化学变化。**

- **蚕丝织成丝绸**——织，就是把线排列组合起来，没产生新物质，物理变化。
- **玉石雕琢成玉器**——也没产生新物质，没发生化学反应，物理变化。
- **粮食酿成美酒**——粮食主要是碳水化合物，C、H、O，可能还带一些硫。酿造过程里会产生各种曲，物质成分彻底重组，产生了新物质，变成了酒精 $\mathrm{CH_3CH_2OH}$。这是化学变化。他顺口提了一句，茅台的股价如今都到每股一千一百块了，"非常的恐怖"；中国的白酒还有浓香型，五粮液是典型的浓香型，酱香型的代表是茅台；啤酒我们中国做得一般，啤酒最好的产地是比利时和德国。
- **生铁冶炼成钢材**——**一定是化学变化**，不要再有人觉得这是物理变化了。

生铁和钢材的区别就在**碳含量**上，这是中学化学的内容：以 2% 为界，含碳大于 2% 的叫生铁，小于 2% 的叫钢材。但真正的冶炼过程非常复杂，绝不是"把碳减一减"那么简单：生铁里的杂质多，除了碳，你还要**脱磷、脱硫、脱氧、脱氮**，把这些有害元素清干净；与此同时，硅、锰、镍这些非常重要的金属还得**保住**；按不同需求，你可能还要往里**加**一些特殊的金属，形成相应的合金。整个过程全是化学反应。

> **结论**：二级辨析落在工艺上时，不要凭感觉，套"有没有产生新物质"这一条。产生了新物质就是化学变化。

蚊香那一条先排掉：蚊香点燃之后会产生烟雾，**烟雾不是原材料，点燃也不算工艺**——它是"过程"和"结果"，不是"材料"和"手段"。

### 功能：主要的那个和顺带的那个

"原材料 + 功能"的题，材料那头一般不难栽跟头，栽跟头的是功能。

#### 剪刀的功能该怎么说

题干是木材∶抽屉，木材是原材料，抽屉的功能是**收纳**。

- **钢铁∶剪刀**：原材料没问题；功能写"切割"有点尴尬。你买一把剪刀是为了切割吗？严格说应该叫**剪裁**更合适。但你也不能说剪刀完全不能切割——它可以切割，只是不是它的**主要功能**。先放一放，看看有没有更好的。
- **棉花∶毛线**：两头都错。毛线的原材料是**羊毛**，不是棉花。功能写"保暖"？那你会把毛线直接围在身上吗？不会，毛线织成毛衣才有保暖作用。
- **石头∶城墙**：城墙是石头的原材料吗？不对，方向又反了。
- **橡胶∶气垫**：原材料没问题——气垫确实就是橡胶做的；功能是**缓冲**，一点不尴尬。

> **结论**：几个选项都能勉强解释的时候，选**最优**的那个。我选一个最优的，一定答案是 D。能在"勉强解释"上恋战的，题目会告诉你答案。

#### 主要功能与次要功能

这道题更绕一层。白醋∶消毒。

白醋正常拿来干嘛？在厨房里**调味**。喜欢酸的就用它调味。至于消毒，那是它**额外**具备的功能——非典那会儿白醋被抢光过，家家户户往屋里撒、往屋里喷，不就是奔着这个去的吗。所以"消毒"是白醋的**次要功能**。

光看功能这一层，这个题已经没法选了。热水器加热、汽油去渍、白糖调味、人参滋补，全都能对上。于是二级辨析又来了：**这些是它们的主要功能，还是次要功能？**

- 热水器——主要就是加热。
- 汽油——本职是**燃烧产生动力**，这是它额外才有的功能；顺带能去渍，是因为汽油是**脂溶性的**，能带走油渍类的脏东西。所以去渍也是次要功能。
- 白糖——主要就是调味。
- 人参——主要就是滋补。

题干给的是次要功能，选项也得给次要功能。答案 B。

### 属性：必然的那一条

黄连∶苦。黄连一定是苦的，这是它最重要的一个**属性**（叫特点也行）。

"属性"这一层要抓一个词：**必然**。

- 班级一定是团结的吗？不一定。
- 钻石一定是坚硬的吗？一定。金刚石嘛，它那种碳的结构、碳碳键，造就了金刚石非常坚硬、非常牢固的特性。
- 花朵一定是鲜红的吗？不一定。
- 城市一定是繁华的吗？不一定。

黄连的"苦"、钻石的"坚硬"是放得进"一定"这两个字里的；班级、花朵、城市都不行。答案 B。

### 属性之外，再看种属

素描∶单色。

什么叫单色？就一个颜色。什么叫素描？拿铅笔描——不用介绍了，铅笔只有一个颜色，就是黑色。所以"单色"是素描的一个**特点**、一个**属性**。

除了属性，这里还藏了第二层关系：**素描是绘画的一种**，这是种属关系。

- 食品∶色素——色素是食品的**特点**吗？谈不上。
- 阅读∶书签——书签是阅读的一个**辅助工具**，不是它的特点或属性。
- 变脸∶表演——也不能说变脸是表演的一般特点。
- 即时∶新闻——新闻的特点就是**即时**；而且新闻是**文体的一种**，跟素描之于绘画一样，是个种属。

两个关系都对上了，答案 D。有时候选项是被第一个关系全排掉的，根本用不着第二个关系来救场；但你自己心里得知道还有第二层。

### 时间、依据、因果、职业

除了材料和工艺、功能、属性、额外，对应关系里还有几个出得比较多的类型，先混个脸熟：

| 对应类型 | 判定要点 | 高频例子 |
| --- | --- | --- |
| 时间顺序 | 先后不能颠倒 | 先学习，再考试 |
| 依据 | 后者遵循前者 | 航行依据航线 |
| 因果 | 前者为因，后者为果 | 炎热导致中暑 |
| 职业 | 身份对应职责 | 老师的职业是上课 |

看着都是一句话的事，但每一类都能挖出二级辨析来。下面拿例题看。

### 时间的先后：对了顺序还不够

#### 顺序反了，直接排

题干是**先规划、再实施、再验收**，一个标准的先后关系。

- 取证怎么可能排在最后？直接排。
- 销售、宣传和生产——应该是**先生产、再宣传、再销售**，生产排在最后不对。
- 招投标：你们这个是先发布一个公告，说我要招标，你们都来投；别人过来投标；投标完了，把所有投标人放一块儿，**开标**。招标、投标、开标，顺序一点不能乱。
- 先播种，播种完了去管理，管理完了最后再收获。

答案 D。这种题不用二级辨析，纯常识就能平推过去。

#### 主体：是不是同一个人干的

题干是**先报警、再救援**。

先消费再生产？错，应该先生产再消费。先手术再住院？错，应该先住院再手术。C、D 排掉。

剩 A、B 两个，靠二级辨析——**主体**。报警和救援：你报警，然后被别人救援，是警察来救援，前后不是一个主体。违章和罚款：我违章了，然后我被罚款了，是同一个主体。毕业和就业也一样，牵涉的是不同主体。时间顺序里会有一个"主体"的二级辨析，靠这一层把 B 排除，答案 A。

> **提示**：这层现在做不出来没有关系，听完这一遍，以后再遇到就一定能做出来。知道了就行了。

### 依据关系：工具不是依据

#### 抽样调查与建模软件

题干是**抽样调查依据抽样原则**。抽样原则这玩意儿，大学概率论里详细讲过；初高中只是简单接触过怎么抽样。

- 调查问卷——它是用来**征求意见**的，不是用来"依据"什么的。
- 人物访谈与访谈内容——先访谈，然后得到访谈内容，这是先后、产出关系，不是依据。
- 数学建模与建模软件：MATLAB 是最常用的建模软件，可它只是个**工具**。你先把建模的规程设计好，然后到 MATLAB 上走一遍——它是工具，不是你依据的东西。
- 设备的操作依据**操作规程**，成立。

答案 D。凡是"我用了这个软件/这个工具"的地方，都别往依据上靠。

#### 关系要经得起追问

这一题考的还是依据：我依据教案，完成今天的授课。

- 教案与课件——我先设计好怎么讲（教案），再拿出我用的 PPT（课件），这俩对今天这堂课都是辅助关系，是个**并列**，没有这一层。
- 信息与分类——我对信息进行分类而已，逻辑关系很弱；归类和分类本来就是近义词，更说明不了什么。
- 提纲与教案、商品与分类——这两个怎么解释都接不上题干。我设计这堂课，教案里**可能**有提纲，也可能没有，很尴尬；就算有，那也只是组成关系。商品需要分类，教案需要提纲吗？**你自己能说服得了自己吗？** 就算钻到牛角尖里，也选不到它，逻辑关系差得太遥远。

真正和题干一模一样的就是那个"依据教案完成授课"的选项，答案 D。

> **易错点**：这类题碰到关系勉强的时候，就用**追问法**把自己顶回去——A 需要 B 吗？真需要吗？说不出来，就是不对应。稍微转一下就转得通的选项不要选。

### 因果关系：因在前，果在后

题干是**失之毫厘，谬以千里**，典型的因果：前面的是因，后面的是果。

- 走为上计∶三十六计——"三十六计，走为上计"，这是**包含关系**，走为上计是三十六计中的一计，不是因果。
- 召之即来、挥之即去——这里头构不成因果。有个同学选了 B，不是的；召之即来导致挥之即去吗？没有因果。你自己好好分析一下。
- 种瓜得瓜、种豆得豆——是因果不假，但它**自成因果**，前半句是因、后半句是果，整组词自己闭合成一个循环；题干是"失之毫厘"为因、"谬以千里"为果。
- 前人栽树，后人乘凉——前人栽树是因，后人乘凉是果。

答案 D。

> **结论**：因果题里最常见的坑，就是那个"看起来也有因果"的干扰项。判断标准是**因和果必须分处题干的两个位置**，不能挤在同一格里自己跟自己玩。

### 全同、并列、包含、交叉、对应

最后把这一节讲的东西串一遍。类比推理一共就那么几类逻辑关系，剩下的是"对应关系"——而对应关系非常复杂。有一个同学说得特别好：对应关系就像一个**兜底**的，你其他关系都找不到，就认为它是对应。没问题，就这么用。

```text
逻辑关系
├── 全同
├── 并列
│   ├── 矛盾关系（互斥，非此即彼）
│   └── 反对关系（互斥，可此非彼）
├── 包含
│   ├── 组成关系（A 是 B 的组成部分）
│   └── 种属关系（A 是 B 的一种）
├── 交叉
└── 对应（兜底：其他关系都对不上，就往对应上想）
    ├── 材料 —— 原材料与成品
    ├── 工艺 —— 成品与制作手段
    ├── 功能 —— 器物与用途（分主要/次要）
    ├── 属性 —— 必然属性
    ├── 次序 —— 时间先后（分主体）
    ├── 依据 —— 行为与遵循的标准
    ├── 因果 —— 前因后果
    └── 职业 —— 身份与职责
```

这张图里，前面几行是"框架性"的关系，特征明显、识别度高；真正难的是最后那一大片对应。上面挂的八种只是高频的常用的一批，对应关系里的考察点非常多。材料、工艺、功能、属性、时间、因果、依据、职业，等等——你需要去看。

> **结论**：做题顺序固定下来：先看题干属于哪一类，再逐个选项过框架关系（是不是全同、是不是矛盾、是不是组成、是不是种属），一轮都排不掉的，进"对应"，然后在对应里做二级辨析。**二级辨析不是可选项**——两个都能解释得通的时候，不做二级，你就只能猜。

后面多刷一些例题、多刷一些练习，其实就巩固得更好一些。

### 本讲提到的题目

下面的题干按课上口述还原，只有实际讲到的那几组词对，选项的排列以讲解先后为准；答案与解析依据在正文对应小节里都能找到。

**例一（答案 D）** 考"原材料"。叶绿体∶细胞——是组成部分不是原材料；乌贼∶墨汁——乌贼喷射墨汁，不是由墨汁做成的；棉花∶布鞋——棉花纺成棉布，棉布做成布鞋，成立。简析见「原材料不等于组成部分，也不等于产物」。

**例二（答案 C）** 考"原材料 + 制作工艺"，题干是泥与陶瓷（烧制）。玉∶手镯——手镯靠"雕"不靠"砸"；鱼∶鸬鹚——鸬鹚吃鱼，属对应不是原材料；铁∶剑——原材料是铁，工艺是淬炼（烧红、锻打、入水）；树与土（树化石）——材料与工艺两头对不上。简析见「工艺得是个真工艺」。

**例三（答案 A）** 考"原材料 + 工艺"，题干玉石∶玉器（雕琢）。蚕丝∶丝绸（织造）、粮食∶美酒（酿造）、生铁∶钢材（冶炼）均成立，蚊香∶烟雾不成立；二级辨析落在物理变化还是化学变化——织造、雕琢是物理，酿造、冶炼是化学。简析见「物理变化还是化学变化」。

**例四（答案 D）** 考"原材料 + 功能"，题干木材∶抽屉（收纳）。钢铁∶剪刀原材料没问题但功能"切割"略勉强；棉花∶毛线两头皆错（毛线原料是羊毛，保暖的是毛衣）；石头∶城墙方向反了；橡胶∶气垫原材料与功能（缓冲）都干净。简析见「剪刀的功能该怎么说」。

**例五（答案 B）** 考"次要/额外功能"，题干白醋∶消毒。热水器加热、白糖调味、人参滋补都是主要功能；汽油的本职是燃烧产生动力，去渍属于额外功能（汽油是脂溶性的）。简析见「主要功能与次要功能」。

**例六（答案 B）** 考"必然属性"，题干黄连∶苦。班级未必团结、花朵未必鲜红、城市未必繁华；钻石一定坚硬（金刚石的碳结构决定）。简析见「属性：必然的那一条」。

**例七（答案 D）** 考"属性 + 种属"，题干素描∶单色。食品∶色素不成立；阅读∶书签——书签只是阅读的辅助工具；变脸∶表演也谈不上是表演的普遍特点；即时∶新闻既满足属性（新闻的特点就是即时）也满足种属（新闻是文体的一种，如同素描之于绘画）。简析见「属性之外，再看种属」。

**例八（答案 D）** 考时间顺序，题干先规划、再实施、再验收。取证排在最后不对；销售、宣传、生产应当先生产再宣传再销售；招投标是先发公告招标、再投标、最后统一开标；先播种、再管理、最后收获。简析见「顺序反了，直接排」。

**例九（答案 A）** 考时间顺序，题干先报警再救援。先消费再生产、先手术再住院顺序都反了；剩两个比"主体"——报警与救援不是同一主体，违章与罚款是同一主体，毕业与就业也牵涉不同主体，据此排掉 B。简析见「主体：是不是同一个人干的」。

**例十（答案 D）** 考"依据"，题干抽样调查依据抽样原则。调查问卷是为征求意见；人物访谈在前、访谈内容在后；建模软件（MATLAB）只是工具不是依据；设备操作依据操作规程。简析见「抽样调查与建模软件」。

**例十一（答案 D）** 考"依据"，即依据教案完成今天的授课。教案∶课件是并列（设计稿与课件，都是辅助）；信息∶分类不成关系，归类与分类只是近义词；提纲∶教案、商品∶分类怎么解释都接不上题干。简析见「关系要经得起追问」。

**例十二（答案 D）** 考"因果"，题干失之毫厘∶谬以千里。走为上计∶三十六计是包含；召之即来∶挥之即去构不成因果；种瓜得瓜、种豆得豆是真因果但自成一体；前人栽树∶后人乘凉才是标准的"前因后果"。简析见「因果关系：因在前，果在后」。

## 类比推理的对应关系与语法关系
> 对应块：BLK30 | 覆盖分集：P15下 | 块标题（分集名）：《第八节——类比推理——刘文超》

知识点讲完了，今天这一节全是练习。对应关系那边的例题一道接着一道，题量非常大，我们一口气做完，然后进入最后一块语法关系。

练习做得快，答案不重要，重要的是每一道排除的时候，你能不能说清楚"为什么它不对"。说不清楚，就等于没做。

### 配套使用：两个东西绑在一起才完整

第一题，鱼饵∶鱼竿。

它俩是什么关系？是不是配套使用的关系？你俩配套使用，拿鱼竿配鱼饵去钓鱼，对吧。

那我们看选项。笔∶书籍，是配套使用的吗？不太合适吧。笔是用来写字的，写诗∶笔，也不太合适——笔的职能是写字，跟书写、跟写诗是一回事，它不是和某本书配套。锅铲∶炒锅，他俩配套没问题。

再看电脑∶无线路由。一定是配套的吗？不一定吧——你的电脑还可能用网线呢；无线路由还可以配手机呢，等等。他俩不是必须配套使用的。你可以单独使用电脑，你没有必要非说他俩一定配套使用，不合适。

所以还是 C 非常完美。

> **易错点**：判断"配套使用"，问的是"是不是必须同时使用、有没有缺一不可"。电脑少了无线路由照样能用，网线、WiFi 配手机都行，这就不是配套。

### 地点还是工具：找最恰当的，别抬杠

第二题，铁匠∶火炉∶镰刀。

铁匠去做这个镰刀，火炉是什么？是一个地点，还是一个工具？我觉得说工具可能更好一点——火炉它是一个工具；或者说你在火炉里面炼，炼到……说地点也可以。

医学家做药剂∶试管。试管是什么？是一个地点，或者是一个工具。A 没问题——试管是你做药的一个必备工具，你完全可能在试管里把这个药做出来、配出来。地点也说得通。

记者做新闻稿是在摄像机。摄像机是个地点吗？你是在摄像机里面做新闻稿吗？它确实是一个配套的工具，但不是主要的，不合适。科学家做新产品是在科学文献里？不好吧。网民在互联网上营销——网民不营销，厂家才营销。

所以还是 A 要更好一点。

但我听见有人在说：我感觉 A 这个试管、药剂也不是特别……

我说，相比之下 A 是最好的呀。我们说得再清楚一点：做这类题，找的是一个最恰当的、最贴近的，我们选一个最好的。要用一个正常人的思维，不要做杠精，没有必要。尤其是做公务员，考试的题目它就是有标准答案的，你想抬杠，那死的一定是你自己。

> **提示**：四个选项里可能有一个不完美、一个"也能这么说"，但你要挑出**最好的那个**，不是挑出没有毛病的那个——那一个通常不存在。

### 原材料、功能、组成，别搞混

第三题，面粉∶面包∶？

面粉是面包的原材料。面包是功能吗？不是。

A，芦苇∶纸。芦苇确实可以造纸，这没问题。那纸的功能是书写吗？各位同学，你觉得合适吗——纸的功能不是书写，**笔的功能才是书写**。所以 A 不合适。

B 不用说了，黄金是戒指的原材料。介质的功能能叫婚戒吗？婚戒是戒指的功能吗？你这么说合适吗？合理吗？戒指的功能你不能叫婚戒。婚戒只是戒指的一种，你也可以说它俩是种属关系，这个说得通，但作为"原材料—功能"这一对，B 不行。

C，轮胎∶汽车。轮胎是汽车的原材料吗？它是汽车的**组成部分**，这不叫原材料。C 也不能选。

那就 D：琉璃是屏风的原材料，没问题；屏风的功能是用来装饰的，没问题。选 D。

这三者的区别，考场上很容易一秒判错，单独拎出来放这儿：

| 关系 | 判断标准 | 本题对应的例子 |
| --- | --- | --- |
| 原材料 | 甲被加工、制作成乙 | 面粉是面包的原材料；琉璃是屏风的原材料 |
| 功能 | 甲是用来干乙的 | 笔的功能是书写；屏风的功能是装饰 |
| 组成 | 甲是乙的一个部分，装上去就在 | 轮胎是汽车的组成部分 |

> **易错点**："组成"和"原材料"的区别就在加工：轮胎不用加工，装到车上就是汽车的一部分；面粉得加工才变成面包。

### 常识题：自然现象的因果别记反

第四题考的是常识，这个题应该没错。

地球的自转引起的是昼夜交替。地球的公转引起的是什么？是春夏秋冬，是四季。

那潮汐是由什么引起的？潮汐是由于月球和太阳的引力引起的——所以一般情况下，白天、晚上，或者一个月里不同时段的潮汐是不一样的，它跟月、日的引力有关系。

所以答案就是 D。这个东西要知道，以后可能会考别的。潮汐和地球的公转，这两个需要说一说，其他的就没什么了。

### 因果之后，还有一段时间顺序

第五题，盲动∶一败涂地。

这是一个因、一个果：盲动导致了一败涂地。然后呢？一败涂地之后你需要重整旗鼓。这是一个先后顺序，一个时间上的顺序——后半截也是"一败涂地，然后去重整旗鼓"。

看选项。超速导致了风驰电掣，这不对吧，说不通。跟风导致了鹦鹉学舌，这也不是因果呀。熬夜导致你萎靡不振，没问题吧；萎靡不振之后，你是不是需要养精蓄锐？这也是一个时间顺序，先萎靡不振，然后养精蓄锐。所以 C 没问题。

顺带说一句，"盲动"就是盲目的地去做一些动作、盲目的地干一些事情。

第六题更绕一点：高考、招生、入学、毕业，这是一个时间顺序吗？

好像都说得过去，但你仔细一想，它根本不是一个严谨的时间顺序。你肯定是**先招生**——我要招多少学生，我得先发出我的招生公告、招生计划；然后你再去高考；高考完了之后你再入学；入学之后你再学习；学习之后你再毕业。这中间事情太多了，A 肯定不是这样一个逻辑关系。

> **易错点**：你报名 ≠ 人家招生。招生是学校先定计划、先发公告的动作，发生在高考之前。千万不能按自己的感受去排顺序。

而你再往 D 上一看，也不可能再选 A 了：先挂号，挂完号再去看病，看完病之后才痊愈。这个太完美了。D 太完美了，不要再去纠结 A，没有意义。

### 诗词对应的是情感，不是字面

第七题。

"故人西辞黄鹤楼"对应的就是送别、离别，是不是都可以？这个先放在这儿。

"折戟沉沙铁未销"，这是什么？这是赤壁怀古，对应的是怀古。所以答案是 C。

"西出阳关无故人"，这个才是送别。

A、B 肯定是不对了。

### 亲属称谓：这题还能错？

一看到这种题，我就看看你们公屏里的答案，真的是一声叹息——回家问问你的爸妈，每个人该叫什么；你以后是要教你的孩子的，你连这些人物关系都数不清吗？

捋一遍：

- 你的爸爸和你的叔父、你的叔叔，他俩是兄弟，对不对。
- 你的哥哥和你的婶婶是夫妻吗？没有。婶婶是谁？是叔父的老婆、叔叔的老婆。哥哥和叔叔的老婆，都差辈儿了。所以选 A 的，没有。
- 你的妈妈和你的嫂子：妈妈是婆婆那一辈，嫂子就是你哥哥的媳妇，你妈妈和你哥哥的媳妇是婆媳。所以 B 没问题，B 的关系是对的。
- 你的姨妈和你的伯伯：姨妈是你妈妈的姐妹，伯伯是你爸爸的哥哥，他俩不是兄妹，以前都不认识。
- 你的奶奶和你的姑姑：她们是母女关系，不能叫子女。选第四个的同学，这是常识，不能错。

答案就是 B。

### 景物对地域

春雨和杏花，都是春天的东西，对应一个地点叫江南。我们一看到江南，脑子里都是"江南好风光"——上有天堂，下有苏杭。把春天这些美景对应到江南，这是一个非常完整的对应。

A，夏河和烈日，都是夏天的，那夏天对应一个江北，江北就是北方。夏天配北方不太好，但你也不能说一定会排除，因为江南和江北，你很难说得清楚。先放在这儿。

B，秋风和腊梅——错了吧？秋风是秋天，腊梅是冬天。

C，秋霜和枯草，都是秋天。秋天是不是一片萧瑟？我对应了塞外——大漠孤烟直。这个不比 A 好多了吗？比 A 好太多了。

D，冬雪和牡丹——牡丹可不是冬天的。

那就选 C。

### 必要条件：水之于生命

这一题没什么好说的，直接选 A。

水对应生命，水是生命所必需的。二氧化碳是光合作用所必需的。二者都是"后者没有前者就不能进行"的关系。其他几个根本就没有什么逻辑关系。

### 两个并列的东西，属性要对得上

#### 都是原材料

先确认逻辑关系对不对。面粉和鸡蛋，他俩是不是都是蛋糕的原材料？

再看别的：香蕉跟西瓜，都是水果的一种，这是种属。纸张跟打印机是文件的原材料吗？不对，这不叫原材料。菊花跟茱萸呢？是重阳节的一些标志、一些象征，这也不是原材料。

水泥跟钢筋，是房屋的原材料，没问题。

#### 都是功能

光盘和硬盘：他俩是并列关系吗？是并列里的反对；然后它们的功能是不是要**存储**？是，他俩都有功能，叫存储。

A，衣架和绳索，功能都叫晾晒。绳索的主要功能是晾晒吗？不太好。绳索能干的事情多了去了。这个地方不太好，先放着。

B，钢叉和锅铲，功能是吃饭。你不会拿锅铲吃饭吧？选 B 的没有。钢叉能不能算？国外确实会用小钢叉吃饭，这很正常，钢叉说得过去；但锅铲不能吃饭，所以这个 A 选项就不够好。

C，签字笔和毛笔，功能都是书写。这太完美了。

D，游泳和泳衣，功能是游泳？这不叫功能。你游泳的时候可能会穿泳衣，可能会借助一下泳圈，这根本不叫功能。

所以答案是 C，没有比 C 更好的，其他的都有很多问题。

### 语法关系：一切从造句子开始

语法关系里先说主谓。

"学生∶学习"，这是一个什么？学生（主语）学习功课，对不对？这是一个非常完整的句式：主谓宾——学生学习功课。

但如果只给了"学生∶学习"，是不是只有一个主谓？是一个主谓关系，顺便说，"学生"这俩字本身还是一个职业。

那动宾呢。"学生∶功课"——学生跟功课，他俩之间就只有一个主语和一个宾语，其他的东西需要你去补齐。补齐了才是"学生学习功课"，缺的那一块就是谓语。

```text
     学生        学习        功课
      |           |           |
      +-----------+-----------+
            主谓宾：学生学习功课
                    |
        +-----------+-----------+
        |                       |
   学生  学习              学生  功课
    （主谓）              （主宾）
        |                       |
  关系就是主谓            谓语缺了，要补
  一个字都不用加          补上"学习"才成话
```

那么，出现语法类关系，我们应该怎么做？这里有一个原则，就是**造句子**。这对主谓、动宾这类关系尤其管用：把两个词都放进同一个句子里造一遍，看是不是通顺。

造句子的规矩有四条：

- 如果加上一个字（一个成分）才能变得通顺，那你就去加字；
- 如果不需要加字，就不要加字；
- 能少加的时候就少加字；
- 真的要加字，加的内容尽量要一样——题干和选项要对称着补。

来做几个题就知道怎么回事了。

### 一个字都不用加，和一定要加字

#### 例一：厨师烹饪食物

这题一看主语、谓语、宾语，非常完整的一个主谓宾：歌唱家歌唱歌曲。

看选项。厨师烹饪食物——非常完整，一个字都不用加。好。

学生学习考试？不对。考试不是"学习"的……你学考试应该叫预习，对吧；要考之前温习，那叫复习。律师反应——"反应"根本不是动词。清洁工施肥、垃圾——这成不了话。

所以答案就是 A。

#### 例二：制定政策、执行政策

设计问卷∶发放问卷，是不是应该先设计问卷再发放问卷？这是一个先后顺序。

那播放和快进呢？磁带的播放和快进，有必然的顺序吗？我可以先播放再快进，也可以先快进再播放。他俩没有一个必然的先后顺序，对不对。放在这儿。

先制定政策、再执行政策，没问题，太完美了——先制定一个政策，再执行这个政策。

复制和修改，我可以先复制再修改，也可以先修改再复制，没有一个必然的先后，所以不对。

预习和考试，考试能用来预习吗？难道你提前知道答案？显然不可能，先预习不是"考试"。

所以选"先制定政策、再执行政策"这一项。

### 练习：主谓、动宾，和那些长得像的

#### 居民居住，继承人继承

这题简单，一看：居民居住，这是不是一个主语、一个谓语？是一个主谓关系。

A，继承人去继承，没问题吧？继承人就是去继承嘛，继承什么遗产等等，对吧——主谓关系。

B，守财奴吝啬。吝啬是一个动词吗？吝啬是一个形容词。守财奴是吝啬的，这不是主谓。C，"守财奴顺从"——怎么能去顺从呢？D，流浪者乞讨——流浪者乞讨什么？乞丐才乞讨呢。流浪就是流浪：我现在背上包出去就可以流浪了，我是个流浪者；流浪者流浪可以，卖艺也可以，但你不能说他乞讨。

所以 A 最好。

#### 在会议上讨论方案，在基层调研实情

在哪做什么。会议上讨论方案，没问题吧？课题上合作计划？手机上研究销量？汽车上分析技术？都不好。

D 我在基层调研实情，太完美了。

#### 规避风险，是为了避免损失

先看逻辑关系：规避风险，应该怎么样？规避风险是为了避免损失，或者说是为了减少损失——要加字才通顺，那你就去加字。

- 购买保险是为了避免赔偿？不对。购买保险是为了赔偿，而不是为了减少赔偿、避免赔偿。
- 关爱老人是为了避免长寿？不对。
- 加强锻炼是为了避免肥胖？没问题。加强锻炼，避免肥胖，成立。

D 呢，保卫军队。军队是保卫，而不是保卫军队——军队还需要你保护啊。逻辑关系也不对。

所以答案是 C。

到这里，整个类比推理就讲完了。
