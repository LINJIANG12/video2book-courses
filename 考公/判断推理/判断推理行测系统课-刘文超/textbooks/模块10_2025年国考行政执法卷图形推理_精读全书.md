## 2025年国考行政执法卷图形推理逐题拆解
> 对应块：BLK27 | 覆盖分集：P14 | 块标题（分集名）：《2025年国考行政执法卷图形推理》

2025年国考，判断推理，我们从行政执法卷开始，图推这一部分从头到尾做一遍，第一题快速做一下。

先把总的面貌说清楚：这一卷的图推从第一题一路排到第八十五题，十道题里前三道是平面图形，接着黑白块、样式规律，后面直接上立体截面、立体拼合、展开图，最后又回到平面。风格跳得挺快，别指望一套方法打天下，每道题都得重新判断"这一题该从哪儿下手"。

所以真正决定做题速度的，就是下手准不准。

### 数面没规律，就去看最大面（第 1 题）

第一题拿过来，我们第一眼能看到什么？一个封闭的整体区域，里面中间有很多个窟窿，有很多的"面"。面太明显了，既然这么明显，那大概率还是跟面有关系，那就先数面。

四幅图数下来，四个面、三个面、三个面、四个面，然后接着 1、2、3、4、5、6、7、8、9 往下数——这后一串是把外框的边数连着数，看它跟几边形有没有关系。一路数到九，感觉明显不对，这路估计出不了规律。

> **结论**：面和边暂时都没有规律，但这不代表跟面无关。面太扎眼的时候，规律往往不在"面的数量"上，而在"某一个特定的面"上。

关于面，除了考数量还能考什么？国考最近特别喜欢考**最大面和最小面**。我们考过最大面和最小面的关系，考过它们跟整体图形的关系，也考过它们内部自己的规律，各种组合都出现过很多种，刷得多了应该有这个感觉。

回到这道题：最小面不好说是谁，先不管。最小面找不到，那就找最大面——这里只有一个最大面是能看出来的。

看最大面。看边长？看不出。看对称性？有规律：它们都是对称图形。那再细一层，是轴对称还是中心对称？

| 选项 | 最大面的样子 | 判定 |
| --- | --- | --- |
| A | 根本不是对称图形 | 排除 |
| B | 明显不是对称图形 | 排除 |
| C | 平行四边形，中心对称 | 排除 |
| D | 是轴对称图形 | 答案 |

> **提示**：中心对称不等于轴对称。平行四边形是中心对称图形，但它不是轴对称图形。C 就栽在这条上。

所以这道题考了半天，就考了一个比较简单的东西：最大面都是轴对称图形。听着简单，但如果你近几年国考题一直在刷，你应该能感觉到——国考在"面"这一栏里反复考的就是最大面、最小面：它俩的关系、跟整体图形的关系、内部单独的规律，甚至跟数量融合在一起。组合非常多，想得到的前提是刷得够。

### 旋转叠平移（第 77 题）

第 77 题就轻松了，一眼就能看出来：这不旋转了吗？

主体图形在转，第 1 幅到第 2 幅转 90 度，第 2 幅到第 3 幅再转 90 度，那下一个自然是再转 90 度之后的样子。

但边上那两个小东西是另一回事——它们每次沿着边线往前挪一格，第一幅到第二幅挪一格，第二幅到第三幅再挪一格，所以问号处它们应该再挪一格。

```text
问号处 = 主图形在第 2 幅的基础上再转 90°
        ＋ 两个小元素各自沿边线再前进 1 格
        两套机制同时对上的那个选项 = C
```

> **易错点**：一眼看到"旋转 90 度"就急着选答案，忘了边上还有两个在动的元素。这种题永远是两套机制叠在一起——主图形一套，小元素一套，两边都要对上号才行。

答案是 C。主图形转，两个小东西移动，挪挪挪。这个大家应该都能搞定。

### 黑白块的部分数（第 78 题）

第 78 题拿过来我们肯定很开心，因为关于这种 5×5 的黑白块，我们做得实在太多了，考点大概心里也有数：最简单的考数量，还可能考位移，可能考黑球跟白球的对称，可能考部分数，可能考一笔画，还可能考连接方式等等。有很多种，一个一个对就行，这几年跑不出这些东西。

数量比较多，先把黑白分开看。

先看白色。题面第一幅，你能一眼看出它是两笔画——找奇点，一个端点、一个端点、一个端点、一个端点，四个奇点，所以是**两笔画**。

> **易错点**：这里最容易看错的就是笔画，有同学看成一笔了，那是基础不过关。数奇点：四个奇点是两笔，不是一笔。

一边数笔画一边看部分：黑色的是一部分，黑色连成一块。白色呢？白色这有一个小球，另外这些白的是不是都连在一起？所以白色是两部分。

接下来这几幅也是同一个套路：这些黑色是不是又都连在一块，黑色一部分；白色这有俩，这几个连起来，两部分。再继续，黑色全部连在一块，黑色一部分，白色两部分。

规律出来了：**黑色都是一部分，白色都是两部分**。

所以去找"黑一部分、白两部分"的选项。

| 选项 | 黑色部分数 | 白色部分数 | 判定 |
| --- | --- | --- | --- |
| A | 1 | 4（一、二、三、四） | 排除 |
| B | 1 | 2 | 答案 |
| C | 1 | 3 | 排除 |
| D | 2 | — | 排除 |

> **提示**：数部分数的时候，"看着挨在一起"和"真的连着"不是一回事。断开的白块别顺手连成一块，A、C 就是白块数多了，D 是黑色断成了两块。

> **易错点**：这一题里面还藏着一个小考点。盯着白色看：这是一个、这是两个、这是三个、这是四个，然后这是一个五块。所以白色部分数是在 1、2、3、4、5 递增，那下一个应该是一个六。挑 2、4、6 来看，第二个选项也满足。

一道题两层考点，方向完全一致：都是第二个。

### 去同存异之后，还要再水平翻转（第 79 题）

第 79 题拿过来，先横着看，看能不能看出规律。做得多了很明显能看出一个样式规律：你会发现这些线条在互相重复，尤其那两个小图形，到第三幅图的时候又冒出来了。

所以大概率是**同存异**，也就是我们常说的消消乐。但方向上要注意：做完消消乐之后，跟第三幅图之间还差一个旋转或者翻转，不是直接相等。

先拿题干那三幅图验证。图 1 和图 2 消消乐：这条线这条线两边都有，消掉；中间那条线没在两边都出现，留下；这个竖线没有消掉，留下；那两个小图形都保留，保留下来应该就是这个样子。再跟图 3 一比——正好是一个翻转，水平翻转。

再看题面里的第二个图形，这是一个 4×4 的区块。既然是去同存异，那就一个块一个块来，规则就三条：

```text
逐块去同存异（消消乐）的判定
  同色 + 同色   →  消掉
  异色 + 异色   →  不消，原样留下
  ─────────────────────────────
  4×4 全部 16 块判完  →  得到的那一幅，恰好就是 B 选项
  再水平翻转一下      →  得到的那一幅，就是 A 选项
```

所以答案是 A。

> **结论**：这一题的顺序不能颠倒——前两幅先消消乐，再水平翻转，才是第三幅。先翻后消就全错了。

这个题思路是比较好找的，尤其是那两个重复出现的小图形，一眼就定位到样式规律，明显感觉到应该进行了一定的旋转或者翻转。画的时候可能稍微有点麻烦，但不要数错了就行。自己画会比看解析快，按行来，判一格填一格，别凭印象。

### 过 P、Q、R 的平面切在哪里（第 80 题）

第 80 题是立体截面，题干说：用经过 P、Q、R 三个点的平面对其进行切割。

拿到这个题，第一步不是选答案，是**先把那个平面找出来**。P、Q、R 三个点确定一个平面，那这个平面在哪？它是从 P、Q 往 R 那边斜着切过去的一个斜切面。

它切的是哪个实体？底下那个长方体，再加上前面那个小斜坡。横着斜切过来，底下这一块是长方体的截面，前面还会带出一小块斜坡的斜面。所以这个截面是长方体被切出来的那块，加小斜坡被切出来的那块，拼在一起——A。

> **易错点**：立体截面不看"像不像"，只看"是不是那个平面切出来的"。先把 P、Q、R 连成平面，平面画出来了，选项基本就只剩一个。

### 立体拼合：先看缺口对不对称（第 81 题）

第 81 题先说难度。这个题如果真要去拼，我估计没有什么特别好的办法，要大量颅内拼合——颅就是脑子的意思，颅内立体拼合就是靠脑子的立体感硬拼，比较麻烦，看能力了。

题目问的是：棱长为 1 的多面体，在 3×3×4 这个空间内进行拼接，不可能是哪一个。难就难在"不可能"这三个字上。要是问"可能"，我觉得可能还好一点。而且 3×3×4 的空间太大了，这里面很多块都放在背后，我们看不见。选项里是三块能拼上、一块拼不上。

> **易错点**：这类题在考场上的理性处理顺序是——先找巧解；巧解没有、又时间紧，就先搁置，有时间再回过头来看，没时间就算了。真硬拼的话，高压状态下你未必有时间，也未必有这个能力。

那巧解在哪儿？这道题有点特殊，是它的特殊性给了我们一个口子。

看选项，你会发现这些图形是成对出现的。你把它转过来比一比：这两个图形是不是一模一样的图形？这两个图形是不是也是一样的？你会发现这两图形是一样的，这两图形也是一样。

既然是同一个多面体重复出现，那两两组合的时候，最后拼出来的东西一定是对称的。

```text
同一个多面体出现两次
   ↓  旋转、翻转之后必须能完全重合
两两组合时，各自缺掉的那个角应当互为对称位置
   A：这两个缺口对称      ✓
   B：这两个缺口对称      ✓
   D：这两个缺口对称      ✓
   C：这两个缺口对称不了  ✗
   ↓
   答案 = C
```

你看 A 选项里，这边和那边是对称的；B 选项空的这两个地方是对称的；第四个选项这两个地方也是对称的；只有 C，这两个对称不了。

所以心思细一点、敏感性好一点，这题可以秒到 C。

> **提示**：立体拼合看着吓人，但出题人往往会给你留口子。找"重复出现的同一块"、找"缺口是不是对称"，往往比真拼一遍快得多。真要一笔一笔硬拼也拼得出来，但那个性价比不高。

### 展开图只认一个标准：字母的开口方向（第 82 题）

第 82 题是一个特别明显的送分题。两个方案。

第一个方案是画橡皮，画出正方体再折，半分钟就出来了。第二个方案是看方向——不用动笔，但看你看得准不准。

题干说的是同一个纸盒的外表面展开图，除了哪一项以外。这里面是不是出现 A 跟 C？A 跟 C 是不是都有方向？那就先拿 A 和 C 对齐。

A 选项里，把一个 C 旋转 90 度放下来，你想象它就是正方体底面那一圈，这四个面是转圈的，所以这个 C 可以平移到那个位置上来。平移过去一看，两边也都是 C，而且这两个 C 的开口方向是一致的。

再看 C 选项：把这两个 C 统一往上旋转 90 度，转过来之后，A、C、C——这两个 C 的开口方向还是一致的。所以 A 跟 C 没问题。

来看第四个：同样把 C 旋转 90 度放上去，这一个 C 往这个方向，那一个 C 往那个方向，一个往左开，一个往右开，跟前面不一样了。前面 A 和 C 都是同一个方向，第四个不一样，那就是它。

```text
判定基准：字母 C 缺口（开口）的朝向
  A ：两端都是 C，开口方向一致      ✓
  C ：转 90° 后两个 C 开口方向一致  ✓
  ④ ：一个往左开、一个往右开        ✗
  → 第四个（B 连看都不用看）
```

> **结论**：同一个正方体的展开图，所有字母的相对朝向是定死的。有一个方向对不上，选项就出局。

方式很多的，很简单的题目，30 秒搞定。

### 面积全军覆没，只剩正方形（第 83 题）

第 83 题我当时拿过来的第一想法是看面积。你看这每一块都像是小正方形的一半，每一处都是正方形的一半。真实的一个想法就是——会不会考面积？但我简单浏览一下就发现，不行：全都是一半，每一个小正方形里你都只选了一半，那就没办法走面积了。没什么规律，那就整体来看。

整体看这些图形有什么特征。有的图形里有一个正方形，这几个是这种拼接方式的；这也有一个正方形，只是外面的拼接方式又不太一样。乍一看反正都有正方形吧。

那难道就考正方形？看这些正方形在哪儿——这个正方形在中间，这个正方形也在中间，这个正方形在中间；这个在边上，这个也在边上，这个也在边上。

就这么简单就做出来了？就考个正方形？这画得花里胡哨的，最后就考了个正方形？

1、3、4 还真有这个答案。看来国考出题人这次还真没为难人。

> **提示**：图形推理里"简单到不像真的"的规律，往往就是答案本身，不是陷阱。想出来了既然这么简单，那就选了走人，别再想了。

### 特征元素连起来看垂直与平行（第 84 题）

第 84 题稍微有点难，因为之前遇到的不多。

先找特征：两个黑的，再加上两个螺旋圈（双圈），这双圈特别特殊。

数数量——这俩黑的，这俩双圈，2、2，没有规律。要说位移，这俩黑的移不到一块去；内外圈一起位移也不是；上下左右横着竖着位移也不对。这两个小元素都是有特征的：两个圈、两个黑。这还能考啥呢？转圈？不对。移动？也不对。

那还剩什么？把它们连起来看。

连起来一看，规律出来了：

```text
把两个黑 + 两个双圈连成折线，逐条看方向
  ① 垂直   ② 垂直   ③ 平行
  ④ 垂直   ⑤ 平行   ⑥ 平行
  ────────────────────────────
  ①④ 成一组（垂直），③⑤⑥ 成一组（平行）
  答案 = 1、2、4，即 C
```

> **易错点**：这道题很大的一个迷惑性在于，它就放在了一个 4×4 的黑白块里。个别同学一看黑白块会误以为这是一个黑白块的题，可能有一定迷惑性。黑白块里突然多这么个东西，他可能就不往下想了。但这根本不是一个完全新的规律。

这个考点我们以前考过，但是已经很久没考了。这个知识点不是什么新知识点，就是两个特征的元素，把它们连起来，看它们连出来的是平行还是垂直。

所以现在很多时候出题人喜欢炒冷饭。喜欢新是新，但他的"新"是跟前四五年不一样的新，出点新的融合性规律；有时候他想到新的，有时候想不到，就把曾经很多年前的一些东西拿出来炒一炒。

所以大家平时做题一定要广泛涉猎，多刷题、多做，你不要管年份。反正这些规律总共就那么些，这几年喜欢考这个，过几年它又考回去，这种循环性的东西一定要多练多做。

> **结论**：黑白块是载体，不是考点。载体上突然多了几个"看起来像新东西"的元素时，先别慌，把它们当成特征元素去连、去数、去比方向。

### 走投无路，就试一笔画（第 85 题）

最后一道，第 85 题。

这个题拿过来有一个非常明显的特征。我一上来就看到 3 了——不知道为什么，这个 3 我一看就忍不住想试试一笔画，实在忍不住。第三个图形明显感觉乱糟糟的，我一看到它就觉得忍不住要走一走试一下，结果发现它一笔画走完了。回过头来再看别的，明显乱糟糟的，我就忍不住想去试试。

结果是：1、3、4 能一笔画完。第二个，这是一个丁字路口，接着又是一个丁字路口，两处就是四个奇点，所以是**两笔画**。第五个图形正好上面一笔、下面一笔，总共两笔。第六个图形也一样，丁字路口、丁字路口、丁字路口，再加一个点，四个奇点，还是两笔画。

所以一笔画的是 1、3、4，两笔画的是 2、5、6，答案是后面这一组，D。

这道题一笔画的特征非常明显，是一个典型的、非常明显的有一笔画特征的图形。

> **提示**：如果你在一道图推上做了半天、做不出来又不想再耗下去，一定要记住我们总说的这句话——**走投无路一笔画**。走投无路了、找不到了，就回头看看一笔画，试一试，大概率就搞定了。
