## 先属性后数量：对称、曲直、开闭与点线面素角
> 对应块：BLK07 | 覆盖分集：P05上 | 块标题（分集名）：《第三节课——图形推理——属性规律和数量规律——刘》

上一节课我们把样式规律收尾了，这一节接着往下走。开新内容之前，先做个小的回顾——不是走形式，这三条线你得先在脑子里分清楚，不然拿到题就会不知道往哪儿站。

### 元素组成不相同也不相似：为什么先查属性

我们已经把元素组成的三种情况都过了一遍：**组成相同**，优先考虑**位置规律**；**组成相似**，考虑**样式规律**，样式规律里又分加减同异和黑白运算两块；那**既不相同、也不相似**的时候呢？优先考虑**属性规律**。

| 元素组成 | 优先考虑 | 里面具体有什么 |
| :-- | :-- | :-- |
| 相同 | 位置规律 | —— |
| 相似 | 样式规律 | 加减同异、黑白运算 |
| 既不相同、也不相似 | 属性规律 | 对称、曲直、开闭 |

注意，最后一行才是这一节的主场。而且属性这一条线上的三个考点是**有先后顺序的**，不是三个并列的选项让你挨个扫一遍。实际做题时我脑子里走的就是这条路：

```text
 元素组成：既不相同，也不相似
                │
                ▼
         优先考虑「属性规律」
                │
                ▼
    ① 对称 ──► ② 曲直 ──► ③ 开闭
                │
                ▼
    三步都没找到规律 ──► 回头查数量规律
                │
                ▼
      点 ── 线 ── 面 ── 素 ── 角
```

读这张图只要记住一件事：走完 ① 再走 ②，走完 ② 再走 ③，不能因为"对称好像没有"就一榔头砸到 ③ 上。顺序本身就是分数。

### 对称性：只要有一个不对称，这题就与对称无关

对称这个知识点非常非常的重要，因为它在国考里一定会考。**如果你做完一整套题，发现从头到尾没有用到这个知识点，那你一定是做错了一道题，至少错了一道。**

对称里面分轴对称和中心对称，这两者一定要做好区分。轴对称里我们还会考对称轴的数量、对称轴的角度旋转等等。

先说一个能救命的原则，它比任何技巧都管用：

> **结论**：一组图形里只要有一幅不是对称图形，这道题就不是对称规律题。

拿例二那六幅图来说。我们一眼扫过去——第一个图形对称，两个圆既对称无数条对称轴、又是中心对称；第二个对称；第三个对称；第四个不对称；第五个对称；第六个跟中心对称。是不是只有第四个是非对称图形？另外五个全部都是对称。

那按我前面说的，只要有一个不是对称的，这题就不是对称的规律，**千万不要在这个死胡同里出不来**，赶紧去想其他的规律。

> **易错点**：有同学心里会嘀咕"就这一个不对称，肯定还是有规律的，我硬找也能找出来"——千万不要这样。只要一个不是，这题就跟对称无关，立刻放手。你越硬找，越容易在错误的方向上把时间耗光。

还有一个特别容易搞混的地方，务必拎出来说。有同学纠结第六幅：你不是说它是轴对称吗？我可没说它是轴对称啊，它只是一个对称图形，它是一个**中心对称**。上一节课我们前前后后讲了二十多道题，你应该对"轴"和"中心"已经有非常直观的感受了，一眼就能分出来，不能到现在还在这个地方出错。

### 曲直性：全直、全曲，还是曲直结合

对称没规律，我们就来看取值性——也就是曲直性。

> **定义**：曲直性指的是，一个图形是全部由直线构成、全部由曲线构成，还是由曲线加直线共同构成。

判断的方法很朴素，拿眼睛扫一遍线条的粗细形状就行。例一的两个图就很典型：第一个全部由曲线构成，第二个全部由直线构成。

#### 例一：三幅全直之后是什么

例一这个题比较简单。拿过来一看，元素的组成是不相同不相似，优先考虑属性；属性里先看对称——这里面对称吗？是不是只有最后一个是对称的？那这题跟对称是没有关系的，对称不行；那就看曲直性。

后面三个是不是全部由直线构成？前面这两个是曲线构成。所以我猜测下一个应该是全曲图形。那来看看选项，A、B、C、D 是不是只有 C 是一个全曲图形？左边三个全部由曲线构成，右边三个都是由直线构成的。

> **注意**：注意我整个分析的方式。不相同不相似，所以优先考虑属性；属性里第一个先看对称，发现对称没规律；然后才去看曲直性。顺序就是这个顺序。

#### 例二：五幅全曲里藏着唯一的不对称

例二。六幅图形不相同不相似，优先考虑属性，属性第一个先考虑对称。这些图形对称吗？第一个对称，两个圆既对称无数条对称轴又是一个中心；第二个对称；第三个对称；第四个不对称；第五个对称；第六个是中心对称。是不是只有第四个是非对称图形，另外五个全部都是对称？

那按我说的，只要有一个不是对称的，这题就不是对称规律，千万别在死胡同里出不来。赶紧想其他规律。

对称走不通，我快速看一眼曲直性：一，全曲线；二，全直线；三，全曲线；四，全曲线；五，全曲线；六，全曲线。是不是分开了？1、3、5 是一组的。答案是第二个。

我本来以为这个题会挺难，结果在取值性这个地方就做出来了。

#### 例三：按行分组，第三行是曲直

例三。拿过来我一看不相同不相似，优先考虑属性，属性第一个先看对称。这个题里面几乎都是对称图形，唯一一个不对称的是谁？就是这个东西，它既没有轴又没有中心，不是。那这个题其实就不是对称图形。记住我说的，只要有一个不是对称的，对称就找不到规律了，赶紧想其他的。

既然对称不是，那就考虑曲直性。第一行这些全部都是直线；第二行这些一看全部都是曲线；第三行，这两个是不是都是曲线加直线构成的？都是曲直。那括号里至少应该是一个曲加直。看选项，谁是曲加直？是不是只有 A 是由曲线和直线共同构成的，其他都不对。答案是 A。

> **易错点**：当然要看成平面图形。这都是平面图形，不是立体图形——你不要把它想成立体了。

#### 例四：三三分组

例四。拿过来简单瞅一眼，1、2、3、4、5、6 元素组成不相同不相似，优先考虑属性。属性里先看对称：第一个就不对称，既没有轴也没有中心。所以这题跟对称没有关系。对称下来之后看曲直性有没有规律：一，曲直；二，全直；三，曲直；四，全直；五，曲直；六，全直。你看能不能三三分组？可以，1、3、5 一组，答案是第四个。

> **提示**：大家一定要记住我做题的思路。这个题考曲直，不是我上来就想到的。是我分析了很久——先看不相同不相似，优先考虑属性；属性里发现有一个不是对称的，就确认跟对称没关系；对称完事了之后我就去看曲直。

### 两个练习：一个看内外，一个看外框

上面四道题规规矩矩，我们来做两个稍微拧一点儿的。

#### 练习一：内外曲直交替

练习一。拿过来还是不相同不相似，优先考虑属性，属性里我首先看它对不对称：第一个就不对称，所以这个题跟对称没有关系。对称结束了之后我就要看曲直了。你看一眼，是不是都是曲直图形？都是曲直构成的。但是我们再来详细地观察：第一个图形应该是外曲内直，第二个是内直外曲，第三个又是外曲内直，第四个又是内直外曲。是不是外曲内直、内直外曲来来回交替的？所以下一个应该是一个外曲内直的图形。找外曲内直，是不是答案是 C？

这类题我一直说得很清楚：**所有题都不可能是纯平平铺直叙给你的**。出题人经常会加上一些自己的想法，或者从另外一个角度、另外一个难度给你增加一些难度。所以这类题你做得越多，首先你思路要明白——你是怎么去思考这个问题的；思路对了之后，剩下的内容就是做大量的例题，去培养自己的做题思维和感觉。

#### 练习二：先锁箭头，再比外框

第二个练习，简单扫一眼，最明显的一个点是不是应该是这个箭头？都有这个箭头。你发现这个箭头在怎么样？是不是在旋转？怎么旋转呢？是不是都在逆时针旋转 45 度——这个样子、这个样子、又这个样子。所以等到下一个图形，首先我这个箭头应该是这个样子的。

箭头这一步没问题吧？长都一样，那 B 和 C 是不是就排除了。我剩 A 跟 D 选。

那 A 跟 D 的区别在哪里？区别是不是就在外面这个框不一样？看外框吧：第一个外框是个圆，是个曲线；第二个外框是个正方形，是个直线；第三个外框是个心，是不是一个曲线；第四个是直线；第五个应该是个曲线。所以这个外框下面是不是应该由一个直线构成，所以答案是 D，A 就错了。

有同学问：这一题怎么没按之前说的"不相同不相似"的顺序来？我其实是按照这个来的——**先对这个图形本身要敏感**。你先确认这个箭头，箭头在转，箭头在这儿，OK 那没问题；确认完了之后，你就一定是从 A 跟 D 里选。剩下你是不是要看选项的区别？看 A 跟 D 的区别是不是就是外框是什么形状？看外框做对比，直线、曲线、直线、曲线，答案就出来了。

还有同学纠结：第四个图形那不是对称吗，这个题为什么不考虑对称？之所以不考虑对称，是因为你仔细给我注意了——这个箭头在怎么转，它是转了 45 度的，这个方向对应了 45 度，它不是一个轴对称；而外框是一个六边形，这就不是一个对称。不要在这个地方马虎了，它不是对称的，所以这个题不考虑对称，不考虑对称那就去考虑曲直嘛，所以是一样的。虽然没有上来讲对称，是因为这个箭头实在太明显了，它完全不对称。

> **结论**：差异型选项的常规打法——先用题干里最扎眼的那个特征（比如这里转动的箭头）锁掉一批选项，再回头比较剩下两个选项之间的差异。**差异本身就是考点**，这道题的差异落在外框的直／曲上。

### 开闭性：蚂蚁能不能跑出去

那我们再来看第三个考点，叫做开闭性。说实话，它考得非常非常少——近 45 年里面，我其实只找到了两道真题。所以这个考点的出现频率非常非常低。这里还是先拿出来讲一讲，万一考了呢。

> **定义**：开闭性指的是图形是全封闭、全开放，还是半开放半封闭。

那什么叫全封闭？你看这个月亮，你在中间放上一个小蚂蚁，它能跑出去吗？跑不出去吧，所以它就是一个全封闭的图形。再看这个笑脸，我在笑脸中间放一只蚂蚁，它是不是也跑不出去？它也是一个全封闭的图形。那什么叫全开放？放一只蚂蚁，它是不是畅行无阻？这就是一个全封闭和一个全开放。

我们以前一直考的是全封闭和全开放，所以之前一直没有去讲半开半闭。但是 2019 年春季的联考，竟然考了一道半封闭和半开放的，所以我也把这道例题给大家拿出来了。

```text
        判断标准：往图形里放一只蚂蚁，问它能不能跑出去

   月亮、笑脸 ──── 跑不出去 ──►  ┌────────┐
                                  │ 全封闭 │   常规考法
                                  └────────┘

   四散的线条 ──── 畅行无阻 ──►  ┌────────┐
                                  │ 全开放 │   常规考法
                                  └────────┘

   中间是几个面，
   外面有线连着，
   形不成一个完整的"面" ──────►  ┌──────────────┐
                                  │ 半开放半封闭 │  2019 春季联考
                                  └──────────────┘
```

> **易错点**：这种题的特征有的时候其实蛮明显的。像有些图形里面会留下一些开口——某个圆突然没封上，开了个口。见到这种图形，我们就可以考虑开闭性了。

#### 六个银行标志那道题

来看例一，非常经典的一道例题。

我们还是理一理做题思路。拿过来我简单扫一眼，不相同不相似，优先考虑对称，一定是。第一个是轴对称的，也是一个中心；第二个对称；第三个是中心对称；第四个也对称；第五个又对称，又是一个中心；第六个——不对称。看到了吗？看到这个**小开口**了吗？它不对称。所以这六个图里有一个不对称的时候，你要注意：这个题不是在考察对称这个规律。

那你再来看曲直，这题跟曲直有关系吗？好像没有吧，是不是都是曲直，而且这个图形你也数不出曲直性来。所以这题跟曲直没关系了。那我们再来看，是不是这个题就是开闭啊？刚才我说了，开个小开口的时候，就可以考虑开闭性。

那你看一看：第一幅图是不是一个全封闭的呀？它是一个封闭的图形，你放一只蚂蚁，它逃不出来吧。第二幅，放一只蚂蚁，能不能出来？可以啊，这是一个开放的。第三幅，这地方是不是开口啊？放一只蚂蚁是可以出来的，它也是一个开放的。第四幅，蚂蚁出不来，它是封闭的。第五个呢，封闭的。第六个呢，是不是开放的。

开闭性是不是就把这个题分开了？1、4、5 一组，2、3、6 一组。答案是第二个。

有几个有点生活常识的同学会觉得：这几个图形代表的是什么标志啊？图一是不是一个中国银行的标志？图二呢，是农行的。图三是哪一个？图三是浦发银行，上海浦东发展银行的。图四呢，图四是不是工商银行？图五这是以前的，我查了一下，是深圳发展银行的，以前的深发展，后来是被中国平安给并了，吸收之后变成了现在的平安银行——以前的深发展是一个很厉害很厉害的银行。最后第六个，这是农村信用社，农信社。

有同学就会问：这六个不都是银行的标志吗，会不会还有相应的规律？这里我还是强调一点：**除了江苏以外**，我们再去做图形推理的时候，是不考虑这些图形的含义的。除了江苏省以外，其他的考试我们都是不考虑图形的内涵和它的含义，只考虑图形的规律。不要从其他的角度去考虑，那是没有规律的。

> **易错点**：除江苏以外，图形推理不考图形的内涵与含义，只看图形本身的规律。江苏的小伙伴除外。

#### 半开放半封闭那道题

来看例二，这个就是我说的今年新考的这一道。

这个题目我进行了一个重新录制，因为这个题目一直没有一个特别完美的答案。我第一次讲这个题的时候，所给的一个规律是关于开闭性的。

以第二个为例：我第一次说第二个图形是一个全封闭，什么意思呢？你看它外面这一个框，是不是完完整整地把这个全部都给包在内了，它是一个完整的、完全包在内的。③也一样，我认为它是一个全封闭的图形。而①呢，它是一个面，剩余的都是线在连接着，所以它最外面没有办法完成一个大的一个面，所以我把它定义为半开放半封闭。以至于你看 ②③⑤，我就定义为是全封闭了。然后 ①④⑥，因为跟①一样，中间是这几个面，然后外面还有线连着，没有办法进行一个完全的封闭。所以我最开始是这么定义的，答案应该选第三个。

后来呢，经过各位同学的集思广益，我觉得另外一种方式会更好一点，解释得也更好一点。是什么呢？其实①② 这两个面之间，是不是通过一条线连接着？四呢，这个面有三个，这三个面之间是不是也通过这样的线来连接着？六呢，这几个叶子，这几个面是不是都是用这个线来连接着的。而另外的 ②③⑤ 这几个面之间，这几个面是不是都挨在一起、靠在一块儿的？

所以说，答案虽然还是 C 选项，但我们的解释角度不太一样了。我更倾向于后面这种解释：①④⑥ 是它们之间都通过线在连接着，另外的 ②③⑤ 是它们这几个面都靠在一起。

> **提示**：为什么我觉得这种解释更贴近一点？关于这种"几个面之间用这个线进行连接"，在最近的国考卷里是有过类似的这种方式的——具体哪一年我记不清了，但应该就是最近的国考卷。国考卷里出现过"几个面之间用线连接"和"几个面靠在一起"这种规律，所以我感觉联考应该是参照了国考，可能就出现了这个题目。所以后一种解释方式会更好。

关于这个题，给的答案依然没有变，还是第三选项，只是我们关于它的解释变了。

### 属性规律走一遍回头看

最后简单做一个总结。

关于属性规律这个方向，什么时候用？元素组成不相同不相似的时候，优先考虑属性。

属性里面，第一个先看对称。对称里面有轴对称和中心对称；轴对称里面要额外关注对称轴的方向和对称轴的数量，这些都有可能成为我们的考点；也可能是这个图形既轴对称又中心对称，等等。对称性非常非常的重要，所以呢我也带着大家做了大量的练习题来巩固它。

对称结束了之后呢，我们再去看一眼曲直。曲直里面也是优先看这个图形它是一个全直的图形，还是一个全曲线的图形，或者说看一看，如果不行，再去看一下它是不是由曲直来构成——考法会比较细化一点，大家对这种细化的考点也要清楚。

然后我们再去看开闭。开闭我们优先是去考虑全开放和全封闭，只有极个别有些题，我们实在是找不着规律的时候，才可以去考虑它是不是半开放和半封闭的。

这就是我们所谓的一个属性规律，也就是我做属性题的一个完整顺序。

### 数量规律：数量很明显时，就别先看属性

好，那我们翻到第四节，数量规律。

> **说明**：刚才思路被直播间的问题打岔了，我重新来理一下，不然思路就断了。

那什么时候我们考虑数量规律？元素的组成既不相同也不相似的时候，我们刚才说了，优先考虑属性。属性里面是对称、曲直、开闭，我先想了这些。**但其实会有一些题，它的数量规律非常明显，它有一些特征——你可能会跳过属性，说"我先不用看"。**

比如我一看这个题，"哎，这里面有好多条曲线"，所以我就猜测这个题好像要考我数曲线的数量，那我就跳过属性，直接去数线。或者这个题里面有非常多的面儿、一个一个的面儿，非常非常典型，那这个题我可能一眼就觉得 OK，这题要考我的面数量，所以我就跳过属性去看面了。

这就是关于数量规律。数量规律也非常的重要，可能占到了小一半的数量，小一半类的题型。所以数量里面的考点也比较多，大概会有点、线、面、素、角，我们化为点线面素角五个题型给大家讲。大家也按照这个顺序来记忆就可以了。

### 数的点：只数交点

那我们先说最简单的点的数量。

> **定义**：在公务员考试里面，"点"指的是**交点**。点是有非常多种的：有交点，有端点，有直线和曲线的交点等等——点的数量非常杂、非常多。我们数点的时候，数的是**线与线的交点**。

具体到图形上可以再往下细分一层：

| 点的类型 | 怎么数 |
| :-- | :-- |
| 直线与直线的交点 | 常规数交点 |
| 曲线与曲线的交点 | 常规数交点 |
| 直线与曲线的交点 | 常规数交点 |
| 切点 | 一个圆和一条线相切，切点**只有一个点**，它也算交点 |
| 端点 | 不是交点，不算 |
| 完全没有交点的图形 | 数点时是**零** |

大家注意了，前两个是不是直线和直线的交点？第三个图形是不是一个直线和曲线的交点？这个图形是不是一个曲线和曲线的交点？所以这三类是不是也可以分成三类不同的考点？直线和直线、曲线和曲线、曲线和直线，这也是三类不同的考点。

那切点呢？一个圆、一条线，这个圆和这个线是不是有一个切点？它有一个切点，而切点是不是**只有一个点**？注意，它也是一个交点。

#### 什么图形一看到就该想数点

数点这种题的特征图有三类：

1. **线条交叉非常明显**，像一个大树杈一样，线条在中间交叉出好几个交点；
2. **画了一条线在里面乱窜**，中间会形成一些点；
3. **相切比较多**，图上一串切点，此外可能还额外有一些其他的点。

> **提示**：很多同学会觉得这些东西出现的时候未必一定是数点，但它确实是数点的特征图——它有可能考一笔画（这个我还没有讲）。但是出现的时候，你不仅要想到一笔画，也要能想到它可能是数点。

#### 数点例一：从大树杈找到规律

我带着大家做例一。这题不难，这些都不是难题。

拿过来之后大家先想什么？先看到了什么？其实对于我来说，我拿到这个题的时候，第一眼看的是对称。我一看选项里面所有的这个选项，应该是都不相同、不相似，优先看属性。属性里我第一个先看对称，我看对称的时候发现：诶，是不是第二个不是一个对称图形？我一看第二个不是对称图形，所以这个题对称没有规律了。曲直、开闭都没什么规律。

那属性没规律，怎么办？我是不是一下盯到了第一个图形？这是不是一个大树杈子？中间有一个交点。所以我来猜这个题是不是有可能是考点。我只是说它**有可能是**考点啊，没说它一定是的，所以我们来测试一下：数点对不对？一个点、两个点、三个点、四个点、五个点——找到规律了。这题很简单。

那这个也找一个六个交点的，瞅一眼：六个交点呢是哪一个？第一个不对；第二个，一、二、三、四、五、六，没问题；这个是十个交点，不用看了。答案是第二个。

> **提示**：注意我是怎么思考这个题的，不是我上来就能想到。最重要的是这个点——我是怎么想到这个题就数点了呢。属性没规律的时候，再回头看图上有没有特别扎眼的视觉特征：大树杈、乱窜的线、大量的切点。有，就去数点。

### 本讲提到的题目

这九道题都是图形推理，题干的具体图形只能按课堂口述还原；答案和判断依据的关键特征在下面逐条列出，完整解析都在正文对应位置。

**曲直例一** —— 题干：一组图形，其中若干幅全部由直线构成、若干幅全部由曲线构成，问下一幅应选哪个。**答案：C。** 解析：后三幅全直、前两幅全曲，推断下一幅为全曲；四个选项中只有 C 是全曲图形（左边三个全曲，右边三个全直）。

**曲直例二** —— 题干：六幅不相同不相似的图形，其中只有一幅不对称，问应选哪一项。**答案：第二项。** 解析：一幅不对称即出局，对称无规律；转看曲直，1、3、5 全曲一组，其余为全直，故取第二项。

**曲直例三** —— 题干：图形按行排列，第一行全直、第二行全曲，问括号里应填哪一项。**答案：A。** 解析：第三行两幅均为曲直结合，括号里至少应有一个曲直结合，只有 A 由曲线和直线共同构成。

**曲直例四** —— 题干：六幅不相同不相似的图形，问应选哪一项。**答案：第四项。** 解析：第一幅即不对称，对称无规律；曲直性上 1、3、5 为曲直、2、4、6 为全直，三三分组后选第四项。

**练习一** —— 题干：一串由内外两层构成的图形，问下一项。**答案：C。** 解析：内外曲直交替出现（外曲内直 → 内直外曲 → 外曲内直 → 内直外曲），下一个应为外曲内直，只有 C 符合。

**练习二** —— 题干：外框内含一个箭头的图形连续出现，问下一项。**答案：D。** 解析：箭头每次逆时针旋转 45 度，B、C 因箭头方向不符被排除；A 与 D 的差别只在外框，外框按曲线、直线、曲线、直线、曲线交替，下一个应为直线外框，故选 D。

**开闭例一** —— 题干：六幅由内层形状和外框组成的图形，问应选哪一项。**答案：第二项。** 解析：第六幅因小开口不对称，且六幅均为曲直构成，两个属性都排除后看开闭——1、4、5 全封闭一组，2、3、6 全开放一组，下一个应开放，取第二项。

**开闭例二**（2019 年春季联考） —— 题干：由若干面和连接线构成的图形，问应选哪一项。**答案：C（第三项）。** 解析：①④⑥ 各面之间靠线连接，②③⑤ 各面彼此紧挨，按此分组答案仍是第三项。

**数点例一** —— 题干：一组线条交错的图形，问应选哪一项。**答案：第二项。** 解析：第二幅不对称，曲直、开闭也无规律；回到图形本身，第一幅像大树杈，中间有明显交点，数交点得 1、2、3、4、5，选出有 6 个交点的第二项。

> **承前启后**：上一节讲完「先属性后数量：对称、曲直、开闭与点线面素角」，下一节接着讲「图形推理的数量规律：属性排干净之后，点和线怎么下手」。

## 图形推理的数量规律：属性排干净之后，点和线怎么下手
> 对应块：BLK08 | 覆盖分集：P05中1 | 块标题（分集名）：《第三节课——图形推理——属性规律和数量规律——刘》

图形推理做到后面，真正拉开差距的从来不是"看出一个规律"，而是"从一堆没规律的图形里，把该数的东西挑出来"。前者靠灵感，后者靠流程。

这一讲我们把属性的路走完，然后集中处理数量里的**点**和**线**。点这块我一共带你过五道题，线这块补两块基本功。中间有几道题是真难，做不出来很正常，我把走过的弯路原样留给你。

### 拿到题先走哪条路

先接一道题的尾巴。答案是第四个，这个大家都知道了，但我拿到题的时候不会直接报答案，得先把推理链走完。

第一个动作几乎不用想：**不相同、不相似**。这几个图形之间既不相同也不相似，那就没有整体性的相似规律可看，就去看属性。

- 对称：第一个就不对称，其余几个也不对称。对称，出不了规律。
- 曲直：一个曲线图形，一个曲线，第三个又是直线。曲直是乱的。
- 开闭：这一堆图形谈不上开闭。

三条属性路全堵死，只剩数量。点、线、面、素、角，数哪个？

> **定义**：数量规律的五把钥匙——**点**（交点、切点）、**线**（直线、曲线、一笔画）、**面**（封闭区域）、**素**（图形元素）、**角**。后面一路用的就是"点线面素角"这个口诀。

很多学过的同学上来看到这种线条交叉的题，第一反应是"一笔画"。我先说一句：这个思路方向一点问题没有，能想到说明你学过。但这道题确实不是一笔画，简单一看就不是。一笔画我后面会专门讲，今天不占这个篇幅。

思路的骨架就这一条：

```text
不相同、不相似
      │
      ▼
先看属性：对称 → 曲直 → 开闭
      │        都没规律
      ▼
再看数量：点 → 线 → 面 → 素 → 角
      │
      ├─ 通用切口：数直线、数曲线
      └─ 特殊切口：先圈出每个图形里"都有"的那个部件
                 （圆、弧），再数它与周边线条的关系
                  ——交点、切点、圆内还是圆外
```

> **提示**：属性这一遍是"排除法"，不是"确认法"。它唯一的作用是把路堵窄、直接给答案的是不存在的；三条都没规律，才轮到数量上场。

回到这道题。落到数量上，数交点：第一个图形，线和线之间形成 2 个交点；第二个图形，直线之间的交点也是 2 个；第三个 4 个；第四个 4 个。**2、2、4、4，成对递增**，下一个就该找 6 个交点的，落在第四个。

### 交点题：先找到"每个图都有"的那个部件

#### 例三：2016 年国考，答案在圆上

这道题一点都不简单，这话我得说在前头。很多同学问"为什么别人能秒出答案"，多半是提前领了讲义、提前做过了。你要是做得慢，千万不要被他们带跑偏了，觉得自己怎么怎么样。他们现在临时做，这道题也得多想一会儿。

老老实实按流程走。

第一步，不相同不相似，优先看属性。

- 对称：只有第六个不对称，其他都对称。六个里有一个例外，对称就不能是规律。
- 曲直：都是曲线图形，曲直区分不开。
- 开闭：一看就不像开闭，跟开闭没关系。

属性走完，来到点线面素角。说实话，这个题让我第一时间想到"数点"，我是想不到的，我心里过了好几个方案都没找着。凭什么上来就想数点？这道题得拐个弯。

拐在哪儿？拐在你把每个图形摊开看一遍：**每一个图形里都有一个圆**，而且文章全都做在这个圆上——焦点、线，都跟这个圆有关系。既然都有圆，那就好办了，去数圆跟周边线条的交点。

第一个图形，直线和这个圆相交，圆上两个点；第二个图形，圆上只有一个点。点着点着，规律就分出来了——**1、3、6，答案是第四个**。

> **易错点**：不要因为"没想到数点"就否定自己。数点是一个需要**切入点**的规律，切入点就是那个每个图都有的圆。先找切入点，再决定数什么。

这道题请大家记下来——**2016 年国考**。由它演变出了 2019 年的题，今年也出了一道跟它非常像的。真题就那么些，你把这几道吃透，后面遇到变体就是老朋友了。

#### 练习一：切点和曲直交点连着数

这一道更热闹。先排属性：

- 不对称，不是对称规律；
- 曲直：四个选项全是曲线（我习惯用 `C` 表示曲线、`Z` 表示直线），全都是曲线，曲直排除不了任何选项；
- 开闭：也没关系。

数量上：数直线没规律；数曲线，题里都只有一个圆，也没规律；点、面、素、角同样没规律。到这一步，常规口径全走不通了。

怎么办？再看一眼图形：**都有圆，也都有切点**，切点特别明显。

- 第一个：切点 2 个；
- 第二个：切点 3 个；
- 第三个：这条直线跟曲线的交点 4 个；
- 第四个：5 个。

下一个就找 6 个交点的。四个选项数下来，只有第二个是 1、2、3、4、5、6。**答案是第二个。**

> **结论**：这题考的是"切点"，但要和曲直交点连起来一起数，别在数到 3 个的地方停手。

答对的同时，这道题还顺手打掉了两个错误答案，我一并在这儿说清楚。

**第一种说法："每个图都只有一条曲线。"** 有人问老师，你看这几个图都只有一条曲线，能不能按曲线条数做？我只能说你去数一数，选项里那条是两条。更关键的是，这个东西你很难说它是两条曲线——就好比那个"八"，你看着它是两笔，其实它是一条曲线，它全程平滑、没有折点。我们找的是最优解，最优解一定是第二个。

**第二种说法："这是一笔画。"** 这题跟一笔画一毛钱关系都没有。自己没学明白的，先不要往这个方向上打叉。

#### 练习二：数点的时候，不用再分曲直

这道题是带着答案来的：一看前四个都对称，那就去选项里找对称的。

然后你去看选项会发现什么？**A、B、C、D 四个全部都不对称，一个都不是对称图形。**

总有人怀疑：老师，你这选项是不是被拉伸过？拉变形了？在这儿我明确告诉大家——**没有拉伸**，原图就是这么画的，就是这个样子。这个圆不在中间，它就不是从中间切开的，所以它不对称。

对称、曲直、开闭，全没有关系。那只剩数量，先看点。

点怎么数？这道题里是圆跟圆切、圆跟圆切、圆跟直线切，再一个点、一个点地数过去：1、2、3、4。

> **易错点**：数点的时候，**曲直交点、直直交点全都数进去，不用分得那么细**。分细是给自己找麻烦，把所有点当成点，整体规律往往就出来了。

所以去找 5 个点的选项——**A**。

### 换一个切口：只看圆里面

这是练习三，2018 年国考。这道题我是真觉得难，做不出来很正常；能做出来的那位同学，相当厉害。

我先请大家把刚才那道题翻出来——2016 年那道。我们把 16 年和 18 年这两道摆在一起看，会发现它们非常非常像：

- 16 年：每个图形都有一个圆，看的是**圆和周边这些线之间的交点**；
- 18 年：还是每个图形都有一个圆，看的仍然是**圆跟周边这些线在边上之间的关系**。

18 年这道题，就是从 16 年那道题演化出来的。16 年那道你要是研究透了，这一道基本就出来了。

这道题的推进过程也值得看一遍。

属性：不对称排除；曲直都是曲线，区分不开；开闭——**开闭的考点非常少**，直接不用看。

数量：数线、数面，其实都没规律。但"都有个圆"这个信号太明显了，还是去看圆和这些线的关系。

第一反应还是数交点：一个、两个、三个、四个，两个曲直交点、四个曲线交点……2、2、4、2、3，摆了一圈，**没规律**。那就别硬撑，题目已经变形了，再想它还能考什么。

> **易错点**：一条规律试出来不成立，最忌讳死磕。要马上退回来换一个"看"的角度——同一批交点，换一个位置范围去数，规律可能就出来了。

这次换的角度是：**只数圆以内的交点**。

```text
把交点分成三个抽屉
  ├── 圆上：切点
  ├── 圆外：圆与圆周以外的线条相交处
  └── 圆内：圆以内区域里的交点

先整个数一遍；数乱了，换一个抽屉再数一遍。
```

- 第一个图形，圆内没有交点，0 个；
- 第二个图形，圆内 1 个；
- 第三个图形，圆内 2 个；
- 第四个图形，圆内 1、2、3、4，四个。

下一个应该找圆内有 5 个交点的选项。选项里数下来，C 明显是 5 个。**答案是 C。**

在数之前，有一句必须提前说：刚才有同学问，端点算不算交点。**端点不是交点。** 我最后再强调一遍。

把这道题讲完，我想多说两句比做题本身更重要的话。

第一，基本的思维和思路一定要扎实。"不相同不相似"、先属性后数量、点线面素角、切入点先行——这些基本东西越扎实，考场上能调用的就越多。

第二，去刷大量的题，而且要**把历年国考的题研究透**。我再说一遍：**不是说你做对了就行了**。做对了，跟你真正掌握它，差了十万八千里。有时间一定要多思考——去分析这么多年出题人在想什么，他的偏好是什么，这道题为什么要这么出、那些点为什么要这么摆，你该怎么攻破它。能把这些想清楚、想明白了，你才叫成熟，你才叫成功。

刷题量上去了，这个感觉会慢慢多起来。这也是为什么我把 16 年那道题反复强调了三遍。

还有同学最近经常来问我：老师，你考这个，学完了到底有什么用啊？以后考公真能用上吗？

我就说一句：你们太年轻了。

行测的全称是**行政职业能力倾向测验**，是国家公务员总局为国家选拔人才设的考试。全国多少人在考公务员，上千万（具体数字我也不知道）。这么庞大的一群人，选拔过程是一堆糊涂蛋选出来的？可能吗？判断推理里四个模块，每一个都在考察大家的判断、逻辑思维等各方面的能力，全都是在侧面测你的能力。

这跟"我以后就是去菜市场买个菜，学微积分有什么用"是一个道理。咱们讨论这个其实是没有意义的，好好去做就是了。你还没有达到那个高度；等你有一天达到那个高度了，再去和公务员总局的那帮老师去理论吧。希望有那么一天。

### 数量的线：先分清一条直线、一条曲线

前面数量一直挂在"点"上，下面转到"线"。这块知识点比点多，学过的同学知道数直线、数曲线、一笔画等等都会用，看着吓人，其实没有想象中那么难。

#### 直线：不要数成线段，也不要数成射线

先问一个特别朴素的问题：**什么叫直线？**

我指着一个图问大家，这个图形里有几条直线？现场最容易错的就是这个。有同学说三条，有同学说四条，都不对，**就是两条**。

> **定义**：图形推理里数直线，数的是**完整的直线**。题目画一条线就是一条，你不要把它拆成线段来数，也不要按射线的两端去数。

> **易错点**：选项图里一条完整的直线和其他线交叉，看起来像被分成了几截——**交叉不等于断开**。该算一条的还是一条。

那什么时候优先想到数直线？看题干给的信号：

1. 出现了**多边形**——多边形自带很多条边；
2. 出现了**单一的直线**。

这两样一出现，就可以优先想：这题是不是要数直线的条数。

#### 曲线：折点就是分界线

再来，什么叫曲线？

**一条平滑的、没有折点的曲线。** 整条线一气呵成，从头到尾都在平滑地走，那就是一条曲线。

比如那个"八"。我随便画一个，从这个点出发一路写下来，全程都是一个非常平滑的过程——它只有一条曲线。

反过来，我画着画着不画了，中间拐了一下，**这就出现折点了**。一旦出现折点，就得算成两条曲线。

> **定义**：**折点就是曲线的分界线。** 一条曲线加一个折点，等于两条曲线。判断一个图形有几条曲线，不用去纠结它像什么，只看一件事：**有没有折点。**

按这个标准：图六只有一条曲线；图七有折点，是两条曲线；那个"八"没有折点，是一条曲线。

那什么时候优先想到数曲线？也是看信号：

1. 整个图形**全是曲线**；
2. 出现了**小圆**；
3. 出现了**单独的弧线**。

只要图形是这个样子的，优先去数曲线。

| 图形给你的信号 | 优先考虑 |
| --- | --- |
| 多边形、单一的一条直线 | 数直线 |
| 整幅全曲线、出现小圆、出现单独的弧线 | 数曲线 |
| 每个图形里都有同一个圆，周边线条与它相交 | 数它与周边的交点、切点 |
| 交点整个数下来是乱的 | 换范围数，比如只数圆内 |

这张表可以直接抄走，考场上按信号反查。

#### 落到例题上

例一这一题我为什么会想到数直线？照流程先走一遍：不对称，第二个图形不对称；曲直没关系；开闭没关系——只能看数量。点？没有点的特征。数线：这里面好多单一的直线，又有好多多边形，**不用想，一定是数线**。

数一数：五角星 10 条直线，第二个 9 条，第三个 8 条，第四个 7 条。下一个找 5 条的——**答案 A**，一条两条三条四条五条，只有 A。

这题的特征还是很明显的，大家认准特征就行。

例二我刚说了个头——这题是不是全部都是四条曲线。思路还是老三样：先排对称、曲直（这里是全曲）、开闭，都没有；再看数量，一眼看到这么多条单一的曲线——你不数曲线，你数啥？

### 本讲提到的题目

课上过的题，按讲解顺序列一遍。题干按课堂上的口头描述还原，答案都是当场定的，解析依据都在正文里，能对上号的自己翻回去看。

**承接例（答案是第四个的那道）**

- 题干：四个图形，线条之间形成的交点个数依次为 2、2、4、4，问下一个图形的交点个数，以及四个选项中哪一个符合。
- 答案：第四个（下一个交点应为 6 个）。
- 解析：对称、曲直、开闭三条属性路全排除后落到数点，交点成对递增。见「拿到题先走哪条路」。

**例三（2016 年国考）**

- 题干：四个图形，每个图形中都有一个圆，圆周边还有若干直线或弧线；已知前后图形中圆与周边线条的交点数呈 1、3、6，问下一个应是多少、哪个选项符合。
- 答案：第四个（1、3、6）。
- 解析：属性排除后靠"每个图形都有一个圆"这个切入点，从交点数量下手。见「答案在圆上」。

**练习一**

- 题干：图形中都有圆或弧，且有明显的切点；题干图形依次含 2 个切点、3 个切点、4 个曲直交点、5 个交点，问下一个是几个、哪个选项符合。
- 答案：第二个（1、2、3、4、5、6）。
- 解析：属性排除不了，常规数量口径也没规律，切点与曲直交点连着数才是正解。见「切点和曲直交点连着数」。

**练习二**

- 题干：题干四个图形均对称，选项 A、B、C、D 四个全部不对称；题干图形的交点数依次为 1、2、3、4，问哪个选项的交点数为 5。
- 答案：A。
- 解析：选项全不对称排除对称规律；数点时不分曲直交点和直直交点。见「数点的时候，不用再分曲直」。

**练习三（2018 年国考）**

- 题干：每个图形都有一个圆，题干图形圆内的交点数依次为 0、1、2、4，问下一个应是几个、哪个选项符合。
- 答案：C（圆内有 5 个交点）。注意端点不算交点。
- 解析：整个数交点得到 2、2、4、2、3 不成规律，改成只数圆内交点即见规律；本题由 2016 年国考那道演化而来。见「换一个切口：只看圆里面」。

**例一（数直线）**

- 题干：图形中既有单一直线又有多个多边形，题干图形的直线条数依次为 10、9、8、7，问哪个选项是 5 条直线。
- 答案：A。
- 解析：出现多边形和单一直线，优先想数直线；直线要数完整的，交叉不切分。见「直线：不要数成线段，也不要数成射线」。

**例二（数曲线）**

- 题干：全部由曲线构成的图形，课上指出"是不是全部都是四条曲线"。
- 答案：未给出（例二只开了头）。
- 解析：思路仍是先排属性、再数曲线；见「曲线：折点就是分界线」。

另：由 2016 年国考那道演变而来的 2019 年题，课上只说"到时候能够做出来"，题干没给，这里不补。

## 数量规律里的“线”：把思路一步步走通
> 对应块：BLK09 | 覆盖分集：P05下 | 块标题（分集名）：《第三节课——图形推理——属性规律和数量规律——刘》

先把上一题收个尾。第一个图形是一条曲线，后面几个依次数下去，一、二、三、四——题干这几个图形都是四条曲线，找到它，答案就是 C。

这个题本身没什么可犹豫的，但刚才那句"开闭不对"得掰扯清楚：**我们讲的开闭，是整个图形全开还是全闭，不是去抠某个局部是开、是半开。** 按局部去数局部，方向一上来就跑偏了。

然后进例三。

### 属性排除干净，数量才有落脚点

例三拿过来，第一反应还是老顺序：不相同不相似，先看属性。

- 对称？第一个图形就不对称，这题跟对称没关系，划掉。
- 曲直性？清一色全是曲的，划掉。
- 开闭？这一个图里有全开的、全闭的、半开的、半闭的，凑不成规律。而且开闭这个点，几乎不用优先想。

> **提示**：开闭性近几年一共就考过两道题。它是"看见特征才回头想"的那一类，不是拿来当起手式的。真有题出现了开闭特征，回头看的仍然是**整个图形**——全开放还是全封闭——而不是某一个角开、某一个角闭。

属性这三条路都断了，才轮到数量：点、线、面、素、角。

点，好像没有点，没有点的特征。线，特征非常明显，好多单一的曲线堆在那儿，曲率一眼就能看出来。既然线这么扎眼，那就先看曲线。

一条曲线，一条曲线，三条曲线；一条，一条，三条。这里有个细节必须点出来：**一条曲线不再往下拆**。不管它在画面上绕了多大的弯，只要是连续的一笔，就是一条。

排下来，1、2、5 三个图形的曲线数是同一档，答案落在第二个。

> **结论**：数量规律的第一反应永远是"数"——点线面素角里，哪个特征最扎眼就先数哪个。数直线只数一条直线，数曲线只数一条曲线，别自己加戏。

### 一排数看不出名堂，就要把两排数放一起减

例四是浙江卷的，比例三难一点点。难不在计算，难在"数完这条数还数不出来的时候怎么办"。

属性这边还是老样子：不对称、全曲，开闭不用想，直接进数量。

点——第二个图就是个圆，连点都没有，肯定没规律。

线——曲线的特征太扎眼了，好多单一的曲线摆在那儿。一条曲线，一条曲线，第三幅图两条曲线，再看第四幅，一条……数完曲线，分不开，没规律。

怎么办？脑子里那句应该是：**我是不是还有直线呢？** 有曲有直，既然属线，那就把直线也数一遍。

直线——两条、零条、三条，两条，一条，一条……单看这一排，还是没规律。两排都没规律，那就上下相减，上面减下面。

减完之后规律就出来了：

- 曲线比直线多一条的图形，差是 1；
- 直线比曲线多一条的图形，差是 -1。

也就是说，**差的绝对值恒为 1**。回到选项里去对应，答案是 A。

> **结论**：数量规律里，"两排都没规律"不是死局，先试试排与排之间的加减。曲线减直线、直线减曲线、点加边、面减线，都是真题里真实出现过的考法。

> **易错点**：差值题一定要写清楚是"谁减谁"，方向反了符号全反，答案会整个翻过来。

### 真经是真经，难就难在见得太少

接下来这段话我每次都要说，但你们听不进去。

例五这题也不难。属性：对称、曲直、开闭都没有规律。数量：点线面素角，一眼就看到这题跟线有关——这些图形都是一笔画成的。但又不是一笔画，那规律是什么？看了半天，没太想清楚。

我直接告诉你：看**第一条线和最后一条线**这两条线之间是什么关系。

第一幅，垂直；第二幅，垂直；第三幅，平行；第四幅，平行；第五幅，垂直；第六幅，平行。1、2、5 都是垂直关系，答案 C。

> **结论**：当"数线条数量"这条路走到头、看不出名堂，就把关注点从"数量"挪到"位置"——第一条线和最后一条线之间是平行还是垂直。首尾两笔的位置关系，是位置规律里最常考的一个切入点。

等一下，我要先说一件事，居然有人觉得例五难。

我告诉你，你去参加浙江的考试，这个题是一定要做出来的，千万不要再说想不到、很难。你想不到，是因为你做的题还不够多，你对这类题还差得远。这个题在浙江的同学是都做出来了的。别的省份也一样，只要参加公务员考，这种题的难度是应该搞得定的。

我为什么对这一个题说这么多？

第一，你做多了就知道，按数值取的题一定跟数有关；第二，这题绝对不是第一次出现。你把历年浙江的真题刷完，会发现"做差有规律"这一类至少出现过两三次。你去参加这个考试，就应该把 19 年浙江历年的真题全部做一遍，并且把这个题里出现的规律性、出题人的一些偏好和可能性都研究透了，考试的时候才能游刃有余，才能想到这些是一定想得到的。

这绝对不能列为难题，连难题的边都没到。

> **结论**：数量规律其实就两大类——按数值取，按位置取。数得乱的是数值，数不出的是位置。而位置规律是真正稀缺、需要经验才能识别的那一类。

另外，你们反馈最多的一个问题是：老师，这个我学的时候特别爽，我觉得我都学会了，但考试的时候很多东西想不到。

只有两个原因。第一，基本知识扎得不够牢；第二，你见的题太少。基本知识打得非常牢，再加上大量刷真题，或者把某一类研究得非常透彻，考试的时候才能更加游刃有余。十个里对八个，是很正常的，也是必须要达到的。

现在做不出来不要害怕。现在只是把基本打牢了，让你见识见识。见得越多了，考试的时候才能出得越多，一定要大量地做题。

顺带给你们一个看真题时顺手该留意的方向：

> **提示**：打开历年真题，别急着对答案，先翻一翻出题人习惯在哪儿放那些"好数"的东西。直线那侧，单一的一条直线、三角形、多边形这类边界清晰的结构是高频载体；曲线那侧，单一的曲线和全曲的图形出现频率更高。见得多了，这种预判素材的感觉自然就有了。

至于课时——我讲"线"这一块，连讲三天，整整数个小时。别的机构、别的老师，同样的内容可能两个钟头就翻过去了。内容量至少是三倍。不是我啰嗦：知识点给两小时，你可能刚明白点东西，老师就翻页了，还没来得及复习。不如像这样，一个知识点配很多例题，再配很多练习，当堂就给你巩固掉，让你见得越多、认识越多，考试的时候才能发挥得越多。希望你们能理解我的良苦用心。

### 八道练习，把完整思维走一遍

先立一条纪律，这条纪律比这八道题本身都值钱：

> **易错点**：我把这道题放在"线数量"这一节，不代表你就可以跳过属性直接去数线。哪怕你正好在刷这一节，顺序也必须是"先属性、再数量"，属性三条路都断了才轮到数线。想到线，一定是你走完正常思维之后剩下的结果，不是我提前告诉你的。

#### 练习一：先把对称排除干净

不相同不相似。先看属性，发现 B 这个东西不对称——**注意，B 不对称**。

假如你认为 B 是对称的，这题也没有答案；再假如它有两条对称轴、是个中心对称图形，也没有答案，因为中心对称会把其他所有规律全部打乱。所以结论是：没对称。曲直性，清一色的曲，也没有规律。

再进数量：没有点；线特征非常明显，数曲线——B 形状里头是两条曲线，眼睛形状里头是三条曲线，第一个图形里是一条曲线。找三条曲线的，答案是第二个。

#### 练习二：线分了方向，就只挑一个方向数

这题拿过来大家去想：对称、曲直、开闭，你乱试一气也试不出东西，因为这里只能数线。**而且这里的线可以再分方向：横线和竖线。**

我先看竖的：三条竖线，三条竖线，三条竖线——有规律。找三条竖线的选项，只有 C 是三条全是竖线，其他不用看了，结束。这题不用想多。

#### 练习三：汉字考的是笔画，也是线

这题挺难，我如果不讲的话，很多同学想不到：考的是**汉字**。

> **结论**：汉字题常考这几样——笔画数（这个字由几笔构成）、线数量（里面有几条直线、几条曲线）、面的数量（后面会讲）、部分数、结构（遇到了再说）。

这个题解在"线"上：每个汉字是不是都有个撇？一个撇、两个撇、一二三四、五个撇，1、2、3、4、5。找四个撇的，那个是 B。最后一个 1 到 6 六个撇，不对。

注意，他数的是**撇**，不是捺——捺不算，全是撇。

这题也不变态，一定是能做出来的。你现在没做出来，是因为见得太少，就该多刷。

#### 练习四：两排都乱，加起来就有规律

这题很多人都觉得难。我按正常人的思路走一遍：对称、曲直、开闭，我一看都不考，也没规律。直接看数量。

每个图形里都有中间那一小块黑的，黑点很明显。数黑点：五、六、三、六、四、四——**没规律**。但是我知道一定跟它有关系。

数完点，还缺一个东西是什么？再看一眼外框：三角形有三条边。边数：三条、四条、五条、四条、六条、四条。

黑点数量一排，边数量一排，两排单独看都是乱的——那就全部加起来。八、十、八、十、十、八。

规律出来了：1、3、6 是一组，和相等；2、4、5 是另一组。答案是 A。

> **结论**：加法也是加减考法的一种。减法没规律，就看和；和也没规律，再换别的加减组合。

#### 练习五：数出来的和想出来的，不一定一样

对称、取值、开闭，都不行；所有图形都是一个曲的，曲直也排除不了；不像点，看线——单一的曲线，好几个圆。

先数曲线：一条、两条、三条，有规律了；一、二、三、四、五，1 到 5。题干排下来了，我该找一个**六条曲线**的。

数出来的情况是：C 像六条，D 也像六条。而中间那个"眼睛"到底算不算一条线？算一条不合适，不算也不合适。**这时候你就得警惕了：D 这个选项本身就不够严谨。**

怎么解决？如果光数曲线还分不开，那就再数直线：一条、两条、三条、四条，直线也是 1 到 5 的规律，那答案图形的直线也得是 6 条。再回到 C：曲线 1、2、3、4、5、6，直线也是 1、2、3、4、5、6，曲线直线都是 6，妥了。

B 怎么淘汰？你把那个椭圆算成一条——平滑曲线，没有折点、没有折线，上面是个圆盖，算一条；中间那个小圆算一条；再加上别处的两条。1、2、3、4 一看就是四条线，而直线太多了，方向就不对。

> **易错点**：一个选项的局部"数不清"，往往不是题目不严谨，而是这个选项本身就是错的，别死磕。能不去研究它，就不去研究它。

考试的时候，你未必能想到这么远。你可能上来就觉得 D 不对，觉得在 C 就已经做完了——这也对，反正答案都是 C。

#### 练习六：这才是难题

这题我给大家点时间，你们看看。你们也看不出来。给你们时间做，做不出来的都是天才了。

难在哪儿？首先我一看，是不是都是三条直线，那一定就是这三条直线之间的关系。

我直接给大家答案：它们是**位置之间的关系**。我先把每个图里的小格子列出来，再看红、蓝、绿三条线各自怎么走：

```text
红 蓝 绿 三线同框 · 逐格追踪（示意，非原图）

        ①        ②        ③        ④        ⑤
     ┌────┐  ┌────┐  ┌────┐  ┌────┐  ┌────┐
红   │ ▓▓ │  │    │  │    │  │    │  │    │  每步向下移一格，移到头绕回最上一格
     │    │  │ ▓▓ │  │    │  │    │  │    │
蓝   │    │  │    │  │ ▓▓ │  │    │  │    │  每步向右移一格，移到头绕回最左一格
     │    │  │    │  │    │  │ ▓▓ │  │    │
绿   │    │  │    │  │    │  │    │  │ ▓▓ │  转过一个角度再转回来，走到位置就重合
     └────┘  └────┘  └────┘  └────┘  └────┘
```

所以从第一幅往后推，红色那条线应该在下面那一格；蓝色的那条在往右移完一格之后又绕回左边继续右移；绿色的那条转到某个角度就转回来，走到那个位置又重合，下一个就该回到上面去了。

这才叫难题。你做不出来非常正常；你要能做出来，我才觉得你厉害。之前那些题都是能做出来的。很多同学之所以做题不行，就是见得还不够多。

### 平行还是垂直，以及各省卷子之间互相抄

最后一道练习八简单多了，就是纯粹的平行和垂直：平行、垂直、平行、平行、垂直、垂直。134 一组，答案 C。

好，今天可以完美收官了。

但这个收尾比那道题值钱，我再拎出来说一遍。这几道题的来历，你们要记着：

- 练习七是 2019 年的北京卷，实际考的时间是 2018 年 12 月；
- 练习八跟它一样，出自 2019 年河北卷，2019 年 5 月考；
- 再往前翻，还有一道 2019 年山东卷，4 月 20 号考的。

这几道题里面，北京卷是最先出的。北京出完之后，山东模仿了一下，河北又模仿了一下。

所以我为什么说这个题你应该能做出来？因为它不是平白无故凭空生出来的，它出现过，你做过，你把它想明白了，再见到的时候就知道怎么做。**天下的文章一大抄，天下的试卷也是一大抄**，行测的出题就是你抄抄我的、我抄抄你的，而且都优先去抄国考。

各位同学，要多练，做得越多，考试的时候能想到的才越多。
