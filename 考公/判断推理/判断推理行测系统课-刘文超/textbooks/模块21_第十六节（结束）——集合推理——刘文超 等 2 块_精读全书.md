## 集合推理：所有与有的，推与不推
> 对应块：BLK50 | 覆盖分集：P25上 | 块标题（分集名）：《第十六节（结束）——集合推理——刘文超》

### 先掂一掂分量

先说一件事，免得你觉得这章的分量配不上它名字里那个"推理"两个字：**集合推理的考评非常低。**

国考加联考，近十年其实只在 2018 年考过一道；近五六年一道没考；再往前，也没考过。所以大家看，考频低得相当可怜。

但有些地方不一样。广东省考、广东选调、深圳市考——从广东这些考试来看，一般情况下每年大概一道，或者两年一道，这已经算考得非常多的了。**广东同学一定要重点掌握。**

其他一些地方零星出现过：

- 江西 2018 年以前出过，2018 年以后加入了联考、跟着联考卷子走，也就没再出现过了；
- 江苏 2018 年以前出现过，最近这五六年也没有出现过了；
- 四川一般上半年、下半年各一场考试，每两次考试中间大概会有一道题；
- 山东、辽宁、上海可能偶尔出一道。

整体考评都不多，但我们还是系统学一遍——不为考频，为的是真上了考场不至于两眼一抹黑。

### 一个"回家过年"的模型

集合推理，故名思意就是跟集合有关系。我们先搭一个模型出来：我们班是一个集合，集合里有很多元素。

现在我说一句：**所有的同学都回家过年了。** 这句话能推出什么？

第一，所有前推后，这是百分之百的。"所有A都是B"直接就是"A推B"，我们在翻译推理最开始就讲过。班级所有同学都回家过年了，那就是同学推出回家过年。

第二，所有可以推某一个。我们班有30个人，我假设里面有张三。张三回家过年了吗？肯定对——所有人都回家了，那张三当然回家了。**所有都可以推某一个，这没有问题。**

第三，所有可以推有的。张三都回家了，我能不能说"有的同学回家过年了"？没问题。

所以"所有"这一句话，其实把这三种情况一次性给全了：某一个人成立、"有的"成立、"所有"本身也成立。这是第一个概念，简单说一下。

### "有的"到底覆盖多大范围

接下来是集合推理里最重要的那个词：**有的。**

我一说"有的同学回家过年了"，它到底包含哪些？它包含三种情况：

- 一个人回家过年了——可以叫做"有的同学回家过年了"；
- 一部分人回家过年了——也可以这么叫；
- 全班所有人都回家过年了——同样可以这么叫。

三种情况，你都可以用"有的同学回家过年了"这句话去说。这一点必须先钉死，后面所有的坑都是从这里挖出来的。

### 推不出来的，一律记成误区

#### 有的A是B，推不出有的A不是B

我问大家一个问题：**所有的同学都回家过年了，能不能推出"有的同学没回家过年"？**

能不能推？不能。

为什么不能？还是回到刚才那三种情况去分类讨论：如果真的出现的是"全部人都回家过年了"这种情况，那么在这种情况之下，"有的同学没回家过年"就推不出来。

这就是第一大误区：**有的A是B，推不出"有的A不是B"**。画个重点，这是一定要记的。

那再问一个更接地气的：**"有的男生是靓仔"，能不能推出"有的男生掉毛"？**

一定不能。还是分类讨论：如果所有男生都是靓仔——这完全可能嘛——那在这种情况下，"有的男生掉毛了"就推不出来。

这个地方特别要小心，因为**很多同学很容易被生活常识干扰**。

我们之前讲翻译推理，一直在说一件事：翻译推理最核心的东西就是翻译，你一定是把它翻译出来，然后去做题。千万不要把自己的常识绕进去，**千万不要烧脑，你一烧脑，大概率就做错了。**

你脑子里想的是"这帮人这么老多，肯定有掉毛的吧"——那是你的生活常识。生活常识不能用在推理里。这是逻辑，一定要拎清楚。

> **易错点**：有的A是B → 推不出 → 有的A不是B。记住这一条就够。
>
> **提示**：反过来也一样，"有的"推不出"所有"——这个坑我们后面环保那道题里会亲眼看到。

#### 有的A是B，不能逆否

第二大误区：**有的A是B，完全不能够进行逆否。**

只有"所有"才行。我们说所有A都是B，所有A百分之百属于B，在这种情况下可以逆否：否B推否A，这是没问题的。

但是一变成"有的"，就完全没办法逆否了。为什么？

"所有A是B"是绝对性的，肯定可以推出"所有A都是B"，百分之百。但"有的A是B"呢？它是"其中有的A是B"——这句话是不是变了味儿了？它讲的是**可能**是二，只是一部分是一、又是二，不再是全集合都是二了。那你这时候再反着推怎么推？你本身就是一个可能性，我拿一个可能性去逆否，推不动。

> **结论**：只有"所有"能逆否，"有的"绝对不能逆否。

这个"有的不能逆否"其实也可以用集合的理念去证明，但证明相对来说稍微复杂一点，而且证明完了对我们整体的理解也没有太大帮助，反而徒增一些记忆负担，所以我们就不证了。感兴趣的同学可以去网上搜一搜。

在这个小点里，大家只需要记住一点：**它不能进行逆否。** 请把它记住，这就是我们的第二大误区。

### 有的怎么串，串到哪儿为止

#### 有的A是B，等价于有的B是A

这是核心考点。

我打个比方：拿"公务员"这个集合来说——两个集合中间是不是一定是有交集的？一定是。也就是说，一定会存在着一个人或者一部分人，他既是公务员，又是另外那个身份。

如果这句话是对的，那我反过来说，是不是也没有问题？因为一定存在着一个或者几个人。既是这样，那我正着说、反着说，这两句话都没有任何毛病，是没有毛病的。

道理就在这里：**A和B这两个集合中间一定是有交集的，也就是一定存在着既是一又是二的人**，所以你反过来说"有的B是A"也是没有任何问题的。

换成你更熟悉的说法：**有的博士是教授，等价于有的教授是博士。** 这跟类比推理里的交叉关系完全一致——博士和教授这两个集合是有交叉的。正着说、反着说都没问题，因为一定存在着有的人，他既是博士又是教授，所以你反过来说"有的教授是博士"也是没有问题的。

> **结论**：有的A是B 等价于 有的B是A。这是最核心的考点，请牢牢记住。

#### 所有A是B，可以推出有的B是A

我把这个结论再往下搭一层。

我说"所有的警察都是公务员"，那么能不能推出"有的警察是公务员"？没问题吧？所有都可以推有的。也就是所有的A是B可以推出有的A是B。

那"有的警察是公务员"，又等价于"有的公务员是警察"。所以这两条之间是不是又建立起了一个联系？

一层一层搭下来：**所有的警察是公务员 → 有的警察是公务员 → 有的公务员是警察。** 没有问题吧？这是我们一步步下来的，所以所有A是B可以推出有的B是A。

#### 递推串联时，"有的"只能站在起点

第五个考点，这个最容易被忽略。

"所有"可以翻译成一推二。如果一推二、二推三，我们是不是可以等价于一推三？中间这个直接把它连接起来就好。翻译推理最开始已经讲过一推二、二推三等价于一推三，这个是没有问题的。

但中间插入一个"有的"，情况就变了。

我们分两种情况看。

**"所有A是B" 后面接 "有的B是C"——串不通。**

"所有A是B"，所有A百分之百都是二，这没问题。然后来一个"有的B是C"——这个"有的"就不是百分之百了对吧？它可能是 0.01%，一直到 99.99%，它就是一部分了；可能是 50%、60%，我随便说一个数。所以这里变成了"有的B是C"，而不是"所有B都是C"了。既然不是所有B都是C，那所有的B都是C这个前提就不成立。到这个地方就没办法把它串起来了，A就推不出C。

因为所有A都是B，但只有"有的B"才能是三，一和三中间连不通了。

**"有的A是B" 后面接 "所有B是C"——串得通。**

"有的A是B"，可能有一部分A是B。然后"所有B都是C"——这个地方是一个百分之百，所有B都可以进到三里，所以B跟三是可以连起来的。于是"有的A"就可以推到"有的C"，也就是有的A是C。

```text
串得上：
  所有A是B  +  所有B是C  ->  A推C
  有的A是B  +  所有B是C  ->  有的A推C

串不上：
  所有A是B  +  有的B是C  ->  A推不出C
```

> **结论**：有的在做推理的时候，只能作为递推的一个起点。放在前面可以连，放在中间连不通。

### 考点收口

这五条就是我们关于集合推理最核心的考点，搞定了，集合推理就没有再难的了。我们再整体说一遍：

- 第一大误区：有的A是B，推不出有的A不是B。
- 第二大误区：有的A是B 不能够进行逆否——记住，它不能逆否。
- 核心考点：交叉理论，有的A是B 等价于 有的B是A。
- 所有A是B 可以推出有的A是B；再借等价，又能推出有的B是A。
- 递推推理时，"有的"只能作为推理的一个起点。

以上就是关于集合的所有重要知识点。下面我们一起做几道例题，看怎么把这些知识点运用起来。

### 例题：把规则一条条用起来

#### 十多年来国考唯一的那道

这道题是这十多年来国考出的这一道，就这一道。

拿过来第一步肯定是翻译了。三个条件我读一遍：

- 30岁以下的，有一部分报名参加了外语培训班 → 有的30岁以下 → 外语培训；
- 该公司的部门经理一致同意在周末进行野外的拓展 → "一致同意"就是所有 → 所有部门经理 → 拓展；
- 所有报名外语培训的，都反对拓展 → 所有外语培训 → 否拓展。

三个翻译推理我都写出来了。那我第一个想法是什么？一定是看一看这三个能不能把它们串起来。

串：外语培训 → 否拓展；拓展 → 部门经理，所以否拓展 → 否部门经理。**三个"所有"全串起来了**，串起来就是这个样子。

当所有都串起来之后，这个时候我们第一个想法要看什么？看**出题人会不会是想让我们把这所有的条件都利用起来**，来进行出这个答案。这很大概率是吧。

那如果将所有的知识点都利用起来，你能推出什么来？你能推出：**有的30岁以下的员工不是部门经理。** 看一看有没有这个答案——正好有，是第四个。那答案选第四个就走了。另外三个肯定是推不出来的，既然推不出来，我们就不需要去看了，因为只有一个正确答案。

所以解这类题的第一个重要思路是：**翻译完之后先看能不能串；能串，就把所有条件都利用起来，看能推出什么，然后去选项里找这个答案，找到了直接走人。**

> **注意**：如果这个题没有第四个选项呢？那你再从第一个到第二个一个个来看。如果直接有了，那你直接选完就走了。

#### 联考那仅有的一道"独苗"

这是联考这么多年来仅有的一道独苗。

先翻译：

- 行驶超过60的应当报废 → 所有行驶超60 → 应当报废；
- 有些超60的存在设计缺陷 → 有的行驶超60 → 设计缺陷；
- 在应当报废的汽车中，有的不是T品牌 → 有的应当报废 → 否T品牌；
- 所有T品牌都不存在设计缺陷 → 所有T品牌 → 否缺陷。

翻译完之后第一个想法：看能不能串起来。设计缺陷跟第四条串起来，否后推否前 → 否T品牌，所以推得"有的行驶超60的汽车不是T品牌"。选项里好像没有这个答案。暂时没有更多能连的了，那就一个个看。

A和B说"有的T品牌应当报废"。我们只能推出"有的应当报废的不是T品牌"。那它能推出A和B吗？推不出来。"有的A是B"等价于"有的B是A"，它只能等价于"有的不是T品牌的应当报废"。**我只能推出"有的不是T品牌怎么样"，推不出"有的T品牌怎么样"。** A和B两个都排除掉。

> **易错点**：A和B犯的正是第一大误区。有的报废汽车推出"不是T品牌"，是推不出"是T品牌"的。

C说"报废的汽车都应该行驶超过60"，也就是报废推行驶超60。前推后可以，但后推前是推不出来的，所以C错。

那就只剩第四个。第四个说"有的存在设计缺陷的应当报废"：它先等价于"有的有设计缺陷的是行驶超过60的"；再往下，行驶超60的都应当报废，这是"所有"，可以串。于是推出"有的存在设计缺陷的应当报废"。**答案选第四个。**

> **提示**：这类题你把上面那五条重点往里带就可以了。

#### "并非所有的博士……"

先翻译三句：

- 有多名干部是博士 → 有的干部是博士；
- 并非所有的博士都是统计专业毕业的 → 有的博士 → 否统计学专业；
- 所有的男性都是统计学专业的 → 所有男性 → 统计学专业。

第二句翻译可能要多想一会儿。给点时间让你去理解，你大概也能反应过来：**"并非所有的博士都是统计专业毕业的"，核心意思就是——有的博士不是统计学专业毕业的。** "并非"是否定，"所有"的否定是什么？所有式的矛盾就是"有的不是"。

大家有没有想到我们上一节课所学的真假推理？所有式的矛盾是什么？——"所有A是B"的矛盾是"有的A不是B"。翻译过来就是：有的博士不是统计学专业毕业的。这不就是真假推理吗？所有式的一个矛盾。

那后面是不是又是"所有"了？所有的男性都是统计学专业的。

这个能不能连起来？能。否后推否前：否统计学专业 → 否男性。而"有的博士不是统计学专业"接上来，就推出——**有的博士不是男性。** 选项里有，答案选第二个，直接走人。

### 六边形：把"所有"与"有的"和真假推理合成一张网

上节课我们学了真假推理，这节课又学了集合推理。那我们把真假推理和集合推理里**所有涉及"所有"跟"有的"之间的关系**——无论是矛盾关系还是推出关系——用这样一副六边形统一地合在一起，给大家再去梳理一遍，有利于大家的记忆。

```text
           ┌──────────────┐
           │   所有A是B   │
           └──────────────┘
┌──────────────┐      ┌──────────────┐
│   某个A是B   │      │  所有A不是B  │
└──────────────┘      └──────────────┘
┌──────────────┐      ┌──────────────┐
│   有的A是B   │      │  有的A不是B  │
└──────────────┘      └──────────────┘
           ┌──────────────┐
           │  某个A不是B  │
           └──────────────┘
```

读图：最上面是"所有"，最下面是"某个"，中间左右两列是"有的"；左半边全是"是"，右半边全是"不是"。

**第一层关系：从上到下是推出关系。**

如果说所有的A都是B——我们班级里所有人都回家了——那么能推出某一个A是B吗？没有问题。某个同学回家了，是不是一定能够推出我们班有的人回家了，也就是有的A是B？可以的。

右边从上到下同理：如果所有A都不是B——我们班所有人都没回家——那我一定能推出班级里的某个人不是B；既然某个人没有回家，是不是可以推出有的人没有回家？也是可以的。

所以从上到下是一个推出关系。

**第二层关系：对角线是矛盾关系。**

我们换一支颜色的笔，看这个六边形的对角线：

| 对角线配对 | 关系 | 结论 |
| --- | --- | --- |
| 所有A是B | 有的A不是B | 矛盾关系，必一真一假 |
| 所有A不是B | 有的A是B | 矛盾关系，必一真一假 |
| 某个A是B | 某个A不是B | 矛盾关系，必一真一假 |

"所有A是B"的矛盾是"有的A不是B"；"所有A不是B"的矛盾是"有的A是B"；"某个同学回家了"和"某个同学没回家"，他俩之间一定是矛盾关系。

**第三层关系：上下两组是对立关系。**

"所有A是B"和"所有A不是B"不可能同时为真，**所有所有必有一假**；又因为它们都在上面，所以我们叫它**上反对**。

"有的A是B"和"有的A不是B"不可能同时为假，**有得有得必有一真**；因为它们在下面，我们叫它**下反对**。

> **结论**：从上到下是推出关系，对角线是矛盾关系，上面是上反对，下面是下反对。总的来说三组矛盾、两个反对，这六个关系既包含了我们真假推理的，也包含了集合推理的。

拿到真假推理，我们第一步是先去找矛盾；如果没有矛盾，我们再去找反对关系。这张图里的关系一定要搞定，最好是理解性地去记，而不是死背。

### 继续做题：等价、逆否与选项陷阱

#### 选手喝茶：红茶还是绿茶

翻译题干：有的选手比赛时喝茶；喝茶的人要么喝红茶，要么喝绿茶。

**第一个选项**：一名比赛时不喝红茶的选手，一定喝绿茶。这是一定错误的。因为不喝红茶的选手，还有可能根本不喝茶呢——他有可能不喝茶，不是一定喝绿茶。

**第二个选项**：该围棋队没有选手比赛时喝黑茶。这个是对的。因为有的选手是喝茶的；如果他喝茶了，他一定在红茶跟绿茶里选，没人喝黑茶。也就是这个选手要么他是不喝茶的，如果喝茶的话，他一定在红茶跟绿茶里选。

**第三个选项**：有的选手比赛时不喝茶。这个是推不出来的——有的A是B推不出有的A不是B，第一大误区。

综合一下，答案只有第二个能推出来。

#### 懂法语和懂英语：问的是"不能推出"

翻译：有的懂英语的人不懂法语 → 有的英语 → 否法语；所有懂法语的人都懂英语 → 法语 → 英语。

注意，这道题问的是**不能**推出的。

先做等价：有的英语 → 否法语，等价于有的否法语 → 英语，也就是"有的不懂法语的人懂英语"——第四个，能推出来。

第二个怎么推？"所有懂法语都懂英语"是不是能推出"有的懂法语的是懂英语"？能。然后做一个替换——有的A是B等于有的B是A——就替换成"有的懂英语的是懂法语"，也就是"有些懂英语的人也懂法语"。所以A也是对的。通过题干我们能推出A和第四个。

剩下这两个：有些懂法语的人不懂英语、有些懂法语的人懂英语。

"有些懂法语的人不懂英语"是推不出来的，这就是第一大误区。但更根本的原因是：它其实是题干那句话"所有懂法语的人都懂英语"的**矛盾命题**——所有式的矛盾是"有的不是"。既然它跟题干完全是一个矛盾命题，那第二个肯定是错的。

C说"没有一个懂法语的人不懂英语"，翻译过来就是"所有的懂法语的人都是懂英语的"，这跟题干里那句话是一回事，所以C也能推导出来。

**答案选第二个。**

#### 环保主义者：别把"反对减少"当成"支持加大"

翻译：

- 有一些环保主义者是热爱旅游的 → 有的环保主义者 → 热爱旅游；
- 所有的环保企业代表都是支持减少风景区开发的 → 环保企业代表 → 减少风景区开发；
- 所有热爱旅游的都反对减少风景区开发 → 热爱旅游 → 否减少风景区开发。

翻译完之后，第一个看能不能串。第一句话可以串：有的环保主义者 → 热爱旅游 → 否减少风景区开发。第二句话也可以串：环保企业代表 → 减少风景区开发，否后推否前 → 否热爱旅游。

先看第一句话能推出什么：有的环保主义者是反对减少风景区开发的。而第四个选项说"有的环保主义者是**支持**减少风景区开发的"，这就错了，跟它不一样。我们只能推出"有的"推"否减少"，推不出"减少"。**所以第四个错。**

第二个能不能推出"环保企业代表推否旅游"？那不正好看好就是第二句话吗——所有环保企业代表都不热爱旅游。**所以答案选第二个就走了。**

另外几个重点说一下，因为有些同学容易想错。

**第三个**说"有些热爱旅游的支持加大风景区开发"。通过第三句我们能推出什么？所有热爱旅游的可以推"有的热爱旅游的是反对减少风景区开发"。那么——**反对减少风景区开发，等于支持加大吗？**

不等于。他俩不能划等号。我反对你减少，这里面的意思可能是：哎，你可以加大；也可以保持不变啊。所以反对减少并不等于支持加大。**第三个是错的，有个别同学千万不要陷入在这个选项里。**

**A选项**说"所有的环保主义者都是反对风景区开发的"。我们刚才推导完了，只能说"有的环保主义者是反对减少风景区开发的"。题干中我们只能说"有的"，但是**有的推不了所有的**，所以A错在这里。

#### 问"一定是假的"的那道题

这个题稍微上了一点难度，因为它问的是"哪个说法**一定是假的**"。注意他的问法，这个题很有意思。大家自己做一下。

答案：D（第四项），有的30岁以下的员工不是部门经理。

解析：三个条件全是"所有"，可以全串成 `外语培训 → 否拓展 → 否部门经理`；由"所有"可推"有的"，得"有的30岁以下是外语培训"，再顺链推到"有的30岁以下不是部门经理"。其余三项推不出。

**第二题（联考独苗）**

题干：行驶超过60的应当报废；有些超60的存在设计缺陷；在应当报废的汽车中，有的不是T品牌；所有T品牌都不存在设计缺陷。问：由此可以推出？

答案：D（第四项），有的存在设计缺陷的应当报废。

解析：第二句与第四句用否后推否前串起来得"有的行驶超60不是T品牌"（选项中无此项）；"有的行驶超60是设计缺陷"与"所有行驶超60应当报废"可串，得"有的存在设计缺陷的是行驶超过60的"，再串"所有行驶超60→应当报废"，即得答案。A、B 犯"有的推不出否"，C 犯"前推后不能反推"。

**第三题**

题干：有多名干部是博士；并非所有的博士都是统计专业毕业的；所有的男性都是统计学专业的。

答案：B（第二项），有的博士不是男性。

解析："并非所有A是B"即"有的A不是B"，得"有的博士不是统计学专业"；第三句"所有男性→统计学专业"否后推否前得"否统计学专业→否男性"，两段串起来即得"有的博士不是男性"。

**第四题**

题干：有的选手比赛时喝茶，喝茶的人要么喝红茶，要么喝绿茶。问：下列哪项正确？

答案：B（第二项），该围棋队没有选手比赛时喝黑茶。

解析：不喝红茶的人可能根本不喝茶，第一项错；喝茶者只在红茶、绿茶中选，"不喝黑茶"成立；"有的喝茶"推不出"有的不喝茶"，第三项犯第一大误区。

**第五题**

题干：有的懂英语的人不懂法语；所有懂法语的人都懂英语。问：下列哪项**不能**推出？

答案：B（第二项），有些懂法语的人不懂英语。

解析：该选项是"所有懂法语都懂英语"的矛盾命题，必然错；A 由"所有法语→英语"推得"有的法语是英语"再等价换位得到；C"没有一个懂法语的人不懂英语"即原句"所有懂法语都懂英语"；第四项由原第一句直接换位得到。

**第六题**

题干：有一些环保主义者是热爱旅游的；所有的环保企业代表都支持减少风景区开发；所有热爱旅游的（人）都反对减少风景区开发。问：由此可以推出？

答案：B（第二项），所有环保企业代表都不热爱旅游。

解析：第二句与第三句在"减少风景区开发"上取否，用否后推否前串得"环保企业代表 → 否热爱旅游"。第四项把"否减少"说成"减少"，A 把"有的"说成"所有"，C 把"反对减少"等同于"支持加大"，三者均错。

## 集合推理收官：把"有的"串成一条链
> 对应块：BLK51 | 覆盖分集：P25下 | 块标题（分集名）：《第十六节（结束）——集合推理——刘文超》

集合推理到这儿就算讲完了。这些年能考的题就那么些，最近出的我几乎都拿上来了——从第七题一路做到第十五题，一道一道过。做完你会发现，这类题真不难，我们所有的题目都在绕着同样几个点打转，把这几个点想明白就行了。

开练之前先把最容易翻车的一条钉在这儿：**"不确定"不是"为假"，"不确定"就是有可能。** 题目问"一定为假"的时候，你得先把这个弯转过来——要找的恰恰不是那个"一定为真"的选项，而是那个"百分之百错"的选项。

### 一条证书链串到底

第七题的题干翻译成逻辑语言其实很短：

- 所有法学专业的学生都获得了法律资格证 → 法学学生 → 法律资格证
- 获得法律资格证的人又都获得了教师资格证 → 法律资格证 → 教师资格证
- 有的法学专业的学生成了公务员 → 有的法学学生 是 公务员
- 有的逻辑学专业的学生也成了公务员 → 有的逻辑学生 是 公务员
- 所有逻辑学专业的学生都未获得教师资格证 → 逻辑学生 → 否教师资格证

两个"所有"都是前推后。两个"有的"都要换位置——"有的法学学生是公务员"和"有的公务员是法学学生"完全等价，"有的逻辑学生是公务员"和"有的公务员是逻辑学生"也完全等价。等价是双向的，这一点后面还会反复用到。

然后串链。法学生推法律资格证，法律资格证推教师资格证，所以教师资格证摆在这。那它还能往哪推？看最后那句：所有获得教师资格证的，都不是逻辑学专业毕业的。这就是否后推否前。

```text
链条一（从法学学生出发）
  法学学生 ──→ 法律资格证 ──→ 教师资格证 ──→ 否逻辑学学生

链条二（从逻辑学学生出发）
  逻辑学学生 ──→ 否教师资格证 ──→ 否法律资格证
```

两条链的末环都是"否后推否前"在干活。

现在看选项。第一个选项说：有一个人获得了教师资格证，并且他并非逻辑学专业的。这百分之百正确，因为教师资格证直接就推否逻辑学学生。第二个选项说：有个公务员既没有法律资格证，又不是逻辑学专业的。可能吗？可能。题干只给了"有的公务员有法律资格证""有的公务员是逻辑学专业的"，我否定不了它，所以它是有可能的。第三个选项说：有法律资格证的人并非是法学专业的。这是把第一条的后推前拿来用——后推前是不确定，不确定就是有可能。第四个选项说：有个人是逻辑学专业的，同时获得了法律资格证。百分之百错误，因为逻辑学专业的学生一律没有法律资格证，这跟题干正面撞上了。

> **结论**：题干问的是"一定为假"。A 一定为真，B 有可能，C 不确定（有可能），只有第四个百分之百错。答案是第四个。

> **易错点**：问"一定为假"的时候，别下意识地去挑"最像题干"的选项。先给每个选项定性——必然为真、有可能、必然为假——再从里面挑那个必然为假的。

### 80 小时和 60 小时的两道坎

第八题讲的是创新学分，翻译如下：

- 参加社会服务表现积极，可以获得创新学分 → 社会服务表现积极 → 创新学分
- 参加学术活动，也可以获得创新学分 → 学术活动 → 创新学分
- 所有机电工程专业的学生都参与了学术活动 → 机电学生 → 学术活动
- 大多数机电学生参加社会服务的时间超过 80 小时 → 有的机电学生 服务超 80 小时
- 其余的学生参加社会服务的时间均不足 60 小时 → 有的机电学生 服务不足 60 小时
- 服务时长达到 60 小时以上，被认为表现积极，同时可以拿到优秀实践奖 → 服务超 60 → 表现积极 ∧ 优秀实践奖

"大多数""其余"翻译成"有的"。因为考试里的"大多数"从来不等于全体，它至少保证存在——这就已经够你推理了。

串链：

```text
  机电学生 ──→ 学术活动 ───────────→ 创新学分
      │
      └──→（大多数）服务超 80
                └──→ 服务超 60 ──┬──→ 表现积极
                                  └──→ 优秀实践奖
```

第一个选项说：所有参与学术活动的机电学生都参加了社会服务。这句话听着特别像题干，其实一点都不特殊——所有机电学生都参与学术活动了，所以"参与学术活动的机电学生"就是所有机电学生。那所有机电学生都参加社会服务吗？不知道。题干只说大多数超 80 小时、其余不足 60 小时。

> **易错点**："不足 60 小时"完全可能就是 0。有的学生服务时长就是 0，0 小时等于压根没参加社会服务。所以"都参加了社会服务"推不出来。第一个选项就错在这儿。

第二个选项扯到"与其他专业学生相比"，题干里根本没提其他专业，不用推。第三个选项说：有的获得优秀实践奖的机电学生获得了创新学分。怎么串？大多数机电学生服务超 80 小时，超 80 就一定超 60，超 60 就一定表现积极、一定拿奖；而所有机电学生都参与学术活动，参与学术就能拿创新学分。两条线在"机电学生"这个点上接上了，C 成立，答案就是 C。

第四个选项翻译过来是："除非参加社会服务时长达到 60 小时以上，否则没有其他途径可以获得优秀实践奖。""除非……否则不"要翻成后推前，即 优秀实践奖 → 服务超 60。而题干第五句说的是 服务超 60 → 表现积极 ∧ 优秀实践奖，正好是它的反面。后推前推不出来，所以第四个错。

> **提示**："除非 A，否则不 B"这个句式，永远翻成 $B \to A$，也就是后推前。它是后推前里最值钱的一种：只要题干里有一句方向相反的"前推后"跟它对着干，这个选项就一定错。这类句式在真题里出现频率极高，看到它心里先咯噔一下。

### 能串起来，却用不上

第九题是道江西的题，两句话：

- 所有刑侦专业的大四毕业生，毕业以后都当了警察 → 刑侦毕业生 → 警察
- 刑侦专业的大四在校生（还没毕业呢）都不是警察 → 刑侦大四在校生 → 否警察

都是"所有"，前推后。串是能串上的：否后推否前，从"否警察"推出"否刑侦专业的大四在校生"，也就是"刑侦专业的毕业生不是刑侦专业的大四在校生"。

但你看看这话像什么话。刑侦专业的毕业生，那肯定不是刑侦专业的大四在校生啊——这不废话吗，也不是什么考点。所以它虽然能串起来，但没有用。

> **提示**：能串起来 ≠ 有用。串完之后一定要拿结论读一遍，凡是读出来像常识废话的，说明这条链根本不是这道题要的，直接放弃它去找别的。

选项全是带"有的"的，说明这道题跟"有的"有关系。"有的 A 是 B"等价于"有的 B 是 A"，三句都拿过来一看，答案直接就跳出来了。答案选第二个。

### "必须做到"的否定，不等于"一定不能做到"

第十一题翻译过来是：领导干部首先要做到某一件事；干部要带头不做某一件事。两句都是"凡是……都……"式的"所有"，前推后。

A、B 两个选项，分别是第一句和第二句的后推前——后推前都不确定，直接排除，很好排。C 选项说的是"领导干部要首先做到这件事"，跟第一句原话是一个意思。"所有"能推出"有的"，"有的 A 是 B"又等价于"有的 B 是 A"，一换位就是"有的领导干部做到了这件事"，正是 C。所以 C 一步推出来，答案选 C。

D 选项要单独拎出来说，因为很多同学在这儿会栽跟头。D 说的是第一句话的否定，那它等价于"一定不能做到"吗？绝不等价。我们把"必须做的"这个范围画出来看：

```text
   必须做的         也可能必须做的      一定不能做的       也可能一定不能做的
  ┌──────────┬──────────────────┬──────────────┬────────────────────┐
  │  必须做  │     也可能必须做  │   一定不能做  │   也可能一定不能做 │
  └──────────┴──────────────────┴──────────────┴────────────────────┘
                  ↑ 中间这一大片，就是"不确定"的疆域
```

"可能必须做"和"可能一定不能做"这两片区域之间是矛盾关系，但"必须做"和"一定不能做"之间不是矛盾关系，中间还夹着整整两片地带。所以否掉"必须做"，只能落到右边这一大片模糊地带里，推不出正中间那个"一定不能做"。

> **易错点**：D 的依据要去第一句话里找，别跑到第二句话里找。这两句话说的根本不是同一件事，翻译成逻辑语言是两个独立的条件，谁也否定不了谁。

> **结论**："否前"推不出任何东西。翻译出来是"否前"的选项，一律排除。

### 同一道题换个省还在考

第十二题我摆了两道题在这儿，一道是 2019 年四四川省下半年，另一道是 2023 年广东省。刚才两道题刚做完没两分钟，我就把它们放在一起，是想跟大家说一件事。

大家平时刷题，别总盯着自己省那些题。等你把自己省的刷完了，国考、联考、各省单独命题的行测申论，本质上没有什么区别，你都要去刷。现在考公的竞争压力越来越大，题量真的得非常铺开，甚至想把所有的题库都刷穿。拘泥于本省那几道题，很多时候多刷别的省的题，对你更有帮助。你看这两道，广东省那道就是从上一道完完全全扒下来的，答案设计都一模一样。

那就翻译。12 个人里有 3 个干部是博士，这就是"有的干部是博士"；题干说"并非所有干部都是博士"，而"所有"的否定就是"有的不是"，所以是"有的干部不是博士"，也就是有的干部不是管理学专业的；所有女性都是管理学专业的 → 女性 → 管理学。串起来：否管理学 →（否后推否前）→ 否女性，跟"有的干部是博士"接上，得到"有的干部不是女性"。跟上一道题的答案结构一模一样，完全就是一个题。

### 川籍工作人员不是管理人员

第十三题是道四川题：

- 管理人员都具有博士学位 → 管理人员 → 博士
- 大部分川籍工作人员不超过 30 周岁 → 有的川籍 → 不超过 30
- 少部分川籍工作人员没有博士学位 → 有的川籍 → 否博士

"少部分"也是"有的"。串链：否博士 →（否后推否前）→ 否管理人员，跟"有的川籍"接上，得到"有的川籍工作人员不是管理人员"。选项里有，答案选第四个，走人。

### 缺的不是常识，是自律

第十四题是江苏题。题干的核心就一句：有的人不缺少健康常识，却缺乏自律精神。

就这一句，翻译过来是"有的人否健康常识 ∧ 否自律"。而"有的 A 是 B"等价于"有的 B 是 A"——A 是"不缺少健康常识"，B 是"缺乏自律精神"，换过来就是"有的缺乏自律精神的人不缺少健康常识"。答案直接选第二个。

> **结论**："有的 A 是 B" ≡ "有的 B 是 A"。它的核心考点就这一个，而且永远不要去跟我玩逆否——"有的"是不能逆否的。

题干后面还有一长串，也都是前推后：有自律精神的人都会早睡、都会坚持运动；有自律精神的人不会放纵自己，能够维持自己的生理节律、保持健康幸福。这些链条基本没派上用场，因为选项一个都不走它们。

看看其他三个是怎么错的。A 选项把"运动"和"自律"的关系反了——题干是"自律 → 坚持运动"，A 写成了"运动 → 自律"，后推前，推不了。C 选项是"否自律"，无论挂在第二句还是第三句上，它都是否前，不确定，也不成立。第四个选项把"生理节律"和"健康生活"摆在一起，问的是这两者之间有没有推导关系——可它们在题干里只是同一条链上并列的两个结论，谁也推不出谁。所以答案只能是第二个。

### 驴友协会不同意，技术骨干就出局

第十五题，最后一道：

- 部分员工还成立了一个驴友协会 → 有的员工 是 驴友协会
- 驴友协会中的一些人是技术骨干 → 有的驴友协会的人 是 技术骨干
- 企业的管理层所有人员都同意把钱挪作他用 → 管理层 → 同意
- 驴友协会的成员都不同意 → 驴友协会 → 否同意

先串：驴友协会 → 否同意 →（否后推否前）→ 否管理层。所以能推出"有的员工不是管理层"。但这话没啥意义——员工本来就有的是不是管理层的。

一看选项，全跟技术骨干有关，那这道题一定挂在第二句上。第二句"有的 A 是 B"等价于"有的 B 是 A"，把技术骨干换到前面：有的技术骨干是驴友协会的。驴友协会能推什么？推否同意，否同意再推否管理层。于是"有的技术骨干不是管理人员"出来了，选项里有，答案选 A。结束战斗。

### 这类题，绕不开的就是这几个点

十五道题做下来，你会发现这种题其实是不难的，所有题目都在绕着同样几个点转，把这几个点想明白就行了。

**第一大误区**："有的一是二"推不出"有的一不是二"。

**第二大误区**：以为"有的"可以做逆否。别跟我玩逆否这一套，"有的"是不能逆否的。

**核心考点**："有的 A 是 B"等价于"有的 B 是 A"。你一遇到"有的"，先把这个等价式在脑子里默写一遍。

**桥接规则**：如果一道题里全是"所有"、一个"有的"都没有，其实照样能通过"所有"推出"有的"——"所有 A 是 B"可以推出"有的 A 是 B"，再等价成"有的 B 是 A"。所以"所有 A 是 B"是能推出"有的 B 是 A"的，这条链是通的。

**第五条**："有的"只能作为推理的起点。"有的"一进来就说明这个人已经存在了，接下来全靠"所有"跟它接。所以看到"有的"，先别急着在它自己身上推，看看它能挂上哪条链。

这五条想明白了，我们做下来的很多题其实都是翻译完直接就做掉了，甚至有些直接秒掉。

定一个复习节奏给你：今天听完，你现在多半还处在模棱两可的状态，这很正常。明天自己把这十五道题重做一遍，过一个星期再做一遍，再过一个月回头再做一遍，每次都要加上自己的思考、自己动脑。到那个时候，你对这类题型就完全融会贯通了。

这类题型是很简单的，不是什么难题，千万不要把它想难了。

### 本讲提到的题目

- **第七题**。题干：所有法学专业学生都获得法律资格证；获得法律资格证者都获得教师资格证；有的法学专业学生成了公务员；有的逻辑学专业学生也成了公务员；所有逻辑学专业学生都未获得教师资格证。**答案：第四个**。解析见「一条证书链串到底」——A 由"教师资格证 → 否逻辑学学生"必然为真；B、C 只是"有可能"；D"逻辑学生有法律资格证"与"逻辑学生 → 否教师资格证 → 否法律资格证"正面矛盾，百分之百为假。
- **第八题**。题干：社会服务表现积极可获创新学分；参加学术活动也可获创新学分；所有机电工程专业学生都参与学术活动；大多数机电学生服务超 80 小时；其余服务不足 60 小时；服务超 60 小时即为表现积极并可获优秀实践奖。**答案：C**。解析见「80 小时和 60 小时的两道坎」——A 因"不足 60 可能为 0"而推不出；D 翻成"奖 → 超 60"的后推前，与题干反向。
- **第九题**（江西）。题干：所有刑侦专业大四毕业生毕业后都当警察；刑侦专业大四在校生都不是警察。**答案：第二个**。解析见「能串起来，却用不上」——"刑侦毕业生 → 否刑侦大四在校生"是常识废话，题目只能挂在"有的"的等价换位上。
- **第十题**。题干：有的新入职员工拥有海外留学经历；所有有海外留学经历者都被董事长单独接见过；所有甲省员工都没有被董事长单独接见过。**答案：第四个**。解析：海外经历 → 董事长 →（否后推否前）否甲省，接"有的新入职员工有海外经历"，得"有的新入职员工不是甲省的"。
- **第十一题**。题干两句均为"所有"结构：领导干部首先要做到……；……干部要带头不做……。**答案：C**。解析见「"必须做到"的否定，不等于"一定不能做到」」——A、B 是后推前，D 是否前（且"必须做"与"一定不能做"不是矛盾关系），只有 C 能由"所有 → 有的 → 等价换位"直接推得。
- **第十二题**（2019 四四川省下半年与 2023 广东省同型题）。题干：12 人中有 3 名干部是博士；并非所有干部都是博士；所有女性都是管理学专业。**答案：与上一题相同**，即"有的干部不是女性"。解析：否管理学 →（否后推否前）否女性。
- **第十三题**（四川）。题干：管理人员都具有博士学位；大部分川籍工作人员不超过 30 周岁；少部分川籍工作人员没有博士学位。**答案：第四个**，即"有的川籍工作人员不是管理人员"。
- **第十四题**（江苏）。题干：有的人不缺少健康常识，却缺乏自律精神；自律者都会早睡、坚持运动；有自律精神者不会放纵自己，能维持生理节律、保持健康幸福。**答案：第二个**，即"有的缺乏自律精神的人不缺少健康常识"。
- **第十五题**。题干：部分员工成立了驴友协会；驴友协会中一些人是技术骨干；企业管理层所有人员同意把钱挪作他用；驴友协会成员都不同意。**答案：A**，即"有的技术骨干不是管理人员"。
