## 逻辑判断入门与翻译推理：把每句话先翻译成箭头
> 对应块：BLK36 | 覆盖分集：P19上 | 块标题（分集名）：《第十节——逻辑判断——翻译推理——刘文超》

判断推理讲到现在，我们进第四章——逻辑判断。

一听到"逻辑"两个字，很多同学就有点发怵，觉得这是判断推理里最难的一块。我不这么看。我觉得整个判断推理里最难的是图推，逻辑判断其实比图推好做，而且做题的时间要更短一些。逻辑这一块，技巧性其实是相对更强的。

至于大家为什么会觉得它难——是因为它背后确实挂着一门正经的学科，叫逻辑学，大学里还有专门研究这个的专业。但大家想一想，人家是专业学逻辑学的，我们是要考一个公务员。筛选一个公务员，我只需要你有**最基本的逻辑判断能力**、逻辑够清晰就可以了。那点专业的知识体系，我真不需要。

所以这个模块，大家千万不要去怕。没有你们想象的那么难。

### 这一章有五类题型

整个逻辑判断里，现在常考的大概就这么五类。我挨个简单说一说，大家先混个脸熟，知道哪些是重点、哪些是基础就行。

| 题型 | 考频（国考） | 大致情况 |
| --- | --- | --- |
| 翻译推理 | 一般一道，最多一道，有时不考 | 近三年国考几乎没考过专门的翻译推理题 |
| 组合排列（朴素逻辑） | 一般两道左右 | 两道题难度可能差很远，要么很简单，要么极复杂 |
| 日常结论 | 一个，最多一个，有时不考 | 靠生活常识，没有太多方法技巧可传授 |
| 逻辑论证 | **6～7 个** | 十道里考六七个，是最大头、最重要的一块 |
| 真假推理 | 十年里只考过一道 | 那道是 2018 年国考；各地联考、省考里零星出现，十题里约一道 |

顺手再提两个小类：像"原因解释"这一类，都比较简单，我就不单独拆出来了。我列的这几个，说得未必够全，但几乎已经覆盖了最重要的题型。

几点要提前给大家交个底：

- **翻译推理别看考得少就不当回事。** 它是其余几类的**基础**。就像我们学数学得先会加减法，考试的时候未必直接考你加减法，可它是整个往上走的地基。这个基础不会，别的很可能都不会。
- **组合排列的取舍问题**——该取哪些、该放哪些、到底要不要硬啃——等做到题再看，现在先不操心。国考和各地省考在这方面差别不大。
- **逻辑论证才是重点。** 十道逻辑判断里面它一般占 6 到 7 个。大家平时刷题看到的加强、削弱、论证那一堆，统统归在这一类。
- **真假推理考得极少。** 2018 年国考考过一道，别的年份基本不露面。

> **提示**：逻辑论证这一块，如果你本来就是理科研究生，学的生物、化学、物理，那这块课我几乎不用讲——它本质上就是"做一个实验，得出一个结论，问你这个结论得靠不靠谱"，加强削弱就围着这个转。你自己做都能做得非常好。

### 一眼认出翻译推理

先看题型特征。翻译推理的题，特征只有一条：**题干里出现了非常明显的逻辑关联词**。

最典型的关联词是"如果……那么……"。比如"你如果今天晚上讲课，那么风雨无阻我一定来"——满足前面这个条件，我一定到场。这就是一类条件。

还有一类是"只有……才……"："只有你讲课我才去听课，别人讲课我不听"；"只有到了东北，你才能吃到正宗的锅包肉"。这也是条件，也很明显。

所以你看到题干里冒出这么一串句子——

> 如果乱扔垃圾，就会被认为没有道德；如果没有道德，就没人和他做朋友；如果没有朋友，就会寸步难行，无法继续留在这里。

再一看提问，问的是"可以推出什么结论""不能推出什么结论"——好，典型的翻译推理。

很多同学可能学过什么"假言命题""选言命题""联言命题"，这些名词在市面上很多机构、很多老师那儿都被做过变形，搞得更直观、更高大上。但叫什么其实不重要。在我们这儿统一就叫**翻译推理**，不需要给它套那些名词。道理也很直白：只要翻译过来就 OK 了。

> **提示**：上面提到的"只有……才"，对应的是另一类条件，它的翻译规则我一会儿再讲，先别混。

### 前推后：如果 A 那么 B

翻译推理的解题思维就一句话：**先翻译，再推理**。

先看第一个规则：前推后。

什么叫翻译？举个例子："如果你能在城里买房子，那么我就嫁给你。"满足前面这个条件——你在城里买了房子——那么后面我就执行一个动作：我嫁给你。

这就像编程序一样：

```text
   ┌──────────────┐        ┌──────────────┐
   │  条件 A      │  ───▶  │  动作 B      │
   │  在城里买房   │        │  我嫁给你     │
   └──────────────┘        └──────────────┘
          │
          │  A 不成立，程序不往下走
          ▼
   ┌──────────────┐
   │  婚事未知     │  ←  嫁不嫁？不一定
   └──────────────┘
```

前面这个条件成立，我就执行下面这个程序，条件推动作。翻译过来就是：

$$\text{买房} \rightarrow \text{嫁你}$$

考试里当然不能这么长，后面我们会简写。用 A 代表前面那句话、B 代表后面那句话，翻译成 **A → B**，就完事了。箭头就是"推出"的意思。

现在我先来考一考大家的逻辑关系。这个程序是真实存在的——**你买房了，我一定嫁给你**。

那我问你：如果你**没有买房**，能推出什么来？我嫁不嫁你呢？各位同学好好想一想。

这个程序只知道"买了房就执行"，你现在往程序里输入了一个"没买房"，它不知道该怎么办了。没买车行不行？可能我对你就是真爱，我不在意这个房子；也可能咱俩一起买，我照样嫁。所以**没买房，我嫁不嫁你——不一定**。

来，再问一个：如果我现在**嫁给你了**，能推出你买房了吗？

还是不一定。我虽然说了你买房我一定嫁给你，但你没买房我可能也嫁给你呀。所以后推前是推不了的。

那反过来问一个：我**没有嫁给你**，能推出什么来？能推出你一定没买房吗？

这个可以推。因为前面能推出后面，那么否定了后面，就可以推出否定前面。当年学过的**逆否命题**，一模一样，是个逆否等价。

### 等价关联词：出现即前推后

"如果 A 那么 B"只是最典型的一类前推后。与它等价的关联词还有一大票，只要出现，都是前面推后面。

| 关联词 | 例句 | 翻译 |
| --- | --- | --- |
| 如果 A，那么 B | 如果超哥不拖堂，那么我就可以早睡 | 否拖堂 → 早睡 |
| 只要 A，就 B | 只要你买房，我就嫁给你 | 买房 → 嫁你 |
| 为了 A，一定要 B | 为了成功上岸，那么一定要好好听课 | 上岸 → 听课 |
| 所有 A，都 B | 凡是我们都坚决拥护 | 我们都坚决拥护 |
| 凡是 A，都 B | 同上 | 同上 |
| 一定 | 一定是中国人 | 前件 → 一定是中国 |

这些没有更好的办法，**背下来**。不要死记，靠例题去滚，去加深印象。

这里再送大家一个小技巧，省得背到一半懵了：**若、则、就、都**，这几个字只要在关联词里冒出来，这个关联词就是前推后。这几个我们考得最多，也最好认。请把这句写在讲义上。

> **注意**：翻译的时候遇到否定式，就在前面给它加个负号。比如"如果超哥不拖堂，那么我就可以早睡了"，我简写成 `否拖堂 → 早睡`，一眼就知道前半截是带否定的。

### 逆否等价：否后必否前

刚才讲"我没嫁给你 → 你没买房"的时候已经把逆否带出来了。这里正式说一遍。

**逆否等价**：`A → B` 等价于 `¬B → ¬A`。

我们拿一句话试："如果某人是东北人，那么一定是中国人。"翻译过来是 `A → B`，东北人推出中国人，这没问题。逆否是什么？`¬B → ¬A`，就是：**如果你不是中国人，能推出你一定不是东北人**。这个可以推，成立。

再看四种情形，哪种能推、哪种不能推：

```text
   肯前  A  ──▶  B        一定成立
   否后 ¬B  ──▶ ¬A        一定成立（逆否等价）

   否前 ¬A  ──▶  ?        推不出
   肯后  B  ──▶  ?        推不出
```

一个一个说清楚：

- **肯前必肯后**。肯定了箭头前面的，推出了一定后面的。东北人一定是中国人，没问题。
- **否后必否前**。否定了后面的，推出否定前面的。跟上面那个逆否等价一模一样，可以直接划等号。
- **否前推不出来**。你不是东北人，能推出你不是中国人吗？我可能是北京人啊，我是中国人。这叫**不确定**。
- **肯后也推不出来**。你是中国人，能推出你一定是东北人吗？不一定。这也是**不确定**。

再来一个更接地气的例子，把这四种关系一次走完。假设"**只要你报了班，我就免费送你书**"，翻译成 `A → B`，报班 → 送书。

- 我问你：我不报班，我送不送你书？**不一定**。我可能也送。这是否前，推不出东西。
- 我再问：我现在送你书了，能推出你报班了吗？**不一定**。送你书不代表你报了班。这是否肯后，也推不出。
- 但是，如果我**没有送你书**，能推出什么？能推出你一定**没有报班**。这个没问题。这就是逆否等价。

所以整套东西，最后浓缩成一句口诀：

> **口诀**：**肯前必肯后，否后必否前，否前肯后不确定。**
>
> 东西很少，你重点记住一个逆否等价就行。

### 两道例题把规则跑通

规则讲完了，上两道例题跑一遍，你会发现就这么点事。

#### 拔河比赛那道题

题干三条：天气晴朗就举办拔河比赛；风很大就不举办拔河比赛；不举办拔河比赛就举办演讲比赛。实际情况是——**我们正在举办拔河比赛**。问能推出什么。

先翻译，三句都是"如果……那么……"，一律前推后：

```text
   晴天  ──▶  拔河
   风大  ──▶  否拔河
   否拔河 ──▶  演讲
```

翻译出来这题其实就 OK 了。逐条对答案：

- **第一条 `晴天 → 拔河`**：现在我知道拔河，能推出晴天吗？**推不出**。这叫**肯后**，肯后是什么也推不出来的。所以第一条错。
- **第二条 `风大 → 否拔河`**：把它逆否一下，否后推否前，**`拔河 → 否风大`**，也就是"风不大"。**推得出**，第二条没错。
- **第三条 `否拔河 → 演讲`**：现在我知道拔河，拔河就是"否拔河"吗？否了。**否前**，推不出"演讲"。所以第三条也错。

答案就是第二个：风不大。

就这么一个简单的东西，没有太多东西。大家好好梳理一下就 OK 了，你只需要知道怎么去翻译。

#### 上报与开除那道题

题干：老师把此事向学校上报，学生会被开除；学生被开除，学院年终考核会被一票否决；未将此事上报，学校的作弊现象将愈演愈烈。

三句翻译：

```text
   上报  ──▶  开除  ──▶  否决
   否上报  ──▶  作弊
```

第二句和第三句能不能接在一起？能。前两条首尾相接，先串起来。第三条我们给它做逆否：否后推否前，`¬作弊 → ¬上报`，就是 **`否作弊 → 上报`**。这样四者就全连成一条链了：

```text
   否作弊  ──▶  上报  ──▶  开除  ──▶  否决
```

连上之后看选项：

- **A：该年终考核未被一票否决**，即 `否否决`。从链尾出发，整串一路逆否回来：`否否决 → 否开除 → 否上报 → 否作弊`。推得出，**答案就是 A**。
- **B：学院的考核被一票否决**，即 `否决 → 否作弊`。这是后推前，推不了，**错**。
- **C：该学生如果被开除了，说明老师已经将此事上报学校了**，即 `开除 → 上报`。`上报 → 开除` 可以，但反过来是后推前，推不出，**错**。
- **D：作弊现象愈演愈烈，说明没有被开除**，即 `作弊 → 否开除`。`否作弊 → 开除` 可以，但这是**否前**，推不出，**错**。

你看，B、C、D 犯的其实是同一个基本错误。这题我讲得细一点，应该没什么问题了。

> **结论**：一串翻译出来的东西，只要首尾能接上，就把它连成一条链。顺推是从左往右走，逆推则是整串同时取否，从最右端一路走回最左端。

### 练习题里最容易翻车的地方

#### 吸烟者禁止入内

这道题略微有一点点难度，很多同学没想明白该怎么做，难点在于：**题干里根本没有告诉你"如果……那么……"**，得自己翻译。

题干写的是"吸烟者禁止入内"，它的意思就是"如果你吸烟，那么禁止入内"，翻译成 `吸烟 → 禁止入内`。后面说来了三位客人，他们都不吸烟，也就是 `否吸烟`。

来问：`否吸烟` 能推出什么？

这**又是否前**，推不出。我只能说"不一定"。所以答案只能选"他们**可能会被允许入内**"这一项——只能说不一定，得不出一个确定性的结论。

#### 岩浆海洋

题干：如果月球表面曾是岩浆海洋，那么元素就是连续的；如果岩浆海洋的存在得到确认，那么巨型冲击假说将成为最有力的起源。

翻译：

```text
   海洋  ──▶  连续
   海洋  ──▶  假说
```

逐项看：

- **A：如果月球表面不曾是岩浆海洋，那么元素分布就不是连续的**，即 `否海洋 → 否连续`。否前，推不出，**错**。
- **B：如果巨型冲击假说没有成为最有力的起源，那么月球表面的元素分布是连续的**，即 `否假说 → 连续`。`否假说` 可以先从第二条逆否出 `否海洋`，但 `否海洋 → 连续` 是否前，推不出，**错**。
- **C：元素不是连续的，则不曾是岩浆海洋**，即 `否连续 → 否海洋`。这不就是第一条 `海洋 → 连续` 的逆否等价吗？没问题，**答案就是 C**。
- **D：连续 → 假说**。肯后，什么也推不出，**错**。

其实整道题就用了这么点知识，多一点都不需要。

#### 四位老师获奖

张老师：如果我能获奖，那么李老师也能获奖。李老师：如果我能获奖，那么刘老师也能获奖。刘老师：如果田老师没获奖，那么我也不能获奖。

翻译：

```text
    张  ──▶  李  ──▶  刘
   否田  ──▶  否刘      （逆否后： 刘 ──▶ 田）
```

四者连成一条链：`张 → 李 → 刘 → 田`。

问的是：上述三位老师说的都对，并且四位老师中有三位获奖，那么谁没获奖？

**张没获奖。** 因为如果张获奖了，那么四个人就全都获奖了，那就不止三个人了。所以只能是后三位获奖，张没有获奖。

#### 小张小李应聘

小张说：如果做了业务经理，会开拓新业务。小李说：如果我做了经理，我会优化管理、精简人员。最终他们当中只有一个人当上了业务经理。

翻译：

```text
   张  ──▶  开拓新业务
   李  ──▶  精简人员
```

先看 A：不仅开拓了新业务，还精简了人员。这**推不出来**——张和李只有一个人当上了业务经理，这两件事根本不在同一个人身上。排除。

B 选项"如果该公司开拓了新业务，肯定是小张当上了业务经理"，这道题的分析在这里还没有展开，本节先把题面和已有结论放这儿，等下一节接上。

### 本讲提到的题目

**例一｜天气晴朗与拔河比赛**

题干：天气晴朗就举办拔河比赛；风很大就不举办拔河比赛；不举办拔河比赛就举办演讲比赛。假设以上陈述属实，实际我们正在举办拔河比赛，可以推出什么结论？

答案：风不大。依据是 `风大 → 否拔河` 的逆否式 `拔河 → 否风大`（见"拔河比赛那道题"）。

**例二｜上报与开除**

题干：如果老师将此事向学校上报，该学生会被开除；如果该学生被开除，学院年终考核会被一票否决；如果未将此事上报，学校的作弊现象将愈演愈烈。

答案：该年终考核未被一票否决。依据是 `否作弊 → 上报 → 开除 → 否决` 整串逆否为 `否否决 → 否作弊`（见"上报与开除那道题"）。

**练习一｜吸烟者禁止入内**

题干：吸烟者禁止入内，来了三位客人，他们都不吸烟。

答案：他们可能会被允许入内。依据是 `吸烟 → 禁止入内` 的否前 `否吸烟` 属不确定，只能说"不一定"。

**练习二｜月球岩浆海洋**

题干：如果月球表面曾是岩浆海洋，那么元素就是连续的；如果岩浆海洋的存在得到确认，那么巨型冲击假说将成为最有力的起源。

答案：元素不是连续的，则不曾是岩浆海洋。依据是 `海洋 → 连续` 的逆否等价 `否连续 → 否海洋`。

**练习三｜四位老师获奖**

题干：张老师——如果我能获奖，那么李老师也能获奖；李老师——如果我能获奖，那么刘老师也能获奖；刘老师——如果田老师没获奖，那么我也不能获奖。上述三位老师说得都对，且四位老师中有三位获奖。

答案：获奖的是后三位，没获奖的是张老师。依据是 `张 → 李 → 刘 → 田`，若张获奖则四人全获奖，与"只有三人"矛盾。

**练习四｜小张小李应聘**

题干：小张应聘时说如果做了业务经理会开拓新业务；小李应聘时说如果做了经理会优化管理、精简人员。最终两人中只有一个人当上了业务经理。以下哪项必定是真的？

已排除的一项：不仅开拓了新业务，还精简了人员。依据是张、李只有一人当上业务经理，两条结论不在同一人身上。其余选项的分析留待下一节。

## 翻译推理：后推前的方向，和"谁放在箭头后面"
> 对应块：BLK37 | 覆盖分集：P19下 | 块标题（分集名）：《第十节——逻辑判断——翻译推理——刘文超》

### 收尾：两个选项死在同一个方向上

上一题还没讲完，我们把剩下的选项收掉。

先看 B。选项里出现的是"新业务"和"当上经理"，翻译过来方向是**新业务推当经理**。我问一句：能推吗？不能。这是后推前，从后往前推，推不出来——新业务开不开展，跟某个人当不当得上经理，本来就没有必然关系。B 错。

C 一样惨。"如果该公司精简了人员，那么小李一定当上经理"，翻译过来是**精简人员推小李当经理**，又是一条后推前。B 和 C 犯的是一模一样的错：理论上前推后可以，后推前推不了，方向全是反的。所以 C 错。

于是答案就是第四个。D 说"如果该公司没有拓展新业务"，翻译成否新业务，否后推否前，往前能推出"没有拓展新业务"这一侧必然成立的结论，方向是对的。D 没问题。

> **易错点**：判断一个选项对不对，翻译完先别急着看结论听着像不像。**先看箭头方向对不对**。方向反了，选项说得再顺溜也是错的。

方向这件事一旦定错，后面满盘皆输。所以这一讲我们要解决的，其实就一个问题：**箭头到底该往哪边指。**

### 只有才：为什么偏偏是后推前

课间十分钟，我们回来接着讲。刚才一路推的都是前推后，从现在起我们翻到另一头——**后推前**，从后面往前面推。

它最典型的关联词就一个，就仨字：只有才。

只有刘老师讲课，我才来上课。
如果刘老师讲课，我就来上课。

你觉得这两句一样吗？不一样。

我们用后推前推一遍。"只有刘老师讲课我才来上课"，翻译过来是：**我来上课，推刘老师讲课**。反过来说，你今天真的来上课了，你手上就多了一个证明——这节课是刘老师讲的。**后面**那个条件，反过来证明了**前面**那个。这就是后推前。

```text
前推后：  A ──→ B          如果就、只要就、所有都、凡是都
后推前：  B ──→ A          只有才、步步、除非否则不、必要条件
逆否等价：否 A → 否 B      跟原句是同一句话，推出来的东西一样
```

读图：两条方向相反，却是逆否关系，永远成对出现。中文语序是会骗人的——你顺着念下来的顺序推，十次错八次。正确的做法是**先认出关联词，再决定谁站箭头前、谁站箭头后**。

> **结论**：只有才 = 后推前。翻译的时候，永远从"才"字后面那个条件往前推，别顺着句子语序推。

#### 步步：不到长城非好汉

"不到长城非好汉"，这是步步，后推前：**好汉推长城**。

有同学会纳闷：非得后推前吗？我前推后行不行？其实是一样的。你自己给它加两个字试试——"如果不到长城，那莫非好汉"，否长城推否好汉，标准的逆否等价，一转手就变成好汉推长城。

所以不管你从哪头下笔，**步步最后都落在"好汉推长城"上**。这就是我为什么说步步用后推前最省事：你把它倒过来翻译一遍就完事了。

#### 除非否则不：除非你买花，否则我不原谅你

"除非你买花，否则我不会原谅你"——除非否则**不**。注意，这个"不"字不能落掉。后推前：**原谅你推买花**。

什么意思？如果我原谅你了，那就证明你一定买花了。

#### 必要条件：谁是谁必不可少的条件

"淡水是人生存的必要条件"——还是后推前：**生存推淡水**。你现在活着，一定是有淡水的。

"谁是谁的基础""谁是谁的前提""谁是谁必不可少的条件"，说的都是只有才这一路，翻译方向也全都是后推前。

### 除非否则少了一个"不"怎么办

上面一路都在讲除非否则**不**，那有同学要问了：题干写的是"除非 A，否则 B"，没有那个"不"字，怎么办？

自己加一个。**否 B 推 A**，负负得正。

> **定义**：除非 A，否则 B ⟺ 否 B 推 A。

来个狠一点的例子："除非你还钱，否则我就打你。"这里"否则"后面已经带了个"不"字，那就是**否打你推还钱**——只要我没动手，就证明你把钱还了。

### 必要条件的语序陷阱：谁是必不可少的，谁放后面

这块最容易翻车，我单独拎出来说。

我先写两句几乎一模一样的话：

- 氧气是人生存的必要条件
- 人生存的必要条件是氧气

这两句是一个意思吧？当然是。但你要是机械地套"后推前"，第一句你推成生存推氧气，第二句你又推成氧气推生存——**同一句话，你推出了两个相反的结论**。推到氧气推生存的时候，能推出什么？什么也推不出来。

那到底怎么区分？记住这一句就够：

> **结论**：谁是必不可少的，谁给我放在箭头的后面。

```text
   谁必不可少            谁必不可少
   ----------            ----------
   生存 ──→ 氧气         生存 ──→ 氧气
```

读图：不管"氧气"两个字摆在句子的哪个位置，只要它是必不可少的那个，它就得站在箭头后面。

"氧气是人生存的必要条件"——谁必不可少？氧气。氧气放后面：生存推氧气。
"人生存的必要条件是氧气"——谁必不可少？还是氧气。氧气放后面：生存推氧气。

这就一样了。

再看一句日常的："每个人的成功都离不开夜以继日的努力。"谁必不可少？努力。努力放后面，所以是**成功推努力**。意思是：你只要成功了，就证明你一定努力过。

这一条你记住了，必要条件的题以后再出现，不会错。

### 例一：把只有才和如果那么串成一条链

来，做一道例一。这道题非常典型，就是"如果……那么……"和"只有……才……"混着出。

第一句是"如果……没有底线思维……就不能做到严格自律"，翻译成**否底线推否自律**。

第二句是只有才，后推前：**底线推不忘初心**。

第三句还是只有才，后推前：**不忘初心推坚守理想信念**。

```text
第一句  取逆否        自律 ──→ 底线思维
第二句  只有才        底线思维 ──→ 不忘初心
第三句  只有才        不忘初心 ──→ 坚守理想信念
```

三条推完，我们问一句：**能不能连成一条链？**

第一句现在还孤零零挂在那儿，给它做个逆否等价：否后推否前，**自律推底线**。这一接，四条全部焊上了：

自律 ──→ 底线思维 ──→ 不忘初心 ──→ 坚守理想信念

连起来就好办了，一个一个选项对过去。

**A** 说：如果领导干部不能严格自律，就会丧失底线思维。翻译是**否自律推丧失底线思维**。否自律站的是**否前**，否前什么都推不出来。A 错。

**B** 说：只有不忘初心才能做到严格自律。只有才，后推前，**自律推不忘初心**。自律在链子上，不忘初心也在链子上，推得通。B 就是正确答案。

剩下的两个：

**C** 是"只要……就……"，前推后，**坚守理想信念推自律**。可我这条链是自律一路推到坚守理想信念，你从最末端往回推——推不了。C 错。

**D** 也是"只要……就……"，**不忘初心推严格自律**。这条长得特别像 B，但它是前推后，而 B 是后推前。从后往前推，推不出来。D 错。

> **易错点**：这道题最大的坑，是把"只有才"和"只要就"弄混。**只要就 = 前推后，只有才 = 后推前**，很多同学就栽在这俩上，一定给我区分开。B 和 D 只差一个"只有才"还是"只要就"，就一个对一个错。

### 例二：问"哪项跟题干不一样"，先看方向再看逆否

例二考的不是"选对的"，是选**和题干不一样**的那个。这一类题要格外小心，因为它反过来问。

题干用的是"除非否则"，翻译成否 B 推 A，写出来就是**否法庭推支付**。

**A** 是只有才。后推前，否法庭推支付。跟题干一模一样。一样就不能选——它问的是不一样的。

**B** 是"如果……那么……"，前推后，**支付推否法庭**。题干是后推前、方向朝前，B 是前推后、方向朝后，完全不一样。B 就是答案。

**C** 是"如果……那么……"，**否支付推法庭**。你把它逆否等价一下——否法庭推支付。跟题干一样。

**D** 是"如果……那么……"，否法庭推支付。这就是题干原话。

所以只有 B 不一样，答案选第二个。

> **提示**：做这类"与题干不同"的题，最好的习惯是**四个选项全翻译成箭头写下来**，横向比一遍。方向一样、结论一样，就是"一样"；只要方向反了，它就是你要找的那个"不一样"。

### 练习一：己所不欲，勿施于人

练习一很轻松。孔子说"己所不欲，勿施于人"，问：以下哪项**不是**这句话的逻辑推理。

步步，翻译：**施于人推己所欲**。这句话的意思就是，我对别人做的那些我自己都受不了的事，我不能施给别人。

题干的译文先钉死为"施于人推己所欲"，再看选项：

**A** 是"若……则……"，前推后，**己所欲推施于人**。跟题干反着来。A 就是那个"不是"，**答案 A**。

**B** 是只有……才……，后推前，施于人推己所欲。一样。
**C** 是除非否则不，后推前，施于人推己所欲。一样。
**D** 是"凡是……都……"，前推后，施于人推己所欲。一样。

这一道题里，我把前推后、后推前、若则、只有才、除非否则不、凡是都，又整整复习了一遍。**这题出得是真好。**

### 练习二：不要自己脑补

第二道，前几句我们一句一句推。

第一句只有才，后推前：**事业的成功推努力奋斗**。
第二句只有才，后推前：**人生的幸福推事业的成功**。接上去，人生幸福推事业成功推努力奋斗。
最后一句"如果……就……"，前推后：**努力奋斗推勇于承受痛苦和艰难**。

几条连完，题干给了一个结论：世界上有些人十分畏惧痛苦和艰难，不愿意承受。翻译成**否承受**。

否承受站在**否后**，否后推否前：有些人是不努力奋斗、不能事业成功、不能家庭幸福。

所以答案选第四个。

A 和 B 不用看，一定错——它们都是"承受推成功""承受推幸福"，从后往前推，推不出来。

> **易错点**：C 和 D 这两项，从生活常识看**两句话都对**，但 C 不是我们从题干推出来的。题干只能推出"有些人不愿意承受，所以有的人不努力奋斗、事业不成功、不幸福"，推不出 C 说的那一句。这题很多人错，根子就在你老去脑补一些题干之外的东西。

记住：这就是逻辑，逻辑只讲题干给你的东西。你不要自己脑补，严格按照题干给的东西去推，就一定能做对。

### 练习三："大量的资本支持是必不可少的"

第一句：大量的资本支持是必不可少的。谁必不可少？**大量的资本支持**，放后面。前推后：**前进推大量资本支持**（发展中国家向经济发达国家前进的过程中）。

第二句：高储蓄率是必不可少的。谁必不可少？高储蓄率，放后面。**大量资本推高储蓄率**。

链条：前进 ──→ 大量资本支持 ──→ 高储蓄率。

**A**：大量的资本就可以实现跨越。翻译成资本推前进——后推前，前两个后推前，推不了。A 错。
**B**：高储蓄率推资本支持。又是一个后推前，推不了。B 错。
**C**：没有获得大量的资本支持 → **否资本推储蓄率不高**。否资本是什么也推不出来。C 错。
**D**：没有高储蓄率 → 否后推否前 → 不能跨越 → 否前进。没问题。**D 是答案。**

> **易错点**：C 是本题最典型的坑。**资本推高储蓄率可以，是否资本什么也推不出来。**你不能因为"现实里听着挺顺"就把它选上。

### 练习四：只要不起雾，就能起飞

题干是"只要……就……"，前推后：**否起雾推能起飞**。

四个选项翻译一遍，横着比：

| 选项 | 关联词 | 翻译 | 与题干的关系 |
| --- | --- | --- | --- |
| A | 如果……那么…… | 起飞 推 否起雾 | 原句的逆否，一样 |
| B | 如果……那么…… | 否起飞 推 起雾 | 逆否回来正是原句，一样 |
| C | 除非否则 | 否起飞 推 起雾 | 与 B 一模一样，一样 |
| D | — | 与题干方向不符 | 不一样 |

A、B、C 三个说的都是同一件事，绕一圈全回到原句——A 逆否一次是原句，B 和 C 逆否一次也正好是原句，而 B 和 C 彼此翻译结果完全相同，说明它们本来就是同一个意思。

**所以只有第四个跟题干对不上，答案就是第四个。**

### 这块是后面所有逻辑判断的地基

最后我说两句。

很多同学会跟我说：老师，我做了这么多，感觉浪费时间啊，这题有什么好做的。主要原因就一个：**你不熟**。

你做多了就会发现，这题在整个公务员考试里真的太简单了。你只要把它翻译过来，这题就一定能拿分。

你现在慢，慢在**熟练度**上，不在能力上。等你慢慢刷了大量题，再遇到这种题你会很高兴的——一看就知道：这题我一定会做，我只要翻译就行了。我可能只是需要一点熟练度而已。

但这一块你必须掌握。它是我们后面**所有逻辑论证、逻辑判断的基础**。我讲后面逻辑判断的时候，会经常用到这里的基本逻辑学知识。

> **结论**：觉得掌握得不够好的同学，回去把今天这些例题、练习全部再刷一遍。这一步没有捷径，但也不需要天赋——**翻译过来就能拿分**。

好，今天就讲到这儿。比预计的略微慢了一点点。

### 本讲提到的题目

题干均为课上口述的要点，解析依据见上文对应小节。

#### 例一

题干由三句构成：一句"如果……没有底线思维……就不能做到严格自律"，两句"只有……才……"（底线思维与不忘初心、不忘初心与坚守理想信念）。

答案：**B**。三条翻译取逆否后连成"自律 → 底线思维 → 不忘初心 → 坚守理想信念"一条链，只有 B"自律推不忘初心"在链上成立；A 用了否前，C、D 把"只要就"当成了"只有才"。

#### 例二

题干为一句"除非否则……"（法庭与支付的语境），问：哪项判断的含义**与上述判断不一样**。题干译为**否法庭推支付**。

答案：**B**。A、C、D 翻译（或逆否等价）后都与题干一致，B"支付推否法庭"是前推后，方向与题干相反。

#### 练习一

孔子说"己所不欲，勿施于人"，问：以下哪项**不是**这句话的逻辑推理。题干为步步，译为**施于人推己所欲**。

答案：**A**。A"若……则……"译成"己所欲推施于人"，与题干方向相反；B、C、D 三项均与题干一致。

#### 练习二

题干含两句"只有……才……"（事业成功与努力奋斗、人生幸福与事业成功）和一句"如果……就……"（努力奋斗与勇于承受痛苦和艰难），并给出结论：世界上有些人十分畏惧痛苦和艰难，不愿意承受。

答案：**第四个（D）**。"否承受"走否后推否前，推出有些人没有努力奋斗、事业不成功、家庭不幸福；A、B 均为后推前推不动；C 虽然符合生活常识，但不是题干推得出来的。

#### 练习三

题干两句均为"……是必不可少的"：大量的资本支持是必不可少的、高储蓄率是必不可少的（发展中国家向经济发达国家前进的过程）。

答案：**D**。链条为"前进 → 大量资本支持 → 高储蓄率"；A、B 均为后推前推不动，C 用否前推不出任何东西，D 走否后推否前成立。

#### 练习四

题干"只要不起雾，就能起飞"，问哪一项与上述论断**不一致**。题干译为**否起雾推能起飞**。

答案：**第四个（D）**。A 译成"起飞推否起雾"是原句逆否；B、C 都译成"否起飞推起雾"，逆否回来也是原句，且二者彼此完全相同——A、B、C 说的都是同一件事。
