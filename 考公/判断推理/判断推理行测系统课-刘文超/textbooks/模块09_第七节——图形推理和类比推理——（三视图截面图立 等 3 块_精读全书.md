## 三视图、截面图与立体拼合：把立体拍扁、劈开、拼回去
> 对应块：BLK24 | 覆盖分集：P13上 | 块标题（分集名）：《第七节——图形推理和类比推理——（三视图截面图立》

### 主视图、左视图、俯视图

好，各位同学，这是图推的最后一节，第七节，三视图截面图和立体拼合。

先说清楚一件事：空间类题型走到这里，基本就收官了。上一节课我们讲的是空间重构，剩下的就是三视图、截面图和立体拼合。这一节课我们把这三样放到一块儿看——它们其实是同一件事的三个视角：**面对一个立体，要么把它拍扁成一个平面图，要么拿刀把它劈开看截面，要么把它拆成零件再拼回去。**

三视图这个东西，初中和高中我们就学过了。主视图，就是你从正面看；左视图，从左面来看；俯视图，从上面来看。这三个东西合起来叫"主左俯"三视图。

原理也不复杂：投影。一个立体图形，通过正面、左侧、上面这三个方向的投影，落到一个平面上，变成三张平面图。这样研究起来更有助于做工程制图等等一些研究。

```text
   俯视图 ── 从上面往下看
        ↓
   ┌──────────┐
   │  立体    │ ◄── 左视图 ── 从左面看
   │  图形    │ ◄── 主视图 ── 从正面看
   └──────────┘
```

那考试里面关于三视图会怎么考呢？其实也是最基本的三视图，题干给一个立体图形，再给几个平面图，让你挑出对应视角的那一个。

题型判定其实比较简单：一眼看出这是个立体图形，然后确认哪个选项给的是哪个方向，剩下的就是"照着拍"。所以这一节的难点从来不在判定，在细节。

接下来这几个细节，你自己不注意就全错。

### 三视图的四条硬规矩

#### 三视图一定是平面图

这是第一点，最基本的一条。

我们说从正面看、从上面往下看、从左面看，看到的**都是一个平面图**。因为投影落到纸面上的东西，永远是平的。

> **结论**：选项里只要画出了立体感——还是立体的、带透视的、带"厚度"画法的——不用算，直接排除。

例一就是这么做的。题干给一个立体、三个平面图，问主视图。B 和 C 这两个里面有东西"呈现出了一个立体"，三视图不可能是立体，所以 B、C 先排除。这就是第一道门槛，很多人甚至过不了这道门槛。

#### 原图有线才有线，没线别自己脑补

这是最容易翻车的地方，我特别要多说两句。

很多同学看到立体图形顶部是一个半圆，就觉得"那主视图上这里应该有一条弧线把它隔开"。你千万不要心里想着有个半圆。

**这条线你是看不到的，这是一个你想象中来的线。你千万不要把你想象出来的线给我放在上面啊，那是你想象的，原图中没有这条线。**

举个例子：那个从某个方向去看的立体，上面明显是个半圆。选项二在中间多画了一条线，把半圆"隔开"了。错。原图里根本没有那条线，正确的是选项一。

> **易错点**：主视图的轮廓，只由"这个方向上真正能看见的棱"决定。看不见的棱不画，不要把自己脑子里补全出来的三维形状当成题面给的线。

#### 被前面挡住的线，考试版是"不画"

第三个知识点。做主视图的时候，前面一些东西会把后面的东西给遮住——这一条谁都懂。

那被遮住的部分怎么处理？有两个版本。工程制图里，我们以前学的时候是用**虚线**来表示的，就是"我看不见，但我还是给你画出来"。

但考试不是这么考。你看题干那个例子：前面是圆锥和立方体，后面那个东西被遮住了。图一用虚线把被遮的部分画出来，工程制图里没问题，但考试的时候一般不给你这种选项；图二把被遮住的那两条线画成实线，错；图三——后面对看不见，看不见我就不画——**这才是我们考试过程中最常出的那个**。

所以记住考试版就行：虽然我看不见，那看不见我就不画。图一是我用了虚线来画的，但是考试的时候一般不给图一，主要是给图三。

> **结论**：看见的画实线，看不见的不画。别去选那个"用虚线表示被遮部分"的选项。

#### 圆柱的主视图，顶部是一条直线

最后一条，也是一个高频坑。

一个圆柱，俯视图是个圆，没错；主视图是什么？你正面去看，看到上面是**一条直线**。不是圆。图中图二也可以叫左视图——圆柱主左是一样的——它的上面是一条直线。

虽然上面是个圆，但你这么看主视图的时候，它就是一条直线。

你就想那个矿泉水瓶：里面都是水，上面瓶口是个圆，但是主视图看过去，瓶口就是一条横线。

记这个例子，比记那个圆柱管用。

> **易错点**：例一的 A 和 D 就差在这儿。A 把圆柱顶画成了弧面，D 画成平的——D 对。因为圆柱从正面看，顶是一条线。

### 一串例题，把主左辅的手感摸出来

下面我们用大量例题和练习，帮大家找一找主左辅这几个图形的感觉。

**例一**，给的立体图形，第二个图形是俯视图，第三个是主视图。同理换一组，第一个是俯视图，就该找主视图。排除 B、C（它们是立体的），A 和 D 的区别在圆柱顶部——刚才讲过，应该是平的，所以答案是第四个。

**例二**，A 上来先排除，那条线不可能有，完全不是一回事。B、C、D 的区别在那一条线和那两条小线。这几条线原图中有吗？你看那个位置，根本没有。所以答案直接就是 B。

**例三**，这个略微有点难。题干说"从任何一个角度观看"——这是什么意思？我们平时讲的是主视图、左视图、俯视图，那么既然他说任何一个角度，你能不能从底下往上看？能不能从右面看？能不能从后面往前看？关于这个立体，你其实有六个方向，任何一个角度都可以。

答案就藏在这句话里。选项 A 是从正面看的主视图，没问题。B 是从底下往上看——很多同学没想到了吧。你看那个位置，它是没有这条线的，所以你根本看不到。C 也没问题，它是从右往左看的，那两个阴影你也能看到。**所以只有 D，你是看不出来的。** 你从哪个方向看都看不出来。为什么？因为这么细的线，原图里压根就没有。哪怕上面那地方有个斜角，也带不出这么细的线。所以 D 是不可能的。

这题略微难了一点，六个方向、六张选项，课上如果没理解清楚，就自己暂停一下好好观察观察，尽量把这个空间想象出来。这里需要你有一点空间想象能力，慢慢练。

> **提示**：题干一旦把"从任何一个角度"这五个字写出来，就把主视图的三个方向扩成了六个方向（正、背、左、右、上、下）。这时候你要挨个方向去试，而不是默认在三个方向里挑。

**例四**，2019 年浙江的题，相对来说比较简单，它问主视图。A 和 B 长得一样，C 和 D 不一样。区别在哪？看主视图上这一块的高度非常高，A 和 B 画得矮，直接排除。C 和 D 的区别在左视图里。从左面看，那个立方体相当于挂在整个图形的外面。所以 C 画错了，D 才对。对这个结构感觉好的同学一眼就能看出是 C；看不出来的，我给你指一下：图形的后面那个面在这儿，左边这个正方体它是挂在外面、多出去一块的，所以 C 那个位置肯定不对。答案是 C。

**例六**，这是一个主视图、一个俯视图，加一个立体图形。一眼看上就该找俯视图，从上往下看的俯视图。A 上来先排除，这个方向不对，缺东西；B 也排除，B 是中间这个东西紧贴着，可原图里这条线跟后面还有一定的距离，很明显还有一点点距离；剩下 C 和 D，区别在那两条线——虽然你感觉上面好像有一个弧度，但这条线是看不见的，这条线是没有的。所以答案是 C。

**例七**，送分题。简单一看就没有能数错的，C 里画的那条线是看不见的，答案是 A。这种一定要去拿分。

**例八**，这题考的是展开图。你看这个地方是不是应该补一条线？补一条线，然后到这儿 OK，再补一条线——它应该是展开图。右面那个也是，你再补一条线补齐。所以选项里首先一条：B 和 D 缺这条线，因为你缺一条线了，第二个和第四个不能选。把 A 和 C 的这两条线补齐之后，看 A 和 C 的区别：区别就在这个边。但你看这是一条短边，这是一条长边，我们就说看长短吧。再看原图里，里面这条线紧接着的这两个，哪一条都不是短边。所以 A 排除了——A 接的是一个最短边，我这地方接的这两个哪一个都不是短边。答案是 C。

**例九**，这题的规律特别好找：这些图形的俯视图都长得一个样子。看出来了没有？一个、两个、三个，反正画得不标准了，但所有图形的俯视图都是它。既然题干给的那几个俯视图是一样的，选项里我找一模一样的俯视图——只有第四个。答案是第四个。

> **提示**：像例九这种"多个选项共用同一个视角"的题，考场上就是秒杀的。你只要验证出题干给的那几个俯视图确实是同一个，剩下的选项里找相同的就行，连立体形状都不用细看。

**例十**，这个题相对简单，就是一个立体几何。第一个图形对应第二个——它俩对得上，很简单。第二个对应的是一：这个是从正面看的，是它的主视图；另一个是它的俯视图，一眼就看出来了。最后一个对应三，上面这个是俯视图（从上往下看），这个是左视图（从左往右看）。主、左、俯三个完全对应上了，所以答案是 A。

回头看这十道题，你会发现有些题做的时候脑子是懵的、方向找不对。这很正常。想不到很正常，想不到的原因就是——**因为你做的题实在太少了。**

你做的题越多，这种感觉就会出现；再见到题，很快就能反映出来大概有哪些套路。所以一定要大量地刷题。大家会发现我的课程设置里面例题和练习非常非常多，主要的原因就是让大家大量地练习、找感觉。其实我所有课程里的练习，虽然已经很多了，但还不够多。课程系统结束之后，还是需要经过大量地刷真题来巩固。

### 立体拼合：先数数量，别急着拼

立体拼合这块儿，我们就一道题，但它值得单独拿出来说，因为它体现的是一种**做题顺序**的思维，比拼出来本身重要得多。

例五是 2019 年国考的题。题干给一个多面体，这是一个正视图、这是一个后视图，问右边问号处应该填哪一个。图形可以拆分成四块，1234。

很多同学一拿过来就开始懵：这个怎么拼啊？这太复杂了。

**先确认数量。** 你看，正视图这边 1 到 22，总共 22 个；后视图这边数下来是 22 个。问号那儿呢，12345 是五个，123456 是六个，12345 是五个——缺六个。

这时候你到选项里去找一找有几个：A 是四个，B 是五个，C 是五个，**只有第四个是六个**。答案就是 D。这不就结束了吗？

这个题甚至还没有用到去拼合。

> **结论**：拿到立体拼合题，先数方块数量，对得上就赢了一大半；数量对不上，再去考虑它是怎么拼的。这是一个正常人的思维——你不能上来就难，怎么怎么样啊。你是个正常人，应该先干这件事。

那这道题真要是硬拼呢？我把立方体拼合的示意图给大家弄出来了，你一看就知道——**如果真要去拼，这个题非常复杂**。这里面你怎么想？太难了，需要非常强大的空间重构能力。

所以你看，国家卷也没有为难你啊，你通过数量就做出来了。出题人是很有水平的，他们非常有水平——他们知道这个题真要拼是很费劲的，所以他们留了一个数量上的口子给你。

考试时间那么短，除非你是专业来学的，否则不要去碰那个空间结构。想都想不到，别硬想。

### 截面图：拿菜刀"咔"一下

好，三视图这块儿就这么多。注意一些小细节就行了。下面来看第二个考点，截面图。

#### 什么是截面图

看这个图形，这可能是一个小零件。注意啊，这个地方是菜刀——看好了，这个地方叫菜刀，这个东西是菜刀，看出来了吧？

什么叫截面图？就是这个菜刀"咔"砍了一刀，砍完之后，这个截面就是截面图。**我砍你一刀，然后得到这个截面，就是截面图。**

好，概念讲清楚了。但这里经常有一个问题：很多同学会把截面图和剖视图弄混。这个我们必须掰开了说。

#### 截面图不是剖视图

拿一个菜刀砍完之后的零件来看：

菜刀出现的这个砍的区域，是你的**截面图**。就是切出来的那一个面。

什么叫**剖视图**？这个很多工科的同学、学工程设计的、画过图纸的同学就知道——你描述一个零件、描述一个图形的时候会出现一个剖视。什么叫剖视呢，就是从中间切开了之后，这个投影。

```text
   菜刀"咔"一下，横着切过去

   ┌──────────┐
   │  小零件  │ ───────────▶  刀刃走过的那个面  =  截面图
   └──────────┘                      （只有切面本身）

   ┌──────────┐
   │ ┌──────┐ │                    切完以后，往里看到的东西
   │ │ 切面 │ │ ───────────▶  切面 + 整个外轮廓  =  剖视图
   │ └──────┘ │
   └──────────┘
```

> **定义**：**截面图**＝你切出来的那一个面，本身。**剖视图**＝从这个方向往里看，投影出来的东西，等于中间那个截面加上零件的外轮廓，合起来整体。

这里我再说一遍，你一定要确认区分出截面图和剖视图：截面图就是你切出来的那一个面算，千万不要把它想象成剖视图。这两者一定要区分开。

考试里问的永远是"截面图"，不是剖视图。

#### 一刀切，不许拐弯

说完概念，我们再说怎么切。我要说一点：**我们所有的切都叫"一刀切"。**

就是你去砍这个东西的时候，你只能一刀下去。各位同学，这个刀怎么样？它不能拐弯啊。你砍的时候你就一直往下砍，你不能拐弯——你斜着砍，突然横着砍了，不行。一定是一刀切。

很多同学会觉得：老师你开玩笑，哪会有同学会知道拐弯这种事情？别笑，有非常非常多的同学会犯这个错误：切着切着，从这个图形切到那个图形，然后到下面就拐弯了。

一刀切这个原则，在后面的例题里会反复救你的命。

#### 常见立体各能切出什么

我们把常见的立体图形各能切出什么形状过一遍，这个必须记住，考试的时候不会这么简单。

```text
   一刀切  ──►   ╲
                  ╲
                   ╲      切面是一个平面，
                    ╲     所以截面只能是一个平面图形

   拐弯切  ──►   ╲
                  ╲__
                     ╲     这是两段拼出来的"面"，
                      ╲    实际上下刀得到的不是一个截面
```

| 立体 | 切法 | 切出来的截面 |
| --- | --- | --- |
| 正方体（六面体） | 拦腰横切 | 矩形（正方形） |
| 正方体 | 上下竖着切 | 矩形 |
| 正方体 | 斜着切 | 矩形 |
| 正方体 | 斜切，且保证上下两边平行 | 梯形 |
| 正方体 | 从一条棱斜着切 | 三角形（只能是锐角三角形） |
| 圆柱 | 横着切 | 圆 |
| 圆柱 | 斜着切 | 椭圆 |
| 圆柱 | 斜着或竖着切 | 矩形 |
| 圆锥 | 横着切一刀 | 圆 |
| 圆锥 | 斜着切一刀 | 椭圆 |
| 圆锥 | 从最中间竖着切 | 三角形 |
| 圆台 | 横着切一刀 | 圆 |
| 圆台 | 斜着切一刀 | 椭圆 |
| 圆台 | 竖着往下切 | 梯形 |

逐个说一下。

**正方体切矩形**是最容易的，拦腰切一下就出来了，上下竖着切也出来，斜着切还是出来，三种都可以。

**正方体切梯形**也不难。梯形有什么特点？上下两个底是平行的。你只要保证这俩平行就行——斜着切一下，上底和下底平行，它就是一个梯形。

**正方体切三角形**，从一个棱斜着切一下。这里有个小问题，我要专门讲：你从这个棱开始斜着切，那个角现在是多少度？是 60 度。我能不能让这个角增加？能，往下移就行。往下移、往下移，这个角度在增加。一直往下移，移到三个边合在一起变成一个直角的时候，是不是就出现直角了？

但是——各位同学，你横着切的时候，切出来是三角形了吗？不是。你横着切，切出来的是一个矩形。

所以注意啊：

> **结论**：正六面体只能切出锐角三角形，切不出直角，更切不出钝角。考试的时候如果题干给的是六面体，选项里出现了直角三角形或者钝角三角形，一定是错误答案，没有任何疑虑。

#### 拿刀试试

上面这些都是基础，真正做题的时候没那么简单。来一起截一截。

**例一**，大家基本都选了 A，因为 A 你根本截不出来。横着截、竖着截、斜着截都不行。那 B 呢？正方体截出一个正三角形太容易了，我随随便便从这取几个点，保证这三个边相等，不就 OK 了吗。C 也很容易，你横着切一刀不就完了吗。D 是不是更容易？你随便从这取一个，是不是很轻松就切出来一个 D 来。

这不就是 B 吗，这不就是 C 嘛，这不就是 D 吗。A 是截不出来的。所以这也没什么疑问。

**例二**，这个也比较简单。一个有立方体存在的图形，切一个 A（长方体、矩形）是非常容易的，我从这随便取一点就切出来了。那 B 怎么切？很多同学说你从上往下切一刀不就完了吗——切不出这个图形来，因为上面还多出来一截呢。所以 B 是切不出来的。C 比较容易，这样横着切一刀就切出来了。D 也不难，你想切个梯形，是不是随便找个地方就切出来了？有一个正方体，你随随便便就切出来了。

这里很多同学栽在 B 上。我给大家看一看：从上往下看那个蓝色的，你从上往下切——注意，我只要这个截面。**其实截完了之后是不是只有这个东西？上面这些线都是没有的，上下这些线都是没有的，其实只有这个东西。** 这样你就只能得到这个截面。

另外，刚才有同学问：例一切正方形不是很容易吗？哎，怎么又不好使了。切一个正方形——你从这不就切出来了吗？随随便便切一下，非常可以。好好去观察啊，一定要好好观察。**对一个正方体再切不出一个正方形来，可就完了是吧。**

**例三**，这个略微难一点。这个图形是由上下两个部分构成的，所以 A 选项既然也是上下两个部分，那你就先把这个地方拉条横线，心里大致预期一下：上面是一个截面，下面是一个截面，应该是穿越了上面和下面这两个部分的。

看 A：A 上面是一个梯形，下面又是一个梯形。能不能截？可以从最上面开始往下截。上面这个梯形没问题，我截出来了；然后我把这个截面继续扩大，按这个方向继续往下截，继续截，没问题。上面一个梯形，下面一个梯形——这不就是 A 吗，没问题。

B 没有人选吧？人家问不可能啊。B 太容易了，从这随便切一下就是 B，没问题。

那么看 C。C 也是由上下两个部分构成的，上面一看好像是一个三角形（A 是个三角形），那怎么切呢？就这么斜着切一下。切完之后大家看一看：下面这个部位你能切出一个矩形来吗？你沿着这个方向——你不能拐弯儿啊，你不能拐弯，你直着再往下切，你斜着切，下面只能是一个梯形。你下半部分只能是一个梯形，你切不出一个矩形来。

所以无论怎么切，下面只能是一个梯形，C 就错了。D 是很容易的，D 上面这个东西上下都是矩形，你从这儿随便切一下就行了。

> **提示**：这种"上下两截、形状还不一样"的截面题，解法是——先按分割线把选项拆成上下两块，再把立体也按结构拆成上下两部分，一块一块去对。只要有一块对不上，整个选项就废了。**中间最容易被骗的是下半部分，因为大家都习惯性地在下面画一个规规矩矩的矩形。**

**例四**，这个就直接秒杀选 C。人家问的是不可能——是不是不可能截出直角三角形吧？不可能。正六面体出直角三角形，一定是错的。这题秒杀选 C，结束，没什么可讲的，讲过了。

其他几个简单看一看：图一很容易，简单这么切一下就行；图二这个正三角形很容易，随便找个地方就切出来了，切个三角形还不容易嘛；图三也很容易，这种立方体你切出个梯形来，那不是分分钟的事吗，太多地方可以切了。

秒杀，就选 C 了。

## 立体截面、立体拼合与类比推理
> 对应块：BLK25 | 覆盖分集：P13中1 | 块标题（分集名）：《第七节——图形推理和类比推理——（三视图截面图立》

### 截面图：一刀切下去，切不出来就排除

这道题的答案是第四个。还好大家没有选 A——A 肯定是可以的，你随随便便找一个地方就能切出这个等边三角形，三角形很容易切，从它后面也能切出来。这里面背部有点复杂，但一点也不影响，切个三角形还不容易吗。所以 A 就不用说了。

B 也是可以切的。B 其实你就从这儿切，斜着划过去，B 就切出来了。C 也没问题，你竖着切，这切一下、那切一下，肯定没问题。

所以 ABC 其实都 OK，D 是切不出来的。D 上面是个菱形，这菱形怎么切呢？我取一个点、取中点，是不是应该这么切——这个菱形 OK，后面还有一个。举一个……这个菱形切出来之后你看，接触这个面是不是在这儿？来，这个面，你怎么能够切出一个三角形呢？三角形是切不出来的。你就切吧，切到底也好，切到哪儿也好，是不是这个地方又多了一个东西？这个地方会拐弯的，你切不出三角形来。

略难了一点，但其实用排除还是 OK 的。再给大家看一遍：A 没问题。B 可能有同学没切出来，B 其实就是这么切的，刚才我画的那个，我画得不好看；这个呢是特意给大家做出来的。C 是不是也很容易？你从上往下切一刀就行了。所以就是 D 是切不出来的：D 的下面这个三角形切不出来，上面这个菱形是很容易的，但下面那个三角形切不出来——简单一看那个地方多了一点东西，就切不出来了。

> **结论**：这种题不需要你理解整个立体结构，只要挨个选项去试切——能切出来的留下，切不出来的排除。D 会在切的过程中"多出一块"或者"拐弯"。

例六我们就秒杀选 A。

A 选项这个图形，这条线——题干上哪有这条线？你从上往下切一刀，切一刀没有这条线。注意，A 直接秒杀，没啥说的。

B 是不是从这个地方切一个过去就行了？C 不用看，C 非常容易，随便找个地方就切出来了。D 也没问题，这些都很容易找到。这个 A 太明显了，错误太明显了，这没什么说的。

> **易错点**：切的时候不要只盯着"大形"对不对，要把选项上每一条线都对上。选项上多出一条线，而题干里怎么切都切不出这条线——这就是秒杀点。

> **定义**：一刀切。截面图就是一刀切出来的那个平面——一刀下去，不许拐弯。

关于截面其实我们就讲完了。但还是得说一嘴：大家需要大量地去练习和熟悉，找到这个感觉其实没有那么难。

这里注意，一刀切，不能拐弯。然后有简单的截面，还有复杂一些的截面。注意，各位同学一定要知道，每一种我们常见的图形——圆柱、圆锥、圆台、六面体——它们能切出什么图形来，这才是我们需要掌握的东西。

> **结论**：截面的功夫不在某一道题上，而在"每一种常见立体都能切出什么"这张清单上。这张清单靠练，不靠听。

### 立体拼合：有凸必有凹，有凹必有凸

好，那最后咱们再讲一下最后一个考点，就是立体拼合。立体拼合的解题原则会更加的简单。

什么意思啊？就是既然是拼合在一起，很多个图形也好、很多个立体图形或者平面图也好，它们拼合在一起——既然拼合在一起，是不是应该有凸必有凹，有凹必有凸？

它就像那个榫卯一样。我们以前的工匠、木匠，榫卯是有榫就有卯，是相互拼合在一起的。你看，这块是不是缺了一块？那另外一块不就把它给补上了吗。你就缺了一块、有凸的地方，那有凹进去的，就应该有凸的地方把它给拼在一起；有凸出来的，就一定有一个凹的地方，把它俩拼在一起。就像榫卯一样，会完整完美地契合在一起。这就是立体的拼合。

```text
   凸(A)  <--->  凹(B)     可以拼
   凸(A)  --x--  凸(C)     没有人接
   凹(A)  --x--  凹(C)     没人扣
```

读图：凸只能配凹，凹只能配凸；一旦两头都是凸，就没有地方承接它，直接排除——立体拼合题八成的排除都是这一刀。

#### 凸和凹一一配对，简单题直接秒杀

来看例一。这个题比较简单，是不是可以秒杀？他们 2、3、4 组成。

这是二，这是三，这是四，拼合在一起吧。你看这是不是凸出来一块？凸出来一个小尖，一个小圆锥。那既然有凸出来了——我说有凸必有凹嘛——你突出这个东西，是不是一定有个地方得把它给接住？一定要把它接住。

A 选项是不是又凸出来一个？这两个凸怎么办？没地方，没法办，所以 A 就排除了。B 没问题，你凸出来这个地方，正好我这个地方凹进去了，OK，把你承接住了。所以 B 没有问题——先放在这，我没有办法确认它一定是对的，答案先放在这。

C 是不是错了？C 虽然有凹进来这个地方，哎，虽然我这个能承接住它了——但是它是不是又多出来一块？你确实能承接住它了，你又多出来一块，那多出这一块又没有地方去，那就没有地方能接住你了，所以 C 就错了。

D 怎么一看，没有地方接着。有凸必有凹，它没有凹。所以答案就是 B。这个题是比较简单，是不是直接秒杀了？

来看例二，这个题也 OK，就看能不能组成呗。

A 选项跟谁组成？A 选项是不是和第四个可以组成？很多同学对第四个有点疑问，来看一眼第四个。你看，第四个是跟这个 A 能够拼合的。

你注意啊，这个地方这个小的立体，它不在最边上。你看好了，它不在最边上，它其实就在中间。看好，它就是在中间，我把它补齐了，它就是在中间。如果说这个东西在边上，它应该是这么画的，这个地方会接上；但是你看这个地方和这边没有接上。注意啊，这个情况才是大家想象中的在边儿上的画法，它就是在中间。这个地方简单说一嘴，别理解错了。

好，那咱们再回过头来。B 选项跟谁？B 选项是不是跟这个三？C 选项跟谁？C 是不是跟这个一？那是不是只有第四个拼不成？第四个跟谁都拼不成，所以答案就是 D。就这么简单。

#### 图一复杂就看区别，必要时转一转

OK，再看一下例三。

这个题也比较简单。那简单在哪里啊？是不是大家一定要看——你不要被它上来这个东西吓住了。你说我不知道怎么做，这东西太复杂了。没有啊，你去观察它的区别啊，去观察 ABCD 的区别。

它们很明显的区别在哪？你看这个地方是不是有一个这个——这个地方有一个这个。你看，在原图中是不是这个地方有一个凸出来的小东西？然后这个地方是不是截去一块？是不是这两个东西很明显有区别？

那么你来看，在原图中，这个凸出来的东西和那个缺了一块的东西，它俩是不是在一侧呀？就他俩在同一侧。那你看 A 选项，这两个东西，一个在左边、一个在右边，A 就错了。B 选项，OK。C 选项，你看这两个是不是又变成两侧了？又错了。这很明显，A 跟 C 错了。

那就剩下 B 跟 D 了呗。你去观察 B 跟 D 的区别，告诉我 B 跟 D 的区别在哪里？B 跟 D 的区别是不是在中间这个地方？中间这个地方就很明显了：这个位置一定是 B。

> **提示**：图一复杂的时候不要硬去"想象怎么拼"，而是把四个选项摆在一起比——先找到那两个"很明显有区别"的部件，再看这个区别在四个选项之间是怎么摆放的，答案自己就浮出来了。看区别，一定要看。

那咱们最后来做一道。这个题有点难，虽然说好像是有点难，但其实呢也还行。

你看啊，他是不是让你把这些东西拼合在一起？让你去拼合组合成这个多面体。那我们来观察啊——1、2 是不是就差个 3？他是不是只让我们拿三个去拼？这个相对来说是不是没有那么复杂？就三个嘛，总比四个要好得多。

这个题很多同学第一个思维是数数量，对不对？但是数数量你会发现没办法，就是说选不出来。1、2、3、4、5，这是五个；1、2、3、4、5，这也是五个；都是五个，数数量数不出来啊。只能去看一看。

那你看看怎么拼呢？想想怎么拼。我这里给大家做出来了，看一看怎么拼的：把这个红色的把它转一个方向，在这呢；然后第二个图形这个蓝色的，你把它倒过来，把它立起来放在这啊；那是不是最后就剩下了这个绿色的。答案 A。

但是这个 A 是不是把它调过来了？注意啊，虽然这个 A 你是把它调过来了，答案就是 A。

> **易错点**：数数量是这类题的思维定式，但只要选项里各块的"个数"一样，数数量就必然失效。这时候只能转——把每一块转个方向，试着往那个缺口上凑。

这个题整体做下来，其实这个题是比较难的，但是不是说这个题难到不可做。你去转一转还是 OK 的。

你看好了，这是不是山东的题啊？那如果有山东的考生遇到这种题，还是要做。山东的行测和申论合起来满分是 200 分，山东的学子有能达到 187 分高分的那种同学，你想想他是多么的变态，那遇到这种题他依然是做得出来的。所以说山东的竞争环境是非常大的。作为山东的学子，这种题一定是要拿下来的——丢分不应该丢在这样的题里面。

### 类比推理：十个题，九个对，五到八分钟

那最后呢，咱们再讲一下判断推理的第二章——类比推理。

类比推理我们先从整体来看。大家来分析一下，这是我们的考试大纲。他说得很清楚，叫做"最为贴近或者相似的词"。

是不是他说"最为"啊？是不是有一个比较？是不是这里告诉我们，你选一个最好的。那可能说这个题里面有两个可能都还行，对吧？假设出现了两个都有道理的，那我们去选那个最有道理的、最好的一个。这个思维要有。

> **定义**：类比推理，就是在两个词或者三个词之间，找出逻辑关系最贴近的那一组。题干给两个词或三个词，选项要选和它逻辑相近的。

这种题在考试的时候一般是十个。我先说国考是十个，省考不好说，因为省考可能会有些缩减，有时候变成八个呀，有时候变成七个呀，不一定。那么国考是十个。

那这十个题，一般情况下的正确率和时间应该怎么分配呢？一般情况下，正确率我们应该对到九个左右。注意啊，这十个是比较简单的，绝对是我们拿分的。

对十个，错一个左右。什么题可能做不出来呢？一般两类题，我们不强求。

第一类就是和常识连在一起的。你像去年国考出了什么马蹄莲啊、蟹爪兰啊，这还好，其实可以分析出来。但如果出现了像什么法国对应了一个法兰克福，这种国家和城市的对应，如果你不知道，那这个题可能真就做不出来。把这种和常识联系起来的，可能你就错了，这个情有可原，那没有关系，因为没办法。

那还有一类呢，就是这个题可能出的就是你有点别扭。你确实找得很别扭，尤其在考对应关系的时候，有的时候比较别扭。多数有那么一个，你做起来会非常的别扭，就觉得怎么怎么觉得都不太好啊，不是足够清晰的，可能会有一个。所以这种题你可能会错一个。

> **结论**：类比十个题，最多错一个，要对上九个。允许错的就两类：一是和常识绑定的（比如国家与城市的对应，不知道就真做不出来，情有可原）；二是出得别扭、关系不够清晰的那一个。

花的时间大概多长呢？一般情况这十个题都比较简单，你看到有的时候一眼就看出来了。一般情况下十个题五到八分钟。你注意掐好时间，一般情况下五到八分钟，有的时候一般情况下五分钟就做完了。如果说你有一两个题，就是觉得好像能做出来、好像多想一想，但是绝对不能超过八分钟。要在五到八分钟之间，一定要把这个题搞定。

那这关于类比所用的时间和你的正确率，好。那我们来看一看大概的题型，就这三类。考试里面涉及到的这种关系有：语义、逻辑和语法。大概就三个。

OK，那我们先说第一个，语义关系。

### 近义词和反义词：先判关系，再挑唯一

语义关系其实比较好，比较简单。语义关系第一个就是近义词和反义词。

这两个词是近义词，这两个词是反义词。近义词里面，理想跟梦想是不是近义词？OK。那如果加一点难度，是不是就会出一些成语？比如锲而不舍和坚持不懈，算加了一点难度。

那这个地方如果出现成语了——注意啊，我们这个地方的成语和言语里面的成语不太一样。言语里面的成语考察的是两个比较相近的成语它们的细微差别；但在我们这个判断里面，它不会考你这些。不需要你掌握足够特别特别大量的这种成语，差不多你是一个正常的人、正常的语文水平、你正常积累的这些成语，差不多就够了。他不会考得太复杂，通过字面理解有时候差不多就能理解出来。

> **易错点**：为了类比去做大量的成语积累，是用不太到的。你平时做言语时积累的那些成语，在类比这里就足够了。

好，那我们看反义词：勇敢跟懦弱；言而有信跟言而无信。这有近义词，也有反义词。

#### 两个都像的时候，做二级辨析

有些时候，仅仅通过近义词和反义词，没有办法选出唯一的答案，可能最后会有两个答案都是近义词或者都是反义词。比如 A 选项和 B 选项，他俩都是近义词。

出现这种情况，大家要知道，一定是有一个更好的。那这个更好的我们如何去选择出来呢？需要进行一个二级辨析——就是我细分一下，再看看这两者之间有什么区别。

那这些区别一般是两种情况。第一类就是感情色彩：如果出现成语了，会出现褒义词、贬义词，还有中性词。词性上也有区别。还有一些呢是词语结构上的区别——你像"大小同意"，这个词本身你不知道有什么，但是你去观察，这里面有很多不一样的地方：

> 大跟小是反义词，同跟异是反义词，这个词的词语结构形成了两对反义词。

那你选的答案，是不是也应该是这样一种词性的结构？

好，我们一起来看，看几道就知道了。

来，快速做下例一。这题简单一看，精致和粗糙——它俩应该叫做反义词吧？这不是很明显的反义词？

看，A 河水跟海水不是反义词；B 山峰和深渊，各位同学，这很明显不是反义词——山峰跟深渊是两个不同的自然景观、自然现象，你不能说这是反义词。C 违背和遵守是反义词，没问题。D，怀疑的反义词是什么？是不是应该是信任？我怀疑你、我信任你。守信叫做信守诺言，不是我信任你，不是一个意思。所以答案就是 C。这是个简单的题。

例二：这个题是和成语联系在一起的，来看看选什么。

这个题错的人太多了，太多人选了第二个。来我们分析：大义凛然和卑躬屈膝，这两个是不是反义词？大义凛然，一身正气、有骨气；卑躬屈膝，就是没骨气。这是反义词。

那我反义词来看 A 选项：安分守己和好高骛远，当然是反义词吗？很明显不是。安分守己是什么？是恪守本分。那好高骛远是什么？是眼高手低——有很高的但不切实际的理想，我们叫眼高手低，那叫好高骛远。这俩不是反义词。

B 选项：穷奢极欲和节衣缩食，一个是奢侈，一个是节俭。你说这是反义词，没问题，OK，放在这儿。

C 选项：得心应手和百无一能。什么叫得心应手？我做事情得心应手，是不是很熟练？什么叫做百无一能？百无一能就是什么都不会。前面讲的是熟练，后面是说我什么都不是，他俩不是反义词，不是一个东西。

D 选项：持之以恒和虎头蛇尾。这没问题。持之以恒就是一直能坚持；虎头蛇尾就是开头做得很好，但是结尾很差，这就没有办法持之以恒。

所以 B 跟 D 这两个都可以啊。既然都是反义词，你没有办法去区分开，这个时候是不是就要进行一个二级辨析？

二级辨析关于成语的二级辨析，非常典型。就看褒贬义。大义凛然是不是就是一个褒义词？好词儿嘛。卑躬屈膝，这是一个贬义词吧。那你看褒贬义：B 选项穷奢极欲是不是一个贬义词？节衣缩食，大家告诉我，这是一个什么词？节衣缩食啊，这是不是一个中性词？说没有非常明显的感情倾向，这是一个中性词。D 选项持之以恒呢？褒义词呗。虎头蛇尾？贬义词吗？

答案就是 D。这就是我进行了一个二级辨析。关于成语的二级辨析，最重要的就是褒贬义和中性词。

> **提示**：一组成语先都是反义词怎么办？看感情色彩——题干那对是"褒义＋贬义"还是"贬义＋中性"？只有感情色彩的配对方式跟题干一致的那个，才留得下来。成语二级辨析里，褒贬义是最常考、也最好用的一条。

那我就不多说了。来，一起看一下例三。

这个有不少同学选了 C，我们来看一眼，这个答案是第四个。

生死跟存亡是不是近义词？生死就是存亡嘛，这是近义词。轻重跟缓急能是一样的吗？不一样吧——这个是物体的轻重，这个是水流的缓还是急，他俩不是一个意思。亲疏长幼，亲疏是什么？是我跟你的关系亲密还是疏远；长幼呢，就是长和幼嘛。完全不是一个意思。OK，这不是近义词。

C 真伪和对错，大家告诉我，什么叫真伪？是不是我说真的和假的？对不对，真伪是不是真假啊？我说这个钱是真的还是假的，那我能说这个钱是对的还是错的吗？真伪和对错能是一样的吗？不是吧，各位同学。真假和对错不一样，这个钱是真的还是假的，这个事情是对的还是错的，完全不一样。所以 C 是错的。所以答案就是 D 选项：好坏就是优劣嘛，好就是优，坏就是劣。所以答案就是 D。

> **易错点**：近义词题最爱踩的坑，是把"两个不同的维度"当成了同一组词——轻重（说的是物体）≠ 缓急（说的是水流）、亲疏（说的是关系）≠ 长幼（说的是辈分）、真伪（说的是真假）≠ 对错（说的是是非）。看到一对并列的词，先问自己一句：它们说的是不是同一件事的两个面？

#### 词里面还套着两对反义词：拆结构

刚才讲的呢就是我们所谓的近义词和反义词。说完这个之后呢，我们再来说一下下一个。

例四这个题简单一看啊——首先你告诉我，成败跟呼吸有关系吗？成败跟呼吸没关系，他俩没一毛钱关系。

但是呢这个题怎么看他们的逻辑关系是什么？但是你看啊，成跟败是不是一个反义词啊？这是不是要进行一个词语结构的划分，是不是你拆分它的结构？成跟败是反义词，呼跟吸也是反义词——这个里面内部是反义词。

那你看一看：A，拉跟扯是反义词吗？我拉你一下、我扯你一下，这是近义词吧；拖拽，我拖你一下、我拽你一下，这都是近义词是吧。A 就错了。

B，好跟歹，对吧？这个人不识好歹，是不是反义词？有始有终，始终是反义词吧？他们内部都是反义词。OK，B 没问题，放在这。

看一眼 C 吧——这里面的两个字不构成反义关系。

D，推一根箭推荐给你，推介是不是严格来说、详细来说可以叫做近义词？这也不是反义词吧。

是不是只有 B 里面的是反义词？只有 B 是反义词。

> **结论**：这道题不看两个词整体是什么关系，只看词"里面"的那一层结构——题干是"成／败 ＋ 呼／吸"，两层都是反义；只有内部两层都是反义的选项（B）才跟它同类。

好，这就关于词语结构的拆分。

### 比喻和象征意义：不用分得太清楚

那说完这个之后呢，我们再来说一下下一个：比喻和象征意义。

比喻和象征意义啊，其实我们不需要拆得很清楚。你说这个是比喻，那个是象征，不太需要。

那我们看一看啊，什么叫做比喻啊？月亮，有时月亮弯弯的像个镰刀，有时圆圆的像个玉盘。月亮跟玉盘是不是就是一个比喻的意思？玉盘是把月亮比喻成玉盘，这就是一个比喻。

那什么叫象征意义啊？松鹤是不是象征的是长寿啊？松鹤同春、松鹤遐龄，这是不是都是松鹤象征的是长寿？

那关于松鹤还有一个"驾鹤西去"。很多同学一想到松鹤，就想到了"驾鹤西去"这个词，但其实这个也依然是长寿的意思。因为这个鹤一直被形象地认为是对长寿有意义的，我们说它比较长寿，会跟神仙相伴。所以"驾鹤西去"是一种非常委婉的说法：就是你变成神仙了、羽化登仙了，驾着这个仙鹤走了，就是离世了。所以这个依然是仙鹤、是长寿的意思。

> **结论**：比喻和象征不用硬分——你不用去论证"月亮—玉盘"到底算比喻还是象征，会做题就够了。

好，我们来看例一。来，一起做一下。哎呀，好吧，我看一下各位同学里面选什么的都有啊，选得很有意思。

你看，沧桑跟白发，是不是白发象征了沧桑？没问题吧？选 A 的各位同学，你告诉我，酒窝能象征着清纯吗？王宝强也有酒窝啊，能象征清纯吗？无论这个人长得丑啊还是美啊，他可能都有酒窝啊，能象征清纯吗？逗我的吗？选 A 的那两个同学，自己反省一下啊。

B 选项没问题吧？乳牙可以象征着稚嫩。小孩子的牙，可以的。然后见状跟鲁莽没有关系。还有选 D 的同学，眼镜可以象征着博学吗？现在的小孩子，幼儿园就戴眼镜了，对不对？幼儿园就戴眼镜了，能象征博学吗？戴着眼镜就博学啊？选 D 的同学，啊哎呀，对吧。

所以这个题选 B。

来看一下例二。这个题应该都选 B 了吧？我看还有个别选 A 的同学——你这在逗我呢吗？七寸啊，你什么时候听过"七寸"这个词啊？那不就是打蛇打七寸吗？你还有其他地方听过这个词吗？没有吧。这里面肯定是七寸对应了要害，或者说对应了事物的关键。

是不一定从 B 跟 D 里选吗？然后这里什么对应了头绪啊？眉目——这事有眉目了；OK，这事有头绪了，没问题啊。那这事有脉络了，跟头绪有关系吗？脉络能象征着头绪吗？脉络是指着整体这个事情的脉络，它是一个从头到尾的脉络；头绪就刚有个开头。

所以脉络对应不了头绪，答案落在 B。

## 类比推理：语义辨析收尾，逻辑关系里的全同与并列
> 对应块：BLK26 | 覆盖分集：P13下 | 块标题（分集名）：《第七节——图形推理和类比推理——（三视图截面图立》

### 先别急着说服自己

这块开头还接着上一道题没说完。答案是 B，但选 A 的同学不少，而且一个个都挺能给自己找理由。

"七寸你跟我说对应一个尺度"——七寸是一种尺度，勉强也算对得上；线索是一种头绪，同样算对得上。听着好像都没毛病，可他把数字一换就露馅了：这地方改个六寸行不行？改个五寸行不行？改个三寸行不行？七寸之所以能和要害绑在一起，是因为它是个固定的象征说法，一换成"尺度"这个泛指的大类，就散了。象征一旦被拉成"具体的一个 : 宽泛的一类"，选项就再也撑不住。

"你肯定是拿七寸去对要害跟脉络呀"——他的意思就是这个。这些常识还是要有，七寸和尺度压根就不是一回事。

> **提示**：类比推理里，"能对上"和"对得上"是两件事。任何对应都要经得起把具体项换掉的检验——换了还成立，才叫关系；换了就散，说明你抓的只是字面。

选 A 的人真正的问题不是不会，而是把自己说服了，却没说服题目。

### 语义关系：一组练习捋清高频易混成语

#### 指鹿为马 : 颠倒黑白

第一道练习的题干是 指鹿为马 : 颠倒黑白。指鹿为马是赵高干的，本质就是颠倒黑白，近义词。顺着这个思路去找近义词：

A 项 师心自用 : 固执己见——近义词。师心自用、固执己见，再加一个刚愎自用，这三个是同一个意思，都是自以为是。这几个可以凑在一起记。

B 项 目无全牛 : 鼠目寸光——压根不是一回事。目无全牛说的是技艺精湛到不需要看整头牛就能下刀，熟得不能再熟；鼠目寸光说的是眼光狭小。一个夸手艺，一个贬见识。

C 项 不以为然 : 不屑一顾——也不行。不以为然是不认为是正确的，不屑一顾是鄙视、瞧不起。

D 项 最容易翻车：不孚众望 : 众望所归。众人期待叫什么，那叫众望所归；不孚众望是"孚"（让人信服）的反义，不能让人信服。它俩是反义词，不是近义词。

很多同学错，就错在把"不负众望"和"不孚众望"混成了一个词。不负众望是不辜负大家的期望，跟不孚众望完全是两码事。

> **易错点**：
> - 不负众望 = 不辜负大家的期望；
> - 不孚众望 = 不能让人信服；
> - 众望所归 = 众人期待。
> - 目无全牛 = 技艺精湛；鼠目寸光 = 眼光狭小。
> 读音只差一个字，意思差着一个方向。

答案是 A。他说这本来应该算基本语文常识，OK，但错误率高得有点吓人了。

#### 邯郸学步 : 东施效颦

第二道：邯郸学步 : 东施效颦。都是模仿别人、模仿不成、效果非常差，近义词。这一题正确率比较高。

A 项 如法炮制 : 依样葫芦——都是照着别人做，近义词，没问题。
B 项 循规蹈矩 : 步人后尘——不对。循规蹈矩是规规矩矩遵守规则，步人后尘是走了别人的老路。
C 项 滥竽充数 : 鱼目混珠——都是以次充好、以假乱真，近义词。
D 项 兔死狐悲 : 狗仗人势——不是一回事。兔死狐悲是为同类的不幸感到悲伤；狗仗人势不用解释了。

A 和 C 都是近义词，那就上二级辨析看褒贬：邯郸学步和东施效颦都是贬义词；A 项如法炮制、依样葫芦都是中性词；C 项滥竽充数、鱼目混珠都是贬义词。贬义对贬义，答案 C。

#### 陈词滥调 : 老生常谈

第三道：题干 陈词滥调 : 老生常谈。老生常谈嘛，没有什么新鲜的了，近义词。

A 项 按部就班 : 循序渐进——近义词，都是一步一步来。
B 项 博闻强识 : 见多识广——近义词，都是见识广。
C 项 见义勇为 : 助人为乐——不是近义词。见义勇为是助人为乐的一种，是种属关系，不能划等号。
D 项 八面玲珑 : 面面俱到——近义词。

一级都过了，再上二级辨析看感情色彩：陈词滥调是贬义，老生常谈是中性；A 项两个都是中性；B 项两个都算褒义，肯定不是"贬对中性"；D 项八面玲珑是贬义——形容一个人八面玲珑，不是个好词儿；面面俱到则是中性，说一个人面面俱到，好的坏的都往上靠。所以只有 D 前面贬义、后面中性，答案 D。

> **易错点**：见义勇为 ⊂ 助人为乐，是包含关系不是并列。八面玲珑偏贬，面面俱到居中，看着都是"面面"，感情色彩不一样。

#### 象征类：含义分不开，就看词性

第四道练的是象征。

A 荆棘 : 困难——没问题，荆棘密布，象征困难，是比喻。
B 布衣 : 学生——不对，布衣象征的是百姓。
C 心腹 : 信任——不对，心腹比喻的是信任的人，不是"信任"本身。
D 智库 : 束缚——没问题，智库是满清十大酷刑里的一种刑具，象征束缚。

排掉 B 和 C，剩 荆棘 : 困难 和 折柳 : 惜别 两个候选。含义上已经分不出来了，再看形式：荆棘是一件事物、一个名词（荆棘密布），智库是刑具，也是名词；折柳是一个动作。名词对名词更工整，所以选 智库 : 束缚。

借这个题，他把类比推理的判断顺序讲了一遍——这是整节最该记住的一条：

> **结论**：类比推理一定是先看含义，用含义来确认类比关系。含义确认不了、需要二级辨析了，再去看形式，也就是词性、结构这些东西。含义优先，形式垫后，绝不能一上来就比词性。

> **易错点**：这个题里 A 和 C 压根不需要看形式——它们的含义直接就错了，轮不到词性上场。

#### 没有逻辑关系，就去比词性和结构

第五道更怪：古为今用 : 天罗地网，这俩没有逻辑关系。但硬看形式还是有规律——两词都是由反义词拼起来的，古/今、天/地。

既然整体看不出规律，就把这个词性结构划分开来看：A 项里有一半"里外"是反义、没问题，但另一组"因"和"圆"并不是反义关系，排除；B 项的左右、深浅都成立，先留着；C 排除。答案 B。

### 逻辑关系：全同

语义关系讲完，进入逻辑关系——这是类比推理里最重要的一节。第一个逻辑关系叫全同。

#### 全同就是能写等号

全同就是完全相同。在整个逻辑关系里，A 集合和 B 集合一模一样，A = B，A 就是 B，B 就是 A。老鼠就是耗子，耗子就是老鼠。浪漫就是罗曼蒂克（romantic），罗曼蒂克就是浪漫——这是唯一一个可以直接写等号的关系。

#### 四季与春夏秋冬

题干 四季 : 春夏秋冬。春夏秋冬等于四季，完全相等，全同。这道题大家做得很好。

A 情绪 : 喜怒哀乐——这能换成等号吗？不能，情绪太多了。
B 颜色 : 赤橙黄绿青蓝紫——也不对。现在的颜色比这七个多得多，配色几百上千都配得出来。
C 一天 : 早中晚——选 C 的同学我问你：上午算啥？下午算啥？后半夜算啥？早中晚涵盖不了一天。
D 四方 : 东南西北——没问题。四方在古代指的就是东南西北，想确认的可以去翻《辞海》，上头写得很清楚。

答案 D。

#### 五行与金木水火土

练习：五行 : 金木水火土，全同，答案是 D。

A 四书五经——四书是《大学》《中庸》《论语》《孟子》；五经是《诗》《书》《礼》《易》《春秋》，不是《大学》。这些都要知道，考试会直接考。
B 五音 : 宫商角徵羽——五音里那个徵字特别容易写错，写成"止"就废了。
C 五色 : 青黄赤白黑——中国古代说的五色是青、黄、赤、白、黑，不是青黄赤白绿。
D 五味 : 酸苦甘辛咸——对，这五味出自《黄帝内经》。

> **提示**：这一组题是把类比和常识焊在一起的。常识储量不够，就只能靠排除硬猜，错误率自然高。

顺带说一句，第一版讲义里"五味"那行我打错了一个字，后来会改掉，以改后的讲义和 PPT 为准。

#### 亲属称谓：全同还是对应

另一道：岳父就是丈人，全同。舅舅和外甥是对应关系——你是我的舅舅，我是你的外甥。姨妈和婶婶不一样：姨妈是母亲的姐妹，也就是你妈妈的姐姐和妹妹；婶婶是你叔叔或伯父的老婆。伯父和侄子也是一段对应关系，跟舅舅和外甥一个道理。所以答案是 祖母 : 奶奶，奶奶就是祖母。

讲到这儿他没绷住：家庭关系搞不清的同学回去问你爸问你妈——你们家你管你外婆叫祖母啊？你祖母你管她叫外婆？逗我呢。这些关系不能乱。

### 逻辑关系：并列

生和死是不是并列？都是一种生存状态。苹果和香蕉并列，都是水果。黑和白并列，都是颜色。确认了——并列关系，就是两者属于同一类东西。

但并列还要再分成两种：矛盾关系和反对关系。

#### 矛盾：不是生就是死

设一个大集合，人的生存状态。不是生，就是死，没有第三种。"虽生犹死"——那也是生；"半生不死""半死不活"——人家也还活着呢。要么生，要么死，没有中间地带，这就叫并列里的矛盾关系，记成"并矛"。

#### 反对：黑与白之外，还有别的颜色

黑和白绝不是反义词，它们都是一种颜色。设一个更大的集合叫"颜色"，里面站着黑色、白色，还有绿色等等。除黑色和白色之外，还有其他颜色——这就叫反对关系，并列里的反对。苹果和香蕉同理，是"水果"这个大集合里的反对。

```text
并列关系之一：矛盾关系（"并矛"）

  [ 人的生存状态 ]              <- 整个大集合
      |- 生
      `- 死

  不是生就是死，没有第三种状态  =>  矛盾关系


并列关系之二：反对关系

  [ 颜色 ]                       <- 更大的大集合
      |- 黑色
      |- 白色
      |- 绿色
      `- ……（红、黄、蓝……）

  黑与白之外还有其他颜色        =>  反对关系
```

读图就是一句话：矛盾是把大集合分尽了（不生就是死），反对是这两个只占大集合的一部分（黑、白之外还有绿）。

很多同学会把矛盾关系直接当成反义词。生死是反义词吗？对称和不对称是反义词吗？你觉得是就是，先按反义词去做；做出来了就选，做不出来，回过头来再想并列里的矛盾。两者不冲突，是先后顺序的问题。

> **易错点**：矛盾与反对判不清，是这一节错误率的主要来源。原因就一个——没把"除了这两个，还有没有第三个"这个问题问到底。

#### 例一：开与关

题干 开 : 关。第一反应"这不是反义词吗"，没错，先按反义词看。

A 痛苦 : 快乐——就算当反义吧。情绪里除了痛苦和快乐还有一大票：喜怒哀乐、忧思悲恐，多了去了，这是并列里的反对。
C 盈利 : 非盈利——除了盈利以外，其他都叫非盈利。一分钱没挣，那是非盈利；持平呢？持平也是非盈利。盈利和非盈利占满了整个集合，是矛盾。
D 工作 : 休息——工作跟休息能叫反义词吗？不工作就是休息？我去打健身，是工作还是休息？我去打篮球呢？你们现在听我在这儿直播，是工作还是休息？健身、打篮球、学习，哪一样都不落在这两头。

答案是 C。

> **结论**：题里同时出现"不"字或"非"字的一对词，合起来一定是并列里的矛盾关系。对称/不对称是这样，盈利/非盈利也是这样——因为带了这个字，它已经把整个集合占满了。

#### 例二：往里带，顺序反了一定错

题干是"往里带"的关系，看到这种题就往里带上想。

A 舞台演奏钢琴 : 乒乓球在球台上打——你说这逻辑也说得通，可顺序反了。钢琴是在舞台上，乒乓球是在球台上。顺序反了一定错。
B 手风琴 : 钢琴——都是琴；除了手风琴和钢琴，还有其他的琴，所以是并列里的反对。足球和乒乓球同理。没问题。
C 音乐家演奏钢琴 : 运动员打乒乓球——顺序还是反的。题干是物品在前、场所在后，C 是人在前、事在后。
D 琴声 : 钢琴 / 喝彩 : 乒乓球——钢琴有琴声，乒乓球对应的是喝彩，不合适。

答案 B。

> **易错点**：逻辑方向反了就是错，"听着也说得通"救不了它。

#### 例三：人民币、美元与欧元

题干 人民币 : 美元 : 欧元，都是各国的货币单位，并列，属于并列里的反对——所有货币单位这个大集合里，还有很多别的成员。

A 海鲜 : 海鸥——选 A 的有吗？没有吧，它俩没法并列。
B 贵州 : 杭州——贵州人家是个省，杭州是个省会城市，常州是个地级市，并列不了。选 B 的同学，你不怕人家贵州人来打你啊？
D 宽恕 : 品性——宽恕跟品性有什么关系？诚信才是一种品性。

答案 C。

#### 练习：动与静

一看"动 : 静"，很多同学上来一想：老师，这是反义词吧。反义词做不出来，那就往并列的矛盾上想——不是动，就是静；我们不是在动，那不是动就是静。它们都是一种状态，是并列里的矛盾。

A 东 : 西——方向里除了东西，还有南北、东南、西南，是反对。
B 贫 : 富——除了贫就是富吗？小康算啥？不穷不富的中产阶级算啥？是反对。
C 黑 : 白——除了黑和白，还有赤橙黄绿青蓝紫，是反对。
D 取 : 值——除了取就是值，是矛盾。（取值之外还有点、线、面、素、角。）

答案 D。

#### 练习：番茄与蹴鞠

A 番茄来自美洲 : 蹴鞠来自中国——顺序反了。
B 番茄炒饭 : 健身蹴鞠——没有逻辑关系。
C 番茄是一种植物 : 人类是一种蹴鞠——不对。
D 番茄 : 白菜，都是蔬菜，并列里的反对；篮球 : 蹴鞠，都是运动，也是并列里的反对。没问题。

答案 D。他还多补了一层：番茄是国外的，篮球也是国外的；蹴鞠是中国的，白菜应该也是中国的——不过这层用不上，"不用想到这么深"。

#### 练习：羌笛与钢琴，为什么是更贴近的那个

A 羌笛 : 钢琴（都是乐器，并列里的反对）: 马褂 : 长袍（都是服饰，并列里的反对）——逻辑没问题。
B 胡琴 : 钢琴 : 马褂 : 西服——也都是并列里的反对，没问题。
C 京剧 : 钢琴——京剧是个剧种，你说京剧跟昆曲放在一块可以，你不能把一个剧种跟一个乐器放一块。
D 琴键 : 钢琴 : 唐装 : 马褂——琴键是钢琴的组成部分，这条成立；可马褂是不是唐装，他自己也不确定（"黄马褂"听着像是清朝的），就算假设马褂是唐装的一种，那也是种属关系，跟前面的组成关系对不上。（组成关系和种属关系，下一节讲。）

A 和 B 都没毛病，那就上二级辨析，看哪个更贴近：胡琴是中国的，钢琴是西方的；马褂是中国的，西服是国外的。都是"中国—国外"的对照，所以 B 更整齐。

> **结论**：类比推理里，逻辑关系对上了只是入场券，最后一定要找一个更好的、更贴近的。A 不是不行，是 B 更好。

#### 两条顺序，记牢就够

```text
类比推理的判断顺序

  [ 第一步：比含义 ]
        |
        +-- 含义能确定关系 --------> 直接定答案
        |
        +-- 含义确定不了
                |
                v
  [ 第二步：比形式 ]
     词性 / 结构 / 感情色彩
                |
                v
  [ 找一个更好的、更贴近的 ]
```

含义优先，形式垫后；最后一步，"更好"优先于"对就行"。
