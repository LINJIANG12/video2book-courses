## 且、或与组合排列：把题面翻成逻辑语言
> 对应块：BLK38 | 覆盖分集：P20上 | 块标题（分集名）：《第十一节——逻辑判断—组合排列—刘文超》

昨天我们把翻译推理里的前推后和后推前讲完了，今天把剩下三块拼图补齐：且关系、或关系、要么要么。

这三个词看着眼熟，但它们到底差在哪、能推出什么，差别一点不小。而且还有一个特别容易踩的坑——看到"虽然……但是……"就以为是转折，结果它其实是个且关系。先把概念和词儿理顺，再上题。

### 三种连接词，三种真假格局

#### 且关系：两个都得成立

且关系就是 A 且 B，两者同时成立。

比如"物美并且价廉"——你得既物美，同时又价廉，这叫且关系。再比如"超哥长得帅并且有才华"，既帅又有才华，也是一个样。记住这四个字：**同时成立，缺一个都不行**。

#### 或关系：至少一个成立

或关系就是"或者……或者……"，至少有一个成立。

我说这个周六或者周日休息，这句话里包含几种情况？我们数一数：

- 我周六休息了；
- 我周日休息了；
- 我两天都休息了。

**三种情况，至少有一个成立**。你也可以两个都成立，这就是或关系——"你或者他，或者它，或者两个都可以"。

> **定义**：或关系展开成三种情况（只 A、只 B、A 且 B），是三个里面至少中一个。

#### 要么要么：只能有一个成立

最后是"要么……要么……"。比如要么小红是我老婆，要么小丽是我老婆，这里面只能有一个人是我老婆。

（虽然可能有些人心里是这么想的，但是不行啊。）

要么要么只有两种情况：要么小红，要么小丽。

> **易错点**：**要么要么 ≠ 或关系**。或关系允许两个都成立，要么要么只允许恰好一个成立。题干里"只能去一个""必须有且只有一个"这类说法，对应的都是要么要么，不是或。

| 关系 | 逻辑含义 | 展开成几种情况 |
| :--- | :--- | :--- |
| 且关系 | A、B 必须同时成立 | 全中 |
| 或关系 | A、B 至少有一个成立 | 只 A、只 B、A 且 B |
| 要么要么 | A、B 恰好一个成立 | 只 A、只 B |

### 认词不认语气

概念说完，就得解决一个非常实际的问题：**卷面上怎么认出它**。

#### 且的等价关联词

| 关系 | 等价关联词 |
| :--- | :--- |
| 且 | 且、并且、和、既……又……、不仅……而且……、虽然……但是…… |
| 或 | 或者、……和……至少一个 |
| 要么要么 | 要么……要么……、……和……只有一个 |

物美和价廉、既物美又价廉、不仅物美而且价廉——全是且关系。

最后一个"虽然……但是……"，很多同学一看到就头疼：这不是转折吗？这怎么能是且关系呢？

来看两句：

- 虽然我很丑，但是我很温柔；
- 虽然你很好，但是我不能和你在一起。

这是一个转折关系没错。但你把"丑"和"温柔"拎出来看——它们是不是同时存在的？"你很好"和"我不能和你在一起"，是不是同时存在的？**既不丑且温柔、既好且不能在一起，转折的是语气，不是事实上的并存关系。**

> **提示**：转折词在逻辑上只表示"两件事都有，但重点在后面那个"，它并不否定前一件也成立。所以"虽然……但是……"照收进且关系，别因为语气变了就改判。

而且你要记着，**且的等价关联词是最多的**，考场上辨认的时候不用慌——多练就熟了，一做题你自然就认得出来。

#### 或的等价关联词

最直接的就是"或者"。另一种说法是"……和……至少一个是"，比如"周六和周日至少有一天休息"，跟"周六或周日休息"完全等价。

#### 要么要么的等价关联词

"要么……要么……"，还有一种绕着弯的表述——"……和……只有一个"。比如"小红和小丽只有一个是我老婆"，就是要么小红要么小丽。

### 或关系怎么翻译：否一推一

或关系真正开始干活的，是它那条专门的翻译规则。

#### 正着推：否定一项，拿到另一项

**或关系为真的时候，否定一项可以得到另一项**，这叫"否一推一"。

我周一或者周二上班。现在已知：我周一这一天没有上班。能推出什么？各位同学，周一或者周二上班这句话是真的，那我周一没上班，那我肯定周二上班了。

这就是否一推一：我否定一个，能推出另外一个。

> **结论**：或关系的翻译写法是 `A 或 B`，用的时候优先想否一推一——否定其中一项，推出另一项。注意**否定的是靠后那一项**（否后得前），这一点后面例二还会专门强调。

#### 前提：或关系必须为真

这里有句话叫"或关系为真"。什么意思？难道或关系还能为假吗？

想一想，**它当然可以为假**。所以否一推一能不能用，取决于这个"或"是不是真的成立。看这个题：

> 如果这道题的答案是 A 或 B，那么我就错了。

现在我已知：这道题的答案不是 A。能不能推出答案一定是 B？

不能吧？还可能是 C，还可能是 D，还可能是 E，还可能是 F。但这句话也没问题啊——正确答案就算真是 C，这句话照样成立。

为什么否一推一在这儿就错了？因为**这个"或"在"如果"里面**。"如果"后面的东西未必是真的，它只表示"在某个条件下会怎样"，而这个条件本身没告诉你成不成立。

#### 那个"如果"到底坑在哪

把"如果"拿掉再说一遍。

我不说"如果"，我直接说：这道题的答案是 A 或 B。这就是一句题干，这句话是真的。然后问，如果不是 A，能不能推出是 B？可以。

一个"如果"在不在，否一推一能不能用，完全是两回事。

> **易错点**：**"或"如果出现在"如果……那么……"这个条件句里，它未必为真，此时不能用否一推一**。做题时先确认这个"或"是真实发生的事实陈述，还是藏在一个假言条件里。

### 例一：一个或关系串起整条链子

第一道例题，四句话，我们一句一句翻译。

原文说的是：被告**有罪或者**是疯子；有罪**则**被处死；是疯子**则**永远接受住院治疗；证据不够有力**则**不应该被处死。

翻译成符号：

```text
①  有罪 或 疯子                       （或关系）
②  有罪 → 处死                        （前推后）
③  疯子 → 住院治疗                    （前推后）
④  否证据有力 → 否处死                （前推后）
```

翻译完没有问题，那就往下推。已知：证据不够有力。

```text
已知：否证据有力
  │
  │ ④ 原样
  ▼
否处死
  │
  │ ② 逆否等价（否后推否前）
  ▼
否有罪
  │
  │ ① 或关系否一推一，否定"有罪"
  ▼
疯子
  │
  │ ③
  ▼
永远接受住院治疗            → 选 C
```

一推就直接出答案了，说明逻辑非常清晰。整个过程其实只用了一个或关系、一个前推后、一个逆否等价。

> **结论**：这类题你只要会翻译就一定能拿分。翻译对了，推理就是水到渠成的事。

### 例二：逆着目标往回推

第二道题条件多一点，但不多。原文是：

> 小钱教德语，那么小孙不教俄语；
> 小李教德语或者小钱教德语；
> 如果小孙不教俄语，那么小赵不教法语；
> 小赵教法语或者小赵不教英语。

问题问：哪项为真，可以推出小李教德语。

翻译：

```text
①  小钱教德语 → 小孙不教俄语
②  小李教德语 或 小钱教德语            （或）
③  小孙不教俄语 → 小赵不教法语
④  小赵教法语 或 小赵不教英语          （或）
```

想推出"小李教德语"，得用哪句？②。要拿到前面的"小李教德语"，就把后面那项否定掉——**小钱不教德语**。

那"小钱不教德语"哪来的？① 逆否：

```text
① 逆否：  小孙教俄语 → 小钱不教德语
  │
  └─ ③ 逆否：  小赵教法语 → 小孙教俄语
        │
        └─ 合起来能落到 A、D 这类选项上 → A、D 错
```

最后只剩 C，再回验一遍 C。验 C 只能拿最后一句下手：④ 是"小赵教法语 或 小赵不教英语"，验证的办法是假设它不成立——假设小赵不教法语，用或关系否一推一，否定后面那一项，得到小赵不教英语，前后不冲突，所以 C 站得住。

> **提示**：**否一推一否定的是或后面那一项**。④ 的后面写的是"小赵不教英语"（否周英），你把它否定掉，得到的是"小赵教英语"。这个方向千万别看反了。

整条链子一环套一环，每一句都不是白给的。你只要把它翻译出来，从头到尾全部串起来就完事了。这种题现在觉得绕、花时间，是因为还不熟练；慢慢就好了。

### 德摩根定律：否号放进去，且变或或变且

上面是把关系翻译成正向箭头，接下来是它的另一半——**否定**。翻译推理里关于否定的部分，就叫德摩根定律。

#### 且关系的否定，从三种情况数起

我还是取"物美价廉"这个例子：物美**且**价廉。这是一个且关系，现在我要否定它，怎么否定？

你不能说"这句话是假的"，得落到具体的情况上。否定一个且关系，有三种方式：

- 不物美；
- 不价廉；
- 既不物美且不价廉。

这三种情况都是"物美且价廉"的否定。

但你把这三种合起来看——**是不是就等于"不物美或者不价廉"**？

不物美，或者不价廉：它包含"只不物美"、"只不价廉"、"既不物美又不价廉"，正好就是那三种情况。

所以 `A 且 B` 的否定，就是 `否A 或 否B`。

#### 或关系的否定，只有一种情况

再看"周一或者周二上班"。它的否定是什么？怎么能说明这句话错了？

只有一种情况：**周一没上班，并且周二也没上班**。

两边都不成立，才谈得上"周一或周二上班"是假的。所以 `A 或 B` 的否定，就是 `否A 且 否B`。

#### 一句话记住它

| 原式 | 否定后 |
| :--- | :--- |
| A 且 B | 否 A 或 否 B |
| A 或 B | 否 A 且 否 B |

把这两个放在一起看，你会发现它们**互为否定**，规则就一条：

> **结论**：**否号放进去，且变或、或变且。** 且关系加个非号就变成或关系，或关系加个非号就变成且关系，两个命题互为否定。

### 德摩根上场：资产荒那一题

德摩根什么时候用得上？当题里给的是被否定的且关系，而选项是以或关系的形式出现的时候——它就是解题的那把钥匙。

例三是一个典型的翻译推理。原文是：

> 企业信用风险上升和有效信贷需求不足，就会陷入资产荒。
> 上述论证为真，银行没有陷入资产荒。

第一句前面是 A 且 B，后面推出一个结论，是前推后：

```text
（信用风险上升 且 有效信贷需求不足） → 陷入资产荒
```

已知"没有陷入资产荒"，是**否后**。逆否等价，否后推否前：

```text
否陷入资产荒
  │  否后推否前
  ▼
否（信用风险上升 且 有效信贷需求不足）
  │  德摩根：否号放进去，且变或
  ▼
否信用风险上升 或 否有效信贷需求不足
```

展开就是：**信用风险没有上升，或者有效信贷需求没有出现不足**——这就是选项 A。其他选项都跟这个结论对不上，答案就是 A。

一整个后推前加一个且变或，就结束了。

### 三道练习

上面是把规则讲完，下面三道题练手。都是同一套动作：**先去翻译，再顺着推**。

我再多说一句：这种题你**不要老用自己的脑子去想去猜**。你用自己的逻辑去琢磨"这个应该是这样吧"，没有用——这叫翻译推理，你只需要把整个翻译翻译出来，再按翻译的规则推就行了。真要说有用，是高手才能用；普通人脑容量有限，安安心心地按流程做就行。

#### 苗苗喜欢民族舞

> 苗苗喜欢民族舞。她们班学生或者喜欢拉丁舞，或者喜欢芭蕾舞。喜欢民族舞的都不喜欢芭蕾舞。
> 以下哪个为真，可以推出苗苗喜欢街舞？

就一个或关系，很简单。翻译：

```text
①  苗苗喜欢民族舞
②  拉丁舞 或 芭蕾舞                （或）
③  喜欢民族舞 → 不喜欢芭蕾舞
```

苗苗喜欢民族舞，由 ③ 得苗苗不喜欢芭蕾舞；由 ② 的否一推一，否定后面那一项，得苗苗喜欢拉丁舞。

```text
① 苗苗喜欢民族舞 ──③──→ 不喜欢芭蕾舞
                            │
                            │ ② 或关系否一推一
                            ▼
                     喜欢拉丁舞
```

看选项。A 说"舞蹈班**有些**喜欢拉丁舞的学生也喜欢街舞"——"有些"不是一定，推不出来。B 说"喜欢拉丁舞的**都**喜欢街舞"，这就是前推后，苗苗喜欢拉丁舞，自然苗苗喜欢街舞。

答案 B。

#### 衣服不搭无所谓，基金不买你心碎

> 衣服不搭无所谓，基金不买，你心碎。
> 小方不同意上述说法。以下哪项是小方的看法？

先看这两句话是什么关系。这里面的逗号**是一个连接**，把前后连起来了，所以它是一个 A 且 B：

```text
（衣服不搭 → 无所谓） 且 （基金不买 → 你心碎）
```

小方不同意，就是对这个且关系做了否定。上德摩根：否 A 或否 B。

- 否 A：衣服不搭**有所谓**；
- 否 B：基金不买**你不心碎**。

答案就是第二个。就是一个且关系的否定，德摩根定律一下，答案直接就出来了。

#### 权钱交易与真正的动力

> 如果有人可以通过资源炒作暴富，或者通过权钱交易腐败发财，那么人们的创新就不会有真正的动力。

前推后，翻译成：

```text
（炒作暴富 或 权钱腐败） → 否动力
```

A 说"有人可以通过炒作暴富，就能权钱腐败"——或关系前推后，没这么推的，肯定不行。B 说"没有人可以权钱腐败，就会有真正的动力"——题干是前推后，B 写成了否前推后，推不出来。C 说"人们创新没有真正的动力"能推出什么——肯后，肯后啥也推不出来，后往前是推不动的。

答案 D。D 说人们具有真正的动力。动力是后件，否后推否前，否定后面那个或关系：

```text
（炒作暴富 或 权钱腐败） → 否动力
        │  逆否
        ▼
动力 → 否（炒作暴富 或 权钱腐败）
        │  德摩根：或变且
        ▼
   否炒作暴富  且  否权钱腐败
```

否 A 且否 B 是且关系，D 选项只说了"没有人可以通过权钱交易腐败"这一支。**且关系的两支都成立，只说其中一支当然也对**，所以 D 没有任何问题。

很多同学在这里看不明白，我再补一句：否 A 且否 B 能不能推出否 B？物美且价廉能不能推出物美？能，没问题吧。那么否 A 且否 B 能推出否 B，当然也没问题。所以动力推出否权钱腐败，成立。

### 这一块内容到此为止

最后给翻译推理做个整体收口。

这一类题认的就是"如果、那么、只有、才"这些典型的逻辑关联词，解题思路就一句话：**先翻译，后推理**。

我讲过的内容是这么几块：前推后、后推前、逆否等价、且关系与或关系，最后是德摩根定律。这些已经占到我们整个考试里翻译推理的 95% 及以上，应付公务员考试的翻译推理足够了。

你问讲得全不全？**没有。** 我只是把经常考、考得太多的先讲完了。翻译推理在国考里一般最多考一道，十个题里就一道，而且最近好几年几乎相当于没考。

那为什么还讲这么多？因为翻译推理是我们后面所有要学内容的基础，我才在这个地方用了这么大的篇幅。

至于我没讲的那些——不是说不一定考，是不重要。以后你自己做题时碰到什么乱七八糟、完全没见过的说法，如果你有较真的精神想弄清楚，那就自己百度一下、自学一下就行；我在这里再花大篇幅讲太多没有用，因为几乎不怎么考。

所以翻译推理并没有大家想象的那么难。你把这些需要的东西慢慢整理整理，把例题好好做一做，做得多了自然就找到感觉了。到考试的时候你会很喜欢这种题——因为你知道这种题一旦出现，大概率就是能拿分的。

### 组合排列：改了个名字的老朋友

翻到下一节，组合排列，也叫排列组合。

在真正的逻辑学里，它其实叫**朴素逻辑**。之所以改这个名字，是因为我们没必要搞那么专业，你看我用"组合排列"这个直白的说法，你一看就知道这题大概是排列组合，学起来也省劲。

#### 题目长什么样

组合排列的题目特征非常固定：

> **题干给出两组及两组以上的对象，然后给出几组对象之间的关系**，让我们把对应关系找出来。

举个例子。题干给了甲、乙、丙三个人，又给了北京、广州、杭州三个地点，然后说这三个人分别对应这三个地方，谁来自哪里我不知道。接着又给了一些关系，比如第一个条件说：甲比杭州人的年龄大。

这题问什么？找一找谁来自哪里。

第一句话能得出什么结论？**甲不是杭州人**——甲比杭州人年龄大，那甲自己当然不能是杭州人。既然甲不是杭州人，就可以去排除，选项里"甲是杭州人"的那个选项直接就错了。

这就是第一种方法：排除法。

#### 排除法：读一句排一句

来两道实际的。

第一道，四个人拿到了前四名：

> 赵、钱、孙、李四个人获得了前四名。孙先生和李先生经常打篮球。第一名和第三名是在这次比赛中刚认识的。第二名不会骑自行车，也不打篮球。

读一句排一句地来：

```text
条件①  孙先生和李先生经常打篮球
        → 单独看这句，什么也排不掉

条件②  第一名和第三名是比赛中刚认识的
        ①② 合起来 → 第一名、第三名不可能是孙和李
        → 排除掉一个选项

条件③  第二名不打篮球
        → 第二名既不是孙，也不是李
        → 排除 B、D

                                              答案 A
```

整道题只用了最朴素的排除法就能做完。当然这道题非常简单。

第二道是六个人下乡挂职，人事部、组织部、办公室分别提要求：

> 人事部：甲和丁两个人只能去一个。
> 组织部：若丁不去，则戊也不能去。
> 办公室：甲、丙两人中必须留下一个。

```text
第一句  甲和丁只能去一个
        → "丙和丁都去" ✗，排除 A

第二句  若丁不去，则戊也不能去
        → 前推后：否丁 → 否戊
        → 逆否等价：戊去 → 丁一定去
        → "戊去了、丁没去" ✗，排除 B

第三句  甲、丙两人中至少留下一个
        → "他们仨全去了" ✗，排除 C

                                              剩 第四个
```

又是读一句排一句，答案就出来了。

顺便提醒一句：组合排列出简单题会非常简单，出难题会非常难。刚才是简单的，一会儿会看难的，我们由简入难。

#### 代入法：把选项塞回题干

第二个方法是代入法。

**排除和代入可不一样**：排除是读一句、排一句，挨着题干的句子走；代入法是**把选项直接代入题干中去验证**。

什么时候用哪个？记住这条：

> **结论**：**题干的条件是确定的，优先用排除法；题干的条件不确定，尝试代入法。**

有些同学对这句话有点懵——什么叫条件确定？什么叫条件不确定？拿个例子你就知道了。

#### 三个人的预测只对了一半

> 三个人一起猜四个班的出场顺序。甲说一班第一个出场、二班第三个出场；乙和丙的预测分别落在三班、四班、一班上。结果发现，他们的预测都只对了一半。

你听清楚这句关键条件：**"他们的预测都只对了一半"**。

这就是题干条件不确定的典型。你手里的信息只有一半是对的，我怎么用你？我告诉你"A 班第一个"对不对，我根本不知道。既然读一句排一句排不动，那就把选项一个个代进去验证。

怎么代？先把 A 选项代进去，看看他们每个人是不是都只预测对了一半。先看甲：

```text
代入 A 选项
  │
  ├─ 甲：一班第一个出场  → 错
  │       二班第三个出场  → 错
  │       （前半句就错了）
  │
  ├─ 乙：……
  └─ 丙：……
```

甲这一关就没过去。接下来照这个办法，把乙、丙两个人的两句预测也逐个对过去，A 能不能站住脚就一目了然了。

组合排列的两种基本功就是这两样：条件确定用排除法，条件不确定用代入法。先把这两把基本功练熟，剩下交给熟练度。

## 组合排列的破题思路：代入排除、最大信息与列表
> 对应块：BLK39 | 覆盖分集：P20下 | 块标题（分集名）：《第十一节——逻辑判断—组合排列—刘文超》

### 把选项代进题干里，一个一个试

咱们先把刚才那道题收个尾。甲、乙、丙三个人，各自预测各班的出场顺序，题干里有一句话是死规矩：**他们的预测都只对了一半**。

什么叫"只对了一半"？预测是"一班第一个出场"这样一整句话，前半句后半句连在一起。什么叫"对一半"，就是这一句话里对了一截、错了一截。

A 选项带进去。甲说"一班第一个出场"——一班第一个出场的不是甲，错；甲说"二班第三个出场"——出场的也不是甲，错。整句话全错。既然是全错，那就不是"只对一半"，A 当场出局。

再看 B。甲说"一班第一个出场"，错；甲说"二班第一个出场"，错。前半句错了。乙说"三班第一个出场"——三班第一个出场还真是乙，对；乙说"四班第二个出场"，出场的不是乙，错。后半句也错了。整句话还是全错，B 一样出局。

A、B 都死了，那就只剩 C。带进去再看：甲"一班第一个出场"错、"二班第三个出场"对；乙"三班第一个出场"对、"四班第二个出场"错；丙"四班第二个出场"对、另一个错。每个人都是一半一半，正好对上题干那句"都只对了一半"。答案就是 C。

C 符合了就不用再看 D 了。

> **结论**：代入排除的核心就一句话——把选项当成已知代进题干，只要跟题干里任何一条硬条件直接打架，这个选项当场死。

```text
        ┌──────────────┐
        │   读题干条件  │
        └──────┬───────┘
               ▼
        ┌──────────────┐
        │  挑一个选项   │
        └──────┬───────┘
               ▼
      ┌─────────────────────────┐
      │ 把选项当成已知，代进题干 │
      └───────────┬─────────────┘
                  ▼
        ┌─────────┴─────────┐
        │                   │
   跟某条硬条件打架     处处都对得上
   （这个选项出局）    （这个选项留下）
        │                   │
        └────► 换下一个 ◄───┘
                     │
                     ▼
              四个全被砍光
                     │
                     ▼
            剩下的那一个 = 答案
```

读图：四个选项就是四条支路，每条支路拿题干去撞一次，撞出矛盾的那条当场剪掉，全剪完了，剩下的那条就是答案。

#### 练习一：三个人转岗

这题简单到有点糊弄人。人事部的张三、后勤部的李四、综合办的王五，三个人一起转岗。

关键词不是"转岗"，是"**转岗**"——转到别的岗位上去，那还能留在原地吗？显然不能。张三本来就在人事部，所以他不能还在人事部，D 选项直接否掉。李四本来在后勤部，李四不能还在后勤部，B 选项也否掉。

最后那句话别漏了：李四不去人事。C 选项跟它对着干，排除。

三个选项秒杀完，答案就是 A。

> **提示**：这种题你不用算，也不用推。四个字"进行转岗"已经把人名和岗位全锁死了，凡是让人待在自己老家的选项，连想都不用想。四个选项里只要有三个撞在这条硬条件上，答案就是第四个，剩下的那个连分析都省了。

#### 练习二：每人至少答对一道

这题有点墨迹。四位考生，三道题（松花湖、净月潭、天池），题干只有一条硬条件：**每位考生至少答对其中一道题**。

条件越少越好代。带 A：第一位考生三道题全错，直接违反"至少答对一道"，A 出局。带 B：前三位都还能凑出至少一道对，第四位考生三道全错，又违反条件，B 出局。带 C：第一位、第二位、第三位各答对一道，第四位答对两道，四个人全都满足"至少一道"。答案就是 C。

这题确实不难，思维也清清楚楚，就是挺恶心的——句子读着绕，做着做着眼花缭乱。

说实话这题我也不爱做，有的时候看着都有点懵。

> **提示**：所以这类题我的重点从来不是"做得快"，是"你会这个思维"。题干给了一条什么条件，你就拿这一条去撞选项，别的花里胡哨的东西一概不看。会这个思维，慢一点也不丢分；不会这个思维，做得再快也是白做。

### 最大信息法：找被提得最多的那个词

组合排列里，条件往往是一大坨，有时候还一句套一句，看着就晕。除了代入排除，还有几个辅助手段。第一个叫**最大信息法**。

什么是最大信息？就是**条件里出现次数最多的那个词**。

举个例子。甲乙丙丁四个人，分别来自四个地方：上海、北京、长春、杭州。现在给了五六个条件，一大堆话。怎么办？先别动脑子，把条件里每个词拎出来数一遍。

| 条件里出现的词 | 出现次数 |
| :--- | :--- |
| 丙 | 3 |
| 乙 | 2 |
| 甲、丁 | 各 1 |
| 北京 | 2 |
| 上海、长春、杭州 | 各 1 |

数完就明白了：丙被提了三次，是全场出现最多的词。

那就把丙当成推理的起点。因为它身上的限定条件最多，我很可能靠这三句就把丙先解出来；丙一解出来，后面的条件环环相扣，就全都能跟着松开。

> **结论**：最大信息法不是玄学，就是"谁被叫得最勤，就先审谁"。出题人在这种题上其实出得挺巧的——解开一个扣子，后面一串全跟着掉下来。你要找的，就是那个扣子。

```text
   一堆条件（还可能一句套一句）
              │
              ▼
     把条件里每个词拎出来数一遍
              │
              ▼
   ┌──────────────────────────┐
   │ 挑出被提得最多的那个词    │
   └────────────┬─────────────┘
                ▼
        从它下手，先把它定死
                │
                ▼
      环环相扣，别的条件跟着松开
```

拿一道真题试试。张、王、赵、李四个人，各负责一项工作：行政、销售、研发、安保。四个人对四份工作。

按最大信息法，先数一遍。行政出现了几次？张不做行政、王不做行政、李不做行政，再加上一句"赵不做行政"，一共四次。安保呢？只有三次。那起点清清楚楚——**行政**。

从行政下手：张不做行政，王不做行政，李也不做行政，三个人全被排掉了。那谁做行政？只剩赵。

赵做行政，那赵做安保、赵做研发就都不可能了，B 和 D 两个选项先排掉。

再补一刀。第三句是"如果……那么……"的结构，翻译过来是：**否定张做研发，推出否定赵做行政**。

这里用逆否等价：否张研发 → 否赵行政，等价于 **赵做行政 → 张做研发**。

赵做行政，我刚已经证明出来了。所以张做研发。A 选项说张做销售，错了。答案就是 C。

就这么简单。这题的重点不在计算，在于你找没找到"行政"这个起点。

> **易错点**：数都数不明白，就别怪题难。数词的时候一个一个数出来，别凭感觉。这一步看着最没技术含量，其实它是整道题的胜负手。

### 符号化：比较类条件直接写成大小号

第二个辅助手段：**符号**。

题里要是出现"谁比谁年龄大""谁成绩比谁好""谁的收入怎么样""谁的身高怎么样"这类比较类的说法，别在脑子里绕，直接写成大于号小于号。哪个大、哪个小、哪个等于，一眼就看出来了。

但这里有个坑，是下面那道药效题踩出来的，所以先记住一句话：比较的时候，**不同的度量必须分成不同的线**。

甲、乙、丙、丁、戊、己六种药。题干给了几句：甲比乙有效；丙的毒副作用比丁大；戊的药效最差；乙的药效与己的药效相同。

我先问大家一个问题：**毒副作用跟药效有关系吗？**

没有。既不成正比，也不成反比，两者是完全不同的两条线，没有任何关系。翻译的时候一定要把它们分开列，不能混成一条。

分开列出来就是这样：

```text
   药效线：    甲 ＞ 乙 ＝ 己 ＞ 戊
   毒副作用线： 丙 ＞ 丁
                （两条线谁也带不动谁）
```

对照选项：

A 说甲跟丁的药效相同。丁的药效题干压根没提过——提到丁的是"丙的毒副作用比丁大"，那是另一条线。推不出来。

B 说戊的毒副作用最大。毒副作用这条线里只出现了丙和丁，戊根本没出场。推不出来。

C 说甲的药效是最有效的。己、丙、丁、戊的药效一条都没参与比较，我连它们排哪儿都不知道，凭什么说甲最大。推不出来。

只剩 D。D 说己比甲差。乙等于己，甲大于乙，那己当然小于甲。成立。答案是第四个。

> **注意**：以后考试碰到"药效"和"毒副作用"同时出现，记住它们是两条不同的线，单独列。千万不要把它们给弄混了。

### 列表法：四个对象对四件事，先画表

第三个辅助手段：**列表**。

很多同学一看到"四个人、四个职位"就懵，本能反应是列个表格：张、王、赵、李一行，销售、研发、行政、安保一列，一格一格去推、去打叉打勾。

我要说：**表格本身就是一个非常好的方式**，不用犹豫。对象和事情都是几个、都是一一对应的时候，表格把"谁和谁还没对上"这件事直接摊在你眼前，比在脑子里记要靠谱得多。

拿一道招聘题来看，这题得用列表才做得快。先把题目条件捋直：

- 合格的教师有三个条件：责任心、知识、管理能力突出；
- 甲乙丙丁四个大学生来应聘，四个人**至少符合其中一个条件**——不然你来干嘛呢；
- 合格的教师**只有一个人**；
- 甲乙的管理水平相当；
- 乙丙都有责任心；
- 丙丁并非都有责任心；
- 四个人中**三个人的责任心强**；
- **两个人的管理能力突出**；
- **一个人的知识丰富**。

先画表，边看条件边填。乙丙都有责任心，在责任心这一栏打勾。丙丁并非都有责任心，丙既然有了，那丁就没有。再来"三个人责任心强"——乙、丙、丁里丁是排除的，那就得是甲乙丙三个都强。第一栏填满了。

第二栏管理。甲乙的管理水平相当，是好是坏？不知道，填不了。知识丰富的是谁？也不知道，填不了。

到这儿很多人就走进死胡同了，出不来了：这一栏空着，那一栏也空着，越想越乱。

> **易错点**：不是你笨，是有条件你漏看了。回去再读一遍题干开头那句"合格的教师有三个条件"，还有那句"只有一个人合格"。这两句不是废话，是这一栏的钥匙。

钥匙在这儿：**只有一个人合格，只有一个人知识丰富**。合格的这个人本来就该具备那三个条件，所以唯一知识丰富的这个人，就是唯一合格的那个人。也就是说，另外三个人的知识全都不丰富。

拿这把钥匙一开，丁的知识那栏直接写死：他不丰富。

再看"每个人至少符合一个条件"。丁的责任心不行、知识也不行，你既然来应聘了，不能什么都不符合，那就只剩管理这一项——丁的管理能力**一定突出**。

回到管理栏。题目说两个人的管理能力突出，甲乙的管理水平相当。甲乙俩能都突出吗？不能，丁已经占了一个了，两人都突出就成三个人了。既然甲乙水平一样，那只能一起打叉。

两个人里另一个只能是丙。于是丙责任心强、管理突出，知识那一栏只能是丙。丙三项全中，甲、乙只中责任心，丁一项不中——**只有丙合格**。答案是 A。

| 判断项 | 甲 | 乙 | 丙 | 丁 |
| :--- | :--- | :--- | :--- | :--- |
| 责任心 | 强 | 强 | 强 | 无 |
| 知识 | 不丰富 | 不丰富 | **丰富** | 不丰富 |
| 管理 | 不突出 | 不突出 | **突出** | 突出 |
| 是否合格 | 否 | 否 | **是** | 否 |

表读法：竖着看一列，三项全强的才叫合格，整张表里只有丙这一列是三项全中。

听说挺多人选了第四个。搞得我都有点不太相信这个答案，是不是我弄错了。后来一个一个对下来，丙是没毛病的。

### 一拖五：一个大题干带五个小题

来看一个大家真会碰上的题型：**一拖五**。

什么叫一拖五？就是一个大题干，后面跟五个小题。这种题特别重要，肯定要做。你不能说这题我不做——不行，肯定要做。

别怕，五个小题里一定有简单的。

#### 先把题干翻译成符号

第一句话：如果甲去黑龙江，那么乙去江苏。翻译成 `甲去黑龙江 → 乙去江苏`。

看到这种"如果……那么……"你一定要敏感，这是翻译推理的活。翻译推理是整个逻辑学的基础——它不会，后面的东西你一样都学不了。别因为它题少就把它略过去，略过你就废了。

第二句话是"只有……才……"，只有字后面是前、"才"前面是后，所以翻译成 `丁去云南 → 丙去福建`。

第三句是"或者"：乙去江苏拍古建筑，或者戊去福建拍人物。

第四句：去江苏拍古建筑的大学生，临行前和乙、丁话别了。跟人话别，说明他不是那两个人，那就是**乙和丁都没去江苏**。

#### 第一个小题：推出三条能带下去的结论

这题问：根据以上信息可以得出哪些结论。

题干里已经明确告诉我们乙、丁都没去江苏。那就从这里出发。

**第一条**：乙没去江苏。拿第一句话去撞——`甲去黑龙江 → 乙去江苏`，否后推否前，得到 **甲没去黑龙江**。

**第二条**：乙没去江苏。拿第三句话去撞——`乙去江苏拍古建筑 ∨ 戊去福建拍人物`，一端否了，另一端必须成立，所以 **戊去福建拍人物**。

**第三条**：戊去了福建，第二句话 `丁去云南 → 丙去福建` 的后件被否了，否后推否前，得 **丁没去云南**。

三条结论摆在这儿，答案就是第四个（丁不去云南）。

> **结论**：第一个小题的用处不只是拿一道分。它是从大题干里榨出来的三条结论，后面几个小题全靠它们。

#### 哪些结论能带到后面的小题里

这里有个点特别多人忘，我单独强调一遍。

**大题干推出来的结论，后面所有小题都能用。** 因为它是从题干里来的，是这个大题无条件成立的。

**小题自己加条件推出来的结论，后面一律作废。** 你看第二个小题的题干是"如果丙去西藏，则可以得出哪些结论"——它前面加了个"如果"。加了"如果"得出的东西，就不是大题干无条件成立的东西，下一个小题再用就是越界，作废。

```text
  大题干（无条件）──► 三个结论 ──┬──► 第二个小题：可以用
                                  └──► 最后一个小题：还可以用

  小题自己加的"如果……"──► 该小题的结论 ──► 后面一律作废
```

读图：结论能不能往下带，只看它是不是从"大题干"这一步无条件推出来的。

#### 第二个小题：只能用大题干给的东西

第二个小题：如果丙去西藏，可以得出哪些结论。

那就把上面那三条摆到桌上用。

B 说乙去福建。错，戊去福建了。
C 说丁去云南。错，丁没去云南。
D 说戊去黑龙江。错，戊去福建了。
A 说甲去黑龙江。甲没去黑龙江是他必然的，但"甲可以去了黑龙江"并没有被否定——题干说的是甲去了黑龙江乙就得去江苏，现在乙没去江苏，反推不出甲一定没去黑龙江，所以 A 站得住。

答案就是 A。

> **提示**：注意这里第三条的用法。D 选项"戊去黑龙江"是被戊去福建直接顶掉的——一个人一个地方，去了福建就不可能同时在黑龙江。别自己绕远路。

#### 最后一个小题：列表收口

真有点难度的就是这个，解题方式是列表，会更清晰。

先做一件事：把**地点和题材的对应关系**理出来。这是题目直接给的——去黑龙江的拍风景，去云南的拍花卉，去江苏的拍古建筑，去福建的拍人物。五个地方五个题材一一对应，剩下一组就是西藏和野生动物。

| | 黑龙江—风景 | 云南—花卉 | 江苏—古建筑 | 福建—人物 | 西藏—野生动物 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 甲 | × | | | | |
| 乙 | √ | | × | | |
| 丙 | | | | | |
| 丁 | × | × | × | × | ？ |
| 戊 | | | | √ | |

表里的记号就是这么打进去的：

- 乙去黑龙江拍风景，黑龙江这一列给乙打勾，其他人都打叉；
- 甲没去黑龙江，甲这一行打叉；
- 丁没去云南，丁这一行打叉；
- 戊去福建拍人物，福建这一列给戊打勾；
- 第四句那个条件别忘了——乙和丁都没去江苏拍古建筑，乙和丁在江苏这列都打叉。

然后看丁：黑龙江、云南、江苏、福建，四列全是叉。

一个人一个地方，五个地方总得去一个。丁前四个都被排除了，那他只剩西藏。丁去西藏拍野生动物，答案就是 C（第四个）。

其实没那么难，一道一道往上打叉，一整道题就通了。

> **结论**：你要相信出题人在题目中的设置都是非常一环扣的，一定是能通出来的。别被这个纸老虎吓住了。

### 这一章怎么变成自己的

最后说几句实在的。这一章我并不觉得有多少难的，很多人做不出来，是因为学得不够到位、刚开始不够熟练，不是题的问题。

我的课程我常说一句话，你学任何一门课程都适用：**至少听三遍**。听一遍是走马观花，就知道个大概，离你理解、离你能应用，差了十万八千里。

还有，如果你听的时候觉得有点懵、有点跟不上，那大概率不是内容的问题，是**没做预习**。我的讲义都发给你们了，提前在讲义上看一看、做一做，带着答案和疑问进课堂，跟起来完全是两回事。

还是那句话：先自己做一遍、推一推，推不动了再回来听，听两遍。方法就这一个，别的花招没有。
