### 元素组成相似：样式规律的入口

上一节课我们学的是位置规律。位置规律的识别特征是什么？是**元素的组成相同**——组成相同的时候，我们优先考虑位置规律。

这一节讲样式规律。样式规律最重要的识别特征叫做：**元素的组成是相似的**。

注意了，是"相似"，不是"相同"。那这个"相似"到底怎么定义？

就是线条在重复地出现。你在整个题目过程中会发现，有些线来来回回地出现。

你看这个九宫格的第一行：这条线和这条线，是不是只出现了两次？这两条线、这条线，是不是也出现了两次？再来看第二行，这个 Z 字形和这个 Z 字，是不是都出现了两次？这个斜杠，是不是也出现了两次？你看在这一幅图里面，是不是在线条重复地出现？

出现这种情况了，我们就要把它定义为：它的元素组成是相似的。

> **结论**：元素组成**相同**，优先考虑位置规律；元素组成**相似**，考虑样式规律。判断入口就是这一句话，但很多人做题时根本停不下来去数"这条线出现几次"，直接上手排除选项，结果全错。

### 相加、相减、求同：结构对齐，考得不多

元素组成相似会考哪些？加减同异。

第一个考点叫**加减同异**，这个很重要，尤其在国考里，几乎每年是一道的；各地的省考呢，这个知识点也蛮重要的。

什么叫相加？你看前面这个圆加上这个十字叉，是不是就等于第三个——圆中间加一个十字叉。这是不是就是一个加法？我在做一个加法的运算，两个图形在做加法。

什么叫相减？你看第三个图形减去第二个图形，是不是就等于第一个图形？圆加一个十字叉，减去这个十字叉，不就等于圆吗。

这就是最简单的相加和相减。这个知识点其实考得并不多。

**求同**就更简单一点：前面第一个图和第二个图都有一个十字叉，都有，所以就把这个十字叉保留下来，别的都消掉。

求同和相加、相减，考的都不多。

### 求异：记成消消乐就够了

考的最多的是第二个，叫**求异**。这个非常重要。

什么叫求异？这个词我们不去理会它，不去理会求异是个什么东西，其实不重要。

你看，第一个图形和第二个图形，这个十字叉是不是在前两个图形中都出现了？那这两个十字叉，到第三个图形的时候，是不是消失了？

什么意思？是不是就像我们以前玩那个消消乐——手机上那个游戏，两个一样的放在一起，是不是就消掉了？两条相同的线放在一起、叠加了，它就消掉了。

你可以把这个东西记为消消乐就好了。你想起来玩这个游戏：消消乐，两个一样的东西，到第三幅图就消失了，这叫求异。

你不用记这个概念，挺闹心的；你就记住"消消乐"就行——两条线一样重合了就消掉，没重合的就留下。

```text
【相加】图1 + 图2  ->  图3     两图不重合的线全部留下
【相减】图3 - 图2  ->  图1     把图2 的部分去掉，剩下图1
【求同】图1 与 图2 都有的那条线留下，其余全部消掉
【求异】图1 与 图2 重合的线消掉，不重合的线全部留下   <- 考得最多
```

### 前三道例题：一点弯都没有

来做题。先看例一，这个题我们简单来看一下，相对来说简单一点。

你看这个题里的特点，是不是叫做线条在重复地出现？第一个图里面，这个东西和这个东西，是不是重复出现了？两个重复的东西到第三幅图是不是没了？是不是叫消消乐。我们认为消消乐就可以了。

再等到第二个里面，这条线、这条线、这条线、这条线，是不是重复的？重复的就被消掉了，所以在下一幅图里不应该出现这四条。所以你看，A 出现了错了，B 这条线错了，C 这两条线错了，答案是不是就是第四个？

还是比较简单的。这就是所谓的一定要注意啊，这叫线条重复出现；线条重复出现，我们就去考察的是加减同异这一类的。

例二。线条是不是在重复地出现？怎么看呢——你看这是不是一个十字叉？第二图是不是也有十字叉，到第三幅图里没有了？上面这两个和上面这两个，是不是出现了两次？这两个"数"是不是出现了两次？

那这种情况下，我们叫做元素组成相似。元素组成相似，是不是考虑加减同异？各位同学说考虑加减同异——你看，是不是这一题也是消消乐？这个知识点考的最多，中间这两条一样的线就消掉了。

那我们来看这个规律：这两幅图形里这两条线是不是一样？一样，那就应该消掉了，这条线不应该有；这两条线是不是也一样？这条线也不应该有；这两条线是不是都不该有？来看选项：A 选项是不是有这条线，错了；B 选项这条线是不是错了；C 没问题；D 是不是也有这条线，错了。是不是直接选 C？前几个就很容易判定出来了。

例三。这个题是不是也很明显在线条在重复地出现？是不是相似？第一幅图里面，这一条、这一条，是不是每一个都出现了两次？你慢慢慢慢看一看，这个感觉就有了。

那我们来看看它是什么规律：这两条线是不是一样的线？是不是一样的？到第三幅图里是不是没了？是不是它也是一个消消乐，是不是也是一个求异？好。再看第二行，这两个是不一样的，到第三幅图没了。那我们定义了这是一个消消乐。

好，那我们来来看看选项。第三幅里面找找它们相同的是什么：这个三角形和这个三角形是不是相同的？这两个相同的是不是应该被消掉？不应该出现吧。消消乐嘛，他俩一样的，那就消掉了。消掉，看选项：B 选项这个是不是错了，这地方不应该有；C 这个地方是不是也错了；D 这条线是不是也不该有。所以答案是不是就是 A？

> **提示**：像这种题，当你确定好它是一个什么规律的时候，你也可以去挑那么一两条线入手。比如挑最后一行的这条线和这条线——我就挑这一条线，它俩一样，应该被消掉，所以选项里有它的就不行。用一两条很有代表性的线，能排掉一些选项；不行，你再挑第二条线，然后再看看能不能排除一些选项。也不用非要整体去看，把每一个细节都抠得很细，那是不需要的。

前三个都是比较简单的，没有任何的弯。但考试呢，像前三个这种题其实不太多了，现在都会额外地给去加一点难度。

### 位置规律叠上来：2015 年那道国考

来看一下例四，这个题是不是略微加了一点难度。

第一行，第一个是一个竖的小长方形，第二个是一个直角三角形。第三个你看一看——是不是这里有一个三角形，然后又有一个长方形？是不是前面两个相加？把第一幅这个长方形给旋转了，旋转完和第二幅图形在一起，合起来是这个样子，然后这个地方和这个地方重合了，所以这个地方重合了，重合的地方是不是消掉了？是不是消消乐？是不是一个消消乐？

所以你看好了，他是一个把位置规律叠加了样式规律。

这是现在最新的一种命题，现在大家都喜欢这么来命题。因为公务员考试难度加大了，光给你考最简单的东西，他觉得太简单了，所以会把很多东西揉在一起，来增加相应的难度。但其实也还好，大家对这种题见得多了，其实就不觉得特别难了——他还是那个消消乐。

```text
样式 + 位置的复合做法

  ① 竖小长方形        ② 直角三角形        ③ = 结果
        |                                            |
        |  ① 先旋转 90 度得到 ①'                     |
        +--------------------> ①' 与 ② 叠在一起       |
                                             重合的线 -> 消掉
                                             不重合的线 -> 留下
                                             得到 ③
```

那旋转方向怎么定？你说不是旋转吗，那你说这个是顺时针旋转 90 度还是逆时针旋转的？我现在是不是确定不了？好，那我通过第二幅图来看——第二幅图很明显，应该是这么旋转的，转成这个样子，然后再和这个图形叠加在一起。这个地方重复了，这个地方没有了。这就确定好了，应该是顺时针旋转 90 度。

所以接下来这组图的第一幅图，应该顺时针旋转 90 度。顺时针旋转 90 度，是不是应该变成这个样子了？我画一画。既然这个样子，它和第二幅图放在一块了，来看一看它跟第二幅图放在一块，叠加会成什么样子？

来看这两条线：这两条线是不是重合了？应该没有了，消消乐，这两条线没有了——把 C 排除了。然后再来看这条线是不是也重合了，那这条线也不应该有，所以 B 也排除了。A 不用看了，这形状一看就不对，线的位置就不对。所以答案是不是就是第四个？

这就是一个位置加样式的复合考法。这类题我们就多刷一些，不光刷这个最简单的。刚才这一道，是 2015 年的国考。

### 再叠一层：2019 年那道国考

来看一下例五。这道题是不是变成了 19 年的国考？又加了一点难度。我们国考里出题就喜欢这么出：加上一个变形，加上一个位置，再加上一个样式，复合给大家，国考里几乎这样也是一年一道的。

先看第一行。明显感觉到线条在重复地出现。我画这个圈，画这个平行四边形，是不是都有？这个平行四边形是不是在第三幅图里没有了？消掉了。消掉了之后，我们来看看它变成了一个什么图形——我把剩余的地方画出来：第一幅图是不是剩余两条线。

第二幅图呢，剩了一条线加上一个横杠；然后一条竖线加一横杠。前两幅图进行加减同异，也就是消消乐，相同的地方消掉。经过这种运算变成这个样子了，它跟这个第三幅图是一个什么关系呢？旋转吧。

那你看是顺时针 90 度还是逆时针 90 度？顺时针、逆时针，是不是都一样？分不出来。我看到有同学告诉我"顺时针、逆时针都不对"——你现在是分不出来的，因为你顺时针和逆时针都得到了它。

好，我们看第二幅图。你看是不是把这个完完整整地给消掉了？把它消掉之后，这两幅进行消消乐，应该得到了这个加上这个。它俩图是个顺时针还是逆时针呢？我现在也确认不了。

那就看第三幅图。地方第三幅图我们来看一看，这里面我们先进行一个加减同异的运算：来，这条竖线和这条竖线它是不是应该消掉了？这个横线和这条横线是不是也消掉了？这个小竖线和这个小竖线是不是也消掉了？再来看这个横线和这个横线是不是也消掉了？还有哪些能消的？一条、两条、三条、四条，这条线是不是也能消掉？这条线也消掉了。看还有能消的吗？好像没了。

既然没了，我们看一看消完之后的样子：这一条线保留了；第一幅图里的这两条线保留了；来到第二幅图，这两条线保留了，然后这一条线也保留了，OK。

我前两幅图进行加减同异，是不是变成这个样子了？看不懂吗各位同学，我是不是一直在讲消消乐？这不是一个消消乐运算吗？消消乐就是两个完全相同的线会被消掉。

那既然是它，我们看一看：这个真正的题肯定经过旋转了吧。顺时针旋转 90 度还是逆时针旋转 90 度？我们不知道。但是你看看选项——这个题是不是就是 B 选项？这个东西是不是就是 B 选项？所以 B 选项是不是一定错了，它就是没转的那个原样。

顺时针旋转 90 度是谁？OK，是不是 D？逆时针旋转 90 度呢？没有。所以是不是只有 D 是最后一个旋转的图形？拿过来给大家看一眼，是不是只有 D？

这是 2019 年国考的这一道题，略微难一点。但不要觉得它定义为难题，它绝对不是难题——只要你把相应的知识点知道，知道这个题考什么，你只要略微多花一点点时间。

### 横着看是相加：九宫格的另一种算法

来看一下例六。这个题选的是第四个。

我们看到九宫格，是不是先横着看的？先横着看。你看这是不是多了一个？多的这一个变成了它。那能通过什么运算变成这个样子？是一个相加的运算——把第一个和第二个加起来就是第三个。

第二行验证一下：这个东西和下面这个东西相加，变成了它。

你看我要求的这一幅图，是不是跟前面那个要么相同、要么只有一个？加完了之后还得是它。看一眼选项：A 这个头就不对了；B 可不可以？没问题；C 呢？加完了也是这个，没问题；D 也没问题。是不是只排除了 A？

好，那只排除了 A 之后，我们来看最后一个：加上这个会怎么样？哎，是不是每一个都有啦？合并完了是不是应该是这个样子？所以这个错了、这个错了、这个错了。答案就是第四个。

它就是一个加法，一个比较简单的加法。大家做一个加法的运算就 OK 了，不难。

以上就是我们讲的六个小的例题。前三个是很简单，后三个略微来一点难度，然后我们再多刷一些练习，把这个小的知识点、近些年的例题都做一做。

### 怎么把图推练起来

练习一比较简单，我就不说了：加减同异，这个消消乐，它俩一样是不是就消掉了？消完了之后约没了，是不是只剩下 A 了？

我刚才看到很多同学说，公务员这个判断推理好难。其实没有那么难。判断推理是我所讲的三个模块中最简单的一个模块，也是大家最容易去学的，而且能够很轻易达到 80% 以上的正确率。大家一定要有信心，千万不要在这个地方出现了。

那整个判断推理里，图推呢，应该是这些里面最难一点的，可能有难题。并不是所有题都是难题——我们十个里面只要争取对上八个就行了。不要去对那一两个特别难的，或者出题人自己奇思妙想的时候才想起来的一个题，不要去纠结这个东西。把我们正常可以拿的那八个拿到手就足够了。

很多同学在做图推的时候觉得难，就是因为有些题、有些出题人的方式确实有很多，有的时候真的是想不到。

那图推这个模块怎么才能做好、怎么练到非常好的程度？首先把基础知识掌握了；第二个就是多刷一些真题，多去练，把各类的情况——出题人可能有的一些情况你都见识了、都想到了、都做过、都接触过了，这样在考试的时候你才能够做对得更多。

不是所有题都是那么平铺直叙的。因为出题人现在会觉得，我出这种简单平铺直叙的题彰显不出自己的能力，而且现在的学员素质又越来越高了，所以他就会加一些难度。

给大家看一个例子，这个题你横着看，发现没有规律。你确实感觉很多线条在重复地出现，三个都重复出现，但得不出第四个图形；你说横着看没有规律，第二行横着看好像也没有规律。

那九宫格横着看没有规律的时候怎么看？横着看没有规律，是不是竖着看？我们竖着来看一看，这里面竖着怎么有规律——是不是这个图形加上这个图形，它俩一相加是不是变成前面了？是不是下面两个图形相加，得到了第一个图形？

```text
横着看没规律 -> 换成竖着看

        ┌────────┐
        │  最上格  │   <- 下面两格相加 = 最上格
        ├────────┤
        │   中格   │
        ├────────┤
        │   下格   │
        └────────┘

        每一行都是同一条：下两格相加，得到最上面那一格
```

注意到了吧，这题是竖着看的。再看选项：缺了什么？想变成上一个，是不是去了一个竖、一个横？所以竖和横是不一定要出现在这个图形中。是不是只有 D 了？

我们只有见得越来越多。那你看出题人可能会怎么样，你事先不知道，你只有见得越多了，考场过程中你才能够做出来的越多。所以我的判断推理里为什么会准备大量的这种练习题，各种类型的练习题都放在这里，让大家去找感觉。一定是用大量的练习题去巩固这类题型。

### 练习三：旋转叠在消消乐上

来，你再看练习三，这题也不简单。这个模块不给大家更多时间了。这道题很难，如果你不在纸上做一做，可能没有那么快。直接给到我答案的同学应该都是做过的，你们应该是提前预习都做过了。

好，我们来分析一下：是不是也有一点加减同异？能看出来吧？他应该是样式类规律，元素的组成是不是相似？这个东西加上这个东西，不就是它吗？是不是有些东西在重复出现？

但是他是个怎么回事呢？看一看他是怎么加的：是不是把第二幅图怎么样？各位同学，把第二幅图给我旋转 90 度来。把第二幅图旋转 90 度，转过来之后变成了什么？看到了吗？我把第二幅旋转 90 度转过来，是不是变成它了？然后第一幅图和旋转后的第二幅图进行加减同异。

这幅图和这幅图进行加减同异，是不是又是一个消消乐？重复的相同的东西消掉了。中间竖着这个鼻子消掉了，是不是就变成了它？

所以这个题里的基调考的还是消消乐这个规律。那我们就看消消乐这个规律：我先把这个图形给他求出来，然后再重新旋转。

```text
题目关系：  第一幅  +  第二幅(旋转90度)  =  第三幅
缺的是第二幅 -> 用第一幅 和 第三幅 反推它

位置            第一幅      第三幅      =>  第二幅该怎么放
第1个位置        没有        有         =>  第二幅这里要有一个白圈
第2个位置       有白圈       没有        =>  第二幅这里也要有白圈（两两消掉）
第3个位置       黑圈        黑圈        =>  第二幅这里是空白（没被消，说明只有一幅有）
第4个位置(左下)  没有        黑         =>  第二幅这里要有一个黑
第5个位置        黑圈        黑圈        =>  第二幅这里是空白
```

既然是消消乐，我一个位置一个位置来看。我点那个红点，你们能看清不啊？就点那个小红点了。

第一个位置：这个位置第一幅图没有，第二幅图呢也没有，但是第三幅图有了——所以这第二幅图是不是应该有一个它呀？我们是不是加减同异，相同的会被消掉，所以这个地方是不是应该有一个白圈？

再来看第二个位置：第一幅图有白圈，第三幅图发现没了，所以这个地方我是不是应该也有一个白圈？两个白圈一相加，然后就消掉了。

好，那再来看，我顺时针看第三个位置——这个黑圈的位置：第一幅图是一个黑的，第三幅图还是一个黑的，没有消掉，所以这地方应该是个空白，什么都没有。

再往前看第四个位置，左下角这个位置：第一幅图啥也没有，第三幅图发现有了一个黑的，所以这个地方是不是应该是个黑的？第二幅图是个黑的。

第五个位置：也有说法——第一幅图是个黑的，第三幅图还是个黑的，所以这个地方应该啥也没有吧。

好，到这里我是不是把这个图做出来了？是不是通过加减同异把这个图做出来了？应该是这个样子的。

那我做出来之后，是不是应该把这幅图旋转 90 度回去啊？虽然我把它求出来了，但是我是不是应该把这幅图旋转回去？我旋转 90 度，再旋转回去，是不是就是 B 选项？你看看 B 选项是不是就是它旋转 90 度回去？

这幅图其实如果你做开了，并没有想象中那么难。它就是一个消消乐的规律、加减同异，相同的被消掉了；整个过程中额外叠加了一个旋转。你把它旋转回去，求出来之后再旋转回来，就是 B。

> **结论**：这种题略微有点难度确实是有的，但你就往上加就行了——通过加减运算把它求回来。有的、没有的，你应该求回来就 OK 了。

主要是跟大家来说，考试的时候之所以大家觉得难，是因为你碰到这种把位置规律和样式规律融在一起的题，所以你会觉得耗费一些时间。但其实还好，只要你能发现它的规律、知道他在考什么，那这个题其实就已经解决一半了。真正的难题是这个题——你根本就想不到他在考你什么，那才是真正的难题。是你做了好几圈下来，你发现我实在是找不着他想考我什么。刚才那两个题，你还能够知道他在考察你加减同异，已经很不错了。

### 剩下两道练习：纯消消乐

看练习四，这个题是很明显，这两个东西是不是一样？一样，消掉了，然后变成了它。是不是一个消消乐？你看第三幅图，同理，消消乐，他俩没有什么可消掉的。所以答案就是 C。

再看练习五。线条又是不是又在重复地出现了？你看 A 选项里，这两个是不是一样？一样，没了，消掉了；然后呢，这条线和这条线一样，消掉了。第二行再来看，这个地方和这个地方，到第三个是不是消掉了？这个十字叉和这个十字叉，到第三个是不是也消掉了？是一个消消乐。

再看最后一个：这条线和这条线是不是消掉了？选项中不应该有这条线，B 跟 C 排除了。等 D——D 里面那肯定就不对了吧，他俩又不一样，不可能全消没。所以答案就是 A。消消乐嘛，答案就是 A 了。

练习六刚点了个题名，这一讲就先收在这里了。

## 样式规律收尾与属性规律开篇
> 对应块：BLK05 | 覆盖分集：P04中1 | 块标题（分集名）：《第二节课——图形推理—样式规律和属性规律——刘文》

来谈练习六。这个题是不是也是一个简单的、非常普通的消消乐？

消消乐这种题，考察的东西非常多——只要它考了，90% 都在考察"两个相同的线就约掉"这一个规律。我现在拿的这些基本都是近几年的：18、19 的这些题。各个省份的题目是不是很明显地在重复出现？同一条规律，反复地翻出来考你。

所以这一段先把这个规律收干净，再往下开一个新的考点。

### 消消乐收官：两个相同的就约掉

> **定义**：**消消乐（求异）**——同一个位置、同样的一组图里，出现两条相同的线，它们就互相约掉；没被约掉的线原样保留。整幅图是"加完再减"，不是简单地看数量增减。

练习六就是这么走的。

第一幅图里，这条线和这条线，到第二幅图又没了吧；那就对了，它俩约掉了。到第二幅图横着看，这条线和这条斜线，又没了吧——又是一对。第三幅图同理，再看一条线和一条线，应该约掉。

于是选项里 C 和 D 排除了。

这里有个操作细节要特别注意：**别整体看，去找其中的一条线来看。** 你就看这两条线，一样有，那就应该被消掉；有它没它，一目了然。整体去比一堆线，人会看花眼；抓一条线，题目就解决了。

剩下 A 和 B 的区别，也是找两条线随便一看——它有线，它没有。这条线和这条线既然都有，那就应该约掉；既然要约掉，这个选项里就不该留着它。A 排除，答案就是 B。

练习七是 2018 年的国考。原线条又在重复出现了：第一行第一列里，前两幅图的那两条线相同，到第三幅图就约掉了，其他线全都保留；第二行也一样，这个东西和这个东西相同，约掉。到了第三行，那两条线就不应该再出现——A 出现了错，B 出现了也错，D 也出现了也错。答案就是 C。

> **注意**：国考这几年几乎是年年都出。同一个规律在 15 年、18 年、19 年都做过，这题只要出现，你就必须拿分——这是在给大家送分的，你不拿别人就拿了。

到这里，加减同异的样式规律就算讲完了：六个例题加上七个练习，13 个题，其实已经挺多了。规律你是知道了，但**看的多不等于做得快**，只有练得越多，考场上才越快想到它。所以先把基础知识打牢，不用着急；等所有知识都过完一轮，我会再带大家去刷真题——看真题拿到手该怎么处理，十个题我们到底能不能对八九个。

> **提示**：我承诺过资料分析跟完能对 18 个甚至更多，刷题的时候我会把这个诺言兑现。直播也会一直做到国考前，每天晚上八点到十点，周一到周五，锁定直播间跟着就行。纯小白同学建议先去补一遍公考答疑那期，里面对公考的认识和复习策略讲得挺全，也不会枯燥。

### 元素组成相同还是相似：分岔点在这里

先解决一个最容易混的分岔：**元素组成相同**和**元素组成相似**，一字之差，选的方向完全不同。

你不能把它们都叫"相同"。看第一组：这一行 1、2、3、4，是不是四个黑的；第二幅是不是四个黑的；第三幅也是四个黑的——每一幅黑块数量都一样，这才叫**元素组成相同**。

再看另一组：这一行四个黑块，下一幅五个黑块，再下一幅三个黑块。元素种类是同一批，但数量对不上，这就只能叫**元素组成相似**。

分岔之后怎么办，前面已经讲过规矩了：

| 元素的组成 | 特征 | 优先考虑 |
| :--- | :--- | :--- |
| 相同 | 每幅图元素数量完全一致 | 位置（平移） |
| 相似 | 元素种类一致、数量不同 | 样式（黑白运算） |
| 既不相同也不相似 | 没有任何共同元素可循 | 属性（对称、曲直、开闭） |

拿现成的例子说：第一行是四个黑块，数量不变，那就优先去看位置——具体就是看这些小黑块在整个区域里怎么平移，是顺时针走、横着走，还是竖着走。那个题里四个块就是**整体逆时针走了一个格**，绕着外面这个圈走，一目了然。

而黑块数量不同的时候，优先考虑的就是黑白运算。

### 黑白运算：出题人给黑白自己定的一套加减法

什么叫黑白运算？就是出题人在这道题里**额外附加了一种运算规则**，由他给黑和白定义出一种加减关系。

你看这个：一个黑、一个白，"黑加上白等于什么"？等于白。再来，白加黑，等于白。再看第三个，白、黑、白、黑，四个加起来，等于一个白。

> **定义**：**黑白运算**——出题人规定"黑"和"白"相加减得到什么（黑+白=白、白+黑=白，或者黑+黑=白、白+白=黑，等等），并且这个运算在整幅图、整道题里都严格成立。

所以记住一句话：**黑块数量不同，优先考虑黑白运算。**

### 实战：定好顺序，从零点顺时针走

这类题怎么做得更快？关键是**定一个顺序**，而且这个顺序随你自己定。我自己的习惯是顺时针从 0 点开始，先看第一个区域——因为这样我能更准确一点。

0 号位置起、顺时针编号，是这么回事：

```text
   ┌─────────────┬─────────────┐
   │      0      │      1      │     从 0 号位置起，顺时针编号
   ├─────────────┼─────────────┤     0 → 1 → 2 → 3
   │      3      │      2      │
   └─────────────┴─────────────┘
```

你先看谁都行，我习惯从 0 开始。你把这个位置现在需要的算式**先抓住**（比如"我现在需要知道白加白等于谁"），然后**回原题中去找**这一对。

#### 例一：轮廓一样，就只剩颜色了

拿过题来一看：这几个图形都是被分割成了相同数量的区域，两个区域、三个区域、四个区域，每一幅的分割都一样。分割区域相同，唯一的区别就是里面的黑白颜色不同。

> **结论**：分割区域都一样、只有黑白颜色在变的这类题，优先考虑黑白运算。你去考虑黑白运算一定没有错，你就大胆去用吧。

按 0 号位置顺时针走。0 号位置这个区域是白，上面那个也是白。白加白等于什么呢？**回原题中去找**——原题里确实有白加白等于白。所以这个区域应该是白。

A 没问题，B 错了，D 也没问题。剩 A 和 D 两个，那就看它们的区别在哪个区域——正好就在这个区域里。这个区域是黑，那个是白，那黑加白等于什么？还是回原题中去找：黑加白等于黑。这个位置就该是黑色，D 排除，答案就是 A。

#### 例二：一个位置就秒杀

第一行黑块数量是 3、3、4，不一样，优先黑白运算。第一个位置：白加白等于什么？回头找——白加白等于白，所以第一个位置就该是白。对不上，直接秒杀第二个选项。黑白运算的题，相对来说就是比较简单。

#### 三道练习：每题换一套算式

这里要特别提醒：**每一道题定义的算式都不一样**，上一题的结论不能带到下一题。

- **练习一**：黑块数量 2、3、5，元素组成相似，优先黑白运算。0 号位置：白加白——回原题找，白加白等于**黑**。这个位置必须是黑，A、D 在这个位置对不上，都排除。剩 B、C，区别在另一个区域，那个区域是黑加黑，回原题找，黑加黑等于黑，这个区域还是黑，B 排除。答案是第三个。
- **练习二**：第一行 4、5、5，元素组成相似，优先黑白运算。0 号位置：黑加黑等于什么？等于**白**，这个位置应该是白，B、D 都错，排除。再看 A 和 C 的区别，正是在这个位置：白加黑等于什么？回头找，白加黑等于**黑**，这个位置应该是黑。答案是 A。
- **练习三**：5、4、5，黑块数量不同，优先黑白运算。看第一个位置：很明显这两个都是白，白加白——找一找，白加白等于白，所以这两个位置应该是白，A、B 都排除。剩 C、D，区别在那两个位置上：黑加黑等于什么？等于白，这两个位置应该是白。答案是 C。

### 用到哪条算式就回原题找哪条

我见过有同学一上手就把四种运算全列出来：白加白等于白、黑加白等于黑、白加黑等于黑、黑加黑等于白——"老师，四个运算我找到了"。

**不要做这么傻这么笨的事情。** 没有必要先把它们都列出来、都找出来，这样计算量特别大，浪费的时间太多。公务员考试对时间的要求非常严格，根本不要去做这种事情。

我是这么做的：**先找到我需要什么，我再回去找。** 我从 0 号位置开始看，看到两个白，我现在需要知道的就是"白加白等于谁"，那我就回到原题中去找。仅此而已。

一定要节省时间，非常重要。

至于"用完要不要验证"——有同学问：老师，不用验证吗？一定是这个吗？

只能说你做的题还不够多。等你做多了、刷多了，你就知道了：这种题只要遇见了，几乎根本不用验证，那一定是考这个规律。如果你不放心，或者你还有时间，那就再找一个跟他一样的对一对，看看是不是这个结果；但做多了你就会发现，一看着就知道它要考你什么，根本不需要。

顺带把九宫格的看法也说清楚：**横着看是优先，这类题占到 90% 以上。** 万一横着看做不出答案，再回去想竖着看；再不行就考虑米字型；米字型还不行，再考虑 S 型——这个顺序上一节课都交代过，就不再啰嗦了。到现在为止竖着看的题几乎没出现过，但你做多了自己就吃到了。

### 既不相同也不相似：优先看属性

第一个知识点收口，再把整条岔路口重新捋一遍：元素组成相同，优先看位置；元素组成相似，优先看样式规律；样式规律里又分成加减同异和黑白运算两块，而加减同异里最核心的就是求异，也就是消消乐，占到 90% 以上。

那第三节看的是什么？是**属性规律**。

> **定义**：**属性规律**——元素的组成既不相同、也不相似，图形之间找不到任何共同元素可循时，优先去看图形本身的属性。

属性里最重要的、也是大家最熟悉的有三样，先记住这六个字：

> **对称、曲直、开闭。**

对称、曲直、开闭——大家慢慢做着，慢慢学着，学着学着就记住了，最后都能背下来。既然对称最重要，我们就从对称开始讲。

#### 轴对称：既考方向，也考数量

什么叫轴对称，这个不用多说了，就是有个对称轴。

这里要特别注意两件事：**对称轴的方向**，和**对称轴的数量**。

看这三个图：第一个是对称轴竖着；第二个的对称轴就旋转了 45 度。那我完全可以考你——下一个的对称轴是不是又旋转 45 度，是不是变成平行的了。**方向完全可以在上面做文章。**

数量更能做文章。第三个是五角星，大家告诉我它有几条对称轴？是不是五条。一条、两条……我画得不像了，但它是五条。所以对称轴的数量一样可以拿来命题。

> **提示**：这两条是轴对称的出题方向——**方向**和**数量**。后面大量练到这类题，你就知道出题人是怎么摆布它们的了。

#### 中心对称：绕着中心转 180 度

第二个很多同学就忘了，概念也一起重新打出来，我带大家读一遍：

> **定义**：**中心对称**——在一个平面里，把一个图形绕着一个点旋转 180 度，图形重合了，这个图形就叫中心对称图形，这个点叫**对称中心**。

怎么理解都行。等价的说法是：这个图形里任何一个点，穿过这个中心，都能找到它的对称点。

看第一个平行四边形。它有轴吗？你不能说它有，它没有轴对称。但它是不是又对称了？对上了——我在这个平行四边形的最中间点一个点，绕着这个点旋转 180 度以后一模一样，又回来了，旋转 180 度之后还是它。这就是中心对称图形。

你也可以这样验：随便在图形里点一个点，穿过这个中心这条线，都能找到它的对称点。

再看这几个字母。中间这三个都没有轴，一个轴都不能说。但 N 的中间点上一个点，绕着它旋转 180 度，是不是又回来了？Z 没有轴，但你在这个地方找到一个中心，图中任何一个点穿过这条中心都能找到对称点；S 也一样，穿过这条中心都能找到它的对称点。

这个就是中心对称。

## 找中心、找轴：图形推理里的对称性
> 对应块：BLK06 | 覆盖分集：P04下 | 块标题（分集名）：《第二节课——图形推理—样式规律和属性规律——刘文》

### 绕着中心转半圈，还是它自己

在图形的正中间点一个点，然后绕着这个点旋转 180 度——转完了，还是它。这就是中心对称。

我判断一个图形是不是中心对称，很少真的去转，更常用的办法是随手在图上挑一个点，然后问自己一句话：这个点穿过中心，它的对称点在哪儿？找得到，整个图形就是中心对称的。任何一个点都找得到，那就更不用说了。

```text
轴对称：沿一条直线对折，左右两半互为镜像
      ─────────────      ← 对称轴
      ◣        ◢
      ◠        ◠         折得上去，才是轴对称

中心对称：绕一个点旋转 180°，图形与自身重合
            P'
            ●
       P' ● O ● P        P 与 P' 关于中心 O 成对称
            ●
            P
```

平行四边形。有同学问：平行四边形为什么不是轴对称？同学，你给我画条轴呗。你画一条轴我看看。左右对称吗？像个镜子一样对折，折得上吗？你去找个对称轴，找不到。

```text
      ______
     /     /           中心对称 ✔  绕两条对角线的交点转 180° 重合
    /_____/            轴对称   ✘  怎么折都折不出镜像
```

还有一个图形要特别记一下：它有四条对称轴，同时又是中心对称的。我在中心点一个点，绕着中心转 180 度，还是它；换任何一个点穿过中心，都能找到它的对称点。

> **注意**：轴加中心对称的图形，一定要给它做出标记。这是最容易漏的一类——你在题干上把它标出来，后面分组才不会把它和"只有中心"的那一组混在一起。

### 五角星不是中心对称

回到正事先问一句：这个五角星是中心对称吗？有同学说是。同学，你把它旋转 180 度试试。底下这个角转到上面来，五个角的方向全反了，重合不了。

而且它连一个中心都点不出来。我随手挑一个点，穿过中心去找它的对称点，应该在这儿——可它在图外。所以五角星没有对称中心。

> **易错点**：五角星是轴对称，有五条对称轴，但它不是中心对称。经常有同学做着做着就忘了这一条，务必在题干旁边写上"五角星 = 有轴，无中心"。

### 找中心的两种手法

判定中心对称其实就两条路：

一是旋转 180 度，看重合不重合；二是点出中心点，逐点去找对称点。

我更喜欢第二种。旋转 180 度当然也行，但你得把整个图形转一遍，那个中心点其实并不直观，也不太好算；点一个点就顺手多了——找到中心点，所有点的对称点都能顺着它推出来。哪条路都行，看个人习惯，这本来就是初高中就学过的老知识。

### 六个例题，一个考点一个考点地练

**例一** 一上来题干四个图形我全标了：五角星五条轴，第二个两条轴，第三个两条轴，第四个一条轴。到现在为止所有人都是一个轴对称的，那首先你就得找一个轴对称的。

看选项：A 是轴对称吗？A 不是轴对称，画一条轴它不对称。B 呢？B 也不对称，它没有对称轴，它是个中心对称。C 是轴对称。D 也是中心对称。

所以这个题只选 C，不用想太多。这个题想多了没用——因为题干已经把路堵死了，所有人都是轴对称，你只要锁住那个唯一带轴的选项就行。

**例二** 第一个图形我一眼就看出能点出中心，而且还有轴，轴加中心。第二个有点像 Z，Z 是什么？Z 是非常典型的中心对称，可以点个中心、没有轴。第三个有一个中心，而且有两条对称轴。

严格来说，我应该找"中心对称 + 两条对称轴"的图形。那就先找中心：A 是一个中心，没问题；B 不是；C 不是；D 也不是。都不是中心，答案已经选完了。轴我压根没用上，这题就结束了，答案 A。

**例三** 题干第一幅，能点出一个中心，不是轴对称。第二幅也有中心，同时又是轴对称，有四条对称轴。第三幅肯定不是轴对称，看着有点平行四边形的意思，有个中心。第四幅有一个中心，还有两条对称轴。第五幅没有轴，能点出一个中心。第六幅有中心，轴有四条。

到这里就区分开了：1、3、5 只是中心，2、4、6 既是中心又是轴。答案就是 1、3、5。

**例四** 题干六个图形全是轴对称，一个一个画上轴。所以应该找轴：A 是轴对称，B 不对，C 是轴对称，D 也是轴对称。ABD 三个怎么排除？一眼就看出来——这个对称轴在转。每一次旋转 45 度，下一个对称轴应该是竖直的。这个题考的就是对称轴的方向，答案是 A。

**例五（2019 年国考）** 不相同、不相似，优先考虑属性，属性先考虑对称。题干全是轴对称，轴在旋转，每次 45 度。按旋转的方向一推，B 和 D 都对。

这时候关键的思维是：我已经排除了 A 和 C，那我是不是应该去找 B 和 D 的区别？

区别就在图形自己身上。第一幅图里的对称轴，是不是自己就带了一条？第三幅自带，第五幅自带——1、3、5 图形本身就带轴。再看 2、4、6，中间没有自带的轴。

所以下一个应该选中间没有的，D 就这么被排除了。答案 B。

> **结论**：排除到剩两个选项时，别急着硬找差异，先看看这两个选项之间"有没有"某个属性的差别——有和没有，往往就是答案。

### 真题里的对称长什么样

真题里出现轴对称图形，做着做着有了感觉你会发现，这个题拿过来你一眼就知道大概率考轴对称。而且轴对称里一般塞了很多特别明显的特征。

比如带方向的箭头，比如躺着的、横着的三角形，比如一些字母。你把这些见多了，感觉自然就有了。

```text
轴对称常见外形
   →  →  →        带方向的箭头
   △  ▽  △        带方向的三角形
   A  H  T        单字母本身的对称
```

再来看真题里的中心对称，特点同样明显。

S、Z、N，这几个字母只要出现了，这题一定考中心对称，非常典型。像太极图，你仔细看，它就是一个 S。像 who 这几个字母，你把它拆开看，是不是一个 Z。还有平行四边形，以及平行四边形的各种变形——Z 的变形就是平行四边形。

还有一类是两个一模一样的东西，转了 180 度之后又对上了，只是方向变了。最下面那一排你再看：两个本来不一样的东西，旋转 180 度之后一模一样——两个一模一样的东西在转来转去。

> **易错点**：百分号是中心对称，但绝对不是轴对称。很多同学在这儿栽跟头。中间那一笔不是轴——如果它是轴的话，画出来应该是一个圆。你实在判断不出来，就把脑袋转过去歪着看，一看就知道。它是中心对称，画个点，穿过去能找到对称点。

```text
   典型中心对称外形
   S   Z   N   ♢(平行四边形变形)   %(百分号)
```

### 对称是国考绕不开的一考点

这个知识点非常的重要。国考十道图形推理，一定会有一个考对称。

所以你今年做完一份国考卷子，通篇下来发现自己一次都没用到对称——那我可以告诉你，你至少错了一道题。回去检查一下，一定错了一道。

至于感觉怎么来的：不是背下来的，是你把基础知识掌握好了，然后做大量的真题，慢慢就有感觉了。出题人可能用的方式你知道的越多，考试的时候你能做出来的概率就越大。我们能做的就是去刷大量的题，让这些东西长在身上。

### 练习一到练习七

**练习一** 数对称轴的数量。题干那几个图形都是三条对称轴，答案 A。

**练习二（国考）** 还是轴在转。顺时针转 45 度，下一个轴应该是这个样子，答案 C。

**练习三（2016 年国考）** 对称轴的方向一直在转，转 45 度，下一个应该是横的，答案是第二个。

这里有同学会问：老师，第一幅图都是横的，这幅图变成竖的了，这规律可以吗？当然可以。我们看它的规律是不是在旋转 45 度——只要依然满足旋转，就可以了。

**练习四** 题干要拆开看。第一个明显能点出中心，第二个明显能画出一条轴，第三个是 S，明显一个中心，第四个是平行四边形，中心对称。

> **提示**：平行四边形不是轴对称，这里没有轴。还在问的同学，你自己去画一画，哪来的轴？你告诉我哪来的轴？

后面三个：一个中心、一个轴、一个中心对称、两个轴对称。中心跟轴就分开了，1、3、4 是一组，答案是第四个选项。

**练习五** 这个题出得一般，我只能说出题人出题很一般。题干拿过来一看，第二个既中心又轴，第三个既中心又轴，第四个就是个轴，第五个第六个也都是轴。再看选项，ABCD 全是轴对称。

那还有什么区别？中心有吗？好，有三个是中心对称——但也成不了规律。这个题的考点就是最简单的那一条：每一个图形都有一条对称轴。你找一个有轴的就行了。

很多同学这个题蒙了，就是因为想多了。你想复杂了，就看不到最简单的东西了。

**练习六** 不相同不相似，优先考虑属性，轴在这儿。题干这一列轴是竖的、竖的、横的、竖的、竖的，在这么转。

我一开始还判成了顺时针，走着走着发现不对——整错了。他这两个轴应该逆时针转回来，然后再这么转，又逆时针又往上转，这样这样地转下去。下一个应该转到这个位置。

答案 D。

**练习七** 有很多同学选了 A。规律大家都找到了：题干 1、2、3 都是三条对称轴。那你告诉我 A 有几条？A 的中间是一个正方形，这个东西你怎么给我画出三条对称轴来？就这么画对称吗？

A 只有一个对称轴。有三条对称轴的是 B 选项。不要马虎。

### 练习八：那种恶心的题怎么办

这道题是山东的，非常难。

分析的时候要先看整体——整体看不出来。好像没什么规律，其他规律好像也没太有。怎么办？往细里看：每个小图形里面，大的小的、黑的白的，是不是每一个都自身对称？

对，那就是从对称轴之间的关系入手。我先只画两个白色的小图形的对称轴：图一两条轴夹角 45 度；图二两条轴平行；图三又是 45 度；图四又是 45 度；图五平行了、重合了；图六也平行。

所以 1、3、4 是一组，答案 A。

再说一句那个黑色的，他没加进去，加进去规律更完整：图一黑色和两个白的，一个平行、一个 45 度夹角；图二黑色和两个都是垂直；图三是一个平行、一个 45 度；图四一个平行、一个 45 度；图五和两个的夹角都是 90 度。另外那三个是两个都 90 度、两个都 45 度、两个都 90 度，夹角都相同。

这个题很恶心，也很变态。我们说图形推理难，难就难在这种变态题上，很多同学在这里都会崩溃。

但有句话我一定要讲：考试的时候，如果你一眼很明显找不到规律，或者做着做着发现这题不行了，千万不要较真，千万不要死磕这一道，没有必要。十个题里面，我们一定会有那么一两个是你想不到的。不要较真，不要钻那个牛角尖，该扔就扔。

当然也不会所有题都这么恶心，山东也有做得还行的题。

### 练习九到练习十一

**练习九** 也是山东的。看第一行：一个轴、一个轴、两轴。第二行：一个轴、一个轴、两轴、一个轴、两轴、三轴。

什么规律？$1 + 1 = 2$，$1 + 2 = 3$，是轴的数量在做加法。所以第三行是两个加三，应该找一个有五条轴的，答案 D。这种考法挺多，我们见得多一些。

**练习十** 题干第一行：一条对称轴、一条两条对称轴、一条两条三条四条对称轴，1、2、4。下面一行是一条、两条，那就应该找一条四条对称轴的，答案是 B。1、2、4 对应 1、2、4，规律就这么简单。

**练习十一（19 年联考）** 最后一道，简单说一下。其实这题不难。你看外圈都有一个圆，圆里边的图形在旋转，所以外圈应该从 A 和 D 里选，B 和 C 先排了。

A 和 D 的区别在中间那个图形。中间那个图形是不是一个轴对称？是。那就看它的对称轴是横的还是竖的——A 的对称轴是竖的，D 的是横的，竖横竖竖，我们该找一条横的。答案是第四个。
