# 2023年国考判断推理（副省·行政执法卷）真题精讲

## 差异题概览

### 取材范围

* 副省和行政执法这两套卷子的差异题，有很大一部分跟地市级卷是重样的。

* 重样的不重复讲，只把不重复的那些差异题摘出来，一道一道带做。

* 差异部分包括九道图形推理，以及几道定义判断和语句表达题。

### 三条主线

* 黑白块的题，先问"变还是不变"。

* 立体图形逃不出"画橡皮"和空间想象。

* 语句题考的根本不是这句话说了什么，而是它想让你关注哪儿。

## 图形推理差异题：黑白块与对称

### 黑白块抓不变

* **黑白块的第一反应**

    * > **定义**：黑白块图形优先考虑平移。

    * 第一步想到平移没有争议，但平移只是"第一反应"，不是"必须验证到底"。

    * > **易错点**：一旦画面感觉不对（比如中间是纯空白、整体没有"挪一格"的感觉），就该立刻换思路，别在一条死路上耗时间，更不要硬往转圈上靠。

* **解题动作：先比变化，再找不变**

    * 图形里小方块太多，而且每一个都是半个方块，看久了头晕。

    * 处理办法是把前两幅摆在一起比：先看哪些变了，再看哪些没变。

    * 对比结果：中间那一大块——从中间一直往下——跟上一幅一模一样，一个点没动；唯一在动的是最上面那一行，顺时针转了 90 度。

    ```text
    ┌──────────────────────────┐
    │  顶部一行：顺时针转 90°  │  ← 每一幅都在动
    ├──────────────────────────┤
    │                          │
    │   中间与下方：纹丝不动   │  ← 逐幅对比完全一致
    │                          │
    └──────────────────────────┘
    ```

    * 图上把不动的区域框出来，答案就写在这个框里；既然存在"不变"，就去找"不变"。

    * 存在"不变"时不必再去逐个验证"顺时针 90 度"——你看了只会徒增头晕和恶心，答案已经出来了。

    * 四个选项里只有 B 在这个区域没有变化，**答案选 B**。

### 特征图形外轴对称内中心对称

* 这一题的特征图形太明显了，明显到每一个元素都是特征图。

| 图形 | 对称性 |
| :--- | :--- |
| 三角形、五角星、箭头、半圆 | 轴对称 |
| Z 字形、长方形、平行四边形、百分号 | 中心对称 |

* 原图外面一圈全是轴对称，里面一圈全是中心对称，出题率就这么直接给出了。

* 解法就是去找"外面轴对称、里面中心对称"的选项，**答案选 D（第四个）**。

* > **提示**：原图里那两条线并不是等长的，上面那条比下面那条长，它压根就不是一个半圆，撑不起轴对称——这就是 C 为什么不合适。

### 九宫格黑白块优先黑白运算

* 识别条件：一是黑白块，二是九宫格；两个条件一叠加，优先级就出来了。

* 条件一：九宫格多数情况是横向运算，不可能"第一列和第二列运算得到第三列"，先把运算方向定死。

* 条件二：每幅图里黑块、白块的数量都不一样，数量不一样就说明黑白块本身在参与运算。

* > **结论**：优先看黑白运算；如果黑白运算走不通，再回头找别的规律。

* 验证方法：考场上没有工夫一个一个全看，随便抓几个验证一下就行——抓第一幅和第二幅的黑加黑得白，再抓一组黑加黑还是白，到第三幅再验一次还是白，验证三次全都对，那大概率就是它，不用再往下验。

* 排除方法：用"黑+黑=白"先把两个选项毙掉，剩下 A 和 C；A 和 C 的区别只在第一个位置，那就只看第一个位置。

* 第一个位置是白加黑得白，A 错，**答案选 A**。

## 图形推理差异题：立体图形

### 六面体折纸盒的新变形：橡皮法

* **橡皮法**

    * > **定义**：橡皮法是在六面体纸盒题中，把图形当作橡皮在纸面上按位置关系画出来求解的方法。

    * 价值：它是正确率非常高、而且不需要动脑的解法——只要把它画下来，题就解决了。

    * 适用范围：出现新题型、你看不懂的、没有明显方向性的题，有了新的变形照样能处理。

* **橡皮法的走法**

    * 先定位图形，假设它是最上面那个面。

    * 找到它的右边对应的是哪一块。

    * 拿右边那块一分为四，画出对应的面。

    * 旋转图形，检查另外几块的对应关系。

    * 四个面全画完之后，回头跟选项一一对比。

    * 真实操作中，做到第三步左右答案就已经出来了。

* **本题的判断**

    * > **易错点**：题干画了五个面，但选项里把这四个 1/4 合在一起，那不就是第六个面吗——所以它仍然是六面体，不能因为题干画了五个面就说它不是六面体。

    * 四个选项中只有 B 是一上一下的排布，其他都不是，B 选中；后面把剩下的面画完回头一比，跟 B 一模一样。

* **不用橡皮法的解法**

    * 这个解法有点抽象，需要一点空间想象力：取简单角度切入，把下面那一段当成"四周"，把上面那个当成"盖子"盖下去，再把两个小面各折 90 度折过去。

    * 关键的一步是这两个面是接壤的——因为这两条边其实是同一条边；同一条边把它旋转过去，这两个面最终就会挨在一起，方向一个朝左、一个朝右。

    * 选项里"一个向左、一个向右"的只有 B，这一点直接锁定答案，**答案还是 B**。

* > **结论**：这个题在设置上其实对考生很友好，出题人没有刻意为难你，只要把这两个面搞明白就能选出来。

    * 真要难到什么程度呢？得让你把四个面合一块儿才出答案，那难度就太高了，没什么技巧可言。

    * 真到那一步，最快的解法还是画橡皮。

### 问的是视图，不是截面

* > **定义**：截面图是一刀切下去看能切出什么。

* > **定义**：视图是从某个角度看过去长什么样。

* > **易错点**：一定要看明白题干问的是视图，不是截面图，这两个千万别弄混——这道题最大的问题不是难度，是审题。

* 逐个看选项（题干说的是从任意角度看）：

    * A：从正面看过去，就是主视图，能看到。

    * B：从左往右看或者从右往左看，都是这个图形，能看到。

    * C：从上往下看不是俯视图——俯视图上那条线必须是实线，说明这个地方是接上的、不能是空的，而 C 没把它接上，所以 C 错。

    * 第四个：45 度斜着看。题干说的是任意角度，斜着看过去，上面那两条线、紧接的那两条线、最底下还有一条线，五条线全都能对上。

* C 看不到、第四个能看到，而问的是"不可能"看到的那一个，**答案选 C**。

### 立方体重构：数量排除不掉就死盯灰块

* 这类题的规律就两条：要么简单，做出来走人；要么难，涉及到空间想象能力，想象不到就算了。

* 本题是 3×3 加 5，总共 18 个小方块。

* 第一步数数量直接失效：选项里方块数量都是一样的。

    * > **易错点**：立方体重构现在考数量的题已经很少了；一旦数不出差异，就别在数量上纠缠，转而盯住选项里"数量固定但摆放不同"的那几个块。

* 突破口是题目给了三个灰色块，那就重点看灰块，一个一个去对应原图：

    * 第一个灰块：把它旋转、先立起来再转过来——这一步确实挺费劲，需要点空间想象能力，没有什么好办法；对上之后题目里的一部分块就被"消灭"掉了。

    * 第二个灰块：把它旋转 90 度之后，会发现那两个白块跑到这里来了，黑的第二个就跑到了对应位置，又消灭掉几个。

    * 剩下的就只有两个白色块加下面一个底座这三块了。

    * 第三个灰块：把它原地旋转 180 度，正好对上，**答案选第三个**。

* 难的就是要空间想象能力，没有什么好办法；简单的简单、难的难。

## 图形推理差异题：线条与元素

### 对称轴穿过了几个面

* 特征：拿过来第一反应是两个点，再一细看，三个图形都能看到三个面，而且明显是对称的。

* 先把对称轴画出来：三个竖的，两个横的，方向上分不开。

* 常规的细分考法考过：对称轴跟中间的线形成直角、跟中间的线垂直、跟中间的线平行；把这几个直角都画出来一数，数量上又没有关系。

* 那还剩什么？看对称轴穿过了几个面：

    * 第一个图形：对称轴穿过 3 个面。

    * 第二个图形：只穿过 1 个面。

    * 第三个图形：只穿过 1 个面。

    * 第四个图形：只穿过 1 个面。

    * 第五个图形：穿过 3 个面。

    * 第六个图形：穿过 3 个面。

* **答案选 D（第四个）。**

* > **结论**：这又是一个细化的新考法，表面上对称性没变、本质也没变，但出题人总想挖掘一些你没见过的新角度——对称轴穿过面的数量。

* 这类题只能靠大量刷题：刷过的题会让你感觉到出题人可能往哪个方向考；"跟中间线平行""跟中间线垂直""穿过什么"这些细分类都考过，只是这次突然冒出来一个"穿面"。

### 丁字口多，就是两笔画

* 操作方式：从丁字口出发，挨一笔走一遍，看看能不能回到下一个丁字口。

* 判定标准：

    * 从一个丁字口出发，发现下一个还是丁字口——一笔画。

    * 一共找到四个奇点（四个丁字口）——两笔画。

* 本题逐个走的结果：

    * 从这个丁字口出发，发现下一个还是丁字口——一笔画。

    * 从这个丁字口出发，又是一个丁字口——两个丁字口。

    * 接着还能找到两个丁字口，一共四个奇点——两笔画。

    * 第四个图形：同样是四个丁字口——两笔画。

    * 第五个图形：还是这样——两笔画。

    * 最后一个：从这个丁字口出发，走着走着发现能一笔画完。

* **答案选 C。**

* 其它方向无效：去数面，对面之间是没规律的；回过头来还是得从一笔画入手。

* 识别信号：一团一团的线条，而且你能明显感觉到有一个是可以一笔画成的，就顺着这个方向走，一定搞得定。

* > **提示**：走投无路的时候，就想一笔画——很多线条型题的最后一步都在这儿。

* > **易错点**：这类题要是"就是看不出来"，那绝对是你题刷少了。

### 小元素：别数数量和种类，数面

* 识别：一看就是小元素，看不出来的话就过分了。

* 小元素第一件事是数数量——一看全是九个，不用看了。

* 第二个是数种类——123456789，9 种；数量也是九、种类也是九，说明数量和种类都跟它没关系。

* 那就别想复杂了——数窟窿，数封闭的区域，也就是数面。

* 适用范围：有些字母题、汉字题、数字题，遇到这种情况数窟窿特别好使；有些小学生做不出来的题，可能幼儿园、没学过数字的人反倒做出来了，靠的就是数面这双眼睛。

* 一数就是规律：

    ```text
    第 1 幅：1、2、3、4
    第 2 幅：1、2、3、4、5
    第 3 幅：1、2、3、4、5
    第 4 幅：必然是 5 个一组
    ```

* **答案选 D**，这题做多了也比较容易想到。

## 定义判断与语句表达差异题

### 化学动力学必须落在化学反应上

* 化学动力学研究的是化学反应速率和反应机理。

* 后面那一堆不用看：既然研究化学反应速率和机理，那下面举的东西必然得是一个化学反应；题干没体现，说明你选的那个选项不满足这个前提。

* B 选项是蒸腾作用，这是一个物理反应。

| 反应类型 | 判断标准 |
| :--- | :--- |
| 化学反应 | 有新物质生成 |
| 物理反应 | 没有新物质生成 |

* 蒸腾作用没有新物质生成，所以是物理反应，这是九年级化学最先教的东西，**答案选第二个**。

### 语句表达看它要你关注哪儿

* 解法上没有什么巧办法，五个句子都得读一读，因为选项全涉及到了。

* 第一个选项：为什么夏天看到的夜空星星比冬天看到的多？它对应的是第五个"为什么"。这句话最核心想表达的不是地点，而是一个问号，要引起你关注的是背后那个原因。

* 第二个选项：给了一个时间，又给了原子弹爆炸成功。哪个是重点？不是前面那个时间，重点是原子弹爆炸成功这个事件本身，对应"突出报道事件本身"。

* 第三个选项：杨先生带着两岁的女儿去看病，没想到一个咳嗽就要花 1000 多元。这句话想突出的既不是杨先生也不是女儿，而是这件事本身——一个咳嗽就要花 1000 多，还是对应第二个。

* 最后一个：高考状元"为什么"在某某省消失了。它想引起你对何地的探索——为什么是这个地方、这个地方发生了什么变化、为什么这个地方没有了，对应第四个。

* **答案选第二个。**

* > **易错点**：很多人最后一个选了第五个。不是的——它突出的是问号、是"为什么"，对应的是"为什么"那一类；"为什么在某某省消失"强调的恰恰是这个地方，对应第四个。

### 数字农业：直升机喷药是农业机械化

* 题干问的是"没有体现"哪一个，涉及数字农业、数字化技术、数字化表达、可视化表达。

* A：大数据平台上点一下就能看到土壤的各种指标、进行农田管理，完全就是数字化表达、可视化表达，完全体现。

* B：某柑橘产业建立大数据产业中心以驱动发展。方向应该没错，但"大数据中心"还加了引号，到底想干什么说不清楚，最后一句又没什么大作用；它体现了，但表达不严谨。

* C：通过电子标签技术对单个产品赋予信息、进行信息的可追溯，这个其实是正确的；只是说了"单个产品"、没说是"农产品"，表达不严谨。

* 第四个：轻型直升机完成喷药，这跟数字化有什么关系都没有，这叫农业机械化，**答案选第四个**，靠的是对比择优。

* > **结论**：ABC 都体现了（虽然有瑕疵），只有第四个完全没有体现——它百分之百是农业机械化，不存在数字化。

* 成因：这类题目很多时候是出题人从一篇文章里摘出来的，摘抄时不会把每个点都写清楚，往往会做一些删减，可能就没把"农业"这几个字放上去，但它实际上是整篇文章里很重要的一个段落；所以我们只能对比择优。

* > **易错点**：可能有人杠——直升机里不也有程序吗？1921 年就已经有人用飞机喷药了，数字农业肯定是近代才有的词，1921 年的飞机喷药妥妥是农业机械化，不是数字化。

### 对偶之间可以互推词性和含义

* > **定义**：对称推断法其实就是对偶和排比，以及由此推断其相对位置的一种方法。

* 这个概念一般出现的时候都说得比较隐晦、比较书面。

* 解法不是硬啃题干：不理解没关系，去看选项，很多时候你看看选项，就帮你理解题意了。

* 第一个选项："几轩旧南阁子中"的"中"是语气词，构不成排比也不是对偶，排除。

* 第二个选项："急湍甚箭，猛浪若奔"，没问题，这是对偶；它说了"剑"是名词，于是推断"奔"也是名词，这就是相对位置的推断；正常我们理解"奔"是奔跑、奔流不息，但这里取的是奔马之意。太正确了，**答案选第二个**。

* 第三项虽然也是对偶，但它只是单独去说了"立"的含义，没有进行相对位置的推断，不对。

* 第四项也一样，只是单独说了这个"域"的意思，同样没有做相对位置的推断，不对。

* 结论：你不是在硬啃题干，而是用下面的选项反过来帮助自己理解题意。

## 考场取舍与破题习惯

### 止损时机

* 立方体重构给自己 30 秒决定这题做不做：简单能做，就做；想不明白，千万千万不要再耽误下去。

* 如果没有足够强的空间想象能力，还在这儿耗上 2 分钟，2 分钟之后拿到的很可能还是个错答案，那就得不偿失了。

* 行就上，不行就走；等有剩余时间了，你要是觉得自己还能勉强再试，再回来做——但千万不要一头扎进去出不来。

### 兜底方向与积累

* 走投无路的时候就想一笔画，很多线条型题的最后一步都在这儿。

* 定义判断问"没有体现"的那一项时只能对比择优，因为出题人摘抄文章时往往有删减、表达不严谨，只能择优排除。

* 细化的新考法只能靠大量刷题：做题做多了你会有感觉，会知道出题人可能往哪个方向考。

* 表面上很难、考场上不一定想得出来的是这几类：抓"变与不变"的、考对称轴穿面数量的、六面体折纸盒的新变形。

* 还有一道妥妥的争议题题面已经给出来但没有讲解，留给自己做一遍、读一读题干。

## 架构创新

* **架构创新**

    * > **定义**：基本原件不变、整体结构布局改变、产生新功能的创新。

    * 三个要件必须同时对上，任一条不满足即排除。

    * 与定义要件正面冲突的选项是最快的排除方式，比"选项看起来不合理"好使得多；题干第一句就能否掉的选项不必再细看。

* **四个选项的落点**

    * 用陶瓷底板替代传统不锈钢底板：核心原件直接被换掉，与"基本原件不变"正面撞车，题干第一句即可否掉。

    * 改良工艺生产出满足市场需求的薄板：产物仍是薄板，薄板本来就有，不缺功能，"满足市场需求"也不构成一种新功能，过不了"产生新功能"这一条。

    * 可拆卸手柄的锅：以前只有一个手柄用来颠锅，现在多配几个手柄、装在锅的不同位置，可以煲汤、可以做别的烹饪，核心原件没动而换来了其他烹饪需要。

    * 手机聊天软件增加拜年红包：红包的基本架构早就搭建完成，底层代码与核心架构没有变化，变化的是拜年吉祥语和自定义红包图片，而图片本来微信就能发，是人为往里放的内容。

* **判定"拜年红包"同样成立的三条理由**

    * 该词搜索结果清一色是互联网相关语境，既然词的语境是互联网，微信这个软件身上的架构创新就该按互联网语境理解。

    * 十几亿人在过年时同时抢红包、形式各异而不崩溃、每笔钱都准确到账，背后技术量极大；表面看着谁都会，是因为底层代码和核心架构早已搭建完成。

    * 写一篇讲架构创新的论文时可以把这个功能大写特写：底层逻辑没变、背后代码基本没变化，只做了简单微调就满足新功能，这也算架构上的创新。

    * > **易错点**：以上是对"拜年红包"这一选项的个人判断，不是标准答案。该题是"考生回忆版"真题，出题人从未公布正确答案，网络上的答案是同行共同商定出来的，出题人自己认哪一个并不关心。这类题不必纠结，纠结没有意义。

## 定义判断的提分判断

* **定义判断的做题方式**

    * 定义给了几个要件就问什么答什么，按题干所给对应，不需要任何学科基础。

    * 题干问"没有体现""不属于"的，必须把否定的那一项选出来。

* **定义判断的提分空间**

    * 刷几十套卷子和刷一两套卷子，最终结果差不太多。

    * 刷非常多的题对正确率没有明显提高；练到一两百套定义判断时可以回头验证这一判断。

    * 定义判断本身没有可提高的地方：问什么、定义一个东西，跟它对应上就完了。

## 体验式采访

* **体验式采访**

    * > **定义**：你要亲自去体验生活，才能得到最真实的报道。

    * 完整动作链是"体验 → 报道"，两环缺一不可；选项只要断了其中一环就不成立。

* **选项判断**

    * 作家为了解包身工的悲惨遭遇深入工厂、亲身进入包身工的生活，写出报告文学《包身工》：体验与报道齐备。

    * 为了解传销组织的真面目打入内部来揭示这场骗局：深入体验之后再报道，链条完整。

    * 电视台推出"体验 360 行"，派记者体验教师、警察、商贩各一周作系列报道：深入体验之后再报道，链条完整。

    * 报社要求年轻记者沉入生活、了解基层，最后落在"改变官话套话的文风"：只沉入生活而没有报道基层，链条断在后半截。

    * > **提示**：题干并没有要求必须是记者，作家一样可以去采访、去体验生活。报告文学是介于新闻报道和小说之间、兼有新闻和文学特点的散文，作家深入体验后做报告文学式的呈现完全成立。

## 伴性遗传

* **伴性遗传（sex-linked inheritance）**

    * > **定义**：控制性状的基因位于性染色体上，且这个性状只在一种性别上得以体现。

    * 拆成两条判定：基因是否位于性染色体；是否只在一种性别上得以体现。

    * 选项说"常染色体"的直接排除；说"女性发病率高"或"男性发病率高"但两性都有的，不满足"只在一种性别上体现"，同样排除。

    * > **易错点**：看到"常染色体"三个字，而定义说的是性染色体，直接排除，不要犹豫。

* **性染色体的区段结构**

    * 女性的性染色体是 XX，男性的是 X 和 Y；X 较长较大，Y 是男性独有的、又短又小，这一对染色体一大一小并不对应。

    * 常染色体上每个位置都有一个等位基因，性染色体上并不是所有位置都有等位基因。

    * 结构示意：

        ```text
          X 染色体（长而大）                  Y 染色体（短而小）
        ┌────────────────────┐            ┌────────────────────┐
        │ X 独有区段         │            │ Y 独有区段         │
        │ Y 上没有对应基因   │            │ 致病基因在此       │
        │ 致病基因在此       │            │ → 伴Y遗传          │
        │ → 伴X遗传          │            │                    │
        ├────────────────────┤            ├────────────────────┤
        │ X、Y 同源区段      │ ◄═══════════►│ 对应同源区段       │
        │ 此段有等位基因     │            │ 此段有等位基因     │
        └────────────────────┘            └────────────────────┘
        ```

    * X 与 Y 有对应关系的那一段叫 XY 同源区段，这一段上存在等位基因。

    * 致病基因落在 X 独有区段（Y 上没有对应位点、不存在等位基因）就是伴 X 染色体遗传。

    * 致病基因落在 Y 独有区段就是伴 Y 遗传。

* **遗传类型的特征**

    * 伴 Y 遗传表现为父传子、子传孙，因为只有男性携带这条 Y 染色体，它就这么一路传下去。

    * "在家族男性亲属中代代遗传"就是一个伴 Y 染色体遗传，既属于伴性遗传，也可以直接放进伴 Y 遗传里。

    * 广东省考的科学推理科目会考这一块，常识判断里也会考。

    * | 类型 | 特点 |
      | :--- | :--- |
      | 伴 X 隐性遗传 | 红绿色盲，男性多于女性 |
      | 伴 X 显性遗传 | 患者中女性多于男性 |
      | 伴 Y 遗传 | 只有男性有 Y，父传子、子传孙 |

## 负性倾向

* **负性倾向（negative bias）**

    * > **定义**：负性信息比其他信息得到优先的注意和加工。

    * 题目问"下列哪一项没有体现负性倾向"，只需看该项是否对负性信息做了优先的注意和加工。

* **选项判断**

    * 被试者对负面词汇的正确率高于对正面词汇的正确率：对负向信息进行了优先的加工。

    * 传播过程中对一些负面的细节更容易关注和报道：注意与加工都体现。

    * 在同等情况下更注重这些缺点：负向信息得到注意和加工。

    * 只是报道某种违法行为、期望各级政府进行有效管理：没有任何负向偏向，只是客观报道"有违法行为"并希望管理部门管一管。

    * > **易错点**：一定要把"没有体现"的那一项选出来，千万不要因为题干里的"没有"两个字看漏，反过来把体现了的那几项选上。

## 子弹时间

* **子弹时间（bullet time）**

    * > **定义**：一种变速效果，使用在电影、电视节目或者电脑游戏等领域，强化慢镜头或者时间静止等效果。

* **选项判断**

    * 电视剧里女主角目睹车祸发生的过程在她眼前无数次闪现：这叫重复镜头，同一过程不停地闪，没有慢镜头回放也没有让时间静止。

    * 这个人去世后大部分时间都在看以前拍摄的视频、时间在他身上似乎静止：题干只说反复观看，没有慢速播放，也没有时间静止。

    * 小说里没答完卷子祈祷时间静止、然后时间真的静止：定义限定在电影、电视节目和电脑游戏领域，不在小说里。

    * 通过电视转播看到滑雪运动员缓慢地在空中划出优美的曲线、翻转瞬间每个动作都无比清晰：滑雪世界纪录是时速 255 公里，这么快的动作想看清每个瞬间、看出"缓慢地划出曲线"，一定经过了慢放。

* **直播同样可以做慢放**

    * 直播是多机位完成的复杂系统，不是"一个镜头怼在那一直不动"，背后是好多个机器。

    * NBA 直播中经常出现犯规，等裁判宣判会进入几秒的"垃圾时间"，导播就在这段时间里把之前的动作从各个角度慢放，看有没有打手、到底怎么回事。

    * 世界杯足球直播也会在犯规或进球后突然切一个画面，把刚才的动作来一段近距离的慢镜头。

    * 三个错误项都错得绝对时，对比择优只能选它。

## 分布区

* **分布区**

    * > **定义**：把所有位点用最短的连续边界连起来，用这样一个最小的凸多边形来表示；每一个内角都不能超过 180 度；而且必须包含所有的位点。

    * 判定三条：是否包含全部位点、是否为最短的连续边界、每个内角是否都不超过 180 度。

* **选项判断**

    * 有位点落在多边形外面，而且也不是最短的连续边界，排除。

    * 剩下两类形态相近的选项再查内角：某个内角超过 180 度的把它打直、连成直线，得到的正是答案项那种形式。

    * 未做打直处理、内角超过 180 度的形态排除。

## 类比推理的考点范围

* **词与词之间的逻辑关系**

    * 考点就是词和词之间的逻辑关系：比喻、近义、全同、种属、组成、功能、交叉。

    * 关系对上了就出答案，对不上就排除；只有与题干逻辑关系相同的选项才能留下。

* **看不出关系时的应对**

    * 题干里看不出明显关系时，可以转去看选项，从选项的排列逻辑反推题干考什么。

    * 读题干读得一头雾水时不要硬啃，先看选项，往往一下就通了。

### 比喻与近义词

* **花海书山**

    * "花多如海，书多如山"是一个比喻，对应项"车多如流、人多如潮"同为比喻关系。

    * 含"苦雨"的那一组对不上，苦雨是久下成灾的雨。

* **一望无垠**

    * 一望无垠与辽阔是近义词关系；对应项"耳提面命"就是教导的意思，同为近义。

    * > **提示**：一望无垠、耳提面命这类常用成语平时也要积累，它们除了判断，在言语里也比较常见。

### 时间先后与选项借力

* **特征提取、模式匹配和语音识别**

    * 接诊病人、网上挂号、健康宣讲按常识应是先网上挂号、再接诊病人、最后健康宣讲，选项给出的顺序不对。

    * 接到报警、询问证人、勘验现场没有明显的谁先谁后。

    * 租赁船只、发生损害、请求赔偿应是先租赁、再损害、后请求赔偿，顺序也不对。

    * 提交资料、资格审查、报名成功是时间上的先后顺序，对应。

* **选项借力的价值**

    * 对这些术语不深刻时，从选项反推是类比推理里非常实用的一招。

### 职位与工作内容

* **刑事警察与外交领事**

    * 刑事警察与交通警察是并列关系，都是警察各管一摊；外交领事与对外交涉不是并列关系，排除。

    * 刑事警察与公安机关是组成关系，不是种属关系：种属要能造句说"刑事警察是公安机关"，组成则是"他是公安机关的一部分"。

    * "维护主权和对外交涉"中，对外交涉的目的是维护主权，两者对应不上，排除。

    * 刑事警察与刑事事件是工作对象关系（侦办刑事案件），而驻外务官的对外交涉是工作任务关系，前后不一致，排除。

    * 刑事警察的工作内容是打击犯罪，外交人员的工作内容是对外交涉，同为工作内容对应关系。

    * > **提示**：外交领事是派驻他国的代表，比如总领事，是一种职务，类似厅长、司长这样的职务，所以它对应的是对外交涉，不是并列。

### 原材料与全同

* **原棉与脱脂棉**

    * 原棉是原始的棉花，脱脂棉是脱去了脂肪的棉，原棉是脱脂棉的一个原材料。

    * 粘土是陶器的原材料，对应同一关系；这类原材料关系在类比推理里已经出现过很多次。

    * 白酒与烧酒是全同关系，白酒又称烧酒，老白干、烧刀子等同。

    * 镜头是摄像头的组成部分，属组成关系。

    * 视力表的作用是测视力，属功能对应。

* **看不出原材料关系的补救**

    * 看选项能一眼识别关系类型，靠选项反推题干关系。

### 颜色命名方式

* **以植物命名**

    * 海棠红、南瓜橙：海棠和南瓜都是植物，属以植物命名的颜色。

    * 苏丹红：苏丹是国家、首领的名字，命名理由虽无定论，但肯定不是植物。

    * 景泰蓝："景泰"是一个年号，属年号命名。

    * 孔雀：属动物命名。

### 交叉关系

* **匿名投票、实名投票与现场投票**

    * 匿名投票与实名投票是并列关系；投票可以线上投也可以现场投，按实名、匿名分又有实名投票、匿名投票。

    * 实名投票可能是现场的也可能是网络的，匿名投票同样如此，所以匿名投票与现场投票、实名投票与现场投票都是交叉关系。

    * 战国文字是古代文字的一种，是种属关系；金融危机、粮食危机、生态危机是不同领域的并列关系，对不上。

    * 油料作物、糖料作物都是一种经济作物，是种属关系，同样对不上。

    * 早间会议与午间会议是并列的；早间会议可能是工作会议也可能不是，工作会议可能是早间也可能是午间，午间会议与工作会议同样是交叉关系。

## 支持项与代际退化

* **嗅觉退化的结论**

    * 结论：人类的嗅觉经历着不断削弱、逐渐退化的过程。

    * "随着人类的进化，嗅觉中枢在大脑皮层中所占的面积逐渐减少"最能支持这一结论：面积减少即说明它进行了退化。

* **退化的适用边界**

    * 退化指一代人与下一代人之间后代逐代变弱，是代际之间的比较，与基因一代一代传递下去的变化有关。

    * 个体年轻时嗅觉敏感、老年身体机能整体下降导致嗅觉不如年轻时灵敏，是个体在一生中的衰老变化，任何人都一样。

    * > **易错点**：把"不同人群之间嗅觉差异很大、老年人明显低于年轻人"当成了退化支持项，这是把个体衰老错认成代际退化，不该犯这种错误。

* **受体基因数量是无关项**

    * 人类大约有 1000 多个受体相关基因，其中只有 390 个可以编码嗅觉受体；这是两件事。

    * 前面说的是"有 1000 多个受体相关基因"，后面说的是"其中只有 390 个可以表达"，而不是"以前表达了 1000 个、现在只表达了 390 个"。

    * 人类 DNA 上携带着大量基因和各种等位基因，但并不是每一个基因都会表达，人类本来能表达的就很少；这跟进化、退化没有任何关系，只是一个陈述句。

* **跑偏项**

    * 拿嗅觉跟视觉作对比的内容偏离了结论，不构成支持。

## 公式与类型的失效

* **不存在通吃公式**

    * 凡是靠套"哪种削弱类型""哪种支持类型"才能做出来的题，一定是把题干的方向读错了。

    * 很多加强削弱题直接取自真实的生物论文，做删减、提纯后拿来命题；此时不是在给一个现成的逻辑结构挑选项，而是给一段话找它自己的逻辑关系。

* **"退化"类选项的判定**

    * 退化、萎缩、下降都需要前后对比：以前能编码 400 个、现在只能编码 300 个，才叫退化。

    * 题干若只是平铺直叙地陈述一件事，没有给出前后两个时间点或两个状态的数据，该选项就只是一个陈述句，推不出任何"变化"类的结论。

    * > **易错点**：看到"退化""萎缩""下降"，先回头找题干有没有提供前后两个时间点或两个状态的数据，再决定这个选项是否成立。

* **大脑实验能提供的论据层级**

    * 科学至今对大脑的机理理解非常有限：不明白大脑为什么能完成这么多工作，所以做大脑实验时只能机械观测——思考时哪一个区域在动、哪个区域变大、哪个区域变小、哪些部位的电信号有波动。

    * 正因如此，在生物学论文上，"大脑皮层的面积减小"本身就可以认为这里是有作用的。

## 加强削弱的问法与答案方向

### 问法与选项的先后

    * 题干出现"没有""不""不是"这类词，必须先把它圈出来，否则很容易一下就选到相反的方向上去。

    * "最能质疑"里的"最"字要求选项之间做比较，不是找到一个能质疑的项即可交卷。

### "没有质疑"落在加强项上

    * 题干观点：人们认为沙粒漂浮的现象主要来自于静电。

    * 问"没有质疑"，答案一定落在加强项上。

    * 加强项内容：R 行星跟彗星的组成类似，彗星靠近时产生静电、其表面将会发生漂浮；这是从"彗星是这样的"类比到 R 行星上也可能成立。

    * 类比加强有强有弱：人跟小老鼠整体上很多基因、很多情况不一样；有些药在小老鼠身上有用，能不能用在人身上不一样，往往到二期、三期临床才发现对人体不产生效果——在动物身上有效就推断人身上有效，是典型的类比加强。

    * 有质疑的两类情形：

        * 另有他因：表面存在这些东西，它们会带动相关释放；也可能是不受离心力作用时其表面会脱落、速度快。

        * 直接否定论点：静电作用只能扬起小的沙粒，而目前沙粒都是很大很大的，直接告诉它浮不起来。

### "前提"必搭桥

    * 论据：该基因如果被消除掉，离子流速降低；该基因如果过度表达、表达得多了，离子流速增加。论点：该基因对抗旱性发挥关键作用。

    * 论据和论点说的根本不是一回事——前面只说表达、消除、表达，最后导致的是离子流速变化，怎么突然就得出"抗旱"，中间一定得把桥搭起来。

    * 问"前提"时搭桥项是唯一可能：必须把离子流速和抗旱性之间这座桥搭起来。

    * > **易错点**：不要在论据内部找答案。论据和论点说的不是一回事时，问前提必搭桥。

### "最能质疑"要比强弱

    * 观点：这些家长热衷于购买有儿童标签的食品，是因为他们觉得标有这样的食品会会更加营养健康、更加适合儿童。

    * 第一项：我国并没有设置专门的儿童食品分类，这些儿童食品缺乏相关法律法规，也缺乏食品安全的国家标准——连标准是什么、该多少都没规定。标儿童字样的不一定更健康，可以质疑。

    * 第二项：孩子在不同的年龄阶段需求量会发生变化，几乎所有儿童食品都没有明确标识年龄段和适用年龄，买回去的未必更适合自家的孩子，可以质疑。

    * 第三项：所谓儿童食品的成分和普通食品没有区别，甚至可能因添加过量甜味而有害——你标儿童食品、标这些东西又不犯法，也没有法规去规定。这一项先否定"更营养更健康"，再指出可能有害。

    * 第四项：包装设计和食品外观，与食品的观点扯远了，是无关项。

    * A、B、C 都能质疑，但"最能质疑"的是最狠的那个：前两项只是说市场相对混乱、给了一个提示，第三项直接从根上拔掉观点，答案选第三项。

### "不能支持"是无关项

    * 观点：只要完善了物流、提高了人员素质，就能够有效解决电商直播并没有解决的农产品难卖问题。

    * 从业者承认的问题只有两个：物流有问题、直播人员素质有问题。支持他的观点，就要证明这两条确实有问题。

    * 可支持项：

        * 直播内容单调、易引起审美疲劳、不利于树立良好形象——对应直播人员能力不足（这里的"素质"指实际能力）。

        * 生鲜冷链物流无法满足农产品的消费需求——对应物流现在不行。

        * 农村出城的第一公里没有得到完善——对应物流现在不行。

    * 唯一不能支持的是 B：农产品销售环节没有制定统一的标准、质检不足，这不属于从业者的观点范围，是无关项。

## 常识兜底：金属汞与烷基汞

* **金属汞（mercury）**

    * 常温下是液态，而且是常温下唯一的液态金属。

* **烷基（alkyl）**

    * 指甲基、乙基这一类：一个碳上带着若干氢的基团，代表物是甲烷，属于典型的有机物结构。

* **烷基汞**

    * 是已知毒性最大的汞化合物，毒性大于所有其他汞化合物；而有机汞的毒性又大于无机汞，所以烷基汞一定属于有机汞。

* **甲基汞**

    * 毒性比无机汞大 500 倍；比值大的那个不可能是被比较项，所以甲基汞不是无机汞。

* **推不出来的一项**

    * 推不出来的是"有机汞和无机汞不能呈现出液态"。

    * 题干只说金属汞是常温下唯一的液态金属，限定在金属范围内、限定在常温这个条件；题干根本没提有机汞与无机汞的关系，也没给其他温度条件。

    * 化学基础薄弱时也可以硬推：有机汞毒性最大、烷基汞毒性又是所有汞化合物中最大的，所以烷基汞必是有机汞；甲基汞比无机汞大，比值高的那个就不是无机汞。

## 考古类加强削弱

* **论据强度的分布**

    * 加强削弱大致分两类：一类偏理科（如生物学），一类是考古类。

    * 理科类属于近现代科学，只有几百年历史、技术发达，可以做大量实验，所以论据比较充分。

    * 考古面对的是几千年前的东西，古代没有摄像头、没有影像能照下来，也没留下太多东西，所以经典论据读着会觉得稍微有点牵强，但古代留存本来就有限。

* **考古证据的常见来源**

    * 第一类是出土的文物、遗迹、遗址。

    * 第二类是文字记录，比如甲骨文，比如《史记》这样的古代史书。

    * 文字记载是不是一定真实，无法百分之百确定；无限去杠就没法研究了。考古只能靠着一些踪迹来证明一些东西。

* **弥子国遗址题**

    * 结论：推测岳阳新墙河流域古城址等是东周时期迁来的弥子国遗址；理由是东周时期（灭国之后）迁徙到了这里，这一带应是其生活活动与栖息之地。

    * 能支持的两项：一是拿文字记载说明迁徙定居在现在的岳阳，二是与相传弥子国的都城岳阳大体相当——能找到一条文字记载来说明迁到这里，已经相当充分。

    * 不能支持的一项：说他们如今定居在陕西白河县；题干讲的是岳阳，答非所问。

    * > **易错点**："墓地均属楚系"只能算一个很小的佐证，严格说它只说明弥与楚在迁来之前或迁来之后文化相通（弥与楚本来同族同姓，文化相通顺理成章）。很多同学觉得它可疑，其实题干本身也没太说明白；因为 C 错得太离谱，选 C 就可以。

    * > **提示**：这种考古题不要跟它死抠细节，跟政治论述一样，没必要把每道题的细节都抠得清清楚楚。

## 翻译推理的箭头方向

| 逻辑词 | 箭头方向 |
| :--- | :---: |
| 如果……就…… | 前 → 后 |
| 只要……就…… | 前 → 后 |
| 只有……才…… | 后 → 前 |

* **放后原则**

    * 谁是必要，谁是关键，谁就放在箭头的后面。

* **入手方式**

    * 从选项入手，来回对应：看到选项先别急着推，先回头在题干里找它。

* **减税降费题的判断**

    * A 项：大力度减税降费是帮助资金渡过难关的必要举措，属于关键、属于必要，应放箭头后面，即用"资金渡过难关"推"大力度减税降费"，与题干"只有……才……"方向一致。

    * B 项：题干说"稳住市场主体是关键"，关键应放箭头后面；该项用"只要……就……"前推后，把市场主体推到了前面，正好反了。

    * C 项：题干是"只有……才……"，应后推前，即市场法制化推放管服；该项用"如果……就……"推出放管服推市场法制化，顺序错了。

    * D 项：内生动力、吸引力、创造力都落在"才"后面，彼此是并列关系、彼此之间不具备任何推导关系，合起来是一个整体，没有推导性。

    * 答案 A。翻译推理不要想太多，就是按公式把它翻译出来。

## 代入排除：从条件最多的项目切入

* **题面结构**

    * 五人：石、白、于、方、叶；四个项目：单板、跳台、越野、高山滑雪。

    * 每人参加一个项目，每个项目都有一到两人参加；由"每人参加一个项目"和"每个项目都有人参加"两条可反推出分配模式只能是 1-1-1-2。

* **已知条件**

    * ①（石 或 白）参加高山滑雪 → 方参加单板，且于参加高山滑雪

    * ②于参加高山滑雪 → 白与叶均参加单板

    * ③于与方至少有一个人参加高山滑雪

* **设问与推演**

    * 设问：如果叶没有参加高山滑雪，能确定推出什么。

    * 入手项选择：一定从条件最多的那一项入手；高山滑雪这一项已知条件覆盖了五个人，不从它入手就过分了。

    * 条件③"至少有一个人"就是一个或关系：石或白之中有一人参加高山滑雪。

    * 推演过程：

        ```text
        已知：叶 没有参加 高山滑雪
              高山滑雪按 1-1-1-2 分配 ⇒ 石、白、于、方 中必有 1~2 人参加

        分支一（假设）：石 或 白 参加高山滑雪
           |-- 条件① ⇒ 方 参加单板，且 于 参加高山滑雪
           |-- 条件② ⇒ 白、叶 均参加单板
           `-- 核对：单板出现 方、白、叶 三人
                     ⇒ 超过"每个项目 1~2 人" ⇒ 假设不成立
                     ⇒ 石、白 都没参加高山滑雪

        分支二（剩余）：只剩 于、方
           |-- 高山滑雪必须有人参加 ⇒ 于 或 方 参加高山滑雪（条件③必然为真）
           `-- 条件② ⇒ 白、叶 均参加单板
                     ⇒ 白 参加单板 ⇒ 白 没有参加跳台（答案）
        ```

    * 排除逻辑：假设石或白参加高山滑雪，条件①推出方参加单板且于参加高山滑雪，条件②再推出白与叶均参加单板，此时单板上有方、白、叶三人，与"每个项目均有一到两人参加"不符，故假设不成立，石、白都没有参加高山滑雪。

    * 剩余结论：高山滑雪一定得有人参加，所以"于或方参加高山滑雪"必然为真；再由条件②推出白与叶均参加单板。能确定的结论只有一条——白和叶都参加单板，因此白没有参加跳台，选第四项。

    * 其余选项的错误：方参加单板只是条件①成立时的结论，而条件①已被排除，故推不出方参加越野；石参加高山滑雪已被排除；叶未参加单板与"叶参加单板"相反。

## 常识与论文是加强削弱的底子

* 平时做判断推理跟常识有关系，有些题目一定要有基本的常识、基本的积累，不可能零积累就把它做好。

* 后面这些加强和削弱类的题，大多从真正的论文里扒出来，把一些关键词的内容扒出来：到底怎么加强这个结论、哪些证据可以支持、哪些证据不行。

* 跟导师答辩论文时导师挑出的那些问题，本身就是在削弱、在质疑：凭什么通过这个就能得出这个结论，中间缺了哪些东西，论据充分不充分。有过这种经历的人做加强削弱优势很大。

* 你并不需要更多的学习，论文写作与答辩经历本身就是最好的积累；认真写、别总想着抄一点糊弄一点，最后糊弄的都是自己。
