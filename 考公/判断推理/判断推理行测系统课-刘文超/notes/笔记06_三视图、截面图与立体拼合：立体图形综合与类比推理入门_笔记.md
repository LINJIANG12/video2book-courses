# 三视图、截面图与立体拼合：立体图形综合与类比推理入门

## 三视图、截面图与立体拼合的统一视角

* **空间类题型的收官**

    * 三视图、截面图、立体拼合是同一件事的三个视角：面对一个立体，要么把它拍扁成一个平面图，要么拿刀把它劈开看截面，要么把它拆成零件再拼回去。

* **主左俯三视图**

    * 主视图是从正面看，左视图是从左面看，俯视图是从上面看，三者合称主左俯三视图。

    * 原理是投影：立体图形通过正面、左侧、上面这三个方向的投影落到一个平面上，变成三张平面图。

* **三视图题的命题方式与难点**

    * 考试里给的是一个立体图形，再给几个平面图，让你挑出对应视角的那一个。

    * 题型判定很简单：一眼看出是个立体图形，再确认哪个选项给的是哪个方向，剩下的就是照着拍。

    * 这一节的难点从来不在判定，在细节；细节自己不注意就全错。

## 三视图的四条硬规矩

* **三视图一定是平面图**

    * > **定义**：从正面看、从上面往下看、从左面看，看到的都是一个平面图，因为投影落到纸面上的东西永远是平的。

    * 选项里只要画出了立体感——立体的、带透视的、带厚度画法的——不用算，直接排除。

* **原图有线才有线，没线不要自己脑补**

    * > **易错点**：⚠️ 主视图的轮廓只由这个方向上真正能看见的棱决定，看不见的棱不画，不要把自己脑子里补全出来的三维形状当成题面给的线。

    * 看到立体图形顶部是个半圆，就在主视图上补一条弧线把它隔开——这条线是想象出来的，原图里根本没有。

* **被前面挡住的线，考试版是不画**

    * 工程制图里用虚线表示"我看不见，但我还是给你画出来"，考试不是这么考，一般不给这种选项。

    * 把被遮住的部分画成实线是错的；看不见就不画，才是考试过程中最常出的那一版。

    * > **结论**：看见的画实线，看不见的不画，别去选那个"用虚线表示被遮部分"的选项。

* **圆柱的主视图，顶部是一条直线**

    * 圆柱的俯视图是圆，主视图顶部是一条直线，不是圆。

    * 圆柱的主视图和左视图长得一样，顶部都是一条直线。

    * 类比矿泉水瓶：里面都是水，上面瓶口是个圆，但主视图看过去瓶口就是一条横线。

    * > **易错点**：⚠️ 某道题里 A 与 D 只差这一点——A 把圆柱顶画成弧面，D 画成平的，D 对。

## 三视图实战技巧

* **"从任何一个角度"要把方向扩到六个**

    * 一个立体实际有六个方向：正、背、左、右、上、下。

    * 题干一旦把"从任何一个角度"这五个字写出来，就把主视图的三个方向扩成了六个方向，这时候要挨个方向去试，而不是默认在三个方向里挑。

    * 判断某个选项能不能出现，看它那些细线在原图里到底有没有；哪怕原图别处有个斜角，也带不出原图中不存在的细线，任何方向都看不到。

* **多个选项共用同一视角**

    * 题干给的几个图形俯视图都长得一样时，选项里直接找一模一样的俯视图，立体形状连细看都不用。

* **同构选项的排除顺序**

    * 先排掉画成立体感、带透视、带厚度的选项，这是一道基本门槛。

    * 再按主视图上的高度排掉明显画矮画高的选项。

    * 最后逐条核对剩下的细线是否真在原图对应位置上，很多选项的全部差别就落在那一两条线上。

* **展开图先补线再比接边**

    * 先判断是不是展开图：该补的那条线没补上的选项先排掉。

    * 补齐之后再看接的是短边还是长边，与原图里对应位置实际接上的两条边去比长短。

* **手感靠题量，不靠天赋**

    * 做题时脑子懵、方向找不对是正常的，想不到的原因就是做的题实在太少了。

    * 课程里的例题和练习已经非常多但仍不够，课程系统结束之后还需要靠大量刷真题来巩固。

## 立体拼合：先数数量，别急着拼

* **先确认数量**

    * > **结论**：拿到立体拼合题，先数方块数量，对得上就赢了一大半；数量对不上，再去考虑它是怎么拼的。不能一上来就往难处想。

    * 某年国考的多面体拼合题中，正视图这边数下来是 22 个，后视图这边数下来也是 22 个，问号处是缺的，选项里 A 是 4 个、B 是 5 个、C 是 5 个，只有第四个是 6 个。

    * 这道题全程用不上拼合，凭数量就做出来了。

* **真去硬拼的代价**

    * 那个多面体可以拆分成四块，真要拼起来非常复杂，需要非常强大的空间重构能力。

    * 出题人知道硬拼很费劲，所以特意留了一个数量上的口子给你。

    * 考试时间那么短，除非是专业来学的，否则不要去碰那个空间结构。

## 截面图与剖视图

* **截面图**

    * > **定义**：截面图就是你切出来的那一个面本身。

    * 概念来自菜刀"咔"砍一刀，砍完之后的那一个面就是截面图。

* **剖视图**

    * > **定义**：剖视图是从这个方向往里看投影出来的东西，等于中间那个截面加上零件的外轮廓，合起来是整体。

    * 描述零件、描述图形时，从中间切开了之后的投影，就是剖视。

* **两者的差别**

    * > **结论**：考试里问的永远是截面图，不是剖视图；千万不要把截面图想象成剖视图，这两者一定要区分开。

    * 截完以后只有刀刃走过的那个面，上下多出来的那些线在截面上根本不存在。

```text
       菜刀"咔"一下，横着切过去

       ┌──────────┐
       │  小零件  │ ───────────▶  刀刃走过的那个面  =  截面图
       └──────────┘                      （只有切面本身）

       ┌──────────┐
       │ ┌──────┐ │                    切完以后往里看到的东西
       │ │ 切面 │ │ ───────────▶  切面 + 整个外轮廓  =  剖视图
       │ └──────┘ │
       └──────────┘
```

## 一刀切原则

* **只能一刀下去，不许拐弯**

    * 所有的切都叫一刀切：砍的时候一直往下砍，不能斜着砍到一半突然横着砍。

    * 非常多的同学会犯这个错误：切着切着，从这个图形切到那个图形，到下面就拐弯了。

    * 一刀切原则在后面的例题里会反复起作用。

* **切面是平面**

    * 一刀切出来的切面是一个平面，所以截面只能是一个平面图形。

    * 拐弯切出来的是两段拼出来的"面"，实际上不是一刀切，得到的不是一个截面。

```text
       一刀切  ──►   ╲
                      ╲
                       ╲      切面是一个平面，
                        ╲     所以截面只能是一个平面图形

       拐弯切  ──►   ╲
                      ╲__
                         ╲     这是两段拼出来的"面"，
                          ╲    实际上下刀得到的不是一个截面
```

## 常见立体各能切出什么

| 立体 | 切法 | 切出来的截面 |
| :--- | :--- | :--- |
| 正方体（六面体） | 拦腰横切 | 矩形（正方形） |
| 正方体 | 上下竖着切 | 矩形 |
| 正方体 | 斜着切 | 矩形 |
| 正方体 | 斜切，且保证上下两边平行 | 梯形 |
| 正方体 | 从一条棱斜着切 | 三角形（只能是锐角三角形） |
| 圆柱 | 横着切 | 圆 |
| 圆柱 | 斜着切 | 椭圆 |
| 圆柱 | 斜着或竖着切 | 矩形 |
| 圆锥 | 横着切一刀 | 圆 |
| 圆锥 | 斜着切一刀 | 椭圆 |
| 圆锥 | 从最中间竖着切 | 三角形 |
| 圆台 | 横着切一刀 | 圆 |
| 圆台 | 斜着切一刀 | 椭圆 |
| 圆台 | 竖着往下切 | 梯形 |

* **正方体切矩形**

    * 拦腰切、上下竖着切、斜着切三种都可以切出矩形（正方形），是最容易的一类。

* **正方体切梯形**

    * 梯形的特点是上下两个底平行，只要保证这俩平行，斜着切一刀就是一个梯形。

* **正六面体只能切出锐角三角形**

    * 从一条棱斜着切，切点处的角最初是 60 度；往下移这个角度在增加。

    * 但一直往下移到三个边合在一起变成直角的时候，切出来已经不是三角形了——横着切切出来的是矩形。

    * > **结论**：正六面体只能切出锐角三角形，切不出直角，更切不出钝角；题干给的是六面体，选项里出现直角三角形或者钝角三角形，一定是错误答案，没有任何疑虑。

## 截面实战判断

* **上下两截形状不一样：拆开来一块一块对**

    * 立体由上下两个部分构成、选项也分上下两截时，先拉一条横线，把选项和立体都按结构拆成上下两部分，一块一块去对。

    * 只要有一块对不上，整个选项就废了。

    * 沿同一方向继续往下扩大截面时不能拐弯，斜着切下去，下半部分只能出梯形。

    * > **提示**：这类题最容易被骗的是下半部分，因为大家都习惯性地在下面画一个规规矩矩的矩形。

* **求"截不出来"的那一项**

    * 逐项验证每个形状是否真能被一刀切出来；正三角形、矩形、梯形在正方体上都随手可切。

    * 从上往下切一刀时，截面上除了刀刃走过的那个面，上下多出来的部分都不存在，切不出带多余部分的形状。

    * 遇到看似复杂的选项先别慌：随便找个地方切一下往往就出来了。

* **正方形随手可切**

    * 切一个正方形——从正方体上随便切一下，非常可以。

    * > **易错点**：⚠️ 对一个正方体再切不出一个正方形来，可就完了是吧——正方形是随手可切的。

## 立体截面：一刀切的判定方式

* **一刀切**

    * > **定义**：截面图就是一刀切出来的那个平面——一刀下去，不许拐弯。

    * 切出来的面是"平"的：切到底、切到哪儿，中途不能转弯改变方向。

    * 常见立体中必须逐一掌握各自能切出什么：圆柱、圆锥、圆台、六面体。

    * > **结论**：截面的功夫不在某一道题上，而在"每一种常见立体都能切出什么"这张清单上；这张清单靠练，不靠听。

* **挨个选项试切**

    * > **规则**：能切出来的留下，切不出来的排除；四个选项逐个试过去即可。

    * 判据是切的过程本身，不需要先理解整个立体结构。

    * 试切时先看"大形"对不对，再把选项上的每一条线都往上对。

    * > **易错点**：切的时候不要只盯着大形对不对，要把选项上每一条线都对上；选项上多出一条线，而题干里怎么切都切不出这条线，这就是秒杀点。

* **切不出来的两种表现**

    * > **易错点**：D 会在切的过程中"多出一块"或者"拐弯"——这是排除的信号。

    * "多出一块"：切到中途截面形状位置上多出了不属于目标图形的部分，多出来的部分没有地方可以承接。

    * "拐弯"：目标图形的某个角在切的过程中必然发生转折，而一刀切不允许转折。

    * 截面题里常出现"看起来是某个面本身就有的形状"作干扰项，此时要往该面内部去试切，而不是只在该面上切。

* **简单截面与复杂截面**

    * 简单的截面一刀即可得到，比如从某个规则面的中部竖着切一刀。

    * 复杂的截面需要绕到立体内部去切，背部结构复杂不构成障碍，切割方向正确就能得到。

    * 例六的秒杀逻辑是：题干上根本不存在选项所画的那条线，无论怎么切都无法产生，直接排除。

## 立体拼合：凸凹一一配对

* **凸凹配对**

    * > **定义**：多个立体图形或平面图形拼合在一起时，必然有凸必有凹、有凹必有凸。

    * 机理如同榫卯：这块缺了一块，就由另一块凸出来的地方把它补上；有凸出来的地方，一定有一个凹进去的地方把它接住。

    * 配对关系如下：

        ```text
        凸(A)  <--->  凹(B)     可以拼
        凸(A)  --x--  凸(C)     没有人接
        凹(A)  --x--  凹(C)     没人扣
        ```

    * 凸只能配凹，凹只能配凸；一旦两头都是凸，就没有地方承接它，直接排除——立体拼合题八成的排除都是这一刀。

* **凸和凹一一配对，简单题直接秒杀**

    * 判定路径：先在题干里找凸出的部件，再逐个选项看有没有对应的凹去承接。

    * 出现两个凸而没有对应凹，排除。

    * 出现"能承接住题干凸出物，但自己又多出一块凸"，排除——多出的那一块同样没有地方接住。

    * 四个选项都没有凹可以承接，答案就在剩下那个选项。

* **选项图一复杂就看区别**

    * > **提示**：图一复杂的时候不要硬去想象怎么拼，而是把四个选项摆在一起比——先找到那两个"很明显有区别"的部件，再看这个区别在四个选项之间是怎么摆放的。

    * 判断步骤：先在原图上标出"凸出来的小东西"和"被截去一块"这两处，再看它们在选项中是否仍处在同一侧。

    * 把这两个部件拆到左右两侧的选项（一个在左、一个在右）错误。

    * 剩下两个候选再比它们自身的差异，差别落在哪一块上，答案就在哪一块对应的选项上。

* **数量相等时数数量失效**

    * > **易错点**：数数量是这类题的思维定式，但只要选项里各块的"个数"一样，数数量就必然失效。

    * 题目要求三块拼合时，先确认只拿指定的几块去凑，块数少时拼合难度明显下降。

    * 数量路线走不通时改走转动：把每一块转个方向，试着往缺口上凑。

    * 摆放顺序是任意的，最终呈现的立体可以把选中的答案图整体调转方向来看，判断不受影响。

* **小部件位置辨析**

    * 有的小立体并不在最外沿，而是在中间；对照"在边上"时应该是另一幅画法，那个位置会和两侧接上。

    * 读图时先确认这个小立体到底在边上还是在中间，避免按想象中的在边画法去配对。

## 类比推理的题量、时间与题型

* **类比推理**

    * > **定义**：在两个词或者三个词之间，找出逻辑关系最贴近的那一组；题干给两个词或三个词，选项要选和它逻辑相近的。

    * 考纲原文为"最为贴近或者相似的词"，"最为"意味着必须选一个最好的。

    * 若出现两个选项都有道理，就选最有道理、最好的那一个，这个思维要始终带着。

* **题量与目标正确率**

    * 国考固定 10 题；省考不好说，可能缩减为 8 题或 7 题，不固定。

    * 目标是对上 9 个，错一个左右；这 10 题比较简单，属于必须拿分的部分。

* **允许错的两类**

    * 第一类是与常识绑定在一起的题。比如国家与城市的对应，不知道就真做不出来，情有可原。

    * 常识类的植物名（如马蹄莲、蟹爪兰）反倒还好，可以分析出来；真正做不出来的是纯事实性对应。

    * 第二类是出得别扭的题，尤其考对应关系时有一道就是找起来很别扭，怎么都觉得不够清晰、不够好。

* **时间分配**

    * 一般 5 到 8 分钟内把这 10 题做完，有时候一眼就能看出答案，一般情况下 5 分钟就够。

    * 个别题觉得好像能做出来、好像多想一想可以做出来，也绝不能超过 8 分钟。

    * 一定要掐好时间，锁定在 5 到 8 分钟之间完成。

* **三类逻辑关系**

    * 语义关系。

    * 逻辑关系。

    * 语法关系。

    * 语义关系里最基础、最常考的是近义词和反义词、比喻和象征意义。

## 语义关系之近义词与反义词

* **近义词**

    * 基础词对：理想与梦想。

    * 加难度的词对：锲而不舍与坚持不懈这类近义成语。

    * 近义词的近义，如拉与扯、拖与拽、推介与推荐，本身是近义而非反义。

* **反义词**

    * 基础词对：勇敢与懦弱、言而有信与言而无信。

    * 语义不同的两个对象不构成反义：河水与海水只是并列的水体；山峰与深渊是两个不同的自然景观与自然现象。

    * 怀疑的反义词是信任；守信指的是信守诺言，与信任不是一回事，不能当成怀疑的反义词。

* **成语在这一考点里的考法**

    * > **易错点**：为了类比去做大量的成语积累是用不太到的，平时做言语时积累的那些成语，在类比这里就足够了。

    * 与言语里的成语区分：言语考察两个相近成语之间的细微差别，类比推理不考这种细微差别。

    * 掌握标准是正常人的语文水平、正常积累的成语，通不过字面理解大致能判断出来即可，题目不会出得太复杂。

* **两个选项同属近义或反义时做二级辨析**

    * 触发条件：仅凭近义词/反义词判断不能选出唯一答案，可能两个选项都是近义词或都是反义词。

    * > **规则**：一定有一个更好的，需要做二级辨析——把两者再细分，看有什么区别。

    * 二级辨析的三个角度：感情色彩、词性、词语结构上的区别。

    * 感情色彩分为褒义词、贬义词、中性词；成语二级辨析中褒贬义是最常考也最好用的一条。

    * 判据是配对方式与题干一致才留下：题干是"褒义＋贬义"就选褒对贬，题干是"贬义＋中性"就选贬对中性。

    * 词语结构上也要对齐：像"大小同异"这类词，拆开是大与小反义、同与异反义，自身形成两对反义词；选项也应当是这种词性结构。

* **词内还套着两对反义词时拆结构**

    * > **规则**：这类题不看两个词整体是什么关系，只看词"里面"那一层的结构。

    * 成败与呼吸之间没有直接语义关系，但成与败是反义、呼与吸也是反义，两层内部都是反义。

    * 逐个选项检查内部两层是否都构成反义：好与歹是反义、有始有终内部也是反义，保留。

    * 内部两个字不构成反义关系的选项排除。

    * 内部构成的是近义关系的选项（如拉扯、推介）排除。

* **近义词题最易踩的维度错位**

    * > **易错点**：把"两个不同的维度"当成同一组词。看到一对并列的词，先问一句：它们说的是不是同一件事的两个面？

    * 生死与存亡是近义：生与死就是存与亡。

    * 轻重与缓急不是近义：轻重说的是物体的轻重，缓急说的是水流的缓或急。

    * 亲疏与长幼不是近义：亲疏说的是关系的亲密或疏远，长幼说的是辈分。

    * 真伪与对错不是近义：真伪说的是真假，对错说的是是非。

    * 好坏就是优劣：好即优、坏即劣，是真近义词。

## 比喻和象征意义

* **判定原则**

    * > **结论**：比喻和象征不用硬分——不用去论证"月亮—玉盘"到底算比喻还是象征，会做题就够了。

* **比喻与象征的典型对应**

    * 月亮弯弯时像镰刀、圆圆时像玉盘；玉盘是把月亮比喻成玉盘。

    * 松鹤同春、松鹤遐龄，都表示松鹤象征长寿。

    * "驾鹤西去"也是长寿之意：鹤一直被认为与神仙相伴，鹤长寿，所以"驾鹤西去"是变成神仙、羽化登仙的委婉说法，指离世。

* **可用的象征对应**

    * 白发象征沧桑。

    * 乳牙象征稚嫩，是小孩子才有的牙。

    * 七寸对应要害，或者对应事物的关键。

    * 眉目对应头绪："这事有眉目了"即有头绪了。

    * > **易错点**：脉络对应不了头绪——脉络指整个事情从头到尾的脉络，头绪只是刚有个开头。

* **撑不起语义的对应**

    * 酒窝对应不了清纯：人长得丑或美都可能有酒窝，与清纯无关。

    * 眼镜对应不了博学：现在幼儿园就有小孩戴眼镜，戴眼镜不等于博学。

## 类比推理的判断顺序

* **判断顺序**

    * > **定义**：先比含义，用含义确认类比关系；含义确认不了、需要二级辨析了，再去看形式，也就是词性、结构、感情色彩。

    * 含义能确定关系，直接定答案；含义确定不了，才进入形式比较。

    * 逻辑关系对上只是入场券，最后一定要找一个更好的、更贴近的选项。

    * > **易错点**：绝不能一上来就比词性。含义上已经直接判错的选项，根本轮不到形式上场。

* **"能对上"不等于"对得上"**

    * 任何对应都要经得起把具体项换掉的检验：把七寸换成六寸、五寸、三寸还成立，才叫关系。

    * 七寸之所以能和要害绑在一起，是因为它是个固定的象征说法；一换成"尺度"这个泛指的大类，就散了。

    * > **易错点**：选错的通常不是不会，而是把自己说服了，却没说服题目。

```text
类比推理的判断顺序

  [ 第一步：比含义 ]
        |
        +-- 含义能确定关系 --------> 直接定答案
        |
        +-- 含义确定不了
                |
                v
  [ 第二步：比形式 ]
     词性 / 结构 / 感情色彩
                |
                v
  [ 找一个更好的、更贴近的 ]
```

含义优先，形式垫后；最后一步，"更好"优先于"对就行"。

## 语义关系

* **近义成语辨析**

    * 指鹿为马是赵高干的，本质就是颠倒黑白，两者近义。

    * 师心自用、固执己见、刚愎自用是同一组近义词，都表示自以为是。

    * 邯郸学步与东施效颦是近义词：都是模仿别人、模仿不成、效果非常差。

    * 如法炮制与依样葫芦是近义词，都是照着别人做。

    * 滥竽充数与鱼目混珠是近义词，都是以次充好、以假乱真。

    * 陈词滥调与老生常谈是近义词，都是没有什么新鲜的了。

    * 按部就班与循序渐进是近义词，都是一步一步来；博闻强识与见多识广是近义词，都是见识广。

* **一级近义通过后的二级辨析**

    * 感情色彩是二级辨析的主要落点：邯郸学步与东施效颦都是贬义，如法炮制与依样葫芦都是中性，滥竽充数与鱼目混珠都是贬义，贬义对贬义才定答案。

    * 陈词滥调是贬义、老生常谈是中性；A 项按部就班与循序渐进都中性，B 项博闻强识与见多识广都算褒义，只有 D 项八面玲珑是贬义、面面俱到是中性。

    * > **易错点**：见义勇为属于助人为乐，是种属关系，不能当近义词划等号。八面玲珑偏贬，面面俱到居中，看着都是"面面"，感情色彩不一样。

* **高频易混成语对照**

    读音只差一个字的成语，意思往往差着一个方向。

    | 成语 | 含义要点 |
    | :--- | :--- |
    | 不负众望 | 不辜负大家的期望 |
    | 不孚众望 | 不能让人信服，"孚"即让人信服 |
    | 众望所归 | 众人期待 |
    | 目无全牛 | 技艺精湛到不用看整头牛就能下刀 |
    | 鼠目寸光 | 眼光狭小 |
    | 不以为然 | 不认为是正确的 |
    | 不屑一顾 | 鄙视、瞧不起 |
    | 循规蹈矩 | 规规矩矩遵守规则 |
    | 步人后尘 | 走了别人的老路 |
    | 兔死狐悲 | 为同类的不幸感到悲伤 |
    | 狗仗人势 | 倚仗别人的势力欺压人 |
    | 八面玲珑 | 偏贬义，形容一个人圆滑 |
    | 面面俱到 | 中性，好的坏的都往上靠 |

* **象征关系：含义分不开就看词性**

    * 荆棘象征困难（荆棘密布），是比喻。

    * 智库是满清十大酷刑里的一种刑具，象征束缚。

    * 折柳象征惜别。

    * 布衣象征的是百姓，不是学生。

    * 心腹比喻的是信任的人，不是"信任"本身。

    * 荆棘与智库都是一件事物、一个名词，折柳是一个动作；名词对名词更工整。

    * > **易错点**：布衣与心腹两压根不需要看形式——它们的含义直接就错了，轮不到词性上场。

* **无逻辑关系时改看结构**

    * 古为今用与天罗地网之间没有逻辑关系，但两词都由反义词拼成：古/今、天/地。

    * 整体看不出规律时，把词性结构划分开逐组核：A 项里外是反义没问题，另一组"因"和"圆"不是反义关系，排除；左右、深浅都成立的选项才是答案。

## 逻辑关系：全同

* **全同关系（identity）**

    * > **定义**：A 集合和 B 集合完全相同，A = B，A 就是 B，B 就是 A。

    * 这是整个逻辑关系里唯一一个可以直接写等号的关系，如老鼠就是耗子，浪漫就是罗曼蒂克（romantic）。

    * 判定方法：把题干两词换成等号，再代入选项两词检验，等号仍然成立就是全同。

* **集合过大导致等号不成立**

    * 四季等于春夏秋冬，全同成立。

    * 情绪不止喜怒哀乐，等号不成立。

    * 颜色不止赤橙黄绿青蓝紫，现在配色几百上千都配得出来。

    * 早中晚涵盖不了一天，上午、下午、后半夜都落不进去。

    * 四方在古代指的就是东南西北，全同成立。

* **常识型全同题**

    * 五行 : 金木水火土，对应五味 : 酸苦甘辛咸，这五味出自《黄帝内经》。

    * 五音 : 宫商角徵羽；五色 : 青黄赤白黑，古代五色里没有绿。

    * 四书是《大学》《中庸》《论语》《孟子》，五经是《诗》《书》《礼》《易》《春秋》；《大学》属四书不属五经。

    * > **易错点**：五音里那个徵字特别容易写成"止"，写错即废。

    * > **提示**：这一组题把类比和常识焊在一起，常识储量不够就只能靠排除硬猜，错误率自然高。

* **亲属称谓：全同还是对应**

    * 岳父就是丈人，全同；祖母就是奶奶，全同。

    * 舅舅和外甥是对应关系：你是我的舅舅，我是你的外甥；伯父和侄子同理。

    * 姨妈是母亲的姐妹，也就是你妈妈的姐姐和妹妹。

    * 婶婶是你叔叔或伯父的老婆，与姨妈不是同一人。

    * > **易错点**：家庭称谓不能乱套，祖母和外婆指的是不同的人。

## 逻辑关系：并列

* **并列关系（parallel）**

    * > **定义**：两者属于同一类东西，各自都是同一大集合里的一个成员。

    * 生和死都是一种生存状态；苹果和香蕉都是水果；黑和白都是颜色。

    * 并列还要再分成矛盾关系和反对关系两种。

* **矛盾关系（并矛）**

    * > **定义**：设一个大集合，不是其中之一就是另一个，没有第三种状态，大集合被这两项分尽。

    * 人的生存状态里，不是生就是死。"虽生犹死"仍算生，"半生不死""半死不活"人家也还活着。

    * 盈利与非盈利：一分钱没挣是非盈利，持平也是非盈利，两项占满整个集合。

    * 动与静：我们不是在动，那不是动就是静。

    * 取与值：除了取就是值。

    * 开与关、盈利与非盈利、动与静、取值都属于此类。

    * > **结论**：题里同时出现"不"字或"非"字的一对词，合起来一定是并列里的矛盾关系——对称/不对称、盈利/非盈利都是这样，因为带了这个字，它已经把整个集合占满了。

* **反对关系**

    * > **定义**：两个词同属一个大集合，但只占大集合的一部分，除这两项之外还有其他成员。

    * 颜色集合里有黑色、白色，还有绿色以及红、黄、蓝等，黑与白是反对关系。

    * 水果集合里除苹果、香蕉外还有别的水果。

    * 情绪里除痛苦、快乐外，还有喜怒哀乐、忧思悲恐。

    * 方向里除东、西外还有南北、东南、西南。

    * 贫富之外还有小康、不穷不富的中产阶级；黑白之外还有赤橙黄绿青蓝紫。

    * 手风琴与钢琴都是琴，除此以外还有其他琴；足球与乒乓球同理。

    * 番茄与白菜都是蔬菜；篮球与蹴鞠都是运动。

    * 人民币、美元、欧元都是各国货币单位，货币单位这个大集合里还有很多别的成员。

    * 黑与白不是反义词，它们都是一种颜色。

```text
并列关系之一：矛盾关系（并矛）

  [ 人的生存状态 ]              <- 整个大集合
      |- 生
      `- 死

  不是生就是死，没有第三种状态  =>  矛盾关系


并列关系之二：反对关系

  [ 颜色 ]                       <- 更大的大集合
      |- 黑色
      |- 白色
      |- 绿色
      `- ……（红、黄、蓝……）

  黑与白之外还有其他颜色        =>  反对关系
```

矛盾是把大集合分尽了，反对是这两项只占大集合的一部分。

* **矛盾与反对的判定方法**

    * 核心就一个问题：除了这两个，还有没有第三个。

    * 先按反义词去做；做出来了就选，做不出来，回过头再想并列里的矛盾。两者不冲突，是先后顺序的问题。

    * 生死是反义词吗？对称和不对称是反义词吗？先按反义词试，做不出来再转并列里的矛盾。

    * 工作与休息做不成反义词：不工作就是休息？去健身、去篮球、听直播，哪一样都不落在这两头。

    * > **易错点**：矛盾与反对判不清是这一节错误率的主要来源，原因就一个——没把"除了这两个，还有没有第三个"这个问题问到底。

* **顺序敏感型题干**

    * "往里带"的题干，判定形态是物品在前、场所在后。

    * 舞台演奏钢琴 : 乒乓球在球台上打——钢琴在舞台上，乒乓球在球台上，逻辑说得通，但顺序反了。

    * 音乐家演奏钢琴 : 运动员打乒乓球——题干是物品在前、场所在后，这一项是人在前、事在后，顺序还是反的。

    * 番茄来自美洲 : 蹴鞠来自中国，顺序反了。

    * 琴声 : 钢琴 搭配 喝彩 : 乒乓球——钢琴有琴声，乒乓球对应的是喝彩，对应关系不合适。

    * > **易错点**：逻辑方向反了就是错，"听着也说得通"救不了它。

* **二级辨析：找一个更好的、更贴近的**

    * 羌笛 : 钢琴 : 马褂 : 长袍，与 胡琴 : 钢琴 : 马褂 : 西服，逻辑关系都成立，都是并列里的反对。

    * 胡琴是中国的、钢琴是西方的；马褂是中国的、西服是国外的，都是"中国—国外"的对照，后者更整齐。

    * 组成关系和种属关系不能错配：琴键是钢琴的组成部分，这条成立；就算假设马褂是唐装的一种，那也是种属关系，与组成关系对不上。

    * 剧种与乐器不同层，不能并列：京剧跟昆曲放一块可以，把一个剧种跟一个乐器放一块不行。

    * 类目层级不同不能并列：贵州是省，杭州是省会城市，常州是地级市。

    * 宽恕与品性无关，诚信才是一种品性。

    * 番茄炒饭与健身蹴鞠之间没有逻辑关系；"人类是一种蹴鞠"是种属错配。

    * > **结论**：逻辑关系对上了只是入场券，最后一定要找一个更好的、更贴近的。
