# 2023年国考判断推理（地市级卷）真题精讲

## 黑白块与黑白点的六条思考方向

小黑白点、黑白块、黑白圆这一类图形，常见的考法与观察对象可以先固定下来，拿到题按顺序一个一个对。

| 考法 | 看什么 |
| :--- | :--- |
| 平移 | 横向移、竖向移、内外圈顺时针或逆时针移，或者旋转加翻转 |
| 部分数 | 数黑色、白色各自由几部分构成 |
| 对称性 | 黑块白块各自对不对称，以及对称轴的方向 |
| 点连接 | 黑色方块是不是靠"顶点对顶点"连起来的 |
| 一笔画 | 把黑色连起来，能不能一笔画完 |
| 黑白运算、加减同异 | 前两个推出第三个，一般只在九宫格或"三推三"里出现 |

> **提示**：排除法一个选项都排不掉时，说明数量之外的那把钥匙还没找到，不要在数量上硬磨。

### 平移

* **平移（translation）**
    * > **定义**：整个图形沿固定方向做位移，不改变内部结构。
    * 横向移动与竖向移动是最常见的两种。
    * 有内外两圈时，可分别顺时针或逆时针移动。
    * 也可以是"旋转加翻转"的组合运动。
    * > **易错点**：图形杂乱、黑白元素数量多且分布平均时通常不走平移，因为要逐个位置去数，太费劲。

### 部分数

* **部分数（connected components）**
    * > **定义**：数出黑色区域、白色区域各自由几块连通部分构成。
    * 考白色的部分数和考黑色的部分数都可能。
    * 规律常表现为一部分、两部分、三部分、四部分、五部分的递增序列，找到缺的那个即可。

### 对称性

* **对称性（symmetry）**
    * > **定义**：考察黑块、白块各自是否轴对称或中心对称。
    * 除图形本身的对称外，还要看对称轴的方向在序列中怎么变化。
    * 某一幅图形的对称若先映入眼帘，往往就是整道题的破题点，后面不必再数。
    * > **易错点**：⚠️ 画法特殊的对称容易被看漏——第一幅图形的白色其实对称，只是线条画得让人不易察觉，要等到后面某幅图形的对称被认出来，回头才敢确认它。

### 点连接

* **点连接（vertex connection）**
    * > **定义**：判断图形中某色部分是不是靠"顶点对顶点"的方式首尾连起来。
    * 只有点与点相接的图形才符合，靠线段连接的图形不符合。

### 数量与对称都不够时

* **组合考法**
    * 同一道题可以先数数量排掉选项，再看对称，再看点连接，三层考点叠加。
    * 只用数量和对称两层都排不掉任何选项时，说明还存在第三层考点没被识别。

## 一笔画

### 判定工具

* **奇点（odd vertex）**
    * > **定义**：一个点上有三条线伸出，该交点的个数就是奇点数。
    * 奇点数等于能起笔的端点数。
* **丁字口**
    * > **定义**：一个点上伸出三条线的交点，与奇点是同一个东西的不同叫法。
    * 形状像"丁"字，是最容易在图上直接找出来的特征。
* **笔数（stroke count）**
    * > **定义**：最少需要几笔才能把图形连着画完。
    * 规则：笔画数 = 奇点数 ÷ 2。
    * 奇点为 0 时是一笔画。

### 图形与笔画数

* **"日"的变形图**
    * > **定义**：一个封闭区域，中间有 1 条封闭的线把它分开。
    * 0 个奇点，一笔画。
    * 分割线即使与外框沾了边，本质仍是 1 条线，仍是"日"的变形图。
* **"田"的变形图**
    * > **定义**：一个封闭区域，中间有 2 条线把它分割开。
    * 4 个丁字口，4 个奇点，两笔画。
* **分离图形**
    * 两个分离的图形，笔画数各自算完再相加。
    * 内外分离时就是"外面一笔画、里面一笔画"，合计两笔画。

### 识别信号

* 数面找不到规律时，改看端点与交点。
* 一笔画题里大量出现"一眼就能沿着线条画完"的封闭图形，通常是提示。
* 出现两端各长出一个角的双端点结构，说明存在丁字口奇点。

```text
"日"的变形图  =  一个封闭区域 + 1 条分割线  →  0 个奇点  →  一笔画
"田"的变形图  =  一个封闭区域 + 2 条分割线  →  4 个丁字口  →  两笔画

丁字口：一个点上伸出三条线的交点
奇  点：丁字口的个数，也就是能起笔的端点数
笔  数：笔画数 = 奇点数 ÷ 2（奇点为 0 时是一笔画）
```

> **注意**：走投无路时想一想是不是一笔画。做完一整套国考题都没遇到对称，大概率是有一道题做错了。

## 黑白运算与加减同异

### 概念

* **黑白运算**
    * > **定义**：同一组图形中，前两个经过某种运算推出第三个。
* **加减同异（消消乐）**
    * > **定义**：前两个图形中重复出现的线条相互约掉、消掉，剩下的合成第三个。
    * 常见的外部形态是一个框加中间各种线条，重复线条约掉后得到第三个。
    * 验证方式是逐块比对：某块在前两个里相同就应消失，只有其一有就应保留。

### 题型限定

* 只出现在九宫格或者"三推三"里，不会出现在前面五类考法中，因为这类题必须靠"推"而不是靠"看"。
* 九宫格可以横着推也可以竖着推，横竖两个方向都能运算出下一个。
* "三推三"是出题人已经把首尾圈好，给你三个推第四个。
* 判别时不必纠结名称，相同的约掉、不相同的保留就是消消乐。

```text
九宫格：横着看 —— ①② → ③      竖着看 —— ①④ → ⑦
        ⑤⑥ → ⑦              ②⑤ → ⑧
        ⑧⑨ → ⑨              ③⑥ → ⑨

三推三： ○ ○ ○            给你圈好首尾，让你推下一个
```

## 四白一黑的相邻关系

* **相邻个数（adjacency）**
    * > **定义**：在"四白一黑"构造里，分别数每个白块与黑块相邻的个数。
    * 四个白块都是三个与黑相邻、一个与黑不相邻。
    * 数量上四白一黑只能排除一个选项，剩余三个要靠这层相邻关系区分。

## 旋转与翻转的等价描述

* **顺时针旋转 90 度（rotation）**
    * 白色块一行一行地移动一个位置，整体看上去是顺时针旋转了 90 度。
* **左右翻转（flip / reflection）**
    * 同一个变化也可以描述为左右翻转，两种说法都成立。
    * 相邻两图之间可以先左右翻再上下翻，累积后回到初始位置。
* **答案判定**
    * 无论用旋转 90 度描述还是用"左右翻、上下翻交替"描述，落点一致。
    * 通过第一行通常就能直接得出答案。

## 空间折叠与投影面积

### 折叠过程

* **纸片划分（four parts）**
    * > **定义**：一张纸被线分成 A、B、C、D 四部分，经两次折叠后求投影面积。
* **默认前提**
    * 考场拿到这题先默认各条线长度相等，取一个容易的方式做出来。
    * 原题的设计本身就是这两条线相等，不相等则该题没有确定答案。
* **两次折叠的计算**
    * 第一次从上往下折，折完的面积是 B + D。
    * 再左右折，A 被盖住一次，重叠面积是 A。
    * 最终投影面积 = B + D − A。

### 容斥等价

* **容斥（inclusion–exclusion）**
    * 两张纸叠在一起的投影面积 = 两张纸面积之和 − 重叠部分的面积。
    * 重叠面积取哪一块要实际看出来，图形不对称时它并不等于 A，此时答案就不是原来那个选项。
* **无效区域（region C）**
    * C 在第一次折叠时被遮住，第二次折叠后仍然在里面，有没有 C 对最终面积没有影响。
    * 凡是结果与 C 有关的选项全部排除，剩下的即是答案。
    * 把 C 拿掉重画一遍，折叠过程与结果完全不变。

```text
第一次上往下折   →  面积 = B + D
再左右折         →  A 被盖住一次，重叠面积 = A
最终投影面积     →  B + D − A        （答案：第四个）
```

> **注意**：这类题实质是空间折叠加容斥，图形推理里少见的硬功夫；想不出 C 无关时，就老老实实画。

## 截面

* **截面（cross-section）**
    * > **定义**：用一个平面去切立体图形，考察切面可能是什么形状。
    * 先排除"无论怎么切都切不出来"的选项，这类选项通常就是答案。
    * 正圆这类形状横切、竖切、斜切都得不到，因为切割面必须落在实体的分界处。
    * 竖着切一刀可以直接得到对称的纵向截面。
    * 沿着明显的中线斜切一刀即可得到带中线的截面。
    * 从中间斜着切一刀就得到两个半椭圆拼成的截面。

## 立体拼合

* **灰色块对应（gray blocks）**
    * > **定义**：给出若干个选项视图，把每个视图中的灰色块与原立体中的对应部位配对。
* **易出难易两个极端**
    * 这类题要么很简单要么很难，经常出现在两个极端。
    * 当题目直接告诉你"三个灰色"时，已经给出了清晰的思考方向，题目就简单。
    * 几个颜色都不告诉你、只说一半灰一半白时，几乎只能靠空间想象，考场上很难做。
* **推倒法**
    * 把选项中的一个块沿视图方向"推倒"，看它落到原立体的哪一层。
    * 与最底下那一层吻合的就是它的对应部位。
* **颈部配对**
    * 灰色块后面若紧跟一个白色块，灰色是"脑袋"、白色是"脖子"、再往下是身子。
    * 候选块后面没有白色脖子的，不能作为该部位的对应。
    * 把候选块旋转 180 度后再看能否贴上去，是常用的验证手段。
    * 灰色—白色脖子—底座三段齐全的对应剩下的那个。
* **考场策略**
    * 找到方法且题目简单的就做。
    * 空间想象能力不足又很难的题可以先放掉，剩时间再回来。

## 国考出题信号

* **对称信号（symmetry marker）**
    * 国考有一个很大的特点：这么多年来每套卷子一定会考一个对称。
    * 十个图形推理都做完后发现没有考对称，说明很可能有一道题做错了。
    * 某道题其他方向都试过还走不通时，回头想想是不是对称。
    * 走投无路时再想一笔画。

## 数部分

* **分色计数（split counting）**
    * > **定义**：把黑色部分和白色部分分开数，各自统计几块。
    * 可能是黑色没规律而白色有规律，也可能是白色没规律而黑色有规律，所以必须单独数。
    * 拿掉对称这一条之后，数部分是最稳的一步。
    * 黑白部分数可以正好互补，规律互为镜像。

```text
黑：1  3  3  1  3  1     → 取 1、4、6      （答案：第二个）
白：3  1  1  3  1  1     →  跟黑色正好相对
```

> **易错点**：⚠️ 数部分永远是黑白分开数，合在一起数规律会被抵消掉。

## 小元素

* **小元素（small elements）**
    * > **定义**：图中反复出现的体量很小、种类很少的图形单元。
* **思考顺序**
    * 先数数量。
    * 数量没规律再想种类。
    * 种类也没规律再看看排布。
* **差值分组**
    * 两种元素的数量关系成组：某组第一种比第二种多一个，另一组第二种比第一种多一个。
    * 只需数个数就能分出两组，不必再往下找别的规律。

```text
图号   ①   ②   ③   ④   ⑤   ⑥
圆圈   5   0   1   3   4   2
方块   4   1   2   2   3   3
差值  +1  −1  −1  +1  +1  −1
       └──── 同号一组 ────┘   └── 同号一组 ──┘
        1、4、5                        2、3、6      （答案：C）
```

## 图形推理的节奏控制

* **合理用时**
    * 地市级这十个图形推理整体不难，目标是做对八个，八分钟对八个是合理节奏。
    * 副省级里有几个难的，地市级这十个没有完全无法操作的。
* **止损原则**
    * 肯定没有要求全对，这个要求太高，毕竟时间有限。
    * 想不出来就扔掉，不要钻在里面出不来。
    * 钻进一个题里两分钟、三分钟过去还没做出来，这种时间浪费非常不值得。
    * 找不着思路先放一放，回头有时间再回来。

## 定义判断的总印象

* **争议少（unambiguous items）**
    * 国考的定义判断一般情况下很少有争议类的题目。
    * 定义给得都比较清晰，题相对简单。

### 微量鉴定

* **微量鉴定（trace evidence identification）**
    * > **定义**：对案件现场较小的、不易察觉的物质（细小毛发、指甲缝里的人体组织等）进行鉴定，再与嫌疑样本做同类型、同一性鉴定，看是不是同一个人。
    * 三个必要条件同时成立：取自案件现场、体量微小不易察觉、与嫌疑样本做了同类型同一性鉴定。
* **排除车辆驾驶人员采血**
    * 根本不是案件现场，是把人带走了采血。
    * 采一管子能抽很多，不属于体量微小、不易察觉。
    * 只判定有没有酒后驾车，没有与嫌疑样本做同类型、同一性鉴定。
* **正确项特征**
    * 现场提取受害人的毛发、衣物纤维做鉴定，认定受害人与嫌疑人的车辆是否存在接触，三个条件全中。
* **不属于微量**
    * 拆解车辆特定部位不属于体量微小的物质材料。
    * 人体损伤程度不是微量物质。

### 政策工具

* **供给型政策工具（supply-side policy instrument）**
    * 提供资金、建设食堂和养老设施属于供给型。
    * 鼓励院校开设老年服务管理、护理等养老相关专业，对应提供人才，也属于供给型。
* **环境型政策工具（environmental policy instrument）**
    * 带书名号的《指导意见》可对应到目标规划、法制管制这一类，归入环境型。
* **需求型政策工具（demand-side policy instrument）**
    * 政府向养老机构购买居家养老服务、为其覆盖的失能老人提供服务，对应服务外包。
* **服务外包、劳动力外包**
    * 这些名词在日常生活中已经比较常见，属于要懂的基本类型。
    * 参加面试时可能直接出这类题，不会管你懂不懂。

> **提示**：题干读不懂就放弃题干，直接定位到问的那个词，重点读选项里能读懂、能对应的后半段。

### 民宿

* **民宿（homestay / B&B）**
    * > **定义**：把闲置的住处租给游客并同时提供经营性质的服务，经营者要从中挣钱。
* **符合项**
    * 市中心两居室闲置房子租给来旅游的家庭，并提供导游服务。
* **不符合项**
    * 家庭农场建设亲子服务乡村乐园，是亲子农家乐不是民宿。
    * 网上找到心仪城市互换旅行、双方各自为对方提供住宿，是你我互住，不经营不挣钱。
    * 古宅整套租给平台由平台做酒店式服务，是酒店不是民宿。

### 背信避险

* **背信避险（ex ante avoidance of betrayal）**
    * 定义用字每个都认识、连生僻字都没有，但组合起来不像人话。
    * 其中唯一相对可读的一句是：人们面对人为风险时，比面对客观风险时更为保守。
* **选项横向对照**
    * 机器阅卷是客观的，人工阅卷是人为主导的。
    * 抛硬币是随机的，裁判随机是人为主导的。
    * 抽签决定是随机的，老师指派是人可控的。
    * 三个选项的共同点：当结果本来可以由人决定时，人反而更倾向于交给随机的、客观的机制。

```text
B：机器阅卷   （客观）  ←→  人工阅卷   （人为）
C：抛硬币     （随机）  ←→  裁判随机   （人为）
D：抽签决定   （随机）  ←→  老师指派   （人为可控）
```

> **易错点**：⚠️ 定义判断里读不懂题干，第一反应不该是硬啃。选项本身就是出题人留给你的说明书，横向排开三四个选项，共同点往往就是定义的落点。

## 客观风险与人为风险

   * **客观风险**

       * > **定义**：概率本来就摆在那里的风险，可能出错也可能不出错，与人的好恶无关。

       * 刨除掉硬币可能被人做了手脚这种情况，当它是一枚正常硬币，正面朝上的概率固定为 50%。

       * 写五张纸条去拿一张，概率固定为五分之一。

       * 硬币、签筒里那点"万一被人做手脚"的可能，都属于客观风险。

   * **人为风险**

       * > **定义**：有人掺和进来之后产生的风险；概率再低也还是客观的，一旦掺进好恶就变了质。

       * 换成人来指派，嘴上说随机，仍可能掺杂个人情感：喜欢这个同学，不喜欢另外一个同学。

       * 老司机跟新司机那组都是人开的，属人为风险，压根没有客观那一份。

   * **同构选项判定法**

       * 题目要考哪一种风险，先看选项体现没体现，而不是硬啃题干。

       * 一组选项高度同构、能明显划到一堆去时，剩下那一个就是答案。

       * 题干特别晦涩、想不明白时去看选项；选项往往就是现成的例子，对例子的理解能反过来帮你读懂题干。

## 小中取大与大中取大

   * **小中取大（minimax）**

       * > **定义**：在每一种自然状态下分别看收益，先把目光钉在最差的状态那一列，再在那一列里挑收益最大。

   * **大中取大（maximax）**

       * > **定义**：先把目光钉在最好的自然状态那一列，再在那一列里挑收益最大。

   * 两者都是取最大，区别只在于先把目光钉在哪一列上。

| 决策类型 | 锁定列 | 列内动作 | 本题结果 |
| :--- | :--- | :--- | :--- |
| 小中取大 | 最差的状态（销路最差） | 收益最大 | 方案三，16 |
| 大中取大 | 最好的状态（销路最好） | 收益最大 | 方案二 |

   * 四个选项中同时对应"小中取大取方案三、大中取大选方案二"的是第四个。

## 异企合作

   * **异企合作（cross-enterprise collaboration）**

       * > **定义**：两个或两个以上不同行业的企业进行营销。

       * 硬条件之一：必须是两个或两个以上企业。

       * 硬条件之二：必须是不同行业。

       * 典型形态是别人做营销时顺手把京东或天猫捎上——广告画面最后显示一句"欢迎大家到京东去购买"，或画一只京东小狗，旁边一个搜索框写着"搜索京东"。

       * 京东这边额外几乎不付出什么成本，等于白捡了市场营销里的那块资源。

| 选项 | 情况 | 判定 |
| :--- | :--- | :--- |
| A | 一个集团下面的两家餐饮公司 | 同行业、同集团，不成立 |
| B | 某日用企业，只是不同的收纳盒怎么组装 | 还是一家公司，不成立 |
| C | 某运动品牌卖球鞋、送奥运吉祥物 | 还是自己给自己，不成立 |
| D | 某互联网公司和商业银行开发的联名信用卡，卡面上显示与京东合开 | 两家公司共享营销资源，成立 |

   * > **易错点** ⚠️：两个硬条件少一个字都不成立。集团内部两家餐饮公司不算，拆成不同收纳盒还是同一家公司不算，品牌自己送自己的吉祥物也不算。

## 侵染性与非侵染性

   * **侵染性病害（infectious disease）**

       * > **定义**：由病原物引起、可以相互传染的植物病虫害。

       * 病原物包括细菌、真菌、病毒、支原体、衣原体。

   * **非侵染性病害（non-infectious disease）**

       * > **定义**：由环境条件造成的植物病虫害，不会相互传染。

   * **非侵染性的识别**

       * 微酸环境是环境因素，浇水浇多了是环境因素。

       * 除草剂导致也是外来的环境因素。

       * 真菌是会传染的，属于侵染性，划掉。

       * 符合非侵染性的是 1、2、3 三项。

## 联合式构词法

   * **联合式构词法（coordinative word formation）**

       * > **定义**：由两个意义相近、相反或相对的语素组合成一个词。

   * **选项判定**

       * "叮咚"是两个不同的声音，不相同、不相反，也不相对，联系不上。

       * "开"与"关"一定相反，组合成一个词——开关，正是灯上那个开关，对应得最完整。

       * "椅"与"子"里的"子"是名词的附加成分，不相同、不相反、也不相对。

       * "蹉跎"单独看这两个字看不出相反；即使拿不准它算不算"相对"，"开"和"关"一定相反。

   * **积累提示**

       * 蹉跎说的是虚度光阴，两个字合起来才成这个词，单独拆开各有个的意思。

       * 查《新华字典》或《说文解字》一个字一个字看本义怎么一路演到今天，属于顺手做的事，对做题不是必须。

   * > **提示**：题干读不懂时去看选项，选项能帮你反推题干要什么。

## 细胞学检查

   * **细胞学检查（cytology examination）**

       * > **定义**：取患者病变部位脱落的、刮取的或穿刺获取的细胞，做病理形态学的观察，据此作出诊断，主要应用于肿瘤。

       * 要件一：取材部位必须是病变部位。

       * 要件二：观察对象是病理形态学。

       * 要件三：用途是诊断，尤其是肿瘤诊断。

       * 三条里有任何一条对不上，就不是在讲细胞学检查。

   * **成立项**

       * 用拉网法收集食道癌患者的食道脱落细胞，鉴定细胞形态，进行病理形态学的观察，明确癌变的性质，三个动作一个不缺。

       * 细胞形态摆在那儿，其实就能确认这是什么样的癌。

   * **排除项**

       * 采集血液样本：血液不是病变部位；后面"分析血细胞比例的变化"也对不上，血常规看的是中性粒细胞、C 反应蛋白这些比例，分析的是比例不是形态学。

       * 皮肤纤维的过度增生、抑制炎症细胞、最后修复再生细胞：这是治疗；题干做的是观察形态、作出诊断，不是帮你修复。

       * 脑疝患者穿刺放出脑脊液降低颅内压：也是治疗，既没提取细胞，更没做形态学观察。

   * > **易错点**：血液分析常被拿来圆"白血病、血癌"，但后半句"分析血细胞比例的变化"一压就露馅了。

   * **应用广度**

       * 这种检查在现在的医学领域应用非常广泛，看小细胞肺癌、非小细胞肺癌等等，对肿瘤来说是非常常见的手段。

## 预判设计

   * **预判设计（anticipatory design）**

       * > **定义**：让功能主动找到用户，并与其产生自然的交互。

       * 原文只分了自动性预判与引导性预判两支，被摘出来做选项的三个全都落在这两支里。

   * **不属于预判设计的形态**

       * 购物软件按关键词相关性排序：用户输入"男士 T 恤"、商品按关键词相关性排列，需求与结果一一对应，没有替用户多想一步，这是应该的，不是预判。

       * 这种排序的学名是搜索竞价排名：用户之所以排在前面，很多时候是商家花钱打了广告，搜出来的未必是真正想要的那一个，叫综合评价、综合排序。

   * > **提示**：题目问的是"不属于"，出题人摘选项时把中间最关键的那句解释删掉了——翻译软件"你可能没听清"、外卖软件"我预判了你的预判"都没留下，只剩首尾，所以只凭残缺描述会选错。

   * > **易错点** ⚠️：在搜索框输入"预判设计"会冒出好多个子条目，它确实在猜你可能想搜"预判设计 翻译软件"，这功能可以叫预判设计。但选项说的不是这个功能，别把搜索框的联想功能和选项里说的搜索相关性排序搅在一起。

### 自动性预判与引导性预判

   * **自动性预判**

       * > **定义**：用户还没开口，功能自己先动。

       * 某翻译软件：第一遍是正常速度播放，你再点一下，产品判断你可能是刚才没听清，或者想听清某个词的念法，于是把语音播放速度变慢到大概 0.75 倍；谷歌翻译就是这个样子。

       * 某外卖软件：给店家评分，勾的分数在两颗星以下时，系统自动帮你勾上匿名，免得你和商家起冲突；想实名再自己点回来取消。

   * **引导性预判**

       * > **定义**：用户点了一下，功能替他补一步。

       * 缺货时给出一个同款，主动递上"找相似"。

```text
  预判设计
    │
    ├── 自动性预判：用户还没开口，功能自己先动
    │      ├── A 某翻译软件：第二遍再点，播放速度降到 0.75 倍
    │      └── B 某外卖软件：给出差评（两颗星以下），系统自动勾选匿名
    │
    └── 引导性预判：用户点了一下，功能替他补一步
           └── C 缺货时，给出"找相似"

  D 购物软件按关键词相关性排序 —— 上面两支里都没有它
```

## 数学的加法与语文的加法

   * **数学的加法**

       * > **定义**：多个同类的量相加，结果收敛成一个数。

       * 小计加起来就是总计。

       * 单科分加起来就是总分。

       * 某公司有好多分公司，某个分公司自己的账目加起来做一个合计，那就是一个小计；一张数学卷子有选择题、有大题，把题目都加起来就是一个单科的总分。

       * 分公司这一个月只卖了一个产品也照样可以做小计，单科分只有一道题也一样成立。

   * **语文的加法**

       * > **定义**：多个同类的项拼合，结果仍是一个集合或一堆词，不发生数值上的合并。

       * 分目录加起来不等于总目录。

       * "预" + "判" = "预判"，得到的还是两个字，只不过成了一个词，不是 $1 + 1 = 2$。

       * 公基讲义的目录里，第一章到第十章那一层是总目录，下一层的二级目录、三级标题是分目录，把分目录加起来字都不一样，根本加不到一起。

       * 《四库全书》《永乐大典》以及《文苑英华》《太平广记》这类搜集类书籍，把这一类别的书全都搜在一起，加起来得到的仍是一本一本、上千本的一个合集。

| 形态 | 数学的加法 | 语文的加法 |
| :--- | :--- | :--- |
| 基本式 | $1 + 1 + 1 + 1 = 4$ | 预 + 判 = 预判 |
| 汇总一 | 小计 + 小计 = 总计 | 分目录 + 分目录 ≠ 总目录 |
| 汇总二 | 单科分 + 单科分 = 总分 | 一本 + 一本 = 一座合集 |
| 结果 | 一个数 | 仍是一个集合 |

   * 小计与题干形成数学上的加法，选项里只有"单科分 : 总分"同样对应，第四个是更好的答案。

   * > **提示**：防杠——有人会说"单科分它不是一个集合"，可小计本身也不像集合；两边对应得非常整齐，而分目录那种只有语文上的加合、没有数学运算。

## 命名方式与交叉关系

   * **命名方式**

       * 按材质命名的一类：铜镜。

       * 按功能命名的一类：化妆镜，用它来看化妆。

   * **交叉关系**

       * > **定义**：两个概念分属不同分类维度，部分交叉但互不包含。

       * 有的铜镜是化妆镜，有的化妆镜是铜镜。

       * 铜镜的前身是青铜器，最早是用来祭祀的，哪止化妆这一件事，所以一定按交叉关系处理。

       * 木碗与汤碗同理：木按材质、汤按功能，有的木碗是汤碗，有的汤碗是木碗。

       * 金簪与发簪不是交叉：发簪也叫簪子，簪本身就是盘发的那个东西，发簪等价于"簪"这个字，金簪是发簪的一种，属种属关系。

| 选项 | 命名依据 | 关系 | 判定 |
| :--- | :--- | :--- | :--- |
| A | 木（材质）: 汤（功能） | 交叉 | 成立 |
| B、C | "古瓶"的"古"不是按功能命名，"门"也不是按材质命名 | —— | 命名依据这一关就过不去 |
| D | 金（材质）: 发簪（功能） | 种属 | 排除 |

## 语义之外的对应结构

   * **近义判断的失效**

       * "猛药去疴，重典治乱"第一眼看上去有点近义的意思，但细究肯定不是近义词；四个选项里没有一个是近义词，所以这一题不能仅从近义词来看。

   * **目的式对应结构**

       * > **定义**：前后两分句是手段与目的的关系，前者是为了后者。

       * "猛药去疴"：猛药是为了去疴。

       * "重典治乱"：重典是为了治乱。

       * "静以修身，俭以养德"：静是为了修身，俭是为了养德，与题干一一对应。

       * "从善如登，从恶如崩"也是同一结构，这一句前后两次出现在省考面试，一次是 2020 年的浙江，一次是 2021 年的陕西，都是结构化面试，题面仅一句话。

   * > **注意**：这类词目的积累值得做，重复出现的句子尤其要记，平时多做一些其他省的题目，有可能遇到原题。

## 类比推理的关系判定

   * **因果关系**

       * > **定义**：前项导致后项，造一句"前项导致了后项"能通。

       * 强光照射导致视力损伤。

       * 台风过境导致渔业停产：台风要过境了，为防止风险提前几天不去了，一直等风平浪静再过去。

       * 原油进口 : 能源紧缺——因果反了，是能源紧缺才需要进口。

       * 风险防范 : 消防演练——是目的关系，消防演练的目的是风险防范。

       * 业务扩张 : 网络招聘——方向是反的，因果也没那么强：业务扩张了不一定非要网络招聘，而业务不扩张、正常的人员流动也照样要网络招聘，现在的招聘多数都是网络招聘。

   * **递增关系**

       * > **定义**：同一个序列上程度由低到高逐级上升。

       * 亚音速 < 音速 < 超音速，不到音速、音速、超音速，标准的递增。

       * 标清 < 高清 < 超清，看视频的时候清晰度在逐步升高。

       * 迁怒 : 愤怒不对，迁怒是迁怒于他人，愤怒就是愤怒、暴怒，后一组在递增而 A 跑偏了。

       * 幽静 : 寂静 : 安静不对，这是三种不同的静，属并列关系。

       * 厅 : 市 : 省不对，厅局级、部长、省部级、处级、科级、科员属于行政级别序列；"市级、省级"说的是做卷子的层级，另有县级、乡镇，两套不在一个序列上。

   * **并列关系**

       * > **定义**：同属一个类别，相互之间没有包含关系。

       * 片剂、散剂、气雾剂是药物的三种不同剂型：散剂就是粉末那一类，往身上喷的云南白药和往鼻子里喷的鼻炎药都是气雾剂。

       * 头 : 腰 : 腿三个并列。

       * 边塞诗 : 山水诗 : 抒情诗是交叉，边塞诗里有描写山水的，山水诗里有描写边塞的，借山水诗抒情也成立。

       * 口头契约 : 君子协定 : 书面协定也是交叉：按形式分有口头协议、书面协议、音频协议、视频协议，按人分有君子约定、小人约定、君子协定、小人协定、普通人协定，两个系列交叉。

       * 涉"泉水"的一项一般认为泉水是天然的，与另一项构成种属关系，不是并列。

   * **常识门槛下的关系对应**

       * 疾病、中间是花粉、喷嚏三者，对应的是病因与症状：花粉是病因，喷嚏是症状。

       * 肺炎能与这个结构挂上钩，但咳嗽接到支原体这里接不上。

       * 题干逻辑清楚、选项却有明显常识门槛的题，遇到时老老实实按关系去对，病因、症状、疾病三者之间能一一挂上钩就留，挂不上就换。

## 作答通则

   * **定义判断的时间分配**

       * 这 10 道定义判断属于"简单、非常简单、没什么争议性"的水平，除了最后一题，剩下 9 道题都不应该做错。

       * 合理的时间分配是 10 道题 8 分钟做完 9 道，不能再低；只允许错最后那一道。

   * **否定词标记**

       * 考场上遇到"不属于""不包括""没有"，第一件事是把它圈出来再说。

       * 很多人在"让功能主动找到用户"上读到一半就往下走，一看到缺货冒出的"找相似"就当场选中，而题目问的是"不属于"。

   * **选项同构法**

       * 几个选项高度同构、能明显划到一堆去时，剩下那一个就是答案。

   * **造句定因果**

       * 判断因果先把方向定死，造一句"谁导致了谁"就清楚了；造出来还得拐个弯，或者得再补一句"目的是"，那多半就不是因果。

   * **回忆版题目的争议性**

       * 国考真题都叫"考生回忆版"，题目不发给大家，网上没有、也不公布题目，更不可能公布答案。

       * 讲题时没有一个人手上有真正的标准答案，都是同行之间觉得答案应该是这个，一定带主观性；真有争议的题会告诉大家这是一个争议。

## 病因与症状

* **病因（etiology）**
    * > **定义**：病根儿上的那个东西，是病原本身，不是"原因之一"，更不是症状。
    * 判定依据是看同一组选项里其他项给的是什么：肺炎给的是支原体，乙型脑炎给的是病毒，都是"病原"。
    * 同理，秋季腹泻应该给病毒、给轮状病毒，而不该给饮食。
    * 秋季腹泻是自限性疾病，传播途径不止粪到口一种：还有空气传播，粪便里的病毒扩散到空气当中，从呼吸道进入人体。
    * > **易错点**：⚠️ 把"秋季腹泻"直接等同于普通拉肚子。它是一个专门的病名，不是日常说的闹肚子。

* **症状（symptom）**
    * > **定义**：病发之后在人体上表现出来的状态。
    * 支原体是肺炎的病因，咳嗽是症状；把咳嗽摆到病因的位置上，搭配就反了。
    * 失眠的主要症状是睡不着觉、睡眠质量不好、总醒、睡眠状态很差，恶梦不是。
    * 乙型脑炎的病因是病毒，它的主要特征是发热。

* **可能性与核心病因**
    * 恐惧**可能会**导致失眠，这只是一种可能性，恐惧并不是失眠的核心病因。
    * 把"我吃饭就腹泻、我正常吃饭也腹泻"当成病因是典型的想当然：饮食这个口子太大，没有落到病根儿上。
    * 一道题里给的是不是"病因"，看其他选项给的是什么就清楚了——出题人自己就是按"肺炎—支原体""脑炎—病毒"这种病根对应来出题的。

## 必然先后顺序

* **必然先后（necessary precedence）**
    * > **定义**：两个动作必须按这个次序发生，不这么排就不成立。
    * 切入点是生活经验：买房子必须先交定金，所以"预订—交定金"是必然先后。
    * 先选购家电，再上门安装，然后使用，最后维修保养，整条链是必然先后。

* **不是必然先后的信号**
    * 加装内饰和购买保险谁先都行：先买车险再加脚垫、先加脚垫再买车险都无所谓，没有必然先后。
    * 修剪草坪是园林养护的一种，这是包含关系、种属关系，不是先后关系。
    * 收看节目、视频连线、关注互动之间没有必然先后：可以只互动不连线。
    * > **易错点**：⚠️ 不要把"习惯上的顺序"当成必然先后。判据是"必然"，不是"通常"。

* **看选项自学**
    * 四个选项全都是带先后顺序的，选项本身就给出了参照物。
    * 对股票、资产评估这类不熟的领域，从选项反推关系即可，不必逐个去查概念。

## 种属关系与造句验证

### 种属关系的判定

* **种属关系（species-genus relation）**
    * > **定义**：后者是前者的一种，前者包含后者，造句为"X 是一种 Y"。
    * 火星探测是深空探测的一种，深空探测就是在浩瀚的宇宙空间中进行探索。
    * 公益组织是社会组织的一种。

* **从陌生选项反推词义**
    * 遇到不认识的词，先看同一题里其他选项给出的同类词，靠它们把词义推出来。
    * 无人采样不是核酸采样：火星、月球都无人上去，直接用设备采样。
    * 无人采样可以理解成一种技术，遥感技术也是一种技术，是深空探测使用到的一种工具。

### 造句的角色校验

* **主体与客体（subject and object）**
    * 造句能造通只说明语法成立，不说明逻辑关系成立，还要问这两个词在同一句话里是不是扮演同样的角色。
    * "在公益组织做公益事业""公益组织搞慈善捐款"，公益组织是行为的**主体**。
    * "在宇宙空间做深空探测"，宇宙空间是**客体**、是地点；深空探测的主体是科技部门、科学家们，科学家才该跟公益组织对应。
    * 前面是主体、后面是客体，主体和客体对不上，整项排除。

* **常识边界的处理**
    * 红十字会按常识理解是公益组织的一种，但接不住主体与客体对应这一关。
    * 国际红十字会是非政府组织，本国的红十字会像是事业单位、工作人员有事业编，是否属于公益组织不必深究，判错即可。
    * 优先看关系对不对得上，不要为了一个机构去补编制、隶属这类细节。

## 语义关系

### 下手顺序

* **先挑最陌生的一组**
    * 陌生的一组更可能是答案所在；很熟的那几组往往是干扰项。
    * 反义、近义两组都确定无误时，其余选项只需排除，不必再深挖。

* **不要死磕单个词**
    * 十个词能懂八个就够，判断推理里用到的成语大多认识，最多一两个需要用排除法判定出来。
    * 顺手做成语积累，对言语理解也有好处。

### 干扰项排除

* **反义关系的判定**
    * 缄口不言与口若悬河、畅所欲言是反义：一个不说话，一个话多。
    * 放荡不羁与虚怀若谷不是反义：虚怀若谷是谦虚，反义应该是不谦虚，跟放荡不羁没关系，用基本常识就能排除。

* **近义关系的判定**
    * 守口如瓶与三缄其口是近义。
    * 礼贤下士（敬重、礼遇贤能之士）与大智若愚（聪明却外显愚钝）不是近义，两者跟"虚心"都没有关系。

## 前提假设的搭桥法

* **搭桥（linking assumption）**
    * > **定义**：把论据和论点这两件不同的事连起来的中间前提。
    * 提问是"前提"时直接找搭桥项，不用想，一定考搭桥。
    * 搭法：把论据里的关键概念和论点里的关键概念搭在一起。

* **识别论据与论点说的是两件事**
    * 论据只说深度学习技术能自动读取并识别视网膜扫描数据，论点却跳到"该技术有可能改变传统的心脏病筛查方式"。
    * 两件事中间明显缺东西，答案只能是搭桥项；不搭桥的题，出题人把非搭桥项当答案本身就是有问题的。
    * 搭桥内容是：扫描出来的数据能够反映微血管变化，是预测心脏病较灵敏的指标。
    * 由此把"视网膜扫描数据"和"心脏病筛查方式"接上。

## "我是你原因的原因"

* **原因的原因（cause of the cause）**
    * > **定义**：甲是乙的原因，乙又是丙的原因，则甲是丙的"原因的原因"。
    * 结构信号是"甲和乙无关，乙是丙导致的"，此时去问一句"丙是谁带来的"。
    * 削弱办法是指出甲其实导致了乙，从而否定"无关"这一说法。

* **套用到产业就业题**
    * 观点一：产业优化升级是导致第二产业从业人员减少的一个原因。
    * 观点二：与产业优化升级没有关系，是第三产业的蓬勃发展吸纳了第二产业的就业人员。
    * "产业优化升级拉动了第三产业的蓬勃发展"正好构成"我是你原因的原因"——我导致了你，你才导致后面的，所以"没关系"是错的。

## 加强与削弱的选项取舍

### 加强题的选项质量排序

* **排序标准**
    * 完美对应（题干核心词一一对上）> 明确相关（说得不清楚但方向一致）> 不确定项（说"还不知道"）> 无关项。
    * 看到"不够深入""还无法评估"这类表述，就是不确定项，只能垫底。

* **深海开采题**
    * 反对者的观点是深海开采会对海洋产生不利影响。
    * B 项说深海开采释放泥浆会威胁生态环境，噪音、声波对鱼类等产生不利影响，"深海开采"和"不利影响"两端完美对应，选它。
    * A 项说对深海环境研究不够深入、技术还不成熟，潜台词是能不能产生影响还不知道，属不确定项。
    * 第四项说海洋彼此相连、开采评估应全局考虑，到底什么影响、什么样的不利影响没说清楚，同样是不确定项。
    * C 项说人类金属需求得不到满足，与观点无关。

### 反向问法的处理

* **"不能支持"的取法**
    * 题干问"不能支持"时，答案是最能削弱的那一项，而不是最能加强的。
    * 常规做法：先把完全无关的排掉，剩下的再比谁更接近。
    * 都不完美时，只要存在一个完全无关项就选它——对比择优。

* **污水处理的比较题**
    * 观点：与传统手段相比，微生物是一种处理污水的更佳手段，支持它需要做比较。
    * A 说物理方法不好、C 说化学方法不好、B 说微生物好，都只是单边，勉强算支持。
    * 第四项说微生物与土壤改良，完全无关，只能选第四项。

## 前推后与后推前

* **因果方向（causal direction）**
    * > **定义**：由原因推向结果是前推后，由结果倒回原因是后推前。
    * > **注意**：前推后可以，后推前不确定。涨价还可能有别的原因，所以有周期推不出经济在复苏。
    * 大宗商品指原油、天然气以及一些重金属等金属；价格高于平均值即称为进入"超级周期"。

$$
经济增长动力 \to 大宗商品进入超级周期
$$

* **论证断链的位置**
    * 论据：近来一两年大宗商品涨价，价格处于非常高的水平。
    * 题干给的关系是"大宗商品进入超级周期是全球经济增长出现新动力的结果"，方向由动力指向周期。
    * 论点：历史上大宗商品进入超级周期往往会带动全球的经济复苏，因此预示当下的全球经济正在复苏。
    * 原文只把上面那一段箭头讲通了，下面一段是从"已经有周期"倒着往回推，回推不成立，所以整个论证是错误的。

```text
    论据侧（题干已经给的）              论点侧（题干想要的）
   ─────────────────────────────────────────────────────────
    全球经济出现新的增长动力
            │
            │  题干："……是……的结果"   前推后，成立
            ▼
    大宗商品进入超级周期   （近期已经涨价）
            │
            │  ✗  后推前，不成立
            │     涨价也可能是别的原因带来的
            ▼
    当下的全球经济正在复苏
```

* **削弱断链的做法**
    * 削弱论证的本质是切断论据到论点的通路。
    * 最好的切法不是直接说"经济没复苏"（那是直接反驳结论），而是给论据换一个因果来源。
    * "地缘政治引发了本轮大宗商品价格上涨"补上了断掉的那一环：涨价不是增长带来的，是地缘政治带来的，"涨价→复苏"这条链就断了。
    * 其余选项与题干明显没有关系，属无关项，不必逐个深究。

## 一拖五

### 材料与条件

* **一拖五（shared-material set）**
    * 给一份整体材料，后面跟随五道小题。
    * 一般是翻译推理与排列组合的融合题型，比较简单，尤其第一问和第二问非常简单，属于送分。
    * 练上几遍就能在五六分钟之内对三四问；与其在这类题上耗时间，不如去找能更快把分捞回来的地方。
    * > **易错点**：⚠️ 不要一看到这种题就放弃，它是简单题不是难题，怕就完了，去做。

* **题干给定的三个条件**
    * 材料：六个部门各推荐两个人，共 12 人，每人最多值一天。
    * 条件一：第二天和第四天不能安排法务部门的人值班。
    * 条件二：如果安排后勤部门的人，则只能安排在法务部门的人值班的前一天，即后勤的后面一定跟一个法务。
    * 条件三：研发部门的人只能安排在后勤部门的人的前一天。
    * 三条合起来的部门链条：研发 → 后勤 → 法务。

### 可选日期与部门链条

* **后勤的可选日期**
    * 第一天排后勤 → 第二天必须排法务 → 与条件一冲突，不行。
    * 第二天排后勤 → 第三天排法务，不冲突，可以。
    * 第三天排后勤 → 第四天必须排法务 → 与条件一冲突，不行。
    * 第四天排后勤 → 第五天排法务，可以。
    * 第五天排后勤 → 第六天排法务，可以。
    * 第六天排后勤 → 需要第七天排法务，而没有第七天，不行。
    * 结论：后勤部门只能安排在第二、第四、第五天值班；这个结论要记下来，后面的题反复用。

* **条件的使用方向**
    * 条件二翻译过来就是"后勤的后面一定跟一个法务"，把这条关系说反、或者根本对不上的选项都是错的。
    * 条件三连起来就是：研发的后面一定是后勤，后勤的后面一定是法务。
    * > **提示**：一定要从已知条件最多的地方入手，不是一个一个去试。财务、后勤、研发的链条都是现成的，顺着链条一撞，选项自己就倒下了。

### 各问的判定

* **前两问的排法**
    * 问"哪一项一定不正确"：只用条件一、条件二逐项秒排，答案是第一项。
    * 问"后勤部门可以安排在哪几天"：在条件一、条件二里试一遍，答案是第二、第四、第五天。
    * 问"安排后勤两人时哪一项一定不正确"：后勤两人从 2、4、5 里选 $C_3^2$，不能选 4 和 5（后勤后面跟后勤违反条件二），所以第二天一定后勤、第三天一定法务，于是"第三天安排财务"一定错。

* **问"可能"的做法**
    * 题干问"可能"说明排列不固定、排列有很多种，做排除法。
    * 第一天不能排后勤：后勤只能在第二、第四、第五天。
    * 第一天不能再排财务：财务只有两个人，第三天和第五天各一名已经用完，再排就变成三个财务，不符题意。
    * 第一天排研发也不成立：第一天研发 → 第二天后勤 → 第三天法务，与题干"第三天是财务"冲突。
    * 三条排完只剩最后一个选项。

* **问"一定正确"的做法**
    * 题干是"没有安排财务和后勤"，顺条件三先推出：研发只能排在后勤的前一天，没有后勤就一定没有研发。
    * 财务、后勤、研发三个部门被砍掉，剩下人事、法务、销售三个部门共 6 人。
    * 能判定"研发不在"的是条件三；条件二涉及法务，而题干没说有没有法务，判定不出谁在谁不在。
    * 从已知信息最多的地方下手：第二天和第四天都不能排法务，第四天是否销售、是否人事都不确定，第二天则只能是人事或销售，所以"第二天"这一项一定正确。

## 节奏与放弃策略

* **不钻牛角尖**
    * 类比推理里有些题略超纲，不要钻在某一题里面没完没了——钻了三分钟也未必能做对。
    * 对自己把握不准、觉得有争议的题直接放弃，匀出时间去做简单题。
    * > **易错点**：不要为了一个生僻词把整道题当难题死磕。

* **一拖五靠量不靠想**
    * 一拖五确实是简单题，见一次做一次，做上几遍就有感觉。
    * > **提示**：不要怕，怕就完了，去做。
