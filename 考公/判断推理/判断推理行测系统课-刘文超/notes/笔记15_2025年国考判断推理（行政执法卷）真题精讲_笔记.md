# 2025年国考判断推理（行政执法卷）真题精讲

## 全卷题面结构

### 十道题的分布节奏

* **题号与题量**

    * 图推从第 1 题一路排到第 85 题，共十道题。
    * 开头那道称作"第一题"，之后按原题号 77 至 85 往下讲，依次是 77、78、79、80、81、82、83、84、85。

* **题型排布**

    * 十道题里前三道是平面图形。
    * 接着是黑白块、样式规律，后面直接上立体截面、立体拼合、展开图，最后又回到平面。
    * 风格跳得挺快，别指望一套方法打天下，每道题都得重新判断"这一题该从哪儿下手"。
    * 真正决定做题速度的就是下手准不准。

## 面的考察

### 数面与数边失效时

* **从"面"切入的判断**

    * 图形是一个封闭的整体区域，里面中间有很多个窟窿，面太明显了。
    * 面这么明显，大概率还是跟面有关系，那就先数面。

* **两条路都数不出规律**

    * 四幅图数下来是四个面、三个面、三个面、四个面，不成规律。
    * 把外框的边数连着数，得到 1、2、3、4、5、6、7、8、9，一路数到九，仍然看不出跟几边形有关系。

* **面太扎眼时的转向规则**

    * > **结论**：面和边暂时都没有规律，但这不代表跟面无关。
    * 面太扎眼的时候，规律往往不在"面的数量"上，而在"某一个特定的面"上。
    * 最小面不好说是谁，先不管；最小面找不到，就找最大面——这里只有一个最大面是能看出来的。

### 最大面与最小面的考法

* **国考反复考的两个面**

    * 国考最近特别喜欢考最大面和最小面。
    * 考过最大面和最小面的关系，考过它们跟整体图形的关系，也考过它们内部自己的规律。
    * 各种组合都出现过很多种，想得到的前提是刷得够。

* **最大面属性的判定顺序**

    * 看边长：看不出。
    * 看对称性：有规律，四幅图的最大面都是对称图形。
    * 再细一层：是轴对称还是中心对称。

| 选项 | 最大面的样子 | 判定 |
| :--- | :--- | :--- |
| A | 根本不是对称图形 | 排除 |
| B | 明显不是对称图形 | 排除 |
| C | 平行四边形，中心对称 | 排除 |
| D | 是轴对称图形 | 答案 |

* **对称性的判定结论**

    * > **提示**：中心对称不等于轴对称。平行四边形是中心对称图形，但它不是轴对称图形。C 就栽在这条上。
    * 这道题考了半天，就考了一个比较简单的东西：最大面都是轴对称图形。

## 位置类：旋转叠元素移动

### 两套机制同时进行

* **主图形一套机制**

    * 主体图形在转：第 1 幅到第 2 幅转 90 度，第 2 幅到第 3 幅再转 90 度。
    * 那问号处自然是再转 90 度之后的样子。

* **边上小元素另一套机制**

    * 边上那两个小东西每次沿着边线往前挪一格。
    * 第一幅到第二幅挪一格，第二幅到第三幅再挪一格，所以问号处它们应该再挪一格。

```text
问号处 = 主图形在第 2 幅的基础上再转 90°
        + 两个小元素各自沿边线再前进 1 格
        两套机制同时对上的那个选项 = C
```

* **判定与易错处**

    * > **易错点**：一眼看到"旋转 90 度"就急着选答案，忘了边上还有两个在动的元素。这种题永远是两套机制叠在一起——主图形一套，小元素一套，两边都要对上号才行。
    * 答案是 C。

## 黑白块：部分数与笔画

### 黑白块的稳定考点清单

* **可能考的方面**

    * 关于 5×5 的黑白块做得实在太多了，考点大概心里也有数。
    * 最简单的考数量，还可能考位移，可能考黑球跟白球的对称，可能考部分数，可能考一笔画，还可能考连接方式等等。
    * 有一个一个对的必要，这几年跑不出这些东西。

* **下手顺序**

    * 数量比较多，先把黑白分开看。

* **笔画先于部分数**

    * 题面第一幅的白色能一眼看出是两笔画：找奇点，一个端点、一个端点、一个端点、一个端点，四个奇点，所以是两笔画。
    * > **易错点**：这里最容易看错的就是笔画，有同学看成一笔了，那是基础不过关。数奇点：四个奇点是两笔，不是一笔。

* **部分数的规律**

    * 黑色连成一块，黑色是一部分。
    * 白色这有一个小球，另外这些白的是不是都连在一起，所以白色是两部分。
    * 后面几幅是同一个套路：黑色全部连在一块、黑色一部分，白色两块、白色两部分。
    * 规律是黑色都是一部分、白色都是两部分，答案取"黑一部分、白两部分"的选项。

| 选项 | 黑色部分数 | 白色部分数 | 判定 |
| :--- | :--- | :--- | :--- |
| A | 1 | 4（一、二、三、四） | 排除 |
| B | 1 | 2 | 答案 |
| C | 1 | 3 | 排除 |
| D | 2 | — | 排除 |

    * > **提示**：数部分数的时候，"看着挨在一起"和"真的连着"不是一回事。断开的白块别顺手连成一块，A、C 就是白块数多了，D 是黑色断成了两块。

* **藏在第二层的考点**

    * 盯着白色看：这是一个、这是两个、这是三个、这是四个，然后这是一个五块。
    * 白色部分数是在 1、2、3、4、5 递增，那下一个应该是一个六。
    * 挑 2、4、6 来看，第二个选项也满足。
    * 一道题两层考点，方向完全一致：都是第二个，答案 B。

## 一笔画

### 走投无路就试一笔画

* **兜底原则**

    * > **结论**：在一道图推上做了半天、做不出来又不想再耗下去，一定要记住走投无路一笔画。
    * 走投无路了、找不到了，就回头看看一笔画，试一试，大概率就搞定了。

* **一眼可辨的触发特征**

    * 一上来就看到 3，就忍不住想试试一笔画。
    * 第三个图形明显感觉乱糟糟的，一看就忍不住要走一走试一下，结果发现它一笔画走完了。
    * 回过头来再看别的，明显乱糟糟的，就忍不住想去试试。
    * 这道题一笔画的特征非常明显，是一个典型的、非常明显的有一笔画特征的图形。

* **各图笔画数的判定**

    * 1、3、4 能一笔画完。
    * 第 2 个是一个丁字路口，接着又是一个丁字路口，两处就是四个奇点，所以是两笔画。
    * 第 5 个图形正好上面一笔、下面一笔，总共两笔。
    * 第 6 个图形是丁字路口、丁字路口、丁字路口，再加一个点，四个奇点，还是两笔画。
    * 一笔画的是 1、3、4，两笔画的是 2、5、6，答案是后面这一组。

## 样式类：去同存异与翻转

### 消消乐的识别与验证

* **识别信号**

    * 先横着看，这些线条在互相重复，尤其那两个小图形，到第三幅图的时候又冒出来了。
    * 所以大概率是同存异，也就是常说的消消乐。
    * 方向上要注意：做完消消乐之后，跟第三幅图之间还差一个旋转或者翻转，不是直接相等。

* **用题干三幅图验证**

    * 图 1 和图 2 消消乐：两边都出现的线消掉。
    * 中间那条线没在两边都出现，留下；这个竖线没有消掉，留下；那两个小图形都保留。
    * 消完的图形再跟图 3 一比，正好是一个水平翻转。

* **4×4 区块的逐块规则**

```text
逐块去同存异（消消乐）判定（4×4 逐块过）
  同色 + 同色        消掉
  异色 + 异色        不消，原样留下
  ------------------------------
  16 块全部判完   得到 B 选项（尚未翻转）
  再水平翻转一下   得到 A 选项（答案）
```

* **操作顺序与效率**

    * > **结论**：这一题的顺序不能颠倒——前两幅先消消乐，再水平翻转，才是第三幅。先翻后消就全错了。
    * 画的时候可能稍微有点麻烦，但不要数错了就行。
    * 自己画会比看解析快，按行来，判一格填一格，别凭印象。
    * 思路比较好找，尤其是那两个重复出现的小图形，一眼就定位到样式规律，明显感觉到应该进行了旋转或者翻转，答案是 A。

## 立体类规律

### 立体截面

* **第一步不是选答案**

    * 题干说用经过 P、Q、R 三个点的平面对其进行切割。
    * 拿到这个题，第一步不是选答案，是先把那个平面找出来。
    * P、Q、R 三个点确定一个平面，这个平面是从 P、Q 往 R 那边斜着切过去的一个斜切面。

* **截面的构成**

    * 它切的是底下那个长方体，再加上前面那个小斜坡。
    * 横着斜切过来，底下这一块是长方体的截面，前面还会带出一小块斜坡的斜面。
    * 截面是长方体被切出来的那块，加小斜坡被切出来的那块，拼在一起。

* **判定标准**

    * > **易错点**：立体截面不看"像不像"，只看"是不是那个平面切出来的"。先把 P、Q、R 连成平面，平面画出来了，选项基本就只剩一个。
    * 答案 A。

### 立体拼合

* **难在"不可能"三个字**

    * 题目问棱长为 1 的多面体在 3×3×4 这个空间内进行拼接，不可能是哪一个。
    * 真要去拼没有特别好的办法，要大量颅内拼合——颅内立体拼合就是靠脑子的立体感硬拼，比较麻烦，看能力。
    * 难就难在"不可能"这三个字上；要是问"可能"，还好一点。
    * 而且 3×3×4 的空间太大了，这里面很多块都放在背后，我们看不见；选项里是三块能拼上、一块拼不上。

* **巧解：看缺口对不对称**

    * 这道题有点特殊，是它的特殊性给了我们一个口子：选项里这些图形是成对出现的。
    * 把它转过来比一比，会发现这两个图形是一样的，这两图形也是一样。
    * 既然是同一个多面体重复出现，那两两组合的时候，最后拼出来的东西一定是对称的。

```text
同一个多面体出现两次
   ↓  旋转、翻转之后必须能完全重合
两两组合时，各自缺掉的那个角应当互为对称位置
   A：这两个缺口对称      ✓
   B：这两个缺口对称      ✓
   D：这两个缺口对称      ✓
   C：这两个缺口对称不了  ✗
   ↓
   答案 = C
```

    * 心思细一点、敏感性好一点，这题可以秒到。
    * > **提示**：立体拼合看着吓人，但出题人往往会给你留口子。找"重复出现的同一块"、找"缺口是不是对称"，往往比真拼一遍快得多。真要一笔一笔硬拼也拼得出来，但那个性价比不高。

* **考场上的理性处理顺序**

    * > **易错点**：这类题在考场上的理性处理顺序是先找巧解；巧解没有、又时间紧，就先搁置，有时间再回过头来看，没时间就算了。真硬拼的话，高压状态下你未必有时间，也未必有这个能力。

### 展开图

* **两种方案**

    * 第一个方案是画橡皮，画出正方体再折，半分钟就出来了。
    * 第二个方案是看方向，不用动笔，但看你看得准不准。

* **判定基准是开口方向**

    * 问的是同一个纸盒的外表面展开图，除了哪一项以外。
    * 里面是不是出现 A 跟 C，A 跟 C 是不是都有方向，那就先拿 A 和 C 对齐。
    * A 选项里，把一个 C 旋转 90 度放下来，想象它就是正方体底面那一圈，这四个面是转圈的，所以这个 C 可以平移到那个位置上来；平移过去一看，两边也都是 C，而且这两个 C 的开口方向是一致的。
    * C 选项里把这两个 C 统一往上旋转 90 度，转过来之后是 A、C、C，这两个 C 的开口方向还是一致。
    * 第四个同样把 C 旋转 90 度放上去，这一个 C 往这个方向、那一个 C 往那个方向，一个往左开、一个往右开，跟前面不一样。
    * 前面 A 和 C 都是同一个方向，第四个不一样，那就是它。

| 选项 | 开口方向表现 | 判定 |
| :--- | :--- | :--- |
| A | 两端都是 C，开口方向一致 | 通过 |
| C | 转 90° 后两个 C 的开口方向一致 | 通过 |
| D（第四个） | 一个往左开、一个往右开 | 出局 |

* **判定与效率**

    * > **结论**：同一个正方体的展开图，所有字母的相对朝向是定死的。有一个方向对不上，选项就出局。
    * 第四个出来之后，B 连看都不用看。
    * 方式很多的，很简单的题目，30 秒搞定。

## 面积失效后看整体特征

* **面积为什么走不通**

    * 每一块都像是小正方形的一半，每一处都是正方形的一半，第一想法就是会不会考面积。
    * 简单浏览一下就发现不行：全都是一半，每一个小正方形里都只选了一半，那就没办法走面积了。
    * 没什么规律，那就整体来看。

* **正方形处在哪儿**

    * 有的图形里有一个正方形，这几个是这种拼接方式的；这也有一个正方形，只是外面的拼接方式又不太一样。
    * 乍一看反正都有正方形，那就看这些正方形在哪儿。
    * 这个正方形在中间，这个正方形也在中间，这个正方形在中间。
    * 这个在边上，这个也在边上，这个也在边上。
    * 1、3、4 还真有这个答案，国考出题人这次还真没为难人。

* **简单规律的取舍**

    * > **提示**：图形推理里"简单到不像真的"的规律，往往就是答案本身，不是陷阱。想出来了既然这么简单，那就选了走人，别再想了。

## 特征元素连线

* **特征元素的识别**

    * 先找特征：两个黑的，再加上两个螺旋圈（双圈），这双圈特别特殊。
    * 数数量——这俩黑的，这俩双圈，2、2，没有规律。
    * 说位移，这俩黑的移不到一块去；内外圈一起位移也不是；上下左右横着竖着位移也不对。
    * 转圈不对，移动也不对，那还剩什么？把它们连起来看。

* **连线后的分组**

```text
把两个黑 + 两个双圈连成折线，逐条看方向
  1 垂直   2 垂直   3 平行
  4 垂直   5 平行   6 平行
  -----------------------------
  1、4 成一组（垂直）；3、5、6 成一组（平行）
  答案 = 1、2、4，即 C
```

* **载体迷惑**

    * > **易错点**：这道题很大的一个迷惑性在于，它就放在了一个 4×4 的黑白块里。个别同学一看黑白块会误以为这是一个黑白块的题，可能有一定迷惑性。黑白块里突然多这么个东西，他可能就不往下想了。但这根本不是一个完全新的规律。
    * > **结论**：黑白块是载体，不是考点。载体上突然多了几个"看起来像新东西"的元素时，先别慌，把它们当成特征元素去连、去数、去比方向。

* **知识点的循环性**

    * 这个考点以前考过，但是已经很久没考了，不是什么新知识点。
    * 本质就是两个特征的元素，把它们连起来，看它们连出来的是平行还是垂直。
    * 出题人喜欢炒冷饭，他的"新"是跟前四五年不一样的新，出点新的融合性规律；有时候想不到，就把曾经很多年前的一些东西拿出来炒一炒。
    * 平时做题一定要广泛涉猎、多刷题多做题，不要管年份；这些规律总共就那么些，这几年喜欢考这个，过几年它又考回去，循环性的东西一定要多练多做。

## 预判与事后找补

* **后视错觉**
    * > **定义**：一种认知偏差，事情发生之后，即使个体此前没有对它做过预判，也认为自己早就知道会这样。
    * 本质就是马后炮，判定分两步：事前有没有明确的判断，事后有没有用行动兑现；两步都成立就不属于后视错觉。
    * 事前已有预期且被证实的选项直接排除：升职申请失败的悲观者早就认为自己不行，最后确实失败，前后一致；听到高温预警而不上山的人做了明确预判，后来确实很热，前后也对得上。
    * "我早该想到"不等于"我早就知道"：忘了按周末通勤情况预估堵车、事后懊悔，是懊悔不是马后炮。
    * 典型马后炮：股票大跌后才说"我早就察觉到那些信号了，觉得走势不好，怎么就没早卖"——当时只有"信号好像不太好""万一涨了呢"，没有明确判断也没有行动，继续拿着，事后才回头挑蛛丝马迹叙述成预判。
    * > **易错点**：⚠️ 预判 = 明确的判断 + 用行动兑现。只有迹象、感觉、"万一"，事后才被讲成"我早就知道"，那就是死鸭子嘴硬式的找补。

```text
【真正的预判】
  "我觉得这只股票一定会跌"
        |
        v  用行动兑现
  马上卖出
        |
        v
  跌了 —— 预判正确

【马后炮】
  "信号好像不太好""万一涨了呢"
        |
        v  没有明确判断、没有行动
  继续拿着
        |
        v
  跌了 —— "我早就察觉到那些信号了！"
```

## 或然率模型

* **或然率理论**
    * > **定义**：或然率由传播内容对受众的吸引力和受众获取该内容的费劲程度共同决定，二者之比即为或然率。
    * 判定只抓分子分母：分子增大、分母减小则值必然增大，反过来分母增大则值减小。
    * 公式：$\text{或然率} = \text{报偿的保证} \div \text{费力的程度}$。
    * 符合项：平台用数据分析和个性化算法直接推荐符合偏好的视频，分子增大（推的都是我喜欢的，更有吸引力与实用性）、分母减小（不必再自行搜索），两头同向，值必然增大。
    * 使值减小项：想看的影视作品播放前被插入 2 分钟广告，等同于要多熬 120 秒，获取途径变难，分母增大。
    * 使值减小项：电视内视频播放必须先注册登录才能搜索观看，传播途径前置了一道门槛，不熟悉操作的老人更是难度剧增。
    * > **易错点**：⚠️ 题干里的"费力的程度"指获取大众传播内容、使用传播途径的难度，不是购买商品的难度。优化商品布局、把畅销品放在出口处、顾客扫码支付，讲的是购买行为，与题干不搭嘎。

* **报偿的保证**
    * > **定义**：传播内容满足消费者需要的程度，即内容对受众的吸引力和实用性——受众需不需要它、喜不喜欢它、用不用它。

* **费力的程度**
    * > **定义**：受众获得该信息的费劲程度，即要不要很费劲才能看到它。

## 自动投案：判定主体与盘问、审讯的边界

* **自动投案**
    * > **定义**：公安机关没有发现某人犯事，其自己主动去交代。
    * 判定主体只有公检法：父母劝他投案不算，单位发现款项异常、开始查账也不算，司法机关没发觉的情况下去投案都算。
    * "被迫"不取消自动投案的性质：无人知晓时主动交代，即使出于压力也是主动交代，与劝说主体的身份无关。
    * 符合项：入室盗窃被判刑后，服刑期间主动交代司法机关完全没有掌握线索的另一走私案主谋身份。
    * 符合项：公安机关在隐患排查、入户走访中发现其形迹可疑，经盘问后主动交代罪行——排查只是摸排，尚未对犯罪事实与犯罪嫌疑人形成发觉。
    * 不属于项：公安机关经侦查已确认其为犯罪嫌疑人，又把他从拘留所调出来审讯，他才交代自己的罪行。
    * > **易错点**：⚠️ 盘问 ≠ 审讯。讯问、审讯是把人带过去正式询问，盘问只是常规地问一问（你刚才干嘛、你前天去哪），题干出现"盘问"不代表公安机关已经掌握了事实。

## 同一认定：两个硬性要件与不符合项

* **同一认定**
    * > **定义**：在侦查中，由具有专门知识的人或了解客体特征的人，通过比较先后出现的客体的特征，判断客体是不是同一个。
    * 客体指与相关案件有关联的人或物。
    * 两个硬性要件：必须先后出现两个客体，判断的必须是"是不是同一个"。
    * 符合项：把犯罪现场提取的 DNA 与 DNA 库比对来查找犯罪嫌疑人——库中已存有此人的信息，现场又提取到一份，用先后出现的客体特征判断是否同一个人。
    * 不符合项：检查手机中存储的信息以确认是否为报案人所丢失的——只有一部手机，判断的是这部手机与报案人之间的归属关系，没有先后出现的两个客体。
    * 不符合项：多次鉴定缴获的走私物品是否某国外厂家、某批次生产——同一牌子的手机都长一样，但同一认定要验证的是这一部是不是那一部，不是鉴定厂家批次。
    * 不符合项：检查嫌疑车上缴获的物品是否属于违禁品——根本没有作同一性判断，也没有先后出现的两个客体。

## 概念间关系与流程顺序

### 三维反求的四个步骤
* **三维反求工程**
    * 步骤顺序就排在题干里：测量 → 数据处理 → 图形加工 → 验证。
    * 测量：用高精度的三维技术获取零件各表面的空间点，把各处长度、高度先测出来。
    * 数据处理：通过一定的算法，从测量数据中提取零件的设计和加工特征——对象正是上一步测出的数据。
    * 图形加工：使用计算机辅助设计软件，把数据与特征重构为三维模型。
    * 验证：通过 3D 打印把样品制造出来，检查它是否满足最开始测量的精度和其他性能指标。
    * 判序技巧：先确定哪一步的产出是下一步的输入，后一步必排在前一步之后。

### 汛期的包含与时序
* **春汛、夏汛及其细分**
    * 春汛：气候转暖、流域内的季节性积雪融化、河流解冻或者春雨引起的汛；桃花盛开时节出现的春汛又叫桃汛。
    * 凌汛：春季河水解冻引起的汛。
    * 夏汛：发生在夏季的汛，习惯上把夏季三伏前后的汛期叫做伏汛。
    * 包含关系：春汛包含凌汛，河水解冻只是春汛的一种成因；夏汛包含伏汛，三伏天肯定在夏天。
    * > **易错点**：⚠️ "伏汛在凌汛前"把夏汛排到了春汛前面，是时序颠倒；含包含关系时先看季节归属，不能按字面排列。

### 国、都、鄙、邑
* **四个古代城邑概念**
    * 国：指诸侯的封地，又可以指天子或诸侯的都城。
    * 都：指大的城邑，后来引申为有重要政治地位的大城邑。
    * 邑：指城镇。
    * 鄙：指边远的小城镇、小城市。
    * 包含关系：都、鄙都属于邑——大的城邑是城邑，边远的城邑也是城邑，二者与邑都是包含关系。
    * 交叉关系：国与都交叉，有一部分城邑既是国里的都城，又属于都所指的那种有重要政治地位的大城邑。
    * > **提示**：某一项以"国"作难以判断的干扰项时，先把它放掉，把后面几个概念看明白，题就做完了。

## 词义取舍

* **断取**
    * > **定义**：断章取义，即只取一个词的一半词义来用。
    * 判定杠杆是"词的本意"与"实际取的部分"是否一致：只取一半就是断取，取整词本意就未断取。
    * 用了比喻也不等于断取，只要引号里的词取的仍是整词本意。
    * > **注意**：题干里带"没有"两个字时，问的是"没有使用断取"的一项，先把否定词圈出来再逐项排除。

| 说法 | 词的本意 | 实际只取了 | 判定 |
| :--- | :--- | :--- | :--- |
| 小儿科 | 医院里小孩的那个科室 | "小" | 断取 |
| 光杆司令 | 部队打没了，只剩一个司令，没有下属 | "光杆"，即光棍、一个棍儿 | 断取 |
| 上刀山下火海 | 两种危险都上 | "下火海" | 断取 |
| 开药方 | 医生开方子治病的比喻义 | 整词本意：走投无路时找老师要一个方向、破解之道 | 未断取 |

## 常识型定义的研究对象与手段

### 细胞化学
* **细胞化学**
    * > **定义**：研究细胞的化学成分，在不破坏的状态下用生化和物理的技术，对细胞各种组分里的各种成分到底多少进行分析。
    * 切入点是"化学"两个字：只有对化学成分做含量分析的选项才对得上。
    * 符合项：研究动物细胞内的核酸、蛋白质吸收不同紫外线光的特点并分析其含量——对象是化学成分，用的是物理手段（荧光分析一类），落到含量分析上，三者齐备。
    * 不符合项：只观察细胞环境中的各种影响和活动。
    * 不符合项：显微镜下观察形态。
    * 不符合项：观察小鼠免疫细胞被病原体释放毒素杀害的动态过程。
    * 兄弟学科：研究形态的是细胞形态学；研究生理活动与代谢的是细胞生理学；研究细胞内遗传物质的是细胞遗传学；研究各种生命规律的是细胞生物学；研究物理状态的是细胞物理学；研究免疫的是细胞免疫学。
    * > **提示**：常见资料把这一研究写成"定性分析"，题干给的是"定量分析"，谁有问题并不确定，但定性与定量之别不影响本题的判定。

### 土地监测
* **土地监测**
    * > **定义**：利用遥感遥测技术进行相应的监测、测定，获得土地类型数据。
    * 切入点是"遥感""遥测"四个字，没有这两项技术的选项直接删掉，不必逐字读完拗口的断句。
    * 符合项：使用遥感获得土地类型数据。
    * 不符合项：现场踏测、现场勘测，没有用遥感。
    * 不符合项：土地权属资料的变更，与遥感遥测没有关系。
    * 不符合项：用红外线特征的遥感绘制植被的生长周期图——定义指向对土地地形、土地利用情况的监测，如土地红线、各块土地拿来做什么、土地使用情况，而不是测森林长得好不好、植被什么时候长。
    * > **提示**：断句陌生的长定义往往只需抓一个专有技术词，锁定后可以直接定答案。

## 定义判断的考场策略

* **无技巧性与唯一实用技巧**
    * 现在的定义判断越来越考常识积累，技巧性很少，做得多做得少差别不大。
    * 真正能用的技巧只有一个：遇到难的、有争议的、想不明白的、模棱两可的题，及时扔掉去做别的。
    * 十道题的总盘时间就是 10 分钟，不要在一道题上弄来弄去磨掉三分钟。
    * 大量刷题的主要收益不是手快，而是掌握哪些题该舍、做好时间分配。
    * 常识就是定义判断的底层能力：天文地理、生物化学都要广泛涉猎，涉猎越广，定义一出来就越能大致判断选项长什么样。
    * 靠定义本身带出的浅显技巧（没有"遥测"没有"遥感"的选项直接删）不需要谁教，它对提分几乎没用。

## 出题规律与考场取舍

* **炒冷饭**

    * 出题人的"新"是跟前几年不一样的"新"：能想到新的就出新的，想不到的时候，就把你很多年前的东西拿出来炒一遍。

    * 图形规律总共就那么些，这几年喜欢考这个，过几年他又考回去，是循环性的。

    * 平时做题一定要广泛涉猎，多刷题、多做，不要管年份，也不要按年份划复习范围。

    * 常见伪装是把老规律塞进 4×4 的黑白块里：图形里突然多了这么一个东西，人就不会往老考点上想，个别同学会误以为这是黑白块的题。

* **考场取舍**

    * 要大量颅内立体拼合的题，考场上如果没有特别好的办法，先搁置，等有时间再回过头来看；没时间就算了。

    * 这类题出题人往往留了解法的口子，敏感性不好、没看到这一点的，硬算很消耗脑细胞，也未必有这个时间，建议先放一放。

    * 定义判断碰到表述拗口的选项，第一眼可以先扔到一边，做法是先看别的，最后再回头看。

## 面

### 面的考查形式

* 拿到整体封闭图形，先老老实实数面；数出来的个数三、四这样来回跳、翻来覆去看不出规律时，面与边就暂时先不过去。

* > **易错点**：面太明显的时候，这题大概率还是跟面有关，不要因为数不出数量就换方向。

* 考"面"除了考面本身的数量，最常考面与外框的对应关系——这个外框是几边形。

* 面积若没有区分度就走不下去：有的题每个位置都恰好是某个小正方形的一半，看面积全是一样。

### 最大面与最小面

* 国考最近还喜欢考最大面和最小面的关系。

    * 最大面跟其他面、跟整体图形的关系。

    * 最小面跟最大面、跟整体图形的关系。

    * 最大面内部自己的规律。

    * 上述关系还可以跟数量糅合在一起考，可考的组合非常多。

* 最小面不好说是谁、找不到时，就先找最大的那个面，再看它跟整体、跟别的面有什么关系。

* 最大面本身可看的属性：边长、对称轴、是否对称图形。

* 本题边长看不出，对称轴方向好像不一定，唯一能坐实的是它们首先都是对称图形。

* 逐项排除：

    * 第一个选项，最大面根本不是对称图形。

    * 第二个选项，最大面也明显不是对称图形。

    * C 选项的最大面是个平行四边形，是个中心对称，不是轴对称。

    * 第四个的最大面没问题，是一个对称图形。

* 本题考的就是最大面都是轴对称图形，答案是第四个。

## 黑白块：部分数

### 黑白块的常见考点

* 5×5 的黑白块做得太多，考点大概都知道：数量、位移、黑白球的对称、部分、一笔画、连接线，近些年也跑不出去这些东西。

* 5×5 数量比较多，先把黑球和白球分开看。

* 白色里有一个小球是孤立的，其他白的都连在一起，所以白色是两部分。

* 黑色是连成一部分的。

### 部分数与内含递增

* 图形之间的规律是统一的：黑色都是一部分，白色都是两部分，找"一部分 + 两部分"的选项。

* 白色本身还藏着一条细分递增：分点数依次是一个、两个、三个、四个、五个，下一个应找有六个的。

* 逐项排除：

    * A 项黑色一部分没问题，白色却出现了一部分、两部分、三部分、四部分，表多了。

    * C 项黑色一部分没问题，白色出现一部分、两部分、三部分，也不对。

    * 还有黑色本身变成两部分的，也错。

* 答案：第二个选项，黑色一部分、白色两部分，且白色分点数是六个。

## 奇点与一笔画

* > **定义**：奇点就是"丁字路口"那种交叉点。

* 奇点为 0 个或 2 个，可以一笔画；奇点为 4 个，就得分两笔。

* > **提示**：走投无路，一笔画——找不动、想不到别的规律时就回头试一笔画，大概率有可能就搞定了。

* 典型题里第三个图形看着乱糟糟的，一眼看到就忍不住想试一笔画，结果一笔画能走完，所以 1、3、4 符合。

    * 第五个图形正好上面一笔、下面一笔，总共也是两笔。

    * 第六个图形有四个丁字路口、四个奇点，两笔画。

* 答案：第二个。

## 样式类：去同存异与翻转的规则与逐块验证

* 看到线条互相重复出现、尤其明显地回过头又出现，优先想"样式规律 + 去同存异"，也就是消消乐。

* 去同存异规则三条：

    * 两个都有——消掉。

    * 我没有、你有，或者你有、我没有——没有消掉，留下。

    * 白 + 白保留，黑 + 黑消掉，黑 + 白保留。

* > **易错点**：白 + 黑一定要留下，两个颜色不一样，异了它不消。

* 以三幅图里的前两幅为基准做去同存异，把留下来的线画出后，它跟第三幅图正好是一个水平翻转的关系。

## 立体图形

### 斜切面

* 题干说现在用经过 P、Q、R 三个点的平面对其进行切割。

* > **易错点**：P、Q、R 这三个点不一定就能确定一个平面，你得先把这个平面找出来。

* 这个平面从 P、Q 斜着连到 R，是一个斜切的面。

* 它切的是底下那个方体、长方体，前面还多出一个小斜坡；紧接着在前面这个小斜坡里面又切了一半，只切了一部分。

* 横着这么一刀切过来以后，得到的是底下那个方体加一个小斜坡，而这个斜坡那部分又被切走了一块。

* 答案：A。

### 立体拼合中的"不可能"

* 问"不可能"，意味着选项里是三个能拼上、一个拼不上，难点全在"不可能"这三个字上；如果问的是"可能"反而好做一点。

* 棱长为 1 的多面体在 3×3×4 的空间内拼接，这个空间太多了，里面有很多块放在背后、看不见，真去拼要大量颅内立体拼合，很麻烦。

* 解法第一步，看这四个图形之间的关系：两个图形一模一样，另外两个旋转过来也一样，即两组图形两两相同。

* 解法第二步，让两两相同的图形去拼合：A 选项的这两个地方是对称的，B 选项空的这个地方和那个地方对称，第四个选项这两地方也对称。

* 原理是两两组合时两边给的是一模一样的东西，拼合出来的整体肯定是一个对称的东西，缺的那两个角应该是对称的。

* C 选项这两块对称不了，所以 C 就是那个拼不出来的。

* 答案：C。

### 纸盒展开图

* 题干问的是"同一个纸盒的外表面展开图"，设问是"除了哪项以外"，即三个选项是一样的。

* 方法一是画橡皮：在方格纸上把展开图折成立体的样子画出来，各个面的关系一摆开就清楚了，半分钟就出来。

* 方法二是看方向：不画橡皮就看方向，没有那么快，但只要看得准也成立。

* A 选项把两个 C 都旋转 90 度放上去，会发现 A 的两端各是一个 C；正方体下面这一圈四个面是转圈的，C 可以平移到对应位置，所以 A 的两边也都是同样形状的 C。

* C 选项把两个 C 统一往上旋转 90 度，转过来之后两个 C 的开口方向一致，所以 C 目前没有问题。

* 第四个把 C 旋转 90 度放上去，会发现一个往这个方向、一个往右开，两个 C 的方向不一样了；而 A 里两个 C 都是往两个相反方向的，C 里也都是往两个方向的。

* 既然 A 跟 C 一样、第四个跟前面两个都不一样，答案就锁定第四个，B 就不用管了。

* 答案：第四个，整体 30 秒左右可以搞定。

## 定义判断

### 后视错觉

* > **定义**：后视错觉是一种认知偏差——一个事情发生之后，即使这个个体之前没有对此做过预判，他也认为自己早就知道会这样。

* 通俗讲就是马后炮：事情发生之前你不说，发生了之后就说"我早就知道会这样""我以前就知道会这样""我猜就知道会这样"。

* 判定关键在于判断"是不是真的做过预判"，看有没有用行动支持这个预判。

* A 选项：小锦是一个悲观的人，升职申请失败后灰心丧气地说"我早就知道我什么都不如别人"。

    * 题干白纸黑字交代他是悲观的人，说明他在申请升薪之前就认为自己不行。

    * 前后一致，不存在马后炮行为，没有认知偏差，所以 A 不对。

* B 选项：朋友叫阿新去爬山，阿新说高温预警不适宜爬山，最后阿星说"哎，我早就说会很热"。

    * 他之前就说过会很热，来了之后确实热了，是真预判，也没有认知偏差，排除。

* C 选项：小林参加了一个重要的会议迟到了，懊悔地说"我早该想到周一早上会堵车，不应该按照周末的通勤情况来"。

    * 他是忘了，不是他预判了，之前并没有做任何预判。

    * 他后来说的是"我早该想到"，并没有说"我早就知道今天早上会堵车，所以我迟到了"；他要是那么说了才叫马后炮。

    * > **易错点**："我早该想到"不等于"我早就知道"。

* 第四个选项：小飞在股票大跌之后懊恼地说"我早就察觉到那些信号了，觉得走势不太好，怎么就没有早卖出去啊"。

    * 预判是觉得这股票一定会跌；如果真的预判到它一定跌，他就卖了，不会干等着它跌。

    * 他拿这只股票时只是突然来个消息觉得走势不太好，又觉得那边有很多消息、明天又能升，想再拿几天万一涨了；第二天发现跌了才后悔。

    * 他忽略了自己"再拿拿"的想法，只挑对自己有利的部分事后回想，这就是死鸭子嘴硬式的找补。

* 答案：第四个，A、B、C 是铁错。

* > **提示**：这类题出得很难也出得很好，它需要你对整个文段进行分析、对比择优，而不是浅显地给你一个一一对应的说法，对分析判断能力有要求。

### 选择或然论理论

$$
\text{选择或然论理论} = \frac{\text{报偿的保证}}{\text{费力的程度}}
$$

* > **定义**：报偿的保证，指传播内容满足消费者需要的程度，也就是内容对受众的吸引力和实用性——传播的内容有没有吸引力，你需不需要它、喜不喜欢它、用不用它。

* > **定义**：费力的程度，指获得这个信息的费劲程度，就是难不难——要跨过各种很费劲的坎才能看到这个传播的内容。

* > **提示**：考场上高压状态下看到这种表述会想直接扔到一边，做法是先看别的，然后再回头看；这题其实出得很简单，认真读一遍两分钟一定能读懂。

* A 选项：视频号平台借助数据分析和个性化算法，给用户推荐符合其偏好的视频。

    * 推的都是用户喜欢的，报偿的保证增大，分子增大。

    * 直接推荐符合偏好的视频，用户不需要额外去搜索，费力程度减小，分母减小。

    * 分子增大、分母减小，整体必然增大，答案直接结束选 A。

* B 选项：时下流行的某影视作品，在播放之前被插入了一段 2 分钟的广告。

    * 本来直接点开就能看，现在得在播放器里等 120 秒，获取这个内容的难度增加了。

    * 分母增大，整体减小，排除。

* C 选项：某商家优化了商品的布局，将畅销的商品放在了出口处，顾客可以直接扫码支付。

    * > **易错点**：题干中的"费力的程度"指的是获取传播内容、使用传播途径的难度，即大众传播内容及其传播途径的难度，不是购买这个产品的方便程度。

    * 这一项连对象都不是同一样东西，一个是商品，一个是传播内容，排除。

* 第四个选项：电视内的视频播放，开机后必须要先注册登录才能搜索观看。

    * 相当于在传播途径前面加了一道门槛，又要注册又要登录，获取难度大幅增加。

    * 费力程度增加，选择或然论会下降，排除。

* 答案：A，回头来看很好选。

### 自动投案

* > **定义**：自动投案就是公安机关没有发现你犯事了、没有发现你的犯罪事实、也没有把你确认为犯罪嫌疑人，然后你自己主动去说。

* > **提示**：这类题可以不看定义，从选项的措辞就能锁定答案。

* 第二个选项：乙致人重伤后潜逃了，公安机关经过侦查，确认该犯罪嫌疑人是甲。

    * 选项写明"公安机关经过侦查"，公安已经花大量力气侦查调查，并已把甲确认为犯罪嫌疑人。

    * 已经被确认为犯罪嫌疑人，就谈不上自动投案。

* 答案：第二个。

* A 选项：甲涉嫌多起诈骗，在公安机关进行一次隐患排查、入户走访的过程中被发现形迹可疑，经过盘问主动交代了自己的罪行。

    * 隐患排查就是公安里面最重要的摸排，是一个人一个人地摸排。

    * 公安此时对犯罪事实、对犯罪嫌疑人都没有发觉，只是发现他形迹可疑、鬼头鬼脑躲躲闪闪。

    * 没有把甲确认为犯罪嫌疑人，也没有发现任何犯罪事实，所以这肯定是自动投案。

* 其余选项的判断理由，长文未说明。

## 盘问与讯问

* **盘问**

    * > **定义**：民警在事发现场正常询问情况、套两句话。

    * 典型情境：民警对鬼鬼祟祟之人问"你刚才干嘛呢""你前天去哪了""你之前都去过哪里"。

    * 该次盘问本身没查出什么，公安机关也没发现当事人犯罪，没有审讯、没有讯问、没有强制措施，当事人自己把罪行交代了。

* **讯问 = 审讯**

    * > **定义**：公安机关把当事人带过去询问，讯问与审讯是同一个东西。

    * 分水岭：一个是在现场随口问问，一个是把人带过去正式问。

* > **易错点**：盘问 ≠ 讯问（审讯）。问出东西来的那个属于后者，性质完全不一样。

## 自动投案：只看是否已被司法机关盯上

* > **定义**：只要公检法都没有发现、没有介入，自己主动去交代，就算自动投案。

* 判定只看有没有被司法机关盯上，与"主动"的施动方无关。

    * 单位发现款项异常、开始查账——单位不是司法机关，公安没发现、法院没发现，仍然成立自动投案。

    * 父母劝去投案没效果——父母不是司法机关。

    * 是被迫还是自愿、心里害怕才去——都不影响这个定性。

* 边界一：服刑期间主动交代另一桩走私案的主谋，公安机关根本没有掌握线索，成立自动投案。

* 边界二：公安机关已把你定性为犯罪嫌疑人、已查过你要去抓，人在拘留所又被审问才交代——这是已归案之后再交代问题，不成立自动投案。

* > **易错点**：错选"被迫"的，根本原因是忽略了"公检法未发现"这个前提；错选"已归案后交代"的，忽略了"公安机关已定性、你人在拘留所被审"。

## 定义判断里的排序题

* **三维反求工程**

    * > **定义**：以高精度三维技术获取零件空间坐标，经数据处理与图形处理重构模型，再制出样品反推校正的流程。

```text
  ①  测量
      高精度三维技术获取零件表面各点的空间坐标
      记录各方向的长度、高度等原始数据
        │
        ▼
  ②  数据处理
      用算法从测量数据中提取零件的设计与加工特征
        │
        ▼
  ③  图形处理
      用计算机辅助设计把数据与特征重构为三维模型
        │
        ▼
  ④  3D 打印制出样品，验证精度与其他性能指标 → 反推校正
```

    * 各步要点

        * 测量：获取零件表面各个点的空间坐标，把各个方向的长度、高度测出来。

        * 数据处理：通过算法从测量数据中把零件的设计特征和加工特征提取出来。

        * 图形处理：使用计算机辅助设计，把数据与特征重构为三维模型。

        * 验证反推：3D 打印制出样品，检验是否满足最开始那个精度和其他性能指标，反过来推。

* > **提示**：定义判断里混进来的排序题，别硬抠题干的技术含义，把选项当成流水线看：谁在前、谁在后、生效结果在哪一步。顺着"原始数据 → 加工 → 模型 → 实物验证"这条线走即可。

## 概念关系

* **全同**

    * 汇编语言又称符号语言，二者是同一个东西。

* **并列**

    * 行政文书与商务文书并列：前者是行政类公文（含函等），后者是公司之间的商务相关文书。

    * "都"与"鄙"并列：大的城邑是"都"，边远的城邑是"鄙"，二者同属"县"这个大概念。

* **种属**

    * 函是行政文书的一种。

    * 汇编语言是计算机语言的一种。

* **交叉**

    * > **定义**：一个概念既可以指 A 又可以指 B，且两个所指存在部分重叠时，按交叉处理。

    * "国"指诸侯的封地，又可以指天子或诸侯的都城；"都"指大的城邑，引申为有重要政治地位的大城邑——"国"里的城不一定是"都"，"都"也不一定指"国"的都城。

    * 例证：北上广深都是有重要政治地位的大城邑，但只有一座是都城。

* 词语的准确所指

    * "国"：诸侯的封地；天子或诸侯的都城。

    * "都"：大的城邑；有重要政治地位的大城邑。

    * "鄙"：边远的小城镇、小城、小城市。

    * "县"：城镇，是覆盖"都"与"鄙"的大概念。

* > **易错点**：一个概念既可以指 A 又可以指 B，往往不是"全同"也不是"并列"，而是交叉；遇到所指部分重叠就按交叉处理。凡涉及交叉关系的题，含非交叉项的那一组直接排除。

## 汛期概念

## 断章取义

* **断取 = 断章取义**

    * > **定义**：把成语/词语的原意找出来，再看选项里是不是只留了其中一个词素，只留一部分即为断章取义。

* 判定为断章取义的实例

    * "小儿科"本意是医院里小孩的那个科室，选项中只取"小"的意思（见过很多大阵仗，眼前情形只是小事）。

    * "光杆司令"本意是部队打没了、只剩司令员没有下属，选项中只取"光杆"（光棍）之意。

    * "上刀山下火海"中消防员只做了"下火海"，没有上刀山。

* 判定为未断章取义的实例

    * "开药方"取的是三字全意：走投无路找老师，希望老师给出一个解决问题的方向，未只取"开"或只取"药方"。

## 细胞化学

* > **定义**：用生化和物理的技术，在不破坏细胞的状态下，对细胞各种组分里的化学成分进行相应的分析。

* 核心抓取要素

    * 看到"化学"两个字。

    * 生化和物理技术。

    * 对细胞各种组分的成分进行分析。

* 所属学科的分辨

    * 细胞化学之外还有细胞生物学、细胞形态学、细胞生理学、细胞遗传学、细胞物理学、细胞免疫学等，各研究对象不同。

    * "观察细胞环境当中的各种影响与活动"是观察，与化学无关。

    * "显微镜下观察形态"属于细胞形态学。

    * "小鼠免疫细胞、病原体释放毒素杀死免疫细胞的动态过程"属于细胞生物学、细胞病理学或细胞免疫学，不是化学。

* 正确项：动物细胞内的核酸、蛋白质吸收不同紫外线光的特点并分析其含量，用到荧光分析一类技术，且题干明确要求"分析其含量"。

* 边界：细胞化学的经典说法是"定性分析"，而题面给的是"定量分析"，二者不一致的原因长文未能确认；但对解题无影响。

* > **提示**：个别细节与权威定义对不上时别在细节上死磕，只要定义的核心要素能被选项覆盖，答案就定下来了。

## 同一认定：主体、方式与判断内容三要素

* > **定义**：在侦查中，由具有专门知识的人或者了解客体特征的人，通过比较先后出现的客体的特征，对客体是不是同一个作出判断。

* 三要素

    * 主体：具有专门知识的人，或了解客体特征的人。

    * 方式：比较先后出现的客体的特征。

    * 判断内容：是不是同一个。

    * "客体"所指：相关的案件、关联的人或者物。

* 正确项：犯罪现场提取的 DNA 与 DNA 库进行比对来查找犯罪嫌疑人。DNA 库中已存有该人信息，现场又提取到其 DNA，比较先后出现的客体特征即可判断是否同一人。

* 边界一：检查手机中存储的信息以确认是否为报案人所丢失——只有一部手机，判断的是手机与人的归属关系，不存在先后两个客体，不成立同一认定。

* 边界二：对缴获的走私物品多次鉴定，确认是否某个国外厂家生产——同品牌同批次不等于同一台，判断的是厂家牌子，不是"这一台"与"那一台"。

* 边界三：判断犯罪嫌疑人车上缴获的物品是否属于违禁品——没有同一性判断，不成立。

## 定义判断的做题策略

* 趋势：定义判断越来越考常识性的东西，越来越没有什么技巧性，做得多做得少帮助都不大。

* 唯一的技巧：遇到难的、有争议的、自己想不明白的、模棱两可的题，快速地扔掉，去做其他题。

    * 十道题的总时间是十分钟，绝不能一道题弄两三分钟、三五分钟。

* 真正有用的东西是常识

    * 定义判断需要的常识就是常识判断那个模块：天文地理、生物化学，各种知识都要广泛涉猎。

    * 有了常识和定义，平时涉猎广泛，定义一出来就能判断，甚至能预判选项长什么样。

    * 浅显技巧即使不说也会用，例如第 95 题一看"遥感遥测"，没有遥测、没有遥感的直接删掉——这种技巧不需要专门学。

* > **提示**：常识沉淀不是考前突击能解决的，它对应长期的知识面；多做题唯一真正的用处是让你见得多，不是为了练手速。

## 古文造句定关系

* 方法：加引号的古文选项考的不是古文本身，而是它背后的逻辑关系；不知道原文也能猜出七八八，再造句验证。

* 造句法：在方式后面接"为了"，看能否接上目的。

    * "嘤其鸣矣，**为了**求其友声"——鸟儿叫是方式，求其友是目的，方式目的关系。

* 对应选项的辨析

    * "遏其生机"配"以（此）求高价"——"以（此）求高价"即"为了求得高价"，遏制生机是方式、抬高价格是目的，方式目的关系，符合。

    * "求之其本，经旬必得"——心想求其根本，经过一段时间必有所收获，是"如果……那么……"的条件关系。

    * "道不拾遗，夜不闭户"——并列关系。

    * "避其锐气，击其惰归"——时间顺序。

* 答题结论：判断推理里的加引号古文，先猜意思，再造句定关系。

## 近义词与褒贬色彩

* 题干成语

    * 殚精竭虑：全副精力、整个身心倾注于某件事，用尽心力、费尽心思，褒义词。常见搭配"殚精竭虑地备课"。

    * 费尽心机：费尽了心机、小心思，也是用尽心思，贬义词。常见搭配"费尽心机地讨好某人"。

    * 关系：核心意思都是"费尽心思"，广义上构成近义词，色彩为前褒后贬。

* 三步判定法

    * 先定关系：近义、反义或无关。

    * 再定色彩：褒、贬、中。

    * 最后在选项里挑"关系+色彩"都最匹配的那一个；找不到完美的就挑最接近的，判断推理永远选最优解。

* 选项色彩比对

    * 狐假虎威与虚张声势是近义词，但都是贬义，对不上"前褒后贬"。

    * 舍生忘死与死里逃生完全不是近义词：前者是不顾个人安危、将生死置之度外的牺牲精神，后者是在危险中幸免于难、逃出来了。

    * 光怪陆离是千奇百怪、色彩纷杂鲜丽的中性词；五光十色是明亮鲜丽、花样繁多的褒义词，褒贬不同。

    * 侃侃而谈是理直气壮、不慌不忙地说话、很自信的褒义词；喋喋不休是唠唠叨叨、没完没了的贬义词。

* > **易错点**：褒贬不同还能是近义词吗？能。应用场景不同但有共同核心意思，"殚精竭虑地备课"与"费尽心机地讨好老板"都含"费尽心思"，广义上可认定为近义词。

* > **易错点**：觉得侃侃而谈和喋喋不休不像近义词，也是因为较真了；两者都在说"不停地说"，从这个广义角度即有近义关系。

## 时间顺序

* 题干链条：群众来访 → 窗口接待（接访）→ 群众反映问题 → 调查督办。

* 选项顺序排查

    * 地面实验、点火飞行、燃料加注——"燃料加注"与"点火飞行"顺序反了，必然先加注再点火；火箭在空中不可能临时加注，抬不赢。

    * 支付本币兑换外币、确认汇率——确认汇率不能放在最后，得先看汇率确认好再去兑换。

    * 建造堤坝、潮汐发电、送电入户——顺序成立。

    * 重启谈判、临时休战——顺序反了，先临时休战再重启谈判。

* 潮汐发电常识：潮汐即涨潮落潮，涨落潮之间有水头差，产生水的势能推动涡轮机；原理上需要建堤坝把涨潮时的水蓄满，利用压差和势能。

* > **提示**：作为公务员要连潮汐发电、国家大型水电站名称这类基本常识都知道，不应该在这里卡住。

## 方式目的与工具

* 题干拆解

    * 收集罪证是目的，提取指纹是方式，透明胶是工具。

    * 造句：提取指纹是为了搜集罪证。

    * 透明胶是提取指纹的工具——警匪片或影视剧中常见拿透明胶在墙上、把手等位置粘取指纹，不算冷门。

* 选项排查

    * 叶子发黄是因为温度不当，是因果不是"为了"；后半段敲碎车窗为了逃生自救、安全锤是工具没问题，但前两句不构成方式目的。

    * 收集罪证、提取指纹、透明胶——目的、方式、工具三段完全对应。

    * 设置防护是为了道路施工成立，但混凝土不是设置防护的工具。道路施工设置防护用的是锥桶、雪糕桶或大的塑料立方体，起隔离和引导作用；混凝土是水泥、砂石搅拌物，摊在路上一天两天就干，凝固后属建筑材料。

    * 冷风入侵导致肩周疼痛，是因果不是"为了"。

* > **结论**：判断"方式—目的—工具"三段式，最容易翻车的是第三段——选项给的东西在生活常识上根本干不了这个活，看到"设置防护+混凝土"这种组合要立刻警觉。

## 代入法

* 步骤：先给题干里的两对词各定一个关系性质，再去看哪个选项的两边关系完全一致；主宾方向反了同样是错。

* 题干两对词

    * 行政机关与行政文书：行政机关发布行政文书，主谓宾结构，主在前、宾在后。

    * 编程人员与汇编语言：编程人员编写汇编语言，同为主宾；汇编语言可理解为 C++ 这一类计算机语言。

* 选项关系比对

    * 行政管理与行政文书："利用行政文书进行行政管理"，工具在前；编程语言与汇编语言："利用汇编语言进行传递指令"——两项同为工具在前、宾在后，与题干主宾方向相反。

    * 行政文书与商务文书面是并列，符号语言与汇编语言是全同——前后关系性质不一致。

    * 行政文书与监管函是种属（函是行政文书的一种），汇编语言与计算机语言是种属——两边关系一致。

* 关系性质清单：主宾、并列、全同、种属、交叉。主宾还分"主→宾"和"宾→主"两个方向。

## 题量与难度变化

* **2025 年类比**

    * 类比题从十道改为五道，难度较前两年有所下降。

    * 该部分以种属关系收尾，例如"汇编语言是计算机语言的一种"这种表述，选第四项。

## 就题论题：加强削弱的非标准化走向

* **就题论题**

    * > **定义**：一个题讨论一个题、一个选项讨论一个选项，不再指望"某类选项必然是加强、必然是搭桥、必然是必要条件"这种固定对应。

    * 公务员考试的逻辑加强削弱越来越非标准化，考研逻辑相对更标准化一些。

    * 做题必须挂靠真实领域：生物类挂生物学，文学类、考古类挂真实论文的写法。

    * > **结论**：没有那么多必然性的方式，技巧方法不那么明显，越来越不明显——这是逻辑当前的出题方向。

    * > **提示**：不要过度追求"标准化"，不要赌"某一类的一定比另一类的强"，尤其公务员逻辑里强弱已经没那么清晰。

* **论文语感训练**

    * 多去知网检索论文，尤其是自己的毕业论文、研究生论文，研究作者怎么补充论据、怎么把桥搭上。

    * 研究生开组会时给别人的论文挑问题、抬杠、找漏洞，这类训练对加强削弱题更有帮助。

    * > **结论**：加强削弱没有一劳永逸的技巧，只能多做题、慢慢找规律。

## 否定式设问：除了哪项以外均能……

* **"除……均能"问法**

    * > **定义**：题干问"除了哪项以外均能质疑/均能支持"时，答案就是那个**不能**质疑、不能支持的那一项。

    * > **结论**：其他选项质疑得再弱也轮不到它们，因为总不能去选一个加强项当答案。

    * 拔河实验题里"团队一起工作个人的贡献不被凸显、容易失去积极性"，是在解释"人数增加、平均出力减少"，属于**加强项**，在"均能质疑"的问法下恰恰是那个不能质疑的，必选。

    * > **易错点**⚠️：很多同学只是没看到"除了哪一项（外）均能质疑"这个括号，读题时先定位问法再找加强项。

* **可用的两条质疑方向**

    * 极端化反驳：人数过少时效率同样会下降，所以"减少人数能提升业绩"站不住。

    * 替代方案反驳：增强个体对团队的归属感、责任感也能更好地提高团队业绩，那么"减少人数"就不是"最佳"途径。

* **边际递减与线性反比**

    * > **定义**：人越多时平均每个被试者的出力下降，是边际收益递减，不等于团队总业绩随人数线性下降。

    * > **易错点**⚠️：把"人越多、单人出力越少"读成"人越少、业绩越高"，是把边际递减读成线性反比，实验只支持前者，结论跨到了后者。

    * 拔河与公司团队合作不是一回事，团队合作和管理方式比拔河复杂得多，不能拿一个拔河实验外推公司业绩。

## 竞争力论证中的单一变量

* **价格与竞争力**

    * > **结论**：题干给的链路是"成本涨 → 价格高 → 竞争力下降"，支持项必须在"价格"这一环上做文章。

    * > **定义**：竞争力一定是跟其他国家比出来的。

    * 标准支持方向是"我们涨、别人没涨"：其他国家科技创新、成本没有上涨，仍靠低价竞争；我方成本涨 10%，价格大概率跟着涨 10%，竞争力自然被削弱。

    * 反向校验：如果所有国家都同步上涨 10%，彼此的相对价格没变，竞争力就不受影响。

* **三类无关项**

    * 追溯已知前提的成因：题干已把"原材料涨价"当既定事实，选项再去解释它为什么涨，与"涨价是否削弱竞争力"无关。

    * 偷换变量：谈技术、质量等并未发生变化的因素与竞争力的关系；一个产品卖得好是质量、技术、成本等综合作用，今年只有价格一个变量在动，控制单一变量就只讨论原材料涨价。

    * 语义不明确：堆一堆与结论没有必然逻辑关系的话，例如电子消费缩减但电子产品并未降价，说明不了价格对竞争力的影响。

    * > **提示**：最容易犹豫的是那个确实提到"竞争力"的选项——它说技术质量优势使 H 国过去极具竞争力、近年在减弱，但技术和质量一直就是这样、并未提升，且"竞争优势逐渐减弱"讲的是技术质量优势不再凸显，与"价格和竞争力"无关。

## 考古类论证的间接证据

* **考古证据的间接性**

    * > **定义**：医药类可以做三期临床实验、设对照组、做显著性分析，结论接近确定性，有就是有。

    * > **定义**：考古类很难找到非常确定的证据，多靠各种细微线索或间接线索来证明。

    * 考古论文的措辞通常给的是"很可能属于……"而不是"一定"，它本身就在承认不确定性。

* **类比加强在考古里的力度**

    * > **定义**：类比加强指"化石里有些东西跟某个真核生物很像，那个东西属于真核，所以它属于真核"。

    * > **结论**：在一般逻辑题里类比加强很弱很弱（如同"马云是老师又有钱，某人也是老师也有钱"的牵强类比），但在考古里就算比较有力的证据。

    * 这类题要仔细看论据、看它找的是什么样的证据，去理解、去感受这种证据链。

* **间接证据的具体形态**

    * 特异性结构：化石里发现类似孢子的圆形结构，而该结构只在真核里出现过。

    * 形态高度接近：化石中某些结构的形态与某种真核生物非常接近。

    * 直径区间对不齐也能支持：原核、真核直径区间有重合；两者处在同一数量级，而微观生物里很多东西能落在同一数量级已属不易；题干说的是直径"一般"大多数在这个区间，不是一确定一定在这个区间。

    * 主体描述留有余地：题干只说"有些细胞"，没说完全是单细胞的；真核语境下"单细胞"一般指单核细胞，丝状体可能由多个细胞组成且已呈现一定复杂性。

    * 偷换主体的选项——整段论据只谈真核，选项却转去谈已知原核——就是那个不支持的。

    * > **提示**：选项的表述有时只截取了原论文的一小部分，看上去有瑕疵，但答案不会有争议，不必在单个瑕疵上纠缠。

## 搭桥缺口的识别

* **缺搭桥**

    * > **定义**：论点里的 A 和理由里的 B 根本不是一回事，且中间没有任何一环能自动连上。

    * 典型形态：论点说"各种癌症增加可能与空气中的 PM2.5 有关"，理由只说"PM2.5 会导致脏器的炎症和应激反应"，而炎症、应激反应与癌症之间的关系没有交代。

    * 桥要落在缺的那一环上：补"炎症反应是明确的致癌危险因素"。

    * > **结论**：识别出缺桥就直接锁定搭桥项，其余选项完全不用看，绝对浪费时间。

## 结合常识判断削弱的强弱

* **果实养分的来源**

    * 果实一般不进行光合作用；光合作用要有叶绿体，而叶绿体一般在叶子上，叶子大、光线强，在叶子处生产能量再输送给果实。

    * > **结论**：果实不是自己挣养分的，套袋动不了"叶子生产 → 输送 → 果实长大"这条线，所以"套袋过早使果实失去营养竞争力"这个理由离谱在常识。

* **疏除冗余幼果的实质**

    * 蟠桃授完粉、刚长出小果时，一棵树会结大量果实，而树就那么大、叶子就那么多、能量有限，果太多则每个果都长不大、卖不上价。

    * 果农在幼果很小时就砍掉一部分，等于提前把"分蛋糕"的人数砍掉：原来三个果各分三分之一都长不大，砍到只剩一个则独占全部、长得足。

    * 即便留下的不一定是优质大果，剩下的果吸收到的能量变多也照样会变大。

* **削弱项要比"谁更符合现实"**

    * > **结论**：两个选项都有削弱作用时，不要停在"能不能削弱"，要比谁更符合现实——直接找到原因根子且符合生物学常识的更强。

    * "桃树长得太快、萌芽肥和花后肥都没有追施、导致后期营养供应不足"直接落到营养不足的根子上，并彻底否定"过早套袋导致其失去营养竞争力"的理由。

    * "没分出大小果就完成了疏除冗余幼果"虽有一定削弱但牵强，与实际的生物过程不太一样。

    * 无关项：只说套袋期间果实大小基本一致、无病虫害（讲的是跟病虫害的关系，与套袋过早是否成立无关）；讲甜度而非大小；以及纸袋遮光影响光合能力后又拐到甜度上。

## 一拖五的季度容量模型

* **底层条件**

    * 某科研机构全年举办八次学术会议，每季度最多举办三次，各次会议时间不重叠。

    * 四条钉死的条件：丁和辛安排在第二季度；甲和戊在同一个季度；丁在乙之后、丙之前；丙在甲之前、己之后。

    * 顺序链为 乙 → 丁 → 丙 → 甲 → 己，只约束相对先后，不锁定具体季度。

    * > **结论**：把季度当容量格子，一格塞满三场就再也挤不进人，后面几问全在算这个容量。

    * 戊跟着甲走属于捆绑绑定：要么同季度一起排、要么两个季度都不排。

* **同季度内部也有先后**

    * > **易错点**⚠️：同一个季度里开三场，这三场之间同样有先后，所以"丁在乙之前"并不意味着乙一定在第一季度，乙完全可以在第二季度排在丁前面。

    * 读图方式：横着看是会议先后，竖着看是季度的容量上限；丙挤不进二季度时会落到三季度，与甲、戊凑满一格。

* **五问的加码与答案**

| 题 | 新增前提 | 问什么 | 答案 |
| :--- | :--- | :--- | :---: |
| 106 | 第二季度只安排两次会议 | 哪次会议一定在第一季度 | 乙（第二项） |
| 107 | 无（回到底层条件） | 哪两次会议可以安排在第一季度 | 第四项 |
| 108 | 每季度至少安排一次，且最后一个季度仅安排一次 | 哪两个会议一定在第三季度 | 甲、戊 |
| 109 | 丙、戊安排在第四季度 | 哪两次会议可以安排在第三季度 | 第四项 |
| 110 | 甲安排在第三季度，且第四季度不安排会议 | 庚不可能和哪次会议安排在同一季度 | 丙（第二项） |

* **106 与 107 的假设边界**

    * 106 设了"第二季度只安排两次会议"：丁、辛已经占了两次，二季度不能再排别人；乙在丁之前又只能排第一或第二季度，故乙只能在第一季度。

    * > **易错点**⚠️：带"如果"开头的题得出的结论只在那个前提下成立，它不属于底层条件，带不进下一问——这个坑很多人一整组题都栽在里面。

    * 107 只能回到底层条件：含丁的选项直接排除（丁、辛确定在二季度）；丙有可能在二季度，但那样二季度被丁、辛、丙占满，甲就跑不进来，而丙在甲之前，所以甲绝不可能在第一季度。

* **108 的捆绑倒推**

    * 丙在丁之后，最多只能到第二季度；若丙占了二季度，丁、辛、丙凑满三场，甲同样进不去。

    * 甲和戊捆绑、要都在要不在都不在；最后一个季度仅一次会议，排除了甲、戊同在第四季度。

    * 两头一夹，甲到不了二季度也到不了四季度，甲、戊一定在第三季度；丙也可以在第三季度排在甲之前，甲与戊之间的先后则不确定。

* **109 的排除顺序**

    * 戊在第四季度则捆绑的甲也在第四季度，含甲、戊的选项直接排除。

    * 乙在丁之前，而丁在二季度，所以乙只能在第一季度或第二季度，到不了第三季度，含乙的选项也排除。

* **110 的支点是丙**

    * 情况一：丙在第二季度，二季度被丁、辛、丙占满，乙在丁之前又挤不进二季度，只能在第一季度，己、庚随便放，庚无论放一季度还是三季度都不与丙同格。

    * 情况二：把丙拿掉，它挤到第三季度，与甲、戊又组成一个三人组，每季度最多三场，同样没有人能插进去。

    * > **结论**：从前往后排，丙一旦落位那一格就满了，庚再也挤不进去，所以庚不可能与丙安排在同一个季度。

* **训练强度**

    * 前两三问相对简单，第四五问略难，五问做对三四问很正常、五个全对也不算特别难。

    * 这类题没有什么一次性拿下的好办法，也没有特别好的技巧，全靠大量排列组合练习，一个题慢慢找规律，做得多了自然就快了。
