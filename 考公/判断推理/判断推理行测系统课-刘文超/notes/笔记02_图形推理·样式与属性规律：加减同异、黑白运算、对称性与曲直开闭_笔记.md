# 图形推理·样式与属性规律：加减同异、黑白运算、对称性与曲直开闭

## 样式规律的识别入口

* **元素组成相同**

    * 是位置规律的识别特征
    * 组成相同的时候，优先考虑位置规律

* **元素组成相似**

    * > **定义**：有些线条在重复地出现，在整个题目过程中来来回回地出现

    * 是样式规律最重要的识别特征
    * 与"元素组成相同"不同，入口落在"相似"而不是"相同"上
    * 判断入口就这一句话：元素组成相同优先考虑位置规律，元素组成相似考虑样式规律

    ```text
    九宫格第一行：这线和这线只出现两次；那两线、这线也只出现两次
    九宫格第二行：Z 字形和 Z 字都出现两次；这条斜杠也出现两次
    线条反复出现  ->  判定为「元素组成相似」  ->  样式规律
    ```

* **易错点**：⚠️ 很多人做题时根本停不下来去数"这条线出现几次"，直接上手排除选项，结果全错。

## 加减同异的四种运算

### 相加、相减与求同

* **相加**：两个图形做加法运算得到第三个图形——圆加上十字叉，等于圆中间加一个十字叉
* **相减**：第三个图形减去第二个图形等于第一个图形——圆加十字叉减去十字叉，就等于圆
* **求同**：前面第一个图和第二个图都有的那条线保留下来，其余部分全部消掉
* 三者考得并不多

### 求异：记成消消乐就够了

* **求异**

    * > **定义**：图1 与图2 重合的线消掉，不重合的线全部留下

    * 考得最多，是这一类里的核心考点
    * 不必去理会"求异"这个名字本身，只要记住"消消乐"：两条相同的线叠在一起就消掉，没重合的留下
    * 元素组成相似的题目，绝大多数落到求异上

    ```text
    【相加】图1 + 图2 -> 图3     两图不重合的线全部留下
    【相减】图3 - 图2 -> 图1     把图2 的部分去掉，剩下图1
    【求同】图1 与图2 都有的那条线留下，其余全部消掉
    【求异】图1 与图2 重合的线消掉，不重合的线全部留下
            ^ 考得最多；求同、相加、相减考得并不多
    ```

* **考频判断**：加减同异在国考几乎每年一道，各地省考也算重要考点

## 九宫格的观察方向

* **横着看**

    * 第一个图形加第二个图形得到第三个图形，是相加运算
    * 下一行同样验证成立：下面这个加这个变成它
    * 要求的那一幅与前两个相比，要么相同，要么只多出一部分，加完之后仍应是它
    * 先按此排除头部就不对的选项，再用要求的那一幅去核对剩下的选项

* **横着没规律就竖着看**

    * 横着看三个图形都感到线条在重复出现，却得不出第四个图形；第二行横着看也没有规律
    * 九宫格横着看没有规律时，改为竖着看：下面两个图形相加，得到第一个图形
    * 每一行都遵循同一条：下两格相加，得到最上面那一格

    ```text
    横着看没规律  ->  换成竖着看

    ┌────────┐
    │ 最上格 │ <- 下面两格相加 = 最上格
    ├────────┤
    │  中格  │
    ├────────┤
    │  下格  │
    └────────┘

    每一行都是同一条：下两格相加，得到最上面那一格
    ```

* **结论**：竖和横不一定要出现在这个图形中——问"想变成上一个缺了什么"，若答案是去掉了一个竖、一个横，选项里缺这两笔才是对的

## 位置规律叠加样式规律

### 旋转加消消乐

* **复合关系**

    * > **定义**：把位置规律揉进样式规律，先旋转再叠加，最后做消消乐

    * 现在最新的一种命题方式，公务员考试难度加大，只给最简单的东西显得太简单，于是把很多东西揉在一起增加难度
    * 见得多了就觉得不难，本质还是消消乐

    ```text
    样式 + 位置的复合做法

    ① 竖小长方形   ──旋转 90 度──>  ①'
    ② 直角三角形
    ①' 与 ② 叠在一起
      重合的线   -> 消掉
      不重合的线 -> 留下
    结果 = ③
    ```

* **旋转方向的确定**

    * 不能凭空断定是顺时针还是逆时针 90 度，要通过同组的第二幅图来看
    * 第二幅图能确定第一幅图该怎么转：转成那个样子再与它叠加，重合处消失，由此定出是顺时针旋转 90 度
    * 后续几组就按同一规则处理：先旋转 90 度，再与第二幅叠加，该重合的线消掉

* **选项排除顺序**

    * 形状、线的位置就不对的选项直接排除，不用看细节
    * 剩下的逐条检查"本该消掉的线是否还在"，据此排除
    * 答案 D

### 方向不必强分

* **消完再比旋转**

    * 先在两幅图之间做加减同异（消消乐），把相同的部分消掉
    * 消剩下的图形与第三幅图比对，发现是旋转关系
    * 顺时针 90 度与逆时针 90 度是否都说得通一时分不出来时，不要硬猜

* **顺逆都成立的情况**

    * 出现"顺时针、逆时针都不对"的说法，是因为在消完的图形上顺时针和逆时针都得到了它，此时两种都算对
    * 换用选项来比对：与第三幅图完全相同、没经过旋转的那个选项一定错
    * 把选项里顺时针 90 度、逆时针 90 度各对应出来，通常只有一项是旋转后的图形
    * 答案 D

### 反推缺格

* **关系式**：第一幅 + 第二幅（旋转 90 度）= 第三幅；缺的是第二幅，用第一幅和第三幅反推它

    * > **规则**：先按加减同异把缺的图形求出来，再整体旋转 90 度转回去

    * 逐个位置对照，规则如下

| 位置 | 第一幅 | 第三幅 | 第二幅应有的内容 |
| :--- | :--- | :--- | :--- |
| 第 1 个 | 没有 | 有 | 有一个白圈（两两消掉） |
| 第 2 个 | 有白圈 | 没有 | 有一个白圈（两两消掉） |
| 第 3 个 | 黑圈 | 黑圈 | 空白（没被消，说明只有一幅有） |
| 第 4 个（左下） | 没有 | 黑 | 有一个黑 |
| 第 5 个 | 黑圈 | 黑圈 | 空白 |

* **收尾**：把求出来的图形旋转 90 度回去，与选项对照，答案 B
* 结论：这类题略有难度但不难，往上加就行——通过加减运算把它求回来，"有的、没有的"求回来即可
* 觉得耗时的原因是碰到位置与样式融在一起的题；发现规律、知道考什么，题就已经解决一半

## 用单条线快速排除选项

* **挑代表性线条入手**

    * 规律确定后，不必整体去看，可以挑一两条很有代表性的线
    * 例：挑最后一行的这条线和这条线，它俩一样应该被消掉，选项里有它的就不行
    * 一条线能排掉一些选项；排不掉，再挑第二条线继续排
    * 不需要把每一个细节都抠得很细

* **整体消消乐的排除**

    * 两处重合都能消掉，说明这一行没有该出现却出现的线
    * 含"该消未消"线条的选项直接排除
    * 两个图形不同的情况不可能全消没，据此排除最后一项

## 图推的备考取向

* **知识加刷题**：首先把基础知识掌握，其次多刷真题，把各类情况——出题人可能采用的方式——都见识过、想过、做过、接触过，考场上才能做对得更多
* **难度在上升**：出题人觉得简单平铺直叙的题彰显不出能力，而学员素质越来越高，所以会额外地加一点难度
* **得分预期**：图推是判断推理里最难一点的，可能有难题；十个里面争取对上八个即可，不要去纠结那一两个特别难的、或出题人奇思妙想才想起来的题
* **学科信心**：判断推理是三个模块中最简单的一个，最容易达到 80% 以上的正确率
* **靠见量取胜**：事先无法知道出题人会怎么做，只有见得越多，考场上做得出来的才越多；靠大量练习题巩固这类题型来找感觉

## 消消乐（求异）

* **消消乐（求异）**

    * > **定义**：同一个位置、同样的一组图里，出现两条相同的线就互相约掉，没被约掉的线原样保留。整幅图是「加完再减」，不是简单地看数量增减。

    * 判定方式：两条线是否完全相同，相同即约掉，不同即保留。

    * 占比：这类题考察的东西非常多，只要考了消消乐，90% 都在考察「两个相同的线就约掉」这一条规律。历年真题里 18、19 年各省份的题目明显在重复出现，同一条规律被反复翻出来考。

    * 操作要点：**别整体看，去找其中的一条线来看**。抓一条线，核对它在下一幅里还在不在，一目了然；整体去比一堆线，人会看花眼。

    * 练习六的走法：第一幅里这两条线到第二幅没了吧，那就对了，它俩约掉了；第二幅横着看，这条线和这条斜线又约掉一对；第三幅同理再约掉一对。

    * 练习六的排除：第三幅该约掉的一对线，C 和 D 留着，排除；A 多出一条本该被约掉的线，排除；答案 B。

    * 练习七（2018 国考）：三行九宫格，第一行第一列前两幅图中的两条线相同，到第三幅被约掉，其他线全部保留；第二行同理；第三行那两条线不该再出现，A、B、D 都留着它，答案 C。

    * > **提示**：国考近几年几乎年年都出，同一条规律在 15 年、18 年、19 年都做过，这题只要出现就必须拿分——这是在给大家送分，你不拿别人就拿了。

    * 加减同异收官的体量：六个例题加上七个练习，共 13 题，已经挺多。规律知道了不等于做得快，只有练得越多，考场上才越快想到它。

    * ⚠️ **易错点**：不要整体比一堆线。锁定其中一条线去核对，是这类题最快的突破口。

## 元素组成相同与相似

* **元素组成相同**

    * > **定义**：每一幅图的元素数量完全一致。

    * 识别：这一行 1、2、3、4 都是四个黑的，第二幅也是四个黑的，第三幅还是四个黑的，黑块数量每幅都一样，这才叫元素组成相同。

    * 优先考虑位置（平移）：四个黑块数量不变，就去看这些小黑块在整个区域里怎么平移，是顺时针走、横着走还是竖着走。

    * 已给出的例子：那个题里四个块整体逆时针走了一个格，绕着外面这个圈走。

* **元素组成相似**

    * > **定义**：元素种类是同一批，但数量对不上。

    * 识别：这一行四个黑块，下一幅五个黑块，再下一幅三个黑块。

    * 优先考虑样式（黑白运算）。

* **三者分岔表**

    | 元素的组成 | 特征 | 优先考虑 |
    | :--- | :--- | :--- |
    | 相同 | 每幅图元素数量完全一致 | 位置（平移） |
    | 相似 | 元素种类一致、数量不同 | 样式（黑白运算） |
    | 既不相同也不相似 | 没有任何共同元素可循 | 属性（对称、曲直、开闭） |

* **岔路口的整体**

    * 元素组成相同，优先看位置；元素组成相似，优先看样式规律；元素既不相同也不相似，优先看属性规律。

    * 样式规律里分成加减同异和黑白运算两块，加减同异里最核心的就是求异（消消乐），占到 90% 以上。

    * ⚠️ **易错点**：元素组成「相同」和「相似」一字之差，选的方向完全不同，不能都叫「相同」。

## 黑白运算

* **黑白运算**

    * > **定义**：出题人在这道题里额外附加了一种运算规则，由他给黑和白定义出一种加减关系。

    * 判定方式：规定「黑」和「白」相加减得到什么（黑+白=白、白+黑=白，或者黑+黑=白、白+白=黑，等等）。

    * 成立范围：这个运算在整幅图、整道题里都严格成立。

    * 记忆句：**黑块数量不同，优先考虑黑白运算。**

    * 典型例证：一个黑加一个白等于白；白加黑等于白；白、黑、白、黑四个加起来等于一个白。

* **0 号位置顺时针编号**

    * 顺序随自己定，习惯是从 0 点开始顺时针走，先看第一个区域，这样能更准确一点。

    ```text
       ┌─────────────┬─────────────┐
       │      0      │      1      │     从 0 号位置起，顺时针编号
       ├─────────────┼─────────────┤     0 → 1 → 2 → 3
       │      3      │      2      │
       └─────────────┴─────────────┘
    ```

    * 先把这个位置现在需要的算式抓住，再回原题中去找这一对。

### 例一：轮廓相同只剩颜色

* **识别特征**

    * 几个图形都被分割成相同数量的区域，两个区域、三个区域、四个区域，每一幅的分割都一样。

    * 唯一的区别就是分割区域里面的黑白颜色不同。

* **结论**

    * > **结论**：分割区域都一样、只有黑白颜色在变的这类题，优先考虑黑白运算，去考虑黑白运算一定没有错，大胆去用。

* **推断过程**

    * 按 0 号位置顺时针走，0 号位置这个区域是白，上面那个也是白，问题是「白加白等于什么」。

    * 回原题中去找，原题里确实有白加白等于白，所以这个区域应该是白。

    * A 没问题，B 错了，D 也没问题。剩 A 和 D 两个，区别正好就在这个区域里。

    * 这个区域是黑、那个是白，问题是「黑加白等于什么」，回原题中去找，黑加白等于黑，这个位置就该是黑色，D 排除，答案 A。

### 例二：一个位置秒杀

* **推断过程**

    * 第一行黑块数量是 3、3、4，不一样，元素组成相似，优先黑白运算。

    * 第一个位置是白加白等于什么，回头找，白加白等于白，所以第一个位置就该是白。

    * 对不上，直接秒杀第二个选项。

* **难度评价**

    * 黑白运算的题相对来说就是比较简单。

### 三道练习的算式

* **练习一（黑块 2、3、5）**

    * 元素组成相似，优先黑白运算。

    * 0 号位置：白加白，回原题找，白加白等于**黑**，这个位置必须是黑，A、D 对不上，都排除。

    * 剩 B、C，区别在另一个区域：那个区域是黑加黑，回原题找，黑加黑等于黑，这个区域还是黑，B 排除。答案是第三个。

* **练习二（第一行 4、5、5）**

    * 元素组成相似，优先黑白运算。

    * 0 号位置：黑加黑等于**白**，这个位置应该是白，B、D 都错，排除。

    * A 和 C 的区别正是在这个位置：白加黑等于什么，回头找，白加黑等于**黑**，这个位置应该是黑。答案是 A。

* **练习三（5、4、5）**

    * 黑块数量不同，优先黑白运算。

    * 第一个位置明显这两个都是白，白加白，找一找白加白等于白，所以这两个位置应该是白，A、B 都排除。

    * 剩 C、D，区别在那两个位置上：黑加黑等于白，这两个位置应该是白。答案是 C。

## 算式的取用纪律

* **用到哪条算式就回原题找哪条**

    * 错误做法：一上手就把四种运算全列出来（白加白=白、黑加白=黑、白加黑=黑、黑加黑=白），「四个运算我找到了」。

    * ⚠️ **易错点**：不要做这种先把它们都列出来、都找出来的事情，计算量特别大，浪费的时间太多；公务员考试对时间的要求非常严格。

    * 正确做法：先找到我需要什么，我再回去找。从 0 号位置开始看，看到两个白，现在需要知道的就是「白加白等于谁」，那就回到原题中去找，仅此而已。

    * 一定要节省时间，非常重要。

* **每题定义的算式都不一样**

    * 上一题的结论不能带到下一题。

    * 这七道题里黑白运算的算式每题都不一样：白+白在例一和例三里等于白，在练习一里却等于黑。

    * 永远不要把上一题的结论带进下一题，用到哪条算式，就回原题里去找那一条。

* **要不要验证**

    * 遇到这类题几乎根本不用验证，那一定是考这个规律。

    * 如果不放心，或者还有时间，那就再找一个跟他一样的对一对，看看是不是这个结果。

    * 做多之后就会发现一看着就知道它要考什么，根本不需要验证。

* **看得多不等于做得快**

    * 规律的讲解到此为止，先把基础知识打牢，不用着急。

    * 等所有知识都过完一轮，再回去刷真题——看真题拿到手该怎么处理，十个题到底能不能对八九个。

## 九宫格的看法

* **看图顺序**

    * 横着看是优先，这类题占到 90% 以上。

    * 万一横着看做不出答案，再回去想竖着看。

    * 再不行就考虑米字型；米字型还不行，再考虑 S 型。

    * 到现在为止竖着看的题几乎没出现过，但做多了自己就吃到了。

## 属性规律

* **属性规律**

    * > **定义**：元素的组成既不相同、也不相似，图形之间找不到任何共同元素可循时，优先去看图形本身的属性。

    * 属性里最重要的、也是大家最熟悉的有三样，先记住这六个字：**对称、曲直、开闭**。

    * 慢慢做着、慢慢学着，学着学着就记住了，最后都能背下来。

* **岔路口的完整顺序**

    * 元素组成相同，优先看位置。

    * 元素组成相似，优先看样式规律。

    * 元素既不相同也不相似，优先看属性规律。

### 轴对称：方向与数量

* **轴对称**

    * > **定义**：图形有一条对称轴。

    * 出题方向一：**对称轴的方向**。第一个图的对称轴竖着，第二个图的对称轴旋转了 45 度，那么下一个的对称轴完全可以再旋转 45 度变成平行的，方向完全可以在上面做文章。

    * 出题方向二：**对称轴的数量**。五角星有五条对称轴，一条、两条、三条……数量一样可以拿来命题。

    * > **提示**：这两条是轴对称的出题方向——方向和数量；大量练到这类题，就能看出出题人是怎么摆布它们的。

* **和中心对称的区别**

    * 平行四边形不能说它有轴，它没有轴对称，但绕着中间点旋转 180 度以后一模一样，是中心对称图形。

### 中心对称

* **中心对称（central symmetry）**

    * > **定义**：在一个平面里，把一个图形绕着一个点旋转 180 度，图形重合了，这个图形就叫中心对称图形，这个点叫对称中心。

    * 等价说法：图形里任何一个点，穿过这个中心，都能找到它的对称点。

    * 平行四边形：在它的最中间点一个点，绕着这个点旋转 180 度以后一模一样，又回来了，旋转 180 度之后还是它。

    * 验法一：随便在图形里点一个点，穿过这个中心这条线，都能找到它的对称点。

    * 验法二：字母 N 中间点上一个点，绕着它旋转 180 度就又回来了。

    * 字母 Z、S 都没有轴，但都能找到一个中心，图中任何一个点穿过这条中心都能找到它的对称点。

* **易混点**

    * 中间那几个字母一个轴都不能说（没有轴对称），但仍然是中心对称图形。

    * ⚠️ **易错点**：判断中心对称不要一味去找轴，找不到轴不等于不对称。

## 题目速查

题干按课堂口述还原，图形以原题为准；每题的解析依据都能在上文正文里找到对应的那一步。

| 题目 | 课堂口述还原 | 答案 | 关键一步 |
| :--- | :--- | :--- | :--- |
| 练习六 | 由若干线条构成，前两幅图之间都是「两条相同的线互相约掉、其余保留」，问号处该选哪一项 | B | 抓单条线核对：第三幅该约掉的一对线，C、D 留着；A 多一条本不该出现的线 |
| 练习七（2018 国考） | 三行九宫格，每行都是前两幅图中的相同线到第三幅被约掉、其余线保留；第三行问号处 | C | 第三行那两条该约掉的线不该出现，A、B、D 都留着它 |
| 例一 | 轮廓相同、都分割成若干区域，区域内黑白颜色不同 | A | 0 号位置 白+白=白，排除 B、C；黑+白=黑，排除 D |
| 例二 | 黑块数量为 3、3、4 的一行图形 | 第二个选项 | 0 号位置 白+白=白，该位置就该是白，一个位置秒杀 |
| 练习一 | 黑块数量为 2、3、5 的一行图形 | 第三个选项 | 0 号位置 白+白=**黑** 排除 A、D；黑+黑=黑 排除 B |
| 练习二 | 黑块数量为 4、5、5 的一行图形 | A | 0 号位置 黑加黑=白 排除 B、D；白+黑=黑 落在 A、C 的区别处 |
| 练习三 | 黑块数量为 5、4、5 的一行图形 | C | 白+白=白 排除 A、B；黑+黑=白 落在 C、D 的区别处 |

* **这七道题的共同结论**

    * 黑白运算的算式每题都不一样：白+白在例一和例三里等于白，在练习一里却等于黑。

    * 永远不要把上一题的结论带进下一题，用到哪条算式，就回原题里去找那一条。

## 对称的两类及其判定

### 两类对称的判定方式

   * **轴对称（axial symmetry）**

       * > **定义**：沿一条直线对折，图形左右两半互为镜像，这条直线就是对称轴。

       * 判定方式是找得到轴：随手画一条轴，折得上去、与自身完全重合，才算轴对称。

       * 一个图形可以有多条对称轴，五角星就有五条。

   * **中心对称（central symmetry）**

       * > **定义**：在图形的正中间点一个点，绕着这个点旋转 180 度，转完了还是它自己。

   * **找中心的两种手法**

       * 手法一：把整个图形旋转 180 度，看重合不重合。

       * 手法二：随手在图上挑一个点，设想它穿过中心之后落在哪儿，图内找得到对称点即成立。

       * 任意一个点都能在图内找到关于中心的对称点，整个图形便确定为中心对称。

   * **两种手法的取舍**

       * 这两条路都行，属于初高中就学过的老知识，看个人习惯。

       * 旋转 180 度需要把整个图形转一遍，中心点并不直观、也不好算；点一个点就顺手多了——找到中心点，其余点的对称点都能顺着它推出来。

```text
轴对称：沿一条直线对折，左右两半互为镜像
      ─────────────      ← 对称轴
      ◣        ◢
      ◠        ◠         折得上去，才是轴对称

中心对称：绕一个点旋转 180°，图形与自身重合
            P'
            ●
       P' ● O ● P        P 与 P' 关于中心 O 成对称
            ●
            P
```

### 兼有两重对称性的图形

   * 既有对称轴、又中心对称的图形要单独盯住，常见形态是同时拥有四条对称轴。

   * 判定表现：在中心点一点、绕中心旋转 180 度仍是自身；换任何一个点穿过中心，都能找到它的对称点。

   * > **注意**：这类图形一定要在题干上做出标记，否则后面分组时容易和「只有中心」的那一组混在一起，是最容易漏掉的一类。

   * 题干交替出现两种图形时，区分就出来了：只有中心的归一组，中心加轴的归另一组，答案取前者。

### 平行四边形的对称性

   * **平行四边形（parallelogram）**

       * 绕两条对角线的交点旋转 180 度能与自身重合，所以是中心对称。

       * 找不到任何一条对称轴，怎么折都折不出镜像，所以不是轴对称。

```text
  ______
 /     /           中心对称 ✔  绕两条对角线的交点转 180° 重合
/_____/            轴对称   ✘  怎么折都折不出镜像
```

### 五角星

   * **五角星（pentagram）**

       * > **定义**：轴对称图形，有五条对称轴。

       * 旋转 180 度之后底下这个角转到上面来，五个角的方向全反，重合不了。

       * 连一个对称中心都点不出来：随手挑一个点，穿过中心去找它的对称点，对称点落在图外。

       * > **易错点**：⚠️ 五角星是「有轴、无中心」。做题做着做着经常就忘了这一条，务必在题干旁边写上这句话。

## 图形外观识别

### 轴对称常见外形

   * 带方向的箭头。

   * 躺着的、横着的三角形。

   * 单字母本身的对称形态，例如 A、H、T。

```text
轴对称常见外形
  →  →  →      带方向的箭头
  △  ▽  △      带方向的三角形
  A  H  T      单字母本身的对称
```

### 中心对称常见外形

   * **字母类**

       * S、Z、N——这几个字母只要出现，这题一定考中心对称，非常典型。

       * 太极图仔细看，本身就是一个 S。

       * who 这几个字母拆开看，是一个 Z。

   * **几何类**

       * 平行四边形，以及平行四边形的各种变形；Z 就是平行四边形的变形。

       * 百分号：中间那一笔不是轴——如果它是轴，画出来应该是一个圆。

   * **成对同形旋转型**

       * 两个一模一样的图形，转 180 度之后又对上了，只是方向变了，像是两个一样的东西在转来转去。

```text
典型中心对称外形
  S   Z   N   ♢(平行四边形变形)   %(百分号)
```

### 常见图形的对称性对照

   * 拿到题不必真去旋转或对折，先判断它属于哪一类已知形态。

   * 平行四边形、Z、百分号同属「有中心、无轴」；五角星属「有轴、无中心」。

   * 箭头、躺倒的三角形、A / H / T 属轴对称外形；S、Z、N、太极图、who 属中心对称外形。

   * 判断实在拿不准时，可以把脑袋转过去歪着看，百分号歪着一看就能看出来。

| 图形 | 轴对称 | 中心对称 |
| :--- | :--- | :--- |
| 平行四边形 | 无，找不到对称轴 | 有，绕两条对角线交点转 180° 重合 |
| Z | 无 | 有，非常典型的代表 |
| S、N、太极图、who | 长文未说明 | 有 |
| 百分号 | 无，中间那一笔不是轴 | 有 |
| 五角星 | 有，五条对称轴 | 无，对称点落在图外 |
| 箭头、躺倒的三角形、A、H、T | 有 | 长文未说明 |

## 考法与解法

### 属性优先的切入点

   * 题干图形**不相同、不相似**时，优先考虑属性，属性里先考虑对称。

   * 国考十道图形推理一定有一道考对称；一份卷子通篇做完一次都没用到对称，那至少错了一道题，回去检查。

### 只考轴对称的题

   * 题干四个图形全部是轴对称，逐一标上轴：五条轴、两条轴、两条轴、一条轴，由此先确立「要找一个轴对称」。

   * 逐项排除：A 不是轴对称，画一条轴它不对称；B 也不对称，它是个中心对称；C 是轴对称；D 是中心对称，只有 C 可选。

   * > **易错点**：⚠️ 这种题想多没用。题干已经把路堵死了，所有人都是轴对称，锁住那个唯一带轴的选项就行。

### 中心与轴的组合筛选

   * **先锁中心**

       * 题干第一个既轴又中心，第二个像 Z、只有中心，第三个中心加两条轴，目标就是「中心对称 + 两条对称轴」。

       * 先筛中心：A 是中心没问题，B、C、D 都不是中心，答案已经出来；轴这一条压根没用上，这题就结束了。

   * **交替分组**

       * 题干六幅依次是：只有中心、中心加四条轴、只有中心、中心加两条轴、只有中心、中心加四条轴，于是 1、3、5 一组，答案是 1、3、5。

   * **中心与轴交叉分类**

       * 题干前四个依次是能点出中心、能画出一条轴、S 形的中心、平行四边形的中心；后面三个是一个中心、一个轴、一个中心加两个轴。

       * 中心与轴就分开了，1、3、4 是一组，答案是第四个选项。

### 对称轴方向的旋转

   * **旋转步长**

       * 题干六个图形全是轴对称，一个一个画上轴就能看到对称轴在转，每一步旋转 45 度，下一幅的对称轴方向随之改变。

   * **旋转方向**

       * 顺时针转 45 度是一种走向；另有题目轴向呈竖、竖、横、竖、竖，一开始容易误判成顺时针，实际是逆时针转回来、再往上转，这样交替转下去，由此定出下一个轴的落点。

   * **变向也成立**

       * 有一题第一幅图是横的、第二幅变成竖的，看着不规律，但只要依然是旋转 45 度，规律就成立，不必因为形状变了就否定。

### 对称轴数量的考查

   * **直接数轴**

       * 题干图形都是三条对称轴时，找同样有三条对称轴的选项。

       * 练习七里题干 1、2、3 都是三条对称轴，A 的中间是一个正方形，画不出三条对称轴、只有一条，有三条的是 B。

   * **轴数做加法**

       * 每行前两个图形的轴数相加得到第三个：$1 + 1 = 2$，$1 + 2 = 3$；第三行是两轴加三轴，应找有五条轴的。

   * **组内轴数相同**

       * 题干按组分布，组内对称轴数量相同：第一行是一条、两条、四条轴，第二行是一条、两条轴，对应关系就这么简单。

### 图形自身是否自带轴

   * 排除到只剩两个选项时，区别可能就在图形自己身上：第一、三、五幅图形本身就带一条轴，二、四、六幅中间没有自带的轴。

   * 既然轴向旋转的规律已经确定，下一项应当找中间没有自带轴的，据此排除掉一个，答案落在另一个上。

   * > **提示**：排除到剩两个选项时，别急着硬找差异，先看看这两个选项之间「有没有」某个属性的差别——有和没有，往往就是答案。

### 子图形之间的对称轴关系

   * 整体看不出规律、其他规律也没太有时，往细里看：每个小图形里大的小的、黑的白的是不是每一个都自身对称。

   * 只画两个白色小图形的对称轴：图一两轴夹角 45 度，图二两轴平行，图三 45 度，图四 45 度，图五平行且重合，图六平行；所以 1、3、4 是一组。

   * 把黑色小图形也算进去，规律更完整：图一黑色与两个白色一个平行、一个成 45 度夹角；图二黑色与两个都是垂直；图三一个平行、一个 45 度；图四一个平行、一个 45 度；图五与两个的夹角都是 90 度；另外三个分别两个都 90 度、两个都 45 度、两个都 90 度，夹角都相同。

   * 图形推理难就难在这类题上，很多同学在这里会崩溃。

### 内外分层

   * 外圈都有一个圆，圆里边的图形在旋转，外圈相同的一组先排除。

   * 剩下两个的区别在中间那个图形：中间图形是轴对称，A 的对称轴是竖的、D 的是横的，按竖横竖竖的走向该找一条横的，答案是第四个。

## 考场取舍

### 想不通就放弃

   * 如果一眼很明显找不到规律，或者做着做着发现这题不行了，千万不要较真，千万不要死磕这一道，没有必要。

   * 十道题里一定会有那么一两道是你想不到的，不要较真，不要钻牛角尖，该扔就扔。

### 手感的来源

   * 见多轴对称图形后，拿到题一眼就知道大概率考轴对称。

   * 轴对称的题里一般塞了很多特别明显的特征。

   * 这种感觉不是背下来的，是把基础知识掌握好之后做大量真题慢慢形成的；出题人用的方式你知道的越多，考试时能做出来的概率就越大，能做的就是去刷大量题，让这些东西长在身上。

## 元素组成与规律优先级

| 元素组成 | 优先考虑 | 里面具体有什么 |
| :--- | :--- | :--- |
| 相同 | 位置规律 | —— |
| 相似 | 样式规律 | 加减同异、黑白运算 |
| 既不相同、也不相似 | 属性规律 | 对称、曲直、开闭 |

* **元素组成三岔口**

    * > **定义**：元素组成决定题目的第一顺位落脚点，三种情况各对应一条规律线。

    * 组成相同，优先考虑位置规律。
    * 组成相似，考虑样式规律，样式规律里分加减同异和黑白运算两块。
    * 既不相同、也不相似，优先考虑属性规律。
    * 属性规律这一条线上只有对称、曲直、开闭三个考点，不是三个并列选项让你挨个扫一遍。

* **属性三考点的先后顺序**

    * ① 对称 → ② 曲直 → ③ 开闭，三个考点有先后顺序，必须依次走完。
    * 走完 ① 再走 ②，走完 ② 再走 ③，不能因为"对称好像没有"就一榔头砸到 ③ 上。
    * 顺序本身就是分数。
    * 三个考点都没有规律，才回头查数量规律，顺序为点 → 线 → 面 → 素 → 角。

    * 判定路线：

        ```text
        元素组成：既不相同，也不相似
            |
            v
        优先考虑「属性规律」
            |
            v
        ① 对称 -> ② 曲直 -> ③ 开闭
            |
            v
        三步都没找到规律 -> 回头查数量规律
            |
            v
        点 -> 线 -> 面 -> 素 -> 角
        ```

## 对称性

* **对称性（symmetry）**

    * > **定义**：属性规律的第一个考点，分轴对称和中心对称两类，这两者一定要做好区分。

    * 轴对称里还会考对称轴的数量、对称轴的角度旋转。
    * 图形也可能既轴对称又中心对称，例如两个圆既对称无数条对称轴、又是中心对称。
    * 有图形只是中心对称而不是轴对称，不能因为它对称就当轴对称用。

* **不成对称即出局**

    * > **定义**：一组图形里只要有一幅不是对称图形，这道题就不是对称规律题。

    * 见到一幅非对称图形就立刻放下对称，不要在死胡同里出不来。
    * 做法是：先看选项不相同不相似，优先考虑属性；属性里第一个查对称，发现有一幅不对称，就确认跟对称无关，再去看曲直。
    * 对称在国考里一定会考。
    * > **易错点**：不要因为"就这一个不对称，硬找也能找出来"而继续死磕，越硬找越容易在错误方向上把时间耗光。

* **对称无规律后的转向**

    * 对称没规律就转看取值性，也就是曲直性。
    * 属性里对称、曲直都没规律，再考虑开闭。

## 曲直性

* **曲直性（curvilinearity）**

    * > **定义**：曲直性指一个图形是全部由直线构成、全部由曲线构成，还是由曲线加直线共同构成。

    * 曲直性归在取值性上考，是对称没规律之后的下一步。
    * 判断方法很朴素，拿眼睛扫一遍线条的粗细形状。
    * 考法比较细化：全直、全曲线、曲直结合三种形态都要清楚。

* **曲直例一**

    * 元素组成不相同不相似，优先考虑属性；先看对称，发现只有最后一幅是对称的，与对称无关。
    * 后三幅全部由直线构成，前两幅由曲线构成，推断下一幅应是全曲图形。
    * 四个选项中只有 C 是全曲图形（左边三个全由曲线构成，右边三个全由直线构成）。
    * 答案：C。

* **曲直例二**

    * 六幅图形不相同不相似；第一幅既对称无数条对称轴又是中心对称，第二、三、五幅对称，第六幅是中心对称。
    * 只有第四幅既没有轴也没有中心，是唯一的非对称图形，故对称无规律。
    * 快速转看曲直性：一全曲线，二全直线，三全曲线，四全曲线，五全曲线，六全曲线。
    * 1、3、5 成组，答案第二项。

* **曲直例三**

    * 图中几乎都是对称图形，唯一不对称的那一幅既没有轴又没有中心，故对称无规律。
    * 曲直性按行分组：第一行全部是直线，第二行全部是曲线，第三行两幅都是曲线加直线构成。
    * 括号里至少应该有一个曲加直，只有 A 由曲线和直线共同构成。
    * 答案：A。
    * > **易错点**：这都是平面图形，不是立体图形，不要把它想成立体。

* **曲直例四**

    * 1—6 元素组成不相同不相似，优先考虑属性；第一幅就不对称，既没有轴也没有中心，与对称无关。
    * 曲直性依次为：曲直、全直、曲直、全直、曲直、全直，可以三三分组。
    * 1、3、5 一组，答案第四项。
    * > **提示**：这个题考曲直不是上来就想到的，是先不相同不相似→优先属性→发现有一幅不对称→确认与对称无关→才转去看曲直。

* **内外曲直交替**

    * 第一幅就不对称，与对称无关；每幅图形都是曲直构成，但要往内外两层里再看。
    * 依次为外曲内直 → 内直外曲 → 外曲内直 → 内直外曲，内外曲直来回归替。
    * 下一个应该是外曲内直的图形，答案 C。
    * 所有题都不可能平铺直叙地给，出题人常加上自己的想法，或从另一个角度、另一个难度增加难度。
    * 思路对了之后，剩下的就是做大量例题，培养做题思维和感觉。

* **先锁箭头再比外框**

    * 最扎眼的特征是每幅图里都有同一个箭头，箭头都在逆时针旋转 45 度。
    * 箭头这一步锁定方向后，长度都一样的 B、C 被排除，只剩 A 与 D。
    * A 与 D 的区别只在外框形状，外框依次为圆（曲线）、正方形（直线）、心（曲线）、直线、曲线。
    * 下一个外框应由直线构成，答案 D；A 的外框是曲线，排除。
    * 本题不考虑对称：箭头转了 45 度，不对应一个轴对称；外框是六边形，也不是对称图形。
    * > **提示**：差异型选项的常规打法是先用题干里最扎眼的特征锁掉一批选项，再回头比较剩下两个选项之间的差异；差异本身就是考点，本题的差异落在外框的直／曲上。

## 开闭性

* **开闭性（openness / closedness）**

    * > **定义**：开闭性指图形是全封闭、全开放，还是半开放半封闭。

    * 判断标准是往图形里放一只蚂蚁，问它能不能跑出去。
    * 月亮、笑脸中间放蚂蚁跑不出去，是全封闭；四散的线条里蚂蚁畅行无阻，是全开放。
    * 以前一直考全封闭和全开放，所以半开半闭一直没有讲；2019 年春季联考考了一道半封闭和半开放的。
    * 出现频率非常低，近 45 年里只找到两道真题。
    * 优先考虑全开放和全封闭，只有个别实在找不着规律的题，才去考虑半开放和半封闭。
    * 特征有时蛮明显：某些图形里会留下开口，比如某个圆突然没封上、开了个口，见到这种图形就可以考虑开闭性。

    ```text
    月亮、笑脸    : 蚂蚁跑不出去  ->  全封闭
    四散的线条    : 蚂蚁畅行无阻  ->  全开放
    中间是几个面，外面有线连着，形不成一个完整的"面"
                  : 蚂蚁跑不出去  ->  半开放半封闭
    ```

* **开闭例一**

    * 元素组成不相同不相似，优先考虑属性，先看对称：前五幅都对称，第六幅因为留了小开口而不对称。
    * 有一个不对称即出局，本题不考察对称规律。
    * 再看曲直：六幅都是曲直构成，而且数不出曲直性规律，与曲直无关。
    * 于是落到开闭：第一、四、五幅蚂蚁跑不出，为全封闭一组；第二、三、六幅蚂蚁能出来，为全开放一组。
    * 答案：第二项。
    * 六个图形分别是中国银行、农业银行、上海浦东发展银行、工商银行、原深圳发展银行（后被平安吸收，成为现在的平安银行）、农村信用社。
    * > **易错点**：除江苏以外，图形推理不考图形的内涵和含义，只看图形本身的规律；这几个图形虽然都是银行标志，但含义里找不到规律。

* **开闭例二**

    * 以往只考全封闭与全开放，这道 2019 年春季联考的题考到了半开放半封闭。
    * 第一版解析：②③⑤ 外面一个框完整包住全部内容，定义为全封闭；①④⑥ 中间是几个面、外面有线连接，最外层形不成一个完整的"面"，定义为半开放半封闭。
    * 更倾向的解释角度：①④⑥ 的各个面之间通过线连接，②③⑤ 的各个面彼此紧挨在一起。
    * 两种解释下答案都是第三项，变的只是解释角度。
    * > **提示**：国考卷里出现过"几个面之间用线连接"和"几个面靠在一起"这类规律，联考应该就是参照国考出的题，所以后一种解释更贴近命题意图。

## 数量规律

* **数量规律的启动条件**

    * 元素组成既不相同也不相似时优先考虑属性规律。
    * 但有些题的数量规律非常明显、有明显特征，可以跳过属性直接去数。
    * 特征一：题里"有好多条曲线"，就猜测考曲线数量，跳过属性直接数线。
    * 特征二：题里有非常多的、一个一个的面，非常典型，就跳过属性去看面。
    * 数量规律也非常重要，可能占到接近一半的题量。

* **数量规律的五个考点**

    * 点、线、面、素、角五个题型，按这个顺序记忆。
    * 属性三个考点全部走完还没找到规律，才回头查数量规律。

## 数的点

* **点（交点，point / intersection）**

    * > **定义**：在公务员考试里面"点"指的是交点，数点时数的是线与线的交点。

    * 点有非常多种：有交点，有端点，有直线和曲线的交点等等，数量非常杂、非常多。
    * 线与线的交点可再细分三类：直线与直线的交点、曲线与曲线的交点、曲线与直线的交点，这三类也可以看成三类不同的考点。
    * 切点是一个圆和一条线相切的点，只有一个点，它也算交点。
    * 端点不是交点，不算。
    * 完全没有交点的图形，数点时是零。

| 点的类型 | 怎么数 |
| :--- | :--- |
| 直线与直线的交点 | 常规数交点 |
| 曲线与曲线的交点 | 常规数交点 |
| 直线与曲线的交点 | 常规数交点 |
| 切点 | 一个圆和一条线相切，切点只有一个点，它也算交点 |
| 端点 | 不是交点，不算 |
| 完全没有交点的图形 | 数点时是零 |

* **数点的特征图**

    * 线条交叉非常明显，像一个大树杈一样，线条在中间交叉出好几个交点。
    * 画了一条线在里面乱窜，中间会形成一些点。
    * 相切比较多，图上一串切点，此外可能还额外有一些其他的点。
    * > **提示**：这些特征出现时有可能考一笔画，但不仅要想到一笔画，也要能想到它可能是数点。

* **数点例一**

    * 先走属性：选项都不相同不相似，优先看属性，第二个不是对称图形，对称没有规律，曲直、开闭也没什么规律。
    * 属性没规律后回头看图上有没有扎眼的视觉特征：第一幅像一个大树杈，中间有一个交点。
    * 这时只是猜"有可能"是考点，再去测试：数出一、二、三、四、五个交点，规律成立。
    * 有六个交点的是第二幅，另一幅有十个交点；答案第二项。
    * > **提示**：特征图只说明有可能考这个点，不是一定；想到之后还要实际去数、去验证。
