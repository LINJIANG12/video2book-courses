# 2023年2月26日联考判断推理真题精讲

## 联考套卷与底本选择

### 联考的概念与题面特点

- 联考的参加省市、自治区将近 20 多个，卷子整体大差不差，中间可能稍微差几道题，重复度非常高。
- 重复度这么高，就没必要一套一套分开讲：挑其中一套当典型讲透，这一套就能当镜子用。
- 湖北卷的题目在联考各套里面题量算是最多，拿它当底本最划算。
- 这一套原卷讲解的范围是第 71 题到第 78 题。
- 手上的卷面都是"考生回忆版""网友回忆版"，真实考场上卷子长什么样没见过，所以不敢打包票。

### 图推的整体成色

- 联考这几年的判断推理图推都很奇怪，出题人特别想标新立异，但过于沉浸在自己的出题思维里，很多时候让人摸不着头脑。
- 有些题留下了很大的争议：不是不会，是题出得稍微也不太严谨，谁也不知道他内心到底想怎么样的。
- 定义判断部分的成色：联考的定义判断很多出得比较生涩，专业名词特别多，不太好理解；第 76 题还算好一点的，从第 77 题开始后面都不太好理解。

### 回忆版的处理原则

* **回忆版（图可能不是原样）**

    * 手上有回忆版，就在心里留一道"图可能不是原样"的保险。

    * 细节处有分歧时，不要把全部身家押在某一版上。

## 旋转类图推与基元拆解

### 中心对称

* **中心对称（central symmetry）**

    * > **定义**：图形旋转 180 度之后还是它自己。

    * 判断标准就这一条：转 180 度，与原图完全重合。

    * 典型参照是字母 S，旋转 180 度之后它还是这个样子。

### 切表层对称会漏看第二个图形

- 很多人拿过来一看就懵，会冒出两类想法：第一类是直接切对称。
- 拿对称去切的结果是：第二个图形对称、第四个大概好像也对称、第五个也对称；1、3、6 猜它是不是中心对称，但好像不是。
- 心里会冒出"另外三个难道没有规律"，可另外三个又确实是有规律的。
- 最后一刀切下去得到一组轴对称、一组中心对称，选 2、4、5，答案 B，直接选了就走，不要过度纠结。
- 坑出在第二个图形：很多人看 2 只看了轴对称，没往下拆；把 2 拆成三个会发现，它也是三个一模一样的单元旋转 120 度拼出来的，跟 1、3、6 是一路货色。
- 这样一来按刚才的理论就该是 1、2、3、6 一组，那就没有答案了。

> **易错点**：图形推理的结论成立与否，取决于你"看"到了哪一层。只看到表层的对称性，很容易就把一组本该同质的图形拆散了。拆开基元，是判断"这堆东西到底怎么来的"最稳的一招。

### 基元与旋转角度逐图拆解

- 判定路径：全部图形都由同一个基元旋转得到，那就从"基元"下手。

| 图形 | 拆开之后是什么 | 旋转角度 | 基元本身轴对称吗 |
| :--- | :--- | :--- | :--- |
| 1 | 3 个相同单元 | 120° | 否 |
| 2 | 3 个相同单元 | 120° | 是 |
| 3 | 6 个相同单元 | 60° | 否 |
| 4 | 正五边形单元 × 8 | 45° | 是 |
| 5 | 3 个相同单元（中间有点重复的线） | 120° | 是 |
| 6 | 3 个相同单元 | 120° | 否 |

- 角度这条路直接死：120° 的有四个（1、2、5、6），60° 一个，45° 一个，根本凑不成两组。
- 剩下的分法是看基元：把基元本身排成一排，问这 6 个基元能不能分成两组。
- 分法是三个基元本身轴对称（其中一个是正五边形），另外三个不是；按此分，2、4、5 一组，答案 B。

* **三层递进关系**

    * 第 1 层是表层现象：2、4、5 看着对称，1、3、6 看着中心对称。
    * 第 2 层是基元加旋转角度：角度分不开，这层不可用。
    * 第 3 层是基元是否轴对称：一组 2、4、5，一组 1、3、6，答案 2、4、5 选 B。

    ```text
      第 1 层  表层看到的现象
      ┌───────────────┬───────────────┐
      │   2    4    5  │   1    3    6  │
      │   看着对称     │   看着中心对称 │
      └───────────────┴───────────────┘
                    │ 拆开基元
                    ▼
      第 2 层  基元 + 旋转角度
      ┌───────────────┬───────────────┐
      │ 角度 120/120/60/45/120/120    │
      │ → 分不成两组，不可用            │
      └───────────────┴───────────────┘
                    │ 舍弃角度，改看基元本身
                    ▼
      第 3 层  基元是否轴对称
      ┌───────────────┬───────────────┐
      │ 基元轴对称     │ 基元非轴对称   │
      │   2    4    5  │   1    3    6  │
      └───────────────┴───────────────┘
                    ▼
          答案：2、4、5 → 选 B
    ```

### 分组规律的严谨表述

> **易错点**：不能说"三个有规律、三个没规律"。这六个全都是旋转得来的，两组都有各自的规律。正确的说法是——一组是由轴对称基元旋转得到的，另一组是由非轴对称基元旋转得到的。

- 把"分组规律"说成"有一组没规律"，是典型的粗暴解释；有些机构给这道题的解法就是这么粗暴的：三个轴对称、三个非轴对称，一刀切。
- 理由很硬："一组有规律、另一组没规律"这种形式在现在的考试里非常非常少，近些年几乎已经不考了。
- 前些年可能在吉林自主命题的一些省份见过，但现在吉林也参加联考了，所以几乎没有了。
- 每组都要有各自的共同特征和规律，这是出题的底线。

### 回忆版分歧的具体表现

- 回忆版本身就有分歧：第 4 个图形有的版本显示它是完全对称的，确实是轴对称图形、这两处是对称的；有的版本给得又不太对称，局部有一些小偏差。
- 倾向于猜它是对称的，但这只能算猜测。

### 考场结论

- 考场上真遇上这道题，选一个，走了就得了，不要去纠结。
- 很难猜透出题人的心；这种题里浪费更多的时间，把"我觉得对"的选了就走。
- 就算争论一小时、跟所有人去怼，又能怎样，这一小时不会有任何收获，也没有任何意义。

## 交点数

### 逐层排除路径

- 第一步看属性：2 好像有对称轴，4 好像也有，5 也是对称的，其他不对称，由此得出一组对称一组不对称。
- 属性这条路直接 pass：又是"一组有规律一组没规律"，这种几乎不考、不严谨；而且第 4 个图形明显也不对称。
- 第二步看点、线、面、素、角：面是窟窿多但数量乱；线是直线、曲线单数；直线的加减组合还是凑不出两组；素、角肉眼看过去也没有规律，全部出局。
- 走完属性和点线面素角，只剩一条路：数点。
- 第三步数点就卡住了：点太多了，有交点，有曲线跟直线的交点，各种交点混在一起，纯粹数点根本数不清。
- 找到"只能数点"这一步真的不容易，很多人内心就崩溃了，可能就走了；这道题确实非常难。
- 第四步答案是现成的：数曲线跟直线的交点。

* **排除路径**

    ```text
      面：窟窿多但数量乱   → 2 / 一堆 / ……  没规律，出局
      线：直线、曲线单数   → 4曲3直 / 8直2曲(实为7直)  没规律，出局
        直线的加减组合   → 还是凑不出两组，出局
      素、角             → 肉眼看过去也没有规律，出局
      ─────────────────────────────────
      剩下一条路         → 只能数点
    ```

### 一笔画条件不成立

> **易错点**：这一题没有一笔画，也不符合奇点个数为 0 或 2 的一笔画条件。所以"数点"不是数交点总数，更不是一笔画，只能落到某一种特定的点上。

### 曲线与直线交点计数

| 图形 | 曲线与直线交点数 |
| :--- | :--- |
| 1 | 6 |
| 2 | 9 |
| 3 | 6 |
| 4 | 6 |
| 5 | 9 |
| 6 | 2 + 中间小图 7 = 9 |

- 1、3、4 三个都是 6，2、5、6 三个都是 9，答案选 C。
- 这种题在考场上是"一步一步搂到那儿"的；如果真的搂不动，差不多点、走人就行，别再耗时间了，它确实挺费心、挺费神。

## 小元素

### 两种起手思路

- 这道题相对好一点，第一眼看到全是生活化的图形，能映入眼帘的差不多两种思路。
- 第一种数部分：这是四个部分，这是三个部分，这是一部分，没规律，数部分出不去。
- 第二种看小元素：这是三只老鹰；这片叶子能不能看出是三片相同的叶子；1、4、5 里面都是三个相同的小元素。
- 再看另外三个：第二个里面相同的小元素是两个圆，那就是两个；第六个比较明显也是两个。
- 第三个虽然是个对称性的、元素都挨在一起，不好说，但既然规律已经摆在那儿，就把它看成两个相同的小元素就行，不用过度纠结。
- 结论是 1、4、5 一组，答案选 C。

> **结论**：小元素题里"少数派"那一个图形不用死磕。只要 3、3、3 和 2、2 已经明明白白摆在那里，孤例往多数那边靠就是正解。

## 三视图

### 视图用词与观察方向

| 题干用词 | 观察方向 |
| :--- | :--- |
| 侧视图 | 题干已经给你标好方向了，照着给的方向看，不是"从左往右" |
| 正视图 | 从正面往里看 |
| 顶视图 | 从上往下看 |
| 左视图 / 主视图 / 俯视图 | 另一套叫法，跟上面三个不是一回事 |

> **易错点**：题干写"侧视图"并且画了方向箭头，就按箭头方向看。千万别在脑子里自动替换成"左视图"，方向一换，整个选项全废。

### 四个选项逐个排除

- 这道题比前几道简单，只看侧视图就能把 A、B、D 三个全排掉。
- A 错在"该画的线没画"：侧视图方向看，最底下那层没问题，最右边那个也能看到；第二层从侧面看过去有一条线是能看到的，没画。
- B 出局在位置：侧视图第一个图就错了，最底下那两个图形位置反了，侧向看的时候左右是反的。
- D 出局在方向：侧视图方向就反了，这一下就出掉了。
- C 侧视图完全没问题：底下那个正方形没问题，最右边那个三角形没问题；第二层那个正方形能看见，后面那个三角形被挡住了看不见，所以不需要画线、也没有画，没有问题；最上面那个也能看见。

### 三视图的验证顺序

- 三视图不用一上来就三个都验，先挑最有杀伤力的那个视图验。
- C 的正视图也没问题：别看它是斜的，本质一样，底下那层没问题，上面那层也没问题，中间是空的也没问题，最上面就是它。
- C 的顶视图从上往下看：这几个对得上，那几个也对得上，后面看不见的那块不用管；中间这一摞三个，从上往下看正好是这个区域；最后两个能不能看见当然能看见，一个是从这个地方看下来的，一个是从那个地方看下来的。
- 三视图这东西自己回去好好想一遍：可能跟着讲的时候跟不上，因为它有点立体的形式；自己静静地一个一个看，肯定能看出来。

## 黑白块

### 黑白块只有两种考法

* **黑白块的判断方向**

    * 先看现象：这些图都是黑白块，黑色区域各不相同；既然黑色区域都不一样，考位置、考旋转就不太可能了，大概率不考旋转类。

    * 遇到这种黑白块的题，脑子里只有两种考法——第一，黑白运算（黑跟白之间的运算）；第二，加减同异（消消乐那种，两两消除、两两相加或相减），无外乎就这两种。

### 横向排除与竖向验证

- 先试横向的黑白运算：拿第一个验一下，白加白等于白，成立；再看第二图白加白等于黑，完了，横向的黑白运算没规律了。
- 再试横向的加减同异，横着看这三组也没有规律，横向两条路都断了。
- 九宫格还能怎么看——竖着看：白加白得白，白加白得白，白加白得白，验几个差不多了；横着都不成立，那基本就是这个规律了。
- 逐个位置验证的推进顺序：白加白得白，第一行三格都该是白，排掉一个；第二行三个都是白的，这三个区域都得是白的，再排掉几个。
- 剩下 A 和 C 的区别就剩下一个位置：找出一个白加黑的区域，看白加黑等于黑，A 排掉，答案选 C。

* **横竖两条路**

    ```text
      横向看（按行）                竖向看（按列）
      ┌────────────────────┐      ┌────────────────────┐
      │ 白+白=白  ✓        │      │ 白+白=白  ✓        │
      │ 白+白=黑  ✗        │      │ 白+白=白  ✓        │
      │ 加减同异 ✗         │      │ 白+白=白  ✓        │
      └────────────────────┘      └────────────────────┘
            │ 两头都不通                   │ 成立
            ▼                             ▼
         横向放弃                   白+黑=黑 → 排除 A
                                       答案：C
    ```

### 黑色区域相加的等价理解

- 还有一种理解方式也通：把这三格看成从上到下的相加关系，这个位置、这个位置、这个位置都保留了，因为这个位置重复了，这个位置也保留了，另一个位置是叠加的，也保留。
- 所以是黑色区域相加的关系，答案同样是 C。
- 规律要么是黑白加，要么就是加减同异，两种思路殊途同归，答案都是 C。

## 图推的整体节奏

### 五分钟与期望收益

* **联考图推的时间分配**

    * 联考图推一般就是五道题目，这五道题千万不要纠结，想不出来就果断、大胆地扔。

    * 这五道题一定要控制在五分钟以内：能做出一道就做一道，能做出两道就做两道，剩下几个全扔了，蒙一蒙也无所谓。

    * 期望账：只做出两道、另外三道蒙一下，每道蒙对的概率大概是 0.75，两道做对的加上三道蒙的，期望大概能拿到 2.75 个题、对两到三个。

    * 在某一个题上死磕两分钟最后也未必能磕出来，在这里扔了过多的时间反倒可能拖累整体的正确率。

    * 可以这么做的原因是联考里的数量关系比较简单，完全可以把判断推理里匀出来的时间挪一部分到数量关系上去做。

    * > **结论**：时间是你要分配的资源，不是你用来证明自己聪明的战场。挑薄弱的地方、挑简单的地方多拿分，判断推理里那些没必要的纠结不要过度消耗。

    * 做对两个就挺好，做对两个多一点也可以，做对两个或者再蒙对一个、两三个就可以了；不要过度为难自己，也不要过度浪费太多时间，因为时间是有限的，这就是考场思维。

## 定义判断

### 挑能读懂的部分

* **生态恢复岸线**

    * 题干有些词挺拗口，就挑能读懂的往下走。

    * "生态恢复"首先要恢复；通过人工或者间接保护修复，这叫修复；把原来的人工构造，最大程度地恢复到自然的状态。

    * 问的是"属于"的是哪个，答案是 C：修复建设具有自然岸滩形态的生态功能的海堤，它确实修复了，确实把人工的改成了尽可能恢复到自然。

    * A 排除的理由是把自然的改成了人工的，方向完全反了。

    * B 排除的理由是只说打造黄金旅游岸线，根本没说清楚是恢复成自然还是以前什么样现在打造成什么样，完全没交代，不明确。

    * D 排除的理由是压根没有修复过程，它本来就是自然的，你没做任何修复。

    * > **结论**：答案就是 C。

### 可得性启发

* **可得性启发（availability heuristic）**

    * > **定义**：人在进行判断的时候，往往依赖最先想到的信息，并认为这些事件更容易出现。

    * 也就是说你最先联想到的那个信息，你认为它更常出现，但这并不一定是真的，因为你最先想到的并不是真实情况。

    * 读完题名再回头把能理解的部分拼起来就是这个定义，不要指望能从名字本身得到什么启发。

    * 匹配项是 D：判断交通工具安全的时候认为乘坐飞机更危险，因此首先想到的是关于飞机失事的报道，而通常想不起火车意外的报道。

    * 真实原因是飞机失事这个信息的冲击力太强了，最先跳出来；真实情况未必如此，飞机的出事率其实比火车、汽车要低，我们却拿"更容易想起来"当成了"更常出现"。

    * > **易错点**：读不懂就不硬读，直接读选项，看选项能不能帮你做排除。读不懂题名，就从选项里挑你读得懂的，用它们的关系去筛。

    * 另一个读不明白的选项到底属于哪一种并不确定，它肯定不是可得性启发、不跟可得性启发贴边，搞不好是代表性启发，不去纠结了。

### 同构选项

* **同构选项**

    * > **定义**：意思相同、说法不同的两个选项。

    * 同一个题的选项里出现同构项，它们一定同生共死——你要是选了 B 就必须选 C。

    * 所以 B 和 C 一定不能同时作为答案，一定都排除。

    * 触发后的效率极高：一旦发现两个选项意思一样，直接一起划掉。

    * 76 题之后的第一道不好理解的题就靠它解题：题干太晦涩、专业名词太多，B 和 C 可以叫同构选项（一个说贵的被认为质量好，一个说穿高档服装的被认为更成功），排掉之后剩下第四个就是答案。

    * 这道题确实挺难的，做对的概率不会高，但解题思路记住了就行，不用过度纠结。

### 不真正连带责任

* **不真正连带责任**

    * 名词本身读不懂就算了，改读后面能读懂的部分：债务人和债权人就通俗理解为欠钱的和被欠钱的，普通人按这个理解就行。

    * 硬条件一：债务人不止一个（存在债务人甲、债务人乙）。

    * 硬条件二：各人赖以负债的原因不同。

    * 触发条件：任何一个债务人履行了全部的债务，全部的债务就都没了。

    ```text
      债权人  ──────►  债务人甲（原因甲）
                └──►  债务人乙（原因乙）
                          │
                          └── 任一方清偿全部 → 债务整体消灭

      两个硬条件：① 债务人有多个
                  ② 各人赖以负债的原因不同
    ```

    * > **注意**：再往下都是不学法的人不该硬啃的部分，我们不是法学生，不能拿法学专业标准来要求自己。

* **不真正连带责任逐项判定**

    * A 符合：医院输血血液质量不合格导致病情加重，医院和血液机构是两个不同的债务人，基于不同的发生原因，任一方把全部赔偿都掏了债务就没了；血液机构该负责是因为提供的应该是质量合格的，医院也该负责是因为输血之前肯定要核查、要核对、确保安全。

    * B 不行，两处都错：第一，没有产生债务，小赵根本没有起诉他俩，债权债务关系压根没建立起来；第二，串通抬价是同一个原因、违反的是同一个商业行为，不构成"不同原因"。

    * C 不行：小刘和小宋各持股 50% 都是因为公司经营不善而欠钱，属于相同原因，不是不真正连带责任。

    * D 无法判断：一般出现交通事故交警一定要来定责，看责任归谁、是单方责任还是双方各负一定比例，谁是主责谁是次责；定完责之后周大爷才起诉，主次责按比例赔。

    * > **结论**：定责这一环没有，"是不是不真正连带责任"就无从谈起——有可能只有一个人有责任，有可能两个人都有责任，前提都不成立，选项自然站不住。

    * 四个选项过下来，站得住的就是 A。

## 考场取舍

   * **过一遍，别回头**

       * > **结论**：遇到自己不熟悉的题，只用"读懂了的那部分信息"去解题，读不懂的部分一律不管。

       * 选项之间互相咬合、每个看着都有道理时，综合比较落到某个选项就收手，不要再回头抠

       * 一道题多纠结一分钟，不一定更准，很可能只是把第一直觉里那个正确答案给推翻了，再白白搭进去一分钟

       * 这一分钟交给数量关系更划算，联考的数量关系够简单，很可能就换回一道题

   * **"读懂了"的判定标准**

       * 以债务责任题为例，能接住三条就足以定答案

       * 知道债务人与债权人分别是谁

       * 题干按不同原因给的情况分得清楚

       * 知道"一个人履行了债务，全体的债务就消灭"

       * 抓住这三条，其余咬不清的选项根本不用管

## 定义判断的通法

   * **从选项入手**

       * 这十道题除个别稍微绕一点，其余都称得上"仁慈"

       * 出题人压根没想考你有多懂法律、多懂地理，他只要你认出题干里那几个实打实的词

       * 做法是遇到生涩、不会的词就从选项入手：先看选项，不要死磕题干

       * 选完了，觉得那个可能是对的，就选了走人，别浪费时间

   * **止损时间**

       * > **注意**：这类题最多给 10 分钟，多一分钟都不要给。

       * 同一个题，做一分钟和纠结三分钟，正确率大概率没区别

       * 目标是把整张卷子的分拿高，不是把这一道题做完美

       * 十道题在 10 分钟里做对六到八个问题不大，相对简单的一扫就选完，该蒙的就蒙

       * 把定义判断的时间省下来去做确定性高、正确率稳的题，拿分更容易，这才是整张卷子的最优解

   * **进步难的原因**

       * 联考的定义判断做很多题也不见长进

       * 出题人这么多年没换过，一直是同一个人

       * 他出的东西就是直接弄一些很晦涩、很专业的名词出来，让人不舒服

## 以实词定生死的定义题

   * **生物修复**

       * 题干里"利用生物的生命代谢活动"这一句就是全部切入点

       * > **定义**：何谓修复，就是靠活的生命的代谢去干活的活儿

       * 题目问的是"不属于"，目标就是找一个没有生命代谢活动的

       * 只有把玉米这类粮食作物里的某些成分提取出来做成可降解塑料这一项符合，全是提取和加工，没有活物在里面代谢

       * 剩下几个都是在土壤里靠生物、靠细菌和芽孢杆菌一类微生物、靠藻类的共生关系起作用的，全是有生命代谢在跑

   * **隐匿性降水**

       * > **定义**：在地面或者地表面及低空直接凝结出来的降水

       * 对应露水和霜，都是在地表面结出来的

   * **直接性降水**

       * > **定义**：从空中直接往地面落下来的降水

       * 对应雨、雪、冰雹

   * **雾凇与雨凇的分野**

       * > **易错点**：雨凇和雾凇是两回事。雨凇是边降边冻的，属于空中降落的直接性降水，所以排除；雾凇是在地面、地表面那一层形成的，才落在隐匿性降水里。

       * 雾凇的成因是冬天水汽大、空气里全是水蒸气，天一冷就凝住，与霜是同一个道理

## 哪个选项更贴近定义

   * **环境的吸收能力**

       * > **定义**：自然环境能够对人类生产当中产生的废弃物，具有自动的容纳、吸收和消化的能力

       * 坑在选项上，答案选 PM2.5 能被大自然转化成危害较小的物质、进一步达到分解到无害状态这一项，自转、吸收、消化、无害化一整套全对上了

       * 主张"该城市大气允许承载物的最大数量"更贴切的理由站不住：该表述从头到尾没提"吸收""消化"，说的是"最大允许承载量"

       * 对任何一个城市都希望污染物是零的，但为了城市发展，人会忍受一定量的污染存在；那个最大允许承载量完全可能就是人类能忍受的上限，不等于环境能吞下的量

       * 风能带走一部分、人工治理能处理一部分，都不算环境本身在"吸收消化"

       * 反过来看，题干已经默认 PM2.5 是危害物质，选中那一项顺着说"转化成危害较小的物质""达到无害状态"，等于明确把它当成了人类的废弃物

       * > **提示**：看定义题，不要去追选项里的细节有多真，要去追它跟定义贴得有多紧。

   * **商业效用原则**

       * > **定义**：一是市场主体提供的商品或服务能发挥基本的功能作用；二是如果缺少必要的使用条件导致交易目的落空，这部分条件应当予以补足

       * 第一半好懂：买个房子得能住，买个手电筒得能亮，买个电视得能看

       * 关键在第二半的必要条件，判定口径是"没它不行"

       * 买房子烂尾、没给盖房顶就没法住，房顶就是必要条件，缺了它交易目的就落空

       * 买房送车位排除：可能压根没车，只要能住就够用，车位不是必要条件

       * 买桌子送椅子排除：桌子可以单独用，很多地方就是张桌子放杂物，不一定非配椅子

       * 购买家电享受三包服务排除：买个二手电脑照样能开机能用，非得有三包才能用吗

       * 答案落在出售地下酒窖附带出入通道这一项：买个酒窖没通道人进不去也出不来，进出通道就是没它不行

## 问法与生僻名词

   * **被害人盲点症**

       * > **定义**：有了迫切的欲望，判断力丧失了，对自己所处的风险视而不见这样一种状态

       * 问的是"不属于"，没注意到这个"不"字会挨个选项去对，越对越懵，觉得哪个都像

       * 争抢座位不慎滑倒受伤这一项不算：自己没站稳摔的，连被害人都不是，身上怎么会有被害人盲点症

       * 为了强身健体高价买大量伪劣保健品，迫切的欲望就是想要肌肉，于是被骗的风险被视而不见

       * 兼职刷单导致经济受损，迫切的欲望就是那份高额回报

       * 幻想一夜暴富给了骗子可乘之机，欲望迫切、判断力减弱，也对风险视而不见

       * > **提示**：这类判断题的定义往往是从论文里整段摘出来、剪一剪筛一筛做成的，枝节条件往往被砍掉了很多，所以看到的都是干巴巴几句，容易理解不了。遇到这种定义别硬抠，就按它字面给的这点东西用。

   * **禁止性规范**

       * 词太专业，正常没学过法的人读完都不知道在说什么

       * 省事的办法是遇到专业名词直接跳到定义的最后一句

       * 后面解释也读不懂，就只取"禁止性规范"这五个字靠常识去理解：规范你这个东西不能干，禁止就是不能干

       * 回到选项里找，只有"任何组织不得以任何方式侵害他人的肖像权"这一项是"不能干"，"不得"即明令禁止

       * > **易错点**：别顺手就想去背授权性规范、义务性规范、禁止性规范这几个法律名词。没必要——以前没出现过，以后也不会再出现，记它纯属浪费复习时间。通过有限的理解判断就够了。

## 构词路径

   * **仿译词与异译词、音译词**

       * 仿译词是异译词的一类，异译词是按意思来翻译的词

       * 旁边还有一路是借词，用外语的音去译，叫音译词

       * 仿译词的路径是拿本族（本族就是汉族）的构词规则，去和外语一一对应，两个字对两个字

   * **用英语即可排除的选项**

       * "蜜月"就是 honeymoon，honey 是蜜、moon 是月；"足球"就是 football，foot 是足、ball 是球，两边严丝合缝

       * 可口可乐是 Coca-Cola、高尔夫是"高尔夫"，全是音译，属于借词那一路

       * 激光（laser，雷射）、天使（angel）是两个词对过来，但既不是按意思翻的、也不是按音翻的，说不清是哪一路

       * > **提示**：这题还算仁慈，只用了英语。好在是英语，起码那两个音译词一眼能排掉；要是换成希腊语、西班牙语，那就真没法做了。

## 原材料之外的陷阱项

   * **看似顺理成章的联想**

       * 葡萄是葡萄酒的原材料是标准关系，答案落在枇杷膏的原材料是枇杷这一项

       * > **易错点**：常识不熟的时候别硬猜，类比的"陷阱项"往往就藏在那种听起来顺理成章的联想里。

   * **黄金档**

       * 是过去电视台的播出时间段，印象里晚上八点到九点半连播两集电视剧，中央一套那会儿就这么排的

       * 是个不错的时段概念，跟黄金作为原材料没有半点关系

   * **香蕉水**

       * 不是香蕉榨出来的水，是闻着有香蕉味儿所以叫香蕉水

       * 实际是化学合成的

   * **杜鹃**

       * 本来就有两种解释，既可以指鸟，也可以指杜鹃花

       * 两者关系说复杂了，但肯定不是原材料

## 属性题要问必然不必然

   * **必然属性与或然属性**

       * > **定义**：属性分两种——必然属性和或然属性

       * 判定口径是问"必然不必然"：是必然的才留，是或然的排除

   * **用后项反推前项**

       * "全真阅读"四个字单独看不知道什么意思，但后面"沉浸式"三个字在辅助理解：全真阅读应该就是全身心投入地、沉浸式地读

       * 沉浸式是全真阅读的一种属性，而且是必然属性

   * **或然属性的排除**

       * 线上课程有直播性排除：线上课程还能录播，直播性不是它唯一的性质

       * 乡村教育一定有均衡化排除：乡村教育能让教育更公平、更均衡，但这不是必然的

   * **必然属性与有漏洞的选项**

       * 人工智能必然是数字化的没什么问题，这一项稳了

       * 企业销售都是有盈利性的有漏洞：有些销售就是奔着亏去的，这笔单子赔钱是要通过补贴把市场份额占住，等有了话语权、有了定价权再回头盈利

       * 长远看可能最终还是为了盈利，但每一笔销售并不必然是盈利性的

## 成语与常识顺手积累

   * **近义成语**

       * 天荒地老与海枯石烂都指时间久远，现在多拿来形容爱情，算近义

       * 生僻的孜孜矻矻要留意，它跟孜孜不倦、夙夜匪懈是一路的，都在形容勤奋

       * > **提示**：这类词在选项里露出来，多半就是你该记的那个。

   * **望风披靡与望而却步**

       * > **易错点**：望风披靡有特定场景，专指军队没斗志、没交锋就溃散；望而却步范围就宽了，是遇到危险往后退缩，跟它近义的是望而生畏。

   * **并列关系的真伪**

       * 细胞核和细胞质都是细胞的组成部分，属并列

       * 牙冠不是并列项：牙冠就是牙露在牙龈以外、暴露于口腔的那部分，是牙齿的组成部分

       * 真正的并列答案是"真皮和表皮"这一对；牙冠、牙齿、牙龈这几个词不太了解的，自己去搜一下

   * **佶屈聱牙**

       * 表示文辞艰涩、拗口难懂，关键是它只能形容文字、形容文句，别的都套不上去

   * **春风化雨**

       * 比喻良好的熏陶和教育，用来形容教会没问题，方向是对的

   * **和光同尘**

       * 出自《道德经》，本义是形容自己不露锋芒、与世无争

       * 后来慢慢有了随波逐流的说法，但实际用起来，大家用的还是它本义那一层

## 关系的方向不能反

   * **因果关系看方向**

       * 龋齿就是虫牙、蛀牙，嗜食甜品会导致蛀牙，题干是从后往前导致

       * 顺序反过来的三项都要划掉，只有"地下渗水导致塌方"方向对

   * **功能关系**

       * 针灸的功能是疏通经络

       * 慢跑能增强体质没问题：慢跑锻炼心肺，心肺强了体质自然上去

       * 有两项读不出来，但它们之间根本没有逻辑关系

       * 缺铁会导致供血不足是因果不是功能；展品展示是为了促销是目的关系

   * **原材料加种属**

       * 钢材是游艇的原材料，游艇又是船舶的一种

       * 答案落在旗袍是服饰的一种、丝绸又是旗袍的原材料这一项，两层关系都对上

       * 古体并不是隶书的一种；版画和油画是并列关系

       * 木材是砧板的原材料、砧板是厨具的一种，这一项错在顺序反了

   * **组成加地点**

       * 书页是书籍的组成部分，书籍放在书柜里，是地点关系

       * 答案落在花蕊是花卉的组成部分、花卉长在花坛里，位置也对

       * 舞伴和舞蹈是主宾关系；面条和面片是并列关系

       * 鞋油不算鞋子的组成部分，理由有两点：一不是所有鞋子都需要鞋油，需要的一般主要是皮鞋；二鞋油的主要作用是擦皮鞋时的保养，它是个保养工具，核心关系在这儿，硬往组成关系上凑站不住

   * **先后加组成**

       * 十二时辰按子丑寅卯辰巳午未排，丑时在午时之前，这是先后

       * 丑时、午时又都是十二时辰当中的一个，这是组成，两层都对上了

       * > **易错点**：选项里的"家父"是谦称——我这么称自己的父亲，它不是敬称，把层级说反了。

       * 台风和飓风都是热带气旋的一种，是种属；火车和马车也都是交通工具的一种，还是种属

## 逻辑判断的读题起点

   * **先复述题干，再看选项**

       * 逻辑题上来不要急着看选项，先把题干那套说法完整复述一遍

       * 复述完整了，才拿得住后面每个选项在拆哪一块

   * **阔叶林更适合种人参的论证结构**

       * 针叶林就是松树这一类，叶子一针一针的；阔叶林就是叶子展开的那一类

       * 前提是人参属于喜阴的生物

         ```text
         人参属于喜阴的生物
                │
                ├── 针叶林：叶子细密，透下来的光多
                │        └──► 光照足  ──►  不利人参生长
                │
                └── 阔叶林：叶子大，遮阴效果好
                           落叶厚，冬季还能保暖
                        └──► 遮阴 + 保暖  ──►  更利于人参存活

                ──────────────────────────────
                          上述观点：阔叶林更适合种人参
         ```

       * 题干看懂了，题目问"最能削弱上述观点"，那就是削弱——得找一个能把"阔叶林更适合种人参"给掀掉的说法

       * 对应选项：人参在蒙古栎下长得不好，因为蒙古栎的落叶太厚，幼苗长不出来

## 削弱项的有效形态

* **举例反驳**

    * > **定义**：拿一个具体的事实把对面的说法顶回去，构成有效削弱。

    * 蒙古栎题中题干说阔叶林有利于人参存活，选项举长白山阔叶林不利于蒙古栎生长的例子，用具体事实否掉"阔叶林有利于存活"。

    * 例子方向可由题干线索倒推：落叶太厚 → 落叶能厚成那样只能是阔叶林 → 属于阔叶林特征。

    * 遇到题干出现的陌生名词直接放弃并不划算，这类题明摆着就是要猜。

* **另有他因**

    * > **定义**：结论所设的因果关系还可能由别的因素造成，这是因果倒排的经典削弱。

    * 皮质醇题中结论是"压力水平会反映在头发中储存的皮质醇含量上"，选项指出皮质醇是内置的警报系统，但不是造成这一切的唯一原因。

    * 切入方式是"回稿思维"：皮质醇到底从哪来？一定只跟压力有关吗？其他干扰因素排除了没有？

    * 拿到研究类、实验类题干先问这一层，是最稳的切入角度。

* **唯一剩余项**

    * 四个选项里"矛盾"和"反对"都不存在时，正确项往往是被排除法唯一剩下的那个，不必再比力度。

    * 皮质醇题中两个选项谈压力状态下身体会释放皮质醇，是支持项；一个只谈色素，是无关项；剩下那个才是削弱。

## 削弱题中无效选项的三种形态

* **和稀泥**

    * > **定义**：说出一句两边都不得罪的话，既不构成支持也不构成削弱，等于没说。

    * 典型形式是"多多少少都存在不利于人参生长的因素"，什么都没说清楚。

* **偷换论据**

    * > **定义**：题干比较的是某一维度，选项换到另一个维度，维度一换选项就与该论证无关。

    * 题干论点谈的是针叶林与阔叶林的阳光多少，选项换成坡度太平或太陡，坡度跟这道题没有关系。

* **无关项**

    * > **定义**：只谈事物自身的另一面，与题干结论涉及的核心对象对不上。

    * 皮质醇能改变头发的色素沉着、让头发变灰变白甚至脱落，通篇只谈色素没提压力，而结论是"压力反映在皮质醇含量上"，方向对不上。

    * 淡水虾中含有肺吸虫、人会感染，扯得太远，题干从头到尾讨论的是牛蛙，这条线根本没铺到。

* **反倒构成支持**

    * 康断和紫椴树叶子密、遮阴挡雨，说明是阔叶林，反倒把范围缩到阔叶林，与题干"阔叶林有利于存活"同向。

    * 牛蛙身上还有只寄生牛蛙、不传染给人的寄生虫，是非常微弱的支持作用，绝不是削弱。

    * > **提示**：光看"叶子密"一个特征锁不死是针叶林还是阔叶林，针叶林同样挺密；是"叶子密"加上"遮阴挡雨"两条合起来才更好地指向阔叶林。做这类生活常识题靠的是组合判断，不是靠某一个特征拍板。

    * > **提示**：判断这类选项只问一句——它跟题干结论的方向一不一致，而不是看它出现了哪个熟悉的名词。

## 削弱项之间的力度比较

* **比的是"削掉多少"，不是"对不对"**

    * > **结论**：能削弱只是入场牌，削弱项之间还要分出高下。

    * 牛蛙体内有某种虫还能在人体内寄生，吃了这些牛蛙严重影响健康；我们吃牛蛙一定煮熟了吃，煎、炸、煮高温一上寄生虫也活了不成，所以第一个想到的削弱方式就是"我又不生吃"。

    * 四个选项摊开挨个称：

| 选项 | 它实际说了什么 | 力度判定 |
| :--- | :--- | :--- |
| 高温烹饪把寄生虫全部杀死 | 直接告诉你"全杀死了" | 最强，把结论整个掀翻 |
| 淡水虾含肺吸虫、人会感染 | 讨论的是虾不是牛蛙 | 无关，题干这条线没铺到 |
| 解剖生态养殖的牛蛙没发现任何裂头寄生虫 | 提供相反论据，但只证明其中一种没有 | 削弱成立，幅度有限，只掀翻一小块 |
| 牛蛙身上还有只寄生牛蛙、不传染给人的寄生虫 | 寄生虫本身也不想吃，且有未知风险 | 非常微弱的支持 |

    * 判据是掀翻的范围：A 把结论整个掀翻，C 只掀翻了一小块，这种时候就该选 A。

## 支持题

* **论据细化式加强**

    * > **定义**：把题干已给出的论据补完整、给确切量级，属于加强；比起另起炉灶加一条全新论据更省事。

    * 金星灼热行星云层里没有足够的水蒸气维持生命形式，结论是金星不可能有生命；论证本身充分，不需要搭桥，只需看哪个选项最能支持。

    * 关键在给"不够"一个量级：维持生命要 100 份而金星云层只有 1 份，差 99 份是彻底没戏，差一点点则可以忽略。

* **关键词陷阱**

    * > **易错点**：看到"生命""过敏"这类熟悉名词就以为是支持，是最常见的翻车点。

    * 金星云层中有足够的水、温度也适宜维持生命，是直接反驳——题干说不可能有生命，选项说条件都具备。

    * 磷化氢是一种与生命有关的气体、大气中含有，传达的是"可能有生命"，与结论"不可能有生命"完全相反，是反驳项。

    * 母乳题中"母乳喂养期间母亲进食过敏食物会增加宝宝过敏风险"引入的是"母亲吃过敏食物"这个新因素，方向是"增加"而不是"降低"，属无关项。

* **一道题里错了三处**

    * "仿真的模拟"——仿真模拟本身就不一定真实。

    * "液态水可能维持了约 30 亿年"——给了时间却没给水量；题干说的是没有**足够**的水，不是没有水，够还是不够根本没交代。

    * "只有在 7 亿 5000 万年前金星才变得不适合居住"——不适合居住跟有没有生命不能划等号，不适合人住不等于不能有生命。

* **从机理上打通的支持**

    * 母乳致敏性低：宝宝免疫系统把母乳里的这种蛋白识别成"自己人"，因而不会对它发起攻击，不产生过度的免疫反应，于是不发生过敏，这是从机理上把"为什么能降低"讲通了。

    * 问的是母乳时，没提母乳的选项一律排除，先按这一条砍掉两个再比力度。

    * > **注意**：该题结论"母乳喂养可以降低剖宫产宝宝过敏的风险"是一道营销号式的假新闻，跟制造风险、制造焦虑的假新闻一个路数；无论是剖宫产还是正常分娩对孩子都没有这种影响，不要当真。

## 推出题

* **前提到结论的推导关系**

    * 黄油由 100 多种以上的各种油脂混合在一起，可可脂只由三种油脂构成。

    * 黄油随着温度上升一点点由固体变为液体，可可脂到达熔点时瞬间融化。

    * 推导：混合油脂多 → 每一种熔点大概率都不一样 → 温度往上升一点，这点化一点那点也化一点 → 慢慢融化；只有三种油脂且熔点相近 → 到点就瞬间融化。

    * 抓住"混合油脂多"与"慢慢融化"之间这条推导关系，选项直接拿走。

* **题干未提的一律排除**

    * 所需温度不一样、谁的所需温度更高，题干没提。

    * 所需温度固定不变、不受环境影响，题干根本没说这回事。

    * 用于烹饪对健康更好，属于无中生有。

* **题干画风一转时只认明说的**

    * 心脏受神经控制，一个交感神经、一个迷走神经，安静状态下迷走神经调控比较强，运动时交感神经控制比较强。

    * 胃肠道、生殖系统、血管壁也由交感神经和迷走神经支配。

    * 据此只能推出：交感神经或者迷走神经对心脏和胃肠的调控不同，产生不同的效应。

    * 不受意识支配题干没提；合理使用大脑维持良好情绪没提；冠心病、胃溃疡题干只讲器官根本没讲疾病。

    * > **提示**：题干风格中途一变不要慌，把前后两部分各自说了什么摆平，结论通常就落在两者的差异上。

## 搭桥

* **放大效应**

    * > **定义**：一个变化回过头来还会加剧自身，才叫放大；单方向的因果只是正常现象。

    * 气温升高则冰雪消融得多是正常现象；气温升高导致冰雪消融增多、进而加剧气温升高才是放大。

```text
气温升高
   ↓
冰雪消融增多
   ↓
露出【裸地】—— 深色或黑色，吸热能力远强于白色的雪
   ↓
裸地吸收更多太阳辐射
   ↓
加热大气，气温进一步升高
   ↓
冰雪消融更多  ⟲ 回到第一步
```

    * 雪是白的反射太阳光，裸地是黑的光全吸进来；吸进来就加热大气，加热大气又进一步加剧消融，这才叫放大。

    * > **结论**：放大效应的核心必须是裸地，没有裸地就没有这个正反馈环。

* **搭桥就是补缺环**

    * 格陵兰岛的冰川消融受到了放大效应，题干只交代了冰川消退，没交代格陵兰岛冒没冒出裸地。

    * 缺的就是"格陵兰岛有裸地"这一环，只有把格陵兰岛、裸地、放大效应三头连起来的选项才成立。

    * 搭桥题必有搭桥项，且往往只有一个，找到它即可停止分析其余选项。

## 真假推理

* **常规顺序**

    * 先找矛盾，再找反对。

    * 找矛盾——没有，这四句话里没有任何一对构成矛盾；找反对——也没有，所有所有、有的有的一个都没有。

    * 那就只剩下最笨的办法：代入，去假设。

* **没有矛盾也没有反对时的代入法**

    * 四句话的翻译是：甲「只有……才……」→ 红一推黄二；乙「如果……那么……」→ 红三推蓝四；丙：蓝不是第四 → 否蓝四；丁：黄第二个出场 → 黄二；题干限定只有一个人预测为真。

    * 假设甲为真、其余为假：红是第一个出场就推出黄第二个出场，而丁说的正是黄第二个出场，甲对则丁必对，两个都真与"只有一个为真"矛盾，所以甲不对。

    * 假设乙为真、其余为假：红是三推出蓝是四，丙"否蓝四"为假、丁"黄二"为假；红是三、蓝是四、黄不是二，黄色只剩一、绿色只剩二。

    * 并行的另一条思路：直接假设红黄绿蓝的出场顺序，把四种排列往题干里代，看哪一种满足"只有一个人预测为真"。

* **假设的对象是推导关系，不是前提**

    * > **易错点**：假设"甲"为真，只是假设了"如果红一那么黄二"这个推导关系为真，并没有假设"红一"本身为真，红色不必然是一。

    * 很多同学是碰巧做对了——方向没错，逻辑上少了一步。

    * 正确做法是叠加热设：红只有一和三两种可能，就叠加热设"红一"。这是在穷举可能性，先试哪个都不影响结论的可靠性，而且叠加之后手上的数据更多、更好推。

    * 叠加热设红一后：红一推黄二，甲和丁都真，矛盾，验证第一个假设失败。

    * 假设乙为真时同样叠加热设"红三"：红三推蓝四，丙、丁均为假，黄不是二、不能是三（红占了）、不能是四（蓝占了），只能是黄一、绿二；回头验甲，黄是一推不出黄二，甲也是假的，四个人里只有乙一个为真。

    * > **提示**：把常规的真假推理做明白，比死磕这一道值当得多；没听明白、觉得没意义的可以直接跳过，把题整得太透对提升帮助不大。

## 翻译推理

* **常见口语的翻译**

| 原话 | 关系 | 翻译结果 |
| :--- | :--- | :--- |
| 要么刘家参加，要么正毅参加 | "要么……要么……"，形似"或"但不是完整的"或"，也能否一推一 | 先不落笔 |
| 只有……才…… | 后推前 | 刘推吴 |
| 如果郭斌和吴芳都参加 | 且关系 | 郭且吴 → 施文 |
| 或者丁晓不参加 | 或关系 | 否丁 或 郭 |
| 至少有一人 | 完全的或关系 | 施 或 丁 |

* **从否施文顺两条线走**

```text
起点：施文不参加（否施文）

路线一：否施文 →(否一推一)→ 丁参加 →(否一推一)→ 郭参加 → 链条到此为止

路线二：否施文 →(且的否定，德摩根定律)→ 否郭 或 否吴
          否郭 或 否吴 →(否一推一)→ 否吴 →(否后推否前)→ 否刘
          否刘 →("要么……要么……"否一推一)→ 正毅参加

汇总：丁、郭、正毅 都参加  →  答案选第二个
```

    * 绕点一：丁参加能推出郭参加，是因为"否丁 或 郭"里的丁参加恰好是对前面"否丁"的否定，这就是一次否一推一；语言上有点绕，理清了就通。

    * 绕点二："且"关系的否定要用德摩根定律（De Morgan's laws）拆开，得到"否郭 或 否吴"，才能接着往下走。

    * 这道题通篇用了四次"或"关系，翻译推理题里出现四次"或"量非常大，做明白以后碰到"或"会用得非常溜。

    * 翻译推理最核心的就是老老实实翻译，不要乱想，按步骤一步一步来；看上去没什么技巧，但能确保它一定对，而"确保一定对"这件事本身非常值钱。

## 整套卷子的时间战略

* **不会就跑，不要捂在里面**

    * 整套卷子最核心的一条战略：遇到比较难、比较想不到的题，千万不要浪费时间，不会就先跑，有时间回头再看。

    * 一旦进到死胡同立刻出来，灵感一触发就可能突然想出来。

* **按"大量使用不会就跑"策略算的账**

```text
前 5 题（图推）      ：要求对 2
定义判断            ：做对 6、蒙对 1 = 7，扔掉 3
类比推理            ：这部分非常简单，对 9
最后 9 题           ：对 8（104 难，但很多人用"错方法"也飞快地做出来了）

合计                ：35 题，对 26 题
```

    * 这 26 题 30 到 35 分钟就能搞定，省下来的时间可以转去搞数量关系。

    * 联考的数量关系真的非常简单，那 15 个题可以多对不少；反过来，这 26 个题就算额外再给你 10 分钟也未必能多对两三个。

    * > **结论**：做整个判断推理一定要追求时间的最大化利用，用合理的时间把这些题做完就够了；给足够充裕的时间谁都能做得不错，真正要练的是在有限时间里做出取舍。
