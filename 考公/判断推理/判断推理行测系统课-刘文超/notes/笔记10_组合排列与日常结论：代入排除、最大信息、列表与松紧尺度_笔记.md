# 组合排列与日常结论：代入排除、最大信息、列表与松紧尺度

## 三种连接词的逻辑格局

### 且关系

* **且关系**

    * > **定义**：A 与 B 同时成立，缺一个都不行。

    * 例：物美并且价廉；超哥长得帅并且有才华。

    * 真假格局：只有「全中」一种情况。

    * 它的等价关联词是三种关系里最多的，考场上辨认时最不容易慌。

### 或关系

* **或关系**

    * > **定义**：A 或 B 至少有一个成立，允许两个都成立。

    * 展开成三种情况：只 A、只 B、A 且 B。

    * 例：「我周六或者周日休息」包含周六休息、周日休息、两天都休息三种情况，至少中一个。

    * 也可以两个都成立，这就是或关系。

### 要么要么

* **要么要么**

    * > **定义**：A 与 B 恰好一个成立。

    * 展开成两种情况：只 A、只 B。

    * 例：「要么小红是我老婆，要么小丽是我老婆」，只能有一个人是我老婆。

    * > **易错点**：要么要么 ≠ 或关系。或关系允许两个都成立，要么要么只允许恰好一个成立。题干里「只能去一个」「必须有且只有一个」这类说法对应的都是要么要么，不是或。

### 展开情况对照

* 三者的差别落在「或」这一支能不能两个都成立上，且关系要求全中，或关系要求至少中一个，要么要么要求恰好中一个。

| 关系 | 逻辑含义 | 展开成几种情况 |
| :--- | :--- | :--- |
| 且关系 | A、B 必须同时成立 | 全中 |
| 或关系 | A、B 至少有一个成立 | 只 A、只 B、A 且 B |
| 要么要么 | A、B 恰好一个成立 | 只 A、只 B |

## 等价关联词认读

### 三类等价关联词

* 卷面上靠关联词辨认关系，不必靠语气或常识推断。

| 关系 | 等价关联词 |
| :--- | :--- |
| 且 | 且、并且、和、既……又……、不仅……而且……、虽然……但是…… |
| 或 | 或者、……和……至少一个 |
| 要么要么 | 要么……要么……、……和……只有一个 |

### 且的等价关联词

* 关联词：且、并且、和、既……又……、不仅……而且……、虽然……但是……。

* 「物美和价廉」「既物美又价廉」「不仅物美而且价廉」全是且关系。

* 关联词最多，辨认时不用慌，做题练熟就自然认得出来。

### 虽然……但是……收进且关系

    * > **提示**：转折词在逻辑上只表示「两件事都有，但重点在后面那个」，并不否定前一件也成立，所以「虽然……但是……」照收进且关系，别因为语气变了就改判。

* 「虽然我很丑，但是我很温柔」——丑和温柔同时存在，即既不丑且温柔。

* 「虽然你很好，但是我不能和你在一起」——两件事同时存在，即既好且不能在一起。

* 这是转折关系没错，但转折的是语气，不是事实上的并存关系。

### 或的等价关联词

* 关联词：或者、……和……至少一个。

* 「周六和周日至少有一天休息」与「周六或周日休息」完全等价。

### 要么要么的等价关联词

* 关联词：要么……要么……、……和……只有一个。

* 「小红和小丽只有一个是我老婆」即要么小红要么小丽。

## 或关系的翻译规则

### 否一推一

* **否一推一**

    * > **定义**：或关系为真的时候，否定其中一项可以得到另一项。

    * 例：我周一或者周二上班；已知我周一这一天没有上班。周一或周二上班为真，周一没上班，则周二一定上班。

    * > **结论**：或关系写成 `A 或 B`，用的时候优先想否一推一——否定其中一项，推出另一项；注意否定的是靠后那一项，即否后得前。

### 或关系必须为真

* 否一推一能不能用，取决于这个「或」是不是真的成立——或关系当然可以为假。

    * 反例：「如果这道题的答案是 A 或 B，那么我就错了。」已知答案不是 A，推不出一定是 B，还可能是 C、D、E、F；正确答案真是 C 时，这句话照样成立。

    * 原因：这个「或」在「如果」里面。「如果」后面的东西未必是真的，只表示「在某个条件下会怎样」，而这个条件本身没告诉你成不成立。

    * 去掉「如果」，直接说「这道题的答案是 A 或 B」，就是一句真的题干，此时不是 A 就能推出是 B。

    * 一个「如果」在不在，否一推一能不能用，完全是两回事。

    * > **易错点**：「或」如果出现在「如果……那么……」这个条件句里，它未必为真，此时不能用否一推一。做题时先确认这个「或」是真实发生的事实陈述，还是藏在一个假言条件里。

## 或关系串联推理

### 四句话串成一条链

* 原文条件：被告有罪或者是疯子；有罪则被处死；是疯子则永远接受住院治疗；证据不够有力则不应该被处死。

```text
①  有罪 或 疯子                       （或关系）
②  有罪 → 处死                        （前推后）
③  疯子 → 住院治疗                    （前推后）
④  否证据有力 → 否处死                （前推后）
```

* 已知证据不够有力，推理链：

```text
已知：否证据有力
  │
  │ ④ 原样
  ▼
否处死
  │
  │ ② 逆否等价（否后推否前）
  ▼
否有罪
  │
  │ ① 或关系否一推一，否定「有罪」
  ▼
疯子
  │
  │ ③
  ▼
永远接受住院治疗
```

* 整个过程只用了三个动作：一个或关系、一个前推后、一个逆否等价，翻译对了推理就是水到渠成。

### 逆着目标往回推

* 原文条件：小钱教德语，那么小孙不教俄语；小李教德语或者小钱教德语；如果小孙不教俄语，那么小赵不教法语；小赵教法语或者小赵不教英语。问哪项为真可以推出小李教德语。

```text
①  小钱教德语 → 小孙不教俄语
②  小李教德语 或 小钱教德语            （或）
③  小孙不教俄语 → 小赵不教法语
④  小赵教法语 或 小赵不教英语          （或）
```

* 要拿到②的前项「小李教德语」，就用②否一推一把后项否定掉，需要「小钱不教德语」。

* 「小钱不教德语」由逆否串出来：

```text
① 逆否：  小孙教俄语 → 小钱不教德语
  │
  └─ ③ 逆否：  小赵教法语 → 小孙教俄语
        │
        └─ 合起来能落到 A、D 这类选项上 → A、D 错
```

* 剩 C，回验 C 只能从④下手：假设④不成立即小赵不教法语，用或关系否一推一否定后面那一项，得小赵不教英语，前后不冲突，C 站得住。

* > **提示**：否一推一否定的是「或」后面那一项。④后面写的是「小赵不教英语」，把它否定掉得到的是「小赵教英语」，方向千万别看反了。

## 德摩根定律

### 且关系的否定

* **德摩根定律（De Morgan's laws）**

    * > **定义**：否号放进去，且变或、或变且，两个命题互为否定。

    * 否定「物美且价廉」不能只说「这句话是假的」，要落到具体情况上，有三种：不物美；不价廉；既不物美且不价廉。

    * 这三种合起来正好等于「不物美或者不价廉」——它包含只不物美、只不价廉、既不物美又不价廉。

    * 所以 `A 且 B` 的否定是 `否A 或 否B`。

### 或关系的否定

* 否定「周一或者周二上班」只有一种情况能说明这句话错了：周一没上班，并且周二也没上班。

* 两边都不成立，才谈得上「周一或周二上班」是假的，所以 `A 或 B` 的否定是 `否A 且 否B`。

* 把两条放在一起看，它们互为否定，规则就一条。

| 原式 | 否定后 |
| :--- | :--- |
| A 且 B | 否 A 或 否 B |
| A 或 B | 否 A 且 否 B |

### 适用场景

* 翻译推理里关于否定的部分就叫德摩根定律；把关系翻译成正向箭头之后，它负责另一半——否定。

* 什么时候用得上：当题里给的是被否定的且关系，而选项是以或关系的形式出现时，它就是解题的那把钥匙。

* 资产荒那题：（信用风险上升 且 有效信贷需求不足）→ 陷入资产荒；已知没有陷入资产荒，是否后，逆否等价得否（信用风险上升 且 有效信贷需求不足），德摩根展开为否信用风险上升 或 否有效信贷需求不足，对应选项 A。一整个后推前加一个且变或就结束了。

* 权钱交易那题：（炒作暴富 或 权钱腐败）→ 否动力；动力是后件，逆否得否（炒作暴富 或 权钱腐败），德摩根或变且得否炒作暴富 且 否权钱腐败。

* 否 A 且否 B 是且关系，且关系两支都成立，只说其中一支当然也对，所以「没有人可以权钱交易腐败」这一支站得住。

* > **提示**：不要把或关系当箭头用。「有人能炒作暴富就能权钱腐败」没有这种推法。肯后也推不动——后往前推不出来。

## 翻译推理整体收口

### 已覆盖的模块

* 这一类题认的就是「如果、那么、只有、才」这些典型的逻辑关联词，解题思路就一句：先翻译，后推理。

* 讲过的模块：前推后、后推前、逆否等价、且关系与或关系、德摩根定律。

* 这几块已经占到整个考试里翻译推理的 95% 及以上，应付公务员考试的翻译推理足够了。

* 边界：这些只是经常考、考得太多的部分，并不全；没讲的不一定不考，是不重要。国考里翻译推理一般最多考一道，十个题里一道，最近好几年几乎相当于没考。

* 讲这么多是因为翻译推理是后面所有要学内容的基础。

### 做题心态

* 不要老用自己的脑子去想去猜，琢磨「这个应该是这样吧」没有用——这是翻译推理，只需要把整个翻译翻出来，再按翻译的规则推。

* 真要说「用脑子想」有用，那是高手才能用；普通人脑容量有限，安安心心按流程做。

* 整条链子一环套一环，每一句都不是白给的；把例题好好做一做，做得多了自然找到感觉。

## 组合排列的题目特征

### 朴素逻辑

* 组合排列也叫排列组合，在真正的逻辑学里叫**朴素逻辑**。

* 改名的理由是不必搞得那么专业：用「组合排列」这个直白的说法，一看就知道这题大概是排列组合，学起来也省劲。

* > **定义**：题干给出两组及两组以上的对象，然后给出几组对象之间的关系，要求把对应关系找出来。

* 例：题干给甲、乙、丙三个人，又给北京、广州、杭州三个地点，说这三个人分别对应三个地方、谁来自哪里我不知道，再给出关系，如第一个条件是「甲比杭州人的年龄大」；问题是谁来自哪里。

* 由「甲比杭州人年龄大」可得甲不是杭州人，甲自己当然不能是杭州人；选项里「甲是杭州人」的那个直接就错——这就是第一种方法排除法的起点。

* 组合排列出简单题会非常简单，出难题会非常难，由简入难地练。

## 排除法

### 读一句排一句

* **排除法**

    * > **定义**：读一句、排一句，挨着题干的句子走，用条件去砍掉不可能的选项。

* 前四名题：赵、钱、孙、李获得前四名；孙先生和李先生经常打篮球；第一名和第三名是这次比赛中刚认识的；第二名不会骑自行车，也不打篮球。

    * 条件①孙先生和李先生经常打篮球——单独看这句什么也排不掉。

    * 条件②第一名和第三名刚认识——与①合起来，第一名、第三名不可能是孙和李，排除掉一个选项。

    * 条件③第二名不打篮球——第二名既不是孙也不是李，排除 B、D，剩 A。

* 六人下乡挂职题：人事部要求甲和丁两个人只能去一个；组织部要求若丁不去则戊也不能去；办公室要求甲、丙两人中必须留下一个。

    * 第一句甲和丁只能去一个——「丙和丁都去」不成立，排除 A。

    * 第二句若丁不去则戊也不能去——前推后写成否丁 → 否戊，逆否等价为戊去 → 丁一定去，于是「戊去了、丁没去」不成立，排除 B。

    * 第三句甲、丙两人中至少留下一个——「他们仨全去了」不成立，排除 C，剩第四个。

* 两道题都只用最朴素的排除法做完，顺序是先读一句、排一句。

## 代入法

### 把选项塞回题干

* **代入法**

    * > **定义**：把选项直接代入题干中去验证。

    * 与排除法不同：排除是读一句、排一句，挨着题干的句子走；代入是把选项塞回题干里逐条验。

    * > **结论**：题干的条件是确定的，优先用排除法；题干的条件不确定，尝试代入法。

* 三个人猜四个班出场顺序：甲说一班第一个出场、二班第三个出场；乙和丙的预测分别落在三班、四班、一班上；结果发现他们的预测都只对了一半。

* 「他们的预测都只对了一半」是条件不确定的典型：手里的信息只有一半是对的，告诉你「一班第一个」对不对根本不知道，读一句排一句排不动，只能把选项一个个代进去验证。

* 代入流程：先代入 A 选项，逐人核对是否都只预测对了一半。甲这一关：一班第一个出场错，二班第三个出场也错，前半句就错了，甲这一关没过，选项直接出局；再照同样办法对乙、丙的两句预测逐个核。

* 组合排列的两种基本功就是这两样：条件确定用排除法，条件不确定用代入法；先把这两把基本功练熟，剩下交给熟练度。

## 代入排除法

* **代入排除法**

    * > **定义**：把选项当成已知代进题干逐条比对，只要跟题干里任何一条硬条件直接打架，这个选项当场死；四个全被砍光后剩下的那一个就是答案。

    * 操作序：读题干条件 → 挑一个选项 → 把选项当成已知代进题干 → 判断是冲突还是处处对得上。

    * 判定只需要一条硬条件：题干给了什么条件就拿这一条去撞选项，其他花里胡哨的东西一概不看。

    * 四个选项就是四条支路，每条支路拿题干去撞一次，撞出矛盾的那条当场剪掉，全剪完了剩下的那条就是答案。

    * > **注意**：这类题的重点从来不是"做得快"，是"你会这个思维"；会这个思维，慢一点也不丢分，不会这个思维，做得再快也是白做。

    ```text
            ┌──────────────┐
            │   读题干条件  │
            └──────┬───────┘
                   ▼
            ┌──────────────┐
            │  挑一个选项  │
            └──────┬───────┘
                   ▼
          ┌──────────────────────────┐
          │  把选项当成已知代进题干  │
          └────────────┬─────────────┘
                       ▼
            ┌─────────┴─────────┐
            │                   │
       跟某条硬条件打架     处处都对得上
       （这个选项出局）    （这个选项留下）
            │                   │
            └────► 换下一个 ◄───┘
                          │
                          ▼
                   四个全被砍光
                          │
                          ▼
                 剩下的那一个 = 答案
    ```

* **只对了一半**

    * > **定义**：一整句预测算一条，前半句后半句连在一起；对一半就是这一句话里对了一截、错了一截。

    * 判定：同一句里前后两半全错，就不是"只对了一半"，选项当场出局。

    * 例：甲说"一班第一个出场"错、说"二班第三个出场"也错，整句全错，选项出局。

    * 例：乙说"三班第一个出场"对、说"四班第二个出场"错，后半句错，选项同样出局。

    * 排除到只剩一个选项时，带进去验证人人一半一半即可，不必再看其他选项。

* **转岗题**

    * 题面：人事部张三、后勤部李四、综合办王五三人一起转岗。

    * 关键词不是"转岗"三字，而是"转岗"意味着转到别的岗位上去，人不能再留在原地。

    * 张三本来在人事部，所以不能还在人事部，相应选项直接否掉。

    * 李四本来在后勤部，所以不能还在后勤部，相应选项也否掉。

    * 末句"李四不去人事"与选项对着干的，排除。

    * 三个选项秒杀完，答案就是第四个，剩下的那个连分析都省了。

* **每人至少答对一道**

    * 题面：四位考生、三道题（松花湖、净月潭、天池），题干只有一条硬条件——每位考生至少答对其中一道题。

    * 条件越少越好代：带 A，第一位考生三道题全错，直接违反"至少答对一道"。

    * 带 B，前三位都还能凑出至少一道对，第四位考生三道全错，又违反条件。

    * 带 C，第一、二、三位各答对一道，第四位答对两道，四个人全都满足。

## 最大信息法

* **最大信息**

    * > **定义**：条件里出现次数最多的那个词。

    * 数法：先别动脑子，把条件里每个词拎出来，一个一个数一遍。

    * 机理：被提得最多的词身上的限定条件最多，很可能靠这几句就把它先解出来；它一解出来，后面的条件环环相扣全都能跟着松开。

    * 例（甲乙丙丁分别来自上海、北京、长春、杭州）：数出丙出现 3 次，是全场最多的词，推理从丙下手。

    * 例（张、王、赵、李各负责行政、销售、研发、安保之一）：行政出现 4 次（张不做行政、王不做行政、李不做行政、赵不做行政），安保只有 3 次，起点是行政。

    * > **易错点**：数词的时候一个一个数出来，别凭感觉；这一步看着最没技术含量，其实它是整道题的胜负手。

    | 条件里出现的词 | 出现次数 |
    | :--- | :--- |
    | 丙 | 3 |
    | 乙 | 2 |
    | 甲、丁 | 各 1 |
    | 北京 | 2 |
    | 上海、长春、杭州 | 各 1 |

    ```text
       一堆条件（还可能一句套一句）
                  │
                  ▼
         把条件里每个词拎出来数一遍
                  │
                  ▼
       ┌──────────────────────────┐
       │ 挑出被提得最多的那个词    │
       └────────────┬─────────────┘
                    ▼
            从它下手，先把它定死
                    │
                    ▼
          环环相扣，别的条件跟着松开
    ```

* **从最大信息出发的完整推导**

    * 起点是行政：张不做行政、王不做行政、李也不做行政，三个人全被排掉，只剩赵做行政。

    * 赵做行政，则赵做安保、赵做研发都不可能，两个选项先排掉。

    * 再补一刀：第三句是"如果……那么……"结构，翻译过来是"否定张做研发，推出否定赵做行政"。

    * 逆否等价：否张研发 → 否赵行政，等价于 **赵做行政 → 张做研发**。

    * 赵做行政已经证出，所以张做研发；说张做销售的选项被否，答案落在说张做研发的那个选项上。

    * 这题的重点不在计算，在于找没找到"行政"这个起点。

## 符号化：比较类条件写成大小号

* **符号化**

    * > **定义**：题里出现"谁比谁年龄大""谁成绩比谁好""谁的收入怎么样""谁的身高怎么样"这类比较类说法时，别在脑子里绕，直接写成大于号、小于号、等号。

    * 好处：哪个大、哪个小、哪个等于，写成符号后一眼就看出来了。

* **不同度量必须分成不同的线**

    * > **定义**：比较的时候把互不相关的度量分成不同的线分别列出，两条线谁也带不动谁。

    * 判断问句：毒副作用跟药效有关系吗？没有——既不成正比，也不成反比，是完全不同的两条线。

    * 例（甲、乙、丙、丁、戊、己六种药）：题干给"甲比乙有效""丙的毒副作用比丁大""戊的药效最差""乙的药效与己的药效相同"。

    ```text
       药效线：    甲 ＞ 乙 ＝ 己 ＞ 戊
       毒副作用线：丙 ＞ 丁
                 （两条线谁也带不动谁）
    ```

* **逐个选项核对**

    * A 说甲跟丁的药效相同——丁的药效题干压根没提过，提到丁的是"丙的毒副作用比丁大"，那是另一条线，推不出来。

    * B 说戊的毒副作用最大——毒副作用这条线里只出现了丙和丁，戊根本没出场，推不出来。

    * C 说甲的药效是最有效的——己、丙、丁、戊的药效一条都没参与比较，连它们排哪儿都不知道，推不出来。

    * D 说己比甲差——乙等于己、甲大于乙，那己当然小于甲，成立。

    * > **注意**：考试碰到"药效"和"毒副作用"同时出现，记住它们是两条不同的线，单独列，千万不要把它们弄混。

## 列表法

* **列表法**

    * > **定义**：对象和事情都是几个、且一一对应时，画表格一格一格去推、去打叉打勾，把"谁和谁还没对上"这件事直接摊在眼前。

    * 适用范围：四个人配四个职位这类题；表格本身就是一个非常好的方式，不用犹豫，比在脑子里记要靠谱得多。

* **教师招聘题的条件梳理**

    * 合格的教师有三个条件：责任心、知识、管理能力突出。

    * 甲乙丙丁四个大学生来应聘，四个人**至少符合其中一个条件**。

    * 合格的教师**只有一个人**。

    * 甲乙的管理水平相当；乙丙都有责任心；丙丁并非都有责任心。

    * 四个人中**三个人的责任心强**；**两个人的管理能力突出**；**一个人的知识丰富**。

* **突破口：唯一合格者即唯一知识丰富者**

    * "合格的教师有三个条件"和"只有一个人合格"不是废话，是知识那一栏的钥匙。

    * 合格的这个人本来就该具备那三个条件，所以唯一知识丰富的这个人，就是唯一合格的那个人，另外三个人的知识全都不丰富。

    * 责任心栏：乙丙都有责任心先打勾，丙丁并非都有责任心则丁没有，再加"三个人责任心强"，只能是甲乙丙三个都强。

    * 丁的责任心不行、知识也不丰富，而每人至少符合一个条件，所以丁只剩管理这一项，管理能力一定突出。

    * 管理栏：两个人管理能力突出，丁已占一个；甲乙管理水平相当，不能都突出，只能一起打叉。

    * 两个人里另一个只能是丙，于是丙责任心强、管理突出，知识那一栏也只能是丙——丙三项全中，甲、乙只中责任心，丁一项不中，只有丙合格。

    | 判断项 | 甲 | 乙 | 丙 | 丁 |
    | :--- | :--- | :--- | :--- | :--- |
    | 责任心 | 强 | 强 | 强 | 无 |
    | 知识 | 不丰富 | 不丰富 | **丰富** | 不丰富 |
    | 管理 | 不突出 | 不突出 | **突出** | 突出 |
    | 是否合格 | 否 | 否 | **是** | 否 |

    * 表读法：竖着看一列，三项全强的才叫合格，整张表里只有丙这一列是三项全中。

    * > **易错点**：填到一半走进死胡同出不来，不是笨，是有条件漏看了——回去再读一遍题干开头"合格的教师有三个条件"和"只有一个人合格"这两句。

## 一拖五

* **一拖五**

    * > **定义**：一个大题干，后面跟五个小题的题型。

    * 态度：这类题特别重要，肯定要做，不能说"这题我不做"；别怕，五个小题里一定有简单的。

### 题干翻译成符号

* **如果……那么……**

    * 第一句话"如果甲去黑龙江，那么乙去江苏"翻译成 `甲去黑龙江 → 乙去江苏`。

    * 看到"如果……那么……"一定要敏感，这是翻译推理的活；翻译推理是整个逻辑学的基础，不会它后面的东西一样都学不了。

* **只有……才……**

    * 第二句话是"只有……才……"，只有字后面是前、"才"前面是后，翻译成 `丁去云南 → 丙去福建`。

* **或者**

    * 第三句"或者"翻译成相容选言：`乙去江苏拍古建筑 ∨ 戊去福建拍人物`。

* **跟人话别**

    * 第四句"去江苏拍古建筑的大学生，临行前和乙、丁话别了"——跟人话别说明他不是那两个人，即乙和丁都没去江苏。

### 结论的传递范围

* **可用范围**

    * 大题干推出来的结论，后面所有小题都能用，因为它是从题干里来的，是这个大题无条件成立的。

    * 小题自己加条件推出来的结论，后面一律作废：第二个小题题干前面加了"如果"，加了"如果"得出的东西就不是大题干无条件成立的，下一小题再用就是越界。

    ```text
      大题干（无条件）──► 三个结论 ──┬──► 第二个小题：可以用
                                      └──► 最后一个小题：还可以用

      小题自己加的"如果……"──► 该小题的结论 ──► 后面一律作废
    ```

* **判定口径**

    * 结论能不能往下带，只看它是不是从"大题干"这一步无条件推出来的。

### 第一个小题：榨出三条结论

* **起点**

    * 题干里已经明确告诉我们乙、丁都没去江苏，就从这里出发。

* **三条结论**

    * 第一条：乙没去江苏，撞 `甲去黑龙江 → 乙去江苏`，否后推否前，得 **甲没去黑龙江**。

    * 第二条：乙没去江苏，撞 `乙去江苏拍古建筑 ∨ 戊去福建拍人物`，一端否了另一端必须成立，得 **戊去福建拍人物**。

    * 第三条：戊去了福建，`丁去云南 → 丙去福建` 的后件被否，否后推否前，得 **丁没去云南**。

    * 这个小题的用处不只是拿一道分，它是从大题干里榨出来的三条结论，后面几个小题全靠它们。

### 第二个小题：只能用大题干给的东西

* **把三条结论摆到桌上逐项对照**

    * B 说乙去福建——错，戊去福建了。

    * C 说丁去云南——错，丁没去云南。

    * D 说戊去黑龙江——错，戊去福建了；一个人一个地方，去了福建就不可能同时在黑龙江，别自己绕远路。

    * A 说甲去黑龙江——站得住：题干说的是甲去了黑龙江乙就得去江苏，现在乙没去江苏，反推不出甲一定没去黑龙江，所以"甲可以去了黑龙江"并没有被否定。

* **关键区分**

    * 条件句否定后件只能推出"甲必然没去黑龙江"，推不出"甲一定没去黑龙江"；"必然"和"可能"两说不能混。

### 最后一个小题：列表收口

* **先理出地点与题材的对应关系**

    * 这是题目直接给的：去黑龙江的拍风景，去云南的拍花卉，去江苏的拍古建筑，去福建的拍人物，五个地方五个题材一一对应，剩下一组就是西藏和野生动物。

    | | 黑龙江—风景 | 云南—花卉 | 江苏—古建筑 | 福建—人物 | 西藏—野生动物 |
    | :--- | :--- | :--- | :--- | :--- | :--- |
    | 甲 | × | | | | |
    | 乙 | √ | | × | | |
    | 丙 | | | | | |
    | 丁 | × | × | × | × | ？ |
    | 戊 | | | | √ | |

* **记号怎么打进去**

    * 乙去黑龙江拍风景，黑龙江这一列给乙打勾，其他人都打叉。

    * 甲没去黑龙江，甲这一行打叉；丁没去云南，丁这一行打叉。

    * 戊去福建拍人物，福建这一列给戊打勾。

    * 第四句别忘：乙和丁都没去江苏拍古建筑，乙和丁在江苏这列都打叉。

* **收口**

    * 丁在黑龙江、云南、江苏、福建四列全是叉；一个人一个地方，五个地方总得去一个，丁前四个都被排除了，只剩西藏。

    * 丁去西藏拍野生动物，答案落在说丁去西藏的那个选项上。

    * > **结论**：出题人在题目中的设置都是非常一环扣的，一定是能通出来的，别被这个纸老虎吓住；一道一道往上打叉，一整道题就通了。

## 学习方法

* 任何一门课程至少听三遍：听一遍是走马观花，就知道个大概，离你理解、离你能应用差了十万八千里。

* 听的时候觉得有点懵、有点跟不上，大概率不是内容的问题，是没做预习。

* 讲义提前看一看、做一做，带着答案和疑问进课堂，跟起来完全是两回事。

* 先自己做一遍、推一推，推不动了再回来听，听两遍；方法就这一个，别的花招没有。

## 组合排列的解题起点

   * **组合排列**

       * > **定义**：考场上两极分化的题型——出简单了，一道排除或一代入就解完；一旦出难，推理会变得比较复杂。

       * 复杂时的辅助手段是：先找起点，再列表格。

       * > **提示**：一定要做大量的练习来补充、巩固知识点；基础知识点听懂了就等于学会了，这一点不成立。

       * > **提示**：觉得自己课堂跟不上的同学一定要提前做预习；某一道没听懂，去听回放。

   * **最大信息法**

       * > **定义**：题干里被提及次数最多的那个对象，优先拿它当推理起点。

       * 排序类的条件直接写成符号：把大于号、小于号列出来。

       * 条件更复杂、眼睛看不太出来时，画个图、列个表来帮自己。

   * **翻译推理的复现**

       * 跑道这类题里同时出现了或关系、前推后、"如果……那么……"里的逆否命题、还有一个或命题，全部融合在一起。

       * 翻译推理是最开始讲的东西，是做推理的一个基础；不会它后面真的做不了。

## 逆否命题与跑道题推导

   * **逆否命题（否后推否前）**

       * > **定义**：把「A 导致 B」取否，得到「非 B 导致非 A」。

       * > **结论**：否后推否前，否前推否后。

   * **跑道题的起点**

       * 六个跑道、六个人，条件给了一堆，直接用大脑硬打不好弄，那就列个表、画个图，反正就六个。

       * 哪个条件被涉及得最多，谁就是起点。王伟被提了四次，次数最多。

       * 条件「王伟两侧是单数跑道」：1 号右边是 2 号为偶数不行；2 号两边是 1 和 3 都为单数成立；4 号两边是 3 和 5 都为单数成立；6 号左边是 5 号、右边没有跑道凑不齐不行。

       * > **结论**：王伟 ∈ {2, 4}。

       * 条件「张强两侧是双数跑道」：1 号左边没地方不行；3 号两边是 2 和 4 成立；5 号两边是 4 和 6 成立；6 号右边没地方不行。

       * > **结论**：张强 ∈ {3, 5}。

   * **逆否命题的用武之地**

       * 条件「钱亮在王伟和李明的中间」此时写不进表：王伟和张强的位置都还没定，中间哪儿也定不了，先放着。

       * 条件「王伟不在 2 号跑道」与第一条一碰，王伟就只能是 4 号。

       * 条件「张强在 3 号跑道 → 王伟不在 4 号跑道」是一条前推后；已知王伟就在 4 号，正好用上逆否命题。

         ```text
         张强在 3 号跑道   →   王伟不在 4 号跑道
         ──────────────────────  逆否：否后推否前
         王伟在 4 号跑道   →   张强不在 3 号跑道
         ```

       * 张强不在 3，就只能是 5，这两个人到这儿就都推完了。

       * 收尾：「李明和张强之间隔着两个跑道」——张强在 5，往回挪三个位置，李明在 2；「钱亮在王伟和李明的中间」——王伟 4、李明 2，中间那个 3 是钱亮；「刘平在单数跑道」——单数位 1、3、5 里 3 是钱亮、5 是张强，只剩 1；「孙心在双数跑道」——双数位 2、4、6 里 2 是李明、4 是王伟，只剩 6。

         ```text
         跑道号   1     2     3     4     5     6
         人  名   刘平  李明  钱亮  王伟  张强  孙心
         ```

       * 选项说刘平和孙心之间隔着四个跑道：1 和 6 中间正是 2、3、4、5 四个跑道，成立。

       * > **结论**：答案 A。

## 数字与性别先行型练习

   * **书架分类题**

       * 先把题干直接给的几个位置填进去。

         ```text
         1 号   历史书
         3 号   历史书
        10 号   历史书
         4 号   科技书
         ──────────────────────────
         剩下的空位：2  6  7  8  9   （共五个架子）
         ```

       * 科技书共两本且要求连号排列，4 号已是一本，它的连号伙伴只能是 3 号或 5 号，3 号已经是历史书，所以另一本科技书落在 5 号。

       * 剩下的空位 2、6、7、8、9 一共五个，而文学书四本、儿童书一本，即四个放文学、一个放儿童。

       * 儿童书跟科技书连号：科技书在 4、5 号，能与之连号的空位只有 3 号和 6 号，3 号已是历史书，所以儿童书只能在 6 号，2、7、8、9 全放文学书。

       * > **结论**：儿童书一定在 6 号架，答案 C。

   * **兄弟姐妹排序题**

       * 甲说丁是最小的妹妹——丁是四个人里最小的。

       * 乙说兄弟姐妹当中只有一个男孩、是哥哥——既然只有一个男孩，乙自己一定是女孩；那个男孩是甲还是丙还不知道。

       * 丙说自己是甲的姐姐——丙是女的，那么唯一的男孩就一定是甲。

       * 甲是乙和丁的哥哥，所以甲比乙、丁都大；丙是甲的姐姐，比甲大；丁最小。

         ```text
         丙（甲的姐姐） > 甲（唯一的男孩、哥哥） > 乙（女孩） > 丁（最小的妹妹）
         ```

       * 看选项：丙排第二错，乙排第二也错，甲排第二没问题，乙排第三没问题。

       * > **结论**：从大到小为丙、甲、乙、丁，答案 C。

## 自由度过大时改用代入排除

   * **三人五项工作**

       * 条件：三个人、五项工作（人事、管理、网络、财务、教育），每人至少完成一件，每项工作只能由一个人来做；人事和管理都不是王丽完成的；丁勇做人事 → 李明做财务；完成教育工作的人至少还要完成一项其他的工作。

       * 列表只能打出人事、管理两个叉，别的干不了——自由度太大，可能的情况也太多。

       * 「丁勇做人事 → 李明做财务」是一个条件命题、是一个"假如"，会不会真实发生不一定，所以先放着写不进表。

       * 问题问的是"以下哪项不可能由丁勇来完成"，四个选项里有三个其实都可以，只有一个是错的。

       * > **结论**：条件不确定的时候，优先用代入排除。

   * **代入对象怎么挑**

       * A、B、C、D 不能瞎带、不能从前往后带、更不能挨个试，优先带 B 或者 C。

       * 因为 B 和 C 里都有一个人事，而第三条条件正是"假如丁勇做了人事，那么李明做财务"，代进去这句话里的两半都用上了；条件用得越多，表里填得越死，越好解。

   * **代 B 之后的冲突**

       * 先代 B：丁勇完成网络和人事。× = 确定不做，√ = 确定要做，? = 还没定。

         ```text
                 人事   管理   网络   财务   教育
         王  丽    ×      ×      ×      ×      √
         李  明    ×      ?      ×      √      ?
         丁  勇    √      ?      √      ×      ?
         ```

       * 丁勇做了网络，王丽就不能做网络；李明做了财务，王丽就不能做财务；人事和管理本来就不是王丽的——一排下来王丽只剩教育一格。

       * 第四条摆在那儿：完成教育工作的人至少还要完成一项其他的工作。王丽只做了教育，凑不出第二件，冲突。

       * > **结论**：B 这个选项不可能成立，问的正好就是"不可能"，答案 B。

       * > **提示**：它没有想象中那么难，只要用正常的思维去做，出题人一定给你留好了整个推理逻辑，按正常人的思路走肯定能做出来。

## 比较大小题

   * **先把条件翻译成符号**

       * 王东比董强的分数低 → 董强 > 王东。

       * 赵梅比吴平（萍）的分数高 → 赵梅 > 吴平。

       * 王东跟赵梅得分一样 → 王东 = 赵梅。

   * **能串成串的串起来**

       * 前三条能把董强、王东、赵梅、吴平串成一串。

         ```text
         董强  >  王东  =  赵梅  >  吴平
         ```

       * 剩下那条比较关系说的是另外两个人，跟这条链上的人一个都不重合，插不进来，具体在哪个区域不清楚。

       * 凡是牵扯到那两个陌生人的选项，一律先排除。

   * **串上逐项判定**

       * A 说王东比吴平低——王东 = 赵梅 > 吴平，王东比吴平**高**才对，A 错。

       * D 说董强 > 吴平——这一条链上已经明明白白写着，成立。

       * > **结论**：答案 D。

## 日常结论的题干形态

   * **日常结论**

       * > **定义**：关联词缺席的题干给现象，选项给结论；能选的是从现象里顺推得出来的那一个。

       * 题干没有条件关系：没有"如果……那么……"，没有"只有……才……"，没有"或""且"这些逻辑关联词。

       * 题干整体给的是日常生活中的一些现象、一些理论，然后问能不能推出某个结论来。

       * 有点像言语题：没有典型的逻辑关联词，最后问的也是"你能推出什么、不能推出什么"。

       * 这一类题其实比较简单：没有关联词，只要通过题目里给的现象得出一个结论就完了。

## 选题的松紧尺度

脑子里要有三根弦，先放一张速查表：

| 类别 | 常见信号 | 怎么判断 |
| :--- | :--- | :--- |
| 不选 | 因果的方向反了，A 导致 B 写成 B 导致 A | 逻辑错误 |
| 不选 | 题干没提，选项里凭空多出来 | 无中生有（约占错误选项的 90%） |
| 不选 | 题干一个说法，选项偷换成另一个近似说法 | 偷换概念 |
| 慎选 | 谁比谁、越……越…… | 比较类，盯方向和范围 |
| 慎选 | 一定、必须、只要、肯定、只有、才 | 绝对词，大概率是错的 |
| 慎选 | 最、极、狠 | 程度词太霸道 |
| 慎选 | 狼虎吃肉 → 哺乳动物都吃肉 | 范围扩大 |
| 优选 | 可能、有的、有些 | 委婉，留有余地 |

### 不选

   * **逻辑错误**

       * > **定义**：题目中说 A 导致了 B，选项里变成 B 导致了 A。

       * 因果反了就是典型的逻辑错误，肯定不能选。

   * **无中生有**

       * > **定义**：题目中压根儿就没提，选项里你自己给脑补了一个。

       * > **结论**：这一类里几乎 90% 的错误选项都是无中生有。

       * 这是最最常犯的错误，很多人拿自己有限的生活常识去脑补这件事。

       * > **易错点**：只通过题干给的内容做推导；题干没给，再合理也不选。⚠️

   * **偷换概念**

       * > **定义**：题干一个说法，选项偷换成另一个近似说法。

       * 例子：历史老师问"你是怎么认识李鸿章这个人的"，他想听的是你**评价**这个人、你是怎么**理解**他的；答"我不认识李鸿章"，说的却是"有没有见过他、有没有跟他交往、有没有跟他正式握过手"。

       * 我见没见过他，和我怎么看他，是两码事；辩论赛里的一些诡辩、狡辩也是这么干的。

       * > **提示**：遇到偷换概念，一定要盯住题干里那个词到底是什么意思，别被选项里换了个说法的同一个词骗过去。⚠️

### 慎选

   * **比较类**

       * 说谁比谁、越怎么样、越怎么样的选项要慎选，盯的是方向和范围。

   * **绝对词**

       * 一定、必须、只要、肯定、只有、才，这种非常绝对性的词，遇到了就顿一顿、想一想。

       * > **易错点**：不说它一定是错，但大概率可能是错。

       * 中国说事情一直讲中庸，一般希望把事情说得圆滑一点、平滑一点，不要太绝对，绝对词一出来就得小心。

   * **程度词**

       * 最、极、很、狠，这种程度比较霸道的词，都要小心。

   * **范围扩大**

       * 题目里说狼、虎都是食肉的、都是吃肉的，选项里来一句"哺乳动物都是吃肉的"——这就有了问题：狼和虎吃肉没问题，但哺乳动物还包含了牛、羊之类。

       * > **提示**：范围扩大也不是百分之百错，但一定要小心。

### 优选

   * **模糊词**

       * 看到"可能""有的""有些"这些词，优先选。

       * 道理跟绝对词一样：希望说话更委婉、更圆滑、不得罪任何人。公务员未来跟老百姓打交道也要处理得更圆滑，不能天天跟百姓较真。

   * **松紧度口诀**

       * 绝对词、程度词往边上放一放，模糊词往上提一提。

## 日常结论例题拆解

   * **车辆失窃题**

       * 现象：黑色、灰色是盗贼最喜欢的颜色，亮色系（比如白色）失窃率最低；新款豪车最为畅销，3 年左右的大型车型保值、好转手。

       * 题干里没有"如果……那么……"之类的关联词，就是给了日常现象让人推结论。

       * A、B、D 三个选项都出现了"最"字。

       * > **易错点**：看到"最"字就要小心一点，大概率都是错的。⚠️

       * A：3 年车龄的红色车最容易被盗。题干说的是黑色、灰色是盗贼最喜欢的，颜色就不是红色，肯定不对。

       * B：暗色系在二手车市场最为畅销。题干压根儿没提谁"最为畅销"——提畅销只说的是新款豪车、3 年左右的大型车型。

       * C：崭新款的白色豪华车最不容易被盗。题干说黑灰是盗贼的最爱、亮色系失窃率最低，C 又限定了崭新款和豪华，题干给的都给足了。

       * > **结论**：答案 C。

   * **记忆偏差题**

       * 现象：得高分的记忆更容易被记住，得低分的难以被想起。

       * B：人们最擅长遗忘的是**细节**。题干里提到"细节"这个词了吗？没有，无中生有。

       * C：提到了"公平正义的信念"吗？没有，无中生有。

       * D："错误的记忆让我们自我感觉良好""有利于健康"——提到了吗？都没有，无中生有。

       * A：我们记忆中的成绩**可能**比真实的成绩更优秀。得高分（得 A）的那些总能够想起来，得低分（得 F）的却难以被想起。

       * > **结论**：答案 A，而且这个选项说得非常严谨——它用了"可能"，没有说"一定"。

   * **久坐与癌症**

       * 现象：女性久坐会导致患结肠癌的风险增加、患子宫癌的风险增加等等；题干还专门交代了一句——**无论研究对象在工作时有多活跃，都不会影响这个结果**。

       * A：缺乏运动可能是某些癌症的**首要病因**。"首要病因"哪儿提了？这里只说久坐会使风险增加，仅仅是增加你患病的风险，可不是这个病的首要病因，完全不同的两回事。

       * B：久坐可能对女性健康造成不良的影响。都增加患癌的风险了，当然是造成不良影响了。

       * C：很多同学可能会选 C，但这个 C 千万不要脑补，选 C 的同学一定是脑补的；题干那句"无论工作时有多活跃都不影响这个结果"恰恰是对 C 的削弱，既然题干自己在削弱它，C 就更不用看了。

       * D：上班族女性的身体状况堪忧。一是上班族女性一定是久坐的女性吗？不一定——去银行做前台、做大堂经理，一站就是一天；二是"身体状况堪忧"题干什么时候说过？只说患结肠癌的风险增加了一些。

       * > **结论**：答案 B。

       * > **提示**：平时少做、多站、多运动、多走一走；有条件就站着听课，这本身也是在避免久坐。

   * **极地二氧化碳**

       * 现象：题干给出的是南极与北半球的二氧化碳浓度数据，南极的二氧化碳浓度已经升到那么高。

       * A：人类的活动对地球的影响已经深入到了极地——这就是人类活动的影响，说明影响已经深入极地。

       * B：谈的是南极的地貌。题干里压根儿没提地貌，错。

       * C：说以后不会再降了。题干只是说现在升高到了，凭什么说不会再降，推不出来。

       * D：北极的二氧化碳早就远超了南极。题干给的是**北半球**，北半球能跟北极划等号吗？北半球是整个北半球、平均完了之后的，这里只说了北极一个点，北极是多少根本就没提，你也估不出来。

       * > **结论**：答案 A。什么叫北半球、什么叫北极，这是完全不一样的两个概念。

## 日常结论练习拆解

   * **重度抑郁与中风**

       * 现象：一万名没有中风史的人里，如果你有重度抑郁，患中风的风险增加一倍；没有抑郁的没什么事；**曾经**有过重度抑郁的，即使后来缓解了，这个风险仍然没有变化，仍然和重度抑郁的人一样。

       * A：重度抑郁极有可能演化成中风。题干提到这个了吗？只是说之前的风险可能很小、现在在很小的风险上增加了一倍——**"有风险"和"极有可能演化成中风"，这是两码事**。

       * B：中风患者中患抑郁症的几率也比较高。方向说反了、倒置了：你患重度抑郁会让中风风险增加，不等于说中风患者里就有很多是抑郁来的。

       * C：正在患有、或者曾经患有重度抑郁的人，都是中风的风险因素。说"正在患有"，题干说风险增加了一倍；说"曾经患有"，题干说风险和重度抑郁的人一样，两头都给足了。

       * D：抑郁和中风是老年常见疾病、经常一起发病。提到了吗？没有，无中生有。

       * > **结论**：答案 C，人家说得非常准确，没有给你任何逻辑漏洞。

   * **某市恶性肿瘤**

       * 现象：该市恶性肿瘤的发病率和死亡率相当于欧美等发达国家和地区的**三分之二和四分之三**；平均寿命从 38 岁变成 82 岁；50 年前导致该市人口死亡的主要疾病发病率目前没有降低。

       * A：这类疾病并不是造成目前该市人口死亡的主要原因。无中生有，题干里压根儿没提"主要死亡原因"这件事。

       * B：该市对恶性肿瘤的治疗水平是全国最高。也没提，"治疗水平"这件事整个题干里都没有出现过。

       * C：说"近 50 年间治疗水平一定提高了"要排除，有两点——第一，题干里压根儿没提过"治疗水平"；第二，选它的人脑补了一条心路历程：50 年前主要疾病发病率没降低、平均寿命却从 38 岁变成 82 岁，所以推测治疗水平一定提高了。⚠️

       * D：该市肿瘤的总体发病率和死亡率，比欧美等发达国家和地区低。题干里明明白白写着三分之二和四分之三，既说了发病率也说死亡率，既说了该市也说了欧美等发达国家和地区，严丝合缝。

       * > **结论**：答案 D。

## 日常结论的判断原则

### 只认题干，不做脑补

   * **题干给结果反推原因**

       * > **定义**：题干给出一个结果、让你往回推原因时，这个结果可以由很多个原因共同产生，不能因为其中某一项变了就断定结果一定是它造成的。

       * 人均寿命从古代的三十多岁提高到 82 岁，原因可以列很多条：打仗、饿死、身体条件差、主要的疾病发病率高。

       * 打仗、饥饿、身体条件三项都改善了，而主要的疾病发病率保持不变，人均寿命 82 依然成立。

       * 一个结果背后可以挂着很多条并列原因，任何一条不变，结果都可能照样成立。

   * **说得对不等于能选它**

       * 选项本身是否符合生活常识，与它能否被选中无关；只要不是材料能推出的就得排除。

       * "任何东西过度饮用都会给身体健康造成不良影响"这句话本身没错，连常被认为无毒的水也一样；但材料没提"过量饮用"，在本材料中就是无中生有。

       * 出现争议类选项时不较真，通过排除选一个最优的，这题就结束。

   * **只使用题干信息**

       * 逻辑题最常见的错误就是自己给自己添东西；除了题干以外的东西一律不要去想，脑补出来的东西还不一定对。

       * > **易错点**：逻辑只需要通过题干来做，题外的常识、经验、联想都不作为判断依据。

### 选项越出题干边界的四种形态

   * **"容易引起"被读成"就是它造成的"**

       * 题干说某因素容易引起疾病，只说明疾病可能由它引起，不等于疾病就是由这个因素造成的。

       * 老年痴呆最主要的病因是年龄变大、身体不行；该病不可逆，病因至今没有研究透，只有 β-淀粉样蛋白等几种假说，都没有证实。

       * 引起某疾病的因素非常多时，"仅仅是过量摄入某单一元素造成的"这种片面说法推不出来。

       * 针对老年痴呆的药物研发之所以至今没有成果，与药物上市需经过一期、二期、三期临床和毒性实验等一整套流程、临床结果常与动物实验不符有关。

   * **题干没提的要素被选项自行加上**

       * 题干说铝既能溶于酸又能溶于碱、是人体维持正常运作所需要的微量元素，对应结论是铝为人体必需元素。

       * 题干只说"过量的铝可能引起老年痴呆"，没有说"很容易超标"，选项不能自行加上"超标"；是否容易超标取决于用什么器具盛装饮食。

       * 题干完全没有提烹饪器具与隔夜菜，"红烧肉不能隔夜吃"无从推出。

   * **"受影响"被读成"哪种条件最好"**

       * 材料说橙汁的生物效应受成分影响、成分随气候、土壤、水果成熟度和采摘后的存储方式变化，可以推出"并非所有橙汁都有相同的防癌功能"。

       * 材料从未说过哪种气候、土壤条件最好、哪种保存方式最优，"生于良好气候土壤条件、成功避光保存的橙子最有效"是无中生有。

   * **"降低风险"被读成"患病原因"**

       * 材料只说饮用橙汁与降低某些患病风险相关、减少风险。

       * 降低风险不等于造成患病；癌症的致癌风险非常多，甚至红肉都已被归为致癌物，只因没喝橙汁就致病讲不通。

## 题干本身不严谨时的处理

### 遇到略有问题的题

   * **出题方式决定了信息不完整**

       * 学术论文摘取要点出题，只保留几句话，甚至没有明确数据，因此两组志愿者情况没有详细说明。

       * 两种脑力活动本身到底有没有体能消耗没有说清楚；血压、耗氧量、心排血量等生理指标是实时监测还是结束后才测也无法得知。

       * 处理方式是理解他想说什么、把答案选出来，不要跟他较真、较这个真儿。

   * **题干不严谨对练习无益**

       * 真实论文原文几千字会对每个点详细介绍、不给漏洞，出题人只能摘取关键点，这才是漏洞的来源而非逻辑错误。

       * 例题和真题中不严谨的地方，做判断推理时大概能理解意图即可。

### 耐力测试一题的选项取舍

   * **研究范围之外的不是结论**

       * 选项"玩益智游戏和看电视消耗的体能相同"不在研究范围内：题目没监测这两种脑力活动的体能消耗，"体能"指的是耐力测试过程中的，研究的是脑力活动对后面体力活动的影响。

       * 题干说的生理指标无显著差异，指的是耐力测试过程中的，不是两种脑力活动之间的消耗对比。

   * **实验前提不是结论**

       * 选项"两组志愿者之间的体能素质十分接近"是必须控制好的变量、是实验的基本条件，属于前提而不是推出来的结论。

       * 严谨的论文里两组志愿者年龄、性别、体力等方面应无显著差别，不可能完全一样但要尽可能无显著偏差；研究的变量只有脑力活动一项，两种活动都是脑力活动，其他条件尽量相同。

   * **正确答案与无中生有**

       * 结论是不同脑力活动对体力活动的影响只是造成感觉上的偏差：第一组玩益智游戏，蹬着蹬着觉得"我不行了"就放弃；第二组看跑车纪录片处在运动氛围里，觉得"还能再坚持一会儿"。

       * 选项"体力活动激发脑力劳动者的潜能"题干里根本没有"激发潜能"这回事，属无中生有。

## 逻辑论证：占比最大的题型

### 题型地位与考察点

   * **分值占比**

       * 逻辑判断十来道题里，逻辑论证一般占六到七道，占比太大。

       * 逻辑论证分两类题型：加强和削弱；加强就是赞同，削弱就是反对。

   * **考察的能力**

       * 考的是能不能通过大量数据得出一个准确的结论、结论推得严不严谨、有没有一个正常的论证思维。

       * 做实验、写论文、得出结论的过程本身就是论证；有生物、化学、物理、医学等研究经历的人正确率可保在 90% 以上，没有实验经历的人用正常人的逻辑思维也能做好。

## 论证三件套

### 三个要素的定义

   * **论点（又称论断）**

       * > **定义**：论点就是真实性需要加以证实的判断，即作者持有的观点、对所论述问题提出的见解、主张或态度。

       * 例："某主播是一个良心主播""某药可以治疗肺炎""某人长得很帅"都是表达的见解、主张或态度。

       * 三个要素中论点最重要，它是整篇最后得出的结论，拿到一篇论文先看论点。

   * **论据（证据）**

       * > **定义**：为论点准备的根据，是证明论点的事实和道理；不能白说论点，前面要有一大堆东西才得出结论。

       * 事实类：具体事例、亲身经历、概括出来的事实、统计数字；公务员考试里主要都是事实类。

       * 事实类论据的典型链条：细胞培养与细菌培养发现能杀灭肺炎链球菌 → 喂给有肺炎的小鼠病好了 → 喂给有肺炎的大猩猩也好了 → 临床喂给真正生病的病人肺炎也好了，大量实验数据就是论据。

       * 道理类：被长期证明过、被检验过而断定为正确的观点，如经典著作、权威言论、自然科学的原理定律公式（牛顿第一定律、第二定律、欧姆定律、自由落体）。

   * **论证（隐含的推理）**

       * > **定义**：从论据到论点之间没说出口、但真实存在的推理环节。

       * 论证一般情况下不出现、不说出来，却是真实存在的。

### 隐含论证的常见形态

   * **全称判断式**

       * 由"某人五官端正"推出"某人很帅"，隐含的是"所有五官端正的人都很帅"。

       * 由"免费讲课、免费送讲义"推出"是良心主播"，隐含的是"所有免费讲课、免费送讲义的老师都是良心主播"。

       * 由"工作稳定"推出"职业理想"，隐含的是"所有稳定的工作都是理想的职业"；稳定的依据是工作与工资稳定、不犯大错不会被开除、工资属当地中等偏上水平、女性生育后无职业危机。

   * **多步链条式**

       * 由"药物能杀死肺炎链球菌"推出"可以治疗肺炎"，隐含的是"肺炎链球菌是引起肺炎的主要原因"和"所有能杀死肺炎链球菌的药物都可以治疗肺炎"。

       * 这种论证会略微复杂，不是一句简单的话，但能感受到它是什么。

## 削弱与加强：三处下手

### 削弱：像老师改论文一样挑毛病

   * **论文类比**

       * 把论文交出去，老师挑毛病的落点正好是论点、论据、论证三个要素。

       * 削弱就是在论点、论据、论证这三处的任意一处做文章；三个要素里任何一处做得不够好，都能削弱整篇论文。

   * **第一刀：挑论点**

       * 直接否结论：已有实验证明该成分其实没有延缓衰老这个功能。

       * 同一议题存在完全相反的两种声音：有论文证明抗氧化性与衰老有关，也有论文证明无关、甚至成反比例关系，论点因此不靠谱。

   * **第二刀：挑论据**

       * 质疑数据来源：这些数据感觉都是编的，自己做都做不出来。

       * 质疑实验数量：抗氧化的切入点很多，只做了一个清除自由基的实验，实验太少、论据不充分，要补实验。

       * 质疑统计方法：显著性分析不行，显著性不够显著，数据不严谨，要重做实验。

   * **第三刀：挑论证**

       * 否定论据到论点的桥：抗氧化跟延缓衰老没有关系，两者不是一回事。

       * 桥没搭上，论据和论点都再对也推不出结论。

### 加强：把三处补回来

   * **对应三刀的三种改法**

       * 论据不行 → 重新做实验、补充论据，实验有问题就更正，再多做一些、再解释一些内容以增加论据。

       * 中间联系不紧密 → 增加一个搭桥动作，把这座桥搭上去、让它更好用，在两个概念之间建立起联系。

       * 论点错了 → 更正自己的论点。

   * **加强的本质**

       * 加强就是把削弱的三处逐一补回来，让论文更严谨，与削弱是同一套写论文思维的正面与反面。

## 快速找论点

### 四种定位方法

   * **抓总结性关键词**

       * 论点是一个总结性的语句，关键词有：因此、所以、认为、推出、由此可知。

       * 例：材料里"有人认为这是海水升温导致的"，真正的论点是该鱼类的生存面临巨大挑战，是海水升温导致的。

   * **看首句或末句**

       * 总结性的结论通常落在材料的开头或结尾，要么第一句，要么最后一句。

   * **转折之后表重点**

       * 例："虽然现在还不能确认楼市完全复位，但是……未来楼价调控的压力还是很大的"——"但是"之后的末句才是论点。

   * **结合选项，问啥找啥**

       * 题干问"最能支持赫希尔的推测"，就直接去找赫希尔的推测：火星上有智慧生命。

       * 不要把所有选项都看一遍，题干问什么就去找什么。
