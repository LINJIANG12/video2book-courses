# 真假推理：矛盾关系与反对关系

## 题型识别与考频

* **真假推理**

    * > **定义**：论述中既有真话又有假话，而且真假情况事先不确定，必须从「只有一个人说真话」这类限制条件里把真假硬逼出来。

    * 两个条件要一起看：只有「有真有假」而真假已摆在明面上，就没有推理的余地；正是因为「不知道谁真谁假」，题目才逼着人从限制条件反推。

    * 真假推理是判断推理的收尾题型，考完这一节整个判断推理结束。

* **矛盾命题**

    * > **定义**：互为矛盾的一对命题，非此即彼，必定一真一假、一对一错。

    * 矛盾关系就是突破口：矛盾对里必有一真一假，可以把「唯一的那句真话（或假话）」锁死在矛盾对内。

* **考频**

    * 国考已很久没出，近五六年只出现过一道（2018 年），明年出不出不确定。

    * 其他省份、其他考试考得相对多一些，一般最多一道，约每十个逻辑判断里一道。

    * 考频不高但几乎必考，原因是这类题解题动作极省时间。

## 标准解题动作

* **四步法**

    * **找矛盾**：优先找矛盾，找到矛盾对就等于拿到了突破口；这一组先吃透矛盾关系。

    * **锁位置**：矛盾之外还有「反对」关系可以找，反对关系另行单独讲；只有一句真话就把那句真话圈进矛盾对，只有一句假话就把那句假话圈进矛盾对。

    * **判其余**：矛盾之外的句子真假全部同侧——一句真话时它们全假，一句假话时它们全真。

    * **顺推**：其余几句真假已经定死，把确定为真的句子当条件往选项上推。

    * > **易错点**：真正的难点从来不在第三步、第四步，而在第一步找矛盾；矛盾关系没找出来，后面全盘皆输。

* **动作链**

    ```text
      找矛盾      互相矛盾的两句话，必定一真一假
         │
         ▼
      锁位置      只有一句真话 ⇒ 真话锁在矛盾对里
         │        只有一句假话 ⇒ 假话锁在矛盾对里
         ▼
      判其余      矛盾之外的句子，真假全部同侧
         │
         ▼
      顺推        把确定为真的句子当条件，往选项上推
    ```

    * 矛盾对里到底哪句真、哪句假，很多时候根本不用判，也判不了；只要知道「假话落在周郑之间」，就等于同时知道了「吴、王都是真话」，这已经够推。

## 四组矛盾关系

* **A 与 非A**

    * 「甲拿的」与「甲没拿的」，一真一假，是最简单的一组。

    * 两道四人对话的基础题用的都是这一组，所以表面上看最简单。

* **A 且 B 与 非A 或 非B**

    * 且关系的矛盾就是德摩根定律。

    * 「周一上班并且周二上班」的矛盾是「周一不上班**或者**周二不上班」。

    * > **易错点**：⚠️ 矛盾那一句是「或」不是「且」，字眼千万别看错。

* **A 推 B 与 A 且 非B**

    * 推导关系的矛盾，四组里最重要、也最容易卡住的一组，很多同学拿到就懵。

    * 证伪方式：让前件真的发生、而后件不成立，原命题即被推翻。所以 $A \rightarrow B$ 的矛盾是 $A \wedge \neg B$。

    * 例证：「如果下雨，我就不上班」被证伪的情形就是下雨了，但本人还是跑来上班了。

    * 例证：「如果他好了，那我就好」的反例同样是——他好了，但我没好。

    * 真题手感：「如果李明当教练，那么王芳就要当领队」，李红说「我不同意」，其含义就是 $A \wedge \neg B$，即李明当教练但王芳没当领队。

    * > **易错点**：⚠️ 结构永远是「前件照常成立、后件被推翻」，前件一定要保留；把前件也一起否掉就不是在否定原命题，而是自己另起炉灶。

* **所有是与有的非**

    * 这一组相对更难理解，其实包含两对，本质是同一件事。

    * 「所有人都及格了」——假设班里十个人——它的否定可以是：只有一个人不及格、有几个不及格（两三个到八九个都行）、所有人都不及格；这三句合起来就是「有的不及格」。

    * 「所有人都没上岸」的否定同样有三句：有一个上岸、有几个上岸、所有人上岸；合起来就是「有的上岸」。

    * 把前后都否定一遍得到第二对：「所有非」的矛盾是「有的是」。

    * 四组矛盾必须练到条件反射。

## 主体一致的前提

* **研究主体必须一致**

    * 硬性前提：判定矛盾关系时，研究的主体必须一致，否则不构成矛盾。

    * 反例：「我没考上 100 分」与「全班人都考了 100 分」不是矛盾关系。

    * 错在主体不同：第一句主体是「我」一个人，它的矛盾命题应是「我考了 100 分」；第二句主体是「全班人」，讨论对象根本不是一回事。

    * 「全班人都考了 100 分」是「所有是」，它的矛盾是「有的人没有考 100 分」。

    * > **注意**：「所有是」里的「所有」指全班，「有的非」里的「有的」也指全班，即全班人当中有的没考 100 分，主体仍然是全班，这才是一对真矛盾。

    * 想明白这一条，四组矛盾就真的搞定了。

## 真题实战

### 一句假话在四人之间

* 例一：有且只有一个人登上过卓奥友峰，周、吴、郑、王各说一句话，四人中只有一个人说了假话。

| 说话人 | 原话 | 翻译 |
| :--- | :--- | :--- |
| 周 | 登上卓奥友峰的是郑 | $郑$ |
| 郑 | 我没有参加过 | $\neg 郑$ |
| 吴 | 我参加了那次活动，但是没有登顶 | $\neg 吴$ |
| 王 | 我是吴的候补队员，如果吴没有登顶，那么我就登顶 | $\neg 吴 \rightarrow 王$ |

* 周与郑是 $郑$ 与 $\neg 郑$ 这组矛盾，必有一真一假；唯一的假话只能落在这对里，于是吴、王两句都是真话。

* 吴真得吴没登顶；王真得 $\neg 吴 \rightarrow 王$ 前件成立后件跟着成立，故王登顶。

* 答案 D：王登上了卓奥友峰。

### 一句真话在四人之间

* 例二：四个人抢一个白球，甲说我没拿白球，乙说是丁拿的，丙说乙拿的，丁说白球不是我拿的；只有一个人说了真话。

| 说话人 | 翻译 |
| :--- | :--- |
| 甲 | $\neg 甲$ |
| 乙 | $丁$ |
| 丙 | $乙$ |
| 丁 | $\neg 丁$ |

* 乙与丁又是 $丁$ 与 $\neg 丁$ 的矛盾，必有一真一假；唯一的真话落在这对里，于是甲和丙两句都是假话。

* 甲的话「我没拿白球」是假话，其反面即：甲拿了白球。答案 A。

### 鱼类资源与环境破坏

* 例三：四句话如下，四人中只有一个人说错了。

| 说话人 | 原话 | 翻译 |
| :--- | :--- | :--- |
| 甲 | 有的地方鱼类资源枯竭了 | $有的枯竭$ |
| 乙 | 如果领导不重视，那么该地的环境就遭到了破坏 | $\neg 重视 \rightarrow 破坏$ |
| 丙 | 不存在鱼类资源枯竭的地方，也不存在环境遭到破坏的地方 | $\neg 枯竭 \wedge \neg 破坏$ |
| 丁 | 不存在鱼类资源枯竭的地方 | $所有非枯竭$ |

* 甲与丁是「有的非」对「所有是」，正是第四组矛盾，必有一真一假；说错的那句在他俩之间，于是乙、丙两句都是真话。

* 丙真得不存在环境遭到破坏的地方，即环境没被破坏；乙真为 $\neg 重视 \rightarrow 破坏$，两句一对，否后推否前得领导重视。

* 答案 D：领导重视。

* > **易错点**：⚠️ 丙句里的「不存在」不是「只有……才……」，它没有条件词，不是一个推导句，而是两句话并列，既没有枯竭的地方也没有被破坏的地方；硬要按后推前去翻译才是真读错了。

### 选拔中的真话与假话

* 例四：四句话如下，四人中只有一个人说的是真话。

| 说话人 | 原话 | 翻译 |
| :--- | :--- | :--- |
| 第一句 | 小王会被选上 | $王$ |
| 第二句 | 如果小王被选上，那么小张就不会被选上 | $王 \rightarrow \neg 张$ |
| 第三句 | 只有小张被选上，小王才会被选上 | $张 \rightarrow 王$ |
| 第四句 | 小王和小张都会被选上 | $王 \wedge 张$ |

* 矛盾在第二句和第四句：第二句是 $王 \rightarrow \neg 张$，第四句拆开是 $王 \wedge 张$，前件一样、后件正好相反，正是 $A \rightarrow B$ 与 $A \wedge \neg B$ 这组矛盾。

* 真话锁在二、四之间，于是第一句和第三句都是假话。

* 一假得 $\neg 王$，即小王没被选上；三假的含义是 $张 \rightarrow 王$ 的否定 $张 \wedge \neg 王$，即小张被选上、小王没被选上。

* 答案 D：小张被选上，小王没被选上。

* > **易错点**：⚠️ 这里一定要一眼看出第二句与第四句的矛盾，看不出来这题是解不了的。

### 捐款中的真话与假话

* 例五：林川说我没捐；郑说是吴非捐的；吴非说是郭博捐的；郭博说不是我捐的。四人中只有一个人说了真话。

* 翻译为 $\neg 林川$ / $吴非$ / $郭博$ / $\neg 郭博$。

* 第三句和第四句是 $郭博$ 与 $\neg 郭博$ 的矛盾，真话一定落在他俩之间，于是林川和郑那两句都是假话。

* 林川说「我没捐」是假话，即林川捐了。答案 B。

### 谁说了真话

* 例六：陈华说我在家做作业；刘刚说我没在家做作业；王明说陈华没在家做作业。三句中只有一句是真话。

* 翻译为 $陈$ / $\neg 刘$ / $\neg 陈$。

* 陈华与王明是 $陈$ 与 $\neg 陈$ 的矛盾，真话锁定在他俩之间，那么刘刚那句必为假——刘刚在家做作业。

* 背景条件是星期日只有一个人在家做作业，这个人只能是刘刚，陈华和王明都不在家；于是陈华那句是假话，王明那句「陈华没在家做作业」就是真话。

* 答案：说真话的是王明。

## 觉得难的两个原因

* **翻译推理不过关**

    * 「如果……那么……」「只有……才……」的前推后、后推前翻译不干净，一上手就错。

    * 例证：例四第三句「只有小张被选上，小王才会被选上」翻译为 $张 \rightarrow 王$，用的正是后推前。

    * 在真假推理里出岔子，往往不是真假推理的问题，而是翻译的地基没打牢。

* **矛盾关系没背**

    * 四组矛盾里有两组——$A \rightarrow B$ 与 $A \wedge \neg B$、所有是与有的非——在翻译推理那一节没讲过，所以很多同学会觉得这是新知识。

    * 真觉得理解不了，就回去把例三、例四好好琢磨；实在转不过弯就先背下来——真难就背，理解早晚会有。

    * 只有把矛盾想明白，这类题才算过关。

## 真假推理总流程

* **解题顺序**

    * > **提示**：一定是先找矛盾；如果没有，再找反对。两个要点，顺序别反。
    * 拿到一道真假推理的题，第一件事永远是找矛盾。
    * 矛盾一旦出现，"只有一句真话"这类条件就被这两句直接吃掉。
    * 前面那些题都带矛盾关系，后面的题不带矛盾；不带矛盾，条件就消化不掉，这时候要看的是反对。

* **真假锁定的两句口诀**

    * 矛盾关系，一真一假，其余全假。
    * 找到一个真的，其余都是假的；找到一个假的，其余都是真的。
    * 一定要找到你的矛盾和反对。

```text
        先找矛盾
             │
      ┌──────┴──────┐
   找到了         找不到
      │               │
      ▼               ▼
  一真一假锁死     再去看反对关系
  其余句子全假     所有所有  必有一假
                   有的有的  必有一真
```

* **真话假话要落到具体人身上**

    * 题目给"一真一假"时，把两个选项凑出来不算完，还要判定这一真一假里谁真谁假。
    * 已知条件完全能判定出来时，就必须用上。
    * 例：陈华说"我在家"，王明说"陈华没在家"，真实情况是陈华没在家。
    * 此时陈华这句是假话，王明这句是真话，答案取第二个。

> **易错点**：只凑选项、不判谁真谁假，后面好几道题都会在这一步翻车。

## 矛盾关系

* **矛盾关系（contradiction）**

    * > **定义**：矛盾是一对命题之间必有一真一假的关系。
    * 出现矛盾时，"只有一句真话"这类条件被矛盾的两句直接吃掉：两句里必有一真一假。
    * 真话既然被锁死在其中，剩下的句子就一律为假。
    * 做题先找矛盾，找到了，剩下的交给翻译推理正常推就行。

### 矛盾识别式

* **标准矛盾对**

    * > **定义**：$A \to B$ 与 $A \wedge \neg B$ 互为矛盾。
    * 判定方式：一句是"A 推出 B"，另一句是"A 但 B 不成立"，就是标准矛盾对。
    * 判断是不是矛盾就盯着这个结构看：A 成立、B 不成立。

```text
  甲句 ─┐
        ├── 矛盾 ──►  必有一真一假
  乙句 ─┘                └─►  其余句子一律为假

  识别式：   A → B   与   A ∧ ¬B   互为矛盾
              （A 成立、B 不成立）
```

### 矛盾关系的四组

* **四组矛盾**

    * 第一组：$A$ 与 $\neg A$。
    * 第二组：常说的 $A \wedge B$，它的矛盾是 $\neg A \vee \neg B$。
    * 第三组：$A \wedge \neg B$，这个相对略微难、略微复杂，很多同学没想明白。
    * 第四组的长文未说明具体形式。
    * 实在推不出来就背，四个都可以背下来。

### 且关系的翻译与否定

* **"但是"翻译成且**

    * 例："虽然我很丑，但是我很温柔"——丑和温柔是同时存在的，翻译过来就是且关系。
    * 夏某那句"乙能晋级，但是甲不能晋级"翻译成 `乙 ∧ 否甲`。
    * 它和"否甲 → 否乙"长得非常眼熟：否甲成立、否乙不成立，一对矛盾。

* **且关系的矛盾是或**

    * 且关系的矛盾是"或"，不是"且"。
    * 例：$A \wedge B$ 的否定是 $\neg A \vee \neg B$，写成"甲或乙晋级了"。
    * > **易错点**：有的同学写成"有的晋级""有一个晋级"，翻译到这一步就全乱了。

## 矛盾关系解题实例

### 爆炸案元凶题

题干：只有一句是假话。

| 说话人 | 翻译 |
| :--- | :--- |
| 甲 | 否甲 → 乙（前推后） |
| 乙 | 否甲 ∧ 否乙 |
| 丙 | 乙 ∧ 丙 |

* **矛盾定位与答案**

    * 甲句"否甲 推 乙"与乙句"否甲 且 否乙"是一对矛盾：否甲成立，乙没成立。
    * 一二之间必有一假、一二必有一真。
    * 题目说只有一个是假的，那三就必然是真话。
    * 丙说乙和丙都是爆炸案的元凶，答案 C，即丙是爆炸案的元凶。

* **误判为矛盾的辨析**

    * 有人说乙和丙是矛盾关系，这个判断是错的。
    * 乙说"甲和乙都不是"，丙说"乙和丙都是"，一个说甲乙、一个说乙丙。
    * 俩说的根本不是同一件事，连命题结构都不一样，跟矛盾没有关系。

### 晋级预测题

题干：只有一句预测是对的。

| 说话人 | 翻译 |
| :--- | :--- |
| 方某 | 否甲 → 否乙（如果甲不能晋级，那么乙也不能晋级） |
| 白某 | 否乙（不管甲能不能晋级，乙都不能晋级） |
| 夏某 | 乙 ∧ 否甲（乙能晋级，但是甲不能晋级） |

* **矛盾定位与确定项**

    * 一二不矛盾，二三不矛盾，一三矛盾，方某和夏某是矛盾关系。
    * 题目说只有一个预测是对的，真话就在这一对矛盾里。
    * 剩下白某一个人了，白某必须是假话。
    * 白某说"否乙"是假话，推出乙晋级了；夏某"乙 ∧ 否甲"的否定是"或"，即"甲或乙晋级了"。
    * 两条一合：乙已经晋级，甲有没有晋级不知道，可能都进、可能甲进乙进、可能甲不进乙进。
    * 最终只确定一条：乙晋级，甲不知道。

* **代入选项定答案**

    * C 的条件是"如果甲晋级了"，D 的条件是"如果甲不能晋级"。
    * 代 C：甲晋级 ⇒ 由「否甲 → 否乙」的逆否等价「乙 → 甲」，方某为真；夏某「乙 ∧ 否甲」为假 ⇒ C 真。
    * 代 D：乙成立而甲不成立 ⇒「乙 → 甲」不成立，方某为假 ⇒ D 假。
    * 答案 C。

## 反对关系

* **反对关系（opposition）**

    * > **定义**：矛盾之外的一对命题关系，作用是给出"必有一假"或"必有一真"。
    * 除了矛盾，一对关系叫反对关系；一道题里如果没有矛盾关系，就只剩反对关系可用。
    * 反对关系一共两组：所有所有必有一假；有的有的必有一真。

### 所有所有必有一假

* **"所有都是"与"所有都不是"**

    * > **定义**：「所有……都是」与「所有……都不是」互为反对，必有一假。
    * 拿十个人的班举例：一句"咱们班所有人都是及格的"，一句"咱们班所有人都不及格"。
    * 这两句话不可能同时都是真的；无论几个人及格、无论什么情况，两句话不可能同时存在。
    * 不可能同时为真，那就一定有一个是假的。
    * 可以两个都是假的：假设五个人及格了、五个人没及格，"所有人都及格"和"所有人都不及格"都错。
    * > **提示**：这么记是因为它太绝对了，一想"哎呀，太绝对了"，一定有个假的。

### 有的有的必有一真

* **"有的是"与"有的不是"**

    * > **定义**：「有的……是」与「有的……不是」互为反对，必有一真。
    * 还是这十个人，我说"有的人及格了"、"有的人不及格"。
    * 这两句话可不可以同时都是假的？不能，不管什么情况都不可能两句全假，根本不存在这种情况。
    * 一定有一个是真的。
    * 可以同时都是真的：五个人及格、五个人不及格，两句都真。
    * > **提示**：这么记是因为它有点软，软的东西就没那么绝对，必定能捞出一个真的来。

### 两组反对的记诵要诀

* **两句口诀**

    * 所有所有必有一个是假的：不能同真，可以同假。
    * 有的有的必有一个是真的：不能同假，可以同真。

```text
  所有……都是   vs   所有……都不是    必有一假   （太绝对了）
   不能同真，可以同假

  有的……是     vs   有的……不是      必有一真   （有点软）
   不能同假，可以同真
```

## 反对关系解题实例

### 下雪城市题

题干：三句预言中只有一句是真的。

| 说话人 | 翻译 |
| :--- | :--- |
| 一 | 有的城市下雪了 |
| 二 | 有的城市没有下雪 |
| 三 | 北京和邯郸没有下雪（否北京 ∧ 否邯郸） |

* **反对定位与答案**

    * 这三句话里有矛盾吗？没有，所以要去找反对。
    * 一和二是"有的有的"，必有一真。
    * 题目说只有一句真话，而这个真话一定在一和二之间，那三就一定是假的。
    * 三是且关系，否定叫或，所以推出北京下雪了，或者邯郸下雪了。
    * 此时北京有降雪但邯郸没下雪推不出来，B、C、D 全都推不出来，四个选项一个都选不了。
    * 只能回头判定一和二到底谁真谁假：带"北京或邯郸下雪"回代第一句"有的城市下雪了"，一就是对的。
    * 只有一句真话，二就一定是假的。
    * "有的城市没有下雪"的否定（矛盾）叫"所有都是"，所以所有城市都下雪了，答案 B。

### 超载题

题干：三个结论中只有一个是错误的。

| 说话人 | 翻译 |
| :--- | :--- |
| 甲 | 所有……句式 |
| 乙 | 所有……句式 |
| 丙 | 如意公司和吉祥公司都存在超载问题 |

* **反对定位与答案**

    * 这题里面找不到矛盾，但它有"所有所有"——所有所有太绝对了，必有一假。
    * 甲乙里必有一假，而全题只有一个错，这个错就一定落在甲乙之间。
    * 丙就一定是正确的：如意公司和吉祥公司都存在超载问题，直接推到第二个选项。

### 及格题

题干：三句预言中只有一句是正确的。

| 说话人 | 翻译 |
| :--- | :--- |
| 一 | 甲班有人没及格 |
| 二 | 有人及格了 |
| 三 | 班长没及格 |

* **反对定位与答案**

    * 一和二一说就看到"有的有的"，有的有的必有一真。
    * 正确的那个不一定在一二之间——因为一和二必有一真，只能保证"一二里至少有一句真"。
    * 两句都是真的时候，就跟题干"只有一句真"对不上了；既然整体只有一句真，它就必须落在一二之中，于是三一定是错的。
    * 三说班长没及格是错的，那就是说班长及格了。
    * 班长及格了，这个信息太少，做不出答案，只能老办法判定一和二谁真谁假。
    * 班长及格 ⇒ 能推出"有人及格了" ⇒ 第二句是真的 ⇒ 只有一句真 ⇒ 第一句一定是假的。
    * 第一句"有的人没及格"就是"有的不是"，它的否定、它的矛盾叫"所有是"，所以所有人都及格了，答案 C。
    * A 选项"甲班都没有及格"错了，B 选项"甲班有人没及格"也错了，D 也肯定错。

> **易错点**：反对关系给的只是"至少有一真"或"至少有一假"，不等于"恰好一句真"；把必有一真直接当成只有一句真用，会错判真话的位置。
