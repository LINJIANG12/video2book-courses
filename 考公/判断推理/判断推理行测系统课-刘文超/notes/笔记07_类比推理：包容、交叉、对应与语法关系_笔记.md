# 类比推理：包容、交叉、对应与语法关系

## 包容关系

* **种属关系**

    * > **定义**：A 是 B 的一种；两词是同类项，成员之间彼此平级，只是抽象层级不同。

    * 苹果是水果的一种。

    * 黑色与白色都是颜色的一种；五线谱是乐谱的一种；金文是汉字的一种；麻雀是动物的一种；发卡是首饰的一种；注射器是医疗器械的一种；千斤顶是起重设备的一种。

    * 逻辑主体给出三个词时，前两个词是并列关系、后一个词是它们共同的上位类，如"黑色、白色相对于颜色"。

* **组成关系**

    * > **定义**：A 是 B 的组成部分；两词是异类项，是整体与部件。

    * 轮胎是汽车的组成部分；衣领、衣袖都是衣服的组成部分；针筒是注射器的组成部分。

    * 音符是乐谱的组成部分，汉字是由笔画组成的，笔画是汉字的组成部分。

    * 动物只是生物链中的一个组成部分；首饰是装扮品的组成部分；齿条是千斤顶的组成部分。

    * 逻辑主体给出三个词时，前两个词并列、后一个词是它们共同所属的整体，如"衣领、衣袖相对于衣服"。

* **造句判定法**

    * 造个句子试一遍：「A 是 B 的一种」通顺就是种属，「A 是 B 的组成部分」通顺就是组成。

    * 「轮胎是汽车的一种」不通顺，只能说轮胎是汽车的组成部分；「苹果是水果的一种」通顺。

    * > **易错点**：不要再去找什么"看外延""看定义"的花招，造个句子，通不通顺一句话定生死。

    ```text
    种属：苹果是水果的一种                组成：轮胎是汽车的组成部分

    ┌─────────────┐               ┌─────────────┐
    │    水果     │               │    汽车     │
    │   ┌─────┐   │               │   ┌─────┐   │
    │   │ 苹果 │   │               │   │ 轮胎 │   │
    │   └─────┘   │               │   └─────┘   │
    │     ……      │               │     ……      │
    └─────────────┘               └─────────────┘
      类里的一个成员                  整体上的一块零件
    ```

* **三种层次同时出现时**

    * 针筒∶注射器是组成，注射器∶医疗器械是种属，两层关系一起卡。

    * 麻雀∶动物是种属，动物∶生物链是组成，而麻雀本身也是生物链的一个组成部分，答案是"种属 + 组成"两层。

    * 发卡∶首饰是种属，首饰∶装扮品是组成，两层全对。

* **常识支撑**

    * 千斤顶是省力杠杆，所以才能翘起千斤，它内部是一个一个的齿条。

    * 生物链里包含生产者、初级消费者、中级消费者、更高一级的消费者，还有分解者等等，动物只是其中一部分。

    * 比基尼是泳衣的一种，"泳衣是比基尼的一种"方向反了。

    * > **提示**：这类题会顺带考常识，题干里出现的实物，你得知道它由什么组成、又属于哪一类；不会就去查，别硬猜。

## 包容关系例题

### 中式快餐与日式快餐

* **题干的两层关系**

    * 中式快餐和日式快餐都是快餐，后两个词构成并列关系。

    * 这个并列是反对关系：除了中式的、日式的，还有韩式的等等。

    * 中式快餐与日式快餐跟"快餐"都是一种快餐，这是种属关系。

* **选项比对**

    * A 队长∶队员 相对于 团队：队长和队员是团队的组成部分，不是团队的一种，组成关系，错。

    * B 合法行为∶非法行为 相对于 行为：二者是并列里的矛盾关系，把行为整体占满了；而题干里中式和日式是反对，矛盾对不上反对。

    * C 黑色∶白色 相对于 颜色：黑白之外还有别的颜色，是反对；且黑与白都是一种颜色，是种属关系，与题干完全一致。

    * D 体育、音乐、英语：三项直接就是并列里的反对关系，连四字格那一对都套不上。

    * 答案 C。

### 衣领与衣袖

* **题干的两层关系**

    * 衣服可能还有纽扣等等，衣领和衣袖是并列里的反对关系。

    * 衣领是衣服的什么？组不了"一种"，只能说衣领和衣袖都是衣服的组成部分，这是组成关系。

* **选项比对**

    * A 鱼头∶鱼尾 相对于 鱼：鱼头和鱼尾是并列里的反对，且鱼头、鱼尾都是鱼的组成部分，逻辑完全对得上。

    * B 刑警∶交警 相对于 警察：二者是警察里的反对，刑警、交警之外还有缉毒警等等；但"刑警是警察的一种"成立，是种属关系，与题干的组成不一致。

    * C 古典音乐∶流行音乐 相对于 音乐：两者都是音乐的一种，仍是种属。

    * D 人民币、美元、韩币：三个货币单位之间的并列里的反对关系，逻辑关系不对。

    * 答案 A。

### 针筒与注射器

* **题干的两层关系**

    * 针筒是注射器的组成部分，不是注射器的一种，造句为"针筒是注射器的组成部分"。

    * 注射器是医疗器械的一种，这一层是种属关系。

    ```text
                      推进器
                         │
        ╔════════╧════════╗
        ║                 ║
           针头 ║       针筒      ║
        ║                 ║
        ╚═════════════════╝
                      注射器
    ```

* **选项比对**

    * 组成那一栏只有一个选项完全站得住：齿条是千斤顶的组成部分。

    * 后面那栏千斤顶是起重设备的一种，两层全中，答案 C。

    * D 反了，比基尼是泳衣的一种。

## 包容关系练习

### 音符与乐谱

* **题干的两层关系**

    * 音符是一种乐谱吗？不是，音符是乐谱的组成部分，乐谱是由音符组成的。

    * 五线谱是一种乐谱吗？是，所以后半截是种属关系。

* **选项比对**

    * A 笔画∶汉字、金文∶汉字：汉字由笔画组成；金文是汉字的一种，金文又叫铭文、钟鼎文，是古代写在钟鼎那种金属器物上的文字，殷商时期的那种，两层全对，答案 A。

    * B 树木、森林与自然：这三个之间绝对没有什么包含关系。

    * C 稻穗∶稻谷：方向反了。

    * > **易错点**：组成关系不总是"小的在大的里面"。稻穗整体比稻谷大，稻谷才是被包含的那个；造句子之前先在脑子里把结构想清楚。

    ```text
                      稻穗
                     ╱│╲
                    ╱ │ ╲
                   ╱  │  ╲
                ┌────┐│┌────┐
                │稻谷│││稻谷│  ← 每一颗稻谷，外面都包着一层壳
                └────┘│└────┘
                    ╱ │   ╲
                   │  │   │
                   │ 大米 │    ← 去了壳，就叫大米
                   └──────┘
    ```

    * 稻穗是收割时折下来的那一片，上面全是稻谷，一颗一颗全带着壳；没去壳的叫稻谷（也叫谷子），去了壳才叫大米。

    * 所以只能说稻谷是稻穗的组成部分，说"稻穗是稻谷的组成部分"一定是错的。

### 八卦与乾坤

* **题干关系**

    * 八卦是乾、坤、坎、艮、震、巽、离、兑这八个方向，乾坤只是八卦中的两卦，是组成关系。

* **选项比对**

    * A 九族∶师生：自己这一代算一族，往上四代是父、祖父、曾祖、高祖，往下四代是子、孙子、曾孙、玄孙，加起来正好九族，古代"株连九族"说的就是这个，它里面不包含师生；要灭十族师生才进来，中国历史上唯一被灭十族的人是方孝孺，发生在明成祖朱棣那会儿。

    * B 七情∶情志：佛教的七情是喜怒忧惧爱嗔欲；儒家把"忧"换成"哀"、"嗔"换成"恶"，是喜怒哀惧爱恶欲；中医又是另一套，叫喜怒忧思悲恐惊，而且中医会把每一种都叫作情志。是情志把喜怒忧思悲恐惊装了，而不是七情把情志装了——喜是一种情志，怒是一种情志，忧是一种情志。

    * C 五音∶宫商角徵羽：宫商只是五音中的两个音，是组成关系，与题干完全对上，答案 C。

    * D 四书和五经：二者是并列关系。

### 麻雀与生物链

* **题干的两层关系**

    * 麻雀是动物的一种，是种属。

    * 动物是生物链的什么？组不了"一种"，只能说动物是生物链中的一个组成部分。

    * 麻雀本身也是生物链的一个组成部分。

* **选项比对**

    * A 豆浆∶早餐：豆浆是早餐的一种没错，但早餐跟豆制品不是组成关系。

    * B 开水、纸杯 相对于 便利店：开水不是便利品的组成部分，逻辑关系太差。

    * C 发卡∶首饰：发卡是首饰的一种，首饰是装扮品的组成部分，而且发卡本身也是装扮品的组成部分，两层全对，答案 C。

    * D 钢笔∶电脑：钢笔是电脑的一种显然不成立。

## 包含关系的分层判定

* **先只判"包含"这一层**

    * 进士里面包含了状元、榜眼、探花，中了进士之后第一名是状元，第二名是榜眼，第三名是探花，所以进士∶状元首先是包含关系。

    * 河水跟海水不是包含，银河跟天文不是包含。

    * 学位跟博士是包含：学位包含了硕士学位，还有学士学位、博士学位。只比这一层，答案就是 C。

* **判定原则**

    * 如果包含关系这一层已经能帮你把题做出来，就不要去纠结它到底是种属还是组成。

    * 只有当包含这一层做不出来的时候，才需要进一步往下区分，那时候也没办法，只能进一步去抠。

    * > **易错点**：考场上最忌讳钻牛角尖。造句子觉得"好像也行，但好像也不太通顺"，这说明你其实已经判断出来了，不通顺就是答案，别在那儿反复横跳。

## 交叉关系

* **判定**

    * > **定义**：交叉是两个集合中间有交叉的部分；判断口诀是两边都能找到对方的一部分，且互不包含。

    * 女士这个集合里有一部分是公务员，公务员这个集合里也有一部分是女士，交集就是女公务员。

* **花瓶与瓷器**

    * 花瓶这个集合里有一部分是瓷器，瓷器里也有一部分是花瓶，交叉关系很容易辨别。

    * A 电视机∶电器：电视机是电器的一种，种属关系。

    * B 中药∶植物：中药这个大集合里什么都有，中药里有一部分是植物，植物里也有一部分是中药，但不是所有植物都是中药，交叉关系一模一样，答案 B。

    * C 画作∶诗篇：并列里的反对。

    * D 桌子∶八仙桌：八仙桌是桌子的一种，种属关系。

* **文物与建筑**

    * 文物这个集合里有一部分是建筑，建筑里也有一部分是文物，比如故宫里很多建筑都是文物。

    * A 烹饪∶佐料：烹饪的时候需要使用佐料，这不是交叉关系。

    * B 故宫∶楼房：故宫中有一部分是楼房没问题，两层的、三层的都算，楼房这个概念在古代就有了，两层及以上叫楼房，跟平房做区分；但"楼房中有一部分是故宫"读着就特别别扭，硬要说好像也行，但非常尴尬。

    * C 诗人∶教授：诗人中确实有一部分是教授，教授中确实有一部分是诗人，两向都成立，答案 C。

    * > **易错点**：类比推理要找的是最好的、最贴近的选项。B 硬钻牛角尖可能也能说个"行"，但读起来一点都不通顺，有 C 在就不要去选 B。

* **大学校长与教授**

    * 大学校长中有一部分是教授，教授中有一部分是校长，交叉关系。

    * A 编剧与诗人：编剧中有一部分是诗人，诗人中有一部分是编剧，两向都成立，答案 A。

    * D 刑警与消防队员是两个完全不同的体系，白洋淀是白洋淀、衡水湖是衡水湖，这是并列关系。

    * 选 C 的那项属于对应关系。

## 对应关系

* **兜底口袋的边界**

    * 很多题如果找不到一个特别合理的解释——不是全同，也不是组成、包容、交叉——有很大一部分就认为它是个对应关系。

    * > **提示**：对应关系虽然好找，但它是个"兜底口袋"，别一上来就往里面塞；先老老实实按全同、并列、包容、交叉挨个试一遍，试不通了再落到对应。

* **四种高频对应**

    | 对应类型 | 例子 | 关系解读 |
    | :--- | :--- | :--- |
    | 原材料对应 | 小麦 ∶ 馒头 | 馒头由小麦做成，小麦是馒头的原材料 |
    | 工艺对应 | 白酒 ∶ 发酵 | 白酒由发酵而来，发酵是白酒的制作工艺 |
    | 功能对应 | 银行卡 ∶ 支付 | 银行卡的功能叫支付 |
    | 属性对应 | 盐 ∶ 咸 | 咸是盐的属性，或者说盐是"咸"的一种特点 |

* **小麦与馒头**

    * 小麦是馒头的原材料，是标准的原材料对应。

    * A 麋鹿∶麝香：错。麝香来自雄性麝的香腺囊的分泌物，雌性是没有的，所以麝香来自雄性麝，不来自麋鹿。

    * 其余选项本节未展开，正确答案长文未说明。

## 关系分类

* **逻辑关系**

    * > **定义**：两个词构成的关系，可归为框架性关系与对应关系两大类。

    * 关系分类

        ```text
        逻辑关系
        ├── 全同
        ├── 并列
        │   ├── 矛盾关系（互斥，非此即彼）
        │   └── 反对关系（互斥，可此非彼）
        ├── 包含
        │   ├── 组成关系（A 是 B 的组成部分）
        │   └── 种属关系（A 是 B 的一种）
        ├── 交叉
        └── 对应（兜底：其他关系都对不上，就往对应上想）
            ├── 材料 —— 原材料与成品
            ├── 工艺 —— 成品与制作手段
            ├── 功能 —— 器物与用途（分主要/次要）
            ├── 属性 —— 必然属性
            ├── 次序 —— 时间先后（分主体）
            ├── 依据 —— 行为与遵循的标准
            ├── 因果 —— 前因后果
            └── 职业 —— 身份与职责
        ```

    * 全同、并列（矛盾关系、反对关系）、包含（组成关系、种属关系）、交叉属于框架性关系，特征明显、识别度高。

    * 对应关系非常复杂，可以当兜底用：其他关系都找不到，就认为它是对应。

    * 对应下面挂的八种只是高频常用的一批，对应关系里的考察点非常多。

## 做题顺序与二级辨析

### 三层动作

* **三层动作**

    * 先把明显不对的扔掉。

    * 剩下的比关系。

    * 关系比完还分不出来的，再比二级。

    * 真正卡住做题的往往不是题干，而是四个选项里有两个、甚至三个都能说通，这时候必须往下再走一层。

### 固定做题顺序

* **固定做题顺序**

    * > **定义**：题干与选项的排查有固定次序，不能跳级。

    * 先看题干属于哪一类。

    * 再逐个选项过框架关系：是不是全同、是不是矛盾、是不是组成、是不是种属。

    * 一轮都排不掉的，进"对应"。

    * 然后在对应里做二级辨析。

### 二级辨析

* **二级辨析**

    * > **定义**：两个选项都能解释得通时，用来分出高下的第三层比较。

    * 二级具体是什么因题而异，本节出现的三种：工艺是物理变化还是化学变化；功能是主要的还是次要的；时间顺序里前后是不是同一个主体。

    * > **结论**：二级辨析不是可选项。两个都能解释得通的时候，不做二级辨析就只能猜。

## 原材料与成品

* **原材料的方向**

    * > **定义**：原材料是"由……做出来"的那一方。

    * 叶绿体∶细胞 不成立：叶绿体是细胞的组成部分而不是细胞的原材料，方向反了；细胞里还装着细胞核、线粒体、高尔基体、细胞质等一大堆东西。

    * 叶绿体∶细胞 还有一条更干脆的排除理由：只有植物细胞才有叶绿体，动物细胞里根本没有。

    * 乌贼∶墨汁 不成立：乌贼是往外喷射墨汁的，是产出墨汁的那一方，不是由墨汁做出来的那一方；因果方向一旦搞反，后面全废。

    * 棉花∶布鞋 成立：老北京布鞋是布做的，布是棉花纺成的棉布，棉布再做成一双布鞋。

    * > **易错点**：⚠️ 不要在个别成分上较真，比如"有些鞋底是橡胶的"。题目问的是关系，不是这双鞋里每一根线的成分表；其余选项都是非常明显的错误时，纠结是没有意义的。

## 原材料与制作工艺

* **工艺得是个真工艺**

    * > **定义**：考"原材料 + 制作工艺"时，光把原材料说对还不够，第二格必须是一个真真正正能叫得上名字的工艺。

    * 泥∶陶瓷 用来立标准：泥是陶瓷的原材料，烧制是陶瓷的制作工艺。

    * 玉∶手镯 原材料没问题但工艺不行：手镯是"雕"出来的，不是"砸"出来的，欲砸出手镯来不合适。

    * 鱼∶鸬鹚 根本不叫原材料：鸬鹚是吃鱼的，这是谁捕食谁的对应关系。

    * 铁∶剑 原材料与工艺两头都对：原材料是铁，工艺是淬炼——把铁烧红拿出来，砸、砸、砸，再丢进水里，淬完才是能用的剑。

    * 树与土（树化石）材料说不圆，工艺也挂不上。

    * 整道题的功夫就一句话：看第二格那个词，是不是一个真工艺。

---

## 工艺的物理变化与化学变化

### 工艺变化的判据

* **工艺变化的判据**

    * > **定义**：四个选项全是"某某是某某的原材料 + 某某是制作工艺"、全是真话时，用"有没有产生新物质"来分。

    * 蚕丝织成丝绸：织只是把线排列组合起来，没产生新物质，物理变化。

    * 玉石雕琢成玉器：没产生新物质，没发生化学反应，物理变化。

    * 粮食酿成美酒：粮食主要是碳水化合物，含 C、H、O，可能还带一些硫；酿造过程会产生各种曲，物质成分彻底重组，生成酒精 $\mathrm{CH_3CH_2OH}$ 这样的新物质，化学变化。

    * 生铁冶炼成钢材：一定是化学变化。

    * > **结论**：二级辨析落在工艺上时不要凭感觉，套"有没有产生新物质"这一条；产生了新物质就是化学变化。

### 生铁与钢材的差别

* **生铁与钢材的差别**

    * 以 2% 的碳含量为界：含碳大于 2% 的叫生铁，小于 2% 的叫钢材。

    * 冶炼过程绝不是"把碳减一减"那么简单，全程都是化学反应。

    * 生铁里杂质多，除了碳还要脱磷、脱硫、脱氧、脱氮，把这些有害元素清干净。

    * 与此同时，硅、锰、镍这些非常重要的金属还得保住。

    * 按不同需求还要往里加一些特殊的金属，形成相应的合金。

### 过程与结果

* **过程与结果**

    * 蚊香∶烟雾 不成立：蚊香点燃之后会产生烟雾，烟雾不是原材料，点燃也不算工艺。

    * 它俩是"过程"和"结果"的关系，不是"材料"和"手段"的关系。

---

## 器物与功能

* **功能这一层最容易栽跟头**

    * > **定义**："原材料 + 功能"的题里，材料那头一般不难栽跟头，栽跟头的是功能。

    * 木材∶抽屉 成立：木材是原材料，抽屉的功能是收纳。

    * 钢铁∶剪刀 原材料没问题，功能写"切割"有点尴尬，严格说应该叫剪裁更合适；它不是不能切割，只是切割不是它的主要功能。

    * 棉花∶毛线 两头都错：毛线的原材料是羊毛不是棉花；保暖的是毛衣，把毛线直接围在身上并不保暖。

    * 石头∶城墙 方向又反了，城墙不是石头的原材料。

    * 橡胶∶气垫 原材料与功能都干净：气垫确实就是橡胶做的，功能是缓冲，一点不尴尬。

    * > **结论**：几个选项都能勉强解释的时候，选最优的那个；能在"勉强解释"上恋战的，题目会直接告诉你答案。

---

## 主要功能与次要功能

* **次要功能**

    * > **定义**：不是本职、额外才具备的功能。

    * 白醋∶消毒 题干给的是次要功能：白醋在厨房里调味是本职，消毒是额外具备的功能，非典那会儿白醋被抢光过，家家户户往屋里撒、往屋里喷就是奔着消毒去的。

    * 热水器∶加热 是主要功能，白糖∶调味 是主要功能，人参∶滋补 是主要功能，三项全部排除。

    * 汽油∶去渍 也是次要功能：汽油的本职是燃烧产生动力，能去渍是因为汽油是脂溶性的，能带走油渍类的脏东西。

    * 题干给的是次要功能，选项也得给次要功能。

---

## 必然属性

* **属性判定抓"必然"**

    * > **定义**：属性这一层要抓一个词——必然，即某物是否一定带这个属性。

    * 黄连∶苦 一定成立，"苦"是黄连最重要的一个属性。

    * 钻石∶坚硬 一定成立，金刚石那种碳的结构、碳碳键造就了它非常坚硬、非常牢固的特性。

    * 班级∶团结 不一定，花朵∶鲜红 不一定，城市∶繁华 不一定。

---

## 属性叠加种属

* **两层关系都要对上**

    * > **定义**：有的选项光靠一个关系不够，得两层同时满足。

    * 素描∶单色 属性成立：单色就是一个颜色，铅笔只有一个颜色就是黑色，"单色"是素描的一个特点、一个属性。

    * 种属也成立：素描是绘画的一种。

    * 即时∶新闻 两层都满足：新闻的特点就是即时，新闻又是文体的一种，正如素描之于绘画。

    * 阅读∶书签 不成立：书签是阅读的一个辅助工具，不是它的特点或属性。

    * 变脸∶表演 不成立：变脸说不上是表演的一般特点。

    * 食品∶色素 不成立：色素谈不上是食品的特点。

    * 有时选项会被第一个关系全排掉，根本用不着第二个关系来救场，但心里得知道还有第二层。

## 时间先后

### 顺序判定

* **顺序判定**

    * > **定义**：题干给的是标准先后关系时，这类题不用二级辨析，纯常识就能平推。

    * 题干给的顺序是先规划、再实施、再验收。

    * 取证排在最后 不成立，直接排。

    * 销售、宣传、生产 不成立：应该是先生产、再宣传、再销售。

    * 招标、投标、开标 顺序一点不能乱：先发布公告说要招标，投标人过来投标，最后把所有投标人放一块儿开标。

    * 播种、管理、收获 顺序成立：先播种，播种完了去管理，管理完了最后再收获。

### 主体判定

* **主体判定**

    * > **定义**：时间顺序里前后是不是同一个人干的，这是时间顺序的二级辨析。

    * 报警∶救援 前后不是一个主体：你报警，然后由警察来救援。

    * 违章∶罚款 是同一个主体：我违章了，然后我被罚款了。

    * 毕业和就业 牵涉的也是不同主体。

    * 消费∶生产 顺序反了，应该先生产再消费；手术∶住院 也反了，应该先住院再手术。

    * 一轮排掉反序的选项之后，剩下两个就是靠"主体"这一层分出高下。

---

## 依据关系

### 工具不是依据

* **工具不是依据**

    * > **定义**：依据是后者遵循前者。

    * 抽样调查依据抽样原则 成立：抽样原则在大学概率论里详细讲过，初高中只是简单接触过怎么抽样。

    * 设备的操作依据操作规程 成立。

    * 调查问卷 不成立：它是用来征求意见的，不是用来"依据"什么的。

    * 人物访谈∶访谈内容 不成立：先访谈，然后得到访谈内容，这是先后、产出关系。

    * 数学建模依据建模软件 不成立：MATLAB 是最常用的建模软件，可它只是个工具——先把建模的规程设计好，再到 MATLAB 上走一遍。

    * > **结论**：凡是"我用了这个软件/这个工具"的地方，都别往依据上靠。

### 追问法

* **追问法**

    * > **定义**：关系勉强时用追问法把自己顶回去——A 需要 B 吗？真需要吗？说不出来，就是不对应。

    * 题干是依据教案，完成今天的授课。

    * 教案∶课件 是并列：先设计好怎么讲（教案），再拿出要用的 PPT（课件），两者对今天这堂课都是辅助关系。

    * 信息∶分类 逻辑关系很弱：只是对信息进行分类；归类和分类本就是近义词，更说明不了什么。

    * 提纲∶教案 很尴尬：教案里可能有提纲也可能没有，就算有，那也只是组成关系。

    * 商品∶分类 逻辑关系差得太遥远：商品需要分类，教案需要提纲吗？

    * > **易错点**：⚠️ 稍微转一下就转得通的选项不要选；钻到牛角尖里也接不上题干的选项同样排除。

---

## 因果关系

* **因在前，果在后**

    * > **定义**：前一项是因，后一项是果，两个成分必须分处题干的两个位置。

    * 失之毫厘∶谬以千里 是标准的因果题干：前面的是因，后面的是果。

    * 前人栽树∶后人乘凉 成立：前人栽树是因，后人乘凉是果。

    * 走为上计∶三十六计 不成立：这是包含关系，走为上计是三十六计中的一计，不是因果。

    * 召之即来∶挥之即去 不成立：这里头构不成因果，召之即来并不会导致挥之即去。

    * 种瓜得瓜、种豆得豆 是因果不假，但整组词自成因果，前半句是因、后半句是果，自己闭合成一个循环。

    * > **结论**：因果题最常见的坑就是那个"看起来也有因果"的干扰项，判断标准是因和果不能挤在同一格里自己跟自己玩。

## 对应关系的解题总则

* **排除的标准**

    * > **定义**：对应关系练习中，每排掉一个选项都要能说清楚"为什么它不对"；说不清楚就等于没做，答案本身并不重要。

* **选择的目标**

    * > **提示**：四个选项里可能有一个不完美、一个"也能这么说"，要挑出**最好的那个**，而不是挑出没有毛病的那个——后者通常不存在。

    * 用一个正常人的思维判断，不要做杠精。考试题目是有标准答案的，想抬杠吃亏的是自己。

---

## 配套使用关系

* **配套使用（pair use）**

    * > **定义**：两个东西绑在一起才完整，必须同时使用、缺一不可。

    * 鱼饵∶鱼竿是配套使用：拿鱼竿配鱼饵去钓鱼。

* **不构成配套的干扰项**

    * 笔∶书籍不配套：笔的职能是写字，跟书写、写诗是一回事，它并不与某一本具体的书配套。

    * 锅铲∶炒锅配套，成立。

    * 电脑∶无线路由不配套：电脑还可以用网线，无线路由还可以配手机，两边都能各自单独使用，没有必要非说它们一定配套。

* > ⚠️ **易错点**：判断"配套使用"问的是"是不是必须同时使用、有没有缺一不可"。电脑少了无线路由照样能用，网线、WiFi、配手机都行，这就不是配套。

---

## 地点与工具

* **二选一的判定**

    * > **定义**：第三个词相对前两个动作词，究竟是"场所"还是"工具"存在两种说得通的可能时，只要其中一种解释能成立就可以选，再从中挑最贴切的一种。

    * 铁匠做镰刀，火炉既可说是工具，也可说是地点（人在火炉里炼），两种解释都成立。

    * 医学家做药剂，试管同样是地点或工具；它确实是做药的必备工具，完全可能在试管里把药配出来，答案是这一项。

* **不合适的干扰项**

    * 记者做新闻稿不是在摄像机里做的：摄像机只是一个配套工具，不是主要的，判为不合适。

    * 科学家做新产品不是在科学文献里做的。

    * 网民在互联网上营销：营销的主体是厂家，不是网民。

* > **提示**：出现"也能这么说"的犹豫时，比较两选项谁更贴近、谁更主要，选更好的那个即可。

## 原材料、功能与组成

* **三者的判断标准**

    | 关系 | 判断标准 | 典型例子 |
    | --- | :--- | :--- |
    | 原材料 | 甲被加工、制作成乙 | 面粉是面包的原材料；芦苇是纸的原材料；琉璃是屏风的原材料；黄金是戒指的原材料 |
    | 功能 | 甲是用来干乙的 | 笔的功能是书写；屏风的功能是装饰 |
    | 组成 | 甲是乙的一个部分，装上去就在 | 轮胎是汽车的组成部分 |

* **配套的排除**

    * 芦苇∶纸——芦苇确实可以造纸，但纸的功能不是书写，**笔**的功能才是书写，排除。

    * 黄金∶戒指（婚戒）——婚戒只是戒指的一种，属于种属关系，作为"原材料—功能"这一对不成立。

    * 轮胎∶汽车——轮胎是汽车的组成部分，不是原材料。

* > ⚠️ **易错点**：**组成**与**原材料**的分水岭是加工。轮胎不用加工，装到车上就是汽车的一部分；面粉必须加工才变成面包。

## 因果关系：自然现象成因与因果加时序

### 自然现象的成因

* **三条必须记准的因果**

    * 地球的自转引起昼夜交替。

    * 地球的公转引起春夏秋冬，即四季。

    * 潮汐由月球和太阳的引力引起：白天、晚上或一个月中不同时段的潮汐不一样，都与月、日的引力有关。

* **常识型因果题**

    * 题面以自然现象的成因设问（如重力与自由落体、潮汐的成因），属于常识判断，记住上述因果即可直接定答案。

### 因果之后的时间顺序

* **因果加时序的双段结构**

    * > **定义**：前两项是因与果，后两项是果发生之后要做的事，构成"先因后果，再果后行动"的时间顺序。

    * 盲动导致一败涂地，一败涂地之后需要重整旗鼓，答案落在"熬夜导致萎靡不振，萎靡不振之后需要养精蓄锐"。

* **不成立的因果干扰项**

    * 超速不会导致风驰电掣，说不通。

    * 跟风不会导致鹦鹉学舌，不是因果关系。

* **伪时间顺序**

    * 高考、招生、入学、毕业看似是时间顺序，其实不是：学校要招多少人，得**先**发出招生公告、招生计划，即先招生；然后才是高考；高考之后入学；入学之后学习；学习之后毕业。

    * 真正严谨的时间顺序是：先挂号，挂完号再去看病，看完病之后才痊愈。

* > ⚠️ **易错点**："你报名"≠"人家招生"。招生是学校先定计划、先发公告的动作，发生在高考之前，不能按自己的感受去排顺序。

## 必要条件

* **必要条件（necessary condition）**

    * > **定义**：后者没有前者就不能进行，即"后者离不开前者"。

    * 水对应生命：水是生命所必需的。

    * 二氧化碳对应光合作用：二氧化碳是光合作用所必需的。

    * 其余选项之间根本不构成逻辑关系。

## 诗词与情感的对应

* **对应的是情感，不是字面**

    * "故人西辞黄鹤楼"对应送别、离别。

    * "西出阳关无故人"才是送别。

    * "折戟沉沙铁未销"出自赤壁怀古，对应的是**怀古**，据此定答案。

    * 另两个选项既不对应送别也不对应怀古，一律排除。

## 亲属称谓

* **靠辈分与婚姻关系判定**

    * 爸爸与叔父、叔叔是**兄弟**关系。

    * 哥哥与婶婶**不是夫妻**：婶婶是叔父的老婆、叔叔的老婆，哥哥与叔叔的老婆已经差辈。

    * 妈妈与嫂子是**婆媳**关系：妈妈是婆婆那一辈，嫂子是哥哥的媳妇，这一项成立。

    * 姨妈与伯伯不是兄妹：姨妈是妈妈的姐妹，伯伯是爸爸的哥哥，两人以前并不认识。

    * 奶奶与姑姑是**母女**关系，不能说成子女关系。

* **复习方式**

    * 亲属称谓属于常识中的固定关系，答错时回家问一遍爸妈即可校正；这类题送分，不应失分。

## 景物与地域

* **同一时令的景物绑定同一地域**

    * 春雨与杏花都是春天的东西，对应**江南**——一提到江南就是"江南好风光"，上有天堂，下有苏杭，对应非常完整。

    * 秋霜与枯草都是秋天的景致，秋天是一片萧瑟，对应**塞外**——大漠孤烟直，明显优于其他选项。

* **不成立或不宜排除的干扰项**

    * 夏河与烈日都是夏天的，夏天对应江北（北方）不算贴切，但江南与江北难以说清，不能直接排除。

    * 秋风与腊梅错位：秋风是秋天，腊梅是冬天。

    * 冬雪与牡丹错位：牡丹不是冬天的。

## 并列关系

### 并列项都是原材料

* **先验逻辑关系，再验属性**

    * 题干面粉与鸡蛋都是蛋糕的原材料，选项也要找一对同为某种实物的原材料。

    * 香蕉与西瓜是水果的一种，属于种属关系，不是原材料。

    * 纸张与打印机是文件的原材料，不成立。

    * 菊花与茱萸是重阳节的标志与象征，不是原材料。

    * 水泥与钢筋都是房屋的原材料，成立。

### 并列项功能相同

* **并列中的反对关系加功能一致**

    * 光盘与硬盘是并列关系里的反对关系，二者功能都是**存储**。

    * 衣架与绳索：绳索的主要功能说成晾晒不够好，绳索能干的事情多了。

    * 钢叉与锅铲：功能若定为吃饭，国外确实会用小钢叉吃饭说得过去，但锅铲不能吃饭，整个选项不够好。

    * 签字笔与毛笔，功能都是**书写**，没有更好的答案。

    * 游泳与泳衣：游泳时可能穿泳衣、可能借助泳圈，这根本不叫功能。

## 语法关系

* **主谓（subject–predicate）**

    * > **定义**：前项作主语、后项作谓语，两个词本身已经能成句，造句时一个字都不用加。

    * "学生∶学习"是一个完整的主谓关系，补上宾语就是"学生学习功课"。

    * "学生"这两个字本身还是一个职业名称。

* **动宾（verb–object）**

    * > **定义**：前项作主语、后项作宾语，谓语缺失，缺的那一块需要自己补齐。

    * "学生∶功课"只有一个主语和一个宾语，补上"学习"才成为"学生学习功课"。

```text
     学生        学习        功课
      |           |           |
      +-----------+-----------+
            主谓宾：学生学习功课
                    |
        +-----------+-----------+
        |                       |
   学生  学习              学生  功课
    （主谓）              （主宾）
        |                       |
  关系就是主谓            谓语缺了，要补
  一个字都不用加          补上"学习"才成话
```

---

## 造句子的原则

* **总原则**

    * > **定义**：出现语法类关系就把两个词放进同一个句子里造一遍，看是否通顺；这对主谓、动宾这类关系尤其管用。

* **加字与不加字的四条规矩**

    * 加一个字（一个成分）才能变得通顺的，就去加字。

    * 不需要加字的，就不要加字。

    * 能少加的时候就少加字。

    * 真的要加字，加进去的内容尽量要一样，题干和选项要对称着补。

---

## 造句子的排除实例

### 一个字都不用加

* **完整主谓宾的匹配**

    * 题干"歌唱家∶歌唱∶歌曲"是完整的主谓宾，"厨师∶烹饪∶食物"同样完整，一个字都不用加，成立。

* **不成立的干扰项**

    * 学生学习考试：考试不是"学习"的对象，学考试应该叫预习，考前温习才叫复习。

    * 律师反应："反应"根本不是动词。

    * 清洁工施肥、垃圾：成不了话。

* **主谓与动宾的分辨**

    * 题干"居民∶居住"是主谓关系，"继承人∶继承"成立：继承人去继承遗产。

    * 守财奴吝啬不成立：吝啬是形容词，守财奴是吝啬的，这是主系而非主谓。

    * 守财奴顺从不成立：守财奴怎么会去顺从。

    * 流浪者乞讨不成立：流浪者可以流浪、可以卖艺，但乞讨是乞丐的行为。

### 一定要加字

* **加字后的目的关系**

    * 规避风险是为了避免损失、减少损失，加字才通顺，就去加字。

    * 购买保险是为了赔偿，不是为了避免赔偿、减少赔偿。

    * 关爱老人是为了避免长寿，不成立。

    * 加强锻炼是为了避免肥胖，成立。

    * 保卫军队逻辑不通：军队是保卫的对象，还需要你去保护。

* **题干与选项对称地补**

    * 题干"设计问卷∶发放问卷"考的是必然的先后顺序，"先制定政策、再执行这个政策"同样成立。

* **没有必然先后的干扰项**

    * 播放与快进：可以先播放再快进，也可以先快进再播放，没有必然先后。

    * 复制与修改：可以先复制再修改，也可以先修改再复制，没有必然先后。

    * 预习与考试：考试不可能用来预习，提前知道答案显然不可能，先预习不是"考试"。

### 在哪里做什么

* **场所加动作**

    * 在会议上讨论方案成立，在基层调研实情更贴切。

    * 在课题上合作计划、在手机上研究销量、在汽车上分析技术，都不成立。
