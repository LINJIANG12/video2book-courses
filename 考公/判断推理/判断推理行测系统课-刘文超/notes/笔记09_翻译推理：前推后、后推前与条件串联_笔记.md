# 翻译推理：前推后、后推前与条件串联

## 逻辑判断的题型分布

逻辑判断里现常考的题型大概就这么五类，考频差别很大，先混个脸熟，知道哪些是重点、哪些是基础就行。

| 题型 | 考频（国考） | 大致情况 |
| :--- | :--- | :--- |
| 翻译推理 | 一般一道，最多一道，有时不考 | 近三年国考几乎没考过专门的翻译推理题 |
| 组合排列（朴素逻辑） | 一般两道左右 | 两道题难度可能差很远，要么很简单，要么极复杂 |
| 日常结论 | 一个，最多一个，有时不考 | 靠生活常识，没有太多方法技巧可传授 |
| 逻辑论证 | **6～7 个** | 十道里考六七个，是最大头、最重要的一块 |
| 真假推理 | 十年里只考过一道 | 那道是 2018 年国考；各地联考、省考里零星出现，十题里约一道 |

* **逻辑论证**

    * 十道逻辑判断里一般占 6 到 7 个，是最大头、最重要的一块；平时刷题看到的加强、削弱、论证那一堆，统统归在这一类。

    * > **提示**：学的是生物、化学、物理的理科生，这块几乎不用听——它本质上就是"做一个实验、得出一个结论、问这个结论得靠不靠谱"，加强削弱都围着这个转。

* **翻译推理**

    * 一般一道、最多一道、有时不考，近三年国考几乎没考过专门的翻译推理题。

    * 但它是其余几类的**基础**，像学数学得先会加减法，考试未必直接考加减法，可它是整个往上走的地基；这个基础不会，别的很可能都不会。

* **组合排列（朴素逻辑）**

    * 一般两道左右，两道题难度可能差很远，要么很简单，要么极复杂。

    * 该取哪些、该放哪些、到底要不要硬啃，做到题时再看；国考和各地省考在这方面的差别不大。

* **真假推理**

    * 十年里只考过一道，就是 2018 年国考；各地联考、省考里零星出现，十题里约一道。

* **日常结论**

    * 一个、最多一个、有时不考，靠生活常识，没有太多方法技巧可传授。

> **注意**：像"原因解释"这一类都比较简单，不单独拆出来；上面几类虽未必够全，但几乎已覆盖最重要的题型。

## 翻译推理的识别

* **翻译推理（translation reasoning）**

    * > **定义**：题干给出若干条件句，把每句话先翻译成箭头，再由箭头做形式推理的一类题型。

    * 识别特征只有一条：**题干里出现了非常明显的逻辑关联词**。

    * 问法通常是"可以推出什么结论"或"不能推出什么结论"。

    * 市面上很多机构、很多老师爱把这类题改叫"假言命题""选言命题""联言命题"，叫什么其实不重要，道理很直白——只要翻译过来就 OK 了。

* **最典型的关联词**

    * **如果……那么……**：如"你如果今天晚上讲课，那么风雨无阻我一定来"，满足前面这个条件就一定到场。

    * **只有……才……**：如"只有你讲课我才去听课，别人讲课我不听"；"只有到了东北，你才能吃到正宗的锅包肉"。

    * > **易错点**："只有……才"对应的是另一类条件，翻译规则与"如果……那么"不同，不要提前混在一起。

* **不靠关联词的题面**

    * "吸烟者禁止入内"这类表述题干根本没有"如果……那么……"，得自己翻译成 `吸烟 → 禁止入内`，这是这类题的主要难点。

* **典型题面形态**

    * "如果乱扔垃圾，就会被认为没有道德；如果没有道德，就没人和他做朋友；如果没有朋友，就会寸步难行，无法继续留在这里。"——读完直接问可推出什么，就是标准的翻译推理。

## 前推后

* **前推后（forward implication）**

    * > **定义**：条件句"如果 A 那么 B"翻译成 `A → B`，前件成立就执行后件的动作，条件推动作。

    * 例句"如果你能在城里买房子，那么我就嫁给你"译为 `买房 → 嫁你`；考试里用 A 代表前句、B 代表后句，简写成 `A → B`，箭头就是"推出"的意思。

    * 翻译后的直观形态：

    ```text
       ┌──────────────┐        ┌──────────────┐
       │  条件 A      │  ───▶  │  动作 B      │
       │  在城里买房  │        │  我嫁给你    │
       └──────────────┘        └──────────────┘
             │
             │  A 不成立，程序不往下走
             ▼
       ┌──────────────┐
       │  婚事未知    │  ←  嫁不嫁？不一定
       └──────────────┘
    ```

* **解题总思路**

    * > **定义**：翻译推理的解题思维就一句话——**先翻译，再推理**。

* **否定式的简写**

    * 翻译时遇到否定式，就在前面给它加个负号；如"如果超哥不拖堂，那么我就可以早睡了"简写成 `否拖堂 → 早睡`，一眼就知道前半截是带否定的。

> **易错点**：`否拖堂 → 早睡` 只能推出"不拖堂一定早睡"，从"早睡"推不出"不拖堂"——前件不成立时程序根本不往下走。

## 等价关联词

与"如果 A 那么 B"等价的关联词还有一大票，只要出现，都是前面推后面。这些没有更好的办法，**背下来**，不要死记，靠例题去滚、去加深印象。

| 关联词 | 例句 | 翻译 |
| :--- | :--- | :--- |
| 如果 A，那么 B | 如果超哥不拖堂，那么我就可以早睡 | 否拖堂 → 早睡 |
| 只要 A，就 B | 只要你买房，我就嫁给你 | 买房 → 嫁你 |
| 为了 A，一定要 B | 为了成功上岸，那么一定要好好听课 | 上岸 → 听课 |
| 所有 A，都 B | 凡是我们都坚决拥护 | 我们都坚决拥护 |
| 凡是 A，都 B | 同上 | 同上 |
| 一定 | 一定是中国人 | 前件 → 一定是中国 |

* **若、则、就、都**

    * 这四个字只要在关联词里冒出来，这个关联词就是前推后。

    * 这几个考得最多，也最好认，值得写在讲义上。

## 逆否等价

* **逆否等价（inverse negation equivalence）**

    * > **定义**：`A → B` 等价于 `¬B → ¬A`，也就是**否后必否前**。

    * 例证："如果某人是东北人，那么一定是中国人"翻译为 `A → B`，东北人推出中国人没问题；逆否是"如果你不是中国人，能推出你一定不是东北人"，成立。

* **四种情形**

    ```text
       肯前  A  ──▶  B        一定成立
       否后 ¬B  ──▶ ¬A        一定成立（逆否等价）

       否前 ¬A  ──▶  ?        推不出
       肯后  B  ──▶  ?        推不出
    ```

    * **肯前必肯后**：肯定了箭头前面的，推出了一定后面的；东北人一定是中国人，没问题。

    * **否后必否前**：否定了后面的，推出否定前面的；跟逆否等价一模一样，可以直接划等号。

    * **否前推不出来**：你不是东北人，能推出你不是中国人吗？我可能是北京人啊，我是中国人，这叫**不确定**。

    * **肯后也推不出来**：你是中国人，能推出你一定是东北人吗？不一定，同样是**不确定**。

> **口诀**：**肯前必肯后，否后必否前，否前肯后不确定。** 东西很少，重点记住一个逆否等价就行。

## 串联成链

* **串联（chaining）**

    * > **定义**：一串翻译出来的东西，只要首尾能接上，就把它连成一条链。

    * **顺推**是从左往右走，**逆推**则是整串同时取否，从最右端一路走回最左端。

* **天气晴朗与拔河比赛**

    * 题干三条：天气晴朗就举办拔河比赛；风很大就不举办拔河比赛；不举办拔河比赛就举办演讲比赛。实际正在举办拔河比赛。

    ```text
       晴天  ──▶  拔河
       风大  ──▶  否拔河
       否拔河 ──▶  演讲
    ```

    * 第一条 `晴天 → 拔河`：现在知道拔河，能推出晴天吗？推不出，这叫**肯后**，所以第一条错。

    * 第二条 `风大 → 否拔河`：把它逆否一下，否后推否前得 `拔河 → 否风大`，也就是"风不大"，**推得出**，第二条没错。

    * 第三条 `否拔河 → 演讲`：知道拔河，拔河就是把"否拔河"否了，属**否前**，推不出"演讲"，第三条错。

    * 结论：风不大。

* **上报与开除**

    * 题干：老师把此事向学校上报，学生会被开除；学生被开除，学院年终考核会被一票否决；未将此事上报，学校的作弊现象将愈演愈烈。

    ```text
       上报  ──▶  开除  ──▶  否决
       否上报  ──▶  作弊
    ```

    * 第二句和第三句能接在一起，首尾相接先串起来；第三句做逆否得 `否作弊 → 上报`，四者全连成一条链：

    ```text
       否作弊  ──▶  上报  ──▶  开除  ──▶  否决
    ```

    * A「该年终考核未被一票否决」即 `否否决`：从链尾出发整串逆否回来 `否否决 → 否开除 → 否上报 → 否作弊`，**推得出**。

    * B「学院的考核被一票否决」即 `否决 → 否作弊`：后推前，**推不出**，错。

    * C「该学生如果被开除了，说明老师已经将此事上报学校了」即 `开除 → 上报`：`上报 → 开除` 可以，但反过来是后推前，**推不出**，错。

    * D「作弊现象愈演愈烈，说明没有被开除」即 `作弊 → 否开除`：`否作弊 → 开除` 可以，但这是**否前**，**推不出**，错。

    * B、C、D 犯的其实是同一个基本错误。

> **易错点**：整串逆推不是逐句逆否，而是整串同时取否、从最右端一路走回最左端。

## 练习题的翻车点

* **吸烟者禁止入内**

    * 题干没告诉你"如果……那么……"，得自己把"吸烟者禁止入内"翻译成 `吸烟 → 禁止入内`，很多同学没想明白卡在这儿。

    * 来了三位客人都不吸烟，即 `否吸烟`。

    * `否吸烟` 这**又是否前**，推不出任何东西，我只能说"不一定"；所以答案只能选"他们**可能会被允许入内**"这一项。

* **月球岩浆海洋**

    * 题干：如果月球表面曾是岩浆海洋，那么元素就是连续的；如果岩浆海洋的存在得到确认，那么巨型冲击假说将成为最有力的起源。

    ```text
       海洋  ──▶  连续
       海洋  ──▶  假说
    ```

    * A「如果月球表面不曾是岩浆海洋，那么元素分布就不是连续的」即 `否海洋 → 否连续`：否前，**推不出**，错。

    * B「如果巨型冲击假说没有成为最有力的起源，那么月球表面的元素分布是连续的」即 `否假说 → 连续`：`否假说` 可以先从第二条逆否出 `否海洋`，但 `否海洋 → 连续` 是否前，**推不出**，错。

    * C「元素不是连续的，则不曾是岩浆海洋」即 `否连续 → 否海洋`：这不就是第一条 `海洋 → 连续` 的逆否等价吗，成立。

    * D `连续 → 假说`：肯后，什么也推不出，错。

    * 整道题就用了这么点知识，多一点都不需要。

* **四位老师获奖**

    * 题干：张老师——如果我能获奖，那么李老师也能获奖；李老师——如果我能获奖，那么刘老师也能获奖；刘老师——如果田老师没获奖，那么我也不能获奖。设三位老师说得都对，且四位老师中有三位获奖。

    ```text
        张  ──▶  李  ──▶  刘
       否田  ──▶  否刘      （逆否后： 刘 ──▶ 田）
    ```

    * 四者连成一条链 `张 → 李 → 刘 → 田`。

    * 结论是**张老师没获奖**：如果张获奖，那么四个人就全都获奖了，那就不止三个人；所以只能是后三位获奖。

* **小张小李应聘**

    * 题干：小张应聘时说如果做了业务经理，会开拓新业务；小李应聘时说如果我做了经理，我会优化管理、精简人员。最终两人当中只有一个人当上了业务经理。

    ```text
       张  ──▶  开拓新业务
       李  ──▶  精简人员
    ```

    * 「不仅开拓了新业务，还精简了人员」**推不出来**——张和李只有一个人当上了业务经理，这两件事根本不在同一个人身上，排除。

    * 其余选项的分析此处还没有展开，长文未说明。

## 翻译的两个方向

```text
前推后：  A ──→ B          如果就、只要就、所有都、凡是都
后推前：  B ──→ A          只有才、步步、除非否则不、必要条件
逆否等价：否 A → 否 B      跟原句是同一句话，推出来的东西一样
```

读图：两条方向相反，却是逆否关系，永远成对出现。

   * **前推后**

       * > **定义**：把前件推向后件，记作 A → B；前件成立则后件必然成立。

       * 典型关联词：如果就、只要就、所有都、凡是都。

       * 例：「只要不起雾，就能起飞」译为**否起雾推能起飞**。

   * **后推前**

       * > **定义**：从后件往回推前件，记作 B → A；后面那个条件成立，反过来就证明了前面那个。

       * 例：「只有刘老师讲课，我才来上课」译为**我来上课推刘老师讲课**——今天真来了上课，就多了一个证明：这节课是刘老师讲的。

       * 对照：「如果刘老师讲课，我就来上课」是前推后，与上一句不是一回事。

       * > **注意**：中文语序会骗人，你顺着念下来的顺序推，十次错八次。正确做法是先认出关联词，再决定谁站箭头前、谁站箭头后。

   * **逆否等价**

       * > **定义**：否 A → 否 B，与原句 A → B 是同一句话，推出来的东西一样。

       * 用法：孤立的前推后句接不进链条时，取一次逆否（否后推否前）再接。

## 后推前的关联词

   * **只有才**

       * > **结论**：只有才 = 后推前。翻译时永远从「才」字后面那个条件往前推，别顺着句子语序推。

       * 识别标志：「只有」在前、「才」在后。

   * **步步**

       * 例：「不到长城非好汉」译为**好汉推长城**。

       * 验证：自己加两个字变成「如果不到长城，那莫非好汉」，即否长城推否好汉，标准的逆否等价，一转手就变成好汉推长城。

       * > **结论**：不管从哪头下笔，步步最后都落在「好汉推长城」上；步步用后推前最省事，倒过来翻译一遍就完事。

   * **除非否则不**

       * > **注意**：「除非否则」后面的「不」字不能落掉。

       * 例：「除非你买花，否则我不会原谅你」译为**原谅你推买花**——我原谅你了，就证明你一定买花了。

   * **必要条件**

       * 例：「淡水是人生存的必要条件」译为**生存推淡水**——你现在活着，一定是有淡水的。

       * 同路表述：「谁是谁的基础」「谁是谁的前提」「谁是谁必不可少的条件」，说的都是只有才这一路，翻译方向全是后推前。

## 除非否则少了一个不字

   * > **定义**：除非 A，否则 B ⟺ 否 B 推 A。题干没写「不」字时自己加一个，负负得正。

   * 例：「除非你还钱，否则我就打你」——「否则」后面已经带了个「不」字，那就是**否打你推还钱**；只要我没动手，就证明你把钱还了。

## 必要条件的语序陷阱

   * > **结论**：谁是必不可少的，谁给我放在箭头的后面。

```text
氧气是人生存的必要条件  生存 ──→ 氧气
人生存的必要条件是氧气  生存 ──→ 氧气
```

   * 上面两句是一个意思：不管「氧气」两个字摆在句子的哪个位置，只要它是必不可少的那个，它就得站在箭头后面。

       * 「氧气是人生存的必要条件」——谁必不可少？氧气。氧气放后面：生存推氧气。

       * 「人生存的必要条件是氧气」——谁必不可少？还是氧气。氧气放后面：生存推氧气。

   * > **易错点**：机械地套「后推前」，第一句推成生存推氧气，第二句又推成氧气推生存，同一句话推出两个相反的结论；推到氧气推生存时什么也推不出来。

   * 日常例：「每个人的成功都离不开夜以继日的努力」——努力必不可少，放后面，译为**成功推努力**；你只要成功了，就证明你一定努力过。

## 方向定错就满盘皆输

   * **后推前推不动的两种典型**

       * B 项「新业务推当经理」：后推前。新业务开不开展，跟某个人当不当得上经理，本来就没有必然关系，推不出来。

       * C 项「精简人员推小李当经理」：又是一条后推前，与 B 犯一模一样的错——理论上前推后可以，后推前推不了，方向全是反的。

   * **否后推否前**

       * D 项「如果该公司没有拓展新业务」译成否新业务，否后推否前，往前能推出「没有拓展新业务」这一侧必然成立，方向是对的，D 就是答案。

   * > **易错点**：判断一个选项对不对，翻译完先别急着看结论听着像不像，先看箭头方向对不对。方向反了，选项说得再顺溜也是错的。

## 条件句串成链

   * **链条的连法**

       * 后推前句直接接在前一句的箭尾上；前推后句若与所在位置不相接，取逆否（否后推否前）再接。

       * 接好后逐个选项对过去，看箭头是否与链条同向、首尾是否都在链上。

   * **否前与否后**

       * 否前站在前件位置，**无论往后推什么都推不出结论**。

       * 否后站在后件位置，可走否后推否前，推出前件那一侧为否。

### 底线思维与不忘初心

```text
第一句  取逆否        自律 ──→ 底线思维
第二句  只有才        底线思维 ──→ 不忘初心
第三句  只有才        不忘初心 ──→ 坚守理想信念
```

   * 三句原文的翻译：「如果……没有底线思维……就不能做到严格自律」是**否底线推否自律**；「只有……才……」两句依次是**底线推不忘初心**、**不忘初心推坚守理想信念**。

   * 第一句取逆否得**自律推底线思维**，四条焊成一条链：自律 ──→ 底线思维 ──→ 不忘初心 ──→ 坚守理想信念。

   * A「如果领导干部不能严格自律，就会丧失底线思维」译为否自律推丧失底线思维，否前什么都推不出来，错。

   * B「只有不忘初心才能做到严格自律」后推前，自律推不忘初心，首尾都在链上，推得通，是正确答案。

   * C「只要……就……」前推后，译为坚守理想信念推自律；链条是从自律一路推到坚守理想信念，从最末端往回推不了，错。

   * D「只要……就……」译为不忘初心推严格自律，长得特别像 B，但它是前推后而 B 是后推前，从后往前推不出来，错。

   * > **易错点**：这道题最大的坑，是把「只有才」和「只要就」弄混。**只要就 = 前推后，只有才 = 后推前**。B 和 D 只差一个关联词，就一个对一个错。

### 人生幸福与努力奋斗

   * 三句依次翻译：只有才后推前得**事业的成功推努力奋斗**、只有才后推前得**人生的幸福推事业的成功**、如果就前推后得**努力奋斗推勇于承受痛苦和艰难**。

   * 链条：人生幸福 ──→ 事业成功 ──→ 努力奋斗 ──→ 勇于承受痛苦和艰难。

   * 结论句「世界上有些人十分畏惧痛苦和艰难，不愿意承受」译为**否承受**，站在否后，否后推否前：有些人是不努力奋斗、不能事业成功、不能家庭幸福，答案选第四个。

   * A、B 是「承受推成功」「承受推幸福」，都是后推前，从后往前推不出来，一定错。

   * > **易错点**：C 和 D 从生活常识看两句话都对，但 C 不是从题干推出来的。题干只能推出「有的人不努力奋斗、事业不成功、不幸福」，很多人错在老去脑补题干之外的东西。

### 前进与高储蓄率

   * 「大量的资本支持是必不可少的」——谁必不可少？大量的资本支持，放后面，译为**前进推大量资本支持**（发展中国家向经济发达国家前进的过程中）。

   * 「高储蓄率是必不可少的」——高储蓄率放后面，译为**大量资本推高储蓄率**。

   * 链条：前进 ──→ 大量资本支持 ──→ 高储蓄率。

   * A「大量的资本就可以实现跨越」译为资本推前进，后推前，推不了；B「高储蓄率推资本支持」又一个后推前，推不了。

   * D「没有高储蓄率」走否后推否前 → 不能跨越 → 否前进，成立，是答案。

   * > **易错点**：C「没有获得大量的资本支持 → 否储蓄率不高」是本题最典型的坑。**资本推高储蓄率可以，是否资本什么也推不出来**；不能因为「现实里听着挺顺」就把它选上。

## 与题干不同的选项题

   * **通用做法**

       * 把四个选项全部翻译成箭头写下来，横向比一遍。

       * 方向一样、结论一样，就是「一样」；只要方向反了，它就是你要找的那个「不一样」。

       * 逆否后与题干一致的也算一致——绕一圈回到原句，本质是同一件事。

   * **提问方向相反**

       * 这一类不是选对的，而是选**和题干不一样**的那个，要格外小心。

### 支付与法庭

   * 题干用「除非否则」，译为否 B 推 A，即**否法庭推支付**。

   * A「只有……才……」后推前，否法庭推支付，与题干一模一样，一样，不能选。

   * B「如果……那么……」前推后，**支付推否法庭**；题干是后推前、方向朝前，B 是前推后、方向朝后，完全不一样，是答案。

   * C「如果……那么……」译为否支付推法庭，逆否等价后正是否法庭推支付，与题干一样。

   * D「如果……那么……」否法庭推支付，就是题干原话。

### 己所不欲勿施于人

   * 孔子说「己所不欲，勿施于人」是步步，译为**施于人推己所欲**：我对别人做的那些我自己都受不了的事，不能施给别人。

   * A「若……则……」前推后，译为**己所欲推施于人**，与题干反着来，就是那个「不是」，答案是 A。

   * B「只有……才……」后推前、C「除非否则不」后推前、D「凡是……都……」前推后，三项都译为施于人推己所欲，与题干一致。

   * 这一道题把前推后、后推前、若则、只有才、除非否则不、凡是都又整整复习了一遍。

### 只要不起雾就能起飞

| 选项 | 关联词 | 翻译 | 与题干的关系 |
| :--- | :--- | :--- | :--- |
| A | 如果……那么…… | 起飞 推 否起雾 | 原句的逆否，一样 |
| B | 如果……那么…… | 否起飞 推 起雾 | 逆否回来正是原句，一样 |
| C | 除非否则 | 否起飞 推 起雾 | 与 B 完全相同，一样 |
| D | — | 与题干方向不符 | 不一样 |

   * 题干「只要不起雾，就能起飞」是只要就，前推后，译为**否起雾推能起飞**，问的是与上述论断**不一致**的一项。

   * A 逆否一次是原句；B 和 C 逆否一次也正好是原句，且 B 与 C 彼此翻译结果完全相同，说明它们本来就是同一个意思。

   * > **结论**：A、B、C 说的都是同一件事，绕一圈全回到原句，所以只有第四个跟题干对不上。

## 翻译推理的基础地位

   * 翻译推理是后面**所有逻辑论证、逻辑判断的基础**，讲逻辑判断时会经常用到这里的基本逻辑学知识。

   * 觉得做了这么多题浪费时间、这题有什么好做，根子只有一个：**不熟**。慢在熟练度上，不在能力上。

   * 这类题在整个公务员考试里很简单，只要翻译过来就一定能拿分；刷过大量题之后，再遇到就是「这题我一定会做，我只要翻译就行了」。

   * > **结论**：掌握得不够好的同学，回去把今天这些例题、练习全部再刷一遍。这一步没有捷径，但也不需要天赋——翻译过来就能拿分。
