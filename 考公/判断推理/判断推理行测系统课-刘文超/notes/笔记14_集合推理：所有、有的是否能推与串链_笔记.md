# 集合推理：所有、有的是否能推与串链

## 考情分布

* **集合推理的考评权重**

    * 国考加联考近十年只在 2018 年考过一道，近五六年一道没考，更往前也没考过。
    * 广东省考、广东选调、深圳市考一般每年一道或两年一道，已经算考得非常多的地方。
    * 四川一般上半年、下半年各一场考试，每两次考试中间大概会有一道题。
    * 江西 2018 年以前出现过，2018 年以后加入联考、跟着联考卷子走，之后未再出现。
    * 江苏 2018 年以前出现过，最近这五六年没有出现。
    * 山东、辽宁、上海可能偶尔出一道。

* **学与不学的取舍**

    * 整体考评都不多，但考场上仍需系统掌握，避免两眼一抹黑。
    * 广东地区每年一到两题（省考、选调、深圳市考），要吃透"有的"的两大误区——有的A是B 推不出有的A不是B、也不能做逆否，以及六边形关系网里三组矛盾、两个反对的对应关系。

## 集合与"所有"的推理效力

* **集合推理的模型**

    * 把一群人看成一个集合，集合里有很多元素，命题描述元素与集合的归属关系。
    * 以"所有的同学都回家过年了"为例：所有前推后成立，"同学"直接推出"回家过年"，与翻译推理的规则一致。
    * 30 个人的班里可以指认张三：张三回家过年了。所有都可以推某一个，没有问题。
    * 既然所有人都回家了，"有的同学回家过年了"同样成立。
    * 一句"所有"一次性覆盖三种情况：某一个成立、"有的"成立、"所有"本身成立。

* **"所有"的推出方向**

    * 所有A是B 必然推出 某一个A是B。
    * 所有A是B 必然推出 有的A是B。
    * "所有"是绝对性判断，构成"有的"可逆否的前提。

## "有的"的覆盖范围

* **有的（some）**

    * > **定义**：只承诺"至少存在一个"，不承诺具体比例、也不排除全称情况的弱存在判断。
    * "有的同学回家过年了"同时包含：一个人回家过年、一部分人回家过年、全班所有人都回家过年。
    * 三种情况都能用同一句话去说，这一覆盖范围必须先钉死，后面所有的坑都从这里挖出来。
    * 比例可能在 0.01%，也可能 50%、60%，一直到 99.99%，它只锁定"一部分"。

* **"有的"在链条中的位置**

    * 纯"所有"的链条可以等价连接：一推二、二推三等价于一推三。
    * 链条中一旦插入"有的"，比例不再确定，连接功能随之丧失。

## "有的"的两大误区

* **误区一：有的A是B 推不出有的A不是B**

    * 若真实情况是全部 A 都满足"A是B"（这完全可能），那么"有的A不是B"就推不出来。
    * ⚠️ **易错点**：有的A是B 一定推不出有的A不是B，记住这一条就够。
    * 反方向同坑："有的"推不出"所有"。

* **误区二：有的A是B 不能进行逆否**

    * 可逆否的只有"所有"：所有A都是B 表示所有A百分之百属于B，此时否B 推否A 成立。
    * "有的A是B"讲的是"其中有的A是B"，即可能是B、只是一部分而不是全集合，推不动。
    * 本质是拿一个可能性去做逆否。

* **生活常识的干扰**

    * "有的男生是靓仔"推不出"有的男生掉毛"，若所有男生都是靓仔则更推不出。
    * 翻译推理最核心的动作就是翻译，不要把生活常识绕进去。
    * ⚠️ **易错点**：一烧脑大概率就做错，"这么多人总该有吧"是生活经验，不能用在推理里。

* **"并非所有"的翻译**

    * "并非"是否定，"所有"的否定就是"有的不是"。
    * 例：并非所有的博士都是统计专业毕业的 = 有的博士不是统计学专业毕业的。
    * 这一步等价于真假推理中"所有A是B"的矛盾是"有的A不是B"。

## "有的"的等价与串联

* **有的A是B 等价于 有的B是A**

    * > **定义**：交叉理论——A 与 B 两个集合之间必然有交集，一定存在既是一又是二的人。
    * 正着说、反着说都没有毛病，这是本主题最核心的考点。
    * 例：有的博士是教授 等价于 有的教授是博士，与类比推理中的交叉关系完全一致。
    * 换位只改变前后，不改变"有的"的强度；只掌握正向的"有的应当报废不是T品牌"就推不出"有的T品牌应当报废"。

* **所有A是B 可以推出有的B是A**

    * 第一步：所有A是B 推出 有的A是B（所有可以推有的）。
    * 第二步：由等价把 有的A是B 换成 有的B是A。
    * 例：所有的警察都是公务员 → 有的警察是公务员 → 有的公务员是警察。

* **递推串联时"有的"只能站在起点**

    * 串得上：所有A是B 且 所有B是C，得 A 推 C。
    * 串得上：有的A是B 且 所有B是C，得 有的A 推 C。
    * 串不上：所有A是B 且 有的B是C，得 A 推不出 C。
    * 断点原因：所有A都是B，但只有"有的B"才是C，一和三之间缺一条必然连接。
    * ⚠️ **易错点**：有的只能作为递推的一个起点，放前面可以连，放中间连不通。

```text
串得上：
  所有A是B  +  所有B是C  ->  A推C
  有的A是B  +  所有B是C  ->  有的A推C

串不上：
  所有A是B  +  有的B是C  ->  A推不出C
```

## 六边形关系网

* **关系网的统一图式**

    * 把真假推理与集合推理中所有涉及"所有"与"有的"之间的关系合成一张图。
    * 最上面一格是"所有A是B"，最下面一格是"某个A不是B"。
    * 中间左右两列是"有的"和"某个"；左半边全是"是"，右半边全是"不是"。

```text
           ┌──────────────┐
           │   所有A是B   │
           └──────────────┘
┌──────────────┐      ┌──────────────┐
│   某个A是B   │      │  所有A不是B  │
└──────────────┘      └──────────────┘
┌──────────────┐      ┌──────────────┐
│   有的A是B   │      │  有的A不是B  │
└──────────────┘      └──────────────┘
           ┌──────────────┐
           │  某个A不是B  │
           └──────────────┘
```

* **上下两层是推出关系**

    * 左侧自上而下：所有A是B → 某个A是B → 有的A是B。
    * 右侧自上而下：所有A不是B → 某个A不是B → 有的A不是B。
    * 班级里所有人都回家了，可以推出某一个同学回家了；某个人没回家，可以推出有的人没回家。

* **对角线是矛盾关系**

    * > **定义**：矛盾关系指两句话必一真一假，无法同真也无法同假。
    * 所有A是B 与 有的A不是B 矛盾。
    * 所有A不是B 与 有的A是B 矛盾。
    * 某个A是B 与 某个A不是B 矛盾。

* **上下两组是反对关系**

    * > **定义**：上反对指上方两句不可能同时为真，必有一假；下反对指下方两句不可能同时为假，必有一真。
    * 上反对：所有A是B 与 所有A不是B。
    * 下反对：有的A是B 与 有的A不是B。
    * 三组矛盾、两个反对，这六个关系把真假推理与集合推理的关系全部覆盖。

* **找关系的顺序**

    * 拿到真假推理第一步先去找矛盾命题；找不到矛盾时再去找反对关系。
    * 这张关系网宜理解性地去记，而不是死背。

## 例题解析

* **外语培训班与部门经理**

    * 翻译：有的30岁以下→外语培训；所有部门经理→拓展（"一致同意"即所有）；所有外语培训→否拓展。
    * 三个"所有"全串起来：外语培训 → 否拓展 → 否部门经理。
    * 结论：有的30岁以下的员工不是部门经理，答案选第四项。
    * 解法：翻译完先看能不能串；能串就把所有条件都利用起来算出结果，再到选项里找，找到直接走人。
    * 若选项中没有该结果，再从第一个到第二个逐项排查。

* **报废汽车与设计缺陷**

    * 翻译：所有行驶超60→应当报废；有的行驶超60→设计缺陷；有的应当报废→否T品牌；所有T品牌→否缺陷。
    * 设计缺陷与第四条取否后推否前，得 有的行驶超60不是T品牌，选项中没有这一项。
    * 结论：由 有的行驶超60是设计缺陷 与 所有行驶超60应当报废 串联，得 有的存在设计缺陷的应当报废，答案选第四项。
    * A、B 两项只能得到"有的应当报废的不是T品牌"，推不出"有的T品牌应当报废"。
    * C 项"报废的汽车都行驶超过60"是前推后成立、反推不成立。

* **干部、博士与统计专业**

    * 翻译：有的干部是博士；并非所有博士都是统计专业毕业的；所有男性→统计学专业。
    * 第二句即 有的博士→否统计学专业（所有式的矛盾是"有的不是"）。
    * 全部男性→统计学专业 取否后推否前：否统计学专业→否男性。
    * 结论：有的博士不是男性，答案选第二项。

* **选手喝茶**

    * 翻译：有的选手比赛时喝茶；喝茶的人要么红茶要么绿茶。
    * 喝茶者只在红茶、绿茶中二选一，不喝茶者不受任何约束，因此没有选手喝黑茶，答案选第二项。
    * "一名不喝红茶的选手一定喝绿茶"错误：不喝红茶的人可能根本不喝茶。
    * ⚠️ **易错点**："有的选手比赛时不喝茶"推不出来，犯的是第一大误区。

* **懂法语与懂英语**

    * 翻译：有的英语→否法语；所有法语→英语。
    * 由第一句换位得 有的否法语→英语，即第四项。
    * 所有法语→英语 先推得"有的法语是英语"，再换位得"有的懂英语的是懂法语"，即 A 项。
    * "没有一个懂法语的人不懂英语"翻译过来就是 所有懂法语→英语，与题干同一句，C 项可推。
    * "有些懂法语的人不懂英语"是"所有懂法语都懂英语"的矛盾命题，必然为假。
    * 设问问的是"不能推出"，答案选第二项。

* **环保主义者与风景区开发**

    * 翻译：有的环保主义者→热爱旅游；环保企业代表→减少风景区开发；热爱旅游→否减少风景区开发。
    * 两条链：有的环保主义者→热爱旅游→否减少开发；环保企业代表→减少开发，否后推否前得 否热爱旅游。
    * 结论：所有环保企业代表都不热爱旅游，答案选第二项。
    * ⚠️ **易错点**：第四项把"有的反对减少"说成"有的支持减少"，把否命题当成肯定命题。
    * A 项把"有的"说成"所有"，有的推不出所有。
    * C 项把"反对减少"等同于"支持加大"，二者不能划等号：反对减少还可能意味着保持不变。

* **"一定是假的"设问**

    * 问"哪个说法一定是假的"与常规的"可以推出"方向相反，注意问法。

## 条件翻译速查

* **常见表述到结构的翻译**

    * "一致同意""都""均为"一类全称表述 → 所有A是B。
    * "一部分""有一些""有的" → 有的A是B。
    * "并非所有A是B" → 有的A不是B。
    * "没有一个A不是B" → 所有A是B。
    * "要么……要么……" 给出的是排他选择，落入两个分支之外的情况无依据。

* **通用解题流程**

    * 第一步逐句翻译，把自然语言落成 所有/有的 与箭头。
    * 第二步先看能否串联，优先把"所有"参与的链条全串起来。
    * 第三步把所有条件都利用起来算出结论，回选项中匹配，命中即结束。
    * 第四步没命中再逐项排除，注意误区的方向：是推出它，还是它必须为假。

## "有的"的性质

### 等价换位

* **有的 A 是 B（some A is B）**

    * > **定义**：至少存在一个个体，它既是 A 又是 B。

    * "有的 A 是 B" ≡ "有的 B 是 A"，这个等价是双向的，推理中反复使用。
    * 一遇到"有的"，先把这个等价式在脑子里默写一遍。
    * 推 "有的" 时不碰逆否：❌ "有的 A 是 B" 不能翻成 "有的 A 不是 B" 或任何否命题。

    * > **易错点**：⚠️ 别在"有的"身上玩逆否，"有的"是不能逆否的。

### 从"所有"桥接到"有的"

* **桥接规则**

    * > **定义**：一道题里全是"所有"、一个"有的"都没有时，照样能用"有的"解法。

    * "所有 A 是 B" 推出 "有的 A 是 B"，再等价成 "有的 B 是 A"。
    * 因此 "所有 A 是 B" 能推出 "有的 B 是 A"，这条链是通的。
    * 典型用法：题干只有两句"凡是……都……"，答案却是带"有的"的选项，靠这条链一步推出。

### "有的"只能作起点

* **起点规则**

    * > **定义**："有的"只能作为推理的起点，不能作为被推的落点。

    * "有的"一进来就说明这个人已经存在，接下来全靠"所有"跟它接。
    * 看到"有的"先别急着在它自己身上推，看它能挂上哪条"所有"链。

## 否定方向

### 否后推否前

* **否后推否前（逆否）**

    * > **定义**：由"$A \to B$"推出"否 $B \to$ 否 $A$"，方向是否定双条件互换。

    * 是把"所有"链子接上"有的"时最常用的一环。
    * 典型链：否博士 → 否管理人员；否教师资格证 → 否法律资格证 → 否法学学生。
    * 老师的两条证书链，末环都是"否后推否前"在干活。

### 否前推不出任何东西

* **否前**

    * > **定义**：否 $A \to B$ 不成立，前件取否时后件推不出来。

    * 翻译出来是"否前"的选项，一律排除。
    * > **易错点**：⚠️ 否掉某句话的依据要回到它对应的那一句里找，别跑到另一句去找；两句各自是独立条件，谁也否定不了谁。

## 选项定性的三档

* **必然为假**

    * > **定义**：与题干正面撞上、百分之百错的那一项。

    * 问"一定为假"时，要找的恰恰不是那个"一定为真"的选项，而是那个百分之百错的选项。
    * 定性顺序：先把每个选项标成"必然为真""有可能""必然为假"，再从里面挑出必然为假的那一个。
    * 后推前得不出结论 → 不确定 → 归入"有可能"，不构成错误项。

    * > **易错点**：⚠️ 问"一定为假"时别下意识去挑"最像题干"的选项。

* **不确定就是有可能**

    * > **定义**："不确定"不是"为假"，"不确定"就是有可能。

    * 看到"确定不了"不能判错，要按"有可能"归类。
    * 拿题干否定不掉的说法，答案就落在"有可能"这一档。

## "必须做到"的否定

* **"必须做"与"一定不能做"不是矛盾关系**

    * > **定义**：否掉"必须做"只能落到中间的模糊地带，推不出"一定不能做"。

    ```text
        必须做的     也可能必须的    一定不能的     也可能一定不能的
      ┌──────────┬──────────────┬──────────────┬────────────────────┐
      │  必须做  │  也可能必须做 │  一定不能做  │  也可能一定不能做 │
      └──────────┴──────────────┴──────────────┴────────────────────┘
                    ↑ 中间这一大片，就是"不确定"的疆域
    ```

    * "可能必须做"和"可能一定不能做"这两片区域之间是矛盾关系。
    * "必须做"和"一定不能做"之间不是矛盾关系，中间还夹着整整两片地带。
    * 所以"必须做到"的否定 ≠ "一定不能做到"，这一选项不成立。

## 句式翻译

### 除非 A，否则不 B

* **"除非……否则不"**

    * > **定义**：该句式永远翻成 $B \to A$，属于后推前。

    * 是后推前里最值钱的一种句式，真题出现频率极高，看到它心里先咯噔一下。
    * 判定技巧：只要题干里有一句方向相反的"前推后"跟它对着干，这个选项就一定错。
    * 实例：选项"除非服务超 60 小时，否则没有其他途径获得优秀实践奖"翻成 优秀实践奖 → 服务超 60；而题干给的是 服务超 60 → 表现积极 ∧ 优秀实践奖，正好是它的反面，后推前推不出。

### 大多数、其余、少部分

* **"大多数""其余""少部分"**

    * > **定义**：一律翻译成"有的"。

    * 考试里的"大多数"从来不等于全体，但它至少保证存在。
    * 存在性已经够推理使用，不需要知道具体比例。
    * 例："大部分川籍工作人员不超过 30 周岁"→ 有的川籍 → 不超过 30；"少部分川籍工作人员没有博士学位"→ 有的川籍 → 否博士。

## 串完之后先验结论

* **能串起来 ≠ 有用**

    * > **定义**：逻辑上串得通的链，读出来像常识废话的就不是这道题要的。

    * 串完之后一定要把结论读一遍，凡是读出来像常识废话的，直接放弃它去找别的。
    * 实例："刑侦毕业生 → 否刑侦大四在校生"能串出来，但毕业生本来就不是在校生，属常识废话。
    * 碰到这种题就去看选项在提示什么：选项全是带"有的"的，说明答案挂在"有的"的等价换位上。

## 刷题范围

* **不要拘泥本省**

    * > **定义**：国考、联考、各省单独命题的行测申论，本质上没有区别。

    * 等自己省的题刷完了，要继续去刷国考、联考和其他省单独命题的题。
    * 考公竞争压力越来越大，题量得非常铺开，甚至想把所有题库都刷穿。
    * 多刷别的省的题很多时候比拘泥本省那几道题更有帮助。
    * 实例：广东省那道题是从上一道四川题完完全全扒下来的，答案设计都一模一样，属于同一道题。

## 题目结论与错因

### 法学与逻辑学的证书链

* **题干翻译**

    * 法学学生 → 法律资格证
    * 法律资格证 → 教师资格证
    * 有的法学学生 是 公务员
    * 有的逻辑学生 是 公务员
    * 逻辑学生 → 否教师资格证
    * 教师资格证 → 非逻辑学专业毕业（否后推否前）

    ```text
    链条一（从法学学生出发）
      法学学生 ──→ 法律资格证 ──→ 教师资格证 ──→ 非逻辑学学生

    链条二（从逻辑学生出发）
      逻辑学学生 ──→ 否教师资格证 ──→ 否法律资格证
    ```

* **选项定性**

    * 有人说自己获得了教师资格证并且并非逻辑学专业：必然为真，教师资格证直接推非逻辑学学生。
    * 有个公务员既没有法律资格证又非逻辑学专业：有可能，题干只给了"有的公务员有法律资格证""有的公务员是逻辑学专业的"，否定不了它。
    * 有法律资格证的人并非法学专业：不确定即有可能，这是拿"教师资格证 → 非逻辑学学生"的后推前反着用。
    * 有人是逻辑学专业的同时获得法律资格证：必然为假，逻辑学学生一律没有法律资格证，与题干正面相撞。

* **答案**

    * 选"必然为假"的那一项，即"逻辑学专业学生获得法律资格证"。

### 创新学分的 80 小时与 60 小时

* **题干翻译**

    * 社会服务表现积极 → 创新学分
    * 学术活动 → 创新学分
    * 机电学生 → 学术活动
    * 有的机电学生 服务超 80 小时（"大多数"）
    * 有的机电学生 服务不足 60 小时（"其余"）
    * 服务超 60 → 表现积极 ∧ 优秀实践奖

    ```text
      机电学生 ──→ 学术活动 ───────────→ 创新学分
          │
          └──→（大多数）服务超 80
                    └──→ 服务超 60 ──┬──→ 表现积极
                                      └──→ 优秀实践奖
    ```

* **错因定位**

    * "所有参与学术活动的机电学生都参加了社会服务"：所有机电学生都参与学术活动，所以"参与学术活动的机电学生"就是所有机电学生，而服务时长题干只给了大多数超 80、其余不足 60，推不出全体都参加。
    * > **易错点**：⚠️ "不足 60 小时"完全可能就是 0。有的学生服务时长就是 0，0 小时等于压根没参加社会服务，所以"都参加了社会服务"推不出来。
    * 扯到"与其他专业学生相比"的选项：题干里根本没提其他专业，不用推。

* **答案**

    * 选"有的获得优秀实践奖的机电学生获得了创新学分"：大多数机电学生服务超 80 → 超 80 必超 60 → 超 60 必表现积极、必拿奖；同时所有机电学生都参与学术活动 → 学术活动 → 创新学分，两条线在"机电学生"上接上。

### 刑侦毕业生与在校生

* **题干翻译**

    * 刑侦毕业生 → 警察
    * 刑侦大四在校生 → 否警察

* **结论**

    * 否后推否前可得"刑侦毕业生 → 否刑侦大四在校生"，但这是常识废话，没有用。
    * 选项全是带"有的"的，题目挂在"有的"的等价换位上，答案直接跳出来。

### 海外留学经历与单独接见

* **题干翻译**

    * 有的新入职员工拥有海外留学经历
    * 海外留学经历 → 董事长单独接见
    * 甲省员工 → 否单独接见

* **结论**

    * 海外经历 → 单独接见 →（否后推否前）否甲省，接上"有的新入职员工有海外经历"，得"有的新入职员工不是甲省的"，对应第四个选项。

### 干部必须做到与带头不做

* **题干翻译**

    * 领导干部首先要做到某一件事
    * 干部要带头不做某一件事

    * 两句都是"凡是……都……"式的"所有"，都是前推后。

* **答案**

    * 选"领导干部要首先做到这件事"：跟第一句原话一个意思，"所有"能推出"有的"，再把"有的 A 是 B"等价换成"有的 B 是 A"，就是"有的领导干部做到了这件事"，一步推出。
    * 前两个选项分别是两句的后推前，后推前都不确定，直接排除。
    * 最后一个选项是第一句话的否定，翻译出来是"否前"，推不出任何东西，且"必须做"与"一定不能做"不是矛盾关系。

### 博士干部与女性

* **题干翻译**

    * 12 个人里有 3 个干部是博士 → 有的干部是博士
    * 并非所有干部都是博士 → 有的干部不是博士 → 有的干部 不是管理学专业
    * 女性 → 管理学专业

* **结论**

    * 否管理学 →（否后推否前）否女性，跟"有的干部是博士"接上，得到"有的干部不是女性"。
    * 与前一道题答案结构一模一样，属于同一道题的换皮。

### 川籍工作人员的博士学位

* **题干翻译**

    * 管理人员 → 博士
    * 有的川籍 → 不超过 30 周岁（"大部分"）
    * 有的川籍 → 否博士（"少部分"）

* **结论**

    * 否博士 →（否后推否前）否管理人员，跟"有的川籍"接上，得到"有的川籍工作人员不是管理人员"，对应第四个选项。

### 健康常识与自律精神

* **题干翻译**

    * 核心句：有的人不缺少健康常识，却缺乏自律精神 → 有的人 否健康常识 ∧ 否自律
    * 有自律精神 → 早睡
    * 有自律精神 → 坚持运动
    * 有自律精神 → 不放纵自己 → 维持生理节律 ∧ 保持健康幸福

* **答案**

    * 选"有的缺乏自律精神的人不缺少健康常识"：把"不缺少健康常识"与"缺乏自律精神"换位即可。

* **错因定位**

    * 把"运动"和"自律"关系反了的选项：题干是"自律 → 坚持运动"，它写成"运动 → 自律"，后推前，推不了。
    * "否自律"的选项：无论挂在第二句还是第三句上都是否前，不确定，不成立。
    * 问"生理节律"与"健康生活"之间推导关系的选项：这两者在题干里只是同一条链上并列的两个结论，谁也推不出谁。
    * 早睡、坚持运动、维持生理节律这几条链基本没派上用场，因为选项一个都不走它们。

### 驴友协会与技术骨干

* **题干翻译**

    * 有的员工 是 驴友协会
    * 有的驴友协会的人 是 技术骨干
    * 管理层 → 同意把钱挪作他用
    * 驴友协会 → 否同意

* **结论**

    * 驴友协会 → 否同意 →（否后推否前）否管理层，可得"有的员工不是管理层"，但员工本来就有的是不是管理层的，没有意义。
    * 选项全跟技术骨干有关，说明一定挂在第二句上：把技术骨干换到前面得"有的技术骨干是驴友协会的"，再由驴友协会 → 否同意 → 否管理层，得出"有的技术骨干不是管理人员"。

## 复习节奏

* **三遍重做**

    * > **定义**：刚听完一遍处在模棱两可的状态很正常，靠重做固化。

    * 明天自己把这批题重做一遍。
    * 过一个星期再做一遍。
    * 再过一个月回头再做一遍。
    * 每一次都要加上自己的思考、自己动脑，不要机械对答案。
    * 这类题型本身很简单，不是难题，千万不要把它想难了。
