## 怎么学

- **先练“认题型”，再记方法**：每道题先标记设问方向、论证结构和选项差异，再调用相应模块；这是全课最先要建立的动作。
- **削弱与加强是分值大头**：把第 2～4 册连成一条线，重点练由因推果、他因分析、反向验证与实验型因果的识别和秒杀。
- **解释、选非与评价题先看设问方向**：分清“找原因 / 排除 / 验证”分别要求什么，再套前提、结论与形式逻辑规则，避免把不同题型的答案标准混在一起。
- **一一对应与文氏图是提分点**：第 8 册要把选项约束画成图，逐项排除；关系一旦画清，比反复凭直觉试选项更稳。
- **短期突击按题型线串联**：先用模块全文定位薄弱题型，再用对应复习笔记查规则，最后只回看相关逐字稿，按“识别 → 套法 → 排除”循环刷题。
