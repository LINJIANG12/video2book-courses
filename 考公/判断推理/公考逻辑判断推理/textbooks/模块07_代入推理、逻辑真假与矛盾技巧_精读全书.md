## 把事实真放进逻辑链：代入式推理的完整路径
> 对应块：BLK32 | 覆盖分集：P50 | 块标题（分集名）：《代入事实真进行推理上篇》

“如果我中了500万，那么我就送你一套房子。”小强对小李说。题目再问：如果小强说的是真话，哪个选项为真？

先别急着凭感觉判断。把这句话翻译成逻辑，只有一支箭头：

$A → B$

其中，$A$ 是“小强中了500万”，$B$ 是“送房子”。但一支箭头只告诉你前件和后件之间有联系，并没有告诉我们 $A$ 到底是不是真的。因此，在题干没有额外告诉我们“小强确实中了500万”之前，$A$ 的真假不确定，$B$ 的真假也不确定。选项问的是事实判断，不能拿一个逻辑关系冒充事实真。

如果我们把事实补上，说“事实证明小强确实中了500万”，这就得到 $A$ 为真，于是顺着箭头推出 $B$：小强一定送房子。反过来，如果没有中500万，否定前件，什么也推不出来；即使送了房子，肯定后件，也不能反推一定中了500万；只有“没有送房子”，才能否定后件，反推出一定没有中500万。

这个小例子已经把整类题的做法说透了：**先找逻辑连词，再找题干中已经确定的事实真，把事实真代入，沿合法方向推理。**这一类题在形式逻辑里大约占16%，比例不算低，而且是必须快速拿下的送分题。真正需要练熟的，不是背答案，而是让代入像倒油翁一样，几乎不用想就能走完。

### 先判题型，再动笔

逻辑题一上来不是先看选项，而是先根据题干特征判断题型：是论证推理，还是形式逻辑。进入这一部分，题干通常会同时出现三个信号。

| 题干信号 | 具体表现 |
| --- | --- |
| 多个逻辑条件 | 有“如果……那么……”“只要……就……”“只有……才……”“除非……否则……”等逻辑连词 |
| 一个确定的事实真 | 题干后面直接给出某个人、某件事为真或为假 |
| 选项也是事实判断 | 问哪个说法一定为真、哪个说法可以推出 |

> **定义**：事实真，就是题干已经明确给出的事实判断，不是我们自己从语境里猜出来的可能性。

三个信号凑齐，就可以把事实真代进前面的逻辑链。若只看到了逻辑连词，却没有事实真，题目大概率不能直接确定某个事实；这类题要把“不知道”如实保留下来，不能自己替题干补条件。

做题时可以把结构画成这样：

```text
题干中的多个逻辑条件
          +
题干已经给出的事实真
          +
选项中的事实判断
          ↓
        逐项代入
          ↓
   沿合法方向推出结论
```

我建议刚开始练习时，把每一条逻辑先完整写出来，写熟练以后再直接在题干上画箭头。不要一上来就追求“秒杀”，先把每一步走对；路径熟了，速度自然会出来。逻辑和数学一样，唯手熟尔。

### 一支箭头，两个方向要分清

最基本的命题是 $A → B$。它能支持的推理只有两个方向：肯定前件、否定后件。

| 已知事实 | 合法结论 | 不能据此推出 |
| --- | --- | --- |
| $A$ 为真 | $B$ 为真 | — |
| $¬B$ 为真 | $¬A$ 为真 | — |
| $B$ 为真 | 无 | $A$ 一定为真 |
| $¬A$ 为真 | 无 | $B$ 一定为真 |

为什么不能从 $B$ 回到 $A$？因为 $A → B$ 只意味着“有 $A$ 就有 $B$”，并不意味着“只要有 $B$，就一定有 $A$”。小强送了房子，完全可能是他没中奖、公司送的，或者他中奖之后又因为别的原因没有送房子。这个世界不会因为我们手里有一支箭头，就自动补上逆向关系。

把它串成一条链，结论就更清楚了。题干给出：

$A → B$、$B → C$。

- $A$ 为真，可以一路推出 $B$、$C$ 都为真。
- $¬A$ 为真，否定前件，推不出 $B$、$C$。
- $B$ 为真，只能推出 $C$ 为真，$A$ 是否为真不知道。
- $¬B$ 为真，否定中间环节，可以推出 $¬A$；但 $C$ 是否为真仍然不知道。
- $C$ 为真，肯定后件，不能反推 $B$、$A$。
- $¬C$ 为真，可以逆向推出 $¬B$，再推出 $¬A$。

这就是“小王被评为优秀员工就发年终奖，发年终奖就给小红买钻戒”的完整判断。评为优秀员工，两个结果都能确定；没被评为，什么也推不出来。发了年终奖，只能确定买了钻戒，不能确定是否被评为；没发年终奖，可以推出没有被评为，但买没买钻戒仍然不知道；买了钻戒，不能反推前面两件事；没买钻戒，则可以逆否推出没有发年终奖，而且没有被评为优秀员工。

千万不要掉进“发了年终奖就买钻戒，不发年终奖就一定不买钻戒”的思维误区。否定中间环节只能沿逆否方向退回前件，不会把后面的事实一并否定。

### 把多个条件接成一条链

现在把“倒油翁”的练习再推进一步。题干给出：

$A → B$、$B → C$、$C → ¬D$，同时有 $¬A → E$。

最后一条可以改写成逆否命题：

$¬E → A$

这样整道题就变成：

$¬E → A → B → C → ¬D$

同时保留原来的另一条关系 $¬A → E$。代入任何一个事实，就能沿着这条链向前推；链条走到矛盾方向时，也要注意不是所有组合都能随便拼。

| 已知事实 | 能确定什么 |
| --- | --- |
| $A$ 为真 | $B$、$C$、$¬D$ 为真 |
| $¬A$ 为真 | $E$ 为真 |
| $B$ 为真 | $C$、$¬D$ 为真 |
| $¬B$ 为真 | $¬A$、$E$ 为真 |
| $C$ 为真 | $¬D$ 为真 |
| $¬C$ 为真 | $¬B$、$¬A$、$E$ 为真 |
| $D$ 为真 | $¬C$、$¬B$、$¬A$、$E$ 为真 |
| $¬D$ 为真 | 什么也推不出来 |
| $E$ 为真 | 什么也推不出来 |
| $¬E$ 为真 | $A$、$B$、$C$、$¬D$ 为真 |

这张表里最容易错的是 $D$ 为真和 $¬D$ 为真。看到 $C → ¬D$，$D$ 为真时，$C$ 只能为假；再由 $C$ 的逆否继续往前，得到 $¬B$、$¬A$，最后由 $¬A → E$ 得到 $E$。反过来，$¬D$ 只是这个箭头的后件，不能凭它倒推出前面的命题。$E$ 也是一样：$E$ 为真只是肯定了 $¬A → E$ 的后件，不能反推 $¬A$；只有 $¬E$ 为真，才可以逆否得到 $A$，再把整条链推完。

> **易错点**：看到结论出现在箭头的右边，不代表它一定能倒推。肯定后件、否定前件，通常都推不出新的确定事实。

### 先把题干语言翻译成命题

逻辑题里最容易被中文绕晕的，不是推理，而是翻译。先把几个高频说法固定下来。

“只有 $B$ 才 $A$”表示 $B$ 是必要条件，方向是 $A → B$，也就是“后推前”。不能因为看见“只有”就把箭头反过来。

“除非 $A$，否则 $B$”可以改写为 $¬A → B$。做这类题时，先把“除非”后面加一个括号并否定，再看“否则”后面的结果。

“所有 $A$ 都是 $B$”是 $A → B$；“所有 $A$ 都不是 $B$”是 $A → ¬B$。

“$A$ 且 $B$”是两个同时成立的事实；“$A$ 或 $B$”是至少有一个成立。否定一个“且”，得到的是“或”；否定一个“或”，得到的是“且”。例如，$¬(A ∧ B)$ 等价于 $¬A ∨ ¬B$，$¬(A ∨ B)$ 等价于 $¬A ∧ ¬B$。很多推理看起来突然变复杂，其实只是在前一步做了一次德摩根转换。

### 简单代入题：先从一个小例子开始

#### 没有事实真，就不能制造事实

“小强中奖就送房子”这道题，如果题干只有“如果我中了500万，那么我就送你一套房子”，并没有告诉我们小强是否中奖，那么答案只能是“不能确定”。不是因为不会推，而是因为根本没有可代入的事实真。

把“确实中了500万”加进去，答案才有变化：可以确定送房子。把“没中500万”“送了房子”“没送房子”分别代进去，就会分别得到“推出送房子”“不能推出”“不能推出”“推出没中500万”四种不同结果。题干改一个事实，整道题的结论就跟着改，这就是代入法的敏感之处。

#### 否定后件，直接退回前件

早年有一道很简单的题：“如果王林是公司经理，那么他一定学过管理学。”题干又给出事实：“王林没有学过管理学。”

这里事实真就是 $¬B$，其中 $B$ 是“学过管理学”。由 $A → B$ 的逆否命题，得到 $¬A$，也就是“王林不是公司经理”。所以选择D选项。

这类题不要把现实经验带进来。学过管理学的人未必是经理，没学过管理学的人也不能仅凭经验判断是不是经理；形式逻辑只负责把题干给出的关系算完。不懂管理学的人最后可能是经理，也可能不是经理，但在本题的逻辑关系里，答案只能按箭头确定。

#### 把旅游题接成一条链

2020年国考那道题看起来复杂，核心却是同一条链。先把题干逻辑规范化：

$新疆 → 吐鲁番 ∨ 天池$；

$吐鲁番 ∨ 天池 → 同游$；

$同游 → 小张与小李做约定$；

$做约定 → 小李有时间$。

题干最后给出的事实真是“小李这个夏天没时间”，即 $¬时间$。否定后件，依次逆推：

$¬时间 → ¬约定 → ¬同游 → ¬(吐鲁番 ∨ 天池) → ¬新疆$。

所以可以确定：小张这个夏天没有去新疆，选择A。这里先不要被题目里的“否则”绕住：它只是同一条逻辑关系的另一种表达。把链条接通，结论就很直接。

### 事实真不一定写在“逻辑”句里

有些题看上去铺满了人物、身份、数量，真正有用的事实真却藏在背景描述里。看到“只需一名”“共有两个人”“最后遗憾”等字眼，要马上停下来判断：它是不是已经把某些命题的真假告诉我们了？

#### 身份和人数会直接给出事实

2019年北京那道教师选择题，题干上面有很多看起来复杂的信息，但真正有用的只有几条箭头。现在确定刘老师必去，代入后可以确定周老师也选上、张老师不选。再由相关条件的逆否关系，确定王老师也选上；“王和马中至少有一个”的条件进一步推出牛老师不选。

到这里，能确定的是周老师已选、牛老师未选，刘、王也已经确定。剩下的马老师，题干没有给出足够事实，状态仍然不知道。与马老师有关的组合不能因为“看起来合理”就当成答案。对应选项为A。

我在这类题里经常提醒自己：题干上方的信息不一定都是背景信息，也不一定都要用。真正有价值的背景信息，往往会在后面变成一个事实真，把本来分散的箭头一下子接通。

“只需要一名副书记”也是同样的例子。题干若说明只需要一名副书记，而某两位副书记都没有参加某项活动，那么“没有参加”就已经是事实真；把它代回“只有……才……”的条件，逆否就能得到对应人物一定参加了另一项工作。2016年管综联考和2018年上海题，本质上是在练同一种阅读：不是先把所有人物都推一遍，而是先找那个被数量限制直接钉死的事实。

2018年江苏题则把事实藏在关系交集里。条件是“认识小王的人有公共管理专业硕士学位”“认识林女士的人是江苏人”。要推出一个人同时具备这两个条件，就要找同时认识小王和林女士的人。先列出认识小王者，再列出认识林女士者，取交集，唯一落在同一个人身上的是大李，所以选A。

#### 颜色链里，否定合取只会得到析取

2020年山东题的红、白、黑、花，先不急着看其他颜色。把能用的关系接起来，再代入已经确定的小灰、小红、小辉等信息，最后抓住“白、黑、花→红”这一步。已知小红没有报名，也就是 $¬红$。

由 $白 ∧ 黑 ∧ 花 → 红$ 逆否，得到 $¬白 ∨ ¬黑 ∨ ¬花$。现在白和黑已经确定报名，三个可能否定的项中至少有一个为假；既然白、黑都真，剩下的花就必须为假。答案是“小白和小黑都报名”，选B。

这里难的地方就在“否定一个三个合取，得到的是一个或”，不是把三个都直接判成假。或关系里只要有一项为真，整个或就为真；用已知白、黑为真逐项排除，才得到花为假。

#### 两个人、两层关系，连续代入

有一道题问五个人中谁是卧底。题干先给出“小孙不是卧底”，再通过“只有……才……”的结构推出小钱不是卧底，随后另一个条件又推出小赵不是卧底。三个具体人物已经被排除，结合“五个人中有两个人是卧底”这个人数条件，剩下的两人就指向小李和小周，答案为C。

这条人数条件在这里并没有增加新的逻辑箭头，讲解时反而可以删掉：用前两条条件排除小孙、小钱、小赵，再结合“两个卧底”的数量限制，答案就已经出来。做这类题不要被多余的背景吓住，先找真正能推进的箭头。

六个人的题也可以抽象成一条链来练。设题干中的条件依次写成：

$P ∨ D$、$¬D ∨ G$、$(G ∧ W) → P$、$L → W$、$L ⊕ Z$。

已知 $¬P$ 为真。代入第一组，得到 $D$；把 $D$ 代进第二组，得到 $G$；再用 $G$ 和 $¬P$ 处理第三组，得到 $¬W$；由 $L → W$ 逆否得到 $¬L$；最后因为 $L$ 与 $Z$ 是“不相容选言”，二者一定一真一假，$¬L$ 就推出 $Z$。最后确定参加的是D、G、Z，对应B。

这里把“不相容选言”单独拎出来说一句：它不是“至少一个”，而是“恰好一个为真，一个为假”。既然已经确定刘为假，另一个就必须为真。比相容选言更简单，但不能把“一个或一个”写成“两个都可以”。

### 两个事实真：`and` 一定要分别代入

“而且”看起来只是把两个条件放在一起，实际推理时千万不要把两个事实一次性硬塞进箭头。看到 $A ∧ B$，就把它理解成两个分别独立成立的事实真；先代一个，推出一个新命题，再把另一个代进去。

我用一个简单算式来类比：如果题目同时给出 $A=3$、$B=4$，要求计算一个由 $A$、$B$ 组成的式子，通常先把 $B$ 代入括号，算出括号里的结果，再把 $A$ 代进去。逻辑也是同样的算法：

```text
事实真一 ──代入──> 新命题 ──事实真二代入──> 最终结论
```

顺序不是固定的，原则只有一句：**谁能先推出东西，就先代谁。**

#### 先推得动，再代另一个

题干是 $A → B ∨ C$，事实是 $A ∧ ¬B$。

先代 $A$，得到 $B ∨ C$；再代 $¬B$，因为否定或命题的左边，可以推出右边，得到 $C$。所以：

$$A ∧ ¬B → C$$

一开始也可以把 $¬B$ 放前面，但单独代 $¬B$ 推不动，因为要否定 $B ∨ C$，需要同时知道 $¬B ∧ ¬C$，手头只有 $¬B$。所以先代能产生信息的 $A$，这就是“谁先推得动就先代谁”。

#### 先代能逆否的事实

题干是 $¬C → ¬A ∨ ¬B$，事实是 $¬C ∧ A$。

先代 $¬C$，得到 $¬A ∨ ¬B$；再代 $A$，否定左边，得到 $¬B$。因此：

$$¬C ∧ A → ¬B$$

如果题干把事实写成 $A ∧ ¬C$，推理顺序完全一样。合取的两个事实可以交换书写，先后只是为了节省步骤，不是把两个命题的逻辑意义改变。

#### 否定后件，先退回析取

再看一个很多同学容易晕的模式：$(A ∧ B) → C$，事实是 $A ∧ ¬C$。

单独代入 $A$ 没用，因为前件必须同时满足 $A ∧ B$。先代 $¬C$，通过逆否得到 $¬A ∨ ¬B$；再代 $A$，得到 $¬B$。所以它和上一题是同一套底子：

$$A ∧ ¬C → ¬B$$

这里的顺序也说明了“同时为真”不是“只要其中一项为真就够”。前件是 $A ∧ B$，只有 A 代入，无法触发箭头。

### 固定结构：一道链能秒杀一类题

下面这个结构在考试中反复出现，值得单独记牢：

$$A → D，\quad B ∧ C → ¬D，\quad A ∧ B$$

先代 $A$，由第一支箭头得到 $D$；把 $D$ 代入第二支箭头的逆否命题，得到 $¬B ∨ ¬C$；再代已经给出的 $B$，得到 $¬C$。因此：

$$A ∧ B → ¬C$$

写成一个不带跳步的流程：

```text
A → D
      ↓
D → (¬B ∨ ¬C)      （第二条的逆否）
      ↓
B 代入后得到 ¬C
```

它和前面“两个事实真、两次代入”的模型是同一回事，只是把第二个事实藏在了 $B ∧ C$ 里面。题目一旦给出 $A$ 和 $B$，答案通常就是 $¬C$。这种结构在公考、考研以及管综题里都常见，熟悉了就能少走很多回头路。

### 把固定结构落到人物题

#### 42名员工：教授、年龄和海外招聘

2016年江苏题给定四组关系：所有人都在教学或行政；教授都不担任行政；30岁以下的年轻博士都做行政；海外招聘的人都有博士学位。事实真有两个：李明是教授，李明29岁。

先代“李明是教授”，得到他不担任行政；再由“教学或行政”得到他做教学。由“30岁以下且博士→行政”的逆否命题，有“不行政→不在30岁以下或不是博士”。李明29岁，已经在30岁以下，于是只能是“不是博士”。再由“海外招聘→博士”逆否，得到李明不是海外招聘来的。

所以，李明同时满足“教授”“做教学科研”“不是海外招聘”。选项D“有的教授不是从海外招聘来的”可以由李明直接证明；如果有选项E“有的做教学科研的人不是从海外招聘来的”，同样可以由李明证明，两个选项在这道题里甚至可以同时成立。

顺带记住一个逻辑细节：题干里的“不少”只表示“有一些人”，不是“大多数”。逻辑判断能确认“有的”，不能从“有的”推出“多数”。带“大多”“大多数”的选项，如果没有额外信息，不能直接推出。

#### 同事、同学和球迷

另一道题把固定结构换成了人物关系：

$赵元的同事 → 球迷$；

$赵元的同学 ∧ 软件园工作 → ¬球迷$。

李雅既是赵元的同学，又是赵元的同事。先代“同事”，得到李雅是球迷；把“球迷”代入第二条的逆否，得到“李雅不是同学，或者李雅不在软件园工作”；再代已经确定的“同学”，得到李雅不在软件园工作，答案选C。

王伟只是赵元的同学，而且不在软件园工作，第二条的前件并没有完整成立，所以不能推出更多结论。张明是同学但不是球迷，可以由“同事→球迷”的逆否知道张明不是赵元的同事，但后面的关系没有继续给出确定结果。人物题里，最容易丢分的就是把“一个人只满足部分前件”误当成完整前件。

#### 第三方招聘与销售

2023年管综联考题中，条件是：

$（第三方招聘进入甲公司 ∧ 从事销售）→ 有会计学专业$；

$孔某的高中同学 → 没有会计学专业$。

事实是孟某是孔某的高中同学，同时在甲公司销售部经理岗位上，因而从事销售。先代“孔某的高中同学”，得到孟某没有会计学专业；由前一条逆否得到“非第三方招聘，或者非销售”；再代“从事销售”，得到孟某不是通过第三方招聘进入甲公司，答案选B。

#### 微信群、茶商和“被拉进群”

2017年上海题的结构完全一样：

$（被陈玲拉进群 ∧ 通过该群与蔡俊建立联系）→ 茶叶经销商$；

$陈玲的客户 → ¬茶叶经销商$。

黎阳既是陈玲的客户，又确实通过该群与蔡俊建立了联系。先代“客户”，得到黎阳不是茶叶经销商；将其代入第一条的逆否，得到“没有被陈玲拉进群，或者没有通过该群建立联系”；再代已经确定的“通过该群建立联系”，得到黎阳不是陈玲拉进群的，答案选B。

这两道题一眼看上去人物和场景完全不同，底子却是同一个结构：先由一个事实推出一个结论，再把结论代回另一条条件，最后用第二个事实消掉析取中的一边。固定结构熟了，遇到换皮题就不慌。

### 把几个容易错的地方钉死

#### 逻辑关系不是事实真

$A → B$ 只说明“如果 A，那么 B”。它没有告诉我们 A 真，也没有告诉我们 B 真。没有事实真，就不能从逻辑关系中凭空制造事实。题目问“哪个一定为真”时，必须回到题干给出的确定条件上。

#### 肯定后件、否定前件要停止

$A → B$ 只能走 $A ⇒ B$ 和 $¬B ⇒ ¬A$。看到 $B$ 不要急着退回 $A$，看到 $¬A$ 也不要急着推出 $¬B$。这条规则不是形式上的束缚，而是避免把“充分条件”误当成“必要条件”的底线。

#### 还要知道“且”和“或”怎么否

$¬(A ∧ B)=¬A ∨ ¬B$，$¬(A ∨ B)=¬A ∧ ¬B$。否定一个三项合取时，得到的是三项析取；再根据已经确定为真的项目逐项排除，最后才能把剩下的项目判假。不要看到“否定”就把所有部分一锅端。

#### `只有……才……`和“除非……否则……”要翻译

“只有 B 才 A”是 $A → B$，不要倒着写。“除非 A 否则 B”是 $¬A → B$；当“否则”后面本身已经是否定表达时，要先把实际文字逐字读清楚，再决定 $B$ 是否带否定。翻译错一个否定号，后面全错。

#### 两个事实真不要合成一个“前件”

`and` 不是把条件改写成一个巨大的 $A$。它代表两个独立的事实真。解题时先代能推得动的那个，得到中间命题，再代另一个；顺序只影响步骤，不影响结论。

### 这一套动作真正要记的东西

我把这类题压缩成四步：

1. **找箭头。**把“如果、只有、除非、且、或”都翻译成明确的方向。
2. **找事实真。**题干直接给出的内容、数量限制、身份关系，都可能是事实真。
3. **选入口。**谁先能推出东西，就先代谁；`and` 中的两个事实分别代，不要硬塞。
4. **只走合法方向。**肯定前件、否定后件；遇到合取先拆开，遇到析取要分清已知哪一项为真。

一旦这四步固定下来，题干再长、人物再多，也只是把同一条链换了几句说法。先把简单题做得像 $1+1=2$ 一样熟练，复杂题只是把两三步简单计算接在一起。不要一开始就追求把所有信息都用上，先把真正能推出确定答案的那条链找出来。

### 本讲提到的题目

这一部分把课堂上直接做过、或者明确拿来练习的题目集中列出。题干的字母化表达只是为了方便演算，含义与前面逐题还原的条件一致。

#### 只给箭头与补充事实

- “如果小强中了500万，就送小红一套房子。”只给逻辑关系，不给中奖事实，事实真无法确定；补充“小强确实中奖”后可推出送房子；补充“确实没中奖”“确实送房”“确实没送房”时，分别对应“不能推出”“不能推出”“能推出未中奖”。
- “如果王林是公司经理，那么他一定学过管理学。”事实为“王林没有学过管理学”，推出“王林不是公司经理”，答案D。
- 新疆旅行题：题干给出“去新疆→吐鲁番或天池→同游→小张与小李做约定→小李有时间”，事实为“小李没有时间”，逆否推出“小张没有去新疆”，答案A。
- 2016年国考通过题：已知“$B$通过→$E$通过”、$A ∨ B$、$A → C ∧ D$、$¬C → ¬F$，且$E$不能通过，先得$B$不能通过，再得$A$、$C$、$D$通过；$F$无法确定，答案A。
- 六个人的链式题：按$P ∨ D$、$¬D ∨ G$、$(G ∧ W) → P$、$L → W$、$L ⊕ Z$，并代入$¬P$，得到D、G、Z参加，答案B。
- 五人卧底题：小孙不是卧底，经两条逻辑继续推出小钱、小赵也不是卧底，结合两人卧底的数量限制，剩下小李、小周，答案C。
- 2020年山东颜色题：由白、黑、花的合取条件和小红未报名，确定花未报名，小白、小黑都报名，答案B。
- 2019年北京教师题：由刘老师必去，确定周老师选上、张老师不选、王老师选上、牛老师不选；马老师无法确定，答案A。
- 2016年管综联考和2018年上海题：关键事实是“只需要一名副书记”或“王主席既没参加迎新宣传，也没参加微信平台维护”，逆否后分别推出王书记下乡调研、王主席不在本市过年，答案均为A。
- 2020年北京实验室题：“除非有教师在国际期刊发表论文，否则没有资格申报重点实验室”写成$¬A → ¬B$。甲实验室给出$A$，不能推出相关结论；乙实验室给出$B$，可逆否推出$A$，答案C。
- 2018年江苏人际关系题：同时认识小王和林女士的人只有大李，故大李同时具有公共管理专业硕士学位且是江苏人，答案A。

#### 两个事实真的题

- 42名员工题：李明是教授、29岁两个事实真分别代入，推出他不行政、做教学科研、不是博士、不是海外招聘，故D成立；若另有“有的教学科研人员不是海外招聘”的选项，E也可由李明成立。
- 赵元同事/同学题：李雅既是同事又是同学，推出其不在软件园工作，答案C；王伟、张明的条件不足以推出同样的结论。
- 2023年管综联考题：孟某是孔某同学且从事销售，推出其不是第三方招聘进入甲公司，答案B。
- 2017年上海题：黎阳是陈玲客户且通过该群建立联系，推出其不是陈玲拉进群的，答案B。

## 把事实放进箭头里：代入事实真与判断逻辑真假
> 对应块：BLK33 | 覆盖分集：P51-P52 | 块标题（分集名）：《代入事实真下篇与判断逻辑真假》

先把一个最容易混淆的地方放在桌面上：**事实真不等于逻辑真**。题干写出一个“如果 A，那么 B”，只是告诉我们 A 与 B 之间存在这样一条逻辑关系；它没有替我们宣布 A、B 真的发生了。要让 B 成为事实，就得把 A 这个事实放进去。

所以，题目看起来千变万化，底层却只有一条路：找到已经确定的东西，顺着题干给出的箭头往前推。只是有的题把确定的事实直接写在题干里，有的题把事实藏在了选项的前件里。前者是代入事实真，后者就是判断逻辑真假。

这两种题型一定要先分清。不要一看到“如果”就凭感觉找相似，也不要看到题干很长就开始逐字阅读。先看题干给的是事实还是逻辑，再看选项在问事实还是在问逻辑。

### 先分清两种题型

代入事实真的题目，通常有三个特征：题干给出若干逻辑式，同时给出至少一个确定的事实；选项也都是事实。做题时，把这个事实带进题干条件，沿着逻辑链推出新的事实。

判断逻辑真假的题目，题干没有直接给事实，题干条件和选项全部是逻辑式。常见的逻辑词包括“如果……那么……”“只有……才……”“只要……就……”“除非……否则……”。看到这种结构，锁定题型后，不需要把它当成阅读理解逐字理解。

> **结论**：题干有“逻辑 + 事实”，问事实，是代入事实真；题干和选项全是逻辑，问哪一个逻辑必然成立，是判断逻辑真假。

还有一个边界必须牢记：逻辑成立，只能说明“如果前件为真，后件就必须为真”，不能让前件或后件凭空变成事实。形式逻辑像数学一样，推不出来就是推不出来，不能因为“应该如此”就替题目补上条件。

### 让事实沿着逻辑往前走

#### 目标要一个事实时

先看最直接的问法。

已知 $A\to B$，并且已知 $A$ 为真，那么把 A 代入题干，就能推出 B 为真。这是前面已经讲过的基本套路。

题目换成“需要补充什么条件，才能得到 B 为真”，答案仍然是 A。因为我们不是在问 B 本身能不能从逻辑关系里自动冒出来，而是在问：要让这条逻辑真正启动，前件得是什么？前件为真，才能把后件推出来。

> **提示**：题目问“补什么条件”时，先在选项里寻找能让已知逻辑前件成立的条件；不要因为目标句里出现了 B，就直接去选项中找一个看起来相似的句子。

##### 2021 陕西教师课程题

这道题的目标是推出事实真“孙老师教语文”。题干给了四个教师课程之间的逻辑式。要从目标倒推，先找到“孙老师教语文”所在的“或者”关系。

“或者”有一个非常稳定的用法：否定其中一边，可以推出另一边。于是，为了得到“孙老师教语文”，先补“吴老师不教语文”。再往前找，发现“吴老师不教语文”可以由否定某个“如果……那么……”的后件得到；继续逆推，又得到“张老师教生物”，再得到“苏老师要教物理”，最后把“吴老师教化学”带进去。

整个依赖关系可以压缩成：

```text
目标：孙老师教语文
        ← 吴老师不教语文
        ← 张老师教生物
        ← 苏老师要教物理
        ← 吴老师教化学（选项 C）
```

注意，这不是让我们从左到右凭感觉乱接，而是从目标事实开始，逐个寻找“怎样能让这一条逻辑的前件为真”。每一行都要有题干中的逻辑依据，不能因为人物名字换了一个就停下。

所以答案选 C。这类题的计算量几乎为零，关键就是找到目标之后的逆向依赖。

##### 2025 江苏运动题

这道题换成运动项目，结构没有变。题干里出现“或者两者仅有其一”，先把它理解成一个“或者”关系；其中“只有……才……”则是后推前。

目标是推出“小吴练游泳”。沿着“或者”的关系，补上“否定另一支”的条件，得到“小泉不练游泳”；再用“只有……才……”的后推前，补上“大臣练跳水”；继续往后追，得到“大刘练水球”；最后用“否定或者的左边推出右边”，补上“小泉练赛艇”。

依赖链大致是：

```text
小吴练游泳
    ← 小泉不练游泳
    ← 大臣练跳水
    ← 大刘练水球
    ← 小泉练赛艇（选项 A）
```

于是选择 A。

这类题在考试里往往就是送分题。不要把“或者两者仅有其一”“只有……才……”分别当成两套完全陌生的知识反复阅读；先把它们翻译成箭头，再从目标倒推，剩下的只是查选项。

#### 目标藏在逆否链末端时

真正容易增加难度的，是把多个逻辑式串起来，再逆着求一个事实。考官会把“需要补条件”和“事实代入”放在同一道题里，但本质上仍然是同一条链。

##### 2014 广东联考劫机题

题干给出一条链：

$$
\text{没有故障且没有劫持}
\to\text{被导弹击落}
\to\text{被卫星发现}
\to\text{媒体公布}
$$

目标是推出“飞机被恐怖组织劫持”。原链条的方向不是朝着“劫持”，所以先把整条链做逆否：

$$
\text{没有媒体公布}
\to\text{没有被卫星发现}
\to\text{没有被导弹击落}
\to\text{故障或劫持}
$$

现在箭头已经指向“故障或劫持”，但还不能直接得到“劫持”。因为“故障或劫持”至少有一边成立，还可能只是“故障”成立。

要从中锁定“劫持”，需要两个条件：

1. 先让“故障或劫持”这个“或者”关系为真。逆否链上的否定事实任取一个即可，例如“没有媒体公布”“没有被卫星发现”或“没有被导弹击落”。
2. 再否定“或者”的左边，也就是加上“没有故障”，才能推出“劫持”。

所以，单独有一个“没有故障”是不够的：它只否定了左边，却没有保证“故障或劫持”本身为真。这正是选项设计的坑。课堂给出的正确选项是 B，“没有被导弹击落”；这个事实既能让逆否链的“或者”成立，又能配合“没有故障”推出“劫持”。

> **易错点**：逆否只能把箭头整条转向，不能跳过“或者”关系直接挑出其中一支。先让“故障或劫持”成为真的逻辑前提，再用否定一边推另一边。

#### 同一骨架换皮

公考很爱把同一结构换几个名词。我们不必把每道题都重新理解一遍，只要抓住“目标事实—逆向补条件—否定或关系”的骨架。

##### 2021 江苏社团题

题干给出：李女士参加了合唱团；诗词和书法至少有一个；参加诗词就不参加合唱。

从“李女士参加合唱团”出发，否定“参加诗词就不参加合唱”的后件，可以推出她不参加诗词。再由“诗词或书法至少有一个”，否定诗词后，就能推出她参加书法。

但题干只能推到“参加书法”，还不能凭空推出“参加戏曲社”。所以需要补：

$$
\text{参加书法}\to\text{参加戏曲社}
$$

它的逆否形式

$$
\text{不参加戏曲社}\to\text{不参加书法}
$$

也可以。题目中与这两种表达对应的选项都是可行方向，课堂重点放在 B、D 所体现的等价逻辑上。

这和“参加书法就参加戏曲社”是同一件事吗？方向不一样。正确要求是已知书法为真，再推出戏曲社；不能反过来把两个参加事实的方向颠倒。

##### 2024 浙江剪纸题

这道题只是把“诗词、书法”换成“艺术阅读、版画”，再把“戏曲社”换成“手工剪纸”。

已知“艺术阅读或版画至少有一个”，已知小苏参加书法；由“参加艺术阅读就不参加书法”可以推出不参加艺术阅读，再推出参加版画。要得到“参加手工剪纸”，只需补：

$$
\text{参加版画}\to\text{参加手工剪纸}
$$

也可以补它的逆否：

$$
\text{不参加手工剪纸}\to\text{不参加版画}
$$

因此课堂判定 D。D 项表达的就是“不参加手工剪纸，就不参加版画”，与“参加版画推出参加手工剪纸”方向一致。

如果选项写成“参加手工剪纸或者不参加版画”，也不能被它吓住。令 A 表示参加手工剪纸，B 表示版画，那么

$$
A\lor
eg B\equiv
eg A\to
eg B
$$

它正是“版画推出手工剪纸”的逆否方向。逻辑词一转换，文字上的“或者”就会变成可代入验证的箭头。

### 逻辑不能逆推

代入事实真的章节里，考官最爱挖的坑不是“不会找目标”，而是诱导我们把逻辑倒过来。只要记住一句话：**否定逻辑的前件，什么也推不出来；肯定逻辑的后件，也什么也推不出来。**

#### 否定前件不能启动链条

已知 $A\to B$，只能从 A 推出 B。现在把 A 否定，变成“非 A”，不能因此推出 B，也不能推出非 B。形式逻辑里，推不出来就是推不出来，不能选一个“看起来更合理”的结论。

一个特别直观的例子是：已知“老黄是条狗”，当然可以推出“老黄是条老狗”；但“老黄没有参加活动”可能是年龄、游泳距离、高血压、心脏病之外的其他原因造成的。你不能因为它没有参加活动，就倒推出它一定大于 50 岁、一定有高血压，或者一定有心脏病。

2019 年管综联考的活动题就是这个坑。题干可以合并出“满足年龄、游泳距离、高血压、心脏病中的某些条件就不能参加活动”，而事实是老黄能游 3 千米以上，但没有获批参加活动。题干确认的是“不能参加”这个后件，不能倒推出究竟是哪一个前件条件导致的。课堂选择 E，而 D 选项所代表的“前几个条件至少有一个”不能被直接推出。

#### 肯定后件不能倒推前件

已知 $A\to B$，即便现在知道 B 为真，也只能说 B 这条结果成立，不能因此说 A 一定成立。最典型的错误就是：

$$
A\to B\quad\text{不能改成}\quad B\to A
$$

即使选项写成“如果结果成立，那么原因也一定成立”，方向仍然反了。

在一道“$A\lor B\to C$”的题里，即使已知 C 为真，也不能默认 A、B 至少有一个成立；也许还有题干没有写出的 D 也能导致 C。这里尤其不能因为 C 为真，就擅自把 A 或 B 选出来。

#### “或者”不等于两边都有

“红色或绿色”只能说明每个垃圾桶属于红、绿两类中的一类或两类都算，但不能推出“其中一定有绿色”。所有垃圾桶都可能是红色，也可能都可能是绿色，当然也可能红绿都有。

“电子付款或自动贩卖机”也一样。它不能推出“有一些商户使用自动贩卖机”，因为所有商户都使用电子付款也满足这个“或者”。如果某商户两种都不使用，那么由“或者”的逆否关系，可以推出它不是该市场商户；但只知道某个商户使用了自动贩卖机，只能肯定“或者”的后件，不能倒推它一定在这个市场。

“或者”和“并且”的边界也要记牢：

- $A\lor B$ 为真，不要求 A、B 都真，也不要求其中恰好一个真。
- “两者仅有其一”才是在强调恰好一个。
- $A\land B$ 为假，不等于 A 假并且 B 假；它只表示至少有一个为假，等价于 $
eg A\lor
eg B$。
- “A 为假并且 B 为假”才表示两者都不成立。

#### “只有”与“除非”不能凭语感判断

“只有……才……”是后推前，箭头指向必要条件；“只要……就……”是前推后；要有 A，必须有 B，箭头也指向必须的 B。谁是必须的，箭头就指向谁。

“除非 A，否则 B”翻译成 $
eg A\to B$，也就是 $A\lor B$。如果题目写“除非非 E，否则 F”，前面的“非”取反后就是 E，所以得到 $E\to F$。这类句子不要顺着中文感觉读，抓住括号和非号，结构一写出来，选项就容易比较了。

2001 年广东联考的大嘴鲈鱼题，考的是同一个原则。题干说大嘴鲈鱼“只在有鱼且有浮藻的水中生活”，这是把“有鱼且有浮藻”作为大嘴鲈鱼生活的必要条件，并不等于“河里有鱼且有浮藻，就一定有大嘴鲈鱼”。已知某条河没有大嘴鲈鱼，只是对必要条件的反向否定，不能推出河里没有鱼、没有浮藻，也不能推出一定有鱼或一定有浮藻，所以关于该河的情况什么也推不出来，选择 E。

2016 年北京的野生灵芝题、2018 年北京的抹香鲸题，都是这个结构的改写：

- 野生灵芝只有在温度高且光线昏暗的环境中生长；某林区没有野生灵芝，不能推出温度不高或光线不暗。
- 抹香鲸只有在乌贼存活且不结冰的海域才有；某海域没有抹香鲸，不能推出乌贼不存活，也不能推出该海域结冰。

### 判断逻辑真假先抓结构

#### 先用题干特征锁定题型

前面学过，判断逻辑真假在形式逻辑里占比较高：在统计的一千多道题中，形式逻辑有两百多道，判断逻辑真假约占 22%，有四十多道；近几年国考基本每年都会出现。它又特别技巧性，题干文字往往很长，不掌握方法时容易像做阅读理解一样，读很久也没有结论；掌握结构后，往往二三十秒就能完成。

> **识别方法**：题干条件全是逻辑，选项也全是逻辑。看到“如果……那么……”“只有……才……”“除非……否则……”密集出现，就不要先研究文意，直接把它们翻译成箭头。

题干背景里没有逻辑连词的句子，往往只是背景信息，可以先放一边。真正有用的，是那些带“如果”“只有”“只要”“除非”“或者”“并非”“至少有一个”“最多有一个”的句子。

#### 先把逻辑词翻译成箭头

| 原句 | 标准化表达 | 记忆要点 |
| :--- | :--- | :--- |
| 如果 A，那么 B | $A\to B$ | 前推后 |
| 只要 A，就 B | $A\to B$ | 前推后 |
| 只有 A，才 B | $B\to A$ | 后推前，箭头指向必须条件 |
| 要有 A，必须有 B | $A\to B$ | B 是必要条件 |
| 除非 A，否则 B | $
eg A\to B$，即 $A\lor B$ | 把“除非”后的整体取反 |
| 即使遇到 B，也会 C | $A\to C$ | B 是干扰条件，不改变主逻辑 |
| A 或 B 至少一个 | $A\lor B$ | 不要求两边都真 |
| A 与 B 都为假 | $
eg A\land
eg B$ | 两者都不成立 |
| A 与 B 整体为假 | $
eg(A\land B)$，即 $
eg A\lor
eg B$ | 至少一个不成立 |

“即使”很容易把人带偏。比如“如果你坚持努力，即使备考遇到困难，最终也能成功上岸”，真正的主逻辑只是“坚持努力就成功上岸”，困难只是干扰项。把干扰词去掉，逻辑就干净了。

#### 一句话题直接找逆否

题干只有一句话，选项也只有逻辑式时，不要读完四个选项再慢慢比较。直接找题干逻辑的等价表达，尤其是逆否命题。

##### 2020 省考锻炼题

题干给出：

$$
\text{坚持锻炼}\to\text{发病风险降低}
$$

等价逆否命题是：

$$
\text{发病风险没有降低}\to\text{没有坚持锻炼}
$$

所以选择 B。

“有没有坚持锻炼推出风险提高”是 $
eg A\to
eg B$，它和 $B\to A$ 其实是同一个方向，不等于题干的 $A\to B$。“坚持锻炼就降低风险”则只是把题干原话说了一遍，方向仍然不是逆否。这里没有必要在已经找到答案后继续研究其他选项，考试时不看 A、C、D，反而能把时间省下来。

#### 两句话题要抓共同核心

##### 2022 北京成绩题

题干第一句是“要稳定提高逻辑考试成绩，关键是不能缺少对基本概念的真正理解”，也就是：

$$
\text{取得稳定好成绩}\to\text{真正理解基本概念}
$$

第二句是“如果不能真正理解，即使做很多事，也不可能取得真正的好成绩”。把“即使”去掉，主逻辑是：

$$
\text{没有真正理解}\to\text{没有稳定好成绩}
$$

第二句的逆否命题正好是“取得稳定好成绩就真正理解基本概念”，和第一句一致。A、B、D 分别换成“只有……才……”或“除非……否则……”来表达，逻辑没有变化；C 却把“真正理解”直接推向“好成绩”，方向反了，所以课堂选择 C。

这题给我们的提醒是：不要被换过的逻辑词吓住。先把每句话压缩成 A、B 两端，再看箭头，最后才看选项使用了什么连接词。

##### 2024 江苏鸟飞向天空题

题干是“除非两翼健壮并且能够以共同的力量推动身体，否则不能飞向天空”。记 $A$ 为“两翼健壮”，$B$ 为“能够以共同力量推动身体”，$C$ 为“能够飞向天空”，可以写成：

$$

eg(A\land B)\to
eg C
$$

它等价于：

$$
C\to A\land B
$$

而 $
eg(A\land B)$ 就是 $
eg A\lor
eg B$，所以也可以写成：

$$

eg A\lor
eg B\to
eg C
$$

第二个和第三个表达与题干等价；第一个和第四个把方向或整体结构改了。课堂给出 B，正是选出不等价的那一项。

这类题一定要熟悉到三五秒过一个结构：看到“除非 A 并且 B，否则不能 C”，马上同时写出 $C\to A\land B$ 和 $(
eg A\lor
eg B)\to
eg C$，不要重新阅读中文。

#### 文字只负责包装，箭头才负责推理

##### 2022 陕西节能减排题

题干有两个逻辑式：“只有节能减排，才能控制冰川退缩”翻译为：

$$
\text{控制冰川退缩}\to\text{节能减排}
$$

“如果不减少温室气体排放，94% 的冰川将消失”翻译为：

$$
\text{不减少排放}\to\text{冰川消失}
$$

A、D 都把“减排”放在前面去推“冰川退缩”，方向反了；B 把“冰川消失”推向“不减排”，也反了。C 用“除非减少排放，否则冰川消失”重写了第二条，正好与题干等价，所以选择 C。

题干里“94%”“100 年”等数字只是包装，不要为了理解数字含义而停下。我们要找的是“只有”的方向、条件的整体否定和“除非否则”的等价式。结构化思维一出来，文字就不再是阅读理解的障碍。

##### 2016 国考采访题

题干关键句是“除非用含混不清或者枯燥无味的话来应付，否则采访者没法回答”。不要去研究采访现场发生了什么，只翻译逻辑：

$$

eg(\text{含混不清}\lor\text{枯燥无味})\to\text{没法回答}
$$

它等价于“能够回答，就必须使用含混不清或枯燥无味的话来应付”。选项 C 正是把“除非否则”换成“只有……才……”后的等价表达，所以选择 C。B 把“没法回答”反推成前件，是典型的后推前错误。

### 复杂条件用快速代入验证

#### 先看选项，不急着读完整套文字

前面那些题，题干只有一两句，逻辑式简单，直接对比就能解决。实际考试中更多的是条件多、文字晦涩、三四个箭头互相交叉的题。这时不要逐字读完整篇材料，而是先找逻辑连词，再把题干压缩成若干箭头。

快速代入验证的规则只有一句：

> **把选项逻辑的前件假设为真，带回题干已经确定为真的条件中，看看能不能必然推出选项的后件。能推出，选项成立；推不出，选项不成立。**

注意，这里不是把选项当成事实去“猜”题干，而是做必然性检验。选项前件一旦为真，题干所有已知逻辑都应同时成立；在这个前提下，后件是否为真，才是判断依据。

#### 用一组抽象箭头练习

设题干给出：

1. $A\to B$；
2. $B\to
eg C$；
3. “只有 C 才 D”，即 $D\to C$，其逆否为 $
eg C\to
eg D$；
4. “除非非 E，否则 F”，即 $E\to F$。

我们不背具体文字，只按规则检验选项。

| 选项结构 | 代入后的结果 | 结论 |
| :--- | :--- | :--- |
| $A\to C$ | $A\to B\to
eg C$，不能得到 C | 不成立 |
| $A\to
eg C$ | $A\to B\to
eg C$ | 成立 |
| $B\to A$ | $B\to
eg C\to
eg D$，不能逆推 A | 不成立 |
| $C\to
eg A$ | 是 $A\to
eg C$ 的逆否 | 成立 |
| $
eg D\to
eg A$ | $
eg D$ 是已有链条的后件，不能由此向前推 | 不成立 |
| $A\lor C$ | 等价写成 $
eg A\to C$；代入 $
eg A$ 后什么也推不出 | 不成立 |
| $
eg A\lor
eg D$ | 等价写成 $A\to
eg D$；$A\to B\to
eg C\to
eg D$ | 成立 |
| $A\to F$ | A 与 F 没有可连接的共同端点，属于串行 | 不成立 |
| $
eg F\to
eg E$ | 是 $E\to F$ 的逆否 | 成立 |

这里最值得记住的是“串行”这两个字。题干给了 A、B、C、D，又给了 E、F，但 A 这条链和 E 那条链没有任何共同端点，就不能因为它们都“看起来像箭头”就把 $A\to F$ 接出来。给 A、B 真，最多沿着已有链推出 C、D，不能凭空推出 E、F。

另一个细节是：选项不一定一开始就是标准箭头。看到“至少有一个为真”，先把它改成“或者”；看到“最多有一个为真”，先改成“至少有一个为假”；看到“除非否则”，先取反。翻译完成后再代入，才能真正做到快。

#### 前件已经暴露错误时，后件不用再看

复杂题最省时间的技巧，是只读选项的前一半。

如果选项前件是“非 A”，而题干只有 $A\to B\to
eg C$ 这样的链条，那么代入非 A 后什么也推不出来。后面无论写 B、C、D，都不可能因此变成立，直接排除。

如果选项前件是已知逻辑的后件，例如从 $B\to
eg C$ 里取出 B，或者从 $
eg C\to
eg D$ 里取出 $
eg C$，那也是“肯定后件”。在没有其他可用路径时，后件为真不能反推前件，选项同样排除。

所以考试中不要读完每个选项的所有文字。先看它把哪一个事实带进题干：如果这个事实一进去，题目里的所有箭头都失去方向，后半句不用再看。这个技巧特别适合题干文字晦涩、选项又长又绕的题。

### 两种方法其实是一回事

把前面的内容放在一起，会发现“代入事实真”和“判断逻辑真假”的底层思维是同一个。

| 对比项 | 代入事实真 | 判断逻辑真假 |
| :--- | :--- | :--- |
| 题干给什么 | 逻辑式加事实 | 逻辑式，通常没有事实 |
| 事实放在哪里 | 题干直接给出 | 藏在选项的前件里 |
| 怎么开始 | 把题干事实带入逻辑 | 逐个把选项前件假设为真 |
| 怎么结束 | 推出新的事实 | 推出选项后件，选项才成立 |
| 难度来源 | 可能要多次逆向和或转换 | 同一个动作要重复检验多个选项 |

代入事实真只做一次：事实已经在题干里，把它带进箭头链即可。判断逻辑真假则像是把同一个动作重复几次：每个选项的前件都伪装成一个待检验的事实，依次带入题干，能推出后件的选项才留下。

所以，如果判断逻辑真假做得不稳定，通常不是突然出现了一套完全陌生的规则，而是事实代入还不够熟，或者“顺推、逆否、否定或的一边”没有练到形成条件反射。反过来，复杂逻辑题做得多，也一定会反过来提高事实代入的速度。

> **结论**：判断逻辑真假是升级版、复杂版的事实代入。区别只在于，事实是直接写在题干里，还是藏到了选项的前件。

### 把练习练成秒杀

这类题最终靠的不是临场灵感，而是刻意练习。做完一道题，不要只记住答案，要记住它的结构；下一次遇到换了人物、地点、颜色、运动项目或课程名称的题，直接调用原来的箭头，不要重新从头走一遍阅读流程。

简单题找到逆否或“或者”转换后就收手，不要在已经确定答案后继续花时间研究错误选项。复杂题先看选项前件能不能排除，只有前件确实能带动链条时，才继续验证后件。把“送分题”做对，把“福利题”秒掉，就是最划算的提速方式。

真正要练熟的不是某一道题的答案，而是下面这几条动作：

- 从目标事实倒推需要补什么条件；
- 把“或者”的一边否定掉，推出另一边；
- 把“如果……那么……”整条做逆否；
- 把“只有……才……”翻译成后推前；
- 记住否定前件、肯定后件都不能启动逆向推理；
- 用选项前件代入题干，判断后件是否必然成立。

### 本讲提到的题目

#### 代入事实真

- **2021 陕西教师课程题**：题干给出四个教师课程关系的逻辑式，要求补充条件推出“孙老师教语文”。从目标倒推，依次得到“吴老师不教语文”“张老师教生物”“苏老师要教物理”，选项“吴老师教化学”可以完成链条，答案 C。

## 判断逻辑真假：把选项前件代回题干
> 对应块：BLK34 | 覆盖分集：P53 | 块标题（分集名）：《判断逻辑真假中篇》

好，前面把基本推理原理和解题技巧过了一遍，接下来就直接刷题训练。判断逻辑真假看上去句子长、弯弯绕绕，真正稳定下来的动作却只有一个：

> **把选项的前件代入题干，看能不能推出选项的后件。能推出，选项成立；推不出，选项不成立。**

这句话看着简单，但很多人一看到“如果……那么……”就发怵。真正让人发怵的往往不是推理，而是没有把句子的逻辑结构翻译干净，最后一边查题、一边凭常识脑补。形式逻辑最不欢迎脑补：概念不一样，就是不一样，不能因为它们现实中可能相关，就擅自把它们画上等号。

我们先不用抽象规则，直接进入两道广东题。

### 先把代入验证练成下意识

#### 事实型选项：四个选项逐个带入

先看一道 2022 年广东题的修改版。题干只给了一个条件：

> 喜欢打羽毛球的学生中，来自体育学院的学生一定喜欢登山。

把它翻译成逻辑关系：

$$喜欢打羽毛球 \land 体育学院学生 \rightarrow 喜欢登山$$

这里一定要把“喜欢打羽毛球”和“来自体育学院”看成一个整体前件。喜欢打羽毛球只是其中一个条件，只有它，不能把整个前件肯定下来；喜欢登山则是后件，肯定后件也不能反推前件。

选项换成了四个事实型判断，分别对应甲、乙、丙、丁。我们逐个代入。

甲喜欢打羽毛球，也喜欢登山。他虽然肯定了后件“喜欢登山”，却没有完整肯定前件“喜欢打羽毛球并且来自体育学院”，所以推不出任何新信息。

乙是体育学院学生，也喜欢登山。情况与甲类似：只肯定了前件的一部分，同时肯定了后件，不能推。

丙喜欢打羽毛球，但不喜欢登山。这一下子就有东西可推了。题干是：

$$A \land B \rightarrow C$$

丙给出了 $A$ 和 $
eg C$。由 $
eg C$ 作逆否，可以得到：

$$
eg A \lor 
eg B$$

再把已知事实“喜欢打羽毛球”，也就是 $A$ 代进去，就能推出 $
eg B$，即：

> 丙不是体育学院的学生。

丁不喜欢打羽毛球，但喜欢登山。不喜欢打羽毛球是在否定前件，喜欢登山是在肯定后件，两种方向都不能推，所以也不行。

> **结论**：只有丙能够推出确定结论，答案选 D。

甲、乙、丁分别能推出什么？什么都推不出来。丙却能借助“否定后件”把前件拆开，再把其中一个否定条件排除掉。这是事实型选项最标准的代入方式。

#### 逻辑型选项：题目换皮，方法没变

原题的题干完全一样，区别只在于：选项不再直接陈述甲、乙、丙、丁的事实，而是把事实藏进“如果……那么……”的前件里。

做题方法一点没变。我们还是把每个选项的前件代入题干：

```text
题干条件：P → Q
选项形式：P → R

把选项前件 P 代入题干：
P → Q
若还能由 Q 得到 R，选项成立
若推不到 R，选项不成立
```

A 的前件是“喜欢打羽毛球且喜欢登山”。喜欢打羽毛球只是部分前件，喜欢登山是后件，推不出“体育学院学生”。

B 的前件是“体育学院学生且喜欢登山”。同样只肯定了前件的一部分和整个后件，也不能反推“喜欢打羽毛球”。

C 的前件是“不喜欢打羽毛球且喜欢登山”。否定前件的一部分，又肯定后件，照样推不出来。

D 的前件是“喜欢打羽毛球且不喜欢登山”。它与刚才丙的事实完全一致，所以可以推出“不是体育学院学生”。

所以原题也选 D。

这两道题本质上没有区别。简单一点，考官就把事实型判断直接放在选项里；难一点，就把事实藏进逻辑型选项的前件，让你一个个代入。题目可以换皮，解题动作不用换。

> **易错点**：看到“并且”时，不要只盯着其中一个条件就说自己肯定了前件。$A \land B$ 是一个整体，只有把 $A$、$B$ 都肯定了，才算肯定前件。

### 三句串联，不是三个包袱

接着看一道 2018 年浙江题。题干先是一大段现实背景，选项也全是“如果……那么……”，这已经不是靠生活常识做题了，而是考纯结构。

题干第一句大致是：

> 由于世界范围内各种传染病多发，我国必须在今后 5 年内增加 5% 的财政投入，否则就无法有效应对大面积疫情。

这句话把三个部分串在一起：

> 由于 A，必须 B，否则 C。

不要死磕整句中文，拆成两个逻辑就行：

$$A \rightarrow B$$

$$B 的否定 \rightarrow C$$

也就是：

$$A \rightarrow B$$
$$
eg B \rightarrow C$$

这里可以记一个特别生活化的例子：

> 由于下雨，必须带伞，否则就会淋雨。

拆开就是“下雨推出带伞”，以及“不带伞推出淋雨”。这和题干的结构完全一样。

把背景内容换成字母后，题干的三个逻辑可以整理为：

$$传染病多发 \rightarrow 增加财政投入$$

$$
eg 增加财政投入 \rightarrow 不能有效应对大面积疫情$$

$$增加财政投入 \rightarrow 疫苗研制达到世界先进水平$$

然后代入选项。

A 的前件是“不增加 5% 的财政投入”。这正好命中第二个逻辑，可以推出“无法有效应对大面积疫情”，与 A 的后件一致，因此 A 正确。

B 的前件是“疫苗研制达到世界先进水平”。题干只能由“增加财政投入”推出它，不能由它反推“增加财政投入”。B 想进一步推出“改善医疗科研水平”，属于肯定后件，直接排除。

C 的前件是“世界范围内不爆发传染病”。它否定的是第一个逻辑的前件，否定前件什么也推不出，排除。

D 虽然肯定了“增加财政投入”，但题干能推出的后件是“疫苗研制达到世界先进水平”，D 写的却是“有效改善我国的医疗科研水平”。这两个概念不能偷换。

> **易错点**：疫苗研制达到世界先进水平，不等于有效改善整个医疗科研水平。形式逻辑里，两个概念只要不是同一个概念，就不能靠脑补画等号。

A 已经成立，练习时再把 B、C、D 排除一下就够了。等熟练以后，看到 A 能完整推出后件，直接选、走人，不必把所有错误项都分析得头头是道。

> **结论**：做形式逻辑不要发散，不要脑补，不要推理。题干给什么就推什么，选项写什么才对应什么。

### “只有……才……”永远别翻错

再看一道 2022 年四川题。题干是：

> 如果你认为自己是最优秀的人，那么你就应当按照最优秀的人的标准要求自己。

> 如果你相信自己能够成功，那么你就一定能够成功。

> 只有充分地在行动上展现自己，才能在心里肯定自己。

前三句话不用理解它们的人生道理，只要把结构抓出来。

第一句是“如果你认为……那么……”，所以：

$$A \rightarrow B$$

第二句还是“如果你相信……那么……”，也是：

$$A \rightarrow B$$

第三句是“只有 A，才 B”，后推前：

$$B \rightarrow A$$

也就是：

$$充分地在行动上展现自己 \rightarrow 在心里肯定自己$$

开始代入选项。

A 的前件是“不认为自己是最优秀的人”。它否定了第一条逻辑的前件，否定前件什么也推不出，直接排除。

B 的前件是“在行动上充分展现自己”，正好是第三条逻辑的前件。由前件可以推出后件“在心里肯定自己”，与 B 完全一致，因此 B 正确。

C 说“有人虽然自信能够成功，但是未必能够成功”。题干明明写着“相信自己能成功，就一定成功”，C 却把后件改成了“未必成功”，不对。

D 又把“一定成功”降成了“可能成功”，而且“只有……才……”的方向也写反了。题干给的是“相信自己能成功推出一定能成功”，不是“有成功的可能推出相信自己会成功”。

所以选择 B。

> **定义**：看到“只有 A，才 B”，箭头只能从 B 指向 A；“必须 A，才 B”同样是后推前。

这种结构特别容易被口译带偏。不要凭中文习惯猜，看到“只有”就急着往后写，先记住一句话：

> **“只有”把后件锁住，所以前件必须发生；前件是后面结果的必要条件。**

### 不要强迫每一句都变箭头

再看一道 2021 年江苏题。题干第一、二句非常标准：

> 人无精神则不立。

> 国无精神则不强。

直接翻译：

$$
eg 精神 \rightarrow 
eg 立$$

$$
eg 精神 \rightarrow 
eg 强$$

第三句是：

> 精神是一个民族赖以长久生存的灵魂。

这句话没有标准逻辑词。题目考判断逻辑真假，不需要把“灵魂”生硬翻成箭头。

第四句是：

> 唯有精神达到一定高度，才能在历史的洪流中奋勇向前。

“唯有……才……”仍然是后推前：

$$在历史洪流中奋勇向前 \rightarrow 精神达到一定高度$$

开始验证。

A 说“有精神则立”。题干给的是“无精神则不立”，也就是 $
eg A \rightarrow 
eg B$。它不能推出 $A \rightarrow B$。

> **易错点**：题干是“非 A 推出非 B”，不能因为两边都加了否定，就擅自改写成“A 推出 B”。肯定前件、否定前件、肯定后件、否定后件，方向一变，逻辑身份就全变了。

A 的错误很典型：看见“否定前件”就说能推出“否定后件”，或者看见“否定前件”两边一起翻个身，就改成了肯定前件。两种都不行。

B 的前件是“精神没有达到一定高度”。它虽然出现在第三条可用逻辑的后件位置，但 B 的后件却转成了“精神不是赖以长久生存的灵魂”。题干没有这个推理关系，所以不对。

C 说“一个民族在历史洪流中奋勇向前，则精神达到一定高度”。这正好肯定了第三条逻辑的前件，可以推出后件，C 正确。

D 的前件是“精神达到一定高度”。这是对第三条逻辑后件的肯定。肯定后件什么也推不出，排除。

答案是 C。

做完这道题，我要再强调一遍：判断逻辑真假，切忌“追求极致”，好像题干里每一句都必须翻译成箭头。真正有信息量的可能就一两句话，其余内容就是考官放出来的烟雾弹。

不会翻译的句子先放着，把你会翻译的全部列完，再去选项里找对应关系。绝大多数时候，标准答案早就在那一两句里找到了。如果确实找不到，再回头研究剩下的内容也不迟。

> **结论**：先把标准逻辑词全部翻译完，不要强迫每一句话都承担推理任务。

### 两步串起来，考官最爱考逆否

再看一道 2024 年广东题。题干给了三步：

> 如果不禁止捕鱼，那么鱼类资源会枯竭。

> 如果鱼类资源枯竭，那么渔业生涯会终结。

> 只有渔民收入得到保证，才能使鱼类资源良性循环。

前两步一连，就是一条非常清楚的链：

```text
不禁止捕鱼 ──→ 鱼类资源枯竭 ──→ 渔业生涯终结
```

这时不要急着逐个代入。先看整条链的两端能推出什么。

原链条是：

$$
eg 禁止捕鱼 \rightarrow 渔业生涯终结$$

逆否命题是：

$$
eg 渔业生涯终结 \rightarrow 禁止捕鱼$$

考官看到两条连续逻辑，特别爱考的就是两种形式：直接从链条起点推到终点，或者考整条链条的逆否。C 选项说“如果某地的渔业没有终结，那么一定禁止捕鱼”，正好就是逆否命题，因此可以秒选。

没有这种敏感度也没关系，按正常代入法继续验证。

A 的前件是“鱼类资源没有枯竭”。由第一条逻辑作逆否，可以得到“禁止捕鱼”，但 A 的后件却是不禁止捕鱼，前后正好相反，因此不对。

B 的前件是“禁止捕鱼”。第一条逻辑的前件是“不禁止捕鱼”，B 把它否定了。否定前件什么也推不出，不用看后件。

C 如上，可以推出“禁止捕鱼”，正确。

D 的前件是“渔民收入没有得到保证”。第三句“只有渔民收入得到保证，才能使鱼类资源良性循环”翻译为：

$$鱼类资源良性循环 \rightarrow 渔民收入得到保证$$

D 否定前件，不能推出后件，排除。

> **结论**：当题干出现 $A \rightarrow B \rightarrow C$ 时，除了看 $A \rightarrow C$，还要优先检查 $
eg C \rightarrow 
eg A$。连续逻辑一旦串起来，端到端结论和整链逆否，就是最常见的两种考法。

这种看一眼结构就知道考官大概会把选项写成什么样，叫 sense。做得多以后，考官刚把两个逻辑连起来，你脑子里就已经跳出两种可能：

```text
A → B → C

常见考法一：A → C
常见考法二：非C → 非A
```

有预期，就先去选项里找；没有预期，也完全没关系，照常代入验证。

### 链条能连，就优先看两端

#### 从社会发展到教师素养

再看一道 2022 年江苏题。题干可以抽象为：

> 社会持续发展，需要培养大量高素质人才。

> 培养大量高素质人才，必然要求高校提升教育质量。

> 教育质量提升，又要求提高教师的整体素养。

谁是前提，谁就是必须具备的条件，箭头指向谁。整理后是一条链：

```text
社会持续发展 ──→ 培养大量高素质人才 ──→ 教育质量提升 ──→ 教师整体素养提升
```

A 说“只要社会持续发展，就要求提高教师的整体素养”，直接从链条起点走到终点，正确。

B 的前件是“没有大量高素质人才”。它否定了链条中间条件，无法沿着正方向推出“教育质量提升”；能推出的相关内容应当与社会持续发展方向一致，但 B 没有对应，因此不对。

C 的前件是“培养大量高素质人才”。这只能沿链条继续推出“教育质量提升”，不能倒着推出“社会持续发展”。逻辑不能逆推，C 错误。

D 写的是“如果处在知识经济时代，高校教育质量必定有所提升”。“知识经济时代”只是背景词，没有进入真正参与推理的箭头。不要看到题干里有它，就擅自把它接进逻辑链。

答案是 A。

> **易错点**：背景词、修饰语、现实因果，不等于逻辑前提。题干没有把它连进箭头，它就不参与推理。

这里还有一个很实用的考试策略：已经找到一个最标准、最严密的正确选项后，就不要对错误项追求完美。题目有且只有一个答案。A 从链条起点直接推到终点，形式漂亮、结构严密，B、C、D 就更没有必要反复纠结。

> **结论**：站在考官角度做题。找到最漂亮的正确选项，就把时间留给下一题；不要对错误项过度追求完美。

#### 从“智者”逆推到“听不进意见”

再看一道 2018 年四川题。题干三个条件可以抽象为：

> 如果一个人是智者，那么他一定谦虚。

> 谦虚，才能认识自己的不足。

> 如果听不见别人的意见，就不会认识到自己的不足。

前两步是：

$$智者 \rightarrow 谦虚 \rightarrow 认识自己的不足$$

第三步是：

$$
eg 听得进别人意见 \rightarrow 
eg 认识自己的不足$$

把第三步作逆否：

$$认识自己的不足 \rightarrow 听得进别人意见$$

这样也能接上，整条链变成：

```text
智者 ──→ 谦虚 ──→ 认识自己的不足 ──→ 听得进别人意见
```

考官最喜欢考它的两端：

$$智者 \rightarrow 听得进别人意见$$

或者：

$$
eg 听得进别人意见 \rightarrow 
eg 智者$$

B 正是第二种，正确。

A 从“认识自己的不足”直接推出“智者”，把中间链条跳得太狠。它最多只能先推出“听得进别人意见”，不能倒退到“智者”。

C 的前件是“听得进别人意见”。这是整条链的后件，肯定后件什么也推不出。

D 的前件是“认识不到自己的不足”。由否定中间条件，可以沿逆方向得到“不谦虚”或“不是智者”，但不能推出“听不进别人意见”。

所以选择 B。

看到没有？这道题与前一道几乎一个模子：题干把条件连成一串，正确选项就从链条首尾直接过去；不愿意找捷径，也逐项代入，照样能做。

> **结论**：连续链条能正推就直接正推，能整体逆否就整体逆否，别把一个本可一步完成的推理拆得七零八落。

### “除非……否则……”也要会翻译

再看一道 2020 年浙江题。题干只有两句：

> 除非采取大刀阔斧的举措，经济不可能稳健增长。

> 如果没有经济的稳健增长，公共债务就一定会不断攀升。

第一句是“除非 A，否则 B”，翻译为：

$$
eg A \rightarrow B$$

放到这里就是：

$$
eg 采取大刀阔斧举措 \rightarrow 
eg 经济稳健增长$$

第二句是：

$$
eg 经济稳健增长 \rightarrow 公共债务不断攀升$$

两句相连：

```text
不采取大刀阔斧举措 ──→ 经济不能稳健增长 ──→ 公共债务不断攀升
```

整条链的逆否是：

$$
eg 公共债务不断攀升 \rightarrow 采取大刀阔斧举措$$

D 选项正是这个意思，因此正确。

A 的前件“公共债务不断攀升”是整条链的后件，肯定后件不能反推，排除。

B 用“只有……才……”组织关系，应当从后往前看。它仍然把“公共债务不断攀升”放在前面，先肯定了题干后件，推不出后面的结论，排除。

C 的前件是“采取大刀阔斧举措”。题干第一条逻辑的前件是“不采取大刀阔斧举措”，C 恰好否定前件，推不出后件，排除。

所以答案 D。

> **定义**：“除非 A，否则 B”就是“如果没有 A，就会 B”，即 $
eg A \rightarrow B$。不要因为中文里没有显性的“如果”，就漏掉前面的否定。

“除非、否则、必须、只有、才能、唯有、前提、必要条件”说到底，都是在提示箭头的方向。只要结构翻译对了，具体句子讲的是财政、捕鱼还是精神，都只是字母换衣服。

### 重复条件一标字母，复杂链条瞬间变短

最后看一道 2019 年山东题。题干涉及供给侧结构性改革、顶层设计、公平竞争制度和创新驱动，文字一多，很容易绕进去。不要反复读长句，先给重复出现的内容贴标签。

设：

```text
A = 供给侧结构性改革
B = 竞争政策的基础性地位
C = 加强顶层设计
D = 公平竞争制度
E = 实现创新驱动
```

题干四组条件整理为：

$$B \rightarrow A$$

$$C \rightarrow B$$

$$C \rightarrow D$$

$$E \rightarrow B$$

结构一目了然：

```text
C（加强顶层设计）──→ B（竞争政策基础地位）──→ A（供给侧结构性改革）
│                             ↑
└──→ D（公平竞争制度）          E（创新驱动）
```

C 到 A 是连续链条，所以它的逆否也成立：

$$
eg C \rightarrow 
eg A$$

也就是：

> 如果不加强顶层设计，就不能推动供给侧结构性改革。

A 正确。

B 说“只有推动供给侧结构性改革，才能实现创新驱动”，翻译为 $E \rightarrow A$。但题干只给了 $E \rightarrow B$，由 B 不能逆推 A，因此 B 错误。

C 肯定了 D。D 在题干中只是 $C \rightarrow D$ 的后件，肯定后件什么也推不出，排除。

D 说“只有加强顶层设计，才能推动供给侧结构性改革”，翻译为 $C \rightarrow A$。可是 C 能推出 B 和 D，不能跨过 B 直接推出 A，所以 D 错误。

答案是 A。

> **提示**：练习时可以把完整文字整理成字母链；真正考试时不必写得像论文一样清楚，在题干旁边标几个字母、画两支箭头就够用了。目的只是让重复条件连起来，不是做漂亮的笔记。

这道题也说明了为什么要做标注。五个条件看着长，贴完字母以后，实际只有两条方向：

```text
C → B → A
E → B
C → D
```

结构一旦摊开，每个选项是在肯定前件、否定前件、肯定后件，还是试图跨步逆推，就全都暴露了。

### 把方法压成一张作战图

这套判断逻辑真假，真正要练的不是背诵术语，而是看到结构以后立刻行动。

#### 翻译只看信号词

| 题面表达 | 逻辑方向 |
| :--- | :--- |
| 如果 A，那么 B | $A \rightarrow B$ |
| 只有 A，才 B | $B \rightarrow A$ |
| A 是 B 的前提、必要条件或不可或缺的条件 | $B \rightarrow A$ |
| 必须 A，才 B | $B \rightarrow A$ |
| 必须 A，否则 B | $
eg A \rightarrow B$ |
| 除非 A，否则 B | $
eg A \rightarrow B$ |
| $A \rightarrow B$ 的逆否命题 | $
eg B \rightarrow 
eg A$ |

翻译句子时，不要看它“像不像”某个生活道理，只看标准信号词。没有信号词、又不懂怎样转成箭头的句子，先别硬转；标准逻辑条件已经列完，再去选项里找。

#### 验证只做代入

代入选项以后，按下面几类快速判：

- 否定题干前件，推不出，pass。
- 肯定题干后件，推不出，pass。
- 肯定完整前件，可以顺着推出后件。
- 否定完整后件，可以逆着推出否定前件。
- 只肯定“并且”前件的一部分，不算肯定完整前件。
- 选项后件与题干能推出的概念不完全相同，不能靠现实联系脑补。

#### 连起来先找两端

遇到 $A \rightarrow B \rightarrow C$，先看选项里有没有：

$$A \rightarrow C$$

或：

$$
eg C \rightarrow 
eg A$$

有就直接命中；没有，再逐项代入。这不是玄学，而是连续逻辑最稳定的命题形式。做得多了形成 sense，考官把两个逻辑一连，你就已经在猜他会从哪个端点出题了。

最后再提醒一句：刷题不只是为了选出一个答案。做完以后要想，考官为什么要把条件连起来？他为什么把某句话放在题干却不接进逻辑？为什么要把“疫苗研制水平”和“整体医疗科研水平”分成两个概念？这些才是考点。

> **结论**：形式逻辑不允许脑补，也不允许凭感觉绕路。把选项前件代回题干，把连续条件连成链，把链条首端和整链逆否优先找出来，这就是判断逻辑真假最稳、最快、也最不容易错的动作。

### 本讲提到的题目

#### 广东修改题：四个事实型判断

题干条件：喜欢打羽毛球 $\land$ 体育学院学生 $\rightarrow$ 喜欢登山。

四个事实判断分别是：

- 甲：喜欢打羽毛球，并且喜欢登山；
- 乙：体育学院学生，并且喜欢登山；
- 丙：喜欢打羽毛球，但不喜欢登山；
- 丁：不喜欢打羽毛球，并且喜欢登山。

甲、乙都只提供了部分前件并肯定后件；丁否定部分前件并肯定后件，均无法推出。只有丙能由“不喜欢登山”得到“不喜欢打羽毛球或不是体育学院”，再排除“喜欢打羽毛球”，推出“丙不是体育学院学生”。

**答案：D。**

#### 广东原题：事实藏进逻辑前件

题干条件与修改题相同，选项改为逻辑判断。

A 的前件是“喜欢打羽毛球且喜欢登山”；B 的前件是“体育学院学生且喜欢登山”；C 的前件是“不喜欢打羽毛球且喜欢登山”；D 的前件是“喜欢打羽毛球且不喜欢登山”。

A、B、C 都不能由题干必然推出后件。D 的前件与修改题中的丙完全一致，可以推出“不是体育学院学生”。

**答案：D。**

#### 2018 年浙江题：财政投入与疫情防控

题干逻辑可以整理为：

- 传染病多发 $\rightarrow$ 增加财政投入；
- 不增加财政投入 $\rightarrow$ 无法有效应对大面积疫情；
- 增加财政投入 $\rightarrow$ 疫苗研制达到世界先进水平。

A 从“不增加财政投入”推出“无法有效应对大面积疫情”，能够成立。B 肯定第三个逻辑的后件；C 否定第一个逻辑的前件；D 把“疫苗研制达到世界先进水平”换成“有效改善医疗科研水平”，均不能成立。

**答案：A。**

#### 2022 年四川题：行动展现与心理肯定

题干逻辑可以整理为：

- 认为自己最优秀 $\rightarrow$ 按最优秀者的标准要求自己；
- 相信自己能成功 $\rightarrow$ 一定成功；
- 在行动上充分展现自己 $\rightarrow$ 在心里肯定自己。

A 否定第一句前件，推不出；C 与“相信自己能成功就一定成功”相反；D 混淆“可能成功”与“一定成功”，且“只有……才……”方向错误；B 能由“在行动上充分展现自己”推出“在心里肯定自己”。

**答案：B。**

#### 2021 年江苏题：民族精神

题干可用逻辑为：

- 人无精神 $\rightarrow$ 人不立；
- 国无精神 $\rightarrow$ 国不强；
- 在历史洪流中奋勇向前 $\rightarrow$ 精神达到一定高度。

A 不能由“无精神则不立”反推出“有精神则立”；B 把“精神达到一定高度”的后件换成了无关的“灵魂”判断；D 肯定后件，不能反推；C 肯定前件，可以推出“精神达到一定高度”。

**答案：C。**

#### 2024 年广东题：捕鱼与资源

题干前两步为：

$$
eg 禁止捕鱼 \rightarrow 资源枯竭 \rightarrow 渔业生涯终结$$

整条链的逆否是：

$$
eg 渔业生涯终结 \rightarrow 禁止捕鱼$$

第三步为“鱼类资源良性循环 $\rightarrow$ 渔民收入得到保证”。A 与第一条逻辑的逆否结果相反；B 否定第一条逻辑的前件；D 否定第三条逻辑的前件；C 正好是前两步的整链逆否。

**答案：C。**

#### 2022 年江苏题：高素质人才与教育质量

题干逻辑可整理为：

- 社会持续发展 $\rightarrow$ 培养大量高素质人才；
- 培养大量高素质人才 $\rightarrow$ 教育质量提升；
- 教育质量提升 $\rightarrow$ 教师整体素养提升。

三步相连，A 可以由“社会持续发展”直接推出“提高教师整体素养”。B 的后件不对应可推出的结论；C 试图逆推；D 把“知识经济时代”这个背景词擅自接入推理。

**答案：A。**

#### 2018 年四川题：智者、谦虚与听取意见

题干前两步为“智者 $\rightarrow$ 谦虚 $\rightarrow$ 认识自己的不足”。第三步“听不见别人的意见 $\rightarrow$ 认识不到自己的不足”的逆否是“认识自己的不足 $\rightarrow$ 听得进别人的意见”，因此可连成：

$$智者 \rightarrow 听得进别人意见$$

其逆否为：

$$
eg 听得进别人意见 \rightarrow 
eg 智者$$

A 跨步逆推，C 肯定整链后件，D 从否定中间条件只能得到“不谦虚或不是智者”，均不能成立；B 与整链逆否一致。

**答案：B。**

#### 2020 年浙江题：大刀阔斧与公共债务

题干逻辑为：

$$
eg 采取大刀阔斧举措 \rightarrow 
eg 经济稳健增长 \rightarrow 公共债务不断攀升$$

整链逆否为：

$$
eg 公共债务不断攀升 \rightarrow 采取大刀阔斧举措$$

A、B 肯定整链后件；C 否定第一条逻辑的前件；D 与整链逆否一致。

**答案：D。**

#### 2019 年山东题：结构性改革与顶层设计

设 $A$ 为供给侧结构性改革，$B$ 为竞争政策基础地位，$C$ 为加强顶层设计，$D$ 为公平竞争制度，$E$ 为创新驱动，题干可整理为：

$$B \rightarrow A$$
$$C \rightarrow B$$
$$C \rightarrow D$$
$$E \rightarrow B$$

A 是 $C \rightarrow B \rightarrow A$ 的逆否，即“不加强顶层设计 $\rightarrow$ 不能推动供给侧结构性改革”。B 试图由 $E$ 跨步推出 $A$；C 肯定 $D$ 这一后件；D 试图由 $C$ 跨步推出 $A$，均不能成立。

**答案：A。**

## 判断逻辑真假：长题干快速破题法
> 对应块：BLK35 | 覆盖分集：P54 | 块标题（分集名）：《判断逻辑真假下篇》

判断逻辑真假的题，最容易让人心里发慌：题干一大段，逻辑关系藏在一堆抽象表述里，选项又特别长。好，2025 年国考的这道题就有点“不讲武德”——文字长、逻辑复杂，还要求一分钟内完成。我们不要再试着把每个字都嚼透，第一件事是先把题目放回它本来所属的题型。

> **结论**：看到题干集中出现多个逻辑关系，选项也全是“如果……那么……”这类带逻辑连接的表述，先判定为判断逻辑真假的题，不必先通读全文并翻译每一句话。

随后做的事情反而很朴素：把选项的前件代入题干，验证它能不能推出选项的后件。前提是，我们得先快速看清题干中的逻辑骨架。

### 标注字母，先搭逻辑骨架

先别急着看选项，也别急着纠结每一句到底是左推右还是右推左。给题干中反复出现的概念标上字母。命题、结论或具体表述首次出现时，给它一个字母；同一概念再次出现时，继续使用原来的字母。字母只是临时记号，不需要另外造词。

例如，2025 年国考这道题里可以把逻辑骨架标成：

- “完备的市场体系”记为 $A$；
- “提供企业竞争根基的商业规则或环境”记为 $B$；
- “围绕市场主体需求”记为 $C$；
- “深化要素市场配置改革”记为 $D$；
- “促进要素有序流动并提高要素配置效率”记为 $E$；
- “加强执法效率与司法保障”记为 $F$；
- “落实重大举措必备的战略思路”记为 $G$。

这组符号并不是题目原有的一串英文缩写，而是读题时临时建立的对应关系。读题时不必把它抄得工工整整，关键在于看到“完备的市场体系”时，立刻知道它对应 $A$；看到“提高要素配置效率”时，立刻知道它对应 $E$。判断时看的是概念对应关系，而不是字母本身。末尾标到 $G$，并不表示题干只有七句话，也不表示原句都已经被你完整翻译了。这一步的重点只有一个：先让选项里的长表述能快速回原文定位。

> **提示**：标字母的第二个作用，是迅速发现不同逻辑关系之间有没有相同概念。如果两条逻辑里出现同一个字母，考官就可能拿它做串联；没有重复概念，则先按单条逻辑验证。是否需要做更复杂的连逻辑，留到代入选项时再判断。

### 代入验证，先认箭头的方向

字母标好后，把选项代入题干。先看前件在题干里对应哪条逻辑，再确认能不能推出后件。真正代入时，才去看箭头方向。

以 2025 年国考题为例，可以把标准逻辑关系梳理成：

- “只有深化要素市场配置改革，才能形成完备的市场体系”，即 $D \rightarrow A$；
- “深化要素市场配置改革，必须促进要素有序流动并提高要素配置效率”，即 $D \rightarrow (E \land F)$；
- “只有商业规则完备，才能为企业竞争提供根基”，即 $B \rightarrow C$；
- “完备的市场体系”能推出“企业竞争根基”，即 $A \rightarrow C$。

题干的表述较绕，但判断真假时不必跟着文字来回翻译。代入时始终围绕概念做：选项前件对应 $D$，就沿 $D$ 能走的方向检查；对应 $E$ 与 $F$，就检查它们是否能推出结果；对应 $A$ 或 $B$，就沿着它们能推出的结果核对。

> **易错点**：肯定逻辑的后件，不能反推出前件；否定逻辑的前件，也不能反推出后件。这两种情况，后面那一半选项根本不用继续看。

#### 三个选项排除

2025 年国考题的 A 选项包含“只要形成完备的市场体系，就能……”这样的表述。其前件是 $A$，后件提到了 $E \land F$。题干虽然能推出 $A \rightarrow C$，却不能由 $A$ 推出 $E \land F$，因此 A 不对。

> **提示**：如果把 A 选项的结果改为 $E \land F$，这里反而是能够推出的。不要只要看到选项与题干使用相同概念，就草率地把它判成正确。

B 选项的前件是“加强执法效率与司法保障”，对应 $F$。题干中 $F$ 位于 $D \rightarrow (E \land F)$ 的后件，不能由 $F$ 反推出选项结果，故 B 不对。

C 选项的前件是“使国内市场形成完备商业规则”，对应 $B$。题干能由 $B$ 推出企业竞争根基，并进一步涉及执法效率、司法保障等要求，选项却把“促进要素有序流动、提高要素配置效率”接到了 $B$ 上，这段不能推出，故 C 不对。

> **结论**：A、B、C 都能迅速排除，答案就是 D。

#### 除非变换与否定链

D 选项使用“除非……否则……”。这类结构等价于：

$$P \rightarrow 
eg Q$$

它也可以转成 $
eg Q \rightarrow P$。因此，“除非 $H$，否则 $G$”可以先看作 $G \land H \rightarrow 
eg B$；当原句中的“不能成为企业竞争的市场根基”对应“不能形成完备商业规则环境”时，可以得到一条否定推导链：

$$
eg B \rightarrow 
eg C$$

所以 D 选项在题干中能找到有效推导，答案成立。

这道题文字很晦涩，却正好把整个套路都体现了：看到重复概念，用字母统一；再看选项方向，完成代入；能做逆否的就尝试逆否。真正熟练且冷静时，这道题确实可以在一分钟内解决。

### 找不到标准连词，先只抓“只有才”

接着看 2024 年国考题。题干中有一处明确的“只有……才……”，而选项都是“只要……就……”“如果……那么……”。不要被大段没有明显连词的文字吓住。我们先把“取之不尽、用之不竭”记为 $A$，“扎根人民”记为 $B$，那么题干的核心逻辑是：

$$B \rightarrow A$$

“只有扎根人民，创作才取之不尽、用之不竭”，重点是“扎根人民”是必要条件。只记住这一条，就能先优先寻找它的逆否命题：

$$
eg B \rightarrow 
eg A$$

选项中“如果不扎根人民创作，就不能取之不尽、用之不竭”，正好符合 $
eg B \rightarrow 
eg A$，可以直接选择 B 选项。判断时不需要逐字比较，而是看选项有没有复现这条关系。

> **结论**：先找标准逻辑连词，再找逆否命题。找到一个能由题干推出的选项，就可以选；确实找不到时，再回头考虑是否漏掉了某个条件。

至于“并伴随”一类表述，不要一见“并”就强行拆成标准逻辑关系。不要把“成为中子星并伴随磁场增强”硬读成 $A \land B$，否则这道题可能四个选项全部出错。考官没有把它设计成必须同时满足的两个条件，硬拆只会把题目做死。

判断的标准也很朴素：如果按照你的理解四个选项都错，说明理解得过头了。按考官的表达习惯理解“成为中子星”即可，不要强迫自己把每个细节都抬成“且”。

### 标准连词先画，非标准表述先放下

真正高效率的读题方式，不是强迫自己把题干逐句转成箭头。考场上先把最标准的连词找出来，例如“只有……才……”、“如果……那么……”、“必须……”“只要……就……”、“除非……否则……”。这些句子写出来；暂时不会转的句子，先放在原处。

这样做有充分的原因。考官设置考点，通常也集中在标准逻辑连词上。你完全可以先处理已经看得懂的箭头，尝试从选项中找答案。若找到了，就继续检查其余选项，让判断更稳；若找不到，再回头死磕之前放下的句子。给“每一句都必须标完”设目标，并没有必要。

这种“允许暂放”的态度，在恒星演化的题目里尤其关键。

题干第一句可以标成：恒星足够大 $A$，并且经过超新星爆发 $B$，才会坍塌成中子星 $C$。原句属于 $A \land B \rightarrow C$。

题干第二句：只有强大的磁场 $D$ 和高速自转 $E$，才能成为磁星 $F$，即 $(D \land E) \rightarrow F$。

题干第三句：只有中子星内部物质产生对流，才会伴随电流，标成 $G \rightarrow H$。

这些句子之间没有重复字母，便不需要强行考虑连逻辑，直接用单条逻辑代入即可。

#### 代入题干的四种情形

A 选项是“能够变成磁星的星体，中子星一定会产生强大的磁场”。它的前件是 $F$，后件是 $D$。由 $(D \land E) \rightarrow F$ 不能反推 $D$，所以 A 不对。若把“中子星”改为“强大磁场”或“高速自转”，方向与题干相反的风险就会改变，不能继续按原来判断。

B 选项是“拥有高速自转的中子星一定产生强大磁场”。题干是 $(D \land E) \rightarrow F$，高速自转 $E$ 位于后件，不能反推出 $D$。故 B 不对。

C 选项是“如果没有经历超新星爆发，就不会成为中子星”。因为 $A \land B \rightarrow C$ 包含 $B \rightarrow C$，所以取逆否可得：

$$
eg B \rightarrow 
eg C$$

这与 C 选项完全吻合。因此 C 正确。

D 选项以“对流”开头。题干第三条为 $G \rightarrow H$，而“出现对流”就是肯定 $G$。肯定前件能够推出 $H$ 的确没错，但判断真假的考查点不是“你能否顺着原逻辑走”，而是“选项给出的完整推理是否必然成立”。选项的后件是“出现电流”，题干似乎有“电流”，可题干里只有标准“只有……才……”可画。若这里真的是 $G \rightarrow H$，肯定 $G$ 当然能推出 $H$，可题干讲过“对流出现电流”不是吗？不对。这里说 $G \rightarrow H$ 只是我为了对应选项而临时造的符号，真正要核对的是选项与题干的完整表达是否一致。

> **易错点**：代入时以选项前件的原词定位，不以临时字母硬猜。除非题干确实有标准“只有……才……”，否则不要在非标准表述中强行添上“才会”。若 $G \rightarrow H$ 的确来自题干的“只有对流才会出现电流”，则肯定对流可以推出出现电流，D 也应正确；如果只有对流才出现电流是题干，D 不能说“不对”。这里必须承认逐字稿的识别存在歧义，应保守地保留已经能够确定的 C 选项，而不要补出题面原文。

这处逐字稿转写本身在“只要对流”与“只有对流”之间有歧义。任何文章都不该把这个信息缺口伪装成已经明确的事实。面对 D 时只要守住前面已经成立的 C 选项即可：确定 C 正确，D 选项没有必要作为正确选项一起成立。

### 不确定方向时，用选项的互斥检验

有的句子没有标准连词，方向一时拿不准：比如“在超大、特大城市积极稳步实施城中村改造，是改善民生的重要举措”。这到底是“实施改造”是必要条件，还是“改善民生”是必要条件？暂时没有把握，可以先别下结论。

与之配对的“落实这一重要举措必备的战略思路”则比较清楚：战略思路是必备的，所以是：

$$\text{落实城中村改造重要举措} \rightarrow \text{必备的战略思路}$$

第一条暂不定方向，先看选项。题目来自 2024 年山东，答案指向 D。核心线索是第二条逻辑的逆否命题：“如果不坚持稳中求进，就不能在超大城市落实城中村改造这一重要举措”，与 D 一致。

> **易错点**：不要把“重要举措”机械理解成“必要条件”。前面说了，城中村改造的箭头是前推后，意味着它自身是逻辑的前件，也是判断这个“重要举措”的充分性线索之一。不能因为一个表达里出现“重要”，就自行套用“重要条件”概念。

假如反过来把第一条理解成“改善民生 → 实施城中村改造”，A、B 两个选项都能得到支持，可一个题目不可能有两个正确答案。若把“实施城中村改造”理解成必要条件，结论也是相同。这说明对第一条的理解一定不对；考官的方向，应从选项的互斥检验中校正。

D 选项否定逻辑后件“坚持稳中求进”，可以推出前件“落实城中村改造重要举措”为假。C 选项肯定逻辑后件，不能反推出前件。A、B 都基于错误方向或错误逆否而不能成立。

> **提示**：假如选项里没有针对第一条的 A、B，立即选 D，完全无需研究第一条。选项本身就给足了校验条件。

这种技巧还有一个副产品：有时你能从选项的不同设置看出考官到底把哪一边当条件。普通逗号连接、表达不标准的句子，不能用逗号方向决定逻辑，必须依靠选项验证。

### “所有的 A 都是 B”统一前推后

2021 年北京那道题，是另一类常见文字风格：读起来像常识，逻辑却藏在“所有”“都”里面。

> **定义**：“所有的 $A$ 都是 $B$”就是 $A \rightarrow B$。看到“被选派为青年骨干教师的人，都不具有高级职称”，就把它拆成“青年骨干教师 → 不具有高级职称”，再把前件代入题干。

题干给出两类选派人员，选派人员要么是高级访问学者，要么是青年骨干教师。

高级访问学者需要同时满足：年龄在 40 周岁以上、具有高级职称，工作身份可以是教师或科研人员。这里包含两个并列的身份条件以及两个共同的结果条件。题目文字在转写时“教师或科研人员”可以视为并列身份要求，不影响推理。

青年骨干教师则需要：具有博士学位、近 3 年新进校。

先别把所有条件都建成复杂推理，只看选项需要的概念。

A 选项是“被选派为青年骨干教师的人，都不具有高级职称”。题干只规定高级访问学者具有高级职称，不能推出青年骨干教师都不具有高级职称，故 A 不对。

B 选项是“没有博士学位的人，都在 40 周岁以上”。这一项要经过两步：青年骨干教师必须有博士学位，所以没有博士学位的人不是青年骨干教师；所有选派人员是两类之一，所以此人应为高级访问学者；高级访问学者必须在 40 周岁以上，于是 B 可以推出。把“40 周岁以上”换成“具有高级职称”，同样能够推出。

C 选项是“科研人员都不在近 3 年内新进校”。题干没有给出“科研人员 → 不是近 3 年新进校”的必然关系。科研人员这个身份只出现在高级访问学者的要求中，否定或肯定某个分支的身份，不能越过分支去决定另一个分支。故 C 不对。

D 选项是“具有博士学位的人都在近 3 年新进校”。题干只保证“青年骨干教师 → 博士学位 ∧ 近 3 年新进校”，不能倒过来推“博士学位 → 近 3 年新新校”。具有博士学位的人可能是高级访问学者，不一定满足“近 3 年新进校”。所以 D 不对。

> **易错点**：肯定逻辑后件不能反推前件。题目只说明高级访问学者可能是科研人员、必须年满 40 周岁、必须具有高级职称；题干还明确指出选派对象属于两类之一，并不保证所有选派人员都是科研人员。

答案 B，它的推理链可以压缩为：

$$
eg\text{博士学位} \rightarrow 
eg\text{青年骨干教师} \rightarrow \text{高级访问学者} \rightarrow 40\text{周岁以上}$$

“所有”“都”只是把前推后的文字外壳换了一种写法，本质并没有改变。认出这一层，按部就班代入选项即可。

### 记住这套流程

判断逻辑真假的题，复杂的是文字包装，不是逻辑本身。做熟练了，都能在有限时间内做出正确判断。速度快不快，关键就看你是否能掌握几步固定的检查顺序。

第一步，判题型：题干有多个逻辑，选项也全是逻辑，按判断逻辑真假处理。

第二步，快速标字母：概念首次出现时记字母，后面出现继续用原字母；发现重复，留意有没有连逻辑。

第三步，代入选项：先把选项前件代入题干，验证能否推出选项后件；肯定逻辑后件，或者否定逻辑前件，都不能反推，所以后半部分不用看。

第四步，不会处理的先放：先转化标准逻辑连词；暂时没有方向，就先不画，等选项来校验。

第五步，利用选项校正理解：找不到正确项，或同时得到两个正确项，说明前面的理解有误，回到题干重新确认。

可以把这套动作在脑子里压缩成下面这个图：

```text
┌──────────────┐
│ 题干＋选项逻辑 │
└──────┬───────┘
       │
       ▼
┌──────────────────┐
│ 判题型：逻辑真假题 │
└────────┬─────────┘
         │
         ▼
┌────────────────────┐
│ 标字母、记重复概念   │
│ 找标准连词，定必要箭头 │
└────────┬───────────┘
         │
         ▼
┌──────────────────┐
│ 选项前件代入题干   │
│ 看能否推出选项后件 │
└────────┬─────────┘
         │
         ▼
┌────────────────────┐
│ 不能推出 → 换选项   │
│ 找到唯一正确项 → 结束 │
└────────────────────┘
```

真正需要反复提醒的，是不要强迫自己把所有文字都转成标准箭头。先看标准连词，先抓必要关系，先从最可靠的一处开始。考官没有针对某句话设计选项时，硬翻译那一句不仅浪费时间，还可能让原本简单的题变得一团乱。

## 逻辑真里怎么逼出事实真
> 对应块：BLK36 | 覆盖分集：P55-P56 | 块标题（分集名）：《推出矛盾与两难推理》

这类题在公考里出现得不算多，但它很值得掌握。

为什么？一方面，它能出得很简单，也可以出得很难，上限特别高，最能看出一个题目的技术含量；另一方面，后面的分析推理、图推一拖五等题型，很多都要用到“推矛盾”的思维。你得先把这里的基本模型建立起来。

不过，别一看到“矛盾”两个字，就把两条逻辑当成互相排斥。真正要先立住的是一句听起来反常识、实际上极其重要的话：

> **逻辑真，不等于事实真。**

$A \to B$ 成立，不等于 $A$ 为真，也不等于 $B$ 为真。这两种逻辑可以同时成立，也可以同时为真，丝毫没有什么矛盾。正因为如此，题干只给逻辑、选项却问事实时，我们要做的不是硬把逻辑“翻译”成事实，而是用推矛盾的办法，**把隐藏的事实真逼出来**。

### 先认题型：为什么题目逼你推矛盾

前两种题我们已经接触过。

一种是题干有事实真，选项也有事实真。把已知事实真代入逻辑，继续推就行。这类题很稳，属于要拿分的送分题。

另一种是题干给逻辑真、选项也给逻辑真。我们把选项的前半段代回题干，看能不能推出后半段。这就是判断选项逻辑真假的办法。

这一讲的情况不一样：

```text
题干：只有逻辑真
选项：却是事实真
                    ↓
          逻辑真推不出事实真
                    ↓
          必须找隐藏的事实真
```

看到“题干全是逻辑，选项全是事实”，条件反射就该出来：推矛盾，或者殊途同归。找到事实真以后，再把它代回题干，后半道题就变成了最开始的“事实真代入推理”。

### 推矛盾的核心：谁制造矛盾，谁就不能为真

推矛盾，也可以叫归谬。它不是直接证明某个事实，而是先作一个假设，再问：这个假设一旦为真，会不会把题干带进一个不能接受的局面？

我们先用一个小例子把它钉牢。

- 条件一：$A=5 \to A=4$。
- 条件二：$A=4 \to B=3$。

只看到这两条逻辑，我们什么也不能直接断定。$B=3$ 为真，第二条才启动，推出 $A=4$；再代回第一条，又推出 $A=5$，这就和条件一里的 $A=4$ 冲突了。

于是我们得到一个隐藏的事实真：$B
e 3$。

注意，最后不是说“条件一为假”，也不是说“条件二为假”。更准确地说，是条件二的前件 $B=3$ 假。条件一、条件和二两条逻辑完全可以同时为真；错的是把“$B=3$”这个事实当成了真的。逻辑链一启动，冲突便暴露出来。

> **定义**：推矛盾就是假设一个事实真为真，顺着题干的逻辑推出一个与已知事实或另一条件冲突的结果；谁让冲突发生，谁就不能为真。

```text
假设某个事实真
      ↓
顺着逻辑链启动后续条件
      ↓
得到互相排斥的事实
      ↓
启动者与结果相矛盾
      ↓
隐藏的事实真：启动者为假
```

生活中其实经常在用这套办法。

“**如果他能听你的话，太阳就从西边出来了。**”这句话的重点不是在预测日出，而是在强调：他不会听你的话。太阳不会从西边出来，这件事一旦被假设为真，就说明“他听你的话”不能成立。

“**如果这事像他说的那么简单，就见鬼了。**”意思也很明确：如果他说得对，就要推出“见鬼”这个事实；见鬼不可能，因此他说的一定不对。

“**如果他靠得住，猪都能上树。**”别想“我家猪也许真上过树”，这句话就是靠常识把前提顶回去，从而强调“他靠不住”。大家别想太多，日常语言里那些很有气势的话，往往就是用矛盾来强调事实。

“**山无棱，天地合，乃敢与君绝。**”这里用“只有……才……”的逆否关系：如果“与君绝”，就要求“山无棱、天地合”真的发生；可这是不可能发生的，所以“与君绝”不能为真。

我们不是为了讲几句俏皮话才举这些例子。我们要练的是：看到一个“假设某个事实真”的句子时，马上问一句——**它启动后，会不会撞上一个不可能的事实？**

### 两块最核心的模型

#### 前件一触发，前件就不能为真

第一个模型是：

\[
A \to B
\]

\[
A \to 
eg B
\]

这两条逻辑并不矛盾。它们可以同时为真，但只要 $A$ 为真，第一条会推出 $B$，第二条会推出 $
eg B$，一个 $B$ 不能又真又假。

所以，冲突的“始作俑者”就是 $A$，隐藏的事实真是 $
eg A$。

遇到这两条，看到它们就直接想到：$A$ 不能为真。

#### 殊途同归：不管前提怎么走，都得到同一个结果

第二个模型常被叫作“两难推理”，不过理解成“殊途同归”反而更顺：

\[

eg B \to 
eg A
\]

\[
B \to 
eg A
\]

$B$ 只有真、假两种可能。$B$ 真，走第二条；$B$ 假，走第一条。无论走哪条路，最后都到 $
eg A$。

所以，$
eg A$ 是隐藏的事实真。

这两个模型在底层其实是一回事。将第一个模型的两条命题分别取逆否：

- $A \to B$ 的逆否是 $
eg B \to 
eg A$；
- $A \to 
eg B$ 的逆否是 $B \to 
eg A$。

正好就是第二个模型。

> **结论**：看到“同前件、异后件”，就按“前件为假”推；看到“一个命题和它的否定各自都能推出同一结论”，就按殊途同归推。两条路想用哪条用哪条，结果完全相同。

### 真正上手：连逻辑、找始作俑者、代入

模型认出来还不算完。考题里的逻辑不会整齐地排成两行等我们套公式，真正要练的是把散落条件连成一条链。

先看一个很直观的例子：

- 小张优秀 $\to$ 被聘用；
- 小张优秀 $\to$ 不被聘用。

若两句话都是真话，就说明小张不能优秀，隐藏的事实真就是“**小张没有被评为优秀**”。

再比如三条条件：

- 不学电吉他 $\to$ 当不了乐队主唱；
- 玩乐器 $\to$ 学电吉他；
- 不玩乐器 $\to$ 当主唱。

第一条的逆否是“当主唱 $\to$ 学电吉他”。于是“玩乐器”和“不玩乐器”两支都通向“学电吉他”，殊途同归，答案是学电吉他。

这题也可以不用殊途同归。把第二条取逆否后写成“不学电吉他 $\to$ 不玩乐器”，再接“不玩乐器 $\to$ 当主唱”，就得到“不学电吉他 $\to$ 当不了主唱、又能当主唱”，矛盾，所以“不学电吉他”不能为真。两道方法，最后得到的都是“必须学电吉他”。

> **易错点**：不要把“$A \to B$ 与 $A \to 
eg B$ 矛盾”当成逻辑式彼此矛盾。真正冲突的是假设 $A$ 为真以后，分别被推出的 $B$ 与 $
eg B$。我们要否定的，是启动链条的 $A$，不是笼统地说某条条件为假。

连逻辑时，有几个顺手的小习惯。

前件是“或”，其中一肢为真，就能启动后件；后件是“且”，两肢都为真，才能把这条推理接出去。某条逻辑的某个中项接到另一条的前件、后件上时，就尝试用逆否把它们改写成相同形状。条件允许时，优先找同前件、同后件；接不上再改写，不要在一处死磕。

连接以后，不要问“这里谁对谁错”，要问三件事：

- 哪条事实一启动，后面的矛盾就会被带着跑出来？
- 矛盾的结果具体是什么？
- 把这个始作俑者取反后，其他条件还能推出哪些事实？

这才是完整的解题闭环。

### 文字转逻辑，最容易翻车的地方

很多题做错，不是推矛盾不会，而是题干一句话被读成了另一种关系。

比如“**不能剧烈运动和喝酒**”，并不是“只要不喝酒，哪怕剧烈运动也行”。它是“不能剧烈运动，也不能喝酒”。前面的“不能”可以带到后面的并列项上。

同理，“**不去丹麦和冰岛**”在这里表达的是既不去丹麦，也不去冰岛。若要表达“既不去丹麦，又去冰岛”，就得把谓语重复出来：**“不去丹麦和去冰岛”**。

而“丹麦和冰岛不能同时去”则是另一回事：$ 
eg\text{丹麦} \lor 
eg\text{冰岛} $。只要有一项没去，就符合，不能把它误读成“两项都没去”。

> **提示**：转译时别凭一个“和”字硬猜。看看前后谓语能不能共享、题干有没有“同时”“都”“至少”“至多”这些提示，再把关系写出来。

### 把一套方法打穿：从个人状态到分组名额

“逻辑真、选项事实真”只是入场券，连逻辑本身并不难。下面几类题把同一个方法不断换皮，题型可以很难，底层却没变。

#### 离散数学与计算机报考

2018 年浙江题给出三条逻辑：

- 不学电吉他，就当不了乐队主唱；
- 玩乐器，就会选择电吉他；
- 不玩乐器，就当主唱。

前面已经拆过：主唱 $\to$ 学电吉他，所以玩乐器、不玩乐器都推出学电吉他，答案是学电吉他。

2023 年北京题的结构也很典型：

- 喜欢离散数学，就报考计算机；
- 不喜欢离散数学，就成为算法程序员；
- 不报考计算机，就不成为算法程序员。

第三条的逆否是“成为算法程序员 $\to$ 报考计算机”，接上第二条，就得到“不喜欢离散数学 $\to$ 报考计算机”；第一条又给出“喜欢离散数学 $\to$ 报考计算机”。两支都到报考计算机，答案就是一定报考计算机。

反过来取第三条的逆否“不报考计算机 $\to$ 不喜欢离散数学”，再和第二条的逆否“不报考计算机 $\to$ 喜欢离散数学”放一起，$A$ 假设一启动，就同时推出喜欢与不喜欢。这时再推矛盾也一样。

> 殊途同归和推矛盾不是两种“碰巧能对”的技巧。前者说两条路都到，后者说假设某条路为真会撞墙；它们只是看矛盾链的两种方向。

#### 2017 北京：鲫鱼和鲤鱼的上涨

这题抓住“鲫鱼和鲤鱼至少有一种上涨”与“只有鲫鱼上涨，鲤鱼才上涨”。

“或”的逻辑是：否定一边，就能推出另一边。因此，鲫鱼不上涨 $\to$ 鲤鱼上涨，鲤鱼不上涨 $\to$ 鲫鱼上涨。

“只有鲫鱼上涨，鲤鱼才上涨”只能后推前：鲫鱼上涨 $\to$ 鲤鱼上涨；其逆否是：鲤鱼不上涨 $\to$ 鲫鱼不上涨。

假设鲫鱼不上涨，就会既推出鲤鱼上涨，又推出鲤鱼不上涨。鲫鱼不上涨不能为真，所以鲫鱼一定上涨。由鲫鱼上涨，鲫鱼不上涨为假，再做逆否，可以确定鲤鱼也上涨。答案是两者都上涨。

#### 北欧旅行：先去撞矛盾，再逆否拿全信息

一条条件说：去挪威，就既不去丹麦，也不去冰岛。另一条说：去冰岛，就去挪威，也去丹麦。

后一条中的“非冰岛”一出现，便能把两条接起来。若去挪威，会经由第一条得到“非冰岛”；再由后一条得到“去冰岛、且去挪威和丹麦”。这里真正发生的是“既不去丹麦又去丹麦”，矛盾。

所以，始作俑者是“去挪威”这个事实。隐藏的事实真就是“不能去挪威”。

> **注意**：链条推导的只是逻辑成立时的事实，不表示“去挪威”本身一定为真。正因如此，能用逻辑链撞出冲突的，是我们对“去挪威”的假设。

一旦确定不能去挪威，儿子的条件“非挪威 $\to$ 去瑞典和芬兰”就被启动；再去掉第一条的后件“非冰岛”，也可以由逆否得到“不能不去冰岛”。所以一定去瑞典、芬兰、冰岛。

这一题还藏着一个语言陷阱：前一位说的是“去挪威，就不去丹麦和冰岛”，这是两个后件都要假，写作 $
eg\text{丹麦} \land 
eg\text{冰岛}$。别把它理解成“不能同时去”。

#### 2024 国考预选：被卡的甲与乙

题目有三条条件：

- 甲、乙均未通过 $\to$ 丙通过；
- 乙通过或丙通过 $\to$ 丁通过；
- 甲通过或乙通过 $\to$ 丙通过，但丁不通过。

第三式的前件是“甲或乙”，其中任何一人为真，就会带来“丙通过且丁不通过”。

此时，丙通过又能启动第二式，推出丁通过。于是丁既通过又不通过，矛盾。始作俑者是第三式的前件“甲或乙”，所以它不能为真：

\[

eg\text{甲} \land 
eg\text{乙}
\]

把这个事实代入第一式，丙一定通过；再由第二式，丁也一定通过。答案是丙、丁都通过，甲、乙都不通过。

这里特别能说明“始作俑者”怎么找：第三条推出“丙、丁”，第二条又把“丁”翻成另一种状态，冲突不是因为第三条自己前后乱写，而是它让整条链撞上了其他条件。

#### 两道考研题：一个靠“要么……要么”，一个靠“只要有”

2023 年管综联考那道题，可整理为：

- 买橱柜，就不买卫浴和供暖；
- 不买卫浴，就不买橱柜；
- 不买卫浴或不买橱柜，就买供暖。

把第二条取逆否可得“买橱柜 $\to$ 买卫浴”，它和第三条里的“不买卫浴”接上：买橱柜 $\to$ 不买卫浴，也买供暖；但第一条又说买橱柜就不能买供暖，矛盾。因此不能买橱柜。

非橱柜代入条件，不买橱柜 $\to$ 不买卫浴；再接第三条可得供暖。既然不买卫浴或不买橱柜，就买供暖，故答案是卫浴、供暖都买。

2024 年考研那道题包含“跳水或射箭”“射箭或短跑 $\to$ 体操”以及由短跑、篮球的否定组织出跳水的条件。

若不跳水，由第一个“或”得到射箭；射箭再启动第二个条件，得到体操。

若跳水，由第三个条件取逆否，可得到短跑；短跑再启动第二个条件，也得到体操。

无论跳水还是不跳水，都到体操，这就是标准的殊途同归。也可以从“非体操”出发：它能同时否定第二个条件里的射箭和短跑，再分别与“或”条件连接，推出既跳水又不跳水，矛盾，所以必须选体操。

#### 江苏事业单位：同一套路，换一个连接点

原题大意是：

- 生态 $\to$ 人工智能且能源；
- 教育或医药 $\to$ 人工智能且能源。

“教育或医药”这一支为真，就能启动后件，推出人工智能、能源。假设“教育或医药”成立，则人工智能一方面被推出为真，另一方面在生态支上被推出为假。始作俑者“教育或医药”不能为真，故教育、医药都必须选。

确定教育后，教育这个“或”的一肢就能启动后件，因此人工智能、能源也要选。四个都必须投，唯一推不出的是生态。

考官还能把条件改动一点，让原本的“人工智能”接不上，转而接到“医药”上；连接点一变，始作俑者变了，结论也会跟着变。形式上只改几个字，逻辑内核仍是一套：写逻辑、连逻辑、找始作俑者、取反、代回条件。

### 分组互斥题：难的是设定，不是新公式

#### 七个部门并入三个子公司

这道 2020 年考研题的难点，是“一 个部门只能合并到一个子公司”这个硬设定。

七个部门要并入三个子公司，一个部门不能同时去两家。题干给出两条逻辑：

- 若丁、丙至少有一人没有并入甲公司，则戊、甲都并入甲公司；
- 若甲、乙、庚中至少有一人没有并入丙公司，则戊并入乙公司、丙并入丙公司。

先假设“甲并入甲公司”。由于一个部门只能进一家，此时必有“甲没有并入丙公司”。

第二条的前件是“甲、乙、庚至少一人没有进丙公司”，前件已经是“或”，其中一肢为真就够，所以它可以启动，推出“戊进乙公司、丙进丙公司”。

第一条也会被“丙没有进甲公司”启动，推出“戊进甲公司”。这样，戊既进甲公司又进乙公司，与互斥设定矛盾。

始作俑者是第一条的前件“丁没进甲公司或丙没进甲公司”，所以它为假，得到丁、丙都进甲公司。答案就是丁、丙均并入甲公司。

> **提示**：遇到分组、分配、匹配题，先把“唯一归属”“不能重复”写成硬约束。这类题不一定条件多，但硬约束一旦接到逻辑链上，就是极强的矛盾源。

#### 七个参会者分三组

2023 年上海题把七个人分到三组，每组二至三人，每个人只能去一组。它用“若干人中至少一人分配到某组”表达一个前件为“或”的逻辑，再把不同条件接在一起。连接之后，有人会被同时推去甲组和乙组，违反唯一归属，因此与“张、赵不能进乙、丙组”相矛盾，迫使张、赵都进甲组。

再往下，张、赵进甲组后，与甲组相关的条件启动，推出王、李、孔不能进甲、丙组，于是三人只能进乙组。剩下的陈某便必须进丙组。

这类题看着长，拆开后仍是一次“假设某人进某组—接出另一组—触发互斥”。把“每人只能进一个组”记牢，难点就降下来了。

#### 七名同学分就业、考研、留学

2025 年四川题同样是七人分成就业、考研、留学三种去向，每人只能选一种，题干给出三条逻辑。

题目问谁一定留学。直接把“乙、丁不就业且不考研”当作待检验的假设：如果乙、丁两个前件同时为真，它们既不是就业，也不是考研，就只能留学。把它代入后面的条件，又能推出乙去就业，同时由另一条链推出乙去考研，矛盾。

所以“乙、丁既不就业又不考研”的假设不能为真，乙、丁必须留学。熟悉套路的考场上，可以直接从“留学”反推：既不就业又考研，不就业就只能留学，答案秒选。

这类题最容易给人的错觉是“题干给得太绕”。其实不用绕远路。选项问留学，就把就业、考研先否掉；问一个具体人，就假设他的具体去向，再看能否撞上互斥事实。

### 入选名额：矛盾也可以来自“名额有限”

推矛盾不只有“既真又假”一种来源。

如果题干规定“四人选三”，那么任何人一旦被推出“入选”，其他条件又把他推成“也入选”，最终就可能把四个人都推入选，违反“只有三个名额”。这就是**入选名额型矛盾**。

它和前面的模型没有本质区别，只是矛盾对象换了：

```text
逻辑链推出某人入选
          ↓
其他条件又推出另一个不应入选的人
          ↓
入选总人数超过规定名额
          ↓
启动整条链的事实不能为真
```

这类题的题干特征很固定：题目先告诉你“几选几”，然后用逻辑条件把名额卡住。

#### 四选三：全被推出，就是矛盾

一道比赛结果题给出：四位选三，三位判断者的说法都为真。判断链可以连成：

\[
\text{张入选} \to \text{李入选} \to \text{刘入选} \to \text{田入选}
\]

如果张入选，链条会推出四人全部入选，和“四选三”矛盾。所以张没有入选。问谁没获奖，答案就是张。

这里不是“张、李、刘、田四人不可能按顺序得奖”，而是“张一旦得奖，逻辑链会迫使四个人都进入名额”，超出名额上限，张才被排除。

#### 五选三：先锁不入选名额

2017 年上海题的五人分别为张、王、李、赵、陈，规则是五选三，也就是三个入选、两个不入选。

条件有：

- 张、王至多选一个；
- 张、王、李、赵至少选一个；
- 不选张，就不能选赵；
- 选李，就选王。

设问五人中谁一定入选。

从王切入：

- 若王不入选，根据“张、王至多选一个”，可得张不入选。两个不入选名额已经锁定，因此李、赵、陈全部入选。
- 若王入选，由“张、王、李、赵至少选一个”可知张、李、赵至少有一人入选；这里先把条件二按“否定一边推另一边”的形式使用，可得张不入选，再由“不选张 $\to$ 不选赵”，得到张、赵都不入选。两个不入选名额也锁定，李、陈入选。

无论王选不选，陈都入选。这就是殊途同归，答案选陈。

你也可以从张开始：

- 张不入选，赵也不入选，剩下王、李、陈全入选；
- 张入选，则由第一式可得王不入选，再由“选李 $\to$ 选王”的逆否得到李不入选，因此赵、陈入选。

仍然是殊途同归，结论完全一样。起点可以换，结果不会换。

#### 七人评优：否定一个后件，直接锁满不入选名额

2024 年四川题是七人团队中有四人评优，题干给出一些分组限制，并有“若甲或乙优秀，则陈也优秀”的条件。

若陈不优秀，做逆否可得甲、乙也不优秀。七人中已经锁定三人不入选，正好是三个不入选名额，于是剩余四人全部入选。

若陈优秀，则至少可以确定陈一人入选。

题干只可能有这两种大类情况，所以选项若表达“陈优秀”，或者“甲、乙及其余可入选者中的某一人优秀”，都能覆盖。结果是：陈与剩余四人中的任一人，二者必居其一。

再假想一个附加条件“陈 $\to$ 肖”，那么 $ 
eg\text{陈} \to \text{肖} $ 和 $ \text{陈} \to \text{肖} $ 就成了殊途同归，肖一定入选。考官只需要加这样一个条件，答案立刻收紧为“肖”。这就是名额题常见的微调方式。

#### 男女名额：先数不入选，再套同一结构

2025 年广东题是七名研究生中选四名，其中两名男生、两名女生，另有逻辑条件可推出：某个前件不成立时，刘、吴都不入选。

若前件不成立，就已经有刘、吴两名不入选；第三名不入选由题干对应条件获得后，剩下四人全部入选。若前件成立，则至少有该前件对应的这一人入选。

因此，答案必须是“前件对应的这个人”或者“另外四个全部入选者中的任意一人”二选一。逐项排除，就能定位到正确选项。

这仍然是“人数上限制造矛盾”的老套路。和公式变化相比，题目更常变的是人数、名额、互斥规则，这些文字一旦转成逻辑链，推矛盾就回到熟悉的位置。

### 两难模型怎么落地

最后再把“殊途同归”说得更具体一点。

看北京那道离散数学题，核心不是见到“非”就要推，而是要把“喜欢”和“不喜欢”这两个穷尽可能都试一遍。只要两种情况都推出同一个事实真，就锁定了答案。

同样的方法也可以用来直接做 2017 年北京题：鲤鱼不上涨，鲫鱼一定上涨；鲤鱼上涨，由于“鲫鱼上涨 $\to$ 鲤鱼上涨”，鲫鱼也上涨。两条路都到鲫鱼上涨，这就已经拿到了一个确定事实。

很多看似非常难的分组题，也可以这样做：

- 假设甲进一号组；
- 假设甲不进一号组；
- 如果两组都推出“甲进二号组”或“甲一定不能进一号组”，就已经找到了隐藏事实；
- 再把这个事实代回，不必把所有排列都列出来。

所以“推矛盾”和“两难”并不是两个孤立章节。前者是从矛盾处逼出假，后者是穷尽可能后确认同一个真；它们只是在描述同一套推理的不同方向。

> **结论**：题干全是逻辑、选项全是事实，先找矛盾的始作俑者，或找殊途同归的终点；一旦得到隐藏事实真，后半程就是把它代入逻辑。能连成一条链就别拆开算，能用逆否就别硬背原命题。

这套方法有上下限：简单题可以两三步秒杀，难题则会把语言、互斥、名额、否定命题全裹在一起。真正让考场上的“新题”变成“做过的题”的，不是刷过多少，而是有没有看懂每一道题为什么矛盾、谁制造了矛盾，以及为什么要取它的反。

### 本讲提到的题目

2. **2018 浙江：不学电吉他与乐队主唱**：条件为“不学电吉他 $\to$ 当不了乐队主唱”“玩乐器 $\to$ 学电吉他”“不玩乐器 $\to$ 当主唱”。解析：主唱 $\to$ 学电吉他，玩乐器与不玩乐器都推出学电吉他。答案：学电吉他。

3. **2023 北京：离散数学与计算机**：条件为“喜欢离散数学 $\to$ 报考计算机”“不喜欢离散数学 $\to$ 成为算法程序员”“不报考计算机 $\to$ 不成为算法程序员”。解析：成为算法程序员 $\to$ 报考计算机，两种离散数学态度都到报考计算机。答案：一定报考计算机。

4. **2017 北京：鲫鱼和鲤鱼**：以“鲫鱼和鲤鱼至少有一种上涨”“只有鲫鱼上涨，鲤鱼才上涨”等条件判断两者上涨情况。解析：假设鲫鱼不上涨，会同时推出鲤鱼上涨与不上涨；排除该假设后，鲫鱼上涨，再逆否确定鲤鱼上涨。答案：鲫鱼、鲤鱼都上涨。

5. **2020 北欧旅行**：去挪威 $\to$ 不去丹麦且不去冰岛；非冰岛 $\to$ 去挪威且丹麦；非挪威 $\to$ 去瑞典和芬兰。解析：去挪威会产生“既去丹麦又不去丹麦”的冲突，假设被排除。答案：不去挪威，一定去冰岛、瑞典、芬兰。

7. **2023 管综联考：橱柜、卫浴、供暖**：条件为“买橱柜 $\to$ 不买卫浴且供暖”“不买卫浴 $\to$ 不买橱柜”“不买卫浴或不买橱柜 $\to$ 买供暖”。解析：买橱柜会既不买卫浴、买供暖，又因不买橱柜买到卫浴，冲突。答案：不买橱柜，买卫浴和供暖。

## 代入验证：找到前真后假就够了
> 对应块：BLK37 | 覆盖分集：P57 | 块标题（分集名）：《代入验证寻找矛盾》

一道题明明给了具体情境，为什么我们不跟着文字一点点推，反而可以“秒杀”？

因为问法已经把路指出来了：只要题目问“一定为假”“不可能为真”或者“说法有误”，我们就不必证明题干所说的事情如何发生，只要找一个**能够证明它不成立**的情况。这个情况就是：前件为真，后件为假。

这一章练的正是这件事。把逻辑关系抽出来，箭头从谁指向谁固定好，再把选项代进去，前后件一对照，答案就出来了。文字写得再绕，也绕不过这条结构规则。

### 先看问法，再决定怎么选

前面学的很多题，问的是“一定为真”“能推出什么”，需要顺着题干逻辑往下推。代入验证找矛盾恰好反过来。

题干问“一定为假”，我们就去找与题干矛盾的选项。问“不可能为真”“证明专家的说法有误”“以上断定不成立”，本质上都是同一件事：找前真后假。

问“可能为真”或者“满足条件”，做法也没有换一套逻辑，只是选择方式变了：把与题干矛盾的选项逐个排除，剩下的那个才是答案。这里的“找三次矛盾”，不是找三个一模一样的句子，而是在通常四个选项的题型中，把三个一定为假的选项找出来。找不到矛盾的那一项，才有可能是真的。

> **结论**：问“不可能为真”，就找一个前真后假；问“可能为真”，就排除所有前真后假，剩下哪项选哪项。

第一步永远是看题干问什么。问法一锁定，考查的套路也就锁定了。不要先被一大段叙述带着跑，更不要还没判断问法，就开始尝试用正向推理硬算。

### 一个逻辑为假，只需一种情况

先看最基本的结构：

$$
A \rightarrow B
$$

当 $A$ 为真时，$B$ 一定真，我们才说这个推出式成立。什么情况下这个逻辑不成立？只有在前件 $A$ 真、后件 $B$ 假的时候。

> **定义**：“$A$ 推出 $B$”为假，等价于“$A$ 真且 $B$ 假”。

写成公式，就是：

$$
A \rightarrow B \quad \bot \quad (A \land 
eg B)
$$

这里最需要分清的是：**前件为真，不等于推出式为真。** $A$ 可以确实发生了，但如果 $B$ 没有跟着发生，$A \rightarrow B$ 仍然是假的。我们要检查的不是前件本身，而是这个逻辑有没有在自己的条件下兑现。

比如小张说：“如果我中了 500 万，我就送你一套房子。”什么情况能说明这句话不成立？只有小张中了 500 万，却没有送房子。

- 只中了奖、没买房：前真后假，承诺落空。
- 只买了房、没中奖：条件没有发生，不能据此否定承诺。
- 两件事都没有发生：同样不能证明小张一定会送房子。

换成“发了奖金就请吃饭”也是一样。发了奖金却没有请吃饭，这个逻辑才为假。至于具体是奖金、吃饭，还是中奖、房子，并不会改变判断方式。

#### 换一种方式，也得到前真后假

一开始不习惯“前件真、逻辑反而假”，可以先把推出式换成等价的或命题：

$$
A \rightarrow B \;\Leftrightarrow\; 
eg A \lor B
$$

要让“$
eg A \lor B$”为假，就要对整个或命题取否定：

$$

eg(
eg A \lor B) \;\Leftrightarrow\; A \land 
eg B
$$

这就又回到了前件为真、后件为假。因为“$A$ 推出 $B$”与“$
eg A \lor B$”是一回事，所以它们也必然有同样的矛盾关系。

> **提示**：刚开始不理解时，可以多做一次“推出式换成或命题”的变形。等这个转换变得自然，就直接记住“前真后假”，不用每次都从头推。

### 箭头方向不能看错

同一组内容，箭头换向以后，逻辑就可能不一样。

$A \rightarrow B$ 的前件是 $A$，后件是 $B$，为假时需要 $A \land 
eg B$。而 $B \rightarrow A$ 的前件、后件跟着换位，为假时需要 $B \land 
eg A$。

> **易错点**：一定按题干给出的方向识别前后件。不能因为读起来不顺，就擅自调换箭头。

如果题干使用“只有……才……”这样的表达，要先按“后件推出前件”处理。比如“只有出海或者潜水，天气才会晴朗且温度适宜”，结构应当是：

$$
(\text{出海} \lor \text{潜水}) \rightarrow (\text{天气晴朗} \land \text{温度适宜})
$$

它为假的情况，就是已经出海或者潜水，但天气不晴朗、温度也不适宜。

箭头方向一固定，后件再复杂，也只是“后件整体为假”这一件事。完全不需要把整句话再翻译一次。

### 后件不管多复杂，都先找前件

代入验证时，先在题干里圈出逻辑，再把选项给的具体情况拆成前件、后件两部分。选项若能让前件为真，同时让整个后件为假，就完成了矛盾验证。

比如小张和小李都去参加会议，那么小王不会去参加会议。逻辑是：

$$
(\text{小张去} \land \text{小李去}) \rightarrow 
eg \text{小王去}
$$

要让这句话为假，前件要真：小张和小李都去了。后件要为假：小王“不去”是假的，也就是小王也去了。完整情况就是三个人的判断都变成“去”，此时原来的断定不成立。

> **结论**：不要在选项里寻找“前件真、后件也真”的情况。只要前后件都符合，它还不足以推翻题干；真正要抓的是前件真、后件假。

这里的“前件”可能是单句，也可能由多个条件合取而成。“后件”可能是一句话，也可能包含或、与、非。结构不同，拆法不同，但检验标准始终不变。

### 后件里的或与、和与非

最常见的后件是析取式。

#### 后件是“B 或 C”

如果原逻辑是：

$$
A \rightarrow (B \lor C)
$$

要让整个后件“B 或 C”为假，就要两个部分都不成立，即 $
eg B \land 
eg C$。所以整个逻辑的否定是：

$$
A \land 
eg B \land 
eg C
$$

比如“宅在家里，就能找到男朋友或者发胖”，表述虽然生活化，结构却非常整齐：宅在家里的确发生了，却既没找到男朋友，也没有发胖，这一推出式就为假。

这里不要把“或”理解成前件发生时，两个结果必须一起发生。恰恰相反，要否定“B 或 C”，必须让 B、C 同时为假。

#### 后件是“B 且 C”

如果原逻辑是：

$$
A \rightarrow (B \land C)
$$

后件要求 B 和 C 同时为真。只要其中一个不成立，整个“B 且 C”就不成立。因此它的矛盾条件是：

$$
A \land (
eg B \lor 
eg C)
$$

比如“坚持锻炼身体，心情会变好，身体也会变好”。如果确实坚持锻炼了，但心情没变好，或者身体没变好，就出现了前真后假。

> **提示**：“或”和“且”不能靠直觉处理。否定“B 或 C”，要求两个都假；否定“B 且 C”，只要一个不成立就行。逻辑形式一变，矛盾条件就跟着变。

#### 后件中带着否定

后件里已经有一个“非”时，也不用绕着文字走，仍然对整个后件取否定。

例如：

$$
A \rightarrow (B \lor 
eg C)
$$

后件为假，等价于：

$$

eg(B \lor 
eg C) \;\Leftrightarrow\; 
eg B \land C
$$

所以整个逻辑的否定是：

$$
A \land 
eg B \land C
$$

无论后句写成“B 或者非 C”，还是用生活语言把它藏起来，做法都是一样的：先确认 A 真，再判断整个后句是否假。

### 把常用结构一次理顺

记住前真后假之后，下面这些形式都可以直接用同一套方法处理。下表只负责校对结构，不要求死背；真正做题时，先看箭头，再看后件括号里到底是什么。

| 推出式 | 与之矛盾的论述 |
| :--- | :--- |
| $A \rightarrow B$ | $A \land 
eg B$ |
| $A \rightarrow (B \lor C)$ | $A \land 
eg B \land 
eg C$ |
| $A \rightarrow (B \land C)$ | $A \land (
eg B \lor 
eg C)$ |
| $A \rightarrow (B \lor 
eg C)$ | $A \land 
eg B \land C$ |
| $(B \lor C) \rightarrow A$ | $(B \lor C) \land 
eg A$ |
| $B \land C \rightarrow A$ | $B \land C \land 
eg A$ |
| $B \land 
eg C \rightarrow A$ | $B \land 
eg C \land 
eg A$ |
| $C \land D \rightarrow (A \lor B)$ | $C \land D \land 
eg A \land 
eg B$ |

遇到“B 或 C 推出 A”，前件真就是 B 或 C 至少一个成立，后件假就是 A 不成立，二者同时出现即可。

遇到“B 且 C 推出 A”，则要 B、C 都成立，而 A 不成立。遇到“B 且非 C 推出 A”，自然就是 B 真、C 假、A 假。

不必看到每个新句子都重新想。记住“前件真、后件假”，只是后件换了一个结构，就按对应规则改一下否定结果。

### 问不可能为真：代入找矛盾

代入验证题通常有三个很稳定的特征：

- 题干给出了明确的推出关系；
- 题目问“不可能为真”“一定为假”或者“说法有误”；
- 选项提供的是具体情境，可以直接代回题干检验。

三个特征同时出现时，不必逐项把题干所有条件重新分析一遍。先写出题干逻辑，再逐个查看选项：有没有让前件为真、后件为假？一旦出现，直接选择。

例如，有一道题的条件是“不起雾，则飞机按时起飞”，问“以上断定不成立的是哪项”。原逻辑是：

$$

eg \text{不起雾} \rightarrow \text{按时起飞}
$$

如果选项是“没有起雾，却没有按时起飞”，就同时满足前件真、后件假，正确答案马上出现。飞机为什么没能按时起飞，不需要另外推测。这一类题希望在考试中 20 秒内完成，做熟了，十秒左右更合适。

> **易错点**：没有起雾却按时起飞，是前真后真；已经起雾却按时起飞，是前假后真；已经起雾又没有按时起飞，是前假后假。三种都不符合前真后假，不能选。

另一道农业专家的题，题干说“如果播种前对种子特殊处理，农作物产量会大幅提高”，问哪个选项证明专家的说法有误。只需要找“做了特殊处理，产量却没有大幅提高”。这正是前件发生、后件不发生，找到即可。

还有一道题用“留得五湖明月在，便可不愁无处下金钩”作条件，问哪项不可能发生。把它写成“留得五湖明月在 $\rightarrow$ 不愁无处下金钩”，矛盾情况就是：五湖明月还在，却真要发愁、找不到地方下金钩。只要选项出现前真后假，就完成了验证。

如果刚开始还无法迅速判断“愁得找不到地方下金钩”就是后件为假，可以先把原句变成“并非留得五湖明月在，或者不愁无处下金钩”，再取否定。最后仍然得到“留得五湖明月在且愁得找不到地方下金钩”。熟练以后不用转换，直接看前真后假即可。

### 逻辑不止一条，就逐条找矛盾

有些题目给了不止一个推出关系。这时不要把几条逻辑硬揉成一句。正确选项只要与其中任意一条构成前真后假，就一定是假的；其余选项不属于这种结构，就可以排除。

比如有三条条件连在一起：

- 建乡村，就不建污水厂；
- 建污水厂，就要建排污管道；
- 建排污管道，就不能建垃圾处理厂。

题目问哪项不可能为真，我们先看第二、三条：建污水厂却建排污管道，是前真后真；建污水厂却没有建排污管道，是前真后假。若选项是“建污水厂，同时建垃圾处理厂”，也能命中第三条：建排污管道为真，不建垃圾处理厂为假。直接选它即可。

反过来，“建乡村”出现在第一条的前件，“建污水厂”是它的后件否定，所以“建乡村并建污水厂”同样能构成前真后假。只要选项确实这样写，也可以成为答案。

> **提示**：看到多个逻辑时，逐条检查比把它们串起来更稳。答案不必同时符合所有逻辑；只要有一条例外，就已经足以证明它不可能为真。

### 文字晦涩，结构照样能找

这类题最容易被文字牵着走。题干写得复杂一点，不代表判断规则也复杂。先把长句压缩成骨架，再去核对选项。

有一道题的条件是：“要想发展产业，必须有完备的会展设施和理想的交通条件，从而具备发展产业的硬件基础。”这里有“必须”“从而”，不必自己重写成一大段日常语言。直接拆成：

$$
A \rightarrow B
$$

$$
B \rightarrow C
$$

也就是：

$$
A \rightarrow B \rightarrow C
$$

其中，$A$ 可以对应“想发展产业”，$B$ 对应“完备的会展设施和理想的交通条件”，$C$ 对应“具备发展产业的硬件基础”。选项若说会展设施和交通条件都很好，却不具备产业发展的硬件基础，就是 $A \land B \land 
eg C$，正好构成前真后假。

另一些选项看似在批评“发展不好”，但题干根本没提这个问题；有的说市政设施老化，可题干说的是有没有形成硬件基础，并不等于“硬件基础不完善”。这些都不能直接当作后件否定。

> **易错点**：否定后件要对准原命题。题干只说“没有硬件基础”，选项却改成“硬件基础不完善”“市政设施老化”，不能因为意思相近就当成严格对应。逻辑判断怕的不是换一种说法，怕的是把一个概念偷偷扩宽。

### 问可能为真：先排除矛盾项

当题目问“可能为真”“不矛盾”“能够满足条件”时，正确项不是“最能支持题干”的那一项，而是**没有被题干逻辑排除**的那一项。题干说“能推出什么”，是问一定真；说“能够满足条件”，只是问可能真。不要把两个标准混在一起。

先找出每条题干逻辑的矛盾情况，再逐项代入。一个选项只要命中其中一条矛盾，就一定为假；排除之后，剩下一项。

一道题的条件是：甲不去则乙去；乙去则丙不去；丙去则丁不去。题目问可能为真的选项。

可以先把几个矛盾入口找出来：

- 命中“甲不去则乙去”的矛盾，是甲不去而乙去了。
- 命中“乙去则丙不去”的矛盾，是乙、丙都去了。
- 命中“丙去则丁不去”的矛盾，是丙去了。
- 命中“甲或乙去则丁不去”的矛盾，是甲或乙去了一个，但丁没去。

代入之后，甲不去而乙丙都去的选项，命中了前两条；只有甲去而丙丁不去的选项，既撞上“丙去则丁不去”的矛盾，也撞上“甲或乙去则丁不去”的矛盾；四个人都去，则撞上“乙去则丙不去”。只有“甲、丙、丁都去、乙不去”的情况，不触犯这些矛盾，所以它可能为真。

这里不需要证明“甲、丙、丁都去”一定能从前提推出。我们只需要确认它没有被任何一条前提排除。这个区分非常重要：可能真，不是一定真；不矛盾，也不等于得到支持。

### 代入几组选项就够

“能够满足条件”这类题，尤其适合直接代入。

一道题要求三人选课：两位七年级、一位八年级；七年级和八年级各有可选老师，且三人所教科目各不相同。逐项看：

- 有选项把三位都列成八年级，违背只能选一位八年级；
- 有选项让两位老师都教语文，科目不同这一条不成立；
- 有选项让两位老师都教数学，同样被排除；
- 剩下的一组分别教数学、英语、历史，年级人数符合要求，三科也不重复，因而可能满足条件。

另有一道节目排序题，题干给出三项节目之间的条件，问哪项可能为真。同样不需要把三个节目从头排一遍，只要看选项有没有与其中一条要求形成前真后假。某些组合会让前项内容发生，却让后项要求不成立；这些直接排除。剩下的组合不触发矛盾，因而可能是真的。

> **结论**：代入验证不是“把每个选项都证明一遍”，而是“快速找出哪些选项不可能”。先验证答案范围最小的那条逻辑，往往就能直接锁定；验证完三条仍无法锁定，再把剩下那条补上。

### 同一道题，也可以推矛盾

最后一道题可以同时用两种方法检验。

四个人中恰好有两位正科、两位副科，所以选项一旦明确两个人的身份，另外两个人的身份也就确定了。另一个难点是：甲、乙中恰好有一人正科。

用前真后假验证时：

- 若乙、丙都是正科，那么乙是甲、乙中唯一的正科；可总共已有两位正科，剩下两位必须是副科，条件却让丁不是正科。乙真、丁假，命中矛盾。
- 若甲、丙都是正科，同理，甲是正科却没有让丁成为第二位正科，也命中矛盾。
- 若乙、丁都是正科，那么甲、丙就只能都是副科。但题干说甲、乙中恰好有一人正科，而此时两人都不是，命中另一条条件的矛盾。

三个选项被排除，只剩与所有条件都不矛盾的一项。

还可以用推矛盾的思路。一次先假定甲、乙中恰好一人正科：为了凑够两位正科，另外两人必须都正科；但如果另外两人都正科，甲、乙就都要是副科，和“恰好一人正科”冲突。因此，甲、乙不可能恰好一人正科。

既然如此，只剩两种可能：甲、乙都是正科，或者甲、乙都是副科。选项只要符合其中一种，就没有被排除。

> **提示**：两种方法都可以，不必为了显得复杂而同时使用。结构一眼能推出答案就用推矛盾；题目给了多个具体选项，就代入找前真后假。适合自己的才是快的方法。

### 把判断变成固定动作

做这一类题时，不要从头到尾跟着自然语言读。文字只负责提供情境，逻辑结构才是我们要处理的对象。

遇到“不可能为真”“一定为假”“说法有误”，就按下面的顺序动手：

1. 从题干中摘出逻辑关系，分清箭头方向。
2. 写出这个逻辑的前件和后件；后件有“或”“且”或否定，就先弄清它整体为假需要什么。
3. 把选项代入，查前件是不是真、后件是不是假。
4. 找到一个前真后假的选项，直接选择。

遇到“可能为真”“满足条件”，还是用同一套判断，只是把最后一步改为：

1. 找出每条逻辑的矛盾情况。
2. 逐项代入，把命中矛盾的选项排除。
3. 剩下未被排除的一项，就是可能真的选项。

这才是“代入验证找矛盾”的完整用法。它不需要很多门门道道，难点只在于两点：**箭头方向不能看错，后件的否定不能变形。** 其余都是把已经学会的逻辑结构用到选项上。

> **承前启后**：上一节讲完「代入验证：找到前真后假就够了」，下一节接着讲「真话假话：先占真话名额，再开始推理」。

## 真话假话：先占真话名额，再开始推理
> 对应块：BLK38 | 覆盖分集：P58 | 块标题（分集名）：《真话假话上篇》

真话假话在形式逻辑里占的比重不算低，大概有百分之二十多。奇怪的是，很多同学一遇到这类题就会觉得难，做完之后还总是错。

问题往往不在于我们不会逻辑，而在于解题思维没有切换过来。

前面做事实题时，题干会告诉我们：这些条件都成立，在条件为真的情况下可以推出什么。那种题里，我们可以直接把事实代入条件，使用肯定前件、否定后件、逆否等价这些规则。

真话假话不一样。题干会先给出几句话，再告诉我们其中只有一句真话、两句真话，或者两真两假。此时每一句话的真假都不确定，不能先把一个未知的判断塞进条件里做推理。

> **核心区别**：事实题先把条件当真，再代入事实；真话假话题先找关系、占真话名额，确定某些话为真之后，才能继续推理。

为什么很多同学会在这里出错？因为看到“小明获奖”这样的事实，就立刻把它代进某一句条件。可这句话自己到底是真是假还不知道啊。条件真假不确定，代入事实当然不能展开推理。

所以，真话假话的第一步不是代入，而是看清楚：谁和谁必然一真一假，谁的真话会连累另一句，谁至少要占一个真话名额。

### 先看问法，别把未知条件当真用

真话假话的题干特征非常明确：先给出若干个判断，再明确告诉你这些判断中有几句真话、几句假话，最后问能够推出什么。

这里的关键不是条件本身，而是问法。

普通事实题的条件可以理解成这样的：

```text
条件都成立
    ↓
代入已知事实
    ↓
按照逻辑规则推出结论
```

真话假话题的流程则完全不同：

```text
条件真假未定
    ↓
先找矛盾、同真或不能同假
    ↓
利用真话、假话数量确定名额
    ↓
确定某句话为真后，再代入推理
```

举个例子。题目给出三句话，其中只有一句是真话。第一句和第二句分别是“小明获奖”和“小明没获奖”。

这两句话是不是矛盾关系？当然是。它们永远一真一假，而且题目总共只有一句真话，因此这两句话必然把唯一的真话名额和一个假话名额都占掉了。既然真话名额已经在它们中间，其他的话就只能是假话。

这时候我们才可以把“第一句为假”拿出来，推出第一句对应的具体事实。不能再看到一句可能为真，就马上代入另一句未知真假的条件。

这个切换一定要记住：**真话假话不是把事实真重新做一遍，而是先判断条件的真假名额。**

### 真话名额是推理的发动机

题干告诉你“只有一句真话”，这句话的真正作用不只是告诉你数量，还等于给了我们一个稀缺资源：全题只有一个真话名额。

如果找到一对矛盾关系，矛盾双方必然一真一假，于是它们占掉一个真话名额和一个假话名额，其他句子就只能为假。

如果找到两句同真关系，也就是说第一句一旦为真，第二句也一定为真，那么第一句不能为真，否则两句真话会超出题干允许的数量，于是第一句只能为假。

如果找到两句不能同假，也就是它们至少有一句为真，那么它们至少占掉一个真话名额；如果全题只有一句真话，那么它们各自最多只能有一句为真，其他句子就只能为假。

可以把常用关系压缩成这样：

| 找到的关系 | 关系带来的约束 | 在“只有一句真话”下得到什么 |
| :--- | :--- | :--- |
| 矛盾 | 两句永远一真一假 | 这一对占掉真话名额，其余句子为假 |
| 同真 | 一句为真会带出另一句为真 | 触发同真的前一句为假 |
| 不能同假 | 至少有一句为真 | 这一对占掉真话名额，其余句子为假 |
| 没有现成关系 | 逐项代入观察 | 直接统计每种情况下的真话数量 |

这就是真话假话的发动机。我们不是漫无目的地把所有句子都代入，而是先找一个能锁定名额的关系，再顺着关系推理。

### 优先找矛盾

矛盾关系是四种套路里最先要抓的，因为它最稳定：一句话为真，另一句必假；另一句为真，前一句必假。两句话谁真谁假可以不知道，但“它们一真一假”是确定的。

#### 矛盾关系怎么认

常见的矛盾关系有三种。

第一种是同一个命题和它的否定：

$$
A\quad\text{与}\quad
eg A
$$

小明出现和小明没出现，属于这种情况。

第二种是析取命题和它的完整否定：

$$
A\lor B\quad\text{与}\quad
eg A\land
eg B
$$

“甲或乙至少有一个成立”和“甲、乙都不成立”不可能同时为真，也不可能同时为假。

第三种是一个逻辑命题和它的“前真后假”：

$$
A\to B\quad\text{与}\quad A\land
eg B
$$

这是特别容易考的矛盾。把箭头换成或，就能看清它的结构：

$$
A\to B\equiv
eg A\lor B
$$

而一个析取命题为假，必须两个部分都为假，所以：

$$

eg(A\to B)\equiv A\land
eg B
$$

遇事不决，逻辑箭头就换成“或”。这招不是绕远路，而是把最抽象的箭头关系变成我们熟悉的真假判断。

#### 矛盾关系怎么落到其他句子

看一个三句判断的例子。题目说三句话中只有一句为真，三句话分别是：

- 第一句记成 $A\to B$；
- 第二句记成 $
eg A\land
eg B$；
- 第三句是另一个判断。

第一句和第二句正好是“逻辑命题”和“前真后假”的矛盾关系。它们一定一真一假，因此唯一的真话在它们中间，第三句必然为假。

再看第一句。第一句为假，说明它不是一个成立的逻辑关系，只能是前件为真、后件为假，也就是 $A\land
eg B$。把题中的具体对象带回去，就得到：小张学的是魏碑，小李没有学汉隶。

注意这里的顺序：先由矛盾确定第三句为假，再由第一句为假得到 $A\land
eg B$。不是先随便代一个事实，而是先确定这句话确实为假，才可以利用它的矛盾内容。

如果题目有五句话、六句话，条件很多，也不要先慌。只有一句真话时，找到一对矛盾后，矛盾双方已经把一个真话名额占掉，剩下的句子全部都是假话。这时候条件多反而更好处理，因为大部分句子可以一次性被排除。

有一道2022年国考的五条判断题，关键就是先找出一对完整的析取否定：一、二互相矛盾，三、四、五就只能为假。把三、四、五分别取否定后，再把得到的事实联立起来，就能锁定选项。条件多不可怕，怕的是没有先找矛盾就开始逐句代入。

#### 五人名次题：矛盾一对，其他全假

25年省联考的一道题说五个人中只有一个人说对了。第一句是“郑一定是冠军”，第三句是“郑不能得冠军”，这两句显然矛盾。

既然矛盾双方占掉了唯一的真话名额，其他三句就全部为假：

- 吴和周都不是冠军；
- 钱是季军；
- 王是亚军。

题目问亚军是谁，直接得到王。题目如果改问冠军是谁，就看剩下的名额：吴、周不是冠军，王是亚军，五个人里只剩郑，所以冠军是郑。

这就是矛盾推理的效率：一对矛盾确定名额，其他判断直接变成假话。

#### 四人电影和购物题：矛盾关系要结合题设翻译

有四个人甲、乙、丙、丁，在电影和购物中恰好选择一个：看电影就不购物，购物就不看电影。四句话中只有一句为真：

- 丁有购物；
- 如果甲购物，那么乙看电影；
- 如果丁没有购物，那么丙看电影；
- 甲、乙都有购物。

先把第二句改写成逻辑形式。第二句是“甲购物推出乙看电影”，它的前真后假是：

$$
\text{甲购物}\land
eg\text{乙看电影}
$$

因为每个人在电影和购物中二选一，乙没有看电影就意味着乙购物。所以第二句的“前真后假”就是“甲、乙都有购物”，正好是第四句。

第二句和第四句矛盾，独占一个真话名额，因此第一句和第三句都为假。

第一句为假，得到丁没有购物；根据二选一，丁看电影。第三句为假，说明“丁没有购物”是真的，同时“丙看电影”为假。丙没有电影就只能购物。

所以确定的事实是：丙购物，丁看电影。题目选项直接锁定。

#### 矛盾之后还要分情况

有些题找到矛盾以后，得到的只是一个较弱的结论，不能急着往下推。

2018年省联考的一道两队晋级预测题，四句话中只有一句预测正确。把四句话记成：

- $
eg\text{甲}\to
eg\text{乙}$；
- $
eg\text{乙}$；
- $\text{乙}\land
eg\text{甲}$；
- $
eg\text{甲}\land
eg\text{乙}$。

第一句和第三句是矛盾关系：第一句的前真后假，恰好就是“乙晋级且甲不晋级”。因此第二句和第四句都为假。

第二句为假，说明乙晋级。第四句为假，说明甲、乙不可能都不晋级，也就是至少有一队晋级；但因为乙已经晋级，甲是否晋级仍然不能确定。

这时不能把“甲或乙”直接当成“甲”。肯定逻辑的左边，不能推出肯定逻辑的右边。我们只能分两种情况：

- 甲晋级时，第一句为真，第三句为假；
- 甲不晋级时，第一句为假，第三句为真。

两种情况都符合题干，所以还要看选项。根据“甲晋级”这一可行情况，第一句预测正确，选择相应选项；如果题目问“方某预测正确吗”，甲不晋级时方某反而是错的。

这就是真话假话里常见的最后一步：**矛盾锁定范围，选项再决定是否需要分类。**

#### 看起来相反，不等于矛盾

找矛盾时，最容易错的地方就是把“文字相反”当成“逻辑矛盾”。

判断标准只有一个：两句话是不是永远一真一假。凡是存在一种情况让它们同时为真，或者同时为假，就不是矛盾。

例如，$A\lor B$ 和 $
eg A\land B$ 就不是矛盾。当 $B$ 为真时，第一句因为 $B$ 为真而成立，第二句也因为 $B$ 为真而成立，两句话可以同时为真。

$A\land
eg B$ 和 $
eg A$ 也不是矛盾。当 $A$ 为真、$B$ 为假时，第一句为真，第二句为假；反过来当 $A$ 为真、$B$ 为真时，两句话又同时为假。它们可以同时为假。

再看 $
eg A$ 和 $
eg B$。当 $A$、$B$ 都为假时，两句话都为真；当 $A$、$B$ 都为真时，两句话都为假。因此它们也不是永远一真一假。

所以不要只看两句话里是不是出现了相反的词。要看它们的整体逻辑结构是不是互为否定。主语不同、条件不同，往往就不能直接当矛盾处理；只有命题和它的完整否定，或者逻辑命题的前真后假，才是稳定的矛盾信号。

### 找不到矛盾，就找同真

题目里没有矛盾关系，不代表没有办法。真话假话还有第二种固定套路：找同真的两句话。

所谓同真，就是第一句如果为真，第二句也会跟着为真。它们不是一真一假，而是“一真带一真”。

假设题干只允许一句真话。如果第一句为真会带出第二句也为真，那么出现两句真话，和题干矛盾，所以第一句只能是假。

#### 逻辑箭头是最稳的抓手

同真关系最常见的来源有三种。

一种是把一个命题和包含它的析取放在一起。$A$ 为真时，$A\lor B$ 一定为真；所以 $A$ 和 $A\lor B$ 不能在“只有一句真话”的题里同时为真，$A$ 本身必须为假。

另一种来自逻辑箭头。对于：

$$
A\to B\equiv
eg A\lor B
$$

只要前件为假，即 $
eg A$ 为真，整个逻辑就为真；只要后件为真，即 $B$ 为真，整个逻辑也为真。因此：

- $
eg A$ 为真，会带出 $A\to B$ 为真；
- $B$ 为真，会带出 $A\to B$ 为真。

这就是为什么熟练之后，遇到箭头题可以直接看出同真关系；还不熟时，就先把箭头换成“或”，再判断哪一部分为真。

第三种来自背景限制。比如题目已经规定“只能有一个冠军”，那么“甲队夺冠”会带出“乙队没有夺冠”。如果这两句都被写进判断里，并且全题只允许一句真话，那么“甲队夺冠”就不能为真。

#### 同真与矛盾，结论方向不同

这是最需要分清楚的地方。

| 找到的关系 | 发生什么 | 得到的直接结论 |
| :--- | :--- | :--- |
| 两句矛盾 | 两句永远一真一假 | 真话在两句中，其他句子为假 |
| 两句同真 | 第一句真会带出第二句真 | 第一句不能为真 |
| 两句不能同假 | 两句至少有一句真 | 真话在两句中，其他句子为假 |

举一个三句话的例子。如果第一句和第二句是矛盾关系，只有第一句真话，那么我们可以确定第三句为假。

但如果第一句为真会带出第二句为真，那么得到的是第一句为假，而不是第三句为假。

所以一定要记住这个方向：

> **矛盾推出其他句子为假；同真推出触发同真的那句话为假。**

很多同学做错，并不是没有找到关系，而是把两种关系的结论对象弄反了。

#### 六所高校中标题

题目说有六所高校参加，最终只能有一所中标。三个判断分别涉及：甲或乙中标；丙不中标；丙、戊、己都不中标。题目给出只有一句真话。

这里没有直接矛盾关系，但有同真关系。

如果第一句“甲或乙中标”为真，由于只能有一所中标，那么丙、戊、己就都不中标，第二句和第三句也会为真。这样三句话全真，违反只有一句真话。

所以第一句必须为假，甲、乙都没有中标。

再检查丁：如果丁中标，丙、戊、己仍然都不中标，第二句和第三句会同时为真，也会有两句真话，不符合题干。因此丁也不能中标，答案直接落到“甲乙都没中标”。

这里的关键是：同真关系不是把“甲或乙”和“丙不中标”硬凑成矛盾，而是看第一句一旦为真，是否会把其他判断也带成真。

### 不能同假，也是在占真话名额

第三种关系是两句话不能同时为假。

“不能同假”就是至少有一句为真。它不像矛盾那样固定一真一假，但同样会占用真话名额。

假设题干只有一句真话，而第一句和第二句不能同假，那么真话至少要在它们之间出现。既然全题只有一个真话，第一句、第二句最多只能有一句为真，剩下第三句就必然为假。

有一个男女例子：把三个人记作abc，三个人中有两男一女，其中甲、乙不能同时为男生。唯一的女性只能出现在甲、乙中间，所以丙一定是男生。

这里不是去判断甲和乙到底谁真谁假，而是先利用“甲、乙不能同时为假”占住唯一真话名额，再把丙排除掉。

如果一道题既找不到矛盾，也找不到同真，就检查两句是不是不能同假。这个关系不显眼，却经常能直接把其他句子全部判假。

### 没有现成关系，就直接代入计数

如果既没有矛盾，也没有同真和不能同假，最后一个办法就是把可能的实际情况列出来，直接代入，数一数真话数量。

这在只有两个二元判断时尤其快。

22年广东的一道两件作品题说只有一个人猜对，两个作品分别是稻穗和播种，四个猜测按 1234 标出来分别是：

- 两件作品都能获奖；
- 只有一件作品能获奖；
- 稻穗不会获奖；
- 播种会获奖。

把“稻穗获奖”记成 $A$，“播种获奖”记成 $B$。四种情况如下：

| 实际情况 | 两件都能获奖 | 只有一件获奖 | 稻穗不会获奖 | 播种会获奖 | 真话数 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| $A$、$B$ 都为真 | 真 | 假 | 假 | 真 | 2 |
| $A$ 真、$B$ 假 | 假 | 真 | 假 | 假 | 1 |
| $A$ 假、$B$ 真 | 假 | 真 | 真 | 真 | 3 |
| $A$、$B$ 都为假 | 假 | 假 | 真 | 假 | 1 |

符合“只有一句真话”的情况有两行：稻穗获奖、播种不获奖，以及两件都不获奖。

所以可以确定的是：播种不能获奖。稻穗是否获奖无法确定，答案选择“播种不能获奖”。

这个例子也说明，直接代入不是最后的笨办法，而是当没有关系可抓时最稳的办法。关系清楚时优先用关系，关系不清楚时列出全部情况，不要凭感觉猜。

### 两真两假的固定顺序

题干说“两真两假”时，顺序比“只有一句真话”更固定：先找矛盾，再找同真。

原因是两真两假本身也提供了名额结构。找到一对矛盾后，这两句必然一真一假；因为总共两真两假，剩下的两句也必须一真一假。接着再在剩下的两句里找同真关系，就可以把哪一句为真、哪一句为假锁死。

#### 邀请甲乙的题

四句话分别是：

- 至少邀请甲或乙中的一位，记成 $A\lor B$；
- 不邀请甲，记成 $
eg A$；
- 一定邀请甲，记成 $A$；
- 决定邀请乙，记成 $B$。

题干给出两真两假。

第二句和第三句是 $
eg A$ 与 $A$ 的矛盾关系，所以它们一真一假。于是第一句和第四句也必须一真一假。

如果第四句为真，即 $B$ 为真，那么第一句 $A\lor B$ 也为真，第一句和第四句就会同时为真。再算上第二、三句中的一句真话，就变成三句真话，和题干矛盾。

所以第四句不能为真，得到 $
eg B$。既然第一句和第四句一真一假，而第四句为假，第一句就必须为真，得到 $A\lor B$。

这时才可以把 $
eg B$ 代入 $A\lor B$，推出 $A$ 为真。结论是：邀请甲，不邀请乙。

注意最后一步的先后：必须先确定“至少邀请一人”这句话为真，才能把“乙没有邀请”带进去。没有确定第一句为真时，不能直接拿 $A\lor B$ 做推理。

#### 两位母亲是否去

另一道题说两个判断中有一个猜对。四个判断可以整理成：

- 如果陈没去，那么临也没去：$
eg\text{陈}\to
eg\text{临}$；
- 陈一定会去：$\text{陈}$；
- 陈或临至少有一个去：$\text{陈}\lor\text{临}$；
- 临会去，但陈没去：$\text{临}\land
eg\text{陈}$。

题干是两真两假。

第一句和第四句构成矛盾：第一句的前真后假，正是“陈没去且临去”。所以第一、四句一真一假，第二、三句也一真一假。

如果陈去，那么第二句“陈一定会去”为真，第三句“陈或临”也必然为真，第二、三句同时为真，不符合它们只能一真一假。所以陈不能去。

陈为假时，第二句为假，第三句必须为真，得到“陈或临”为真。既然陈不去，就只能是临去。

因此实际情况是陈没去、临去。代回四个判断，第一句为假，第四句为真，第二句为假，第三句为真。猜对的是第三句和第四句，答案选择对应的两个母亲。

这里仍然是同一套动作：矛盾先锁一对，剩余名额再交给同真关系，最后才把确定的事实代回验证。

#### 两真两假中的分类题

还有一道题里，甲、乙能否晋级被写成了几句不同的话。先要排除看起来相似、实际并不矛盾的一组，抓住逻辑命题和前真后假的一组。剩下两句再用同真关系确定。

最后得到“甲没去、乙去了”的稳定情况，再判断哪一句为真、哪一句为假。由此可知第一句为真，其他相应判断为假，选择 D。

这类题绕的地方在于：找到矛盾并不等于马上能回答选项。矛盾只负责排除一部分可能性，如果剩下的信息还没有闭合，就要把剩下的可能情况分别列出来。

### 把所有方法合成一套动作

真话假话虽然看起来比事实题多了一层真假判断，但套路非常固定。每次做题都可以按下面的动作走。

- 先读数量：是只有一句真话、两句真话，还是两真两假。
- 把每句话翻译成清楚的逻辑形式，尤其是把“如果……那么……”和“只要……就……”写成 $A\to B$。
- 优先寻找矛盾。看到一对矛盾，先记下它们一真一假，再把真话名额和假话名额标出来。
- 找不到矛盾，就找同真。若第一句真会带出第二句真，在只有一句真话时，第一句就是假。
- 同真也找不到，就检查两句能不能同假。不能同假意味着至少占一个真话名额。
- 只有确定某句话为真之后，才把它代入条件，使用肯定前件、否定后件或逆否等价。
- 如果信息仍然不够，就把所有可能情况列出来，逐项数真话。
- 最后把得到的事实代回原题验证。验证不是另起炉灶，而是检查你有没有误读“只有一件”“恰好一个”“不能同时”这些限制。

真正熟练之后，看到“只有一句真话”，脑子里先出现的不是某个具体人物，而是“真话名额”；看到两个互为否定的句子，先标记“一真一假”；看到一个条件命题，先问它的前件为假、后件为真时会发生什么。

这就是这门课里最固定的几板斧。只要把这些关系练到不用犹豫，真话假话题并不会比普通逻辑题更难，反而常常能在三四十秒内完成。遇到不熟的关系，也不要硬猜，先把逻辑箭头换成“或”，把每句话的真假边界写出来，答案就会慢慢浮出来。

### 本讲提到的题目

这节课里出现的题目都可以回到上面的几种关系。下面把明确提到的题目按题干信息收拢，解析依据已经在正文中展开。

#### 三句判断中的唯一真话

题干给出三句话，其中只有一句为真。第一句可记为 $A\to B$，第二句为 $
eg A\land
eg B$，第三句是另一判断；题中的具体对象是小张和小李学什么。

第一句和第二句是逻辑命题与前真后假的矛盾，第三句为假。第一句为假，得到 $A\land
eg B$，也就是小张学魏碑、小李没有学汉隶。答案取与这个事实相符的选项。

#### 五人名次预测

题目说五个人中只有一个人说对，其中“郑一定是冠军”和“郑不能得冠军”矛盾。矛盾占掉真话名额后，其他三句全假，得到吴和周不是冠军、钱是季军、王是亚军。

问亚军，答案是王；问冠军，剩下郑，答案是郑。这个题的关键不是把五个人的说法都代入，而是先看一对矛盾。

#### 四人电影和购物

四个人甲、乙、丙、丁在电影和购物中二选一，四句判断只有一句为真：丁有购物；如果甲购物，那么乙看电影；如果丁没购物，那么丙看电影；甲乙都有购物。

第二句的前真后假是“甲购物且乙不看电影”，由二选一可翻译成“甲乙都有购物”，所以第二句和第四句矛盾。第一、三句为假，推出丁看电影、丙购物。答案是丙购物且丁看电影。

#### 两队晋级预测

四句话中只有一句预测正确，四句可记为 $
eg\text{甲}\to
eg\text{乙}$、$
eg\text{乙}$、$\text{乙}\land
eg\text{甲}$、$
eg\text{甲}\land
eg\text{乙}$。

第一句和第三句矛盾，第二、四句为假；得到乙晋级，但甲是否晋级还不能立即确定。再分甲晋级和甲不晋级两种情况，甲晋级时第一句为真，甲不晋级时第三句为真。由此选择“方某预测正确”的对应选项。

#### 两真两假的邀请判断

四句是“至少邀请甲或乙中的一位”“不邀请甲”“一定邀请甲”“决定邀请乙”，并且两真两假。第二、三句矛盾，第一、四句一真一假；若第四句真，会使第一、四句同时为真，导致总共三句真，所以第四句假、第一句真。由“至少一人”和“乙没邀请”推出甲被邀请、乙未被邀请。

#### 两个母亲是否去

四个判断是“如果陈没去，那么临也没去”“陈一定会去”“陈或临至少有一个去”“临会去，但陈没去”，题干为两真两假。

第一、四句矛盾，第二、三句一真一假。若陈去，第二、三句会同时为真，矛盾，所以陈不去；第三句真再推出临去。最终陈没去、临去，猜对的是第三句和第四句，答案选对应的两位母亲。

#### 六所高校中标题

六所高校中只能有一所中标，三句判断给出“甲或乙中标”“丙不中标”“丙、戊、己都不中标”，并且只有一句为真。

第一句若真，会带出第二、三句也真，故第一句为假，甲乙都不中标。丁若中标，也会让第二、三句同时为真，所以丁不能中标。答案是甲乙都没有中标。

#### 两件作品获奖

两个作品是稻穗和播种，只有一个人猜对。四句分别是“两件都能获奖”“只有一件能获奖”“稻穗不会获奖”“播种会获奖”。

逐项代入四种实际情况，只有“稻穗获奖、播种不获奖”和“两件都不获奖”各自只有一句真话。两种情况都排除了播种获奖，所以能确定的是播种不能获奖；稻穗是否获奖无法确定。

## 真话假话的占位推理与 AEIO
> 对应块：BLK39 | 覆盖分集：P59-P60 | 块标题（分集名）：《真话假话下篇与AEIO》

讲完“优先找矛盾”和“找同真”之后，真话假话题还剩一条很好用的路：**两句话不能同时为假**。如果题干规定总共只有一句真话，那么这两句话里就必定有一句真话。它们先把唯一的真话名额占住，其他话只能为假；如果题干规定总共只有一句假话，对应的占位关系就是“两句话不能同时为真”。

为什么一定要盯住“名额”？因为真话假话题不是让我们把所有可能情况都枚举一遍，而是先确定哪句话必须真、哪句话必须假，再把确定的事实代回逻辑式继续推。很多题一旦锁定这个名额，后面只有一两步；套路练熟以后，二三十秒就能走完。

```text
先找矛盾
    ↓ 找不到
再找同真
    ↓ 还找不到
找不能同时为假
    ↓ 仍无法锁定
选项给出了完整情况，就直接代入数真话、假话
```

> **结论**：真话假话的核心不是“猜谁说谎”，而是利用题干给出的真、假数量，找一组一定同时包含真话或假话的关系，让它们先把名额占住。

### 找不到矛盾与同真时，先让两句话占掉名额

#### 唯一冠军带来的立刻排除

先看最容易识别的一类：如果只有一个冠军，那么“A不夺冠”和“B不夺冠”不能同时为假。

为什么？假如这两句话都是假的，就意味着 A 夺冠、B 也夺冠，直接与“只有一个冠军”矛盾。所以二者至少有一句真话。

如果题干恰好只有一句真话，那么真话就在这两句话中，后面无论再出现什么话，都只能是假话。记住这一条就够了，不需要每次都重新想。

23年广东那道申请题就是这个模型。题目说只有一个人通过了申请，三句话分别是：

- 甲没通过；
- 乙通过了；
- 丙没通过。

甲没通过和丙没通过不能同时为假，否则甲、丙都通过，就与只有一人通过矛盾。因此这两句话里至少有一句真话，唯一的真话已经被它们中的某一句占住，乙通过了必然为假，也就是乙一定没通过。题目问必然错误的话，直接锁定“乙通过”。

这类题如果头脑清醒，二十秒就能做完。诀窍很简单：看到“只有一个”，马上找“某人不成立”组成的两个人话。

#### 逻辑箭头与后件否定，为什么不能同假

第二个关系稍微晦涩，也更重要：**$A\rightarrow B$ 和 $
eg B$ 不能同时为假**。

先把箭头化成等值式：

$$
A\rightarrow B\equiv 
eg A\lor B
$$

接着分别假设其中一句为假。

如果 $A\rightarrow B$ 为假，那么必须有 $A$ 为真且 $B$ 为假。理由是，只有前件真、后件假时，$
eg A\lor B$ 才是假。因此此时 $
eg B$ 一定为真。

如果 $
eg B$ 为假，那么 $B$ 一定为真；后件为真时，$A\rightarrow B$ 无论前件是什么都成立，所以第一句一定为真。

两种情况都指向同一件事：第一句假，第二句就真；第二句假，第一句就真。它们绝不可能同时为假。

> **结论**：看到“一个条件推出 B”与“非 B”放在一起，立刻知道至少有一句真话。若题干只有一句真话，别的陈述就全部出局。

这道关系在真题里考过几次。推导过程第一次做时跟着走一遍，以后直接记：

```text
A → B 为假  ⇔  A and 非B 为真  ⇒  非B 为真
非B 为假    ⇒  B 为真     ⇒  A → B 为真
```

#### 用箭头与后件否定锁定排名

23年陕西的排名题可以直接套这个模型。四个名次对应红、绿、蓝、黄，只有一个人猜对。四个判断是：

- 红等于第一，则黄等于第二；
- 红等于第三，则蓝等于第四；
- 蓝不等于第四；
- 黄等于第二。

先找矛盾，找不到；第二句“红等于第三推出蓝等于第四”与第三句“蓝不等于第四”是一组箭头和后件否定，不能同时为假。它们至少占掉一句真话，所以第一、第四句只能是假话。

第一句是假，意味着“红等于第一且黄不等于第二”。于是红是第一，黄不是第二。既然红不是第三，条件句“红等于第三推出蓝等于第四”的前件为假，第二句反而确定为真；唯一真话已经落在第二句，第三句只能为假，所以蓝等于第四。

现在红是第一、蓝是第四、黄不是第二，剩下的名次只能分给绿和黄：绿是第二，黄是第三。答案就是绿队第二个出场。

这道题难不在逻辑，而在于能不能立刻认出“箭头加后件否定”。认出来以后，不需要重新推一遍真假。

25年浙江的排名题结构完全一样。若“只有一句真话”为真话条件，先观察“只要乙得亚军，甲就得季军”和“甲没有得季军”：前者以后者为后件，后者正好否定该后件，二者不能同时为假。于是另外两句都是假话。

“丙得冠军或丁不等于第四”为假，说明丙不是冠军、丁是第四；“丙获得亚军”为假，说明丙也不是亚军，所以丙只能第三。此时“甲没有得季军”确定为真，第一句则为假，进一步得到乙得亚军且甲不是季军。名次排下来，乙第二、丙第三、丁第四，甲只能拿冠军。

两道题最重要的不是背答案，而是认出箭头和后件否定的占位能力。

#### 只有一句假话时，找不能同时为真

只有一句真话时，找“不能同时为假”；只有一句假话时，就找“不能同时为真”。推理方向千万别反过来。

23年山东的世界杯题只有一句假话：

- 冠军是欧洲球队；
- 冠军是法国队；
- 冠军是南美洲球队；
- 阿根廷不会进入四强。

第一句和第三句不能同时为真，因为冠军不可能既属于欧洲又属于南美洲；第二句和第三句也不能同时为真，因为法国队属于欧洲，不可能是南美洲队。两组都至少要占一句假话名额，而题干总共只有一句假话。

共同压在第三句上的两组假话，只能由同一个第三句来承担。因此“冠军是南美洲球队”必假，其余三句都是真的：冠军是法国队，法国队是欧洲球队，阿根廷不会进入四强。

> **易错点**：“不能同时为真”至少包含一句假话，所以它占的是假话名额；“不能同时为假”至少包含一句真话，所以它占的是真话名额。真话和假话的名额完全不能混用。

#### 四方桌里，顺序条件比选项更关键

25年的国考题是“只有一句真话”与不能同时为假的组合，难点藏在一个很容易漏掉的条件里：甲、乙、丙、丁按顺时针依次围坐。桌子可以转，但顺时针顺序必须是甲、乙、丙、丁。因此甲与丙相对，乙与丁相对。

四句话是：

- 甲说，坐在东边的人说谎；
- 乙说，坐在南边的人说谎；
- 丙说，自己坐在西面或北面；
- 丁说，自己坐在北面。

先看甲、乙。如果两句话都假，就意味着东边和南边两个人都说真话，与“只有一句真话”矛盾。所以甲、乙不能同时为假，唯一真话在甲、乙中，丙、丁都为假。

丙的话为假，说明丙既不在西面，也不在北面，只能在东面或南面；丁的话为假，说明丁不在北面。四个人有两个位置约束，直接分两种情况。

**丙在东面**：丙是假话者，所以甲说“东边的人说谎”为真，乙为假。乙的话为假，说明南边的人说真话，即乙坐在南边；既然丙在东面，乙说自己坐在南边时说谎，乙就应在北面。再按甲的固定顺时针顺序检查，这会把甲放到南面，形成北乙、东丙、南甲、西丁的顺序，实际绕桌是乙、丙、丁、甲，不符合甲乙丙丁的顺时针次序，排除。

**丙在南面**：丙的话为假，表示南边的人说谎，所以乙就是唯一说真话的人。甲为假，表示东边的人说真话，于是乙坐在东面。丙已经坐南面，丁不能坐北面，只能坐西面，甲坐北面。这样是北甲、东乙、南丙、西丁，顺时针正好是甲、乙、丙、丁，符合条件。

因此甲坐在北面。

这类题不一定有 AEIO，但“甲乙不能同时为假”仍然是入口。条件又给出位置必须成组出现时，分情况只需要分丙在东、丙在南两种，因为“不在两个位置”在四选一的位置里只剩两个可能。

### 选项给全时，直接代入数真假

还有一个经常被忽略的入口：**如果选项把完整情况都列出来，就不用苦想复杂推理。**

“完整情况”意味着姓名、身份、奖项数、排名、部门等关键信息在每个选项中都已给定。这时把每个选项代回题干，逐句判断真假即可。一个选项可能只要五到十秒，即使四个选项全部验证，四十秒左右也能完成。

不过不要机械地每次都数完。命题人往往先设置一个很快的排除点，一旦当前判断已经与题干要求冲突，就立刻看下一个选项。

#### 真假数量不确定时，先把数量算出来

十七年国考那道比较大小题，题干说“教练说最多有一个人说假话”，随后又说“教练说的是假话”。第二句说明第一句为假，所以“假话人数小于等于一”不成立。人数是整数，意味着至少有两名说假话；在只有三句话的情况下，只能是两假或三假。

四个选项给出 $A,B,C$ 的具体大小关系，三句话分别是“$B>C$”“$A<C$”“$A<B$”。代入 $A>B>C$：

- $B>C$ 为真；
- $A<C$ 为假；
- $A<B$ 为假。

恰好两句假话，符合条件。其余完整关系代入后都不能得到两句或三句假话，因此选 $A>B>C$。

这类题不是看选项长得像不像，而是先算清题干到底要求两句假、三句假，还是一真两假。数量没有算清，后面的计数就没有标准。

#### 奖项题：先找“必须说假话的人”

22年四川的奖项题说，甲、乙、丙、丁四人参加运动会，每人至少一个奖项，共获十个奖；其中“获得两个奖项的人说假话，其他人说的都是真话”。

选项给出了每人的奖项数。我们代入一个选项后，不必把四句话全部看完。只要找出选项中谁获得两个奖，再看这个人说出的第一句话是否符合题意，冲突就能立即排除。

代入 A、B 两个选项时，甲都获得两个奖，因此甲必须说假话。但“乙、丙获奖总数为五”在两个选项中又都为真，甲已经说真话，与要求矛盾，A、B立即排除。

代入 C，前三人都获得两个奖，这三个人说出的三句话都应假：

- 乙、丙总数不是五，而是四；
- 丙、丁总数不是五，而是六；
- 甲、丁总数不是五，而是六。

只有第四句“甲、乙获奖总数为四”为真，而第四个人获得四个奖，确实应该说真话，C完全符合。选 C 后就不必再看 D；即便继续验证，D中第一句为真，但按奖项数它必须为假，也会立即排除。

> **提示**：代入验证不是“慢方法”。只要选项给全，能最快发现矛盾的那一处，就是最快的排除点。眼睛不够尖也不影响，照着条件一项一项数就行。

#### 身份题与部门题：完整映射直接查表

25年江苏的部门题说，甲、乙、丙三人的部门猜测只有一个正确。选项把三人的完整部门安排列出来，代入每句话即可。A出现两句真，B出现三句假，C只有一句真，D三句都真，答案只能是 C。

21年江苏的身份题更典型：四人身份分别为企业家、大学教师、歌手和会计师，各不重复；只有会计师的预言为真，其余都为假，因此四句话中只有会计师对应的那一句为真。

其中“乙不会成为歌手”和“乙不会成为大学教师”不能同时为假。两者都假，就意味着乙既是歌手又是大学教师，与身份不重复矛盾。它们至少占掉一句真话，所以会计师必在甲、丁之中，乙、丙说假话。丙的话为假，可进一步确定丁是企业家，答案直接落到企业家为丁的选项。

看出来这些关系，可以秒杀；没看出来，也老老实实代入四个完整身份。一个选项十秒左右，四个选项并不会拖慢整道题。

#### 两个人各说两句话，数成三种形态

有些题不是判断整句真假，而是判断每个人两句话的对错形态。常见要求是三个人中：

- 一个人两句都对；
- 一个人一对一错；
- 一个人两句都错。

只有龙井、碧螺春、乌龙茶三种情况，直接分三种代入即可。

以龙井为例，小刘的两句“否龙井”“非碧螺春”全错，小赵的两句“否龙井”“是乌龙茶”也全错；李的两句“非乌龙茶”“是龙井”全真，正好形成两错、一真一错、两真。碧螺春会让三人都变成一对一错；乌龙茶会让两个人两句全真，另一个人两句全错，都不符合。只有龙井符合“全部龙井”的结论。

21年广东的花卉题结构完全相同，只是选项换成牡丹、玫瑰、月季。牡丹会使两个人的两句话都一真一假，玫瑰会使两个人两句全真；两者都不满足三人各不相同。只有月季能形成两真、一真一假、两假，所以答案是月季。

这里最稳的方法仍是代入三种完整情况。不要为了追求“秒杀”强行凭感觉排除，一旦排除错，反而会多绕路。

### AEIO：题面复古，套路却非常固定

AEIO 经常和真话假话一起考。这组字母有时也被顺口记成 AEL，小写连写时就是 `ael`；我们先把这个顺序放一边，真正要记的是标准顺序 AEIO。它在国考里最近一次出现已经是2018年，考研中也有十多年没考了，看起来十分复古。但没听过的人会被名词绕进去，真正听懂以后会发现题目套路固定、过程简单，属于听过一遍就很难再错的考点。

#### 直言命题的四种标准类型

直言命题的标准形式，就是围绕 $S$ 与 $P$ 说什么。

| 类型 | 形式 | 含义 | 记忆方式 |
| :--- | :--- | :--- | :--- |
| A | 所有 $S$ 都是 $P$ | 全称肯定 | “all” |
| E | 所有 $S$ 都不是 $P$ | 全称否定 | “error” |
| I | 有的 $S$ 是 $P$ | 特称肯定 | 有的说对 |
| O | 有的 $S$ 不是 $P$ | 特称否定 | 有的说错 |

比如“所有游客都买了瓷器”是 A，“所有游客都没买瓷器”是 E，“有的游客买了瓷器”是 I，“有的游客没买瓷器”是 O。

这些英文联想只是为了帮助记忆，不是字母的严格词源。只要牢牢记住“A 是全称肯定，E 是全称否定，I 是特称肯定，O 是特称否定”即可。

此外还有两种单称命题：

- 小王买了瓷器，是单称肯定；
- 小王没买瓷器，是单称否定。

单称命题可以直接点名某个人，可以近似理解为特殊的 A 或 O。标准逻辑教材主要掌握前四种，单称命题在题中往往作为最后一块拼图使用，不要把六种平级分类全搅在一起。

#### AEIO 的四种关系

真正需要记的是四组关系。

| 关系 | 命题组合 | 真假特点 | 在真话假话题中的作用 |
| :--- | :--- | :--- | :--- |
| 上反对 | A、E | 不能同真，可以同假 | 至少占一句假话 |
| 下反对 | I、O | 不能同假，可以同真 | 至少占一句真话 |
| 矛盾 | A、O；E、I | 必有一真一假 | 同时占一句真话和一句假话 |
| 差等 | $A\rightarrow I$，$E\rightarrow O$ | 由全称真可推特称真 | 确定真话后继续推出具体情况 |

A 与 E 不可能同时为真，因为“所有都成立”和“所有都不成立”不能并存；但可以同时为假，因为可能有些人成立、有些不成立。因此 A、E 至少有一句假话。

I 与 O 不可能同时为假，因为不可能既“有人是”，又“所有人都是非”。但两者可以同时为真，因为完全可以有人属于 $P$，另一些人属于非 $P$。因此 I、O 至少有一句真话。

A 与 O、E 与 I 则是最标准的矛盾关系。把 A、O 或 E、I 放在一起，它们必然一真一假。可以记“矛盾的浏览器，IE 矛盾”，A、O 则在另一边成对矛盾。

于是，三句话只有一句真话时，如果看到 I、O，至少有一句真；只有一句假话时，如果看到 A、E，至少有一句假；看到 A、O 或 E、I，则真假名额可以一次锁定。

#### 全称、特称和单称之间，只能按方向推

差等关系先记两条：

- A 真，I 一定真；A 真，某个具体的人属于 $P$ 也为真。
- E 真，O 一定真；E 真，某个具体的人不属于 $P$ 也为真。

但反过来不能乱推。A 真，不代表 I 一定真，因为题干只说了“所有”如何，没有保证特称对象一定存在；I 真也不能反推 A。E 与 O 同理。

单称命题还要额外记两条单向推理：

- “小王买了”真，能推出“有的游客买了”真；但“有的游客买了”真，不代表一定是小王买了。
- “小王没买”真，能推出“有的游客没买”真；但“有的游客没买”真，也不代表一定是小王没买。

一句话概括：**小张可以代表“有的”，但“有的”不一定能包住小张。** 特称命题不能随意特指到某个人，推理时不能来回倒。

### 把 AEIO 放进占位模型

#### 2018年国考：矛盾一次锁定两句话

集训是否达标的三句话中，前两句是：

- 所有人都没达标，这是 E；
- 有的会达标，这是 I。

E 与 I 矛盾，一真一假，已经占掉唯一的真话名额和唯一的假话名额。第三句必假。

第三句说“省冠军或国家队达标”，它为假，就意味着省冠军没达标，国家队也没达标。直接得到结论。

题目难不到哪里，就是套路太固定，考官出得多了自然觉得没意思，所以后来考得少了。但只要考出来，基本就是福利题。

#### 2018年陕西：先把矛盾标准形态找全

四位老师中只有一位说真话，核心几句是：

- 所有学生都没及格，E；
- 并不是所有学生都没及格，实际等价于所有学生都及格，属于 A；
- 有的学生没及格，O；
- 王萌萌没及格，是单称 O。

第一条 E 与“并非所有学生都没及格”矛盾，一真一假。其余两句都为假。第四句“王萌萌没及格”为假，说明王萌萌及格；第三句“有的学生没及格”为假，进一步得到所有学生都及格。

既然所有学生都及格，第一句“所有学生都没及格”为假，第二句“王萌萌没及格”为假，第三句“并非所有学生都没及格”为真。唯一真话属于丙。

这道题里，单称命题先放在一边，先找标准的 E 与其矛盾命题。矛盾找准后，单称句只负责把具体人物代入。

#### 2018年山东：AO 矛盾后再推出具体人

四位同学讨论作业完成情况，只有一句假话：

- 所有人都写完作业，A；
- 小李写完作业，单称肯定；
- 有人没写完作业，O；
- 如果小李写完，那么小赵没写完。

“小李写完”与“有人没写完”构成 A、O 矛盾，二者必有一真一假，正好占掉唯一的假话名额。剩下两句都是真的。

“有人没写完”为真，只能由小李之外的人没写完来满足；“小李写完”为真，进一步代入第四句，得到小赵没写完。既然小赵没写完，“所有人写完”就必假，唯一假话是甲。答案选甲。

这类题比前面的 A、O 直接占位多了一步：先从矛盾确定另外两句为真，再把真条件代入推出具体人，最后拿这个人回头判断全称命题。AEIO 难到头，基本就是再多代入一步。

#### 23年福建：AE 只能占假话名额

三句话只有一句真话时，最容易出现的错误是看到 A、E 就直接说“它们占了真话名额，第三句为假”。这正好踩了坑。

A、E 是上反对关系，只能保证至少一句假话，绝不能保证至少一句真话。它们占的是**假话名额**，不是真话名额。

早餐题第一句“所有人都不吃早餐”是 E，相应的“所有人都吃早餐”是 A，第三句是“小李不吃早餐”，属于单称 O。只有一句真话时，正确做法是找同真：若 E 真，则所有人都不吃，小李必然不吃，第三句也为真，与一句真话矛盾。因此第一句只能是假，A 为真，也就是有人吃早餐。

如果题目把条件改成“三句话只有一句假话”，A、E 就能先占掉唯一的假话名额，第三句为真。小李不吃早餐，A“所有人都吃早餐”便为假，E“所有人都不吃早餐”为真。此时可推出所有人都没吃早餐，也能推出小李没吃早餐。

题干只改“真”还是“假”，推理方式没变，结论却会随选项改变，考官随便改一个字就足以检查基本功是否扎实。

#### 最难只多一步：先占名额，再判断谁真

设计工作室有四十二个人，三句话中只有一句真话：

- 有人有证书，I；
- 有人没有证书，O；
- 负责人没有证书，单称 O。

I、O 不能同时为假，至少有一句真。题干只有一句真，所以真话在第一、二句中，第三句必假。负责人没有证书为假，说明负责人有证书，于是“有人有证书”确定为真。

接下来不能因为 A 真，就从内容上直接推出 O 假。O 之所以为假，是因为题干只允许一句真，第一句已经占掉唯一真话名额，除此以外的话都必须是假。

“有人没有证书”为假，恰好等价于“所有人都有证书”，所以四十二个人全有证书。

这里必须分清两种推理：

```text
从内容推：
O为假 ⇔ 所有人都有证书（命题内容上的真假关系）

从名额推：
第一句已经确定为真，而题干总共只有一句真
⇒ 第二句只能说假
```

不要把“题干只允许一句真”混进命题本身，逻辑层就乱了。

22年山东的地震仪预测题也是同样结构。单独判断甲型仪器能否预测，另有“有的型号不能预测”和“有的型号能预测”，题干同样只有一句真。后两句是 I、O，至少占一句真，因此第一句必假，也就是甲型不能预测。

这样一来，“有的型号不能预测”已经由甲型确定为真，唯一真话落在它身上，“有的型号能预测”就必假。后者的矛盾命题 E“所有型号都不能预测”必真，因此乙、丙也都能判断不能预测。

这两道题就是 AEIO 的“天花板”：先由 I、O 占住真话名额，再根据具体单称句判断 I、O 谁真谁假，最后用已确定的真话排除剩余句子。技能熟练以后，真的不难到哪去。

### 本讲提到的题目

下面把练习压缩成一份自检单。题干按讲述中给出的条件还原，答案保留选项字母。

#### 占位关系与唯一名额

- 23年广东申请题：只有一人通过申请；甲没通过、乙通过、丙没通过。问必然错误者。答案 D，即“乙通过”。甲没通过与丙没通过不能同假，真话被占住，所以乙通过必假。
- 25年国考四方桌题：甲乙丙丁按顺时针依次坐，只有一句真话；甲说东边人说谎，乙说南边人说谎，丙说自己位于西面或北面，丁说自己位于北面。问甲的位置。答案 A，即甲在北面。甲乙不能同假，丙丁为假，再分丙在东、丙在南两种情况检验顺时针次序。
- 23年陕西排名题：红、绿、蓝、黄对应第一至第四名，只有一句真；条件依次为“红第一则黄第二”“红第三则蓝第四”“蓝不等于第四”“黄第二”。答案 B，绿第二。第二句与第三句不能同假，锁定第一、四为假，再依次推出红第一、蓝第四、绿第二。
- 25年浙江排名题：甲乙丙丁名次各不相同，只有一句真；条件包括“乙第二则甲第三”“丙冠军或丁不为第四”“甲不为第三”“丙获得亚军”。答案 A，甲冠军。第一句与第三句不能同假，锁定其余两句为假，推出丙第三、乙第二、丁第四。
- 23年山东世界杯题：四句话中只有一句假话，涉及欧洲冠军、法国冠军、南美洲冠军及阿根廷进四强。答案 C。冠军是欧洲和冠军是南美不能同真，冠军是法国和冠军是南美也不能同真，唯一的假话只能是第三句。
- 22年山东地震仪题：只有一句真；甲型仪器能预测某范围内地震、有的型号不能预测、有的型号能预测。答案 C，所有型号都不能预测。I、O 至少占一句真，第一句假；甲型不能预测使第二句真，第三句假，再由 A 与 E 矛盾得到全体不能预测。

#### 完整选项代入

- 十七年国考比较题：教练说“最多一人说假话”，且教练说假；选项给出 $A,B,C$ 的具体大小关系。答案 A，$A>B>C$。教练说假意味着至少两假，只有该选项为两假一真。
- 22年四川奖项题：四人各至少一个奖，共十奖；获得两个奖的人说假，其余人说真。答案 C。A、B 中甲获两个奖却说了真话；C 中前三句假、第四句真，与四人奖项分配吻合。
- 25年江苏部门题：甲乙丙三人的部门猜测只有一项正确，选项给出三人的完整安排。答案 C。只有 C 是一真两假。
- 21年江苏身份题：企业家、大学教师、歌手和会计师不重复，只有会计师的预言为真。答案 D，丁为企业家。乙不会当歌手与乙不会当教师不能同假，会计师只能在甲、丁中；乙丙为假，进一步得到丁为企业家。
- 20年北京茶类题：三种茶，每人两句判断，三人分别为两真、一真一假、两假。答案 C，龙井。龙井对应两错、一真一假、两真；另外两种情况都会使三人出现相同形态。
- 21年广东花卉题：三种花，每人两句判断，三人的真假形态各不相同。答案 B，月季。牡丹会形成重复的一真一假，玫瑰会形成重复的两真，只有月季符合。
- 一道甲乙丙丁各说三句、每人恰有一真两假的可能情况题：只有 D 代入后，每个人的三句话都能得到两假一真。

#### AEIO 综合题

- 2018年国考达标题：只有一句真；前两句为“所有人都不达标”和“有人达标”，第三句涉及省冠军或国家队达标。答案 D，省冠军和国家队均未达标。E、I 矛盾占掉真话，第三句必假。
- 2018年陕西老师题：只有一位老师说真；涉及全体学生未及格、并非全体未及格、有人未及格及王萌萌未及格。答案 C，丙说真。E 与其矛盾命题先占一真一假，另外两句为假，再推出所有学生都及格。
- 2018年山东作业题：只有一句假；涉及全员完成、小李完成、有人没完成，以及“小李完成则小赵没完成”。答案 A，甲说假。单称肯定与 O 命题矛盾占掉假话名额，其余为真，推出小李完成、小赵没完成，从而全称肯定为假。
- 23年福建早餐题：三句话只有一句真，涉及所有人不吃早餐、所有人吃早餐、小李不吃早餐。答案 D，有人吃早餐。只有一句真时不能误用 AE 占用真话名额，应利用 E 真则小李不吃的同真关系推出 E 假、A 真。改为只有一句假后，AE 占掉假话名额，结论改为所有人及小李都不吃早餐。
- 设计工作室证书题：四十二人中三句话只有一句真，分别为“有人有证书”“有人没有证书”“负责人没有证书”。答案 A，所有人都有证书。I、O 至少占一句真，第三句假；负责人有证书使第一句真，再因唯一真话名额确定第二句假，从而得到全员有证书。

> **最后提醒**：AEIO 并不难，真正要防的是把关系记反。A、E 占假话名额，I、O 占真话名额，A、O 与 E、I 同时占真、假两个名额。题面再复杂，最终都回到“找关系、占名额、代入真话、继续推”这四步。
