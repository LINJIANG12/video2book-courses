# 西电：微机原理与接口技术（113 讲）

西安电子科技大学的微机原理课程，以 8086 为主线，从数制运算、微处理器结构、汇编语法与寻址讲起，再延伸到指令系统、程序控制流、中断与字符串操作，最后落到存储器设计、系统总线工作方式、可屏蔽中断系统与 8255A / 8259A / 8253 三块可编程接口芯片。全 113 集，是本仓里偏硬件与接口设计的一门。

- **原视频**：[西电微机原理113讲](https://www.bilibili.com/video/BV1ZJ411b7Na) — Bilibili，BV1ZJ411b7Na
- **全 113 集**，已产出 8 册模块全书、8 篇复习笔记、115 份逐字稿

## 怎么学

这门课**推导与寄存器操作极其密集**：补码运算、标志位判断、寻址方式、时序图，都需要动手画、动手算。光读不写基本记不住。

- **前两册是地基** → 第 1 册（8086 系统基础、数据表示与处理器结构）建立数制与结构认知，第 2 册（汇编语言语法与指令寻址体系）把语句格式与寻址方式讲透，这两册没吃透后面会一直卡
- **汇编要动手写** → 第 3、4 册是程序控制流与程序结构，模块全书保留了课程中的完整程序与逐条解析，建议在 DOSBox 或 emu8086 里跑一遍
- **接口部分抓时序** → 第 6~8 册涉及总线工作方式与三块可编程芯片（8259A / 8255A / 8253），时序图和方式字是考点与难点
- **考前速查** → `notes/` 的 8 篇按「系统基础 / 语法寻址 / 控制流 / 中断与串操作 / 总线 / 存储器 / 接口 / 定时中断」聚合，适合快速过一遍寄存器与指令格式
- **核对原话** → `subtitles/` 有 113 份分集逐字稿；个别集次另附 `_supplement.txt` 补充语料，内容比逐字稿更完整
