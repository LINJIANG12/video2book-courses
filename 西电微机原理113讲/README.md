# 西电：微机原理与接口技术（113 讲）

西安电子科技大学的微机原理课程，以 8086 为主线，从数制运算、微处理器结构、汇编寻址讲起，再延伸到指令系统、子程序与中断，最后落到存储器设计、8259A 中断控制器、8255A 并行接口与 8253 定时计数器等接口芯片。全 113 集，是四门课里唯一以硬件与汇编为主线的。

- **原视频**：[西电微机原理113讲](https://www.bilibili.com/video/BV1ZJ411b7Na) — Bilibili，BV1ZJ411b7Na
- **全 113 集**，已产出 113 篇精读长文、14 册模块全书、7 篇复习笔记、112 份逐字稿

## 怎么学

这门课**推导与寄存器操作极其密集**：补码运算、标志位判断、寻址方式、时序图，都需要动手画、动手算。光读不写基本记不住。

- **按模块推进** → `textbooks/` 14 册的顺序就是讲课顺序。模块 02（数制与补码）和模块 03（8086 结构）是全课地基，这两册没吃透后面会一直卡
- **汇编要动手写** → 模块 04~08 是汇编语言主体，长文保留了课程中的完整程序与逐条解析，建议在 DOSBox 或 emu8086 里跑一遍
- **接口部分抓时序** → 模块 09~14 涉及总线时序与三块可编程芯片（8259A / 8255A / 8253），时序图和方式字是考点与难点
- **考前速查** → `notes/` 的 7 篇按「基础 / 结构 / 指令 / 程序 / 总线 / 中断 / 接口芯片」聚合，适合快速过一遍寄存器与指令格式
- **核对原话** → `subtitles/` 有逐字稿；个别集次附带 `_supplement.txt` 补充语料，内容比逐字稿更完整
