## 微机系统分工与三总线结构


### 课程分工与智能系统信号链路

* **课时与章节分工**

    * 前4章需C语言程序设计能力，汇编语言属低级语言且直接面向微处理器即中央处理器（Central Processing Unit，CPU）；第5章至第10章需数字电路与逻辑设计能力，用到门电路、译码器、存储器芯片、锁存器、缓冲器。
    * 讲授不严格按教材顺序，一处内容牵扯教材前后多处，对应位置随讲随提示。
* **智能电子信息系统信号链路**
    * > **定义**：硬件设计中上了CPU并以CPU为核心设计控制的电子信息系统为智能电子信息系统。
    * CPU只认识二进制代码，外界温度、压力、速度、角度物理量须经转换才能处理。
    * 链路为外部物理量经传感器转电量，毫伏级经放大器放至伏特级，滤波电路滤波后经模数转换进CPU与存储器处理，结果经数模转换与后端调理去控外部设备，或以数字量直接显示打印。
    * 前端调理电路指传感器输出后做放大与滤波的环节，调理后信号留测试点供示波器测量。
    * 模数转换（Analog to Digital，AD）精度有8位、10位、12位，从采样到转成数字量有转换时间体现转换速度，按精度速度需求选型。
    * 何时采样转换由CPU发控制命令控制AD；前端量程各异，程控增益放大器放大倍数由CPU控制切换挡位。
    * CPU型号按需求选，收回数字量放存储器，按算法分析计算处理，结果存存储器并输出，形成闭环。
    * 后端调理电路指数模转换后做放大滤波的环节；数模转换（Digital to Analog，DA）指把数字量转模拟量的环节。
    * 显示用数码管或液晶屏（Liquid Crystal Display，LCD）接收数字量，无需再经DA。
* **软件编程与接口设计分工**
    * CPU编程用汇编语言，对应前4章；设备与CPU经接口电路连接，对应第5章之后，其中第6章为存储器系统，讲CPU外围扩充存储器接口。
    * AD为输入设备，DA为输出设备，输入输出站CPU角度划分，外界进CPU为输入，CPU出外界为输出；常用输入还有键盘，常用输出还有显示器、打印机；设备分并行串行数字模拟格式。
    * 学习用CPU为英特尔（Intel）公司80X86系列8086，工程可选MCS-51系列单片机CPU、德州仪器（TI）公司MSP430、微芯（Microchip）公司PIC单片机CPU，学透一种按需求选型。
    * > **易错点**：AD是输入，DA是输出，方向按CPU角度划分，别记反。

### 三总线方向与系统总线形成

* **早期五大部件与微型化**
    * 算术逻辑运算单元（Arithmetic Logic Unit，ALU）负责加减乘除算术与与或异或非逻辑运算，控制器控制ALU运算及运算方式。
    * 参运数据来自存储器预存或输入设备，运算结果在控制器控制下存回存储器或送输出设备；输入设备记I，输出设备记O，统称I/O设备。
    * 控制器加ALU等集成一颗芯片即CPU，亦称微处理器；以CPU为核心组起即微型计算机；个人计算机（Personal Computer，PC）指放办公桌的微型化计算机。
* **数据总线（Data Bus，DB）与地址总线（Address Bus，AB）与控制总线（Control Bus，CB）**
    * > **定义**：传数据信息的专用通道称数据总线，传地址信息的称地址总线，传控制信息的称控制总线，三者合称三总线，机内只传此三种。
    * `DB`为双向，CPU可经`DB`发存储器也可从存储器接收；`AB`为单向，只由CPU发出找单元找设备；`CB`传控制信息。
    * 存储器地址码简称存储器地址，指存储器每单元号码；I/O地址码简称I/O地址，指众多I/O设备中某一个的编号；未特指时地址指存储器地址。
    * 地址线条数越多可管理外部存储器单元空间越大；8位CPU有8条数据线，16位有16条，32位有32条。
    * CPU引脚按信息分数据引脚、地址引脚、控制引脚，部分为数据地址复用引脚，经分开电路后数据走`DB`、地址走`AB`、控制走`CB`。
    * > **易错点**：`DB`双向、`AB`单向，地址只由CPU发出，别记反。
* **命令信息与状态信息**
    * > **定义**：CPU经`CB`向外发出的读写命令称命令信息，外设与存储器向CPU反馈的工作状态称状态信息，两者合称控制信息。
    * CPU先经`AB`发地址选中单元设备，再经`DB`读回或写入，命令走`CB`；看接口先问该线属三者哪一种。
* **系统总线形成电路与两级总线**
    * > **定义**：把微处理器复用引脚转化成专用`DB`、`AB`、`CB`的电路称系统总线形成电路。
    * 系统总线形成电路用锁存器、缓冲器搭建，属教材第五章内容；设计需掌握CPU每引脚功能及信号间时序关系。
    * 微处理器级总线指微处理器引脚构成的总线，短板为部分引脚复用且驱动负载能力弱。
    * 系统总线亦称系统级总线，指转化后三线形式；微处理器级总线只驱动系统总线形成电路一个负载，大量负载驱动交系统级总线；需与CPU通信的存储器与I/O均挂系统总线。
    * 系统总线形成电路一次解决复用解开与驱动能力提高两问题。

## 存储器组织与接口地址译码


### 只读与随机存储器分工与挂接

* **只读存储器（Read Only Memory，ROM）**
    * > **定义**：掉电后信息不丢失且使用现场只能读的存储器为ROM，称程序存储器。
    * ROM存放系统管理程序与用户程序代码；主板例用可擦除可编程只读存储器（Erasable Programmable ROM，EPROM）在紫外线下可擦除，存放基本输入输出系统（Basic Input Output System，BIOS）。
    * 挂接操作为CPU经地址线发地址找单元，再发读命令输出允许（Output Enable，`OE#`，`#`表低有效）把该单元数据放数据线被读走。
    * 板上只能读，写入靠用户编好调通后用专用写入器写入再插回电路板。
* **随机存取存储器（Random Access Memory，RAM）**
    * > **定义**：掉电后信息丢失且能读能写的存储器为RAM，称数据存储器。
    * RAM存放程序运行期间产生的数据；地址引脚为`A0`至`An`，8位数据引脚为`D0`至`D7`。
    * 读操作为地址总线发地址选中单元，控制总线发读命令`OE#`低有效输出数据；写操作为地址总线发地址，控制总线发写命令写允许（Write Enable，`WE#`）或写（Write，`WR#`）低有效写入数据线数据。
    * 对该单元读还是写由现行执行指令决定，存储器读写指令对存储器，I/O读写指令对I/O。
* **基本输入输出系统上电任务**
    * 加电后CPU从ROM取`BIOS`执行，先对RAM自检看每地址每位（bit）能写能读，再对主板I/O接口电路初始化，最后从磁盘读操作系统到内存，用户在操作系统界面工作。
    * 顺序按硬件依赖排列，先确认RAM可用，再让接口就绪，最后装操作系统。
    * 51系列单片机与MSP430内部带一定容量程序存储器与数据存储器，不够在外部总线扩充；8086内部无存储器电路，所用存储器必须在三总线扩展。
    * 存储器接口设计为教材第六章内容，I/O接口设计为第七章起内容。

| 对比项 | ROM程序存储器 | RAM数据存储器 |
| :--- | :--- | :--- |
| 掉电后信息 | 不丢失 | 丢失 |
| 主要用途 | 系统管理程序与用户程序代码 | 程序运行期间产生的数据 |
| CPU访问方式 | 只能读 | 能读能写 |

### 按字节组织与字存放规则

* **按字节组织与总线条数作用**
    * 存储器按字节组织，一单元一字节存8位`D0`至`D7`，每单元有二进制编码地址码简称地址；4位芯片需两片并成8位，结果必须按字节为铁律。
    * 地址线条数决定可寻址外部存储器空间大小，如4条管理16单元；寻址指寻找将读写单元地址，寻址方式越多编程越灵活。
    * 数据线条数决定一次传送有符号数范围，8位无符号`0~255`带符号`-128~127`，16位无符号`0~65535`带符号`-32768~32767`；两作用别混。
* **8086字单元存放规则**
    * 8086外部16条数据线，一次可传16位占两字节或只传8位；16位数据称一字，低8位`D0`至`D7`称低字节，高8位`D8`至`D15`称高字节。
    * 任意相邻两字节单元拼一字单元，地址低者称低地址单元，高者称高地址单元，字单元地址取低地址单元地址。
    * 存放遵循低字节放低地址单元，高字节放高地址单元；读出低地址单元即低字节。

### 接口地址与译码选通

* **I/O接口电路**
    * > **定义**：设在设备与系统总线之间实现通信的连接电路为I/O接口电路。
    * 输出方向为CPU经数据总线发接口再经数据输出引脚给设备，输入方向为设备经数据输入引脚进接口再经数据总线被读走；CPU只和接口打交道。
    * 显卡连显示器与系统总线、声卡连音箱皆接口电路；数据沿数据总线传送，区别在与哪一接口读写。
    * 存储器与CPU沿数据总线直接通信，设备不行，因设备接收格式各异，有数字模拟并行串行之分。
* **I/O接口地址**
    * > **定义**：分配给I/O设备对应I/O接口电路的地址为I/O接口地址。
    * 对接口读写演变为对该地址操作，同对存储器单元操作演变为对存储器地址操作。
    * 8086用地址线传送，存储器地址用20根，I/O接口地址用16根，同一组地址线既发存储器地址又发I/O地址。
    * CPU靠执行不同指令区分，存储器读写指令对存储器，I/O读写指令对I/O，经相应控制引脚发不同读写控制命令；用户看控制线命令抓住地址给谁。
* **I/O地址译码电路**
    * > **定义**：把一把地址转换翻译成给I/O接口一路控制信号的翻译电路为I/O地址译码电路。
    * 一把地址如16根译成一个引脚选通信号且低有效，地址吻合对应输出有效选中本接口，其余不选中。
    * I/O操作有效控制命令须参加译码，看地址是否I/O地址看控制线有无对I/O操作有效命令。
    * 本质为数字电路（Digital Circuit，数电）问题，用门电路、138译码器、24译码器设计，第七章要求至少掌握门电路给I/O译码，存储器译码为第六章。
    * 例4根`A0`至`A3`分配地址9即二进制`1001`，两个`0`直进或门，两个`1`经反相器再进或门，全`0`输出低有效命中；完整设计还须引I/O控制信号一起译码。
* **裸机与微机系统**
    * 微型计算机裸机指未配设备程序的硬件部分；配相应设备、加上电、灌上程序加载后才成微型计算机系统才能工作；平时买微机简称实为买微机系统。

## 数制转换方法体系


### 手工转换的逼近加权与分组规则

* **字长与位权**
    * 字长用`n`表示，一般8即一字节，字为16；8位位号`D0`至`D7`，权为`1`、`2`、`4`、`8`、`16`、`32`、`64`、`128`，即`2^0`至`2^7`。
    * 转换先看字长，题目要8位而有效不足，高位补零补够8位。
    * 机内数全二进制，十六进制一位对应四位二进制；整数转换为重点，小数为了解。
* **逼近法**
    * 十进制转二进制手工不用除二取余，用逼近法按`128~1`逐位试，够权记`1`并减去该权，不够记`0`，做到第`0`位。
    * 93在8位下对应`01011101`。
* **位置加权法**
    * > **定义**：被转换二进制数每位数字乘该位权最后求和即位置加权法。
    * `01011101`按`1×2^6+1×2^4+1×2^3+1×2^2+1×2^0`求和得`64+16+8+4+1=93`。
* **四位分组法**
    * 十进制转十六进制先转二进制再四位一组，整数从小数点左第`0`至第`3`起分组，最左不足四位高位补零。
    * `0101|1101`对应`5|D`得`5DH`，`H`表十六进制；`101`对`5`、`1101`对`D`直接对应；二进制与十六进制四位一组直接互转；该路比除16取余快。

| 转换方向 | 手工做法 |
| :--- | :--- |
| 十进制到二进制 | 逼近法，按位权逐位试 |
| 二进制到十进制 | 位置加权法，按位求和 |
| 十进制到十六进制 | 先转二进制，再四位一组 |
| 二进制与十六进制 | 四位一组，直接对应 |

### 程序中的进制转换算法

* **除10取余法**
    * > **定义**：对被转换二进制数连除十进制`10`，第一次余数为个位，第二次余数为十位，最后商为百位，依次得每位即除10取余法。
    * 程序中二进制转十进制不用位置加权法因程序复杂，85%至90%用除10取余法。
    * 8位无符号`0~255`最高到百位，除两次即可；结果输出打印显示前须转十进制，CPU结果为二进制不能直接给用户。
    * 十进制演练193除10得中间商19余3为个位，19除10得商1余9为十位，1除10余1为百位；除几次看数的范围。
    * 平时积常用算法函数子程序模板，硬件单稳振荡滤波文档复用，从零做效率低。
* **比较法**
    * 程序中二进制转十进制常用之二为比较法；8位无符号范围`0~255`最高到百位，百十个统计处先清零初始化。
    * 拿被转换数与`100`比，高于等于`100`百位增`1`并减`100`再比，直至不再高于等于`100`已无百位；剩差与`10`比，高于等于`10`十位增`1`并减`10`再比，直至不再高于`10`，剩余为个位。
    * 无符号比高低，带符号才比大小。
* **键盘输入转换算法**
    * > **定义**：对已输入和乘`10`加当前输入，乘加所得和直接为二进制和即键盘十进制转二进制算法。
    * 键盘例先敲`9`后敲`5`按`95`计，第一次数乘`10`加`5`，CPU乘`1010B`结果已二进制不用再转；CPU只认识二进制数。
    * 读程序见此处理即知干此事；程序设计指给文字功能编程序，程序分析指给代码读功能，两线都要训练。

## 算术逻辑运算与状态标志


### 加减实例与寄存器指令基础

* **8位加减实例**
    * 97为`61H`即`01100001B`，89为`59H`即`01011001B`，`B`表二进制数。
    * 手工位对位逢`2`进`1`，97加89得`10111010B`即186即`BAH`，97加89等于186验算对即没错。
    * 减法位对位不够向前借`1`算`2`；97减89程序结果为`08H`。
    * 乘除位对位与十进制一样，了解即可；算术含加减乘除，重点为加法其次减法，乘除了解。
    * 任何运算先弄清字长`n`为8字节运算还是16字运算。
* **寄存器（Register）与拼合关系**
    * CPU内部暂存数据的部件称寄存器；参运数据多在外部存储器，CPU每次经总线远取耗时降速，内部放少量数据直接取提速。
    * 个数越多暂存越多越快，但体积大不再微处理器，综合取少量；8086为16位CPU，内部多16位寄存器，亦允暂存8位字节型。
    * 常用8位为`AL`、`AH`、`BL`、`BH`、`CL`、`CH`、`DL`、`DH`，仅此8个，两两拼16位，`AH`高`AL`低拼`AX`，`BX`、`CX`、`DX`同理。
    * 字节型用8位寄存器，16位字型用16位寄存器。
* **传送加减指令与数字名称规则**
    * 指令助记符（Mnemonic）如`MOV`知传送、`ADD`知相加；把97送`AL`写`MOV AL,97`，机器码`B0H`告CPU送8位数到`AL`后跟`61H`，两字节组成一条指令。
    * 源程序十进制数据无需人工转二进制，汇编翻译时汇编程序自动换算，只记机内全二进制即可。
    * 加法用`ADD`，目的操作数在逗号左，原操作数在逗号右，目的加原和放回目的；例`MOV AL,97`加`ADD AL,89`后`(AL)`指`AL`内容为`4BH`。
    * 减法用`SUB`，目的减原差放回目的；例`MOV AL,97`加`SUB AL,89`后`(AL)`为`08H`。
    * 汇编语法数字以`0`至`9`打头，名称以字母打头，`A`至`F`开头十六进制前冠`0`，如`B3H`写作`0B3H`，汇编靠此区分数字名称。
    * 结果放回目的，目的多为寄存器，绝不能为立即数。

```asm
MOV AL, 97
ADD AL, 89   ; (AL)=4BH，和放回目的
MOV AL, 97
SUB AL, 89   ; (AL)=08H，差放回目的
```

### 状态标志与条件分支判定

* **处理器状态字寄存器（Processor Status Word，PSW）**
    * > **定义**：CPU内部专门存放运算后结果状态的寄存器为PSW，亦称标志寄存器与程序状态字。
    * 8位处理器PSW为8位，16位为16位；一标志一状态用PSW一`bit`描述；8086的PSW为16位，有用仅9位，从右往左第`0`至第`15`位有符号有用，空着无用，见教材15页图2.3中`ALU`下方PSW与18页图2.5。
    * CPU据结果自动设置相应标志，条件分支测即测PSW某状态标志。
    * `MOV`传送实做传送无运算，执行不影响PSW每位；测条件前须保证上方指令影响PSW才能测；分支设计先定测什么条件再定条件怎么产生，有产生才能测。
* **零标志（Zero Flag，ZF）与符号标志（Sign Flag，SF）**
    * `ZF`为第`6`位，结果为`0`置`1`否则清`0`；测`ZF`等`1`即结果为`0`。
    * `SF`取结果最高位，最高为`1`判负置`1`，为`0`判正清`0`，即最高位复读机；带符号数最高位为符号位，8位`D7`、16位`D15`，`0`正`1`负。
    * `SUB`得`08H`例最高`0`为正，`ZF`为`0`，`SF`为`0`。
* **溢出标志（Overflow Flag，OF）与肉眼判法**
    * `OF`为第`11`位，`O`即`over`，有溢出置`1`否则清`0`；溢出指两数运算结果超该字长范围，8位放不下则错，8位范围`+127~-128`，16位同理。
    * 正加正得负即错为溢出；8位数表数范围有限，和超范围8位放不下即错。
    * 加法看次高向最高进位与最高向前进位，要进都进要不都不进无溢出，一进一不进溢出；减法看借位，次高向前借与符号减向前借，要借都借要不都不借无溢出，一借一不借溢出。
    * `SUB`得`08H`例次高与最高皆不借，无溢出，`OF`为`0`。
* **进位标志（Carry Flag，CF）与零标志取值**
    * `CF`加法看最高向前有无进位，有置`1`无清`0`；减法看借位。
    * `53+91`溢出例最高向前无进位，`CF`清`0`；`(-11)+(-3)`得`F2H`例最高向前有进位，`CF`置`1`，丢掉不管。
    * `ZF`看结果是否全`0`，全`0`置`1`，否则清`0`；两例结果非零皆清`0`。
* **奇偶标志（Parity Flag，PF）与辅助进位标志（Auxiliary Carry Flag，AF）**
    * `PF`不管字节字只看低八位`1`个数，偶数置`1`奇数清`0`，别记反；留作串行通信数`1`个数校验的现成硬件。
    * 串行一字节从第`0`起逐位发至第`1`第`2`发完，奇校验发低7累计`1`数，奇则第`7`发`0`保奇，偶则第`7`配`1`凑奇，接收同样数奇认对，偶校验凑偶。
    * `AF`看低四`0~3`向高四`4~7`有无进借，加法第`3`向第`4`进称半进位，减法借称半借位亦称辅助借位；`53+91`例有进置`1`，无进清`0`；主为BCD运算测进借。
    * `(-11)+(-3)`得`F2H`例`AF`为`1`低有进，`OF`为`0`次高最高一致无溢出，`SF`为`1`最高`1`负，`PF`为`0`因`1`个数5奇。
    * 反映结果的六标志为`OF`、`SF`、`CF`、`ZF`、`PF`、`AF`，仅此六个。
* **条件分支流程**
    * 条件即CPU运算后结果某状态；测试点前方必有一次CPU运算才有状态可测。
    * 满足走甲路处理，不满足走乙路处理，最后回到主流程继续执行。

| 运算 | 次高向最高 | 最高向前 | 是否溢出 |
| :--- | :--- | :--- | :--- |
| 加法 | 进位 | 进位 | 无溢出 |
| 加法 | 不进位 | 不进位 | 无溢出 |
| 加法 | 一进一不进 | 不一致 | 溢出 |
| 减法 | 借位 | 借位 | 无溢出 |
| 减法 | 不借位 | 不借位 | 无溢出 |
| 减法 | 一借一不借 | 不一致 | 溢出 |

### 逻辑运算指令与位操作应用

* **与运算指令与清零场合**
    * 助记符为`AND`，`AND DST,SRC`目的和源按位对位与，结果回目的；规则`1`与`1`得`1`，任何数与`0`得`0`；例`MOV AL,97H`加`AND AL,89H`即`01100001B`与`01011001B`结果回`AL`。
    * 应用为某些位清零剩余不变，想清零位与`0`，想不变位与`1`。
    * 例`AX`低4清零其余不变为`AND AX,0FFF0H`，高12全`1`低4全`0`即`FFF0H`，字母开头前加`0`。
    * 算术影响全部标志，逻辑只影响部分，具体第三章后点名。
    * > **易错点**：十六进制字母开头前必须加`0`，`FFF0H`错，`0FFF0H`对，否则汇编当名称。
* **或运算指令与置一场合**
    * 助记符为`OR`，`OR DST,SRC`位对位或，结果回目的；规则`0`或`0`得`0`，任何数或`1`得`1`；例`MOV AL,97H`加`OR AL,89H`。
    * 应用为某些位置`1`剩余不变，想置`1`位或`1`，想不变位或`0`。
    * 例`BX`低4置`1`剩余不变为`OR BX,000FH`，低4为`1`即`0FH`。
* **异或运算指令与取反场合**
    * 助记符为`XOR`，`XOR DST,SRC`位对位异或，结果回目的；规则相同得`0`不同得`1`，即`1⊕1=0`、`0⊕0=0`、`1⊕0=1`。
    * 应用为某些位取反剩余不变，想取反位异或`1`，不变位异或`0`，因异或`1`翻转异或`0`不变。
    * 例`AL`低4不变高4取反为`XOR AL,0F0H`，高4为`1`低4为`0`即`F0H`前加`0`。
* **非运算指令与标志规则**
    * 助记符为`NOT`，`NOT DST`单操作数对指明8位或16位数按位求反，结果回目的。
    * `AND`、`OR`、`XOR`影响部分标志，`NOT`对PSW所有状态标志均无影响；算术影响全部。

| 运算 | 助记符 | 想变位给 | 不变位给 | 应用场合 |
| :--- | :--- | :--- | :--- | :--- |
| 与 | `AND` | `0` | `1` | 某些位清零剩余不变 |
| 或 | `OR` | `1` | `0` | 某些位置1剩余不变 |
| 异或 | `XOR` | `1` | `0` | 某些位取反剩余不变 |
| 非 | `NOT` | 按位求反 | 无 | 单操作数整体取反 |

```asm
AND AX, 0FFF0H  ; AX低4清零其余不变
OR BX, 000FH    ; BX低4置1其余不变
XOR AL, 0F0H    ; AL高4取反低4不变
NOT DST         ; 目的按位求反送回目的
```

## 补码表示与十进制字符编码


### 有符号数表示与范围

* **无符号数表示范围**
    * 范围只由字长定，8位十进制`0~255`十六进制`00H~FFH`，16位`0~65535`即`0000H~FFFFH`。
* **机器数（Machine Number）与符号数字化**
    * > **定义**：最高位表符号其余表数值的表示法为机器数表示法。
    * 8位数`D0`至`D6`表数值、`D7`表符号，16位数`D0`至`D14`表数值、`D15`表符号；正符号`0`，负符号`1`；符号位永最高。
* **原码表示与零的问题**
    * 设带符号数为$X$，原码写$[X]_{原}$即机器数本身符号加数值。
    * 8位例$+3$原为$00000011B$即`03H`，符号`0`数值`0000011B`；$-3$原为$10000011B$即`83H`，符号`1`数值同；$+0$原为`00H`，$-0$原为`80H`。
    * 毛病不在正负在`0`两编码`00H`与`80H`，`0`不分正负故弃用。
    * 范围8位正$+127$至$+0$、负$-0$至$-127$，16位正$+32767$至$+0$、负$-0$至$-32767$，夹两`0`为带病证据。
* **补码（Two's Complement）定义与手工求法**
    * $$[X]_{补} = \begin{cases} X, & X \ge 0 \\ 2^n + X, & X < 0 \end{cases}$$
    * $[X]_{补}$表求$X$补码，$n$为字长取8或16；$X \ge 0$补等本身故正补等原不用算；$X<0$补为$2^n+X$亦写$2^n-|X|$。
    * 定义硬减如$-3$在$n=8$时$2^8-3$即$100000000B$减$11B$一路借位得`FDH`，每求做减法笨。
    * 手工用原码倒符号不变数值按位取反末位加`1`；验$-3$原$10000011B$不动`1`后`0000011B`取反`1111100B`加`1`得`1111101B`连符`11111101B`正好`FDH`，与定义结果一致。
    * 定义定本质且`0`单编码，取反加`1`为做题捷径又快不易错；`0`补为本身8位`00H`，正负分消除。
* **补码表示规则与范围**
    * 机中有符号数一律补码表示，用户眼真值机器眼补码，转换汇编程序做；例`MOV AL,-3`用户写`-3`，汇编成`B0H`操作码告CPU送8位数到`AL`，后跟字节已翻`FDH`即$-3$补码。
    * 范围8位$+127$至$0$至$-128$，16位$+32767$至$-32768$；对比原码8位$+127$至$-127$拖两`0`，补码`0`单多出编码给$-128$，16位多$-32768$。

| 字长 | 无符号范围 | 原码范围 | 补码范围 |
| :--- | :--- | :--- | :--- |
| 8位 | `0~255` | `+127~-127`且两零 | `+127~-128`且单零 |
| 16位 | `0~65535` | `+32767~-32767`且两零 | `+32767~-32768`且单零 |

### 补码加减运算与变补

* **加法公式与实例**
    * $$[X+Y]_{补}=[X]_{补}+[Y]_{补}$$
    * 求和补不必先和再补，直接加补码即可；例$(+53)+(+31)$和$+84$在8位$+127$放下不溢出，$+53$拼`00110101B`，$+31$拼`00011111B`，相加逢二进一得`01010100B`即$64+16+4=84$正好$+84$补。
    * 算时先摆权`32`、`16`、`8`、`4`、`2`、`1`逐位凑。
* **溢出界定与实例**
    * 两数运算结果超字长范围称溢出，8位加8位和还8位超`+127~-128`错，16位超16位范围错。
    * 手工抓次高向最高进位与最高向前进位，要进都进要不都不进正确无溢出，一进一不进必溢出。
    * 例$(+53)+(+91)$和144超$+127$必错，$+91$拼`01011011B`，相加`00110101B+01011011B=10010000B`最高`1`两正得负错溢出。
* **减法公式与减变加价值**
    * $$[X-Y]_{补}=[X]_{补}-[Y]_{补}$$
    * 例$5-3$即$[+5]_{补}-[+3]_{补}$，`00000101B-00000011B=00000010B`即$+2$逐位减正确。
    * $$[X-Y]_{补}=[X]_{补}+[-Y]_{补}$$
    * 把$Y$看$-Y$减变加；例$[+5]_{补}+[-3]_{补}$，$+5$为`00000101B`，$-3$补`FDH`即`11111101B`，相加得`00000010B`另向`CF`挤进位看8位丢掉仍$+2$，与直接减一致；由公式二变来。
    * 价值为手工加比减快提速，且CPU内算术逻辑单元只设加法器不设减法器，简电路缩小体积；数字电路加法器比减法器简单得多。
* **变补与结果仍补码**
    * > **定义**：已知$[Y]_{补}$求$[-Y]_{补}$即变补，亦称求负，对$[Y]_{补}$连符号全按位取反末位加`1`。
    * 例$Y=-3$补`11111101B=FDH`，取反`00000010B`加`1`得`00000011B=03H`即$[+3]_{补}$；会此手减随时变加。
    * 补码数运算结果仍补码；例$(-11)+(-3)$应$-14$补，$-11$原$10001011B$倒得补`11110101B=F5H`，$-3$补`FDH`，相加`11110101B+11111101B=11110010B=F2H`，低向高有进`AF`置`1`，最高向前进位丢掉不管。
    * 读真值对结果再求补符号不动取反加`1`，即`11110010`至`10001101`至`10001110=00001110B=14`符号`1`为$-14$，正好$-14$补；箭头为补码至再求补至原码。

```asm
MOV AL, 35H   ; AL=53
ADD AL, 5BH   ; AL=AL+91，和落AL设六标志
```

### 十进制与字符编码调整转换

* **二进制编码十进制数（Binary Coded Decimal，BCD）**
    * 机内数全二进制且CPU一律视二进制，带符号全补码，编程序常十进制运算，用二进制表十进制即BCD。
    * 十进制`0~9`共10状态需4位，4位16状态取前10即`0000`表`0`至`1001`表`9`，4位权`8`、`4`、`2`、`1`即`2^3`至`2^0`，数电`8421`码即BCD码。
* **组合BCD数与分离BCD数**
    * 存放按字节，存储器与CPU寄存器8086分8位16位；例十进制53组合低4放`3`即`0011`高4放`5`即`0101`，一字节装两位称组合BCD数（combined BCD），亦称压缩BCD数（packed BCD）。
    * 程序员眼BCD53而CPU眼二进制`01010011B=83`，错位为调根子。
    * 分离把`3`放一字节高4填`0`，`5`放下地址字节或下字节型寄存器高4填`0`，一字节只放一位称分离BCD数（unpacked BCD），占两字节；表示不同调整不同。
* **组合加法调整与调整指令选用**
    * 按组合分离放数CPU全按二进制算，结果可能非正确BCD须修正称调整；例53加28手工`3+8`逢十进`1`、`5+2+1=81`，CPU组合`MOV AL,53H`加`ADD AL,28H`即`01010011B+00101000B=01111011B=7BH`，十进制无`B`错因低超`9`不到`16`不进，高同理。
    * 判据为某4位大`9`或不大于`9`但向前有进则加`6`修正，减则减`6`；低看大`9`看`AF`，高看大`9`看`CF`；大或有进加`6`。
    * 例低`1011B=11`大`9`加`6`迫进高加`0`，`01111011B+00000110B=10000001B=81H`低向高进，高不大`9`且无向前进位不用调，得`81H`读十进制81对上；CPU低测`AF`高测`CF`，`AF`专为BCD留。
    * 为6因4位`0~15`共16状态十进制用`0~9`共10，多走6找补，借多退6。
    * 指令归属算术类末教材第53页第3.5.6节，调整依附运算收末尾查一次到位；加减分组合分离调整，乘除只能分离无组合。
    * 被调数默认`AL`故运算目的须`AL`，放`BL`、`CL`够不着错；指令省操作数字段译码快代价放`AL`；手工会调程序别忘`ADD`永二进制须亲手写调。
    * 例`MOV AL,35H`组合35加`ADD AL,27H`按二进制和留`AL`加`DAA`调`AL`和，`DAA`为加法组合BCD调整（Decimal Adjust AL after Addition，DAA）无操作数。

| 运算类型 | 组合BCD数 | 分离BCD数 |
| :--- | :--- | :--- |
| 加法 | `DAA` | `AAA` |
| 减法 | `DAS` | `AAS` |
| 乘法 | 无 | `AAM`系列 |
| 除法 | 无 | `AAD`系列 |

```asm
MOV AL, 35H      ; 组合BCD数35
ADD AL, 27H      ; CPU按二进制相加，和留AL
DAA              ; 对AL中组合BCD和做加法调整，无操作数
```

* **美国标准信息交换码（American Standard Code for Information Interchange，ASCII）**
    * 机内字符均ASCII码表示，机内数二进制带符号补码字符ASCII三填空汇编用；原创7位每字符7位二进制，放字节最小8位高补`0`，故字符高位`b7`恒`0`，高非`0`必非字符；后7真编码，高半`3H~7H`基本常用可写。
    * 可写`0`至`9`对应`30H`至`39H`高半全`3`低半即数字，大写`A`至`F`对应`41H`至`46H`如`A`为`41H`、`F`为`46H`，小写`a`至`f`对应`61H`至`66H`如`a`为`61H`、`f`为`66H`；大小写差`20H`。
    * 键盘输入皆字符屏幕显示皆字符；例敲`1`入`31H`，结果`2`转`32H`送显卡光标处显示`2`。
    * 字符转数字`0`至`9`减`30H`或与`0FH`高与`0`屏蔽低与`1`不变可得；大写`A`至`F`转数字减`37H`，例`41H-37H`借`1`当`16`得`0AH`；反之数字转大写加`37H`，数字`0`至`9`转字符加`30H`；字符变数字减，数字变字符加。
    * 大小写互转差`20H`，小转大减`20H`大转小加`20H`，判断区间复杂推崇逻辑一条：大小写仅第`5`位`20H`位不同，大`0`小`1`其余同，大写`0100`与`0101`打头26字母，小写`0110`与`0111`打头，例大`A`为`01000001`即`41H`小`a`为`01100001`即`61H`。
    * `AL`字母变大写不管原大小统一大写用`AND`清`0`不变，标准`AND AL,0DFH`即`11011111`等效`AND AL,5FH`因字符最高恒`0`；变小写置`1`不变用`OR`，标准`OR AL,20H`即`00100000`该位或`1`其余或`0`；传统判断多条，逻辑一条少速度快；指令越少执行越快。

```asm
AND AL, 0DFH     ; AL字母一律变大写
AND AL, 5FH      ; 等效写法
OR AL, 20H       ; AL字母一律变小写
```
