# 8086汇编程序结构与系统总线工作方式

## 宏指令

### 定义与展开

* **宏指令（macro instruction）**

    * > **定义**：把一段指令序列定义为宏名；汇编程序遇到宏调用时，在调用处插入宏体，并在汇编阶段用实参替换形参。

    * 宏调用最终变成实际机器指令，不是运行时调用的特殊指令。

    * 目标代码清单中，由宏体插入的代码左侧带 `+` 标记，普通指令的机器代码旁没有此标记。

    * 宏展开发生在汇编阶段；子程序调用则是在运行时执行到 `CALL` 时才转移。

* **实参与形参**

    * 替换规则：实参替换形参，位置必须一一对应。

    * 形参有几个就写几个实参；少写或多写都会破坏对应关系。

    * 多出的实参不会按预期成为调用参数，汇编程序会以 `0` 补足，从而得到错误功能。

### 宏与子程序

* **宏指令与子程序**

    * > **定义**：二者都能封装并复用一段程序功能，但宏在汇编时展开，子程序在运行时调用。

    * 空间代价：宏体在每次调用处插入，不另留一份模块；子程序无论调用多少次只保留一份，但模块本身占空间。

    * 时间代价：宏展开后直接执行；子程序还要承担 `CALL`、`RET` 的调用和返回时间。

    * 适用场景：调用少、位置固定且重视执行时间时适合宏；同一功能反复调用时适合子程序。

### 局部标号

* **宏内局部标号**

    * > **定义**：宏定义内部、每次展开后需要保持唯一的标号。

    * 同一宏展开多次时，普通标号会重复出现并触发“标号重复定义”错误。

    * 在宏定义内用 `LOCAL` 声明局部标号。

    * 每次展开时，汇编程序把局部标号自动改为不同的新标号，如 `??0000`、`??0001`、`??0002`。

    * 循环目的地的引用会随局部标号一起改写。

### 光标回车换行

* **`CRLF` 宏**

    * `CRLF` 由 ASCII 中的回车 `CR` 和换行 `LF` 两个名称组合而成，宏名直接表达功能。

    * 宏体通过 `INT 21H` 的 `02` 号功能向屏幕送字符。

    * 第一次令 `DL=0DH` 输出回车码，第二次令 `DL=0AH` 输出换行码。

## 汇编语言程序设计步骤

* **基本步骤**

    * 分析题目：明确输入、输出和要解决的问题，提出算法。

    * 绘制流程图：依据算法或编程思想组织控制流程，并使用规范符号。

    * 编写程序：依据算法、编程思想和流程图写出代码。

    * 上机调试：源程序扩展名使用 `.ASM`，经过汇编得到目标代码，再链接生成 `.EXE` 可执行文件，最后调试。

    * 编写设计说明书：记录程序名称、设计者、日期、算法说明、程序说明和执行说明。

## 逻辑段与源程序结构

### 段定义与当前段

* **逻辑段（logical segment）**

    * > **定义**：8086 源程序中按功能组织的信息单位，不同类型的信息分别放入代码段、数据段和堆栈段。

    * 用 `SEGMENT` 开始定义，用 `ENDS` 结束。

    * `ENDS` 左侧段名必须与 `SEGMENT` 左侧段名一致。

    * 段名具有伪指令属性、段属性和偏移地址属性；为相应段分配的段寄存器不等于该寄存器已被程序初始化。

* **段定义参数**

    * 第一个可选参数是定位类型，规定段起始地址的对齐边界。

    * 第二个可选参数是组合类型，规定多模块程序中同名逻辑段如何链接组合。

    * 第三个可选参数是类别，用单引号括起，说明该段所属信息类别。

    * 段名宜直接体现内容，如 `CODE`、`DATA`、`STACK`；不得与指令助记符、寄存器名等专用符号冲突。

* **当前段（current segment）**

    * > **定义**：某个段寄存器当前所指向的逻辑段。

    * 8086 有 `CS`、`DS`、`ES`、`SS` 四个段寄存器，因此完整程序中当前段最多有四个。

    * 一个段寄存器不指向某段，就不能直接用该寄存器访问该段中的数据。

    * 从一个数据段切换到另一个数据段，需要重新初始化 `DS`；转到另一个代码段执行，则需要使 `CS` 指向相应代码段。

### 定位类型

* **`PAGE`**

    * 段起始地址必须能被 256 整除。

    * 每页为 256 字节；相邻页型段之间最大可能浪费 256 字节。

* **`PARA`**

    * 段起始地址必须能被 16 整除，每节为 16 字节。

    * 省略定位类型时默认采用 `PARA`。

    * 相邻节型段之间最多可能浪费 16 字节；这是程序中最常用的定位方式。

* **`BYTE` 与 `WORD`**

    * `BYTE` 要求段起始地址能被 1 整除，任意地址都能作为起点。

    * `WORD` 要求段起始地址能被 2 整除。

    * 两种类型都不能保证段的起始偏移地址为零。

### 组合类型与类别

* **组合类型（combine type）**

    * 多模块程序各自汇编为 `.OBJ` 后，再由 `LINK` 链接成完整系统。

    * 组合类型规定不同模块中的同名逻辑段如何组合。

    * `STACK` 组合类型向链接程序表明该段是堆栈段。

    * `NONE` 表示本段与任何模块中的任何逻辑段都无关系；省略组合类型时默认按 `NONE` 处理。

* **类别（class）**

    * 类别必须用单引号括起，如 `'DATA'`。

    * 类别用于提示本段承载哪类信息；具体数据由 `DB`、`DW` 等定义语句及变量类型说明。

### `ASSUME` 与段寄存器初始化

* **`ASSUME`**

    * > **定义**：建立段名与段寄存器之间关系的汇编伪指令。

    * 格式为“段寄存器冒号段名”，多个关系用逗号分隔，例如 `ASSUME CS:CODE, DS:DATA, ES:DATA, SS:STK`。

    * `ES:DATA` 表示数据段与附加数据段指向同一个逻辑段。

    * 多行关系时，每一行都必须重新写 `ASSUME`。

    * `ASSUME` 只建立汇编期关系，不把段基址装入 `DS`、`ES` 或 `SS`。

* **段寄存器装载**

    * `CS` 是奇数，不能直接作为 `MOV` 指令目的操作数；`DS`、`ES` 等段寄存器装载通常先经通用寄存器中转。

    * 立即数送入段寄存器时，段名按立即寻址提供段基址值，如 `MOV AX,DATA` 后再 `MOV DS,AX`。

    * 只取段名对应的段基址时，应使用 `SEG` 表达式；不能把段名直接当偏移地址使用。

    * 用户程序负责初始化 `DS`、`ES`、`SS`、`SP`；`CS` 和 `IP` 由系统在程序装入时根据入口地址建立。

### 堆栈段

* **堆栈空间**

    * 堆栈段用 `DB`、`DW` 等定义语句预留空间，常用 `STACK` 组合类型。

    * 采用 `STACK` 组合类型时，系统在可执行文件装入内存过程中初始化 `SS` 和 `SP`，用户代码可不再显式装入。

    * 用户也可自行初始化；系统已经完成的初始化再执行一次不冲突。

    * 堆栈容量按实际调用需求确定，通常留出约 30% 富余量，以适应程序扩充并避免 `SP` 出界。

* **`TOP` 标号**

    * 256 字节堆栈区的末字节偏移为 `00FFH`，`TOP` 位于末字节加一的位置，偏移为 `0100H`。

    * `SP` 指向堆栈的下一个可用单元，而不是最后一个已占用单元。

    * `PUSH` 采用先减后存，`POP` 采用先取后加；`SP` 初始化到 `TOP` 后堆栈才可用。

### 完整源程序

* **标准结构**

    ```asm
    STK     SEGMENT STACK
            DB      256 DUP (?)
    TOP     LABEL WORD
    STK     ENDS

    DATA    SEGMENT
    VAR1    DB      10H
    VAR2    DW      1234H
    DATA    ENDS

    CODE    SEGMENT
            ASSUME  CS:CODE, DS:DATA, ES:DATA, SS:STK
    START:
            MOV     AX, DATA
            MOV     DS, AX
            MOV     BX, DATA
            MOV     ES, BX
            MOV     AX, STK
            MOV     SS, AX
            MOV     SP, TOP

            MOV     AH, 4CH
            INT     21H
    CODE    ENDS
            END     START
    ```

* **入口与启动**

    * `END` 告诉汇编程序总汇编结束，右侧必须给出入口地址表达式。

    * 系统装入程序时，把入口标号的段基址属性装入 `CS`，把偏移地址属性装入 `IP`。

    * `CS:IP` 因此从 `START` 开始取指执行。

    * 一个程序无论包含一个还是多个代码段，文件末尾都只使用一条 `END` 指令。

* **程序结束**

    * `MOV AH,4CH` 与 `INT 21H` 成对使用，把控制权交回 DOS。

    * `INT 21H` 是软件中断指令，`AH` 给出 DOS 功能号。

    * `AH=4CH` 结束用户程序并返回 DOS；`AH=02H` 向屏幕输出字符；`AH=01H` 从键盘读字符。

### `LABEL` 与 `PTR`

* **`LABEL`**

    * > **定义**：为符号赋予段基址、偏移地址和类型属性，但不占用对应存储单元。

    * `DW ?` 会占用两个字存储单元；`LABEL WORD` 只提供字型、段基址和偏移地址属性，不占空间。

    * 堆栈段中 `TOP LABEL WORD` 标出堆栈末字节加一的单元，不占用堆栈存储空间。

    * 同一地址可先定义字节型 `LABEL`，再定义字变量；两个符号指向同一单元，但类型不同。

    * 对同一单元作字节处理时，字节型 `LABEL` 符号长期有效。

* **`PTR`**

    * `BYTE PTR X_WORD` 在当前指令内把字变量的访问类型临时改为字节型，使指令两端的类型一致。

    * 离开该语句后，`X_WORD` 仍保持原来的字变量类型。

* **`LABEL` 与 `PTR`**

    | 比较项目 | `BYTE PTR X_WORD` | `LABEL BYTE` 定义的符号 |
    | :--- | :--- | :--- |
    | 生效范围 | 当前一条指令 | 该符号在所在段内持续有效 |
    | 类型处理 | 每次使用都写 `PTR` | 定义一次后直接使用 |
    | 额外存储 | 不占 | 不占 |

### 等值与定位伪指令

* **`EQU` 与等号**

    * > **定义**：均把右侧表达式的值赋给左侧符号常量，并在汇编阶段完成，不占运行空间。

    * 右侧表达式的值不能超过 65535。

    * `EQU` 定义的符号只能定义一次，再次定义同名符号会报错。

    * 等号定义的符号可以重新赋值；后续引用使用最新值，已生成语句按所在位置使用当时的值。

* **`ORG`**

    * > **定义**：把段内位置计数器定位到指定偏移地址的定位伪指令。

    * 奇数偏移地址上的字变量没有对准，不能用一条字传送指令一次完成读写。

    * `ORG 4` 表示把后续变量定位到偏移 `0004H`，不是空出 4 字节。

    * `ORG` 只控制段内偏移；段基址的对齐由 `SEGMENT` 定位类型控制。

## 分支与循环程序设计

### 条件与分支

* **分支条件（branch condition）**

    * > **定义**：运算结果落实到一个状态标志后，供条件转移指令测试的判定依据。

    * 分支设计先根据题目确定判断依据，再选择对应状态标志，最后选条件转移指令。

    * 常用条件产生方式：`CMP` 产生比较条件，`TEST` 产生位测试条件；允许破坏目的操作数时也可用 `AND`、`OR` 等逻辑运算。

    * 除 `AF` 外的五个状态标志 `ZF`、`SF`、`PF`、`OF`、`CF` 都可作为分支条件。

    * 相等判断围绕 `ZF`；正负与符号位有关；进位及无符号大小关系可能涉及 `CF`。

* **二分支与多分支**

    * 二分支在条件成立与不成立时分别执行不同处理。

    * 多分支串联多个“测试条件—进入处理”的判断，所有条件均不成立时进入公共出口。

    * 多个候选对象可用跳转表组织多分支，以提高执行效率。

* **转移范围与验证**

    * 短距离条件转移以当前 `IP` 为基准，范围约为 128 字节。

    * 目标过远时，可用无条件转移搭桥，再由远处条件转移返回目标位置。

    * 调试时必须分别使每个条件成立与不成立，验证所有分支都能到达正确结果。

### 有序数组合并

* **递增数组合并**

    * 源数组 `DATA1`、`DATA2` 各含递增排列的八位无符号数，数组前两个字节保存自身长度。

    * 目标数组 `BETA` 的前两个字节保存合并后的总长度，其后保存全部合并结果。

    * 比较指针必须从偏移 2 开始，跨过存放长度的头部字段。

    * 用输出指针和两个源指针分别跟踪 `BETA` 的下一空位及两侧尚未处理的元素。

    * 两侧都有元素时，比较当前值，把较小者直接写入 `BETA`，只推进被取走的一侧并减少该侧计数。

    * 任一侧计数为零时，把另一侧余项依次写入 `BETA`。

    * 传送指令可能自动推进地址；重新取数、比较和减计数前，地址与计数必须对应下一个未处理元素。

### 循环结构

* **循环程序（loop program）**

    * > **定义**：通过重复执行同一段工作、修改判断依据并控制返回或退出，完成多次处理任务的程序结构。

    * 循环次数已知时，可先做一轮工作再判断是否继续。

    * 结束条件无法预先确定，或初态可能已满足退出条件时，可先判断退出条件再做一轮工作。

* **二进制中 1 的统计**

    * 每轮将待统计值右移一位，移出位进入 `CF`。

    * `CF=1` 时累计值加一；待统计值变为零时结束。

    * 进入循环前先检查待统计值是否为零，可避免多执行一轮无意义的移位。

* **五个组成部分**

    | 组成 | 作用 | 典型内容 |
    | :--- | :--- | :--- |
    | 初始化 | 建立确定的循环起点 | 计数器、指针、地址与初值 |
    | 循环工作 | 完成一轮核心任务 | 传送、比较、移位、运算 |
    | 修改并测试条件 | 推进判断依据 | 修改计数、移位结果并检查状态标志 |
    | 循环控制 | 决定返回或退出 | 计数到零或满足终止条件 |
    | 结果处理 | 输出或保存最终结果 | 显示或送存，可省略 |

* **初始化与结果处理**

    * 初始化必须建立正确计数和指针；源数组合并时指针若未跨过长度字段，第一次比较就会取错对象。

    * 若结果需每轮显示，可直接放入循环工作，不必等全部循环结束后再处理。

### 冒泡排序

* **冒泡排序（bubble sort）**

    * > **定义**：反复比较相邻元素并在顺序不符时交换，使较大或较小元素逐轮移动到未排序区端部的排序方法。

    * $n$ 个数据第一趟进行 $n-1$ 次相邻比较，此后每趟减少一次，外层循环共 $n-1$ 趟。

    * 每一趟结束后，至少一个极值到达当前未排序范围的确定位置，下一趟继续缩小未排序区。

    * 两个内存单元不能直接交换，可由通用寄存器中转、使用 `XCHG`，或按“保存一个、读取另一个、写回”完成交换。

* **双层计数与提前结束**

    * 外层计数控制还需完成多少趟，内层计数控制当前一趟已完成多少次相邻比较。

    * 外层计数初值为 $n-1$；每趟开始时把外层当前计数复制给内层计数，使内层次数随外层推进逐趟减少。

    * 每趟开始时清零交换标志；一旦发生交换就把标志置为非零。

    * 一趟结束且交换标志仍为零，说明完整扫描未发现逆序，可以直接退出。

    * 交换标志必须每趟重新清零，不能只在程序开始时清零一次。

    * 地址指针在内层扫描中逐个指向相邻元素；比较结束后退回当前元素位置，为下一对相邻比较作准备。

* **8086 排序骨架**

    ```asm
    BUBBLE:
            MOV  CH, 4
    OUTER:
            MOV  CL, CH
            MOV  BL, 0
            MOV  SI, OFFSET BUFF1
    INNER:
            MOV  AL, [SI]
            INC  SI
            MOV  AH, [SI]
            CMP  AL, AH
            JAE  NO_SWAP
            XCHG AL, AH
            MOV  [SI-1], AH
            MOV  [SI], AL
            MOV  BL, 1
    NO_SWAP:
            DEC  SI
            LOOP INNER
            CMP  BL, 0
            JE   DONE
            DEC  CH
            JNZ  OUTER
    DONE:
            RET
    ```

    * 升序比较时，当前数大于后一个数才交换；当前数不小于后一个数时直接跳过交换。

    * 降序时只需改变不交换的条件，双层循环、逐趟缩小未排序区和交换标志结构保持不变。

## 总线与互连层次

### 总线功能

* **总线（bus）**

    * > **定义**：计算机系统中用来传输信息的通道；系统级传送包含地址信息、数据信息和控制信息三类基本信息。

    * CPU 引脚数量有限，地址、数据或控制信息可按时间复用同一引脚。

    * 总线形成电路在规定时序内把复用信息分离：地址进入地址通道，数据进入数据通道，控制信息进入控制通道。

* **系统级互连**

    * 存储器访问需要向存储器提供地址，并在读写时传送数据和相应控制信息。

    * 设计总线形成电路必须同时掌握各引脚功能及其时序关系：功能确定某时刻信号代表什么，时序确定信号何时有效、保持和改变。

### 按层次分类

* **片内总线**

    * 集成电路芯片内部各元件之间的连接线路。

    * 它的组织方式直接影响芯片性能，可编程器件设计中需要由设计者考虑。

* **元件间总线**

    * 又称板内总线，连接印刷电路板上的各元件。

    * 布局和走线会影响电路板性能；高频走线宜避免直角，可采用 $45$ 度或圆弧，特别高频部分还需考虑屏蔽。

* **系统总线**

    * 又称内部总线，连接主板与插入插槽的多块电路板。

    * 它把多个功能部件组织成协同工作的系统，本部分重点讨论系统级总线形成。

* **设备间总线**

    * 又称外部总线或设备间通信总线，连接计算机与打印机等外部设备。

    * 常见接口有 `COM1`、`COM2`、`USB` 等；无相应接口时需配置接口卡。

    * 系统总线和通信总线都必须遵守标准化互连规则，不能各自形成不兼容的连接体系。

## 总线接口芯片

### 缓冲与锁存

* **总线缓冲（bus buffer）**

    * CPU 引脚驱动能力有限；总线上负载较多时，信号需要经过缓冲器隔离不同支路并恢复驱动能力。

    * 双向数据通道常用 `74LS245`；其引脚按一侧输入、另一侧输出集中排列，比输入输出交叉排列的器件更便于 PCB 布线。

* **`74LS244` 单向缓冲器**

    * > **定义**：具有八位单向数据通道的缓冲器，由低电平有效的输出使能 `/1OE` 控制是否驱动数据总线。

    | `/1OE` | 输出状态 |
    | :--- | :--- |
    | 低电平 | 输出跟随输入 |
    | 高电平 | 输出为高阻态 |

    * 用于外设向 CPU 输入数据时，地址译码和读信号使缓冲器在读周期工作。

    * 非读周期必须输出高阻态，让出 CPU 数据总线，避免多个端口同时争用线路。

* **`74LS245` 双向缓冲器**

    * > **定义**：具有 A、B 两组八位数据端的双向缓冲器；`/OE` 决定是否工作，`DIR` 决定数据方向。

    | `/OE` | `DIR` | 数据方向 |
    | :--- | :---: | :--- |
    | 低电平 | 低电平 | B 端到 A 端 |
    | 低电平 | 高电平 | A 端到 B 端 |
    | 高电平 | 任意 | 两侧输出均为高阻态 |

    * `/OE` 为高时，总开关关闭，`DIR` 不起作用。

* **`74LS373` 锁存器**

    * > **定义**：把八位数据暂时保留下来的锁存器；数据输入为 $D_0\sim D_7$，输出为 $Q_0\sim Q_7$。

    * $\overline{OE}$ 为输出使能，有效时允许 $Q$ 输出，失效时输出进入高阻态。

    * 输出使能有效且 $\overline{LE}=1$ 时，$Q$ 逐位跟随 $D$。

    * $\overline{LE}$ 出现下降沿时，把 $D$ 装入 $Q$ 并保持，之后 $D$ 改变也不影响 $Q$。

    * `74LS573` 与 `74LS373` 功能相近，但把输入和输出分别集中到芯片两侧，布线更方便。

* **`74LS374` 锁存器**

    * 与 `74LS373` 都可锁存八位数据，区别是锁存使能端改为时钟端 $CP$。

    * $CP$ 为低电平时输出可接收新数据。

    * $CP$ 出现上升沿时，当前数据打入 $Q$ 并保持到下一次有效时钟沿。

* **器件识别**

    * 识读顺序是“功能—型号—封装”，先判断单向、双向或其他功能，再辨识系列、数字、后缀和封装。

    * `74` 系列通常为 $0$ 至 $+40\,^\circ\mathrm{C}$ 民用器件，`54` 系列为 $-40$ 至 $+70\,^\circ\mathrm{C}$ 军用器件。

    * TTL 速度相对较高但功耗较大；CMOS 功耗较小，选型须综合功能、速度、功耗、电压和环境温度。

### 数据通路控制

* **系统数据总线（system data bus）**

    * > **定义**：连接微处理器、存储器和 I/O 等部件、供它们交换数据的公共信息通道。

    * 8086 的低八位 `AD0~AD7` 和高八位 `AD8~AD15` 各经一片 `74LS245` 接入系统数据总线，共两片形成 16 位双向通道。

    * 外部双向缓冲器既隔离各支路，又恢复驱动能力，使总线能够带动后级负载。

    * 原理图用相同网络名表示电气连通；纸面距离不表示断开，模块边框也不构成电气连接。

* **数据缓冲控制**

    * 8086 的 `DEN#` 接 `74LS245` 的 `/OE`，`DEN#=0` 时打开数据通路，`DEN#=1` 时关闭。

    * 8086 的 `DT/R` 接 `74LS245` 的 `DIR`；发送时为 1、接收时为 0。

    | 状态 | `DEN#` | `DT/R` | 数据方向 |
    | :--- | :---: | :---: | :--- |
    | 不传送数据 | 1 | 不起作用 | 缓冲器关闭 |
    | CPU 向外写 | 0 | 1 | CPU 侧到系统总线侧 |
    | CPU 从外部读 | 0 | 0 | 系统总线侧到 CPU 侧 |

## 8086 引脚、时钟与复位

### 封装与供电

* **引脚与寻址空间**

    * 8086 采用 40 引脚双列直插封装，$V_{CC}$ 和 `GND` 为供电与地引脚。

    * 工作电压为 $+5\,\mathrm{V}$，允许范围为 $4.5\sim5.5\,\mathrm{V}$。

    * 20 根地址线全部用于外部存储器寻址，共有 $2^{20}=1\,\mathrm{MB}$ 个存储单元。

* **工作频率**

    * 8086 工作时钟最高为 5 MHz；8088 常用工作频率为 4.77 MHz。

    * 早期 PC 的 4.77 MHz 时钟可在串行通信累计误差最小的条件下工作。

### 复位与启动

* **`RESET` 复位**

    * > **定义**：使 8086 内部状态回到确定起点、结束后从规定地址开始取指的外部高电平有效信号。

    * 复位高电平宽度不得少于四个时钟周期，即至少 $4T_{CLK}$。

    * 8086 以 `CLK` 下降沿作为同步节拍，复位上升沿、下降沿及有效宽度要与时钟配合。

    * 复位后 `CS=FFFFH`、`IP=0000H`，逻辑地址为 `FFFFH:0000H`，物理地址为 `FFFF0H`。

    * `FFFF0H` 靠近 1 MB 空间高端，可容纳的正常程序空间很小，因此启动位置先放一条跳转指令，再转向空间宽裕的用户程序区。

* **上电与手动复位**

    * RC 延时网络利用电容两端电压不能突变的特性，在上电时形成持续高电平，时间常数为 $\tau=RC$。

    * 手动复位请求为低电平有效；8284 完成极性转换和时钟同步后，向 CPU 输出高电平有效且宽度合格的 `RESET`。

* **`8284` 时钟发生器**

    * `$X_1$`、`$X_2$` 可外接晶体，芯片内部构成振荡环路并经三分频输出 8086 时钟。

    * $$f_{CLK}=\frac{f_{\text{晶振}}}{3}$$

    * 8284 可接收低电平有效的外部复位请求，将其极性转换并同步成 8086 所需的高电平复位信号。

## 总线周期与工作方式

### 时钟节拍

* **时钟节拍（clock cycle）**

    * CPU 以时钟周期作为最小工作节拍；8086 以 `CLK` 下降沿作为同步节拍。

* **总线周期（bus cycle）**

    * > **定义**：CPU 为完成一次外部存储器或 I/O 读写而占用外部总线的时间；不访问外部存储器和 I/O 的指令不需要完整外部总线周期。

    * 一个基本总线周期由 $T_1$、$T_2$、$T_3$、$T_4$ 四个状态组成。

    * $T_1$ 输出访问地址；$T_2$ 起地址线让位并进入数据准备；$T_3$ 附近完成数据交换；$T_4$ 结束周期。

    * 慢速设备来不及响应时，在 $T_3$ 与 $T_4$ 之间插入一个或多个等待状态 $T_W$。

### `READY` 与等待状态

* **`READY` 信号**

    * > **定义**：外部存储器、I/O 电路或设备向 CPU 表示准备状态的输入信号。

    * 若在 $T_3$ 时钟下降沿检测到 `READY=0`，CPU 不进入 $T_4$，而插入 $T_W$。

    * 每个 $T_W$ 的时钟下降沿再次检查 `READY`；仍为 0 就继续等待，读到 1 才进入 $T_4$。

    * $T_W$ 数量由设备速度决定，不是固定写死的状态数。

* **`RDY` 与 8284A**

    * 设备侧准备信号为 `RDY`，先送入 8284A；8284A 将其同步到时钟下降沿，再以 `READY` 送往 8086。

    * `/TEST` 输入用于外部等待，每隔五个时钟周期检查一次；高电平继续等待，低电平结束等待。

### 最小方式与最大方式

* **`MN/MX#`**

    * 高电平选择最小方式，低电平选择最大方式。

    * 方式名称指系统组织形式，不表示 CPU 运算能力发生改变。

* **最小方式（minimum mode）**

    * > **定义**：8086 直接产生存储器和 I/O 读写控制信号的系统组织方式，适合单处理器系统。

    * `HOLD` 是高电平有效的总线申请输入；现行指令执行完后，CPU 输出高电平 `HLDA#` 表示允许接管。

    * CPU 让出总线时，具有三态功能的输出引脚全部进入高阻态。

    * 外部主控设备用完后将 `HOLD` 拉低；CPU 延迟 1～2 个时钟周期，将 `HLDA#` 拉低并收回总线。

* **最大方式（maximum mode）**

    * > **定义**：8086 输出总线状态编码、由 8288 生成最终控制信号的系统组织方式，适合多处理器系统。

    * 8086 输出状态信号 $S_2$、$S_1$、$S_0$，8288 接收后译码产生最终读写控制信号。

    | 操作 | 状态编码 | 8288 输出 | 含义 |
    | :--- | :---: | :--- | :--- |
    | 存储器读 | `101` | `MRDC#` | 存储器向 CPU 送数据 |
    | 存储器写 | `110` | `MWTC#` | 存储器接收 CPU 数据 |
    | I/O 读 | `001` | `IORC#` | I/O 端口向 CPU 送数据 |
    | I/O 写 | 由状态编码识别 | `IOWC#` | I/O 端口接收 CPU 数据 |

    * `S2`、`S1`、`S0` 是总线状态，不是地址或数据。

    * 24、25 号引脚为 `QS1`、`QS0`，表示指令队列取指状态；系统总线设计中可不接。

    * 29 号引脚为 `LOCK#` 输出；关键指令加 `LOCK` 前缀后，CPU 在执行期间输出低电平，表示总线封锁。

* **多处理器总线仲裁**

    * 外部处理器必须先提出总线请求；8086 完成当前操作后响应并把总线输出置为高阻态，外部设备才可接管。

    * 最大方式的 `RQ#/GT0#`、`RQ#/GT1#` 由同一组双向引脚完成请求与允许握手。

    * 主控设备先送负脉冲申请；CPU 现行指令完成后，在同一引脚输出负脉冲允许；接管结束后由主控设备再送负脉冲归还。

    * 同时申请时，31 脚 `RQ#/GT0#` 所接主控设备的优先权高于 30 脚 `RQ#/GT1#` 所接设备。

## 复用引脚与总线形成

### 地址与状态复用

* **`AD0~AD15`**

    * 16 根地址、数据复用引脚在 $T_1$ 输出 $A_0\sim A_{15}$，在 $T_2\sim T_4$ 传输 $D_0\sim D_{15}$。

    * 传送 8 位数据时，偶地址和奇地址对应的高、低字节通路不同，不能任意固定使用某一组 8 位线。

* **`A16/S3~A19/S6`**

    * 4 根高地址、状态复用引脚在 $T_1$ 输出 $A_{16}\sim A_{19}$，在 $T_2\sim T_4$ 输出 $S_3\sim S_6$。

    * $S_6$ 始终为低电平；$S_5$ 辅助反映 CPU 内部 `IF` 状态；$S_4$、$S_3$ 的组合反映当前使用的段寄存器和段。

* **地址锁存允许 `ALE`**

    * `ALE` 平时为低电平，在 $T_1$ 变高，并在 $T_1$ 结束时出现下降沿。

    * 外部电路利用 `ALE` 下降沿把 $T_1$ 期间的地址锁存下来，使 CPU 转入数据阶段后仍保留稳定地址。

    * 20 位地址需要三片八位锁存器：分别锁存 `AD0~AD7`、`AD8~AD15`、`A16/S3~A19/S6`。

    * 锁存器输出合起来形成系统地址总线 $A_0\sim A_{19}$。

    ```text
    AD0..AD7       ──> 74LS373 #1 ──> A0..A7
    AD8..AD15      ──> 74LS373 #2 ──> A8..A15
    A16/S3..A19/S6 ──> 74LS373 #3 ──> A16..A19
                              │
                             ALE
    ```

### 数据方向与读写控制

* **`DT/R`**

    * CPU 向外发送数据时为高电平，CPU 从外部接收数据时为低电平。

    * 其有效电平必须由当前指令的读写方向判断，不能根据上一条指令猜测。

* **`DEN#`**

    * 数据有效信号，低电平有效。

    * 它把 $T_2$ 中的地址转数据过渡阶段与真正稳定的数据阶段区分开；外部电路只在 `DEN#` 有效时读取或送出数据。

* **`M/IO#`**

    * 高电平表示访问存储器，低电平表示访问 I/O 端口。

    * `M/IO#` 判访问对象，`DT/R` 判数据方向，`DEN#` 判数据何时有效，三者不能混用。

* **读写时序**

    * 写操作先确定目标地址并准备数据，再在数据有效条件建立后给出写控制。

    * 读操作先安排读控制，外部设备把数据送入复用线；CPU 在 `DEN#` 有效且数据稳定后采样。

* **两种方式的控制来源**

    * 最小方式下，地址锁存允许由 CPU 的 `ALE` 直接控制；245 的方向和输出允许由 CPU 的 `DT/R`、`DEN#` 直接控制。

    * 最大方式下，373 的锁存允许以及 245 的方向、输出允许均由 8288 产生相应控制。

    * 8288 的 `DEN` 与最小方式 CPU 的 `DEN#` 极性相反，接到 245 的 `/OE` 前需反相。

### 中断与总线握手

* **`INTR` 与 `INTA#`**

    * `INTR` 是高电平有效的外部可屏蔽中断请求输入；仅当 `IF=1` 时，8086 才响应。

    * `INTA#` 是低电平有效的中断响应输出。

    * 8086 必须执行完当前指令后才响应，随后在两个总线周期内发出 `INTA#`。

    * 8259 在第二个响应周期的数据阶段通过 $D_7\sim D_0$ 送出中断类型号；向量地址为类型号乘以 4。

    * 响应完成后应撤销请求，避免服务程序中再次出现同级的非预期中断。

* **`HOLD` 与 `HLDA#`**

    * `HOLD` 为输入，`HLDA#` 为输出，构成总线申请与允许的握手。

    * `HOLD` 高电平有效，CPU 完成现行指令后输出 `HLDA#=1`；主控设备使用完毕拉低 `HOLD`，CPU 延迟 1～2 个时钟周期后收回总线。

* **三类系统总线**

    | 总线 | 8086 最小方式形成方式 |
    | :--- | :--- |
    | 地址总线 | $A_0\sim A_{19}$，20 根，经 3 片 373 形成 |
    | 数据总线 | $D_0\sim D_{15}$，16 根，经 2 片 245 形成 |
    | 控制总线 | `RD#`、`WR#`、`M/IO#`、`BHE#`、`INTA#`、`INTR`、`HOLD`、`HLDA#`、`CLK`、`RESET` 等由 CPU 直接产生 |

## 奇偶存储体与高字节传送

### `BHE#` 与存储体

* **高字节允许 `BHE#`**

    * > **定义**：低电平有效、允许当前传送使用高字节数据通路的信号；与地址共同决定访问哪个存储体。

    * `BHE#/S7` 在 $T_1$ 输出 `BHE#`，$T_2\sim T_4$ 改为状态输出 $S_7$。

    * 高字节允许只在 $T_1$ 给出，必须与地址一起用 `ALE` 锁存，才能在整个传送周期内参与外部译码。

* **奇偶存储体**

    * 外部存储器按偶地址和奇地址拆成两个存储体。

    * 偶地址存储体接 $D_0\sim D_7$，保存字的低字节；奇地址存储体接 $D_8\sim D_{15}$，保存字的高字节。

    * 两个存储体共用高位地址和片选译码，低位地址与 `BHE#` 决定当前通路。

* **字节访问**

    | 访问对象 | `A0` | `BHE#` | 选中存储体 | 数据通路 | 周期数 |
    | :--- | :---: | :---: | :--- | :--- | :---: |
    | 偶地址字节 | 0 | 1 | 偶地址存储体 | $D_0\sim D_7$ | 1 |
    | 奇地址字节 | 1 | 0 | 奇地址存储体 | $D_8\sim D_{15}$ | 1 |

    * 偶地址字节由 $A_0=0$ 选通低字节通路。

    * 奇地址字节由 $A_0=1$ 指示奇地址，再由 `BHE#=0` 选通高字节通路。

* **对准字访问**

    * 对准字从偶地址开始，两个存储体可在同一周期同时有效。

    * $A_0=0$ 选通偶地址体传低字节，`BHE#=0` 选通奇地址体传高字节。

    * 例如字从 `2000H` 开始时，`AL` 位于 `2000H` 走 $D_0\sim D_7$，`AH` 位于 `2001H` 走 $D_8\sim D_{15}$，一个周期完成整个字传送。

* **未对准字访问**

    * 奇地址起始的字先访问奇地址传高字节，再访问下一个偶地址传低字节，需要两个总线周期。

    | 周期 | `A0` | `BHE#` | 数据通路 | 传送内容 |
    | :---: | :---: | :---: | :--- | :--- |
    | 1 | 1 | 0 | $D_8\sim D_{15}$ | 高字节 |
    | 2 | 0 | 1 | $D_0\sim D_7$ | 下一个偶地址的低字节 |

## 8086 与 8088

* **外部数据通路**

    * 8086 外部有 16 根数据线，8088 只有 $D_0\sim D_7$ 八根；8088 原高八位数据引脚转作地址使用。

    * 8088 内部仍为 16 位 CPU，外部数据通路缩小不改变内部 16 位运算性质。

* **指令队列与状态信号**

    * 8086 指令队列为 6 字节，8088 为 4 字节。

    * 8086 使用 `M/IO`，高电平为存储器、低电平为 I/O；8088 使用 `IO/M`，高电平为 I/O、低电平为存储器。

* **16 位字操作**

    * 8086 对准字操作用一个总线周期，未对准字操作用两个。

    * 8088 每次只有八位外部数据通路可用，16 位字无论地址是否对准都需要两个周期。

* **高字节机制**

    * 8086 使用 `A0` 与 `BHE#` 选择两个存储体；8088 没有 8086 式高字节并行选择机制。

    * 设计接口时必须先确认系统 CPU 是 8086 还是 8088；一个 8 位 I/O 端口只占一个地址，不能把任意两个相邻地址直接视为一个 16 位端口。

---

## 系统总线扩充设计

### 题目已知条件

* **设计起点**

    * 存储器、I/O 与后续接口设计通常在已经形成的系统总线上扩充，不要求重画整条系统总线。

    * 读题先确认 CPU 是 8086 还是 8088、工作方式是最小还是最大，再决定信号名、极性、地址根数和数据根数。

* **地址与数据线**

    * 8086 存储器电路使用 20 根地址线 $A_0\sim A_{19}$。

    * I/O 电路只使用 16 根地址线 $A_0\sim A_{15}$；$A_{16}\sim A_{19}$ 为存储器扩展专用。

    * 数据通路按 16 根 $D_0\sim D_{15}$ 考虑：偶地址端口接低八位，奇地址端口接高八位。

* **控制信号**

    * 存储器操作以 `M/IO#=1` 配合 `RD#` 或 `WR#` 判定。

    * I/O 操作以 `M/IO#=0` 配合 `RD#` 或 `WR#` 判定。

    * 涉及高字节通路时必须使用 `BHE#`。

    * 使用中断时还需接入 `INTR` 和 `INTA#`。

    * 若 CPU 为 8088，地址线仍为 20 根，但数据线只有八根，状态信号相应改为 `IO/M`。
