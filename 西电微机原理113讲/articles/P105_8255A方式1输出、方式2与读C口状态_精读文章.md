# 8255A方式1输出、方式2与读C口状态

上节课留了个尾巴：`INTE_A`怎么置`1`。和`B`口一样，也是借`PC`位置`1`达到的，但`A`口`B`口不一样，得看表。书上`302`页表`10.2`：`A`口工作在方式`1`输入时，初始化完紧跟着对`PC4`按位管理置`1`，`INTEA`就置`1`了；`A`口工作在方式`1`输出时，初始化后对`PC6`按位管理置`1`，`INTEA`才置`1`。而`B`口不管输入还是输出，都是对`PC2`置`1`。这个表要会查。

`8255`方式`1`做输入，既可查询也可中断，都可以。下面看`A`口`B`口工作在方式`1`输出的情况，以`PA`口为例。

## 方式1输出：OBF与ACK的一问一答

`PA0`到`PA7`做输出，接的是智能输出设备，`CPU`一方经数据线连过来。做输出，我们盯的是写控制信号。`PA`口初始化成方式`1`输出后，`8255`向设备发的通知信号`OBFA非`变高，表示输出缓冲器是空的。`CPU`朝`PA`口`OUT`写了输出数据，缓冲器满了，`OBF非`变低。高是空、低是满，别记反。

输出缓冲器满、低电平，设备还不知道数据有效了，`8255`就用`OBFA非`低电平通知设备：这个低电平可以直接做设备的`STB非`数据选通信号。在它作用下，有效数据被选通进设备的输入缓冲器，设备收到了，就给`8255`回一个回答信号`ACKA非`（负脉冲）。回答信号一到，`8255`使`OBFA非`变高，高电平又通知设备：输出缓冲器空了，线上数据无效了。

```text
CPU --OUT写--> [PA口输出缓冲器] --D0~D7--> 设备输入缓冲器
8255 --OBF非(低=满/高=空)--> 设备: 数据有效, 来取 (兼做设备STB非)
设备 --ACK非(负脉冲)--> 8255: 收到了 --> OBF非回高(空)
```

读图说明：`OBF非`是`8255`发出的满空状态，`ACK非`是设备回的收到确认，一去一回正好一对联络信号。

用户用查询法，什么时候给方式`1`输出的`PA`口送数据？该查`OBF非`，不该查`ACK`。`OBF非`等于`1`，缓冲器是空的，就可以输出了。

`PA`口方式`1`输出，`A`组中`PC`高四位哪两根充当这一对联络线？书上`301`页：`PC7`和`PC6`。`PC3`还可以做`INTRA`中断请求输出。要能向`8259`发中断，`PA`口必须中断允许：在方式`1`输出初始化完成后，紧跟着对`PC6`位按位管理置`1`，`INTEA`置`1`。一旦允许，内部`INTE = 1`，当`OBF = 1`（缓冲器空）时输出由低变高，`INTRA`由低变高，向`8259`请求中断。记住对照：`PA`方式`1`输入借`PC4`置`INTEA`，方式`1`输出借`PC6`置`INTEA`。

`PA`口方式`1`输出时，`A`组`PC5`、`PC4`没当联络线，还可以做方式`0`的基本输出输入`I/O`线用，做输出还是输入要初始化。`PB`口方式`1`输出我就不讲了，自己看。

## 方式2：方式1输入输出的综合

第三种工作方式方式`2`，双向传输，只有`PA`口有。`PA`口工作在方式`2`中断时，中断请求线用了`PC3`，所以`PB`口再不能做方式`2`，联络线不够用，前面说过。

`PA`口方式`2`实质是方式`1`输入和输出的综合：输出时查`PC7`的`OBFA非`，输入时查`IBFA`。中断时`INTEA`置`1`，能向`8259`发`INTRA`。书上`303`页图`10.9`：方式`2`中断的`INTRA`输出是个或门，输入时的中断条件和输出时的中断条件，任一个发生都能提中断请求。

`PA`口方式`2`时，`PC`口还剩`PC0`、`PC1`、`PC2`三根没用，还可以做基本`I/O`线用。到这里`8255`的工作方式讲完。

## 读端口C：联络状态一次读回

第四个知识点：读端口`C`状态。`PA`口工作在方式`1`或方式`2`、`PB`口工作在方式`1`时，编程序期间读`C`端口，读回来的是状态。书上`304`页图`10.11`，第一行（`A`口`B`口都方式`1`输入）：`D7`、`D6`没用，是`I/O`线；`D5`读回来是`A`口`IBFA`状态；`D4`是`A`口`INTEA`状态；`D3`是`A`口`INTRA`状态；`D2`是`B`口`INTEB`状态；`D1`是`B`口`IBFB`状态；`D0`是`B`口`INTRB`状态。`C`口`8`位在`A`口`B`口工作在方式`1`或方式`2`时，反映不同状态，一看就懂。

## 8255A与系统总线的接口方法

`10.4`节，本章第五个知识点：`8255A`与系统总线的接口，也就是连接。这门课用到的系统总线有五种：`8088`最小、`8088`最大、`8086`最小、`8086`最大、`PC`总线。书上在各种系统下配`8255A`画了很多例子，我画一个跟着看。

和设备相连的是`PA`、`PB`、`PC`口，做输出输入要初始化。和`CPU`（系统总线）一方相连的是`D0`到`D7`。系统总线是`8088`最小或最大、或者`PC-XT`总线，数据线只有`8`根，`8255`的`D0`到`D7`和系统`D0`到`D7`对连。

`RESET`和系统总线提供的`RESET`相连；总线没提供就自己用`RC`电路做上电`RESET`，复位后才能工作。`RD非`、`WR非`：`8088`或`8086`最大方式、或`PC-XT`总线，`RD非`接`IOR非`、`WR非`接`IOW非`；`8088`或`8086`最小方式，`RD非`接`RD非`、`WR非`接`WR非`。

`8086`系统不管最小最大，`D0`到`D7`和数据总线相连时：分配四个连续偶地址连低`8`位，四个连续奇地址连高`8`位。`A1`、`A0`片内寻址加`CS非`片选：`8088`或`PC-XT`系统地址连续，`A1`接`A1`、`A0`接`A0`，`A2`到`A15`（`PC`系统`A2`到`A9`）参加译码做片选；`8086`系统`A1`接`A2`、`A0`接`A1`，片选译码中四个连续偶地址要`A0 = 0`参加译码，四个连续奇地址要`BHE非 = 0`参加译码。`8086`系统`A1`接`A2`、`A0`接`A1`，这一条特别要注意。
