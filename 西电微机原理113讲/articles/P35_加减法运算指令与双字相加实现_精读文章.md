# 加减法运算指令与双字相加实现

我前面把传送类讲完了，今天看`3.5`节算术运算类。既然算术，肯定有加法减法乘法除法，还有`BCD`码调整。先学加法和减法。

## 运算类指令的两条总规则

学这类先抓两点。第一，只要`CPU`执行了运算类某条指令，结果就要影响六个状态标志或其中某些。第二，所有段寄存器不能参加运算。这两点不光算术，下一节逻辑也一样。

## 三条加法指令的分工

算术第一种加法，一共三条。

第一条不带进位加`ADD`，双操作数：

```assembly
ADD DST, SRC
```

功能是目的指明的内容加源指明的内容，源也可以是立即数，和送回目的，源不变：

$$(DST) + (SRC) \to DST$$

`CPU`按和设置六个状态标志`ZF`、`PF`、`SF`、`CF`、`OF`、`AF`。

第二条带进位加`ADC`，也是双操作数：

```assembly
ADC DST, SRC
```

把目的、源、`CF`三者相加送目的，源不变：

$$(DST) + (SRC) + CF \to DST$$

同样按结果设置全部六个标志。

第三条加`1`也叫增量`INC`，单操作数：

```assembly
INC DST
```

把目的指明的内容加`1`送回目的：

$$(DST) + 1 \to DST$$

既然是目的，显然不能是立即数。`CPU`按结果设置除`CF`外五个标志，对`CF`无影响。无影响就是执行前`CF`什么状态，执行后还什么状态。

## 双字相加为什么从低字加起

教材`46`页例`3.2`是结合加法的编程实例。`DVAR`开始连续`8`字节放两个`32`位数`A`和`B`，每个占双字，编程序算`C=A+B`。

分析一下。`DVAR`开始前`4`字节放`A`，后`4`字节放`B`。数据段用`DB`定义，若`A=00127654H`，按低字节放低地址依次是`54H`、`76H`、`12H`、`00H`；若`B=00049821H`，依次是`21H`、`98H`、`04H`、`00H`。

低地址放的是加数低位，多字节相加必须从低位加起。代码段编程，用哪种存储器寻址找到这些单元取数都行。书上又定义了：

```assembly
DVARC DD 1 DUP(?)
```

放结果，至少四个单元，高位进位还要不要单元另说，这个题一看就没进位。我把变量用分配示意图画出来了，代码段编片段，完整程序的段定义、初始化还没讲，现在只编段内片段，听懂了没有。

先取低字加低字：

```assembly
LEA SI, DVAR
MOV AX, [SI]
ADD AX, [SI+4]
```

`LEA`取`DVAR`偏移给`SI`，`[SI]`间接把一个字给`AX`，`[SI+4]`相对找到另一个加数低字，`ADD`相加和在`AX`。然后存低字结果：

```assembly
MOV WORD PTR DVARC, AX
```

直接写`MOV DVARC, AX`行吗。不行。`DVARC`是`DD`双字变量，`AX`是字类型，直接寻址必须加`WORD PTR`说明，中间有个空格，看到了没有。

再做高字，要考虑进位。`SI`增`2`也行，不增用相对也行：

```assembly
MOV AX, [SI+2]
ADC AX, [SI+6]
MOV WORD PTR DVARC+2, AX
```

`[SI+2]`把第一个加数高字给`AX`，`ADC`加`[SI+6]`那个字，和在`AX`，写到`WORD PTR DVARC+2`。编到这题目功能就完成了。

## 三条减法指令的对应关系

再看算术第二类减法，一共五条，加法三条减法五条。先看和加法对应的。

第一条不带借位减`SUB`，双操作数：

```assembly
SUB DST, SRC
```

目的减源，差送回目的，源不变，按差设置六个标志。和不带进位加对应。

第二条带借位减`SBB`：

```assembly
SBB DST, SRC
```

目的减源再减借位`CF`，`CF`要么`0`要么`1`，差送回目的，源不变，按差设置六个标志。操作类型由操作数类型定，一方明确双方明确，以前讲过。

第三条减`1`指令`DEC`：

```assembly
DEC DST
```

把目的指明的内容减`1`送回目的，可以寄存器寻址可以存储器寻址。按差设置除`CF`外五个标志，对`CF`没影响，和`INC`一样。

## AL等于FF时INC后CF是多少

有一年考试出过：若`AL=FFH`全`1`，当前`CF=0`，`8086`执行`INC AL`后，`AL`等于多少，`CF`等于多少。填空题。

用打草稿吗。`AL`全`1`加`1`等于多少。肯定`0`，只能放`8`位，一考就错。有进位，肯定有进位，但`INC`不影响`CF`，所以`CF`依然`0`。明白了吗。凡是打草稿的肯定出错，记住这一条就够了。
