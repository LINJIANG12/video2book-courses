# 译码电路设计：32K地址怎么切成四块，片选从哪来

上讲四个`6264`往板子上一摆，地址线对连、数据线对连都好办，`WE`非对连起来接存储器写`MEMW`非也不难，真正的难点在哪？在译码电路：四个`CS1`非片选从哪来？这一讲就把`32K`地址切开看，再把译码的两条规矩和五种电路形式一次讲透。

## 四个片选引出来：差的只是谁来产生它们

四个器件的`CS1`非端各引一根线，四个片选的样子就出来了。可这四根线悬着不行，得有人产生。每个器件占`8K`，它那`8K`的高位地址不变，拿不变的高位地址去设计译码电路，四个片选就是片外选择的结果。

先把`32K`地址剖开。`8088`最大方式系统，`A0～A12`从全`0`变到全`1`是`8K`，这是片内；高位不到`A13`的那`8K`在哪，由高位定。`A14、A13`这两位：`00`选一个`8K`，`01`又一个`8K`，`10`接着一个，`11`再一个，一共四个`8K`，地址还连续。

> **定义**：`A14、A13`这两位叫模块选择。`CPU`这次读写落在`32K`里的哪个`8K`模块，由它俩定；低位找片内单元，高位`A19～A15`不变，参加译码做器件片选，再和`A14、A13`二次译码做模块选择。

```text
A19 ～ A15   A14 A13   A12 ～ A0
 高位不变      模块选择    片内 8K
 (参加译码)   00/01/10/11  (全0→全1)
     │            │             │
     └─→ 译码出片选 ─→ 二次译码 ─→ 选中 4 个 8K 中的一块
```

读图说明：低`13`位找单元，中`2`位选模块，高`5`位定这`32K`在`1M`中的位置。

这就是书上`198`页`6.4.2`字节扩展的概念。书上拿两片`6116`讲例子：一片`6116`是`2K×8`，系统要`4KB`，两片一串；我们这个例子是系统要`32KB`，一片`6264`是`8K×8`，四片一串。道理同一条。

## 译码设计两条规矩：高位地址译码，控制信号别落下

`6264`掌握到这个层次，扩展电路肯定会画了（`8088`系统先练熟），现在关键就是译码电路设计，规矩两条：

1. 对高位不变的地址进行译码；
2. 控制信号也要参加译码，千万别忘了。

第二条最容易丢。举个例子：拿一个与门，输入是`MEMR`非和`MEMW`非，“与”出来等于`0`才参加译码。为什么？只有它俩“与”出`0`，才表明`CPU`真在对存储器读或写；`CPU`没操作存储器时它俩都是`1`，`1·1=1`，译码就把存储器关掉、输出无效。而且读写不可能同时为`0`，这个思想要看出来。

`8088`最小方式下还有一个：`IO/M`非`=0`必须参加译码。只有它为低，才表明`CPU`操作的是存储器而不是`I/O`。

> **易错点**：只译地址不译控制，`CPU`访问`I/O`时存储器会跟着乱动。地址定位置，控制定“这次是不是找存储器”，缺一不可。

## 译码电路五种形式：门、专用译码器、比较器、FPGA、EPROM

译码电路拿什么搭？形式多得很，工程上比的是性价比。

门电路最直接：与门、或门、与非门、异或门都能堆。专用译码器是数电老熟人：`3-8`线`74LS138`常用，还有双`2-4`译码器`74LS155`，再往上有`4-16`线译码器，查手册去。

比较器也行，我举个例子。`A15、A14`为`01`时选中某模块，就买个比较器：`B2`接`+5V`是`1`，`B1`接地是`0`，等于把`01`接死了；另一边输`A15、A14`进来比较，吻合时输出有效，这不就是译码？完全可以。

`FPGA`这类可编程器件当然行，但为译码那点功能上一片`FPGA`，大材小用了。

`EPROM`做译码最有味道：`A15、A14`为`01`选中某模块，我就在`EPROM`的`01`单元第`0`位（`D0`）事先写个`0`，把`D0`拉出来做片选。高位不变地址做`EPROM`的单元地址，当地址正好落在要选中的范围，单元被选中，读出第`0`位是`0`，片选有效。理解了没有？

> **提示**：形式不重要，思想就一句：高位不变地址进来，特定组合出去一根有效线。选哪种，看性价比估测。

## 第二种器件2114：1K×4，18脚，读写一根线

`6264`讲完看第二种静态`RAM`，现在基本不用了，了解即可：`Intel 2114`，片容量`1K×4`。组系统先位扩展成字节，这是上节课的概念。

引脚自己推：`18`脚双列直插，去掉电源地剩`16`脚。`1K`要`10`根地址线`A0～A9`，`4`位数据`D0～D3`（手册里也标`I/O1～I/O4`），`10+4=14`，剩下的是控制：图`6.3`，第`8`脚片选`CS`非，第`10`脚写控制`WE`非。`14+2`再加电源地，正好`18`根。

读写控制只有一根线：`CS`非`=0`选中，数据脚导通连总线；`CS`非`=1`未选中，高阻。选中前提下，`WE`非加低电平是写，四路数据写进该地址单元；`WE`非加高电平是读，允许输出。不读不写，片选必须无效。

| 条件 | 操作 |
| :--- | :--- |
| `CS`非`=0`，`WE`非`=0` | 写 |
| `CS`非`=0`，`WE`非`=1` | 读 |
| `CS`非`=1` | 未选中，高阻，不读不写 |

算个例子：`8088`系统扩`4KB`静态`RAM`，用`2114`要几片？`8`片。先两片一并做`1K×8`模块（位扩展），再`4`个模块一串做`4K`（字扩展），后面的画法和`6264`的`32K`是一套路子。

$$2 \times 4 = 8\text{片}$$
