# 带符号乘除法与商余数规则

我上次把无符号乘法标志讲了，今天把带符号乘和除法一次讲完。乘除用的少，但必须要掌握。

## 带符号乘法的高位是符号扩展

字节乘，被乘数隐含`AL`，乘数由源寻址指明但不能是立即数，乘出`16`位积高`8`位`AH`低`8`位`AL`。后边就不一样了，带符号乘执行后也只影响`CF`和`OF`。

如果`CF`和`OF`同时`0`，说明`AH`无效。对无符号乘，`CF`=`OF`=`0`说明`AH=0`。但带符号乘`CF`=`OF`=`0`说明`AH`是`AL`有效积的符号扩展。有效积在`AL`，`AL`最高位是符号位，`AH`就是它扩展：`AL`最高`0`积为正`AH`扩展八个`0`即`00H`，`AL`最高`1`积为负`AH`扩展八个`1`即`FFH`。

就像以前讲的，`-1`补码按`8`位是`FFH`，按`16`位是`FFFFH`，高`8`位就是符号扩展，不扩展值就变了。

字乘被乘数隐含`AX`，源指明`16`位乘数，乘出`32`位高`16`位`DX`低`16`位`AX`。带符号字乘`CF`=`OF`=`0`说明`DX`无效，此时`DX`就是`AX`符号扩展。反之字节`AH`或字`DX`有有效积，两标志自动置`1`，高位不能丢。

## 除法指令的两种类型

实际编程乘除比加减少得多，但必须掌握。算术第四种除法，分无符号和带符号：

```assembly
DIV SRC
IDIV SRC
```

必须是源操作数，源不能是立即数，和乘法同规范。操作类型全看源类型：源给字节就字节除，源给字就字除。

## 字节除与字除的隐含寄存器

以无符号为例。字节除被除数隐含目的里，必须`16`位隐含`AX`，除数是源给的`8`位数，`16`位除`8`位。结果商自动`AL`，余数自动`AH`。

字除被除数隐含`32`位，高`16`位`DX`低`16`位`AX`组成`DX:AX`，除数是源指明的`16`位数，`32`位除`16`位。结果商自动`AX`，余数自动`DX`。

```text
字节除:  AX(16被除数) / SRC8  -> AL商, AH余数
字除  :  DX:AX(32被除数) / SRC16 -> AX商, DX余数
```

读图说明：被除数、商、余数位置全隐含，指令里只写除数。

## 商余符号与标志无定义

带符号除商余位置和无符号同，但符号守两条：商同号正异号负，余数始终和被除数同号。被除数正除数正商正余正，被除数正除数负商负余正，被除数负除数正商负余负，被除数负除数负商正余负。

> **结论**：无论带符号还是无符号除法，执行后对`CF`、`ZF`、`SF`、`OF`、`PF`、`AF`六个标志均无定义，执行完去测标志没意义。

应用例如把`8001H`单元字节无符号数做除法，步骤就是按字节除把被除数先放`AX`，除数寻址给出，再`DIV`，商余按上面位置取，具体数字按题面代入就行。
