## 语句种类与宏调用特点

第三章开头讲过语句种类：指令语句 `MOV`、`TEST`，伪指令 `DB`、`DW`、`DD`、`SEGMENT`、`ENDS`、`PROC`、`ENDP`，还有宏指令语句。宏不是 8086 固有的，是你们用宏定义自己研制的新指令。

研制出来后面就能引用。引用直接写宏名，写到那就等效调用，不像子程序得专门 `CALL` 才调。但要引用必须先定义，而且定义必须在整个源程序最开头脑头。现在程序开头是 `STACK SEGMENT`，开头上面先定宏，后面代码段才能引。宏必须定在整个程序前方。

## 宏定义格式规则

宏定义靠宏定义伪指令 `MACRO`：

```assembly
宏名 MACRO [形参1, 形参2, ...]
     ; 宏体
     ENDM
```

宏名在 `MACRO` 左边空格定界，规则跟变量、标号、段名、子程序名一样，首字符必须是字母，起得有意义。回车换行锁光标叫 `CRLF`，一看就知道回车换行；屏幕显示串叫 `DISPLAY`，一看就明白。

`MACRO` 后边可给形参，多项逗号隔开。中括号表示可选，看功能要不要，不要可没有。

`MACRO` 下面用指令语句编一段完成特定功能的程序，叫宏体。结束写 `ENDM`。注意：段结束 `ENDS` 左边写段名，子程序结束 `ENDP` 左边写子程序名，宏结束 `ENDM` 左边什么都不写。

```text
源程序最开头
  宏定义 (宏名 MACRO ... ENDM)
  STACK SEGMENT ...
  DATA SEGMENT ...
  CODE SEGMENT ...
    直接写宏名 = 宏调用 (无需CALL)
```

## SHIFT宏形参提炼方法

例 1：开发一条宏，把某通用寄存器左移或右移若干次。宏定义 `MACRO` 开始，宏名比如 `SHIFT` 代表移位：

```assembly
SHIFT MACRO ...
```

`MACRO` 右边要不要形参，看题里有没有未知项：某通用寄存器哪个未知，左移右移方向未知，若干次次数未知，三个未知，`MACRO` 右边就得定对应形参。形参怎么定、宏体怎么写，下节把三个形参补全，把移位体写出来。
