# 8259A初始化编程：ICW1～ICW4逐位落实

`ICW1`的高三位没用、第`4`位是特征位、第`3`位定触发方式，这些上节课已经定了。今天接着往下抠剩下的每一位，顺带把`ICW2`、`ICW3`、`ICW4`的初始化一次算清。记的时候别孤立背每一位，跟着`BIOS`在`PC`机上的实际做法走：主片写什么、从片写什么、端口是哪个，全部有来处。

## ICW1第2位：8085留下的历史位

第`2`位，书上给你画了个叉，在`8086`系统中没有用。当年`Intel`生产`8259A`时，配的微处理器是`8085`，是个`8`位机，那时这一位是有用的：在`8085`系统中，中断向量在向量表中占`8`个字节；在`8086`系统中，向量只占`4`个字节。

可`8085`早淘汰不用了，系统全是`80x86`系列，所以这一位就不用了。考试看到它，知道是历史遗留、写`0`即可。

## ICW1第1位：单片还是级联

第`1`位可以写`1`也可以写`0`。写`0`是级联工作，写`1`是单片工作。如果是级联工作，初始化完`ICW1`后面还要初始化`ICW3`；如果是单片工作，就不用初始化`ICW3`了。

## ICW1第0位：要不要初始化ICW4

第`0`位书上给你写死了是`1`。书上没写为什么，我补充一下：写`1`就是要初始化`ICW4`，写`0`就是不初始化`ICW4`。但我们都要初始化`ICW4`，所以书上直接标了个`1`。

## 主片ICW1：11H写入20H端口

不用的位都取`0`：高三位取`0`，第`2`位取`0`，上升沿触发第`3`位取`0`，级联工作第`1`位取`0`，要`ICW4`第`0`位写`1`，再加上第`4`位特征位是`1`，拼出来就是`11H`：

```text
D7 D6 D5 D4 D3 D2 D1 D0
 0  0  0  1  0  0  0  1  = 11H
             ^特征位
```

程序这样写：

```assembly
MOV AL, 11H
OUT 20H, AL
```

`20H`没有超出`255`，目的操作数寻址用的是直接寻址，把`AL`内容写到`20H`端口去。`20H`是主片`8259`的端口地址（`A0 = 0`），第`4`位等于`1`，`8259`就识别出这是写进主片`ICW1`了。`ICW1`收到`11H`，主片就被初始化成中断请求上升沿有效、级联工作。

从片同样要初始化，端口换成`A0 = 0`的从片地址：

```assembly
MOV AL, 11H
OUT 0A0H, AL
```

`BIOS`里面就是这样做的。

## ICW2：只写基址，靠顺序识别

初始化`ICW2`时，`A0`要等于`1`。`ICW2`共`8`位：`D0`、`D1`、`D2`是低三位，`D7`到`D3`是高五位。书上说高五位是中断类型码的高五位：`D5`～`D3`写`000`对应`IR0`的类型码，写`001`对应`IR1`，写到`111`对应`IR7`。

给`8259`的`ICW2`写中断类型号，只需要写中断类型号基址，也就是只给`IR0`定类型号就行了，所以低三位肯定是`000`。

> **提示**：类型号、类型码，号就是码，不分家。读到任一个词，指的都是要送上数据线的那个中断向量编号。

在`IBM PC`机中，主片这样写：

```assembly
MOV AL, 08H
OUT 21H, AL
```

`08H`就是`0 0001 000B`的高五位部分？直接记结论：`AL`取`08H`，`OUT`到`21H`（`A0 = 1`），主片的类型号基址就定了。从片则是：

```assembly
MOV AL, 70H
OUT 0A1H, AL
```

从片基址`70H`，端口`A1H`（前面加`0`写成`0A1H`）。

这里有个关键点：向`A0 = 1`的地址`OUT`写，是没有特征位的。没有特征位怎么办？靠顺序识别：初始化`ICW2`必须紧跟在初始化`ICW1`之后，`8259`靠这个顺序认出这次写的是`ICW2`。

## ICW3：级联才写，主从含义不同

如果是级联工作，必须初始化`ICW3`；单片工作就不用。写`ICW3`时`A0 = 1`，同样靠顺序（`ICW2`写完紧跟着写`ICW3`）。

对主片的`ICW3`（`8`位`D0`～`D7`）：某一位写`1`，表明该位对应的`IR`输入端被某从片级联了。主片后面最多能级联`8`个从片，正好一位管一个。某一位写`0`，表明该位对应的`IR`端未被级联。

对从片的`ICW3`：高五位没用，只用低三位，编码`000`到`111`。如果这三位写的是`010`，说明从片的`INT`输出被级联到主片的`IR2`上了。

在`PC/AT`机中，`BIOS`对主片`ICW3`的初始化是：

```assembly
MOV AL, 04H
OUT 21H, AL
```

`04H`就是第`2`位是`1`、其余全`0`，表明主片的`IR2`被从片级联了。对从片则是：

```assembly
MOV AL, 02H
OUT 0A1H, AL
```

`010B`等于`2`，表明从片的`INT`被级联到主片的`IR2`上去了。两边约定好了，对上了。

> **结论**：我认为这些知识点考试不好考，但在实际工程中非常有用。不管上研究生做科研，还是工作中接到软硬结合的题目、要在计算机上开发系统，只要走中断方式，就要对主板上的`8259`做初始化，或者对自己系统里配的那片`8259`做初始化。

## ICW4：嵌套、缓冲与结束方式

初始化`ICW4`也要保证`A0 = 1`，共`8`位。向`A0 = 1`的端口`OUT`写时，如果`D7`、`D6`、`D5`是`000`，就表明写的是`ICW4`，这是特征位。

`D4`位说明嵌套方式：写`0`是完全嵌套，也就是我说的正常嵌套方式，优先权固定，`IR0`最高、`IR1`次之、`IR7`最低；写`1`是特殊嵌套方式，优先权可以用`OCW`写命令来指定。我们一般都用正常嵌套。

第`0`位写`1`。第`1`位选择中断结束方式：写`0`是非自动中断结束，写`1`是自动中断结束。说的是谁？说的是`8259`。`8259`对中断请求服务结束，意味着`ISR`对应位清零；清零是自动还是非自动，一般选非自动——要在中断服务程序`IRET`结束之前，给`OCW2`写`EOI`命令告诉`8259`中断结束。

中间两位：第`3`位说缓冲方式，第`2`位（`M/S`位）说主片还是从片，两位配合用。第`3`位写`1`（`buffer`位）肯定是缓冲方式；我们用的是非缓冲，所以第`3`位应该写`0`，写成`0X`（`00`或`01`）。书上印了个`1X`，我昨天看怎么看都不对，非缓冲就该是`0X`。

这样一来，`PC`机上主片`ICW4`的初始化就是：

```assembly
MOV AL, 01H
OUT 21H, AL
```

`01H`拆开看：缓冲位`0`（非缓冲）、`M/S`位`0`、结束位`0`（非自动）、嵌套位`0`（正常嵌套）。从片同样：

```assembly
MOV AL, 01H
OUT 0A1H, AL
```

到这里，`ICW1`到`ICW4`四步初始化全部落地，主片四条、从片四条，端口与命令字一一对应。
