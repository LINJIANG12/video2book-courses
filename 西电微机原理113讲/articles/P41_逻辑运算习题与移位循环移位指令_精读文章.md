# 逻辑运算习题与移位循环移位指令

我逻辑运算概念讲完了，今天先把`3.10`题里剩的几问讲透，下午下课你们在作业本独立做一遍，然后进`3.7`移位类。

## 测试BX位1位2同时为零

`3.10`第`4`问：测试`BX`位`1`和位`2`，同时为`0`时`AL`置全`1`，否则`AL`清零。

`BX`是`16`位，位`0`位`1`位`2`往上数。测特定位用与：测的位与`1`，不测的位与`0`，任何数与`0`都是`0`，待测两位原来全`0`相与结果肯定`0`。结果全`0`零标志`ZF=1`。只测不破坏`BX`，不能用改目的的`AND`，必须`TEST`。位`1`位`2`掩码二进制`0000 0000 0000 0110B`即`0006H`。用`JZ`测`ZF`，为`0`跳`L1`置全`1`，否则清零，清零后必须`JMP`跳过置`1`段，不然顺序执行覆盖了：

```assembly
TEST BX, 0006H
JZ L1
MOV AL, 00H
JMP L2
L1: MOV AL, 0FFH
L2:
```

## 有一位为零的两种理解

第`5`问：位`1`位`2`有一位为`0`时`AL`置全`1`，否则清零。位`1`位`2`组合四种`00`、`01`、`10`、`11`，汉语有一位为`0`有歧义。

按只有一位为`0`理解，只含`01`、`10`。这两种相与后低`8`位`1`个数都是`1`个奇数，奇偶标志`PF=0`；而`00`零个偶数、`11`两个偶数`PF=1`。只看奇偶就能区分恰好一位`0`，按`PF`条件转就行。

按只要有一位为`0`理解，含`00`、`01`、`10`。先判全`0`：测`ZF=1`就是`00`满足跳置`1`；`ZF=0`再测`PF`判单`1`即`01`或`10`。要两次条件转。语义歧义的题写代码前先注释说明假设。

第`8`问把`AX`各位取反：

```assembly
NOT AX
```

第`9`问`DX`第`7`位取反其余不变。取反位与`1`异或`0 XOR 1=1`、`1 XOR 1=0`，保持位与`0`异或`b XOR 0=b`。第`7`位`1`的`16`位掩码`0080H`：

```assembly
XOR DX, 0080H
```

第`10`问`CX`高低`8`位互换，最简直接换高低字节：

```assembly
XCHG CH, CL
```

## 逻辑算术移位指令格式

`3.7`移位类一共八条，分两类：移位四条，循环移位四条。移位是把操作数左或右移`1`位或若干位。被移数看无符号叫逻辑移位，看带符号叫算术移位，所以分逻辑算术两种。

逻辑算术都分左右。逻辑左移`SHL`：

```assembly
SHL DST, CNT
```

把目的左逻辑移`CNT`次。目的可以字节或字通用寄存器或存储器，段寄存器不能移位，移位是运算凡运算段都不能参加。移位次数`CNT`约定八条全同：`CNT=1`直接写`1`，`CNT>1`不能直接写，必须先送`CL`写成`, CL`。

逻辑右移`SHR`：

```assembly
SHR DST, CNT
```

右逻辑移`CNT`次，语法`CNT`约定和`SHL`完全一致。

## 移位执行过程与溢出判断

以`SHL`字节`D0`到`D7`为例：`D0`进`D1`，`D1`进`D2`，直到`D6`进`D7`，最高`D7`移出进`CF`，最低`D0`空出`CPU`自动补`0`。无符号有效范围左移一次相当于乘`2`。

`SHR`反过来：最高补`0`，最高进次高依次右移，次低进最低，最低移出进`CF`。

逻辑两条加算术两条共四条移位执行后，`CPU`按结果正常设置除`AF`外五个标志`CF`、`ZF`、`SF`、`PF`、`OF`，`AF`未定义。`OF`特别说明：看执行前后最高位符号变没变，变了`OF=1`，否则`0`。只有移`1`次看`OF`有意义，超`1`次`CPU`也设`OF`但失去判断意义。

算术移位带符号数。算术左移`SAL`，算术右移`SAR`：

```assembly
SAL DST, CNT
SAR DST, CNT
```

以`16`位`D15`到`D0`看`SAR`：`D15`符号位，右移时数据右移`D15`进`D14`依次下移，最高符号位移的同时保持原值实现符号扩展，最低`D0`移出进`CF`。算术左移朝左，次高进最高，最高原符号进`CF`，最低补`0`。

> **结论**：算术左移和逻辑左移是一回事`SAL`同`SHL`，只有逻辑右移`SHR`和算术右移`SAR`不同，四条影响除`AF`外五个标志。

## 用移位代替乘法提高速度

举例做`5*12`。当然能用乘法：

```assembly
MOV AL, 5
MOV BL, 12
MUL BL
```

但`CPU`执行乘除比别的慢十几倍几十倍，为提速简单乘除要改写。连加五遍也行，但我要求移位实现。左移一次乘`2`，两次乘`4`，三次乘`8`，四次乘`16`，没有直接乘`12`，用分配律：

$$5 \times 12 = 5 \times (4+8) = 5 \times 4 + 5 \times 8$$

`5*4`左移两次，`5*8`左移三次，相加：

```assembly
MOV AL, 5
MOV CL, 2
SHL AL, CL
MOV BL, AL
SHL AL, 1
ADD AL, BL
```

`AL`左移两次得`5*4`暂存`BL`，`AL`再左移一次得`5*8`，`ADD`相加`AL`就是`5*12`。条数多了占内存，但省时间快得多，实际为提速就用这技巧，缩小倍数就右移。

## 循环移位大小环指令

第二类循环移位。概念是操作数字节或字，左右移最高移出肯定进`CF`。不带进位小环：最高移出同时送最低闭环，每移最高既进`CF`又回最低。带进位大环：最高进`CF`，原`CF`进最低，含`CF`大环。所以两大类四条：

```assembly
ROL DST, CNT
ROR DST, CNT
RCL DST, CNT
RCR DST, CNT
```

`ROL`循环左，`ROR`循环右，最高最低同时送`CF`；`RCL`带进位左，`RCR`带进位右，目的和`CF`大环移`CNT`次。`CNT`约定和基本移位完全一致。

四条执行后只影响`CF`和`OF`，其余四没定义。书上出入以黑板为准，最常用最有意义就是`CF`。

实例若`(BX)=10110110B`，`CF=1`，`(CL)=3`，`CPU`执行循环移位就按大小环一位一位转，移出进`CF`，小环回位大环经`CF`，具体结果按三要素一步步推就行。
