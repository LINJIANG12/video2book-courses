# 段内转移寻址与条件转移范围

我前面把关于数据的八种寻址方式讲完了，其中和存储器有关的五种要你们下去多做作业多上机。今天看寻址的第二大类：关于转移地址的寻址方式。程序要分支要循环就要转移，转移到目的地的地址是多少，怎么找，这就是转移地址寻址。

## 段内转移与段间转移的分工

转移地址寻址分两种：一种是段内转移，前面提过叫近程转移；一种是段间转移，从一个代码段一下跳到另一个代码段。

先看段内转移。段内转移后只有`IP`变了，`CS`没变。我要找的就是转移目的地的`IP`，也就是偏移地址，找到送`IP`就实现转移。

段内找目的地又有两种：段内直接寻址和段内间接寻址。

## 段内直接寻址的标号写法

段内直接寻址指转移指令中直接给出了转移目的地的地址，但地址用标号描述。你们早就见过标号，我举个例子。

代码段里编到某处，我以无条件转移`JMP`为例。想转到下面某条指令去，那条指令的地址程序员并不知道，用标号代替，假设叫`L1`：

```assembly
JMP L1
...
L1: ...
```

对这条`JMP`而言，指令中直接给出了转移目的地地址，这就是段内直接寻址。理解起来很好理解，难的是原理。

## 汇编时给的是相对位移量

汇编程序对你们写的每一行逐行翻译汇编。汇编到这条`JMP`时，先给一个字节操作码，操作码告诉`CPU`做无条件转移。转到哪去。操作码后面给的不是目的地绝对地址，而是相对位移量。

什么叫相对位移量。`CPU`执行完`JMP L1`如果不转移，顺序执行下来有个`IP`值，这个叫当前`IP`。从当前`IP`到转移目的地之间间隔多少字节，负向转就是负位移，正向转就是正位移。如果转移范围没超出`-128`到`+127`，这个位移就是一个字节`8`位，汇编程序就在操作码后给一个字节相对位移量。

汇编是自上而下逐行汇的。先汇这条`JMP`，往下汇才见到`L1`。负向转时间隔字节数已经能数出来，负数用补码表示位移。如果是正向转，汇这条时还不知道`L1`在哪，但知道是段内转，绝对不会超过`+32767`字节，所以统统按两个字节`16`位位移汇。这就是为什么负向没超`-128`的是双字节指令（`1`操作码+`1`位移），正向转全是三字节指令（`1`操作码+`2`位移），负向超`-128`但没超`-32768`的也是三字节。

你们想省空间，正向转又明确知道不会超`+127`，可以写成：

```assembly
JMP SHORT L1
```

告诉汇编这是`SHORT`短转移。短就是以当前`IP`为基准，负不超`-128`正不超`+127`，比近还近。汇出来双字节，`1`操作码+`8`位位移。

## CPU执行时当前IP加位移

`CPU`执行`JMP`就是执行操作码，就知道要无条件转，转移目的地`IP`等于什么。等于当前`IP`加相对位移量。

双字节和三字节操作码肯定不同。`CPU`执行这条时手里有`IP`，双字节指令`IP+2`就是当前`IP`。紧跟操作码的下个单元取出来，不当操作码用，当位移用，加到当前`IP`上就是目的地`IP`。所以好多教材把段内直接寻址也叫段内相对寻址。相对的概念来自`CPU`执行原理，直接的概念来自语句写法。用起来好用，理论上有难度。

## 条件转移只能段内短转移

`8086`所有条件转移指令只能段内转。无条件`JMP`段内段间都行，条件转移只能段内，且范围以当前`IP`为基准`-128`到`+127`字节。

你们编源程序，条件转的范围超了这个，编译时屏幕告诉你转移范围溢出。肉眼看不见，编译程序能算出来。这时候怎么办。必须转又超范围，就用`JMP`搭桥二级跳：先条件跳到附近目的地`1`，在目的地`1`里再`JMP`到真正目的地。实际应用一定要注意。

还有一点：所有条件转移指令的寻址方式都是段内相对寻址，也就是段内直接寻址。记住这一条。

## 一道只做对寥寥无几的填空题

有一年考试有道题：`8086`执行`JZ L1`，说`IP=0100H`，`DISP=FDH`，问执行后`IP`等于多少。

动动脑筋。`JZ`是条件转，肯定双字节，`1`操作码+`8`位位移。`IP=0100H`是这条指令所在偏移，`0100H`放操作码，`0101H`放位移，跑到`0102H`就是当前`IP`。位移`FDH`是多少。补码，`-3`。计算机带符号数用补码，这是考的第二个点。

所以目的地`IP = 0102H + (-3) = 00FFH`。相当于跳到前面那个单字节指令去了。那年做对的寥寥无几，后来这种抽象题都不敢出了。你们看我出这个题，就是看刚才的概念你们理解几分。

## 段内间接寻址的含义

段内转移第二种：段内间接寻址。

直白说就是转移目的地的`IP`间接在某个地方放着。间接的概念从数据寻址讲到现在应该能理解了。存储器地址用`[BX]`间接，操作数所在单元地址间接在`BX`里，把`BX`读出来才是地址。这里一样，目的`IP`间接放着，取出来送`IP`就转过去了。具体哪些形式能间接，后面讲`JMP`间接时再展开。
