# 回车换行控制与DOS 06H非阻塞输入

第一章我就让你们背：`'0'` 到 `'9'`，`'A'` 到 `'Z'`，记不全到 `Z` 起码 `'A'` 到 `'F'` 大小写，`ASCII` 必须拿下。那些能在屏幕直接显示的叫可视字符。今天补几个屏幕不显示字形的：回车 `CR 0DH`，换行 `LF 0AH`，空格 `SP 20H`，都叫非可视字符。别小看这俩，菜单显示、4.39 题人机提示全靠它。

## 回车与换行的分工

假设 `DOS` 界面满屏字，光标在末尾闪。现在我要把下一句话打到下一行最左端，光标怎么过去？很多人以为回车就到下一行，错了。

- 回车：只回当前行最左端。
- 换行：只下移一行，列不动。

必须两个都做，才到下一行最左端：

```assembly
MOV AH, 02H
MOV DL, 0DH  ; 回车
INT 21H      ; 回当前行最左
MOV AH, 02H
MOV DL, 0AH  ; 换行
INT 21H      ; 下移一行
```

先回后换、先换后回效果一样。4.39 题一句话显示完要显示下一句，就得来一次回车换行。用得太多，直接编成子程序，要用 `CALL` 一下就行。

## 系统功能调用分类回顾

上一节到 3.12 过程调用与返回，3.12.5 系统功能调用分两类：`DOS` 高级功能调用，`BIOS` 低级功能调用。上节介绍了：

- `01H`、`07H`、`08H`：都是等键盘输一个字符，区别在有无回显、响不响应 `Ctrl+C` 这些细节。
- `02H`：向屏幕输出一个字符，待输出放 `DL`。
- `05H`：向打印机输出一个字符，同样放 `DL`。

今天接着看 `06H`。

## DOS 06H直接控制台输入输出

`06H` 全称直接控制台输入输出，既能输又能出。输还是出，进之前看 `DL`：

| 进入条件 | 执行动作 |
| :--- | :--- |
| `DL=00H` 到 `FEH` | 输出，`DL` 里 `ASCII` 打到屏幕 |
| `DL=FFH` | 输入，从键盘读一个字符 |

```assembly
MOV AH, 06H
MOV DL, 0FFH ; FFH表示转输入检测
INT 21H
```

`01H`、`07H`、`08H` 没按键会挂起等，`06H` 做输入不等待，非阻塞，瞬间测一下就回来。程序不等的目的是非阻塞检测键盘。

## ZF判断与ESC分支逻辑

不等，怎么知道有没有键？看零标志 `ZF`：

- 无按键：$ZF=1$
- 有按键：$ZF=0$，且被按字符 `ASCII` 自动进 `AL`，跟 `01H` 一样键值在 `AL`。

所以调完紧接着测 `ZF`：

```assembly
MOV AH, 06H
MOV DL, 0FFH
INT 21H
JZ  NO_KEY    ; ZF=1无键，去NO_KEY
CMP AL, 'Q'   ; ZF=0有键，AL里是键值
; ...分支...
NO_KEY:
; ...无键处理...
```

教材 156 页 4.39 题几乎每问都要这个：功能做完暂停，提示按任意键继续，或测特定控制键，靠的就是这个机制。

需求细化一下：如果按的是 `ESC`，回主菜单；不是 `ESC`，这功能重做一遍。`ESC` 的 `ASCII` 就是 `1BH`。有键了，`AL` 跟 `1BH` 比：

```assembly
CMP AL, 1BH
JE  MENU    ; 相等是ESC，回总入口主菜单
JMP FUNC    ; 不等是别的键，重做该功能
```

相等 `JE` 回开头主菜单，不等 `JMP` 回该功能入口重做。讲 `06H` 就是为了解决这类题：每问做完测按键，没按继续干活，按了再看是不是 `ESC`，是回总入口，不是重做。4.39 题每问都是这个套路。
