# 多分支转移桥与跳转表实现

我上节把段内直接寻址讲透了，今天先把段内间接寻址回顾一句，然后举个多分支的例子。你们听完就知道间接转移在程序里到底好在哪。

## 段内间接寻址的应用位置

我要找某个单元，单元里放的是转移目的地的偏移地址，从单元里取出偏移送`IP`，不就实现转移了吗。那找这个单元的地址有几种办法。关于存储器的五种寻址任何一种都能找到，听懂了没有。这就是段内间接寻址。

它在实际程序里用得着，但没有段内直接用得广泛，直接用起来也简单。下面这个例子就是间接最漂亮的用法。

## AL等于几就转到哪里去

我编一段程序，不同分支分别是`L1`、`L2`、`L3`。现在叫你们在红粉笔括号那块编一段实现转移：按`AL`的值，若`AL=1`转`L1`，`AL=2`转`L2`，`AL=3`转`L3`，不是`1`、`2`、`3`就顺序下来。能听懂吗。就是在那块测`AL`，等于几跳哪里。

最笨的办法就是测：`AL`等于`1`吗。是跳过去，不是往下；等于`2`吗。是跑过去，不是又下来；再测等于`3`吗。是跑那，不等于下来。我这只有三项，如果给你们二十项呢。等于`19`吗。不是。等于`20`吗。是，找到了。这样一直排下去，顺序比较效率高吗。不高，能实现但效率不高。

我举这个例子就是要你们找一种提高效率的算法。假如从当前`IP`到目的地相对位移没超`-128`到`+127`，超了处理不一样，但这里先不管，重点看段内。

## 用SHORT搭一座转移桥

看我的笨办法行不行。我建一个分支跳转表，也叫转移桥：

```assembly
TABLE: JMP SHORT L1
       JMP SHORT L2
       JMP SHORT L3
```

`AL=1`跳第一条，从这再跳`L1`；`AL=2`跳第二条，再跳`L2`。这里还有什么关系。如果这些`JMP`全是`SHORT`型，全是双字节指令，排开位移是不是按`2`、`2`、`2`递增。

我都提示到这了。当`AL=1`位移`0`，输入`n`时位移和`n`的关系就是：

$$位移 = (n-1) \times 2$$

`n=1`时`(1-1)*2=0`，`n=2`时`(2-1)*2=2`，`n=3`时`(3-1)*2=4`。看懂了没有。

## DEC加ADD算出桥上偏移

前面先对`AL`减`1`，用`DEC`也行`SUB`也行：

```assembly
DEC AL
```

减`1`后要乘`2`，没学移位就用加法，自身相加就是乘`2`，左移一位也行：

```assembly
ADD AL, AL
MOV AH, 0
```

清零是为了扩展用`AX`。然后把桥首地址取出来：

```assembly
MOV BX, OFFSET TABLE
ADD BX, AX
JMP BX
```

`TABLE`标号给`BX`当基地址，加`AX`算出目标跳转指令地址，`JMP BX`段内间接转到桥上对应分支指令。

验证一下。`AL=1`时`AX=(1-1)*2=0`，`BX+0`等于`OFFSET TABLE`，`JMP BX`跳到`JMP SHORT L1`，顺利到`L1`。`AL=2`时`AX=2`，基址加`2`跳到第二条`JMP SHORT L2`，到`L2`。`AL=3`时`AX=4`，跳第三条到`L3`。这就是用`JMP`在这里做转移桥，跳转表。
