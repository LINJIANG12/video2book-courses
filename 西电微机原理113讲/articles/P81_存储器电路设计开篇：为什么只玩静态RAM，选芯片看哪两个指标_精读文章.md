# 存储器电路设计开篇：为什么只玩静态RAM，选芯片看哪两个指标

如果你的应用系统里，外部`RAM`电路用的是`DRAM`器件，显然，你得配一套地址刷新电路，理解了没有？而地址刷新电路的设计是复杂的。所以我们用户做一般产品设计，外部`RAM`电路没人选`DRAM`，都选静态`RAM`。这一讲我就先把这个调子定死：我们这一章讲存储器电路设计，重点是内存的设计，内存设计的重点又是静态`RAM`电路的设计，当然也不排除只读存储器设计。

## 先定调：内存设计只抓静态RAM

为什么放着`DRAM`不用？两笔账要算清楚。

第一笔是设计复杂度账。`DRAM`靠电容存电荷，电荷会漏，就得不停地刷新，刷新电路复杂。你为一款产品专门搭一套刷新电路，值吗？

第二笔是量账。像计算机上配的内存条，用的全是`DRAM`，人家图的是容量。但人家不怕刷新电路复杂：复杂一次，卖向全球。你复杂一次，你卖给谁？你的量起不来。量能起来，你就不怕它复杂，也不怕性价比。关键就是你设计产品的量起不来。

> **结论**：一般产品设计，外部`RAM`一律选静态`RAM`；`DRAM`只属于内存条那种走量的场合。

还有速度观要摆正。从半导体工艺看，静态`RAM`集成度比`DRAM`低，容量不容易做大，但足够你用。`DRAM`读写速度相对`SRAM`慢，可人家相对慢不等于慢，明白了没有？别一听“慢”就觉得`DRAM`不行。

## 常用器件一眼认：62系列、6116、2114

静态`RAM`既然是重点，器件型号就得一眼认出来。常用的是`62`打头的：`6264`、`62128`、`62256`。

读法是门手艺。`64`是容量：`8×8=64`，按字节算是`8K×8`的容量器件。`62128`就是`16K`。不常用的系列也有，比如`6116`，`16`是容量，它是`2K`字节的器件。再比如`2114`，这个`14`指的是`1K×4`：有`1K`个地址单元，每个单元只能放`4`个`bit`位。

> **易错点**：`2114`的每个单元只有`4`位，不是一个字节。从第一课到第二章我一直在讲，计算机中的存储器是按字节组织的，所以用这种`4`位单元的器件组内存，必须先两片一并，变成字节。

## 位扩展与字扩展：先并成字节，再串出容量

这就是书上`198`页`6.4.1`节位扩展、`6.4.2`节字扩展讲的那句话，理解了没有？

不管用什么型号的器件，给微机系统扩展静态`RAM`，先在位上看是不是`8`位一个单元。`1K×1`的器件，就`8`片一并变成字节，这叫位扩展；`2114`这种`1K×4`的，就两片一并成`1K×8`的一个模块。然后这个方向上有多少个模块去串，看总容量：系统要`16K`，`8`片一并的方案就要`16`个模块往下串，这叫字扩展。

```text
位扩展（先并成字节）            字扩展（再串出容量）
1K x 1 ──┐
1K x 1 ──┤
  ...    ├─→ 1K x 8 模块 ──┐
1K x 1 ──┘                ├─→ 16K 系统
                          ┆（16 个模块往下串）
2114 x 2 ──→ 1K x 8 模块 ──┘
6264 x 1 ──→ 8K x 8（本身已是字节，只串）
```

读图说明：位上不够`8`位的先并，并成字节模块后再串；本身已是`×8`的器件，系统设计只看容量串几片。

## 微机系统的存储器分层：185页图6.1

存储器分类我大概说一下，书上`185`页图`6.1`把微机系统里的存储器从`CPU`内部一路往外摆明白了：`CPU`内部放数据的寄存器，再往外是`Cache`，下来是主存也就是内存，最后是外存。

`Cache`是干什么的？事先把内存里的一些数据搬家搬到`CPU`内部的`Cache`里，`CPU`要用数据时直接从`Cache`取，路短速度就快，这叫一级`Cache`；主板上还能配二级`Cache`。

图上还画了两个箭头，方向要记死：从容量看，越往下走容量越大；从速度看，`CPU`内部存储器速度最高。

```text
CPU 寄存器 → 一级 Cache → 二级 Cache → 主存（内存） → 外存
  速度：高 ────────────────────────────────→ 低
  容量：小 ────────────────────────────────→ 大
```

读图说明：离`CPU`越近越快但越小，离得越远越大但越慢，`Cache`就是拿容量换路程的那一层。

> **提示**：这一段大家一看就会，不用死记，记住“上快下大”四个字就行。

## 选芯片的第一个指标：容量

今天真正要讲的是`186`页`6.2`节，存储器的主要技术指标。你要给系统设计存储器子系统，就得选器件，选器件看什么？不是随便买一片插上就行。

第一个指标是容量。但容量的说法有两套：对芯片讲片容量，一般按位说，几`K`乘几；对微机系统讲容量，按字节衡量。我问你内存多大，你说配了`128`兆，兆后面那个字节都不说了，缺省了，单位全是字节。

看个例子就知道容量指标的厉害。给某系统配`32K`字节静态`RAM`：选`62256`，几片？一片。选`2114`呢？两片才`1K`，这样的模块要`32`个，一个模块两片，是不是要`64`片？光听着都害怕了。

缺点是什么？板子体积大了。不光体积大，干扰大了：线多了干扰大。每片器件工作都要加电，功耗也上去了。所以容量指标不只是“够不够装”，还连着体积、干扰、功耗一串账。

| 方案 | 用片量 | 代价 |
| :--- | :--- | :--- |
| `62256`（`32K×8`） | `1`片 | 体积小、线少、干扰小 |
| `2114`（`1K×4`） | `64`片（`32`个模块） | 体积大、线多、干扰大、功耗高 |

## 选芯片的第二个指标：速度

第二个指标是速度。速度不够，器件跟不上系统，整机就掉速；速度太高，价格昂贵，你用不了那么高的速度，不是把钱废了？所以工程上速度是“跟上就行，不必追高”。

速度跟不上，根子常常在线上。线的长度、线与线的距离都有关系：线越长耦合电容越大，距离越短耦合电容越大。耦合电容大到一定程度，邻线上的交流信号就隔直导交地耦合过来了，幅度可能比较低，这种现象叫信号线之间的串扰，必然带来附加延迟。

工程做法是：把附加延迟估算出来，定一个延迟时间公式，算完再去查手册。手册给出的时间如果比公式算出的时间还小，这个器件就没问题，速度肯定能跟上。懒得推算，跑到柜台问“哪个器件速度高卖给我”，那是拿钱打水漂。

> **结论**：主要技术指标就容量和速度两个。价格、体积、可靠性也算指标，但那是顺带考虑的，主指标就是这两个。
