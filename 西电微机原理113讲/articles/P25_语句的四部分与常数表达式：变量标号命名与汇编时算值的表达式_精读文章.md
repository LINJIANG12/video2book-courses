# 语句的四部分与常数表达式：变量标号命名与汇编时算值的表达式

8086 汇编语言程序语句的种类就三种，常用的主要是指令语句和伪指令语句。第三种宏指令语句本身是 8086 指令系统没有的语句，由用户通过宏定义伪指令定义的，或者说用户开发的新语句。有些语句程序员自己可以开发，工具就是宏定义伪指令。开发了宏指令，后面编程就能引用，类似 C 语言的函数：前面定义函数，下面引用调用，两回事一回事。具体定义方式第三章后半部分才讲。这是 3.1 节一开始要掌握的基本概念。

## 语句最多由四部分组成

下面翻到教材 25 页，3.1.1 汇编语言语句的组成。每种语句由哪几部分组成？一条语句最多四部分。比如数据定义伪指令：

```assembly
DATA1 DB 12H, -12
```

`DB` 叫助记符，后边 `12H, -12` 逗号分隔定义字节型数据，叫操作数，操作数多项之间逗号分隔。助记符一部分，操作数一部分，这就两部分了。

`12H` 存哪个单元？严格说 `DB` 左边要给出单元地址。但实际单元非常多，每个地址都记程序设计极其繁琐，所以把地址符号化。打个比方：每个同学是一个存储单元，学号是地址，人交往全凭学号记忆复杂，起个名字用名字交往就简单了。汇编同理，单元都有地址，直接和地址打交道极其复杂，把用到的单元地址符号化起个符号名称。比如命名 `DATA1`，后面要把 `12H` 读入 `AL` 直接访问 `DATA1`，读后一个数据访问 `DATA1+1`。数据定义伪指令左边起的符号化名称叫变量名，简称变量。

再定义字单元：

```assembly
DATA2 DW ?
```

`DATA2` 是字单元，地址用变量名代替。后面执行：

```assembly
MOV DATA2, AX
```

把 `AX` 内容写入 `DATA2` 地址的字单元。初始没具体数据用问号 `?` 预留空间，打问号实际数据是随机数，开机是多少就是多少，CPU 执行写入指令后才存入目标数据。

变量名、助记符、操作数，操作数后以分号 `;` 开头还能加注释，一条语句最多四部分：名称、助记符、操作数、注释。名称命名规范：凡是名称必须以字母开头，凡是常数必须以 $0 \sim 9$ 开头；名称字符长度不超过 31 个。

## 指令语句中的标号

编程时写指令序列：

```assembly
MOV AX, BX
...
ADD AX, DATA2
JZ  NEXT
```

执行 `ADD AX, DATA2` 结果送回 `AX`，CPU 按结果设置 `ZF` 零标志，再 `JZ` 判断是否为 0：`ZF` 置 1 跳转目标地址，不为 0 顺序执行，典型的条件二分支。`JZ` 后要指定跳转目的地址，具体数字地址无法确定，同样符号化。比如目的指令单元命名 `NEXT`，以冒号结尾，这个名称代表指令在存储器的地址，有段地址有偏移地址，叫标号名，简称标号。不管标号还是变量，凡是名称首字符必须字母开头。`1H` 是数字十六进制常数，`H1` 是名称，就这么个意思。语句四部分就说这么多。

## 常数：数值字符字符串与问号

下面 3.1.2，汇编里的常数及表达式，教材 26 页。常数有几种：

数值常数：十六进制以大写 `H` 结尾；二进制必须大写 `B` 结尾，小写不对，比如 `MOV AL, 10110001B`；十进制结尾可缺省，不缺省用大写 `D`，一般缺省。

字符与字符串常数：单引号括起来的单个字符叫字符常数，比如 `MOV BL, 'A'`，汇编时汇编程序用字符 `ASCII` 码代替，所以也是常数；数据段定义时单引号括起的一串字符叫字符串常数，比如 `STRING DB 'THIS IS ...'`，`STRING` 是变量名。

预留值问号 `?`：数据定义伪指令里用，表明单元数据随机，开机多大就是多大，目的是程序运行期间写入运算结果。这些都叫常数。

| 常数类型 | 写法 | 说明 |
| :--- | :--- | :--- |
| 十六进制 | `12H`、`0FFH` | 大写 `H` 结尾，字母开头前加 $0$ |
| 二进制 | `10110001B` | 必须大写 `B` |
| 十进制 | `12`、`12D` | 一般缺省 |
| 字符 | `'A'` | 汇编时用 `ASCII` 码代替 |
| 字符串 | `'THIS IS ...'` | 数据段定义用 |
| 预留 | `?` | 随机数，运行期写入结果用 |

## 表达式：汇编时算值不是 CPU 算

下面看表达式，教材 27 页。表达式的值是汇编程序汇编过程中计算出来的，不是 CPU 执行指令时计算的！CPU 执行完成的是助记符对应的操作，比如 `MOV` 传送。

算术表达式比如：

```assembly
MOV AL, 5 + 2 * 3
```

操作数项写了算术表达式，汇编程序汇编时先算出值，遵循四则运算：先括号后外边，先乘除后加减，和算术规则一致。也可出现在数据定义伪指令里，比如写 $5 \times 4$，汇编算出 $20$ 即 $14H$ 存入单元，计算机内部数值都用二进制。除法 `/` 取商：$20 / 3 = 6$ 即 $06H$；`MOD` 取余：$20\ \text{MOD}\ 3 = 2$。实际编程允许操作数用算术表达式，但用得不多。表达式里运算符 `+`、`-`、`*`、`/`、`MOD` 叫操作符，参与的数值叫操作数。

逻辑操作表达式与或异或非，比如：

```assembly
AND AL, 21H AND 0FH
```

出现两次 `AND` 要区分：第二个操作数项上的 `21H AND 0FH` 是逻辑表达式，汇编程序汇编时算完；第一个是指令助记符，CPU 执行时才算。两种操作必须分清，逻辑表达式允许出现但很不常用。

第三种关系表达式概念简单，汇编时按关系算出真假值，同样不常用。表达式共同点记住一条：值都是汇编时算好的，CPU 拿到的是现成结果。
