# BCD减法乘除调整与逻辑运算指令

我上次把`BCD`加法调整讲完了，今天把减法乘除调整收尾，顺手进`3.6`逻辑运算。记住一句话：加减乘先运算后调整，只有除法先调整后运算。

## ASCII加法就是分离BCD加法

讲减法前补个知识点。分离`BCD`运算把加数看成字符也一样，比如字符`'8'`的`ASCII`是`38H`，高`4`位都是`0011`。两字符相加高位得`0110`，`ADD`后`AL=6CH`。但`CPU`执行`AAA`第二步把高`4`位清零，调完和高位直接用分离`BCD`一样。

所以有些教材把分离`BCD`加法叫`ASCII`码加法，分离加法调整叫`ASCII`调整，原理完全一致。

## 组合与分离减法调整指令

减法`BCD`同样分组合与分离：组合减调整`DAS`，分离减调整`AAS`，都隐含对`AL`调，调完按结果正常设置六个标志。`DAS`对`AL`组合差减`6`修正，加法加`6`减法减`6`。

看例`3.17`组合`31-87`：

```assembly
MOV AL, 31H
SUB AL, 87H
DAS
```

数学正确应`-56`。`CPU`先二进制减：

$$00110001B - 10000111B = 10101010B(AAH)$$

最高位借位`CF=1`，借了百位`100`，这个概念不能丢。此时`AL=AAH`，低`1010B>9`高`1010B>9`，高低都要减`6`即减`66H`：

$$AAH - 66H = 44H$$

调后`AL=44H`，但`CF=1`借了`100`，实际`-100+44=-56`。结果要连借位一起读。

## 乘法BCD调整与除法先调后算

第三种乘法只能分离，助记符`AAM`。看例`3.18`分离`7*8`：

```assembly
MOV AL, 07H
MOV BL, 08H
MUL BL
AAM
```

字节乘被乘数隐含`AL`，`7*8=56`十进制即`38H`，此时`AX=0038H`纯二进制。但分离`BCD`期望十进制`56`表示`AX=0506H`，不对。`CPU`执行`AAM`对`AX`积做除`10`，商放`AH`余数放`AL`。`0038H`除`10`商`5`余`6`，恢复`AX=0506H`，对了。`AAM`只影响`SF`、`ZF`，`55`页写了，实际用不着我不讲。

最后一类除法调整`AAD`。除法只能分离，第二除前先调后算。看例`3.19`算`27/4`，被除数必须分离表示：

```assembly
MOV AX, 0207H
MOV BL, 04H
AAD
DIV BL
```

`CPU`执行`AAD`隐含对`AX`调，原则是`(AH)*10+(AL)->AX`，调完`AX=27`二进制。然后`DIV BL`用`AX`除`4`，商`AL`余数`AH`。做分离除一定先调后算，和前面加减乘先算后调不一样。`AAD`正常影响`PF`、`SF`、`ZF`，其余三未定义。调完算术类讲完。

## 逻辑运算与标志设置

现在看`3.6`逻辑运算，一共五条。第一章二进制讲过`AND`、`OR`、`XOR`、`NOT`四条，今天加一条。逻辑属运算，段寄存器不能参加，寻址六条也要守。

与操作助记符`AND`，双操作数：

```assembly
AND DST, SRC
```

目的和源按位与送回目的，源不变。第二章就接触过，没接触的是后一句：`CPU`执行与或异或后`CF`、`OF`自动清零，要注意。有时考试出`AND AX, BX`后`CF`等于多少，不用算就是`0`，考概念。书上还写`AF`清零，实际`AF`没定义。

## 或异或测试求反指令

有了与，或就容易了：

```assembly
OR DST, SRC
```

目的和源按位或送回目的，只能按字节或字，`8086`没有双字运算。标志和与一致：`CF`、`OF`清零，`SF`、`ZF`、`PF`按结果设。

异或：

```assembly
XOR DST, SRC
```

按位异或送回目的，`CF=0`、`OF=0`，`SF`、`ZF`、`PF`按结果设。第二章讲应用时什么场合用与或异或必须分清。

今天新加测试：

```assembly
TEST DST, SRC
```

目的和源按位与，但特殊的与，结果既不送回目的也不破坏源，双方保持不变。唯一目的就是按与出结果设标志：`CF`、`OF`清零，`SF`、`ZF`、`PF`正常设。

最后求反：

```assembly
NOT DST
```

单操作数，对目的按位取反送回目的。重要一点是`NOT`对六个标志全无影响，逻辑里影响标志的只有前面四条`AND`、`OR`、`XOR`、`TEST`。
