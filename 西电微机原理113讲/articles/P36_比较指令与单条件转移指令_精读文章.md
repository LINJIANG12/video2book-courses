# 比较指令与单条件转移指令

我上次把`SUB`、`SBB`、`DEC`讲完了，今天把减法后两条收尾。第四条比较指令是程序分支的关键，单条件转移的十条全从它长出来。

## 比较指令只置标志不回送

第四条叫比较指令（`Compare`），助记符`CMP`，双操作数。这是一条特殊的减法：

```assembly
CMP DST, SRC
```

功能是用目的指明的内容减源指明的内容，差既不送回目的，也不影响源，只是按差设置六个状态标志。叫比较就是这个意思。

程序里经常对两数比谁大谁小或是否相等，按结果分支。分支要抓条件，就用`CMP`产生条件。假设两数一个是`α`一个是`β`，先比较就是做减法，按运算产生条件：`CF`、`SF`、`ZF`、`PF`、`OF`都是条件，`AF`辅助进位辅助借位只是`BCD`调整用，不算条件。六个除`AF`剩五个条件。

产生了条件就去测条件，满足干什么，不满足干什么，这就是有条件二分支。分支前要先产生条件，大多数场合用比较产生，当然加法减法也能产生，但在不想破坏目的和源时只有用`CMP`。这是编程思路。

比如两数都是八位，把`α`给`AL`：

```assembly
MOV AL, α
CMP AL, β
```

源用立即数寻址，通过比较就产生了这些条件。`8086`里按单个条件就有转移指令。按`CF`就有`JC`有进位转、`JNC`没进位转，转到哪去。按前面转移寻址，目的地起个标号，这条就是段内相对也就是段内直接。按`SF`就有`JS`结果为负转、`JNS`结果不为负转。

## 零标志对应的两条等效写法

按`ZF`也有两条。`JZ`结果为`0`转。两数比`ZF=1`说明差`0`，差`0`说明两数相等，`8086`里相等用`E`表示，所以`JZ`等效写成`JE`。写`JE`写`JZ`汇出来代码一样，听明白了没有。`ZF=0`说明不等，不等转就是`JNZ`，也可写`JNE`。

按`PF`也有两条：`JP`结果低`8`位`1`个数偶数时转，`JNP`不是偶数时转。按`OF`也有两条：`JO`有溢出转，`JNO`没溢出转。

这样两数比较产生五个条件，每个条件对应两条，我脑子里就记了十条条件转移指令。这些在哪。教材`63`页`3.9.2`节有条件转移，表`3.6`前半就是单个条件对应的转移，这块我就讲完了。表下半还有条件转移，什么意思，下次看。
