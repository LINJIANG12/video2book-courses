# 2114组4K实例与2764编程：从位扩展收尾到自己搭编程器

上讲用`6264`把字节扩展讲透了，这一讲先拿`2114`把`4K`电路画完，位扩展和字节扩展两个概念就彻底收口。然后进`ROM`地盘：`EPROM`选谁、`2764`引脚怎么记、编程器自己能不能搭。最后那道“简述`2764`编程步骤”的题，听完你肯定会。

## 2114组4K：两片一并做模块，四个模块一串

一片`2114`是`1K×4`，两片组成`1K×8`模块：一片的`D0～D3`接系统数据总线低`4`位，另一片的`D0～D3`接高`4`位`D4～D7`，`0`到`7`全接齐。地址`A0～A9`对接，接到系统低`10`根做片内选址，`2^10=1K`，选定某个单元时选定的就是`8`位。

系统要`4K`，这样的模块要`4`个（中间两个画图时缺省）。每个模块两片的`CS`非连在一起，由一路译码信号控制：有效时两片全选中，`CPU`操作就在这`1K×8`内部；`WE`非也接在一起，`8088`最大方式接`MEMW`非，写谁由片选定。

> **结论**：横向扩数据位宽的方向叫位扩展，纵向加容量的方向叫字扩展（字节扩展）。结合`6264`和`2114`，书上这两个概念全部讲完。

```text
模块0: 2114(D0~D3→系统D0~D3) ┐
        2114(D0~D3→系统D4~D7) ├─→ 1K x 8 ──┐
模块1: 2114 x 2 ──────────────→ 1K x 8 ──┤
模块2: 2114 x 2 ──────────────→ 1K x 8 ──┼─→ 4K（字扩展）
模块3: 2114 x 2 ──────────────→ 1K x 8 ──┘
（每模块 A0~A9 对连做片内；CS非对连等译码；WE非对连接 MEMW非）
```

读图说明：先两片一并凑字节，再四个模块一串凑容量，位扩展在横向，字扩展在纵向。

## EPROM选型：程序再小也选2764

片容量小的`EPROM`还有`2732`、`2716`，但早停产了，市场上囤货有，价格很高，划不来。系统程序即使不大，也建议选`2764`；程序量大再上`27128`、`27256`。我们考察以`2764`为主。

## 2764引脚：和6264对应着记

`2764`片容量`8K×8`，和`6264`引脚功能相对应，`28`脚双列直插。`13`根地址（`A12～A8`高`5`位加`A7～A0`低`8`位，`2^13=8K`），`8`根数据`D0～D7`。`13+8=21`，加电源地`23`根，剩下`5`根控制。

看图`6.9`，和`6264`对照着认：`20`脚`CE`非就是片选（`CE`和`CS`一回事），`22`脚`OE`非。片选有效（低电平），`8`个数据脚先从高阻第三态变成正常二态，再给`OE`非加低电平，地址码对应单元的数据读出来，这就是只读状态。

剩下三根：`VPP`端第`1`脚，编程电压输入。正常工作`VCC`给`+5V`；编程电压看厂家型号，通常`+21V～+25V`（`21.5V`、`24V`都有），必须查手册，所以编程器上位机软件先选厂家和芯片型号。`PGM`非第`27`脚，编程控制脉冲，低有效。第`26`脚`NC`悬空。`28`个脚全齐了。

| 引脚 | 功能 |
| :--- | :--- |
| `A0～A12`（`13`根） | 地址输入，`8K`寻址 |
| `D0～D7`（`8`根） | 编程时输入，读出时输出 |
| `CE`非（`20`脚） | 片选，低有效 |
| `OE`非（`22`脚） | 输出允许，读出时低有效 |
| `VPP`（`1`脚） | 编程高压`+21V～+25V`，查手册 |
| `PGM`非（`27`脚） | 编程负脉冲，低有效 |
| `NC`（`26`脚） | 悬空 |

## 别再说“烧”：编程器、写入器才是规范叫法

`EPROM`两种工作方式：正常工作是只读，往里写数据叫编程，编程器也叫写入器。课外做产品，代码往`CPU`内部`ROM`或外部`EPROM`里写，同学老问“老师你有烧写器吗”，“烧”这个词大家都懂，但严格说不准确。

这个说法来自早期一次可编程`PROM`：内部单元带钨丝熔丝，编程用大电流烧断，设备叫烧写器。到了紫外线可擦除的`EPROM`，存储原理变了，没“烧”这回事了，规范术语只能叫编程器、编写器、写入器。你说“烧”别人能理解，那是早期习惯口误沿用下来的。

> **提示**：概念题里写“烧写”不扣分，但“编程”才是这一代器件的准确说法，答题用后者。

## 编程器自己搭：地址数据都拿端口锁存

有了思路，你们下去实践自己都能设计编程器。先别追求和市场产品比性能，先叫它通了，再完善。

新片假定空白，有数据先放紫外线擦除器照干净。地址码不直接挂系统总线，拿输出端口锁存：`8088`数据线只有`8`根，一个`8`位端口锁存做`2764`低`8`位地址`A0～A7`，再一个端口取数据线低`5`位`D0～D4`锁存做高`5`位`A8～A12`，凑齐`13`根。每个端口有片选，由系统地址译码产生，`OUT`指令写进去锁存；两端口全锁`0`，选中的就是`0000H`单元。

数据同样拿输出端口锁存：`OUT`指令把待写数据送过去。地址数据就绪后：`VPP`加高压（手动开关或软件控制电子开关都行），`PGM`非加一个负脉冲，厂家标准约`50ms`（允许`±10%`误差），数据就写进该单元了。写入期间`OE`非必须保持高电平，禁止输出。

```text
OUT 锁存低8位地址 ─→ A7 ~ A0
OUT 锁存高5位地址 ─→ A12 ~ A8
OUT 锁存待写数据  ─→ D7 ~ D0
        │                加 VPP 高压 (+21V~+25V)
        └──── PGM非 加 50ms 负脉冲 ─→ 数据写入该单元
（写入期间 OE非 = 1；上电先 VCC 后 VPP，断电先 VPP 后 VCC）
```

读图说明：三路`OUT`备好地址和数据，高压加负脉冲一次写一个字节，`OE`全程禁输出，上下电顺序反不得。

> **易错点**：`VPP`高达`+21V～+25V`，`VCC`才`+5V`，编程器里一个叫高压一个叫低压。上电先低压后高压，拔片前先关高压后关低压，顺序错了芯片就坏了。

## 写完必校验：读回比对，不等就重写

写完一个字节立即校验：`CE`有效、`OE`有效，读出该单元数据，经输入通道回系统和原数据比对。相等，成功；不等，`OE`无效、`CE`有效，再加高压追加一次`50ms`负脉冲重写再比。多次还不一致，这个单元报废。

然后地址递增：低位送`01H`、高位送`00H`选中第`1`单元，`OUT`锁存数据，加高压加脉冲写。整片`8K`即`8192`字节，循环到全部写完。

## 本讲提到的题目

出一道题：“试叙述（或简述）`2764`的编程过程（编程步骤）”，会叙述吗？最简单三步加收尾：

1. 保证`2764`擦除干净（空白片，有数据先紫外擦除）；
2. 给地址引脚加要编程单元的地址码，给数据引脚加该单元的数据，做好准备；
3. `VPP`端加编程电压，`PGM`非端加`50ms`左右负脉冲，数据写入该单元，再读出来检验；
4. 重复`8K`次，编程完毕。
