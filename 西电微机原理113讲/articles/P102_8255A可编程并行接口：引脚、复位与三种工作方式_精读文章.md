# 8255A可编程并行接口：引脚、复位与三种工作方式

按道理下来应该讲第九章，我先讲第十章。原因是第十章安排的是可编程并行接口芯片，`Intel`公司生产的`8255A`，主要讲这个芯片和它的应用。从第七章讲到现在，讲的都是并行接口：设计`8`位并行输出端口用`74LS374`，设计`8`位并行输入端口用`74LS245`。这就是我的由头：常用芯片做的并行端口，一旦电路设计好、板子焊上，就不可改变了，做输出只能做输出，做输入只能做输入，想改就得动烙铁破坏板子。可有些场合我不希望这样：板子做好了，什么时候这个`8`位端口做输出、什么时候做输入，我要能改变，还不想破坏硬件，怎么办？上可编程器件。编程序向它内部的工作方式控制寄存器端口`OUT`写不同命令，就能改变工作方式。

学任何复杂一点的接口芯片，按我的经验分两步：第一步先看外部，看引脚哪个怎么定义、引脚之间配合有什么时序，把外部特性掌握了；第二步看内部结构，在懂工作原理的基础上掌握编程。两步拿下，就该会应用了。实际工程中常用的可编程并行接口是`8255`，常用的可编程串行接口是`8250`和`8251`（姊妹片，大部分功能相同，还有点不相同）。

## 24根I/O线：PA、PB、PC三个端口

`8255`装在`40`条引脚的双列直插封装（`DIP-40`）里，是`TTL`器件。`40`个引脚好记：除掉`VCC`和`GND`剩`38`根，先说电源地，再两分——与外部设备相连的，和与系统总线（`CPU`一方）相连的。

说到`VCC`和`GND`插一句：`8255A`的电源地排列和常规`TTL`不一样。一般`TTL`左上角是`VCC`、右下角是`GND`，`8255A`不是，它的电源在上方中间某个引脚，地在下方中间某个引脚，具体查手册。千万别拿到器件就认定`VCC`一定在左上角。

再插一句悬空脚：数电课讲过`TTL`悬空按高电平处理，实际工程不一定。我就发现`8255`好多引脚悬空时按低电平处理了。所以实际工程中，多余不用的门输入端必须确保接高电平，接到电源上去。

与外部设备相连的一共`24`根：它是并行接口，一个端口`8`位，共有`3`个`I/O`端口，`3 × 8 = 24`，分别叫`A`端口、`B`端口、`C`端口（`PA`、`PB`、`PC`）。

`PA`口（`PA0`～`PA7`）既可做输出也可做输入：`CPU`执行`OUT`朝`PA`写数据，它就是输出；执行`IN`把外设数据读回`AL`，它就是输入。具体做输出还是输入，可编程确定。`PB`口（`PB0`～`PB7`）同样既可输出也可输入。`PC`口（`PC0`～`PC7`）既可单独做`8`位并行输出或输入，也可拆成两个`4`位端口：高`4`位`PC4`～`PC7`，低`4`位`PC0`～`PC3`。

## A组B组：PC口高低四位的归属

`PC`口能拆，拆开跟谁过？`PA`口某些工作方式下需要借`PC`口高`4`位的引脚做联络线，所以`PA`口`8`根加`PC`口高`4`位，这`12`根统称`A`组`I/O`线。同理，`PC`口低`4`位加`PB`口`8`根，共`12`根，统称`B`组`I/O`线，分组管理。至此`24`根`I/O`引脚介绍完毕。

```text
+-------------- 8255A (DIP-40) --------------+
| PA0~PA7 ---+                               |
|             +-- A组12线 --+                |
| PC4~PC7 ---+              |                |
|                             +-- 外设侧24线 |
| PB0~PB7 ---+              |                |
|             +-- B组12线 --+                |
| PC0~PC3 ---+                               |
| D0~D7 / RD非 / WR非 / CS非 / A1 A0 / RESET |
+--------------- CPU(总线)侧14线 -----------+
```

读图说明：`24`根归外设、`14`根归总线、剩下`VCC`与`GND`，`40`脚一次点清，分组先为方式`1`/`2`借联络线埋好伏笔。

## 工作方式控制寄存器与RESET复位

`8255`内部有一个工作方式控制寄存器端口，`8`位。编程序用`OUT`向它写不同的工作方式控制命令字，就能设置`A`口、`B`口、`C`口的工作方式：做输入还是输出，工作在何种方式下。

`8255`要正常工作，上电必须复位，复位端`RESET`高电平有效。系统应用中有条铁律：外设接口的复位完成应该超前于`CPU`复位。以前有位做工程的朋友碰到过这样一件事：硬件查了没问题，软件也对，`8255`就是调不通，最后查出：`CPU`复位结束开始执行程序、一上来就初始化`8255`，可此时`8255`还在复位中；等`8255`复位完成，`CPU`初始化的时机早错过了，`8255`一直没被初始化，当然不工作。所以施加的复位信号虽与`CPU`同步复位，复位脉冲宽度必须满足：芯片的复位宽度小于等于`CPU`的复位宽度。

复位信号两种来法：一是从系统总线拉，系统上电给`CPU`的`RESET`若已引到总线，直接拉过来，上下电同步复位、协同工作；二是总线没提供`RESET`，自己用`RC`充放电电路上电产生，时间常数`τ = RC`决定的复位宽度必须小于`CPU`的`RESET`宽度。

## 读写控制与片选寻址

`8255`有读控制`RD非`和写控制`WR非`（低有效）。`PC`总线、`8088`、`8086`最大方式系统总线：`RD非`接系统总线的`IOR非`，`WR非`接`IOW非`。`8086`最小方式：`RD非`直接接`CPU`的`RD非`，`WR非`直接接`WR非`。

片选`CS非`（低有效）是片外寻址。`8086`给`I/O`的寻址空间是`64KB`，芯片分到的基地址由片外译码定；芯片内部还有片内寻址：`PA`、`PB`、`PC`三个数据端口各占一个地址，工作方式控制寄存器占一个地址，一片`8255`内部共`4`个`I/O`端口，靠片内地址引脚`A1`、`A0`区分：

| `CS非` | `A1` | `A0` | 选中的内部端口 |
| :---: | :---: | :---: | :--- |
| `0` | `0` | `0` | `PA`口数据端口 |
| `0` | `0` | `1` | `PB`口数据端口 |
| `0` | `1` | `0` | `PC`口数据端口 |
| `0` | `1` | `1` | 工作方式控制寄存器端口 |
| `1` | `×` | `×` | 未选通，数据脚高阻态 |

与系统总线怎么连，看总线位宽。`PC`总线、`8088`系统（`8`位）：`8255`的`A1`接系统`A1`、`A0`接系统`A0`，更高位（`A2`～`A15`）参加译码生成`CS非`。`8086`系统（`16`位，有奇偶对齐）：`8255`的`A1`接系统`A2`、`A0`接系统`A1`；分配偶地址端口（挂低`8`位`D0`～`D7`）时系统`A0 = 0`必须参加译码；分配奇地址端口（挂高`8`位`D8`～`D15`）时`BHE非 = 0`必须参加译码。

到这里数一数讲了多少引脚：`24`根`I/O`加读写、片选、地址、复位共`14`根是`38`，加电源地正好`40`，一个不少，很好记。如果考试有题叫你把`8255`和系统总线连起来，引脚不提示，平时就得背过。考试是闭卷的，考完就可以不背了，工程中查资料就行。

`8086`系统下还要注意：四个偶地址，`8255`的`D0`～`D7`和系统低`8`位相连；四个奇地址，和高`8`位相连。和前面做文章一模一样，后面就不再细讲了。

## 方式0：无联络的基本输入输出

`8255`一共三种工作方式：方式`0`、方式`1`、方式`2`。

方式`0`叫无联络信号的输入输出方式。抓住无联络：`PA`口工作在方式`0`，它和外设之间没有联络，等效于第七章的无条件输入输出方式。`PA`、`PB`、`PC`三个端口都能工作在方式`0`，做输入或做输出。

## 方式1：有联络的选通输入输出

方式`1`是有联络信号的输入输出方式。`PA`口工作在方式`1`，它和设备通信要有联络（握手）信号，设备是智能的，类似第七章的查询法，当然也可以工作在中断方式。

这种工作方式只有`PA`口和`PB`口有，`PC`口没了，只能工作在方式`0`。为什么？`PA`口工作在方式`1`要和设备联络，可引脚里并没有现成的联络引脚，就得靠`PC`口高`4`位充当联络线；`PC`口去给`A`口`B`口当联络线了，自己就不能再工作在方式`1`。`PC`高`4`位帮`A`口、`PC`低`4`位帮`B`口，正好就是前面`A`组`B`组的分法。

## 方式2：准双向的双向总线

方式`2`叫双向工作方式，有联络信号的双向输入输出。方式`0`和方式`1`一旦定死，一个端口要么只能输出、要么只能输入；方式`2`下一个端口既能输出又能输入。但这个双向是准双向：发的时候不能收，收的时候不能发。

准字怎么理解？手机通信是双向的，收音机是单向的，保安拿的对讲机就是准双向：按住按键喂喂喂是发，松开听对方说是收，发时不能收、收时不能发。数据串行通信里单工是单向，双工是双向，半双工就是准双工，一个意思。

方式`2`只有`PA`口有。`PA`口做输出要一对联络线（我给你了、你取走了），反过来做输入又要一对联络线（你给我了、我取走了），加上中断方式还要一根向`CPU`请求中断的线，都从`PC`口借。借完了`PB`口就再没法做方式`2`，联络线不够用了。
