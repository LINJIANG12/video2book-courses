# 8255A片选译码与开关量采集实例

`8255`与系统总线接口，还剩片选译码里的控制信号没说透，补上。然后进本章最后一个知识点：`8255A`的应用，拿例`10.1`从头到尾走一遍读图、算地址、编程序。

## 片选译码：控制信号必须参加译码

`8255`与系统总线接口时，片选译码电路设计中高位不变地址要参加译码，这是老规矩。全地址译码还是部分地址译码，看题目具体要求。但这里主要解释的是：控制信号与出来要等于`0`去参加译码。

控制信号等于`0`，表明`CPU`正在对`I/O`端口执行读或写。此时只要地址吻合，片选必然有效。如果`I/O`地址译码里控制信号没参加，会出什么问题？举个例子：`CPU`正在对存储器读写，而那组存储器单元的低`16`位地址刚好和我们设计的`I/O`端口地址一致。`CPU`读写存储器时地址匹配，`I/O`译码器输出也有效，`8255`片选有效，`D0`～`D7`经驱动器和系统总线接通；可系统总线上还连着正在读写的存储器芯片的数据线，同一根线上同一时刻两个驱动源竞争总线状态。所以`I/O`地址译码除了地址线，控制信号必须参加译码，工程设计一定注意。

不同总线控制信号接入规则：`PC`总线，把`AEN = 0`（允许`CPU`访问`I/O`，非`DMA`周期）引入参加译码；`8086`最小方式，`M/IO非 = 0`代表`I/O`操作，直接做使能条件参加译码；`8088`系统，对应的是`IO/M非 = 1`参加译码。把这些概念融合，`8255A`和各种系统总线的连接要点就齐了。

## 8255A的应用：等效三片常用芯片

本章第六个、也是最后一个知识点是应用。先从逻辑本质上理解`8255`：一片`8255`有`PA`、`PB`、`PC`三个`8`位数据口。如果三个端口都工作在方式`0`输出，功能等效于第七章讲的三片`74LS374`输出锁存器；如果都工作在方式`0`输入，等效于三片`74LS245`或`74LS244`输入缓冲器。所以工程中`8255A`应用十分广泛。

顺带说一句：现代电子技术里，分立的`374`、`245`还是`8255`，都可以直接用`FPGA`替换设计。只要底层硬件工作原理吃透了，就能用硬件描述语言在`FPGA`里实现。但用`FPGA`设计功能电路，前提是对原始芯片的功能和原理有清晰透彻的理解。

## 例10.1：给定译码电路反求端口地址

看例`10.1`。先别管题目要实现什么功能，先看给出的硬件译码电路。以前都是已知端口地址画译码电路，现在反向练：给定硬件译码电路，读图加逻辑分析，求分配给`8255`的端口地址是多少。

先列全部`16`位地址线`A15`到`A0`，看译码电路里的门。电路里有个或门，`A15`～`A11`全接在或门输入端，或门输出要为`0`，对应地址线取值必须全`0`。`A10`也经或门逻辑输入为`0`，再逐级分析`A8`、`A6`的组合。`A5`到`A3`均为`0`。`A9`、`A7`经过反相输出，反相输入为`0`输出才得`1`，所以`A9 = 1`、`A7 = 1`。

`A2`接`8255`的`A1`引脚，`A1`接到`A0`引脚，这些地址线参加译码选中基地址。高位拼出来是`028H`。又接`A0 = 1`、`BHE非 = 0`，说明接在`8086`系统总线高`8`位数据线，分配的是奇地址。后两位由`A2`、`A1`定：`00`是`PA`端口，`01`是`PB`端口，`10`是`PC`端口，`11`是方式控制寄存器端口。对应地址：`0281H`是`PA`口，`0283H`是`PB`口，`0285H`是`PC`口，`0287H`是方式控制寄存器端口。地址分析出来了。

这个译码电路能看出一点毛病。题目说是`8086`最小方式，最小方式下`M/IO非 = 0`才能参加译码，这样才能保证片选有效时`CPU`正在执行`IN`或`OUT`。对四个端口任一个执行`IN`/`OUT`，片选都有效，这是对的。数据总线因为是奇地址，`8255`的`D7`～`D0`接到`CPU`的`D15`～`D8`高`8`位。

题目第`1`问要求画系统总线与`8255`的连接图。其他连接都简单，但连接图里`8255`和系统总线少连了一个`RESET`复位引脚。假定系统总线提供了上电复位信号，必须连过来，至少这样做。不接`RESET`，`8255`不会正常工作：只有上电复位后，才能初始化并开始工作。

## 开关读入与LED输出：方式字90H

题目接着要求：从一个端口读`8`位开关量（非`0`即`1`，外设就是`8`个开关），从另一个端口输出，用`LED`指示。读入是`1`灯亮，读入是`0`灯灭。设计：输入端口选`PA`口接开关，`PA`初始化方式`0`输入；输出端口选`PB`口接`LED`，`PB`工作在方式`0`输出。

方式控制字：最高位标志`D7 = 1`；`A`组方式`0`（`D6D5 = 00`），`PA`输入（`D4 = 1`）；`PC`高四位没用设`0`（`D3 = 0`）；`B`组方式`0`（`D2 = 0`），`PB`输出（`D1 = 0`）；`PC`低四位没用设`0`（`D0 = 0`）。拼出来是`90H`。

```assembly
MOV DX, 0287H
MOV AL, 90H
OUT DX, AL
MOV DX, 0281H
IN AL, DX
```

`0287H`是方式控制寄存器端口，`90H`一写，`PA`方式`0`输入、`PB`方式`0`输出，方式设置完成；`0281H`是`PA`端口，一读，`8`位开关量进`AL`。

## 输出反相：软件NOT与硬件反相器

书上电路里`PB`口接的发光二极管阳极接到`VCC`电源。这种接法下，引脚输出低电平（`0`）灯亮，输出高电平（`1`）灯灭。可题目要求输入`1`灯亮、输入`0`灯灭，逻辑反了。两种解法：

方案一软件取反（书本做法），输出前求反：

```assembly
NOT AL
MOV DX, 0283H
OUT DX, AL
```

注意`PB`口地址是`0283H`。数据求反再输出，读入`1`出去变`0`，灯亮，对上了。

方案二硬件加反相器：`PB`口和发光二极管之间加硬件反相器，软件里`NOT AL`就省了。对照一下：加硬件反相器增加物料成本，不加改用`NOT`指令占用`CPU`执行时间；但反相器不只解决反相，还有驱动放大与电气隔离的作用。

如果要实时监控，开关一动灯就跟着变，程序末尾加无条件跳转`JMP`循环回去重读重输出。但实际工程不能只用无条件死循环：系统陷进去无响应，俗称死机，`CPU`只能空转。所以必须加人机干预程序，比如检测键盘按键，用户按特定键能安全退出返回操作系统。

## 本讲提到的题目

**例10.1（读图求地址并编程）**：`8086`最小方式下给定`8255`译码电路与开关`LED`电路。要求：`1` 求分配给`8255`的四个端口地址并画出系统总线连接图（含`RESET`、`M/IO非`参加译码、`D7`～`D0`接`D15`～`D8`）；`2` 从`PA`口读`8`位开关量，从`PB`口输出驱动`LED`（输入`1`灯亮、输入`0`灯灭）。

解析：读图得基址`028H`加奇地址（`BHE非 = 0`），四个地址为`0281H`（`PA`）、`0283H`（`PB`）、`0285H`（`PC`）、`0287H`（控制）；`PA`方式`0`输入、`PB`方式`0`输出，方式字`90H`（`MOV DX, 0287H` / `MOV AL, 90H` / `OUT DX, AL`）；`MOV DX, 0281H` / `IN AL, DX`读开关；阳极接`VCC`的`LED`低亮高灭，与题意反一拍，软件`NOT AL`后`OUT`到`0283H`，或硬件加反相器（兼驱动隔离）；末尾`JMP`循环做实时监控，并加键盘退出的人机干预，避免死循环无响应。
