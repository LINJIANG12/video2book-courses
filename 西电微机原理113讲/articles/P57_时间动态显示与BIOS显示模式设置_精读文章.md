# 时间动态显示与BIOS显示模式设置

4.39 题第四问拿到时间了，怎么在屏幕方框里动起来？流程不长，但每一步都不能省：取出来是二进制，直接打不出来，得转十进制再转 `ASCII`，摆好光标打上去，打完再取，无限循环，屏幕就是电子表了。再往下，上机交活还得会清屏弹菜单，这就得请 `BIOS` 出来了。

## 二进制时间显示流程

在方框处显示，第一步设光标，定位到指定位置，然后依次：显示时，显示冒号 `:`，显示分，显示冒号，显示秒。

系统取到的是二进制时间。要打出来，先编程序把二进制转十进制，除 10 取余法。转完十进制还不能打，得转数字字符，转 `ASCII` 码，转完才能送显示。

显示两种走法：一位一位打，用 `DOS 02H`（`AH=02H`）；统一放缓冲，末尾写 `$`，调 `DOS 09H`（`AH=09H`）一次打串。都行。

打完再去取时间，取到新二进制再转十进制，再转 `ASCII`，再打，再取。不断循环，屏幕时间就动起来了。流程看着烦，科学上一步不多。

## 临界闪烁频率与刷新要求

动态刷多快才不晃？记一个概念：肉眼临界闪烁频率约 $40\text{Hz}$。低于 40，明显抖；高于 40，分辨不出。传统 `CRT` 场频做 50 或 60，就是让人感觉不到晃。时间动态显示就按这个逻辑搭。

## 上机界面组织要求

4.39 题编完编译链接生成可执行，`DOS` 下一跑：先清屏干净，屏幕中央弹个窗口，显示 1、2 选项菜单，背景可放大，输出时还能设屏幕底色、窗口底色、字符前景色。这些都得靠 `BIOS`。

## BIOS中断分类

做上机作业，`DOS`/`BIOS` 手册用时再查就行。跟 `DOS` 统一用 `INT 21H` 不同，`BIOS` 按类别类型号不同：

| 服务 | 中断 |
| :--- | :--- |
| 屏幕显示 | `INT 10H` |
| 磁盘驱动 | `INT 13H` |
| 键盘输入 | `INT 16H` |

## INT 10H 00H设置模式与清屏

`BIOS INT 10H 00H` 设显示模式，就是设分辨率：

```assembly
MOV AH, 00H
MOV AL, 03H
INT 10H  ; 彩色文本模式
```

功能号送 `AH`，模式送 `AL`。`AL=03H` 进彩色文本模式。模式有彩色文本、彩色图形、黑白文本、黑白图形。文本模式以字符为单位，整屏：

$$80\text{列} \times 25\text{行}$$

80 是每行列数，25 是行数。`DOS` 下不管屏幕多少东西，只要执行 `00H`，都有清屏作用。清完光标自动回左上角，左上角坐标 $(0,0)$，第 0 列第 0 行。列是横向 `X`，0 到 79；行是纵向 `Y`，0 到 24。

## 显存容量与页面划分

文本模式每屏：

$$80 \times 25 = 2000\text{字符}$$

2000 字符约 2KB（标准 2KB=2048 字节）。显卡文本显存一般 8KB，按每页 2KB 划，正好 4 页：

```text
8KB显存 +------------------+
       | Page0  2KB (0页)  | BL=0选中
       +------------------+
       | Page1  2KB (1页)  |
       +------------------+
       | Page2  2KB (2页)  |
       +------------------+
       | Page3  2KB (3页)  |
       +------------------+
```

程序设 `BL=0` 就是选 0 页，往下选 1、2、3 页。后面设光标、打字符都要先说清在哪页上。
