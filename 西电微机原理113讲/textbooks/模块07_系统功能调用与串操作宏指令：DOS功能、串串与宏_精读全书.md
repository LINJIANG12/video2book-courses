## 第 1 章：DOS 01号功能与跳转表多分支设计
> 对应分集：P53 | 原始标题：《DOS 01号功能与跳转表多分支设计》

系统功能调用那么多，上机先用哪个？我们从附录 B 381 页的 `DOS` 功能表看起。表没列全，`BIOS` 表更是没附上，你们用到自己上网搜一下就行。看表要会看：最左一列功能号，`00` 号、`01` 号、`02` 号编下去；第二列是功能叙述；第三列是调 `INT 21H` 之前要准备的入口参数，用 `MOV` 往哪个寄存器写；最后一列是出口参数，调完看哪里。这门课上机要用的，我先说 01 号。

### 带回显控制台输入01H

01 号是带回显的控制台输入，表上地方小写得不清楚，我展开：等待用户从键盘输入一个字符。

比如 4.39 题，让你从键盘输 1 到 5，按 1 完成什么，按 2 完成什么。程序跑到这，怎么输？先把功能号给 `AH`，381 页最左列写得很清楚，功能号在 `AH` 中：

```assembly
MOV AH, 01H
INT 21H
```

01 号不需要入口参数，直接 `INT 21H`。`CPU` 一执行就等在这了，下面不跑了，一直等到用户按一次键。一直没按就一直等。一按键，被按字符回显到屏幕当前光标处，`DOS` 界面就是这样。同时被按字符的 `ASCII` 码放在 `AL` 里。你按的是哪个键，测 `AL` 就知道了。等待时它还检测是不是 `Ctrl+Break`，如果是就退出用户程序回 `DOS`。

### 输入合法性检查

拿到 `AL` 就能 `CMP` 了。可 4.39 题按 1 到 5，直接一个一个比太麻烦，还容易按错。按到 0、按到 6 呢？得重来：

```assembly
AGAIN:
    MOV AH, 01H
    INT 21H
    CMP AL, '1'
    JB  AGAIN
    CMP AL, '5'
    JA  AGAIN
```

低于 `'1'`，按到 0 上去了，跳 `AGAIN` 重输；高于 `'5'`，按到 6 上去了，也重输。这里应该用 `JA`，字符是无符号数，用 `JG` 就按带符号转了。否则肯定是 1 到 5，往下走。

可往下怎么分？是 1 就比，相等跳 1 功能，不是再跟 2 比……要是有 99 个功能，`CMP` 99 次，前面全是无用功，效率太低。我们要找一种不管按几，转到入口花的时间一样多的方法。

### 数据段地址跳转表

程序往下本来就是功能一一段、功能二一段……每段首址都有标号 `J1`、`J2`……标号一定就有段地址、偏移地址属性。利用这个，在数据段建个表：

```assembly
DATA SEGMENT
TABLE DW J1, J2, J3, J4, J5
DATA ENDS
```

`TABLE` 字单元放 `J1` 的 `OFFSET`，`TABLE+2` 放 `J2` 的 `OFFSET`，往下排。这就是地址表，汇编后：

```text
TABLE   : OFFSET J1
TABLE+2 : OFFSET J2
TABLE+4 : OFFSET J3
TABLE+6 : OFFSET J4
TABLE+8 : OFFSET J5
```

`J1` 相对表首位移 0，`J2` 位移 2，`J3` 位移 4，`J4` 位移 6，`J5` 位移 8。输入的 `n` 跟位移什么关系？

$$(n-1) \times 2$$

`n=1` 位移 0，`n=2` 位移 2，`n=3` 时 `3-1=2`，`2×2=4`，对上了吧？找到这个关系，跳转就是在表里取目的地偏移给 `IP`，段内间接寻址，转移地址寻址方式：

```assembly
AND AL, 0FH  ; 字符变数字，高4位清零
SUB AL, 1    ; n-1
SHL AL, 1    ; (n-1)*2
CBW          ; 字节扩展到AX，AH=0
LEA BX, TABLE; BX指表首，段地址默认DS
ADD BX, AX   ; BX += (n-1)*2
JMP WORD PTR [BX] ; 取一字当地址给IP
```

按 3 就是加 4，`[BX]` 间接找到那个单元，取一字不当数据当地址给 `IP`，一下跳过去。不管按 1 还是 5，运算跳转花的时间一样多。这种多分支叫跳转表法：把每个分支目的地偏移都建表，跳转时在表里找地址给 `IP`，效率明显高。4.39 题一开头就要搭这个架子。

> **提示**：`AND AL,0FH` 是字符转数字的关键。`'1'` 到 `'5'` 高半字节都是 3，低半字节正好 1 到 5，清掉高 4 位就剩数字了。

### 代码段转移指令跳转表

跳转表也可以定义在代码段。前面 `MOV AH,1`、`INT 21H`、合法性检查一样，下来：

```assembly
AND AL, 0FH
CBW
; A处
TABLE: JMP SHORT J1
       JMP SHORT J2
       JMP SHORT J3
       JMP SHORT J4
       JMP SHORT J5
```

`TABLE` 是个标号，表里放的不是目的地地址，而是无条件转移指令。按 1，程序想办法跳到这条 `JMP SHORT J1`，搭个桥二次转移到 `J1`；按 2 跳到第二条，二次转到 `J2`，往下一样。理解了没有？数据段表是一次取地址，代码段表是二次搭桥，思想都是跳转表。

## 第 2 章：回车换行控制与DOS 06H非阻塞输入
> 对应分集：P54 | 原始标题：《回车换行控制与DOS 06H非阻塞输入》

第一章我就让你们背：`'0'` 到 `'9'`，`'A'` 到 `'Z'`，记不全到 `Z` 起码 `'A'` 到 `'F'` 大小写，`ASCII` 必须拿下。那些能在屏幕直接显示的叫可视字符。今天补几个屏幕不显示字形的：回车 `CR 0DH`，换行 `LF 0AH`，空格 `SP 20H`，都叫非可视字符。别小看这俩，菜单显示、4.39 题人机提示全靠它。

### 回车与换行的分工

假设 `DOS` 界面满屏字，光标在末尾闪。现在我要把下一句话打到下一行最左端，光标怎么过去？很多人以为回车就到下一行，错了。

- 回车：只回当前行最左端。
- 换行：只下移一行，列不动。

必须两个都做，才到下一行最左端：

```assembly
MOV AH, 02H
MOV DL, 0DH  ; 回车
INT 21H      ; 回当前行最左
MOV AH, 02H
MOV DL, 0AH  ; 换行
INT 21H      ; 下移一行
```

先回后换、先换后回效果一样。4.39 题一句话显示完要显示下一句，就得来一次回车换行。用得太多，直接编成子程序，要用 `CALL` 一下就行。

### 系统功能调用分类回顾

上一节到 3.12 过程调用与返回，3.12.5 系统功能调用分两类：`DOS` 高级功能调用，`BIOS` 低级功能调用。上节介绍了：

- `01H`、`07H`、`08H`：都是等键盘输一个字符，区别在有无回显、响不响应 `Ctrl+C` 这些细节。
- `02H`：向屏幕输出一个字符，待输出放 `DL`。
- `05H`：向打印机输出一个字符，同样放 `DL`。

今天接着看 `06H`。

### DOS 06H直接控制台输入输出

`06H` 全称直接控制台输入输出，既能输又能出。输还是出，进之前看 `DL`：

| 进入条件 | 执行动作 |
| :--- | :--- |
| `DL=00H` 到 `FEH` | 输出，`DL` 里 `ASCII` 打到屏幕 |
| `DL=FFH` | 输入，从键盘读一个字符 |

```assembly
MOV AH, 06H
MOV DL, 0FFH ; FFH表示转输入检测
INT 21H
```

`01H`、`07H`、`08H` 没按键会挂起等，`06H` 做输入不等待，非阻塞，瞬间测一下就回来。程序不等的目的是非阻塞检测键盘。

### ZF判断与ESC分支逻辑

不等，怎么知道有没有键？看零标志 `ZF`：

- 无按键：$ZF=1$
- 有按键：$ZF=0$，且被按字符 `ASCII` 自动进 `AL`，跟 `01H` 一样键值在 `AL`。

所以调完紧接着测 `ZF`：

```assembly
MOV AH, 06H
MOV DL, 0FFH
INT 21H
JZ  NO_KEY    ; ZF=1无键，去NO_KEY
CMP AL, 'Q'   ; ZF=0有键，AL里是键值
; ...分支...
NO_KEY:
; ...无键处理...
```

教材 156 页 4.39 题几乎每问都要这个：功能做完暂停，提示按任意键继续，或测特定控制键，靠的就是这个机制。

需求细化一下：如果按的是 `ESC`，回主菜单；不是 `ESC`，这功能重做一遍。`ESC` 的 `ASCII` 就是 `1BH`。有键了，`AL` 跟 `1BH` 比：

```assembly
CMP AL, 1BH
JE  MENU    ; 相等是ESC，回总入口主菜单
JMP FUNC    ; 不等是别的键，重做该功能
```

相等 `JE` 回开头主菜单，不等 `JMP` 回该功能入口重做。讲 `06H` 就是为了解决这类题：每问做完测按键，没按继续干活，按了再看是不是 `ESC`，是回总入口，不是重做。4.39 题每问都是这个套路。

## 第 3 章：DOS 09H显示字符串与0AH输入串
> 对应分集：P55 | 原始标题：《DOS 09H显示字符串与0AH输入串》

有人问我：我按键时 `CPU` 没执行它，跑过去了，是不是抓不住？不对。你按下去抬起来再快也得几十毫秒，`CPU` 跑一遍才多快？从你按下去到抬起来，`CPU` 不知道跑了多少遍了，肯定抓得住。这个疑问消除了，这是 `06H` 的事。今天我们看串：前面都是一个字符一个字符来，工程里经常要一串，菜单 1 干什么 2 干什么，最后请选择 1 到 5，每行都是一串。一串怎么打出去？看 `09H`。

### 09H功能与DB定义字符串

`09H` 就是向屏幕输出一串。当然你用 `02H` 一个一个打，打多少次也行，可太啰嗦了。一般用 `09H`。

调之前先把串定义在数据段：

```assembly
DATA SEGMENT
STRING DB '2. EDIT'
       DB 0DH, 0AH, '$'
DATA ENDS
```

串肯定用 `DB`，用 `DW` 也能定，一对单引号最多俩字符，太啰嗦。`'2. EDIT'` 是菜单项，后面 `0DH`、`0AH`、`'$'` 干什么后面说。

4.39 题第二问让你们从键盘输一串，找 `ASCII` 最大的显示出来。做菜单要在屏幕打一行，也是串。先把数据段收尾，代码段：

```assembly
CODE SEGMENT
    ASSUME CS:CODE, DS:DATA
START:
    MOV AX, DATA
    MOV DS, AX
    MOV AH, 9
    LEA DX, STRING
    INT 21H
```

堆栈段没写，该声明还得声明。`DS` 初始化完，要显示了，先 `MOV AH,9`，立即寻址给功能号。第二步入口参数：`LEA DX,STRING`，被显示串首字符偏移给 `DX`，段地址在 `DS`，`DS:DX` 指串首。

内存里就是：`STRING` 单元放 `'2'`，下个放 `'.'`，下个放 `'E'`，一直下来最后放 `'$'`。准备好 `INT 21H`，`09H` 就从 `DS:DX` 取一个打一个。光标一开始在这，打 `'2. EDIT'`、回车、换行全出来了。可它取一个打一个光标右移一格，打完最后一个光标到这了，`09H` 没结束，再取再打。后面不是你的字符了，可存储器里还有值，读出来当 `ASCII` 打，满屏乱码。上机你们可以试试。

为什么？只告诉从哪开始，没告诉哪结束。所以必须告诉结束符，就是那个 `'$'`。遇到 `'$'` 就认为 `09H` 结束，`'$'` 本身不显示。

### 回车换行符位置安排

`'$'` 不显示，光标就停在最后可见字符后面。想打完这行自动落下一行行首，不停末尾，就在 `'$'` 前加回车换行：

```assembly
STRING DB 'Hello, World!', 0DH, 0AH, '$'
```

调 `09H`，遇到 `'$'` 前先输出 `0DH`、`0AH`，屏幕回车换行，光标到下一行起始。除了串尾直接定，也可单独编个回车换行子程序，打完 `CALL` 一下，两种都能用。主程序完退出照例：

```assembly
MOV AH, 4CH
INT 21H
CODE ENDS
END START
```

`09H` 三点：功能是打一串，入口是 `DS:DX` 首址，结束是 `'$'`。4.39 题按 1 进功能一，按 2 进功能二，先多次调 `09H` 打菜单，`1. ...`、`2. ...` 都得在数据段定好提示串。进功能一要把小写变大写，先 `09H` 打请输入字符串，打完处理完，输出前再 `09H` 打小写变大写后的结果是，最后才打结果串。人机对话就是这么搭起来的。

### 0AH输入串与缓冲区结构

`01H`、`07H`、`08H` 都是收一个字符进 `AL`，收一串得循环多次，太烦。`0AH` 专门从键盘输一串，自带等待，按回车 `0DH` 才结束。

一串寄存器装不下，必须在数据段开键盘输入缓冲区：

```assembly
DATA SEGMENT
KEYBUF1 DB 20H       ; 第1字节：允许最大个数(含回车)
        DB ?         ; 第2字节：系统填实际个数
        DB 20H DUP(?); 存输入字符
DATA ENDS
```

第 1 字节最大个数，比如 `20H` 就是 32 个，一个字节描述，理论最大 `0FFH=255` 个。第 2 字节实际个数，留着 `DOS` 回车后自动填，不含回车符。后面才是真正放字符的地方。

> **易错点**：`09H` 串尾必须有 `'$'`，`0AH` 缓冲首字节必须先填最大数。两个都是不填就乱，前者满屏乱码，后者多收少收全错。

## 第 4 章：十进制转二进制算法与DOS时间设置
> 对应分集：P56 | 原始标题：《十进制转二进制算法与DOS时间设置》

二进制转十进制用除 10 取余法讲过了，反过来呢？存储器某处一列十进制数，`BCD` 码放的，让你转二进制，什么算法？这就是乘法。今天把这个掰清楚，顺带把书上例 4.12、例 4.10 看了，再进 `DOS` 时间设置，4.39 题第四问做电子表要用。

### 十进制转二进制累乘10法

意思就是：2 乘 10，还没减到 0，加 0 括起来再乘 10；再减 1，还不等于 0，加 1 括起来再乘 10；一直算到减到 0 就不乘了。最后乘出来的和是不是二进制和？对。`CPU` 算：

$$2 \times 10 = 20$$

实际等于 `14H`，`CPU` 只认二进制，结果就是二进制。

工程上那一列十进制数，第一个拿出来乘 10，乘完就是二进制了，运算每一项结果都是二进制，因为 `CPU` 只认二进制。反过来记：二进制转十进制除 10 取余，十进制转二进制乘法累加，这点一定要注意。

### 例4.12公式与错误标志

翻第四章 123 页例 4.12，编子程序把一组 `ASCII` 表示的十进制数转 16 位二进制。`ASCII` 先变数字，再乘 10 相加、乘 10 相加，转成 16 位。

位数多了，乘加结果可能超 16 位。所以题目说：缓冲区第一字节表示位数，后面放十进制数，高位在前低位在后。超一个字范围，就在寄存器给错误标志。置 1 算错还是清 0 算错，自己定。

算法公式：设结果 `Y`，数字 `Xn` 到 `X1`，`X1` 最低，`Xn` 最高：

$$Y = 10 \times (\dots (10 \times (10 \times X_n + X_{n-1}) + \dots + X_3) + X_2) + X_1$$

展开：

$$Y = X_n \times 10^{n-1} + X_{n-1} \times 10^{n-2} + \dots + X_2 \times 10^1 + X_1 \times 10^0$$

这就是位权加权法，应该都看得懂。这个算法就是 4.39 题排序的内涵，下去自己看。

书 120 页例 4.10，子程序 `HEX16_TO_10`，16 位 16 进制（假设在 `AX`）转 10 进制放高速缓冲，是不是除 10 取余？第四章好多例题我都讲过，上节就让你们下去看例题，今天再强调：读多了阅读能力上去了，编写能力才上得去。

### 电子表显示形式

`DOS` 功能先到这。看 156 页 4.39 题第四问：按 `'T'` 显示时间。屏幕做个电子表，最简单：

```text
XX时:XX分:XX秒
```

图形学好的真画个表盘，时针分针秒针动，更漂亮。那是把屏幕看成图形格式，一个像素一个坐标。我们现在一个字符一个坐标，是字符格式，都可以。师傅领进门，修行靠个人，必须下去练。

### DOS 2DH设置系统时间

显示的是系统时间。获取可用 `DOS` 也可用 `BIOS`，校准可用 `DOS` 命令也可用程序，程序校准叫时间设置。从 `DOS` 看怎么设怎么取。

先看设置，`DOS 2DH`。黑板原误写 `0DH`，纠正为 `2DH`：

```assembly
MOV AH, 2DH
INT 21H
```

功能号放 `AH`。调之前入口放好，放 `CH`、`CL`、`DH`、`DL`：

| 寄存器 | 参数 | 范围 |
| :--- | :--- | :--- |
| `CH` | 时 | $0 \sim 23$ |
| `CL` | 分 | $0 \sim 59$ |

### INT 10H 00H设置模式与清屏

`BIOS INT 10H 00H` 设显示模式，就是设分辨率：

```assembly
MOV AH, 00H
MOV AL, 03H
INT 10H  ; 彩色文本模式
```

功能号送 `AH`，模式送 `AL`。`AL=03H` 进彩色文本模式。模式有彩色文本、彩色图形、黑白文本、黑白图形。文本模式以字符为单位，整屏：

$$80\text{列} \times 25\text{行}$$

$$80 \times 25 = 2000\text{字符}$$

2000 字符约 2KB（标准 2KB=2048 字节）。显卡文本显存一般 8KB，按每页 2KB 划，正好 4 页：

```text
8KB显存 +------------------+

       +------------------+
       | Page1  2KB (1页)  |
       +------------------+
       | Page2  2KB (2页)  |
       +------------------+
       | Page3  2KB (3页)  |
       +------------------+
```

程序设 `BL=0` 就是选 0 页，往下选 1、2、3 页。后面设光标、打字符都要先说清在哪页上。

## 第 6 章：串传送指令MOVS与数据块搬家
> 对应分集：P58 | 原始标题：《串传送指令MOVS与数据块搬家》

3.13 节串操作一共五种，上节已经点了名：传送 `MOVS`（`MOVSB`、`MOVSW`），比较 `CMPS`（`CMPSB`、`CMPSW`），扫描 `SCAS`（`SCASB`、`SCASW`），装入 `LODS`（`LODSB`、`LODSW`），存储 `STOS`（`STOSB`、`STOSW`）。每种都能按字节按字。今天先把第一条传送掰透，例 3.36 数据块搬家就是它。

### 四条隐含寻址规则

五种指令目的源全是隐含寻址，规则四条：

源在存储器，地址由 `DS:SI` 指明，隐含的，用前先对 `DS`、`SI` 初始化。源不在存储器在寄存器，字节隐含在 `AL`，字隐含在 `AX`。

目的在存储器，必须由 `ES:DI` 指明，目的串必须定义在附加段 `ES` 段。目的在寄存器，字节用 `AL`，字用 `AX`。

任何一条执行完，`SI`、`DI`（或其中之一，另一端在寄存器嘛）自动变。方向受 `DF` 控制：`DF=0` 自动增，`DF=1` 自动减。增减 1 还是 2看类型：字节增减 1，字增减 2。

任何一条左边都能带重复前缀。`REP` 等效 `LOOP`，`CX` 减 1。`REPZ`（`REPE`）等效 `LOOPZ`，`CX` 减 1 不等于 0 且 `ZF=1` 再来一遍。`REPNZ`（`REPNE`）等效 `LOOPNZ`。`REP` 能挂 `MOVS`、`LODS`、`STOS` 左边，`REPZ`、`REPNZ` 能挂 `CMPS`、`SCAS` 左边，具体哪边挂哪，我列过表。

### MOVSB执行三步过程

助记符 `MOVS`，格式 `MOVSB`、`MOVSW`，或 `MOVS 目的,源` 三种。

`MOVSB` 一条，`CPU` 干两步：第一步源送目的。源默认 `DS` 段 `SI` 作偏移，`MOVSB` 字节，`MOVSW` 字，送到目的，目的固定 `ES` 段 `DI` 指的单元。源目的全隐含。第二步 `SI`、`DI` 自动变，`DF=0` 增，`DF=1` 减，字节 1 字 2。

左边加了 `REP`，还没完，第三步 `CX` 减 1 给 `CX`，不等 0 重来一遍。执行多少遍受 `CX` 限制，相当于循环。传送是数据搬家，不影响 `PSW`。

第三种格式只告诉汇编按字节还是按字翻译，看两操作数定好的类型定。都是字节等效 `MOVSB`，都是字等效 `MOVSW`。实际不太灵，写就得两边类型一致，不然语法错。

跟 `MOV` 的区别记死：`MOVSB`、`MOVSW` 能存储单元到存储单元直接送，`MOV` 不能两单元直送。

书 74 页上方例子：前面 `DATA` 段、`DATA1` 段，`DS` 指 `DATA`，`ES` 指 `DATA1`，`DATA1` 就是附加段了。下面 `MOVS BUFFER2,BUFFER1`，`BUFFER2`、`BUFFER1` 在 `DATA1`（`ES`）用 `DW` 定义，汇编就按 `MOVSW` 编。源 `BUFFER1` 在 `ES` 段，源地址是不是 `ES:SI`？源段能用段超越改，目的段必须 `ES`，两概念不一样。

### 例3.36程序框架实现

书 75 页例 3.36，按标准完整程序设计。读题：`BUFFER1` 100 字节，按次序送 `BUFFER2`。`BUFFER1` 100 字节数据，`BUFFER2` 留 100 字节自由空间，数据块搬家。用串传送做：

```assembly
DATA SEGMENT
BUFFER1 DB 100 DUP(?)
BUFFER2 DB 100 DUP(?)
DATA ENDS
CODE SEGMENT
    ASSUME CS:CODE, DS:DATA, ES:DATA
START:
    MOV AX, DATA
    MOV DS, AX
    MOV ES, AX
    LEA SI, BUFFER1
    MOV DI, OFFSET BUFFER2
    MOV CX, 100
    CLD
    REP MOVSB
    MOV AH, 4CH
    INT 21H
CODE ENDS
END START
```

堆栈段省略了，黑板不够。数据段 `DB` 定义，实际工作把真数据写进去，作业写 `100 DUP(?)` 行。`BUFFER2` 是目的串，该在 `ES` 段，我都定在 `DATA` 了，所以声明 `DS`、`ES` 同一个段，`AX` 过一下都初始化成 `DATA`，都指 `DATA` 段地址。

`LEA SI,BUFFER1` 源有效地址给 `SI`，段在 `DS`。`MOV DI,OFFSET BUFFER2`（`LEA` 也行）目的偏移给 `DI`，段按串操作在 `ES`。`MOV CX,100` 重复次数给 `CX`。首址对首址搬一个，`SI`、`DI` 自动增 1，按地址增大搬，得确保 `DF=0`。开机、`RESET` 后 `DF` 就是 0，为保险排一条 `CLD`。然后 `REP MOVSB`，`CPU` 执行 100 遍，一遍搬一字节，源块到目的地。搬完 `4CH` 结束。

```text

              |搬100次|
目的 ES:DI -> [B2][B2+1]...[B2+99]  (DI+1/遍)
CX=100 -> 0 , DF=0 CLD保证增方向
```

## 第 7 章：串比较指令CMPS与相等搜索程序
> 对应分集：P59 | 原始标题：《串比较指令CMPS与相等搜索程序》

上节搬家留了个尾巴：每搬一字节 `SI`、`DI` 自动减，一直搬完 `CX` 个，从 `004BH`、`044BH` 倒着接过来，数据完整串过来。这样改完，工程上不用预先颠倒翻转源目的，有没有地址重叠结果都对。今天看第二类：比较。

### CMPS书写格式

助记符 `CMPS`，格式：字节 `CMPSB`，字 `CMPSW`，或双操作数：

```assembly
CMPS 目的操作数, 源操作数
```

由两操作数属性定字节还是字。

### 源减目的与标志设置

以 `CMPSW` 为例，两步。第一步比较。通用 `CMP` 是目的减源，串比较反过来，是源减目的：

$$(DS:SI) - (ES:DI)$$

源默认 `DS` 段 `SI` 偏移，目的限定 `ES` 段 `DI` 偏移，两字单元相减。结果既不破坏源也不破坏目的，只置 6 个状态标志 `CF`、`ZF`、`SF`、`OF`、`PF`、`AF`。最核心是 `ZF`：`ZF=1` 相等，`ZF=0` 不等。

第二步指针自动改：`SI`、`DI` 加 2 或减 2，`DF=0` 递增，`DF=1` 递减。通用 `CMP` 还得自己写增减，串比较自动更新。

### REPE重复比较过程

`CMPS` 左边能加 `REPE`（`REPZ`，相等重复）。带上，执行完两步走第三步，相当于 `LOOP`：

$$CX \leftarrow CX - 1$$

`CX` 减 1 不影响标志。然后看条件：`CX≠0` 且 `ZF=1`，重来一轮 1、2、3 步；任一不满足（`CX=0` 或 `ZF=0`）退出。

退出后怎么判是数完了还是比出不等？可用 `JCXZ` 测 `CX=0`，但最后一次恰好减到 0 的，严格得看 `ZF` 才准。这种串比较加重复，一下比完对应字符、对应字是否全同。

```assembly
CLD
MOV CX, 100
REPE CMPSW
; ZF=1全同，ZF=0在某处不等
```

### REPNE搜索相等元

`CMPSW`、`CMPSB` 前也能加 `REPNE`（`REPNZ`，不等重复）：`CX≠0` 且 `ZF=0` 继续，一找到相同（`ZF=1`）或比完（`CX=0`）立刻退。一个是相等才继续找不同，一个是不等才继续找相同，用反了就全错。

### 例3.37对应字搜索设计

例 3.37：`BUFFER1`、`BUFFER2` 各 100 个字的字缓冲区，对比数据，找到相同的字，在 `ADDR` 存它在 `BUFFER1` 中的偏移地址；没找到，`ADDR` 填全 1（`0FFFFH`）未找到标志。

存储器两块字缓冲，各连占 100 字，依次比对应位置字是否相等，不等比下一对，直到找到。找到存偏移，找不到填 `FFFFH`。思路就是 `CLD` 保增方向，`SI` 指 `BUFFER1` 首，`DI` 指 `BUFFER2` 首，`CX=100`，`REPNE CMPSW` 找第一个相等，退出看 `ZF`，`ZF=1` 找到，往回算偏移送 `ADDR`，`ZF=0` 没找到送 `0FFFFH`。

```text
DS:SI BUFFER1 -> [W0][W1]...[W99]
ES:DI BUFFER2 -> [W0'][W1']...[W99']
REPE/REPNE CMPSW : (DS:SI)-(ES:DI) -> ZF, SI+=2 DI+=2
```

> **易错点**：串比较是源减目的，不是目的减源；`CX` 减 1 不影响标志，别拿 `ZF` 判计数。

## 第 8 章：串扫描SCAS检索删除与串存储STOS清屏填充
> 对应分集：P60 | 原始标题：《串扫描SCAS检索删除与串存储STOS清屏填充》

比较是两串对着比，扫描是一个关键字在一串里搜。今天把 `SCAS` 搜透：搜到怎么定位，搜到空格怎么删，满屏 `'1'` 怎么找异类。然后把 `STOS` 补上，例 3.39 清零填 `55H` 就是它，期末最爱考这种小段。

### SCASB三步执行过程

助记符 `SCAS`，字节 `SCASB`，字 `SCASW`，还有双字 `SCASD`。按字节 `SCASB` 第一项就是源减目的。

比如缓冲一堆字节，搜有没有空格。先把空格 `ASCII` 送 `AL`，`AL` 当源，缓冲当目的串，用 `AL` 跟每个单元减：相等找到，不等没找到。初始化目的首偏移给 `DI`，段给 `ES`，核心就是减。

`SCASB` 两步：

$$(AL) - (ES:[DI])$$

差不保留，只置 6 标志，`ZF=1` 找到，`ZF=0` 没找到。第二步 `DI` 自动增减 1，方向 `DF` 定。这条不涉及 `SI`，`SI` 不变。

左边带 `REPNE`（`REPNZ`），走第三步：

$$CX \leftarrow CX - 1$$

`CX≠0` 且 `ZF=0` 重来，`AL` 跟自增后下一单元再减再置标志。

退出紧接着查 `ZF`：1 找到，0 范围内没找到。找到的实际偏移是：

$$DI - 1$$

因为匹配后第二步 `DI` 已自增 1，现在指匹配单元的下一个，得减 1 还原。

### 检索删除与异常字符搜索

题目让搜空格，找到删除。原位覆盖思路：`SCASB` 扫到 `ZF=1`，`DI` 已指下一位，把 `DI` 开始往后所有单元依次前移一位，盖到 `DI-1` 上，跟编辑器按删除后后面前移一样。移动次数看剩余 `CX`。要删所有空格，一次删完继续往下扫到完。

反过来，目的区全铺 `'1'`（`31H`）背景，找不是 `'1'` 的异类。左边配 `REPE`（`REPZ`）：相等继续，不等（`ZF=0`）立刻退，一退就是异类。

原地删搬移回退容易漏边界错指令。还有新建缓冲法：另开同大新缓冲，依次扫原缓冲，不是目标就拷过去，是目标跳过不传，新指针不增。扫完新缓冲就是剔完的。多占点内存，思路清不易错。汇编核心是选对算法逻辑。

### STOS串行通信应用

这段数据往这单元写，写完 `DI` 自动加 1 或减 1，下次 `STOSB` 又写下一单元。所以装入 `LODS`、存储 `STOS` 常被拿去做微机串行通信，发送接收同一套。`STOSB`、`STOSW` 也能带 `REP`，`AX` 写进去 `DI` 加 1，重复下去每单元都写进去了。

五条讲完补一句：`MOVS`、`LODS`、`STOS` 都是数据传送，执行不影响标志。只有 `CMPS`、`SCAS` 才影响标志。

## 第 9 章：IN OUT指令格式与输入端口译码电路
> 对应分集：P61 | 原始标题：《IN OUT指令格式与输入端口译码电路》

`IN`、`OUT` 是对 `I/O` 端口的指令，对端口输出就是 `OUT`，从端口读就是 `IN`。这块第七章以后才用，先把格式和时序拿下，再拿 8 开关读入做个译码例子。

### IN输入指令寻址方式

`IN` 双操作数，源是端口地址，目的是读回来的放哪。8086 有 20 根地址线 `A19` 到 `A0`，低 16 根 `A15` 到 `A0` 同时给 `I/O` 分配地址，所以 `I/O` 空间 64KB：

$$0 \sim 65535 = 0 \sim FFFFH$$

源写法：分给端口的地址 0 到 255，能直接寻址，直接写地址：

```assembly
IN AL, 20H  ; 直接寻址，源是端口地址
```

超 255 必须间接：先 `MOV` 地址给 `DX`，再 `IN AL,DX`。`DX` 当地址寄存器，存储器间接 `BX`、`SI`、`DI` 要打中括号，`I/O` 间接 `DX` 不打括号，语法一定注意。`DX` 里 0 到 65535 任何地址都能间接，直接只能 0 到 255。字节操作目的 `AL`，寄存器寻址。相邻两 8 位端口能组一字端口，字读 `AL` 换 `AX`，一次 16 位。

### OUT输出指令与总线周期等待

`OUT 目的,源`，源出到目的。字节源 `AL`，字源 `AX`，目的 `I/O` 地址。0 到 255 目的能直接写地址直接寻址，超 255 必须 `DX` 间接，0 到 255 也能间接。

特别一点：`IN`、`OUT` 比 `MOV`、`ADD`、`AND` 一般指令多一个时钟。`CPU` 加电复位后靠 `CLK` 引脚时钟节拍工作，一般指令 4 时钟，`IN`、`OUT` 5 时钟。`CLK` 下降沿同步：

```text
T1  T2  T3  Tw  T4  | 下条T1
|---|---|---|---|---|
            ^多出的等待周期Wait
```

`AL` 经数据线送端口，得占外部总线，这段时间叫总线周期。基本总线周期 4 时钟，`IN`、`OUT` 5 时钟。`T1`、`T2`、`T3` 后 `CPU` 自动插 `Tw` 等待再进 `T4`，下个时钟就是下条 `T1`。占外部总线的时间就叫总线周期，把握住。

### 8开关输入设备与244端口结构

比如输入设备是开关量：引脚接地 0，接 5V 1，开关打上 1 打下 0。8 个 `K0` 到 `K7` 开关就是 8 位设备。`CPU` 要拿状态，设备跟 `CPU` 不能直连，得经接口电路，接口至少含一个端口，一端口传一种信息。这是无条件、非智能设备，永远准备好，不是 1 就是 0，接口只含数据输入端口。

端口芯片输入常用 `74LS244`（`245`），8 位缓冲：`D0` 到 `D7` 输入，`Q0` 到 `Q7` 输出，内部 8 个三态门。控制端 `1E` 非、`2E` 非，`1E` 管 `D0` 到 `D3` 四门，`2E` 管 `D4` 到 `D7` 四门，8 门同时控就连一起当 `E` 非。`E` 非=0 变二态导通，设备 1 读 1，0 读 0；=1 三态高阻不工作。

`K0` 接 `D0`……`K7` 接 `D7`，`Q0` 到 `Q7` 经 `D0` 到 `D7` 低 8 数据线接 `CPU`。要读，先让 `1E` 非、`2E` 非=0，就得给端口分配地址。0 到 65535 分一个，比如 `8000H`，`A0` 到 `A15` 是 `8000H`，得设计电路把 `8000H` 转成控制信号。有效地址 `1` 后面全 `0`，16 输入或门（假设有），`A15` 先反再或，`A14` 到 `A0` 零或，全或得 0 就说明线上是 `8000H`。

### MIO与读信号参与译码

`A15` 到 `A0` 又给 `I/O` 又给存储器，怎么保证是对 `I/O`？8086 有输出 `M/IO` 非：存取总线周期输出高，`IN`、`OUT` 的 `I/O` 总线周期输出低。取低跟上面的 0 或，0、0 或得 0，输出低说明 `CPU` 对 `I/O` 读写且地址 `8000H`。

还不行。输入端口 `OUT` 写不能选中，只有读才能选，所以读控制信号=0 也得参加译码。再或一下，输出低说明：`CPU` 对 `I/O` 读，且读地址 `1000000000000000=8000H`，唯一了。拿它做 `1E` 非、`2E` 非，低导通，地址就翻成控制信号了。这就叫 `I/O` 地址译码电路。译码不光翻地址，控制信号也要参加，听懂了没有？

### 宏定义格式规则

```text

   ??0001:
```

读图说明：`LEA` 前面的加号说明这些行是宏体插入的；`NEXT` 是局部标号，编译程序第一次展开时自动把它变成 `??0000`，第二次展开变成 `??0001`。

`LOOP` 后面是不是 `NEXT`？但 `NEXT` 是个局部标号，编译程序就自动地把这个局部标号变成了问号问号 0000（`??0000`）。用这么一个标号代替了原来的局部标号 `NEXT`。汇编完了继续汇编，汇编到第二个调用处，宏体又要插入了，碰到的 `NEXT` 就用问号问号 0001（`??0001`）代替。

那你这样一看，不管插入多少次，标号是不是都在变？标号就不会重复定义。后面是四位数，是不是能调用 65536 次？这就解决了宏体中有局部标号时、程序中若干次调用发生的标号重复定义的矛盾。你要在底下生想，就闹懵了。明白了吧？这是在宏指令应用当中要注意的。

### 6 REPT、IRP、IRPC：留给自己消化

那么我们书上后面还讲了，84 页到 85 页，到 86 页，讲重复宏。重复宏里面有重复宏 `REPT`，不定重复宏 `IRP`，86 页还有不定字符重复宏 `IRPC`。不太用，留给自己去消化。所以本节就讲完了，整个本章也就讲完了。

### 本讲提到的题目

讲到宏和子程序对比时，提到有一年考试考过下面这道简答题，这里按课堂讲法还原。

**题目**：简述在程序设计中，采用宏指令定义的办法和采用子程序定义的办法各有什么优缺点？

**解析**：这道题就从空间和时间两句话去说，依据就是正文第 3 节的对比。采用宏：调用一次宏体插入一次，费程序存储器空间；但直线执行，没有 `CALL` 和 `RET` 的额外开销，省时间。采用子程序：模块只占一份空间，不管调用多少次都省空间；但每次调用多一条 `CALL`、返回多一条 `RET`，费时间。书上 3.16.5 节表 3.8 就是这两句话的总结，答全即得分。
