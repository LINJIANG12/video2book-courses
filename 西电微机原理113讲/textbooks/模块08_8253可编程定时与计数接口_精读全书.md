## 可编程计数器：让定时与分频由程序决定
> 对应块：BLK56 | 覆盖分集：P108-P109 | 块标题（分集名）：《108》

### 从实验室里“不能改”的计数器说起

在数字电路课上，大家可能已经接触过计数器，实验室里也做过 161 之类的计数器实验。我有一次去实验室，看到学生做的是模七计数，计数器已经被七段数码管显示出来了，可任务书上明明要求做模六。

我问他：“你会不会做模六？”

他说：“不会。”

我说：“那你在这里做模七干什么？”

他说：“书上写的是模七。”

我说：“书上写模七，你就做模七；现在老师让你改成模六，你不会，那这个实验就做不下去了。”

这看起来是一件小事，却把固定计数器和可编程计数器的分界线说清楚了。用 161 这样的芯片搭好电路以后，分频系数就固定了，电路一旦焊接完成，想从模七改成模六，就不能再靠改一条指令来完成，只能拿烙铁去破坏原来的连接。

可实际工程并不总是一块硬件只对应一个功能。电路焊好以后，我们可能希望在不同场合产生不同周期、不同占空比的定时波形，也可能希望同一个分频器在必要时换分频系数，又不想每次都拆板子、重新焊接。

这时候就需要可编程器件。8253 是这类器件中很典型的代表，后来的提高型是 8254。先掌握 8253，8254 的许多用法自然就容易理解了。

在较老的计算机主板上，8253、8259 中断控制器、8237 DMA 控制器等芯片曾经共同组成主板上规模较大的集成电路功能组。现在很多功能已经集成到更复杂的芯片里，主板上未必还能直接看见它们，但这些器件各自承担的功能并没有消失，使用它们时的基本思路仍然一样。面对 8253 这样结构比较复杂的器件，第一步仍然应该是先看外部特性，再看内部工作原理。

### 先认外部引脚

8253 采用双列直插式封装，共有 24 根引脚。除去电源和地，剩下的 22 根都是工作信号引脚。学习这类芯片时，可以先把引脚分成两组：一组和 CPU 或系统总线相连，另一组和外部设备相连。

| 类别 | 引脚 | 作用 |
| --- | --- | --- |
| 系统总线侧 | `D0`～`D7` | 传送方式字、计数初值，也把读出的数据送回 CPU |
| 系统总线侧 | `A1`、`A0` | 选择芯片内部的不同端口 |
| 系统总线侧 | `CS#` | 片选信号，低电平有效 |
| 系统总线侧 | `RD#` | 读控制信号 |
| 系统总线侧 | `WR#` | 写控制信号 |
| 外部设备侧 | `CLK0`～`CLK2` | 接收外部设备送来的计数时钟脉冲 |
| 外部设备侧 | `GATE0`～`GATE2` | 对相应计数器进行门控或触发 |
| 外部设备侧 | `OUT0`～`OUT2` | 输出定时结束、分频或工作方式所对应的波形 |

#### 三个独立的计数器

8253 内部有三个相互独立的 16 位计数器，分别叫计数器 0、计数器 1 和计数器 2。每个计数器都有自己的计数初值、计数状态和工作方式。

每个计数器有六种工作方式，编号为方式 0 到方式 5。方式不同，计数器的启动条件、计数过程和 `OUT` 输出波形就会不同；可是，三个计数器的基本外部引脚安排是相同的，都是 `GATE`、`CLK` 和 `OUT` 三个信号。

因此，分析某一个计数器时，可以把它单独拿出来看。以计数器 0 为例：

- `CLK0` 接收外部送来的基准时钟脉冲，8253 对这个脉冲的下降沿进行计数；
- `GATE0` 是门控信号，用来控制计数器是否接受启动或继续计数；
- `OUT0` 是计数器的输出端，用来输出定时结束信号，或者作为分频输出。

有的工作方式要求 `GATE` 保持高电平，门控有效时才接受 `CLK` 的下降沿；有的工作方式则把 `GATE` 的上升沿作为触发条件。也就是说，`GATE` 并不是所有工作方式下都简单理解为“高电平使能”，必须结合具体工作方式来看。

`OUT` 也不能只看成“计数器溢出信号”。某些方式初始化后输出低电平，定时到达后变为高电平；某些方式初始化后输出高电平，定时到达后变为低电平并保持一个时钟周期；还有的方式让 `OUT` 直接输出周期性波形。把这些现象放在一起看，`OUT` 才可以既解释为“定时时间到信号”，又解释为“分频输出”。

#### 级联和 8 位、16 位计数

如果一个 16 位计数器能满足要求，就让某一个计数器单独工作。实际应用中，分频系数需要很大，或者定时时间需要比一个计数器能够提供的时间更长时，可以把几个计数器级联起来。

级联的方法很直接：把前一级计数器的 `OUT` 输出接到后一级计数器的 `CLK` 输入。

```text
CLK0 ──► 计数器 0 ──► OUT0 ──► CLK1 ──► 计数器 1 ──► OUT1 ──► CLK2 ──► 计数器 2 ──► OUT2
```

这样，每一级的输出就成为下一级的时钟，最终可以得到更长的定时周期或更大的分频系数。一个计数器可以单独工作，也可以级联工作，这正是它比固定计数器灵活的地方。

> **提示**：16 位计数器的计数范围只有 0～65535 的量级。当一个计数器达到最大分频能力、定时时间仍然不够时，不能只盯着一个计数器想办法，而要想到级联。

另外，8253 的计数器不一定每次都按完整的 16 位使用。根据定时时间或计数值的要求，可以把一个计数器设置成 8 位计数，也可以选择 16 位计数值的低八位或高八位作为计数器使用。低八位计数只需写一个字节，高八位计数也只需写一个字节；完整 16 位计数则要分两次写入。

#### 8253 和 8254 的区别

8254 是 8253 的提高型，两者最明显的区别有两处。

第一，内部时钟频率范围不同。8253 的外部计数时钟上限按本课给出的规格是 2 MHz，超过这个频率时，8253 反应不过来，必须在外部先加分频器，把输入时钟降到 8253 能接受的范围内。8254 的外部时钟频率上限更高。课堂中提到过 5 MHz 和 8 MHz 两种数据，现场没有最终确定，实际使用时应当以手中型号的器件手册为准。

第二，8254 内部增加了状态寄存器。8253 没有这个状态寄存器；8254 可以把某个计数器的工作方式、`OUT` 引脚电平以及当前计数状态等信息锁存起来，再由 CPU 读出。8253 读计数器当前值时，仍然要先锁存输出锁存器，但这和 8254 的完整状态读回不是同一回事。

在 8253 所允许的 2 MHz 时钟范围内，按本课的讲法，8253 和 8254 的外部引脚是兼容的：把原来的 8253 拔下来，换成 8254，仍然可以按照原来的方式使用。

> **易错点**：8253 没有 `RESET` 引脚。只要程序已经完成初始化，工作中系统复位不会像复位普通寄存器那样自动改变 8253 的工作状态。

### 初始化：先写方式字，再写计数初值

#### 用 `A1A0` 选择内部端口

8253 内部虽然有三个计数器，但它们并不需要三个完全独立的地址。CPU 通过 `A1A0` 选择当前要访问的内部端口，`CS#` 有效以后，才能进行读写。

| `A1A0` | 写操作 | 读操作 |
| --- | --- | --- |
| `00` | 对计数器 0 写计数初值 | 读计数器 0 的当前计数值 |
| `01` | 对计数器 1 写计数初值 | 读计数器 1 的当前计数值 |
| `10` | 对计数器 2 写计数初值 | 读计数器 2 的当前计数值 |
| `11` | 对方式控制寄存器写方式字 | 8253 不适用；8254 可用于读回锁存的状态 |

所以，地址选择的基本关系是：`A1A0=00` 对应计数器 0，`A1A0=01` 对应计数器 1，`A1A0=10` 对应计数器 2，`A1A0=11` 对应方式控制端口。

这里有一个容易混淆的地方：三个计数器各自都需要一个方式控制寄存器，但这三个方式控制寄存器占用的是同一个地址。CPU 向 `A1A0=11` 的端口写方式字时，8253 还要根据方式字最高两位来判断：这个方式字究竟写给哪个计数器。

方式字的最高两位为：

- `00`：写给计数器 0；
- `01`：写给计数器 1；
- `10`：写给计数器 2；
- `11`：对 8253 来说是非法组合；对 8254 来说，可以用来发出状态锁存命令。

因此，看到 `A1A0=11` 还不能直接说“正在操作某一个计数器”，必须结合写入的最高两位来判断。写方式控制字时，最高两位就是片内计数器选择位。

#### 方式控制字每一位的含义

方式控制字是 8 位。把它拆开看，主要分成四组：

| 位 | 名称 | 含义 |
| --- | --- | --- |
| `D7D6` | 计数器选择 | `00` 选计数器 0，`01` 选计数器 1，`10` 选计数器 2 |
| `D5D4` | 读/写格式 | `00` 发锁存命令，`01` 只访问低 8 位，`10` 只访问高 8 位，`11` 先低 8 位、后高 8 位 |
| `D3D2D1` | 工作方式 | 选择方式 0～方式 5 |
| `D0` | 计数进制 | `0` 表示二进制计数，`1` 表示 BCD 计数 |

工作方式的三位编码可以整理成这样：

| `D3D2D1` | 选择的方式 |
| --- | --- |
| `000` 或 `001` | 方式 0 |
| `010` 或 `011` | 方式 2 |
| `100` | 方式 4 |
| `101` | 方式 5 |
| `110` 或 `111` | 不使用 |

`D5D4` 决定访问几个字节，也决定 CPU 读写时采用什么顺序：

- `01`：只访问低 8 位；
- `10`：只访问高 8 位；
- `11`：完整 16 位，先访问低 8 位，再访问高 8 位；
- `00`：不是普通的数据读写，而是锁存命令。

当 `D5D4=00` 时，必须先看 `D7D6`。例如 `D7D6=00`，就是把计数器 0 的输出锁存器锁住；这时即使方式字段写成什么，也不表示要选择另一种工作方式。这个锁存命令的目的，就是让正在跟随计数值变化的输出锁存器暂时停住，使 CPU 能够读到一个稳定值。

`D0` 则决定计数器按二进制还是按 BCD 方式计数。默认写 0，就是普通二进制计数；写 1，才是 BCD 计数。

#### 计数初值为什么要分两次写入

方式字确定了计数器的工作方式和访问格式以后，CPU 还要把计数初值写入计数器内部的计数初值寄存器。方式控制寄存器是 8 位的，8253 的数据引脚也是 8 位的，所以完整的 16 位初值不能一次写完。

如果 `D5D4=11`，就要写两次：

1. 第一次写低 8 位；
2. 紧接着写高 8 位。

顺序不能随意交换，8253 通过这个顺序把 16 位初值组装完整。若把计数器设成 8 位工作，只使用低 8 位，则只写一次；若使用高 8 位，也只写一次。

### 内部结构：初值怎样变成一次定时

下面用计数器 0 来说明内部结构。计数器 1 和计数器 2 的结构相同，只是引脚编号和寄存器编号换成 1、2。

```text
D0～D7 ───────► 数据/控制逻辑 ◄────── CS#、RD#、WR#、A1、A0
                       │
              ┌────────┴────────┐
              │                 │
       A1A0=11 │                 │ A1A0=00
              ▼                 ▼
       8 位方式控制寄存器      CR0：16 位计数初值寄存器
              │                 │  低 8 位 / 高 8 位
              │                 ▼
              │        写初值后的有效时钟下降沿
              │                 │
CLK0 ──► 时钟逻辑 ─────────► CE0：减法计数器
                               ▲   │
GATE0 ─► 门控逻辑 ─────────────┘   │
                                    ▼
                         OL0：输出锁存器 ──► OUT0
                                    ▲
                                    └── 读数前先锁存
```

图中最重要的三个部件是 `CR0`、`CE0` 和 `OL0`。

`CR0` 用来保存 CPU 写入的计数初值；`CE0` 才是内部真正执行减法计数的计数器；`OL0` 是输出锁存器，保存准备提供给 CPU 读出的计数值。

初始化时，CPU 先通过方式控制端口写方式字，确定计数器 0 的工作方式、计数进制以及初值的读写格式；然后再通过计数器 0 的端口写初值。按照大多数工作方式的过程，写完初值后并不是立刻把 `CR0` 变成正在运行的计数值，而是要等到写初值之后出现的第一个 `CLK0` 下降沿，才把 `CR0` 中的初值装入 `CE0`。

之后，如果 `GATE0` 的条件满足，`CE0` 就按照外部时钟的下降沿继续计数。方式 0、方式 1、方式 2、方式 4 和方式 5 中，`CE0` 按计数单位递减；方式 3 则按两个计数单位递减，形成方波所需的计数过程。

`CE0` 每减一次，计数值就送到 `OL0`。因此，若没有锁存，CPU 读出的值会随着 `CE0` 一起变化，读到的不一定是某一瞬间稳定的数值。由于外部 `CLK` 是外部设备提供的，和 CPU 执行 `IN` 指令的时钟并不相同，读取时必须先让 `OL0` 锁住。

锁存和读取的过程可以概括为：

```text
CPU 写方式字：选择计数器和工作方式
        ↓
CPU 写初值：先低 8 位，后高 8 位
        ↓
第一个有效 CLK 下降沿：CR 装入 CE
        ↓
CE 随 CLK 递减，OL 跟随 CE
        ↓
CPU 发锁存命令：OL 暂时不再跟随 CE
        ↓
CPU 按低 8 位、高 8 位顺序读取稳定值
        ↓
16 位读完：OL 解锁，重新跟随 CE
```

所以，“读当前计数值”不是简单地发一条读指令就结束。对于正在运行的计数器，必须先发锁存命令，再读数据。完整 16 位计数要读低 8 位和高 8 位；读完后，输出锁存器才重新跟随 `CE0` 变化。

8254 的状态寄存器也是基于同样的思路：状态可能随计数过程变化，所以先发命令把状态锁住，再通过读操作把稳定状态取出来。

### 六种工作方式

方式字的三位决定工作方式。方式 0 到方式 5 的用途和触发条件不同，不能只看“计数器都是 16 位”就认为它们的外部表现相同。

| 工作方式 | 名称 | 关键特征 |
| --- | --- | --- |
| 方式 0 | 计数到终止中断 | 计数到达终止时，`OUT` 由低变高，可用上升沿请求中断 |
| 方式 1 | 硬件触发单脉冲形成 | `GATE` 的上升沿触发一次单脉冲过程 |
| 方式 2 | 分频器 | 对输入时钟进行分频，输出周期性定时波形 |
| 方式 3 | 方波产生器 | 产生周期性方波，常用于需要稳定节奏的场合 |
| 方式 4 | 软件触发选通信号产生 | 由软件写入方式字和初值来触发 |
| 方式 5 | 硬件触发选通信号产生 | 由 `GATE` 的上升沿触发 |

#### 方式 0：计数到终止中断

方式 0 的名称直接说明了它的用途：计数到达终止时产生中断信号。

初始化后，`OUT` 先输出低电平，随后计数器在门控有效的情况下对 `CLK` 的下降沿计数，计数值逐渐减到 0。计数到达终止时，`OUT` 从低电平变为高电平；这个上升沿可以用来向 CPU 发出中断请求。

“计数到终止中断”这个名称，关键不只是计数器减到了 0，而是计数结束以后，`OUT` 产生了一个能够被外部电路识别为中断请求的变化。

#### 方式 1：硬件触发单脉冲形成

方式 1 是由硬件触发的单脉冲形成方式。所谓硬件触发，就是在设置好工作方式和计数初值以后，还要由 `GATE` 的上升沿来启动这次计数过程。

它适合需要外部事件到来后才开始一次定时过程的场合：门控信号触发，计数器开始工作，计数完成以后输出一个单脉冲。

#### 方式 2 和方式 3：分频与方波

方式 2 是分频器，方式 3 是方波产生器。这两种方式是实际应用中最值得重点掌握的方式。

方式 2 的任务是对外部时钟进行分频，输出用于得到不同周期的定时波形；方式 3 则直接产生方波。方式 3 通常在 `GATE` 有效时工作，计数值和 `CLK` 共同决定方波的周期。

这两种方式的共同点是都利用计数器把外部时钟重新组织成另一种周期波形。不同点在于：方式 2 强调分频，方式 3 强调方波输出。遇到题目时，先看题目要求的是“分频”还是“方波”，这通常就是选择方式字的重要线索。

#### 方式 4 和方式 5：软件触发与硬件触发

方式 4 和方式 5 都是选通信号产生方式，区别在于启动方式不同。

方式 4 是软件触发：程序把方式字和计数初值写入计数器后，过程由软件启动完成。方式 5 则是硬件触发：除了设置方式字和初值，还要等 `GATE` 的上升沿到来，计数器才开始工作。

这两个名称可以先记成一句话：方式 4 软件触发，方式 5 硬件触发。

> **结论**：方式控制字的每一位含义必须熟悉，尤其是 `D7D6` 的计数器选择、`D5D4` 的读写格式、`D3D2D1` 的工作方式和 `D0` 的计数进制。方式字写错，计数初值即使正确，计数器也不会按预想工作。

### 初始化例题：把计数器 0 设成方式 3

下面用一个完整的初始化例子，把地址选择、方式字、初值和指令串起来。

假设分配给 8253 的端口地址是 `300H`～`303H`，可以按下面的方式对应：

| 地址 | 对应端口 |
| --- | --- |
| `300H` | 计数器 0 |
| `301H` | 计数器 1 |
| `302H` | 方式控制寄存器 |
| `303H` | 计数器 2 |

现在要求：把计数器 0 设置成方式 3，计数初值为十进制 2000，采用二进制计数，且按完整 16 位计数。

先看方式字的每一组。

计数器选择为计数器 0，所以 `D7D6=00`。

完整 16 位计数，需要先低 8 位、后高 8 位，所以 `D5D4=11`。

方式 3 的方式编码是 `011`，所以 `D3D2D1=011`。

采用二进制计数，所以 `D0=0`。

把各位放回去：

```text
D7D6    D5D4    D3D2D1    D0
 00      11       011      0
 0011 0110
```

因此，方式字为 `36H`。

初始化程序可以写成：

```asm
MOV DX, 302H
MOV AL, 36H
OUT DX, AL

MOV DX, 300H
MOV AX, 2000
OUT DX, AL
XCHG AH, AL
OUT DX, AL
```

这几条指令要一行一行看。

第一条把 `DX` 指向方式控制寄存器端口 `302H`。接着把 `36H` 送入 `AL`，通过 `OUT DX, AL` 写入方式字，完成计数器选择、工作方式、计数进制和 16 位读写格式的设置。

随后把 `DX` 改成 `300H`，这个地址对应计数器 0。`MOV AX, 2000` 把十进制 2000 送入 `AX`，但 8253 的 `OUT` 指令只能通过 `AL` 送出 8 位数据，所以第一次 `OUT DX, AL` 写入的是初值的低 8 位。

此时 `AH` 里保存的是高 8 位。不能把 `OUT DX, AL` 改成 `OUT DX, AH`，因为 `OUT` 指令的操作数必须是 `AL`。因此用 `XCHG AH, AL` 交换 `AH` 和 `AL`，把高 8 位换到 `AL`，再执行一次 `OUT DX, AL`，高 8 位就写进了计数器 0。

这两条 `OUT` 的顺序不能交换：8253 规定先接收低 8 位，再接收高 8 位。

这里还有一个容易多此一举的问题：既然初值是十进制 2000，是不是必须先手工换算成十六进制，才能知道 `AL` 和 `AH` 该放什么？不需要。汇编程序编译指令时，会替你把 2000 转换成机器能够使用的数值。你只要把十进制数写进 `MOV AX, 2000`，程序就能正确表达这个初值。

还要判断计数宽度。8 位计数的初值范围是 0～255，而 2000 已经超过 255，所以这里不可能只按 8 位计数，必须使用 16 位计数。换句话说，计数值本身也已经帮助我们判断出 `D5D4` 应选择 `11`。

如果计数器 0 采用方式 3，并且 `GATE0` 在工作期间保持高电平，那么计数器就可以按要求周期性工作，输出方波。

> **易错点**：初始化时不要把“先写方式字”和“先写初值”的顺序、16 位初值的低字节先写顺序搞反。方式字和初值分别写入不同的内部寄存器，CPU 并不是把一个 16 位数整体写进计数器。

### 8253 的工作方式怎么落到实际应用

把引脚和工作方式放在一起看，8253 的应用就清楚了。

如果外部设备送来稳定的 `CLK`，我们需要更长的定时周期，就让某个计数器进行计数，再从 `OUT` 取出定时波形；如果需要分频，就让前一级 `OUT` 作为后一级 `CLK`，必要时继续级联；如果需要事件到来后才启动一次脉冲，就选择硬件触发的方式；如果需要软件控制一次启动过程，就选择软件触发的方式。

`GATE` 还可以接固定电平，也可以由 CPU 的一个输出端口控制。例如某些应用需要由程序决定什么时候开始或停止计数，就可以让 CPU 输出端口的某一位连接到对应的 `GATE`，通过改变这一位的电平来控制计数器。

这就是 8253 和前面那些固定计数器最不同的地方：分频系数、工作方式、启动时机和输出形式，都可以通过程序设置，而不是全部焊死在硬件连接中。

考试时不必把每一种工作方式的细节都临时重新推导一遍。方式控制字每一位的含义要背熟；按照本课的考点提炼，8253 应用题重点大多会落在方式 2 和方式 3：方式 2 是分频器，方式 3 是方波产生器。遇到题目先判断它要求的是分频、定时，还是产生方波，再决定工作方式、计数宽度和初值。

## 8253 的计数终止与硬件触发：读懂 OUT0 的整个生命周期
> 对应块：BLK57 | 覆盖分集：P110-P111 | 块标题（分集名）：《110》

把 8253 的方式控制字拆成二进制以后，真正容易把人绕晕的，往往不是 `30H` 怎么写，而是 `OUT0` 究竟在什么时候变高、什么时候变低。

方式零里，`OUT0` 要等计数器从初值一直减到零；方式一里，它还要等 `GATE0` 出现一次硬件触发。相同的引脚，完全不同的动作节奏。我们先把控制字和端口关系钉牢，再沿着 `OUT0` 的变化，把整个计数过程走一遍。

### 方式控制字：一字节负责四件事

8253 内部有三个 16 位计数器，每个计数器都有六种工作方式。三个计数器分别有自己的端口，却共用同一个方式控制寄存器端口。

假定本系统给 8253 分配的端口范围是 `300H～303H`，地址关系就是：

```text
                 +-------------------------+
                 |  方式控制寄存器 303H    |
                 +------------+------------+
                              |
             +----------------+----------------+
             |                |                |
        +----v----+       +---v-----+      +---v-----+
        | 计数器0 |       | 计数器1 |      | 计数器2 |
        |  300H   |       |  301H   |      |  302H   |
        +---------+       +---------+      +---------+
```

也就是说，计数器零、计数器一、计数器二分别占三个地址，但方式控制字都送到 `303H`。方式字中的最高两位负责告诉芯片：“这次要设置哪一个计数器”。

一个方式控制字可以分成四组：

| 位 | 名称 | 作用 |
| :--- | :--- | :--- |
| `D7～D6` | `SC1～SC0` | 选择计数器零、计数器一或计数器二 |
| `D5～D4` | `RW1～RW0` | 规定只写低字节、只写高字节、先低后高，还是在读操作中锁存当前计数值 |
| `D3～D1` | `M2～M1～M0` | 选择六种工作方式之一 |
| `D0` | `BCD` | 选择二进制计数或 BCD 计数 |

`SC1～SC0=00` 选择计数器零，`01` 选择计数器一，`10` 选择计数器二。三个计数器的选择编码虽然不同，最后都要落到同一个 `303H` 端口。

`D5～D4` 决定读写形式。16 位计数值不可能靠一次 8 位端口写完，所以 `RW1～RW0=11` 时，必须先写低 8 位，再写高 8 位。读计数器时也可以用 `RW1～RW0=00` 把当前值锁存起来，这一点后面判断计数是否到零时非常关键。

`D3～D1` 才是工作方式字段，最低位的 `BCD` 再决定用二进制还是 BCD 计数。千万不要把方式字段和计数器选择字段混在一起：前两位选的是“给谁设置”，中间三位选的是“让它怎么工作”。

> **定义**：方式控制字就是写入 `303H` 的一字节配置命令。它同时回答四个问题：选择哪个计数器、按什么形式读写、采用哪种工作方式、使用哪种计数基数。

### 方式零：先把计数值数完

> **定义**：方式零称为计数达到终止的方式，也常叫“计数到终止并产生中断”的方式。计数器装入初值后开始递减，只有减到 `0000H` 时，`OUT0` 才由低电平变成高电平。

这里先把“中断”二字说清楚。8253 本身没有一个专门向 CPU 发出中断请求的内部输出。方式零到达终点后产生的是 `OUT0` 的上升沿；把这个信号接入中断请求系统，才可以进一步让 8259 向 CPU 提出中断请求。

#### 写下方式字和初值

仍然以计数器零为例，假设我们采用 8 位计数、二进制计数、方式零。控制字各字段是：

```text
SC1 SC0 | RW1 RW0 | M2 M1 M0 | BCD
 0   0  |  0   0  |  0  0  0 |  0
        00        000
```

拼起来就是 `00110000B`，即 `30H`：

```asm
MOV DX, 303H
MOV AL, 30H
OUT DX, AL
```

`OUT DX, AL` 执行时，8253 的方式控制寄存器收到一个写信号，并把 `AL` 中的 `30H` 写进去。从此，计数器零就按方式零工作。

这里有一个从软件指令到硬件动作的完整过程：

```text
CPU                    方式控制寄存器              计数器零
 |                              |                       |
 |---- OUT 303H, 30H ----------->|                       |
 |                              |---- 锁存方式零 ------->|
 |<---------------- 写周期结束 -|                       |
```

一旦方式零被确定，`OUT0` 就变为低电平。即使初值还没有写完，它也先保持低电平。接着给计数器零装入初值。假设初值取 `05H`，因为这里只做 8 位计数，写一个字节就够了：

```asm
MOV DX, 300H
MOV AL, 05H
OUT DX, AL
```

注意，方式字写到 `303H`，计数值却要写到计数器零自己的端口 `300H`。这两个地址不能混：一个是“怎么工作”，一个是“按什么初值工作”。

如果采用 16 位计数，程序里看到的寄存器虽然可以装 16 位数，但 8253 的端口仍然是字节宽的，因此要分两次写：

```asm
MOV DX, 300H
MOV AL, 05H               ; 先写低 8 位
OUT DX, AL
INC DX
MOV AL, 00H               ; 再写高 8 位
OUT DX, AL
```

低字节写完后，高字节还没有写，`0005H` 并没有完整装好。只有高低两个字节都写完，在 `GATE0=1` 的条件下，随后到来的第一个有效 `CLK0` 下降沿才把完整初值装入计数单元 `CE`。此后才开始真正递减。

#### OUT0 从低到高意味着什么

假设完整初值是 `0005H`，`GATE0` 一直保持高电平。初值在第一个有效下降沿装入 `CE` 后，后续有效下降沿到来时依次发生：

```text
CE    0005 -> 0004 -> 0003 -> 0002 -> 0001 -> 0000
OUT0  __________________________________________/‾‾‾
                                  终止计数
CLK0  ___|‾|__|‾|__|‾|__|‾|__|‾|__|‾|__|‾|__|‾|__
             有效下降沿依次使 CE 减 1
```

在 `CE` 从 `0005H` 减到 `0000H` 之前，`OUT0` 始终保持低电平；减到零的那一刻，`OUT0` 自动变成高电平并保持下来。这个由低变高的时刻就是终止计数时刻，也就是定时时间到。

如果外部时钟周期为 $T_{\mathrm{CLK0}}$，计数初值为 $N$，定时宽度就是：

$$
T_{\mathrm{out}}=N\times T_{\mathrm{CLK0}}
$$

因此，改变计数初值就能改变定时宽度，不需要把外部硬件分频器重新焊一遍。8253 的价值正在这里：硬件电路不动，只改写 `CR` 中的数，就能改变时间间隔。

> **结论**：`OUT0` 的上升沿不是普通电平变化，而是“这一轮已经数完”的标志。软件可以用它作为状态，也可以把它接入中断系统来唤醒 CPU。

#### 到零以后，CE 并没有停下来

最容易漏掉的是：`CE` 减到 `0000H` 后，`OUT0` 虽然已经变成高电平并保持高电平，但 `CE` 并没有因为到零就停止接收时钟。

下一个计数时钟到来时，它仍然继续减一：

```text
CE     0003 -> 0002 -> 0001 -> 0000 -> FFFFH -> FFFEH -> ...
OUT0   ___________________________________/‾‾‾‾‾‾‾‾‾
                                             上升后保持高
```

方式零没有在这里自动装入原初值。`CE` 会从 `0000H` 继续向下减，`FFFFH`、`FFFEH` 依次过去；`OUT0` 不跟着这些数值重新变化，只维持高电平。

> **易错点**：`CE=0000H` 令 `OUT0` 变高，不等于 8253 已经停机。若想开始下一轮定时，必须重新向 `CR` 写入新的初值；新的一轮到来时，`OUT0` 才重新回到低电平。

所以，方式零中看到 `OUT0` 变高以后，不能干等着它自己恢复低电平。软件必须重新写初值，或者重新执行方式初始化，开始下一周期。

#### GATE0 能让计数暂停，也能把时间拉长

`GATE0` 是方式零的计数允许信号。初值已经装入以后：

- `GATE0=1`，每一个有效 `CLK0` 下降沿都使 `CE` 减一；
- `GATE0=0`，计数停止，当前 `CE` 值保留；
- `GATE0` 再由低变高，计数从保留的值继续，不必重新装入初值。

这意味着，在计数尚未到零时，让 `GATE0` 短暂变为低电平，可以暂停递减；恢复为高电平以后继续数。这样就能用外部硬件把原来的定时宽度拉长。

> **注意**：暂停和重新开始不是一回事。`GATE0` 恢复高电平，是从原计数值继续；重新写 `CR`，则是为下一轮定时提供新初值。

在正常 `GATE0=1` 的计数过程中，软件也可以在 `CE` 尚未减到零时重新写 `CR`。新初值写完以后，下一个有效时钟下降沿会把新数装入 `CE`，`OUT0` 保持在低电平并按新初值重新计数。因为中间的零没有正常形成一次上升沿，所以定时时间被延长了。

> **提示**：重新写 `CR` 的效果要结合它发生的时刻来判断。终止前重装，是用新值替换尚未结束的一轮；终止后重装，才是在启动下一轮。

### 怎样确认计数器已经减到零

最直接的想法是：读出 `CE`，看看它是不是 `0000H`。但这里有两个麻烦。

第一，CPU 按照自己的指令时序运行，计数器却按照外部时钟异步运行。我们发读命令、做判断的时候，`CE` 可能还在继续减。

第二，16 位计数要分低字节和高字节读取。如果读完低字节以后，`CE` 又发生了一次减法，那么把两次读取拼起来得到的就是一个从来没有真正存在过的“拼接值”。

解决办法是先用锁存命令取得一份稳定快照，再读低字节和高字节。对计数器零来说，方式字的高两位选计数器零，`D5～D4=00` 表示锁存读：

```asm
MOV DX, 303H
MOV AL, 00H
OUT DX, AL
```

在这次读操作中，真正起作用的是 `SC1～SC0=00` 和 `RW1～RW0=00`；其余位在这里不决定锁存动作。随后从 `300H` 读低字节，再从 `301H` 读高字节：

```asm
MOV DX, 300H
IN  AL, DX
MOV AH, AL                ; 暂存第一次读到的低字节
INC DX
IN  AL, DX                ; 读高字节
XCHG AH, AL               ; 交换后，AH 为高字节，AL 为低字节
```

这段 `XCHG AH, AL` 很要紧。第一次 `IN` 得到的是低 8 位，先把它放到 `AH`；第二次 `IN` 得到高 8 位并留在 `AL`；交换以后，`AX` 才成为完整的 16 位计数值。读完第二个字节，锁存解除，`CE` 又可以继续变化，但刚才得到的两字节快照仍然一致。

不过，锁存并没有消灭所有竞争。CPU 发出锁存命令以后还要执行若干条指令，这段时间里 `CE` 仍可能经过 `0000H`。如果只是傻傻地等待读数“恰好等于零”，这个零很可能一眨眼就过去了。

更稳妥的办法是保留原初值，用无符号比较判断计数器是否已经回绕。假设初值是 `0005H`，未到零时读回来的值不会大于 `0005H`；一旦计数越过 `0000H`，`CE` 就会进入 `FFFFH` 区间，无符号数自然大于 `0005H`：

```text
未越过零：  0005H, 0004H, 0003H, 0002H, 0001H, 0000H
                                             |
                                             | 越过终止点
                                             v
已经回绕：  FFFFH, FFFEH, FFFDH, ...
```

把锁存、读取、比较和重新装数连起来，可以写成下面这样一段可运行的轮询程序：

```asm
INITIAL  EQU 0005H

WAIT_ZERO:
    MOV  DX, 303H
    MOV  AL, 00H
    OUT  DX, AL           ; 锁存计数器零

    MOV  DX, 300H
    IN   AL, DX           ; 读低 8 位
    MOV  AH, AL
    INC  DX
    IN   AL, DX           ; 读高 8 位
    XCHG AH, AL           ; AX 得到完整计数值

    CMP  AX, INITIAL
    JBE  WAIT_ZERO        ; 尚未越过零，继续读

RELOAD:
    MOV  DX, 300H
    MOV  AL, 05H
    OUT  DX, AL           ; 重新写低 8 位
    INC  DX
    XOR  AL, AL
    OUT  DX, AL           ; 重新写高 8 位
```

> **易错点**：单次锁存读只能保证“先读低、后读高”得到同一个快照，不能保证发出锁存命令之前恰好抓住零。判断回绕比等待一个稍纵即逝的 `0000H` 更可靠。

到这里也要分清 CPU 和外部设备的节拍。`OUT`、读端口、比较和跳转，全由 CPU 的指令时序推动；`CE` 减一，则由外部时钟推动。两者是异步的，不能把程序执行了几条指令和计数已经经过几个时钟直接等同起来。

### 定时唤醒与看门狗

方式零最直接的功能，是让 CPU 定时醒来。正常情况下，CPU 根据需要的周期向 `CR` 重装初值；终止计数到来时，`OUT0` 产生上升沿，并通过外部连接向 8259 提出中断请求。CPU 进入中断服务程序，完成到期处理，再为下一轮定时做好准备。

如果外部时钟稳定，周期计算就是 $N\times T_{\mathrm{CLK0}}$。程序正常运行时，只要在计数器到零之前按时重装它，就可以得到连续、可控的定时过程。

> **结论**：硬件负责把时间数准，软件只负责给出时间长度和安排到期后要做的事情。

把同样的机制反过来用，还能做一个最朴素的看门狗。

用户程序经过翻译、链接后装入内存，CPU 正常执行时，`CS:IP` 必须一直落在真正的指令区域。可是一旦受到干扰，`IP` 可能突然飞到一块数据区域。CPU 到那里照样取指令、照样解释，可它拿到的并不是真正指令，最后不认识、执行不下去，程序就“走飞”了。

看门狗的思路是：正常运行时不断证明程序还活着；程序一旦走飞，不再按时喂计数器，计数器就会替它发出异常信号。

最笨但也最清楚的做法，是先算出正常程序片段的最坏执行时间。指令有多少条、每条指令占多少时钟周期、一个时钟周期有多长，都能逐项累加。然后给 8253 选一个更长的计数值，使：

$$
N_{\mathrm{WDT}}\times T_{\mathrm{CLK0}}>T_{\mathrm{normal}}
$$

两边还要留出足够余量。正常程序运行到预定位置时，在计数器尚未到零以前重新写入初值，相当于“喂一次看门狗”。如果程序很大、执行时间很长，就在若干位置重复这个重装操作，让 `CE` 始终没有机会减到零。

一旦 `IP` 走飞，这些重装操作也跟着没有了。`CE` 继续减，最终到零，`OUT0` 产生终止信号，进入中断服务程序；CPU 在那里无条件远程跳回主程序流程。就这么简单的一个动作，已经能把跑飞的 `IP` 拉回来。

实际工业控制往往不能只说“跳回主程序”就算完，因为程序可能已经走飞到不该恢复的位置。这时要进一步把程序划分成若干小段：每段开始时给 8253 重新装载计数值，同时保存这一段的入口地址；超时发生以后，再根据 `IP` 从哪一段走失，决定回到哪里继续执行。

这就是方式零的延伸用法：它不仅能定时，还能用“正常时会不断重装、走飞后不再重装”的差别，识别程序是否还活着。

### 方式一：让硬件触发一个可编程单脉冲

> **定义**：方式一称为硬件触发的单脉冲形成方式。计数器完成初始化后，`OUT` 保持高电平；每检测到一次硬件触发，便重新装入初值并开始一次减一计数，计到零时输出回到高电平。

方式零由“写入新计数”推动下一轮，方式一则多了一个硬件启动动作。把 `GATE0` 当成触发输入，一次上升沿就能让计数器开始一次单脉冲过程。

#### 方式字和初值仍然从控制字拆起

这里仍以计数器零为例，改用 8 位计数、二进制计数、方式一：

```text
SC1 SC0 | RW1 RW0 | M2 M1 M0 | BCD
 0   0  |  0   1  |  0  0  1 |  0
        01        001
```

`SC1～SC0=00` 选计数器零，`RW1～RW0=01` 表示只写低 8 位，`M2～M1～M0=001` 选择方式一，最低位为二进制计数。合起来是 `00100000B`，即 `20H`：

```asm
MOV DX, 303H
MOV AL, 20H
OUT DX, AL
```

方式一被确定以后，`OUT0` 先变成高电平。接着假设初值为 `04H`，只写低字节即可：

```asm
MOV DX, 300H
MOV AL, 04H
OUT DX, AL
```

初值虽然已经写好，计数却没有立即开始，`OUT0` 仍保持高电平。真正让这次单脉冲开始工作的，是 `GATE0` 上的硬件触发。

#### GATE0 到来后才开始数

当 `GATE0` 出现上升沿时，硬件触发生效，`OUT0` 转为低电平。随后的有效 `CLK0` 边沿把 `CR0` 中的初值装入 `CE`，随后每一个有效计数边沿使 `CE` 减一。

初值为 `4` 时，动作过程可以概括为：

```text
CE    ----< 装入 4 >---- 3 ---- 2 ---- 1 ---- 0
OUT0  __________________\______________________/‾‾
GATE0 ____________/‾‾‾‾‾‾‾‾\____________________
                         硬件触发
CLK0  ___|--+--|--+--|--+--|--+--|--+--|--+--|__
```

这张图只强调动作顺序，不表示各信号的精确相位：`GATE0` 触发以后，初值重新装入；`CE` 数完 $N$ 个时钟后降到零，`OUT0` 回到高电平，单脉冲结束。

若初值为 $N$，低电平脉冲的宽度由计数初值决定：

$$
W_{\mathrm{pulse}}=N\times T_{\mathrm{CLK0}}
$$

所以方式一既叫“硬件触发的单脉冲形成”，也叫“硬件可重触发单稳态”。硬件负责什么时候开始，软件负责这次低电平要持续多久。

如果一次单脉冲还没结束，`GATE0` 又来一次触发，初值会重新装入，计数从头开始。一般程序不会故意这样做，但硬件上必须把这个行为记清楚：方式一的再次触发不是简单忽略，而是重新开始一次计数。

#### 方式零与方式一放在一起看

| 比较项 | 方式零 | 方式一 |
| :--- | :--- | :--- |
| 初始化后的 `OUT` 电平 | 低 | 高 |
| 开始一次计数的条件 | 写入方式字和初值后，在允许条件下开始 | 初始化完成后等待 `GATE` 硬件触发 |
| 输出变低的原因 | 工作方式确定后进入低电平 | 每次硬件触发后进入低电平 |
| 结束条件 | `CE` 减到零 | `CE` 减到零 |
| 计数到零后的状态 | `OUT` 保持高，重新写入新初值才能开始下一轮 | `OUT` 回到高，下一次触发即可重新形成脉冲 |
| 典型用途 | 定时、周期重装、看门狗 | 硬件触发的延时和可编程单脉冲 |

这样一对照，方式零和方式一的区别就很清楚了：两者都靠 `CE` 减到零结束输出，但方式零把“写入初值”当作启动和重装动作，方式一则把 `GATE0` 的硬件触发当作启动和重装动作。

### 抓住四路信号的时间关系

要真正看懂方式一，不能只盯 `CE` 的数字，至少要把 8253 的读/写控制端、`CLK0`、`GATE0`、`OUT0` 这几路信号放在一起看。示波器或逻辑分析仪一次显示全部信号时，它们的时序关系会非常直观。

但实验室里常常只有双通道示波器。没关系，可以两两测量：先固定一组信号作同步，再换另一组信号去测。

> **注意**：换信号时，示波器的时基不要随意改变。若第一组和第二组使用不同的时基位置，看上去对齐的波形其实已经失去共同时间轴，触发沿和计数边沿的关系就不可信了。

观察方式零时，重点看 `GATE0` 有效、下降沿连续计数、`OUT0` 在终止点上升；观察方式一时，则重点看 `GATE0` 的硬件触发、`OUT0` 何时拉低，以及初值数完后何时恢复高电平。单看输出高低很容易觉得“就是一个脉冲”，把四路信号排到一起，才会看到它是硬件触发、时钟计数和输出反馈共同形成的。

### 方式二：先把分频器命令字立起来

接着转到方式二时，我们改用计数器一来设计。端口范围仍取 `300H～303H`，方式字仍写入 `303H`。

现在要求：计数器一、16 位计数、二进制计数、方式二。对应控制字是：

```text
SC1 SC0 | RW1 RW0 | M2 M1 M0 | BCD
 0   1  |  1   1  |  0  1  0 |  0
        01        11        010
```

拼起来就是 `01110100B`，即 `74H`：

```asm
MOV DX, 303H
MOV AL, 74H
OUT DX, AL
```

这一个字节已经把三件事钉死：选择的是计数器一，写入形式是先低字节后高字节，工作方式是分频方式二，计数基数是二进制。

方式二命令字写入以后，计数器一进入工作方式，`OUT1` 转为高电平。这里也不要把芯片引脚理想化成命令一到就瞬间翻转，实际硬件响应总会有一点延迟。

先把这一步的因果链放好，后面分析分频脉冲时，基础才不会乱：计数器一、16 位、二进制、方式二，再把初值写入 `301H` 和 `302H`。至此，8253 的工作方式就从“数到零才结束”的方式零，经过“由硬件触发才开始”的方式一，走到了分频器方式二的入口。

> **承前启后**：上一节讲完「8253 的计数终止与硬件触发：读懂 OUT0 的整个生命周期」，下一节接着讲「8253的计数方式与接口应用」。

## 8253的计数方式与接口应用
> 对应块：BLK58 | 覆盖分集：P112-P113 | 块标题（分集名）：《112》

初值写入计数器，并不意味着外部计数时钟一来，OUT 就会立刻按我们想象的动作变化。这里真正要抓住的，是初值怎样进入计数器、计数器什么时候减一、什么时候自动重装，以及 GATE 在这些时刻起什么作用。

这一块把 8253 的六种工作方式收完，其中重点是方式二和方式三：前者产生周期性窄脉冲，后者产生方波。先把这两者真正算明白，再把程序接回织布机的应用题，8253 就不只是“会选工作方式”了。

### 初值怎样进入计数器

8253 中容易混淆的，是“初值寄存器”和真正参与减一的“计数器”。我们写进去的初值先保存在计数初值寄存器 CR 中；等到允许计数的时钟条件满足，CR 的内容才被送入计数执行部件 CE。CE 才是每来一个外部计数时钟就减一的计数器。

```text
                 允许装载
GATE ───────────┐   ┌───────────┐
                └──►│ CR 初值寄存器 │── 初值 ──► CE 计数器 ──► OUT
CLK ───────────────────────────────►  计数时钟   ↓
                                         每来一个有效边沿减一
```

16 位计数值要先写低 8 位，再写高 8 位，顺序不能颠倒。控制字里选择“低字节在前，高字节在后”，两个 `OUT` 指令执行完，CR 才算完整地装入了一个 16 位数。

初值装入后，CE 每遇到一次外部计数时钟的有效下降沿就减一。减到多少，OUT 怎样动作，则由工作方式决定。方式二和方式三都采用二进制计数；方式三还要额外判断装载值是奇数还是偶数。

> **易错点**：端口地址是对应的，不等于“`OUT 83H, AL` 就一定在给计数器 0 装初值”。`83H` 是控制端口，还是某一路计数初值端口，要看 A1、A0 怎样选中它。控制字写错了，后面的初值就没有按预想工作。

### 方式二：脉冲发生器

方式二也叫频率发生器或分频器。典型用法是让 GATE 保持高电平，写入计数初值 $N$，由 CLK 输入外部计数时钟。CE 递减到特定值时，OUT 拉低一个时钟；紧接着，CR 中的初值自动重新装入 CE，OUT 重新变高，于是开始下一个周期。

我们拿初值 6 来看，不背定义，直接把数数过程走一遍。

CE 装入 6 后：

1. 第一个下降沿后，CE 从 6 变成 5，OUT 仍为高。
2. 第二个下降沿后，CE 从 5 变成 4，OUT 仍为高。
3. 第三个下降沿后，CE 从 4 变成 3，OUT 仍为高。
4. 第四个下降沿后，CE 从 3 变成 2，OUT 仍为高。
5. 第五个下降沿后，CE 从 2 变成 1，OUT 自动变低。
6. 第六个下降沿后，CE 从 1 变成 0；OUT 由低变高，CR 中的 6 自动重新装入 CE。

所以输出的高、低电平不是只出现一次。下一个周期仍从 6 减到 0，低电平仍只保持一个时钟周期，输出脉冲则按固定节拍重复。

```text
CLK 下降沿       写初值   1      2      3      4      5      6
CE                    6      5      4      3      2      1      0
                                               ↓
OUT                   高 ──────────────────────────────────── 高
                                                            │
                                       低 ────────────────  │
                                             只保持 1 个时钟周期

CR 在 CE 到 0 的同时自动重装，下一轮又从初值开始。
```

这里有一个非常值得盯住的细节：第一次从装入初值开始算，到 OUT 第一次由高变低，经历的是 $N-1$ 个下降沿；接下来才用第 $N$ 个下降沿补上低电平的那一个周期。进入稳定运行后，一个完整的输出周期是

$$
T_{\mathrm{OUT}}=(N+1)T_{\mathrm{CLK}}。
$$

不能把方式二的稳态周期想当然地写成 $N T_{\mathrm{CLK}}$。讲方式三时用方式二的输出作时钟，这个 $+1$ 就会直接体现出来。

> **结论**：方式二只需在启动时装入一次初值，CR 和 CE 之间会自行完成“计数到零—重装—再计数”的循环。改变分频周期，重新写初值即可。它比拿一个 16 位二进制计数器自己搭分频器方便得多，不过 8253 本身当然比普通计数器贵。

#### GATE 不是只能一直打开

方式二里，GATE 为高电平时允许计数并允许接受初值；GATE 变成低电平，就停止计数。若在 CE 尚未减到 1 时把 GATE 拉低，当前计数会停住。GATE 再由低变高后，会产生一次重新触发的上升沿；在允许装载的条件下，初值会在随后相应的时钟条件下重新进入 CE。

实际使用时，不必把每一次暂停、恢复的细节都背下来。应用中最常见的情况是 GATE 一直接高电平，保持“允许计数”。题目若明确要求由某个 I/O 位控制 GATE，才需要用输出端口的一根线来控制它。

```text
GATE  保持高电平 ───────────────────────────►  正常、连续地计数
GATE  需要暂停 ───────┐          ┌─────────►  暂停后重新触发
                      └──────────┘
```

记住正常计数时的接线就够了；把复杂的暂停恢复过程全塞进脑子，反而容易用错。

### 方式三：方波发生器

方式三叫方波发生器。初始化时选择 16 位二进制计数，并让计数器 0 工作于方式三。以计数器 0 为例，控制字可以是：

```text
SC1 SC0  RL1 RL0  M2 M1 M0  BCD
 0   0    1   1    0   1   1    0
          低后高          方式三  二进制
```

这就是 `00110110B`，即 `36H`。对控制端口执行：

```asm
MOV AL, 00110110B
OUT 83H, AL
```

仍然是先写初值的低 8 位，再写高 8 位。若初值为 6，就先送 `06H`，再送 `00H`。在初值完整写入后的第一个计数时钟下降沿，初值被同步装入 CE；此后只要 GATE 为高，8253 就按方波方式持续工作，不需要每个周期都重新写一次初值。

> **易错点**：方式三的计数初值若按“一次减一”去算，会把高、低电平宽度算错。它在多数时钟内是按减二推进的。我们必须分清偶数初值和奇数初值，不能只背一个结论。

#### 偶数初值：高、低各一半

当初值为偶数 $N$ 时，CE 每来一个计数时钟下降沿就减二。CE 减到零时，OUT 自动变低；保持一个时钟周期后，CR 的初值又自动装入 CE，OUT 再由低变高。

以 $N=6$ 为例，CE 依次为 $6\to4\to2\to0$，OUT 低电平只占一个时钟；重新装入 6 后，又按 $6\to4\to2\to0$ 重复。

```text
CLK 下降沿       0      1      2      3      4      5      6
CE               6      6      4      2      0      6      4      2
OUT              ┌──────────────┐
                 │              └──────────────┐
                 │                             │
                 └─────────────────────────────┘
                       高 3 个时钟       低 3 个时钟
```

设 $N=2k$，则

$$
T_{\mathrm{高}}=kT_{\mathrm{CLK}},\qquad
T_{\mathrm{低}}=kT_{\mathrm{CLK}}，
$$

所以

$$
T_{\mathrm{OUT}}=NT_{\mathrm{CLK}},\qquad 占空比=\frac{T_{\mathrm{高}}}{T_{\mathrm{OUT}}}=\frac12。
$$

这就是对称方波。初值为 6 时，OUT 每个输入时钟周期完成一次翻转，高、低电平各维持 3 个时钟。

#### 奇数初值：高电平多一个时钟

初值为奇数时情况就变了。初值 5 会在装入 CE 时先被变成 4，也就是用 $N-1$ 把它变成偶数，先完成正半周：

```text
初值 N = 5
装入 CE 的值 = 4
             4 ──减2──> 2 ──减2──> 0 ──保持1个CLK──> OUT 变低
```

OUT 变低后，CR 中的奇数初值 5 再减一，以偶数 4 重新装入 CE；接下来完成负半周，$4\to2\to0$。这样，总的输出周期是 5 个时钟，但高、低两部分不再各占一半。

设奇数初值 $N=2k+1$，则

$$
T_{\mathrm{高}}=(k+1)T_{\mathrm{CLK}},\qquad
T_{\mathrm{低}}=kT_{\mathrm{CLK}}，
$$

因而

$$
T_{\mathrm{OUT}}=NT_{\mathrm{CLK}}，
\qquad
\frac{T_{\mathrm{高}}}{T_{\mathrm{低}}}=\frac{k+1}{k}
e1。
$$

$OUT$ 仍然是方波，但已经不是对称方波。千万不要把“奇数初值”理解为 CE 直接从 5、3、1 往下数；实际装进 CE 的，是经过奇偶处理后的偶数。

> **结论**：方式三用同一个初值同时决定周期和占空。偶数初值得到对称方波；奇数初值下，一个完整周期仍为 $N$ 个计数时钟，但高电平比低电平多一个时钟。CPU 不必参与每个边沿，8253 会在每个周期结束后自动重装。

#### 方波也要把 GATE 接对

方式三的 GATE 与方式二相同：GATE 为高电平时允许计数；GATE 变低会停止计数；GATE 由低变高时形成一次触发上升沿，让初值重新装入并恢复计数。

所以我们在程序里写了方式三和初值，还要在电路里保证 GATE 为高。若只执行初始化程序，GATE 却被悬空，或者接成低电平，8253 仍然可能正常接收初值，却不会按我们要求持续产生方波。

大多数固定连续工作的应用，GATE 接高电平即可；需要由软件控制启停时，再把 GATE 接到 I/O 输出一位。

### 软件与硬件触发的选通信号

方式四叫软件触发的选通信号产生，方式五叫硬件触发的选通信号产生。名字已经把区别说清楚了：方式四在初值写完后，由软件写入动作启动后续的触发计数；方式五要等 GATE 由低变高的上升沿，才把硬件信号当作触发。

这里用“软件/硬件”来记触发来源，不要把它和 GATE 的高、低电平使能作用混成一件事。8253 总共只有六种工作方式，如果把每一种都占一整节课，这门课就得一直耗在方式名称上。这两种选通方式结构简单，按上面的触发来源自学即可，考试时也不需要像方式二、方式三那样花时间重新推一遍。

到这里，六种工作方式就全部收束了。真正应当重点掌握的是：用控制字选方式，用低字节/高字节装初值，再根据外部时钟和 GATE 把输出波形算出来。

### 8253与8254的差别

如果换成 8254，整体使用方法与 8253 一样，但别把两个器件完全当成没有区别的一块芯片。

一个区别在外部计数时钟频率。8253 的计数时钟上限是 2 MHz，8254 比它高，教材中给出的 8254 上限通常是 8 MHz。

另一个区别是 8254 增加了计数状态读回功能。8254 可以锁存并读回各计数器当前状态：CE 是否已经减到零，OUT 当前是高还是低，都能通过状态字观察。8253 没有这样的读回命令，不能用同样的办法直接读出计数器的当前状态。

如果题目明确要求掌握 8254，就补上“计数时钟上限更高、可读回当前状态”这两点；只考 8253 时，先把工作方式和接口连接学扎实就够了。

### 与系统总线怎样连接

8253 共有四个端口：一个控制端口，三个计数器端口。把它接到 8088 或 8086 最小模式系统上，连接思路很固定，关键是把数据线、地址选择和控制信号都照顾到。

| 连接部分 | 要抓住什么 |
| --- | --- |
| 数据总线 | 8088 用 D0～D7；8086 需要考虑 D0～D15 的宽度，不能只接低位就认为完成了整个接口 |
| 端口地址 | 用 A1、A0 选择控制端口和三个计数器端口；地址可以不连续，不必强行假设四个端口挨在一起 |
| 读、写控制 | 8253 的读、写控制信号与系统总线的相应控制信号连接，不能漏掉 |
| PC 总线 | 还要考虑 AEN 信号；它是处理器访问还是 I/O 访问，关系到译码是否有效 |
| I/O 空间标志 | 注意 `M/IO`、`IO/M` 的命名和有效电平，不要机械地想当然 |
| 门控 GATE | 固定允许计数时接高电平；由软件控制时，可接到 I/O 输出口的某一位 |

可以把最常见的连接关系记成下面这样。地址译码的具体电路形式可以不同，但该出现的信号一个都不能少：

```text
             ┌──────────────────────────────┐
系统数据总线 ◄── D0～D7（8088）──────────────┤ D7～D0   │
系统地址总线 ── A1、A0 ─────────────────────┤          │
系统读信号   ── RD ────────────────────────┤  8253    │
系统写信号   ── WR ────────────────────────┤          │
GATE         ── 固定高电平或 I/O 输出 ─────┤          │
             └──────────────────────────────┘
```

读图要注意：系统总线负责 CPU 和 8253 之间的数据传送及端口寻址，外部 CLK 则负责给指定计数器提供计数节拍。GATE 决定是否允许相应的计数动作；它们并不是同一条控制线。

地址不连续也可以。例如题中给定 8253 的端口地址是 `80H～83H`，就按这个地址表写指令；A1、A0 为 `00` 时选中计数器 0，为 `11` 时选中控制端口。`OUT 83H, AL` 在这里就是给控制端口写控制字，而不是给计数器 3 写数——8253 的三个计数器编号是 0、1、2，端口地址才是 `80H～83H`。

### 为什么 0.1 秒要级联

假设系统送来的时钟为 1 MHz，则一个时钟周期是 $1\ \mu s$。0.1 秒相当于

$$
0.1s=10^5\times1\mu s，
$$

也就是需要 100000 个计数时钟。一个 16 位计数器的计数范围是 0～65535，装不下这么大的初值，所以一个通道不够用。

把 100000 拆成两个容易装入的数：

$$
100000=1000\times100。
$$

第一个计数器用方式二产生中间节拍，第二个计数器用方式三产生最终方波：

```text
1 MHz ──► CLK1   计数器1：方式二，初值1000
                         │
                      OUT1 ───────────► CLK2
                                      计数器2：方式三，初值100
GATE1、GATE2 ──高电平─────────────────────┘        │
                                                OUT2
                                                ▼
                                          周期方波输出
```

第一个计数器装入 1000，使自己的输出形成周期节拍；第二个计数器以第一个计数器的输出作为 CLK_2，再装入 100。这样，第二个计数器的工作范围就落在 16 位可表示的计数长度内。最后一个通道的 OUT_2 才是我们需要的 0.1 秒周期信号。

这里要额外分清“按时钟理想值算”和“按方式二精确节拍算”。若按 $1000\times100\ \mu s$ 计算，得到 0.1 秒，这正是课堂上给出的取数思路。但我们在方式二里已经数过：初值 1000 的稳定周期是 $(1000+1)T_{\mathrm{CLK}}$，所以后一级实际得到的周期是

$$
T_{\mathrm{OUT2}}=100\times1001\ \mu s=0.1001\ s。
$$

这个 $0.0001$ 秒差别不是新知识点，而是方式二那个“$+1$ 个时钟”必须落实到级联计算中的结果。若题目要求严格得到 0.1 秒，就要按方式二的真实节拍调整前一级初值；如果只按 10 的幂次拆分，则按 $1000$ 和 $100$ 取值即可。

### 期末之前，方式与应用都要再过一遍

8253 的其他应用，书上例题和 9.19、9.3 等部分的阅读材料留给大家自己看。方式二、方式三的波形和级联程序已经讲过，剩下的例题应当能顺着“工作方式—时钟来源—初值—输出连接—GATE 设置”这条线自己拆开。

临近期末，不再额外塞新的内容，只剩一次串讲。串讲的作用不是再堆一遍知识，而是给你一条复习的引导线。做课后作业时，先别急着看参考答案；先按题目自己写、自己判断，再对照答案检查，否则一眼看到答案，题就等于白做了。

### 本讲提到的题目

题目来自课后习题中关于织布机控制系统的 9.11，共两问。系统使用 8088 最小模式，配置一片 8253，端口地址为 `80H～83H`。

#### 每织一百米，控制织布机下刀打包

织布机每织 1 米，就向 8253 的计数器 0 输入一个计数脉冲。计数器 0 工作于方式二，对这些脉冲进行 100 分频；每累计 100 米，就由 `OUT0` 向织布机发出一个控制命令，让织布机下刀、打包。

1 MHz 是第二问才给定的条件，这一问不要求由 8253 自己产生计数时钟。因此，时钟不是接 1 MHz 振荡信号，而是接织布机每米给出的脉冲。正好计 100 个脉冲触发一次，关系非常简单：1 米一个脉冲，100 米就是 100 个脉冲。

```text
织布机每米产生一个脉冲
             │
             ▼
1 MHz时钟  ── CLK0
             │
         计数器0：方式2，初值100
             │
             ▼
            OUT0 ──► 每100米发出一次下刀、打包命令
```

初值应装 100，而不是 99。方式二要把 CE 从 100 一直数到 0，装入 99 会使分频数量不对。计数器 0 的控制字是 `00110100B`，即 `34H`；GATE0 接高电平，允许连续计数。

```asm
PORT_0    EQU 80H
PORT_CTRL EQU 83H

; 计数器0：方式2，二进制，16位，先低字节后高字节
        MOV     AL, 00110100B
        OUT     PORT_CTRL, AL

        MOV     AL, 64H                 ; 64H = 100
        OUT     PORT_0, AL              ; 先写低8位
        OUT     PORT_0, AL              ; 再写相同的0写高8位
```

电路连接是：织布机的每米脉冲接 `CLK0`，`OUT0` 接织布机的控制命令输入端，`GATE0` 接 +5 V。CPU 执行完这段初始化后，8253 就会每收到 100 个每米脉冲，从 `OUT0` 发出一次控制命令。

不要只写程序而忘记接线。GATE0 若被接成低电平，8253 就停止计数；如果悬空，也不能保证它被当作持续有效的高电平。做这类题时，“8253 要工作”不只是初始化程序写对了，外部脉冲和 GATE 也必须接对。

#### 用计数器 1 和计数器 2 产生 0.1 秒周期信号

系统提供 1 MHz 的计数时钟信号，利用 8253 的两个计数通道产生周期为 0.1 秒的信号。

因为一个 16 位计数器计不满 0.1 秒所需的 100000 个时钟，所以采用两级级联：

- 计数器 1 用方式二工作，装入初值 1000，`OUT1` 接计数器 2 的 `CLK2`；
- 计数器 2 用方式三工作，装入初值 100，最终从 `OUT2` 输出方波；
- 两个 GATE 都接高电平。

```text
1 MHz ──► CLK1
           计数器1：方式2，初值1000
                      │
                   OUT1 ───────► CLK2
                                   计数器2：方式3，初值100
GATE1 ──高电平──────────────────┐   │
GATE2 ──高电平──────────────────┴───┘  OUT2 ──► 周期信号
```

按课堂采用的 $10^3\times10^2$ 计算口径，程序如下：

```asm
PORT_0    EQU 80H
PORT_1    EQU 81H
PORT_2    EQU 82H
PORT_CTRL EQU 83H

        MOV     AL, 00110100B
        OUT     PORT_CTRL, AL          ; 计数器1，方式2

        MOV     AX, 1000
        OUT     PORT_1, AL              ; 先写低8位
        MOV     AH, AL
        OUT     PORT_1, AL              ; 再写高8位

        MOV     AL, 00110110B
        OUT     PORT_CTRL, AL          ; 计数器2，方式3

        MOV     AX, 100
        OUT     PORT_2, AL              ; 先写低8位
        MOV     AH, AL
        OUT     PORT_2, AL              ; 再写高8位
```

如果题目按理想时钟周期直接计算，得到的就是 0.1 秒；若严格按 8253 方式二的稳定节拍计算，则应得到 0.1001 秒。做题时必须看清题目采用哪一种口径，并把自己采用的口径写在答案里，不能只写“1000 和 100”就停住。

但这道题真正要留下的经验只有三句：第一，1 MHz 对应 $1\ \mu s$；第二，一个 16 位计数器装不下 0.1 秒，需要把 100000 拆成两级；第三，级联不仅有软件上的 `OUT1` 接 `CLK2`，还有两个 GATE 都要接成允许计数的高电平。把这三句和前面的方式二、方式三对上，8253 的应用题就没有什么神秘的了。
