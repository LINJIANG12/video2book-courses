## 数据传送类指令与查表实现
> 对应分集：P34 | 原始标题：《数据传送类指令与查表实现》

我今天课堂时间过渡到`3.4`节数据传送类指令。书翻到`38`页，大括号总结了七种：`MOV`学得差不多了，`LEA`，`LDS`、`LES`取地址指针，`LAHF`标志传送，`XCHG`数据交换，`XLAT`字节转换，`PUSH`、`POP`堆栈操作。有些接触过，有些没接触，分类说。

### 传送类指令的两条总规则

学这类之前先抓两点。第一，除`SAHF`还有`POPF`，我在讲`TF`时用过`PUSHF`、`POPF`把`16`位标志压栈出栈，除这两条外，剩下所有传送类指令执行后对六个状态标志均无影响。抓住无影响。只是数据传送没做运算，所以不影响，但那两条除外。

第二，所有传送类指令书写都要守数据寻址总结的六点：立即数只能做源；类型要一致；类型要明确；`DS`、`ES`、`SS`做目的时源不能是立即数；`CS`、`IP`不能做目的；两存储器单元不能直接操作。再加习题`3.3`说的：指令语句不允许两个变量参加运算。学指令都要守这些。

### 通用传送与取有效地址指令

第一种通用数据传送：

```assembly
MOV DST, SRC
```

把源指明的内容传送到目的去。只要编程肯定用到，所以叫通用。谁和谁怎么传，讲寻址时例子很多了，这一种就算讲完了。

第二种取有效地址，书`41`页：

```assembly
LEA reg16, mem
```

给一个`16`位寄存器，后面是五种存储器寻址某一种指明的一个单元。取的是这个单元的有效地址偏移`EA`。`16`位寄存器哪个都对，但最好取到`BX`、`BP`、`SI`、`DI`之一。取到`AX`、`CX`也没错，可它们不能间接不能相对，取来地址肯定要用，做间址相对基址变址都要用，所以选那四个。

看例子。想取`DATA1`单元偏移，前面用过：

```assembly
MOV BX, OFFSET DATA1
```

学了`LEA`可以写：

```assembly
LEA BX, DATA1
```

源用直接寻址找到一个单元，把这个单元的有效地址给`BX`，不是把内容送过去。两条功能完全一样。`LEA`又要和`MOV`区分开：一个取地址，一个取内容，千万别混。

### 标志传送与陷阱位为什么动不了

标志传送两条。第一条`LAHF`（`Load AH from Flags`）：

```assembly
LAHF
```

把标志寄存器`FLAGS`也就是程序状态字`PSW`读出来送`AH`。`AH`是`8`位，`FLAGS`是`16`位，具体是低`8`位送`AH`：

$$AH \leftarrow FLAGS[7:0]$$

反过来`SAHF`（`Store AH into Flags`）：

```assembly
SAHF
```

以`AH`为源送`FLAGS`低`8`位：

$$FLAGS[7:0] \leftarrow AH$$

注意这条执行后直接影响标志。虽然属传送类，但改了标志内容，所以前面说不影响要除它之外。

前面讲过`8086`没有专门让陷阱标志`TF`置`1`清零的指令，当时说用堆栈`PUSHF`、`POPF`改。能不能用`SAHF`改`TF`。不行。`SAHF`只能写低`8`位即`0`到`7`位，`TF`在`PSW`第`8`位属高`8`位，写不到。所以`TF`置`1`清零只能堆栈操作。

### 数据交换指令的额外限制

第五类数据交换，助记符`XCHG`：

```assembly
XCHG DST, SRC
```

把源和目的内容互换。除了通用六点，还加两条：目的和源都不能是立即数，立即数没法被写入没法互换；所有段寄存器`CS`、`DS`、`SS`、`ES`都不能参加交换。

看例子。寄存器换寄存器：

```assembly
XCHG AX, BX
```

对，`AX<->BX`互换。寄存器换存储：

```assembly
XCHG AL, [SI+3]
```

源用寄存器相对指一个字节单元，读出来给`AL`同时把`AL`原值写回去，字节互换，对。高低`8`位互换：

```assembly
XCHG BH, BL
```

都是`8`位类型一致，执行后`BX`高低`8`位互换。错的也要会认：

```assembly
XCHG AX, ES
XCHG AX, BL
```

前者段寄存器不能交换，后者`AX`是`16`位字`BL`是`8`位字节类型不一致，都错。

### 字节转换查表指令

第六类字节转换`XLAT`，单片机里也叫查表指令：

```assembly
XLAT
```

不写显式操作数，源和目的全隐含。`CPU`执行时默认`DS`段，以`BX`内容为基地址，加`AL`内容为位移，算有效地址：

$$EA = (BX) + (AL)$$

$$AL \leftarrow DS:[(BX)+(AL)]$$

把该字节单元数据读出来送`AL`，`AL`原值被表中对应数据替换。

应用场景就是十六进制转`ASCII`。`DS`段用`DB`定义转换表：偏移`00H`放`'0'`的`30H`，`01H`放`31H`，`02H`放`32H`，一直到`09H`放`39H`，`0AH`放`41H`，`0BH`放`42H`，到`0FH`放`46H`。表建好了，代码段调表：

```assembly
MOV AL, 04H
LEA BX, TABLE
XLAT
```

假设待转换`4`，`AL`放`04H`，`LEA`把表首偏移给`BX`，`XLAT`执行`AL<-DS:[BX+AL]`，`AL`变成`'4'`的`34H`。听懂了没有，查表就是这么用的。

## 加减法运算指令与双字相加实现
> 对应分集：P35 | 原始标题：《加减法运算指令与双字相加实现》

我前面把传送类讲完了，今天看`3.5`节算术运算类。既然算术，肯定有加法减法乘法除法，还有`BCD`码调整。先学加法和减法。

### 运算类指令的两条总规则

学这类先抓两点。第一，只要`CPU`执行了运算类某条指令，结果就要影响六个状态标志或其中某些。第二，所有段寄存器不能参加运算。这两点不光算术，下一节逻辑也一样。

### 三条加法指令的分工

算术第一种加法，一共三条。

第一条不带进位加`ADD`，双操作数：

```assembly
ADD DST, SRC
```

功能是目的指明的内容加源指明的内容，源也可以是立即数，和送回目的，源不变：

$$(DST) + (SRC) \to DST$$

`CPU`按和设置六个状态标志`ZF`、`PF`、`SF`、`CF`、`OF`、`AF`。

第二条带进位加`ADC`，也是双操作数：

```assembly
ADC DST, SRC
```

把目的、源、`CF`三者相加送目的，源不变：

$$(DST) + (SRC) + CF \to DST$$

同样按结果设置全部六个标志。

第三条加`1`也叫增量`INC`，单操作数：

```assembly
INC DST
```

把目的指明的内容加`1`送回目的：

$$(DST) + 1 \to DST$$

既然是目的，显然不能是立即数。`CPU`按结果设置除`CF`外五个标志，对`CF`无影响。无影响就是执行前`CF`什么状态，执行后还什么状态。

### 双字相加为什么从低字加起

教材`46`页例`3.2`是结合加法的编程实例。`DVAR`开始连续`8`字节放两个`32`位数`A`和`B`，每个占双字，编程序算`C=A+B`。

分析一下。`DVAR`开始前`4`字节放`A`，后`4`字节放`B`。数据段用`DB`定义，若`A=00127654H`，按低字节放低地址依次是`54H`、`76H`、`12H`、`00H`；若`B=00049821H`，依次是`21H`、`98H`、`04H`、`00H`。

低地址放的是加数低位，多字节相加必须从低位加起。代码段编程，用哪种存储器寻址找到这些单元取数都行。书上又定义了：

```assembly
DVARC DD 1 DUP(?)
```

放结果，至少四个单元，高位进位还要不要单元另说，这个题一看就没进位。我把变量用分配示意图画出来了，代码段编片段，完整程序的段定义、初始化还没讲，现在只编段内片段，听懂了没有。

先取低字加低字：

```assembly
LEA SI, DVAR
MOV AX, [SI]
ADD AX, [SI+4]
```

`LEA`取`DVAR`偏移给`SI`，`[SI]`间接把一个字给`AX`，`[SI+4]`相对找到另一个加数低字，`ADD`相加和在`AX`。然后存低字结果：

```assembly
MOV WORD PTR DVARC, AX
```

直接写`MOV DVARC, AX`行吗。不行。`DVARC`是`DD`双字变量，`AX`是字类型，直接寻址必须加`WORD PTR`说明，中间有个空格，看到了没有。

再做高字，要考虑进位。`SI`增`2`也行，不增用相对也行：

```assembly
MOV AX, [SI+2]
ADC AX, [SI+6]
MOV WORD PTR DVARC+2, AX
```

`[SI+2]`把第一个加数高字给`AX`，`ADC`加`[SI+6]`那个字，和在`AX`，写到`WORD PTR DVARC+2`。编到这题目功能就完成了。

### 三条减法指令的对应关系

再看算术第二类减法，一共五条，加法三条减法五条。先看和加法对应的。

第一条不带借位减`SUB`，双操作数：

```assembly
SUB DST, SRC
```

目的减源，差送回目的，源不变，按差设置六个标志。和不带进位加对应。

第二条带借位减`SBB`：

```assembly
SBB DST, SRC
```

目的减源再减借位`CF`，`CF`要么`0`要么`1`，差送回目的，源不变，按差设置六个标志。操作类型由操作数类型定，一方明确双方明确，以前讲过。

第三条减`1`指令`DEC`：

```assembly
DEC DST
```

把目的指明的内容减`1`送回目的，可以寄存器寻址可以存储器寻址。按差设置除`CF`外五个标志，对`CF`没影响，和`INC`一样。

### AL等于FF时INC后CF是多少

有一年考试出过：若`AL=FFH`全`1`，当前`CF=0`，`8086`执行`INC AL`后，`AL`等于多少，`CF`等于多少。填空题。

用打草稿吗。`AL`全`1`加`1`等于多少。肯定`0`，只能放`8`位，一考就错。有进位，肯定有进位，但`INC`不影响`CF`，所以`CF`依然`0`。明白了吗。凡是打草稿的肯定出错，记住这一条就够了。

## 比较指令与单条件转移指令
> 对应分集：P36 | 原始标题：《比较指令与单条件转移指令》

我上次把`SUB`、`SBB`、`DEC`讲完了，今天把减法后两条收尾。第四条比较指令是程序分支的关键，单条件转移的十条全从它长出来。

### 比较指令只置标志不回送

第四条叫比较指令（`Compare`），助记符`CMP`，双操作数。这是一条特殊的减法：

```assembly
CMP DST, SRC
```

功能是用目的指明的内容减源指明的内容，差既不送回目的，也不影响源，只是按差设置六个状态标志。叫比较就是这个意思。

程序里经常对两数比谁大谁小或是否相等，按结果分支。分支要抓条件，就用`CMP`产生条件。假设两数一个是`α`一个是`β`，先比较就是做减法，按运算产生条件：`CF`、`SF`、`ZF`、`PF`、`OF`都是条件，`AF`辅助进位辅助借位只是`BCD`调整用，不算条件。六个除`AF`剩五个条件。

产生了条件就去测条件，满足干什么，不满足干什么，这就是有条件二分支。分支前要先产生条件，大多数场合用比较产生，当然加法减法也能产生，但在不想破坏目的和源时只有用`CMP`。这是编程思路。

比如两数都是八位，把`α`给`AL`：

```assembly
MOV AL, α
CMP AL, β
```

源用立即数寻址，通过比较就产生了这些条件。`8086`里按单个条件就有转移指令。按`CF`就有`JC`有进位转、`JNC`没进位转，转到哪去。按前面转移寻址，目的地起个标号，这条就是段内相对也就是段内直接。按`SF`就有`JS`结果为负转、`JNS`结果不为负转。

### 零标志对应的两条等效写法

按`ZF`也有两条。`JZ`结果为`0`转。两数比`ZF=1`说明差`0`，差`0`说明两数相等，`8086`里相等用`E`表示，所以`JZ`等效写成`JE`。写`JE`写`JZ`汇出来代码一样，听明白了没有。`ZF=0`说明不等，不等转就是`JNZ`，也可写`JNE`。

按`PF`也有两条：`JP`结果低`8`位`1`个数偶数时转，`JNP`不是偶数时转。按`OF`也有两条：`JO`有溢出转，`JNO`没溢出转。

这样两数比较产生五个条件，每个条件对应两条，我脑子里就记了十条条件转移指令。这些在哪。教材`63`页`3.9.2`节有条件转移，表`3.6`前半就是单个条件对应的转移，这块我就讲完了。表下半还有条件转移，什么意思，下次看。

| 测试条件 | 为1转移 | 为0转移 |
| :--- | :--- | :--- |
| `CF`进位借位 | `JC` | `JNC` |
| `SF`符号为负 | `JS` | `JNS` |
| `ZF`结果为零 | `JZ`/`JE` | `JNZ`/`JNE` |
| `PF`偶校验 | `JP` | `JNP` |
| `OF`溢出 | `JO` | `JNO` |

## 带符号数求绝对值与乘法标志判断
> 对应分集：P37 | 原始标题：《带符号数求绝对值与乘法标志判断》

我前面把比较和单条件转移讲完了，今天拿个完整例题把分支程序的三步走一遍，顺手把乘法标志的影响也讲了。

### BUFFER字变量的绝对值算法

例如存储器`BUFFER`单元有个`16`位带符号数，求绝对值放回原处。

汇编编程第一步是分析题目，提出算法思路。`BUFFER`是字单元，数据段一般`DW`定义，设里面放`X`。数学上：

$$|X| = X, X \ge 0; |X| = -X = 0-X, X < 0$$

`X>=0`本身就是绝对值不用动，`X<0`绝对值是`-X`，计算机里求`-X`就是求补，用`NEG`指令。

第二步画流程图。开始框结束框必须椭圆框，矩形是处理框不能混用，判断用菱形，跨页用带标号圆连接符。逻辑是：`CMP`把`X`和`0`比，两数比影响符号标志`SF`。`SF=1`说明最高位符号位`1`结果为负，测`SF=1`用`JS`，测`SF=0`用`JNS`。若`SF=1`即`X<0`，执行`NEG`求补写回`BUFFER`；若`SF=0`即`X>=0`直接退出。典型的条件二分支。

第三步编程序。完整汇编一般有堆栈段、数据段如`BUFFER DW ?`、代码段，具体代码段流程就是上面比较分支求补，细节按三段写全就行。

### 无符号乘法的高半部判断

这条执行后状态标志不确定没意义，其余没定义，乘法只影响`CF`和`OF`。如果`OF`和`CF`同时`0`，说明高半部积无效。比如字节乘高半部在`AH`，`AH=0`，只要处理低`8`位就行；字乘就是`DX=0`。

如果两标志同时`1`，说明高半部有有效积。比如字节乘字节积超`255`，`AH`里有积，`CF`、`OF`自动置`1`。处理积时要不要处理高半部，就测这两标志。

带符号乘助记符`IMUL`，`CPU`就知道被乘数乘数都是带符号数。

> **提示**：乘法执行后只看`CF`、`OF`，去测`ZF`、`SF`没有意义。

## 带符号乘除法与商余数规则
> 对应分集：P38 | 原始标题：《带符号乘除法与商余数规则》

我上次把无符号乘法标志讲了，今天把带符号乘和除法一次讲完。乘除用的少，但必须要掌握。

### 带符号乘法的高位是符号扩展

字节乘，被乘数隐含`AL`，乘数由源寻址指明但不能是立即数，乘出`16`位积高`8`位`AH`低`8`位`AL`。后边就不一样了，带符号乘执行后也只影响`CF`和`OF`。

如果`CF`和`OF`同时`0`，说明`AH`无效。对无符号乘，`CF`=`OF`=`0`说明`AH=0`。但带符号乘`CF`=`OF`=`0`说明`AH`是`AL`有效积的符号扩展。有效积在`AL`，`AL`最高位是符号位，`AH`就是它扩展：`AL`最高`0`积为正`AH`扩展八个`0`即`00H`，`AL`最高`1`积为负`AH`扩展八个`1`即`FFH`。

就像以前讲的，`-1`补码按`8`位是`FFH`，按`16`位是`FFFFH`，高`8`位就是符号扩展，不扩展值就变了。

字乘被乘数隐含`AX`，源指明`16`位乘数，乘出`32`位高`16`位`DX`低`16`位`AX`。带符号字乘`CF`=`OF`=`0`说明`DX`无效，此时`DX`就是`AX`符号扩展。反之字节`AH`或字`DX`有有效积，两标志自动置`1`，高位不能丢。

### 除法指令的两种类型

实际编程乘除比加减少得多，但必须掌握。算术第四种除法，分无符号和带符号：

```assembly
DIV SRC
IDIV SRC
```

必须是源操作数，源不能是立即数，和乘法同规范。操作类型全看源类型：源给字节就字节除，源给字就字除。

### 字节除与字除的隐含寄存器

以无符号为例。字节除被除数隐含目的里，必须`16`位隐含`AX`，除数是源给的`8`位数，`16`位除`8`位。结果商自动`AL`，余数自动`AH`。

字除被除数隐含`32`位，高`16`位`DX`低`16`位`AX`组成`DX:AX`，除数是源指明的`16`位数，`32`位除`16`位。结果商自动`AX`，余数自动`DX`。

```text
字节除:  AX(16被除数) / SRC8  -> AL商, AH余数
字除  :  DX:AX(32被除数) / SRC16 -> AX商, DX余数
```

读图说明：被除数、商、余数位置全隐含，指令里只写除数。

### 商余符号与标志无定义

带符号除商余位置和无符号同，但符号守两条：商同号正异号负，余数始终和被除数同号。被除数正除数正商正余正，被除数正除数负商负余正，被除数负除数正商负余负，被除数负除数负商正余负。

> **结论**：无论带符号还是无符号除法，执行后对`CF`、`ZF`、`SF`、`OF`、`PF`、`AF`六个标志均无定义，执行完去测标志没意义。

应用例如把`8001H`单元字节无符号数做除法，步骤就是按字节除把被除数先放`AX`，除数寻址给出，再`DIV`，商余按上面位置取，具体数字按题面代入就行。

## 符号扩展指令与BCD加法调整
> 对应分集：P39 | 原始标题：《符号扩展指令与BCD加法调整》

我前面把加减乘除讲了，加减乘除里还剩第五类符号扩展和最后一类`BCD`调整。今天先把符号扩展讲完，加法`BCD`调整讲透。

### CBW与CWD的扩展规则

符号扩展两条。`CBW`无操作数，隐含把`AL`中`8`位带符号数扩展到`AX`变`16`位，扩展后高`8`位`AH`低`8`位原来`AL`，`AH`是`AL`符号扩展。

`CWD`隐含把`AX`中`16`位带符号数扩展成`32`位，高`16`位`DX`低`16`位`AX`，`DX`是`AX`符号扩展。两条不影响标志，但归算术类，设计目的就是有些运算要类型一致。

举例求`Y=A*B+C-18`，`A`、`B`、`C`全字节变量。数据段`DATA_A`单元放`A`，`DATA_B`放`B`，`DATA_C`放`C`，具体数不管；`A*B`字节乘字结果，`Y`显然`16`位，`DATA_Y`用`DW`放结果。代码段直接编功能片段，段定义初始化还没讲不管。

```assembly
MOV AL, DATA_A
IMUL DATA_B
MOV BX, AX
MOV AL, DATA_C
CBW
ADD AX, BX
SUB AX, 18
MOV DATA_Y, AX
```

`MOV AL, DATA_A`取出`A`，`IMUL DATA_B`带符号乘直接寻址读`B`，积`16`位在`AX`。`AX`要加`8`位`C`类型不一致，先把中间积暂存`BX`。`MOV AL, DATA_C`再`CBW`把`C`扩展`16`位，`ADD AX, BX`相加，`SUB AX, 18`得`Y`，`MOV`到字`DATA_Y`。题做完。

实际工程常量表达式常用`EQU`定义符号常量，比如`CC=18`，复杂表达式等值给符号常量，用到就代替，这里用了一次。

### BCD运算的调整时机

第一章说过十进制用`BCD`码，`BCD`数有非压缩和组合两种表示。十进制用`BCD`表示后允许`BCD`形式加减乘除，但`CPU`执行按二进制看，结果可能错，就要调整。

加减先运算后调整，除法先调整后运算，这点要注意。加减调整分非压缩组合各一套，乘除只能非压缩，所以只有非压缩乘除调整。加法组合调整`DAA`，非压缩调整`AAA`，都隐含对`AL`调。

### 组合BCD加法调整实例

复习组合如例`3.15`算`56+73`：

```assembly
MOV AL, 56H
ADD AL, 73H
DAA
```

必须`AL`累加器，不然调前还要送`AL`。`CPU`把`56H`加`73H`看二进制，加得`C9H`即`1001 0011`，但正确应`129`，错了。`DAA`对`AL`调，低`4`位高`4`位各看是否超`9`加`6`修正。低没超`9`且`AF`没置`1`不修正加`0`，高超`9`加`6`修正，加下来`AL=29H`，进位`CF=1`，连`CF`读就是`129`。组合高位向前进位百位在`CF`放着。

### 非压缩BCD加法调整实例

非压缩如例`3.13`算`4+8`：

```assembly
MOV AL, 04H
ADD AL, 08H
AAA
```

`04H`加`08H`二进制得`0CH`，不对，用`AAA`调。`CPU`第一步低`4`位超`9`加`6`修正，高位不加，修正得`1000`进`1`使`AF=1`。第二步高`4`位清零低`4`位不变得`02H`，个位`2`出来了。第三步把`AF`送`CF`同时送`AH`，`AH=01H`。最后结果在`AX=0102H`，对了。非压缩比组合复杂得多，所以工程加法多用组合运算。

## BCD减法乘除调整与逻辑运算指令
> 对应分集：P40 | 原始标题：《BCD减法乘除调整与逻辑运算指令》

我上次把`BCD`加法调整讲完了，今天把减法乘除调整收尾，顺手进`3.6`逻辑运算。记住一句话：加减乘先运算后调整，只有除法先调整后运算。

### ASCII加法就是分离BCD加法

讲减法前补个知识点。分离`BCD`运算把加数看成字符也一样，比如字符`'8'`的`ASCII`是`38H`，高`4`位都是`0011`。两字符相加高位得`0110`，`ADD`后`AL=6CH`。但`CPU`执行`AAA`第二步把高`4`位清零，调完和高位直接用分离`BCD`一样。

所以有些教材把分离`BCD`加法叫`ASCII`码加法，分离加法调整叫`ASCII`调整，原理完全一致。

### 组合与分离减法调整指令

减法`BCD`同样分组合与分离：组合减调整`DAS`，分离减调整`AAS`，都隐含对`AL`调，调完按结果正常设置六个标志。`DAS`对`AL`组合差减`6`修正，加法加`6`减法减`6`。

看例`3.17`组合`31-87`：

```assembly
MOV AL, 31H
SUB AL, 87H
DAS
```

数学正确应`-56`。`CPU`先二进制减：

$$00110001B - 10000111B = 10101010B(AAH)$$

最高位借位`CF=1`，借了百位`100`，这个概念不能丢。此时`AL=AAH`，低`1010B>9`高`1010B>9`，高低都要减`6`即减`66H`：

$$AAH - 66H = 44H$$

调后`AL=44H`，但`CF=1`借了`100`，实际`-100+44=-56`。结果要连借位一起读。

### 乘法BCD调整与除法先调后算

第三种乘法只能分离，助记符`AAM`。看例`3.18`分离`7*8`：

```assembly
MOV AL, 07H
MOV BL, 08H
MUL BL
AAM
```

字节乘被乘数隐含`AL`，`7*8=56`十进制即`38H`，此时`AX=0038H`纯二进制。但分离`BCD`期望十进制`56`表示`AX=0506H`，不对。`CPU`执行`AAM`对`AX`积做除`10`，商放`AH`余数放`AL`。`0038H`除`10`商`5`余`6`，恢复`AX=0506H`，对了。`AAM`只影响`SF`、`ZF`，`55`页写了，实际用不着我不讲。

最后一类除法调整`AAD`。除法只能分离，第二除前先调后算。看例`3.19`算`27/4`，被除数必须分离表示：

```assembly
MOV AX, 0207H
MOV BL, 04H
AAD
DIV BL
```

`CPU`执行`AAD`隐含对`AX`调，原则是`(AH)*10+(AL)->AX`，调完`AX=27`二进制。然后`DIV BL`用`AX`除`4`，商`AL`余数`AH`。做分离除一定先调后算，和前面加减乘先算后调不一样。`AAD`正常影响`PF`、`SF`、`ZF`，其余三未定义。调完算术类讲完。

### 逻辑运算与标志设置

现在看`3.6`逻辑运算，一共五条。第一章二进制讲过`AND`、`OR`、`XOR`、`NOT`四条，今天加一条。逻辑属运算，段寄存器不能参加，寻址六条也要守。

与操作助记符`AND`，双操作数：

```assembly
AND DST, SRC
```

目的和源按位与送回目的，源不变。第二章就接触过，没接触的是后一句：`CPU`执行与或异或后`CF`、`OF`自动清零，要注意。有时考试出`AND AX, BX`后`CF`等于多少，不用算就是`0`，考概念。书上还写`AF`清零，实际`AF`没定义。

### 或异或测试求反指令

有了与，或就容易了：

```assembly
OR DST, SRC
```

目的和源按位或送回目的，只能按字节或字，`8086`没有双字运算。标志和与一致：`CF`、`OF`清零，`SF`、`ZF`、`PF`按结果设。

异或：

```assembly
XOR DST, SRC
```

按位异或送回目的，`CF=0`、`OF=0`，`SF`、`ZF`、`PF`按结果设。第二章讲应用时什么场合用与或异或必须分清。

今天新加测试：

```assembly
TEST DST, SRC
```

目的和源按位与，但特殊的与，结果既不送回目的也不破坏源，双方保持不变。唯一目的就是按与出结果设标志：`CF`、`OF`清零，`SF`、`ZF`、`PF`正常设。

最后求反：

```assembly
NOT DST
```

单操作数，对目的按位取反送回目的。重要一点是`NOT`对六个标志全无影响，逻辑里影响标志的只有前面四条`AND`、`OR`、`XOR`、`TEST`。

## 逻辑运算习题与移位循环移位指令
> 对应分集：P41 | 原始标题：《逻辑运算习题与移位循环移位指令》

我逻辑运算概念讲完了，今天先把`3.10`题里剩的几问讲透，下午下课你们在作业本独立做一遍，然后进`3.7`移位类。

### 测试BX位1位2同时为零

`3.10`第`4`问：测试`BX`位`1`和位`2`，同时为`0`时`AL`置全`1`，否则`AL`清零。

`BX`是`16`位，位`0`位`1`位`2`往上数。测特定位用与：测的位与`1`，不测的位与`0`，任何数与`0`都是`0`，待测两位原来全`0`相与结果肯定`0`。结果全`0`零标志`ZF=1`。只测不破坏`BX`，不能用改目的的`AND`，必须`TEST`。位`1`位`2`掩码二进制`0000 0000 0000 0110B`即`0006H`。用`JZ`测`ZF`，为`0`跳`L1`置全`1`，否则清零，清零后必须`JMP`跳过置`1`段，不然顺序执行覆盖了：

```assembly
TEST BX, 0006H
JZ L1
MOV AL, 00H
JMP L2
L1: MOV AL, 0FFH
L2:
```

### 有一位为零的两种理解

第`5`问：位`1`位`2`有一位为`0`时`AL`置全`1`，否则清零。位`1`位`2`组合四种`00`、`01`、`10`、`11`，汉语有一位为`0`有歧义。

按只有一位为`0`理解，只含`01`、`10`。这两种相与后低`8`位`1`个数都是`1`个奇数，奇偶标志`PF=0`；而`00`零个偶数、`11`两个偶数`PF=1`。只看奇偶就能区分恰好一位`0`，按`PF`条件转就行。

按只要有一位为`0`理解，含`00`、`01`、`10`。先判全`0`：测`ZF=1`就是`00`满足跳置`1`；`ZF=0`再测`PF`判单`1`即`01`或`10`。要两次条件转。语义歧义的题写代码前先注释说明假设。

第`8`问把`AX`各位取反：

```assembly
NOT AX
```

第`9`问`DX`第`7`位取反其余不变。取反位与`1`异或`0 XOR 1=1`、`1 XOR 1=0`，保持位与`0`异或`b XOR 0=b`。第`7`位`1`的`16`位掩码`0080H`：

```assembly
XOR DX, 0080H
```

第`10`问`CX`高低`8`位互换，最简直接换高低字节：

```assembly
XCHG CH, CL
```

### 逻辑算术移位指令格式

`3.7`移位类一共八条，分两类：移位四条，循环移位四条。移位是把操作数左或右移`1`位或若干位。被移数看无符号叫逻辑移位，看带符号叫算术移位，所以分逻辑算术两种。

逻辑算术都分左右。逻辑左移`SHL`：

```assembly
SHL DST, CNT
```

把目的左逻辑移`CNT`次。目的可以字节或字通用寄存器或存储器，段寄存器不能移位，移位是运算凡运算段都不能参加。移位次数`CNT`约定八条全同：`CNT=1`直接写`1`，`CNT>1`不能直接写，必须先送`CL`写成`, CL`。

逻辑右移`SHR`：

```assembly
SHR DST, CNT
```

右逻辑移`CNT`次，语法`CNT`约定和`SHL`完全一致。

### 移位执行过程与溢出判断

以`SHL`字节`D0`到`D7`为例：`D0`进`D1`，`D1`进`D2`，直到`D6`进`D7`，最高`D7`移出进`CF`，最低`D0`空出`CPU`自动补`0`。无符号有效范围左移一次相当于乘`2`。

`SHR`反过来：最高补`0`，最高进次高依次右移，次低进最低，最低移出进`CF`。

逻辑两条加算术两条共四条移位执行后，`CPU`按结果正常设置除`AF`外五个标志`CF`、`ZF`、`SF`、`PF`、`OF`，`AF`未定义。`OF`特别说明：看执行前后最高位符号变没变，变了`OF=1`，否则`0`。只有移`1`次看`OF`有意义，超`1`次`CPU`也设`OF`但失去判断意义。

算术移位带符号数。算术左移`SAL`，算术右移`SAR`：

```assembly
SAL DST, CNT
SAR DST, CNT
```

以`16`位`D15`到`D0`看`SAR`：`D15`符号位，右移时数据右移`D15`进`D14`依次下移，最高符号位移的同时保持原值实现符号扩展，最低`D0`移出进`CF`。算术左移朝左，次高进最高，最高原符号进`CF`，最低补`0`。

> **结论**：算术左移和逻辑左移是一回事`SAL`同`SHL`，只有逻辑右移`SHR`和算术右移`SAR`不同，四条影响除`AF`外五个标志。

### 用移位代替乘法提高速度

举例做`5*12`。当然能用乘法：

```assembly
MOV AL, 5
MOV BL, 12
MUL BL
```

但`CPU`执行乘除比别的慢十几倍几十倍，为提速简单乘除要改写。连加五遍也行，但我要求移位实现。左移一次乘`2`，两次乘`4`，三次乘`8`，四次乘`16`，没有直接乘`12`，用分配律：

$$5 \times 12 = 5 \times (4+8) = 5 \times 4 + 5 \times 8$$

`5*4`左移两次，`5*8`左移三次，相加：

```assembly
MOV AL, 5
MOV CL, 2
SHL AL, CL
MOV BL, AL
SHL AL, 1
ADD AL, BL
```

`AL`左移两次得`5*4`暂存`BL`，`AL`再左移一次得`5*8`，`ADD`相加`AL`就是`5*12`。条数多了占内存，但省时间快得多，实际为提速就用这技巧，缩小倍数就右移。

### 循环移位大小环指令

第二类循环移位。概念是操作数字节或字，左右移最高移出肯定进`CF`。不带进位小环：最高移出同时送最低闭环，每移最高既进`CF`又回最低。带进位大环：最高进`CF`，原`CF`进最低，含`CF`大环。所以两大类四条：

```assembly
ROL DST, CNT
ROR DST, CNT
RCL DST, CNT
RCR DST, CNT
```

`ROL`循环左，`ROR`循环右，最高最低同时送`CF`；`RCL`带进位左，`RCR`带进位右，目的和`CF`大环移`CNT`次。`CNT`约定和基本移位完全一致。

四条执行后只影响`CF`和`OF`，其余四没定义。书上出入以黑板为准，最常用最有意义就是`CF`。

实例若`(BX)=10110110B`，`CF=1`，`(CL)=3`，`CPU`执行循环移位就按大小环一位一位转，移出进`CF`，小环回位大环经`CF`，具体结果按三要素一步步推就行。

## 无条件段间转移寻址方式
> 对应分集：P42 | 原始标题：《无条件段间转移寻址方式》

我上节把`3.7`移位讲完了。`3.8`标志控制像`CLC`清`CF`、`CLI`清`IF`，`51`到`62`页自己看就行。今天补`3.9`转移指令漏的段间部分。

### 转移指令的两大分类

`8086`转移两大类：一大类无条件转移，一大类条件转移。条件转移像前面`CMP`引出的`JZ`、`JNZ`、`JS`、`JNS`等等，还有`3.10`要讲的循环控制`LOOP`，也属条件转移。这是两大类。

无条件里讲转移寻址用过`JMP`学过了，后面子程序调用`CALL`也属无条件。无条件从寻址看有段内段间，各有直接间接，讲转移寻址时段间直接间接我漏掉了，今天补。

条件和循环控制这一大类只能段内转。括号写个短，就是以当前`IP`为中心负或正转，范围不能超`-128`到`+127`字节。寻址全属段内直接也就是段内相对，当时讲过。

### 段间直接转移的FAR写法

比如我定义代码`1`段一部分程序，另一部分放代码`2`段，代码`2`段首址标号`ABC:`。代码`1`段执行期间无条件`JMP`到另一代码段实现段间转，按段间直接就是`JMP ABC`。

但汇编汇这条不知道`ABC`类型。标号有近程远程即`NEAR`、`FAR`型，汇编不知道目的地类型。为让它按远程`FAR`汇，必须写成：

```assembly
JMP FAR PTR ABC
```

告诉汇编我要远程转，`ABC`是`FAR`型。汇出来就是段间无条件转移代码格式。

格式是这样：`1`字节操作码，后面四个字节两字：前一字放目的地偏移`OFFSET ABC`，后一字放段基`SEG ABC`。一共`5`字节，`8086`最长指令。

`CPU`执行译码知道远程转，操作码下字单元取一字给`IP`，下下字单元再取一字给`CS`。有了`CS`和`IP`，一下指到目的地，实现段间远程转。

从书写看指令直接写出目的地地址，叫段间直接寻址；从`CPU`原理看`5`字节直接给出目的地地址。所以不管书写原理只能叫段间直接寻址。不像段内直接还能叫相对，段间直接只能叫直接。这条`JMP`寻址就是段间直接寻址。

### 段间间接转移的DD定义

段间无条件还能段间间接。比如`DS`数据段定义变量`TABLE`：

```assembly
TABLE DD ABC
```

`TABLE`用`DD`定义，单元放`ABC`。`ABC`是另一代码段首址标号，按伪指令定义`DD`放的是偏移加段基四个字节。`JMP`时间接从这个双字单元取出偏移送`IP`、段基送`CS`，就实现段间间接转。具体指令形式和段内间接一样，只是取的是四个字节，实际应用较少但要会认。

## 循环程序结构与循环控制指令
> 对应分集：P43 | 原始标题：《循环程序结构与循环控制指令》

我前面把转移补完了，今天讲循环控制。循环程序至少四部分，循环控制指令四条，先把结构立住。

### 循环程序的四部分组成

参数改完下面循环控制。计数循环显然一条`LOOP`：让`CX`减`1`，没减到`0`又从标号`L1`循环工作一遍：

```assembly
LOOP L1
```

在这转`CX`圈，每次工作参数修改，`CX`减`1`再转。`CX`减到`0`退出循环体。

退出干什么。做结果处理。循环完有结果，结果往哪传往屏幕输都要处理。这部分我打中括号，可有可无。好多手册参数中括号就这意思。如果结果处理在循环体里每次都处理了，这里就不用了。

结果处理完还有别的工作接别的工作，没有就结束。通过这个结构，我一面讲`LOOP`减`1`循环，一面这就是循环程序结构：参数初始化、循环工作、参数修改、循环控制，可选结果处理。次数已知顺序就这样，先初始化下来工作下来修改下来控制，标准结构。

### LOOPZ与LOOPE的双条件循环

第二条`LOOPZ`等效`LOOPE`：

```assembly
LOOPZ 标号
LOOPE 标号
```

`Z`结果为`0`，`E`相等，讲比较时两数相等肯定结果`0`，`ZF=1`就是相等，转到标号。

功能分两步：第一和`LOOP`一样`CX`减`1`送`CX`：

$$(CX)-1 \to CX$$

第二判断：`CX`减`1`不等于`0`，且满足结果为`0`即`ZF=1`，则循环：

$$若(CX)
e 0且ZF=1则循环$$

`CX`等于`0`或`ZF=0`任一不满足就退出顺序下。特别强调这条本身不影响标志，测的`ZF`显然是前方运算影响的`ZF`，抓住这一点。

这种很适合指定区域找不同字符，找到不同自动退出。

### 用EQU求字符串长度

数据段定义：

```assembly
STRING DB '111111211'
COUNT EQU $-STRING
```

串里初衷全字符`'1'`，怕放错找有没有和`'1'`不同，常用`LOOPZ`。循环次数就是字符个数，不能手数，一数错二串长数到什么时候，要科学统计求长度`COUNT`。`$`是汇编当前计数器当前值，汇到哪就是那单元偏移，减`STRING`偏移就是串长字符个数。实际编程求前方串数据个数就用这表达式。

代码段内存从`STRING`开始，前六单元全`'1'`即`31H`，接下来`'2'`即`32H`。程序就是初始化`CX=COUNT`，循环工作比对，`LOOPZ`控制，一见不同退出，具体代码按四部分套就行。

### JCXZ防止零次循环空转

一开始循环次数就`0`，还扎进循环体工作，一开始`CX`减`1`变`FFFFH`，跑`65536`次白跑。所以一开始测`CX`等于`0`吗，等于直接退出，不等才循环，就用`JCXZ`。

像书`66`页`3.10.4`：

```assembly
MOV CX, VAR1
JCXZ DOWN
```

`VAR1`字单元内容给`CX`当次数，一开始怕`0`，`JCXZ DOWN`等于`0`直接退到`DOWN`，不等做循环工作。这就是循环控制。

## 先判定循环结构与统计1的个数
> 对应分集：P44 | 原始标题：《先判定循环结构与统计1的个数》

我上次叫你们带着问题休息：先判定后工作的结构什么场合用。今天看个例子就明白了，循环有两种结构，一种先工作后判定，有些场合要先判定后工作。

### 统计BX中1个数的循环实现

看例子：测`BX`有几个`1`，`16`位数据统计`1`个数。按前面先工作后判定结构想想方法。

`BX`共`16`位，朝右或左移，每移一次移出位在`CF`，测`CF`就测出是否为`1`。工作循环`16`次，次数已知，按这思想编：

```assembly
MOV CX, 16
MOV AX, 0
R2: SHR BX, 1
JNC R1
INC AX
R1: LOOP R2
```

先`MOV CX, 16`初始化次数，`MOV AX, 0`清零放结果。`SHR`把`BX`右移一次移出进`CF`，`JNC`测`CF`，没进位`CF=0`跳`R1`，有进位`CF=1`执行`INC AX`统计一个`1`。`LOOP R2`使`CX`减`1`，没到`0`跳回`R2`再移再测，共`16`遍。`CX`到`0`退出，`AX`就是`BX`中`1`个数。
