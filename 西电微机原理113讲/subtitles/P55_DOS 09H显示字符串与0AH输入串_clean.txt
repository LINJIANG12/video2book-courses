### [02:12] DOS 09H号功能调用功能概述

09H号DOS功能调用的功能是向屏幕（即向显示器）输出一串字符。

当然，向屏幕输出一串字符的时候，你也可以用DOS 02H号功能调用。用DOS的02H号功能调用，把这一串当中的每一个字符输出都调用一次。你这一串字符里面有多少个字符，DOS 02H号功能就调用多少次，是不是也能向屏幕输出一串？但是很啰嗦了。

向屏幕输出一串字符，一般是用09H号功能调用。

### [00:00] DOS 09H 功能调用的字符串回车换行处理

屏幕输出字符串时，遇到 `$` 字符即认为 9 号功能调用结束。9 号功能调用结束时，整个字符串输出到屏幕上，但是结束符 `$` 本身是不显示的。

因为 `$` 不显示，最终光标就会停在字符串最后一个可见字符的后面。如果想让这一行字符串显示完毕之后，光标自动落到下一行行首（即回车换行），而不是停在末尾，可以在结束符 `$` 之前增加回车和换行控制字符。

定义字符串时可以这样做：在字符串结尾、结束符 `$` 之前，写入：
- `0DH`：回车字符（CR）
- `0AH`：换行字符（LF）
- `$`：字符串结束符

```assembly
; 示例：带回车换行的字符串定义
STRING  DB  'Hello, World!', 0DH, 0AH, '$'
```

此时调用 9 号功能，在遇到 `$` 之前会先输出 `0DH` 和 `0AH`，屏幕执行回车换行，光标就会移到下一行的起始位置。

除了直接在字符串末尾定义回车换行符之外，也可以单独编写一个实现回车换行的子程序。当某行字符串显示完毕后，无论当前光标在何处，直接通过 `CALL` 调用该子程序同样可以完成光标回车换行。在程序设计中，这两种方法都可以根据需要灵活选用。

主程序功能执行完毕后的退出处理代码如下：

```assembly
MOV AH, 4CH
INT 21H
CODE ENDS
END START
```

### [02:30] DOS 09H 功能调用总结与人机交互设计

DOS 9 号功能调用的核心要点：
1. **功能**：向屏幕输出一串字符；
2. **入口参数**：待输出字符串的首地址必须存放在 `DS:DX` 寄存器中；
3. **结束标识**：待输出字符串必须以 `$` 字符作为结束标志。

#### 实际应用：菜单与人机对话设计
例如上机实验中的 4.39 题，题目要求根据键盘按键执行不同分支（按 1 执行功能一，按 2 执行功能二）：
1. **菜单输出**：首先需要在屏幕上打印菜单选项（如 `1. ...`、`2. ...`），这就需要多次调用 9 号功能。数据段中需要对应定义好每个选项对应的提示字符串。
2. **人机对话交互**：
   - 题目中功能 1 要求将键盘输入的字符串中的小写字母转换为大写字母。
   - 当用户在菜单中按 `1` 进入功能 1 后，子程序首先通过 9 号功能在屏幕上输出提示信息，如：`"请输入字符串："`，或者询问 `"Do you want to continue? (Y/N)"`。
   - 用户根据提示输入完毕、程序完成大小写转换处理后，在将结果输出之前，再次调用 9 号功能打印结果提示符（例如 `"小写变大写后的结果是："`），最后输出转换后的字符串。

通过规范的 9 号功能提示信息构建人机对话，可以使整个程序的运行流程清晰直观。

### [05:24] DOS 0AH 功能调用：键盘输入字符串缓冲区

DOS 中常用的键盘输入功能对比：
- **01H、07H、08H 号功能**：均用于从键盘接收单个字符，输入的字符存放在寄存器 `AL` 中。若要输入一串字符，需要循环多次调用，程序设计较为繁琐。
- **0AH 号功能**：专门用于从键盘输入一串字符。该功能自带等待功能，调用后程序会挂起等待用户键入字符，直到用户按下**回车键**（`0DH`）输入才宣告结束。

#### 缓冲区机制与内存分配
输入单个字符时，寄存器 `AL` 即可容纳；但输入一整串字符时，CPU 内部的通用寄存器无法存下，因此必须在内存的**数据段（Data Segment）**中预先开辟一个**键盘输入缓冲区**。

在数据段中定义键盘输入缓冲区示例：

```assembly
DATA SEGMENT
    ; 其他变量定义...
    KEYBUF1  DB  20H     ; 第1字节：定义允许输入的最大字符个数（包含回车符）
             DB  ?       ; 第2字节：系统填入的实际输入字符个数
             DB  20H DUP(?) ; 实际存储输入字符的存储空间
DATA ENDS
```

#### 缓冲区结构说明：
1. **第 1 字节（最大字符数）**：
   - 规定允许用户输入的字符串最大字符个数。
   - 如定义为 `20H`（十六进制），即表示最多允许输入 $20\text{H} = 32$ 个字符。
   - 该参数由一个字节描述，因此输入的最大理论字符数为 $\text{0FFH} = 255$ 个。
2. **第 2 字节（实际输入字符数）**：
   - 保留单元，供 DOS 系统在用户按下回车键后，自动填入实际键入的字符个数（不包含回车符）。
