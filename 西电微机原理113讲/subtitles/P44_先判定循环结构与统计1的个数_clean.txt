### [00:23] 实例引入：统计 BX 寄存器中 1 的个数

刚才说，循环程序有两种结构：一种是“先循环工作、后循环判定”的结构；在有些应用场合，也会出现“先循环判定、后循环工作”的结构。

我们看一个例子：测 $\text{BX}$ 寄存器中有几个 1。  
这里的它就是 16 位数据，在这 16 位数据里面统计一下有几个 1。这个题严格来讲应该是：统计 $\text{BX}$ 中 1 的个数。

---

### [01:18] 算法思路与移位测试原理

如果按照我们前面讲的循环程序结构——“先循环工作，后循环判定”，我们来看。  
这是 $\text{BX}$ 寄存器，我们想想方法。

$\text{BX}$ 寄存器一共 16 位，我把这 16 位数据朝右移或者朝左移，每移一次，移出的那一位是不是在 $\text{CF}$？我去测 $\text{CF}$，是不是就测出了是否为 1。  
那这样的工作要循环多少次？16 次。显然是一个循环次数已知的。按照这种思想，我们来编一下程序。

---

### [01:57] 汇编程序实现与执行分析

```assembly
    MOV CX, 16      ; 循环次数初始化
    MOV AX, 0       ; AX 清零，准备存放结果
R2: SHR BX, 1       ; BX 寄存器的值朝右移一次，移出位进入 CF
    JNC R1          ; 测试 CF，若没进位 (CF=0) 则跳到 R1
    INC AX          ; 否则 AX 增 1（统计到一个 1）
R1: LOOP R2         ; CX 减 1，未减到 0 则跳回 R2 继续循环
```

**程序逻辑解析：**
1. 首先 `MOV CX, 16`，完成循环次数的初始化；
2. 接着 `MOV AX, 0`，将 $\text{AX}$ 清零，准备存放统计结果；
3. 然后通过 `SHR` 指令把 $\text{BX}$ 寄存器的值朝右移一次，移出的这一位置入进位标志位 $\text{CF}$；
4. 接下来通过 `JNC` 测试 $\text{CF}$：如果未进位（即 $\text{CF} = 0$），则跳到标号 `R1`；
5. 否则（即 $\text{CF} = 1$），执行 `INC AX`，让 $\text{AX}$ 增 1，代表统计到了一个 1；
6. 接着执行 `LOOP R2`：使 $\text{CX}$ 减 1，如果还没有减到 0，就跳回标号 `R2`。这样把 $\text{BX}$ 的值再朝右移一次、再来测试，总共循环 16 遍。

等 $\text{CX}$ 减到 0 退出循环后，$\text{AX}$ 中的值，就是统计出的 $\text{BX}$ 中 1 的个数。
