### 汇编语言程序中的语句类型与组成

#### 宏指令语句概述
[00:11]
宏指令语句本身是 8086 指令系统没有的语句、没有的指令，8086 指令系统当中本身没有宏指令语句。

它是由用户通过宏定义伪指令（严格来说属于伪指令）所定义的，或者说是用户开发的一种新的语句。也就是说，有些语句程序员自己是可以开发的，而开发所使用的工具就是宏定义伪指令。

当你开发了这样的宏指令之后，在后边的程序设计当中就可以引用该宏指令。它类似于 C 语言当中的函数：前面定义了一个函数，下边编写程序时就可以引用该函数，引用函数也就是调用函数，两者是一回事。

关于宏指令的具体定义方式，我们在第三章后半部分才会讲到。8086 汇编语言程序中语句的种类就这三种（指令语句、伪指令语句、宏指令语句），常用的主要是指令语句和伪指令语句这两种，这是 3.1 节一开始大家需要掌握的基本概念。

#### 3.1.1 汇编语言语句的组成
[02:27]
下面翻到教材第 25 页，开始讲解 3.1 节中的 **3.1.1 汇编语言语句的组成**（此处汇编语言特指 8086 汇编语言）。

刚才提到汇编语言有三种语句，那么每一种语句是由哪几部分组成的？一般一条语句最多由四部分组成。

##### 1. 变量定义与地址符号化
例如数据定义伪指令语句：

```assembly
DATA1 DB 12H, -12
```

其中 `DB` 称为助记符；后边的 `12H, -12`（中间以逗号分隔）定义了字节型的数据，称为操作数。操作数多于一项时，项与项之间用逗号分隔。助记符是一部分，操作数是一部分，这就构成了两部分。

把 `12H` 这个字节型数据存放在存储器的哪个单元？严格来说，在 `DB` 的左边需要给出该存储单元的地址。但实际编程时所用到的单元非常多，若每个单元的物理/偏移地址都需要程序员记忆，程序设计就会极其繁琐。因此，为了在程序设计中便于引用该单元，通常将该单元的地址进行**符号化**。

打个比方：假如每个同学都是一个存储单元，每个人都有学号，学号就是地址。在日常生活中如果人与人交往全凭学号，记忆会非常复杂；而为每个学号对应一个名字，直接用名字交往，记忆就简单得多。汇编语言程序设计同理，每个存储器单元都有地址，若程序直接与地址打交道会极其复杂；为了简化程序设计，将用到的存储单元地址进行符号化，即起一个符号名称。

例如将该单元命名为 `DATA1`：
- 若后续程序需要将该单元中的 `12H` 读入寄存器 `AL`，直接访问 `DATA1` 单元即可；
- 若要读取后一个数据，访问 `DATA1+1` 单元即可。

在数据定义伪指令左边起的这个符号化名称，称为**变量名**（或简称为变量）。

再例如定义一个字单元：

```assembly
DATA2 DW ?
```

这表示 `DATA2` 是一个字（Word）单元，该字单元的地址用变量名 `DATA2` 代替。若后续执行如下操作：

```assembly
MOV DATA2, AX
```

该指令将源操作数 `AX` 中的内容读出，写入到 `DATA2` 地址对应的存储器字单元中。在程序设计中，如果要将某一步的运算结果写入存储单元，而在初始定义阶段尚无具体数据时，可以使用问号 `?` 预留空间。打问号时其实际数据是一个随机数（开机是多少就是多少），待后续 CPU 执行写入指令后，该单元便存入了目标数据。

##### 2. 语句的四部分结构
在上述伪指令语句中，包含：变量名、助记符、操作数；若在操作数后以分号（`;`）开头，还可以添加注释。因此，一条语句最多由四部分组成：
1. **名称**（Name）
2. **助记符**（Mnemonic）
3. **操作数**（Operand）
4. **注释**（Comment）

关于名称的命名规范：
- 凡是名称，起名时**必须以字母开头**（注：凡是常数/数值必须以 $0 \sim 9$ 开头）；
- 名称包含的字符长度不能超过 31 个字符。

#### 指令语句中的标号与分支逻辑
[08:34]
在程序设计过程中，例如编写了以下指令序列：

```assembly
MOV AX, BX
...
ADD AX, DATA2
JZ  NEXT
```

上述代码中：
1. 执行 `ADD AX, DATA2`，将 `AX` 的内容与 `DATA2` 单元的内容相加，结果送回 `AX`；
2. 执行加法指令后，CPU 会根据运算结果设置标志寄存器中的 ZF（零标志位）；
3. 接着通过 `JZ`（Jump if Zero）指令判断运算结果是否为 0：若 ZF 置 1（表示相加结果为 0），条件满足，跳转到目标地址执行；若不为 0，则顺序执行下一条指令。这构成了典型的条件二分支程序。

在 `JZ` 指令后，需要指定跳转的目的地址。对于程序员而言，具体的数字地址无法即时确定，因此同样可以将该指令的目的地址进行**符号化**。

### 3.1.2 汇编语言中的常数及表达式

[01:21]
下面看 3.1.2 节：汇编语言程序设计中用到的常数（教材第 26 页）。
3.1.2 汇编语言中的常数及表达式。

#### 一、常数

常数有以下几种：

1. **数值常数**
   - **十六进制常数**：以大写字母 `H` 结尾。
   - **二进制常数**：必须以大写字母 `B` 结尾（小写 `b` 不对）。例如：
     ```assembly
     MOV AL, 10110001B
     ```
   - **十进制常数**：结尾可以缺省；不缺省时用大写字母 `D` 表示，但一般都不写，采用缺省形式。

2. **字符与字符串常数**
   - [03:13] **字符常数**：用单引号括起来的单个字符。例如：
     ```assembly
     MOV BL, 'A'
     ```
     汇编时，汇编程序会把该项用字符的 ASCII 码代替，所以这也是一个常数。
   - **字符串常数**：在数据段定义数据时，由单引号括起来的一串字符。例如：
     ```assembly
     STRING DB 'THIS IS ...'
     ```
     其中 `STRING` 是变量名，用单引号括起来的这一串字符就叫字符串常数。

3. **预留/未初始化值（问号 `?`）**
   - [04:09] 在数据定义伪指令中，还可以使用问号 `?`。
   - 问号表明该单元的数据是随机的，开机时内存中是多大就是多大。
   - 在数据定义伪指令当中预留问号的目的，是用于在程序运行期间向其中写入运算结果。这些都叫做常数。

#### 二、表达式

[04:44]
下面看表达式（教材第 27 页）。

表达式的值是**汇编程序在汇编过程当中计算出来的，并不是 CPU 执行指令时计算的**！
CPU 执行指令时完成的是指令助记符所对应的操作（例如 `MOV` 传送操作）。

##### 1. 算术表达式

[05:01]
例如以下指令：

```assembly
MOV AL, 5 + 2 * 3
```

操作数项中写入了一个算术表达式。汇编程序在汇编这条语句时，会先计算出这个表达式的值。

汇编程序在汇编、计算算术表达式的值时，遵循常规的四则运算规则：
- 先括号里边，后括号外边；
- 先乘除，后加减。

这与算术运算规则完全一致。

[06:25]
算术表达式也可以出现在数据定义伪指令中。例如：
写入表达式 $5 \times 4$，汇编程序在汇编时计算出结果为 $20$（即十六进制的 $14\text{H}$）。在相应的存储单元（如 $B_1+2$ 单元）中存放的就是 $14\text{H}$。计算机中的数值内部均使用二进制表示。

[07:07]
在算术表达式中：
- 运算符（`+`、`-`、`*`、`/`、`MOD`）称为**操作符**；
- 参与运算的数值（如 `5`、`2`、`3`）称为**操作数**。

教材第 27 页的算术表达式包含加、减、乘、除、`MOD`（取模）：
- **除法（`/`）**：算术表达式取的是**商**。例如操作数项为：
  $$20 / 3$$
  汇编程序汇编计算出的值等于 $6$（十六进制表示为 $06\text{H}$）。
- **取模运算（`MOD`）**：取的是**余数**。例如：
  $$20 \text{ MOD } 3$$
  $3 \times 6 = 18$，余数为 $2$，计算结果为 $2$。

在实际的程序设计当中，允许操作数项使用算术表达式，但使用得并不多。

##### 2. 逻辑操作表达式

[08:34]
第二种表达式是逻辑操作表达式，包括与（`AND`）、或（`OR`）、异或（`XOR`）、非（`NOT`）表达式。

例如以下指令：

```assembly
AND AL, 21H AND 0FH
```

在这条语句中出现了两次 `AND`，必须注意区分：
1. **第二个 `AND`**（操作数项上的 `21H AND 0FH`）：是**逻辑表达式**，其表达式的值是由**汇编程序在汇编过程中**计算完成的。
2. **第一个 `AND`**：是**指令助记符**，该与操作是由 **CPU 在执行这条指令时**计算完成的。

这两种操作必须分清。逻辑表达式允许在操作数中出现，但很不常用。
