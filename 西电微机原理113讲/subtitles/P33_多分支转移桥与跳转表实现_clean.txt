### [00:59] 多分支程序转移问题的提出

我举个例子，动动脑筋。

比如说，我这地方编了一段程序，这个程序的不同分支处分别是：
- $L_1$：`...`
- $L_2$：`...`
- $L_3$：`...`

我现在叫你干什么呢？实现程序转移。相当于现在要实现程序转移，怎么转？

我举个简单的，按 $AL$ 寄存器的值：
- 若 $AL = 1$，则转到 $L_1$；
- 若 $AL = 2$，则转到 $L_2$；
- 若 $AL = 3$，则转到 $L_3$。

我就举这一截。那么，我让你在红粉笔这一块编一段程序实现这个功能。

能听懂我意思吗？就是在红粉笔括号这一块，你给我编一段程序去检测 $AL$：
- 若 $AL$ 等于 1，跳到 $L_1$ 来；
- $AL$ 等于 2，你就给我跳转到 $L_2$ 来；
- 如果 $AL$ 等于 3，程序就转移到 $L_3$ 来；
- 如果不是 1、2 或者 3，那你给我顺序执行下来。

是不是这个意思？有办法没有？

最简单的办法那就是测嘛：
- 你 $AL$ 等于 1 吗？Yes，是不是跳下来了？No，顺序向下；
- 那你等于 2 吗？Yes，是不是跑过来了？No，顺序是不是又下来了；
- 下来以后又测：看你 $AL$ 等于 3 吗？Yes，跑这儿了；不等于 3 是不是可下来了？

那我这里只有 3 项，如果我给你 20 项呢？那你就像这样一直排下去了：那你 $AL$ 等于 19 吗？No。那你 $AL$ 等于 20 吗？是的，找到了。

顺序比较效率高吗？不高。虽然可以实现，但是效率不高。

### [03:51] 优化思路：利用位移量构建“转移桥”

我举的这个例子就是说，在这个地方你要找一种能提高程序效率的算法。

假如从转移当前 IP 开始到目的地之间，转移跳过去的字节数（相对位移量）没有超过 $[-128, +127]$ 个字节。超过 127 字节处理方式还不一样，但这个也无所谓，就是说这个条件可以不要，重点看段内转移。

你有办法没有？你看我这样作，我来一个笨办法，大家看我这个笨办法行不行。

我建立一个分支跳转表（转移桥）：

```assembly
TABLE:  JMP SHORT L1
        JMP SHORT L2
        JMP SHORT L3
```

你看我在这儿是不是搭桥呢？
如果 $AL$ 等于 1 的话，跳到第一条；从这儿是不是可跳到目的地 $L_1$？如果 $AL$ 是 2 的话，跳到第二条指令，是不是又跳到目的地 $L_2$ 了？

你看这地方还有什么关系呢？如果这些 `JMP` 指令都是 `SHORT` 型的话，那么它们都是双字节指令。把这些指令之间相对位移量排开，位移量是不是按 2、2、2 递增？

我现在都提示到这个位置上了，对不对？

- 当 $AL = 1$ 时，位移量是 0；
- 相当于输入为 $n$ 时，位移量与 $n$ 的关系为：
  $$\text{位移量} = (n - 1) \times 2$$
- $n = 1$ 时：$(1 - 1) \times 2 = 0$，相对位移量是 0；
- $n = 2$ 时：$(2 - 1) \times 2 = 2$，位移量是 2；
- $n = 3$ 时：$(3 - 1) \times 2 = 4$，位移量算出来是 4。

### [07:01] 汇编代码推导与实现

你在前面首先是不是要对 $AL$ 减 1？用减 1 指令（当然普通减法指令 `SUB` 也行）：

```assembly
DEC AL          ; AL = AL - 1
```

减 1 之后，现在是不是要乘 2？乘 2 怎么乘呢？
把 $AL$ 自身相加也行，向左移一位也行。现在没学移位指令就用加法：

```assembly
ADD AL, AL      ; 相当于乘 2: AL = (AL - 1) * 2
```

是不是乘 2 了？然后：

```assembly
MOV AH, 0       ; 高位清零，AX = (AL - 1) * 2
```

清零的目的就是为了扩展并使用 $AX$ 寄存器。

然后把转移桥第一条指令的起始地址标为 `TABLE`，再来一条指令取其偏移地址：

```assembly
MOV BX, OFFSET TABLE    ; 取转移表的基地址
```

把这条指令的偏移地址给 $BX$ 了。

接下来：

```assembly
ADD BX, AX      ; 基地址 + 偏移量，计算出目标跳转指令所在地址
JMP BX          ; 段内间接转移，跳到转移桥对应的分支指令
```

---

### [09:05] 执行过程校验与总结

我们来验证一下执行逻辑：

1. **若 $AL = 1$**：
   $AX = (1 - 1) \times 2 = 0$。给 $BX$ 加 0，执行 `JMP BX` 时，$BX$ 就等于 `OFFSET TABLE`，直接跳到 `JMP SHORT L1`，顺利跳转到 $L_1$。

2. **若 $AL = 2$**：
   $AX = (2 - 1) \times 2 = 2$。在 `TABLE` 的基地址上加 2，执行 `JMP BX` 时跳到第 2 条指令 `JMP SHORT L2`，直接跳到 $L_2$。

3. **若 $AL = 3$**：
   $AX = (3 - 1) \times 2 = 4$。给 $BX$ 加 4，跳到第 3 条指令 `JMP SHORT L3`，直接跳到 $L_3$。

看懂了没有？这就相当于用 `JMP` 指令在这里做了一个**转移桥**（跳转表）。
