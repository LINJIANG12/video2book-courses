通过这个结构，我一方面讲了 `LOOP` 指令控制减 1 循环控制循环体的一个循环结构，另一方面，这就看作是循环程序的结构。

循环程序至少由四部分组成（如果要说全的话还有第五部分）：
1. **参数初始化部分**
2. **循环工作部分**
3. **参数修改部分**
4. **循环控制部分**
5. （可选的）**结果处理部分**

在循环次数已知的情况下，这个结构的顺序就是这样。不管完成什么功能，程序的结构都是这样子，而且顺序都不变：先是初始化，下来循环工作，下来参数修改，下来循环控制，这是标准的。

### [03:27] 循环控制指令：LOOPZ / LOOPE

第二条循环控制指令叫 `LOOPZ`，也等效于 `LOOPE`：

```assembly
LOOPZ 标号
LOOPE 标号
```

这里的 Z 代表结果为 0，E 代表相等。我们讲比较指令时，两数相等肯定结果为 0；反之 ZF 置 1 了就是两数相等。转移到标号。

### [04:13] LOOPZ 指令的功能与执行机制

这条指令的功能分为两步：
1. 第一步，和 `LOOP` 指令一样，让 CX 的内容减 1，减 1 后的差送给 CX：
   $$(CX) - 1 \to CX$$
2. 第二步进行判断：若 CX 减 1 后的值不等于 0（CX 减 1 的结果不影响标志，大家一定要注意，不影响标志），且满足结果为 0（即 $ZF = 1$），则循环到标号指明的目的地：
   $$\text{若 } (CX) \neq 0 \text{ 且 } ZF = 1\text{，则循环}$$

如果这两个条件——CX 等于 0 了，或者 $ZF = 0$ 了，总之这两个条件有一个不满足了，就会退出循环，顺序向下执行。

这里我特别强调过：这条指令的执行并不影响标志位。CPU 执行 `LOOPZ` 指令时所测试的 ZF，显然是 `LOOPZ` 指令前方那一条运算指令执行所影响到的 ZF。大家一定要抓住这一点。

### [06:24] 示例：数据段定义与利用汇编计数器求字符串长度

在数据段中有这样的变量定义：

```assembly
STRING DB '111111211'
```

定义一个 `STRING`，`DB`，单引号里面放的是 `'111111211'` 这一串字符。

在这一串字符里面，初衷放的都是字符 `'1'`。害怕放错了，找一下有没有和 `'1'` 不同的字符，常常就要用 `LOOPZ`。

首先循环控制要知道循环次数。循环次数是多少次？串当中有多少字符就是多少次。

这里有多少字符？程序设计总不能用手一个、两个、三个去数。数的时候有两个问题：第一，数错了怎么办？第二，字符串很长数到什么时候去？所以要用一种科学的办法来统计字符串中字符的个数。

求它的长度、字符的个数，定义为 `COUNT`：

```assembly
COUNT EQU $ - STRING
```

`COUNT EQU` 是一个表达式，这个表达式的值就是串的长度。

表达式中的美元符（`$`）是汇编程序里的当前汇编计数器的当前计数值。汇编到哪个单元了，`$` 就是那个单元的偏移地址。用当前汇编位置单元的偏移地址减去 `STRING` 的偏移地址，两个偏移地址一减，就是串的长度，即串中字符的个数。

在实际的程序设计当中，要求前方定义的字符串或数据单元的个数（注意指的是串中字符的个数，而不是字节内存长度），就要用这样的表达式来求。
