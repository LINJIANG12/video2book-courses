## 映射基础理论

### 映射核心概念与要素

* **映射（Mapping）**

    * > **定义**：设 $X$ 与 $Y$ 是两个非空集合，若存在对应法则 $f$，使得对于集合 $X$ 中的每一个元素 $x$，在集合 $Y$ 中都有唯一确定的元素 $y$ 与之对应，则称法则 $f$ 为从集合 $X$ 到集合 $Y$ 的映射，记作 $f: X \to Y$。

    * 单义性规则：允许集合 $X$ 中多个不同元素对应集合 $Y$ 中同一个元素（多对一合法）；严禁集合 $X$ 中单个元素同时对应集合 $Y$ 中两个不同元素（一对多非法）。

    * 符号规范：大写字母 $X, Y$ 严格表示集合，小写字母 $x, y$ 严格表示集合内的具体元素。

    * 对应约束结构：

    ```text
           【允许：多对一】                   【严禁：一对多（非映射）】
       集合 X            集合 Y           集合 X            集合 Y
      +------+          +------+         +------+          +------+
      |  x1  |----+     |      |         |      |     +--->|  y1  |
      |      |     \--->|  y   |         |  x   |-----+    |      |
      |  x2  |----+     |      |         |      |     +--->|  y2  |
      +------+          +------+         +------+          +------+
    ```

* **象与原象（Image and Pre-image）**

    * > **定义**：在映射 $f: X \to Y$ 中，与元素 $x \in X$ 相对应的唯一确定的元素 $y \in Y$ 称为 $x$ 在映射 $f$ 下的象，记作 $y = f(x)$；元素 $x$ 称为元素 $y$ 在映射 $f$ 下的原象。

    * 作用边界：映射的作用对象为任意非空集合，包含空间点、矩阵、几何图形或抽象实体，不局限于数集。

* **映射三要素（Three Elements of Mapping）**

    * > **定义**：决定映射数学结构的三个核心要素：定义域、对应法则与值域。

    * 定义域（Domain）：记作 $D(f)$ 或 $D_f$，为映射中所有原象构成的集合，满足 $D(f) = X$。

    * 对应法则（Rule）：记作 $f$，规定从输入到输出的具体转换逻辑。

    * 值域（Range）：记作 $R(f)$ 或 $R_f$，为所有实际产生的象构成的集合，满足 $R(f) = f(X) = \{f(x) \mid x \in X\}$。

    * 集合从属不对称性：值域必定是目标集的子集（$R_f \subseteq Y$），但不一定等于目标集；集合 $X$ 元素必须全员参与映射，目标集 $Y$ 中允许存在未被映中的闲置元素。

    * 集合嵌套结构：

    ```text
        集合 X (定义域 Df)                   集合 Y (目标集)
        +-----------------+                +---------------------------+
        |                 |                |                           |
        |   所有元素 x    |===== 法则 f ====>|     值域 Rf = f(X)        |
        |   均被完全映出   |                |   (所有实际产生的象)       |
        |                 |                |                           |
        +-----------------+                |   - - - - - - - - - - -   |
                                           |   未被映到的闲置元素       |
                                           |   (允许存在于 Y 中)        |
                                           +---------------------------+
    ```

### 映射分类与拓扑结构

| 映射分类 | 定义核心条件 | 允许多对一 | 允许目标集存在闲置元素 |
| :--- | :--- | :--- | :--- |
| 一般映射 | $\forall x \in X$ 有唯一 $y \in Y$ | 允许 | 允许 |
| 单射 | $x_1 \neq x_2 \implies f(x_1) \neq f(x_2)$ | 严禁 | 允许 |
| 满射 | $R(f) = Y$ | 允许 | 严禁 |
| 双射（一一映射） | 既是单射又是满射 | 严禁 | 严禁 |

* **满射（Surjection）**

    * > **定义**：值域与目标集合完全相等的映射，即 $R(f) = Y$。

    * 判定条件：对任意 $y \in Y$，均存在至少一个 $x \in X$ 使得 $f(x) = y$。

    * 结构特征：目标集合 $Y$ 中不存在未被覆盖的闲置元素。

* **单射（Injection）**

    * > **定义**：集合 $X$ 中任意两个不同元素的象互不相同的映射，即 $x_1 \neq x_2 \implies f(x_1) \neq f(x_2)$。

    * 逆否等价形式：若 $f(x_1) = f(x_2)$，则必有 $x_1 = x_2$。

    * 结构特征：排除多对一重叠，每个象 $y \in R_f$ 对应的原象具有唯一性。

* **双射（Bijection）**

    * > **定义**：既是单射又是满射的映射，亦称一一映射（One-to-one Correspondence）。

    * 基数等价律：若集合 $X$ 与 $Y$ 均为有限集，且存在双射 $f: X \to Y$，则两集合的元素个数严格相等。

    * 映射分类模式对比：

    ```text
        【单射（非满射）】            【满射（非单射）】             【双射（一一映射）】
       X         Y                X         Y                X         Y
      (x1)---->(y1)              (x1)---->(y1)              (x1)---->(y1)
      (x2)---->(y2)              (x2)---/                   (x2)---->(y2)
               (y3: 闲置)        (x3)---->(y2)              (x3)---->(y3)
     (象互不相同，有闲置)         (象有重叠，无闲置)          (无重叠，无闲置，严格对等)
    ```

* **高阶映射概念（Advanced Mapping Concepts）**

    * > **定义**：依定义域与值域数学空间性质衍生的专门映射称谓。

    * 算子（Operator）：作用在函数空间之间的映射。

    * 泛函（Functional）：将函数空间映射至数域的映射。

    * 变换（Transformation）：集合到自身的映射。

### 逆映射与复合映射

* **逆映射（Inverse Mapping）**

    * > **定义**：设映射 $f: X \to Y$ 为单射，值域为 $R_f$，将每一个 $y \in R_f$ 映射回其唯一原象 $x \in X$ 的映射称为 $f$ 的逆映射，记作 $f^{-1}: R_f \to X$。

    * 存在前提：原映射 $f$ 必须是单射。若非单射，反向对应将产生一对多的非法映射。

    * 域转换关系：$D(f^{-1}) = R(f) = R_f$，$R(f^{-1}) = D(f) = X$。

    * 对消性恒等式：对任意 $x \in X$ 有 $f^{-1}(f(x)) = x$；对任意 $y \in R_f$ 有 $f(f^{-1}(y)) = y$。

    * > ⚠️ **易错点**：切勿将逆映射的定义域与目标集合 $Y$ 混淆。在写出逆映射时，必须写 $f^{-1}: R_f \to X$，而不能盲目写成 $f^{-1}: Y \to X$（除非原映射本身已经证明为双射）。

    * 逆映射反转结构：

    ```text
                +----------------- 原映射 f (必须为单射) -----------------+
                |                                                      |
                v                                                      |
        集合 X (原定义域 Df)                                    集合 Y 中的实际值域 Rf
        +-----------------+                                    +---------------------+
        |                 |                                    |                     |
        |        x        |===================================>|          y          |
        |                 |<===================================|                     |
        +-----------------+                                    +---------------------+
                ^                                                      |
                |                                                      v
                +---------------- 逆映射 f^(-1) (以 Rf 为定义域) ---------+
    ```

* **复合映射（Composite Mapping）**

    * > **定义**：设映射 $g: X \to Y_1$ 与 $f: Y_2 \to Z$，若满足相容性条件 $R_g \subseteq D_f$（其中 $D_f = Y_2$），则对任意 $x \in X$ 均有确定值 $f(g(x)) \in Z$ 与之对应，由此构成的映射称为复合映射，记作 $f \circ g: X \to Z$。

    * 接口相容条件：$R_g \subseteq D_f$（内层函数值域必须包含于外层函数定义域）。若存在 $x_0$ 使 $g(x_0) \notin D_f$，则外层法则无定义，复合映射不成立。

    * 执行顺序特征：在表达式 $(f \circ g)(x) = f(g(x))$ 中，右侧 $g$ 为先执行的内层映射，左侧 $f$ 为后执行的外层映射。

    * 非交换性规则：复合运算一般不满足交换律，即 $f \circ g \neq g \circ f$。例如取 $g(x) = \sin x, f(t) = t^2$ 时，$(f \circ g)(x) = \sin^2 x$，而 $(g \circ f)(x) = \sin(x^2)$。

    * 相容性接口约束结构：

    ```text
        集合 X               集合 Y1                      集合 Z
      +--------+          +------------------------+    +--------+
      |        |          | Y1                     |    |        |
      |   x    |== g ===> |   +----------------+   |== f ==>| f(g(x))|
      |        |          |   | Rg (g的值域)   |   |    |        |
      +--------+          |   +----------------+   |    +--------+
                          |         || 包含于      |
                          |   +----------------+   |
                          |   | Df (f的定义域) |   |
                          |   +----------------+   |
                          +------------------------+
    ```

## 函数概念与表示模型

### 函数本质与两要素

* **函数（Function）**

    * > **定义**：设数集 $D \subseteq \mathbf{R}$，若存在对应规则 $f$，使得对于集合 $D$ 中的每一个实数 $x$，都有唯一确定的实数 $y$ 与之对应，则称对应规则 $f$ 为定义在 $D$ 上的函数，记作 $y = f(x), x \in D$。

    * 变量定义：$x$ 称为自变量，$y$ 称为因变量；集合 $D$ 称为定义域（记作 $D$ 或 $D_f$），实际对应的 $y$ 值的集合称为值域（$R_f = f(D) = \{y \mid y = f(x), x \in D\}$）。

    * 记号辨析：记号 $f$ 代表从输入到输出的对应规则（Mapping Rule）；记号 $f(x)$ 代表自变量取 $x$ 时的具体函数值（实数数值）。

    * > ⚠️ **易错点**：黑体大写字母 $\mathbf{R}$（Real Numbers）代表整个实数集，斜体大写字母 $R$ 或下标形式 $R_f$（Range）代表函数的值域集合，两者概念维度不同，切勿混为一谈。

* **函数两要素（Two Elements of Function）**

    * > **定义**：决定实数域函数的两个核心要素——定义域 $D$ 与对应法则 $f$。

    * 要素归并机理：函数的输出目标集已预先限定在实数集 $\mathbf{R}$，只要定义域 $D$ 与对应法则 $f$ 确定，值域像集 $R_f = f(D)$ 即被唯一锁定，无需独立设置。

* **函数表示方法（Representation Methods of Functions）**

    * > **定义**：呈现自变量与因变量依赖关系的三种经典表现形式：解析式法、表格法与图形法。

    * 解析式法（公式法）：用数学算式表达对应关系。优点是关系明确、便于进行极限、导数与积分推导；缺点是部分实际物理过程难以写出简洁初等算式。

    * 表格法：将自变量的值与对应的函数值一一列成表格。优点是数据直观、查阅迅速，在实验记录和数值采样中极为常用；缺点是只能反映离散数据点，无法展现连续变化全貌。

    * 图形法：在直角坐标系中用平面曲线展示函数变化规律。优点是几何形象直观，极值点、单调区间一目了然；缺点是读数精度受限，难以直接用于高精度的代数计算。

### 经典分段函数模型

* **分段函数（Piecewise Function）**

    * > **定义**：在定义域的不同子区间内需要用不同的解析表达式表示的函数。

    * 分析特性：分段函数的连续性、可导性及分段点处的极限为微积分分析的典型对象。

* **绝对值函数（Absolute Value Function）**

    * > **定义**：取实数绝对值的函数，解析式为 $y = |x| = \begin{cases} x, & x \ge 0 \\ -x, & x < 0 \end{cases}$。

    * 定义域与值域：定义域为 $(-\infty, +\infty)$，值域为 $[0, +\infty)$。

    * 图像特征：图像在第一象限为射线 $y = x$，在第二象限为射线 $y = -x$，两段射线在原点 $(0, 0)$ 处交汇形成折角。

    * 图像结构示意：

    ```text
               y
           \   │   /
            \  │  /
             \ │ /   y = x (x ≥ 0)
    y = -x    \│/
    ───────────●───────────> x
               O (0, 0)
    ```

* **符号函数（Signum Function，sgn）**

    * > **定义**：提取实数符号特征的分段函数，解析式为 $y = \operatorname{sgn} x = \begin{cases} 1, & x > 0 \\ 0, & x = 0 \\ -1, & x < 0 \end{cases}$。

    * 定义域与值域：定义域为 $(-\infty, +\infty)$，值域为离散集合 $\{-1, 0, 1\}$。

    * 图像特征：原点 $(0, 0)$ 为孤立实心点；$x > 0$ 时为起点 $(0, 1)$ 空心的水平射线；$x < 0$ 时为起点 $(0, -1)$ 空心的水平射线。

    * 恒等解耦关系：对任意 $x \in \mathbf{R}$ 恒有 $x = \operatorname{sgn}(x) \cdot |x|$，该公式实现了变量方向（符号）与幅度（绝对值）的代数解耦。

    * 图像结构示意：

    ```text
               y
               │        x > 0, y = 1
               │   o─────────────────>
               │
     ──────────●─────────────────────> x
               │ (0, 0) 实心点
               │   o─────────────────>
               │        x < 0, y = -1
    ```

* **取整函数（Floor Function，[x]）**

    * > **定义**：表示不超过实数 $x$ 的最大整数的函数，解析式记作 $y = [x]$。

    * 阶梯分布：在每个半开区间 $[k, k + 1)$（$k \in \mathbf{Z}$）内函数值恒为整数 $k$，呈现向右半开半闭的阶梯状分布（左闭右开）。

    * > ⚠️ **易错点**：取整函数在正数和零处不易出错，但在负数时极易由于直觉惯性而出错。在数轴上，不超过实数的最大整数必落在其左侧，例如 $[-1.6] = -2$（而非 $-1$），$[-5] = -5$。

    * 阶梯结构示意：

    ```text
        y
        │                     o──── [2, 3) -> y=2
        │               o────●      [1, 2) -> y=1
        │         o────●            [0, 1) -> y=0
     ───┼───o────●─────────────────> x
        │   [-1, 0) -> y=-1
        │
    ```

## 函数分析特性

### 有界性与极值常数

* **有界性（Boundedness）**

    * > **定义**：设函数 $f(x)$ 的定义域为 $D$。若存在常数 $K_1$ 使得 $\forall x \in D, f(x) \le K_1$，称 $f(x)$ 在 $D$ 上有上界；若存在常数 $K_2$ 使得 $\forall x \in D, f(x) \ge K_2$，称 $f(x)$ 在 $D$ 上有下界；若存在正数 $M > 0$ 使得 $\forall x \in D, |f(x)| \le M$（即 $-M \le f(x) \le M$），称 $f(x)$ 在 $D$ 上有界。

    * 充要条件：函数在某个数集上有界的充要条件是其在该数集上既有上界，又有下界。

    * 数理逻辑量词：全称量词 $\forall$（表示“对任意”，源自 Any 倒置）；存在量词 $\exists$（表示“存在”，源自 Exist 翻转）。

* **对称有界常数选取规则（Symmetric Bound Selection Rule）**

    * > **定义**：已知函数上界 $K_1$ 与下界 $K_2$ 时，构造满足 $|f(x)| \le M$ 的对称正数常数 $M$ 的选取法则。

    * 极值计算公式：对称上界必须取两端点绝对值的较大者，即 $M = \max\{|K_1|, |K_2|\}$。

    * 覆盖机理：若上界 $K_1 = 5$、下界 $K_2 = -7$，若取 $M = 5$ 则对称区间 $[-5, 5]$ 遗漏 $[-7, -5)$ 部分；必须选取 $M = \max\{|5|, |-7|\} = 7$，区间 $[-7, 7]$ 才能完全包容整个值域。

    * 区间覆盖示意：

    ```text
              -7 (下界 K2)          0        5 (上界 K1)
    ───────────●────────────────────┼────────●─────────────> 函数值 f(x)
               │                             │
    [◄─────────┴─────────────────────────────┴──────────►] 实际取值范围 [-7, 5]
       -7                                           7
    [◄─●────────────────────────────┼───────────────●──►] 对称区间 [-M, M]
      -M                                            M
    ```

### 单调性与奇偶性

* **单调性（Monotonicity）**

    * > **定义**：设函数 $f(x)$ 的定义域为 $D$，区间 $I \subseteq D$。对于区间 $I$ 上的任意两点 $x_1, x_2$，若当 $x_1 < x_2$ 时恒有 $f(x_1) < f(x_2)$，称 $f(x)$ 在 $I$ 上严格单调增加；若恒有 $f(x_1) > f(x_2)$，称 $f(x)$ 在 $I$ 上严格单调减少。

    * 理论功用：构成后续利用一阶导数符号判定函数增减区间的代数基础。

* **奇偶性（Parity）**

    * > **定义**：设函数 $f(x)$ 的定义域为 $D$。若对任意 $x \in D$ 均有 $-x \in D$，且 $f(-x) = f(x)$，则称 $f(x)$ 为偶函数；若对任意 $x \in D$ 均有 $-x \in D$，且 $f(-x) = -f(x)$，则称 $f(x)$ 为奇函数。

    * 几何对称性：偶函数的图形关于 $y$ 轴对称；奇函数的图形关于坐标原点 $(0, 0)$ 对称。

    * > ⚠️ **易错点**：判定奇偶性的第一步，绝对不是直接代入算式验证 $f(-x)$ 与 $f(x)$ 的关系，而是必须先审视定义域 $D$ 是否关于坐标原点对称。若定义域不对称（例如定义在 $[-1, 2)$ 上），该函数直接判定为非奇非偶函数。

* **对称区间奇偶分解定理（Parity Decomposition Theorem）**

    * > **定义**：定义在关于原点对称区间 $[-l, l]$ 上的任意函数 $f(x)$，均可唯一分解为一个偶函数 $g(x)$ 与一个奇函数 $h(x)$ 之和，即 $f(x) = g(x) + h(x)$。

    * 偶函数分量构造：$g(x) = \frac{1}{2}\left[f(x) + f(-x)\right]$，通过算术平均值剥离偶函数成分。

    * 奇函数分量构造：$h(x) = \frac{1}{2}\left[f(x) - f(-x)\right]$，通过半差值剥离奇函数成分。

    * 分解证明与校验：联立 $g(x) + h(x) = f(x)$ 与 $g(x) - h(x) = f(-x)$，相加解出 $g(x)$，相减解出 $h(x)$；代入验证 $g(-x) = g(x)$ 且 $h(-x) = -h(x)$ 均严格成立。

### 周期性与病态函数

* **周期性（Periodicity）**

    * > **定义**：设函数 $f(x)$ 的定义域为 $D$。若存在正数 $l > 0$，使得对于任意 $x \in D$，恒有 $x + l \in D$ 且 $f(x + l) = f(x)$，则称 $f(x)$ 为周期函数，$l$ 称为周期。

    * 正数约束机理：周期的定义严格规定 $l > 0$。若允许 $l = 0$，因 $f(x + 0) = f(x)$ 对所有函数恒成立，将导致所有函数退化为周期函数而丧失研究分类价值。

    * 最小正周期：周期函数的所有正周期中若存在一个最小正数，该正数称为最小正周期（例如 $\sin x$ 的最小正周期为 $2\pi$）。

* **狄利克雷函数（Dirichlet Function）**

    * > **定义**：定义在整个实数集 $\mathbf{R}$ 上的典型非初等函数，解析式为 $D(x) = \begin{cases} 1, & x \in \mathbf{Q} \\ 0, & x \in \mathbf{Q}^c \end{cases}$，其中 $\mathbf{Q}$ 为有理数集，$\mathbf{Q}^c$ 为无理数集。

    * 正有理数周期性：任何正有理数 $r \in \mathbf{Q}^+$ 都是狄利克雷函数的周期。若 $x \in \mathbf{Q}$，因有理数加法封闭有 $x + r \in \mathbf{Q} \implies D(x + r) = 1 = D(x)$；若 $x \in \mathbf{Q}^c$，因无理数加有理数仍为无理数有 $x + r \in \mathbf{Q}^c \implies D(x + r) = 0 = D(x)$。

    * 最小正周期不存在性证明：由周期定义要求周期 $l > 0$，$D(x)$ 的正周期包含全部正有理数 $\mathbf{Q}^+$。若假设存在最小正周期 $T_{\min} \in \mathbf{Q}^+$，则构造 $T' = \frac{T_{\min}}{2}$，显见 $T' \in \mathbf{Q}^+$ 且 $0 < T' < T_{\min}$；根据周期性结论 $T'$ 亦为周期，与 $T_{\min}$ 的最小性假设矛盾。由于在开区间 $(0, +\infty)$ 内不存在最小正有理数，狄利克雷函数不存在最小正周期。

    * 点集分布结构：

    ```text
    y
    │
    1 ─── · · · · · · · · · · · · · · · · · ·  (x ∈ Q,   处处有点、处处有缝)
    │
    0 ─── · · · · · · · · · · · · · · · · · ·  (x ∈ Q^c, 处处有点、处处有缝)
    └───┴────────────────────────────────────> x
    ```

## 初等函数与复合逆向构造

### 反函数代数与几何特征

* **反函数（Inverse Function）**

    * > **定义**：设函数 $f: D \to f(D)$ 为单射，若存在映射 $f^{-1}: f(D) \to D$，使得对每一个 $y \in f(D)$ 均有唯一确定的 $x \in D$ 满足 $y = f(x)$，则称 $f^{-1}$ 为函数 $f$ 的反函数（逆函数），记作 $x = f^{-1}(y)$，习惯上自变量记为 $x$ 时写作 $y = f^{-1}(x)$。

    * 单射必要条件机理：若函数非单射，则存在 $x_1 \neq x_2$ 使得 $f(x_1) = f(x_2) = y$；倒转对应时 $y$ 必须同时指向两个不同的自变量，破坏函数的单值性，无法构造反函数。

    * 充分条件与保单调性：若函数在其定义域上严格单调（递增或递减），则其必然是单射，反函数必定存在；反函数严格保持原函数的单调性。

    * 几何对称性：原函数图象上的点 $(a, b)$ 对应反函数图象上的点 $(b, a)$，两点关于第一、第三象限角平分线 $y = x$ 轴对称，故反函数 $y = f^{-1}(x)$ 与原函数 $y = f(x)$ 的图象关于直线 $y = x$ 成轴对称。

* **反函数存在条件结构对比（Reversibility Structural Comparison）**

    * > **定义**：单射与非单射在反函数构造过程中的单值性对立表现。

    * 映射关系对比：

    ```text
    单射情况（可逆）：
    定义域 D                值域 f(D)
      x1 --------------------> y1
      x2 --------------------> y2
    （每个 y 均有唯一的 x 对应，反向映射 f⁻¹ 成立）

    非单射情况（不可逆）：
    定义域 D                值域 f(D)
      x1 ---------\
                   +---------> y
      x2 ---------/
    （反向时 y 对应多个 x，破坏单值性，无法构造反函数）
    ```

### 复合函数与代数运算

| 运算类型 | 复合代数表达式 | 运算后的合法定义域 | 附加约束条件 |
| :--- | :--- | :--- | :--- |
| 和与差 | $(f \pm g)(x) = f(x) \pm g(x)$ | $D = D_f \cap D_g$ | 无 |
| 积 | $(f \cdot g)(x) = f(x) \cdot g(x)$ | $D = D_f \cap D_g$ | 无 |
| 商 | $\left(\frac{f}{g}\right)(x) = \frac{f(x)}{g(x)}$ | $D = \{x \in D_f \cap D_g \mid g(x) \neq 0\}$ | 分母函数值不得为零 |

* **复合函数（Composite Function）**

    * > **定义**：设因变量 $y$ 是变量 $u$ 的函数 $y = f(u)$，而变量 $u$ 是自变量 $x$ 的函数 $u = g(x)$，将内层函数代入外层表达式所构成的函数 $y = f(g(x))$ 称为复合函数。

    * 中间变量作用：变量 $u$ 称为中间变量，起到承上启下的过渡作用，在最终单自变量表达式中被消去。

    * 构成充要前提：内层函数的值域包含于外层函数的定义域（$R_g \subseteq D_f$），或至少保证二者交集非空（$R_g \cap D_f \neq \emptyset$）；若中间变量取值脱离外层定义域，整个复合无数学意义。

* **函数代数运算（Algebraic Operations of Functions）**

    * > **定义**：两个或多个函数进行和、差、积、商代数四则运算的代数规则与定义域约束。

    * 运算有效前提：参与运算的各函数定义域交集不得为空集，即 $D_f \cap D_g \neq \emptyset$。

### 初等函数体系与扩展

* **基本初等函数（Basic Elementary Functions）**

    * > **定义**：微积分分析基础的五类经典初等函数：幂函数、指数函数、对数函数、三角函数、反三角函数。

    * 幂函数：$y = x^\mu \ (\mu \in \mathbb{R})$。

    * 指数函数：$y = a^x \ (a > 0, a \neq 1)$，以自然常数 $e \approx 2.71828$ 为底的自然指数函数 $y = e^x$ 为微积分核心。

    * 对数函数：$y = \log_a x \ (a > 0, a \neq 1)$，常用对数记作 $\lg x = \log_{10} x$，自然对数记作 $\ln x = \log_e x$。

    * 三角函数：$\sin x, \cos x, \tan x, \cot x, \sec x, \csc x$。

    * 反三角函数：$\arcsin x, \arccos x, \arctan x, \operatorname{arccot} x$。

* **初等函数（Elementary Function）**

    * > **定义**：由常数及基本初等函数经过有限次四则运算和有限次复合步骤所构成，并且可以用一个统一解析式表示的函数。

    * 有限次判定界限：四则运算与复合步骤必须严格为“有限次”；包含无限次代数运算的表达式（如无穷级数 $\sum_{n=1}^\infty f_n(x)$）不属于初等函数范畴。

* **双曲函数与反双曲函数（Hyperbolic and Inverse Hyperbolic Functions）**

    * > **定义**：由自然指数函数 $e^x$ 经有限次代数四则运算构成的特定初等函数族。

    * 经典解析式：双曲正弦 $\sinh x = \frac{e^x - e^{-x}}{2}$；双曲余弦 $\cosh x = \frac{e^x + e^{-x}}{2}$；双曲正切 $\tanh x = \frac{\sinh x}{\cosh x}$。

    * 函数性质归属：双曲函数及其各自的反函数完全由指数函数经有限次代数运算构造而成，在本质上均属于初等函数。

## 数列极限基础理论与证明范式

### 数列与极限定义

* **数列（Sequence）**

    * > **定义**：按照固定次序排布的一列无穷多数 $x_1, x_2, \dots, x_n, \dots$，简记为 $\{x_n\}$，第 $n$ 项 $x_n$ 称为通项或一般项。

    * 逼近直观性：随项数 $n$ 持续增大，数列各点在数轴上向特定定数聚集；通过设定误差容限与项数阈值可实现逼近过程的定量刻画。

* **数列极限精确定义（Limit of a Sequence，ε-N Definition）**

    * > **定义**：设 $\{x_n\}$ 为数列，$a$ 为定数。如果对于任意给定的正数 $\varepsilon$（不论它多么小），总存在正整数 $N$，使得当 $n > N$ 时不等式 $|x_n - a| < \varepsilon$ 恒成立，则称常数 $a$ 是数列 $\{x_n\}$ 的极限（数列收敛于 $a$），记作 $\lim_{n \to \infty} x_n = a$ 或 $x_n \to a \ (n \to \infty)$；若不存在此类常数 $a$，则称数列发散。

    * 核心要素剖析：

        * 误差容限 $\forall \varepsilon > 0$：外界任意给定的微小正数，用于衡量逼近程度与允许的最大误差。

        * 项数界限 $\exists N \in \mathbf{N}^*$：对 $\varepsilon$ 挑战给出的应答界限，$N$ 高度依赖于 $\varepsilon$ 的大小（$\varepsilon$ 越小，$N$ 通常取越大）。

        * 尾部无限项 $n > N$：明确界定在指标界限 $N$ 之后的所有无限多项无一例外均需落入指定范围。

        * 几何距离绝对值 $|x_n - a| < \varepsilon$：展开为 $a - \varepsilon < x_n < a + \varepsilon$，表明点 $x_n$ 完全落在以 $a$ 为中心、半径为 $\varepsilon$ 的对称开区间邻域内；绝对值剔除了单调逼近或左右正负振荡的方向差异，纯粹度量空间欧氏距离。

### 极限证明逻辑与技巧

* **极限证明三段论（Three-Step Proof Method for Limit）**

    * > **定义**：应用数列极限严格定义验证已知极限的标准规范书写程序。

    * 反解分析与取整：在草稿中化简不等式 $|x_n - a| < \varepsilon$，反解求出形如 $n > g(\varepsilon)$ 的不等式；为确保界限为正整数，应用高斯取整函数构造 $N = [g(\varepsilon)] + 1$。

    * 正卷规范三段论模板：第一句，设任给 $\varepsilon > 0$；第二句，取正整数 $N = [g(\varepsilon)] + 1$；第三句，当 $n > N$ 时展开推导得到 $|x_n - a| < \varepsilon$，故命题得证。

    * 证明逻辑流向结构：

    ```text
    思维流向（草稿纸反解分析）：
    |xn - a| < ε  ====(化简与不等式反解)====>  n > g(ε)  ====(取整构造)====>  确定 N = [g(ε)] + 1

    书写流向（正卷规范三段论）：
    任给 ε > 0   ====(亮出应答边界)========>  取 N = [g(ε)] + 1  ====(正向推演)====>  当 n > N 时恒有 |xn - a| < ε
    ```

* **放缩与不等式变号策略（Scaling and Inequality Reversal Strategies）**

    * > **定义**：在复杂分式或指数极限推导中，通过放大误差界限与规范代数变换简化求 $N$ 的技巧。

    * 放缩策略准则：通过缩小分母或放大分子实现左侧放大，即若 $|x_n - a| \le H(n) < \varepsilon$，根据不等式传递性保证原偏差小于 $\varepsilon$。

    * > ⚠️ **易错点**：在等比数列证明中对 $|q|^{n-1} < \varepsilon$ 取对数得 $(n - 1)\ln|q| < \ln\varepsilon$。因公比满足 $0 < |q| < 1$，故对数值 $\ln|q| < 0$ 恒为负数；两边同除以负数时，不等号必须立刻由小于号反转为大于号，即 $n - 1 > \frac{\ln\varepsilon}{\ln|q|}$。

### 典型数列极限证明模型

* **有理分式振荡数列模型（Oscillating Rational Sequence Model）**

    * > **定义**：分子含交错正负项的有理分式数列极限证明模型，通项为 $x_n = \frac{n + (-1)^{n-1}}{n}$，验证 $\lim_{n \to \infty} x_n = 1$。

    * 偏差化简推演：$|x_n - 1| = \left|\frac{n + (-1)^{n-1}}{n} - 1\right| = \left|\frac{(-1)^{n-1}}{n}\right| = \frac{1}{n}$。

    * 证明书写构造：对任意给定的 $\varepsilon > 0$，取正整数 $N = [\frac{1}{\varepsilon}]$（或 $N = [\frac{1}{\varepsilon}] + 1$）；当 $n > N$ 时恒有 $n > \frac{1}{\varepsilon}$，从而 $|x_n - 1| = \frac{1}{n} < \varepsilon$ 恒成立，得证 $\lim_{n \to \infty} \frac{n + (-1)^{n-1}}{n} = 1$。

* **平方反比交错数列模型（Inverse-Square Alternating Sequence Model）**

    * > **定义**：分母含二次多项式的交错数列极限证明模型，通项为 $x_n = \frac{(-1)^n}{(n+1)^2}$，验证 $\lim_{n \to \infty} x_n = 0$。

    * 放缩推导：偏差 $|x_n - 0| = \left|\frac{(-1)^n}{(n+1)^2}\right| = \frac{1}{(n+1)^2}$；利用 $n + 1 > n > 0$ 缩小分母放缩可得 $\frac{1}{(n+1)^2} < \frac{1}{n^2}$。

    * 证明书写构造：对任给的 $\varepsilon > 0$，取正整数 $N = [\frac{1}{\sqrt{\varepsilon}}]$（或 $N = [\frac{1}{\sqrt{\varepsilon}}] + 1$）；当 $n > N$ 时必有 $n > \frac{1}{\sqrt{\varepsilon}}$，进而 $|x_n - 0| = \frac{1}{(n+1)^2} < \frac{1}{n^2} < \varepsilon$ 恒成立，得证 $\lim_{n \to \infty} \frac{(-1)^n}{(n+1)^2} = 0$。

* **等比衰减数列模型（Geometric Decay Sequence Model）**

    * > **定义**：公比绝对值小于 1 的等比数列极限证明模型，通项为 $x_n = q^{n-1}$（$|q| < 1$），验证 $\lim_{n \to \infty} q^{n-1} = 0$。

    * 零公比边界：若 $q = 0$，当 $n \ge 2$ 时各项均为 0，极限显然为 0。

    * 证明书写构造（$0 < |q| < 1$）：对任给的 $\varepsilon > 0$，取正整数 $N = [\frac{\ln\varepsilon}{\ln|q|}] + 1$；当 $n > N$ 时，必有 $n > \frac{\ln\varepsilon}{\ln|q|} + 1 \implies n - 1 > \frac{\ln\varepsilon}{\ln|q|}$；两端同乘负数 $\ln|q|$ 不等号翻转得 $(n - 1)\ln|q| < \ln\varepsilon$，两端恢复自然底数指数得 $|q|^{n-1} < \varepsilon$，即 $|x_n - 0| < \varepsilon$ 恒成立，得证 $\lim_{n \to \infty} q^{n-1} = 0$。
