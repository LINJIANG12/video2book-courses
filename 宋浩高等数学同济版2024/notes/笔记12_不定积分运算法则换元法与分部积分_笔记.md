# 不定积分：运算法则、换元法与分部积分

## 基本积分表与运算性质

### 逆导数映射与常数吸收性

* **不定积分（Indefinite Integral）**

    * > **定义**：已知函数的导数，求其全体原函数的代数运算，标准表述为若 $F'(x) = f(x)$，则 $\int f(x) \, dx = F(x) + C$。

    * 被积函数 $f(x)$ 对应导函数，原函数 $F(x)$ 为特定基准原函数，$C$ 代表任意常数族。

    * 运算本质为微分与求导的逆运算。

    * 对数原函数的任意常数吸收性：对反比例函数求不定积分若写作 $\int \frac{1}{x} \, dx = \ln|nx| + C \quad (n \neq 0)$，由对数代数性质展开为 $\ln|x| + \ln|n| + C$；由于 $\ln|n|$ 为确定有限常数，与任意常数 $C$ 合并后仍等价于任意常数族 $C_1$，故 $\ln|nx| + C$ 与教材基准式 $\ln|x| + C$ 所确定的原函数集合完全一致。

* **基本初等函数积分表（Basic Table of Integrals）**

    * 常数函数积分：$\int k \, dx = kx + C$；对应逆导数 $(kx)' = k$。

    * 幂函数积分：$\int x^\mu \, dx = \frac{x^{\mu+1}}{\mu+1} + C \quad (\mu \neq -1)$；积分幂指数升 1 次，分母除以新指数配平系数。

    * 反比例函数积分：$\int \frac{1}{x} \, dx = \ln|x| + C$；在负半轴 $x < 0$ 时由 $[\ln(-x)]' = \frac{1}{-x} \cdot (-1) = \frac{1}{x}$ 保证，引入绝对值符号将定义域统一拓展为除原点外的全体非零实数。

    * > **易错点**：⚠️ 幂函数积分公式成立的前提是 $\mu \neq -1$；当 $\mu = -1$ 时分母为零无意义，必须切换为对数原函数，且必须严格书写绝对值符号 $|x|$，漏写绝对值属于定义域缺失错误。

    * 指数函数积分：自然指数函数 $\int e^x \, dx = e^x + C$ 为微积分运算的不动点；一般指数函数 $\int a^x \, dx = \frac{a^x}{\ln a} + C \quad (a > 0, a \neq 1)$，求导乘因子 $\ln a$，求积除以因子 $\ln a$。

    * 三角函数基本积分：
        * $\int \cos x \, dx = \sin x + C$
        * $\int \sin x \, dx = -\cos x + C$
        * $\int \sec^2 x \, dx = \int \frac{1}{\cos^2 x} \, dx = \tan x + C$
        * $\int \csc^2 x \, dx = \int \frac{1}{\sin^2 x} \, dx = -\cot x + C$
        * $\int \sec x \tan x \, dx = \sec x + C$
        * $\int \csc x \cot x \, dx = -\csc x + C$

    * 反三角函数导数原型积分：
        * $\int \frac{1}{1+x^2} \, dx = \arctan x + C$
        * $\int \frac{1}{\sqrt{1-x^2}} \, dx = \arcsin x + C$

    * > **提示**：三角函数符号判定准则为“正正余负”——求导或求积运算中，名称带“正”字（正弦、正切、正割）的导数保持正号；名称带“余”字（余弦、余切、余割）的导数必带负号；逆向积分结果导向“余”字头原函数时，前面必须补偿负号。

### 线性运算法则与算子边界

* **线性运算法则（Linear Operational Rules）**

    * 和差可拆性：两函数代数和（差）的不定积分等于各自不定积分的代数和（差）：
      $$ \int [f(x) \pm g(x)] \, dx = \int f(x) \, dx \pm \int g(x) \, dx $$

    * 非零常数可提性：被积表达式中的非零常数因子可自由移出积分符号外部：
      $$ \int k f(x) \, dx = k \int f(x) \, dx \quad (k \neq 0) $$

    * 证明依据：利用微分与积分的互逆关系，等式两端对自变量 $x$ 逐项求导，导函数一致证明原函数族等价。

* **算子操作边界（Operational Boundaries of Operator）**

    * 积分因式常数判定准则：提取因子必须与当前积分变量绝对无关；若因子含有当前积分变量 $x$，严禁移出积分号外部：
      $$ \int x f(x) \, dx \neq x \int f(x) \, dx $$

    * 多元与参变量约束：表达式中若出现非积分变量记号 $y$，在未明确声明 $y$ 与 $x$ 相互独立之前，严禁将 $y$ 视为常数提取到积分号外。

    * 乘除运算非分配性：积分运算对乘除法不具备分配律：
      $$ \int f(x)g(x) \, dx \neq \int f(x) \, dx \cdot \int g(x) \, dx $$
      $$ \int \frac{f(x)}{g(x)} \, dx \neq \frac{\int f(x) \, dx}{\int g(x) \, dx} $$

    * 代数多项式展开范例：$\int \sqrt{x}(x^2 - 5) \, dx = \int (x^{\frac{5}{2}} - 5x^{\frac{1}{2}}) \, dx = \frac{2}{7}x^{\frac{7}{2}} - \frac{10}{3}x^{\frac{3}{2}} + C$。

    * 单项分母有理式项分离：$\int \frac{(x-1)^3}{x^2} \, dx = \int (x - 3 + 3x^{-1} - x^{-2}) \, dx = \frac{1}{2}x^2 - 3x + 3\ln|x| + \frac{1}{x} + C$。

    * 同指数幂底数合并范式：$\int 2^x e^x \, dx = \int (2e)^x \, dx = \frac{(2e)^x}{\ln(2e)} + C = \frac{2^x e^x}{1 + \ln 2} + C$。

    * 三角初等恒等变形：
        * 平方降型：$\int \tan^2 x \, dx = \int (\sec^2 x - 1) \, dx = \tan x - x + C$
        * 二倍角降幂：$\int \sin^2 \frac{x}{2} \, dx = \int \frac{1 - \cos x}{2} \, dx = \frac{1}{2}x - \frac{1}{2}\sin x + C$
        * 积商紧缩：$\int \frac{1}{\sin^2 \frac{x}{2} \cos^2 \frac{x}{2}} \, dx = 4\int \csc^2 x \, dx = -4\cot x + C$

### 微分与积分运算特征对比

* **微积分运算机制差异（Comparison of Differentiation and Integration Mechanisms）**

    * 算法性质差异：求导是具有严格确定性的机械算法；求不定积分是依赖模式逆推与猜测重构的启发式搜索。

    * 规则完备性差异：微分学拥有乘积商数求导法则与链式求导法则，可覆盖全部初等函数复合；积分学仅具备线性运算性质，无通用的乘除运算法则。

    * 初等函数封闭性差异：初等函数的导数必定仍为初等函数；初等函数的原函数可能超出初等函数范畴（如 $\frac{1}{\sqrt{x^4+1}}$ 与 $e^{-x^2}$ 无法用有限次初等运算表达，属于初等函数内不可积）。

    * 抵消非单射性：求导过程中的分子分母约分、乘积项相消破坏并抹去了原始代数结构的信息痕迹，求积必须在终态抵消信息缺失的情况下逆向推演还原路径。

| 比较维度 | 导数运算（微分学） | 不定积分运算（积分学） |
| :--- | :--- | :--- |
| **算法性质** | 严格确定性的机械算法 | 启发式搜索与模式逆推 |
| **规则完备性** | 四则运算律与复合链式法则全面覆盖 | 仅具备线性运算性质，无通用乘除法则 |
| **初等函数封闭性** | 初等函数的导数必定仍是初等函数 | 大量初等函数的原函数非初等函数（初等函数内积不出） |
| **结构敏感度** | 局部参数微调仅引起导数表达式平滑变化 | 局部微小变动可能导致完全无法用初等形式表达 |

## 第一类换元积分法与凑微分技术

### 微分形式不变性与凑项机理

* **第一类换元积分法（Integration by Substitution of the First Kind，凑微分法）**

    * > **定义**：设外层原函数 $F'(u) = f(u)$，内层函数 $u = \varphi(x)$ 可导，则复合微分满足 $dF(\varphi(x)) = f(\varphi(x))\varphi'(x) \, dx$，对应不定积分为：
      $$ \int f(\varphi(x))\varphi'(x) \, dx = \int f(\varphi(x)) \, d(\varphi(x)) = F(\varphi(x)) + C $$

    * 核心操作准则：将积分号内导数因子 $\varphi'(x)$ 求原函数，移入微分符号 $d$ 内部构造整体变量 $d(\varphi(x))$。

    * 运算流向特征：由微分号外部向内部收缩归并。

* **微分内常数平移与配平规则（Rules of Constant Shift and Balancing）**

    * 常数平移不变性：由于常数导数为零，微分算子内部可自由加减任意常数 $C_0$，即 $d(\varphi(x) + C_0) = d(\varphi(x))$。

    * 一次分式配平：$\int \frac{1}{3+2x} \, dx = \frac{1}{2} \int \frac{1}{3+2x} \, d(2x+3) = \frac{1}{2}\ln|3+2x| + C$。

    * 分母整体单项化代换：对于复合分母高次式 $\int \frac{x^2}{(x+2)^3} \, dx$，令 $u = x+2$（反解 $x = u-2, dx = du$），代入展开得 $\int (\frac{1}{u} - \frac{4}{u^2} + \frac{4}{u^3}) \, du = \ln|x+2| + \frac{4}{x+2} - \frac{2}{(x+2)^2} + C$。

    * > **易错点**：⚠️ 整体代换变量时必须联动变换微分算子内部的自变量（$dx = du$），切忌仅代换被积函数而遗漏微元转换。

    * 指数与幂根式配平范例：
        * $\int 2x e^{x^2} \, dx = \int e^{x^2} \, d(x^2) = e^{x^2} + C$
        * $\int x\sqrt{1-x^2} \, dx = -\frac{1}{2} \int (1-x^2)^{\frac{1}{2}} \, d(1-x^2) = -\frac{1}{3}(1-x^2)^{\frac{3}{2}} + C$
        * $\int \frac{e^{3\sqrt{x}}}{\sqrt{x}} \, dx = 2 \int e^{3\sqrt{x}} \, d(\sqrt{x}) = \frac{2}{3}e^{3\sqrt{x}} + C$

### 常用代数与分式积分定式

* **二次标准型与距离系数裂项（Standard Quadratic Formulas and Distance Coefficient Partial Fractions）**

    * 反正切标准积分：$\int \frac{1}{a^2 + x^2} \, dx = \frac{1}{a} \arctan \frac{x}{a} + C \quad (a \neq 0)$。

    * 反正弦标准积分：$\int \frac{1}{\sqrt{a^2 - x^2}} \, dx = \arcsin \frac{x}{a} + C \quad (a > 0)$。

    * 二次差裂项公式：$\int \frac{1}{x^2 - a^2} \, dx = \frac{1}{2a} \ln\left|\frac{x - a}{x + a}\right| + C$。

    * 距离系数法则：因式分解后两项零点的数轴距离倒数等于裂项补偿系数；因式零点为 $a$ 与 $-a$，数轴距离为 $2a$，补偿系数为 $\frac{1}{2a}$；若分母为 $(x+1)(x-3)$，两点间距离为 4，补偿系数即为 $\frac{1}{4}$。

* **对数复合结构与绝对值保留（Logarithmic Composite Structure and Absolute Value Rules）**

    * 对数分式凑微分：$\int \frac{1}{x(1 + 2\ln x)} \, dx = \frac{1}{2} \int \frac{1}{1 + 2\ln x} \, d(1 + 2\ln x) = \frac{1}{2}\ln|1 + 2\ln x| + C$。

    * 微元定义域约束：因 $\ln x$ 天然要求真数 $x > 0$，故 $\frac{1}{x}dx$ 收入微分号写作 $d(\ln x)$ 时内部无需添加绝对值。

    * 外部绝对值留存规则：表达式 $1 + 2\ln x$ 的符号随 $x$ 取值可正可负（$x < e^{-1/2}$ 时为负），故外部绝对值符号不可省略。

### 三角函数积分配型技巧

* **奇偶次幂拆项与降次规则（Parity Split and Degree Reduction Rules for Trigonometric Powers）**

    * 奇数次幂拆项凑微分：抽离一个单项因子移入微分号转化为对偶函数，剩余偶数次幂利用 $\sin^2 x + \cos^2 x = 1$ 转化为对偶多项式。
        * $\int \sin^3 x \, dx = -\int (1 - \cos^2 x) \, d(\cos x) = -\cos x + \frac{1}{3}\cos^3 x + C$
        * $\int \sin^2 x \cos^5 x \, dx = \int \sin^2 x (1 - \sin^2 x)^2 \, d(\sin x) = \frac{1}{3}\sin^3 x - \frac{2}{5}\sin^5 x + \frac{1}{7}\sin^7 x + C$

    * 偶数次幂半角降次：各项均为偶数次幂时，无法拆出单项凑微分，必须通过倍角降幂公式线性降次：
      $$ \sin^2 u = \frac{1 - \cos 2u}{2}, \quad \cos^2 u = \frac{1 + \cos 2u}{2} $$
        * $\int \cos^2 x \, dx = \int \frac{1 + \cos 2x}{2} \, dx = \frac{1}{2}x + \frac{1}{4}\sin 2x + C$
        * $\int \sin^2 x \cos^4 x \, dx = \frac{1}{16}x - \frac{1}{64}\sin 4x + \frac{1}{48}\sin^3 2x + C$

* **三角导数关联网与标准对数积分（Trigonometric Derivative Relations and Standard Logarithmic Integrals）**

    * 正切正割导数关联网：利用 $(\tan x)' = \sec^2 x$ 与 $1 + \tan^2 x = \sec^2 x$，高阶正割抽离 $\sec^2 x dx = d(\tan x)$，如 $\int \sec^6 x \, dx = \int (1 + \tan^2 x)^2 \, d(\tan x) = \tan x + \frac{2}{3}\tan^3 x + \frac{1}{5}\tan^5 x + C$。

    * 积化和差分离角频率：面对不同频率三角函数乘积，利用 $\cos\alpha\cos\beta = \frac{1}{2}[\cos(\alpha - \beta) + \cos(\alpha + \beta)]$ 分离为线性和形式，如 $\int \cos 3x \cos 2x \, dx = \frac{1}{2}\sin x + \frac{1}{10}\sin 5x + C$。

| 被积三角函数 | 核心推导路径 | 标准不定积分原函数 |
| :--- | :--- | :--- |
| $\tan x$ | 商数展开 $\frac{\sin x}{\cos x}$，凑微分 $-d(\cos x)$ | $-\ln\|\cos x\| + C$ |
| $\cot x$ | 商数展开 $\frac{\cos x}{\sin x}$，凑微分 $d(\sin x)$ | $\ln\|\sin x\| + C$ |
| $\sec x$ | 分子分母配乘 $\sec x + \tan x$，凑微分 $d(\sec x + \tan x)$ | $\ln\|\sec x + \tan x\| + C$ |
| $\csc x$ | 半角展开同除 $\cos^2\frac{x}{2}$，凑微分 $d(\tan\frac{x}{2})$ | $\ln\|\csc x - \cot x\| + C$ 或 $\ln\|\tan\frac{x}{2}\| + C$ |

## 第二类换元积分法与根式代换

### 变量代换方向与几何回代

* **第二类换元积分法（Integration by Substitution of the Second Kind，变量代换法）**

    * > **定义**：设 $x = \varphi(t)$ 为单调、可导且导数 $\varphi'(t) \neq 0$ 的参数函数，若 $\int f(\varphi(t))\varphi'(t) \, dt = F(t) + C$，则原积分结果为：
      $$ \int f(x) \, dx = F(\varphi^{-1}(x)) + C $$

    * 核心功能目标：攻克被积表达式中的二次或多次根式，构造平方形态 $\sqrt{(\dots)^2}$ 以消除根号。

    * 运算流向对比：
        * 第一类换元法为“由外向内收缩”，对伴随因子求原函数并归并入微分号（$f(\varphi(x))\varphi'(x)dx \to f(u)du$）；
        * 第二类换元法为“由内向外释放”，代换内部自变量并求导展开微分微元（$dx \to \varphi'(t)dt$）。

    * 参数区间限定原则：限定 $t$ 的取值区间必须满足单调性，以确保反函数 $t = \varphi^{-1}(x)$ 存在且单值；同时限定三角函数取正值区间，确保开方时绝对值符号可直接脱去。

* **直角三角形几何回代法（Right Triangle Geometric Back-Substitution）**

    * 几何作图规则：依据参数代换设法确定直角三角形两边长，利用勾股定理求出第三边长。

    * 边长比值直读：根据几何三角形各边关系，直接读出原式所需的对偶三角函数值，免去代数方程联立反解。

### 三大根式三角代换方案

* **标准二次根式三角代换规则（Standard Quadratic Radical Substitution Rules）**

    * 差方型根式 $\sqrt{a^2 - x^2}$ ($a > 0$)：
        * 代换设定：$x = a \sin t \quad (t \in (-\frac{\pi}{2}, \frac{\pi}{2}))$；微分关系 $dx = a \cos t \, dt$；根式化简为 $a \cos t$。
        * 典型积分：$\int \sqrt{a^2 - x^2} \, dx = \frac{a^2}{2}\arcsin\frac{x}{a} + \frac{x}{2}\sqrt{a^2 - x^2} + C$。
        * 展开要求：积分产生的 $\sin 2t$ 必须利用二倍角公式展开为 $2\sin t \cos t$，方可代入直角三角形边长回代。

    * 和方型根式 $\sqrt{x^2 + a^2}$ ($a > 0$)：
        * 代换设定：$x = a \tan t \quad (t \in (-\frac{\pi}{2}, \frac{\pi}{2}))$；微分关系 $dx = a \sec^2 t \, dt$；根式化简为 $a \sec t$。
        * 典型积分：$\int \frac{1}{\sqrt{x^2 + a^2}} \, dx = \ln(x + \sqrt{x^2 + a^2}) + C$。
        * 绝对值脱除机制：因 $\sqrt{x^2 + a^2} > \sqrt{x^2} = |x|$ 恒成立，真数必大于零，对数绝对值可直接脱去。

    * 逆差方型根式 $\sqrt{x^2 - a^2}$ ($a > 0$)：
        * 代换设定：$x = a \sec t \quad (t \in (0, \frac{\pi}{2}) \cup (\frac{\pi}{2}, \pi))$；微分关系 $dx = a \sec t \tan t \, dt$；根式化简为 $a \tan t$。
        * 典型积分：$\int \frac{1}{\sqrt{x^2 - a^2}} \, dx = \ln|x + \sqrt{x^2 - a^2}| + C$。

| 被积根式特征 | 代换设法 | 参数范围约束 | 微分关系 $dx$ | 根式化简结果 |
| :--- | :--- | :--- | :--- | :--- |
| $\sqrt{a^2 - x^2}$ | $x = a \sin t$ | $t \in \left(-\frac{\pi}{2}, \frac{\pi}{2}\right)$ | $a \cos t \, dt$ | $a \cos t$ |
| $\sqrt{x^2 + a^2}$ | $x = a \tan t$ | $t \in \left(-\frac{\pi}{2}, \frac{\pi}{2}\right)$ | $a \sec^2 t \, dt$ | $a \sec t$ |
| $\sqrt{x^2 - a^2}$ | $x = a \sec t$ | $t \in \left(0, \frac{\pi}{2}\right) \cup \left(\frac{\pi}{2}, \pi\right)$ | $a \sec t \tan t \, dt$ | $a \tan t$ |

### 倒代换与二次三项式配方法

* **倒代换（Reciprocal Substitution）**

    * 适用边界：分母含有高于二次的自变量单项幂且与根式相复合。

    * 运算法则：令 $x = \frac{1}{t}$，微分关系 $dx = -\frac{1}{t^2} \, dt$；将沉底的高次幂翻转至分子端，压低根式外部次数。

    * 典型求解：$\int \frac{\sqrt{a^2 - x^2}}{x^4} \, dx = -\frac{(a^2 - x^2)^{\frac{3}{2}}}{3a^2 x^3} + C$（结合三角代换化为余切二次单项积分并利用三角形回代）。

* **二次三项式配方化归（Form Completion of Quadratic Trinomials）**

    * 统一标准扩展公式：$\int \frac{1}{\sqrt{x^2 \pm a^2}} \, dx = \ln|x + \sqrt{x^2 \pm a^2}| + C$。

    * 系数配平化归：$\int \frac{1}{\sqrt{4x^2 + 9}} \, dx = \frac{1}{2}\int \frac{d(2x)}{\sqrt{(2x)^2 + 3^2}} = \frac{1}{2}\ln(2x + \sqrt{4x^2 + 9}) + C$。

    * 二次三项式配方：$1 + x - x^2 = (\frac{\sqrt{5}}{2})^2 - (x - \frac{1}{2})^2$，代入反正弦公式得 $\int \frac{1}{\sqrt{1+x-x^2}} \, dx = \arcsin(\frac{2x-1}{\sqrt{5}}) + C$。

## 分部积分法与降维求解

### 乘积逆推与凑微分优先级

* **分部积分公式（Integration by Parts Formula，IBP）**

    * > **定义**：源于导数乘积法则 $(uv)' = u'v + uv'$ 两端求不定积分，标准表达式为：
      $$ \int u \, dv = uv - \int v \, du $$

    * 操作结构本质：前项与后项直接相乘（$uv$），减去前后位置调换后的新积分（$-\int v \, du$）。

    * 结构构造前提：被积表达式形式为 $\int f(x)g(x) \, dx$，必须先通过凑微分将其中一个因子塞入微分号内充当 $dv$。

* **凑微分入号优先级阶梯（Priority Hierarchy of Entering Differential Operator）**

    * 判定基准：原函数易求且进出微分号形式不膨胀的函数优先进 $d$；求导能显著降次或脱壳的函数坚决留外充当 $u$。

    * 升次陷阱：多项式 $x^n$ 若错塞入微分号，求积将升次为 $\frac{1}{n+1}x^{n+1}$，导致后续积分不断膨胀失效。

| 优先级顺序 | 函数类型 | 典型代表 | 凑微分策略 | 核心数学机理 |
| :--- | :--- | :--- | :--- | :--- |
| **第一级（最高）** | 指数函数 | $e^x, a^x$ | 坚决优先凑入 $d$ 内部 | 导数与原函数均为其本身，进出微分号形式完全不膨胀 |
| **第二级（次高）** | 三角函数 | $\sin x, \cos x, \sec^2 x$ | 优先凑入 $d$ 内部 | 原函数与导数呈现正余弦简谐循环，易于求出且形式对称 |
| **第三级（较低）** | 幂函数 / 多项式 | $x^n$ | 通常留在外面求导降次 | 仅在搭配对数或反三角函数时，才作为配角被迫凑入 $d$ |
| **第四级（最低）** | 对数与反三角 | $\ln x, \arcsin x, \arctan x$ | 严禁凑入 $d$，坚决留作 $u$ | 原函数极其复杂或未知，通过留在外面求导脱去对数与反三角外壳 |

### 多项式连续降次与展开规范

* **多项式逐步降次（Stepwise Degree Reduction of Polynomials）**

    * 逐阶降次机理：多项式次数为 $n$ 时，一次分部积分仅能降低 1 个阶次，必须连续执行 $n$ 次分部积分方可将多项式彻底化为常数。

    * 典型范例：$\int x^2 e^x \, dx = x^2 e^x - 2\int x e^x \, dx = x^2 e^x - 2(x e^x - e^x) + C = x^2 e^x - 2x e^x + 2e^x + C$。

    * 幂三角混合积分：$\int x \cos x \, dx = \int x \, d(\sin x) = x \sin x - \int \sin x \, dx = x \sin x + \cos x + C$。

* **连续分部符号展开规范（Sign and Bracket Rules in Repeated IBP）**

    * 括号保护规则：由于分部积分公式自带减号，嵌套第二次分部积分时必须在减号后立即添加中括号保护：
      $$ I = u_1 v_1 - \left[ u_2 v_2 - \int v_2 \, du_2 \right] $$

    * 严禁心算去括号，避免因负号分配错误导致符号颠倒。

### 原积分循环重现与方程解法

* **循环积分代数解法（Algebraic Solution of Cyclic Integrals）**

    * 触发场景：指数函数与三角函数乘积、或正割函数奇数次幂积分，连续两次分部后原积分再次重现，且系数不为 $+1$。

    * 指三乘积求解：
      $$ \int e^x \sin x \, dx = e^x \sin x - \int e^x \cos x \, dx = e^x \sin x - \left[ e^x \cos x + \int e^x \sin x \, dx \right] $$
      移项合并代数项得 $2\int e^x \sin x \, dx = e^x(\sin x - \cos x)$，解得原积分为 $\frac{1}{2}e^x(\sin x - \cos x) + C$。

    * 正割奇次幂求解：
      $$ \int \sec^3 x \, dx = \int \sec x \, d(\tan x) = \sec x \tan x - \int \sec x (\sec^2 x - 1) \, dx $$
      移项合并得 $2\int \sec^3 x \, dx = \sec x \tan x + \ln|\sec x + \tan x|$，解得原积分为 $\frac{1}{2}\sec x \tan x + \frac{1}{2}\ln|\sec x + \tan x| + C$。

* **抵消失效校验机制（Cancellation Failure Verification Mechanism）**

    * > **易错点**：⚠️ 展开移项后若出现原积分两边抵消变为 $0 = 0$，必定源于两类操作失误：一是中途换道倒退（第一次将指数移入微分，第二次反悔将三角移入微分，两步互为逆运算退化为恒等式）；二是展开多层中括号或三角求导时遗漏了负号。方向正确时重现项系数绝不为 $+1$。

### 隐式因式构造与换元结合

* **隐式因式微元构造（Differential Construction of Implicit Factor）**

    * 隐式常数构造：孤立的对数函数或反三角函数无明显伴随因式，利用 $dx = d(x)$ 将常数 1 构造成微分项。

    * 对数积分定式：$\int \ln x \, dx = \int \ln x \, d(x) = x \ln x - \int x \cdot \frac{1}{x} \, dx = x \ln x - x + C$。

    * 孤立反余弦积分：$\int \arccos x \, dx = x \arccos x - \int x (-\frac{1}{\sqrt{1-x^2}}) \, dx = x \arccos x - \sqrt{1-x^2} + C$。

    * 幂函数与对数乘积：$\int x \ln x \, dx = \int \ln x \, d(\frac{1}{2}x^2) = \frac{1}{2}x^2 \ln x - \frac{1}{4}x^2 + C$。

    * 幂函数与反正切乘积：$\int x \arctan x \, dx = \frac{1}{2}x^2 \arctan x - \frac{1}{2}\int \frac{x^2}{1+x^2} \, dx = \frac{1}{2}(x^2+1)\arctan x - \frac{1}{2}x + C$。

* **换元先行综合策略（Substitution-First Comprehensive Strategy）**

    * 复合根式消除：被积函数中含有非线性根式时（如 $\int e^{\sqrt{x}} \, dx$），直接分部困难，首选令 $t = \sqrt{x}$（$x = t^2, dx = 2t \, dt$）。

    * 降维分部：原式转化为 $2\int t e^t \, dt = 2(t-1)e^t + C$，回代参数得 $2(\sqrt{x}-1)e^{\sqrt{x}} + C$。

## 有理函数积分与根式有理化

### 有理真假分式分离

* **有理分式分类（Classification of Rational Fractions）**

    * 定义形式：两个多项式的商 $R(x) = \frac{P(x)}{Q(x)}$，分子次数为 $m$，分母次数为 $n$。

    * 类别判定：$m < n$ 为真分式；$m \ge n$ 为假分式。

    * 降次分离原则：任何假分式均可唯一分离为一个多项式整式与一个有理真分式之和；有理函数积分的核心攻坚对象恒为真分式。

* **多项式长除法与配凑拆项（Polynomial Long Division and Form Completion）**

    * 竖式长除规范：当 $m > n$ 时采用长除法，被除式按降幂排列，缺项必须预留空格补齐，避免错位相减。

    * 典型分离求解：$\frac{2x^4 + x^2 + 3}{x^2 + 1} = 2x^2 - 1 + \frac{4}{x^2 + 1}$，积分得 $\frac{2}{3}x^3 - x + 4\arctan x + C$。

    * 同次配凑法：当 $m = n$ 时直接配凑分母因式，$2x^4 + x^2 + 3 = 2x^2(x^2 + 1) - (x^2 + 1) + 4$，逐项整除分离。

### 基础二次与真分式积分模式

* **基础真分式求解定式（Standard Patterns of Basic Proper Fractions）**

    * 一次分母型：$\int \frac{1}{ax + b} \, dx = \frac{1}{a}\ln|ax + b| + C$。

    * 二次可分解型（$\Delta > 0$）：分解为两互异一次因式后裂项相消，如 $\int \frac{1}{x^2 - 3x + 2} \, dx = \int (\frac{1}{x-2} - \frac{1}{x-1}) \, dx = \ln|\frac{x-2}{x-1}| + C$。

    * 二次不可分解型（$\Delta < 0$）：分母配方转化为反正切标准型，如 $\int \frac{1}{x^2 - 2x + 4} \, dx = \int \frac{1}{(x-1)^2 + 3} \, dx = \frac{1}{\sqrt{3}}\arctan(\frac{x-1}{\sqrt{3}}) + C$。

    * 配方负常数型（实质 $\Delta > 0$）：配方后若为 $(x-1)^2 - 4$，按平方差裂项求解，得 $\int \frac{1}{x^2 - 2x - 3} \, dx = \frac{1}{4}\ln|\frac{x-3}{x+1}| + C$。

    * > **易错点**：⚠️ 二次分母配方后若常数项为负，绝对不能套用反正切公式（反正切分母两项必须同为正号），必须按平方差裂项求解。

* **分子一次式的导数分离法（Derivative Separation for Linear Numerator）**

    * 拆项操作准则：在分子中强行配凑分母导数，将真分式精确拆为两项。

    * 结构走向：导数项凑微分转化为对数项；剩余常数项通过分母配方转化为反正切项。

    * 典型求解：$\int \frac{x}{x^2 + 2x + 2} \, dx = \frac{1}{2}\int \frac{2x+2}{x^2+2x+2} \, dx - \int \frac{1}{(x+1)^2+1} \, dx = \frac{1}{2}\ln(x^2 + 2x + 2) - \arctan(x+1) + C$。

### 待定系数法与赋值拆分

* **部分分式分解设项规则（Partial Fraction Decomposition Setup Rules）**

    * 一次因式设项：分母为 $x - a$，分子设常数 $A$。

    * 二次不可约因式设项：分母为 $x^2 + px + q$，分子设一次式 $Bx + C$。

    * 互异因式待定系数法：$\frac{1}{(1+2x)(1+x^2)} = \frac{A}{1+2x} + \frac{Bx+C}{1+x^2}$；两端同乘分母后对比同次项系数解得 $A = \frac{4}{5}, B = -\frac{2}{5}, C = \frac{1}{5}$；积分结果为 $\frac{1}{5}\ln\frac{(2x+1)^2}{x^2+1} + \frac{1}{5}\arctan x + C$。

* **重因式升幂设项与特殊值法（Repeated Factors Setup and Special Value Method）**

    * 重因式设项准则：分母含有 $(x - a)^k$ 时，必须逐级升幂设全 1 次到 $k$ 次项：$\sum_{i=1}^k \frac{A_i}{(x - a)^i}$。

    * 特殊值法（赋值法）：通过代入使各因式为零的特征值瞬间孤立系数，再选取运算简便点（如 $x = 0$）解出剩余系数。

    * 典型求解：$\frac{x^2 + 1}{(x + 2)(x + 1)^2} = \frac{A}{x + 2} + \frac{B}{x + 1} + \frac{C}{(x + 1)^2}$。
        * 代入 $x = -1$ 得 $C = 2$；代入 $x = -2$ 得 $A = 5$；代入 $x = 0$ 解得 $B = -4$。
        * 逐项积分结果为 $5\ln|x + 2| - 4\ln|x + 1| - \frac{2}{x + 1} + C$。

| 分式因式类型 | 分解项假设形式 | 积分求值核心走向 |
| :--- | :--- | :--- |
| 一次因式 $(x - a)$ | $\frac{A}{x - a}$ | 凑微分直接得到对数项 $\ln\|x - a\|$ |
| $k$ 重一次因式 $(x - a)^k$ | $\frac{A_1}{x - a} + \frac{A_2}{(x - a)^2} + \dots + \frac{A_k}{(x - a)^k}$ | 一次项出对数，高次项直接出幂函数 $-\frac{A_i}{(i-1)(x-a)^{i-1}}$ |
| 单个二次因式 $(x^2 + px + q)$ | $\frac{Bx + C}{x^2 + px + q}$ | 分子拆项：分母导数项出对数，常数项配方出反正切 |
| $m$ 重二次因式 $(x^2 + px + q)^m$ | $\sum_{j=1}^m \frac{B_j x + C_j}{(x^2 + px + q)^j}$ | 导数项凑微分降次，高次常数项结合递推或分部积分 |

### 根式有理化换元法

* **单一根式整体换元法（Whole Radical Substitution）**

    * 换元准则：直接令根式整体为新自变量 $t$。

    * 微分联动必须性：反解自变量 $x$ 之后必须立刻求出微分项 $dx$，严防漏乘导数因子。

    * 平方根式求解：$\int \frac{\sqrt{x - 1}}{x} \, dx$，令 $t = \sqrt{x - 1} \implies x = t^2 + 1, dx = 2t \, dt$；原式化为 $2\int \frac{t^2}{t^2 + 1} \, dt = 2t - 2\arctan t + C$；回代自变量得 $2\sqrt{x - 1} - 2\arctan(\sqrt{x - 1}) + C$。

    * 三次根式求解：$\int \frac{1}{1 + \sqrt[3]{x + 2}} \, dx$，令 $t = \sqrt[3]{x + 2} \implies x = t^3 - 2, dx = 3t^2 \, dt$；展开降次积分得 $\frac{3}{2}(\sqrt[3]{x + 2})^2 - 3\sqrt[3]{x + 2} + 3\ln|\sqrt[3]{x + 2} + 1| + C$。

* **互异方根最小公倍数换元法（Least Common Multiple Substitution of Distinct Radicals，LCM）**

    * 触发前提：被积函数中同时出现同一个线性表达式的不同次方根。

    * 换元规则：设 $x = t^L$，其中指数 $L = \text{lcm}(p_1, p_2, \dots)$ 为所有根指数的最小公倍数，使所有方根同时化为纯整数次幂。

    * 典型求解：$\int \frac{1}{(1 + \sqrt[3]{x})\sqrt{x}} \, dx$。根指数为 3 与 2，$\text{lcm}(3, 2) = 6$；令 $x = t^6, dx = 6t^5 \, dt$；原式化为 $6\int \frac{t^2}{t^2 + 1} \, dt = 6t - 6\arctan t + C$；回代得 $6\sqrt[6]{x} - 6\arctan(\sqrt[6]{x}) + C$。
