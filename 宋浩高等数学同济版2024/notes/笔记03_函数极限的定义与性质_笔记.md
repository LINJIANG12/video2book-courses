# 函数极限的定义与性质

## 有限值处的函数极限

### 极限的精确定义

* **自变量趋于有限值的函数极限（Limit of a Function as Variable Approaches Finite Value，$\epsilon$-$\delta$ 语言）**

    * > **定义**：设函数 $f(x)$ 在点 $x_0$ 的某一去心邻域 $\mathring{U}(x_0, \delta)$ 内有定义，若存在常数 $A$，对任意给定的正数 $\epsilon$，总存在正数 $\delta$，使得当 $0 < |x - x_0| < \delta$ 时均有 $|f(x) - A| < \epsilon$，则常数 $A$ 称为 $f(x)$ 当 $x \to x_0$ 时的极限，记作 $\lim_{x \to x_0} f(x) = A$ 或 $f(x) \to A \ (x \to x_0)$。

    * 误差受控机理：正数 $\epsilon$ 代表纵向允许的误差容限，以 $A$ 为中心划定区间 $(A - \epsilon, A + \epsilon)$；分析目标是在横轴上寻找控制半径 $\delta$，使去心邻域内的函数图像完全落在该带状区域内。

    * 几何包夹图示：

        ```text
                   y
                   ^
           A + ε --+-------------+---------------+
                   |             |               |
               A --+-------------o---------------+   <-- (x0 处可以空心无定义)
                   |             |               |
           A - ε --+-------------+---------------+
                   |             |               |
                   +-------------+-------+-------+----> x
                   0           x0-δ     x0     x0+δ
        ```

    * > **易错点**：⚠️ 混淆极限存在与函数的连续性。连续性要求“极限存在”、“该点有定义”且“极限值等于该点函数值”三条件同时成立；而在纯粹讨论极限存在性时，目标点处是否有定义、函数值取何值，对极限是否存在完全没有影响。

* **去心邻域与定义域约束（Deleted Neighborhood and Domain Constraints）**

    * > **定义**：在极限逼近过程中，自变量在目标点附近变动但严格排除目标点本身的局部取值范围。

    * 去心不等式约束：自变量满足 $0 < |x - x_0| < \delta$，不等号左侧 $0 < |x - x_0|$ 保证 $x \neq x_0$，极限仅探讨逼近趋势，自变量最终不需要到达 $x_0$ 点本身。

    * 定义域约束边界：函数 $f(x)$ 仅需在 $x_0$ 的去心邻域内有定义，$x_0$ 目标点处完全可以没有定义。

### 控制半径的选取与放缩

* **控制半径选取原则（Selection Principle of Control Radius，$\delta$）**

    * > **定义**：在 $\epsilon$-$\delta$ 语言证明中，用于约束自变量与趋近目标点之间绝对偏差上限的正实数参量的选取规则。

    * 选取非唯一性：定义仅要求存在合规的正数 $\delta$，若某正数 $\delta_0$ 满足条件，则任意取更小的值（如 $\frac{1}{2}\delta_0$）同样满足控制要求。

    * 邻域紧缩取小规则：$\delta$ 越小则去心邻域越收缩，函数受到的局部约束越强；当面对多重放缩约束时，取交集 $\delta = \min\{\delta_1, \delta_2\}$。

* **典型初等函数的放缩模式（Scaling Patterns for Typical Elementary Functions）**

    * > **定义**：针对不同初等函数结构，通过绝对值偏差展开式构造合格控制半径 $\delta$ 的不等式凑配方法。

    * 常数函数放缩规则：对于 $f(x) = C$，偏差 $|C - C| = 0 < \epsilon$ 恒成立，$\delta$ 可任意选取任意正数（如 $\delta = 1$）。

    * 恒等映射放缩规则：对于 $f(x) = x$，偏差项 $|x - x_0|$ 与控制项形态一致，直接取 $\delta = \epsilon$。

    * 一次线性多项式放缩规则：对于 $f(x) = kx + b$，偏差项展开为 $|k||x - x_0| < \epsilon$，移项放大取 $\delta = \frac{\epsilon}{|k|}$。

    * 具公因式分式放缩规则：对于形如 $\frac{x^2 - 1}{x - 1}$ 的分式，在去心邻域 $x \neq 1$ 条件下约去零因子化简为多项式 $x + 1$，直接取 $\delta = \epsilon$。

## 单侧极限与双侧极限

### 单侧极限的精确表述

* **左极限（Left-Hand Limit，LHL）**

    * > **定义**：自变量 $x$ 仅从点 $x_0$ 的左侧（$x < x_0$）无限趋近于 $x_0$ 时的函数极限，记作 $\lim_{x \to x_0^-} f(x) = A$ 或简记为 $f(x_0^-) = A$。

    * 邻域不等式条件：自变量处于左侧满足 $x_0 - \delta < x < x_0$，化简绝对值后单侧不等式为 $0 < x_0 - x < \delta$。

* **右极限（Right-Hand Limit，RHL）**

    * > **定义**：自变量 $x$ 仅从点 $x_0$ 的右侧（$x > x_0$）无限趋近于 $x_0$ 时的函数极限，记作 $\lim_{x \to x_0^+} f(x) = A$ 或简记为 $f(x_0^+) = A$。

    * 邻域不等式条件：自变量处于右侧满足 $x_0 < x < x_0 + \delta$，化简绝对值后单侧不等式为 $0 < x - x_0 < \delta$。

### 极限存在的判定准则

* **双侧极限充要条件定理（Necessary and Sufficient Condition for Two-Sided Limit）**

    * > **定义**：函数 $f(x)$ 当 $x \to x_0$ 时的双侧极限存在的充分必要条件是左极限与右极限各自存在且数值严格相等，即 $\lim_{x \to x_0} f(x) = A \iff f(x_0^-) = f(x_0^+) = A$。

    * 判定规则：分界点处左右极限只要有一侧不存在，或两侧极限虽存在但数值不相等，则双侧极限判定为不存在。

* **分段函数分界点极限判定（Limit Determination at Dividing Points of Piecewise Functions）**

    * > **定义**：针对在分界点两侧解析表达式不同的函数，通过分别计算单侧极限以确定整体极限的判定方法。

    * 左右极限不相等情形：对于 $f(x) = x - 1 \ (x < 0)$、$0 \ (x = 0)$、$x + 1 \ (x > 0)$，左极限为 $-1$ 而右极限为 $1$，两者不相等，整体极限不存在。

    * 左右极限相等情形：对于 $f(x) = x - 1 \ (x < 0)$、$0 \ (x = 0)$、$2x - 1 \ (x > 0)$，左极限为 $-1$ 且右极限为 $-1$，整体极限存在且等于 $-1$。

    * 点定义值解耦边界：分界点处给出的独立定义（如 $f(0) = 0$）与求得的极限值（$-1$）是否相等完全解耦，对极限存在与否不产生干扰。

## 无穷大处的函数极限与界变量选取

### 无穷大处的函数极限

* **自变量趋于无穷大的函数极限（Limit of a Function at Infinity，$\epsilon$-$X$ 语言）**

    * > **定义**：设函数 $f(x)$ 当 $|x|$ 大于某一正数时有定义，若存在常数 $A$，对任意给定的正数 $\epsilon$，总存在正数 $X$，使得当 $|x| > X$ 时均满足 $|f(x) - A| < \epsilon$，则常数 $A$ 称为 $f(x)$ 当 $x \to \infty$ 时的极限，记作 $\lim_{x \to \infty} f(x) = A$。

    * 对称双向覆盖：条件 $|x| > X$ 等价于 $x > X$ 或 $x < -X$，即自变量脱离闭区间 $[-X, X]$ 向正负两极发散。

    * 单侧无穷大受控条件：自变量趋于正无穷 $x \to +\infty$ 对应单侧约束 $x > X$；趋于负无穷 $x \to -\infty$ 对应单侧约束 $x < -X$。

    * 倒数衰减模型取界：对于反比例函数 $f(x) = \frac{1}{x}$，由误差条件 $\frac{1}{|x|} < \epsilon$ 两边取倒数反解得 $|x| > \frac{1}{\epsilon}$，门槛值直接取 $X = \frac{1}{\epsilon}$。

* **水平渐近线几何特征（Geometric Characteristics of Horizontal Asymptote）**

    * > **定义**：当曲线上的动点沿着曲线无限远离原点时，该动点与某条水平直线的垂直距离趋向于零的几何性质。

    * 渐近包夹机理：$\lim_{x \to \infty} f(x) = A$ 几何上代表自变量跨过门槛边界 $+X$ 与 $-X$ 向无穷远处延伸时，曲线整体被限制在以直线 $y = A$ 为对称轴、半宽为 $\epsilon$ 的水平带状通道内，直线 $y = A$ 即为曲线的水平渐近线。

    * 几何通道图示：

        ```text
                   y
                   ^
           A + ε --+-----------------------------+-------
                   |      ~~~~~~~~~~~~~~~~~~~~~~~|~~~~~~~ f(x)
               A --+-----------------------------+------- (水平渐近线 y = A)
                   |                             |
           A - ε --+-----------------------------+-------
                   |                             |
                   +-----------------------------+------> x
                   0                            +X
        ```

### 界变量的选取原则与对比

* **界变量取大原则（Principle of Taking Maximum for Bound Variable $X$）**

    * > **定义**：在自变量趋于无穷大的极限证明中，用于确定外移观测窗口截断门槛参量的选取准则。

    * 观测窗口外移机理：界变量 $X$ 遵循“越大越好”原则，只要函数在门槛 $X$ 右侧贴近渐近线，将观测窗口继续向右外移（如取 $2X$ 或 $10X$），不等式必然更稳妥成立；多重约束取 $X = \max\{X_1, X_2\}$。

    * > **注意**：放缩过程中若误把界变量改小，考察范围向原点方向蔓延，容易把局部剧烈震荡或超出误差范围的点纳入，导致证明失效。

* **极限受控变量选取方向对比（Comparison of Control Variables Selection Direction）**

    * > **定义**：有限趋近与无穷趋近两类分析过程中核心控制参量演化方向的对比体系。

    * 逼近机制图解：

        ```text
        有限点趋近 (x -> x0):    (------(--- x0 ---)------)
                                       <- delta ->
                                 delta 越小，邻域收缩越紧，函数波动越受控 (取小原则)

        无穷远趋近 (x -> inf):   --------|--------------------->
                                         X
                                 X 越大，区间 [X, +inf) 越靠右，越贴近极限 (取大原则)
        ```

    * 控制变量特征对比：

        | 逼近类型 | 核心控制变量 | 几何区域 | 取值控制方向 | 典型合并操作 |
        | :--- | :--- | :--- | :--- | :--- |
        | 有限趋近 $x \to x_0$ | 邻域半径 $\delta$ | 去心对称区间 $(x_0 - \delta, x_0 + \delta) \setminus \{x_0\}$ | 越小越好（向内紧缩） | $\delta = \min\{\delta_1, \delta_2\}$ |
        | 无穷趋近 $x \to \infty$ | 截断界限 $X$ | 无穷开区间 $(X, +\infty) \cup (-\infty, -X)$ | 越大越好（向两端推移） | $X = \max\{X_1, X_2\}$ |

## 函数极限的基本性质

### 唯一性与局部有界性

* **极限的唯一性（Uniqueness of Limit）**

    * > **定义**：若函数 $f(x)$ 当 $x \to x_0$（或 $x \to \infty$）时的极限存在，则该极限值有且仅有一个确定的常数。

    * 排除多重终点：函数值在自变量逼近的终点不可能同时无限靠近两个不同的数值。

    * 证伪依据：若验证出沿不同路径或不同方向逼近得到的极限数值不相同，即可判定原函数极限不存在。

* **局部有界性（Local Boundedness）**

    * > **定义**：若极限 $\lim_{x \to x_0} f(x) = A$ 存在，则存在正数 $M > 0$ 及 $\delta > 0$，使得当 $0 < |x - x_0| < \delta$ 时，恒有 $|f(x)| \leqslant M$。

    * 概念内涵界定：“局部”指自变量严格限制在 $x_0$ 的去心邻域 $(x_0 - \delta, x_0 + \delta) \setminus \{x_0\}$ 内，不要求在全定义域上有界；“有界”指存在正实数 $M$ 将局部函数值彻底包络在 $[-M, M]$ 内部。

    * 局部上界构造：设定误差容限 $\epsilon = 1$，必存在 $\delta > 0$ 使去心邻域内函数值落在 $(A - 1, A + 1)$，局部界可显式取为 $M = \max\{|A - 1|, |A + 1|\} = |A| + 1$。

    * 局部有界包络图示：

        ```text
        y
        ^
        |                  局部上界 M = |A| + ε
        |   -------------------------------------------------
        |                    f(x) 波动带
        |   A -------------(   *   )------------ (极限值 A)
        |   -------------------------------------------------
        |                  局部下界 -M
        |-------------------|---|---|-------------------------> x
                           x0-δ x0 x0+δ
        ```

### 局部保号性

* **局部保号性（Local Sign-Preserving Property）**

    * > **定义**：若 $\lim_{x \to x_0} f(x) = A$，且常数 $A > 0$（或 $A < 0$），则存在 $\delta > 0$，使得当 $0 < |x - x_0| < \delta$ 时，恒有 $f(x) > 0$（或 $f(x) < 0$）。

    * 符号一致机理：去心邻域内的函数值符号与极限值 $A$ 的符号严格保持一致，极限为正局部函数值必全为正，极限为负局部函数值必全为负。

    * 微小正极限保号构造：即使极限值微弱为正（如 $A = 0.001$），取正数 $\epsilon = \frac{A}{2}$，去心邻域内恒有 $f(x) > A - \epsilon = \frac{A}{2} > 0$。

    * 局部保号图示：

        ```text
        y
        ^
        |                   f(x) 局部曲线段
        |                     .-----.
        |   A --------------(   *   )--------------- (A > 0)
        |                     '-----'
        |   ........................................ y = 0 (x 轴)
        +-------------------|---|---|------------------> x
                           x0-δ x0 x0+δ
        ```

* **局部保号性的去心边界约束（Boundary Constraints of Local Sign-Preserving Property）**

    * > **定义**：保号性在自变量定义域上的有效作用范围与其排他性边界条件。

    * 作用范围边界：保号性严格仅在去心邻域内有效，绝不包含 $x_0$ 点本身。

    * > **易错点**：⚠️ 忽略保号性的去心邻域限制。在 $x_0$ 点处，函数可以完全没有定义，也可以定义为异号数值（例如定义 $f(x_0) = -100$），这丝毫不破坏该点去心邻域内的局部保号性质。

## 函数极限与数列极限的归结原则

### 海涅定理与映射机制

* **海涅定理（Heine's Theorem，又称归结原则）**

    * > **定义**：函数极限 $\lim_{x \to x_0} f(x) = A$ 存在的充分必要条件是：对于任意满足 $x_n \to x_0$ 且 $x_n \neq x_0$ 的数列 $\{x_n\}$，相应的函数值数列 $\{f(x_n)\}$ 均收敛，且 $\lim_{n \to \infty} f(x_n) = A$。

    * 离散采样必收敛律：连续曲线上的全路径均汇聚于目标值 $A$，则在曲线上任意离散采样的点列 $\{f(x_n)\}$ 必然同步趋向于该极限值 $A$。

    * 采样逼近图示：

        ```text
        y
        ^                      f(x) 连续曲线
        |                     /
        |   A -------------->* (x0, A)
        |                   /  ^   ^
        |                  /   |   |  离散数列点 f(xn) 随曲线逼近
        |                 /    |   |
        +----------------+-----+---+---------> x
                        xn3   xn2 xn1  x0
        ```

* **连续与离散映射机制（Mapping Mechanism between Continuity and Discreteness）**

    * > **定义**：海涅定理在连续实数轴整体逼近与离散整码指标采样之间建立的严格双向映射关系。

    * 控制算子映射：函数极限算子 $\lim_{x \to x_0} f(x)$ 控制连续自变量 $x$ 的全域滑移；数列极限算子 $\lim_{n \to \infty} f(x_n)$ 控制离散项数指标 $n$ 的离散逼近。

    * 点列逼近形态自由度：离散点列靠拢 $x_0$ 不受平滑性约束，既可单侧单调逼近，亦可在 $x_0$ 两侧交替振荡收束。

### 归结原则的判定与证伪应用

* **单一数列收敛非充分律（Non-Sufficiency of Single Sequence Convergence）**

    * > **定义**：仅已知某一个特定数列满足函数值数列收敛，无法推导原函数极限必然存在的逻辑不对称性质。

    * 子集非全集机理：任意取定一个特定数列，仅是在无数逼近路径中抽取了一个狭窄子集；子集收敛无法保证全集收敛，海涅定理的等价性严格建立在“任意”收敛数列的基础之上。

    * 经典分段反例验证：针对分段函数 $f(x) = x - 1 \ (x < 0)$、$0 \ (x = 0)$、$x + 1 \ (x > 0)$，取正向点列 $x_n = \frac{1}{n} \to 0$ 时，数列极限 $\lim_{n \to \infty} f(x_n) = \lim_{n \to \infty} (\frac{1}{n} + 1) = 1$ 存在；但连续函数左极限为 $-1$、右极限为 $1$，左右极限不等导致函数极限不存在。

    * 反例离散与连续断裂图示：

        ```text
        y
        ^               y = x + 1 (x > 0)
        |            o==================> (从右侧取 xn = 1/n，极限为 1)
        |   1 ------*
        |           |
        |-----------+-------------------> x
        |          -1
        |            o==================> y = x - 1 (x < 0，从左侧逼近极限为 -1)
        |
        ```

* **海涅定理极限证伪准则（Disproof Criterion of Heine's Theorem）**

    * > **定义**：利用归结原则的逆否命题证伪连续函数极限存在性的操作准则。

    * 发散证伪规则：只要能找到一个满足 $x_n \to x_0$ 且 $x_n \neq x_0$ 的数列 $\{x_n\}$，使得其函数值数列 $\{f(x_n)\}$ 发散，即可断定 $\lim_{x \to x_0} f(x)$ 不存在。

    * 异值证伪规则：只要能找到两个均趋于 $x_0$ 且非零的数列 $\{x_n\}$ 与 $\{y_n\}$，满足 $\lim_{n \to \infty} f(x_n) \neq \lim_{n \to \infty} f(y_n)$，即可断定 $\lim_{x \to x_0} f(x)$ 不存在。
