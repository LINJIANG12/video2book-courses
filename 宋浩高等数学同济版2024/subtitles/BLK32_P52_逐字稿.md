那接着，我们介绍在不定积分里面最重要的、也是做题时候最常考到的——分部积分法。
我们讲不定积分三种方法：第一类换元积分法、第二类换元积分法，还有这个分部积分法，做题的时候用得比较多。
这个分部积分法你看课本的东西，就我们这个教材，尤其是前面的理论部分的讲解，你看和没看没有任何区别，就是好像也不知道怎么弄的。不要紧，我给你讲，听完我的讲解以后，保证比大家看课本看得更清楚。

分部积分这部分，公式就一个，并且其实你也不用管它怎么来的，公式就一个，特别简单：
$$\int u \, dv = uv - \int v \, du$$
公式就这一个。什么意思呢？$d$ 的一前一后两个函数，前后的这两个函数相乘，然后前后的这两个交换顺序。
公式就是这么简单。所以大家以后记分部积分的这个公式，$\int u \, dv = uv - \int v \, du$。

课本上也有一个推导的过程，推导过程也不难：
$(uv)' = u'v + uv'$
所以 $uv' = (uv)' - u'v$。
两边同时取积分：
$$\int uv' \, dx = \int (uv)' \, dx - \int u'v \, dx$$
$v' \, dx = dv$，$u' \, dx = du$。所以：
$$\int u \, dv = uv - \int v \, du$$
公式就出来了。推导过程比较简单，大家其实根本就不用看。

“哎那老师，那太好了，那这个好啊，考试做题的时候哎呀妈呀太简单了，两个相乘然后两个交换，挺好啊。”哪有那么好的事啊！
在做题的时候，一个表达式 $\int \dots dx$，它不会给你现成的“前头的 $u$ 是谁，后头的 $v$ 是谁”。它前面有一堆，你得先用第一类换元积分法把其中的某一项放到 $d$ 的里头去！
所以这个公式的第一步，在做题的时候一般你先得“构造”，你先得把它构造出来。
那么分部积分这部分的要点，其实最重要的就是一个事情，就是：谁做 $u$？谁做 $v$？
课本上有一段解释的过程，在 209 页。说选取 $u$ 和 $dv$ 时，一般考虑下面两点：第一，$v$ 要更容易求得；第二，$\int v \, du$ 要比 $\int u \, dv$ 更容易积出。
哎呀，它说的挺在理，但是实际做题的时候一点用都没有。
我跟你说这句“谁做 $u$、谁做 $v$”，其实也一点用都没有。所以有时候听老师讲课，讲得挺好，但是他讲的方法实不实用？做题的时候好不好用？那是另外一回事。
真正的标准是什么呢？把很复杂的东西讲得特别简单，这就是好老师。

分部积分最重要的问题就是：谁放 $d$ 的后面？谁往 $d$ 的后面去提？
另外一种解释方式就是：向 $d$ 后面拿的时候，优先级是什么？你只要把这个问题搞明白了，分部积分你就能搞定！

先看例 2：
$$\int x e^x \, dx$$
这里有 $x$，这里有 $e^x$。你有两种选择，一个就是把 $x$ 朝里拿，一个就是把 $e^x$ 朝里拿。我们选择把 $e^x$ 朝里拿。
$e^x$ 求原函数还是 $e^x$。好了，一前一后两个函数：
$$= \int x \, d(e^x)$$
先它俩相乘，再它俩交换：
$$= x e^x - \int e^x \, dx = x e^x - e^x + C$$
就完了！

所以刚才说到的优先级的事，你记着：
$e^x$ 的优先级是最高的！有 $e^x$，先把它朝 $d$ 的里头拿。为什么啊？因为 $e^x$ 妙啊，求原函数和求导都是它本身。
“老师，我偏是信你的邪，我就不把 $e^x$ 朝里拿，我就把 $x$ 朝里拿，怎么着，不行吗？”
行啊，你试呗。$x$ 朝里拿是 $\frac{1}{2} x^2$：
$$= \int e^x \, d\left(\frac{1}{2}x^2\right) = \frac{1}{2}x^2 e^x - \frac{1}{2} \int x^2 \, d(e^x) = \frac{1}{2}x^2 e^x - \frac{1}{2}\int x^2 e^x \, dx$$
分部积分做到这一步以后，这里边这个函数一定要朝外拿。原来人家还是个 1 次方，你搞了一次以后变成了 2 次方，你再搞一次变成 3 次方，猴年马月你也做不出来了。所以越来越简单才行，$x$ 朝里拿是不行的。

看例 1：
$$\int x \cos x \, dx$$
这次我们学乖了，把 $\cos x$ 拿进来：
$$= \int x \, d(\sin x) = x \sin x - \int \sin x \, dx = x \sin x + \cos x + C$$
所以这个优先级，$\sin x$ 跟 $\cos x$ 的优先级排在其次。

“老师，如果既有 $\sin x$，又有 $e^x$，老大跟老二一块儿出现了，你怎整？”
我们还是先把 $e^x$ 朝里弄：
$$\int e^x \sin x \, dx = \int \sin x \, d(e^x) = e^x \sin x - \int e^x \, d(\sin x) = e^x \sin x - \int e^x \cos x \, dx$$
一前一后交换了之后，这个 $d$ 里头的东西必须朝外拿，你才能继续做。这个 $e^x$ 咱们再拿一次：
$$= e^x \sin x - \int \cos x \, d(e^x) = e^x \sin x - \left[ e^x \cos x - \int e^x \, d(\cos x) \right]$$
$\cos x$ 朝外拿求导是 $-\sin x$，所以负负得正，变成：
$$= e^x \sin x - e^x \cos x - \int e^x \sin x \, dx$$
一看有点傻眼了，为什么呢？原来求的是 $\int e^x \sin x \, dx$，现在怎么又出来了？求了老半天，要求的那个东西又神奇般地出现了，是不是啊？是的！
你记着：分部积分在做题的时候，常见的一个套路或者常见的一个现象就是：要求的东西竟然又出现了！
要求的东西又出现了，不用慌，不用忙，仔细看一看。
刚才要求的东西是不是又出现了？是的。但这里是个负号吧？挪过去是不是两个相加变成两倍？两边除以 2 是不是就求出来了：
$$\int e^x \sin x \, dx = \frac{1}{2} e^x (\sin x - \cos x) + C$$

不要慌，不要忙，看一看它前面的系数。
如果要求的东西出现了，前面的系数是个 $+1$，那你就死定了！因为两边抵消掉了变成 $0=0$，说明你做错了！
分部积分因为有个负号，要求的东西再次出现，一般是用分部积分至少两次才能再出现。如果系数是 $+1$，你检查你的负号，一检查保证你做错了。如果是其他的系数，挪过去消掉就行了。
分部积分最重要的问题：第一是朝里拿的优先级是谁；第二是要修的东西神奇般地又出现了；第三，分部积分实际考试做题一般要用两次以上。

看例 3：
$$\int x^2 e^x \, dx = \int x^2 \, d(e^x) = x^2 e^x - \int e^x \, d(x^2) = x^2 e^x - 2\int x e^x \, dx$$
再对 $\int x e^x \, dx$ 做一次分部积分：
$$= x^2 e^x - 2\left( x e^x - \int e^x \, dx \right) = x^2 e^x - 2x e^x + 2e^x + C$$
这个题做了两次。原来是 $x^2$，做一次变成 $x$，再做一次就没了，越来越简单。

在例 4 之前，插一个：
$$\int \ln x \, dx$$
这个东西怎么弄？要朝 $d$ 的后头去拿，但只有一个 $\ln x$，它的原函数谁也不知道。
不要紧，把它做成一个函数：$x$ 是个函数吧？
$$= \int \ln x \, d(x) = x \ln x - \int x \, d(\ln x) = x \ln x - \int x \cdot \frac{1}{x} \, dx = x \ln x - x + C$$
所以 $\ln x$ 的原函数是 $x \ln x - x + C$。这个公式大家得记住！以后 $\ln$ 的原函数要做成一个已知的结论。

看例 4：
$$\int x \ln x \, dx = \int \ln x \, d\left(\frac{1}{2}x^2\right) = \frac{1}{2}x^2 \ln x - \frac{1}{2}\int x^2 \cdot \frac{1}{x} \, dx = \frac{1}{2}x^2 \ln x - \frac{1}{4}x^2 + C$$
所以朝里拿的优先级，第三个才是 $x^n$。$e^x, \sin x, \cos x$ 就够你用的，$x^n$ 朝里拿很少很少。

看例 5：
$$\int \arccos x \, dx = x \arccos x - \int x \, d(\arccos x) = x \arccos x + \int \frac{x}{\sqrt{1-x^2}} \, dx$$
把 $x$ 拿到 $d$ 里头去：
$$= x \arccos x - \frac{1}{2} \int \frac{d(1-x^2)}{\sqrt{1-x^2}} = x \arccos x - \sqrt{1-x^2} + C$$

看例 6：
$$\int x \arctan x \, dx = \int \arctan x \, d\left(\frac{1}{2}x^2\right) = \frac{1}{2}x^2 \arctan x - \frac{1}{2} \int \frac{x^2}{1+x^2} \, dx$$
分子加 1 再减 1：
$$= \frac{1}{2}x^2 \arctan x - \frac{1}{2}\left( \int 1 \, dx - \int \frac{1}{1+x^2} \, dx \right) = \frac{1}{2}(x^2+1)\arctan x - \frac{1}{2}x + C$$

例 7 讲过一遍，要求的东西又出现了。

看例 8：
$$\int \sec^3 x \, dx = \int \sec x \, d(\tan x) = \sec x \tan x - \int \tan x \, d(\sec x) = \sec x \tan x - \int \tan^2 x \sec x \, dx$$
$\tan^2 x = \sec^2 x - 1$：
$$= \sec x \tan x - \int \sec^3 x \, dx + \int \sec x \, dx$$
要求的东西又神奇般地出现了，移项除以 2：
$$\int \sec^3 x \, dx = \frac{1}{2}\sec x \tan x + \frac{1}{2}\ln|\sec x + \tan x| + C$$

看例 9：
$$\int e^{\sqrt{x}} \, dx$$
讨厌带根号。令 $t = \sqrt{x} \implies x = t^2, dx = 2t \, dt$：
$$= \int e^t \cdot 2t \, dt = 2\int t e^t \, dt = 2(t e^t - e^t) + C = 2(\sqrt{x}-1)e^{\sqrt{x}} + C$$

如果不换元：
$$\int e^{\sqrt{x}} \, dx = \int e^{\sqrt{x}} \, d(x) = \dots = 2\sqrt{x} e^{\sqrt{x}} - 2\int e^{\sqrt{x}} \, d(\sqrt{x}) = 2(\sqrt{x}-1)e^{\sqrt{x}} + C$$

分部积分第一是朝里拿的优先级，第二是要求的式子神奇般地再次出现。最后一部分是有理函数的积分，我们下节课好好给大家讲。
