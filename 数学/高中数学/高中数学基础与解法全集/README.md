# 高中数学基础与解法全集（198 讲）

B 站高中数学基础与解法全集，长期更新，从零开始覆盖新教材必修一至选必二全部主干：集合与逻辑、函数体系、三角与向量、立体几何与空间向量、直线与圆、圆锥曲线、数列、导数、计数原理与概率统计。课程按「基础概念 → 解法流程 → 大题专练」三层推进，198 集整编为 23 册模块全书与 42 篇主题复习笔记，是本仓覆盖 K12 学段的唯一一门课。

- **原视频**：[高中数学基础与解法全集（涵盖所有）](https://www.bilibili.com/video/BV147411K7xu) — Bilibili，BV147411K7xu
- **全 198 集**，已产出 23 册模块全书、42 篇复习笔记、162 份逐字稿

## 怎么学

- **按教材顺序跟**：课程完全贴合新教材章节序（必修一 → 选必二），每册对应一个专题段，跨册概念有依赖关系，建议顺序学。
- **函数与导数是两大主线**：函数性质（单调/奇偶/周期）贯穿三角、指数对数与导数，笔记 04~09 与 31~35 是这条线的两级台阶。
- **几何双轨**：立体几何走「定义判定 → 空间向量」两套解法（笔记 16~20），解析几何走「直线圆 → 三大曲线」（笔记 22~26），大题专练单独成篇。
- **数列与概率各有速查篇**：数列求通项/求和方法与「必做十题」系列（笔记 27~30），概率统计按必修/选修分层（笔记 21、36~41）。
- **考前只看 `notes/`**：42 篇笔记按小专题拆分，定义、解法流程与易错点并排放置，适合按弱项点查。
