Hello everybody. 这节视频我们重点来研究一下不等式的性质。大家别一看“不等式”就觉得这节课是不是好难呀，其实不是，本节课讲的知识很多都是小学知识。

今天咱们就讲一件事情，就是如果给大家一个条件是 $a > b$，那么由这个条件我们能推出什么样的新表达式呢？

首先第一种运算叫加减乘除。那我奶奶都知道，一开始 $a$ 比 $b$ 大，那我把两边同时加上一个或者减去一个相同的数，这个 $a + c$ 和 $b + c$ 加完之后，那肯定还是 $a$ 比 $b$ 大，不论这个 $c$ 值是正值还是负值。举个例子，十年前我爸爸比我大 20 岁，那过了十年之后，难道我爸爸就比我小了吗？显然这是不合理的。一开始哪个值大，两边加完相同的数还是谁大。这个是加减法。

如果是乘除法呢？如果现在改成两边同时乘一个数，乘完之后是不是一定也是 $a$ 大呢？可注意，这是不一定的。如果两边乘的数都是正数，那没问题，这个式子成立。但是如果乘的是负数的话，那么两边的不等号是要变号的。比如说一开始 $3$ 比 $2$ 大，我两边乘上 $2$，那 $6$ 比 $4$ 也大，没问题，两边乘 $2$ 乘的是正数，不等号方向不变；但是如果我乘 $-2$ 的话，$-6$ 和 $-4$ 谁大？显然 $-4$ 更大，这不等号的方向就要变了。

这是第一组非常简单的不等式的简单运算。那接下来我们来看第二组。

如果现在给大家两个不等式，分别是 $a > b$ 和 $c > d$，这个不等号的方向是一样的，都是大于号或者都是小于号，那我们能得到什么呢？

第一个，同向可加。意思就是说左边大的加大的，和小的加小的，这谁大谁小一目了然，那肯定是左边还比右边大。我觉得这个不需要任何解释，这个太简单了。加法是这个样子，乘法是不是呢？如果两个大的数相乘，它是否一定大于两个小的数相乘呢？注意，这个不一定，它有限制条件。这四个值必须都得是正值，同向、同正才可以乘。这里的“同向”指的是我等号的方向是一样的，都是大于号或者都是小于号；“同正”的意思就是说这四个值 $a, b, c, d$ 都得是正的。满足了这两个条件，它才能乘。

有的宝贝不明白为什么都得是正的，我负的难道不行吗？还真不行。比如举个例子，我们知道 $2$ 比 $-10$ 要大，$3$ 比 $-100$ 要大，那我这两边一乘的话，左边乘左边是 $6$，右边乘右边是 $1000$，难道你能说 $6$ 比 $1000$ 还大？这太荒谬了吧。

所以第二组不等式，它研究的是如果我们有两个不等式，而且它们是同向的，我们可以把它们相加或者相乘。

接下来我们来看最后一组。

如果给大家两个正数，而且 $a > b$ 的话，我们可以对它进行乘方或者开方。乘方的意思就是说两边都 $n$ 次幂，$a^n$ 还大于 $b^n$。开方的意思呢，就是说两边都开 $n$ 次根号，$\sqrt[n]{a}$，$\sqrt[n]{b}$，不等号方向不变。但是有没有前提条件？有。这里面一定要注意这个 $n$ 的取值。目前大家还没学 $n$ 取分数的情况，所以目前 $n$ 只能取整数，而且 $n$ 不能是负的，$n$ 得大于等于 $2$，这是它的前提条件。

以上就是几个简单的不等式的小性质。那真正题目会怎么考呢？

它会在选择题里面给你 A、B、C、D 各种各样的表达式让你去判断谁对谁错，有可能是单选题，有可能是多选题。那我们现在来先看第一个。

已知 $a, b, c$ 都是 $\mathbf{R}$。$\mathbf{R}$ 什么意思？$\mathbf{R}$ 是所有实数的意思，$a, b, c$ 是任意取值的。其中 $a > b$，那就意味着 $a$ 和 $b$ 有可能都是正的，有可能都是负的，有可能一正一负。

现在人家问下面哪一个对。首先 A 选项，$\frac{1}{a}$ 和 $\frac{1}{b}$ 谁大谁小，这个能确定吗？这个不能确定。做这类问题如果想快速判断的话，我们有一个最简便的方法就是代特殊值。大家多代几组值，代几个正值、代几个负值来试一试就好了。那我们就随便代几个值，比如说 $3 > 2$。那咱就来看，A 选项 $\frac{1}{3}$ 是不是小于 $\frac{1}{2}$ 呢？它好像的确是。但是如果我再代一个 $3 > -2$ 呢，$a$ 取 $3$，$b$ 取 $-2$，那难道 $\frac{1}{3} < -\frac{1}{2}$ 吗？正数怎么可能小于负数？所以 A 选项我都把特例找到了，那肯定就不对了。

来看 B 选项。B 选项也一样，它现在把两边都平方了。我们知道两边平方，人家又把这大于号变成小于号，这个平方完符号变不变受什么影响？受你 $a, b$ 到底是正还是负的影响吧。刚才讲过了，如果 $a, b$ 都是正值的话，我们两边都平方、乘方完之后，这个不等号的方向应该是不变的才对，所以 B 选项肯定也不对。

来看 C。C 说什么呢？一开始我们有的是 $a > b$。现在它把 $a$ 和 $b$ 两边都乘一个相同的东西，是谁呢？是 $c$ 的绝对值 $|c|$。它觉得乘完 $c$ 的绝对值之后，这不等号的方向不变。因为他觉得这个绝对值肯定是正的，你乘正数不等号方向肯定不变。那 C 对还是不对？C 不对。因为我们只能保证绝对值它大于等于 $0$。万一，如果非常不幸 $c$ 如果是 $0$ 怎么办？你两边乘 $0$ 之后，这是 $0$，右边也是 $0$，那它就都是 $0$ 就相等了，对不对？所以 C 选项当 $c$ 取 $0$ 的时候，它也是一个特例，C 不对，那就只能选 D 了。

D 选项说什么呢？说本来 $a$ 是大于 $b$ 的，现在我两边都除以 $c^2 + 1$。那除完之后不等号方向不变，为什么不变？因为 $c^2 + 1$ 肯定是正数。两边同时乘以或者除以正数，不等号方向肯定不能变，答案选 D。

这题属于一个难度比较低的题。那我们再稍微来看一看难度大那么一点点的。

首先来看，还是 A、B、C、D 有四个千奇百怪的式子让大家去判断。我们首先来看 A 选项。我们已知 $a, b$ 都是正数，$a > b$，而且 $m$ 一定是负数。它问我什么呢？它说 $a m^2$ 和 $b m^2$ 怎么怎么样。我们知道 $a$ 一开始是大于 $b$ 的，$m^2$ 肯定是正的，那你乘完正数之后不等号方向能变吗？不能变才对，它正好说反了，所以 A 肯定不对。

来看 B。B 选项这个式子对还是不对，你光在这看不太好看，我们把它等价变形变形。它等价于什么呢？我现在想把这个分母乘过去。那乘的过程当中我们初中学过，乘过去的时候变不变号，你要看乘的这东西到底是正还是负，对不对？那 $b - a$，显然 $b - a$ 的话，$b$ 是小的值，$a$ 是大的值，那 $b - a$ 应该是一个负值。咱乘的是个负数就意味着两边乘完之后要……

变号了。现在我们来判断一下他说对还是不对呢？我们知道现在 $m$ 是一个负数，但是它负到什么程度我是不知道的。如果说一会儿判断完这边是正数的话，如果是正数，那它就成立；但是如果你一会儿判断完这边是负数，两个都是负数，具体谁比谁小你知道吗？我们是没有办法判断的，对不对？好，那我们来看，$b$ 是小的数，$b - a$ 肯定是负值。俩负数能判断大小吗？我们不知道，所以 B 选项对错无法判断。

来看 C。C 也是一个看着比较复杂的式子，所以它的处理方式，如果你用最笨最笨的方法，就跟 B 选项一样，把它进行化简，把它进行等价变形。怎么变形呢？把分母去掉不就得了吗？分母一个是 $b - m$，一个是 $b$。两边同乘两分母，都乘 $b(b - m)$。左边就是 $(a - m)b$，右边就是 $a(b - m)$。那么问题来了，同乘这个东西，不等号方向变不变？我得看这个东西的正负。首先按照题目来说，$b$ 肯定是正的；$b - m$ 怎么样呢？它是一个正数减去一个负数，正数减负数肯定也是正的，所以它整体一定大于 0。乘正数不等号方向原来是小于号，现在依然得是小于号。

所以现在的问题变成了我只要证明出下面的式子成立。下面的式子成不成立，我继续化简：$ab - mb$，$ab - am$，两边 $ab$ 约掉。做到这，整道题就如瓮中捉鳖。咱们把两项移到一边去，这个 $-am$ 移到左边的话，就变成了正 $am$：$am - mb$。我只要证明它小于 0 就可以了。它小不小于 0？我把 $m$ 提出来，因式分解一下：$m(a - b)$ 是不是小于 0 的？它如果成立，那么 C 就成立；它如果不成立，C 就不成立。第一步我发现 $a - b$，因为人家说 $a > b$ 了，所以 $a - b$ 一定是正的。$m$ 人家指明了，题目中说了它是负的，一负一正相乘的话，那肯定是小于 0 的。所以 C 选项说得对还是不对？肯定是对的。

最后就剩一个 D 选项了。你看这 D 选项长这个样子，长得多少有点复杂，长得有点恶心。它可以采用跟 C 选项一样去把它化简一下，然后再去看它成不成立。但是如果觉得化简太麻烦了，计算量太大了，咱也可以把题往简单了做，我们采用代特殊值的方法。那就按照题目中说的大小，他说 $a > b$，那我 $a$ 取 2，$b$ 取 1。题目还说 $m < 0$，$m < 0$ 我就把 $m$ 取个 $-1$。我来看看它对不对。左边是 $\frac{a - m}{a^2}$，$\frac{2 - (-1)}{2^2} = \frac{3}{4}$；他说这个数大于 $\frac{b - m}{b^2}$，$\frac{1 - (-1)}{1^2} = 2$。左边算完应该是 $\frac{3}{4}$，右边算完是 2。难道 $\frac{3}{4} > 2$ 吗？显然这是不成立的，对不对？所以 D 选项不对。

总结一下这类比较大小的单选题或者多选题怎么做：

第一，有些题目出得非常非常简单，可以直接利用我们刚才讲过的一些不等式的性质就能做。比如说你看 C 选项，两边乘东西不等号方向变不变，你得看这个东西是正数、还是负数、还是 0。

第二个方法，如果有的式子比较复杂，像第二题的 C 选项，我们可以对这个复杂式子进行化简，先化简完，然后再去看最终化简完的这个式子它对还是不对。如果你觉得化简过程太麻烦了，有些题目甚至化简都化简不了的，比如说 D 选项，题目出得非常刁钻，那我怎么办？我就代特殊值来去做。如果真的找到了一些特殊值使得它不成立，它就一定是不对的。

这是选择题的做法。当然有的时候在解答题里面，人家让你比较两堆值谁大谁小，这个时候我们怎么办呢？这也是小学内容，现在让你比较 $A$ 和 $B$ 谁大谁小，最简单、最不动脑的方法，那就是用两式做减法、做差。做差比较，如果大于 0，那很显然 $A$ 大；如果等于 0，那显然 $A$、$B$ 一样大；但是如果小于 0，那么就 $B$ 大。道理就是这个道理，非常简单。

不同题目难度不一样，不同点在哪？有的式子是简单的式子，有的式子是比较复杂的式子。这里面给大家举了三道题，为啥出这三道题？因为这三道题每道题都有大家需要注意的地方。

首先来看第一题。他不是让我比较这俩谁大谁小吗？那我第一步干吗呢？先做差。我让 $a^2 + b^2 - (4a - 2b - 5)$，看看正负，化简一下。这里面很显然有两个变量，一个是 $a$，一个是 $b$。想都能知道，肯定是 $a$ 和 $a^2$ 放在一起，$b$ 和 $b^2$ 放在一起，对不对？所以它就能化简成为 $a^2 - 4a + b^2 + 2b + 5$。做到这我不知道大家有没有想到什么，这个 $a^2 - 4a$ 好像缺了点东西，$b^2 + 2b$ 好像也缺了点东西，缺了什么呢？能凑成什么呢？好像能凑成完全平方式吧。$a^2 - 4a$ 加几才是完全平方式呢？得加 4。$b^2 + 2b$ 得加几呢？得加 1。然后我发现，加完这个 $4 + 1$ 正好凑成 5 了，上下完全一样，那我就凑成了两个完全平方式。前面是 $(a - 2)^2$，后面是 $(b + 1)^2$。想都不用想，这个值正的还是负的？肯定大于等于 0。大家学会了吗？关键是什么？第一步最关键的就是做差，做完差之后你去判断这个式子到底是正的还是负的。不同式子判断方法不一样，这道题用的是配方的方法凑完全平方式，换一道题那可能方法就不一样了。但是万变不离其宗，你得想方设法把这个式子变简单，怎么简单怎么来。

那我们来看第二题。这道题跟刚才的不同点在于，刚才没有根号，现在有好多好多根号。遇到这种情况我怎么处理呢？第一步大部分同学肯定还是得做差，两者做个差，第一个式子减去第二个式子。这个究竟是正还是负？那就得化简了，光瞪着眼睛在这看是看不出来的。怎么化简？人家都有分母了，你说咋化简？肯定咱就得通分，对不对？所以前两项咱先通通分，先看看是什么东西。通完分分母应该是 $\sqrt{ab}$，分子它俩乘加上它俩乘：$a\sqrt{a} + b\sqrt{b}$。再减去后面也是 $\sqrt{a} + \sqrt{b}$。有的同学做到这就不太会化简了，他觉得就做不了了。大家仔细来看一看，这什么？$a\sqrt{a}$，$a$ 本身就是 $(\sqrt{a})^2$，$a\sqrt{a}$ 那就相当于是 $(\sqrt{a})^3$；$b\sqrt{b}$ 那就是 $(\sqrt{b})^3$……

$\sqrt{b}$ 的立方呗。不知道这个大家还记不记得，这个立方和公式我们在初高衔接内容里面其实讲过，这是能进行因式分解的。公式是长这样的：
$$x^3 + y^3 = (x + y)(x^2 + y^2 - xy)$$

公式这个视频里面就不给大家再推一遍了，大家直接用。把 $x$ 代成 $\sqrt{a}$，$y$ 代成 $\sqrt{b}$ 来试一试。前面就是 $\sqrt{a} + \sqrt{b}$，后面是 $(\sqrt{a})^2 + (\sqrt{b})^2 - \sqrt{ab}$。把它代进来，这个分子就变成了一个大长串，分母不变，再减去后面的一串。

然后大家就会发现，在一开始你觉得这个式子根本就没法化简，但是你如果看出来它是一个立方和公式之后，这立方和因式分解完它会出现一个 $\sqrt{a} + \sqrt{b}$ 这一项。这一项出现两次，那它就能继续因式分解，咱们继续做。

把这个相同部分提出来，后面剩什么？第一项，那就剩这一部分，抄一遍。第二部分剩什么呢？提完之后剩了个 1，所以最后再减个 1 就行了。减 1 咱们能怎么样？减 1 这不是能继续通分吗？这个 1 我们可以写成 $\frac{\sqrt{ab}}{\sqrt{ab}}$。

最后化简，前面不动，后面这个分母是 $\sqrt{ab}$，分子是 $a + b - 2\sqrt{ab}$。不知道大家看到这个式子又能想到什么呢？$a$ 能写成 $(\sqrt{a})^2$，$b$ 能写成 $(\sqrt{b})^2$，再减去 $2\sqrt{a}\sqrt{b}$，这其实本身就是一个完全平方公式，它能写成 $(\sqrt{a} - \sqrt{b})^2$，对不对？

所以最后我们惊喜地发现，它能因式分解成一个非常简单的形式，分母不动，分子是 $(\sqrt{a} - \sqrt{b})^2$。很显然，人家说 $a, b$ 都是正数，所以这一项一定是正的，$\sqrt{ab}$ 肯定也是正的，$(\sqrt{a} - \sqrt{b})^2$ 是大于等于 0 的，所以最后我也发现它大于等于 0。

所以在道题的比较大小过程当中，第一步作差还是不变的，第二步化简的过程当中我们用了一个初高衔接里面讲的公式，叫立方和公式。

这两道题都是直接作差就能比较大小的题目。出题人觉得你直接作差也太弱智了吧，谁都知道作差，那怎么办？人家就出一道你作差没用的题。比如说像这道题，人家让证明这个东西，你会发现如果我们想着直接作差了把它移项的话，这式子里面有 $\sqrt{6}$，有 $\sqrt{7}$，有 $2\sqrt{2}$，有 $\sqrt{5}$，你做完差难道就能做了吗？是不是还是不能做呀？

所以如果你发现直接作差做不了，意味着大家在作差之前应该先变形，再作差。两边都是这么多根号，你说咱们会怎么变形？那就只能会两边平方呗。我们设它是 $A$，设这是 $B$。

很显然，$A, B$ 都是正数对不对？所以这道题我们只需比较两个正数的平方看看谁大就好了。首先我们来算一算 $A^2$ 是谁：
$$A^2 = (\sqrt{6} + \sqrt{7})^2$$
这玩意完全平方是 $6 + 7 = 13$，加上二倍两者乘积 $6 \times 7 = 42$。

我们再来算算 $B^2$ 是谁：
$$B^2 = (2\sqrt{2} + \sqrt{5})^2$$
它是 $8 + 5$——$8 + 5$ 好像也是 13 对不对？加上二倍根号下两者乘积，这个两者乘积就是 $2\sqrt{2} \times \sqrt{5}$。

所以最终我们比较的是谁？你别的都是一样的，我们只需要比较 $\sqrt{42}$ 和 $2\sqrt{2} \times \sqrt{5}$ 是谁。$2\sqrt{2} \times \sqrt{5}$ 就是 $2\sqrt{10}$。2 如果乘进去的话那就变成了 4，就是 $\sqrt{40}$。人家是 42，我是 40，谁大谁小很显然，那就是 $A^2 > B^2$。又因为 $A$ 和 $B$ 都是正数，所以综上发现 $A > B$，证明完毕。

我们讲了几道比较大小的问题，那么接下来有关不等式性质还有最后最后的一类小问题，就是已知不等式让你求一个新的表达式的取值范围问题。比如说你看，给你一个 $a$ 在 1 到 3 之间，给你一个 $b$ 在 2 到 4 之间，问你 $2a - b$ 的取值范围是多少。这道题说实话思路非常简捷。

它给我的是 $a$ 和 $b$ 的范围，结果问我的是 $2a - b$。我们首先一点一点来，我首先问 $2a$ 的范围是多少？$a$ 是 1 到 3 之间，那你说 $2a$ 在哪？$2a$ 不就在 2 到 6 之间吗，两边乘个 2。

人家又问减完 $b$ 怎么样，我不看减 $b$，我把它看成加 $-b$。我问大家 $-b$ 的取值范围是多少？那就把两边都加负号，对不对？两边加负号的话不要忘了，不等号的方向是要改变的。$-b$ 在 -2 到 -4 之间，那我写成正常的顺序的话就是 -4 是小的，-2 是大的，$-b$ 在 -4 到 -2 之间。

我写完这两个式子有什么用？大家有没有发现这两个式子是同向的，都是小于号。由同向的可加性，人家让我求的是 $2a + (-b)$，现在我想把 $2a$ 跟 $-b$ 加起来的话，新的取值范围我只需要把左边小的数加小的数，右边大的数加大的数不就行了吗？

所以最后答案，左边加左边，$2 + (-4)$ 是 -2；右边加右边，$6 + (-2)$ 是 4。它就在 -2 到 4 之间，轻松又愉快。

这道题简单的地方在哪？就在于人家给的条件，它就是单独的一个变量，以一个变量为中心、一个变量为个体给的两个不等式。所以我就把 $a$ 和 $b$ 当成两个基本元素，去凑人家让我求的 $2a - b$ 就好了，非常好凑。

但是，如果这道题给你套一个马甲，我现在不告诉你单独的 $a$ 和单独的 $b$ 是几，出题人给你的范围变成一个非常复杂的表达式，一个是 $4x - y$，一个是 $2x + y$，最后问你一个更复杂的表达式 $5x + y$，这个时候大家还会做吗？还像刚才那么简单吗？好像不是了哟。

但是我们应该能看得出来这两道题实际上本质的做题方法应该是一样的，就是由已知的两个数去凑第三个表达式，对不对？所以现在如果你说我能一眼看出来这个 $4x - y$ 和 $2x + y$ 怎么凑能凑出来 $5x + y$，好，那你厉害，我服你。但是大多数的宝贝应该是看不出来的吧。

刚才这道题第一题大家是不是会了？如果改成第二题怎么办嘞？我们就把第二题想办法变成第一题不就得了吗？虽然它给我的是一个表达式，但是没关系，我可以把它强行看成一个整体，看成一个基本元素，看成一个单项式 $m$。我设成 $m$，这个我设成什么呢？我设成 $t$，或者设成 $n$ 都可以。因此，这道题目虽然给……

给我的式 $x$ 和 $y$ 的一道题，但是我最后一定要把它变成一个基本元素有关 $m$ 和 $n$ 的一道新题就可以了呀。不信大家来看。

我把第一个式子设成了 $m$，第二个式子设成了 $n$。那我去解方程，把 $x, y$ 解出来。怎么解？这是初中初二的知识。两式相加，这个 $-y + y$ 就没有了，这边是 $6x$，$6x = m + n$，所以 $x$ 就应该是 $\frac{1}{6}(m + n)$。那 $y$ 是谁？把 $x$ 代进去，把 $y$ 解出来不就得了嘛。这边的 $y$ 应该是 $n - 2x$，其中 $x$ 是 $\frac{1}{6}(m + n)$。化简一下，我们就得到 $\frac{2}{3}n - \frac{1}{3}m$。这就是 $x, y$ 解完的结果。

那我们现在已经知道了 $x, y$ 怎么变成 $m$ 和 $n$ 了，那我们这道题我就不看 $x, y$ 了，现在我变成一道新的题。第一个，它给我的条件叫 $m$ 在 $-3$ 到 $3$ 之间，$n$ 在 $2$ 到 $9$ 之间。那现在它问我 $5x + y$ 的取值范围。我不喜欢 $x$，也不喜欢 $y$，我喜欢小 $m$ 和小 $n$，所以我直接把 $x, y$ 代进来。$x$ 是它，那就代进来变成 $\frac{5}{6}(m + n)$，然后再加上 $y$，$y$ 是 $\frac{2}{3}n - \frac{1}{3}m$。

就差一点点，这道题就大功告成了喽。$\frac{5}{6}m - \frac{1}{3}m$，$\frac{5}{6} - \frac{2}{6}$ 是 $\frac{3}{6}$，就是 $\frac{1}{2}m$。$\frac{5}{6}n$ 再加上 $\frac{2}{3}n$，$\frac{5}{6} + \frac{4}{6}$ 应该是 $\frac{9}{6}$，$\frac{9}{6}$ 就是 $\frac{3}{2}$。舒服了。

所以接下来我不再求 $5x + y$ 了，我其实就等价于求 $\frac{1}{2}m + \frac{3}{2}n$。前后虽然它的表达式变了，但是我们最后的答案是一模一样的，这只不过是一个整体代换的一个过程。通过这种代换，或者说大家以后会学习到，这个东西其实就叫换元。把一个复杂式子换成一个简单的变量，就叫换元。

通过这个换元的手段，我们发现，原来这第二题已经变成跟第一题一模一样的题目了吧。咱就去凑呗，凑一个 $\frac{1}{2}m$。$\frac{1}{2}m$，把第一个式子两边除以 $2$，那就得到了它大于等于 $-\frac{3}{2}$，小于等于 $\frac{3}{2}$。再把 $n$ 乘个 $\frac{3}{2}$，会得到 $\frac{3}{2}n$。两边的值，$2 \times \frac{3}{2}$ 是 $3$，$3 \times 9 = 27$。

所以最后答案，同向可加性，我们用 $\frac{1}{2}m + \frac{3}{2}n$，那左边加左边，右边加右边，分别得到最大值和最小值。最小值，$\frac{3}{2} + 3$ 应该等于 $\frac{3}{2}$；最大值，是 $\frac{3}{2} + \frac{27}{2} = \frac{30}{2} = 15$。大功告成。

以上就是这个视频的全部内容。我们讲了不等式的一些性质：加减乘除，同向两个式子的加法跟乘法，正数的乘方和开方运算，如何用作差的方法比较大小，还有最后已知不等式求取值范围的问题。完结，撒花！
