Hello everybody，我是神奇小朱。欢迎大家开始平面向量的学习。本期视频跟以往有所不同，今天的视频是平面向量二合一大放送。咱把两节课捏成一个视频，帮助大家一站式学习。大家可以根据自己的学习进度还有脑容量，随时暂停，随时学习。快点开始吧。

在学数学之前，今天咱先学点物理。在物理学里面有很多既有大小又有方向的量。比如说咱们非常熟悉的位移，我从心爱的家走到心爱的学校，位移这个物理量很显然它既有大小，我知道我走多少路，还有方向，我知道往哪走。这种有大小有方向的例子特别多。比如说咱分析斜面上一个小木块所受的力啦，这不同方向上的力，很可能大小也不一样。像这种既有大小又有方向的量，在物理里面我们叫矢量，但是在数学当中我们起了一个新名字，叫向量。因此大家如果想学好向量，就掌握两件事：第一，向量有大小；第二，向量有方向。

那知道向量是啥了，它怎么表示咧？第一个方法，咱画图来表示呗。咱画一个小箭头，这箭头既能表示出它的大小，它多长，又能表示出它往哪指，它的方向是多少。除了几何表示之外，我们还有代数的表示方法。因为咱总不能每次出现向量都画个图吧。第一种代数表示方法，咱由起点到终点给它写下来。它不是由 $A$ 开始到 $B$ 结束吗？咱在这上面加一个小箭头，这就表示 $\vec{AB}$ 这个向量了。那我如果是由 $C$ 起点走到 $D$ 咧？那我姥姥也会了，那就写成 $\vec{CD}$ 向量呗，简直不要太简单。注意哦，起点在前终点在后，别写反了。咱要是把 $\vec{AB}$ 写成 $\vec{BA}$ 了，那可出大事了，咱就由 $B$ 起点往 $A$ 指了。这俩向量长得一模不一样，方向完全相反，不是一回事啊。

这是第一个表示方法，咱把起点和终点连起来。接下来我们来讲第二种表示方法。咱可以把一个向量起个小名，这跟给小孩子起小名是一样的。你说咱有个孩子，每次叫他不能报身份证号吧，咱得给他起个张三、李四这样的小名。向量也一样，咱一般用小写字母表示一个向量，向量 $\vec{a}$、向量 $\vec{b}$。这是向量的第二种表示方法，小写字母加箭头。这里也有一点需要注意哦。这是我用手写出来的，叫手写体。咱手写体是加箭头的，但是还有另外一种书写方法，叫印刷体。啥意思呢？就大家在书上或者练习册上，它在表示向量的时候，人家可以把小写字母加粗加黑表示一个向量，人家不需要加箭头。这大家得认得，它表示 $\boldsymbol{a}, \boldsymbol{b}, \boldsymbol{c}$ 三个向量。当然大家也别淘气说：“啊，那写箭头太麻烦了，每次我也加粗，我也这么写，我加得粗粗的，用这表示向量行不行啊？”不行。咱用咱自己小手写出来的字必须得加箭头，别加粗，别整没用的。

好了，以上就是有关向量本身的一些基础概念。那我们这节课其实涉及到平面向量基础概念其实特别特别多，需要给大家仔仔细细地讲，所以今天我们会给大家做几个快乐小辨析，帮助大家彻底学懂平面向量。

首先问大家一句话，他说“若两个向量大小相等，那么这两个向量就相等”，对还是不对啊？大家可以把自己心目当中的答案打在屏幕上。3，2，1。我给大家画个图。人家这大小相等只是说这几个箭头长度一样，但方向是不是有可能不一样？那我们知道向量既看大小又看方向，你方向都不一样了，能说这几个向量是相等向量吗？显然不能嘛。因此接下来这个知识点大家一定要记好了。人家说或者你推出来两个向量相等，那有两层含义：第一，它的大小，或者说它这个向量箭头的长度是一样的；第二，人家指向的方向也必须完全相同。你看这图形里面这 $\vec{AB}$ 和 $\vec{CD}$ 人家都往上指，这就叫方向一样，我可以把它写成 $\vec{AB} = \vec{CD}$。

而且向量还有一个性质，它特别大胆。你看啊，这向量 $\vec{AB}$，我把它平移了，我把它往下平移，我平移的过程当中有没有改变它的大小和方向啊？是不是没有？我平移前、后两向量大小方向完全一样，前后就是同一个向量。这条向量的性质大家一定一定要记好了：向量可以随意平移。

比如我给大家举个例子吧。他说正六边形 $ABCDEF$ 中心是点 $O$，问哪个跟 $\vec{OA}$ 是相等的呀？我知道 $\vec{OA}$ 在这，你看，在这呢，$\vec{OA}$。它以 $O$ 为起点，$A$ 为终点。然后问我 A、B、C、D 哪个跟它相等，那我就看哪个大小方向都一样呗。首先，$\vec{DO}$ 我发现这大小方向好像的确都一样，那这 A 我赶紧选上。然后 B，$\vec{EO}$，在这呢，大小是一样，但是方向很显然不一样，B 不能选。C，$\vec{FO}$，那这方向也不一样。D，$\vec{CO}$，$\vec{CO}$ 往这指了，方向也不一样。这题出得太简单了啊，纯属逗我玩呢。

我们在讲后续内容之前，再给大家辨析几个小概念啊。向量第一节课嘛，概念课，稍微有点磨叽。这里有三个小概念，意思是比较类似的。第一，线段。这俩端点 $A$ 和 $B$ 有没有起点和终点的这个说法咧？是没有的。$A$ 和 $B$ 没有先来后到。你说线段 $AB$，或者说线段 $BA$，那是一回事。接下来我们来看平面向量。既有大小又有方向的量叫平面向量。比如说我画个平行四边形啊，你说 $\vec{AB}$ 向量跟 $\vec{BA}$ 向量是一个向量吗？不是。跟我们向量比较类似的一个概念在我们教材里面有，它叫有向线段。啥叫有向线段呢？教材给我们的解释是叫有方向的线段。这大家知道一下就行，因为考试考的概率不太大。在我们人教版教材里面，有向线段也用箭头来表示，有方向的啊，由起点到终点一个有向线段。那它究竟跟平面向量有什么区别和联系咧？它俩只有一个不同点，那就是平面向量可以平移。我把 $\vec{AB}$ 移到 $DC$ 上，$\vec{AB}$ 跟 $\vec{DC}$ 是同一个向量，向量可以平移嘛。但是有向线段不一样。有向线段它强调的是起点跟终点，这线段是固定的，定在这了，有向线段可不能平移啊。所以曾经考试考得比较刁的时候，它给你出道多选题，其中一个选项说“平面向量就是有向线段”，这句话对还是不对啊？大错特错。因为向量是活的，它可以平移，但是线段是固定死的，线段就在这，不能平移。

那这向量我们是不是学完了咧？不是哦，我们要对它的大小和方向进一步地深入学习。首先来看向量的大小。啥叫大小啊？就是长度呗。这向量有多长，就是它的大小。我们一般把这向量写出来之后，外边加一个类似于绝对值这符号。它长的是跟绝对值一模一样，但是我们读不读 $\vec{AB}$ 向量的绝对值？我们读的是 $\vec{AB}$ 向量的模长。这符号作为一个整体表示这线段的长度。比如说给大家举个例子，他问 $\vec{AB}$ 向量的模长是多少啊？那如果每格我都看成 1 的话，咋算呀？我姥姥都会，勾股定理呗。这 1，2，3，三格，这 1，2，3，4，四格，那直角边一个 3 一个 4，那斜边呢，就是 5。所以咱就写成 $|\vec{AB}| = 5$，太简单了。

那有两个特殊的常数是需要大家牢牢记住的：一个是 1，一个是 0。我们把模长为 1 的向量称作叫单位向量。我们一般情况下，使用小写字母 $\vec{e}$ 来表示。那我问宝贝们一件事情，单位向量只有一个吗？不一定哦。因为就像我一直给大家强调的一样，向量是有方向的。这四个长度虽然都可以是一，但是方向不一样嘛，所以咱可以记为单位向量 $\vec{e}_1, \vec{e}_2, \vec{e}_3, \vec{e}_4$，它们并不是同一个向量啊。

好了，那我们来看第二个向量。如果模长是 0 的话，这长度缩成 0 了，咱这画图就不太好表示了。我们把长度是 0 的向量起个名字叫零向量。记为一个大 0 上面加一个小箭头。注意哦，我们手写体是 0 加箭头表示零向量，印刷体它会把 0 加粗加黑。那就像咱刚才说的，大家手写的时候你加粗是没用的啊，手写要加箭头。那讲到这呢，聪明宝宝可能会有一个疑问啊：零向量它把长度缩成 0 了，那长度如果是 0 的话，你这点的方向在哪啊？零向量是不是没有方向呢？不是哦。我们规定零向量是有方向的，它的方向是任意的。你不能说人家没有方向啊，它有方向，方向任意，你说它指向哪都行。

我们讲完了向量的大小，向量的模长。第二个重要内容：向量的方向。

这方向说实话，小学就开始学。你说给你俩向量，会有啥关系？要么 1、2，俩方向垂直，叫垂直向量呗。要么呢，平行，叫平行向量呗。要么这俩向量既不垂直又不平行，是吧，这没啥难的对吧？那我们详细来讲一讲啊。首先第一个，垂直怎么记呢？我不讲大家也会，$\vec{a} \perp \vec{b}$，太轻松了。这里面最难的是这个平行。平行其实有两种情况：第一，你看 $\vec{a}, \vec{b}$ 方向都指向右边，它俩方向相同，这叫平行啊，我记为 $\vec{a} \parallel \vec{b}$。那还有另外一种平行，我方向相反，你就说平行不吧？是不是的确是平行的？所以 $\vec{a}, \vec{b}, \vec{c}$ 其实三个向量相互平行。所以如果考试真的问两个向量平行，它俩方向一定相同吗？不一定，有可能方向正好是相反的。

解释到这还没完。你看啊，这呢有一个向量 $\vec{c}$，我们知道啊，向量是可以平移的耶。我把 $\vec{c}$ 画在这，你确能说这个 $\vec{a}$ 跟 $\vec{c}$ 是平行的，那如果我把 $\vec{c}$ 正正好平移了啊，我把它移到跟 $\vec{a}$ 共线的位置，平移的过程当中性质有发生改变没啊？没有啊。所以即便 $\vec{a}$ 和 $\vec{c}$ 现在共线了，我们也叫它俩是平行向量。所以平行向量有另外一个名字，是完全等价的名字，叫共线向量。这说的其实就是一回事，平行跟共线在我们向量里面完全等价。所以有的时候就会发生一些比较诡异的事情。大家用眼睛看的时候啊，你看这 $\vec{a}$ 向量、$\vec{b}$ 向量平不平行啊？平行。那如果换一个说法说 $\vec{a}$ 向量跟 $\vec{b}$ 向量它俩共线，对还是不对啊？对。虽然人家不在同一条直线上，但是它可以平移到一条直线上云。共线就是平行，平行就是共线。是不是挺好玩的？咱初中学习直线的时候怎么说的呀？有两条直线，这叫平行，这叫共线。你俩线都平行了就不可能共线，共线呢就不叫平行。初中的时候我们认为它俩不是一回事，没错啊。但是我们在高中仅限于平面向量这个模块，向量的平行就等价于向量的共线。希望我给大家解释清楚了。

那有关平行向量呢还有一件事，这平行向量的幺蛾子特别多。我们规定：零向量与任意向量都是平行的。漏少写个“与”。你别问为啥，这是我们规定的。记为 $\vec{0} \parallel \vec{a}$，不管 $\vec{a}$ 向量长啥样，总平行。终于讲完了。

那给大家来一个今天的第二个快乐小辨析。大家来想一想，我写向量 $\vec{a} = \vec{b}$，跟把它们俩都加个类似于绝对值这个，这俩式子有没有区别啊？有。$\vec{a} = \vec{b}$ 意思是说俩向量完全相等，大小、方向都一样，长度得一样，方向还一样，这才是 $\vec{a} = \vec{b}$。但如果加了绝对值，表示模长相等，我只关心长度。那我在画图的时候，那可就自由随意多了。只要我画的两线段长度一样就行，咱对它方向没要求。所以有的时候有的题目的一部分它给你这些式子，你得知道是啥意思，图别画错了。

知识点已经讲完了，那我相信很多宝贝肯定跃跃欲试了，来开始做题吧！

给大家准备了一道抢答题，大家可以把心目当中的答案打在屏幕上。给了以下四个说法啊，正确的个数是 0 个、1 个、2 个还是 3 个咧？给大家 5 秒钟思考时间。

正确答案是——哎，我先不说。

首先第一个，说单位向量都相等，对吗？我们知道单位向量是有无数个的，虽然它们的大小都是 1，但是方向有可能不一样。这相等既得大小一样，方向也得一样才行啊。所以第一个说法其实并不对啊。

第二个，他说零向量与任意向量是平行的，这句话说得对不对？对，这是规定。所以他说“因此零向量没有规定方向”，第二句话错了。我们明明规定零向量方向是任意的，向量怎么可能没有方向呢，对不对？所以第二个也不对。

第三个，平面直角坐标系上的 x 轴、y 轴都是向量。这说得有点意思啊，我画个平面直角坐标系，好玩啊。我发现这 x 轴吧、y 轴，的确都是一个箭头对不对？那它是向量吗？它不是向量。我问你它的长度是多少啊？x 轴是无限长的，这向量没有大小。它光有方向是没用的，那大小确定不了，所以它并不是向量。

最后一个，也是这里面最坑的。我不讲的话肯定好多同学都会选错。你看啊，$\vec{a} \parallel \vec{b}$，$\vec{b} \parallel \vec{c}$，则 $\vec{a}, \vec{c}$ 一定平行。这句话在说啥呢？好像平行之间具有传递性嘛，小学就学过，那它对不对呢？这也不对。因为在平行或者共线里面我们是不是讲过一个特例啊？咱是不是说过零向量与任何一个向量都是平行的，对不对？所以大家想，这 $\vec{b}$ 向量作为 $\vec{a}, \vec{c}$ 的连接，如果 $\vec{b}$ 向量是零向量会发生什么？我画个图。一个 $\vec{a}$，一个 $\vec{c}$，我再点了个点表示零向量，表示 $\vec{b}$ 向量。你看，它俩平行不？平行。它俩平行不？平行。但是 $\vec{a}, \vec{c}$ 平行不？不平行。这就是特例，他说得不对。

所以正确答案选 A，四个说法全错。大家做对了吗？

以上就是我们有关平面向量的基础概念。那后续内容我们会讲点什么咧？咱会讲多个向量之间的运算。完结，撒花！

[听音转录 · P70 平面向量】2向量的加减数乘运算（易）]
> 来源：**听音转录**——非平台字幕，由讲师原声转录

向量一共我们在高中阶段会接触四种运算，我们这个视频先给大家讲其中三个线性运算，分别是加法、减法跟数乘，一个一个一个讲。咱首先来看向量的加法。

在好几千年前，亚里士多德就知道两个力的组合作用可以用一个平行四边形法则得到。我把它翻成人话，放在一个情境里，大家来体会一下。

咱们的故事发生在17和18世纪的美洲。从前有两个人，一个叫小帅，一个叫小壮，在美国中东庄园里拉石头。两人一起拉，一个往这边拉，一个往这边拉。那你说最后这石头往哪走嘞？这石头有可能往这边走吗？绝无可能。它肯定往大致这个方向走，对不对？

那具体这方向怎么确定的？就是由这两个力、这两个向量所形成的平行四边形决定的。以它俩为平行四边形的两边，那对角线就是这石头走的方向。换句话说，这两个力所作用的效果最终就相当于、等价于这一个力在这石块上的作用。也就是说，这两个向量的和就等于这一个向量。这就是向量的加法，也被称之谓叫平行四边形法则。

$\vec{a} + \vec{b}$ 怎么做呀？再做一遍，咱先偷偷画个平行四边形，然后把对角线连起来，这就是 $\vec{a} + \vec{b}$。会画了吧？平行四边形法则什么时候用啊？用眼睛看呗。你看 $\vec{a}$ 和 $\vec{b}$ 俩向量啥关系？它是不是由一个起点出发的？$\vec{a}$ 和 $\vec{b}$ 得共起点的时候，咱们才能用。

那有的时候俩向量并不共起点啊。比如说你看这俩向量，$\vec{a}$、$\vec{b}$，人家是首尾相接的，$\vec{a}$ 向量的终点正好是 $\vec{b}$ 向量的起点。那这个时候我们还有另外一个法则，叫三角形法则。如果俩向量首尾相接了，那它俩的和就是由最开始的起点直接连接最后的终点，长这样的。

那有同学不服，说为啥呀？你看呢，三角形跟平行四边形是一回事。我如果把 $\vec{b}$ 向量往上平移，往上平移，我平移到这来，现在这是 $\vec{b}$ 向量。可不可以平移？可以啊，那向量是来回平移的。所以你自己看嘛，那你说是 $\vec{a}$ 向量加 $\vec{b}$ 向量，是不是最后效果就是由第一开始的起点到最后的终点连起来呀？所以说实话，这俩法则是同一件事情。只不过共起点的时候，咱用平行四边形法则；首尾相接的时候，咱用三角形法则而已。

$$1 - 2 \times \left(\frac{\sqrt{5}-1}{4}\right)^2 = 1 - 2 \times \frac{5 + 1 - 2\sqrt{5}}{16} = 1 - \frac{6 - 2\sqrt{5}}{8} = 1 - \frac{3 - \sqrt{5}}{4} = \frac{4 - 3 + \sqrt{5}}{4} = \frac{1 + \sqrt{5}}{4}$$
D选项说得没错，太舒服了。
