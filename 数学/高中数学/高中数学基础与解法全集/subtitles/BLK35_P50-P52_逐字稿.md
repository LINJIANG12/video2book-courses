那关键是啥呀？咱只要把其中任何一段它的取值范围找到是不是行了呀？首先左端点，咱把图放大，这值是几？相当于问大家 $\tan$ 的多少度是 $1$？$\tan 45^\circ$ 是 $1$，$45^\circ$ 其实就是 $\frac{\pi}{4}$ 嘛。右端点它无限往上走是不是？所以它就无限趋近于渐近线了吧？渐近线是多少来着？应该是 $\frac{\pi}{2}$ 啊。所以其中一段我就直接写出来了，是 $\frac{\pi}{4}$ 到 $\frac{\pi}{2}$ 之内。

写完一段怎么写别的段？咱把它简单地往右平移 $\pi$，往左平移 $\pi$，平移 $\pi$、平移 $2\pi$、平移 $-\pi$、平移 $-2\pi$，平移整数倍的 $\pi$，在原来的基础上都加 $k\pi$ 就行了。所以谁是答案？只能选 D。

又是具有周期性函数的看图说话。有周期性我不怕，我先把一段画出来，然后再把它直接平移、平移、平移就可以了。找其中一段，再找不同段之间的距离，就能完美完成任务。

接下来再来，它问我一个新函数，这新函数取个绝对值它问我周期是多少？小笨蛋，这我看到看出来了。怎么叫取绝对值啊？上方的图形不动，下方图形原本是这么画，我把它翻上来呗。所以相当于问我这一个一个的小 U 字形它的周期是多少。这周期，我把它往右平移再往右平移，这周期你看最低点，最低点是什么？是在这个点，往右平移到这个点，最低点之间距离多少啊？从这到这，这是 $0$，这是 $-\frac{\pi}{2}$，这应该是 $-\pi$。距离我这么一算它是 $\pi$。那这段距离就是周期，所以直接选 B。

做了这么多的题，说白了就干一件事，就是画图。图像是解决几乎所有函数问题的最核心方法。这函数只要能画图，无论是难题还是简单题都是看图说话。那有关三角函数综合难题，我们将在未来给大家详细讲解。完结撒花！

Hello everybody，我是神级小猪。有关三角函数，我们已经出了很多期视频了。今天我们稍作休息，在讲更难的问题之前，把前半部分三角函数的一些大家可能并不太熟练，甚至连听都没听过的解题技巧，帮助大家查缺补漏，教几个必备的做题妙招，绝对能让大家开开眼。废话不多说，我们正式开始。

首先，我们来介绍一个有关同角三角函数的常用技巧。我们直接以一道高考题为例。很多同学一看，题目告诉我们：
$$\cos\alpha + 2\sin\alpha = -\sqrt{5}$$
一个方程里面有两个未知数，$\sin\alpha$ 和 $\cos\alpha$ 均未知。常规思路通常利用：
$$\sin^2\alpha + \cos^2\alpha = 1$$
两个未知数、两个方程联立求解。比如直接把第一个式子代入第二个式子中，把 $\cos\alpha$ 写成 $-\sqrt{5} - 2\sin\alpha$，然后建立一个关于 $\sin\alpha$ 的一元二次方程。这个方程虽然能解，但由于出题人即使再善良，化简后的方程系数如果较为复杂，利用求根公式：
$$\sin\alpha = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$
求解依然会特别麻烦。很多情况下，一元二次方程的判别式 $\Delta$ 非常难算。

所以今天给大家介绍一个全新的方法，叫做对偶式。什么时候使用？当题目中出现条件形如若干倍的 $\sin$ 加上若干倍的 $\cos$ 等于一个常数时，就可以大胆利用对偶式。

具体操作方法如下：已知条件为 $\cos\alpha + 2\sin\alpha = -\sqrt{5}$。构造对偶式时，将式子中的 $\cos$ 换成 $\sin$，$\sin$ 换成 $\cos$，中间的正号变成负号，新得到的式子即为原式的对偶式：
$$\sin\alpha - 2\cos\alpha = x$$
假如我们能够求出该式的值 $x$，原式与对偶式就构成了一个二元一次方程组，其求解难度远低于二元二次方程组。

那么对偶式的值该如何求解？推导过程如下：
将两式分别左右两边平方。第一个式子展开为：
$$\cos^2\alpha + 4\sin^2\alpha + 4\sin\alpha\cos\alpha = 5$$
第二个式子平方展开为：
$$\sin^2\alpha + 4\cos^2\alpha - 4\sin\alpha\cos\alpha = x^2$$
将两式相加：
$$(\cos^2\alpha + \sin^2\alpha) + 4(\sin^2\alpha + \cos^2\alpha) = 5 + x^2$$
即：
$$1 + 4 = 5 + x^2$$
$$5 = 5 + x^2$$
解得：
$$x = 0$$

既然 $x = 0$，即 $\sin\alpha - 2\cos\alpha = 0$，移项可得：
$$\sin\alpha = 2\cos\alpha$$
两边同除以 $\cos\alpha$，即得：
$$\tan\alpha = 2$$

对偶式的一般形式如下：
若已知条件为：
$$a\sin\alpha + b\cos\alpha = c$$
构造其对偶式：
$$a\cos\alpha - b\sin\alpha = x$$
（对偶规则：$\sin$ 与 $\cos$ 互换，中间符号由加变减；若原式为减，则变为加）。
将两式分别平方后相加，交叉项 $\pm 2ab\sin\alpha\cos\alpha$ 刚好抵消，左边利用同角三角函数平方和公式化简，直接得出核心结论：
$$a^2 + b^2 = c^2 + x^2$$
即两个系数的平方和等于等号右侧常数的平方和。通过该公式快速求出 $x$ 后，再解二元一次方程组，即可求出 $\sin\alpha$ 和 $\cos\alpha$ 的值。

我们再来看一道进阶题目：已知 $\sin\alpha + 2\cos\alpha = \frac{2}{5}$，且 $\alpha \in (\frac{\pi}{2}, \pi)$，求 $\sin\alpha\cos\alpha$ 的值。
如果用常规方法代入 $\sin^2\alpha + \cos^2\alpha = 1$，展开化简后会得到带分数的复杂一元二次方程：
$$5\cos^2\alpha - \frac{8}{5}\cos\alpha - \frac{21}{25} = 0$$
计算判别式非常繁琐。

改用对偶式：
设对偶式为：
$$\cos\alpha - 2\sin\alpha = x$$
直接利用结论 $a^2 + b^2 = c^2 + x^2$：
$$1^2 + 2^2 = \left(\frac{2}{5}\right)^2 + x^2$$
$$5 = \frac{4}{25} + x^2$$
$$x^2 = \frac{121}{25}$$
$$x = \pm \frac{11}{5}$$

接下来分情况联立二元一次方程组：
第一种情况，当 $x = \frac{11}{5}$ 时：
$$\begin{cases} \sin\alpha + 2\cos\alpha = \frac{2}{5} \\ \cos\alpha - 2\sin\alpha = \frac{11}{5} \end{cases}$$
将第一式两边乘 2 与第二式相加消去 $\sin\alpha$：
$$5\cos\alpha = 2 \times \frac{2}{5} + \frac{11}{5} = \frac{15}{5} = 3 \implies \cos\alpha = \frac{3}{5}$$
代入得 $\sin\alpha = -\frac{4}{5}$。

第二种情况，当 $x = -\frac{11}{5}$ 时：
同样将第一式乘 2 与第二式相加：
$$5\cos\alpha = \frac{4}{5} - \frac{11}{5} = -\frac{7}{5} \implies \cos\alpha = -\frac{7}{25}$$
代入求得 $\sin\alpha = \frac{24}{25}$。

根据已知条件，$\alpha \in (\frac{\pi}{2}, \pi)$，即 $\alpha$ 为第二象限角。第二象限角的横坐标 $\cos\alpha < 0$，纵坐标 $\sin\alpha > 0$。因此第一组解不符，舍去；第二组解成立。
由此求得：
$$\sin\alpha\cos\alpha = \left(\frac{24}{25}\right) \times \left(-\frac{7}{25}\right) = -\frac{168}{625}$$

接下来看第二个技巧：巧用三角函数定义。
三角函数的定义是角的终边与单位圆交点的坐标：纵坐标为 $\sin\alpha$，横坐标为 $\cos\alpha$，纵坐标比横坐标为 $\tan\alpha$。当题目给出较复杂的三角函数大小比较时，将其转化为单位圆上的坐标关系求解往往更加直观。

以一道高考真题为例：在平面直角坐标系中，单位圆上有四条实线圆弧 $AB, CD, EF, GH$。点 $P$ 在这四段圆弧中的一段上，满足：
$$\tan\alpha < \cos\alpha < \sin\alpha$$
判断点 $P$ 落在哪个圆弧上。

利用单位圆定义，设点 $P$ 的坐标为 $(x, y)$，则 $\cos\alpha = x$，$\sin\alpha = y$，$\tan\alpha = \frac{y}{x}$。不等式转化为：
$$\frac{y}{x} < x < y$$
拆分为两个不等式分析：
首先看 $y > x$：在平面直角坐标系中，直线 $y = x$ 是第一、三象限的角平分线。$y > x$ 表示点在直线 $y = x$ 的上方区域。仅凭此条件即可排除弧 $AB$。

再看另一个不等式 $\frac{y}{x} < x$。由于不等式两边同乘 $x$ 需考虑符号，因此分情况讨论：
1. 当 $x > 0$ 时，两边同乘 $x$ 不等号不变，得 $y < x^2$。抛物线 $y = x^2$ 开口向上且经过点 $(1, 1)$。在第一象限（$x > 0$）内，$y < x^2$ 表示位于抛物线下方。此时弧 $CD$ 并不在抛物线下方，故排除。
2. 当 $x < 0$ 时，两边同乘 $x$ 不等号改变方向，得 $y > x^2$。在第二象限（$x < 0$）内，要求点落在抛物线 $y = x^2$ 的上方区域。观察可知圆弧 $EF$ 完全满足在 $y = x$ 上方且在 $y = x^2$ 上方。
因此正确选项为 C。

再来看诱导公式与三角形相关的性质。
已知 $\triangle ABC$ 为锐角三角形，判断下列结论的正确性：
A. $\sin(B + C) = \sin A$
B. $\sin\frac{A+B}{2} = \cos\frac{C}{2}$
C. $\sin B < \cos A$
D. $\tan A \tan B > 1$

分析 A 选项：在三角形中，$A + B + C = \pi$，故 $B + C = \pi - A$。
$$\sin(B + C) = \sin(\pi - A) = \sin A$$
故 A 正确。

分析 B 选项：$A + B = \pi - C$，两边除以 2 得 $\frac{A+B}{2} = \frac{\pi}{2} - \frac{C}{2}$。
$$\sin\left(\frac{A+B}{2}\right) = \sin\left(\frac{\pi}{2} - \frac{C}{2}\right) = \cos\frac{C}{2}$$
“奇变偶不变，符号看象限”，由于 $\frac{C}{2}$ 为锐角，符号为正，故 B 正确。

分析 C 选项与 D 选项：这里涉及锐角三角形的一个重要二级结论：
在锐角三角形中，任意一个角的正弦值一定大于另一个角的余弦值，即：
$$\sin A > \cos B, \quad \sin B > \cos A, \quad \sin A > \cos C, \dots$$
推导过程如下：
在锐角三角形中，$A, B, C \in (0, \frac{\pi}{2})$。
因为 $C < \frac{\pi}{2}$，且 $C = \pi - (A + B)$，所以：
$$\pi - (A + B) < \frac{\pi}{2} \implies A + B > \frac{\pi}{2} \implies A > \frac{\pi}{2} - B$$
因为 $A$ 与 $\frac{\pi}{2} - B$ 均在区间 $(0, \frac{\pi}{2})$ 内，而正弦函数 $y = \sin x$ 在该区间单调递增，两边同时取正弦保持不等号方向不变：
$$\sin A > \sin\left(\frac{\pi}{2} - B\right)$$
利用诱导公式 $\sin(\frac{\pi}{2} - B) = \cos B$，即证：
$$\sin A > \cos B$$
同理可得 $\sin B > \cos A$。
因此 C 选项表述的 $\sin B < \cos A$ 错误。

对于 D 选项：
$$\tan A \tan B = \frac{\sin A}{\cos A} \cdot \frac{\sin B}{\cos B} = \frac{\sin A}{\cos B} \cdot \frac{\sin B}{\cos A}$$
因为是锐角三角形，正弦与余弦值均为正数。由上述结论可知：
$$\frac{\sin A}{\cos B} > 1 \quad \text{且} \quad \frac{\sin B}{\cos A} > 1$$
两个大于 1 的正数相乘必然大于 1，因此 $\tan A \tan B > 1$ 恒成立，D 选项正确。

最后看三角函数的图象变换技巧，以函数 $y = \sin|x| + |\sin x|$ 为例分析性质。
对于复合绝对值函数的作图：
1. 画 $y = \sin|x|$：保留 $y$ 轴右侧的图象不变，再将其沿 $y$ 轴对称翻折到左侧，得到一个偶函数图象。
2. 画 $y = |\sin x|$：将 $x$ 轴下方的负半部分图象直接沿 $x$ 轴翻折到上方，成为一系列向上的波峰。

两图象逐段叠加相加：
在 $[0, \pi]$ 上，两个均为向上的半波，叠加后波峰高度由 1 变为 2；
在 $[\pi, 2\pi]$ 上，$\sin|x|$ 为负半波，$|\sin x|$ 为正半波，两者大小相等、符号相反，相加完全抵消，函数值恒等于 0。
同理在负半轴由于对称性进行周期性叠加。

由此图象可直观判断：
- 函数为偶函数，关于 $y$ 轴对称；
- 在区间 $[\frac{\pi}{2}, \pi]$ 上单调递减；
- 在 $[-\pi, \pi]$ 上与 $x$ 轴有 3 个交点（零点）；
- 函数值域为 $[0, 2]$。
