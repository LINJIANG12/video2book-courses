上节课我们讲了直线和圆的位置关系，一共有三种：要么相交，要么相切，或者离老远相离。

今天我们来研究两个圆之间，圆和圆有什么位置关系。

现在只给大家画了一个圆，我再画一个。目前你看，它们离得好远好远，没发生关系，这是一种情况。那我稍微近一近，在外面贴贴了，贴上去了，这也是一种情况。那我再让它再近一点，出现两个交点相交了，这也是一种。那我继续进，相交交交，两个圆在里面贴贴了。然后我继续远，贴贴又跑出去了。

所以大家发现没，随着两个圆的相对位置的变化，它们的关系也在发生变化。总结下来，两个圆之间一共有五种位置关系。

第一种，外离。两个圆之间离得好远好远，没有任何交点。稍微近一点，外切，两个圆在外部进行一个贴贴，有一个交点。两个圆心之间再近一点，它就有两个交点了，这个叫相交，挺好理解的。那如果我再近呢？大家来观察，蓝色这个圆贴到里面去，它也能产生一个交点。这种情况它也相切了，但是我们称作内切。所以圆和圆之间的相切有两种相切：一种叫外切，一种叫内切，这大家应该能区分得出来。

当然还有另外一种情况，当两个圆一大一小的时候，小的在里面，大的在外面，这个叫内含。所以外离跟内含是两个极端情况，它们都能保证两个圆之间没有交点。

这是我在图形上给大家展现两个圆的位置关系。那我如果从代数的角度，能不能通过算术把两个圆的位置关系算出来呢？完全可以。

究竟是哪几个量在影响圆和圆的位置关系？一个圆就两个参数：一个叫圆心，一个叫半径。所以判断位置关系我们也从这两点来看：
第一，你看两个圆的圆心之间的距离，我们称之为圆心距 $d$ 是多少；
第二，你再来看 $r_1$、$r_2$ 分别是多少。

那在每种情况下，这五种情况中，$r_1$、$r_2$、$d$ 究竟有啥关系呢？

咱先从两个极限情况、好分析的来分析，就相切的时候。外切是一个怎么样的情况？大家有没有发现，圆心距正好和 $r_1$ 还有 $r_2$ 的和是相等的，即：
$$r_1 + r_2 = d$$
这是外切的情况。

那内切是个什么情况？两个圆的圆心距之间怎么算？这条线段好短好短，跟 $r_1$、$r_2$ 有啥关系呢？谁是 $r_1$？$r_1$ 是红色圆的半径，它可以这么长。谁是 $r_2$？$r_2$ 是蓝色圆的半径，它可以移动到这里。所以我发现，红色圆的半径减去蓝色圆的半径正好等于中间这一点点，对不对？红色圆的半径减去蓝色圆的半径，正正好等于中间的圆心距。长的减短的等于这一段，没问题。所以内切的时候就是圆心距等于两个圆之间半径之差：
$$d = |r_1 - r_2|$$
如果不知道 $r_1$、$r_2$ 谁大的情况下，我就加个绝对值，比较严谨。

我已经把两种极限情况下 $d$ 还有 $r_1$、$r_2$ 之间的关系找到了。那其他的三种情况你肯定也会了。$d = r_1 + r_2$ 的时候是外切的，那啥时候外离？圆心距是不是得比临界情况更远、更大？你看，这个 $d$ 应该比 $r_1 + r_2$ 要大：
$$d > r_1 + r_2$$
这时候咱就叫外离。

那什么时候相交呢？$d = r_1 + r_2$ 的时候是外切，$d = |r_1 - r_2|$ 的时候是内切。相交应该处于外切跟内切之间的一个情况，所以我只要保证圆心距 $d$ 比 $r_1 + r_2$ 要近，但是要比 $|r_1 - r_2|$ 要远：
$$|r_1 - r_2| < d < r_1 + r_2$$
这个时候它就相交了。

最后，啥时候是内含呢？比内切的情况再近一点、再小一点：
$$d < |r_1 - r_2|$$
这就是内含。

这么多式子你用记吗？我从来不记。咱记住两个中间相切的极限情况，另外三个不就也好记了吗？

所以总结一句话：想看圆和圆的位置关系，你先算两个圆之间的圆心距 $d$ 是多少。咋算圆心距？圆心肯定是知道的，两点间距离公式是不是就可以了？然后把 $r_1$、$r_2$ 找到，看这三者之间到底啥关系就好了。

废话缩太多了，咱直接牛刀小试。

给两个圆，太好心了，都给的标准形式，那圆心、半径都知道。
第一个圆：注意是 $(-2, 0)$，半径 $r^2 = 4$，那 $r_1$ 就应该是 $2$。
第二个圆：圆心 $(2, 1)$，$r_2^2 = 9$，那 $r_2$ 就是 $3$。

$r_1$、$r_2$ 找到了，咋算圆心距？两点间距离公式，图都不用画：
$$d = \sqrt{(-2 - 2)^2 + (0 - 1)^2} = \sqrt{(-4)^2 + (-1)^2} = \sqrt{17}$$

然后接下来怎么办？大家在脑中就想那五种位置关系，从外离到内含，咱重点抓住两个相切的极限情况。
啥时候外切？当圆心距等于 $r_1 + r_2$，$d = 5$ 的时候外切。
啥时候内切？当这两个半径相减，$|2 - 3| = 1$，$d = 1$ 的时候它是内切。
那我来看看，$\sqrt{17}$ 是处在 $1$ 到 $5$ 之间，还是小于 $1$，还是大于 $5$ 呢？
咱知道 $5$ 是 $\sqrt{25}$，$\sqrt{17}$ 显然正好在 $1$ 到 $5$ 之间吧。其实就类似于你脑中有一个数轴，卡在 $1$ 和 $5$ 之间这三个区域你选一个，它在中间，那对应的情况就是相交，选 B。

那如果我换一道题，算完有个 $d$ 是 $8$。我也好判断，用 $8$ 跟 $1$ 和 $5$ 比较，看落在哪个部分。$8$ 显然比 $5$ 还大，所以在数轴上它应该处在这个位置，对应的情况应该是外离，多简单。

再来，2014年湖南高考。
有个圆 $x^2 + y^2 = 1$，不用说，圆心是 $(0, 0)$，半径是 $1$。
第二个圆它是一般形式，挺损的，我得先化成标准形式。$x$ 两项提出来 $x^2 - 6x$，先加 $9$；加上 $y$ 两项 $y^2 - 8y$，这里得加 $16$。等于这一边是 $25$，原来是 $m$，所以相当于我加上了一个 $25 - m$。
化简：
$$(x - 3)^2 + (y - 4)^2 = 25 - m$$
所以第二个圆的圆心应该是 $(3, 4)$，半径 $r_2$ 别看错了，应该是 $\sqrt{25 - m}$。

看它说什么，它说外切。什么时候外切来着？脑中想图，外切的话 $d$ 应该正好等于 $r_1 + r_2$。
圆心距我还没算，但是口算也能算出来了：
$$d = \sqrt{(3 - 0)^2 + (4 - 0)^2} = \sqrt{3^2 + 4^2} = 5$$
$$d = r_1 + r_2 \implies 5 = 1 + \sqrt{25 - m}$$
变成了有关 $m$ 的方程。移过来根号等于 $4$，根号等于 $4$ 的话：
$$25 - m = 16 \implies m = 9$$
选 C，完美。

以上就是咱今天讲的第一种题型，是不是还挺好理解的。圆和圆之间一共五种位置关系，你重点抓住两种相切的情况：一个是 $r_1 + r_2$，一个内切是 $|r_1 - r_2|$。外切圆心距比较大，内切圆心距比较小。然后咱只需要算出来真正的圆心距 $d$ 是多少，看看比大的数大，还是比小的数小，还是落在两者之间，对应的三种情况你就找到了。

这题太简单，稍微来点新型的。现在人家不讨论圆的位置关系是什么，人家问两个圆之间的公切线。

两圆的公切线问题，啥叫公切线？就是你要找到一条直线，既跟第一个圆相切，又跟第二个圆相切。
对于第一种外离的情况，公切线只有这么一条吗？不一定，我对称着下边是不是也能画出来一条？就这两条吗？大家来想想有没有其他情况？怎么能跟两圆都相切？我可否在中间这样切完又这样切？这也可以。或者我从下往上切，也可以。
所以如果两个圆距离比较远、是外离的情况下，公切线应该有一、二、三、四，一共四条。
这四条公切线由对称性可知，一定是关于两个圆心相连的这条线上下对称的。两圆圆心一连完就是对称轴对不对？初中数学不用我讲，你上面有一条，下面对应对称的也有一条；左边有一条，对称过来右边也有一条，一共四条。

讲完这个，那其他四种情况都有几种公切线呢？
比如外切的情况，在它上下肯定能找到两条：一条，两条。还有没有别的？咱过中间这个切点是不是还能找到这样的一条，使得两圆都跟它相切？所以外切的时候应该有一、二、三，有三条。
那相交的时候呢？中间这并不是切线，只能找到上面一条还有下面一条，共两条。
第四个，如果是内切呢？内切的时候咱在里面是找不到公切线的，好像只有在这个切点能找到一条公切线，对不对？
最后内含，一个在里面一个在外面，有可能找到公切线吗？绝无可能，是零条。

所以大家发现没，不同的圆和圆的位置关系，它对应的公切线条数完全不一样：
外离有 4 条，外切有 3 条，相交有 2 条，内切有 1 条，内含没有公切线。

笨的题怎么考？先给你或者你判断完圆和圆的位置关系之后，问你公切线有几条。你直接看图或者背下来就行了，公切线条数跟它的位置关系是完完全全可以一一对应的。

损一点，人家反过来考。比如突击检查，已知有两个圆 $C_1$ 和 $C_2$ 有三条公切线，这句话怎么翻译，什么意思？
三条公切线对应只有一种情况，那就是两圆得外切，懂了吧。

它心挺善的，给了两个圆，问我公切线有且仅有多少条。问我公切线有几条就相当于在问我这两个圆的位置关系是怎么样的。
刚才那套路再做一遍。第一个圆写成标准形式，第二个圆也写成标准形式。
第一个圆圆心应该是 $(-1, -1)$，半径应该是 $2$。
第二个圆化简完应该是：
$$(x - 2)^2 + (y - 1)^2 = 4$$
圆心 $(2, 1)$，半径是 $2$。

判断两圆位置关系，脑中想图。
我先算 $r_1 + r_2$，这时候两圆是外切的，$r_1 + r_2 = 4$。
然后我再算 $|r_1 - r_2|$，差是 $0$。
那我来算一算真正的 $d$ 是多少：
$$d = \sqrt{(2 - (-1))^2 + (1 - (-1))^2} = \sqrt{3^2 + 2^2} = \sqrt{13}$$
咱知道 $4$ 是 $\sqrt{16}$，所以显然 $\sqrt{13}$ 应该正好夹在两种情况之间。所以由内切到外切的话，那中间情况就应该是相交了。相交的公切线一条、两条，没有第三条，答案选 B，看懂了吧。

这种判断两个圆公切线有几条的类型题，我相信大家已经会了。但是我现在的再损一点：我给大家两个圆之后，我让大家把它的公切线真正的方程求出来。不让你判断条数了，直接给我求。

咱咋做？大家记住，叫数形结合。

大家可千万别小看只有一行的小小题目。既然让你求直线的方程，所以这题必然会考察直线的知识；而且前面还有两个圆，还会考察圆和圆的位置关系，你得先知道两圆啥位置你才能去找公切线；而且既然问公切线，公切线本质上也是一条切线，这道题目里面还会用到上节课讲的直线和圆的位置关系，圆心到直线的距离得等于半径。考察直线，考察圆，考察圆和圆的位置关系，最后还考察直线和圆的位置关系，真得很恶心。今天咱们重点把它解决一下。

首先我得知道你这两个圆啥位置关系，对不对？大家可以画图来看。
这是一个平面直角坐标系。
第一个圆，单位圆，半径是 $1$ 的，很好画。
第二个圆的圆心是 $(3, 4)$，半径是 $\sqrt{16} = 4$。纵坐标已经是 $4$ 的情况下，其实我这个圆画的时候大体上就得跟 $x$ 轴相切了。
那我来判断一下两个圆的位置关系。这个地方是有几个交点？是一个还是两个？我得看一下圆心距怎么样。
两点间距离公式：横坐标是 $3$，纵坐标是 $4$，斜边显然就是 $5$。
圆心距 $5$ 正好等于半径 $r_1$ 和半径 $r_2$ 的和：$r_1 = 1$，$r_2 = 4$，$1 + 4 = 5$。原来这两个圆是外切的情况。

画完之后我发现这两个圆是外切的，那公切线的条数外切应该有三条：一条，两条，中间公共切点还能再做出来一条。
这题是全让我求出来吗？他说“都相切的一条直线的方程”，就是这三条当中你任选一个会做就行。作为高考题，在高考考场上你选哪条最简单？
我做完图发现，其中有一条线怎么做出来是竖直的，好像跟 $y$ 轴平行。具体平行不？我来看看。
首先它跟第一个圆相切，原点到它的距离得是 $1$。
第二个圆横坐标是 $3$，到这条直线的距离等于半径得是 $4$。整个长度 $4$ 减去它的横坐标 $3$ 的话，正好也等于 $1$。
所以相当于两个圆最左侧这两个点的坐标其实都是 $-1$。两点一连相切了，这条直线是最好写的：
$$x = -1$$
最简单，没什么好讲的。

但是今天我提高要求，你光会求这条直线不行，我要求大家把另外两条公切线也得会求。

好戏马上开始。我先问大家这一条切线怎么求？
它是公切线，跟两圆都相切，意味着两个圆的圆心到它的距离应该都等于半径。
所以我们第一个方法，我先把这条直线设出来，比如说它是：
$$y = kx + m$$
这条直线里面有两个参数 $k$ 和 $m$。我通过两次点到直线距离把 $k$ 和 $m$ 解出来。
我先把它变成一般式：
$$kx - y + m = 0$$
第一个，原点到这条直线的距离：
$$\frac{|m|}{\sqrt{k^2 + 1}} = 1$$
第一个方程有了。
第二个方程，我再列个点到直线距离，分母还是 $\sqrt{k^2 + 1}$。圆心现在变成了 $(3, 4)$，那就是：
$$\frac{|3k - 4 + m|}{\sqrt{k^2 + 1}} = 4$$
$k$ 和 $m$ 两个未知数两个方程，理论上能不能解得出来？能。但好解不？显然不好解。这里面既有绝对值，又有根号，根号里面还带着平方，你想硬解说实话真不好解。我相信在场同学 99% 你都解不出来。如果有的宝贝能解出来的，你把过程发在评论区，大家去给他点赞去。

这种解方程的、单纯用代数的方法去解决问题的思路今天我不讲。你没动脑子，光列两次点到直线距离，是不思考了，但是计算量太大。

我今天讲第二个方法：咱在代数的基础上再加一点几何。啥意思？
整个这问题现在不就两个圆吗？两个圆心我还都知道。我把这两个圆心如果连起来的话，像穿糖葫芦一样这么一穿，大家说是不是我做出来的这条绿线正好是两圆的对称轴？两圆关于这条绿线对称，没问题吧。
那既然整个图形是关于这个绿线对称的，那我做出来的公切线，这条线和这条线关于这个对称轴肯定是不是也对称？这三条线相交的应该是同一点。
而且我另外的第三条公切线也得跟我对称轴对称，对称轴是这条直线的垂直平分线，它必定得是垂直的。

这对称看不明白的同学，我把这个图倒过来给大家画。刚才把两圆画斜了你看不出来，那我水平画两个：一个圆，两个圆。我把圆心这么一连，然后我开始做公切线了。上面我是不是能做一条公切线？能。那对称的下面我可不可以做？还可以做。这两条线关于这个对称轴对称，这三条线共同交于同样的一个点。

这交点首先肯定得在对称轴上。对称轴的方程不要太好求，经过两点 $(0, 0)$ 跟 $(3, 4)$，方程应该是：
$$y = \frac{4}{3}x$$
而且这点还在黑线上，其中一个黑线我刚才刚刚已经会求了，这条黑线是 $x = -1$。所以我就令这直线方程的 $x$ 取 $-1$，就是这个交点坐标。
$x$ 取 $-1$，$y$ 取的就是 $-\frac{4}{3}$。
这三条直线的公共交点坐标我就找到了：$(-1, -\frac{4}{3})$。

那我现已经知道这黑线经过这个定点的情况下，我再设直线的时候还设 $y = kx + m$ 吗？你这么设不是有两个参数 $k$ 和 $m$，解两个方程不好解吗。咱都知道定点的情况下我是不是可以列点斜式？
现在我把这个 $l_2$ 设成：
$$y - \left(-\frac{4}{3}\right) = k(x - (-1))$$
化简一下：
$$kx - y + k - \frac{4}{3} = 0$$
我直线方程都有了的情况下，怎么求这里面单一参数 $k$ 呢？我列一次任何一个点到直线距离是不是就可以了？你列小圆的、列大圆的都行。
我就选简单的，列小圆，小圆圆心是 $(0, 0)$。
点到直线距离：
$$\frac{\left|k - \frac{4}{3}\right|}{\sqrt{k^2 + 1}} = 1$$
太好算了。咱把它乘过来，然后两边平方：
$$\left(k - \frac{4}{3}\right)^2 = k^2 + 1$$
这一展开之后，$k^2$ 也能约掉，你最后解的不是一个一元二次方程，解的是一元一次方程：
$$k^2 - \frac{8}{3}k + \frac{16}{9} = k^2 + 1 \implies -\frac{8}{3}k = -\frac{7}{9} \implies k = \frac{7}{24}$$
然后把 $k$ 带进来，直线 $l_2$ 的方程就有了，写完是：
$$7x - 24y - 25 = 0$$
这个计算量可以说几乎没有。因为你用上了一点几何知识，这两条线应该关于这个对称轴是对称的，它们三条线经过的是同一个定点。这定点我还能求，那我列直线的时候我就不列 $y = kx + m$ 了，我列成点斜式，只有一个变量，我解一个变量的方程太好解了。

这是我求这条 $l_2$ 的过程。我问大家，这个 $l_3$ 你求的时候怎么求？
这方法说实话那就太多了，我们也是采用代数加几何的混合方法。用上一点几何，这条直线不仅过刚才我们的这个定点，而且我知道这条线跟对称轴垂直。对称轴的斜率我都知道了是 $\frac{4}{3}$，那你这切线的斜率跟它相乘应该是 $-1$，斜率我其实能直接求，应该是 $-\frac{3}{4}$，互为负倒数。
斜率都有了，我想求直线方程，那我就设了：
$$l_3: y = -\frac{3}{4}x + m$$
咱把这参数求出来就行了。想求参数，列一个方程就行，咱就列一个任何一个点到直线距离等于半径就行吧。
把直线写成一般形式，两边乘个 $4$：
$$3x + 4y - 4m = 0$$
点 $(0, 0)$ 到直线距离：
$$\frac{|-4m|}{\sqrt{3^2 + 4^2}} = 1 \implies \frac{4|m|}{5} = 1 \implies |m| = \frac{5}{4}$$
$m = \pm \frac{5}{4}$，但是你看一看你要哪一个。
我在图上画，只有这一条直线是符合题意的，那为啥最后求出来有两个值呢？因为你光确定了斜率，而且到原点距离是 $1$ 的话，除了我们要去求的目标直线是符合这个条件的，其实下边是不是也有一条直线，斜率也能满足是 $-\frac{3}{4}$，然后到原点距离也是等于 $1$ 的？这条直线是不对的，你是要排除掉的。
上面这条直线跟 $y$ 轴的截距应该是正的，我下面这道直线跟 $y$ 轴的交点截距应该是负的。$m$ 代表的不就是跟 $y$ 轴的截距吗？所以 $m$ 应该取正不能取负。最后逼得 $m$ 只能取 $\frac{5}{4}$。
这一整道题咱就做完了，$\frac{5}{4}$ 代进去，第三条直线方程：
$$3x + 4y - 5 = 0$$

说实话费劲不？太费劲了。因为这种它真的让你把公切线求出来的题目，你光会代数没用，你列完方程你不会解。咱得多多少少结合点几何知识，我们在几何方面下下功夫、动动脑子，咱们的计算量就特别小。其实反复的就利用上对称：两条边上的公切线关于对称轴对称，它们三个交于一个点，这点我是能求的，我列直线方程我列点斜式；这条直线是关于对称轴垂直的，我能直接算出来斜率的情况下，那我直接列出初中的 $y = kx + m$，再加上点到直线距离，就能把 $m$ 求出来了。
