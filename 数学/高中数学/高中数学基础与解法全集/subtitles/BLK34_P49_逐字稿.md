第三类，非常重要的，也是一个复合函数。他把咱会的 $\sin x$，这 $x$ 变成了一大坨，变成了一个整体 $\omega x + \varphi$。这种变形方式太重要了，年年都考，每一张卷子，全国一卷、二卷、甲卷、乙卷全都考。正是因为他比较重要，而且内容非常多，所以我们下周单独出一节课，给大家完整地讲一讲 $f(x) = \sin(\omega x + \varphi)$ 这种题到底怎么做。

首先来看第一题，他给我什么呢？给我两个自变量 $x_1, x_2$ 都在 $0$ 到 $\pi$ 之间。说什么呢？说 $x_1$ 的 $\sin$ 和 $x_2$ 的 $\sin$ 相等。啥叫 $\sin$ 相等？哎哟，那不就 $\sin x$ 这图像上，在 $0$ 到 $\pi$ 这范围内找两个高度相等的点不就得了嘛。函数值相等，那不就是高度一样高嘛。所以我设了啊，左边我设为 $x_1$，右边设为 $x_2$。

现在人家问 $\cos \frac{x_1 + x_2}{3}$，这 $\cos$ 不 $\cos$ 的我先不管，我先问大家 $x_1 + x_2$ 是啥东西？我们来看看图啊，放大一点。我们知道这两点是一边高的，换句话说，它是关于 $\frac{\pi}{2}$ 这对称轴得对称的吧。既然中点这坐标是 $\frac{\pi}{2}$，那宝贝们，中点坐标公式，$x_1 + x_2$ 应该是多少啊？应该是中点坐标的两倍吧。所以虽然这道题没有告诉大家 $x_1$ 是谁，$x_2$ 又是谁，没关系，它俩的和一定是一个定值，等于 $\pi$。

第二类，复合函数。说实话，复合函数他有可能咋复合，那复合方法可多了去了，他想怎么复合就怎么复合。但解决复合函数我们最关键的方法，最常用的方法，不知道大家有没有总结过啊，把那两个字打在屏幕上，叫换元。

换元能帮助我们把一些复杂函数变简单，不信大家来看。他给我的叫什么？叫 $\cos^2 x + \sin x - 2$。哎哟，这函数怎么分析怎么恶心，因为它有两个不同的部分，一个叫 $\sin$，一个叫 $\cos^2$。这两部分放在一起咱真是不太会研究。但是我问大家，它俩有没有关系啊？这 $\cos^2$，哪儿出现过 $\cos^2$？咱不是学过 $\sin^2 x + \cos^2 x = 1$ 吗？所以显然 $\cos^2 x$ 我居然就能写成 $1 - \sin^2 x$ 呗。所以干脆我不装了，我直接把 $\cos^2 x$ 写成 $1 - \sin^2 x$ 来做。

带进来，那这个函数，也就是 $-\sin^2 x + \sin x - 1$。我舒服了，这 $\sin x$ 从头到尾不断不断不断在出现，恶心我，出题人恶心我。怎么办？把它设为 $t$。那最后就变成 $-t^2 + t - 1$，变成一个有关 $t$ 的二次函数。二次函数谁还不会啊？谁都会了。

那关键是别忘了，$t$ 是我们自己设的，$t = \sin x$。这新变量的取值范围我们求没求？我们还没求。$t$ 的范围是由 $x$ 的范围决定的。现在题目中给我的这个范围，$-\frac{\pi}{6}$ 到 $\frac{2\pi}{3}$ 是 $x$ 的范围哦。我们已知 $x$ 求 $\sin x$ 的整体范围，得画图像或者画单位圆。

我还是习惯画单位圆啊。这个脑子里可就不能直接画图了，因为这是一个取值范围问题，咱就慢慢画。首先来画一个 $-\frac{\pi}{6}$，在哪啊？$-30^\circ$，在这儿。$\frac{2\pi}{3}$ 在哪啊？$120^\circ$，在这儿。非常快。那咱从这个角转到这个角的过程当中，我们划过的那段弧长就它呗。

那现在我问的是 $\sin$ 值，$\sin$ 值就是这段弧长的纵坐标。纵坐标啥时候最大？都讲累了，这最高呗，最高点是 $1$。纵坐标谁最小？它最小呗。最小这值又来了，$1 : \sqrt{3} : 2$，$30^\circ$-$60^\circ$-$90^\circ$ 三角形，斜边是 $1$，小直角边显然就是 $\frac{1}{2}$。别忘了加负号，它在 $x$ 轴的下方。所以 $t$ 的取值范围就在 $-\frac{1}{2}$ 到最高点 $1$ 之间。

为啥都取闭区间？因为人家这里面左右都能取得到，这每个点其实都是实心点。

因此接下来的问题变成了一个：已知 $t$ 的取值范围，求二次函数最大值的问题。这还用我讲吗？初中生都会了。这二次函数开口向下，对称轴 $-\frac{b}{2a}$ 应该是 $\frac{1}{2}$。咱截的是谁？截的是 $-\frac{1}{2}$ 到 $1$，这是 $-\frac{1}{2}$，这是 $1$。最后人家问这一段它的最大值，最大值就在对称轴处取得，把 $\frac{1}{2}$ 这点带进来：$-\frac{1}{4} + \frac{1}{2} - 1$，答案 $-\frac{3}{4}$，轻松愉快。

这个就是一个简单的复合函数。咱通过同角三角函数关系，咱把这 $\cos^2 x$ 用 $1 - \sin^2 x$ 来表示，最终整个函数就只含有 $\sin$ 了。只含有 $\sin$，那换元不就行了吗？

那出题人觉得你这也太简单了吧，考不到大家，他想给大家出得再难一点，能不能？当然可以。

现在出题人发力了，他把这题改得更复杂，让你更看不出来了。它变成一个分数形式，有分子分母吧，也是既有 $\sin$ 又有 $\cos$，既存在两个东西和，又存在两个东西积，挺烦人。那这个时候我怎么办？

这作为一个复杂的复合函数，跟刚才的题目其实思路是类似的。刚才咱把两个不一样的东思想尽办法找关系，最后化成一个相同的一个整体变量。这式子里面哪不一样，咱就找哪的关系。现在也一样，既有和又有积，一样吗？不一样，找关系。咋找？

这是一个非常经典的模型。咱先找 $\sin x \pm \cos x$ 以及 $\sin x \cos x$ 之间的关系。它俩想乘起来，这原本是个加法减法，怎么能让它俩乘起来呀？非常简单，咱把整个式子，不论是加还是减，平方一下，那就会出现一个完全平方公式：$\sin^2 x + \cos^2 x \pm 2\sin x \cos x$。

好家伙，$\sin^2 x + \cos^2 x$ 谁啊？那不就是 $1$ 嘛。所以变成了 $1 \pm 2\sin x \cos x$。我舒服了。所以原来这加法和乘法之间有完完全全的等式关系。我即便有的时候给大家改成减法，那我Initialized也只需要把这加号改成减号而已。

所以这式子告诉我们，有的时候题目里面虽然看着是两个不同的组成部分，但是我们能把两个不同部分进行统一。直接应用上 $2\sin x \cos x$，把 $1$ 移到左边去，那就是 $(\sin x + \cos x)^2 - 1$ 呗。把它带进来，带这里面去。

所以现在的 $f(x)$，分子咱不动，分母的 $2\sin x \cos x$ 给它换掉，换成它，它平方再减 $1$。前面加 $2$ 后面减 $1$，那其实就是加 $1$ 呗。上下这长得那是形状一模一样，赶紧换元。

设它为 $t$。最后显而易见，原来这复杂的表达式绝对能化简成一个有关 $t$ 的新函数：$\frac{t}{1 + t^2}$。一次比二次，被讲过太多回了，咱直接上下除以 $t$。分子除以 $t$ 是 $1$；分母每一项也除以 $t$，那就是 $\frac{1}{t} + t$。出现啥玩意儿了？出现对勾函数了，出现能用基本不等式来解决的问题了。

他让我求整体的最大值，实际上我只需要去求分母的最小值。分母最小的时候，整体反而最大。分母最小值 $t + \frac{1}{t}$ 谁还不会？两式的和大雨等于两倍根号下两者乘积：$t + \frac{1}{t} \ge 2\sqrt{t \cdot \frac{1}{t}}$，它俩一乘完就剩一个 $1$，就等于 $2$。带进去，最大值为 $\frac{1}{2}$。

那别忘了，能不能取得到 $\frac{1}{2}$ 啊？这等号啥时候取的？当且仅当它俩相等的时候。那问题是这 $t$ 能不能等于 $1$？我要看 $t$ 能不能等于 $1$ 的话，我就看这个整体。这方程有没有解？咱咋解？这是两个未知数，好像看着不太好解，但是我们是不是还知道 $\sin^2 x + \cos^2 x = 1$ 啊？两个未知数两个方程，这不就能解了吗？而且我发现其实我不解，有一个答案，这答案我猜都能猜得出来。我只要猜出来一个就行了，我没必要都解出来，我只要猜一个。猜谁？它取 $0$，它取 $1$。$0 + 1$ 是不是 $1$？没错。$0^2 + 1^2$ 是不是 $1$？没错。所以 $\sin x = 0$、$\cos x = 1$，$x$ 取谁就好了呢？$x$ 取 $0$ 不就得了嘛。

我只要解出来这么一个解，别的解我都不看了。只要它存在，就能使得 $t$ 取得 $1$；只要 $t$ 能取得 $1$，这不等号就能取得等号；这原式就能取得最后的最值 $\frac{1}{2}$。

所以今天我们讲了 $\sin x$ 图像是怎么画出来的。我通过在单位圆上转圈，把图像一圈圈就转出来了。而且 $\sin x$ 图像性质特别丰富：定义域、值域、对称轴、对称中心、单调性、周期性。这一页大家记得自己整理一下，课后再推一遍。因为我们后续在讲函数综合的时候，这一页的性质我们可要经常用了。
