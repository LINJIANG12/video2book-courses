Hello everybody，我是神仙七小竹。立体几何的解答题无非就问三件事：证明平行垂直、求角度以及求距离。这三件事用我们学的空间向量全都能解决。这个视频我们重点来研究空间向量是如何证明平行跟垂直的。本节课是空间向量解答题的最关键的基础课，一定要把每一个知识点都搞清楚。快点开始吧。

今天我们来研究平行跟垂直。这个是老生常谈的问题了。平行无非就是线线平行、线面平行，还有面面平行；垂直分别是线线垂直、线面垂直和面面垂直。虽然这里面看起来好像有六种不同的情况，但实际上这六种不同的情况就两件事：一个叫线，一个叫面。所以如果想用空间向量研究平行垂直关系的时候，咱得先知道线和面怎么用空间向量来表示。

我们一个一个来看。首先，如何用空间向量来表示一条线呢？比如说 $A_1C$ 这条直线。这条直线怎么确定的？我们知道两点就能确定一条直线。而且我们还知道，如果把其中一个点看成起点，另一个看成终点，我们还能由这两点确定一个向量。这个向量的方向就能代表这条直线倾斜的方向。我们把直线上两点确定的向量叫这条直线的方向向量。怎么求？很简单，先把起点终点的坐标写出来。$A_1$ 点坐标，随便举例子了，长宽高比分别是 $1:2:1$，那么 $A_1$ 点就是 $(1, 0, 1)$，$C$ 点就是 $(0, 2, 0)$。那么 $\vec{A_1C}$ 就是终点减起点，得到 $(-1, 2, -1)$。所以用空间向量表示线太简单了，我们只需要在线上找两个点，坐标一减就行。

但是如果想用空间向量表示面的话，可没有那么简单。难道咱能随便在面上找两个点，这形成的向量能代表这个面吗？不能。因为经过这个向量的有无数个面，你怎么知道这个向量表示的是哪个面？所以用一个向量不行。有的宝贝就想，那我用两个向量唄，两个不共线的向量那不就能确定一个面了吗？但是咱选两个向量表示一个面有点麻烦，最好能选一个向量。实际上这个向量我们不在这个面上选，我们去选跟这个面垂直的一个向量，用这个向量的方向来代表这个平面。跟面垂直的向量叫这个面的法向量。

注意，对于同一个面来说法向量可能有无数个，可能有的长一点，有的短一点，有的是朝上，有的是朝下。不过没关系，它们都叫法向量。原理很简单，因为只要法向量所代表的一条直线的方向确定，面的方向一定也是跟着一起确定的。比如说法向量如果是竖直的，那么跟它垂直的面必然是水平的，不论这个面如何平移。所以我们知道了用方向向量表示线，用法向量表示面。有了这个基础，所有的线面平行跟垂直的问题全都能解决。不信来看。

在以前我们想证明两条线平行，我们用的是平面几何或者立体几何的方法。但是今天我们只需要建完系之后，找到两条直线的方向向量，想证明线线平行，我们只需要去证两个向量是平行的就可以了，是不是很简单？

那如果想证明线面平行，我们用方向向量表示线，用法向量表示面。我们不需要直接证明线面怎么怎么样，我们只需要证明这两个向量之间是垂直的就行了。因为如果法向量跟这条直线是垂直的，那跟法向量垂直的面跟直线一定是平行关系。当然这不是最终形式，我们用向量的方法去表示垂直的时候，我们经常用的应该是数量积。向量垂直就等价于它们的数量积为 $0$。

如果你这个都听懂了，那下一个简直就是小菜一碟。想证明面面平行，我们并不直接去看面，而应该分别去看两个面的法向量。只要两个法向量是平行关系，那两面肯定也是平行关系。

有了平行作为基础，我相信垂直对大家来说也是瓮中捉鳖。证明线线垂直，我们只需要证两条线的方向向量，让向量 $\vec{a}$ 和向量 $\vec{b}$ 的数量积为 $0$，它俩垂直就可以了。想证明线面垂直，我们并不直接去证，而分别找线的方向向量和面的法向量。如果方向向量和法向量是平行关系，那线面一定是垂直关系。最后，两个面想垂直，那么只要让它们的法向量相互垂直就可以了，两个法向量的数量积必然为 $0$。

那我相信宝贝们肯定都有一个问题：只要涉及到面，咱就找法向量，但是你还没教我法向量怎么求呢。所以接下来我们重点讲法向量如何求。

找法向量其实就是找这个面的垂线。根据垂线的判定定理我们知道，它想成为垂线，只要它能跟这个面上两条相交的直线都垂直就可以了。那面上的两条相交直线想确定方向也很简单，用方向向量，分别记为向量 $\vec{a}$ 还有向量 $\vec{b}$。所以第一步，在面上找两个方向向量 $\vec{a}$ 和 $\vec{b}$，然后让法向量都跟它们垂直。想跟它们垂直，那数量积就是 $0$。我们得到两个方程去解这个法向量就可以了。

当然讲完思路，咱得实际来操作一下。比如说咱们就举一个非常古老的例子，这个图我们看过太多次了。边长比比如说 $2:1:1$。现在我问，$A_1C_1B$ 这面的法向量怎么求？

第一步，在这面上选两条线。那选哪条线呢？无非这面就是由三个点确定的，所以想找面上的向量，咱得先把这三个点的坐标写出来。我直接写了：$A_1$ 点 $(1, 0, 1)$，$B$ 点 $(1, 2, 0)$，$C_1$ 点 $(0, 2, 1)$。找到起点终点坐标，那随意选两向量，比如我就选 $\vec{BC_1}$ 向量，还有 $\vec{BA_1}$ 向量。

$\vec{BC_1}$，终点减起点，第一个 $0 - 1$ 是 $-1$，$2 - 2$ 是 $0$，$1 - 0$ 是 $1$。类似的 $\vec{BA_1}$ 我也能算：$(1 - 1, 0 - 2, 1 - 0)$。所以这个面上两个方向向量都找到了。我们最后想求法向量。空间向量得有三个坐标，三个坐标都不知道没关系，就设成 $(x, y, z)$。那怎么求 $x, y, z$？刚才都说了，只需要让法向量和另外两个向量数量积为 $0$ 就可以了。和这两条直线垂直的向量一定是法向量。所以把所有问题变成一个代数运算。

第一个方程，$\vec{n}$ 和 $\vec{BC_1}$ 算数量积：$x \cdot x + y \cdot y + z \cdot z$，$-x + 0y + z = 0$。
第二个方程，还是两向量 $x \cdot x + y \cdot y + z \cdot z$，$0x - 2y + z = 0$。

按理来说，两个方程是解不出来三个未知数的。不过没关系，因为我们知道法向量也不是唯一确定的，你只要在众多有长有短的法向量里面求出来其中一个就够了。所以我们就强行解，令其中比如说令 $x = 1$，那解一下，很显然 $z = x = 1$。$z = 1$，$y$ 等于几？第二个方程告诉你了，$y$ 应该等于 $\frac{z}{2} = \frac{1}{2}$。所以最后法向量就如愿求出：$(1, \frac{1}{2}, 1)$。

这就是求法向量的标准过程。第一步不可避免的，你得先找到面上的两个方向向量；第二步，列两个数量积等于 $0$ 的方程；第三步，解出来。

当然，肯定有宝贝觉得这个过程太麻烦了，我太不想算了。别慌，我们对于法向量是有简便算法的，而且在网上随便一搜法向量，大家肯定能搜得到各种各样的速算技巧。那么今天就给大家介绍众多速算技巧当中的一个。

举个例子，现在已知向量 $\vec{a}$ 和向量 $\vec{b}$，由这两个向量确定的法向量一定能求。究竟怎么求？法向量最后值跟谁有关？只跟这六个数有关。想速算，我们第一步，把每个向量抄两遍：$\vec{a}$ 向量 $(1, 2, 1)$，再抄一遍 $(1, 2, 1)$；$\vec{b}$ 向量 $(-1, 0, 3)$，再抄一遍 $(-1, 0, 3)$。这第一步我们叫每个向量写两遍。

第二步，这一共有六列，我们第一列还有最后一列不要，只保留中间四列。我们称之为叫掐头去尾留中间。

最后，重点来了。咱们想求的法向量其实无非就是得到三个数，分别是 $x, y$ 和 $z$ 三个坐标。$x$ 坐标我们要交叉相乘再相减。具体操作一下，那就是 $2 \times 3 - 0 \times 1$，算完的答案放在 $x$ 坐标的位置，$6 - 0$ 就是 $6$，很好算。那 $y$ 坐标也一样，我还是交叉相乘：$1 \times (-1) - 3 \times 1$，算完的答案是 $-4$。最后 $z$ 坐标我不说大家也会了，交叉相乘再相减：$1 \times 0 - 2 \times (-1)$，算完是 $2$。最后得到的答案就是法向量。

这个运算过程其实就是大家以后在大学里面学习的线性代数的叉乘运算，没有那么神秘。大家把这个运算过程记下来就好了。第一步，每个向量写两遍，掐头去尾留中间；第二步，交叉相乘再相减。但是注意，交叉相乘再相减的顺序一定是一致的。

很多同学可能会问是谁减谁？我们一般是用这个方向相乘减去这个方向相乘。有的老师可能给大家总结成什么撇和捺，但是有的宝贝就像我，分不清哪个是捺哪个是撇，语文没学那么好。所以你怎么记呢？大家就画叉。你看好了，你叉是怎么画的，就用谁再减谁。画叉，先它俩乘，再减去它俩乘。不信的话你可以验算一下。最后我们得到答案跟原来你看数量积是不是 $0$：$1 \times 6 - 8 + 2$，正好是 $0$，答案绝对没错。

但是一般情况下，我们算完这个法向量其实并不一定是一个最简结果，因为我们知道向量是可以来回伸缩的。这个 $(6, -4, 2)$ 其实都是 $2$ 的倍数，所以我可以把它整体除以 $2$，得到一个好看且好算的法向量，写成 $(3, -2, 1)$，这样比较好。

当然练一道题肯定不够，我们可以验算一下刚才用普通方法做这题的结果。两向量：$(-1, 0, 1)$ 写两遍，$(0, -2, 1)$ 写两遍。掐头去尾留中间，交叉相乘再相减：$0 \times 1 - (-2) \times 1$，$0 - (-2)$ 应该等于 $2$；交叉相乘再相减：$0 - (-1)$ 应该是 $1$；交叉相乘再相减：$2 - 0 = 2$。你看看，$(2, 1, 2)$ 跟原来的 $(1, \frac{1}{2}, 1)$ 是不是一个方向的向量呢？咱把它每一项都乘 $2$ 那不就是 $(2, 1, 2)$ 吗？完全没错。

不信就再来练一道。求法向量，两个向量分别是 $(1, \sqrt{3}, 0)$ 跟 $(-2, \sqrt{3}, 3)$。每个向量写两遍。开始了，掐头去尾留中间，交叉相乘再相减。第一个数是 $3\sqrt{3} - 0$，就是 $3\sqrt{3}$；第二个数，交叉相乘再相减，$0 - 3$ 就是 $-3$，直接口算；第三个数，交叉相乘再相减，$\sqrt{3} - (-2\sqrt{3})$，应该是 $3\sqrt{3}$。每项都有 $3$，所以最后我们求得的法向量都除以一个 $3$：$(\sqrt{3}, -1, \sqrt{3})$。

验证一下法向量，它俩对应项乘一下：$1 \times \sqrt{3} - \sqrt{3} + 0 = 0$，没问题。第二个向量再来验算一下：$-2\sqrt{3} - \sqrt{3}$ 得 $-3\sqrt{3}$，再加上 $3\sqrt{3}$ 也是 $0$，完全没问题，这就是答案。

当然，光会速算可不行，因为考试的时候立体几何是考大题的，这个书写过程那是必须要写的。所以还是建议大家，我们第一开始讲的原始方法你必须得会，在会算、算对而且算得快的基础上，大家再去用速算的方法对最后你刚才算出的答案进行验证，这在考试里面是最稳妥的。因为一旦法向量大家算错了，那基本上立体几何可就得不了几分了。

在正式讲解之前，我们先来复习一下，咱怎么用空间向量来表示线和面来着？

线线角可不是第一次学了。我们发现两条直线所形成的夹角，这里它形成了一个锐角，其实还有一个钝角同时存在，对不对？那我们规定，两条直线所夹的较小的这个，在这幅图里面这个锐角，当做线线角 $\alpha$。所以 $\alpha$ 它的取值范围有多大？它有可能是 $0^\circ$（两条直线重合或平行的），也有可能是一个锐角，最大最大不能超过一个直角，$\alpha \in [0, \frac{\pi}{2}]$。

现在问题来了，我们如何用向量来求这个角呢？很简单。咱咋用向量表示直线？就找这两条线的方向向量。比如说举个例子，我这么找一个，再这么找一个，分别记为 $\vec{a}$ 和 $\vec{b}$ 好了。我把直线的问题转化成向量的问题，向量咱好不好求角度啊？太好求了吧。向量夹角 $\theta$ 咱可以用数量积来表示，对不对？我们知道向量一旦找到，夹角一定能算：

$$\cos\theta = \frac{\vec{a} \cdot \vec{b}}{|\vec{a}| |\vec{b}|}$$

这不就一下求完了吗？但是有一个问题。我这样画的时候大家发现，的确我求完向量夹角的 $\theta$ 跟我要求得的线线角的确是一模一样、大小完全相等的。但其实理论上还有另外一种情况。你说我万一在取向量的时候，一个往上取，另外一个反向取的话，那我用这公式求完这个 $\theta$ 就在这儿了吧？那么这种情况下，$\alpha$ 跟 $\theta$ 啥关系？显然就不相等，而是互补关系了。

第一步，找代表直线的方向向量所形成的夹角 $\theta$；
第二步，我求的是 $\theta$，但是真正人家让你求的是线线角 $\alpha$，找 $\alpha$ 和 $\theta$ 的关系。

咋找关系？我给大家具体举个例子。比如说题目中如果让我求 $\sin\alpha$，那无非就两种情况呗。第一种情况，$\theta$、$\alpha$ 相等，那 $\sin\alpha$ 就是 $\sin\theta$；第二种情况，如果它们俩是互补的，$\alpha$ 我能写成 $\pi - \theta$，所以让我求 $\sin\alpha$ 就是求 $\sin(\pi - \theta)$。这是用啥公式来化简？当然是诱导公式，它就等于 $\sin\theta$，对不对？

以上就是线线角的知识。如果想听一句话总结，那就是想求线线角，那就找两线的方向向量所形成的夹角 $\theta$。那我真正要求的线线角 $\alpha$ 跟夹角 $\theta$ 之间究竟有什么关系呢？第一，线线角恒为正；第二，$\alpha$ 跟 $\theta$ 之间函数名是不变的，$\sin$ 对应 $\sin$，$\cos$ 对应 $\cos$，不变名。

讲完线线角，接下来我们来看线面角。

线面角咋定义的？我们在必修二学的，先做这条直线在这个平面上的投影，所谓的投影啥叫投影？其实我在这条直线上找个点，做线面垂直，然后一连接出来，这必然是一个直角三角形，我们把这个锐角 $\alpha$ 的值作为线面角的值。

很显然，线面角的取值范围一定在 $0$ 到 $90^\circ$ 之间。就像刚才一样，$0$ 到 $90^\circ$ 的角，无论人家最后让我求的是 $\sin\alpha$ 还是 $\cos\alpha$，我们最后一定一定要先加上绝对值，咱必须保证求完的值是一个正值。

紧接着我们如何用向量来求？线面角线面角，咱得先求这线的方向向量；第二步，还得求面的法向量。两个向量有了，我们只会求什么来着？抱歉，只会求这已知的两个向量的夹角，咱会求的是这个角 $\theta$。

那我姥姥也能看出来了，这角跟我想要的 $\alpha$ 角之间可大不一样，它俩绝大部分情况下应该是不相等的，啥关系呢？我这 $\theta$ 对顶角一画，这两个角显然应该是互余关系，它俩相加是 $90^\circ$，我 $\alpha$ 能写成 $90^\circ - \theta$。

当然其实还有另外一种情况，你想，我刚才画的法向量是向上的，有没有可能法向量是向下的？当然可以。因此这种情况我也得考虑在内。这幅图里面，这线和法向量之间所形成夹角，那我画的时候就画在这了，这个 $\theta$ 角变成了我已知的 $\alpha$ 角和 $90^\circ$ 的外角。所以外角我们初中学过，$\theta$ 就应该等于 $\alpha + 90^\circ$，所以 $\alpha$ 就是 $\theta - \frac{\pi}{2}$。

因此大家有没有发现，无论是哪种情况，我 $\alpha$、$\theta$ 差的永远是 $\frac{\pi}{2}$ 的奇数倍，对不对？因此如果我想求 $\sin\alpha$，举个例子，在第一种情况下，它就是绝对值的 $\sin$，把 $\alpha$ 替换成 $\frac{\pi}{2} - \theta$。奇变偶不变，里面是二分之奇数 $\pi$，因此咱一定要把 $\sin$ 变成 $\cos$。诱导公式跟我说，奇变偶不变，里面是 $\frac{\pi}{2}$，那化简完 $\sin(\frac{\pi}{2} - \theta)$ 就是 $\cos\theta$，函数一定是要变名的。

因此求线面角的时候跟我求线线角不一样。第一句话，因为它恒是一个锐角，所以我们求的 $\sin$ 也好、$\cos$ 也好，恒为正；但是前后要变名，前面是 $\sin$，我要写成 $\cos$；前面是 $\cos$，我要求的反而就是 $\sin\theta$。这就是线面角的口诀：恒为正，要变名。

咱之前咋学的二面角来着？二面角大小得看图形画成啥样。对应不动的这两面，题目有可能问的是这个角，这二面角显然是一个钝角。但是跟它相对的，如果人家问的是下面这个角，这 $\alpha_2$ 又变成一个锐角了。

因此二面角的取值范围在 $0$ 到 $\pi$ 之间。这范围锐角、钝角都取得到的话，最后我们想求二面角的 $\sin$ 值、$\cos$ 值，可就有太大影响了。

首先来看 $\sin$ 值，如果问的是二面角的 $\sin$，$0$ 到 $\pi$ 在第一、二象限，$\sin$ 值永远是正的，这是三角函数知识。所以最后求的那个值必然为正，就加一个绝对值。先判断正负，至于里面写什么，一会儿再说。

如果问 $\cos$ 值呢？$\cos$ 值的正负能像刚才 $\sin$ 值那样一下确定吗？先画一下 $\cos$ 的图像，它是一个偶函数，这是 $0$，这是 $\pi$。所以惊奇发现，现在取的是 $\alpha$ 在 $0$ 到 $\pi$ 之内，这个 $\cos$ 值，锐角的话的确是一个正值，比较喜欢；但是它同时也能取到钝角，钝角的 $\cos$ 可是一个负值。

总结一句话，题目当中一旦问二面角的 $\cos$ 值的时候，它是正还是负，跟 $\alpha$ 角到底它是锐角还是钝角是有关系的，正负不定。所以加完绝对值之后前面要加正负号，正负号需要我们自己来判断。

如果指明的这个角在图形当中发现它明显是个锐角，那求完这个咱一定是取正的。但如果指明的二面角是钝角，最后取的必然是负号。

绝大部分题目，如果真的考了 $\cos$ 值在高考当中，图形里面到底是锐角还是钝角是直接能看出来的，非常明显。当然也有曾经非常非常少的情况下，观察发现二面角锐不锐、钝不钝不是特别好看，那就需要别的判定方法了。这种比较少见的情况不是今天基础视频要讲的内容，后续的习题课再给大家讲那种比较难的二面角正负的判断，今天都是非常明显的。

现在已经知道了，二面角 $\sin$ 值恒为正，$\cos$ 值可正可负，跟这角锐钝相关。里面填什么？得去看求完的两向量，这两面的法向量之间夹角 $\theta$ 跟真正的二面角 $\alpha$ 之间的关系。

这里给大家举了三个例子，举例子的时候都把钝角当成二面角了，这是 $\alpha$、$\alpha$、$\alpha$。

为啥举三个例子？两面算完的法向量有可能都朝里，有可能都朝外，有可能一个朝里、一个朝外。严谨地去看看它们究竟是啥关系。

第一种情况，如果都朝里，这两个箭头所形成的角度是这个角。这 $\theta$ 跟 $\alpha$ 之间啥关系？这是一个四边形，四边形另外两个角都是 $90^\circ$。四边形四个角相加应该是 $360^\circ$，两角都是 $90^\circ$，那么 $\alpha$ 跟 $\theta$ 另外两个角度相加应该是 $180^\circ$ 的。$\alpha$ 可以写成 $180^\circ - \theta$，差 $\pi$。

第二种情况一模一样，把两箭头延长一下，两箭头所形成的夹角在图形里面是这样画的。这俩角关系跟刚才可以说是一模一样，还是相加为 $180^\circ$，所以还是能写成这个关系。

但是有一种情况不一样，如果是一个朝里、一个朝外的情况，延长一下，这俩向量的夹角可就在这了。这 $\alpha$ 跟这个角是互补的，这个角又跟 $\theta$ 是互补的，相当于无论是 $\alpha$ 还是 $\theta$ 都跟同一个角互补，那么 $\alpha$ 与 $\theta$ 可就相等了。

分析的时候给大家分析了一、二、三，三种情况，但是角度关系只有一、二，两种情况。

到这还没完，还有好消息。角度情况虽然有两种，但是三角函数关系居然只有一种。因为最后这绝对值里面肯定是要放 $\sin\theta$ 或者是 $\cos\theta$ 的，只要看前后函数名变不变是不是就行了？无论是差整数倍的 $\pi$ 还是它俩相等，根据诱导公式，这两种情况前后应该都是不变函数名的，只有 $\frac{\text{奇数}\pi}{2}$，像 $\frac{\pi}{2}$、$\frac{3\pi}{2}$、$\frac{5\pi}{2}$ 才变。整数倍的 $\pi$ 跟相等情况根本不变名。

前面是 $\sin$，后面也写 $\sin$；前面是 $\cos$，后面照抄 $\cos$，就是这么简单。

所以对二面角大家就记住了：第一句话，$\sin$ 恒为正，$\cos$ 有正有负；但好消息是一定不变名。

大家可以把这三种不同角度放在一起想一下：线线角、线面角，还有二面角。前两个好求的点在于，无论是求 $\sin$ 还是求 $\cos$，恒为正，不需要做任何判断，直接大胆加绝对值。

从另外一个角度来讲，线线角跟二面角好求的点在哪？注意，它俩前后函数名不变。变不变名其实就是指绝对值里面、外边 $\alpha$ 跟 $\theta$ 函数名一不一样。这三种角度之间只有线面角函数名是变的。

回顾一下，就线面角比较特殊，$\sin$ 要变 $\cos$，$\cos$ 要变 $\sin$，别的大都不需要变。线线角是 $\sin$ 对应 $\sin$，$\cos$ 对应 $\cos$；二面角也一样，$\sin$ 对应 $\sin$，$\cos$ 对应 $\cos$。但线面角需要变函数名。

以上就是三种不同角度在用向量处理问题的时候的一些不同点。具体给大家举一个二面角的例子。

还是这 2021 年天津高考题，在求刚才线面角的时候已经讲过了。只不过现在提问变了，变成二面角的正弦值了。

把没用的擦一下。以 $A_1C_1$ 为交线，一个面是 $A_1C_1E$，就是刚才刚求完的面，法向量还放在这；另外一个面是 $A_1C_1A$。

蓝面的法向量已经求好了，再求一下粉面的法向量 $\vec{n}_2$。求的时候先选两个向量，这交线可以前后用两次，所以 $A_1C_1$ 要留下来，一会求法向量。另外一个选 $AC_1$ 也好，选 $AA_1$ 也好，其实都可以。$AC_1$ 是刚才的向量，所以干脆直接用这俩向量求法向量就可以了。如果没发现也没关系，用 $AA_1$ 也能求，一点也不难。今天就用刚写完的这俩向量求 $\vec{n}_2$。

设它是 $(x, y, z)$。首先这俩数量积一下：
$$2x + 2y + 2z = 0$$
两边都除以 $2$，即 $x + y + z = 0$。

下一个它俩又数量积：
$$2x + 2y + 0z = 0$$
$2x + 2y = 0$，那么 $x + y = 0$。

如果令 $x = 1$，那 $y = -1$。$x + y = 0$ 的话，$z$ 就一定等于 $0$。所以答案直接有了：$(1, -1, 0)$。有的时候传统方法其实更快，不需要非得记速算方法。

$\vec{n}_1$、$\vec{n}_2$ 算完之后，求 $\cos\langle\vec{n}_1, \vec{n}_2\rangle$：
$$x_1x_2 + y_1y_2 + z_1z_2 = 2 + 2 = 4$$
算模长，$\vec{n}_1$ 的模长是 $\sqrt{4 + 4 + 1} = \sqrt{9} = 3$；$\vec{n}_2$ 的模长是 $\sqrt{1 + 1} = \sqrt{2}$。因此最后是：
$$\frac{4}{3\sqrt{2}} = \frac{2\sqrt{2}}{3}$$

还没算完，要求的是二面角的正弦值。如果这角设为 $\beta$，它的正弦值 $\sin\beta$ 来看一下：二面角 $\sin$ 值恒为正，而且前后不变名，所以直接照抄，$\sin$ 对应 $\sin$。

刚才求完的是 $\cos$，现在要用的是 $\sin$，平方和是 $1$，所以用 $1$ 减去上面这数的平方：
$$\sqrt{1 - \left(\frac{2\sqrt{2}}{3}\right)^2} = \sqrt{1 - \frac{8}{9}} = \sqrt{\frac{1}{9}} = \frac{1}{3}$$
完美。

三种角度都给大家讲完了。这三种角度对应的三幅图大家多看看，多练练，其实蛮好记的：
第一，看某个角度的 $\sin$ 值或者 $\cos$ 值到底是加绝对值，还是绝对值前面要加正负号。只有二面角的 $\cos$ 值需要考虑正负，别的都是正的。
第二，考虑要不要变名。前前后后只有线面角需要变名，别的都不变名。一点都不复杂。
