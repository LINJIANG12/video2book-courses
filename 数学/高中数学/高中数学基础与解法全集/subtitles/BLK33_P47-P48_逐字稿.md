在正式讲诱导公式之前，我们先花两分钟时间简单给大家回顾一下什么是任意角的三角函数定义。

以前咱们求三角函数，是把一个角放在直角三角形里，用直角三角形三边的比例关系来表示一个锐角的三角函数值。但是现在我们知道，角不一定是锐角，角可以是任意的，它有始边，还有终边，这终边能来回转圈。所以如果我们想求除了锐角之外的任何一个角的三角函数值，那就得有一个新的定义了。

怎么说呢？我们发现每一个角它一定都有且仅有一条终边，这条终边跟一个单位圆（半径为 $1$ 的圆）有且仅有一个交点。角的大小就唯一能确定一个交点坐标。咱咋规定呢？我们规定这个点的横坐标 $x_0$ 的值就是 $\cos\alpha$，它的纵坐标就是 $\sin\alpha$。最后，纵坐标除以横坐标是它的 $\tan\alpha$。

因此在我们新的定义之下我发现，三角函数值变成坐标值了，那坐标就有正也有负。像第二象限的一个角，它的纵坐标（它的 $\sin$ 值）就一定为正，但是它的横坐标（它的 $\cos$ 值）就必须为负。三角函数的正负，它的符号取决于这角的终边在第几象限。

这就是在网络上大家经常说的“符号看象限”。符号指的是谁的符号？是三角函数值的正负，它们的正负要看这角的终边在第几象限。$\sin$ 值看的是纵坐标，纵坐标啥时候为正？当然在 $x$ 轴上方，一、二象限为正，三、四象限为负。$\cos$ 看的是横坐标，横坐标啥时候为正？在 $y$ 轴的右侧，一、四象限 $\cos$ 为正，二、三象限 $\cos$ 为负。最后，$\tan$ 咋看呢？我得既看 $y_0$ 也得看 $x_0$，结合起来。两者同号那就是正，两者异号那就是负。

这三幅图大家得把它们牢牢印在脑子里。宝贝们要熟练到什么程度？我随便问个问题，大家在两秒钟之内给出答案。比如说第三象限的 $\cos$ 值是正还是负？问我 $\cos$ 值，脑中马上画图，$\cos$ 就是 $x$ 值，$x$ 值一、四为正，二、三为负。问的是第三象限，那么很显然求完的答案必须得是一个负值。

我们这节课会大量地运用到这种正负判断，“符号看象限”这句话特别特别重要。以上就是我们所有的复习内容，那么接下来我们正式开始进入诱导公式的学习。

刚学的宝贝肯定会有一个疑问：啥是诱导公式？这诱导公式看着听起来好像不是那么正经。诱导公式它是用来干嘛的？一句话，诱导公式就是用来帮助我们求不同角的三角函数关系的。

以前我们只知道 $\sin\alpha$、$\cos\alpha$ 和 $\tan\alpha$ 这种同一个角三角函数之间的转换。但是现在经过这节课之后就不一样了，诱导公式能帮助我们建立起不同角度，比如说我把好好的一个 $\alpha$ 角度加个负号，或者加减整数倍的 $\pi$，或者加减 $\frac{1}{2}\pi$、$\frac{3}{2}\pi$、$\frac{5}{2}\pi$，加减二分之几 $\pi$。那么这些变化之后的角度和我原来这 $\alpha$ 之间，三角函数值究竟有什么关系、怎么转换，就是我们诱导公式的内容。

今天我们就一共学一、二、三，三组公式。

首先我们来看第一组，最简单的，把 $\alpha$ 前面加负号。先给大家结论，然后再给大家证明。

$\sin(-\alpha)$ 我可以直接把负号提出来，它是负的 $\sin\alpha$：
$$\sin(-\alpha) = -\sin\alpha$$

同样的，$\tan(-\alpha)$ 这个负号我也可以直接提出来：
$$\tan(-\alpha) = -\tan\alpha$$

但是跟它们不一样的是，$\cos(-\alpha)$ 跟 $\cos\alpha$ 之间是完全相等的：
$$\cos(-\alpha) = \cos\alpha$$

奇怪，为啥是这样的？我们所有的诱导公式都可以通过画图来推导。大家看，现在我们想研究 $\alpha$ 和 $-\alpha$ 的关系，那我先画个图，我随便画一个 $\alpha$。比如把 $\alpha$ 画在这，我姥姥都知道，你这么转是正的，$-\alpha$ 在哪？我得反着转，这是 $-\alpha$。

我们算三角函数值，看的就是交点坐标。很显然交点坐标一上一下完全对称。这两个点横坐标是一模一样的，横坐标一样意味着 $\cos$ 值就是一样的。纵坐标怎么样？纵坐标一正一负，长度是相等的，那就互为相反数，所以它们的纵坐标（它们的 $\sin\alpha$）这两个角一正一负，它们是互为相反数的。$\tan\alpha$ 就更简单了，$\sin$ 比 $\cos$，$\sin$ 比 $\cos$ 就是 $\tan$，只不过加了个负号而已。

因此第一组公式太简单了，大家就记住，$\cos$ 里面的负号可以直接去掉，$\sin$ 和 $\tan$ 里面的负号可以提出来。

举个最简单的例子，显现到考试都不考：$\sin(-75^\circ)$ 这个负号我直接提出来，是 $-\sin 75^\circ$。类似地，$\tan$ 的这个负号能不能提？也能提，它是 $-\tan 35^\circ$。中间这个 $\cos$，$\cos$ 负号可以直接去掉，我写成 $\cos 125^\circ$。是不是很简单？

那可能有宝贝想了，学这玩意有啥用？第一组公式大家虽然看着没有那么明显，但是它隐隐约约已经体现出来了，有一些我们看着不喜欢的角度、看着难受的角度，我可以把它转化成为我们喜欢的、看着舒服的角度，它能起到化简的作用。这一点在第二组和第三组公式里面大家会看得更明白。

接下来我们来看第二组诱导公式。这么多公式，肯定有宝贝担心这玩意需不需要背？不需要，别瞎担心。现在给大家讲的是帮大家理解公式，我们最后会帮大家记忆。这些公式让我硬背我都背不下来。

所以咱先来观察观察第二组诱导公式在讲什么。我发现它是一倍的 $\pi$ 加或者减 $\alpha$，它还有二倍的 $\pi$ 加减 $\alpha$。所以整个第二组公式研究的就是 $k\pi \pm \alpha$ 和角 $\alpha$ 之间的关系。你看最后落脚点是不是都是角 $\alpha$ 的三角函数值？那究竟这两种角它们的三角函数有什么关系、如何体现、怎么推导呢？我画图来推导。

选一个幸运儿，咱就推它。咋推？我还是先把 $\alpha$ 画出来。我随便画的，这些 $\alpha$ 其实在第几象限都行，我习惯就放在第一象限来推一下。$\alpha$ 我已经画好了，那我问大家，$\pi - \alpha$ 怎么回事？如果 $\alpha$ 是 $30^\circ$，$\pi - \alpha$ 就是 $180^\circ - 30^\circ = 150^\circ$。它俩应该是一个互补关系，一左一右是对称的。

两角终边都找到了，那我们想找三角函数就是找交点关系。交点关于 $y$ 轴对称，所以很显然纵坐标相等，$\sin$ 值就相等。$\cos$ 值长度虽然一样，但是一正一负，那我发现 $\cos$ 值就正好是互为相反数的。这不就推完了吗？

如果有的宝贝比较好奇，说别的我也想推推、我想试试，可以。每一个诱导公式大家都可以通过画这种图形来去分析。受时间限制我不给大家一个个推了，咱直接来看第三组公式。

又是这么一大坨。第三组公式研究的是啥？看好了，跟刚才类似但不完全一样，它研究的是 $\frac{\pi}{2} \pm \alpha$ 以及 $\frac{3\pi}{2} \pm \alpha$。所以像这种 $\frac{1}{2}\pi$、$\frac{3}{2}\pi$，未来还会有 $\frac{5}{2}\pi$。我们如何用一个表达式把它们概括起来呢？我们用 $\frac{k\pi}{2} \pm \alpha$ 来表示，其中这里的 $k$ 我们只取奇数 $1, 3, 5, 7, 9$，当然 $-1, -3, -5$ 也是可以的。我们现在讨论 $\frac{\text{奇数}\cdot\pi}{2} \pm \alpha$ 与 $\alpha$ 的关系。

我们在第一开始没有公式的时候，那我肯定还是通过画图来做。举个例子，再挑一个幸运儿，咱们挑这两个吧。我想看看这 $\frac{\pi}{2} + \alpha$ 跟 $\alpha$ 之间到底存在什么秘密，那我还是画图。

我刚才一直都是把 $\alpha$ 角画在第一象限去推导，大家可能觉得是不是只有第一象限满足呢？其实不是的，我把 $\alpha$ 角今天画在第二象限也一样。好，$\alpha$ 画完，我该画 $\alpha + \frac{\pi}{2}$ 了。

啥是 $\alpha + \frac{\pi}{2}$？那不就是 $90^\circ + \alpha$ 吗？我在 $\alpha$ 的基础上把它增加 $90^\circ$，我转 $90^\circ$。往哪个方向转角增大呢？我们知道逆时针转是在增大，顺时针转是在减小，所以我现在要把 $\alpha$ 加 $90^\circ$，就转到这，这是一个直角。这蓝色的边就是 $\frac{\pi}{2} + \alpha$ 的终边。

我想看这两个角三角函数值有啥关系，我把这交点的坐标咱得找到吧。找坐标咱得把它往坐标轴上做垂线，做一条垂线，再做一条垂线。有意思，这垂直，这垂直，这一条线上有一、二、三，三个垂直，这不一线三垂直模型，初中大家学的。

有啥意义呢？一点、一叉 $90^\circ$；一点、一叉 $90^\circ$；再来，一点、一叉 $90^\circ$。所以我发现上下两个三角形每一个角都相等，而且它的斜边还都是单位圆的半径，斜边也相等。这两个三角形是全等三角形，对不对？

全等就意味着短边短边相等，长边长边相等。但是大家别高兴太早，咱三角函数最关键的是看正负，对不对？如果第一个交点我设为 $(x_0, y_0)$，在这幅图里面大家自己看，$\alpha$ 角它的横坐标是 $x_0$，转化到下面就变成纵坐标了，对不对？当然很显然在第二象限里面，对应的这个横坐标 $x_0$ 必然是一个负值。那我比较庆幸的是啥呢？我在第三象限这里面，这个位置也是一个负值，所以我直接就找到了这个点的坐标，我不用加负号，它本身就是 $x_0$ 的位置。

接下来我们来看一看纵坐标怎么回事。刚才如果觉得横坐标讲得太快，咱们再来看一下纵坐标。这第一个交点它的纵坐标是 $y_0$，而且我明确地发现这纵坐标一定为正，它在原点的上方，对不对？好，那类似地，这一段是粉的，这段粉的是 $y_0$，那下面这段粉的是不是也是 $y_0$？没错，它的长度的的确确是 $y_0$。但是大家别忘了，这第三象限点它的横坐标必须得是负值吧？因此从坐标的角度，我这个点应该填 $-y_0$ 是比较合适的。

看图说话，这一点坐标咋写？横坐标是 $-y_0$，纵坐标这个点刚才说了是 $x_0$：$(-y_0, x_0)$。把没用的擦一擦。现在我要找三角函数关系，这角度的 $\sin$ 值等于这交点的纵坐标，纵坐标是 $x_0$。$x_0$ 是谁？$x_0$ 是第一个点的横坐标，是 $\cos\alpha$。所以第一个公式：
$$\sin\left(\frac{\pi}{2} + \alpha\right) = \cos\alpha$$

类似地，如果我取 $\cos$ 呢？$\cos(\frac{\pi}{2} + \alpha)$ 等于对应这个点的横坐标，横坐标是 $-y_0$。$y_0$ 是谁来着？$y_0$ 是角 $\alpha$ 的纵坐标，$y_0$ 是 $\sin\alpha$。所以非常显然 $-y_0$ 就是负的 $\sin\alpha$。这第二个公式这不就又推完了吗？
$$\cos\left(\frac{\pi}{2} + \alpha\right) = -\sin\alpha$$

这一页的公式，说实话咱通过图像上去看的话没有那么好看，没有那么明显，但的确每一个公式它都能画出来推。

现在交给我们的问题就是，这第二组跟第三组公式我怎么用、我怎么记？总不能死记硬背吧？所以咱先来找规律。

第一组公式是 $\frac{1}{2}\pi$、$\frac{3}{2}\pi$、$\frac{5}{2}\pi$，是二分之奇数 $\pi$。第二组公式它是 $\pi$ 的整数倍，是 $k\pi$（$1\pi, 2\pi, 3\pi, 4\pi$）。那这个 $k\pi$ 我可以怎么写呢？$k\pi$ 咱是不是其实能写成 $\frac{2k\pi}{2}$。我往刚才这个形式上去靠，都写成了二分之几 $\pi$。刚才二分之奇数 $\pi$，现在 $\frac{2k\pi}{2}$，$2k$ 是什么？$2k$ 这整体是偶数。比如这个 $\pi$ 我可以写成 $\frac{2\pi}{2}$，这 $2\pi$ 我可以写成 $\frac{4\pi}{2}$。

所以现在咱就齐了：$\frac{1}{2}\pi$、$\frac{2}{2}\pi$、$\frac{3}{2}\pi$、$\frac{4}{2}\pi$、$\frac{5}{2}\pi$、$\frac{6}{2}\pi$、$\frac{7}{2}\pi$。现在所有的二分之几几 $\pi$ 加减 $\alpha$ 的诱导公式，我全都能会写。那有啥规律呢？

我发现我们上面这组，当 $k$ 取奇数的时候，前面如果是 $\sin$，我化简完，不管正负，大家看化简完是不是都变成 $\cos$ 了？这个函数变了。类似地，如果化简之前是 $\cos$，现在化简完变成谁？反过来变成 $\sin$ 了。化简之前是 $\tan$，化简完之后变成也变了，$\cot$（cotangent）。这是啥呢？一个角的 $\cot$ 其实就是 $\frac{1}{\tan}$，$\tan$ 跟 $\cot$ 应该是互为倒数的。

我搞清楚了，咱们上面这组公式，二分之奇数 $\pi$ 的时候前后函数要变名，我们称之为叫“奇变”。但是反过来，当二分之几 $\pi$ 这上面是偶数的时候，取 $\pi$ 的整数倍（$1\pi, 2\pi, 3\pi, 4\pi, 5\pi, 6\pi$，无论是几倍 $\pi$），$\pi$ 的整数倍这只取偶数，前后变名吗？前面是 $\sin$，我后面还是 $\sin$；前面是 $\cos$，我后面还是 $\cos$；前面是 $\tan$，我后面居然还是 $\tan$。一句话总结，叫“偶不变”。

这里的“奇”和“偶”指的是啥？指的是 $\frac{1, 3, 5, 7, 9\pi}{2} \pm \alpha$，还是 $\frac{2, 4, 6, 8, 10\pi}{2} \pm \alpha$。当分子是奇数，前后函数名必变，$\sin$ 变 $\cos$，$\cos$ 变 $\sin$。当分子是偶数，前后函数名不变，前面写谁后面得照抄。这就是我们诱导公式的第一步：先判断函数名变不变。

光看这函数是谁，这诱导公式记完了吗？还没有，差在哪？我发现有的它是正的，有的它又是负的，一会儿正一会儿负。这正负能不能死记硬背呢？答案是不能，正负是不可以死记硬背的。那咋办呢？咱得知道是正还是负。所以我们只要发明一个方法能让大家判断出来正负就行了。

怎么判断？大家看。对于一个给定的诱导公式，我随便挑一个，这诱导公式它肯定是成立的。无论这 $\alpha$ 取什么值它总是成立的。$\alpha$ 只要是个角度，无论是正角、负角、锐角、钝角都成立，$\alpha$ 随便取值。所以大家首先要明白，这公式本身有没有负号，跟 $\alpha$ 角咱带什么值是没关系的。既然没关系，那我肯定怎么简单怎么带。我假设，我在推导公式的时候我假设：如果 $\alpha$ 是一个锐角。

为什么选锐角？大家马上就能明白。现在我在推导公式之前我照抄一遍，我只知道奇变偶不变。这是 $\frac{3}{2}$，$3$ 是奇数，二分之奇数 $\pi$，函数名是要变的，前面是 $\cos$，后面我要写 $\sin$。但问题是我要不要加正负号？我取正还是取负？这是我目前不知道公式之前面临的一个问题。那我们的解决方式就是假设 $\alpha$ 是锐角。

锐角的好处是啥？大家看，我们第一象限角，无论是横坐标还是纵坐标，无论是 $\sin$ 值还是 $\cos$ 值，是不是都为正？所以我把它想象成锐角的好处就在于这个地方，等式的右边目前这个部分它一定是恒为正的。换句话说，我为了判断前面有没有正负号，我只要看这左边是正是负是不是就行了？那左边是正是负看什么？符号看象限。

咱得找 $\frac{3\pi}{2} - \alpha$ 在哪，对不对？我们知道，刚才我们假设 $\alpha$ 是一个锐角了，那 $\frac{3\pi}{2}$ 是谁？$\frac{3\pi}{2}$ 应该是 $y$ 轴的负半轴。为啥？因为这是 $\frac{1}{2}\pi$、$\frac{2}{2}\pi$、$\frac{3}{2}\pi$。我现在的这个角基础上减一个锐角，它要变小。减完之后大家自己看，它跑第几象限去了？这角跑第三象限去了。那么问题来了，第三象限角的 $\cos$ 值是正不是负？这不是咱刚才刚刚问过的问题吗？是正还是负？明显是一个负值，对不对？符号看象限，这幅图不是让大家牢牢记住了吗？所以在这里面用起来。

第三象限角根据我的判断，这整体它一定是一个负值。负值怎么样呢？你前面是负的，后面是正的，那你为了调和这种正负，必须在这个地方强行加一个负号。这诱导公式咱就判断完了：
$$\cos\left(\frac{3\pi}{2} - \alpha\right) = -\sin\alpha$$

整个这就是我们记忆诱导公式的方法。每一个公式全都不用背，但是要通过我们的理解和规律去推。我们的口诀是：**奇变偶不变，符号看象限**。

举两个例子。现在给大家 $\frac{5\pi}{2}$，$5$ 是什么数？$5$ 是奇数，对不对？那奇就得变。变和不变指的是什么？指的是函数要不要变。前面是 $\sin$，我后面写谁？我写 $\cos$。

但是有一个问题，我这要不要加正负号？我要不要加我就看什么呢？我就看前面、后面这符号一不一致。我把这 $\alpha$ 想象成一个锐角。注意我是想象的，实际这 $\alpha$ 是啥都行。我为了推导公式把它想象成锐角，有什么好处？等号这边我不用去看了，它一定是正的，锐角的什么三角函数值都是正的。我只要看左边。左边正负看什么？符号看象限。咱看这个角度在第几象限不就行了吗？

首先我们来看 $\frac{5\pi}{2}$ 在哪：这是 $\frac{0}{2}\pi$、$\frac{1}{2}\pi$、$\frac{2}{2}\pi$、$\frac{3}{2}\pi$、$\frac{4}{2}\pi$、$\frac{5}{2}\pi$，这是 $\frac{5\pi}{2}$。我需要在它的基础上看好是要加 $\alpha$，对不对？我要加锐角。加，这个角要变大，我这么一加你看，这终边跑哪来了？跑第二象限了，对不对？第二象限的 $\sin$ 值正的负的？第二象限对应的应该是 $y$ 轴的正半轴，第二象限的 $\sin$ 值必然为正。那前后都是正的，那我还需要在这画蛇添足再加个负号不？就不需要了。

我通过这么两步就把诱导公式推导完了：第一步，奇变偶不变；第二步，符号看象限：
$$\sin\left(\frac{5\pi}{2} + \alpha\right) = \cos\alpha$$

如果大家觉得不爽，咱们就再来看第二个例子：$\cos(2023\pi - \alpha)$。哎呀这有的同学一看，这是不是奇数？这奇数是不是得变？宝贝们，不是。这奇和偶指的是二分之几 $\pi$ 上面这个数是奇还是偶。如果它是奇数，它肯定写成刚才一样的二分之几几 $\pi$；如果是偶数，它不会写什么 $\frac{2\pi}{2}$、$\frac{4\pi}{2}$，谁会这么给你写？它直接就把它转化成一个整数了。所以说整数倍的 $\pi$ 大家自己看，最后我化简完肯定这函数是不变的，前面是 $\cos$，后面我也写 $\cos$。

所以问题的关键点变为了：这个正负我是不是也得去看一看？它要么是正要么是负，只有一种情况是合理的。那怎么看呢？有的宝贝觉得这 $2023$，这数太大了太恶心了是不是？没关系，这数太大意味着我这加的这个 $k\pi$ 加得太多。我们知道对于一个给定的角来说，我把它加 $2\pi$ 是啥意思？是不是转一圈转回来了？我加 $2\pi$、加 $4\pi$、加 $6\pi$、加 $2k\pi$，它们的终边是一个。终边是一个意味着它们的三角函数肯定是同一个值吧。

因此我真的需要看什么 $2023\pi$ 这么大的数吗？不用，我把它在基础上减去 $2k\pi$。那我减多少比较合适？我直接就减 $2022\pi$，好不好？我减 $2k\pi$，减这么多，减 $2022\pi$ 之后它的终边是同一个位置。所以 $2023 - 2022$ 就是 $\pi - \alpha$：
$$\cos(2023\pi - \alpha) = \cos(\pi - \alpha)$$
这两个三角函数值肯定是完全相等的。

因此问题变成了：这两个角三角函数有啥关系？第一个方法因为太简单了，咱可以直接用推导是不是？说这是 $\alpha$，这是 $\pi - \alpha$。$\alpha$ 和 $\pi - \alpha$ 我要看它俩 $\cos$ 值啥关系，那肯定 $\cos$ 值一正一负。我们 $\cos$ 看的是横坐标，所以这里面我通过画图判断它一定得是负的。没问题吧？这是第一种判断方法，因为对于这个公式来说太简单了。

那接下来我们还可以继续利用我们刚才口诀的判断方法，也是完全可以的。第一步，奇变偶不变，刚才已经判断完了。$\pi$ 其实就是 $\frac{2\pi}{2}$，上面这数是个偶数，函数名不变，我只要看正负就好了。正负怎么看？我把 $\alpha$ 想象成一个锐角。想象成锐角的好处，这一个地方一定是正的，我只要看等号左边是正是负就行了。符号看象限，这 $\pi - \alpha$ 在第几象限呢？我们假设 $\alpha$ 是锐角的话，那么 $\pi$ 减去一个锐角它在第二象限。第二象限 $\cos$ 值是一个负值，所以一负一正，为了让这公式成立，那我只能在前面加负号：
$$\cos(2023\pi - \alpha) = -\cos\alpha$$

这就是诱导公式的快速判断方法。这里面每一个公式我都不记，但是我们都得会现推。大家第一开始推的时候可能会稍微有点慢，但是大家今天推、明天推，一周过后，稍微慢一点的同学要保证在 $10$ 秒钟之内推完，快的宝贝们得在 $5$ 秒内推完。因为诱导公式其实是一个蛮重要的公式，它能告诉我们不同角度之间它们的三角函数关系，我们能把一个看着好复杂的一个角给它转化成一个我们已知的、我们会做的一个角度。

光说不练假把式，咱光会推导没用，咱得会做题。我们来看看题目里面它怎么考。

在正式做高考题和模拟题之前，我先给大家出一个，在最后帮大家记忆一下公式。

已知 $\sin 165^\circ = \frac{\sqrt{6}-\sqrt{2}}{4}$，这是白给我条件了，给我这条件让我利用诱导公式来求出 $\cos 255^\circ$。那我一看这两个角一样吗？$165^\circ$、$255^\circ$，我姥姥都能看出来它是不一样的，所以它是不同角的三角函数关系。不同角三角函数关系咱现在就只会啥呢？就只会诱导公式。所以大概率这两个角之间它差的要么是二分之奇数 $\pi$，要么它差整数倍的 $\pi$。

那我们来算一算。我一看，$255^\circ$ 跟 $165^\circ$ 差多少？两者一减：
$$255^\circ - 165^\circ = 90^\circ$$
$90^\circ$ 那不正好差 $\frac{\pi}{2}$ 吗？

因此它让我求的是 $\cos 255^\circ$，我不写 $255^\circ$，我把 $255^\circ$ 写成 $90^\circ + 165^\circ$：
$$\cos 255^\circ = \cos(90^\circ + 165^\circ)$$
太好了。所以 $90^\circ$ 加上一个角度，诱导公式怎么写呢？奇变偶不变，$90^\circ$ 是 $\frac{\pi}{2}$，这分子是奇数，奇要变，所以把 $\cos$ 写成 $\sin$，$165^\circ$ 不动。

最后一个问题，前面填正号填负号我怎么看？符号看象限，我们要去看这角在第几象限。这里面注意了，我们刚才怎么说的？很多同学在这容易错。我们现在要做的是推公式，我要把公式的正负号搞定。这公式本身跟这个角的值是多少、是锐角还是钝角没关系。我知道 $165^\circ$ 它不是锐角，但是我们在推导公式的时候要把它想象成一个锐角，这点非常重要。好处就一个，就是等号右边这正负号跟前面正负号完全一致。

$90^\circ$ 加锐角脑中一想图，$90^\circ$ 加上一个小锐角很显然这角应该在第二象限。第二象限的 $\cos$ 值应该是负值，所以咱最后得加负号：
$$\cos(90^\circ + 165^\circ) = -\sin 165^\circ$$
因此最后答案应该等于：
$$-\frac{\sqrt{6}-\sqrt{2}}{4} = \frac{\sqrt{2}-\sqrt{6}}{4}$$

总结一下，这 $\alpha$ 的取值是任意的。这 $\alpha$ 可以取 $30^\circ$，可以取 $60^\circ$，可以取 $160^\circ$，取谁都行。但是我在推导的时候我把 $\alpha$ 想象成锐角，这样比较好推。因为整个公式不会因为 $\alpha$ 的范围变化公式变了，公式是永远不变的。

今天我们以一个小小综合题作为今天视频的结尾。整个题目就一个条件，就是这个等式，然后让我求另外一个式子的值。那我一看这式子里面有 $\theta + \frac{\pi}{2}$，有 $\frac{3\pi}{2} - \theta$，有 $\frac{\pi}{2} + \theta$，有 $\theta - \pi$，太恶心了。但是能不能化简？咱能通过诱导公式来化简。

第一个式子：$\sin(\theta + \frac{\pi}{2})$。$\frac{\pi}{2}$ 是二分之奇数 $\pi$，函数名要变，$\sin$ 变成 $\cos$。具体是正是负，我想象一下，$\theta$ 如果是锐角的话，$\frac{\pi}{2} + \text{锐角}$ 在哪？$\frac{\pi}{2}$ 加一个小的锐角第二象限，第二象限的 $\sin$ 值看纵坐标，纵坐标为正，所以诱导公式用起来这为正：
$$\sin\left(\theta + \frac{\pi}{2}\right) = \cos\theta$$

第二项：$\sin(\frac{3\pi}{2} - \theta)$。$\frac{3\pi}{2}$ 显然它是一个二分之奇数 $\pi$，前后名咱得变，前面是 $\sin$，我得变成 $\cos$。具体是正是负怎么看？我还画图。我给大家是用手画的，大家这个图得在脑子里面自己想，别再动手画了。$\frac{3\pi}{2}$ 在 $y$ 轴负半轴，减 $\theta$ 这个角要变小，终边跑第三象限去了。第三象限的 $\sin$ 值它是负的，所以我们这符号就填个负号：
$$\sin\left(\frac{3\pi}{2} - \theta\right) = -\cos\theta$$

我们在假设 $\theta$ 是一个锐角的情况下，我们化简完这式子的正负号仅跟前面这式子的正负号有关。前面是正我这就填正，前面是负我这就填负，很简单。

再来判断两个。$\frac{\pi}{2} + \theta$，又是二分之奇数 $\pi$，我都讲烦了。函数名得变，$\sin$ 变成 $\cos$。正的负的我来看，$\frac{\pi}{2}$ 加上一个小锐角，它的 $\sin$ 值应该为正，正号加上去。其实真正大家掌握了这个方法之后，判断起来其实非常快。

最后，$\tan(\theta - \pi)$ 这个大家怎么看呢？那其实就是 $-\pi + \theta$，对不对？$-\pi$ 是 $\pi$ 的整数倍，别管正的负的，只要是 $\pi$ 的整数倍，前后函数名不变，前面是 $\tan$ 我还是 $\tan$。紧接着正的负的？这是 $0$，$-\pi$ 在这……

我在 $-\pi$ 的基础上加一个 $\theta$，我把 $\theta$ 想象成一个锐角，它跑第三象限去了。第三象限的 $\tan$ 值应该是一个正值，正号，加上。

所以通过这个诱导公式的变换，我发现整个这道题目能化简。已知前面不动，这个写成 $\cos$，后面也不动，最后一项改成减 $2\cos$。让我求什么呢？$\frac{2 + \sin\theta \cos\theta}{1 - \tan\theta}$。来看看。

前面后面这个式子长得都够恶心，先来看看这个条件怎么化简吧。这一项二次的，这一项 $\sin$ 乘 $\cos$ 也是一个二次的，后面只是一个单独的 $\sin$ 和 $\cos$ 都是一次的。这玩意儿咋化简呢？我一看前两项，好像每项都有 $\cos$ 对不对？我先试着把它提出来：$\cos\theta(\cos\theta - 2\sin\theta) =$ 后面提一个 2，是 $2(2\sin\theta - \cos\theta)$。

$\cos\theta - 2\sin\theta$ 与 $2\sin\theta - \cos\theta$，这俩其实就差一个负号对不对？所以如果我把它移项，减 2 等于 0 的话，我把它提出来。咱提出来一个 $\cos\theta - 2\sin\theta$，粉的都提出来，剩余的这个 $\cos$ 不是减 2，是加 2，最后等于 0。所以两项相乘等于 0，这一化简因式分解其实就是。要么第一项是 0，要么第二项是 0。第一项是 0 意味着 $\cos\theta = 2\sin\theta$。如果我把 $\cos$ 除过去的话就意味着 $\tan\theta = \frac{1}{2}$。那第二项如果是 0 的话，意味着 $\cos\theta = -2$。大家来自己想一下，$\cos$ 能是 -2 不？啥是 $\cos$？$\cos$ 是单位圆上点的横坐标。单位圆它的半径是 1，横坐标、纵坐标它最大值都是 1，最小值都是 -1，所以无论是 $\sin$ 还是 $\cos$，它的值域是固定的，永远在正负 1 之间动，去不了 -2 的，所以这个肯定是不对的。

因此前面这么一大坨式子，经过化简之后我发现，它就在告诉我 $\tan\theta = \frac{1}{2}$，太舒服了。所以已知 $\tan$ 是 $\frac{1}{2}$，那赶紧代成 $\frac{1}{2}$ 吧，还等啥呢？$1 - \frac{1}{2} = \frac{1}{2}$，乘上来就变成了 $2(2 + \sin\theta \cos\theta)$。

最后一步了。这题咱能不能算，就看 $\sin\theta \cos\theta$ 都能不能求出来。第一个方法，我已知 $\tan$，我当然可以把 $\sin$ 和 $\cos$ 都求出来。这是我们上一个视频的内容，我们已知 $\sin^2\theta + \cos^2\theta = 1$，我们还已知 $\tan\theta$ 是 $\frac{\sin\theta}{\cos\theta}$，俩未知数俩方程一定可以解。但是我们知道这是二次方程，它至少有两组解，哪组解合适还是都要，咱得去判断，比较麻烦，所以我们可以尝试用另外一个方法。

已知 $\tan$ 想求这一项，大家难道什么都想不到吗？别的咱都不动，咱把 $\sin\theta \cos\theta$ 想象成一个分数，它除了一个 1。谁是 1？咱可以把 1 写成 $\sin^2\theta + \cos^2\theta$ 吧，这里面可以运用 1 的代换。写完有啥好处？分子 $\sin\theta \cos\theta$，大家想象成 $x \cdot y$，它是一个二次项；这也是二次项，这也是二次项。分子分母每一项次数都一样，齐次式可以化简呀，我把分子分母每一项都除以 $\cos^2\theta$。第一项除以 $\cos^2\theta$ 就变成了 $\frac{\sin\theta}{\cos\theta}$，就是 $\tan\theta$；第二项除以 $\cos^2\theta$，$\frac{\sin^2\theta}{\cos^2\theta}$ 就是 $\tan^2\theta$；第三项除以 $\cos^2\theta$ 就是 1。

因此化齐次式的这个做法，不需要真的把 $\sin$、$\cos$ 都求出来，咱直接把 $\tan\theta = \frac{1}{2}$ 代进来就好了。$\frac{\frac{1}{2}}{\frac{1}{4} + 1}$，最后答案 $\frac{24}{5}$，完美。

这就是今天给大家讲的所有有关诱导公式的内容。什么是诱导公式来着？它研究的是不同角的三角函数关系。什么样的不同角？怎么不同啊？它是有先决条件的：要么是 $-\alpha$，要么是整数倍的 $\pi \pm \alpha$，要么是 $\frac{\text{奇数}\pi}{2} \pm \alpha$。这三组公式我们都给大家推导了，都可以利用画单位圆找坐标的方式去推。
