# 导数·不等式证明与恒成立

## 题型三分与求解链路

### 三种题面长相

* **不含参数的不等式**

    * > **定义**：题面里除 $x$ 外没有任何字母，要求证明式子恒大于零或恒小于零。

    * 主流方法：直接构造函数求导，把它化归为最值问题。

* **含参数且给了参数范围**

    * > **定义**：函数里除 $x$ 外还有一个参数 $a$，题干写明 $a\ge 1$、$a\le 2$ 之类的范围，要求证明不等式。

    * 主流方法：变换主元，把参数消掉后掉回第一类题。

* **含参数但不给范围（恒成立求范围）**

    * > **定义**：题面说某不等式恒成立，反求参数的取值范围。

    * 主流方法：直接分类讨论、分离参数、端点效应与必要探路、数形结合。

| 类型 | 参数 | 给不给范围 | 主流方法 |
| :--- | :--- | :--- | :--- |
| 不含参数 | 无 | —— | 直接构造函数求导（化成最值问题） |
| 含参数 | 有 | 给了 | 变换主元，把参数消掉 |
| 恒成立求范围 | 有 | 不给 | 分类讨论 / 分离参数 / 端点效应 |

### 求证前的翻译

* 证 $f(x)>0$ 等价于证 $f$ 的最小值大于零；证 $f(x)<0$ 等价于证 $f$ 的最大值小于零；证 $f(x)\ge 0$ 等价于最小值大于等于零。
* 翻译完条件之后，"求参数范围"就自动变成"求某个函数的最值"，这条线索贯穿全部恒成立题型。
* 连等式 $A<B<C$ 要拆成左右两个不等式分别证，"挣两个"。
* 严格与不严格的差别只看最值点能否取到：单调递增函数在左端点 $x=0$ 取最小值，若定义域是 $x>0$ 就取不到，只能写严格大于；$x$ 能取到 $-1$ 之类时最值取等号，结论要写成大于等于。

### 固定动作链

    ```text
    移项，把含 x 的项放到一边
        → 两大坨相乘
        → 有 ln x 就尽量把 ln x 单独放一边
        → 构造函数 → 求导 → 定单调 → 找最值
    ```

* > **提示**：简单题直接做；稍微难一点的先变形，把式子变简单再进这套流程。

## 不含参数的不等式证明

### 等价于最值问题

* 例：$x>0$ 时证 $(x-2)e^x+x+4>0$。设 $f(x)=(x-2)e^x+x+4$，则 $f'(x)=(x-1)e^x+1$，$f''(x)=xe^x>0$ 说明 $f'$ 单调递增；带特殊值 $f'(0)=-1+1=0$，故 $0$ 右侧 $f'$ 恒正、$f$ 递增，$f(x)>f(0)=2>0$。
* > **提示**：判断出导函数是单调函数后，它的图像就能画；画图只需带**能定号的那一两个点**，通常带定义域的端点值或零点附近的值。

### 导函数正负定不了就再求导

* 一阶导正负判断不了时的第一反应是再求一次导，不动脑子的方法。
* 例：$0<x<1$ 时证 $x-x^2<\sin x<x$。左半边 $f(x)=\sin x-x+x^2$，$f'(x)=\cos x-1+2x$ 正负不定，$f''(x)=2-\sin x>0$ 恒成立，$f'(0)=0$，故 $f$ 递增、$f(x)>f(0)=0$；右半边 $g(x)=\sin x-x$，$g'(x)=\cos x-1\le0$，$g$ 递减、$g(x)<g(0)=0$。
* > **提示**：三角函数项正负看不出时，用 $\cos x\in[-1,1]$、$\sin x\le 1$ 这类粗界配合同号项相加，常能一步定死二阶导的符号。

### 对数与指数的分流处理

* **对数单身狗，指数找朋友**

    * > **定义**：含 $\ln$ 的式子越与其他项缠在一起求导越复杂，必须先做等价变形把 $\ln$ 单独拎出来；指数 $e^x$ 与别项混在一起求导总能求，且常常越求越简单。

    * 例：$x>1$ 时证 $1<\dfrac{x-1}{\ln x}<x$。左边因 $\ln x>0$ 乘过去，除以 $x$ 得 $\ln x-x+1<0$，其导为 $\dfrac1x-1<0$，递减、$F(1)=0$，二阶导都不必求；右边得 $G(x)=\ln x+\dfrac1x-1>0$，$G'(x)=\dfrac{x-1}{x^2}>0$，递增、$G(1)=0$。

    * 例：$x>0$ 时证 $\dfrac{(x+2)\ln(x+1)}{2x}>1$。先除以正数 $\dfrac{x+2}{2x}$ 得 $\ln(x+1)>\dfrac{2x}{x+2}$，移项设 $g$，$g'(x)=\dfrac1{x+1}-\dfrac4{(x+2)^2}$ 通分后分子是 $x^2$，即 $g'(x)=\dfrac{x^2}{(x+1)(x+2)^2}>0$，递增、$g(0)=\ln1=0$。

* **通分化简时先别急着乘开**

    * > **提示**：分式求导得到"上导乘下减上乘下导"之后，先看两项有没有公因式，能提出公因式就比全部乘开更省事。

    * 例：$h(x)=\dfrac{x^2-2x}{x-\ln x}$ 的导数为 $\dfrac{(x-1)(2x-2\ln x+2)}{(x-\ln x)^2}$，提出 $x-1$ 即可，不必展开成四项对四项。

### 自变量为正整数时：换元与取对数

* 上下都是自变量的幂指函数（$\left(\dfrac{n}{n+1}\right)^{n+1}$）既不是幂函数也不是指数函数，求导法则没有学过，必须**两边取对数**。
* 自变量取正整数时图像是一串分立的点，**导数在其中没有意义**；处理办法是另起炉灶把 $n$ 换成连续变量 $x$，再用换元把式子降下来。
* 例：证正整数 $n$ 满足 $\left(\dfrac{n}{n+1}\right)^{n+1}<\dfrac1e$。取对数得 $(n+1)\ln\dfrac{n}{n+1}<-1$，令 $t=\dfrac{x}{x+1}=1-\dfrac1{x+1}\in\left[\dfrac12,1\right)$，化为 $\ln t<t-1$。
* > **结论**：$\ln t<t-1$（$t>0$）当且仅当 $t=1$ 取等，它就是 $y=\ln x$ 在 $(1,0)$ 处的切线 $y=x-1$；能事先确定 $t$ 取不到 $1$ 时可放心写严格不等式。
* 该结论可直接背用；取 $n=2024$ 即得 $\left(\dfrac{2024}{2025}\right)^{2025}<\dfrac1e$。

## 变换主元

### 使用条件与决策树

* **变换主元（Change of main variable）**

    * > **定义**：不把 $x$ 看成变量，反而把该看成参数的东西当成真正的变量；因为 $a$ 本身也在变，把它升格为自变量后，含 $x$ 的部分整体退化成系数。

    * 触发条件三条：式子里有参数；题目给了参数取值范围；**该参数在不等式里只出现一次、形式单一**。

    * > **易错点**：第三条最容易被忽略也最致命。参数一旦出现两种以上形式（同时有 $a$、$a^2$、$\ln a$、$e^a$），变换后并不比原来简单，就不要再变换。

```text
              拿到"含参数的不等式证明"
                          │
              参数 A 有没有给定取值范围？
                    ／            ＼
                  没有              有
                   │                │
            恒成立求参数范围     A 在式子里出现几次？
            （另一套方法）      ／        ＼
                             一次          多次
                              │              │
                        形式是单一的吗？   形式多样？
                              │              │
                         变换主元        换了也看不清
                    （斜率 ±，最值在     → 回归本质：把 X
                     参数区间的端点）     当自变量，参数当常数
                              │
                    参数被彻底消掉，
                     掉回第一类题
```

### 落地步骤

* 把式子看成关于 $a$ 的一次函数 $g(a)=k(a)\,a+\text{常数}$，先判系数 $k$ 的正负定出单调性。
* 单调性确定后，用题目给的参数范围取端点值，得一个**不含参数**的新函数，再按第一类题求导做。
* 例：$a\ge 1$ 时证 $f(x)=\dfrac{ax^2+x-1}{e^x}+e>0$。乘 $e^x$ 化为 $ax^2+x-1+e^{x+1}>0$，把它看成关于 $a$ 的一次函数，斜率 $x^2\ge0$（$x=0$ 单独验证，此时 $f(0)=e-1>0$），故关于 $a$ 递增，最小值在 $a=1$ 处，参数消失后剩 $h(x)=x^2+x-1+e^{x+1}$；$h'=2x+1+e^{x+1}$，$h''=2+e^{x+1}>0$，带特殊值 $h'(-1)=0$ 定出 $x=-1$ 为最小值点，$h(-1)=0$，故 $h(x)\ge0$。
    * > **易错点**：结论是 $\ge$ 而不是 $>$。$x=-1$ 是能取到的，函数在那里正好与 $x$ 轴相切，抄题时等号容易漏。
* 例：$a\le2$、$x>1$ 时证 $f(x)=a(x-1)+1-\ln x-e^{x-1}<0$。斜率 $x-1>0$ 关于 $a$ 递增，最大值在 $a=2$，参数消失后得 $h$，$h'=2-\dfrac1x-e^{x-1}$ 正负不定，$h''=\dfrac1{x^2}-e^{x-1}$ 单调递减（减函数减增函数）、$h''(1)=0$，配 $h'(1)=0$ 判定 $h'<0$，$h$ 递减且最大值 $h(1)=0$，因 $x>1$ 取不到 $1$，故严格小于零。
* 另一条收尾链路：变换主元后若 $x$ 被消掉，只剩一个关于 $a$ 的不等式，再对 $a$ 求一次导即可。例 $a>0$ 时 $f(x)=a^2+ae^x-x>2\ln a+\dfrac32$ 恒成立，$f'=ae^x-1$ 零点 $x=\ln\dfrac1a$，最值代回化归为 $G(a)=a^2-\ln a-\dfrac12>0$，$G'(a)=\dfrac{2a^2-1}{a}$ 零点 $a=\dfrac{\sqrt2}{2}$，最小值 $\dfrac12\ln2>0$。
    * > **提示**：该题不适合变换主元，因为 $a$ 出现三次且形式多样，并且 $a>0$ 的端点 $0$ 代不进 $\ln 0$。

## 恒成立求参数范围的方法谱系

### 方法选型

* 分离参数法：小题里最常用，最不用动脑子。
* 分类讨论：大题里的主力，最万能。
* 端点效应与各种"点效应"：统称必要探路，大题里也常见。
* 数形结合：有些题直接要求证明恒成立。
* > **结论**：分类讨论是最万能的，应该在掌握其他所有方法之前先掌握它；别的"奇技淫巧"是它之上的加速器。

### 存在与恒成立、单调性条件的翻译

* **存在成立**与**恒成立**原理相同，差别落在第一步：分离参数后，"存在"只要求最小值，"恒成立"要求最大值（或反之），具体看不等号方向。
* > **提示**：分离参数以后，第一个动作永远是先问自己"要的是最值还是极值"。

    | 已知 | 推出 |
    | :--- | :--- |
    | $f'(x)>0$ | $f(x)$ 单调递增 |
    | $f'(x)<0$ | $f(x)$ 单调递减 |
    | $f(x)$ 单调递增 | $f'(x)\ge 0$（不是 $>0$） |
    | $f(x)$ 单调递减 | $f'(x)\le 0$（不是 $<0$） |

    * > **易错点**：$y=x^3$ 在原点处导数为零却是单调递增的，所以由"单调递增"反推必须写成大于等于零。

* 题面虽不写"恒成立"，但"当 $x\ge\cdots$ 的时候"这类条件一旦给出，就是对定义域内一切 $x$ 成立。

### 分离参数与除数变号

* 分离参数的前提与变换主元同源：参数虽可能出现两次，但形式上只有一种，能合并、能单独拎出来。
* > **易错点**：$h(x)=\dfrac{x^2-2x}{x-\ln x}$ 是分式函数，$h(1)=\dfrac{-1}{1}=-1$ 是负的，不要想当然认为分式函数值恒正。
* **除数会变号时先分类，再谈最值**：

```text
分母含因子 (x − b)，零点为分界点 x = b

  情形一   x = b      分母为零 → 左边不含 k → 对 k 不产生任何限制
     │
  情形二   x > b      除数为正 →  k ≥ h(x)  →  取 h 的最大值
     │
  情形三   x < b      除数为负 →  k ≤ h(x)  →  取 h 的最小值
            （且落在定义域内）
```

    * 无论上类下类，研究的都是同一个函数本身，只是分别要最大值与最小值。
    * > **结论**：两个约束 $k\ge\max$ 与 $k\le\min$ 要取交集；交集为空说明翻译出了问题，要回头查。
    * 例：$f(x)\le k\,g(x)$ 恒成立，两约束给出 $k\ge1$ 且 $k\le e^2$。

* 分离参数后若分式求导化简出来，符号往往最终压在**某一个因子**上，该因子的零点就是单调性分界。

### 分类讨论与类二次函数四步

* **适用场景**：参数出现两种及以上形式（既有 $a$、$e^a$、$\ln a$、$a^2$），无法把 $a$ 单独放到不等号一边。

* **拆式子的标准流程**：求导（复合函数先对内层求导再乘内层导数）→ 判断能否因式分解 → 按根定号 → 按零点与定义域分类。

* **类二次函数四步法**（式子形如 $(e^x+b)(e^x+c)$，把 $e^x$ 当整体当二次函数看，用穿针引线分析）：

    1. **定开口**：把 $e^x$ 当成一个整体，看开口朝上还是朝下。
    2. **求零点**：把两个因子分别置零。
    3. **判定义域**：两个根有没有落在题给定义域内——无根、有一个根、两个根都在。
    4. **比大小**：两个根都在定义域内时还要比较谁在左谁在右。

* 例：$f'(x)=(2e^x+a)(e^x-a)$。根 $2e^x=-a$ 只在 $a<0$ 时存在，根 $e^x=a$ 只在 $a>0$ 时存在，于是按 $a=0$、$a>0$、$a<0$ 分三类。
    * $a=0$：导函数为 $2e^{2x}$ 恒正，原函数在整个定义域递增。
    * $a>0$：第一因子恒正，只看 $e^x-a$，导函数先负再正，原函数先减后增。
    * $a<0$：第二因子恒正，只看 $2e^x+a$，导函数先负再正。
    * > **提示**：第二问求最小值直接沿用第一问分好的三类，不要重新讨论——参数类型不同，图像形状与最值位置就都定了。
    * 三类各自在前提条件下解出范围后**取并集**，例中答案 $a\in\left[-2e^{\frac34},\,1\right]$。

* > **易错点**：分类讨论最后一关是取交集还是取并集。各情况解出的范围彼此独立、都能成立，一般取**并集**；而题给的硬性前提（如 $a>2$、$a<0$）必须与每一类解出的范围取**交集**。两个方向搞反答案整个错。

* **两个零点都在定义域内时按根的位置再分类**，例 $h'(x)=(2x-3)(e^{2x-a}-1)$ 的零点是 $\dfrac32$ 与 $\dfrac a2$，$a>2$ 时两点都在 $x\ge1$ 内，按 $a>3$、$2<a<3$、$a=3$ 三类；$a=3$ 是两根重合，导函数恒为正，原函数一直递增，这一类不能漏。
    * > **提示**：故意把指数配成 $e^{(\text{线性})}-1$ 的形式，$e^u-1$ 与 $u$ 同号，一步锁死符号。
    * > **提示**：判断乘积图像形状最省事的办法是"看远端"——令 $x$ 取极大值判断这一项的正负，据此定开口方向。

### 恒成立不必分出谁是真最小值

* > **结论**：恒成立意味着定义域上每一个点都得满足要求。当多个候选极值点难以排序时，**不必非分出谁是真正的最小值**；把每个候选点的函数值都写出来、逐个要求非负，再取这些约束的交集，完全等价而且更省事。

    * 例：$h(x)=(x-2)e^{2x-a}-x^2+3x-1\ge0$ 在 $x\ge1$、$a>2$ 上恒成立，三个约束分别是端点处 $e^{2-a}\le1$（$a\ge2$）、固定零点 $\dfrac32$ 处 $e^{3-a}\le\dfrac52$（$a\ge3-\ln\dfrac52$）、随 $a$ 变动的零点 $\dfrac a2$ 处化简成 $-(a-2)(a-6)\le0$（$a\in[2,6]$）；三类取交集后再并集，得 $a\in\left[3-\ln\dfrac52,\,6\right]$。

    * > **易错点**：不要被"前提是 $a>2$ 可结果里出现 $a=2$"绊住。意思是凡大于 $2$ 且满足约束的 $a$ 都成立，$2$ 本身取不到反而更稳妥。

### 翻译陷阱

* **"当且仅当"是双向命题**，等价于左边成立推出右边、右边成立推出左边。
* **"某不等式成立当且仅当 $x\in[c,d]$"的读法**：该不等式的解集恰是 $[c,d]$。连续函数保证至少有一个端点取到边界值，但**定义域端点能不能取到必须先看一眼**——取不到的端点（如分母为零）不能拿来当边界。
    * 例：$f(x)=\ln x-\ln(2-x)+ax+(1-x)^3b$ 在 $x\in(0,2)$ 上，若 $f(x)>2$ 当且仅当 $x\in[1,2]$。$x=2$ 处分母为零取不到，且 $x\to2^-$ 时 $f(x)\to+\infty$，所以只能由 $f(1)=2$ 定出 $a$。
* **求对称中心的三步**：凑出定值 → 横坐标取两个自变量中点 → 纵坐标取定值的一半。
    * 例：$f(x)+f(2-x)=2a$，故对称中心 $(1,a)$；含 $x$ 与 $2-x$ 这种结构时中点基本锁死在 $1$ 上。
* > **注意**：把 $\ln x-\ln(2-x)$ 合并成对数的商会改变定义域（原来分子分母同号即可，合并后要求都为正），但求导结果一样，心里有数即可。
* **求导后的分式只保留对称轴**：定一个关于 $1$ 对称的二次函数在讨论区间里的正负，算对称轴处的函数值比算判别式更简单。例中 $b<0$ 时二次函数顶点在对称轴 $x=1$ 处，值为 $3b+2$。

## 端点效应

### 地基与剥层

* **端点效应（Endpoint effect）**

    * > **定义**：恒成立 $\Rightarrow$ 端点函数值满足题意的同号要求；这是第一层，也是后面所有层的地基。

    * 典型长相：函数又长又复杂、中间夹着一个参数，对 $x\ge x_0$（或含 $x_0$ 的区间）恒成立，反求参数范围。

* **剥套娃规则**：端点代进去若正好卡在临界（等于零），就去求一阶导；若一阶导在端点也等于零，继续求二阶导；**以此类推，直到不再临界为止**。

```text
   题意：  f(x) ≥ 0 ， ∀ x ≥ x0
        │
        ▼
  第 1 层：端点代进去         f(x0) = ?
        │  f(x0) = 0    ← 正好卡在临界
        ▼
  第 2 层：端点处一阶导       f'(x0) = ?
        │  f' ≥ 0 才递增；f' < 0 就出现负值，不符合题意
        │  f'(x0) = 0   ← 又卡在临界
        ▼
  第 3 层：端点处二阶导       f''(x0) = ?
        │  f'' ≥ 0 → f' 递增 → f' > 0 → f 递增 → 达标
        │  f'' < 0 → 链条整体反过来：f' 递减 → f' < 0
        │             → f 递减 → 出负值
        ▼
        终于得到一个只含 a 的式子 → a 的取值范围（先猜着）
```

* **推理链条**：$f''(x_0)\ge0 \Rightarrow f'$ 递增 $\Rightarrow$ $x_0$ 附近 $f'>0 \Rightarrow f$ 递增 $\Rightarrow$ 满足恒非负。反向链条同理。
* 例：$x\ge0$ 上某含 $\ln(1+x)$ 的不等式恒 $\ge0$。$f(0)=0$，$f'(0)=0$，$f''(x)=\dfrac{-2ax-2a-1}{(x+1)^2}$，代 $0$ 得 $-2a-1\ge0$，即 $a\le-\dfrac12$。
    * > **结论**：一般情况下约八成题目靠端点分析得到的范围就是最终答案。

### 猜测到证明的两步闭环

* 端点分析只能保证端点及其附近满足题意，离端点很远的点**必须证**。卷面上写"证明它的充分性"即可。
* **证明手段是变换主元**：把 $a$ 当自变量、$x$ 当参数，多数题此时 $f$ 是关于 $a$ 的一次函数；配合端点效应给出的 $a$ 范围，取最不利的那一个端点值代入，参数消失，剩下的就是一道普通导数题。

```text
   带参数的 f(x)
        │  ① 端点效应（剥套娃 f、f'、f''……）
        ▼
   参数 a 的取值范围            ← 这只是「猜」
        │  ② 变换主元：把 a 当成真正的变量
        ▼
   f 原来是关于 a 的单调函数（多数题都是）
        │  ③ 把求出的 a 范围用上（取最不利的那一个端点）
        ▼
   不含参数的 g(x)
        │  ④ 此时就是一道普通的导数题：求导 / 变形都用得上
        ▼
   充分性成立 → 答案确认
```

* 例：上题 $f(x)=\ln(1+x)-x-a\cdot x\ln(1+x)$ 在 $x\ge0$ 上关于 $a$ 单调递减（系数 $-x\ln(1+x)$ 非正），故 $f(x)\ge g(x)=\left(1+\dfrac{x}{2}\right)\ln(1+x)-x$；$g'(x)=\dfrac12\ln(1+x)+\dfrac{1+\frac x2}{1+x}-1$，$g''(x)=\dfrac{x}{2(1+x)^2}\ge0$，配合 $g'(0)=g(0)=0$ 得证。
* 例：$x\ge1$ 上某不等式恒 $\le0$，把 $a$ 单独写出来后 $f(1)=1+a\le0$ 直接给出 $a\le-1$，连一阶导都不用求。证充分性时 $f$ 关于 $a$ 单调递增（系数 $4x\ln x+1>0$），取 $a=-1$ 得 $g(x)=(4x-2x^2)\ln x+1-x^2$，$g'(x)=(4-4x)(\ln x+1)\le0$，$g(x)\le g(1)=0$，得证。

### 严格性

* 严格批卷时需要补一句：$a$ 大于所求边界的那一侧，端点处二阶导小于零，一阶导在端点递减，于是**存在** $x_0$ 使 $(0,x_0)$ 上一阶导为负、原函数递减，原函数在该区间内小于等于零、跑到 $x$ 轴下方，不符合题意。
* 这句话已暗含在端点效应的分析过程里，写不写看时间，但写上是满分的保障。
* > **结论**：导数模块里任何一个方法都不是万能的。端点效应大约有 10% 到 20% 的题目会失效。

## 端点效应失效

### 失效判据

* > **结论**：当目标函数在整个定义域上**一直单调递增或一直单调递减**时，最值只可能在端点取到，端点效应成立。

* 失效判据可以合并成一句话：**只要除端点以外还可能存在别处的极值点，端点效应就不成立**。

```text
┌──────────────────────────────────────────────────────────┐
│  端点值是个非零定值                                       │
│   G                                                   │
│   │     ●  ← G(0) > 0，跟 a 一点关系都没有                │
│   │    ╱ ╲                                               │
│   │   ╱   ╲___                                           │
│   └──┬──────────┬────────→ x                             │
│      0      还有一个真正的极小值在这里                      │
│     ✘ 端点管不住它                                         │
└──────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────┐
│  端点值正好是 0，但函数不单调（更隐蔽）                     │
│   G            ╱                                          │
│   │     ╲    ╱                                            │
│   │      ╲__╱   ← x₀ 处藏着极小值，图像还跟 x 轴相切         │
│   └───────●────────────────→ x                            │
│           0                                                │
│     ✘ 长得跟"能用"一模一样，照样错                          │
└──────────────────────────────────────────────────────────┘
```

### 失效一：端点值与参数无关

* **表现**：端点代进去得到一个与 $a$ 完全无关的死数，且不是零，图形从一个悬在半空的点出发，恒非负或恒非正就必然要求另有极小值点，此时端点分析完全管不住中间那段图像。
* **参数不能分离时只能带着参数求导**：参数在 $\ln$ 内部与外部各出现一次时无法合并，只能老老实实带参求导。
* 例：$a>0$，某含参不等式对 $x\ge0$ 恒成立。$g(0)=\dfrac32-2\ln2\approx0.11>0$ 属失效情形一；导函数符号最终压在一次因子 $x+4-4a$ 上，其余因子在 $x\ge0$ 上恒正，根为 $x=4a-4$。
    * $a\le1$：根落在定义域外，定义域上导函数恒正，$g$ 递增，最小值 $g(0)>0$，这一类全部成立。
    * $a>1$：根落进定义域，$g$ 先减后增，极小值在 $x=4a-4$ 处取得，必须把该点代入。
    * 代入化简：$1+a(4a-4)=4a^2-4a+1=(2a-1)^2$，用对数公式写成 $2\ln|2a-1|$；再用 $4a^2-4a=(2a-1)^2-1$ 配方把二次比一次除下去，最后设 $t=2a-1$，不等式化为 $2\ln t-t-\dfrac1t\ge 2\ln2-\dfrac32$。
    * 右边恰为左边函数在 $t=2$ 处的值，即 $h(t)\ge h(2)$。$h'(t)=\dfrac{2t-t^2-1}{t^2}=-\dfrac{(t-1)^2}{t^2}<0$，$h$ 单调递减，故 $t\le2$，即 $a\le\dfrac32$；与第一类取并集得 $a\in\left(0,\dfrac32\right]$。
    * > **提示**：不等式右边那个"莫名其妙给定的常数"往往是左边函数在某个特殊点处的函数值；猜特殊点（如令 $t=2$ 代左边）验证一下，就能把它写成 $h(t)\ge h(2)$ 的形状，从而脱衣服求单调性。

### 失效二：端点为零但函数不单调

* **表现**：端点代入正好等于零，看起来正是临界情况，但往下证的时候发现函数根本不单调，先增后减再增都可能有，极小值点藏在端点之外。
* **通用判据**：当发现除端点以外存在一个点**既满足函数值为零、又满足导数值为零**，两方程同时成立，就说明另有极小值点，光分析端点一定失效。
    * > **结论**：跟 $x$ 轴相切的位置 = 函数值为零的位置 = 导数为零的位置。

* 例：$f(x)=e^x+ax^2-\dfrac12x^3-x-1\ge0$ 对任意 $x\ge0$ 恒成立。端点一路降到二阶导给出 $a\ge-\dfrac12$，但取 $a=-\dfrac12$、$x=1$ 验证得 $f(1)=e-3<0$，说明端点效应失效。

* **挖出藏起来的极小值点**：

    * 联立 $f(x_0)=0$ 与 $f'(x_0)=0$，两个方程两个未知数 $x_0$ 与 $a$，把含 $a$ 的部分配平（第一式乘 $2$、第二式乘 $x_0$）后相减消去 $a$，得只含 $x_0$ 的方程 $(2-x_0)e^{x_0}+\dfrac12x_0^3-x_0-2=0$。

    * 含 $e$ 的系数无法与代数部分调和，**让含 $e$ 的系数为零**得 $x_0=2$，代回验证 $\dfrac12\cdot8-2-2=0$ 确实成立，说明该方程有解、$x=2$ 就是被藏起来的极小值点。

    * 代回原函数：$f(2)=e^2+4a-7\ge0$，得 $a\ge\dfrac{7-e^2}{4}$。

* ### 考场上真正该走的路

* 参数只出现在唯一位置时，优先分离参数，而不是去挖隐藏极值点。

```text
┌──────────────────────────────────────────────────────────────┐
│  恒成立问题（f(x) ≥ 0 恒成立，求 a 的范围）                   │
└──────────────────────────────────────────────────────────────┘
                            │
            ┌───────────────┴───────────────┐
            │                               │
      参数好分离？                      参数不好分离
      （只出现一次）                    （出现多次，混在 ln 里等）
            │                               │
            ▼                               ▼
    分离参数 a ≥ φ(x)                  带着参数直接求导
            │                               │
            ▼                               ▼
      φ 无参数 → 求最值              判导函数正负 → 分类讨论
            │                               │
            ▼                               ▼
      拆因子 → 判正负                        │
            │                               │
            └───────────┬───────────────────┘
                        ▼
              ┌──────────────────┐
              │  函数在定义域上单调？│
              └──────────────────┘
                 │            │
                是           否
                 │            │
                 ▼            ▼
           只看端点      ★ 端点效应失效 ★
                          │
                          ├─ 端点值与 a 无关（是个定值）
                          │    → 找别的极小值点，带入
                          │
                          └─ 端点恰为 0，但函数不单调
                               → 令 f(x₀)=0 且 f'(x₀)=0
                                  联立方程组消去 a，解出 x₀
                                  再把 x₀ 代回求 a 的范围
```

* 例：$e^x+ax^2-\dfrac12x^3-x-1\ge0$ 分离参数得 $a\ge\dfrac{\frac12x^3+x+1-e^x}{x^2}=\varphi(x)$（$x>0$，$x=0$ 时两端自动成立），求 $\varphi$ 在 $x>0$ 上的最大值：

$$\varphi'(x)=\frac{\frac12x^3-x-2+(2-x)e^x}{x^3}=\frac{(2-x)\left(e^x-\frac12x^2-x-1\right)}{x^3}$$

    * > **提示**：分子里 $e^x$ 只出现一次，其余是幂函数，加号把式子分成两块；只要其中一块也藏着同一个因子就能提出来。判断某块是否含因子 $(x-c)$，**只需把 $x=c$ 代进去看是不是零**，这是最省力的因式分解入口。不会长除法时可从最高次项开始硬凑：$\dfrac12x^3-x-2=(x-2)\left(\dfrac12x^2+x+1\right)$。

    * 括号恒正要**证**不能引用：设 $h(x)=e^x-\dfrac12x^2-x-1$，$h''(x)=e^x-1\ge0$（$x\ge0$）、$h'(0)=0$、$h(0)=0$，层层推出 $h(x)\ge0$。
        * > **易错点**：$e^x$ 的泰勒展开虽然一眼可见，但考试里凡是引用现成不等式都要自己求导证一遍。

    * 导函数符号完全由 $2-x$ 决定，先正后负，最大值在 $x=2$ 处取得：$\varphi(2)=\dfrac{7-e^2}{4}$。这与"隐藏极值点代回"算出的 $e^2+4a-7\ge0$ 完全一致。

* > **结论**：这类题真正的难点不在求导后的常规操作，而在于**往因式分解的方向上去想**。

## 必要探路

### 三个特殊点来源

* **必要探路**

    * > **定义**：在动导数之前，先在定义域里找**一些特殊点**代进去，把参数的一个必要范围问出来。

    * 三类特殊点：端点（$x=0$、$x=\frac{\pi}{2}$ 这类）、区间内的零点（某个 $x_0$ 使函数值恰等于临界常数）、极值点（单调性发生转折的点）。

    * 共同点：它们都把一整段连续的可能性压缩成了一个具体的数。恒成立难在要同时管住整个区间，必要探路是先把几个代表点的口子堵上，掏出参数的必要范围。

    * 端点效应只是必要探路的一个子集。

```text
   恒成立问题：某个不等式在定义域 D 上恒成立
                      |
              去 D 里找特殊点
                      |
     +----------------+----------------+
     |                |                |
   端点            区间内零点        极值点
  函数值恰好卡在    既过零点又整条    单调性发生转折的点
  临界常数上        曲线在它上方
     |                |            两侧的值由它决定
  F'(0) ≥ 0         相切 ⇒
  （或 ≤ 0）        F'(x₀) = 0
     |                |
     +--------> 通常解出一个确定值 <----+
                      |
        拿到范围后再分类讨论、换主元、验证
```

* **相切判据**

    * > **定义**：恒成立加上有最值，意味着临界点上"相切"，即该点同时满足函数值为零与导数值为零。

$$\begin{cases} f(x_0, a) = 0 \\ f'(x_0, a) = 0 \end{cases}$$

    * 解出 $x_0$ 后把它当特殊点代回原不等式，直接得到参数的**必要范围**，然后回头检验充分性。

* **三个来源的实际形态**

    * **端点**：把定义域端点代进去，能解就解。端点值常常正好等于零或正好是关于参数的表达式，一代就有收获。
    * **区间内零点**：恒 $\ge0$ 且在某处取到零，函数与 $x$ 轴相切，逼出 $F'(x_0)=0$。
    * **自己找**：既不单调、区间内又看不到零点时，设 $x_0$，用两个方程联立把它解出来。消元的原则是**消掉形式单一的那个变量**。

* > **提示**：题设让求**值**而不是求范围，这个反常的提法本身就是最强的信号——它暗示函数在区间内部有一个零点，去找它。
    * 例：含参不等式对 $t\in(-1,1)$ 恒成立求 $K$ 的值。两边取对数（先查真数 $1+t$、$1-t$ 皆正）化为 $F(t)=\dfrac{K}{1+t}-\dfrac{1-K}{1-t}\le0$，$t=0$ 处 $F(0)=0$，相切逼出 $F'(0)=K-(1-K)=2K-1=0$，得 $K=\dfrac12$。
    * > **易错点**：拿到相切给出的必要条件后**必须代回验证**，不验证这题等于白做；$K=\dfrac12$ 代回后根号下化为 $1-t^2\le1$，才敢说"若有值只能是 $\frac12$"。

* > **易错点**：区间内零点这个特殊点在"两边本来就不相等"的粗糙不等式里往往**用不了**——右边不含参数算出的是定值，左边含参数，含参式子不可能等于定值。

### 整数参数与粗不等式

* 恒成立还额外限定参数只能取整数时，必要探路比正常做法省得多。

    * 先堵老路：分离参数难做；端点带不进去（如 $\ln0$ 不存在）；区间内零点凑不出来。
    * 只剩最经典的一招：**随便取一个让计算最省的值**，取 $x=1$（因 $\ln1=0$），含 $\ln$ 的项直接塌掉，整理得 $k$ 的一个上界；既然 $k$ 是整数，$k$ 一定比这个上界小，该范围内最大的整数就是候选值。
    * 例中探得上界在 $0$ 与 $1$ 之间，故 $k=0$；只剩验证 $k=0$ 是否真成立。
    * > **结论**：必要探路遇上"求整数参数"，就大胆带一个值探路，把参数的大致范围先探出来，再在这个范围里取整数候选。

* **粗不等式的证法**：两边都除以 $x$，除完左边是 $(2\ln x+1)/x$ 型（先增后减、往上凸，最大值在 $x=\sqrt e$ 处，约 $1.2$），右边是 $3x\ln x+8$ 型（先减后增、往下凸，最小值在 $x=\frac1e$ 处，$8-\frac3e\approx6.9$）；一凸一凹、**我这边最小值比你那边最大值还大**，证毕。
    * > **提示**：遇到不等式证明里同时出现对数和其他函数，先问一句"能不能整体除以 $x$"；除完得到的 $\dfrac{\ln x}{x}$ 型与 $x\ln x$ 型都是高一就该记住的标准图像。
    * > **易错点**：含 $\ln x$ 的求导永远是"左导乘右加左乘右导"，$\ln x$ 永远消不掉，求导越求越复杂；求最值前必须先变形。

### 看不见零点就把零点解出来

* **发散用法**

    * > **定义**：函数不单调、区间内看不到零点、且极值点随参数变化看不清正负时，特殊点就是那个"非常潇洒的极值点"。

    * 极点为负时的临界情况正是零点。设零点为 $x_0$，它同时满足"是零点"和"是极值点"两个条件，两个方程两个未知数，一定能解出来。

    * 例：$f(x)=(x-a)^2\ln x\le 4e^2$ 对任意 $x\in[1,3e]$ 恒成立。

        * 先带端点 $3e$（$0$ 带不进 $\ln0$）：$(3e-a)^2\ln3e\le4e^2$，移项开方得 $3e-\dfrac{2e}{\sqrt{\ln3e}}\le a\le3e+\dfrac{2e}{\sqrt{\ln3e}}$。这是 $a$ 至少要满足的范围，左端与最终答案一致，右端不一致。

        * 差距说明端点之外还藏着一个随参数变化的极值点。联立 $(x_0-a)^2\ln x_0=4e^2$ 与 $2(x_0-a)\ln x_0+\dfrac{(x_0-a)^2}{x_0}=0$；$x_0$ 形式分散、$a$ 形式只有 $x_0-a$ 一处，**消 $a$**：从第一式整理出 $(x_0-a)^2=\dfrac{4e^2}{\ln x_0}$ 代入第二式，移项得 $x_0^2\ln^3x_0=e^2$；试 $x_0=e$ 得 $e^2\cdot1=e^2$ 成立，故特殊点是 $x_0=e$。

        * 代回：$(e-a)^2\le4e^2$，得 $-e\le a\le3e$。与端点范围取交集即得最终答案 $3e-\dfrac{2e}{\sqrt{\ln3e}}\le a\le3e$。

* **探路之后的三个好处**

    * 有了 $a$ 的范围，导函数里 $\ln x-\dfrac ax$ 的单调性立刻可判（$a>0$ 时 $\dfrac ax$ 递减，整体递增）。
    * 端点正负号好判断：$x=1$ 处值 $1-a$，$a$ 为四点几故为负；$x=e$ 处值 $3-\dfrac ae\ge0$ 已知 $a\le3e$。
    * 两个零点的大小关系**是确定的**，不用再做多余的分类讨论。

* **检验阶段**

    * 导函数 $H'(x)=\dfrac{(x-a)\big[2x\ln x+(x-a)\big]}{x}$ 在 $[1,3e]$ 上先正、再负、再正，原函数先增、再减、再增，最大值只可能在隐零点 $x_0$ 或右端点 $3e$ 处取得。
    * $3e$ 那条不必再证——它本来就是探路时用同一个不等式得到的，天然成立。
    * $x_0$ 那条有两个变量证不了，必须用隐零点满足的等式 $2x_0\ln x_0+(x_0-a)=0$ 消 $a$，得 $x_0-a=-2x_0\ln x_0$，代入后目标化为 $x_0^2\ln^3x_0\le e^2$；已知 $x_0\in(1,e)$ 且 $x^2\ln^3x$ 在 $x>1$ 上递增，左边 $<e^2$。
    * > **易错点**：探路只保证函数在所探的那几个点处满足要求，其余无数个点必须回头证明，不能因为"心里知道它是答案"就交卷。

* > **提示**：探出参数范围后，如果参数表达式过于复杂，**不要硬用变换主元**——它这时是关于 $a$ 的二次函数，对称轴落点难定，还得再分类讨论；带着参数老老实实分析反而更省。

### 特殊点带不进去时的试探策略

* **例：$|x-a|\le\dfrac{2e}{\sqrt{\ln x}}$ 对任意 $x\in[1,e]$ 恒成立**

    * 端点 $x=1$ 带不进去（$\sqrt{\ln1}=0$），但端点之外有一个既是零点又是极值点的点。$x_0=e$ 代进去得 $a=3e$ 或 $a=-e$，由"既零点又极值点"这条筛出 $a=3e$。
    * 证法一：令 $g(x)=x+\dfrac{2e}{\sqrt{\ln x}}$，$g'(x)=1-\dfrac{e}{\sqrt{x^2(\ln x)^3}}$；因已知 $x_0\in[1,e]$，根号内各因子全正，故 $g'>0$，$g$ 递增，最大值 $g(e)=3e$。
    * 证法二：分离参数，每一步都等价的，要带绝对值：$x-\dfrac{2e}{\sqrt{\ln x}}\le a\le x+\dfrac{2e}{\sqrt{\ln x}}$。左边是 $x$ 递增减倒数递减，整体递增，最大值 $g_1(e)=-e$，得 $a\ge-e$；右边递减增递增的复合结构求出导后先减后增、最小值 $h(e)=3e$，得 $a\le3e$。答案 $a\in[-e,\,3e]$。
    * > **易错点**：分离参数开根号时 $a$ 与 $x$ 的大小未知，直接分离必须保留绝对值，这一处最容易丢步。

* **例：$\ln(x+1)+a-a^2e^x\le0$ 对任意 $x\in(-1,+\infty)$ 恒成立，$a>0$**

    * 端点是 $-1$，$\ln0$ 带不进去。$x\to-1^+$ 时函数值趋于负无穷，图像只能递增最多相切，临界点得自己找。
    * 猜零点 $x_0=0$：$f(0)=0$ 给出 $a=0$ 或 $a=1$，再由 $f'(0)=1-a^2=0$ 筛出 $a=1$。卷面上只需写令 $x=0$ 得 $a(1-a)\le0$，配合 $a>0$ 得 $a\in(0,1]$。
    * 检验：$f'(x)=0$ 等价于 $(x+1)e^x=\dfrac{1}{a^2}$。$a\in(0,1]$ 给出 $\dfrac1{a^2}\in(0,1]$，而 $h(x)=(x+1)e^x$ 在 $(-1,+\infty)$ 上值域为 $[0,+\infty)$、$h(0)=1$，故交点横坐标是 $0$，即 $x_0\in(-1,0)$。
    * 最大值在 $x_0$ 处取到，由导函数方程消元得 $f(x_0)=\ln(x_0+1)-\dfrac{1}{x_0+1}+a\le0$；再用切线 $e^{x_0}\ge x_0+1$ 得 $a=\dfrac{1}{\sqrt{(x_0+1)e^{x_0}}}\le\dfrac{1}{x_0+1}$，于是 $f(x_0)\le\ln(x_0+1)\le0$，一次切线放缩收工。
    * > **提示**：这个范围的价值在下游——没有 $a$ 的精确范围就没有 $\dfrac1{a^2}$ 的范围，没有它就没有 $x_0$ 的范围，最后一步根本无法落笔。

* **例：$a\ln x+\sqrt{1+x}\le\dfrac{\sqrt x}{2a}$ 在给定区间（含下界 $\frac{1}{e^2}$）上恒成立**

    * 难点：两个根号形状不同无法一起换元，还有 $\ln x$，且 $a$ 既在分母上又在右边，**没法分离参数**。
    * 端点带不进去（$\ln$ 好解但 $\sqrt{1+x}$ 不好解）。找比端点大、又与 $\ln$ 有关、代入好算的值，试 $x=1$，得 $a\le\dfrac{\sqrt2}{4}$，同时该正数分母说明 $a$ 不能为负。
    * 验证特殊点是否成立：$x_0=1$ 时第一个方程给出 $a=\dfrac{1}{2\sqrt2}=\dfrac{\sqrt2}{4}$，第二个方程代入 $x_0=1$ 得 $\dfrac{\sqrt2}{4}+\dfrac{\sqrt2}{4}-\dfrac{\sqrt2}{2}=0$，两式同时成立，故特殊点就是它，答案 $0<a\le\dfrac{\sqrt2}{4}$。

* **先变形再变换主元**

    * 换成关于 $a$ 的函数后，$-\dfrac{\sqrt x}{2a}$ 这一项单调性可定，但 $\ln x$ 的系数符号随 $x$ 变，两个加起来看不出版本。
    * > **易错点**：换主元之后**不能默认"就单调了"**；$x<1$ 时 $\ln x$ 为负、开口向下，函数有增有减，还要再分类。

    * 动脑子的做法：既然已知 $a>0$，每一项都除以 $a$，把 $a$ 与 $\ln x$ 分开，$a$ 的倒数看成一个整体；令 $t=\dfrac1a$，取值范围两边取倒数得 $t\in[2\sqrt2,+\infty)$，式子成为关于 $t$ 的**开口向下二次函数**，对称轴是 $\dfrac{\sqrt{1+x}}{\sqrt x}$。

    * > **结论**：变换主元也可以动脑子——**可以先变形再变换主元**，而不是给什么就直接换。

    * 情况一：对称轴不在定义域内，即 $\dfrac{\sqrt{1+x}}{\sqrt x}\le2\sqrt2$，平方得 $x\ge\dfrac17$，此时函数在 $t\in[2\sqrt2,+\infty)$ 上递减，最大值在 $t=2\sqrt2$ 处取得；剩下的不等式里**既有 $\sqrt x$ 又有 $\sqrt{1+x}$，两种根号**。
    * 情况二：$x<\dfrac17$，对称轴在定义域内，最大值在对称轴处取得；把最大值带进去化简后**只剩一种根号**，换元 $M=\sqrt x\in\left[\dfrac1e,\dfrac1{\sqrt7}\right]$，$\ln x=2\ln M$，落成 $\dfrac{4\ln M}{M}+\dfrac1M+M\le0$；$f'(M)=\dfrac{M^2+3-4\ln M}{M^2}$，分子单调递增且带 $M=\frac1{\sqrt7}$ 验证为正，故 $f$ 递增，最大值 $f\left(\frac1{\sqrt7}\right)=-\dfrac{4\ln7}{\sqrt7}+\dfrac1{\sqrt7}+\sqrt7<0$，成立。

* **放缩精度**

    * 情况一直接求导要在三种不同分母之间通分、还要对多个根号因式分解，能算出来也不算真懂题；先把 $\sqrt x$ 换元 $M$、$\ln x=2\ln M$，把一根号消掉，问题只剩 $\ln M\le M-\dfrac{\sqrt{2(1+M^2)}}{2}$。
    * 先试粗糙的切线放缩 $\ln M\le M-1$：移项平方后要证 $M^2-2M+1\le0$，而这是完全平方式大于等于零，**放缩失败**。失败的原因是把曲线放缩成直线，**太粗糙**。
    * 改用曲线拟合曲线的精细放缩，分界点是 $M=1$：
        * $M<1$ 时用 $\ln M\le\dfrac{2(M-1)}{M+1}$，通分合并平方后归约为 $2M^2+1\ge(M+1)^2$，即 $(M-1)^2\ge0$——这就是柯西不等式。
        * $M\ge1$ 时用 $\ln M\le\dfrac12\left(M-\dfrac1M\right)$，移项平方后归约为 $M^2+\dfrac1{M^2}-2\ge0$，即 $\left(M-\dfrac1M\right)^2\ge0$。
    * > **结论**：放缩失败不是这题没路，是放缩精度不够；换更精细的式子即可。

## 放缩与变形工具箱

### 常用不等式

* $e^x\ge x+1$（$x$ 为任意实数成立时右端非负才可开方用），$e^x$ 在原点处的切线就是 $y=x+1$。
* $x\ge0$ 时 $e^x\ge1+x+\dfrac{x^2}{2}+\dfrac{x^3}{6}+\cdots$，取前面几项即为 $e^x>x^2/2+x+1$ 一类结论的来源；考试中引用它必须自己求导证一遍。
* $\ln t<t-1$（$t>0$），当且仅当 $t=1$ 取等，是 $y=\ln x$ 在 $(1,0)$ 处的切线。

* **飘带放缩不等式**

    * > **定义**：当 $T>1$ 时 $\ln T$ 大于 $\dfrac{2(T-1)}{T+1}$；三者构成一族关系 $\dfrac{2(T-1)}{T+1}\le\ln T\le\dfrac12\left(T-\dfrac1T\right)$，中间是 $\ln T$，上界是 $\dfrac12(T-\frac1T)$，下界 $\dfrac{2(T-1)}{T+1}$ 是它们之间的"带子"。

    * 换元 $T=\dfrac{1+x}{1-x}$（$x\in(0,1)$ 时 $T>1$）、解出 $x=\dfrac{T-1}{T+1}$ 后，原不等式等价于 $\ln T\ge\dfrac{2(T-1)}{T+1}$。

    * 三个函数在 $T=1$ 附近贴得很紧，用它对 $\ln T$ 放缩特别精确。
    * > **提示**：左右两边的函数都是关于 $T$ 的分式函数；分式函数的化简技巧比 $\ln T$ 的化简技巧多得多也方便得多，换元过去通常大幅降难度。

* $\sin x\le x$（$x\ge0$；$\sin x$ 关于原点对称，左侧 $\sin x\ge x$）。
* $\cos x+\dfrac{x^2}{4}-1\le0$（$x\in[0,1]$）：$P'(x)=\dfrac x2-\sin x$，$P''(x)=-\cos x+\dfrac12<0$，$P$ 递减、$P(0)=0$。
    * > **提示**：要用到的角度数值得背——$1$ 弧度约 $57.3^\circ$，而 $\cos x=\dfrac12$ 对应 $60^\circ$，在 $0\sim1$ 上有 $-\cos x<-\dfrac12$。
* 柯西不等式形如 $2M^2+1\ge(M+1)^2$ 的形式化简。

### 放缩与分段原则

* 分析三角函数时因为它本身震荡，**经常把给定范围分成几块讨论**；分块之后每块里两个函数的大小关系才好说。
* 分块不等于每块都要精算：三角函数有上下界，而一次函数、指数函数涨得又猛又凶，函数值一旦差得够远，**大胆放缩**就够。例如 $x\in\left[\frac{3\pi}{4},+\infty\right)$ 上，$e^x\ge e^{3\pi/4}>e^2=7.29$ 而 $\sqrt2\sin\left(x+\frac\pi4\right)$ 上限只有 $\sqrt2$，两等号不可能同时取到，零个数就此定死。
* 粗糙放缩的样板：$e^x>0$、三角项落在 $[-\sqrt2,\sqrt2]$、一次函数在端点处取到该段最小/最大值，三块相加符号已经确定，不需要任何精细计算。
* 区间端点的等号能否取到要逐个确认：端点处取不到（分母为零、真数为零）时只能取极限值；连续性保证解集闭区间里至少有一个端点取到边界值，但究竟是哪一个必须由"该点能否代入"来判断。
* > **提示**：$g(x)=\sqrt2\sin\left(x+\frac\pi4\right)=\sin x+\cos x$，辅助角公式把它拆成两个熟悉的函数，画图时先画 $\sqrt2\sin x$（零点 $0,\pm\pi$），再按"左加右减"整体左移 $\frac\pi4$，负零点 $-\pi$ 左移后正是 $-\frac{5\pi}4$ 这个截断点。
* > **提示**：判断零点个数可以借助切线斜率。$e^x$ 在原点处切线是 $x+1$，$g'(x)=\sqrt2\cos\left(x+\frac\pi4)$ 在 $x=0$ 处等于 $\sqrt2\cdot\dfrac{\sqrt2}{2}=1$，即 $g$ 过 $(0,1)$ 的切线也是 $x+1$；两条切线重合说明两曲线只有一个交点。
* > **注意**：数形结合容易被扣分。远离分界点的区间靠符号一句话说完即可，但**过渡区间必须靠切线斜率相等来锁定零点唯一**，不能只写图形结论；答题卡上要把区间分块写成标准文字论证。

### 指数找朋友与整体除法

* $e^x$ 越跟别的东西合在一起求导后越简单；孤零零一个反而难办。
* 例：证 $e^x+\sin x+\cos x-2x-2\ge0$。整体除以 $e^x$（即每项乘 $e^{-x}$）得 $Q(x)=1+\left(\sqrt2\sin\left(x+\frac\pi4\right)-2x-2\right)e^{-x}\ge0$，此时指数已"找到朋友"，求导后项与项相消、$e^{-x}$ 被整体提出来：$Q'(x)=2(x-\sin x)e^{-x}$。
* $e^{-x}$ 恒正，正负只看 $x-\sin x$；$y=x$ 正是 $\sin x$ 在原点处的切线，$0$ 是唯一分界点，右侧直线在上（导数为正）、左侧三角在上（导数为负），故 $Q$ 先减后增、最小值 $Q(0)=0$。
* > **结论**：除以 $e^x$ 这条路**根本不用分类讨论**，一行导数直接定全局；而沿原式一路求导则要在 $[0,\frac{5\pi}4]$ 与 $(-\infty,-\frac{5\pi}4]$ 上分段处理。
* > **结论**：人让证哪个不等式，不化简不变形直接求导，函数就会变复杂；"指数找朋友"的真正好处是求完导还能因式分解，因式分解完指数与三角彻底分家。

### 起手式与收尾准则

* 恒成立问题的标准起手式：**先分类问一遍特殊点长什么样，再挑能用的那个**。

```text
   恒成立 + 有最值  ⇒  临界点（相切）
                                  │
                    函数值 = 0  与  导数值 = 0
                                  │
                    两个方程联立，解出临界点 x0
                                  │
                    把 x0 当特殊点代回原不等式
                                  │
                    得到参数的【必要】范围 a
                                  │
        范围可用 ───→ 回头检验充分性（求导／放缩／换元）
        范围不好用 ──→ 先变形 → 再变换主元（如令 t = 1/a 看二次函数）
                                  │
                                 答案
```

* 抛值时记住三件事：

    1. 扔进去得到的是**必要条件**，不是答案，一定要回头检验充分性。
    2. 判断"扔的这个点是不是真特殊点"，靠的是**两个方程能不能同时成立**。
    3. 拿到范围之后，**后面所有的估值、对称轴、区间端点都从它出**——$\dfrac1{a^2}$ 的范围、$x_0$ 的范围全是它的下游；范围估不准，后面会冒出一堆没必要的分类讨论。

* 方法优先级：参数只出现一次、形式单一时优先考虑分离参数；参数出现多次或混在 $\ln$ 里没法分离时，老老实实带着参数分析、分类讨论。
* 任何单一方法都不是万能的。分离参数、分类讨论、端点效应、必要探路各有失效形态，选型的依据永远是"参数出现几次、函数在定义域上是否单调、有没有能代进去的特殊点"这三问。

### 易错点速查

* 变换主元只适用参数出现一次、形式单一的情形；参数出现 $a$、$a^2$、$\ln a$、$e^a$ 多种形式时不要用。
* 最小值能取到时结论写 $\ge$ 而不是 $>$；定义域开区间使最值点取不到时才写严格不等号。
* 由"单调递增"反推导函数必须写 $f'(x)\ge0$，不能写 $>0$。
* 分离参数时若分母会变号，要按分界点分三类；由负除过去要变号；不含参数的临界那类不产生任何约束。
* 分类讨论最后是取并集还是取交集：各情况解出的范围取并集，题给的硬性前提取交集。
* 端点代进去得到的是与参数无关的定值、或者端点为零但函数不单调时，端点效应失效，须去找端点之外的极小值点。
* 找极值点的通用动作是解 $f(x_0)=0$ 与 $f'(x_0)=0$ 的方程组，消掉形式单一的那个变量，让含 $e$ 的系数为零往往能给出解，再代回验证。
* 要引用泰勒展开、切线不等式这类现成结论时，考试里必须自己再求导证一遍。
* 归约到形如 $2M^2+1\ge(M+1)^2$ 时不要与 $2\ln M\ge2M-2$ 混看——后者平方后要求的是完全平方式小于等于零，必然证不出来，说明放缩用错了。
* 数形结合容易丢分，过渡区间必须靠切线斜率相等锁定零点唯一，并写成标准文字论证。
* 数形结合里"点不出头、只能相切"是常见陷阱；$x=0$ 处函数值为零只说明它是零点，要断定它是极大值点还需 $H'(0)=0$。
