# 必修阶段综合复习

## 图像与解析式的正反考查

### 具体函数图像的两种出题方向

* 正着考：给出解析式，问四幅图中哪一个是它的图像。
* 反着考：给出图像，问哪一个解析式对应它，反过来考更难。
* 无论正着反着，前提都是先在心里攒住一批「书上未必出现、但极其重要」的图像。
* 真正考试中的解析式必定非常复杂，分析入口固定为四项：奇偶性、单调性、周期性、最值。

### 必须主动画图的两种图像

* **类二次图像**

    * > **定义**：形状非常接近二次函数，最低点落在 $x=0$ 处，最低点的值为 $2$。

    * 奇偶性为偶函数。
    * 例型为 $\lvert x\rvert-2$ 一类。
    * 判题时见到必须立刻在草纸上画出来，而不是逐点算值。

* **类三次图像**

    * > **定义**：形状非常接近三次函数图像的单调性由底数决定。

    * 奇偶性为奇函数。
    * 例型为 $a^x+a^{-x}$。
    * $a>1$ 时单调递增，$0<a<1$ 时单调递减。
    * 判题时见到必须立刻画图。

```text
  两个必须主动画图的函数

  编号   形状                奇偶性    单调性
  ────  ──────────────────   ──────    ──────────────────
   1     类二次 ∣x∣-2 一类   偶函数    最低点在 x=0，值 2
   2     类三次 a^x+a^(-x)   奇函数    a>1 增，0<a<1 减
```

### 奇偶性筛选后的量级判定

* 图像关于原点对称，则对应函数一定是奇函数，选项中可先按奇偶性筛掉不合格项。
* 偶函数乘奇函数得奇函数；奇函数除以偶函数也得奇函数。
* 出现「偶函数（非奇非偶）×奇函数」这类混搭项时，$f(-x)$ 与 $f(x)$ 既不相等也不互为相反数，属于无法判定项。
* 筛完之后仍剩两项时，改用取值量级判断：读图像给出的最大值或最小值量级，再分别拆开两个解析式估计量级。
* 若两项都写成同一个奇函数与同一个恒 $\ge 2$ 的类二次函数之商，则商的量级不可能超过 $3$，剩下的乘法项即为答案。

> **易错点**：不要一上来就把 $\pm\pi$ 代入找零点。$\pi$ 与 $-\pi$ 都是 $\sin$ 的零点，代进去函数值都是零，两个选项会一起被淘汰，判不出结果。

### 复杂解析式的性质叠加

* 两坨奇函数相加，结果必为奇函数；奇加奇的结论可直接使用。
* 前半部分中真数位置随 $x$ 增大而变大，说明对数函数部分递增。
* 后半部分若为底数大于 $e$ 的类三次函数，同样递增。
* 增函数加增函数，单调性保留，因此整体单调递增。
* 结论确定后，图像可在草图上直接画出，后续关于单调区间、零点、对称性的提问都能落地。

## 零点问题的画图法

### 三个高频等价式

| 表达式 | 结论 |
| :--- | :--- |
| $f(x)=f(-x)$ | 偶函数，对称轴为 $y$ 轴 |
| $f(x+a)=f(x-a)$ | 对称轴为 $x=a$，算法是括号里两个横坐标相加除以二 |
| $f(x+a)+f(x-a)=C$ | 存在对称中心 |

* 形如 $f(x)=f(-x)$ 说明关于 $y$ 轴对称；形如 $f(x)=f(2-x)$ 说明 $x=1$ 也是对称轴，一个函数可以同时有两条对称轴。
* 再配合已知 $f(x)$ 在 $[0,1]$ 上等于 $x^3$，按「先作偶函数对称得左半、再按第二条对称轴左右翻转、再按第三条对称轴翻回左侧」三步走，图像为周期循环的小碗。
* 反复左右翻转后可推出周期 T 不断出现，理论上该函数有无数条对称轴，所有整数都是对称轴。

> **结论**：零点问题里，图形有了，零点就好找好算。凡是给了图像才能解决的题，先画图，别硬算。

### 复杂零点函数的分离策略

* 零点问题大部分情况需要画图，且题给的不是 $f(x)$，而是关于 $f$ 的复杂代数表达式。
* 面对一大坨函数时不要去分析它，先观察它由哪几小坨构成，再把它们分离、分别画图。
* 分离出的其中一坨若正是前面已经画完的 $f(x)$ 图像，可直接复用。
* 另一坨若含三角函数与绝对值：其周期属于 $\frac{\pi}{\omega}$ 型，画图时「最高点到最低点」只算半个周期；出现绝对值则把下方部分翻上去，图形变成一个个小馒头。
* 翻转完成后直接数图形与 $x$ 轴的交点个数即可，无需解析求解。

> **结论**：凡是具有两个对称轴、两个对称中心，或者一个对称轴加一个对称中心的函数，都能推出它具有周期性。

## 抽象函数的对称性与周期性密码

### 三个必背周期表达式

| 表达式 | 结论 |
| :--- | :--- |
| $f(x+a)=f(x)$ | 周期是 $a$ |
| $f(x+a)=-f(x)$ | 周期翻倍，变成 $2a$ |
| $f(x+a)=\dfrac{1}{f(x)}$ | 周期翻倍，变成 $2a$ |

### 周期性与对称性的分界

* 一个式子里出现两个 $f$ 时，判断它是周期性还是对称性，只看括号里面的 $x$ 是同号还是异号。
* 括号里总是异号的是对称性，总是同号（同正或同负）的是周期性。
* 周期性与对称性并非互不相干，在实际考题中完全可以有机结合使用。

```text
  对称性（括号里异号）              周期性（括号里同号）
  ─────────────────────────         ─────────────────────────
  f(x)     = f(-x)                  f(x+a)  = f(x)
  f(x+a)   = f(x-a)                 f(x+a)  = -f(x)
  f(x+a) + f(x-a) = C               1/f(x+a) = f(x)

  x 与 -x 异号                      x+a 与 x+a 同号（同正或同负）
  x+a 与 x-a 异号
```

### 对称量推出周期

* 两个对称轴是 $a$ 和 $b$，或者两个对称中心是 $a$ 和 $b$：$T=2\lvert a-b\rvert$。
* 一个对称轴是 $a$、另一个对称中心是 $b$：$T=4\lvert a-b\rvert$。
* 记忆抓手是 $\sin x$ 的图像：两轴之间、两中心之间的一个完整周期都是间距的两倍，一轴一中心的间距则是周期的四分之一。

```text
  ┌────────────────────────────────────────────┐
  │  两相邻对称轴   a ───── B ───── b           │
  │      周期 = 两轴间距的 2 倍，T = 2|a-b|      │
  ├────────────────────────────────────────────┤
  │  两相邻对称中心 A ───── B ───── b           │
  │      周期 = 两中心间距的 2 倍，T = 2|a-b|    │
  ├────────────────────────────────────────────┤
  │  一轴一中心    a ──── A ──── B              │
  │      周期 = 二者间距的 4 倍，T = 4|a-b|      │
  └────────────────────────────────────────────┘
```

> **提示**：算对称中心横坐标的公式与对称轴是同一套，都把式子里两个横坐标相加除以二。差别只在纵坐标：$f(x+a)+f(x-a)=C$ 的对称中心是 $\left(\dfrac{a+b}{2},\dfrac{C}{2}\right)$。

## 奇偶、中心、周期串联型综合题

* 题设形态：函数 $f(x)$ 不恒等于零，$f(\pi)=0$，且对任意 $x,y$ 成立
* 待判定关系式：$f(2x+y)+f(2x-y)=f(2x)\cdot f(y)$，四个选项依次问 $f(0)$、$f$ 是否偶函数、是否关于 $(\pi,0)$ 对称、周期是多少。
* 综合性质的清单固定为五样：奇偶性、轴对称、中心对称、周期性，以及由它们导出的周期性结论，每项都有对应的表达式套路。

### $f(0)$ 的取值与排除

* 令 $x=y=0$ 得 $2f(0)=f(0)^2$，当作解方程 $2x=x^2$ 处理可得两个值：$f(0)=0$ 或 $f(0)=2$。
* 正确的排除法是假设 $f(0)=0$，把 $y$ 取成 $0$，左边出现 $2f(2x)$，右边含因子 $f(0)$ 为零，于是 $f(2x)=0$ 对一切 $x$ 成立。
* 把 $2x$ 记作 $t$ 即得 $f(t)=0$ 恒成立，与「不恒等于零」的题设矛盾，所以 $f(0)$ 只能是 $2$。

> **易错点**：直接用「不恒等于零」把 $f(0)=0$ 舍去属于逻辑漏洞。「不恒等于零」指的是图像不是一条水平直线，不等于图像不能在某些点处取值为零，这个排除路径不成立。

### 偶函数的判定

* 用 $f(-x)$ 的路径是把 $y$ 换成 $-x$，得 $f(2x)+f(-2x)=f(2x)\cdot f(0)$。
* 代入 $f(0)=2$ 后两边都有 $f(2x)$，约去后得 $f(-2x)=f(2x)$。
* $2x$ 能取遍全体实数，记作 $t$ 就是 $f(-t)=f(t)$，故 $f$ 为偶函数。

### 对称中心的判定

* 判定中心对称先反推目标形状：关于 $\pi$ 对称的最简表达式是 $f(\pi+x)+f(\pi-x)=0$，两个横坐标相加除以二恰为 $\pi$，纵坐标相加除以二恰为 $0$。
* 原式中已有两个 $f$ 相加，只需让它们分别取到 $\pi+x$ 与 $\pi-x$，即把 $x$ 与 $y$ 都代成 $\dfrac{\pi}{2}$。
* 代后右边出现 $f(\pi)\cdot f\!\left(\dfrac{\pi}{2}\right)$，而 $f(\pi)=0$，零乘得零，于是目标式成立，图像关于 $(\pi,0)$ 对称。

> **提示**：所有目标函数最终都要尽量化简成「两个 $f$ 相加」或「两个 $f$ 相等」的形状，靠往这个形状上凑来倒推代入值。

### 周期的确定

* $f$ 是偶函数即对称轴为 $x=0$，同时关于 $(\pi,0)$ 对称，属一轴一中心结构，必然具有周期性。
* 套用一轴一中心公式得 $T=4\lvert 0-\pi\rvert=4\pi$，所以「周期是 $2\pi$」不成立。

## 抽象函数的单调性转化

### 相同变量放一起

* 抽象函数考单调性时，条件常给出一长串同时含 $x_1$、$x_2$ 且两者混着出现的式子，处理方法只有一个：相同变量放一起，本质就是一次因式分解。
* $f(x_1)$ 与 $f(x_1)$ 相同、$f(x_2)$ 与 $f(x_2)$ 相同，先移项把两边前面的乘式相减，移项后剩下的部分同样要归堆，使系数也相减。
* 随后因式分解：前一部分把 $x_2$ 提出来出现 $x_1-x_2$，后一部分把 $x_1$ 提出来出现 $x_2-x_1$，两个因子同为 $x_1-x_2$，直接提出公因子。
* 提公因子后 $x_1$、$x_2$ 仍掺在一起，用变形操作：两边同除以 $x_1x_2$，左侧第一项只剩 $\dfrac{f(x_1)}{x_1}$，第二项同理，形式变为 $\dfrac{f(x_1)}{x_1}=\dfrac{f(x_2)}{x_2}$。
* 把 $\dfrac{f(x)}{x}$ 想象成新函数 $g(x)$ 整体换元，条件即变成 $g(x_1)=g(x_2)$，这正是单调递减的标志。

### 换元后与定义域取交集

* 已知 $g(x)=\dfrac{f(x)}{x}$ 在 $(0,+\infty)$ 上单调递减且 $f(2)=4$，先算 $g(2)=\dfrac{f(2)}{2}=2$。
* 求值目标一律要把 $f$ 往 $\dfrac{f(x)}{x}$ 上凑：$f(x)>2(x-3)$ 等价于 $f(x-3)>2(x-3)$，再等价于 $g(x-3)>2$。
* 变形成 $g(x-3)>g(2)$ 后，因 $g$ 单调递减，不等号方向改变，得 $x-3<2$，即 $x<5$。
* 定义域要求 $f$ 括号内的数落在 $(0,+\infty)$ 内，前后括号范围一致，故 $x-3>0$，即 $x>3$。
* 两个不等式取交集得 $3<x<5$。

> **结论**：整个过程最关键的是化简条件式，最常用的方法就是相同变量放一起。

## 三角恒等变换的三条路径

### 找角关系

* 题目前后出现两个明显的不同角度时，必须先分析二者的关系，不分析这题做不出来。
* 两角都长一大坨、看不出关系时用换元：把其中一个整体设为 $\beta$，把另一个也用 $\beta$ 表示后代入化简，通常能看出整体形如 $\dfrac{\pi}{2}-k\beta$。
* 前后函数名要变而角不变，说明是诱导公式；由一倍角变四倍角时，四倍角公式虽未学过，但可由二倍角公式两次相乘得到。
* 例：已知 $\sin\beta=\dfrac{\sqrt3}{3}$，先由 $\cos 2\beta=1-2\sin^2\beta$ 得 $\cos 2\beta=\dfrac13$，再由 $\cos 4\beta=2\cos^2 2\beta-1$ 得 $-\dfrac79$。

> **提示**：考试里经常出现前后两角都长一大坨的题，把其中一个设成整体、再把另一个表示成这个整体，往往就能做出来。

### 找次数关系

* 该方法常在凑齐次式时使用。
* 例型 $\dfrac{\sin 2\theta}{2+\cos^2 2\theta}$：分子展开后是一次乘一次的二次式，分母 $\cos^2\theta-\sin^2\theta$ 也是二次式，所以常数 $2$ 也要改写成二次式。
* 把 $2$ 写成 $2\sin^2\theta+2\cos^2\theta$，再照抄一份 $\cos^2\theta-\sin^2\theta$，合并同类项得 $\sin^2\theta+3\cos^2\theta$。
* 上下同除以 $\cos^2\theta$，原式化为 $\dfrac{2\tan\theta}{\tan^2\theta+3}$，全部转成一倍角问题。
* 只要题目给了 $\tan\theta$ 的值或能求出 $\tan\theta$ 的值，就找到了出路；常用手段是二倍角公式与 $\sin^2+\cos^2=1$ 的代换，使分子分母次数一致。

### 找标志

* 绝大多数题目不会主动给角关系或次数关系，而是通过式子本身的长相暗示该用哪个公式；标志识别是主力手段。
* 看到 $\dfrac{\sqrt3}{2}\cos\theta-\dfrac12\sin\theta$，想象成 $\sin$ 口减 $\cos$ 口：谁的 $\sin$ 是 $\dfrac12$、谁的 $\cos$ 是 $\dfrac{\sqrt3}{2}$ 都是 $30^\circ$，故它等于 $\sin\left(\dfrac{\pi}{3}-\theta\right)$，是辅助角公式或两角和差的逆用。
* 看到 $\dfrac{2\tan\theta}{1+\tan^2\theta}$ 属于万能公式而不是二倍角公式，标志是分母为加号；把它写成 $\dfrac{2\sin\theta\cos\theta}{\left(\frac{\sin\theta}{\cos\theta}\right)^2+1}$ 后上下同乘 $\cos^2\theta$，分母化为 $\cos^2\theta+\sin^2\theta=1$ 约掉，得 $\sin 2\theta$。
* 看到 $1-\cos 2\theta$ 立刻想成 $2\sin^2\theta$，看到 $1+\cos 2\theta$ 立刻想成 $2\cos^2\theta$；凡是出现 $1\pm\cos$ 的式子都这么化，可解决绝大部分题目，因此不必特意背半角公式，只背一个二倍角公式就够。
* 例：$\dfrac{1-\cos 2\theta}{1+\cos 2\theta}$ 分子分母各自降次后约为 $\dfrac{\sin^2\theta}{\cos^2\theta}=\tan^2\theta$。
* 出现 $\sin$ 乘 $\cos$ 时想两角和差公式，出现 $2\alpha+\beta$ 这类写法时想二倍角公式，先求出一倍角 $\alpha+\beta$，二倍角自然随之可得。

```text
  ┌────────────────────────┬───────────────────────────────┐
  │  看到的式子             │  它其实是谁                    │
  ├────────────────────────┼───────────────────────────────┤
  │ √3/2·cosθ - 1/2·sinθ   │ 辅助角公式 / 两角和差逆用      │
  │                        │ = sin(π/3 - θ)               │
  │                        │ 标志：谁 sin=1/2，谁 cos=√3/2  │
  ├────────────────────────┼───────────────────────────────┤
  │ 2tanθ / (1 + tan²θ)    │ 万能公式，不是二倍角          │
  │                        │ 二倍角分母是减号，本式是加号  │
  ├────────────────────────┼───────────────────────────────┤
  │ 1 - cos2θ              │ = 2sin²θ（降次）              │
  │ 1 + cos2θ              │ = 2cos²θ（降次）              │
  └────────────────────────┴───────────────────────────────┘
```

> **易错点**：$\dfrac{2\tan\theta}{1+\tan^2\theta}$ 与 $\dfrac{2\tan\theta}{1-\tan^2\theta}$ 形状极像，判别只看分母是加号还是减号。

### 求 $\sin(u)$ 还是 $\cos(u)$

* 需要先求二倍角时，先求出一倍角 $\sin(\alpha+\beta)$ 或 $\cos(\alpha+\beta)$，二选一的判断标准看目标式展开后的形状。
* $\sin$ 展开是 $\sin\cos+\cos\sin$，含 $\sin$ 与 $\cos$ 相乘项；$\cos$ 展开是 $\cos\cos-\sin\sin$，不含 $\cos$ 相乘项。
* 若待处理式恰为 $\dfrac{\sqrt3}{2}\sin\alpha-\dfrac12\cos\alpha$ 这种 $\sin$、$\cos$ 各自一次的线性组合，就应求 $\sin(\alpha+\beta)$，把 $\sin\alpha\cos\beta$ 与 $\cos\alpha\sin\beta$ 两数相加即可。
* 有了 $\sin(\alpha+\beta)$ 后，求 $\cos 2(\alpha+\beta)$ 直接代入 $\cos 2u=1-2\sin^2u$。

## 三角函数图像的难度分档

### 出题人的三档手法

* 基础档：直接给出 $A\sin(\omega x+\varphi)$，在多选题中问它是否对称轴、是否对称中心、是否单调递增。
* 一般档：给一幅三角函数图像，让从中寻找几何关系，图像可能千奇百怪，需要利用图像上的特殊点做题，并对这些几何点做「翻译」。
* 高难档：不直接给式子，先在草纸上写下来并展开，展开成一大坨之后再变难，需要用三角恒等变换往回推、化简回来。
* 无论哪一档，基础手段都是整体换元法：把 $\omega x+\varphi$ 看成一个整体 $t$，由 $x$ 的范围求出 $t$ 的范围，再去观察 $A\sin t$ 这个基础函数。

```text
  ┌──────────┬──────────────────────────────────────────┐
  │  比较善  │ 直接给解析式，式子有了就好做            │
  ├──────────┼──────────────────────────────────────────┤
  │  一般    │ 画一幅图像去找几何关系                   │
  │          │ → 利用图像上的特殊点做题                │
  │          │ → 对几何点做「翻译」                    │
  ├──────────┼──────────────────────────────────────────┤
  │  再坏点  │ 不给式子，先写下来展开成一大坨          │
  │          │ → 往回推把它化简回来                    │
  │          │ → 必然用上三角恒等变换公式              │
  └──────────┴──────────────────────────────────────────┘
```

## 对称轴与对称中心的式子翻译

### 由对称轴翻译

* 图像上给出的对称轴往往是取得最高点、取得最大值的那个对称轴，与其他对称轴的区别正在于此。
* 把横坐标 $x_0$ 带进去，要求 $\omega x_0+\varphi$ 使整体取最大值，即让 $\sin t$ 取最大值，得 $\omega x_0+\varphi=\dfrac{\pi}{2}+2k\pi$。
* 该写法有前提：为保证整体确实取最大值，系数 $A$ 必须为正。
* 若 $A$ 为负则正好反过来，取的是 $\sin$ 的最小值那些点，因为取最小值再乘负号整体才取最大值；一般情况下题目会先定好 $A>0$、$\omega>0$，偶尔会考相反情形。

### 由对称中心翻译

* 把给出的对称中心横坐标 $x_0$ 带进去，$\omega x_0+\varphi$ 是个零点，函数值为零。
* 在无任何限制条件时写 $\omega x_0+\varphi=k\pi$ 即可，无论 $\omega$、$A$ 正负都成立。
* 若题目给定 $A>0$ 且 $\omega>0$，可以精细一层：此时整体图像与 $\sin t$ 最大值对最大值、最小值对最小值、左右对左右完全一一对应，下行零点精确写成 $(2k+1)\pi$，上行零点写成 $2k\pi$。
* 题目没有给 $A$ 与 $\omega$ 的限制条件时，千万不要只写等于整数倍的 $\pi$。

```text
  sin t 的零点分两种，走向完全不同

            2kπ                （偶数倍 π）
             ▲   上行零点：由负往正
             │
  ───────────┼──────────────────────────→ t
             │
             ▼   下行零点：由正往负
            (2k+1)π            （奇数倍 π）

  复合后只有 A 与 ω 同号时，两图才完全一一对应，
  此时下行零点才可精确写成 (2k+1)π。
```

## 点条件翻译成轴与中心

* 同一周期内两个点函数值相等且两点均给出、纵坐标不给时，两点关于对称轴对称，取其中点横坐标 $x_0=\dfrac{x_1+x_2}{2}$ 即可转化成对称轴。
* 同一单调区间内两个点的函数值互为相反数时，连接两点会发现连线正好经过对称中心，由此转化成对称中心。
* 两类条件都属于「点条件」，翻译成轴与中心后，回到前面那套翻译成式子的流程。

## 几何关系综合多选的拆解

* 题设形态：$f(x)=A\sin(\omega x+\varphi)$（$A>0$，$\omega>0$，$0<\varphi<\pi$），与 $x$ 轴右侧的第一个交点为 $C$；以 $C$ 为圆心的圆与图像交于 $M$、$N$ 两点，$M$ 在 $y$ 轴上。
* 读图第一步要排除的错觉：$N$ 点的位置看起来像最低点，但它只是一个非常普通的点，并不是最低点。

### 周期与参数求解

* 圆是以 $C$ 为中心的中心对称图形，三角函数图像因为 $C$ 是与 $x$ 轴的第一个交点（零点必是中心）也是以 $C$ 为中心对称的图形。
* 两个中心对称图形共用同一个对称中心时，它们的交点关于该中心对称，因此 $C$ 是 $M$、$N$ 的中点，$C$ 处的值就是另外两个已知横坐标的中点。
* 该中点处恰是半个周期所在，故一个完整周期为两倍关系，得 $\omega=\dfrac{\pi}{T}=2$。
* 再用整体换元法求 $\varphi$：把图像上取得最高点的位置 $x=\dfrac{\pi}{12}$ 带进去，令 $\sin$ 取最大，$\sin$ 最高点为 $k\pi+\dfrac{\pi}{2}$，结合 $0<\varphi<\pi$ 解出 $\varphi=\dfrac{\pi}{3}$。
* 另一种求法是带 $\dfrac{\pi}{6}$ 这个零点：已知 $A>0$、$\omega>0$，可判定它是上行零点，精确写成 $2k\pi$，代入后由 $\varphi\in(0,\pi)$ 定出 $k=0$，同样得 $\varphi=\dfrac{\pi}{3}$。

### 平移后的对称性判定

* 把图像整体向左平移 $\dfrac{\pi}{12}$ 后，纵坐标为 $A\sin\left(2x+\dfrac{\pi}{2}\right)$，不必化简，直接把待验证的横坐标 $x=\dfrac{\pi}{4}$ 带进去。
* 代入得 $2\times\dfrac{\pi}{4}+\dfrac{\pi}{2}=\pi$，整体取 $\pi$ 时对应的是对称中心而非对称轴，所以「关于 $x=\dfrac{\pi}{4}$ 轴对称」不成立。
* 几何法同样可判：周期为 $\pi$，半个周期为 $\dfrac{\pi}{2}$，故 $\dfrac{\pi}{4}$ 恰是半个周期处，是中心对称点。

### 圆半径的用法

* 半径的真正突破口不是长度本身，而是「$M$ 点在 $y$ 轴上」这一特殊性：$M$ 点横坐标为 $0$，$C$ 点横坐标已知。
* $CM$ 的水平分量与竖直分量（$M$ 点纵坐标）构成直角三角形，把两边同乘 $12$ 得 $5\pi$ 与 $4\pi$，构成 $3$-$4$-$5$ 三角形，斜边对应第三边为 $3\pi$，除以 $12$ 得到 $\dfrac{\pi}{4}$ 的量级。
* $M$ 点纵坐标的用法是把 $M$ 点横坐标带进去求 $f(0)=A\sin(\varphi)$，$\varphi$ 已知后即可解出 $A$，量级为 $\dfrac{\sqrt3}{6}\pi$。

> **结论**：这类题考察的就是三角函数图像上的几何问题，需要分析图形中的点、线、关系才能定出 $A$、$\omega$、$\varphi$；这三个值到手后，单调性、周期、对称性、零点等提问都能解决。

## 降次与辅助角合并

* 题目形态固定为 $\sin$ 乘 $\cos$，再配一个 $\sin^2$ 或 $\cos^2$，外加一个常数，是小题大题必考一类。
* 先看次数：$\sin$ 乘 $\cos$ 是一次幂，$\sin^2$ 或 $\cos^2$ 是二次幂，整体都是二次，因此必须用二倍角公式把二次幂全部降次换成一次幂。
* 降次过程中次数下降，角由一倍角变成二倍角：$\sin\alpha\cos\alpha=\dfrac12\sin 2\alpha$。
* $\cos^2\alpha=\dfrac12+\dfrac12\cos 2\alpha$，$\sin^2\alpha=\dfrac12-\dfrac12\cos 2\alpha$，两条直接写公式即可。
* 降次后若出现 $\sin$ 减 $\cos$ 的形式，最后一步必定用辅助角公式合并，一般合并为 $A\sin(\omega x+\varphi)+B$。
* 遇到 $\sin$ 减 $\cos$ 时，看谁的 $\cos$ 是 $\dfrac{\sqrt3}{2}$、谁的 $\sin$ 是 $\dfrac12$，两者都是 $30^\circ$ 即 $\dfrac{\pi}{6}$，据此可合并成 $\sin\left(2\alpha-\dfrac{\pi}{6}\right)$。
* 合并成标准形式后，关于对称轴、奇偶性、增区间、零点的问题都可以接着处理。

## 例题速查

### 求值化简

* 化简 $\dfrac{\sin 2\theta}{2+\cos^2 2\theta}$：走找次数关系路线，分母先改写成 $\sin^2\theta+3\cos^2\theta$，再上下同除以 $\cos^2\theta$，结果为 $\dfrac{2\tan\theta}{\tan^2\theta+3}$。

### 标志识别

* $\dfrac{\sqrt3}{2}\cos\theta-\dfrac12\sin\theta$ 化简为 $\sin\left(\dfrac{\pi}{3}-\theta\right)$。
* $\dfrac{2\tan\theta}{1+\tan^2\theta}$ 化简为 $\sin 2\theta$，走万能公式路线，分母是加号所以不是二倍角。
* $\dfrac{1-\cos 2\theta}{1+\cos 2\theta}$ 由 $1-\cos2\theta=2\sin^2\theta$、$1+\cos2\theta=2\cos^2\theta$ 化简为 $\tan^2\theta$。

### 求值

* 已知 $\sin\beta=\dfrac{\sqrt3}{3}$，求 $\sin\left(\dfrac{\pi}{2}-4\beta\right)$：诱导公式化为 $\cos 4\beta$，由 $\cos 2\beta=1-2\sin^2\beta=\dfrac13$ 再由 $\cos 4\beta=2\cos^2 2\beta-1=\dfrac29-1$ 得 $-\dfrac79$。

### 抽象函数单调性

* 设 $g(x)=\dfrac{f(x)}{x}$ 在 $(0,+\infty)$ 上单调递减且 $f(2)=4$，求使 $f(x)>2(x-3)$ 成立的 $x$ 的范围：$g(2)=\dfrac{f(2)}{2}=2$，原不等式等价于 $g(x-3)>g(2)$，由 $g$ 单调递减得 $x-3<2$ 即 $x<5$，再由定义域得 $x>3$，两者取交集得 $3<x<5$。

### 降次合并练习

* $\sin$ 乘 $\cos$ 配 $\sin^2$ 或 $\cos^2$ 再加一个常数的题，按「降次 → 辅助角合并成 $A\sin(2\alpha+\varphi)+B$」的链路完整走一遍，题干完整版见课堂板书。
