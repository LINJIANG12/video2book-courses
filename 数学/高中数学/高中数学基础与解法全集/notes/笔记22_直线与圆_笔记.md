# 直线与圆

## 倾斜角与斜率

### 倾斜角

* **倾斜角（angle of inclination）**

    * > **定义**：$x$ 轴正方向与直线 $l$ 向上方向所成的角，记作 $\alpha$。所谓"向上方向"指直线从下往上走的那一端；直线掉头后向上端随之换边。

    * 每条直线都有倾斜角，一条不例外，包括竖直直线。

    * 取值范围是 $[0,\pi)$，左闭右开。取 $\pi$ 不到的唯一理由：与 $x$ 轴平行的直线若取指向左侧的方向作向上端，夹角为 $180^\circ$，与"每条直线只能有一个倾斜角"冲突，因此统一规定取 $0^\circ$。

    * 倾斜角有锐角也有钝角，不都小于 $90^\circ$。

* **判定要点**

    * $\alpha$ 可取 $0$ 意味着 $\sin\alpha$ 不一定大于零：取 $\alpha=0$ 时 $\sin\alpha=0$。

### 斜率

* **斜率（slope）**

    * > **定义**：$k=\tan\alpha$，$\alpha$ 为该直线的倾斜角。物理原型是斜面的坡度，即倾斜角正切值；$\tan$ 值越小直线越平，越大越陡。

    * 斜率与解析式 $y=kx+b$ 中的系数 $k$ 是同一个数，几何量与代数系数合一。

    * 由两点坐标求：$k=\dfrac{y_1-y_2}{x_1-x_2}$。作垂线构造直角三角形，对边是纵坐标之差，邻边是横坐标之差。

    * > **易错点**：$\frac{y_1-y_2}{x_1-x_2}$ 与 $\frac{y_2-y_1}{x_2-x_1}$ 等价，但分子分母必须同向相减；一处用 $1-2$、另一处用 $2-1$ 会得到相反数。

* **单值性**

    * 斜率相等的两条直线，倾斜角一定相等（$k_1=k_2$ 推出 $\alpha_1=\alpha_2$）。

### 竖直线：有角无斜率

* **唯一缺口**

    * 与 $x$ 轴垂直的直线倾斜角为 $\dfrac{\pi}{2}$，倾斜角存在；但 $\tan\dfrac{\pi}{2}$ 无意义，斜率不存在。

    * 其余直线都有斜率：单调递增为正，单调递减为负。倾斜角与斜率不是一一对应，倾斜角全覆盖而斜率有缺岗。

    * > **易错点**：竖直线是"看着会做却每道都错"的典型来源；凡涉及 $k$ 的推导，都必须回头检验竖直情形是否被漏掉。

```text
        唯一"有角没斜率"的直线：

                    |
                    |   与 x 轴垂直
                    |   倾斜角 alpha = pi/2   ✓ 存在
                    |
        ------------+--------------> x 轴
                    |
              k = tan(pi/2) = tan 90deg   ✗ 不存在
```

* **互推的两个方向错误**

    * "倾斜角为 $\alpha$ 则斜率必为 $\tan\alpha$"——错误，$\alpha=\dfrac{\pi}{2}$ 时无斜率。

    * "斜率为 $\tan\alpha$ 则倾斜角必为 $\alpha$"——错误，未限定 $\alpha\in[0,\pi)$ 且 $\alpha\ne\dfrac{\pi}{2}$ 时，正切的周期性使 $\tan405^\circ=\tan45^\circ=1$，反推不唯一。

    * > **提示**：两类错误方向相反——一是没有斜率也敢写 $k=\tan\alpha$，二是有 $k=\tan\alpha$ 就敢反推 $\alpha$。凡 $k$ 与 $\alpha$ 互推，先确认 $\alpha$ 的范围是否被钉死。

### 平行与垂直的斜率判据

* **平行**

    * 平行 $\Rightarrow$ $k_1=k_2$。

    * > **结论**：平行一定斜率相等，但斜率相等不一定平行，反用时必须排除两直线重合。

* **垂直**

    * $k_1k_2=-1$，即两斜率互为负倒数。由 $k_2=\tan\left(\dfrac{\pi}{2}+\alpha\right)=-\dfrac{1}{\tan\alpha}$ 得出。

* **前提与漏解**

    * 上述全部推导只在两直线斜率都存在时成立；含竖直直线时 $k_1=k_2$ 与 $k_1k_2=-1$ 双双失效，必须单独验证。

    * 平行例题：$2ax+y-1=0$ 与 $(3a-1)x-4ay-1=0$ 平行。有斜率时 $k_1=-\frac{1}{2a}$、$k_2=\frac{3a-1}{4a}$，等值得 $a=-\dfrac{1}{3}$；无斜率时 $a=0$，两线为 $x=1$ 与 $x=-1$，仍平行。答案 $a\in\left\{-\dfrac{1}{3},\,0\right\}$。

    * 垂直例题：$ax+2y+6=0$ 与 $x+a(a+1)y-1=0$ 垂直。有斜率时 $k_1=-\dfrac{a}{2}$、$k_2=-\dfrac{1}{a(a+1)}$，积为 $-1$ 得 $a=-\dfrac{3}{2}$；无斜率时 $a=0$，两线为 $y=-3$ 与 $x=1$，仍垂直。答案 $a\in\left\{-\dfrac{3}{2},\,0\right\}$。

    * > **易错点**：把 $y$ 系数除过去时未检验该系数是否为 $0$，是漏掉第二个解的直接原因。

### 倾斜角范围与斜率范围的换算

* **同一情境两套区间**

    * 已知 $A(-2,3)$、$B(\sqrt3,4)$，直线 $l$ 过 $P(0,1)$ 且与线段 $AB$ 有交点。临界直线是 $PA$ 与 $PB$：$k_{PA}=\dfrac{3-1}{-2-0}=-1$ 对应 $\alpha=135^\circ$，$k_{PB}=\dfrac{4-1}{\sqrt3-0}=\sqrt3$ 对应 $\alpha=60^\circ$。

    * 倾斜角轴从 $0$ 起转到 $\pi$：$\alpha\in\left[\dfrac{\pi}{3},\,\dfrac{3\pi}{4}\right]$，两端闭，因为线段相交含与端点相交。

    * 斜率轴从 $\pm\infty$（即竖直位置）起转，要跳过中间整段：$k\in(-\infty,-1]\cup[\sqrt3,+\infty)$。

    * > **易错点**：斜率的区间不是 $[-1,\sqrt3]$，那恰恰是要扔掉的一段。两者做题步骤相同但起点与范围不同。

```text
倾斜角轴（从 0 开始转，转到 pi 为止）：

   0        [ pi/3 == pi/2 === 3pi/4 ]        pi
   X ------<======= 允许区间 ========>--------X
  取不到          闭区间，两端都取得到        取不到


斜率轴（从 -inf 开始转，转到 +inf 为止，起点是竖直线的位置）：

  -inf <====== [-1]        [ sqrt(3) ======> +inf
                 \________/
                  整段都要扔掉
```

### 三点共线与三线不能成三角形

* **三点不能构成三角形**

    * 翻译为三点共线，即任取两点求斜率并令其相等。

    * $A(1,2)$、$B(5,-4)$、$C(9,t)$：$k_{AB}=\dfrac{2-(-4)}{1-5}=-\dfrac{3}{2}$，$k_{BC}=\dfrac{t+4}{9-5}=\dfrac{t+4}{4}$，相等得 $t=-10$。

* **三条直线不能构成三角形**

    * 存在三种翻译，只想到第一种是绝大多数人的终点。

    * $l_1: ax+2y-1=0$、$l_2: y=2x+1$、$l_3: y=-3x-1$，$k_1=-\dfrac{a}{2}$。

    * 情形一：$k_1=k_2$，$a=-4$；情形二：$k_1=k_3$，$a=6$（两线平行已含重合情形）。

    * 情形三：三线交于同一点。联立已知两线得交点 $\left(-\dfrac{2}{5},\,\dfrac{1}{5}\right$，代入 $l_1$ 得 $a\left(-\dfrac{2}{5}\right)+2\left(\dfrac{1}{5}\right)-1=0$，$a=-\dfrac{3}{2}$。

    * > **结论**：$a\in\left\{6,\,-4,\,-\dfrac{3}{2}\right\}$。斜率全不相等时三线未必能围成三角形，汇聚一点同样构不成。

```text
"三条直线不能构成三角形" 的三种翻译：

   (1) 其中两条平行     ->  k 相同      ->  a = 6  或  a = -4
   (2) 其中两条重合     ->  k 相同      ->  已含在 (1) 里
   (3) 三条交于同一点   ->  联立解出交点，
                            该交点在第一条直线上  ->  a = -3/2
```

## 直线的方程

### 确定一条直线的条件

* **两个要素**

    * 经过一个点的直线有无数条，缺的是倾斜方向；一个点加一个斜率就唯一确定一条直线。

    * 翻译成式子的通行手段是"设"：把线上任一点坐标设为 $(x,y)$，再去找 $x$ 与 $y$ 的关系。

* **三种方程形式**

    * > **定义**：点斜式 $y-y_1=k(x-x_1)$，由一点一斜率直接写出。

    * > **定义**：两点式 $y-y_1=\dfrac{y_1-y_2}{x_1-x_2}(x-x_1)$，把斜率用两点坐标预先算好。

    * > **定义**：直线一般式 $Ax+By+C=0$，即"多少 $x$ 加多少 $y$ 加多少等于 $0$"，见到即知是一条直线。

    * > **易错点**：两点式与点斜式没有本质区别，区别只在斜率是否已算好；已知两点坐标时用两点式即可，其余变体不必学。

* **斜率不直接给时**

    * 已知直线过 $(-1,2)$ 且与 $3y=2x+9$ 垂直：整理后者得 $k_2=\dfrac{2}{3}$，由 $k_1k_2=-1$ 得 $k_1=-\dfrac{3}{2}$，代点斜式得 $2y+3x-1=0$。

### 垂直平分线与中点公式

* **中点坐标公式**

    * > **定义**：$M\left(\dfrac{x_1+x_2}{2},\,\dfrac{y_1+y_2}{2}\right)$，对应坐标取平均。

* **求法拆成两件**

    * 垂直平分线同时具备"过 $AB$ 中点"与"垂直于 $AB$"，即一点一斜率，直接套点斜式。

    * 例：$AB$ 斜率为 $-\dfrac{1}{3}$，中点 $(2,3)$，垂直平分线斜率 $3$，方程 $3x-y-3=0$。

### 设元：一步压一个变量

* **一个变量原则**

    * 设点的坐标时，若该点落在某条已知直线上，第一步就把该直线的解析式用上，把两个坐标压成一个变量；写成 $(m,n)$ 等于人为引入两个变量并制造冗余约束。

    * 例：点 $B$ 在 $y=\dfrac{1}{2}x-\dfrac{5}{2}$ 上，应写成 $\left(m,\,\dfrac{1}{2}m-\dfrac{5}{2}\right)$，再借中点条件 $M\left(\dfrac{5+m}{2},\,\dfrac{m-3}{4}\right)$ 落在 $2x-y-5=0$ 上解出 $m=-1$。

* **三角形里求第三条边**

    * 已知 $A(5,1)$、中线 $CM$ 在 $2x-y-5=0$ 上、高 $BH$ 在 $x-2y-5=0$ 上，求 $BC$。

    * 中线条件眼下两端坐标全缺，先搁置；高条件提供垂直关系 $k_{BH}=-2$，配合 $A$ 得 $AC: y=-2x+11$。

    * 与中线联立得 $C(4,3)$；$B$ 设成一元后代入中线得 $B(-1,-3)$；两点式收尾 $5y-6x+9=0$。

### 法向量

* **法向量（normal vector）**

    * > **结论**：一般式 $Ax+By+C=0$ 中，由 $A$、$B$ 组成的向量 $(A,B)$ 必是该直线的法向量，即与直线方向垂直。

    * 证明路径：找截距得两个点，作原点到直线的垂线，构造 $3$、$4$、$5$ 一类的全等直角三角形，垂线方向即 $(A,B)$。

    * 法向量有无穷多个，但 $(A,B)$ 必定是其中之一；系数长得再古怪结论也不变，如 $5x-6y+11=0$ 的法向量是 $(5,-6)$。

## 距离公式

### 两点间距离公式

* **公式**

    * $d=\sqrt{(x_1-x_2)^2+(y_1-y_2)^2}$，由作平行于坐标轴的辅助线补出直角三角形，再对勾股定理得到。

    * > **易错点**：横纵坐标之差必须加绝对值，谁大谁小随图形而定；纵坐标方向可以互换，因为外层有平方。

    * 谁当 $(x_1,y_1)$、谁当 $(x_2,y_2)$ 无所谓。

* **交点坐标**

    * 两条直线联立解二元一次方程组即可，不平行必有交点；这是本章唯一不需要额外公式的知识点。

### 点到直线距离公式

* **公式**

    * $d=\dfrac{\left|Ax_0+By_0+C\right|}{\sqrt{A^2+B^2}}$，其中直线为 $Ax+By+C=0$，点为 $P(x_0,y_0)$。

    * 推导链：垂足 $Q$ 在"过 $P$ 且斜率为 $\dfrac{B}{A}$ 的直线"上；借助法向量做投影 $d=\dfrac{\left|\vec{PG}\cdot\vec{n}\right|}{|\vec{n}|}$；因 $G$ 在直线上满足 $Ax_1+By_1=-C$，代入后 $x_1,y_1$ 消失、$C$ 保留。

    * 笨办法（过 $P$ 作垂线、联立求 $Q$、再套两点间距离）结果相同但计算量极大。

* **记法三步**

    * 第一步也是最关键的一步：直线必须先化成一般式 $Ax+By+C=0$。

    * 分母：一次项系数的平方和开根号，常数项不参与。

    * 分子：把点当变量代进直线解析式，算完取绝对值。

    * 原点无特权，公式中它就是 $(0,0)$。

    * 例：点 $(1,3)$ 到 $2x-y+5=0$，$d=\dfrac{4}{\sqrt5}=\dfrac{4\sqrt5}{5}$；点 $(-2,0)$ 与 $(4,a)$ 到 $x-y+1=0$ 距离相等，约分后 $|5-a|=1$，$a=4$ 或 $6$。

### 平行线间距离公式

* **公式与由来**

    * 两条平行线必同斜率，可写为 $Ax+By+C_1=0$ 与 $Ax+By+C_2=0$（平行时 $C_1\ne C_2$）。

    * 在一条线上任取点作垂线，转化成点到直线距离，得 $d=\dfrac{|C_1-C_2|}{\sqrt{A^2+B^2}}$。

    * 例：$x+2y-3=0$ 与 $x+2y+6=0$，$d=\dfrac{9}{\sqrt5}=\dfrac{9\sqrt5}{5}$。

* **系数必须配齐**

    * > **易错点**：公式成立的前提是两条直线的 $x$、$y$ 系数完全相等；出现两组不同系数时先化齐，否则分母取谁无从下手。

    * $x+2y-3=0$ 与 $2x+4y+3=0$：把前者整体乘 $2$ 配齐后得 $d=\dfrac{9}{\sqrt{20}}=\dfrac{9\sqrt5}{10}$。

    * "两直线上任取 $P$、$Q$ 求 $PQ$ 最小值"绕一道弯仍是同一件事：垂线段最短，即平行线间距离。$3x+4y-7=0$ 与 $6x+8y+3=0$ 配齐后得 $\dfrac{17}{10}$。

## 圆的标准方程

### 标准方程与读方程

* **圆的标准方程**

    * > **定义**：$(x-a)^2+(y-b)^2=r^2$，圆心 $(a,b)$，半径 $r$。

    * 来源是圆的定义（圆上点到圆心距离为定值）配两点间距离公式，平方去掉根号。

    * 双向使用：给圆心半径能写出式子，给式子能一眼读出圆心与半径。

    * > **易错点**：圆心取括号内数的相反数（标准式写的是减号），半径取右端数的算术平方根而非其本身。$(x+1)^2+(y+3)^2=2$ 的圆心是 $(-1,-3)$、半径是 $\sqrt2$；$(x-1)^2+(y-2)^2=3$ 的圆心是 $(1,2)$、半径是 $\sqrt3$。

### 求圆心半径的三种给法

* **条件类型**

    * 直接给出圆心与半径。

    * 借初中几何：圆上两点到圆心等距，圆心落在该两点连线的垂直平分线上；求垂直平分线后与"圆心所在直线"联立。

    * 情境包装：斐波那契螺旋线用 $1,1,2,3,5,8,13$ 作半径（每个数等于前两个之和），问下一段圆弧所在圆得 $(x+4)^2+(y-2)^2=169$。

* **设一元解法**

    * 圆心在直线 $y=-2x+1$ 上且 $(3,0)$、$(0,1)$ 都在圆上：设圆心横坐标为 $m$、纵坐标写 $-2m+1$，只留一个变量；由两点到圆心距离相等平方后约去 $5m^2$，得 $10m=10$，$m=1$。

    * > **提示**：点落在已知直线上时纵坐标直接写成对应值，避免引入两个无法联立的变量。

* **垂直平分线解法**

    * 同一题中 $(3,0)$ 与 $(0,1)$ 的垂直平分线为 $3x-y-4=0$，与 $y=-2x+1$ 联立同样得圆心 $(1,-1)$、半径 $\sqrt5$、方程 $(x-1)^2+(y+1)^2=5$。

### 点与圆的位置关系

* **判定式**

    * > **结论**：比较 $(x_0-a)^2+(y_0-b)^2$ 与 $r^2$——小于在圆内，等于在圆上，大于在圆外；不画图，代数判定。

    * 该判定是后续大量参数范围题的地基，一般方程同样适用。

### 圆上最值铁律

* **通用规律**

    * > **结论**：凡与圆有关的最值问题，最值都在"定点与圆心相连"的那条直线上取得。

* **四个落点**

    * 圆外定点 $G$ 与圆上动点：最大值 $d+r$，最小值 $d-r$（$d>r$）。

    * 圆内定点 $G$ 与圆上动点：最大值 $d+r$，最小值 $r-d$。公式仍是连圆心，一字不改。

    * 圆上动点到定直线：过圆心作该直线的垂线，两个交点分别是最大与最小位置；只需求圆心到直线距离 $d$，加减半径。

* **典型应用**

    * 过两点的最小圆以两点连线为直径，圆心为中点。过 $P(4,3)$、$Q(2,5)$ 的最小圆圆心 $(3,4)$、半径 $\sqrt2$，圆上点到原点距离范围为 $[5-\sqrt2,\,5+\sqrt2]$。

    * 半径为 $2$ 的圆过定点 $(5,12)$、求圆心到原点距离：圆心轨迹是以 $(5,12)$ 为圆心、半径 $2$ 的圆，原问题平移成圆上动点到定点问题，最小值 $13-2$。

## 圆的一般方程

### 配方

* **一般方程**

    * > **定义**：$x^2+y^2+Dx+Ey+F=0$，由标准方程展开、合并同类项、全挪到等号左边得到；反过程叫配方。

    * > **提示**：由上到下是展开，由下到上是配方；考试里给数字，给字母只在校验推导时出现。

    * 配方动作：$x^2+Dx$ 补 $\frac{D^2}{4}$ 凑成 $\left(x+\frac{D}{2}\right)^2$，$y$ 侧同理；常数项移到右边变 $-F$，两边同补 $\frac{D^2}{4}+\frac{E^2}{4}$ 后约掉。

    * 结果 $\left(x+\frac{D}{2}\right)^2+\left(y+\frac{E}{2}\right)^2=\frac14\left(D^2+E^2-4F\right)$。

### 圆心与半径的读取

* **公式**

    * > **结论**：圆心 $\left(-\dfrac{D}{2},\,-\dfrac{E}{2}\right)$，即 $x$、$y$ 一次项系数各除以 $-2$；半径 $r=\dfrac12\sqrt{D^2+E^2-4F}$。

    * $x^2+y^2-4x-m$ 中 $D=-4$、$E=0$、$F=-m$，半径 $\frac12\sqrt{16+4m}$；若圆面积为 $\pi$ 即 $r=1$，得 $m=-3$。

    * > **提示**：半径公式远不如圆心公式好记，且高中会背的公式到高三常会忘。$x^2+y^2-4x-m$ 配方成 $(x-2)^2+y^2=m+4$，速度并不慢。

    * > **易错点**：配方是必须掌握的核心方法，不能只靠背公式——后续圆锥曲线模块公式更多，方法比记忆保值。

### 长得像圆不一定是圆

* **判别式**

    * > **结论**：凡是形如 $x^2+y^2+Dx+Ey+F=0$ 的方程，用 $D^2+E^2-4F$ 的符号判断：正为圆，零为一点（半径 $0$ 的圆），负为空集（平方和不可能小于 $0$）。

    * 例：$D^2+E^2-4F=4+16-24<0$，方程不表示任何图形。

    * 判据记不住时直接配方看式子是否成立。

* **二次项系数不必等于 1**

    * > **易错点**：圆的一般方程中 $x^2$ 与 $y^2$ 的系数只需相同，不要求等于 $1$；两边同乘非零数仍是同一个圆。

    * $ax^2+(a+2)y^2+ax+\cdots$ 型方程为圆的条件是 $a^2=a+2$，得 $a=2$ 或 $a=-1$；$a=2$ 时归一后 $D^2+E^2-4F=1+4-10<0$，不成立，故 $a=-1$。

    * 对应方程 $x^2+y^2+4x+8y-5=0$，圆心 $(-2,-4)$，半径 $\frac12\sqrt{16+64+20}=5$。

    * 形如 $3x^2-3y^2$ 的正负不同系数不是圆，可能为双曲线。

### 已知三点定圆

* **两种方法**

    * 几何法：圆心在任意两点连线的垂直平分线上，两条垂直平分线交点即圆心。$(-1,2)$、$(2,5)$、$(7,2)$ 中第一三点连线水平，中垂线为 $x=3$，与另一点中垂线交得圆心 $(3,1)$。

    * 代数法：设 $x^2+y^2+Dx+Ey+F=0$，三点代入得三元一次方程组 $D-2E-F=5$、$2D+5E+F=-29$、$7D+2E+F=-53$，解出 $D=-6$、$E=-2$、$F=-7$。

    * > **结论**：三点给得特殊时几何法顺手，三点歪斜时代数法更稳；两法都必须会。

* **一般方程下的点与圆、动点最值**

    * 标准方程的一切结论可原样平移。点 $P(1,2)$ 在圆外求参数范围时，除代入得 $m>-2$ 外，还须并上方程本身成圆的条件 $1^2+(-2)^2-4m>0$ 即 $m<\frac54$，最终 $m\in\left(-2,\tfrac54\right)$。

    * > **易错点**：只代入不等式就交卷是这类题最常见的失分点，开区间才是满分答案。

    * $x^2+y^2-4x+4y+6=0$ 配成 $(x-2)^2+(y+2)^2=2$，三角形面积最小等价于圆上点到定直线距离最小，过圆心作垂线，高最小值 $3\sqrt2-\sqrt2=2\sqrt2$，底 $2\sqrt2$，面积 $4$。

## 直线与圆的位置关系

### 三种关系与判定

* **分类**

    * 按交点个数分相交、相切、相离三种，全部由圆心到直线的距离 $d$ 与半径 $r$ 比较决定。

    * > **结论**：$d<r$ 相交（两交点，可求弦长），$d=r$ 相切（一交点，半径垂直切线），$d>r$ 相离（无交点，出不了什么题）。

    * 相切的代数依据是初中几何的切线性质——切点与圆心连线必垂直于切线，故 $d$ 恰为半径。

```text
        相交                 相切                 相离
      _________          __________          __________
     /         \        /          \        /            \
    |     O     |      |     O      |      |      O       |
     \_________/        \____●_____/        \____________/
       d < r               d = r               d > r
      两个交点             一个切点             没有交点
     可以求弦长          半径 ⊥ 切线          出不了什么题
```

### 相交时求弦长

* **垂径定理**

    * 圆上一条弦被过圆心的垂线平分，源于两端半径构成的等腰三角形三线合一。

    * 半弦长 $m=\sqrt{r^2-d^2}$，弦长 $AB=2m$；斜边是半径、直角边是圆心到直线距离，构成直角三角形。

```text
            A
           /|\
          / | \
       r /  |h  \ m  ← 半弦长
        /   |d   \
       C----M-----B
          弦 AB = 2m

   d = 圆心到直线的距离   （高）
   r = 半径                （斜边）
   m = √(r² − d²) = 弦长 / 2
```

* **例算**

    * 圆 $(x-1)^2+y^2=1$ 与直线 $x+3y-2=0$：$d=\frac{|1-2|}{\sqrt{10}}=\frac{1}{\sqrt{10}}$，$d<r$ 故相交；弦长 $2\sqrt{1-\frac{1}{10}}=2\sqrt{\frac{9}{10}}$。

    * 圆 $(x-1)^2+(y-1)^2=3$ 与 $x-y+m=0$，弦长也是 $m$：$d=\frac{|m|}{\sqrt2}$，$\left(\frac{m}{2}\right)^2+\left(\frac{m}{\sqrt2}\right)^2=3$ 得 $m=2$。

### 弦长的最值

* **两个极值**

    * > **结论**：过定点的弦中，最长的是"圆心与定点连线所成的直径"（长度 $2r$），最短的是与这条直径垂直的弦。

    * 证明骨架：任取一条不垂直的弦，两直角三角形斜边同为半径、平方和为定值，比较 $OP$ 与 $OH$ 即可知不垂直时更长。

* **定点直接给出**

    * 圆 $x^2+y^2-6x=0$（圆心 $(3,0)$，半径 $3$），过 $(1,2)$ 的弦最短：$OP=\sqrt{(3-1)^2+(0-2)^2}=2\sqrt2$，半弦长 $\sqrt{9-8}=1$，弦长 $2$。此处无需求直线方程，直接两点间距离即可。

* **定点藏在含参直线里**

    * 直线 $y+a(x-1)+2=0$ 合并为 $a(x-1)+(y+2)=0$，令参数失效即令 $x-1=0$，得定点 $(1,-2)$，问题退化为上一条。

    * 圆心 $(0,-2)$、半径 $\sqrt5$ 时，半径 $1$、$OP=1$，最短弦长 $4$。

* **三角形面积**

    * 圆心 $(1,0)$、半径 $2$ 与直线 $x+my+1=0$ 交于 $A,B$，要求 $S=\frac85$：$d=\frac{2}{\sqrt{1+m^2}}$，$S=\sqrt{4-d^2}\cdot d$，平方化简得 $25m^2=4(1+m^2)^2$，因 $1+m^2>0$ 可直接开根号，化为 $2m^2-5|m|+2=0$，$(2|m|-1)(|m|-2)=0$，$m=\pm\frac12$ 或 $\pm2$。

### 相切

* **由相切求参数**

    * 圆 $(x-1)^2+(y-1)^2=1$ 与 $3x+4y-b=0$ 相切：$\frac{|7-b|}{5}=1$，$b=2$ 或 $12$。

* **切线长**

    * 圆心 $(2,1)$、半径 $1$，原点 $O$ 与圆相切于 $P$：$OP^2=OC^2-R^2=5-1$，$OP=2$。不必求出切点坐标，切点处直角三角形内直角边为半径、斜边为定点到圆心的距离。

* **两切线夹角**

    * 圆心 $(2,0)$、半径 $\sqrt5$，过 $(0,-2)$ 作两切线夹角 $\alpha$：连圆心与定点构成对称图形，$\alpha=2\theta$，$\sin\theta=\frac{\sqrt5}{2\sqrt2}$，$\cos\theta=\sqrt{\frac38}$，倍角公式得 $\sin\alpha=\frac{\sqrt{15}}{4}$。

    * > **提示**：上下对称时求一半是最省力的入口，整体图形太大不好下手。

* **两切点间距离**

    * 圆 $(x-3)^2+(y-4)^2=5$ 从原点引两切线，切点 $P$、$Q$：$OP=5$（两点间距离），切线长 $\sqrt{25-5}=2\sqrt5$；求 $PQ$ 用等面积法，半弦长等于 $\frac{\frac12\sqrt5\cdot 2\sqrt5}{\frac12\cdot 5}=2$，$PQ=4$。

## 圆与圆的位置关系

### 五种位置关系

* **圆心距一把尺子**

    * > **结论**：只看圆心距 $d$ 与 $r_1+r_2$、$|r_1-r_2|$ 这两个临界值的关系。记两个相切极限即可，其余三种自然带出。

    * $d=r_1+r_2$ 外切，$d=|r_1-r_2|$ 内切；比外切临界更大是外离，比内切临界更小是内含，夹在两者之间是相交。

```text
O---------O      外离
  O-------O      外切
    O-----O      相交
      O---O
        O-O      内切
        (O)      内含
```

| 位置关系 | 圆心距与半径的关系 | 公共切线条数 |
| :--- | :--- | :--- |
| 外离 | $d > r_1 + r_2$ | 4 |
| 外切 | $d = r_1 + r_2$ | 3 |
| 相交 | $\lvert r_1 - r_2 \rvert < d < r_1 + r_2$ | 2 |
| 内切 | $d = \lvert r_1 - r_2 \rvert$ | 1 |
| 内含 | $d < \lvert r_1 - r_2 \rvert$ | 0 |

* **先化标准再比大小**

    * > **易错点**：$r_1$、$r_2$ 是半径不是半径的平方。给 $r^2=4$ 要先开方得 $r=2$，直接拿 $4$ 与圆心距比是本类题的主要失分点。

    * $(x+2)^2+y^2=4$ 与 $(x-2)^2+(y-1)^2=9$：$r_1=2$、$r_2=3$，$d=\sqrt{(-2-2)^2+(0-1)^2}=\sqrt{17}$，因 $1<\sqrt{17}<5$ 故相交；若圆心距换成 $8$，则 $8>5$ 外离。

    * $x^2+y^2=1$ 与 $x^2+y^2-6x-8y+m=0$ 外切：后者配方得 $(x-3)^2+(y-4)^2=25-m$，圆心 $(3,4)$，$r_2=\sqrt{25-m}$，$d=5$，$5=1+\sqrt{25-m}$ 得 $m=9$。

    * > **易错点**：配方后右边是 $25-m$ 整体，既不是 $25$ 也不是 $-m$；开根号那一步不能丢。

* **反向考查**

    * "两圆有且仅有三条公切线"直接翻译成外切；先判位置再答条数即可。

### 求公切线方程

* **对称性把两个未知数压成一个**

    * 单位圆 $x^2+y^2=1$ 与圆心 $(3,4)$、半径 $4$ 的圆：$d=5=1+4$ 外切，共三条公切线。

    * 竖直那条最好求：到 $(0,0)$ 距离 $1$、到 $(3,4)$ 距离 $4$，直接得 $l_1:\ x=-1$。

    * 两条外公切线关于连心线对称，交点落在连心线上。连心线过 $(0,0)$ 与 $(3,4)$，即 $y=\frac{4}{3}x$；令 $x=-1$ 得该点 $\left(-1,-\frac{4}{3}\right)$，称外位似中心。

    * 已知该定点后改设点斜式 $y+\frac{4}{3}=k(x+1)$，只对小圆圆心列一次距离式 $\frac{|k-\frac{4}{3}|}{\sqrt{k^2+1}}=1$，解得 $k=\frac{7}{24}$，即 $l_2:\ 7x-24y-25=0$。

    * 第三条切线过两圆切点，垂直于连心线，斜率 $-\frac{3}{4}$ 为负倒数；设 $y=-\frac{3}{4}x+m$，由原点距离得 $|m|=\frac{5}{4}$，由图取正，$l_3:\ 3x+4y-5=0$。

    * > **提示**：竖直的切线写不成 $y=kx+m$，斜率法捞不到它，必须看图数长度单独捡出来。

    * > **提示**：出现两个解不知道留哪个时，代回另一个圆验一遍。$m=-\frac{5}{4}$ 对应 $3x+4y+5=0$，到大圆圆心距离为 $6$ 而非 $4$，一验即露。

```text
                    l2:  7x - 24y - 25 = 0
                         /
                        /
        P(-1, -4/3)  * /
                    |/          O(0,0) r=1
      l1: x = -1    |              O(3,4) r=4
                    |\
                    | \
                    |  \         l3:  3x + 4y - 5 = 0
                    |   \
```

    * 只有 $l_1$、$l_2$ 这对共点于 $P$；过切点的 $l_3$ 不经过 $P$。外切三线中只有两条共点，不能记成"三条都过那一点"。

## 直线与圆的最值

### 四个基础模型

* **通用第一步**

    * > **结论**：所有与圆有关的最值问题第一步都是找圆心；圆心连线的两个交点就是最值点。

* **模型清单**

    * 圆上动点到定点 $G$：连线与直径的两个交点取最大 $|OG|+R$ 与最小 $|R-OG|$，依据是三角形两边之和大于第三边。

    * 圆上动点到定直线：过圆心作垂线取两个交点，距离在 $[|d-R|,\,d+R]$ 上跑。

    * 过圆内定点作弦：最长为 $OP$ 所在直径 $2R$；最短是与 $OP$ 垂直的弦，$L_{\min}=2\sqrt{R^2-d^2}$，$d=OP$。

    * 两圆上各取一动点：最长 $d+R_1+R_2$（异侧外端点），最短 $|d-R_1-R_2|$（内侧靠彼此一端）。

    * > **易错点**：动点到定直线求的是"圆上所有点"的最值，必须先算圆心到直线的距离再整体加减半径，拿圆上某一点去算没有意义。

    * > **提示**：双动点题第一反应永远是先固定一个，把它降成单动点。

### 先判内含还是相离

* **模型选错全盘皆错**

    * 单位圆与 $(x-3)^2+y^2=25$（圆心 $(3,0)$、半径 $5$）：圆心距 $3$，$3+1=4<5$，两圆内含而非相离。

    * 内含时最长 $d+R_1+R_2=9$，最短 $R_2-d-R_1=1$，两圆心均在 $x$ 轴上，连心线即 $x$ 轴本身。

    * > **结论**：这类题真正考的不是最值，而是会不会先判两圆关系。

### 将军饮马与对称化归

* **同侧折线对称成异侧线段**

    * 初中结论：从 $A$ 到河边再到 $B$，过 $A$ 作河岸对称点 $A'$，则 $AP+PB=A'P+PB\ge A'B$，两点共线时取等。

    * > **结论**：同侧折线距离问题，经常对称过来转成异侧线段长度问题。

* **定点加一个圆**

    * $A(0,3)$、$P$ 在 $y=-x-3$ 上、$Q$ 在圆 $(x-2)^2+(y-1)^2=5$ 上，求 $PA+PQ$ 最小值。对称 $A'$ 得 $(-6,-3)$，问题化为圆上动点到定点 $A'$ 的最小距离，等于 $|A'C|-r=4\sqrt5-\sqrt5=3\sqrt5$，此时 $A'$、原点、$C$ 三点共线。

    * > **易错点**：对称对象的优先级是能固定的就固定。点能对称而圆不好对称；把动圆整体对称过去等于把图形搬一遍，白费力气。

* **两圆各取一动点**

    * 两圆圆心 $(0,2)$、$(3,5)$，半径 $1$、$2$，$P$ 在 $x$ 轴上运动求 $PM+PN$ 最小。先对称较小圆，圆心变为 $(0,-2)$；先把两个动点固定，折线最短时 $P$ 在连线交点上，问题退化为两动点各自到 $P$ 的距离之和最小；再连两圆心，得 $\sqrt{58}-2-1=\sqrt{58}-3$。

### 定弦长加向量

* **隐藏的小圆**

    * > **定义**（弦中点轨迹）：半径为 $R$ 的圆上，长度为定值 $l$ 的弦的中点，轨迹是一个半径为 $\sqrt{R^2-\frac{l^2}{4}}$ 的圆，与原圆同心。

    * 圆 $(x-3)^2+y^2=4$（圆心 $(3,0)$、半径 $2$）上 $A,B$ 满足弦长 $2\sqrt3$，三角形为 $30^\circ$、$30^\circ$、$120^\circ$，圆心到弦中点距离恒为 $1$，弦中点 $G$ 在半径 $1$ 的隐藏圆上。

* **向量和**

    * 平行四边形对角线性质给 $\vec{OA}+\vec{OB}=2\vec{OG}$，于是求和模最小即求 $G$ 到 $O$ 的距离最小，答案 $2\times(3-1)=4$。

    * > **结论**：定弦长加向量和，等于找隐藏的小圆加连弦中点。

* **数量积**

    * 极化恒等式 $\vec{PA}\cdot\vec{PB}=\left(\vec{PG}+\vec{GA}\right)\cdot\left(\vec{PG}+\vec{GB}\right)=|\vec{PG}|^2-|\vec{GA}|^2$（$\vec{GA}$ 与 $\vec{GB}$ 互为相反数）。

    * 弦长 $2\sqrt3$ 使 $GA=\sqrt3$ 为常数，双动点降为单动点；$G$ 在半径 $1$ 的小圆上、$P$ 在 $y=-x+4\sqrt2$ 上，圆心到直线距离为 $4$，最短 $PG=4-1=3$，最小值 $3^2-(\sqrt3)^2=6$。

    * > **提示**：极化恒等式的价值不止是少算一步，更在于把双动点降成单动点。

### 数形结合三型

* **统一套路**

    * 看到什么式子就翻译成什么线，然后找相切；三型的差别只在收尾。

| 型 | 看到的样子 | 翻译成 | 边界条件 | 收尾 |
| :--- | :--- | :--- | :--- | :--- |
| 截距型 | $ax + by$ 的最值 | 直线 $ax + by = M$ | 与圆相切 | 取对应的那一侧 |
| 斜率型 | $\frac{y-a}{x-b}$ 的范围 | 连线斜率 $k$ | 与圆相切 | 取两根之间 |
| 距离型 | $\frac{\lvert ax+by+c\rvert}{\sqrt{a^2+b^2}}$ | 到直线 $ax+by+c=0$ 的距离 | 点到线距离 $\pm R$ | 结果别忘乘回 $\sqrt{a^2+b^2}$ |

* **截距型**

    * 圆 $(x-2)^2+(y-1)^2=9$ 求 $x-y$ 最大值：设 $x-y=M$ 即 $y=x-M$，$M$ 越大直线越低，最低仍与圆有交点处即相切。$d=\frac{|1-M|}{\sqrt2}=3$，两个解对应上下两个切点，取大者 $M_{\max}=1+3\sqrt2$。

* **斜率型**

    * 圆 $(x-3)^2+(y-3)^2=2$ 求 $\frac{y}{x}$ 范围：看作点 $(x,y)$ 与原点连线斜率，令 $y=kx$ 得 $\frac{|3k-3|}{\sqrt{1+k^2}}=\sqrt2$，平方化简 $7k^2-18k+7=0$，两根之间即范围。

    * 分子分母看不出斜率时先凑：$\frac{y}{x-1}=1+\frac{y-2}{x-1}$，于是转化为点 $(1,2)$ 的连线斜率范围；解得 $k=\frac{10\pm3\sqrt6}{2}$ 后还要加回 $1$，最终区间 $\left[2-\frac{3\sqrt6}{2},\,2+\frac{3\sqrt6}{2}\right]$。

* **距离型**

    * $\frac{|2x+y-1|}{\sqrt5}$ 中绝对值内的 $2x+y-1$ 就是直线 $2x+y-1=0$ 的左端，故该式等于圆上点到该直线的距离。圆心到直线距离 $\frac{8}{\sqrt5}$，加减半径 $\sqrt2$ 后乘回 $\sqrt5$，得 $\left[8-\sqrt{10},\,8+\sqrt{10}\right]$。

    * > **易错点**：距离型最容易漏的是最后乘回 $\sqrt{a^2+b^2}$——凑分母时人为多除了什么，答案必须还原。

### 参数方程与三角换元

* **圆的参数方程**

    * > **定义**：$\begin{cases}x=a+R\cos\alpha\\ y=b+R\sin\alpha\end{cases}$，本质是由 $\cos^2\alpha+\sin^2\alpha=1$ 得到的三角换元，作用是用一个变量同时表示两个变量、消元。

* **求线性式最值**

    * $(x-2)^2+(y-1)^2=9$ 代入得 $x-y=1+3\cos\alpha-3\sin\alpha=1+3\sqrt2\cos\left(\alpha+\frac{\pi}{4}\right)$，最大 $1+3\sqrt2$，与数形结合结果一致。

* **带权距离平方和**

    * $P$ 在单位圆上求 $PA^2+2PB^2+PC^2$ 的最大值与最小值之和：设 $x=\cos\alpha$、$y=\sin\alpha$ 逐项展开，$\cos^2\alpha+\sin^2\alpha=1$ 吃掉所有二次项，$\cos$ 项自行约掉，最后只剩 $K+A\sin\alpha$，最值之和即常数项的两倍 $2K$。

    * > **结论**：带权距离平方和的收尾是常数项的两倍，与 $\sin$ 的系数无关。

* **三等分点与斜率最大值**

    * 圆 $x^2+y^2=4$ 上动点 $P$，$A(1,0)$、$B(3,0)$，$M$ 在 $PA$ 上且 $PM=2MA$，求 $MB$ 斜率最大值。

    * 向量法：由 $\vec{AM}=\frac13\vec{AP}$ 得 $k=\frac{2\sin\alpha}{2\cos\alpha-7}=\frac{\sin\alpha}{\cos\alpha-\frac72}$，即单位圆上动点与定点 $\left(\frac72,0\right)$ 连线斜率，相切时最大，$k_{\max}=\frac{2\sqrt5}{15}$。

    * 几何法：在 $A$ 外侧取 $N(7,0)$ 使 $AN=3AP$，两条线斜率相同，问题变成固定点 $N(7,0)$ 到圆上动点的斜率最大，半径 $2$、$ON=7$，$\sin\theta=\frac{2}{7}$，得同一结果。

    * > **结论**：多想少算。数形结合与几何条件用得越充分，计算量越小；这套思路在椭圆、双曲线、抛物线上同样成立。

## 切线问题与隐圆

### 圆外点引切线

* **常规路线**

    * 直线过圆外点，设斜率 $k$ 写点斜式 $y-3=k(x-2)$，再令圆心到直线的距离等于半径：$\frac{|2k-3|}{\sqrt{1+k^2}}=\sqrt2$。

    * > **注意**：该路线以点在圆外为前提；点在圆上时套用纯属浪费。

### 圆上点引切线

* **改写法则**

    * 切点与圆心连线即半径，切线与半径垂直，斜率互为负倒数；由 $k=-\frac{x_0}{y_0}$ 与点斜式化简得 $x_0x+y_0y=x_0^2+y_0^2$。

    * > **结论**：圆 $x^2+y^2=R^2$ 上点 $P(x_0,y_0)$ 处的切线方程是 $x_0x+y_0y=R^2$。

    * 一般式 $x^2+y^2+2x-y-8=0$ 上点 $P(2,1)$ 的切线 $6x+y-13=0$。

* **记法**

    * 把 $x^2$ 想成两个 $x$ 相乘，把其中一个换成 $x_0$；$y^2$ 同理；常数项不动。

    * 一次项用均分原则：把 $x$ 写成 $\dfrac{x+x}{2}$，只把其中一个 $x$ 换成 $x_0$，于是 $x$ 改写为 $\frac{x_0+x}{2}$，系数与常数项都不动；负号一律当作系数的一部分。

    * 标准式更省事，不必展开成一般式：$(x-a)^2$ 当作两个 $x-a$，均分其一给 $x_0$ 即可。

### 切点弦

* **同一公式的第二次出场**

    * > **结论**：过圆外一点作圆的两条切线，两切点连成的切点弦方程，就是用该点改写圆方程所得的直线。

    * 圆 $x^2+y^2=4$ 外点 $(3,2)$ 的切点弦为 $3x+2y=4$。

* **成立的原因**

    * 设切点 $A(x_1,y_1)$、$B(x_2,y_2)$，$AB$ 同时是过 $A$ 与过 $B$ 的切线，故 $x_1x+y_1y=R^2$、$x_2x+y_2y=R^2$；两式都含点 $X_0Y_0$，把变的量设成 $x,y$、把 $x_0,y_0,R^2$ 固定，得 $x_0x+y_0y=R^2$，它同时过 $A$ 与 $B$，两点定线即切点弦。

    * 关键在于两式中 $x_0,y_0,R^2$ 不变、$x_1,x_2,y_1,y_2$ 变。

* **把动点静下来**

    * 圆心 $(2,0)$、半径 $1$，$M$ 在 $y=x$ 上作两切线，切点弦 $PQ$ 过 $(1,3)$：设 $M(m,m)$，对标准式改写得 $(m-2)(x-2)+my=1$，代入 $(1,3)$ 解得 $m=-\frac12$，切点弦为 $5x+y-8=0$。

### 切线最值三兄弟

* **同一模型的三问**

    * 直线上的动点 $P$ 引两切线，切点 $A,B$，圆心 $O$，三个问题共用同一结论。

    * $\sin\angle APB$ 最大：$\sin\alpha=\frac{R}{OP}$，要角度大就要斜边 $OP$ 小。

    * 四边形 $AOBP$ 面积最小：筝形面积为两个三角形之和，等价于切线长 $PB=\sqrt{OP^2-OB^2}$ 最小，同样要求 $OP$ 小。

    * 弦 $AB$ 最小：$AB=2R\cos\alpha$，$\cos\alpha$ 在 $\left(0,\frac{\pi}{2}\right)$ 上递减，故仍要求 $\alpha$ 最大。

    * > **结论**：三问的最值点是同一个——过圆心作 $P$ 点所在直线的垂线，垂足即最值点。

* **对角线乘积转面积**

    * 圆心 $M(1,1)$、直线 $y=-2x-2$，$P$ 引两切线切点 $A,B$，求 $PM\cdot AB$ 最小。对角线互相垂直的四边形面积等于对角线乘积一半，故等价于筝形面积最小。

    * 垂线过 $M$ 斜率为 $\frac12$，方程 $y-1=\frac12(x-1)$，与原直线联立得 $P(-1,0)$；再用 $P$ 改写圆方程得切点弦 $2x+y+1=0$。

* **由最大角反求斜率**

    * 圆 $(x+1)^2+(y-2)^2=4$ 与直线 $y-kx+1=0$ 相切，$\angle APB$ 最大值为 $90^\circ$：四边形中有三个直角且相邻边相等，为正方形，圆心到直线距离是半径的 $\sqrt2$ 倍即 $2\sqrt2$；$\frac{|3-k|}{\sqrt{1+k^2}}=2\sqrt2$，平方后 $(7k-1)(k+1)=0$，$k=\frac17$ 或 $k=-1$。

* **切点弦过定点与向量翻译**

    * 圆心 $(1,1)$、半径 $\sqrt2$，直线 $y=-x-1$ 上动点 $P(m,-m-1)$ 引两切线：切点弦整理得 $m(x-y)-x-2y+1=0$；令 $m$ 的系数为零并联立 $x-y=0$ 与 $-x-2y+1=0$，得过定点 $\left(\frac13,\frac13\right)$。

    * 弦中点 $M$ 与 $P$ 的距离最小时仍取垂足：$CP=\sqrt2+\frac{3\sqrt2}{2}=\frac{5\sqrt2}{2}$，$\sin\alpha=\frac25$，$PM=\sqrt2\left(\frac52-\frac25\right)=\frac{9\sqrt2}{10}$。

    * 大段代数不等式 $x_1(x_2-1)+y_1(y_2-1)+2-x_2-y_2<0$ 把 $2$ 拆成两个 $1$ 后化为 $(x_1-1)(x_2-1)+(y_1-1)(y_2-1)<0$，即两向量数量积小于零，说明夹角为钝角；问题最终等价于 $\angle APB$ 恒为锐角。

    * > **提示**：结构复盘——简单圆知识、切点弦定点、平面几何转三角函数、变形识别向量数量积，四问四法。

### 隐圆的第一条路：几何条件藏圆

* **识别标志**

    * $\angle APB=90^\circ$ 或 $\vec{PA}\cdot\vec{PB}=0$：$P$ 在以 $AB$ 为直径的圆上。

    * $AB$ 长定且所对圆周角为定值（定长定角）：$P$ 在 $\triangle PAB$ 的外接圆上，半径由正弦定理 $\frac{AB}{\sin\alpha}=2R$ 求得。

    * 例：$l_1$、$l_2$ 过 $A(2,0)$、$B(4,2\sqrt2)$ 且始终垂直，$P$ 为交点，则 $P$ 在以 $AB$ 为直径的圆上；直径 $\sqrt{(4-2)^2+(2\sqrt2)^2}=2\sqrt3$，原点在圆上，故 $OP\in[0,\,2\sqrt3]$。

    * > **提示**：识别出圆就直接用几何，不必先设两条直线求交点再发现是圆；后续更不该再用参数方程硬算。

### 隐圆的第二条路：阿波罗尼斯圆

* **定长定比模型**

    * > **定义**：$AB$ 长固定、$PA:PB=\lambda$ 固定时，点 $P$ 的轨迹是一个圆，称阿波罗尼斯圆（阿氏圆）。

    * 圆心必在直线 $AB$ 上。

* **快速算法**

    * > **结论**：只需在直线 $AB$ 上找到两个满足 $PA:PB=\lambda$ 的点，它们就是直径两端，中点即圆心。

    * $AB=6$、比 $2:1$：$A(-3,0)$、$B(3,0)$，区间内的点在 $x=1$（$AP=4$、$PB=2$），$B$ 外侧点由 $PB+6=2PB$ 得 $x=9$；直径两端 $1$ 与 $9$，半径 $4$。

    * 坐标验证：设 $PA=2PB$，平方展开得 $3x^2+3y^2-30x+36=0$，即 $x^2+y^2-10x+9=0$，配方为 $(x-5)^2+y^2=16$，圆心 $(5,0)$、半径 $4$，与快速算法一致。

* **解法选择**

    * $AB=2$、$AC=\sqrt2\,BC$ 这类非整数比例，凑整点困难时直接解析几何：以中点为原点建系，$A(-1,0)$、$B(1,0)$，解得 $x^2+y^2-6x+1=0$，即 $(x-3)^2+y^2=8$，圆心 $(3,0)$、半径 $2\sqrt2$；面积最大时高即半径，$S_{\max}=\frac12\cdot2\cdot2\sqrt2=2\sqrt2$，避开正余弦定理。

* **自带相似三角形**

    * 连圆心 $G$ 与动点 $P$，则 $\triangle PAG\sim\triangle BGP$，相似比等于 $\lambda=PA/PB$，一般地相似比就是 $\lambda$。

* **逆向：由圆与系数反推定点**

    * 圆 $x^2+y^2=3$ 上动点 $M$，求 $\sqrt3\,MA+MB$ 最小。$OA=1$、$OM=\sqrt3$，取 $OH=3$ 使 $\frac{OA}{OM}=\frac{OM}{OH}=\frac{1}{\sqrt3}$，则 $\triangle AOM\sim\triangle MOH$，把带系数的 $\sqrt3\,MA$ 换成不带系数的 $MH$，问题化为折线最短，$HB=\sqrt{(1-3)^2+(2-0)^2}=2\sqrt2$。

    * > **结论**：带系数的和要先造一组相似把系数消掉，再走对称折线或两点连线。

### 阿氏圆逆用

* **先给圆、再问比例**

    * 圆与 $x$ 轴相切于原点、与 $y$ 轴正半轴交于 $A$、$B$，$|AB|=2$：由垂径定理与切点圆心构成矩形，半弦 $1$、半径 $\sqrt2$，圆心 $(1,\sqrt2)$，方程 $(x-1)^2+(y-\sqrt2)^2=2$；令 $x=0$ 得 $A$、$B$ 纵坐标为 $\sqrt2-1$ 与 $\sqrt2+1$。

    * 过 $A$ 作直线交单位圆于 $M$、$N$，问 $NA/NB$ 是否等于 $MA/MB$：**连圆心是不可跳过的步骤**；$\frac{OA}{ON}=\sqrt2-1=\frac{1}{\sqrt2+1}=\frac{ON}{OB}$，两三角形相似得 $\frac{NA}{NB}=\sqrt2-1$。

    * 推导中只用到点 $N$ 在单位圆上（$ON=1$），与其具体位置无关，故 $M$ 侧结果相同——固定长加固定比，动的点必然在同一个圆上。

* **想不到阿氏圆时的兜底**

    * 设 $N(\cos\alpha,\sin\alpha)$，两点间距离公式展开：$NA^2=2(\sqrt2-1)(\sqrt2-\sin\alpha)$，$NB^2=2(\sqrt2+1)(\sqrt2-\sin\alpha)$。

    * 两式相除 $\frac{NA}{NB}=\sqrt{\frac{\sqrt2-1}{\sqrt2+1}}$，分母有理化后得 $\frac{\sqrt2-1}{\sqrt2+1}=(\sqrt2-1)^2$，即 $NA/NB=\sqrt2-1$，与相似法一致，且 $\sin\alpha$ 被约掉。

    * > **提示**：同一题有三条路——相似连圆心（最省）、阿氏圆逆用（知背景但无助解题）、参数方程硬算（想不到时的兜底）。

### 隐圆的第三条路：代数式自己就是圆

* **带根号**

    * $y=1+\sqrt{4-x^2}$ 移项平方得 $x^2+(y-1)^2=4$，圆心 $(0,1)$、半径 $2$。

    * > **易错点**：根号整体非负决定了 $y\ge1$，故真实曲线只是圆的上半侧；因能取等号，端点是实心点。

    * 与 $y=x+b$ 有两个交点时 $b$ 介于 $1-2\sqrt2$ 与 $1+2\sqrt2$ 之间，两端相切各只有一个交点，都取不到。

* **带绝对值**

    * $\sqrt{1-y^2}=|x|-1$：分 $x\ge0$ 与 $x<0$ 讨论，分别得 $(x-1)^2+y^2=1$（只取 $x\ge1$ 的右半侧）与 $(x+1)^2+y^2=1$（只取 $x\le-1$ 的左半侧），两端均为实心点。

    * 附加条件来自根号非负：$|x|\ge1$，故每支只保留外侧半圆。式子中把 $x$ 换成 $-x$ 不变，说明图形关于 $y$ 轴对称，但它不是函数。

    * 与斜率为 $1$ 的直线有两个不同交点时 $b$ 范围为左开右闭（$-1-\sqrt2$ 到 $1+\sqrt2$），且别忘了并上截距为零的情形。

## 对称问题

### 点关于点

* **中点公式即答案**

    * > **结论**：已知点 $A(x_A,y_A)$ 关于点 $P(x_P,y_P)$ 的对称点，横纵坐标分别取平均，与中点坐标公式完全相同。

    * > **提示**：这一条看似废话，却是所有对称题的母版——只要对称中心是点，立刻回到中点公式。

### 点关于直线

* **两个方程**

    * 设对称点 $N(x,y)$：第一式中点 $G\left(\frac{x_A+x}{2},\frac{y_A+y}{2}\right)$ 在直线上；第二式连线与直线垂直。

    * 例：直线 $2x-y-6=0$、点 $M(1,1)$。中点代入得 $2x-y-11=0$；直线斜率 $2$，$k_{MN}=-\frac12$ 得 $x+2y-3=0$；联立得 $N(5,-1)$。

    * 验算两关：中点 $(3,0)$ 满足直线方程，$k_{MN}=-\frac12$ 与斜率 $2$ 乘积为 $-1$。

    * > **易错点**：第二式写成斜率乘积 $-1$ 有前提——两条直线都不能竖直。出现竖直线时回到垂直的定义：横坐标相等或纵坐标相等。

### 直线关于点

* **方法一：斜率不变加距离相等**

    * 直线绕点转 $180^\circ$ 与自身平行，斜率不变，故只需设一个未知参数 $y=k_0x+m$。

    * 直线 $x+2y-1=0$ 关于 $(1,2)$ 的对称直线：设 $x+2y-m=0$，点 $(1,2)$ 到两线距离相等，得 $|5-m|=4$，$m=1$ 或 $9$；$m=1$ 是自身（原点在该直线上），舍去，答案 $x+2y-9=0$。

    * > **提示**：坚持写一般式的好处是 $A$、$B$ 不变故分母 $\sqrt{A^2+B^2}$ 相同，约掉后只剩绝对值方程，一解出两个答案。

* **方法二：取两点做对称点再定直线**

    * 直线上任取两点，分别用中点公式求其关于 $P$ 的对称点（取整点最省事），两点确定一条直线。化归到点关于点的对称，不需另想。

### 倒角公式

* **公式**

    * > **定义**：由两条直线的斜率直接得到夹角的正切，$\tan\theta=\tan(\alpha_1-\alpha_2)=\frac{k_1-k_2}{1+k_1k_2}$，其中 $\theta$ 是两直线倾斜角之差。

* **谁减谁**

    * 顺着所求角从起始边顺时针转到终止边，分子就是"起始边斜率减终止边斜率"；并非必须大减小。

    * 斜率 $3$ 与 $2$：$\tan\theta=\frac{3-2}{1+6}=\frac17$。

    * 斜率 $-1$ 与 $\frac12$：顺时针由 $-1$ 转向 $\frac12$ 得 $\tan\alpha=\frac{-1-\frac12}{1-\frac12}=-3$；换一个角则分子换成 $\frac12-(-1)$，分母不变，得 $\tan\beta=3$。

    * > **结论**：两角互补时正切值互为相反数。倒角公式的结果带符号，同时携带"谁减谁"的方向信息。

### 直线关于直线

* **两步收工**

    * 三条直线必交于同一点（对称使两边与轴夹角相等），且这个点是已知的——联立 $L_1$ 与 $L$ 即可求到；于是问题塌缩成只求斜率 $k$。

    * 例：$L_1: y=2x-2$ 关于 $L: y=x$ 的对称直线。联立得公共点 $(1,1)$；$\tan\alpha=\frac{2-1}{1+2\times1}=\frac13$，$\tan\beta=\frac{1-k}{1+k}$，两者相等得 $k=\frac12$；点斜式得 $y=\frac12x-\frac12$。

    * 另一法：在 $L_1$ 上任取一点，作其关于 $L$ 的对称点，该点必在对称直线上，两点定线。

```text
            L1 (斜率 2)
             /
            / α
   ────────●────────────────  L2 (斜率 1)  过公共点 P
            \ β
             \
            L3 (斜率 k)

   · 三条直线交于同一点 P
   · α = β  ⇒  (k1-k2)/(1+k1k2) 两边相等
   · 定点 P + 斜率 k  ⇒ 点斜式收工
```

### 圆的对称

* **只动圆心**

    * > **结论**：圆的对称问题全部塌缩成圆心的问题，因为对称前后半径不变。

    * 圆关于点对称：求圆心关于该点的对称点，转成点关于点。

    * 圆关于直线对称：求圆心关于该直线的对称点，转成点关于直线。例：圆心 $(1,1)$、半径 $1$ 的圆关于 $y=x+2$ 对称，设新圆心 $(a,b)$，中点在直线上得 $b=a+4$，斜率互为负倒数得 $\frac{b-1}{a-1}=-1$，解得 $(-1,3)$，半径不变，方程 $(x+1)^2+(y-3)^2=1$。

    * > **易错点**：不要用一般式 $x^2+y^2+Dx+Ey+F=0$ 去套对称公式绕远路；正确姿势永远是先写圆心与半径，对称只动圆心。

* **直线是圆的对称轴**

    * > **结论**：圆的对称轴必定经过圆心，把圆心坐标代入直线方程即得所求条件。

### 圆上存在两点关于直线对称

* **先排除**

    * 相离时圆上点全在直线一侧，对称点必一左一右，不满足。

    * 相切时唯一交点就在直线上，直线上点关于该直线对称就是自身，出题人不取这种情形。

    * > **结论**：圆上存在两点关于直线 $L$ 对称 $\iff$ $L$ 与圆相交。

* **翻译方式**

    * 把整个圆关于 $L$ 对称过去得到对称圆，交点成对地关于 $L$ 对称；因此"圆上存在两点关于 $L$ 对称"等价于"原圆与对称圆有交点"，落到代数上就是 $L$ 与圆相交。

    * 随机任取的一对对称点不会同时落在同一个圆上，不必纠结。

    * 例：圆 $(x+2)^2+(y+1)^2=9$ 上存在两点关于 $ax+by+1=0$ 对称，条件等价于直线过圆心 $(-2,-1)$，即 $-2a-b+1=0$，$b=1-2a$；代入整理得 $f(a)=5a^2+20a+40$，开口向上，对称轴 $a=-2$，最小值 $20$。
