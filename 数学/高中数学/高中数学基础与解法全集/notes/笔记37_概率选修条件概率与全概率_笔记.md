# 概率选修·条件概率与全概率

## 概率的计数底座

* **概率即情况数之比**

    * > **定义**：概率 = 满足事件的情况数 ÷ 所有可能情况的数量；所谓算概率，本质是数情况数。

    * 计算工具箱是排列组合：题目绝大多数是"数数"问题。

### 组合还是排列：选完之后任务结束没有

* **选型判定**

    * > **结论**：在若干不同对象中选出后，**判断任务是否结束**——结束了只选不排，用 $C$；没结束，内部还要再分配或再排序，用 $A$。

    * $C_n^m$ 只选不排，无内部次序；$A_n^m$ 选完还要区分次序。

* **典型对照**

    * 2023 全国甲卷：$2,3,5,6$ 中任选两个不同数字，乘积能被 $3$ 整除。不区分顺序，分母 $C_4^2$，六种取法中五种符合，概率 $5/6$；等价说法是"只要选到 3 或选到 6"。

    * 2023 全国乙卷：六个作文主题，甲乙两位同学各挑一个，求抽到不同主题的概率。题目未要求主题互不相同，故 $6\times 6=36$；分子需把选出的两个主题分给甲乙，选完还要再排列一次，用 $A_6^2=6\times5=36$。

### 不相邻模型：插空

* **四个 1 两个 0 不相邻**

    * 先把四个相同的 1 排好，不考虑它们之间的顺序（相同元素互换不产生新情况），前后加中间共 $5$ 个空；题目未禁止零出现在排头排尾，故 $5$ 个空均可插，分子 $C_5^2=10$，只选不排。

    * 分母换角度：在 $6$ 个位置中任选 $2$ 个放零，其余位置自然填 1，$C_6^2=15$。概率 $2/3$。

    * > **提示**：排列组合的插空模型不熟时，先回到排列组合本身补齐再回来做题。

### 分步用乘法，分类用加法

* **分步**

    * 涉及先后承接的多步事件，各步概率相乘。

* **分类**

    * 把目标事件拆成若干互斥的子情形，各情形概率相加。

    * 例：甲、乙两球入盒概率分别为 $\frac12$、$\frac13$ 且互不影响。至少一个入盒：正面相加 $\frac12\cdot\frac23+\frac12\cdot\frac13+\frac12\cdot\frac13$；反面用 $1-\frac12\cdot\frac23=\frac23$。

    * > **提示**：看到"至少"二字，立刻同时尝试正面分类与反面相减两条路。

* **正难则反**

    * 直接数目标情况困难时，改数对立事件再用 $1$ 减。

    * 例：4 个球（1 白 1 红 2 黄）取两个，颜色不同的概率。直接数得 3 类共 5 种；反面数同色只有"两黄"1 种，$C_4^2-1=5$，概率 $5/6$。

## 独立性与乘法公式

### 独立与一般乘法公式

* **相互独立**

    * > **定义**：两事件 $A$、$B$ 相互独立时，$P(AB)=P(A)P(B)$；$AB$ 即 $A\cap B$，表示两件事同时发生。

    * > **易错点**：把 $P(A\cap B)$ 拆成两个概率相乘，前提是独立，不能随意拆。

* **乘法公式**

    * $$P(AB)=P(A)\,P(B\mid A)=P(B)\,P(A\mid B)$$

    * 无论 $A$、$B$ 是否独立都成立：先假定 $A$ 发生，再在 $A$ 的条件下让 $B$ 发生，两步概率相乘；另一形式等价。

* **分步读图**

    * 多步事件可直接画树状分叉，每条路径概率是路径上各段概率之积，各路径之间相加。

    ```text
                      第一问对 (0.6)
                            |
              +-------------+-------------+
              |                           |
        第二问对 (0.4)              第二问错 (0.6)
           满分                       只得 5 分

                      第一问错 (0.4)
                            |
              +-------------+-------------+
              |                           |
        第二问对 (0.1)              第二问错 (0.9)
           只得 5 分                     零分
    读图：满分只走"对→对"；零分只走"错→错"。
    ```

    * 满分 $=0.6\times0.4$；零分 $=0.4\times0.9$。频率估计概率时，把已知人数比例直接当概率代入。

* **合格品中的等第品**

    * 废品率 $4\%$，合格品中一等品占 $75\%$，任取一件是一等品的概率 $=0.96\times0.75$，即两步到达。

### 放回与不放回：差别全在分母

* **摸球判定**

    * 放回：本次摸完不影响下次，袋中球数不变，两次摸球相互独立，分母恒为初始球数。

    * 不放回：摸走即取出，球数逐次减一，分母每次减 1。

    * 例：袋中 2 红 3 黑 4 白，共 9 球，连摸两次。放回时黑再白 $=\frac39\times\frac49=\frac4{27}$；不放回时 $=\frac39\times\frac48=\frac16$，白球未摸出故仍为 4 个。

* **只关心某一类球时的简化**

    * 只关心红球何时被摸出时，把其余 7 个非红球合并当作一个整体，红球数始终为 2。

    * 例：9 球（2 红 7 非红）不放回，一旦摸出红球即停止，摸球次数不超过三次的概率：

    $$\frac29+\frac79\cdot\frac28+\frac79\cdot\frac68\cdot\frac27=\frac{21}{36}=\frac7{12}$$

    * 三种情形为摸 1 次、2 次、3 次才摸到红球，分类相加；红球从未被摸出时数量不变。

## 条件概率

### 定义与图形理解

* **条件概率（conditional probability）**

    * > **定义**：$P(B\mid A)$ 表示"在事件 $A$ 已发生"的条件下事件 $B$ 发生的概率。

    * $$P(B\mid A)=\frac{P(A\cap B)}{P(A)}$$

    * 顺序固定：分母是条件 $P(A)$，分子是 $A$、$B$ 同时发生。

    * 竖线写法中竖线表示"后面的条件"，条件写在竖线后面。

    ```text
    P(全体) = 1
    +-----------------------------------------------+
    |                                               |
    |        +--------------+                      |
    |        |      A       |                      |
    |        |   +----------+----+                 |
    |        |   |  A∩B     | B  |                 |
    |        |   +----------+----+                 |
    |        +--------------+                      |
    |                                               |
    +-----------------------------------------------+
    读图：大矩形是样本空间，面积 1；中间重合部分是 A∩B。
          竖线右边写"在 A 已发生的条件下"。
    ```

    * 几何含义：把样本空间从大方框缩小到 $A$，以 $A$ 为新基准，$B$ 能发生的部分只有 $A\cap B$，即小面积除以 $A$ 的面积。

### 先把交集当成阅读理解

* **读懂"同时发生"**

    * > **结论**：算条件概率时，$P(AB)$ 一定先当阅读理解题做，按语文读懂"$AB$ 同时发生"是什么局面，再动手算。

    * 任何一道条件概率题第一步都是判定交集的具体情形。

* **子集情形**

    * 2011 辽宁：从 $1,2,3,4,5$ 取两个不同数，$A$ 为和为偶数，$B$ 为两数皆偶，求 $P(B\mid A)$。$B$ 发生必然导致 $A$ 发生，交集就是 $B$ 本身。

    * $P(A)$：和为偶含偶+偶 $\{2,4\}$ 与奇+奇 $\{1,3\},\{3,5\},\{1,5\}$，共 4 种，$P(A)=\frac4{10}$；$P(B)=\frac1{10}$；$P(B\mid A)=\frac14$。

    * > **易错点**：交集未必比两事件复杂；一事件蕴含另一事件时交集直接退化为小者。

### 条件信号与事件自设

* **识别条件概率的语言信号**

    * 出现"在……的条件下""已知……发生了""已知某事件发生"等表述，即为条件概率。

    * 题面没写条件字样但描述了已发生的事实时（如"放到验钞机上，发现是假钞"），同样按条件处理。

    * > **易错点**：题目未给事件 $A$、$B$ 时不要慌，条件有多长就按它的语义自行设事件；"已知某天"设为 $A$、"随后一天"设为 $B$。

* **直接给概率型的处理**

    * 2014 新课标 II：一天空气质量为优概率 $0.75$，连续两天为优概率 $0.6$，求已知某天优良则随后一天也优良的概率。分母直接取 $0.75$，分子"今天优良且明天优良"即连续两天优良，取 $0.6$，结果 $0.8$。

## 条件概率的三种算法

### 公式法

* **定义**

    * 分母算条件事件的概率，分子算交集的概率；两个概率的分母可以不同，只要比值相等。

* **无放回抽牌**

    * 52 张牌不放回抽两次。第一次抽到 A 为 $\frac4{52}$，第二次 $\frac3{51}$，两次都抽到 A $=\frac4{52}\times\frac3{51}=\frac1{221}$。

    * 条件式 $P(\text{第二次 A}\mid\text{第一次 A})=\frac{1/221}{4/52}=\frac1{17}$；分子复用第一问已算出的结果，不重复计算。

* **多对象分派型**

    * 2025 江苏期末：$4\times100$ 米接力共 7 条赛道，第 3、4 道为黄金赛道，1 至 7 班按序抽道，求 1 班未抽到黄金赛道条件下 3 班抽到黄金赛道的概率。

    * 分母：1 班只能抽 $1,2,5,6,7$，$P(A)=\frac57$。

    * 分子总数：1 班、3 班各选一条且不能重复，为 $A_7^2=42$；目标情况 $5\times2=10$，得 $\frac{10/42}{5/7}=\frac5{21}$。

### 一刀两断法

* **缩小样本空间**

    * > **结论**：条件已发生时，把已发生事实看作已改变局面，以新局面为基准重新计数，前面的一切不再计入。

    ```text
    原样本空间：52 张牌
            │
            │  第一次已经抽到一张 A（条件已经发生）
            ▼  一刀两断
    新样本空间：51 张牌，其中 3 张 A
            │
            ▼  再抽一次，抽到 A
    3 / 51 = 1/17
    ```

    * > **提示**：使用前提是**时间线上、逻辑上有先后次序**，否则不能一刀两断。

* **适用与不适用**

    * 适用：先后抽取、依次抽道、先分类后检验等有明确先后结构的场合。

    * 不适用：一次性抽出若干个对象、两对象之间不分先后的场合；强行使用会把条件事件的分子误判成对立面。

* **验钞机案例**

    * 20 张钞票含 5 张假币，任意抽两张，其中一张验出是假钞，求另一张也是假钞的概率。

    * 事件 $A$ 为"至少有一张是假币"，非"只有一张是假的"；$P(A)=\frac{5\times15+C_5^2}{C_{20}^2}=\frac{85}{190}$，$P(AB)=\frac{C_5^2}{C_{20}^2}=\frac{10}{190}$，故 $P(B\mid A)=\frac{2}{17}$。

    * 一刀两断得出的 $\frac4{19}$ 错误，因为两张是同时抽出、不分先后。

### 韦恩图法

* **读图求交叠比例**

    * 已知两个事件的边缘比例与交集比例，交叠块用"边缘相加减交集"求得。

    * 2023 全国甲卷：60% 爱好滑冰、50% 爱好滑雪、70% 两样都爱好。交集 $=60\%+50\%-70\%=40\%$；只滑冰 $20\%$，只滑雪 $10\%$。

    * 在滑雪条件下也滑冰的概率 $=\frac{40}{50}=\frac45$；读法是"以条件人群为基准，其中满足目标的占多少"。

```text
    +---------------------------------------------------+
    |                     100%                          |
    |    +--------------+         +--------------+     |
    |    |  只滑冰 20%  |         |  只滑雪 10%  |     |
    |    |              +---------+---------+    |     |
    |    |              |  都爱好  40%       |    |     |
    |    +--------------+---------+---------+----+     |
    |                                                   |
    +---------------------------------------------------+
    读图：中间 40% 是算出来的——60 + 50 = 110，中间被数了两遍，
          减去 70，得 110 - 70 = 40。
    ```

### 分歧的裁决与副产物

* **两法答案不一致时**

    * 先后结构成立时两法本应一致；出现不一致说明条件事件被误读成"对立面"。

    * 接力赛题若坚持"3 班抽时前两班已抽走、手里只剩 5 条道"，所用知识已超出条件概率范围，需要后述的全概率公式处理。

* **抽到顺序的无关性**

    * 同一条件下，被询问的班级与抽到第几位无关，"谁先抽谁后抽"不改变最终概率。

## 排列型条件概率

### 分母是全排列

* **次序型样本空间**

    * 对象等价且逐个依次产出时，所有情况是把全部对象在次序上全排列，分母取全排列数而非组合数。

    * 例：笼中 7 只猫（3 黑 4 白）依次钻出，分母为 $A_7^7$，即全部出猫次序。

* **交集的计数**

    * 要求"前两只都是黑猫"：三只黑猫中选两只放入两个不同位置得 $A_3^2$，其余 5 只全排列得 $A_5^5$，概率 $\frac{A_3^2 A_5^5}{A_7^7}=\frac17$。

    * > **易错点**：不能用组合——黑猫占两个不同位置，本身带有先后次序；且分母已把全体排好，分子也必须把剩余个体排完。

* **并事件的分类计数**

    * "至少有一只是黑的"分三类：黑黑 $\frac17$、黑白 $\frac27$、白黑 $\frac27$，合计 $\frac57$；分类项之间互斥，相加。

    * 分类计数表：

    | 情形 | 情况数 | 概率 |
    | :--- | :--- | :--- |
    | 第一黑、第二黑 | $A_3^2\cdot A_5^5$ | $\frac17$ |
    | 第一黑、第二白 | $3\times4\cdot A_5^5$ | $\frac27$ |
    | 第一白、第二黑 | $4\times3\cdot A_5^5$ | $\frac27$ |

### 条件项的缩小

* **缩小后重新计数**

    * $P(A_2\mid A_1)$：假定第一只已是黑猫，剩余 6 只中 2 黑 4 白，分母 $A_6^6$，分子 $2\cdot A_5^5$，结果 $\frac13$。

    * $P(A_5\mid A_2)$ 过程完全对称，同为 $\frac13$；黑猫处在第几位只改变标签位置，不改变剩余结构。

* **公式法复核**

    $$P(A_5\mid A_2)=\frac{P(A_2A_5)}{P(A_2)}=\frac{A_3^2 A_5^5/A_7^7}{3\cdot A_6^6/A_7^7}=\frac{3\times2}{6}=\frac13$$

    * 两法各有分工：一法算得快，另一法把"分母是条件、分子是同时发生"的结构显式呈现，值得都掌握。

## 全概率公式

### 从加法乘法到分类又分步

* **两步基本操作**

    * 分类用加法：把所有互斥情形分干净再相加。

    * 分步用乘法：在前一步已发生的前提下让后一步发生，两个条件概率相乘。

    * 例：三名嫌疑人指认概率 $0.1$、$0.3$、$0.6$，"身败名裂"即指认错误，前两条互斥路径相加得 $0.4$。

    * 例：两次独立断案正确率分别为 $0.1$、$0.2$，两案皆错为 $0.9\times0.8=0.72$。

* **既分类又分步**

    * 难题的困难在于同一道题内既要用加法又要用乘法：先按某个原因把目标事件分类，每一类内部再分步。

    * 例：选人概率各 $0.5$，"变大"概率 $0.3$；变大时与小兰出行概率 $0.9$，没变时为 $0.5$，求小兰出行成功概率 $0.3\times0.9+0.7\times0.5=0.62$。

    ```text
                        柯南今天的状态
                  ┌──────────┴──────────┐
              变大(新一) 0.3         没变大 0.7
                  │                        │
            ┌─────┴─────┐            ┌─────┴─────┐
          小兰 0.9    惠子 0.1      小兰 0.5    惠子 0.5
            │             │            │             │
           ✔            ✘            ✔            ✘
        想要的情况    不要的情况    想要的情况    不要的情况
    ```

    * 目标情况是"变大小兰"与"没变大小兰"两条路径；路径内分步相乘，路径之间相加。

### 公式结构与使用条件

* **全概率公式（law of total probability）**

    * > **定义**：若事件 $A_1,A_2,\dots,A_n$ 互斥且构成样本空间的一个划分（概率之和为 $1$），则

    * $$P(B)=\sum_{i=1}^{n}P(A_i)\,P(B\mid A_i)=P(A_1)P(B\mid A_1)+P(A_2)P(B\mid A_2)+\cdots+P(A_n)P(B\mid A_n)$$

    * 每一项一条路径：先 $A_i$ 发生（乘 $P(A_i)$），再在 $A_i$ 条件下 $B$ 发生（乘 $P(B\mid A_i)$）；各项互斥，最后相加。

    * > **提示**：遇到这类题直接画树状图，按路径逐条算完再求和。

* **典型模型：抽取型**

    * 2024 上海：科技比赛有 A、B、C 三题库，题量 5000、4000、3000，共 12000 道，正确率 $0.92$、$0.86$、$0.72$，随机抽一道求正确概率。

    * 先分类：抽到 A、B、C 的概率分别为 $\frac5{12}$、$\frac13$、$\frac14$，和为 1。

    $$P=\frac5{12}\times0.92+\frac13\times0.86+\frac14\times0.72=0.85$$

    * 交通迟到型同理：乘火车、轮船、飞机概率 $0.2$、$0.4$、$0.4$，迟到概率 $0.5$、$0.2$、$0$，得 $0.2\times0.5+0.4\times0.2+0.4\times0=0.18$。

* **典型模型：换罐型**

    * 甲罐 5 红 2 白 3 黑，乙罐 4 红 3 白 3 黑；从甲罐随机取一球放入乙罐。$A_1,A_2,A_3$ 分别表示取出红、白、黑，$B$ 表示从乙罐取出红球。

    ```text
     甲罐: 5红 2白 3黑 (共10)        乙罐: 4红 3白 3黑 (共10)
             |                                |
             | 先随机取一个放入               |
             v                                v
       A1 红 5/10  --->  乙罐变 5红3白3黑(共11)  --->  B(取红): 5/11
       A2 白 2/10  --->  乙罐变 4红4白3黑(共11)  --->  B(取红): 4/11
       A3 黑 3/10  --->  乙罐变 4红3白4黑(共11)  --->  B(取红): 4/11
    ```

    * $$P(B)=\frac5{10}\times\frac5{11}+\frac2{10}\times\frac4{11}+\frac3{10}\times\frac4{11}=\frac{25+8+12}{110}=\frac9{22}$$

    * $P(B\mid A_1)$：分母 $P(A_1)=\frac5{10}$，分子即第一条路径 $\frac5{10}\times\frac5{11}$，约去得 $\frac5{11}$；也可直接一刀两断——红球已入乙罐，乙罐即为 5 红 3 白 3 黑共 11 球，取红即 $\frac5{11}$。

* **典型模型：通信传输型**

    * 信道传输 0、1 两种信号，各次传输相互独立；发 0 收 1 概率 $\alpha$，发 1 收 0 概率 $\beta$。

    | 发送 \ 接收 | 收到 0 | 收到 1 |
    | :--- | :--- | :--- |
    | 发送 0 | $1-\alpha$ | $\alpha$ |
    | 发送 1 | $\beta$ | $1-\beta$ |

    * 单次传输：收到的信号即为译码。三次传输：每个信号重复发三回，收到信号中出现次数多的即为译码码字。

    * 单次传输依次收到 $101$：分三步，为 $(1-\beta)^2(1-\alpha)$。

    * 三次传输发 1 依次收到 $101$：为 $\beta(1-\beta)^2$。

    * 三次传输发 1 译码为一：四类情形 $111$、$101$、$110$、$011$，后三者概率相同（因子次序可交换），得 $P=(1-\beta)^3+3\beta(1-\beta)^2$。

    * $\alpha\in(0,0.5)$ 时发 0 用三次传输译码为 0 的概率大于单次传输：作差提公因式，

    $$P_1-P_2=(1-\alpha)\big[(1-\alpha)^2+3\alpha(1-\alpha)-1\big]=\alpha(1-\alpha)(1-2\alpha)>0$$

    * 三次传输发 0 译码为 0：$P_1=(1-\alpha)^3+3\alpha(1-\alpha)^2$；单次传输发 0 译码为 0：$P_2=1-\alpha$；差为 $\alpha(1-\alpha)(1-2\alpha)$，在 $\alpha\in(0,0.5)$ 时为正。

    * > **提示**：字多的题并不必然更难；只要把所问情况分类清楚，每类内部再分步相乘、加法收尾即可。

### 整体法与站排

* **触发条件**

    * 取球过程步骤过多、按步枚举时情况数失控，改用整体法：把逐次取球理解为把取出的球依次站成一排。

    * 关键切口是"停止动作"——凑齐第三种颜色只可能发生在最后一次取球，故只需讨论最后一个位置的颜色，前面若干次不必细拆。

    * > **易错点**：不要死守"分几步乘几个概率"，分类粒度过细反而做不动；此时乘的是情况数而非概率，实质仍是分步乘法与分类加法。

* **分母用排列**

    * 站排问题有次序，$C_7^5$ 不够，分母取 $A_7^5$。

* **分子按末位分类**

    * 例：袋中 2 白 2 红 3 黄共 7 球，不放回取球，凑齐三色时停止，求共取 5 个球的概率。

    * 第五次为白球：两个白球任选其一，末位为 2 种；前四位只能取剩余 5 球中的 4 个依次排列 $A_5^4$，无需细分红黄配比，得 $2\cdot A_5^4$。

    * 第五次为红球：同理得 $2\cdot A_5^4$。

    * 第五次为黄球：黄球共 3 个，末位 3 种；前四位取 $W_1,W_2,R_1,R_2$ 全排列 $A_4^4$，得 $3\cdot A_4^4$。

    $$P=\frac{2A_5^4+2A_5^4+3A_4^4}{A_7^5}=\frac{240+240+72}{2520}=\frac{23}{105}$$

## 互斥与独立

* **互斥（mutually exclusive）**

    * > **定义**：两个事件无法同时发生、没有公共部分，可直接用语言与情境判断。

    * 甲罐一次只取一球，取出的球不可能既红又黑，故 $A_1,A_2,A_3$ 两两互斥。

* **独立（independent）**

    * > **定义**：两个事件的发生互不影响，只能用公式判定：$P(A\cap B)=P(A)P(B)$ 则独立，否则不独立。

    * 换罐题中 $P(A_1\cap B)=\frac{25}{110}=\frac5{22}$，而 $P(A_1)P(B)=\frac12\times\frac9{22}=\frac9{44}$，两者不等，故 $A_1$ 与 $B$ 不独立。

* **两概念的分工**

    * 互斥靠语言理解、独立靠公式验证，判定路径完全不同，不可混用。

    * 独立用加法会导致出现互斥并存的荒谬结论。

* **未知情形不是不可确定**

    * > **易错点**：看到"不知道是哪种情况"就写"无法确定"是常见丢分点；只要各情形互斥且构成完整划分，未知部分可由全概率公式加回来，$P(B)=\frac9{22}$ 是确定的。

## 贝叶斯公式

### 结构与来源

* **贝叶斯公式（Bayes' formula）**

    * > **定义**：贝叶斯公式是分母由全概率公式算出的那类条件概率，用于已知结果 $B$ 发生，反查它由哪个原因 $A_i$ 带来。

    $$P(B\mid A_i)=\frac{P(A_i)\,P(B\mid A_i)}{P(B)}$$

    * 分子是"某一条线上的概率"：$A_i$ 先发生、再在其条件下 $B$ 发生，两步相乘。

    * 分母是全概率公式的完整结果：$B$ 的一切可能来源路径概率之和。

    ```text
                       事件 B 想要发生
                  ┌───────  ┼  ────────┐
               A1         A2   ...    An
             P(A1)      P(A2)        P(An)
                │          │            │
            P(B|A1)    P(B|A2)   ... P(B|An)
                │          │            │
                v          v            v
          P(A1)P(B|A1) ...        P(An)P(B|An)
                └──── 相加 = P(B) ────┘
                  （这就是全概率公式）

       已知 B 发生了，问它是由哪一个 A 带来的？
       P(B|Ai) = P(Ai) * P(B|Ai) / P(B)
                        ↑ 分子           ↑ 分母
                     就一条线       全概率公式的完整结果
    ```

    * 作答方式仍是设事件、套条件概率公式、分子分母分别算，无需生背公式，画树状图即可。

### 分母是全概率，分子是一条线

* **柯南第二问**

    * 已知小兰成功出去玩，求柯南没变大的概率。设"柯南没变大"为 $A$，"小兰成功出去玩"为 $B$。

    * 分母 $P(A)$ 即小兰出行成功的总概率，直接复用全概率公式结果 $0.62$。

    * 分子 $P(A\cap B)$ 是"没变大且小兰出行"这一条路径，$0.7\times0.5=0.35$。

    * 结果 $\frac{0.35}{0.62}=\frac{35}{62}$。

* **试剂检测**

    * 患病率 $0.05$，试剂在患病前提下的阳性率（准确率）$0.95$，未患病前提下的误报率 $0.005$；已知检验阳性，求真患病概率。

    ```text
                 患病 0.05  ---> 测出阳性 0.95   ==> 这条线 0.05*0.95
       这个人 ──┤
                 未患病 0.95 ---> 测出阳性 0.005  ==> 这条线 0.95*0.005
    ```

    * 分母（阳性总概率）$=0.05\times0.95+0.95\times0.005=0.05225$；分子（阳性且患病）$=0.05\times0.95=0.0475$。

    * 结果 $\frac{0.0475}{0.05225}=\frac{10}{11}$。

    * > **易错点** ⚠️："准确率 $95\%$"指患病前提下测出阳性的概率，含 $5\%$ 漏检（患病却测成阴性）；"误报率 $0.5\%$"指未患病前提下误报阳性。两者方向相反，不可互换。

* **放不放回红白球**

    * 袋中 2 红 3 白，除颜色外相同；取红球不放回，取白球放回，连续取三次。已知袋中还剩一个红球，求第二次取红球的概率。

    * 分母的语义：原来 2 红，末了剩 1 红，说明三次取球中恰好有一次取到红球。

    * 三种情形分步相乘：红白白 $=\frac25\cdot\frac34\cdot\frac34$（第一次取红后袋中变 4 球，后两次取白均放回故分母恒为 4）；白红白 $=\frac35\cdot\frac25\cdot\frac34$；白白红 $=\frac35\cdot\frac35\cdot\frac25$（袋中始终 5 球）。

    * 三种情形的分母各不相同：红白白为 $5\times4\times4$，白红白为 $5\times5\times4$，白白红为 $5\times5\times5$。

    $$P(A)=\frac25\cdot\frac34\cdot\frac34+\frac35\cdot\frac25\cdot\frac34+\frac35\cdot\frac35\cdot\frac25=0.549$$

    * 分子即"白红白"一条路径 $\frac35\cdot\frac25\cdot\frac34=\frac9{50}$，结果 $\frac{9/50}{0.549}=\frac{20}{61}$。

    * > **提示**：红球处在第几位决定袋子在第几步由 5 球变 4 球，逐情形看分母的跳变即可，不必另找规律。

## 解题通则

* **总纲**

    * > **结论**：分类用加法，分步用乘法；加法与乘法不需生背新公式，两者在同一道题里一起出现时即为全概率公式，其分母再充当贝叶斯公式的分母。

    * 剩余工作量是排列组合的计数：选完是否还要排、有次序的用 $A$、只选的用 $C$。

* **解题顺序**

    * 判定题型：条件概率看语言信号，全概率看"是否需先对某个原因分类"。

    * 条件概率先读懂交集语义，再定分母分子；没有事件就自设。

    * 分类务必检查互斥且完备，避免重复计数或漏计。

    * 步骤失控时改整体法，按末位或关键位分类，其余部分整体排列。

* **方法取舍**

    * 公式法永远可用；一刀两断仅在有时间与逻辑先后时使用；韦恩图适合只有边缘比例与交集比例的数据型条件。

    * 两种方法结论冲突时，以公式法为准，并回头检查条件事件是否被误读为对立面。
