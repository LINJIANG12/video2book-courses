# 立体几何综合·大题专练

---

## 建系的起手式

* **原点选取**

    * > **定义**：建系时把原点放在题设中垂直条件最多的那个点上。

    * 垂直条件越多，点坐标不用凑、不用算，直接写得出来，答案在起手处就已经稳了一半。

    * 常见的垂直条件来源有三条：题给的一条棱垂直底面、题给的一个直角、题给的等腰关系配三线合一。

    * 棱垂直底面属线面垂直，于是这条棱与底面内任意一条线都垂直，底面各点的两维坐标可直接写。

* **建系中最容易翻车的环节**

    * 建系题里最常翻车的不是计算，是「凭什么这么建」的依据。

    * 坐标系选好后先做一遍合理性检查：轴的方向是否真的互为垂直、题给的 $60^\circ$ 之类的角度是否被正确处理。

* **坐标与向量的书写**

    * 线用两点构成的向量表示，取终点减起点，例如 $\overrightarrow{CE}=E-C$。

    * 面用法向量表示，在面上任取两个不共线向量。

    * 平面图形里不好看出夹角关系时，把该面单独抽出来画一遍平面图，往往一步就顺了。

* **典型的坐标书写形态**

    * 底面在 $XY$ 平面内时，底面上各点 $Z$ 坐标一律为 $0$；在底面正上方的点，只差一个待定的高度参数。

    * 底面图形稍微复杂时不要在立体图上硬算，先在平面图里把特殊点（三等分点、中点）标全。

* **底面图形特殊时的直接结论**

    * 底面出现对称结构时，垂足、对称轴交点一类位置可以零计算得到，直接作为原点。

    * 例如底面为筝形时，两条对称轴的交点即为最简原点，轴上的垂足不必再算。

## 法向量的求法

* **卷子写法**

    * > **定义**：设法向量 $\vec n=(x,y,z)$，令它与面上任一向量的数量积为零，解线性方程组。

    * 这一步「装模作样地列出来、把数量积算出来」是有分的，阅卷按列式给分，不能跳过直接写答案。

    * 解出 $X$、$Y$、$Z$ 的比例后，令其中任意一个为 $1$，其余按比例解出即可。

* **速算口诀**

    * > **结论**：法向量速算口诀——每个向量写两遍，掐头去尾留中间，交叉相乘再相减。

    ```text
       u = (-1, 1, 0)         v = (-1, 0, 2)
       (-1,  1,  0)           (-1,  0,  2)     ← 每个向量写两遍
       (-1,  1,  0)           (-1,  0,  2)

       掐头去尾：第一列与最后一列不要，只看中间两列

              1   0              0   2
              1   0      ⟶        0   2

       交叉相乘再相减，顺序不能减错：

         1 × 2 − 0 × 0  =  2            → n_x
         0 × (−1) − (−1) × 2 = 2        → n_y
         (−1) × 0 − 1 × (−1) = 1        → n_z

                   n₁ = (2, 2, 1)
    ```

    * 口诀与列式法的结果完全一致，列式只是把手算过程写全。

* **找零法**

    * > **结论**：从两个向量的分量里找那个「零」，零乘谁都是零，先把这一位跳过去，只让其余分量配平。

    * 含零的分量最好用：它所在的方程直接少一个未知量，只剩两元关系。

    * 两个坐标互成比例时，把倍数大的放前面、小的放后面，再把负号任意加在其中一项上，保证两项恰好互为相反数。

    * 速算口诀是「掐头去尾」，找零是「掐到那个零就停」，两者是同一思路的两面；矩阵看着费劲时先扫哪里有零。

* **底面法向量的省事写法**

    * 底面即 $XOY$ 平面时，法向量直接写 $(0,0,1)$，不再重复计算。

    * 某个面在前一问已经求过法向量时，直接抄用，不要算第二遍，考试时间省在这种重复劳动上。

    * 法向量整体乘任意非零倍数都算对，不必纠结正负号与具体倍数。

## 三类角度与函数名换算

* **线面角**

    * > **结论**：线面角的正弦、余弦与向量夹角的正弦、余弦要变名。

    $$\sin\alpha=|\cos\theta|,\qquad \cos\alpha=|\sin\theta|$$

    * 加绝对值的原因：线面角 $\alpha$ 的取值范围是 $0\sim 90^\circ$，属于第一象限，正弦与余弦都必须为正。

    * 线面角口诀：值为正，但要变名，$\sin$ 变 $\cos$、$\cos$ 变 $\sin$，一定要变。

    * 法向量朝上时 $\alpha$ 与 $\theta$ 互余，$\alpha=90^\circ-\theta$；法向量朝下时二者互补，$\alpha=\theta-90^\circ$；两种情形下 $\alpha$ 与 $\theta$ 都不相等，差着 $90^\circ$。

    * > **易错点**：⚠️算出的负号是法向量朝下的产物，不是答案的负号，线面角永远为正，不要把负号一起抄上去。

* **二面角**

    * > **结论**：二面角不变名，$\sin\alpha=\sin\theta$、$\cos\alpha=\cos\theta$，与线面角正相反。

    * 法向量的方向由取向量的顺序决定，可以朝上也可以朝下，于是 $\theta$ 或等于 $\alpha$，或与 $\alpha$ 互补，两种情形都不影响正弦、余弦的函数名。

    * 二面角可以是锐角也可以是钝角，符号必须看图判定：第一象限三角函数全正，第二象限正弦为正、余弦为负。

    * 题目给二面角的余弦值为正，说明该二面角是锐角，加完绝对值即可不必再判断象限。

    * 绝大多数考法是问二面角的正弦值，因为正弦无论锐角钝角都为正；若题目问余弦值，就必须先判定锐钝再定符号。

* **异面直线所成的角**

    * 两条看似相交的线可能根本不在同一平面内，先确认共面与否再下笔。

    * 求法通常是把其中一条平移，使两线共面，化为同面角的夹角。

* **角度类比的统一处理**

    * 三个角度形式各异时，把它们统一到同一个三角形、同一根斜边上表达，右侧因子常常自动约掉。

    ```text
       sin θ  =  FC / FD      (直角在 C)
       sin α  =  BF / FD      (直角在 B)
       sin β  =  FC / FB      (直角在 C)

       sin α · sin β  =  (BF/FD)·(FC/FB)
                       =  FC / FD          ← BF 与 FB 约掉
                       =  sin θ
    ```

## 线面平行的四招

* **四招总览**

    * > **结论**：线面平行有四招，不是挑一招，而是四招都得会，因为题目会告诉你哪招不好用。

    ```text
                         要证  线 ∥ 面
                                │
          ┌─────────────────────┼─────────────────────┐
       第一招                第二招               第三招
      找平行四边形          找中位线或相似        平面外另选一点
          │                     │                     │
    在面内另找一组          找一个特别明显的点，    在直线所在平面之外
    平行且相等的线，        把这点与线的两个端点    任选一点，与两
    凑成平行四边形          连线，交点一连          端点各连一条
          │                     │                     │
    注意：是「另外」一组    两三角形必定相似，      新线必与原直线
    线，不是题给的那组      交点大概率是中点或      平行，证它是中位线
                            三等分点               或 1:2、1:3 等分线
    ───────────────────────────────────────────────────────────
                          第四招：面面平行
              过已知线作新面，新面内先做好一对线线平行
              （这两条线是自己作的，那对平行白送），
              再证新连的线与原平面内某条线平行，
              两对相交线分别平行 ⟹ 面面平行
              ⟹ 一个面上任何一条线 ∥ 另一个面
    ```

* **第一招：找平行四边形**

    * 关键是找题目没有给出的「另外一组」平行且相等的线，用题给的那组去凑是凑不出来的。

    * 当所在面太小、容纳不下所求的那条线时，直接放弃这一招。

* **第二招：相似找中位线**

    * 空间中往往有一个特别明显的点，它既不在那条直线上也不在目标面内，把它与线的两个端点连接。

    * 两条连线与目标面必有交点，两组三点构成的两个三角形必定相似，交点大概率落在中点或三等分点上。

    * 当这个明显的点也不好用（例如它与目标面看不出关系）时，立刻改用其他招。

* **第三招：平面外另选点连端点**

    * 在直线所在平面之外任取一点，与直线的两个端点各连一条，交线一连，这条新线必然与原直线平行。

    * 再证它是中位线或按 $1:2$、$1:3$ 等比例分的等分线（用相似），线面平行即成立。

* **第四招：面面平行**

    * 平行四边形与中位线都不好找时使用：过两个端点作面上某条线的平行线，自然撑出第三点，三点确定一个新面。

    * 只要再证出第二对线线平行，由两对线线平行得面面平行，面面平行则面上任一线与另一斜面平行。

    * 题目已经给出两对平行时，面面平行是白送的，线面平行随之直接成立。

* **推线面平行的书写三要点**

    * 线线平行；该线在平面内；待证线不在该平面内。

    * > **易错点**：⚠️第三点「不在这个面内」最容易漏，少写一个条件就扣一分。

* **不必真画出来的交线**

    * 两个面只找到一个公共点时，交线位置不必真作出来，用「过一个平面的平行线作平面，所得交线与该平行线平行」直接锁定交线与某已知线的平行关系。

    * 交线与平面内的某条已知线平行、而交线不在该平面内（否则两线同面又平行只能重合，矛盾），即得线面平行。

    * 立体图上辅助线一多就容易乱，把底面抽出来单独画一遍平面图形往往一步就顺。

## 垂直关系的三条触发线

* **等腰三角形三线合一**

    * > **结论**：等腰三角形一定考三线合一，底边上的中线（也是高、顶角平分线）必垂直于底边。

    * 题给一组相等边后要立刻联想到三线合一，这条线常常就是后续所有垂直关系的起点。

    * 等腰配相等夹角时优先找全等：两边分别相等、夹角也相等、还共用一条边，构成 SAS 全等，全等又产生新的等腰与新的垂直。

* **面面垂直转线面垂直**

    * > **结论**：出现面面垂直，几乎必考「在一个面上作交线的垂线」。

    * 交线是两垂面的公共线；在其中一个面上作交线的垂线，则这条线垂直于另一个面，得线面垂直。

    * 线面一垂直，这条线与该面上任何一条线都垂直，于是它与交线也垂直——线面垂直是「同时垂直于面上所有线」的跳板。

    * 证面面垂直的本质是让其中一个面经过另一个面的垂线，即仍归结为找一条线面垂直。

* **垂直可以算出来**

    * 数值平方凑得上就是在暗示直角：先算出三边长度，检查两边平方和是否等于第三边平方。

    * > **结论**：边长的平方关系凑得上，说明题目在暗示这一角是直角，压轴题里这是非常常见的信号，读数要读出暗示。

* **题目给的垂直条件要保留**

    * 题面直接给的一条垂直（如 $BF\perp AO$）是全题枢纽，后续的线面垂直、面面垂直、二面角几乎都要靠它搭桥。

## 几何法求二面角

* **定义法**

    * > **定义**：在二面角的两个面上分别作交线的垂线，这两条线的夹角就是二面角的平面角。

    ```text
             ╱▒▒▒▒▒▒╲             ╱▓▓▓▓▓▓╲
            ╱  交线  ╲           ╱  交线  ╲
           ●━━━━━━━━━●         ●━━━━━━━━━●
            ↑ 垂直交线           ↑ 垂直交线
            └───────┐
                    │ 这个角就是二面角的平面角
                    └───────┘
    ```

    * 两个面上的垂线都难找时，定义法用不了，改走三垂线定理。

* **三垂线定理**

    * > **定义**：在面上取一个明显的点 $P$，作 $PO\perp$ 底面于 $O$，再过 $O$ 作交线的垂线 $OG$，则 $PG\perp$ 交线。

    ```text
        面上任取明显的点 P
                 │
                 │ PO ⊥ 底面
                 ▼
                 P
                ╱│
               ╱ │  PO ⊥ 底面
              ╱  ▼
             O ──────►  过 O 作交线 BC 的垂线 OG

        PO ⊥ 底面，OG ⊥ BC，OG 在底面内
        ⇒ 三垂线定理：PG ⊥ BC
        ⇒ PO ⊥ BC、PG ⊥ BC 都垂直于交线
        ⇒ ∠PGO 就是二面角的平面角
    ```

    * 点 $P$ 要选最好作垂线的：底面内的点不行，就选垂足已知的那个高上的点（如 $A$ 点），或某条线段的三等分点。

    * 在高上的点作底面垂线，其垂足就是底面垂足与该点的连线交点。

* **几何法的过程一步不能少**

    * 不能直接宣称「我做出来的角就是二面角」，只能通过定义来证，即两条线都垂直于交线。

    * 典型的证明链与阅卷扣分点：

    ```text
       辅助线：过 E 作 EG ⊥ BD 于 G，再过 G 作 CD 的平行线 GH ⊥ BC，
       垂足 H，连接 EH。

       ① EG ∥ OA 且 OA ⊥ 底面 BCD ⟹ EG ⊥ 底面 BCD
          ⇒ EG ⊥ BC                    ★ 要写「EG 在平面 BCD 内」
       ② GH ⊥ BC，EG ⊥ BC，两线都在平面 EGH 内
          ⇒ BC ⊥ 平面 EGH               ★ 面面垂直的判定不能漏
          ⇒ EH ⊥ BC                     ★ 线线垂直前必须先有「线在面上」
       ③ EG ⊥ BC，EH ⊥ BC，两线都在平面 EGH 内
          ⇒ ∠EGH 就是二面角 E−BC−D 的平面角
    ```

    * > **易错点**：⚠️在线面、线线之间来回推时，必须写一句「这条线在那个面上」，这不是废话，是推理完整性，阅卷按此扣分。

* **几何法与建系法的分工**

    * 几何法计算量小，但书写过程要求严格，一条辅助线的来由与每个「在面内」都要交代清楚。

    * 建系法计算量可大，但书写简单；题目里那条关键线直接建不出来时，仍必须先证明出一串垂直关系，才有资格建系。

    * 特殊角（如 $45^\circ$）优先考虑几何法，把这个角在图形中真正找出来，再用相似与勾股定长。

## 先证后建：辅助线是自己挣出来的

* **先证后建的触发信号**

    * 出现「三角形绕一点歪放」的模型（两条边分别相等，形似张开的嘴）时，建系之前必须先补证一串垂直。

    * 「谁说某条线一定垂直于底面了」——题目没说就得证，先用完所有条件再开建。

    * 题设里尚未使用的那个角度条件往往就是补齐垂直关系的关键，用完后才能建系。

* **设边长要选带根号的值**

    * 设边长时涉及根号与终点，尽量设成整数比例的放大值（例如设二而不设一），避免后面反复除分数。

    * 各条边算出来后应能验证勾股关系闭合，再开坐标系写点坐标。

* **定位未知点坐标的捷径**

    * 题给向量相等（如 $\vec{EF}=\vec{DA}$）时，若 $E$ 恰好是原点，$\vec{EF}$ 直接就是 $F$ 点的坐标，用终点减起点即刻写出。

    * 中点坐标用中点公式 $(x_1+x_2)/2$ 一把算出来，不必另找路线。

* **辅助线是算出来的不是看出来的**

    * 位置不确定的点必须先钉死，否则后面全是空中楼阁；钉死的手段依次是勾股、斜率、相似、解析几何联立。

    * > **结论**：辅助线永远不是「连出来」的，是「算出来」的。

    * 条件中出现一个定义方式古怪的点（例如由一条垂直关系而非「在某边上」定义的点）时，第一件事就是把这个点的位置求出来。

## 平面内求未知点的两条路

* **解析几何法**

    * > **提示**：图形出现「垂直」条件时，先别硬找相似三角形，先想能不能用斜率——两条直线垂直就翻译成「斜率乘积为 $-1$」。

    * 边长方正、含直角时，在该平面内直接建一个平面直角坐标系最省事。

    * 由两点求出一条线的斜率，另一条垂直线的斜率随之确定，解析式直接写出，两线联立求交点即得目标点坐标。

    * 算完往往出现惊喜式的结论（例如目标点正好落在某条边的中点上），这个结论要被后续每一问反复使用。

* **Z 字形（全等）法**

    * > **结论**：底面出现十字图形（Z 字形）时，两条线垂直当且仅当两端形成的两个直角三角形相似。

    * 正向用：两角相等推出两线必垂直。

    * 反向用：题目已给垂直，就断定那两个直角三角形相似；再验证一组对应边相等，相似升级为全等，两条对角线互相平分，目标点即中点。

    * 作法：把已知的那条线延长补全图形，再过另一顶点作垂线设垂足。

    * 对应角用正切定值，配合直角边长即可求出垂线段长度；若求出的垂线段与另一条已知边完全相等，全等就到手了。

    * > **易错点**：⚠️这类图形默认不画全，必须主动延长补全，「目标是中点」是被算出来的结论，不能靠观察断言。

* **矩形的对称性**

    * 出现直径所对圆周角为直角、再加上下两条线平行（同旁内角也是直角）时，整个图形就是一个矩形。

    * 矩形对角线互相平分，画出圆心所在的对角线后，另一条对角线也是直径，第二点可看成第一点的延长线；落笔时「由对称性得」即可，不必细证。

## 降维转化

* **降维方向**

    * > **结论**：转化的方向永远是降维——面 → 线，线 → 三角形。

* **链条**

    * 面面垂直 → 线面垂直 → 两条同时垂直于某线的线 → 线线角。

    * 二面角 → 交线在两面上的垂线所成线线角。

    * 线面角 → 平面内斜线与射影所成角。

    * 异面直线夹角 → 平移其中一条使其共面。

    * 每一层转化都在降低题目的自由度，使待求量落进一个具体的三角形里。

* **平行的传递性**

    * 同一个方向上的多条中位线互相平行（例如同一条大线的中位线必平行），这条性质让第一问的结论成为后续各问的工具。

* **几何法与向量法的分工**

    * 建系向量法计算量和工作量都不小，但不用动脑子；几何法要想得深，但计算量不大。

    * 前几问用几何法做的题，后面几问硬上建系属于脱裤子放屁，且建系往往需要题目根本没给的额外条件。

## 平移法与它的代价

* **平移的常规用途**

    * 线线角、异面直线夹角统一时首选平移：把其中一条平移到与另一条有交点的位置，落进一个具体三角形。

    * 平移后选哪条线移、移到哪，判据是「移完之后立刻能凑出一个三角形」。

    * 常常是平移那条较短的线，或者与另一条已证平行因而立刻有交点的线。

* **平移法的使用条件**

    * 平移的对象必须是已知线段或可立即求出的线段，否则平移只会把未知量搬个家。

    * 目标三角形的三边必须都能用勾股、中位线、余弦定理在可接受的次数内求出。

    * > **结论**：若平移后需要连列四五个余弦定理才能解出，就该放弃平移法——平移时爽，计算时崩，考场上根本用不出来。

    * 求第三条边时优先想到「改双余弦贴切法」：两个角互补、余弦互为相反数，在一个三角形里列一次余弦定理、在另一个里再列一次，全题只剩一条未知边时必然可解。

    * 多三角形问题的标准打法：先在边全已知的小三角形里求出某个角的余弦值，再把这个角搬进大三角形列三边一角。

## 三向量和的平方

* **触发条件**

    * > **结论**：出现 1、2、3、4 四个点围成的小环形，四条边长度都已知，且所求夹角的两条边与中间那条线垂直（垂直已知也可）——三个条件同时满足时，线线角必然可求。

* **代数形式**

    * 把目标线段写成三段首尾相接的向量和，平方后展开：

    $$\overline{DB}^{\,2}=\overline{DO}^{\,2}+\overline{OG}^{\,2}+\overline{GB}^{\,2}+2\,\overline{DO}\cdot\overline{OG}+2\,\overline{OG}\cdot\overline{GB}+2\,\overline{DO}\cdot\overline{GB}$$

    * 中间两项数量积全为零（直角已证），只剩最后一项含夹角余弦，代数值解出即可。

* **选点的诀窍**

    * 不是随便凑四点，而是要看哪一点同时垂直于另外两点所在的方向，能让两个中间数量积都归零。

    * 重心是关键节点：两条中线的交点是重心，分中线时按三等分取，重心到中点占三分之一、到顶点占三分之二。

    * > **提示**：找长线上的点行不通（那条线上没有别的点、夹角关系无从确定），必须把折线拐到重心处才凑得成环形。

* **结果的符号与锐钝判定**

    * 算出负的余弦值说明所求线线角是钝角，但二面角与它可能互补；取方向相反的那个补角，再结合图形判定题目问的是哪一个。

## 建系受阻时的判断

* **建系好不好做的检验**

    * 先问坐标系能不能自然立起来：三轴方向是否都有题设支撑，点坐标是否都能直接读出或一步算出。

    * 若某个待定点所在平面与底面的关系题目没说，它就不一定落在所设坐标面上，建系便做不下去。

    * > **结论**：建系需要题目没给的额外条件时，果断改几何法。

* **三问式流程**

    * 先扫一眼四个条件是否成立（四点成环形、边长已知、有直角、能建系），再决定往哪条路走，比一上来就开算划算得多。

    * 方法要挑不要硬来：平移法爽而算崩，建系法缺条件，几何法深而算少。

* **中考场心态**

    * 每一步难度都不大的题，靠的是把多个知识点「拼」在一起而非某一步的深度；拼接口的衔接处才是真正的失分点。

    * 位置不确定就停下先定位，后面每一问都会用到这个位置。

## 翻折

* **总纲**

    * > **结论**：翻折前后的图形全等——对应边相等、对应角相等、对应点的位置关系也相等。

    * 这句话记住之后，一大半翻折题不用算就已经会了。

    * 折叠后得到的图形仍保持原有的三角形形状（如等腰直角三角形的顶角仍在折痕中点处）。

* **翻折后的面面垂直照常处理**

    * 折叠给出「某条线垂直于底面」时，按面面垂直的老套路处理：过折后图形的顶点作交线垂线，垂足处立即得到线面垂直。

    * 底面法向量直接写 $(0,0,1)$；原点选在初始图中任意便于求坐标的点都可以。

* **点重合条件**

    * > **结论**：翻折题一旦出现「点重合」条件，立刻反应成两点间距离相等，然后老老实实列一个一元一次方程。

    * 找距离相等的两点要抓最关键的两点：一个是被翻过去落到已有点上的点，另一个是题目所问的点。

    * 翻折前该点到「重合点」的长，翻折后等于它到「原位置点」的长，两式相等即得方程。

    * > **提示**：⚠️不要去求轨迹、也不要讨论参数范围，那是把简单题做复杂；左右两边平方后未知数同次幂，会自动约掉降为一元一次方程。

* **翻折与建系的关系**

    * 折后长度可直接用两点间距离公式在坐标系里算，也可以在立体图形中用斜边平方和算，两者等价，来回转化即可。

    * 一眼能看出「以某点建系就结束」的翻折题属常规题型。

## 点的运动轨迹

* **旋转轨迹**

    * 三角形绕一条边旋转时，顶点扫出的轨迹是一个圆：几何体呈上下两个圆锥共底面的形状。

    * > **定义**：圆心是该旋转点到旋转轴的垂足 $G$，半径是该点到轴的距离；运动过程中该点到 $G$ 的距离恒定。

    * 找圆心的通用办法就是取「点到对称轴的垂足」，这个结论对所有旋转轨迹都成立。

* **轨迹的用处**

    * 轨迹结论是后续更难翻折题的直接工具，直线轨迹、圆轨迹都要能一眼认出。

    * > **提示**：遇到立体几何里看不懂的图形，把旋转体想象成陀螺一转，往往就通了。

## 历年真题线索

* **线面平行第一问（全国卷）**

    * 三棱锥中一条棱是高且两腰相等、底面是直角三角形时，高在底面上的垂足落在腰的垂直平分线上，而该垂直平分线平行于底面另一直角边。

    * 由高与等腰得垂点到两腰端点等距，由底面直角得这条垂直平分线平行于另一直角边，两条凑出中位线定理，线面平行一行证完。

    * 也可引入腰的中点作中位线，把新面与原平面做成面面平行，同一结论两条路。

* **线面平行第一问（直线交线型）**

    * 两个中点分别在两个平面上时，中位线必与第三个平面平行；用过该中位线作的面与原平面的交线同样平行于它。

    * 关键是把交线与「过平面外一点连两端点」得到的新中位线联系起来。

* **三个角一锅端（圆与直线型）**

    * 底面为圆、直径垂直于竖直杆时，直径所对圆周角为直角，竖杆与底面垂直又给出一批直角，图形特殊程度极高。

    * 求线面角时若斜线与底面无交点，可平移到与底面有交点的位置，转成平面内的直角三角形。

    * 求异面直线夹角时，把短边平移到交点处；若平移后的三角形形状定不了，先回原图形找隐藏直角，别急着列余弦定理。

    * > **提示**：判断三角形形状先于列余弦定理；只有形状定不了、是非常一般三角形时才用余弦定理，一旦发现特殊结构就走特殊三角形。

* **面面垂直证明（勾股暗示直角型）**

    * 底面直角三角形配上「两条中线加一条垂直」的条件时，三角形的三边长度全部由中点条件与勾股算出。

    * 三边平方若恰好凑成勾股数，即为题目暗示的直角；随后把这条垂线平移到另一平面对应的中位线上，即得线面垂直，进而面面垂直。

* **二面角求值（末问）**

    * 交线在中点连线上时，中点连线在两个平面内的垂线一条题给、一条刚才证出，线线角即二面角。

    * 该线线角与二面角可能互补，三角函数可相互转化，最终求正弦值时互补不影响结果。

    * 此类题的得分点是三向量和的平方：把折线写成三段向量和，中间两项数量积为零，末项直接解出余弦。

    * 最终余弦为负说明锐钝需重新判定，取补角得到二面角，正弦值与锐钝无关。
