# 立体几何·空间几何体与点线面

## 点线面的表示与十一类关系符号

* **点线面记号约定**

    * 点用大写字母 $A$、$B$、$C$、$D$；直线用小写字母 $l$；平面用希腊字母 $\alpha$、$\beta$、$\gamma$。

    * 也可用已知点直接表示：两点确定一条直线，记作直线 $AB$；三个不共线的点确定一个平面，记作平面 $ABC$。

    * > **注意**：小写 $a$ 与 $\alpha$ 字形极像，一个是直线一个是平面。题干里凡是单个字母孤立出现，先判断它是线还是面。

* **十一类关系符号**

    | 关系 | 符号 |
    | :--- | :--- |
    | 点在直线上 / 点在直线外 | $A \in l$ / $A \notin l$ |
    | 点在平面内 / 点在平面外 | $A \in \alpha$ / $A \notin \alpha$ |
    | 线在面内 | $l \subset \alpha$ |
    | 线与面只有一个公共点 | $l \cap \alpha = \{P\}$ |
    | 线面平行 / 线面垂直 | $l \parallel \alpha$ / $l \perp \alpha$ |
    | 面与面相交 | $\alpha \cap \beta = l$ |
    | 面面平行 / 面面垂直 | $\alpha \parallel \beta$ / $\alpha \perp \beta$ |

    * 点对线、点对面用 $\in$ 与 $\notin$；线对面必须换成 $\subset$，写成 $l \in \alpha$ 是错的。

    * $l \cap \alpha = \{P\}$ 与 $\alpha \cap \beta = l$ 的本质都是集合求交：两个集合的公共元素是一个点，或是一条直线。

* **符号与图形对号入座**

    * 判读流程固定为三步：符号 → 读成一句话 → 想象对应图形，翻译这一层不能省。

    * $a \cap \alpha = A$ 对应线明显扎出面 $\alpha$、与面只有一个交点的图形；$a \subset \alpha$ 与 $a \not\subset \alpha$ 分别是线在面上、线不在面上。

    * 三个面 $\alpha$、$\beta$、$\gamma$ 两两有交线、三条线 $a$、$b$、$c$ 交于一点，对应含"三面三线共点"结构的图。

    * "点 $A$ 不属于面 $\alpha$"对应点飞到面外的图，此时常有直线在 $\alpha$ 上。

    * $\alpha \cap \beta = a$ 且点 $P$ 既不在 $\alpha$ 上也不在 $\beta$ 上，对应交线为 $a$、点在两面之外的图。

## 平面的基本性质与确定条件

* **三条基本性质（公理性质，无需证明，以理解为主）**

    * 过不在一条直线上的三个点，有且只有一个平面。

    * 若一条直线上的两个点都在一个平面内，那么这条直线也在这个平面内。

    * 两个不重合的平面若有一个公共点，则有且只有一条过该点的公共直线。

    * > **易错点**："不共线"是三点定面的命根子。三点若共线，它们只确定一条直线，而过一条直线的平面有无数个。

* **三个推论**

    * 一条直线和直线外的一点，有且仅有一个平面——直线上任取两点加直线外一点构成三角形。

    * 两条相交直线有且仅能确定一个平面。

    * 两条平行直线有且仅有一个平面。

* **常见真伪判别**

    * "三个不同的点能确定一个平面"错，必须不共线。

    * "一条直线和一个点能确定一个平面"错，点必须在直线外。

    * "空间中两两相交的三条直线确定一个平面"错，这是最隐蔽的一条：三线若交于同一点，前两条已确定一个面，第三条完全可以支出去，三线仍两两相交却定不出唯一平面。

    * "两条平行直线确定一个平面"对。

    * "交于同一点的三条直线在同一平面内"错。

    * "一个角的两边所在直线分别平行于另一个角的两边所在直线，则两角相等"错，可以一个锐角一个钝角。

    * "三角形 $ABC$ 在平面 $\alpha$ 外，三边延长线分别与 $\alpha$ 交于 $P$、$Q$、$R$，则 $P$、$Q$、$R$ 一定共线"对：平面向无限方向延展，直线不可能一部分在面上、一部分飞出去，三条边延长后整条直线仍在原面上；两面相交，交线有且仅有一条，$P$、$Q$、$R$ 都在这条交线上。

    * "四个点不共面，则其中任意三点必然不共线"对：若其中三点共线，由推论一"直线和直线外一点有且仅能确定一个平面"，四点必共面，与已知矛盾。

## 线线位置关系与异面直线

* **空间三种位置关系**

    * 同一个平面内两条直线只有相交与平行两种；空间中多出第三种，既不相交也不平行，称为异面直线。

    * > **定义**：异面直线——不在任何一个平面内的两条直线。

    * > **判定**：两条直线既不平行也不相交，就是异面直线。

    * 两条直线要么共面、要么异面；共面时再分相交与平行。

* **正交性的反向理解**

    * 正向理解是证不存在那个公共平面：取 $AA_1$ 与 $BC$，由 $A$、$A_1$、$B$ 三点确定唯一平面，而直线 $BC$ 上的点 $C$ 在此平面之外，故不存在同时经过两条直线的平面。

    * 三类典型图形覆盖绝大多数判断题：

        ```text
        图一：直线整条伸出平面之外

                  /
                 /   l
                /
          =============  α


        图二：两线分别与交线的两端相交

            /          \
        l₁ /            \ l₂
          /              \
        ---/----------------\---  β∩γ


        图三：原本相交的一对直线被整体平移到半空

               /\
              /  \    l₁ 与 l₂：原先在同一个面上相交
             /____\
          =============  α
        ```

        * 图一靠"线整条不在面上"；图二靠"两线与交线分处两端、一上一下"；图三靠"平移不改变相交关系，但能改变共面关系"。

* **伪装成异面的平行**

    * 两个不同面上各有一条直线都平行于同一条交线，这两条线不是异面直线。

    * 两条平行直线确定一个面，说明这两条线共面、平行；"分别在不同面上"与"不在同一个平面内"是两回事。

* **正方体棱中点判定实例**

    * $A$、$B$、$C$、$D$、$E$、$F$ 为正方体各棱中点，与 $EF$ 关系的判定工具只有两个：证明既不平行也不相交，或对照上面三类图形。

    * $BC$ 与 $EF$：由中位线与平行四边形得 $BC \parallel EF$，共面，排除。

    * $CD$ 与 $EF$：$DF$ 与 $GE$ 平行且相等构成平行四边形，两线相交；把其中一条沿方向平移到 $EF$ 的位置，属于图三，异面。

    * $DA$ 与 $EF$：$A$、$D$、$F$ 确定平面 $ADF$（后面那个面），点 $E$ 支出此面，属图一，异面，视觉上的交点不是真交点。

    * $AB$ 与 $EF$：$AF \parallel BE$ 得梯形 $AFEB$，点 $E$ 在平面 $ABF$ 上，共面，排除。

    * 结论：与 $EF$ 异面的是 $CD$ 与 $DA$。

* **线面与面面的位置关系**

    * 直线与平面三种位置关系：相交（一个交点）、直线在平面内、直线与平面平行。

    * 两个不同的平面要么平行，要么相交；相交时有且仅有一个交线。

* **线面关系的真命题判别**

    * $a \subset \alpha$，$b \not\subset \alpha$ ⇒ $a$ 与 $\alpha$ 一定相交：为真。$b$ 至少与 $\alpha$ 有交点且该交点不在 $a$ 上。

    * $a \subset \alpha$，$b \not\subset \alpha$ ⇒ $a$、$b$ 必为异面：错误。$b$ 与 $\alpha$ 的交点若恰在 $a$ 上则两线相交；也可能 $b \parallel \alpha$ 且 $b \parallel a$。

    * $a \not\subset \alpha$，$b \not\subset \alpha$ ⇒ $a \parallel \alpha$：错误。两条线可一高一低使直线穿过 $\alpha$ 产生交点。

    * $a \parallel \alpha$，$b \subset \alpha$ ⇒ $a \parallel b$：错误。$b$ 在 $\alpha$ 上的方向可以任意倾斜。

## 异面直线所成的角

* > **定义**：异面直线所成的角——把其中一条直线平移，使两线相交，所得的锐角或直角。

    * 规定两条直线所形成的非钝角作为这两条直线的夹角，量出来的可能是 $45^\circ$ 而不是 $135^\circ$。

    * 判定两条线是否垂直，就看平移后共面夹角是否为 $90^\circ$；不到 $90^\circ$ 就不垂直。

* **正方形中的三种角**

    * 一条边与另一条边：平移后成直角，$90^\circ$，线线垂直。

    * 两条对角线：平移后恰为正方形另一条对角线，对角线成 $90^\circ$，线线垂直。

    * 一条对角线与一条边：平移后构成等腰直角三角形，两直角边均 $45^\circ$。

* **空间角度问题的统一动作**

    * 平移到共面、再量角，这是空间里所有角度问题的基础动作。

## 空间四边形与中点连线

* > **定义**：空间四边形——平面四边形沿任意一条对角线折起、四点不共面后顺次相连所得的封闭图形。

    * 空间四边形有 $AB$、$BC$、$CD$、$DA$ 四个面。

    * 与三棱锥只差一根线：把 $AC$ 连上，三角形各分一刀变成四个面，图形即成为三棱锥。

* **对角线相等时的中点四边形**

    * 已知空间四边形 $ABCD$ 且 $AC = BD$，四个面的四条棱的中点连成四边形，其形状是菱形。

    * 推导：在 $\triangle ABC$ 中 $EF$ 是 $AC$ 的中位线，$EF \parallel AC$ 且 $EF = \tfrac12 AC$；在 $\triangle ADC$ 中 $HG$ 同样是 $AC$ 的中位线，$HG \parallel AC$ 且 $HG = \tfrac12 AC$。由平行传递性 $EF \parallel HG$，又 $EF = HG$，平行且相等，四边形为平行四边形。

    * 同理在 $\triangle ABD$、$\triangle BCD$ 中 $EH$、$FG$ 都是 $BD$ 的中位线，长度均为 $\tfrac12 BD = \tfrac12 AC$；四边全等于棱长的一半，故为菱形。

    * 这道题真正在考的是空间里的平行传递性：两条都平行于同一条线，则这两条平行。

## 三种平行的关系网

* **平行的种类与互推方向**

    * 空间中平行只有三种：线线平行、线面平行、面面平行；点与点之间只谈重合，不谈平行。

    ```text
      线线平行  ──▶  线面平行  ──▶  面面平行
      线线平行  ◀──  线面平行  ◀──  面面平行

      向下是判定（条件写全才得分），向上是性质（由已知推结论）
    ```

* **线线平行的两条基本依据**

    * 平行于同一条直线的两条直线平行：$a \parallel c$，$b \parallel c$ ⇒ $a \parallel b$。

    * > **定义**：等角定理——空间中两个角的两条边分别平行，则这两个角相等或者互补。

        * 两种可能都要想到：边的平行方向可能一致，也可能相反，只认"相等"会栽在"互补"上。

* **六个方向的条件清单**

    | 方向 | 依据 | 条件数 |
    | :--- | :--- | :--- |
    | 线线 → 线面 | 线面平行判定定理 | 三推一 |
    | 线面 → 线线 | 线面平行性质定理 | 三推一 |
    | 线面 → 面面 | 面面平行判定定理 | 五推一 |
    | 线线 → 面面 | 两对相交直线分别平行 | 七推一 |
    | 面面 → 线线 | 面面平行性质一 | 二推一 |
    | 面面 → 线面 | 面面平行性质二 | 二推一 |

    * 最容易漏掉的是"面面 → 线面"，它给出证明线面平行的第二条路。

    * 面面平行还有传递性：$\alpha \parallel \beta$，$\beta \parallel \gamma$ ⇒ $\alpha \parallel \gamma$。

## 线面平行的判定与性质

* **判定定理**

    * > **定义**：判定定理回答"我怎么判断它成立"，性质定理回答"已知它成立，它有什么性质"。

    * 平面外的一条直线和此平面内的一条直线平行，则该直线与此平面平行：

        $$L \parallel M,\quad L \not\subset \alpha,\quad M \subset \alpha \;\Longrightarrow\; L \parallel \alpha$$

    * 一句话是线线平行推出线面平行，形式上是三推一，三个条件必须写全。

    * 少写 $L \not\subset \alpha$ 就被反例推翻：此时 $L$、$M$ 同在 $\alpha$ 上且平行，$L$ 是在面上而不是与面平行。

* **判定定理的用法边界**

    * 只要**存在**一条线与它平行即可，平面内其他再多直线与它不平行没有关系。

    * > **易错点**：把平面内三条边都不平行当成"线不平行面"是最经典的坑；平面里有三千条不平行，也只要那一条。

* **性质定理**

    * 直线 $L$ 与平面 $\alpha$ 平行，则过 $L$ 的平面与 $\alpha$ 相交，所得交线与 $L$ 平行：

        $$L \parallel \alpha,\quad L \subset \beta,\quad m = \alpha \cap \beta \;\Longrightarrow\; L \parallel m$$

    * 本质是由线面平行推出线线平行；条件 $L \subset \beta$ 是"过该直线的平面"，千万别漏写。

    * 题目平白无故给出线面平行时，就应当想到用这条性质。

* **性质定理的选面策略**

    * 过 $L$ 的面有无数个，选面标准是：既要过 $L$，又要跟题目所问的点产生关系。

    * 四棱锥比例题实例：$P$ 在平行四边形 $ABCD$ 外构成三棱锥，$E$ 是 $AD$ 中点，$F$ 在 $PC$ 上，$PA \parallel$ 面 $EBF$ 时求 $PF : FC$。选面 $PAF$（三点定面），交线由两面公共点连成，交线 $\parallel PA$，进而得到大三角形与小三角形相似。

    * 交点在 $AC$ 上的位置靠重心定：在 $\triangle ABD$ 中 $AE$、$BE$ 为中线，交点 $G$ 是重心，$AG : GE = 2 : 1$，即 $G$ 在 $AE$ 上的位置为 $1 : 2$；$F$ 同为 $1 : 2$，得 $PF : FC = 1 : 2$。

    * 重心把每条中线按 $2:1$ 分开，从顶点算起是长的两份，从中间点算起是短的一份。

## 面面平行的判定与性质

* **判定定理**

    * 一个平面内的两条相交直线都与另一个平面平行，则这两个平面平行：

        $$L \parallel \beta,\; M \parallel \beta,\; L \cap M = P,\; L \subset \alpha,\; M \subset \alpha \;\Longrightarrow\; \alpha \parallel \beta$$

    * 五推一，少一个条件扣一分。

    * 追问一"为什么非得两条线"：经过一条线的面有无数个，随便取一个面过 $L$，它可能与 $\beta$ 根本没有交线，一条定不住。

    * 追问二"为什么非得相交"：若在 $\alpha$ 内取两条平行线，经过这两条平行线的面一望无际，仍推不出两面平行。

    * 缺出的两个条件是 $L \subset \alpha$、$M \subset \alpha$：只在 $L$、$M$、$P$、$\beta$ 四个量之间转换而突然冒出 $\alpha$，逻辑链条断裂，等于"没钱凭什么别人给钱"。

* **七推一推论**

    * 一个平面内有两条相交直线，分别平行于另一个平面内的两条直线，则两个平面平行：

        $$\begin{aligned} & L_1 \parallel L_2,\; M_1 \parallel M_2 \\ & L_1 \cap M_1 = S,\; L_2 \cap M_2 = T \\ & L_1, M_1 \subset \alpha,\; L_2, M_2 \subset \beta \\ & L_1 \cap \beta = \varnothing \end{aligned} \;\Longrightarrow\; \alpha \parallel \beta$$

    * 它是判定定理的前置条件版本：两对都成立线线平行 ⇒ 两对线面平行 ⇒ 面面平行。

    * > **易错点**：只写前六个条件推不出面面平行。四条线两两对应平行但全都落在同一个平面上时，两面是重合关系，必须补排除条件 $L_1 \cap \beta = \varnothing$（或写成 $L_1, M_1$ 不在 $\beta$ 上、$L_2, M_2$ 不在 $\alpha$ 上，任写其一）才凑成七推一。

    * 未来最常用的证明路线就是找两对相交的线线平行，再把这七条老老实实写全。

* **面面平行的三条性质**

    * 性质一（面面 → 线线）：两个平面平行，第三个平面与这两个平面分别相交，所得两条交线互相平行。

    * 性质二（面面 → 线面）：两个平面平行，其中一个平面内的任意一条直线都与另一个平面平行：

        $$\alpha \parallel \beta,\quad L \subset \alpha \;\Longrightarrow\; L \parallel \beta$$

        * 只两推一，不必另加"$L$ 不在 $\beta$ 上"：过一条直线作与它平行的面只能作出来一个，若 $L$ 又在 $\beta$ 上，两面之间有交点就与平行矛盾了，定义上已排除。

    * 性质三：面面平行有传递性。

* **面面平行的判读技巧**

    * 先扫一眼有没有公共点，有公共点必然不平行，这比任何定理都快。

    * 反证式的传递性很好用：若绿 $\parallel$ 蓝而红不 $\parallel$ 蓝，则绿与红也不平行。

    * > **易错点**：立体图里看着像交点的两个点必须回头检查——那两条线共面吗？不共面就是异面直线，"交点"是假的；共面且不平行才是真交点。

## 小面延展与特殊截面

* **题目给的面往往是不完全的面**

    * 沿几何体表面一刀切下去，截到某条棱时切面还没结束，可以继续切；题目给的三角形只是整个截面的一小部分。

    * > **定义**：一个多边形形的"面"展开完全，指它的每一条边都落在空间几何体的表面上。

    * 对照：$AB$、$BC$ 在表面上而 $AC$ 在体内，说明没展开完全；四条边每条都在表面上才算展开完全。

* **延展的两个方法**

    * 做平行线：过面内一个点，作另一条边的平行线。新线与原边平行即与原面共面，不会支出去，连接后小图形变大图形；这是最常用也最爱考的方法。

    * 延长法：把其中一条边延长出去，延长点在同一直线上、仍在同一平面内，连接后小面变大面。

* **正六边形截面**

    * 从正方体上三个棱中点 $A$、$B$、$C$ 出发：过 $B$ 作 $AC$ 的平行线落到棱中点 $G$，得 $GB \parallel AC$，四点共面得梯形 $AGBC$，此时 $AG \parallel MN$，题目其实已经做完；但 $AC$ 在体内，还没完。

    * 过 $C$ 作 $AG$ 的平行线落到 $H$，面对角线平行于面对角线得 $CH \parallel AG$，五点共面；连 $AH$ 后 $H$ 仍在体内。

    * 过 $H$ 作 $GB$ 的平行线落到 $S$，得 $SH \parallel GB$，连 $AS$ 后 $AS$ 与 $SH$ 全部落在表面上，展开完成。

    * 最终图形 $AGBCHS$ 六条边都是面对角线的一半、长度相等，是正六边形截面。

    * 正六边形截面是高频特殊截面，能否默画、能否认出，直接决定能否秒掉一整类题。

* **延展失效时改走面面平行**

    * 正方体题中若在面 $MNP$ 内怎么画都找不到与 $AB$ 平行的线，延展方法失效，改找过 $AB$ 且与面 $MNP$ 平行的新面。

    * 过 $A$ 作 $NP$ 的平行线（就是那条棱），$AB$ 与该棱形成新面；新面内再引出第三条线与 $MN$ 平行，两组都相交，七推一面面平行，面面一平行线面即平行。

* **零散小面与完整面的判别实例**

    * 四个面两两平行的判断中，只有第二个平行；第一个因六个棱中点共面且与对面有交点而不平行，第三个把 $ABC$ 过 $C$ 作 $AB$ 的平行线延展成侧面后用反证式传递性排除，第四个把 $BC$ 延展成正六边形后可见公共点。

    * 另一道四个面判断中，可判不平行的原因是 $MP$、$NP$ 都在体内、面未展开完全；展开过 $P$ 作 $MN$ 的平行线（就是这条线）后与大面产生交点。

## 线面平行的三条辅助线路

* **两条总路线**

    ```text
    目标：证  l ∥ α

    路线一（找线）：在平面 α 内找一条线 l′，证 l ∥ l′  →  线线平行 ⇒ 线面平行
    路线二（找面）：过直线 l 作一个面 β，证 β ∥ α     →  面面平行 ⇒ 线面平行
    ```

    * 真正的难点只有两个：面上那条平行线怎么找，那个面怎么造；两者都有固定套路。

* **第一招：在面内找平行四边形**

    * 把待证线段平移到目标面内，找一条同向等长的线段（优先找棱、中点连线这类现成的平行关系）。

    * > **易错点**：找到了不能写"我看出来了"。既然连了辅助线构出平行四边形，必须把另外两条边连起来并证明那两条边平行且相等——一组对边平行且相等推出平行四边形，再由另一组对边平行推出线线平行，进而线面平行，整套链条一步不能跳。

    * 正方形 $ABCD$ 与正方形 $ABEF$ 沿 $AB$ 折起，$M$、$N$ 为各自对角线交点：取 $G$、$H$ 为 $BE$、$BC$ 的中点，$NG$ 与 $MH$ 同为中位线，都平行于 $AB$ 且都等于 $AB$ 的一半，故 $NGHM$ 为平行四边形，$MN \parallel GH$，而 $GH$ 在面 $BCE$ 内，证得 $MN \parallel$ 面 $BCE$。

    * 死穴：出题人可能把待证线段搞得特长、相应面搞得特短，平移过去根本装不下这个平行四边形，此时改用第二招。

* **第二招：取点连线找中位线**

    ```text
    ① 在"线"与"面"之外取一点 P
    ② 连 PM、PN（M、N 为待证线段的两个端点）
    ③ PM、PN 与目标平面各交于一点，两个交点都在面内
    ④ 连接这两个交点 —— 这就是你想要的线
    ```

    * 两个交点都在同一面内，连接它们的线也在面内，等于在目标面上白捡一条线；能否平行再去证。

    * 大概率两个交点正好是整个线段的中点，即一条中位线；偶尔是三等分点、四等分点，理论上都行。

    * 判平行的关键只有一句：两边比例一样就是相似图形，两条线一定平行。

    * 取点原则：不能取面内的点，不能取待证线段上的点；剩下候选中要挑连出的线不支出体外的那个。

    * 同一正方形例题改用第二招：在 $MN$ 与面 $BCE$ 之外只能取 $A$，连 $AN$ 延长交面于 $E$、连 $AM$ 延长交面于 $C$；$M$、$N$ 分别是 $AC$、$AE$ 的中点，在 $\triangle ACE$ 中 $MN$ 是 $EC$ 的中位线。

    * 三棱柱例题中取点只能取 $A$，两条连线与面的交点中一个直接是 $E$，另一个靠平行四边形对角线相互平分知是 $AC$ 的中点，两中点连线为中位线。

    * 2022 天津题取点 $D$（$D$ 与 $F$ 已有连线且延长后与目标面有交点），连 $DE$ 延长与 $AB$ 的反向延长线交于 $G$，此点即小面被扩大成的同一张大面上的点；由直角三角形全等得 $DG = 2DE$，即 $E$ 是 $DG$ 中点，加 $F$ 为题设中点，得 $EF$ 为中位线。

    * > **易错点**：$DE$ 与 $AB$ 在立体图中看似相交，实为异面直线。必须把所在面单独摊成平面图，才能看出真实交点来自延长线；把辅助线做到体外、伸出去是允许的。

* **第三招：过端点作平行线造平行面**

    * 立体几何中待证直线一定以线段形式出现，必然有两个端点，做平行面就从端点入手。

    * > **方法论**：过这两个端点中的任意一个，作目标面上某条线的平行线；新线与原线段一连，三点确定一个面。

    * 接下来在这个新面里找**两条**线分别证与目标面平行：不能用待证的 $MN$，用了等于证完，必须用 $MN$ 之外的另外两条边。

    * 两对线面平行推出面面平行，面面一旦平行，其中一个面上任何一条线（包括 $MN$）都与另一个面线面平行。

    * 正方形例题中过 $N$ 作 $EB$ 的平行线（落到 $AB$ 的中点 $H$），$NH \parallel BE$、$MH \parallel BC$ 两对线线平行，得面 $NMH \parallel$ 面 $BCE$。

    * 2022 天津题中过 $E$ 作 $CA$ 的平行线（把侧面单独看出，$E$ 为中点，作出的是中位线），得第一对平行；再由 $M$、$F$ 为两边中点得 $MF$ 为中位线，结合平行传递性得 $MF \parallel AB$，凑成第二对。

* **三招的适用纪律**

    * 三个方法不是三选一：做平行四边形、做中位线、做平行面都得会，考试不一定考哪个，出题人真会故意卡到前两个都做不了。

    * 顺序上先掌握思路与连法，会证之后再补书写规范。

* **面面平行的实质**

    * 书上的面面平行证明写成"找两对线面平行"，但写 $l \parallel \beta$ 与 $m \parallel \beta$ 时真正在找的是线线平行——只是要在目标面上找到跟它们各自平行的一条线而已。

    * 这就是面面平行为什么与第一招（找线）死死绑在一起的原因。

## 线线平行的两条路线

* **平面几何路线**

    * 图中到处都是平行四边形、正方形、矩形、菱形，都是特殊平行四边形，对边平行；三角形中有中位线；也可用相似证平行。

    * "上下两条线平行、一三就平行"的传递性也是平面几何内容。

* **立体几何路线**

    * 若题目已给或前面已证出一条线与一个面平行，就过这条线作一个面，该面与原面必有交线。

    * > **结论**：线面平行，则这条线与那个交线必然平行。

    * 做中位线辅助线时之所以敢连出去，正是因为题目已经要求这条线与该面平行，据此判定这个面与目标面的交线必与原线平行。

* **两条路都能用的实例**

    * 三棱柱中 $F$ 是 $AA_1$ 的中点，$BF$ 与 $AE$ 交于 $M$，另一交点为 $N$，求证 $MN \parallel BC_1$。

    * 立体几何路线：用第一问证出的线面平行，过该线作面，交线即所求，$M$ 正好是两面的交点，不需任何辅助线。

    * 平面几何路线：由相似比 $1:2$ 知 $N$ 是 $1:2$ 的三等分点；把侧面单独摊开是个平行四边形，连线后两条中线相交于重心，$M$ 也是 $1:2$；两边等分点比例相同，故 $MN \parallel BC_1$。

    * 这个例子说明立体几何问题可分解成两个不同面上的平面图形问题，用平面几何逐一解决。

## 斜二测画法

* **斜二测画法的三条规矩**

    * 把原来垂直的 $x$ 轴、$y$ 轴，在新图形中让它们形成的夹角变成 $45^\circ$。

    * 所有平行于 $x$ 轴的线段，长度在二维画法与三维画法中都不变。

    * 所有平行于 $y$ 轴的线段，长度除以二；平行于 $z$ 轴的线段，长度与平行于 $x$ 轴的同样不变。

    | 图上的方向 | 原图长度 | 直观图长度 |
    | :--- | :--- | :--- |
    | 平行于 $x$ 轴的线段 | $a$ | $a$ |
    | 平行于 $y$ 轴的线段 | $b$ | $\dfrac{b}{2}$ |
    | 平行于 $z$ 轴的线段 | $c$ | $c$ |

    * 正方体底面的正方形之所以画成平行四边形：原本垂直的两条边一条在 $x$ 轴上、一条在 $y$ 轴上，必须改成 $45^\circ$，平行于 $y$ 轴的那条边长度再减半。

* **面积按固定比例变化**

    * > **结论**：$S_{\text{原}} = 2\sqrt2\,S_{\text{直}}$。

    * 推导：等腰直角三角形两腰为 $a$、原高为 $H$，斜二测后新的高是 $H$ 作为斜边的一半再换算成直角边，即 $h' = \dfrac{H}{2\sqrt2}$；原面积 $S = \dfrac12 aH$，新面积 $S' = \dfrac12 a\cdot\dfrac{H}{2\sqrt2}$，两者恰差 $2\sqrt2$ 倍。

    * 三角形、四边形、五边形、六边形全都满足这个关系，因为多边形可拆成一个个三角形再拼起来。

* **由直观图还原平面图**

    * 还原时**平行性质不能变，垂直性质可以变**；原来垂直的两条边斜二测后不再垂直，但平行的两条边转化前后照样平行。

    * 还原次序：先确定位置已知的两个点，第三个点先判断它在 $y$ 轴上还是在 $x$ 轴上——这条边原来平行于 $y$ 轴，转化后仍平行于 $y$ 轴，转化前必然也在 $y$ 轴上，长度取现在的两倍；第四点靠平行性确定，平行于 $x$ 轴的边长度前后不变。

    * 等腰梯形还原例：直观图底角 $45^\circ$、腰与上底均为 $1$，先求下底为 $1 + \sqrt2$，得 $S_{\text{直}} = \dfrac{1+(1+\sqrt2)}{2}\times\dfrac{\sqrt2}{2}$，再乘 $2\sqrt2$ 得原图面积 $2+\sqrt2$；原图实际是直角梯形。

    * 周长还原例：$A'B'$、$A'C'$ 均为 $1$，$AB \parallel x$ 轴、$AC \parallel y$ 轴，则 $\angle A = 90^\circ$ 且两直角边相等，是等腰直角三角形，$BC = \sqrt2$。作图时先画最易画的 $AB$（长度不变，取 $1$），再画 $AC$（长度加倍，取 $2$），得 $BC = \sqrt{2^2+2^2} = 2\sqrt2$，周长 $1 + 2 + 2\sqrt2 = 3 + 2\sqrt2$。

    * > **注意**：知道面积比例结论不代表会还原，还原才是这一步真正的考点。

    * 斜二测画法只是最标准的画法，平时做题私下画不必如此标准，它本身不是这一部分的重点。

## 表面积

* **棱柱、棱锥、棱台**

    * 把每个面的面积分别求出来再相加，每个面是什么形状就套对应的平面公式：平行四边形用底乘高，三角形用 $\dfrac12$ 底乘高，梯形用上底加下底乘高除以二。

* **圆柱**

    * 侧面展开是矩形，宽为柱高 $h$，长为底面圆周长 $2\pi R$。

    * 侧面积 $2\pi Rh$，表面积 $S_{\text{柱}} = 2\pi Rh + 2\pi R^2$。

* **圆锥**

    * 侧面展开是扇形，半径即母线长 $l$，扇形弧长正好等于底面圆周长 $2\pi R$。

    * 侧面积 $S_{\text{侧}} = \dfrac12\cdot 2\pi r\cdot l = \pi rl$；问表面积时还要再加底面 $\pi r^2$。

    * 母线可能直接给出，也可能由底面半径与高先用勾股定理求出。

* **圆台**

    * 侧面展开是圆环的一部分，上下两段弧长分别为 $2\pi R_1$ 与 $2\pi R_2$，两线间距离是小母线 $l$。

    * > **注意**：公式里的"高"是圆台的小母线 $l$，不是圆台自身的高。

    * 侧面积按梯形公式算：$S_{\text{侧}} = \dfrac{2\pi R_1 + 2\pi R_2}{2}\cdot l = \pi(R_1+R_2)l$；也可用大扇形面积减小扇形面积，但过程繁琐。

## 柱体与锥体的体积

* **基本公式**

    * 柱体（棱柱与圆柱一律如此）体积等于底面积乘高；锥体（棱锥与圆锥一律如此）体积等于 $\dfrac13$ 底面积乘高。

    * 公式本身不复杂，缺的是高：高中范围内通常不直接给出高或底面积，需要自己求。

* **求高的标准动作：一柱擎天**

    * 找出一个直角三角形，把体对角线或面对角线塞进去用勾股定理。

    * 正四棱柱（底面是正方形且侧棱垂直于底面）实例：$BD = 4\sqrt2$ 是底面正方形的对角线，故边长为 $4$；$DB_1 = 9$ 是体对角线，直棱柱侧棱垂直于底面，构成直角三角形，高 $BB_1 = \sqrt{9^2 - (4\sqrt2)^2} = 7$，体积 $V = 16\times7 = 112$。

* **侧面积最值与基本不等式**

    * 正四棱柱对角线长为 $3$，求侧面积最大值：面对角线构成 $45^\circ$ 直角三角形，$AC = \sqrt2 a$，列恒等式 $2a^2 + H^2 = 9$。

    * 由基本不等式 $2a^2 + H^2 \ge 2\sqrt2\,aH$ 得 $aH \le \dfrac{9}{2\sqrt2} = \dfrac{9\sqrt2}{4}$。

    * > **易错点**：上面求出的是一个面的面积，问"侧面积"必须排除上下底面后乘以 $4$，得 $S_{\text{侧}} = 4aH \le 9\sqrt2$。凡问侧面积，先在脑中念一遍"排除了哪两个面"。

    * 题目中"对角线"若不特别说明，指两点距离最远的那条，即体对角线。

* **台体体积公式与三种体的统一**

    * 棱台与圆台共用同一公式：$V = \dfrac13 H\left(S_1 + S_2 + \sqrt{S_1S_2}\right)$，其中 $S_1$ 为上底面积、$S_2$ 为下底面积、$H$ 为高。

    * 理解方式：$\dfrac13$ 乘进去看成上底面、下底面、几何平均三者的平均值。

    * 让 $S_1$ 趋近于零（把上底面缩成一个点再与下底面四点相连），公式退化为 $\dfrac13 S_2 H$，即锥体体积。

    * 令 $S_1 = S_2 = S$，公式退化为 $V = \dfrac13(S + S + S)H = SH$，即柱体体积。

    * 棱台与圆台能用同一公式的理由是祖暅原理：两者上下底面面积相同、对应面相似，任意平行平面截得的截面面积必然相同，逐层叠起来体积当然相同。

* **台体例题**

    * 正四棱台上下底边长分别为 $A_1B_1 = 1$、$AB = 2$，侧棱 $AA_1 = \sqrt2$。作俯视图，两个正方形中心重合，$A'A = \dfrac{2\sqrt2 - \sqrt2}{2} = \dfrac{\sqrt2}{2}$，侧棱中"竖直"的那一份才是高：

        $$h = \sqrt{AA_1^2 - \left(\frac{\sqrt2}{2}\right)^2} = \sqrt{2 - \frac12} = \frac{\sqrt6}{2}$$

        代入 $S_1 = 1$、$S_2 = 4$、$\sqrt{S_1S_2} = 2$，得 $V = \dfrac13\cdot\dfrac{\sqrt6}{2}\cdot 7 = \dfrac{7\sqrt6}{6}$。

    * 圆台体积比：两圆台上下底面半径相同、母线分别为 $\sqrt3$ 与 $2\sqrt2$。母线、母线在水平方向的投影 $R_1 - R_2$ 与竖直边组成直角三角形，$h_i = \sqrt{l_i^2 - (R_1-R_2)^2}$。因 $S_1 = S_2 = \pi R^2$，公式中 $S_1 + S_2 + \sqrt{S_1S_2}$ 部分完全相同并约掉，体积之比只剩高之比：$\dfrac{V_{甲}}{V_{乙}} = \dfrac{h_1}{h_2} = \dfrac{\sqrt3}{2\sqrt2} = \dfrac{\sqrt6}{4}$。

    * "正棱台"的含义有两层：上下底面都是正多边形；各侧棱长度相等，即上底面在底面的投影正好落在中心点上，歪出去就不能叫正棱台。

## 换顶点与等体积法

* **三棱锥的换顶点**

    * 三棱锥体积 $\dfrac13\times$ 底面积 $\times$ 高，出题人给的顶点未必是好算的那个；把谁当上顶点时底面积与高都好求，就用谁。

    * 正方体棱长为 $2$，$M$、$N$ 分别是 $BB_1$、$AB$ 的中点，求四面体 $A_1-D_1MN$ 的体积：把 $D_1$ 当上顶点、面 $A_1MN$ 当底面，因为 $A_1MN$ 恰在正方体表面上，面积特别好求，而高就是棱 $D_1A_1$ 本身，长度为 $2$。

    * 底面 $\triangle A_1MN$ 是等腰三角形，两腰 $A_1M = A_1N = \sqrt5$，底 $MN = \sqrt2$；作 $A_1N$ 边上的高落在 $MN$ 中点，$h = \sqrt{5 - \left(\dfrac{\sqrt2}{2}\right)^2} = \dfrac{3}{2}\sqrt2$，故 $S = \dfrac12\cdot\sqrt2\cdot\dfrac{3}{2}\sqrt2 = \dfrac32$，体积 $\dfrac13\times\dfrac32\times2 = 1$。

    * > **易错点**：出题人给的顶点你不必照用；他给的顶点往往正是难算的那个，转换顶点反而好算。

* **等体积法求点到面的距离**

    * 同一个四面体有四种选顶点的方式，四个量满足等量关系 $\dfrac13 S_1H_1 = \dfrac13 S_2H_2 = \dfrac13 S_3H_3 = \dfrac13 S_4H_4$，知道任意三个量第四个量就出来了。

    * 求点 $P$ 到平面 $\alpha$ 的距离 $h$ 时，若不好直接作垂线，就找一个以 $P$ 为顶点、以 $\alpha$ 内图形为底面的棱锥，把体积用两种顶点各算一遍，列方程解出 $h$。这对棱柱、棱锥、球体全都通用。

    * 正方体棱长为 $2$，求 $D_1$ 到面 $A_1BD$ 的距离：另选 $B$ 为上顶点、面 $A_1DD_1A$ 为底面，体积 $\dfrac13\times 2\times2 = \dfrac43$，高为 $2$；而 $\triangle A_1BD$ 三边都是同一面的对角线，长度相等，是边长 $2\sqrt2$ 的等边三角形，面积 $2\sqrt3$。于是 $H_1 = \dfrac{3V}{S_{A_1BD}} = \dfrac{3\times\dfrac43}{2\sqrt3} = \dfrac{2\sqrt3}{3}$。

    * 直三棱柱体积为 $3$ 时，三棱锥体积是它的 $\dfrac13$，即 $1$；求 $A$ 到面 $A_1BC$ 的距离得 $h = \dfrac{3}{S_{\triangle A_1BC}}$。

    * 有些题全程不出现体积，只问点到面的距离——把距离看成高、用体积算两遍列方程，正是这类题的完整路径。

* **平行传递性与垂直传递性**

    * 无论在平面里还是空间里，传递性都可用：两条平行线各自与第三条平行，则第三条与它们平行；一条线与第三条垂直，过它再做两次平行，另一条线也与第三条垂直。

    * 正方体内一点在中点、两点同为棱中点时，平行四边形的对角线相互平分常被用来确认某点是大三角形某边的中点。

## 球

* **祖暅原理**

    * > **定义**：祖暅原理（密室积同）——夹在两平行平面之间、被任意平行平面所截截面面积恒定的两个几何体，体积相等。

    * 它讲的是切片：几何体由一层一层的面叠成，每层面积都相同，叠出来的体积当然也相同。

* **球体积的推导**

    * 先推半球：在半球旁作一个底面半径为 $R$、高也为 $R$ 的圆柱，以上底面为底、以下底面中心为顶点挖去一个圆锥，得到一个新几何体。

    * 用同一平面去截两边。半球截面是圆，半径由勾股定理得 $\sqrt{R^2 - h^2}$，面积 $\pi(R^2 - h^2)$；另一侧截面是圆环，小圆半径为 $h$（截面图中的三角形是等腰直角三角形，圆锥高与切片高同为 $h$），面积 $\pi R^2 - \pi h^2$。

    * 两边截面面积恒等，由祖暅原理得 $V_{\text{半球}} = V_{\text{圆柱}} - V_{\text{圆锥}} = \pi R^3 - \dfrac13\pi R^3 = \dfrac23\pi R^3$，再乘二得 $V_{\text{球}} = \dfrac43\pi R^3$。

    * 用的是割补法：整个大体积减去挖掉的圆锥体积。

* **球表面积的推导**

    * 取球面上非常小的一块曲面 $\Delta S$，它与球心连成一个类似小锥体；底面严格说是弯的，但取得足够小时可以近似成平面，这是极限思想。

    * 每块对应的小锥体体积为 $V_i = \dfrac13\Delta S_i\cdot R$，其中高近似为半径 $R$。把 $N$ 块加总：

        $$V_{\text{球}} = \frac13 R\left(\Delta S_1 + \Delta S_2 + \cdots + \Delta S_N\right) = \frac13 R\cdot S$$

        再由 $\dfrac43\pi R^3 = \dfrac13 R\cdot S$ 解出 $S_{\text{球}} = 4\pi R^2$。

* **两个公式必须分清**

    * $V = \dfrac43\pi R^3$ 是体积，$S = 4\pi R^2$ 是表面积。

    * > **易错点**⚠️：$\dfrac43$ 与 $4$ 这两个数字千万别记混，$4\pi R^2$ 才是表面积。

* **球从来不单独考**

    * 直接给半径再背公式的考法不会出现，球一般与其他空间几何体结合，考的过程中经常要构造直角三角形用勾股定理。

    * 球内接圆柱（2011 四川）：设柱高 $H$、底面半径 $r$，过球心作截面得 $R^2 = \left(\dfrac{H}{2}\right)^2 + r^2$；$2\pi$ 为定值只需最大化 $rH$，基本不等式给出 $Hr \le \dfrac{R^2}{2}$，等号成立时 $r = \dfrac{H}{2}$，此时侧面积 $=\pi R^2$，故 $S_{\text{球}} : S_{\text{侧}} = 4\pi R^2 : \pi R^2 = 4 : 1$。

    * 正方体的内切球与外接球（2006 山东）：内切球是球在正方体内膨胀到最大，与六个面各有一个切点，直径等于棱长 $a$，$R_{\text{内}} = \dfrac a2$；外接球是正方体被球从外面包住缩小到最小，八个顶点都卡在球面上，直径即体对角线，由 $1 : \sqrt2 : \sqrt3$ 得体对角线 $=\sqrt3 a$，$R_{\text{外}} = \dfrac{\sqrt3}{2}a$。体积与半径的立方成正比，$V_{\text{内}} : V_{\text{外}} = 1 : 3\sqrt3 = 8\sqrt3 : 9$。

    * 一个截面两个圆锥：球体积为 $\dfrac{32}{3}\pi$ 得 $R = 2$、直径 $4$；两圆锥顶点分居直径两端，高之比 $1:3$ 故两高为 $1$ 和 $3$；球心在直径中点，球心到截面的距离为 $3 - 2 = 1$，勾股定理得截面半径 $r = \sqrt{2^2 - 1^2} = \sqrt3$。两圆锥体积之和 $=\dfrac13\pi r^2(h_1 + h_2) = \dfrac13\pi\cdot3\cdot4 = 4\pi$。

## 垂直的四张网

* **线面垂直的定义**

    * > **定义**：如果一条直线和一个面内任意一条直线都是垂直的，那么直线与平面相互垂直。

    * 直观的物理解释是地面上竖立的电线杆：地面上随便画一条线，电线杆与它都成直角。

    * 引申性质：已知 $L \perp \alpha$，则该面上任何一条直线都与 $L$ 垂直。完整写法必须补上"$m$ 在面上"：

        $$L \perp \alpha,\quad m \subset \alpha \;\Longrightarrow\; L \perp m$$

    * > **易错点**：不写 $m \subset \alpha$ 形式上逻辑断裂——$L$ 没变却从面 $\alpha$ 跳到线 $m$，两者的关系没有交代，推着推着下面所有推理全部塌掉。

* **判定定理**

    * 一条直线与一个平面内的两条相交直线都垂直，则线面垂直，形式上是四步：

        | 步骤 | 内容 |
        | :--- | :--- |
        | 已知 | $L$ 与 $m$ 垂直，$L$ 与 $n$ 垂直 |
        | 补充 | $m$ 与 $n$ 相交于一点 $P$ |
        | 补充 | $m \subset \alpha$，$n \subset \alpha$ |
        | 结论 | $L \perp \alpha$ |

    * 定义的苛刻之处（面内无数条线）与判定的宽松之处（只要两条相交线）正相对照。

    * > **易错点**："相交"两个字是硬条件。反例：底面上有互相平行的 $AB$ 与 $CD$，底面外有一条直线 $AD$ 与这两条都成 $90^\circ$，但它与底面是平行关系而非垂直。

* **垂直题的通用推进链**

    ```text
    题目白送一个线线垂直  →  往往一点用没有
            ↓
    自己再找一个线线垂直（连辅助线也要算上）
            ↓
    两条相交直线 + 一条绿线，两对线线垂直
            ↓
    推出线面垂直
            ↓
    线面一旦垂直 → 又蹦出一堆新的线线垂直
    ```

    * 白送的线线垂直若本身就是异面直线则完全不可用，关键是主动连辅助线补出第二组。

* **直三棱柱例题：同一思路用两遍**

    * 条件：$AB$、$AC$、$AA_1$ 三边相等（$BC$ 未给，底面只是等腰三角形），且 $AC \perp B_1C_1$。

    * 第一遍：直三棱柱意味着侧棱与底面线面垂直，故 $AA_1 \perp AC$；邻边相等且垂直的平行四边形是正方形，两条对角线 $A_1C_1$ 与 $AC$ 垂直。于是 $A_1C_1$ 与两条相交线 $AC$、$AB$（前者由题给、后者由正方形对角线）都垂直，得 $A_1C_1 \perp$ 面 $ABC_1$。

    * 第二遍：$AB$ 既与 $A_1C_1$ 垂直，又与 $AC$ 垂直，故 $AB \perp$ 面 $ABC_1$；线面一垂直，$AB$ 与该面内未用的 $AC$ 垂直，底面成为等腰直角三角形，$BC = \sqrt12$。

    * $B_1C_1B$ 是直角三角形（$BB_1$ 垂直于底面），$B_1C_1 = \sqrt{(\sqrt{12})^2 + (\sqrt6)^2} = 3\sqrt2$。

* **四棱锥实战：同一条线当两次交际花**

    * 条件：四棱锥 $P-ABCD$ 中 $AP \perp$ 面 $PCD$，$AD \parallel BC$，$AB = BC$，$AB = \dfrac12 AD$，$E$、$F$ 为对应棱中点。

    * 由 $ED = BC$ 且 $AD = 2BC$ 得 $EDFC$ 为平行四边形，其对角线 $EF$ 与 $AC$ 互相平分，故 $G$ 是 $AC$ 的中点。

    * 证 $AP \parallel BF$ 时第一招作废（面太小、线太长）；第二招取 $C$，连 $PC$ 交面于 $F$、连 $AC$ 交面于 $G$，$F$ 与 $G$ 同为 $\triangle ABC$ 两边的中点，$FG$ 为中位线，$FG \parallel AB$，线面平行成立。

    * 证 $BE \perp$ 面 $PAC$：面 $PAC$ 上只有 $AP$、$PC$、$AC$ 三条线，与 $BE$ 共面的只有 $AC$，故先证 $BE \perp AC$——平行四边形 $EDFC$ 又是菱形（$ED = BC$），对角线互相垂直。

    * 再证 $BE$ 与余下条件挂钩：$BE \parallel CD$，而 $AP \perp$ 面 $PCD$ 给出 $AP \perp CD$，由平行（垂直）的传递性得 $BE \perp CD$，进而 $BE \perp AP$。

    * $BE$ 出现两次、与两条相交线都垂直，故 $BE \perp$ 面 $PAC$。

* **面面垂直**

    * 判定定理：一个平面经过另一个平面的垂线，则两个平面垂直。形式是 $L \perp \alpha$，$\beta$ 经过 $L$（即 $L \subset \beta$）⇒ $\alpha \perp \beta$；这个面无论怎么经过 $L$ 都能推出面面垂直。

    * 性质定理：两个平面垂直，一个面内有一条直线垂直于这两个平面的交线，则这条线与另外一个面线面垂直：

        $$\alpha \perp \beta,\quad \alpha \cap \beta = L,\quad M \subset \beta,\quad M \perp L \;\Longrightarrow\; M \perp \alpha$$

    * > **提示**：题目白给一个面面垂直时，唯一能想到的用法就是找这两面交线的垂线——先定交线，再找与交线垂直的那条线，这条线是自己找出来的，找到它就得到一条新的线面垂直。

    * 本质是由面面垂直推线面垂直。

    * 证明面面垂直前要先决定谁当"下面的面"：谁的垂直条件多，就给谁当底面，再去证另一个面的垂线。

* **用画图去否定**

    * 图形选择题的重点不是算，而是感受构造不出结论的那些反例。

    * $m \perp n$ 且 $m \parallel \alpha$：与一条固定直线垂直的线有无数条，可以绕着 $n$ 在空间中"转圈"，它们与 $\alpha$ 的关系各不相同，可能平行也可能垂直，推不出结论。

    * $m \parallel n$，$m \parallel \alpha$，$\alpha \perp \beta$：另一个面怎么画不确定，$m$ 与 $\beta$ 的关系也不确定。

    * $m \perp n$，$m \perp \beta$，$n \perp \alpha$：为真。跟同一个面垂直的两条线必然平行，不需要任何定理；与固定直线垂直的面有无数个，但它们像穿糖葫芦一样彼此平行，无论取哪个方向 $m$ 与 $\alpha$ 都线面垂直。

    * $m \perp n$，$n \perp \beta$，$\beta \perp \alpha$：$m$ 可以在与 $n$ 垂直的范围内转圈，与 $\alpha$ 的位置关系完全不确定。

    * > **易错点**⚠️：线线垂直加上线面垂直，推不出线面垂直。"看起来垂直"是最贵的陷阱，必须能同时画出"看起来不垂直"的反例才能判错。

* **菱形底面加一根旗杆**

    * 菱形的现成垂直是对角线互相垂直；旗杆条件 $BE \perp$ 底面使 $BE$ 与底面上任何一条线（含对角线）都垂直，得 $AC \perp BD$ 与 $BE \perp AC$。

    * $AC$ 与两条相交线都垂直，故 $AC \perp$ 面 $BED$；面 $AEC$ 经过 $AC$，由线面垂直一步得面面垂直。

    * 若给 $\angle ABC = 120^\circ$，菱形一分为二得两个 $60^\circ$，相当于两个等边三角形拼成；再给 $AE \perp EC$ 则 $\triangle AEC$ 是直角三角形。

    * 求三棱锥 $E$-$ACD$ 体积时把 $\triangle ACD$ 当底面、$BE$ 当高。设菱形边长 $a$，则 $S_{\triangle ACD} = \dfrac{\sqrt3}{4}a^2$，高 $BE$ 必须用 $a$ 表示（多引入一个变量就变成两变量一方程，解不出来）：$BG = \dfrac a2$，$EG = \dfrac{\sqrt3}{2}a$，由 $BE = \sqrt{BG^2 - EG^2} = \dfrac{\sqrt2}{2}a$。

    * 代入 $\dfrac13\cdot\dfrac{\sqrt3}{4}a^2\cdot\dfrac{\sqrt2}{2}a = \dfrac{\sqrt6}{3}$ 得 $a = 2$。

    * 侧面积逐面算：$AE = EC = \sqrt6$，$S_{\triangle AEC} = 3$；$ED = \sqrt6$、$AD = 2$，$\triangle AED$ 是 $\sqrt6,\sqrt6,2$ 的等腰三角形，$S_{\triangle AED} = \sqrt5$，$\triangle EDC$ 同理 $S = \sqrt5$，合计 $S_{\text{侧}} = 3 + 2\sqrt5$。

    * > **易错点**：三棱锥的侧面积与表面积不一样，侧面积是除底面之外另外三个面的面积之和。

* **逆向思维：卡住时倒着想**

    ```text
    已知：AC ⊥ PB（已经证出来的）
    目标：CM ⊥ PB

      ↓  PB 前后出现两回 ⇒ PB 是"交际花"，CM 必然也与 PB 垂直
      ↓  同一条 PB 与两条线都垂直 ⇒ PB ⊥ 这两条线所成的面
      ↓  面上一共三条线，垂直前两条，第三条必然也垂直
      ↓  所以必须先证明 AM ⊥ PB
      ↓  连辅助线时就得把 AM 连上
    ```

    * 垂直问题条件特别多时不知道往哪条路想，就把要证明的东西当成已知条件推一推；题目让你证的结论肯定成立，反推能直接指出该连哪条辅助线。

    * 四棱锥梯形底面实例中，$AC \perp$ 面 $PAB$ 由面面垂直的性质定理得到（$AC$ 是交线 $AB$ 在面 $ACD$ 内的垂线），进而 $AC \perp PB$；由 $M$ 是 $PB$ 中点、$A$ 是 $PA$ 中点且 $PA = AB$ 得 $\triangle PAB$ 是等腰三角形，中线三线合一得 $AM \perp PB$，$PB$ 遂与 $AM$、$AC$ 都垂直而垂直于面 $ACM$，最终 $CM \perp PB$。

    * 同样是梯形底面且 $AB = 2CD$ 时，$PA = AB$ 并没说 $PA$ 是四棱锥的高——没说线面垂直就不是旗杆，可用的只有面 $PAB$ 与面 $ABCD$ 面面垂直这一条。

* **四个定理的骨架**

    * 线面垂直的性质：已知线面垂直，则线与面上任何一条线垂直，写的时候别漏"$m \subset \alpha$"。

    * 线面垂直的判定：找这个面上任意两条相交直线，都与这条线垂直即可推出线面垂直，"相交"缺一不可。

    * 面面垂直的判定：让其中一个面经过另一个面的垂线。

    * 面面垂直的性质：白给面面垂直时找两面交线的垂线，这条垂线与另一个面线面垂直。

## 判定表与共性易错清单

* **平行的条件数表**

    | 目标 | 依据 | 完整条件 |
    | :--- | :--- | :--- |
    | 线线 $\parallel$ 线线 | 平行传递性 | $a \parallel c$，$b \parallel c$ |
    | 线面 $\parallel$ | 判定定理 | $L \parallel M$，$L \not\subset \alpha$，$M \subset \alpha$ |
    | 线线 $\parallel$ | 线面平行性质 | $L \parallel \alpha$，$L \subset \beta$，$m = \alpha \cap \beta$ |
    | 面面 $\parallel$ | 判定定理 | $L \parallel \beta$，$M \parallel \beta$，$L \cap M = P$，$L \subset \alpha$，$M \subset \alpha$ |
    | 面面 $\parallel$ | 七推一推论 | 两对线线平行 + 两组相交 + 两组分别含于两面 + 排除两面重合 |
    | 线线 $\parallel$ | 面面平行性质一 | 两平行面被第三面所截，截线平行 |
    | 线面 $\parallel$ | 面面平行性质二 | $\alpha \parallel \beta$，$L \subset \alpha$ |

* **垂直的条件数表**

    | 目标 | 完整条件 |
    | :--- | :--- |
    | 线线 $\perp$ 线线 | $L \perp \alpha$，$m \subset \alpha$ |
    | 线面 $\perp$ | $L \perp m$，$L \perp n$，$m \cap n = P$，$m \subset \alpha$，$n \subset \alpha$ |
    | 面面 $\perp$ | $L \perp \alpha$，$L \subset \beta$ |
    | 线面 $\perp$ | $\alpha \perp \beta$，$\alpha \cap \beta = L$，$M \subset \beta$，$M \perp L$ |

* **共性书写纪律**

    * 每次在线与面之间做转换，都要把线与面的关系定义出来：线上要写"在哪个面上"或"不在哪个面上"，面相关的要写"含哪条线"。

    * 由面跳到线、由线跳到面的每一次转换，缺条件都会让整条逻辑链断裂。

    * 面面平行的七推一中，第七个排除条件判卷不严格时写不写都行，但建议写上。

* **共性图像陷阱**

    * 立体图里看着像交点的两个点，必须检查那两条线是否共面：不共面就是异面直线，"交点"是假的。

    * 判定两面是否平行先扫一眼有没有公共点，有公共点必然不平行。

    * 辅助线做出版面之外、伸出体外部是允许的，只要延长的落点在同一个面上。

    * 面面平行后用其性质二推出线面平行时，仍要写"$DE \subset$ 面 $DEG$"这类归属条件，不写必扣分。

* **几何体部分的通用入口**

    * 空间几何体的"高"永远是要自己求的量：找直角三角形、把体对角线或面对角线塞进去用勾股定理；球的问题同样经常要构造直角三角形。

    * 求最值的基本动作是基本不等式，配"平方和为定值、最大化乘积"的结构；由基本不等式得到一个面的量之后，要立刻回到题目问的是面积、侧面积还是表面积。

    * 顶点、底面的选取是棱锥与等体积法的共同枢纽：同一个四面体换顶点可以得到四组等量关系，知道任意三个量第四个量就现成。
