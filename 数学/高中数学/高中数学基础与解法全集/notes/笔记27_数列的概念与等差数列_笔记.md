# 数列的概念与等差数列

## 数列的本质与图像

* **数列（sequence）**

    * > **定义**：按一定顺序排列的一组数。

    * 与集合的区别：集合里不能有两个一样的数，数列里完全可以有重复的数，出现重复项不影响它作为数列成立。

    * 真正被研究的是有规律的一列数，生活中的成绩记录、零花钱记录只是数列的原型。

* **数列的图像**

    * > **定义**：函数图像上自变量取自然数处的点，把对应的函数值一个一个分离出来摆成的离散点集。

    * 函数自变量可取遍 $x$ 轴上所有连续的点；数列的自变量 $n$ 只能取第一项、第二项、第三项……

    * > **易错点**：$n$ 的取值只能取正整数，零都取不到，没有"第 $0$ 项"这一说。

    * 以 $2^n$ 为例，数列的图像只是指数函数图像上的若干个点：

    ```text
           y
           │                    ●
           │                 ●
           │              ●
           │  y = 2^x
           │         ●
           │      ●
           │   ●
           │ ●
           └───────────────────────────► x
             0.5  1  2   2.33  2.5

       数列的图像 = 这条曲线在 x = 1, 2, 3, 4, ... 处的点，
                    一个一个单独拎出来摆着
    ```

## 通项公式与前 $n$ 项和

* **通项公式（general term formula）**

    * > **定义**：数列第 $n$ 项的表达式。

    * 等价说法：通项公式就是数列的解析式，与函数的解析式作用相同——$n$ 代几就得到第几项的数值。

    * 例：$2^1,2^2,2^3,2^4,\dots$ 的通项公式为 $2^n$，代入 $n=1$ 得第一项，代入 $n=2$ 得第二项。

* **前 $n$ 项和 $S_n$**

    * > **定义**：把 $a_1$ 到 $a_n$ 这一串数加起来得到的值，记作 $S_n$。

    * 因果链是固定的：通项公式给出每一项的值，每一项都知道了才能求前 $n$ 项和。

    * 例：$a_n=\dfrac{n(n+1)}{2}$ 时，$a_1=1$、$a_2=3$、$a_3=6$，故 $S_3=10$。

    * 例：$2,4,8,\dots$ 中 $S_3=2+4+8=14$。

* **整章的研究对象**

    * 只有两件事：通项 $a_n$ 和前 $n$ 项和 $S_n$。

    * 二者对特定数列可以相互转化——给通项求和，或给前 $n$ 项和求通项。

    * 主线只有一条：把题目里所有乱七八糟的项，全部化归成最少的几个基本量。

* **判定一个式子能否充当通项公式**

    * 规则：逐项代入核对，把已知项的下标代入候选式，看是否复现该项的值。

    * 例：首项为 $\sqrt3$ 的数列，候选式代入 $n=1$ 不得 $\sqrt3$ 的先排除，再用 $n=2$ 是否得 $\sqrt7$ 区分余下选项。

    * 例：前五项为 $2,0,2,0,2$ 的数列。"奇数取 $2$、偶数取 $0$"五项全对；$2\left|\sin\dfrac{n\pi}{2}\right|$ 逐项代入也得 $2,0,2,0,2$；$4\left|\cos\dfrac{n\pi}{3}\right|$ 在 $n=2$ 处算出 $4\left|\cos\dfrac{2\pi}{3}\right|=2$，与第二项 $0$ 冲突。

    * > **提示**：判断三角函数型选项时，与其硬背不如再画一遍单位圆，顺手把三角函数复习了。

## 递推公式与周期数列

* **递推公式（recursion formula）**

    * > **定义**：一个式子中同时含有第 $n$ 项、第 $n+1$ 项或第 $n-1$ 项的表达式。

    * 本质是数列的变化规律：掌握它就知道整个数列怎么变，并能由前几项一步步推到任意一项。

    * 读法：$a_{n+2}=a_{n+1}-a_n$ 表示连续三项中最后一项等于第二项减第一项。

    * 换元的类比：与 $f(x)=3x+2$ 一样，等号两侧的 $n$ 是同一个 $n$，要变一起变，可以代入不同的值；令 $n=1,2$ 同时给出 $a_3=a_2-a_1$。

    * 例：$a_1=3$，$a_2=6$，$a_{n+2}=a_{n+1}-a_n$。逐项推进得 $a_3=3$，$a_4=-3$，$a_5=-6$，$a_6=-3$，$a_7=3$，$a_8=6$，$a_9=3$，序列以 $6$ 为周期。$2026=6\times337+4$，取一个周期里第 $4$ 个值，故 $a_{2026}=-3$。

* **周期数列求前 $n$ 项和**

    * > **提示**：一旦发现周期，就不要一项一项硬加，用"完整周期数 $\times$ 周期和 $+$ 剩余项"这个套路两步完成。

    * 例：周期为 $1,\sqrt3,2$，周期和为 $3+\sqrt3$，$2024=3\times674+2$，故 $S_{2024}=674\times(3+\sqrt3)+1+\sqrt3=2023+675\sqrt3$。

* **和谐递进数列**

    * > **定义**：无穷数列满足 $a_p=a_q\Rightarrow a_{p+1}=a_{q+1}$，即相等的一对会牵出后面一整串相等。

    * 推法：一旦发现 $a_1=a_4$，即可推出 $a_2=a_5$；再由 $a_3=a_6$ 推出 $a_4=a_7$；由此 $a_7=a_4$、$a_8=a_5$、$a_9=a_3$，整个数列周期为 $3$。

    * 例：已知 $a_1=1$，$a_2=\sqrt3$，$a_4=1$，$a_8\cdot a_9=2\sqrt3$。由 $a_8=\sqrt3$ 与积得 $a_9=2$，又 $a_9=a_3$，故数列为 $1,\sqrt3,2$ 循环。

## 等差数列的定义

* **等差数列（arithmetic sequence）**

    * > **定义**：从第二项起，每一项与它前一项的差都等于同一个常数，这个数列叫等差数列，这个常数叫公差，通常记作 $d$；数列的第一项叫首项。

    * 定义式：$a_{n+1}-a_n=d$。

    * 例：$1,3,5,7,9$ 首项为 $1$、公差为 $2$；$2,5,8,11$ 首项为 $2$、公差为 $3$。

    * > **易错点**：公差定义在"后一项减前一项"上，是 $a_2-a_1$ 而不是 $a_1-a_2$，别减反了。

* **边界情形**

    * $d=0$：常数列 $2,2,2,\dots$ 是特殊的等差数列，公差就是零。

    * $d<0$：公差可以为负数，递减的数列同样是等差数列，不能一看到数值往下掉就判否。

    * 判定标准自始至终只有一条：后一项减前一项是不是同一个定值。

* **等差中项（arithmetic mean）**

    * > **定义**：三个数 $a,b,c$ 成等差数列时，中间那一项 $b$ 叫等差中项。

    * 结论：$a+c=2b$，中间项就是两侧项的平均值。例中 $2+8=10=2\times5$、$5+11=16=2\times8$。

    * 推导：由 $\begin{cases}a_{n+1}-a_n=d \\ a_n-a_{n-1}=d\end{cases}$ 两式相减，$d$ 消去，得 $a_{n+1}+a_{n-1}-2a_n=0$，即 $a_{n+1}+a_{n-1}=2a_n$。

    * > **注意**：相减时正负号别写错，移项前必须先把 $a_n$ 前的系数合并成 $-2a_n$。

* **唯一性**

    * 首项与公差两个量一旦确定，整个等差数列就被唯一确定。

    * 因此任何一道题的所有条件与所求，都可以转化成关于 $a_1$ 与 $d$ 的问题。

## 等差数列的通项公式

* **两种形式**

    * 以 $a_1$ 为基准：$a_n=a_1+(n-1)d$，下标与 $1$ 差几个就加几个 $d$，如 $a_7=a_1+6d$。

    * 以任意项 $a_m$ 为基准：$a_n=a_m+(n-m)d$，如 $a_9=a_2+7d=a_4+5d=a_{10}-d$。

    * 两者只差一个基准，第一式是第二式中 $m=1$ 的特例。

    * 方向判定：目标下标比起点大就加对应倍数的 $d$，比起点小就减。

    * > **提示**：挑一个合适的起点，往往比老实从 $a_1$ 算快得多。

* **换基准带来的直接收益**

    * 例：已知 $a_3+a_9=28$，求 $a_{13}-\dfrac12a_{20}$。以 $a_1$ 为基准得 $a_1+5d=14$，进而 $a_{13}-\frac{a_{20}}{2}=\frac{a_1+5d}{2}=7$。

    * 换基准：$a_1+5d$ 正是 $a_6$，条件等价于 $a_6=14$；以 $a_6$ 为基准时 $a_{13}=a_6+7d$、$a_{20}=a_6+14d$，$14d$ 被分母的 $2$ 约掉，一步得 $\frac{a_6}{2}=7$。

## 前 $n$ 项和与倒序相加

* **倒序相加**

    * 做法：把同一和写成正序与倒序两行，两行相加使每一对相配项都得到同一个定值，左边得 $2S$。

    ```text
        1  +  2  +  3  +  4  +  …  + 99  + 100   =  S
      100  + 99  + 98  + 97  +  …  +  2  +   1   =  S
      ───────────────────────────────────────────────────
      101 + 101 + 101 + 101 + …  + 101 + 101        =  2S
                      共 100 个 101
    ```

    * $1$ 到 $100$ 的和中共有 $100$ 个 $101$，故 $2S=100\times101$，$S=5050$。

* **通用公式的推出**

    * 把 $a_1+a_2+\cdots+a_n$ 与 $a_n+a_{n-1}+\cdots+a_1$ 两式相加，每一对首尾相配的和都等于 $a_1+a_n$，配对数恰为 $n$，得 $S_n=\dfrac{n(a_1+a_n)}{2}$。

    * 口诀：首项加末项，乘以项数，再除以二。$S_8$ 用 $\dfrac{8(a_1+a_8)}{2}$，$S_{1000}$ 用 $\dfrac{1000(a_1+a_{1000})}{2}$。

* **用通项消掉末项**

    * 把 $a_n=a_1+(n-1)d$ 代入并化简，得 $S_n=na_1+\dfrac{n(n-1)}{2}d$。

    * 这个公式长相难看但必须会：$S_8=8a_1+28d$，$S_{1000}=1000a_1+\dfrac{1000\times999}{2}d$。

    * 例：$a_1=3$，$d=2$，求 $S_6$：$S_6=6\times3+\dfrac{6\times5}{2}\times2=18+30=48$。

* **两式的选用**

    | 公式 | 形式 | 选用场合 |
    | :--- | :--- | :--- |
    | 求和第一式 | $S_n=\dfrac{n(a_1+a_n)}{2}$ | 式子对称美观，已知首项与末项时更简单 |
    | 求和第二式 | $S_n=na_1+\dfrac{n(n-1)}{2}d$ | 只要掌握 $a_1$ 与 $d$ 就能求任意前 $n$ 项和 |

## 全部转成 $a_1$ 与 $d$

* **执行流程**

    ```text
            题面给出的任意一条信息
                       |
            通项变形：a_m = a_1 + (m-1)d
            求和变形：S_n = n·a_1 + n(n-1)/2 · d
                       |
              未知量只剩 a_1 与 d
                       |
         两元一次方程组 / 拆出倍数关系 / 直接代入
                       |
                  题目所求
    ```

    * 做题第一步是数条件：两个独立条件（哪怕一个含 $a$ 一个含 $S$）配两个未知数走方程组；只有一个条件就把它翻译成 $a_1$ 与 $d$ 之间的倍数关系，一路代到底。

    * ⚠️ **易错点**：决定能不能暴力的是信息条数而不是形式，只有一个条件时必须换思路。

* **方程组型**

    * $a_3+a_4=7$，$a_2+a_5=5$，求 $S_{10}$：转化得 $2a_1+5d=7$、$4a_1+7d=5$，第一式乘 $2$ 后相减得 $3d=9$，$d=3$，$a_1=-4$，$S_{10}=10\times(-4)+45\times3=95$。

    * ⚠️ **易错点**：此题 $a_1$ 是负数，$10\times(-4)=-40$，最后一步别把符号丢了，也别下意识按正数算。

    * $a_4+a_5=24$，$S_6=48$，求公差：得 $2a_1+7d=24$ 与 $6a_1+15d=48$，二元一次方程组解出 $d=4$。

    * $S_9=81$，$a_2=3$，求 $a_{10}$：由 $9a_1+36d=81$ 得 $a_1+4d=9$，由 $a_1+d=3$，两式相减得 $d=2$、$a_1=1$，$a_{10}=a_1+9d=19$。

* **单条件型**

    * $a_2=3a_1$，求 $\dfrac{S_{10}}{S_5}$：$a_2=a_1+d=3a_1$ 给出 $d=2a_1$，于是 $S_{10}=10a_1+45d=100a_1$、$S_5=5a_1+10d=25a_1$，比值为 $4$。

    * $a_9=-a_1$，求 $\dfrac{S_9}{a_{10}}$：$a_9=a_1+8d$ 给出 $a_1=-d$，于是 $S_9=9a_1+36d=-27a_1$、$a_{10}=a_1+9d=-8a_1$，比值为 $\dfrac{27}{8}$。

* **选基准：让式子自己退化**

    * 前 $n$ 项和之间可以互相表示：$S_4=S_5-a_5$，$S_6=S_5+a_6$。

    * 据此 $S_4+S_6-2S_5=a_6-a_5=d$，所以"$d>0$"与"$S_4+S_6>2S_5$"互为充分必要条件；全转 $a_1$、$d$ 也得同一结果 $S_4+S_6-2S_5=\dfrac12d$。

    * 某个含 $S_5$ 的不等式组，每项都含 $S_5$，全减 $S_5$ 后退化成初中不等式组 $0$、$-a_5$、$a_6$；已知 $a_1=4$，代入 $a_5=a_1+4d$、$a_6=a_1+5d$ 得 $-4-4d\ge0\Rightarrow d\le-1$、$8+9d\le0\Rightarrow d\le-\dfrac89$，取更紧的一条得 $d\in\left(-\infty,-\dfrac89\right]$。

* **两条通法**

    * 通法一：不管给什么，全部转化成 $a_1$ 与 $d$，这是最不需要动脑也最保险的做法。

    * 通法二：自己挑一个基准量做，优先挑式子中下标挨得最近的那一项（如 $S_4$、$S_5$、$S_6$ 就以中间的 $S_5$ 为基准）。

## 五组二级结论

* **下标和相等则对应项之和相等**

    * $m+n=p+q$ 时有 $a_m+a_n=a_p+a_q$。

    * 蕴含两层条件：下标和相等是第一层，左右项数相等是第二层，两个条件缺一不可。

    * ⚠️ **易错点**：$a_1+a_3+a_8$（$1+3+8=12$）可换为 $a_2+a_4+a_6$，但不能换为 $3a_4$——后者是四项，项数不等。

    * 最常用形态：若干项下标成等差且项数为奇数时，它们的和等于"项数 $\times$ 中间那一项"。

    * 例：$a_2+a_8=10$ 即 $2a_5=10$，得 $a_5=5$，于是 $a_3+a_5+a_7=3a_5=15$。

    * 例：$a_4+a_6+a_8+a_{10}+a_{12}=90$，配对得 $2a_8+2a_8+a_8=5a_8=90$，$a_8=18$；求 $\frac{a_{10}}{a_{14}}$ 时以 $a_8$ 为起点写成 $\frac{a_8+2d}{a_8+6d}$，上下同时减掉 $\frac23$ 倍分母后 $d$ 全消，得 $\frac23a_8=12$。

    * 例：$3a_3+2a_8=25$ 共五项、下标和 $3\times3+8+8=25$，改写成 $5a_5$，得 $a_5=5$。

* **$S_n$ 是无常数项的二次函数**

    * $S_n=na_1+\dfrac{n(n-1)}{2}d=\dfrac{d}{2}n^2+\left(a_1-\dfrac{d}{2}\right)n$，常数项必为零。

    * 图象一定经过原点。

    * $d=0$ 时退化为直线，常数列 $2,2,2,\dots$ 的 $S_n=2n$ 就是一条直线。

    * ⚠️ **易错点**：判断"哪个不可能是 $S_n$ 的图象"时，"过原点"是死条件，"是不是曲线"是活的，应选不过原点的那项。

* **$\left\{\dfrac{S_n}{n}\right\}$ 是等差数列**

    * $\dfrac{S_n}{n}=\dfrac{d}{2}n+\left(a_1-\dfrac{d}{2}\right)$ 是关于 $n$ 的一次函数，故 $\left\{\dfrac{S_n}{n}\right\}$ 是等差数列，公差为 $\dfrac{d}{2}$。

    * 判定一个数列是等差的三条路径：证后一项减前一项恒为定值；求出通项发现是关于 $n$ 的一次函数；证 $a_{n+1}+a_{n-1}=2a_n$（较少用）。

    * 例：$a_1=20$，$\dfrac{S_{n+1}}{n+1}-\dfrac{S_n}{n}=-\dfrac32$，求 $a_{20}$。设 $b_n=\dfrac{S_n}{n}$，则 $\dfrac{d}{2}=-\dfrac32$ 得 $d=-3$，$a_{20}=a_1+19d=20+19\times(-3)=-37$。

    * 不用这条结论也做得出来：题给了 $a_1$，$S_{n+1}$ 与 $S_n$ 都能用 $a_1$ 和 $d$ 表示，只是计算量大一些。

* **分组求和构成的数列仍是等差数列**

    * $S_n$，$S_{2n}-S_n$，$S_{3n}-S_{2n}$，… 循环下去构成公差为 $n^2d$ 的等差数列。

    * 直观来源：$a_3$ 比 $a_1$ 大 $2d$、$a_4$ 比 $a_2$ 也大 $2d$，故 $a_3+a_4$ 比 $a_1+a_2$ 大 $4d$；改成三项一组时每组比前一组大 $9d$；规律即"组数 $\times$ 组内项数"个 $d$。

    * > **提示**：这条结论的识别条件非常苛刻——看到 $S_2,S_4,S_6,S_8$、或 $S_3,S_6,S_9$、或 $S_4,S_8,S_{12}$ 就大胆用。

    * 考题常给无减号形式：给 $S_3:S_6=1:3$，设 $S_3=k$ 则 $S_6=3k$，新数列四项为 $k,2k,3k,4k$，故 $S_9=6k$、$S_{12}=10k$。

* **奇数下标的前 $n$ 项和**

    * $S_{2n-1}=(2n-1)a_n$，即 $S_5=5a_3$、$S_9=9a_5$、$S_{19}=19a_{10}$，下标与末项下标的换算是"下标加 $1$ 再除以 $2$"。

    * 推导：$S_5=\dfrac{5(a_1+a_5)}{2}$，而 $a_1+a_5=2a_3$ 与分母的 $2$ 约掉，得 $5a_3$。

    * 用途：$a_n$ 总是比 $S_n$ 好求，这条式子把求和压缩成求一个单项，如 $S_{79}=79a_{40}$。

    * 反向用法：$a_n=\dfrac{S_{2n-1}}{2n-1}$，等差数列的通项也能化回前 $n$ 项和。

    * 例：$a_1+a_3+a_5=9=3a_3$，得 $a_3=3$，$S_5=5a_3=15$。

    * 例：$a_2+a_6=a_3+a_5=2a_4=10$ 得 $a_4=5$；再由 $a_8=a_4+4d=9$ 得 $d=1$、$a_1=4$，于是 $a_3=a_4-d=4$。

    * 双数列：已知 $a_n:b_n$ 求 $S_{11}:T_{11}$，因 $11$ 为奇数，$S_{11}=11a_6$、$T_{11}=11b_6$，故 $S_{11}:T_{11}=a_6:b_6$；反向已知 $S_n:T_n$ 求 $a_7:b_7$，代入 $a_7=\dfrac{S_{13}}{13}$、$b_7=\dfrac{T_{13}}{13}$，得 $a_7:b_7=S_{13}:T_{13}$。

    * > **提示**：把所有 $S$ 换成奇数下标、所有 $a$ 换成 $a_{\frac{2n-1}{2}}$，一次整体代换就够了，不必逐项硬转。

## 数列的变形

* **倒数成等差：裂项相消**

    * 条件：$\{a_n\}$ 各项为正，且 $\left\{\dfrac{1}{a_n}\right\}$ 是公差为 $3$ 的等差数列。

    * 核心等式：$a_na_{n+1}=\dfrac13\left(\dfrac1{a_n}-\dfrac1{a_{n+1}}\right)$，即相邻项相乘等于 $\dfrac13$ 倍的相邻项倒数之差。

    * 连加时每一项都能拆成倒数之差，中间逐项约掉，只剩首尾：

    ```text
      a1a2 + a2a3 + a3a4 + ... + a(n-1)an
                        |
           每一项拆成 1/3 × (该项两项的倒数之差)
                        |
      = 1/3 × [ (1/a1 − 1/a2) + (1/a2 − 1/a3) + (1/a3 − 1/a4) + ... ]
                        |
           −1/a2 与 +1/a2 约掉，−1/a3 与 +1/a3 约掉，……
                        |
           中间全部抵消，只剩首尾：1/a1 − 1/an
    ```

    * > **提示**：看到"倒数成等差"与"相邻项乘积"这两个信号，立刻想到这条裂项链。

* **三角换元与齐次化**

    * 适用信号：出现 $x^2+y^2=$ 定值，且各变量无法拆成关于 $a_1$、$d$ 的单值关系。

    * 例：$a_1^2+a_3^2=2$ 且 $a_1\ge1$。若硬转成 $2a_1^2+4d^2+4a_1d=2$，这是二次方程，解不出 $a_1$ 或 $d$，必须换路。

    * 换元：令 $a_1=\sqrt2\cos\alpha$、$a_3=\sqrt2\sin\alpha$；再由等差中项得 $a_2=\dfrac{a_1+a_3}{2}=\dfrac{\sqrt2}{2}(\cos\alpha+\sin\alpha)$。

    * 齐次化：目标式化为 $\dfrac{2\sin\alpha+\cos\alpha}{2\cos\alpha+\sin\alpha}$，分子分母同除 $\cos\alpha$，再设 $x=\tan\alpha+2$，得 $f(x)=\dfrac{2x-3}{x}=2-\dfrac3x$，是一个反比例函数。

    * 定范围：由 $a_1\ge1$ 得 $\cos\alpha\ge\dfrac{\sqrt2}{2}$，用单位圆定出临界点在 $\pm\dfrac\pi4$，在 $[0,2\pi]$ 内取 $\alpha\in\left[0,\dfrac\pi4\right]$，故 $\tan\alpha\in[0,1]$，$x\in[1,3]$。

    * ⚠️ **易错点**：求值域之前必须先求定义域，$\alpha$ 的范围不定，$x$ 的范围就不定，后面的单调性判断全是空中楼阁。

    * 值域：$f(x)$ 在 $x>0$ 上单调递减，代端点得 $f(1)=-1$、$f(3)=1$，值域为 $[-1,1]$。

## 题型总览

* **暴力计算**：把所有问题全部转化成 $a_1$ 与 $d$，适用于所有简单题，也是最常考、最不需要动脑的一类。

* **二级结论**：熟练使用下标和相等、$S_n$ 是无常数项二次函数、$\frac{S_n}{n}$ 是等差数列、分组求和、奇数下标 $S_{2n-1}$ 这五条，以减少计算、快速得到答案。

* **数列的变形**：倒数、三角换元、齐次化、裂项相消，常见于数列压轴题；三角换元那道题套的是数列外壳，真正考的是换元、齐次化与函数求值域。

* **共同主线**：永远把式子往"能识别"的方向推——$a_n$ 与 $S_n$ 互推、奇数下标的 $S$ 化成单项的倍数、下标和相等凑成对称，凡是能"凑"的地方都凑成基本量；公式不多，真正值钱的是"往哪凑"的判断力。
