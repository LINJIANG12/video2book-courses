# 统计与概率必修

## 数据的来源与抽样方法

* **全面调查（普查）与抽样调查**

    * > **定义**：普查是把想研究的对象每一个都研究一遍；抽样调查只抽其中一部分研究。

    * | | 全面调查 | 抽样调查 |
      | :--- | :--- | :--- |
      | 系统性与全面性 | 每个都研究，比较系统、比较全面 | 只看了一部分，不够全面 |
      | 代价 | 调查对象多，费时、费力、费钱 | 省时、省力、又省钱 |

    * 总体数目很小（如检查班上五名同学的作业）时优先普查。
    * 涉及安全底线的事情（航天器零部件检查）必须普查，一个都不能靠抽。
    * 研究对象庞大而需求只是「大致了解」（如五万名学生的近视比例）时用抽样调查。
    * 对象本身带有破坏性、抽样即毁掉（20 枚战略级导弹测杀伤力）时只能抽样。

* **总体、个体、样本与样本容量**

    * > **定义**：总体是研究对象的全体，个体是每一个研究对象，样本是实际抽出的那一部分，样本容量是样本中个体的个数。

    * 四个词前面必须加上你要研究的那个量：调查运动员的年龄时，总体是 1000 名运动员的年龄，个体是每名运动员的年龄，样本是抽出的 100 名运动员的年龄，样本容量是 100。

    * > **易错点**：写总体、个体、样本时只写研究对象本身（写成「这 1000 名运动员」）就错了，主语必须是研究对象的那个量。

* **简单随机抽样**

    * > **定义**：简单随机抽样使每个个体被抽中的机会均等。

    * 抽签法：编号写在形状相同的小纸片或小球上，全部放入不透明盒子搅拌后不放回地逐个抽取；编号几即第几号个体入样本。
    * 随机数法：编号后用随机数工具（电脑）直接产生规定范围内的随机整数，产生哪个数对应个体入样本。
    * 抽签法适合总量不大的情形，人数多时费时费力，宜改用随机数法。

* **分层抽样**

    * > **定义**：分层抽样就是按比例抽样——总体由特征差距明显的几部分组成且各部分比例不同时，各部分按同样比例抽取。

    * 某校 1200 名学生中抽 60 人，高一、高二、高三人数比为 1:2:3，则三段分别抽 10、20、30 人。
    * 分配步骤固定：先求比值之和，再算「总人数 ÷ 比值之和 = 一份对应的人数」，最后各比值乘这个一份。
    * 四个年级人数比 4:5:5:6、分层抽 300 人时：比值和 20，每份 $300\div20=15$，一年级抽 $4\times15=60$ 人。

    * > **易错点**：分层分配最常错在「忘了先求一份是多少」；唯一钥匙是总人数除以比值之和。

* **用样本估计总体**

    * > **定义**：抽样之后用样本的特征去估计总体的特征；样本中某类占比多大，就估计总体中同类也占相近比例。

    * 《九章算术》粟米题：抽 254 粒有甲骨 28 粒，问 1534 粒中有多少甲骨，$1534\times\dfrac{28}{254}\approx169$。
    * 这条规律同时是估计全市某特征人数的依据：先算出样本中该特征的频率，再乘总体规模。

## 描述统计量：集中趋势与离散程度

* **平均数**

    * > **定义**：全部数据求和再除以数据个数，表示整体平均水平，记作 $\bar{x}$。

    * 例：0、1.2、1.5、3、3、9 六个数，平均数为 $2.95$。
    * 用求和符号写作 $\bar{x}=\dfrac{x_1+x_2+\cdots+x_n}{n}=\dfrac{1}{n}\sum_{i=1}^{N}x_i$。

* **众数**

    * > **定义**：样本中出现次数最多的那个数据。

    * 例：0、1.2、1.5、3、3、9 中 3 出现两回，众数为 3。

* **中位数**

    * > **定义**：把数据从小到大（或从大到小）排列后处于最中间位置的数。

    * 数据个数为奇数时取最中间的一个，为偶数时取中间两个数的平均值。
    * 设共 $K$ 个数：$K$ 偶时取第 $\frac{K}{2}$ 个与第 $\frac{K}{2}+1$ 个的平均值；$K$ 奇时取第 $\frac{K+1}{2}$ 个。
    * 例：六个数取 1.5 与 3 的平均值得 2.25；七个数 1、3、9、9、12、13、15 的中位数为 9。

* **极差**

    * > **定义**：最大数据减去最小数据，是最粗的离散指标，只看头尾，中间信息全丢。

    * 例：0、1.2、1.5、3、3、9 的极差为 $9-0=9$。

* **方差**

    * > **定义**：每个数据减去平均数后平方，求和再除以数据个数，记作 $s^2$。

    * $s^2=\dfrac{1}{n}\sum_{i=1}^{N}(x_i-\bar{x})^2$。
    * 例：平均数为 4 的六个数据，按定义算得平方和 26，方差 $26\div6=\dfrac{13}{3}$。

* **标准差**

    * > **定义**：方差开平方，衡量数据波动幅度。

    * 离散程度的度量工具只有三个：极差、方差、标准差。

* **读图判断统计量的技巧**

    * 中位数只需数出排序后的第几个与第几个，无须算出全部数据。
    * 平均数与分界点比较时不必精算：若绝大多数点落在分界点同一侧，平均数必被拉到该侧。
    * 标准差大小看点的分散程度：点越集中标准差越小，极值越远标准差越大。
    * 例：讲座后正确率的点集中于高位，标准差小、极差 $100-80=20\%$；讲座前点分散，极差 $95-60=35\%$。

## 数据的线性变换

* **每个数都乘 a 再加 b**

    * > **定义**：把原数据组中每个数都变为 $ax_i+b$，得到新数据组。

    * 新平均数 $\bar{x}'=a\bar{x}+b$。
    * 新方差 $s'^2=a^2s^2$，与所加的常数 $b$ 无关。
    * 新标准差 $s'=|a|s$，必须取绝对值，因为标准差恒为正。
    * 例：平均值为 5 的组每个数乘 2 加 1，新平均值为 $5\times2+1=11$；方差为 0.01 的组每个数乘 10，新方差为 $100\times0.01=1$。

* **方差的推导机理**

    * 展开 $\dfrac{1}{n}\sum_{i=1}^{N}\bigl[(ax_i+b)-(a\bar{x}+b)\bigr]^2$。
    * 两端的 $b$ 相互抵消，每项化为 $a(x_i-\bar{x})$。
    * 每项都含 $a$ 且被平方，提出 $a^2$ 后括号内正是原方差，得 $a^2s^2$。

    * > **易错点**：新方差不能写成 $a^2s^2+b$；新标准差不能写成 $as$（$a$ 为负时结果为负）。

## 求和符号与方差的两个公式

* **求和符号 Σ**

    * > **定义**：$\sum_{i=1}^{N} x_i$ 表示把 $i$ 从 1 取到 $N$，把底下的式子逐项加起来。

    ```text
                    N
                    Σ        ← 大写希腊字母 Sigma，"求和"
           从这里 ↓  ↓ 到这里
                  i = 1

       读作：把 i 从 1 一直取到 N，把底下的 x(i) 一项一项加起来
    ```

    * 符号的三个部分：$\Sigma$ 表示「加起来」，下限 $i=1$ 是 $i$ 的最小取值，上限 $N$ 是 $i$ 的最大取值。
    * 变量字母可换：$\sum_{n=1}^{100}\dfrac{x_n}{n}$ 与 $\sum_{i=1}^{N}p_i$ 同理，只是习惯用 $i$。
    * 展开示例：$\sum_{i=1}^{N}p_i=p_1+p_2+\cdots+p_N$；$\sum_{i=1}^{N}y_i^3=y_1^3+y_2^3+\cdots+y_N^3$。
    * 反向压缩 $x+x^2+\cdots+x^n$：找出在变的量（指数）设成新字母，底数照抄，写成 $\sum_{i=1}^{N}x^i$。

    * > **易错点**：下限是 0 还是 1 决定第一项是什么，看求和符号第一步永远是先看上下限。

    * 设新字母时必须避开题中已用的字母，$n$ 已被占用就不能再用 $n$。

* **求和号的两个运算技巧**

    * > **定义**：$\sum_{i=1}^{n}(a_i+b_i)=\sum_{i=1}^{n}a_i+\sum_{i=1}^{n}b_i$，对加减的求和可拆开；$\sum_{i=1}^{n}m a_i=m\sum_{i=1}^{n}a_i$，常数可以提出求和号。

    * 拆项的依据是加法的交换律与结合律，减号同理。
    * 提系数的判据是「谁在变」：下标 $i$ 变化时，其余如 $m$、$2$、$\bar{x}$ 都不动，可当系数提出。
    * 求和号内不含 $i$ 的项（如 $\bar{x}^{\,2}$）相当于 $N$ 个同样的数相加，即 $N\bar{x}^{\,2}$。

* **方差的第二个公式**

    * > **定义**：$s^2=\dfrac{1}{n}\sum_{i=1}^{N}x_i^2-\bar{x}^{\,2}$，其中第一项恰是各数据平方的平均数。

    * 两个公式等价的推导：展开完全平方得 $x_i^2-2\bar{x}x_i+\bar{x}^{\,2}$，拆成三个求和，再依次化为 $\sum x_i^2$、$2\bar{x}\cdot N\bar{x}$、$N\bar{x}^{\,2}$，与 $\frac1n$ 约分后系数合并即得。
    * 选用判据：平均数好求且逐项减平均数好算时用第一个公式；$x_i$ 与平均数分开独立计算时用第二个公式。

* **知二求一**

    * > **定义**：方差、平方和、平均值三者由等式连接，知其中任意两个即可求第三个。

    * $x_1,x_2,x_3$ 平均数 2、方差 1，则 $\dfrac{1}{3}(x_1^2+x_2^2+x_3^2)=1+4=5$。
    * 去掉一部分数据时的通法：先用 $\text{平方和}=n\bigl(s^2+\bar{x}^{\,2}\bigr)$ 求出整体与被去掉部分的平方和，相减得剩余平方和，再配剩余平均值回代公式。
    * 容量 10、平均数 6、方差 2，减去平均数 5、方差 1 的 5 个数据：整体平方和 $10\times(2+36)=380$，去掉部分 $5\times(1+25)=130$，剩余 $250$；剩余平均数 $\dfrac{6\times10-5\times5}{5}=7$；剩余方差 $\dfrac{250}{5}-49=1$。
    * 容量 10、平均数 15、方差 3，去掉一个 15：平方和 $2280-225=2055$，剩余 9 个数平均数仍为 15，新方差 $\dfrac{2055}{9}-225\approx3.33$。

    * > **易错点**：去掉一个正好等于平均值的数，平均值不变、方差变大；这类只比大小的题用直觉即可判断。

    * 整体去掉两端的特例：$x_1<\cdots<x_6$ 去掉最小值与最大值后，中位数（$x_3$、$x_4$ 的平均）不变，标准差变小；极差可不变（存在并列极值时），故「极差不大于原极差」成立。

## 两组数据的合并

* **不等量的分层合并**

    * > **定义**：左组 $m$ 个数（平均 $\bar{x}$、方差 $s_x^2$）、右组 $n$ 个数（平均 $\bar{y}$、方差 $s_y^2$）合成整体，整体平均 $\bar{z}$。

    * $\bar{z}=\dfrac{m\bar{x}+n\bar{y}}{m+n}$，本质是按人数占比的加权平均。
    * $s^2=\dfrac{m}{m+n}s_x^2+\dfrac{n}{m+n}s_y^2+\dfrac{m}{m+n}(\bar{z}-\bar{x})^2+\dfrac{n}{m+n}(\bar{z}-\bar{y})^2$。
    * 记忆三件事：加权分数都是人数占比；平均数乘平均数、方差乘方差；还要补上两个「平均值之差」的平方项。
    * 验证：男生 50 人（平均 54、方差 20）与女生 40 人（平均 45、方差 11）合成，整体平均 $\dfrac{54\times50+45\times40}{90}=50$，整体方差 $\dfrac{228240}{90}-50^2=36$。

* **等量合并**

    * > **定义**：两组各 $n$ 个数（平均 $\bar{x}$、$\bar{y}$，标准差 $s_1$、$s_2$）合成一组。

    * 新平均数 $\bar{z}=\dfrac{\bar{x}+\bar{y}}{2}$。
    * 新标准差 $s=\sqrt{\dfrac{s_1^2+s_2^2}{2}+\dfrac{(\bar{x}-\bar{y})^2}{4}}$。

* **配对差数列**

    * 配对实验中取差 $z_i=x_i-y_i$，则 $\bar{z}$ 为两组平均值之差；判定式 $\bar{z}\ge 2s$ 成立即认为处理工艺有显著提高。
    * 例：10 次配对实验 $z_i=x_i-y_i$ 得 $\bar{z}=11$、$s=\sqrt{6.1}\approx2.47$，$2s\approx4.94<11$，故甲工艺的伸缩率相对乙有显著提高。

    * > **提示**：合并公式能推出来就别硬背；先用第二个方差公式一步步算通，再把公式当提速工具。

## 频率分布直方图：从分组到读图

* **分组、频数与频率**

    * > **定义**：把取值相近的数据分成一组，凑成一根柱来画，得到频率分布直方图；落在某区间内的数据个数叫频数，频数占总数之比叫频率。

    * 数据量大到无法逐个画柱时必须分组；五个人画柱状图即可，画不下五百个人才需要直方图。
    * 柱状图与折线图看增长与趋势、扇形图看各部分占整体的比例，频率分布直方图看分布。
    * 例：500 名学生的游戏时长按组距 2 分六组，各组频率 $0.114,\ 0.28,\ 0.27,\ 0.20,\ 0.10,\ 0.036$。
    * 所有区间频率之和恒等于 1，这是全章读图的地基。

* **纵轴是「频率除以组距」**

    * > **定义**：横轴是各组区间，纵轴是频率与组距之比，柱宽等于组距。

    * 条形图是每个数据各自一根柱；频率分布直方图是同组数据合成一根柱。
    * 例：组距为 2 时，$6\sim8$ 组频率 0.2，纵坐标为 $\dfrac{0.2}{2}=0.1$。
    * 组距没有固定值，由取值范围与柱子数量的美观程度决定；组距一变纵轴读数随之改变，但「哪根柱更高」的结论不变。

    ```text
       纵轴 = 频率 / 组距
      0.16 ┤
      0.14 ┤        ┌────────┐   ┌────────┐
      0.12 ┤        │        │   │        │
      0.10 ┤        │        │   │        │   ┌────────┐
      0.08 ┤  ┌─────┤        │   │        │   │        │
      0.06 ┤  │     │        │   │        │   │        │
      0.04 ┤  │     │        │   │        │   │        │
      0.02 ┤  │     │        │   │        │   │        │   ┌────────┐   ┌────────┐
      0.00 ┼──┴─────┴────────┴───┴────────┴───┴────────┴───┴────────┴───┴────────┴──→ 时长
             0~2      2~4      4~6      6~8      8~10     10~12
             频数 57  140   135       100    50      18
             频率 .114 .28   .27      .20   .10     .036
    ```

* **矩形面积等于频率**

    * > **定义**：每个小矩形的面积（柱宽 × 柱高）恰等于该组的频率，所有小矩形面积之和等于 1。

    * 面积 $=\dfrac{\text{频率}}{\text{组距}}\times\text{组距}=\text{频率}$，除以组距再乘回组距恰好抵消。
    * 例：$2\sim4$ 组柱高 0.14、宽 2，面积 $0.28$，正是该组频率。
    * 用总面积等于 1 可解未知柱：其余各柱面积合计 0.3，含两个未知柱的两组每组面积 $\dfrac{A}{2}$、合计 $A$，则 $0.3+A=1$，得 $A=0.7$（两组频率各 0.35）。

* **从图反查人数**

    * 逆向链条固定：纵坐标 × 组距 = 频率，频率 × 总人数 = 人数。
    * 例：组距为 4、柱高 0.05 的组，频率 $4\times0.05=0.2$，400 个体中人数 $400\times0.2=80$。
    * 某一组的纵坐标没给时，用 $1-$ 其余各组频率之和求它；组数多时从数据少的一侧倒着累加更快。

* **图是有损的**

    * 柱状图无损，能从图上读出每个数据的具体值；频率分布直方图只保留「每组有多少个」，组内原始数据被过滤掉。
    * 因此精确的平均数、众数、中位数、标准差、方差无法从图上直接算，只能估计。

## 由直方图估计统计量

* **估平均数**

    * > **定义**：假设每组数据都落在区间中点上，用中点乘该组频率再求和，得到平均数的估计值。

    * 例：各组中点为 1、3、5、7、9、11，频率依次 $0.114,\ 0.28,\ 0.27,\ 0.20,\ 0.10,\ 0.036$，估计值 $\bar{x}\approx1\times0.114+3\times0.28+5\times0.27+7\times0.20+9\times0.10+11\times0.036\approx5$。

    * > **易错点**：代表值必须取中点，取区间端点会把估计值系统性推偏。

* **估中位数**

    * > **定义**：取一条竖线使左右两侧面积各占 0.5，该竖线的横坐标即中位数的估计值。

    * 判定竖线落在哪一组：自左向右累加各柱面积，累计值首次跨过 0.5 的那一组即为所落组。
    * 补最后一段：所需面积差 $\div$ 该柱高度 = 该段横向宽度，加到该组左端点上。
    * 例：前两组面积 $0.14+0.28=0.394$，差 $0.5-0.394=0.106$，除以第三组柱高 0.135 得宽约 0.785，横坐标为 $4+0.785=4.785$。
    * 例：左侧各块累加得 0.48，距 0.5 差 0.02，在下一柱内取宽 $0.02\div0.5=0.04$，中位数为 $2+0.04=2.04$ 吨。

    ```text
              累计频率 = 0.5
       0.5 ────────────────────┬─────────────────────────
                               │
          ┌─────┬────────┬─────┼─────┬───────┬───────┐
          │     │        │     │     │       │       │
    ──────┴─────┴────────┴─────┴─────┴───────┴───────┴────→ 时长
         0~2    2~4     4~6    6~8   8~10    10~12
          .14    .28    | .27 |    .20    .10     .036
          └─ .394 ─┘   ↑
                      0.394 + (0.5-0.394)/0.135 = 4 + 0.785 = 4.785
    ```

* **估百分位数**

    * > **定义**：第 $p$ 分位数对应使左侧面积为 $p$、右侧面积为 $1-p$ 的那条竖线的横坐标。

    * 累加方向选面积短的一侧，再用「面积差 ÷ 该柱高度」补最后一段。
    * 例：估第 80% 分位数时从右往左累加得 $0.06+0.06+0.06=0.12$，距 0.2 差 0.08，该柱高 0.3，段长 $\dfrac{0.08}{0.3}=\dfrac{4}{15}$，横坐标为 $3-\dfrac{4}{15}=\dfrac{41}{15}$。

* **平均数与中位数的位置关系**

    * 分布完全对称时，平均数估计值与中位数估计值重合。
    * 分布偏向一侧、有小尾巴时，平均数离小尾巴更近：小尾巴在左则平均数在左、中位数在右；小尾巴在右则相反。
    * 机理：平均值更容易受少数极端值影响；工资 5000、6000、7000、8000、9000 的中位数与平均数都是 7000，其中 9000 改成 9 万后平均数大涨而中位数不动。

## 百分位数的计算规则

* **由排序数据求第 $p$ 分位数**

    * > **定义**：数据从小到大排好后，算 $n\times p\%$，若为整数 $i$ 取第 $i$ 个与第 $i+1$ 个数的平均值，若不是整数取比它大的最近整数所对应的那个数。

    * 例：8 个已排序数据求第 25% 分位数，$8\times25\%=2$ 为整数，取第 2、3 项的平均值（不是第 2 项）。
    * 例：求第 80% 分位数，$8\times80\%=6.4$ 非整数，取第 7 个数。
    * 例：求第 30% 分位数，$8\times30\%=2.4$ 非整数，取第 3 个数。
    * 求第 50% 分位数，$8\times50\%=4$ 为整数，取第 4、5 项的平均值，这就是中位数。
    * 常用名称：50% 分位数称中位数，25% 分位数称第一四分位数（下四分位数），75% 分位数称第三四分位数（上四分位数）。

    * > **易错点**：这套规则的前提是数据已从小到大排好；没排就数必错。先排列，再数。

## 概率的基本概念与古典概型

* **随机试验、样本空间与样本点**

    * > **定义**：观察随机事件发生结果的过程叫随机试验；随机事件可能发生的所有情况构成的集合叫样本空间（记 $\Omega$），其中每一个可能情况叫样本点。

    * 样本空间与样本点就是集合与元素的关系。
    * 抛两次硬币共 $2\times2=4$ 种；抛三次共 8 种，靠把那一次正（或那一次反）出现的位置拆开单独列得到。
    * 条件说不清时按位置拆，是反复要用的基本动作。

    ```text
    第一次\第二次      正        反
            正      正正      正反
            反      反正      反反
    ```

    ```text
    正正正   正反正   正正反   反正正
    反正反   正反反   反反正   反反反
    ```

* **古典概型**

    * > **定义**：$P(A)=\dfrac{\text{目标情况数}}{\text{所有情况数}}$，分母是样本空间内所有可能情况的数量，分子是目标事件发生的情况数量。

    * 使用前提一：样本空间里的点能数得过来，不是无限大。
    * 使用前提二：每一个样本点发生的可能性相等。
    * 硬币不均匀且未告知正反面概率时，古典概型算不出结果。
    * 例：硬币抛三次至少出现两次反面，分母 8、分子 4，概率 $\dfrac12$。

    * > **易错点**：样本空间的元素必须等可能。两次掷骰子的「点数和」是由多次结果汇总出的量，不是样本点；「和是 2」只出现一次而「和是 3」出现两次，不能拿和的取值范围当样本空间。

* **数情况的三种方法**

    * 连线法：从若干件东西中取两件，手法是连线条，分母为 $4+3+2+1=10$。
    * 表格法：掷骰子、先后分两次抽取、两个集合中分别取数，画二维表格最直观。
    * 枚举法：两种都用不了时把情况逐条列出（如硬币抛三次）。

    * 五件产品含两件次品，任取两件恰有一件次品：分母 10，与 $D$ 连的有 3 种、与 $E$ 连的有 3 种，$DE$ 是两件次品不计，概率 $\dfrac{6}{10}=0.6$。
    * 2、3、5、6 中任取两个不同数字，乘积被 3 整除：6 种中只有 $2\times5$ 不行，概率 $\dfrac56$。
    * 1~5 中任取两个，两数之和为偶数：偶加偶 1 种 + 奇加奇 3 种共 4 种，概率 $\dfrac4{10}=\dfrac25$。
    * A、B、C 三人排队，A 先于 B 通过：6 种排列中满足的有 3 种，概率 $\dfrac36=\dfrac12$。
    * 140 名教职员工中 40 人 35 岁以上，抽一人 35 岁以下：$\dfrac{140-40}{140}=\dfrac57$。
    * 50 本书中取到英文书概率为 $\dfrac25$，设中文书 $X$ 本，则 $\dfrac{50-X}{50}=\dfrac25$，得 30 本。

* **骰子：分两次就列表格**

    * 均匀正方体骰子先后抛两次，所有情况 $6\times6=36$ 种。

    ```text
    第一次\第二次   1    2    3    4    5    6
          1       2    3    4    5    6    7
          2       3    4    5    6    7    8
          3       4    5    6    7    8    9
          4       5    6    7    8    9   10
          5       6    7    8    9   10   11
          6       7    8    9   10   11   12
    ```

    * 点数和是 5 的组合共 4 种，概率 $\dfrac4{36}=\dfrac19$。
    * 点数和的分布为 $1,2,3,4,5,6,5,4,3,2,1$（对应和 2~12）。
    * 点数和不超过 5 为 $\dfrac{10}{36}$，大于 5 为 $\dfrac{36-10}{36}=\dfrac{26}{36}$，为偶数为 $\dfrac{18}{36}$，故 $P_2>P_3>P_1$。

* **有放回抽取**

    * > **定义**：取出一个后放回再取，前后两次互不影响、相互独立，每次都从同样的对象中取，故分母是各次取值数的乘积。

    * 五张卡片抽一张放回再抽一张，分母 $5\times5=25$，第一次大于第二次的是上三角 $4+3+2+1=10$ 种，概率 $\dfrac{10}{25}=0.4$。
    * 从 $\{1,2,3,4,5\}$ 取 $A$、从 $\{1,2,3\}$ 取 $B$，$B>A$ 的概率：分母 $5\times3=15$，满足条件 3 种，概率 $\dfrac3{15}=\dfrac15$。

    * > **结论**：题目里出现「先后」「放回」「分先后」就要想到二维表格；表格分上三角、对角线（两次相等）、下三角三档。

* **多事件之间的关系**

    * 韦恩图：外框表示样本空间 $\Omega$，圆圈表示事件，重叠部分表示 $A\cap B$。

    ```text
            全集 Ω
       ┌──────────────────┐
       │    ┌────┐        │
       │    │ A  │        │
       │  ┌─┼──┐─┼──┐     │
       │  │ │ A∩B │ │    │
       │  └─┼──┴─┼──┘     │
       │    │ B  │        │
       │    └────┘        │
       └──────────────────┘
    ```

    * > **定义**：$P(AB)$ 表示 $A$ 与 $B$ 同时发生（交事件，也叫积事件）；$P(A+B)$ 表示 $A$ 或 $B$ 发生（并事件，也叫和事件）。

    * > **结论**：两事件既不能同时发生、概率之和又等于 1 时互为对立事件；互斥只要求无交集，故互斥不一定对立，对立一定互斥。

    * 对立事件的补事件记为 $\bar A$（非 $A$、$A$ 的补集），满足 $P(A)+P(\bar{A})=1$，即 $P(\bar{A})=1-P(A)$。
    * 求某事件概率困难时改求其反面，两者相加为 1。

    ```text
            全集 Ω
       +--------------------+
       |    +-------+        |
       |    |   A   |  ##### |
       |    +-------+  ##### |   ##### 即 A 的补集
       +--------------------+
    ```

* **互斥时的加法**

    * > **定义**：$A$、$B$ 互斥时，$P(A+B)=P(A)+P(B)$。

    * 例：52 张牌中抽一张，$A$ 为红桃 $K$、$B$ 为黑桃，两事件互斥，$P(A\cup B)=\dfrac1{52}+\dfrac{13}{52}=\dfrac7{26}$。
    * 例：甲乙下棋，和棋概率 $\dfrac12$、甲胜概率 $\dfrac13$，甲不输即甲胜或和棋，两事件互斥，$P=\dfrac13+\dfrac12=\dfrac56$。
    * 例：$A$、$B$、$C$ 两两互斥，$P(A)=\dfrac15$、$P(C)=\dfrac13$、$P(A\cup B)=\dfrac8{15}$，则 $P(B)=\dfrac8{15}-\dfrac15=\dfrac13$，$P(B\cup C)=\dfrac23$。

    * > **注意**：加法公式只在互斥时成立，用之前必须先判断两事件是否互斥。

## 事件的独立性

* **独立性的定义**

    * > **定义**：对任意两个事件 $A$、$B$，若 $P(AB)=P(A)\cdot P(B)$ 成立，则称 $A$ 与 $B$ 相互独立；等式不成立则不独立。

    * 直觉上可理解为两件事互不影响；形式上完全由该等式判定。
    * 反例：$P(A)=\dfrac12$、$P(B)=\dfrac13$ 且 $A$、$B$ 互斥时 $P(AB)=0\ne\dfrac16$。
    * 独立是无数种情境里较特殊的一种，绝大多数情境并不独立。

    * > **易错点**：凡是要求 $P(AB)$，第一步不是算而是在情境中读懂「$A$ 与 $B$ 同时发生」到底是什么，这一步偷懒后面全错。

* **独立性的乘法用法**

    * 两件独立事件同时发生，概率直接相乘：两枚硬币 $P(A)=P(B)=\dfrac12$，$P(AB)=\dfrac14$。
    * 连做 $n$ 次且每次独立：$n$ 局连赢概率为 $p^n$，如连赢三局 $0.7^3$、连赢一百局 $0.7^{100}$。
    * 三胎全女孩（每次相互独立、生女概率 0.6）：$0.6^3=0.216$。
    * 出现「至少」「至多」时正面讨论太难，改做反面再用 1 减：至少生一个女孩 $=1-0.4^3=0.936$。
    * 甲乙各以 0.6 的概率独立击中同一目标，目标被击中的概率 $=1-0.4\times0.4=0.84$。
    * $n$ 位同学各自以概率 $p$ 独立通过，至少一人通过的概率为 $1-(1-p)^n$。
    * 甲乙丙通过概率分别为 0.8、0.6、0.5 且独立，全达标为 $0.24$，至少一人没达标为 $1-0.24=0.76$。

    * > **结论**：若 $A$、$B$ 独立，则 $\bar A$ 与 $\bar B$、$\bar A$ 与 $B$、$A$ 与 $\bar B$ 三种组合也独立，一律可直接相乘。

    * 硬币正面记 $A$、骰子点数 3 记 $B$，至少有一件发生：$P(A\cup B)=1-P(\bar A)\cdot P(\bar B)=1-\dfrac12\times\dfrac56=\dfrac7{12}$。
    * 三道工序次品率分别为 $\dfrac1{70}$、$\dfrac1{69}$、$\dfrac1{68}$ 且互不影响，正品概率 $\dfrac{69}{70}\times\dfrac{68}{69}\times\dfrac{67}{68}=\dfrac{67}{70}$，次品概率 $\dfrac3{70}$。

* **互斥、对立、独立辨析**

    ```text
    ① 互斥：A 与 B 没有交集，不可能同时发生

            __________
           |          |
           |    A     |
           |          |
           |__________|

           __________
           |          |
           |    B     |
           |          |
           |__________|


    ② 对立：在互斥的基础上，A 与 B 的概率加起来还等于 1

          ______________________
         |    _______   _______ |
         |   |       | |       | |
         |   |   A   | |   B   | |
         |   |       | |       | |
         |   |_______| |_______| |
         |______________________|
              A 与 B 装满了 Ω


    ③ 独立：A 与 B 可以有交集，交集的概率 = P(A) × P(B)

          ______________________
         |    _______   _______ |
         |   |       | |       | |
         |   |   A   |•|   B   | |
         |   |       |•|       | |
         |   |_______|•|_______| |
         |______________________|
                  ↑
            交集概率 = P(A)×P(B)
    ```

    * 一句话区分：互斥看有没有交集，对立在互斥之上再加一条「概率和为 1」，独立不看形状、只看等式是否成立。

* **判断独立靠算不靠猜**

    * > **结论**：除极显然的情形（投硬币与投骰子）外，绝大部分情况都要通过计算 $P(AB)=P(A)P(B)$ 是否成立来判定，语义上「觉得互相影响」极不可靠。

    * 一家三个小孩：$A$ 无女孩、$B$ 最多一个女孩、$C$ 至少两个女孩、$D$ 既有男孩又有女孩。
    * 三小孩有次序，共 8 种：零个女孩 男男男 1 种；一个女孩 女男男、男女男、男男女 3 种；两个女孩 3 种；三个女孩 1 种。
    * $P(B)=\dfrac48=\dfrac12$，$P(D)=\dfrac68=\dfrac34$，$P(BD)=\dfrac38$（有且仅有一个女孩），且 $\dfrac38=\dfrac12\times\dfrac34$，故 $B$ 与 $D$ 独立。
    * 同一题中 $A$ 与 $C$ 互斥；$A$ 是 $B$ 的子集（不是 $B$ 是 $A$ 的子集）；$B$ 与 $C$ 既不互斥又穷尽全部情况，故对立。

    * 六个球标 1~6 有放回取两次，所有情况 $6\times6=36$：甲为第一次取出 1、乙为第二次取出 2、丙为两次之和是 8、丁为两次之和是 7。
    * $P(\text{甲})=\dfrac6{36}=\dfrac16$，$P(\text{丙})=\dfrac5{36}$（$2+6$ 起共 5 种），但甲丙同时发生要求第二次取 7，不存在，概率为 0，故不独立。
    * $P(\text{丁})=\dfrac6{36}=\dfrac16$，$P(\text{甲丁})=\dfrac1{36}=\dfrac16\times\dfrac16$，故甲与丁独立。

    * > **易错点**：算 $P(\text{甲丁})$ 时 $6+1$ 不算——那是第一次 6、第二次 1，与「第一次取出 1」的要求相反，只有「第一行第一列」一格符合。

* **没有情境时用韦恩图**

    * 已知 $P(A)=\dfrac13$、$P(B)=\dfrac16$，未说明二者关系，可分别按互斥、独立、子集三种假设作图求解。
    * 假设独立时 $P(A\cap B)=\dfrac13\times\dfrac16=\dfrac1{18}$，$A$ 的月牙为 $\dfrac13-\dfrac1{18}=\dfrac5{18}$，$B$ 的月牙为 $\dfrac16-\dfrac1{18}=\dfrac2{18}$，$P(A\cup B)=\dfrac{5+1+2}{18}=\dfrac49$。

    ```text
            P(A) = 1/3                    P(B) = 1/6
          ______________               ______________
         /              \             /              \
        |  左月牙 5/18   |   A∩B 1/18  |  右月牙 2/18  |
         \______________/              \______________/
                \____________|____________/
                             |
                       P(A∪B) = 4/9
    ```

    * > **易错点**：独立意味着两事件有交集，画图时必须画成有交集的形式，不能画成互斥。
    * 若 $B$ 是 $A$ 的子集，则 $AB$ 就是 $B$ 本身，概率为 $\dfrac16$ 而不是 $\dfrac1{18}$。

* **分类用加法与分步用乘法**

    * > **定义**：所求事件分成多种互斥情况时用加法；一件事分成几步完成、每步相互独立时用乘法。

    * 逛街 0.5、看电影 0.4、窝家 0.1，三者互斥且概率和为 1，出门玩（逛街或看电影）用加法得 0.9。
    * 连输两局：第一局胜 0.6 输 0.4、第二局胜 0.3 输 0.7，两局独立，连输概率 $0.4\times0.7=0.28$。
    * 袋中红黄白各一球、有放回取三次，全部情况 $3\times3\times3=27$ 种，需用树状图展开（三维情形表格画不出）。

    ```text
    第 1 次          第 2 次          第 3 次

      Y                 Y                 Y R W
      |               / | \             / | \
      R              Y  R  W           Y  R  W
     /|\             /|\ /|\           /|\ /|\ /|\
    Y R W           Y R W Y R W       Y R W Y R W Y R W
    | | |           | | | | | |        | | | | | | | | | |
    Y R W           Y R W Y R W       Y R W Y R W Y R W
    | | |           | | | | | |        | | | | | | | | | |
    Y R W           Y R W Y R W       Y R W Y R W Y R W
                                    |
                                    +-- 共 3×3×3 = 27 种情况
    ```

    * 三色有放回取三次：全同 $\dfrac3{27}=\dfrac19$；全不同 $\dfrac6{27}=\dfrac29$；不全相同 $\dfrac8{27}$；无红球 $\dfrac8{27}$。
    * 同一题不用枚举也能算：每次取到指定颜色都是 $\dfrac13$，$P(WWW)=\left(\dfrac13\right)^3=\dfrac1{27}$，三种全同情况相加得 $\dfrac19$。
    * 做题有两条路：穷举所有情况逐个数，或用「分类加法 + 分步乘法」，不同情境各有长处。

    * 轮流投篮（甲先投，先中者胜或各投三次为限），甲命中 $\dfrac13$、乙 $\dfrac12$ 且互不影响。
    * 乙在第 2 局取胜 $\dfrac23\times\dfrac12=\dfrac13$；第 4 局取胜 $\dfrac23\times\dfrac12\times\dfrac23\times\dfrac12=\dfrac19$；第 6 局取胜同式再乘一对得 $\dfrac1{27}$。三类相加得 $P(\text{乙胜})=\dfrac{13}{27}$。
    * 每人只投两个球：第 4 局结束 $\dfrac19$；第 6 局结束 $\dfrac19\times\dfrac13=\dfrac1{27}$，合计 $\dfrac4{27}$。

* **与排列组合的衔接**

    * 当前求概率主要靠一个一个列出情况，等于手工枚举；学完排列组合后这一过程会大幅简化。
    * 无论是否引入排列组合，思路始终是分类用加法、分步用乘法。

## 概率大题：方案、取球与比赛

* **方案选择：招聘三门考试**

    * 三门及格概率分别为 $A$、$B$、$C$，都在 0 与 1 之间且相互独立。
    * 方案一：三门中至少两门及格，事件分四类 $AB(1-C)$、$AC(1-B)$、$BC(1-A)$、$ABC$，$P_1=AB+AC+BC-2ABC$。
    * 方案二：先随机选两门、这两门都及格。选 AB、选 AC、选 BC 三类各占 $\dfrac13$，$P_2=\dfrac{AB+AC+BC}{3}$。

    ```text
                  先从三门里随机选两门（三种可能，各占 1/3）
                                 |
            +--------------------+--------------------+
            |                    |                    |
          选 AB                选 AC                选 BC
         概率 1/3             概率 1/3             概率 1/3
            |                    |                    |
       这两门都及格         这两门都及格         这两门都及格
         概率 AB              概率 AC              概率 BC
            |                    |                    |
            +------ 分步用乘法 ---+------ 分步用乘法 ----+
                                 |
                  每一类：从"选"算起，共两步
                  加起来：分类用加法
                                 |
                      P_2 = (AB + AC + BC) / 3
    ```

    * > **易错点**：方案二不能写成 $AB+AC+BC$，漏掉了「选」这一步本身的概率 $\dfrac13$；求概率要从第一步算到最后，不能把中间某一步当最终结果。

    * 比较大小用 $P_1-P_2=\dfrac23(AB+AC+BC)-2ABC$。
    * 三元基本不等式：$x_1+x_2+\cdots+x_n\ge n\sqrt[n]{x_1x_2\cdots x_n}$，故 $AB+AC+BC\ge3(ABC)^{2/3}$。
    * 由此 $P_1-P_2\ge2(ABC)^{2/3}-2ABC=2(ABC)^{2/3}\bigl(1-(ABC)^{1/3}\bigr)>0$，因 $ABC\in(0,1)$，故 $P_1>P_2$，方案一更合适。

* **取球：等可能性的陷阱**

    * 红球 $x$、黄球 $y$、蓝球 $z$，总数 $x+y+z=4$，取到红或黄概率 $\dfrac34$、黄或蓝概率 $\dfrac12$，得 $x+y=3$、$y+z=2$，解出 $x=2,y=1,z=1$。
    * 有放回取两次时，样本空间不是 9 个颜色点而是 16 个编号点：颜色对应的球数不同，各颜色点并不等可能。

    ```text
               第二次 ↓
                     R1        R2        Y         B
          第一次 →
           R1            R1R1      R1R2      R1Y       R1B
           R2            R2R1      R2R2      R2Y       R2B
           Y             YR1       YR2       YY        YB
           B             BR1       BR2       BY        BB
    ```

    * 颜色相同的取法：$YY$、$BB$ 与红球那一块 $R$ 的四个点（含 $R_1R_2$），共 6 种，$P(\text{甲胜})=\dfrac6{16}=\dfrac38$，乙胜 $\dfrac58$，游戏不公平。

    * > **提示**：颜色对应的球数不一样时不能只把颜色拎出来当样本点，必须给同色球分别标号，保证每个样本点等可能。

* **几局几胜：决胜局必在最后**

    * > **定义**：无论打了几局，最终获胜的一方在最后一局一定是赢的——不可能出现「最后一局是败方赢、结果另一方夺冠」。

    * 甲每局胜 $\dfrac23$、乙 $\dfrac13$，各局独立。
    * 三局结束即 $\left(\dfrac23\right)^3+\left(\dfrac13\right)^3=\dfrac8{27}+\dfrac1{27}=\dfrac13$（甲甲甲与乙乙乙两类）。
    * 比了四局甲获胜：只算三局中恰有一局乙胜且该局在前三局，$\dfrac13\left(\dfrac23\right)^3=\dfrac8{81}$，三类相加 $3\times\dfrac8{81}=\dfrac8{27}$；「甲甲甲甲」不存在，因为前三局结束比赛就已结束。
    * 七局四胜且主客场安排为「主 客 主 客 主 客 主」，甲主场胜率 0.8、客场胜率 0.4，各场独立。

    ```text
    局次      1     2     3     4    |   5     6     7
    场地      主    客    主    客    |   主    客    主
    甲胜概率  0.8   0.4   0.8   0.4   |  0.8   0.4   0.8
    ```

    * 前两场至少赢一场：反面是主场全输，$1-0.2\times0.2=0.96$。
    * 二比二之后甲最终获胜：情况① 第 5、6 局连胜 $0.8\times0.4=0.32$；情况② 第 5 局输、第 6、7 局胜 $0.2\times0.4\times0.8=0.064$；情况③ 第 5 局胜、第 6 局输、第 7 局胜 $0.8\times0.6\times0.8=0.384$；合计 0.768。乙不可能在最后一局赢。

    * > **易错点**：主场甲输是 0.2、客场甲输是 0.6，二者不能混；全输写成 0.2×0.2=0.04，不是 0.4。

    * > **结论**：题目若问「当二比二时」，前面四局已经发生、概率视为 1，不必再为「打成二比二」乘一个概率因子。

## 频率与概率的关系

* **频率不等于概率**

    * > **结论**：概率是事件本身的固有属性，频率是有限次试验中实际出现的比例，带随机性；只能用频率估计概率，不能把二者等同。

    * 次品率 0.05 的产品任取 200 件，不一定有十件次品，只能说估计有十件，实际可能全是次品。
    * 抛 100 次硬币出现 51 次正面，$51/100=0.51$ 是频率；写成「正面概率的估计值是 0.51」才对。
    * 掷 100 次骰子出现 6 的结果 20 次，其频率是 $20/100=0.2$，这句只谈频率，判为正确。

* **标记重捕法估鱼数**

    * > **定义**：先捕获并标记一批生物放回，充分混匀后再捕一批，用两次捕获中标记比例相等列比例式估计总量。

    * 第一次捞出 120 条鱼做记号放回，再捕 100 条中有记号 10 条：$\dfrac{120}{X}=\dfrac{10}{100}$，得 $X=1200$。
    * 之所以要「经过适当时间」，是为了让标记鱼与未标记鱼在池中充分混匀。

## 统计与概率的综合应用

* **直方图给出概率**

    * 题目用频率分布直方图给出数据时，用频率估计概率，之后按概率参与运算。
    * 求未知柱参数：组距为 10，面积 = 高 × 10，各柱面积之和为 1；列一个方程解 $a$、$b$，得 $a=0.028$、$b=0.04$。
    * 求「1 分钟以内」的频率：某柱边界为 55 与 65 秒，60 秒卡在正中，需把该柱一分为二只取左半面积。

        $$\text{甲}=0.05+0.17+10a+5b=0.05+0.17+0.28+0.20=0.7$$
        $$\text{乙}=0.2+0.3+0.1=0.6$$

* **闯关密码锁：机会次数的概率**

    * 规则：两道锁，每道必须在 1 分钟内解开才算成功；先开始者有 2 次连续机会，第二人也有 2 次机会，某人两次用完仍有锁未解则换人。
    * 甲先出场、不超过三次机会过关：甲两次全成功 $0.7\times0.7=0.49$；甲一胜一负再由乙成功，两种顺序各 $0.7\times0.3\times0.6=0.126$；合计 $0.49+0.126+0.126=0.742$。
    * 一次机会不可能过关，因为解一把锁就占用一次机会。

    ```text
    甲先出场
      甲 甲                      0.7 × 0.7                = 0.49
      甲胜甲负 乙胜乙胜           0.7 × 0.3 × 0.6 × 0.6    = 0.0756
      甲胜甲负 乙胜乙负           0.7 × 0.3 × 0.6 × 0.4    = 0.0504
      甲胜甲负 乙负乙胜           0.7 × 0.3 × 0.4 × 0.6    = 0.0504
      甲负甲胜 乙胜乙胜           0.3 × 0.7 × 0.6 × 0.6    = 0.0756
      甲负甲胜 乙胜乙负           0.3 × 0.7 × 0.6 × 0.4    = 0.0504
      甲负甲胜 乙负乙胜           0.3 × 0.7 × 0.4 × 0.6    = 0.0504
      甲负甲负 乙胜乙胜           0.3 × 0.3 × 0.6 × 0.6    = 0.0324
                                                                ─────
                                                                合计 = 0.8752
    ```

    * 乙先出场：把前两局的甲换成乙、后两局换成甲，结构不变、数重算。

    ```text
    乙先出场
      乙 乙                      0.6 × 0.6                = 0.36
      乙胜乙负 甲胜甲胜           0.6 × 0.4 × 0.7 × 0.7    = 0.1176
      乙胜乙负 甲胜甲负           0.6 × 0.4 × 0.7 × 0.3    = 0.0504
      乙胜乙负 甲负甲胜           0.6 × 0.4 × 0.3 × 0.7    = 0.0504
      乙负乙胜 甲胜甲胜           0.4 × 0.6 × 0.7 × 0.7    = 0.1176
      乙负乙胜 甲胜甲负           0.4 × 0.6 × 0.7 × 0.3    = 0.0504
      乙负乙胜 甲负甲胜           0.4 × 0.6 × 0.3 × 0.7    = 0.0504
      乙负乙负 甲胜甲胜           0.4 × 0.4 × 0.7 × 0.7    = 0.0784
                                                                ─────
                                                                合计 = 0.8752
    ```

    * > **结论**：两种出场顺序下团队进入下一关的概率都是 0.8752，与出场顺序无关。

    * > **易错点**：$0.7\times0.3\times0.4\times0.6$ 这类「甲一胜一负、乙一输一胜」的情形与几局几胜同构——为了比到第四局还想赢，最后那一手必须是赢的一方，只不过这里赢的一方中途换了人。

## 高频题型速查

* **统计量计算**

    * | 题型 | 关键结论 |
      | :--- | :--- |
      | 线性变换 $ax+b$ | $\bar{x}'=a\bar{x}+b$，$s'^2=a^2s^2$，$s'=\lvert a\rvert s$ |
      | 求平方的平均数 | 用第二公式，$\dfrac{1}{n}\sum x_i^2=s^2+\bar{x}^{\,2}$ |
      | 整体去掉一部分 | 各自平方和相减，配剩余平均数回代 |
      | 去掉等于平均值的数 | 平均值不变、方差变大 |
      | 两组合并 | $\bar{z}=\dfrac{m\bar{x}+n\bar{y}}{m+n}$，方差加两项均值差平方 |
      | 等量合并 | $\bar{z}=\dfrac{\bar{x}+\bar{y}}{2}$，$s=\sqrt{\dfrac{s_1^2+s_2^2}{2}+\dfrac{(\bar{x}-\bar{y})^2}{4}}$ |

* **直方图读图**

    * | 所求 | 公式 |
      | :--- | :--- |
      | 某组频率 | 柱高 × 组距 |
      | 某组人数 | 柱高 × 组距 × 总人数 |
      | 缺失组频率 | $1-$ 其余各组频率之和 |
      | 平均数估计 | $\sum(\text{区间中点}\times\text{频率})$ |
      | 中位数估计 | 左侧累计跨过 0.5 所在柱，再补 $\dfrac{\text{面积差}}{\text{柱高}}$ |
      | 第 $p$ 分位数 | 左右面积各占 $p$ 与 $1-p$ 的竖线横坐标 |

* **概率计算**

    * | 题型 | 方法 |
      | :--- | :--- |
      | 从若干件中取两件 | 连线法，分母 $4+3+2+1=10$ |
      | 分两次、有先后或放回 | 二维表格，分母为两次取值数之积 |
      | 三次及以上或三色取球 | 树状图，分母 $3^n$ |
      | 同色球数不等的取球 | 必须给同色球编号，保证样本点等可能 |
      | 「至少」「至多」 | 求反面再用 $1$ 减 |
      | 独立事件同时发生 | $P(A)P(B)$，含 $\bar A$、$\bar B$ 的组合同样独立 |
      | 互斥事件的并 | $P(A)+P(B)$，先判定互斥 |
      | 判断独立 | 算 $P(AB)$ 与 $P(A)P(B)$ 是否相等，不靠语义 |
      | 无情境求并概率 | 画韦恩图，把整体拆成左月牙 + 交集 + 右月牙 |
