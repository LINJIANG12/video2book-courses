# 函数的概念·定义域与值域

## 函数记号与代入规则

### 用 f(x) 代替 y 表示函数

* **函数记号的由来**

    * > **定义**：把不同的函数用不同的字母 $f$、$g$、$h$ 表示，并在字母后的括号里写明自变量是谁，记作 $f(x)$、$g(x)$、$h(m)$。

    * 用 $y$ 表示函数时，两个不同的函数共用同一个字母 $y$，问「$x=0$ 时 $y$ 等于多少」无法判断指的是哪一个函数。

    * 不同函数必须起不同的名字，相当于每个人都有自己的名字；全用一个名字表示时，老师一叫就全班站起来。

    * $f$ 取自英文 function 的首字母，属于约定而非推导。

    * 名字后面还要挂一个「车牌」写明自变量是谁，否则 $h(m)=n^2$ 这样的式子说不清 $m$、$n$ 哪个是自变量。

        ```text
             函数名字   自变量"车牌"
                │          │
                ▼          ▼
                f  ──────── ( x )   =  2x + 1
                g  ──────── ( x )   =  x² - 2x
                h  ──────── ( m )   =  …… 有关 m 的函数
        ```

### 要变一起变

* **代入规则**

    * > **结论**：同一个等式左右两边的 $x$ 是同一个 $x$，左边括号里怎么变，右边解析式中所有的 $x$ 就跟着一起变。

    * $f(x)=2x+1$ 时，$f(0)=2\times0+1=1$，$f(1)=2\times1+1=3$，$f(100)=2\times100+1$。

    * 括号里代入表达式同样成立：$f(2m)=2(2m)+1=4m+1$。

    * $f(x^2+1)=2(x^2+1)+1=2x^2+3$，括号里换成 $x^2+1$，右边每一个 $x$ 都换成 $x^2+1$。

        ```text
           f( x² + 1 )  =  2 · (x² + 1)  +  1
                                  │
           括号里换成 x²+1  ───────┴──  右边每一个 x 都换成 x²+1

           =  2x² + 2 + 1  =  2x² + 3
        ```

### 代换不等于相等

* **代换与等式的区别**

    * > **易错点**：代换可以代换，但不代表前后相等。无论怎么代换，等号左右两边的 $x$ 是同一个 $x$，要变一起变。

    * 把 $x$ 换成 $x^2+1$ 是代换过程，不代表 $x=x^2+1$；类比换手机，从苹果换成华为不等于苹果手机等于华为手机。

    * 先把 $x$ 代成 $0$ 再代成 $1$，不代表 $0=1$。

    * 换元设 $x-1=t$ 之后又把 $t$ 换回 $x$，是另一次代换，不代表 $x-1=x$、$-1=0$。

### 判断前后两个 x 是否同一个

* **判据**

    * > **定义**：两个 $x$ 是不是同一个，只看它们是否处在「要变一起变」的同一个等式内部判断，不跨等式。

    * $f(x)=x^2-2x$ 与 $f(x)=x^2-1$ 是两个不同的函数，两个等式中的 $x$ 毫无关系。

    * 两个不同的函数（如 $2x+3$ 与 $x^2+4$）里的 $x$ 不是同一个；只有在同一个式子内部，左右两个 $x$ 才是一个。

    * 例外：解方程组联立之后，两个方程中的 $x$ 才是同一个 $x$；未联立前，两个函数就是两个不同的 $x$。

        ```text
           等式 A ： f(t) = t² - 1     ← A 里的 t 与 A 里的 x 是同一个

           等式 B ： f(x) = x² - 1     ← B 里的 x 与 A 里的 t 毫无关系

           「是不是同一个 x」只在自己的那一个等式内部判断
        ```

### 已知 f(x-1) 求 f(x)

* **凑括号法**

    * 目标是让括号内的 $x-1$ 变成 $x$，由 $x-1=x$ 移项解得 $x$ 要替换成 $x+1$。

    * 代入后得 $f(x-1)=\big[(x+1)-1\big]^2-2\big[(x+1)-1\big]=(x+1)^2-2(x+1)-2=x^2-1$。

    * > **注意**：算时分两步——先让括号回到 $x$，使整个式子变回 $f(x)$ 的原样，最后再化简；不要把化简和代换搅在一起，这是新手最容易翻车的地方。

* **换元写法**

    * 设 $x-1=t$，则所有 $x$ 都写成 $t+1$，得 $f(t)=(t+1)^2-2(t+1)=t^2-1$。

    * 求的是 $f(x)$ 不是 $f(t)$，最后把 $t$ 换成 $x$，答案 $x^2-1$。

        ```text
           已知 f(x) = x² - 2x ，求 f(x - 1)

           ① 设整体      x - 1 = t        ⇒  x = t + 1
           ② 右边整体替换 f(t) = (t+1)² - 2(t+1)
           ③ 化简        f(t) = t² - 1
           ④ 换回        f(x) = x² - 1        ← 这才是最终答案

           （① ④ 两步在考场上通常一起写：( (x+1)-1 )² - 2((x+1)-1) = x² - 1）
        ```

### 给 f(m) 求 f(x)

* **双向代换规则**

    * > **结论**：给 $f(x)$ 求 $f(m)$，把 $x$ 换成 $m$；给 $f(m)$ 求 $f(x)$，把 $m$ 换成 $x$。两个方向的规则完全一样，都是「要变一起变」。

    * 计算完 $f(m)$ 后回代，只需把上下所有的 $m$ 换成 $x$，括号内外一起变。

    * 例：$f(\sqrt{x}+1)=2x+1$。设 $\sqrt{x}+1=m$，则 $\sqrt{x}=m-1$，$x=(m-1)^2$，原式变成 $f(m)=2(m-1)^2+1=2m^2-4m+3$，故 $f(x)=2x^2-4x+3$。

    * 该题还应补充定义域：$\sqrt x+1\ge 1$，由括号内部范围一致，得 $x\in[1,+\infty)$。

## 函数的定义与三要素

### 函数是什么

* **函数的本质是加工厂**

    * > **定义**：给定任何一个 $x$，都有唯一确定的 $y$ 与之对应，这种 $x$、$y$ 的关系就叫函数。高中阶段这个定义没有太大变化。

    * 一个确定的函数代表一个固定的运算过程：无论什么东西进来，都走同一套加工流程。

    * $f(x)=x^2+x$ 时，$0$ 进来出去的是 $0^2+0=0$，$1$ 进来出去的是 $1^2+1=2$，$3m+5$ 进来出去的是 $(3m+5)^2+(3m+5)$。

    * 不同函数解析式不同，相当于不同加工厂加工流程不同；$g(x)=2x+1$ 时 $0\mapsto1$、$1\mapsto3$、$3m+5\mapsto 2(3m+5)+1$。

    * 生活中的函数例子：整形医院把单眼皮变双眼皮，消化系统把食物变成另一种东西，婚礼把男孩女孩变成新婚夫妻。

    * 高中相对初中的新增之处，只在于把加工流程本身起了名字 $f$、$g$、$h$，并在名字后挂一个写清自变量的括号。

        ```text
                      进来的东西                出去的函数值
                         │                          ▲
                         │   ① 平方                │
           ─────────────►│──────────────────────────┼────►
                         │   ② 加上它自己            │
                         │                          │
                  f(x) = x² + x   （谁进来都走这一套）
        ```

### 函数三要素

* **三要素**

    * > **定义**：自变量 $x$ 取值所构成的集合，叫做这个函数的定义域；只有让 $x$ 取定义域范围内的值，原式才有意义。

    * 函数值所形成的集合叫做值域，即 $y$ 的取值范围。

    * 对应法则是变量 $x$ 与变量 $y$ 如何对应的运算法则，例如「套根号」这个运算过程 $F$。

    * 定义域、值域、对应法则三者构成**函数三要素**，三者确定，函数就确定。

* **具体函数与抽象函数**

    * 解析式已经给出、可以直接代入的是**具体函数**。

    * 整个问题从头到尾都不知道 $F(x)$ 解析式的函数称为**抽象函数**。

    * 求定义域分这两类题型，做题方法完全不同。

## 复合函数

### 嵌套次序与解析式写法

* **复合函数的定义**

    * > **定义**：函数套函数，一层包一层，称为复合函数，$f(g(x))$ 中先走内层 $g$ 再走外层 $f$。

    * $x$ 先进 $g(x)$ 得到 $g(x)$，再把 $g(x)$ 当成一个整体放进 $f$ 加工，得到 $f(g(x))$。

        ```text
             x
             │
             ▼
           ┌──────┐
           │  g   │   先走内层：x  ──►  g(x) = 2x + 1
           └──────┘
             │
             ▼
           ┌──────┐
           │  f   │   再走外层：整个 g(x) 当成一个整体 ──►  f(g(x))
           └──────┘

           f(g(x)) 是"先进 g，后进 f"，由内到外
        ```

* **解析式的展开**

    * 写 $f(g(x))$：先把 $g(x)$ 替换成它的解析式，再把 $f$ 中所有的 $x$ 换成该解析式。

    * 已知 $f(x)=x^2+x$，$g(x)=2x+1$：

        ```text
           f(g(x))  =  f( 2x + 1 )   把 f 里所有 x 换成 2x+1
                    =  (2x+1)² + (2x+1)

           g(f(x))  =  g( x² + x )   把 g 里所有 x 换成 x²+x
                    =  2(x²+x) + 1
        ```

    * > **易错点**：复合函数不满足交换律，$f(g(x))\neq g(f(x))$。做题时永远由内到外，先确定里面那个括号到底等于什么。

### 已知 g(f(x)) 求参数

* **固定套路**

    * 第一步由内到外算出 $g(f(x))$ 的解析式。

    * 第二步与题目已知的结果列成方程。

    * 第三步用「对应项系数相等」比出参数。

    * 第四步把常数项再验一下。

    * > **提示**：这四步中间任何一步都不能跳，尤其是最后的验证。

* **算例**

    * 已知 $f(x)=2x+a$，$g(x)=\dfrac{1}{4}x^2+3$，且 $g(f(x))=x^2-x+1$，求 $a$。

    * 由内到外：$g(f(x))=g(2x+a)=\dfrac{1}{4}(2x+a)^2+3$。

    * 与已知结果相等：$\dfrac{1}{4}(2x+a)^2+3=x^2-x+1$，两边乘 $4$ 得 $4x^2-4x+4=4x^2+4ax+a^2+12$。

    * 对应项系数相等：$4a=-4$，得 $a=-1$。

    * 验证常数项：$(-1)^2+3=4$，与左边常数项一致，$a=-1$ 成立。

## 定义域

### 三条硬性要求

* **具体函数扫点**

    * 具体函数求定义域，就是求 $x$ 的范围，把解析式里对 $x$ 的要求逐条抄下来。

    | 你在解析式里看到 | 对自变量的要求 |
    | :--- | :--- |
    | 分式 | 分母不能为零 |
    | 根号 $\sqrt{\cdots}$ | 根号里面大于等于零（非负数） |
    | 某个数的零次幂 | 零次幂里面装的东西绝不能是零 |
    | 正切 $\tan x$ | $x \ne \dfrac{\pi}{2}+k\pi$（$k$ 为整数） |
    | 对数 | 真数为正，$x>0$ |

    * 任何数的零次幂都等于一（$3^0=1$，$(-1)^0=1$），唯独 $0^0$ 没有意义，所以零次幂默认带着「底数不为零」的前提条件。

    * > **提示**：出现零次幂，就默认带着「底数不为零」的前提条件，与根号、分母属于同一层级的「扫描点」。

    * 高考中有定义域限制的函数一共五种，上面五类就是全部；前三条是当前必须掌握的。

### 多条限制：先各解再取交集

* **求交集的步骤**

    * 每条要求先各自解出「允许的区间」，三个要求**同时成立**，所以最后要取**交集**。

    * 解不等式时，如 $-x^2+\cdots$，两边乘 $-1$ 再变号并因式分解，得根 $x=2$ 与 $x=3$；二次函数开口向下，要求函数值 $\le 0$ 即取 $x$ 轴下方的部分，得闭区间 $[2,3]$，两端都能取到。

    * 画数轴：能取到的点画**实心点**，被挖掉的点画**空心点**。

    * 交剩下的若干段不相连的小段，最后要**连在一块用并集写**。

        ```text
        要求①：根号内 ≥ 0        →  解出区间 A
        要求②：分母 ≠ 0           →  解出"挖掉若干点"
        要求③：零次幂底数 ≠ 0      →  解出"挖掉若干点"
                             │
                             ▼
             三者同时成立  ⇔  A ∩ (挖点的区间) ∩ (挖点的区间)
                             │
                             ▼
                      数轴上画出来 → 剩余几段 → 用并集连写
        ```

    * > **易错点**：两条及以上限制时，先各自解出允许的区间，最后一定取**交集**；而交出来的若干个不相连的小段，写成答案时要用**并集**连写。这两步不要搞反。

### 抽象函数求定义域

* **两条口诀**

    * > **易错点**：定义域指的永远是它**对应这个函数自己**的 $x$ 的范围，不是 $x-1$ 的范围，也不是 $2x-1$ 的范围。

    * 前后两个 $x$ 根本不是一个 $x$，因为它们处在两个不同的函数中。

    * 两个函数都用同一个 $f$、同一个对应法则，$f(\text{☆})$ 与 $f(\text{□})$ 的**范围是一致的**。

* **范围一致的原因**

    * 同一个对应法则对内部的范围要求始终一样：$f(x)\to\sqrt x$ 要求 $x\ge0$，$f(2x)\to\sqrt{2x}$ 要求 $2x\ge0$（等价于 $x\ge0$），$f(3x-5)\to\sqrt{3x-5}$ 要求 $3x-5\ge0$（等价于 $x\ge\frac53$）。

    * 甭管里面的东西长得多复杂，外面对应法则没变，对进来的要求就不变。

        ```text
          同一个对应法则（套根号）内部的范围要求

             f(x)        →  √x        →  要求：x ≥ 0
             f(2x)       →  √2x       →  要求：2x ≥ 0   （等价于 x ≥ 0）
             f(3x-5)     →  √(3x-5)   →  要求：3x-5 ≥ 0 （等价于 x ≥ 5/3）
        ```

* **算例**

    * 已知 $f(x)$ 的定义域是 $[-3,2]$，求 $f(2x-1)$ 的定义域。

    * 第一句说的是第一个函数里那个 $x$ 的范围为 $[-3,2]$，不是 $2x-1$ 的范围。

    * 括号内部范围一致，故 $2x-1$ 的范围也是 $[-3,2]$，解 $-3\le 2x-1\le 2$ 得 $-1\le x\le \dfrac32$。

    * 所以 $f(2x-1)$ 的定义域是 $\left[-1,\dfrac32\right]$。

    * 变式：$f(x+2)$ 的定义域。先由 $x+2\in[-3,2]$ 得 $x+2$ 的范围是 $[-1,4]$；再由 $2x-1\in[-1,4]$ 解得 $0\le x\le \dfrac52$，即 $[0,\frac52]$。

## 求解析式的四种方法

### 待定系数法

* **适用条件与做法**

    * > **结论**：当题目非常直白地告诉了你函数类型时，用待定系数法。

    * 一次函数设 $f(x)=kx+b$，二次函数设 $f(x)=ax^2+bx+c$。

    * 出现 $f(f(x))$ 这类嵌套时只做代换，右侧照抄，靠「要变一起变」把右边也整体替换。

* **一次函数算例**

    * $f(x)$ 是一次函数且 $f(f(x))=4x-3$，求 $f(1)$。

    * 设 $f(x)=kx+b$，代换得 $f(kx+b)=k(kx+b)+b=4x-3$，化简为 $k^2x+kb+b=4x-3$。

    * 对应项系数相等：$k^2=4$ 与 $kb+b=3$。$k=2$ 时 $b=1$，解析式 $2x+1$；$k=-2$ 时 $b=-3$，解析式 $-2x+3$。

    * 两个解析式给出同一个函数值 $f(1)=1$，最终答案仍是 $1$。

    * > **提示**：算出「两个解析式」很正常，像 $k^2=4$ 天生给两个根。题目往往只问**函数值**，两个解析式给出的同一个函数值最后合流成一个答案，这是题目故意设计的，不必慌。

* **二次函数算例**

    * $f(x)$ 是二次函数，$f(x+1)-f(x)=2x$，且 $f(0)=1$。

    * 设 $f(x)=ax^2+bx+c$，先求 $f(x+1)=a(x+1)^2+b(x+1)+c$，代入原式。

    * 用最笨的展开法：完全平方 $x^2+2x+1$，正负 $c$ 约掉、$\pm ax^2$ 约掉、$bx$ 减 $bx$ 约掉，剩 $2ax+a+b=2x$。

    * 对应项系数相等：$2a=2$ 与 $a+b=0$，得 $a=1$、$b=-1$；再由 $f(0)=1$ 得 $c=1$。

    * 所以 $f(x)=x^2-x+1$。

### 换元法

* **四步走**

    * > **定义**：把复杂整体强行设成一个新字母 $m$，使其变成单项式，再解出老变量关于新变量的表达式。

        ```text
                  换元法四步走

          ① 设元      复杂的整体  →  设成 m（把它变成单项式）
                         │
          ② 反解      解出 x = 关于 m 的表达式
                         │
          ③ 代回      原式中「所有」的 x 都换成 m 的表达式
                      （要变一起变，一个都不能漏）
                      左边括号整体就化简成了 f(m)
                         │
          ④ 回代      求的是 f(x) 不是 f(m)
                      把所有 m 换成 x，左右一起变
        ```

    * 例：设 $m=\dfrac{x}{x+1}$，则 $m(x+1)=x$，合并同类项得 $x(1-m)=m$，即 $x=\dfrac{m}{1-m}$。

    * 前后两个式子等价，所以必须把**所有** $x$ 都换成 $\dfrac{m}{1-m}$，繁分式上下同乘 $1-m$ 后化简得 $f(m)$。

    * > **提示**：化简验证只在第一次做，后面直接写「设 $\frac{x}{x+1}=m$」把它当整体，中间分子分母的化简可以跳过。

* **带根号算例**

    * 已知 $f(\sqrt{x}+1)=2x+1$，求 $f(x)$。

    * 设 $m=\sqrt{x}+1$，则 $\sqrt{x}=m-1$，$x=(m-1)^2$，原式变成 $f(m)=2(m-1)^2+1=2m^2-4m+3$。

    * 把 $m$ 换成 $x$，得 $f(x)=2x^2-4x+3$。

    * 还应补充定义域 $x\in[1,+\infty)$：由 $\sqrt{x}\ge0$ 得 $\sqrt{x}+1\ge1$，括号内部范围一致，故 $x\ge1$。

    * > **注意**：不写这个定义域严格来说不算全对；考试若要求必须写就老老实实写。

* **含分式括号算例**

    * 已知 $f\left(\dfrac{1-x}{1+x}\right)=x$，求 $f(x)$ 的解析式。

    * 设 $\dfrac{1-x}{1+x}=m$，两边乘 $(1+x)$ 得 $1-x=m+mx$，以 $x$ 合并同类项移项得 $x=\dfrac{1-m}{1+m}$。

    * 原式变成 $f(m)=\dfrac{1-m}{1+m}$，把所有 $m$ 换成 $x$，得 $f(x)=\dfrac{1-x}{1+x}$。

    * 定义域要把 $x=-1$ 挖掉，因为原式中 $x+1$ 作分母不能为零。

### 整体代换法

* **适用条件与信号**

    * > **结论**：当发现等号左右两边有关系、它们是一个整体时，或者换元法做不了时，用整体代换法。

    * 换元并非万能：括号里的整体若会解出一元二次方程，就要走判别式与求根公式，两个根都要分别代，代完还是平方再取倒数，太麻烦。

    * 此时可以不解，把大圆圈看成一个整体，观察两边究竟有什么关系。

    * 换元失效往往是一个信号：前后两个部分很可能有关系，能相互表示就能统一成一个整体，再整体换元。

* **互为倒数的信号**

    * 形如 $x^2$ 与 $\dfrac{1}{x^2}$ 的两坨互为倒数，乘积为 $1$，可以用完全平方式统一。

    * $x^2+\dfrac{1}{x^2}=\left(x-\dfrac{1}{x}\right)^2+2$。

        ```text
           两个"长得像"的部分（互为倒数）：

                ①        ②
             x²     与    1/x²
              │
              │  ② = 1/①
              ▼
           完全平方式：① + ② = (① - ②)² + 2·①·②
                     ①·② = 1
                     ⇒  x² + 1/x² = (x - 1/x)² + 2
                        └────┬────┘
                        互为倒数的两坨，被统一成一个整体
        ```

    * 把两边都设成 $m$：$f(m)=m^2+2$，所以 $f(x)=x^2+2$。

    * > **结论**：整体代换与换元本质上是同一个方法，就是把一个整体看成一个变量。

### 构造方程组法

* **适用条件与代换合法性**

    * > **结论**：当一个方程里面有好几个未知函数值、一个方程不够解时，需要构造另一个方程。

    * 一个方程里有 $f(x)$ 与 $f(-x)$ 两个未知量，相当于二元一次方程 $2a+3b=3$，一个方程解不出唯一解。

    * 代换的合法性要求：把 $x$ 全部代换掉，且未知数数量不能增加，仍然是 $f(x)$ 与 $f(-x)$ 这两个。

    * 把 $x$ 都换成 $2x$ 是没道理的：换完后 $f(2x)$、$f(-2x)$ 依然未知，反而引入了新变量。

    * $x$ 与 $-x$ 互为相反数，所以把所有 $x$ 换成 $-x$，未知数的位置互换但数量不变。

* **解法算例**

    * 已知 $2f(x)-f(-x)=3x^3$，求 $f(x)$。

    * 把所有 $x$ 换成 $-x$，负的负得 $2f(-x)-f(x)=-3x^3$，与原式构成二元一次方程组。

    * 用方框 ○ 代表 $f(x)$、圆圈 ○ 之外另记 $f(-x)$：① $2\square-\bigcirc=3x^3$；② $2\bigcirc-\square=-3x^3$。

    * ① 两边乘 2 得 $4\square-2\bigcirc=6x^3$，与 ② 相加得 $3\square=3x^3$，所以 $f(x)=x^3$。

        ```text
          用「方框 + 圆圈」把抽象函数变成二元一次方程组

              ┌──────────────────────────┐
              │  f(x)  →  □              │
              │  f(-x) →  ○              │
              └──────────────────────────┘

          ①    2□ - ○ = 3x³
          ②  (x → -x)   2○ - □ = -3x³

          ① 两边乘 2 ： 4□ - 2○ = 6x³
          ②            2○ - □ = -3x³
               ────────────────────────
               相加 ： 3□      = 3x³      →  f(x) = x³  ✓
        ```

* **倒数型算例**

    * 已知 $2f(x)-f\left(\dfrac{1}{x}\right)=2x-1$，求 $f\left(\dfrac12\right)$。

    * $x$ 与 $\dfrac1x$ 互为倒数，把所有 $x$ 换成 $\dfrac1x$，得 $2f\left(\dfrac1x\right)-f\left(\dfrac1{1}{x}\right)=\dfrac2x-1$，而 $\dfrac1{1/x}=x$。

    * 两式相加消掉一个：第一个式子两边乘 2 后相加，得 $3f(x)=4x+\dfrac2x-3$，即 $f(x)=\dfrac{4x+\frac2x-3}{3}$。

    * 所以 $f\left(\dfrac12\right)=\dfrac{2+4-3}{3}=1$。

### 四种方法怎么选

* **方法对照**

    | 方法 | 什么时候用 |
    | :--- | :--- |
    | **待定系数法** | 当已知**函数类型**的时候 |
    | **换元法** | 当 $f$ 括号里面**特恶心**、需要还原成单项式的时候 |
    | **整体代换法** | 当发现等号**左右两边有关系**、它们是一个整体的时候；或者说**换元法做不了**的时候 |
    | **构造方程组法** | 当这**一个方程里面有好几个变量**、一个方程不够解的时候 |

* **四道题的方法分工**

    * 「$f(x)$ 是一次函数且 $f(f(x))=4x-3$」——已给函数类型，待定系数法。

    * 「$f(x)$ 是二次函数且 $f(x+1)-f(x)=2x$」——已给函数类型，待定系数法。

    * 「$f\left(\frac{1-x}{1+x}\right)=x$」——括号极复杂，换元法。

    * 「$2f(x)-f(-x)=3x^3$」——一个方程两个未知量，构造方程组法。

    * 「$f\left(x^2+\frac{1}{x^2}\right)=\left(x-\frac1x\right)^2+2$」——换元解不出二次方程，整体代换法。

## 分段函数

### 结构与实际情境

* **分段函数的形式**

    * > **定义**：大括号括起来、在 $x$ 的不同段用不同解析式的函数叫分段函数。

    * 生活模型：横轴是学习时间，纵轴是学习效果。没学习时效果为零，学习时间变长效果提升；但一天只有 24 小时，超过某个临界点效率下降，所以 $0\sim12$ 小时用一段解析式，大于 12 小时用另一段。

* **招手即停票价**

    * 5 千米以内（含 5 千米）票价都是 2 元，坐 1000 米与坐 2 千米同价。

    * 5 千米以上每增加 5 千米票价增加 1 元，不足 5 千米按 5 千米算。

    * 图像特征：$0$ 到 5 千米这一段是水平的，其余部分是阶梯状的。

    * 票价只能从 2 加 1 加 1 加 1，取到 2、3、4、5 这些整数，2.5、2.3、3.2、4.5 取不到；走 7 千米与走 8 千米票价相同。

### 剥洋葱求值

* **逐层剥法**

    * 设 $f(x)=\begin{cases}x^2+1, & x<1 \\ 2x-2, & x\ge 1\end{cases}$，求 $f(f(1))$。

    * 先算 $f(1)$：$1$ 落在 $x<1$ 这一段，取第一个解析式，得 $1^2+1=2$。

    * 原式变成 $f(2)$，$2$ 落在 $x\ge1$ 这一段，取第二个解析式，得 $2\times2-2=2$。

    * 所以 $f(f(1))=2$。

    * > **易错点**：复合函数求值不是「代入一次就完事」。每剥一层，都必须重新判断这个自变量落在哪个区间，重新选解析式。

### 分段标准里藏着不等式

* **解不等式定范围**

    * 已知 $g(x)=x^2-2$，且 $f(x)=\begin{cases}g(x)+x, & x<g(x) \\ g(x)-x, & x\ge g(x)\end{cases}$。

    * 把 $g(x)$ 翻译成 $x^2-2$：第一段是 $x^2+x+2$，第二段是 $x^2-x-2$。

    * 第一段条件 $x<x^2-2$ 等价于 $x^2-x-2>0$，因式分解 $(x-2)(x+1)$，开口向上，得 $x>2$ 或 $x<-1$。

    * 第二段是上一段的补集，不用再解，得 $-1\le x<2$。

        ```text
                f(x) = { x² + x + 2 ,  x < g(x)
                         { x² - x - 2 ,  x ≥ g(x)

          分段标准 →  解不等式 →  两段各取一段 x 的范围

           第一段：x < x²-2  ⇔  x²-x-2 > 0
                                因式分解 (x-2)(x+1)
                                开口向上的二次函数
                                x > 2  或  x < -1

           第二段：x ≥ x²-2 ⇔  x²-x-2 ≤ 0
                                正好是上一段的补集
                                -1 ≤ x < 2
        ```

* **求值域**

    * > **提示**：不管函数图像怎么复杂，值域就是纵坐标的取值范围，也就是函数值的取值范围。

    * 第二段 $y=x^2-x-2$ 对称轴为 $\dfrac12$，$\Delta=1-8=-7<0$ 与 $x$ 轴无交点；在 $x=-1$ 与 $x=2$ 处函数值都是 $0$，但两端都是空心点，取不到。

    * 最低点在 $x=\dfrac12$ 处，函数值 $\dfrac14-\dfrac12-2=-\dfrac94$；从最低点往上走到 $0$ 为止，中间 $(0,2)$ 的值取不到，故值域为 $\left[-\dfrac94,\,0\right]$。

    * 第一段 $y=x^2+x+2$ 在 $x=-1$ 处函数值为 $1-1+2=2$，且 $x=-1$ 是空心点取不到，往上无限延伸，故值域为 $(2,+\infty)$。

    * 两段值域用并集合并：$\left[-\dfrac94,\,0\right]\cup\left(2,+\infty\right)$。

        ```text
          f 的值域（两段并集）

          第二段 y = x²-x-2 ,  x∈[-1,2)   最低点 x=½ → -9/4
                ▁▂▃▅▆█▇▅▃▂▁   区间被两个空心点"掐"出缺口 (0, 2) 取不到
                                → 值域 [ -9/4 , 0 ]

          第一段 y = x²+x+2 ,  x<-1 或 x>2   在 x=-1 处 y=2（空心）
                → 值域 ( 2 , +∞ )

          合并：  [-9/4 , 0 ]  ∪  (2 , +∞)
        ```

### 分段函数里的参数 a

* **条件确定时直接算**

    * $f(x)=\begin{cases}3x+2, & x<1 \\ 2x^2, & x\ge 1\end{cases}$，条件为 $f(f(0))=4a$。

    * $f(0)$：$0$ 满足 $x<1$，代入第一段得 $f(0)=3\times0+2=2$。

    * 所以 $f(f(0))=f(2)$，$2\ge1$ 代入第二段得 $f(2)=2\times2^2=8$。

    * 由 $4a=8$ 得 $a=2$。

* **条件含参数时分类讨论**

    * 条件改成 $f(f(a))=4a$ 时，不知道 $a$ 比 1 小还是比 1 大，必须硬着头皮分类讨论。

    * 情况① $a<1$：$f(a)=3a+2$。再分 1.1 与 1.2。

    * 1.1 $3a+2<1$ 即 $a<-\dfrac13$：$f(f(a))=f(3a+2)=3(3a+2)+2=9a+8=4a$，得 $5a=-8$，$a=-\dfrac85$；检验 $-\dfrac85<1$ 与 $-\dfrac85<-\dfrac13$ 都成立。

    * 1.2 $3a+2\ge1$ 即 $a\ge-\dfrac13$：$f(f(a))=2(3a+2)^2=4a$，即 $9a^2+10a+4=0$，$\Delta=100-144=-44<0$，无解。

    * 情况② $a\ge1$：$f(a)=2a^2$。

    * > **提示**：处在 $a\ge1$ 这个前提里，$2a^2\ge2>1$ 是白送的信息，直接用它替代机械分类，省掉一整层讨论。

    * 于是 $f(2a^2)=2(2a^2)^2=8a^4=4a$，移项除以 $2a$ 得 $2a^3-a^2=0$，即 $a^2(2a-1)=0$，$a=0$ 或 $a=\dfrac12$ 都不满足 $a\ge1$，无解。

    * 最终答案 $a=-\dfrac85$。

        ```text
          f(f(a)) = 4a 的分类讨论树

          情况①：a < 1
             └─ f(a) = 3a+2
                ├─ 1.1  3a+2 < 1  (a < -1/3)
                │        f(f(a)) = f(3a+2) = 3(3a+2)+2 = 9a+8 = 4a
                │        ⇒ 5a = -8 ⇒ a = -8/5
                │        检验：-8/5 < 1 ✓   -8/5 < -1/3 ✓   成立
                │
                └─ 1.2  3a+2 ≥ 1  (a ≥ -1/3)
                         f(f(a)) = 2(3a+2)² = 4a
                         ⇒ 9a²+10a+4 = 0 ,  Δ = 100-144 = -44 < 0
                         ⇒ 无解

          情况②：a ≥ 1
                └─ f(a) = 2a²
                   2a² ≥ 2 > 1（不用再分了！）→ f(2a²) = 2(2a²)² = 8a⁴
                   8a⁴ = 4a ⇒ 2a³ = a² ⇒ a²(2a-1) = 0
                   ⇒ a = 0 或 a = 1/2，都不符合 a ≥ 1，无解

          最终答案：  a = -8/5
        ```

### 压轴：f(f(a)) − f(a) + 2 = 0

* **第一步换元**

    * $f(x)=\begin{cases}x^2+2x, & x\le 0 \\ -x^2, & x>0\end{cases}$，求 $f(f(a))-f(a)+2=0$ 的解。

    * 式子中前后两个 $f(a)$ 是同一个东西，反复出现的复杂部分用**换元**处理。

    * 设 $f(a)=m$，方程变成 $f(m)-m+2=0$，即 $f(m)=m-2$。

* **两轮分类**

    * 第一轮求 $m$：$f(m)$ 有两段解析式，带哪一段不知道，分两种情况。

    * $m\le0$ 时用第一段：$m^2+2m-m+2=0$，即 $m^2+m+2=0$，$\Delta<0$ 无解，这种情况不成立。

    * $m>0$ 时用第二段：$-m^2-m+2=0$，两边乘 $-1$ 得 $m^2+m-2=0$，因式分解 $(m+2)(m-1)=0$。

    * 因第二种情况要求 $m>0$，舍去 $m=2$，取 $m=1$。

    * 第二轮求 $a$：由 $f(a)=1$ 重复同样的操作，再分类一次。

    * $a\le0$ 时 $a^2+2a=1$，即 $a^2+2a-1=0$，求根公式得 $a=-1\pm\sqrt2$；因该分支要求 $a\le0$，取 $a=1-\sqrt2$。

    * $a>0$ 时 $-a^2=1$ 即 $a^2=-1$，无解，舍去。

    * 最终 $a=\boxed{1-\sqrt2}$。

    * 完整流程：一个式子中不断重复的复杂部分用换元；换元建立新老变量关系后去解方程；解方程要先知道解析式是啥，带哪段不知道就分类讨论；分完类求出 $m$ 再回过来用同样方法求 $a$。

        ```text
           f(x) = { x²+2x ,  x ≤ 0
                    { -x²   ,  x > 0

            y ▲
              │╲
              │ ╲          ╱│
              │  ╲        ╱ │
       ───────┼───╲──────╱──┼────► x
            (-2)│ ╲   ╱    │        抛物线在负半轴
                │  ╲_╱     │        开口向上，过 (0,0)
                │   ●(0,0) │
          另一支：x>0 的 -x² 只保留正半轴那一段
        ```

### 数形结合：换成画图看

* **化为两图像求交点**

    * 把 $f(m)=m-2$ 看成两个函数 $y=f(m)$ 与 $y=m-2$ 相等，即取它们的交点。

    * $y=x^2+2x$ 因式分解知有两个零点 $x=0$ 与 $x=2$，在负半轴画开口向上的抛物线。

    * $y=-x^2$ 只保留 $x>0$ 的正半轴那一段，负半轴部分擦掉。

    * $y=m-2$ 是一条斜率为 $1$ 的上升直线。

* **读图结论**

    * 直线只与下边那支抛物线有交点，与另一支没有交点，所以第一种情况（$m\le0$）算都不用算即可判无解。

    * 交点对应的 $m=1$。

    * 求 $a$ 时回到 $y=f(x)$ 图像上找函数值为 $1$ 的点，只有第一段上有解，第二段带进去无解。

    * 具体计算仍要正经做：用对应解析式等于函数值 1，通过求根公式算出 $a$。

    * > **提示**：画图能出奇制胜，解决分段函数、复合函数难题时往往有效；图像交点与解方程的关系会在函数应用的内容里专门讲。

## 分式函数的值域

### 总思路：截图像，看图说话

* **两步走流程**

    * 值域指的是 $y$ 的取值范围；求值域基本上都要通过画图，从图像上看 $y$ 的范围。

    * 第一步按题目给的 $x$ 区间把对应的图像截出来，题目要哪段就画哪段。

    * 第二步找最高点和最低点，并判断两端能不能取到。

        ```text
           ① 截图像 —— 把题目给的 x 区间对应的那一段抠出来
                        │
                        ▼
           ② 看图说话 —— 找最高点 / 最低点
                        │
                        ▼
           ③ 定开闭 —— 实心点取得到，空心点取不到
        ```

### 反比例函数

* **基本性质**

    * > **定义**：反比例函数 $y=\dfrac1x$ 的两条渐近线是 $x=0$ 与 $y=0$。

    * > **易错点**：反比例函数永远不与 $x$ 轴相交，只可能无限趋近，所以 $0$ 永远取不到。

    * 另一个端点取不取到，完全看题目给的区间在端点处是开是闭。

* **算例**

    * $x\in[3,+\infty)$：图像是从 $\left(3,\dfrac13\right)$ 往右上方走的一段，最低点 $\dfrac13$ 能取到，最高无限趋近于 $0$，值域 $\left[\dfrac13,+\infty\right)$。

    * $x\in(-\infty,-2]\cup(0,3)$：第一段最低点 $x=-2$ 得 $-\dfrac12$（闭区间取到），向上无限趋近 $0$（取不到）；第二段 $x=3$ 处为 $\dfrac13$ 但区间开所以取不到，往左无限趋近 $+\infty$。

    * 所以值域是 $-\dfrac12\le y<0$ 或 $\dfrac13<y<+\infty$。

### 一次比一次型

* **拆分子的变形**

    * > **结论**：一次比一次型函数一定是由反比例函数左右上下平移得到的。

    * 变形原则是分母不动，把分子拆成分母的形式、往分母上凑。

    * $\dfrac{2x-3}{x+1}=2-\dfrac5{x+1}$：分子凑分母倍数时 $1$ 要补成 $2$，再补 $-5$ 才与原式一致。

    * 对 $x$ 加减相当于左右平移，左加右减；对函数整体加减相当于上下平移，上加下减。

    * 上式中基础函数是 $-\dfrac5x$，先对 $x$ 加 $1$（向左平移一个单位），再整体加 $2$（向上平移两个单位），渐近线变成 $x=-1$ 与 $y=2$，图像经过二四象限。

        ```text
                y                                 y
                │                                 │
                │  ╲                              │   ╲
                │   ╲    y = -5/x                 │    ╲    y = -5/(x+1) + 2
          ──────┼────╲────────→ x         ───────┼─────╲──────→ x
                │     ╲                           │      ╲
                │      ╲                          │       ╲   ← 整体上移 2
                │       ╲                         │
                │        ╱                        │       ╱
                │      ╱                          │      ╱
                │    ╱                            │    ╱
                      x = 0                             x = -1

           渐近线：x = 0, y = 0            渐近线：x = -1, y = 2
        ```

* **书写顺序的干扰**

    * > **易错点**：不要被函数形式迷惑。$\dfrac{2-3x}{2x-3}$ 上下都是一次函数，写成 $-3x+2$ 就一眼看清了。

### 一步到位的作图法

* **两步定位图像**

    * 逐步平移法要先对式子做变形、再逐张画图，做题过程多。

    * 一步到位法分两步：先找两条渐近线，再找特殊点。

    * 竖直渐近线：图像断开处，就是 $x$ 取不到的值，直接看分母的零点。

    * 水平渐近线：$x$ 取很大时无限趋近的值，只看最高次项 $x$ 前面的系数之比。

    * > **提示**：对特别大的数，给它加个 $1$、减个 $3$ 对整体没有影响，所以 $\dfrac{2x-3}{x+1}$ 在 $x$ 取 100、1000、10000 时都约等于 $\dfrac{2x}{x}=2$。

    * 特殊点一般取 $y$ 轴截距，用来定图像经过哪几个象限。

* **算例**

    * 例一 $y=\dfrac{x+1}{2x-1}$：竖直渐近线 $x=\dfrac12$，水平渐近线取系数比 $1:2=\dfrac12$；令 $x=0$ 得 $y=-1$，图像经过 $(0,-1)$，故经过二四象限。

    * 例二 $y=\dfrac{2-3x}{2x-3}$：竖直渐近线 $x=\dfrac32$，水平渐近线 $-3:2=-\dfrac32$；令 $x=0$ 得 $y=-\dfrac23$ 是负值，只能经过二四象限。

    * 求值域示例（例二，$x\in(3,+\infty)$）：最低点在 $x=3$ 处，值为 $\dfrac{2-3\times3}{2\times3-3}=-\dfrac73$；最高无限趋近水平渐近线，不可能超过它。

    * 值域是 $\left(-\dfrac73,-\dfrac32\right)$：$-\dfrac73$ 开是因为 $3$ 是开区间端点取不到，$-\dfrac32$ 开是因为只能无限趋近、不能穿过。

* **两种作图法的取舍**

    * > **结论**：方法一是一步一步看函数如何由反比例函数平移而来，过程较复杂；方法是先画水平与竖直渐近线，再找特殊点（一般是 $y$ 轴截距），直接把图像画出来。

### 对勾函数

* **定义与性质**

    * > **定义**：$y=ax+\dfrac{b}{x}$（$a,b>0$）这类「正比例函数 + 反比例函数」形式的函数图像形似对勾，称为对勾函数。

    * 只要发现有一个正比例函数加上或减去一个反比例函数，就是对勾或双刀。

    * 关于原点中心对称，经过一三象限，两条渐近线：一条无限趋近于 $y$ 轴，另一条是 $y=\dfrac{b}{a}x$。

    * 第一象限内函数值先越来越小、后越来越大，能取到一个最低点。

* **画法与最低点**

    * 画法三步：先画 $y=ax$，再画 $y=\dfrac bx$，最后把两图像作**加法**（函数值相加）。

    * 第一象限内两函数值都是正数，新图像必然比任何一条都高；$(0,1)$ 内贴着反比例图像上方画，经过 $(1,1)$ 后贴着直线略上方走，整体形似小对勾。

    * 最低点来自基本不等式：$ax+\dfrac bx\ge2\sqrt{ab}$，当且仅当 $ax=\dfrac bx$ 即 $x=\pm\sqrt{\dfrac ba}$ 时取到。

    * $x+\dfrac1x\ge2$，在 $x=\pm1$ 取到；第三象限对应点为 $(-1,-2)$。

    * $x+\dfrac4x\ge4$，在 $x=\pm2$ 取到。

    * $2x+\dfrac3x\ge2\sqrt6$，在 $x=\pm\dfrac{\sqrt6}{2}$ 取到；也可以直接把 $x$ 代进去求 $y$ 坐标。

    * > **结论**：对勾函数是高一阶段最重要的函数之一，从高一到高三都要反复利用它的性质和图像，画图是解决其问题的第一步。

### 双刀函数

* **定义与性质**

    * > **定义**：$y=ax-\dfrac bx$ 中间换成减号，图像形似两条飘带，也叫飘带函数。

    * $x$ 为正时递增，$x$ 为负时也递增，是中心对称图形。

    * > **易错点**：双刀函数是**递增**的，别跟对勾函数搞混——对勾是第一象限先减后增、有最低点，双刀是两头都往上走。

    * 见到正比例函数减去一个反比例函数，如 $2x-\dfrac3x$，直接画成两个小飘带。

### 化归到对勾

* **拆分子化为对勾加平移**

    * 分子复杂分母简单时就拆分子，利用「它除以它加上它除以它加上它除以它」。

    * $\dfrac{x^2+2x+3}{x}=\dfrac{x^2}{x}+\dfrac3x+\dfrac{2x}{x}=x+\dfrac3x+2$，即对勾函数整体上移 $2$ 个单位。

    * 最低点、最高点在两坨相等时取得：$x=\pm\sqrt3$，$\sqrt3$ 处函数值 $2\sqrt3$，上移后为 $2\sqrt3+2$；$-\sqrt3$ 处为 $-2\sqrt3$，上移后也不会超过 $2\sqrt3$。

* **截图像求值域**

    * 题目给 $x\in[2,+\infty)$，只关心第一象限 $2$ 之后那一段（因为 $2>\sqrt3\approx1.73$）。

    * 最小值在所取区间的端点 $x=2$ 处取得：$\dfrac{4+4+3}{2}=\dfrac{11}{2}$。

    * 值域为 $\left[\dfrac{11}{2},+\infty\right)$。

* **基本不等式的死角**

    * > **结论**：基本不等式的使用条件有一定局限性；画了完整图像的对勾函数没有局限性——基本不等式能做的题对勾全能做，对勾能做的题基本不等式不一定能做。

    * 基本不等式给出的 $2\sqrt3+2$ 只适用于 $x>0$ 的整段图像的最低点；一旦只取其中一段，最小值就落在所取区间的端点处。

### 二次比一次

* **整体换元化简**

    * 分母太简单时，出题人可能把 $x$ 变成 $x+1$、$x+2$、$2x+1$ 等，处理思路与基本不等式一致：整体换元。

    * 令整个 $x+1$ 设成 $m$，则 $x=m-1$，把所有 $x$ 全换成 $m-1$。

    * $\dfrac{x^2+4x+6}{x+1}=\dfrac{(m-1)^2+4(m-1)+6}{m}=\dfrac{m^2+2m+3}{m}=m+2+\dfrac3m$。

    * 分子化简：$m^2-2m+1+4m-4+6=m^2+2m+3$；合并同类项后拆分子即得对勾加常数。

* **新变量也要有范围**

    * 用换元后横轴不再是 $x$ 轴而是 $m$ 轴。

    * > **易错点**：题目给 $x$ 的范围是 $[0,1]$，则 $m=x+1$ 的范围是 $[1,2]$（两边都加 1）。换元后新变量一定有取值范围，不求这个范围，最后截图像必截错，整道题就错了。

* **截图像求值域**

    * 先判断最低点：两坨相等时取等号，$m=\sqrt3$ 正好落在 $[1,2]$ 内。

    * 最小值 $m=\sqrt3$ 处为 $\sqrt3+\dfrac3{\sqrt3}+2=2\sqrt3+2$。

    * > **提示**：最大值不能凭草图判断，草图上看着 $2$ 更大，但实际可能相反，一定要算一算比一比。

    * $m=1$ 处 $1+3+2=6$；$m=2$ 处 $2+\dfrac32+2=5.5$，所以最大值是 $6$。

    * 值域为 $[2\sqrt3+2,\ 6]$，两端实心点全都取得到。

### 一次比二次

* **同除换成倒数**

    * 一次项在哪就把哪换元：设整个 $x-1=m$，则 $x=m+1$。

    * 新变量范围：$x\in(0,1]$ 时 $m=x-1\in(-1,0]$。

    * $\dfrac{x-1}{x^2-x+4}$ 换成 $\dfrac{m}{m^2+m+4}$，此时分子是单项式，用上下同时除以分子这一步非常关键。

    * 同除 $m$ 得 $\dfrac{1}{m+1+\dfrac4m}$。

* **剥洋葱三步求范围**

    * 第一步求对勾 $m+\dfrac4m$ 在 $m\in(-1,0)$ 上的范围：截第三象限那一段，最高点在 $m$ 接近 $-1$ 处趋近，$-1$ 是空心点取不到，代入得 $-1+(-4)=-5$，故范围 $(-\infty,-5)$。

    * 第二步加 $1$：两个端点都加 1，负无穷加 1 还是负无穷，$-5+1=-4$，得 $(-\infty,-4)$。

    * 第三步取倒数：设 $t=m+1+\dfrac4m\in(-\infty,-4)$，则 $y=\dfrac1t$ 是反比例函数，在一三象限截 $t$ 为负的一段。

    * 最小值在 $t=-4$ 处趋近 $-\dfrac14$ 但取不到，最大值无限趋近 $0$。

    * 最终值域为 $\left(-\dfrac14,\,0\right)$，都是开区间。

    * > **结论**：二次比一次与一次比二次两个题型形态不同，共同点是**把一次项整体换元**，并且必须求出新变量的取值范围。

### 二次比二次：凑分母

* **凑分母造出一次项**

    * 二次比二次没有一次项，不能直接换元，要人为找到一次项，方法叫「凑分母」。

    * 分母不能动，任务是把分子凑成分母的倍数：$2x^2+9x+13=2(x^2+4x+6)+(x+1)$。

    * 拆分子：$\dfrac{2x^2+9x+13}{x^2+4x+6}=\dfrac{2(x^2+4x+6)+(x+1)}{x^2+4x+6}=2+\dfrac{x+1}{x^2+4x+6}$。

    * 第二项又变成一次比二次，按老办法处理：一次项整体换元，设 $x+1=m$，由 $x$ 的范围求得 $m$ 的范围为 1 到 2。

* **取倒数求值域**

    * > **提示**：这个式子与二次比一次那题 $\dfrac{x^2+4x+6}{x+1}$ 互为倒数，分子分母调了个个儿而已。

    * 已知 $\dfrac{x^2+4x+6}{x+1}$ 在给定范围上的值域是 $[2\sqrt3+2,\ 6]$，取倒数把两个端点分别取倒数，得 $\left(\dfrac16,\ \dfrac1{2\sqrt3+2}\right)$。

    * > **提示**：原来大的数取完倒数反而小，原来小的数取完倒数反而变大，所以端点次序要对调。

    * 最后整体加 $2$：$\dfrac16+2=\dfrac{13}{6}$；$\dfrac1{2\sqrt3+2}=\dfrac{\sqrt3-1}{4}$（需分母有理化），加上 $2$ 得 $\dfrac{7+\sqrt3}{4}$。

    * 值域为 $\left(\dfrac{13}{6},\ \dfrac{7+\sqrt3}{4}\right)$。

### 分式函数求值域总表

* **类型与核心动作**

    | 函数类型 | 求值域的核心动作 |
    | :--- | :--- |
    | 反比例函数 | 直接画图，两条渐近线是 $x=0$ 与 $y=0$ |
    | 一次比一次 | 先找两条渐近线（分母零点、最高次系数之比），再找 $y$ 轴截距定象限 |
    | 二次比一次 | 拆分子化成对勾 → **把二次项整体换元**，然后求新变量的范围 |
    | 一次比二次 | 分子分母同除一次项 → 换成倒数 → **把一次项整体换元**，然后求新变量的范围 |
    | 二次比二次 | **凑分母**把分子凑成分母倍数，拆成常数加一次比二次型，再换元 |

* **反复出现的口诀**

    * 画图是第一步，截图像是第二步，看图说话定开闭。

    * 最容易翻车的地方只有一个：换元之后千万别忘了求新变量的取值范围。

* **课后练习类型**

    * 分式函数这一部分的作业题是四道同一类型的题：在给定的定义域范围内求出函数整体的值域。
