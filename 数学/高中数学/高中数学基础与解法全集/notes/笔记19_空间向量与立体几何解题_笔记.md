# 空间向量与立体几何解题

## 空间向量与平面向量的迁移

* **向量（vector）**

    * > **定义**：既有大小又有方向的量。

* **平面向量与空间向量**

    * 平面向量：起点与终点都取在一个平面内的向量。
    * 空间向量：起点与终点在整个三维空间中的向量。
    * 平面向量成立的性质，空间向量几乎一条不少地全部成立。

    ```text
            二维：一个平面里画箭头                  三维：整个空间里画箭头

                  B                                        B
                  ↑                                       ╱ ↑
            A ────┼────►                          A ────┼────►
              只谈方向和长短                    不在同一个"面"里，规则完全一样
    ```

* **空间向量的两类运算**

    * 线性运算：加法、减法、乘一个实数。
    * 数量积：$\vec{a}\cdot\vec{b}=|\vec{a}||\vec{b}|\cos\theta$。
    * 数量积是标量，线性运算的结果仍是向量。

## 加、减、数乘与分解

* **加法的两条法则**

    * 平行四边形法则：两个向量凑成共起点，补成平行四边形，对角线即为和向量，与物理中力的合成一致。
    * 三角形法则：不共起点时首尾相接，从第一个向量的起点直连最后一个向量的终点。
    * 例：$\vec{AB_1}+\vec{B_1C}=\vec{AC}$。

* **减法**

    * > **定义**：$\vec{a}-\vec{b}$ 就是 $\vec{a}+(-\vec{b})$。

    * $-\vec{b}$ 大小不变、方向相反；两个向量首尾相接后直连两端。
    * > **提示**：箭头落在第一个向量的终点上，$\vec{DC_1}$ 那一端没有箭头。
    * 空间情形相同：$\vec{DA_1}-\vec{DC_1}$ 把两个终点连起来，指向 $\vec{DA_1}$。

* **数乘**

    * 长度按比例伸缩，方向不变；乘负数方向反转。
    * 大小与方向都相同即**相等向量**，如棱柱中 $\vec{DA_1}=\vec{CB_1}$。
    * 上底面中心 $O$ 满足 $\vec{A_1O}=\frac12\overrightarrow{A_1C_1}$，故 $\overrightarrow{A_1C_1}$ 是 $\vec{A_1O}$ 的 $2$ 倍。

* **分解**

    * > **结论**：合并与分解是线性运算的一体两面。

    ```text
       近路（沿一条棱）：   D₁ ─────────────► A
                            = D₁A₁ + A₁A

       绕远（多走一段）：   D₁ ─────► B ─────► A
                            = D₁B + BA

       更远（走三段）：     D₁ ─► C₁ ─► C ─► B ─► A
                            = D₁C₁ + C₁C + CB + BA

       走法不唯一，但最后必须回到 A
    ```

## 基底与空间向量基本定理

* **空间向量的基本定理**

    * > **定义**：三维空间中任意三个不共线的向量都可以作为一组基底；空间中任意一个向量都能被这三个向量**唯一**地线性表示。

    ```text
       平面：2 个基底向量 → 表示任意向量              空间：3 个基底向量 → 表示任意向量（唯一）
              ↗ ↘                                            ↗  ↓  ↘
             a   b                                          a   b   c
    ```

* **选基底的位置信号**

    * 条件汇集最密集的那个点就是基底顶点：多个已知夹角、相等长度都发自同一点时，以该点为核心选基底。
    * 三棱柱中 $\angle BAA_1=\angle CAA_1=60^\circ$ 加正三角形底面，三个 $60^\circ$ 集中在 $A$ 点，故取 $\vec{AA_1}=\vec{a}$、$\vec{AB}=\vec{b}$、$\vec{AC}=\vec{c}$。
    * 分解完成后所有几何问题都退化成基底之间的代数运算。

* **三角形中线的向量式**

    * $\vec{ON}=\frac12\vec{OB}+\frac12\vec{OC}$，即 $\vec{OB}+\vec{OC}=2\vec{ON}$。
    * 空间四边形 $OABC$ 中 $M$ 为 $OA$ 中点、$N$ 为 $BC$ 中点时，走 $M\to O\to N$ 得 $\vec{MO}=-\frac12\vec{a}$、$\vec{ON}=\frac12\vec{b}+\frac12\vec{c}$。
    * 沿棱走 $M\to A\to B\to N$ 得同样结果：$\vec{MA}=\frac12\vec{a}$、$\vec{AB}=\vec{b}-\vec{a}$、$\vec{BN}=\frac12(\vec{c}-\vec{b})$。
    * > **易错点**：两条走法答案必须一致；不一致说明某一段的符号或长度出错。若"终点减起点"没跟上，问题出在平面向量而非空间向量。

## 数量积与夹角

* **数量积及其逆用**

    * 正用：$\vec{a}\cdot\vec{b}=|\vec{a}||\vec{b}|\cos\theta$。
    * 逆用：$\cos\theta=\dfrac{\vec{a}\cdot\vec{b}}{|\vec{a}||\vec{b}|}$。
    * 求夹角固定两步：先求数量积，再求两个模长，作比即得。
    * 线线角、异面直线所成角、线面角全部可由这一式解决，无需分析几何关系。

* **模长的计算**

    * 完全平方公式：$|\vec{a}+\vec{b}|=\sqrt{\vec{a}^2+\vec{b}^2+2\vec{a}\cdot\vec{b}}$（依据向量与自身夹角为 $0^\circ$、$\cos 0^\circ=1$）。
    * 三项展开：$|\vec{a}-\vec{b}+\vec{c}|=\sqrt{\vec{a}^2+\vec{b}^2+\vec{c}^2-2\vec{a}\cdot\vec{b}+2\vec{a}\cdot\vec{c}-2\vec{b}\cdot\vec{c}}$。
    * > **结论**：用向量求线段长度是高考立体几何大题的常见考法。

* **三个 $60^\circ$ 撑起来的基底**

    * 三棱柱底面边长等于侧棱长且 $\angle BAA_1=\angle CAA_1=60^\circ$：底面是正三角形，侧面是菱形，$\vec{a}$、$\vec{b}$、$\vec{c}$ 模长均为 $1$、两两数量积均为 $\frac12$、各自平方均为 $1$。
    * 分解：$\vec{AB_1}=\vec{a}+\vec{b}$，$\vec{BC_1}=\vec{a}-\vec{b}+\vec{c}$。
    * 展开六项后 $\vec{a}^2$ 与 $-\vec{b}^2$ 约掉、$\vec{a}\cdot\vec{b}$ 与 $-\vec{a}\cdot\vec{b}$ 约掉，余三项各 $\frac12$，得数量积为 $1$。
    * 两模长分别为 $\sqrt3$ 与 $\sqrt2$，故 $\cos\theta=\dfrac{1}{\sqrt6}=\dfrac{\sqrt6}6$。
    * 正方体棱长 $1$ 时 $\vec{D_1A}$ 与 $\vec{D_1C_1}$ 模长均为 $\sqrt2$、$D_1AC_1$ 为正三角形夹角 $60^\circ$，数量积为 $1$。
    * > **提示**：此类题会故意把向量放在不共起点的位置；求数量积、模长时凡是不好求的量，一律先分解成基底。

## 空间直角坐标系

* **建系的前提**

    * 三维用三根两两互相垂直的轴，只有正方体、长方体这类图形天然满足。
    * > **易错点**：题目没有说明几条线两两垂直时绝不能建系，硬建一分拿不到；空间向量法用不了的题只能回到几何法。
    * 空间向量法失效的两类情形：动点非常多无法找到墙角模型；可以建系但必须先证垂直，证明本身仍需传统立体几何手法。

* **三轴的顺序**

    * > **定义**：坐标轴有先后顺序，不可随意排列组合。

    * $z$ 轴取竖直方向；$x$、$y$ 由右手定则确定。
    * 大拇指与 $z$ 轴同向，四指转 $90^\circ$ 握拳，**先碰到的轴为 $x$，后碰到的为 $y$**，顺序不能乱。

    ```text
       两根筷子代表 x 轴和 y 轴，牙刷代表 z 轴（筷子立不住）

             ║  ← 牙刷 = z 轴
             ║
         ════╬════      桌面
           ╱   ╲
         筷子1  筷子2      = x 轴 / y 轴（还没定谁是谁）

       操作：① 大拇指摆在 z 轴同方向上
             ② 四指转动 90°，握成拳
             ③ 四指先碰到的轴 → x 轴
                四指后碰到的轴 → y 轴
    ```

    * 长方体三棱长 $2:1:1$ 时以一顶点为原点，竖棱作 $z$ 轴，余下两轴由转 $90^\circ$ 时先划过的定 $x$、后划过的定 $y$。

* **四类点的坐标读取**

    * 坐标轴上的点：只看所在轴的分量，其余为 $0$，如 $A(1,0,0)$、$C(0,2,0)$、$D_1(0,0,1)$。
    * 两轴所成平面上的点：第三个分量为 $0$，如 $xOy$ 面内的 $B(1,2,0)$。
    * $xOz$ 这类面内的点：$y$ 分量为 $0$，如 $A_1(1,0,1)$、$C_1(0,2,1)$。
    * 空间任意一点：用投影读数，$B_1$ 是 $B$ 竖直抬高一个单位，得 $B_1(1,2,1)$；从 $xOz$ 面投影看它落在 $A_1$ 上再沿 $y$ 平移 $2$，结果同为 $(1,2,1)$。
    * > **提示**：同一道题换两个方向读必须一致，这是极好的自查手段。

* **向量坐标与坐标下的线性运算**

    * 向量坐标 = 终点坐标逐项减起点坐标。
    * 中点坐标 = 两端点对应坐标取平均，如 $N\left(\frac{\sqrt3}{2},-\frac12,2\right)$。
    * 加减按对应项直接运算，数乘每个分量同乘一个数；空间模长是**三个平方和再开根号**（勾股定理的推广），别少加一项。

    | 运算 | 计算 | 结果 |
    | :--- | :--- | :--- |
    | $\vec{a}=(1,0,2)$ 的模长 | $\sqrt{1^2+0^2+2^2}$ | $\sqrt5$ |
    | $\vec{b}=(-1,3,1)$ 的模长 | $\sqrt{(-1)^2+3^2+1^2}$ | $\sqrt{11}$ |
    | $\vec{a}+\vec{b}$ | $(-1+1,\,0+3,\,2+1)$ | $(0,3,3)$ |
    | $\vec{a}-\vec{b}$ | $(1-(-1),\,0-3,\,2-1)$ | $(2,-3,1)$ |
    | $\vec{a}+2\vec{b}$ | $(1-2,\,0+6,\,2+2)$ | $(-1,6,4)$ |
    | $3\vec{a}$ | 每个坐标乘 $3$ | $(3,0,6)$ |

* **坐标下的数量积**

    * $\vec{a}=(x_1,y_1,z_1)$、$\vec{b}=(x_2,y_2,z_2)$ 时 $\vec{a}\cdot\vec{b}=x_1x_2+y_1y_2+z_1z_2$。
    * 长方体 $AB=2$、另两棱为 $1$，$E$ 为 $A_1C$ 中点时：$A(1,0,0)$、$B(1,2,0)$、$D_1(0,0,1)$、$A_1(1,0,1)$、$C(0,2,0)$、$E\left(\frac12,1,\frac12\right)$；$\vec{AD_1}=(-1,0,1)$、$\vec{BE}=\left(-\frac12,-1,\frac12\right)$，数量积 $1$，模长 $\sqrt2$ 与 $\sqrt{\frac32}$，故 $\cos\theta=\frac{\sqrt3}3$。
    * > **结论**：建系免去了"先求模长再求夹角"的迂回，坐标写出后 $x\cdot x+y\cdot y+z\cdot z$ 即可。
    * > **提示**：平移法能用但费劲时（平移后三角形不好解）就该换空间向量法。

* **三套办法的分工**

    | 场景 | 用哪套 | 前提 |
    | :--- | :--- | :--- |
    | 图形方正、有三条两两垂直的线 | 建系法：点坐标 → 向量坐标 → 数量积 | 系建得起来 |
    | 图形不规则但某点条件密集 | 选基底法：分解成基底 → 基底间运算 | 能找到三个不共线向量 |
    | 图形歪斜、系建不了 | 平移加解三角形 | 传统几何老老实实用 |

    * 建系最省力；建不了系退回选基底；基底也不好找的用平移法。
    * 数量积的正经用途是求角度——线线角、异面直线所成角、线面角、二面角全靠它。

## 方向向量与法向量

* **方向向量**

    * > **定义**：直线上两点所确定的向量叫做这条直线的方向向量。

    * 求法：把两点坐标写出，终点减起点。长宽高比 $1:2:1$ 的长方体中 $A_1C$ 的方向向量为 $\vec{A_1C}=(-1,2,-1)$。

* **法向量**

    * > **定义**：跟平面垂直的向量叫做这个平面的法向量。

    * 不能用面上两点构成的向量代表该面：过该向量的平面有无数个，无法确定是哪一个面。
    * 同一个面有无数个法向量，长短、朝向都可不同；只要法向量所代表的直线方向确定，面的方向就随之确定。

    ```text
       线  →  方向向量（躺在线上，起点→终点）
       面  →  法  向量（悬在面上，垂直于面）

       方向向量 · 方向向量   与  线的平行 / 垂直
       方向向量 · 法  向量   与  线面的平行 / 垂直
       法  向量 · 法  向量   与  面的平行 / 垂直
    ```

* **六种平行垂直结论的翻译**

    | 要证的结论 | 取什么向量 | 转化为 |
    | :--- | :--- | :--- |
    | 线线平行 | 两条直线的方向向量 | 两向量平行 |
    | 线面平行 | 直线方向向量、面的法向量 | 两向量垂直（数量积为 $0$） |
    | 面面平行 | 两个面的法向量 | 两法向量平行 |
    | 线线垂直 | 两条直线的方向向量 | 两向量垂直（数量积为 $0$） |
    | 线面垂直 | 直线方向向量、面的法向量 | 两向量平行 |
    | 面面垂直 | 两个面的法向量 | 两法向量垂直（数量积为 $0$） |

    * 六种情况全是"方向向量"与"法向量"的搭配；所有垂直关系最终都落在"数量积等于 $0$"。
    * > **注意**：证线面平行时不直接证线面关系，只需证该直线的方向向量与面的法向量垂直。

* **求法向量的原始方法**

    * 本质是找这个面的垂线；由垂线判定定理，与面上两条相交直线都垂直即可。
    * 三步：面上取两个方向向量 $\vec{a}$、$\vec{b}$；设 $\vec{n}=(x,y,z)$ 与它们数量积为 $0$，列两个方程；解出 $x,y,z$。
    * 边长比 $2:1:1$ 的长方体中面 $A_1C_1B$：$A_1(1,0,1)$、$B(1,2,0)$、$C_1(0,2,1)$，取 $\vec{BC_1}=(-1,0,1)$、$\vec{BA_1}=(0,-2,1)$，方程 $-x+z=0$、$-2y+z=0$，令 $x=1$ 得 $\vec{n}=\left(1,\frac12,1\right)$。
    * > **提示**：两个方程解三个未知数是正常的，法向量本就不唯一，求出其中一个即可。

* **叉乘速算法**

    * 三句口诀：每个向量写两遍 → 掐头去尾留中间 → 交叉相乘再相减。
    * 结果只与 $\vec{a}$、$\vec{b}$ 的六个分量有关：

    ```text
       ① 每个向量写两遍：
            a1    a2    a3    |   a1    a2    a3
            b1    b2    b3    |   b1    b2    b3

       ② 掐头去尾留中间（保留中间四列）：
            a2    a3    a1    a2
            b2    b3    b1    b2

       ③ 交叉相乘再相减：
            x = a2·b3 − a3·b2
            y = a3·b1 − a1·b3
            z = a1·b2 − a2·b1
    ```

    * > **易错点**：谁减谁必须顺序一致，一般是"这个方向相乘减去那个方向相乘"；可用画叉辅助记忆——先画到的两条先乘。算完要验算对应项相乘是否为 $0$。
    * $\vec{a}=(1,2,1)$、$\vec{b}=(-1,0,3)$ 得 $(6,-4,2)$，各项均有公因子 $2$，约去后得 $(3,-2,1)$。
    * $\vec{a}=(-1,0,1)$、$\vec{b}=(0,-2,1)$ 得 $(2,1,2)$，与原始方法的 $\left(1,\frac12,1\right)$ 同向。
    * $\vec{a}=(1,\sqrt3,0)$、$\vec{b}=(-2,\sqrt3,3)$ 得 $(\sqrt3,-1,\sqrt3)$。
    * 该运算即线性代数中的叉乘运算。

* **书写规范**

    * 立体几何考大题，原始方法的列方程过程必须写出来；速算法只用于验算。
    * 建系之前要写一段传统几何证明：抄题给的面面垂直，推出线线垂直，并说明这两条线都在该面内。

    ```text
       满分建系说明模板：

       因为 平面 △ ⊥ 平面 □（抄题）
       所以 CC₁ ⊥ CA，CC₁ ⊥ CB
       又 CC₁、CA、CB 都在平面 ABC 内
       故 CC₁ ⊥ 平面 ABC，可取 CC₁ 为 z 轴
    ```

    * > **易错点**：只写"以 $C$ 为原点、$CA$ 为 $x$ 轴、$CB$ 为 $y$ 轴、$CC_1$ 为 $z$ 轴"而不管垂直依据，会扣分。
    * 直三棱柱中侧棱与底面垂直时，侧棱与底面上任何一条直线都垂直。

* **一条完整流水线的顺序**

    * 写清建系依据 → 逐个写坐标（中点一律用中点坐标公式）→ 线用方向向量、面用法向量 → 最后只做一件事：数量积。
    * 是垂直时数量积为 $0$；线面平行同样落到数量积为 $0$（线平行于面当且仅当线垂直于该面法向量）。

## 动点与存在性

* **用 $\lambda$ 把三元降为一元**

    * "点在侧棱（线段）上"翻译成三点共线：设终点坐标为 $(x,y,z)$，令目标向量等于基向量的 $\lambda$ 倍。

    ```text
       动点在 EC 上运动：

       设 P(x, y, z)，则  EP = λ·EC

       EP = (x−1, y−1/2, z)        EC = (−1, 1/2, √3)
       λ·EC = (−λ, λ/2, √3λ)

       对应坐标相等：
           x = 1 − λ
           y = 1/2 + 1/2·λ
           z = √3·λ

       得  P(1−λ, 1/2 + 1/2·λ, √3·λ)     三个分量都成了 λ 的函数
    ```

    * > **结论**：把"点在棱上"翻译成向量平行关系，三个变量就压成一个参数，三元问题变成一元问题。
    * 正四棱柱（$AB=1$、高 $\sqrt3$、$E(1,\frac12,0)$、$C(0,1,0)$、$B_1(1,1,\sqrt3)$）中动点 $P$ 即按上式取 $\lambda$。

* **存在性的两种结局**

    * 解出落在 $0<\lambda<1$ 内的值，存在，位置随之确定。
    * 各分量对 $\lambda$ 提出互相矛盾的要求，不存在。

* **法向量可以直接识别，不必自己算**

    * 题目已给出线面垂直时，被垂直的那条线方向就是法向量。
    * 正四棱锥（底面正方形、侧棱为边长的 $\sqrt2$ 倍）中，$SD\perp$ 平面 $PAC$，故 $\vec{SD}=(-1,0,-\sqrt3)$ 已经是平面 $PAC$ 的法向量。
    * 侧棱 $SC$ 上是否存在点 $E$ 使 $BE\parallel$ 平面 $PAC$：设 $E(0,\lambda,\sqrt3-\sqrt3\lambda)$，则 $\vec{BE}=(-1,\lambda,\sqrt3-\sqrt3\lambda)$，由 $\vec{BE}\cdot\vec{SD}=1-3+3\lambda=0$ 得 $\lambda=\frac23$，即 $E$ 为三等分点、$SE:EC=2:1$。
    * > **结论**：选了空间向量法就要一以贯之，不中途改用几何法，否则前面的坐标全白算。
    * 正四棱锥以底面中心 $O$ 为原点、$OS$ 为 $z$ 轴时，底面边长设为 $\sqrt2$ 则 $OB=OC=1$、侧棱 $2$、高 $\sqrt3$，$S(0,0,\sqrt3)$、$B(1,0,0)$、$D(-1,0,0)$、$C(0,1,0)$、$A(0,-1,0)$。

* **三点共线定理**

    * > **定义**：若 $M$ 在直线 $AB$ 上，则存在实数 $\lambda,\mu$ 使 $\overrightarrow{OM}=\lambda\overrightarrow{OA}+\mu\overrightarrow{OB}$，且恒有 $\lambda+\mu=1$。

    * 系数分配规律：$\overrightarrow{OA}$ 前的系数看**离 $A$ 远的那一段**所占比例。
    * $AM:MB=1:2$ 时 $\overrightarrow{OM}=\frac23\overrightarrow{OA}+\frac13\overrightarrow{OB}$；$AM:MB=2:5$ 时为 $\frac27$ 与 $\frac57$。
    * 菱形底面四棱锥中 $M$ 同时与 $C,E$ 共线、与 $D,F$ 共线，连用两次：设 $\overrightarrow{PM}=m\overrightarrow{PC}+n\overrightarrow{PE}$（$m+n=1$）、$\overrightarrow{PM}=x\overrightarrow{PD}+y\overrightarrow{PF}$（$x+y=1$），代入 $\overrightarrow{PF}=\frac12\overrightarrow{PC}$、$\overrightarrow{PE}=\frac23\overrightarrow{PD}$，由 $\overrightarrow{PC}$ 与 $\overrightarrow{PD}$ 不共线比较系数得 $m=\frac y2$、$\frac{2n}3=x$，联立解出 $m=\frac14$、$n=\frac34$、$x=y=\frac12$，即 $\overrightarrow{PM}=\frac12\overrightarrow{PF}+\frac12\overrightarrow{PD}$，$M$ 是 $DF$ 中点。

## 三类角度

* **通性与根源**

    * > **定义**：只会计算两个已知向量的夹角余弦 $\cos\theta=\dfrac{\vec{a}\cdot\vec{b}}{|\vec{a}||\vec{b}|}$。

    ```text
       无论题目问什么
       ① 找方向向量（线）/ 法向量（面）
       ② 求两向量的夹角 θ 的 cos
       ③ 按口诀换算回真正的角
    ```

    * 方向向量与法向量都不唯一：方向可正可反，法向量可朝上可朝下、长度可伸缩；这个"不唯一"是全部分类讨论的根源。
    * > **结论**：三类角度的差别只在第三步换算规则——线线角与二面角不变函数名，线面角变名。

* **线线角**

    * > **定义**：两条直线所成夹角中较小的那个锐角为线线角 $\alpha$，$\alpha\in\left[0,\frac{\pi}2\right]$。

    * $\alpha$ 与 $\theta$ 或相等、或互补；求 $\sin$ 时 $\sin(\pi-\theta)=\sin\theta$，两种情况结果一致，不必区分。
    * > **结论**：线线角口诀——恒为正，加绝对值；前后函数名不变。$\cos\alpha=|\cos\theta|$，$\sin\alpha=\sin\theta$。

    * 长方体三边 $3,4,5$ 求 $BC_1$ 与 $A_1C$ 线线角：$A_1(4,0,3)$、$C(0,5,0)$、$B(4,5,0)$、$C_1(0,5,3)$，$\vec{BC_1}=(-4,0,3)$、$\vec{A_1C}=(-4,5,-3)$，$\cos\theta=\frac{7\sqrt2}{50}$，故 $\cos\alpha=\frac{7\sqrt2}{50}$，$\sin\alpha$ 由 $\sqrt{1-\cos^2\theta}$ 化简。
    * 正三棱柱棱长 $2$ 求 $CB_1$ 与 $A_1B$ 所成角余弦：$B(\sqrt3,0,0)$、$C(0,1,0)$、$A_1(0,-1,2)$、$B_1(\sqrt3,0,2)$，两向量 $(\sqrt3,1,-2)$、$(\sqrt3,-1,2)$，$\cos\theta=-\frac14$。
    * > **易错点**：算出负值不必慌，线线角必为锐角，$\cos\alpha$ 一定为正，先加绝对值，前后不变名，答案 $\frac14$。
    * > **提示**：底面是等边三角形时不必以顶点为原点，以底边中点建系往往更简单。
    * 曲池（上下底面为扇环形的柱体，圆心角 $90^\circ$、半径比 $1:2$、$AB=AA_1=1$）中求 $BE$ 与 $C_1D$ 所成角余弦：$D(2,0,0)$、$B(0,1,0)$、$C(1,0,0)$、$C_1(1,0,1)$，$E$ 的投影对应圆心角 $30^\circ$，$1:\sqrt3:2$ 得 $G(\sqrt3,1,0)$、$E(\sqrt3,1,1)$，$\vec{BE}=(\sqrt3,0,1)$、$\vec{C_1D}=(1,0,-1)$，$\cos\alpha=\frac{\sqrt6-\sqrt2}4$。
    * > **提示**：凡与圆相关的题尽量以圆心为原点建系。
    * 几何法求角度思维含量高、计算量少；空间向量法思维少、套路固定但设坐标与求解的计算量稍大。

* **线面角**

    * > **定义**：直线在平面上的投影所成的锐角（投影即在直线上取点作线面垂直，连出直角三角形）为线面角 $\alpha$，取值在 $0^\circ$ 到 $90^\circ$ 之间。

    * 求法：先求直线方向向量，再求面的法向量，算两向量夹角 $\theta$。
    * 法向量朝上时 $\alpha+\theta=90^\circ$；朝下时 $\theta$ 是外角、$\theta=\alpha+90^\circ$。两种情形 $\alpha$ 与 $\theta$ 相差 $\frac{\pi}2$ 的奇数倍。
    * > **结论**：线面角口诀——恒为正，加绝对值；要变名，前面 $\sin$ 我写 $\cos\theta$，前面 $\cos$ 我写 $\sin\theta$。
    * > **结论**：三类角度中只有线面角需要变名。

    * 棱长 $2$ 的正方体中 $E$、$F$ 为 $BC$、$CD$ 中点，求 $AC_1$ 与面 $A_1EC_1$ 线面角：$A_1(0,0,2)$、$E(2,1,0)$、$C_1(2,2,2)$，方向向量 $(2,2,2)$，面上取 $\vec{A_1C_1}=(2,2,0)$、$\vec{EC_1}=(0,1,2)$，解得法向量 $(2,-2,1)$，$\cos\theta=\frac{\sqrt3}9$，恰好是所求正弦值；若问余弦值则由平方和换算。
    * 正三棱锥 $P-ABC$ 侧面均为直角三角形、$E$、$F$ 为 $AB$、$BC$ 中点，求 $PB$ 与面 $PEF$ 线面角：$P$ 是三个直角面的汇集顶点，本身就是墙角，以 $P$ 为原点、$PA$、$PB$、$PC$ 为三轴建系。
    * > **易错点**：题目没给 $P$ 到底面的距离，要靠直角关系推侧棱长与高的关系，画图推导很别扭；倒过来以 $P$ 为原点建系即可绕开。
    * > **提示**：大量出现中点时把棱长设成 $2$ 而非 $1$，可避免中点坐标出现分数；得 $A(2,0,0)$、$B(0,2,0)$、$C(0,0,2)$、$E(1,1,0)$、$F(0,1,1)$，方向向量截取一半写作 $(0,1,0)$ 更省事，法向量 $(0,1,1)$ 与 $(1,1,0)$ 速算得 $(-1,1,-1)$，所求正弦值为 $\frac{\sqrt3}3$。

* **二面角**

    * > **定义**：二面角取值在 $0$ 到 $\pi$ 之间，锐角钝角都取得到。

    * 求 $\sin$：$0$ 到 $\pi$ 落在一、二象限，恒为正，加绝对值即可。
    * 求 $\cos$：锐角为正、钝角为负，**正负不定**，加绝对值后还要自行加正负号。
    * > **结论**：绝大多数情况下图形中锐角钝角直接可判断。

    ```text
       两面法向量共三种朝向（都以钝角作二面角 α）：

          ①  都朝里              ②  都朝外              ③  一里一外

              ╱↗ ↖╲                  ╲↗ ↖╱                  ╱↗
            ╱    │    ╲              ╱    │    ╲              ╱   │
          α│     │     │θ          α│     │    │θ           α│   │ θ
            ╲    │    ╱              ╲    │   ╱               ╲  │
              ╲↘ ↙╱                  ╲↘ ↙╱                   ╲↘

           α + θ = 180°           α + θ = 180°             α = θ
    ```

    * 朝向分三种而角度关系只有两种：要么差整数倍的 $\pi$，要么相等。
    * 整数倍的 $\pi$ 与相等情形都用诱导公式得**不变函数名**；只有 $\frac{\text{奇数}\pi}{2}$ 才变名。
    * > **结论**：二面角口诀——$\sin$ 恒为正，$\cos$ 需判锐钝；但一定不变名。
    * 棱长 $2$ 正方体中 $A_1-C_1E-A$ 的正弦值：面 $A_1C_1E$ 法向量 $(2,-2,1)$，面 $A_1C_1A$ 取交线向量 $(2,2,0)$ 与 $\overrightarrow{AC_1}=(2,2,2)$，解得 $(1,-1,0)$，$\cos\langle \vec n_1,\vec n_2\rangle=\frac{2\sqrt2}3$，故 $\sin\beta=\sqrt{1-\frac89}=\frac13$。
    * > **结论**：交线向量在两个面上各用一次都能选；有时传统列方程法比速算法更快，不必强记速算。
    * 两面夹角与二面角不是一回事，见「立体几何大题的路线选择」中的口径说明。

* **三类角度对比**

    | 角度类型 | $\sin$ 的符号 | $\cos$ 的符号 | 前后函数名 |
    | :--- | :--- | :--- | :--- |
    | 线线角 | 恒为正 | 恒为正 | 不变：$\sin \leftrightarrow \sin$，$\cos \leftrightarrow \cos$ |
    | 线面角 | 恒为正 | 恒为正 | 变：$\sin \leftrightarrow \cos$，$\cos \leftrightarrow \sin$ |
    | 二面角 | 恒为正 | 需判锐钝 | 不变：$\sin \leftrightarrow \sin$，$\cos \leftrightarrow \cos$ |

    * 线线角与线面角无论求 $\sin$ 还是 $\cos$ 都恒为正，不必判断即可加绝对值。
    * 线线角与二面角的共同点是绝对值内外函数名一致；只有线面角变名。

## 投影与距离

* **投影**

    * > **定义**：向量在直线上的投影长度等于该向量与这条直线方向上单位向量的数量积的绝对值；投影向量等于该数量积再乘单位向量。

    * 推导：过终点作垂线得直角三角形，$AG=AP\cos\theta$，而 $\vec{AP}\cdot\vec{u}=|AP|\cdot1\cdot\cos\theta=AG$。
    * 投影长度公式：$|\vec{AP}\cdot\vec{u}|$；投影向量公式：$(\vec{AP}\cdot\vec{u})\vec{u}$。
    * 单位向量：$\vec{u}=\dfrac{\vec{AB}}{|\vec{AB}|}$，即直线上任取两点构成的向量除以其模长。
    * > **易错点**：投影长度要加绝对值（长度必为正而数量积可正可负）；投影向量公式不能加绝对值——同向时数量积为正、反向时为负再乘反向单位向量，公式已把两种方向统一。
    * 例：$|\vec{b}|=\sqrt3$、$\vec{b}=(1,1,-1)$，$\vec{u}=\left(\frac{\sqrt3}3,\frac{\sqrt3}3,-\frac{\sqrt3}3\right)$，$\vec{a}\cdot\vec{u}=-\frac{2\sqrt3}3$，投影向量为 $\left(\frac13,\frac13,-\frac13\right)$。

* **点到直线的距离**

    * 图形上是一条垂线段的长度，须放回直角三角形用勾股定理。
    * $d=\sqrt{|\vec{AP}|^2-(\vec{AP}\cdot\vec{u})^2}$，其中 $\vec{u}$ 是直线方向上的单位向量、$A$ 是线上任取点、$G$ 为垂足。

    ```text
              P
              |\
              | \  斜边 AP（A 点在 l 上，可任取）
           PG |  \
              |   \
              G----A
                l 上
    ```

    * 例：$A(2,1,1)$，$B(1,0,0)$、$C(1,1,0)$ 共线，$\vec{BC}=(0,1,1)$，$\vec{u}=\left(0,\frac{\sqrt2}2,\frac{\sqrt2}2\right)$，$\vec{AB}=(-1,-1,-1)$，$d=\sqrt{3-2}=1$。
    * 另一条路：三点确定一个面，点到线距离即该三角形的高。先求三边 → 余弦定理求 $\cos\theta$ → 由 $\cos^2+\sin^2=1$ 得 $\sin\theta$ → $h=MN\cdot\sin\theta$。

* **点到平面的距离**

    * > **定义**：$d=\left|\dfrac{\vec{AP}\cdot\vec{n}}{|\vec{n}|}\right|$，其中 $\vec{n}$ 为平面的法向量、$A$ 为面内任取点。

    * 理由：该距离就是 $\vec{AP}$ 在法向量方向上的投影长度，而法向量方向的单位向量是 $\dfrac{\vec{n}}{|\vec{n}|}$。
    * > **结论**：点到面的距离比点到直线距离还简单，连勾股定理都不用，直接就是投影长度。
    * 已给法向量时：四面体 $P-ABC$ 中 $\vec{CP}\cdot\vec{n}=2-4+0=-2$、$|\vec{n}|=\sqrt2$，距离为 $\sqrt2$。
    * 法向量自求时：四棱柱中 $AB\parallel DC$、$AA_1\perp$ 底面、$AD\perp AB$、$AB=AA_1=2$、$AD=DC=1$，以 $A$ 为原点、$AB$、$AD$、$AA_1$ 为三轴建系，$B(2,0,0)$、$C(1,1,0)$、$M(0,1,1)$、$B_1(2,0,2)$，面上取 $\vec{CM}=(-1,0,1)$、$\vec{CB_1}=(1,-1,2)$，方程 $x-y+2z=0$、$-x+z=0$，解得 $\vec{n}=(1,3,1)$，距离 $\frac{2}{\sqrt{11}}=\frac{2\sqrt{11}}{11}$。
    * > **易错点**：单位向量这一步最易掉链子——点到线要除以直线方向向量的模长，点到面要除以法向量的模长，直接拿法向量点乘算出的是数量的倍数而非距离。

* **公式汇总**

    | 目标 | 做法 | 公式 |
    | :--- | :--- | :--- |
    | 向量在直线上的投影长度 | 目标向量点乘直线方向单位向量后取绝对值 | $\left|\vec{AP}\cdot\vec{u}\right|$ |
    | 向量在直线上的投影向量 | 上述数量积再乘单位向量 | $(\vec{AP}\cdot\vec{u})\vec{u}$ |
    | 点到直线的距离 | 放回直角三角形用勾股定理 | $d=\sqrt{\lvert\vec{AP}\rvert^2-(\vec{AP}\cdot\vec{u})^2}$ |
    | 点到平面的距离 | 即法向量方向上的投影长度 | $d=\left\lvert\dfrac{\vec{AP}\cdot\vec{n}}{\lvert\vec{n}\rvert}\right\rvert$ |

    * 点与点、点到线、点到面是教材明确给出公式的三种距离；点线面之间共有六种距离关系。

* **距离的转化**

    * 线面距离：能被求的线面距离必是线面平行，线上任取一点即化为点到面距离。
    * 面面距离：两面必平行，任取一个面上一点作另一面的垂线，化为点到面距离。
    * > **结论**：这两类虽无独立公式，但都能转化到点到面距离。

    ```text
       平行情形下距离全部相等

            ══════════════  线 l（平行于平面 α）
            ───────╮
                    ╰──╮
            ────────╮ ╰──╮
                     ╰──╮
            ══════════════  面 α

       线上任取一点 → 点到面的距离 → 套公式
    ```

* **异面直线的距离**

    * > **定义**：分别在两条直线上取点连线，使其与两条直线都垂直，这条公垂线的长度即为距离。

    * 两条线平行时，退化为线上任一点到另一条线的距离。
    * 公垂线常无法直接定位，但它是所有公垂线段中最短的：等价于**第一条直线上动点到第二条直线的点线距离的最小值**。
    * > **易错点**：立体图形里随便连的线段比公垂线长，直观上看着更短的是错觉——三维中这条线是斜的。
    * 教材未要求此内容，若考很可能放在新定义题中。

* **动点最值**

    * 动点到固定直线的距离公式不变，变的是动点坐标含参数。
    * 正四棱柱 $AB=1$、高 $\sqrt3$、$E(1,\frac12,0)$、$B_1(1,1,\sqrt3)$，$P$ 在 $EC$ 上运动，$P\left(1-\lambda,\frac12+\frac12\lambda,\sqrt3\lambda\right)$。
    * 竖直直线 $BB_1$ 的单位向量直接取 $(0,0,1)$；$\vec{PB_1}=\left(\lambda,\frac12-\frac12\lambda,\sqrt3-\sqrt3\lambda\right)$，模长平方中 $3\lambda^2$ 两项约掉，得
    * $PG^2=\frac54\lambda^2-\frac12\lambda+\frac14$，开口向上，对称轴 $\lambda=-\frac{b}{2a}=\frac15$。
    * 此时 $EP=\frac15EC$，$|EC|=\sqrt{1+\frac14+3}=\frac{\sqrt{17}}2$，故 $EP=\frac{\sqrt{17}}{10}$；最短距离本身为 $\frac{\sqrt5}5$。
    * > **提示**：$\lambda$ 是 $EP$ 占 $EC$ 的比例，天然满足 $0<\lambda<1$；题中说"直线 $EC$ 上动点"时端点是否取得到并不严谨，但对称轴处仍成立。
    * 同一题按异面直线距离的新定义去做，过程完全一致。

## 四点共面

* **方法总览**

    | 方法 | 核心一句话 |
    | :--- | :--- |
    | 平行法 | 两条连线平行 → 四点共面 |
    | 距离法 | 第四个点到另三点所成平面的距离等于零 |
    | 法向量法 | 两个面的法向量共线，且两面有公共点 → 两面是一个面 |
    | 平面向量基本定理 | 三个向量中有一个能被另外两个线性表示 → 共面 |

    * 三点必能确定一个平面，难点只在第四点是否落在该平面上；四种方法至少要会两种。

* **平行法**

    * 四个点中有两组连线平行，四边形是梯形，必共面，连坐标都不用建。
    * 直三棱柱中 $D$、$E$、$F$、$H$ 为各棱中点时：连 $EF$ 是三角形中位线故 $EF\parallel AC$，连 $DH$ 同理 $DH\parallel AC$，两条平行线上各取两点，四点共面。

* **距离法**

    * 取其中三点成面，证第四点到该面的距离为 $0$。
    * 四棱锥 $P-ABCD$ 中 $\triangle PAD$ 以 $AD$ 为斜边的等腰直角三角形、$BC\parallel AD$、$AB\perp AD$、$AD=2$、$AB=BC=1$、$PC=\sqrt2$，$E$、$F$ 为 $PD$、$BE$ 中点，证 $P$、$A$、$C$、$F$ 共面。
    * 建系依据：出现等腰先做三线合一，过 $P$ 作 $AD$ 中点 $G$ 的垂线；$GC=1$、$PG=AG=1$、$PC=\sqrt2$，直角集中在 $PG$ 上，故底面与侧面垂直，可以建系。

    ```text
       以 G 为原点建系，各点坐标：

           点        x        y        z
          ------------------------------------
           A         0       −1        0
           B         1       −1        0
           C         1        0        0
           D         0        1        0
           E         0       1/2      1/2
           F        1/2     −1/4      1/4
           P         0        0        1
    ```

    * 面 $PAC$ 上取 $\overrightarrow{AP}=(0,1,1)$、$\overrightarrow{AC}=(1,1,0)$，速算法得法向量 $\vec{n}_1=(-1,1,-1)$、$|\vec{n}_1|=\sqrt3$。
    * $\overrightarrow{AF}=F-A=\left(\frac12,\frac34,\frac14\right)$，代入距离公式得 $d=\frac{\left|-\frac12+\frac34-\frac14\right|}{\sqrt3}=0$，故四点共面。
    * > **提示**：分子恰为零时分母不必真算，但书写上仍要老老实实写出模长。

* **法向量法**

    * > **结论**：与一条固定直线垂直的两个面必定平行；这两个面又一定有公共点，看起来平行的面有交点只能是同一个面。

    ```text
        一条法向量（像穿羊肉串的签子）
                    │
        ════════════╪════════════   ← 平面 Π₁ 与它垂直
        ════════════╪════════════   ← 平面 Π₂ 与它垂直
                    │

        跟一条固定直线垂直的两个面 ⇒ 平行
        但 Π₁、Π₂ 一定有公共点（四个点就在里面）
        看着是平行的面 ∧ 又有交点 ⇒ 它俩只能是一个面 ⇒ 四点共面
    ```

    * 上例中面 $APC$ 的法向量为 $(-1,1,-1)$；面 $APF$ 上取已有的 $\overrightarrow{AP}$ 与 $\overrightarrow{AF}$，叉乘得 $\vec{N}_2=\left(-\frac12,\frac12,-\frac12\right)$，恰为 $\vec{N}_1$ 的 $\frac12$ 倍，即 $\vec{N}_2=2\vec{N}_1$，二者共线，四点共面。

* **平面向量基本定理**

    * > **定义**：平面内任意两个不共线的非零向量能表示该平面内任一向量，即 $\overrightarrow{AC}=\lambda\,\overrightarrow{AB}+\mu\,\overrightarrow{AD}$。

    * 反过来在空间中同样成立：三个向量中只要有一个能被另外两个线性表示，三个向量必在同一平面内。
    * > **提示**：二维需两个方向做基底，三维需三个方向做基底，三个方向之间不可能相互表示；现在能相互表示，说明退化成了二维。
    * 上例取 $\overrightarrow{AP}$、$\overrightarrow{AC}$、$\overrightarrow{AF}$，设 $\overrightarrow{AF}=\lambda\overrightarrow{AP}+\mu\overrightarrow{AC}$：

    ```text
       (1/2, 3/4, 1/4) = λ(0,1,1) + μ(1,1,0) = (μ, λ+μ, λ)

       μ = 1/2        （x 分量）
       λ + μ = 3/4    （y 分量）
       λ = 1/4        （z 分量）

       三个方程、两个未知数，第三个方程只用来检验：
       1/4 + 1/2 = 3/4  成立 ⇒ 三向量共面 ⇒ 四点共面
    ```

    * > **易错点**：自设的系数不能与题目已有的 $\lambda$ 混用，这是两个不同的东西；应另设 $s$、$t$。
    * 例：$\vec{i}$、$\vec{j}$、$\vec{k}$ 不共面，$\overrightarrow{AB}$、$\overrightarrow{BC}$、$\overrightarrow{CD}$ 由它们表示，已知四点共面。设 $\overrightarrow{CD}=s\overrightarrow{AB}+t\overrightarrow{BC}$，因三基向量不共面、各方向前系数须相等；后两个方程不含 $\lambda$，可直接解出 $s=t=1$，再由第一方向得 $\lambda=1$。

* **系数和为一**

    * > **结论**：$O$ 为空间内任意一点、$A$、$B$、$C$ 不共线时，$P$、$A$、$B$、$C$ 四点共面的充要条件是 $\alpha+\beta+\gamma=1$，其中 $\overrightarrow{OP}=\alpha\overrightarrow{OA}+\beta\overrightarrow{OB}+\gamma\overrightarrow{OC}$。

    * 推导：先用三角形法则把 $\overrightarrow{AC}$、$\overrightarrow{AB}$、$\overrightarrow{AD}$ 都改写成 $\overrightarrow{OC}-\overrightarrow{OA}$ 等形式，再合并同类项移到一边，得某系数乘 $\overrightarrow{OA}$ 等于 $a\overrightarrow{OB}+b\overrightarrow{OC}+c\overrightarrow{OD}$；三个系数的分母都是 $\lambda+\mu-1$，分子之和恰等于分母，故和为 $1$。
    * 用法：题目给出 $\frac78$ 时，另一系数须为 $\frac18$，代回检验即可。
    * > **结论**：这是一个二级结论，考试直接用可能扣分，用"两个向量表示第三个"更稳妥。

## 立体几何大题的路线选择

* **读题先看底面**

    * 菱形暗含对角线互相垂直且互相平分；菱形中的 $60^\circ$ 说明它由两个正三角形拼成，这类免费信息必须先装进脑子。
    * 直角梯形 $2:1:1$ 由三个等腰直角三角形拼成，常连对角线造垂直；出现 $60^\circ$ 的菱形常作某边的垂线。
    * 出现等腰先做三线合一，取中点连中线；边长条件要放在自己造的直角三角形里，用来定 $P$ 与底面的相对位置。

* **"交际花"**

    * 一条直线同时垂直于一个平面内的两条相交直线，则垂直于该平面；这条被两条线同时"认领"的线就是交际花。
    * 菱形底面四棱锥中 $\overrightarrow{AD}\cdot\overrightarrow{AP}=0$、$\overrightarrow{AB}\cdot\overrightarrow{AP}=0$，即 $AD\perp AP$、$AB\perp AP$，故 $AB\perp$ 平面 $PAD$，$AB$ 就是交际花。
    * 直角梯形底面的四棱锥中，平面 $PAD\perp$ 平面 $ABCD$，交线为 $AD$；$CD\perp AD$（直角梯形的两个直角）故 $CD\perp$ 平面 $PAD$，取 $PD$ 中点 $G$ 后 $AG\perp PD$（正三角形三线合一）、$AG\perp DC$，$AG$ 成为交际花，从而 $AG\perp$ 平面 $PCD$。
    * > **结论**：出现面面垂直时常去找交线的垂线——由面面推线面，再由线面推线线。

* **线面平行的三条路**

    * 思路一：在目标面上找一条与待证线方向一致的线，凑成平行四边形，由线线平行得线面平行。
    * 思路二：在面外与线外找一个公共点，连两个端点使两条连线各与面产生一个交点，跑出中位线或相似图形，回到线线平行。
    * 思路三：过待证线两端点作两个面，证面面平行，面面平行则线面平行。
    * 三棱锥 $P-ABC$ 中 $PA\perp$ 底面、$\angle BAC=90^\circ$、$AB=1$、$AC=AP=2$，$D$、$E$、$N$ 为 $PA$、$PC$、$BC$ 中点，$M$ 为 $AD$ 中点，证 $MN\parallel$ 平面 $BDE$。
    * 中位线法：取 $P$ 连两端点，$PM$ 交面 $BDE$ 于 $D$、$PN$ 交于 $G$；$D$ 是 $PM$ 的 $2:1$ 三等分点，$G$ 是 $\triangle PBC$ 两条中线（$BE$、$PN$）的交点即重心，也是中线的 $2:1$ 点，故 $\triangle PDG\sim\triangle PMN$，$DG\parallel MN$，而 $DG\subset$ 平面 $BDE$，得线面平行。
    * 选点技巧：$C$ 与 $N$ 连线交点在 $B$ 上，但 $C$ 与 $M$ 连线的交点支得出去、不好作，水平不够时改取 $P$。
    * 构造面面平行法：过 $N$ 作 $BE$ 的中位线（在 $EC$ 上取中点 $H$），由 $M$ 为 $DA$ 中点、$H$ 为 $EC$ 中点得 $MH$ 是梯形中位线，故 $DE\parallel MH\parallel AC$；两对相交线分别平行，两面平行，$MN$ 随之线面平行。
    * 直角梯形底面四棱柱中证 $DN\parallel$ 平面 $C_1BM$：把 $DN$ 平移到 $M$，因连的都是中点，两条线都与侧棱 $CC_1$ 平行且都等于它的一半，故平行且相等，构成平行四边形。

* **坐标系怎么摆**

    * > **结论**：直角情况最丰富的地方就选原点，三轴的位置视直角在哪里而定。

    * 先说不能怎么摆：菱形底面四棱锥中不能取 $AB$ 为 $x$ 轴、$AD$ 为 $y$ 轴、$AP$ 为 $z$ 轴，因为 $\angle DAB=120^\circ$，三条棱之间不是直角。
    * 菱形底面四棱锥的正确摆法：$AP$ 作 $z$ 轴、$AD$ 作 $y$ 轴，$x$ 轴取与 $AD$ 垂直且过 $BC$ 中点的方向。设 $AB=a$，则 $P(0,0,\sqrt2a)$、$D(0,a,0)$、$B\left(\frac{\sqrt3}2a,-\frac12a,0\right)$、$C\left(\frac{\sqrt3}2a,\frac12a,0\right)$、$F\left(\frac{\sqrt3}4a,\frac14a,\frac{\sqrt2}2a\right)$、$E\left(0,\frac23a,\frac{\sqrt2}3a\right)$。
    * $B$、$C$ 的 $y$ 坐标一正一负、恰关于原点对称，这才是"$x$ 轴过 $BC$ 中点"该有的样子。
    * > **提示**：求法向量前先做伸缩——每项乘 $a$、除以分母、再除以 $\sqrt2$，把 $\overrightarrow{AE}$ 化简成 $(0,\sqrt2,1)$、$\overrightarrow{AC}$ 化简成 $(\sqrt3,1,0)$，速算法得法向量 $(-1,\sqrt3,-\sqrt6)$，与 $\overrightarrow{BF}=\left(-\frac{\sqrt3}4a,\frac34a,\frac{\sqrt2}2a\right)$ 数量积为 $0$。
    * 三棱锥 $P-ABC$ 中 $PA\perp$ 平面 $AMN$ 且 $\triangle AMN$ 是等腰三角形：取 $AN$ 中点 $O$，以 $OM$ 为 $x$ 轴、$OA$ 为 $y$ 轴、$OP$ 为 $z$ 轴，得 $A\left(0,-\frac{\sqrt3}2,0\right)$、$P\left(0,-\frac{\sqrt3}2,1\right)$、$M\left(\frac{\sqrt5}2,0,0\right)$、$N\left(0,\frac{\sqrt3}2,0\right)$。
    * 同题中 $B$ 由"$M$ 是 $PB$ 中点"倒推：$B=\left(\sqrt5,\frac{\sqrt3}2,-1\right)$；$C$ 比例关系 $2:1$，用 $\overrightarrow{NC}=\frac12\overrightarrow{PN}$ 列式得 $C\left(0,\sqrt3,-\frac12\right)$。
    * 直角梯形底面四棱锥中取 $AD$ 中点 $O$ 为原点，与 $AB$ 平行的方向作 $x$ 轴、另一方向作 $y$ 轴、$OP$ 作 $z$ 轴，得 $A(1,0,0)$、$B(1,2,0)$、$C(-1,4,0)$、$D(-1,0,0)$、$P(0,0,\sqrt3)$、$E\left(-\frac12,2,\frac{\sqrt3}2\right)$。
    * > **结论**：建系法不是笨办法，是唯一能同时喂给后面每一问的路；后面若要算角度总要建系，不如一开始就建。
    * 碰到直角梯形底面，先单独把底面的二维图画出来标上边长，避免在三维图上纠缠。

* **棱锥体积的特殊方法**

    * 常规 $V=\frac13 S_{\text{底}}h$ 中选高选底不好办时，改用下面的特殊方法。
    * 方法一（转换顶点）：题目指定的顶点不必真当顶点，换成好求高、好求底面积的那个顶点。
    * 方法二（比例方缩）：任一棱上取一点并与顶点相连，截出的小三棱锥体积按棱长比例缩放。

    ```text
       中点情形：上、下两个三棱锥共用同一个底，
       而 A、D 到该面的距离相等，故体积各占一半

             A ●
              /|\
             / | \
            /  |  \
       垂足/   |   \垂足
          /    |    \
         S-----P-----D          P 恰在中点
          \           /
           \         /
            └───────┘
               面

       两个直角三角形 AAS 全等 ⇒ 两点到底面的距离相等
    ```

    | 缩放方式 | 小三棱锥体积占原 $V$ 的比例 |
    | :--- | :--- |
    | 一条棱缩到中点 | $\frac12V$ |
    | 一条棱缩到三等分点 | $\frac13V$ |
    | 两条棱分别缩到 $\frac12$、$\frac13$ | $\frac16V$ |
    | 三条棱分别缩到 $\frac15$、$\frac12$、$\frac13$ | $\frac1{30}V$ |

    * 三等分点时两体积共用底而高成 $1:2$，相似比给出体积比 $1:2$；多棱同时缩放则逐次相乘。
    * 三棱锥 $P-ABC$ 中 $PA=1$、$PB=2\sqrt3$、$PC=3$、$AB=3$、$BC=\sqrt6$、$AC=\sqrt7$，$M$、$N$ 在 $PB$、$PC$ 上且 $PA\perp$ 平面 $AMN$。
    * 锁位置：$\cos\angle APB=\frac{1+12-9}{2\cdot1\cdot2\sqrt3}=\frac{\sqrt3}3$，在直角三角形 $PAM$ 中 $\frac{PA}{PM}=\cos\angle APM$，得 $PM=\sqrt3$（恰在 $PB$ 中点）；同理 $\cos\angle APC=\frac{1+9-7}{2\cdot1\cdot3}=\frac12$ 得 $PN=2$（在 $PC$ 的 $\frac23$ 处）。
    * 共角的 $\triangle PMN$ 与 $\triangle PBC$ 列同一个余弦定理，式中只剩 $MN$：$\frac{3+4-MN^2}{2\cdot2\sqrt3}=\frac{12+9-6}{2\cdot2\sqrt3\cdot3}$，得 $MN=\sqrt2$。
    * 体积：$PB$ 缩到 $PM$、$PC$ 缩到 $PN$ 是 $\frac13$ 的关系，故 $V_{P\text{-}ABC}=3V_{P\text{-}AMN}$；$AM=MN=\sqrt2$、$AN=\sqrt3$，底面为等腰三角形，$S_{\triangle AMN}=\frac12\cdot\sqrt3\cdot\sqrt{2-\frac34}=\frac{\sqrt{15}}4$，故 $V_{P\text{-}AMN}=\frac{\sqrt{15}}{12}$，$V_{P\text{-}ABC}=\frac{\sqrt{15}}4$。

* **两个必须记死的口径**

    * > **易错点**：**两个面的夹角与二面角不是一回事。**二面角可锐可钝；"两面夹角"指两个二面角中较小的那个，必为非钝角。

    ```text
                两面夹角 θ
              ／        ＼
        ┌──────          ──────┐
        │                        │
        └────────────────────────┘
            n₁ ↗      ↖ n₂
               法向量夹角 φ
    ```

    * 两条法向量分别垂直于公共交线，且各自与对应半平面互补，$\varphi$ 同时与 $180^\circ-\theta$ 和 $\theta$ 互补，故 $\varphi=\theta$。
    * > **结论**：法向量夹角为锐角时，它正好就是两面夹角。
    * 第一题中平面 $BDF$ 的法向量 $(\sqrt3,1,0)$ 可由辅助线得到而不用算：过 $F$ 作 $FG\parallel BD$ 交 $AC$ 于 $G$，$BD\perp AC$ 给出 $G$ 是 $AC$ 中点，$F$ 是 $PC$ 中点故 $FG$ 是 $\triangle PAC$ 的中位线而 $FG\parallel PA$，$PA\perp$ 底面则 $FG$ 同时垂直于 $AC$、$BD$，$FG$ 就是平面 $BDF$ 的法向量。
    * 平面 $ABE$ 的法向量取 $\overrightarrow{AB}$ 与 $\overrightarrow{AE}$ 得 $(\sqrt2,\sqrt6,-\sqrt3)$；两法向量夹角 $\frac{2\sqrt6}{2\sqrt{11}}=\frac{\sqrt{66}}{11}$，即两面夹角的余弦值。
    * 线面角与法向量夹角互余，$\alpha=\frac{\pi}2-\theta$，函数名要变；由 $\sin\theta=\frac{k}{2\sqrt{3k^2-4k+2}}=\frac{\sqrt3}6$ 解得 $k=\frac12$，此时 $E$ 为 $PD$ 中点。

* **外接球球心法**

    * 球心 $Q$ 的垂足必落在底面三角形的外接圆圆心 $S$ 上：$QS$ 与底面上 $SA$、$SB$、$SC$ 都构成直角三角形，共用同一高且斜边相等，故 $SA=SB=SC$。
    * 定圆心的办法是取任意两边的中垂线，$AC$ 太斜，选 $AB$ 与 $BC$ 的中垂线。
    * 直角梯形底面四棱锥中 $S(-2,1,0)$，验证 $SA^2=SB^2=SC^2=10$；球心 $Q=(-2,1,t)$ 必在此基础上沿竖直方向平移。
    * 判存在性：设 $Q\in AE$，由三点共线写 $(-2,1,t)=(1,0,0)+\lambda\left(-\frac32,2,\frac{\sqrt3}2\right)$。

    | 分量 | 左端 | 右端 | 结论 |
    | :--- | :--- | :--- | :--- |
    | $x$ | $-3$ | $\lambda\cdot\left(-\frac32\right)$ | $\lambda=2$ |
    | $y$ | $1$ | $\lambda\cdot 2$ | $\lambda=\frac12$ |
    | $z$ | $t$ | $\lambda\cdot\frac{\sqrt3}2$ | 待定 |

    * 各分量对 $\lambda$ 的要求互相矛盾，$Q$ 连直线 $AE$ 都不在线上，线段更不可能，故**不存在**这样的点。

## 综合题型小结

* **同一道题的三条路落点一致**

    * 菱形底面四棱锥证 $BF\parallel$ 平面 $ACE$：向量法（连用两次三点共线）、几何法、建系法三路殊途同归，全只证"$M$ 是 $DF$ 中点"这一件事。
    * 几何法补点：在 $PD$ 上取 $S$ 使其为 $PE$ 中点，则 $S$ 同时是 $PD$ 的三等分点；$\triangle PCE$ 中 $FS$ 是中位线得 $FS\parallel CE$，$\triangle FSD$ 中 $SE=ED$ 故 $EM$ 是中位线，顺势得 $M$ 为 $FD$ 中点。
    * 之后设 $G$ 为菱形中心（$BD$ 平分 $\angle B$，其终点即 $BD$ 中点），$G\in AC$ 故在平面 $ACE$ 内，$\triangle BDF$ 中 $GM$ 是中位线，$GM\parallel BF$ 且 $GM\subset$ 平面 $ACE$，得线面平行。
    * > **易错点**：向量法与几何法落点完全一样，选哪条路取决于哪门手艺更硬，而不是哪条路更短。

* **第二问要作废第一问的结论**

    * 条件 $k=\frac23$ 不再成立时，所有依赖三等分点算出的量全部作废；其余点坐标不变仍可用。
    * 求 $E$ 的一般坐标：在 $yOz$ 面内设 $E(0,y_0,z_0)$，由 $\overrightarrow{PE}=k\overrightarrow{PD}$ 得 $y_0=ak$、$z_0=\sqrt2a(1-k)$。

* **立体几何大题的全部能力点**

    * 平行证明的三条路、向量法的三点共线定理、建系时轴的摆法、棱锥体积的特殊方法、点面距离公式、角度的互余换算、外接球球心的定位。
