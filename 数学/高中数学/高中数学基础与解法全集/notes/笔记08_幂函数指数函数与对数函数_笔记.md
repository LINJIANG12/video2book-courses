# 幂函数·指数函数与对数函数

## 三大初等函数的辨识

* **幂函数（power function）**

    * > **定义**：形如 $y=x^{a}$（$a$ 为常数）的函数，底数固定为 $x$，指数固定。
    * 标准形式前只允许乘系数 $1$，写成 $k\cdot x^{a}$（$k\neq1$）一律不是幂函数。
    * 定义域由 $a$ 的分数写法决定，可为 $[0,+\infty)$、$\mathbb{R}$ 或去掉 $0$ 的集合。

* **指数函数（exponential function）**

    * > **定义**：形如 $y=a^{x}$（$a>0$ 且 $a\neq1$）的函数，底数固定，指数是自变量。
    * $a<0$ 时函数图像画不出来：$x=\frac12$ 得 $(-1)^{\frac12}$ 无意义，$\frac14,\frac16,\frac18$ 同样无意义，图像不连续，故不研究。

* **对数函数（logarithmic function）**

    * > **定义**：形如 $y=\log_a x$（$a>0$ 且 $a\neq1$）的函数，真数位置是自变量。

* **辨识口诀**

    * 变量在**指数位**上是指数函数，变量在**底数位**上是幂函数。
    * 把 $2$ 与 $x$ 换个位置，函数类型整个翻转：$2^{x}$ 是指数函数，$x^{2}$ 是幂函数。
    * 同一个式子换个自变量就换一副面孔：把 $x$ 固定、让 $a$ 变，$S(x)$ 由幂函数型变成指数函数型。

* **三大函数横向对比**

    | 项目 | $y=x^{a}$ | $y=a^{x}$ | $y=\log_a x$ |
    | :--- | :--- | :--- | :--- |
    | 底数要求 | 无（系数只能为 $1$） | $a>0,\ a\neq1$ | $a>0,\ a\neq1$ |
    | 定义域 | 由 $a$ 的写法决定 | $\mathbb{R}$ | $(0,+\infty)$ |
    | 值域 | 随 $a$ 变 | $(0,+\infty)$ | $\mathbb{R}$ |
    | 单调性 | $a>0$ 时在第一象限递增；$a<0$ 递减 | $a>1$ 增；$0<a<1$ 减 | $a>1$ 增；$0<a<1$ 减 |
    | 定点 | $(1,1)$ | $(0,1)$ | $(1,0)$ |
    | 渐近线 | 无 | $x$ 轴 | $y$ 轴 |
    | 对称关系 | 关于 $y$ 轴对称则为偶函数 | $a^{x}$ 与 $\left(\frac1a\right)^{x}$ 关于 $y$ 轴对称 | $y=\log_a x$ 与 $y=\log_{\frac1a}x$ 关于 $x$ 轴对称 |

## 幂函数

### 标准形式与识别

* $y=x^{a}$ 前面**只能乘 $1$**，任何 $k\neq1$ 的系数都破坏标准形式。
* 典型陷阱：给出 $f(x)=(m^{2}-m-2)x^{m}$ 是幂函数且为轴对称图形，由「是幂函数」得 $m^{2}-m-2=0$，解得 $m=2$ 或 $m=-1$。
* $m=2$ 时 $f(x)=x^{2}$ 关于 $y$ 轴对称；$m=-1$ 时 $f(x)=x^{-1}$ 是反比例函数，它是中心对称图形，但同时也有对称轴 $y=x$，同样满足「轴对称图形」。
* > **易错点**：条件只说「轴对称图形」时 $m=-1$ 也成立；若条件收紧为「关于 $y$ 轴对称」，才只剩 $m=2$。是条件说得不够精确，不是算错。

### 必背的五个幂函数

* $y=x$（一次幂）、$y=\dfrac1x$（$x$ 的负一次幂，反比例函数）、$y=x^{2}$（二次函数）、$y=\dfrac12$ 次幂（$x^{\frac12}=\sqrt{x}$）、$y=x^{3}$（三次函数）。
* $x^{\frac12}=\sqrt{x}$ 的含义由两边同取平方得到，前提是 $x\geq0$；图像只在 $x$ 正半轴有，是增函数且增加越来越缓。
* $x^{\frac13}$ 是开三次根号；一般地 $\frac1m$ 次幂就是开 $m$ 次根号。

### 第一象限的增减规律与公共定点

* > **结论**：所有幂函数 $y=x^{a}$ 的图像都过定点 $(1,1)$，因为 $1^{a}=1$ 与 $a$ 无关。这个点比单调性更好用。
* 只谈第一象限时：$a<0$ 单调递减；$0<a<1$ 单调递增但增得缓；$a>1$ 单调递增且增长很快。
* 第一象限内增长次序：$a=3$ 增长极快，$a=2$ 很快，$a=\frac12,\frac13,\frac14$ 增长较慢；另有 $a>0$ 一般情形下 $a>e$ 增得快、$a<e$ 增得慢。

* **四曲线配对题的破局手段**

    * 当规律只告诉你「同属一类」而无法区分时，**代特殊值**（交点横坐标 $1$ 附近、或 $4$ 这类好算的数）是最省事的手段。
    * 例：四个幂函数指数取 $\pm2,\pm\frac12$，$c_4$ 增长最快对应 $n=2$，$c_3$ 递增但越来越缓对应 $n=\frac12$；$c_1,c_2$ 都递减，只剩 $-2$ 与 $-\frac12$，令 $x=4$ 得 $4^{-2}=\frac1{16}$、$4^{-\frac12}=\frac12$，故 $c_2\to-\frac12$，$c_1\to-2$。

### 分数指数幂与画图三步走

* > **定义**：$x^{\frac{n}{m}}$ 的含义是先对 $x$ 做 $n$ 次幂（分子是几就几次方），再对这一整体开 $m$ 次根号（分母是几就开几次根号）。
* 例：$x^{\frac23}$ 表示对 $x$ 先平方再开三次根号。
* 分母是偶数（$2,4,6,\dots$）时偶次根号要求被开方数非负，只能推出 $x\geq0$，图像只在第一象限。
* 分母是奇数时奇次根号对 $x$ 无限制，定义域含负半轴，必须补另一半图像；负半轴的图像靠算 $f(-x)$ 判定：$f(-x)=f(x)$ 是偶函数、关于 $y$ 轴对称，$f(-x)=-f(x)$ 是奇函数、关于原点对称。
* 例 $x^{\frac35}=\sqrt[5]{x^{3}}$：奇次根号里的负号能提出来，得 $f(-x)=-\sqrt[5]{x^{3}}$，奇函数、图像关于原点对称。
* 例 $x^{-\frac23}=\dfrac{1}{\sqrt[3]{x^{2}}}$：分母不能为零 $\Rightarrow x\neq0$，三次根号对 $x$ 无限制，故定义域是 $x\neq0$；又 $f(-x)=\dfrac{1}{\sqrt[3]{(-x)^{2}}}=f(x)$，偶函数、图像关于 $y$ 轴对称。

```text
                  拿到 y = x^a
                        |
          +-------------+-------------+
          |                           |
   第一步：用结论              第二步：判断定义域
   只管第一象限                      |
          |                  +-------+-------+
   a < 0  → 单调递减        x >= 0          x 可取负值
   0<a< 1 → 增得比较缓      只有第一象限      （含 R）
   a > 1  → 增得很快        画完，收工          |
                                              |
                                    第三步：算 f(-x) 补另一半
                                              |
                              +---------------+---------------+
                              |                               |
                        f(-x) = f(x)                    f(-x) = -f(x)
                            偶函数                        奇函数
                          关于 y 轴对称                  关于原点对称
```

* > **易错点**：只画一半图像是这类题最常见的失分点。定完定义域一定要回头看一眼 $x<0$ 能不能取，能取就必须补另一半。
* 同底幂反复出现的化简套路：上下同除以 $x^{a}$，把指数合并、三个 $x$ 的位置集中到一处，复杂函数会一下子变得好分析。

## 指数运算法则与化简

### 三条运算法则

* $r$、$s$ 可以是整数、分数，甚至无理数：
    * $a^{r}\times a^{s}=a^{r+s}$（如 $2^{\frac13}\times2^{\frac14}=2^{\frac7{12}}$，$2^{\sqrt3}\times2^{\sqrt5}=2^{\sqrt3+\sqrt5}$）
    * $(a^{r})^{s}=a^{rs}$（如 $\left(2^{\frac13}\right)^{6}=2^{2}=4$）
    * $(ab)^{r}=a^{r}\times b^{r}$
* 任何非零数的 $0$ 次幂都是 $1$；$0^{0}$ 没有意义，碰到这种项先确认底数非零。

### 偶数陷阱与绝对值

* > **易错点**：把 $\frac26$ 约成 $\frac13$ 是约分时最大的坑。约分会把「偶数」这个性质弄丢，一旦丢了、分母变奇数，负数的取值就可能整体翻转。
* 验证反例：$(-2)^{\frac26}$ 是先平方再开六次根号，结果必为正；而 $(-2)^{\frac13}$ 是负数，两者不对应。
* 归纳成一句话：先 $n$ 次幂再开 $n$ 次根号，$n$ 为奇数时结果等于它自己、可正可负；$n$ 为偶数时结果一定是正值，$a$ 正负未知时最后必须加绝对值。
* 实战提醒：$16^{\frac34}=\left(2^{4}\right)^{\frac34}=2^{3}=8$，$16^{\frac12}=4$ 要写成 $|16|=16$，这类「先偶数次幂再开同样次数根号」的项必须带绝对值。

### 根号套根号的化简套路

* > **技巧**：习惯上把根号改成指数。因为运算法则里 $r$、$s$ 可取整数、分数、无理数，但一个式子里前前后后好多根号、根号套根号根本无法运算，必须先统统转化成 $x^{\frac{m}{n}}$ 的形式。
* 通用套路——先全部转成指数形式，再只盯一个底数，用「底数相同指数相加」合并，最后把指数连乘。
* 例 $\sqrt[3]{xy^{2}+\sqrt{xy^{-1}}}\cdot\sqrt{xy}$：内部 $\sqrt{xy^{-1}}=x^{\frac12}y^{-\frac12}$，括号内合并为 $x^{\frac32}y^{\frac32}$；套整体三次根号得 $x^{\frac12}y^{\frac12}$；再乘外面的 $x^{\frac12}y^{\frac12}$，$x$ 与 $y$ 的指数都是 $1$，结果为 $xy$。

```text
   整体外边：三次根号            外面还乘：√(xy)
   ┌───────────────────┐        ┌─────────────┐
   │  x y²  +  ( x y⁻¹ )^(1/2)   │ × x^(1/2) y^(1/2)
   └───────────────────┘        └─────────────┘

   由里向外剥洋葱：
   (x y⁻¹)^(1/2) = x^(1/2) · y^(-1/2)
   内部合并：x^1 + x^(1/2) = x^(3/2)
             y² + y^(-1/2) = y^(3/2)
   套上 1/3 次幂：x^(3/2×1/3)=x^(1/2)，y 同理 = y^(1/2)
   再乘外面的 x^(1/2)·y^(1/2)
   x 指数：1/2 + 1/2 = 1      y 指数：1/2 + 1/2 = 1
   最终：x · y
```

* 其他常用型：$\left(\dfrac{27}{8}\right)^{-\frac23}=\left[\left(\dfrac32\right)^{3}\right]^{-\frac23}=\left(\dfrac32\right)^{-2}=\dfrac49$；$(0.0064)^{-\frac13}=\left[\left(\dfrac25\right)^{3}\right]^{-\frac13}=\dfrac52$。

## 指数函数

### 描点画图与单调性

* $y=a^{x}$ 图像横过定点 $(0,1)$，当 $x$ 每大 $1$，函数值变为原来的 $a$ 倍。
* $a>1$（如 $2^{x},3^{x},4^{x}$）单调递增；$0<a<1$（如 $\left(\frac12\right)^{x},\left(\frac13\right)^{x},\left(\frac14\right)^{x}$）单调递减。
* $2^{x}$ 的描点数据：$\left(-3,\frac18\right),\left(-2,\frac14\right),\left(-1,\frac12\right),(0,1),(1,2),(2,4),(3,8)$，一个比一个高。
* 四条曲线（$3^{x},2^{x},\left(\frac12\right)^{x},\left(\frac13\right)^{x}$）配对：左边两条递增，增长快的在上面，故 $3^{x}$ 在上、$2^{x}$ 在下（也可取 $x=1$ 比较 $3>2$）；右边两条递减，用 $a^{x}$ 与 $\left(\frac1a\right)^{x}$ 关于 $y$ 轴对称的关系对应，别写反。

### 五条性质

* **定义域**：$x\in\mathbb{R}$。
* **值域**：$(0,+\infty)$，$0$ 取不到，是开区间。
* **单调性**：$a>1$ 增；$0<a<1$ 减。
* **渐近线**：$x$ 轴，图像无限趋近但不相交。
* **定点**：$(0,1)$，因为 $a^{0}=1$ 与 $a$ 无关。
* **对称性**：单看一段曲线既无对称轴也无对称中心；$a^{x}$ 与 $\left(\frac1a\right)^{x}$ 的图像关于 $y$ 轴对称。

### 定点变形：让参数失效

* 形如 $y=a^{x}$ 才是指数函数；$3a^{x}$、$a^{2x-3}$、$a^{x}-3$ 统统不是，它们经过的定点不再必然是 $(0,1)$。
* > **结论**：定点就是与参数取值无关的那个点。想方设法**让参数失效**即可——在指数式里让参数失效的唯一手段就是把指数做成 $0$。
* 例 $f(x)=a^{2x-2}+3$：令 $2x-2=0$ 得 $x=1$，此时 $f(1)=a^{0}+3=4$，恒过定点 $(1,4)$。
* 对数函数同理由 $\log_a1=0$ 给出定点，如 $f(x)=\log_a(2x-3)-4$：令 $2x-3=1$ 得 $x=2$，$f(2)=-4$，定点为 $(2,-4)$。
* 幂函数复合型让参数失效有两条路：令整体等于 $1$（$1^{a}=1$），或令整体等于 $0$（$0^{a}=0$，$a>0$）。找到一条够用，找到两条全写上。
* 例：$x\in(0,1)$ 的监测函数化简后令 $x=\frac12$ 得 $S(\frac12)=\frac12$ 与 $a$ 无关，过定点 $\left(\frac12,\frac12\right)$；令 $x=1$ 得 $S(1)=1$，同时过 $(1,1)$。

### 分段函数：整体单调的三重条件

* 例 $f(x)=\begin{cases} ax+3a-8, & x<0 \\ a^{x}, & x\geq 0 \end{cases}$ 在 $\mathbb{R}$ 上单调递增：直线段递增给 $a>0$，指数段递增给 $a>1$。
* 还必须看分界点：把 $0$ 分别代入两段得 $3a-8$ 与 $a^{0}=1$，要求 $1\geq3a-8$，即 $a\leq3$。
* 验证能否取等：$a=3$ 时分界点重合为一个实心点，仍满足单调递增，故可取等。
* 三式取交集得 $a\in(1,3]$，左开右闭。

### 复合函数：换元与同增异减

* > **结论**：复合函数最常用的手段是**换元**。把内层设为一个新变量 $t$，内层二次函数与外层指数函数都会画，一个整体函数就变成两个小函数。
* 值域用「由内向外一层层剥」：先求内层 $t$ 的范围，再求外层的范围。画外层图时要看清坐标轴是谁。
* 单调性口诀「同增异减」：内外层单调性相同则整体递增，相反则整体递减；也可用定义直接看「$x$ 增大 $\Rightarrow$ 每一层怎么变」。
* 例 $f(x)=\left(\frac12\right)^{x^{2}+4x+3}$：定义域为 $\mathbb{R}$；内层对称轴 $x=-2$、顶点值 $-1$，故 $t\geq-1$；外层递减，$t=-1$ 时取最大值 $\left(\frac12\right)^{-1}=2$，$t\to+\infty$ 时 $y\to0$ 但取不到，值域 $(0,2]$；在 $[-2,+\infty)$ 上内层增、外层减，同增异减得整体单调递减。
* 层数太多时「同增异减」失效，退回最原始的办法：自变量增大了，就逐步看函数值是增大还是减小（例如反比例减 $1$、放进幂函数、再加 $1$、最后又放在反比例里共五六层）。
* 除以一个越来越小的正数，整个值反而越来越大——这一处最易反直觉。

## 对数的定义与基本运算

### 指对互化与活动范围

* > **定义**：$\log_a b$ 表示「$a$ 的多少次幂等于 $b$」，底数 $a$ 在下标、真数 $b$ 在正上方，整体读作「以 $a$ 为底 $b$ 的对数」。
* 符号的来历：像根号一样，$a^{x}=b$ 中 $x$ 存在但初中无法表示，就发明一个新符号把它表示出来。
* > **结论**：底数 $a>0$ 且 $a\neq1$；真数 $b>0$。两者的范围都到指数式 $a^{x}=b$ 那边去看。
* > **易错点**：真数位置大于 $0$ 是非常重要的结论，「以 $2$ 为底 $-3$ 的对数」不存在，写完没有意义。
* 互化实例：$3^{x}=6\Rightarrow x=\log_3 6$；$100^{x}=2\Rightarrow x=\log_{100}2$；反过来 $\log_8 9$ 即「$8$ 的多少次幂等于 $9$」，$\log_3 27=3$，$\log_2 16=4$。
* 化简方向：看到对数就问「它等价于哪个指数式」；看到对数前面带系数就想「把它顶到真数上去」。
* 几乎 $95\%$ 以上的题需要把指数变成对数来做，因为对数公式刚学，出题人一定考公式而不让你求指数。

### 两条必背特殊值

* $\log_a 1=0$（任何数为底、$1$ 为真数），$\log_a a=1$（任何数为底它自己的对数）。
* > **结论**：这两条必须背下来，后面所有「剥洋葱」题全靠它们开路。

* **三层对数剥洋葱示范**

    * $\log_2\left(\log_{\frac12}\left(\log_2 x\right)\right)=0$：第一层用 $\log_a1=0$ 得真数为 $1$，剥掉最外层；第二层用 $\log_a a=1$ 得底数等于真数，剥掉第二层；剩下 $\log_2 x=\frac12$，指对互化得 $2^{\frac12}=x$，即 $x=\sqrt2$。

```text
      log₂(  log_{1/2}(  log₂ x )  )  =  0
        │          │            │
        │          │            └── 第三层：底数 2，真数是 x
        │          └── 第二层：底数 1/2，真数是「log₂ x」这一整体
        └── 第一层：底数 2，真数是「log_{1/2}(log₂ x)」这一整体

      第一层 = 0  →  真数 = 1（因为 logₐ1 = 0）
                     ↓ 剥掉最外层这层皮
      第二层 = 1  →  底数 = 真数（因为 logₐₐ = 1）→ 真数 = 1/2
                     ↓ 剥掉第二层
      log₂ x = 1/2  →  化成指数：2^(1/2) = x
                     ↓
                    x = √2
```

* 高考型例：$x>0$ 且一个对数式等于某个常数，化成指数式后落到一元二次方程 $x^{2}+2x-15=0$，解得 $x=3$ 或 $x=-5$，用范围限制 $x>0$ 取 $3$。
* > **提示**：看到对数式里塞着一个二次式，第一反应永远是把它化成干净的指数式或方程，别在真数那一坨里跟二次三项式硬碰硬。
* 2015 浙江型例：已知 $4^{a}=3$，则 $(2^{a})^{2}=3$。**易错点**：$2^{a}$ 绝不可能取负号——指数一定大于 $0$，所以只取正根 $\sqrt3$，不要开成 $\pm$；于是 $2^{a}+2^{-a}=\sqrt3+\frac1{\sqrt3}=\frac43\sqrt3$。

### 四组核心公式

* **指对互化**：$a^{x}=b\Longleftrightarrow x=\log_a b$，一句话是指数与对数可以相互转化。
* **互逆运算**：$a^{\log_a b}=b$，$\log_a(a^{x})=x$。加减互逆、乘除互逆，指与对也互逆；先取对数再取指数、先取指数再取对数，结果都是它自己。
* **数乘运算（下头公式）**：$\log_{x^{m}}\left(y^{n}\right)=\frac{n}{m}\log_x y$，$n$ 放分子、$m$ 放分母。「下头」就是把底数真数脑门上的幂提下来放到前面。
    * 实例：$\log_{16}32$ 中 $16=2^{4}$、$32=2^{5}$，下头得 $\frac54\log_22=\frac54$；$\log_{27}9$ 中 $27=3^{3}$、$9=3^{2}$，下头得 $\frac23$。
    * 逆用（系数上头）：$m\log_x y=\log_x(y^{m})$，真数脑门上的东西可以提出来写成 $n$；既然能下头就能上头，系数与指数可来回变换。例 $4\log_9\sqrt3=\log_9\left(\sqrt3\right)^{4}=\log_99=1$。
    * 推论：令 $n=m$ 得 $\log_{x^{m}}y^{m}=\log_x y$——底数与真数同时取 $m$ 次幂，值不变。这是不等式里统一底数的依据。
* **同底数对数加减**：$\log_a m+\log_a n=\log_a(mn)$，$\log_a m-\log_a n=\log_a\frac{m}{n}$。
    * 例 $2^{x}=3$、$y=\log_2\frac89$，求 $2x+y$：先把 $x$ 写成 $\log_23$，得 $2\log_23+\log_2\frac89$；系数不能直接相加，用逆用把系数上头，$2\log_23=\log_29$；同底相加真数相乘得 $\log_28=3$。
    * 例 $2^{a}=6$，求 $\log_23$ 是 $a$ 的几分之几：$a=\log_26$，把 $3$ 写成 $\frac62$，逆推回去得 $\log_2\frac62=\log_26-\log_22=a-1$。
    * > **结论**：所有对数公式都可以逆用，左能推右，右也能推左。

### 换底公式

* > **定义**：$\log_x y=\frac{\log_a y}{\log_a x}$（$a>0$ 且 $a\neq1$），新底 $a$ 任意选择，想换成谁就换成谁。
* > **易错点**：分子分母位置不能反。真数永远在上面，原来的底永远在下面。
* 两个常用底：$\lg y=\log_{10}y$（因为常用十进制且写 $\log_{10}$ 太麻烦）；$\ln y=\log_e y$，其中 $e\approx2.71828$，在微积分、物理学、金融学中都常见。
* $e$ 的来历（大学阶段的极限，此阶段只需记住它是一个数、约等于 $2.71828$）：$\lim_{n\to\infty}\left(1+\frac1n\right)^n$ 恒趋近于它；把 $1$ 处函数值为 $1$ 的反比例函数线段延展成封闭图形，当阴影面积为 $1$ 时延展量也无限趋近于它。
* 什么时候用：题目中同时出现好几个不一样的底（底越多越恶心）就大胆换底，选 $10$ 还是选 $e$ 都行，选一个顺手顺口的。
* 例 $\log_2 9\cdot\log_3 4=\frac{\lg9}{\lg2}\cdot\frac{\lg4}{\lg3}=\frac{2\lg3}{\lg2}\cdot\frac{2\lg2}{\lg3}=4$。
* 天津卷型例 $\left(2\log_4 3+\log_8 3\right)\left(\log_3 2+\log_9 2\right)$：统一换成以 $e$ 为底，第一括号化为 $\frac43\cdot\frac{\ln3}{\ln2}$，第二括号化为 $\frac32\cdot\frac{\ln2}{\ln3}$，相乘对数因子约掉得 $2$。
* 大长式子拆开一段一段来：$\ln(2e^{2})+\log_3 7\cdot\log_7 81-\ln 2-\log_2\sqrt2-\log_2\sqrt8$。第一项拆成 $\ln2+2\ln e=\ln2+2$（$\ln2$ 没有办法化简，原样保留）；第二项用换底得 $\frac{\ln81}{\ln3}=\frac{\ln3^{4}}{\ln3}=4$；第四、五项把根号写成 $2^{\frac12}$、$2^{\frac32}$ 后用下头或互逆运算得 $\frac12$、$\frac32$。合计 $(\ln2+2)+4-\ln2-\frac12-\frac32=4$。

### 真数底数对调取倒数

* > **结论**：$\log_x y=\frac{1}{\log_y x}$，底数真数互换位置，整个值取倒数。
* 用途：对数出现在分母上时不好处理，把真数底数调换位置即可化简。
* 例 $2^{a}=10$、$5^{b}=10$，求 $\frac1a+\frac1b$：$\frac{1}{\log_2 10}+\frac{1}{\log_5 10}=\lg2+\lg5=\lg10=1$。
* 常数补充：$\lg100=2$，$\lg1000=3$；以 $a$ 为底 $a$ 的对数总等于 $1$，非常好用。

## 对数函数

### 图像与六条性质

* 每学一个运算就诞生一种函数：平方 $\to$ 二次函数，根号 $\to$ 根式函数，指数 $3^{\frac12}$ $\to$ 指数函数 $3^{x}$，对数 $\log_3 2$ $\to$ 对数函数 $\log_3 x$。
* 以 $2$ 为底与以 $\frac12$ 为底的作图数据：

    | $x$ | $1$ | $2$ | $4$ | $8$ | $\frac12$ | $\frac14$ | $\frac18$ |
    | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
    | $\log_2 x$ | $0$ | $1$ | $2$ | $3$ | $-1$ | $-2$ | $-3$ |
    | $\log_{\frac12} x$ | $0$ | $-1$ | $-2$ | $-3$ | $1$ | $2$ | $3$ |

    * 两组值互为相反数，图像上下翻转即可得到第二条曲线。
    * $a>1$ 时单调递增；$a<1$（落在 $0$ 到 $1$ 之间）时单调递减，与指数函数完全一样。

* **六条性质**

    * 定义域：$(0,+\infty)$，只能在 $x$ 正半轴内取值。这一条即使别的都不会也必须记住，它是所有对数陷阱的根源。
    * 值域：$\mathbb{R}$，从最小到最大无限延伸，每个值都能取到。
    * 单调性：$a>1$ 递增；$0<a<1$ 递减。
    * 渐近线：$y$ 轴，离 $y$ 轴越来越近但永远无法靠近。
    * 定点：$(1,0)$，由 $\log_a1=0$ 得出，与底数 $a$ 无关。
    * 对称性：$y=\log_a x$ 与 $y=\log_{\frac1a}x$ 关于 $x$ 轴对称。

* **四条曲线一起画的上下关系**

    * 上面两条单调递增（底数大于 $1$），下面两条单调递减（底数在 $0$ 到 $1$ 之间）。
    * 判断上面为什么是 $\log_2 x$、下面为什么是 $\log_3 x$：**代一个值**即可——$\log_22=1$ 说明它过 $(2,1)$，$\log_33=1$ 说明它过 $(3,1)$；经过 $(1,0)$ 与 $(2,1)$ 的函数必在更上方，底数大的被压得更低。
    * 另外 $\log_a x$ 与 $\log_{\frac1a}x$ 关于 $x$ 轴对称。

```text
                y
                ↑
   log₂x   ╲╲                    ← 经过 (2,1)，在更上面
           ╲ ╲____
   log₃x  ╲   ╲  ╲_____          ← 经过 (3,1)，底数大被压得更低
          ╲    ╲      ╲____
  ─────────╲────╲────────────●────→ x
            ╲    ╲        (1,0)
   log_{1/2} ╱    ╱  ╱‾‾‾‾‾╲
   log_{1/3} ╱    ╱   ╱‾‾‾‾‾‾‾╲    ← 上两条曲线关于 x 轴的镜像

          x>1 的部分在轴上方（函数值为正）
          x<1 的部分在轴下方（函数值为负）
```

### 定义域：所有陷阱的源头

* 「根号 + 对数」混合结构：根式在分母上则 $3x-2>0$（不能取 $0$）；对数真数为 $2x-1$ 则 $2x-1>0$；两式取交集得 $x>\frac23$。
* 求 $f(x)=\sqrt{\log_{0.5}(1-x)}$ 的定义域：根号内非负 $\log_{0.5}(1-x)\geq0$；把 $1-x$ 设成整体 $m$，以 $0.5$ 为底的函数递减且过 $(1,0)$，要求 $\geq0$ 对应 $m\in(0,1]$；于是 $0<1-x\leq1$，解得 $[0,1)$。

### 解对数不等式：脱衣服

* 把同一个底的对数当成一个新函数设出来，就是构造函数；然后靠单调性「脱衣服」。
* > **结论**：单调递增约掉后不等号方向不变；单调递减约掉后**一定变号**；如果既不递增也不递减，是不能约的。
* 陷阱在真数：不等式两边**都是真数**，真数位置都要大于 $0$，必须与脱衣服得到的不等式同时成立。
* 例 $\log_3(2x+1)>\log_3(x-1)$：以 $3$ 为底递增，约掉得 $2x+1>x-1\Rightarrow x>-2$；再附加 $x-1>0$，最终 $x>1$。只写 $x>-2$ 是错的。
* 例 $\log_{\frac13}(2x+1)>\log_{\frac13}(x-1)$：以 $\frac13$ 为底递减，约掉后变号得 $2x+1<x-1$；再附加 $2x+1>0$、$x-1>0$，三者取交集结果为空集。

* **底不一样怎么办：同次幂统一**

    * 用不着换底公式就能统一：把底数与真数同时 $m$ 次幂，值不变。
    * 例 $\log_{\sqrt3}(2x+1)>\log_3(x^{2})$：两边同时平方成以 $3$ 为底，$\log_{\sqrt3}u=\log_3u^{2}$，值不变；约掉得 $2x+1>x^{2}$。
    * > **易错点**：真数条件要以**原始数据**为准，是 $2x+1>0$ 且 $x>0$，而不是 $x^{2}>0$。

* **右端是个常数**

    * 以 $0.5$ 为底、$1$ 的对数就是 $0$，所以常数可以先化成同底对数再脱衣服。
    * 例解以 $0.5$ 为底的不等式时，脱衣服后因为递减必须变号；解完千万别忘求定义域，真数要 $1-x>0$，两式同时成立才有解。
    * 两种思路：画图做，或利用函数单调性脱衣服。两种方法都别忘了最后三个字——定义域。

### 复合函数的单调性

* 内层二次函数外套对数函数，属复合函数，遵循「同增异减」。
* 外层是 $\ln x$ 时，因为 $e=2.71828>1$，外层永远递增，所以整体递增只要求内层取增区间。
* 例 $f(x)=\ln\left(x^{2}+2x-3\right)$：内层开口向上、对称轴 $x=-1$，增区间为 $[-1,+\infty)$；但内层在**真数位**，必须整体为正，令 $x^{2}+2x-3>0$ 即 $(x+3)(x-1)>0$，得 $x<-3$ 或 $x>1$；两者取交集，递增区间为 $(1,+\infty)$。
* > **易错点**：常见错答是 $[-1,+\infty)$——只顾单调性，忘了真数必须为正。这道题非常爱考。
* 想求递减区间时内外层单调性必须相反，分两类情形：① 外层增（$a>1$）、内层减，动轴定区间求 $a$ 的范围；② 外层减（$0<a<1$）、内层增，同样动轴定区间。两类各自得到范围后**取并集**。

## 比较大小

### 第一步：估值，钉到数轴上

* 估算的第一个动作是把这个数跟 $0$ 和 $1$ 这两个最特殊的东西比较：小于零、在零一之间、还是大于一。
* $\log_2 0.4<0$（底数大于 $1$ 递增，自变量落在 $0$ 到 $1$ 之间）；$\pi^{0.1}>1$（正底数、正指数，结果是正数且大于 $1$）；$\left(\frac13\right)^{\frac12}=\sqrt3\approx1.732$（根号 $3$ 这个值得记住）。
* $\ln3>1$：因为 $\ln e=1$ 而 $e\approx2.718$，自变量取到 $e$ 时函数值才是 $1$，现在 $3>e$。

    | 特殊值 | 约等于 | 记忆要点 |
    | :--- | :--- | :--- |
    | $\ln 2$ | $0.69$ | 必记 |
    | $\ln 3$ | $1.1$ | 必记 |
    | $\ln 5$ | $1.61$ | 非常少见，但偶尔会遇上 |

* > **结论**：$\ln3$ 精确值约 $1.0986$，但记小数点后那么多位没有意义，记成 $1.1$ 就行。
* 最值钱的一招：以任何数为底，**$a$ 的 $x$ 次方作真数，对数值就是 $x$**。把底数的整数次幂摆到真数位置，对数值立刻映入眼帘。
    * $\log_3 8$：$3^1=3<8<9=3^{2}$，故值在 $1$ 与 $2$ 之间。
    * $\log_4 25$：$16=4^{2}<25<64=4^{3}$，故值在 $2$ 与 $3$ 之间，是个二点几的值。
* 高一期中型例 $A=0.49$、$B=2^{0.7}$、$C=\log_{0.7}2$：$A$ 是零点几，$B$ 大于一，$C$ 底数小于 $1$ 递减且自变量 $2>1$ 故小于零，得 $B>A>C$。

### 第二步：数形结合

* 专治「估完之后三个值全部落在零到一之间」的情形：形式像的函数一起画出来，答案就在高低上。
* 底数是分数画起来别扭时用**花束型**：$a^{x}$ 与 $a^{-x}$ 关于 $y$ 轴对称，先画 $3^{x}$、$5^{x}$ 再对称过去。
* 趋势：底数大于 $1$ 且越来越大时图像越靠近 $y$ 轴；底数小于 $1$ 时底数越小反而越靠近 $y$ 轴。
* 例 $A=\left(\frac13\right)^{\frac23}$、$B=\left(\frac15\right)^{\frac23}$、$C=\left(\frac13\right)^{\frac12}$：$A$、$C$ 同在 $\left(\frac13\right)^{x}$ 上而 $\frac12<\frac23$ 且该曲线在 $x>0$ 时递减，故 $C$ 在 $A$ 上方；粉色曲线整体在蓝色下方，$B$ 最小。得 $C>A>B$。
* 同型例 $C=\log_2 0.3$、$A=0.2^{0.8}$、$B=0.8^{0.2}$：$C$ 估值大于一最大；底数小于 $1$ 时底数越小图像越远离 $y$ 轴，故 $0.2^{x}$ 在上、$0.8^{x}$ 在下，再配上 $A$ 取 $x=0.8$、$B$ 取 $x=0.2$，得 $C>B>A$。

### 第三步：找中间值，往中间插一根针

* 两个值都落在零到一之间时，找一个中间值看是不是一个大一个小。最常找的是 $\frac12$，能解决 $90\%$ 的题目。
* > **结论**：中间值未必是题给的，很多时候要自己找，而且是越找越往里挤——$\frac12$ 不行就试 $\frac14$、$\frac13$，$\frac12$ 到 $\frac14$ 之间就想到 $\frac13$。
* 方法一（把常数也化成对数后同底相减）：比较一个对数与 $\frac12$，把 $\frac12$ 写成 $\log_a\sqrt a$，两边同时取以 $a$ 为底的对数即可。**易错点**：以 $a>1$ 为底的对数是增函数、方向不变；若换成以 $0.5$ 为底则为递减函数，不等号方向要改变，有的题目就专门在这里设陷阱。
* 方法二（两边同时取以 $a$ 为底的指数）：本质与方法一完全一样，只是构造一个函数 $G(x)=a^{x}$ 去想。
* 例 $A=\log_5 2$、$C=\frac12$、$B=\log_8 3$：$A<\frac12$（$2<\sqrt5$）；把 $\frac12$ 写成 $\log_8\sqrt8$ 后得 $\frac12<B$；合起来 $A<C<B$。
* 例 $A=\log_9\pi$、$B=\sin29^{\circ}$、$C=\log_3 4$：由 $\sin29^{\circ}<\sin30^{\circ}=\frac12$（直角三角形中斜边变长、对边不变则比值变小）得 $B<\frac12$；以 $9$ 为底、$\pi>3$ 得 $A>\frac12$；$A$ 与 $C$ 之间不需要任何中间值——底数真数同时平方后 $\log_2 3=\log_49$、$C=\log_9 16$，由 $\pi<4<16$ 直接得 $A<C$。最终 $C>A>B$。
* 例 $A=\log_2 3$、$B=\log_4 5$、$C=\sqrt2$：$A$ 平方成 $\log_49$ 后由 $9>5$ 得 $A>B$；比 $A$ 与 $C$ 用两边同时平方——左边 $9$，右边 $2^{2\sqrt2}$ 而 $2\sqrt2\approx2.8<3$，故 $2^{2\sqrt2}<8<9$，得 $A>C$。合起来 $A>C>B$。
* 例 $A=\log_{26}78$、$B=1.25^{0.9}$、$C=\log_9 18$：三个全在 $1$ 到 $2$ 之间，估值失败，一个中间值不够。
    * 先挑最软的 $B$：$0.9$ 接近 $1$ 所以 $B<1.25=\frac54<1.5$，预想的中间值 $1.5$ 没用上。
    * 再用真数相乘拆常数：$\log_{26}78=1+\log_{26}3$，$\log_9 18=1+\log_92$，区间从 $[1,2]$ 平移到 $[0,1]$。
    * $\frac12$ 用不上（$\sqrt{26}>3$ 使上面那个值小于 $\frac12$，$2<\sqrt9=3$ 使下面那个也小于 $\frac12$）；$\frac14$ 也用不上（两边乘 $4$ 上头后得 $3^{4}=81>26$ 与 $2^{4}=16>9$，都大于 $\frac14$）。
    * 取 $\frac13$：左边乘 $3$ 上头得 $\log_{26}27>1$，右边乘 $3$ 上头得 $\log_9 8>1$，故两个值都落在 $\left(\frac13,\frac12\right)$ 之间，加 $1$ 后 $A$、$C$ 都大于 $\frac43$；而 $B<\frac54<\frac43$，故 $B$ 最小，得 $A>C>B$。

### 连等式：设中间值，三种图像一起画

* 连等式的处理办法是**设中间值** $M$，人为引入一个变量，再把每一项分别解成关于 $M$ 的函数。
* 例 $2^{x}=3^{z}=y^{-13}$：得 $x=\log_2 M$，$z=\log_3 M$，$y=M^{-\frac1{13}}$——一道题同时考了指数函数、对数函数与幂函数。
* 三条图像：$\log_2M$ 与 $\log_3M$ 都过 $(1,0)$ 且递增；$M^{-\frac1{13}}$ 过 $(1,1)$ 且在第一象限单调递减。
* > **易错点**：只看第一象限就够用。因为 $M=2^{x}$ 恒大于零，这个式子不成立的话原式本身就不成立，所以 $M$ 天然大于零。
* 大小关系只在**两两交点处**才变，所以图像被两个焦点切两刀分成三份，逐段读高低即可；某个顺序可能永远不成立，据此即可排除选项。

```text
	        M 轴（自变量 M）自左向右推移

   M → 0            两个交点之间              M → +∞
  ┌────────────┬────────────────────┬────────────┐
  │  Y > Z > X │     Z > Y > X      │  Z > X > Y  │
  └────────────┴────────────────────┴────────────┘
      可能              可能                  可能

   ⇒  「X > Y」这种顺序永远不成立
```

### 构造函数脱衣服比大小

* 把不等式翻译成函数值：两边形式不一致时先「让系数对上」，改出一个左右结构相同的不等式，再构造函数。
* 2012 浙江型例：条件形如 $2^{a}+2a$ 与 $2^{b}+3b$。因为 $b>0$，$2b<3b$，可建立关于 $2^{a}+2a$ 与 $2^{b}+2b$ 的不等式；设 $f(x)=2^{x}+2x$，增函数加增函数必单调递增，增函数两边「脱衣服」不等号方向不变，得 $a>b$。
* 课堂练习型：$5^{a}+2a=5^{b}+3b=5^{c}+c$ 且三者均正，以中间的 $2a$ 为基础凑出 $f(x)=5^{x}+2x$，由 $f(b)<f(a)<f(c)$ 得 $b<a<c$。
* > **注意**：加号改成减号后就不行了。$2^{x}-2x$ 用基本不等式无法确定增减性，学了导数后会发现它是先减后增的；函数不单调就不能脱衣服，$a$ 与 $b$ 的大小关系无法确定。
* 单选里如果两个选项的结论**互相打架**，其中一个已经证明对了，另一个可以直接排除，根本不用验算另一个——这是最省时间的路。

### 糖水不等式

* > **定义**：若 $a>b>0$ 且 $m>0$，则 $\frac{b}{a}<\frac{b+m}{a+m}$。
* 推导没有技术含量，完全等价于交叉相乘：$ab+bm<ab+am$，约掉 $ab$ 得 $bm<am$，两边除以 $m$ 就回到 $b<a$。
* 直观含义：一杯糖水质量 $a$ 克、其中糖 $b$ 克，糖的质量分数是 $\frac{b}{a}$；再放入 $m$ 克糖，新浓度是 $\frac{b+m}{a+m}$。一句话：糖水加糖，甜更甜。
* 前提条件就是糖水的条件：整杯质量大于糖的质量（$a>b$），溶液质量为正（$a>0$），加的是糖不是减糖（$m>0$）。
* > **结论**：糖水不等式专门用来解决**不同底的两个对数的比较**。分子小、分母大的分数就是一杯糖水；做法是给两个分数同时加上同一个数使分母变成相同的对数，分子也加同样的数。
* 例比较 $\log_4 3$ 与 $\log_5 4$：换成 $\frac{\ln3}{\ln4}$ 与 $\frac{\ln4}{\ln5}$，加糖 $\ln\frac54$ 使分母变成 $\ln5$、分子变成 $\ln\frac{15}{4}$，而 $\frac{15}{4}<5$，故 $\log_4 3<\log_5 4$。
* 例证 $\log_5 7<\log_6 8$：要证的方向要求浓度比 $1$ 小，先倒写成 $\log_75$ 与 $\log_68$，加糖 $\ln\frac87$，得 $\frac{\ln5}{\ln7}<\frac{\ln\frac{40}{7}}{\ln8}<\frac{\ln6}{\ln8}$。
* 2020 新课标三卷型例比较 $\log_53$、$\log_85$、$\log_{13}8$：三者估值全落在零到一之间且无法相互转化，用糖水不等式。先比 $A$、$B$，加糖 $\ln\frac85$，分子变成 $\ln\frac{24}{5}$，而 $\frac{24}{5}<\frac{25}{5}$，得 $A<B$；再比 $A$、$C$，加糖 $\ln\frac{13}{5}$，分子变成 $\ln\frac{39}{5}$，而 $\frac{39}{5}<\frac{65}{5}$，得 $A<C$。所以 $\log_53$ 最小。
* 题目附带条件 $5^{5}<8^{4}$ 与 $13^{4}<8^{5}$ 的用途：它们是**中间值**。前者两边取以 $8$ 为底的对数得 $\log_85<\frac45$，后者两边取以 $13$ 为底的对数得 $\log_{13}8>\frac45$，于是 $B<\frac45<C$，得 $C>B$，与前面合起来仍是 $A$ 最小。

* **要记住的小链链**

    * $\log_23<\log_34<\log_45<\log_56<\cdots<\log_{99}100$，即当底数与真数总是差一对的时候，随着底数增大这个值也越来越大。
    * 换成换底公式看是 $\frac{\ln2}{\ln3},\frac{\ln3}{\ln4},\dots,\frac{\ln99}{\ln100}$：$\ln x$ 递增但增速越来越慢，所以相邻两段的差距越来越小（$\ln99=4.595$、$\ln100=4.605$ 只差 $0.1$，而 $\ln2=0.69$、$\ln3=1.1$ 差 $0.5$），整串无限趋近于 $1$ 但始终大于 $1$，所以只能填大于号。
    * 分子大于分母的那一串 $\log_75,\log_86,\log_97,\log_{10}8$ 同理，全部填大于。
    * 严谨证法一（构造函数）：令 $f(x)=\frac{\ln(x+2)}{\ln x}$，把分子凑成 $\ln x+\ln\left(1+\frac2x\right)$，得 $f(x)=1+\frac{\ln\left(1+\frac2x\right)}{\ln x}$；$x>1$ 时分子单调递减、分母 $\ln x$ 单调递增，**减函数除以增函数必递减**，故整条不等式链成立。
    * 严谨证法二就是回到糖水不等式。

## 可构造三角形函数

### 定义与只需一条不等式

* > **定义**：对任意实数 $a,b,c$，$f(a),f(b),f(c)$ 都能作为三角形的三边长，则称 $f(x)$ 为可构造三角形函数。
* 初中结论是「两边之和大于第三边」，但实际操作中不需要写三回：只需**边长小的两边之和大于最长的那条边**，另两条不等式会被自动推出来。

```text
        D                    E                    F
        |●-------------------●-------------------●|
        |          <------ D + E ------>         |
        |                                        |
        |   只用一条：两条较短边之和 > 最长那条边   |
        |   （另两条不等式会被这一条自动推出来）    |
        |                                        |
        D + E > F      ← 只列这一条就够了
```

* > **结论**：这类题第一步永远是**把自变量的任意取值翻译成值域内的任意取值**——定义域内随便取 $\Rightarrow$ 值域内随便取，三个函数值就是值域里任意三个点。

### 分式求值域：凑分母加分类讨论

* 凑分母的通用做法：分母不动，分子从最高次开始看，分母加 $1$ 分子也加 $1$，然后拆成两段、一段与分母约掉、一段留下。
* 例 $f(x)=\frac{2^{x}+t}{2^{x}+1}$：把 $2^{x}$ 看成整体，它是一次比一次型，凑分母得 $f(x)=1+\frac{t-1}{2^{x}+1}$。
* 内层分母 $2^{x}+1$ 向上平移一个单位，值域 $[1,+\infty)$；整体 $\frac{t-1}{2^{x}+1}$ 是反比例函数，$t-1$ 的正负决定画在一三象限还是二四象限，故要分类讨论：

    | 参数范围 | $\dfrac{t-1}{2^x+1}$ 的值域 | $f(x)=1+\dfrac{t-1}{2^x+1}$ 的值域 |
    | :--- | :--- | :--- |
    | $t>1$ | $(0,\ t-1)$ | $(1,\ t)$ |
    | $t<1$ | $(t-1,\ 0)$ | $(t,\ 1)$ |
    | $t=1$ | 恒等于 $0$ | $\{1\}$ |

* $t=1$ 时分子分母一样，$f(x)\equiv1$，是常值函数，三个函数值全等于 $1$，能构成等边三角形，符合题意。

### 只取最极端的那一组

* 人为规定 $f(a)\leq f(b)\leq f(c)$，因为三值可随意取，总有一个相对的大小关系。
* 题干要求**任意取值**都成立，所以只要最极限的情况成立就够：$t>1$ 时两个小的无限趋近 $1^{+}$、最大的无限趋近 $t^{-}$，故要求 $1+1\geq t$。
* 验证能否取等：$t=2$ 时在 $(1,2)$ 内任取三个值，两个小的都比 $1$ 大，和必大于 $2$，符合题意，故能取等，得 $t\leq2$，与 $t>1$ 取交集得 $t\in(1,2]$。
* $t<1$ 同理：$t+t\geq1$，得 $t\geq\frac12$，与 $t<1$ 取交集得 $t\in\left[\frac12,1\right)$。
* 三种情况取并集，最终 $t\in\left[\frac12,2\right]$。
* > **结论**：完整套路三步——① 把「任意取值」翻译成「值域内任意取值」；② 用凑分母求出值域（要分类讨论）；③ 只取最极端的那一组（两个趋近下界、一个趋近上界）列一条不等式，解完验证能否取等。

## 必背丑函数元件

### 类二次：$a^{x}+a^{-x}$

* > **结论**：$a>0$ 且 $a\neq1$ 时 $f(x)=a^{x}+a^{-x}$ 是先减后增的偶函数，最低点在 $x=0$ 处取得，最小值为 $2$。
* 最小值 $2$ 的来源：令 $x=0$ 得 $a^{0}+a^{-0}=1+1$。
* > **易错点**：考试曾专门要求**证明**它大于等于 $2$。严格证法用基本不等式：两数之和 $\geq2\sqrt{\text{两者乘积}}$，而乘积正是 $a^{x+(-x)}=a^{0}=1$，所以 $\geq2$。等号在 $a^{x}=a^{-x}$ 时成立，解得 $x=0$。
* 单调递增的严格证明（不需导数）：设 $a^{x}=t$，则 $y=t+\frac1t$，即指数函数套对勾函数。
    * $a>1$、$x>0$ 时内层 $t>1$ 递增，外层在 $(1,+\infty)$ 上递增，同增 $\to$ 整体递增。
    * $0<a<1$、$x>0$ 时内层 $t\in(0,1)$ 递减，外层在 $(0,1)$ 上递减，同减 $\to$ 整体递增。
    * $x<0$ 不用再证：设 $f(x)$ 则 $f(-x)=f(x)$，是偶函数，右侧递增则左侧递减。
* 作为外层的 $t=a^{x}$ 恒大于零，所以外层对勾函数只画第一象限，最小值在 $t=1$ 处取得。

### 类三次：$a^{x}-a^{-x}$

* $a>1$ 时像单调递增的三次函数；$0<a<1$ 时像单调递减的函数。
* 理由：$a>1$ 时 $a^{x}$ 增、$a^{-x}$ 减，增减得增；$0<a<1$ 时反过来，增减得减。
* 无论哪种情况都是**关于原点对称的奇函数**，形状像三次函数，所以称为类三次函数。
* 这两个函数（$a^{x}\pm a^{-x}$）是做题的基本零件。

### 四个必背奇函数

* $\dfrac{a^{x}-a^{-x}}{a^{x}+a^{-x}}$ 与 $\dfrac{a^{x}-1}{a^{x}+1}$ 都是奇函数。
* 第二个的证明：设 $f(x)=\frac{a^{x}-1}{a^{x}+1}$，令 $f(-x)=\frac{a^{-x}-1}{a^{-x}+1}$，上下共同乘以 $a^{x}$ 得 $\frac{1-a^{x}}{1+a^{x}}$，分母不变、分子变号，故 $f(-x)=-f(x)$。
* > **易错点**：这一组必须记牢「上面减、下面加」。如果上下调个个儿（上面加下面减）或左右调个个儿，形式变了但**奇偶性不变**。
* 另外还有一批与对数有关的奇函数也要背下来：$\ln\dfrac{x+a}{x-a}$、$\ln\left(\sqrt{x^{2}+1}\pm x\right)$。
* 这批函数每道题都要用，考试里几乎场场出现。

* **一奇一偶相乘除，结果必为奇**

    * 例 $f(x)=\frac{e^{x}-e^{-x}}{\ln|x|}$：分子 $e^{x}-e^{-x}$ 是类三次、奇函数；分母 $\ln|x|$ 中 $|-x|=|x|$ 值不变，是偶函数；所以 $f(x)$ 是奇函数，可直接排除关于 $y$ 轴对称的选项。
    * 剩下两个选项靠**代特殊值定符号**区分：取 $x=100$，$e^{100}$ 极大而 $e^{-100}$ 无限接近 $0$，分子必为正；$\ln100$ 为正；商为正。
    * 若上面这些结论一个都不知道，只能一点一点算 $f(-x)$，做完再看相等还是互为相反数——慢但也能做。

* **排列组合：先变形再识别**

    * 例 $\ln(e+ex)$：先把 $e$ 提出来成 $\ln e+\ln\dfrac{1+x}{1-x}$，后半截是纯奇函数，整体等于**奇函数 + 1**，即 $1$ 就是 $\ln e$；奇函数加 $1$ 相当于图像上移一个单位，对称中心由原点变为 $(0,1)$。
    * > **结论**：一旦识别出函数有对称中心 $(0,b)$，整道题一定是围着这个中心转的。
    * 例分子每项都带 $a$ 的分式：把 $a$ 提出变成 $a(x^{2}+1)$，分子拆开左右各除以分母后剩一个 $a$，再加 $2a$；分子是奇函数、分母 $x(x^{2}+1)$ 是偶函数，一奇一偶相除得奇函数，再加 $2a$，对称中心在 $(0,2a)$。

## 对称性驱动的三类题型

### 求和问题与牛逼公式

* 第一步永远是**先研究对称性**；找到对称中心 $(a,b)$ 后，最高点与最低点必然关于对称中心对称，纵坐标之和为 $2b$。
* 例：三次幂（奇）减一个对数奇函数再乘奇函数得奇函数，最后加 $3$，对称中心变为 $(0,3)$，所以 $M+m=2\times3=6$，单调性完全不用看。
* 例区间 $[-1,5]$ 上的丑函数：$x^{2}-4x=(x-2)^{2}-4$，$e^{x-2}-e^{2-x}$ 中两个指数互为相反数，$x+1=(t+2)+1=t+3$——每一个 $x$ 全都是 $x-2$，**换元**令 $t=x-2$ 即可。$x^{2}-4x\to t^{2}-4$，$e^{x-2}-e^{2-x}\to e^{t}-e^{-t}$，$x+1\to t+3$；类三次（奇）乘类二次（偶）得奇，再加奇函数 $t$ 仍是奇，加 $3$ 后关于 $(0,3)$ 对称，故 $M+m=6$。
* 那个区间不是 $[-a,a]$ 形式时不要慌：先找中心，再看区间中点是否关于中心对称。$t=x-2$ 把 $x\in[-1,5]$ 变成 $t\in[-3,3]$，$3$ 与 $-3$ 关于 $0$ 完全对称。
* > **结论**：这类题的区间一定是出题人凑好的——它必然保证截完之后最左点和最右点关于对称中心对称，否则这道题就白出了。看到区间不是 $[-a,a]$ 的形式就要警觉。
* > **易错点**：换元只是**整体代换**，没有改变函数的最大值和最小值；但必须注意新元的取值范围。

* **牛逼公式**

    * > **定义**：只要 $x_1,x_2,\dots,x_{n}$ 的横坐标关于对称中心的横坐标对称，那么它们的**纵坐标之和**就等于 $nb$。有两个数乘 $2b$，三个数乘 $3b$，$n$ 可奇可偶。若这 $n$ 个里含有中心本身那一项，则 $n$ 为奇数且 $b$ 出现 $\frac{n+1}{2}$ 次。
    * 配套的心算画面：横轴上 $x_1$ 到 $x_n$ 一字排开，关于对称中心竖直对称。

```text
	      x1   x2   x3        xk        x_{k+1}  ...  x_n
	       |    |    |          |            |
-------●----●----●-----.----●------------●-------- x
                        |
                        ·  对称中心 (a, b)
                    · · · · · · · ·

   x1 + x2 + ... + x_n = k 对称点对 × 2b  +  (若有中点项，则 + 中心纵坐标)
```

    * 例：解析式含 $\ln\left(\sqrt{(3x)^{2}+1}-3x\right)$，把 $3x$ 换成元就是 $\sqrt{t^{2}+1}-t$，纯奇函数；加 $x$ 仍奇；再加 $1$ 得对称中心 $(0,1)$，$b=1$。数数：$1$ 到 $2024$ 共 $2024$ 个，$-1$ 到 $-2024$ 共 $2024$ 个，中间还有一个 $0$，共 $4049$ 个且关于 $0$ 对称，按公式答案就是 $4049$。
    * 两步底层逻辑：求出对称中心 $(a,b)$，然后**数数**——数好左边加了几个，用这个数乘 $b$。

### 解抽象函数不等式

* 三步固定：看对称性 $\to$ 看单调性 $\to$ 解不等式。它就是求和问题再多看一步单调性。
* > **结论**：题目不会主动告诉你要去求对称性和单调性，这两步得你自己主动做；把图像准确画出来之后才有资格去解不等式。
* 偶函数光知道奇偶性是不够的——同一个偶函数既能画成左边凹右边凸，也能反过来，必须判定它在 $x>0$ 的部分到底是增是减。判定方式是用定义看 $x$ 增大时 $y$ 到底增大还是减小；两个「增 + 增」相加必单调递增。
* 比较函数值大小的底层说法：一个点离原点越远（不管在左还是在右）函数值就大，离原点越近函数值就越小，所以真正要比的是**自变量关于原点的远近**，用绝对值表示。

    * **单调型**：严格递增则脱衣服不变号；严格递减则变号。
    * **不单调型**（先减后增等）：想比较函数值就得**看图说话**——离对称轴远函数值大，离对称轴近函数值小。对称轴为 $x=a$ 时解 $|m-a|>|n-a|$ 就够了。

* **中心对称 + 大于号：$f(m)+f(n)>2a$**

    * 等号情形：$f(m)+f(n)=2a$ 意味着 $m$ 点与 $n$ 点正好关于对称中心对称，此时 $m+n=2t$。
    * 改为大于号：函数值要变大，就得让自变量往外跑。$m$ 点在更左边才能让函数值更大；$n$ 处的函数值同样要变大，只能由右往左跑。看 $m$、看 $n$ 都一样，两点全都在变小，加完自然小于 $2t$。
    * > **结论**：对称中心为 $(t,a)$ 时，$f(m)+f(n)\begin{cases}>2a\\=2a\\<2a\end{cases}\Longleftrightarrow\begin{cases}<2t\\=2t\\>2t\end{cases}$，不等号方向完全相反，因为函数值的增减在这里是「背离型」的。

```text
       f(x)
        ^
        |        · 中心 (t, a)
   2a  |·········╱···╲········
        |      ╱          ╲
   ---- +----/--------------\----> x
             m      t       n

  等号时：m + n = 2t，且 f(m)+f(n) = 2a
  改为大于号：函数值要变大 ⇒ 自变量往外跑
             ⇒ m 变小、n 也变小  ⇒  m + n < 2t
```

* **没见过面的函数怎么找对称中心**

    * 第一步看对称性：把 $f(x)$ 写出来，把所有 $x$ 全换成 $-x$ 写出 $f(-x)$，与 $f(x)$ 对应项相加（或相减），化成 $2b$ 或 $0$。
    * 例 $f(x)=\ln\left(\sqrt{x^{2}+1}+x\right)-\frac{2}{e^{x}+1}$：$f(-x)=\ln\left(\sqrt{(-x)^{2}+1}-x\right)-\frac{2}{e^{-x}+1}$；后一项上下同乘 $e^{x}$ 得 $\frac{2}{1+e^{x}}$。两式对应项相加，前半由同底对数相加、真数相乘再用平方差公式得 $\ln\left[\left(x^{2}+1\right)-x^{2}\right]=\ln1$；后半得 $\ln1-2=-2$。于是 $f(x)+f(-x)=-2$。
    * > **结论**：形如 $f(x)+f(-x)=2b$ 的式子代表对称中心为 $(0,b)$。这里 $-2\div2=-1$，对称中心是 $(0,-1)$。
    * 第二步看单调性：$x$ 越大 $\sqrt{x^{2}+1}+x$ 越大，$\ln$ 递增，故第一部分递增；$x$ 增大则 $e^{x}+1$ 变大，在分母上取倒数后越来越小，前面还有负号，减去越来越小的数反而越来越大，故第二部分也递增。整体单调递增。
    * 题问 $f(\text{甲})+f(\text{乙})>-2$ 时，$-2$ 正好是中心纵坐标的两倍。等号下中心横坐标为 $0$，有 $x+(2x-1)=2\times0$；改为大于号意味着自变量往右移变大，最终 $3x-1>0\Rightarrow x>\frac13$。

### 恒成立求参数

* > **结论**：恒成立问题本质上是一个**求函数最值**的问题。比喻：说班里每人考分都比 $60$ 分高，那即便考得最差的那位也大于 $60$。
* 高一阶段最常用的方法就是**分离参数**：把参数单独分离出来移到等号一边。
* 两边同除一个恒为正的量时不用讨论变号一定不变号——例如 $2^{x}+2^{-x}$ 是类二次函数，恒大于零。
* 得到形如「参数 $\leq$ 某个复杂式子」之后，就转化成了求该式子的最小值问题。

* **经典变形：换元成对勾函数**

    * $2^{2x}+2^{-2x}$ 与 $2^{x}+2^{-x}$ 长得不一样但可以相互表示：由 $(2^{x}+2^{-x})^{2}=2^{2x}+2^{-2x}+2\cdot2^{x}\cdot2^{-x}=2^{2x}+2^{-2x}+2$ 得前者等于后者的平方减 $2$。
    * 设 $t=2^{x}+2^{-x}$，分子由 $t^{2}-2$ 再加 $3$ 得 $t^{2}+1$，整个式子成为 $\frac{t^{2}+1}{t}=t+\frac1t$，正是对勾函数。
    * > **易错点**：套基本不等式前必须判断**等号什么时候取得**。对勾函数的真最小值在 $t=1$ 处，但类二次函数 $t=2^{x}+2^{-x}$ 能取 $1$ 吗？不能，它的最小值是 $2$。
    * > **易错点（换元后最致命的错误）**：**每换一个新元，都千万不要忘了去求新元的取值范围**。这里是 $t\geq2$，我们真正截取的是 $2$ 到 $+\infty$ 这一段，所以这段上的最小值在 $t=2$ 处取得，故 $a\leq2+\frac12=\frac52$，而不是 $a\leq2$。

```text
     致命陷阱：换元后必须回代新元 t 的取值范围

   y
   |        /
   |      /          ← 对勾函数 t + 1/t 的真·最小值在 t = 1
 2 |----●-------------
   |  /  |
   |/    |  /
   |   ●──────────────  ← 我们真正截取的是 t >= 2 这一段
   | 2  |
   +----+------------------> t
       t=2

   若忘掉 t >= 2：会写出 a <= 2      ✗
   正确：最小值在 t = 2 处取，a <= 5/2
```

* 这道经典题要记住四件事：第一，恒成立求参数先想分离参数；第二，分离完转化成求最值；第三，最值怎么求——看着恶心的两部分之间一定要去找关系，找到关系再换元；第四，每换一个新元必须求新元的取值范围，然后才去套基本不等式、对勾函数等一切现成结论。

## 换元与动轴定区间

### 偶函数定参数

* 偶函数可走定义 $f(x)=f(-x)$，也可带特殊值减少计算量；$f(1)=f(-1)$ 一般更省事。
* 例 $f(x)=\frac{3^{a+1}+1}{3^{1-a}+9}$ 是定义域上的偶函数：交叉相乘得 $3\cdot3^{a}+1=3\cdot3^{-a}+9$，即 $3^{a}-3^{-a}=\frac83$。
* 令 $u=3^{a}>0$，$u-\frac1u=\frac83$，两边乘 $u$ 得 $3u^{2}-8u-3=0$，解得 $u=3$ 或 $u=-\frac13$（舍去），故 $a=1$。
* 答案对应的函数是 $f(x)=3^{x+1}+3^{1-x}$，把其中一个 $3$ 提出来正是 $a^{x}+a^{-x}$ 型；偶函数乘 $3$ 仍与偶函数性质相符。

### 平方关系与 $t$ 的取值范围

* $9^{x}$ 与 $3^{x}$ 的关系是 $9^{x}=3^{2x}$，二者能互相表示的关键是**隐含着平方关系**。
* 设 $t=3^{x}+3^{-x}$，则 $t^{2}=3^{2x}+3^{-2x}+2$，所以 $9^{x}+9^{-x}=t^{2}-2$。
* 于是 $g(x)=9^{x}+9^{-x}+m\cdot f(x)+m^{2}-1$ 变成关于 $t$ 的函数 $H(t)=t^{2}-2+3mt+m^{2}-1=t^{2}+3mt+m^{2}-3$。
* $t=3^{x}+3^{-x}$ 是类二次型函数，最小值 $2$，所以 $t\geq2$——这一步必须先定下来。
* > **结论**：出现 $a^{x}+a^{-x}$，又出现 $a^{2x}$ 与 $a^{-2x}$ 时，总是把一次的整体设成 $t$ 后平方，平方完之后另一部分自然而然就出现了，两部分用同一个 $t$ 表示。

### 动轴定区间

* 求二次函数的最小值时，如果对称轴是一个含参数的变量、而自变量只能取某段固定区间，那就是动轴定区间问题：要判断对称轴落在区间里面还是外面。
* 例 $H(t)=t^{2}+3mt+m^{2}-3$、$t\geq2$、对称轴 $t_{0}=-\frac{3m}{2}$。
    * $t_{0}\leq2$（即 $m\geq-\frac43$）：区间上整体递增，最小值在 $t=2$ 处取得，$H(2)=4+6m+m^{2}-3=m^{2}+6m+1$。可以取等号（相等时最小值依然在 $t=2$ 处取得）。
    * $t_{0}>2$（即 $m<-\frac43$）：先减后增，最小值在对称轴处取得，$H\left(-\frac{3m}{2}\right)=\frac{9m^{2}}{4}-\frac{9m^{2}}{2}+m^{2}-3=-\frac{5m^{2}}{4}-3$。
    * 写成分段：$m\geq-\frac43$ 时最小值为 $m^{2}+6m+1$，$m<-\frac43$ 时为 $-\frac{5m^{2}}{4}-3$。
* > **注意**：是令 $t$ 取 $2$ 得到 $H(2)$，不是令 $x$ 取 $2$。

```text
   H(t) = t² + 3mt + m² − 3 ，  t ≥ 2 ，  对称轴 t₀ = −3m/2

   情形一：t₀ ≤ 2 （即 m ≥ −4/3）        情形二：t₀ > 2 （即 m < −4/3）
         ↑                                        ↑        │
         │        ↗                                │    ╱───┼────
   2 ───┼──────╱───                        2 ───┼───────╱    │
         │    ╱    ↗                            │   ╱  t₀  ↘ ╱
         └──────────→ t                        └────────────────→ t
      递增，最小值在 t = 2                   递减再增，最小值在 t = t₀
```

* > **结论**：这一块的思维动作就两个——**同除同底幂把指数合并**，以及**换元之后由内到外一层层剥**。

## 两道指数中档题的通用套路

### 过两点求参数

* 「函数经过两点」第一反应是把点带进去解方程组；但当分母里也有 $2^{x}$ 时别硬算，**先把分母乘过去**。
* 得到的两个等式形状都是「左边一个 $2$ 的幂，右边一个带 $a$ 的 $a$ 的一次量」，题干常直接把「指数部分要相加、一次部分要相乘」告诉你。
* 做法是左乘左、右乘右，两个等式同向叠在一起，凑出 $2$ 的 $(p+q)$ 次幂与 $p\cdot q$，中间 $a^{2}$ 被整体约掉，再与题干等式一对即得解。
* > **结论**：凡遇到「左边一个指数函数、右边一个一次项」的式子套式子，第一反应永远是**同底幂相乘、异底幂相除，把指数凑到一起去**。

### 复合函数单调性求参数范围

* 二次函数作内层、$2^{\text{二次式}}$ 作外层，外层一定单调递增，所以「在 $[0,1]$ 上单调递减」只需要让内层在该区间上递减。
* 设内层为 $t$，开口向上的二次函数两根是 $0$ 与 $a$，对称轴为 $\frac a2$；要让 $[0,1]$ 整段落在递减的左半支上，需 $1\leq\frac a2$。
* 不需要分类讨论 $0$ 与 $a$ 谁在左边——无论谁在左，对称轴都是 $\frac a2$，把 $[0,1]$ 放进去看它是否整段落在左半支即可。
* > **提示**：每次列不等式都要验证能不能取等。$1=\frac a2$ 时两点重合，区间仍满足单调递减，所以 $a\geq2$。
