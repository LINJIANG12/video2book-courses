# 立体几何·外接球与内切球

---

## 外接球的存在性与球心

### 存在条件

    * **外接球（circumscribed sphere）**

        * > **定义**：过多面体全部顶点、且各顶点到此球心距离相等的球；半径等于球心到任意一个顶点的距离。

        * 三棱锥一定有外接球，四棱锥不一定有；因此绝大多数外接球题考的是三棱锥的外接球。

        * 球心确定后，半径随之确定，不需要另求。

### 球心的确定步骤

    * **通用求球心法**

        * 取一个面（一般是底面 $ABC$），先求出该三角形的外心 $O$。

        * 球心必在「过 $O$ 且垂直于平面 $ABC$」的这条直线上；只有直线上的点，到 $A$、$B$、$C$ 的距离才相等。

        * > **定义**：$SO$ 与 $OA$、$OB$、$OC$ 拼成三个直角三角形，公用高 $SO$，三条直角边因 $O$ 是外心而相等，故三条斜边 $SA$、$SB$、$SC$ 必相等。

        * 再在这条直线上取点，使其到没用上的那个顶点 $P$ 的距离等于它到底面任一顶点的距离，该点即球心。

```text
              P
              ●
              │╲
              │ ╲   PA ⊥ 平面 ABC
              │  ╲
       A ───●──O──●─── B      O：△ABC 的外心
             ╱
            ╱
           C

   l = 过 O 且垂直于平面 ABC 的直线
   球心 S 一定落在 l 上（只有 l 上的点，到 A、B、C 距离才相等）
```

    * 难题可能真的需要按这套通用步骤逐层定位；多数题目有可直接套用的模型。

## 补全模型：圆柱型与圆锥型

### 圆柱型（线面垂直）

    * **圆柱外接球**

        * > **定义**：上下底面圆上每一点都在同一球面上，轴截面上是一个以体对角线为斜边的直角三角形。

        * 设底面直径 $d$、高 $H$、外接球半径为大 $R$：

$$(2R)^2 = d^2 + H^2$$

        * 半径只与「底面直径」和「高」两个量有关。

    * **线面垂直补成圆柱**

        * 识别信号：题目明写线面垂直，如 $PB \perp$ 平面 $ABC$。

        * $PB$ 即圆柱的母线，$PB$ 的长度就是圆柱的高，与原三棱锥的高同值。

        * 底面三角形 $ABC$ 有唯一外接圆，把它作为圆柱底面圆、把 $P$ 放到上底面圆上；同一圆柱只有一个外接球，故三棱锥的外接球与该圆柱的外接球是同一个球。

        * 底面外接圆直径用正弦定理求：$\dfrac{a}{\sin A}=\dfrac{b}{\sin B}=\dfrac{c}{\sin C}=2R$，题目通常会给出「对边对角」；给的是三边就先余弦定理或作高求角。

        * > **结论**：出现线面垂直的三棱锥，不要在三棱锥本身上去想外接球位置，直接补成圆柱求外接球。

        * > **易错点**：题目里没有线面垂直时不要硬套圆柱型。

    * **线面垂直型代表例题**

        * 例：$PA \perp$ 平面 $ABC$，$PB = PC = 3$，$BC = 2\sqrt6$，$PA = 4$，求外接球表面积。等腰三角形作底边上的高得 $\sqrt3$，$\sin C = \dfrac{\sqrt3}{3}$，$2R_{\text{底}} = 3\sqrt3$。

$$2R_{\text{球}} = \sqrt{(3\sqrt3)^2 + 4^2} = \sqrt{43},\qquad S = 4\pi \cdot \frac{43}{4} = 43\pi$$

        * 例：$PA \perp$ 平面 $ABC$，$\angle B = \dfrac{\pi}{4}$，$BC = 2$，$AB = \dfrac{\sqrt2}{2}$，$PA = 1$，求外接球体积。补全法得 $AC = \dfrac{\sqrt{10}}{2}$，$2R_{\text{底}} = \sqrt5$，于是 $2R = \sqrt6$，$R = \dfrac{\sqrt6}{2}$，$V = \sqrt6\pi$。

        * 例：$PA \perp$ 平面 $ABC$，$\angle BAC = 120°$，$AB = 3$，$AC = 2\sqrt3$，$Q$ 在 $BC$ 上运动，直线 $PQ$ 与平面 $ABC$ 所成角最大值 $60°$，求外接球体积。取 $\tan\alpha = \dfrac{PA}{AQ} = \dfrac{3}{AQ}$（选 $AQ$ 作直角边，因为底面条件多而 $PQ$ 未知），$\tan\alpha$ 最大即 $AQ$ 最小，得 $AQ_{\min} = \sqrt3$；底面高 $\sqrt3$ 与半底 $\sqrt2$ 成 $1:2$，得 $30°$，$2R_{\text{底}} = \dfrac{2\sqrt3}{\sin 30°} = 4\sqrt3$。

$$2R_{\text{球}} = \sqrt{(4\sqrt3)^2 + 3^2} = \sqrt{57},\qquad V = \frac{19}{2}\sqrt{57}\,\pi$$

### 圆锥型（正棱锥）

    * **圆锥外接球**

        * 球心在圆锥的高上；底面半径为小 $r$，球心到底面的一段为 $H - R$，勾股定理：

$$r^2 + (H - R)^2 = R^2$$

        * 方程中 $R^2$ 可约掉，本质是一元一次方程，极易解出。

    * **正棱锥看成圆锥**

        * 正三棱锥、正四棱锥、正五棱锥、正六棱锥统一这样处理：底面正多边形有且只有一个外接圆，圆与上顶点构成圆锥，顶点与底面各顶点共用这个外接球。

        * 只需拿到圆锥的高 $H$ 与底面外接圆半径 $r$，连接球心与底面任一顶点即为所求半径。

        * 「方锥」即正四棱锥，出自《九章算术》。

    * **底面过球心的内接方锥**

        * 球 $O$ 的内接正四棱锥 $P-ABCD$ 底面过球心时，$O$ 到四个底面顶点距离都是 $R$，底面边长为 $\sqrt2 R$，底面积 $2R^2$，高为 $R$：

$$V = \frac13 \cdot 2R^2 \cdot R = \frac23 R^3$$

        * 由体积反解球半径即得 $R = 1$。

    * **正四棱锥的球截面**

        * 底面边长 $4\sqrt2$、侧棱 $4\sqrt5$：底面中心到顶点 $4\sqrt2 \cdot \dfrac{\sqrt2}{2} = 4$，高 $8$，于是圆锥底面半径 $4$、高 $8$，$4^2 + (8-R)^2 = R^2 \Rightarrow R = 5$。

        * 求平面截外接球的截面面积，走三步：定球心到截面的距离 $d$、用垂径定理求截面圆半径 $r_{\text{小}} = \sqrt{R^2 - d^2}$、再乘 $\pi$。

        * 求 $d$ 的省力做法：正四棱锥关于「过一组对棱中点的竖直面」对称，球心在该对称面上，球心到侧面的垂足必落在对称轴（顶面等腰三角形的中线）上，用大三角形定 $\sin\alpha$、小三角形定 $d$。本例 $PM = 8$、$MB = 2\sqrt2$、$PB = 6\sqrt2$，$\sin\alpha = \dfrac13$，小三角形斜边 $R = 5$，得 $d = \dfrac53$。

$$r_{\text{小}} = \sqrt{25 - \frac{25}{9}} = \frac{10\sqrt2}{3},\qquad S_{\text{截面}} = \pi r_{\text{小}}^2 = \frac{200}{9}\pi$$

        * > **易错点**：正棱锥几何性质丰富、各面互为对称，最容易在外接球之上再叠加截面面积、体积等考点。

## 垂面型与二面角型

### 垂面型：已知两面垂直

    * **识别信号**：题目明写两个面垂直，如 $PAC \perp ABC$。

    * **只看两个圆**：$PAC$ 与 $ABC$ 各有唯一外接圆，两垂直圆面与三棱锥共用同一外接球；因此只需两个外接圆半径 $R_1$、$R_2$ 与公共弦（交线）$AC$ 的长度 $L$。

    * **球心位置**：球心是「过 $O_1$ 作面 $PAC$ 的垂线」与「过 $O_2$ 作面 $ABC$ 的垂线」的交点；过两圆圆心向公共弦作垂线，垂足同为 $AC$ 中点 $G$，两段构成矩形。

```text
              面 PAC ⊥ 面 ABC，交线 AC = L

        A ●─────────────────────● C
         ╲                     ╱
          ╲    O₁G            ╱
           ╲     │           ╱
     ──────────────●G──────────────     ← 面 ABC，O₂ 在此面内
             ╱    │        ╲
           ╱     │         ╲

   球心 S = （过 O₁ 垂直面 PAC 的直线）∩ （过 O₂ 垂直面 ABC 的直线）
   R² = OO₂² + O₂A² = O₁G² + R₂²
```

    * **核心公式**

$$R^2 = R_1^2 + R_2^2 - \left(\frac{L}{2}\right)^2$$

        * 推导要点：$R^2 = OO_2^2 + O_2A^2$，而 $OO_2 = O_1G$，$O_1G^2 = R_1^2 - GC^2 = R_1^2 - \left(\dfrac{L}{2}\right)^2$。

        * $R_1$、$R_2$ 必能由正弦定理求出；$L$ 一般由题目直接给出（就是两个垂面的交线长度），很少需要自己求。

    * **垂面型代表例题**

        * 例：$PAB \perp ABC$，$PA = PB = 4$，$AB = 4\sqrt3$，$\angle ACB = 120°$。$\triangle PAB$ 是 $1:1:\sqrt3$，故 $30°$、$30°$、$120°$，$\dfrac{4\sqrt3}{\sin 120°} = 2R_1 = 8 \Rightarrow R_1 = 4$；$\triangle ABC$ 中 $120°$ 对边同为 $AB = 4\sqrt3$，故 $R_2 = 4$。

$$R^2 = 16 + 16 - \frac{(4\sqrt3)^2}{4} = 20,\qquad S = 4\pi R^2 = 80\pi$$

    * **鳄鱼小嘴模型：把隐藏的垂直顶出来**

        * > **定义**：若四边形中 $AB = AD$、$BC = CD$，形似张开的鳄鱼上下嘴；取 $BD$ 中点 $G$，连 $AG$、$CG$，则 $AG \perp BD$、$CG \perp BD$，从而 $BD \perp$ 平面 $AGCG'$，图形左右对称，中间截面是对称面。

        * 例：三棱锥中 $PC = 3\sqrt2$，其余各棱均为 $2\sqrt3$，全无垂直条件。取 $AB$ 中点 $G$，因 $\triangle PAB$、$\triangle CAB$ 均为边长 $2\sqrt3$ 的等边三角形，得 $PG = CG = 3$，而 $PC = 3\sqrt2$ 构成 $1:1:\sqrt2$，故 $\angle PGC = 90°$；$PG \perp AB$、$PG \perp GC$ 推出 $PG \perp$ 平面 $ABC$，又 $PG \subset$ 平面 $PAB$，故平面 $PAB \perp$ 平面 $ABC$，转入垂面型：$R_1 = R_2 = 2$（等边三角形 $\dfrac{2\sqrt3}{\sin 60°} = 4$），$L = 2\sqrt3$。

$$R^2 = 4 + 4 - \frac{12}{4} = 5,\qquad S = 4\pi R^2 = 20\pi$$

        * > **易错点**：垂直不一定直接给，往往要靠鳄鱼小嘴模型自己算出来；顶不出这层垂直，垂面型公式根本用不上。

        * 同一模型的变式练习同样不告知面面垂直：先取中点连辅助线顶出线面垂直，再定出两个垂面与交线长，代入 $R_{\text{球}}^2 = R_1^2 + R_2^2 - \dfrac{L^2}{4}$，最后对选项。

### 二面角型：已知两面夹角

    * **适用情形**：题目只给两个面形成的二面角 $\alpha$（$30°$、$60°$、$150°$ 等任意角），不给垂直。

    * **记号**：两圆圆心 $O_1$、$O_2$，公共弦 $AC$ 的中点 $G$，球心 $O$，$L = AC$。

    * **垂径定理给两条边**：

$$O_1G = M = \sqrt{R_1^2 - \left(\tfrac{L}{2}\right)^2},\qquad O_2G = N = \sqrt{R_2^2 - \left(\tfrac{L}{2}\right)^2}$$

    * **球面上的等腰三角形**：$OA = OC$，$G$ 是 $AC$ 中点，三线合一得 $\angle OGA = 90°$，故

$$R^2 = OG^2 + \left(\frac{L}{2}\right)^2$$

        * 四边形中另两个直角来自球心的构造：球心落在「过该面外接圆圆心且垂直该面」的直线上，于是 $\angle GO_1O = \angle GO_2O = 90°$。

    * **命门一步：把四边形看成两个直角三角形拼成的外接圆**

        * 两个直角三角形共用斜边 $OG$；由斜边中线等于斜边一半，两三角形共用同一外接圆圆心，即 $OG$ 是该圆的直径，$R_0 = \dfrac{OG}{2}$。

        * 二面角 $\alpha$ 由此变成 $\triangle GO_1O_2$ 的内角，可正大光明用正弦定理：$\dfrac{O_1O_2}{\sin\alpha} = 2R_0 \Rightarrow OG = \dfrac{O_1O_2}{\sin\alpha}$。

        * $O_1O_2$ 由余弦定理补：$O_1O_2^2 = M^2 + N^2 - 2MN\cos\alpha$。

    * **核心公式**

$$\boxed{\;R^2=\frac{M^2+N^2-2MN\cos\alpha}{\sin^2\alpha}+\left(\frac{L}{2}\right)^2\;}$$

        * 口诀：$\sin^2\alpha$ 的分母压着一个余弦定理 $M^2+N^2-2MN\cos\alpha$，再加 $\tfrac14L^2$。

        * 四个量中 $L$ 由题目给出，$\alpha$ 由题目给出，$M$、$N$ 必须自己用勾股定理抠出来。

        * > **提示**：约掉 $(1-\cos\alpha)$ 时留意 $\alpha = 0$ 的退化情形，此时 $\sin^2\alpha = 0$，公式分母为零不能算；$2R^2 \ne 0$ 已把这种可能排除。

    * **二面角型代表例题**

        * 反过来求二面角：$S\!-\!ABC$ 底面是边长 $3$ 的等边三角形，$SA = 2\sqrt3$，$SB = \sqrt3$，外接球表面积 $21\pi$，求二面角 $S\!-\!AB\!-\!C$ 的余弦值。$R_1 = \dfrac{3}{\sqrt3} = \sqrt3$；$\triangle SAB$ 三边除以 $\sqrt3$ 得 $2:1:\sqrt3$ 即 $1:\sqrt3:2$，是直角三角形，斜边 $2\sqrt3$ 为直径，$R_2 = \sqrt3$；$L = 3$，$M^2 = N^2 = 3 - \dfrac94 = \dfrac34$。

$$\frac{21}{4} = \frac{\tfrac34+\tfrac34-\tfrac32\cos\alpha}{\sin^2\alpha} + \frac94 \;\Longrightarrow\; \frac{3}{2}\cdot\frac{1-\cos\alpha}{1-\cos^2\alpha} = \frac{3}{2(1+\cos\alpha)} = 3 \;\Longrightarrow\; \cos\alpha = -\frac12$$

        * 反过来求表面积：$PABC$ 中 $\triangle PAC$ 是以 $AC$ 为斜边的等腰直角三角形，$AB = AC = \sqrt6$，$CB = 2\sqrt2$。$R_1 = \dfrac{\sqrt6}{2}$（斜边中点即圆心）；$\triangle ABC$ 为等腰三角形，$BC$ 边所对角的正弦为 $\dfrac{2}{\sqrt6}$，$\dfrac{\sqrt6}{2/\sqrt6} = 2R_2 \Rightarrow R_2 = \dfrac32$；$L = \sqrt6$，$M^2 = \dfrac64 - \dfrac64 = 0$，$N^2 = \dfrac94 - \dfrac64 = \dfrac34$。

$$R^2 = \frac{0+\tfrac34-0}{\sin^2\alpha} + \frac64 = \frac52,\qquad S = 4\pi R^2 = 10\pi$$

        * > **提示**：$M = 0$ 或 $N = 0$ 是正常情形，不是算错——它表示圆心恰落在公共弦上（如直角三角形斜边即直径），照常往公式里带即可。

## 长方体补全型

### 三种可塞入长方体的图形

    * **墙角模型**：三棱锥三条棱两两垂直，对应长方体的长、宽、高，题目必给三条棱长。

    * **两对棱垂直**：出现两对线线垂直时构成直角，属于「有时候」能塞进长方体，考得较少。

    * **对棱相等模型**：最常见，如 $PC = AB$、$PA = BC$ 两两相等。

    * > **结论**：墙角模型与对棱相等模型统一处理成「补全长方体」，求出长方体长宽高后带公式得半径。

### 对棱相等的摆放与长宽高

    * 上底面画一条对角线，下底面**反着**画另一条对角线，四点即三棱锥四个顶点。

```text
   上底面 ── 画一条对角线

   ┌───────────────┐
   │ P ╲           │
   │     ╲         │
   │       ╲       │
   │         ╲     │
   │           ╲   │
   │             ╲ │
   │               A
   └───────────────┘

   下底面 ── 反着画另一条

   ┌───────────────┐
   │               C
   │             ╱ │
   │           ╱   │
   │         ╱     │
   │       ╱       │
   │     ╱         │
   │ B ╱           │
   └───────────────┘
```

    * 每一条棱都是长方体的面对角线；面对角线按所在面成对相等，对棱相等天然成立；看到对棱相等就该往这个方向想。

    * 三条面对角线长设为 $m$、$n$、$p$，长宽高设为 $a$、$b$、$c$：

$$a^2+b^2=m^2,\qquad b^2+c^2=n^2,\qquad a^2+c^2=p^2$$

    * 球心就是长方体中心，体对角线即外接球直径：

$$(2R)^2 = a^2+b^2+c^2$$

    * 补全后与原三棱锥共用同一外接球，四个点都是长方体顶点。

    * **求解技巧**：只求外接球时不必解出 $a^2$、$b^2$、$c^2$，三式直接相加即可；若还问体积（需要 $abc$）才必须两两相减分别解出。

    * **等腰四面体代表例题**

        * 对棱相等的四面体称为等腰四面体。$AB = 4$，$BC = 5$，$\cos\angle ABC = \dfrac18$，则 $\dfrac18 = \dfrac{4^2+5^2-AC^2}{2\cdot4\cdot5} \Rightarrow AC = 6$，三条面对角线为 $4$、$5$、$6$。

$$a^2+b^2=36,\quad b^2+c^2=16,\quad a^2+c^2=25 \;\Longrightarrow\; a^2=\frac{45}{2},\; b^2=\frac{27}{2},\; c^2=\frac52$$

        * 体积用大体积减四个小三棱锥，每个小三棱锥都是墙角模型、体积 $\dfrac{abc}{6}$：

$$V = abc - 4\cdot\frac{abc}{6} = \frac13 abc = \frac{15\sqrt6}{4}$$

        * 表面积：

$$S = 4\pi R^2 = \pi(a^2+b^2+c^2) = \frac{77}{2}\pi$$

    * **墙角模型代表例题**

        * 2008 年福建高考题：三条侧棱两两垂直且长度都是 $\sqrt3$，长方体长宽高相同即正方体。

$$R^2 = a^2+b^2+c^2 = 3+3+3 = 9,\qquad S = 4\pi R^2 = 36\pi$$

    * **条件藏在折痕里的代表例题**

        * 三角形三边为 $\sqrt7$、$3$、$2$，$M$、$N$、$P$ 分别是三边中点，沿三条中位线折成四面体。

        * 折叠中 $A$、$B$、$C$ 三点汇聚于同一点 $G$，四面体以 $G$ 为顶点、$MNP$ 为底面；底面三边是中位线，长度为原边一半 $1$、$\dfrac32$、$\dfrac{\sqrt7}{2}$；三条侧棱长同为 $\dfrac{\sqrt7}{2}$、$\dfrac32$、$1$，即 $GM$ 与 $NP$、$GN$ 与 $MP$、$GP$ 与 $MN$ 分别对棱相等，落回对棱相等模型。

        * 直接相加求和：

$$a^2+b^2+c^2 = \frac{1}{2}\left(1+\frac94+\frac74\right) = \frac52,\qquad V_{\text{球}} = \frac43\pi R^3 = \frac{5\sqrt{10}\pi}{24}$$

## 正四面体常用数据

| 量 | 值（棱长记作 $a$） | 说明 |
| :--- | :--- | :--- |
| 高 | $\dfrac{\sqrt6}{3}a$ | 底面中心到顶点 |
| 体积 | $\dfrac{\sqrt2}{12}a^3$ | 最好会，不会也没关系 |
| 外接球半径 | $\dfrac{\sqrt6}{4}a$ | 由外接球模型得到 |
| 内切球半径 | $\dfrac{\sqrt6}{12}a$ | 由 $3V \div S_{\text{表}}$ 得到 |
| 棱切球半径 | $\dfrac{\sqrt2}{4}a$ | 三法通吃，见棱切球一节 |

    * 高的一柱擎天推法：底面中心与顶点连线，三条中线交成一个 $120°$ 的等腰三角形，其边长为 $\dfrac{\sqrt3}{3}a$，勾股定理得 $\dfrac{\sqrt6}{3}a$。

    * > **结论**：$\dfrac{\sqrt6}{4}a + \dfrac{\sqrt6}{12}a$ 正好等于高，说明正四面体的外接球球心与内切球球心重合于同一点。

```text
        D ●                顶点，高 h = √6a/3
          │
          │   R 外接球 = √6a/4  = 3h/4
          │
        O ○                三个球的球心重合在 O
          │   r 内切球 = √6a/12 =  h/4
          │   ρ 棱切球 = √2a/4   （球心相同，但半径更大！）
          │
        G ●                底面中心
```

    * $DO : OG = 3 : 1$，$O$ 是高的四等分点；外接球半径与内切球半径之和恰等于高，这是三球共心的证明。

    * > **易错点**：只有正四面体三球共心，一般三棱锥不成立。

## 内切球

### 轴截面法（对称锥体）

    * **对称锥体的通用套路**

        * 圆锥、圆台这类旋转对称体，球心必在图形中心线上，找对称截面（轴截面）把它降成平面图形来研究。

        * 球心到下底面的距离与到侧壁（母线）的距离都等于半径。

    * **方法一：找截面 + 相似（或三角函数）**

        * 例：圆锥底面半径 $1$、母线 $3$，求内切球体积。底面半径与母线之比 $1:3$，高为 $2\sqrt2$，球心到顶点距离 $2\sqrt2 - R$。

$$\frac{R}{2\sqrt2 - R} = \frac13 \;\Longrightarrow\; R = \frac{\sqrt2}{2},\qquad V = \frac43\pi R^3 = \frac{\sqrt2}{3}\pi$$

    * **方法二：等面积法求内切圆半径**

        * 放进截面后，要的半径就是该三角形内切圆的半径。以内切圆圆心把三角形分成三个小三角形，各高都是 $R$，面积和为原面积 $S$：

$$S = S_1 + S_2 + S_3 \;\Longrightarrow\; \frac12 L R = S \;\Longrightarrow\; R = \frac{2S}{L}$$

        * 该式对任意三角形都成立。本例底 $2$、高 $2\sqrt2$，$S = 2\sqrt2$，周长 $L = 3+3+2 = 8$，$R = \dfrac{2\times2\sqrt2}{8} = \dfrac{\sqrt2}{2}$，与方法一一致。

    * **圆台内切球**

        * > **提示**：题目说「存在内切球」是有信息量的——并非所有圆台都有内切球；又高又瘦的圆台与两侧面相切就与上下底面不相切，反之亦然。

        * 轴截面是梯形。把圆画成既切底边又切腰，底面位置即被唯一确定；连辅助线得两个直角，由 HL 全等知下底面半径也为 $2$、下半段腰长也是 $2$，梯形定为上边 $4$、下边 $8$、腰 $6$。

        * 圆与上下两条平行边都相切，而两平行边间距即圆台的高，故半径等于高的一半：

$$h = \sqrt{6^2 - 2^2} = 4\sqrt2,\qquad r = 2\sqrt2,\qquad S_{\text{球}} = 4\pi r^2 = 32\pi$$

        * > **易错点**：不是所有锥体都有对称性。普通三棱锥没有轴截面，对称截面这条路直接断掉，必须换等体积法。

### 等体积法

    * **等体积法（general formula）**

        * > **定义**：球与每个面只有一个切点，把切点与球心连起即为半径；球心把锥体分成若干小锥体，每个的体积都是 $\dfrac13 S_i R$，公用高都是内切球半径。

        * 四面体被分成四个：底面一个、$PAB$、$PAC$、$PBC$ 各一个。于是

$$V = \frac13 (S_1 + S_2 + S_3 + S_4)\cdot R \;\Longrightarrow\; R = \frac{3V}{S_{\text{表}}}$$

        * 用法：求出多面体体积与表面积，相乘 3 后相除即可，不要求图形有对称性。

    * **翻折题里的「体积最大」翻译成面面垂直**

        * 例：边长 $2$ 的正方形沿对角线 $AC$ 对折成三棱锥，求体积最大时的内切球。$D$ 的轨迹是以 $AC$ 中点 $G$ 为圆心的圆，两个面之间的二面角不断变化。

        * > **结论**：当且仅当两个折面面面垂直时，所得三棱锥体积最大——面面垂直时过 $D$ 作交线 $AC$ 的垂线所得 $DG$ 恰是高；其他时刻新连的高与 $DG$ 构成直角三角形，$DG$ 是斜边更短，等于把高变短，体积减小。

        * 所以「翻折过程中体积最大」这个条件，固定翻译成面面垂直。

        * 面面垂直时底面积 $1 \times 2 = 2$，$AG = \sqrt2$，$DG = \sqrt{2^2-(\sqrt2)^2} = \sqrt2$：

$$V = \frac13 \times \frac12 \times 2 \times 2 \times \sqrt2 = \frac{2\sqrt2}{3}$$

        * 表面积：底面 $2$，侧面 $ADC$ 翻折前后面积不变也是 $2$，另两个面是边长 $2$ 的等边三角形、各 $\sqrt3$，共 $2\sqrt3$。

$$S_{\text{表}} = 4 + 2\sqrt3,\qquad R = \frac{3V}{S_{\text{表}}} = \frac{2\sqrt2}{4+2\sqrt3} = \frac{\sqrt2}{2+\sqrt3} = 2\sqrt2 - \sqrt6$$

        * 分母有理化用平方差公式，上下同乘 $2 - \sqrt3$。

        * > **易错点**：边长 $a$ 的等边三角形面积 $\dfrac{\sqrt3}{4}a^2$ 必须背下来。

    * **墙角模型：翻折不只锁长度，还锁角度**

        * 例：边长 $2$ 的正方形，三个三角形分别沿三条边上折，使 $A$、$B$、$C$ 折到同一点 $A_1$，构成三棱锥。

        * > **提示**：翻折不只用「线段长度不变」，也保留「角度不变」——$A$ 点处折出的三个直角折完仍是三个直角，一旦认出三个角都是直角就是墙角模型，可直接放进长方体：由 $A$ 点引出的三条线分别作长宽高，两条为 $1$、一条为 $2$，即 $1\times1\times2$ 的长方体。

$$V = \frac13 \times \frac12 \times 1 \times 2 \times 1 = \frac13$$

        * 内切球：三个侧面就是墙角引出的三个直角三角形，底面另算，四个面加起来 $S = 4$，故 $r = \dfrac{3V}{S} = \dfrac{3\times\frac13}{4} = \dfrac14$，$V_{\text{球}} = \dfrac43\pi\left(\dfrac14\right)^3 = \dfrac{\pi}{48}$。

        * > **易错点**：判断某个面是不是面面垂直必须靠算，不能靠看。若 $A_1EF$ 与底面面面垂直，则过 $A_1$ 作 $EF$ 的垂线、因 $\triangle A_1EF$ 等腰而三线合一得的 $A_1G$ 应同时垂直于 $GD$；但算出 $1 + 9 \ne 5$，三边不满足勾股，说明 $A_1G$ 不是高、面面垂直不成立。

        * 遇到这种情况改用鳄鱼小嘴模型：$A_1E = A_1F$、$BE = BF$、$DE = DF$，取 $BD$ 中点连 $AG$、$CG$，新三角面是整个图形的对称面，高落在对称面底边 $CG$ 上，外接球球心与内切球球心也都落在该面上。

        * **抓对称就是全部**：不管二面角是 $30°$、$45°$、$60°$ 还是任意角，其性质都落在轴截面（对称面）上。

### 分析内切球的通用手法

    * > **提示**：内切球问题往往可以把三维图形转成分析一个面上的图形；这个面通常来自图形的对称性，做法就是鳄鱼小嘴取中点构造对称面。

## 球与球相切

    * **两球相切的基本结论**

        * > **结论**：两球相切时，两个球心与切点三点必在一条直线上，圆心距等于 $R_1 + R_2$。

    * **正四面体里塞两个球**

        * 正四面体先后加入一大一小两球，大球是该四面体的内切球；小球与大球相切且与三个侧面都相切。设棱长 $a = 6$，高 $h = 2\sqrt6$，大球直径恰为高的一半 $=\sqrt6$。

        * 笨方法：小球在高的正对称截面上，切点必在侧面三角形的高上；侧面三角形的高（侧棱中线）为 $2\sqrt3$，底面中心到棱的距离为 $\sqrt3$，大三角形正弦值 $\dfrac{\sqrt3}{3\sqrt3} = \dfrac13$，小球那一段为 $\sqrt6 - r_2$。

$$\frac{r_2}{\sqrt6 - r_2} = \frac13 \;\Longrightarrow\; r_2 = \frac{\sqrt6}{4}$$

        * 巧解法：过两球唯一交点作与底面平行的面，小球只与这个新底面有一个交点，所以小球就是这个新小三棱锥的内切球。大四面体的高被大球直径按 $1:2$ 分成（大球球心占高的 $\dfrac14$，直径占 $\dfrac12$），图形整体等比缩小，内切球半径同比缩小：

$$r_1 = \frac{\sqrt6}{12}\times 6 = \frac{\sqrt6}{2},\qquad r_2 = \frac{\sqrt6}{4},\qquad r_1 : r_2 = 2 : 1$$

    * **圆柱里塞小球**

        * 圆柱底面半径 $R$、高 $2R$，轴截面恰为正方形。塞入与内切球外切、且与底面侧面都相切的小球：小球心在对角线上，形成的小正方形对角线为 $\sqrt2(R-r)$，这条对角线同时是两球球心距 $R + r$。

$$\sqrt2 R - \sqrt2 r = R + r \;\Longrightarrow\; r = \frac{\sqrt2-1}{\sqrt2+1}R = (3-2\sqrt2)R$$

        * 容纳球数：作俯视图，化为圆内塞圆，圆心、切点共线。连垂线放直角三角形，斜边为 $R - r$、直角边为 $r$：

$$\sin\alpha = \frac{r}{R-r} = \frac{3-2\sqrt2}{2\sqrt2-2}$$

        * 取 $\sqrt2 \approx 1.414$，得 $0.1994 < 0.207 < 0.2079$，即 $11.5° < \alpha < 12°$，一个球占角 $2\alpha \in (23°, 24°)$。

$$\frac{360°}{24°} = 15 < \frac{360°}{23°} \approx 15.65$$

        * 一周能放 $15$ 点多，必取整：每层 $15$ 个（还多一点小空隙，但塞不下 $16$ 个）；上下两层合计 **$30$ 个**。

## 棱切球

### 定义与切点定位

    * **棱切球（insphere of edges）**

        * > **定义**：与多面体各个棱都相切的球；内切球是到各个面距离相等，棱切球是到各个棱距离相等。

        * 「点到一条棱的距离」必须作垂线，垂足即切点；确定球心的前提是先确定切点在哪，切点位置相当关键。

        * 考的棱切球题其几何体几乎都有对称性；一旦不对称，棱切球没法做。

    * **切点靠对称性确定**

        * 正四面体中 $BD = BC$，用鳄鱼小嘴模型取轴截面画中点：球无论画在哪画多大，与 $DC$ 这条棱的切点不可能在轴截面前面或后面——图形前后对称，切点唯一，只能落在轴截面的中点上；同理 $CD$、$AD$ 的切点也在各自中点。

    * **正四面体棱切球：三法通吃**

        * 正四面体棱长 $a$，与六条棱都相切球的表面积。

        * 方法一（最基础、最通用）：老实找球心找切点，列等式，上下两个三角形都列勾股。

$$R + \sqrt{R^2 + \frac{a^2}{4}} = \frac{\sqrt6}{3}a$$

        * > **提示**：两个根号的问题不要直接两边平方，先把其中一个根号移过去再平方，$R^2$ 与 $R^2$ 正好约掉，剩下全是 $a^2$，解出 $\rho = \dfrac{\sqrt2}{4}a$。

        * 方法二（共用球心）：正四面体面面对称，外接球球心与内切球球心是同一点，与各棱等距的棱切球球心也在同一点；球心相同但半径要重算。

$$\rho^2 = \left(\frac{a\sqrt3}{6}\right)^2 + \left(\frac{\sqrt6 a}{12}\right)^2 = \frac{a^2}{12} + \frac{a^2}{24} = \frac{a^2}{8} \;\Longrightarrow\; \rho = \frac{\sqrt2}{4}a$$

        * 方法三（放进正方体）：正四面体各棱相等即满足对棱相等，可内接于正方体；正方体高度对称，棱切球球心在正方体中心，切点是棱中点，该点到正方体棱长的一半即半径。正四面体棱长 $a$ 时正方体棱长为 $\dfrac{\sqrt2}{2}a$，其一半为 $\dfrac{\sqrt2}{4}a$。

        * 三法殊途同归：

$$\rho = \frac{\sqrt2}{4}a,\qquad S = 4\pi \rho^2 = \frac{\pi a^2}{2}$$

        * > **易错点**：方法多是因为正四面体特殊；换成普通三棱锥只能老老实实找球心、找切点、列方程。

    * **正三棱锥棱切球：球心跑到延长线上**

        * 2022 年广东一模：正三棱锥底面边长 $2\sqrt6$、侧棱 $3$，求棱切球半径。

        * 一柱擎天求高：底面边长一半 $\sqrt6$，在 $1:1:\sqrt3$ 的等腰三角形中 $\sqrt6 \div \sqrt3 = 2\sqrt2$。

$$h = \sqrt{3^2 - (2\sqrt2)^2} = 1$$

        * 高只有侧棱的 $\dfrac13$，是很矮很胖的三棱锥：三棱锥较高时外接球、内切球、棱切球球心都在体内；很矮时无法在高上找到使两距离相等的点，球心跑到体外，须在延长线上找。

        * 之前的计算不白算：$\sqrt2$、$R$、$\sqrt{R^2-2}$ 与球心相对位置全都不变；连球心与顶点得两个直角三角形共用斜边、高相等，由 HL 全知另一边相等（是底边的一半 $\sqrt6$），对应长度相等。

        * > **提示**：错的只是加减号——正四面体是「两段相加等于高」，这里变成「长的减短的等于高」，即 $1$；两个根号仍用移项再平方，$R^2$ 约掉。

$$\rho = \sqrt{120 - 48\sqrt6}$$

        * 开根号得到的是负值形式，不必慌：$\rho^2$ 本身带根号，按「平方后中间是减号、且二倍两者乘积对得上」在选项中筛选（$2 \times 4 \times 3\sqrt6 = 24\sqrt6$，恰是 $48$ 的一半），对应选项 C。

## 模型选择与练习重点

| 题目给的条件 | 用哪个模型 | 核心动作 |
| :--- | :--- | :--- |
| 两个面互相垂直 | 垂面型 | 只看两个外接圆，矩形里量对角线 |
| 只给两面形成的二面角 | 二面角型 | 两外接圆 + 垂径定理 → 余弦定理 + 正弦定理 |
| 三条侧棱两两垂直 | 墙角模型 | 补全成长方体 |
| 对棱两两相等 | 对棱相等模型 | 上下一条反向对角线，补全长方体 |
| 三棱锥明写线面垂直 | 圆柱型 | 补全成圆柱，底面直径与高勾股 |
| 正棱锥（正四棱锥 / 方锥） | 圆锥型 | 看成圆锥，列 $r^2 + (H-R)^2 = R^2$ |
| 轴截面是圆锥 / 圆台 | 内切球轴截面法 | 截面 + 相似，或等面积法 $R = \dfrac{2S}{L}$ |
| 一般不对称锥体 | 内切球等体积法 | $R = \dfrac{3V}{S_{\text{表}}}$ |
| 球与球相切 | 球心切点共线 | 圆心距 $= R_1 + R_2$，可转化为某个小三棱锥的内切球 |

    * 出现两面夹角就用二面角型，把两个三角形的事变成两个圆的事，最后解一个四边形；出现墙角模型、对棱相等模型，或一道题里垂直条件特别多，就补全成长方体——垂直条件越多，越该往长方体上想。

    * 五个外接球模型可压成一句话：看到线面垂直补圆柱，看到正棱锥想圆锥，看到面面垂直用 $R^2 = R_1^2 + R_2^2 - \dfrac{L^2}{4}$，看到两面夹角用二面角型，看到墙角或对棱相等补长方体。

    * 练习重点：垂面型中不告知面面垂直的变式题（须自己用鳄鱼小嘴顶出垂直）；正四棱锥一类因几何性质丰富、各面互为对称，最容易在外接球之上叠加截面面积与体积考点，值得反复练熟。
