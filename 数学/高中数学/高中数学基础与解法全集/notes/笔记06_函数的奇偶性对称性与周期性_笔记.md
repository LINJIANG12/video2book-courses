# 函数的奇偶性·对称性与周期性

## 奇偶性的代数定义

* **偶函数（even function）**

    * > **定义**：满足 $f(-x) = f(x)$ 的函数，图像关于 $y$ 轴轴对称。

        * 推导本质：图像左右对称，取横坐标 $x$ 与 $-x$ 两点，纵坐标必须相等。
        * 对称轴的一般化即 $f(a+x) = f(a-x)$，当 $a = 0$ 时退化成本式。

* **奇函数（odd function）**

    * > **定义**：满足 $f(-x) = -f(x)$ 的函数，图像关于原点中心对称。

        * 三个等价写法互相通用：$f(x) = -f(-x)$、$f(-x) = -f(x)$、$f(x) + f(-x) = 0$。
        * 推导本质：关于原点对称时两点纵坐标互为相反数，而互为相反数等价于相加等于 $0$。

* **四类划分**

    * 按对称性，函数分四类：奇函数、偶函数、非奇非偶函数、既奇又偶函数。

    * 非奇非偶函数大量存在，如任取一条不过原点的直线，既不关于 $y$ 轴对称也不关于原点对称。

    * 既奇又偶的函数只有一类：$y = 0$。因为 $x$ 轴既关于 $y$ 轴对称，又关于原点对称。

    * 奇偶性是更一般的对称性（轴对称 $x=a$、中心对称 $(a,b)$）在 $a=0$、$b=0$ 时的特例。

## 定义域是第一道关口

* **定义域关于原点对称是必要前提**

    * > **结论**：判断奇偶性先看定义域。定义域不关于原点对称的，图像一定不关于 $y$ 轴或原点对称，可直接出局。

        * 前提只说「有可能」具备奇偶性，是否真是奇或偶还要具体分析。
        * 典型反例：$f(x)=x^2$ 定义域为 $(-1,1]$，左开右闭，左右不对称，故不是偶函数。

* **有限点定义域**

    * 由根号条件解出的定义域若只剩有限个点，如 $\sqrt{1-x^2}+\sqrt{x^2-1}$，需 $\{-1,1\}$ 两点同时满足。

    * 此时可直接把 $x^2 = 1$ 代回化简，函数值恒为 $0$，落在 $x$ 轴上，故是既奇又偶函数。

* **不对称定义域直接判死**

    * 分式整体要求 $\ge 0$ 时，两式同号等价于相乘 $\ge 0$，但必须补上分母不为 $0$ 的隐藏条件。

    * 解出定义域为 $[-1,1)$ 一类的左闭右开区间时，不关于原点对称，直接判非奇非偶。

## 判定流程

* **两步法**

    * > **结论**：第一步看定义域；第二步定义域对称后，能画图就直接看图像，画不了就算 $f(x)$ 与 $f(-x)$ 的关系——相等是偶函数，互为相反数是奇函数，两者都没关系是非奇非偶。

    ```text
                判断奇偶性
                    |
      +-------------+-------------+
      |                           |
  第一步：看定义域            定义域不对称
      |                        （直接出局）
      | 对称
      +-------------+-------------+
                    |
        +-----------+-----------+
        |                       |
     能画图                   画不了（太复杂）
        |                       |
     看图像               算 f(-x) 与 f(x)
        |                       |
        +-----------+-----------+
                    |
       相等 → 偶函数   互为相反数 → 奇函数
                    |
            两者都没关系 → 非奇非偶
    ```

* **画不出图时算 $f(-x)$**

    * 图像复杂的函数（如 $f(x)=\dfrac{|x^3-x|}{\sqrt{x^2-1}}$）属最常见情形，只能走代数。

    * 先由根号在分母上取严格大于：$x^2 > 1$，得定义域 $(-\infty,-1)\cup(1,+\infty)$，关于原点对称，可以继续。

* **化简要点**

    * 偶次幂括号内的负号直接消掉，如 $(-x)^2 = x^2$。

    * 奇次幂括号内的负号要提出来，如 $(-x)^3 = -x^3$。

    * 绝对值内整体取相反数，值不变，所以 $\left|-x^3+x\right| = \left|x^3-x\right|$。

    * 化简后 $f(-x)$ 的解析式与 $f(x)$ 完全一致，即为偶函数。

## 必背奇偶函数清单

* **奇函数清单**

    | 函数 | 说明 |
    | :--- | :--- |
    | $y = x,\; y = x^3,\; y = x^5$ | $x$ 的奇数次幂 |
    | $y = \dfrac{1}{x},\; y = \dfrac{1}{x^3}$ | 反比例型，$x$ 的奇数次幂 |
    | $y = x + \dfrac{1}{x}$ | 对勾函数 |
    | $y = x - \dfrac{1}{x}$ | 双刀函数 |

* **偶函数清单**

    | 函数 | 说明 |
    | :--- | :--- |
    | $y = x^2,\; y = x^4,\; y = x^6$ | $x$ 的偶数次幂，图像全是向上开口的抛物线 |
    | $y = \lvert x \rvert$ | 关于 $y$ 轴对称的一条折线 |

* 清单会随函数种类增加而扩充，学到指数函数、对数函数后需扩充到十几个乃至二十几个。

## 奇偶性的运算律

* **四条结论**

    | 组合 | 结果 |
    | :--- | :--- |
    | 奇 $+$ 奇 | 奇 |
    | 奇 $\times$ 奇 | 偶 |
    | 奇 $\times$ 偶 | 奇 |
    | 奇 $+$ 偶 | 非奇非偶 |

    * 减法与加法同规律，除法与乘法同规律：奇除以奇得偶。

* **负号的塞与消**

    * > **结论**：偶函数的括号内负号可加可约；奇函数括号内的负号能提到外边写成 $-f(x)$，外边的负号也能塞进括号写成 $f(-x)$。

    * 这是化简奇偶混合式子的主力工具，能化腐朽为神奇。

* **证明范式**

    * 函数长相复杂时第一步是「设」：设 $h(x) = f(x)g(x)$，把整体当成新函数。

    * 例：设 $f$、$g$ 均为奇函数，则 $h(-x) = f(-x)\cdot g(-x) = [-f(x)]\cdot[-g(x)] = f(x)g(x) = h(x)$，故 $h$ 为偶函数。

## 零点性质与参数求解

* **零点性质**

    * > **结论**：在原点处有定义的奇函数必有 $f(0) = 0$。

        * 推导：由 $f(x) + f(-x) = 0$ 令 $x = 0$，得 $2f(0) = 0$。

        * 「在原点处有定义」不可省略：$y = \dfrac{1}{x}$ 是奇函数，但原点处无定义。

        * 图像上等价于奇函数必经过原点。

* **取特殊值法**

    * > **结论**：已知奇偶性求参数时，可把 $f(\text{甲}) = \pm f(\text{乙})$ 中的自变量代成 $0$、$1$、$2$ 等特殊值，建立关于参数的方程，比通篇化简省力。

    * 例：$g(-1) = -g(1)$ 化为 $(3a+2-1)^5 = -(3a-3)^5$，五次幂约掉后得 $3a+1 = -(3a-3)$，即 $6a = 2$，$a = \dfrac13$。

    * 代特殊值时先检查取值是否使分母为 $0$：如分母含 $x - 1$ 时不能代 $x = 1$，可改代 $x = 2$。

    * 直接写 $f(x) = -f(-x)$ 的笨办法在选择填空中很少用，一般只在大题严格证明时使用。

* **从定义域抠参数**

    * > **结论**：题目同时给出定义域且函数为奇偶函数时，定义域两端的点一定互为相反数，可直接把参数解出。

    * 例：定义域由两个分母排除得 $x \ne 1$ 与 $x \ne -\dfrac{a}{3}$，两排除点必须关于原点对称，故 $a = 3$，连代值都省了。

    * 例：偶函数定义域端点满足 $a - 6 = -2a$，得 $a = 2$；解析式再由 $f(1) = f(-1)$ 得 $2b = 0$，即 $b = 0$，于是 $a + b = 2$。

* **零点性质直取参数**

    * 三次函数 $f(x)$ 已知为奇函数，把所有 $x$ 代 $0$ 后化简得 $f(0) = a$，由 $f(0) = 0$ 直接得 $a = 0$。

## 由奇偶性反求解析式

* **求谁设谁**

    * 已知定义在 $\mathbf{R}$ 上的奇函数在 $x > 0$ 时的解析式，求整个解析式。

    * > **方法**：设 $x < 0$，由奇性得 $f(x) = -f(-x)$；此时 $-x > 0$ 可代入已知解析式，把式中的 $x$ 全部换成 $-x$。

    ```text
                  y 轴
                   │
          f(x) ↖   │   ↗ f(-x)
          (未知)   │   (已知：x > 0 的解析式)
         ──────────┼──────────────► x
          x < 0    │      -x > 0
                   │
            关于原点对称：f(x) = -f(-x)
    ```

    * 不画图时纯代数也成立：$x < 0 \Rightarrow -x > 0$，把 $-x$ 当作整体代入即可。

* **$x = 0$ 必须单列**

    * > **易错点**：题干说「定义在 $\mathbf{R}$ 上」时解析式要分三段，$x = 0$ 那段要单独抠出来。往已有分段里代代不进去——分母为 $0$。回到原点用 $f(0) = 0$。

    * 三段式结果形如 $f(x)=\begin{cases} x^2 + \dfrac{1}{x} + 2, & x > 0 \\ -x^2 + \dfrac{1}{x} - 2, & x < 0 \\ 0, & x = 0 \end{cases}$。

* **一个方程两个未知数**

    * 设 $f$ 为偶函数、$g$ 为奇函数，由 $f(x) + g(x) = \dfrac{1}{x-1}$ 求 $f(x)$。

    * 把所有 $x$ 换成 $-x$ 得第二式 $f(-x) + g(-x) = \dfrac{1}{-x-1}$，再用偶性奇性代回即两方程两未知数。

    * 一加一减相消后得 $2f(x) = \dfrac{1}{x-1} + \dfrac{1}{-x-1}$，即 $f(x) = \dfrac{1}{2(x-1)} - \dfrac{1}{2(x+1)}$。

## 对称轴的一般式

* **标准式**

    * > **定义**：$f(a+x) = f(a-x) \iff$ 函数 $f(x)$ 的图像关于直线 $x = a$ 对称。

    * 推导：设对称轴两侧一段长度为 $x$，则两侧点横坐标为 $a+x$ 与 $a-x$，轴对称要求纵坐标相等。

    * $x = a$ 的来历：它正是 $a+x$ 与 $a-x$ 的中点 $\dfrac{x_1 + x_2}{2} = \dfrac{2a}{2}$。

* **一般式**

    * > **定义**：$f(A+x) = f(B-x) \iff$ 对称轴为 $x = \dfrac{A+B}{2}$。

    * 例：$f(x) = f(4-x)$ 中对称轴 $x = \dfrac{x + (4-x)}{2} = 2$。

    * 例：$f(3-x) = f(9+x)$ 中对称轴 $x = \dfrac{3 + 9}{2} = 6$。

* **系数无关**

    * $x$ 前的系数换成 $2x$、$3x$、$\dfrac12 x$ 一律不影响结论，照样丢给中点坐标公式处理。

    * 例：$f(100 - 2x) = f(300 + 2x)$ 中对称轴 $x = \dfrac{300 + 100}{2} = 200$。

    * > **易错点**：真正要盯的是两个横坐标能否约掉（系数互为相反数），而不是系数的具体数值。

## 对称中心的一般式

* **标准式**

    * > **定义**：$f(a+x) + f(b-x) = c \iff$ 对称中心为 $\left(\dfrac{a+b}{2},\ \dfrac{c}{2}\right)$。

    * 判定依据只有两条：纵坐标之和为定值；两个横坐标相加也是定值（一个 $+x$ 一个 $-x$ 恰好消掉，只剩 $a+b$）。

    * 记作 $(M,N)$ 时对应 $a + b = 2M$、$c = 2N$，求中心就是「和的一半」。

* **纵坐标要除以二**

    * 横坐标取两个横坐标的中点，纵坐标取两个纵坐标中点，右侧已加好的定值要再除以 $2$。

    * 例：$f(3-x) + f(5+x) = 6$ 的对称中心是 $(4,3)$；$f(9+x) + f(-5-x) = 4$ 的是 $(2,2)$。

    * 例：$f(3+x) + f(2-x) = 8$ 的是 $\left(\dfrac52, 4\right)$；$f(100-2x) + f(300+2x) = 300$ 的是 $(150,150)$。

    * > **易错点**：等号右边的 $c$ 是纵坐标和的一半的**两倍**，必须除以 $2$ 才能拿回纵坐标本身。

* **中位线几何图像**

    ```text
                  A ●━━━━━━━━━━━● B          上底 = f(a - x)
                    ╲           ╱
                     ╲         ╱
                      ╲       ╱
              M₁   ●━━━━━━━━━━━●           中位线 = b
                      ╱       ╲
                     ╱         ╲
                    ╱           ╲
                  C ●━━━━━━━━━━━● D          下底 = f(a + x)

       上下底的中点连线 = 梯形中位线，长度 = (上底 + 下底) / 2
    ```

    * 两个全等梯形上下翻转拼成矩形，即可得出「上底 + 下底 = 中位线的两倍」。

    * 翻译回函数值即 $f(a-x) + f(a+x) = 2b$。

* **同一中心的多种写法**

    * 一个式子只能推出一个对称中心，反过来表达同一对称中心的式子可以有多种写法，只需保证横坐标相加除以 $2$ 相同。

    * $f(x) + f(4-x) = 0$、$f(1-x) + f(3+x) = 0$ 的对称中心都是 $(2,0)$。

    * 反向编造：$f(6+x) + f(m-x) = 0$ 要以 $(2,0)$ 为中心，则 $(6+m) \div 2 = 2$，得 $m = -2$。

## 轴对称与中心对称的分流判据

* **唯一信号：括号里 $x$ 的正负**

    * 对称性的表达式必须同时满足三条：两个 $f$；括号里一个是 $+x$ 一个是 $-x$；横坐标相加为定值。

    * 括号里两个 $x$ 同为正或同为负，则不是对称性，而是周期性。

    ```text
            看括号里面 x 的正负号 —— 这是唯一判断标准

                  一个正 x，一个负 x  ──►  对称性
                  ( x 前符号一正一负 )     右边两个 f 相等  → 对称轴
                                          右边两个 f 相加  → 对称中心

                  x 同为正，或同为负  ──►  周期性
                  ( 注意是括号里面 )       f 外边的正负无所谓
    ```

* **$f = f$ 与 $f + f = \text{常数}$**

    | 式子长相 | 说的是 | 结论 |
    | :--- | :--- | :--- |
    | $f(\cdot+x) = f(\cdot-x)$ | 两个 $f$ 相等 | 对称轴 $x = \dfrac{A+B}{2}$ |
    | $f(\cdot+x) + f(\cdot-x) = C$ | 两个 $f$ 相加是定值 | 对称中心 $\left(\dfrac{A+B}{2}, \dfrac{C}{2}\right)$ |

    * 两个 $f$ 相等：纵坐标一样高，是左右对称，属轴对称。

    * 两个 $f$ 相加为定值：一个高一个矮、一高一低夹着一点，是中心对称。

    * 奇函数（中心 $(0,0)$）与偶函数（轴 $x=0$）是这一判据下的特例。

* **带负号先移项**

    * 形如 $f(\cdot) = -f(\cdot)$ 的式子先移项，立刻变成 $f(\cdot) + f(\cdot) = \text{常数}$，中心对称形态毕露。

    * 例：$f(x) = -f(6-x)$ 移项为 $f(x) + f(6-x) = 0$，对称中心 $(3,0)$；选「周期 6」「周期 12」者是把括号内的正负号看漏了。

## 平移与对称性的搬移

* **$f(x+2)$ 是奇函数**

    * > **结论**：$f(x+2)$ 是奇函数 $\iff f(x)$ 的对称中心是 $(2,0)$。

    * 平移方向推法：$f(x+2)$ 是 $f(x)$ 向左平移两个单位，反推要把 $f(x+2)$ 向右移回两个单位，故中心从 $(0,0)$ 移到 $(2,0)$。

    * 代数保底法：设 $g(x) = f(x+2)$，$g$ 为奇函数得 $g(x) = -g(-x)$，即 $f(x+2) + f(-x+2) = 0$，横坐标 $(x+2)$ 与 $(2-x)$ 相加除以 $2$ 得 $2$，定值 $0$ 除以 $2$ 得 $0$，中心 $(2,0)$。

* **平移会把对称中心一起搬走**

    * 由 $f(1-x) + f(3+x) = 0$ 只能先求出 $f(x)$ 的对称中心 $(2,0)$。

    * 若题目问的是 $f(x+2)$ 的图像，则 $f(x+2)$ 是 $f(x)$ 左移两个单位，中心变成 $(0,0)$，即关于原点对称。

    * 同理 $y = \dfrac{1}{x-2}$ 是 $y = \dfrac{1}{x}$ 右移两个单位，对称中心由 $(0,0)$ 变为 $(2,0)$。

## 共用对称中心的两个函数

* **交点成对出现**

    * 两个函数的对称中心都是 $(2,0)$ 时，图像的任意一个交点必能找到关于该中心对称的另一个交点。

    ```text
              一号函数图象(蓝)              二号函数图象(红)
                    \                          /
                     \        · · · · ·        /
                      \    ·             ·    /
                       \  ·               ·  /
              ----------●-------------------●----------
                        ·        (2,0)      ·
                         ·                 ·
                          ·               ·
                           ·             ·
                            · · · · · · ·

       两曲线关于 (2,0) 成中心对称
       ⇒ 任意两个图象的交点，一定成对关于 (2,0) 对称
    ```

* **坐标和公式**

    * 设公共对称中心为 $(A,B)$，两图象有 $N$ 个交点 $(x_1,y_1),\dots,(x_N,y_N)$。

    * 每一对交点横坐标之和为 $2A$、纵坐标之和为 $2B$；若存在与中心重合的交点，它自身的坐标就是 $(A,B)$。

    * > **结论**：$x_1 + \cdots + x_N = NA$，$y_1 + \cdots + y_N = NB$，$N$ 取奇数偶数都成立。

    * 例：公共对称中心 $(2,0)$、共 $N$ 个交点时，$x_1 + \cdots + x_N = 2N$。

## 解析式里藏着对称性

* **拆分子看奇偶**

    * 题面完全不出现关于 $f$ 的表达式，对称性藏在解析式的长相里时，用「拆分子」手法。

    * 例：$f(x) = \dfrac{2022x^3 + 2x^2 + 3x + 6}{x^2 + 3}$，分母 $x^2+3$ 不动，把分子的 $2x^2 + 6$（恰为分母两倍）摘出来当整体：

    * $$\frac{2022x^3 + 3x}{x^2 + 3} + 2$$

    * 其中 $\dfrac{2022x^3+3x}{x^2+3}$ 是奇函数（分母在 $x \to -x$ 下不变，分子整体取相反数），对称中心在原点；整体加 $2$ 是向上平移两个单位，故 $f(x)$ 的对称中心是 $(0,2)$。

    * 于是 $f(a) = 14$ 时，$f(a) + f(-a) = 2 \times 2 = 4$，得 $f(-a) = -10$。

* **硬算关系**

    * 直接写出 $f(a)$ 与 $f(-a)$，一正一负的 $2022a^3$ 与 $3a$ 靠相加约掉，通分得 $f(a) + f(-a) = \dfrac{4a^2+12}{a^2+3} = 4$，答案同样是 $-10$。

    * > **易错点**：当前解析式简单，硬算得动；等学到指数、对数与指对复合后解析式会复杂到硬算不动，拆分子、变形化简去看奇偶性反而是唯一捷径。这类题的核心是考察对称性，不是考察算术速度。

## 单调性的表达与脱衣服

* **三种等价写法**

    * $$x_1 > x_2 \Rightarrow f(x_1) > f(x_2)$$

    * $$(x_1-x_2)\,[f(x_1)-f(x_2)] > 0$$

    * $$\frac{f(x_1)-f(x_2)}{x_1-x_2} > 0$$

    * 式子 $(a-b)\,[f(a)-f(b)] > 0$ 表示对任意 $a,b$ 都成立：两因子同号，同正时 $a>b$ 且 $f(a)>f(b)$，同负时 $a<b$ 且 $f(a)<f(b)$，合起来即单调递增。

    * 后两种本质等价，都是「两式同号」，只是把乘法写成分式。

* **穿衣服与脱衣服**

    * 「穿衣服」：自变大小时两边同时套 $f$，增函数不变号，减函数变号。

    * 「脱衣服」：由 $f(\text{甲}) > f(\text{乙})$ 等价反向剥掉外层 $f$，增函数保持大于号，减函数要变成小于号。

    * > **结论**：解 $f(\text{甲}) > f(\text{乙})$ 就三个字——脱衣服，脱完问题即解决。

    * > **易错点**：只有单调函数才能脱衣服。既有增又有减的函数身上的衣服是分块穿的，脱不动；见到这种函数直接脱一定错。

## 抽象函数不等式的三类分诊

* **只有单调性**

    * 已知 $f$ 在 $\mathbf{R}$ 上单调递增，求 $f(2x) > f(6)$：脱衣服且不变号，得 $2x > 6$，解集 $(3,+\infty)$。

* **奇函数 $+$ 单调性**

    * 奇函数在 $(-\infty,0)$ 上单调递减，借关于原点对称把图像旋转 $180^\circ$，可知它在**整个 $\mathbf{R}$ 上都单调递减**。

    * 解 $f(2m^2+m) \ge f(2m-2) + f(0)$：先用 $f(0) = 0$ 化简，再移项得 $f(2m^2+m) \ge -f(2m-2)$。

    * 用奇性把外负号塞进括号：$-f(2m-2) = f(-(2m-2)) = f(2-2m)$，凑成 $f > f$ 后才能脱衣服。

    * > **提示**：负号塞进去是对**整个括号**取负号。$2m-2$ 是整体，取负得 $2-2m$，不是 $2m+2$。

    * 减函数脱衣服变号：$2m^2+m \le 2-2m$，即 $(2m-1)(m+2) \le 0$，解集 $m \in \left[-2,\ \tfrac12\right]$。

* **偶函数 $+$ 单调性**

    * 偶函数在 $[0,+\infty)$ 上单调递增，图像左右对称、先减后增，**在整个 $\mathbf{R}$ 上并不单调**，不能脱衣服。

    * 图像左右完全对称意味着函数值随「离原点的距离」增大而增大，故不等式等价于 $|2x-1| > |x-2|$。

    * 两边都有绝对值时两边平方（完全等价）：$4x^2 - 4x + 1 > x^2 - 4x + 4$，即 $3x^2 > 3$，解集 $(-\infty,-1)\cup(1,+\infty)$。

    * 绝对值是从看图得来的，不看图直接把 $f$ 脱掉，绝对值会凭空消失、答案随之出错。

* **分诊表**

    | 类型 | 已知条件 | 关键动作 | 易错处 |
    | :--- | :--- | :--- | :--- |
    | 只有单调性 | $f$ 在 $\mathbf{R}$ 上单调 | 两边脱衣服 | 减函数要变号；非单调函数不能脱 |
    | 奇函数 $+$ 单调性 | $f(-x)=-f(x)$，在某区间单调 | 先把外负号塞进括号凑成 $f>f$，再脱衣服 | 塞负号是对**整个括号**取负 |
    | 偶函数 $+$ 单调性 | $f(-x)=f(x)$，在 $[0,+\infty)$ 单调 | 不能脱衣服，改解 $\lvert\text{甲}\rvert > \lvert\text{乙}\rvert$ 再平方 | 只在一半定义域单调不等于整体单调 |

## 抽象函数综合题的完整流程

* **条件翻译成图**

    * 已知定义域为 $\mathbf{R}$ 的 $f$ 满足：两 $f$ 相等的式子（横坐标相加除以 $2$ 得 $1$，即对称轴 $x = 1$）；$f(-2) = -f(4)$；在 $[1,+\infty)$ 上单调递增。

    * 翻译条件二：$-2 + 4 = 2$ 正好是 $1$ 的两倍，$-2$ 与 $4$ 关于对称轴 $x=1$ 对称，故必有 $f(-2) = f(4)$；与题设 $f(-2) = -f(4)$ 联立得 $f(4) = -f(4)$，所以 $f(4) = 0$、$f(-2) = 0$，图像过 $(4,0)$。

    * > **结论**：该条件等价于一句话——$4$ 处函数值为 $0$，其对称点 $-2$ 处也必须为 $0$。

* **由对称性与单调性画出图像**

    ```text
       f(x)
         ↑      ╱╲
         │    ╱    ╲            ╱  ← x > 4 时 f(x) > 0
      ───┼──╱────────╲────────╱────→ x
       -2      1       4
          ╲  ╱          ╲
           ╲╱            ╲___      ← -2 < x < 1 时 f(x) < 0
            f < 0        f < 0
       规律：f(x) > 0 ⟺ x > 4 或 x < -2
             f(x) < 0 ⟺ -2 < x < 1
    ```

    * 在 $[1,+\infty)$ 上递增且过 $(4,0)$，右边画完往左翻一倍即得整条图像。

    * 注意负半轴上 $f$ 为负对应的自变量区间是 $(-2,1)$，不要误取 $0$ 左侧的一小段。

* **解不等式**

    * 解 $f(x-1)\cdot f(x) > 0$：两式同号，分同正同负两类讨论。

    * 若 $x > 0$，则 $f(x) > 0$，需 $f(x-1) > 0$，即 $x - 1 > 4$，得 $x > 5$。

    * 若 $x < 0$，则 $f(x) < 0$，需 $f(x-1) < 0$，即 $-2 < x-1 < 0$，得 $-1 < x < 1$；与前提 $x<0$ 取交集得 $(-1,0)$。

    * 类内取交集、类间取并集，最终解集 $(-1,0)\cup(5,+\infty)$。

    * > **提示**：抽象函数题的固定套路是先把抽象条件翻译成能画图的话，再画图，最后解不等式。

## 周期的定义与基本式

* **周期性**

    * > **定义**：$f(x+a) = f(x) \iff f$ 的周期 $T = a$。

    * 周期即「重复」：把长度为 $a$ 的图象段平移 $a$ 个单位，总与自身重合。

    * 周期取正值，$f(x) = f(x-4)$ 与 $f(x) = f(x+4)$ 一样，都用大自变量减小自变量，周期为 $4$。

* **与对称式的区分**

    * $f(x+2) = f(x+6)$ 有两个 $f$ 看似像对称，但括号里两个 $x$ 都是正的，表示的是周期性。

    * > **易错点**：判断周期还是对称只看括号里 $x$ 的正负，`f` 前面挂的负号只影响周期长短，不影响性质类别。

## 迭代法确定周期

* **三条必背结论**

    ```text
      ┌──────────────────────────────────────────────────────┐
      │  ① f(x+a) = f(x)          两自变量相减，周期就是谁   │
      │  ② f(x+a) = -f(x)         前面加负号，周期 ×2 → 2a   │
      │  ③ f(x+a) = k / f(x)      取倒数形式，周期 ×2 → 2a  │
      │        k ≠ 0，(1 / -1 / 2 / -2 ...) 都一样           │
      └──────────────────────────────────────────────────────┘
    ```

    * 迭代的依据是「要变一起变」：等号左右两侧的 $x$ 是同一个 $x$，可同时换成任何表达式。

* **加负号型的迭代**

    * 由 $f(x+a) = -f(x)$ 把两边 $x$ 同时换成 $x+a$，得 $f(x+2a) = -f(x+a)$。

    * 再由原式把 $f(x+a)$ 替换成 $-f(x)$，负负得正，得 $f(x+2a) = f(x)$，周期 $2a$。

* **取倒数型的迭代**

    ```text
      f(x+a) = k / f(x)          ①   （题给）

      两边所有 x 同时  →  x+a
      ------------------------------------------------------------
      f(x+2a) = k / f(x+a)       ②

      ② 的分母 f(x+a) 由 ① 替换：  = k / [ k / f(x) ]

           k     k
        = ────────  = f(x)          （k·k 提到分子上，约掉）

        ------------------------------------------------------------
        f(x+2a) = f(x)     ⟹   周期 T = 2a
    ```

    * > **易错点**：$f(x+a) = -\dfrac{1}{f(x)}$ 的周期是 $2a$，**不是 $4a$**——它只是把 $k$ 代成了 $1$。

* **更长式子的迭代**

    * 条件 $f(x+1) = f(x) - f(x-1)$：把 $x$ 全换成 $x+1$ 得 $f(x+2) = f(x+1) - f(x)$。

    * 把原式代入消掉 $f(x+1)$：$f(x+2) = [f(x) - f(x-1)] - f(x) = -f(x-1)$。

    * 两边 $x$ 再同时换成 $x+1$，左边成 $f(x+3)$、右边成 $-f(x)$。

    ```text
      ┌────────────────────────────────────────────┐
      │ 无负号:  (x+2) - (x-1) = 3   → 周期 3      │
      │ 有负号:  周期 ×2              → 周期 6  ✓  │
      └────────────────────────────────────────────┘
    ```

    * > **易错点**：周期 6 是两步来的——先由自变量差 $3$ 得基础值，再因前面带负号翻倍。

## 周期一给，大数化小

* **取余定位**

    * 已知 $f(x) = -f(x+3)$，括号内两个 $x$ 同为正，是周期性；自变量相减得 $3$，前面带负号周期翻倍，故 $T = 6$。

    * 配 $f(1) = 2$ 求 $f(2024)$：$337 \times 6 = 2022$，$2024 \div 6 = 337 \cdots 2$，故 $f(2024) = f(2)$。

    ```text
      已知:  f(x) = -f(x+3),  f(1) = 2
      问:    f(2024) = ?

      2024 ÷ 6 = 337 …… 2          ( 337 × 6 = 2022 )

          f(2024) = f(2024-6) = f(2018) = …… = f(2)
    ```

* **余点代值**

    * 题目给的是 $f(1)$ 而不是 $f(2)$，得回到抽象表达式做代值：由 $f(x+3) = -f(x)$ 令 $x = -1$，得 $f(2) = -f(-1)$。

    * 由 $f(1) = 2$ 可继续推出 $f(-2) = -f(1) = -2$，最终 $f(2024) = f(2) = 2$。

    * > **提示**：这类题最忌讳蒙题。周期一给第一反应是取余；余点题目没给函数值时，就回到抽象表达式代值，把已知点「搬」过去。这两步是全部套路。

## 双变量抽象函数等式

* **要变一起变**

    * 式子形如 $f(x+1) + f(x-1) = f(x)\cdot f(1)$，括号里同时出现 $x$ 与 $y$，等号左右的 $x$ 是同一个 $x$，$y$ 是同一个 $y$，要变一起变。

    * 抽象函数等式光放着没用，必须反复代值、反复变形。

* **令 $y = 1$ 拿周期**

    * 已知 $f(1) = 1$，令 $y = 1$ 后右侧 $f(x)\cdot f(1)$ 化为 $f(x)$，得 $f(x+1) + f(x-1) = f(x)$。

    * 移项即 $f(x+1) = f(x) - f(x-1)$，与迭代例题同一形态，周期 $T = 6$。

    ```text
        f(x+1) + f(x-1) = f(x)
              ──────────────────────►  f(x+1) = f(x) - f(x-1)
                                          正是同一道高考题
            ──────────────────────────────────────────
            T = 6
    ```

* **候选值必须回代筛除**

    * 令 $x = y = 0$ 得 $f(0) + f(0) = f(0)\cdot f(0)$，设 $M = f(0)$ 则 $M^2 = 2M$，因式分解得 $M = 0$ 或 $M = 2$，两个候选值。

    * 令 $y = 0$ 得 $f(x+1) + f(x-1) = f(x)\cdot f(0)$：若 $f(0) = 0$，则 $2f(x) = 0$，推出 $f(x) \equiv 0$，与 $f(1) = 1$ 矛盾，排除；若 $f(0) = 2$，与 $f(1) = 1$ 相容，保留。

    * > **提示**：代值代出的方程往往不止一个解，必须拿题目的另一个已知条件回头筛选，否则掉进「两个答案」的坑。

* **递推与周期求和**

    * 由 $f(x+1) = f(x) - f(x-1)$ 令 $x = n-1$ 得递推式 $f(n) = f(n-1) - f(n-2)$。

    * 令 $x = y = 1$ 得 $f(2) + f(0) = f(1)^2$，即 $f(2) = 1 - 2 = -1$。

    * 逐项递推：$f(1)\sim f(6) = 1,\; -1,\; -2,\; -1,\; 1,\; 2$，一个周期内六项之和为 $0$。

    ```text
      一个完整周期 = 6 个点

        周期①   1   2   3   4   5   6        和 = 0
        周期②   7   8   9  10  11  12        和 = 0
        周期③  13  14  15  16  17  18        和 = 0
        周期④  19  20  21  22                ← 多余的 4 个
                  └──── 对应回 1、2、3、4 ────┘
    ```

    * 1 到 22 共含三个完整周期加四个余项，完整周期和为 $0$，总和只剩 $f(19)\sim f(22)$，即 $f(1)\sim f(4) = 1 + (-1) + (-2) + (-1) = -3$。

    * > **结论**：这类抽象函数题的核心方法是同一个式子反复用——既用来榨出性质（周期性），也用来代值榨出特殊点的函数值。
