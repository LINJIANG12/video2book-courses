# 立体几何·垂直与角度

## 垂直证明的基本模型

* **线线垂直才是真正的主线**

    * 题目要求证线线垂直时，两条线基本必是**异面直线**（无交点、无角度可谈），唯一入口是去找一个面证明线线垂直。

    * > **定义**：若 $L \perp \alpha$ 且 $m \subset \alpha$，则 $L \perp m$——线面垂直可以一次性供给面上**任何**一条线的垂直关系。

* **证线面垂直：找面内两条相交直线**

    * 规则：在面内找到两条**相交**直线，待证线与这两条都线线垂直，则线面垂直。

    * > **易错点**：两条直线若不相交，判定不成立。一条线跟平面内两条不相交的直线都垂直，该线与这个面是**平行**关系，不是垂直。

* **循环疑云的解法：一条线穿过一个三角形**

    * 证线线垂直要证线面垂直，证线面垂直要证线线垂直，看似循环；合并两幅图后得到高频模型：一条线与三角形的**其中两条边**都垂直，即可推出它与第三条边垂直。

    * > **结论**：想证一条线垂直于三角形的某一条边，只需证出它垂直于另外两条边。

* **从面面垂直往下推**

    * 已有两个面面垂直时，取其中一面上与两面的**交线**垂直的直线，则该线垂直于另一个面。

    * > **结论**：这类题最后的落脚点都在**线线垂直**上——先由面面垂直推线面垂直，再由线面垂直上线线垂直。题目给出的面面垂直不是白给的。

* **从线面垂直推到面面垂直**

    * 两个面中，只要其中一个面**经过**了另一个面的垂线，则两面垂直。

* **选线的铁律**

    * 同一个面内有多条候选线时，一律选**垂直条件最丰富**的那条（与底面垂直的棱、底面正方形的对角线、平行于它们的线优先）。

## 图形识别：图形里藏着的直角

* **旗杆三棱锥：四个面全是直角三角形**

    * 典型配置：$PA = AB = BC = 1$，$AC = \sqrt2$，$PA \perp$ 平面 $ABC$。底面三边 $1:1:\sqrt2$ 是直角三角形，高从**非直角顶点** $A$ 引出，像旗杆一样插在底面上。

    * 线面垂直立刻供给 $\angle PAC$、$\angle PAB$ 均为直角，$\triangle PAC$ 两直角边 $1$、$\sqrt2$ 给出 $PC = \sqrt3$。

    * 证 $BC \perp$ 平面 $PAB$：$BC \perp AB$（底面直角）+ $BC \perp PA$（$PA$ 垂直整个底面）⇒ $BC \perp$ 平面 $PAB$，进而 $\angle PBC$ 也是直角。

    * > **结论**：这种形状共四个面，**每个面都是直角三角形**，四个直角对应四个面，应作为基本图形长期记忆。

* **正方形与半圆：面面垂直一路用到结论**

    * 边长为 $2$ 的正方形与以 $CD$ 为直径的半圆所在的面面垂直，$M$ 是圆上一点，求证 $\text{面}AMD \perp \text{面}BMC$。

    * 链条：正方形中 $AD \perp CD$ ⇒ $AD \perp$ 半圆所在面 ⇒ $AD \perp DM$、$AD \perp CM$；又 $CD$ 为直径，圆周角为直角 ⇒ $CM \perp DM$。

    * $CM$ 同时垂直相交的 $AD$ 与 $DM$ ⇒ $CM \perp$ 平面 $ADM$；平面 $ADM$ 经过 $CM$ ⇒ 两面垂直。

* **$90^\circ$ 藏在不同的地方**

    * 2012 年全国高考题：三棱柱侧棱垂直底面，底面是等腰直角三角形且侧棱等于底面直角边，$D$、$E$ 为中点。侧面是 $1:2$ 的长方形，等于两个正方形拼成，$CE$ 与 $CD$ 各成 $45^\circ$，合成 $90^\circ$，即 $CE \perp CD$。

    * 同题闭合：$BC$ 垂直底面且垂直侧棱 ⇒ $BC \perp$ 所在绿面 ⇒ $BC \perp DC$、$BC \perp CE$；$CE$ 同时垂直 $CD$、$BC$ ⇒ $CE \perp$ 该面 ⇒ 经过 $CE$ 的蓝面与该面垂直。

    * 四棱柱削去一角（正方形底面 $ABCD$，$E$ 为 $AD$ 中点且 $AE \perp$ 底面，$M$ 为 $DC$ 中点）：$EM$ 是 $\triangle ACD$ 的中位线 ⇒ $EM \parallel AC$；正方形对角线 $AC \perp BD$ ⇒ $EM \perp BD$；$AE \perp$ 底面 ⇒ $AE \perp BD$，$BD$ 平行于上底面的 $B_1D_1$，传递后 $B_1D_1$ 同时垂直于两面内的两条相交线 ⇒ 线面垂直 ⇒ 两面垂直。

    * > **结论**：两个待证面共约六条线时，通用的挑法是选**最特殊、垂直条件最丰富**的那条；斜线一律先排除。

* **垂直小妙招清单**

    * **等腰三角形** → 三线合一：取底边中点连接，该线同时是中线、高、顶角平分线。

    * **菱形** → 连接对角线，菱形对角线相互垂直。

    * **$60^\circ$ 菱形** → 不当菱形看，一分为二拆成两个全等的等边三角形，再走等腰的三线合一。

    * **等腰梯形 $1:1:1:2$** → 连对角线即得垂直。可用初中法：先证为菱形（对边平行且相等且邻边相等），取底边中点得直角三角形，直角三角形斜边中线等于斜边一半，故对角线与该边垂直；或用外角 $60^\circ$ 推出 $30^\circ$、$60^\circ$、$90^\circ$。

    * **直角梯形 $1:1:2$** → 连对角线，取底边中点构造正方形，斜边中线等于斜边一半得直角。

    * **直角梯形 $1:\sqrt3:2$** → 先连一条对角线，再取一条腰的中点连接即得垂直；可由 $1^2+(\sqrt3)^2=2^2$ 构造 $30^\circ$，放大成边长 $2a$ 的等边三角形取中点，由左右对称知该线是垂直平分线。

    * **两面相交** → 找交线的垂线，垂于交线即得线面垂直，进而与另一面上任意线垂直。

    * **边长比例就是角度** → 长方形底面上动点满足 $\frac{AF}{FD}=\frac{BE}{BA}$ 时，两个比值分别是两个角的正切值，正切值相等则角相等，再由"一点一差 $90^\circ$"得两线垂直。

* **底面先行：藏在底面里没明说的直角**

    * 2021 年浙江四棱锥 $P\text{-}ABCD$：底面平行四边形 $\angle ABC = 120^\circ$，$AB = 1$，$BC = 4$，$PA = \sqrt{15}$，$M$、$N$ 分别为 $BC$、$PC$ 中点，$PD \perp DC$，$PM \perp MD$。

    * 底面 $\angle DCB = 180^\circ - 120^\circ = 60^\circ$，$DC = AB = 1$，$CM = 2$，故 $\angle DCM = 60^\circ$。

    * $$DM^2 = 1^2 + 2^2 - 2\cdot1\cdot2\cdot\cos 60^\circ = 3 \;\Rightarrow\; DM = \sqrt3$$

    * 再由 $DC^2 + DM^2 = 1 + 3 = 4 = CM^2$ 得 $\angle CDM = 90^\circ$，即隐藏条件 $DC \perp DM$。

    ```text
            D
            |\
         √3 | \ 1
            |  \
            M---C
              2

       DC ⊥ DM（隐藏直角）
       DC = 1 , CM = 2 , ∠DCM = 60°
       → DM = √3 , ∠CDM = 90°
    ```

    * > **结论**：立体几何题必须把底面当初中题先算透；题目隐藏的直角往往是后续所有推理的启动键。

* **正三角形与全等的双重触发（2017 年全国高考）**

    * 四面体 $ABCD$，$ABC$ 为正三角形，$ACD$ 为直角三角形，$\angle ABD = \angle CBD$：两角相等且共用 $BD$，由 SAS 得 $\triangle ABD \cong \triangle CBD$，故 $AD = CD$，两面均为等腰三角形。

    * 取 $AC$ 中点 $G$，则 $DG \perp AC$（三线合一），底面等边三角形中 $BG \perp AC$，两条相交线 ⇒ $DG \perp$ 底面。

* **等腰梯形对角线 + 面面垂直（2025 年江西模拟）**

    * $AD$、$BE$、$CF$ 三线平行，两个全等的 $1:1:2$ 等腰梯形 $ADFC$ 与 $BEFC$ 面面垂直，$G$、$H$、$L$ 为中点，求证 $\text{面}GHL \perp \text{面}DEF$。

    * 交线为 $CF$；等腰梯形上下底的中点连线由对称性直接得 $GH \perp$ 交线 ⇒ $GH \perp$ 底面 ⇒ $GH$ 垂直底面上任意线（含 $EF$）。

    * $L$、$H$ 为中点，连接 $BE$ 得中位线，与 $GH$ 平行从而也垂直 ⇒ $EF$ 同时垂直两条相交线 ⇒ $EF \perp$ 该面 ⇒ $\text{面}GHL \perp \text{面}DEF$。

    * > **结论**：只得到"一条线垂直于一个面"不够用，必须再在这个面上落实一条具体的线线垂直。

## 三垂线定理

* **定义与机理**

    * > **定义（三垂线定理）**：平面内有一条斜线，过斜线的端点作平面的一条垂线，垂足与斜线端点的连线就是斜线在该平面内的**投影**；若平面内某条直线与这条**投影**垂直，则该直线一定与斜线本身垂直。

    * 机理自洽：过斜线上一点作平面垂线得到的投影线本身就是**线面垂直**（线面垂直由线线垂直证出）⇒ 投影线与平面内任何线垂直 ⇒ 与投影垂直的线和投影所在平面垂直 ⇒ 与面内另一条线垂直 ⇒ 与斜线垂直。

* **几何图像**

    * 想象太阳垂直照向平面，$OP$ 的影子 $OP'$ 即 $OP$ 的投影；面上小粉线既垂直投影线（定理假设），又因面面垂直而垂直另一条蓝线，两条蓝线相交 ⇒ 小粉线垂直该面 ⇒ 再垂直面内任意线。

    * > **结论**：斜线有投影，面上有直线垂直该投影，则该直线必与原斜线垂直。

* **能想不能写**

    * 该定理极好用，但新高考卷**不能直接作为结论引用**：可用于简化思考过程，答题时仍须逐步证明"斜线垂直投影线"这一步。

    * 正四棱柱例：$AA_1 = 4$，$AB = 2$，$E$ 在 $CC_1$ 上满足 $CE_1 = 3CE$（四等分点），证线面垂直。

    * 第一条垂直不用三垂线定理也成立：正方形底面 $BD \perp AC$，且侧棱 $AA_1 \perp$ 底面 ⇒ $BD \perp AA_1$，两条相交线 ⇒ $BD \perp$ 平面 $A_1C$ 所在的面 ⇒ $BD \perp A_1C$。

    * 第二条 $A_1C \perp BE$ 用三垂线定理：把 $A_1C$ 塞进 $1:2$ 的侧面，$A_1$ 的影子落在 $B_1$ 上，投影为 $B_1C$，只需证 $BE \perp B_1C$。

    * 初中十字模型验证：侧面中 $BC = 2$，$BB_1 = 4$，$CE = 1$，$\angle EBC$ 的正切值为 $\frac12$，$B_1C$ 与水平方向夹角的正切值为 $2:4 = \frac12$，两角相等，一点一差 $90^\circ$。

    * 考试书写必须补齐：由 $B_1C \perp BE$ 推到 $A_1C \perp BE$ 需严格写出——过 $A_1$ 作 $A_1B_1 \perp$ 侧面 ⇒ $A_1B_1$ 垂直面上一切线含 $BE$ ⇒ 与平面证 $B_1C \perp BE$ ⇒ $B_1C \perp$ 该面 ⇒ 线线垂直。

* **交线垂线找不到时的三垂线法（求二面角）**

    * 在任一面取一点 $P$，作 $PP' \perp$ 平面 $\beta$ 得投影点 $P'$；过 $P'$ 作交线 $l$ 的垂线 $P'G$，$G$ 为垂足；连接 $PG$，则 $\angle PGP'$ 即为二面角。

    * 适用条件：两面内**直接找与交线垂直的线**实在找不到时使用。

    * 2023 年天津三棱台例：$AA_1 \perp$ 平面 $ABC$，$AB \perp AC$，$AB = AC = AA_1 = 2$，$A_1C_1 = 1$，$M$、$N$ 为中点，求面 $C_1MA_1$ 与面 $ACC_1A_1$ 所成角的余弦值。

    * 交线为 $A_1C_1$，定义法失效（绿面蓝面上都找不到瞬间可证的垂线）⇒ 改用三垂线法。

    * 棱台的侧面 $A_1ACC_1$ 经过侧棱 $AA_1$ ⇒ 该侧面与底面垂直 ⇒ 过 $M$ 作底面垂线只需作交线 $AC$ 的垂线，过 $M$ 作 $MG \perp AC$，$G$ 为 $AC$ 中点。

    * 侧面展开为 $1:2:\sqrt5$ 的三角形与边长为 $2$ 的矩形；取中点后左右各为 $1:2:\sqrt5$ 的直角三角形，$MG = 1$（$AB$ 的一半）。

    * 用等面积法求 $GS$：$\frac{\sqrt5}{2} = \frac12\cdot AC_1 \cdot GS \Rightarrow GS = \frac{\sqrt5}{\sqrt6}$；再求斜边，最终余弦值为 $\frac23$。

* **书写规范：三垂线法一个限定条件都不能少**

    * 用**定义法**找角时，可直接说"两线均垂直交线，故该角为二面角"。

    * 用**三垂线法**时不能直接宣称，必须逐步证明：$PP' \perp \beta$ ⇒ $l \perp PP'$（$l$ 在 $\beta$ 内）⇒ $l \perp$ 平面 $PP'G$（须写出 $PP'$ 与 $P'G$ 相交于 $P'$、且两线都在该面内）⇒ 因 $PG$ 在该面内，故 $l \perp PG$（须写出该限定条件）⇒ 才能判定 $\angle PGP'$ 为二面角。

    * > **易错点**：三垂线法少写一个限定条件即为扣分点，证明链一节都不能省。

## 垂直有时候是算出来的

* **勾股定理与数量积两条算路**

    * 当题目不再给垂直条件时，说明垂直需要主动去算：首选勾股定理；也可令两线段数量积为零。

* **圆锥中的对称（2020 年新课标一卷）**

    * 圆锥底面圆内接正三角形，$AE$ 为直径，$AE = AD$，$P$ 在 $DO$ 上且 $PO = \frac{\sqrt6}{6}DO$，证 $PA \perp$ 平面 $PBC$。

    * 识别对称：$AC = AB$，$OC = OB$ ⇒ 直径 $AE$ 是 $BC$ 的垂直平分线；$PB = PC$（同为圆锥母线），整个图形关于该直径前后对称，故只需证明 $PA$ 与 $PB$、$PC$ 中一条垂直。

    * 第一组垂直不需算：$BC$ 在底面，$BC \perp AE$，且 $DO$ 为圆锥的高 ⇒ $DO \perp$ 底面 ⇒ $DO \perp BC$，两条相交线 ⇒ $BC \perp$ 平面 $AEO$ 所在的面。

    * 第二组需算：设半径为 $1$，则等边三角形边长与 $AB$ 均为 $\sqrt3$，高 $DO = \sqrt3$，$PO = \frac{\sqrt6}{6}\cdot\sqrt3 = \frac{\sqrt2}{2}$。

    * $$PA = \sqrt{1^2 + \left(\frac{\sqrt2}{2}\right)^2} = \sqrt{\frac32},\qquad PB = \sqrt{\frac32}\ (\triangle POA \cong \triangle POB)$$

    * $\frac32 + \frac32 = 3 = AB^2$，由勾股定理得 $PA \perp PB$。

* **菱形折叠（2016 年课标二卷）**

    * 菱形边长 $5$，$AC = 6$（半长 $3$，故菱形由 $3:4:5$ 定形），$E$、$F$ 在两边上且 $AE = CF = \frac54$（四等分点），$EF$ 交 $BD$ 于 $H$，沿 $EF$ 折叠后给 $OD' = \sqrt{10}$，证 $DH \perp$ 底面。

    * 折叠前后 $\triangle DEF$ 均为等腰三角形，$H$ 为中点 ⇒ $DH \perp EF$，得第一组垂直。

    * 第二组算：$DH = 4$（由 $3:4:5$ 与四等分点按相似得），$OH = 1$，$3^2 + 1^2 = 10 = OD'^2 \Rightarrow D'H \perp OH$。

    * $D'H$ 同时垂直 $DH$ 与 $OH$ ⇒ $D'H \perp$ 大底面。

* **球中的五点：$PB$ 与平面 $PAM$**

    * $P$、$A$、$M$、$N$、$B$ 在半径为 $2$ 的球上，$AB$ 为直径，$MN$ 为弧 $A\cdots B$ 的三等分点，$P$ 在底面的投影 $Q$ 是 $ON$ 的中点。

    * 底面形状：$AB$ 为直径，$MN$ 三等分 ⇒ 三个圆周角各为 $60^\circ$ ⇒ 构成 $2:2$ 的等腰梯形（$1:1:1:2$ 型），连对角线即得 $MA \perp MB$；弧上任意等分点推出的对角线垂直结论可直接使用。

    * **正法（不计算）**：由对称性 $AM \parallel ON$；$ON$ 在底面且 $PQ \perp$ 底面 ⇒ $ON \perp PQ$，又 $ON \perp MB$（对称性）⇒ $ON \perp$ 相应平面 ⇒ $ON \perp PB$，再由平行传递得 $AM \perp PB$。加上 $AB$ 为直径 ⇒ $\angle AMB = 90^\circ \Rightarrow MB \perp PB$，两条相交线 ⇒ $PB \perp$ 平面 $PAM$。

    * **算法**：$OP = 2$，$OQ = 1$，$PQ = \sqrt{2^2 - 1^2} = \sqrt3$；$MB$ 为 $120^\circ$ 圆周角所对弦（比例 $1:1:\sqrt3$，边长 $2\sqrt3$）；由 $\sqrt3$、$\sqrt3$、$2\sqrt3$ 恰为直角三角形三边得 $PM \perp PB$。

    * > **结论**：同一道题给两条路时，计算法往往更短；但底面分析不能省——它同时提供平行与垂直两组信息。

* **一条动线，两条路（2021 年全国甲卷）**

    * 直三棱柱，侧面是正方形，$E$、$F$ 为中点，给定 $BF \perp A_1B_1$，证 $BF \perp DE$（$D$ 为动点）。

    * 底层转换：动点 $D$ 从 $A$ 运动到 $E$ 时，$ED$ 扫出平面 $B_1A_1E$；要证一条动线始终与 $DE$ 垂直，等价于证 $BF \perp$ 该面，与 $D$ 的位置彻底无关。

    * **第一条路（硬算）**：$AB = BC$ 给出等腰三角形三线合一 $BE \perp AC$；侧棱垂直底面 ⇒ $BE \perp AA_1$；两条相交线 ⇒ $BE \perp$ 平面 $A_1E$ 所在面 ⇒ $A_1E \perp BE$。

    * 关键卡点是 $AC$ 未给，必须算出来：由 $BF \perp A_1B$ 下移得 $BF \perp AB$；$AF = 1$，$BF = \sqrt{1^2 + 2^2} = \sqrt5$；再由 $BF \perp AB$、$AB = 2$ 得第三条边 $\sqrt{5 + 4} = 3$；于是 $AC = \sqrt{9 - 1} = 2\sqrt2$，其半长为 $\sqrt2$。

    * 比较得 $\frac{1}{\sqrt2} = \frac{\sqrt2}{2}$，两角相等，一点一差 $90^\circ$，得 $A_1E \perp EF$。

    * $A_1E$ 同时垂直 $BE$ 与 $EF$ ⇒ $A_1E \perp$ 目标面 ⇒ $BF \perp A_1E$；再由 $BF \perp A_1B_1$ 两条相交线 ⇒ $BF \perp$ 扫出的面 ⇒ $BF \perp DE$。

    * **第二条路（斩开面）**：目标面并未展开，可过面上某顶点作另一边的平行线——过 $E$ 作 $EG \parallel A_1B_1$（$G$ 为 $BB_1$ 中点），三角形面延展成梯形。

    * 改证 $BF \perp BG$ 与 $BF \perp EG$；此处侧面是边长为 $2$ 的正方形，$E$、$G$ 为中点，长度比 $1:2$，两角正切值互为倒数，一点一差 $90^\circ$，即十字模型。

    * > **结论**：第一开始不直接给棱长时，须会用勾股定理把所有未知边长先算出来；这类"算出来的垂直"在全国乙卷一类题目中是第一步。

## 空间中的三种角

* **线线角**

    * > **定义**：线线角（异面直线所成的角）＝ 两条线平移到相交位置后所取的**锐角**。

    * 取值范围 $0 \le \theta \le \frac{\pi}{2}$；$\theta = 0$ 对应两线平行或重合，$\theta = \frac{\pi}{2}$ 对应两线垂直。

    * 平移到有交点后左右有两个角（一个锐角一个钝角），规定取锐角，否则同两条线会出现两个线线角。

* **线面角**

    * > **定义**：线面角 ＝ 斜线与它在平面内的**投影**所成的锐角。

    * 取值范围 $0 \le \theta \le \frac{\pi}{2}$；取 $0^\circ$ 对应直线与平面平行或重合，取 $90^\circ$ 对应直线垂直平面。

    ```text
                P
                ●
                |\
                | \
                |  \  ← 斜线 OP
                |   \
                | θ  \
                O─────● P'
                      ⟂

        P' 是 P 在平面内的投影，PP' ⊥ 平面
        斜线 OP 与它的投影 OP' 所成的角 θ，就是线面角
    ```

    * 数学关系：$\sin\theta = \dfrac{\text{点到面的距离}}{\text{斜线长}}$，斜边即已知的线段长。

* **二面角**

    * > **定义**：在两个面上分别找交线的垂线，这两条线所成的线线角即二面角。

    * 取值范围 $0 \le \theta \le \pi$，**可钝可直**。

    ```text
                  绿面（含交线 PQ）
                    ╲
                     ╲   ①  钝角区
                      ╲
            A ●────────P════════Q────────● B
          交线 PQ（两面公共的棱）
                      ╱
                     ╱   ②  锐角区
                    ╱
                  蓝面（含交线 PQ）

        夹角①（钝角）、夹角②（锐角）都是合法的说法
    ```

    * 记号含义：**二面角 $A\text{-}PQ\text{-}B$** 指的是由 $A$、$PQ$、$B$ 标定的那个角，可为钝角；求锐角时写成如 $C\text{-}PQ\text{-}B$。

    * 只说"$\alpha$ 与 $\beta$ 两面的夹角"而不标点时，一律取**不大于 $90^\circ$ 的较小锐角**。

## 线线角的求法

* **总路径**

    * 基础法只有一条：**平移 + 解三角形**。平移后是特殊三角形则一眼看出，否则用解三角形求对应角。

* **平移一条线就够了（正六棱柱）**

    * 正六棱柱所有棱长为 $1$，求侧面两条对角线 $AB_1$ 与 $FE_1$ 所成角的余弦值。

    * $AB_1$ 所在侧面与 $EFF_1E_1$ 所在面平行且全等，把 $AB_1$ 平移到后面即得线线角。

    * 三边：两个侧面对角线均为 $\sqrt2$；底面正六边形内角 $120^\circ$，连接 $D$、$F$ 得 $1:1:\sqrt3$ 的等腰三角形，$DF = \sqrt3$。

    * $$\cos\alpha = \frac{(\sqrt2)^2 + (\sqrt2)^2 - (\sqrt3)^2}{2\cdot\sqrt2\cdot\sqrt2} = \frac{1}{4}$$

* **平移出去也没关系（2017 年新课标二卷）**

    * 直三棱柱中 $AB = 2$，$BC = 1$，$\angle ABC = 120^\circ$，$CC_1 = 1$，求 $AB_1$ 与 $BC_1$ 所成角的余弦值；侧面 $BCC_1B_1$ 是 $1\times1$ 正方形。

    * 把 $AB_1$ 平移到过 $B$ 的位置，线支出棱外；把角放进 $\triangle BC_1F$ 中（$F$ 由 $B_1$ 沿 $A_1B_1$ 方向平移 $AB$ 的距离得到，即 $A_1B_1$ 延长一倍的中点处）。

    * 三边：侧面内的斜线 $\sqrt2$；平移前后等长故 $\sqrt5$；$BF = 2$，$BC_1 = 1$，夹角 $60^\circ$，为 $30$、$60$、$90$ 三角形，故 $C_1F = \sqrt3$。

    * $$\cos\alpha = \frac{(\sqrt2)^2 + (\sqrt5)^2 - (\sqrt3)^2}{2\cdot\sqrt2\cdot\sqrt5} = \frac{\sqrt{10}}{5}$$

    * 平移出的点不好定位时，只需想清该点由哪个点沿哪个方向平移了多长，再反复用解三角形求边。

* **两条都得平移：中位线法**

    * 取 $AB$ 与 $BB_1$ 的中点连线（中位线）表示 $AB_1$，取 $BB_1$ 与 $B_1C_1$ 的中点连线表示 $BC_1$，两中位线共点于 $BB_1$ 的中点，线线角即它们所夹的角。

    * 三边：$\frac{\sqrt5}{2}$、$\frac{\sqrt2}{2}$；第三边由两条互相垂直的线段拼成——一条平行于 $AA_1$ 长 $1$，一条平行于 $A_1C_1$ 长 $\frac{\sqrt7}{2}$。

    * 其中 $AC^2 = 2^2 + 1^2 - 2\cdot2\cdot1\cos120^\circ = 7 \Rightarrow AC = \sqrt7$，$A_1C_1 = \sqrt7$。

    * $$QP = \sqrt{1^2 + \left(\frac{\sqrt7}{2}\right)^2} = \frac{\sqrt{11}}{2}$$

    * > **易错点**：中位线法算出的余弦值为 $-\frac{\sqrt{10}}{5}$，这是钝角的值，与所求锐角互补。算成负值不要改符号，取绝对值即可。

## 线面角的求法

* **定义法：定义说啥做啥**

    * 过线上一点主动作面的垂线，找到垂足（投影点），连接交点与投影点，构成的直角三角形中斜边与投影所夹的锐角即线面角。

    * 长方体长宽高为 $2$、$2$、$1$，求 $AC_1$ 与上底面 $A_1B_1C_1D_1$ 所成角：交点为 $C_1$，垂足为 $A$（棱 $A_1A$ 即上底面垂线）。

    * 对角线 $A_1C = 2\sqrt2$，垂线段长 $1$，斜边 $\sqrt{1^2 + (2\sqrt2)^2} = 3$，故 $\sin\theta = \frac13$。

* **小妙招：先找面面垂直，再作交线的垂线**

    * > **提示**：要找某个面的垂线，先在图形中找**面面垂直**，然后只作两面的交线垂线即可。

    * 正三棱柱中侧棱长与底面边长相等，求 $AB_1$ 与侧面 $ACC_1A_1$ 所成角：交点为 $A$，需过 $B_1$ 作该侧面的垂线。

    * 上下底面都经过侧棱而与侧面垂直；因 $B_1$ 在上底面内，只需在上底面作交线的垂线——取底面等边三角形中点 $G$，三线合一得 $BG \perp$ 交线。

    * 边长全为 $1$ 时，斜边 $\sqrt2$，直角边为正三角形的高 $\frac{\sqrt3}{2}$。

    * $$\sin\theta = \frac{\sqrt3/2}{\sqrt2} = \frac{\sqrt6}{4}$$

    * 四面体例（2018 年）：$\triangle ABC$ 等边，面 $ABC \perp$ 面 $ABD$，交线为 $AB$；$CD$ 与平面 $ABD$ 的交点为 $D$，支出点 $C$ 恰在另一个垂直面内，故过 $C$ 作 $AB$ 的垂线 $CM$（三线合一）即得 $CM \perp$ 平面 $ABD$，所求角为 $\angle CDM$。

    * $CM = \frac{\sqrt3}{2}\cdot 2 = \sqrt3$，$DM = \sqrt{AD^2 + AM^2} = \sqrt{12+1} = \sqrt{13}$，$CD = 4$，故 $\sin\angle CDM = \frac{\sqrt3}{4}$。

* **垂线做不出来时：等体积法求点到面距离**

    * 垂线与垂足实在找不出时，只需求出点到面的距离这个**数值**，再代回 $\sin\theta = \dfrac{d}{\text{斜线长}}$。

    * 方法：把该距离看作以该点为顶点的三棱锥的高，由 $V = \frac13 S_{\text{底}} \cdot h$ 解出；求体积时**换一个顶点**作上顶点以避开未知的那个高，割补法同样可用。

    * 2018 年江苏正三棱柱：所有棱长为 $2$，$P$、$Q$ 为中点，求 $A_1C_1$ 与平面 $AQC_1$ 所成角。

    * 以 $C$ 为上顶点、$\triangle AQC$ 为底、$CC_1 = 2$ 为高算体积；$\triangle A_1QC_1$ 三边为 $\sqrt3$、$\sqrt5$、$\sqrt8$，恰好 $\sqrt3^2 + \sqrt5^2 = \sqrt8^2$，是直角三角形，面积 $\frac{\sqrt5}{2}$。

    * 由 $V = \frac13 \cdot \frac{\sqrt5}{2} \cdot H = \frac43 \Rightarrow \sqrt5 \cdot H = 2 \Rightarrow H = \frac{2\sqrt5}{5}$。

    * $$\sin\theta = \frac{H}{2} = \frac{2\sqrt5/5}{2} = \frac{\sqrt5}{5}$$

    * > **结论**：线做不出、垂足找不到时，改算点到面距离即可，但必须掌握求点到面距离。

* **同一道题两种解法答案一致**

    * 上题若走定义法：$AQ$ 是底面等边三角形的高（三线合一），又垂直侧棱 ⇒ $AQ \perp QC_1$ 且 $AQ \perp CC_1$，两条相交线 ⇒ $AQ \perp$ 侧面，于是平面 $AQC_1$ 与该侧面垂直；面面垂直下，过 $C$ 作小黄面的垂线只需作交线 $C_1Q$ 的垂线。

    * 侧面是边长为 $2$ 的正方形，$Q$ 为 $BC$ 中点，所求角落在 $1$、$2$、$\sqrt5$ 的直角三角形中，$\sin\theta = \frac{1}{\sqrt5} = \frac{\sqrt5}{5}$，与等体积法完全一致。

    * 结论：能找垂线者零计算量，依赖空间想象力与小妙招的熟练度；找不到者用等体积法或割补法，量大但不需要想象。

## 二面角的求法

* **定义法：两面各作一条交线垂线**

    * 2011 年全国卷四面体 $ABCD$：$AB = \sqrt2$，其余棱长为 $1$，则 $\triangle ACD$ 与 $\triangle BCD$ 均为边长 $1$ 的等边三角形，求二面角 $A\text{-}CD\text{-}B$。

    * 在两个等边三角形内各作一条底边 $CD$ 的高，垂足同为 $CD$ 的中点 $G$，故二面角为 $\angle AGB$。

    * $AG = BG = \frac{\sqrt3}{2}$，$AB = \sqrt2$。

    * $$\cos = \frac{\frac34 + \frac34 - 2}{2\cdot\frac34} = -\frac{1}{3}$$

    * 适用条件：两面内都能较快作出与交线垂直的线。

* **三垂线法**

    * 步骤：一个面上取不在交线上的点 → 作另一个面的垂线得投影点 → 过投影点作交线的垂线 → 连接投影点与原点和垂足。

    * 三步内含两个降维：作线面垂线用"找面面垂直 + 交线垂线"；最后一步退化为平面内作垂线。

* **共同的底牌**

    * 无论求哪种角，策略都只有一条：**先大胆地把那个角度找出来，再大胆地算**。

    * 分析过程中要不断把立体图形拆成一个一个平面图形；一旦把角表示成某个三角形的角，立体问题就退化为平面问题。

    * 比大小与最值题同样如此：哪怕两个点都在动，也必须先把三个角都表示成某三角形内的角。

## 角度比大小与动点问题

* **三个角同时表示（正三棱柱各棱长相等）**

    * 设每条棱长为 $1$，$E$、$F$ 为棱上的动点，记 $EF$ 与 $AA_1$ 的线线角为 $\alpha$，$EF$ 与平面 $ABC$ 的线面角为 $\beta$，面 $FBC$ 与底面所成二面角为 $\gamma$。

    * 题目未说明 $E$、$F$ 固定，即两个点都是动点。

    * $\alpha$：过 $F$ 作 $FG \perp AC$ 于 $G$，因 $FG \perp AC$ 且 $AA_1 \perp AC$，两条直线同垂直于 $AC$ 故平行，即 $FG \parallel AA_1$，于是 $\alpha = \angle EFG$。

    * $\beta$：$FG \perp$ 平面 $ABC$，$G$ 是 $F$ 在底面的投影，$\beta = \angle EGF$。

    * $\gamma$：面 $FBC$ 在动，定义法失效；改用三垂线法，继续作 $GS \perp BC$ 于 $S$，则 $\gamma = \angle FGS$。

    ```text
            平面 FBC（动）        平面 ABC（不动）
                  ╱                  ─────
                 ╱                      │
            S ──╱────                 G  │
             ╲ ╱                     ╱    │
              F                    ╱      │
                                FG ⊥ 底面
    ```

    * $\alpha$ 与 $\beta$ 同在直角三角形 $EFG$ 中，由大边对大角比较：$FG = 1$ 固定，$GE < 1$（$G$ 固定、$E$ 在棱上动，斜线段 $GE$ 短于其投影、投影又短于整条棱，故红 < 绿 < 蓝），得 $\alpha \le \beta$。

    * $\beta$ 与 $\gamma$ 分处两个直角三角形但共用直角边 $FG$；$\triangle GES$ 中斜边 $GE$ 必大于直角边 $GS$，同高下边越长角越小，故 $\beta \le \gamma$。

    * 最终 $\alpha \le \beta \le \gamma$。

    * > **易错点**：$G$ 是 $F$ 在底面的投影，$F$ 在侧棱上移动，故 $G$ 固定、只有 $E$ 在动。把 $GE<1$ 硬算反而容易绕进去，压到底面平面上看一眼即可。

* **动点轨迹要先挖出来（2023 徐州高二期中）**

    * 直四棱柱底面为边长 $2$ 的正方形，高 $\sqrt3$，$M$ 是侧面 $BCC_1B_1$ 内的动点（不含边界）且 $AM \perp MC$，求 $A_1M$ 与该侧面所成角的正切值取值范围。

    * 单一的线线垂直没有用处，必须凑成一对：长方体中 $BC \perp$ 侧面 ⇒ $BC \perp MC$，与题给的 $AM \perp MC$ 配成一对，推出 $MC \perp MB$。

    * > **结论**：所有条件都要压到已知的那一个面（侧面）上才好用。

    * $MB \perp MC$ 即直径所对圆周角为直角 ⇒ 轨迹是**以 $BC$ 为直径的圆**，半径 $r = 1$，圆心 $O$ 即底面正方形中心，$B_1O = 2$。

    ```text
            C₁────────────────B₁
             │                │
             │  M₂            │
             │    ╲           │
             │      ╲         │
             │        ╲       │   圆弧 M：以 BC 为直径
             │          ╲     │   半径 r = BC/2 = 1
             │   ···········  │
             │   ·   O    ╲   │   O：圆心 = 底面正方形中心
             │   ·········╲   │   B₁O = 2（正方形对角线的一半）
             │              ╲ │
            C────────────────B
                  BC = 2
    ```

    * 线面角落在直角三角形中：交点为 $M$，过 $A_1$ 作垂线直接用侧棱 $A_1B_1$（侧棱垂直该侧面）。

    * $$\tan\alpha = \frac{A_1B_1}{B_1M} = \frac{2}{B_1M}$$

    * $B_1M$ 最大值在 $M$ 与 $C$ 重合时取得：$B_1M_{\max} = \sqrt{(\sqrt3)^2 + 2^2} = \sqrt7$。

    * 最小值在 $B_1$、$M$、$O$ 三点共线时取得：$B_1M_{\min} = B_1O - r = 2 - 1 = 1$。

    * 因 $B_1M \in [1, \sqrt7)$ 且位于分母，故

    $$\tan\alpha \in \left(\frac{2}{\sqrt7},\ 2\right]$$

    * > **易错点**：题目写明 $M$ 是侧面**内的动点，不含边界点**，故 $M = C$ 不可达，$\frac{2}{\sqrt7}$ 取不到；$B_1M = 1$ 对应的点在内部、可达，所以是左开右闭。

* **二面角的单调性：把立体压成平面**

    * 侧棱垂直底面的三棱柱，$\angle BAC = 90^\circ$，$AB = AC = 1$，$AA_1 = \sqrt2$（侧面为边长 $\sqrt2$ 的正方形）；$D$、$E$ 为定点（$E$ 为中点），$F$ 在 $CC_1$ 上运动；面 $DEF$ 与面 $EFB$ 所成二面角记为 $\alpha$。

    * 交线 $EF$ 在动，定义法失效；三垂线法中**必须选不动的那一面作底**——面 $EFB$ 即侧面 $BB_1C_1C$ 恒定，故过 $D$ 作侧面的垂线。

    * 隐藏的面面垂直：侧棱垂直底面，侧面又经过该侧棱 ⇒ 侧面 $\perp$ 底面 ⇒ 过 $D$ 作底面与侧面交线 $BC$ 的垂线 $DG$ 即为侧面垂线；$G$ 是 $BC$ 的四等分点（中位线的一半）。

    * 再过 $G$ 作交线 $EF$ 的垂线 $GH$，垂足 $H$；所求二面角为 $\alpha = \angle GHD$，$\tan\alpha = \dfrac{DG}{GH}$，其中 $DG$ 固定，只有 $GH$ 在变。

    * $H$ 是 $GE$ 的垂足，$GH \perp HE$ ⇒ $H$ 在**以 $GE$ 为直径的圆**上；$G$、$E$ 均固定，故 $H$ 的轨迹由 $G$、$E$ 直接确定，不必先定 $F$。

    ```text
            B₁─────────────C₁
            │  E           │      E 是 BB₁ 的中点，不动
            │   ·╲         │
            │     ╲        │      F 在 CC₁ 上，从 C₁ 运动到 C
            │       ╲  F   │
            │        ╲╲    │
            │         H╲   │      H 是 G 到交线 EF 的垂足
            │  G ···  ╲╲   │
            └─────────────┘
             B             C

             G 在 BC 上，且 BG = (1/4)BC
             GH ⊥ EF，H 是垂足（动）
    ```

    * $GH$ 作为该圆上的一条弦，由普通弦过渡到直径 $GE$ 再过渡到另一段弦，长度**先增大再减小**。

    * $\alpha$ 与 $GH$ 反向（$DG$ 固定，对边越长角越小），故 $\alpha$ **先减小再增大**。

## 不好建系的处理策略

* **两类难法**

    * 第一类：图形特别难看不好建系，或图形尚可但垂直条件没有直接给出，须先自己证出来。

    * 第二类：第一类之上再叠一层——系建好了，但某些点支出去了、斜出去了，坐标不好求。

* **一个垂直往下滚一层（2021 浙江四棱锥）**

    * 已知 $PD \perp DC$（题目给）、$PM \perp MD$（题目给）、$DC \perp DM$（底面算出）。

    * $DC$ 同时垂直 $PD$ 与 $DM$，两条线在 $D$ 点相交构成一个面 ⇒ $DC \perp$ 该面 ⇒ $DC \perp PM$。

    * $PM$ 同时垂直 $DC$（刚推出）与 $MD$（题目给），两线在 $M$ 处相交构成平面 $DCM$ ⇒ $PM \perp$ 平面 $DCM$。

    * $D$、$C$、$M$ 全在底面 $ABCD$ 上 ⇒ $PM \perp$ 平面 $ABCD$。于是第一问 $AB \perp PM$ 直接得证。

    ```text
            PD  ⊥  DC   （题目给）
                 ╳
                ╱ ╲
              PM    DM
                 ╳
            PM  ⊥  DM   （题目给）
    ```

    * > **易错点**：垂直条件多时不要一上来就乱推。一个一个推，每推出一个先记下来，再看下一个。

* **面面垂直：先找交线的垂线（2022 年新高考一卷）**

    * 直三棱柱中 $\angle ABC = 90^\circ$，$AA_1 = AB$，$D$ 为 $AB$ 中点，棱柱体积 $4$，$\triangle A_1BC$ 面积为 $2\sqrt2$，平面 $A_1AB \perp$ 平面 $A_1BC$。

    * "直"意味着侧棱与底面是**线面垂直**关系，这一条后面必用。

    * 第一问用等体积法，不需建系、不需知道垂足位置：棱柱体积是同底同高三棱锥体积的 $3$ 倍，故 $V_{\text{锥}} = \frac43$。

    * $$\frac13 \cdot 2\sqrt2 \cdot h = \frac43 \quad\Longrightarrow\quad h = \sqrt2$$

    * 第二问：两面的交线显然是 $A_1B$。找垂线时**优先在形状已知的面上找**——侧面 $A_1AB B_1$ 形状不明，绿面 $A_1BC$ 是等腰直角三角形。

    * 取 $A_1B$ 中点 $G$，由三线合一得 $AG \perp AB$（即垂直交线）⇒ $AG \perp$ 平面 $A_1BC$。

    * $BC \perp AG$（面面垂直给出）与 $BC \perp AA_1$（"直"给出）两条相交线 ⇒ $BC \perp$ 平面 $ABB_1A_1$。

    * $BC$ 由此与底面、斜面上的所有线垂直，三角形形状全部可用。

    * > **结论**：题目给的每个条件都要用上；"直"给一条、面面垂直给一条，两条凑齐以某条棱为核心的两对垂直，称为条件刚好对上。

* **系该建在谁身上：选垂直条件最密集的点**

    * 挣出 $PM \perp$ 平面 $ABCD$ 后，必以 $PM$ 为 Z 轴；在该平面内以 $M$ 为原点再作两条互相垂直的 X、Y 轴。

    * 轴的放法不随意：过 $M$ 选垂直条件较多的方向（如 $DM$）作一轴，再取与它垂直且与 $AB$、$DC$ 平行的方向作另一轴。

    * > **结论**：原点选**垂直条件聚集的那个点**；哪条线垂直于一个面，就拿它当坐标轴。

    * 必须建**右手系**，扫描顺序反了会导致后面所有有向角、法向量的正负号全错。

    * 一条轴与一个平行方向定下后，另一条由右手系唯一确定，不存在第二种排法。

    * 2021 浙江题的具体坐标：$A(-\sqrt3,\, 2,\, 0)$、$C(\sqrt3,\, -1,\, 0)$、$D(\sqrt3,\, 0,\, 0)$、$M(0,0,0)$、$P(0,\,0,\,2\sqrt2)$、$N\left(\frac{\sqrt3}{2},\, -\frac12,\, \sqrt2\right)$。

    * 其中 $PM$ 题目未给，须先算：$AM^2 = 3 + 4 = 7 \Rightarrow AM = \sqrt7$，$PM^2 = 15 - 7 = 8 \Rightarrow PM = 2\sqrt2$。

    * > **注意**：$C$ 点的 Y 坐标是 $-1$，落在 Y 轴负半轴上，求 $N$ 时要用到这个负号。

* **淘气点：硬求，还是绕过去（2019 浙江斜三棱柱）**

    * $\angle ABC = 90^\circ$，$\angle BAC = 30^\circ$，$AA_1 = A_1C = AC$，$E$、$F$ 分别为 $AC$、$A_1B_1$ 中点。第一问证 $EF \perp BC$，第二问求线面角。

    * 三棱相等 ⇒ $\triangle A_1AC$ 为等边三角形 ⇒ 三线合一得 $A_1E \perp AC$（交线），结合面面垂直得 $A_1E \perp$ 平面 $ABC$，后续必用。

    * 第一问：$BC \perp AB$（题给）与 $BC \perp A_1E$（上一步）相交于 $B$；过 $A_1$ 作 $BC$ 的平行线，该线与 $A_1E$、$A_1B_1$ 都垂直 ⇒ 垂直该面 ⇒ 垂直面上含 $EF$ 在内的一切线。

    * 建系有两种：以 $E$ 为原点时 Z 轴直接是 $EA_1$，但 B 点坐标难表示；以 $B$ 为原点时取 $BC$ 为 X 轴、$BA$ 为 Y 轴、过 $B$ 平行 $A_1E$ 的直线为 Z 轴，**好处是 $A$、$C$ 都落在坐标轴上**。

    * 设 $BC = 1$，$AB = \sqrt3$，$AC = 2$：$B(0,0,0)$、$C(1,0,0)$、$A(0,\sqrt3,0)$、$E\left(\frac12,\frac{\sqrt3}{2},0\right)$、$A_1\left(\frac12,\frac{\sqrt3}{2},\sqrt3\right)$。

    * **法二（绕过点的坐标）**：$F$ 不在任何 $XOZ$ 或 $YOZ$ 平面上，支出去了；最终目标是 $\overrightarrow{EF}$，求 $F$ 只是中间一步，可直接略过。

    * 换一条好算的路径：$\overrightarrow{EF} = \overrightarrow{EA_1} + \overrightarrow{A_1F}$，其中 $\overrightarrow{EA_1} = (0,\,0,\,\sqrt3)$（竖直向上、长度即等边三角形的高）。

    * $A_1F$ 是 $\tfrac12$ 的 $A_1B_1$，而 $A_1B_1$ 即 $AB$ 的平移，$AB = (0,\,-\sqrt3,\,0)$。

    * $$\overrightarrow{EF} = (0,\,0,\,\sqrt3) + \tfrac12 (0,\,-\sqrt3,\,0) = \left(0,\, -\tfrac{\sqrt3}{2},\ \sqrt3\right)$$

    * > **结论**：点太淘气、支出去了，不必硬求其坐标；**绕开点坐标直接求向量坐标**，用向量线性运算另选一条好走的路径。

    * **法一（硬求）也可行**：棱柱上下底面对应边是同一个平移向量，故 $\overrightarrow{B_1A_1} = \overrightarrow{BA} = (0,\sqrt3,0)$；已知 $A_1$ 坐标，逐项对数即可解出 $B_1$ 的三个分量，再用中点公式求 $F$。算得出来，只是磨叽，且须额外记住"对应边同一平移向量"这件事。

* **异面直线要发生关系，先连一条辅助线（2015 浙江）**

    * 斜三棱柱中 $\angle BAC = 90^\circ$，$AB = AC = 2$，$AA_1 = 4$，$A_1$ 在底面的投影恰是 $BC$ 的中点 $O$。

    * 投影点即题目直接给出线面垂直：$A_1O \perp$ 底面。于是过 $O$ 竖 Z 轴，$OA$ 同时作 X 轴与 Y 轴的依据，建系几乎不用推导。

    * 第一问证 $AE \perp$ 平面 $A_1BC$（$E$ 为 $BC$ 中点）：底面是等腰直角三角形，$AO$ 是斜边中线也是高 ⇒ $AO \perp BC$，得第一对垂直。

    * $AD$ 不好看，把 $A$ 平移下来即为 $AO$；$AO$ 同时垂直 $CE$（三线合一）与 $A_1O$（线面垂直）⇒ $AO \perp$ 相应平面 ⇒ $AD \perp$ 平面 $A_1BC$。

    * > **结论**：异面直线要发生关系先连辅助线；这条线往往是中点连线、平行线或高。

    * $OB = \sqrt2$，$A_1O = \sqrt{16 - 2} = \sqrt{14}$，$A_1 = (0,\,0,\,\sqrt{14})$，$\overrightarrow{A_1B} = (0,\, \sqrt2,\, -\sqrt{14})$。

    * 另一向量不必求 $D$ 点：$AD$ 不好求但 $AO$ 好求，二者等长同向，$AO = (-\sqrt2,\,0,\,0)$。

    * 面 $BDB_1$ 上选 $\overrightarrow{BB_1}$，可平移到 $\overrightarrow{AA_1} = (-\sqrt2,\,0,\,\sqrt{14})$；另一条边取 $DB_1$，它就是底面 $OB$ 方向。

    * 求得 $\vec{n_1} = (0,\, \sqrt7,\, 1)$。

* **两类难题的收尾**

    * 第一类三条铁律：**底面先当初中题算**、**找隐藏的垂直条件**、**找垂直条件最密集的点当原点**。

    * 第二类两条路：水平高者**硬求点坐标**（图形确定后坐标必可求）；更省事的是**绕过点的坐标直接求向量坐标**，用线性运算、平移或另选路径。

    * 两条路的共同归宿：把立体几何问题转化成向量问题来做。

## 法向量

* **传统解法（必须写全）**

    * 在平面内取两个已知向量 $\vec{BA}$、$\vec{BD}$，设法向量为 $(x,\, y,\, z)$，列出

    $$\vec{BA}\cdot(x,y,z) = 0,\qquad \vec{BD}\cdot(x,y,z) = 0$$

    * 这一步在答题卡上必须体现。

    * 若 $\vec{BA}$ 只有 $y$ 分量非零，则乘完只剩 $2y = 0$，直接定下 $y = 0$；再由 $\vec{BD}$ 解出一元一次方程 $x + z = 0$，随便取 $x = 1$ 即得 $(1,\,0,\,-1)$。

    * > **结论**：法向量求解中，**只含一个分量的项直接决定一个分量**，剩余的一元一次方程随便取值即可——法向量乘任何非零倍数方向不变。

* **速算三步法**

    * 每个向量写两遍（复制一遍），横着摆成三行。

    * 掐头去尾，只留中间一列；再交叉相乘再相减。

    ```text
        ( x  y  z )
        ( 1  1  1 )     ← 向量 BD
        ( 1  1  1 )     ← 复制一遍
        ( 2  0  0 )     ← 向量 BC

    掐头去尾，只留中间这一列：
        ( 1  1 )
        ( 1  1 )
        ( 0  0 )

    交叉相乘再相减：
        1×1 - 1×0 = 1
        1×2 - 1×0 = 2
        1×0 - 1×2 = -2
    ```

    * 结果 $(0,\, 2,\,-2)$ 即法向量坐标，可约去公因数写成 $(0,\, 1,\,-1)$。

    * > **注意**：速算法属大学知识，考试只能直接写出算好的结果，不能写出方法名称；三个数的顺序不能搞反，写前默念一遍"掐头去尾留中间"。

* **法向量的伸缩性**

    * 一个面的法向量有无数个，彼此成倍数关系；怎么简单怎么写。

    * 2022 新高考一卷的两个法向量：$\vec{n_1} = (1,\,0,\,-1)$ 用传统解方程组，$\vec{n_2} = (0,\, 1,\,-1)$ 用速算法。

## 向量法求角度的公式细节

* **线面角要变名**

    * 线面角是直线与法向量所成夹角的**余角**：设所成角为 $\alpha$，直线与法向量夹角为 $\beta$，则 $\alpha = 90^\circ - \beta$。

    ```text
                ┌───────────────┐
             α ╱               │  β
              ╱                │ ╱
        ─────●──────────────────●────────  直线方向
        ╲
         ╲  法向量方向 n

       β = <直线, n>   ，   α = 90° - β

       ⇒  sin α = cos β   （要变名！）
    ```

    * 故 $\sin\alpha > 0$ 必须加绝对值；题目问 $\sin$ 时中间要写 $\cos\langle \overrightarrow{AN}, \vec{n}\rangle$，问 $\cos$ 则相反。

* **二面角与线线角不变名**

    * 求二面角时函数名保持不变：外面是 $\sin$，里面仍写 $\sin\langle \vec{n_1}, \vec{n_2}\rangle$。

    * 若已知 $\cos\langle \vec{n_1}, \vec{n_2}\rangle = \frac12$，则 $\sin\langle \vec{n_1}, \vec{n_2}\rangle = \frac{\sqrt3}{2}$（由平方和为 $1$）。

    * > **结论**：只有线面角变名，二面角与线线角都不变名。这是向量法求角度最容易丢分的一处，宁可多写一步转化也不要凭手感直接抄。

* **负值的处理**

    * 2021 浙江题终算：平面 $PDM$ 即 $XOZ$ 平面，法向量 $\vec{n} = (0,\,1,\,0)$；$\overrightarrow{AN} = \left(\frac{3\sqrt3}{2},\, -\frac52,\, \sqrt2\right)$，$|\overrightarrow{AN}| = \sqrt{15}$。

    $$\cos\langle \overrightarrow{AN}, \vec{n}\rangle = -\frac{5}{2\sqrt{15}}$$

    * 所求线面角正弦值 $=\left|-\frac{5}{2\sqrt{15}}\right| = \frac{\sqrt{15}}{6}$。

    * > **易错点**：⚠️ 线面角的正弦值必然为正，忘了加绝对值是最常见的丢分点。算出负数更不能当算错而改符号——应当取绝对值，改符号等于错上加错。
