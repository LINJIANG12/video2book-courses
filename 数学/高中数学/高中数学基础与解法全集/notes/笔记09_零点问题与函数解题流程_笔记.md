# 零点问题与函数解题流程

## 零点的定义与三重等价

* **零点（zero of a function）**

    * > **定义**：使 $f(x_0)=0$ 的实数 $x_0$ 叫作函数 $f(x)$ 的零点。

        * 零点是一个**数**，不是点：写成 $1$、$4$、$6$，绝不写成 $(1,0)$、$(4,0)$、$(6,0)$。定义句的主谓宾是「实数 $x_0$ 叫零点」，数才叫零点。
        * 由 $f(x_0)=0$ 直接推出：零点就是方程 $f(x)=0$ 的解。

* **零点、交点、解三者等价**

    * > **结论**：$f(x_0)=0 \iff$ $y=f(x)$ 的图像与 $x$ 轴相交于横坐标 $x_0$ $\iff$ $x_0$ 是方程 $f(x)=0$ 的解。

    ```text
              f(x0) = 0
                   │
          ┌────────┼────────┐
          ▼        ▼        ▼
       零点 x0   图像与 x 轴  方程 f(x)=0
                的交点      的解
          └────────┼────────┘
               三者完全等价
    ```

    * 题目问「有几个零点」时，可以数与 $x$ 轴的交点，也可以数方程的解，两条路完全可互换。

## 零点存在定理

* **零点存在定理（intermediate value theorem 的初等形式）**

    * > **结论**：若 $f(x)$ 在 $[a,b]$ 上连续，且 $f(a)\cdot f(b)<0$，则在 $(a,b)$ 内至少存在一个零点 $x_0$，使 $f(x_0)=0$。

        * 两个条件必须同时成立：闭区间 $[a,b]$ 上连续 + 两端点函数值异号（乘积小于 $0$）。
        * 几何机理：由 $a$ 点连着走到 $b$ 点，函数值一正一负，途中必然穿过 $x$ 轴，穿过处即零点。
        * 反向走（一负一正）同样穿过 $x$ 轴，零点照样存在。

* **只能说「至少一个」**

    * 定理给的是零点个数的**下限**，不是上限。

    ```text
       若一路“拐弯抹角”：
            ╲    ╱╲        ╱
             ╲╱    ╲  ╱╲  ╱
       ─────●───────●────●───────  y = 0
            零点    零点  零点     ⇒ 可以有很多个，但至少一个
    ```

* **充分不必要**

    * > **易错点**：零点存在定理是充分不必要条件，正着推成立，反着推不成立。由「在 $[a,b]$ 上有零点」不能反推端点函数值异号。

        * 反例：可画出一条曲线与 $x$ 轴有交点（确实有零点），但两端点函数值同为正，属同号。

* **单调函数上的定位法**

    * 单调递减的函数，两端点一正一负即可断定区间内有零点。
    * 不单调的复杂函数，仅靠判断端点异号无法判断有无零点，必须把单调性请出来。

## 用单调性定位零点

* **把陌生函数看成熟函数**

    * 增减性由主体项决定：$\ln x$ 递增、$2x$ 递增、指数函数递增、幂函数按指数单调。
    * 增函数 + 增函数 = 递增；加减一个常数不改变单调性。
    * 形如「以 $a>1$ 为底的对数」与「递减分式」相减，整体仍递增：前者增、后者减，$a$ 越大前者越大，后者越小，差单调递增。

    * > **结论**：陌生解析式的函数只要单调性可判，零点就落在左右两侧函数值异号的位置之间。

* **代值找正负交替点**

    * 例：$f(x)=\ln x+2x-1$，单调递增。$f(1)=\ln 1+2-1=1>0$；$f\left(\tfrac12\right)=\ln\tfrac12+1-1=\ln\tfrac12<0$。零点落在 $\left(\tfrac12,\,1\right)$ 内。
    * 单调递增时，$f(1)>0$ 已定，则 $x>1$ 处不必再看，只需往左找负值点。
    * 例：$f(0)=\log_4 4-\dfrac41=1-4=-3<0$；$f(1)=\log_4 6-2<0$；$f(2)=\log_4 8-\dfrac43>0$，零点在 $1$ 与 $2$ 之间。

* **比较对数与有理数的大小**

    * > **提示**：两条通用路子——回对数定义粗估，或两边同时取以同一底数的指数消掉对数。

        * 估法：由 $4^1=4<6$、$4^2=16>6$ 知 $\log_4 6$ 落在 $1$ 与 $2$ 之间，故 $1.$-几减 $2$ 必小于 $0$。无理对数值算不出小数，只能估算它落在哪两个整数次幂之间。
        * 消法：$4^{\log_4 6}=6$、$4^2=16$，$6<16$ 故 $\log_4 6<2$。
        * 叠加：消掉对数后得到指数比大小，再两边同取 $n$ 次幂把分数指数约掉。如比较 $8$ 与 $4^{\frac43}$：同取三次幂，左得 $(2^3)^3=2^9$，右得 $4^4=(2^2)^4=2^8$，故 $8>4^{\frac43}}$。

## 把零点翻译成两个图像的交点

* **两条作图路径**

    * > **结论**：$f(x)=0 \iff$ $y=f(x)$ 与 $y=g(x)$ 的交点横坐标，其中 $g(x)$ 是把 $f(x)$ 移项整理后的另一半。

    ```text
       路径 A：整体作图
          f(x) = 0  ⇔  y = f(x) 与 x 轴的交点

       路径 B：拆成两半看交点
          f(x) = 0  ⇔  f(x) − g(x) = 0  ⇔  y=f(x) 与 y=g(x) 的交点

       x² + x − 2 = 0
            ⇕
       x² = 2 − x
            │
            ▼
       抛物线 y = x² 与直线 y = 2 − x 的两个交点：x = −2, 1
    ```

    * 二次函数是最小验证：$x^2+x-2=(x+2)(x-1)$，与 $x$ 轴交于 $-2$ 与 $1$；拆成 $x^2=2-x$ 后，抛物线与直线交点横坐标同样是 $-2$ 与 $1$。

* **整体画不出时的拆法**

    * 把 $x$ 移到右边，左右两边都减一个 $x$，使每一半都成为会画的初等函数。
    * 例：右半边固定为 $-x$，即二、四象限的角平分线；左边分别是递减的对数函数、递增的指数函数、幂函数。
    * $y=-x$ 与三条曲线各有一个交点，指数函数增长最快故自变量最小，对数函数增长最慢故自变量最大，幂函数居中，得 $x_1>x_3>x_2$。

## 用奇偶性定零点个数

* **偶函数零点成对出现**

    * 判定偶函数：解析式中 $x$ 全以 $x^2$ 形式出现，则 $f(-x)=f(x)$ 成立。
    * > **结论**：偶函数图像关于 $y$ 轴对称，零点必成对出现；若已知「有且仅有一个零点」，该零点只能是原点，即 $f(0)=0$。

        * 除原点外任何零点，其关于 $y$ 轴的对称点也是零点，必然成对；想只有一个，零点必须落在对称轴上。

* **由零点个数反解参数**

    * 例：$f(x)=x^2+2a\log_2\!\big(a^2x^2+2\big)+a^2-3$ 为偶函数且有唯一零点。
    * 代入 $x=0$：$0+2a\log_2 2+a^2-3=0$，$\log_2 2=1$，得 $a^2+2a-3=0$，即 $(a+3)(a-1)=0$。
    * 题设 $a>0$，取 $a=1$。

## 分段函数的零点

* **逐段画图**

    * 分段函数每段分别研究，画在同一坐标系里拼起来，各段只保留自己定义域内的部分。
    * 例：$f(x)=\begin{cases} -x^2-2x, & x\le 0 \\ \left|\log_{0.5}x\right|, & x>0 \end{cases}$
        * 左支：$-x^2-2x$ 开口向下，零点 $0$ 与 $-2$，对称轴 $x=-1$ 处取最大值 $1$。
        * 右支：$|\log_{0.5}x|$ 是 V 形，$x=1$ 处取最小值 $0$；负值部分上下翻转留在 $x$ 轴上方。

* **让水平线动起来**

    * 求 $f(x)+1-m=0$ 有四个零点时，不必重画 $f(x)+1-m$，把 $y=m-1$ 看成一条随 $m$ 上下平移的水平直线。
    * $m$ 是参数、$x$ 是变量；相对 $x$ 而言 $m-1$ 是固定值。

    ```text
       y = m − 1  是一条“会动”的水平直线

       左支（x ≤ 0）：−x² − 2x，开口向下，在 x = −1 处取最大 1
       右支（x > 0）：|log₀.₅x|，V 形，最小值 0（在 x = 1）

       直线与两支的交点个数：
         m−1 < 0     →  左 2 + 右 0 = 2
         m−1 = 0     →  左 2 + 右 1 = 3
       ┌ 0 < m−1 < 1 →  左 2 + 右 2 = 4   ✔ 四个零点
         m−1 = 1     →  左 1 + 右 2 = 3
         m−1 > 1     →  左 0 + 右 2 = 2
    ```

    * 临界值无需计算：最高位置就是左支对称轴 $x=-1$ 处的函数值 $(-1)^2$ 型代入得 $1$，最低位置是 $0$。
    * 由 $0<m-1<1$ 得 $m\in(1,\,2)$，开区间，两端都取不到四个交点。

## 复合函数的零点

* **换元由外到内**

    * $f(f(x))=3$ 有两层套娃，直接画图不可能，用换元把内层设成整体 $m$。
    * 先只看外层：$f(m)=3$ 的交点横坐标就是 $m$ 的候选值。
    * 再回内层：每个 $m$ 值对应一条水平直线 $y=m$，其与 $y=f(x)$ 的交点个数才是 $x$ 的解个数。

    ```text
       f(f(x)) − 3 = 0
              │
              │  外层套内层：令内层 f(x) = m（换元）
              ▼
       f(m) = 3                       ← 先只看外层，解出中间量 m
              │
              ▼
       m₁ < 0      （来自直线段 x + 4）
       m₂ ∈ (0,1)  （落在 0 到 1 之间，来自 |log₂x| + 1）
       m₃ > 1      （大于 1，同样来自 |log₂x| + 1）
              │
              │  再回内层：y = m 是一条水平直线
              ▼
       y = f(x) 与 y = m₁  相交  →  1 个交点
       y = f(x) 与 y = m₂  相交  →  1 个交点
       y = f(x) 与 y = m₃  相交  →  3 个交点
              │
              ▼
       零点总数 = 3 + 1 + 1 = 5
    ```

* **关键边界必须回代验证**

    * > **易错点**：换元得到的 $m$ 值不能靠「看图」判断大小关系，必须回原方程解出精确值。

        * 例：$m_3$ 来自 $|\log_2 x|+1=3$，解得 $|\log_2 x|=2$，故 $x=4$ 或 $x=\tfrac14$；前者即 $m_3=4$，恰卡在「三交点变两交点」的临界位置。
        * 分段点处 $f(x)$ 取绝对值前后的最低点为 $(1,0)$，图像在 $(1,1)$ 处取到。

* **计数口径**

    * 求 $m$ 的方程有几个解 ≠ 零点个数。必须把每个 $m$ 展开成一条水平线，数清每条线与 $y=f(x)$ 的交点数再相加。

## 函数题的通用解题流程

* **三招总纲**

    * > **结论**：**能画图就画图；画不了图就想性质；图像画不出、性质也用不上，再去变形。**

        * 不需要判断题目属于哪个章节、用哪个定理，按顺序往下走，总有一招能踩上。
        * 题目越难，这个方法越好用。

    ```text
    ┌──────────────────────────────────────────────┐
    │  拿到一道不会的函数题                        │
    └──────────────────────────────────────────────┘
                        │
                        ▼
            ┌───────────────────────┐
            │ 第一招：能画图就画图  │  因式分解找零点、对称性补零点、
            └───────────┬───────────┘  分段函数拆两段、对勾函数的基本形、
                        │              绝对值的两种图像变换、翻折与平移
                        ▼
                画得出来吗？
               ╱          ╲
             能              不能
            │                 │
            ▼                 ▼
       图像信息就是     ┌───────────────────────┐
       答案的骨架      │ 第二招：想性质        │  单调性脱衣服、构造
                        └───────────┬───────────┘  函数换皮、轴对称与
                        │            │            中心对称、两次对称
                        ▼            ▼           推出周期性
                有性质吗？        ┌─────────────────┐
               ╱        ╲         │ 第三招：变形      │  去绝对值、分离参数、
            有            没有      └────────┬────────┘  换元拆分子、放缩构造
            │             │                 │            同构式
            ▼             ▼                 ▼
        用性质解决    回到变形            变形后图像和性质
                                            可能一起搞定
    ```

    * > **结论**：图是信息密度最高的中间产物。难题做不出来，多数不是想不到高级技巧，而是第一步、第二步该拿的分没拿全。

## 第一招 画图

* **从因式分解与对称性读零点**

    * 已因式分解的多项式，每个因式为 $0$ 各给一个解，图像与 $x$ 轴的交点横坐标即这些解。
    * 例：$x(x-1)$ 与带参数的二次因式相乘，四次函数至少有两个零点 $0$、$1$。
    * 题目补一句「图像关于直线 $x=2$ 对称」，则 $1$ 与 $3$、$0$ 与 $4$ 关于 $x=2$ 对称，右侧零点被补出，共四个零点 $0,1,3,4$。
    * 求系数之和用韦达定理：$(x-3)(x-4)=x^2-7x+12$，故 $a=-7$、$b=12$，$a+b=5$。

* **对勾函数的标准形**

    * > **结论**：形如 $ax+\dfrac{b}{x}$ 是正比例函数与反比例函数之和；$a,b$ 均为正时图像是两个小钩钩，第一象限的最低点函数值为 $2\sqrt{ab}$。

        * 由 $ax+\dfrac{b}{x}\ge 2\sqrt{ax\cdot\dfrac{b}{x}}=2\sqrt{ab}$，乘积中 $x$ 约掉。
        * > **易错点**：$2\sqrt{ab}$ 是最低点的**函数值**，不是横坐标。均值不等式取等条件是两部分相等，令 $ax=\dfrac{b}{x}$ 解得最低点横坐标为 $\sqrt{\dfrac{b}{a}}$，两者不能互换。

    * $x+\dfrac1x$：令 $x=\dfrac1x$ 得 $x=\pm1$，最低点 $(1,2)$；减 $1$ 后最低点下移为 $(1,1)$。
    * $x+\dfrac4x$ 在 $[1,4]$ 上：最低点在 $x=2$ 处取到，函数值 $4$；两端点 $x=1$ 与 $x=4$ 的函数值都是 $5$，落差为 $1$。

* **区间截取**

    * 题目问「$x\in[a,b]$ 时函数值在 $1$ 到 $3$ 之间，求 $b-a$ 最大值」，等价于问满足条件的取值区间最长能有多长。
    * 步骤：先让最大值 $3$ 出现（$3$ 只在一个点取到，右端点只能放这儿）→ 再往下截到最低点使最小值为 $1$ → 确认再多截就破坏最小值为止。
    * 例：$f(x)=\begin{cases} -x^2+2x, & x\le 1 \\ x+\dfrac1x-1, & x>1 \end{cases}$，左段开口向下、最高点 $(1,2)$、对称轴 $x=1$，对称轴左边与函数值 $1$ 的交点横坐标 $a=-1$。
    * 右端点由 $b+\dfrac1b-1=3$ 得 $b+\dfrac1b=4$，两边同乘 $b$ 得 $b^2-4b+1=0$，$b=2\pm\sqrt3$；根在 $1$ 的右边，取 $b=2+\sqrt3$（舍去 $2-\sqrt3<1$）。
    * 于是 $b-a=2+\sqrt3-(-1)=3+\sqrt3$。

* **绝对值的两种图像变换**

    * > **结论**：对函数整体取绝对值 $|f(x)|$，只把 $x$ 轴下方的图像对称翻上来，$x$ 轴上方原封不动。

    ```text
       整体取绝对值：只翻 x 轴下方那部分

          y                        y
          │      ╱╲                │    ╭─╮  ╭─╮
          │     ╱  ╲               │   ╱   ╲╱   ╲
       ───┼────╱────╲────→x     ───┼──╱─────────╲──→x
          │   ╱      ╲             │
          │  ╱        ╲            │  x 轴下方的部分被翻上来
          └─ 翻上来 ──┘             └─ 原图在 x 轴下方的影子
    ```

    * > **结论**：$f(|x|)$ 分两步作图——先在正半轴上按原来的 $f(x)$ 画，再关于 $y$ 轴左右对称翻到左边。

        * $x>0$ 时 $f(|x|)=f(x)$，右侧图像与原函数完全一样；$x<0$ 时 $f(|x|)=f(-x)$，不必真去画 $f(-x)$，把右边关于 $y$ 轴照镜子即可。

* **平移与翻折的临界条件**

    * 例：$f(x)=\left|x+\dfrac4x-a\right|+a$，$x\in[1,4]$ 时最大值为 $5$，求 $a$ 的最大值。
    * $a$ 较小时减 $a$ 使图像整体落在 $x$ 轴上方，绝对值不起作用，再加 $a$ 平移回去，原函数不变，最大值仍是端点值 $5$。
    * $a$ 变大后出现 $x$ 轴下方部分，取绝对值翻上来会鼓出一个「肚子」；肚子顶点即 $x=2$ 处的函数值。
    * > **结论**：临界条件是翻折后 $x=2$ 处的值恰好等于端点值 $5$，即平移量恰好等于落差 $5-4=1$。

    ```text
            y
       5 ┤ ●──────────────────●      端点，x=1 与 x=4，函数值都是 5
          │ ╲                ╱
          │   ╲            ╱
       4 ┤     ● 顶点(2,4)         ← 原最低点
          │       ╲      ╱
          │         ╲  ╱            ← 往下平移 a 后，一部分落到 x 轴下方
       0 ┼───────────┼───────────────→ x
          1     1/2   2          4
                    ↑
          翻折后鼓出的"肚子"最高点，恰好等于 5 时为极限状态
    ```

    * 整个计算只用平移与翻折两条初中几何：平移不改变高度（$5-4=1$ 始终是 $1$），翻折不改变长度，鼓出部分的高度是原来落差的一半，即 $\tfrac12$。
    * 从端点值 $5$ 往下量 $\tfrac12$，得 $a_{\max}=5-\tfrac12=\tfrac92$。

## 第二招 性质

* **脱衣服**

    * > **定义**：把单调函数两边的 $f$ 约掉、只看不等号变不变，这个操作叫脱衣服。

        * 单调递增：不等号方向不变；单调递减：不等号方向改变。

    * 形式 $f(\text{甲})>f(\text{乙})$ 可直接脱；一边是常数时，先把常数写成 $f(\text{某})$ 的形式。
    * 例：$f(xy)=f(x)+f(y)-1$ 在 $(0,+\infty)$ 上为减函数，求 $f(\log_2 x-1)>1$ 的解集。
        * 令 $x=y=1$ 得 $f(1)=f(1)+f(1)-1$，即 $f(1)=1$；原不等式即 $f(\log_2 x-1)>f(1)$。
        * 减函数脱衣服反向：$\log_2 x-1<1$，即 $\log_2 x<2$。
        * 还须满足定义域 $\log_2 x-1>0$，即 $x>2$，与前者取交集得 $2<x<4$。

* **试探取值前先看定义域**

    * > **易错点**：$0$ 不在 $(0,+\infty)$ 内，$f(0)$ 根本不存在，不能令 $x=y=0$。试探取值之前必须先看清定义域。

    * 同理，解抽象不等式时括号里的表达式也必须满足定义域要求；只解了不等式一边、漏掉定义域是最常见的错。

* **单调性的换皮写法**

    * 不写「减函数」三个字，而是写成 $x_1>x_2$ 时 $f(x_1)>f(x_2)$、$(x_1-x_2)\,[f(x_1)-f(x_2)]>0$ 或 $\dfrac{f(x_1)-f(x_2)}{x_1-x_2}>0$，本质都是单调性。
    * > **结论**：两式同号意味着 $x_1$ 与 $x_2$ 大小时 $f(x_1)$ 与 $f(x_2)$ 同序，读到这种式子就往单调性上靠。

* **构造函数法**

    * > **定义**：把一个复杂表达式整体看作新函数、设元替换的变形手法叫构造函数法。

        * > **结论**：变形原则一句话——**相同变量放一起，不同变量放两边**。

    * 例：已知 $x_1>x_2$ 且 $f(x_1)-f(x_2)>x_1^2-x_2^2$，判断 $f(x)-x^2$ 的单调性。
        * $x_1>x_2 \Rightarrow x_1^2-x_2^2>0$，正数乘过去不变号，整理得 $f(x_1)-x_1^2>f(x_2)-x_2^2$。
        * 设 $g(x)=f(x)-x^2$，则 $x_1>x_2$ 时 $g(x_1)>g(x_2)$，故 $g$ 在该区间上单调递增。
        * > **易错点**：这里说的是 $g$ 递增，**不是 $f$ 递增**。

    * 例：$f$ 为定义在 $\mathbf{R}$ 上的奇函数，任意不相等的正数 $x_1,x_2$ 有 $\dfrac{f(x_1)-f(x_2)}{x_1-x_2}<0$。
        * 不妨设 $x_1>x_2$，分母为正故分子为负，得 $x_2f(x_1)-x_1f(x_2)<0$。
        * 两边同除以 $x_1x_2$（二者为正，不变号），得 $\dfrac{f(x_1)}{x_1}<\dfrac{f(x_2)}{x_2}$。

    * > **易错点**：除以 $x_1x_2$ 不变号，靠的是「$x_1,x_2$ 为正数」这个条件，条件里的「正数」二字不是废话。

        * 结论是 $g(x)=\dfrac{f(x)}{x}$ 在 $(0,+\infty)$ 上单调递减，**不是在整个 $\mathbf{R}$ 上**。
        * 奇函数除奇函数得偶函数（分子分母均为奇函数），故 $g$ 是偶函数，可把负自变量对称到正半轴。

* **轴对称与中心对称的换皮写法**

    * > **结论**：$f(a+x)=f(b-x)$ 的图像关于直线 $x=\dfrac{a+b}{2}$ 对称。

        * 函数值相等即左右对称，对称轴就是两个横坐标的中点；相加后 $x$ 恰好消掉。

    * > **结论**：$f(a+x)+f(b-x)=c$ 的图像关于点 $\left(\dfrac{a+b}{2},\,\dfrac{c}{2}\right)$ 中心对称。

        * $f+f$ 为定值意味着一高一低、一大一小，中点是中心；纵坐标要再除以 $2$。

    ```text
       两类对称信息的提取流程

       题给条件                       可直接读出
       ─────────────────────────────────────────────
       f(x) = f(-x)                  偶函数，关于 y 轴对称
       f(a+x) = f(b-x)                关于直线 x = (a+b)/2 对称
       f(a+x) + f(b-x) = c            关于点 ((a+b)/2, c/2) 中心对称
       ─────────────────────────────────────────────
       规则：轴对称给「相等」，中心对称给「和为定值」
    ```

* **对称中心处必过对称中心**

    * > **结论**：函数在对称中心处有定义，则必过对称中心，函数值为 $0$。

        * 理由：若该点函数值不为 $0$，其关于中心的对称点也在图像上，同一横坐标对应两个纵坐标，那就不是函数了。
        * 代数验证：把对称式中的 $x$ 全代 $0$，得 $2g(2)=0$。
        * 奇函数是中心 $(0,0)$ 的特例，故 $g(0)=0$。

* **两次对称推周期性**

    * > **结论**：题目给出两次对称——一个对称轴加一个对称中心、两个对称轴或两个对称中心——即可推出整个函数具有周期性。

    ```text
       周期性是怎么“长”出来的

       起点：[-2, 2] 上的一段抛物线 y = x² − 4

            ┌── 对称中心 (2,0)，翻转 180° ──┐
            │                                │
       ─────┼────────────────────────────────┼────────→ x
           -2      0       2                4        6
           └──── 偶函数，关于 y 轴翻 ────┘
       ↑ 先向右翻，再向左翻；然后再向右、再向左 ……
       每翻一次，图像就向右（或向左）多铺一个长度 8 的单位
    ```

    * 例：$f(2+x)+f(2-x)=0$ 给出对称中心 $(2,0)$；$[−2,2]$ 上 $f(x)=x^2-4$ 本身关于 $y$ 轴对称，给出偶性。
    * 轴对称 $x=0$ 与中心对称 $x=2$ 合用，每翻一次多铺 $6+2=8$ 个单位，周期 $T=8$。
    * 大数化小：$2029\div 8=253\cdots5$，故 $f(2029)=f(5)=f(-3)=f(3)=-f(1)=3$，其中 $f(1)=(-1)^2-4=-3$。
    * > **结论**：不要真把函数画到 $2029$ 那么长；由周期性取余即可。

    * 两个对称中心的情形同理，且对称中心有无穷多个。
    * 例：$g$ 为奇函数（中心 $(0,0)$），又有 $g(2+x)+g(2-x)=0$（中心 $(2,0)$），则 $-6$ 也是对称中心，$g(-6)=0$。
    * 由关系式令所有 $x$ 取 $-6$ 得 $g(-6)=f(-6)+36$，故 $f(-6)=-36$。

## 第三招 变形

* **绝对值不等式不需要分类讨论**

    * > **结论**：$|u|\le v$ 等价于 $-v\le u\le v$，直接写双边，不必分类讨论。

    ```text
       |★| ≤ △   的几何含义（到原点的距离）

                 △            （△ 到原点的距离）
              ◀────▶
       ────────┼──────────────┬──────────────→ 数轴
            −△  │              │  △
                 ◀────────────▶
                      ★ 可活动的范围

       等价于：  −△ ≤ ★ ≤ △     ← 直接写双边，不用分类讨论
    ```

    * 例：$x\in[2,3]$ 时 $\left|x-k\right|\le\dfrac{k}{x}$ 恒成立。去绝对值得 $-\dfrac{k}{x}\le x-k\le\dfrac{k}{x}$。
    * $x\in[2,3]$ 全为正，两边乘 $x$ 不需要考虑不等号方向。

* **分离参数**

    * > **结论**：求参数取值范围时，把参数与变量拆开；恒成立的标准翻译是「比最小值还小」。

    * 左边一支：$k-\dfrac{k}{x}\le x$，两边乘正数 $x$ 得 $kx-k\le x^2$，整理得 $k(x-1)\le x^2$；$x-1>0$ 可移到右边，得 $k\le\dfrac{x^2}{x-1}$。
    * 恒成立即 $k$ 比 $\dfrac{x^2}{x-1}$ 的最小值还小，于是化为二次比一次型函数的最值问题。

* **换元与拆分子**

    * 二次比一次、一次比二次的标准处理是把一次项整体换元。
    * > **易错点**：换元时最容易丢的是**新元的取值范围**，它是旧元范围整体平移得到的；漏掉这一步后面所有最值都算错。

    * 左边一支令 $x-1=m$，则 $m\in[1,2]$；$\dfrac{x^2}{x-1}=\dfrac{(m+1)^2}{m}=m+2+\dfrac1m$。
    * 由 $m+\dfrac1m\ge 2$ 得原函数 $\ge 4$，取等条件 $m=1$ 且 $1\in[1,2]$ 可行，故 $k\le 4$。
    * 右边一支：$k(x+1)\ge x^2$，分离参数得 $k\ge\dfrac{x^2}{x+1}$；令 $x+1=t$，则 $t\in[3,4]$，$\dfrac{(t-1)^2}{t}=t+\dfrac1t-2$。
    * > **注意**：$k$ 比函数值大，求的是**最大值**，基本不等式只管最小值，不能硬套；只能回到对勾函数图像，在 $t\in[3,4]$ 单调递增，最大值在 $t=4$ 处为 $4+\tfrac14-2=\tfrac94$。

* **恒成立先看定义域**

    * > **易错点**：恒成立问题必须先检查式子是否有意义。原式含分母 $\dfrac{k}{x}$，若 $k\in[2,3]$ 就有 $x=k$ 使分母为 $0$，式子无意义，不能算作恒成立。

    * 综合两个限制得 $k\in\left[\tfrac94,\,4\right]$，再抠掉 $k\in[2,3]$（含 $3$），最终 $k\in(3,\,4]$。

* **放缩与同构式**

    * 例：$a,b\in\mathbf{R}$ 且 $2^a+\log_2 a=4^b+2\log_4 b$，判断 $a$ 与 $2b$ 的大小。
    * 第一步化底：$4^b=2^{2b}$，$2\log_4 b=\log_2 b$，原式化为 $2^a+\log_2 a=2^{2b}+\log_2 b$。
    * 第二步放缩：$\log_2(2b)=1+\log_2 b>\log_2 b$，把右边的一个 $\log_2 b$ 换成更大的 $\log_2(2b)$，等式即变为不等式
    * $$2^a+\log_2 a\ <\ 2^{2b}+\log_2(2b)$$
    * 第三步设元：$f(x)=2^x+\log_2 x$，左右结构完全相同，得 $f(a)<f(2b)$；$f$ 是增函数（增函数加增函数），脱衣服得 $a<2b$。
    * > **结论**：放缩是把小的变大、大的变小，牺牲精确性换取左右结构一致；结构一致的式子叫**同构式**。
    * 凑成同构式的思路在导数、圆锥曲线等模块同样重要。

## 抽象函数求值

* **代特殊值**

    * 给出一个 $g(a)$ 之类的特殊值，就往那个特殊值上代。
    * 例：$g(x+y)-g(y)=x(x+y-2)$，$g(1)=0$。直接代 $x=y=0$ 会把 $g(0)$ 消掉求不出，须取 $x=1$、$y=0$。
    * 代入得 $g(1)-g(0)=1\times(1+0-2)=-1$，故 $g(0)=1$。

* **消去无关变量求解析式**

    * > **结论**：要求 $g$ 的解析式，就保留 $g$、把无关变量置成已知值消掉。

    * 令 $y=0$：$g(x)-g(0)=x(x-2)$，代入 $g(0)=1$ 得 $g(x)=x^2-2x+1$。
    * 于是 $f(x)=\dfrac{g(x)}{x}=x+\dfrac1x-2$（$x\neq 0$），解析式本身同时给出了第三问要用的 $x\neq 0$。

* **偶函数求参的两条路**

    * > **结论**：解答题必须用定义法，令 $f(-x)=f(x)$ 把解析式代进去解；选择题可代特殊值 $x=1$，解 $f(1)=f(-1)$，压力小得多。

    * 定义法能解决几乎所有奇偶性求参问题，是通法；特殊值法只适合等式对任意 $x$ 成立、且解析式在特殊值处可算的小题。
    * 整理同底数幂时用「同底数幂相乘、指数相加」，过程中容易出现整体取相反数。
    * > **易错点**：分母整理后恰是原分母的相反数，若直接把分母约掉会差一个负号；负负得正对齐后才能归到同底形式。

## 复合函数求值域与新定义

* **由里往外一点点求**

    * 复合函数求值域的标准方法是剥洋葱：先求最内层的取值范围，再看套上外层函数之后如何。
    * 例：$[x]$ 表示不超过 $x$ 的最大整数，求 $[f(x)]$ 的值域，其中 $f(x)=\dfrac{2^x-\tfrac12}{2^x+1}$。
    * 凑分母化简：把分子改写成 $(2^x+1)-\left(1+\tfrac12\right)$ 的形式，得 $f(x)=\dfrac12-\dfrac{1}{2^x+1}$，分子不含变量。
    * $2^x>0 \Rightarrow 2^x+1>1$，令 $t=2^x+1>1$，则 $y=\dfrac12-\dfrac1t$ 是反比例函数上移 $\dfrac12$。
    * 截取 $t>1$ 的图像：最小值极限为 $-\tfrac12$，最大值极限为 $\tfrac12$，两端都取不到，值域为 $\left(-\tfrac12,\ \tfrac12\right)$。

    ```text
       y
       ↑
    1/2 ································  渐近线，取不到 y = 1/2
       │                          ╭────
       │                     ╭────╯
       │                  ╭──╯
     0 ├────────────────●──────────────────→ t
       │              (1,0)
    ```

    * 外层再套高斯函数，$-1$ 到 $\tfrac12$ 之间的数只能取 $-1$ 与 $0$ 两个值。

    ```text
       -1      -1/2        0       1/2      1
        ●--------●---------●--------●--------●
        │  取 -1 │  取  0  │              │
        └────────┴─────────┘
            高斯函数作用后的取值只有这两个
    ```

    * 值域为 $\{-1,\ 0\}$。

* **高斯函数的取整方向**

    * > **定义**：$[x]$ 表示不超过 $x$ 的最大整数；$[5.8]=5$，$[-3.1]=-4$。

    * > **易错点**：负数是向更小的方向取，高斯函数与四舍五入不是一回事，是一个全新的函数定义。

    * 新定义的外壳剥掉后，剩下的往往只是复合函数求值域或换元对勾函数等常规考法。

## 对数方程的定义域陷阱

* **化指数方程再换元**

    * 同底数对数相减，真数相除：移项后得 $\log_2\dfrac{A}{B}=2$，指对互化得 $\dfrac{A}{B}=2^2=4$。
    * 整理成 $9^{x-1}-5=4\cdot 3^{x-1}-8$。因 $9=3^2$，故 $9^{x-1}=(3^{x-1})^2$，每一项都含 $3^{x-1}$，立刻换元 $t=3^{x-1}$。

    $$t^2-4t+3=0 \quad\Longrightarrow\quad (t-1)(t-3)=0$$

    * > **易错点**：解出的是中间变量 $t$，不能直接当答案。$3^0=1$ 给 $x=1$，$3^1=3$ 给 $x=2$，必须回代。

* **回代后的真数检验**

    * > **结论**：对数方程必须考虑定义域，真数要大于 $0$。

        * 本题 $x=1$ 时 $3^{x-1}=1$，代入分母得 $1-2=-1$ 为负，不合题意，舍去。
        * 只有 $3^{x-1}=3$ 时分母为正，第一项也为正，最终解为 $x=2$。

## 情境化的对数计算

* **第一步是主动取底**

    * 例：太阳质量 $M=\dfrac{4\pi^2r^3}{GT^2}$，已知 $\lg\dfrac{r^3}{GT^2}=28.7$、$\lg 2=0.3$、$\lg\pi=0.5$。
    * 题目只给 $\lg$ 型条件而公式里全无对数，故第一步必须主动两边同取 $\lg$。
    * > **结论**：两边同时取相同的运算，等号不变；这一步是整题最关键的一步。

* **下头公式与指对互化**

    * 真数相乘对数相加：$\lg M=\lg 4+2\lg\pi+\lg\dfrac{r^3}{GT^2}$。
    * 下头公式把真数位置的指数提到前面作系数：$\lg 4=2\lg 2=0.6$，$2\lg\pi=1$。
    * 故 $\lg M=0.6+1+28.7=30.3$，指对互化得 $M=10^{30.3}=10^{30}\times 10^{0.3}$。
    * 由 $\lg 2=0.3$ 直接得 $10^{0.3}=2$，故 $M=2\times 10^{30}$。
    * > **易错点**：不要把 $10^{30.3}$ 强行约成 $10^{30}$；这类题故意让结果落在给定 $\lg$ 值能拆开的整数与小数点上。

* **对数估算**

    * > **提示**：估算 $\log_a b$ 就是找它落在哪两个熟悉的整数次幂之间，再取对应指数区间。
    * 例：$\log_3 8$ 落在 $1$ 与 $2$ 之间，因为 $\log_3 3=1$、$\log_3 9=2$。
    * 例：$\log_5 4$ 落在 $\tfrac12$ 与 $1$ 之间，因为 $\log_5\sqrt5=\tfrac12$、$\log_5 5=1$，而 $\sqrt{16}=4<\sqrt{25}=5$。

## 构造函数与比大小

* **变形与设元**

    * 把 $x_1$、$x_2$ 分开、构造 $g(x)=\dfrac{f(x)}{x}$ 后，问题变成比较 $g(4^{0.2})$、$g(0.4^2)$、$g(\log_{0.2}4)$。
    * > **结论**：不要逐个算这三个 $g$ 的值，先比较里面三个自变量的大小，再在图像上定位。

* **三个自变量的估算**

    * $4^{0.2}$：$0.2$ 很小，$4^{0.2}$ 略大于 $1$（约 $1.32$）。
    * $0.4^2=0.16$。
    * $\log_{0.2}4$：底数 $0.2=\dfrac15=5^{-1}$，下头得 $-\log_5 4\in(-1,\ -0.5)$，落在负半轴。
    * 负半轴的值用偶性对称到正半轴，与 $\log_5 4$ 是同一个函数值。

    ```text
       x 轴：   0.16        0.5~0.6        1.32
                ●────────────●──────────────●
                log_0.2 4  ≈ log_5 4      4^0.2
                （负半轴，对称到正半轴看绝对值）
    ```

    * $g$ 在 $(0,+\infty)$ 上递减，自变量越小函数值越大，得 $b>c>a$。

## 含参换元求根的个数

* **两层分析：先 $m$ 后 $x$**

    * 例：$f(x)=\dfrac{g(x)}{x}=x+\dfrac1x-2$，解方程 $f\left(\left|2^x-1\right|\right)+\dfrac{2k}{\left|2^x-1\right|}-3k=0$。
    * 复合函数最重要的方法是换元：内层整体反复出现，设 $\left|2^x-1\right|=m$。
    * 代入并两边同乘 $m$（$m\neq 0$）得关于 $m$ 的一元二次方程：

    $$m^2-(3k+2)m+2k+1=0$$

    * 这只是关于 $m$ 的解数，最终要的是关于 $x$ 的解数；每个 $m$ 值展开成一条水平直线，交点数才是 $x$ 的解数。

* **内层函数的交点个数**

    * $y=m=\left|2^x-1\right|$ 的图像：$2^x$ 下移 $1$ 后过原点，再取绝对值把 $x$ 轴下方翻上来；左支以 $m=1$ 为渐近线，永不取到。

    ```text
        y = m
          ↑
          │        m₂ > 1   ──────────────●      右支上 1 个交点
          │                                ╱
          │  m = 1  ┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄╱         左支的渐近线，永不取到
          │                              ● (1,0)
          │   0 < m₁ < 1  ──────────●─────●            2 个交点
          │                       ╱         ╲
        ──┼────────────────────●────────────────────→ x
          │                  (0,0)
          ↑ m = 0 时虽然也有 1 个交点，但 m 在分母上，不能取 0
    ```

    * $0<m<1$ 时水平线有 2 个交点，$m>1$ 时有 1 个交点，$m=0$ 虽有 1 个交点但 $m$ 在分母上必须舍去。
    * 三个 $x$ 解 $=2+1$，即一个 $m$ 根在 $(0,1)$、另一个根在 $(1,+\infty)$。

* **由根的分布反解参数**

    * 开口向上（最高次项系数为 $1$）、一根在 $0$ 与 $1$ 之间、一根大于 $1$，等价于两个函数值条件：

    $$y(0)=2k+1>0,\qquad y(1)=1-(3k+2)+2k+1=-k<0$$

    * 解得 $k>-\tfrac12$ 与 $k>0$，取交集 $k>0$。
    * 充分性由零点存在定理保证：由正变负的过程必然穿过 $m$ 轴，一根必在 $(0,1)$ 内；开口向上且另一端在 $1$ 之后由负转正，根必大于 $1$，画不出其他形态。

* **边界核验**

    * $m=1$ 单独讨论：代入得 $1-(3k+2)+2k+1=0$，约简后 $k=0$。
    * $k=0$ 时二次方程退化为 $m^2-2m+1=0$，即 $(m-1)^2=0$，只有重根 $m=1$，两条水平线合并成一条，只可能给出一个 $x$ 解，不合题意。
    * 因此 $k=0$ 排除，最终为开区间 $k>0$。
    * $m=0$ 的情形由分母不为 $0$ 直接排除，不参与讨论。
    * > **结论**：由图像判断交点个数只能给出充分性结论，等号附近的临界情形必须回代单独核验。
