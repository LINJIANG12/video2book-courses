## 空间直角坐标系与向量的坐标运算
> 对应块：BLK52 | 覆盖分集：P70下 | 块标题（分集名）：《69 向量 线性运算 空间直角坐标系 向量模》

把平面几何推进到三维空间，很多同学一听就发怵，总觉得自己空间想象能力不够用，脑子转不过弯。其实完全不用慌，空间直角坐标系的名字起得“很中国”——八个空间区域叫“卦限”，八卦的卦，听着挺亲切，也很形象。到了高等数学里，引入坐标系的终极目的根本不是考大家的立体透视画功，恰恰相反，是为了用代数运算把空间几何问题彻底降维。只要给向量安上了坐标，几何里那些绕来绕去的位置关系、平行判断、距离计算，全都可以变成小学生都会算的加减乘除。

### 空间直角坐标系与八个卦限

研究平面问题时，两条互相垂直的数轴把平面分成了四个象限。到了三维空间，我们在过空间原点 $O$ 的三条两两垂直的数轴——$x$ 轴（横轴）、$y$ 轴（纵轴）和 $z$ 轴（竖轴）——构建起空间直角坐标系。这三个坐标面（$xOy$ 面、$yOz$ 面、$zOx$ 面）就像切西瓜一样，把整个三维空间切成了八个部分，每一个部分就叫作一个**卦限**。

#### 八个卦限的分布规律

很多同学初学时总记不住这八个卦限是怎么排的，其实只要记住一句话：**以 $xOy$ 坐标面为界，上面四个按逆时针转，下面四个正对对应**。

```text
                  +z 轴 (竖轴)
                     ^
                     |
                     |  第Ⅱ卦限         第Ⅰ卦限
                     |  (-, +, +)      (+, +, +)
                     |       \             /
                     |        \           /
                     |         \         /
                     +----------\-------/-------------> +y 轴 (纵轴)
                    / \          \     /
                   /   \          \   /
                  /     \          \ /
                 /       \          +  原点 O
                /         \        /
               /           \      /
              /             \    /
             /          第Ⅲ卦限   第Ⅳ卦限
            v           (-, -, +) (+, -, +)
     +x 轴 (横轴)
   --------------------------------------------------
   [注] 位于 xOy 平面 (z > 0) 上方的为第 Ⅰ、Ⅱ、Ⅲ、Ⅳ 卦限（逆时针排列）；
        位于 xOy 平面 (z < 0) 下方的为第 Ⅴ、Ⅵ、Ⅶ、Ⅷ 卦限（分别在 Ⅰ、Ⅱ、Ⅲ、Ⅳ 正下方）。
```

上图展示了空间直角坐标系的右手系朝向以及位于上半平面的四个卦限分布，下半平面正对排布。具体规则如下：

- **上半空间（$z > 0$）**：直接看 $xOy$ 平面，从 $x$ 轴正半轴沿逆时针方向绕向 $y$ 轴正半轴，与平面直角坐标系的四个象限完全一致：
  - 第Ⅰ卦限：$x > 0, y > 0, z > 0$；
  - 第Ⅱ卦限：$x < 0, y > 0, z > 0$；
  - 第Ⅲ卦限：$x < 0, y < 0, z > 0$；
  - 第Ⅳ卦限：$x > 0, y < 0, z > 0$。
- **下半空间（$z < 0$）**：正好位于上半空间的正下方，编号也是一一对应的：
  - 第Ⅴ卦限：在第Ⅰ卦限正下方，$x > 0, y > 0, z < 0$；
  - 第Ⅵ卦限：在第Ⅱ卦限正下方，$x < 0, y > 0, z < 0$；
  - 第Ⅶ卦限：在第Ⅲ卦限正下方，$x < 0, y < 0, z < 0$；
  - 第Ⅷ卦限：在第Ⅳ卦限正下方，$x > 0, y < 0, z < 0$。

> **提示**：在考研和后续多元微积分做题时，卦限其实用得比较少，最常考、用得最多的绝大多数都是第一卦限（三个坐标分量全为正的区域）。大家只要掌握它的命名规则和分布顺规，不被名词唬住即可。

#### 特殊几何位置的坐标特征

空间中的点如果刚好落在了坐标面上或者坐标轴上，它的坐标分量会出现成批的“零”。这个规律极为简单，也最为关键：**缺哪个字母，哪个字母就是零**。

| 空间几何位置 | 满足的代数方程 | 坐标的一般形式 | 几何特征说明 |
| :--- | :--- | :--- | :--- |
| **$yOz$ 坐标面** | $x = 0$ | $(0, y, z)$ | 不含 $x$ 分量，左右不偏 |
| **$xOz$ 坐标面** | $y = 0$ | $(x, 0, z)$ | 不含 $y$ 分量，前后不偏 |
| **$xOy$ 坐标面** | $z = 0$ | $(x, y, 0)$ | 不含 $z$ 分量，即水平地面 |
| **$x$ 坐标轴** | $y = 0, z = 0$ | $(x, 0, 0)$ | 落在 $x$ 轴上，其余两维为零 |
| **$y$ 坐标轴** | $x = 0, z = 0$ | $(0, y, 0)$ | 落在 $y$ 轴上，其余两维为零 |
| **$z$ 坐标轴** | $x = 0, y = 0$ | $(0, 0, z)$ | 落在 $z$ 轴上，其余两维为零 |
| **坐标原点 $O$** | $x = 0, y = 0, z = 0$ | $(0, 0, 0)$ | 三个坐标轴的交点 |

### 向量的坐标分解与代数表示

有了空间直角坐标系后，空间里的任意一个向量就可以从几何箭头转变为一组代数数字。

#### 基本单位向量与长方体分解

在很多教科书里，这一段推导往往一笔带过，我们把它讲透。

我们在 $x$ 轴、$y$ 轴、$z$ 轴的正方向上，分别从原点引出长度为 $1$ 的单位向量，依次记作 $\boldsymbol{i}, \boldsymbol{j}, \boldsymbol{k}$：
- 沿 $x$ 轴正向的基本单位向量：$\boldsymbol{i} = (1, 0, 0)$；
- 沿 $y$ 轴正向的基本单位向量：$\boldsymbol{j} = (0, 1, 0)$；
- 沿 $z$ 轴正向的基本单位向量：$\boldsymbol{k} = (0, 0, 1)$。

这三个向量模长都为 $1$，彼此正交垂直，构成了三维空间的一组标准正交基底。

现在假设空间中有一点 $M(x, y, z)$，从原点 $O$ 到 $M$ 引出位置向量 $\vec{OM}$。过点 $M$ 分别向三个坐标面作垂线，就能在空间中撑起一个以原点 $O$ 和点 $M$ 为对角顶点的长方体。

```text
                  +z
                   ^          z*k
                   |          |
                   |          +------------ M(x, y, z)
                   |         /|           /|
                   |        / |          / |
                   |       /  |         /  |
                   k      /   |        /   |
                   |     /    |       /    |
                   |    /     +------/-----+ N
                   |   /     /      /     /
                   |  /     /      /     /
                   | /     /      /     /
                   +------/------/-----+-----> +y
                  O \    /      /     /
                     \  /      /     /
                      \i      /     /
                       \     /     /
                        v   /     /
                         \ /     /
                          +-----+ P (x*i)
                         /
                        v
                       +x
```

长方体中向量沿三个坐标轴方向分解的几何路径示意：从 $O$ 经 $P$ 到 $N$ 再到 $M$。

从原点 $O$ 走到顶点 $M$，按照向量的加法法则，完全可以看作三个折线向量的首尾相接：
1. 先从原点 $O$ 沿着 $x$ 轴走到点 $P$，这一段向量是 $\vec{OP} = x\boldsymbol{i}$；
2. 再从点 $P$ 平行于 $y$ 轴走到底面顶点 $N$，这一段向量是 $\vec{PN} = y\boldsymbol{j}$；
3. 最后从点 $N$ 垂直向上沿着平行于 $z$ 轴方向走到终点 $M$，这一段向量是 $\vec{NM} = z\boldsymbol{k}$。

这三个向量首尾相接直接相加，其合向量正好就是对角线向量 $\vec{OM}$：
$$
\vec{OM} = \vec{OP} + \vec{PN} + \vec{NM} = x\boldsymbol{i} + y\boldsymbol{j} + z\boldsymbol{k}
$$

> **定义**：表达式 $\vec{OM} = x\boldsymbol{i} + y\boldsymbol{j} + z\boldsymbol{k}$ 称为向量 $\vec{OM}$ 的**坐标分解式**。

#### 坐标形式的引入与“点 vs 向量”的本质辨析

每次写向量都要写 $\boldsymbol{i}, \boldsymbol{j}, \boldsymbol{k}$，头上还得戴小箭头，中间还要写加号，做题时代数运算极度繁琐。因此我们直接把三个基底前面的系数抽出来，记作有序数组：
$$
\vec{OM} = (x, y, z) \quad \text{或} \quad \boldsymbol{r} = (x, y, z)
$$
这就是向量的**坐标表示**。在后续所有的考研和期末计算中，我们基本通篇都用这种坐标形式。

> **易错点**：**必须分清空间中的“点”与“向量”**！
>
> 空间中有一个固定的几何点 $A(1, 1, 1)$，而从原点出发指向该点的位置向量记作 $\vec{OA} = (1, 1, 1)$。
> 它们的书写形式一模一样，都是三个数字 $(1, 1, 1)$，但物理与数学内涵截然不同：
> - **点**表示空间中的一个绝对“位置”，不能随意挪动；
> - **向量**具备大小与方向，是“自由向量”，可以任意平行移动。
> 
> 在做题列式时，脑子里一定要清楚当前处理的对象到底是一个静止的空间位置点，还是一个可以运算的自由向量。

### 向量坐标的线性运算与平行判定

把几何箭头换成三维坐标后，向量所有的几何运算都变成了三个分量的代数运算。

#### 加法、减法与数乘运算

设向量 $\boldsymbol{a} = (a_x, a_y, a_z)$，$\boldsymbol{b} = (b_x, b_y, b_z)$，$\lambda$ 为任意实数：
- **向量加法**：各坐标分量分别相加
  $$
  \boldsymbol{a} + \boldsymbol{b} = (a_x + b_x, \; a_y + b_y, \; a_z + b_z)
  $$
- **向量减法**：各坐标分量分别相减
  $$
  \boldsymbol{a} - \boldsymbol{b} = (a_x - b_x, \; a_y - b_y, \; a_z - b_z)
  $$
- **数乘向量**：实数乘入每一个分量
  $$
  \lambda \boldsymbol{a} = (\lambda a_x, \; \lambda a_y, \; \lambda a_z)
  $$

例如已知 $\boldsymbol{a} = (1, 2, 3)$，$\boldsymbol{b} = (4, -1, 6)$：
- $\boldsymbol{a} + \boldsymbol{b} = (1+4, \; 2+(-1), \; 3+6) = (5, 1, 9)$；
- $\boldsymbol{a} - \boldsymbol{b} = (1-4, \; 2-(-1), \; 3-6) = (-3, 3, -3)$；
- $5\boldsymbol{a} = (5 \times 1, \; 5 \times 2, \; 5 \times 3) = (5, 10, 15)$。

#### 向量平行的坐标充要条件与“分母为零”的本质

从几何上讲，两个非零向量 $\boldsymbol{a}$ 与 $\boldsymbol{b}$ 平行（记作 $\boldsymbol{a} \parallel \boldsymbol{b}$），充要条件是存在唯一的实数 $\lambda$，使得：
$$
\boldsymbol{b} = \lambda \boldsymbol{a}
$$
代入坐标分解式 $(b_x, b_y, b_z) = \lambda (a_x, a_y, a_z)$，即要求三个分量分别满足：
$$
\begin{cases}
b_x = \lambda a_x \\
b_y = \lambda a_y \\
b_z = \lambda a_z
\end{cases}
$$
当各个分量均不为零时，消去参数 $\lambda$，就得到了教科书上常见的比例表达式：
$$
\frac{b_x}{a_x} = \frac{b_y}{a_y} = \frac{b_z}{a_z}
$$
即：**两非零向量平行，其对应坐标成比例**。

> **易错点**：**坐标比例式中分母出现零到底合不合法？**
>
> 很多同学看到形如 $\frac{0}{0} = \frac{3}{1} = \frac{3}{1}$ 或者 $\frac{2}{1} = \frac{0}{0} = \frac{0}{0}$ 的式子，心里直打鼓：小学就学过“分母绝不能为零”，高数里难道是未定式洛必达法则求导？
> 
> **绝对不是洛必达法则！**
> 
> 在解析几何与向量代数中，比例式 $\frac{b_x}{a_x} = \frac{b_y}{a_y} = \frac{b_z}{a_z}$ 只是一种**简写记号**，它的数学本质是线性相关方程组 $b_x = \lambda a_x, b_y = \lambda a_y, b_z = \lambda a_z$。
> 这里的约定是：**如果某个分母为零，那么对应的分子也必须同时为零**。
> 例如向量 $\boldsymbol{a} = (1, 0, 0)$ 与 $\boldsymbol{b} = (2, 0, 0)$，它们都在 $x$ 轴上，显然平行（$\boldsymbol{b} = 2\boldsymbol{a}$），写成比例形式就是：
> $$
> \frac{2}{1} = \frac{0}{0} = \frac{0}{0}
> $$
> 这在向量坐标几何中完全成立、合理合法。
> 
> 但在实际做题时，最稳妥、最直观的办法不是去写容易引起心理障碍的带零分母比例式，而是直接观察两组坐标之间是否存在统一的整倍数因子 $\lambda$。一眼能看出倍数，平行的结论当场即可敲定。

#### 以向量为元的线性方程组解法

如果方程组中的未知数不是普通实数，而是向量，求解方法与初中代数中的消元法完全一致。

例如求解方程组：
$$
\begin{cases}
5\boldsymbol{x} - 3\boldsymbol{y} = \boldsymbol{a} \\
3\boldsymbol{x} - 2\boldsymbol{y} = \boldsymbol{b}
\end{cases}
$$
其中已知 $\boldsymbol{a} = (2, 1, 2)$，$\boldsymbol{b} = (1, 1, -2)$。

求解过程如下：
1. **代数消元**：观察未知向量系数，将第一个方程两边乘以 $2$，第二个方程两边乘以 $3$：
   $$
   \begin{cases}
   10\boldsymbol{x} - 6\boldsymbol{y} = 2\boldsymbol{a} \\
   9\boldsymbol{x} - 6\boldsymbol{y} = 3\boldsymbol{b}
   \end{cases}
   $$
   两式直接相减，消除 $\boldsymbol{y}$：
   $$
   \boldsymbol{x} = 2\boldsymbol{a} - 3\boldsymbol{b}
   $$
2. **计算 $\boldsymbol{x}$**：
   $$
   \boldsymbol{x} = 2(2, 1, 2) - 3(1, 1, -2) = (4, 2, 4) - (3, 3, -6) = (1, -1, 10)
   $$
3. **回代求解 $\boldsymbol{y}$**：
   由第二个原方程 $3\boldsymbol{x} - 2\boldsymbol{y} = \boldsymbol{b}$ 可得：
   $$
   2\boldsymbol{y} = 3\boldsymbol{x} - \boldsymbol{b} \implies \boldsymbol{y} = \frac{1}{2}(3\boldsymbol{x} - \boldsymbol{b})
   $$
   将 $\boldsymbol{x} = (1, -1, 10)$ 代入：
   $$
   3\boldsymbol{x} - \boldsymbol{b} = 3(1, -1, 10) - (1, 1, -2) = (3, -3, 30) - (1, 1, -2) = (2, -4, 32)
   $$
   乘以前面的系数 $\frac{1}{2}$：
   $$
   \boldsymbol{y} = \frac{1}{2}(2, -4, 32) = (1, -2, 16)
   $$

解得向量解为 $\boldsymbol{x} = (1, -1, 10)$，$\boldsymbol{y} = (1, -2, 16)$。

### 定比分点与两点间向量表示

在立体几何中，如何用坐标求线段上的分点、求两点构成的自由向量，全靠向量减法的几何规则。

#### 定比分点公式与中点公式推导

设空间中有两个已知点 $A(x_1, y_1, z_1)$ 和 $B(x_2, y_2, z_2)$，在直线 $AB$ 上求一点 $M(x, y, z)$，使得向量 $\vec{AM}$ 与向量 $\vec{MB}$ 满足比例关系：
$$
\vec{AM} = \lambda \vec{MB} \quad (\lambda 
eq -1)
$$

这里用到了向量减法的核心几何口诀：“**指向被减**”。

```text
                        M
                      /   \
                     /     \
         \vec{AM}   /       \   \vec{MB}
                   /         \
                  v           v
                 A ---------> B
                  ^          ^
                   \        /
           \vec{OA} \      / \vec{OB}
                     \    /
                      \  /
                       O (原点)
```

由图可知向量三角形中的减法对应关系：
- 向量 $\vec{AM}$ 从 $A$ 指向 $M$，终点是 $M$，根据“指向被减”，它等于以 $M$ 为终点的位置向量减去以 $A$ 为终点的位置向量：
  $$
  \vec{AM} = \vec{OM} - \vec{OA}
  $$
- 向量 $\vec{MB}$ 从 $M$ 指向 $B$，终点是 $B$：
  $$
  \vec{MB} = \vec{OB} - \vec{OM}
  $$

将两式代入已知条件 $\vec{AM} = \lambda \vec{MB}$：
$$
\vec{OM} - \vec{OA} = \lambda (\vec{OB} - \vec{OM})
$$
移项整理，将含有未知向量 $\vec{OM}$ 的项全部归拢到左边：
$$
\vec{OM} + \lambda \vec{OM} = \vec{OA} + \lambda \vec{OB} \implies (1 + \lambda)\vec{OM} = \vec{OA} + \lambda \vec{OB}
$$
因为 $\lambda 
eq -1$，两边同除以 $(1 + \lambda)$，得到点 $M$ 的位置向量表达式：
$$
\vec{OM} = \frac{1}{1 + \lambda}(\vec{OA} + \lambda \vec{OB})
$$
转化为坐标分量形式，即为**定比分点坐标公式**：
$$
x = \frac{x_1 + \lambda x_2}{1 + \lambda}, \quad y = \frac{y_1 + \lambda y_2}{1 + \lambda}, \quad z = \frac{z_1 + \lambda z_2}{1 + \lambda}
$$

> **结论**：**中点公式**是定比分点在 $\lambda = 1$ 时的特例。
> 当 $\vec{AM} = \vec{MB}$ 时，点 $M$ 即为线段 $AB$ 的正中点，其坐标直接为两端点坐标的算术平均值：
> $$
> x = \frac{x_1 + x_2}{2}, \quad y = \frac{y_1 + y_2}{2}, \quad z = \frac{z_1 + z_2}{2}
> $$

#### 两点间向量的求法与书写规范

已知起点 $A(x_1, y_1, z_1)$ 和终点 $B(x_2, y_2, z_2)$，求由 $A$ 指向 $B$ 的向量 $\vec{AB}$。

按照推导过程：
$$
\vec{AB} = \vec{OB} - \vec{OA} = (x_2, y_2, z_2) - (x_1, y_1, z_1) = (x_2 - x_1, \; y_2 - y_1, \; z_2 - z_1)
$$
牢记八字口诀：**终点坐标，减起点坐标**。
箭头指向谁，就用谁的坐标减去出发点的坐标。

> **易错点**：**点不能直接相减！**
>
> 比如 $A(1, 1, 1)$，$B(2, 3, 4)$，有的同学图省事，在卷面上直接写：
> $$
> \vec{AB} = B - A = (2, 3, 4) - (1, 1, 1) = (1, 2, 3)
> $$
> 这样写在严格的数学规范里是**不合规**的。因为空间中的“点”是几何位置，数学上没有定义过点与点之间的减法操作。真正发生相减的是点 $B$ 的位置向量 $\vec{OB}$ 与点 $A$ 的位置向量 $\vec{OA}$。
> 
> 为了保证卷面无懈可击，我们在正式解题时，直接在心中完成“终点减起点”的分量相减，把 $(2, 3, 4) - (1, 1, 1)$ 留在草稿纸上，答题纸上直接写出相减后的最终向量：
> $$
> \vec{AB} = (2-1, \; 3-1, \; 4-1) = (1, 2, 3)
> $$

### 向量的模与空间两点间距离

向量不仅有方向，还有大小。向量的大小在代数上叫作向量的**模**（即几何长度）。

#### 空间对角线与两次勾股定理

设空间向量 $\boldsymbol{r} = (x, y, z)$，要求它的模长 $|\boldsymbol{r}|$。我们在构建的长方体中连续应用两次勾股定理即可推导完成：

```text
               竖直高度 z
                   |
                   |       /| 对角线向量 r 的模长 |r|
                   |      / |
                   |     /  |
                   |    /   |
                   +   /    |
                   |  /     |
                   | /      |
                   +--------+
                  原点   底面对角线: \sqrt{x^2 + y^2}
```

1. 在 $xOy$ 水平底面内，横向边长为 $|x|$，纵向边长为 $|y|$，由底面直角三角形的勾股定理，底面对角线长度为：
   $$
   d_{\text{底}} = \sqrt{x^2 + y^2}
   $$
2. 在由底面对角线与竖直高 $z$ 构成的直角三角形内，空间对角线即为向量 $\boldsymbol{r}$ 的长度，再来一次勾股定理：
   $$
   |\boldsymbol{r}|^2 = d_{\text{底}}^2 + z^2 = (\sqrt{x^2 + y^2})^2 + z^2 = x^2 + y^2 + z^2
   $$
两端开平方，得到向量模长公式：
$$
|\boldsymbol{r}| = \sqrt{x^2 + y^2 + z^2}
$$

例如向量 $\boldsymbol{a} = (1, 1, 1)$，它的模为：
$$
|\boldsymbol{a}| = \sqrt{1^2 + 1^2 + 1^2} = \sqrt{3}
$$

#### 空间两点间距离公式与同向单位向量

根据两点构成向量的坐标法则，设 $A(x_1, y_1, z_1)$，$B(x_2, y_2, z_2)$，则向量 $\vec{AB} = (x_2 - x_1, y_2 - y_1, z_2 - z_1)$。
两点间的几何空间距离 $d(A, B)$，本质上就是向量 $\vec{AB}$ 的模长：
$$
d(A, B) = |\vec{AB}| = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2 + (z_2 - z_1)^2}
$$
这与高中所记的三维距离公式完全相同，但此刻它获得了清晰的向量几何支撑。

在很多物理与力学问题中，我们常常只需要保留向量的方向，而将其长度归一化为 $1$，这就是**单位向量**。
与非零向量 $\vec{AB}$ 同方向的单位向量记作 $\boldsymbol{e}$（或 $\vec{AB}^\circ$），其计算方法就是用原向量除以它自身的模长：
$$
\boldsymbol{e} = \frac{\vec{AB}}{|\vec{AB}|} = \frac{1}{|\vec{AB}|} (x_2 - x_1, \; y_2 - y_1, \; z_2 - z_1)
$$

#### 题目一：以向量为元的线性方程组

**【题干】**
已知向量 $\boldsymbol{a} = (2, 1, 2)$，$\boldsymbol{b} = (1, 1, -2)$，求解满足下列方程组的未知向量 $\boldsymbol{x}$ 和 $\boldsymbol{y}$：
$$
\begin{cases}
5\boldsymbol{x} - 3\boldsymbol{y} = \boldsymbol{a} \\
3\boldsymbol{x} - 2\boldsymbol{y} = \boldsymbol{b}
\end{cases}
$$

**【解析】**
利用代数加减消元法：
1. 方程 $(1) \times 2 - (2) \times 3$：
   $$
   (10\boldsymbol{x} - 6\boldsymbol{y}) - (9\boldsymbol{x} - 6\boldsymbol{y}) = 2\boldsymbol{a} - 3\boldsymbol{b} \implies \boldsymbol{x} = 2\boldsymbol{a} - 3\boldsymbol{b}
   $$
   代入坐标计算分量：
   $$
   \boldsymbol{x} = 2(2, 1, 2) - 3(1, 1, -2) = (4 - 3, \; 2 - 3, \; 4 - (-6)) = (1, -1, 10)
   $$
2. 由第二个方程得 $2\boldsymbol{y} = 3\boldsymbol{x} - \boldsymbol{b}$，故 $\boldsymbol{y} = \frac{1}{2}(3\boldsymbol{x} - \boldsymbol{b})$：
   $$
   3\boldsymbol{x} - \boldsymbol{b} = 3(1, -1, 10) - (1, 1, -2) = (3 - 1, \; -3 - 1, \; 30 - (-2)) = (2, -4, 32)
   $$
   $$
   \boldsymbol{y} = \frac{1}{2}(2, -4, 32) = (1, -2, 16)
   $$

**【答案】**
$\boldsymbol{x} = (1, -1, 10)$，$\boldsymbol{y} = (1, -2, 16)$。

#### 题目二：利用向量模证明等腰三角形

**【题干】**
已知空间三点分别为 $M_1(4, 3, 1)$，$M_2(7, 1, 2)$，$M_3(5, 2, 3)$，证明以这三点为顶点的三角形 $\triangle M_1M_2M_3$ 为等腰三角形。

**【解析】**
计算三角形三条边对应向量的模长：
1. 边 $M_1M_2$ 的长度：
   $$
   |\vec{M_1M_2}| = \sqrt{(7-4)^2 + (1-3)^2 + (2-1)^2} = \sqrt{3^2 + (-2)^2 + 1^2} = \sqrt{9 + 4 + 1} = \sqrt{14}
   $$
2. 边 $M_2M_3$ 的长度：
   $$
   |\vec{M_2M_3}| = \sqrt{(5-7)^2 + (2-1)^2 + (3-2)^2} = \sqrt{(-2)^2 + 1^2 + 1^2} = \sqrt{4 + 1 + 1} = \sqrt{6}
   $$
3. 边 $M_3M_1$ 的长度：
   $$
   |\vec{M_3M_1}| = \sqrt{(4-5)^2 + (3-2)^2 + (1-3)^2} = \sqrt{(-1)^2 + 1^2 + (-2)^2} = \sqrt{1 + 1 + 4} = \sqrt{6}
   $$

**【答案】**
因边长 $|\vec{M_2M_3}| = |\vec{M_3M_1}| = \sqrt{6}$，且不等于 $|\vec{M_1M_2}|$，故 $\triangle M_1M_2M_3$ 是以 $M_3$ 为顶点的等腰三角形。

#### 题目三：在坐标轴上求与两已知点等距离的点

**【题干】**
在 $z$ 轴上求一点 $M$，使得点 $M$ 到点 $A(-4, 1, 7)$ 与到点 $B(3, 5, -2)$ 的距离相等。

**【解析】**
1. 设点定位：由于点 $M$ 位于 $z$ 轴上，其横坐标与纵坐标均为零，可设点 $M$ 坐标为 $(0, 0, z)$。
2. 建立等距方程：由条件 $|MA| = |MB|$，即 $|MA|^2 = |MB|^2$：
   $$
   (-4 - 0)^2 + (1 - 0)^2 + (7 - z)^2 = (3 - 0)^2 + (5 - 0)^2 + (-2 - z)^2
   $$
3. 展开去括号：
   $$
   16 + 1 + (49 - 14z + z^2) = 9 + 25 + (4 + 4z + z^2)
   $$
   $$
   66 - 14z + z^2 = 38 + 4z + z^2
   $$
4. 两边消去二次项 $z^2$，合并同类项求解一元一次方程：
   $$
   66 - 38 = 4z + 14z \implies 18z = 28 \implies z = \frac{28}{18} = \frac{14}{9}
   $$

**【答案】**
所求点 $M$ 的坐标为 $\left(0, 0, \frac{14}{9}\right)$。

#### 题目四：求指定向量同方向的单位向量

**【题干】**
已知空间两点 $A(4, 0, 5)$，$B(7, 1, 3)$，求与向量 $\vec{AB}$ 同方向的单位向量。

**【解析】**
1. 求有向线段向量 $\vec{AB}$（终点坐标减起点坐标）：
   $$
   \vec{AB} = (7 - 4, \; 1 - 0, \; 3 - 5) = (3, 1, -2)
   $$
   （注意：千万不可用起点减终点，方向颠倒会导致整个物理方向相反）。
2. 求向量 $\vec{AB}$ 的模长：
   $$
   |\vec{AB}| = \sqrt{3^2 + 1^2 + (-2)^2} = \sqrt{9 + 1 + 4} = \sqrt{14}
   $$
3. 单位化：将向量乘以其模长的倒数：
   $$
   \boldsymbol{e} = \frac{\vec{AB}}{|\vec{AB}|} = \frac{1}{\sqrt{14}}(3, 1, -2) = \left(\frac{3}{\sqrt{14}}, \; \frac{1}{\sqrt{14}}, \; -\frac{2}{\sqrt{14}}\right)
   $$

**【答案】**
与 $\vec{AB}$ 同方向的单位向量为 $\left(\frac{3}{\sqrt{14}}, \; \frac{1}{\sqrt{14}}, \; -\frac{2}{\sqrt{14}}\right)$（或写作 $\frac{1}{\sqrt{14}}(3, 1, -2)$）。

### 方向角与方向余弦

#### 坐标轴的正方向与方向角取值范围

要描述一个空间向量的走向，最直接的办法就是看它和三条空间坐标轴之间的夹角。

假设有一个非零向量 $\boldsymbol{r} = (x, y, z)$，为了观察方便，我们把它的起点平移到空间直角坐标系的原点 $O$。这时候，向量 $\boldsymbol{r}$ 与三条坐标轴之间就自然形成了三个夹角：
- 与 $x$ 轴正向的夹角记为 $\alpha$；
- 与 $y$ 轴正向的夹角记为 $\beta$；
- 与 $z$ 轴正向的夹角记为 $\gamma$。

这三个角 $\alpha, \beta, \gamma$，就叫做非零向量 $\boldsymbol{r}$ 的**方向角**。

```text
               z 轴
                ^
                |      /  向量 r
                |     /
                |    /   角 gamma
                |   /---------
                |  /       角 beta
                | /                  
                +--------------------> y 轴
               / \ 
              /   \ 角 alpha
             /     \
            v       \
          x 轴
```
*图示说明：非零向量 $\boldsymbol{r}$ 的起点置于坐标原点时，与空间直角坐标系各正半轴形成的立体夹角。*

这里有一个非常关键的概念细节，很多同学在刚学的时候都会心生疑问：既然是向量和坐标轴的夹角，那坐标轴难道不是一条直线吗？平面几何里两条直线相交，夹角向来取锐角或者直角（范围是 $[0, \frac{\pi}{2}]$），为什么这里向量和轴的夹角可以是个钝角呢？

> **注意**：坐标轴绝不仅仅是一条几何直线，它是一条**带有指定正方向的有向轴**。

我们所说的向量与坐标轴的夹角，严格特指该向量与坐标轴的**正方向（正半轴）**之间的夹角。
如果向量朝向该轴的正方向倾斜，夹角就是锐角；如果向量背离该轴的正方向、朝负方向倾斜，它与正半轴形成的夹角自然就是一个钝角。

> **结论**：方向角 $\alpha, \beta, \gamma$ 的取值范围是闭区间 $[0, \pi]$（即 $0^\circ \sim 180^\circ$）：
> - 当向量与某坐标轴正向完全重合时，方向角取极小值 $0$；
> - 当向量与该坐标轴垂直时，方向角为 $\frac{\pi}{2}$；
> - 当向量与该坐标轴正向完全反向时，方向角取极大值 $\pi$。

#### 方向余弦推导与单位向量化

知道了方向角的范围，我们来看看怎么通过向量的坐标把这三个角求出来。

设向量 $\boldsymbol{r} = (x, y, z)$，它的模长（也就是终点到原点的距离）为：
$$|\boldsymbol{r}| = \sqrt{x^2 + y^2 + z^2}$$

从原点向 $x$ 轴正方向看，终点向 $x$ 轴作垂线，原点、终点和垂足构成了一个直角三角形。在这个三角形中，斜边长为向量模长 $|\boldsymbol{r}|$，邻边长就是坐标值 $x$。根据直角三角形中余弦函数的定义（邻边比斜边）：
$$\cos\alpha = \frac{x}{|\boldsymbol{r}|} = \frac{x}{\sqrt{x^2 + y^2 + z^2}}$$

同理，向 $y$ 轴与 $z$ 轴引垂线，立刻可以得到另外两个余弦值：
$$\cos\beta = \frac{y}{|\boldsymbol{r}|} = \frac{y}{\sqrt{x^2 + y^2 + z^2}}$$
$$\cos\gamma = \frac{z}{|\boldsymbol{r}|} = \frac{z}{\sqrt{x^2 + y^2 + z^2}}$$

这三个余弦值 $\cos\alpha, \cos\beta, \cos\gamma$，就称为向量 $\boldsymbol{r}$ 的**方向余弦**。

如果我们把这三个方向余弦作为一个整体，写成一个向量的形式，就会发现一个极其优美的代数特征：
$$(\cos\alpha, \cos\beta, \cos\gamma) = \left(\frac{x}{|\boldsymbol{r}|}, \frac{y}{|\boldsymbol{r}|}, \frac{z}{|\boldsymbol{r}|}\right) = \frac{1}{|\boldsymbol{r}|}(x, y, z) = \frac{\boldsymbol{r}}{|\boldsymbol{r}|} = \boldsymbol{e}_r$$

式中的 $\boldsymbol{e}_r$ 正是与向量 $\boldsymbol{r}$ 同方向的**单位向量**。

这个等式把方向余弦的本质揭示得一清二楚：**一个向量的方向余弦，本质上就是与它同方向的单位向量在各个坐标轴上的分量坐标**。

既然 $\boldsymbol{e}_r$ 是单位向量，那么它的模长必然恒等于 $1$，于是直接导出了方向余弦的基本恒等式：
$$\cos^2\alpha + \cos^2\beta + \cos^2\gamma = \left(\frac{x}{|\boldsymbol{r}|}\right)^2 + \left(\frac{y}{|\boldsymbol{r}|}\right)^2 + \left(\frac{z}{|\boldsymbol{r}|}\right)^2 = \frac{x^2 + y^2 + z^2}{|\boldsymbol{r}|^2} = 1$$

> **结论**：任意非零向量的方向余弦平方和恒等于 $1$：
> $$\cos^2\alpha + \cos^2\beta + \cos^2\gamma = 1$$

在实际做题求解时，步骤次序必须清晰：**先算向量坐标 $\to$ 再求向量模长 $\to$ 代入求出方向余弦 $\to$ 最后结合区间 $[0, \pi]$ 反解方向角**。特别注意，当方向余弦为负数时，反解出来的方向角必然是落在 $(\frac{\pi}{2}, \pi]$ 范围内的钝角。

### 向量在轴上的投影与分向量

#### 概念辨析：点的投影、分向量与投影数值

投影这部分内容在很多教材里写得非常抽象，又是引轴又是画平面，还造了一堆带上下标的符号，很多同学读得晕头转向。其实把这层窗户纸捅破，它的实质非常接地气。

先消除一个符号上的陌生感：教材里经常写“在 $u$ 轴上的投影”，什么是 $u$ 轴？我们平时只见过 $x$ 轴、$y$ 轴、$z$ 轴，根本没有 $u$ 轴。这里的 $u$ 轴纯粹是一个泛指，代表空间中任意一条给定了方向的有向直线（可以是 $x, y, z$ 轴，也可以是空间中任意射线）。

在这个前提下，必须严格分清三个层层递进、但性质截然不同的概念：

```text
               点 M
                *
               /|
     向量 r   / | 
             /  | 过点 M 作垂直于轴的平面
            /   | 
           v    v
       ----+----*------------> u 轴
           O   M' (垂足点)
           [----]
          向量 OM' (分向量)
          数值 lambda (投影值)
```
*图示说明：空间向量向有向轴引垂面形成的垂足点、分向量与投影标量。*

- **点的投影**：过空间一点 $M$ 向 $u$ 轴作垂直平面，交点 $M'$ 称为点 $M$ 在 $u$ 轴上的投影。注意，$M'$ 是一个**几何点**。
- **分向量**：若向量起点在 $O$、终点为 $M$，则轴上的有向线段 $\vec{OM'}$ 称为该向量在 $u$ 轴上的**分向量**。它是一个**几何向量**，具有大小和方向，可以表示为 $\vec{OM'} = \lambda \boldsymbol{e}$（其中 $\boldsymbol{e}$ 是 $u$ 轴正方向上的单位向量）。
- **向量在轴上的投影**：记作 $\mathrm{Prj}_u \boldsymbol{r}$。它是分向量前面的那个有向缩放系数 $\lambda$。**投影是一个具体的实数（标量），绝对不是向量！**

> **易错点**：投影是一个实数，不是向量！
> 当 $u$ 轴恰好就是坐标轴 $x$ 轴时，向量向 $x$ 轴投影所截得的数值 $\lambda$，其实就是该向量的第一维坐标 $x$。
> - 问：“向量在 $x$ 轴上的**投影**是多少？” $\to$ 答：是一个数（对应坐标值 $x$）；
> - 问：“向量在 $x$ 轴上的**分向量**是多少？” $\to$ 答：是一个向量，必须写成 $x\boldsymbol{i}$（漏掉基向量 $\boldsymbol{i}$ 就会被扣光分数）。

举个典型例子：对于向量 $\boldsymbol{a} = (1, 1, 1)$：
- 它在 $x$ 轴上的投影为数值 $1$；
- 它在 $x$ 轴上的分向量则是 $1 \cdot \boldsymbol{i} = \boldsymbol{i}$。

---

#### 投影的计算公式与几何性质

设向量 $\boldsymbol{a}$ 与有向轴 $u$ 的夹角为 $\varphi$（$\varphi \in [0, \pi]$），从直角三角形的边角关系可知，投影值的大小等于模长乘以夹角的余弦：
$$\mathrm{Prj}_u \boldsymbol{a} = |\boldsymbol{a}|\cos\varphi$$

当 $\varphi$ 是锐角时，$\cos\varphi > 0$，投影为正，说明分向量方向与轴正向一致；
当 $\varphi = \frac{\pi}{2}$ 时，$\cos\varphi = 0$，投影为 $0$，说明向量与轴垂直；
当 $\varphi$ 是钝角时，$\cos\varphi < 0$，投影为负，说明分向量方向与轴正向相反。

向量投影满足以下三条重要的代数运算性质：

```text
               向量 b
                ^
               / \
     向量 a   /   \ 向量 (a + b)
             /     \
            /       v
       ----+-------+-------+---> u 轴
           |<-Prj a|<-Prj b|
           |<--- Prj(a+b) ->|
```
*图示说明：向量加法的投影等于各向量投影的代数和。*

- **性质一（夹角公式）**：
  $$\mathrm{Prj}_u \boldsymbol{a} = |\boldsymbol{a}|\cos(\boldsymbol{a}, \hat{\boldsymbol{u}})$$
- **性质二（可加性）**：两个向量和在轴上的投影，等于它们各自在轴上投影的代数和：
  $$\mathrm{Prj}_u (\boldsymbol{a} + \boldsymbol{b}) = \mathrm{Prj}_u \boldsymbol{a} + \mathrm{Prj}_u \boldsymbol{b}$$
  从几何上看，根据三角形法则，向量 $\boldsymbol{a}$ 的终点接向量 $\boldsymbol{b}$ 的起点，两者在轴上的投影线段首尾相接，总长度恰好等于合向量 $\boldsymbol{a}+\boldsymbol{b}$ 的投影长度。
- **性质三（数乘齐次性）**：向量数乘后的投影，等于数乘该向量的原投影：
  $$\mathrm{Prj}_u (\lambda \boldsymbol{a}) = \lambda \mathrm{Prj}_u \boldsymbol{a}$$

### 两个向量的数量积（点乘）

#### 核心速记与代数运算法则

很多教材在讲数量积时，一上来就是一大串物理背景和抽象推导，很多同学看半天抓不住重点。其实在平时的考题和计算中，数量积的算法只需要记住一句话：**对应坐标相乘，然后全部加起来**。

设两个向量为 $\boldsymbol{a} = (a_x, a_y, a_z)$，$\boldsymbol{b} = (b_x, b_y, b_z)$。
它们做数量积，记号是在中间点一个实心点“$\cdot$”，所以数量积在口语中又叫**点乘**：
$$\boldsymbol{a} \cdot \boldsymbol{b} = a_x b_x + a_y b_y + a_z b_z$$

例如 $\boldsymbol{a} = (1, 1, 2)$，$\boldsymbol{b} = (0, 2, 3)$，做点乘就是：
$$\boldsymbol{a} \cdot \boldsymbol{b} = 1 \times 0 + 1 \times 2 + 2 \times 3 = 0 + 2 + 6 = 8$$

整个计算前后只要几秒钟。而且从名称上就能看破实质：**“数量积”，积出来的结果必然是一个纯数量（实数），绝不再带有任何方向**。

在此基础上，我们导出两个向量夹角的余弦计算公式。
设两个非零向量 $\boldsymbol{a}, \boldsymbol{b}$ 的夹角为 $\theta$（规定 $\theta \in [0, \pi]$），则：
$$\cos\theta = \frac{\boldsymbol{a} \cdot \boldsymbol{b}}{|\boldsymbol{a}||\boldsymbol{b}|} = \frac{a_x b_x + a_y b_y + a_z b_z}{\sqrt{a_x^2 + a_y^2 + a_z^2}\sqrt{b_x^2 + b_y^2 + b_z^2}}$$

> **注意**：观察分式 $\frac{\boldsymbol{a} \cdot \boldsymbol{b}}{|\boldsymbol{a}||\boldsymbol{b}|}$：分子上的“$\cdot$”是两个向量之间的点乘运算；分母上的乘号是两个实数模长之间的普通代数乘法，两者概念不能混淆。

#### 物理背景推导与几何性质

为什么数量积要定义成这副模样？它的物理源头是**恒力做功**。

在物理学中，如果一个物体在恒力 $\boldsymbol{F}$ 作用下产生位移 $\boldsymbol{s}$，当力与位移不在同一直线上、夹角为 $\theta$ 时，只有力在位移方向上的有效分量才会做功。因此功的计算公式为：
$$W = |\boldsymbol{F}||\boldsymbol{s}|\cos\theta$$

数学家从中提炼出了数量积的原始几何定义：
$$\boldsymbol{a} \cdot \boldsymbol{b} = |\boldsymbol{a}||\boldsymbol{b}|\cos\theta$$

结合上一小节讲过的投影公式 $|\boldsymbol{b}|\cos\theta = \mathrm{Prj}_{\boldsymbol{a}} \boldsymbol{b}$，数量积也可以写成几何投影的形式：
$$\boldsymbol{a} \cdot \boldsymbol{b} = |\boldsymbol{a}|\mathrm{Prj}_{\boldsymbol{a}} \boldsymbol{b} = |\boldsymbol{b}|\mathrm{Prj}_{\boldsymbol{b}} \boldsymbol{a}$$

由几何定义可以立即推导出以下核心性质与判别准则：

- **自身点乘求模长**：
  向量与自身做点乘，夹角 $\theta = 0$，$\cos 0 = 1$：
  $$\boldsymbol{a} \cdot \boldsymbol{a} = |\boldsymbol{a}||\boldsymbol{a}|\cos 0 = |\boldsymbol{a}|^2 \implies |\boldsymbol{a}| = \sqrt{\boldsymbol{a} \cdot \boldsymbol{a}}$$
  > **结论**：向量自身点乘等于其模长的平方。
- **垂直判定准则（极其重要）**：
  若非零向量 $\boldsymbol{a}, \boldsymbol{b}$ 互相垂直，则夹角 $\theta = \frac{\pi}{2}$，$\cos\frac{\pi}{2} = 0$，此时 $\boldsymbol{a} \cdot \boldsymbol{b} = 0$。
  反过来，如果两个非零向量的点乘为 $0$，因为模长均不为零，必有 $\cos\theta = 0$，从而夹角必为 $\frac{\pi}{2}$。
  > **结论**：两非零向量相互垂直的充分必要条件是它们的数量积等于零：
  > $$\boldsymbol{a} \perp \boldsymbol{b} \iff \boldsymbol{a} \cdot \boldsymbol{b} = 0 \iff a_x b_x + a_y b_y + a_z b_z = 0$$
  > （按数学约定，零向量方向任意，它与任何向量均平行也均垂直，且模长为 $0$，故上述充要条件对包含零向量的情形同样成立。）

数量积满足常规的代数运算法则：
- 交换律：$\boldsymbol{a} \cdot \boldsymbol{b} = \boldsymbol{b} \cdot \boldsymbol{a}$；
- 分配律：$(\boldsymbol{a} + \boldsymbol{b}) \cdot \boldsymbol{c} = \boldsymbol{a} \cdot \boldsymbol{c} + \boldsymbol{b} \cdot \boldsymbol{c}$；
- 数乘结合律：$(\lambda \boldsymbol{a}) \cdot \boldsymbol{b} = \lambda (\boldsymbol{a} \cdot \boldsymbol{b}) = \boldsymbol{a} \cdot (\lambda \boldsymbol{b})$。

有了这些运算律，我们就能严格证明坐标计算公式的成立。
把向量按基底展开为 $\boldsymbol{a} = a_x \boldsymbol{i} + a_y \boldsymbol{j} + a_z \boldsymbol{k}$，$\boldsymbol{b} = b_x \boldsymbol{i} + b_y \boldsymbol{j} + b_z \boldsymbol{k}$。
由于三条坐标轴互相正交且基向量为单位向量：
$$\boldsymbol{i} \cdot \boldsymbol{i} = \boldsymbol{j} \cdot \boldsymbol{j} = \boldsymbol{k} \cdot \boldsymbol{k} = 1$$
$$\boldsymbol{i} \cdot \boldsymbol{j} = \boldsymbol{j} \cdot \boldsymbol{k} = \boldsymbol{k} \cdot \boldsymbol{i} = 0$$
利用分配律把九项逐一展开，六个交叉正交项全变成 $0$，剩下的三个平方项系数全为 $1$，瞬间化简为 $a_x b_x + a_y b_y + a_z b_z$。

### 两个向量的向量积（叉乘）

#### 几何定义与右手螺旋法则

讲完数量积，再来看第二个积——向量积。
所谓“谜底就在谜面上”，数量积求出来是个数量（数），而**向量积求出来必须是一个向量**！
向量积在两向量之间用一个叉号“$\times$”连接，因此俗称**叉乘**。

既然乘出来的结果是一个向量，就必须从**方向**和**大小**两个要素来完整定义它：

```text
               向量 (a x b)
                    ^
                    | (垂直于 a 与 b 确定的平面)
                    |
                    |      / 向量 b
                    |     /
                    |    / 夹角 theta
                    |   /
                    +--+--------> 向量 a
```
*图示说明：向量积 $\boldsymbol{a} \times \boldsymbol{b}$ 的方向同时垂直于 $\boldsymbol{a}$ 和 $\boldsymbol{b}$，且符合右手螺旋法则。*

- **方向规定**：向量 $\boldsymbol{a} \times \boldsymbol{b}$ 与 $\boldsymbol{a}$、$\boldsymbol{b}$ 都垂直，并且 $\boldsymbol{a}, \boldsymbol{b}, \boldsymbol{a} \times \boldsymbol{b}$ 构成**右手系**。
  所谓右手系：伸出右手，四指从第一项 $\boldsymbol{a}$ 的方向通过小于 $\pi$ 的夹角转向第二项 $\boldsymbol{b}$ 的方向握拳，此时大拇指所竖直指向的方向，就是叉乘向量 $\boldsymbol{a} \times \boldsymbol{b}$ 的方向。
- **大小规定**：
  $$|\boldsymbol{a} \times \boldsymbol{b}| = |\boldsymbol{a}||\boldsymbol{b}|\sin\theta$$
  其中 $\theta$ 是 $\boldsymbol{a}$ 与 $\boldsymbol{b}$ 之间的夹角（$\theta \in [0, \pi]$）。

> **提示**：做几何题时，只要题目要求寻找一个**同时垂直于已知两向量 $\boldsymbol{a}$ 和 $\boldsymbol{b}$ 的新向量**，脑海中要瞬间反应出——直接求它们的叉乘 $\boldsymbol{a} \times \boldsymbol{b}$！

由向量积的定义直接引出两项极端情形的推论：
- **自叉乘为零向量**：向量与自己做叉乘，夹角 $\theta = 0$，$\sin 0 = 0$，故：
  $$\boldsymbol{a} \times \boldsymbol{a} = \boldsymbol{0}$$
  > **易错点**：这里的结果是**零向量 $\boldsymbol{0}$**，绝对不能随手写成纯数字数字 $0$！零向量是有方向的（方向任意），只是模长为 $0$。
- **平行判定准则**：
  若两非零向量 $\boldsymbol{a} \parallel \boldsymbol{b}$，则它们同向时 $\theta = 0$、反向时 $\theta = \pi$。在这两种情况下，都有 $\sin\theta = 0$。
  > **结论**：两非零向量平行的充分必要条件是它们的向量积为零向量：
  > $$\boldsymbol{a} \parallel \boldsymbol{b} \iff \boldsymbol{a} \times \boldsymbol{b} = \boldsymbol{0}$$

#### 行列式展开与两阶余子式速算法

在实际做题计算坐标时，向量积是通过一个三阶行列式来表达和求解的：
$$\boldsymbol{a} \times \boldsymbol{b} = \begin{vmatrix} \boldsymbol{i} & \boldsymbol{j} & \boldsymbol{k} \\ a_x & a_y & a_z \\ b_x & b_y & b_z \end{vmatrix}$$

> **注意**：行排列顺序绝对不能乱写！第一行永远固定是基向量 $\boldsymbol{i}, \boldsymbol{j}, \boldsymbol{k}$；第二行必须是前一个向量 $\boldsymbol{a}$ 的坐标；第三行必须是后一个向量 $\boldsymbol{b}$ 的坐标。行列式交换两行必须反号，顺序颠倒结果就会彻底变反！

计算这个三阶行列式，通常有两种方法：

- **对角线法则（折线法）**：主对角线三项相加，副对角线三项相减，一共六项。这种方法非常容易在正负号和下标上绕晕，极易抄错看错，在实战中并不推荐。
- **按第一行展开法（强烈推荐的考场提分技巧）**：
  根据行列式按行展开定理，行列式的值等于第一行的元素分别乘以其对应的代数余子式：
  $$\boldsymbol{a} \times \boldsymbol{b} = (-1)^{1+1} \begin{vmatrix} a_y & a_z \\ b_y & b_z \end{vmatrix} \boldsymbol{i} + (-1)^{1+2} \begin{vmatrix} a_x & a_z \\ b_x & b_z \end{vmatrix} \boldsymbol{j} + (-1)^{1+3} \begin{vmatrix} a_x & a_y \\ b_x & b_y \end{vmatrix} \boldsymbol{k}$$

仔细观察正负号系数：
- 第一个系数 $(-1)^{1+1} = +1$，正号；
- 第三个系数 $(-1)^{1+3} = +1$，正号；
- **中间第二个系数 $(-1)^{1+2} = -1$，必须取负号！**

实战中在草稿纸上的极速计算流程如下：
1. 算第一维：盖住第一行第一列，直接算剩下的二阶行列式 $\begin{vmatrix} a_y & a_z \\ b_y & b_z \end{vmatrix} = a_y b_z - a_z b_y$，算出多少就是多少；
2. 算第二维：盖住第一行第二列，算二阶行列式 $\begin{vmatrix} a_x & a_z \\ b_x & b_z \end{vmatrix} = a_x b_z - a_z b_x$，**算出来的结果必须立即添上一个负号**；
3. 算第三维：盖住第一行第三列，算二阶行列式 $\begin{vmatrix} a_x & a_y \\ b_x & b_y \end{vmatrix} = a_x b_y - a_y b_x$，算出多少就是多少。

> **易错点**：中间项一定要加负号！无数考生在考场上叉乘算错，百分之九十全是因为把中间项的负号给漏掉了。

另外，最终的运算结果强烈建议直接写成三维坐标形式 $(x, y, z)$，不要写成繁琐的带有 $\boldsymbol{i}, \boldsymbol{j}, \boldsymbol{k}$ 的形式，既省时间又不会因为漏画向量箭头而被扣格式分。

#### 运算律与行列式性质的深刻对应

向量积的代数运算规律非常特殊，它并不满足普通乘法的交换律。而这些看似古怪的运算法则，只要从线性代数中行列式的性质来审视，每一条都显得极其自然：

- **反交换律（交换变号）**：
  $$\boldsymbol{b} \times \boldsymbol{a} = -(\boldsymbol{a} \times \boldsymbol{b})$$
  **对应行列式性质**：在求 $\boldsymbol{b} \times \boldsymbol{a}$ 时，相当于把原来行列式的第二行与第三行互换了位置。根据行列式基本性质，**互换行列式的任意两行，行列式的值改变符号**。从几何上看，手心转向颠倒后大拇指指向完全相反，故必带负号。
- **分配律**：
  $$(\boldsymbol{a} + \boldsymbol{b}) \times \boldsymbol{c} = \boldsymbol{a} \times \boldsymbol{c} + \boldsymbol{b} \times \boldsymbol{c}$$
  **对应行列式性质**：若行列式的某一行元素都是两个数之和，则该行列式可以拆成两个行列式的和：
  $$\begin{vmatrix} \boldsymbol{i} & \boldsymbol{j} & \boldsymbol{k} \\ a_x + b_x & a_y + b_y & a_z + b_z \\ c_x & c_y & c_z \end{vmatrix} = \begin{vmatrix} \boldsymbol{i} & \boldsymbol{j} & \boldsymbol{k} \\ a_x & a_y & a_z \\ c_x & c_y & c_z \end{vmatrix} + \begin{vmatrix} \boldsymbol{i} & \boldsymbol{j} & \boldsymbol{k} \\ b_x & b_y & b_z \\ c_x & c_y & c_z \end{vmatrix}$$
- **数乘结合律**：
  $$(\lambda \boldsymbol{a}) \times \boldsymbol{b} = \boldsymbol{a} \times (\lambda \boldsymbol{b}) = \lambda (\boldsymbol{a} \times \boldsymbol{b})$$
  **对应行列式性质**：行列式某一行的所有元素若有公因子 $\lambda$，可以把公因子提到行列式符号外面。
- **自身叉乘与平行判定**：
  $\boldsymbol{a} \times \boldsymbol{a} = \boldsymbol{0}$ 对应行列式第二行与第三行完全相同，两行相同行列式必为 $0$；
  $\boldsymbol{a} \parallel \boldsymbol{b}$ 对应第二行与第三行成比例，两行成比例行列式必为 $0$。

把几何向量与行列式两套理论融会贯通后，这些规律根本不需要死记硬背。

#### 几何应用：平行四边形与三角形面积

向量积除了用来寻找空间公垂向量，最核心的几何用途就是快速求解空间图形的面积。

```text
               D +---------------+ C
                /               /
               /               /  h = |b| sin theta
   向量 b     /               /
             /   theta       /
            A +---------------+ B
                  向量 a
```
*图示说明：以向量 $\boldsymbol{a}$ 和 $\boldsymbol{b}$ 为邻边构成的平行四边形，高为 $|\boldsymbol{b}|\sin\theta$。*

假设以向量 $\boldsymbol{a}$ 和 $\boldsymbol{b}$ 为相邻两边构成一个空间平行四边形 $ABCD$：
- 取边长 $|\boldsymbol{a}|$ 为底；
- 作垂直于底的高 $h$，在直角三角形中可知 $h = |\boldsymbol{b}|\sin\theta$。

因此该平行四边形的面积为：
$$S_{\Box} = \text{底} \times \text{高} = |\boldsymbol{a}| \cdot (|\boldsymbol{b}|\sin\theta) = |\boldsymbol{a}||\boldsymbol{b}|\sin\theta$$

对照向量积的大小编码：$|\boldsymbol{a} \times \boldsymbol{b}| = |\boldsymbol{a}||\boldsymbol{b}|\sin\theta$。
两者完全一致！

> **结论**：以 $\boldsymbol{a}$ 和 $\boldsymbol{b}$ 为邻边的空间平行四边形面积，恰好等于这两向量之向量积的模长：
> $$S_{\Box} = |\boldsymbol{a} \times \boldsymbol{b}|$$
> （特别提醒：面积是模长，是一个正数值，绝对不能直接拿叉乘出来的向量当成面积！）

平行四边形沿对角线切开就是两个全等的三角形。因此，以 $\boldsymbol{a}$ 和 $\boldsymbol{b}$ 为邻边所围成的空间三角形面积，就是平行四边形面积的一半：
$$S_{\triangle} = \frac{1}{2} |\boldsymbol{a} \times \boldsymbol{b}|$$

如果已知空间三角形的三个顶点坐标 $A, B, C$，求该三角形的面积，标准化解题路径只有三步：
1. 计算有向线段向量：$\vec{AB} = B - A$，$\vec{AC} = C - A$（终点坐标减起点坐标）；
2. 计算向量积：先列三阶行列式，求出 $\vec{AB} \times \vec{AC}$ 的三维坐标；
3. 求模取半：$S_{\triangle ABC} = \frac{1}{2}\sqrt{x^2 + y^2 + z^2}$。

这种方法完全跳过了在三维空间中作高、求夹角的几何麻烦，纯粹依靠代数坐标一套带走。

### 数量积与向量积的综合辨析

为了让大家在面对具体题目时能够准确选型、绝不混淆，我们把数量积与向量积的全部特征梳理成如下对比表：

| 辨析维度 | 数量积（点乘 $\boldsymbol{a} \cdot \boldsymbol{b}$） | 向量积（叉乘 $\boldsymbol{a} \times \boldsymbol{b}$） |
| :--- | :--- | :--- |
| **运算符号** | 实心圆点“$\cdot$” | 叉号“$\times$” |
| **运算结果性质** | **纯实数（标量）**，无方向 | **空间向量**，兼具大小与方向 |
| **几何大小定义** | $|\boldsymbol{a}||\boldsymbol{b}|\cos\theta$ | 模长为 $|\boldsymbol{a}||\boldsymbol{b}|\sin\theta$ |
| **方向规定** | 无方向 | 同时垂直于 $\boldsymbol{a}$ 与 $\boldsymbol{b}$，服从右手系 |
| **坐标计算方法** | 对应坐标相乘求和：$a_x b_x + a_y b_y + a_z b_z$ | 三阶行列式展开：$\begin{vmatrix} \boldsymbol{i} & \boldsymbol{j} & \boldsymbol{k} \\ a_x & a_y & a_z \\ b_x & b_y & b_z \end{vmatrix}$ |
| **交换律表现** | 满足常规交换律：$\boldsymbol{a} \cdot \boldsymbol{b} = \boldsymbol{b} \cdot \boldsymbol{a}$ | 反交换律（变号）：$\boldsymbol{b} \times \boldsymbol{a} = -(\boldsymbol{a} \times \boldsymbol{b})$ |
| **自乘结果** | $\boldsymbol{a} \cdot \boldsymbol{a} = |\boldsymbol{a}|^2$（模长平方） | $\boldsymbol{a} \times \boldsymbol{a} = \boldsymbol{0}$（**零向量**） |
| **位置关系判定** | **垂直判定**：$\boldsymbol{a} \perp \boldsymbol{b} \iff \boldsymbol{a} \cdot \boldsymbol{b} = 0$ | **平行判定**：$\boldsymbol{a} \parallel \boldsymbol{b} \iff \boldsymbol{a} \times \boldsymbol{b} = \boldsymbol{0}$ |
| **典型应用场景** | 算夹角余弦、判断垂直、求做功、求轴投影 | 找公垂法向量、算平行四边形/三角形面积 |

### 本讲提到的题目

#### 题目一：求两点间向量的模、方向余弦与方向角

**题干**：
已知空间两点 $M_1(2, 2, \sqrt{2})$ 与 $M_2(1, 3, 0)$。试求以 $M_1$ 为起点、$M_2$ 为终点的向量 $\vec{M_1M_2}$ 的坐标、模长、方向余弦及各个方向角。

**解析与解答**：
1. **求向量坐标**：
   空间向量由终点坐标减去起点坐标构成：
   $$\vec{M_1M_2} = (1 - 2, 3 - 2, 0 - \sqrt{2}) = (-1, 1, -\sqrt{2})$$
2. **求向量的模长**：
   $$|\vec{M_1M_2}| = \sqrt{(-1)^2 + 1^2 + (-\sqrt{2})^2} = \sqrt{1 + 1 + 2} = \sqrt{4} = 2$$
3. **求方向余弦**：
   各分量分别除以模长：
   $$\cos\alpha = \frac{-1}{2} = -\frac{1}{2}$$
   $$\cos\beta = \frac{1}{2}$$
   $$\cos\gamma = \frac{-\sqrt{2}}{2} = -\frac{\sqrt{2}}{2}$$
   检验平方和：$(-\frac{1}{2})^2 + (\frac{1}{2})^2 + (-\frac{\sqrt{2}}{2})^2 = \frac{1}{4} + \frac{1}{4} + \frac{2}{4} = 1$，计算完全正确。
4. **求方向角**：
   方向角取值范围为 $[0, \pi]$：
   - 因为 $\cos\alpha = -\frac{1}{2} < 0$，$\alpha$ 为钝角，解得 $\alpha = \frac{2\pi}{3}$（即 $120^\circ$）；
   - 因为 $\cos\beta = \frac{1}{2} > 0$，$\beta$ 为锐角，解得 $\beta = \frac{\pi}{3}$（即 $60^\circ$）；
   - 因为 $\cos\gamma = -\frac{\sqrt{2}}{2} < 0$，$\gamma$ 为钝角，解得 $\gamma = \frac{3\pi}{4}$（即 $135^\circ$）。

#### 题目二：基础向量积行列式展开运算

**题干**：
已知向量 $\boldsymbol{a} = (1, 1, 2)$，$\boldsymbol{b} = (0, 2, -1)$。试求向量积 $\boldsymbol{a} \times \boldsymbol{b}$。

**解析与解答**：
构造三阶行列式，将 $\boldsymbol{a}$ 填入第二行，$\boldsymbol{b}$ 填入第三行：
$$\boldsymbol{a} \times \boldsymbol{b} = \begin{vmatrix} \boldsymbol{i} & \boldsymbol{j} & \boldsymbol{k} \\ 1 & 1 & 2 \\ 0 & 2 & -1 \end{vmatrix}$$

采用第一行余子式展开速算法：
- **第一维（$\boldsymbol{i}$ 分量）**：
  去掉第一行第一列，二阶行列式为：
  $$\begin{vmatrix} 1 & 2 \\ 2 & -1 \end{vmatrix} = 1 \times (-1) - 2 \times 2 = -1 - 4 = -5$$
- **第二维（$\boldsymbol{j}$ 分量，必须取负值）**：
  去掉第一行第二列，二阶行列式为：
  $$\begin{vmatrix} 1 & 2 \\ 0 & -1 \end{vmatrix} = 1 \times (-1) - 2 \times 0 = -1$$
  取负号后为：$-(-1) = 1$；
- **第三维（$\boldsymbol{k}$ 分量）**：
  去掉第一行第三列，二阶行列式为：
  $$\begin{vmatrix} 1 & 1 \\ 0 & 2 \end{vmatrix} = 1 \times 2 - 1 \times 0 = 2$$

最终求得向量积坐标为：
$$\boldsymbol{a} \times \boldsymbol{b} = (-5, 1, 2)$$

#### 题目三：含负分量向量的叉乘实战

**题干**：
已知向量 $\boldsymbol{a} = (2, 1, -1)$，$\boldsymbol{b} = (1, -1, 2)$。试求向量积 $\boldsymbol{a} \times \boldsymbol{b}$。

**解析与解答**：
列出三阶行列式：
$$\boldsymbol{a} \times \boldsymbol{b} = \begin{vmatrix} \boldsymbol{i} & \boldsymbol{j} & \boldsymbol{k} \\ 2 & 1 & -1 \\ 1 & -1 & 2 \end{vmatrix}$$

在草稿纸上分步提取二阶行列式计算各维数值：
- **第一维**：划去第一行第一列：
  $$\begin{vmatrix} 1 & -1 \\ -1 & 2 \end{vmatrix} = 1 \times 2 - (-1) \times (-1) = 2 - 1 = 1$$
- **第二维（注意带负号）**：划去第一行第二列：
  $$\begin{vmatrix} 2 & -1 \\ 1 & 2 \end{vmatrix} = 2 \times 2 - (-1) \times 1 = 4 - (-1) = 5$$
  牢记中间项反号规则，取负值后得到：$-5$；
- **第三维**：划去第一行第三列：
  $$\begin{vmatrix} 2 & 1 \\ 1 & -1 \end{vmatrix} = 2 \times (-1) - 1 \times 1 = -2 - 1 = -3$$

整理得结果：
$$\boldsymbol{a} \times \boldsymbol{b} = (1, -5, -3)$$

#### 题目四：求解两向量构成的空间平行四边形面积

**题干**：
已知空间两向量 $\boldsymbol{a} = (1, 1, 2)$ 与 $\boldsymbol{b} = (0, 3, 0)$。试求以 $\boldsymbol{a}, \boldsymbol{b}$ 为相邻边构成的空间平行四边形的面积。

**解析与解答**：
1. **求两向量的向量积**：
   $$\boldsymbol{a} \times \boldsymbol{b} = \begin{vmatrix} \boldsymbol{i} & \boldsymbol{j} & \boldsymbol{k} \\ 1 & 1 & 2 \\ 0 & 3 & 0 \end{vmatrix}$$
   - 第一维：$\begin{vmatrix} 1 & 2 \\ 3 & 0 \end{vmatrix} = 1 \times 0 - 2 \times 3 = -6$；
   - 第二维：$- \begin{vmatrix} 1 & 2 \\ 0 & 0 \end{vmatrix} = -(0 - 0) = 0$；
   - 第三维：$\begin{vmatrix} 1 & 1 \\ 0 & 3 \end{vmatrix} = 1 \times 3 - 1 \times 0 = 3$；
   得到叉乘向量：$\boldsymbol{a} \times \boldsymbol{b} = (-6, 0, 3)$。
2. **计算向量积的模长得到面积**：
   $$S_{\Box} = |\boldsymbol{a} \times \boldsymbol{b}| = \sqrt{(-6)^2 + 0^2 + 3^2} = \sqrt{36 + 9} = \sqrt{45} = 3\sqrt{5}$$
   故该平行四边形的面积为 $3\sqrt{5}$。

#### 题目五：求解空间三点围成的三角形面积

**题干**：
已知空间直角坐标系中三点坐标为 $A(1, 2, 3), B(3, 4, 5), C(2, 4, 7)$。试求三角形 $\triangle ABC$ 的面积。

**解析与解答**：
1. **构造以 $A$ 为共同起点的两条边向量**：
   $$\vec{AB} = (3 - 1, 4 - 2, 5 - 3) = (2, 2, 2)$$
   $$\vec{AC} = (2 - 1, 4 - 2, 7 - 3) = (1, 2, 4)$$
2. **计算两边向量的向量积 $\vec{AB} \times \vec{AC}$**：
   $$\vec{AB} \times \vec{AC} = \begin{vmatrix} \boldsymbol{i} & \boldsymbol{j} & \boldsymbol{k} \\ 2 & 2 & 2 \\ 1 & 2 & 4 \end{vmatrix}$$
   - 第一维：$\begin{vmatrix} 2 & 2 \\ 2 & 4 \end{vmatrix} = 2 \times 4 - 2 \times 2 = 8 - 4 = 4$；
   - 第二维（中间取负）：$- \begin{vmatrix} 2 & 2 \\ 1 & 4 \end{vmatrix} = -(2 \times 4 - 2 \times 1) = -(8 - 2) = -6$；
   - 第三维：$\begin{vmatrix} 2 & 2 \\ 1 & 2 \end{vmatrix} = 2 \times 2 - 2 \times 1 = 4 - 2 = 2$；
   得到向量积坐标：$\vec{AB} \times \vec{AC} = (4, -6, 2)$。
3. **计算三角形面积**：
   $$S_{\triangle ABC} = \frac{1}{2} |\vec{AB} \times \vec{AC}| = \frac{1}{2} \sqrt{4^2 + (-6)^2 + 2^2} = \frac{1}{2} \sqrt{16 + 36 + 4} = \frac{1}{2} \sqrt{56}$$
   化简根式：$\sqrt{56} = \sqrt{4 \times 14} = 2\sqrt{14}$。
   代入得：
   $$S_{\triangle ABC} = \frac{1}{2} \times 2\sqrt{14} = \sqrt{14}$$
   故三角形 $\triangle ABC$ 的面积为 $\sqrt{14}$。

## 空间曲面、空间曲线与平面方程精读讲义
> 对应块：BLK54 | 覆盖分集：P72上 | 块标题（分集名）：《71 曲面方程 平面方程 直线方程》

在解析几何与空间多元微积分的体系中，我们终于正式迈入了三维空间的大门。高等数学在这一节的研究核心是空间里的几何体与其代数方程之间的对应关系，而最基本、最重要、计算考查最频繁的基石就是**平面与直线**。

这一讲我们先建立对三维空间中“曲面”与“曲线”的宏观认知，随后把全部火力聚焦在最基础也是最重要的空间曲面——**平面**上，彻底攻克平面的点法式、一般式、特殊位置分布、截距式、平面夹角以及空间点面距离。

### 空间曲面与空间曲线的基本认识

在正式求解具体方程前，我们首先要在脑海中建立起空间几何形体与代数方程的对应直觉。

#### 空间曲面的代数表达

在三维直角坐标系中，曲面是一个二维几何对象。在代数上，我们用一个包含三个变量的三元方程来刻画它：

$$F(x, y, z) = 0$$

或者在很多显式函数场合，把某一个坐标（通常是 $z$）表示为另外两个坐标的二元函数：

$$z = f(x, y)$$

满足该方程的所有点 $(x, y, z)$ 汇聚在空间中，就构成了空间曲面。

这里很多初学者常有一个思维定势：“曲面，那必须得是弯弯曲曲的吧？”

并不是。我随手拿起一本高数课本，课本的封面是一个平整的面，那这个平面是不是曲面？当然是！平面属于特殊的曲面——曲率为零的曲面。我们在本章重点剖析的平面，正是空间曲面家族中最平整、最基础的成员。

#### 空间曲线的代数表达

如果维度继续降低，空间中的一条线（空间曲线）该如何用代数方程刻画？

如果退回平面二维直角坐标系，一个方程 $y = f(x)$ 或 $F(x, y) = 0$ 就能表示一条曲线。但到了三维空间，一个三元方程代表的是一张曲面，而不是一条线。若想在三维空间中钉死一条曲线，必须让**两个曲面相交**。

```text
       曲面 F(x, y, z) = 0
             \      /
              \    /
  -------------+--+-------------
              /    \
             /      \
       曲面 G(x, y, z) = 0
            ====交线====
          (空间曲线 C)
```
*图解说明：三维空间中的一条线不能由单一方程描述，而是两个空间曲面相互交截后的交线。*

好比翻开书本，两个相交的书页（两个平面）夹出来的那条书脊缝，就是一条笔直的线。因此，在代数上表示空间曲线，必须将两个曲面方程联立为一个方程组：

$$\begin{cases} F(x, y, z) = 0 \\ G(x, y, z) = 0 \end{cases}$$

同理，直线是不是曲线？直线当然是特殊的曲线。当上述方程组中的两个曲面都是平面时，两面相交得到的交线就是空间直线。这就是空间曲线与空间曲面的基本对应关系。

### 平面的点法式方程与一般式规范

平面在空间中千姿百态，我们如何用最精炼的代数语言把它唯一确定下来？

#### 点法式的几何推导

确定一个平面最稳固的几何要素，是一个定点加上平面的倾斜姿态。而刻画平面姿态最好的工具，就是与该平面垂直的向量——**法向量**。

> **定义**：垂直于某一平面的非零向量，称为该平面的**法向量**，通常记作 $\boldsymbol{n} = (A, B, C)$。

我们需要明确法向量的一个物理直觉：法向量是唯一的吗？绝不唯一。拿书本平面做参考，垂直于书面向上的向量是法向量，垂直于书面向下的向量也是法向量；长一点、短一点、乘以任意非零常数，方向朝上朝下，全都是该平面的法向量。做题时只要挑最简便、分量最小的一组非零分量即可。

```text
               n = (A, B, C) (法向量)
               ^
               |
           +---|--------------------+
          /    |          P(x,y,z) /
         /     +--------->        /
        /    P0(x0,y0,z0)        /
       +------------------------+  平面 Π
```
*图解说明：平面的法向量 $\boldsymbol{n}$ 垂直于平面内以定点 $P_0$ 为起点的任意向量 $\vec{P_0 P}$。*

现在我们在空间中推导平面的方程：
1. 已知平面经过定点 $P_0(x_0, y_0, z_0)$，法向量为 $\boldsymbol{n} = (A, B, C)$；
2. 设 $P(x, y, z)$ 为该平面内的任意一点，连接 $P_0$ 与 $P$，构成平面上的向量：
   $$\vec{P_0 P} = (x - x_0, y - y_0, z - z_0)$$
3. 既然法向量 $\boldsymbol{n}$ 垂直于整个平面，那么它必然垂直于平面内的任何一个向量，自然垂直于 $\vec{P_0 P}$；
4. 两个向量垂直，它们的数量积（点乘）必然为零：
   $$\boldsymbol{n} \cdot \vec{P_0 P} = 0$$
5. 展开向量坐标对应相乘求和，即得到经典的**点法式方程**：
   $$A(x - x_0) + B(y - y_0) + C(z - z_0) = 0$$

点法式听起来像极了“法式面包”，但它是整个空间解析几何里实用性最强、调用频率最高的工具。做题时只要抓到“一个点”和“一个法向量”，点法式直接套入即可成型。

#### 化简要求与一般式转换

在解题实践中，写出点法式绝不能算完工，必须就地展开合并同类项：

$$A x + B y + C z - (A x_0 + B y_0 + C z_0) = 0$$

将常数项整体记作 $D = -(A x_0 + B y_0 + C z_0)$，就得到了**平面的一般式方程**：

$$A x + B y + C z + D = 0$$

在最终落笔书写一般式时，有两项重要的规范化习惯：
1. **右侧必须归零**：将所有变量项与常数全部移到等号左侧，右侧整理为 $0$。
2. **首项系数化正**：如果化简后 $x$ 的系数算出来是负数（例如 $-x - 2y + 3z - 5 = 0$），习惯上全式同乘 $-1$，改写为 $x + 2y - 3z + 5 = 0$。至于 $x$ 的系数是不是非得化成 $1$，没有硬性规定，是 $3$ 就保留 $3$，无需强行除成分数。

#### 从一般式反读法向量

一般式与法向量之间存在直接的透视关系：在一般式 $A x + B y + C z + D = 0$ 中，$x, y, z$ 的系数组成的有序数组 $(A, B, C)$，正是该平面的一个法向量：

$$\boldsymbol{n} = (A, B, C)$$

常数项 $D$ 的大小仅仅决定了平面的空间平移位置，对平面的法向量方向没有任何干扰。

> **提示**：看到一般式方程，法向量能立刻读出；但若要找平面经过的点，一般式并没有直观给出，此时可使用特值法，令其中两个变量为 $0$，解出第三个变量对应的坐标即可。

### 特殊位置平面与空间投影形态

一般式方程 $A x + B y + C z + D = 0$ 中，系数 $A, B, C$ 绝不能同时为零（即 $A^2 + B^2 + C^2 
eq 0$）。若它们全为零，式子退化为 $D=0$，在几何上没有任何曲面意义。

但若其中某一个或两个参数为零，平面便会处于与坐标轴、坐标面平行的特殊优美姿态。

```text
一般方程参数特征       几何空间形态                法向量特征
------------------------------------------------------------------------
D = 0                 过坐标原点 (0, 0, 0)        n = (A, B, C)
A = 0 (缺 x 项)       平行于 x 轴                 n = (0, B, C) ⊥ x 轴
B = 0 (缺 y 项)       平行于 y 轴                 n = (A, 0, C) ⊥ y 轴
C = 0 (缺 z 项)       平行于 z 轴                 n = (A, B, 0) ⊥ z 轴
A = B = 0 (缺 x,y 项) 平行于 xOy 坐标面           n = (0, 0, C) ∥ z 轴
A = C = 0 (缺 x,z 项) 平行于 xOz 坐标面           n = (0, B, 0) ∥ y 轴
B = C = 0 (缺 y,z 项) 平行于 yOz 坐标面           n = (A, 0, 0) ∥ x 轴
```

#### 缺常数项与过原点平面

当 $D = 0$ 时，方程退化为：

$$A x + B y + C z = 0$$

显然，将坐标原点 $(0, 0, 0)$ 代入方程左边恒成立。因此，$D=0$ 充要对应着**经过坐标原点的平面**。

#### 缺一个一次项与平行于坐标轴的平面

若方程中缺少某一个坐标变量（例如 $A = 0$），方程化为：

$$B y + C z + D = 0$$

此时法向量为 $\boldsymbol{n} = (0, B, C)$。计算它与 $x$ 轴正方向的基向量 $\boldsymbol{i} = (1, 0, 0)$ 的点积：

$$\boldsymbol{n} \cdot \boldsymbol{i} = 0 \times 1 + B \times 0 + C \times 0 = 0$$

法向量与 $x$ 轴垂直，由于法向量垂直于整个平面，这意味着**平面本身必然平行于 $x$ 轴**。若在此基础上同时满足 $D=0$（即 $B y + C z = 0$），则该平面直接**包含（经过）$x$ 轴**。

如何建立空间几何直观？以 $y + z = 1$ 为例：
1. 首先在 $yOz$ 坐标面上画出二维直线 $y + z = 1$；
2. 由于方程中完全没有 $x$ 的限制，无论 $x$ 取 $1$、$100$ 还是 $-50$，$y$ 与 $z$ 只要满足 $y + z = 1$ 即可；
3. 将 $yOz$ 坐标面上的这条直线沿着平行于 $x$ 轴的方向左右无限拉伸拉扯，在空间中扫出来的一张倾斜平面，就是 $y + z = 1$。

同理，$A x + C z + D = 0$ 缺少 $y$，平面平行于 $y$ 轴；$A x + B y + D = 0$ 缺少 $z$，平面平行于 $z$ 轴。例如 $x - y = 0$ 即 $y = x$，就是在 $xOy$ 面上的角平分线沿 $z$ 轴上下拉伸所形成的纵向平面。

#### 缺两个一次项与平行于坐标面的平面

若方程中同时缺少两个变量（例如 $A = 0$ 且 $B = 0$），方程仅剩：

$$C z + D = 0 \implies z = -\frac{D}{C}$$

记常数 $c = -D/C$，方程即 $z = c$。
此时法向量为 $\boldsymbol{n} = (0, 0, C)$，方向与 $z$ 轴完全重合或反向。

几何直观非常直接：无论 $x$ 和 $y$ 在平面上怎么游走，$z$ 坐标永远锁死在标高 $c$ 上。这相当于拿一把水平的刀，在高度 $z=c$ 处平行于地面切了一刀。因此：
- $z = c$ 表示**平行于 $xOy$ 坐标面**的平面；当 $c=0$ 时，即为 $xOy$ 坐标面本身；
- $x = a$ 表示**平行于 $yOz$ 坐标面**的平面；当 $a=0$ 时，即为 $yOz$ 坐标面本身；
- $y = b$ 表示**平行于 $zOx$ 坐标面**的平面；当 $b=0$ 时，即为 $zOx$ 坐标面本身。

### 截距式方程及其适用边界

除了点法式与一般式，平面还有一种形式对称、几何特征一目了然的表达方式——截距式。

#### 截距式的代数结构

如果已知一个平面与空间三条坐标轴均有交点，设在 $x$ 轴上的截距为 $a$（交点 $(a, 0, 0)$），在 $y$ 轴上的截距为 $b$（交点 $(0, b, 0)$），在 $z$ 轴上的截距为 $c$（交点 $(0, 0, c)$），且 $a, b, c 
eq 0$。

```text
               z
               ^
               |  (0, 0, c)
               +
              / \
             /   \
            /     \
           /       \
 (0, b, 0)+---------+ (a, 0, 0)
         /           \
        /             \
       +---------------> y
      /
     v x
```
*图解说明：平面截三根坐标轴于三点，围出空间三角倾斜面，方程即由三轴截距联合决定。*

满足条件的平面方程可直接写为：

$$\frac{x}{a} + \frac{y}{b} + \frac{z}{c} = 1$$

将三点代入检验：
- 代入 $(a, 0, 0)$：$\frac{a}{a} + 0 + 0 = 1$，成立；
- 代入 $(0, b, 0)$：$0 + \frac{b}{b} + 0 = 1$，成立；
- 代入 $(0, 0, c)$：$0 + 0 + \frac{c}{c} = 1$，成立。

因此，只要题目直接给出了平面在三根坐标轴上的截距或交点坐标，无需联立求法向量，直接套入截距式即可出结果。

#### 截距式的应用禁区

> **易错点**：截距式中的分母 $a, b, c$ 绝对不能为零。

如果一个平面恰好经过坐标原点 $(0, 0, 0)$，它在三条轴上的截距均为 $0$。分母不能为零，这意味着**经过原点的平面无法用截距式表示**。同理，若平面与某一条坐标轴平行，它与该轴没有有限焦点，截距不存在，也无法使用完整的截距式。做综合题时，截距式使用频率相对较低，掌握其形式与前提即可。

### 两平面的夹角计算与位置关系判定

三维空间中两平面的相对姿态，完全映射为它们各自法向量之间的空间姿态。

#### 两平面的夹角定义与余弦公式

两张平面相交时，空间中会形成四个两两互补或相等的二面角。高数中对两平面的夹角有明确约定：

> **定义**：两平面的夹角 $\theta$ 规定取为**锐角或直角**，即范围严格限制在：
> $$\theta \in \left[0, \frac{\pi}{2}\right]$$

平面的姿态由法向量决定。设平面 $\Pi_1$ 的法向量为 $\boldsymbol{n}_1 = (A_1, B_1, C_1)$，平面 $\Pi_2$ 的法向量为 $\boldsymbol{n}_2 = (A_2, B_2, C_2)$。法向量本身的夹角可能是锐角，也可能是钝角。

由于平面夹角 $\theta \in [0, \pi/2]$，其余弦值 $\cos\theta$ 必须恒大于等于零。因此在套用向量数量积公式计算夹角时，**分子必须加绝对值**：

$$\cos \theta = \frac{|\boldsymbol{n}_1 \cdot \boldsymbol{n}_2|}{|\boldsymbol{n}_1| |\boldsymbol{n}_2|} = \frac{|A_1 A_2 + B_1 B_2 + C_1 C_2|}{\sqrt{A_1^2 + B_1^2 + C_1^2} \sqrt{A_2^2 + B_2^2 + C_2^2}}$$

> **提示**：部分参考书在列写两平面夹角公式时偶尔漏掉分子绝对值，或写成正负号形式。我们必须在公式分子上钉死绝对值符号——只要计算两平面的夹角，结果必须落回第一象限的非负余弦值。

#### 两平面的位置关系分类

空间中两个平面的位置关系包括：垂直、平行、重合、斜交。

| 位置关系 | 几何特征 | 法向量代数条件 | 坐标系数特征 |
| :--- | :--- | :--- | :--- |
| **垂直** ($\Pi_1 \perp \Pi_2$) | 夹角 $\theta = \frac{\pi}{2}$ | $\boldsymbol{n}_1 \cdot \boldsymbol{n}_2 = 0$ | $A_1 A_2 + B_1 B_2 + C_1 C_2 = 0$ |
| **平行** ($\Pi_1 \parallel \Pi_2$) | 夹角 $\theta = 0$ 且两面无交点 | $\boldsymbol{n}_1 \parallel \boldsymbol{n}_2$ | $\frac{A_1}{A_2} = \frac{B_1}{B_2} = \frac{C_1}{C_2} 
eq \frac{D_1}{D_2}$ |
| **重合** ($\Pi_1 = \Pi_2$) | 两面完全贴合同一平面 | $\boldsymbol{n}_1 \parallel \boldsymbol{n}_2$ | $\frac{A_1}{A_2} = \frac{B_1}{B_2} = \frac{C_1}{C_2} = \frac{D_1}{D_2}$ |
| **斜交** | 夹角 $\theta \in \left(0, \frac{\pi}{2}\right)$ | 既不垂直也不平行 | 坐标系数不成比例且数量积非零 |

在表示平面符号时，通常使用大写的希腊字母 $\Pi$（注意两腿笔直，不要随手写成圆周率 $\pi$ 的弯腿）。

#### 实战判定策略与快速识别口诀

做题判定两个平面的空间几何关系时，推荐遵循以下高效排查路径：

```text
       输入两个平面方程: Ax+By+Cz+D=0
                     │
                     ▼
           [第一步: 观察系数比例]
          XYZ系数成比例，常数项呢？
          ┌──────────┴──────────┐
      比例全同              仅XYZ成比例
         │                      │
       [重合]                 [平行]
         │                      │
         └──────────┬───────────┘
                    ▼ (系数不成比例)
           [第二步: 检查法向量点积]
           A1A2 + B1B2 + C1C2 是否为 0？
          ┌──────────┴──────────┐
         是                     否
         │                      │
       [垂直]                 [斜交]
                                │
                          套用绝对值余弦公式求夹角
```

1. **先扫平行与重合**：这是肉眼最快识别的。观察 $x, y, z$ 的系数比。如果对应系数完全成两倍、三倍比例，但常数项不成比例（例如 $x + y + z + 1 = 0$ 与 $2x + 2y + 2z + 5 = 0$），两平面必然**平行**；若连常数项都按同一比例缩放（例如 $x + y + z + 1 = 0$ 与 $2x + 2y + 2z + 2 = 0$），两者本质就是同一个方程除以非零常数，两平面必然**重合**。
2. **不成比例再验垂直**：口算法向量点积 $A_1 A_2 + B_1 B_2 + C_1 C_2$。若积为零，立刻判定为**垂直**。
3. **若前三者皆否，即为一般斜交**：此时老老实实代入余弦绝对值公式求出 $\cos\theta$，反求夹角 $\theta$。

### 点到平面的距离公式

在平面二维解析几何中，我们学过平面上一点 $(x_0, y_0)$ 到直线 $A x + B y + C = 0$ 的距离：

$$d = \frac{|A x_0 + B y_0 + C|}{\sqrt{A^2 + B^2}}$$

到了三维空间，空间点到平面的投影垂直距离，其公式在结构上具有完全一致的升维对称性。

> **结论**：设空间定点为 $P_0(x_0, y_0, z_0)$，平面方程为一般式 $A x + B y + C z + D = 0$，则点 $P_0$ 到该平面的距离 $d$ 为：
> $$d = \frac{|A x_0 + B y_0 + C z_0 + D|}{\sqrt{A^2 + B^2 + C^2}}$$

记忆与计算这个公式极为直观：
- **分母**：平面法向量的模长 $\sqrt{A^2 + B^2 + C^2}$；
- **分子**：把点 $P_0(x_0, y_0, z_0)$ 的坐标直接代入平面方程的左端，然后套上一层绝对值（距离绝不能为负）。

#### 例题一：点法式基本建立与一般式规范

**【题目】**
求过点 $P_0(2, -3, 0)$，且法向量为 $\boldsymbol{n} = (1, -2, 3)$ 的平面方程。

**【考查重点】**
点法式套用、展开化简与一般式标准化。

**【详细解析】**
1. 已知定点 $P_0(2, -3, 0)$，法向量分量为 $A = 1, B = -2, C = 3$。直接写出平面的点法式方程：
   $$1 \cdot (x - 2) + (-2) \cdot [y - (-3)] + 3 \cdot (z - 0) = 0$$
   整理中间括号符号：
   $$(x - 2) - 2(y + 3) + 3z = 0$$
2. 展开多项式：
   $$x - 2 - 2y - 6 + 3z = 0$$
3. 合并常数项，化为规范的一般式方程：
   $$x - 2y + 3z - 8 = 0$$

此时 $x$ 的系数为正数 $1$，格式完全符合规范要求。

#### 例题二：不共线三点确定平面方程（双解法）

**【题目】**
求经过三点 $M_1(2, -1, 4)$、$M_2(-1, 3, -2)$、$M_3(0, 2, 3)$ 的平面方程。

**【考查重点】**
几何不共线三点定面的充要性、向量叉乘构造法向量技巧、待定系数法（不定齐次方程组）消元思维。

> **注意**：空间中任意三点不一定能确定唯一平面——若三点共线，过该直线的平面有无数个；只有不共线的三点才能唯一锁定一个平面。

##### 方法一：点法式与向量积叉乘法（推荐核心方法）

1. 在平面内构造两条不共线的向量（以 $M_1$ 为公共起点）：
   $$\vec{M_1 M_2} = M_2 - M_1 = (-1 - 2,\; 3 - (-1),\; -2 - 4) = (-3, 4, -6)$$
   $$\vec{M_1 M_3} = M_3 - M_1 = (0 - 2,\; 2 - (-1),\; 3 - 4) = (-2, 3, -1)$$
2. 平面的法向量 $\boldsymbol{n}$ 同时垂直于平面内的向量 $\vec{M_1 M_2}$ 与 $\vec{M_1 M_3}$，直接用两向量作向量积（叉乘）：
   $$\boldsymbol{n} = \vec{M_1 M_2} \times \vec{M_1 M_3} = \begin{vmatrix} \boldsymbol{i} & \boldsymbol{j} & \boldsymbol{k} \\ -3 & 4 & -6 \\ -2 & 3 & -1 \end{vmatrix}$$
3. 计算三阶行列式：
   - $\boldsymbol{i}$ 分量：$4 \times (-1) - (-6) \times 3 = -4 + 18 = 14$；
   - $\boldsymbol{j}$ 分量：$-\left[(-3) \times (-1) - (-6) \times (-2)\right] = -(3 - 12) = 9$；
   - $\boldsymbol{k}$ 分量：$(-3) \times 3 - 4 \times (-2) = -9 + 8 = -1$。
   由此求得平面的法向量：
   $$\boldsymbol{n} = (14, 9, -1)$$
4. 选取平面上的定点写点法式：三点皆在面上，可选任意一点。但解题时优先挑选 $M_3(0, 2, 3)$——因为该点坐标中包含一个 $0$，且另两个分量均为正数，在做减法代入时符号最不易出错：
   $$14(x - 0) + 9(y - 2) - 1(z - 3) = 0$$
5. 展开并合并常数项：
   $$14x + 9y - 18 - z + 3 = 0 \implies 14x + 9y - z - 15 = 0$$

##### 方法二：一般式与待定系数法（代数消元法）

1. 设平面的一般式方程为：
   $$A x + B y + C z + D = 0$$
2. 将三点坐标分别代入方程，建立关于待定系数 $A, B, C, D$ 的方程组：
   $$\begin{cases} 2A - B + 4C + D = 0 & \text{—— 代入 } M_1(2, -1, 4) \quad (1) \\ -A + 3B - 2C + D = 0 & \text{—— 代入 } M_2(-1, 3, -2) \quad (2) \\ 2B + 3C + D = 0 & \text{—— 代入 } M_3(0, 2, 3) \quad (3) \end{cases}$$
3. 这是一个 4 个未知数、3 个方程的不定齐次方程组，存在无穷多组非零解（因为一般式全式乘以任意非零常数代表同一平面）。我们选定常数 $D$ 作为自由未知量，将 $A, B, C$ 全部用 $D$ 线性表示：
   - 将式 $(2)$ 左右乘以 $2$，得：$-2A + 6B - 4C + 2D = 0$；
   - 与式 $(1)$ 相加，恰好同时消去 $A$ 与 $C$：
     $$(2A - 2A) + (-B + 6B) + (4C - 4C) + (D + 2D) = 0 \implies 5B + 3D = 0$$
     解得：
     $$B = -\frac{3}{5}D$$
   - 将 $B = -\frac{3}{5}D$ 代入式 $(3)$ 解 $C$：
     $$2\left(-\frac{3}{5}D\right) + 3C + D = 0 \implies 3C = \frac{6}{5}D - D = \frac{1}{5}D \implies C = \frac{1}{15}D$$
   - 将 $B, C$ 代入式 $(2)$ 解 $A$：
     $$A = 3B - 2C + D = 3\left(-\frac{3}{5}D\right) - 2\left(\frac{1}{15}D\right) + D = -\frac{9}{5}D - \frac{2}{15}D + D$$
     通分合并：
     $$A = \frac{-27 - 2 + 15}{15}D = -\frac{14}{15}D$$
4. 将解得的 $A, B, C$ 统一代回一般式方程：
   $$\left(-\frac{14}{15}D\right) x + \left(-\frac{3}{5}D\right) y + \left(\frac{1}{15}D\right) z + D = 0$$
5. 两端同除以非零常数 $D$：
   $$-\frac{14}{15} x - \frac{3}{5} y + \frac{1}{15} z + 1 = 0$$
6. 两端同乘以 $-15$，消除分母并将首项化正：
   $$14x + 9y - z - 15 = 0$$

两种方法殊途同归。但在实战考场上，待定系数法计算分数通分耗时且极易算错，强烈推荐掌握方法一的向量积叉乘法。

#### 例题三：过坐标轴与已知点的平面方程求解

**【题目】**
求经过 $x$ 轴，且经过点 $A(4, -3, -1)$ 的平面方程。

**【考查重点】**
空间示意图构思策略、利用坐标轴隐含要素简化计算。

**【解题构思与草图直觉】**
拿到这类几何题，切忌在草稿纸上费力去抠三维空间坐标系（试图把三根轴画得无比精准透视），那纯粹是难为自己的空间想象力。我们只需要画一个示意图：画一个倾斜的平面，标出一条经过它的直线（$x$ 轴），在平面上点一个已知点 $A$。

```text
               n (所求法向量)
               ^
               |
         +-----|--------------+
        /      |     A(4,-3,-1)
       /       +------>       /
   x轴/=============O(0,0,0)=/
     +----------------------+  平面 Π
```
*图解说明：平面包含 $x$ 轴，因此原点 $O$ 必然在平面上，且 $x$ 轴的基向量 $\boldsymbol{i}$ 与向量 $\vec{OA}$ 均在平面内。*

**【详细解析】**
1. **寻找面内定点**：平面既然经过整条 $x$ 轴，那它必须经过 $x$ 轴上的所有点，最简便的定点就是坐标原点 $O(0, 0, 0)$。
2. **寻找面内两个方向向量**：
   - 一个是原点指向点 $A$ 的向量：
     $$\vec{OA} = (4 - 0, -3 - 0, -1 - 0) = (4, -3, -1)$$
   - 另一个是 $x$ 轴自身的方向向量，直接取 $x$ 轴正方向的单位基向量：
     $$\boldsymbol{i} = (1, 0, 0)$$
3. **叉乘求法向量**：所求平面的法向量 $\boldsymbol{n}$ 必然垂直于整个平面，因而同时垂直于 $\boldsymbol{i}$ 和 $\vec{OA}$：
   $$\boldsymbol{n} = \boldsymbol{i} \times \vec{OA} = \begin{vmatrix} \boldsymbol{i} & \boldsymbol{j} & \boldsymbol{k} \\ 1 & 0 & 0 \\ 4 & -3 & -1 \end{vmatrix}$$
   展开计算分量：
   - $\boldsymbol{i}$ 分量：$0 \times (-1) - 0 \times (-3) = 0$；
   - $\boldsymbol{j}$ 分量：$-\left[1 \times (-1) - 0 \times 4\right] = -(-1) = 1$；
   - $\boldsymbol{k}$ 分量：$1 \times (-3) - 0 \times 4 = -3$。
   得到法向量：
   $$\boldsymbol{n} = (0, 1, -3)$$
4. **点法式建方程**：定点取原点 $(0, 0, 0)$，列写点法式：
   $$0 \cdot (x - 0) + 1 \cdot (y - 0) - 3 \cdot (z - 0) = 0 \implies y - 3z = 0$$

方程中缺少 $x$ 且常数项为 $0$，从代数形态上再次印证了该平面必包含 $x$ 轴。

#### 例题四：求两已知平面的空间夹角

**【题目】**
求两平面 $\Pi_1: x - y + 2z - 6 = 0$ 与 $\Pi_2: 2x + y + z - 5 = 0$ 的夹角 $\theta$。

**【考查重点】**
从方程直读法向量、模长计算、两平面夹角绝对值余弦公式。

**【详细解析】**
1. 分别读取两平面的法向量：
   - 由 $\Pi_1: x - y + 2z - 6 = 0$，读出 $\boldsymbol{n}_1 = (1, -1, 2)$；
   - 由 $\Pi_2: 2x + y + z - 5 = 0$，读出 $\boldsymbol{n}_2 = (2, 1, 1)$。
2. 快速口算系数比：$1/2 
eq -1/1$，显然两平面既不平行也不重合。
3. 计算两向量的数量积（点积）：
   $$\boldsymbol{n}_1 \cdot \boldsymbol{n}_2 = 1 \times 2 + (-1) \times 1 + 2 \times 1 = 2 - 1 + 2 = 3$$
   点积不为 $0$，排除垂直，两面处于斜交状态。
4. 计算两法向量的模长：
   $$|\boldsymbol{n}_1| = \sqrt{1^2 + (-1)^2 + 2^2} = \sqrt{1 + 1 + 4} = \sqrt{6}$$
   $$|\boldsymbol{n}_2| = \sqrt{2^2 + 1^2 + 1^2} = \sqrt{4 + 1 + 1} = \sqrt{6}$$
5. 代入两平面夹角公式（注意分子取绝对值）：
   $$\cos \theta = \frac{|\boldsymbol{n}_1 \cdot \boldsymbol{n}_2|}{|\boldsymbol{n}_1| |\boldsymbol{n}_2|} = \frac{|3|}{\sqrt{6} \times \sqrt{6}} = \frac{3}{6} = \frac{1}{2}$$
6. 在 $\theta \in [0, \pi/2]$ 范围内反求角度：
   $$\theta = \frac{\pi}{3} \quad (\text{即 } 60^\circ)$$

#### 例题五：过已知两点且垂直于已知平面的方程

**【题目】**
求经过点 $M_1(1, 1, 1)$ 与点 $M_2(2, 1, 3)$，且垂直于已知平面 $\Pi_0: x + y + z = 0$ 的平面 $\Pi$ 的方程。

**【考查重点】**
面面垂直性质的代数转化、双垂直条件求法向量。

```text
            n (所求法向量)
            ^
            |       /  n0 (已知面法向量)
            |      /
      +-----|-----/----------------+
     /      |    /                 /
    /       +-------> M2(2,1,3)   /
   /      M1(1,1,1)              /  所求平面 Π
  +-----------------------------+
               |  垂直
               v
        [ 已知平面 Π0: x+y+z=0 ]
```
*图解说明：所求平面的法向量 $\boldsymbol{n}$ 既与面内连线 $\vec{M_1 M_2}$ 垂直，又必须与垂直平面的法向量 $\boldsymbol{n}_0$ 保持垂直。*

**【详细解析】**
1. **分析法向量的双重垂直关系**：
   - 设所求平面 $\Pi$ 的法向量为 $\boldsymbol{n}$；
   - 点 $M_1, M_2$ 都在平面 $\Pi$ 上，因此向量 $\vec{M_1 M_2}$ 在平面内，必有 $\boldsymbol{n} \perp \vec{M_1 M_2}$；
   - 平面 $\Pi$ 垂直于已知平面 $\Pi_0$，两平面互相垂直，则它们的法向量也必然互相垂直，必有 $\boldsymbol{n} \perp \boldsymbol{n}_0$。
2. **提取分量并做叉乘**：
   - 已知平面 $\Pi_0: x + y + z = 0$ 的法向量为 $\boldsymbol{n}_0 = (1, 1, 1)$；
   - 计算平面内的向量：
     $$\vec{M_1 M_2} = (2 - 1,\; 1 - 1,\; 3 - 1) = (1, 0, 2)$$
   - 所求法向量 $\boldsymbol{n}$ 同时垂直于 $\boldsymbol{n}_0$ 与 $\vec{M_1 M_2}$，直接用两者叉乘构造：
     $$\boldsymbol{n} = \boldsymbol{n}_0 \times \vec{M_1 M_2} = \begin{vmatrix} \boldsymbol{i} & \boldsymbol{j} & \boldsymbol{k} \\ 1 & 1 & 1 \\ 1 & 0 & 2 \end{vmatrix}$$
3. **计算行列式**：
   - $\boldsymbol{i}$ 分量：$1 \times 2 - 1 \times 0 = 2$；
   - $\boldsymbol{j}$ 分量：$-(1 \times 2 - 1 \times 1) = -(2 - 1) = -1$；
   - $\boldsymbol{k}$ 分量：$1 \times 0 - 1 \times 1 = -1$。
   求得法向量：
   $$\boldsymbol{n} = (2, -1, -1)$$
4. **选取定点写出方程**：
   选取定点 $M_1(1, 1, 1)$，套用点法式：
   $$2(x - 1) - 1(y - 1) - 1(z - 1) = 0$$
5. **展开合并**：
   $$2x - 2 - y + 1 - z + 1 = 0 \implies 2x - y - z = 0$$

检验：将 $M_2(2, 1, 3)$ 代入：$2(2) - 1 - 3 = 0$，成立；法向量 $(2, -1, -1)$ 与已知法向量 $(1, 1, 1)$ 点积为 $2 - 1 - 1 = 0$，互相垂直，答案完全正确。

有同学上节课听完点到平面的距离公式，心里直犯嘀咕：如果把点的坐标代到平面方程左边，要是等于零，那分子不就一直是零了吗？
怎么会一直等于零呢？因为这个点在平面外面，它不在这个面上！把不在平面上的点代入平面方程，等式根本不成立，左边算出来必定是一个非零的数值。取绝对值之后再除以法向量的模长，就是该点到平面的垂直距离。
这个公式在做题时必须直接套用，如果考场上现场去推导，那可就麻烦了去了。不过出题老师经常会在这里设置一个小障碍——故意不把平面写成一般式，比如写成 $x + y + z = 10$。按照标准规范，常数项必须挪到等号左边，先整理为 $x + y + z - 10 = 0$，然后再套公式。以点 $(1, 2, 3)$ 到该平面的距离为例：
$$d = \frac{|1 + 2 + 3 - 10|}{\sqrt{1^2 + 1^2 + 1^2}} = \frac{|-4|}{\sqrt{3}} = \frac{4}{\sqrt{3}} = \frac{4\sqrt{3}}{3}$$

### 空间直线方程的三种表达形式

在三维空间中，确定一条直线通常有两种基本几何思路：一种是视作两个不同平面的相交交线；另一种是指定直线上的一点以及直线的延伸走向。由此衍生出空间直线的三种标准方程形式。

#### 一般式方程：两平面的相交交线

在空间中，两个相交平面所共有的所有点构成的集合，就是一条直线。因此，将两个平面的方程联立在一起，就构成了空间直线的一般式方程：

$$\begin{cases} A_1 x + B_1 y + C_1 z + D_1 = 0 \\ A_2 x + B_2 y + C_2 z + D_2 = 0 \end{cases}$$

```text
        平面 \Pi_1 (法向量 n_1)
             \         / 平面 \Pi_2 (法向量 n_2)
              \       /
               \     /
                \   /
                 \ /
==================+==================> 交线 L (方向向量 s = n_1 x n_2)
                 / \
                /   \
```
*图示说明：两个相交平面的交线即为空间直线，交线的延伸方向同时垂直于两个平面的法向量。*

一般式非常符合直观几何想象，但我们需要反思一个基础几何问题：在什么情况下，两个平面联立出不来唯一的一条直线？
只有两种退化情况：
1. 两个平面互相平行：此时两平面没有公共点，交集为空，形不成交线；
2. 两个平面重合：此时两平面方程本质相同，交集是整个平面，公共部分拥有无数条直线，无法唯一定位一条直线。

不过在各类考试与常规习题中，只要题目给出了由两平面联立的一般式，其系数必定满足相交条件，一定能确定唯一一条直线。

一般式方程虽然形式规整，但在解决距离、投影和夹角等动态问题时使用并不方便。面对一般式，最核心的破局思路在于求出该直线的走向——即直线的**方向向量**。
观察上述几何示意图可以清晰看出：直线 $L$ 既属于平面 $\Pi_1$，又属于平面 $\Pi_2$。这意味着直线的延伸方向必定同时与平面 $\Pi_1$ 的法向量 $\vec{n}_1$ 垂直，也与平面 $\Pi_2$ 的法向量 $\vec{n}_2$ 垂直。
在向量代数中，寻找一个同时与两个已知向量垂直的向量，标准工具正是向量积（叉乘）。

> **结论**：若空间直线由两个平面的交线一般式给出，则该直线的方向向量 $\vec{s}$ 可以直接通过两平面法向量的向量积求得：
> $$\vec{s} = \vec{n}_1 \times \vec{n}_2$$
> 这一结论是贯穿空间直线所有计算的核心钥匙。

#### 点向式方程：点与方向向量的对称比例

如何完全确定一条直线的空间位置？几何上只需要两个要素：
1. 直线上已知的一个定点 $P_0(x_0, y_0, z_0)$；
2. 与该直线平行的非零向量，称为该直线的**方向向量**，记作 $\vec{s} = (m, n, p)$。

直线的方向向量不是唯一的。只要与直线平行，取同向向量、反向向量，或者伸长、缩短任意非零常数倍的向量，都可以充当直线的方向向量。

点向式方程的推导极为简明：
在直线上任取一个动点 $P(x, y, z)$，连接已知点与动点构成的向量为：
$$\vec{P_0 P} = (x - x_0, y - y_0, z - z_0)$$
由于点 $P$ 始终在直线上，向量 $\vec{P_0 P}$ 必然与方向向量 $\vec{s} = (m, n, p)$ 平行。由两向量平行的充要条件（对应坐标成比例），立即得到：

$$\frac{x - x_0}{m} = \frac{y - y_0}{n} = \frac{z - z_0}{p}$$

这个方程称为直线的**点向式方程**，由于各坐标分式两两对称相等，在教材中也常被称为**对称式方程**。

在书写和记忆点向式方程时，建议遵循固定的书写节奏以避免混乱：
第一步，先写分子，写出动点坐标与已知定点坐标的差值：$x - x_0$、$y - y_0$、$z - z_0$；
第二步，在三个分子下方整齐划一地写出“比上等于”：$\frac{\quad}{m} = \frac{\quad}{n} = \frac{\quad}{p}$，将方向向量的分量填入分母。

举个例子：已知直线经过点 $(1, 2, 3)$，方向向量为 $(-5, 6, 0)$，其点向式方程直接写为：
$$\frac{x - 1}{-5} = \frac{y - 2}{6} = \frac{z - 3}{0}$$

> **提示**：这里的第三项分母出现了 0，但绝不违背普通数学中“除数不能为 0”的算术法则。点向式方程中的分式形式是一种**几何向量平行的形式记号**，当某个分母为 0 时，根据比例关系其分子必须同时为 0，即表示 $z - 3 = 0$。在空间几何中，这表明该直线上所有点的 $z$ 坐标恒为 3，直线整体平行于 $xOy$ 坐标平面，垂直于 $z$ 轴。

#### 参数式方程：动点坐标的一元参数化

点向式方程三个分式两两相等，如果设这个共同的比值为参数 $t$：
$$\frac{x - x_0}{m} = \frac{y - y_0}{n} = \frac{z - z_0}{p} = t$$
分别解出 $x, y, z$，即可得到直线的**参数式方程**：

$$\begin{cases} x = x_0 + mt \\ y = y_0 + nt \\ z = z_0 + pt \end{cases}$$

参数式方程具有无可替代的实战价值：它把直线上任意动点的三个空间坐标 $x, y, z$，统一表示成了单一独立参数 $t$ 的一元线性函数。
在后续求解直线与平面的交点、直线与直线的交点、垂足坐标以及动点距离时，只要将参数式代入其他几何方程中，就能将三元问题瞬间降维为关于 $t$ 的一元一次方程，运算极其顺畅。

#### 一般式化为点向式与参数式

在考题与实际应用中，最常见的综合题型就是将一般式方程转化为点向式或参数式。转化的核心任务就是找出直线的两要素：**直线上的一点**与**直线的方向向量**。

我们通过一个标准例题来掌握完整步骤：
将直线的一般式方程化为点向式和参数式：
$$\begin{cases} x + y + z + 1 = 0 \\ 2x - y + 3z + 4 = 0 \end{cases}$$

第一步：确定直线上的一点 $P_0$。
直线上有无穷多个点，理论上只需对 $x, y, z$ 中的某一个变量赋予特殊常数值，再联立求解剩余两个未知数即可。
平时做题大家最习惯令 $z = 0$。如果对本题令 $z = 0$，虽然完全可以解出 $x$ 和 $y$，但算出来的数值是分数。为了求得整洁的整数坐标，教材在此处令 $x = 1$。
将 $x = 1$ 代入原方程组：
$$\begin{cases} 1 + y + z + 1 = 0 \implies y + z = -2 \\ 2(1) - y + 3z + 4 = 0 \implies -y + 3z = -6 \end{cases}$$
将两式直接相加：
$$4z = -8 \implies z = -2$$
代回第一式得 $y = 0$。
于是求得直线上一个确定的整点坐标：$P_0(1, 0, -2)$。

> **易错点**：求直线上一点时，令 $z = 0$、$x = 0$ 或 $y = 0$ 是不是万能的？
> 答案是否定的。令 $z = 0$ 在几何上的本质，是用坐标面 $xOy$ 去截这条直线以求交点。如果已知直线恰好与 $xOy$ 平面平行（即方向向量的 $z$ 分量为 0 且直线不在 $xOy$ 面内），那么直线与 $xOy$ 平面根本没有交点。此时若强行令 $z = 0$，所得二元方程组将出现矛盾无解。遇到这种情况切莫慌乱，说明所选截面与直线平行，只需换用令 $x = 0$ 或 $y = 0$ 即可。

第二步：求直线的方向向量 $\vec{s}$。
从两平面方程中直接提取法向量：
第一个平面方程 $x + y + z + 1 = 0$ 的法向量为 $\vec{n}_1 = (1, 1, 1)$；
第二个平面方程 $2x - y + 3z + 4 = 0$ 的法向量为 $\vec{n}_2 = (2, -1, 3)$。
直线的方向向量取两法向量的叉乘：
$$\vec{s} = \vec{n}_1 \times \vec{n}_2 = \begin{vmatrix} \vec{i} & \vec{j} & \vec{k} \\ 1 & 1 & 1 \\ 2 & -1 & 3 \end{vmatrix}$$
展开计算各项分量：
- $\vec{i}$ 分量：$1\times 3 - 1\times(-1) = 3 + 1 = 4$；
- $\vec{j}$ 分量：$-(1\times 3 - 1\times 2) = -(3 - 2) = -1$；
- $\vec{k}$ 分量：$1\times(-1) - 1\times 2 = -1 - 2 = -3$。
求得方向向量为 $\vec{s} = (4, -1, -3)$。

第三步：写出点向式并导出参数式。
以点 $P_0(1, 0, -2)$ 为基准，分母填入方向向量各分量：
$$\frac{x - 1}{4} = \frac{y}{-1} = \frac{z + 2}{-3}$$

> **注意**：写出点向式后，千万不要自作聪明地给方程各项同乘 12 去消掉分母！点向式本身要求分母清晰对应方向向量的分量，分子保持一次标准形式，直接保留分式形式才是最规范的答案。

设上式等于参数 $t$，整理即得参数式方程：
$$\begin{cases} x = 1 + 4t \\ y = -t \\ z = -2 - 3t \end{cases}$$

### 空间两直线的位置关系与夹角计算

空间直线无限向两端延伸。两条直线在空间中的相对位置比平面几何更为丰富，不仅可以平行、相交，还可能处于异面状态。

#### 两直线的夹角公式

空间两直线相交或异面时，都会在空间中形成角。由于直线不带固有指向，其相交会形成两对对顶角，其中一对为锐角（或直角），另一对为钝角（或直角）。
在立体几何与高等数学中，统一规定**两直线的夹角 $\theta$ 取锐角或直角**，即：
$$\theta \in [0, \frac{\pi}{2}]$$

设直线 $L_1$ 的方向向量为 $\vec{s}_1$，直线 $L_2$ 的方向向量为 $\vec{s}_2$。两方向向量本身的夹角余弦值通过数量积计算。为了确保最终角落在 $[0, \frac{\pi}{2}]$ 区间内，必须对数量积分子的结果强制加上绝对值：

$$\cos\theta = \frac{|\vec{s}_1 \cdot \vec{s}_2|}{|\vec{s}_1||\vec{s}_2|}$$

分母是两个方向向量模长的乘积，分子是数量积的绝对值，计算结果恒非负，反三角函数求解出的 $\theta = \arccos(\dots)$ 即为两直线的唯一夹角。

#### 两直线的位置关系判别体系

利用方向向量与直线上已知点的代入检验，可以系统判定空间两直线的全部几何位置关系：

1. **两直线垂直**：
   两直线垂直当且仅当其延伸走向互相垂直，对应方向向量互相垂直：
   $$L_1 \perp L_2 \iff \vec{s}_1 \perp \vec{s}_2 \iff \vec{s}_1 \cdot \vec{s}_2 = 0$$

2. **两直线平行**：
   两直线平行要求其方向向量共线（成比例），且不能相互重叠：
   $$L_1 \parallel L_2 \iff \vec{s}_1 \parallel \vec{s}_2$$
   并且在 $L_1$ 上任取一点代入 $L_2$ 的方程，等式不成立。

3. **两直线重合**：
   两直线重合首先要求方向向量平行（$\vec{s}_1 \parallel \vec{s}_2$），同时在 $L_1$ 上任取一点代入 $L_2$ 的方程，等式依然严格成立。
   
   > **提示**：有同学常问：重合是不是平行的一种特殊情形？在答题时如果判定为平行，需不需要特别强调“平行且不重合”？
   > 在高等数学的标准考题与学术规范中，通常结论中所称的“平行”即默认排除了重合情形；如果两直线所有点完全重叠，直接回答“两直线重合”即可。

4. **两直线相交与异面**：
   如果两直线的方向向量不平行（即不平行也不重合），它们在空间中有两种状态：
   - 共面且相交：两直线在同一平面内，有且仅有一个交点；
   - 异面不相交：两直线既不平行也不相交，在空间中交错延伸。
   教材中并没有为既不平行也不垂直的普通异面状态起生僻名称，做题时按几何本质区分是否共面相交即可。

#### 两直线夹角典型算例

已知直线 $L_1$ 的方向向量为 $\vec{s}_1 = (1, -4, 1)$，直线 $L_2$ 的方向向量为 $\vec{s}_2 = (2, -2, -1)$，求两直线所成夹角 $\theta$。

第一步，计算方向向量的数量积：
$$\vec{s}_1 \cdot \vec{s}_2 = 1\times 2 + (-4)\times(-2) + 1\times(-1) = 2 + 8 - 1 = 9$$

第二步，计算各自模长：
$$|\vec{s}_1| = \sqrt{1^2 + (-4)^2 + 1^2} = \sqrt{1 + 16 + 1} = \sqrt{18} = 3\sqrt{2}$$
$$|\vec{s}_2| = \sqrt{2^2 + (-2)^2 + (-1)^2} = \sqrt{4 + 4 + 1} = \sqrt{9} = 3$$

第三步，代入公式计算余弦值：
$$\cos\theta = \frac{|\vec{s}_1 \cdot \vec{s}_2|}{|\vec{s}_1||\vec{s}_2|} = \frac{|9|}{3\sqrt{2} \times 3} = \frac{9}{9\sqrt{2}} = \frac{1}{\sqrt{2}} = \frac{\sqrt{2}}{2}$$
因为 $\cos\theta = \frac{\sqrt{2}}{2}$ 且 $\theta \in [0, \frac{\pi}{2}]$，解得两直线的夹角为：
$$\theta = \frac{\pi}{4}$$

### 直线与平面的空间位置关系与夹角

直线与平面的交互关系是空间解析几何的重头戏，也是极易产生概念混淆的地方。

#### 直线与平面夹角及其正弦公式

直线与平面的夹角具有明确的几何定义：**直线与其在平面上的正投影直线所夹的锐角 $\theta$**，规定范围同样为 $\theta \in [0, \frac{\pi}{2}]$。

```text
          n (法向量)
          ^
          |      s (直线的方向向量)
          |     /
          |    /
          |   /
          |  / )  \phi (向量夹角)
          | /
----------+------------------------- 平面 \Pi
         /| \
        / |  \ ) \theta (线面夹角)
       /  |   \
      /   |    \-----> 投影直线
```
*图示说明：平面的法向量垂直于投影面，直线的方向向量与法向量的夹角 $\phi$ 与线面夹角 $\theta$ 构成互余关系。*

仔细观察上图的几何关系：
直线的代表向量是其方向向量 $\vec{s}$，而平面的代表向量是垂直于该面的法向量 $\vec{n}$。
向量 $\vec{s}$ 与 $\vec{n}$ 本身的空间夹角设为 $\phi$。因为法向量 $\vec{n}$ 垂直于平面内的投影直线，所以在直角三角形中，夹角 $\phi$ 与所求的线面角 $\theta$ 必然互余（即 $\theta + \phi = 90^\circ$）或者互补相关。
根据三角函数互余诱导公式：
$$\cos\phi = \cos(90^\circ - \theta) = \sin\theta$$
向量数量积公式求出的是 $\cos\phi$，而该值恰恰等于线面角的正弦值 $\sin\theta$！

由此得出直线与平面的夹角公式：
$$\sin\theta = \frac{|\vec{s} \cdot \vec{n}|}{|\vec{s}||\vec{n}|}$$

> **易错点**：全书所有立体几何夹角公式（两向量夹角、两平面夹角、两直线夹角）左侧全部是余弦 $\cos\theta$，**唯独直线与平面的夹角公式左侧是正弦 $\sin\theta$**！这是因为直线用了方向向量、平面用了法向量，法向量自带一个 $90^\circ$ 的转角，导致余弦反转为了正弦。考场上见到线面角，第一反应必须锁定 $\sin$。

#### 线面垂直与平行的向量对偶关系

当直线与平面处于特殊位置关系时，其几何直观与向量代数关系呈现出有趣的“反转对偶”：

1. **直线与平面垂直**：
   直观上直线垂直于平面，意味着直线的走向与平面的法线走向完全一致或反向。
   因此，直线的方向向量与平面的法向量必然**平行**：
   $$L \perp \Pi \iff \vec{s} \parallel \vec{n}$$

2. **直线与平面平行**：
   直观上直线平行于平面，意味着直线的走向完全卧在平面的平行方向上，自然与平面的垂直法向量互相垂直。
   因此，直线的方向向量与平面的法向量必然**垂直**：
   $$L \parallel \Pi \iff \vec{s} \perp \vec{n} \iff \vec{s} \cdot \vec{n} = 0$$

> **注意**：很多初学者在这里极容易转晕，把“线面垂直”记成“向量垂直”。千万不要死记死背口诀，考试或做题时在草稿纸上花两秒钟画一个小平面和一根法线，一眼就能看出向量是平行还是垂直。

### 空间四大夹角公式系统对比

为了防止在综合考题中将各类夹角公式混淆，我们将立体几何中四个最核心的夹角公式进行横向对照归纳：

| 几何对象 | 核心代表向量 | 角度范围 $\theta$ | 计算函数 | 公式 | 绝对值要求与关键特征 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **两向量夹角** | 向量 $\vec{a}$ 与 $\vec{b}$ | $[0, \pi]$ | $\cos\theta$ | $\cos\theta = \frac{\vec{a}\cdot\vec{b}}{|\vec{a}||\vec{b}|}$ | 分子**不加**绝对值，允许取钝角 |
| **两平面夹角** | 法向量 $\vec{n}_1$ 与 $\vec{n}_2$ | $[0, \frac{\pi}{2}]$ | $\cos\theta$ | $\cos\theta = \frac{|\vec{n}_1\cdot\vec{n}_2|}{|\vec{n}_1||\vec{n}_2|}$ | 分子**必加**绝对值，约定只取锐角 |
| **两直线夹角** | 方向向量 $\vec{s}_1$ 与 $\vec{s}_2$ | $[0, \frac{\pi}{2}]$ | $\cos\theta$ | $\cos\theta = \frac{|\vec{s}_1\cdot\vec{s}_2|}{|\vec{s}_1||\vec{s}_2|}$ | 分子**必加**绝对值，约定只取锐角 |
| **线面夹角** | 方向向量 $\vec{s}$ 与法向量 $\vec{n}$ | $[0, \frac{\pi}{2}]$ | $\sin\theta$ | $\sin\theta = \frac{|\vec{s}\cdot\vec{n}|}{|\vec{s}||\vec{n}|}$ | 分子**必加**绝对值，**全篇唯一使用正弦** |

四大公式的记忆纲领极为清晰：
- 只有两向量本身的夹角允许是钝角，所以分子不加绝对值；其余三种空间几何体夹角一律只取非负锐角，分子统统加绝对值；
- 只有直线与平面是“跨界组合”（一个用方向向量，一个用法向量），导致余弦转化为正弦；其余三类公式一律使用余弦。

### 综合例题全流程精析

通过四道具有代表性的考查题型，完整串联直线的点向式、一般式、参数式以及线面空间关系的实战应用。

#### 过定点求已知平面的垂线方程

求过点 $(1, -2, 4)$ 且与平面 $2x - 3y + z - 4 = 0$ 垂直的直线方程。

解题思路：
要求直线方程，首选点向式，必须掌握已知定点与方向向量。已知直线过定点 $P_0(1, -2, 4)$。
题目要求直线与已知平面垂直。根据线面垂直的对偶结论，直线的方向向量 $\vec{s}$ 可以直接选取该平面的法向量 $\vec{n}$。
已知平面的法向量为：
$$\vec{n} = (2, -3, 1)$$
直接令所求直线的方向向量 $\vec{s} = \vec{n} = (2, -3, 1)$。
代入点向式方程：
$$\frac{x - 1}{2} = \frac{y - (-2)}{-3} = \frac{z - 4}{1}$$
化简即得：
$$\frac{x - 1}{2} = \frac{y + 2}{-3} = \frac{z - 4}{1}$$

#### 求平行于两平面交线的直线方程

求与两平面 $x - 4z = 3$ 和 $2x - y - 5z = 1$ 的交线平行，且过点 $(-3, 2, 5)$ 的直线方程。

解题思路：
所求直线过已知点 $P_0(-3, 2, 5)$，且平行于已知两平面的交线。因此，两平面交线的方向向量就是我们所求直线的方向向量。
提取两平面的法向量：
第一个平面 $x - 4z - 3 = 0$ 缺少 $y$ 项，其法向量对应分量为 0，即 $\vec{n}_1 = (1, 0, -4)$；
第二个平面 $2x - y - 5z - 1 = 0$ 的法向量为 $\vec{n}_2 = (2, -1, -5)$。
交线的方向向量通过向量积求得：
$$\vec{s} = \vec{n}_1 \times \vec{n}_2 = \begin{vmatrix} \vec{i} & \vec{j} & \vec{k} \\ 1 & 0 & -4 \\ 2 & -1 & -5 \end{vmatrix}$$
展开计算：
- $\vec{i}$ 分量：$0\times(-5) - (-4)\times(-1) = 0 - 4 = -4$；
- $\vec{j}$ 分量：$-(1\times(-5) - (-4)\times 2) = -(-5 + 8) = -3$；
- $\vec{k}$ 分量：$1\times(-1) - 0\times 2 = -1 - 0 = -1$。
求得交线方向向量为 $(-4, -3, -1)$。
为了书写整洁，直线的方向向量可以自由反向放大或缩小，我们提取公因数 $-1$，选取同向的正值向量 $\vec{s} = (4, 3, 1)$。
结合已知点 $(-3, 2, 5)$，写出点向式方程：
$$\frac{x - (-3)}{4} = \frac{y - 2}{3} = \frac{z - 5}{1} \implies \frac{x + 3}{4} = \frac{y - 2}{3} = \frac{z - 5}{1}$$

#### 求直线与平面的空间交点

求直线 $\frac{x - 2}{1} = \frac{y - 3}{1} = \frac{z - 4}{2}$ 与平面 $2x + y + z - 6 = 0$ 的交点坐标。

解题思路：
求解直线与平面的交点，最强效的工具就是直线的参数式方程。
令点向式比值等于参数 $t$：
$$\frac{x - 2}{1} = \frac{y - 3}{1} = \frac{z - 4}{2} = t$$
解出直线上动点的参数坐标：
$$\begin{cases} x = 2 + t \\ y = 3 + t \\ z = 4 + 2t \end{cases}$$
将动点坐标整体代入平面方程 $2x + y + z - 6 = 0$ 中：
$$2(2 + t) + (3 + t) + (4 + 2t) - 6 = 0$$
去括号展开化简：
$$(4 + 2t) + (3 + t) + (4 + 2t) - 6 = 0$$
$$(2t + t + 2t) + (4 + 3 + 4 - 6) = 0$$
$$5t + 5 = 0 \implies t = -1$$
求出交点对应的参数值 $t = -1$ 后，将其回代至直线的参数式中：
$$x = 2 + (-1) = 1$$
$$y = 3 + (-1) = 2$$
$$z = 4 + 2(-1) = 2$$
由此直接求得直线与平面的交点坐标为 $(1, 2, 2)$。代入平面方程核验：$2(1) + 2 + 2 - 6 = 0$，结果完全吻合。

#### 求过点且与已知直线垂直相交的直线方程

求过点 $A(2, 1, 3)$ 且与已知直线 $L: \frac{x + 1}{3} = \frac{y - 1}{2} = \frac{z}{-1}$ 垂直相交的直线方程。

解题思路：
本题条件非常丰富：所求直线不仅过已知点 $A$，而且与已知直线 $L$ 既要**相交**，又要**垂直**。
只要牵涉到直线的相交点，第一时间设定交点坐标。
设两直线的交点（垂足）为 $B$。因为点 $B$ 在已知直线 $L$ 上，将其用直线 $L$ 的参数形式表达。
令直线 $L$ 的方程比值等于 $t$：
$$\frac{x + 1}{3} = \frac{y - 1}{2} = \frac{z}{-1} = t \implies \begin{cases} x = -1 + 3t \\ y = 1 + 2t \\ z = -t \end{cases}$$
因此交点 $B$ 的坐标可以设为 $(-1 + 3t, 1 + 2t, -t)$。
所求直线是连接定点 $A(2, 1, 3)$ 与交点 $B$ 的连线，向量 $\vec{AB}$ 即为该直线的方向向量：
$$\vec{AB} = B - A = (-1 + 3t - 2, \; 1 + 2t - 1, \; -t - 3) = (3t - 3, \; 2t, \; -t - 3)$$
接下来利用“垂直”条件定出未知数 $t$：
已知直线 $L$ 的方向向量为 $\vec{s}_1 = (3, 2, -1)$。所求直线与 $L$ 垂直，意味着向量 $\vec{AB}$ 必须与 $\vec{s}_1$ 正交（数量积为 0）：
$$\vec{AB} \cdot \vec{s}_1 = 0$$
将坐标代入数量积方程：
$$3(3t - 3) + 2(2t) + (-1)(-t - 3) = 0$$
展开合并同类项：
$$(9t - 9) + 4t + (t + 3) = 0$$
$$(9t + 4t + t) + (-9 + 3) = 0$$
$$14t - 6 = 0 \implies 14t = 6 \implies t = \frac{3}{7}$$
注意计算必须格外仔细，解出参数 $t = \frac{3}{7}$ 后，将其代回向量 $\vec{AB}$ 的各分量：
- $x$ 分量：$3\left(\frac{3}{7}\right) - 3 = \frac{9}{7} - \frac{21}{7} = -\frac{12}{7}$；
- $y$ 分量：$2\left(\frac{3}{7}\right) = \frac{6}{7}$；
- $z$ 分量：$-\frac{3}{7} - 3 = -\frac{3}{7} - \frac{21}{7} = -\frac{24}{7}$。
得到方向向量为：
$$\vec{AB} = \left(-\frac{12}{7}, \; \frac{6}{7}, \; -\frac{24}{7}\right)$$
在写点向式方程时，分母无需带复杂繁琐的分数。我们提取公因数 $-\frac{6}{7}$：
$$\vec{AB} = -\frac{6}{7} (2, \; -1, \; 4)$$
直接选取精简的整数向量 $\vec{s} = (2, -1, 4)$ 作为所求直线的方向向量（若选 $(-2, 1, -4)$ 亦完全等价）。
已知直线过点 $A(2, 1, 3)$，写出点向式方程：
$$\frac{x - 2}{2} = \frac{y - 1}{-1} = \frac{z - 3}{4}$$

### 本讲提到的题目

#### 点到平面距离引例
- **题干**：求点 $P(1, 2, 3)$ 到平面 $x + y + z = 10$ 的距离。
- **解析**：
  先将平面方程化为标准一般式 $x + y + z - 10 = 0$。法向量模长为 $\sqrt{1^2 + 1^2 + 1^2} = \sqrt{3}$。
  将点代入方程左边并取绝对值：$|1 + 2 + 3 - 10| = |-4| = 4$。
  代入点到平面距离公式：
  $$d = \frac{4}{\sqrt{3}} = \frac{4\sqrt{3}}{3}$$
- **答案**：$\frac{4\sqrt{3}}{3}$。

#### 点向式方程书写引例
- **题干**：求过点 $(1, 2, 3)$ 且方向向量为 $\vec{s} = (-5, 6, 0)$ 的直线的点向式方程。
- **解析**：
  分子写各坐标差 $x - 1, y - 2, z - 3$，分母填入方向向量各分量 $-5, 6, 0$。分母为 0 属于规范形式记号，代表平面几何条件 $z = 3$。
- **答案**：$\frac{x - 1}{-5} = \frac{y - 2}{6} = \frac{z - 3}{0}$。

#### 一般式化点向式与参数式
- **题干**：将直线的一般式方程 $\begin{cases} x + y + z + 1 = 0 \\ 2x - y + 3z + 4 = 0 \end{cases}$ 化为点向式和参数式方程。
- **解析**：
  1. 令 $x = 1$，联立 $\begin{cases} y + z = -2 \\ -y + 3z = -6 \end{cases}$ 解得定点 $P_0(1, 0, -2)$；
  2. 提取法向量 $\vec{n}_1 = (1, 1, 1), \vec{n}_2 = (2, -1, 3)$，叉乘求方向向量：
     $$\vec{s} = \vec{n}_1 \times \vec{n}_2 = (4, -1, -3)$$
  3. 写出点向式：$\frac{x - 1}{4} = \frac{y}{-1} = \frac{z + 2}{-3}$；
  4. 设比值为 $t$，导出参数式：$\begin{cases} x = 1 + 4t \\ y = -t \\ z = -2 - 3t \end{cases}$。
- **答案**：
  点向式为 $\frac{x - 1}{4} = \frac{y}{-1} = \frac{z + 2}{-3}$；
  参数式为 $\begin{cases} x = 1 + 4t \\ y = -t \\ z = -2 - 3t \end{cases}$。

#### 两直线夹角计算题
- **题干**：已知直线 $L_1$ 的方向向量为 $\vec{s}_1 = (1, -4, 1)$，直线 $L_2$ 的方向向量为 $\vec{s}_2 = (2, -2, -1)$，求两直线的夹角 $\theta$。
- **解析**：
  计算数量积 $\vec{s}_1 \cdot \vec{s}_2 = 1\times 2 + (-4)\times(-2) + 1\times(-1) = 9$。
  模长分别为 $|\vec{s}_1| = \sqrt{18} = 3\sqrt{2}$，$|\vec{s}_2| = \sqrt{9} = 3$。
  代入夹角公式：
  $$\cos\theta = \frac{|9|}{3\sqrt{2}\times 3} = \frac{\sqrt{2}}{2} \implies \theta = \frac{\pi}{4}$$
- **答案**：$\frac{\pi}{4}$。

#### 过定点求平面的垂线方程
- **题干**：求过点 $(1, -2, 4)$ 且与平面 $2x - 3y + z - 4 = 0$ 垂直的直线方程。
- **解析**：
  线面垂直则直线的方向向量与平面的法向量平行。平面的法向量为 $\vec{n} = (2, -3, 1)$，直接取直线的方向向量 $\vec{s} = (2, -3, 1)$。由点向式直接写出方程。
- **答案**：$\frac{x - 1}{2} = \frac{y + 2}{-3} = \frac{z - 4}{1}$。

#### 求平行于两平面交线的直线方程
- **题干**：求过点 $(-3, 2, 5)$ 且与两平面 $x - 4z = 3$ 和 $2x - y - 5z = 1$ 的交线平行的直线方程。
- **解析**：
  两平面的法向量分别为 $\vec{n}_1 = (1, 0, -4)$，$\vec{n}_2 = (2, -1, -5)$。
  交线方向向量为两法向量的叉乘：
  $$\vec{s} = \vec{n}_1 \times \vec{n}_2 = (-4, -3, -1)$$
  取同向正向量 $\vec{s} = (4, 3, 1)$。结合已知点 $(-3, 2, 5)$ 写出点向式方程。
- **答案**：$\frac{x + 3}{4} = \frac{y - 2}{3} = \frac{z - 5}{1}$。

#### 直线与平面的交点求解
- **题干**：求直线 $\frac{x - 2}{1} = \frac{y - 3}{1} = \frac{z - 4}{2}$ 与平面 $2x + y + z - 6 = 0$ 的交点。
- **解析**：
  将直线设为参数式：$x = 2 + t, y = 3 + t, z = 4 + 2t$。
  代入平面方程：$2(2 + t) + (3 + t) + (4 + 2t) - 6 = 0 \implies 5t + 5 = 0 \implies t = -1$。
  代回参数式求出坐标：$x = 1, y = 2, z = 2$。
- **答案**：交点坐标为 $(1, 2, 2)$。

#### 过点且与已知直线垂直相交的直线方程
- **题干**：求过点 $A(2, 1, 3)$ 且与直线 $L: \frac{x + 1}{3} = \frac{y - 1}{2} = \frac{z}{-1}$ 垂直相交的直线方程。
- **解析**：
  设两直线交点为 $B(-1 + 3t, 1 + 2t, -t)$。
  所求直线方向向量为 $\vec{AB} = (3t - 3, 2t, -t - 3)$。
  两直线垂直则 $\vec{AB} \cdot \vec{s}_1 = 0$，其中 $\vec{s}_1 = (3, 2, -1)$：
  $$3(3t - 3) + 2(2t) + (-1)(-t - 3) = 0 \implies 14t - 6 = 0 \implies t = \frac{3}{7}$$
  代入求得 $\vec{AB} = \left(-\frac{12}{7}, \frac{6}{7}, -\frac{24}{7}\right) = -\frac{6}{7}(2, -1, 4)$。
  取方向向量 $\vec{s} = (2, -1, 4)$，结合定点 $A(2, 1, 3)$ 写出点向式。
- **答案**：$\frac{x - 2}{2} = \frac{y - 1}{-1} = \frac{z - 3}{4}$。

### 向量代数运算与几何特征

向量是整个空间解析几何的基石。在解析几何中，我们很少去生硬地做几何辅助线，而是把空间点、线、面的几何形态翻译成向量的模、夹角、垂直与平行。这一板块重点解决向量的坐标生成、共线判定、方向角体系以及两大乘法（数量积与向量积）的实战应用。

#### 两点确定向量与共线判定

在空间直角坐标系中，任何几何线段的定向都可以归结为由起点指向终点的向量。这是最基础、但也最容易忙中出错的地方。

> **结论**：已知空间两点 $A(x_1, y_1, z_1)$ 与 $B(x_2, y_2, z_2)$，由 $A$ 指向 $B$ 的向量 $\vec{AB}$ 永远遵循“终点坐标减起点坐标”法则：
> $$\vec{AB} = (x_2 - x_1, y_2 - y_1, z_2 - z_1)$$

在做题时，写成有序数组的坐标形式 $(X, Y, Z)$ 最简捷；而在理论推导与严谨表述中，将其写成基本单位向量的线性组合 $X\vec{i} + Y\vec{j} + Z\vec{k}$ 则是最严格的。

两个非零向量共线（即空间位置互相平行），其几何特征在代数上表现为它们的分量必须完全成比例。

```text
向量平行（共线）几何示意：

       a ───> (a_x, a_y, a_z)
─────────────────────────────────────
       b ───────> (b_x, b_y, b_z)

代数充要条件： a_x / b_x = a_y / b_y = a_z / b_z = λ
```

> 上图展示了两向量在空间中相互平行时的几何形态与其代数坐标分量严格成比例的充要对应关系。

如果已知点 $A(1, 2, 3)$ 和点 $B(3, 5, t)$，由它们构成的向量为：
$$\vec{AB} = (3-1, 5-2, t-3) = (2, 3, t-3)$$
若已知 $\vec{AB}$ 与向量 $\vec{a} = (2, 3, 2)$ 平行，我们立刻列出对应分量的比例方程：
$$\frac{2}{2} = \frac{3}{3} = \frac{t-3}{2}$$
因为 $\frac{2}{2} = 1$，所以必有 $\frac{t-3}{2} = 1$，解得 $t - 3 = 2$，即 $t = 5$。

> **易错点**：遇到分量含未知数的平行判定题，心算时切忌把减号看漏或者移项变号出错。这类送分题一旦算错，整道大题后续的几何方程将全部崩溃。

#### 模长与方向角求解规范

向量的模刻画了空间位移的绝对长度，而方向余弦与方向角则给出了该向量在三维空间中的精确姿态。

> **定义**：设向量 $\vec{r} = (x, y, z)$，其模长定义为空间欧式距离：
> $$|\vec{r}| = \sqrt{x^2 + y^2 + z^2}$$
> 向量 $\vec{r}$ 与三条坐标轴正向的夹角分别记为 $\alpha, \beta, \gamma$（称为方向角），其取值范围严格限定在闭区间 $[0, \pi]$。各方向角的余弦值（称为方向余弦）由下式确定：
> $$\cos \alpha = \frac{x}{|\vec{r}|}, \quad \cos \beta = \frac{y}{|\vec{r}|}, \quad \cos \gamma = \frac{z}{|\vec{r}|}$$
> 且恒满足归一化恒等式：$\cos^2 \alpha + \cos^2 \beta + \cos^2 \gamma = 1$。

例如已知空间两点 $A(1, 1, -\sqrt{2})$ 与 $B(2, 2, 0)$，要求向量 $\vec{AB}$ 的模、方向余弦及方向角：
1. 先求向量分量：$\vec{AB} = (2-1, 2-1, 0-(-\sqrt{2})) = (1, 1, \sqrt{2})$；
2. 计算模长：$|\vec{AB}| = \sqrt{1^2 + 1^2 + (\sqrt{2})^2} = \sqrt{1 + 1 + 2} = \sqrt{4} = 2$；
3. 代入求方向余弦：
   $$\cos \alpha = \frac{1}{2}, \quad \cos \beta = \frac{1}{2}, \quad \cos \gamma = \frac{\sqrt{2}}{2}$$
4. 求解方向角：因为 $\cos \alpha = \frac{1}{2}$ 且 $\alpha \in [0, \pi]$，得 $\alpha = \frac{\pi}{3}$；同理 $\beta = \frac{\pi}{3}$；由 $\cos \gamma = \frac{\sqrt{2}}{2}$ 得 $\gamma = \frac{\pi}{4}$。

> **注意**：方向角完全可能是钝角！当且仅当向量在某坐标轴上的投影分量为负数时，其方向余弦值为负，此时对应的方向角必落在 $(\frac{\pi}{2}, \pi]$ 之内。反三角函数取值时千万不可盲目套用锐角。

#### 数量积与向量积的运算法则

点乘（数量积）与叉乘（向量积）是空间解析几何中使用频次最高、期末考试必考的两个代数工具。

| 运算类型 | 记号 | 结果性质 | 坐标运算法则 | 几何核心意义 |
| :--- | :--- | :--- | :--- | :--- |
| 数量积（点乘） | $\vec{a} \cdot \vec{b}$ | 纯量（标量） | $a_x b_x + a_y b_y + a_z b_z$ | 判定正交垂直（$\vec{a} \cdot \vec{b} = 0 \iff \vec{a} \perp \vec{b}$） |
| 向量积（叉乘） | $\vec{a} \times \vec{b}$ | 向量（矢量） | 三阶行列式展开 | 构造同时垂直于 $\vec{a}, \vec{b}$ 的法向量；模为所夹平行四边形面积 |
| 混合积 | $(\vec{a} \times \vec{b}) \cdot \vec{c}$ | 纯量（标量） | 先叉乘得到向量，再与第三向量做点乘 | 模为三向量张成的平行六面体体积；共面判定 |

数量积的计算极为直观，对应分量相乘再求和。例如若 $\vec{a} = (1, -2, -3)$，$\vec{b} = (2, 2, -3)$，则：
$$\vec{a} \cdot \vec{b} = 1\times 2 + (-2)\times 2 + (-3)\times (-3) = 2 - 4 + 9 = 7$$
若求 $2(\vec{a} \cdot \vec{b})$，纯量倍乘直接计算得 $2 \times 7 = 14$。

相比之下，向量积的计算相对繁琐，要求严格掌握三阶行列式展开流程：
$$\vec{a} \times \vec{b} = \begin{vmatrix} \vec{i} & \vec{j} & \vec{k} \\ a_x & a_y & a_z \\ b_x & b_y & b_z \end{vmatrix} = \begin{vmatrix} a_y & a_z \\ b_y & b_z \end{vmatrix}\vec{i} - \begin{vmatrix} a_x & a_z \\ b_x & b_z \end{vmatrix}\vec{j} + \begin{vmatrix} a_x & a_y \\ b_x & b_y \end{vmatrix}\vec{k}$$

> **易错点**：计算中间第二项（$\vec{j}$ 的分量）时，划去第一行第二列后算出的二阶行列式前面**必须添上负号**！无数同学在考场上把这个负号漏掉，导致整个法向量方向全错。

以 $\vec{a} = (1, -2, -3)$，$\vec{b} = (2, 2, -3)$ 为例：
- $\vec{i}$ 分量：$\begin{vmatrix} -2 & -3 \\ 2 & -3 \end{vmatrix} = (-2)(-3) - (-3)(2) = 6 - (-6) = 12$；
- $\vec{j}$ 分量：$-\begin{vmatrix} 1 & -3 \\ 2 & -3 \end{vmatrix} = -[1(-3) - (-3)(2)] = -[-3 - (-6)] = -3$；
- $\vec{k}$ 分量：$\begin{vmatrix} 1 & -2 \\ 2 & 2 \end{vmatrix} = 1(2) - (-2)(2) = 2 - (-4) = 6$。

因此得到 $\vec{a} \times \vec{b} = (12, -3, 6)$。
如果要计算 $(3\vec{a}) \times (2\vec{b})$，利用纯量乘法的结合律与分配律，系数可直接提出外层：
$$(3\vec{a}) \times (2\vec{b}) = 3 \times 2 (\vec{a} \times \vec{b}) = 6(12, -3, 6) = (72, -18, 36)$$

若进一步求混合积 $((3\vec{a}) \times (2\vec{b})) \cdot \vec{c}$，其中 $\vec{c} = (2, 1, 3)$：
课本中混合积虽然带有星号，但千万不要把它当成高深未测的神秘概念。在实战解题中，根本无需强行套用三阶坐标混合行列式，直接遵循“先算前两者的叉乘，再与第三者点乘”的自然两步走即可：
$$((3\vec{a}) \times (2\vec{b})) \cdot \vec{c} = (72, -18, 36) \cdot (2, 1, 3) = 72 \times 2 + (-18) \times 1 + 36 \times 3 = 144 - 18 + 108 = 234$$

#### 空间图形的向量积面积公式

在二维平面几何中，求三角形面积往往要费尽心机找底边和高；但在三维空间中，底和高在空间倾斜摆放，投影极为复杂，强行找高只会把题目做死。解析几何处理空间面积的唯一标准武器就是向量积的模。

```text
空间向量积与面积几何对应：

        C
       / \
      /   \
  AC /     \
    /   S   \
   /         \
  A ──────────> B
        AB

平行四边形面积 S_▱ = |AB × AC|
三角形面积     S_△ = (1/2) |AB × AC|
```

> 上图说明了空间三角形面积如何通过两边向量的叉乘模长直接折半计算，从而免去三维空间中繁琐的作垂线找高步骤。

> **结论**：空间任意三个不共线点 $A, B, C$ 构成的三角形面积，等于两邻边向量 $\vec{AB}$ 与 $\vec{AC}$ 叉乘向量模长的一半：
> $$S_{\triangle ABC} = \frac{1}{2} |\vec{AB} \times \vec{AC}|$$

在具体计算时，$\vec{AB} \times \vec{AC}$ 与 $\vec{AC} \times \vec{AB}$ 仅相差一个负号，由于外层取的是向量模长，谁在前谁在后对最终面积结果毫无影响。

例如由三点计算得两邻边向量分别为 $\vec{AB}$ 与 $\vec{AC}$，叉乘计算得到法向矢量，以坐标分量绝对值为 $9, 4, 1$ 为例：
1. 模长计算：
   $$|\vec{n}| = \sqrt{9^2 + (-4)^2 + 1^2} = \sqrt{81 + 16 + 1} = \sqrt{98} = 7\sqrt{2}$$
2. 求半得三角形面积：
   $$S = \frac{1}{2} \times 7\sqrt{2} = \frac{7}{2}\sqrt{2}$$

### 空间平面方程的构建方法

求空间平面方程，本质上就是寻找确立平面姿态的“一法一点”——已知法向量 $\vec{n} = (A, B, C)$ 与平面上一点 $M_0(x_0, y_0, z_0)$，平面的点法式方程便水到渠成。整个解题过程的核心难点全在“如何从花样繁多的几何条件中提取出法向量”。

#### 点法式构建与法向量提取

点法式方程是平面解析几何的核心表达式：
$$A(x - x_0) + B(y - y_0) + C(z - z_0) = 0$$

> **提示**：解题时务必牢记，点法式只是书写平面方程的中间步骤，最终答案在试卷上必须展开、合并同类项，化为一般式 $Ax + By + Cz + D = 0$。

在最典型的位置关系中，若要求一个平面过给定点 $M_0(1, 2, 3)$ 且垂直于已知直线 $\frac{x-x_1}{2} = \frac{y-y_1}{4} = \frac{z-z_1}{5}$：
空间中直线垂直于平面，意味着直线的方向正好就是平面的法线方向。因此，直线的方向向量天然地成为平面的法向量：
$$\vec{n} = \vec{s} = (2, 4, 5)$$
点有了，法向量有了，直接代入点法式：
$$2(x - 1) + 4(y - 2) + 5(z - 3) = 0$$
去括号展开化简：
$$2x - 2 + 4y - 8 + 5z - 15 = 0 \implies 2x + 4y + 5z - 25 = 0$$

#### 空间已知顶点确定平面的叉乘法

已知不在同一直线上的三点 $A(2, 2, 1), B(1, 0, 3), C(0, 3, -2)$，求过这三点的平面方程。面对这类经典题，通常有两种截然不同的解题思路。

```text
三点定面几何叉乘法：

            C
           ^
          /
      AC /
        /
       A ───────> B
           AB

法向量 n = AB × AC 同时垂直于平面内两不共线向量
```

> 上图直观呈现了利用平面内任意两不共线向量的叉乘运算，直接构造垂直于该平面的法向量的过程。

第一种思路是代入待定系数法：设平面一般式为 $Ax + By + Cz + D = 0$。将三点坐标分别代入，得到一个包含 4 个未知数、3 个方程的齐次线性方程组。有些同学试图强行解出 $A, B, C, D$ 的绝对数值，结果发现根本解不出来——因为平面方程各项同乘任意非零常数均等价，方程组本就有无穷多组解。必须用其中一个未知数（例如 $C$）去表达其余三个变量：
$$A = -\frac{4}{5}C, \quad B = \frac{7}{5}C, \quad D = -\frac{11}{5}C$$
然后再回代入方程，两边同除以 $C$ 并消去分母。这种方法计算极其繁杂，符号层层嵌套，考场上极易算晕。

强烈推荐第二种思路——几何叉乘法：
三点既然在同一平面内，两两相连得到的向量 $\vec{AB}$ 与 $\vec{AC}$ 必定完全落在该平面上。那么，这两条向量的叉乘向量必与该平面处处垂直，也就是平面的法向量！
1. 求两向量坐标：
   $$\vec{AB} = (1-2, 0-2, 3-1) = (-1, -2, 2)$$
   $$\vec{AC} = (0-2, 3-2, -2-1) = (-2, 1, -3)$$
2. 叉乘计算法向量：
   $$\vec{n} = \vec{AB} \times \vec{AC} = \begin{vmatrix} \vec{i} & \vec{j} & \vec{k} \\ -1 & -2 & 2 \\ -2 & 1 & -3 \end{vmatrix}$$
   - $x$ 分量：$(-2)(-3) - 2(1) = 6 - 2 = 4$；
   - $y$ 分量：$-[(-1)(-3) - 2(-2)] = -(3 + 4) = -7$；
   - $z$ 分量：$(-1)(1) - (-2)(-2) = -1 - 4 = -5$。
   得到法向量 $\vec{n} = (4, -7, -5)$。
3. 写点法式：三点中任意一点皆可使用，推荐选取含有坐标 $0$ 的点 $B(1, 0, 3)$，计算最简：
   $$4(x - 1) - 7(y - 0) - 5(z - 3) = 0$$
   展开合并：
   $$4x - 4 - 7y - 5z + 15 = 0 \implies 4x - 7y - 5z + 11 = 0$$
相比繁重的消元法，叉乘法步骤清晰，几乎没有任何算错的死角。

#### 坐标轴平行平面的法向量构造

求平行于某坐标轴且过两已知点的平面方程。很多教材在这一节总结了各类“特殊平面方程的缺项规律”（如平行于 $y$ 轴的平面必缺 $y$ 项，设为 $Ax + Cz + D = 0$）。

> **提示**：死记缺项公式非常容易在紧张时记混。最稳健的办法是画草图进行几何受力分析式推理：利用坐标轴的基底向量构造叉乘。

若平面平行于 $y$ 轴，意味着 $y$ 轴的延伸方向与平面平行，那么平面的法线必定与 $y$ 轴垂直！
$y$ 轴的方向向量就是标准基底 $\vec{j} = (0, 1, 0)$。
同时，平面过点 $A(1, 0, 1)$ 与点 $B(0, 1, -1)$（或向量分量已知为 $\vec{AB} = (1, -1, 2)$），说明平面的法向量也必须与向量 $\vec{AB}$ 垂直。

两个垂直线索一碰头，平面的法向量呼之欲出——直接对 $\vec{AB}$ 与 $\vec{j}$ 做叉乘：
$$\vec{n} = \vec{AB} \times \vec{j} = \begin{vmatrix} \vec{i} & \vec{j} & \vec{k} \\ 1 & -1 & 2 \\ 0 & 1 & 0 \end{vmatrix} = (-2, 0, 1)$$

> **拓展辨析**：
> - 若平面平行于 $x$ 轴，则法向量垂直于 $\vec{i} = (1, 0, 0)$；
> - 若平面平行于 $y$ 轴，则法向量垂直于 $\vec{j} = (0, 1, 0)$；
> - 若平面平行于 $z$ 轴，则法向量垂直于 $\vec{k} = (0, 0, 1)$。

法向量 $\vec{n} = (-2, 0, 1)$ 拿到手后，取已知点 $(1, 0, 1)$ 写点法式：
$$-2(x - 1) + 0(y - 0) + 1(z - 1) = 0 \implies -2x + 2 + z - 1 = 0 \implies -2x + z + 1 = 0$$
在规范的解析几何书写中，一般式首项 $x$ 的系数习惯上化为正数，两边同乘以 $-1$，最终写为：
$$2x - z - 1 = 0$$

#### 双重垂直与双重平行的空间定位

空间几何中最具综合性的两类求面问题，是通过与其他两个几何对象的正交或平行关系建立约束：

```text
空间法向量双重垂直示意：

       n_1 (面 1 法向量)
        ^       n_2 (面 2 法向量)
        │      ^
        │     /
        │    /
        │   /
        └───┼───────> n = n_1 × n_2 (所求平面法向量)
```

> 上图说明了当所求平面同时垂直于两个已知平面时，其法向量必与两已知法向量同时正交，可通过二者叉乘直接解出。

1. **与两个已知平面垂直**：
   若所求平面同时垂直于平面 $\Pi_1$ 与平面 $\Pi_2$，根据立体几何定理，所求平面的法线必定同时垂直于 $\Pi_1$ 的法向量 $\vec{n}_1$ 与 $\Pi_2$ 的法向量 $\vec{n}_2$。
   因此，所求平面的法向量可直接由两已知法向量叉乘获得：$\vec{n} = \vec{n}_1 \times \vec{n}_2$。
   例如已知 $\Pi_1: 2x + 2y - z = 0$ 与 $\Pi_2: 3x - y - z = 0$，提取法向量 $\vec{n}_1 = (2, 2, -1)$，$\vec{n}_2 = (3, -1, -1)$。
   叉乘计算得：$\vec{n}_1 \times \vec{n}_2 = (-3, -1, -8)$。
   我们既可以直接用 $(-3, -1, -8)$，也可以取其反向向量 $(3, 1, 8)$ 作为法向量（同一直线上的反向向量完全等价）。过给定点 $(1, 2, -1)$ 写点法式：
   $$3(x - 1) + 1(y - 2) + 8(z - (-1)) = 0 \implies 3x + y + 8z + 3 = 0$$

2. **与两条已知直线平行且过原点**：
   若所求平面与直线 $L_1$、直线 $L_2$ 均平行，则平面的法向量必定与两直线的方向向量 $\vec{s}_1, \vec{s}_2$ 均正交。
   法向量直接取 $\vec{n} = \vec{s}_1 \times \vec{s}_2$。
   这里常常潜伏着一个关于直线方程形式的考查：若 $L_1$ 为对称式 $\frac{x}{1} = \frac{y}{2} = \frac{z}{1}$，其方向向量显然为 $\vec{s}_1 = (1, 2, 1)$；但若 $L_2$ 给的是参数式方程：
   $$\begin{cases} x = 1 \\ y = -1 + t \\ z = 2 + t \end{cases}$$
   很多同学不知道如何提取其方向向量。我们可以通过还原对称式来观察：
   $x = 1$ 实际上意味着参数 $t$ 的系数为 $0$，即 $x = 1 + 0t \implies t = \frac{x - 1}{0}$；其余两式为 $t = \frac{y + 1}{1}, t = \frac{z - 2}{1}$。
   因此，参数中 $t$ 前面的系数即为直线的方向分量！直接读出 $\vec{s}_2 = (0, 1, 1)$。
   叉乘计算平面的法向量：
   $$\vec{n} = \vec{s}_1 \times \vec{s}_2 = \begin{vmatrix} \vec{i} & \vec{j} & \vec{k} \\ 1 & 2 & 1 \\ 0 & 1 & 1 \end{vmatrix} = (1, -1, 1)$$
   由于平面过原点 $(0, 0, 0)$，直接写出方程：
   $$1(x - 0) - 1(y - 0) + 1(z - 0) = 0 \implies x - y + z = 0$$

### 空间直线方程的表示与转换

在三维空间中，直线可以被视为动点沿某一方向匀速移动的轨迹（点向式与参数式），也可以被视为两个不平行平面的交线（一般式）。掌握不同直线形式之间的转换与直线上动点的参数化表示，是攻克线面综合大题的杀手锏。

#### 点向式方程的记号保留规范

已知直线上一点 $M_0(x_0, y_0, z_0)$ 与方向向量 $\vec{s} = (m, n, p)$，直线的点向式（对称式）方程为：
$$\frac{x - x_0}{m} = \frac{y - y_0}{n} = \frac{z - z_0}{p}$$

在实际书写中，有两个极其关键的规范和习惯需要注意：
1. **书写节奏**：写对称式时，最流畅且不易出错的习惯是先写分子中的点坐标，即先写好 $\frac{x - x_0}{\square} = \frac{y - y_0}{\square} = \frac{z - z_0}{\square}$，再将方向向量的三个分量一气呵成填入分母。
2. **方向分量为零的处理**：若直线的方向向量中某分量为 0，例如过点 $M_1(5, 2, -3)$ 与 $M_2(-1, 2, 3)$ 的直线，两点相减得向量 $(-6, 0, 6)$。提取公因数化简后方向向量取 $\vec{s} = (-1, 0, 1)$。写出的点向式为：
   $$\frac{x - 5}{-1} = \frac{y - 2}{0} = \frac{z + 3}{1}$$

> **易错点**：千万不要以为分母不能为 0，就自作聪明地把分母为 0 的项移项拆开，或者把分母为 1 的 1 省略不写！这里的等比形式是一种约定俗成的代数简记法，其严格含义是 $x - 5 = -(z + 3)$ 且 $y - 2 = 0$。在解析几何中，分母出现 0 必须原汁原味地保留在分母位置。

#### 两平面交线向对称式与参数式的转化

期末考试非常喜欢给出用两平面相交表示的一般式直线方程：
$$\begin{cases} A_1x + B_1y + C_1z + D_1 = 0 \\ A_2x + B_2y + C_2z + D_2 = 0 \end{cases}$$
这类方程无法直接读出直线的方向和经过的点。将其转化为对称式与参数式，必须完成两个核心步骤：

```text
两平面交线的一般式转对称式：

     平面 1 (法向量 n_1)
         \       /  平面 2 (法向量 n_2)
          \     /
           \   /
            \ /
   ──────────X──────────> 方向向量 s = n_1 × n_2
          交线 L
```

> 上图描绘了两相交平面的法向量叉乘后，所得向量的方向恰好完全贴合该两平面公共交线的延伸方向。

1. **求方向向量 $\vec{s}$**：
   直线作为两平面的交线，必然同时完全躺在两个平面内。因此，直线的延伸方向必定同时与两平面的法线正交：
   $$\vec{s} = \vec{n}_1 \times \vec{n}_2$$
2. **寻找直线上任意一点**：
   一条直线由无穷多个点组成，我们只需要找出其中任意一个特殊点。常规操作是令三坐标之一为 0（令 $x=0$、令 $y=0$ 或令 $z=0$），然后求解关于剩余两个未知数的二元一次方程组。

例如给定交线一般式方程：
$$\begin{cases} x - y + z - 1 = 0 \\ 2x + y + z - 4 = 0 \end{cases}$$
- 第一步，求法向量的叉乘：两平面法向量分别为 $\vec{n}_1 = (1, -1, 1)$，$\vec{n}_2 = (2, 1, 1)$。
  $$\vec{s} = \vec{n}_1 \times \vec{n}_2 = \begin{vmatrix} \vec{i} & \vec{j} & \vec{k} \\ 1 & -1 & 1 \\ 2 & 1 & 1 \end{vmatrix} = (-2, 1, 3)$$
- 第二步，求直线上一点：令 $y = 0$，原方程组简化为：
  $$\begin{cases} x + z - 1 = 0 \\ 2x + z - 4 = 0 \end{cases}$$
  下式减上式立刻解得 $x = 3$，代回得 $z = -2$。于是求出直线上一个特异点坐标 $(3, 0, -2)$。
- 第三步，写出对称式方程：
  $$\frac{x - 3}{-2} = \frac{y - 0}{1} = \frac{z - (-2)}{3} \implies \frac{x - 3}{-2} = \frac{y}{1} = \frac{z + 2}{3}$$
- 第四步，引入参数 $t$，将每一项单独解出，得到参数式方程：
  令 $\frac{x - 3}{-2} = \frac{y}{1} = \frac{z + 2}{3} = t$，则：
  $$\begin{cases} x = 3 - 2t \\ y = t \\ z = -2 + 3t \end{cases}$$

#### 空间动点的参数化表示与垂足求解

直线的参数式方程是处理“两线垂直相交”、“线面交点”等几何约束问题威力最大的代数工具。参数式用单个变量 $t$ 把空间直线上千千万万个动点的坐标全部统一刻画了出来。

考虑一个典型高频题型：求过点 $A(2, 1, 3)$ 且与已知直线 $L_1: \frac{x+1}{3} = \frac{y-1}{2} = \frac{z}{-1}$ 既垂直又相交的直线 $L_2$ 的方程。

```text
过已知点且与已知直线垂直相交：

     A (2, 1, 3)
      │
      │ 向量 AB ⊥ s_1
      ▼
──────B(t)─────────────────────> 直线 L_1 (方向向量 s_1)
   垂足交点 (参数化表达)
```

> 上图展示了借助已知直线的单参数方程将未知交点参数化，再通过正交垂直点乘为零建立方程求解参数的完整闭环。

解题关键在于：所求直线 $L_2$ 与已知直线 $L_1$ 相交于某点 $B$，而点 $B$ 既然在 $L_1$ 上，就必须服从 $L_1$ 的参数分布律！
1. 建立动点坐标：设 $L_1$ 的参数方程为：
   $$\begin{cases} x = -1 + 3t \\ y = 1 + 2t \\ z = -t \end{cases}$$
   因此交点 $B$ 的坐标可明确设为 $B(-1 + 3t, 1 + 2t, -t)$。
2. 构造连接向量：所求直线的方向向量正是从已知点 $A$ 指向交点 $B$ 的向量 $\vec{AB}$：
   $$\vec{AB} = (-1 + 3t - 2, 1 + 2t - 1, -t - 3) = (3t - 3, 2t, -t - 3)$$
3. 施加垂直正交约束：直线 $L_2$ 垂直于 $L_1$，意味着方向向量 $\vec{AB}$ 必须垂直于 $L_1$ 的方向向量 $\vec{s}_1 = (3, 2, -1)$，两者的数量积必定恒等于 0：
   $$\vec{AB} \cdot \vec{s}_1 = 0$$
   代入坐标展开计算：
   $$3(3t - 3) + 2(2t) + (-1)(-t - 3) = 0$$
   $$9t - 9 + 4t + t + 3 = 0 \implies 14t - 6 = 0 \implies t = \frac{3}{7}$$
4. 确定方向向量分量并化简：将 $t = \frac{3}{7}$ 回代入向量 $\vec{AB}$：
   $$\vec{AB} = \left(3\left(\frac{3}{7}\right) - 3, 2\left(\frac{3}{7}\right), -\frac{3}{7} - 3\right) = \left(-\frac{12}{7}, \frac{6}{7}, -\frac{24}{7}\right)$$
   直线的方向向量只在乎方向比例，不在乎长度。我们提出公因子 $\frac{6}{7}$：
   $$\vec{AB} = \frac{6}{7}(-2, 1, -4)$$
   直接选取最简整数组 $(-2, 1, -4)$（或反向的 $(2, -1, 4)$）作为直线 $L_2$ 的方向向量！
5. 写出直线方程：过点 $A(2, 1, 3)$，方向向量为 $(-2, 1, -4)$：
   $$\frac{x - 2}{-2} = \frac{y - 1}{1} = \frac{z - 3}{-4}$$

### 位置关系判定与空间几何度量

空间解析几何的最终目标，是判定不同维度几何实体之间的相对姿态，并计算它们之间的距离与夹角。在这一板块中，概念辨析的严谨性与公式细节的精确度决定了一切。

#### 空间平面之间的位置关系与非钝角夹角

两个空间平面 $\Pi_1: A_1x + B_1y + C_1z + D_1 = 0$ 与 $\Pi_2: A_2x + B_2y + C_2z + D_2 = 0$，其相对位置关系完全由法向量 $\vec{n}_1 = (A_1, B_1, C_1)$ 与 $\vec{n}_2 = (A_2, B_2, C_2)$ 的代数特征主导。

```text
平面位置关系判定树：

                  ┌─── 两法向量成比例 (平行)
                  │       ├── 常数项比例全等 ───> 重合
                  │       └── 常数项比例不等 ───> 平行 (且不重合)
两平面相对位置 ───┤
                  └─── 两法向量不成比例
                          ├── 点乘等于零 ───────> 垂直
                          └── 点乘不等于零 ─────> 斜交
```

> 上图展示了两平面相对位置关系的层次化判别逻辑树：先根据法向量是否成比例判断平行与否，再依次细分重合、平行、垂直与斜交。

判定流程极其清晰：
1. **第一步看平行**：观察 $\vec{n}_1$ 与 $\vec{n}_2$ 的分量是否成比例。若成比例，再核对常数项之比 $\frac{D_1}{D_2}$ 是否一致。如果全部等比例，则两平面为同一平面，属于**重合**；若仅系数成比例而常数项不成比例，则两平面**平行**。
   > **易错点**：很多初学者以为重合是平行的一种特殊情况。必须明确澄清：在解析几何的命题规范中，判定结果若为平行，指的必须是“平行且不重合”！
2. **第二步看垂直与斜交**：若法向量不成比例，则必相交。进一步计算数量积 $\vec{n}_1 \cdot \vec{n}_2$：若为 0，则两平面**垂直**；若不为 0，则两平面属于一般的相交，即**斜交**。

在计算两平面的夹角时，有一个致命的三角约束必须铭记于心：
> **注意**：两向量的夹角可以取钝角（范围 $[0, \pi]$）；但**两平面的夹角、两直线的夹角、直线与平面的夹角绝对不能取钝角**！平面夹角被定义为两平面相交构成的二面角中的较小者（锐角或直角），取值范围恒为 $[0, \frac{\pi}{2}]$。

因此，两平面的夹角余弦公式分子**必须无条件加上绝对值**：
$$\cos \theta = \frac{|\vec{n}_1 \cdot \vec{n}_2|}{|\vec{n}_1||\vec{n}_2|}$$
例如求平面 $x + y = 0$ 与平面 $3x = 0$ 的夹角：
提取法向量 $\vec{n}_1 = (1, 1, 0)$，$\vec{n}_2 = (3, 0, 0)$。
$$\cos \theta = \frac{|1\times 3 + 1\times 0 + 0\times 0|}{\sqrt{1^2 + 1^2 + 0^2}\sqrt{3^2 + 0^2 + 0^2}} = \frac{3}{\sqrt{2} \times 3} = \frac{1}{\sqrt{2}} = \frac{\sqrt{2}}{2}$$
因为 $\theta \in [0, \frac{\pi}{2}]$ 且题目要求的是求夹角而非夹角余弦，必须明确写出弧度值：$\theta = \frac{\pi}{4}$。

#### 空间直线的夹角与线面交点解算

1. **两直线的夹角**：
   与平面夹角完全一致，两直线的夹角同样限定在 $[0, \frac{\pi}{2}]$ 之内，其公式分子同样必须加绝对值：
   $$\cos \theta = \frac{|\vec{s}_1 \cdot \vec{s}_2|}{|\vec{s}_1||\vec{s}_2|}$$
   例如直线 $L_1$ 的方向向量 $\vec{s}_1 = (1, -4, 1)$，直线 $L_2$ 的方向向量 $\vec{s}_2 = (2, -2, -1)$：
   - 点乘：$1\times 2 + (-4)\times(-2) + 1\times(-1) = 2 + 8 - 1 = 9$；
   - 模长：$|\vec{s}_1| = \sqrt{1 + 16 + 1} = \sqrt{18} = 3\sqrt{2}$，$|\vec{s}_2| = \sqrt{4 + 4 + 1} = \sqrt{9} = 3$；
   - 余弦值：$\cos \theta = \frac{|9|}{3\sqrt{2} \times 3} = \frac{\sqrt{2}}{2} \implies \theta = \frac{\pi}{4}$。

2. **直线与平面的交点求解**：
   求已知直线与已知平面的交点坐标，最干净利落的办法依然是参数化代入法。
   设有直线 $\frac{x+2}{2} = \frac{y-3}{-3} = \frac{z-5}{-1}$ 与平面 $3x + y - 2z - 7 = 0$。
   - 设直线参数为 $t$，写出空间点的坐标表达式：
     $$x = -2 + 2t, \quad y = 3 - 3t, \quad z = 5 - t$$
   - 将动点坐标代入平面方程：
     $$3(-2 + 2t) + (3 - 3t) - 2(5 - t) - 7 = 0$$
     $$-6 + 6t + 3 - 3t - 10 + 2t - 7 = 0 \implies 5t - 20 = 0 \implies t = 4$$
   - 将解出的参数值 $t = 4$ 回代入动点坐标：
     $$x = -2 + 2(4) = 6, \quad y = 3 - 3(4) = -9, \quad z = 5 - 4 = 1$$
   交点坐标直接锁定为 $(6, -9, 1)$。

#### 直线与平面的位置关系与术语规范

判定直线与平面的位置关系，需要联立考察直线的方向向量 $\vec{s}$ 与平面的法向量 $\vec{n}$：

```text
线面相对位置几何示意：

1. 直线垂直于平面：          2. 直线平行于平面：          3. 直线落在平面上：
          n                           n                           n
          ^                           ^                           ^
          │                           │                           │
  ────────┼──────> 直线 s             │                           │
          │                   ────────┴─────────> 直线 s          │
    ┌─────┴─────┐               ┌───────────┐               ┌─────┴─────┐
    │   平面    │               │   平面    │               │ ──s──────>│ 直线
    └───────────┘               └───────────┘               └───────────┘
     s ∥ n (成比例)               s ⊥ n (点乘为0)             s ⊥ n (点乘为0)
                                且点不在平面上              且点在平面上
```

> 上图对比展示了直线与平面的三种典型位置形态：方向向量与法向量平行对应线面垂直，正交则根据点是否在面内区分为线面平行或直线落在平面上。

- 若 $\vec{s} \parallel \vec{n}$（两向量分量成比例），则直线的方向与平面的法向重合，几何结论为**直线垂直于平面**。
- 若 $\vec{s} \perp \vec{n}$（即 $\vec{s} \cdot \vec{n} = 0$），此时直线的方向横向平行于平面，但这包含两种可能：直线浮在平面上方（平行），或者直线完全没入平面之中（在平面内）。
  为了加以区分，只需在直线上任取一点（从点向式分子可直接读出），代入平面方程：
  - 若该点不满足平面方程，则判定为**直线平行于平面**；
  - 若该点完全满足平面方程，则判定为**直线落在平面上**。

> **易错点**：针对直线完全位于平面内的情形，在表述上**绝对不能说“直线与平面重合”**！重合是针对同维度对象而言的（两平面重合、两直线重合）；而直线是一维几何对象，平面是二维几何对象，两者维度不对等，绝不可能发生“重合”。规范的学术用语唯有“**直线落在平面上**”（或“直线在平面内”）。

#### 点到平面距离公式与正交投影点

点到平面的度量包含两个核心指标：标量层面的距离，以及矢量层面的正交投影坐标。

1. **点到平面的距离**：
   > **公式**：空间点 $P(x_0, y_0, z_0)$ 到平面 $Ax + By + Cz + D = 0$ 的距离为：
   > $$d = \frac{|Ax_0 + By_0 + Cz_0 + D|}{\sqrt{A^2 + B^2 + C^2}}$$

   > **易错点**：使用该公式前，必须确保平面方程右端已经移项归零！如果平面方程写为 $4x - 5y + 3z = 1$，常数项必须先挪到左边写成 $-1$，否则分子代入时绝对值内部常数项极性颠倒，全盘皆输。

   例如计算点 $(2, 0, 3)$ 到平面 $4x - 5y + 3z = 1$ 的距离：
   平面整理为 $4x - 5y + 3z - 1 = 0$。
   $$d = \frac{|4(2) - 5(0) + 3(3) - 1|}{\sqrt{4^2 + (-5)^2 + 3^2}} = \frac{|8 + 0 + 9 - 1|}{\sqrt{16 + 25 + 9}} = \frac{16}{\sqrt{50}} = \frac{16}{5\sqrt{2}} = \frac{8\sqrt{2}}{5}$$

2. **点在平面上的正交投影点求解**：
   若已知点 $A(-1, 2, 0)$ 和平面 $x + 2y - z + 1 = 0$，求点 $A$ 在平面上的正交投影点 $B$：
   投影点 $B$ 本质上就是从 $A$ 点向平面引垂线所得的垂足。
   - 垂线的方向向量天然就是平面的法向量 $\vec{n} = (1, 2, -1)$；
   - 垂线过点 $A(-1, 2, 0)$，其参数方程为：
     $$x = -1 + t, \quad y = 2 + 2t, \quad z = -t$$
   - 垂足 $B$ 是垂线与平面的交点，将参数方程代入平面：
     $$(-1 + t) + 2(2 + 2t) - (-t) + 1 = 0$$
     $$-1 + t + 4 + 4t + t + 1 = 0 \implies 6t + 4 = 0 \implies t = -\frac{2}{3}$$
   - 将 $t = -\frac{2}{3}$ 回代入参数方程，即得投影点 $B$ 坐标：
     $$x = -1 - \frac{2}{3} = -\frac{5}{3}, \quad y = 2 + 2\left(-\frac{2}{3}\right) = \frac{2}{3}, \quad z = -\left(-\frac{2}{3}\right) = \frac{2}{3}$$
     即投影点为 $B\left(-\frac{5}{3}, \frac{2}{3}, \frac{2}{3}\right)$。

此结果可直接通过两点间距离公式进行交叉核验：
$$|\vec{AB}| = \sqrt{\left(-\frac{5}{3} - (-1)\right)^2 + \left(\frac{2}{3} - 2\right)^2 + \left(\frac{2}{3} - 0\right)^2} = \sqrt{\left(-\frac{2}{3}\right)^2 + \left(-\frac{4}{3}\right)^2 + \left(\frac{2}{3}\right)^2} = \frac{\sqrt{4 + 16 + 4}}{3} = \frac{\sqrt{24}}{3} = \frac{2\sqrt{6}}{3}$$
而由点到平面距离公式计算：
$$d = \frac{|-1 + 2(2) - 0 + 1|}{\sqrt{1^2 + 2^2 + (-1)^2}} = \frac{4}{\sqrt{6}} = \frac{2\sqrt{6}}{3}$$
两法所得完全吻合，形成严密闭环。

### 本讲提到的题目

本节完整汇集了本讲教学中出现的全部 20 道经典习题，题干、完整解题推导与最终答案均严格还原。

#### 向量运算与几何特征题

**向量共线未知参数求解**
- **题干**：已知空间点 $A(1, 2, 3)$ 和点 $B(3, 5, t)$，且由它们构成的向量 $\vec{AB}$ 与已知向量 $\vec{a} = (2, 3, 2)$ 平行，求未知数 $t$ 的值。
- **解析**：由两点坐标先求出向量：$\vec{AB} = (3-1, 5-2, t-3) = (2, 3, t-3)$。两向量平行，其对应坐标分量成比例：$\frac{2}{2} = \frac{3}{3} = \frac{t-3}{2}$。由于 $\frac{2}{2} = 1$，必有 $\frac{t-3}{2} = 1 \implies t - 3 = 2 \implies t = 5$。
- **答案**：$t = 5$

**向量模长、方向余弦与方向角**
- **题干**：已知空间点 $A(1, 1, -\sqrt{2})$ 与点 $B(2, 2, 0)$，求向量 $\vec{AB}$ 的模、方向余弦以及方向角。
- **解析**：
  1. 向量坐标：$\vec{AB} = (2-1, 2-1, 0-(-\sqrt{2})) = (1, 1, \sqrt{2})$；
  2. 模长：$|\vec{AB}| = \sqrt{1^2 + 1^2 + (\sqrt{2})^2} = \sqrt{4} = 2$；
  3. 方向余弦：$\cos \alpha = \frac{1}{2}, \cos \beta = \frac{1}{2}, \cos \gamma = \frac{\sqrt{2}}{2}$；
  4. 方向角：在 $[0, \pi]$ 范围内求角，得 $\alpha = \frac{\pi}{3}, \beta = \frac{\pi}{3}, \gamma = \frac{\pi}{4}$。
- **答案**：模长为 $2$；方向余弦为 $\left(\frac{1}{2}, \frac{1}{2}, \frac{\sqrt{2}}{2}\right)$；方向角为 $\alpha = \frac{\pi}{3}, \beta = \frac{\pi}{3}, \gamma = \frac{\pi}{4}$。

**数量积、向量积与混合积综合计算**
- **题干**：已知向量 $\vec{a} = (1, -2, -3)$，$\vec{b} = (2, 2, -3)$，$\vec{c} = (2, 1, 3)$，分别求：
  1. $2(\vec{a} \cdot \vec{b})$；
  2. $(3\vec{a}) \times (2\vec{b})$；
  3. $((3\vec{a}) \times (2\vec{b})) \cdot \vec{c}$。
- **解析**：
  1. $\vec{a} \cdot \vec{b} = 1\times 2 + (-2)\times 2 + (-3)\times (-3) = 2 - 4 + 9 = 7$。因此 $2(\vec{a} \cdot \vec{b}) = 2 \times 7 = 14$；
  2. $(3\vec{a}) \times (2\vec{b}) = 6(\vec{a} \times \vec{b})$。三阶行列式展开：
     $$\vec{a} \times \vec{b} = \begin{vmatrix} \vec{i} & \vec{j} & \vec{k} \\ 1 & -2 & -3 \\ 2 & 2 & -3 \end{vmatrix} = (6 - (-6))\vec{i} - (-3 - (-6))\vec{j} + (2 - (-4))\vec{k} = (12, -3, 6)$$
     因此 $(3\vec{a}) \times (2\vec{b}) = 6(12, -3, 6) = (72, -18, 36)$；
  3. 混合积直接点乘：
     $$(72, -18, 36) \cdot (2, 1, 3) = 72\times 2 + (-18)\times 1 + 36\times 3 = 144 - 18 + 108 = 234$$
- **答案**：(1) $14$；(2) $(72, -18, 36)$；(3) $234$。

**三维空间三角形面积求解**
- **题干**：已知三维空间中三角形的顶点构成两邻边向量 $\vec{AB}$ 与 $\vec{AC}$，经计算其分量满足 $\vec{AB} \times \vec{AC} = (9, -4, 1)$，求此三角形的面积。
- **解析**：空间三角形面积等于以两邻边为边张成的平行四边形面积的一半：$S = \frac{1}{2} |\vec{AB} \times \vec{AC}|$。计算向量积的模：$|\vec{AB} \times \vec{AC}| = \sqrt{9^2 + (-4)^2 + 1^2} = \sqrt{81 + 16 + 1} = \sqrt{98} = 7\sqrt{2}$。故三角形面积为 $S = \frac{7\sqrt{2}}{2}$。
- **答案**：$\frac{7\sqrt{2}}{2}$

#### 平面与直线方程构建题

**过一点且垂直于直线的平面方程**
- **题干**：求过点 $(1, 2, 3)$ 且垂直于直线 $\frac{x}{2} = \frac{y}{4} = \frac{z}{5}$ 的平面方程。
- **解析**：直线垂直于平面，直线的方向向量即为平面的法向量：$\vec{n} = (2, 4, 5)$。由点法式直接写出方程：$2(x - 1) + 4(y - 2) + 5(z - 3) = 0 \implies 2x + 4y + 5z - 25 = 0$。
- **答案**：$2x + 4y + 5z - 25 = 0$

**过已知顶点确定平面方程**
- **题干**：求过不共线三点 $A(2, 2, 1), B(1, 0, 3), C(0, 3, -2)$ 的平面方程。
- **解析**：
  构造平面内两向量：
  $$\vec{AB} = (1-2, 0-2, 3-1) = (-1, -2, 2)$$
  $$\vec{AC} = (0-2, 3-2, -2-1) = (-2, 1, -3)$$
  平面的法向量由两向量叉乘获得：
  $$\vec{n} = \vec{AB} \times \vec{AC} = \begin{vmatrix} \vec{i} & \vec{j} & \vec{k} \\ -1 & -2 & 2 \\ -2 & 1 & -3 \end{vmatrix} = (4, -7, -5)$$
  选用点 $B(1, 0, 3)$ 写出点法式：$4(x - 1) - 7(y - 0) - 5(z - 3) = 0 \implies 4x - 7y - 5z + 11 = 0$。
- **答案**：$4x - 7y - 5z + 11 = 0$

**平行于坐标轴且过两点的平面方程**
- **题干**：求平行于 $y$ 轴且过两点 $A(1, 0, 1)$ 与点 $B$（两点间向量为 $\vec{AB} = (1, -1, 2)$）的平面方程。
- **解析**：平面平行于 $y$ 轴，则法向量垂直于 $y$ 轴方向向量 $\vec{j} = (0, 1, 0)$，同时垂直于 $\vec{AB}$：
  $$\vec{n} = \vec{AB} \times \vec{j} = \begin{vmatrix} \vec{i} & \vec{j} & \vec{k} \\ 1 & -1 & 2 \\ 0 & 1 & 0 \end{vmatrix} = (-2, 0, 1)$$
  过点 $(1, 0, 1)$ 写点法式：$-2(x - 1) + 0(y - 0) + 1(z - 1) = 0 \implies -2x + z + 1 = 0 \implies 2x - z - 1 = 0$。
- **答案**：$2x - z - 1 = 0$

**过一点且与两已知平面垂直的平面方程**
- **题干**：求过点 $(1, 2, -1)$ 且与两平面 $\Pi_1: 2x + 2y - z = 0$ 和 $\Pi_2: 3x - y - z = 0$ 均垂直的平面方程。
- **解析**：所求平面的法向量垂直于已知两平面的法向量 $\vec{n}_1 = (2, 2, -1)$ 与 $\vec{n}_2 = (3, -1, -1)$：
  $$\vec{n} = \vec{n}_1 \times \vec{n}_2 = (-3, -1, -8)$$
  取等价法向量为反向向量 $(3, 1, 8)$，代入点法式：$3(x - 1) + 1(y - 2) + 8(z - (-1)) = 0 \implies 3x + y + 8z + 3 = 0$。
- **答案**：$3x + y + 8z + 3 = 0$

**与两直线平行且过原点的平面方程**
- **题干**：求过原点 $(0, 0, 0)$ 且与直线 $L_1: \frac{x}{1} = \frac{y}{2} = \frac{z}{1}$ 以及直线 $L_2: \begin{cases} x = 1 \\ y = -1 + t \\ z = 2 + t \end{cases}$ 均平行的平面方程。
- **解析**：$L_1$ 方向向量为 $\vec{s}_1 = (1, 2, 1)$；$L_2$ 从参数提取方向向量为 $\vec{s}_2 = (0, 1, 1)$。平面的法向量正交于两直线方向：
  $$\vec{n} = \vec{s}_1 \times \vec{s}_2 = \begin{vmatrix} \vec{i} & \vec{j} & \vec{k} \\ 1 & 2 & 1 \\ 0 & 1 & 1 \end{vmatrix} = (1, -1, 1)$$
  过原点写点法式：$1(x - 0) - 1(y - 0) + 1(z - 0) = 0 \implies x - y + z = 0$。
- **答案**：$x - y + z = 0$

**过两点的空间直线方程**
- **题干**：求过点 $M_1(5, 2, -3)$ 与点 $M_2(-1, 2, 3)$ 的直线对称式方程。
- **解析**：由两点坐标得向量：$\vec{M_1M_2} = (-1-5, 2-2, 3-(-3)) = (-6, 0, 6)$。提取公因子化简方向向量为 $\vec{s} = (-1, 0, 1)$。选取点 $M_1$ 写出点向式：$\frac{x - 5}{-1} = \frac{y - 2}{0} = \frac{z + 3}{1}$。
- **答案**：$\frac{x - 5}{-1} = \frac{y - 2}{0} = \frac{z + 3}{1}$

**过一点且垂直于平面的直线方程**
- **题干**：求过点 $(2, -1, 5)$ 且垂直于平面 $x - 5y + 3z = 0$ 的直线方程。
- **解析**：直线垂直于平面，直线的方向向量直接取平面的法向量：$\vec{s} = \vec{n} = (1, -5, 3)$。过点 $(2, -1, 5)$ 写出对称式：$\frac{x - 2}{1} = \frac{y + 1}{-5} = \frac{z - 5}{3}$。
- **答案**：$\frac{x - 2}{1} = \frac{y + 1}{-5} = \frac{z - 5}{3}$

**两平面交线向对称式与参数式的转化**
- **题干**：将直线的交线方程 $\begin{cases} x - y + z - 1 = 0 \\ 2x + y + z - 4 = 0 \end{cases}$ 转化为对称式与参数式方程。
- **解析**：
  1. 方向向量：两平面法向量为 $\vec{n}_1 = (1, -1, 1), \vec{n}_2 = (2, 1, 1)$。
     $$\vec{s} = \vec{n}_1 \times \vec{n}_2 = (-2, 1, 3)$$
  2. 直线上一点：令 $y = 0$，解方程组 $\begin{cases} x + z = 1 \\ 2x + z = 4 \end{cases}$ 得 $x = 3, z = -2$。点为 $(3, 0, -2)$。
  3. 对称式：$\frac{x - 3}{-2} = \frac{y}{1} = \frac{z + 2}{3}$；
  4. 参数式：令比值为 $t$，得 $\begin{cases} x = 3 - 2t \\ y = t \\ z = -2 + 3t \end{cases}$。
- **答案**：对称式为 $\frac{x - 3}{-2} = \frac{y}{1} = \frac{z + 2}{3}$；参数式为 $\begin{cases} x = 3 - 2t \\ y = t \\ z = -2 + 3t \end{cases}$。

**过已知点与已知直线垂直相交的直线方程**
- **题干**：求过点 $A(2, 1, 3)$ 且与直线 $L_1: \frac{x+1}{3} = \frac{y-1}{2} = \frac{z}{-1}$ 既垂直又相交的直线方程。
- **解析**：
  1. 设交点 $B$ 在 $L_1$ 上，写出其参数坐标：$B(-1 + 3t, 1 + 2t, -t)$；
  2. 构造连接向量：$\vec{AB} = (3t - 3, 2t, -t - 3)$；
  3. 垂直条件 $\vec{AB} \cdot \vec{s}_1 = 0$（$\vec{s}_1 = (3, 2, -1)$）：
     $$3(3t - 3) + 2(2t) - (-t - 3) = 0 \implies 14t - 6 = 0 \implies t = \frac{3}{7}$$
  4. 回代得 $\vec{AB} = \left(-\frac{12}{7}, \frac{6}{7}, -\frac{24}{7}\right) = \frac{6}{7}(-2, 1, -4)$。
  5. 取方向向量为 $(-2, 1, -4)$，过点 $A(2, 1, 3)$ 写方程：$\frac{x - 2}{-2} = \frac{y - 1}{1} = \frac{z - 3}{-4}$。
- **答案**：$\frac{x - 2}{-2} = \frac{y - 1}{1} = \frac{z - 3}{-4}$

#### 位置关系与度量求解题

**两平面相对位置关系辨析**
- **题干**：分别判定下列各对平面的相对位置关系：
  1. $2x + y - z = 1$ 与 $6x + 3y - 3z = 3$；
  2. $x - y - z = 0$ 与 $2x + 4y - 6z = 1$；
  3. $5x + 3y - z = 0$ 与 $x - 6y - 3z = 2$；
  4. $2x + y - z = 1$ 与 $6x + 3y - 3z = 5$。
- **解析**：
  1. 法向量 $\vec{n}_1 = (2, 1, -1), \vec{n}_2 = (6, 3, -3)$。满足 $\frac{2}{6} = \frac{1}{3} = \frac{-1}{-3} = \frac{1}{3}$，常数项比值同样为 $\frac{1}{3}$。两方程实质完全一致，为**重合**；
  2. 法向量 $\vec{n}_1 = (1, -1, -1), \vec{n}_2 = (2, 4, -6)$。点乘为 0 时对应互相垂直，判定为**垂直**；
  3. 法向量 $\vec{n}_1 = (5, 3, -1), \vec{n}_2 = (1, -6, -3)$。不成比例，点乘不为 0。判定为**斜交**；
  4. 系数满足 $\frac{2}{6} = \frac{1}{3} = \frac{-1}{-3}$，而常数项比值为 $\frac{1}{5} 
e \frac{1}{3}$。判定为**平行**（平行且不重合）。
- **答案**：(1) 重合；(2) 垂直；(3) 斜交；(4) 平行。

**两平面夹角求解**
- **题干**：求两平面 $x + y = 0$ 与 $3x = 0$ 的夹角 $\theta$。
- **解析**：提取法向量 $\vec{n}_1 = (1, 1, 0), \vec{n}_2 = (3, 0, 0)$。夹角余弦公式（分子带绝对值）：
  $$\cos \theta = \frac{|\vec{n}_1 \cdot \vec{n}_2|}{|\vec{n}_1||\vec{n}_2|} = \frac{|3|}{\sqrt{2} \times 3} = \frac{\sqrt{2}}{2}$$
  由于 $\theta \in [0, \frac{\pi}{2}]$，解得 $\theta = \frac{\pi}{4}$。
- **答案**：$\frac{\pi}{4}$

**点到平面的距离计算**
- **题干**：求点 $(2, 0, 3)$ 到平面 $4x - 5y + 3z = 1$ 的距离。
- **解析**：平面方程右端归零化为 $4x - 5y + 3z - 1 = 0$。代入距离公式：
  $$d = \frac{|4(2) - 5(0) + 3(3) - 1|}{\sqrt{4^2 + (-5)^2 + 3^2}} = \frac{|8 + 0 + 9 - 1|}{\sqrt{16 + 25 + 9}} = \frac{16}{\sqrt{50}} = \frac{16}{5\sqrt{2}} = \frac{8\sqrt{2}}{5}$$
- **答案**：$\frac{8\sqrt{2}}{5}$

**两直线夹角求解**
- **题干**：求直线 $L_1$（方向向量 $\vec{s}_1 = (1, -4, 1)$）与直线 $L_2$（方向向量 $\vec{s}_2 = (2, -2, -1)$）之间的夹角 $\theta$。
- **解析**：
  $$\cos \theta = \frac{|\vec{s}_1 \cdot \vec{s}_2|}{|\vec{s}_1||\vec{s}_2|} = \frac{|1\times 2 + (-4)\times (-2) + 1\times (-1)|}{\sqrt{1 + 16 + 1}\sqrt{4 + 4 + 1}} = \frac{|2 + 8 - 1|}{\sqrt{18}\sqrt{9}} = \frac{9}{3\sqrt{2}\times 3} = \frac{\sqrt{2}}{2}$$
  因此夹角 $\theta = \frac{\pi}{4}$。
- **答案**：$\frac{\pi}{4}$

**直线与平面的交点求解**
- **题干**：求直线 $\frac{x+2}{2} = \frac{y-3}{-3} = \frac{z-5}{-1}$ 与平面 $3x + y - 2z - 7 = 0$ 的交点。
- **解析**：设直线参数方程为 $x = -2 + 2t, y = 3 - 3t, z = 5 - t$。代入平面方程：
  $$3(-2 + 2t) + (3 - 3t) - 2(5 - t) - 7 = 0 \implies 5t - 20 = 0 \implies t = 4$$
  将 $t = 4$ 代入参数方程，得 $x = 6, y = -9, z = 1$。
- **答案**：$(6, -9, 1)$

**直线与平面的相对位置关系判定**
- **题干**：
  1. 判定直线 $\frac{x-2}{3} = \frac{y+2}{1} = \frac{z-3}{-4}$ 与平面 $x + y + z - 3 = 0$ 的相对位置关系；
  2. 判定法向量为 $\vec{n} = (1, \frac{1}{2}, -\frac{1}{4})$ 的平面与交线方向向量为 $\vec{s} = (-28, -14, 7)$ 的直线的相对位置关系。
- **解析**：
  1. 直线方向向量 $\vec{s} = (3, 1, -4)$，平面法向量 $\vec{n} = (1, 1, 1)$。计算点乘：$\vec{s} \cdot \vec{n} = 3(1) + 1(1) + (-4)(1) = 0$，说明 $\vec{s} \perp \vec{n}$。取直线上一点 $(2, -2, 3)$ 代入平面方程：$2 + (-2) + 3 - 3 = 0$，方程成立。说明直线上该点完全落在平面内，判定结果为**直线落在平面上**；
  2. 平面法向量 $\vec{n} = (1, \frac{1}{2}, -\frac{1}{4})$ 放大 4 倍得 $(4, 2, -1)$；直线的方向向量 $\vec{s} = (-28, -14, 7) = -7(4, 2, -1)$。两向量完全成比例，即 $\vec{s} \parallel \vec{n}$，判定结果为**直线垂直于平面**。
- **答案**：(1) 直线落在平面上；(2) 直线垂直于平面。

**点在平面上的投影点与距离**
- **题干**：已知空间点 $A(-1, 2, 0)$ 与平面 $x + 2y - z + 1 = 0$：
  1. 求点 $A$ 到平面的距离；
  2. 求点 $A$ 在平面上的正交投影点 $B$ 的坐标。
- **解析**：
  1. 距离计算：
     $$d = \frac{|-1 + 2(2) - 0 + 1|}{\sqrt{1^2 + 2^2 + (-1)^2}} = \frac{4}{\sqrt{6}} = \frac{2\sqrt{6}}{3}$$
  2. 投影点求解：过点 $A$ 且以平面法向量 $\vec{n} = (1, 2, -1)$ 为方向向量的垂线参数方程为：
     $$x = -1 + t, \quad y = 2 + 2t, \quad z = -t$$
     代入平面方程：
     $$(-1 + t) + 2(2 + 2t) - (-t) + 1 = 0 \implies 6t + 4 = 0 \implies t = -\frac{2}{3}$$
     回代得坐标：$x = -1 - \frac{2}{3} = -\frac{5}{3}, y = 2 - \frac{4}{3} = \frac{2}{3}, z = \frac{2}{3}$。
- **答案**：(1) 距离为 $\frac{2\sqrt{6}}{3}$；(2) 投影点为 $\left(-\frac{5}{3}, \frac{2}{3}, \frac{2}{3}\right)$。
