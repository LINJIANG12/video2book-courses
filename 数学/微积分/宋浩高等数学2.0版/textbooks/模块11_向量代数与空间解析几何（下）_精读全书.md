## 空间曲面基础：球面、旋转曲面、柱面与二次曲面精读讲义
> 对应块：BLK57 | 覆盖分集：P74 | 块标题（分集名）：《72 曲面基本问题 旋转曲面 柱面》

在进入三维空间解析几何后，我们研究几何图形的基本思路，与初高中在二维平面直角坐标系中完全相通：由点到线，由线到面。在平面解析几何中，我们研究直线与二次曲线；到了三维空间，一个方程 $F(x, y, z) = 0$ 通常代表一个空间曲面。面对浩瀚的空间图形，我们怎么研究？最基础、最直观的曲面是什么？从最简单的球面出发，再到空间旋转形成的旋转曲面、平行拉伸得到的柱面，最后归纳总结出一类极其重要的二次曲面。这一讲我们就把空间曲面的基本机理、作图与方程求解彻底吃透。

### 球面及其几何方程

#### 球面的几何定义与标准方程推导

什么是球面？大家在初中就知道平面上的圆：平面内到定点的距离等于定长的所有点的集合。把这个概念平移到三维空间，原理完全一样：空间中到定点的距离等于定长的所有点组成的几何图形，就叫做**球面**。

定点叫做**球心**，定长叫做**半径**。注意在三维空间中，我们要严谨地称其为球心，不再叫圆心。

设球心为 $M_0(x_0, y_0, z_0)$，半径为 $R$。任取球面上任意一点 $M(x, y, z)$。由空间两点间的距离公式，动点 $M$ 与球心 $M_0$ 的距离满足：

$$|MM_0| = \sqrt{(x-x_0)^2 + (y-y_0)^2 + (z-z_0)^2} = R$$

两边同时平方以去掉根号，即得到球面的标准方程：

$$(x-x_0)^2 + (y-y_0)^2 + (z-z_0)^2 = R^2$$

> **定义**：以点 $M_0(x_0, y_0, z_0)$ 为球心、以 $R$ 为半径的球面标准方程为 $(x-x_0)^2 + (y-y_0)^2 + (z-z_0)^2 = R^2$。

特别地，如果球心恰好位于坐标原点 $(0, 0, 0)$，则 $x_0 = 0, y_0 = 0, z_0 = 0$，球面方程立刻简化为最常见、最工整的形式：

$$x^2 + y^2 + z^2 = R^2$$

#### 关键辨析：球面与球体

这里必须严格区分一对概念：**球面**和**球体**。

很多人脱口而出觉得它们是一回事，其实差别巨大：**球面是空心的，球体是实心的**。

球面只是外面那一层薄薄的壳，属于二维曲面，它对应的代数关系是严格的**等式**：

$$(x-x_0)^2 + (y-y_0)^2 + (z-z_0)^2 = R^2$$

而球体不仅包含这层外皮，还包含外皮内部包裹着的所有内部空间点，属于三维立体区域。它的代数关系必须写成**不等式**：

$$(x-x_0)^2 + (y-y_0)^2 + (z-z_0)^2 \le R^2$$

> **易错点**：等号表示空心曲面（球面），小于等于号表示实心区域（球体）。后续在学习多元微积分、计算重积分与高斯公式时，积分区域究竟是边界曲面还是内部立体区域，全看这里是等号还是不等号。

#### 配方法求解球面方程与代数特征

在考试中，题目往往不会直接给出标准方程，而是给出一个展开的二次多项式方程，需要我们判断其曲面类型并确定几何参数。

> **例题**：判断方程 $x^2 + y^2 + z^2 - 2x + 4y = 0$ 表示怎样的曲面？

解题思路非常直接：将同变量的项分别组合，利用配方法化为完全平方式：

$$(x^2 - 2x) + (y^2 + 4y) + z^2 = 0$$

第一项配成完全平方需加 $1$，第二项配成完全平方需加 $4$。等号左边总共增加了 $1 + 4 = 5$，为了保持恒等，等号右边也必须同步加 $5$：

$$(x^2 - 2x + 1) + (y^2 + 4y + 4) + z^2 = 5$$

$$(x-1)^2 + (y+2)^2 + z^2 = 5$$

将此结果与球面标准方程 $(x-x_0)^2 + (y-y_0)^2 + (z-z_0)^2 = R^2$ 对比：
- 球心坐标为 $M_0(1, -2, 0)$；
- 半径为 $R = \sqrt{5}$。

因此，该方程表示以 $(1, -2, 0)$ 为球心、以 $\sqrt{5}$ 为半径的球面。

由该例题可以提炼出识别球面方程的三个核心规律：

> **结论**：
> 1. **二次项系数全等**：$x^2, y^2, z^2$ 三项的系数必须完全相等且同号。若系数不为 1，必须能同除该系数化为 1；
> 2. **绝无交叉乘积项**：方程中绝对不能出现 $xy, yz, zx$ 交叉项；
> 3. **一次项自由出现**：可以包含 $x, y, z$ 的一次项，它们通过配方决定球心坐标相对于坐标原点的平移偏移量。

### 旋转曲面的形成原理与快速求解法

#### 旋转曲面的几何机理与代数推导

什么是旋转曲面？在平面直角坐标系中有一条平面曲线，让它围绕同一平面内的一条固定直线（旋转轴）旋转一周（$360^\circ$），在三维空间中所扫过的曲面，就叫做**旋转曲面**。

很多同学看课本推导感到吃力，因为教材里一会儿开根号、一会儿加绝对值和正负号。其实只要抓住几何本质，推导极其顺畅。

以课本经典模型为例：设在 $yOz$ 坐标面内有一条平面曲线 $C$，其方程记为 $f(y, z) = 0$。现在让这条曲线绕 $z$ 轴旋转一周，求生成的曲面方程。

```text
           z 轴
            ^
            |       * M1(0, y1, z1) 原曲线上的动点
            |      /|
            |     / | 距离为 |y1| (旋转半径)
            |    /  |
    (0,0,z) +---o---+ - - - - - (水平截面圆，半径 r = |y1|)
           / \ /   /
          /   * M(x, y, z) 旋转后的空间动点：x^2 + y^2 = y1^2
         /   /
        +----------------> y 轴
       /
      v
    x 轴
```

读图说明：原曲线动点 $M_1$ 绕 $z$ 轴旋转时，竖向坐标 $z$ 保持不变；它到 $z$ 轴的距离 $|y_1|$ 为旋转圆半径，在空间任一位置的动点 $M(x, y, z)$ 均满足 $x^2 + y^2 = y_1^2$。

推导步骤如下：
1. **坚守不动轴**：设原曲线上的动点为 $M_1(0, y_1, z_1)$，满足 $f(y_1, z_1) = 0$。当该点绕 $z$ 轴做水平圆周旋转时，该点的高度没有发生任何升降。因此旋转后曲面上对应点 $M(x, y, z)$ 的竖坐标依然保持不变：
   $$z = z_1$$
2. **确定旋转圆半径**：动点 $M_1$ 绕 $z$ 轴旋转出的轨迹必然是一个平行于 $xOy$ 面的水平圆，圆心位于 $z$ 轴上的 $(0, 0, z)$。这个圆的半径就是动点 $M_1$ 到 $z$ 轴的垂直距离，即横向坐标的绝对值 $|y_1|$。
3. **建立空间代数关系**：在三维空间中，点 $M(x, y, z)$ 到 $z$ 轴的距离为 $\sqrt{x^2 + y^2}$。由于该点在圆周上，此距离必然等于圆半径 $|y_1|$：
   $$\sqrt{x^2 + y^2} = |y_1| \implies x^2 + y^2 = y_1^2 \implies y_1 = \pm\sqrt{x^2 + y^2}$$
4. **回代原曲线方程**：将 $z_1 = z$ 和 $y_1 = \pm\sqrt{x^2 + y^2}$ 代入原曲线方程 $f(y_1, z_1) = 0$，即得旋转曲面方程：
   $$f(\pm\sqrt{x^2 + y^2}, z) = 0$$

这里必须格外理清：原平面曲线中的 $y_1$ 是二维平面里的坐标，而生成曲面后的 $x$ 和 $y$ 是三维空间中的坐标变量。

#### 旋转曲面速算口诀与递进演练

在实际解题和考试中，大多数曲线方程天然带有变量的平方项。反复写正负号和根号容易引起计算混乱。为此，宋浩老师总结了一条极其实用的做题口诀：

> **核心口诀**：
> **围绕着谁旋转，谁就不动；另外的变量平方，直接替换成剩下两个变量的平方和（把缺少的那个变量补进来）！**

为什么可以这样做？因为绕哪个轴旋转，该轴对应的坐标值在旋转过程中始终保持不变；而垂直于该轴的平面截线必为圆，圆半径的平方正好等于垂直平面内另外两个坐标的平方和。

下面通过一系列典型题目进行实战演练：

##### 抛物线绕对称轴旋转

在 $yOz$ 面上有一条抛物线 $z = y^2$，绕 $z$ 轴旋转 $360^\circ$，求所成曲面方程。
- 绕 $z$ 轴旋转 $\implies z$ 不动；
- 将 $y^2$ 直接替换为剩下两个变量的平方和 $x^2 + y^2$；
- 直接写出曲面方程：
  $$z = x^2 + y^2$$
此曲面称为**旋转抛物面**。

##### 改变旋转轴方向

在 $xOy$ 面上有一条抛物线 $y = x^2$，绕 $y$ 轴旋转 $360^\circ$，求所成曲面方程。
- 绕 $y$ 轴旋转 $\implies y$ 不动；
- 空间中缺少变量 $z$，将 $x^2$ 替换为剩下两个变量的平方和 $x^2 + z^2$；
- 得到方程：
  $$y = x^2 + z^2$$

##### 一次关系式转化为平方项

在 $yOz$ 面上有一条直线 $z = y$，绕 $z$ 轴旋转 $360^\circ$，求所成曲面方程。
- 原方程是一次形式，为使用平方和口诀，先对两边平方：$z^2 = y^2$；
- 绕 $z$ 轴旋转 $\implies z^2$ 不动；
- 将 $y^2$ 替换为 $x^2 + y^2$；
- 得到方程：
  $$z^2 = x^2 + y^2$$
一条过原点的倾斜直线绕竖直坐标轴旋转，形成的是一个**圆锥面**。

##### 椭圆绕不同轴旋转（橄榄球模型）

在 $xOy$ 面上有一标准椭圆 $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$：
- **情况一：绕 $y$ 轴旋转 $360^\circ$**
  - 绕 $y$ 轴旋转 $\implies y$ 项保持不动，即 $\frac{y^2}{b^2}$ 不变；
  - 缺 $z$ 变量，将 $x^2$ 替换为 $x^2 + z^2$；
  - 得到旋转椭球面方程：
    $$\frac{x^2 + z^2}{a^2} + \frac{y^2}{b^2} = 1$$
- **情况二：绕 $x$ 轴旋转 $360^\circ$**
  - 绕 $x$ 轴旋转 $\implies x$ 项保持不动，即 $\frac{x^2}{a^2}$ 不变；
  - 将 $y^2$ 替换为 $y^2 + z^2$；
  - 得到旋转椭球面方程：
    $$\frac{x^2}{a^2} + \frac{y^2 + z^2}{b^2} = 1$$
几何直观上，椭圆绕轴旋转如同旋转一个橄榄球，截面在垂直于旋转轴的方向上为正圆。

##### 圆锥面与半顶角的几何推导

一条动直线绕与它相交的定轴旋转一周，所生成的曲面叫做**圆锥面**。定轴叫旋转轴，交点叫顶点，两直线的锐夹角 $\alpha$ 叫做**半顶角**。

在 $yOz$ 面内取一条过原点的直线，它与旋转轴 $z$ 轴的夹角为 $\alpha$。
- 该直线与横轴 $y$ 轴正向的夹角即为 $90^\circ - \alpha$；
- 直线的斜率为 $k = \tan(90^\circ - \alpha) = \cot\alpha$；
- 该直线的平面方程为 $z = k y = (\cot\alpha) y$；
- 两边同时平方：$z^2 = y^2 \cot^2\alpha$；
- 让该直线绕 $z$ 轴旋转：$z^2$ 保持不动，将 $y^2$ 替换为 $x^2 + y^2$，即得圆锥面的标准方程：
  $$z^2 = (x^2 + y^2)\cot^2\alpha$$

##### 双曲线绕对称轴旋转

设在 $zOx$ 面上有一条双曲线 $\frac{x^2}{a^2} - \frac{z^2}{c^2} = 1$：
- **绕 $z$ 轴旋转（绕虚轴旋转）**：
  $z$ 轴项不动，将 $x^2$ 替换为 $x^2 + y^2$，得到：
  $$\frac{x^2 + y^2}{a^2} - \frac{z^2}{c^2} = 1$$
  曲面连成完整的一体，中间收腰，类似冷却塔，称为**单叶双曲面**。
- **绕 $x$ 轴旋转（绕实轴旋转）**：
  $x$ 轴项不动，将 $z^2$ 替换为 $y^2 + z^2$，得到：
  $$\frac{x^2}{a^2} - \frac{y^2 + z^2}{c^2} = 1$$
  原双曲线的两支各自旋转，在空间形成左右对称、互不连通的两个独立曲面，外形形似“两个分立的馒头”，称为**双叶双曲面**。

#### 易混辨析：旋转抛物面与圆锥面的纵剖面差异

在后续多元微积分（尤其是三重积分和曲面积分）中，有两个图形极易被同学混淆：
- 旋转抛物面：$z = x^2 + y^2$
- 圆锥面上半部分：$z = \sqrt{x^2 + y^2}$（即 $z^2 = x^2 + y^2, z \ge 0$）

很多同学疑惑：若用水平面 $z = c > 0$ 去截这两个曲面，截痕同样都是圆（$x^2 + y^2 = c$ 和 $x^2 + y^2 = c^2$），为什么前者的外边缘是平滑弯曲的深碗，而后者的外边缘是笔直倾斜的锥体？

要看清空间曲面的外轮廓形态，必须掌握**截痕法**：横着切看不出曲率差异，就纵向切一刀！

令 $y = 0$（即用纵向坐标面 $xOz$ 剖切曲面）：
1. 对 $z = x^2 + y^2$：令 $y = 0$，得到剖面线 $z = x^2$。这是一条标准抛物线，随着 $|x|$ 增大，斜率越来越陡，因而整个曲面是一个底部平缓、向上逐渐陡峭的平滑旋转碗状曲面；
2. 对 $z^2 = x^2 + y^2$：令 $y = 0$，得到剖面线 $z^2 = x^2 \implies z = \pm x$。这是两条通过原点的相交直线，斜率恒定，因而整个曲面的边缘是一条条直线母线，呈现出笔直刚挺的圆锥面。

```text
  【旋转抛物面纵截面】(y = 0)             【圆锥面纵截面】(y = 0)
         z 轴                                    z 轴
          |      z = x^2                          |      z = ±x
      \   |   /                               \   |   /
       \  |  /                                 \  |  /
        \_|_/                                   \ | /
          +---------> x 轴                        +---------> x 轴
                                                 / | \
      剖面为抛物线（平滑弯曲）                  /  |  \
      整体呈现碗状曲面                         /   |   \
                                       剖面为两条直线（笔直边界）
                                       整体呈现圆锥面
```

读图说明：截痕法通过令 $y=0$ 考察纵截面。$z=x^2$ 的二次曲线特性决定了抛物面的平滑弯曲，而 $z=\pm x$ 的线性关系决定了圆锥面由直线母线扫出的笔直锥体特征。

### 柱面的几何直观与方程判别

#### 柱面的几何定义与“缺少变量”的本质

什么是柱面？在空间中，一条动直线沿着一条固定的平面曲线移动，且在移动过程中始终平行于一个固定方向，这条动直线所扫过的曲面就叫做**柱面**。
- 这条固定的平面曲线叫做**准线**；
- 移动的动直线叫做**母线**。

形象地说，这就像拿一根垂直的棍子沿着案板上的曲线贴着转动一圈，棍子扫出的轨迹就是柱面。

在三维空间直角坐标系中，柱面有一个标志性的代数特征：

> **结论**：
> **在空间直角坐标系中，如果一个方程只含有两个坐标变量，缺少第三个坐标变量，它在空间中必然表示一个母线平行于缺失变量坐标轴的柱面！**

为什么？以方程 $x^2 + y^2 = R^2$ 为例：
- 在二维平面 $xOy$ 中，它是一个半径为 $R$ 的圆；
- 但在三维空间直角坐标系 $(x, y, z)$ 中，方程中完全没有出现变量 $z$。这意味着 $z$ 可以任意取值，无论 $z = 0, z = 1, z = -3, z = 100$，只要点 $(x, y)$ 满足 $x^2 + y^2 = R^2$，点 $(x, y, z)$ 就在曲面上；
- 这相当于将 $xOy$ 面上的那个圆，沿着平行于 $z$ 轴的方向上下无限平移拉伸，最终在空间中拉出了一个上下贯通的**圆柱面**。

#### 典型柱面解析与平面作为广义柱面

##### 圆柱面

方程为 $x^2 + y^2 = R^2$。缺少变量 $z$。准线为 $xOy$ 面上的圆，母线平行于 $z$ 轴上下无限延伸。

##### 抛物柱面

方程为 $y^2 = 2x$ 或 $x^2 = ay$。
- 以 $y^2 = 2x$ 为例，缺少变量 $z$；
- 在 $xOy$ 面上画出抛物线 $y^2 = 2x$；
- 因为 $z$ 可以任意取值，将此抛物线平行于 $z$ 轴向上、向下整体平移延伸，在空间中形成一个拱形板状曲面，称为**抛物柱面**。

##### 平面作为特殊的广义柱面

方程为 $y = x$ 或 $x + y = 1$。
- 很多初学者容易误认为这是一条直线。在三维空间中，缺少 $z$ 变量，意味着准线是一条直线；
- 将直线 $y = x$ 沿着平行于 $z$ 轴的方向上下移动，形成的是一个立在空间第一、三象限平分位置的**平面**；
- 同理，$x + y = 1$ 在空间中也是一个母线平行于 $z$ 轴的倾斜平面。平面本质上是准线为直线的特殊柱面。

##### 椭圆柱面与双曲柱面

- **椭圆柱面**：方程为 $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$。缺少变量 $z$。以 $xOy$ 面上的椭圆为准线，母线平行于 $z$ 轴拉伸；
- **双曲柱面**：方程为 $\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$。缺少变量 $z$。以 $xOy$ 面上的双曲线为准线，母线平行于 $z$ 轴延伸，由前后分离的两面瓦状曲面组成。

### 常见二次曲面与截痕分析法

#### 从旋转对称到伸缩变换：二次曲面的演化

什么是二次曲面？三元二次方程 $F(x, y, z) = 0$ 所表示的曲面，统称为二次曲面。

在前面研究旋转曲面时，我们发现旋转曲面具有天然的轴对称性，垂直于旋转轴的两个二次项系数必然完全相等（例如 $x^2 + y^2 = a^2 z^2$ 中 $x^2$ 和 $y^2$ 的系数相同）。

如果三维空间物体的对称性被打破，方程中两个变量的系数不再相等（例如 $\frac{x^2}{a^2} + \frac{y^2}{b^2} = z^2$，其中 $a 
e b$），曲面在几何上发生了什么改变？

其几何机理极其清晰：**伸缩变换**。相当于把原本具有圆对称性的旋转曲面，沿着某个坐标轴方向“朝里压一压”或“朝外拉一拉”。圆截面被拉伸成了椭圆，旋转曲面就推广演化为更普遍的一般二次曲面。

#### 六大常见二次曲面解析

通过截痕法，我们可以将高等数学中最重要的六大二次曲面彻底厘清：

##### 椭圆锥面

标准方程为 $\frac{x^2}{a^2} + \frac{y^2}{b^2} = \frac{z^2}{c^2}$（或 $\frac{x^2}{a^2} + \frac{y^2}{b^2} = z^2$）。
- 用水平面 $z = z_0 
e 0$ 切割，截痕为椭圆 $\frac{x^2}{a^2} + \frac{y^2}{b^2} = \frac{z_0^2}{c^2}$；
- 用纵向坐标面 $x = 0$ 或 $y = 0$ 切割，截痕为过原点的两条相交直线（$y = \pm\frac{b}{c} z$ 或 $x = \pm\frac{a}{c} z$）；
- 整体形态为顶点对顶点的两个椭圆锥体。

##### 椭球面

标准方程为 $\frac{x^2}{a^2} + \frac{y^2}{b^2} + \frac{z^2}{c^2} = 1$。
- 用平行于任意坐标平面的平面切割，截痕均为椭圆（截面超出范围时无实数解）；
- 若 $a = b = c$，曲面退化为正球面；若其中任意两个半轴长相等，为旋转椭球面；若三者互不相等，则是经过三向不同比例拉伸的封闭椭球面。

##### 单叶双曲面

标准方程为 $\frac{x^2}{a^2} + \frac{y^2}{b^2} - \frac{z^2}{c^2} = 1$。
- 代数特征：二次项为“两正一负”，常数项为正 $1$；
- 截痕分析：水平截面 $z = z_0$ 恒为椭圆 $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1 + \frac{z_0^2}{c^2}$。当 $z = 0$ 时截面最小，称为**颈椭圆**；
- 整个曲面连贯成单一整体，中间纤细、上下延展，形似小蛮腰。

##### 双叶双曲面

标准方程为 $\frac{x^2}{a^2} - \frac{y^2}{b^2} - \frac{z^2}{c^2} = 1$。
- 代数特征：二次项为“一正两负”，常数项为正 $1$。正项所对应的坐标轴即为曲面张开的方向轴；
- 截痕分析：由方程可知 $\frac{x^2}{a^2} = 1 + \frac{y^2}{b^2} + \frac{z^2}{c^2} \ge 1$，必须满足 $|x| \ge a$ 才有实数点。在 $-a < x < a$ 的空间区域内没有任何曲面存在；
- 曲面被完全阻断分离为两片，形成左右对称、独立分开的两个凸形罩面（“两个分立的馒头”）。

##### 椭圆抛物面

标准方程为 $z = \frac{x^2}{a^2} + \frac{y^2}{b^2}$。
- 代数特征：一边是一次项，另一边是两正二次项之和；
- 截痕分析：必有 $z \ge 0$。用水平面 $z = z_0 > 0$ 切割，截痕为椭圆；用垂直平面 $y = 0$ 切割，截痕为抛物线 $z = \frac{x^2}{a^2}$；用 $x = 0$ 切割，截痕为抛物线 $z = \frac{y^2}{b^2}$；
- 整个曲面形态为一个开口向上的椭圆底深碗。

##### 双曲抛物面（马鞍面）

标准方程为 $\frac{x^2}{a^2} - \frac{y^2}{b^2} = z$。
- 代数特征：一边是一次项，另一边是一正一负二次项之差；
- 它是所有二次曲面中立体形态最复杂、最难想象的一个，因外形酷似马背上的马鞍而得名。

#### 重点攻克：三刀剖切马鞍面

在学习高等数学时，很多同学面对双曲抛物面感到头晕手生。要彻底看透它的结构，不需要死记硬背，必须用截痕法切下三刀：

```text
                  z 轴 (向上)
                   |
             \     |     /   <-- y = 常数截面：开口向上的抛物线 z = x^2/a^2 - C
              \   _|_   /        (前后翘起的马鞍头尾)
               \_/ | \_/
                /  |  \
   ============/===+===\============ x 轴
             /    / \    \
            /    /   \    \  <-- x = 常数截面：开口向下的抛物线 z = -y^2/b^2 + C
           (    /     \    )     (左右垂下的马鞍两翼)
            \  /       \  /
             \/         \/
             /
            v y 轴
```

读图说明：双曲抛物面由三个方向截面共同交织而成。固定 $y$ 时剖面为开口向上的抛物线（支撑骑手的前后鞍桥），固定 $x$ 时剖面为开口向下的抛物线（跨在马背两旁的护腿下垂面），水平剖切时则展现为双曲线。

##### 第一刀：水平横切（令 $z$ 为常数）

假设用水平面 $z = 1$ 切割：
$$\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$$
截痕是一条以 $x$ 轴为实轴的标准双曲线。

若用水平面 $z = -1$ 切割：
$$\frac{x^2}{a^2} - \frac{y^2}{b^2} = -1 \implies \frac{y^2}{b^2} - \frac{x^2}{a^2} = 1$$
截痕依然是双曲线，但实轴变成了平行于 $y$ 轴的方向。水平截痕始终是双曲线，这也是它名字中“双曲”的来源。

##### 第二刀：侧向竖切（固定 $x$ 为常数）

取平行于 $yOz$ 面的平面 $x = 1$ 切割，代入方程得：
$$z = -\frac{y^2}{b^2} + \frac{1}{a^2}$$
注意观察 $y^2$ 前面的系数：它是一个**负数**！
这说明该剖截线是一条**开口向下的抛物线**。在几何上，这正是马鞍跨放在马背两侧、顺着马身向下耷拉下垂的形态。

##### 第三刀：正向竖切（固定 $y$ 为常数）

取平行于 $xOz$ 面的平面 $y = 1$ 切割，代入方程得：
$$z = \frac{x^2}{a^2} - \frac{1}{b^2}$$
注意观察 $x^2$ 前面的系数：它是一个**正数**！
这说明该剖截线是一条**开口向上的抛物线**。在几何上，这正是马鞍前后两头向上扬起、用来稳住骑手不至于前后滑落的鞍桥形态。

三刀切完，马鞍面的几何结构便一览无余：
- 沿着前后方向（$x$ 方向），它是向上扬起的抛物线；
- 沿着左右方向（$y$ 方向），它是向下弯曲的抛物线；
- 沿着水平方向（$z$ 方向），它是向四周扩散的双曲线。

### 空间二次曲面与柱面分类总结

为了便于复习自查和查阅对比，我们将本讲涉及的核心曲面整理为对照表格：

| 曲面类型 | 标准方程 | 二次项符号特征 | 典型截痕分析 | 几何外形特征 |
| :--- | :--- | :--- | :--- | :--- |
| **球面** | $(x-x_0)^2+(y-y_0)^2+(z-z_0)^2=R^2$ | 三项同号且系数全等 | 任意方向截面均为圆 | 空心对称球面 |
| **圆柱面** | $x^2 + y^2 = R^2$ | 缺 $z$ 变量 | 水平截面为圆，纵截面为平行线 | 母线平行于 $z$ 轴的圆筒 |
| **旋转抛物面** | $z = x^2 + y^2$ | 缺常数项，两正二次项同系数 | 水平截面为圆，纵截面为抛物线 | 平滑碗状曲面 |
| **圆锥面** | $z^2 = x^2 + y^2$ | 缺常数项，两正一负二次项 | 水平截面为圆，纵截面为相交直线 | 笔直外壁的顶对顶双锥面 |
| **椭球面** | $\frac{x^2}{a^2} + \frac{y^2}{b^2} + \frac{z^2}{c^2} = 1$ | 三个二次项全为正，常数项为 1 | 三个坐标截面均为椭圆 | 封闭的三向伸缩卵形体 |
| **单叶双曲面** | $\frac{x^2}{a^2} + \frac{y^2}{b^2} - \frac{z^2}{c^2} = 1$ | 两正一负，常数项为 1 | 水平截面为椭圆，纵截面为双曲线 | 连成一整块的小蛮腰冷却塔 |
| **双叶双曲面** | $\frac{x^2}{a^2} - \frac{y^2}{b^2} - \frac{z^2}{c^2} = 1$ | 一正两负，常数项为 1 | 沿正项轴截面为椭圆，中间断开 | 左右分立的两个独立馒头形罩面 |
| **椭圆抛物面** | $z = \frac{x^2}{a^2} + \frac{y^2}{b^2}$ | 一次项对两个同号二次项 | 水平截面为椭圆，纵截面为抛物线 | 椭圆底开口朝上的大碗 |
| **双曲抛物面** | $z = \frac{x^2}{a^2} - \frac{y^2}{b^2}$ | 一次项对一正一负二次项 | 水平截面为双曲线，正反纵截面正负抛物线 | 鞍桥翘起、两翼下垂的马鞍面 |

掌握空间曲面的核心在于两点：一是牢记**“围绕谁转谁不动，余者平方换平方和”**的旋转代换法则；二是熟练运用**“截痕法”**对曲面进行横向与纵向切片分析。将方程形式与几何空间直观紧密挂钩，后续遇到重积分的立体投影与曲面积分的曲面定向问题时，便能迅速下笔、胸有成竹。

## 向量的概念、运算与空间直角坐标系
> 对应块：BLK109 | 覆盖分集：P117 | 块标题（分集名）：《【黑板】向量的概念运算和空间直角坐标系》

先从一个动作说起吧。用力推一件东西的时候，我们关心的从来不只是“用了多大力”，还要问“朝哪个方向推”。大小和方向这两样信息合在一起，才完整地描述了这一次作用。我们把这样的对象叫作向量。

向量不是从天上掉下来的抽象名词。高中我们已经接触过它，只是那时常用力、位移这些具体的东西来感受它。现在进入空间解析几何，我们要把它放进三维坐标里，重新把它的符号、长度、方向以及运算关系一件件理清。

### 先抓住大小和方向

#### 有向线段记向量

用一个有向线段表示向量：箭头从起点指向终点。

```text
A ●──────────────● B
  ──────────────→
```

如果起点是 \(A\)，终点是 \(B\)，就记作

$$
\overrightarrow{AB}.
$$

这里的顺序很重要：\(\overrightarrow{AB}\) 是从 \(A\) 指向 \(B\)，不能把箭头方向忘掉。

在不同的书里，向量的记法会有差别。线性代数里常用 \(\alpha,\beta,\gamma\) 这样的希腊字母表示向量，而 \(A,B,C\) 往往被当作常数；那本书从头到尾都在讲向量，字母默认就是向量，加不加箭头反而没那么必要。进入高数的向量代数后，我们更常用带箭头的写法，把“这是向量”和“这是点或常数”区分开。

> **提示**：看到字母时，先看这套教材的约定，不要把线性代数里的字母习惯原封不动搬过来。

#### 自由向量：平移以后还是它

我们这里研究的向量叫作自由向量。自由的意思是，它和起点在哪里没有关系。把一段有向线段整体平移到别的位置，长度不变、方向不变，仍然表示同一个向量。

```text
A ●────────→● B

A'●────────→● B'
```

所以自由向量不是“被钉在某一条线段上”的东西。我们可以把不同起点、终点的有向线段放在一起比较，只要它们的长度和方向完全对应，就可以看成同一个向量。

> **定义**：自由向量是可以在空间中任意平移、而不改变其大小和方向的向量。

这一步为后面的运算准备了条件：既然起点不重要，我们就可以按需要把两个向量的起点挪到同一点，再把它们拼起来。

#### 模、单位向量与零向量

向量的模，也叫向量的大小，就是对应有向线段的长度。例如

$$
|\overrightarrow{AB}|=1,
$$

就表示这段有向线段的长度是 \(1\)。

线性代数里常用双竖线记向量的模；本讲采用单竖线记法。记号看起来不一样，说的都是“长度”，不要被写法吓住。

> **定义**：模等于 \(1\) 的向量叫作单位向量。

零向量则是一个特殊对象：它的长度等于 \(0\)，方向可以取任意方向。这里的“任意方向”不是说它同时拥有所有方向，而是说约定上无法再给它指定一个唯一方向。正因为如此，在本讲的约定里，零向量和任意向量都平行，也和任意向量都垂直。

> **易错点**：零向量不要按照普通向量去想象方向。它没有唯一的确定方向，长度和方向要分开记。

#### 夹角、平行与垂直

两个向量的夹角记作

$$
\angle(\vec a,\vec b),
$$

它的取值范围是 \(0\) 到 \(\pi\)，也就是从 \(0^\circ\) 到 \(180^\circ\)。如果其中一个是零向量，因为零向量的方向是任意的，所以它和另一个向量的夹角也可以按约定取任意值。

平行最容易在这里出问题。两个向量只要方向相同，平行；方向相反，也还是平行。

```text
同向：   ───→ A        ───→ B

反向：   ───→ A        ←─── B
```

所以，平行既有同向平行，也有反向平行。不能因为箭头反过来了，就把“平行”改名叫“相反”。两个向量平行，也常说是共线，两个说法是一回事。

两个向量垂直时，夹角就是 \(90^\circ\)，这里没有那么多花样。刚才说的零向量，因为方向任意，也按本讲约定和任意向量垂直。

> **结论**：判断平行时先看方向，不要求箭头一致；判断垂直时看夹角是否为 \(90^\circ\)。

#### 共面：先平移起点，再看是否落在一个平面

如果有三个或三个以上的向量，把它们的起点都平移到同一个点之后，如果这些向量的终点都落在同一个平面上，就称这些向量共面。

这里“平移”不能换成随便挪动。自由向量只保证整体平移不改变向量，不能把向量旋转、折断或者任意拉扯。

我们研究的是空间解析几何，空间是三维的，所以并非任意三个向量都共面。墙角就是一个直观例子：墙角的三条边从同一个点出发，却不能同时放在一个平面里。正因为空间有不同方向，才有“共面”和“不共面”的区别。

### 向量的线性运算

#### 加法：先接方向，再看合成的结果

向量的加法并不是把两个长度机械相加。我们更习惯用平行四边形法则：把 \(\vec a\) 和 \(\vec b\) 的起点挪到同一点，作一个以它们为邻边的平行四边形，从共同起点指向对角顶点的那条对角线，就是 \(\vec a+\vec b\)。

```text
                 C
              ↗     ↖
           B /       \ A
            /         \
           O ───────── D
```

图中 \(C\) 所对应的对角线就是两个向量相加后的结果。这里当然不是说 \(\vec a+\vec b\) 一定比原来两个向量都长；它是一个新的向量，长度和方向都由几何位置决定。

也可以用三角形法则：把第一个向量的终点接到第二个向量的起点，首尾相接后，从总起点指向总终点的向量就是和向量。

```text
O ───→ A ───→ C
    └────────→ B
```

两条法则说的是同一件事，只是画法不同。平行四边形法则比较直观，三角形法则在做减法和后面处理线段关系时更方便。

加法满足交换律和结合律：

$$
\vec a+\vec b=\vec b+\vec a,
$$

$$
(\vec a+\vec b)+\vec c
=\vec a+(\vec b+\vec c).
$$

这些运算律先记住即可。前面这些基本运算高中大多接触过，真正进入后面的内容时，直接和直线、平面打交道会更多。我们不必在简单运算上反复绕圈，先把方向、起点和符号认清楚。

> **结论**：加法不是长度相加，而是先按方向把向量接起来，再取合成向量。

#### 减法：先反方向，再用三角形法则

减法可以看成加上负向量：

$$
\vec a-\vec b=\vec a+(-\vec b).
$$

什么是 \(-\vec b\)？它的长度和 \(\vec b\) 一样，方向完全相反。把 \(\vec b\) 的箭头掉个头，就得到 \(-\vec b\)。

因此，做 \(\vec a-\vec b\) 时，可以先把 \(\vec b\) 反向，再按加法处理。也可以直接用三角形法则：把两个向量的起点放在一起，从被减向量的终点指向被减向量的起点，连出结果向量。

```text
B ●────────→● A
  ←──────────
        B − A
```

对减法来说，记住“首尾相接、从被减向量终点指向被减向量起点”比死背图形更不容易错。

由三角形法则，可以得到两个三角不等式：

$$
|\vec a+\vec b|
\leq |\vec a|+|\vec b|,
$$

$$
|\vec a-\vec b|
\leq |\vec a|+|\vec b|.
$$

它们表达的是同一个几何事实：三角形任意一边都不超过另外两边之和。第一个不等式取等号时，\(\vec a\) 和 \(\vec b\) 同向；第二个不等式可以把 \(\vec a-\vec b\) 看成 \(\vec a+(-\vec b)\)，相关的两个向量同向时取等号，也就是原来的两个向量方向相反。

> **易错点**：不等式右边是两个模的“和”，不是先把两个向量方向拼起来再比较。后面做空间解析几何时，遇到几何关系时它经常是很朴素的三角形边长关系。

#### 数乘：只看方向和倍数

把一个实数 \(\lambda\) 乘到向量 \(\vec a\) 上，记作

$$
\lambda\vec a.
$$

不用先背一长串公式，先看几何意义就够了。

| 乘数 | 方向 | 长度 |
| :--- | :--- | :--- |
| \(\lambda>0\) | 与 \(\vec a\) 同向 | 变为原来的 \(\lambda\) 倍 |
| \(\lambda<0\) | 与 \(\vec a\) 反向 | 变为原来长度的倍数 |

所以：

- \(2\vec a\)：方向不变，长度变成两倍；
- \(-\vec a\)：方向相反，长度不变；
- \(-2\vec a\)：方向相反，长度变成两倍。

这就是数乘的规律。看一眼方向和倍数，比死背公式更牢。

#### 平行四边形中的向量表示

设平行四边形的两条邻边向量分别是

$$
\vec a=\overrightarrow{AB},\qquad
\vec b=\overrightarrow{AD}.
$$

由平行四边形法则，对角线 \(AC\) 就是两个邻边向量的和：

$$
\overrightarrow{AC}=\vec a+\vec b.
$$

取对角线 \(AC\) 的中点 \(M\)，从 \(M\) 指向 \(A\) 的向量是 \(CA\) 的一半，而 \(CA\) 与 \(AC\) 方向相反，因此

$$
\overrightarrow{MA}
=\frac12\overrightarrow{CA}
=-\frac12(\vec a+\vec b).
$$

再看 \(MB\)。\(M\) 把 \(DB\) 也分成相等的两段，且 \(DB\) 的方向是从 \(D\) 指向 \(B\)，所以

$$
\overrightarrow{MB}
=\frac12\overrightarrow{DB}
=\frac12(\vec a-\vec b).
$$

这三个式子看起来只是把同一张平行四边形换成了向量语言。后面遇到空间中的点、线段关系时，我们也会反复使用这种“先分解，再合成”的办法。

#### 单位化：把任意非零向量变成同方向的单位向量

给定一个非零向量 \(\vec a\)，先求它的模，再用模的倒数去乘它：

$$
\vec e=\frac{1}{|\vec a|}\vec a.
$$

这样得到的 \(\vec e\) 有两个性质：

1. 模等于 \(1\)，所以它是单位向量；
2. 乘的是正数 \(1/|\vec a|\)，所以它与 \(\vec a\) 同方向。

因此，\(\vec e\) 就是 \(\vec a\) 方向的单位向量。

这里要特别分清三种问法。若题目问“与 \(\vec a\) 同向的单位向量”，答案是

$$
\frac{1}{|\vec a|}\vec a.
$$

若问“与 \(\vec a\) 反向的单位向量”，答案前面加负号：

$$
-\frac{1}{|\vec a|}\vec a.
$$

若只问“与 \(\vec a\) 平行的单位向量”，因为平行包含同向和反向，两个答案都要考虑：

$$
\pm\frac{1}{|\vec a|}\vec a.
$$

> **易错点**：题目里的“平行”不是“同向”的暗号。平行而不同向时，负号不能省。

#### 平行判定的充要条件：成比例

在 \(\vec a
e\vec 0\) 时，\(\vec b\) 与 \(\vec a\) 平行的充要条件是：存在一个实数 \(\lambda\)，使得

$$
\vec b=\lambda\vec a.
$$

换句话说，两个非零向量平行，当且仅当它们成比例。系数 \(\lambda\) 可以取正数，也可以取负数：正数对应同向平行，负数对应反向平行。

零向量比较特殊。由于它和任意向量都平行，把它写成 \(\vec b=0\vec a\) 就可以纳入这个关系中。

$$
\vec b=0\vec a=\vec 0.
$$

所以判断平行时，不需要先钻进复杂的几何图里；如果一个向量已经是零向量，就直接利用它的特殊性。

### 空间直角坐标系

#### 右手系与三个坐标面

建立空间直角坐标系，要有 \(x\) 轴、\(y\) 轴、\(z\) 轴，并且遵守右手系准则：

1. 右手四指弯曲，先经过 \(x\) 轴正半轴；
2. 再经过 \(y\) 轴正半轴；
3. 右手大拇指指向的方向，就是 \(z\) 轴正半轴。

无论课本把坐标轴画成哪一种角度，正方向的判定都按这个准则来。画图时常见的是下面这种示意：

```text
                 Z
                 ↑
                 |
        Y ─────── O ───────→ X
                /
               ↙
```

三个坐标平面分别是：

| 坐标面 | 自由变化的坐标 | 固定坐标 | 方程 |
| :--- | :--- | :--- | :--- |
| \(XOY\) 面 | \(x,y\) | \(z=0\) | $z=0$ |
| \(YOZ\) 面 | \(y,z\) | \(x=0\) | $x=0$ |
| \(ZOX\) 面 | \(z,x\) | \(y=0\) | $y=0$ |

这里有一个容易忽略的书写细节：\(XOY\) 和 \(YOZ\) 按轴的顺序写，而 \(x\) 轴和 \(z\) 轴所确定的平面，按这里的习惯写成 \(ZOX\)，不写成 \(XOZ\)。顺序记错不至于让整个几何关系失效，但坐标面的名称要尽量写准确。

三个坐标面把空间切成八个卦限。我们可以把它想成墙角：地面之上有四个卦限，地面对称的位置之下还有四个，一共八个。

> **提示**：卦限通常不按“第一个、第二个”去记。做题时真正重要的是点落在哪些坐标面上，以及坐标的符号变化；不必花时间去背“第七个卦限到底是哪一个”。

#### 三个坐标轴上的点

坐标轴上的点，特征是两个坐标恒为零：

| 坐标轴 | 点的坐标 |
| :--- | :--- |
| \(x\) 轴 | $(x,0,0)$ |
| \(y\) 轴 | $(0,y,0)$ |
| $z$ 轴 | $(0,0,z)$ |

例如，\(x\) 轴上的点可以写成 \(P(x,0,0)\)，其中 \(x\) 可以任意变化；另外两个坐标之所以是零，是因为点在 \(x\) 轴上，垂直于 \(x\) 轴的两个坐标方向都没有偏移。

#### 从点坐标到向量坐标

现在把一个三维向量放进坐标系。若点 \(M\) 的坐标是

$$
M(x,y,z),
$$

那么从原点 \(O\) 指向 \(M\) 的向量记作 \(\overrightarrow{OM}\)。先在三个坐标轴上取单位向量：

$$
\vec i=(1,0,0),\qquad
\vec j=(0,1,0),\qquad
\vec k=(0,0,1).
$$

它们分别沿着 \(x,y,z\) 轴的正方向。

把 \(M\) 的三个坐标分别看成沿三个坐标轴的有向线段，就能得到三条基本向量：

$$
x\vec i,\qquad y\vec j,\qquad z\vec k.
$$

先由平行四边形法则把 \(x\vec i\) 和 \(y\vec j\) 相加，再和 \(z\vec k\) 相加，最终得到

$$
\overrightarrow{OM}
=x\vec i+y\vec j+z\vec k.
$$

所以，点 \(M(x,y,z)\) 对应的位置向量写成坐标形式就是

$$
\overrightarrow{OM}=(x,y,z).
$$

这里有一个特别容易混的地方：点 \(M\) 的坐标和向量 \(\overrightarrow{OM}\) 的坐标看起来完全一样，但它们不是同一个对象。前者说的是“点在哪里”，后者说的是“从原点指向这个点的向量是什么”。

教材为了严谨，尽量把向量写成 \(x\vec i+y\vec j+z\vec k\) 的形式；我们做题时则常常直接写成 \((x,y,z)\)，因为这样运算方便，不必每次都把三个箭头和三个字母都写出来。两种写法表示的是同一个向量，别因为写法不同就以为是两个不同概念。

> **定义**：点 \(M(x,y,z)\) 的位置向量是以原点为起点、以 \(M\) 为终点的向量，满足
> $$
> \overrightarrow{OM}=x\vec i+y\vec j+z\vec k.
> $$

#### 坐标形式下的线性运算

一旦向量写成坐标形式，加法、减法和数乘就都可以直接对应对应坐标。

例如，设

$$
\vec a=(1,2,3),\qquad \vec b=(0,0,5).
$$

那么：

$$
\vec a+\vec b=(1+0,\,2+0,\,3+5)=(1,2,8),
$$

$$
\vec a-\vec b=(1-0,\,2-0,\,3-5)=(1,2,-2),
$$

$$
2\vec a=(2,4,6).
$$

这些结果不是新规定，而是前面几何法则在坐标里的直接写法。加法对应坐标相加，减法对应坐标相减，数乘对应每个坐标都乘上同一个数。

#### 用坐标判断两个向量平行

设

$$
\vec a=(a_x,a_y,a_z),\qquad
\vec b=(b_x,b_y,b_z).
$$

如果两个向量平行，就有

$$
\vec b=\lambda\vec a,
$$

也就是

$$
(b_x,b_y,b_z)
=\lambda(a_x,a_y,a_z).
$$

因此，对应的三个坐标成比例，正确的对应关系是

$$
\frac{b_x}{a_x}
=\frac{b_y}{a_y}
=\frac{b_z}{a_z},
$$

但这里要把每个比号理解成“对应坐标的比例”，不能机械地把它当成普通分数。

例如，

$$
\vec a=(1,1,2),\qquad
\vec b=(2,2,4).
$$

显然 \(\vec b=2\vec a\)，所以它们平行。对应坐标的比例分别是

$$
1:2=1:2=2:4.
$$

再看一个容易把人卡住的例子：

$$
\vec a=(1,0,0),\qquad
\vec b=(2,0,0).
$$

它们当然平行，因为 \(\vec b=2\vec a\)。如果机械地写成分数，就会碰到

$$
\frac12=\frac00=\frac00.
$$

这里的 \(0/0\) 并不是普通除法。比例可以读成“比分”，就像球赛写成 \(1:0\) 是左边进一个、右边进零，并不是在计算 \(1\div0\)。所以在向量坐标的平行判定中，零出现在分母的位置，并不代表这个比例关系失去意义。

> **易错点**：坐标成比例的说法包含零坐标时，优先回到“是否有一个统一的 \(\lambda\)，使 \(\vec b=\lambda\vec a\)”这个本质。不要被形式上的零除号吓住。

#### 线段分点关系与空间中点公式

设空间中有两点

$$
A(x_1,y_1,z_1),\qquad
B(x_2,y_2,z_2),
$$

点 \(M\) 在线段 \(AB\) 上，并且满足

$$
\overrightarrow{AM}
=\lambda\overrightarrow{MB}.
$$

要求 \(M\) 的坐标时，可以把原点 \(O\) 也连进来。先分别看两条向量：

$$
\overrightarrow{AM}
=\overrightarrow{OM}-\overrightarrow{OA},
$$

$$
\overrightarrow{MB}
=\overrightarrow{OB}-\overrightarrow{OM}.
$$

把它们代入条件：

$$
\overrightarrow{OM}-\overrightarrow{OA}
=\lambda
\left(\overrightarrow{OB}-\overrightarrow{OM}\right).
$$

把含有 \(\overrightarrow{OM}\) 的项整理到左边：

$$
(1+\lambda)\overrightarrow{OM}
=\overrightarrow{OA}
+\lambda\overrightarrow{OB}.
$$

因此

$$
\overrightarrow{OM}
=\frac{1}{1+\lambda}
\left(
\overrightarrow{OA}
+\lambda\overrightarrow{OB}
\right).
$$

把 \(A,B\) 的坐标带进去，就得到

$$
M\left(
\frac{x_1+\lambda x_2}{1+\lambda},
\frac{y_1+\lambda y_2}{1+\lambda},
\frac{z_1+\lambda z_2}{1+\lambda}
\right).
$$

这里整理时要除以 \(1+\lambda\)，所以要保证 \(1+\lambda
e0\)。这个条件不是额外凭空的限制，而是分母不能为零的直接要求。

特别地，当 \(\lambda=1\) 时，

$$
\overrightarrow{AM}=\overrightarrow{MB},
$$

也就是 \(M\) 把线段 \(AB\) 平分，\(M\) 是中点。空间中点坐标公式于是变成

$$
M\left(
\frac{x_1+x_2}{2},
\frac{y_1+y_2}{2},
\frac{z_1+z_2}{2}
\right).
$$

这和高中学过的平面中点公式是一样的，只不过现在每个点多了第三个坐标，分量分别处理即可。

### 看到这些概念时，先把对象分清

这一讲的内容看似分成向量概念、向量运算和坐标系几块，实际上它们是一条线。

先确定对象：有向线段有起点和终点，长度由模描述，方向由箭头描述。向量是自由向量，所以可以为了运算而整体平移；零向量则要按“长度为零、方向任意”的特殊约定处理。

再确定运算：加法把向量按方向接起来，减法先反向，数乘只改变长度倍数和方向。把这些几何意义记住后，才不会把向量当成普通数字乱套。

最后把向量放进三维坐标系：用右手系确定正方向，用 \(XOY\)、\(YOZ\)、\(ZOX\) 三个坐标面描述位置，用 \(\vec i,\vec j,\vec k\) 分解任意位置向量。到了这一步，前面的平行四边形法则、三角形法则和数乘规律，就都变成了对应坐标上的直接计算。

最需要反复提醒的只有几处：点坐标和向量坐标外形相同但对象不同；平行的反向情形不能漏掉；零向量的方向是任意的；比例式在坐标为零时不能被误读成普通除法。把这些地方分清，向量就不难。

### 本讲提到的题目

#### 与非零向量平行的单位向量

给定一个非零向量 \(\vec a\)，求与它平行的单位向量。

先求同方向的单位向量：

$$
\vec e=\frac{1}{|\vec a|}\vec a.
$$

若只要求平行，反向也要算上，因此答案为

$$
\boxed{
\pm\frac{1}{|\vec a|}\vec a
}.
$$

题目若明确问“同向”，取正号；明确问“反向”，取负号。

#### 平行四边形中的向量

在平行四边形 \(ABCD\) 中，设

$$
\vec a=\overrightarrow{AB},\qquad
\vec b=\overrightarrow{AD},
$$

并取 \(M\) 为对角线 \(AC\) 的中点，表示 \(\overrightarrow{AC}\)、\(\overrightarrow{MA}\)、\(\overrightarrow{MB}\)。

由平行四边形法则，

$$
\overrightarrow{AC}=\vec a+\vec b.
$$

因为 \(\overrightarrow{MA}=\frac12\overrightarrow{CA}\)，所以

$$
\overrightarrow{MA}
=-\frac12(\vec a+\vec b).
$$

又因为 \(\overrightarrow{MB}=\frac12\overrightarrow{DB}\)，而

$$
\overrightarrow{DB}
=\overrightarrow{AB}-\overrightarrow{AD}
=\vec a-\vec b,
$$

故

$$
\overrightarrow{MB}
=\frac12(\vec a-\vec b).
$$

#### 线段分点与中点

设

$$
A(x_1,y_1,z_1),\qquad
B(x_2,y_2,z_2),
$$

点 \(M\) 在线段 \(AB\) 上，且

$$
\overrightarrow{AM}
=\lambda\overrightarrow{MB}.
$$

在 \(1+\lambda
e0\) 时，

$$
M\left(
\frac{x_1+\lambda x_2}{1+\lambda},
\frac{y_1+\lambda y_2}{1+\lambda},
\frac{z_1+\lambda z_2}{1+\lambda}
\right).
$$

当 \(\lambda=1\) 时，\(\overrightarrow{AM}=\overrightarrow{MB}\)，点 \(M\) 是中点，答案为

$$
M\left(
\frac{x_1+x_2}{2},
\frac{y_1+y_2}{2},
\frac{z_1+z_2}{2}
\right).
$$

## 把向量说清楚：模、方向与投影
> 对应块：BLK110 | 覆盖分集：P118 | 块标题（分集名）：《【黑板】向量的模｜方向角｜方向余弦｜投影》

先把向量的起点挪到原点。这不是随手一挪，而是接下来一切计算的前提：只要向量从原点出发，它的终点坐标就直接告诉了我们这个向量的一切。先把一条斜边的投影拆进直角三角形里，剩下的事情就顺了。

### 向量的模与两点间距离

向量的模，也就是长度，从原点出发的向量 $\boldsymbol r=(x,y,z)$ 落在空间直角坐标系里。先在 $xy$ 平面内用一次勾股定理，得到它那条水平方向的投影长为 $\sqrt{x^2+y^2}$；再在包含 $z$ 的直角三角形里用一次勾股定理：

$$|\boldsymbol r|=\sqrt{x^2+y^2+z^2}.$$

这个公式太熟了，就一带而过。

两点之间距离的公式也很熟。设 $A(x_1,y_1,z_1)$，$B(x_2,y_2,z_2)$，那么

$$|AB|=\sqrt{(x_1-x_2)^2+(y_1-y_2)^2+(z_1-z_2)^2}.$$

有两种看法，结果一样：要么先把 $\overrightarrow{AB}$ 求出来，再求它的模；要么直接套两点间距离公式。怎么写都行，区别只是繁简。高中时就熟悉的公式，这里不必多费口舌。

> **定义**：若 $\boldsymbol a=(a_1,a_2,a_3)$、$\boldsymbol b=(b_1,b_2,b_3)$，则
> $$\overrightarrow{AB}=\boldsymbol b-\boldsymbol a,\qquad |AB|=|\boldsymbol b-\boldsymbol a|.$$

> **易错点**：坐标全要一起平移，不能只挪其中的一个或两个分量。若起点在 $A$、终点在 $B$，那么即使 $A$、$B$ 两个点离原点都很近，连接它们的那个向量自身长度未必小。按起点、终点都平移回原点再算，两种算法的结果就完全一致了。

### 求单位向量：终点减起点

已知 $A=(4,0,5)$，$B=(7,1,3)$，求与 $\overrightarrow{AB}$ 方向相同的单位向量。题里给的数字可以直接往下算，但先把那一步为什么要这么写说明白。

引入原点 $O$，把 $\overrightarrow{OA}$ 和 $\overrightarrow{OB}$ 画出来。由 $A$ 指向 $B$ 的向量是向量的减法，"指向被减"——所以是 $\overrightarrow{OB}$ 减 $\overrightarrow{OA}$：

$$\overrightarrow{AB}=\overrightarrow{OB}-\overrightarrow{OA}=(7,1,3)-(4,0,5)=(3,1,-2).$$

它的模为

$$|\overrightarrow{AB}|=\sqrt{3^2+1^2+(-2)^2}=\sqrt{14}.$$

与它同方向的单位向量就是

$$\frac{1}{\sqrt{14}}(3,1,-2).$$

口语里说"终点减起点"当然没问题，做题时也完全够用。但这个说法并不完全严谨：点减点是什么东西？没学过。严格地说，这是两个**向量**相减，只是因为 $\overrightarrow{OA}$、$\overrightarrow{OB}$ 的坐标和点 $A$、$B$ 相同，形式上看起来像点在相减。很多书干脆不写中间这步，直接写 $B-A$；结果当然对，但知其然也要知其所以然：减去的是以原点为起点的位置向量。

同一道例题，改一改问法，答案就会变：

- **与 $\overrightarrow{AB}$ 方向相同**：$\dfrac{1}{\sqrt{14}}(3,1,-2)$；
- **与 $\overrightarrow{AB}$ 方向相反**：$-\dfrac{1}{\sqrt{14}}(3,1,-2)$；
- **与 $\overrightarrow{AB}$ 平行**：$\pm\dfrac{1}{\sqrt{14}}(3,1,-2)$；
- **与 $\overrightarrow{AB}$ 共线**：$\pm\dfrac{1}{\sqrt{14}}(3,1,-2)$。

> **易错点**：审题一定严。"方向相同""方向相反""平行""共线"这四种问法，正负号大不一样。"平行或共线"时正负号都要写，别只写一个。

### 方向角与方向余弦

有了坐标，接下来是方向角与方向余弦。这部分比前面麻烦得多，而且后面大量内容都要用到它。

#### 方向角：三个角与取值范围

设 $\boldsymbol r
e\boldsymbol 0$。它与 $x$ 轴正半轴的夹角记为 $\alpha$，与 $y$ 轴正半轴的夹角记为 $\beta$，与 $z$ 轴正半轴的夹角记为 $\gamma$，这三个角就是方向角。

> **定义**：方向角必须针对非零向量定义，是它与三个坐标轴**正向**的夹角。书上说"与三个坐标轴的夹角"，也是指正向。

> **易错点**：零向量的方向角没有定义。学生问过"零向量方向角是什么"——没有，定义域里就排除了。

$$0^\circ\le \alpha,\beta,\gamma\le 180^\circ.$$

#### 方向余弦：为什么用余弦而不用正弦

由直角三角形中的邻边比斜边，

$$\cos\alpha=\frac{x}{|\boldsymbol r|},\qquad \cos\beta=\frac{y}{|\boldsymbol r|},\qquad \cos\gamma=\frac{z}{|\boldsymbol r|}.$$

这三个数就是方向余弦。

> **提示**：为什么用余弦不用正弦？角度范围是 $0^\circ$ 到 $180^\circ$。正弦函数在这段区间里先增后减，一个确定的正弦值对应两个不同角度，角不能唯一确定。而余弦函数在这段区间里从 $1$ 单调减到 $-1$，给定方向余弦就能唯一锁定方向角，算起来也方便。

把三个方向余弦排成一个新向量：

$$\left(\cos\alpha,\cos\beta,\cos\gamma\right)
=\frac{1}{|\boldsymbol r|}(x,y,z)
=\frac{1}{|\boldsymbol r|}\boldsymbol r.$$

这不就是 $\boldsymbol r$ 的单位化吗？它与 $\boldsymbol r$ 同方向，模为 $1$。理解了"单位化"这三个字，形式立刻就够具体了：沿着 $\boldsymbol r$ 的方向量下去，长度到 $1$ 时停笔，得到的就是它。

> **结论**：方向余弦满足
> $$\cos^2\alpha+\cos^2\beta+\cos^2\gamma=1.$$

把分子代进去立刻得到：

$$\frac{x^2+y^2+z^2}{|\boldsymbol r|^2}=1.$$

数量积就是我们在线性代数里讲过的内积。课本的叙述看起来比较乱，咱们先从最简单、最常用的地方入手。两个向量的数量积非常好求，坐标给出来就能直接算。

### 点乘的第一种定义：坐标直接算

> **定义**：设 $\boldsymbol a=(a_1,a_2,\ldots,a_n)$，$\boldsymbol b=(b_1,b_2,\ldots,b_n)$，则
> $$
> \boldsymbol a\cdot\boldsymbol b=a_1b_1+a_2b_2+\cdots+a_nb_n.
> $$

符号中间有一个点，所以也叫**点乘**。计算时不是先求两个向量的模，而是对应坐标直接相乘，再把乘积加起来。

比如

$$
\boldsymbol a=(1,1,2),\qquad
\boldsymbol b=(0,1,-1),
$$

则

$$
\boldsymbol a\cdot\boldsymbol b
=1\times0+1\times1+2\times(-1)
=0+1-2=-1.
$$

> **注意**：这个点不能省。字母 $\boldsymbol a$ 后面直接跟 $\boldsymbol b$，那是字母连乘；写成 $\boldsymbol a\cdot\boldsymbol b$，才表示数量积。

> **结论**：数量积的最终结果是一个数，这个数可以为正、为负，也可以为零。

所以实际做题时，第一种定义最好用，也是最常用的。其余两种定义，主要是帮助我们理解数量积为什么是负数、它和夹角有什么关系。

### 点乘的其他两种定义：做功与投影

第二种定义是从力做功来的。沿着位移 $\boldsymbol s$ 的方向作用一个力 $\boldsymbol F$，二者的夹角是 $\theta$。把力沿位移方向分解，平行分量是 $F\cos\theta$，力乘上位移，就是这个力所做的功，因此

$$
\boldsymbol F\cdot\boldsymbol s=|\boldsymbol F|\,|\boldsymbol s|\cos\theta.
$$

不管物理背景是什么，两个向量的数量积可以定义成

$$
\boxed{\boldsymbol a\cdot\boldsymbol b
=|\boldsymbol a|\,|\boldsymbol b|\cos\theta},
$$

其中 $\theta$ 是两个向量的夹角，取值范围是 $[0,\pi]$。

两个向量的模都大于等于零，但 $\cos\theta$ 可能是负的，所以数量积也可能为负。这一点很要紧：不要因为前面算出来的结果是个数，就误以为它一定非负。

> **易错点**：向量夹角是 $\angle(\boldsymbol a,\boldsymbol b)$，没必要硬记一个烦人的符号；知道它表示两个向量之间的夹角即可。

第三种定义和投影有关。$|\boldsymbol b|\cos\theta$ 正是 $\boldsymbol b$ 在 $\boldsymbol a$ 方向上的投影，所以

$$
\boldsymbol a\cdot\boldsymbol b
=|\boldsymbol a|\operatorname{proj}_{\boldsymbol a}\boldsymbol b.
$$

交换两个向量的角色，又能写成

$$
\boldsymbol a\cdot\boldsymbol b
=|\boldsymbol b|\operatorname{proj}_{\boldsymbol b}\boldsymbol a.
$$

投影符号里含有 `project` 的字样，来源就是英文投影仪 `projector` / 投影 `project`；这个符号确实比较古怪，记住它表示“一个向量在另一个向量上的投影”就行。

三种定义看起来有点烦，实际上最常用的是坐标公式。三角函数公式则能反解夹角：

$$
\boxed{\cos\theta
=\frac{\boldsymbol a\cdot\boldsymbol b}{|\boldsymbol a|\,|\boldsymbol b|}}.
$$

点乘怎么算？按第一种定义算；向量模怎么求？前面已经学过。公式就摆在面前。

### 点乘的几个常记结论

先看自己与自己做点乘。若 $\boldsymbol a=(m,n,p)$，则

$$
\boldsymbol a\cdot\boldsymbol a=m^2+n^2+p^2=|\boldsymbol a|^2.
$$

用三角函数定义也能说明：一个向量和它自己的夹角是 $0^\circ$，$\cos0^\circ=1$，因此结果就是模的平方。

再看垂直关系：

> **结论**：两个非零向量垂直的充要条件是 $\boldsymbol a\cdot\boldsymbol b=0$。

非零向量垂直时，夹角是 $90^\circ$，$\cos90^\circ=0$，点乘自然为零。至于零向量，它的方向是任意的，与任意向量都平行，也与任意向量都垂直，结论同样成立。

这个结论**需要计算才能判断**。而 $\boldsymbol a=(1,1,2)$ 与 $\boldsymbol b=(2,2,4)$ 是否平行，用眼睛就能看出来，因为后者是前者的两倍，不需要做点乘。一个要算，一个一看便知，别把两者的判断方法混在一起。

> **常记结论**：
> $$\boldsymbol a\cdot\boldsymbol a=|\boldsymbol a|^2,\qquad
> \boldsymbol a\perp\boldsymbol b\iff \boldsymbol a\cdot\boldsymbol b=0.$$

坐标系的三个单位向量 $\boldsymbol i,\boldsymbol j,\boldsymbol k$ 分别沿着 $x$ 轴、$y$ 轴、$z$ 轴，彼此垂直，所以

$$
\boldsymbol i\cdot\boldsymbol j
=\boldsymbol j\cdot\boldsymbol k
=\boldsymbol i\cdot\boldsymbol k=0.
$$

点乘还有交换律、分配律和数乘的结合律：

$$
\begin{aligned}
\boldsymbol a\cdot\boldsymbol b&=\boldsymbol b\cdot\boldsymbol a,\\
(\boldsymbol a+\boldsymbol b)\cdot\boldsymbol c
&=\boldsymbol a\cdot\boldsymbol c+\boldsymbol b\cdot\boldsymbol c,\\
\lambda(\boldsymbol a\cdot\boldsymbol b)
&=(\lambda\boldsymbol a)\cdot\boldsymbol b
=\boldsymbol a\cdot(\lambda\boldsymbol b).
\end{aligned}
$$

这三条都可以回到原始定义去理解或验证，使用时一带而过即可。

### 例题：由点乘反解夹角

设 $M,A,B$ 三点构成直角三角形，$M$ 是直角顶点，且

$$
M=(1,1,1),\qquad A=(2,2,1),\qquad B=(1,1,2).
$$

求 $\angle AMB$。

第一步不是直接代夹角公式，而是先把 $\overrightarrow{MA}$ 和 $\overrightarrow{MB}$ 找出来。向量始终是**终点减起点**：

$$
\overrightarrow{MA}=\boldsymbol a-\boldsymbol m=(1,1,0),
\qquad
\overrightarrow{MB}=\boldsymbol b-\boldsymbol m=(0,0,1).
$$

第二步做点乘：

$$
\overrightarrow{MA}\cdot\overrightarrow{MB}
=1\times0+1\times0+0\times1=0.
$$

第三步代入夹角公式：

$$
\cos\theta
=\frac{0}{\sqrt{1^2+1^2+0^2}\,\sqrt{0^2+0^2+1^2}}
=\frac{0}{\sqrt2\cdot1}=0.
$$

因此 $\theta=\dfrac{\pi}{3}$。

这里最容易错的是分子和分母里的模。点乘算出来是 $0$，但分母是两个模的乘积，不能把模也省略掉。

### 叉乘算出来的不是数，是向量

现在看向量积。叉乘比点乘复杂得多，最该先记住的一句话是：

> **结论**：两个向量的向量积是一个向量。

我为什么一直强调“点乘是一个数，叉乘是一个向量”？因为向量由两个东西决定：方向和大小。叉乘的这两部分要分别看。

#### 大小：由两模和夹角决定

$$
|\boldsymbol a\times\boldsymbol b|
=|\boldsymbol a|\,|\boldsymbol b|\sin\theta.
$$

角 $\theta$ 是两向量的夹角。

#### 方向：由右手系准则决定

右手伸出来，四指弯曲，按 $\boldsymbol a$、$\boldsymbol b$ 的顺序转过去；大拇指所指的方向，就是 $\boldsymbol a\times\boldsymbol b$ 的方向。

若先经过 $\boldsymbol a$ 再经过 $\boldsymbol b$，大拇指朝一个方向；改成 $\boldsymbol b\times\boldsymbol a$，四指先经过 $\boldsymbol b$ 再经过 $\boldsymbol a$，方向就反过来。

> **提示**：做题时不必总画严格的右手系示意图。后面很多例题都会问“求一个同时与 $\boldsymbol a$、$\boldsymbol b$ 垂直的向量”，这时就是求它们的向量积，因为 $\boldsymbol a\times\boldsymbol b$ 同时垂直于 $\boldsymbol a$ 和 $\boldsymbol b$。

右手系容易把人讲晕，连大小带方向一起规定，确实容易懵。所以公式不必从定义硬推，我们倒过来，从一个具体计算入手，把这两个向量怎么叉乘彻底算一遍。

### 叉乘的行列式：记住三行怎么摆

$$
\boldsymbol a=(a_1,a_2,a_3),\qquad
\boldsymbol b=(b_1,b_2,b_3).
$$

则

$$
\boxed{
\boldsymbol a\times\boldsymbol b=
\begin{vmatrix}
\boldsymbol i&\boldsymbol j&\boldsymbol k\\
a_1&a_2&a_3\\
b_1&b_2&b_3
\end{vmatrix}
}.
$$

第一行永远是 $\boldsymbol i,\boldsymbol j,\boldsymbol k$。第一个向量放第二行，第二个向量放第三行。两行顺序绝对不能弄反：交换第二、三行，相当于交换行列式的两行，结果要变号，向量方向也跟着变。

#### 展开这个行列式

先通看一遍：
$$
\begin{vmatrix}
\boldsymbol i&\boldsymbol j&\boldsymbol k\\
m&n&p\\
a&b&c
\end{vmatrix}.
$$

按第一行展开，三项的符号依次是 $+,-,+$。只有中间那一项前面要加负号，这是最容易算错的地方。

第一项：去掉第一行、第一列，剩下 $\begin{vmatrix}n&p\\ b&c\end{vmatrix}$，结果是 $nc-pb$，直接写在 $\boldsymbol i$ 后面。

第二项：去掉第一行、第二列，剩下 $\begin{vmatrix}m&p\\ a&c\end{vmatrix}$，结果是 $mc-pa$，但前面有负号，所以 $\boldsymbol j$ 的系数是 $pa-mc$。

第三项：去掉第一行、第三列，剩下 $\begin{vmatrix}m&n\\ a&b\end{vmatrix}$，结果是 $mb-na$，直接写在 $\boldsymbol k$ 后面。

合起来就是
$$
\begin{vmatrix}
\boldsymbol i&\boldsymbol j&\boldsymbol k\\
m&n&p\\
a&b&c
\end{vmatrix}
=(nc-pb)\boldsymbol i+(pa-mc)\boldsymbol j+(mb-na)\boldsymbol k.
$$

若
$$
\boldsymbol a=(a_1,a_2,a_3),\qquad
\boldsymbol b=(b_1,b_2,b_3),
$$
则可以直接按坐标算：

$$
\begin{aligned}
\boldsymbol a\times\boldsymbol b
={}&(a_2b_3-a_3b_2)\boldsymbol i\\
&-(a_1b_3-a_3b_1)\boldsymbol j\\
&+(a_1b_2-a_2b_1)\boldsymbol k.
\end{aligned}
$$

这样记更省事：第一项直接算，第二项先算好再加负号，第三项直接算。

#### 把计算过程亲手走一遍

设
$$
\boldsymbol a=(2,1,3),\qquad
\boldsymbol b=(1,0,1).
$$

先算 $\boldsymbol i$ 的系数：$1\times1-3\times0=1$。

再算中间项：$2\times1-3\times1=-1$，外面加负号，得到 $\boldsymbol j$ 的系数 $1$。

最后算 $\boldsymbol k$ 的系数：$2\times0-1\times1=-1$。

所以
$$
\boxed{\boldsymbol a\times\boldsymbol b
=(1,1,-1)\boldsymbol i+(0,0,0)\boldsymbol j+(-1,0,0)\boldsymbol k
=\boldsymbol i-\boldsymbol j-\boldsymbol k}.
$$

这就得到了一个新的向量。它的方向按右手系确定，大小是 $|\boldsymbol a||\boldsymbol b|\sin\theta$，两点都对上了。

> **易错点**：不要把“中间项要加负号”误解成“中间的两个数要交换”。这里真正变化的是这一项前面的正负号。

实际做题时，写成坐标形式即可：

$$
(a_1,a_2,a_3)\times(b_1,b_2,b_3)
=\bigl(a_2b_3-a_3b_2,\;a_3b_1-a_1b_3,\;a_1b_2-a_2b_1\bigr).
$$

代数余子式的一大堆展开过程可以留在草稿纸上，不必全部抄进答卷。把代数余子式这一堆证明过程全写出来，既费时间，又容易把负号抄错。真正要记住的只有一个技巧：第二项前面有负号。

### 叉乘的性质

叉乘的大小由 $|\boldsymbol a||\boldsymbol b|\sin\theta$ 决定，方向由右手系决定。做题时，右手系不必画得特别严格，但有一个判断特别实用：

> **结论**：求一个同时与 $\boldsymbol a$、$\boldsymbol b$ 都垂直的向量，就求 $\boldsymbol a\times\boldsymbol b$。

下面几性质，重点在于用刚学过的行列式把结果算出来。

#### 一个向量和它自己叉乘

$$
\boldsymbol a\times\boldsymbol a=\boldsymbol 0.
$$

注意，右边要写成**零向量**，因为叉乘的结果是向量。

有两种理解方式。从大小看，一个向量和它自己的夹角是 $0^\circ$，而 $\sin0^\circ=0$，所以叉乘结果的模为零，结果只能是零向量。从计算看，行列式的第二行和第三行完全相同，两行相等，行列式值为零。

#### 两向量平行

> **结论**：两个向量平行的充要条件是它们的叉乘等于零向量。

判断平行并不需要做叉乘。比如 $(1,1,1)$ 和 $(2,2,3)$ 这种对应坐标成比例的情况，一眼就能看出来。它们确实平行时，叉乘行列式的两行成比例，所以值为零。

这里再强调一次：叉乘结果是向量，模为零的向量是零向量，不是数字零。

#### 交换两个向量，方向相反

$$
\boldsymbol b\times\boldsymbol a
=-(\boldsymbol a\times\boldsymbol b).
$$

交换第二行和第三行，就是交换行列式的两行；交换两行要变号。换成右手系也很直观：$\boldsymbol a\times\boldsymbol b$ 时四指先经过 $\boldsymbol a$ 再经过 $\boldsymbol b$，$\boldsymbol b\times\boldsymbol a$ 时顺序反过来了，大小相同，方向相反。

> **易错点**：点乘的次序可以交换，叉乘的次序不能随便交换。

#### 向量加法的分配律

$$
(\boldsymbol a+\boldsymbol b)\times\boldsymbol c
=\boldsymbol a\times\boldsymbol c+\boldsymbol b\times\boldsymbol c.
$$

这也不用另外发明解释，把行列式写出来就明白了。设

$$
\boldsymbol a=(a_1,a_2,a_3),\quad
\boldsymbol b=(b_1,b_2,b_3),\quad
\boldsymbol c=(c_1,c_2,c_3),
$$

那么
$$
(\boldsymbol a+\boldsymbol b)\times\boldsymbol c
=
\begin{vmatrix}
\boldsymbol i&\boldsymbol j&\boldsymbol k\\
a_1+b_1&a_2+b_2&a_3+b_3\\
c_1&c_2&c_3
\end{vmatrix}.
$$

由于两个向量是按坐标相加的，叉乘中的第二行可以写成两个坐标行之和：
$$
\begin{vmatrix}
\boldsymbol i&\boldsymbol j&\boldsymbol k\\
a_1&a_2&a_3\\
c_1&c_2&c_3
\end{vmatrix}
+
\begin{vmatrix}
\boldsymbol i&\boldsymbol j&\boldsymbol k\\
b_1&b_2&b_3\\
c_1&c_2&c_3
\end{vmatrix}.
$$

好多同学在这里会用错，是因为漏掉了“其余的行保持不变”这句话。两边第一行、第三行都得原样保留，不能跟着乱动。

#### 数乘的结合律

$$
\lambda(\boldsymbol a\times\boldsymbol b)
=(\lambda\boldsymbol a)\times\boldsymbol b
=\boldsymbol a\times(\lambda\boldsymbol b).
$$

一个数乘一个向量，就是把这个数乘到向量的每个坐标上。把 $\boldsymbol a$ 换为 $\lambda\boldsymbol a$，行列式的第二行就有一个公因子 $\lambda$，可以提到行列式外；把 $\boldsymbol b$ 换为 $\lambda\boldsymbol b$，第三行也有同样的公因子。提出来，结论自然就出来了。

> **结论**：向量积是“算出一个新向量”，数量积是“算出一个数”。数量积的常用工具是坐标公式和夹角公式；向量积的常用工具是三行行列式及右手系。

### 向量积的面积应用

课本没有把两个重要应用展开，但这两条一定要补上，因为它们把叉乘的大小真正用起来了。

#### 平行四边形的面积

设 $\boldsymbol a$、$\boldsymbol b$ 围成平行四边形，两向量夹角为 $\theta$。以 $\boldsymbol a$ 为底，底长 $|\boldsymbol a|$；以 $\boldsymbol b$ 为斜边，它在垂直于 $\boldsymbol a$ 方向上的高是 $|\boldsymbol b|\sin\theta$。

由平行四边形面积等于底乘高，

$$
S_{\text{平行四边形}}
=|\boldsymbol a|\cdot|\boldsymbol b|\sin\theta
=|\boldsymbol a\times\boldsymbol b|.
$$

所以平行四边形的面积就是两向量叉乘结果的**模**。

> **注意**：这里说的是叉乘结果的模，不是叉乘结果本身。叉乘结果是向量，向量本身不能直接当作面积。

如果真回到空间图形里求底和高，会发现相当麻烦：图是三维的，高也不总是落在纸面上。用叉乘大小公式，一步就得到答案。

#### 三角形的面积

两个向量作为邻边时，平行四边形被对角线分成了两个全等的三角形，所以三角形面积是平行四边形的一半：

$$
S_{\triangle}
=\frac12|\boldsymbol a\times\boldsymbol b|.
$$

高仍然是 $|\boldsymbol b|\sin\theta$，底是 $|\boldsymbol a|$，底乘高再除以 $2$，最后就落到叉乘的模上。

#### 三角形面积例题

设三个点为

$$
A=(1,2,3),\qquad B=(3,4,5),\qquad C=(2,4,7),
$$

求三角形 $ABC$ 的面积。

先找两个起点相同的向量：

$$
\overrightarrow{AB}=(2,2,2),\qquad
\overrightarrow{AC}=(1,2,4).
$$

用叉乘：

$$
\overrightarrow{AB}\times\overrightarrow{AC}
=
\begin{vmatrix}
\boldsymbol i&\boldsymbol j&\boldsymbol k\\
2&2&2\\
1&2&4
\end{vmatrix}
=(4,-6,2).
$$

这里不要把 $\boldsymbol k$ 写在行末的坐标后面，那样写起来比较麻烦。直接写成三个坐标行，按刚才的规则算就行；代数余子式等过程不用抄进答卷。

叉乘结果的模为

$$
\left|\overrightarrow{AB}\times\overrightarrow{AC}\right|
=\sqrt{4^2+(-6)^2+2^2}
=\sqrt{56}
=2\sqrt{14}.
$$

所以

$$
\boxed{S_{\triangle ABC}
=\frac12\sqrt{56}
=\sqrt{14}}.
$$

一道“求三角形面积”的题，本质上就是：找出起点相同的两个邻边向量，做叉乘，再取模，最后除以 $2$。

### 本讲提到的题目

#### 求三角形夹角

已知
$$
M=(1,1,1),\quad A=(2,2,1),\quad B=(1,1,2),
$$
求 $\angle AMB$。

解析：按“例题：由点乘反解夹角”中的步骤，先算 $\overrightarrow{MA}$、$\overrightarrow{MB}$，再点乘，最后代夹角公式。答案是 $\dfrac{\pi}{3}$。

#### 两向量所围图形的面积

已知 $\boldsymbol a$、$\boldsymbol b$ 的夹角为 $\theta$，求它们围成的平行四边形与三角形的面积。

解析：直接使用“向量积的面积应用”中的底乘高推导。平行四边形面积为 $|\boldsymbol a\times\boldsymbol b|$，三角形面积为 $\dfrac12|\boldsymbol a\times\boldsymbol b|$。

## 把三维平面写进方程
> 对应块：BLK112 | 覆盖分集：P120 | 块标题（分集名）：《【黑板】平面及其方程》

先别急着套公式，我们把对象想清楚。

在三维空间里，如果 $z$ 能写成 $x,y$ 的二元函数 $z=f(x,y)$，那么 $x,y$ 每取一组值，$z$ 就有相应的取值；这些点连起来，就是一张弯弯曲曲的曲面。

可并不是所有曲面都能把 $z$ 单独写成 $x,y$ 的显式函数。有些曲面虽然能用 $x,y,z$ 之间的关系描述，却不能直接整理成 $z=f(x,y)$。这时就改写成三元方程

$$
F(x,y,z)=0.
$$

所以，三元方程未必是在故意把事情说复杂。它是在给那些不能写成 $z=f(x,y)$ 的曲面留位置。

曲线的想法也一样。一个弯弯曲曲的线，可以看成两个曲面的公共部分：两个曲面方程联立，凡是同时满足这两个方程的点，就落在交线上。换句话说，**曲线是方程组的轨迹，两个曲面相交得到曲线**。

下面进入平面。平面当然比一般曲面简单得多：只要抓住“一个点”和“一个法向量”，整个平面就能被写进方程里。

### 一个点和一个法向量锁住平面

这里说的平面都在三维空间中。

先取平面上一个已知点 $M_0(x_0,y_0,z_0)$，再取一个垂直于平面的法向量

$$
\boldsymbol n=(A,B,C).
$$

后面我们约定：平面的法向量写作 $\boldsymbol n$，直线的方向向量写作 $\boldsymbol s$。符号固定下来，看到它就知道在谈什么。

现在，假设法向量不唯一。眼前这个法向量朝上，旁边那个朝下，难道不也垂直于平面吗？当然也是。**只要方向垂直，都可以充当法向量，所以法向量不唯一。** 长度可以改，非零倍数也可以改；真正不能改的，是它与平面的垂直关系。

接下来问一句更关键的：怎样表示平面上的所有点？

从平面上任取一点 $P(x,y,z)$，连接已知点 $M_0$ 与它，得到

$$
\overrightarrow{M_0P}=(x-x_0,\ y-y_0,\ z-z_0).
$$

这个向量就在平面内。已知 $\boldsymbol n$ 垂直于整个平面，因此 $\boldsymbol n$ 也垂直于 $\overrightarrow{M_0P}$。两个向量垂直，就用数量积为零来判断：

$$
\boldsymbol n\cdot\overrightarrow{M_0P}=0.
$$

点积展开，得到

$$
A(x-x_0)+B(y-y_0)+C(z-z_0)=0.
$$

> **定义**：已知平面上一点和它的一个法向量，写成的
> $$
> A(x-x_0)+B(y-y_0)+C(z-z_0)=0
> $$
> 称为平面的**点法式方程**。

这里每一部分都有明确分工：$(A,B,C)$ 是法向量，$(x_0,y_0,z_0)$ 是平面上一点。点法式的名字已经把这两样东西全说出来了。我以前每次看到“点法式”，脑子里先冒出来的居然是法式面包；名字可以饿，式子可不能背反。

### 点法式直接落笔

设平面经过点 $(2,-3,0)$，法向量为 $(1,-2,3)$。套点法式：

$$
1\cdot(x-2)+(-2)(y+3)+3(z-0)=0.
$$

法向量 $(1,-2,3)$ 放到 $(A,B,C)$ 的位置，已知点放到 $(x_0,y_0,z_0)$ 的位置，一点不乱。整理得

$$
\boxed{x-2y+3z-8=0}.
$$

> **易错点**：求平面的方程，不能写到点法式就停笔。点法式适合找关系、写答案，但最后通常还要化成一般式；只写点法式，容易丢步骤分。

点法式真正好用的地方，还在于它把“我知道什么”和“还缺什么”分得很清楚。有点，不一定有法向量；有法向量，也不一定知道用哪个点。法向量一旦有了，平面内随便哪一点都可以拿来代入。三个点只要不共线，当然也可以挑一个坐标最简单、最不容易写错符号的点。

### 三个不共线点定平面

设三点为

$$
M_1(2,-1,4),\qquad M_2(-1,3,-2),\qquad M_3(0,2,3).
$$

这里先踩一个很容易踩的坑：**点的坐标不要和向量的坐标混着写。** $M_1$ 是一个点，$M_1M_2$ 才是由这个点指向另一个点的向量。点写成 $M_1=\cdots$，很容易把点当成向量，后面符号就乱了。

三个点能不能唯一确定一个平面？还得补一句：**三点必须不共线。** 如果三点在同一条直线上，能包含它们的平面有无数多个；只有不共线时，平面的方向才被真正锁住。

#### 法向量为什么来自叉乘

在点法式里，点任选一个，真正缺的是同时平行于

$$
\overrightarrow{M_1M_2},\qquad \overrightarrow{M_1M_3}
$$

的法向量。换句话说，要找一个同时垂直于这两个向量的向量。这正是叉乘最直接的用法。右手定则当然要熟，但做题时更该记住的是：**与两个向量都垂直的方向，就用它们的叉乘去找。**

先写

$$
\overrightarrow{M_1M_2}=(-3,4,-6),
$$

再写

$$
\overrightarrow{M_1M_3}=(-2,3,-1).
$$

于是可取

$$
\boldsymbol n
=\overrightarrow{M_1M_2}\times\overrightarrow{M_1M_3}
=(14,9,-1).
$$

叉积算出来带有公因数时，不必机械地照抄整串结果。比如结果若写成 $5(1,2,2)$，直接取 $(1,2,2)$ 就够了；它和 $5(1,2,2)$ 垂直的方向完全相同，系数短一点，后面的点法式也简单一点。若三个分量已经没有公因数，就不用硬“化简”。

点的选择会影响计算长度，却不会改变平面。这里我选 $M_3(0,2,3)$，因为它带有零坐标，代入后负号更少，不容易看错。点法式为

$$
14x+9(y-2)-(z-3)=0.
$$

整理得到

$$
\boxed{14x+9y-z-15=0}.
$$

### 一般式是最终答案的样子

把点法式展开：

$$
\begin{aligned}
A(x-x_0)+B(y-y_0)+C(z-z_0)&=0\\
Ax+By+Cz-Ax_0-By_0-Cz_0&=0.
\end{aligned}
$$

令

$$
D=-Ax_0-By_0-Cz_0,
$$

就得到平面的一般式

$$
\boxed{Ax+By+Cz+D=0}.
$$

一般式有一个非常实用的特点：法向量直接从系数里读出来，

$$
\boldsymbol n=(A,B,C).
$$

但常数项 $D$ 只告诉你平面相对于原点在哪里，不能单独指出一个已知的面上点。想拿一个具体点，还是要点法式，或者自己找截距、找过平面的直线。

> **易错点**：一般式中的 $A,B,C$ 对应法向量，但 $(A,B,C)$ 一般不是平面上的点，不要把法向量坐标当成已知点代进去。

#### 最后的系数要整理

一般式已经写出来，还不等于可以交卷。至少处理两件事。

先约公因数。例如

$$
5x+5y+5z-10=0
$$

应约成

$$
x+y+z-2=0.
$$

再统一第一个非零系数的正负。如果 $x$ 的系数为负，就把整式同时乘以 $-1$，让第一个非零系数为正。注意是整式一起变，不能只改一个符号。

这样处理，不是为了好看，而是让答案更短、更稳定，也避免同一平面出现太多写法。

#### 一般式也能解题，但通常不是首选

还是以前面三个点为例，若从一般式出发，就先设

$$
Ax+By+Cz+D=0.
$$

把三个点分别代入：

$$
\begin{cases}
2A-B+4C+D=0,\\
-A+3B-2C+D=0,\\
2B+3C+D=0.
\end{cases}
$$

看起来突然冒出来四个未知数 $A,B,C,D$，却只有三个方程。高中的感觉是“不够解”，但这里是齐次线性方程组，有无穷多解。无穷并不等于没法用：它意味着 $(A,B,C,D)$ 只能确定一个比例。

把 $D=-2B-3C$ 代入前两式，得到

$$
2A-3B+C=0,\qquad -A+B-5C=0.
$$

由第二式得 $A=B-5C$，再代回第一式：

$$
2(B-5C)-3B+C=0
\quad\Longrightarrow\quad
-B-9C=0.
$$

于是 $B=-9C$，$A=-14C$，再由 $D=-2B-3C$ 得 $D=-15C$。所以

$$
A:B:C:D=14:9:-1:-15.
$$

取这组比例，仍得到

$$
\boxed{14x+9y-z-15=0}.
$$

你看，一般式法不是不能做；它只是要先解方程组，再处理整体比例。平时当然优先用点法式加叉积，快得多，也更符合“先找法向量”的自然思路。

### 特殊平面不要死背，要从方程现推

看到系数为零，方程就会露出它的几何形状。

#### 常数项为零

如果 $D=0$，一般式变成

$$
Ax+By+Cz=0.
$$

把原点代入，恒有 $0=0$，所以这个平面一定经过原点。

这只是一个特点，不代表它只经过原点。平面方程本来就描述一片面，不是只指向一个点。

#### 缺少 $x$ 项

如果 $A=0$，方程变成

$$
By+Cz+D=0.
$$

先别急着在脑子里硬画立体图。我们暂时退到 $yz$ 平面里看。若方程是

$$
y+z=1,
$$

它在二维图上就是一条无限延伸的直线。但回到原方程，$x$ 根本没有出现，这意味着 $x$ 可以任意取值。同一条 $yz$ 平面中的直线沿 $x$ 方向平行移动，扫出的正是一个平面。

因此，$A=0$ 表示一个平行于 $x$ 轴的平面；当 $D=0$ 时，$x$ 轴上的点也能满足方程，此时平面包含 $x$ 轴。

$B=0$、$C=0$ 的读法完全相同：先看缺掉哪个坐标，再判断相应坐标可以怎样自由变化。这里不要死背整张特殊平面表；遇到一次，推一次，反而更不容易忘。

#### 同时缺少 $x$、$y$ 项

若 $A=B=0$，就只剩

$$
Cz+D=0,
$$

也就是一个坐标被固定的平面。以

$$
z+1=0
$$

为例，它就是 $z=-1$，而 $x,y$ 都可以任意取。$x=1$、$y=1$ 也是同一种读法：固定一个坐标，另外两个坐标自由变化，就得到一个平面。

> **结论**：这些特殊平面不是额外规定，而是系数为零后“哪个坐标不再受方程约束”的直接结果。现推比死记牢。

### 截距式把三个轴上交点写进来

如果一个平面分别与 $x$ 轴、$y$ 轴、$z$ 轴交于非零点，相应的三个截距记为 $a,b,c$，那么平面方程可以写成

$$
\boxed{\frac{x}{a}+\frac{y}{b}+\frac{z}{c}=1}.
$$

这就是截距式方程。使用它要盯住几个细节：

- $a,b,c$ 都不能为零；
- 右侧必须是 $1$，不能写成 $0$；
- 截距可以为正，也可以为负。

题面若直接给出与 $x$、$y$、$z$ 轴的截距分别为 $1,2,3$，立刻得到

$$
\frac{x}{1}+\frac{y}{2}+\frac{z}{3}=1.
$$

但最后仍要回到一般式。两边同时乘以 $6$：

$$
6x+3y+2z-6=0.
$$

所以

$$
\boxed{6x+3y+2z-6=0}.
$$

截距式非常好认，却不常直接作为最终答案。遇到轴交点就用它起步，最后老老实实化一般式。

### 两个平面的夹角交给法向量

严格地说，两个平面的夹角可以从它们的交线上取点，再在两个平面内分别作垂直于交线的直线，用这两条直线的夹角来定义。

不过，点法式一出现，法向量就在手边。与其再找两条辅助直线，不如直接研究两个法向量。

两个平面的法向量之间的夹角，与两个平面的夹角可能相等，也可能互为补角。这是因为法向量分别垂直于两个平面，换到同一个截面里，相应角之间会出现直角关系。

关键结论是：**平面的夹角取 $0^\circ$ 到 $90^\circ$ 之间的角，不会取钝角；法向量的夹角却可能是钝角。** 因此不能丢掉绝对值。

设两平面的法向量分别为 $\boldsymbol n_1,\boldsymbol n_2$，夹角为 $\theta$，则

$$
\boxed{
\cos\theta
=\frac{
\left|\boldsymbol n_1\cdot\boldsymbol n_2\right|
}{
|\boldsymbol n_1|\,|\boldsymbol n_2|
}
}.
$$

绝对值把法向量的钝角翻成对应的锐角，这正是平面夹角所需要的。

#### 垂直与平行都看法向量

两个平面垂直时，它们的法向量也垂直，所以判定条件是

$$
\boldsymbol n_1\cdot\boldsymbol n_2=0.
$$

书写时用垂直符号 $\perp$，不要写成 $\pi$；这个符号的两条腿都是直的。

两个平面平行时，它们的法向量平行，因此对应分量成比例：

$$
\frac{A_1}{A_2}
=\frac{B_1}{B_2}
=\frac{C_1}{C_2}.
$$

> **结论**：垂直看点积，平行看方向。平面方程里法向量的分量一读出来，空间关系就能翻译成代数关系。

现在看一个具体计算。已知两个平面

$$
x-y+2z-6=0,
$$

$$
2x+y+z-5=0.
$$

直接从一般式读法向量：

$$
\boldsymbol n_1=(1,-1,2),\qquad
\boldsymbol n_2=(2,1,1).
$$

于是

$$
\boldsymbol n_1\cdot\boldsymbol n_2
=1\cdot2+(-1)\cdot1+2\cdot1=3,
$$

$$
|\boldsymbol n_1|=|\boldsymbol n_2|=\sqrt6.
$$

所以

$$
\cos\theta
=\frac{|3|}{\sqrt6\sqrt6}
=\frac12.
$$

两个平面的夹角为

$$
\boxed{\theta=\frac{\pi}{3}}.
$$

### 过两点且垂直于已知平面

这一类题不要被书上的绕路吓住。正常思路仍然是点法式：平面内取一点很容易，真正要解决的是法向量。

先说结构。一个平面经过两个点 $M_1,M_2$，并且垂直于一个已知平面。目标平面内当然有向量 $\overrightarrow{M_1M_2}$；目标平面的法向量还必须垂直于这个已知平面的法向量。两条方向都拿到了，再用叉乘求它们的共同法向量。

用一道题把流程走完。目标平面经过

$$
M_1(1,1,1),\qquad M_2(0,1,-1),
$$

并且垂直于平面

$$
x+y+z=0.
$$

已知平面的法向量是

$$
\boldsymbol n_0=(1,1,1).
$$

平面上两点的连线向量为

$$
\overrightarrow{M_1M_2}=(-1,0,-2).
$$

为使结果简洁，取

$$
\begin{aligned}
\boldsymbol n
&=\overrightarrow{M_1M_2}\times\boldsymbol n_0\\
&=(-1,0,-2)\times(1,1,1)\\
&=(2,-1,-1).
\end{aligned}
$$

选坐标更顺眼的 $M_1(1,1,1)$ 代入点法式：

$$
2(x-1)-(y-1)-(z-1)=0.
$$

整理得

$$
\boxed{2x-y-z=0}.
$$

这类题做题时通常不需要画图。书上有时画图，是为了帮助理解；真正落笔时，仍然是点法式、叉乘、点法式。不要为了“看起来像空间题”去画一个自己掌握不准的立体图，反过来把简单的代数关系弄乱。

### 点到平面的距离

设平面外一点为

$$
P_0(x_0,y_0,z_0),
$$

平面的一般式为

$$
Ax+By+Cz+D=0.
$$

点到平面的距离公式是

$$
\boxed{
d=
\frac{
|Ax_0+By_0+Cz_0+D|
}{
\sqrt{A^2+B^2+C^2}
}
}.
$$

使用时先看平面方程的右边。公式要求写成 $Ax+By+Cz+D=0$；若题目给成等于其他数，先把所有项移到左边。

分子就是把 $P_0$ 的坐标代到平面方程左边，再加绝对值。这里最容易产生一个疑问：点不是代进“等于零”的方程了吗？为什么分子还会有东西？

因为 $P_0$ 是平面外的点。代进去只是计算这个点代入左端的值，并不是预先知道它一定为零。若代入后真等于零，那说明 $P_0$ 根本不在平面外，而是在平面上；此时分子为零，算出的距离也正好是零。

所以这个公式对平面外点最常使用，对平面上的点同样成立：

$$
\text{点在平面上}\Longleftrightarrow Ax_0+By_0+Cz_0+D=0.
$$

分母是法向量的模 $\sqrt{A^2+B^2+C^2}$。把公式记牢，具体的点坐标直接代进去即可，不必为了显得复杂而绕路。

### 本讲提到的题目

#### 过已知点且法向量已知

**题目**：求经过点 $(2,-3,0)$、法向量为 $(1,-2,3)$ 的平面方程。

**解析**：直接套点法式，把法向量放入 $A,B,C$ 的位置，把已知点放入 $x_0,y_0,z_0$ 的位置。

$$
(x-2)-2(y+3)+3z=0.
$$

**答案**：

$$
\boxed{x-2y+3z-8=0}.
$$

#### 三个不共线点确定平面

**题目**：求经过 $M_1(2,-1,4)$、$M_2(-1,3,-2)$、$M_3(0,2,3)$ 的平面方程。

**解析**：三点不共线，先写两条平面内向量，再用叉乘求共同法向量：

$$
\overrightarrow{M_1M_2}=(-3,4,-6),\qquad
\overrightarrow{M_1M_3}=(-2,3,-1),
$$

$$
\overrightarrow{M_1M_2}\times\overrightarrow{M_1M_3}=(14,9,-1).
$$

选较简单的 $M_3$ 写点法式：

$$
14x+9(y-2)-(z-3)=0.
$$

**答案**：

$$
\boxed{14x+9y-z-15=0}.
$$

#### 过 $x$ 轴和已知点

**题目**：求经过 $x$ 轴及点 $(4,-3,-1)$ 的平面方程。

**解析**：$x$ 轴给出方向向量 $(1,0,0)$，原点与已知点给出向量 $(4,-3,-1)$。二者叉乘得到法向量 $(0,1,-3)$。选原点代入点法式，比选 $(4,-3,-1)$ 更简单。

**答案**：

$$
\boxed{y-3z=0}.
$$

#### 已知三个轴截距

**题目**：一个平面与 $x,y,z$ 轴的截距分别为 $1,2,3$，求它的方程。

**解析**：先写截距式

$$
x+\frac y2+\frac z3=1,
$$

再两边乘以 $6$，整理成一般式。

**答案**：

$$
\boxed{6x+3y+2z-6=0}.
$$

#### 两平面的夹角

**题目**：求平面 $x-y+2z-6=0$ 与平面 $2x+y+z-5=0$ 的夹角。

**解析**：从一般式读出法向量 $(1,-1,2)$、$(2,1,1)$，代入带绝对值的法向量夹角公式。

$$
\cos\theta=\frac{|3|}{\sqrt6\sqrt6}=\frac12.
$$

**答案**：

$$
\boxed{\theta=\frac{\pi}{3}}.
$$

#### 过两点且垂直于已知平面

**题目**：求经过 $M_1(1,1,1)$、$M_2(0,1,-1)$，并且垂直于平面 $x+y+z=0$ 的平面方程。

**解析**：已知平面的法向量为 $(1,1,1)$，目标平面内向量为 $\overrightarrow{M_1M_2}=(-1,0,-2)$。二者叉乘得目标平面的法向量 $(2,-1,-1)$，再写点法式。

**答案**：

$$
\boxed{2x-y-z=0}.
$$

## 一个点，一个方向，写出空间直线
> 对应块：BLK113 | 覆盖分集：P121上 | 块标题（分集名）：《【黑板】直线及其方程》

我们之前学的直线都在平面上，现在把目光挪到空间。空间直线有一个很好用的出发点：先在它上面找一个点，再找一个方向，顺着这个点、沿着这个方向无限延伸，直线就被钉死了。

后面所有方程，无论是两个平面交出来的，还是一个点配一个方向写出来的，背后的东西都是这一句。真正写题时容易出错的，往往不是记不住公式，而是把点、方向向量、法向量这几个角色摆错了位置。把这几个角色分清，式子就不难写。

### 先把直线的几何关系想明白

已知直线上一点 $P_0(x_0,y_0,z_0)$，再给它一个非零方向向量 $\boldsymbol{s}=(m,n,p)$，我们就能从 $P_0$ 出发，沿 $\boldsymbol{s}$ 指向的方向无限延伸；反向也同样可以。这样得到的点全在直线上，方向也始终不变，所以直线被唯一确定。

方向向量并不唯一。沿同一条直线走，我取一小段是一个方向向量，取长一点仍然是；朝相反方向取，得到的向量虽然方向变了，但仍然能代表这条直线。因此不必纠结“到底该取多长”，只要它非零、方向与直线一致就可以。

> **结论**：空间中的一条直线，可以由“直线上的一点”和“一个非零方向向量”确定。

> **易错点**：直线的方向向量和经过直线的平面的法向量不是一回事。前者顺着直线走，后者垂直于平面，符号上也最好按约定俗成的写法分开：方向向量记作 $\boldsymbol{s}$，法向量记作 $\boldsymbol{n}$。最好别随手换标号，不然和书上的记法一对不上，检查时就费劲了。

用一幅最简单的图把关系摆出来：

```text
          直线上一点 P₀(x₀, y₀, z₀)
                         +
          一个非零方向向量 s = (m, n, p)
                         ↓
             从 P₀ 出发，沿 s 双向延伸
                         ↓
                  得到唯一一条直线
```

读图：点和方向缺一不可；点管“从哪儿出发”，方向向量管“往哪儿走”。

### 先定交线，再定方向

#### 一般式：两个平面的交线

空间中的一条直线可以先看成两个平面的交线。设这两个平面为

$$
A_1x+B_1y+C_1z+D_1=0,
$$

$$
A_2x+B_2y+C_2z+D_2=0.
$$

那么这条直线就是同时满足这两个方程的点组成的公共部分。板书时很容易把它们看成一长串字母，其实别被它唬住：上面写的是一张“面”，下面写的是另一张“面”，两张面相交，交出来的那条缝就是直线。

所以，看到直线的两个一般式方程，第一件应当顺手做的事，是分别找出两个平面的法向量

$$
\boldsymbol{n}_1=(A_1,B_1,C_1),\qquad
\boldsymbol{n}_2=(A_2,B_2,C_2).
$$

它们虽然都垂直于各自的平面，但同时也共同垂直于这条交线。用法向量求直线方向的思路，就是从这里来的。

#### 点向式：一个点加上一个方向

现在换一个更直接的办法：假设直线经过 $P_0(x_0,y_0,z_0)$，方向向量是 $\boldsymbol{s}=(m,n,p)$，我们来找直线上任意一点 $P(x,y,z)$。

从 $P_0$ 指向 $P$ 的向量是

$$
\overrightarrow{P_0P}=(x-x_0,\ y-y_0,\ z-z_0).
$$

只要 $P$ 在这条直线上，$\overrightarrow{P_0P}$ 就必须与方向向量 $\boldsymbol{s}$ 平行。两个向量平行，对应坐标成比例，于是

$$
\boxed{
\frac{x-x_0}{m}
=
\frac{y-y_0}{n}
=
\frac{z-z_0}{p}
}.
$$

这个式子叫**点向式方程**，也叫**对称式方程**。“对称式”的意思就在三个分式的结构相似、写法对称；不过，“点向式”确实更说清楚它究竟在做什么：点指向方向，方向决定整条线。

> **易错点**：刚学时最好照着“先点、后方向”的顺序落笔。先完整写好 $x-x_0$、$y-y_0$、$z-z_0$，再依次放上方向向量的三个分量。三个分式同时写，最容易乱的就是把已知点放到分母、方向向量放到分子。

例如，直线经过点 $(1,2,3)$，方向向量是 $(-1,2,4)$，就有

$$
\frac{x-1}{-1}
=
\frac{y-2}{2}
=
\frac{z-3}{4}.
$$

### 有了点向式，推参数式

#### 从点向式到参数式

点向式当然能把直线的点、方向说清楚，但三个分式一起写，刚开始确实不太适应。参数式换个写法，常常更顺手。

还是以前面的直线为例：

$$
\frac{x-1}{-1}
=
\frac{y-2}{2}
=
\frac{z-3}{4}.
$$

令三个相等的比值为参数 $t$，就得到

$$
\begin{cases}
x=1-t,\\
y=2+2t,\\
z=3+4t.
\end{cases}
$$

这一组方程就是直线的参数方程。既然叫参数方程，$t$ 当然就是参数，它可以任意取值。$t=0$ 时，三个坐标回到 $1,2,3$，正好是直线上的已知点。$t$ 往正的方向增大，点沿 $(-1,2,4)$ 这一侧走；$t$ 往负的方向减小，就沿相反方向走。

也可以把刚才的系数统一写成“点的坐标加上 $t$ 乘方向分量”：

$$
\begin{cases}
x=1+t(-1),\\
y=2+t(2),\\
z=3+t(4).
\end{cases}
$$

这样一来，结构就特别清楚了：每个坐标都是“起点坐标 + 参数 × 方向分量”。三个 $t$ 的系数合起来，正是这条直线的方向向量。

拿 3D 打印机来想就很容易。打印机从 $(1,2,3)$ 出发，随着 $t$ 逐渐增大，把相邻的点一个个打印出来，连起来就是直线的一侧；$t$ 取负数，就朝相反方向打印，仍然落在同一条直线上。直线之所以是无限延伸的，原因就在这里：$t$ 没有停在某一个固定值上。

```text
        已知点 (1, 2, 3) + 方向向量 (-1, 2, 4)
                              ↓
                        引入参数 t
                              ↓
             x = 1 + t(-1)，y = 2 + 2t，z = 3 + 4t
                              ↓
                   t 任取，得到整条直线
```

读图：参数式没有换掉直线的点与方向，只是让点沿着这个方向动起来。

#### 从参数式倒推点向式

有时题目直接给参数式，反过来写点向式反而更费劲，但思路一点都不复杂：**先把参数 $t$ 提出来。**

假设

$$
\begin{cases}
x=2,\\
y=t,\\
z=1+t.
\end{cases}
$$

由这三个式子可以分别读出

$$
t=\frac{x-2}{0},\qquad
t=y,\qquad
t=z-1.
$$

于是先整理成

$$
\frac{x-2}{0}
=
\frac{y}{1}
=
\frac{z-1}{1}.
$$

为什么第一式可以出现零？因为这里的每个分式只是“$t$ 的同一个比值”，不是说真的要做一次除以零的运算。整理后一眼就能看出：直线上有点 $(2,0,1)$，方向向量是 $(0,1,1)$，所以点向式为

$$
\boxed{
\frac{x-2}{0}
=
\frac{y}{1}
=
\frac{z-1}{1}
}.
$$

> **易错点**：不要因为分母写着 $0$ 就立刻判定式子无效。关键看分式表示的是“比值”还是实际除法。这里三个分式都等于 $t$，$0$ 完全可以放在分母的位置上。

这一步最值得记住的不是某个具体数字，而是转换动作：先令 $t=0$ 找点，再把 $t$ 的系数合起来找方向。点向式和参数式，本来就是同一条直线的两种写法。

### 知道两个平面，怎样找回这条直线

来看一道完整的题。直线由两个平面的交线给出：

$$
\begin{cases}
x+y+z+1=0,\\
2x-y+3z+4=0.
\end{cases}
$$

要求用点向式和参数式表示。我们最终要拿到两样东西：方向向量、直线上一点。

先求方向向量。两个平面的法向量分别是

$$
\boldsymbol{n}_1=(1,1,1),\qquad
\boldsymbol{n}_2=(2,-1,3).
$$

交线同时垂直于这两个平面，所以取

$$
\boldsymbol{s}=\boldsymbol{n}_1\times\boldsymbol{n}_2
=(4,-1,-3).
$$

这个结果没有什么特别好化简的地方，就取 $\boldsymbol{s}=(4,-1,-3)$ 作为直线的方向向量。

再求直线上一点。最常见的做法是令 $x=0$，代回两个平面方程：

$$
\begin{cases}
y+z+1=0,\\
-y+3z+4=0.
\end{cases}
$$

两式相加，得到

$$
4z+5=0,\qquad z=-\frac54.
$$

代回第一式可得

$$
y=\frac14.
$$

所以直线上一点是

$$
P_0\left(0,\frac14,-\frac54\right).
$$

点和方向都有了，点向式直接写出来：

$$
\boxed{
\frac{x-0}{4}
=
\frac{y-\frac14}{-1}
=
\frac{z+\frac54}{-3}
}.
$$

相应的参数式则为

$$
\boxed{
\begin{cases}
x=4t,\\
y=\frac14-t,\\
z=-\frac54-3t.
\end{cases}
}.
$$

你算出来的点可能和书上的答案不一样，但不要一看到不同就慌。直线上的点不唯一，方向向量也不唯一。方向向量整体乘一个非零常数，仍能表示同一条方向；点向式最后表达的是同一条直线，不要求必须和书上的那个点、那组方向向量长得一模一样。

### 求点时，别只盯着一个坐标平面

例子里令 $x=0$，算起来很顺。但把问题再往前追一步：令 $x=0$、$y=0$、$z=0$，是不是一定能找到交点？

不一定。

$x=0$、$y=0$、$z=0$ 不是随手写下的三行条件，它们分别是三个坐标平面。令某个坐标等于零，本质上是让目标直线去和那个坐标平面相交。万一这条直线和该坐标平面平行，它就根本没有交点，代数上当然就解不出来。

例如，$x=0$ 表示一个平面。把一条直线想成笔直地立在黑板前面，并且与黑板平行，那么它和这个平面就没有交点。此时令 $x=0$ 求点，只会白忙一场。换一个坐标试试，令 $y=0$ 或令 $z=0$，也许就能找到。

但是，三个坐标平面都不行的情况不可能发生。三个坐标平面就像教室里的几面墙和地板，空间中的一条直线不可能与它们全都平行，它总能和其中至少一个平面相交。

> **结论**：求直线上的点时，令某个坐标等于零后如果无解，不要在同一条路上硬算；换另一个坐标平面继续试。

至于为什么常见的是令 $x=0$、$y=0$、$z=0$，而不是令某个坐标等于 $1$、$2$？因为“令坐标等于零”对应现成的坐标平面，想到这一层不需要额外构造；“这玩意谁能第一反应想到令 $x=1$”呢？能用坐标平面解释的取法，就优先用坐标平面。

参数方程还经常用在“求交点”这一类题上。直线与平面求交、两直线求交，题目要追着一个具体的交点走时，都可以考虑把直线的参数式摆出来。参数式中点会怎样变化，交点又在什么参数处被平面方程卡住，这些都要在后面的练习里继续熟悉。

### 直线的夹角：只取锐角部分

两根空间直线之间的夹角，就是它们各自方向向量夹角的锐角部分。这个角度有点不直观：你可以拿两条胳膊比划一下，两条胳膊的方向当然有夹角，但它们不一定相交。

所以，空间中两直线的夹角不要求两直线必须先交于一点。只要取到各自的方向向量 $\boldsymbol{s}_1$ 和 $\boldsymbol{s}_2$，就有

$$
\boxed{
\cos\theta
=
\frac{|\boldsymbol{s}_1\cdot\boldsymbol{s}_2|}
{|\boldsymbol{s}_1|\,|\boldsymbol{s}_2|}
},
\qquad
0\leq\theta\leq\frac{\pi}{2}.
$$

为什么要加绝对值？因为方向向量可以反向取，$\boldsymbol{s}_1$ 与 $\boldsymbol{s}_2$ 的夹角可能是钝角，但两条直线本身约定取锐角部分。若点积是负数，直接放进去会把 $\theta$ 算成钝角；用绝对值把它翻到正的一侧，最后得到的才是需要的角度。

> **易错点**：直线的夹角不是“两个方向向量夹角是多少，就原封不动取多少”。它有固定范围：$0\leq\theta\leq\pi/2$。方向向量的选法变了，方向向量的夹角可能变；直线的锐角夹角却不因此改变。

### 两根直线到底是什么关系

拿到两根直线的方向向量后，通常先判平行，再判垂直。两项都不是时，才归到斜交。常见的位置关系如下：

| 位置关系 | 用方向向量判断 | 还要注意什么 |
| :--- | :--- | :--- |
| 平行 | $\boldsymbol{s}_1\parallel\boldsymbol{s}_2$，对应坐标成比例 | 只有方向一致，还看不出是否重合 |
| 垂直 | $\boldsymbol{s}_1\cdot\boldsymbol{s}_2=0$ | 空间中通常是异面垂直；相交且共面时也可以垂直 |
| 重合 | 两个方向向量平行 | 再取一条直线上的一点，该点也必须落在另一条直线上 |
| 斜交（斜角） | 既不平行，也不垂直 | 还分异面斜交和同面斜交两种 |

“垂直”这一项最容易被平面几何的习惯带着跑。我们画图时，脑子里往往自动把它补成两条相交直线；但在空间里，垂直的两条直线完全可以不相交，甚至不在同一个平面上。因此，空间中谈垂直时，一般先想到的是**异面垂直**；相交、同面当然也算垂直。

判断重合也不能只看方向。两个方向向量平行，只能说明方向相同，还不能保证两条线就是同一条线。再从其中一条直线上取一点，如果这个点也满足另一条直线的方程，才能据此认定两线重合。

至于斜交，它就是剩下的情况：既不是特殊方向上的平行，也不是正交。因为平行、垂直、重合都比较特殊，斜交才是空间中两条直线更一般的样子。它也不只一种形态，可以异面，也可以同面。

### 例题：先判关系，再算夹角

给定两条直线

$$
L_1:\quad
\frac{x-1}{1}
=
\frac{y-4}{-4}
=
\frac{z+3}{1},
$$

$$
L_2:\quad
\frac{x-2}{2}
=
\frac{y+2}{-2}
=
\frac{z-1}{-1}.
$$

要求它们之间的夹角。先从分母读方向向量：

$$
\boldsymbol{s}_1=(1,-4,1),\qquad
\boldsymbol{s}_2=(2,-2,-1).
$$

拿到向量后别急着代夹角公式，先判断两直线的位置关系。

第一步，判平行。看对应分量：

$$
(1,-4,1)
ot\parallel(2,-2,-1).
$$

几个对应分量明显不成比例，所以不是平行。

第二步，判垂直。口算点乘：

$$
\boldsymbol{s}_1\cdot\boldsymbol{s}_2
=1\times2+(-4)\times(-2)+1\times(-1)
=2+8-1=9.
$$

点积不是零，所以也不是垂直。既然既不平行，又不垂直，两直线就是斜交的，位置关系判断到此为止。

最后求它们的锐角夹角：

$$
\cos\theta
=
\frac{|\boldsymbol{s}_1\cdot\boldsymbol{s}_2|}
{|\boldsymbol{s}_1|\,|\boldsymbol{s}_2|}
=
\frac{9}{\sqrt{1^2+(-4)^2+1^2}\,\sqrt{2^2+(-2)^2+(-1)^2}}.
$$

两个模分别是

$$
|\boldsymbol{s}_1|=\sqrt{18},\qquad
|\boldsymbol{s}_2|=3.
$$

因此

$$
\cos\theta=\frac{9}{3\sqrt{18}}=\frac{\sqrt2}{2},
$$

$$
\boxed{\theta=\frac{\pi}{4}}.
$$

这道题真正值得练熟的是判断顺序：先看对应分量是否成比例，再看点积是否为零，最后才进入求夹角的公式。不要看到两个分式方程就立刻背公式往里代。

### 直线与平面的夹角：方向向量遇上法向量

直线与平面的夹角有严格的几何定义：在直线上任取一点，从这点向平面作垂线，垂线与平面的交点叫垂足；把这点和垂足连起来，这段连线与原直线所夹的锐角，就是直线与平面的夹角。

它的取值范围仍然是

$$
0\leq\theta\leq\frac{\pi}{2}.
$$

图上随手取到的角有时看着像钝角，但定义取的是锐角部分，别随手拿图上的“视觉角”替代它。

接下来要换一个角色。前面量两根直线，用的是两个方向向量；现在只有一根直线和一个平面，于是取直线的方向向量 $\boldsymbol{s}$，再取平面的法向量 $\boldsymbol{n}$。直线的方向用 $\boldsymbol{s}$ 找，垂直于平面的方向用 $\boldsymbol{n}$ 找，两个向量就准备好了。

真正的转换可以用三角形来处理。先认清图上标出的待求角 $\theta$ 在哪儿，再看 $\boldsymbol{s}$ 与 $\boldsymbol{n}$ 夹的是哪个角，这两个角并不是画图时随手一指就能当成同一个角。后续用向量算长度和夹角时，真正要做的是借助三角形，把方向向量与法向量的夹角换到所求的 $\theta$ 上，而不是把“两向量求夹角”的旧公式原封不动套过来。空间里的直线与平面，落到向量运算上，核心仍然是先找准对象的垂直关系。

## 从夹角到位置关系：直线与空间中的基本问题
> 对应块：BLK114 | 覆盖分集：P121下 | 块标题（分集名）：《【黑板】直线及其方程》

把几种夹角公式并排写出来，你会发现它们长得实在太像了：都是“两个向量做点乘，再除以两个向量的模的乘积”。可这里偏偏有的是余弦、有的是正弦，分子的绝对值也时有时无。要是把它们混在一起，做题时就只能靠背；真正把“取锐角还是取钝角”“方向向量与法向量到底谁和谁垂直”弄清楚，公式里的每一个符号都有理由。

接下来我们就顺着这个思路，把夹角、直线与平面的位置关系，以及常见求法连起来。

### 四个夹角公式，关键在加不加绝对值

设 $\boldsymbol a,\boldsymbol b$ 是两个向量，$\boldsymbol s_1,\boldsymbol s_2$ 是两条直线的方向向量，$\boldsymbol n_1,\boldsymbol n_2$ 是两个平面的法向量，$\boldsymbol s$ 是一条直线的方向向量，$\boldsymbol n$ 是一个平面的法向量。四种常用夹角公式如下。

| 夹角 | 公式 | 取值与绝对值的原因 |
| :--- | :--- | :--- |
| 两向量的夹角 | $\displaystyle \cos\theta=\frac{\boldsymbol a\cdot\boldsymbol b}{|\boldsymbol a||\boldsymbol b|}$ | 夹角可以取钝角，所以分子不取绝对值 |
| 两平面的夹角 | $\displaystyle \cos\theta=\frac{|\boldsymbol n_1\cdot\boldsymbol n_2|}{|\boldsymbol n_1||\boldsymbol n_2|}$ | 取锐角，法向量点乘后要取绝对值 |
| 两直线的夹角 | $\displaystyle \cos\theta=\frac{|\boldsymbol s_1\cdot\boldsymbol s_2|}{|\boldsymbol s_1||\boldsymbol s_2|}$ | 取锐角，方向向量点乘后要取绝对值 |
| 直线与平面的夹角 | $\displaystyle \sin\theta=\frac{|\boldsymbol s\cdot\boldsymbol n|}{|\boldsymbol s||\boldsymbol n|}$ | 取锐角；这里的夹角是方向向量与法向量的夹角 |

> **结论**：两平面的夹角、两直线的夹角用余弦，直线与平面的夹角用正弦；除“两向量的夹角”外，分子都要加绝对值。

#### 为什么最后一个偏偏是 $\sin\theta$

两向量的夹角 $\theta$ 可以大于 $90^\circ$，因此直接用点积公式：

$$
\cos\theta
=\frac{\boldsymbol a\cdot\boldsymbol b}{|\boldsymbol a||\boldsymbol b|}.
$$

但两平面、两直线只取锐角。它们的法向量或方向向量可能正交，也可能夹成钝角；为了让公式只反映夹角的大小、不受所选向量正负方向的影响，就在分子上加绝对值。

直线与平面则多转了一个弯。我们要求的 $\theta$，是直线和平面本身所成的锐角；$\boldsymbol s$ 与 $\boldsymbol n$ 的夹角则是 $\frac{\pi}{2}-\theta$，两者互余。所以

$$
\cos\left(\frac{\pi}{2}-\theta\right)
=\sin\theta
=\frac{|\boldsymbol s\cdot\boldsymbol n|}{|\boldsymbol s||\boldsymbol n|}.
$$

这里写成 $\sin\theta$，一点也没写错。看到 $\sin$，不要先怀疑公式，得先看清题目究竟要的是哪一个角。

> **易错点**：不要把直线与平面的夹角，直接套成方向向量与法向量的夹角。前者与后者互余，这正是最后一种公式单独出现 $\sin$ 的原因。

### 直线与平面的位置关系，不止“平行”一种

直线和平面的位置关系，常见的有四种：

| 位置关系 | 方向向量 $\boldsymbol s$ 与法向量 $\boldsymbol n$ 的关系 |
| :--- | :--- |
| 直线与平面平行 | $\boldsymbol s\cdot\boldsymbol n=0$ |
| 直线与平面垂直 | $\boldsymbol s\parallel\boldsymbol n$ |
| 直线落在平面内 | $\boldsymbol s\cdot\boldsymbol n=0$，且直线上有一点的坐标满足平面方程 |
| 直线与平面斜交 | 既不垂直，也不平行 |

其中，直线垂直于平面最好判断：平面的法向量 $\boldsymbol n$ 与平面内所有方向都垂直，所以把 $\boldsymbol n$ 取作直线的方向向量，直线就与平面垂直。

直线平行于平面，则是 $\boldsymbol s\perp\boldsymbol n$。法向量垂直于平面，方向向量又垂直于法向量，因此方向向量和这个平面平行。不过，只做到这里，我们还只是说明它“方向上不会穿过平面”，究竟是落在平面内，还是在平面外，还差一步。

#### 平行和在平面内，用一个点就能分开

现在假设已经知道 $\boldsymbol s\cdot\boldsymbol n=0$。从直线上任取一点 $P$，把它的坐标代入平面方程：

- 满足平面方程，直线就在平面内；
- 不满足平面方程，直线与平面平行。

为什么只要检查一个点就够了？因为 $\boldsymbol s\perp\boldsymbol n$，沿直线移动时，位置向量在法向量方向上的投影不会改变。因此，一个点满足平面方程，直线上所有点都满足；一个点不满足，整条直线都不在这个平面内。

> **结论**：判断直线和平面的位置关系，先看 $\boldsymbol s$ 与 $\boldsymbol n$ 是否垂直；若垂直，再取直线上一点代入平面方程，区分“落在平面内”和“平行”。

#### 直线在平面内，不能说与平面“重合”

“直线落在平面内”，不要改口说“直线与平面重合”。

两个东西要谈重合，首先得是对等的概念。两根直线可以重合，因为它们本质上都是线；两个平面也可以重合，因为它们本质上都是面。直线和平面却不是同一层次的对象：一个平面是整个无限延展的面，直线只是其中一条细线。平面当然比“一根线”大得多，它们并不相等。

可以想成两个双胞胎：两人长得一模一样，叫作一样，那也得先是同一层次的人。直线与平面不对等，所以不能叫“重合”。

至于“直线在平面内算不算平行”，这里也不能含糊。我们说“直线与平面平行”，指的就是直线在平面外与平面平行。落在平面内这个特殊情况，已经不包含在“平行”这个说法里了。

剩下一种就是斜交：直线穿过平面，但不和这个平面垂直。就是斜着过来，不需要另外找什么新公式。

> **易错点**：直线与平面没有“重合”这个位置关系。落在平面内与在平面外平行，也不能混为一谈。

### 过一点作平面的垂线：法向量直接作方向向量

现在做一个很典型的题：**过点 $A(1,-2,4)$，作平面 $2x-3y+z-4=0$ 的垂线。**

先画图想一想：一个平面，一个给定点，要从点出发作平面的垂线。点有了，方向呢？

平面方程已经给出了法向量

$$
\boldsymbol n=(2,-3,1).
$$

与平面垂直的直线，方向向量就取平面的法向量。于是点有了，方向也有了，直接写对称式：

$$
\boxed{\frac{x-1}{2}=\frac{y+2}{-3}=\frac{z-4}{1}}.
$$

这类题不用绕弯子。**给定点用过一点的法向直线，就把平面的法向量搬来作直线方向向量。** 但相应的图一定要适当画一画；脑中能把点、平面和法向直线摆到同一个空间里，后面的空间几何题才不会只靠公式硬套。

> **易错点**：对称式每一项都要“坐标减已知数”。点 $A(1,-2,4)$ 对应的分子就是 $x-1$、$y+2$、$z-4$，特别是中间一项的 $+2$，不要漏掉这个加号。

### 与两平面的交线平行：先求交线的方向向量

下一题是：**过点 $A(-3,2,5)$，作与直线 $\ell$ 平行的直线，其中 $\ell$ 是两个平面 $x-4z=3$ 与 $2x-y-5z=1$ 的交线。**

既然已经给出了交线，我们还可以把它写成交线方程

$$
\begin{cases}
x-4z=3,\\
2x-y-5z=1.
\end{cases}
$$

但求与它平行的直线，不需要把交线的方程再解出来；只要知道它的一个方向向量。直线的方向向量垂直于交线所在的所有平面，所以取两个已知平面的法向量的叉积即可：

$$
\boldsymbol n_1=(1,0,-4),\qquad
\boldsymbol n_2=(2,-1,-5),
$$

$$
\boldsymbol s=\boldsymbol n_1\times\boldsymbol n_2
=(-4,-3,-1).
$$

成比例的向量都能表示同一条直线的方向。这里可以统一乘上 $-1$，取

$$
\boldsymbol s=(4,3,1).
$$

再将已知点代入对称式：

$$
\boxed{\frac{x+3}{4}=\frac{y-2}{3}=\frac{z-5}{1}}.
$$

> **结论**：给的是“两平面的交线”，求与它平行的直线，方向向量取两法向量的叉积；点给了、方向有了，就可以直接写直线。

方向向量不必死抠叉积算出的那一组。只要整体成比例，就可以取整数、约去公因数，甚至把三个数都变号，得到更简洁的同一组方向向量。

### 求交点：先把直线变成参数式

直线和平面求交点，一看到“交点”，脑子里就应该立刻冒出**参数式**。直线与直线求交点如此，直线与平面求交点也是如此。

已知直线

$$
\frac{x-2}{1}=\frac{y-3}{1}=\frac{z-4}{2},
$$

以及平面

$$
2x+y+z-6=0.
$$

把分母都设成同一个参数 $t$。参数式不用死记：看到哪一项是 $t$ 的分母，就用 $t$ 去表示它。直线上的点就是

$$
x=2+t,\qquad y=3+t,\qquad z=4+2t.
$$

现在把这组坐标整个塞进平面方程：

$$
2(2+t)+(3+t)+(4+2t)-6=0.
$$

整理得

$$
5+5t=0,\qquad t=-1.
$$

把 $t=-1$ 代回，三个坐标便一起出来：

$$
\boxed{P(1,2,2)}.
$$

这就是“参数式好处理”的原因：三个坐标被一个参数 $t$ 拴在一起。求直线与平面的交点时，不必分别去解三个方程，只要把参数式代入平面，再把参数解出来即可。

> **提示**：平面如果有截距式，看到与 $x$ 轴、$y$ 轴、$z$ 轴的截距，就想到截距式；求交点，就想到参数式。让不同条件触发各自熟悉的方程，不要拿一种形式硬解所有问题。

### 垂直而且相交：让连接向量垂直于原直线

接下来看一道很容易把“垂直”和“垂直相交”混淆的题：**过点 $A(2,1,3)$，作直线 $\ell$ 的垂线，并且要求与 $\ell$ 相交。**

这里的“与直线垂直”一定要听完整。两根直线可以异面垂直，可题目偏偏还要求“相交”，所以这就不是随便找一条方向垂直的直线，而是要过给定点作一条垂直的**垂线段**。既然相交，就一定有交点，仍然先写参数式。

已知直线

$$
\frac{x+1}{3}=\frac{y-1}{2}=\frac{z}{1}.
$$

设它上面的一点为 $P$，则

$$
P(t)=(-1+3t,\ 1+2t,\ -t),
$$

其方向向量是

$$
\boldsymbol s=(3,2,1).
$$

要使 $AP$ 与原直线垂直，就要让 $\overrightarrow{AP}$ 与 $\boldsymbol s$ 的点乘等于零。向量用终点减起点：

$$
\overrightarrow{AP}
=P(t)-A
=(-3+3t,\ 2t,\ -t-3).
$$

于是

$$
(-3+3t,2t,-t-3)\cdot(3,2,1)=0,
$$

$$
-9+9t+4t-t-3=0.
$$

化简得到

$$
12t-12=0,\qquad t=1.
$$

所以垂足为

$$
P(1)=(2,3,-1).
$$

所求直线的方向向量可以直接取

$$
\overrightarrow{AP}=(0,2,-4)\sim(0,1,-2).
$$

最终写成

$$
\boxed{y-1=\frac{3-z}{2}}.
$$

这里不绕弯子：先找交点，再写交点的参数式；交点与给定点连接成的向量，必须和原直线方向向量垂直。用点乘等于零，把参数解出来，整道题就结束了。

> **易错点**：“两直线垂直”不必然相交，因为还可能是异面垂直；“过一点作直线的垂线”则要求那条垂线真的穿过已知直线。题目若同时说了“垂直、相交”，就要老老实实找垂足。

### 过一条直线的所有平面：平面束

还有一类题，看起来名字有点吓人：求过一条已知直线的所有平面。这叫作直线的**平面束**。

可以想象一本合上的书。中间的“书脊”是一条已经确定的直线；把书向不同方向翻开，每一页纸的平面都经过这条书脊。于是过这条直线的所有平面，就像围绕书脊翻开的书页。

```text
                     确定的直线（书脊）
                            │
              ╱─────────────┼─────────────╲
             ╱              │              ╲
            ╱               │               ╲
           ╱     过这条直线的各个平面         ╲
          ╱                                  ╲
```

> **定义**：过同一条直线的所有平面，称为这条直线的平面束。

假定一条直线由两个相交平面

$$
\Pi_1:\ x+y-z-1=0,
\qquad
\Pi_2:\ x-y+z+1=0
$$

确定。既然这两个平面方程可以写成 $F_1=0$、$F_2=0$，那么将它们作线性组合，也能得到一个经过原直线的平面：

$$
\Pi_\lambda:\ F_1+\lambda F_2=0.
$$

把它展开，就是

$$
(1+\lambda)x+(1-\lambda)y+(\lambda-1)z+(\lambda-1)=0.
$$

这里一定要盯住“**一个式子照搬，另一个整体乘上 $\lambda$**”：左边的第一式不乘，第二式整体乘上 $\lambda$，再相加令其等于零。它仍然是一个平面方程；$\lambda$ 取不同的值，就得到不同的平面，而原直线的交点同时满足 $F_1=0$ 和 $F_2=0$，自然也满足这个线性组合。

> **结论**：两平面的交线可以表示成平面束 $F_1+\lambda F_2=0$。看到“直线加上一个约束条件”，常常就可以从这个平面束里挑出合适的那个平面。

### 直线在平面上的投影，只需挑出那一个垂直平面

给定直线

$$
\begin{cases}
x+y-z-1=0,\\
x-y+z+1=0,
\end{cases}
$$

以及平面

$$
x+y+z=0,
$$

求这条直线在给定平面上的投影直线。

先把题目意思弄明白。所谓“直线在平面上的投影直线”，从 $l$ 上任取一点，向 $\Pi$ 作垂线；垂线在 $\Pi$ 上的垂足连成的那条直线，就是 $l$ 在 $\Pi$ 上的投影。因此，我们需要的，是过原直线且与 $\Pi$ 垂直的那个平面。

这正好是平面束派上用场的地方：原直线就是两个已知平面的交线，它所生成的平面束为

$$
x+y-z-1+\lambda(x-y+z+1)=0.
$$

它的法向量可以读出来：

$$
\boldsymbol n_\lambda=(1+\lambda,\ 1-\lambda,\ \lambda-1).
$$

所给平面的法向量是

$$
\boldsymbol n=(1,1,1).
$$

要使这两个平面垂直，它们的法向量就要点乘为零：

$$
(1+\lambda,1-\lambda,\lambda-1)\cdot(1,1,1)=0.
$$

因此

$$
1+\lambda+1-\lambda+\lambda-1=0,
$$

解得

$$
\lambda=-1.
$$

代回平面束，得到与所给平面垂直的平面

$$
(x+y-z-1)-(x-y+z+1)=0,
$$

即

$$
y-z-1=0.
$$

投影直线就在“$x+y+z=0$”和“$y-z-1=0$”的交线上。联立后得到 $x=0$、$y=\frac12$、$z=-\frac12$，所以投影方向为 $(0,1,-1)$，投影直线为

$$
\boxed{\left(0,\frac12,-\frac12\right)+t(0,1,-1)}.
$$

这个题当然有别的做法。平面束并不总是做题时最短的路线，它更像是一把好用的备用钥匙：先知道它能做什么，遇到“过直线的一族平面”再加垂直、平行等条件时，就知道可以从哪里下手。

### 本讲提到的题目

这里把这一讲出现过的题目集中收拢。每一题的完整推导都在上面相应的小节中，答题时先抓住条件对应的向量关系，再选最合适的方程形式。

#### 过一点作平面的垂线

**题目**：过点 $A(1,-2,4)$ 作平面 $2x-3y+z-4=0$ 的垂线。

**答案**：平面的法向量 $(2,-3,1)$ 就是垂线的方向向量，故所求直线为
$$
\frac{x-1}{2}=\frac{y+2}{-3}=\frac{z-4}{1}.
$$

#### 作与两平面交线平行的直线

**题目**：过点 $A(-3,2,5)$，作与直线平行的直线；给定直线是平面 $x-4z=3$ 与 $2x-y-5z=1$ 的交线。

**答案**：交线的方向向量可取
$$
(1,0,-4)\times(2,-1,-5)=(-4,-3,-1)\sim(4,3,1).
$$
所求直线为
$$
\frac{x+3}{4}=\frac{y-2}{3}=\frac{z-5}{1}.
$$

#### 求直线与平面的交点

**题目**：求直线
$$
\frac{x-2}{1}=\frac{y-3}{1}=\frac{z-4}{2}
$$
与平面 $2x+y+z-6=0$ 的交点。

**答案**：令直线参数为 $t$，将 $x=2+t$、$y=3+t$、$z=4+2t$ 代入平面，得 $5+5t=0$，所以 $t=-1$，交点为
$$
\boxed{(1,2,2)}.
$$

#### 过一点作已知直线的垂线，且与已知直线相交

**题目**：过点 $A(2,1,3)$，作直线
$$
\frac{x+1}{3}=\frac{y-1}{2}=\frac{z}{1}
$$
的垂线，并且要求相交。

**答案**：设垂足为 $P(t)=(-1+3t,1+2t,-t)$，由 $\overrightarrow{AP}\cdot(3,2,1)=0$ 得 $t=1$。垂足为 $(2,3,-1)$，所求直线为
$$
\boxed{y-1=\frac{3-z}{2}}.
$$

#### 求直线在平面上的投影直线

**题目**：求直线
$$
\begin{cases}
x+y-z-1=0,\\
x-y+z+1=0
\end{cases}
$$
在平面 $x+y+z=0$ 上的投影直线。

**答案**：过原直线且与给定平面垂直的平面为 $y-z-1=0$。它与给定平面的交线方向为 $(0,1,-1)$，投影直线为
$$
\boxed{\left(0,\frac12,-\frac12\right)+t(0,1,-1)}.
$$

## 曲面怎么认：球面、旋转曲面与二次曲面
> 对应块：BLK115 | 覆盖分集：P122 | 块标题（分集名）：《【黑板】曲面》

曲面这部分本身内容不算多，但后面三重积分、曲面积分都要用，尤其是三重积分。所以这一讲先不急着算什么，先得把几类最常见的曲面认出来，特别是旋转曲面——考试特别容易考，题目往往就是一个填空。

真正需要仔细听的是旋转曲面。它的定义并不复杂，难的是我们脑子里的坐标轴只有 $x$、$y$，突然多出一个 $z$ 轴，很容易晕。

### 球面：先看距离，再配方

球面最直接。它以 $M_0(x_0,y_0,z_0)$ 为球心，半径为 $R$。球面上的点到球心的距离都等于 $R$，所以

$$
\sqrt{(x-x_0)^2+(y-y_0)^2+(z-z_0)^2}=R.
$$

有时候也不写根号，两边同时平方，得到更常用的形式：

$$
(x-x_0)^2+(y-y_0)^2+(z-z_0)^2=R^2.
$$

如果球心在原点 $O(0,0,0)$，就直接简化成

$$
x^2+y^2+z^2=R^2.
$$

> **定义**：$M_0(x_0,y_0,z_0)$ 是球心，$R$ 是半径。记住"球面上的所有点到球心的距离都等于半径"这一句，球面方程就不用记了。

再来看一个具体例子：

$$
x^2+y^2+z^2-2x+4y=0
$$

表示什么曲面？很明显用配方。$x^2-2x$ 配方加一，$4y$ 配方加四，得到

$$
(x-1)^2+(y+2)^2+z^2=5.
$$

球心是 $(1,-2,0)$，半径是 $\sqrt{5}$。一四是一五，左右两边同时乘以五。$z^2$ 没有一次项，就不用配方。

> **易错点**：配方时注意$y+2$里的$2$对应的是$-4y$，$x-1$里的$1$对应的是$-2x$。右边$5$别漏了，那是把两边同时加上的$1+4$。

后面遇到三元二次方程，一般就表示一个球面。做题这部分没有什么太大的问题，简单的东西我们一略而过。

### 旋转曲面：哪个轴不动，哪个平方补上去

先说什么叫旋转曲面。我们在 $YOZ$ 平面上有一条曲线，假设它的方程是

$$
F(y,z)=0.
$$

注意它和我们平常讲的不太一样，平常不是 $x$ 就是 $y$，这里方是个 $y$ 和 $z$ 的函数，是一条平面曲线。到目前为止它还是个平面曲线，是 $y$ 和 $z$ 之间的一个表达式。现在把这条曲线沿着 $z$ 轴旋转 $360$ 度一周，就得到了一个三维的曲面。

现在问旋转完了以后它的曲面方程是什么？这里比较难，一定要仔细听。

为了防止大家把原来的表达式和新的表达式区别不开，我故意把这里的 $y$ 和 $z$ 都写上。$y_1$ 和 $z_1$ 是原来的 $y$ 和 $z$ 的变量。它围绕着 $z$ 轴旋转，随便取一个点，假设原来的点 $(y_1,z_1)$，那么这个 $z_1$ 坐标在旋转过程中是不动的——因为它是绕 $z$ 轴旋转的，是平着转的。

那么什么东西动了呢？原来在 $YOZ$ 平面上的这个点，它到 $z$ 轴的距离就是一个"$y$ 值"。旋转之后，这个 $y$ 值变成了到 $z$ 轴的距离，而这个距离正是 $\sqrt{x^2+y^2}$。所以原来的 $y_1$ 变成了 $\pm\sqrt{x^2+y^2}$。

书上就是这么写的

$$
\sqrt{x^2+y^2}=|y_1|.
$$

但做题的时候我们一般是这么写：把原来的 $y$ 变成 $\sqrt{x^2+y^2}$。这是为什么？因为原来的 $y$ 有可能是正的，也可能是负的，我们不是把它变成 $y$ 本身，而是把它变成它的绝对值 $|y|$。而 $|y|=\sqrt{x^2+y^2}$，这里多出来的 $x$ 就是原来没有的那个变量。

实际上，做题时更常用的写法是：$\sqrt{x^2+y^2}=|y_1|$，然后两边同时平方，得到

$$
x^2+y^2=y_1^2.
$$

然后你回头看原来的方程，原来的 $y$（就是 $y_1$）是出现在 $y^2$ 这个位置的，所以就把 $y_1^2$ 这个位置换成 $x^2+y^2$。

我知道讲到这里大家可能"我好像完全听懂了"又"好像一个字都没听懂"，不要紧，我再给你举个例子，保证你听懂。

#### 例子一：$z=y^2$ 绕 $z$ 轴旋转

原来 $y$ 和 $z$ 的表达式是 $z=y^2$，这个大家太熟了，不就是个简单的二次函数吗？这个图咱比较熟。注意原来这个 $z=y^2$ 是个平面上的图。说把这个曲线围绕着 $z$ 轴旋转 $360$ 度，旋转完了以后这个小图这么一画一旋转，大家是比较清楚的。

现在问，这就成一个考试题了：说这个方程围绕着 $z$ 轴旋转得到的曲面方程是什么东西？这是个填空题。

首先，围绕着 $z$ 轴旋转，它的 $z$ 坐标是不动的。那么原来这个点原来的 $y$ 的这个值，它这么一旋转得到的是个圆，圆的方程是不是 $x^2+y^2=R^2$？原来那个 $R$ 就是 $y$ 的绝对值，所以就是把原来的 $y^2$ 变成 $x^2+y^2$，这个曲面就是 $x^2+y^2=z$。

老师这我好像没太懂。没关系，我再给你举个例子。

#### 例子二：$y=x^2$ 绕 $y$ 轴旋转

原来有个图，说 $y=x^2$，这个大家忒熟了吧，这是最简单的二次函数。因为一会儿要画三维的图，所以我把 $x$ 轴 $y$ 轴规划成这个样子。

现在围绕着 $y$ 轴旋转 $360$ 度，一旋转得到的是这么个图。先看原来的这个点，它的 $y$ 坐标是不变的，所以 $y$ 是不变的。原来这个点这么一旋转是个圆，这个圆是关于 $xz$ 的一个圆，圆心在原点，所以是 $x^2+z^2=R^2$，这里的 $R$ 是啥？是 $y$。所以原来的 $x^2$ 现在变成了 $x^2+z^2$，结果就是 $x^2+z^2=y$。

#### 例子三：$z=y$ 绕 $z$ 轴旋转得到圆锥面

在 $y$ 和 $z$ 坐标里面，有一条直线 $z=y$，这个好理解吧？最简单的一次函数。说把这条直线绕着 $z$ 轴旋转 $360$ 度——大家先在脑海中构思一下。

好，我们开始算了。任取原来曲线上的任意一点，这个 $z$ 是不动的（因为它绕着 $z$ 轴旋转）。那么原来的这个 $y$ 值，这个点这么一旋转形成了一个圆，这个圆是关于 $xy$ 的一个圆，圆心在原点，那就是 $x^2+y^2=R^2$，这个 $R$ 就是原来 $y$ 的绝对值。所以

$$
x^2+y^2=y_1^2.
$$

只不过这个地方这样写很别扭：$y$ 和 $y_1$ 长得一模一样，你不能给他约了吧？不，不是这个意思，是把它变成 $y$ 的绝对值，然后就是 $\sqrt{x^2+y^2}=|y_1|$。你原来不是 $y$ 吗？现在不是变成 $\pm\sqrt{x^2+y^2}$ 了吗？那这个 $y_1$ 不就是 $\pm\sqrt{x^2+y^2}$ 了吗？没错。

> **易错点**：原来的 $y$ 是什么就变成什么（$y\to\pm\sqrt{x^2+y^2}$），原来出现 $y^2$ 的地方就变成 $x^2+y^2$。原来是 $y$ 线性出现，然后把两边同时平方，得到 $x^2+y^2=z^2$。所以得到的这个圆锥面就是 $x^2+y^2=z^2$。

### 柱面：没有哪个坐标，就平行于哪个轴移动

## 空间曲线：看见两个曲面的交线
> 对应块：BLK116 | 覆盖分集：P123 | 块标题（分集名）：《【黑板】空间曲线》

### 这部分以理解为主

空间曲线很少单独出题，可它偏偏不能略。后面的曲线积分就是沿着空间曲线做积分，真到那一步，题目里出现的曲线又相对简单，一般就是直线；真要绕得太复杂，题目本身也不好做。所以这一块的心态要摆正：别急着背公式，先把图看清楚。定义记住了、图想象出来了，后面自然接得上；硬背几条结论，考场上照样画不出交线。

### 空间曲线是两个曲面的交线

> **定义**：空间曲线可以理解为两个曲面的公共轨迹，也就是两个曲面相交得到的曲线。

最好用的例子就在手边：书的两页纸。每一页都是一个平面，而平面是曲面的特殊情形。两页纸相交，交出来的是什么？书脊上的一条直线。直线当然也是曲线的特殊情况。于是"两个曲面相交得到曲线"这件事，就有了最朴素的理解。

这里的关键是"两个曲面"，不是两个方程随便凑在一起，更不是把一条线和一个面拼起来。无论后面碰到圆柱、球还是锥，骨架都是这一句。

```text
   曲面 ①  x² + y² = 1（圆柱面）
   曲面 ②  2x + 3z = 6（平面）
   ─────────────────────────────
   两者相交  →  一条空间曲线
```

### 两个例子：先认曲面，再想交线

遇到两个方程一起给，先别急着联立求解。正确的顺序是：先把每一个方程认成它所描述的曲面，想象两个面怎么相遇，交线自然就浮出来了。

#### 圆柱面被平面斜着切一刀

$$x^2+y^2=1,\qquad 2x+3z=6$$

先看第一个。它在 $xOy$ 面里是一个半径为 1 的圆，式子里没有 $z$，也就是这个圆可以沿着 $z$ 轴上下自由搬家，于是得到半径为 1 的圆柱面——我们一直叫它"烟囱"。

再看第二个。它只含 $x,z$，不含 $y$，是 $xOz$ 平面里的一条直线：和 $x$ 轴交在 $x=3$（$2\times 3=6$），和 $z$ 轴交在 $z=2$（$3\times 2=6$）。不含 $y$ 就意味着这条直线可以沿着 $y$ 轴平移，一整片扫过去，扫出的正是一个平面。这个平面是斜的，它与 $x$ 轴的交点 $x=3$ 在圆柱面外（圆柱面横截面半径只有 1），与 $z$ 轴的交点 $z=2$ 也在上方，所以切出来的口子当然不是平的。

两件事凑在一起：圆柱面被一个斜着的平面斜切一刀，交线就是一条空间曲线。

这刀的斜度不用死算，你就找一支粗一点的笔当烟囱——笔身就是圆柱面，拿刀这么斜着削一下，削出来的那圈就是交线。不难吧。

#### 上半球面上怼进一根烟囱

$$z=\sqrt{a^2-x^2-y^2},\qquad \left(x-\frac a2\right)^2+y^2=\left(\frac a2\right)^2$$

第一个方程两边平方，得到 $x^2+y^2+z^2=a^2$；又因为 $z$ 取的是正根号，$z\ge 0$，所以它是半径为 $a$ 的上半球面。这个已经讲过好几回了，样子就是半个西瓜。

第二个方程先在 $xOy$ 面里看：它是一个圆，圆心在 $\left(\frac a2,\,0\right)$，半径为 $\frac a2$。没有 $z$，照样沿 $z$ 轴上下平移，于是又是一个圆柱面，还是一根"烟囱"。

这回画面就清楚了：半个西瓜上，拿烟囱怼了一下。烟囱壁和西瓜皮贴在一起的那条线，就是交线——仍然是两个曲面相交得到的曲线。至于黑板上画出来的立体图，我肯定不如书上画得好，你把注意力放在"两个曲面相交成一条曲线"这件事上就够了。

把已经见过的组合放在一起看，规律就很直白：

| 两个相交的曲面 | 形象理解 | 交线 |
| :--- | :--- | :--- |
| 两个平面 | 书的两页纸 | 书脊上的直线 |
| 圆柱面与斜平面 | 烟囱被斜着切一刀 | 斜着切出来的那一圈 |
| 上半球面与圆柱面 | 半个西瓜上怼进一根烟囱 | 烟囱壁和西瓜皮贴合的那条线 |

### 参数方程：一个参数带着三个坐标走

空间曲线的参数方程写成

$$x=x(t),\qquad y=y(t),\qquad z=z(t).$$

三个坐标都由同一个参数 $t$ 控制。$(x,y,z)$ 是空间中一个点的坐标，$t$ 一动，这个点就在空间里划出一条轨迹；轨迹跑遍了，就是曲线。这和一元函数的图像是同一个想法，只不过图像里的"点"搬到了三维空间。

这一节同样以理解为主。真正做曲线积分时，题目里的曲线一般都很简单，因为太麻烦题目就不好做了。

课本上给的例子是：圆柱面 $x^2+y^2=a^2$ 上有一个点，它以角速度 $\omega$ 绕 $z$ 轴旋转，同时以速度 $v$ 沿 $z$ 轴正方向匀速上升。求它的参数方程。

```text
   圆柱面        x² + y² = a²
   旋转          ↻ 绕 z 轴，角速度 ω（匀速）
   上升          ↗ 沿 z 轴正方向，速度 v（匀速）
   ─────────────────────────────
   投影到 xOy 面  半径 a 的圆上匀速转圈
   高度          z = vt
```

三步就够了。

$z$ 坐标最简单：竖直方向速度恒为 $v$，走了时间 $t$，高度自然就是 $z=vt$。虽然它在空间里是螺旋着走的，可你只盯着 $z$ 坐标看，它就是笔直、匀速地往上走。

$x,y$ 坐标是绕圈子的结果。把这条螺旋线投影到 $xOy$ 面上，它就是半径为 $a$ 的圆上匀速转圈。角速度是匀速的——就像老驴拉磨，一圈一圈，快慢不变。时间是 $t$，角速度是 $\omega$，那么转过的角度就是 $\omega t$。半径是 $a$，夹角是 $\omega t$，$x$ 是这个角的邻边，$y$ 是对边，于是

$$x=a\cos(\omega t),\qquad y=a\sin(\omega t).$$

合起来就是

$$\begin{cases}
x=a\cos(\omega t),\\
y=a\sin(\omega t),\\
z=vt.
\end{cases}$$

这里有一个特别值得停一下的问题：$\omega t$ 一直变大，点怎么能绕圈圈，它不会越转越远吗？问得好。$\omega t$ 确实一直变大，但 $\cos$ 和 $\sin$ 是周期函数。角度一过 $2\pi$，就正好转完一圈又回到原处，接着转第二圈。所以 $x,y$ 在绕圈圈，$z$ 在稳稳地往上走，两个一合，就是一条螺旋上升的线。

顺便说一句，课本后面还会出现球面方程，这里就不重复了——三重积分里的球面坐标是个很重要的点，放到那个时候再详细讲。

### 投影：空中的圆和它的影子

空间曲线在坐标面上的投影，这一整节课文我们先不展开；但最后一个例子必须吃透，因为到了三重积分、曲面积分，它天天出现。甚至"先一后二还是先二后一"的积分顺序选择，都要靠投影来定。立体图想象不出来，很多三重积分的题目就只能干瞪眼。

这里我插一句实在话：很多同学其实从这儿开始就已经听不懂了。但事情从这儿往下只会越变越糟，不会越来越好，所以一定得好好听。

题目给了两个曲面，要求求出它们的交线，并求交线在 $xOy$ 面上的投影：

$$z=\sqrt{4-x^2-y^2},\qquad z=\sqrt{3x^2+y^2}.$$

#### 先把两个曲面认出来

第一个两边平方是 $x^2+y^2+z^2=4$，正根号意味着 $z\ge 0$——半径为 2 的上半球面。这个已经讲过两次了，咱们不啰嗦。

第二个是这一节的生面孔。两边平方：

$$z^2=3x^2+y^2.$$

怎么认出它？老办法，两个方向各切一刀。令 $z$ 取常数，$3x^2+y^2$ 就固定了，横截面是一条闭合曲线；再令 $x=0$，得到 $y^2=z^2$，即 $z=\pm y$，是 $yOz$ 平面内的两条直线；令 $y=0$，得到 $z^2=3x^2$，即 $z=\pm\sqrt3\,x$，是 $xOz$ 平面内的两条直线。各个方向都是过原点的直线——这就是一个锥面。再看正根号，$z\ge 0$，留下的是上半支。

> **提示**：$z^2=3x^2+y^2$ 的两个系数不同，严格说是椭圆锥面，$z$ 取常数时横截面是椭圆；两个系数相等时才是圆锥面，横截面才是圆。

有人会问：这个锥面是不是到上面某个面就停住了？不是的，它会一直往上长开——就像冰淇淋外面那个筒，叫什么专业用语我还真不知道，我对这些吃的一窍不通。总之，这个锥面是无限延伸的，别把它想成一个有盖子的东西。

半球面和锥面相交，交出来的是什么形状？一个圆。再次记住：两个曲面相交，得到曲线。

#### 求交线，再看它的投影

交线上，两个方程的 $z$ 必然相等：

$$\sqrt{4-x^2-y^2}=\sqrt{3x^2+y^2}.$$

两边同时去根号、移项：

$$4-x^2-y^2=3x^2+y^2\;\Longrightarrow\;4(x^2+y^2)=4\;\Longrightarrow\;x^2+y^2=1.$$

代回任一个方程，$z=\sqrt{4-1}=\sqrt3$。所以空间中那条交线是

$$\begin{cases}
x^2+y^2=1,\\
z=\sqrt3.
\end{cases}$$

圆心在 $z$ 轴上，半径为 1——请注意，这是悬在半空里的圆。

这个圆为什么长这样，值得再讲一遍故事。$x^2+y^2=1$ 是一根竖着的烟囱，也就是圆柱面；$z=\sqrt3$ 是一个水平的平面；烟囱被平着切一刀，切口就是一个圆。你看，方程写出来谁都看得懂，可脑子里如果没有这根烟囱，方程写得再漂亮，照样还是不明白。两个方程明明就是同一个故事，写成"圆柱面加切平面"和写成"半径 1 的圆加高度 $\sqrt3$"，是同一件事，可只有前一种说法能让你看见那个图。

现在回到题目要求的投影。所谓投影，就是把这条空中的曲线按坐标面的规矩落下去。$xOy$ 面上 $z=0$，所以投影是

$$\begin{cases}
x^2+y^2=1,\\
z=0.
\end{cases}$$

```text
   空间中的交线                    在 xOy 面上的投影
   x² + y² = 1,  z = √3            x² + y² = 1,  z = 0
   圆悬在半空                        圆落在 xOy 面上
```

> **易错点**：空间中的交线在 $z=\sqrt3$，书上写的 $z=0$ 是投影。两个都没错，讲的是两件事：一个是圆本身悬在哪里，一个是它在 $xOy$ 面上的影子落在哪里。千万别把这两个高度混为一谈。

这幅立体图后面会一直用：先一后二还是先二后一、积分区域怎么定，都得靠它。把"空中的圆"和"面上的影子"这两层分清，三重积分和曲面积分里这一类题才算真正有了抓手。

空间曲线这一节的内容说到底就这么几条：定义是两个曲面相交；例子是圆柱、球面、锥面这些东西碰面；参数方程是一个参数带着三个坐标转；投影是分清空中的曲线和它在坐标面上的影子。真正做题时，曲线往往比想象中简单得多，不用自己吓自己。
