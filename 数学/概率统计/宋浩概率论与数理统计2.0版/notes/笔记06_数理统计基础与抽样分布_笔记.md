# 数理统计基础与抽样分布

## 总体、样本与统计量概念体系

* **总体与个体（Population and Individual）**

    * > **定义**：数理统计中所研究对象的全体称为总体，总体中包含的每一个考察对象称为个体。在实际统计研究中，总体通常由其数量指标 $X$ 及其概率分布完全刻画，总体与随机变量 $X$ 等同看待。

    * 容量分类：按所含个体总数，总体分为有限总体与无限总体。当有限总体的容量极大时，工程与理论上均视作无限总体处理。

* **简单随机样本（Simple Random Sample，SRS）**

    * > **定义**：从总体 $X$ 中随机抽取 $n$ 个个体 $X_1, X_2, \dots, X_n$，若满足代表性与独立性，则称 $(X_1, X_2, \dots, X_n)$ 为容量为 $n$ 的简单随机样本，简称样本。

    * 核心判定条件（i.i.d. 特征）：
      * 同分布性（代表性）：每个随机变量 $X_i$ 与总体 $X$ 具有完全相同的概率分布（$X_i \sim F(x)$）。
      * 相互独立性（独立性）：$X_1, X_2, \dots, X_n$ 彼此相互独立。

    * 随机变量与观察值边界：
      * 抽样完成前：$X_1, X_2, \dots, X_n$ 是 $n$ 个相互独立的随机变量，具有随机波动性。
      * 抽样完成后：观测获得的一组具体确定数值 $(x_1, x_2, \dots, x_n)$ 称为样本观察值（样本实现值）。

    * 联合概率分布表述：
      * 连续型总体：样本联合概率密度等于各边缘密度之乘积，$f^*(x_1, \dots, x_n) = \prod_{i=1}^n f(x_i)$。
      * 离散型总体：样本联合分布律等于单点概率之乘积，$P(X_1=x_1, \dots, X_n=x_n) = \prod_{i=1}^n P(X=x_i)$。

* **统计量（Statistic）**

    * > **定义**：设 $X_1, X_2, \dots, X_n$ 为来自总体 $X$ 的样本，$g(X_1, X_2, \dots, X_n)$ 为样本的实值连续函数。若函数 $g$ 中**不包含任何未知的总体参数**，则称 $g(X_1, X_2, \dots, X_n)$ 为统计量。

    * 判定法则与准则：
      * 统计量只能依赖于样本随机变量 $X_1, \dots, X_n$ 以及已知的数学常数或抽样容量 $n$。
      * 表达式中只要含有一个未知参数（如未知的总体均值 $\mu$ 或总体方差 $\sigma^2$），则绝非统计量。
      * 若参数为题目明确已知的确定常数（如 $\mu_0, \sigma_0^2$ 已知），则将其代入后的表达式是合法的统计量。

    * > **易错点**：⚠️ 统计量本身依然是随机变量，在样本未观测前取值随机；只有代入具体样本观察值后才得到一个确定的统计量取值。样本容量 $n$ 是已知常数，不属于未知参数。

## 常用统计量及其分布特征

* **样本均值（Sample Mean，$\bar{X}$）**

    * > **定义**：样本观测数据的算术平均数，刻画数据的集中趋势：
      $$\bar{X} = \frac{1}{n} \sum_{i=1}^n X_i$$

    * 数学期望：若总体期望 $E(X) = \mu$，则恒有 $E(\bar{X}) = \mu$（无偏性）。

    * 方差特征：若总体方差 $D(X) = \sigma^2$，则恒有 $D(\bar{X}) = \frac{\sigma^2}{n}$，离散度随样本容量增大按 $\sqrt{n}$ 速率衰减。

* **样本方差（Sample Variance，$S^2$）与样本标准差（$S$）**

    * > **定义**：消除自由度损失后经修正的离差平方和平均值，刻画样本数据的离散波动程度：
      $$S^2 = \frac{1}{n-1} \sum_{i=1}^n (X_i - \bar{X})^2$$
      样本标准差 $S = \sqrt{S^2}$。

    * 分母取值规则：分母必须除以自由度 $n-1$（而非 $n$），才能保证样本方差是总体方差 $\sigma^2$ 的无偏估计，即 $E(S^2) = \sigma^2$。

    * 样本未修正方差对比：定义 $S_n^2 = \frac{1}{n}\sum_{i=1}^n (X_i - \bar{X})^2 = \frac{n-1}{n} S^2$。其期望为 $E(S_n^2) = \frac{n-1}{n}\sigma^2 \ne \sigma^2$（有偏估计）。

    * 展开恒等式与快速计算：
      $$\sum_{i=1}^n (X_i - \bar{X})^2 = \sum_{i=1}^n X_i^2 - n\bar{X}^2$$
      $$S^2 = \frac{1}{n-1}\left(\sum_{i=1}^n X_i^2 - n\bar{X}^2\right)$$

* **样本矩（Sample Moments）**

    * > **定义**：样本关于原点或均值的各阶算术平均多项式。

    * 样本 $k$ 阶原点矩：$A_k = \frac{1}{n}\sum_{i=1}^n X_i^k$（特别地，$A_1 = \bar{X}$）。
    * 样本 $k$ 阶中心矩：$B_k = \frac{1}{n}\sum_{i=1}^n (X_i - \bar{X})^k$（特别地，$B_2 = S_n^2$）。
    * 矩的一致性：由辛钦大数定律，当总体各阶矩存在时，样本各阶原点矩依概率收敛于总体对应的理论原点矩：$A_k \xrightarrow{P} \alpha_k = E(X^k)$。

* **顺序统计量（Order Statistics）与样本极值**

    * > **定义**：将样本观察值按数值从小到大重新排序所得的有序序列 $X_{(1)} \le X_{(2)} \le \dots \le X_{(n)}$。
    * 最小观测值（极小值）：$X_{(1)} = \min(X_1, X_2, \dots, X_n)$。
    * 最大观测值（极大值）：$X_{(n)} = \max(X_1, X_2, \dots, X_n)$。
    * 样本极差（Sample Range）：$R = X_{(n)} - X_{(1)}$，反映极端波动跨度。

## 抽样分布与分位数理论

* **抽样分布（Sampling Distribution）**

    * > **定义**：样本统计量作为随机变量，其所遵循的概率分布称为该统计量的抽样分布。抽样分布是连接样本数据与未知总体参数的理论推断桥梁。

* **分位数（Quantile / Fractile）**

    * > **定义**：设连续型随机变量 $X$ 的概率密度为 $f(x)$，对给定的置信水平 $\alpha$（$0 < \alpha < 1$），满足其右侧曲线下面积等于 $\alpha$ 的点称为上侧 $\alpha$ 分位数，记作 $z_\alpha$：
      $$P(X > z_\alpha) = \int_{z_\alpha}^{+\infty} f(x)\,\mathrm{d}x = \alpha$$

    * 标准正态分布分位数对称性法则：
      * 对称关系：$z_{1-\alpha} = -z_\alpha$。
      * 分布函数对应：$\Phi(z_\alpha) = 1 - \alpha$，即 $P(X \le z_\alpha) = 1 - \alpha$。
      * 双侧分位数关系：$P(|X| \le z_{\alpha/2}) = 1 - \alpha$ 且 $P(|X| > z_{\alpha/2}) = \alpha$。

## 三大抽样分布体系

* **卡方分布（$\chi^2$ Distribution）**

    * > **定义**：设 $X_1, X_2, \dots, X_n$ 相互独立且均服从标准正态分布 $N(0, 1)$，则其平方和服从自由度为 $n$ 的卡方分布，记作 $\chi^2 \sim \chi^2(n)$：
      $$\chi^2 = \sum_{i=1}^n X_i^2 = X_1^2 + X_2^2 + \dots + X_n^2 \sim \chi^2(n)$$

    * 核心性质与数字特征：
      * 取值范围：$\chi^2 \ge 0$。
      * 数学期望：$E(\chi^2) = n$（自由度即均值）。
      * 方差数值：$D(\chi^2) = 2n$。
      * 可加性（再生性）：若 $\chi_1^2 \sim \chi^2(n_1)$ 且 $\chi_2^2 \sim \chi^2(n_2)$ 相互独立，则：
        $$\chi_1^2 + \chi_2^2 \sim \chi^2(n_1 + n_2)$$
      * 渐近正态性：当 $n \to \infty$ 时，$\frac{\chi^2 - n}{\sqrt{2n}} \xrightarrow{d} N(0, 1)$。

* **t 分布（Student's t-Distribution）**

    * > **定义**：设随机变量 $X \sim N(0, 1)$，$Y \sim \chi^2(n)$，且 $X$ 与 $Y$ 相互独立，则称统计量 $T$ 服从自由度为 $n$ 的 $t$ 分布，记作 $T \sim t(n)$：
      $$T = \frac{X}{\sqrt{Y / n}} \sim t(n)$$

    * 结构与图形特征：
      * 对称性：概率密度曲线关于 $t = 0$ 严格偶对称，峰值位于原点。
      * 尾部厚重性：形态与标准正态分布相似，但方差更大、尾部更厚，小样本下离散程度高于正态分布。
      * 分位数对称性：$t_{1-\alpha}(n) = -t_\alpha(n)$。
      * 数字特征：当 $n > 1$ 时 $E(T) = 0$；当 $n > 2$ 时 $D(T) = \frac{n}{n-2} > 1$。
      * 极限逼近：当自由度 $n \to \infty$ 时，$t(n)$ 弱收敛于标准正态分布 $N(0, 1)$。

* **F 分布（Fisher-Snedecor Distribution）**

    * > **定义**：设随机变量 $U \sim \chi^2(n_1)$，$V \sim \chi^2(n_2)$，且 $U$ 与 $V$ 相互独立，则两个独立卡方变量除以各自自由度后的比值服从第一自由度为 $n_1$、第二自由度为 $n_2$ 的 $F$ 分布，记作 $F \sim F(n_1, n_2)$：
      $$F = \frac{U / n_1}{V / n_2} \sim F(n_1, n_2)$$

    * 倒数互逆性质：
      * 变量倒数分布：若 $F \sim F(n_1, n_2)$，则其倒数 $\frac{1}{F} \sim F(n_2, n_1)$。
      * 分位数互逆公式：计算小分位数时使用关键恒等式：
        $$F_{1-\alpha}(n_1, n_2) = \frac{1}{F_\alpha(n_2, n_1)}$$

    * 与 t 分布的平方联系：若随机变量 $T \sim t(n)$，则 $T^2 \sim F(1, n)$。

## 正态总体下的经典抽样定理

* **单正态总体的四大抽样定理**

    * > **定义**：设总体 $X \sim N(\mu, \sigma^2)$，$X_1, X_2, \dots, X_n$ 是来自该总体的容量为 $n$ 的简单随机样本，$\bar{X}$ 为样本均值，$S^2$ 为样本方差。

    * 定理一（均值正态性）：
      $$\bar{X} \sim N\left(\mu, \frac{\sigma^2}{n}\right) \quad \Longleftrightarrow \quad \frac{\bar{X} - \mu}{\sigma / \sqrt{n}} \sim N(0, 1)$$

    * 定理二（方差卡方性）：
      $$\frac{(n-1)S^2}{\sigma^2} = \frac{\sum_{i=1}^n (X_i - \bar{X})^2}{\sigma^2} \sim \chi^2(n-1)$$

    * 定理三（均方独立性）：
      样本均值 $\bar{X}$ 与样本方差 $S^2$ 相互独立。

    * 定理四（消去未知方差的 t 构造）：
      由定理一与定理二，利用定理三的独立性消除未知参数 $\sigma$，构造得到：
      $$\frac{\frac{\bar{X} - \mu}{\sigma / \sqrt{n}}}{\sqrt{\frac{(n-1)S^2}{\sigma^2(n-1)}}} = \frac{\bar{X} - \mu}{S / \sqrt{n}} \sim t(n-1)$$

    * > **易错点**：⚠️ $\sum_{i=1}^n \frac{(X_i - \mu)^2}{\sigma^2} \sim \chi^2(n)$，而 $\sum_{i=1}^n \frac{(X_i - \bar{X})^2}{\sigma^2} = \frac{(n-1)S^2}{\sigma^2} \sim \chi^2(n-1)$。因为用样本均值 $\bar{X}$ 代替了未知真值 $\mu$，造成了 1 个自由度的损失。

* **双正态总体的三大抽样定理**

    * > **定义**：设总体 $X \sim N(\mu_1, \sigma_1^2)$，$Y \sim N(\mu_2, \sigma_2^2)$ 相互独立。样本 $(X_1, \dots, X_{n_1})$ 与 $(Y_1, \dots, Y_{n_2})$ 分别来自两总体，样本均值与方差记为 $\bar{X}, S_1^2$ 和 $\bar{Y}, S_2^2$。

    * 定理五（两均值差正态分布，$\sigma_1^2, \sigma_2^2$ 已知）：
      $$\frac{(\bar{X} - \bar{Y}) - (\mu_1 - \mu_2)}{\sqrt{\frac{\sigma_1^2}{n_1} + \frac{\sigma_2^2}{n_2}}} \sim N(0, 1)$$

    * 定理六（两样本方差比 F 分布）：
      $$\frac{S_1^2 / \sigma_1^2}{S_2^2 / \sigma_2^2} \sim F(n_1 - 1, n_2 - 1)$$
      特别地，当两总体方差相等（$\sigma_1^2 = \sigma_2^2$）时，直接有：
      $$\frac{S_1^2}{S_2^2} \sim F(n_1 - 1, n_2 - 1)$$

    * 定理七（两均值差 t 分布，$\sigma_1^2 = \sigma_2^2 = \sigma^2$ 未知）：
      引入两样本联合加权无偏方差（混合样本方差，Pooled Variance）：
      $$S_w^2 = \frac{(n_1 - 1)S_1^2 + (n_2 - 1)S_2^2}{n_1 + n_2 - 2}$$
      则消除未知参数 $\sigma^2$ 后有：
      $$\frac{(\bar{X} - \bar{Y}) - (\mu_1 - \mu_2)}{S_w \sqrt{\frac{1}{n_1} + \frac{1}{n_2}}} \sim t(n_1 + n_2 - 2)$$
