# 多维随机变量及其联合分布

## 联合分布与边缘分布

* **二维联合累积分布函数（Joint Cumulative Distribution Function，F(x, y)）**

    * > **定义**：对二维随机变量 $(X, Y)$ 及任意实数对 $(x, y)$，定义二元函数：
      $$F(x, y) = P(X \le x, Y \le y), \quad -\infty < x, y < +\infty$$
      为 $(X, Y)$ 的联合分布函数。

    * 单调不减性：固定一个自变量，$F(x, y)$ 关于另一个自变量单调不减。

    * 极限性质：
      $$F(-\infty, y) = F(x, -\infty) = F(-\infty, -\infty) = 0, \quad F(+\infty, +\infty) = 1$$

    * 右连续性：关于 $x$ 和关于 $y$ 均分别满足右连续。

    * 矩形区域概率公式（四点公式）：
      $$P(x_1 < X \le x_2, y_1 < Y \le y_2) = F(x_2, y_2) - F(x_1, y_2) - F(x_2, y_1) + F(x_1, y_1) \ge 0$$

    * 边缘分布函数导出：
      $$F_X(x) = F(x, +\infty) = \lim_{y \to +\infty} F(x, y), \quad F_Y(y) = F(+\infty, y) = \lim_{x \to +\infty} F(x, y)$$

* **二维离散型分布与边缘分布律（Bivariate Discrete Distribution）**

    * > **定义**：若 $(X, Y)$ 所有可能取值对有限或可列，其联合分布律记作 $P(X = x_i, Y = y_j) = p_{ij}$（$i, j = 1, 2, \dots$）。

    * 归一性：$p_{ij} \ge 0$ 且 $\sum_i \sum_j p_{ij} = 1$。

    * 边缘分布律计算法则：对同行或同列元素求和（边缘加和消去另一维度变量）：
      $$P(X = x_i) = p_{i\cdot} = \sum_{j} p_{ij}, \quad P(Y = y_j) = p_{\cdot j} = \sum_{i} p_{ij}$$

* **二维连续型分布与边缘概率密度（Bivariate Continuous Density）**

    * > **定义**：若存在非负二元可积函数 $f(x, y)$，使得联合分布函数可表示为双重积分：
      $$F(x, y) = \int_{-\infty}^x \int_{-\infty}^y f(u, v)\,\mathrm{d}v\,\mathrm{d}u$$
      则称 $(X, Y)$ 为二维连续型随机变量，$f(x, y)$ 称为联合概率密度。

    * 规范性（全平面双重积分为 1）：
      $$\int_{-\infty}^{+\infty} \int_{-\infty}^{+\infty} f(x, y)\,\mathrm{d}x\,\mathrm{d}y = 1$$

    * 平面区域概率求法：对平面上任一可积区域 $D$：
      $$P((X, Y) \in D) = \iint_D f(x, y)\,\mathrm{d}x\,\mathrm{d}y$$

    * 边缘概率密度计算法则（积分消元法）：
      * $X$ 的边缘密度：固定 $x$，对 $y$ 积去全域：
        $$f_X(x) = \int_{-\infty}^{+\infty} f(x, y)\,\mathrm{d}y$$
      * $Y$ 的边缘密度：固定 $y$，对 $x$ 积去全域：
        $$f_Y(y) = \int_{-\infty}^{+\infty} f(x, y)\,\mathrm{d}x$$

    * 几何直观（切片截面面积）：$f_X(x_0)$ 物理意义为用垂直于 $x$ 轴的平面 $x = x_0$ 截割联合密度曲面 $z = f(x, y)$ 所得纵截面的面积。

    * > **易错点**：⚠️ 求边缘密度在确定被积变量的积分上下限时，积分限绝不能含有被积变量自身，且求 $f_X(x)$ 积出的结果只能含有 $x$（$y$ 必须被完全消去）。

## 条件分布与统计独立性

* **条件概率分布（Conditional Distributions）**

    * > **定义**：在给定的一个随机变量取特定值的条件下，另一个随机变量的概率分布称为条件分布。

    * 离散型条件分布律：在事件 $\{Y = y_j\}$ 发生的条件下，$X$ 的条件分布律为：
      $$P(X = x_i \mid Y = y_j) = \frac{p_{ij}}{p_{\cdot j}} = \frac{P(X=x_i, Y=y_j)}{P(Y=y_j)} \quad (p_{\cdot j} > 0)$$

    * 连续型条件概率密度：在 $f_Y(y) > 0$ 的点处，$Y = y$ 条件下 $X$ 的条件密度函数定义为：
      $$f_{X|Y}(x \mid y) = \frac{f(x, y)}{f_Y(y)}$$
      同理，在 $f_X(x) > 0$ 处，$f_{Y|X}(y \mid x) = \frac{f(x, y)}{f_X(x)}$。

    * 连续型乘法公式：
      $$f(x, y) = f_X(x) f_{Y|X}(y \mid x) = f_Y(y) f_{X|Y}(x \mid y)$$

* **随机变量的相互独立性（Independence of Random Variables）**

    * > **定义**：若对任意实数 $x, y$，联合分布函数均可分解为边缘分布函数的乘积：
      $$F(x, y) = F_X(x) F_Y(y)$$
      则称随机变量 $X$ 与 $Y$ 相互独立。

    * 离散型独立充要条件：对所有的 $(x_i, y_j)$，联合分布律等于边缘分布律乘积：
      $$p_{ij} = p_{i\cdot} p_{\cdot j}$$

    * 连续型独立充要条件：在整个平面上（除面积为 0 的个别边界点外），联合密度函数可分解为两边缘密度之积：
      $$f(x, y) = f_X(x) f_Y(y)$$

    * 区域矩形化判定定理：若联合概率密度 $f(x, y)$ 的非零定义域 $D = \{(x, y) \mid f(x, y) > 0\}$ 不能表示为笛卡尔积矩形区域 $[a, b] \times [c, d]$（比如定义域带有 $x < y$ 或 $x^2+y^2 \le 1$ 相互制约的边界），则 $X$ 与 $Y$ 必然不独立。

    * 分离变量法（快速判定法）：若定义域为矩形，且联合密度能分解为一个关于 $x$ 的因子与一个关于 $y$ 的因子的乘积 $f(x, y) = g(x) h(y)$，则 $X$ 与 $Y$ 必相互独立。

## 两个随机变量函数的分布

* **和的分布与卷积公式（Sum Distribution and Convolution Formula）**

    * > **定义**：设 $(X, Y)$ 的联合概率密度为 $f(x, y)$，由它们构成的和变量 $Z = X + Y$ 的分布称为和分布。

    * 连续型卷积公式：
      $$f_Z(z) = \int_{-\infty}^{+\infty} f(x, z - x)\,\mathrm{d}x = \int_{-\infty}^{+\infty} f(z - y, y)\,\mathrm{d}y$$

    * 独立和卷积公式：若 $X$ 与 $Y$ 相互独立，则代入 $f(x, y) = f_X(x) f_Y(y)$ 得：
      $$f_Z(z) = \int_{-\infty}^{+\infty} f_X(x) f_Y(z - x)\,\mathrm{d}x = \int_{-\infty}^{+\infty} f_X(z - y) f_Y(y)\,\mathrm{d}y$$

    * 常见独立分布的可加性定理：
      * 二项分布可加性：若 $X \sim B(n_1, p), Y \sim B(n_2, p)$ 且独立，则 $X + Y \sim B(n_1 + n_2, p)$。
      * 泊松分布可加性：若 $X \sim P(\lambda_1), Y \sim P(\lambda_2)$ 且独立，则 $X + Y \sim P(\lambda_1 + \lambda_2)$。
      * 正态分布再生性：若 $X \sim N(\mu_1, \sigma_1^2), Y \sim N(\mu_2, \sigma_2^2)$ 且独立，则线性组合：
        $$aX + bY \sim N(a\mu_1 + b\mu_2, a^2\sigma_1^2 + b^2\sigma_2^2)$$

* **商与积的分布（Quotient and Product Distributions）**

    * 商的分布（$Z = \frac{Y}{X}$）：
      $$f_Z(z) = \int_{-\infty}^{+\infty} |x| f(x, xz)\,\mathrm{d}x$$

    * 积的分布（$Z = XY$）：
      $$f_Z(z) = \int_{-\infty}^{+\infty} \frac{1}{|x|} f\left(x, \frac{z}{x}\right)\,\mathrm{d}x$$

* **极值与最值分布（Distributions of Maximum and Minimum）**

    * > **定义**：设随机变量 $X, Y$ 相互独立，其分布函数分别为 $F_X(x), F_Y(y)$。构造新变量：$M = \max\{X, Y\}$，$N = \min\{X, Y\}$。

    * 最大值分布函数公式（全小于等于）：
      $$F_M(z) = P(\max\{X, Y\} \le z) = P(X \le z, Y \le z) = F_X(z) F_Y(z)$$
      推广到 $n$ 个独立同分布变量：$F_{\max}(z) = [F(z)]^n$。

    * 最小值分布函数公式（对偶补集转化）：
      $$F_N(z) = P(\min\{X, Y\} \le z) = 1 - P(X > z, Y > z) = 1 - [1 - F_X(z)][1 - F_Y(z)]$$
      推广到 $n$ 个独立同分布变量：$F_{\min}(z) = 1 - [1 - F(z)]^n$。

    * 密度函数导出：直接对分布函数 $F_M(z)$ 或 $F_N(z)$ 求导即得各自的概率密度。
