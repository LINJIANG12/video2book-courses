# 参数估计理论与方法

## 参数估计基本概念与点估计框架

* **参数估计（Parameter Estimation）**

    * > **定义**：在总体概率分布形式已知但包含一个或多个未知参数的设定下，根据从总体中抽取的样本信息，对这些未知参数进行定量推断与估计的统计推断方法。

    * 分类范畴：
      * 点估计（Point Estimation）：用样本构造确切统计量给出未知参数的一个具体数值估计。
      * 区间估计（Interval Estimation）：给出包含未知参数真值的置信范围并提供置信水平度量。

* **点估计量与点估计值（Point Estimator and Estimate）**

    * > **定义**：设待估总体参数为 $\theta$。样本统计量 $\hat{\theta}(X_1, X_2, \dots, X_n)$ 称为未知参数 $\theta$ 的点估计量；代入具体样本观察值后算得的确定实数 $\hat{\theta}(x_1, x_2, \dots, x_n)$ 称为点估计值。

    * 记号规范：估计量与估计值均使用带尖帽的符号 $\hat{\theta}$ 标记。

## 点估计构建方法

* **矩估计法（Method of Moments，MOM）**

    * > **定义**：基于大数定律中经验矩收敛于理论矩的思想，用样本原点矩直接替换总体原点矩，通过联立方程组反解未知参数的估计方法。

    * 核心理论桥梁：
      * 总体 $k$ 阶原点矩：$\alpha_k = E(X^k) = g_k(\theta_1, \dots, \theta_m)$。
      * 样本 $k$ 阶原点矩：$A_k = \frac{1}{n}\sum_{i=1}^n X_i^k$（特别地，$A_1 = \bar{X}$，$A_2 = \frac{1}{n}\sum X_i^2$）。
      * 理论等价替代依据：辛钦大数定律保证 $A_k \xrightarrow{P} \alpha_k$。

    * 矩估计方程组构建步骤：
      * 单参数情形：令总体期望等于样本均值 $E(X) = \bar{X}$，解出 $\hat{\theta} = h(\bar{X})$。
      * 双参数情形：联立一阶矩与二阶矩方程组：
        $$\begin{cases} E(X) = \bar{X} \\ E(X^2) = \frac{1}{n}\sum_{i=1}^n X_i^2 \end{cases} \quad \text{或等价使用} \quad \begin{cases} E(X) = \bar{X} \\ D(X) = B_2 = \frac{1}{n}\sum_{i=1}^n (X_i - \bar{X})^2 \end{cases}$$
      * 反解方程组即得参数的矩估计量。

    * 优缺点与适用边界：
      * 优点：构造直观简单，计算量小，不需要总体具有复杂的完全解析形式，只要低阶矩存在即可求解。
      * 缺点：往往没有充分利用样本的全体分布信息，估计精度和有效性可能不如极大似然估计。

* **极大似然估计法（Maximum Likelihood Estimation，MLE）**

    * > **定义**：基于概率最大原理（高概率事件在一次试验中最易发生），选取使已抽出的样本联合概率（或联合密度）达到最大值的参数作为估计值的估计方法。

    * 似然函数（Likelihood Function，$L(\theta)$）构建：
      * 离散型总体：$L(\theta) = \prod_{i=1}^n P(X = x_i; \theta)$。
      * 连续型总体：$L(\theta) = \prod_{i=1}^n f(x_i; \theta)$。

    * 对数似然函数（Log-Likelihood Function，$\ln L(\theta)$）：
      * 利用对数函数的严格单调递增性，乘积转化为连加：
        $$\ln L(\theta) = \sum_{i=1}^n \ln f(x_i; \theta)$$

    * 导数驻点求解流程（正规平滑条件）：
      * 对参数求一阶导并令其为 0，建立对数似然方程：
        $$\frac{\mathrm{d}\ln L(\theta)}{\mathrm{d}\theta} = 0 \quad \text{或} \quad \frac{\partial \ln L(\theta_1, \dots, \theta_m)}{\partial \theta_j} = 0 \ (j=1, \dots, m)$$
      * 解对数似然方程组获得驻点，并检验二阶导小于 0 确认极大值。

    * 边界极值求解（不可导情况）：
      * 均匀分布 $U(a, b)$ 或 $U(0, \theta)$：因概率密度含有示性函数分段区间，似然函数处处递减。
      * 极值点落在参数支撑边界上，例如 $U(0, \theta)$ 的极大似然估计量为样本最大值：
        $$\hat{\theta}_{MLE} = \max(X_1, X_2, \dots, X_n) = X_{(n)}$$

    * 极大似然估计的不变性原则（Invariance Principle）：
      * 若 $\hat{\theta}$ 是参数 $\theta$ 的极大似然估计量，函数 $u(\theta)$ 具有单值反函数，则 $u(\theta)$ 的极大似然估计量必为 $u(\hat{\theta})$。

    * > **易错点**：⚠️ 均匀分布等区间端点含参数的模型，严禁盲目求导令导数为 0；必须根据支撑集指示函数画出似然函数随 $\theta$ 的单调增减趋势，在边界处锁定极值点。

## 估计量的三大评价标准

* **无偏性（Unbiasedness）**

    * > **定义**：若估计量 $\hat{\theta}$ 的数学期望恒等于待估真值 $\theta$，即：
      $$E(\hat{\theta}) = \theta$$
      则称 $\hat{\theta}$ 为参数 $\theta$ 的无偏估计量。若 $E(\hat{\theta}) \ne \theta$，则称有偏，差值 $\text{Bias}(\hat{\theta}) = E(\hat{\theta}) - \theta$ 称为系统偏差。

    * 典型估计量无偏性校验：
      * 样本均值：$E(\bar{X}) = \mu$ 恒成立，$\bar{X}$ 是总体均值 $\mu$ 的无偏估计。
      * 修正样本方差：$E(S^2) = \sigma^2$ 恒成立，$S^2$ 是总体方差 $\sigma^2$ 的无偏估计。
      * 样本二阶中心矩（未修正方差）：$E(S_n^2) = \frac{n-1}{n}\sigma^2 \ne \sigma^2$，是有偏估计；但当 $n \to \infty$ 时其期望收敛于 $\sigma^2$（渐近无偏）。
      * 均匀分布端点估计：$U(0, \theta)$ 的极大似然估计 $X_{(n)}$ 满足 $E(X_{(n)}) = \frac{n}{n+1}\theta$（有偏），修正估计量 $\frac{n+1}{n} X_{(n)}$ 为无偏估计量。

* **有效性（Efficiency / Minimum Variance）**

    * > **定义**：在同一参数 $\theta$ 的无偏估计量类中，方差更小的估计量被认为更为有效。若 $\hat{\theta}_1$ 与 $\hat{\theta}_2$ 均为 $\theta$ 的无偏估计量，且：
      $$D(\hat{\theta}_1) < D(\hat{\theta}_2)$$
      则称 $\hat{\theta}_1$ 比 $\hat{\theta}_2$ 更有效。

    * 比较原则：有效性比较的前提必须是**两个估计量都满足无偏性**；若估计量有偏，则不能单纯对比方差，而需引入均方误差（Mean Squared Error，$\text{MSE}(\hat{\theta}) = D(\hat{\theta}) + \text{Bias}^2(\hat{\theta})$）。

* **一致性 / 相合性（Consistency）**

    * > **定义**：随着样本容量 $n$ 趋于无穷大，估计量序列依概率收敛于参数真值，即对任意 $\varepsilon > 0$ 恒有：
      $$\lim_{n \to \infty} P(|\hat{\theta}_n - \theta| < \varepsilon) = 1 \quad \Longleftrightarrow \quad \hat{\theta}_n \xrightarrow{P} \theta$$
      则称 $\hat{\theta}_n$ 为参数 $\theta$ 的一致估计量（相合估计量）。

    * 充要充分判据：若 $\lim_{n \to \infty} E(\hat{\theta}_n) = \theta$ 且 $\lim_{n \to \infty} D(\hat{\theta}_n) = 0$，则由切比雪夫不等式可直接推得 $\hat{\theta}_n$ 必是一致估计量。

## 区间估计理论与置信区间

* **区间估计基本概念（Interval Estimation）**

    * > **定义**：在给定的置信度 $1 - \alpha$（$0 < \alpha < 1$）下，利用样本统计量构造出由两个随机变量界定的区间 $[\underline{\theta}(X_1, \dots, X_n), \bar{\theta}(X_1, \dots, X_n)]$，使得真值落入该区间的概率满足：
      $$P(\underline{\theta} \le \theta \le \bar{\theta}) \ge 1 - \alpha$$
      该区间称为参数 $\theta$ 的置信水平为 $1 - \alpha$ 的置信区间，$\underline{\theta}$ 称为置信下限，$\bar{\theta}$ 称为置信上限。

    * 统计本质解读：置信区间端点 $\underline{\theta}$ 与 $\bar{\theta}$ 依赖于样本，是随机区间；未知参数 $\theta$ 是固定常数。置信度 $1 - \alpha$ 表示在大量重复抽样中，包含真值的随机区间所占的理论比例。

* **枢轴量法（Pivot Quantity Method）**

    * > **定义**：寻找一个样本与待估参数的联合函数 $G(X_1, \dots, X_n; \theta)$，满足：
      * 包含待估参数 $\theta$ 与样本统计量；
      * 不包含任何其他未知的多余干扰参数；
      * 其自身的抽样概率分布完全确定已知，且完全不依赖于未知参数 $\theta$。

    * 构造与求解三步法：
      * 第一步：选定抽样定理推导的合适枢轴量 $G$ 及其已知分布（如 $N(0, 1)$、$\chi^2$、$t$、$F$ 分布）；
      * 第二步：根据置信水平 $1 - \alpha$，确定分布的分位数临界值 $c_1, c_2$，使得 $P(c_1 \le G \le c_2) = 1 - \alpha$；
      * 第三步：通过代数不等式变形，将 $c_1 \le G \le c_2$ 转化为待估参数处于中间的形式 $\underline{\theta} \le \theta \le \bar{\theta}$。

## 正态总体参数的区间估计方案

* **单个正态总体均值 $\mu$ 的置信区间**

    * 方差 $\sigma^2$ 已知情形（Z 检验枢轴量）：
      * 枢轴量：$Z = \frac{\bar{X} - \mu}{\sigma / \sqrt{n}} \sim N(0, 1)$。
      * 置信度为 $1 - \alpha$ 的双侧置信区间：
        $$\left[ \bar{X} - z_{\alpha/2} \frac{\sigma}{\sqrt{n}}, \quad \bar{X} + z_{\alpha/2} \frac{\sigma}{\sqrt{n}} \right]$$

    * 方差 $\sigma^2$ 未知情形（t 检验枢轴量）：
      * 枢轴量：用样本标准差 $S$ 替代未知 $\sigma$，$T = \frac{\bar{X} - \mu}{S / \sqrt{n}} \sim t(n-1)$。
      * 置信度为 $1 - \alpha$ 的双侧置信区间：
        $$\left[ \bar{X} - t_{\alpha/2}(n-1) \frac{S}{\sqrt{n}}, \quad \bar{X} + t_{\alpha/2}(n-1) \frac{S}{\sqrt{n}} \right]$$

* **单个正态总体方差 $\sigma^2$ 的置信区间**

    * 均值 $\mu$ 未知情形（$\chi^2$ 检验枢轴量）：
      * 枢轴量：$\chi^2 = \frac{(n-1)S^2}{\sigma^2} \sim \chi^2(n-1)$。
      * 概率等式：$P\left(\chi^2_{1-\alpha/2}(n-1) \le \frac{(n-1)S^2}{\sigma^2} \le \chi^2_{\alpha/2}(n-1)\right) = 1 - \alpha$。
      * 置信度为 $1 - \alpha$ 的双侧置信区间：
        $$\left[ \frac{(n-1)S^2}{\chi^2_{\alpha/2}(n-1)}, \quad \frac{(n-1)S^2}{\chi^2_{1-\alpha/2}(n-1)} \right]$$

* **双正态总体均值差与方差比的置信区间**

    * 均值差 $\mu_1 - \mu_2$（方差未知但假定相等 $\sigma_1^2 = \sigma_2^2$）：
      * 引入混合样本方差：$S_w^2 = \frac{(n_1-1)S_1^2 + (n_2-1)S_2^2}{n_1+n_2-2}$。
      * 枢轴量：$T = \frac{(\bar{X} - \bar{Y}) - (\mu_1 - \mu_2)}{S_w \sqrt{\frac{1}{n_1} + \frac{1}{n_2}}} \sim t(n_1 + n_2 - 2)$。
      * 双侧置信区间：
        $$\left[ (\bar{X} - \bar{Y}) - t_{\alpha/2}(n_1+n_2-2) S_w \sqrt{\frac{1}{n_1} + \frac{1}{n_2}}, \quad (\bar{X} - \bar{Y}) + t_{\alpha/2}(n_1+n_2-2) S_w \sqrt{\frac{1}{n_1} + \frac{1}{n_2}} \right]$$

    * 方差比 $\frac{\sigma_1^2}{\sigma_2^2}$（均值 $\mu_1, \mu_2$ 未知）：
      * 枢轴量：$F = \frac{S_1^2 / \sigma_1^2}{S_2^2 / \sigma_2^2} \sim F(n_1-1, n_2-1)$。
      * 置信度为 $1 - \alpha$ 的双侧置信区间：
        $$\left[ \frac{S_1^2}{S_2^2} \frac{1}{F_{\alpha/2}(n_1-1, n_2-1)}, \quad \frac{S_1^2}{S_2^2} F_{\alpha/2}(n_2-1, n_1-1) \right]$$
