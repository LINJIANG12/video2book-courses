# 假设检验原理与正态总体推断

## 假设检验基本思想与决策理论

* **统计假设与假设检验（Statistical Hypothesis and Testing）**

    * > **定义**：对总体分布的形式或总体未知参数提出的某种统计断言称为统计假设。利用抽取的样本信息，依据既定统计准则判断该假设是否应当被接受或拒绝的推断过程称为假设检验。

    * 原假设（零假设，Null Hypothesis，$H_0$）：
      * 传统上被保留或怀疑的对象，通常代表现状、无差异、无显著改进或既定理论标准。
      * 表达式中恒包含等号（$=$、$\le$、$\ge$）。

    * 备择假设（对立假设，Alternative Hypothesis，$H_1$）：
      * 与原假设互为对立面，通常代表研究者试图通过试验数据来支持证明的新突破、新发现或显著差异。

    * 假设检验方向分类：
      * 双边检验（Two-sided Test）：$H_0: \theta = \theta_0 \longleftrightarrow H_1: \theta \ne \theta_0$。
      * 单边右侧检验（Right-sided Test）：$H_0: \theta \le \theta_0 \longleftrightarrow H_1: \theta > \theta_0$。
      * 单边左侧检验（Left-sided Test）：$H_0: \theta \ge \theta_0 \longleftrightarrow H_1: \theta < \theta_0$。

* **假设检验推断逻辑与核心原理**

    * 概率性反证法思想：
      * 首先假定原假设 $H_0$ 为真；
      * 在此假定下推导检验统计量 $T$ 的确定抽样分布；
      * 考察实际样本算得的检验统计量观测值是否落入小概率拒绝域。

    * 小概率事件实际不发生原理：
      * 在单次随机抽样或单次试验中，具有极小概率 $\alpha$ 的事件在工程与统计上被认为几乎不可能发生。
      * 若小概率事件在一次试验中实际发生了，则构成统计矛盾，从而有充分理由推翻前提，即拒绝原假设 $H_0$。

    * 拒绝域与临界值：
      * 拒绝域（Rejection Region，$W$）：在 $H_0$ 成立假定下发生概率仅为 $\alpha$ 的取值集合。
      * 接受域（Acceptance Region，$\bar{W}$）：样本统计量大概率落入的集合，满足 $P(T \in \bar{W} | H_0 \text{ 为真}) = 1 - \alpha$。
      * 临界值（Critical Value）：划分拒绝域与接受域边界的理论分位点数值。

* **两类错误与检验功效**

    * > **定义**：基于有限随机样本作出的统计决策具有不确定性，必然面临两类判定风险：

    * 第一类错误（弃真错误，Type I Error）：
      * 状态本质：原假设 $H_0$ 为真，但样本观测值落入拒绝域，导致错误地拒绝了真实的 $H_0$。
      * 发生概率：$P(\text{拒绝 } H_0 \mid H_0 \text{ 为真}) = \alpha$。
      * 显著性水平（Significance Level）：由研究者事先指定的常数 $\alpha$（如 $0.05, 0.01$），严格限制了犯弃真错误的概率上限。

    * 第二类错误（取伪错误，Type II Error）：
      * 状态本质：原假设 $H_0$ 实际上为假，但样本观测值落入接受域，导致未能推翻虚假的 $H_0$。
      * 发生概率：$P(\text{接受 } H_0 \mid H_0 \text{ 为假}) = \beta$。

    * 检验功效（Power of the Test）：
      * 定义：在备择假设为真时正确拒绝错误原假设的概率，量化为 $1 - \beta$。

    * 两类错误的权衡准则：
      * 在样本容量 $n$ 固定的前提下，$\alpha$ 与 $\beta$ 呈现此消彼长的对立制约关系（压低 $\alpha$ 必然抬高 $\beta$）。
      * 同时压低两类错误风险的唯一途径是增大样本容量 $n$。
      * 奈曼-皮尔逊（Neyman-Pearson）原则：在严格控制第一类错误发生率不超过 $\alpha$ 的约束下，尽可能最小化第二类错误概率 $\beta$（使功效 $1 - \beta$ 最大化）。

* **假设检验规范五步决策流程**

    * 步骤一：根据实际工程或科研意图设立原假设 $H_0$ 与备择假设 $H_1$。
    * 步骤二：给定显著性水平 $\alpha$（通常取 $0.05$ 或 $0.01$）。
    * 步骤三：在假定 $H_0$ 成立的前提下，选取或构造检验统计量及其理论抽样分布。
    * 步骤四：依据分布的分位数与备择假设的方向，求出临界值并确定拒绝域形式。
    * 步骤五：代入实际样本数据计算检验统计量观测值，对照拒绝域作出拒绝或接受 $H_0$ 的决策结论。

## 单个正态总体参数的假设检验

* **总体均值 $\mu$ 的假设检验**

    * 方差 $\sigma^2$ 已知情形（Z 检验 / U 检验）：
      * 检验统计量：
        $$Z = \frac{\bar{X} - \mu_0}{\sigma / \sqrt{n}} \sim N(0, 1)$$
      * 双边检验（$H_1: \mu \ne \mu_0$）拒绝域：$|Z| \ge z_{\alpha/2}$。
      * 单边右侧检验（$H_1: \mu > \mu_0$）拒绝域：$Z \ge z_\alpha$。
      * 单边左侧检验（$H_1: \mu < \mu_0$）拒绝域：$Z \le -z_\alpha$。

    * 方差 $\sigma^2$ 未知情形（t 检验）：
      * 检验统计量（样本标准差 $S$ 替代未知 $\sigma$）：
        $$t = \frac{\bar{X} - \mu_0}{S / \sqrt{n}} \sim t(n-1)$$
      * 双边检验（$H_1: \mu \ne \mu_0$）拒绝域：$|t| \ge t_{\alpha/2}(n-1)$。
      * 单边右侧检验（$H_1: \mu > \mu_0$）拒绝域：$t \ge t_\alpha(n-1)$。
      * 单边左侧检验（$H_1: \mu < \mu_0$）拒绝域：$t \le -t_\alpha(n-1)$。

* **总体方差 $\sigma^2$ 的假设检验（$\chi^2$ 检验）**

    * 均值 $\mu$ 未知情形：
      * 检验统计量：
        $$\chi^2 = \frac{(n-1)S^2}{\sigma_0^2} \sim \chi^2(n-1)$$
      * 双边检验（$H_0: \sigma^2 = \sigma_0^2 \longleftrightarrow H_1: \sigma^2 \ne \sigma_0^2$）拒绝域：
        $$\chi^2 \le \chi^2_{1-\alpha/2}(n-1) \quad \text{或} \quad \chi^2 \ge \chi^2_{\alpha/2}(n-1)$$
      * 单边右侧检验（$H_1: \sigma^2 > \sigma_0^2$）拒绝域：
        $$\chi^2 \ge \chi^2_\alpha(n-1)$$
      * 单边左侧检验（$H_1: \sigma^2 < \sigma_0^2$）拒绝域：
        $$\chi^2 \le \chi^2_{1-\alpha}(n-1)$$

    * > **易错点**：⚠️ 卡方分布是不对称的偏态分布，双边检验的临界值不能像正态分布或 t 分布那样直接添负号，必须分别通过查表计算右侧临界值 $\chi^2_{\alpha/2}(n-1)$ 与左侧临界值 $\chi^2_{1-\alpha/2}(n-1)$。

## 两个正态总体参数的差异性假设检验

* **两总体均值差 $\mu_1 - \mu_2$ 的检验**

    * 两方差 $\sigma_1^2, \sigma_2^2$ 已知情形（双样本 Z 检验）：
      * 检验假设：$H_0: \mu_1 - \mu_2 = \delta$（通常测试均值无差异，$\delta = 0$）。
      * 检验统计量：
        $$Z = \frac{(\bar{X} - \bar{Y}) - \delta}{\sqrt{\frac{\sigma_1^2}{n_1} + \frac{\sigma_2^2}{n_2}}} \sim N(0, 1)$$
      * 双边拒绝域：$|Z| \ge z_{\alpha/2}$。

    * 两方差未知但假定相等 $\sigma_1^2 = \sigma_2^2 = \sigma^2$（双样本 t 检验）：
      * 引入混合样本方差：
        $$S_w^2 = \frac{(n_1-1)S_1^2 + (n_2-1)S_2^2}{n_1+n_2-2}$$
      * 检验统计量：
        $$t = \frac{(\bar{X} - \bar{Y}) - \delta}{S_w \sqrt{\frac{1}{n_1} + \frac{1}{n_2}}} \sim t(n_1 + n_2 - 2)$$
      * 双边检验（$H_1: \mu_1 - \mu_2 \ne \delta$）拒绝域：
        $$|t| \ge t_{\alpha/2}(n_1 + n_2 - 2)$$
      * 单边右侧检验（$H_1: \mu_1 - \mu_2 > \delta$）拒绝域：
        $$t \ge t_\alpha(n_1 + n_2 - 2)$$

* **两总体方差齐性检验（F 检验）**

    * 检验假设：
      * 原假设与备择假设：$H_0: \sigma_1^2 = \sigma_2^2 \longleftrightarrow H_1: \sigma_1^2 \ne \sigma_2^2$（方差齐性判定）。

    * 检验统计量：
      * 两个独立样本方差的比值：
        $$F = \frac{S_1^2}{S_2^2} \sim F(n_1 - 1, n_2 - 1)$$

    * 拒绝域判定准则：
      * 双边检验拒绝域：
        $$F \ge F_{\alpha/2}(n_1-1, n_2-1) \quad \text{或} \quad F \le F_{1-\alpha/2}(n_1-1, n_2-1)$$
      * 利用 F 分布的倒数互逆性质计算左临界值：
        $$F_{1-\alpha/2}(n_1-1, n_2-1) = \frac{1}{F_{\alpha/2}(n_2-1, n_1-1)}$$
      * 单边右侧检验（$H_1: \sigma_1^2 > \sigma_2^2$）拒绝域：
        $$F \ge F_\alpha(n_1-1, n_2-1)$$

    * 工程应用意义：在执行双样本 t 检验前，通常必须首先进行 F 检验以严格验证“两总体方差相等”这一先决前提条件。
