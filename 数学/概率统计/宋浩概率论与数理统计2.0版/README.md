# 宋浩《概率论与数理统计》2.0 版

宋浩老师的《概率论与数理统计》2.0 版。课程从随机事件与概率的基本模型出发，依次讲一维与多维随机变量及其分布、数字特征与极限定理，再转入数理统计的抽样分布、参数估计与假设检验，公式推导与典型例题并行推进，是配套《高等数学》2.0 版的后半程课程。

- **原视频**：https://www.bilibili.com/video/BV1JXppejE8q — Bilibili，BV1JXppejE8q
- **63 集**，已产出 6 册模块全书、8 篇复习笔记、48 份逐字稿

## 怎么学

- **概率基础** → 模块 01 打通样本空间、事件关系与概率计算模型，后面所有分布都建在它上面
- **随机变量** → 模块 02~03 讲一维与多维随机变量的分布律、密度与联合分布，重点是密度函数的求法
- **数字特征与极限定理** → 模块 04 覆盖期望方差、协方差与相关系数，以及大数定律与中心极限定理
- **统计推断** → 模块 05~06 从抽样分布讲到参数估计与假设检验，是做题与应用的落点
- **公式速查** → `notes/` 下的 8 篇笔记按主题归类，考前按分布类型逐条回顾
