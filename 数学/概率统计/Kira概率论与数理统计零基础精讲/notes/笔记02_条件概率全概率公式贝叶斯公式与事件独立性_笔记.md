# 条件概率、全概率公式、贝叶斯公式与事件独立性

## 条件概率

* **条件概率（Conditional Probability）**

    * > **定义**：设 $A$、$B$ 为两个事件，当 $P(B)>0$ 时，称 $P(A \mid B)=\dfrac{P(AB)}{P(B)}$ 为"在 $B$ 发生的条件下，$A$ 发生的概率"。

    * 记忆口诀"分子合体，比上条件"：分子是 $A$、$B$ 合在一起（$AB$）发生的概率，分母是条件 $B$ 单独发生的概率。

    * 本质上它仍是**竖线左边事件 $A$ 的概率**，$B$ 只是一条信息、一个背景，化简时反复用到这一点。

    * 直观理解用**缩减样本空间**：已知 $B$ 发生，就把样本空间缩小到 $B$ 这个范围里看问题，$P(A \mid B)$ 就是 $A \cap B$ 那部分样本点占 $B$ 的比重；条件概率问题经常可以画图观察。

    * > **易错点** ⚠️：$P(A)$ 与 $P(A \mid B)$ 谁大**没有必然联系**，取决于 $B$ 提供的是什么信息。以掷骰子"掷出 2"为例：

    | 给出的信息 | $P(\text{掷出} \ 2 \mid \text{信息})$ | 说明 |
    | :--- | :--- | :--- |
    | 掷出的是偶数 | $1/3$ | 信息让概率变大 |
    | 掷出的是奇数 | $0$ | 2 不是奇数，直接无了 |
    | 掷出的是整数 | $1/6$ | 废信息，概率不变 |

* **包含关系下的不等式**（题设：$A \subset B$，$P(B)>0$）

    * 画图法：单独看 $A$ 的概率是 $A$ 占 $\Omega$ 的比重；$B$ 条件下是 $A$ 占 $B$ 的比重。$A$ 整个落在 $B$ 里，后者显然更大，故 $P(A) \le P(A \mid B)$。

    * 推导法：$A \subset B$ 时 $P(AB)=P(A)$，于是 $P(A \mid B)=\dfrac{P(A)}{P(B)} \ge P(A)$——除以一个小于等于 1 的正数，不等号往外拐。

    * 等号可以取到：$P(B)=1$（$B$ 与 $\Omega$ 重合）时给不给 $B$ 这个条件都一样，所以结论是"$\le$、等号可取"，不是严格小于。

* **条件概率的性质**

    * 条件概率也是概率（缩减样本空间后在新空间里算的概率），非负性、规范性、可列可加性、加法减法公式与普通概率**完全一脉相承**，把条件 $C$ 当"挂件"挂到每个公式上即可，不用重新背。

    * 最常用的是对立事件，口诀"看半边"：$P(\bar{A} \mid C)=1-P(A \mid C)$——把 $\bar A$ 写成 $1-P(A)$，再把条件 $C$ 挂上。

    * > **易错点** ⚠️：只能对竖线**左边**的事件化简，右边是不能动的。$P(A \mid \bar{C})$ 这个式子本身没有化简余地，只能按定义拆开：$P(A \mid \bar{C})=\dfrac{P(A\bar{C})}{P(\bar{C})}=\dfrac{P(A)-P(AC)}{1-P(C)}$，分子用减法公式展开、分母用对立事件。

## 乘法公式

* **乘法公式（Multiplication Formula）**

    * > **定义**：由条件概率公式把 $P(B)$ 乘过去而来：$P(AB)=P(B)\,P(A \mid B)$，即"$A$、$B$ 一起发生的概率 = $B$ 发生的概率 × $B$ 发生条件下 $A$ 又发生的概率"。

    * 要当成成熟公式做题**直接用**，不要每题现推条件概率定义再解。

    * 推广形式：若 $P(A_1A_2\cdots A_{n-1})>0$，则 $P(A_1A_2\cdots A_n)=P(A_1)\,P(A_2 \mid A_1)\,P(A_3 \mid A_1A_2)\cdots P(A_n \mid A_1A_2\cdots A_{n-1})$——$n$ 个事件一起发生，拆成一步一步递进研究。

* **抽象概率小题套路**

    * 从要求的、最复杂的那个概率入手，通过化简拿到信息。

    * 见到 $P(A)$ 与条件概率并存、求 $P(AB)$，直接上乘法公式：已知 $P(A)=a$、$P(B \mid A)=b$，则 $P(A\bar{B})=P(A)-P(AB)=a-ab$，一步到位。

    * 条件概率的分子先看包含关系再展开：$AB \subset A \cup B$，交完就是被包含的事件，故 $P(AB \mid A \cup B)=\dfrac{P(AB)}{P(A \cup B)}=\dfrac{P(AB)}{P(A)+P(B)-P(AB)}$。

    * 求 $P(A \cup B)$ 缺 $P(AB)$ 而题给了条件概率（如 $P(A \mid B)=0.5$、$P(B)=0.3$）时，乘法公式直接得 $P(AB)=0.15$，省去"拆定义再解方程"的绕路。

* **拨电话问题**（忘记末位数字，在 0~9 中随机拨号）

    * 设 $A_i$="第 $i$ 次拨通"（第 $i$ 次的事件常这样设），$B$="不超过三次打通"。"不超过三次"是或的关系，直接打开加法公式繁琐时**想反面，转成交**：$P(B)=1-P(\bar{A}_1 \bar{A}_2 \bar{A}_3)$。

    * 三次拨号**不独立**——上次拨错会排除一个错误选项，下次建立在上次信息之上，必须用乘法公式递进：$P(B)=1-\dfrac{9}{10}\times\dfrac{8}{9}\times\dfrac{7}{8}=\dfrac{3}{10}$。

    * 已知末位是奇数时样本空间缩成 5 个奇数：$P(C)=1-\dfrac{4}{5}\times\dfrac{3}{4}\times\dfrac{2}{3}=\dfrac{3}{5}$——多一条信息，概率判断真的会变。

## 事件独立性

* **相互独立（Independence）**

    * > **定义**：$A$、$B$ 满足 $P(AB)=P(A)P(B)$ 就称 $A$ 与 $B$ 相互独立。这是定义式，不需要任何前提。

    * 在 $P(B)>0$ 前提下（为保证条件概率有定义），定义式等价于 $P(A \mid B)=P(A)$——"已知 $B$ 已发生"这条信息对判断 $A$ 没有任何用处，给了个寂寞。

    * 影响是相互的：$P(A)P(B)>0$ 时，$P(B \mid A)=P(B)$ 与 $P(AB)=P(A)P(B)$ 等价——$B$ 的信息对 $A$ 没用，$A$ 的信息对 $B$ 也没用。

    * 做题三条路随便走：乘积式 $P(AB)=P(A)P(B)$；"条件概率等于无条件概率"；直观的"概率互不影响"（往往对应独立试验的背景）。

* **独立性的三条性质**

    * **带上对立仍独立**：$A$、$B$ 独立，则 $A$ 与 $\bar{B}$、$\bar{A}$ 与 $B$、$\bar{A}$ 与 $\bar{B}$ 四组全独立。证明思路：$P(A\bar{B})=P(A)-P(AB)=P(A)\bigl(1-P(B)\bigr)=P(A)P(\bar{B})$，凑出"乘积概率等于概率乘积"的形状即独立，以后当常识直接用。

    * **零一事件与谁都独立**：任何事件都与概率为 0 或 1 的事件相互独立。概率为零的情形用不等关系夹逼：$AB \subseteq A \Rightarrow 0 \le P(AB) \le P(A)=0$，两头一夹 $P(AB)$ 只能为零；概率为一的情形（直接夹夹不住）借助对立转化：$P(C)=1$ 则 $P(\bar{C})=0$，$\bar{C}$ 与 $B$ 独立，再由"带上对立仍独立"得 $C$ 与 $B$ 独立。

    * > **注意**：概率为零推不出事件不可能发生，"$P(A)=0$ 所以 $A$ 是空集、$AB$ 是空集"的思路不严格——只能用概率去推概率，举特例可以帮理解但不是数学证明。

* **独立与互斥的辨析**

    * 直观：独立是**概率上**定义的关系，互斥是两个事件**没有交集**，两者没有必然关系；但在 $P(A),P(B)\in(0,1)$ 前提下：**独立一定不互斥，互斥一定不独立**（一对逆否命题，指证其一即可）。

    * 证明核心：互斥则 $P(AB)=P(\varnothing)=0$，而限定正概率时两个正数的乘积必大于零，故 $P(AB) \ne P(A)P(B)$，不独立。

    * > **易错点** ⚠️：结论的前提是两个概率都严格在 0 到 1 之间。失去前提就没有必然联系——极端例：不可能事件与必然事件既互斥又独立。题目只说"互斥"而没说概率范围时，凡与独立有关的选项直接排除。

    * 互斥条件下唯一一定成立的是 $P(A\bar{B})=P(A)-P(AB)=P(A)$；而"$\bar{A}$ 与 $\bar{B}$ 互斥"和"$\bar{A}$ 与 $\bar{B}$ 相容"都只是可能：$\bar{A}\cap\bar{B}$ 是"$A$、$B$ 都不发生"的区域，一般相容，但 $A$、$B$ 恰为对立事件时它又变空、互斥。两个矛盾的选项也可能都不一定对，正确选项的意思是"一定对"。

* **两两独立与相互独立**

    * **两两独立**：三个事件两个两个看都独立，即 $P(AB)=P(A)P(B)$、$P(BC)=P(B)P(C)$、$P(AC)=P(A)P(C)$ 三条同时成立——彼此概率互不影响并不容易，不要觉得两两独立很弱。

    * **相互独立**更强：在两两独立基础上追加 $P(ABC)=P(A)P(B)P(C)$。说相互独立，等于四个等式全给你随便用；说两两独立，只有前三个随便用。两两独立不一定相互独立——事件一多，概率影响的情况更复杂。

    * 阵营结论：相互独立的随机事件，任何部分经过**和、差、积、逆**运算后，结果都与另一部分独立——**只要字母不重复出现，两个阵营必独立**（如 $(A\cup\bar{B})$ 与 $C$、$(A-B)$ 与 $C$），后面统计部分还有大用。

    * 字母重复出现（如 $A$ 与 $A\cup C$）一般不独立，但只能说"不一定"——万一 $A$ 是必然事件，零一事件与谁都独立。

* **独立性混入计算题**

    * 文字题先翻译："两个独立事件 $A$、$B$ 都不发生的概率为 $\frac{1}{9}$"即 $P(\bar{A}\bar{B})=\frac{1}{9}$；"$A$ 发生 $B$ 不发生与 $B$ 发生 $A$ 不发生的概率相等"即 $P(A\bar{B})=P(\bar{A}B)$。

    * 独立条件下最喜欢乘积：后者用减法公式展开 $P(A)-P(AB)=P(B)-P(AB)$，消去 $P(AB)$ 得 $P(A)=P(B)=p$；再用 $\bar{A}$、$\bar{B}$ 仍独立拆乘积 $(1-p)^2=\frac{1}{9}$，解得 $p=\frac{2}{3}$。

    * 三人独立猜谜（各人猜出概率 $\frac{1}{5}$、$\frac{1}{3}$、$\frac{1}{4}$）："被猜出"指三人中有一人猜出，独立试验下事件全独立，直接一减概率相乘：$P(A_1\cup A_2\cup A_3)=1-\dfrac{4}{5}\times\dfrac{2}{3}\times\dfrac{3}{4}=\dfrac{3}{5}$。

    * 与拨电话问题的区别：拨电话不独立（前一次结果给后一次新信息），必须逐级乘条件概率；三人猜谜独立，直接概率相乘。

## 全概率公式

* **完备事件组（划分，Partition）**

    * > **定义**：同一次试验下的一组事件 $B_1,B_2,\cdots,B_n$ **两两互斥**，并且**并集恰为全集 $\Omega$**，称为完备事件组，也叫样本空间的一个划分——不重不漏地瓜分了样本空间。

    * 每次试验必有且仅有一个样本点出现，而这个样本点必然落在某个 $B_i$ 中，所以**做一次试验，$B_1$ 到 $B_n$ 中必有且仅有一个发生**。

    * 最简单的完备事件组是 $A$ 与 $\bar{A}$：两两互斥，并起来刚好是全集。

* **全概率公式（Total Probability Formula）**

    * > **定义**：$B_1,\cdots,B_n$ 为完备事件组时，对 $\Omega$ 中任一事件 $A$ 有 $P(A)=\sum\limits_{i=1}^{n}P(B_i)\,P(A \mid B_i)$，这个思想也叫**全集分解**。

    * 推导骨架：$P(A)=P(A\Omega)=P\bigl(A(B_1\cup\cdots\cup B_3)\bigr)=P(AB_1\cup AB_2\cup AB_3)$，其中 $AB_i$ 两两互斥且并起来刚好是 $A$（借助划分把 $A$ 也不重不漏地瓜分了），用有限可加性拆成概率之和，每项再上乘法公式。

    * 读法："要么 $A$ 带着 $B_1$ 一起发生，加要么带着 $B_2$，加要么带着 $B_3$"——分析出层次、找到完备事件组后，看着瓜分图自己就能顺下来，不用背。

* **题型特征与设字母**

    * 四个特征：样本空间恰被一组 $B_i$ 瓜分完备（往往已知每个 $P(B_i)$）；题目分**两个层次**（阶段）、暗含分类讨论的味道；$A$ 只要发生必然带着某个 $B_i$ 一起发生，且已知 $P(A \mid B_i)$；要求的正是**第二层**的 $P(A)$。

    * > **提示**：设字母就两句话——**谁瓜分就设谁为 $B_1,B_2,\cdots,B_n$；求谁就设谁为 $A$**。全概率的题原题不给你字母，这是通用起手式。

    * 例（次品问题）：甲乙丙市场占有率 $\frac{1}{4},\frac{1}{4},\frac{1}{2}$，次品率 $2\%,1\%,3\%$，则 $P(A)=\dfrac{1}{4}\times0.02+\dfrac{1}{4}\times0.01+\dfrac{1}{2}\times0.03=0.0225$；占有率就是 $P(B_i)$，次品率就是 $P(A \mid B_i)$，条件给得齐全。

    * 例（迟到问题）：火车、轮船、汽车、飞机以 $0.2,0.1,0.3,0.4$ 瓜分，迟到条件概率 $\frac{1}{3},\frac{1}{12},\frac{1}{4},0$，则 $P(A)=0.2\times\frac{1}{3}+0.1\times\frac{1}{12}+0.3\times\frac{1}{4}+0.4\times0=0.15$——**飞机不可能迟到，$0.4\times0$ 这一项也要老老实实写上，漏了分母比例就出问题**。

    * 例（不放回取球）：50 球 20 黄 30 白，甲取后不放回，乙取到黄球是两个层次：$P(A)=\dfrac{20}{50}\times\dfrac{19}{49}+\dfrac{30}{50}\times\dfrac{20}{49}=\dfrac{2}{5}$；条件概率按剩余的 49 个球用古典概型算。

## 贝叶斯公式

* **贝叶斯公式（Bayes Formula）**

    * > **定义**：$P(B_i \mid A)=\dfrac{P(AB_i)}{P(A)}$——它就是一个普普通通的条件概率，**不用背**，千万不要想复杂。

    * 分母 $P(A)$ 用**全概率公式**的结果：贝叶斯与全概率往往一起出现，题目上一问算过全概率就直接抄，没算就自己先算；分子 $P(AB_i)$ 一定是全概率公式中的**某一项**，抄下来即可。

    * 概率意义是**知果推因**（后验）：已知结果 $A$ 发生了，反推它来自某个原因 $B_i$ 的概率——与一开始单独看 $B_i$ 的概率（先验）不同，这就是"结果"这个信息带来的影响。

* **典型计算**

    * 次品问题第二问：已知买到次品，它出自甲厂的概率 $P(B_1 \mid A)=\dfrac{0.25\times0.02}{0.0225}\approx0.22$——先验 0.25 降到后验 0.22，因为份额更大、次品率也更高的丙厂更可能是源头。

    * 迟到问题：已知迟到，乘汽车（$B_3$）来的概率 $P(B_3 \mid A)=\dfrac{0.3\times\frac{1}{4}}{0.15}=0.5$——先验 0.3 升到后验 0.5；而乘飞机的后验概率直接降为 0。

    * 误收问题：发 A 占 $\frac{3}{5}$、发 B 占 $\frac{2}{5}$（频繁程度之比 3:2 就是市场份额），A 被误收作 B 的概率 0.04、B 被误收作 A 的概率 0.07 是两个不同的数——"没有误收"时 $P(A \mid H)=1-0.04=0.96$。分母 $P(A)=\dfrac{3}{5}\times0.96+\dfrac{2}{5}\times0.07=0.604$，分子取第一项：$P(H \mid A)=\dfrac{\frac{3}{5}\times0.96}{0.604}\approx0.9536$。

    * 被题目字母绕进去时，一旦确定模型是全概率 + 贝叶斯，就**按自己的体系重新设字母**（如原发层用 $H$、接收层用 $A$），自己看懂自己的设法即可。

* **方法小结**

    * 四步流程：第一层"谁瓜分设谁"、第二层设结果事件；画两个图层看图说话；先算全概率把分母铺满（瓜分里的每一块都不能漏，哪怕条件概率为 0）；最后分子回全概率公式里"找那一项"。

    * 判断题型看问法："已知他迟到了""已知收到的是 A"——先给一个**结果**让你反推**原因**，就是贝叶斯；反推原因时分母必然要算全概率，实为"全概率 + 贝叶斯"的组合。

## 抽签原理

* **抽签原理（签序公平性）**

    * > **定义**：$n$ 个人排队依次抽签（等价于一个人依次抽 $n$ 个签），抽到某种签的概率**与抽签顺序无关**，只与不同签所占的比例有关；特指**无放回**的情形。

    * 来源：50 球 20 黄不放回，第一人取黄概率 $\frac{20}{50}=\frac{2}{5}$，第二人算出来也是 $\frac{2}{5}$，可推至第 50 人都相同——无放回仍能保证人人公平；有放回情形太平凡，自然一样。

    * 用到拨电话旧题：试验前凌空看，每次拨通概率都是 $\frac{1}{10}$（拨错的号不再拨，相当于无放回抽球），且 $A_1,A_2,A_3$ **两两互斥**（第一次打通就不存在第二、三次），用有限可加性直接拆开：$P(B)=\dfrac{1}{10}+\dfrac{1}{10}+\dfrac{1}{10}=\dfrac{3}{10}$，与乘法公式递进的结果一致；每次拨通概率为 $\frac{1}{5}$ 时同理合计 $\frac{3}{5}$。

    * > **注意**："每次拨通概率相等"是**试验进行之前**凌空说的；一旦第一个号拨下去、有了信息，后面的条件概率就开始变化。考试用抽签原理要**叙述一下原理**，不然像瞎蒙。

## 随机变量的引入

* **随机变量（Random Variable）**

    * > **定义**：设随机试验的样本空间为 $S$，$X=X(\omega)$ 是定义在 $S$ 上的**单值实值函数**；一句话——只要有随机性，万物皆可随机变量。

    * 随机性：事先可以预知所有可能的结果，但只有做完实验之后才知道具体取哪个值。

    * 本质是个函数：自变量是**样本点**（不可再分的基本事件），$X$ 每取一个值对应一个基本事件；一般不写函数形式，只用一个大写字母表示。

    * 与数字无关的结果可**数量化（赋值）**：掷硬币正面向上记 $X=1$、反面向上记 $X=0$；设废品数为 $X$ 后，"至多抽到两件废品"就是 $P(X \le 2)$、"未抽到废品"就是 $P(X=0)$——文字表达的事件统一成数学上的**取值和范围**。

    * 单值函数意味着**不同取值两两互斥**：$X=0$（没有次品）与 $X=1$（有一件次品）不可能同时发生；且做完一次试验，$X$ 只能取一个值。

    * 取值有随机性：试验前能明确 $X$ 的可能**范围**（如寿命统一设 $X>0$、可带小数取连续值），但预知不了具体取值。

    * 记号约定：**大写字母**有随机性，每个取值都带概率、不能确定取哪个值；**小写字母**是高数中的普通变量，表示随机变量的取值，说取几就取几。

    * 分类：**离散型**与**连续型**两大类，方法截然不同；此外还有非离散非连续的中间地带。

    * 意义：上一章的事件用文字叙述、彼此孤立，引入随机变量后转化为可统一研究的取值与范围问题，理论体系从**静态到动态、从孤立到系统**地延展开来。
