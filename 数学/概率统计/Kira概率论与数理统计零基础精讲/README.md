# Kira《概率论与数理统计》零基础精讲

Kira 老师的概率论与数理统计零基础精讲课，约 25 小时覆盖从随机事件到假设检验的完整考研数学基础阶段内容。课程前半是概率论（事件与概率、一维与二维随机变量、数字特征、大数定律），后半是数理统计（抽样分布、参数估计、置信区间、假设检验），讲法贴着零基础学员走，每个概念都先给直观再给公式。

## 怎么学

- **按册顺学，不要跳章** → 六册对应课程的六章主线，随机事件 → 随机变量 → 多维分布 → 数字特征 → 抽样分布 → 估计与检验，前面不熟后面必然吃力
- **一维与二维是全课地基** → 第二、三册占全课近一半时长，分布函数、密度函数与边缘条件分布要练到看到题就知道用哪套
- **公式集中记忆** → 第四册的期望方差表与第八、九篇笔记把数字特征公式收成一张速查网，适合反复背
- **数理统计靠框架记公式** → 第五、六册的三大抽样分布、矩估计与最大似然、置信区间、假设检验公式多但套路固定，配合笔记 11~13 速查
- **基础阶段节奏** → 每天 1~2 块（每块约 50 分钟），配合笔记复盘，一个月可过完一轮
- **考前速查** → `notes/` 里的 13 篇笔记按知识主题跨块聚合，笔记开头的知识拓扑树可直接导入 Markmap 或 XMind 生成脑图
