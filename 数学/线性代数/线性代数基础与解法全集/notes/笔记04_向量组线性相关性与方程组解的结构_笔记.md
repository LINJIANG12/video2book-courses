# 向量组线性相关性与方程组解的结构

## 向量与向量组

### 向量的两种写法

* **向量与行向量、列向量**

    * 向量是既有大小又有方向的量，进了矩阵的世界就有了新身份：只有一行的矩阵叫**行向量**，只有一列的矩阵叫**列向量**。

    * > **约定**：线性代数里提到「向量」默认指**列向量**，需要指行向量时会额外说明。

* **转置写法**

    * 列向量除了竖着写，还可以写成一个行向量再在右上角补一个转置符号。

    * 这样写纯粹是为了省版面：竖着写要占 $n$ 行，横着写一行就够。

    * 两种写法做题时都可以用，竖式看起来更直观，横式更省空间。

### 向量组

* **定义**

    * > **定义**：向量组是若干个**同维数**的列向量组成的集合。

    * 设 $\alpha_1,\alpha_2,\cdots,\alpha_m$ 都是 $n$ 维列向量，它们就构成一个向量组。

* **向量组与矩阵的互相转换**

    * 每个向量 $n$ 维就有 $n$ 行，一共 $m$ 个向量就有 $m$ 列，按列拼起来就是一个 $n\times m$ 的矩阵。

    * > **易错点**：维数不同的一堆向量凑不成向量组，同一个向量组里的向量维数必须全部相同。

### 秩的第四种理解：独立向量的个数

* **按行看：独立向量与多余向量**

    * 矩阵的每一行是一个行向量（写成 $\alpha_1^{\mathsf T}$ 这样的形式），前两行是有效方程，对应的行向量就叫**独立向量**。

    * 第三行是多余方程，对应的行向量就叫**多余向量**，两者是同一件事的两种说法。

* **按列看：主元列就是独立向量**

    * 把矩阵按列拆开得到四个列向量，这个向量组里独立向量的个数就等于矩阵的秩。

    * > **结论**：向量组的秩 $=$ 独立向量的个数；把向量组拼成矩阵化成行阶梯形后，主元所在列对应的向量就是独立向量，其余列是多余向量。

    * 例：化成阶梯形后秩为三，四个列向量里有一个向量等于另外三个之和，它就是那个多余向量。

    ```text
        按行看：  A 的每一行 ⟶ 一个行向量（写成 α₁ᵀ 这种形式）
                  有效方程 = 独立向量，多余方程 = 多余向量

        按列看：  向量组 α₁,…,αₘ 按列拼成 A
                  主元所在的列 = 独立向量（个数 = 秩）
                  其余列 = 多余向量，可由主元列表示
    ```

## 线性组合与线性表示

### 向量的加法、数乘与线性组合

* **向量的加法与数乘**

    * 两个同维向量对应相加就是向量的加法，一个数乘一个向量就是把向量里每个元素都乘上这个数。

* **线性组合**

    * > **定义**：给向量组 $\alpha_1,\dots,\alpha_m$ 配一组**任意**的常数 $k_1,\dots,k_m$，式子 $k_1\alpha_1+\cdots+k_m\alpha_m$ 就叫一个**线性组合**。

    * 组合的形式就是「每个向量数乘一个数，再把这 $m$ 个结果加到一起」。

### 线性表示的定义

* **定义**

    * > **定义**：若**存在**一组数使 $\beta$ 能写成 $\lambda_1\alpha_1+\cdots+\lambda_m\alpha_m$，就说 $\beta$ 可由这个向量组**线性表示**。

* **与线性组合的差别**

    * 线性组合里的系数是**任意**的，可以随便选；线性表示里的系数是**存在**的，起码是确定下来的。

    * 于是可以把组合里的 $k_1,\dots,k_m$ 当成未知数，把表示里的 $\lambda_1,\dots,\lambda_m$ 当成这个未知数的解。

### 线性表示翻译成方程组

* **翻译方式**

    * 把表示式改写成 $x_1\alpha_1+x_2\alpha_2+\cdots+x_m\alpha_m=\beta$，方程组有解时解就是那组表示系数。

* **为什么是方程组**

    * 把系数乘进各个向量再相加后，左右两边都是列向量，分量逐个相等就得到一个线性方程组。

* **充要条件**

    * > **结论**：$\beta$ 能由 $\alpha_1,\dots,\alpha_m$ 线性表示，等价于方程组 $x_1\alpha_1+\cdots+x_m\alpha_m=\beta$ 有解。

    * 换成秩的说法：$r(\alpha_1,\dots,\alpha_m)=r(\alpha_1,\dots,\alpha_m,\beta)$，加进来的 $\beta$ 没有增加独立向量的个数。

    ```text
        β 可由 α₁,…,αₘ 线性表示
                │  把表示系数看成未知数
                ▼
        x₁α₁ + x₂α₂ + … + xₘαₘ = β          ← 线性方程组
                │  系数矩阵 (α₁,…,αₘ)，增广矩阵 (α₁,…,αₘ,β)
                ▼
        r(α₁,…,αₘ) = r(α₁,…,αₘ,β)   ⟺   方程组有解
                │
                ▼
        解出来的解向量就是表示系数 (λ₁,…,λₘ)
    ```

### 被表示的可丢掉

* **从秩看**

    * $\beta$ 能被向量组表示，加进 $\beta$ 之后独立向量的个数没有增加，说明 $\beta$ 本身是一个多余向量。

* **从列变换看**

    * 把第一列乘 $-\lambda_1$ 加到 $\beta$ 那一列，再把 $-\lambda_2$ 倍加回去，一路消下去 $\beta$ 就变成零向量，同样说明它是多余向量。

* **口诀**

    * > **口诀**：被表示的可丢掉，丢掉之后 $r(\alpha_1,\dots,\alpha_m,\beta)=r(\alpha_1,\dots,\alpha_m)$。

    * 丢掉多余的向量不改变独立向量的个数，这就是口诀成立的理由。

### 从一个向量到一个向量组

* **两个向量都能被表示时**

    * $\beta_1$、$\beta_2$ 都能由 $\alpha_1,\dots,\alpha_m$ 表示时，把两条表示关系合并成一个式子。

    * 合并的结果是 $r(\alpha_1,\dots,\alpha_m,\beta_1,\beta_2)=r(\alpha_1,\dots,\alpha_m)$，相当于把两个多余向量一次性丢掉。

    * 理由是把两个多余向量都丢掉，独立向量的个数仍然没有变化。

* **向量组之间的表示**

    * 两个向量也可以看成一个向量组，这就自然过渡到向量组之间的表示问题。

    * > **定义**：组二 $\beta_1,\dots,\beta_l$ 中每一个向量都能由组一 $\alpha_1,\dots,\alpha_m$ 线性表示，就说组二可由组一线性表示。

* **两个方向的公式**

    * 组二可由组一表示时，被表示的可丢掉，写出来就是 $r(\mathrm{I},\mathrm{II})=r(\mathrm{I})$。

    * 组一可由组二表示时，反过来得到 $r(\mathrm{I},\mathrm{II})=r(\mathrm{II})$。

    * > **提示**：拼起来的秩相当于桥梁，把两边连了起来；公式里的 $\mathrm{I}$、$\mathrm{II}$ 分别代表两组向量。

### 向量组等价与三秩相等

* **定义**

    * > **定义**：两个向量组能**互相**线性表示，就说这两个向量组**等价**。

* **充要条件**

    * > **结论**：两向量组等价 $\iff$ 三秩相等 $r(\mathrm{I})=r(\mathrm{II})=r(\mathrm{I},\mathrm{II})$。

    * 拼起来的秩同时等于两个组的秩，把两条表示方向的式子合并就得到三秩相等。

* **单向表示加等秩也够用**

    * 组一可由组二表示时先得 $r(\mathrm{I},\mathrm{II})=r(\mathrm{II})$，题干又给 $r(\mathrm{I})=r(\mathrm{II})$，于是三秩相等。

    * > **结论**：一个向量组可由另一个向量组线性表示，并且两个向量组的秩相等，也能推出这两个向量组等价。

### 例题：证明可表示并求表示式

* **题型**

    * 给定向量组 $\alpha_1,\alpha_2,\alpha_3$ 与向量 $\beta$，证明 $\beta$ 能由这组向量线性表示，并求出表达式。

* **招式**

    * 先证 $r(\alpha_1,\alpha_2,\alpha_3)=r(\alpha_1,\alpha_2,\alpha_3,\beta)$，依据是「被表示的可丢掉」。

    * 再把 $\alpha_1,\alpha_2,\alpha_3,\beta$ 拼成增广矩阵，用初等行变换化到行最简形，把表示系数当成方程组的解来求。

    * 行最简形对应 $x_1+3x_3=2$ 与 $x_2-2x_3=-1$，主变量是 $x_1$、$x_2$，自由变量是 $x_3$。

* **结论**

    * 令 $x_3=k$（$k$ 为任意常数）得 $\beta=(2-3k)\alpha_1+(2k-1)\alpha_2+k\alpha_3$。

    * > **易错点**：末尾必须标注 $k$ 为任意常数，方程组有无穷多解意味着表示方式不唯一。

### 例题：证明两个向量组等价

* **题型**

    * 给定 $\alpha_1,\alpha_2$ 与 $\beta_1,\beta_2,\beta_3$，证明这两个向量组等价。

* **招式**

    * 要证等价就证三秩相等，技巧是先求五个向量拼成的大矩阵的秩，因为它包含的信息最多。

    * 大矩阵化成行阶梯形得 $r(\alpha_1,\alpha_2,\beta_1,\beta_2,\beta_3)=2$。

    * 看其中 $\alpha_1$、$\alpha_2$ 对应的两列，它们仍是行阶梯形，所以 $r(\alpha_1,\alpha_2)=2$。

    * 剩下 $r(\beta_1,\beta_2,\beta_3)$ 单独抽出来不一定是阶梯形，可以重新化简，也可以观察它的行不成比例直接判定。

* **结论**

    * 三个秩都等于 2，三秩相等成立，两个向量组等价。

### 线性表示公式小结

* **一张表记住六条**

    | 条件 | 结论 | 口诀 |
    | :--- | :--- | :--- |
    | 组一可由组二线性表示 | $r(\mathrm{I})\le r(\mathrm{II})$ | 被表示的秩不大 |
    | 组一可由组二线性表示 | $r(\mathrm{I},\mathrm{II})=r(\mathrm{II})$ | 被表示的可丢掉 |
    | 组一可由组二表示，组二不可由组一表示 | $r(\mathrm{I})<r(\mathrm{II})$ | 单向表示，秩严格小 |
    | 组一可由组二表示，且 $r(\mathrm{I})=r(\mathrm{II})$ | 两向量组等价 | 表示加等秩必等价 |
    | 组一与组二互相线性表示 | 两向量组等价 | 互相表示即等价 |
    | 组一可由组二表示，且组一向量个数大于组二向量个数 | 组一必线性相关 | 少表多多必相关 |

* **逐条说明**

    * 被表示的秩不大：一都能被二表示，说明二里独立向量的个数不少于一里的个数，秩自然不会更小。

    * 单向表示且反向不成立时，两种「相等」的可能都被排除，秩只能严格小于。

    * 最后一条先换个说法：一里一定有多余向量，等学到线性相关就明白它说的就是这个。

    * > **口诀**：被表示的秩不大、被表示的可丢掉、三秩相等即等价、少表多多必相关。

* **少表多多必相关的道理**

    ```text
         一中向量的个数（大）                二中向量的个数（小）
      ┌───────────────────────────┐      ┌───────────────────┐
      │  ░░░░░ 多余向量 ░░░░░      │      │  ▓▓▓ 独立向量 ▓▓▓  │
      │   ┌─────────────────┐     │      └───────────────────┘
      │   │ ▓▓ 独立向量 ▓▓ │     │             ↑
      │   └─────────────────┘     │        R2 = 二的秩
      └───────────────────────────┘
            ↑ R1 = 一的秩，且 R1 不超过 R2
    ```

    * 一的总数比二大，一的独立向量个数又不超过二，除去独立向量剩下的全是多余向量，所以一里一定有多余向量。

## 线性相关与线性无关

### 定义与两种视角

* **定义**

    * > **定义**：存在**不全为零**的数 $k_1,\dots,k_m$ 使 $k_1\alpha_1+\cdots+k_m\alpha_m=\mathbf 0$，就说这个向量组**线性相关**。

    * > **定义**：**当且仅当** $k_1=k_2=\cdots=k_m=0$ 才使线性组合等于零，就说这个向量组**线性无关**。

* **方程组视角**

    * 把 $k_1,\dots,k_m$ 看成 $x_1,\dots,x_m$，组合式就是一个 $m$ 元齐次线性方程组。

    * > **结论**：向量组线性相关 $\iff$ $x_1\alpha_1+\cdots+x_m\alpha_m=\mathbf 0$ 有非零解；线性无关 $\iff$ 该齐次方程组仅有零解。

* **线性表示视角**

    * 线性相关意味着组内**至少存在一个向量**可以用其余向量线性表示，这个向量就是多余向量。

    * 线性无关意味着组内**任何一个向量**都不能由其余向量线性表示，全部都是独立向量。

    * 两个视角如何接通：相关时取 $k_i\neq 0$，把 $k_i\alpha_i$ 单独留在左边、其余项移到右边，两边同除以 $k_i$ 就得到 $\alpha_i$ 由其余向量表示的式子。

* **秩视角**

    * > **结论**：$\alpha_1,\dots,\alpha_m$ 线性相关 $\iff r(\alpha_1,\dots,\alpha_m)<m$；线性无关 $\iff r(\alpha_1,\dots,\alpha_m)=m$。

    * 相关说明存在多余向量，独立向量的个数必然小于向量总数 $m$；无关说明全部都是独立向量，秩正好等于 $m$。

### 两种判定方法

* **判定路线**

    ```text
        判断向量组 α₁,…,αₘ 是否相关
            ├── 定义法：设 k₁α₁ + … + kₘαₘ = 0
            │      仅有零解 → 无关        有非零解 → 相关
            └── 秩法：拼成矩阵，化行阶梯形数非零行
                   秩 = m → 无关         秩 < m → 相关
    ```

* **定义法**

    * 设系数 $k_1,\dots,k_m$ 使线性组合等于零，目标变成证明系数全为零（无关）或找出不全为零的取值（相关）。

* **秩法**

    * 把向量组拼成矩阵化行阶梯形，秩与向量个数一比就有结论。

    * > **提示**：求一个向量组的秩时，初等行变换、初等列变换、行列混用都可以；但解方程组与求极大无关组只允许初等行变换。

### 用秩判定具体向量组

* **两个向量看比例**

    * 两个向量不对应成比例时，它们就是独立向量，向量组线性无关，秩等于 2。

* **三个向量化阶梯形**

    * 把三个向量拼成矩阵做初等行变换，化成阶梯形后秩等于 2。

    * 秩 2 小于向量个数 3，说明组里存在多余向量，这个向量组线性相关。

### 定义法证明抽象向量组无关

* **题型**

    * 已知 $\alpha_1,\alpha_2,\alpha_3$ 线性无关。

    * 又设 $\beta_1=\alpha_1+\alpha_2$、$\beta_2=\alpha_2+\alpha_3$、$\beta_3=\alpha_3+\alpha_1$，证明这三个 $\beta$ 线性无关。

* **招式**

    * 抽象题走定义法：设 $x_1\beta_1+x_2\beta_2+x_3\beta_3=\mathbf 0$，目标是证明 $x_1=x_2=x_3=0$。

    * 把三个 $\beta$ 换成 $\alpha$ 的形式并合并同类项，得到 $(x_1+x_3)\alpha_1+(x_1+x_2)\alpha_2+(x_2+x_3)\alpha_3=\mathbf 0$。

    * 用上「$\alpha$ 组线性无关」，得 $x_1+x_3=0$、$x_1+x_2=0$、$x_2+x_3=0$ 三个方程。

    * 系数行列式 $\begin{vmatrix}1&0&1\\1&1&0\\0&1&1\end{vmatrix}=2\neq 0$，系数矩阵满秩，齐次方程组仅有零解。

* **结论**

    * $x_1=x_2=x_3=0$ 正合线性无关的定义，所以 $\beta_1,\beta_2,\beta_3$ 线性无关。

    * > **提示**：同一套定义法反过来也管用，若最后解出无穷多解，就说明存在不全为零的系数，向量组线性相关。

### 四条推论

* **部分相关，整体必相关**

    * > **口诀**：本身相关，增加相关。

    * 理由：原本相关就说明组里有多余向量，再加几个向量进来，那个多余向量的地位没有被破坏。

* **整体无关，部分必无关**

    * > **口诀**：整体无关，部分无关。

    * 理由：整组全是独立向量，从中任取一部分，取出来的当然还是独立向量。

    * 也可以反证：假设取出的部分相关，由第一条推论整组也该相关，与已知无关矛盾。

* **无关组加一个向量变相关，则该向量可被表示且表示唯一**

    * 设 $\alpha_1,\dots,\alpha_m$ 无关而 $\alpha_1,\dots,\alpha_m,\beta$ 相关，则 $\beta$ 可由 $\alpha_1,\dots,\alpha_m$ 线性表示，并且表示方式唯一。

    * 表示的存在性：$\alpha$ 组无关给出 $r(\alpha_1,\dots,\alpha_m)=m$；拼上 $\beta$ 相关说明拼起来的秩小于 $m+1$，越拼越大又给出不小于 $m$；两边一夹得 $r=m$。

    * 表示的唯一性：把 $\alpha$ 组当系数矩阵、拼上 $\beta$ 当增广矩阵，两个秩都等于 $m$ 且等于未知数个数，方程组有唯一解。

    * > **提示**：证明过程可以不必死记，要记的是独立向量、多余向量、线性表示与线性相关性之间的那层对应。

* **向量个数超过维数，必相关**

    * > **口诀**：个数大于维数，必相关（矮胖必相关）。

    * 理由：$m$ 个 $n$ 维向量拼成的矩阵有 $n$ 行 $m$ 列，是矮胖型，秩不超过行数，所以 $r(A)\le n<m$。

    * 秩小于向量个数就说明存在多余向量，这个向量组一定线性相关。

### 推论实战：一道两问证明题

* **题型**

    * 设向量组 $\alpha_1,\alpha_2,\alpha_3$ 线性相关，向量组 $\alpha_2,\alpha_3,\alpha_4$ 线性无关。

    * 第一问证明 $\alpha_1$ 可由 $\alpha_2,\alpha_3$ 线性表示；第二问证明 $\alpha_4$ 不能由 $\alpha_1,\alpha_2,\alpha_3$ 线性表示。

* **第一问的招式**

    * 先由「整体无关，部分无关」从 $\alpha_2,\alpha_3,\alpha_4$ 无关得到 $\alpha_2,\alpha_3$ 无关。

    * 再用已知的 $\alpha_1,\alpha_2,\alpha_3$ 相关，套第三条推论：无关组加一个向量变相关，则这个向量可被表示且表示唯一。

* **第二问的招式**

    * 用反证法，假设 $\alpha_4$ 能由 $\alpha_1,\alpha_2,\alpha_3$ 线性表示。

    * 第一问已证 $\alpha_1$ 可由 $\alpha_2,\alpha_3$ 表示，所以 $\alpha_1$ 在 $\alpha_1,\alpha_2,\alpha_3$ 里是多余向量，把它丢掉。

    * 于是 $\alpha_4$ 能由 $\alpha_2,\alpha_3$ 线性表示，这恰好说明 $\alpha_2,\alpha_3,\alpha_4$ 线性相关，与已知矛盾。

* **结论**

    * 假设不成立，$\alpha_4$ 不能由 $\alpha_1,\alpha_2,\alpha_3$ 线性表示；第二问的结论往往要借第一问已完成的那件事。

## 极大线性无关组

### 定义与不唯一性

* **定义**

    * > **定义**：向量组的一个部分组若满足两条，本身线性无关，且原向量组的任意一个向量都能由它线性表示，这个部分组就叫原向量组的**极大线性无关组**。

    * 一句话概括：把组里所有独立向量挑出来构成的新向量组，就是极大线性无关组，剩下的全是多余向量。

    * 「任意向量都能由部分组表示」这条是自动满足的：它自己表示自己没有障碍，其余的多余向量本来也能被表示。

    * 考研里常说的**最大无关组**与极大线性无关组是同一个东西。

* **不唯一但个数固定**

    * 取 $(1,0,0)$、$(0,1,0)$、$(0,0,1)$、$(0,0,2)$ 时，前三个向量是一个极大无关组，第一、二、四个向量也是。

    * > **结论**：极大线性无关组可能不唯一，但包含的向量个数一定相等。

* **特殊情况**

    * 向量组本身线性无关时，它的极大线性无关组就是它自己。

### 初等行变换不改变列向量之间的线性关系

* **结论与理由**

    * > **结论**：初等行变换不会改变列向量之间的线性关系。

    * 设 $x_1\alpha_1+\cdots+x_m\alpha_m=\mathbf 0$，这里的 $x$ 正是列向量之间的线性关系。

    * 把它展开成齐次方程组，对矩阵做初等行变换，同解变换保证解没有变，$x$ 没变，列向量之间的关系也就没变。

* **具体例子**

    * 已知某个方程组的解 $x=(5,0,3)^{\mathsf T}$，写成向量形式就是 $5\alpha_1+0\alpha_2+3\alpha_3=\beta$。

    * 把增广矩阵化到行最简型之后，新的列向量之间依然满足「五倍第一列加零倍第二列加三倍第三列等于右端向量」。

* **用途**

    * 这条性质是求极大线性无关组的全部依据：可以放心在化简后的矩阵上找主元列，再把结论搬回原矩阵。

### 求极大无关组的三步流程

* **题型**

    * 给定矩阵 $A$ 的列向量组，求它的一个最大无关组，并把不属于最大无关组的列向量用最大无关组线性表示。

* **三步流程**

    ```text
        拼成矩阵 A ──初等行变换──▶ 行最简形
                                      │
                            主元所在列 = 独立向量
                                      │
            ┌─────────────────────────┴─────────────────────────┐
            ▼                                                   ▼
      对应回原矩阵，这些位置的列就是极大无关组       非主元列的分量直接读出表示系数
                                                 （原封不动搬回原矩阵的列上）
    ```

    * 第一步：把 $A$ 化成行最简形，变化前的列向量记为 $\alpha_1,\dots$，变化后的记为 $\beta_1,\dots$，两者的线性关系一致。

    * 第二步：在行最简形里找主元列，主元落在第一、二、四列时 $\beta_1,\beta_2,\beta_4$ 就是一个最大无关组，对应回原矩阵得到 $\alpha_1,\alpha_2,\alpha_4$。

    * 第三步：非主元列按行最简形的分量直接读系数，$\beta_3=\beta_1-\beta_2$、$\beta_5=4\beta_1+3\beta_2-3\beta_4$。

    * > **提示**：读系数的窍门是行最简形里每个非主元列的分量，恰好就是它被主元列表示时的系数。

* **结论**

    * 同样的关系原封不动搬回原矩阵：$\alpha_3=\alpha_1-\alpha_2$、$\alpha_5=4\alpha_1+3\alpha_2-3\alpha_4$。

## 方程组解的结构

### 拿到方程组的第一步

* **判定的入场规则**

    * 非齐次方程组 $Ax=b$：$r(A)=r(A,b)=n$ 唯一解，$r(A)=r(A,b)<n$ 无穷多解，$r(A)<r(A,b)$ 无解。

    * 齐次方程组 $Ax=0$：零解天然存在，所以不存在无解的情形；$r(A)=n$ 时仅有零解，$r(A)<n$ 时有无穷多解。

* **求解的固定流水线**

    ```text
        增广矩阵（齐次的常数列可省） ──初等行变换──▶ 行最简型
                │
        非零行首元素对应主变量，其余变量是自由变量
                │
        把自由变量设为 k₁, k₂, … ，用它们表示主变量
                │
        得到方程组的通解
    ```

    * 写出增广矩阵是第一步，齐次方程组的常数列全是零，不写也不影响。

    * 化到行最简型之后，非零行的首个元素所在列对应主变量，其余变量是自由变量。

### 非齐通 = 齐通 + 非齐特

* **观察两个通解**

    * 非齐次方程组与它的导出组左边长得一模一样，只是常数项不同。

    * 把两个通解都写出来，前半部分完全一样，非齐次方程组的通解末尾多了一个向量。

* **结论**

    * > **结论**：非齐次线性方程组的通解 $=$ 齐次线性方程组的通解 $+$ 非齐次方程组的一个解。

    * 多出来的那个向量就是非齐次方程组的一个解，它的名字叫**特解**。

* **用途**

    * 把 $Ax=b$ 换成 $Ax=c$ 时，系数矩阵还是 $A$，所以 $Ax=0$ 的通解照用，只要再找一个 $Ax=c$ 的解加上去就行。

    ```text
        Ax = b 的通解
          =  Ax = 0 的通解            +   Ax = b 的一个特解
          =  k₁ξ₁ + k₂ξ₂ + … + kₛξₛ   +   η
             └── 基础解系，个数 n − r(A) ──┘   └─ 随便哪个解都行 ─┘
    ```

### 基础解系

* **定义**

    * > **定义**：齐次方程组的通解由多个任意常数乘上彼此独立的解向量再相加得到，这些彼此无关的解向量构成的向量组就是**基础解系**。

    * 通解本身不重要，重要的是基础解系里那几个向量：知道了它们，给每个配上任意常数再相加就是通解。

* **通解的写法**

    * 基础解系为 $\xi_1,\dots,\xi_s$ 时通解写成 $x=k_1\xi_1+k_2\xi_2+\cdots+k_s\xi_s$，并标注 $k_1,\dots,k_s$ 为任意常数。

    * 基础解系不唯一，它是解向量的极大线性无关组，而极大线性无关组本身就可能不唯一。

### 基础解系的向量个数

* **个数等于自由变量的个数**

    * 通解里每个独立向量都配一个任意常数，两者一一匹配，所以任意常数的个数就是基础解系中向量的个数。

    * 任意常数是给自由变量取的参数，于是个数又等于自由变量的个数。

* **用秩算出这个个数**

    * 主变量的个数等于秩 $r(A)$，主变量加自由变量等于变量总数 $n$。

    * 设自由变量个数为未知量，由 $r(A)+?=n$ 得 $?=n-r(A)$。

    * > **结论**：$n$ 元齐次线性方程组 $Ax=0$ 的基础解系含 $n-r(A)$ 个向量，它同时是自由变量的个数、任意常数的个数。

### 求基础解系与通解的例子

* **题型**

    * 求齐次线性方程组的基础解系与通解。

* **招式**

    * 写出系数矩阵（齐次不用写常数列），化到行最简型，得到最简方程组 $x_1=\frac27x_3+\frac37x_4$、$x_2=\frac57x_3+\frac47x_4$。

    * 主变量是 $x_1$、$x_2$，自由变量 $x_3$、$x_4$ 平移到等号右边，本身保持 $x_3=x_3$、$x_4=x_4$。

    * 令 $x_3=k_1$、$x_4=k_2$，按 $x_1,x_2,x_3,x_4$ 的顺序把解向量排出来。

    * 排出来的结果：$x=k_1\begin{pmatrix}\frac27\\\frac57\\1\\0\end{pmatrix}+k_2\begin{pmatrix}\frac37\\\frac47\\0\\1\end{pmatrix}$。

* **结论**

    * 基础解系就是 $\xi_1=\left(\frac27,\frac57,1,0\right)^{\mathsf T}$ 与 $\xi_2=\left(\frac37,\frac47,0,1\right)^{\mathsf T}$。

    * > **易错点**：末尾一定要标注 $k_1,k_2$ 为任意常数，漏掉这句话要扣分。

### 判断基础解系的三个条件

* **三个条件**

    ```text
        是解 ──── 每个 ξᵢ 都满足 Aξᵢ = 0
        无关 ──── ξ₁,…,ξₛ 线性无关，没有多余向量
        个数 ──── 恰好 n − r(A) 个，与自由变量个数对上
                │
                ▼
        三条同时满足 ⟺ ξ₁,…,ξₛ 是 Ax = 0 的基础解系
    ```

    * 是解：每一个 $\xi_i$ 都是 $Ax=0$ 的解，判断时把它代进方程验一验即可。

    * 无关：这组向量线性无关，等价于拼成的矩阵秩等于向量的个数。

    * 个数：总数必须是 $n-r(A)$，多一个少一个都不行。

    * > **结论**：任意 $n-r(A)$ 个线性无关的解都能组成 $Ax=0$ 的基础解系。

* **判定的优先顺序**

    * 三个条件可以先把最容易查的挑出来查，个数不足时一票就能否决，不必先去啃无关性。

    * > **提示**：抽象题里判断「是不是解」记住一句，代入以后结果为零就是解，别去猜 $A$ 长什么样。

### 抽象方程组的判定题

* **题型**

    * 已知 $\xi_1,\xi_2,\xi_3$ 是 $Ax=0$ 的一组基础解系，判断给出的几个向量组里哪些也是基础解系。

* **逐个条件的招式**

    * 「是解」的判断：$A(\xi_1-\xi_3)=A\xi_1-A\xi_3=0-0=0$，组合出来的向量依然是解。

    * 「无关」的判断：把三个向量按列拼成矩阵做初等列变换，用一列把另一列的组合成分消掉，秩不变，算出来的秩等于 3。

    * 「个数」的判断：已有基础解系含三个向量，所以新的向量组也必须恰好有三个。

* **三个向量组的分析**

    * 第一组：是解、无关、个数也对，三条全中，它确实是基础解系。

    * 第二组：是解没问题，但做列变换时某一列被消成零，秩只有 2，相关，淘汰。

    * 第三组：是解也没问题，可是它只有两个向量，个数就不够，直接淘汰。

* **结论**

    * 能构成基础解系的只有第一组，判定流程就是三条缺一不可。

### 三个秩的证明

* **$AB=O$ 时秩的界**

    * 题型：设 $AB=O$，证明 $r(A)+r(B)\le n$，$n$ 是矩阵相乘的内标。

    * 招式：把 $B$ 按列分块成 $B=(B_1\ B_2\ \cdots\ B_l)$，$AB=O$ 拆开就是 $AB_1=0,\dots,AB_l=0$。

    * 于是 $B$ 的每一列都是 $Ax=0$ 的解，而基础解系可以表示所有解，所以这些列都能被基础解系线性表示。

    * 被表示的秩不大：$r(B)\le n-r(A)$，移项就得 $r(A)+r(B)\le n$。

* **同解方程组秩相等**

    * 题型：设 $n$ 元齐次方程组 $Ax=0$ 与 $Bx=0$ 同解，证明 $r(A)=r(B)$。

    * 招式：解完全相同推出通解相同，基础解系里向量的个数也就相同。

    * 个数公式一写：$n-r(A)=n-r(B)$，于是 $r(A)=r(B)$。

* **秩不变式 $r(A)=r(A^{\mathsf T}A)$**

    * 题型：证明 $r(A)=r(A^{\mathsf T}A)$。

    * 路线：转化为证明 $Ax=0$ 与 $A^{\mathsf T}Ax=0$ 同解，同解就能推出两个秩相等。

    * 第一向：设 $\xi$ 是 $Ax=0$ 的任意一个解，两边左乘 $A^{\mathsf T}$ 得 $A^{\mathsf T}A\xi=0$，说明 $\xi$ 也是 $A^{\mathsf T}Ax=0$ 的解。

    * 第二向：设 $\eta$ 是 $A^{\mathsf T}A\eta=0$ 的任意一个解，两边左乘 $\eta^{\mathsf T}$ 得 $\eta^{\mathsf T}A^{\mathsf T}A\eta=0$。

    * 把左边写成 $(A\eta)^{\mathsf T}(A\eta)=0$，设 $A\eta=(a_1,\dots,a_n)^{\mathsf T}$，这式子就是 $a_1^2+a_2^2+\cdots+a_n^2=0$。

    * 平方和为零迫使每个 $a_i$ 都为零，于是 $A\eta=0$，说明 $\eta$ 也是 $Ax=0$ 的解。

    * > **易错点**：矩阵乘法没有消去律，不能从 $A^{\mathsf T}A\eta=0$ 里把 $A^{\mathsf T}$ 约掉，必须靠乘 $\eta^{\mathsf T}$ 凑出平方和为零才行。

### 特解与特解的位置

* **特解并不特殊**

    * > **定义**：非齐次方程组通解里多出来的那个解叫**特解**，它只是一个让方程成立的解，没有任何特殊性。

* **写通解的练习**

    * 已知 $\xi_1,\dots,\xi_n$ 是 $Ax=0$ 的基础解系、$\eta$ 是 $Ax=b$ 的一个解。

    * 齐次通解写成 $k_1\xi_1+\cdots+k_n\xi_n$，非齐次通解在它后面补上 $\eta$：$x=k_1\xi_1+\cdots+k_n\xi_n+\eta$。

    * > **易错点**：末尾加的是特解 $\eta$ 这个解向量，不是常数项 $b$；写成「齐通加 $b$」是高频错误。

### 常数项未知也能求通解

* **题型**

    * 一个非齐次线性方程组，常数项全部未知，只知道 $\eta$ 是它的一个解，要求通解。

* **招式**

    * 先用系数矩阵求齐次通解：化行最简后主变量是 $x_1$、$x_3$，同解方程组为 $x_1=x_2+x_4$ 与 $x_3=2x_4$。

    * 令自由变量 $x_2=k_1$、$x_4=k_2$，按分量排出解向量得
      $x_{\text{齐通}}=k_1\begin{pmatrix}1\\1\\0\\0\end{pmatrix}+k_2\begin{pmatrix}1\\0\\2\\1\end{pmatrix}$。

    * 最后把已知的特解 $\eta$ 加上去，$x_{\text{非齐通}}$ 就等于这个齐通再加 $\eta$。

* **结论**

    * 常数项一个都不知道也能把非齐次方程组的通解写出来，靠的就是「非齐通等于齐通加非齐特」。

### 解的混合运算

* **核心手法**

    * 判断一个混合表达式是谁的解，手法永远是同一条：把它代进 $A$ 里算一遍，看结果等于零还是等于 $b$。

* **四种情形**

    | 表达式 | 代入后的结果 | 结论 |
    | :--- | :--- | :--- |
    | $k_1\xi_1+k_2\xi_2$（$\xi$ 是齐次解） | $0$ | 是 $Ax=0$ 的解 |
    | $\eta_1-\eta_2$（$\eta$ 是非齐次解） | $b-b=0$ | 是 $Ax=0$ 的解 |
    | $\eta+\xi$（一个非齐次解加一个齐次解） | $b+0=b$ | 是 $Ax=b$ 的解 |
    | $k_1\eta_1+k_2\eta_2$，且 $k_1+k_2=1$ | $(k_1+k_2)b=b$ | 是 $Ax=b$ 的解 |

* **齐次解的线性组合还是齐次解**

    * $A(\xi_1+\xi_2)=A\xi_1+A\xi_2=0+0=0$，带系数也一样，常数可以提到 $A$ 外面去。

    * 所以齐次解的任意线性组合仍然是 $Ax=0$ 的解，这也是「基础解系的线性组合就是通解」的依据。

* **两个非齐次解相减变成齐次解**

    * $A(\eta_1-\eta_2)=A\eta_1-A\eta_2=b-b=0$，所以两个非齐次解之差是导出组的解。

* **非齐次解加齐次解还是非齐次解**

    * $A(\eta_1+\xi_1+\xi_2)=b+0+0=b$，结果等于 $b$，它仍是 $Ax=b$ 的解。

* **系数和为一的非齐次解组合还是非齐次解**

    * $A(k_1\eta_1+k_2\eta_2)=k_1b+k_2b=(k_1+k_2)b=1\cdot b=b$，靠的就是 $k_1+k_2=1$ 这个条件。

    * > **口诀**：判断混合运算的结果看 $b$ 的系数和，系数和为 0 是齐次解，系数和为 1 是非齐次解。

### 综合选择题：通解形式的判定

* **题型**

    * 已知 $\xi_1,\xi_2$ 是 $Ax=0$ 的基础解系，$\eta_1,\eta_2$ 是 $Ax=b$ 的两个不同的解，$k_1,k_2$ 为任意常数，判断哪个选项是 $Ax=b$ 的通解。

* **两个检查方向**

    * 非齐特：看选项里多出来的那部分是不是 $Ax=b$ 的解，判断依据是代入后 $b$ 的系数和。

    * 齐通：看 $k$ 乘向量的那部分能否构成齐通，也就是那几个向量能否构成基础解系，回到「是解、无关、个数」三条。

* **先查非齐特**

    * 选项里的 $\frac12\eta_1-\frac12\eta_2$ 系数和是 $\frac12-\frac12=0$，它是齐次解。

    * 代入验证也得到零，所以它当不了 $Ax=b$ 的特解，放它的选项被一票排除。

* **再查齐通**

    * 剩下选项的系数和都等于 1，非齐特这一关全过，接着比它们各自调出来的向量。

    * 由 $\xi_1$ 与 $\xi_1-\xi_2$ 组成的那一组，用初等列变换能把 $\xi_2$ 还原出来，变换后就是已知的基础解系，三条全合格。

    * 由 $\xi_1$ 与 $\eta_1-\eta_2$ 组成的那一组不合格：$\eta_1-\eta_2$ 确实是齐次解，但它究竟是哪一个解并不确定，甚至有可能是 $\xi_1$ 的倍数而与 $\xi_1$ 相关。

    * > **提示**：抽象题里「它是一个齐次解」与「它是哪一个齐次解」是两回事，来源不确定、可能撞车的向量不能顶基础解系的席位。

* **结论**

    * 能构成 $Ax=b$ 通解的是齐通合格且特解合格的那一项，两道关卡缺一不可。
