# 特征值、对称矩阵对角化与二次型

## 相似对角化与特征值、特征向量

### 对角矩阵的高次幂与普通矩阵的两条思路

* 对角矩阵求高次幂的规律

    * 对角矩阵的平方还是对角矩阵，对角线上的数各自平方，交叉位置全是零。
    * 三次幂同理，对角线上留下 $1^3$ 与 $3^3$，三阶对角矩阵也是同一个思想。
    * > **结论**：对角矩阵的高次幂，只要把主对角线上的数全部换成 $N$ 次幂。

        $$\Lambda^N = \operatorname{diag}(\lambda_1^N, \lambda_2^N, \dots, \lambda_n^N)$$

* 普通矩阵求高次幂，思路一：找规律法

    * 先把二次幂、三次幂老老实实算出来，观察有没有固定规律。
    * 部分题目确实能吃这一套，但它不是通用解法。

* 普通矩阵求高次幂，思路二：往对角矩阵上靠

    * 找一个可逆矩阵 $P$，把 $A$ 与对角矩阵建立联系，把问题变成对角矩阵的高次幂。
    * 这条路就是相似对角化，也是这类题的正规解法。

* > **定义**：如果存在可逆矩阵 $P$，使得 $P^{-1}AP = \Lambda$（$\Lambda$ 是对角矩阵），就说方阵 $A$ 可以相似对角化。

### 相似对角化求高次幂：三明治结构

* 由 $P^{-1}AP = \Lambda$ 两边同时左乘 $P$、右乘 $P^{-1}$，得到 $A = P\Lambda P^{-1}$。
* 算 $A^2$ 时把每个 $A$ 都换成 $P\Lambda P^{-1}$，中间的 $P^{-1}P$ 化成单位矩阵直接消掉。

    $$A^2 = (P\Lambda P^{-1})(P\Lambda P^{-1}) = P\Lambda^2 P^{-1}$$

* 推广到 $N$ 次幂，每两份三明治之间的 $P^{-1}P$ 都消掉，中间只留下一串 $\Lambda$。

    $$A^N = P\Lambda^N P^{-1}$$

* 计算顺序：先算 $\Lambda^N$（对角线上各自取 $N$ 次幂），再左乘 $P$、右乘 $P^{-1}$ 还原。

* 整条链路

    ```text
    求 A 的 N 次幂（A 不是对角矩阵，硬乘没有规律）
            │
            ▼
    找可逆 P，使 P⁻¹AP = Λ            ← 相似对角化
            │
            ▼
    A = PΛP⁻¹   ⟹   A^N = P Λ^N P⁻¹
            │
            ▼
    Λ^N：对角线上的数各自取 N 次幂
    ```

* 题目只给 $A$、不给 $P$ 与 $\Lambda$ 时，这两个矩阵要自己求，于是必须先学会求特征值与特征向量。

### 特征值与特征向量的定义

* > **定义**：满足 $A\xi = \lambda\xi$（$\xi \neq 0$）的向量 $\xi$ 称为 $A$ 的特征向量，数 $\lambda$ 称为 $A$ 的特征值。

    $$A\xi = \lambda\xi \qquad (\xi \neq 0)$$

* 几何理解：矩阵乘向量的效果相当于一个数乘该向量，向量方向不变、只做伸缩。
* $\xi$ 必须非零：零向量会让等式对任意 $\lambda$ 都成立，带不出任何信息。
* 表述要带归属：说特征向量时必须写清是"矩阵 $A$ 对应于特征值 $\lambda_1$ 的特征向量"。

### 特征值的求法

* 把 $\lambda\xi$ 改写成 $\lambda E\xi$ 再移项，化成齐次线性方程组。

    $$(A - \lambda E)\xi = 0$$

* $\xi \neq 0$ 说明这个齐次方程组有非零解，等价于系数矩阵 $A - \lambda E$ 不满秩。
* $A - \lambda E$ 是方阵，不满秩等价于行列式为零，这就是求特征值的特征方程。

    $$\vert A - \lambda E \vert = 0$$

* $n$ 阶矩阵解出 $n$ 个特征值，其中有相等的值，这些重复的值叫重根。
* 常用化简招式一：按零多的那一行展开，只剩一两项要算。
* 常用化简招式二：先把某行加到另一行制造出零与公因子，提出公因子后再展开、因式分解。

### 特征向量的求法

* 把每个特征值回代到 $(A - \lambda E)x = 0$，解齐次方程组，解向量就是特征向量。
* 基础解系里的向量就是该特征值对应的无关特征向量。
* 要求"特征向量"时，答案要写通解 $k\xi$（$k$ 为任意常数），它包含该特征值的全部特征向量。

* > **易错点**：只写一个基础解系不算完整的特征向量答案。若只做相似对角化，写到基础解系就足够。

* 求解流程

    ```text
    令 |A − λE| = 0
          │
          ▼
    解出特征值 λ1, λ2, …, λn（可能有重根）
          │ 逐个回代
          ▼
    解 (A − λi E)x = 0，取基础解系 ξ1, ξ2, …
          │
          ▼
    基础解系向量就是对应的特征向量
    ```

### 对角矩阵与可逆矩阵 P 的拼装

* $\Lambda$ 由特征值组成：主对角线上全部是特征值，其余位置全是零。
* $P$ 由特征向量按列拼成：$\xi_1, \xi_2, \dots, \xi_n$ 依次作为各列。
* > **易错点**：$\lambda_i$ 与 $\xi_i$ 必须位置一一对应，因为 $\xi_i$ 正是由 $\lambda_i$ 回代解方程组得到的。

* 顺序错位的后果：$(1,1)^{\mathrm T}$ 对应特征值 $2$，$(-1,1)^{\mathrm T}$ 对应特征值 $4$。
* 对角线上只能写 $\mathrm{diag}(2,4)$，不能随手写成 $\mathrm{diag}(4,2)$。
* $P$ 的可逆保证：各列全部取自各个基础解系中的向量，它们彼此线性无关。

### 一道二阶题的完整流程

* 题型：已知 $A = \begin{pmatrix} 3 & -1 \\ -1 & 3 \end{pmatrix}$，求特征值与特征向量。
* 招式一，求特征值：令 $|A - \lambda E| = 0$，用对角线法则展开得 $\lambda^2 - 6\lambda + 8 = 0$，因式分解 $(\lambda-2)(\lambda-4)=0$。
* 结论：$\lambda_1 = 2$，$\lambda_2 = 4$。
* 招式二，求 $\lambda_1 = 2$ 的特征向量：写出 $A - 2E = \begin{pmatrix} 1 & -1 \\ -1 & 1 \end{pmatrix}$。
* 把系数矩阵化到行最简形，得方程 $x_1 - x_2 = 0$，令自由变量 $x_2 = k_1$。
* 结论：$x = k_1(1,1)^{\mathrm T}$ 是 $A$ 对应于特征值 $2$ 的全部特征向量。
* 招式三，求 $\lambda_2 = 4$：$A - 4E$ 化行最简得 $\begin{pmatrix} 1 & 1 \\ 0 & 0 \end{pmatrix}$，令 $x_2 = k_2$（与上面区别开）。
* 结论：$x = k_2(-1,1)^{\mathrm T}$ 是 $A$ 对应于特征值 $4$ 的全部特征向量，写全这两句答案才完整。
* 拼装结果：$P = \begin{pmatrix} 1 & -1 \\ 1 & 1 \end{pmatrix}$，$\Lambda = \begin{pmatrix} 2 & 0 \\ 0 & 4 \end{pmatrix}$。
* 于是 $P^{-1}AP = \Lambda$，这个 $A$ 可以相似对角化。

### 遇上重根：能不能对角化

* 重根凑够了向量的例子

    * 令 $|A - \lambda E| = 0$，这个行列式第二行只有一个位置不为零，按第二行展开，得特征值 $-1, 2, 2$。
    * 分别解 $\lambda = -1$ 与 $\lambda = 2$ 对应的齐次方程组，各取基础解系。
    * 对角矩阵写成 $\mathrm{diag}(-1,2,2)$，$P$ 由基础解系的三个向量按列拼成，个数凑够三阶。
    * 结论：能写成 $P^{-1}AP = \Lambda$，这个 $A$ 可以相似对角化。

* 重根凑不齐向量的例子

    * 已知特征值 $2,1,1$：$\lambda = 2$ 的基础解系含 $(0,0,1)^{\mathrm T}$。
    * $\lambda = 1$ 的基础解系只有一个向量 $(1,-2,1)^{\mathrm T}$，$P$ 的第三列没有办法写。
    * 补一个同方向的倍数看似可行，但两列成比例、$P$ 不满秩，依然不可逆。
    * 结论：找不到可逆矩阵 $P$，这个矩阵不能相似对角化。

### 可相似对角化的充要条件

* > **结论**：$n$ 阶矩阵 $A$ 可相似对角化，当且仅当 $A$ 的线性无关的特征向量的个数等于矩阵的阶数 $n$。

* 无关向量有两个现成来源

    * 同一个基础解系内的向量彼此线性无关。
    * 不同特征值对应的特征向量一定线性无关。
    * 两部分个数加起来达到 $n$，就凑齐了可逆矩阵 $P$ 所需的列。

* 本质是找可逆矩阵 $P$：每个特征向量都是 $n$ 维的，$P$ 的 $n$ 列必须线性无关。
* 判断的落点：单根一定能提供一个无关特征向量，所以只需看重根能否提供与重数相同的个数。

### 特征值的性质

* 全部特征值相乘等于行列式

    $$\lambda_1 \lambda_2 \cdots \lambda_n = \vert A \vert$$

* 由乘积式得到一组等价关系：$|A| \neq 0$ 等价于没有零特征值，也等价于 $A$ 可逆。
* 全部特征值相加等于 $A$ 的迹，即主对角线上的元素之和。
* 真题（2008）：三阶矩阵 $A$ 的特征值是 $2, 3, \lambda$，且 $|2A| = -48$，求 $\lambda$。
    * 第一个考点：$|kA| = k^n|A|$。
    * 第二个考点：$|A|$ 等于全部特征值之积。
    * 解法：$|2A| = 2^3 \cdot 2 \cdot 3 \cdot \lambda = 48\lambda = -48$，得 $\lambda = -1$。

### 特征向量的性质

* 每个特征值至少提供一个特征向量：$A - \lambda E$ 不满秩，对应齐次方程组至少有无穷多解。
* 不同特征值的特征向量一定线性无关。
* 由此得一条好用的充分条件：$n$ 阶矩阵具有 $n$ 个互不相同的特征值，就一定可以相似对角化。
* 属于同一特征值的特征向量的线性组合，仍是该特征值的特征向量，因为齐次方程组的解做组合还是解。
* 属于不同特征值的特征向量的线性组合，不是特征向量，这一条用得很少，有印象即可。

### 相关矩阵的特征值与特征向量

* 这张表要背下来：已知 $A$ 的特征值 $\lambda$ 与特征向量 $\xi$，表中各矩阵的特征值随之确定。

    | 矩阵 | 特征值 | 特征向量 |
    | :---: | :---: | :---: |
    | $A$ | $\lambda$ | $\xi$ |
    | $kA$ | $k\lambda$ | $\xi$ |
    | $A + bE$ | $\lambda + b$ | $\xi$ |
    | $A^N$ | $\lambda^N$ | $\xi$ |
    | $A^{-1}$ | $\dfrac{1}{\lambda}$ | $\xi$ |
    | $A^{*}$ | $\dfrac{\vert A \vert}{\lambda}$ | $\xi$ |
    | $A^{\mathrm T}$ | $\lambda$ | **不是** $\xi$ |

* 推导的通用套路：让新矩阵去乘 $\xi$，看结果等于什么数乘 $\xi$。
* $A + bE$：用分配律展开得 $A\xi + bE\xi = \lambda\xi + b\xi = (\lambda+b)\xi$，特征值加 $b$。
* $A^N$：每碰到一次 $A$ 就掉出一个 $\lambda$，一路拆下去变成 $\lambda^N\xi$。
* $A^{-1}$：两边左乘 $A^{-1}$ 得 $\xi = \lambda A^{-1}\xi$，再除以 $\lambda$ 即得特征值 $\dfrac{1}{\lambda}$。
* $A^{*}$：借 $A^* = |A|A^{-1}$，从 $A^{-1}$ 的结果两边同乘 $|A|$，得特征值 $\dfrac{|A|}{\lambda}$。
* $A^{\mathrm T}$：特征值相同但特征向量不再继承，用 $|A^{\mathrm T} - \lambda E| = |(A-\lambda E)^{\mathrm T}| = |A - \lambda E|$ 验证特征值一致。
* 组合规则：除转置外，表中几项可以任意组合，特征值跟着做同样的运算。

### 组合矩阵特征值的真题

* 求 $|4A^{-1} - E|$，三阶矩阵 $A$ 的特征值为 $1, 2, 2$。

    * 层层变形：$A^{-1}$ 的特征值是 $1, \dfrac{1}{2}, \dfrac{1}{2}$。
    * $4A^{-1}$ 把 $A^{-1}$ 当新矩阵套 $kA$ 公式，特征值变成 $4, 2, 2$。
    * 再减单位矩阵，特征值全部减一得到 $3, 1, 1$。
    * 行列式等于特征值之积，所以 $|4A^{-1}-E| = 3 \times 1 \times 1 = 3$。

* 求 $A^* + 3A - 2E$ 的特征值，三阶矩阵 $A$ 的特征值为 $1, -1, 2$。

    * 把目标矩阵写成 $\lambda$ 的函数 $f(\lambda) = \dfrac{|A|}{\lambda} + 3\lambda - 2$，其中 $|A| = 1 \times (-1) \times 2 = -2$。
    * 逐个代入：$f(1) = -2 + 3 - 2 = -1$，$f(-1) = 2 - 3 - 2 = -3$，$f(2) = -1 + 6 - 2 = 3$。
    * 同一个函数还能顺手算行列式与迹，它们分别是特征值的乘积与和。

* 特征值里混进 $0$ 的同型题，特征值为 $0, -1, 2$。

    * 直接代入会让分母为零，处理办法是把 $|A|$ 改写成 $\lambda_1\lambda_2\lambda_3$，让 $\lambda_1$ 与分母约掉。
    * 得 $f(\lambda_1) = \lambda_2\lambda_3 + 3\lambda_1 - 2 = -2 + 0 - 2 = -4$。
    * 另外两个特征值分母不为零，正常代入得 $f(-1) = -5$，$f(2) = 4$，答案为 $-4, -5, 4$。

### 相似的定义与数值型性质

* > **定义**：设 $A$、$B$ 都是 $n$ 阶矩阵，如果存在可逆矩阵 $P$ 使 $P^{-1}AP = B$，就说 $A$ 与 $B$ 相似。

* 定义里的 $B$ 不要求是对角矩阵。$B$ 恰好是对角矩阵时，就是相似对角化问题。
* 相似的数值型性质全部相等：行列式、秩、特征值、迹、特征多项式。
* 判参数的顺序：先看迹（主对角线元素相加，最容易），再看行列式。
* 真题（2019）：两个含参数 $x, y$ 的矩阵相似，求参数。
    * 用迹相等列出第一个方程，两边主对角线元素之和相等。
    * 用行列式相等列出第二个方程，左边按含 $2$ 的那一行展开得 $2(-2x+4)$，右边主对角线行列式得 $-2y$。
    * 两个未知数两个有效方程，联立解得 $x = 3$，$y = 2$。

### 相似对角化的起源

* 设 $\xi_i$ 是 $A$ 对应于 $\lambda_i$ 的特征向量，对每个 $i$ 都有 $A\xi_i = \lambda_i\xi_i$，把它们按列拼成矩阵等式。

    $$A(\xi_1, \xi_2, \dots, \xi_n) = (\lambda_1\xi_1, \lambda_2\xi_2, \dots, \lambda_n\xi_n) = (\xi_1, \xi_2, \dots, \xi_n)\Lambda$$

* 记 $P = (\xi_1, \dots, \xi_n)$，它由 $n$ 个线性无关的特征向量拼成，所以可逆，于是 $AP = P\Lambda$。
* 两边同时左乘 $P^{-1}$ 得 $P^{-1}AP = \Lambda$，相似的定义就此凑出，对角化最根本的起源在这里。

## 内积、正交与实对称矩阵的对角化

### 内积与向量的长度

* 内积就是高中学过的数量积换了名字，代数上等于元素对应相乘再相加。

    $$(x, y) = x_1y_1 + x_2y_2 + \cdots + x_ny_n = x^{\mathrm T}y$$

* 向量长度（高中叫模长）等于向量与自己的内积再开根号。

    $$\|x\| = \sqrt{(x, x)} = \sqrt{x_1^2 + x_2^2 + \cdots + x_n^2}$$

* 长度恒非负：$x$ 不是零向量时长度大于零，$x$ 是零向量时长度等于零。

### 单位化

* 长度等于 $1$ 的向量叫单位向量，一般用 $e$ 表示。
* 单位化的做法：用向量除以它自己的长度。
* 例题：$\alpha = (1,1,-1)^{\mathrm T}$ 的长度是 $\sqrt{1^2+1^2+(-1)^2} = \sqrt3$。
* 单位化结果 $e = \dfrac{1}{\sqrt3}\begin{pmatrix} 1 \\ 1 \\ -1 \end{pmatrix}$，用原向量除以自身长度得到。

### 正交与施密特正交化

* > **定义**：$(x, y) = 0$ 与 $x$、$y$ 正交互为充要条件。正交就是高中的垂直，代数上表现为对应相乘再相加等于零。

* 正交化的几何想法：把 $y$ 中沿 $x$ 方向的分量去掉，剩下的 $y'$ 与 $x$ 正交，注意 $y'$ 已不是原来的 $y$。
* 施密特正交化公式，对线性无关的 $\alpha_1, \alpha_2, \alpha_3$：

    $$\beta_1 = \alpha_1$$

    $$\beta_2 = \alpha_2 - \frac{(\alpha_2, \beta_1)}{(\beta_1, \beta_1)}\beta_1$$

    $$\beta_3 = \alpha_3 - \frac{(\alpha_3, \beta_1)}{(\beta_1, \beta_1)}\beta_1 - \frac{(\alpha_3, \beta_2)}{(\beta_2, \beta_2)}\beta_2$$

* 两个记忆规律

    * 位置对位置：$\beta_k$ 的开头就是 $\alpha_k$。
    * 减去前面所有旧的 $\beta$，每个被减项的系数是内积之比。
* $\beta_1$ 前面没有旧的 $\beta$ 所以不减，$\beta_3$ 前面两个都减，做题一般只用前两个式子。
* 得到的三个新向量两两正交，随便挑两个都是正交关系。
* 正交单位化 = 先正交化、再单位化，两者是串联的两步。
* 例题招式：三个线性无关向量做正交单位化，先按公式依次算出 $\beta_1, \beta_2, \beta_3$，再各除以自身长度得到 $e_1, e_2, e_3$。

### 正交矩阵

* > **定义**：由两两正交的单位向量拼成的矩阵叫正交矩阵，一般记作 $Q$。

* 核心性质：$Q^{\mathrm T}Q = QQ^{\mathrm T} = E$，因此逆矩阵不用算，直接转置即可。

    $$Q^{-1} = Q^{\mathrm T}$$

* 性质的理解：$Q^{\mathrm T}Q$ 的元素是列向量之间的内积，同列内积为 $1$、异列内积为 $0$，结果就是单位矩阵。
* 正交化加单位化的目的，就是把普通向量整理成能拼出正交矩阵的两两正交单位向量。

### 实对称矩阵的四条性质

* > **定义**：满足 $A^{\mathrm T} = A$ 的矩阵叫对称矩阵，关于主对角线对称。研究的基本都是实对称矩阵。

* 性质一：实对称矩阵一定可以相似对角化，不必再逐题检查重根。
* 性质二：不同特征值的特征向量一定正交，正交比线性无关更强。
* 性质三：同一特征值（重根）的特征向量若不正交，用施密特正交化把它化成两两正交。
* 性质四：处理完正交性之后，把所有特征向量单位化。
* > **易错点**：正交化、单位化之后的向量仍然是原矩阵的特征向量，可以放心使用。

* 拼装结论：整理后的向量拼成的矩阵既是可逆矩阵又是正交矩阵，于是两个等式同时成立。

    $$Q^{-1}AQ = \Lambda, \qquad Q^{\mathrm T}AQ = \Lambda$$

* 两类矩阵的核心任务对比

    * 普通矩阵的核心是判断重根能否提供足够多的无关特征向量。
    * 实对称矩阵一定能对角化，核心变成把重根向量正交化、再把全部向量单位化，拼出 $Q$。

### 正交相似对角化的完整流程

* 流程本身

    ```text
          求特征值 |A − λE| = 0
                  │
          求特征向量 (A − λE)x = 0 的基础解系
                  │
          重根的特征向量不正交？ ──是──► 施密特正交化
                  │
          全部向量单位化
                  │
          按列拼成正交矩阵 Q，对角矩阵与特征值一一对应
                  │
          Q^-1 A Q = Q^T A Q = Λ
    ```

* 用途：把实对称矩阵化成对角矩阵，同时拿到正交矩阵与合同变换所需的矩阵。

### 二阶实对称矩阵：先 P 后 Q

* 第一问求可逆矩阵 $P$ 使 $P^{-1}AP = \Lambda$：先求特征值，再求特征向量，把特征向量按列拼成 $P$。
* 这里两个特征向量属于不同特征值，$A$ 又是实对称矩阵，所以两者天然正交，施密特一步都不用上。
* > **易错点**：只正交、没单位化，$P$ 只是一般的可逆矩阵，不能说它是正交矩阵。

* 第二问求正交矩阵 $Q$：步骤相同，只多出单位化这一步，$Q$ 由单位化后的特征向量按列拼成。
* 求 $Q^{\mathrm T}AQ = \Lambda$ 与求 $Q^{-1}AQ = \Lambda$ 是一回事，因为正交矩阵满足 $Q^{-1} = Q^{\mathrm T}$。
* > **易错点**：对角矩阵上的特征值顺序必须与 $Q$ 的列向量严格对应，不能错位。

* 用正交矩阵完成的这种对角化，叫正交相似对角化。

### 三阶实对称矩阵的全流程

* 第一步，求特征值：写 $|A - \lambda E| = 0$，把第二行的一倍加到第一行造出零与公因子，提公因子后按该行展开并因式分解。
* 结论：$\lambda_1 = 2$，$\lambda_2 = \lambda_3 = 1$。
* 第二步，求 $\lambda = 2$ 的特征向量：解 $(A - 2E)x = 0$，化简后令自由变量为任意常数，通解中的基础解系向量即为所求。
* 第二步（续），求 $\lambda = 1$ 的特征向量：$x_2$ 与 $x_3$ 都是自由变量，基础解系是两个向量，正好补齐重根所需的个数。
* 第三步，检查重根向量是否正交：把这两个向量做内积，结果等于 $1$ 而不是 $0$，需要正交化。
* 因为不同特征值的特征向量天然正交，所以只处理重根这一组，套施密特公式得 $\beta_1$ 与 $\beta_2$。
* 第四步，全部单位化：$\lambda = 2$ 的向量与 $\beta_1, \beta_2$ 各自除以自身长度，得到 $e_1, e_2, e_3$。
* 小技巧：向量里出现 $\frac{1}{2}$ 这类非整数分量时，先把整个向量按倍数放大成整数分量，再单位化，结果与直接单位化一致。
* 收尾：$P = (e_1, e_2, e_3)$，对角矩阵上依次是 $2, 1, 1$，于是 $P^{-1}AP = P^{\mathrm T}AP = \Lambda$。

## 二次型及其矩阵

### 二次型的定义

* 二次型是含 $n$ 个变量 $x_1$ 到 $x_n$、不含常数的二次齐次多项式。
* "二次齐次"指每一项未知数的次数和均为二，"多项式"在这里可以理解为函数。
* 换一种说法：二次型就是不含常数、每一项未知数次数和均为二的函数。

### 表格法写二次型的矩阵

* 任何二次型都能写成矩阵形式，列向量是 $x$，左边是 $x^{\mathrm T}$。

    $$f = x^{\mathrm T}Ax = (x_1, x_2, \dots, x_n)\,A\,\begin{pmatrix} x_1 \\ x_2 \\ \vdots \\ x_n \end{pmatrix}$$

* 难点在中间那个 $A$，它有三条要点

    * $A$ 是二次型的矩阵，它是对称矩阵，并且唯一。
    * 题目问二次型的秩，实际问的是 $A$ 的秩。
    * 二次型与它的对称矩阵一一对应，给出一个就能写出另一个。

* 填表规则

    ```text
                 x1      x2      x3
           x1 [  a11     a12     a13 ]
           x2 [  a21     a22     a23 ]
           x3 [  a31     a32     a33 ]

    平方项 xi^2 的系数  →  写进主对角线 aii
    交叉项 c·xi·xj     →  系数对半劈开 c/2
                          分别写进 (i,j) 与 (j,i) 两个对称位置
    ```

* 平方项看成 $x_i$ 乘 $x_i$，横向纵向都找 $x_i$，落点就在主对角线。
* 交叉项 $x_ix_j$ 对应两个对称位置，把系数均分到这两处即可。
* 例一：$f = x^2 + 4xy - 3z^2 + yz$，主对角线填 $1, 0, -3$。
* 再看交叉项：$xy$ 系数 4 拆成两个 2，$yz$ 系数 1 拆成两个 $\frac{1}{2}$，$xz$ 没有该项填两个 0。

    $$A = \begin{pmatrix} 1 & 2 & 0 \\ 2 & 0 & \frac{1}{2} \\ 0 & \frac{1}{2} & -3 \end{pmatrix}$$

* 例二：$f = 2x_1x_2 + 2x_1x_3 + 2x_2x_3$ 没有平方项，主对角线全为零，三个交叉项各拆出 1。

    $$A = \begin{pmatrix} 0 & 1 & 1 \\ 1 & 0 & 1 \\ 1 & 1 & 0 \end{pmatrix}$$

* 例二求秩：用对角线法则算 $|A| = 2 - 0 = 2 \neq 0$，矩阵满秩，二次型的秩为 3。

### 标准形与规范形

* 标准形：只含平方项、不含交叉项的二次型，平方项系数可以是任意实数。

    $$f = k_1x_1^2 + k_2x_2^2 + \cdots + k_nx_n^2$$

* 规范形：特殊的标准形，平方项系数只能取 $1$、$-1$ 或 $0$。

    $$f = d_1x_1^2 + d_2x_2^2 + \cdots + d_nx_n^2, \qquad d_i \in \{1, -1, 0\}$$

* 交叉项指 $x_1x_2$、$x_1x_3$ 这类不同未知数相乘的项。
* 两种特殊形的矩阵都是对角矩阵，规范形的对角元素还额外受系数限制。

    | 类型 | 含有的项 | 平方项系数 | 对应矩阵 |
    | :--- | :--- | :--- | :--- |
    | 一般二次型 | 平方项 + 交叉项 | 任意实数 | 对称矩阵 |
    | 标准形 | 只含平方项 | 任意实数 $k_i$ | 对角矩阵 |
    | 规范形 | 只含平方项 | 只能取 $1, -1, 0$ | 对角矩阵（系数受限） |

* 目标由此确定：把含交叉项的普通二次型化成标准形或规范形，手段是换元法。

### 线性变换

* "线性"指未知数的次数均为一，"变换"可以理解为换元。
* 矩阵形式是旧变量列向量等于系数矩阵乘新变量列向量。

    $$x = Cy$$

* > **易错点**：旧变量必须放在左侧，写成 $y = Cx$ 方向就反了。

* 判定是否为线性变换的两条硬标准

    * 变量个数不能变：原来三个 $x$，换元后仍是三个 $y$。
    * 不能有常数项：常数不是未知数，混进来就不是线性变换。

* 可逆性的意义

    * 系数矩阵 $C$ 满秩（一般求行列式，不为零）时，这个线性变换可逆。
    * 不可逆的变换没有意义：零矩阵对应的换元把二次型变成恒为零，回不到原二次型。
    * 可逆线性变换不损失任何信息，是化二次型时想要的那一类。

### 合同

* 把 $x = Cy$ 代入二次型，中间那个矩阵变成 $C^{\mathrm T}AC$。

    $$f = x^{\mathrm T}Ax = (Cy)^{\mathrm T}A(Cy) = y^{\mathrm T}(C^{\mathrm T}AC)y$$

* > **定义**：设 $A$、$B$ 都是 $n$ 阶矩阵，如果存在可逆矩阵 $C$ 使 $C^{\mathrm T}AC = B$，就说 $A$ 与 $B$ 合同。

* 二次型的角度：一个二次型经过可逆线性变换得到新二次型，两个二次型的矩阵就是合同关系。
* 定义本身不挑对称性：只要存在可逆 $C$ 满足 $C^{\mathrm T}AC = B$，两个 $n$ 阶矩阵就合同。
* 合同对角化：$A$ 为对称矩阵时，一定存在可逆矩阵 $C$ 使 $C^{\mathrm T}AC$ 为对角矩阵。
    * 依据是把 $C$ 取成实对称矩阵的正交矩阵 $Q$，正交矩阵本身可逆。
* 化标准形的原理就此打通：取 $x = Qy$，$Q^{\mathrm T}AQ = \Lambda$ 是对角矩阵，对角线上是特征值。
* 这个换元 $x = Qy$ 称为正交变换，它把二次型化成标准形。

### 正负惯性指数与惯性定理

* 正惯性指数 $p$ 的三种等价说法

    * 标准形中正平方项的个数。
    * 正特征值的个数。
    * 规范形中系数为 $1$ 的个数。

* 负惯性指数 $q$ 与它相反：负平方项个数、负特征值个数、规范形中系数为 $-1$ 的个数。

    | 惯性指数 | 看标准形 | 看特征值 | 看规范形 |
    | :--- | :--- | :--- | :--- |
    | 正惯性指数 $p$ | 正平方项个数 | 正特征值个数 | 系数为 $1$ 的个数 |
    | 负惯性指数 $q$ | 负平方项个数 | 负特征值个数 | 系数为 $-1$ 的个数 |

* 秩等于两个惯性指数之和：取 $x = Qy$ 后对角矩阵的秩就是非零特征值个数，而相似变换不改变秩。

    $$r(A) = p + q$$

* > **结论**（惯性定理）：二次型经过多次可逆线性变换，正负惯性指数不发生改变。

* 惯性指数不变带来连锁固定：正负特征值个数不变，两者之和也就是秩不变。
* 记忆锚点：初等变换的不变量是秩，可逆线性变换的不变量是正负惯性指数。

## 二次型化标准形与规范形

### 正交变换化标准形

* 正交变换是特殊的可逆线性变换，它比一般可逆变换多一个特点：不改变图像形状（了解即可）。
* 代入 $X = QY$ 后，两个 $Q$ 恰好把 $A$ 夹成对角矩阵。

    $$f = (QY)^{\mathrm T}A(QY) = Y^{\mathrm T}(Q^{\mathrm T}AQ)Y = Y^{\mathrm T}\Lambda Y = \lambda_1y_1^2 + \lambda_2y_2^2 + \lambda_3y_3^2$$

* > **结论**：正交变换化标准形，标准形的各项系数就是 $A$ 的全部特征值。

* 步骤：写出 $A$，求特征值与特征向量，重根特征向量做施密特正交化，全部单位化后按列拼成正交矩阵 $P$，再令 $X = PY$。
* 题型：求正交变换 $X = PY$ 把二次型化为标准形，实质是求正交矩阵 $P$ 使 $P^{-1}AP = P^{\mathrm T}AP = \Lambda$。
* 例题：$A$ 的特征值为 $-2, 1, 1$，重根向量正交化、全部单位化后拼出 $P$，得标准形 $f = -2y_1^2 + y_2^2 + y_3^2$。
* > **易错点**：求出正交矩阵并不算结束，必须写出"经正交变换 $X = PY$，二次型化为标准形"这句结论。

* 正交矩阵同时满足相似与合同，所以正交变换能做到合同且相似，这是它独有的效果。

### 两条路线对比：正交变换与配方法

* 两种变换的差别集中在换元矩阵、系数的性质与能化到的终点。

    | 对比项 | 正交变换 $X = QY$ | 配方法 $X = PY$ |
    | :--- | :--- | :--- |
    | 换元矩阵要求 | 必须是正交矩阵 | 只要可逆即可 |
    | 标准形系数 | 一定是特征值 | 不一定是特征值，与特征值同正负 |
    | 能否化规范形 | 不能 | 能，把系数吸收进平方向 |
    | 换元矩阵求法 | 求特征向量、正交化、单位化后拼列 | 先写出 $Y = CX$，再求 $C^{-1}$ |

* 题目指定用哪种方法就必须用哪种，方法限定不能自行换路子。
* 正交变换只能把系数变成特征值，这是它化不出规范形的根本原因。

### 配方法的原理

* 配方法只要求一个可逆线性变换，不要求正交。
* 操作要点是"一次解决一项"：第一轮吸收所有含 $x_1$ 的项，第二轮处理 $x_2$，第三轮处理 $x_3$。
* 换元方式：让每个 $y_i$ 分别等于配出的一个完全平方式。
* 可逆性来源：每轮消去一个变量，换元对应的矩阵是主对角形的，行列式一定不为零。
* > **易错点**：配方顺手写出的是 $Y = CX$，方向不对。两边左乘 $C^{-1}$ 得 $X = C^{-1}Y$，真正要的变换矩阵是 $P = C^{-1}$。

* 系数特征：配方法所得标准形的系数不再是特征值，但由惯性定理可知与特征值同正负。

### 配方法实战：借了要还

* 先配 $x_1$：把含 $x_1$ 的项挑出来，系数 2 提到括号外，配出 $(x_1-x_3)^2$。
* 配的时候借了东西：括号里多出 $2x_3^2$，借了最后要减回去。
* 再配 $x_2$：提出 2 配出 $(x_2-2x_3)^2$，检查多减了 $8x_3^2$，在后面加上 $8x_3^2$ 抵消。
* 前后剩下的 $-2x_3^2$ 与 $8x_3^2$ 合并成 $6x_3^2$，配方结束。

    $$f = 2(x_1-x_3)^2 + 2(x_2-2x_3)^2 + 6x_3^2$$

* 换元：令 $y_1 = x_1-x_3$，$y_2 = x_2-2x_3$，$y_3 = x_3$，此时写出的是 $Y = C_1X$。
* 收尾：题目要的变换矩阵要写成 $X = C_1^{-1}Y$，对 $C_1$ 求逆即可。

### 化规范形：系数吸收进平方向

* 从配好的平方项出发，把系数吸收到平方向里面：$2(x_1-x_3)^2 = \big(\sqrt2\,(x_1-x_3)\big)^2$。
* 依次吸收，第一个 2、第二个 2 与 6 都进入平方号内，平方项前面的系数全都变成 $1$。

    $$y_1 = \sqrt2(x_1-x_3), \qquad y_2 = \sqrt2(x_2-2x_3), \qquad y_3 = \sqrt6\,x_3$$

* 系数全为正时规范形各项系数都是 $+1$，某个系数为负则对应项自然带负号。
* > **易错点**：旧变量仍要放在左侧，此时的换元式写成 $Y = C_2X$ 的形式。

* 求逆小技巧：把常数 $\sqrt2$ 提到矩阵外面，用 $(kA)^{-1} = \dfrac{1}{k}A^{-1}$ 只求里面那个矩阵的逆。

### 没有平方项：平方差换元

* 前提提醒：先有平方才能配方，只有交叉项时配方无从下手。
* 创造平方向的办法：对交叉项 $x_1x_2$ 做平方差换元。

    $$x_1 = y_1 + y_2, \qquad x_2 = y_1 - y_2, \qquad x_3 = y_3$$

* $x_3 = y_3$ 绝对不能丢，每个变量都得有着落，换元矩阵才可逆。
* 换元后二次型出现平方向，接着按常规套路配方，再把系数吸收进平方向就得到规范形。
* 两次换元的拼接方式

    ```text
    第一次换元：X = C1·Y
    第二次换元：Z = C2·Y
    目标：求 X = ?·Z
         由 Z = C2·Y 两边左乘 C2 的逆，得 Y = C2^(-1)·Z
         代回第一次换元，得 X = C1·C2^(-1)·Z
    所以总的变换矩阵 P = C1·C2^(-1)
    ```

## 正定二次型与负定二次型

### 正定与负定的定义

* 前置事实：$X = 0$ 时二次型的每一项都含变量，所以 $f$ 恒等于 $0$。
* 因为零向量处 $f$ 恒为零，研究二次型取值的正负必须看 $X \neq 0$ 的情形。
* > **定义**：对任何 $X \neq 0$ 都有 $f(X) > 0$，称 $f$ 为正定二次型，$A$ 为正定矩阵。

* > **定义**：对任何 $X \neq 0$ 都有 $f(X) < 0$，称 $f$ 为负定二次型，$A$ 为负定矩阵。

* "正定"的记忆法：只要 $X$ 不是零向量，$f$ 就一定取正值。

### 用定义判断正定

* 判断思路：要否证正定，找出一个 $X \neq 0$ 使 $f(X) \le 0$ 就够了。
* 例题招式：取 $X = (1,0,0)^{\mathrm T}$，交叉项全部归零，只剩第一个平方项的系数。
* 结论：代入得 $f = -5 < 0$，一个反例即可判定该二次型不正定。

### 判断正定的四个充要条件

* 四个条件互相等价，每条都是充要条件，用哪个都行。判断对象一定是对称矩阵。
* 四个条件的关系

    ```text
    定义：X ≠ 0 时 f(X) > 0
    （等价写法：f ≥ 0，且仅当 X = 0 时 f = 0）
            │
            ├──► 顺序主子式全部大于零        ← 最常用
            │
            ├──► 正惯性指数 = n（等价于特征值全大于零）
            │
            └──► A 与单位矩阵合同：P^T A P = E
    ```

* 第一条，定义本身：$X \neq 0$ 时 $f(X) > 0$，等价写法是 $f \ge 0$ 且仅当 $X = 0$ 时取到零。
* 第二条，顺序主子式均大于零

    * 顺序主子式就是左上角的行列式，一阶是 $a_{11}$，$n$ 阶就是 $|A|$ 本身。
    * 一阶、二阶直到 $n$ 阶全部大于零，$A$ 就是正定矩阵，这条最好记也最常用。

    ```text
            | a11  a12  a13 |
    A  =    | a21  a22  a23 |
            | a31  a32  a33 |

    一阶顺序主子式：| a11 |
    二阶顺序主子式：| a11  a12 |
                    | a21  a22 |
    n 阶顺序主子式：就是 |A| 本身
    ```

* 第三条，正惯性指数等于 $n$，等价于特征值全部大于零，因为对角线上就是特征值。
* 第四条，$A$ 与单位矩阵合同，即存在可逆矩阵 $P$ 使 $P^{\mathrm T}AP = E$。
    * 理解路径：$X = PY$ 把 $f$ 变成 $Y^{\mathrm T}EY$，这是正惯性指数为 $n$ 的规范形。
    * 可逆变换不改变惯性指数，所以 $A$ 的正惯性指数也是 $n$，与第三条是一回事。
    * 反过来由 $C^{\mathrm T}EC = A$ 把中间的 $E$ 省去，得正定矩阵的分解 $A = C^{\mathrm T}C$。
* 应试口径：多数题目只需记住顺序主子式均大于零这一条。

### 含参数的正定问题

* 题型：二次型含参数 $\lambda$，已知它正定，求参数的取值范围。
* 招式：写出矩阵，逐阶检查左上角的行列式，最后把各阶条件取交集。
* 一阶顺序主子式为 $1$，天然大于零，不给出任何约束。
* 三阶顺序主子式就是 $|A|$，大于零解得 $-4 < \lambda < 0$。
* 与二阶条件取交集后，最终范围是 $-4 < \lambda < 0$。

### 负定的充要条件：奇负偶正

* 第一条，把定义里的大于零换成小于零即可。
* 第二条，顺序主子式：奇数阶为负，偶数阶为正。
    * > **易错点**：不能记成"顺序主子式均小于零"，这个说法是错的。
* 第三条，负惯性指数等于 $n$，等价于特征值全部小于零。
* 例题：先写矩阵，再逐阶看左上角的行列式。
    * 一阶顺序主子式小于零，这一条已经排除正定。
    * 二阶大于零，三阶（即 $|A|$）小于零。
    * 奇数阶为负、偶数阶为正，符合奇负偶正，该矩阵是负定矩阵。

### 正定与负定判定对照

* 四条判定途径并排对照

    | 判定途径 | 正定 | 负定 |
    | :--- | :--- | :--- |
    | 定义（任意 $X \neq 0$） | $f(X) > 0$ | $f(X) < 0$ |
    | 顺序主子式 | 各阶全部大于零 | 奇数阶为负，偶数阶为正 |
    | 惯性指数 | 正惯性指数等于 $n$ | 负惯性指数等于 $n$ |
    | 特征值 | 全部大于零 | 全部小于零 |

* 实操中最快的一条仍是顺序主子式：正定全正，负定奇负偶正。
* 定义法留给选择题找反例，惯性指数与特征值两条多在概念判断题里出现。
