# 特征值、对称矩阵对角化与二次型

## 特征值与特征向量

* **特征值与特征向量（Eigenvalue & Eigenvector）**

    * > **定义**：满足 $A\xi = \lambda\xi$（$\xi \neq 0$）的向量 $\xi$ 称为矩阵 $A$ 的特征向量，数 $\lambda$ 称为 $A$ 的特征值。

    * 本质：向量经矩阵 $A$ 作用后方向不变、只做伸缩，效果相当于一个数乘上这个向量。

    * 求特征值：把 $\lambda\xi$ 写成 $\lambda E\xi$ 移项得 $(A-\lambda E)\xi = 0$，这是齐次线性方程组；要求 $\xi \neq 0$ 即有非零解，故系数矩阵不满秩，得特征方程 $|A - \lambda E| = 0$。

    * $n$ 阶矩阵有 $n$ 个特征值（可能含重复的**重根**）。

    * 求特征向量：把每个 $\lambda_i$ 回代到 $(A - \lambda_i E)x = 0$，解齐次方程组，基础解系向量就是特征向量。

    * $k\xi_1$（$k$ 为任意常数）是该方程组的通解，也是对应于 $\lambda_1$ 的**全部特征向量**。

    * 表述要完整：特征向量必须说清是「哪个矩阵的、对应于哪个特征值的」特征向量。

    * > **易错点** ⚠️：题目求特征向量时要写出通解（全部特征向量），只写基础解系不对；但相似对角化问题中写出基础解系即可。

## 相似对角化

* **相似（Similarity）**

    * > **定义**：设 $A$、$B$ 都是 $n$ 阶矩阵，若存在可逆矩阵 $P$ 使 $P^{-1}AP = B$，则称 $A$ 与 $B$ 相似。$B$ 不一定是对角矩阵；$B$ 恰为对角矩阵时就是相似对角化。

    * 相似矩阵的一切数值型性质都相等：行列式、秩、特征值、迹、特征多项式。

    * 用相似求参数的顺序：先看**迹**（主对角线元素之和最简单），再看**行列式**，联立解出参数。

* **相似对角化（Diagonalization）**

    * > **定义**：存在可逆矩阵 $P$，使 $P^{-1}AP = \Lambda$（$\Lambda$ 为对角矩阵），称 $A$ 可相似对角化。

    * 动机：对角矩阵的高次幂只需把主对角线上的数各自取 $N$ 次幂；普通矩阵写成 $A = P\Lambda P^{-1}$ 后有 $A^N = P\Lambda^N P^{-1}$（三明治结构，中间 $P^{-1}P$ 消成单位矩阵），把高次幂问题转化为对角矩阵的高次幂问题。

    * 拼装规则：$\Lambda$ 由**特征值**组成，$P$ 由**特征向量按列**拼成；$\lambda_i$ 与 $\xi_i$ 必须位置一一对应，顺序不能错位。

    * $P$ 可逆的保证：只要 $P$ 的列全部取自各基础解系中的特征向量，$P$ 就一定可逆。

    * 充要条件：$n$ 阶矩阵 $A$ 可相似对角化 $\iff$ $A$ 的线性无关特征向量个数等于 $n$。

    * 个数怎么数：单根特征值必提供一个无关特征向量；不同特征值的特征向量必线性无关；把各基础解系向量个数加总，够 $n$ 个就能对角化。

    * 判断的关键在**重根**：重根能否提供与重数相同个数的无关特征向量。提供不够时 $P$ 凑不满 $n$ 列；硬补成比例向量则 $P$ 秩不满、不可逆，都不能对角化。

    * 推论：$n$ 阶矩阵有 $n$ 个互不相同的特征值 $\Rightarrow$ 一定可相似对角化。

* **$P^{-1}AP = \Lambda$ 的来源**

    * 设 $A\xi_i = \lambda_i\xi_i$，按列拼成矩阵：$A(\xi_1,\dots,\xi_n) = (\lambda_1\xi_1,\dots,\lambda_n\xi_n) = (\xi_1,\dots,\xi_n)\Lambda$。

    * 令 $P = (\xi_1,\dots,\xi_n)$，由 $n$ 个线性无关特征向量拼成故可逆，得 $AP = P\Lambda$，左乘 $P^{-1}$ 即 $P^{-1}AP = \Lambda$。

## 特征值与特征向量的性质

* **特征值的数值性质**

    * 所有特征值之积等于行列式：$\lambda_1\lambda_2\cdots\lambda_n = |A|$。

    * 推论：$|A| \neq 0 \iff$ 无零特征值 $\iff$ $A$ 可逆。

    * 所有特征值之和等于**迹**（trace）：$\sum\lambda_i = $ 主对角线元素之和。

    * 配套公式：$|kA| = k^n|A|$。例：特征值 $2,3,\lambda$、$|2A| = -48$，则 $2^3\cdot 2\cdot 3\cdot\lambda = 48\lambda = -48$，$\lambda = -1$。

* **特征向量的结构性质**

    * 每个特征值至少提供一个特征向量（$|A-\lambda E| = 0$ 保证 $A - \lambda E$ 不满秩，齐次方程组有无穷多解）。

    * 不同特征值的特征向量一定线性无关。

    * 属于**同一**特征值的特征向量的线性组合，仍是该特征值的特征向量（齐次方程组解的线性组合仍是解）。

    * 属于**不同**特征值的特征向量的线性组合，不是特征向量。

* **相关矩阵的特征值与特征向量（必背表）**

    * 已知 $A$ 的特征值为 $\lambda$、特征向量为 $\xi$，则：

    | 矩阵 | 特征值 | 特征向量 |
    | :---: | :---: | :---: |
    | $A$ | $\lambda$ | $\xi$ |
    | $kA$ | $k\lambda$ | $\xi$ |
    | $A + bE$ | $\lambda + b$ | $\xi$ |
    | $A^N$ | $\lambda^N$ | $\xi$ |
    | $A^{-1}$ | $\dfrac{1}{\lambda}$ | $\xi$ |
    | $A^{*}$ | $\dfrac{|A|}{\lambda}$ | $\xi$ |
    | $A^{\mathrm T}$ | $\lambda$ | **不是** $\xi$ |

    * 推导思路：用新矩阵去乘 $\xi$ 验证；$A^{-1}$ 由 $A\xi = \lambda\xi$ 两边左乘 $A^{-1}$ 得 $\xi = \lambda A^{-1}\xi$；$A^{*} = |A|A^{-1}$ 顺势推出。

    * $A^{\mathrm T}$ 的特征值：$|A^{\mathrm T} - \lambda E| = |(A-\lambda E)^{\mathrm T}| = |A - \lambda E|$，与 $A$ 完全相同；但特征向量不再是 $\xi$。

    * 除转置外，上述矩阵可**任意组合**：新矩阵的特征值 = 对每个 $\lambda$ 做同样的运算 $f(\lambda)$。

    * 应用：$A$ 特征值 $1,2,2$，则 $4A^{-1} - E$ 的特征值依次为 $4\cdot\frac12 - 1$ 那样逐层变换得 $3,1,1$，行列式 $= 3\times1\times1 = 3$（行列式即特征值之积）。

    * 含 $A^{*}$ 的组合：特征值 $1,-1,2$ 时 $f(\lambda) = \frac{|A|}{\lambda} + 3\lambda - 2$，$|A| = -2$，逐个代入得 $-1,-3,3$。

    * > **易错点**：某特征值为 $0$ 时不能直接代入 $\frac{|A|}{\lambda}$（分母为零）。处理：$|A|$ 改写成 $\lambda_1\lambda_2\lambda_3$ 与分母约分，例如 $f(\lambda_1) = \lambda_2\lambda_3 + 3\lambda_1 - 2$ 再代入。

## 内积、长度与正交

* **内积（Inner Product）**

    * > **定义**：$(x, y) = x_1y_1 + x_2y_2 + \cdots + x_ny_n = x^{\mathrm T}y$，即高中数量积的代数化——元素对应相乘再相加。

* **向量长度（Length / Norm）**

    * $\|x\| = \sqrt{(x, x)} = \sqrt{x_1^2 + \cdots + x_n^2}$。

    * $\|x\| \ge 0$ 恒成立，且 $\|x\| = 0 \iff x = 0$。

    * **单位向量**：长度等于 $1$ 的向量，一般记作 $e$。

    * **单位化**：非单位向量除以自身长度即变为单位向量，如 $\alpha = (1,1,-1)^{\mathrm T}$，$\|\alpha\| = \sqrt3$，$e = \frac{1}{\sqrt3}(1,1,-1)^{\mathrm T}$。

* **正交（Orthogonality）**

    * > **定义**：$(x, y) = 0 \iff x$ 与 $y$ 正交（即高中的垂直关系）。

## 施密特正交化

* **施密特正交化（Gram-Schmidt Orthogonalization）**

    * 作用：把线性无关的向量组变成**两两正交**（相互正交）的向量组。

    * 公式（三个向量时）：

    $$\beta_1 = \alpha_1$$

    $$\beta_2 = \alpha_2 - \frac{(\alpha_2, \beta_1)}{(\beta_1, \beta_1)}\beta_1$$

    $$\beta_3 = \alpha_3 - \frac{(\alpha_3, \beta_1)}{(\beta_1, \beta_1)}\beta_1 - \frac{(\alpha_3, \beta_2)}{(\beta_2, \beta_2)}\beta_2$$

    * 记法规律：**位置对位置**（$\beta_i$ 的开头是 $\alpha_i$）；**减去所有旧的 $\beta$**，每个旧 $\beta$ 的系数是「$\beta$ 与新向量 $\alpha$ 的内积」除以「$\beta$ 与自己的内积」。实际做题常只用前两个式子。

    * 几何理解：把 $y$ 沿 $x$ 方向的分量去掉，剩下的方向就与 $x$ 正交（得到的 $y'$ 已不是原来的 $y$）。

    * **正交单位化** = 先正交化，再逐个单位化。

## 正交矩阵

* **正交矩阵（Orthogonal Matrix）**

    * > **定义**：由两两正交的**单位**向量按列拼成的矩阵，记作 $Q$。

    * 性质：$Q^{\mathrm T}Q = QQ^{\mathrm T} = E$（对角线上是各单位向量与自己的内积 $1$，交叉位置是正交内积 $0$）。

    * 由此 $Q^{-1} = Q^{\mathrm T}$，正交矩阵的逆特别好求。

## 实对称矩阵的正交对角化

* **实对称矩阵（Real Symmetric Matrix）**

    * > **定义**：满足 $A^{\mathrm T} = A$ 的矩阵，元素关于主对角线对称。

    * 四条性质：

        * 实对称矩阵**一定**可以相似对角化（普通矩阵要讨论重根，这里直接保证）。

        * **不同特征值**的特征向量一定**正交**（普通矩阵只有「无关」，正交更强）。

        * 属于**同一重根**的特征向量若不正交，用施密特正交化处理成正交。

        * 所有特征向量再**全部单位化**。

    * > **易错点**：正交化、单位化后的向量**仍然是原矩阵的特征向量**，放心使用。

    * > **易错点**：只正交、未单位化的特征向量拼成的 $P$ **不是**正交矩阵；必须正交化加单位化齐备才算。

* **正交相似对角化的完整流程**

    ```text
      求特征值 |A - λE| = 0
              |
      求特征向量 (A - λE)x = 0 的基础解系
              |
      重根的特征向量彼此不正交？ --是--> 施密特正交化
              |                           |
              +---------- 变成两两正交 <--+
              |
      全部单位化
              |
      按列拼成正交矩阵 Q ，对角矩阵与特征值一一对应
              |
      Q^-1 A Q = Q^T A Q = Λ
    ```

    * 普通矩阵对角化的核心问题是判断重根能否提供足够特征向量；实对称矩阵反正能对角化，核心问题变成**写出正交矩阵 $Q$**。

    * 拼出的 $Q$ 同时满足 $Q^{-1}AQ = \Lambda$ 与 $Q^{\mathrm T}AQ = \Lambda$（因 $Q^{-1} = Q^{\mathrm T}$）。

    * 题目问「求 $Q^{\mathrm T}AQ = \Lambda$」与「求 $Q^{-1}AQ = \Lambda$」是同一回事。

    * > **易错点**：对角矩阵上的特征值与 $Q$ 的列向量必须一一对应，顺序不能摆错。

    * 单位化小技巧：向量分量带 $\frac12$ 这类分数时，先按倍数放大成整数分量再单位化，结果一样。

## 二次型及其矩阵

* **二次型（Quadratic Form）**

    * > **定义**：含 $n$ 个变量 $x_1$ 到 $x_n$、不含常数的**二次齐次多项式**——每一项未知数的次数和均为二的函数。

* **二次型的矩阵 $A$**

    * 任何二次型都可写成矩阵形式 $f = x^{\mathrm T}Ax = (x_1,\cdots,x_n)\,A\,(x_1,\cdots,x_n)^{\mathrm T}$。

    * $A$ 是二次型的矩阵：一定是**对称矩阵**，且**唯一**；二次型与 $A$ 一一对应。

    * **二次型的秩** = 矩阵 $A$ 的秩。

    * 写 $A$ 的表格法：上方与左侧都标 $x_1$ 到 $x_n$，按下标定位——

    ```text
                 x1      x2      x3
           x1 [  a11     a12     a13 ]
           x2 [  a21     a22     a23 ]
           x3 [  a31     a32     a33 ]

           平方项  xi^2 = xi·xi  -> 系数 aii 落在主对角线
           交叉项  c·xi·xj      -> 系数对半劈开，c/2 与 c/2
                                   均分到 (i,j) 与 (j,i) 两个对称位置
    ```

    * 例：$f = x^2 + 4xy - 3z^2 + yz$ 对应 $A = \begin{pmatrix} 1 & 2 & 0 \\ 2 & 0 & \frac12 \\ 0 & \frac12 & -3 \end{pmatrix}$；缺项系数写 $0$。

    * 例：$f = 2x_1x_2 + 2x_1x_3 + 2x_2x_3$ 无平方项，$A = \begin{pmatrix} 0 & 1 & 1 \\ 1 & 0 & 1 \\ 1 & 1 & 0 \end{pmatrix}$，行列式为 $2 \neq 0$，秩为 $3$，二次型的秩即 $3$。

## 标准形、规范形与线性变换

* **标准形（Standard Form）**

    * > **定义**：只含平方项、不含交叉项的二次型 $f = k_1x_1^2 + k_2x_2^2 + \cdots + k_nx_n^2$，系数 $k_i$ 为任意实数。

    * 对应矩阵是对角矩阵 $\operatorname{diag}(k_1, \cdots, k_n)$。

* **规范形（Normal Form）**

    * > **定义**：特殊的标准形，平方项系数只能取 $1$、$-1$ 或 $0$（$0$ 即没有这一项）。

* **三种形态对比**

    | 类型 | 含有的项 | 平方项系数 | 对应矩阵 |
    | :--- | :--- | :--- | :--- |
    | 一般二次型 | 平方项 + 交叉项 | 任意实数 | 对称矩阵 |
    | 标准形 | 只含平方项 | 任意实数 $k_i$ | 对角矩阵 |
    | 规范形 | 只含平方项 | 只能取 $1, -1, 0$ | 对角矩阵（系数受限） |

* **线性变换（Linear Transformation）**

    * > **定义**：一次换元 $x = Cy$，即每个旧变量都写成新变量的一次式，矩阵形式 $x = Cy$（$C$ 为系数矩阵）。

    * 两条硬标准：**变量个数不能变**；**不能有常数项**（常数不是未知数，混入就不叫线性）。

    * > **易错点**：**旧变量必须写在左侧**，即 $x = Cy$；写成 $y = Cx$ 方向就反了。

    * 可逆性：$C$ 满秩（行列式不为零）时变换可逆，不损失任何信息；不可逆的变换（如零矩阵）把二次型变恒为零、无法变回，没有意义。

## 合同与惯性定理

* **合同（Congruence）**

    * > **定义**：设 $A$、$B$ 都是 $n$ 阶矩阵，若存在**可逆**矩阵 $C$ 使 $C^{\mathrm T}AC = B$，则 $A$ 与 $B$ 合同。

    * 来源：二次型 $f = x^{\mathrm T}Ax$ 经可逆变换 $x = Cy$ 变为 $f = y^{\mathrm T}(C^{\mathrm T}AC)y$，新旧二次型的矩阵 $A$ 与 $C^{\mathrm T}AC$ 合同。

    * 定义只要求 $n$ 阶矩阵，**不挑对称性**：非对称矩阵满足该等式也可称合同。

    * 合同对角化：对称矩阵 $A$ 一定存在可逆 $C$ 使 $C^{\mathrm T}AC$ 为对角矩阵——取 $C$ 为正交矩阵 $Q$ 即可（$Q^{\mathrm T}AQ = \Lambda$ 且 $Q$ 可逆）。

* **正惯性指数 $p$ 与负惯性指数 $q$**

    * $p$ 的三个等价说法：标准形中**正平方项的个数** = **正特征值的个数** = 规范形中系数为 $1$ 的个数。

    * $q$ 同理：负平方项个数 = 负特征值个数 = 规范形中系数为 $-1$ 的个数。

    | 惯性指数 | 看标准形 | 看特征值 | 看规范形 |
    | :--- | :--- | :--- | :--- |
    | 正惯性指数 $p$ | 正平方项个数 | 正特征值个数 | 系数为 $1$ 的个数 |
    | 负惯性指数 $q$ | 负平方项个数 | 负特征值个数 | 系数为 $-1$ 的个数 |

    * 二次型矩阵的秩等于正负惯性指数之和：$r(A) = p + q$（相似对角化不改变秩，对角矩阵的秩即非零特征值个数）。

    * **惯性定理**：二次型经过可逆线性变换，正负惯性指数不变——这是可逆线性变换下的不变量（类比初等变换下秩不变）。

## 正交变换化标准形

* **正交变换（Orthogonal Transformation）**

    * > **定义**：$x = Qy$（$Q$ 为正交矩阵）的线性变换，本质是特殊的可逆线性变换，不改变图像的形状。

    * 原理：$f = (Qy)^{\mathrm T}A(Qy) = y^{\mathrm T}(Q^{\mathrm T}AQ)y = y^{\mathrm T}\Lambda y = \lambda_1y_1^2 + \lambda_2y_2^2 + \lambda_3y_3^2$。

    * > **结论**：正交变换化标准形，标准形的系数就是 $A$ 的**全部特征值**。

    * 正交矩阵 $P$ 对 $A$ 既相似又**合同**（$P^{-1}AP = P^{\mathrm T}AP = \Lambda$ 同时成立），这是普通可逆矩阵做不到的。

* **操作步骤**

    * 写出二次型矩阵 $A$ → 求特征值、特征向量 → 重根的特征向量用施密特正交化（不同特征值的天然正交，无需处理）→ 全部单位化按列拼成正交矩阵 $P$ → 令 $x = Py$。

    * 例：$\lambda_1 = -2$，$\lambda_2 = \lambda_3 = 1$，得标准形 $f = -2y_1^2 + y_2^2 + y_3^2$。

    * > **易错点** ⚠️：求出正交矩阵不算结束，最后必须写成线性变换形式——「经正交变换 $x = Py$，二次型化为标准形 $f = \cdots$」。

## 配方法化标准形与规范形

* **配方法（Completing the Square）**

    * > **定义**：不用正交矩阵，直接找可逆矩阵 $P$，把二次型的普通形式逐项配成完全平方从而化为标准形的可逆线性变换法。

    * 核心口诀：**一次解决一项**——第一次吸收掉所有含 $x_1$ 的项，第二次解决 $x_2$，第三次解决 $x_3$。

    * 可逆性保证：每次解决一个变量，换元矩阵呈主对角形，行列式必不为零，一定是可逆线性变换。

    * 配方是「借了要还」：配 $(x_1-x_3)^2$ 会多出 $2x_3^2$（前面挂着系数 2），要在后面减回去；再如配出 $(x_2-2x_3)^2$ 多减了 $8x_3^2$，需加回。例：$f = 2(x_1-x_3)^2 + 2(x_2-2x_3)^2 + 6x_3^2$。

    * > **易错点**：换元顺手写出的是 $y = Cx$，但线性变换要求旧变量在左侧——先老实写 $y = C_1x$，两边左乘 $C_1^{-1}$ 得 $x = C_1^{-1}y$，**变换矩阵取 $P = C^{-1}$**。

    * 配方法得到的标准形系数**不是特征值**，只与特征值**同正负**（由惯性定理保证）。

* **配方法化规范形**

    * 手段：把平方项前的系数**吸收进平方向**，如 $2(x_1-x_3)^2 = \big(\sqrt2(x_1-x_3)\big)^2$，系数 $2,2,6$ 全正则规范形系数全为 $+1$；哪个系数为负，对应项就是 $-y_i^2$。

    * 求逆技巧：把 $\sqrt2$ 这类公因子提到矩阵外，套 $(kA)^{-1} = \frac1k A^{-1}$，只需求里面矩阵的逆再乘 $\frac1k$。

    * 正交变换**做不到**这一点——它只能把系数变成特征值，化不出系数 $1,-1,0$ 的规范形，所以配方法有独占用途。

    * > **易错点**：题目限定用配方法时，用正交变换做就是错误答案。

* **无平方项：平方差换元**

    * 前提：**先有平方项才能配方**；只有交叉项（如 $x_1x_2$）时先自己创造平方向。

    * 平方差换元：$x_1 = y_1 + y_2$，$x_2 = y_1 - y_2$，$x_3 = y_3$——**最后一个变量也绝不能丢**，每个变量都得有着落，矩阵才可逆。

    * 换元后出现平方向，再按配方 → 吸收系数 → 换元的路子化规范形。

    * 两次换元接总变换：由 $x = C_1y$ 与 $z = C_2y$，得 $y = C_2^{-1}z$，代入得 $x = C_1C_2^{-1}z$，总变换矩阵 $P = C_1C_2^{-1}$。

## 正定二次型

* **正定与负定（Positive / Negative Definite）**

    * 前提认知：$x = \mathbf 0$ 时 $f = 0$ 恒成立，该位置对研究正负无意义，所以只讨论 **$x \neq \mathbf 0$** 的情形。

    * > **定义**：对任何 $x \neq \mathbf 0$ 都有 $f(x) > 0$，称 $f$ 为**正定二次型**，对称矩阵 $A$ 为正定矩阵；对任何 $x \neq \mathbf 0$ 都有 $f(x) < 0$，称 $f$ 为**负定二次型**，$A$ 为负定矩阵。

    * 只讨论对称矩阵的正定：正定概念从二次型诞生，而二次型的矩阵一定是实对称矩阵。

* **用定义判定**

    * 判**不正定**只需一个反例：找到某个 $x \neq \mathbf 0$ 使 $f(x) \le 0$ 即可。

    * 技巧：取 $x = (1,0,0)^{\mathrm T}$ 这类简单非零向量代入，交叉项全归零，只看剩下方平方项系数；如 $f = -5 < 0$，立即得出不正定。

* **正定的四个充要条件**

    * 条件一（定义本身）：$x \neq \mathbf 0$ 时 $f(x) > 0$；等价写法：$f \ge 0$ 且**当且仅当 $x = \mathbf 0$ 时 $f = 0$**（考研更常用后者）。

    * 条件二：**顺序主子式均大于零**。顺序主子式即**左上角的行列式**：

    ```text
            | a11  a12  a13 |
    A  =    | a21  a22  a23 |
            | a31  a32  a33 |

    一阶顺序主子式：| a11 |
    二阶顺序主子式：| a11  a12 |
                    | a21  a22 |
    n 阶顺序主子式：就是 |A| 本身
    ```

    * 一阶、二阶直到 $n$ 阶**全部大于零**才正定（缺一不可）。

    * 条件三：正惯性指数等于 $n$，即特征值全部大于零。

    * 条件四：$A$ 与单位矩阵合同，即存在可逆矩阵 $P$ 使 $P^{\mathrm T}AP = E$；反过来也成立，且可写成 $A = C^{\mathrm T}C$（正定矩阵的分解形式）。

    * 含参数题型：已知正定求参数范围，逐阶令顺序主子式大于零再取交集，如解得 $-4 < \lambda < 0$。

* **负定的充要条件（奇负偶正）**

    * 定义条件同正定，把大于零换成小于零。

    * 顺序主子式判据：**奇数阶顺序主子式为负、偶数阶为正**，矩阵才负定。

    * > **易错点** ⚠️：负定**不是**「顺序主子式均小于零」——那样偶数阶就判错了，必须奇负偶正。

    * 惯性指数判据：负惯性指数等于 $n$，即特征值全部小于零。

* **正定与负定判定对照**

    | 判定途径 | 正定 | 负定 |
    | :--- | :--- | :--- |
    | 定义（任意 $x\neq\mathbf 0$） | $f(x)>0$ | $f(x)<0$ |
    | 顺序主子式 | 各阶全部 $>0$ | 奇数阶 $<0$，偶数阶 $>0$ |
    | 惯性指数 | 正惯性指数 $=n$ | 负惯性指数 $=n$ |
    | 特征值 | 全部 $>0$ | 全部 $<0$ |
