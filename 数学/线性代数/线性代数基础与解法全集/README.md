## 怎么学

- **跟着例子入门** → 课程从鸡兔同笼引出行列式与方程组，先看懂例子再回头记定义，比一上来背公式顺畅得多
- **练熟行列式七个题型** → 第一册把定义、展开与计算收在一册，目标是题型「看名字就知道怎么下手」
- **打通矩阵工具箱** → 第二册的矩阵运算、逆矩阵与分块矩阵是后面所有判定的工具，克拉默法则也在这里收口
- **抓住方程组主线** → 第三册用初等变换与秩把解的判定串起来，记住「非齐通 = 齐通 + 非齐特」这一句
- **攻克对角化与二次型** → 第四册从对角矩阵的高次幂讲起引出特征值，到正交变换化标准形，是命题热点
- **考前速查** → `notes/` 里的 5 篇笔记按知识主题跨块聚合，适合考前集中过一遍
