# 宋浩《线性代数》3.0 版

宋浩老师的《线性代数》3.0 版，是配合考研大纲的完整系统课。课程从行列式的定义与计算起步，经矩阵运算、逆矩阵与初等变换、矩阵的秩，逐步推进到向量与向量组的线性结构、线性方程组的解的判定与通解，再落到特征值与相似对角化、二次型的化标准形，最后收在向量空间、基与坐标变换上，把「用矩阵语言描述线性问题」这条主线讲成体系。

- **原视频**：https://www.bilibili.com/video/BV1d7wAzsE8V — Bilibili，BV1d7wAzsE8V
- **39 集**，已产出 8 册模块全书、11 篇复习笔记、42 份逐字稿

## 怎么学

- **先算熟行列式** → 模块 01 是全课的算力基础，n 阶行列式的展开与性质必须练到形成肌肉记忆
- **打通矩阵运算** → 模块 02、03 讲矩阵运算、逆矩阵、初等变换与秩，这四件事是后面所有判定的工具箱
- **抓住线性结构** → 模块 04 讲向量与向量组的线性相关性，是理解秩、解空间的唯一入口
- **解方程组** → 模块 05 用秩把克拉默法则、解的判定与通解统一起来，别把三种情形分开背
- **对角化与二次型** → 模块 06、07 是命题热点，实对称矩阵正交对角化与惯性定理要能当定理直接用
- **冲刺速查** → `notes/` 里的 11 篇笔记按考点切分，适合考前两周每天过一两篇
