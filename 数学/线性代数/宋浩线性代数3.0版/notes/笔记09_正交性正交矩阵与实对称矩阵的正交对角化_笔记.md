# 正交性、正交矩阵与实对称矩阵的正交对角化

## 内积

### 内积的定义与写法

* **内积（inner product）**

    * > **定义**：设 $\alpha=(a_1,a_2,\cdots,a_n)^T$，$\beta=(b_1,b_2,\cdots,b_n)^T$，则 $(\alpha,\beta)=a_1b_1+a_2b_2+\cdots+a_nb_n$，即分量对应相乘再相加。

    * 列向量与行向量的算法完全一样，都是分量对应相乘再相加。

    * 例：$\alpha=(1,-2,2)^T$，$\beta=(2,2,-1)^T$，则 $(\alpha,\beta)=1\times2+(-2)\times2+2\times(-1)=2-4-2=-4$。

    * 消歧写法：两个都是列向量时内积写成 $\alpha^T\beta$，两个都是行向量时写成 $\alpha\beta^T$，两者都等于 $a_1b_1+a_2b_2+\cdots+a_nb_n$。

    * > **提示**：$(\alpha,\beta)$ 的括号天生有两读法，不是写法有毛病——同一个式子既可读成把 $A$ 按列切成分块矩阵 $A=[\alpha\ |\ \beta\ |\ \cdots]$，也可读成 $\alpha$ 与 $\beta$ 的内积：

    ```text
        [  a1   a2   a3  ...  an  ]
     A =[  a2'  a3'  a4' ...  a'n' ]      这一摞数按列切开
        [  a3'' a4'' a5''...  a'n'']
          |     |
          |     +-------------->  第 2 列，记作 beta
          +-------------------->  第 1 列，记作 alpha

        读法一：按列切块  ->   A = [ alpha | beta | ... ]
        读法二：按内积读  ->   (alpha, beta)
        同一对括号，断法两种
    ```

    * > **提示**：做题时不要只停留在口头的「对应相乘再相加」，把式子写成 $\alpha^T\beta$ 形式更不容易被扣分。

### 内积的四条运算性质

* **内积的运算性质**

    * 非负性：$(\alpha,\alpha)=a_1^2+a_2^2+\cdots+a_n^2\geq 0$。

    * 由非负性得 $(\alpha,\alpha)=0$ 的充要条件是 $\alpha$ 为零向量。

    * 对称性：$(\alpha,\beta)=(\beta,\alpha)$，因为对应相乘再相加时谁乘谁都一样。

    * 常数朝外提：$(k\alpha,\beta)=k(\alpha,\beta)$，两个常数一起提则 $(k\alpha,k\beta)=k^2(\alpha,\beta)$。

    * 加法可拆：$(\alpha_1+\alpha_2,\beta)=(\alpha_1,\beta)+(\alpha_2,\beta)$。

    * 加法可拆的验证：设 $\alpha_1=(a,b,c)^T$，$\alpha_2=(m,n,p)^T$，$\beta=(h,i,k)^T$，左边为 $(a+m)h+(b+n)i+(c+p)k$，右边为 $(ah+bi+ck)+(mh+ni+pk)$，逐项相等。

    * > **提示**：四条里最要紧的是非负性与加法可拆；常数朝外提在证 $\Vert k\alpha\Vert$ 以及拿 $k$ 当特征值倒推时还要再用一次。

## 向量的模与单位向量

### 模

* **向量的模（norm）**

    * > **定义**：$\Vert\alpha\Vert=\sqrt{x_1^2+x_2^2+\cdots+x_n^2}$，即向量的长度。

    * 与内积互通：$\Vert\alpha\Vert=\sqrt{(\alpha,\alpha)}$，$(\alpha,\alpha)=\Vert\alpha\Vert^2$。

    * 例：$(1,2,3)^T$ 的模为 $\sqrt{1+4+9}=\sqrt{14}$；$(-1,0,1)^T$ 的模为 $\sqrt{1+0+1}=\sqrt2$。

    * > **易错点**：向量的模在线性代数里写四根竖线 $\Vert\alpha\Vert$，不要与标量的模（两根竖线）写混。

* **模的三条性质**

    * 非负：$\Vert\alpha\Vert\geq 0$，它是根号，恒不为负。

    * $\Vert\alpha\Vert=0 \iff \alpha=0$，平方和为零则每一项都为零。

    * 数乘：$\Vert k\alpha\Vert=|k|\cdot\Vert\alpha\Vert$，推导为 $\sqrt{(k\alpha,k\alpha)}=\sqrt{k^2(\alpha,\alpha)}=\sqrt{k^2}\cdot\sqrt{(\alpha,\alpha)}=|k|\Vert\alpha\Vert$。

    * > **易错点**：结果里 $k$ 外面是绝对值 $|k|$ 而不是 $k$，根源是 $\sqrt{k^2}=|k|$。

### 单位向量与单位化

* **单位向量与单位化（unit vector, normalization）**

    * > **定义**：长度为 $1$ 的向量叫单位向量。

    * > **定义**：用模的倒数去乘一个向量把它化成单位向量，这个过程叫单位化，即 $\dfrac{1}{\Vert\alpha\Vert}\alpha$。

    * 例：把 $(1,2,3)^T$ 单位化得 $\dfrac{1}{\sqrt{14}}(1,2,3)^T=(1,2,3)^T/\sqrt{14}$。

### 三角不等式

* **三角不等式（triangle inequality）**

    * > **定义**：$\Vert\alpha+\beta\Vert\leq \Vert\alpha\Vert+\Vert\beta\Vert$。

    * 几何解释：$OA=\alpha$，$AC=\beta$，$OC=\alpha+\beta$，即把 $\alpha,\beta$ 首尾接起来的那条线，也是以它们为邻边的平行四边形对角线：

    ```text
                  C
                  ●
                 / \
            β   /   \   α
               /     \
              ●-------●
              O       A

        OA = α        从 O 指向 A
        AC = β        从 A 指向 C
        OC = α + β    从 O 指向 C，也是平行四边形对角线
    ```

    * 三角形两边之和大于第三边，故 $\Vert\alpha\Vert+\Vert\beta\Vert>\Vert\alpha+\beta\Vert$。

    * 取等号的情形：两向量同向、首尾接成一条直线时成立。

    ```text
        B ●············● A ··············● C
          ←---- β ----→      ←---- α ----→

        BC 是 β + α 首尾接成的整段
        长度正好等于 |β| + |α|  ⇒  等号成立
    ```

    * > **注意**：等号情形不必推式子去证；三角不等式与柯西-施瓦茨不等式考研几乎不用考。

## 正交与正交向量组

### 正交

* **正交（orthogonality）**

    * > **定义**：两个向量的内积等于零就叫正交，记作 $\alpha\perp\beta$；本质就是垂直，高维时才改叫正交。

    * 零向量与任意向量都正交。

    * 与自身正交的向量只能是零向量，因为 $(\alpha,\alpha)=0\iff\alpha=0$。

### 正交向量组

* **正交向量组（orthogonal vector set）**

    * > **定义**：一个向量组若两两正交，且其中不含零向量（每个向量都非零），就叫正交向量组。

    * 例：$\alpha_1=(2,0,0)^T$，$\alpha_2=(0,4,0)^T$，$\alpha_3=(0,0,7)^T$，三者非零且 $\alpha_1^T\alpha_2=2\times0+0\times4+0\times0=0$，故为正交向量组。

* **标准正交向量组（orthonormal vector set，又称单位正交向量组）**

    * > **定义**：既是正交向量组、每个向量又都是单位向量的向量组。

    * 例：$\varepsilon_1=(1,0,0)^T$，$\varepsilon_2=(0,1,0)^T$，$\varepsilon_3=(0,0,1)^T$。

### 正交向量组一定线性无关

* **定理：正交向量组一定线性无关**

    * 设 $\alpha_1,\dots,\alpha_s$ 为正交向量组，假设 $k_1\alpha_1+k_2\alpha_2+\cdots+k_s\alpha_s=0$。

    * 关键一步：两边同时与 $\alpha_1$ 做内积。

    * 用内积的线性性质展开：$k_1(\alpha_1,\alpha_1)+k_2(\alpha_2,\alpha_1)+\cdots+k_s(\alpha_s,\alpha_1)=0$（右边与零向量做内积为零）。

    * 用正交性化简：$\alpha_2,\dots,\alpha_s$ 与 $\alpha_1$ 内积全为零，只剩 $k_1(\alpha_1,\alpha_1)=0$。

    * 正交向量组的每个向量都非零，故 $(\alpha_1,\alpha_1)\ne 0$，乘积为零只能是 $k_1=0$。

    * 再依次与 $\alpha_2,\dots,\alpha_s$ 做内积，同理得 $k_2=0,\dots,k_s=0$，系数全零即线性无关。

* **正交与线性无关的强弱**

    * 正交的条件比线性无关更强：正交 $\Rightarrow$ 线性无关，线性无关 $\nRightarrow$ 正交。

    * 二维平面上的对应：线性相关 $\iff$ 一个向量是另一个向量的几倍 $\iff$ 两向量平行；不平行 $\iff$ 线性无关。

    * 例如 $\alpha+2\beta=0$ 即 $\alpha=-2\beta$，方向相反、长度是 $\beta$ 的两倍，是线性相关；$\alpha-\frac12\beta=0$ 即 $\alpha=\frac12\beta$，也是线性相关。

    * 垂直的一对必然线性无关，但线性无关的一对只说明不平行，不说明垂直，所以不一定正交。

## 施密特正交化

### 三个公式与系数取法

* **施密特正交化（Schmidt orthogonalization）**

    * > **定义**：把一个已知的线性无关向量组，替换成一个与之等价、且两两正交的向量组。

    * 已知 $\alpha_1,\alpha_2,\alpha_3$ 线性无关，求与之等价的正交向量组 $\beta_1,\beta_2,\beta_3$。

    * 之所以要这么折腾，是因为正交的条件比线性无关强，不能随便拿一个线性无关的向量组顶上。

    * 三个公式：$\beta_1=\alpha_1$；$\beta_2=\alpha_2-k_1\beta_1$；$\beta_3=\alpha_3-k_1\beta_1-k_2\beta_2$。

    * 记法规律：右边那个 $\alpha_i$ 的下标与左边这个 $\beta_i$ 一模一样；$\beta$ 的下标从 $1$ 开始依次往上数，顺序不乱。

* **系数 $k_i$ 的取法**

    * 通用写法是「被减的那个 $\alpha$ 撞上已得的 $\beta$」，分母为 $\beta$ 与自身的内积，分子为 $\alpha$ 与 $\beta$ 的内积。

    * 例：$\alpha_1=(0,1,1)^T$，$\alpha_2=(1,0,1)^T$，$\alpha_3=(1,1,0)^T$。

    * 求 $\beta_1=\alpha_1=(0,1,1)^T$ 直接得到；$\beta_1^T\beta_1=0^2+1^2+1^2=2$，$\alpha_2^T\beta_1=1\times0+0\times1+1\times1=1$，故 $k_1=\frac12$，$\beta_2=(1,0,1)^T-\frac12(0,1,1)^T=(1,-\frac12,\frac12)^T$。

    * 求 $\beta_3$ 时 $k_1$ 要换成 $\alpha_3$ 去撞 $\beta_1$：$\alpha_3^T\beta_1=1\times0+1\times1+0\times1=1$，仍得 $k_1=\frac12$。

    * $k_2$ 由 $\beta_2^T\beta_2=1+\frac14+\frac14=\frac32$ 与 $\alpha_3^T\beta_2=1\times1+1\times(-\frac12)+0\times\frac12=\frac12$ 得 $k_2=\frac{1/2}{3/2}=\frac13$。

    * 结果 $\beta_3=\alpha_3-\frac12\beta_1-\frac13\beta_2=(1,1,0)^T-\frac12(0,1,1)^T-\frac13(1,-\frac12,\frac12)^T=(\frac23,\frac23,-\frac23)^T$。

    * > **注意**：$\alpha_i$ 常常不是凭空给定的，而是自己先求出来的特征向量。

### 完整解题步骤

* **施密特正交化的完整流程**

    ```text
        已知矩阵 A
            │
            ├─→ ① 求特征值 λ
            │
            ├─→ ② 求特征向量 α₁, α₂, α₃   这一步保证它们线性无关
            │
            ├─→ ③ 把特征向量施密特正交化   → β₁, β₂, β₃
            │
            └─→ ④ 再单位化             → 标准正交向量组
    ```

    * 第四步没有难度，就是用模的倒数乘以该向量。

    * > **注意**：只做①②③不算完，真实考题里那三个 $\alpha_i$ 往往要自己一步步求出来。

## 求与若干向量都正交的向量

* **解法：把正交条件翻译成齐次线性方程组**

    * > **定义**：设所求向量为 $\gamma=(x_1,x_2,x_3)^T$，则 $\gamma\perp\alpha\iff\alpha^T\gamma=0\iff\alpha_1x_1+\alpha_2x_2+\alpha_3x_3=0$。

    * 与 $k$ 个向量都正交，就得到 $k$ 个内积为零的方程；未知量是 $\gamma$ 的各分量，把这些向量的分量按行填进去即为系数矩阵。

    * 四步走：把系数矩阵化成行最简形 → 找没有主元的那一列定出自由未知量 → 给自由未知量赋值（如 $x_3=c$）并回代解出其余分量 → 代回读出 $\gamma$ 的基本解。

    * > **提示**：这一类题的入手点是「翻译」而不是「构造」——「和这两个向量都正交」翻译过来就是两行系数、一行一个内积为零，翻译完就是熟悉的齐次线性方程组。

    * > **易错点**：题目要求所求向量为非零向量，赋的字母必须不为零，平凡解（$c=0$，$\gamma=0$）要扔掉。

## 正交矩阵

### 定义与逆矩阵

* **正交矩阵（orthogonal matrix）**

    * > **定义**：设 $A$ 是 $n$ 阶方阵，若 $AA^T=E$，则称 $A$ 为正交矩阵。

    * 由可逆矩阵性质 $AB=E\Rightarrow B=A^{-1}$，得 $A$ 是正交矩阵 $\iff A^{-1}=A^T$。

    * 这个等价关系保证 $AA^T=E$ 成立时 $A^TA=E$ 也成立，因为 $A^TA=A^{-1}A^{-1}=(A^{-1})^2=E$。

    * 反过来证某个矩阵正交，可把 $A^{-1}$ 朝定义式里带，看 $A^{-1}(A^{-1})^T$ 是否为 $E$。

### 行列式与特征值

* **行列式**

    * 由 $AA^T=E$ 两边取行列式，用「行列式转置值不变」得 $|A|\cdot|A^T|=|A|^2=|E|=1$，故 $|A|=\pm1$。

    * > **注意**：正交矩阵的行列式是 $\pm1$ 而不一定是 $1$，正负要看具体情况。

* **特征值**

    * 若 $\lambda$ 是正交矩阵 $A$ 的特征根，则 $\frac1\lambda$ 也是 $A$ 的特征根。

    * 推导：由 $A\alpha=\lambda\alpha$ 两边同乘 $A^{-1}$ 得 $\alpha=\lambda A^{-1}\alpha$，即 $\frac1\lambda\alpha=A^{-1}\alpha=A^T\alpha$。

    * 因 $A^T$ 与 $A$ 有相同的特征根，$\frac1\lambda$ 就是 $A$ 的特征根。

    * > **易错点**：把 $\lambda$ 放到分母前必须先说清 $\lambda\ne0$。依据是 $|A|=\pm1$，而行列式等于所有特征值的**相乘**（不是相加），既然相乘为 $\pm1$，所有特征值都不为零，取倒数合法。

* **例：$A$、$B$ 正交且 $|AB|=-1$ 时求 $|A+B|$**

    * > **易错点**：$|A+B|\ne|A|+|B|$，行列式对加法不可拆。

    * 把 $A$ 右乘、$B$ 左乘各一个单位阵，并把它们换成有用的东西：$B^T(A+B)A^T=B^TAA^T+B^TBA^T=B^TE+EA^T=B^T+A^T$。

    * 右边：$|B^T+A^T|=|(A+B)^T|=|A+B|$。

    * 左边：$|B^T||A^T||A+B|=|B||A||A+B|=|AB||A+B|=-|A+B|$。

    * 两边并置得 $-|A+B|=|A+B|$，即 $2|A+B|=0$，故 $|A+B|=0$。

    * > **提示**：往矩阵上凑单位阵 $E$、再从左右把因子提出来的思路在行列式题里通用。

### 运算是封闭的

* **转置、逆与伴随仍正交**

    * $A^T$ 正交：把 $A^T$ 带进定义式得 $A^T(A^T)^T=A^TA=E$。

    * $A^{-1}$ 正交：用 $(A^{-1})^T=(A^T)^{-1}$（转置与求逆可交换顺序），得 $A^{-1}(A^{-1})^T=A^{-1}(A^T)^{-1}=A^{-1}A^{-1}=E$。

    * $A^*$ 正交：用「先取逆再转置等于先转置再求逆」，逆、转置、$E$ 三者顺序可任意交换，带入 $A^*(A^*)^T=E$ 成立。

    * 伴随公式：$A^{-1}=\frac{1}{|A|}A^*$，即 $A^*=|A|A^{-1}$；特别地 $E^*=|E|E^{-1}=E$。

* **乘积仍正交**

    * $A$、$B$ 都是正交矩阵则 $AB$ 也是：$(AB)^T=B^TA^T=B^{-1}A^{-1}=(AB)^{-1}$。

### 正交矩阵保持什么

* **保持内积与长度**

    * 内积被保持：$(A\alpha,A\beta)=\alpha^TA^TA\beta=\alpha^T\beta=(\alpha,\beta)$，用到 $A^TA=E$ 与内积的转置写法。

    * 长度被保持：$\Vert A\alpha\Vert^2=(A\alpha)^T(A\alpha)=\alpha^TA^TA\alpha=\alpha^T\alpha=\Vert\alpha\Vert^2$，故 $\Vert A\alpha\Vert=\Vert\alpha\Vert$。

    * 内积不变则长度不变，长度不变则夹角不变；正交变换只把向量搬到新位置，相互位置关系一点不动。

* **行向量组与列向量组**

    * 把 $A$ 按列分块成 $A=(\alpha_1,\alpha_2,\cdots,\alpha_N)$，则 $A^TA=E$ 展开为

    $$
    \begin{bmatrix} \alpha_1^T \\ \alpha_2^T \\ \vdots \\ \alpha_N^T \end{bmatrix}
    \begin{bmatrix} \alpha_1 & \alpha_2 & \cdots & \alpha_N \end{bmatrix}
    = \begin{bmatrix} 1 & 0 & \cdots & 0 \\ 0 & 1 & \cdots & 0 \\ \vdots & \vdots & & \vdots \\ 0 & 0 & \cdots & 1 \end{bmatrix} = E
    $$

    * 看主对角线：$\alpha_i^T\alpha_i=1$，即 $\alpha_i$ 与自身的内积为 $1$，模为 $1$，是单位向量。

    * 看主对角线以外：$i\ne j$ 时 $\alpha_i^T\alpha_j=0$，即两两正交。

    * 结论：正交矩阵的行向量组与列向量组都是单位正交向量组。

## 正交相似与实对称矩阵的对角化

### 正交相似

* **相似与正交相似**

    * 相似：存在可逆矩阵 $P$ 使 $P^{-1}AP=B$。

    * > **定义**：正交相似：存在一个正交矩阵 $Q$ 使 $Q^{-1}AQ=B$；因 $Q^{-1}=Q^T$，该式也可写成 $Q^TAQ=B$。

    * 三者关系是单向链条：

    ```text
                正交相似
          （存在正交矩阵 Q，使 Q⁻¹AQ = B）
                      │
                      │  要求更强，范围更小
                      ▼
                    相似
          （存在可逆矩阵 P，使 P⁻¹AP = B）
                      │
                      │  要求更松，范围更大
                      ▼
                    等价
          （存在可逆矩阵 P、Q，使 PAQ = B）
    ```

    * 正交相似一定推出相似，相似一定推出等价，不能倒着走。

### 实对称矩阵的三条性质

* **特征值与特征向量**

    * > **性质**：实对称矩阵的特征值一定是实数，特征向量一定是实向量；普通方阵的特征值不一定是实数。

* **不同特征值对应的特征向量**

    * > **性质**：实对称矩阵不同特征值对应的特征向量一定正交。

    * 对照：普通方阵不同特征值对应的特征向量只保证线性无关。

    | 矩阵类型 | 特征值 | 不同特征值对应的特征向量 |
    | :--- | :--- | :--- |
    | 普通方阵 | 不一定是实数 | 线性无关 |
    | 实对称矩阵 | 一定是实数，特征向量一定是实向量 | 正交（线性无关自然也成立） |

    * 两条结论不能串台：普通方阵给的是线性无关，实对称矩阵给的是正交。

* **重根的线性无关特征向量个数**

    * > **性质**：实对称矩阵的任意一个 $s$ 重特征根，对应的线性无关特征向量个数恰好就是 $s$ 个。

    * 由此直接得到实对称矩阵必有 $n$ 个线性无关的特征向量；方阵可相似对角化的重要条件就是有 $n$ 个线性无关特征向量。

    * > **结论**：实对称矩阵一定可以相似对角化，绝不能答「不能相似对角化」。

    * 更强的结论：实对称矩阵可以正交相似于对角形，即能找到一个正交矩阵 $P$ 使 $P^{-1}AP$ 为对角形。

### 求正交矩阵的流程

* **审题：要可逆矩阵还是正交矩阵**

    * 若题目求可逆矩阵 $P$ 使 $P^{-1}AP$ 为对角形，解题过程与相似对角化的题型完全一样：找出 $n$ 个线性无关特征向量，每个做成列构成 $P$。

    * 求正交矩阵 $Q$ 使 $Q^{-1}AQ$ 为对角形才是正交相似独有的题型，流程是正交化 → 单位化 → 按列做成矩阵 $Q$。

    * 两步的计算量都很大：一是求出所有特征值，二是对每个特征值求出它对应的特征向量的基础解系。

    * > **提示**：不同特征值对应的特征向量已经正交，不需要做正交化；同一个特征值对应的特征向量若不相互正交，才需要施密特正交化后单位化。

* **两类向量的分工**

    * 不同特征值之间：跳过正交化，直接单位化。

    * 同一特征值内部：先口算内积——对应分量相乘再相加等于零就是已经正交，直接单位化；不等于零才做施密特正交化。

    * > **注意**：不要把施密特正交化无差别地当成「使命的转化」去用，两个向量尚可，三个向量计算量就很大。

### 三类题型

* **三个互异的单根**

    * 例 $A=\begin{pmatrix}2&-2&0\\-2&1&-2\\0&-2&0\end{pmatrix}$，展开得 $|\lambda E-A|=(\lambda-1)(\lambda-4)(\lambda+2)=0$。

    * 三个互异单根：$\lambda_1=1$，$\lambda_2=4$，$\lambda_3=-2$。

    * 基础解系：$\alpha_1=(2,1,-2)^T$，$\alpha_2=(2,-2,1)^T$，$\alpha_3=(1,2,2)^T$。

    * 两两内积均为零：$\alpha_1^T\alpha_2=4-2-2=0$，$\alpha_1^T\alpha_3=2+2-4=0$，$\alpha_2^T\alpha_3=2-4+2=0$，故天然正交，不做施密特正交化。

    * 三个向量的模都是 $\sqrt9=3$，只需单位化得 $\gamma_1=(\frac23,\frac13,-\frac23)^T$，$\gamma_2=(\frac23,-\frac23,\frac13)^T$，$\gamma_3=(\frac13,\frac23,\frac23)^T$。

    * 按列拼成 $Q=\begin{pmatrix}\frac23&\frac23&\frac13\\\frac13&-\frac23&\frac23\\-\frac23&\frac13&\frac23\end{pmatrix}$，则 $Q^{-1}AQ=\mathrm{diag}(1,4,-2)$。

    * > **提示**：这三列的顺序不是固定的，可以任意调整，只需与对角线上特征根的顺序保持一致。

* **一个单根加一个二重根**

    * 例 $A=\begin{pmatrix}3&-3&-3\\-3&3&3\\-3&3&3\end{pmatrix}$，用一列的相同数消去后得 $|\lambda E-A|=\lambda^2(\lambda-9)=0$。

    * $\lambda_1=\lambda_2=0$，$\lambda_3=9$。

    * 基础解系：$\lambda=0$ 对应 $\alpha_1=(1,1,0)^T$，$\alpha_2=(\frac12,0,\frac12)^T$；$\lambda=9$ 对应 $\alpha_3=(-1,1,1)^T$。

    * 不同特征值之间已正交：$\alpha_1^T\alpha_3=-1+1+0=0$，$\alpha_2^T\alpha_3=-\frac12+0+\frac12=0$，这两个直接单位化即可。

    * 同一特征值内部不正交：$\alpha_1^T\alpha_2=1\cdot\frac12+1\cdot0+0\cdot\frac12=\frac12\ne0$，必须正交化。

    * 正交化的「死算」形式：$\beta_1=\alpha_1$，$\beta_2=\alpha_2-\dfrac{\beta_1^T\alpha_2}{\beta_1^T\beta_1}\beta_1$，其中系数 $=\frac{1/2}{2}=\frac14$，故 $\beta_2=(\frac12,0,\frac12)^T-\frac14(1,1,0)^T=(\frac14,-\frac14,\frac12)^T$。

    * 单位化：$\gamma_1=\frac1{\sqrt2}(1,1,0)^T=(\frac{\sqrt2}{2},\frac{\sqrt2}{2},0)^T$；$|\beta_2|=\sqrt{\frac1{16}+\frac1{16}+\frac14}=\frac{\sqrt6}{4}$，$\gamma_2=(\frac{\sqrt6}{6},-\frac{\sqrt6}{6},\frac{\sqrt6}{3})^T$。

    * $\gamma_3$ 不用正交化只单位化，$|\alpha_3|=\sqrt3$，$\gamma_3=\frac1{\sqrt3}(-1,1,1)^T=(-\frac{\sqrt3}{3},\frac{\sqrt3}{3},\frac{\sqrt3}{3})^T$。

    * 按列拼成 $Q=(\gamma_1\ \gamma_2\ \gamma_3)$，$Q^{-1}AQ=\mathrm{diag}(0,0,9)$，对角元按特征根顺序 $0,0,9$ 搬过去。

    * > **提示**：单根配二重根是期末与考研都比较喜欢考的题型。

    * > **注意**：同一特征值对应的特征向量也可能本就正交，所以不必一律正交化；即使已经正交也硬去正交化，会白白浪费很多时间。

* **三个重根**

    * 例 $\lambda_1=\lambda_2=\lambda_3=1$，特征向量的基础解系一定是三个。

    * 先判断三者是否已成正交关系（其中一个与另外两个都正交的情况也存在），能判就判。

    * 若三者不成正交关系，则三个一起做施密特正交化得 $\beta_1,\beta_2,\beta_3$，再统一单位化得 $\gamma_1,\gamma_2,\gamma_3$，按列拼成 $Q$。

    * 这一类相对前两类出现较少，正交化过程相对繁琐。

### 全流程主干

* **正交相似对角化的主干**

    * 先求出所有特征值，再对每个特征值求出特征向量的基础解系。

    * 不同特征值之间不碰正交化，只在同一个特征值内部判断要不要正交化。

    * 最后统一单位化，按列拼成 $Q$，特征根按顺序搬到对角线上。

    * > **提示**：拿到题先用笔把 $a_{12}$ 与 $a_{21}$、$a_{13}$ 与 $a_{31}$、$a_{23}$ 与 $a_{32}$ 这些对称位置描出来确认是实对称矩阵，再把题面里「正交矩阵」四个字勾出来。
