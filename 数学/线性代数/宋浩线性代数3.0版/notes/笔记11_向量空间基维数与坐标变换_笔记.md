# 向量空间、基、维数与坐标变换

## 向量空间的判定

### 三个条件与封闭性

    * **向量空间（vector space）**

        * > **定义**：设 $V$ 是由 $n$ 维向量组成的集合，$\mathbb{R}$ 为实数域。若 $V$ 是非空的、$V$ 对加法是封闭的、$V$ 对数乘是封闭的，就称 $V$ 是一个向量空间。

        * 三个条件是「与」的关系，任何一条不成立就直接否掉。

        * 封闭的含义：集合里边的两个向量相加还在这个集合里边；集合里边的向量 $\alpha$ 与任给的实数 $k$ 的数乘 $k\alpha$ 还在这个集合里边。出去了，就不叫封闭。

        * > **注意**：封闭性是这一部分唯一的门槛；拿到一个集合，第一个动作永远是先判非空——它最便宜，也最容易找到反例。

    * **验证非空的办法**

        * 取零向量。零向量是 $n$ 维向量，它只要满足集合的门槛就一定在里面。

        * > **提示**：「各个分量随便取实数」这个判断，后面判子空间时还要再用一次。

```text
候选集合 V
│
├─ 条件一：非空     --否-->  不是向量空间
├─ 条件二：加法封闭 --否-->  不是向量空间
├─ 条件三：数乘封闭 --否-->  不是向量空间
│
└─ 三关全过         --是-->  V 是向量空间
```

### 全体 n 维向量组成的集合

    * **$\mathbb{R}^n$**

        * > **定义**：$n$ 维向量空间就是全体 $n$ 维向量组成的集合，记作 $\mathbb{R}^n$。

        * 形如 $\alpha=(a_1,a_2,\dots,a_n)^T$ 的向量，$n$ 个分量都可以随便取实数。

        * $n$ 指维数、$n$ 个分量；一个生成向量空间用的向量组有几个向量是另一回事，随便多少个都行。

### 分量被钉死的两个集合

    * **$V_1$（第一个分量为零）**

        * 非空：零向量 $\mathbf{0}=(0,0,\dots,0)^T$ 落在 $V_1$ 里。

        * 加法封闭：$\alpha+\beta=(0,\ a_2+b_2,\ \dots,\ a_n+b_n)^T$，第一分量是 $0+0=0$ 仍为零，其余分量后面本就随便取。

        * 数乘封闭：$k\alpha=(0,\ ka_2,\ \dots,\ ka_n)^T$，第一分量是 $0\cdot k=0$ 仍为零，后面照样随便取。

        * 三条全过，$V_1$ 是向量空间。

    * **$V_2$（第一个分量为一）**

        * 非空：取 $\alpha=(1,1,\dots,1)^T$ 就在 $V_2$ 里。

        * 加法不封闭：$\alpha+\beta=(2,\ a_2+b_2,\ \dots,\ a_n+b_n)^T$，第一分量是 $2$，与 $V_2$ 要求的 $1$ 对不上。

        * 一条不成立就够了，$V_2$ 不是向量空间。

| 条件 | $V_1=\{(0,a_2,\dots,a_n)^T\}$ | $V_2=\{(1,a_2,\dots,a_n)^T\}$ |
| :--- | :--- | :--- |
| 非空 | 零向量落在里面 | $(1,1,\dots,1)^T$ 落在里面 |
| 加法封闭 | $0+0=0$，封闭 | $1+1=2\neq 1$，不封闭 |
| 数乘封闭 | $0\cdot k=0$，封闭 | 一条已否，不必再验 |
| 结论 | 是向量空间 | 不是向量空间 |

> **易错点**：零和一这两个集合长得几乎一样，差的恰恰是封闭性最敏感的那一格。碰到「某个分量被钉死」的集合，先别急着说它像 $\mathbb{R}^n$，先拿两个元素加起来，看被钉死的那一格会不会跑掉。

## 方程组解集

### 齐次与非齐次

    * **齐次线性方程组 $AX=\mathbf{0}$ 的解集 $S_1$**

        * 非空：取 $X=\mathbf{0}$，则 $A\cdot\mathbf{0}=\mathbf{0}$，零解属于 $S_1$。

        * 加法封闭：设 $A\alpha=\mathbf{0}$、$A\beta=\mathbf{0}$，则 $A(\alpha+\beta)=A\alpha+A\beta=\mathbf{0}+\mathbf{0}=\mathbf{0}$。

        * 数乘封闭：设 $k\in\mathbb{R}$，则 $A(k\alpha)=kA\alpha=k\cdot\mathbf{0}=\mathbf{0}$。

        * 三条全过，$S_1$ 是向量空间。

    * **非齐次线性方程组 $AX=b$ 的解集 $S_2$**

        * 设 $A\alpha=b$、$A\beta=b$，则 $A(\alpha+\beta)=A\alpha+A\beta=b+b=2b$。

        * 集合要求的是 $AX=b$，算出来却是 $2b$，等不上，所以 $S_2$ 对加法不封闭，不是向量空间。

        * $b$ 不等于零，正因为 $b\neq \mathbf{0}$，$2b$ 才真的不等于 $b$。

```text
齐次   Aα = 0,  Aβ = 0
       A(α+β) = Aα + Aβ = 0 + 0 = 0     ->  封闭
       A(kα)  = kAα     = k·0   = 0     ->  封闭

非齐次 Aα = b,  Aβ = b,  b 不等于 0
       A(α+β) = Aα + Aβ = b + b = 2b    ->  2b 不等于 b, 不封闭
```

> **结论**：两边用的完全是同一套运算，唯一的差别在右端项——齐次那儿的零向量，加多少都还是零；非齐次那个 $b$，加一次就翻倍了。

## 向量组生成的向量空间

### 定义与验证

    * **由向量组生成的向量空间 $V(\alpha_1,\dots,\alpha_s)$**

        * > **定义**：$V(\alpha_1,\alpha_2,\dots,\alpha_s)=\{k_1\alpha_1+k_2\alpha_2+\dots+k_s\alpha_s \mid k_1,\dots,k_s\in\mathbb{R}\}$。

        * 取两个已知向量时记作 $V=\{\lambda\alpha+\mu\beta \mid \lambda,\mu\in\mathbb{R}\}$。

        * 非空：取零向量（$\lambda=\mu=0$ 时就是零向量）。

        * 加法：设 $\gamma_1=k_1\alpha+k_2\beta$、$\gamma_2=k_3\alpha+k_4\beta$，则 $\gamma_1+\gamma_2=(k_1+k_3)\alpha+(k_2+k_4)\beta$，两个系数各自做加法后仍是两个实数，仍是 $\alpha,\beta$ 的线性组合。

        * 数乘：$k\gamma_1=(kk_1)\alpha+(kk_2)\beta$，两个系数 $kk_1,kk_2$ 是实数，仍是 $\alpha,\beta$ 的线性组合。

        * 推广后同样成立：加起来系数还是那些系数，乘一个实数系数也还是那些系数，怎么折腾都跑不出这个形式。

    * **生成向量空间里的向量组**

        * 上面那套验证从头到尾只用到「能写成这组向量的线性组合」，一次都没用过「线性无关」，所以线性相关的也行、线性无关的也行。

        * > **提示**：生成向量空间里的向量组**不需要线性无关**；线性无关是讨论基的时候才登场的东西，别提前用。

    * **等价向量组生成的同一空间**

        * > **结论**：两个向量组如果等价（可以相互线性表示），那么它们生成的向量空间是相同的。

## 子空间

### 判定与例子

    * **子空间（subspace）**

        * > **定义**：设 $V$ 是向量空间，$W$ 是 $V$ 的非空子集，并且对于 $V$ 里定义的加法和数乘这两种运算都是封闭的，那么 $W$ 就叫 $V$ 的子空间。

        * 等价的说法：$V_1$、$V_2$ 都是向量空间且 $V_2$ 包含于 $V_1$，就称 $V_2$ 是 $V_1$ 的子空间。

    * **例子**

        * 第一个分量是零的 $V_1$ 包含于 $\mathbb{R}^n$：$\mathbb{R}^n$ 里所有分量都可以随便取，光是第一个分量取零的这一类它就全装得下，所以 $V_1$ 是 $\mathbb{R}^n$ 的子空间。

        * 只包含零向量的子集叫零子空间。

    * > **提示**：封闭性判断、生成向量空间、子空间都是后面基、维数、坐标、过渡矩阵的语言和工具，先把词认熟。

## 基与维数

### 基的两条要求

    * **一组基（basis）**

        * > **定义**：设 $V$ 是一个向量空间，$\alpha_1,\alpha_2,\dots,\alpha_r$ 满足两个条件——这 $r$ 个向量线性无关，且 $V$ 中任意一个向量都可以由这个向量组线性表示——那么这个向量组就叫 $V$ 的一组基。

        * 这两条要求与极大线性无关组的定义非常接近：一组基其实就是该向量组的极大线性无关组。

        * 名字里「一组」要留个心眼：$\alpha_1,\dots,\alpha_r$ **不是唯一的**，这边是 $V$ 的一组基，那边也可能是 $V$ 的一组基。

        * 高数里记作 $i,j,k$ 的 $(1,0,0),(0,1,0),(0,0,1)$ 是 $\mathbb{R}^3$ 最常用的一组基，但并不是唯一的。

### 维数

    * **维数（dimension，dim）**

        * > **定义**：一组基里含向量的个数就叫向量空间的维数，记作 $\dim V=r$，$V$ 就叫 $r$ 维向量空间。

        * 维数就是极大线性无关组所含向量的个数，也就是向量组的秩——维数和秩在这儿是同一个数。

        * 基可以换、可以挑，维数却永远不变。

        * 边界：$\dim V=0$ 的零空间（里面只有零向量）**没有基**，基至少得有一个非零向量撑在那里。

        * > **易错点**：常见手忙脚乱是把「基不唯一」看成了「维数也不唯一」。不唯一的是基这个具体的一组东西，唯一的是它背后那个数字。

### 找基的固定套路

    * **凑够维数且线性无关**

        * 已知 $V$ 是 $r$ 维的，那么只要 $\alpha_1,\dots,\alpha_r$ 是 $r$ 个线性无关的向量，它就是 $V$ 的一组基。

        * 证明：$r$ 维空间里 $r+1$ 个向量必然线性相关，多的那个能由前面这 $r$ 个线性表示出来，第二条要求自动满足。

        * > **结论**：任何一个 $r$ 个线性无关的向量组，都是 $r$ 维向量空间的一组基。

    * **典型例子的基与维数**

        * 对象：$\mathbb{R}^n$ 中所有形如 $(0,a_2,\dots,a_n)$ 的向量组成的集合。

        * 候选基：$\beta_1=(0,1,0,\dots,0)^T,\ \beta_2=(0,0,1,\dots,0)^T,\ \dots,\ \beta_{n-1}=(0,0,\dots,0,1)^T$，共 $n-1$ 个。

        * 线性无关：每个向量在自己那个非零坐标上占着 1，其它位置全是 0，谁也化不成别人的线性组合。

        * 能表示一切：$(0,a_2,\dots,a_n)=a_2\beta_1+a_3\beta_2+\dots+a_n\beta_{n-1}$。

        * 维数为 $n-1$。

## 由向量组确定基与维数

### 两种情形

    * **$\alpha_1,\dots,\alpha_s$ 生成的向量空间 $L$**

        * 这个向量组可能线性相关也可能线性无关，两种情况要分开处理。

| $\alpha_1,\dots,\alpha_s$ 的情形 | $L$ 的一组基 | $\dim L$ |
| :--- | :--- | :--- |
| 线性无关 | 它本身 $\alpha_1,\dots,\alpha_s$ | $s$ |
| 线性相关 | 任取它的一个极大线性无关组 $\alpha_1,\dots,\alpha_r$ | $r$ |

    * **线性相关时的结论**

        * 秩的定义就是极大线性无关组所含向量的个数，所以 $\dim L=R(\alpha_1,\dots,\alpha_s)=r$。

        * > **结论**：用 $\alpha_1,\dots,\alpha_s$ 的所有线性组合描述 $L$ 与只用 $\alpha_1,\dots,\alpha_r$ 描述的是同一个空间，后面 $s-r$ 个向量「白给」，能被前面 $r$ 个表示出来，拿掉不影响结果。

    * **省事的统一办法**

        * 不管线性相关与否，直接用下面只做初等行变换的办法挑出极大线性无关组。

### 初等行变换挑基

    * **列排成矩阵，只做初等行变换**

        * 把向量按列排成矩阵，只做初等行变换化成行最简形。

        * 行最简形里非零行的首非零元（这些 $1$）所在的列，对应的就是原矩阵里那一组极大线性无关向量。

        * 能这么干的原因：初等行变换是由可逆矩阵左乘得到的，把列向量整体换了一套基来描述，但列与列之间的线性相关关系原封不动，所以行最简形里第几列冒出主元，第几个原向量就必在该极大线性无关组里。

```text
   α1 α2 α3 α4  作列排成 3 行 4 列
                |
   只做初等行变换, 不做列变换
                |
   非零行的首非零元
   落在第 1、2、4 列
                |
   取回原矩阵的第 1、2、4 列
                |
   {α1, α2, α4} 就是
   极大线性无关组 = 一组基
                |
                  dim L = 3
```

    * > **易错点**：行变换不要和列变换混着做。只做行变换时列的编号稳定、可以回头对回原向量；一旦掺了列变换，编号就乱套了，回头取列必然取错。

### 齐次方程组的基与维数

    * **基础解系就是一组基**

        * 基础解系的定义就是解向量的极大线性无关组，而一组基又正好等于极大线性无关组，两个定义一撞，基础解系就是一组基。

        * 维数就等于基础解系里解的个数，即 $n-r$。

    * **求解流程**

        * 把 $A$ 化成行最简形，非零行的首非零元（这些 $1$）对应的 $x$ 留在左边，其余的 $x$ 挪到右边。

        * 自由未知量分别取基本单位向量，依次解出基础解系。

```text
  A  --行-->  [ 1  0  0 | -1/2 ]
               [ 0  1  0 | -1/2 ]
  |
  |  非零行首非零元为 1 的列是 x1, x2
  |  其余的 x 挪到右边, 自由未知量是 x3, x4
  |
  |   x3 = 1, x4 = 0  =>  η1 = ( 0, 0, 1, 0 )
  |   x3 = 0, x4 = 1  =>  η2 = ( 1/2, 1/2, 0, 1 )
  |
  |   基础解系 {η1, η2} 也就是一组基
  |   dim = n - r = 4 - 2 = 2
  v
```

    * > **结论**：$Ax=0$ 的解空间，一组基取基础解系，维数是 $n-r$，即未知量个数减去系数矩阵的秩。

## 坐标

### 坐标的定义

    * **坐标（coordinate）**

        * > **定义**：给定一组基 $\xi_1,\xi_2,\dots,\xi_r$，向量 $\alpha$ 由这组基线性表示的那组系数，就叫 $\alpha$ 在这组基下的坐标：$\alpha=k_1\xi_1+\dots+k_r\xi_r \Longrightarrow [\alpha]_\xi=(k_1,k_2,\dots,k_r)^T$。

        * 二维平面上向量 $(1,2,3)$ 的坐标是 $(1,2,3)$，这有个前提：基取成 $\{(1,0,0),(0,1,0),(0,0,1)\}$，直接读分量就是系数。

        * 坐标要根据这组基发生变化，基一换，坐标就跟着变，坐标不是一成不变的。

        * > **易错点**：坐标不是向量自身的属性，它是「向量 + 基」这一对东西合起来才有的属性。拿向量在标准基下的坐标去回答「在某组基下的坐标」，全错。

    * **标准正交基（orthonormal basis）**

        * 一组基如果两两正交并且每个向量都是单位向量，就叫标准正交基，也就是标准正交向量组。

### 换基后坐标的变化

    * **同一个向量的两组坐标**

        * 向量取 $\alpha=(4,2,-3)^T$，换基后坐标就变。

| 选用的基 | 向量 $\alpha=(4,2,-3)^T$ 的坐标 |
| :--- | :--- |
| $(1,0,0),\ (0,1,0),\ (0,0,1)$ | $(4, 2, -3)^T$ |
| $(1,0,0),\ (1,1,0),\ (1,1,1)$ | $(2, 5, -3)^T$ |

    * **逐行往下解系数**

        * 设基为 $\xi_1=(1,0,0)$、$\xi_2=(1,1,0)$、$\xi_3=(1,1,1)$，系数是 $k_1,k_2,k_3$。

        * 第三行已达 $3$，故 $k_3=-3$。

        * 第二行要为 $2$，而 $k_3$ 已贡献 $-3$，故 $k_2=5$（$5-3=2$）。

        * 第一行要为 $4$，故 $k_1=2$（$2+5-3=4$）。

### 证基与求坐标合做

    * **在 $R^3$ 中证基并求坐标**

        * 已知 $\beta=(1,1,1)^T$，要证 $\xi_1,\xi_2,\xi_3$ 是 $R^3$ 的一组基，并求 $\beta$ 在这组基下的坐标。

        * 证法一：$R^3$ 是三维空间，只要三个向量的行列式不等于零，就是线性无关，从而是一组基。

        * 证法二（更省事）：求 $\beta$ 的坐标等于解非齐次线性方程组 $\beta=k_1\xi_1+k_2\xi_2+k_3\xi_3$，把三个向量作列排成系数矩阵、右端放上 $\beta$，只用初等行变换化到左边成为单位阵。

        * 化成行最简形后得 $\begin{bmatrix}1&0&0&-\frac{1}{6}\\0&1&0&\frac{5}{6}\\0&0&1&-\frac{2}{3}\end{bmatrix}$，左边是单位阵说明线性无关。

        * 坐标就是增广部分那三个数：$-\frac{1}{6},\ \frac{5}{6},\ -\frac{2}{3}$。

    * > **结论**：一组基靠「线性无关 + 能表示一切」定死，维数数的是基里向量有几个且等于秩，坐标是拿一组基把向量拆开后露出来的那串系数；基换了坐标就换，维数始终是那个唯一的数。

## 过渡矩阵

### 定义与位置

    * **过渡矩阵（transition matrix）**

        * 记号 $[\alpha_1\ \alpha_2\ \cdots\ \alpha_n]$ 表示把这 $n$ 个基向量按列排成一个 $n$ 阶方阵。

        * > **定义**：设 $\alpha_1,\dots,\alpha_n$ 与 $\beta_1,\dots,\beta_n$ 是 $n$ 维向量空间 $V$ 的两组基，满足 $[\alpha_1\ \alpha_2\ \cdots\ \alpha_n]C=[\beta_1\ \beta_2\ \cdots\ \beta_n]$ 的矩阵 $C$，就是由 $\alpha$ 组基到 $\beta$ 组基的过渡矩阵。

        * 记 $A=[\alpha_1\ \alpha_2\ \cdots\ \alpha_n]$、$B=[\beta_1\ \beta_2\ \cdots\ \beta_n]$，定义式简写成 $AC=B$。

        * 位置：由哪组基到哪组基，$C$ 就落在「到」字后面那组基的右端。写成上下两行时上面一行 $\alpha_1\alpha_2\alpha_3$、下面一行 $\beta_1\beta_2\beta_3$，$C$ 就写在下面那一行的正右边。

        * 反方向的过渡矩阵记作 $C_1$，满足 $[\beta_1\ \beta_2\ \cdots\ \beta_n]C_1=[\alpha_1\ \alpha_2\ \cdots\ \alpha_n]$，$C_1$ 落在 $\alpha$ 那一行的右端。

        * > **易错点**：这两行上下不要互换，也不要写成一行。由哪组基到哪组基一定要搞清楚，牵涉的就是 $C$ 放在哪的问题。

    * **左边是单位阵的情形**

        * $[\alpha_1\ \alpha_2\ \alpha_3]=E$，$[\beta_1\ \beta_2\ \beta_3]=\begin{bmatrix}1&1&0\\1&0&1\\0&1&1\end{bmatrix}$。

        * 由定义 $EC=[\beta_1\ \beta_2\ \beta_3]$，单位阵乘矩阵相当于没乘，所以 $C$ 就是右边那个矩阵本身。

### 三条性质

    * **$C$ 一定可逆**

        * $A$、$B$ 里的每个向量都是 $n$ 维向量，每组都有 $n$ 个且都线性无关，$n$ 个 $n$ 维向量线性无关就是满秩，所以 $A$ 可逆、$B$ 也可逆。

        * 两边都可逆，$C$ 必可逆。

    * **$C=A^{-1}B$**

        * 由 $AC=B$ 两边同时左乘 $A^{-1}$（$A$ 可逆已由上一条保证）即得 $C=A^{-1}B$。

        * 这就是求过渡矩阵的标准流程：两组基分别按列排成 $A$、$B$，然后算 $A^{-1}B$。

    * **正反两个过渡矩阵互逆**

        * 反方向有 $BC_1=A$，同理 $C_1=B^{-1}A$。

        * 两式相乘得 $CC_1=A^{-1}BB^{-1}A=E$。

        * > **结论**：由 $\alpha$ 到 $\beta$ 的过渡矩阵，与由 $\beta$ 到 $\alpha$ 的过渡矩阵，互为逆矩阵。

### 用增广矩阵一次搞定

    * **把求逆和相乘合并**

        * 要求的东西说到底是矩阵方程 $AX=B$ 的解 $X$，这种矩阵方程有专门的计算方法：把 $A$ 放左边、$B$ 放右边，只做初等行变换。

        * 等到左边变成单位阵时，右边得到的就是 $A^{-1}B$，也就是要的 $C$；求逆与相乘两件事被合并成一串行变换，一次完成。

```text
[  A  |  B  ]   ──只对左半边做初等行变换──▶   [  E  |  A⁻¹B  ]
```

    * > **提示**：若 $A=\begin{bmatrix}1&0&0\\1&1&0\\1&1&1\end{bmatrix}$，老办法 $C=A^{-1}B$ 要先单独求逆再乘一遍，两趟事；用增广矩阵的写法计算量小得多。

## 坐标变换

### 公式推导

    * **坐标变换公式**

        * 设 $\xi$ 在 $\alpha_1,\alpha_2,\alpha_3$ 下的坐标是 $x_1,x_2,x_3$，在 $\beta_1,\beta_2,\beta_3$ 下的坐标是 $y_1,y_2,y_3$。

        * 由坐标的定义，向量本身是同一个：$\xi=x_1\alpha_1+x_2\alpha_2+x_3\alpha_3=y_1\beta_1+y_2\beta_2+y_3\beta_3$。

        * 写成矩阵是 $[\alpha_1\ \alpha_2\ \alpha_3]\begin{bmatrix}x_1\\x_2\\x_3\end{bmatrix}=[\beta_1\ \beta_2\ \beta_3]\begin{bmatrix}y_1\\y_2\\y_3\end{bmatrix}$。

        * 用过渡矩阵式 $[\alpha_1\ \alpha_2\ \alpha_3]C=[\beta_1\ \beta_2\ \beta_3]$ 换掉右边，再两边同时左乘 $[\alpha_1\ \alpha_2\ \alpha_3]^{-1}$（该矩阵可逆，前面已证），得 $\begin{bmatrix}x_1\\x_2\\x_3\end{bmatrix}=C\begin{bmatrix}y_1\\y_2\\y_3\end{bmatrix}$。

        * > **结论**：坐标之间的变换公式就是 $x=Cy$。

### C 在两个公式中的位置

```text
基 与 基 之 间 ：

[α1 α2 α3]  ×  C  =  [β1 β2 β3]
               ↑
         C 夹在两组基中间
```

```text
坐 标 与 坐 标 之 间 ：

[x]  =  C  ×  [y]
        ↑
  C 压在 [y] 左边
```

    * > **结论**：基之间的转换公式，$C$ 夹在两组基中间；坐标之间的转换公式，$C$ 压在 $y$ 的左边。念一遍，记牢。

### 规范正交基的情形

    * **充要条件**

        * > **定理**：如果 $\alpha_1,\dots,\alpha_n$ 是规范正交基，那么 $\beta_1,\dots,\beta_n$ 是规范正交基的充要条件是 $C$ 是一个正交矩阵。

        * 正向：$[\alpha_1\ \cdots\ \alpha_n]$ 本身是正交矩阵，$C$ 也正交，$[\beta_1\ \cdots\ \beta_n]=[\alpha_1\ \cdots\ \alpha_n]C$ 是两个正交矩阵相乘，仍是正交矩阵；而一个矩阵是正交矩阵，它的列向量组就是标准正交向量组。

        * 反向：$\beta$ 规范正交则 $[\beta]$ 正交，$C=[\alpha]^{-1}[\beta]$ 是两个正交矩阵相除，仍是正交。

        * > **提示**：做题时这个定理用得不多——真要用到规范正交基、正交矩阵，这部分的计算量就海了去了。

### 已知一个坐标求另一个

    * **由 $C$ 与 $y$ 求 $x$**

        * 已知 $C$ 是由 $\alpha$ 组基到 $\beta$ 组基的过渡矩阵，$\xi$ 在 $\beta$ 组基下的坐标是 $(1,2,-3)^T$。

        * 套公式 $x=Cy$，得 $x=\begin{bmatrix}0\\3\\1\end{bmatrix}$，即在 $\alpha_1,\alpha_2,\alpha_3$ 之下的坐标是 $(0,3,1)^T$。

        * > **提示**：坐标一般规规矩矩竖着写三个数，不要写成带箭头的列向量。

    * **由 $C$ 求反方向的过渡矩阵**

        * 反方向写成 $BC_1=A$，两边同时左乘 $B^{-1}$ 得 $C_1=B^{-1}A$，也就是 $C^{-1}$。

        * $C$ 已有的情形下，直接用初等行变换法求逆阵即可。

    * **由 $x$ 求 $y$ 的两条路**

        * 常规路子：$A=[\alpha_1\ \alpha_2\ \alpha_3]=\begin{bmatrix}1&0&0\\1&1&0\\1&1&1\end{bmatrix}$，$B=[\beta_1\ \beta_2\ \beta_3]$；$C=A^{-1}B$，而 $x=Cy$ 要求的是 $y$，故 $y=C^{-1}x$。

        * 其中 $C^{-1}=(A^{-1}B)^{-1}=B^{-1}A$，逆矩阵带括号要把顺序颠倒过来，不是 $AB^{-1}$。

        * 纯计算下来 $y=\begin{bmatrix}1\\3\\-2\end{bmatrix}$，即 $(1,3,-2)^T$。

        * 另一条路：表示系数已知，向量本身也就现成了。$\gamma=-2\alpha_1+\alpha_2+2\alpha_3=\begin{bmatrix}1\\0\\0\end{bmatrix}\cdot(-2)+\begin{bmatrix}1\\1\\0\end{bmatrix}+\begin{bmatrix}1\\1\\1\end{bmatrix}\cdot 2=\begin{bmatrix}1\\3\\2\end{bmatrix}$。

        * 再解 $\gamma=y_1\beta_1+y_2\beta_2+y_3\beta_3$，把 $B$ 和 $\gamma$ 摞成增广矩阵 $\begin{bmatrix} B & \gamma \end{bmatrix}$ 做初等行变换，解出 $y=\begin{bmatrix}1\\3\\-2\end{bmatrix}$，与方法一完全一样。

        * > **易错点**：$(A^{-1}B)^{-1}$ 是 $B^{-1}A$，不是 $AB^{-1}$；这一步写反了，后面全错。
