# 不定积分

## 原函数与不定积分

 * **原函数（primitive function）**

   * > **定义**：在某个区间上，若 $F'(x) = f(x)$，就称 $F(x)$ 是 $f(x)$ 在这个区间上的**一个**原函数。

   * 同一区间上原函数不唯一：设 $F$、$G$ 都是 $f$ 的原函数，则 $[F(x)-G(x)]' = 0$，而在一个区间上导数恒为零的函数是常数。

       * > **结论**：同一个区间上，$f(x)$ 的任意两个原函数只相差一个常数；抓住一个原函数 $F(x)$，全部原函数就是 $F(x)+C$ 这一族。

   * 原函数、不定积分都是「在某个区间上」的概念：$1/x$ 的定义域断成 $(-\infty,0)$ 与 $(0,+\infty)$ 两段，两段各找各的原函数。

 * **不定积分（indefinite integral）**

   * > **定义**：函数 $f(x)$ 的**原函数的全体**，称为 $f(x)$ 的不定积分，记作 $\int f(x)\,dx$。

   * 记号分工：$\int$ 叫积分号，$f(x)$ 叫被积函数，$x$ 叫积分变量；积分变量字母可随意换（$x$、$u$、$t$），但同一个式子前后要一致。

   * $\int f(x)\,dx = F(x)+C$，其中 $F$ 是任意一个原函数，$C$ 是**任意**常数（不是固定某数）。

       * > **易错点**：不定积分不是某一个函数，而是一个函数组——集合里每个函数的导数都等于 $f(x)$，一个不多、一个不少。

 * **积分与微分互为逆运算**

   * 先微分、后积分：$\displaystyle\int dF(x) = F(x)+C$——抵消后要补一个任意常数 $C$，因为不定积分给的是一组函数。

   * 先积分、后微分：$\displaystyle d\left(\int f(x)\,dx\right) = f(x)\,dx$——整组函数相差常数、常数的微分为零，结果唯一确定，正好抵消，连 $C$ 都不写。

   * 记号 $\int f(x)\,dx$ 里带着微分 $dx$ 是关键设计：正因如此，$g'(x)\,dx$ 能合成 $d(g(x))$，微分的全部运算都能搬进积分号里用，换元才能落笔。

 * **人口模型的逆运算视角**

   * 人口模型 $P'(T)=\lambda P(T)$ 的解法就是「已知微分还原函数」：凑出 $d(\ln P(T)) = \lambda\,dT$，倒回去得 $\ln P(T)=\lambda T+\tilde C$，再还原 $P(T)=P_0\,\mathrm{e}^{\lambda(T-T_0)}$。

   * 已知速度求路程、已知切线斜率求曲线，与人口模型同型——统统归结为求导的逆运算，即不定积分问题。

## 基本积分表

 * **公式的来源**

   * 每条积分公式都是从熟悉的求导公式「倒回去」得到的；做题的思维方向与求导相反：不是问「它的导数是什么」，而是问「什么函数的导数是它」。

       * > **易错点**：初学最典型的方向错误——看到 $\sin x$ 提笔写 $\int\sin x\,dx=\cos x+C$。正确答案是 $-\cos x+C$，因为要找的是「谁的导数是 $\sin x$」。

   * 积分表上的公式要背出来，后面每一步积分计算都靠它。

 * **基本积分表（求导公式 → 不定积分）**

   | 求导公式（正向） | 不定积分（倒回去） |
   | :--- | :--- |
   | $(x)' = 1$ | $\int 1\,dx = x + C$ |
   | $\left(x^{\alpha}\right)' = \alpha x^{\alpha-1}$ | $\int x^{\alpha}\,dx = \dfrac{x^{\alpha+1}}{\alpha+1} + C \quad (\alpha \neq -1)$ |
   | $(\ln\lvert x\rvert)' = \dfrac{1}{x}$ | $\int \dfrac{1}{x}\,dx = \ln\lvert x\rvert + C$ |
   | $(\mathrm{e}^x)' = \mathrm{e}^x$ | $\int \mathrm{e}^x\,dx = \mathrm{e}^x + C$ |
   | $(\sin x)' = \cos x$ | $\int \cos x\,dx = \sin x + C$ |
   | $(\cos x)' = -\sin x$ | $\int \sin x\,dx = -\cos x + C$ |
   | $(\tan x)' = \sec^2 x$ | $\int \sec^2 x\,dx = \tan x + C$ |
   | $(\sec x)' = \sec x\,\tan x$ | $\int \sec x\,\tan x\,dx = \sec x + C$ |
   | $(\arcsin x)' = \dfrac{1}{\sqrt{1-x^2}}$ | $\int \dfrac{dx}{\sqrt{1-x^2}} = \arcsin x + C$ |
   | $(\arctan x)' = \dfrac{1}{1+x^2}$ | $\int \dfrac{dx}{1+x^2} = \arctan x + C$ |

   * $\cot x$、$\csc x$ 相应的一批结果也在表里。

 * **$\alpha = -1$ 与 $\ln\lvert x\rvert$**

   * $\int x^{\alpha}\,dx$ 特意不含 $\alpha=-1$，由 $\int\frac{dx}{x}$ 补上。

   * 在 $(0,+\infty)$ 上 $\ln x$ 是 $1/x$ 的原函数；在 $(-\infty,0)$ 上 $\ln x$ 无意义，改用 $\ln(-x)$——复合求导 $[\ln(-x)]' = \frac{1}{-x}\cdot(-1) = \frac{1}{x}$。

   * 两段合并：$\displaystyle\int\frac{dx}{x}=\ln|x|+C$——绝对值正是为同时覆盖两段而加的。

## 线性性质

 * **线性性质（linearity）**

   * > **结论**：设 $f$、$g$ 的原函数都存在，$k_1$、$k_2$ 为任意常数，则 $\int\bigl[k_1 f(x)+k_2 g(x)\bigr]dx = k_1\int f(x)\,dx + k_2\int g(x)\,dx$。

   * 等号的含义是**函数组**意义上的相同：右边两个函数组各取一个函数相加拼出的新函数组，与左边函数组完全一样，并不是「左边一个函数等于右边一个函数」。

   * 证明靠求导的线性：$[k_1F+k_2G]'=k_1f+k_2g$，故左边等于 $k_1F+k_2G+C$；右边 $k_1C_1+k_2C_2$ 合并仍是任意常数，两边表示同一函数组。

   * 用处一句话：**表上没有的，想办法拆成表上有的**。

 * **拆法示例**

   * $\int\tan^2 x\,dx$：恒等变形 $\tan^2 x=\sec^2 x-1$，拆开查表得 $\tan x - x + C$。

   * $\int\sin^2\frac{x}{2}\,dx$：先降幂 $\sin^2\frac{x}{2}=\frac{1-\cos x}{2}$，得 $\frac{x}{2}-\frac{1}{2}\sin x+C$。

   * $\int\frac{(x+\sqrt{x})(x-2\sqrt{x})^2}{\sqrt{x}}\,dx$：先展开分子合并同类项，再逐项除以 $\sqrt x$ 化为 $\int(x^{5/2}-3x^2+4x)\,dx$，逐项套幂函数公式得 $\frac{2}{7}x^{7/2}-x^3+2x^2+C$。

   * $\int\frac{x^4}{1+x^2}\,dx$：分子次数高，先「添一项减一项」做除法 $\frac{x^4}{1+x^2}=x^2-1+\frac{1}{1+x^2}$，得 $\frac{x^3}{3}-x+\arctan x+C$。

   * 已知曲线每点切线斜率为 $x^2$ 且过 $(3,2)$：$f(x)=\frac{x^3}{3}+C$，代入定出 $C=-7$；「经过某点」这类附加条件负责从不定积分给出的函数族里挑出要的那一个。

## 第一类换元积分法（凑微分）

 * **定理与流程**

   * > **定义**：若 $f(x)=\tilde f(g(x))\cdot g'(x)$（新函数 $\tilde f$ 套在 $g(x)$ 上再乘 $g$ 的导数），且 $\int\tilde f(u)\,du=F(u)+C$ 会求，则 $\int f(x)\,dx=F(g(x))+C$。

   * 验证是必须的：$(F(g(x)))'=F'(g(x))\cdot g'(x)=\tilde f(g(x))\,g'(x)=f(x)$——$F(g(x))$ 确实是原函数，这是整个方法的根基。

   * 一路等号的写法：$\int f(x)\,dx=\int\tilde f(g(x))\,g'(x)\,dx=\int\tilde f(g(x))\,d(g(x))=\int\tilde f(u)\,du=F(u)+C=F(g(x))+C$；等号链本身已顺带完成验证，不必回头另算导数。

   * 四步流程：**凑**（在微分号里凑出 $g(x)$，让 $g'(x)\,dx$ 合成 $d(g(x))$）→ **换**（令 $u=g(x)$）→ **算**（写出 $F(u)+C$）→ **回代**（$u=g(x)$ 代回去）。功夫全在「凑」。

       * > **易错点**：这一步验证（确认结果是原函数）不能省——可以由等号链顺带完成，但方法本身必须站得住。

 * **最简单的凑：$x$ 加减常数**

   * $d(x-a)$ 与 $dx$ 一样——微分号里加一个数、减一个数，微分不变（常数的微分为零）；这是凑微分最常用的一手。

   * $\displaystyle\int\frac{dx}{x-a}=\int\frac{d(x-a)}{x-a}=\ln|x-a|+C$。

   * $\displaystyle\int\frac{dx}{(x-a)^n}=\int u^{-n}\,du=\frac{(x-a)^{-n+1}}{-n+1}+C$（$n\neq1$）。

   * $\displaystyle\int\frac{dx}{x^2-a^2}$：先分解因式拆项 $\frac{1}{x^2-a^2}=\frac{1}{2a}\left(\frac{1}{x-a}-\frac{1}{x+a}\right)$，分别凑 $d(x-a)$、$d(x+a)$，得 $\frac{1}{2a}\ln\left|\frac{x-a}{x+a}\right|+C$。

 * **先提常数再凑：$\frac{x}{a}$ 进微分号**

   * $\displaystyle\int\frac{dx}{x^2+a^2}$：提出 $a^2$，里面乘 $a$ 外面除 $a$，凑 $d\frac{x}{a}$，得 $\frac{1}{a}\arctan\frac{x}{a}+C$。

   * $\displaystyle\int\frac{dx}{\sqrt{a^2-x^2}}$：根号里提出 $a^2$ 得 $a\sqrt{1-(x/a)^2}$，$dx$ 写成 $a\,d\frac{x}{a}$ 消掉分母的 $a$，得 $\arcsin\frac{x}{a}+C$。

   * 这两题 $g(x)=\frac{x}{a}$，$g'(x)=\frac1a$，但不先写出 $\frac1a$ 再放，直接在微分号里凑 $dx=a\,d\frac{x}{a}$ 一步到位。

 * **三角函数的凑**

   * $\displaystyle\int\tan x\,dx$：拆 $\tan x=\frac{\sin x}{\cos x}$，分子 $\sin x\,dx=-d(\cos x)$，得 $-\ln|\cos x|+C=\ln|\sec x|+C$。

   * $\displaystyle\int\cot x\,dx$：$\cos x\,dx=d(\sin x)$，得 $\ln|\sin x|+C$。

   * $\displaystyle\int\sec x\,dx$：分子分母同乘 $\cos x$，化为 $\int\frac{d(\sin x)}{1-\sin^2 x}$，套 $\int\frac{du}{1-u^2}=\frac12\ln\left|\frac{1+u}{1-u}\right|+C$，再分子分母同乘 $1+\sin x$ 化简，最终 $\ln|\sec x+\tan x|+C$。

   * $\displaystyle\int\csc x\,dx=\ln|\csc x-\cot x|+C$（同理）。

       * > **易错点**：做到 $\frac12\ln\left|\frac{1+\sin x}{1-\sin x}\right|+C$ 也是对的——不定积分用不同做法会得出不同外形的结果，可能两个都对，不要轻易断言谁对谁错。

   * 中间一步 $1\pm\sin x$ 恒正（$|\sin x|<1$），绝对号可去掉才能继续化简；但对数真数为正的要求本身是必要的。

 * **吸根号与积化和差**

   * $\displaystyle\int\frac{dx}{\sqrt{x}(1+x)}$：$d\sqrt{x}=\frac{1}{2\sqrt x}\,dx$，故 $\frac{dx}{\sqrt x}=2\,d\sqrt{x}$，分母的 $x$ 写成 $u^2$，得 $2\arctan\sqrt{x}+C$。

   * $\displaystyle\int\sin mx\cos nx\,dx$（$m\neq n$）：积化和差 $\sin mx\cos nx=\frac12[\sin(m+n)x+\sin(m-n)x]$ 拆开，每个用 $dx=\frac{1}{k}d(kx)$ 凑，得 $-\frac12\left[\frac{\cos(m+n)x}{m+n}+\frac{\cos(m-n)x}{m-n}\right]+C$。

   * 同法：$\int\sin mx\sin nx\,dx=\frac12\left[\frac{\sin(m-n)x}{m-n}-\frac{\sin(m+n)x}{m+n}\right]+C$；$\int\cos mx\cos nx\,dx=\frac12\left[\frac{\sin(m-n)x}{m-n}+\frac{\sin(m+n)x}{m+n}\right]+C$。

   * > **提示**：凑微分法新做出的公式不必死背——要背的是「凑」的手法本身：看到分母、三角函数、根号，想哪个函数能吸进微分号里去。

## 第二类换元积分法

 * **定理**

   * > **定义**：要求 $\int f(x)\,dx$，令 $x=\varphi(t)$，设反函数 $t=\varphi^{-1}(x)$ 存在；若 $\int f(\varphi(t))\,\varphi'(t)\,dt=\Phi(t)+C$，则 $\int f(x)\,dx=\Phi(\varphi^{-1}(x))+C$。

   * 起点等号先打问号：定义里 $d$ 后面跟的是积分变量，$d\varphi(t)$ 这种写法定义中没出现过；验证后问号才去掉。

   * 验算：$\frac{d}{dx}\Phi(\varphi^{-1}(x))=\Phi'(t)\cdot\frac{dt}{dx}=f(\varphi(t))\,\varphi'(t)\cdot\frac{1}{\varphi'(t)}=f(x)$——反函数求导法则使 $\varphi'(t)$ 消掉。

   * 两类换元方向相反：第一类把 $\varphi'(x)$ 凑进微分号、换掉「里层」；第二类把 $x$ 整个换成 $\varphi(t)$、换掉「外层」。读法相同：先换元，积出来，再回代。

 * **正弦代换消 $\sqrt{a^2-x^2}$**

   * 目的有明确指向：找代换把根号去掉。令 $x=a\sin t$，$t\in\left(-\frac{\pi}{2},\frac{\pi}{2}\right)$，则 $\sqrt{a^2-x^2}=a\cos t$——$t$ 取在该区间保证 $\cos t>0$，开根号无正负号问题。

   * $dx=a\cos t\,dt$，积分化为 $a^2\int\cos^2 t\,dt$；倍角公式 $2\cos^2 t=1+\cos 2t$ 降幂。

   * 回代：$t=\arcsin\frac{x}{a}$，$\frac{a^2}{2}\cdot\frac12\sin 2t=\frac{a^2}{2}\sin t\cos t=\frac{x}{2}\sqrt{a^2-x^2}$（$a$ 拆成 $a\sin t=x$ 与 $a\cos t=\sqrt{a^2-x^2}$ 各乘一个）。

       * > **结论**：$\displaystyle\int\sqrt{a^2-x^2}\,dx=\frac{a^2}{2}\arcsin\frac{x}{a}+\frac{x}{2}\sqrt{a^2-x^2}+C$。

   * 求导给了一个函数总能做；给了一个函数求不定积分做的是逆运算，不容易想——所以需要换元这样的方法与技巧。

 * **正割代换消 $\sqrt{x^2-a^2}$**

   * 令 $x=a\sec t$，恒等式 $\sec^2 t-1=\tan^2 t$ 使 $\sqrt{x^2-a^2}=a\tan t$。

   * $t$ 的取法：$x>a$ 时取 $\left(0,\frac{\pi}{2}\right)$；$x<-a$ 时取 $\left(\pi,\frac{3\pi}{2}\right)$——两段里 $\tan t$ 都为正，开根号本该出的 $a|\tan t|$ 不需要绝对值。

       * > **易错点**：不定积分里一旦出现绝对号，这个积分就麻烦了；挑 $t$ 的范围正是为了保证开根号出来的因子恒正，把绝对值摘掉。

   * $dx=a\sec t\,\tan t\,dt$，约分后只剩 $\int\sec t\,dt=\ln|\sec t+\tan t|+C$（第一类换元已求过）。

   * 回代：$\sec t=\frac{x}{a}$，$\tan t=\frac{\sqrt{x^2-a^2}}{a}$，对数里多出的 $-\ln a$ 并进任意常数。

       * > **结论**：$\displaystyle\int\frac{dx}{\sqrt{x^2-a^2}}=\ln\left|x+\sqrt{x^2-a^2}\right|+C$。

 * **三类最简二次根式**

   | 积分 | 变量代换 | $t$ 的取法 | 开根号依据 |
   | :--- | :--- | :--- | :--- |
   | $\int\sqrt{a^2-x^2}\,dx$ | $x=a\sin t$ | $\left(-\frac{\pi}{2},\frac{\pi}{2}\right)$，$\cos t>0$ | $1-\sin^2 t=\cos^2 t$ |
   | $\int\frac{dx}{\sqrt{x^2-a^2}}$ | $x=a\sec t$ | $x>a$ 取 $\left(0,\frac{\pi}{2}\right)$；$x<-a$ 取 $\left(\pi,\frac{3\pi}{2}\right)$，$\tan t>0$ | $\sec^2 t-1=\tan^2 t$ |
   | $\int\frac{dx}{\sqrt{x^2+a^2}}$ | $x=a\tan t$ | $\left(-\frac{\pi}{2},\frac{\pi}{2}\right)$，$\sec t>0$ | $1+\tan^2 t=\sec^2 t$ |

   * 三行同一句话：代换挑成三角函数，恒等式把根号化成单项；范围挑准让因子恒正，绝对值消失。

 * **躲开高次展开**

   * $\int x(2x-1)^{100}\,dx$：令 $2x-1=t$，$x=\frac{1+t}{2}$，$dx=\frac12\,dt$，化为 $\frac14\int(t^{100}+t^{101})\,dt$，结果 $\frac14\left(\frac{(2x-1)^{101}}{101}+\frac{(2x-1)^{102}}{102}\right)+C$——目的是避免展开一百次方的括号。

 * **一题三解：两类换元可结合**

   * $\int\frac{dx}{x^2\sqrt{1+x^2}}$（先在 $x>0$ 上做，定义域断成两段分别谈）三个答案都是 $-\frac{\sqrt{1+x^2}}{x}+C$：

   * 解法一（纯第一类）：$x>0$ 时从根号里提出 $x$：$\sqrt{1+x^2}=x\sqrt{1+\frac{1}{x^2}}$，再凑 $\frac{dx}{x^3}=-\frac12\,d\left(1+\frac{1}{x^2}\right)$（微分号里加个 1 等于不加，凑成完整的 $u$）。

   * 解法二（先第二类再第一类）：令 $x=\frac1t$，$dx=-\frac{dt}{t^2}$，化出 $-\int\frac{t\,dt}{\sqrt{1+t^2}}$，紧接着凑 $t\,dt=\frac12\,d(1+t^2)$。

   * 解法三（正切代换）：令 $x=\tan t$，$\sqrt{1+x^2}=\sec t$，化为 $\int\frac{\cos t}{\sin^2 t}\,dt$，凑 $d(\sin t)$ 得 $-\frac{1}{\sin t}$，最后借 $\tan t=x$、$\sec t=\sqrt{1+x^2}$ 回代。

       * > **提示**：从根号里提东西等步骤可先按正的假设算完，然后**真的动手验算**另一段上导数是否等于被积函数——是，则那段的不定积分同样是这个函数（求导过程不含正负号分支时成立）。

   * 两类换元法不是各管一摊，结合起来使用常常才是顺的路。

## 分部积分法

 * **公式**

   * 来源：乘积微分公式 $d(uv)=u\,dv+v\,du$ 移一项得 $u\,dv=d(uv)-v\,du$，两边做不定积分。

       * > **定义**：$\displaystyle\int u\,dv = uv - \int v\,du$，即分部积分公式。

   * 含义很具体：$\int u\,dv$ 不会求，但 $\int v\,du$ 会求，则原积分解决。

   * $\int d(uv)$ 后面不用补 $C$——右边还剩着 $\int v\,du$，常数由它带着；等号同样是函数组意义上的相等。

 * **降次功能**

   * $\int x\cos x\,dx$：$\cos x\,dx=d(\sin x)$，得 $x\sin x-\int\sin x\,dx=x\sin x+\cos x+C$。

   * $\int x^2e^x\,dx$：$e^x$ 放进微分号，做一次 $x$ 的次数降一次，做两次后多项式变常数，结果 $e^x(x^2-2x+2)+C$。

       * > **结论**：$n$ 次多项式配三角函数或指数函数，分部积分要做 $n$ 次——做一次降一次次，$n$ 次之后多项式变成常数，积分就出来了。

 * **谁放进微分号**

   | 被积函数的样子 | 谁往微分号里放 | 做完之后发生什么 |
   | :--- | :--- | :--- |
   | $P_n(x)$ 配 $\sin\alpha x$、$\cos\alpha x$、$e^{\lambda x}$ | 三角、指数进去 | 多项式做一次降一次次，$n$ 次后变常数 |
   | $P_n(x)$ 配 $\arcsin x$、$\arctan x$、$\ln x$ | 多项式进去 | 反三角、对数一求导就消失 |
   | $e^{\lambda x}$ 配 $\sin\alpha x$、$\cos\alpha x$；$\sqrt{x^2\pm a^2}$ | 谁进都行 | 原积分带着非 $1$ 的系数绕回来，移项解方程 |

   * 多项式配三角、指数时，$P_n$ **不能**往微分号里放：放进去变成 $n+1$ 次多项式，分部一次次数反而更高，越走越远。

   * 多项式配反三角、对数时把 $P_n$ 放进去：虽然升成 $n+1$ 次多项式，但另一头求导后 $\arcsin x\to\frac{1}{\sqrt{1-x^2}}$、$\arctan x\to\frac{1}{1+x^2}$、$\ln x\to\frac1x$——讨厌的函数没了。

       * > **易错点**：$\int x^2e^x\,dx$ 若把 $x^2$ 放进微分号，结果越来越复杂——一个越走越远，一个一步步逼近答案，方向选错就白做。

 * **典型例题**

   * $\int\ln x\,dx$：没东西放进微分号时，$x$ 本身就是 $v$——$x\ln x-\int x\cdot\frac1x\,dx=x\ln x-x+C$。

   * $\int x\arctan x\,dx$：把 $x$ 放进微分号 $\frac12\int\arctan x\,d(x^2)$，剩下的 $\int\frac{x^2}{1+x^2}\,dx$ 用分子加 1 减 1 拆开，最终 $\frac12(x^2+1)\arctan x-\frac{x}{2}+C$。

   * $\int\frac{x}{1+\cos x}\,dx$：先用 $1+\cos x=2\cos^2\frac{x}{2}$ 化分母，$\frac12\int x\sec^2\frac{x}{2}\,dx=\int x\,d\!\left(\tan\frac{x}{2}\right)$（系数一对一正好抵掉），再分部：$x\tan\frac{x}{2}+2\ln\left|\cos\frac{x}{2}\right|+C$。

       * > **易错点**：凑微分时系数要当场算清——$d\!\left(\tan\frac x2\right)=\frac12\sec^2\frac x2\,dx$，原有的 $\frac12$ 一对一正好抵掉，不会多出个 $\frac14$。

 * **绕圈型：解方程**

   * $\int e^{\lambda x}\cos\alpha x\,dx$、$\int e^{\lambda x}\sin\alpha x\,dx$、$\int\sqrt{x^2+a^2}\,dx$：两因子谁也不退场（$\cos$ 进去变 $\sin$、$\sin$ 再进去变回 $\cos$；$e^{\lambda x}$ 求导还是自己），做两次分部积分又回到原地。

   * $I=\int e^x\sin x\,dx$：第一次 $\sin x$ 进微分号，第二次 $\cos x$ 进微分号，得 $I=-e^x\cos x+e^x\sin x-I$；原积分带系数 $-1$ 绕回，移项解出 $I=\frac12 e^x(\sin x-\cos x)+C$。

   * 两次放进微分号的必须是**同一类**函数：第一次放三角第二次也放三角；若第二次改放 $e^x$，等式两边一消什么也得不到，白做。

   * 关键在系数：绕回来的系数只要不是 $1$，等式就能解；恰好是 $1$ 就无解。

 * **二次根式六公式**

   * 根式在分母的三个：$\int\frac{dx}{\sqrt{a^2-x^2}}=\arcsin\frac{x}{a}+C$；$\int\frac{dx}{\sqrt{x^2\pm a^2}}=\ln\left|x+\sqrt{x^2\pm a^2}\right|+C$（$\pm$ 占两条）。

   * 根式在分子的三个：$\int\sqrt{a^2-x^2}\,dx$（换元法求得）；$\int\sqrt{x^2\pm a^2}\,dx$（分部积分求得）。

   * $I=\int\sqrt{x^2+a^2}\,dx$：取 $u=\sqrt{x^2+a^2}$、$dv=dx$，分子加 $a^2$ 减 $a^2$ 拆开后 $I$ 带系数 $-1$ 绕回，移项得 $\frac12 x\sqrt{x^2+a^2}+\frac{a^2}{2}\ln\left(x+\sqrt{x^2+a^2}\right)+C$；同法 $\int\sqrt{x^2-a^2}\,dx=\frac{x}{2}\sqrt{x^2-a^2}-\frac{a^2}{2}\ln\left|x+\sqrt{x^2-a^2}\right|+C$。

       * > **易错点**：$d\left(\sqrt{x^2+a^2}\right)=\frac{x}{\sqrt{x^2+a^2}}\,dx$——漏掉分子上那个 $x$，下面就做不下去或得出错误结果。

       * > **提示**：$x+\sqrt{x^2+a^2}$ 恒正，绝对值可省；$x+\sqrt{x^2-a^2}$ 在 $x\le -a$ 时是负的，绝对值不能丢。

   * 攒齐六公式的意义：根号里是一般二次三项式（如 $\sqrt{x^2+px+q}$）时配方后都化成标准形——判别式小于零配出 $x^2+a^2$ 型，两个不同根配出 $x^2-a^2$ 型，重根则成完全平方。

 * **降次递推**

   * > **结论**：对 $\int f^n(x)\,dx$ 这类积分，用分部积分降次，建立 $I_n$ 与 $I_{n-1}$ 的递推公式；起点 $I_1=\int f(x)\,dx$ 通常好求，$I_1$ 知道则 $I_n$ 全知道。

   * $I_n=\int\frac{dx}{(x^2+a^2)^n}$：把分子写成 $(x^2+a^2)-x^2$（前面补 $\frac{1}{a^2}$），第二块里 $\frac{x\,dx}{(x^2+a^2)^n}$ 放进微分号（它差常数系数就是 $\frac{1}{(x^2+a^2)^{n-1}}$ 的导数），分部一次后两个 $I_{n-1}$ 并起来。

       * > **结论**：$I_n=\dfrac{x}{2(n-1)\,a^2\,(x^2+a^2)^{n-1}}+\dfrac{2n-3}{2(n-1)\,a^2}\,I_{n-1}\quad(n\ge 2)$，其中 $I_1=\dfrac{1}{a}\arctan\dfrac{x}{a}+C$。

       * > **易错点**：拆分子时 $(x^2+a^2)-x^2$ 等于 $a^2$ 而不是 $1$，必须补 $\frac{1}{a^2}$ 等式才成立；放微分号时别忘了导数前系数 $-2(n-1)$。

   * 取 $u$、$v$、决定谁进微分号，是分部积分法带技巧性的关键；四点说明（含递推）都在教这件事。

## 积分表的扩充与配方

 * **新表条目**

   * $\int a^x\,dx=\frac{a^x}{\ln a}+C$（$a=e$ 时即 $e^x+C$）；$\int\sec x\,dx=\ln|\sec x+\tan x|+C$；$\int\csc x\,dx=\ln|\csc x-\cot x|+C$。

   * 分母 $a^2-x^2$、$x^2\pm a^2$ 一族，及根号在分子上的 $\sqrt{a^2-x^2}$、$\sqrt{x^2\pm a^2}$ 一族，都要牢记。

 * **根号里是二次三项式：先配方**

   * $\int\sqrt{x^2-2x+5}\,dx$：配方 $x^2-2x+5=(x-1)^2+2^2$，令 $u=x-1$、$a=2$ 套现成公式，得 $\frac{x-1}{2}\sqrt{x^2-2x+5}+2\ln\left|x-1+\sqrt{x^2-2x+5}\right|+C$。

   * 配成什么样由判别式说了算：判别式小于零配出 $u^2+a^2$，大于零配出 $u^2-a^2$，两种都有现成公式。

   * $\int(x+1)\sqrt{x^2-2x+5}\,dx$：把 $x+1$ 往根号里二次三项式的导数 $2x-2$ 上凑——写成 $\frac12[(2x-2)+4]$ 拆成两项；导数部分进微分号积出 $\frac13(x^2-2x+5)^{3/2}$，常数部分套第一问，合计 $\frac13(x^2-2x+5)^{3/2}+(x-1)\sqrt{x^2-2x+5}+4\ln\left|x-1+\sqrt{x^2-2x+5}\right|+C$。

   * 推广口径：$\int\frac{dx}{\sqrt{x^2+px+q}}$ 关键是配方；根号前挂 $ax+b$ 时把分子拆成「导数的倍数 + 剩余常数」两项。

## 初等函数的可积性

 * **求导与求积分不对称**

   * 初等函数（基本初等函数经有限次加减乘除与复合）在定义域上连续、几乎处处可导，求导只要仔细肯定好求，导数仍是初等函数。

   * 但初等函数的原函数可能**不是初等函数**——函数连续原函数存在，却写不成基本初等函数的有限次组合，用初等方法解不出来。

   * 积不出的实例：$\int\frac{\sin x}{x}\,dx$、$\int e^{-x^2}\,dx$、$\int\sqrt{1-k^2\sin^2 x}\,dx$（$0<k^2<1$，后者称**椭圆积分**）。

 * **有理函数必定可积**

   * 有理函数 $R(x)=\frac{P_m(x)}{Q_n(x)}$：分子分母都是多项式；它的不定积分一定求得出，且原函数是初等函数。

   * 三点不妨的约定：分子分母无公因式（有则约掉）；$Q_n$ 最高次项系数不妨设为 1；$m<n$（真分式）。

   * $m\ge n$ 时先多项式除法：$\frac{P_m(x)}{Q_n(x)}=P_{m-n}(x)+\frac{r(x)}{Q_n(x)}$，商多项式逐项直接积分（没有困难），核心问题只剩真分式。

   * 分母因式分解（代数基本定理）：$n$ 次多项式 $Q_n$ 有 $n$ 个根，实根 $\alpha_k$（重数 $m_k$）与成对共轭虚根 $\beta_k\pm i\gamma_k$（重数 $n_k$），且 $\sum m_k + 2\sum n_k = n$。

   * 分母分解为 $Q_n(x)=\prod(x-\alpha_k)^{m_k}\cdot\prod\left(x^2+p_kx+q_k\right)^{n_k}$，其中二次因子判别式小于零，$\beta_k=-\frac{p_k}{2}$、$\gamma_k^2=q_k-\frac{p_k^2}{4}>0$。

## 部分分式：两条定理与拆分

 * **实根剥离定理**

   * > **定义**：设 $Q(x)=(x-\alpha)^kQ_1(x)$，$Q_1(\alpha)\neq0$（否则 $\alpha$ 不止 $k$ 重），则存在实数 $\lambda$ 与多项式 $P_1(x)$，使 $\dfrac{P(x)}{Q(x)}=\dfrac{\lambda}{(x-\alpha)^k}+\dfrac{P_1(x)}{(x-\alpha)^{k-1}Q_1(x)}$，且 $\deg P_1<\deg[(x-\alpha)^{k-1}Q_1(x)]$（剩下的仍是真分式）。

   * 证明思路：令 $\lambda=\frac{P(\alpha)}{Q_1(\alpha)}$（$\neq0$），则多项式 $P(x)-\lambda Q_1(x)$ 在 $x=\alpha$ 处为零、必有因子 $x-\alpha$，两边同除 $Q(x)$ 即得。

       * > **易错点**：$P(\alpha)\neq0$——否则 $x-\alpha$ 也是分子因子，成了该约掉的公因子；这层因子还在分母里，分子在 $\alpha$ 处就必须不为零。

   * 反复套用，$k$ 层实根一层一层剥，剥一层掉出一个会积的简单分式，直到剩下 $\frac{P^*(x)}{Q_1(x)}$、$x-\alpha$ 的幂完全消失。

 * **共轭复根剥离定理**

   * 设 $Q(x)$ 有一对 $L$ 重共轭虚根 $\beta\pm i\gamma$，对应二次因子 $x^2+2\xi x+a^2$（$\xi=-\beta$，$a^2=\beta^2+\gamma^2$；判别式 $-4\gamma^2<0$，实数范围内分不动），则存在实数 $\mu$、$\nu$ 与多项式 $P^*(x)$ 使

     $$\frac{P(x)}{Q(x)}=\frac{\mu x+\nu}{\left(x^2+2\xi x+a^2\right)^{L}}+\frac{P^*(x)}{\left(x^2+2\xi x+a^2\right)^{L-1}Q^*(x)}$$

   * 关键升级：分子不再是常数，而是一次式 $\mu x+\nu$——这种形状的积分会做。

   * 证明关键：复数 $\frac{P(\beta+i\gamma)}{Q^*(\beta+i\gamma)}$ 可唯一写成 $\mu(\beta+i\gamma)+\nu$（$\mu,\nu$ 为实数，两个方程解两个未知数）；代 $\beta-i\gamma$ 相当于取共轭，实系数多项式取共轭时系数不动、$i$ 变号，故一对共轭根都是 $P(x)-(\mu x+\nu)Q^*(x)$ 的根，整除二次因子成立。

   * 剥到底得到**部分分式**：

     $$\frac{P(x)}{Q(x)}=\sum_{k}\sum_{r=1}^{m_k}\frac{\lambda_{kr}}{(x-\alpha_k)^r}+\sum_{k=1}^{J}\sum_{r=1}^{n_k}\frac{\mu_{kr}x+\nu_{kr}}{\left(x^2+2\xi_kx+a_k^2\right)^r}$$

     实根因子从一次幂排到重数次幂，一项不落；共轭虚根对同理。

 * **两种最简分式的积分**

   | 最简分式 | 处理套路 | 原函数形态 |
   | :--- | :--- | :--- |
   | $\frac{\lambda}{(x-\alpha)^n}$ | $n=1$ 出对数；$n\ge 2$ 当幂函数积 | $\ln\lvert x-\alpha\rvert$ 或 $\frac{(x-\alpha)^{-n+1}}{-n+1}$ |
   | $\frac{\mu x+\nu}{(x^2+2\xi x+a^2)^n}$ | 拆分子：导数部分进微分号；常数部分配方、换元、递推 | 对数或幂，常数部分递推到 arctan 收尾 |

   * $\int\frac{\mu x+\nu}{(x^2+2\xi x+a^2)^n}dx$ 拆分子：$\mu x+\nu=\frac{\mu}{2}(2x+2\xi)+(\nu-\mu\xi)$——一次项凑分母导数，常数项补差。

   * 导数部分：$\frac{\mu}{2}\int\frac{d(x^2+2\xi x+a^2)}{(x^2+2\xi x+a^2)^n}$，$n=1$ 出对数（二次三项式判别式小于零恒正，对数里不用绝对值），$n\ge2$ 出幂。

   * 常数部分 $I_n=\int\frac{dx}{(x^2+2\xi x+a^2)^n}$ 是整个有理函数积分里最困难的一块：配方 $x^2+2\xi x+a^2=(x+\xi)^2+(a^2-\xi^2)$，换元化成 $\int\frac{du}{(u^2+A^2)^n}$ 递推。

       * > **结论**：$I_n=\dfrac{x+\xi}{2(a^2-\xi^2)(n-1)(x^2+2\xi x+a^2)^{n-1}}+\dfrac{2n-3}{2(a^2-\xi^2)(n-1)}\,I_{n-1}$，起点 $I_1=\dfrac{1}{\sqrt{a^2-\xi^2}}\arctan\dfrac{x+\xi}{\sqrt{a^2-\xi^2}}+C$。

 * **收官命题**

   * > **结论**：有理函数的不定积分一定是初等函数，而且明确知道怎么求出来。

   * 流程：分母因式分解（实根 $(x-a)^k$、共轭复根 $(x^2+2\xi x+a^2)^L$）→ 两条定理逐层剥离得部分分式之和（系数由待定系数法确定）→ 线性性放行逐项积分（幂/对数、凑微分、配方 + 递推 + arctan）→ 原函数为初等函数。

   * $n$ 大时递推一层层降次手算量很大，但麻烦是计算量问题，不是理论问题——理论上一定求得出来。

## 待定系数法实战

 * **例：四参数全由代值与比系数定出**

   * $\int\frac{4x^3-13x^2+3x+8}{(x+1)(x-2)(x-1)^2}\,dx$：$x-1$ 是二重因子，按定理样式从一次幂排到重数次幂，架子为 $\frac{A}{x+1}+\frac{B}{x-2}+\frac{C}{x-1}+\frac{D}{(x-1)^2}$。

   * 去分母得恒等式（对一切 $x$ 成立）后，经验是**尽可能不解方程组**，代特殊值：代 $x=-1$ 定 $A=1$，代 $x=2$ 定 $B=-2$，代 $x=1$ 定 $D=-1$——每次代入让最多的项当场消失。

   * 没有新根可代时比最高次项系数：右边三项首项系数恰为 $A$、$B$、$C$（$D$ 那项最高二次插不上话），$4=A+B+C$ 定 $C=5$。

       * > **提示**：比较系数时挑最高次项——$x^2$、$x$ 的系数算起来比 $x^3$ 讨厌，别自找麻烦。

   * 逐项积分：$\ln|x+1|-2\ln|x-2|+5\ln|x-1|+\frac{1}{x-1}+C$；对数前的系数放哪儿都行（$-2\ln|x-2|$ 即 $\ln|x-2|^{-2}$），卷面保持一种写法。

 * **例：虚根代入一顶两方程**

   * $\int\frac{x^4+x^3+3x^2-1}{(x^2+1)^2(x-1)}\,dx$：架子 $\frac{A}{x-1}+\frac{Bx+C}{x^2+1}+\frac{Dx+E}{(x^2+1)^2}$——二次因子 $x^2+1$ 重数 2，从一次幂排到平方，每层配一次分子。

   * 代 $x=1$ 定 $A=1$；代 $x=i$：含 $(x^2+1)$ 的项全消失，两边是复数，实部虚部分别相等，一次代入赚回两个方程，定 $D=2$、$E=1$。

   * 剩下比较 $x^4$、$x^3$ 系数定 $B=0$、$C=1$；分解为 $\frac{1}{x-1}+\frac{1}{x^2+1}+\frac{2x+1}{(x^2+1)^2}$。

   * 第三块拆两半：$\frac{2x}{(x^2+1)^2}$ 分子恰是分母导数，进微分号得 $-\frac{1}{x^2+1}$；$\int\frac{dx}{(x^2+1)^2}$ 造分子 $1=(1+x^2)-x^2$，第二项里 $\frac{x\,dx}{(x^2+1)^2}=-\frac12\,d\!\left(\frac{1}{x^2+1}\right)$，分部一次转回 $\arctan x$。

   * 合并（$\arctan x$ 出现两次，整份加二分之一）：$\ln|x-1|+\frac32\arctan x-\frac{1}{x^2+1}+\frac{x}{2(x^2+1)}+C$。

   * 节奏：先把「一击致命」的特殊值代完，剩下的零头用比较系数补齐——比解五元一次方程组方便。

   * 总口径：复杂有理函数求不定积分两步走——先部分分式化成简单分式之和（代数功夫），再逐项积分（积分功夫）。

## 可化为有理函数的积分：根式代换

 * **两个变量的有理函数**

   * > **定义**：$R(u,v)$ 是关于 $u,v$ 的有理函数，指 $R(u,v)=\dfrac{P(u,v)}{Q(u,v)}$，其中 $P$、$Q$ 都是关于 $u,v$ 的多项式（两个变量加加乘乘在一起）。

 * **一次分式的根式：必定走得通的代换**

   * 对 $\int R\left(x,\sqrt[n]{\frac{\alpha x+\beta}{mx+\nu}}\right)dx$：令 $t=\sqrt[n]{\frac{\alpha x+\beta}{mx+\nu}}$，两边取 $n$ 次方解出 $x=\dfrac{\beta-\nu t^n}{m t^n-\alpha}=\varphi(t)$——$t$ 的有理函数。

   * $dx=\varphi'(t)\,dt$（仍是有理函数），根式代换后恰好就是 $t$ 本身、一丝根号不剩，整体化为 $t$ 的有理函数积分，必积；积完把 $t$ 用根式带回去。

       * > **结论**：只要根号里是一次分式，代换 $t=\sqrt[n]{\dfrac{\alpha x+\beta}{mx+\nu}}$ 必能把原积分化成有理函数的积分；这条路必定走得通，差别只在计算量。

       * > **易错点**：换元要换全套——$x$ 写成 $t$ 的函数之外，$dx$ 也要写成对 $t$ 的导数再乘 $dt$；漏了 $dx$ 这步，代换没有完成。

   * 分母退化成常数的特例：根式退化成根号下的一次式（如 $\sqrt{4x-3}$），落进同一类型。$\int\frac{x\,dx}{\sqrt{4x-3}}$：令 $t=\sqrt{4x-3}$，$x=\frac{t^2+3}{4}$，$dx=\frac{t}{2}\,dt$，分母的 $t$ 与 $dx$ 里的 $t$ 消掉，结果 $\frac{\sqrt{4x-3}\,(4x+6)}{24}+C$。

 * **不同次根式并存：取根指数公倍数**

   * $\int\frac{dx}{x\sqrt[3]{x}-x\sqrt{x}}$：一个代换只干得掉一个根式，取 2 和 3 的公倍数 6，令 $t=\sqrt[6]{x}$，$x=t^6$，两个根同时消掉（$\sqrt[3]{x}=t^2$、$\sqrt x=t^3$），$dx=6t^5\,dt$。

   * 化为 $6\int\frac{dt}{t^3(1-t)}$ 后拆部分分式：复杂问题老实待定系数法，简单场合可心算凑——盯住总分子，$\frac{1-t^3}{ }$ 那份由 $(1-t)(1+t+t^2)=1-t^3$ 顶上，故 $\frac{1}{t^3(1-t)}=\frac1t+\frac{1}{t^2}+\frac{1}{t^3}+\frac{1}{1-t}$。

   * 结果：$6\ln\left|\frac{\sqrt[6]{x}}{1-\sqrt[6]{x}}\right|-\frac{6}{\sqrt[6]{x}}-\frac{3}{\sqrt[3]{x}}+C$。

       * > **易错点**：几种不同次的根式同时出现时，代换次数取各根指数的公倍数，一次把根式全部消灭；只按其中一个设代换，另一个根式原样留着，代换白做。

 * **两个根式能合并：先拧成一个**

   * $\int\frac{\sqrt{1+x}}{x\sqrt{1-x}}\,dx$：$\frac{\sqrt{1+x}}{\sqrt{1-x}}=\sqrt{\frac{1+x}{1-x}}$ 恰是根号里的一次分式（$n=2$），令 $t=\sqrt{\frac{1+x}{1-x}}$。

   * 解出 $x=\frac{t^2-1}{t^2+1}$，$dx=\frac{4t}{(t^2+1)^2}\,dt$，化为 $\int\frac{4t^2}{(t^2-1)(t^2+1)}\,dt$；心算拆 $\frac{1}{t^2-1}+\frac{1}{t^2+1}=\frac{2t^2}{(t^2-1)(t^2+1)}$，故要拆的正是它的两倍。

   * 结果：$\ln\left|\frac{\sqrt{1+x}-\sqrt{1-x}}{\sqrt{1+x}+\sqrt{1-x}}\right|+2\arctan\sqrt{\frac{1+x}{1-x}}+C$。

       * > **提示**：拿到带根式的积分先端详根式的长相——两个根式能并成一个「根号下的一次分式」就按那套代换走；并不成、又是不同次的，就取根指数的公倍数另设代换。

 * **幂次之和是根指数的倍数**

   * $\sqrt[n]{(\alpha x+\beta)^i(mx+\nu)^j}$ 且 $i+j=kn$：$i$、$j$ 单独都不是 $n$ 的倍数（谁也拉不出根号），但借足次数改写为 $(\alpha x+\beta)^k\sqrt[n]{\left(\frac{mx+\nu}{\alpha x+\beta}\right)^{j}}$——前一半整个拉出根号成多项式，剩下的是一次分式 $n$ 次根的 $j$ 次幂（分子分母对调，仍是那个类型），令 $t$ 照样有理化。

   * 实例 $\int\frac{dx}{\sqrt[3]{(x-1)^2(x+1)^4}}$：$2+4=6$ 是 3 的倍数，提出 $(x+1)^2$，令 $t=\sqrt[3]{\frac{x+1}{x-1}}$，解出 $x=\frac{t^3+1}{t^3-1}$、$dx=\frac{-6t^2}{(t^3-1)^2}dt$，约分后只剩 $\int-\frac{3}{2t^2}\,dt=\frac{3}{2t}+C$，回代得 $\frac32\sqrt[3]{\frac{x-1}{x+1}}+C$。

   * 根式一族的信条同一句：把根号划掉，一切回到有理函数。

   | 根式的长相 | 处置办法 | 化归结果 |
   | :--- | :--- | :--- |
   | 根号下是一次分式 $\frac{\alpha x+\beta}{mx+\nu}$ | 令 $t=\sqrt[n]{\frac{\alpha x+\beta}{mx+\nu}}$，反解出 $x=\varphi(t)$ | $t$ 的有理函数 |
   | 不同次的根式并存（如 $\sqrt[3]{x}$ 与 $\sqrt{x}$） | 次数取根指数的公倍数（如 $t=\sqrt[6]{x}$） | $t$ 的有理函数 |
   | 两个根式能合并（如 $\frac{\sqrt{1+x}}{\sqrt{1-x}}$） | 先并成 $\sqrt{\frac{1+x}{1-x}}$，再按第一行办 | $t$ 的有理函数 |
   | $\sqrt[n]{(\alpha x+\beta)^i(mx+\nu)^j}$ 且 $i+j=kn$ | 提出 $(\alpha x+\beta)^k$，归入第一行 | $t$ 的有理函数 |

## 万能代换

 * **覆盖范围与公式**

   * $R(\sin x,\cos x)$ 指 $\sin x$ 与 $\cos x$ 的有理函数；$\tan x=\frac{\sin x}{\cos x}$、$\cot x=\frac{\cos x}{\sin x}$、$\sec x=\frac{1}{\cos x}$、$\csc x=\frac{1}{\sin x}$ 全是它们的有理式，所以这个记号覆盖**全部**三角函数的有理函数。

   * > **定义**：万能代换——令 $t=\tan\frac{x}{2}$（即 $x=2\arctan t$），则

     $$\sin x=\frac{2t}{1+t^2},\qquad \cos x=\frac{1-t^2}{1+t^2},\qquad dx=\frac{2}{1+t^2}\,dt.$$

   * 公式不用死背，条条能推：$\sin x=2\sin\frac x2\cos\frac x2$ 分子分母同除 $\cos^2\frac x2$，分子成 $2t$、分母翻上去是 $1+t^2$；$\cos x=\cos^2\frac x2-\sin^2\frac x2$ 同样一除；$dx$ 对 $x=2\arctan t$ 求导即得。

   * 代入后三角函数没了，只剩 $t$ 的有理函数——必积；积完 $t=\tan\frac{x}{2}$ 代回。三角函数的有理函数因此**都能解决**。

 * **实战**

   * $\int\frac{dx}{4\sin x+\cos x+4}$：令 $t=\tan\frac x2$，分母通到 $1+t^2$ 上成 $\frac{3t^2+8t+5}{1+t^2}$，约去后得 $\int\frac{2\,dt}{3t^2+8t+5}$；判别式 $4>0$ 因式分解 $(3t+5)(t+1)$，两项**必是相减**（相加则分子 $t$ 的一次项消不掉），$(3t+5)-3(t+1)=2$，结果 $\ln\left|\tan\frac{x}{2}+1\right|-\ln\left|3\tan\frac{x}{2}+5\right|+C$。

   * 拆分时 $3\,dt=d(3t+5)$，$\int\frac{3\,dt}{3t+5}=\ln|3t+5|$，前面不再留系数。

 * **迫不得已才用**

   * 有别的办法尽量用别的办法，想了别的办法都做不出来才用万能代换——它公式多、负号多，错一个负号全盘皆输。

   * 同一道题 $\int\frac{\cot x}{1+\sin x}\,dx$ 两种解法对比：

     | 对比项 | 万能代换 | 凑微分 |
     | :--- | :--- | :--- |
     | 换元 | $t=\tan\frac{x}{2}$，$\sin,\cos,\cot,dx$ 四套公式 | $u=\sin x$，一个 $d(\sin x)$ 就够 |
     | 化简量 | 通分、约分、凑分子，步步小心 | 一步拆分，通分口算可验 |
     | 出错概率 | 高——错一个负号全盘皆输 | 低——没有复杂计算 |

   * 凑微分解法：$\cot x=\frac{\cos x}{\sin x}$，$\cos x\,dx=d(\sin x)$，令 $u=\sin x$ 化为 $\int\frac{du}{u(1+u)}=\int\left(\frac1u-\frac{1}{1+u}\right)du$，结果 $\ln|\sin x|-\ln(1+\sin x)+C$。

       * > **易错点**：不同方法得到的不同表达式不一定是恒等式，但可以相差一个常数——两个都可能对；验证的办法是求导，不是急着认定谁错了。

## 定积分的思想源头

 * **积分学思想的三个来源**

   * 古希腊穷竭法：阿基米德用穷竭法计算抛物线拱形（曲边三角形）的面积。

   * 中国古代：刘徽割圆术——用圆内接正 $N$ 边形近似代替圆，$N$ 趋于无穷大时正多边形与圆合为一体。

   * 十七世纪开普勒：创造性地发展穷竭法用于各种面积、体积计算，著书算酒桶体积，据说算了 87 种形状的旋转体体积；微积分学科最后由牛顿与莱布尼茨建立。

   * 开普勒三大定律：轨道是椭圆、太阳位于一个焦点；向径在相同时间里扫过的面积相同（速度不是常数）；周期平方与椭圆半长轴立方成正比。牛顿利用三大定律严格推导出万有引力定律。

 * **穷竭法四步**

   ```text
   划分：把要算的图形切成 N 小块
     ↓
   近似：每一小块用会算的图形代替（单块仍算不准）
     ↓
   求和：N 个近似值加起来 —— 只是近似值
     ↓
   取极限：N 趋于无穷大，近似值变精确值
   ```

   * 开普勒第二定律的面积算法：把扇形分成许多小扇形——小扇形那条边是椭圆弧仍不能求，但顶角很小可近似当圆扇形（有公式）；全部加起来，$N$ 取无穷大近似变精确。

 * **不定积分与定积分的界线**

   * 不定积分是导数的反问题（已知导数还原函数），挂在微分学一边；严格地说，积分学从定积分这一节才开始。

 * **穷竭法实战：$y=x^2$ 下的曲边三角形**

   * 求 $y=x^2$、$x$ 轴与直线 $x=1$ 围成的面积：令 $h=\frac1N$，分点 $x_i=\frac{i}{N}$（$i=0,1,\dots,N$），切成 $N$ 个细条；每条顶上是抛物线弧，单条不会算。

   * 每条作两个矩形：高取左端点 $\left(\frac{i-1}{N}\right)^2$ 的比真实面积小，高取右端点 $\left(\frac{i}{N}\right)^2$ 的比真实面积大；求和得 $S'_N=\frac{1}{N^3}\sum_{i=1}^{N}(i-1)^2$ 与 $S''_N=\frac{1}{N^3}\sum_{i=1}^{N}i^2$，夹住真值 $S'_N<S<S''_N$。

   * 平方和公式 $\sum_{i=1}^{N}i^2=\frac{N(N+1)(2N+1)}{6}$：代入后分子主部都是 $2N^3$，两个极限都是 $\frac13$，夹逼得 $S=\frac13$。

   * 任取版本：每个小区间里**任取** $\xi_i$（取哪都行），以 $\xi_i^2$ 为高作和 $\sigma_N=\sum_{i=1}^{N}\frac1N\xi_i^2$，由 $\left(\frac{i-1}{N}\right)^2\le\xi_i^2\le\left(\frac{i}{N}\right)^2$ 夹在 $S'_N$ 与 $S''_N$ 之间，极限同样是 $\frac13$；$\xi_i$ 怎么取都不影响极限值。

       * > **结论**：划分 → 近似代替（任取 $\xi_i$）→ 求和 → 取极限——近似值在 $N\to\infty$ 时逼成精确值，这就是定积分的全部思想。
