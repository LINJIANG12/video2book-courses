## 怎么学

- **按"定义—定理—证明—反例"四件套学**：数学分析的功夫在证明，光记结论会在 ε-δ 题上卡住。
- **ε-N 与 ε-δ 语言要反复写**：数列极限、函数极限、一致连续都用同一套量词结构，练到能自己改写。
- **顺序不能跳**：实数完备性 → 极限 → 连续 → 微分 → 积分 → 级数，每一层都拿上一层当工具。
- **多元部分抓"降维与换元"**：偏导、全微分、重积分、曲线曲面积分，核心都是把多元问题化成一元或标准形。
- **场论三大公式统一看**：Green、Gauss、Stokes 用微分形式串起来，比分别背公式更稳。
- **每章先动手再做例题**：证明题先写自己的思路，再对照课程里的构造与放缩。
