# 由果推因、因果比较与实验型秒杀

## 因果方向与结构识别

* **由果推因**

    * > **定义**：先出现结果 $B$，再把 $B$ 归因于 $A$，即由“A 与 B 同时存在”推出“$A$ 导致 $B$”。

    * 削弱的核心是解释已经发生的结果：找出真正造成 $B$ 的另一原因 $C$，使“$A$ 导致 $B$”失去唯一解释权。

    * 也可以直接否定原联系，如指出 $A$ 根本产生不了 $B$、必要作用条件不存在，或用“同因不同果”揭穿联系。

* **由因推果**

    * > **定义**：先给出原因或措施 $A$，再推出结果 $B$，即讨论“采取 $A$ 能否带来 $B$”。

    * 削弱时应给结果设置障碍：引入 $C$ 使 $B$ 无法成立，而不是说明“换一种方式也能得到 $B$”。

    * “坐火车能到北京”被“坐飞机也能到”否定，是因为替代路径不能排除火车；由果推因则要给已发生的“到达北京”另找真实原因。

* **方向判定**

    * 先问题干是“先做某事”还是“先出现某结果”：前者是因在果前，后者是果在因前。

    * 再问要破坏的结论是什么：“$A$ 能否带来 $B$”与“$B$ 是否由 $A$ 造成”不能混答。

    * > **易错点**：削弱时必须辨清方向；支持或假设只需加强题干所述联系，不必先争论属于由因推果还是由果推因。

| 结构 | 题干真正追问 | 有效削弱 | 常见无效项 |
| :--- | :--- | :--- | :--- |
| 由果推因 | $B$ 是不是由 $A$ 造成 | 真实发生的另一原因 $C$ 也能造成同一 $B$ | 只说 $C$ 理论上可能造成 $B$ |
| 由因推果 | $A$ 能不能带来 $B$ | $C$ 使 $B$ 不能成立 | 只说其他方式也能带来 $B$ |

## 由果推因的替身机制

* **真实他因**

    * > **定义**：标准由果推因削弱，是给已经发生的结果安排一个新的“背锅侠”；新原因必须实际造成该结果，并在概念上独立于题干所称原因。

    * 替身不必让旧原因彻底为假；只要证明“即使旧原因成立，仍有另一个足以产生结果的原因”，原归因就失去唯一性。

    * 在对比实验中，新原因必须真实出现在这次试验里，不能只给出一般规律或理论可能性。

* **三项对应检查**

    * **同一结果**：新原因解释的必须是题干正在讨论的那个结果，不能只解释相关现象。

    * **同一主体**：新原因必须发生在题干讨论的同一批人、同一地区、同一物种或同一时期。

    * **真实发生**：具体人物、具体试验和具体时段中的“当时发生”强于“通常、可能、理论上”。

| 检查 | 有效信息 | 无效或不足信息 |
| :--- | :--- | :--- |
| 结果对应 | 新原因直接解释目标结果 | 只解释原因、后果或邻近指标 |
| 主体对应 | 落在题干这批对象身上 | 换成相关但未进入题干的另一批对象 |
| 时空对应 | 在题干所指时期或实验中发生 | 只说一般情况下可能发生 |
| 原因独立 | 与原原因属于不同解释链 | 仍在原原因链条中，只换主语或描述其后果 |

* **他因不是反命题**

    * “肥料过期”不能自动推出“过期肥料一定无效”，要真正削弱高产由肥料造成，必须给出土质差异等真实替代原因。

    * “肉还在保质期内”没有解释腹泻；同一个人确实吃了另一种导致腹泻的食物，才构成替身。

    * 排除一个旧原因，不等于直接断言旧原因的反命题；标准动作是找到另一个对同一结果有解释力的原因。

* **多段叙述只拆关键推理**

    * 长题干可能同时包含“先解释原因”和“再推出后果”两段，只需锁定核心结果和被归因的那条联系。

    * 一个选项只要有效破坏其中一个关键因果，就能完成反驳，不必把题干所有句子全部否定。

    * 题干出现“因此”不代表选项就是有效他因；还要确认选项是否真的提供了独立原因，而不是顺着结果写评价、谈影响或谈别的对象。

* **识别不等于作答模板**

    * 由果推因结构不与“他因”选项一一对应；存在匹配他因时可直接选，没有匹配他因时仍可检查直接反驳。

    * 同一因在不同条件下出现不同结果、同一结果在相同原因下仍有差异，都可能破坏原联系。

    * > **易错点**：选项只要需要再补一句“也就是说……”才能接上题干，就先检查主体、时期、范围和修饰对象，不能替选项脑补缺失剧情。

## 实验型因果的基本框架

* **实验结构**

    * > **定义**：实验型因果题通常呈现“有 $A$ 有 $B$，无 $A$ 无 $B$”，再把两组差异归因于 $A$；实验包装本质上仍是“结果在先，再解释原因”。

    * 观察到的对应关系只说明相关，不能自动证明 $A \rightarrow B$。

    * 实验题存在两个最常见的缺口：实验前起点不同，或两组同时还做了其他能够造成 $B$ 的事情。

* **削弱与支持的两个方向**

    * 削弱不必证明“$A$ 完全没用”，只要指出结果差异可能另有来源即可。

    * 支持也不必重复“有 $A$ 有 $B$”，只要堵住“起点不同”和“另有他因”两个解释口子。

    * 试验组与对照组不是天然可信的比较；实验设计是否把除 $A$ 以外的条件控制一致，才决定差异能否归因于 $A$。

* **实验条件三查**

    * **起点查**：采取干预之前，两组在结果指标及与处理因素直接相关的基线上是否一致。

    * **变量查**：除了研究变量 $A$，两组是否还有其他差异同时变化。

    * **指标查**：测得的指标能否代表结论所说的完整结果。

    * 看到“实验前做过检测”不等于信息充分；只有“实验前检测结果相同或无明显差异”才提供起点信息。

* **指标不能偷换结论**

    * 若论据只测血糖，结论却直接说“整体健康水平”，血糖相同不等于健康水平相同。

    * 其他疾病指标可能更好，说明实验变量可能抵消了另一些坏影响，仍能削弱“全麦面包不比白面包更健康”。

    * 反过来，个体对某物过敏只说明该个体不能使用，不能证明它对整体人群无效。

* **群体结果与个体结果**

    * 实验比较的通常是比例、平均值或整体趋势，单独一个成员的结果不能推翻总体结论。

    * 结论若只说“风险提高”“概率上升”，没有说每个人必然发生；用“未必人人如此”不能否定概率结论。

    * > **易错点**：题干讨论平均效果时，不要拿一个个例反驳；题干讨论某类人时，也不要改拿未被研究的对象作比较。

## 比较起点与同一起跑线

* **基线相同**

    * > **定义**：比较之前起点相同，是指两组在实验、训练或措施发生前，与目标结果直接相关的基础水平一致或没有明显差异。

    * 基线相同而结果不同，支持“措施 $A$ 导致结果 $B$”。

    * 基线不同而结果不同，说明差异可能早已存在，不能直接归功于措施 $A$。

    * 两组在措施之外还有其他共同影响因素，也会使结果差异无法唯一归因于 $A$。

| 比较前或比较中的情况 | 对“$A$ 导致 $B$”的影响 |
| :--- | :--- |
| 两组相关基线相同 | 支持 |
| 两组原有基础不同 | 削弱 |
| 两组除 $A$ 外其他条件相同 | 支持 |
| 两组还做了其他足以影响 $B$ 的事 | 削弱 |

* **比较对象**

    * 最可靠的比较是同一群体在干预前后的变化，或干预组与对照组各自干预前后的变化。

    * “最终结果相同”不等于“措施无效”；一个高起点组降到与低起点组相同，可能说明措施正在弥补原有差距。

    * 专业组与普通人比较时，要确认专业组开始训练前与普通人没有相关结构差异，不能只看训练后的终点。

    * 只比较专业组内部是否一致，不等于完成“专业组与非专业组”的比较；只说普通人也参加过某些训练，也不能说明差异在训练前就已存在。

* **基线不只看一个表面数字**

    * **整体基线**：两组原有的健康、记忆、身体机能、应激反应等是否相同。

    * **因素专属基线**：研究叶酸对中风风险的影响，还要看两组原有的叶酸水平；同样剂量对“严重缺乏者”和“不缺乏者”效果可能不同。

    * **状态与时空基线**：婴儿实验若分别在不同时间、地点进行，饥饿、睡眠和环境状态就可能混入结果。

    * **数值例型**：叶酸组中风概率为 $2.7\%$，不含叶酸组为 $3.4\%$；支持该结论需要补上两组原有叶酸水平无明显差异，而不只是“都做过检测”。

    * **方向例型**：步行组年龄更大却恢复得更远，起点方向更不利，反而可能支持步行；若年龄更小的一组走得更远，才是起点不同削弱。

* **起点不同如何解释表面矛盾**

    * 严查酒驾城市与不严查城市当前事故率相同，不足以说明严查无效。

    * 若严查城市原本事故率更高，严查后降到与另一城市相同，相同终点可能正来自不同起点。

    * 水果实验中，亚洲人风险下降 $34\%$、欧洲人下降 $25\%$；若亚洲人平时摄入水果更少，补充幅度更大，效果差异可能来自原始摄入起点，而非体质。

* **概率结论与个体差异**

    * 早餐实验讨论的是男女“增重概率变高”，不是每个人必然增重。

    * “某人不吃早餐也增重”或“不吃早餐不一定增重”没有直接否定概率结论。

    * “对女性影响不大”也不能直接改成“没有影响”；只要数据仍显示风险上升，就不能抹去作用。

    * > **易错点**：“不完全相同”不等于“存在足以解释结果的明显差异”。只有明确指出差异方向、相关基线和足以造成结果的程度，才构成有效起点削弱。

## 没有做与做了的差异

* **反事实比较**

    * > **定义**：“如果没有……”是在比较“做了 $A$”与“不做 $A$”两种条件下的结果，而不是只看是否跨过某条及格线或达标线。

    * 做了以后仍不及格、仍有疾病或仍然晒黑，不能脱离“不做时如何”直接断言 $A$ 无效。

    * 防晒霜、家教、药物和训练的作用都应看它把结果向有利方向移动了多少。

* **反事实结论**

| 假设不做 $A$ 时的结果 | 对“$A$ 有效”的含义 |
| :--- | :--- |
| 比现在更差 | $A$ 仍有效果，支持 |
| 与现在差不多 | $A$ 可能无效，削弱 |
| 比现在更好 | $A$ 可能产生反效果，强烈削弱 |

* **质变与量变**

    * 没有发生质变，不等于没有量变；及格与不及格是质变，成绩提高多少是量变。

    * 训练后仍不及格，可以被“不训练会更差”削弱，因为训练把成绩向上托了，只是没有跨过及格线。

    * 同理，不吃药只能活一年、服药后活三年，药物仍可能有效；不能只因患者最终去世就否定治疗作用。

* **跨人反事实的起点条件**

    * 用“另一个相似对象没做 $A$”代替同一个人“不做 $A$”时，必须先确认两者条件相同或相近。

    * 乐乐没参加体能训练仍不及格，不能自动搬到起点未受控的小刘身上。

    * 有效的跨人比较应明确：与乐乐身体素质相同的人若不参加训练会怎样。

    * > **提示**：看到“如果不参加”“没有实行”“不用某物”，先锁定做与不做之间的方向，再检查选项是否把不做的结果说成更差、差不多或更好。

## 第三者建立因果联系

* **直接原因排除第三者**

    * > **定义**：题干承认原因 $A$ 直接导致结果 $B$，于是断言 $C$ 与 $B$ 无关；削弱时不能只找另一个导致 $B$ 的原因，而要建立 $C \rightarrow A \rightarrow B$。

    * “$C$ 不会直接影响 $B$”只排除了直接作用，不能排除 $C$ 通过中间环节影响 $B$。

    * $A$ 在削弱中就是连接 $C$ 与 $B$ 的第三者；只要补上“$C$ 导致 $A$”，被排除的关系就能重新接回。

* **常见因果链**

| 被排除的原因 | 直接原因 | 所需中间链 |
| :--- | :--- | :--- |
| 消极情绪 | 自主神经变化引发哮喘 | 消极情绪 → 自主神经变化 → 哮喘 |
| 营养不均衡 | 毛囊受损导致脱发 | 营养不均衡 → 毛囊受损 → 脱发 |
| 胶原蛋白 | 表皮干细胞更新使皮肤年轻 | 胶原蛋白 → 干细胞更新 → 皮肤年轻 |
| 脑部 DNA 变异 | 杏仁核活动增加引发疾病 | DNA 变异 → 杏仁核活动增加 → 抑郁症、焦虑症 |
| 全球变暖 | 大气环流影响高温 | 全球变暖 → 改变大气环流 → 改变极端天气强度 |
| 污水 | 直接伤害螃蟹 | 污水 → 蓝藻死亡 → 幼蟹缺食 → 螃蟹减少 |
| 盐度增加 | 直接伤害幼虾 | 高盐 → 有机物难以存活 → 幼虾缺食 → 养虾场损失 |

* **有效连接与无效干扰**

    * 有效项准确说明“被排除者导致直接原因”，或说明“被排除者通过某中间环节影响结果”。

    * 另找一个直接导致 $B$ 的原因，只能说明可能有他因，不能证明题干比较的 $C$ 与 $B$ 无关是错的。

    * 两个现象同时出现只是相关，不能替代一条具体的因果路径。

    * 只比较某一类对象内部谁更重要，没有回答该类对象整体是否起作用。

    * 方向反成“结果导致直接原因”会接到相反链条；“有直接也有间接”“原因复杂”“因人而异”都没有给出具体联系。

    * > **易错点**：第三者不必是最先出现的那个原因，它可以是连接被排除原因与结果的中间环节；真正要找的是“$C$ 能否改变 $A$ 或通往 $B$”。

* **替代办法的必要依赖**

    * > **定义**：题干由“新办法 $X$ 可以实现目标 $Y$”推出“旧办法 $Z$ 不再需要”；削弱方式是指出“实现 $X$ 必须依赖 $Z$”。

    * 替代形式能实现目标，只说明存在另一种选择，不能说明旧条件失去必要性。

    * 人造牛肉要获取牛身上的干细胞，因此不能推出人类以后不再养牛。

    * 网上词义由词典提供数据，因此改用网络检索不等于词典不再需要。

    * 相应电子图书通常以纸质图书出版为前提，因此纸质书不能被完全取消。

    * 新办法成本高、口感差、存在使用障碍或旧办法仍有优点，都不能证明旧办法是新办法实现的必要条件。

## 因果倒置与共同他因

* **直接因果倒置**

    * > **定义**：题干由 $A$ 与 $B$ 同时存在推出 $A \rightarrow B$，直接倒置选项则指出 $B \rightarrow A$，即结果才是原因。

    * 削弱题先找“具备 $B$ 的人反而更常具有 $A$”这一标准形状。

    * “改变 $A$ 就能改变 $B$”与“$A$ 是 $B$ 的原因”结构相同；若结论主张减少或治疗 $A$ 能改善 $B$，假设就包括排除 $B$ 导致 $A$。

    * 假设题问“结论依赖的假设”时，说明 $A$ 是原因、不是 $B$ 造成的结果，就能排除倒置并支持干预结论。

* **共同他因**

    * > **定义**：共同他因是第三因素 $C$ 同时导致 $A$ 与 $B$，使二者虽然相关，却未必存在 $A \rightarrow B$ 的直接关系。

    * 共同他因是因果倒置的变形：不一定出现 $B \rightarrow A$，只需解释为什么 $A$ 与 $B$ 总是同时出现。

    * 问削弱时，共同他因能架空 $A \rightarrow B$；问支持时，应改找“$A$ 如何影响 $B$”的作用机制。

* **题目方向**

| 设问 | 优先寻找 |
| :--- | :--- |
| 削弱 | $B \rightarrow A$，或 $C$ 同时导致 $A$、$B$ |
| 支持 | $A$ 的作用机制最终到达 $B$，或“没有 $A$ 就没有 $B$” |
| 假设 | 排除 $B \rightarrow A$，坐实 $A \rightarrow B$ |

* **直接倒置例型**

| 题干中的 $A$ 与 $B$ | 倒置关系 |
| :--- | :--- |
| 常喝咖啡与心脏病 | 心脏病患者特别爱喝咖啡 |
| 关门窗与睡眠质量差 | 睡眠质量差的人更喜欢关窗 |
| 使用社交软件与健康 | 身体健康的人会在工作之余使用社交软件 |
| 饲养宠物与家庭幸福感 | 有时间且已有幸福感的家庭才会养宠物 |
| 晚睡与认知表现好 | 认知表现好的人睡眠质量高，所以选择晚睡 |
| 社交媒体时长与孤独 | 更容易孤独的人更喜欢使用社交媒体 |
| 方向感与嗅觉 | 嗅觉进化有利于导航，嗅觉灵敏反而支持方向感 |
| 部落战争与男女比例失调 | 男性先大量死亡造成劳动力不足，失调继而引发战争 |

* **共同他因例型**

| $A$ 与 $B$ | 共同因素 $C$ |
| :--- | :--- |
| 地球转速放缓与强震增多 | 地核轻微变化同时导致二者 |
| 长期应激与疼痛慢性化 | 焦虑倾向同时带来高应激与更高慢性化发生率 |
| 为他人花钱与幸福感 | 与他人关系好同时带来较高花费比例和较强幸福感 |
| 掌握两种语言与延缓痴呆 | 认知功能好同时使人更易学习双语，也更能延缓痴呆 |

* **标准倒置优先**

    * 题目一旦给出标准倒置，应先检查它是否严格对应 $B$ 导致 $A$，不要继续给含混选项补因果剧情。

    * > **易错点**：共同出现只说明相关，不能自行决定因果方向；选项若只重复“有关”，仍未回答谁是因、谁是果。

---

## 因果倒置的识别与排除

* **相关与因果方向**

    * “脑组织铝含量与病情严重程度有关”仍可能只是相关性，不能区分铝导致痴呆还是痴呆带来铝含量变化。

    * “焦虑倾向同时带来高应激与更高的疼痛慢性化率”不是两条独立机制，而是共同因素同时造成两个结果。

    * 问支持时，要找“$A$ 的作用影响 $B$”；问削弱时，才优先找倒置或共同他因。

* **程度与概念偷换**

    * “使用社交软件”不等于“长时间使用电脑或手机”，题干没有“长时间”就不能补上。

    * “长期应激”对应时间长短，“缓解应激”对应程度高低；缓解不等于从来没有长期应激。

    * 镁离子含量“高”与镁离子“有”是两个概念，讨论高低不能用“正常狗没有镁离子”替代。

    * “关窗不适合所有房间”只说不普遍适用，不等于关窗对适合的房间没有作用。

* **比较范围**

    * 题目讨论使用社交软件的人，就不能用不用社交软件者的状况反驳。

    * 题目讨论掌握两种语言的人，就不用讨论只掌握一种语言却未患痴呆的人。

    * 题目讨论“被狗咬伤”而非“被狗咬伤致死”，增加致死、严重程度等限定就换了问题。

* **表面相关项**

    * “样本数量不足”轻易不选；统计结论首先取决于抽样是否随机、是否有代表性，而不是样本数量单一指标。

    * 药物不需要“不会产生任何副作用”这种绝对保证；不同阶段需要不同剂量、剂量与年龄相关，也不直接回答药物能否治病。

    * “居住条件好就必然幸福”“繁忙就必然不幸福”“生活满意度低就必然孤独”“精力不济就必然认知差”都属于题干未提供的脑补链。

    * “有待商榷”“受多因素影响”“因人而异”如果没有给出具体方向和联系，信息近乎没有。

## “只有……才……”的方向

* **必要条件表达**

    * > **定义**：“只有 $A$ 才 $B$”表示 $B \rightarrow A$，即实行 $B$ 是出现 $A$ 的必要条件。

    * 生活语感容易把它读成“$A$ 所以 $B$”，但逻辑题必须服从文字结构，不能擅自把箭头调换。

* **削弱路径**

    * 削弱 $B \rightarrow A$，只需找到“前件真、后件假”：$A$ 成立而 $B$ 不成立。

    * 若“只有经济增长才实行责任制”成立，经济增长并不要求一定实行责任制；找到“经济增长但未实行责任制”即可否定必要条件。

    * 行业形势导致经济增长是在解释 $A$ 的成因，不是在判断“是否实行 $B$”是否为 $A$ 的必要条件。

    * 责任制调动员工积极性是在说明 $B$ 的作用，不等于回答“$A$ 能否推出 $B$”。

* **对象与结论范围**

    * 用乙公司否定只针对甲公司的结论，必须先证明乙公司与甲公司足够相似，或把原结论扩大到所有公司。

    * > **易错点**：“只有……才……”固定按后件推前件处理；削弱时寻找“必要条件不存在”，不能凭生活直觉改成充分条件。

## 评价题的两面判断

* **评价结构**

    * > **定义**：评价题不直接要求支持或削弱，而是提出一个关键问题；答案若支持原结论，结论成立，若削弱原结论，结论不成立。

    * 读选项时先问“答案改变后，结论是否跟着改变”，而不是看问题是否专业、复杂或听起来贴近主题。

* **评价问题的两种形式**

    * **他因问题**：除研究因素外，是否还有别的原因造成结果差异？有则削弱，没有则支持。

    * **移植问题**：让另一对象采取同一措施后，能否得到相同或明显不同的结果？能则支持，不能则削弱。

* **评价方向**

| 关键问题的答案 | 对结论的影响 |
| :--- | :--- |
| 能证明措施造成差异，或排除其他解释 | 支持 |
| 仍可能有其他解释，或措施不能造成同样差异 | 削弱 |

* **评价例型**

    * 空气质量较好若源于措施更有效，可以问：另一城市有没有其他原因导致空气质量差？

    * 也可以问：另一城市采用同样措施后，空气质量能否明显提升？能提升支持，不能提升削弱。

    * 有规律工作是否导致长胖，应找其他条件相仿但没有从事规律工作的人，比较同样八年中体重如何变化。

    * 若无规律工作者也同样增重，工作导致长胖被削弱；若他们不增重或减重，工作导致长胖得到支持。

    * 性别差异、调查年限为何选八年、八年后是否继续增重，都不能直接判断这八年增重是否由规律工作造成。

    * > **提示**：评价题的锁定句是“与调查对象其他情况相仿，但没有某项行为的人后来怎样”，关键条件是可比起点，而不是只找一个“同样做过的人”。

## 幸存者偏差与样本代表性

* **幸存者偏差（survivorship bias）**

    * > **定义**：只看到经过某种筛选后留下来的对象，便把它们的共同特征当作全部对象的特征，忽略未进入视野或已经被淘汰的个体。

    * 典型推断是“眼前样本 → 全体对象”；问题不在样本看起来少，而在于样本可能没有随机性或代表性。

    * 观察范围本身会筛选对象：医院只看就医伤员，返航记录只看幸存飞机，现存建筑只看没有消失的道观。

* **代表性与随机性**

    * 抽样是否可靠，关键不是绝对数量，而是抽取对象能否覆盖不同情况、是否具有足够随机性。

    * 样本多不保证代表总体；同一种非随机抽样，截取位置不同就可能得到差异很大的比例。

    * 样本少也不必然推翻统计结论；只要抽样足够随机、有代表性，较少样本仍能较稳定反映总体。

* **不可见群体**

| 可见样本 | 未进入样本的群体 | 推断漏洞 |
| :--- | :--- | :--- |
| 火车上买到票的人 | 没买到票的人 | 采访者天然看不到未买到票者 |
| 博主文章的跟帖者 | 不关注、不跟帖的民众 | 忠实粉丝使支持率虚高 |
| 医院里被狗咬的儿童 | 多数不去医院就医的较大年龄被咬者 | 就医行为把年龄分布筛偏 |
| 返回的受损飞机 | 机腹等要害中弹后未返航的飞机 | 返航条件只留下部分损伤样本 |
| 现存的风景名胜道观 | 偏僻、景色一般且已消失的道观 | 现存筛选制造“古代都选绝美处”的错觉 |
| 上岸后有肺的陆地动物 | 上岸后死亡、没有肺的鱼 | 只有成功存活者留下可见特征 |

* **特殊场景的同类结构**

    * 身边人大多大学毕业，不能推出所有人都应大学毕业；社会总体中具有本科学历者只占 $5\%\sim6\%$。

    * 被采访者若大多是了解或喜爱冰雪旅游的年轻人，其高体验比例不能代表地区整体旅游需求。

    * “所有现存道观都在名山大川”不能倒推“古代所有道观都选在风景绝美处”；景色一般的道观可能因战乱、改建而消失。

    * 陆地动物都有肺可以由幸存机制解释：没有肺的鱼上岸后死亡，只有有肺者存活并繁衍。

* **选项识别**

    * 优先找直接说明“样本为何系统性偏离总体”的信息，如“关注者多为粉丝”“较大年龄被咬者不去医院”“失败个体已被淘汰”。

    * “样本数量不足”只是统计条件，不能替代对随机性、代表性和筛选机制的检查。

    * 讨论观点对错、观点分析是否充分，不是质疑“跟帖支持率能否代表民众态度”。

    * 讨论投资额、旅游资源或消费方案，不是在质疑受访者需求能否代表整体。

    * > **易错点**：看不到的群体可能不是数量少，而是根本没有进入调查、返航、就医或存续记录；只要存在这种筛选机制，眼前样本就不能直接当作全部。

## 实验因果的统一检查

* **从结果倒推原因**

    * 先圈出已经出现的结果，再确认题干把它归因于哪个措施、特征或起点。

    * 找是否有一个真正落在实验对象、实验时期中的替代原因。

    * 若没有匹配他因，再检查是否直接否定原联系、存在共同他因或发生因果倒置。

* **从比较追到起点**

    * 找到措施 $A$ 与结果 $B$ 后，先查干预前两组相关基线，再查过程中是否只有 $A$ 不同。

    * 结局差异可能来自原起点，实验过程差异可能来自额外措施，指标差异可能来自结论扩大。

    * 结论涉及概率、平均或整体趋势时，个别反例不能推翻；涉及某个明确个体时，个体经历反而不能代替总体规律。

* **从“如果没有”校准效果**

    * 结论说措施有效，就看不做时是否更差；结论说措施无效，就看不做时是否差不多甚至更好。

    * 效果可以是量变而非质变，不能只盯是否达标、治愈、消失或通过。

* **从样本来源检查代表性**

    * 问样本如何进入调查、实验、返航、就医或留存记录，警惕经过筛选的“可见部分”。

    * 只有排除起点差、额外变量、指标偷换、样本筛选与因果倒置，才能把结果差异稳定归给研究因素。
