## 找到结果的真正“背锅侠”：由果推因的论证结构与方法
> 对应块：BLK19 | 覆盖分集：P30-P31 | 块标题（分集名）：《由果推因的论证结构与方法》

### 先弄清：削弱时才需要区分因果方向

“讲了这么久，才到第四章？”有同学会问。我们把课程体系搭起来，最重要的就是第二、第三、第四章，这三章在真题里占比也最高。把它们理解清楚，后面更多是在不同问法中运用这些体系；先把地基打牢，比急着往后赶有用。

这一章先复习一个很容易忽略的点：**由因推果和由果推因的区别，只在削弱时需要辨析。** 如果题目问支持或假设，抓住结论说明的因果联系即可，不必先争论究竟是“由因推果”还是“由果推因”。

由果推因相对难一些，在部分考试中不算特别高频；但对日常逻辑思维很有价值，所以还是建议掌握。既然不容易被纯语音转录记住，我们用一张图把两类因果的攻防看明白：上排是题干常见的由果推因，下排是它的削弱；最后再看由因推果，它需要用另一种方式防守。

```text
┌─────────────────────────────────────────────────────────┐
│ 由果推因：先看到结果，再解释为什么                       │
│                                                         │
│   事实结果 B ──────────────► 原因 A                     │
│   （例：R 型卖得好）            （例：消费者更喜欢易清洗）│
│                                                         │
│   削弱：找到真正让 B 发生的 C                           │
│   （不是 A，而是 C）                                   │
└─────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────┐
│ 由因推果：先给原因，再推出结果                           │
│                                                         │
│   原因 A ──────────────► 结果 B                         │
│   （例：坐飞机）             （例：明天能到北京）        │
│                                                         │
│   削弱：找到让 B 不成立的其他原因 C                     │
│   （不是 A 能带来 B，而是出现阻断因素）                 │
└─────────────────────────────────────────────────────────┘
```

“坐火车可以去北京”是我们很熟的说法。如果讨论的是“坐火车能不能去北京”，再说“坐飞机也可以去”或“坐火箭也可以去”，并没有回答火车行不行；其他方式能去，不影响火车也能去。由果推因则完全相反，它是先看到“到了北京”这个结果，再找“究竟为什么到”。把这两个方向弄清楚，就不会在“其他原因能否削弱”上反复摇摆。

> **易错点**：削弱时区分方向，支持时先别分。支持或假设只要能够加强题干所说的联系即可，并没有必要先把“由因推果”和“由果推因”分得特别细。

### 两种他因，不能混着记

同样是引入“他因”，两种因果结构要求引入的东西完全不同。

| 结构 | 题干在问什么 | 正确削弱方式 | 常见迷惑选项 |
| :--- | :--- | :--- | :--- |
| 由因推果 | 原因 A 能不能带来结果 B | 引入让 B 不成立的其他原因 | 其他方式也能带来 B |
| 由果推因 | B 是不是由 A 造成的 | 引入真正造成 B 的其他原因 C | 理论上 C 也能造成 B，但没有真实发生 |

在图示中，可以从“引入点”看削弱方向。当使用因推果时，削弱箭头从 B 指向“使 B 不成立”，而由果推因的削弱则是从 A 指向“真正造成 B 的 C”，二者在起点、终点上刚好错位。

> **定义**：**由果推因的标准削弱**就是为题干已经发生的结果找一个新的“背锅侠”——这个原因必须真实造成该结果，而且与题干所说的原因无关。若题干给出的是一个对比试验，新原因还必须真实出现在这次试验里，而不是只在理论上可能起作用。

> **易错点**：只说“飞机、火车、火箭都能去北京”这类理论可能性，不是由果推因的有效削弱；同样，只说“下雨可能减少火灾”，若没说降雨确实发生，也不能拿来否定“政府扑灭火灾的努力见效”。

例如，小汪昨天已经到了北京，现在解释他一定是坐飞机来的。要削弱，不能只说“自驾也能到北京”，因为他有没有开车还不知道。正确的信息应当指出“小汪确实是坐高铁到达北京的”，把他原来的交通方式替换掉。又比如，如果有选项说“持续降雨可以有效控制火灾”，它只是一个一般性的可能性；要真正解释某地去年的火灾为什么减少，还必须落在该地那一年实际发生的降雨上。

真实发生还不够，必须对得上题干主体。题干在讲“小汪为什么到北京”，选项也要说“小汪为什么到”；题干在讲一组“久坐并患抑郁症的青少年”，替代原因也必须属于这批人，不能换成“这些孩子中家境不好、长期兼职的人”，因为后者可能根本没有参加那个久坐实验。

> **结论**：削弱由果推因时，要同时扣住三项：**同一结果、同一主体、真实发生**。满足得越完整，选项越符合题干故事；只满足其中一项，很容易掉进考官设计的坑。

### 背锅侠必须真的到场

小汪吃了一块肉后拉肚子。如果只是说“这块肉在保质期内”，并没有排除食物中毒的可能，也就不能削弱“吃肉导致拉肚子”；要另找一个原因，例如他吃了冰淇淋或别的变质食物。

这个例子把“真实发生”和“同主体”绑定在一起。针对某个具体的人，只要说另一样东西确实让他生病，就构成对原有解释的替代；面对考试，不能拿“冰淇淋也能引起拉肚子”代替“这些受试者还吃了冰淇淋”。前者只是常识，后者才落到题干的具体对象和事件中。

设想一个选项：“过期的过磷酸钙肥料导致东边亩产比西边高。”不能因为“过期”就擅自补出“过期肥料一定无效”。有可能仍然有效，也有可能不是唯一原因。必须再给出一个与肥料无关的真正因素，题干“东边亩产高是施过磷酸钙造成的”这个解释才被动摇。由果推因的削弱不要求把旧原因彻底证明为假，而是要求给结果安排一个同样能真实起作用的替身。

> **提示**：排除一个旧原因，不等于直接断言旧原因反命题。必须拿出“真正带出结果的另一个原因”，才完成由果推因的削弱。

### 果与因方向选择的两道门槛

由果推因题在考法上并不是非他因不可。即使题干形式是“A 与 B 同时存在，所以 A 导致 B”，考官真正设置由果推因选项的比例也未必高；支持时常考建立联系或前件后件，削弱时也可以直接质疑“A 导致 B”。

所以选择前有两道门槛。

#### 门槛一：有没有真正匹配的“他因”选项

如果选项提供了“同样能解释这个结果、但没有落在题干主体上”的原因，这才是由果推因的标准选项。看到一个高度契合的反事实说法，例如“原本土壤肥力就更高”，整个理由便已经扣上，可以直接选。

如果所有选项都明显无关，才需要继续考虑别的方法：直接针对因果联系本身说“A 导致 B”不对，或通过同因不同果、同果不同因揭穿联系。识别题目结构只是第一步，选对削弱路径才是关键。

#### 门槛二：是不是由果推因题，就只能选他因

不是。即使结构属于由果推因，也可以直接否定“静电导致漂浮”“酵素导致低感染率”等结论，不必硬套他因。结构是一种常见考法，不是唯一出题方式；如果有另一条同样符合题干逻辑且更直接的反驳路径，按题目实际逻辑判断即可。

> **结论**：由果推因和削弱选项**不是一一对应**。题干用因果语言给出结论，只能说明存在这种论证；选项有可能用他因反驳，也可能直接反驳结论。一定要按选项实际给出的信息判断。

这两种门槛的差异，可以通过一组对照看清因果方向和目标对象不同所带来的不同削弱路径：同样面对“原因导致结果”的表述，图中各条路径最终分别指向否定原联系或引入替身。

```text
由果推因：A 与 B 同时存在 ──► 认为 A 导致 B

削弱路径一（他因）：
   B ← C 真正造成 B（C 与题干所称原因不同）
   路径重点：证明“不是 A，而是 C”

削弱路径二（直接反驳）：
   同因不同果 / 同果不同因 / 作用条件不成立
   路径重点：证明“A 导致 B”这条联系不可靠
```

图中的第一行只告诉我们题干的通常写法，不能由此推出选项必须走哪条路径。削弱任务始终是破坏结论的根据，具体采用替身还是直接反驳要看选项。

不少同学看到因果结论就固定去找新原因，因而漏掉更直接的选项。这里有本质区别：一种是把“原先的解释”换成“另一件真实的事”，另一种是直接表明“原先所说的因果联系并不成立”。两种只要真正削弱成功，都是有效答案。

### 两个日常小例子：别换车、也别开飞机

由因推果和由果推因，生活中都有非常具体的影子。

小汪选择坐飞机，明天就能到北京。反驳这个说法，需要指出“最近雷暴天气导致去北京的航班取消”，也就是一个让结果不能成立的现实原因。换成“坐高铁也可以去北京”则是无用的，因为高铁是否可达与飞机是否可达无关。

小汪已经到达北京，现在有人认为他是坐飞机来的。要替换这个解释，也可以在同样的人身上给出另一个确实发生过的交通方式：也许是自驾，也许其他方式。两种句式有本质区别：前者是“先选飞机，能否成行”，后者是“已经到达，究竟怎么到达”。

分清这两种句式，关键就是问一句：题干是先讲“做了某件事”，还是先讲“出现了某个结果”？前者是因在果前，削弱要给结果设置障碍；后者是果在因前，削弱要给结果找到真正原因。

### 一用“结果在先”，就知道该找什么

由果推因的标准外形很简单：先给一个结果，再为这个结果提出原因。读题时先问“结果是什么”，再问“为什么”，最后把选项与结果、主体逐一对照。

| 步骤 | 要问自己的问题 | 对答案目的 |
| :--- | :--- | :--- |
| 识别结果 | 发生了什么已经出现的事实？ | 锁定要解释的现象 |
| 锁定原因 | 论断把这归因于什么？ | 找到需要替代的旧原因 |
| 准备他因 | 什么真实原因让同一结果发生？ | 让“背锅侠”接替原原因 |
| 核对主语 | 原因是否属于题干讨论的那一拨人或事？ | 防止拿无关对象来解释 |
| 排查直接反驳 | 是否直接说“A 导致 B”不成立？ | 防止被固定的选项模式限制 |

这一步并不是要求每道题都按表格机械执行。“换雨林、火星石、吃冰淇淋”只是帮助我们形成“结果在先”的习惯。真正做题时，多数由果推因题一眼便能看出结构，正确答案和题干结论会紧密扣在一起，可以直接选出。

反过来，由因推果的“能去北京”是一个不排斥其他方式的事实，削弱时不能引入“另种交通方式也能去”来反问“原方式为何不能”。这正是“互斥”与“背锅”的差别，前者要给已有原因设置障碍，后者要说明原解释不是最佳解释。

### 不要在题干结论后面过度联想

这个道理看起来朴素，却能滤掉大量错误选项。选项中与原文似有关联，但并未明确包含题干关键因果时，一律不要替它补上缺失的条件。

小汪吃了一块肉，却说“肉还在保质期内”。保质期与生病之间没有直接联系，除非再给出一个其他原因，题干原有解释并没有被动摇。类似地，某人早一天收稻子、晚一天收稻子，不能脑补成“稻子还没熟就被割了”。题干若已给出实际亩产，成熟稻子今天割还是明天割，本就不会自动改变那个亩产。

人们容易对选项补全一个对自己有利的剧情，却忘了做题靠的是题干真实提供的信息。选项主语不对，讨论对象不对，时间不对，同样是偏离。凡是结论刚好需要你加一句“也就是说……”才能成立，就先停下来检查。

> **易错点**：选项中的“可能、也许、通常、理论上”不等于对题干事件发生了作用。要削弱一个具体故事，必须给出具体人物、具体时期或具体试验中真实发生的原因。

### 从雨林到男

#### 雨林缩小得慢，不一定是政策的功劳

假设 H 国政府说：卫星照片显示政府保护赤道雨林的努力取得显著成效，因为雨林面积缩小比例明显低于往年。这是一个“先给结果，再给原因”的标准结构。

要削弱，就给这个结果找另一位真正起作用的原因。C 选项说，去年 H 国旱季出现异常的大面积降雨。雨季降水充沛，火势减少，森林自然能减轻损失。雨季缓解了灾情，这并不等于政府过去的努力失效；既然现在有了新的原因，原来的归因自然应当被重新审视。

其他干扰项要么无关，要么强度不够。去年用于保护雨林的财政投入低于往年，不等于没有成效；邻近的 G 国雨林没缩小，主体都不在 H 国；“保护费用只占年度财政支出很小比例”，也未必意味着绝对金额少，更不能推出措施无效。全球性的环境问题同样没有回答：H 国政策究竟是不是缩小速度下降的原因。

> **提示**：国家公园也能让雨林少受破坏，但只是泛泛的可能性；正确选项必须写明降雨发生在 H 国去年那个旱季中，解释正在被解释的具体年份。

#### 男孩成绩下降，可能是游戏耗去了精力

“男孩危机”题也是一个典型：男孩调皮捣蛋、学习成绩不如女孩，专家认为原因在于家庭和学校不恰当的教育。题干讨论的是男孩问题的成因，我们要找的是其他原因。

家庭对独生子女的过度呵护，仍属于家庭教育，不能选。真正的答案 E 选项指出，现代社会游戏泛滥，男孩天性比女孩更喜欢游戏，大量精力被耗去。这既不是家庭教育，也与学校方式无关；它能直接解释男孩学习表现不如女孩。

C 选项尤其容易让人上当。它指出男孩发展潜能优于女孩，大学毕业后更容易在事业上有所成就，意思无非是“男孩危机也不可怕，将来能追上来”。但我们问的是男孩危机的原因，不是它的后果，更不是未来是否严重。讨论“为何发生”，不能拿“发生后影响不大”来代替。

D 选项说家庭教育中女性充当了主要角色，也不能直接推出男孩成绩差。虽然主体是家庭教育，却仍没有说男性怎样对女孩构成有效教育；只在相关领域出现，不等于已经解释了男孩成绩落后。综合来看，只有 E 选项真正给“男孩危机”找了一个来自家庭和学校之外的替身。

> **结论**：看到“家庭和学校导致……”时，不要只因选项出现“家庭”便认定它属于他因。其他原因必须在概念上独立于原原因，仅仅更换主语不够。

### 施肥提高产量，别被词语绕进去

施肥实验是比较典型的“结果在先”结构。试验结果先摆出来：东边地施用过磷酸钙，亩产三百；西边地未施用这种肥料，亩产一百五十。论述说因此东边地产量高，是因为施用过磷酸钙。真正应该解释的是东西两地的亩产差异。

于是 E 选项自然成为答案：两地土质本来不同，土质差异便足以造成产量差异，不必假定只有肥料在起作用。其他选项则像考官随手挖出的坑。

A 选项说“给东边地施用的过磷酸钙是一个过期的肥料”，却不能直接认为过期必然无效。要真有第二个原因解释高产，应当直接指出“东边土质本来就不一样”，而不是用“过期”替代差异。

C 选项是典型的句式坑：“每块地种植了不同种类的四种玉米。”不同种类说的是玉米品种，而不是东西两块地之间不同。意思是每块地都种了同样四种玉米（第一种、第二种、第三种、第四种），因此并未真正引入新的变量。

D 选项“两块地田间管理没有明显不同”排除了其他差异，反而说明产量差更可能是肥料造成的，这是支持而不是削弱。比较的主体是东边和西边，南边的地与这道题无关。

要特别留意词语的修饰对象：句中“不同种类”可能修饰“玉米”，不一定修饰“每块地”。这种小差异看似不起眼，却决定了选项有没有提供新的他因。读选项时要慢慢找准它真正在说什么，并检查修饰谁、主体是谁、是否在题干的时空范围内。

### 捕食与反刍：谁才是原因

剑齿象灭绝的题，题干给出历史事实后，结论说人类过度捕杀可能是灭绝的原因。削弱方法仍是寻找与人类无关的其他因素。疾病、小行星、瘟疫、气候，或史前动物之间的大规模捕杀，都可能构成真正的他因。A 选项恰好给出了“史前动物之间大规模捕杀”的解释，因此被选中。

B 选项说剑齿象遇到人类攻击时缺乏自我保护能力，这仍在人类与剑齿象之间寻找原因，不能削弱“人类捕杀”本身，反而像支持了题干的担忧。C 选项谈南美洲、北美洲的种群迁徙，没有涉及灭绝原因；D 选项可能是气候变化，却没说明与剑齿象灭绝直接相关。这里选 A 很简单：不是人类过度捕杀，而是史前动物相互捕杀。

与此类似，2021 年国考以近十万年前反刍动物种群大幅衰减为结果，声称早期人类活动是重要原因。D 选项指出同一时期大型猫科动物繁盛，并大规模捕食这些动物，正好构成一个与人类无关的替代解释。

B 选项说这些动物遭遇人类攻击时能够进行一定的防御。可是“有防御能力”等于“不会被人类攻击导致数量锐减”吗？C 选项提到同期马、驴等动物也大幅衰减，但讨论的主体是反刍动物，与马驴关系不大。A 选项说衰减后的反刍动物为人类提供了更多食物，只谈结果的影响，不回答结果如何产生。A、B、C 都是考官常用的干扰路径，唯独 D 真正抢走了“人类捕杀”这个因果位置。

> **提示**：看到“他因”时先排除那些仍在原主体链条内的情况。既然结论说“人类活动导致衰减”，谈“这些动物有防御能力”“人类后来获得更多食物”都没有离开原链条。

### 静电不是漂浮的唯一解释

2023 年一道国考题问“不能质疑上述观点”的选项。结论是：行星表面的沙粒漂浮现象主要来自静电。因为太阳风进入表面产生电场，沙粒受静电作用离开表面，没有太阳时又落下来。

要质疑这个结论，须证明沙粒漂浮不必由静电造成。B 选项指出表面存在一氧化碳、干冰等挥发性物质，它们的升华会释放沙粒。这并非静电，而是另一种直接释放机制。C 选项更是直接质疑结论：行星质量小，静电只能扬起较小沙粒，而目前漂浮的沙粒尺寸都很大，静电根本解释不了；这是直接反驳，不必引入他因。

D 选项说行星自转很快，物体受到离心作用，尘埃和石块会脱离行星。这是除了静电以外的真实机制，也是标准的由果推因选项。A 选项却在说彗星受太阳风产生的静电影响，其表面沙粒也将悬浮，复述的是原结论，不能质疑。

原结论是“主要来自静电”，A 选项只说静电也能让沙粒悬浮；这不妨碍还有其他主要原因存在。因此 B、C、D 都能削弱，A 反而支持，是标准答案。遇到“没有质疑”的问法，恰恰需要格外小心：不是“能不能找到反驳”，而是“哪一项没有反驳”。这种题的数量判断也常用“同因不同果”“同果不同因”检查选项是否在破坏原联系。

### 破壁机销量：促销是另一个卖点

2022 年的一道国考题中，结论是消费者更喜欢易于清洗的破壁机。依据是 R 型销量更好，R 型相对 W 型更易清洗，而 W 型的特点则是噪音较少。既然清洗容易这一解释已经被摆出来，要反驳就得说明消费者还因为别的优势选择了 R 型。

A 选项说 R 型比 W 型网上促销力度大、价格更有优势。消费者喜欢易于清洗；若 R 型促销更多、价格更低，也可能因此销量更好。促销与价格不是“容易清洗”的另一种说法，确确实实是另一个原因。

B 选项说 W 型外观设计更美观，白领更倾向买 W 型，解释了 W 型为什么有市场，却没有解释 R 型为什么销量更好。C 选项说该品牌整体占有率高，讨论的却是“消费者为什么更喜欢容易清洗的 R 型”，这二者不是一回事。D 选项说 R、W 两型销售渠道一致，意味着排除了销售网络等因素，反而倾向于支持题干结论。

> **结论**：渠道相同、差异更少，倾向的是支持而不是削弱；解释错了对象，说得再多也接不上题干。

这道题也说明了选项的修饰对象。“与 W 型相比，R 型促销力度更大、价格更具优势”，比较的主体始终是 R 型和 W 型。若选项突然换到整体品牌、整体销量或 W 型用户，就不要再勉强往结论上套。

### 旧因果被包装进新结构

有些题会故意增加背景，甚至把一个很长的叙述藏进另一段因果里。2023 年国考就有一道大宗商品进入“超级周期”的题：分析人士认为大宗商品涨价是“出现新增长动力”的结果，历史上大宗商品进入超级周期后又会带动经济复苏。这是两道推理混在一块：先由果推因解释涨价，后一段展开涨价之后的结果。

问“最能削弱”时，可以去拆第一段。必须找到的是，在“新增长动力”之外，让大宗商品真正涨价的替代原因。顺着两段之间的“因此”反推回去，答案其实就藏在选项里。A 选项说“地缘政治风险加剧使供应紧张引发涨价”，正是如此。

B 选项说天然气涨价推高化肥成本，进而推高全球粮价，却没有说全球粮价上涨为什么就不能带来经济复苏；即便它不讨论涨价的原因，最后也没有得到“经济不复苏”的结果，因此不能用于削弱。C、D 分别谈环保、碳中和、产业布局、救市计划和寻找新增长动力，都不在解释大宗商品涨价。A 直接补上题干的“结果”由何引起，路径非常短，答案因此非常清楚。

> **提示**：题干叙述长，不代表削弱路径长。带着问题“哪个选项替我解释了核心结果”来读，往往能跳过许多背景句，抓住主要矛盾。

### 链条可以拆，也可以逐环节替代

由果推因常被包装在其他结构里，但不是所有包含“因此”的选项都等于他因。2022 年国考列车订餐题就是如此：某地区推出互联网订餐并进行了宣传，前面的订单尚可，后来没有增长甚至下降；于是认为该地区旅客对网上订餐的需求不高。

这里的结果是订单差，原因却被解释成“没有需求”。削弱它就是寻找一个与需求量无关的现实阻碍。

I 选项说能接受网络订餐的餐厅数量少、食品品种单一。这说明即便有需求，现有服务也满足不了，订单差未必是需求不足，I 能削弱。IV 选项说线上宣传缺少对用户的精准定位，许多订票用户根本不知道可以网上订餐。也是同一个结果、同一个主体、真实发生的原因，IV 也能削弱。II 选项说即使推出网络订餐，大部分乘客仍喜欢去餐车就餐。这等于直接说他们没有网上订餐需求，恰好顺着题干，不能削弱。III 选项谈其他地区短途列车多、长途列车订餐量大，主体不对，不能削弱。

同样是“因此”，有的选项补了一个原因，有的只是顺着结果写了一个评论，有的在说无关地区或无关对象。我们不能仅凭“因此”两个字选他因，要看选项中是否确实存在一个能解释该结果的独立原因。

### 酵素、蛋壳与低感染率

2020 年国考题给出一个同时出现的 A 与 B：某种澳大利亚鸟类的蛋自然感染率应为 $20\%$，实际仅为 $9\%$，其蛋壳中含有溶酶酵素。研究者认为，酵素正是抵御细菌侵扰的关键因素。这仍是“A 与 B 同时存在，所以 A 导致 B”，不能因为用了实验数据，就认为只有一种答案。

考官当然会设计由果推因选项。I 选项称蛋壳中酵素含量与其他动物相当。如果酵素是感染率低的原因，那么含量相同，结果也应大致相同；事实却是 $9\%$ 对 $20\%$，同因不同果，这可以削弱。II 选项说蛋壳被碳酸钙包裹，防水性和抗细菌能力更强，这不是酵素，而是“蛋壳盔甲”真正起了作用，II 可以削弱。III 选项说鸟类散发的特殊气味减少蛋壳上的细菌，同样是在用非酵素因素解释低感染率，III 也可以削弱。

D 选项却说该鸟类的蛋壳比别的动物薄三分之一，更容易被微生物侵入。若蛋壳因素成立，感染率似乎应当更高，而不是 $9\%$；现在结果偏低，反倒说明还可能存在酵素这样的保护因素，因此 D 至少在加强题干，是不能削弱的一项。

> **结论**：在“有没有削弱”的题里，选项“很强地讲了别的机制”，不代表它能削弱。必须检查这个机制最终是破坏原联系，还是反过来让原联系更可信。

### 同一温度下的天文学论证

2022 年省联考金星大气题，看似涉及许多生物和气体名词，实际核心仍然很窄。发现金星有磷化氢后，研究者认为，这可能是某种生物留下的印记；至于生物本身是有氧还是厌氧，暂且不论。

因此削弱时要找的是另一个导致磷化氢出现的原因，而且必须与生物无关。A 选项提到二氧化碳、浓硫酸和温室效应，却没有说明这些因素产生磷化氢。B 选项提到不需呼吸、适应金星环境的动物，依然落在“生物造成”的框架内，不能削弱。

C 选项明确指出某些光化学过程能释放大量磷化氢，给出了不依赖生物的直接机制，答案就是 C。D 选项只说磷化氢需要能量才能发挥作用，却没有说这能量在金星上以何种实际方式促成了磷化氢，也就没有构成另一个真实原因。

> **提示**：不能因为“光化学”听起来比“生物印记”更复杂就优先选它，理由很简单：只有它真正把“磷化氢的出现”解释了，才是对原结论的削弱。

金星题剥开天文名词后仍能看出标准结构：观察到某物，提出某原因；正确项给出第三种解释且不涉及原原因。遇到文字较长、无关信息很多的题，可以先圈出“结果”和“结论词”，其余再当作背景。

### 在选项里找现成的因果链

不是每道题都写得明确。有些论述包含两组“原因—结果”，需要你在选项里找到直接能扣住其中一组的那条链。

2019 年浙江题就是这种情形，菲律宾无法拒绝美国要求出兵越南，是因为依赖美国的安全保障；而为了避免直接卷入有关自身利益、风险严重的越战，它只少量派遣民用工程部队，始终拒绝战斗，也是原因所在。两句话本质都是把某现象归因于别的原因。

题干问“哪项最能反驳”，但无从直接判断这究竟考由果推因还是别的考法时，不妨先把选项扫一遍：若选项中有一条明显的“另找原因解释结果”链，就优先验证它。A 选项说菲律宾提出的出兵条件是美国提供安全保障，但题干没有谈“出兵条件”，无关。B 选项说菲律宾派工程兵说明同盟薄弱，题干没有提同盟，无关。C 选项说菲律宾若派战斗部队可能承担风险，题干也没有给出这项风险事实，关联不上。D 选项则说菲律宾不拒绝美国要求其出兵，是因为经济严重依赖美国，这是一个与安全保障不同、却能真正解释“不拒绝出兵”的原因；即便不能顺带解释“为何只派少量工程兵”，仅对第一组因果的反驳已经成立，所以 D 是正确项。

> **结论**：当题干明确说某现象由“甲”导致时，找到“现象由乙导致”的选项就已足够反驳，不必强行同时反驳题干所有句子。

有人会疑惑：“这怎么判断考不考由果推因？”别猜，先看选项：有匹配的他因就直接验证；如果一个都没有，再继续找别的削弱路径。考官不会因为题干提到了两种因果，就要求考生一定把两个因果都否掉；只要有一个选项能有效破坏其中一个关键联系，就已经完成反驳。

### 相似实验：效应混淆的主体重复

实验题并不可怕。万变不离其宗：实验只是在给定条件下，先呈现一个结果，再把结果归因于某个条件；考官常问能否用“同时出现”推出“是这个条件导致”。

2021 年新疆题讲青少年久坐不运动与抑郁症风险增加。研究发现每天多一小时久坐，抑郁评分就会增加，因此认为久坐会增加抑郁风险。正确的他因必须在实验中出现：这些久坐青少年同时沉迷恐怖类游戏，恐怖游戏严重影响了精神，反而造成抑郁风险。题干问“这些久坐的青少年”，他因也必须对这同一批人说，恐怖游戏因而落入实验范围内。

B 选项却只说“这些孩子中家境不好、长期奔波兼职的青少年也会患上抑郁症”，没有点明这些青少年是否属于久坐的那一拨人；退一步说，即使他们属于久坐实验者，未必同时又在兼职。如果要改得严谨，应说“这些久坐的孩子，长期奔波兼职，并因兼职而增加抑郁风险”，这样才与 A 选项同属一条由果推因的因果链。

C 选项说这些孩子中长期久坐的青少年，学习成绩优于同龄人，讨论的是学习结果，不是抑郁风险。D 选项说经常久坐、不运动的青少年在全部青少年中所占比例很低，无论比例高低，都不解释“久坐的那一批为什么出现抑郁”。所以 A 才对。

> **易错点**：题干做实验，选项给出“理论上可能影响同一结果”的信息时，理论推断不代替真实场景。只有原因真实落在本实验的主体内，才算“另一个背锅侠”。

### 史前工具与人类脸型

2017 年国考题：200 万年前人类开始用石器处理食物，如切肉、捣碎，同时人类逐渐演化出较小的脸型与更弱的咀嚼肌、咬力。研究者据此推测，工具的使用减弱了咀嚼力量，从而导致人类脸型变化。这仍然是 A 与 B 同时存在，再推出 A 导致 B。

削弱需要在当时的人类中找到另一个原因，选项 B 说 200 万年前人类食物类型发生变化，这加速了人类脸型变化。明确发生在同一历史时期，且独立于工具，替代解释成立，因此选 B。

A 选项说与人类接近的灵长类动物白天有一半时间用于咀嚼，脸大、肌肉发达，这只是说明咀嚼多和脸型特征之间可能有关联，没有讲工具，也没有讲这些动物是否使用或不使用工具；且讨论对象不是人类。C 选项说使用石器后，更多食物经过更高程度处理，变得易于咀嚼，这顺着题干强化了工具与咀嚼减弱的联系，削弱不了。D 选项说早期人类较小的咀嚼结构又使大脑增大成为可能，讲的是脸型与脑容量的后续关系，与“是不是工具导致脸变小”没有直接因果对应。B 才是真正“背锅”的那个原因。

> **结论**：由果推因题最怕时间错位。题干讨论史前时代，就不能拿现代美容技术削脸；题干讨论一个实验，就不能拿试验之外的因素替代。

### 早餐与体重：三个频率点

2021 年四川题讲不吃早餐与体重增加的试验，结论是不吃早餐会使无论男性还是女性体重增加的概率变高。题干中，早餐与体重的判断基于“增加的概率”，不是保证每一个人都一定增重。削弱时需要另找原因，而且必须落到参加试验的这批男女身上。

A 选项说“不吃早餐，体重不一定都会增加”，题干本来说的是概率，不保证每个人都会增重，所以这句话没有否定结论。C 选项说 18 岁以下的人不一定出现相同情况，题干讨论的就是受试对象，没有进入 18 岁以下的范围。D 选项说相比男性，不吃早餐对女性的影响不大，但 1.4 倍仍说明有影响，不能把“不大”替换成“没有”。

B 选项提出男女体重增加主要是早上睡懒觉造成的，这提供了一个与“不吃早餐”不同的原因。只有明确指向这批男女的睡懒觉，才算这个原因真的发生在试验中；严谨的改法应当是“参加试验的这些男女，体重增加主要是早上睡懒觉造成的”，而不是泛泛地说“睡懒觉也会增重”。原选项虽然表述稍显宽泛，但已经带着“这些男女”的指向，所以可以按考官意图认定其构成对原结论的替代。

> **结论**：削弱的是“某因素导致结果发生”，不是“所有对象、所有个体都必然产生结果”。凡是想通过“未必每个人如此”来否掉一个概率结论，都属于没有击中要害。

#### 怎样理解“背锅侠”的精确含义

“背锅侠”不是随便找一个能造成结果的人，而是替代原结论所指定的原因。它要同时满足“同一对象、同一结果、实际发生”，少一个都容易滑向错误。

以“杀猪肉导致腹泻”为例，“肉在保质期内”不是“背锅侠”，它没有解释腹泻；“吃了冰淇淋导致腹泻”才是在同一事件中解释原因的另一种可能。考试中用“过期肥料”替代“土壤不同”、用“睡懒觉”替代“不吃早餐”时，也要认清前者只是碰到原对象，尚未给出新的解释，后者才真正承担解释责任。

> **提示**：因果论证的削弱不是证明“我原先说的原因一定错”，而是提供“即使原先原因成立，还有另一个足以产生结果的原因”，从而让原结论无法独占解释权。理解这一点，就能区分真正的他因与仅仅带有怀疑色彩的描述。

### 题干、结论和选项要扣在一起

由果推因题真正做得快，是因为题干结构、结论的表述和选项中的解释往往能严密扣合。看一眼就能确定谁是替代原因、是否同主体、是否在题干的时空内。

真正需要经常停下来检查的，是那些表面有因果词、但没有真正解释结果的选项。当一条结论混合多段叙述，要先确认哪一段是要被削弱的主要推理，而不是见到任何一个“因此”就选定。当选项讨论别的地区、别的物种、别的时期或结果发生后的影响，即使它听起来合理，也不能接替题干中的原因。

做熟的应当是四个动作：

- 看清结果，说清它是什么；
- 确认对象没有换；
- 验证新原因确实存在；
- 对照选项真正削弱哪条联系。

如果题干已经由果推因，而且选项给出了标准他因，就选那个他因；如果选项是对“A 导致 B”本身的直接反驳，只要有效，也可以选。不要被“我认为这是一道由果推因题”绑架，进而认为所有选项都必须是同一种形式。

> **定义**：由果推因的识别与由果推因的作答之间，留有一道用于保护判断力的缓冲带。**识别**的是题干逻辑，**作答**的是“最能削弱”的选项，两者有关联，但不是同义词。

由果推因讲到这儿。先把“结果—解释原因”的方向放对，再看“同一结果、同一主体、真实发生”，最后检查是不是拿别的对象、别的时期或无关机制来凑答案。这几条立住，因果题里的大多数干扰项自然会被排除。

## 秒杀思路的基本框架
> 对应块：BLK20 | 覆盖分集：P32

为什么把这一类方法叫作“秒杀”？

不是因为我们看到选项就能随便蒙，而是因为这类题从题干到选项，都有非常固定的底层逻辑结构。只要把结构认出来，正确选项往往就已经摆在选项里了，剩下的工作只是把它从一堆看似有道理的话里挑出来。

这一章列出了五个常见、最喜欢考的秒杀思路：通过第三者建立联系、比较之前起点必须相同、如果没有会不会更好或者会不会更差、因果倒置，以及幸存者偏差。我们先把第一个——“通过第三者建立联系”——讲透。它看起来分散在神经、疾病、基因、产业、气候等完全不同的题目里，底层其实只做一件事：题干把“直接关系”说成“没有关系”，我们要找出把这两者重新接起来的中间环节。

> **定义**：当题干认为“甲直接导致乙，所以丙和乙没有关系”时，削弱它的关键不是再找一个乙的原因，而是建立“丙导致甲，甲导致乙”这条链。丙就是那个“第三者”。

### 先把“没有关系”拆开

这类题干最常见的句式是：因为是 A 直接导致 B，所以 B 和 C 没有关系，C 不是导致 B 的原因。

这里的关键词不是“直接”，而是“直接导致”。命题人实际上只否定了 C 对 B 的直接作用，却顺手把它扩大成了 C 对 B 没有任何关系。我们真正要问的是：C 能不能通过别的因素影响 B？

```text
题干的原判断：

A ──直接导致──> B
C ──被认为没有直接关系──> B

削弱方向：

C ──导致──> A ──导致──> B
```

这条链一旦接上，C 虽然没有直接导致 B，却仍然可能是 B 的间接原因。更准确地说，C 仍然是 B 的原因链条中的一个环节，只是它藏在了 A 的后面。

举一个生活里的例子。B 不幸被杀了，直接动手的是 A，那么 C 跟 B 被杀有没有关系？如果 C 雇佣了 A 去杀 B，那么 C 难道一点责任都没有吗？直接杀人的是 A，但 C 通过 A 这个第三者参与了结果，所以不能因为 C 没有亲手动手，就说 C 与 B 的死完全没有关系。

再比如，明明是小李打了人，小张和这起打人事件有什么关系？如果小张和小李根本不认识，那么小张当然可以被排除在外；但如果小张雇了小李去打人，小张就和打人事件建立了联系。这里连接小张和小李的，正是“小李”这个第三者。

环境问题也一样。二氧化碳导致南极冰川融化，这并不自动说明人类与冰川融化无关。如果人类导致了二氧化碳增多，那么链条就变成：

```text
人类 ──导致──> 二氧化碳增多 ──导致──> 南极冰川融化
```

人类没有直接站在冰川面前，却通过二氧化碳影响了结果。没有直接关系，不等于没有间接关系。

#### “不能直接影响”只是换了一种说法

还有一种问法，表面上看似不同，底层仍然完全一样：题干说，C 不会直接影响 B，所以 B 不会因为 C 的改变而改变。这时候我们要找的，仍然是 C 通过 A 间接影响 B 的可能。

比如，人类不会直接去吃南极的企鹅，但这并不意味着企鹅减少与人类完全无关。人类制造温室效应，改变了企鹅赖以生存的环境，那么人类就可能通过环境这个中间环节影响企鹅数量。

这里的“直接”很重要。没有直接作用，只能说明关系不是一步到位的，不能说明关系不存在。真正要问的是：能不能找到一条由 C 出发、经过某个中间环节、最后到达 B 的路径？

> **提示**：看到“不会直接影响”“没有直接关系”“与……无关”时，先别急着接受题干的扩大结论。把“没有直接”改写成“是否能间接”，答案方向通常就出来了。

### 正确选项只需要把断掉的链条接回去

按照这类题目的命题方式，选项不需要写得很复杂。只要它能把题干断开的因果链接上，就能完成削弱；反过来说，只是换了一个原因、只是说两个现象同时出现、只是比较同一类对象谁更重要，通常都没有真正触及题干的核心。

为了避免字母在不同题型里混淆，可以把结构换成语义名称：

| 题干锁定的说法 | 最需要的选项 | 完成的链条 |
| --- | --- | --- |
| 直接原因 X 导致结果 Y，所以变量 Z 与 Y 无关 | Z 导致 X | Z → X → Y |
| 变量 C 不会直接影响结果 Y，所以 Y 不会因 C 改变 | C 通过 X 间接影响 Y | C → X → Y |
| 替代办法 X 可以实现目的 Y，所以旧办法 Z 不再需要 | 实现 X 必须依赖 Z | X 依赖 Z 才能实现 Y |

前两行属于同一个思路：第三者建立联系。第三行看起来换了一个问法，本质上仍然是在寻找一个不能被绕开的前提。我们先把第一种链条看熟，后面再处理“替代办法”这一种变体。

### 真题一：直接原因被拿来排除旧原因

#### 哮喘题：情绪未必是直接原因

2016 年国考的一道题，反对者认为，迷走神经兴奋性的提高和交感神经反应性的降低，才是哮喘的原因，因此情绪与哮喘无关。题目要我们最能削弱反对者的观点，也就是要说明：情绪仍然可能和哮喘有关系。

按照固定结构，理想选项不需要证明“情绪直接导致哮喘”，只需要证明“情绪改变了那些神经变化，神经变化又导致哮喘”：

```text
消极情绪 ──> 迷走神经/交感神经变化 ──> 哮喘
```

选项 D 正是这样说的：消极情绪会提高患者的迷走神经兴奋性，并降低交感神经的反应。它没有改变题干所说的直接原因，却把情绪接到了直接原因前面，所以“情绪与哮喘无关”的结论被削弱了。

这道题的其他选项，正好说明了错项为什么看起来也有道理。A 说消极情绪可以诱发身体疾病，但身体疾病不一定就是哮喘，没有把情绪和哮喘连起来。B 说哮喘会造成焦虑、抑郁和愤怒，这是“哮喘导致情绪”，把因果方向反过来了；题目要讨论的是情绪能不能影响哮喘，不是哮喘出现后情绪会怎样。C 只说焦虑、抑郁和愤怒等消极情绪是普遍问题，却没说它们会不会引起哮喘，和题干争的不是一个问题。

所以这里要牢牢记住：我们要证明的不是“情绪一定是唯一原因”，而是“不能因为有直接原因，就把间接影响也排除掉”。选项 D 一接上这条链，答案就出来了。

#### 脱发题：旧原因可能藏在中间环节

2019 年国考的一道题，研究人员认为人类脱发是由营养不均衡导致的；反对者提出，脱发是毛囊受损导致的，言下之意是营养不均衡并不是原因。题目要求最能削弱反对者。

反对者的推理是：

```text
毛囊受损 ──导致──> 脱发
所以营养不均衡与脱发无关
```

要削弱它，就要说营养不均衡没有真正被排除，它可能先造成毛囊受损，再通过毛囊受损导致脱发：

```text
营养不均衡 ──导致──> 毛囊受损 ──导致──> 脱发
```

因此，毛囊受损是营养不均衡导致的，这句话就直接秒选。它不一定是最直观的描述，但因果方向和中间环节都完全正确。

B 说长期营养不足的人也容易脱发，听起来很像在讲营养和脱发，但它把“营养不均衡”偷换成了“营养不足”，不是题干原来的命题。C 说使用洗发水也会损害毛囊，这是在寻找另一个导致脱发或毛囊受损的原因，却没有说明营养不均衡和脱发的关系。D 说毛囊受损使人不能吸收营养从而导致脱发，反而是在支持“毛囊受损导致脱发”这一条，并没有把营养不均衡接到毛囊受损之前。

这类题最容易被“毛囊受损”这个直接原因带着走。可我们真正要问的是：营养不均衡是不是被反对者排除得太快了？只要找到“营养不均衡→毛囊受损”，答案就不是凭感觉选出来的。

#### 皮肤年轻题：把胶原蛋白接回干细胞

2021 年国考的一道题，反对者认为表皮干细胞的更新才是皮肤年轻的原因，因此否定了胶原蛋白是皮肤年轻原因的说法。题目要削弱这个结论。

这里需要接回的不是“胶原蛋白直接让皮肤年轻”，而是：

```text
胶原蛋白 ──> 促进表皮干细胞更新 ──> 皮肤年轻
```

选项 C 说胶原蛋白对促进表皮干细胞的更新至关重要，正好把胶原蛋白放到了第三方位置上。只要干细胞更新确实能让皮肤年轻，胶原蛋白就仍然可能是影响皮肤年轻的深层原因，反对者“胶原蛋白无关”的说法就不能成立。

A 说表皮干细胞更新还需要其他化合物促进，但没有说明胶原蛋白在其中起什么作用，关系没有落地。B 说表皮干细胞的再生能力会随年龄增长而衰退，这是在描述干细胞自身的变化，没有建立胶原蛋白和皮肤年轻之间的联系。D 说胶原蛋白的表达在不同干细胞之间存在很大差异，意思是“因情况而异”，却仍然没有回答胶原蛋白到底会不会影响皮肤年轻。

所以这类题不要只盯着结论里最显眼的那个原因。要看题干到底否定了谁、又把哪个直接原因推到了前面，然后去找被否定者和直接原因之间有没有一条可走的路。

#### 第二产业题：另一种原因不等于原来原因无关

2023 年国考的一道题讨论某地区第二产业从业人员减少的原因。另一种观点认为，第三产业蓬勃发展，吸纳了大量第二产业人员，因此这件事和第二产业优化升级无关。

反对者的结构是：

```text
第三产业发展 ──吸纳人员──> 第二产业从业人员减少
所以第二产业优化升级与人员减少无关
```

要削弱它，就要找到第二产业优化升级如何影响第三产业：

```text
第二产业优化升级 ──拉动/促进──> 第三产业发展
第三产业发展 ──吸纳人员──> 第二产业从业人员减少
```

选项 A 说第二产业的优化拉动了第三产业的发展，正好补上了中间这条链。第二产业虽然没有直接吸纳人员，但它可能通过推动第三产业，最终影响到第二产业从业人员数量。

B 说第三产业整体规模比第二产业小，讨论的是规模大小，题目讨论的是人员为什么减少。C 说第三产业的发展得益于优化的营商策略，这更像是在给第三产业寻找另一个原因，反而在一定程度上支持了“第二产业优化不是原因”的观点。D 说第二产业和第三产业都对吸纳就业做出贡献，只说明两者都有贡献，却没有说明第二产业优化升级是否导致第二产业人员减少。

### 影响关系可以绕一道弯

有些题不会直接说“所以 C 和 B 没关系”，而是说“C 不会直接影响 B，所以 B 不会因 C 改变”。问法变了，抓链的方法不变。

#### DNA、杏仁核和疾病

2020 年四川的一道题，反对者认为，脑部杏仁核活动增加是引发抑郁症和焦虑症的原因，所以脑部 DNA 变异与这些疾病无关。题目要求最能削弱反对者。

正确的连接应当是：

```text
脑部 DNA 变异 ──导致──> 杏仁核活动增加
杏仁核活动增加 ──导致──> 抑郁症和焦虑症
```

因此，只要选项说明 DNA 变异导致杏仁核活动增加，就说明 DNA 仍然处在疾病发生的原因链上。选项 C 正是“脑部 DNA 的变异是使杏仁核活动增加的原因”，可以秒选。

B 说不健康的生活习惯也会引发抑郁症和焦虑症。这只是增加了另一个可能原因，并没有回答 DNA 变异和杏仁核活动之间到底谁更相关。D 说有些患者同时发生 DNA 变异，还伴随抑郁症或焦虑症，这只是两个现象同时出现，不能直接推出 DNA 变异导致疾病；甚至还可能是疾病反过来导致 DNA 变化。

> **易错点**：同时发生不等于因果关系。题目要的是一条从被排除的原因通向结果的路径，不是把几个现象摆在一起。

#### 基因、催产素和社交能力

2019 年四川的一道题，反对者认为，4 号染色体某区域的催产素决定了人的社交能力，因此否定了 CD38 和 CD157 基因表达影响社交能力的原有观点。题目同样要求削弱反对者。

要削弱它，不能只重复“催产素会影响社交能力”，因为这只支持了反对者。我们必须把原来的基因接回催产素：

```text
CD38、CD157 基因表达 ──控制/影响──> 催产素分泌
催产素 ──影响──> 社交能力
```

选项 A 说 CD38 和 CD157 控制着催产素的分泌，正是所需的中间联系。这样一来，即使催产素是影响社交能力的直接环节，基因表达也仍然可能是更深层的原因。

B 说催产素的分泌影响共情、信任、慷慨和社交能力，只能说明催产素确实有影响，反而接近支持反对者。C 只比较 CD38 和 CD157 两种基因哪一种影响更大，而题干问的是这两类基因整体能不能影响社交能力；在两个对象内部比较，不等于回答整体有没有作用。D 说基因表达能否影响行为很大程度上取决于社会环境，表述含糊，没有把基因、催产素和社交能力连起来。

这也是一种常见坑：题目问“某一类因素整体有没有作用”，选项却让你比较这一类因素内部谁更大。看到这种内部互比，不要被它带走。

#### 全球变暖和大气环流

2021 年山东的一道题要求支持第一种观点：高温天气是气候变暖导致的。反对者认为，高温天气是大气环流造成的，与全球变暖无关。

支持第一种观点，就等于反驳反对者。我们要建立的是：

```text
全球变暖 ──改变──> 大气环流特征
大气环流特征 ──改变──> 高温等极端天气的强度
```

因此，正确选项应当说明全球变暖改变了大气环流。选项 C 说全球气候变暖通过改变大气环流的特征，改变高温等极端天气的强度，正好把两者接上。

A 把方向说反了，变成大气环流导致全球变暖；B 只是解释什么是高温天气，没有谈全球变暖和大气环流；D 说持续高温的原因很复杂，既有直接原因也有间接原因，这种“既有直接又有间接”的说法没有指出具体因果链，不能完成削弱。

题干问的是“全球变暖和高温天气有没有关系”，不是“高温天气到底复杂不复杂”。选项越含糊，越要回到那条具体的链上。

#### 污水、盐度和“不直接伤害”

这种“不会直接影响”的问法，在考研题里也反复出现，底层结构完全一样。

有一道题认为，有害物质会导致鱼死亡，但螃蟹不怕有害物质，所以捕蟹和蟹类加工不会像渔业一样受到影响。要削弱它，只需证明污水仍然能够通过某个中间环节影响螃蟹。污水可以把蟹苗杀死，可以把螃蟹的食物杀死，也可以引来更多螃蟹的天敌；这些因素任一发生变化，都可能让螃蟹的生存受到影响。

其中，幼蟹的主要食物蓝藻无法在污染水质中继续存活，就是一个标准的第三者：

```text
污水污染 ──> 蓝藻无法存活 ──> 幼蟹缺少食物 ──> 螃蟹难以存活
```

选项 C 把“污水不会直接影响螃蟹”改成了“污水仍然会间接影响螃蟹”，所以能够解释蟹类加工为什么仍可能受到影响。

后面换成盐度增加和虾，逻辑也没有变。干旱、高温导致盐度增加，鱼大量死亡；虾不怕盐，按理说盐度不会直接杀死虾，但养虾场最后仍然遭受损失。原因是高盐环境先让幼虾吃的有机物难以存活，食物消失后，幼虾自然受到影响：

```text
盐度增加 ──> 有机物难以存活 ──> 幼虾缺少食物 ──> 养虾场遭受损失
```

选项 C 正是这个结构。这里一定要分清：虾“不怕盐”，只说明盐没有直接杀死虾，不说明盐度不能通过食物等中间环节影响虾。谈鱼、谈有关部门是否注意、谈蟹类是否已经形成适应污水的机制，都没有完成这条链。

### 有替代办法，不代表旧办法没有必要

后面三道题的结构和前面的题略有不同，但本质还是一样。

题干给出的推理是：既然 A 这个办法可以实现目的 C，那么 B 就没有必要了。要反驳，不能只说 A 的成本高、口感差或者可能有其他缺点，因为这些问题并没有回答“实现 A 是否必须依赖 B”。真正能削弱它的选项，必须说明 B 是实现 A 的必要条件。

```text
题干的跳跃：

替代办法 X ──可以满足目的──> 目的 Y
所以旧办法 Z 不再需要

削弱方向：

实现替代办法 X ──必须依赖──> 旧办法 Z
没有 Z，就无法实现 X，也就无法达到 Y
```

这不是“第三者建立联系”的同一种表面句式，但它同样是在找不能绕开的条件：题干说“不用 B 也能达到目标”，我们就去找“实现 A 本身必须先有 B”。

#### 人造牛肉：合成手段仍然需要牛的来源

有媒体据此认为，人造牛肉会取代真正的牛肉，人类以后不用再养牛，只要使用人造牛肉就可以。

这里省略了题干没有明说的条件：制造人造牛肉的干细胞，必须从牛身上获取。于是链条是：

```text
想要合成人造牛肉 ──必须依赖──> 从牛身上获取干细胞
没有牛 ──> 无法获取所需干细胞 ──> 无法合成人造牛肉
```

所以，制造人造牛肉的干细胞仍然必须从牛身上获取，说明人类不能停止养牛。选项 D 直接击中这个必要条件，媒体的结论就不能成立。

A 说人造牛肉成本高、不能大规模生产，这回答的是人造牛肉能否普及，不是人造牛肉的制造是否必须依赖牛。B 说人造牛肉口感比真牛肉差，也没有回答养牛是不是合成牛肉的必要前提；口感不好，最多影响人们选择哪种牛肉，并不能推出必须养牛。C 说人造牛肉有助于应对未来肉类紧缺，这是人造牛肉的优点，和媒体所声称的“养牛不再需要”没有直接关系。

#### 现代汉语词典：网上搜索也需要词条来源

2023 年江苏的一道题中，有网友认为，互联网时代可以通过上网检索，所以现代汉语词典已经远离了人们，不再需要这本词典。

这位网友的跳跃是：网上能查到词义，所以词典没有必要。要反驳，只需找到网上词义来源对词典的依赖：

```text
想要上网检索词义 ──必须依赖──> 词典提供词条数据
没有词典提供词条 ──> 网上未必有相应内容可供检索
```

选项 B 说网上查到的词义解释其实是由词典作为数据提供的。这样一来，虽然人们表面上是在网上搜索，实际上词典仍然是内容来源，不能因为检索渠道变成了互联网，就说词典本身不再需要。

A 说词典每隔几年会修订，修订频率与人们是否远离它没有直接关系。C 说词语和用语的精确解释对国人很重要，讨论的是重要性，不是词典是否仍然参与网上词条的提供。D 说网络字词解释有时不清楚、容易出错，也不能直接推出必须使用词典；题干没有要求网上内容百分之百准确，只要能够检索到就可以。

这里尤其不要脑补。题目问的是“词典还是不是网上检索的必要来源”，不是“网上信息是否完美”。D 只有在明确说“必须用词典来校对或纠正”时，才可能击中必要条件，但原话并没有这样说。

#### 纸质书和电子图书：替代形式也绕不开来源

最后一道题中，王研究人员认为，传统的纸质书将来最终会被电子图书取代，理由是电子图书可以满足人们的阅读需求。

这里的跳跃是：既然电子图书能够满足阅读需求，所以将来不需要纸质书。要削弱它，不是说纸质书有哪些好处，而是说明电子图书的生成仍然必须依赖纸质书：

```text
想要拥有电子图书 ──必须先有──> 相应的纸质图书出版
没有纸质图书 ──> 没有相应的电子图书
```

选项 D 说，通常只有在纸质图书出版的前提下，才会有相应的电子图书。电子图书再好，也跳不过纸质书这个前提，因为没有纸质书就没有电子书的来源，纸质书就不可能被完全淘汰。

A 说电子图书可能更容易损害视力，B 说有些读者习惯纸质书、不愿数字阅读，C 也都在说纸质书或纸质阅读的某种好处。纸质书有好处，不等于纸质书永远不会被取代；将来电子阅读体验继续改善，读者习惯也可能改变。只有“没有纸质书就没有电子书”这种明确的必要条件，才真正击中了题干的结论。

> **结论**：替代办法能实现目的，只能说明“它有另一种选择”，不能说明“原来的办法不再需要”。凡是题干从“可以做到”直接跳到“因此不需要”，都要立刻追问：实现这个替代办法，是否仍然必须依赖原来的条件？

### 考场怎么识别，不要被错项牵着走

这类题秒杀的关键，不是把每个错误选项都研究透，而是先准确写出题干真正争的东西，再去找那条最直接的连接。

可以按这个顺序做：

先把题干里的对象分成三类：结果是什么，谁是题干承认的直接原因，谁被题干排除或说成不再需要。

接着把题干推理写成一条链。被排除的原因如果没有直接连接，就问它能不能通过直接原因间接影响结果；如果新办法可以实现目的，就问实现新办法是否必须依赖旧条件。

然后看选项是否准确提供了缺少的那一环。优先找“被排除者导致直接原因”或者“实现新办法必须依赖旧条件”的选项；方向一旦反了，就算话说得很像，也不能选。

最后再检查选项是否真的在说题干争议的关系。只是说某现象普遍存在、某对象比较重要、某种办法成本高、某些人暂时不接受，或者把因果关系倒过来，都不能完成削弱。

| 常见干扰 | 为什么不够 |
| --- | --- |
| 把 A 导致 B 说成 B 导致 A | 方向相反，接到题干因果链上只会得出相反结论 |
| 另找一个导致结果的原因 | 可能有其他原因，不等于题干比较的两个原因没有联系 |
| 两个现象同时出现 | 同时发生不能自动推出因果，甚至可能是结果反过来造成原因 |
| 在同一类对象内部比较谁更重要 | 题目问的是整体有没有作用，内部比较没有回答整体问题 |
| “有直接也有间接”“原因很复杂”“因人而异” | 说法过于笼统，没有给出可验证的具体联系 |
| “会引起重视”“对某人有重要性” | 主观重视或现实重要性不等于题干中的客观因果关系 |
| 谈成本、口感、修订频率、检索准确性 | 只有在题干明确把它们作为必要条件时，才可能影响结论 |

也要注意一个阅读顺序：先理解正确选项为什么对，再去理解错误选项。正确选项的结构一旦确认，其他选项往往是考官故意设置的烟雾弹；能理解就理解，理解不了也不必在它们身上耗时间。像“1+1=2”一样，看到“情绪导致神经变化，神经变化导致哮喘”，答案就已经自己站出来了。

> **易错点**：不要因为一个选项“听起来也有道理”就把它当成答案。削弱题要削弱的是题干的推理，不是找一条与题干完全无关的合理事实。

### 把两种结构记成两张图

第一种结构，是题干用直接原因排除第三者；我们用第三者把关系接回来。

```text
甲 ──直接导致──> 结果
丙 ──被判断为无关──> 结果

削弱：
丙 ──导致──> 甲 ──导致──> 结果
```

第二种结构，是题干用替代办法否定旧办法；我们寻找替代办法依赖旧办法的必要条件。

```text
新办法 ──可以实现──> 目标
所以旧办法 ──不再需要──> 目标

削弱：
实现新办法 ──必须依赖──> 旧办法
```

真正需要记住的，不是某道题里“哮喘、脱发还是全球变暖”，而是两条稳定的思考路线：没有直接关系，不等于没有关系；有了替代办法，也不等于原来的条件不再需要。识别出第三者，或者识别出必要条件，先把链条写出来，正确选项就可以直接定位。秒杀不是跳过逻辑，而是把逻辑压缩成最短的一条路，然后沿着这条路走到底。

> **承前启后**：上一节讲完「秒杀思路的基本框架」，下一节接着讲「比较之前起点必须相同：把因果比较拉回同一起跑线」。

## 比较之前起点必须相同：把因果比较拉回同一起跑线
> 对应块：BLK21 | 覆盖分集：P33 | 块标题（分集名）：《秒杀思路二上篇》

我们经常会有这样一个思维误区：衡量自己努力有没有效果时，不去和自己的起点比较，反而直接拿别人的终点来比。

条条大路通罗马，对不对？我们在通往罗马的路上努力，不能去跟那些出生在罗马的人比。要比，就拿自己努力的样子和自己没努力的样子比；如果一定要和别人比，那么两个人的起点也必须相同。起点不同，最后拿结果一比，结论很可能就是错的。

> **结论**：比较两个结果之前，先问一句——它们的起点相同吗？起点相同，结果差异才有资格用来解释某个因素的作用；起点不同，结果差异可能只是原有差距。

### 先把比较对象找对

比如小汪努力工作，最后赚钱还是没有马爸爸多。这能不能说明努力工作不会让小汪赚更多钱？不能。

小汪努力工作能不能赚更多钱，应该和“平行世界中的小汪不努力”去比较，而不是和马爸爸的终点比较。别人起点更高、平台更大、条件更好，当然不能拿来直接衡量小汪的努力。

再比如小汪天天给孩子喝牛奶，但孩子身高还是没有隔壁老王家的孩子高，这能不能说明喝牛奶没有帮助长高？也不能。隔壁老王家的孩子可能基因更好，还打篮球，是“穆铁柱”那一类；你拿两个起点不同的孩子比身高，怎么能怪牛奶？

真正要比较的是：小汪给孩子喝牛奶时的结果，和小汪不给孩子喝牛奶时的结果。

> **易错点**：题目说“有 A 的人结果好，没有 A 的人结果差”，并不自动等于“A 导致了结果好”。还要确认两组人在受到 A 之前是不是同一个起点。

### 对照实验的底层结构

很多判断推理题会把背景包装成试验组和对照组，但剥开包装，本质上就是“有 A，同时有 B；没有 A，同时没有 B”。

以增强体力的药为例：

- A 组定期服用增加体力的药，后来体力素质比 B 组高十分；
- B 组服用等量的安慰剂，相当于没有吃药。

这看上去是在说：有药并且体力好，没有药并且体力不好，因此“吃药”推出“体力提升”。

可是，想评价吃药到底能不能提升体力，最直接的比较应该是：

```text
理想比较：同一个群体、同一条起跑线

有药  ──→  体力结果
无药  ──→  体力结果

题干常见比较：
A 组有药  vs  B 组无药
```

假设 A 组吃药前和 B 组一样，都是 70 分；吃药后 A 组变成 80 分，那么多出来的 10 分就很可能是药带来的效果。

反过来，如果 A 组没吃药之前就已经是 80 分，甚至 85 分，吃药后仍然是 80 分，那么这 10 分的差异就不能直接归功于药。此时，A 组本来就比 B 组起点高，药甚至可能没有效果。

> **定义**：比较之前起点相同，是说两组在实验、训练或措施发生之前，相关基础水平一致或没有明显差异。

因此，看到选项说“试验前两组身体素质相同”，往往是在支持“药物有效”；看到“试验前 A 组本来就比 B 组好”，往往是在削弱“药物有效”。

### 起点相同怎样支持，起点不同怎样削弱

可以把这个方法整理成一张判断表：

| 比较前的情况 | 对结论的影响 | 典型表达 |
| :--- | :--- | :--- |
| 两组起点相同 | 支持“有措施就有结果” | 训练前田氏体与普通人没有区别 |
| 两组起点不同 | 削弱“结果由措施造成” | 第二组记忆力本来就偏弱 |
| 试验中还有其他影响因素 | 削弱 | A 组除了吃药，还进行了额外训练 |
| 试验中没有其他影响因素 | 支持 | 排除其他原因后，差异大概率来自该措施 |

注意这里的“同一起点”不是只看一个表面数字。判断试验是否严谨，至少要看与结论直接相关的基线。例如研究叶酸对中风风险的影响，不仅要比较两组原有的健康情况，也要比较原有的叶酸缺乏程度。一个人平时就严重缺叶酸，另一个人根本不缺，即使两人同样补了叶酸，最后结果不同，也不能简单归因于叶酸。

这也是为什么“参加试验之前、开始练习之前、训练之前”是这类题最醒目的信号词。只要选项谈到“之前”，就要立刻检查它是在说：两组相同，还是两组不同。

> **易错点**：“试验前做过检测”不等于“试验前检测结果相同”。只说检测过，却没有说结果如何，等于没有提供比较信息。

### 这类题还有两种支持方式

试验组和对照组看起来结构很复杂，其实出题方式很固定。除了“比较之前起点相同”，还可以从其他角度支持“A 推出 B”。

一种方式是**建立联系**：说明 A 本身确实可能影响 B。比如打击乐演奏者田氏体纤维更粗壮，同时说明练习打击乐能够让田氏体纤维变粗壮，就建立了“打击乐训练”和“田氏体变化”之间的联系。

另一种方式是**前件后件**：有 A 时出现 B，没有 A 时不出现 B。例如打过打击乐的人田氏体纤维粗壮，没有打过打击乐的人田氏体纤维不粗壮，这也能支持 A 推出 B。

所以，对照实验中常见的支持方式主要有三种：

- 比较之前起点相同；
- 建立 A 与 B 的联系；
- 用“有 A 有 B、无 A 无 B”的前件后件结构支持。

其中“比较之前起点相同”最固定，考官往往直接写成“在训练之前，两组没有差异”。但“建立联系”和“前件后件”也经常出现，不能只会认一种选项。

相对地，考官也可以通过引入其他原因来削弱：比如 A 组除了吃药，还吃了另一种药，或者进行了额外训练；这样，体力变好就可能不是原来那种药单独造成的。

大家不要把试验组、对照组看成可怕的东西。它反而是结构固定、比较容易秒杀的题型，因为考官能设计的支持和削弱方式就那么几种。

### 识别题干：先找 A，再找 B

题干说“练习音乐会导致大脑结构变化”，其中“田氏体变大”就是结果 B。我们真正要问的是：音乐训练能不能让田氏体变大？

最理想的比较不是“音乐家训练后的田氏体”和“普通人现在的田氏体”，而是看音乐家在训练前后发生了什么变化，再与没有训练的人作参照。

如果音乐家开始训练前，田氏体和同年龄非音乐家差不多大，训练后却明显变大，那么“起点相同、结果不同”就很支持音乐训练造成变化。

如果音乐家开始训练前田氏体本来就大，训练后还是那么大，那么训练是否让它变大就不能确定。别人训练后可能是 100，普通人可能是 70，但关键不在于音乐家之间是不是每个人都一样，而在于比较对象是“音乐家”和“非音乐家”，不是“音乐家”和“音乐家”。

这里还有一个常见坑：选项只说“音乐家彼此的田氏体体积差不多”，并没有完成音乐家和非音乐家的比较。题目要解释的是训练能不能带来变化，只要整体上音乐家比普通人有相应差异即可，音乐家内部是 100、101 还是 105，并不是关键。

另一个坑是只说“普通人小时候也参加过促进田氏体发育的活动”。即使普通人也参加過一些训练，只要他的田氏体仍比音乐家小，就不能否定训练之后的变化。除非选项明确指出，这种差异在训练前就已经存在。

### 打击乐练习：把大脑结构变化再练一遍

有一道题把研究对象换成专业打击乐演奏者：研究发现，打击乐演奏者大脑中的田氏体纤维比一般人更粗壮，因此得出“练习打击乐能够有效改变大脑结构”。

判断时要抓住比较对象：是专业打击乐演奏者和一般人。真正需要确认的是，打击乐演奏者在练习之前，田氏体是否和一般人没有区别。

如果练习前两者没有区别，练习后专业演奏者的纤维更粗壮，那么支持结论；这一类正确选项几乎是固定模板：

> 某人或某组在练习之前，起点与对照对象相同。

其他选项为什么不行？因为它们只是在说“存在差异”，却没有说明差异是不是由练习造成的。

- 左右半球与一般人存在差异：可能是天生不同，并不一定是打击乐训练带来的改变。
- 其他类型乐手也有相似特征：其他乐手也有这个特征，不能确定就是打击乐单独造成的。
- 业余爱好者介于专业演奏者和普通人之间：也可能是三类人天生就处于不同水平，不能据此建立因果关系。

核心不是看到“更粗壮”就接受，而是追问：这个更粗壮是练习前就有，还是练习后才出现？

### 严查酒驾：结果一样，不代表措施无效

还有一道题说，对交通事故的调查发现，严查酒驾的城市和不严查酒驾的城市，事故率其实一样。按表面看，似乎可以推出严查酒驾不会改变交通事故率，但多数专家认为严查酒驾确实能降低事故发生率。

问题出在哪里？严查酒驾的城市和不严查酒驾的城市，可能起点并不相同。

要判断严查酒驾有没有效果，应比较同一个城市严查前后的变化：

```text
同一个城市：严查前的事故率  vs  严查后的事故率
```

而不是只比较：

```text
城市 A：严查酒驾后的事故率  vs  城市 B：不严查酒驾的事故率
```

假如 A 城市原本事故率很高，严查后降到了和 B 城市一样；这不能说明严查无效，反而可能说明严查有效。类比一下：原来成绩不好的同学经过努力学习，最后和学霸考得一样高，你能说学习没用吗？学习当然可能有用，因为他是在弥补原来的差距。

反过来，如果 A 城市在严查前就和 B 城市一样，严查后仍然一样，那么严查可能确实没有发挥作用。

所以，“严查酒驾的城市原本事故率很高”反而能解释为什么两组现在事故率相同：不是措施没有效果，而是两组本来不在同一条起跑线上。

这题的其他选项也各有迷惑性：

- “没有消除酒驾”不等于“不能降低事故率”，一个谈的是是否彻底消除，一个是谈事故数量是否下降。
- “提高交通安全意识比严格管理更重要”，并没有否定严格管理也能降低事故率。坐飞机能更快到北京，不代表坐火车不能到北京。
- “其他交通违章也应该制止”，讨论的是别的违章，不是严查酒驾能否降低事故率。
- “大城市和小城市事故率不一样”，却没有说明 A、B 到底谁大谁小，因此不能据此解释 A、B 的差异。

> **提示**：看到“消除”“降低”“更重要”“其他也应该”等表述，要先确认它们是否在回答题干真正问的那个变量，而不是换了一个相邻话题。

### 引导问题：两组记忆能力起点不同

心理学实验把被试分成两组。第一组被问“汽车以多快的速度相撞”，第二组被问“汽车以多快的速度猛烈相撞”，第二组受到了更强暗示。一周后再问挡风玻璃是否碎，结果第二组记错的比例比第一组高两倍以上。心理学家据此认为，引导会导致更多人记错。

要削弱这个结论，关键仍然是：两组被试的记忆能力起点是否相同？

如果第二组本来就记忆力较差，第一组本来就记忆力较好，那么第二组记错更多，可能只是原有记忆能力差异造成的，和引导没有关系。

所以“第二组被试的记忆力本来就偏弱”就是典型的起点不同削弱。反过来，如果两组没有引导时记忆错误比例相同，后来第二组因为接受引导而明显增加错误，就能支持“引导导致记忆错误增加”。

几个选项可以很快筛掉：

- 第二组人数更多，但实验比较的是比例，人数多少不改变比例结论。
- “时隔一周再询问的合理性有待商榷”，属于“说了等于没说”。“有待商榷”本身就是没有给出确定信息。
- “两组被试者在认知水平上没有差距”虽然不是最严谨的记忆能力表述，但它至少没有说两组存在记忆能力差距，所以不能作为削弱。要削弱，必须明确说存在相关差距。

> **易错点**：削弱“引导导致记忆错误”不能靠“第二组人数更多”，而要质疑“第二组是否本来就更容易记错”。

### 轻断食：个体反例不能推翻整体趋势

再看一组对比试验。第一组志愿者进行轻断食，体内酮体增多，氧化应激和炎症水平下降；第二组没有轻断食，身体状况不如第一组。研究者由此认为，轻断食可以改善健康。

这里仍然是“有 A 有 B、无 A 无 B”：有轻断食，身体改善；没有轻断食，身体没有同样改善。

但如果试验开始前第一组的身体机能、应激反应本来就比第二组好，那么后来的差异可能来自起点，而不是轻断食。更严谨的选项会直接说第一组的身体素质本来就比第二组好，或者第一组炎症水平本来就更低。

反过来，如果试验前两组相关健康指数基本相似，那就是标准的“起点相同”，是对研究结论的支持。

“某一位志愿者”在连续断食后炎症得到较大缓解，不能推翻整体结论。试验组和对照组看的是整体情况、平均水平或比例，单独拿出一个个例，不能质疑整体趋势。这种选项属于个体反例，不能反驳平均值或总体性结论。

> **结论**：A 项虽然表述不够严谨，没有直接指定“第一组比第二组好”，但它确实指出了两组基础状况有差异，方向上是在削弱；C 项则明确说明起点相似，方向上是支持。

### 叶酸与中风：起点要查到“缺乏程度”

有一道稍微难一点的题，研究者想说明服用叶酸能够让中风风险下降。两组都服用固定复方制剂，区别只在于一组联合服用叶酸，另一组不服用叶酸。结果显示，联合服用叶酸的一组中风概率为 2.7%，另一组为 3.4%。

题目要支持“叶酸导致中风风险下降”，最标准的补充前提是：试验前两组患者的健康情况没有差异。

但这道题提醒我们，基线不止一个。除了健康情况，还要看与所服用的东西直接相关的初始水平——两组原有的叶酸水平是否有明显差异。

比如研究维生素对健康的影响，如果一组平时特别缺维生素，另一组根本不缺，每天还给两组补充同样多的维生素，那么最后结果不同，可能只是因为一组“缺得多”、一组“已经不缺”，并不说明同样剂量的维生素对两组效果相同。

所以，严谨的比较至少要关注：

- 试验前两组整体健康情况是否相同；
- 试验前与处理因素直接相关的基线水平是否相同；
- 试验过程中是否还有其他因素同时影响结果。

选项说“试验前两组叶酸水平没有明显差异”，就是在补充第二个起点条件，能够支持叶酸与中风风险下降之间的联系。

其他选项则没有击中这个比较点：

- 药物能对抗心肌缺血、减轻心肌梗死范围，但题干讨论的是叶酸，不是这种药。
- “不会产生任何副作用”是典型福利选项。吃任何药都不可能承诺完全没有副作用，题目也没有问副作用。
- “试验前对两组都进行了中风检测”只说检测过，没有说检测结果相同或不同，仍然等于没有提供比较信息。

> **易错点**：题干只说“做过检测”不是支持；必须说“检测结果没有差异”才真正提供了起点信息。

### 把整类题压缩成一条判断线

遇到试验组和对照组、专业组和普通人、训练者和未训练者，不要先被长文字吓住。只要按下面这条线走：

```text
找到 A：措施、训练或关键因素
找到 B：结果、变化或改善
追问 A 之前两组起点是否相同
      ├─ 相同 → 支持 A 导致 B
      ├─ 不同 → 削弱 A 导致 B
      └─ 有其他共同影响因素 → 削弱
```

还要同时记住两个层面：

一是结构层面。题干大多是“有 A 有 B，无 A 无 B”，所以支持 A 推出 B；正确选项可以从“起点相同”“建立联系”“前件后件”三个方向出现。

二是比较对象层面。一定要确认比较的是同一群体前后，还是两个群体的终点。比较对象错了，后面所有推理都会错。

最后再把几类高频坑记牢：

- 只说结果有差异，不说差异由什么造成；
- 只说做过检测，不说检测结果；
- 只说总体上存在差异，不说比较对象是不是题目要求的两个群体；
- 拿一个个例反驳整体平均值；
- 说“消除”却拿来回答“降低”，或拿“另一种方式更有效”来否定“当前方式是否有效”；
- “有待商榷”“不会产生任何副作用”这类看似肯定、实则没有实质信息的表达，不要选。

这类题真正的福利，不在于它有复杂的实验背景，而在于它的起点比较非常固定。看到“试验之前”“练习之前”“训练之前”，先找相同还是不同；看到结果差异，再问差异是不是由这个因素带来的。抓住这一点，文字再长，结构也不会散。

### 本讲提到的题目

#### 音乐训练与田氏体

有研究认为，成年音乐家与成年非音乐家相比，七岁左右开始训练的成年音乐家，其田氏体区别特别明显。由此得出结论：从幼年开始的音乐训练会导致大脑结构变化。

题目要求支持或假设这一结论。正确答案为 A：在音乐家开始训练之前，它们的田氏体体积并不比同年龄非音乐家大，训练后才出现明显差异。

解析：训练前起点相同，训练后结果不同，才能较有力地说明音乐训练与田氏体变化之间的联系。B 项“生命晚期训练”偏离了题干“幼年开始训练”；C 项只比较音乐家彼此，不比较音乐家与非音乐家；D 项没有说明非音乐家 childhood 是否参与过相关活动，不能直接解释差异来源。

#### 专业打击乐与大脑结构

研究发现，打击乐演奏者大脑中的田氏体纤维比一般人更粗壮，据此认为练习打击乐能够有效改变大脑结构。

题目要求支持这一结论。正确答案为 C：专业打击乐演奏者在练习打击乐之前的田氏体与一般人没有区别。

解析：练习前起点相同，练习后出现差异，支持练习打击乐与田氏体纤维变粗壮之间的联系。其他选项只说明存在差异，却没有排除天生差异或其他原因。

#### 严查酒驾与事故率

对交通事故的调查发现，严查酒驾的城市和不严查酒驾的城市，事故率一样。多数专家认为严查酒驾能够降低交通事故发生率。题目要求最能消除这一不一致的解释。

正确答案为 A：严查酒驾的城市，交通事故率曾经都很高。

解析：两组现在事故率一样，不等于严查没有效果。若严查城市原本事故率更高，严查后降到与另一城市相同，反而说明严查可能有效。只有比较同一城市严查前后的起点与结果，才能判断措施是否发挥作用。

#### 引导与记忆错误

第一组被问汽车以多快的速度相撞，第二组被问汽车以多快的速度猛烈相撞；一周后再问挡风玻璃是否碎，第二组记错的比例更高。心理学家据此认为，引导会导致更多记忆错误。

题目要求最能削弱这一结论。正确答案为 B：第二组被试的记忆力本来就偏弱。

解析：如果第二组原本就更容易记错，那么两组错误比例的差异可能来自记忆能力起点不同，而不是引导造成。第二组人数更多不影响比例；认为“一周后再询问的合理性有待商榷”没有提供确定信息；说认知水平没有差距也不能构成削弱。

#### 轻断食与健康改善

第一组志愿者进行轻断食，体内酮体较多，氧化应激和炎症水平下降；第二组没有轻断食，身体状况不如第一组。研究者据此认为轻断食可以改善健康。

题目要求最能削弱研究人员结论。正确答案为 A：所招募志愿者的身体机能和应激反应等本身就有差异。

解析：如果第一组原本身体状况就更好，那么两组后来的差异可能来自起点，而不是轻断食。某一位志愿者炎症缓解只是个体反例，不能推翻整体试验结果；“试验前两组相关健康指数基本相似”反而是支持。

#### 叶酸与中风风险

研究者比较了两组患者：实验组服用叶酸、卡波平等构成的复方制剂，对照组服用卡波平但不服用叶酸。实验组中风概率为 2.7%，对照组为 3.4%。题目要求补充能够支持“服用叶酸能降低中风风险”的前提。

正确答案为 A：试验前两组体内叶酸水平没有明显差异。

解析：判断叶酸是否影响中风风险，除了比较整体健康情况，还要比较两组原有的叶酸水平。初始缺乏程度不同，补叶酸后的效果就可能不同。只有相关起点一致，服用叶酸与中风风险下降之间的联系才更可信。

## 实验型因果题：别只盯着结果，先找“起点”和“如果没有”
> 对应块：BLK22 | 覆盖分集：P34-P35 | 块标题（分集名）：《秒杀思路二下篇与秒杀思路三》

好，如果一道题已经告诉你，亚洲人每天吃新鲜水果后，心脏病和中风风险降低了 34%；欧洲人吃同样新鲜的水果，风险只降低了 25%。先别急着被这两个数字绕进去。

摆在我们面前的问题只有一个：同样是吃水果，为什么两组人的效果不一样？研究者认为，是因为亚洲人的体质更适合吃新鲜水果。这个结论能不能站住？

真正能一刀切掉它的，不是“亚洲人平均寿命更长”，也不是“欧洲人还吃水果加工制品”，而是一个非常朴素的反问：**亚洲人实验前，平时吃水果的量是不是本来就和欧洲人一样？**

如果本来就不一样——亚洲人平时几乎不吃水果，欧洲人平时就经常吃——那么亚洲人突然天天吃，效果当然可能更明显。就像久旱逢甘露：本来缺得厉害，补进去当然效果大；另一边原本就不缺，再补进去，变化自然没那么明显。这样一来，风险下降比例不同，根源可能就是两组的起点不同，而不是体质不同。

这就是实验型因果题最稳的一条秒杀线：**看结果之前，先看起点；看“做了什么”之前，先看还有什么别的因素。**

### 起点相同，是因果实验的命门

这类题的结构并不复杂。常见实验会呈现这样的关系：采取行动 A 时出现结果 B，不采取 A 时没有 B，于是得出“A 导致 B”的结论。

```text
有 A ───────→ 有 B
无 A ───────→ 无 B
                   │
                   ▼
             结论：A 导致 B
```

但“A 和 B 同时出现”不等于“A 造成 B”。考官最常撬动的就是两个缺口：实验前两组的起点不同，或者 A 组还被塞进了另一个足以造成 B 的因素。

```text
观察到的差异：有 A 组有 B，无 A 组没有 B

需要排除的两种可能：
起点不同：实验前身体、状态、环境等基础条件不同
另有他因：A 组还做了别的事，那个别的事足以造成 B
```

这两个方向都能削弱。不是要证明“A 一定没用”，只要指出“结果未必由 A 造成”，结论就不能直接成立。

反过来问，支持也只有两个方向：实验前两组起点相同，或者确认没有其他原因造成结果差异。把这两处堵住，A 才是更可信的原因。

> **结论**：实验型因果题里，削弱不必推翻结果，只需证明“其他原因也可能造成结果”；支持也不必重复结果，只需排除其他解释。

#### 水果实验：难点不在数字，在“此前吃了多少”

2017 年浙江事业单位那道题难在哪里？难在它比较抽象，而且结论把不同效果归到了“体质”上。

题干用两组实验呈现差异：有吃新鲜水果习惯的人，风险下降得多；没有这种习惯的人，风险没有这么明显，于是认为吃水果与风险下降有关。题目问，最能削弱上述结论的是哪项。

正确选项 C 的信息是：与欧洲人相比，亚洲人平时就没有吃水果的习惯。它没有否定吃水果可能有益，而是指出亚洲人实验前的“水果摄入起点”更低。起点更低，开始吃之后变化更大，因果关系仍然成立；但“亚洲人效果更好”的原因，完全可能只是原有摄入不足，而不是体质特殊。

这和“两个人吃同一种维生素，一个人效果更好”是一回事。缺的人补完，效果明显；本来就不缺的人再补，变化可能很小。只要补充前的身体基础不同，后面的效果就不能直接拿来比较。

其余选项为什么不行？

- A 说亚洲人的平均寿命比欧洲人长，讨论的是寿命，不是两种吃水果习惯为什么产生了不同的风险下降比例。
- B 说有些新鲜水果与心脏关系不大，但我们根本不知道两组人具体吃的是哪些水果，不能替他补上前提。
- D 说欧洲人还吃各种水果加工制品，看似增加了欧洲人的水果摄入，可加工制品到底更好还是更坏并没有说明；而且如果“多吃水果必然降低更多风险”，欧洲人吃得更多，效果理应比亚洲人更好，D 反而让原结论更可疑，并不能解释原结论。

大家一定要抓住这里的高频语言：**“两组在实验前是否相同”“平时有没有这个习惯”“开始干预前的基础状态是否一致”。**只要选项里出现类似的比较，它就可能是在攻击“起点”。

#### 抚慰婴儿实验：先排他因，再查实验条件

2023 年山东那道题问：哪种做法最能削弱“轻微运动节奏是抚慰婴儿的最佳方法”。

实验有四组：有轻微运动节奏的婴儿平静得快；没有运动节奏的婴儿平静得慢。结论就把“更快平静”归到了运动节奏上。

考官特别爱用两种下手方式。

第一种，在实验过程中悄悄加入别的原因。比如“让父亲抱着婴儿，也能使婴儿平静下来”。这句话并不是在拆台。它把“母亲抱着”排除了：母亲抱也行，父亲抱也行，剩下最关键的差异才是运动节奏。所以这个选项不但没有削弱，反而支持了节奏的作用。

第二种，攻击四组实验的起点。比如 A 项说四种方法分别在不同时间和地点进行。这里没有必要说清究竟谁高谁低，只要指出时间、地点不同，就说明婴儿面对的环境和状态可能不一致。

比如，有运动节奏的一组恰好是在婴儿吃饱、准备睡觉时进行的；没有节奏的一组却恰好发生在婴儿饿得要哭的时候。最后一个闹得厉害、前一个安静得快，到底是节奏造成的，还是状态造成的？把这一点排除，结论才稳。

D 项说，摇动婴儿车或摇床，也会产生与行走类似的运动节奏。这也不是削弱。**类似的节奏不等于完全相同的节奏。**摇床同样可能有抚慰效果，但程度弱于走路；走路仍然可能是效果最好的方式。题干要证明节奏有效，不要求所有类似节奏的效果完全相同。

> **易错点**：读到“另一个办法也有效”，不要立刻判为削弱。先问它是在证明结论不成立，还是在排除母亲、环境等其他解释。很多看似反例的选项，反而是在替核心结论排他。

#### 餐前喝水实验：支持题就是反过来堵两个口子

再看 2017 年省联考那道题。两组人对比：餐前喝水的一组体重下降 4.3，不喝水的一组只下降 0.8，所以得出“餐前喝适量的水真能减肥”。题干还特意告诉读者，不喝水组的平均运动量反而更高。

运动量更高，却没有多减重，这已经排除了“喝水组瘦得更多只是因为运动更多”这一解释。现在要支持“喝水导致减重”，正确方向仍然是两个：

- 两组实验前的身体素质相同；
- 没有其他原因让喝水组减重更多。

C 项说，除了餐前喝水，两组其他情况都一样。这就是标准的“除关键变量外，其余条件相同”，直接把实验起点堵住。

A 项说，喝水组同时注意控制饮食。这是在给结果安上另一个原因：体重下降可能来自控制饮食，而不是餐前喝水，所以它是在削弱。倘若 A 改成“喝水组没有特别控制饮食”，才会转为支持。

D 项是一个很典型的迷惑项：不喝水组在吃饭时会喝更多汤和饮料。但汤和饮料更多，不等于总摄入一定更多，完全可能只是主食减少了。选项没有把“摄入总量”或“摄入能量”真正说清楚，不能脑补。

B 项说，不喝水组中有人减了 4 千克，也不能动结论，因为题干比较的是两组的平均效果。某一个人减得多，不代表整组平均值会跟着改变。

这些题一旦做得多了，你就会发现正确项的文字长相非常稳定：

> 在实验之前，两组起点相同；除了研究变量，其他条件一样；没有其他因素造成结果差异。

看到这些表达，就要马上意识到：命题人正面支持了“变量造成结果”。

#### 步行与按摩：起点方向不能看反

2017 年四川那道题，中风幸存者被分为步行组和按摩组。步行组走得比按摩组更远，于是研究者认为，适度运动比按摩更能促进身体恢复。

削弱有两条路：步行组可能吃了别的药；也可能两组原本的身体状态不同。C 项说，步行组还服用了相关治疗药物，而按摩组没有。这就引入了一个完全足以解释“走得更远”的他因，直接削弱运动的效果。

A 项却把年龄说反了：步行组平均 72 岁，按摩组平均 65 岁。年纪更大、身体通常更弱，本来不占优势的步行组反而恢复得更好，这更像在支持步行有效，而不是削弱。只有把两个年龄互换，让更年轻的组走得更远，才构成“起点不同”的削弱。

还有两个范围陷阱：

- B 项谈生活质量更高。题干争论的是“步行是不是让身体恢复得更多”，不是“最终生活质量会不会更高”，话题被换掉了。
- D 项说身体严重受损者接受按摩效果更佳，但题干主体是“身体适度受损的中风幸存者”。受损程度变了，主体范围也变了，不能直接反驳题干里的主体。

遇到这类题，不能只扫数字，必须把**时间、对象、受损程度、评价指标**逐一钉住。

#### 过量咖啡：非但量不同因不同因也要抓

2015 年山东那道题的标准结构更直接：第一组过量饮用咖啡，心脏病比例较高；第二组没有过量饮用咖啡，心脏病比例较低，于是得出“过量饮用咖啡会增加心脏病风险”。

B 项说，第一组被试者每天的運動量远小于第二组。这就不是咖啡一个变量不同了。第二组心脏病比例低，可能不是“没喝过量咖啡”的功劳，而是他们运动得更多、心脏更健康。第一种削弱方式已经成立。

A 项只说每天喝两杯的人心脏功能未受影响，题干讨论的是五杯或五杯以上的过量饮用。讨论对象都换了，当然无关。

C 项说咖啡因还会引发焦虑症，仍然是咖啡干的，但题干根本没讨论焦虑症。咖啡能做什么不重要，关键是它与心脏病风险有没有关系。

D 项说第一组中部分人每天喝十杯，只给了一个个体情况和数量，没有说明十杯造成了什么结果。题干本来就在说“五杯以上”，再重复一个更大的数字，没有增加任何因果信息。

这类题真正敏感的不是“咖啡”，而是三种语言：

- 实验前身体起点是否不同；
- 两组是否还做了别的事；
- 结论讨论的是平均效果、整体风险，还是某一个人的特殊情况。

#### 全麦面包：削弱还能从“测错了指标”切入

2024 年北京那道题问“无法质疑”。实验中，白面包组和全麦面包组三周后的血糖水平相同，于是研究者认为，全麦面包不比白面包更健康。

只看血糖，似乎结论成立。但这里埋了一个坑：**血糖水平相同，是否就等于健康水平相同？**

考官从三个角度设计削弱。

| 质疑角度 | 具体逻辑 | 削弱结果 |
| :--- | :--- | :--- |
| 起点不同 | 吃全麦面包的一组原本血糖就更高，实验后却降到与白面包组相同 | 说明全麦面包可能确实在降血糖 |
| 另有他因 | 吃全麦面包的一组虽然做了很多让血糖升高的行为，最后仍与另一组无差异 | 说明全麦面包的益处可能抵消了坏影响 |
| 指标不等价 | 血糖只是健康的一项指标，其他疾病相关指标可能更好 | 说明血糖相同不等于健康相同 |

A 项直接给出实验前血糖不同，是标准的起点削弱。B 项指出其他与疾病相关的血生化指标明显更好，C 项进一步点明餐后血糖不是健康的唯一指标，二者都在攻击“用单一指标代替整体健康”的跳跃。

所以三个选项都能削弱，真正选 D：有些人对全麦面包中的麦麸过敏，只能选择白面包。这里讨论的是两组受试者形成的整体实验结果，题干根本没有说“对所有人来说都必须吃全麦面包”。“有些人过敏”只是个体情况，不能证明白面包整体上不如全麦面包。有些人不能吃头孢，也推不出头孢不能治病。

> **结论**：做实验题不能默认“题目拿来测的指标就是完整结论”。论据只测了 A，结论却说 B；如果 A 并不是 B 的充分代表，选项就可以从“指标遗漏”处完成削弱。

### “如果没有”真正比较的是什么

前面这条思路练熟后，再换一把更好认的钥匙：**如果没有做这件事，会不会更好？会不会更差？**

小王女士涂了防晒霜，旅游回来还是晒黑了。防晒霜到底有没有用？不能只看“她最后黑没黑”，而要比较她涂防晒霜和没涂防晒霜之间的差别。

如果不用防晒霜会更黑，说明防晒霜仍然有用，它抵消了一部分晒黑的影响；如果不用和用了以后差不多，才说明防晒霜基本无效。

请家教也一样。小张的孩子请了家教，期末仍然没及格，不能因此说家教一定没用。如果没请家教分数更低，家教仍然有效；如果没请家教和请了以后一样，才可能说明家教没有产生作用。

吃药更是如此。癌症患者服药三年后仍然去世，不代表药一定没用。如果不服药只能活一年，药就让他多活了两年；如果不服药反而能活五六年，那才说明药可能起了反作用。

这类题真正比较的不是“结果有没有跨过一条线”，而是“做与不做之间差了多少”。

> **定义**：没有发生质变，不等于没有量变。及格与不及格是一次质变，成绩是否提高则是量变；孩子仍然不及格，不代表之前的努力没有让成绩提高。

选项语言也特别好认：只要看到“如果没有……”“不参加……”“没有实行……”，立刻判断答案是好是坏。

| 假设不做某事时的结果 | 对“该事有效”的含义 |
| :--- | :--- |
| 比现在更差 | 该事仍有效果，支持原结论 |
| 与现在差不多 | 该事可能无效，削弱原结论 |
| 比现在更好 | 该事不仅无效，甚至可能有反效果，强烈削弱 |

#### 体能训练班：看到“如果不参加”就可以秒选

2023 年北京那道题中，乐乐妈妈因为乐乐体育成绩依然不及格，就认为课外体能训练班根本没什么用。题目问，哪项最能削弱这个结论。

B 项说：如果乐乐不参加这个训练班，成绩会更差。

答案已经出来了。乐乐现在虽然不及格，但如果没有训练班会更差，说明训练班确实把成绩往上托了，只是没有跨过及格线。妈妈只盯着最终是否及格，忽略了与“不参加”的差别，所以 B 正好削弱她的结论。

A 项说体育成绩提高得很慢，一个学期确实很难见效。这反而能说明“成绩没及格很正常”，在一定程度上支持“训练班不是没用”，不能选。

C 项说体能教练经验丰富、教学经验丰富。有经验不等于这个训练班一定有效，也不等于一定无效，不能脑补出必然因果。

D 项最容易让人想到“前假后真”：小刘没参加训练，却及格了。但这还不够。前假后真要求可比主体是同一个人，或者至少是其他条件相同、相近的人。题目只说同年级的小刘，没说小刘与乐乐身体素质相同。没有控制起点，就不能把小刘的结果直接搬到乐乐身上。

如果 D 改成“与乐乐身体素质相同的小刘没有参加训练，期末也及格了”，那才可能构成有效的前假后真。但原选项没有这个条件。

看到标准表达时别贪恋其他选项。B 已经把“做”和“不做”之间的差异说清楚，直接选走即可。练习时可以把其余选项快速扫一遍，考试时则不要在已经锁定标准项后继续消耗时间。

### “只有……才……”先把箭头钉死

接下来这道 2019 年国考题故意挖了一个很明显的坑。

题干说，自从前年甲航运公司实行经理任期目标责任制以后，公司的经济效益逐年提升；但给出的结论却是：“只有甲公司经济稳步增长，才实行经理任期目标责任制。”

按我们的日常理解，很自然会读成：实行责任制，所以经济效益增长。但考官就是要你只服从文字里的逻辑结构。

设“甲公司经济稳步增长”为 A，“实行经理任期目标责任制”为 B，“只有 A 才 B”明确表达的是：

$$
B \rightarrow A
$$

也就是后件推前件：实行责任制时，经济稳步增长才成立。这里不要自作主张改成 $A \rightarrow B$。考官已经把箭头钉死了，我们就按题目给的方向走，不要跟考官较真。

要削弱 $B \rightarrow A$，只要出现“前件真、后件假”即可：甲公司经济稳步增长，却没有实行经理任期目标责任制。D 项说，如果甲航空公司没有实行任期责任制，经济效益还可以增长得更快，恰好构成这个情形。它说明经济增长并不以实行责任制为必要条件，直接击中原结论。

A 项说国家经济增速快、航运行业整体形势好，看似是“行业形势导致甲公司经济增长”的他因，可题干争论的不是“甲公司经济增长为什么发生”，而是“经济增长与是否实行责任制之间是什么关系”。它没有击中 $B \rightarrow A$。

B 项拿乙航空公司说话，而题干结论只针对甲公司。要用乙公司做前真后假，至少得说明乙公司与甲公司情况类似，或者把结论扩大为对所有公司都成立。原选项没有这个前提。

C 项说责任制调动了员工积极性，讨论的是 B 产生什么作用；题干讨论的是 A、B 之间的逻辑关系。B 推出另一个结果，与 A 能否推出 B 不是一回事。

> **易错点**：“只有……才……”不能凭生活感觉顺手换箭头。形式上就是“后件推前件”；削弱时寻找“后件为真、前件为假”。

### 评价题：别替答案先站队

“评价”看起来是新问法，实质并不神秘。题目不直接要求支持或削弱，而是问你：关键问题是什么？如果这个问题的答案朝一边，就支持；朝另一边，就削弱。

```text
                   ┌─ 答案支持结论
需要询问的关键问题 ─┤
                   └─ 答案削弱结论
```

它既不正着说，也不反着说，只把判断方向留在答案里。读选项时，要找出“答案的两面分别会落到支持还是削弱”。

#### 空气质量：两把评价尺都能用

2022 年上海那道题说，去年甲城市空气质量优良的天数比乙城市多，因此研究者认为，甲城市空气质量更好的原因是其措施更加有效。题目问，哪个问题的答案能够评价这一结论。

小汪和小李都生病了，小汪吃了某种药，恢复得比小李快。能直接说“药更有效，所以小汪恢复得更快”吗？至少要追问两个问题。

一个是：有没有与吃药无关的其他原因，让小汪恢复得更快？如果有，削弱；如果没有，支持。

另一个是：让小李也吃同一种药，他会恢复得和小汪一样快吗？如果能，支持；如果仍不如小汪，说明小汪恢复快未必源于这种药，削弱。

对应空气质量，题目可以问：乙城市有没有其他原因导致空气质量差？也可以问：乙城市采用甲城市的措施后，空气质量能否明显提升？D 项采取的是第二种问法，因此是标准答案；E 项若按第一种问法设计，同样可以评价。

A 项只问甲、乙两城措施究竟差在哪里。即便告诉你差异是若干条，也不能证明这些差异就是空气质量差异的原因。B 项问措施能否在短时间内见效，但题干没有讨论快与慢。C 项问空气质量引发的健康问题是否更少，仍是结论的下游结果，不是“措施是否造成空气质量差异”本身。

评价题要找的不是“看起来很专业的问题”，而是“答案改变后，结论跟着变不变”的问题。

#### 有规律工作与体重：与其其他情况相仿的人作比较

2017 年管综联考有一道很适合秒杀的评价题。有规律的工作会导致人长胖。研究者调查了一组刚工作八年的大学毕业生，发现其体重增加了 8 千克，于是得出上述结论。

题目问：关于结论的正确性，最需要询问的关键问题是哪项？

E 项一出来，特征就非常明显：找一组与调查对象其他情况相仿、但没有从事有规律工作的人，询问他们在同样八年中体重是增加、减少，还是基本不变。

如果这批人没有从事有规律工作，体重也同样增加，说明“长胖”未必由有规律工作造成，结论被削弱；如果这批人没有增加，甚至减少，那么长胖就更可能与有规律工作有关，结论得到支持。

这个问题的答案会直接改变结论成立与否，所以它是真正的评价问题。

D 项问男性和女性的体重增加是否有较大差异。题干讨论的是所有人的结论，男女之间的差异不能决定“有规律工作是否导致长胖”。C 项追问为什么看八年而不是七年或九年，可题干本来就在讨论一段时间的工作，调查年数具体取多少并不影响要判断的因果关系。另一个选项问八年后体重会不会继续增加，讨论的是未来趋势，也不是这八年增加是否由规律工作造成。

A 项看似相近，实际偷换了变量。它问经常体育锻炼的人体重如何变化，题干讨论的却是“有规律的工作”对体重的影响。体育锻炼当然也可能影响体重，但那是另一个原因，不能代替 E 项的比较。

考场里真有人十秒钟做完，往往不是把十道题都重新推导了一遍，而是抓住了“与调查对象其他情况相仿，但没有某项行为”这个固定结构。看到没有某项行为的人会怎样，答案已经浮出来了。

### 把两条秒杀线练成条件反射

这两条思路并不神秘，难点在于见到新题时不要又把它当成新题。

做实验型因果题，先找结论到底把哪个结果归给了哪个动作；再检查比较对象、时间和测量指标是否一致。选项若说实验前起点不同、除了某变量外其他条件一样、另有药物或治疗，那就分别对应“削弱”“支持”“削弱”。不要读完具体故事才想起逻辑。

做“如果没有”题，先把“没做某事时会更差、差不多还是更好”写在脑子里。结论说某事有用，就看不做是否更差；结论说某事没用，就看不做是否差不多甚至更好。对“更好”“更差”这种模糊词，必须追问到底什么结果，不能脑补。

考场不是用来重新学习一个新考点的，而是用来识别已经练熟的结构。看到 A 与 B 同时出现，就问：起点相同吗？有没有他因？看到“如果没有”，就问：做与不做差在哪里？这两把钥匙一旦形成条件反射，正确项就会非常显眼。

这就是所谓“先胜而求战”：还没逐字比较所有细节，结构已经告诉你该选谁。当然，结构只能帮你迅速定位，最后仍要检查主体、范围、平均值和指标有没有偷换。

## 因果倒置：同时出现，不等于谁推谁
> 对应块：BLK23 | 覆盖分集：P36-P37 | 块标题（分集名）：《秒杀思路四》

这节课讲第四个秒杀思路：因果倒置。因果倒置出现频率比较高，也是大家相对比较熟悉的一个思路。熟悉到什么程度？熟悉到你只要把这个结构看熟，选项扫一遍就能出答案——这就是“秒杀”真正的意思：不是靠聪明，是靠敏感。

为什么这个思路能秒杀？因为它的结构太标准了。标准到只要你对这个结构足够敏感，看到选项的一瞬间就能判断它是不是；不标准的地方它一个都不沾。我们先把这个结构刻进脑子里。

### 认结构：题干只有一种长相

因果倒置的题干一定是这个长相：**具备 A 特征的人，发现同时具备 B 特征**。比如经常吸烟的人往往发现他们的肺部不太好；经常做工作的人往往发现他们的腰不太好。A 与 B 同时存在，于是得出结论：所以 A 是 B 的原因。

它也可以被设计成一个实验：试验组有 A、有 B——试验组吃了一个药，结果他的病就好了；对照组没吃这个药，病就没好。于是结论是：吃药是病好的原因，A 是 B 的原因。

这种结构我们已经见了很多很多了。这里要分清一个关系：**这种结构不一定百分之百考因果倒置，但因果倒置的题一定是这个结构。** 换句话说，只要看到“A 与 B 同时出现，所以 A 推 B”，而问题问的是削弱，你就直接去看有没有因果倒置的选项；有，直接就选；没有，再去思考这个结构的其他考法。

```text
题干结构：具备 A 的人 ──同时出现──▶ 具备 B 的人
          （A 与 B 同时存在）  ⇒  结论：A 是 B 的原因

  ┌ 问削弱 ──▶ 因果倒置：不是 A 推 B，而是 B 推 A
  │            也可引入他因：别的原因导致了 B
  │            也可直接针对结论反驳
  ├ 问支持 ──▶ 建立联系：A 带来的某个作用 / 影响因素 ⇒ B
  │            或前甲后甲：没有 A 的人确实不 B
  └ 问假设 ──▶ 排除因果倒置，坐实 A 推 B（假设题正着说是支持，反着说是削弱）
```

读图记住三件事：削弱里最先找因果倒置；支持里是建立联系和前甲后甲；假设题问的是“最可能依赖的假设”，正着说就是支持，反着说就是削弱。

### 认选项：因果倒置只有两种长相

第一种，最标准的那种：**具备 B 特征的人，往往是选 A**。注意它的口吻：不是 A 导致了 B，而是 B 导致了 A。

第二种稍微绕一点：A 和 B 虽然同时存在，但它俩没有因果关系。为什么？因为是 C 同时导致了 A 与 B。既然 A 和 B 同是 C 的结果，那它俩之间就不必然有因果关系。

> **定义**：因果倒置就是题干由“A 与 B 同时存在”推出“A 导致 B”，选项反过来告诉你是 B 导致 A；它的变形是引入一个第三因素 C，让 C 同时导致 A 与 B，从而把 A 与 B 的因果关系架空。

考官考因果倒置，选项基本就是这两种长相：要么直接倒置，要么引入 C。我们把这两只眼睛练出来，后面就是一秒钟的事。

### 问削弱：标准倒置一网打尽

先说一个总原则：当一个标准的因果倒置选项摆在面前，你知道考官心里的正确选项就是它了，其他选项就不要脑补了。最快的办法就是直接找标准的因果倒置选项，直接选，人走就行了。除非选项里根本没有这样的标准选项，你不得已才逼着自己去脑补，那是另外一种情况。

**2016 广东·咖啡与心脏病。** 调查显示经常喝咖啡的人患心脏病的概率更高，题干里风险高出了 2.5 倍；结论是咖啡中的某种物质一定是导致人们患上心脏病的原因。A 与 B 同时存在，削弱题，直接找倒置：C 选项说的是不是喝咖啡导致心脏病，而是得心脏病的人特别爱喝咖啡。标准倒置，秒杀。其他选项不要脑补：爱喝咖啡的人大都性格开朗、喜欢运动，运动的人心脏病风险就一定低吗？不一定；用餐时喝咖啡可以降低血脂，降低血脂就一定降低心脏病风险吗？不一定；咖啡含有提高心脏活力的成分，心脏活力高心脏病风险就一定低吗？也不一定。一看 C 在那儿，A、B、D 就别想了。

顺带提醒一句，你还可以把 C 换掉：如果把实验的“之前起点”写出来——比如参加研究前心脏健康状况就比不喝咖啡的人差——那心脏病的概率当然高，这就是之前讲过的“比较之前起点不相同”；或者说两组人每日运动量不一样，那高出 2.5 倍的差距也可能是运动造成的，而不是咖啡。C、E、F 在那样的改写下都能成为正确选项，考官只是选其中一种。

**2018 广东·关门窗与睡眠质量。** 调查发现关闭门窗入睡的人更容易频繁醒来、睡眠质量不佳，于是认为就寝时关闭门窗会降低睡眠质量。结构照旧，削弱题。选项 B：睡眠质量差的人更喜欢关闭门窗睡觉——不是关窗导致睡不好，而是睡不好的人更爱关窗。因果倒置，秒杀。顺带把其他选项的路堵死：A 说调查对象大多数是年轻人，我们讨论的是关窗和睡眠质量，年轻人关不关窗关它什么事？无关；C 说门窗紧闭影响空气质量从而影响睡眠，这是标准的建立联系，这道题如果问支持，选的就是 C；D 说夜间开窗并不适合所有房间——这是“不完美”型选项，不适合所有房间不等于弊端，我适合 90% 的房间难道不行吗？这是考官常用的迷惑方式，记住：不要把“不完美”“不适用于所有情况”当成削弱。

**2024 事业单位·睡眠质量与身体问题。** 睡眠质量不好的人同时总会出现一些身体有问题的症状，比如偏头疼，于是得出结论：睡眠不足导致身体出现问题。又是 A 与 B 同时存在，削弱。选项 C：身体常出问题的那些人往往患有睡眠质量过差的问题——不是睡眠不足导致身体出问题，而是身体出问题的人更容易睡不好。因果倒置，秒杀。A 只说人体总会出现一些问题，没说这问题是不是睡眠不足造成的，无关；B 说平常人偶尔也会睡眠质量差——我管你平常人呢，题干讨论的就是这帮睡眠质量不好的人；D 说两组人员的性别和年龄并不完全相同，这是很多同学经常掉的坑：并不完全相同并不是一个削弱，我不需要百分之百全部相同，他们可以略有差异——100 分、99 分、98 分，这也叫因人而异，并不代表有好有坏。D 永远不要选。

**2020 江苏·社交软件与基层工作人员健康。** 调查报告：使用社交软件的人，患某病的概率都比较低；管理人员据此认为，使用社交软件有利于基层工作人员的健康。削弱题，找倒置。C 选项：该企业基层工作人员压力很大，身心健康的那帮人。正是因为身心健康，才会在工作之余使用社交软件——是身心健康导致他们会用社交软件，而不是使用社交软件让人更健康。标准倒置，秒杀。A 是考官经常挖的坑：长时间使用电脑或手机会引发健康问题——使用社交软件不等于长时间使用电脑或手机；就算把电脑手机换成社交软件也不行，因为题干没说“长时间使用”，你不要长时间使用不就行了。B 说员工没有足够时间和精力锻炼身体，那又怎样？有没有时间锻炼身体，跟社交软件能不能让人更健康，是两回事，无关。D 说工作人员普遍在 40 岁以上，很多人不用社交软件——我管你不用社交软件的人怎么样，我们讨论的正是使用社交软件的人，无关。

**2020 四川·宠物与家庭幸福感。** 调查显示饲养宠物的家庭幸福感普遍较高，高于没养宠物的家庭，于是认为饲养宠物有助于提升家庭幸福感。削弱，找倒置。D 选项：家庭饲养宠物通常是因为成员中有时间而且有家庭幸福感——不是养宠物让人更幸福，而是幸福的人才会去选择养宠物。这跟前面那道社交软件一个味儿，秒杀。其他选项是考官故意考你会不会脑补：样本数量不足——记住，仅仅说样本不足的选项一般不会成为正确选项，除非其他选项烂到渣，只要有一个选项像点人样都别选它；B 说养宠物的多是居住条件较好的居民，居住条件好跟幸福感高有什么关系？不要脑补，题干没说；C 说没养宠物的家庭成员多是工作繁忙的在岗职工，繁忙就一定不幸福吗？有些人工作繁忙也可以很充实、很幸福。不要脑补居住条件好就等于幸福，也不要脑补繁忙就等于不幸福。

**2025 省联考·晚睡与头脑敏锐。** 研究发现晚睡的人在认知测试中表现更好，于是认为晚睡的人比早睡的人头脑更敏锐。文字看似有点长，但试验的看结果就行，结构照旧。A 选项：认知测试得分高的人睡眠质量很高，他们不需要太早进入睡眠，所以他们选择晚睡——不是晚睡导致头脑好，而是头脑好的人选择晚睡。标准倒置，秒杀。考试时直接过，前面这些字都不用看，这样才能省时间。B 说既不能睡太多也不能睡太少对保证大脑敏锐的思考至关重要：这道题讨论的是晚睡和早睡，睡多睡少和早睡晚睡不是一个概念，对概念的定义一定要敏锐，别被考官这样一下子诱导到脑补的坑里；C 说无论晚睡还是早起都是个人生活习惯，受多重因素影响——那晚睡到底脑子好还是不好？你光说受到多重影响，一个好与坏都没说，属于说了等于没说；D 说晚睡者有夜间活动习惯，难早起，起床后精力不济——精力不济了，认知就一定出问题吗？不一定，精力不济也不能说晚睡的人头脑就不敏锐了，不要脑补。

**2020 浙江·社交媒体与孤独感。** 问卷调查显示，在社交媒体上花费超过 120 分钟的人，感受到的孤独是那些不花的人的两倍；研究人员解释说，可能是因为社交媒体花的时间越多，现实中交流就越少，就更容易感到孤独。结论：社交媒体花的时间长是人们感受孤独的原因。这里再记一个等价关系：**“A 是 B 的原因”和“改变 A 就能改变 B”是一回事**，结论说减少社交时间有助于减少孤独感，跟“社交时间是孤独的原因”在结构上完全一样。削弱，找倒置：A 选项，越容易感到孤独的人越喜欢用社交媒体——不是社交让人更孤独，而是孤独的人更喜欢用社交。秒杀。其他选项全是坑：对生活满意度越低就一定越孤独吗？很多人满意度低不在于不孤独，在于没有钱，有钱了谁还在意孤独不孤独；通过社交媒体了解其他人的生活，跟你孤独不孤独有什么关系；发表积极经历让接收信息的人心态失衡，看见别人好自己心里过不去——这选项也太离谱了，考官随便编的，即使心态失衡也不代表孤独。心态失衡、了解别人的生活、满意度低，都不能脑补成孤独或者不孤独。

### 反过来做：假设题里排除倒置就是支持

前面全是在削弱里找倒置。但这个结构反过来还能用，而且威力更大。关键就是一句话：**改变 A 就能改变 B，这句话成立的前提是 A 必须是 B 的原因。** 如果 A 不是 B 的原因，你改变 A 也就影响不了 B。

打个大家再熟悉不过的比方：细菌和感冒往往同时存在，细菌含量高的人往往同时有感冒，所以我减少细菌就可以治疗感冒——这句话对不对？对，因为细菌是因、感冒是果，改变因就能改变果。可是如果我改成：感冒的人同时总是有很多鼻涕，那我减少鼻涕能不能治疗感冒？不能。因为鼻涕是感冒的果而不是因，擦掉鼻涕当然治不好感冒。

```text
结论：减少 A 能治疗 / 改善 B   ⇔   A 推 B（A 是因，B 是果）

  A ──因──▶ B      减少 A ⇒ 可能改变 B    ✔ 假设成立
  B ──果──▶ A      改变 A ≠ 改变 B        ✘ 前提不成立
     （感冒 ──▶ 鼻涕：擦鼻涕治不了感冒）
     （细菌 ──▶ 感冒：减少细菌可能治好感冒）
```

那医生说“减少铝就能治疗痴呆”，他的结论要成立的前提是什么？就是铝一定是生病的原因，而不能是生病带来的结果。要支持这个假设，就得说不是 B 推 A，而是 A 推 B；也就是排除掉因果倒置的选项——不是 B 推出 A，那自然就支持了 A 推出 B。记住这个思维：**排除掉因果倒置，就是支持。**

**2011 管综联考·硅化物治疗行为痴呆。** 这道题比较难，五六十%的同学第一次做都会做错。题问的是医生最可能依赖的假设。背景是：行为痴呆的人往往铝含量比较高，同时有一种硅化物可以吸收铝，于是陈医生据此认为可以用硅化物治疗行为痴呆。“硅化物减少铝、改变了铝就能改变痴呆”，说明铝是痴呆的原因。答案就是排除倒置的那个选项：**D，过量的铝是导致行为痴呆的原因**——铝是痴呆的原因，而不是痴呆的结果，排除了“痴呆带来铝”这种因果倒置；既然铝是原因，减少铝当然就能影响痴呆。其他选项：A 说行为痴呆症大脑组织的铝通常过高、但具体数量不会变化——数量变不变跟铝能不能治疗痴呆没关系，我管你变不变；B 说硅化物在吸收过程中不会产生副作用——这根本不是我们对一个药的要求，我们只要求弊不大于利，“不会产生任何副作用”不选；C 说用来吸收铝的硅化物的数量与年龄相关——数量跟年龄的关系对不对，跟能不能治病没关系，无关；E 说脑组织铝含量与病情严重程度有关——这确实是复述了论据，A 与 B 确实相关，但谁是因谁是果没说，只是相关而已。

**公考原题·狗的镁离子与行为焦虑。** 这道题跟上一道没有任何区别，只不过把人换成了狗，把铝换成了镁离子，把吸收铝的化合物换成了一种能降低镁离子的药。焦虑症的狗血液中镁离子含量高，所以“降低镁离子就能治疗行为焦虑”。跟鼻涕一样：要是镁离子只是病的结果，改变它也没用。所以正确选项必须说镁离子是生病的原因，而不是生病的结果。答案还是 **D：行为焦虑症不会让狗的血液中产生更多的镁离子**——焦虑症推出镁离子这件事不存在，就排除了镁离子是患病结果的可能，那就一定是镁离子导致焦虑症，改变镁离子当然就能改变患病状态。跟上一道题的 D 一模一样，区别只是排除的对象从“痴呆带来铝”换成了“焦虑带来镁离子”。这里的坑在 A：正常狗的血液中没有镁离子——题干讨论的是镁离子含量的高低，高低和有无是截然不同的两个关系，题干说高低、选项说有无，肯定不对。恰恰相反，要支持“镁离子高是生病的原因”，应该说那些没有生病的狗镁离子都低，这才是前甲后甲的支持。B“不会产生任何副作用”永远不选；C“不同阶段的狗需要口服不同剂量”，跟上一道“数量与年龄相关”是一个坑，不影响镁离子到底是不是原因。

### 难题照样秒杀：文字再晦涩也要看穿底下的结构

再看两道文字比较晦涩的题。文字晦涩不要紧，一定要看懂底下的结构。

**2020 管综联考（考研）·方向感与嗅觉。** 教授根据实验推测：一个人的空间记忆力好、方向感强，会使他的嗅觉更为灵敏。实验结果是寻路任务中得分高的人嗅觉也灵敏，标准的 A 与 B 同时存在。削弱要设计的就是嗅觉灵敏推出方向感强。**A 选项**：大多数动物主要靠嗅觉寻找食物、躲避天敌，嗅觉进化有利于导航——正是嗅觉推出了方向感强，结构没问题；主体是“大多数动物”，动物到底等不等于人？人也是动物嘛，如果其他选项都比较差，就说明考官就是故意的，看你能不能想到这一点。选 A。其他选项为什么不行：B 说有些参试者是美食家，常应邀到各处品尝美食——他只说了嗅觉灵敏或者味觉灵敏，没说方向感强，何况还是“有些”；C 说部分参试者是马拉松运动员，方向感很强，但只说了方向感没说嗅觉；这些都是个例。在对比试验、在做实验、人数很多的实验里面，个体反例是不行的，讨论的是平均值和整体情况。D 说同样的测试中该教授本人记忆力强——只要做实验，本人下场肯定不能选，我们讨论的是试验的结果。E 说有的年轻人因为过分投入方向感要求比较强的电脑游戏，食不知味——这是前真后假吗？不是。喜欢玩游戏的人很菜，瘾却特别大，“人菜瘾大”，喜欢玩方向感要求强的游戏，不等于这个人方向感一定强。所以 B、C、D、E 全不选，A 就是考官设计的一个标准的因果倒置。

**2020 管综联考（考研）·部落战争与男女比例。** 一般情况下男女比例差不多恒定，可某个时间段女性数量比男性高了三倍以上，男女严重失调；与此同时，围绕着父系组织的大量部落开启了战争模式。结论：部落战争导致了男性被杀、女性被掳，导致了该时间段男女比例的严重失调。又是“与此同时”——两个东西同时存在，然后说 A 推 B。削弱要是考因果倒置，他会怎么说？不是战争导致男女失调，而是男女失调引发了部落战争。**E 选项**：某种疾病导致男性大量死亡，使得当时部落严重缺乏劳动力，通过发起战争来获得劳动力和食物的补给——疾病导致男性大量死亡，男女已经失调；由于失调导致部落战争。标准的因果倒置，选 E。过其他选项时心里要一直清楚：这道题讨论的只有部落战争和男女失调，他俩谁是因谁是果。A 说其他时代也存在过男女失调——光说失调肯定不行，我们还没有说部落战争；B 说动物界不少动物雌性数量远超过雄性——主体不对，而且你只说了失调，没说战争；C 说人类是哺乳动物，出生时男女比例是 1.04 比 1，长大后一般不会有大规模变动——跟题干的变动、战争、男女比例的关系都没说，无关，随便扯的；D 说古代战争主要以男性参战为主、战争非常凶残、生还者极少——这说明战争确实会让男女失调，虽然不是一个严谨的支持选项，但本质上是顺着题干说的，是支持而不是削弱。

### 引入第三者：C 同时导致了 A 和 B

除了直接说“不是 A 推 B，而是 B 推 A”，解释“A 与 B 为什么同时存在”还有另一种方式：是 C 同时导致了 A，也同时导致了 B。A、B 同时存在，但两者之间可能没有因果关系，都是 C 导致的。这也是对“A 推 B”的削弱，而且考官很爱考——这就是因果倒置的变形。

**2019 浙江·地球转速与强震。** 研究发现地球转速放缓的同时强震增多，于是认为地球转速放缓导致强震多发。标准的 A 与 B 同时存在。考官当然可以说“不是转速放缓导致强震，而是强震让转速放缓”，标准的倒置；也可以不这么说。选项里 D 就是后者这种“共同他因”：地球地核的轻微变化导致地球转速放缓，也导致全球范围的强震多发——C（地核变化）同时导致了 A 和 B，那 A、B 就不一定有因果关系了。选 D。这是一种变形的因果倒置。A 只举了一个数字陈述：转速缓慢的时期每年发生 25~30 次强震，其他时期约 15 次——它只是确认了同时存在，并没有说明谁是因果；B 说转速放缓时期火山喷发时间没有明显变化——我们讨论的是转速放缓和强震，你给我整火山喷发肯定不选；C 说转速放缓会使昼夜长短发生变化，导致全球强震多发——地球放缓带来的一个作用、一个影响因素，最后强震多发，这是非常漂亮、标准的建立联系的支持。题目问削弱选 D，问支持选 C。不管考官在因果倒置和共同他因里选哪一种，我们都要能秒对。

**2019 国考·应激与慢性疼痛。** 这道题问的是支持。论据是：应激本身没有镇痛能力，但流行病调查发现长期应激与疼痛慢性化的发生正相关——所谓正相关，就是 A 多的时候 B 也多，两件事相关。但相关是没有因果方向的：A 多导致 B 多有可能，B 多导致 A 多也有可能，相关只是同时存在，不代表因果关系。结论是：长期处于巨大压力下的人群，疼痛的症状更易迁移，进而发展成慢性疼痛，也就是 A（长期应激、巨大压力）是因，B（疼痛慢性化）是果。问支持时最喜欢两种方式：建立联系和前甲后甲。**B 选项**：长期应激带来的作用因素影响，使人的疼痛抑制系统的功能被削弱了——这就是标准的建立联系的支持。那如果问削弱呢？A 选项：具有焦虑倾向的人同时应激水平高，疼痛慢性化的发展发生率也会更高——有一个东西同时导致了 A 和 B，看似相关其实是因为有第三者总在同时导致它俩发生，所以削弱了“A 是因 B 是果”，这就是变形的因果倒置。C 说吸烟与之应激相似——我们讨论的是长期应激和巨大压力能不能产生疼痛慢性化，吸烟与之应激相似并不能代表它们有因果关系。D 是个大坑：如果能有效地缓解应激、保持心态平和，疼痛慢性化发生率将降低 50%——这是不是前甲后甲、是不是建立联系？注意题干出现程度副词的时候一定要小心。这道题说的不是应激，是“长期”应激；“长期”对应的是什么？对应的是时间的长短；缓解应激对应的是什么？是程度的高低。时间的长短和程度的高低不是一回事。即使你有效地缓解了应激，它是长期应激还是短期应激？不一定吧。你不能脑补说有效缓解了应激就等于没有应激了、就没有长期应激了。D 要想成为前甲后甲的支持，必须明明白白把“没有长期应激”写在选项里。所以记住：有效缓解不等于不长期应激。

**2024 广东·为他人花钱与幸福感。** 调查发现，在别人身上花钱支出比例较大的人幸福感比较强，于是有人认为：为了提高幸福感，购物时应该给别人花更多的钱；或者说“给别人花更多的钱可以提高自己的幸福感”，改变花钱比例就能改变幸福感，花钱是因，幸福是果。削弱要说不是花钱导致幸福，而是幸福感高的人特别爱给别人花钱——跟养宠物那题一模一样。但选项里没有这句话，它有另一个：与他人关系好的人，同时很幸福，同时也喜欢给别人花钱。引入了一个 C：与他人关系好，同时导致了 A（给别人花钱）和 B（幸福），把 A 与 B 的因果关系削弱了，变形因果倒置，秒选 D。考官一般考因果倒置就这两种选择：要么直接倒置，要么引入 C。其他选项：给友人推荐的商品如果受到认可，人们也会感到幸福——题干里这帮人到底存不存在“推荐商品”这件事，根本没说，题干研究的是花钱比例，跟“受不受人喜爱”是两回事；为他人购买的商品没有受到人喜爱，容易使人沮丧——题目没有说买的东西喜欢不喜欢，单说你花没花钱，你爱买啥买啥，受人喜爱肯定不能选，只讨论花钱，不讨论喜欢不喜欢；购物带来的快感很短暂，个人面临的困难不会因为购物而消失——所以给别人花钱到底能不能提高幸福感，跟没说一样，有困难有压力就不幸福吗？迎难而上，有时候反而很幸福。

**2015 河南·掌握两种语言与延缓痴呆。** 研究发现，同时掌握两种语言的人患痴呆的时间都会晚一些，于是认为掌握两种语言可以延缓痴呆。削弱秒选 B。考官当然可以这样设计：说大脑认知功能好的人，因为他们认知功能好，所以喜欢去学两种语言，而认知功能好本身也能延缓痴呆——一个 C（认知功能）同时导致了 A（会双语）和 B（延缓痴呆）；如果不这么说也行，你可以说某种基因既同时导致了他们有语言天赋，又同时导致了他们的脑子很好。你随便找一个事，只要能找到 C 同时导致 A、B，就说明不是 A 与 B 有因果关系。当然，考官也可以直接考因果倒置：说那帮痴呆比较晚发生的人，他们不知道为什么，反正就喜欢学两种语言。C 说相当多的人只掌握一种语言，但一生都没有出现痴呆——我们讨论的不是那些只掌握一种语言的人，我们讨论的就是掌握两种语言的人，他们是不是导致痴呆发生得晚；至于是只掌握一种语言的人，根本不是这道题的讨论范围。跟前面那道社交软件一个道理：我管你不用社交软件的人怎么样。

### 这些坑，考官很爱挖

做了这么多题回头看，你会发现考官挖的坑翻来覆去就是那么几个。把它们钉死，比多刷十道题还管用。

> **易错点一**：“并不完全相同”不是“不相同”。我不需要百分之百全部相同，100 分、99 分、98 分也叫因人而异，并不完全相同也可以非常接近。选项里出现“并不完全相同”，永远不要选。

> **易错点二**：“样本数量不足”轻易不要选。除非其他选项烂到渣，再考虑它；只要有一个选项像点人样，就不要选它。

> **易错点三**：程度副词要盯着。题干说“使用社交软件”，选项说“长时间使用电脑或手机”，这是两个概念；就算把电脑手机换成社交软件也不行，因为题干没说长时间使用。题干说“长期应激”，选项说“缓解应激”，也不行——“长期”是时间的长短，“缓解”是程度的高低。

> **易错点四**：“不完美”“不适用于所有情况”不是削弱。不适合所有房间，不等于我就是弊端；我适合 90% 的房间难道不行吗？

> **易错点五**：“有”和“高”不一样，“没有”和“低”也不一样。题干讨论镁离子含量的高低，选项说正常狗没有镁离子，概念就偷换了。

> **易错点六**：相关不等于因果方向。E 说脑组织铝含量与病情严重程度有关，确实相关，但谁是因谁是果没说，只是复述了论据而已。

> **易错点七**：看讨论范围。题干讨论使用社交软件的人，你就别管那些不用的人；题干讨论掌握两种语言的人，你就别管只掌握一种语言的人；题干讨论睡眠质量不好的人，“我管你平常人呢”。

> **易错点八**：药物不需要零副作用。我们对一个药的要求是弊不大于利，“不会产生任何副作用”这种选项不选；“不同阶段需要不同剂量”“剂量与年龄相关”也不影响它能不能治病。

> **易错点九**：最经典的脑补链条，能避则避：居住条件好就等于幸福、繁忙就等于不幸福、对生活满意度低就等于孤独、心态失衡就等于孤独、精力不济就等于头脑不敏锐、没有时间锻炼就等于用社交软件不能更健康——这些题干都没说，考官就爱顺着你的脑补给你挖坑。

把这些收好，还有一个总原则再强调一遍：**当一个标准的因果倒置选项摆在面前，其他选项就不要脑补了。** 直接找标准倒置选项，直接选，人走就行。除非选项里根本没有标准选项，你不得已才逼着自己脑补，那是另外一种情况。

### 越敏感，才能越快越对

秒杀思路的因果倒置，我们就讲到这里。总结一下：标准的结构就是“A 与 B 同时存在，所以 A 是因、B 是果”，或者说“改变 A 就能改变 B”。只要是这种结构，考官想考削弱，就有可能出因果倒置的选项；当然也有其他的考法，但我们只要看到因果倒置的选项，问的是削弱，直接秒选，没问题。

这个思路真正考验的不是智商，而是敏感度：对题干结构的特征越敏感，对选项的正确性越敏感，大家就可以越快、越对地做好我们的考试题。

秒杀思路四就先讲到这儿。接下来，我们讲秒杀思路五。

### 本讲提到的题目

1. **2016 广东｜咖啡与心脏病**：调查发现常喝咖啡的人患心脏病概率更高，结论认为咖啡中的某种物质导致心脏病。**答案 C**——心脏病患者特别爱喝咖啡，因果倒置。换成“两组实验者之前起点不同”“每日运动量不同”（E、F）同样能削弱。
2. **2018 广东｜关窗与睡眠质量**：关闭门窗入睡者更易频繁醒来，结论认为关窗会降低睡眠质量。**削弱选 B**（睡眠质量差的人更喜欢关窗），**问支持选 C**（关窗影响空气质量进而影响睡眠），D“夜间开窗不适合所有房间”是无关项。
3. **2024 事业单位｜睡眠质量与身体问题**：睡眠质量差者常伴偏头疼等身体问题，结论认为睡眠不足导致身体问题。**答案 C**——身体常出问题的人往往睡眠质量差，因果倒置。
4. **2020 江苏｜社交软件与健康**：使用社交软件者患病概率低，管理人员认为社交软件有利于基层工作人员健康。**答案 C**——正是因为身心健康，才会在工作之余使用社交软件。
5. **2020 四川｜宠物与幸福感**：养宠物家庭幸福感较高，结论认为养宠物提升家庭幸福感。**答案 D**——成员中有时间且已有幸福感的家庭才会去养宠物。
6. **2025 省联考｜晚睡与头脑敏锐**：晚睡者认知测试表现更好，结论认为晚睡使人头脑更敏锐。**答案 A**——认知好的人睡眠质量高、无需太早入睡，所以他们选择晚睡。
7. **2020 浙江｜社交媒体与孤独**：社交媒体时长超 120 分钟者孤独感为不花者的两倍，结论认为社交时长是孤独的原因。**答案 A**——越容易感到孤独的人越喜欢用社交媒体。
8. **2011 管综联考｜硅化物治疗行为痴呆**（问医生最可能依赖的假设）：**答案 D**——过量铝是行为痴呆的原因，排除“痴呆带来铝”的因果倒置；“不会产生副作用”“数量与年龄相关”不是这个结论的必要前提。
9. **公考原题｜镁离子与狗的行为焦虑**（问假设）：**答案 D**——行为焦虑不会让狗的血液中产生更多镁离子，排除了“焦虑带来镁离子”的因果倒置。
10. **2020 管综联考（考研）｜方向感与嗅觉**：寻路得分高者嗅觉灵敏，教授推测方向感强会使嗅觉更灵敏。**答案 A**——嗅觉进化有利于导航（动物含人）；美食家、马拉松运动员、教授本人、爱玩方向感游戏的人，都不足以构成削弱。
11. **2020 管综联考（考研）｜部落战争与男女比例**：结论认为部落战争导致男女比例严重失调。**答案 E**——疾病导致男性大量死亡→缺乏劳动力→发起战争，因果倒置。
12. **2019 浙江｜地球转速与强震**：结论认为地球转速放缓导致强震多发。**答案 D**——地核轻微变化同时导致转速放缓与强震多发；**问支持选 C**（昼夜长短变化→强震）。
13. **2019 国考｜应激与慢性疼痛**（问支持）：**答案 B**——长期应激削弱人的疼痛抑制系统功能；**问削弱选 A**（焦虑倾向同时带来高应激与更高的慢性化发生率）。D“有效缓解应激”不等于“没有长期应激”。
14. **2024 广东｜为他人花钱与幸福感**：花钱比例大者幸福感强，结论认为购物时应给他人花更多的钱。**答案 D**——与他人关系好的人既幸福又喜欢给别人花钱，引入第三因素。
15. **2015 河南｜双语与延缓痴呆**：掌握两种语言的人痴呆发生较晚。**答案 B**——引入第三因素（如认知功能好或某种基因）同时导致“会双语”与“延缓痴呆”；“只掌握一种语言却未患痴呆”不在讨论范围内。

## 你看到的，未必是全部
> 对应块：BLK24 | 覆盖分集：P38 | 块标题（分集名）：《秒杀思路五》

### 那些活蹦乱跳的流浪猫

好，大家先想一想：我们在街上看见很多流浪猫，它们看起来都活蹦乱跳的，是不是就能说明，流浪猫其实很容易生存下来？

还真不一定。

因为死掉的那些流浪猫，你根本看不见。你能观察到的，往往只是那些成功活下来的幸存者，不能因为他们状态不错，就反推所有同类都能顺利活下去。这种“我见到的就是全部”的想法，就是**幸存者偏差**。

生存状况与“能不能看见”有关，而不是“它们都容易活下来”本身在起作用。这个判断是后面所有例子的共同起点。

再看一个更直观的：在战地医院里，伤员往往表现为胳膊、腿受伤。我们如果据此认为“战争中最容易中弹的部位是胳膊和腿”，能不能这样推？

不能。因为没被击中胳膊和腿的人——例如击中头部的伤员——可能根本没能回到医院，自然也不会出现在我们观察到的伤员里。

> **易错点**：只说“样本少”，并不必然能质疑一个统计或抽样结果的效力，关键要看它是否具备足够的随机性与代表性。

二战时分析怎样加固飞机以减少被击落，也有过类似的故事：返航飞机的伤口大多集中在机翼，于是有人主张加固机翼。但我们看到的只是能飞回来的飞机；机腹或其他要害部位受创的飞机可能根本没能回来。只盯着“幸存飞机”的伤口分布，不能直接代表所有飞机的损伤情况。

这和1966年我国华北地区大旱的背景不同；这与二战飞机加固的故事，恰好属于两个不同层面的时代对照。我们能把握的核心方法都是一致的：**看得到的那一部分，未必能代表没看到的那一部分**。不要因为眼前样本似乎“很明显”，就把它当成所有情况。

如果我们身边的人恰好大多是本科毕业生，这不能直接推出“所有人都应该大学毕业”。据一组统计，中国目前具有本科学历的人只占5%～6%。我们眼中“身边的人是什么样”，并不等于社会总体就是这样。

> **提示**：世界很大，不要一叶障目，不要把自己观察到的东西当成全部情况。

### 抽样与代表性

#### 从局部到整体的推断

那么，幸存者偏差的推断究竟哪里出了问题？

它通常想通过眼前的一部分——或者统计中的一个样本——去推测全部个体，认为眼前看到的一些特征就是全体都具备的共性。问题在于：当前看到的那一部分，如果本身就不具有普遍性，那当然不能直接拿它来代表全部。**如果样本缺乏随机性或代表性，由此得出的统计结论就未必可靠。**

这正是为什么不能简单地说“样本数量少，所以统计结论不可信”。做统计不可能把所有人逐个调查一遍，抽样调查准不准，关键不是抽了多少人，而是抽取的人能不能覆盖不同的情况，即是否具备足够随机性和代表性。

看一个抽样对比，左边有多个局部范围，在不同位置看到的比例差异很大；右边充分随机抽取不同数量的样本点后，都会呈现相近的比例结论。读图时可以看到，随机分布下，样本较少、较多的局部选取仍能比较稳定地反映总体；但非随机抽样时，截取的位置不同，得到的比例可能完全不同。

> **易错点**：不要把“样本多”当成可靠结论的保证条件。能否代表全体情况，要看抽样是否随机、是否有代表性。

### 选项是怎么设计的

那遇到这种题目，我们怎样秒杀？

这类幸存者偏差的题目，选项往往有比较固定的特征：它们会直接指出你观察到的那些人、事、物为什么不具有代表性——比如“这些人本来就是你的粉丝”“这些人都是爱好者”“没有买到票的人根本不在被采访的人群里”。

火车上采访“买到票了吗”，得到的回答自然都是“买到了”。但那些没买到票的人，恰恰是你根本采访不到的人。讨论失业问题也一样：问身边同事，大家都有工作，并不意味着社会中失业的人很少。你问不到那些已经不在职场中的人，得到的样本当然会显得很“乐观”。

#### 看“跟帖比例”的支持率

我们来看一道质疑博主结论的题。

结论是：因为85%的跟帖赞同他的观点，所以大部分民众赞同他的观点。选项A说有些人虽然赞同他的观点，但不赞同他的分析；选项B说他的观点后来被证明是错误的；选项C说反对者的理由更充分。三个选项都在讨论观点本身到底对不对，或者分析是否充分，但题干要求的是质疑这个“由跟帖支持率推出民众支持率”的推理，而不是判断观点正误，所以这些都不对。

选项E说：关注该博主文章的大部分人都是其忠实粉丝。这就直接说明跟帖者不具有代表性——不赞同的人根本不会去跟帖，也不会关注博主，赞同的比例当然就偏高。这正是典型的幸存者偏差削弱。

所以正确选项是E。

> **结论**：当题干问“最能质疑上述结论”时，应优先找那些指出样本不具代表性、无法代表整体的意见。

#### 看“采访对象”的需求

另一道题是2024年国考的题目。结论是HD地区旅游需求很高，常态化消费将成为越来越多人的选择，论据是说采访的人里有90%最近体验过，65%的人每年都会体验冰雪旅游。

我们不是要证明HD地区需求高或低，而是要质疑：从这些采访对象的需求，能推出HD地区的整体需求吗？

答案的关键就在于受访者。如果受访者几乎都是了解或者喜爱冰雪旅游的年轻人，而你恰好去找这些粉丝做采访，他们的冰雪旅游需求当然高。可是你有去采访过那些没有相关兴趣的人吗？

**采访对象本身带有特定偏好，不能代表全体受访者的真实需求。**

选项A直接指出：受访者几乎都是了解或喜爱冰雪旅游的年轻人。这正好是样本不具代表性的标准削弱，所以答案是A。

B项说近5年冰雪旅游产业的年均投资额较高；C项说HD区域冬季较长，许多游客会来此体验；D项说可以推出套餐组合、吸引更多消费。这些选项要么偏离“需求高不高”这个核心问题，要么仍在支持“需求多”的结论，并不能质疑“采访结果代表整体”的推断，所以不选。

#### 看“医院”样本的局限

再来看2009年考研题。

论据是：在医院里发现被狗咬伤的患者大多在13岁以下；因此得出结论，狗倾向于咬13岁以下的儿童。

这背后的逻辑是：医院所看到的被咬伤者多数是儿童。但这能代表所有被咬伤者吗？

不能。医院所看到的被狗咬伤者能否代表所有被咬的人？这正是幸存者偏差的要害。

被狗咬伤的13岁以上人群，大多数都不去医院就医，所以你在医院里根本看不见这些人，医院里的样本自然偏向13岁以下儿童。

这和火车上采访大家都买到票是同一个道理：没买到票的人，你根本采访不着。正确答案是B选项。

其他选项A、C也错在过度引入了题干之外的信息：说被狗咬伤并致死的大多数人年龄在65岁以上，讨论的是“致死”情况；题干仅说“被狗咬伤”，并未提及“致死”“严重咬伤”等程度问题。D项说13岁以下的儿童就医时病情已恶化，题目讨论的是狗的年龄倾向，与病情是否严重、是否恶化无关。E项说养德国牧羊犬的家庭往往没有13岁以下小孩，这跟狗是否倾向咬13岁以下儿童也没有直接关联。

> **提示**：遇到含程度副词的选项要格外警惕，结论没有提到的内容绝不能脑补。

#### 看“现存道观”的选址

2022年上海题，结论是古代道观选址一定都在风景绝美之处，论据是我们看到所有现存道观都位于名山大川。

这一推理的问题很明确：我们所看到的“现存道观”并不代表历史上所有道观的情况。

如果周边景色一般的道观地处偏僻的城镇，很可能因为历经战乱、改建而消失。那么今天我们就看不到它们，只剩下位于风景绝佳处的道观。

选项C指出“很多周边景色一般的道观地处偏远城镇，已经因战乱和改建消失”，正好解释了我们为何只看到风景绝美的道观。

所以答案C成立。其他选项A讨论其他宗教建筑与本题无关；B说许多道观风景被破坏，题目讨论的是“选址”问题，不是“现存风景是否被破坏”。D说“小隐隐于野，隐于市”等，与题干无关。

如果能看懂这层逻辑，就能快速锁定C项。

#### 看“没有肺的鱼”为何消失

2025年的上海题文字较晦涩，它要解释的是为什么我们看到从鱼进化而来的陆地动物有肺，而没有鳃，肺对陆地生活有显著优势。

这个解释看似合理，但如果要更深入地问一步：“没有肺的鱼”去了陆地会怎样？

A项的解释是：只有有肺的鱼才能上岸并在陆地上存活，那些没有肺的鱼上了岸以后都死光了。这正好指出了“幸存者偏差”——我们只看到有肺的个体活了下来，就以为所有鱼都能成功上岸。

所以答案是A。

其他选项B、C提到人类胚胎的鳃裂和鳃提取氧气的特点；D认为鳃体积小，不适合大型动物，但这些都没有直接解释“肺”的由来；题目需要说明的是“肺”如何成为幸存个体的特征，而不是只讨论鳃本身。

### 题目中反复出现的底层思维

> **总结**：这些题目的共同点在于，我们看到了某个特征，似乎就认为所有个体都具备这个特征，但实际上不符合这个特征的个体可能早就消失或不曾进入我们的视野，所以不能把“看到的”直接当作“全部的”。

这类题在国考、上海卷以及2009年考研中都出现过，属于相对固定的思路。所谓“秒杀”，就是看到题干中的样本从某个特定渠道进入，然后选项告诉你这些样本被某种机制筛选过，直接秒选。能看透这个结构，一道题就秒杀了。

最后送大家一个提示：你看到的东西不一定代表所有；那些和你不一致的个体，可能你根本看不到。掌握“样本是否随机、是否具有代表性”这一判断核心，你就能在考场快速识别出所有的幸存者偏差题。

### 本讲提到的题目

#### 85%跟帖与大部分民众

**题干**：某博主认为自己的观点得到了大部分民众的赞同，因为其文章下85%的跟帖都赞同他的观点。以下哪项最能质疑该结论？

**解析**：题干推理为“跟帖者大多赞同→民众大多赞同”，质疑的关键在于跟帖者能否代表全体民众。选项E指出关注该博主文章的人大多是其忠实粉丝，不赞同的人不会跟帖或关注，因此跟帖中的支持率不能代表全体民众的态度，构成典型的幸存者偏差削弱。其他选项讨论的是观点对错或分析是否充分，并未直接指出样本代表性存在问题。

**答案**：E

#### H地区旅游需求

**题干**：根据采访结果，有90%的受访者最近体验过冰雪旅游，每年还有65%会体验，HD地区常态化旅游消费将成为越来越多人的选择。以下哪项最能削弱上述结论？

**解析**：题干从受访者的体验比例推测HD地区整体旅游需求，关键漏洞在于受访者是否具有代表性。选项A指出受访者几乎都是了解或喜爱冰雪旅游的年轻人，说明调查对象本身带有偏好，无法代表整体需求，构成幸存者偏差削弱。

**答案**：A

#### 狗倾向于咬13岁以下儿童

**题干**：儿科医生发现，在医院里被狗咬伤的患者大多是13岁以下的儿童，因此认为狗倾向于咬13岁以下的儿童。以下哪项最能削弱该结论？

**解析**：题干依赖“医院患者”这一个来源的样本。选项B指出被狗咬伤的13岁以上人群大多数不去医院就医，这使得医院样本无法代表全部被咬伤者，属于典型的幸存者偏差，削弱力度最强。

**答案**：B

#### 古代道观选址与风景

**题干**：某景点现存的道观都坐落在风景绝美之处，据此推测古代道观选址一定都在风景绝美之处。以下哪项为真，最能质疑这一推测？

**解析**：题干把现存道观的分布当作所有古代道观的分布。选项C指出周边景色一般的道观地处偏远城镇，且历经战乱与改建而消失，解释了为何我们看不到那些不符合规律的实例，构成幸存者偏差削弱。

**答案**：C

#### 陆地动物为何有肺

**题干**：有观点认为，肺对陆地生活有显著优势，因此陆地动物从鱼进化而来后都具有肺。以下哪项为真，最能支持上述理解？

**解析**：该观点需要解释为什么我们只看到有肺的陆地动物。选项A指出没有肺的鱼上岸后无法存活，只有有肺的鱼能够存活下来，这正是幸存者偏差式的解释：没有肺的个体已经被自然淘汰，答案选A。

**答案**：A
