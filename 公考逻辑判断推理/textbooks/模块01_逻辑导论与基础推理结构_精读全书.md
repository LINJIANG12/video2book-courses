## 逻辑导学：先看懂结构，再选择答案
> 对应块：BLK01 | 覆盖分集：P01 | 块标题（分集名）：《逻辑导学与判断推理基本思路》

我以前其实考虑过讲公考逻辑，但总觉得，光讲逻辑这一点点，对大家的帮助不大，所以一直没有开这套课。

这就是 BLK01 的 P01，也就是逻辑判断部分的第一节导学课。我们先不急着刷题，先把一个问题弄清楚：逻辑考试到底考什么？又怎样才能事半功倍地备考？

前段时间，有个同学一直在问我：“老师，最近很多公考的同学都在听你的考研逻辑课，你要不要讲一套专门针对公考的逻辑课？”我说，只讲逻辑不够啊。他说：“判断推理里面还有图推、定义、类比，不都是靠逻辑思维吗？你研究一下，把这些都讲了不就行了？”

后来我让他先发一些图推题看看。文件一打开，我的天啊，他竟然给我整理好了1000多道图推题。我花了几天时间，把这1000多道题做了两遍，发现里面其实有很多套路和技巧。既然逻辑和图推都能讲，那我就讲一套免费的课程给大家听。逻辑本来是老本行，图推里也有很多逻辑思维的技巧，后面也值得期待。

所以我们先不急着刷题，先把一个问题弄清楚：逻辑考试到底考什么？又怎样才能事半功倍地备考？

### 公考逻辑和考研逻辑，考点到底像不像

说到国内的逻辑考试，最重要的就是公考逻辑和管理类联考、也就是考研逻辑。它们到底相同，还是不同？很多同学会问这个问题。

从考点框架、底层逻辑和出题套路来看，它们是完全相同的。联考逻辑参考了国外相应的逻辑考试，公考逻辑在一定程度上也参考了管理类联考，所以两者是一脉相承的。这两个考试考的东西，本质上是一样的。

真正的区别，在出题目的。公考逻辑一题只有一分钟，联考逻辑、考研逻辑一道题有两分钟。这不是时间的简单差异，而是题目性质的差异。

公考既然只有一分钟，题目就一定结构更简单、套路更直接，文字相对少，更容易秒杀。因为出题范围比较广，严谨性也可能不如考研逻辑：一分钟就要做完，不可能把每道题都出得像考研题那么难。如果每道题都那么难，大家根本做不完，时间不允许。

考研逻辑每道题有两分钟，而且每年出的题数量也比较少，所以它可以相对复杂一些，考点更细致，文字更多，变化更多，也更加严谨。

但是从备考的本质来说，二者没有那么大的不同。公考的同学不需要因为自己考的是公考，就把逻辑学成另一套东西。我们真正要掌握的，是底层结构、推理方法和选项模式。

### 逻辑考的是思维模式的切换

逻辑考试不管是公考逻辑、考研逻辑，还是其他逻辑考试，考查的都是思维模式的切换。

什么叫思维模式的切换？不同的题型、不同的考点，对应着不同的解题思维。我们首先要判断题型，判断考点，然后根据判断出来的题型，去找与之对应的解题思维。

这就像古人说的“兵来将挡，水来土掩”。你不能一把钥匙开所有的锁，更不能还没判断题型，就凭感觉去试。

如果你不能判断题型，不能判断考点，那实际上就是用感觉做题。正确率和提升效率肯定都会很低。

这里有三层特别关键的切换。

第一层，是从题型识别切换到考点识别。题目问的是支持、削弱、假设还是别的形式，只是一个外在表现；你还要继续追问，题干到底用了什么推理结构。

第二层，是从具体的文字切换到底层的逻辑结构。正确选项不是某一个固定句子，而是有它自己的结构模式。题干结构一旦确定，正确选项就应该按照相应的结构出现。你一旦熟悉这个模式，就会发现正确选项在向你招手。

第三层，是从日常的发散思维切换到考试的收敛思维。日常生活中的思维往往是发散的，想到哪儿说到哪儿；但逻辑考试要求的是收敛、严谨的逻辑思维。日常经验有时能帮你做对题，有时却会把你带进思维误区。如果考官在题目里挖了一个坑，而你又没有经过严谨训练，一定会掉进去。

所以，逻辑题最重要的提醒只有四个字：不要脑补。不要凭日常经验替题干补出它没有写出来的关系。真正要训练的是结构化思维。

### 不要把逻辑做成阅读理解

我们备考，当然希望又快、又好、又对地做对逻辑题。什么最关键？就是在做题和备考的过程中，深刻理解考点是什么，以及一道题的底层逻辑是什么。

千万不要用做阅读理解的方式做逻辑题。

用阅读理解的方式，做题时能不能做对？可能能做对。但你做一千道题之后会发现，正确率和以前差不多。因为你靠的是“男人的直觉、女人的直觉”，而不是方法论；你只是锻炼了一下自己的智力，并没有真正提高对逻辑结构的理解。

如果没有方法论的指导，你的直觉很难提高。备考是为了提高分数，就要找到方法，找到考点。

那逻辑的考点到底是什么？

逻辑考点就是固定的思维套路、固定的推理结构，以及与这个结构对应的固定正确选项模式。

数学里的考点大家比较容易理解，比如方程、行程问题、盐水问题，都是固定的考点。逻辑其实也一样。一个东西要真正称得上考点，至少有三个特征。

#### 结构固定，答案模式可以识别

一个考点的第一个特征，是题干结构固定，正确选项的模式也固定，而且这个模式可以被识别出来。

如果你真正理解了一个考点的结构，做题时甚至不需要看答案，就知道自己一定做对了。这个能力对考试状态非常重要。

你做完十道题，完全不知道自己对了几道，和做完十道题，心里知道“至少对八道”，是完全不同的状态。前一种人越做越慌，后一种人知道自己站在哪里。

真正理解考点，不只是会做一道题。你还可以站到考官的角度：知道这个考点能出成什么样的题，甚至能自己出一道对应这个考点的题目。能做到这一点，才说明你不是只记住了一道题，而是理解了它。

#### 一个考点一定对应多道题

一个考点只对应一道题，不能叫考点，它必须对应多个题目。

相同考点的题目，文字可以不同，结构和推理却相同。考试真正考的是，你能不能看见文字下面隐藏的推理和结构。

大家一定要有这个意识。否则，你永远靠感觉做题，很难提升。

怎么判断自己是不是看懂了？很简单：你能不能给这道题换一个故事背景，能不能换掉文字，还能不能想到一道具有相同考点的题目？能不能从一道题联想到另一道题？

比如听完课以后，我随便拿出的一道题，问大家：“你们能不能想到这道题在真题里对应哪几道题？”如果大家马上能想到几道真题，能说出它们虽然文字不同、考点相同，那就说明你开始理解这个考点了。

#### 考点必须具有连续性和复现性

第三个特征，是考官考过的考点必须具有连续性和复现性。

很多同学做题时容易犯一个错误：自己觉得某个考点没用，于是就想“我觉得考官考的是这个问题，考官肯定觉得我说的没错”。在考场上，不要教考官做人。考官觉得有用，才有用。

怎么判断一道题是不是考官想考的考点？要到其他真题里找。如果一道题之外，十年、二十年、几千道题里从来没有出现过相同考点，那大概率不是你看错了，就是你还没有真正理解考官想考什么。

如果你判断一个考点，却发现自己几乎没见过它复现，就要回头想一想：我理解的真的是这个考点吗？大概率是理解错了。

### 支持和削弱不是考点，题干结构才是

这里有一个特别容易犯的错误：很多同学说“我削弱题做得不好”，或者“我支持题做得不好”。如果你只知道这一层，根本没有办法提高。

削弱、假设、支持，都不是逻辑题真正的考点，它们只是考官提问的表现形式。出成选择题还是填空题，也不是考点；考点藏在题干的逻辑架构里，核心是论据和结论的结构。

一道题可以问支持，也可以把支持改成反驳、把支持换成削弱，但题目蕴含的考点不变。正着说是支持，反着说是削弱，不能因为问题里出现了“支持”两个字，就把它当成一个独立的考点。

所以，正确的备考方式不是把题目分成“支持题”和“削弱题”，然后分别刷；而是要按题目的考点分类。不同题目都叫支持题，里面考的可能是不同结构。如果不拆到结构这一层，你就不知道到底该练什么。

### 先抽象结构，再看选项

做逻辑题时，很多人一看到选项就急着往上套答案。先别急。我们先把选项盖住，练习从题干里找结构。

先找结论和结论的引词。题目里“所以”“因此”“于是研究者认为”这类词，常常在提示结论；结论引词右边的内容是结论，左边通常是我们要追溯的论据。

找到论据和结论以后，不要停留在故事里，把它压成几个符号。下面这些结构，都是从题目里抽出来的：

```text
A 具备 B
   │
   └── B 与 C 的联系没有说明
          ↓
C 与 A 相关
```

```text
A 与 B 同时出现
   │
   └── A 如何作用于 B 没有说明
          ↓
A 导致 B
```

```text
A 是 B
A 是 C
   │
   └── B 与 C 的联系没有说明
          ↓
所以 A 是 C
```

```text
A 与 B 有相关性
   │
   └── 谁因谁果没有说明
          ↓
A 导致 B
```

看到结构以后，先问自己三个问题：结论是什么？论据是什么？从论据到结论，缺口在哪里？

然后再想，如果我是考官，会从哪个角度出正确选项？逻辑结论不能凭空成立。题干从论据推到结论，中间缺的那一块，正确选项就应该把那一块补上。

这就是选项应该匹配的结构模式，不是凭感觉看到一个“好像有道理”的句子就选。

### 相关性不能直接等于因果

#### 抗性、叶绿素与甲醛污染

我们先看一道2021 年四川的题。题目问：“以下哪项为真，最能反驳上述专家的观点？”

先不看选项，先找结构。题干给出的论据是：抗性弱的植物品种，叶绿素含量下降越快。专家的结论是：甲醛污染对室内植物的影响，与植物抗性相关。

把它压成 A、B、C：A 是植物抗性弱，B 是叶绿素含量下降，C 是甲醛污染对室内植物的影响。题干其实是在说：

```text
A 具备 B
        ↓
C 与 A 相关
```

真正缺的，不是 A 和 B 的关系，而是 B 和 C 的关系。叶绿素含量变化为什么能说明甲醛污染的影响？它和污染影响之间到底是什么联系？

如果题目问支持，就要建立 B 和 C 的联系。课堂中对应的正确选项是 B：叶绿素含量的变化，是评价影响程度的重要指标。这样一来，A 具备 B，B 又能评价 C，结论就能被建立起来。

如果题目问反驳，就要说明 C 其实不取决于 B。课堂中对应的是 C 选项：甲醛污染对室内植物的影响取决于叶片大小，而不是取决于抗性所对应的叶绿素变化。这就削弱了“抗性影响污染效果”的推理。

如果把同一个选项改换成根的长短、茎的粗细，文字可以变化，但逻辑仍然是：只要不是 B，就不能把这个 C 归因于 B。文字不重要，B、C 之间的结构才重要。

所以，支持和削弱的选项可以完全不同，但它们服务的仍然是同一个考点：A 和 C 为什么会因为 B 而发生联系。

#### 疟原虫感染与癌症

再看一道关于疟原虫和癌症的题。论据是，感染疟原虫的小鼠生存时间大大增加；研究者由此宣称，疟原虫感染可以治疗癌症。

这里的结构是：

```text
感染疟原虫
      +
小鼠生存时间增加
      ↓
疟原虫感染可以治疗癌症
```

把 A 看成感染，把 B 看成小鼠生存时间增加。题干把 A 和 B 同时出现，直接推成 A 导致 B。问题是，A 到底做了什么，才让 B 发生？

支持它，就要补上 A 对 B 的作用。课堂中 D 选项说明了这条机制：感染入侵人体后可以激活 NK 细胞，NK 细胞可以杀死癌细胞。这样就形成了完整的作用链：

```text
感染疟原虫
      ↓
激活 NK 细胞
      ↓
杀死癌细胞
      ↓
小鼠生存时间增加
```

所以，按这道题的讲解，支持时选择 D。不是因为选项里出现了“癌症”两个字，而是因为它真正建立了 A 到 B 的作用。

如果考官把支持改成削弱，正确选项会换成指出主体不同的那一类。实验是在老鼠身上做的，结论却要说到人身上。老鼠和人相同，能够支持；老鼠和人不同，就能够削弱。题干只需要把问题从支持换成削弱，考点并没有改变，仍然是“实验对象能不能支持结论对象”的主体范围。

大家不要再说“我削弱不好”，要说清楚自己到底是哪一类的削弱不好：是主体范围，还是因果关系？如果是因果倒置不好，就专门练因果倒置；明确病因以后，提升就像看病找准了病一样，会快得多。

#### 牙龈炎与老年痴呆

牙龈炎和老年痴呆的题，也是同一个思路。题干说，牙龈的损伤程度和海马体的体积有很大关系；结论是，对老年人而言，预防牙龈炎有助于预防老年痴呆。

这里的结构是：

```text
牙龈损伤程度与海马体体积相关
                    ↓
预防牙龈炎有助于预防老年痴呆
```

如果改变 A，就能够改变 B，那么题干实际上把 A 当成了因，把 B 当成了果。这里的 A 是牙龈状况，B 是老年痴呆的状态。

但相关性本身只能说明两者一起变化，不能自动说明谁因谁果。就像感冒治好了可以不流鼻涕，但把鼻涕擦掉，并不能把感冒治好。因为感冒是因，鼻涕是果。反过来，也可能是鼻涕的状态在前，感冒在后。

因此，题干从“牙龈损伤程度和海马体体积相关”推到“预防牙龈炎有助于预防老年痴呆”，需要证明牙龈炎确实通过某种作用影响老年痴呆。

课堂中的 B 选项给出了联系：导致牙龈炎的细菌可以入侵脑组织，并对神经细胞造成损伤。这样，A 和结论中的结果之间就有了作用路径，支持成立。

A 选项说牙龈炎会影响心脏、肺部功能，还会引起胃部疾病，看似是在说牙龈炎“干了什么”，但这些作用和老年痴呆没有关系，所以只是考官故意设置的迷惑项。不能在选项里看到一个主语相符就直接选，必须看它最终有没有连接到结论。

如果问削弱，C 选项是因果倒置：不是牙龈炎导致老年痴呆，而是老年痴呆的人不刷牙，所以出现了牙龈炎。题干原来把 A 当因、B 当果，C 选项则告诉你，因果方向可能反过来了。

所以，问支持时要建立联系；问削弱时，除了可以拆掉联系，也可以引入其他原因、指出因果倒置。这里真正考的仍然是论据和结论的结构，而不是“支持”这个词本身。

### 同一主语的两句式推理

#### 金星与生命

再看金星有没有生命的问题。题干的论据是，金星中没有足够的水蒸气；结论是，金星不可能有生命。

这类题通常是一个主语、两个性质：

```text
A 是 B
A 是 C
```

这里 A 都是金星，B 是“没有足够的水蒸气”，C 是“不可能有生命”。问题是：凭什么 A 是 B，就能推出 A 是 C？B 和 C 之间到底是什么关系？

要支持结论，就要建立“没有足够的水蒸气”与“没有生命”之间的联系。课堂中 B 选项说，金星云层的水含量相当于维持类似地球生命所需要的百分之一。既然需要的量是百分之百，而实际只有百分之一，当然就足以支持“没有足够的水蒸气，所以没有生命”。

如果题目问削弱，就要说明这个联系不必然。比如金星虽然没有足够的水蒸气，却可能存在其他状态的水；没有水蒸气，不等于完全没有水，更不等于一定没有生命。课堂中 A 选项可以从这个角度形成一定程度的削弱，但它不是这道题的标准支持项。

这道题让我再次看到，逻辑结论不能凭空成立。看到 A 是 B，还不能自动得到 A 是 C；我们必须寻找 B 与 C 的连接。

### 建立联系：先找“谁做了什么”

建立联系，是逻辑考试里最标准、最常见的考点之一。

题干给出的结论经常是“A 推出 B”：A 导致了 B，或者说 A 能带来 B。可是 A 和 B 不会凭空连在一起，题目中间必然缺了一段。正确选项要做的，就是告诉考官：A 通过什么作用、什么因素，最终影响了 B。

可以把它的基本形态记成：

```text
A 产生一个作用或因素
          ↓
这个作用或因素影响 B
          ↓
A 推出 B
```

这里最关键的，不是选项的具体故事，而是选项里有没有把“作用或因素”搭出来。

#### 站立听课与注意力

有一道题说，站立听课的学生比坐着的学生更加专注。题目问支持上述观点。

支持它，不能只重复“站立更专注”，而要说站立为什么能让人专注。课堂中的 A 选项给出了这样一条链：站立听课需要大脑平衡，也需要身体控制肌肉收缩，这些压力会导致人的注意力更加集中。

这里的逻辑是：

```text
站立听课
   ↓
大脑平衡、身体控制肌肉收缩
   ↓
注意力更加集中
```

这就是一个标准的建立联系。题干要的是“站立带来专注”，选项补上了站立带来的作用，而且这个作用最终落到了“专注”上。

B 选项说，长时间坐着听课会增加脊柱压力，不利于身体健康。作者或坐姿有问题，并不意味着站立就一定更专注；它没有补上题干缺失的链路，所以只是无关选项。

大家要学会一个很快的判断：看选项时先找主语和结论是否对上，再看中间有没有真正的联系。会的题直接找正确选项，不需要把四个选项逐一代入验证。考试中一道题可能只有三四十秒，逐项验证会消耗大量时间；直接定位正确选项，才是最快的做法。

#### 茶碱、咖啡因与疼痛

又有一道题说，可可中含有的茶碱和咖啡因，可以有效减轻压力和缓解疼痛。题目同样要求支持上述观点。

这和站立听课没有本质区别，都是 A 推出 B。茶碱和咖啡因要“做点什么”，才能减轻压力、缓解疼痛。

课堂中的 B 选项说，可可中的茶碱和咖啡因能够刺激大脑分泌内啡肽，而内啡肽对于减轻压力和缓解疼痛非常有效：

```text
茶碱和咖啡因
       ↓
刺激大脑分泌内啡肽
       ↓
减轻压力、缓解疼痛
```

这就是标准的建立联系，秒选 B。

A 选项虽然提到了可可中的咖啡因，但只说咖啡因只有在特定条件下才能发挥，并没有说明它能减轻压力或缓解疼痛。这个选项是考官设计的迷惑项：主体沾边，结论却没有接上。

#### 最友好者生存与大脑缩小

还有一道题讨论合作与人类大脑的关系。题干认为，在分工日益明确的时代，富有合作精神的人会有更多生存和繁衍的机会；“最友好者生存”是导致人类大脑不断缩小的重要原因。

这里要支持的是“最友好者生存导致大脑缩小”。所以正确选项必须说明最友好者生存到底做了什么。

B 选项给出的联系是：合作会减少人们的攻击性，而攻击性的减少会使人身体变轻、脑容量变小。

```text
合作、最友好者生存
          ↓
减少攻击性
          ↓
脑容量变小
```

这就是标准的建立联系，所以选择 B。

如果选项只是说大脑变小会让人更有合作精神，方向反了；如果只是描述一个没有连接到大脑的其他影响，也没有完成支持任务。正确选项不是“看起来很聪明”，而是必须沿着题干缺口搭出路径。

从这几道题里可以看到，建立联系的题目在考官心中没有本质区别：疟原虫感染为什么要治疗癌症，牙龈炎为什么要影响老年痴呆，站立为什么要更专注，茶碱和咖啡因为什么要缓解疼痛，合作为什么要让大脑缩小，文字可以完全不同，但结构都可以压成“A 做了什么，最终影响 B”。

这就是这个考点的固定模式。只要对结构足够敏感，看到选项的一瞬间，正确选项就会变得很明显。

### 先吃肉，再啃排骨，最后吃渣渣

题目的难度和考试中的比重有优先级。逻辑题不是所有考点都一样，有些考点简单、出现频率高，应该先掌握；有些考点难一些，再往后啃；还有些零散内容，最后处理。

建立联系就是逻辑考试里的“红烧肉”，而且是好吃、容易下手的红烧肉。

在约一千道题里，单是建立联系这个考点就占了10%几，有100多道题。题目文字可能不同，但基本都可以用同一个结构处理，熟练之后可以秒杀。

所以不要一开始就把所有题型混在一起凭感觉刷。应该先识别自己错得最多的考点，集中突破这一类。把一类考点练对，相关题目就会一起变对。刷五六百道题却只按“支持题、削弱题”分类，效率当然会低；按底层考点分类，才有针对性地提升。

这就是“建立联系”这类考点的优先级。你要先把肉吃掉，再去啃排骨，最后才是渣渣。

### 备考逻辑，先上兵，再胜兵

我讲逻辑时，特别喜欢《孙子兵法》里的两句话。

第一句是“上兵伐谋”。我们要先听课，先建立方法论，再去刷题。不要根据自己的感觉做题，因为感觉永远是那样：以前做对的，现在还是对的；以前做错的，现在还是错的；有时候以前做对，第二次反而做错；以前做错，第二次又碰巧做对。这样的状态没有系统性的提升。

先听课，不是让你听完以后死记答案，而是让你知道每一种结构怎么识别、缺口在哪里、正确选项应该长什么样。没有方法论，刷题只是在重复原来的自己。

第二句是“胜兵先胜而求战”。这句话放到数学题里很好理解：如果你已经知道自己会做一道数学题，动手前就知道答案一定能得到，剩下的只是把步骤和计算写出来。逻辑也一样。

一道逻辑题如果你已经学过、理解了考什么，你通常知道它应该怎样推出，也知道正确选项应该满足什么模式。真正做题时，只是把这个判断落实下来。

所以备考时不要只问“选哪个”，更要问“这道题考什么”。更不要把“选哪个选项”变成一种信仰。练习中的题目，考试的每一道原题都不可能原封不动地再出现。我们真正要提升的是解题方法论。

看懂考点，你就是“胜兵”：还没做完，就已经知道这道题应该怎样处理；看懂结构之后，你甚至不用对答案，就能知道自己为什么一定选它。

相反，做题时不知道考什么、也不知道应该选什么，只想着“跟着感觉来两下”“代入验证试一试”，这就是“先战而后求胜”。这种方法的错误率高，效率又低。我们要尽量把自己训练成“胜兵”，体会先胜而求战的秒杀快感。

### 最快的解题方法，是直接找正确选项

很多人做题时习惯把选项一个一个看过去，一个一个代入验证。公考题目数量很大，有的甚至有一百三十道题，你一定要在最短时间内做对。黄花菜都要凉了，还逐项验证，当然不行。

最快的解题方法，是直接去找正确选项。

你当然不可能每道题都做到百分之百，但如果有百分之五十、百分之六十的题能直接定位正确选项，你已经省掉了相应的时间；学得足够好，百分之七八十的题都可以直接秒选走人。真正不知道考什么，或者两个考点很像时，才需要对比验证。

这套课程也不要求大家一看到选项就马上作答。我们反而要练一个相反的动作：做题之前先把选项盖住，思考 10~20 秒，问自己三个问题：结论是什么？论据是什么？推理是什么？如果我是考官，我会从哪个角度出正确选项？

等你把答案选项打开的那一刻，往往一眼就能看到那个正确选项。因为你在看选项之前，已经把题干的结构和缺口看出来了。

刚开始训练时，你想20 秒，甚至看了20 秒也不知道考什么，必须打开选项，这都没有关系。随着刻意练习，以前要想20 秒的题，可能两秒、三秒就能识别；训练足够多以后，甚至一秒就能知道它在考什么。

提升速度的关键，不是把每个选项都看得更快，而是能站到和考官同频交流的位置上。考官用什么结构出题，你就用什么结构拆题；考官怎样搭正确选项，你就按什么模式去找。文字只是外衣，结构才是考官真正交流的内容。

### 本讲提到的题目

这些题的文字虽然不同，考点结构却是相通的。把题干和课堂中已经给出的选项收拢在这里，便于回看；题干或选项没有展开的部分，不另行补写。

- **2021 年四川题｜抗性、叶绿素与甲醛污染**：题干问“以下哪项为真，最能反驳上述专家的观点？”论据是抗性弱的植物品种叶绿素含量下降越快，结论是甲醛污染对室内植物的影响与植物抗性相关。支持需要建立“叶绿素含量变化—污染影响”的联系，B 选项对应“叶绿素含量的变化是评价影响程度的重要指标”；反驳则可以说明污染影响取决于叶片大小等 D 因素，而不是叶绿素变化。**答案：按题目问法选 C；若改成支持，选 B。**

- **疟原虫感染与癌症题**：感染疟原虫的小鼠生存时间大大增加，研究者据此宣称疟原虫感染可以治疗癌症。支持时要补出感染对小鼠状态的作用，D 选项给出“感染入侵人体后激活 NK 细胞，NK 细胞杀死癌细胞”，答案选 D。题干还留下实验对象是小鼠、结论对象是人的缺口：指出主体不同可以削弱，若改成这种问法则选相应的削弱项。**考点是主体范围和 A 导致 B 的机制。**

- **牙龈炎与老年痴呆题**：牙龈损伤程度和海马体体积有很大关系，结论是对老年人而言，预防牙龈炎有助于预防老年痴呆。支持选项 B 指出导致牙龈炎的细菌可以入侵脑组织并损伤神经细胞，建立了作用联系；A 选项只说牙龈炎影响心脏、肺部和胃部，和老年痴呆没有接上。若改为削弱，C 选项指出老年痴呆的人不刷牙、进而出现牙龈炎，是因果倒置。**答案：支持选 B，削弱选 C。**

- **金星与生命题**：金星中没有足够的水蒸气，结论是金星不可能有生命。B 选项说云层水含量只有维持类似地球生命所需的 1%，因此支持“没有足够水蒸气—没有生命”的联系；A 选项指出可能存在其他状态的水，从一定程度上削弱这个判断。**答案：支持选 B；A 可作为削弱方向。**

- **站立听课与注意力题**：结论是站立听课的学生比坐着的学生更加专注。A 选项说明站立需要大脑平衡、控制肌肉收缩，这些压力会让注意力更加集中，补上“站立—作用—专注”的链条；B 选项只说久坐伤害脊柱和健康，不能证明站立更专注。**答案：A。**

- **二〇二二年省联考题｜茶碱、咖啡因与疼痛**：可可中的茶碱和咖啡因可以有效减轻压力、缓解疼痛。B 选项说它们能够刺激大脑分泌内啡肽，而内啡肽对减轻压力、缓解疼痛有效；A 选项只说咖啡因在特定条件下才能发挥，没有接到结论。**答案：B。**

- **二〇二〇年江苏题｜最友好者生存与大脑缩小**：题干认为富有合作精神的人有更多生存和繁衍机会，并称“最友好者生存”是人类大脑不断缩小的重要原因。B 选项给出“合作减少攻击性，攻击性减少使身体变轻、脑容量变小”的作用链；只说大脑变小会让人更有合作精神，方向相反。**答案：B。**

> **结论**：逻辑不是凭感觉在几个选项里挑一个，而是先判断题干的推理结构，再沿着论据到结论的缺口寻找匹配的模式。先听课建立方法，再按考点集中训练，最后用直接定位正确选项的方式把速度练出来。不要脑补，不要做阅读理解；看到结构，正确选项就在那里。

## 逻辑导学下篇：看懂考点，再谈秒杀
> 对应块：BLK02 | 覆盖分集：P02-P03 | 块标题（分集名）：《逻辑导学下篇与解题方法概论》

### 先看地图：公考逻辑到底考什么

我先把近10年国考、各省联考以及部分事业单位的题目做了一个考点统计，一共1013题。先看这个数字，是因为很多同学一学逻辑，第一反应是“题型好多”，但其实先把地图摊开，题目并没有想象中那么散。

| 大类 | 题数 | 占比与特点 | 备考位置 |
| --- | ---: | --- | --- |
| 论证推理 | 704 | 约占70% | 绝对主战场 |
| 形式逻辑 | 232 | 不到25%左右 | 考点分类清楚，整体相对简单 |
| 分析推理 | 77 | 不到10% | 题量较少，类型较固定 |

三部分合起来，就是整个公考逻辑判断的基本版图。不要一上来就钻进某一道题的文字故事里，先知道自己站在哪张地图上，后面的学习才不会东一榔头、西一棒子。

#### 三个大类

论证推理是从论据推出结论。有些人把它说成“从论据推出论点”，两种叫法没有区别；你愿意叫结论就叫结论，愿意叫论点就叫论点，知道它们说的是同一件事就行。这里是704道题，约占70%，所以它重中之重。为什么很多同学都专门听论证推理，原因就在这里。

形式逻辑在课程里也常被叫作翻译逻辑。它只看逻辑结构，不看具体内容，是逻辑学里的一个专有名词。公考里的形式逻辑相对简单，甚至可以说比考研的形式逻辑简单一个级别；它有时是几句话就能完成判断的题，不需要在故事里停留太久。

分析推理一共有77道题，不到10%。有人把它叫综合推理，这个叫法也不必纠结。它主要涉及分类、分组、队列、画表格、数读等固定类型，另有一拖五这样的组合题，后面会作为专题处理。

#### 几个名称要统一

先把三个容易制造障碍的称呼统一：

- “结论”和“论点”说的是从论据推出来的那个判断，不要因为名字不同就以为有两种结构。
- “形式逻辑”和“翻译逻辑”说的是同一种只看结构的逻辑。
- “分析推理”和“综合推理”在备考中通常作为同一部类理解；综合推理还可以看作分析推理中的一部分。

> **易错点**：不要把名称差异当成知识差异。名词只要听懂，真正的内容仍然是看选项的逻辑关系、题干的推理结构。

### 把考点分布变成复习顺序

考点数量不一样，分布也不一样。整体来看，论证推理里由因推果最重要，占了论证推理的40%多；由果推因不到5%；两句式推理大约66道题；解释题、选非题很多时候并不是全新的底层结构，而是把前面考点换成了解释、支持、削弱等问法。解释现象接近支持，解释矛盾接近削弱。结论推出虽然有一些题，但近些年考得已经比较少了。

这里最重要的不是把所有数字背下来，而是知道哪些考点必须投入时间，哪些考点在某些地区不值得过度纠缠。

| 考点观察 | 统计表现 | 对备考的提示 |
| --- | --- | --- |
| 由因推果 | 论证推理中占40%多，各地区都可能考 | 重中之重，必须练到看见结构就能反应 |
| 由果推因 | 整体不到5%，国考近10年仍有题 | 按地区和年份决定投入程度 |
| 评价题型 | 国考近5年没有出现，近10年只有1道；广东则考了30多道 | 非广东考生不必把大量时间耗在这里 |
| 两句式推理 | 国考考得较多，江苏、北京、四川等考得相对少 | 先掌握共同结构，再按报考地区调整 |
| 形式逻辑中的直言命题 | 1000道题里约6道，近5年很少出现 | 重点掌握前六类，直言命题不必过度投入 |

同一个考点，在不同地区可能完全是两种待遇。国考近10年会考由果推因，但陕西、广东、北京等地的省考可能不考；国考经常考两句式推理，但江苏、北京、四川的分布又不一样。如果你确定报考某一个省市，一定要先搞清楚那个地区近年的重点，而不能拿一张全国平均分布图代替自己的备考安排。

这就是分布意识的价值：对考点越清楚，重心越容易集中，效率也越高。常考、稳定的考点一定要清楚；考得少、地区差异又大的考点，知道它的位置就够了。

论证推理内部还会继续细分。整体上有九个大的考点，当前导学最需要先记住的是由因推果，它几乎是后续学习的重中之重；建立联系、两句式推理、由果推因、解释题型、选非等问法，也都在这个大框架里。正确的选项不是凭空写出来的，而是有模板的；不同考点对应的正确选项模板，导学时先知道它们存在，后面再逐一拆开。

有人会问：拿到一道题，我怎么知道考官考的是什么？可以把正确选项想象成一串钥匙。你拿朋友给的一串钥匙去开门，钥匙上有五六把，你一开始不知道哪一把对应，但逐把试一下，总有一把能打开。逻辑考试也是这样，考官设置的正确选项，通常落在大类里的几个模板中。熟悉之后，你一眼就能认出对应关系；还不熟悉，也可以先在心里把几种模板过一遍，最多几秒钟就能定位方向。

这里的关键不在于“我觉得它像对的”，而在于从逻辑结构上理解：这个选项为什么能成为正确选项，它在题干里到底承担什么作用。

错题也可以反过来帮助我们建立分布感。如果由果推因老是错，就专门加强这一类；如果涉及前后关系、总相同一类的题老是错，往往说明你对题干和结论的主体范围不够敏感；如果前真后假老是错，就把前后真假关系单独练熟。错题不是只记录一个“错了”，而是要用它定位自己没有掌握好的考点。

形式逻辑也不能只笼统地说“我翻译逻辑不好”。你要进一步知道自己错的是判断逻辑真假、代入验证找矛盾、文氏图，还是真话假话。前六类考点比较重要；直言命题只有少量题目，而且近5年几乎没有出现，不必投入与它不相称的时间。

分析推理的总题量更少。它里面的分类、分组、队列、画表格、数读，训练方式都比较固定。一拖五近9年考了45道题，最近3年集中考队列加分组；看到这个变化，就应该知道重点应该先放在哪里。专项训练之后，这类题是可以比较快提升的。

### 学逻辑的四个阶段

学习任何东西，都有一个从陌生到熟悉、再到熟练的过程。这里用开车来类比，会特别直观。

```text
UI：既不知道怎么做，也不会做
          ↓ 学习
CI：脑子开始有意识，但还不会做
          ↓ 练习
CC：有意识地按照方法去做
          ↓ 大量实践
UC：不依赖刻意思维，已经能够稳定完成
```

这不是说每个人做题都严格处在四个阶段的某一行，而是说学习可以沿着这条路径循环推进。开车之前，你既不知道方向盘怎么用，也不会开；去驾校以后，教练会告诉你什么时候打灯、什么时候减速，你开始知道动作，但实际仍然做不好；拿到驾照以后，开车时还会不断回想教练的指导，这是有意识地会做；开得足够多、走过足够多的路以后，很多动作就变成下意识反应了。

学习逻辑也是如此。很多人做题时看起来能做出答案，甚至能靠直觉做对不少题，但这只是处在一种自发的、无意识的状态：我没有想这道题考什么，也没有调用方法，只是凭感觉选了一个答案。它可以偶尔成功，却很难带来稳定提升。

#### 从UC回到CC

要提高，不能永远停在凭直觉的状态，而要有意识地把自己从UC拉回CC。做题时，先想题干结构和结论，再想题目可能需要什么方法、技巧或套路。这个过程刚开始会显得别扭，甚至比凭感觉做题还慢，但这是把模糊经验变成可复制方法的过程。

有意识的能力一旦符合考官出题的结构，再经过足够多的题、足够多的练习和足够多的课程训练，就会重新回到UC。那时不是又退回凭感觉，而是“看一眼就知道考什么、看一眼就知道正确选项应该是什么样”，这种无意识是建立在方法论之上的，所以才能真正称为高手。

#### 三个做题境界

可以把做题能力分成三个阶段：

| 境界 | 做题状态 | 主要问题或进步 |
| --- | --- | --- |
| 初阶 | 不知道考什么，完全靠阅读理解和感觉 | 可能做对一些题，但很难提升 |
| 中阶 | 知道基本考点，简单题可以秒杀，复杂题通过排除比较确定答案 | 开始用结构和套路做题 |
| 高阶 | 看题就知道考点、推理结构和正确选项模板 | 在看选项前，脑中已经有了大致的答案方向 |

最重要的路径就是：UC到CC，再从CC回到UC。永远停留在感觉里，题做得再多也只是增加熟练度；真正高水平的熟练，是把方法内化之后形成的专业UC。

### 备考目标不是刷题数量

一道具体的题做完以后，你以后大概率不会再遇到一模一样的题。考场上的题目也不会和练习题完全相同。所以，做题和备考的目的，不是把眼前这一道题选对，而是看懂它考什么，提取出里面的考点，整理出一套自己的方法，再用这套方法去做考场上的新题。

备考过程中，“选什么”并不是最重要的；“你学到了什么”才重要。你学到了什么方法、学到了什么套路，才决定你面对新题时能不能迁移。

有一个很直观的比较：如果你真正理解了考点，哪怕只刷了几百道题，甚至1000道题，考场上遇到同一考点的题时，你都像是做过旧题一样；如果你始终不理解考点，只是凭感觉刷5000道题，那么每一道题都要重新用感觉判断，做对的题和做错的题都会不断出现。

所以，不要把“我做对了几道题”当成唯一目标。更有价值的问题是：

- 这道题究竟在考什么？
- 正确答案需要承担什么逻辑功能？
- 同一考点换一种文字，我还能不能认出它？

#### 理解考点的四个好处

第一，理解考点以后，做题速度会明显提高。看见结构就能定位选项的，十秒左右就可能解决；如果没有看出推理是什么，就可能花两三分钟还在猜。

第二，理解考点可以举一反三。你不是只学会这一道题，而是学会这一类题。别人靠感觉做十道题，你把一道题的考点真正看明白，可能就等于把这一类题都掌握了。

第三，理解考点才能正确复盘错题。没有考点分类，复盘往往只能停留在“又错了”；有了考点框架，你才能知道自己是某个考点不熟，是主体范围没看清，还是被某个固定误区带偏，然后有针对性地练习。

第四，理解考点会让题目变得更容易记忆。公考题目虽然文字晦涩，底层考点和结构却没有那么多。真正看出结构之后，题目就像熟悉的旧题，即使题目借鉴了多年前的联考真题，也能一眼认出它考的是什么。

#### 做慢做错的四个原因

平时又慢又错，通常可以从四个方向诊断。

**第一，没有理解题干的推理。** 题目让你从论据推到结论，你却把故事里的日常因果关系理解歪了，推理一旦偏了，答案很容易错。

**第二，不熟悉正确选项的陈述模式和结构。** 你只知道“这个选项感觉对”，却说不出它为什么能对、它在题干中起了什么作用。正确选项不是靠语气、故事感或常识选出来的，而是要完成某个逻辑任务。

**第三，忽略了主体范围和效果范围。** 已经有意识地分析论据和结论，却因为题干与结论的主体不同、范围不同，掉进了文字细节的坑。基础理论已经理解之后，这类问题通常需要通过针对性刷题来减少。

**第四，疯狂脑补，掉进考官挖的坑。** 考官会先确定考点，再找文字把题目包装起来，先设计正确选项，再围绕常见思维误区设计迷惑选项。错误选项往往正好针对我们日常思维中容易犯的错。你把误区纠正了，坑就没有那么可怕了。

> **结论**：初学者最常见的是前两种问题；进入中阶以后，要特别注意范围和脑补。错题复盘时，要能回答“我错在四类原因中的哪一类”，而不是只记一个选项字母。

### 论证推理的解题骨架

论证推理的结构来自“论据到结论”的推理。一道题通常包括提问句、论据、结论和选项，其他文字大概率是背景信息或干扰信息。真正的任务，是把题干里的逻辑骨架抽出来，再判断选项能不能和这个骨架扣在一起。

```text
提问句
  ↓
判断题型与方向：支持还是削弱
  ↓
寻找结论引词 → 找到结论
  ↓
从结论向前回溯 → 找到论据
  ↓
提炼从论据到结论的推理结构
  ↓
判断正确选项应承担的功能
  ↓
回到选项中匹配
```

#### 找对结构再读选项

正确的阅读顺序不是先读选项，也不是从第一句开始把整篇文章当小说读完。

第一步，看提问句。先判断它是不是论证推理，再判断是在问支持、削弱、假设、解释还是评价。削弱和支持的具体方向要先分清，是正着说还是反着说，但不要只停留在“我要找加强项”或“我要找削弱项”。

第二步，找结论引词。常见的形式包括“所以”“据此”“调查结果表明”“研究发现”“研究人员据此得出结论”“该研究团队由此认为”等等。结论通常在引词右边，但也不是每道题都如此；有些题目的结论会在第一句，关键是有意识地去找。

第三步，找到结论以后，一般从结论引词向前回溯一句寻找论据。找到论据和结论后，想清楚二者之间到底是什么推理，而不是只凭故事背景。

第四步，结构明确以后再看选项。问自己：如果考官想考C，C需要完成什么功能；如果B作为答案，它对应的是什么功能。不要只问“哪个选项对”，而要问“哪个选项最像考官要考的点”。

第五步，做完以后再想一道和一两道相同考点的题。能够横向联想到同类题，说明你不只是做对了一道题，而是已经看懂了它的结构。

大多数论证题里，至少七八成的文字属于背景或干扰信息，甚至有时只读结尾两句就能找到论据和结论。很多人做题慢，是因为从第一句读到最后一句，被长篇故事和背景绕晕了。背景信息能不看就不看，先把推理链条找出来。

#### 站在考官的角度

考官出题时，先想这道题要考什么，再找一段文字把考点包装起来，然后设计正确选项和错误选项。正确选项往往落在一个有限的范围里，比如引入他因、直接举例、引入其他因素的影响，后面每一个考点还会有更具体的模式。看似不同的话，可能都在完成同一个逻辑任务。

所以，题目最重要的不是“谁对”，而是“到底考什么”。如果C对，它在结构上为什么能对？如果B对，它对应的是哪一个考点？考点和选项必须像虎符一样扣在一起，题目才能严丝合缝。

> **提示**：优先在脑中预想正确选项应该承担什么作用，再去选项中寻找匹配项。找不到时再用排除比较，但不要把逐个代入变成主要解法。

### 底层结构：把不同故事看成同一道题

文字可以换，结构不会轻易换。所谓题干的底层结构，就是与文字无关的逻辑关系。下面的例题分别来自江苏、四川、浙江、山东、国考和联考，故事完全不同，但抽出来以后往往是同一种题。

#### A与B同时存在，推出A是B的原因

第一种结构是：A和B同时出现，题干因此把A说成B的原因。

| 例题来源 | 论据中的共同出现 | 题干结论 |
| --- | --- | --- |
| 2020年江苏 | 使用社交软件的基层工作人员，患病概率明显低于不使用的人 | 认为使用社交软件导致患病概率低 |
| 2020年四川 | 饲养宠物的家庭成员幸福感普遍高于不饲养宠物的家庭 | 认为饲养宠物导致幸福感高 |
| 2020年浙江 | 社交媒体使用时间超过125分钟的人，孤独感约为少于30分钟者的两倍 | 认为社交媒体使用时间越长，越容易感到孤独 |
| 2019年浙江 | 地球转速放缓时，强震也增多 | 认为地球转速放缓导致强震增多 |

它们的核心都是：

$$
A\text{与}B\text{同时存在}\Rightarrow A\text{是}B\text{的原因}
$$

这里不是说A、B同时出现就自动证明了因果，而是说考官在题干中搭的就是这个论证骨架。看到这种结构，先把A和B分别找出来，再问：A到底是什么作用导致B，支持时就补足联系，削弱时则要针对这个因果联系寻找问题。建立联系、由果推因等问法，都可能围绕这种结构展开。

#### 对比试验：有A有B，无A无B

第二种结构是对比试验。它不是一个孤立的考点，而是考官提供论据时经常使用的标准模式。

```text
有 A：有 B
无 A：无 B
          ↓
结论：A 导致 B
```

比如，睡眠时间短的人患癌风险更高，而睡眠时间较长的人风险较低，于是题干把睡眠时间短说成患癌风险高的原因。50岁时，摄入盐较少的人平均寿命长，吃得咸的男性和女性寿命都更短，死亡风险更高，题干就推出吃盐多会增加死亡风险、降低预期寿命。

还有常喝绿茶与心血管风险的对比，以及过量饮用咖啡与心脏病风险的对比：喝绿茶的一组风险较低，不喝的一组风险较高；喝咖啡较多的一组心脏病比例高，不喝的一组比例低。考官把这些文字换掉以后，结构仍然是有A有B、无A无B，因此建立联系时可以补足A对B的影响，削弱时要警惕因果倒置等问题。

这类题不要死抠“绿茶”“咖啡”“睡眠”或“盐”这些具体内容。内容只是考官拿来包装结构的材料，真正要抓的是A有没有带来B，以及题干把这个结果当成了什么结论。

#### 两句式推理：A推出B，所以A推出C

第三种结构是标准的两句式推理：

$$
A\text{推出}B（或}A\text{是}B）
\Rightarrow
A\text{推出}C（或}A\text{是}C）
$$

2025年国考的一题先给出PM2.5会导致炎症和氧化应激反应，最后认为死于癌症的风险增加与PM2.5有关。这里论据说的是A推出B，结论要说的是A推出C，论据和结论的主体保持一致。

2024年山东的一题说，相关部门针对直播乱象拓宽了投诉渠道，因此直播带货中的违法行为有所减少。它的推理是：对于直播乱象，拓宽渠道，所以现象减少。题干要补足的，是从“渠道拓宽”到“违法行为减少”的联系，这正是建立联系和补全逻辑要处理的地方。

2023年国考的一题把“基因表达”“钾离子流速”和“抗旱中的关键作用”串在一起：有基因表达时流速较高，不表达时流速较低，题干因此推出这个基因能够在抗旱中发挥关键作用。它仍然是从A推出B，再把B和C联系起来，主体没有换。

2024年联考的题也不是在考二手烟这个表面内容，而是先把二手烟暴露与血液中的某项指标联系起来，再把这个指标与智力、阅读推理能力联系起来，最后推出二手烟暴露会影响智力发育。文字关系稍微绕一点，底层仍然是同一个两句式骨架。

> **定义**：两句式推理不是只抓结论，也不是只盯某一个主体。论据和结论中的A必须保持一致，题目真正要求的是把A到B和A到C之间的联系说清楚。

这几组题在考官心里其实分别是一道题。只要你能把A、B、C抽出来，看到新故事时就不会再被文字牵着走。

### 做对之后还要做什么

一道题做对，不等于学习已经完成。真正的高手会在做对之后继续提取结构，在做错之后精准定位原因。

#### 三个要

**做完对的题，要说得出它的底层结构。** 如果你能把题目抽象成“A与B同时存在，所以A是B的原因”，或者“有A有B、无A无B，所以A导致B”，就说明你看到了可迁移的东西。

**做对的题，要能联想到同类题。** 每做一道题，都试着说出一到两道考相同逻辑的题。说不出来，可能只是靠感觉猜对，做下一道仍然会错。能够复现、迁移和联想，才说明这个考点真正掌握了。

**做错的题，要及时复盘原因。** 从“没有理解题干推理”“没有理解正确选项功能”“忽略主体或效果范围”“掉进考官挖的坑”中找准自己的问题，再做针对性练习。不是每一道错题都值得重做，但每一个反复出现的错误，都应该归到一个可处理的考点上。

此外，练习要优先做近10年的题目。1000多道近年题已经足够熟悉当前考点的文字风格和分布。旧题不是没有用，只是文字风格和考点分布可能发生变化；先做近年题，建立对当前考试的判断力，再去做靠谱的旧题。多做旧题并不能弥补对近年题型的理解，反而可能把时间花在已经不太贴近当前考试的表达上。

#### 三个不要

**不要就题论题、死抠字眼。** 绝大多数选项之所以正确，原因是它和题干的逻辑结构匹配，而不是因为它复述了题干背景。文字内容可以更换，结构关系才是重点。

**不要仅凭感觉疯狂刷题。** 只关心“这一道选没选对”，刷1000道题可能只是在重复使用同一种模糊感觉。把题目数量换成对考点和方法的理解，才有可能真正提高成绩。

**不要脑补。** 做题时要把日常发散思维切换成收敛、严谨的逻辑思维。故事里看起来合理的解释，不一定是考官要的逻辑解释；遇到不确定的选项时尤其要克制，不要为了让某个选项说得通而不断替题干添加前提。

逐个验证不是完全不能用，但它应该是一个兜底方法：当你暂时看不出考点、也没有识别出推理结构时，至少可以快速在两项之间做选择，不能因此长期恋战。论证推理的结构一旦看懂，选项往往几秒内就能定位；看懂了结构，十秒左右可能解决，完全没看懂则可能花很久还在猜。

### 系统框架要覆盖每一种题

学习技巧不能只会一招半式。学一个技巧做一道题，做另一个技巧做另一道题，考场上真正碰到时仍然可能不知道怎么办。方法论的价值，在于它要有一个架构，能够覆盖不同题目，而不是孤零零地堆技巧。

这套系统按三大模块展开：论证推理、形式逻辑、分析推理；一拖五另作专题。论证推理包含绪论和九个大的知识考点，其中两句式推理继续拆成三个小考点，由因推果继续拆成五个小考点。形式逻辑主要掌握前六类，直言命题单独看；分析推理也以前五类为主，最后一类题量较少。

按考点来学，还有一个好处：遇到错题时，你知道它是哪一类问题，而不是笼统地说“我削弱学不好”。“削弱学不好”和“逻辑学不好”一样，范围太大，很难指导下一步。真正有用的复盘语言是：我在由因推果中对A、B的因果联系不熟；在两句式推理中没有看出主体一致；在对比试验中没有抓住有A有B、无A无B；在组织答案时把背景当成论据。

这套系统追求的，是从考官命题的角度理解一道题的考点和底层逻辑。考官先想考点，再包装文字，再安排选项；你也应该先想考官要考什么，再预测正确选项应该承担什么功能。不要等到看完所有选项才开始猜答案，要在读题阶段就建立答案的可能形态。

### 真正要练成的能力

课程内容最终要落到几种可重复的能力上。

你首先要知道逻辑在考什么，知道一套题目为什么设置成这个样子；其次要熟悉一个考点后，能把这一类题快速解决，而不是只会做练习中出现过的原题；还要能深刻理解国考历年题目的考点分布和解题方法，知道不同地区在出题风格和考点分布上的差异；更重要的是，做错题时能够按照考点复盘，知道自己错在结构、范围、选项功能还是日常脑补。

所谓“胜兵先胜而求战”，放在逻辑里，就是先判断出题结构，再决定怎么下手。先定位考点，再抽出结构；先预测答案功能，再去选项中寻找匹配。只要形成这个顺序，做题就不再是面对一篇故事后凭感觉选择，而是把一道新题还原成已经掌握的题型。

目标不是让每一道练习题都变成“做过”的题，而是让每一个新考点都能被识别、每一种答案功能都能被解释。等你能够在看到选项之前，脑中已经有了两三种可能的正确选项模式，并且能和题干结构迅速扣合时，秒杀就不再是口号。

### 本讲提到的题目

这一部分只整理题干中已经明确出现的信息。逐字呈现中没有给出的完整选项、选项字母和具体原文，不在这里凭常识补造；能确定的是每道题的结构、考点和正确选项应承担的功能。

#### 建立联系类题目

- **2020年江苏题**：调查显示，使用社交软件的基层工作人员患病概率明显低于不使用社交软件的人，题干据此认为使用社交软件是患病概率低的原因。分析：A是使用社交软件，B是患病概率低，论证结构是A与B同时存在，所以A是B的原因。考点是建立联系；正确选项应补足使用社交软件与患病概率低之间的因果联系，若问削弱则应针对该联系提出问题。
- **2020年四川题**：饲养宠物的家庭成员幸福感普遍高于没有饲养宠物的家庭，题干把饲养宠物视为家庭幸福感高的原因。分析：A是饲养宠物，B是幸福感高。正确选项应说明饲养宠物带来的某种作用或影响因素，如何导致幸福感提高。
- **2020年浙江题**：在社交媒体上每天花费时间超过125分钟的人，孤独感大约是少于30分钟者的两倍，题干由此认为社交媒体使用时间越长，越容易感到孤独。分析：A是使用时间，B是孤独感，结构仍是A与B同时出现后被推成因果。正确选项的功能是补足A导致B的联系。
- **2019年浙江题**：过去一个半世纪中，地球转速放缓时，强震也增多，题干据此认为地球转速放缓导致强震增多。分析：这是同步出现被解释为因果关系的结构；支持应补足转速放缓与强震之间的联系，削弱则不能只停留在复述转速放缓和强震同时出现。

#### 对比试验类题目

- **睡眠与癌症风险题**：和睡眠6—8小时的参与者相比，夜间睡眠更少的人患癌风险更高；逐字稿还提到从不睡眠的人风险升高60%。分析：这是有“短睡眠”对应高风险、有“正常或较长睡眠”对应较低风险的对比证据，结论是睡眠时间短导致患癌风险高。正确选项应说明短睡眠对风险的影响。
- **摄盐与寿命题**：50岁时，摄入盐较少的人平均寿命长，吃得咸的男性和女性寿命都更短、死亡风险增加，题干推出吃盐多会增加死亡风险、降低预期寿命。分析：男女两组只是文字上的并列，真正要抽取的是盐摄入量与寿命风险的对比，支持应补足高盐摄入造成风险增加的联系。
- **绿茶与心血管风险题**：常喝绿茶被结论为有益心血管，论据中喝绿茶的一组风险较低，不喝的一组风险较高。分析：结构是有A有B、无A无B，因此A推出B。正确选项应说明喝绿茶如何影响心血管风险。
- **咖啡与心脏病风险题**：每天过量饮用咖啡的一组心脏病比例高，不喝咖啡的一组比例低，题干推出过量饮用咖啡会增加心脏病风险。分析：同样是对比试验，正确选项应承担A导致B的因果功能，而不是只重复“咖啡”和“心脏病”两个词。

#### 两句式推理类题目

- **2025年国考题**：PM2.5会导致炎症和氧化应激反应，题干认为死于癌症的风险增加与PM2.5有关。分析：论据和结论的主体都是PM2.5，结构是A推出B，所以A推出C。正确选项应补足PM2.5导致癌症风险增加的联系。
- **2024年山东题**：针对直播乱象拓宽投诉渠道，题干据此认为直播带货中的违法行为有所减少。分析：A是拓宽投诉渠道，B是减少违法行为。结论要从A推出C，核心是建立B与C之间的联系。
- **2023年国考题**：有基因表达时钾离子流速较高，不表达时较低，题干认为该基因在抗旱中发挥关键作用。分析：论据是A推出B，结论是A推出C，主体仍然是同一个基因。正确选项应把基因表达、钾离子流速与抗旱作用连接起来。
- **2024年联考题**：二手烟暴露会影响儿童智力发育，题干中间还给出了二手烟暴露与血液中某项指标、以及该指标与智力和阅读推理能力之间的关系。分析：无论中间的具体名词如何表述，骨架都是A推出B，再由A推出C。正确选项应补足这两段联系中缺失的一段。

## 两句式与一句式推理：先认结构，再补方向
> 对应块：BLK03 | 覆盖分集：P04-P05 | 块标题（分集名）：《两句式与一句式推理及补全逻辑》

判断推理里，有一道坎不算高，却特别容易把人绊倒：明明题干说的是同一个结论，为什么有的题直接支持结论就够，有的题却必须把论据也拉进推理？

很多同学不是不会找结论，也不是不知道哪个选项有关，而是没有先看透论据和结论的连接方式。题目里好像都写着“最能支持上述结论”，但只要论据和结论发生重复，考查的就不再是“结论对不对”，而是“从论据到结论的这步推理稳不稳”。

两句式推理在题目中的占比大约只有 10%—15%，频率不算高。可偏偏就是这 10%—15%，如果不弄明白，我们会一直纠结：同一个“A推出C”，为什么在一道题里可以直接支持，在另一道题里却不能选？例子支持为什么有时能选、有时又一定不能选？选项明明搭上了论据和结论，为什么还可能被判错？

答案只有一句话：**先认结构，再补方向。**

### 先找结论，再向前倒一句

做加强、削弱、前提和假设题，先别急着把整段材料从头看到尾。先找结论引词，比如“因此”“所以”“据此认为”“研究发现”“这说明”“故而”。找到以后，朝结论左边倒一句，那通常就是论据。

```text
背景、数据、实验描述等铺垫信息
                 │
                 ▼
      论据：材料实际给出的关系 A → B
                 │
      这里缺一环，正确选项往往要补它
                 ▼
      结论：题干要推出的关系 A → C
```

不要死抠某几个字，也不要因为主语换了名字就看不出来。我们要抓的是结构关系：论据和结论是不是共享了同一部分信息。相同的主体、相同的结果、相同的作用，只要构成可识别的重复，就说明论据与结论之间已经存在一条显性的推理链。

> **方法**：找到结论后，向前倒一句，比较论据和结论的前一半或后一半。前面重复，后面不同，或者后面重复、前面不同，都属于两句式推理；没有明显重复，通常就是一句式推理。

这个动作非常快，却能把后面所有选项的判断方向定下来。

### 重复就是两类推理的分界线

#### 两种常见的两句式结构

第一种是前一半相同。

```text
论据：A → B
结论：A → C
缺口：B → C
```

比如，“有某种事物，就会出现某种结果”，这是论据；最后却推出“另一主体也会出现同一结果”。共同的“A”已经写出来了，真正没写出来的是从论据结果到结论结果的连接。

第二种是后一半相同。

```text
论据：B → C
结论：A → C
缺口：A → B
```

比如，“某种条件出现，人们就采取某种行为”，最后却推出“另一主体出现时，人们也采取同样行为”。共同的“C”已经给出了，终点相同，但缺少前面两个起点之间的联系。

#### 一句式推理是什么样

一句式推理的结论本身就带着较完整的推理，论据更多是实验数据、对比结果、统计信息或背景介绍，和结论没有明显重复。

| 识别结果 | 论据与结论的关系 | 正确选项要做什么 |
| :--- | :--- | :--- |
| 两句式推理 | 有前一半或后一半重复 | 优先支持或反驳论据到结论的推理 |
| 一句式推理 | 没有明显重复 | 直接支持或反驳结论即可 |

> **结论**：同样看到“A推出C”，一句式题可以直接补“A如何推出C”；两句式题却要优先补“论据怎样参与这个C”。不能把两套判断标准混在一起。

### 同一个结论，为什么答案会变

2024年省联考有一道题，结论是“气候变暖让这片海域变得越来越绿”。论据说，海水变绿代表海中存在以浮游植物为基础的生态系统。

这里“变绿”重复了，所以是标准的两句式推理。结构可以写成：

```text
浮游植物 → 海水变绿

要补：气候变暖 → 浮游植物
```

正确选项要说明，气候变暖会加速浮游植物生长。D项虽然说气候变暖与海水变绿存在正相关，看起来已经支持了“为什么变暖会变绿”，但它只碰了结论，没有让原有论据中的“浮游植物”参与推理。

注意，D项不选，**不是因为“正相关”这个词天然不能选**。如果把理由记成“正相关不够明确”，遇到下一道同样出现正相关选项的题，我们很可能又会判断错。真正的原因只有一个：这是两句式推理，只支持结论还不够。

#### 改一处内容，题型就变了

再看一道关于绿地与孤独感的题。论据给出公园、绿地、居住环境和相关调查数据，结论是绿地面积增加会降低人们的孤独感。论据和结论没有明显重复，所以它是一句式推理。

这时，选项直接建立“绿地面积增加”与“孤独感降低”的联系即可。例如，绿地增加使人与人的互动频率提高，而互动频率提高有助于消除孤独感。这就是标准的建立联系，答案可以选D。

但如果我在论据中补上一句：“绿地面积多，会让人们有机会更多地接触自然空间。”结构立即改变：

```text
论据：绿地面积增加 → 更多接触自然空间
结论：绿地面积增加 → 孤独感降低
缺口：更多接触自然空间 → 孤独感降低
```

此时再选“互动频率提高”就不能只盯着主语了，必须让“接触自然空间”参与推理。正确选项应说明，定期接触自然空间有助于缓解孤独感。

考官为了避免争议，有时会把原来的干扰项改得不那么像。例如，选项只说“绿地面积大小与社交频率相关”，或者“面积大的小区有更多互动”，却不再明说互动会带来更低的孤独感。这时我们不能脑补“互动多，所以孤独感少”。选项没有把最后一步说完整，就不能脑补替它完成。

> **易错点**：题干有相关词，不等于结论自动成立。相关是题干要论证的内容，不是我们可以擅自补上的中间步骤。

#### 例子支持为什么有时对、有时错

无糖饮料与长胖的题也把这件事讲得很典型。结论是，经常喝无糖饮料的人反而更容易长胖；论据解释，无糖饮料降低了人对甜味的反应，从而让人摄入更多糖。

```text
无糖饮料 → 摄入更多糖
摄入更多糖 → 容易长胖
```

因此，要补的是“摄入更多糖会导致长胖”。如果某个选项只举儿童喝无糖饮料后肥胖的例子，它的确能证明“无糖饮料与肥胖之间可能存在联系”，但没有证明题干自己给出的那套解释。

所以，例证并不是一律不能选。错误不在“举例”，而在两道题的论证结构不同。下一道饥饿与愤怒的题就是一句式推理：论据是对情绪的实验数据分析，没有直接给出“饥饿如何导致愤怒”，结论才提出二者关系。此时用饥饿状态下受试者出现易怒、愤怒情绪的数据来举例，就是有效支持。

但如果把论据改成“饥饿会导致血糖降低”，再由血糖降低推出饥饿使人愤怒，就变成了：

```text
血糖降低 → 愤怒
血糖降低 → 饥饿
缺口：血糖降低 → 愤怒
```

此时同一个饥饿实验例子只支持“饥饿引起愤怒”的直接结论，不能补上“血糖降低导致愤怒”的中间环节，答案也就随之改变。

一句话记住：**例子在缺少中间链的题中可以补联系；论据已经给出中间链时，例子反而可能绕开考官要你补的那一环。**

### 做题不能只盯结论

两句式推理出现后，正确选项要优先支持或反驳“从论据到结论的推理”，不能只针对结论。题干中的常见考点分为三类：

- 补全逻辑的支持或假设；
- 建立联系的支持或假设；
- 指出相同是支持，指出不同是削弱。

这一块重点展开的是第一类：补全逻辑。所谓补全，就是把题干故意断开的那一环接上。前提题和加强题一样，都是顺着题干的方向说，不能凭感觉另起炉灶。

最基本的判断式只有两个：

$$
A \rightarrow B + B \rightarrow C = A \rightarrow C
$$

以及

$$
B \rightarrow A + A \rightarrow C = B \rightarrow C
$$

换成文字就是：**论据加选项，应当能够推出结论。**

> **定义**：补全逻辑不是“选项同时提到两个概念”就够了，而是选项必须提供一条方向正确、足以把论据接到结论上的逻辑链。

### 搭桥只对了一半

很多人到这里会直接记一个口诀：搭桥。题干出现两个概念，选项同时把两个概念连起来，通常就能选。

这个口诀只对了一半。考官如果暂时没有设置方向相反的干扰项，“搭桥”确实能帮你迅速缩小范围；但一旦有 $B \rightarrow C$ 和 $C \rightarrow B$ 两个选项，只看概念根本没有区别。考官的心里始终有一条正确方向，桥也必须朝着论证需要的方向搭。

2013年山东那道题中，结论是人类祖先早在320万年前就已经双脚行走，论据是非洲南方古猿已经具有定型的弓形足。前一半“人类祖先”重复，后一半不同，所以要补：

```text
弓形足 → 双脚行走
```

如果选项只说“弓形足与双脚行走有关”，仍然没有把方向说清楚。考官完全可以同时设置“弓形足推出双脚行走”和“双脚行走推出弓形足”，此时就必须选前者。搭桥没有方向，补全逻辑有方向。

体育课那道题也是同一个坑。论据说，没有体魄就没有好的学习状态，结论却是“提升学习成绩就必须开设体育课”。把论据改写成它的逆否方向，可以得到：

```text
好的学习状态 → 强健体魄
成绩提升 → 好的学习状态
缺口：强健体魄 → 开设体育课
```

正确项是“体育课是强健体魄的必要途径”，即“强健体魄推出体育课”。“体育课推出强健体魄”虽然同样搭上了两个概念，却把方向反了。

> **易错点**：不要把自己的做题正确率交给考官。考官不设反向干扰项时，靠“搭桥”可能蒙对；考官一设，你就必须靠方向做对。考官出了迷惑项而你能排除，这道题才算真正掌握。

### 先把选项翻译成箭头

补全逻辑看的就是箭头方向。先把常见的关联词翻成形式逻辑，很多选项甚至不用完整读完。

| 选项表达 | 箭头方向 |
| :--- | :--- |
| 只要 $B$，就 $C$ | $B \rightarrow C$ |
| 如果 $B$，那么 $C$ | $B \rightarrow C$ |
| 只有 $C$，才有 $B$ | $B \rightarrow C$ |
| $B$ 是 $C$ 的必要条件 | $B \rightarrow C$ |
| $C$ 是 $B$ 的必要途径 | $C \rightarrow B$ |

> **口诀**：“只有……才……”是后推前；“只要……就……”、“如果……那么……”通常按前推后理解。谁是必要条件，箭头就指向谁。

看到“只有仪式性活动才有鹿角饰品”，不能把它读成“有鹿角饰品，所以有仪式性活动”，而应先翻译为“仪式性活动推出鹿角饰品”。箭头一旦翻出来，选项的方向就藏不住了。

### 补链不是死记选项

补全逻辑的题目，背景材料可以换得很远，结构却高度稳定。我们真正要练的是看到结构以后直接锁定正确项，而不是把每道题的知识点各背一遍。

#### 人类祖先与考古发现

人类祖先与南方古猿的题，要补“弓形足推出双脚行走”。马坑里发现牛角、由此推测马坑可能与祭祀有关，要补“牛角推出祭祀”。活动地点附近发现鹿角饰品、由此推测当时已有仪式性活动，要补“鹿角饰品推出仪式性活动”。

这三道题的故事一个讲直立行走，一个讲祭祀，一个讲仪式活动，材料看起来毫无关系，结构却完全相同。考官甚至可以替换名词、调整背景，只要“论据主体→论据结果、论据主体→结论结果”不变，正确项就仍然是中间那条链。

火星上发现类似丹麦海岸的圆形鹅卵石，由此推测火星上曾出现水流，要补“鹅卵石推出水流”。如果选项写成“只有被水冲刷才会形成鹅卵石”，正好就是所需方向。

#### 地质、矿物与科学概念

科学概念题同样不靠死记。题干说理论无法被证伪，所以不是真正意义上的科学，要补“无法证伪推出不是真正的科学”，或者补它的逆否方向“真正的科学推出能够被证伪”。

“只有能被证伪的理论，才能称得上真正意义上的科学”就是合格表述。

景观里的石英砂存在平行直线的断裂结构，由此推测景观是巨大陨石撞击形成的，要补“平行直线断裂结构推出陨石撞击”。“只有经历了高速陨石撞击，才会显示平行直线断裂结构”正好符合方向。

火星表面的圆形平顶山探测到某些矿物质，由此推测火星早期覆盖冰原或曾有较多火山活动，要补“这些矿物质推出冰原”或“这些矿物质推出火山活动”。相应地，选项可以表述为“只有存在火山活动，才会出现这些矿物质”，也可以换用逆否方向。

含晶体的盐里发现某些矿物晶体，由此推测盐来自地幔，要补“这些矿物晶体推出地幔来源”。“某类晶体只能形成于地幔过渡带”就是需要的联系。

> **结论**：材料里的名词再陌生，逻辑结构也不会变。能把复杂故事压缩成 $A \rightarrow B$、$A \rightarrow C$，就已经解决了大部分识别工作；背景再长，也不用逐字背。

#### 从照片、PM2.5到二手烟

在目前的技术条件下，用照片作为证据不恰当，而论据说照片不真实，要补“不真实推出不恰当”，也可以换成它的逆否方向“真实推出可以恰当作为证据”。所以，选项可以写“不能完全反映真实的东西，不能成为恰当的理由”，也可以写“只有真实的东西才能在法庭上作为证据”。

PM2.5与癌症风险的题中，结论是PM2.5会增加患癌风险，论据是PM2.5会导致脏器炎症和氧化应激反应。需要补的是“炎症和氧化应激反应推出癌症风险增加”。“炎症和氧化应激反应是明确的致癌危险因素”直接命中。

二手烟与儿童智力发育的题也一样。结论是儿童暴露于二手烟会影响智力发育，论据是二手烟会增加血液中尼古丁代谢物含量，同时还说明智力发育水平与阅读、数学和推理能力相关。需要补“尼古丁代谢物含量增加推出这些能力下降”。

这里有一个很典型的坑。另一个选项只说“阅读、数学和推理能力是智力发展的重要标准”，它支持的是论据中“什么是智力发育水平”这一局部表述，并没有连接“二手烟→尼古丁代谢物增加”和“智力发育受影响”。它支持了一个句子，却没支持论据到结论的整条推理。

#### 家具、肥皂与服务数量

家具制作不是艺术，论据却说家具制作必须注重实用性，需要补“注重实用推出不是艺术”，或者补“艺术推出不重视实用”。在选项里，它既可以写成“注重实用性就不再是艺术品”，也可以写成“艺术品不重视实用性”。

海水中肥皂不起清洁作用，论据是海水的钠离子会阻止肥皂中的钠离子充分溶解，需要补“不能充分溶解推出不能发挥清洁作用”。对应选项是“肥皂中的钠要先充分溶解，才能发挥清洁作用”。反方向“只要充分溶解，就一定能清洁”没有承担题干要求的关键条件，不能选。

窗口业务数量持续下降，由此推出服务质量与办理水平会下降，需要补“业务数量下降推出服务质量下降”，或者补“服务质量不下降推出业务数量不下降”。如果选项是“只有业务数量不下降，服务质量才不会下降”，翻译后正是后一条，能够成立。

### 后一半相同，更容易把起点混在一起

有些题不是前一半重复，而是后一半重复。识别时仍然只看结构，不要被表述差异带跑。

#### 房价与购房意愿

2017年广州那道题说，人们感知到房价上涨时会买，感知到房价下跌时不买；由此得出政府的鼓励性购房政策出台并不会刺激购房意愿。

“人们不购买”重复了，是后一半相同：

```text
论据：感知房价下跌 → 不购买
结论：出台鼓励性购房政策 → 不购买
缺口：出台鼓励性购房政策 → 感知房价下跌
```

所以正确项必须说明，政策出台会使大部分人感知房价还要下跌。只说“大部分人购房主要受房价变动影响，不受政府政策影响”，仅仅支持了结论，没有让“价格感知”参与推理。

#### 调剂生与医生

2020年管综那道题相对复杂一些。论据说，医生是崇高而辛苦的职业，必须有足够的爱心和兴趣才能做好；结论是宁可招不满，也不要招调剂生。

把论据结构化：

```text
有爱心且有兴趣 → 能做好医生
做不好医生 → 没有爱心或者没有兴趣
```

“不要招调剂生”的言外之意是“调剂生做不好医生”。要把前面接起来，至少要说明调剂生没有爱心，或者没有兴趣。C项说调剂生往往对医学缺乏兴趣，正好补上了缺口。

如果只选“调剂生做不好医生”，那只重复了结论。如果选项说调剂生具有奉献精神，题干里根本没有出现奉献精神，也不能凭空替命题人补进去。

#### 达芬奇与智能机器人

2025年广东省的题与调剂生那道题结构一致。论据说，智能机器人能够精准完成细节操作，并合理规划任务；结论是外科手术机器人达芬奇虽有精密操作能力，但仍不算是智能机器人。

把论据写成必要条件：

```text
智能机器人 → 精密操作且合理规划
不精密操作或不规划 → 不是智能机器人
```

达芬奇已经满足“精密操作”，那么只差“合理规划”。要推出它不是智能机器人，就必须说明它不能合理规划。选项B正好补上。

这里也不能脑补“精密操作差不多就算智能机器人”。题干给的是两个必要条件，达芬奇满足一个，不等于同时满足两个，更不等于它就是智能机器人。

### 方向一反，正确项就变成干扰项

补全逻辑里，方向错误比缺少中间概念更隐蔽。

例如，在“家具不是艺术”的题中，“实用性推出非艺术”可以补链；到了相反表述中，就不能因为也出现了“实用性”和“艺术”而直接选择。

又如，肥皂题要求的是“充分溶解是发挥清洁作用的必要条件”。“只要充分溶解，就一定能清洁”把充分条件说成了不缺的充分条件，逻辑负担一下就重了。

这背后的原则没有例外：

> **易错点**：一个选项同时出现 $B$ 和 $C$，只说明它涉及两端；只有箭头从题干需要的一端指向另一端，它才是在补全论证。

我们没有必要去猜考官会不会设置反向项。题目一旦把这个坑摆出来，我们就应当能稳定排除。

### 中间句是隐藏的陷阱

最强干扰项不一定是方向相反的选项，也可能是只支持题干某一局部、看起来很有道理，却绕开真正缺口的选项。

二手烟题中，“阅读、数学和推理能力是智力发展的重要标准”就是一个典型。它确实支持了论据中关于“智力发展水平”的说明，甚至让人觉得很专业，但论证真正需要的是：

```text
二手烟 → 尼古丁代谢物增加 → 智力相关能力变化
```

只说“相关能力很重要”，仍然没有把“二手烟”接到“智力发育受影响”。识别这种选项时，不要问“它和材料有关吗”，要问“它补的是不是论据到结论的那条路”。

类似的坑还包括：

- 气温与海水变绿有关，但气温怎样通过浮游植物使海水变绿没有说清；
- 绿地面积与社交频率相关，但互动为什么能降低孤独感没有说清；
- 无糖饮料可能导致肥胖，但没有接上“无糖→更多糖摄入→长胖”；
- 互动、社交频率或相关能力很重要，但没有把题干指定的那条中间路径接完整。

它们的共同点是：都能解释材料的一部分，却不能作为完整论证的补全。

### 把判断动作固定下来

遇到疑难题，不需要把所有选项都读完。结构一旦看透，答案往往就在第一个符合方向的选项上。

```text
先找结论
   │
   ▼
向前倒一句找论据
   │
   ▼
检查前一半、后一半是否重复
   │
   ├─ 无明显重复：一句式，直接围绕结论建联系
   │
   └─ 有明显重复：两句式，写出缺口
                      │
          ┌───────────┴───────────┐
          ▼                       ▼
   论据 A → B              论据 A → C
   结论 A → C              结论 B → C
          │                       │
          ▼                       ▼
      补 B → C               补 B → A
```

做题时可以压缩成一套固定动作：

- 找“因此、所以、据此、这说明”等结论引词；
- 朝前倒一句找论据，不对无关背景恋战；
- 比较论据与结论的前一半、后一半；
- 没重复，就检查选项能否直接支持结论；
- 有重复，就先写出缺少的中间箭头；
- 把选项逐条翻译成箭头，检查方向和必要条件；
- 一旦找到严格符合结构的选项，停止扫描其他无关表述。

这就是补全逻辑能够“秒杀”的原因。不是题目没有难度，而是逻辑能考的结构本来就不多。反复看穿几道题，看到新材料时就会发现：无非是把“粘土”换成“晶体”，把“陨石撞击”换成“地幔来源”，背景没大变，考点也没有大变。

### 本讲提到的题目

以下题目均按课堂讲解时复述的题干要点整理，只保留讲师明确说出的条件与答案，不补造未展示的选项。

- **气候变暖与海水变绿**：气候变暖使海域变绿；绿色代表存在以浮游植物为基础的生态系统。最能支持的选项应说明气候变暖会加速浮游植物生长，课堂答案为C。D项“正相关”只支持结论，没有补上浮游植物这一环。
- **绿地与孤独感**：绿地面积增加会降低孤独感，原论据为调查或实验数据，属于一句式推理。建立绿地面积、互动频率与孤独感的联系即可，课堂答案为D。若论据增加“绿地多使人有更多机会接触自然”，就改为补“接触自然空间→缓解孤独感”，课堂改为C。
- **无糖饮料与长胖**：无糖饮料降低甜味反应，使人摄入更多糖，由此推出经常喝无糖饮料更容易长胖。应补“摄入更多糖→长胖”，课堂答案为B；只举儿童肥胖的例子没有补上中间机制。
- **饥饿与愤怒**：实验数据显示饥饿状态下更易出现易怒、愤怒情绪，由此推出饥饿使人愤怒，属于一句式，课堂答案为C。若论据改成“饥饿→血糖降低”，则应补“血糖降低→愤怒”，C不再符合。
- **房价感知与购房意愿**：人们感知房价下跌就不买，由此推出鼓励性购房政策不会刺激购房意愿。应补“政策出台→人们感知房价下跌”，课堂答案为C。
- **弓形足与直立行走**：南方古猿具有弓形足，由此推出人类祖先早在320万年前已双脚行走。应补“弓形足→双脚行走”，课堂答案为D；反向表达不能选。
- **体育课与学习成绩**：没有体魄就没有好的学习状态，由此推出提升成绩必须开设体育课。应补“强健体魄→开设体育课”，课堂答案为A。
- **牛角与马坑祭祀**：马坑中间发现牛角，由此推测马坑可能与祭祀有关。应补“牛角→祭祀”，课堂答案为D。
- **鹿角饰品与仪式活动**：活动地点附近发现鹿角饰品，由此推测当时已有仪式性活动。应补“鹿角饰品→仪式性活动”，课堂答案为E。
- **鹅卵石与火星水流**：发现类似丹麦海岸的圆形鹅卵石，由此推测火星曾出现水流。应补“鹅卵石→水流”，课堂答案为A。
- **可证伪性与科学理论**：无法被证伪的理论不是真正意义上的科学。应补“无法被证伪→非真正科学”，或补其逆否方向“真正科学→能够被证伪”。
- **平行直线断裂与陨石撞击**：景观中的石英砂有平行直线断裂结构，由此推测景观由巨大陨石撞击形成。应补“平行直线断裂结构→陨石撞击”，课堂答案为A。
- **火星矿物质与冰原、火山活动**：圆形平顶山探测到相关矿物质，由此推测火星早期覆盖冰原并曾有较多火山活动。可补“矿物质→冰原”或“矿物质→火山活动”，课堂答案为C。
- **盐中晶体与地幔**：盐中含某些矿物晶体，由此推测盐来自地幔。应补“矿物晶体→地幔来源”，课堂答案为B。
- **照片与证据真实性**：目前技术条件下，用不真实的照片作为证据不恰当。应补“不真实→作为证据不恰当”，或补“真实→可以恰当作为证据”，课堂答案为A。
- **PM2.5与癌症风险**：PM2.5导致炎症和氧化应激反应，由此推出其会增加患癌风险。应补“炎症和氧化应激→癌症风险增加”，课堂答案为A。
- **家具与艺术**：家具制作必须实用，由此推出家具制作不是艺术。应补“注重实用→非艺术”，或补“艺术→不重视实用”，课堂答案为D。
- **海水与肥皂**：海水中的钠离子阻止肥皂中的钠离子充分溶解，由此推出肥皂不起清洁作用。应补“不能充分溶解→不能发挥清洁作用”，课堂答案为A。
- **二手烟与儿童智力**：二手烟增加儿童体内尼古丁代谢物，题干又以阅读、数学和推理能力说明智力水平，由此推出二手烟影响智力发育。应补“代谢物增加→相关能力下降”，课堂答案为A。
- **窗口业务量与服务质量**：各窗口每年办理业务的平均数量下降，由此推出办理水平会降低。应补“业务量下降→服务质量下降”，或补“服务质量不下降→业务量不下降”，课堂答案为A。
- **调剂生与医生素养**：做好医生需要足够的爱心和兴趣，由此推出宁可招不满也不招调剂生。应补“调剂生没有兴趣”或“调剂生没有爱心”，课堂答案为C。
- **达芬奇与智能机器人**：智能机器人需要精密操作且合理规划，由此推出能精密操作的达芬奇不是智能机器人。应补“达芬奇不能合理规划”，课堂答案为B。
- **虚拟竞技与运气**：单纯靠运气获胜的不是电竞游戏，虚拟环境中的智力、体力对抗都是电竞游戏，由此推出虚拟竞技不是无规则竞技。应补“非单纯靠运气→非无规则竞技”，或补“无规则竞技→单纯靠运气”，课堂答案为D。

做题最后只守住一个判断：先把题干压成箭头，再看选项是不是用正确的方向把缺口接上。方向对了，选项里的故事再复杂也只是换了包装；方向错了，即便把两端概念都写出来，也只是“搭上了”，没有真正补全。

> **承前启后**：上一节讲完「两句式与一句式推理：先认结构，再补方向」，下一节接着讲「建立联系：把推理断点接成完整推理」。

## 建立联系：把推理断点接成完整推理
> 对应块：BLK04 | 覆盖分集：P06 | 块标题（分集名）：《建立联系：推理断点处的连接方法》

做到这里，我们已经能把一部分常见题干翻译成明确的逻辑关系。考官还会不会换一种方式设计正确项？会。补全逻辑可以直接用“只要……就……”把话接上，而建立联系往往不使用那么严格的逻辑连词，它要你在论据与结论之间补上一条真实的作用、因素或影响关系。

这恰恰是建立联系题好做的原因：题干已经把论据和结论摆出来了，推理断点也很明显。我们不需要猜整道题在研究什么，只要沿着题目往前找、往后找，看看中间究竟少了哪一句。

> **定义**：建立联系，就是在论据与结论之间补上“论据为什么能够导致结论”的桥梁。桥梁可以是趋势关系，也可以是某个因素带来的作用、功能或影响。

### 先找断点，再写缺口

拿到建立联系的题目，我们先别急着看选项。先做三件事：找到结论，定位它前面的论据，再比较二者的主体与信息。

如果论据与结论的前一半相同、后一半不同，题干往往是两句式推理。比如：

$$
A \rightarrow C
$$

这里，$A$ 是题干已经给出的论据，$C$ 是题干要求支持的结论，真正缺少的是：

$$
A \rightarrow B
\qquad\text{或}\qquad
B \rightarrow C
$$

前一种补法，是直接建立“论据特征与结论”之间的联系；后一种补法，是先找出中间变量，再补“结论特征为什么能推出中间变量”。我们后面会看到，这两种补法本质上都在处理同一个断点。

> **结论**：建立联系题不是让我们证明结论一定为真，而是让我们补上题干自己尚未说出的那部分理由。

#### 主体重复，往往就是断点提示

题干中的论据和结论如果反复围绕同一个对象展开，例如“脑细胞多少”“牙齿多少”“离子流速”“基因”“消化道不适”等，就说明论据与结论只差一截。

```text
定位结论
   ↓
向前找到论据
   ↓
比较论据与结论：哪些信息重复，哪些信息尚未接通
   ↓
把重复部分记作 A，把未接通的结论记作 C
   ↓
写出缺口：A 为什么能推出 C？或 B 为什么能推出 C？
   ↓
按缺口去匹配选项
```

读图要点：先抽象出 $A$、$B$、$C$，再找能完成 $A\rightarrow C$ 或 $B\rightarrow A$ 的选项。不要一上来就在四个选项之间来回比较，更不要因为某个选项里出现了熟悉的专业名词，就以为它能支持结论。

### 从“越多越……”建立联系

#### 脑细胞与聪明程度

先看2019年广东联考这道题。结论是狗比猫更聪明，理由部分说，猫的皮层神经细胞数量只有狗的一半。先把比较对象倒过来：猫的脑细胞比狗少，也就等于狗的脑细胞比猫多。

现在得到的是：

- 论据：狗的脑细胞比猫多；
- 结论：狗比猫更聪明。

但“脑细胞多”为什么就能推出“狗更聪明”？题干没有把这句话说完，这就是断点。正确项应当建立“狗的脑细胞更多”与“狗更聪明”之间的关系。

如果选项使用严格的逻辑连词，可以写“只要脑细胞多，就一定更聪明”；如果不使用逻辑连词，也可以写“脑细胞越多，越聪明”。这两种表述都在建立联系。关键不在于有没有“只要……就……”，而在于它有没有把“脑细胞多”与“聪明”接起来。

再比如，“动物的聪明程度随其大脑皮层神经细胞数量增加而提高”，也是在说同一个关系。考官未必非得写逻辑连词，考官可以只写事实关系。

> **易错点**：看到“越……越……”就直接套用某个模板，要先问一句：这个“越”是否真的连接了题干的论据与结论。没有连接对象，再漂亮的趋势句也没有用。

#### 脂肪与健康

再看2021年这道题，它要求支持这样一个结论：在肉类中，选择水产品会更健康。题干给出的理由有两个：其一，水产品的脂肪含量比较低；其二，水产品含有较多的不饱和脂肪酸。

把三个信息分别记下来：

- $A$：脂肪含量低；
- $B$：不饱和脂肪酸多；
- $C$：更健康。

现在需要建立的，是 $A\rightarrow C$ 或 $B\rightarrow C$。也就是说，低脂肪能推出更健康，或者不饱和脂肪酸多能推出更健康，任意一条都足以补上缺口。

所以，“肉类脂肪含量越低越健康”可以支持结论，“不饱和脂肪酸越多越健康”也可以支持结论。题目实际选择的是B项，也就是前者。

> **易错点**：E项只说“脂肪含量越低，不饱和脂肪酸越多”，它建立的是 $A$ 与 $B$ 的关系，并没有把 $A$ 或 $B$ 接到 $C$ 上。两个论据互相解释，不等于它们能推出结论。

这两道题完全一样：某项特征多或强，就更具备某项特点。考官可以把它写成“越多越……”，也可以写成“某因素带来某种影响”，还可以用“只要……就……”把逻辑补全。建立联系只是不一定用逻辑连词，并不意味着没有逻辑。

### 牙齿、粪便与体长

建立联系的结构一旦看懂，就会变得非常好秒杀。

2017年山东题根据某种动物的牙齿多、口器大、粪便化石长10厘米，推测它的体长可能超过两米。结论显然是“体长可能超过两米”，论据则是“牙齿多”或“粪便大”。

我们先别管选项写了多少背景，直接问：缺什么？

- 如果走“牙齿多”这条路，缺的是“牙齿越多，体长越长”；
- 如果走“粪便大”这条路，缺的是“粪便越大，体长越长”。

所以正确项应当在这两组对应关系中二选一。实际选择的是C项：“对于这类无脊椎动物而言，拥有的牙齿越多，身体越长。”

B项说“直径25厘米的牙齿可以掠食任何大型无脊椎动物”，没有建立牙齿数量与体长之间的趋势关系。25厘米的牙齿能做什么，说的是功能，不是体长，不能代替桥梁。

还有一个迷惑项D项说“牙齿和体长有固定的构成比例”。这个说法看起来比“越多越长”还确定，可它仍然没有支持当前推测，原因有两个。

第一，题干只提供了“牙齿多、可能体长超过两米”，没有告诉我们二者究竟按什么固定比例构成。仅仅说“存在固定比例”，仍然没有告诉我们这个比例能把已知事实连到两米以上。

第二，即使假定是一比一，25厘米的牙齿也不能凭空推出两米体长。结论需要的是可用的关系，关系存在却不给出具体内容，同样没有补上断点。

> **结论**：选项不是只要出现“固定比例”这种看起来很强的词就正确。它必须能利用题干已知的信息，真正把论据接到结论上。

考官写完一个标准正确项后，其他错误项往往是围绕它编出来的，未必每一项都值得深挖。学完这个考点以后，不妨自己试着编几道题，再编几项错误选项。你会发现，很多错误项只是换了主语、换了方向，或者只说了一个看似相关的因素。等你真能出题了，看到选项时也就不会再被它牵着走。

### 先翻译论据，再建立联系

有些题目的论据没有直接写成“因为$A$，所以$B$”，而是把$A$与$B$分成两种情况并列起来。看起来像在描述事实，实际上隐藏着一条推理。

#### 有$A$如何，无$A$如何

再看2023年国考题：有这个基因时，钾离子流速高；没有这个基因时，离子流速低。由此得出结论：这个基因在抗旱中发挥了关键作用。

题目中的论据不能只看到“有基因—流速高”和“无基因—流速低”这两半，还要把两组情况放回去翻译：

> 有这个基因，离子流速就会提高；没有这个基因，离子流速就较低。

于是论据被翻译成：

$$
\text{有基因} \rightarrow \text{离子流速提高}
$$

结论则是：

$$
\text{有基因} \rightarrow \text{抗旱能力增强}
$$

两条推理的前半句相同，后半句不同，缺口随之出现：离子流速提高，为什么就能推出抗旱能力增强？

正确项必须能够完成这一步，例如说明离子流速越高，抗旱性越强。题目实际选择的就是C项。

这道题比前面的题多埋了一点坑。坑不在选项，而在于论据的表述方式：它没有直接写“基因可以增加离子流速”，而是把有基因和没有基因放在一起说。只要把这种对照式描述翻译成因果关系，原来的结构马上就会显现出来。

> **提示**：看到一个“结论引导词”，先向左找它前面的论据；看到对照的两组情况，先比较“有什么”和“没有什么”分别带来了什么变化。翻译之后，再看论据究竟能推出哪一步，不能直接被选项里的结论句带走。

#### 选项有时会帮我们反推论据

有的同学看到选项会疑惑：“我怎么知道离子流速真能决定抗旱性？”

这很正常。我们不是看到选项以后，再回头给自己编一个理由。真正有用的办法，是先牢记题目需要什么样的桥梁，再看选项的表述是否恰好符合这个结构。

题干问“离子流速提高”为什么能推出“抗旱能力增强”，答案就应该以离子流速为主体，说明它带来的作用、因素或影响能导致抗旱性增强。选项一旦呈现这个完整结构，题干和选项就会彼此印证，而不是让你在四个选项里反复脑补。

漂亮的正确项并不是靠几个关键词堆出来的。它的漂亮，在于论据端、桥梁端、结论端都能一一对上。大家做得多以后，要对这种完整结构产生敏感度：看到选项的一瞬间，就能判断它是不是正好在补那道断点。

### 一个论据，两个可用路径

#### 蕨类植物为何能应对环境变化

再看24年的国考题。题干谈到蕨类植物有两个特点：基因组极为庞大，出现得也非常久远。结论是，蕨类植物的这些特征有助于它们应对地球环境的变化。

这里有两个论据支点：

- $A$：基因组庞大；
- $B$：出现时间久远；
- $C$：能够应对环境变化。

要支持结论，可以建立 $A\rightarrow C$，也可以建立 $B\rightarrow C$。因此，选项只需要抓住一条有效路径，不必把两个特征全塞进去。

实际正确项C选择了基因组庞大这一条，说明庞大基因带来的某种作用或影响因素能够使蕨类植物适应环境。换成“基因组越大，越能适应环境”，或者“出现时间越久远，越能适应环境”，也都能补上相同的逻辑断点。

除了“越……越……”这种趋势关系，选项还可以直接说某项特征带来了一个作用、一个因素或一个影响，而这个作用能够导致结论。写法不同，任务完全一样。

> **结论**：当论据和结论的前一半重复时，选项空间其实很小。无非是让已知特征直接推出结论，或者让已知特征通过某个作用、因素、影响到达结论。考官真正拿去充数的写法并没有多少。

#### 久坐为什么会影响记忆

2020年山东题说，久坐会使脑内某个区域缩小，而且无法改变这一缩小趋势；结论却是久坐会影响人的记忆。

先把题干整理一下：

- 久坐导致脑内某区域缩小；
- 该区域缩小；
- 久坐影响记忆力。

前两句话的共同基础是“久坐导致脑内某区域缩小”，但它怎么就能影响记忆？这里不能越过脑内区域，直接说“缩小”和“记忆”有关。正确选项应当说明这个脑内区域与记忆形成之间的关系。

题目选择的是C项，它说明该脑内区域与记忆形成有关。读法是：

```text
久坐
  ↓
脑内某区域缩小
  ↓
该区域与记忆形成有关
  ↓
久坐影响人的记忆
```

读图要点：论据里的“缩小”必须经过“该区域与记忆形成有关”这一层，才能接到结论。只重复“久坐”“缩小”或者“记忆力”，中间仍然少一环。

> **易错点**：方向不能反。题干缺的是“脑内区域缩小为什么能影响记忆”，不是“记忆力如何导致脑内区域缩小”。选项即使同时出现了两端，也要检查它是不是从论据指向结论。

### 中间变量：补上$B\rightarrow A$

有些题目的论据与结论并不只差一层。我们不能总把中间变量塞进题干两半之间，还要先找到真正缺少的那条连接。

#### 吃辣与血干细胞动员

2022年省考题认为，吃辣可以促进血干细胞动员。论据则说，某种由吃辣带来的刺激能够直接影响造血干细胞，并增加血干细胞动员。

先看已知关系：

$$
A \rightarrow C
$$

其中，$A$ 是吃辣带来的某种刺激，$C$ 是增加血干细胞动员。结论却不是 $A\rightarrow C$，而是：

$$
B \rightarrow C
$$

$B$ 是吃辣。要从“吃辣”走到“增加血干细胞动员”，只靠题干现有的 $A\rightarrow C$ 还不够，因为 $A$ 只是吃辣之后出现的某种刺激。我们必须先补：

$$
B \rightarrow A
$$

也就是：吃辣会带来这种刺激。

题目选择B项：“吃辣导致痛觉，并激活伤害感受神经元。”它正好把吃辣与题干中的刺激联系起来。题干已有“吃辣带来刺激—增加血干细胞动员”，正确项再补“吃辣—产生这种刺激”，整条链就闭合了。

> **结论**：当题干呈现“$A\rightarrow C$”的论据，但结论写的是“$B\rightarrow C$”时，选项应优先寻找 $B\rightarrow A$。它不是让结论回到论据，而是给论据补上来源。

这里还有一个很典型的迷惑项C。它的主语也是“吃辣”，看上去与正确项几乎一样，却说吃辣能促进消化液分泌、增加消化酶活性或加速肠道蠕动。这些作用与题干中的血干细胞动员没有建立关系，因此不能选。

> **易错点**：只看主语相同就选。正确项不仅要照顾结论端，还要把结论所需的那个具体作用接回来。吃辣能做的事情很多，不代表吃辣做的每一件事都能支持当前结论。

#### 化肥滥用、水体营养与甲烷

再看2019年山东题，题干用一条完整的中间链提出建议：为了降低温室气体排放，应该限制化肥滥用。论据是，富含营养的水体会释放更多的甲烷。

先从论据与结论的共同部分里找关系。题目实际使用的是：

- $A$：水体营养丰富；
- $B$：化肥滥用；
- $C$：释放更多温室气体所形成的结果，即建议限制化肥滥用。

已有的是：

$$
A \rightarrow C
$$

结论需要的是：

$$
B \rightarrow C
$$

所以缺失的仍然是 $B\rightarrow A$：化肥滥用会让水体营养变得丰富。

正确项D指出，滥用化肥很容易给水体或沉积物带来过多营养，正好把“化肥滥用”接到“水体营养丰富”。整条推理便是：

```text
化肥滥用
   ↓
水体营养过多
   ↓
释放更多甲烷
   ↓
形成需要控制的温室气体问题
```

读图要点：题目讨论的不是“化肥会不会污染环境”这样宽泛的问题，而是“化肥滥用为什么会带来更多温室气体”。选项必须参与这条具体推理，不能只说化肥有污染。

这道题与吃辣题没有本质区别。题干已经给出一段从中间变量到结果的关系，我们只需在选项中补出结论的起点如何进入这段关系。考官在命题时，做的也是同一件事。

### 变化为什么不等于完善

再看2025年浙江题，它讨论的是鸟类迁徙。

结论认为，鸟是通过学习，不断完善迁徙路线。论据是：它在飞行中不断改变线路，并路过一些新地方。

只看论据，最多能推出“路线在变化”。变化可能意味着路线更优、更短、耗能更少，也可能只是到处乱飞，甚至可能是鸟在迷路。题干把“变化”直接接到“完善”上，中间同样缺一座桥。

所以正确项需要说明路线变化带来了什么作用。实际选择的D项指出：随着迁徙次数增加，路线变化得更加优质、更短，消耗的能量也更少。这里的“更优、更短、耗能更少”才把“变化”限定成了“完善”。

如果路线越变越绕、越来越难找、越来越累，那就不是完善，甚至可能说明它出了问题。论据里虽然出现了“完善”，但只要没有说明完善的判断标准，支持力度仍然不足。

> **易错点**：两个词听起来相关，不代表它们在逻辑上相等。“变化”不自动等于“完善”，“敏感”不自动等于“不健康”，“失眠”也不自动等于“不健康”。建立联系题经常故意用这种语义上沾边、逻辑上却没有接上的选项。

看这类题目的选项之前，一定要先说清楚正确项应该承担什么作用。先问：题干的变化究竟带来了什么？只有当答案能解释这种变化为什么意味着结论所说的结果，它才是桥梁；否则只是借用了题目里的几个词。

### 提出建议，也可能在中间缺一步

#### 投诉渠道与直播带货违法

再看24年的广东题。针对直播带货乱象，相关部门拓宽了消费者投诉渠道。结论是，直播带货违法现象将有所减少。

论据是“拓宽投诉渠道”，结论是“违法现象减少”。为什么投诉渠道拓宽以后，违法行为就会减少？正确项必须把这两端接起来。

实际选择的是A项：“拓宽消费者投诉渠道，有助于遏制直播带货的违法行为。”它正好直接补上了缺口。其他选项即使谈的是直播行业，也不能代替投诉渠道与违法减少之间的这条具体关系。

这里尤其要分清题目到底在问什么。它不是在泛泛讨论“直播带货违法现象会不会减少”，也不是只让你赞同政策结论；它是在问“题干为什么能从拓宽投诉渠道推出违法现象减少”。

> **结论**：两句式推理里，直接重复或支持最终结论，不一定就是正确项。论据必须参与推理。如果选项绕开了论据，它即使与结论一模一样，也可能只是一个迷惑项。

#### 家族史、风险提示与预防糖尿病

再看19年的广东题，它要求补充前提。结论是：了解家族史有助于更好地预防糖尿病。论据则是：了解家族史，是提示糖尿病风险的重要依据。

“提示风险”和“帮助预防”显然不是同一个动作。知道风险并不自动等于完成预防，中间仍然需要一道桥。

正确项应当说明：了解糖尿病风险这件事，怎样进一步帮助人们预防糖尿病。也就是说，它要指出一个由“提示风险”带来的作用或影响。题目选择的B项正是“了解糖尿病风险有助于预防糖尿病”。

这道题与直播带货题的结构没有区别。前者从“了解家族史”走向“提示风险”，再由“了解风险”走向“预防”；后者从“拓宽投诉渠道”走向“违法现象减少”。两题都用同一种办法补缺口，只是换了生活场景。

#### 咖啡因与奶茶健康

2021年广东题中，专家提醒青少年，为了保持健康，奶茶不要贪杯。题干给出的理由是：奶茶含有较多咖啡因。

整理之后就是：

- 论据：奶茶含咖啡因；
- 结论：奶茶不能多喝，多喝不健康。

为什么含咖啡因就能推出不健康？还要说明摄入咖啡因达到什么程度时会产生健康影响。正确项A指出，过量摄入咖啡因会影响人们的健康，恰好把“咖啡因”与“不健康”接起来。

其他选项即使也谈咖啡因，却没有完成这个连接：有人对咖啡因更敏感，不等于不健康；失眠不等于不健康；吸引力更高，也不等于不健康。正确项必须同时接住“过量咖啡因”和“健康受到不良影响”两端。

> **易错点**：支持题不是找“最有科学感”的句子，而是找“最能补齐题干推理”的句子。题目要的是“含咖啡因—不健康”的桥梁，就不能被其他健康话题带走。

#### 丁酸盐与大脑功能

2021年上海题中，研究人员根据膳食纤维能够提高丁酸盐水平的研究，建议老年人多吃富含膳食纤维的食物，以延缓大脑功能的衰退。

这里已经有了“膳食纤维提高丁酸盐水平”，而最终结论是“多摄入膳食纤维有助于延缓大脑功能衰退”。但丁酸盐为什么会影响大脑功能？这一步仍需补上。

正确项应当以丁酸盐为主体，说明它带来的某种作用、功能或影响能够作用于大脑。题目选择的是B项：丁酸盐带来的作用能够增强大脑细胞的抗炎能力。既然作用直接落在大脑细胞上，它就有理由支持对大脑功能的保护。

这条推理可以写得很清楚：

```text
多补充膳食纤维
       ↓
提高丁酸盐水平
       ↓
增强大脑细胞的抗炎能力
       ↓
延缓大脑功能衰退
```

读图要点：建立联系题不一定必须照搬题干的“膳食纤维”作为选项主语。这里需要补的是“丁酸盐水平为什么能影响大脑功能”，所以主语应当是丁酸盐。

### “不吃有害”不等于“吃出好处”

最后一道题特别适合检查我们有没有真正理解建立联系。

24年省联考题发现，地中海膳食等膳食模式能够保护老年人的认知能力。论据是，这些膳食模式强调了多吃某些食物、少吃或不吃另一些食物。

如果只支持“不吃某些有害食物”，最多能说明我们避免了一定损害；它不能自动说明我们的认知能力得到了保护。没有被骗、没有损失，不等于钱变多了；没有摄入有害因素，也不等于已经获得了好处。

要推出“保护认知能力”，还需要说明这些被强调摄入的食物能带来什么积极作用。它们是否可以减少肥胖、预防或改善三高，再由这些作用连接到认知能力？只要建立起这条链，就能支持结论。

实际正确项D正是分别说明相关食物有助于控制血糖、改善血脂等。这些作用共同指向肥胖与三高问题，再连接到认知能力的保护，因而比单纯重复“这种膳食有利于延缓认知退化”更符合这道两句式推理的缺口。

> **易错点**：B项直接支持最终结论，看上去与题干高度一致，却不能选。原因不是它内容错误，而是它没有让论据参与推理。如果这是一句式推理，前面的论据删掉以后，单独支持结论是可以的；可本题属于两句式推理，论据与结论的主体重复，必须把论据搭进选项。

> **结论**：句子式推理的选项要“论据 + 结论”；两句式推理还要额外回答“论据为什么能导致结论”。只重复结论，在两句式推理里反而可能成为专门设计的迷惑项。

### 正确项为什么看起来特别漂亮

做建立联系类型的题目久了，我们会发现，正确项往往有一种很稳定的“长相”。它不是堆术语，也不是故意写得复杂，而是两端都照顾到了。

> **结论**：漂亮的正确项通常具备“论据端、作用端、结论端”三个位置：论据端承接题干，作用端解释中间发生了什么，结论端回到题干要支持的结果。

大体可以分成三类。

| 题干缺口 | 正确项的任务 | 常见表达方向 |
| :--- | :--- | :--- |
| 已有 $A\rightarrow C$ | 直接补全两端 | $A$ 越多，$C$ 越明显；$A$ 能影响 $C$ |
| 已有 $A\rightarrow C$，要推 $B\rightarrow C$ | 补上 $B$ 如何进入已有关系 | $B$ 导致 $A$；$B$ 带来产生 $A$ 的刺激 |
| 论据与结论前一半相同 | 让论据中的主体实际参与推理 | 论据主体通过某种作用、因素或影响到达结论 |

表格只说明模板，不代表看到某几个词就机械套用。无论写“越……越……”，还是写“带来了一个作用”，都必须检查主语、方向与题干的缺口。

补全逻辑与建立联系也要分开。补全逻辑可以直接用逻辑连词补：

- “只要$B$就$C$”；
- “只有$C$才$B$”；
- “$B$是$C$的充分条件”。

建立联系则未必使用逻辑连词。它可以告诉我们，$B$ 带来了一个作用、一个因素或一个影响，而这个作用、因素或影响能够导致$C$。

无论使用哪种句式，判断标准都一样：把选项代入题干，看看它能不能真正把论据接到结论上。

### 一套稳定的解题动作

现在可以把建立联系题的做题动作压缩成一套固定流程。

先找结论。题干里的“因此”“由此推测”“专家认为”“建议”“提醒”等词，常常会把结论从材料中拎出来。结论找到后，不要急着向后看选项，先问：题干为什么能得出它？

再倒着找论据。沿着结论向前读，把题干真正使用的依据找出来。若前后分别有论据和结论，不要只摘一个共同主语，而要把各自的特征完整写出来。

然后比较论据与结论。如果前一半相同、后一半不同，通常就是两句式推理。把重复部分抽象为 $A$，把尚待解释的部分记为 $C$，问题便成为“为什么$A$能推出$C$”。

接着判断有没有中间变量。若题干已经给出 $A\rightarrow C$，而结论却是 $B\rightarrow C$，就检查选项能否补出 $B\rightarrow A$。若题干只是并列给出两个论据特征，则可以让任意一个特征直接连接结论。

最后再读选项。只问一件事：这个选项补的是不是刚才写出的缺口？主语是谁？方向从哪里到哪里？有没有真的接住结论？不要问“它听起来像不像正确答案”，而要问“它能不能让题干往前走一步”。

```text
题干
  │
  ├─ 找到结论 C
  │
  ├─ 向前找到论据 A 或已有关系 A → C
  │
  ├─ 比较重复信息，找出不一致处
  │
  ├─ 需要时设中间变量 B
  │
  └─ 到选项中寻找
       A → C
       B → A
       或“A 的作用 / 因素 / 影响 → C”
```

读图要点：选项匹配的是缺口，不是主题。题干谈健康，选项也谈健康，只能说明话题相同；只有把论据特征与结论结果真正接起来，才构成支持。

> **易错点**：错误项常见有四种形态。第一，只建立两个论据之间的关系，却不连接结论；第二，主语和话题相同，但描述的并不是题干所需作用；第三，直接重复最终结论，却绕开论据；第四，把连接方向写反。四种问题都可以回到缺口处检查，不需要凭感觉硬选。

### 本讲提到的题目

**题目：2019年广东联考——狗比猫更聪明。** 题干称，猫的皮层神经细胞数量只有狗的一半，要求最能支持狗比猫更聪明的结论。解析：论据只能得到狗的脑细胞比猫多，还要建立脑细胞数量与聪明程度之间的联系。答案：选择表达“脑细胞越多，越聪明”或大脑皮层神经数量与聪明程度正相关的选项。

**题目：2021年——肉类中的水产品更健康。** 题干称，水产品的脂肪含量比较低，并含有较多不饱和脂肪酸，要求最能支持选择水产品更健康。解析：要么建立脂肪含量低与健康之间的联系，要么建立不饱和脂肪酸多与健康之间的联系；只说明脂肪与不饱和脂肪酸之间的关系不足。答案：B项，肉类脂肪含量越低越健康。

**题目：2017年山东——某远古动物的体长可能超过两米。** 题干提供其牙齿多、口器大及粪便化石大等信息，推测体长可能超过两米。解析：补出“牙齿越多，体长越长”或“粪便越大，体长越长”即可；25厘米牙齿能捕食大型动物没有连接体长。答案：C项，牙齿越多，身体越长。

**题目：2023年国考——某基因在抗旱中发挥关键作用。** 题干对比：有该基因时离子流速高，无该基因时离子流速低。解析：先把论据翻译成“该基因能够提高离子流速”，再建立离子流速提高与抗旱性增强之间的联系。答案：C项，离子流速越高，抗旱性越强。

**题目：24年国考——蕨类植物的特征有助于应对环境变化。** 题干给出蕨类植物基因组庞大、出现时间久远两个特点。解析：可以让庞大基因组直接连接适应环境，也可以让出现时间久远直接连接适应环境。答案：C项，庞大基因带来的影响有助于蕨类植物适应环境。

**题目：2020年山东——久坐影响人的记忆。** 题干称久坐会导致脑内某区域缩小，且无法改变缩小趋势。解析：补出该脑内区域与记忆形成之间的关系，不能跳过中间区域。答案：C项，脑内相关区域与记忆形成有关。

**题目：2022年省考——吃辣促进血干细胞动员。** 题干称，吃辣带来的某种刺激能够直接影响造血干细胞，并增加血干细胞动员。解析：论据是“某种刺激—增加动员”，结论是“吃辣—增加动员”，需要补出吃辣会产生这种刺激。答案：B项，吃辣导致痛觉，激活伤害感受神经元。

**题目：2019年山东——限制化肥滥用以降低温室气体排放。** 题干称，富含营养的水体会释放更多甲烷。解析：已有“水体营养丰富—释放更多甲烷”，需要补出“化肥滥用—使水体营养丰富”。答案：D项，滥用化肥容易给水体或沉积物带来过多营养。

**题目：2025年浙江——鸟通过学习不断完善迁徙路线。** 题干称鸟的飞行线路不断变化，并会路过一些新地方。解析：路线变化本身不等于完善，必须说明变化带来的路线更优、更短、耗能更少等作用。答案：D项，随着迁徙次数增加，路线变化得更加优质、更短，耗能更少。

**题目：24年广东——拓宽投诉渠道能减少直播带货违法现象。** 题干称相关部门针对直播带货乱象拓宽了消费者投诉渠道。解析：必须建立“拓宽投诉渠道—减少违法现象”，不能只重复最终结论。答案：A项，拓宽消费者投诉渠道有助于遏制直播带货违法行为。

**题目：19年广东——了解家族史有助于预防糖尿病。** 题干称，了解家族史是提示糖尿病风险的重要依据，要求补充支持前提。解析：从“了解风险”连接“预防糖尿病”。答案：B项，了解糖尿病风险有助于预防糖尿病。

**题目：2021年广东——青少年为了健康不要多喝奶茶。** 题干理由是奶茶含有较多咖啡因。解析：补出过量摄入咖啡因会影响健康。答案：A项，过量摄入咖啡因会影响人们的健康。

**题目：2021年上海——老年人应多吃富含膳食纤维的食物。** 题干称，多补充膳食纤维能够提高丁酸盐水平，相关膳食有助于延缓大脑功能衰退。解析：补出丁酸盐的作用与大脑功能之间的联系。答案：B项，丁酸盐能够增强大脑细胞的抗炎能力。

**题目：24年省联考——地中海膳食等模式能够保护老年人认知能力。** 题干称这些膳食模式强调摄入某些食物并不摄入另一些食物。解析：只支持“不吃有害”最多说明没有损害，不能证明具有保护作用；还需要说明所摄入食物通过控制血糖、改善血脂、减少肥胖或三高等作用连接认知能力。答案：D项，相关食物分别具有控制血糖、改善血脂等作用。
