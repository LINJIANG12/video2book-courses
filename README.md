# 课程精读教材与复习笔记合集

四门真实网课的**精读教材长文 + 模块合辑全书 + 思维导图复习笔记**，全部由 [Video2Book](https://github.com/LINJIANG12/video2book) 从课程音频重构而成。

长视频课的痛点很直接：讲得好的课往往几十上百集，看不完，看完了也记不住；想回头查某一讲，还得在进度条里来回拖。这里把每门课拆成了三层资料——

- **单集精读长文**：一集一篇，哪一讲忘了直接翻哪一篇，不用再拖进度条
- **模块合辑全书**：按知识体系重新分册，像教材一样可以体系化通读
- **复习笔记**：跨模块聚合，带知识拓扑树，考前速查或直接导成脑图

正文保留了讲师原本的推导过程、板书案例和课堂比喻，不是把视频压成要点列表。

## 应该怎么学

不同目标对应不同的入口，不用四门都从头读：

**想系统学一门课** → 进课程目录，从 `textbooks/` 的模块 01 顺序往下读。模块顺序与课堂讲授顺序一致，每册开头有导读、结尾有模块技术总结，读起来是连贯的教材而不是拼凑的笔记。

**想补某一讲 / 查一个知识点** → 用浏览器的仓库内搜索，或把仓库克隆到本地后用编辑器全库检索（VS Code 按 `Ctrl+Shift+F`）。长文信息密度高、术语统一，跨课程检索也能定位到具体讲解。

**考前突击** → 直接看 `notes/`。笔记的粒度比长文大、比教材小，重点是跨章节的概念对比与速查条目，适合快速过一遍知识体系。

**想边看视频边对照** → 每门课的目录页都给了原视频链接；需要确认讲师原话时，去 `subtitles/` 找同编号的逐字稿。

**零基础不知道从哪开始** → 先读[黑马程序员：Python + AI 入门](黑马程序员-Python-AI/)，它从装环境讲起；有 Python 基础后，按兴趣选 NLP 或数据库方向。

## 三类产物怎么选

| 产物 | 在哪 | 粒度 | 什么时候用 |
| :--- | :--- | :--- | :--- |
| 单集精读长文 | `<课程>/articles/` | 一集一篇 | 定向查阅某一讲，或跟着课程进度逐集精读 |
| 模块合辑全书 | `<课程>/textbooks/` | 一册覆盖若干集 | 体系化通读、跨章节串联、打印装订 |
| 复习笔记 | `<课程>/notes/` | 一篇跨多个模块 | 考前速查、知识盘点、导入脑图 |
| 逐字稿 | `<课程>/subtitles/` | 一集一份 | 核对讲师原话、检索课程里提过的具体名词 |

产物命名规则统一：`PXX_` 前缀对应原始分集编号，`模块XX_` 与 `笔记XX_` 是整编后的新编号，两者可用集号互相追溯。

## 阅读与工具

**在线阅读**：直接在 GitHub 点开任意 `.md` 文件即可，标题会自动生成目录锚点。

**克隆到本地**（约 10 MB，音频未入库）：

```bash
git clone https://github.com/LINJIANG12/video2book-courses.git
```

**推荐阅读器 Typora**：三类产物都按 Typora 排版。数据库与 NLP 的长文含行内公式，需要在「偏好设置 → Markdown」中勾选**内联公式**，否则公式会原样显示 `$…$` 源码。

**导入脑图**：复习笔记开头的知识拓扑树用缩进层级表达结构，VS Code 装 Markmap 插件后打开即可预览，XMind 可通过导入 Markdown 大纲生成导图。笔记正文的标题层级同样可作为脑图节点。

## 关于生成方式

本仓库内容全部由 [Video2Book](https://github.com/LINJIANG12/video2book) 生成，流程不落中间逐字稿文件：

1. 解析课程合集结构，用 ffmpeg 把每集音频提取为 16kHz 单声道切片
2. 宿主模型直接聆听音频切片，按统一风格提示词逐集写成精读长文
3. 多集长文按知识体系切分成模块，整编为合辑教材；再跨模块归并成复习笔记
4. 交付前过一遍机器门禁，套话填充、空壳标题、分集平铺标题等问题会被拦下

各课程的账本字段显示听音与写作均由宿主原生完成（`asr_engine` / `doc_engine` 均为 `agent-native`），未经外部转录服务。

想用自己的课程跑一遍，见 [Video2Book 仓库](https://github.com/LINJIANG12/video2book)；听音通道由配套的 [omni-media](https://github.com/LINJIANG12/omni-media) 提供。
