## 应该怎么学

不同目标对应不同的入口，不用二十三门都从头读：

**想系统学一门课** → 进课程目录，从 `textbooks/` 的模块 01 顺序往下读。模块顺序与课堂讲授顺序一致，每册开头有导读、结尾有模块技术总结，读起来是连贯的教材而不是拼凑的笔记。

**想查一个知识点** → 用浏览器的仓库内搜索，或把仓库克隆到本地后用编辑器全库检索（VS Code 按 `Ctrl+Shift+F`）。模块全书信息密度高、术语统一，跨课程检索也能定位到具体讲解。

**考前突击** → 直接看 `notes/`。笔记的粒度比模块全书小，重点是跨章节的概念对比与速查条目，适合快速过一遍知识体系。

**想专攻现代大模型全栈架构** → 读 [Stanford CS336：从头构建大语言模型](Stanford-CS336-从头构建大语言模型/)，从分词算法、Transformer 算子工程、Triton GPU 内核、分布式并行一直讲到扩展定律与强化学习对齐（RLVR），是全库系统深度最硬核的一门课。

**想掌握现代大模型应用开发、Agent 智能体与知识库 RAG** → 读 [2026版LangChain教程](2026版LangChain教程/)，从多平台模型统一接入、LangSmith 链路追踪、Agent 自主调度、中间件 Hook 拦截到基于 Milvus 的知识库实战，全景覆盖现代 AI 应用开发落地方案。

**想吃透计算机视觉与深度学习表征** → 读 [Stanford CS231N：深度学习与计算机视觉](Stanford-CS231N-深度学习计算机视觉/)，李飞飞教授团队打造的视觉经典，从反向传播、CNN 卷积网络、视觉 Transformer（ViT）一直讲到自监督与 Diffusion 扩散模型。

**想吃透现代计算机系统与操作系统内核** → 读 [南京大学：操作系统原理（蒋炎岩）](南京大学-操作系统原理/)，蒋炎岩老师 2026 年最新录制，从状态机模型、C 语言底层运行时一直讲到并发控制、崩溃一致性与大模型时代的操作系统演进。

**想系统学考研数学或打牢微积分基础** → 读 [宋浩《高等数学》2.0 版](宋浩高等数学2.0版/)，149 讲按考研大纲完整覆盖，从极限、微分中值定理一路讲到多元微积分与幂级数，配套【黑板】集专攻计算技巧；若只想要一元微积分主线，可选更精简的 [同济版 2024](宋浩高等数学同济版2024/)（56 讲）。

**想掌握计算机网络五层模型并练计算题** → 读 [中科大：计算机网络（自顶向下）](中科大计算机网络/)，中科大郑烇、杨坚老师 69 讲，从应用层、套接字编程、TCP 拥塞控制讲到 SDN 与网络安全，最后两册是各章习题的大题精解。

**想系统学数据库原理（关系模型、范式、查询优化）** → 读 [数据库系统原理（DBMS）](数据库系统原理/)，28 讲覆盖数据模型、SQL 标准语言、安全性与完整性、关系数据理论、数据库设计与查询处理；只想动手练工具则看 [MySQL 大课](MySQL数据库入门到大牛/)，只想两小时跑通 SQL 全流程则看 [SQL 两小时半](SQL两小时半入门/)。

**想突击公考判断推理拿分** → 读 [公考逻辑：判断推理系统课](公考逻辑判断推理/)，63 讲按八大题型推进，核心是题型识别优先于知识积累：削弱加强是分值大头，一一对应与文氏图是提分点，适合短期应试训练。

**想掌握 AI 时代的全新开发范式与智能体协作** → 读 [南京大学：生成式软件工程【连载中】](南京大学-生成式软件工程/)，从 LLM 计算本质、Prompt 上下文机理到 Git 有向无环图与 Multi-Agent 并发协作，探索软件工程第一性原理。

**初入科研迷茫、想掌握学术研究与论文心法** → 读 [南京大学：科研筑基（结丹期教授）](南京大学-科研筑基/)，直击选题痛点、学术写作汇报与科研身心秩序。

**想探索人类心理困扰、精神病理与临床案例分析** → 读 [北京大学：变态心理学](北京大学-变态心理学/)，北京大学心理学专业旗舰课程，从生物-心理-社会理论模型、精神分裂症谱系、抑郁与双相心境障碍，到焦虑强迫、进食成瘾与人格障碍，结合真实临床病例深度推演，兼具学术严谨与人性深度。

**想从零系统学通英语语法、或查语法点** → 读 [英语语法精讲合集](英语语法精讲合集/)，先建「句子成分 + 十大词类」的语法地图，再逐块攻克时态与虚拟语气、非谓语与从句、冠词介词代词，直到被动、倒装、强调、省略与标点；既适合零基础从头读，也适合按主题查笔记速查。

**想边看视频边对照** → 每门课的目录页都给了原视频链接；需要确认讲师原话时，去 `subtitles/` 找同编号的逐字稿。

**零基础不知道从哪开始** → 两条路：[黑马程序员：Python + AI 入门](黑马程序员-Python-AI/)从装环境讲起，是通用编程基础；[pink老师：AI + 前端入门](pink老师-AI前端入门/)从网页标签与样式讲起，能更快看到可见成果。有 Python 基础后，再按兴趣选 [NLP](黑马程序员-AI大模型NLP/)、[LangChain 应用开发](2026版LangChain教程/)、[大模型全栈（CS336）](Stanford-CS336-从头构建大语言模型/)、[计算机视觉（CS231N）](Stanford-CS231N-深度学习计算机视觉/)、[操作系统原理](南京大学-操作系统原理/)、[生成式软件工程](南京大学-生成式软件工程/)、[计算机网络](中科大计算机网络/)、[数据库（MySQL）](MySQL数据库入门到大牛/)或[微机原理](西电微机原理113讲/)方向。非计算机方向另有[高等数学](宋浩高等数学2.0版/)、[英语语法](英语语法精讲合集/)、[公考判断推理](公考逻辑判断推理/)与[变态心理学](北京大学-变态心理学/)。

## 三类产物怎么选

| 产物 | 在哪 | 粒度 | 什么时候用 |
| :--- | :--- | :--- | :--- |
| 模块合辑全书 | `<课程>/textbooks/` | 一册覆盖若干集 | 体系化通读、跨章节串联、打印装订 |

产物命名规则统一：`PXX_` 前缀对应原始分集编号，`模块XX_` 与 `笔记XX_` 是整编后的新编号，两者可用集号互相追溯。

> **关于单集精读长文**：它是本流程用于整编的**中间产物**，本仓库不再收录。需要按集精读时，按集号在 `textbooks/` 里定位它所在的模块即可——模块内仍按讲授顺序编排。

## 关于生成方式

本仓库内容全部由 [Video2Book](https://github.com/LINJIANG12/video2book) 生成：

1. 解析课程合集结构，用 ffmpeg 把每集音频提取为 16kHz 单声道切片
2. 逐集处理音频，按统一风格提示词写成单集精读长文（**中间产物，不随本仓库发布**）
3. 多集长文按知识体系切分成模块，整编为合辑教材；再跨模块归并成复习笔记
4. 交付前过一遍机器门禁，套话填充、空壳标题、分集平铺标题等问题会被拦下

逐字稿由听音通道产出：宿主本身具备音频模态时直接聆听切片，纯文本宿主则由配套的 [omni-media](https://github.com/LINJIANG12/omni-media) 交由外部模型代读。两条通道都要求「真正处理过本集音频」，不得跳过取音频直接编造正文。

想用自己的课程跑一遍，见 [Video2Book 仓库](https://github.com/LINJIANG12/video2book)；听音通道由配套的 [omni-media](https://github.com/LINJIANG12/omni-media) 提供。
