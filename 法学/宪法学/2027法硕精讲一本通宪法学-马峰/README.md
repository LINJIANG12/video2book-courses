# 2027 法硕《精讲一本通》宪法学（马峰）

众合马峰老师的法硕宪法学精讲。课程以「宪法是什么—如何制定修改—国家如何构成—公民有何权利—国家机构如何运转」为主线：先立宪法的概念、渊源与基本原则，再讲立法权限与法律规范体系，随后依次展开国家性质与基本经济制度、政权组织形式与选举制度、民族区域自治与政党制度、特别行政区与基层群众自治，最后落到公民权利义务与国家机构体系。

- **原视频**：https://www.bilibili.com/video/BV16r5j6JEMm — Bilibili，BV16r5j6JEMm
- **54 集**，已产出 13 册模块全书、19 篇复习笔记、57 份逐字稿

## 怎么学

- **立宪基础** → 模块 01~03 讲宪法的概念渊源、基本原则、宪法规范与制宪释宪修宪，是理解全课的前提
- **法律规范** → 模块 04~05 聚焦立法权限、规范体系与立法审查，注意与法理学、法律渊源划清分工
- **国家制度** → 模块 06~09 覆盖基本经济制度、政权组织形式、选举制度、政党与民族区域自治、特别行政区与基层自治
- **权利义务** → 模块 10 专讲公民基本权利与义务，是宪法的核心命题
- **国家机构** → 模块 11~13 讲人大制度、国家主席、国务院、中央军委、监察委员会与审判检察机关
- **专题回顾** → `notes/` 下的笔记按制度分篇，适合按专题快速串联
