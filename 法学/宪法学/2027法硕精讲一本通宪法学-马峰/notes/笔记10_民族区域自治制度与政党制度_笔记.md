# 民族区域自治制度与政党制度

## 民族区域自治的概念与特点

### 两个自治的结合

* **民族区域自治**
    * > **定义**：民族自治和区域自治的结合，同时是两个限定——民族被限定了区域，区域当中又划定了民族。
    * 不是纯粹的民族自治：纯粹的民族自治意味着该少数民族可以自主决定本民族的、或者说民族相关的所有问题，甚至可以选择独立地建立自己的民族国家。
    * 不是纯粹的区域自治：纯粹的区域自治意味着民族地方所有事务都可以不服从中央管理、完全由自己决定，包括在军事上、外交上都有自己的军事和外交管理权。
    * 民族地方在处理地方性事务上有一定自主性，但和主权相关的问题要服从中央的统一管理。
    * 双重限定的判断：汉族跑到新疆不能享受新疆的民族自治待遇，因为该区域中限定的民族是维吾尔族；维族同胞跑到山西也很难享受，因为他脱离了他所限定的区域。

### 三个特点与概念的互推

* **依法统一**
    * 正面：依照宪法和相关法律，在国家统一领导下进行自治。
    * 反面：不能各自为政、不能擅自设立。
* **聚居为基**
    * 正面：以少数民族聚居为基础。
    * 反面：不能在散居的区域设立，少数民族的人口要相对足够地集中。
    * "聚居式基础"要求自治地方中少数民族的人口比例达到相对集中的程度，不能只有一个少数民族就设一个自治地方，那会变成个人自治。
* **三个自治**
    * 建立自治地方、设立自治机关、行使自治权利，管理本民族内部的地方性事务。
* **概念的三个要点**
    * 在国家的统一领导下：尽管用了"自治"二字，仍是在国家统一领导下的自治，服从中央的统一管理，并没有改变中国作为单一制国家的整体国家结构形式。
    * 以少数民族聚居为基础。
    * 三个自治：既是民族相关的事务，也是地方性的事务。

| 聚居形态 | 例子 |
| :--- | :--- |
| 一个少数民族聚居 | 西藏自治区（藏族）、宁夏回族自治区（回族） |
| 两个或两个以上少数民族聚居 | 贵州黔东南苗族侗族自治州——苗族和侗族人口数也差不多，都达到了聚集状态 |
| 一个为主、多个为辅 | 新疆——人口最多的少数民族是维吾尔族，此外还有哈萨克族、蒙古族、回族等 |

> **结论**：三个特点合并起来就是概念；概念直接强调了"在国家统一领导下"，没强调"依照相关法律"，但国家统一领导是法治国家下的国家行为，守法没有疑问。概念是三点的合并，特点是三个点的展开，前两个方面各做正反两方面描述。这一知识点当多选题准备最合适，但因有热度，也不排除主观题，需要背诵。

## 民族区域自治制度的优越性

### 四个好

* **对整体好**
    * 民族区域自治保证了国家的整体利益和少数民族的具体利益高度结合，有利于国家统一领导。
    * 核心是整体和部分的关系：既满足整体的需要，也符合部分的利益，是两相结合。
    * 这句话体现了人民民主专政和民族平等，需要完整记忆。
* **聚居好、散居也好**
    * 聚居的少数民族通过划定自治地方、设立自治机关、行使自治权利，充分享受当家作主的权利（自治权）。
    * 散居在全国各地的少数民族权益也能得到保障：在非民族地方虽享受不到特殊的民族优惠和民族政策，但可以到本民族的自治地方去，那里能集中地、针对性地满足其民族需求和民族特点，可以作为大本营和依靠。
    * 对比：汉族不管跑到哪里都享受不到相应待遇。
* **对经济和文化的发展好**
    * 民族区域自治能够把行政区域和经济文化发展的区域结合起来，更好地因地因民族制宜，帮助少数民族地区发展经济文化事业。
    * 汉族地方与少数民族地方的发展程度客观上存在差异，在特定的民族地方集中进行政策倾斜、给予特殊优惠，能加快经济文化事业发展，缩小不同地方的发展差异，实现平衡发展。
* **对民族关系好**
    * 有利于各民族的团结和各民族的相互合作。
    * 民族关系的内容即平等、团结、互助、和谐。

### 局面的来之不易

* 作为大国来讲，面对的最大威胁往往并不在外部，而是在内部——民族纷争激化会让大国家在内部遭受动乱、付出巨大代价，甚至打断国家正常发展、使国运中断。
* 今天的和谐稳定民族关系是长期民族融合以及汉族与少数民族之间长期交流（物理交流和经济文化方面的交流整合）的结果，是来之不易的局面。
* 任何对民族分裂势力的支持、任何制造民族分裂的行为，都要与之坚决划清界限并坚决斗争——其目的是从根本上破坏国家当前的发展格局。

### 怀柔与重拳出击

* 怀柔政策：对少数民族地方的正当诉求积极回应，给予特别待遇来支持当地发展。
* 硬的一手：对想要制造民族分裂、想要分裂祖国的行动必须重拳出击。
* 历史依据：新疆和西藏历史上曾出现过以分裂国家为目的的极端暴恐事件，是付出惨痛代价后才吸收了这些经验，因此治安维护层面必须重拳出击。

## 民族自治地方

### 自治地方的三级

* **民族自治地方**
    * 中国民族自治地方有且只有三级：自治区、自治州、自治县。
    * 最低只到"县"这一级。
    * 三级分别对应汉族地方熟悉的省、市、县。

| 民族自治地方 | 对应汉地层级 |
| :--- | :--- |
| 自治区 | 相当于一个**省** |
| 自治州 | 相当于一个**地级市**（比省低一级，比县高一级） |
| 自治县 | 相当于一个普通的区或者县 |

### 不层层嵌套

* 区、州、县是划定的三个级别，不是"自治区—自治州—自治县"逐级套娃。
* 自治州可以在自治区底下（本质上就是个地级市），也可以在一般的省底下——贵州本身是省，黔东南地区苗族和侗族达到聚集状态就在这个省底下设自治州，与一般的市级别相当。
* 自治县可以在自治州底下，也可以在一般的地级市底下。
* 拉萨市、乌鲁木齐市、呼和浩特市都是普通的地级市，在自治区底下充当省会或首府。
* 关键是在级别上能够形成隶属关系。

```text
省级单位（省 / 自治区）
     ├── 自治州        ← 也可以是一般地级市
     └── 一般地级市
              └── 自治县  ← 也可以是一般区县

  只要当地少数民族达到聚居状态、有条件设立，
  就可以设。关键是级别上能形成隶属关系，
  而不是"自治区—自治州—自治县"逐级套娃。
```

### 民族乡不是自治地方

* 民族乡只是一个少数民族人口比较多的乡，不是自治地方——叫自治地方的话前头得有两个字"自治"。
* 除了少数民族人口比较多、管理上要注意符合一些少数民族的特点以外，其他层面和一般的乡没有任何区别，理解成普通地方即可。

## 民族自治机关

### 双重属性与范围

* **自治机关**
    * 双重属性：首先是一个地方的国家机关；同时它属于自治机关的这样一个序列。
    * 由此有两套权利：一般地方国家机关所享有的权利，加上民族地方自治机关所特有的自治权利。
    * 范围只有两个：人大和政府。
    * 民族地方的法院、检察院、监察委等其他国家机关都只能叫普通的地方国家机关，只有普通地方国家机关的权利，没有自治权利。
* 三个自治层层嵌套：自治权力是自治机关的权利，自治机关又是自治地方当中的特定的国家机关；不是自治机关的，与自治权利无关。

### 民族成分限定的职位

* **职位限定**
    * 人大方面：人大常委会的主任或副主任。
    * 政府方面：一把手，即自治区主席、自治州州长、自治县县长。
    * > **易错点**：为什么安排在常委会而不是人大——人大是个会，是临时性会议，没有固定职位可供安排，开会时间也非常短。说"人大开会期间你们可以本民族的人管理本民族的事，闭会以后就没关系了"很荒谬；只有安排在常委会的日常工作中才真有诚意。
* **民族成分要求**
    * 由实行区域自治的少数民族公民担任，不是随便搞一个少数民族就可以。
    * 该少数民族还必须在当地达到聚居状态，民族成分要与当地实行区域自治的少数民族成分形成匹配。

| 安排 | 有没有问题 | 为什么 |
| :--- | :--- | :--- |
| 新疆，人大常委会副主任是汉族人 | 没问题 | 主任或副主任有一个就行 |
| 新疆，人大常委会副主任也是维族人 | 没问题 | 两个都算超额完成任务——**划定的是下限** |
| 新疆维吾尔自治区**政府主席是汉族人** | **有问题** | 主席、州长、县长必须由实行区域自治的民族公民担任 |
| 新疆维吾尔自治区人大常委会主任是维族人、副主任是汉族人 | 没问题 | 主任本身已符合要求 |

### 地方自治民族的确定

* 自治地方的名称本身就标明实行区域自治的民族，如黔东南苗族侗族自治州、土家族自治州、回族自治区、蒙古族自治县，不必另外去记。
* "新疆维吾尔自治区"意味着在新疆这个大区域达到整体聚居状态的少数民族是维吾尔族，安排哈萨克族担任不成立。
* 哈萨克族同胞的办法：在自治区底下设立哈萨克族的自治州或自治县，让其在范围相对较小的自治州或自治县范围内达到区域自治状态。
* ⚠️ 由本民族的人管理本民族的事，才能了解当地民族情况和本民族的特殊需要，有针对性地实施民族特殊政策；民族不同则特点习惯不同、语言不通，什么都展开不了。

## 自治权利

### 反向记忆法

* **自治权利**
    * 自治权利是民族地方自治机关所享有的一种特殊权利，或者说是一个加引号的"特权"——民族政策非常优惠、非常优厚，所以这个"特权"的范围极大。
    * 整个民族区域自治法 80% 以上的内容是告诉你民族地方能干什么，不到 20% 的内容是不能干什么、受到什么限制。
    * 记忆方法：不记能干什么，只记不能干什么、受到什么限制；只要不是不能干的，反推其他的都是能干的。
    * 该方法偏选择题；自治权利若考必考简答题，答题规模就是一句话，但民族区域自治制度有热度，不能存侥幸心理，要全面复习。

### 六条限制

| # | 领域 | 自主的内容 | 限制 |
| :--- | :--- | :--- | :--- |
| 1 | 立法 | 制定自治条例和单行条例，变通上位法 | **宪民基专不得变** |
| 2 | 行政管理（执法） | 变通上级发布的命令和政策 | **须报上级批准；上级 60 天内答复，逾期未答复视为默许** |
| 3 | 财政税收 | 自主管理本地方的财政收入 | **自治州、自治县减税须报省级政府批准** |
| 4 | 经济建设 | 自主安排本地区经济发展计划和项目 | **边境贸易、开辟贸易口岸须经国务院批准** |
| 5 | 教科文卫 | 发展具有民族特色的教科文卫事业 | **国际交流仅自治区、自治州可以，自治县无对外交流权** |
| 6 | 公安 | 组建公安部队 | **须经国务院批准** |

* **立法**
    * 自治条例和单行条例的变通限制是"宪民基专不得变"：只要不涉及宪法、民族区域自治法的基本原则和专门规定，通通都可以变通、实行不一样的政策。
    * 自治条例和单行条例本身需要经过批准。
* **行政管理（执法）**
    * 变通出现在两个机关、两种要求：人大是立法机关，立法层面有变通权；政府是行政机关、执行机关，变通在行政管理、执行或执法层面，须经上级国家机关批准。
    * 上级机关的批准时间是 60 天，60 天内给予答复。
    * 视为默许的理由：凡需上级批准才能干的事，法定时间不作答复即不作为，不作为已经影响到别人享受其应享受的权利，属错上加错。
* **财政税收**
    * 地方财政税收都归民族地方自己使用，中央不拿你的钱；不够花时中央还可能进行财政方面的转移支付。
    * 在国家统一税收减免政策之外还要再单独减免税收，自治州和自治县必须经省级政府批准；这里的"省"指省、自治区、直辖市，不一定是自治区。
* **经济建设**
    * 与外国接壤的边境民族地方包括内蒙、新疆、西藏，也包括云南的一些自治县和自治州、贵州的边境地区。
    * 单一制国家中地方与国外交往活动受严格限制，因为国际社会当中只有一个中国，能够代表中国立场和态度的只有中央政府。
* **教科文卫**
    * 国际交流除级别要求外还有领域要求——仅限于教科文卫方面，军事、政治方面当然不可以，否则就是里通外国。
* **公安**
    * 说的是组建单独的公安部队，不叫组织军队：公安对内维持稳定，军队对外，民族地方不可能有军队，组织军队会造成国家割据分裂。
    * 警力配置可以人员多一点、装备可以好一点，涉及武装力量问题，所以必须经国务院批准。

### 语言文字与可反推事项

* **语言文字**
    * 语言文字没有什么限制：民族地方能够优先使用本地区的语言文字。
    * 优先使用当地语言文字或者说当地的通用语言，除普通话以外也必须有当地少数民族通用的语言文字，这是保留本民族文化遗产的重要部分。
* **只要不涉及六条限制就可以做的事**
    * 优先开发本地的自然资源。
    * 享受高考教育加分。
    * 享受国内的财政优惠、财政补贴。
    * 举办具有民族特色的运动会，比如内蒙古的摔跤、赛马、那达慕。

### 二次反推

* 反推方法：既然限制是"不能做的"，那再反着说过来就是正面能做的。
* 领域口诀：立法行政、财政经济、文教公安，最后加上少数民族永远不言自明的基本权利语言文字；各项都可以加"自主"二字。

| 限制 | 二次反推 |
| :--- | :--- |
| 宪民基专不得变 | 可以制定自治条例、单行条例对上位法进行变通 |
| 变通批准 60 天 | 可以变通上级国家机关的命令和政策 |
| 州县减税省政府 | 可以自主管理本地区的财政收入 |
| 边贸口岸国务院 | 可以自主安排本地区的经济建设规划、经济发展计划 |
| 不交流自治县 | 可以自主发展/管理本地区具有民族特色的教科文卫事业 |
| 公安批准国务院 | 可以组建公安部队 |
| （无限制） | 优先使用本地区的语言文字 |

## 民族自治法规

### 自治条例与单行条例

* 民族地方制定的、涉及区域自治的规范性文件只有两类：自治条例和单行条例，一般统称"民族自治法规"。
* 二者都是行使变通权的结果，都体现民族区域自治当中的"自治"要素——与一般地方不一样，它们都有变通权。
* **自治条例**是对自治权的综合性运用，变通是综合性的变通，不是针对某一个领域，而是涉及一个基本原则、一个总体规划。
* **单行条例**是在某一个特定领域、特定方面行使变通权的结果。
* 可类比法理学的一般法与特别法关系：一般变通对应自治条例，针对特定事项的变通对应单行条例。
* 涉及基本原则、机构设置、自治机关职权的规范性文件属于综合性范畴，只能叫自治条例；单行条例往往会点明所针对的具体领域或具体问题。

### 立法现状

* 不管自治条例还是单行条例，都需要经过批准。
* 自治区层面会有很多单行条例：针对语言文字方面、特殊的民族习惯、经济层面、科技发展层面、文化发展层面都有相应规定。
* 自治区这一级的综合性自治条例至今没有获批过。
* 新疆曾报出一个关于本地方综合变通的自治条例，报到全国人大后被直接打回——内容形同独立宣言。
* 后来改为让内蒙古先做，理由是内蒙古自治区的建立早于新中国，其政治素养可靠；内蒙古报出的自治条例同样未获批。

## 政党

### 概念定义

* **政党**
    * > **定义**：政党，是指一定阶级或者阶层的先进分子组成、以控制或者夺取国家政权为政治目的、有严密的组织体系和严格的组织纪律的、现代国家政治活动的中心力量。
* "中心力量"指现代国家的政治活动都是依托于政党、或者说以政党的名义来进行的，而不是政治家单打独斗、单枪匹马地进行政治活动。
* 政党的成立是为了适应现代民主政治活动的需求而设立的。
* 概念与特征是总分关系：概念一拆分就变成特征，特征的要素一归拢就合成概念。

### 四个特征

* **阶级性**
    * 政党是一定的阶级或者阶层的先进分子组成，代表了一定的阶级或者说阶级当中的一个特定群体的利益，反映特定阶级或者阶层的利益诉求。
    * 中国共产党首先是中国工人阶级的先锋队，代表工人阶级、体现工人阶级的意志；它也是中华民族的先锋队，但首先是工人阶级的政党。
    * 美国的民主党和共和党都代表资产阶级，反映的是资产阶级当中不同倾向、不同群体的倾向（民主党偏左、共和党偏右），本质上都在反映资产阶级的意志。
* **政治性**
    * 政党是以控制、夺取或者影响国家政权运作为目的的，具有政治性。
    * 控制国家政权就变成执政党；参与国家政权建设就是参政党；夺取国家政权就是反对党或者说革命党。
* **组织性**
    * 政党有非常严密的组织系统，有最基层的党组织，也有上层和中层的党组织。
    * 中国共产党从党中央到最基层党支部，组织体系甚至比国家机关的组织系统还复杂——国家机关最低只到乡一级，村里没有国家机关只有基层群众自治组织，但村里和城市社区里都有党支部。
    * 学校里有党委、分党委、院党委或党支部，研究生阶段的班级里也会设党支部。
* **纪律性**
    * 有严格的组织纪律来约束党员或者党组织的行动。
    * 法治思想核心要义中的"依规治党"，其"规"指的就是党内法规，确立了严格的党组织的纪律。

### 起源

* 现代政治这套整体的规则起源于英国，因为英国是世界上最早的宪政国家。
* 政党源于英国、源于英国的议会斗争，议会当中的议员组团斗争形成了所谓的政党。
* 世界上最早的政党是英国议会斗争过程中所形成的辉格党和托利党。

## 中国共产党领导下的多党合作和政治协商制度

### 制度入宪与对民主党派的方针

* 制度全称：中国共产党领导下的多党合作和政治协商制度。
* 1993 年在宪法中明确。
* 中国共产党对民主党派的政策是十六个字：长期共存、互相监督、肝胆相照、荣辱与共。
* 这十六个字不会考主观题，但客观题考到要能答出。

### 三个是什么与一个不是什么

* 共产党是什么：执政党，居于领导地位。
* 民主党派是什么：参政党，功能是参政议政，参与国家政权建设。
* 双方合作协商的组织形式是什么：中国人民政治协商会议。
* 双方的关系不是什么：不是执政党与反对党的关系，不存在轮流执政，民主党派主要发挥监督功能。
* 反向强调的理由："多党合作""政治协商"表达的是我党对民主党派的友好态度；若对方要反对、要取而代之，双方就成了敌对关系，而政治上有敌对关系就必须进行政治斗争，就没有合作基础了。

### 政治领导的属性

* 多党合作和政治协商制度的前提是民主党派必须接受和坚持中国共产党的领导，这是该制度的基础与核心。
* 党的领导是政治领导，即政治路线、政治方针和政治政策的领导，是方向上的领导。
* ⚠️ 它不是组织和人事上的领导：共产党有共产党的党中央，民主党派有民主党派的党中央；各有各的党支部、各有各的党员。若组织和人事上也存在领导关系，党的党组织就变成民主党组织的上级、党的领导人变成民主党派的领导人、共产党员变成民主党派的党员——那就不成其为一个党了，也就不能再"多党"。

### 民主党派的地位与权利

* 民主党派也是政党，有自己的政治追求和政治目标，只是这种追求和目标不会和共产党的政治方向相抵触。
* 在法律范围内，民主党派与党具有组织上的独立，也有法律范围内的政治自由。
* 法律地位上双方平等——都是社团概念；政治地位上不同——党居于领导地位、居于执政地位。

## 中国人民政治协商会议

### 双组织属性

* **中国人民政治协商会议**
    * 政协是个"双组织"：既是爱国统一战线的组织形式，也是多党合作政治协商的组织形式。
    * 政协不是国家机关，也不能等同于一般的人民团体——它的政治影响力比一般人民团体大得多。

### 没有公权力

* 政协在国家政治活动当中有非常重要的政治影响力，但没有公权力。
* 没有公权力的理由一：基于人民主权，行使人民赋予的公权力必须是被人民选择或被人民选举的产物。民主党派不是人民选择的——中国人民选择的是中国共产党，所以是党才有公权力。
* 没有公权力的理由二：政协委员不是人民选举的产物，而是推荐、协商的产物，没有经过正式的选举程序。人民选举的是人大，人大才能行使公权力。
* 政协既不是被人民选举的，也不是由人大产生的：政协在 1949 年建国之前就已存在（当年有《共同纲领》），而人大始建于 1954 年一届人大一次会议，存在时间比人大还早，不可能是人大产生的。
* 结论：人民选择了共产党，所以共产党才是执政党；人民选举了人大，所以人大才是国家权力机关；政协只是一个能够参与国家政治活动的政治组织。

### 影响力指向

* 政党通过政协和民主党派展开合作协商，能够影响到党的决策。
* 人大开会时政协同时开会，政协委员还可以列席人大会议，参与人大所议事项的讨论，从而影响到人大的决策。
* 政协的政治影响力主要影响那些有权力的机关。

### 三项功能

* 政协的功能概括为 12 个字：政治协商、民主监督、参政议政。
* 政治协商——有事商量。
* 民主监督——监督国家机关、监督执政党。
* 参政议政——在国家大政方针上参与讨论，然后提供自己的意见。
* 核心是重在参与，永远参与，但没法直接作出具有法律效力的决定，因为作出这种决定是执政党和国家机关才有的权利。
* 通俗版的"三陪"：陪开会（列席会议）、陪讨论（发言、提供意见）、陪视察（到国家机关视察工作时陪同）。
* "三陪"的核心是"陪"——不是提供或发挥自己的影响力，但没法直接行使公权力。
