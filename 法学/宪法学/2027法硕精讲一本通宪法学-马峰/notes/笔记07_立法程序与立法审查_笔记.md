# 立法程序与立法审查

## 立法程序的三大原则

### 务实原则

* **立法规划**

    * > **定义**：确保立法活动有序开展的一个非常重要的要求，就是关于立法的一个**计划**。

    * 一届全国人大任期 5 年，全国人大和全国人大常委会都是 5 年任期；这 5 年中今年立什么法、明年立什么法要有总体安排，不能脚踩西瓜皮滑到哪里算哪里。

    * 立法规划能让立法节奏稳定，立法计划还要**面向社会公开**，一定程度保障民众对立法机关活动的知情权。

    * 层级可涵盖 5 年完整人大任期，可具体到某一年的**年度立法规划**，也可具体到某一专业领域或方向的**专项立法规划**。

    * > **结论**：对法律人来讲，最好的励志方法就是立法规划——看看今年考不过、明年有多少部新法要出来，复习量有多大。

* **论证会与听证会**

    * 专业性较强的法律案要召开论证会，可以吸收或者委托相关领域的专家来起草法律草案。

    * 立法过程中有两个会是碰到以后**应当开**的：论证会、听证会。

    | | 论证会 | 听证会 |
    | :--- | :--- | :--- |
    | 解决什么问题 | 专业技术难题 | 关系重大的公共利益问题 |
    | 难还是大 | 难事 | 大事 |
    | 面向谁开 | 专家、学者 | 社会公众 |
    | 保障什么 | 科学性 | 民主性 |

    * **论证会**解决专业技术难题，为保障法案制定的**科学性**，有时还让专家直接参与法律草案的**起草**。

    * **听证会**解决的不是专业技术难题，它是个**大事**——专业上难度很有限但影响范围很大，会影响老百姓切身利益；既然影响公众利益，就得听社会公众或民意代表的意见。

    * 例：自来水公司把水价从五块一吨提到八块一吨，数字改起来小学生都能搞定，但不能直接改，因为它影响老百姓的钱袋子。

    * > **结论**：**难事论证，大事听证**，这两个会是应当开的。

* **立法评估**

    * 立法评估分**事前评估**与**事后评估**，二者针对的事不一样：事前评估针对**可行性**，事后评估针对**实施效果**。

    * > **结论**：论证会、听证会是"应当开"，评估则是**可以**搞的。

    * 全国人大、全国常委会的法律成百上千，若每部法律事前都搞可行性评估、事后都搞效果评估，全国人大、全国常委会就天天搞评估、什么都耽误了。

    * 针对全国范围立法搞一次评估，所耗时间、精力、人力物力超乎想象；没有成百上千人的专家团队分散在全国各地、经过半年到一年以上反复搜集数据、论证、数据核验，拿不出真正翔实且有意义的评估报告，拿出来也是想当然、纸上谈兵。

    * > **结论**：评估只针对有必要的才可展开；立法的条件肉眼可见地成熟，或法律实施的效果肉眼可见地好、肉眼可见地坏，就没必要非得搞评估。**应当开会、应当论证、应当听证；但是评估是可以搞的。**

* 法律条文应当**明确具体、具有可操作性**，即内容上要能落地、能执行；这一条主要表达理念，了解即可。

### 民主原则

* 法案要体现民意，落点有三个：面向社会公众开放的**听证会**、**草案的公开**、**基层立法联系点**。

* > **易错点**：作为专家去开会，你参加的是**论证会**，不能跑到听证会去。

    * 听证会听的是老百姓的意见；没有做过真正的调研、没有被民众所选举或推举，就没有资格代表民众。

    * 专家社会形象不佳，很重要的原因就是开会时**去错了地方**——本该去论证会却跑去听证会，不了解民众实际诉求又随意发言。

    * 能发挥作用的领域是**专业技术领域**，不是听证会所面向的重大事项问题。

* **草案公开三十天**

    * 法律草案原则上要向社会公布，征求意见时间**不少于 30 天**，但**委员长会议决定不公开的除外**。

    * 这是**草案公开**而不是法律公开——草案能不能正式通过还得打上问号，但现在就要求草案公开。

    * 公开后民众有较集中的意见，直接在立法过程当中就改掉，不必等到它成为法律；这体现**全过程民主**。

    * 公开吸收民众意见有**时间的下限**即 30 天，保障时间充裕。

    * > **易错点**：公开是原则，但委员长会议有例外，决定不公开就不公开。

* **基层立法联系点**

    * 全国人大常委会的工作机构可以根据实际需要——主要是法工委——设立**基层立法联系点**，深入推进基层群众有关法律草案和立法工作意见。

    * > **定义**：能够搜集到民众意见的这个实体组织，就叫基层立法联系点。

    * 听取老百姓的意见、接受民众意见不只是立法过程当中才做的事，它是**常态化的**，并由一个**实体的组织**来保障。

    * 不单全国人大有，省人大常委会、市人大常委会也有，往往共用一个基层立法联系点，一般就设在各地人大常委会的办公地点，专门有一个办公室。

    * > **结论**：这就是民主性原则的制度保障；基层立法联系点是 2023 年才提出的要求，推广铺开需要时间，但未来都会有。

### 合法性原则

* 立法工作要**严格依照法律规定的权限、步骤、次序来展开**；本身比较虚，最核心的体现是前面已总结过的立法原则制度设计。

## 人大系统的工作套路

### 三四五

* > **结论**：说到人大系统，要记住 **345 问题**——**五级人大、四级常委（专委）、三级秘书长**。

    * 人大是五级：国、省、市、县、乡；

    * 常委会是四级：国、省、市、县，**乡没有常委会**；

    * 秘书长只有三级：国、省、市，只在市一级以上才有。

* 政府当中也是一样的套路。

### 值班的值班的

* 人大开会的时间也不过七天（原来是半个月，疫情之后这两年基本等于七天、一星期），地方人大的时间只会更短；一年当中绝大多数时间人大处于休眠或闭会期间。

* > **结论**：**人歇，事不能歇**。人大闭会要有给他**值班的**组织，叫**常委会**，作为常设机构替他处理日常工作。

* 但常委会在本质上**还是个会**——省人大常委会、市人大常委会、县人大常委会，一年开六次、俩月一次，总有闭会的时候。

* > **定义**：**值班的值班的**是在常委会闭会期间给常委会处理各种日常工作的机构，中央叫**委员长会议**；地方不叫委员长会议，叫**主任会议**（名儿有梯度，干的事和定位一样），是小规模会议，有各种突发情况可随时开会。

* > **结论**：说"人大不干活"的道理就在这儿——人大一年当中绝大多数时间都是闭会期间，常委会不开会时就由委员长会议或主任会议处理。

### 主席团

* 人大开会期间工作时间有限、非常宝贵，必须有一个**组织者**安排各项会议议程、组织代表。

    * 例：山东、河南、河北代表团讨论什么，广东、广西代表团、福建代表团讨论什么，得有组织者把任务有序分派。

    * > **结论**：这个组织者叫**主席团**；在人大开会期间，是主席团在集中地安排和处理各项工作。

    * 名义上是干活，实际上他说了算，那叫**管事**——一个机关当中最重要的权利就是这个机关各项工作的**安排和指挥权**。

    * > **结论**：什么叫领导？**领导就是指挥权、部署权、安排权**。

* 实践中这些人是同一套人，但**身份和名义**不同：人大开会期间是主席团，闭会期间是常委会，常委会再闭会期间是委员长会议或主任会议；委员会长会议成员**天然是主席团成员**。

* **乡人大**：开会期间是**主席团**；闭会以后没有常委会，**主席团继续存在**，开会是它、闭会也是它；主席团扛不住时交给**主席、副主席**（乡一级有常设个人），从性质上与上面一模一样，只是架构更简单。

* > **结论**：这就明白了**委员长会议说不公开就不公开**的原因——因为它说了算。

## 全国人大的审议

### 会前一个月

* 开会讨论的法律案，要在**举行会议前一个月**发给代表听，让代表事前做准备；如果有比较集中的意见，甚至可以提前开一个**研讨会**来听取代表意见。

* > **结论**：**你不能用草案来偷袭代表**。草案不能当场给，当场给谁都反应不过来；民法典一千多条、生态环境法典规模还更大，上午给、下午就要提意见甚至表决，神仙也提不出来。

* 常委会这边也要提前把草案发给委员，只不过**提前七天、一星期**就够，发给他们的目的是让他们做好准备，有时还可提前让他们反馈意见。

* > **结论**：**人大一个月，人常一星期。**

* 提案主体很多，有国家机关提案，也有代表或委员个人联合提案；这两类具体主体放到**人大的职权**中去背。

* > **提示**：复习节奏混乱是很多人没能坚持到最后的主因——前期如狼似虎，后期像泄了气的皮球；总体复习效果是**马拉松赛跑**，百米冲刺跑不完全程，跑到终点才重要。

### 开会五步

* **第一步，听取提案人的说明**：让提案人做**提案说明**，讲清为什么要制定这个法、有什么意义、条件是否成熟。

    * > **提示**：不要小看提案说明，它是集中表达立法者制定该法基本意图和目的的内容，是非常重要的**立法资料**；做**主观目的解释（立法者目的解释）**时要分析立法资料，典型的就是提案说明。

* **第二、第三步：两个讨论同步展开**。

    * 第一个讨论：草案交给**各个代表团**审议（山西、山东、河南河北、广东广西、湖南湖北等），代表团代表全国各地人民反映意见。

        * > **结论**：代表团审议说白了就是在**变相搜集全国人民的意见**，主要保障法案的**民主性**。

    * 第二个讨论：交给**各个专门委员会**审议。专委会最大的特点是一个字——**专**，在某一专业领域有自己的专业特长。

        * > **结论**：专委会的讨论主要不是保障民主性，而是保障法案的**专业性、科学性**；科学立法、民主立法贯穿立法工作始终。

* **第四步，搜集意见**：由**宪法和法律委员会**搜集各代表团和其他各专委会的意见，并根据意见给出针对草案的**修改稿**和**审议报告**。

    * 审议报告重点解决的是**各方的分歧和所谓的合宪性问题**。

    * > **结论**：这就体现了对草案的**合宪性控制**——**合宪性审查不是说在法案出台之后才开始，也不是生效之前才开始，而是在立法过程当中、针对草案就已经开始了**，从源头上避免违宪。

* **第五步，形成表决稿**：意见全部搜集完后形成**表决稿**，不叫修改稿了，就是正式上会举手表决的最终修改成果。

* > **结论**：修改稿、表决稿、审议报告在这个过程中都由**宪法和法律委员会**提供，尤其是审议报告重点解决合宪性问题。

### 撤回与授权

* 表决之前提案人突然说想撤回，可不可以？

    * 你前头红口白牙说这个法特别重要，我把它交给代表团、交给专委会审议，宪法和法律委员会搜集意见、给出审议报告、修改稿、表决稿，马上要表决了你要撤回——这是浪费全国人大的时间。

    * > **结论**：**凡事不是你想撤就能撤的，你想撤得经过同意。**人大这边经过**管事的**即**主席团**同意；常委会这边经过**委员长会议**同意。

* 审议过程中出现**重大问题需要进一步研究**（问题分歧比较大，或有些意见很重要一时半会儿说不清楚），经主席团提出、由大会全体会议决定，**可以授权给常委会**根据代表的意见进一步审议、做决定。

    * 要么让常委会先做决定然后报告，要么让常委会拿个方案，下次人大开会时再做决定。

    * > **结论**：人大开会时间很宝贵，不能因为一个法案久拖不决；常委会在闭会期间值班、有充分时间做评估，下次人大开会时报告一下即可。

## 常委会的审议

### 提前七天与列席

* 正式开会前一般要**提前七天**把草案发给常委会组成人员——人大提前一个月，常委会提前一星期。

* 常委会审议法律案时**应当邀请有关的全国人大代表列席会议**；法案与某些代表的身份、地区或专业特长有关联时可以叫来列席发表意见。

* > **易错点**：**列席**与**出席**不是一回事。

    * **出席**：你是这个机关的组成人员，本单位开会，名正言顺地去，最后表决时可以举手投票。

    * **列席**：不是本单位开会，你以外人身份到其他单位去，能参与讨论、发表意见，但**不能举手投票**。

    * 到本单位开会叫出席，到外单位开会叫列席；人大代表到人大开会叫出席，到常委会去开会叫列席。

### 三读

* 常委会讨论某个法案，一般要**全体会议讨论**才能提交常委会表决，即三次全体会议讨论；第一读是第一次讨论，二读第二次，三读第三次，往往意味着第三读以后就可以提交表决。

* > **易错点**：这个"三读"是**开会讨论三次**的意思，**不是念三遍的意思**。

* **第一读**：听取提案人的说明，然后常委会分组会议进行讨论，产生意见交给**宪法和法律委员会**。

* **第二读**：宪法和法律委员会根据各种意见提出针对草案的**修改稿**并作汇报，修改完再交给常委会成员进一步讨论。

* **第三读**：讨论宪法和法律委员会给出的**审议报告**，有修改稿的再次讨论修改稿，最终由它来做**表决稿**。

* > **结论**：不管人大还是人常立法过程，有意见就都移交给、反馈给**宪法和法律委员会**，因为审议报告、修改稿、表决稿都是它提供的；这个委员会的成员基本能代表中国法律领域最专业的意见。

* 撤回同样不是想撤就能撤，常委会这边要经过**委员长会议**同意。

* > **结论**：三读也不是铁板一块——各方意见比较一致、没有特别大分歧可以**两读**；意见特别一致或立法紧迫情况特别紧急可以**一读**；但**最少也得一读**，不能连会都不开直接表决，立法工作不能儿戏。

### 三种表决

* **一般表决**：人大开会期间，或常委会由委员长会议交给全体代表、全体委员去表决，是常规的、一般的表决。

* **单独表决**：交付常委会会议表决前，**委员长会议**可以决定将**个别意见分歧大的重要条款**单独表决。

    * 针对的是**重要且分歧大**的个别条款；多数情况是全部条款中绝大多数是"大路货"没有分歧，争议焦点聚焦在一到两条，牵一发而动全身。

    * 单独表决就是在**试水**——针对分歧较大的个别条款预先表决一次摸摸底；分歧能解决，整部法律肯定能过，继续往前推；分歧没解决，整部法律没必要往前推了。

    * 例：修改个人所得税法，争议焦点一定是**税率**和**起征点**；税由谁征收、何时征收、税收未来交给谁集中处理使用都没争议。

* **合并表决**：对于多部法律中涉及同类事项的个别条款要修改的，得一并提出法律案，经常委会**委员长会议**决定可以**合并表决**，当然也可以分别表决。

    * 法律是成体系的，改 A 就得一并改相关的 B、C、D，否则相当于人为制造了它与法律体系内部其他法律的冲突。

    * > **结论**：合并表决就是**打包表决**，主要是为了提高表决**效率**，不用表决四次，一次搞定。

* > **易错点**：单独表决与合并表决法条上都是**可以**不是应当，委员长会议说可以就可以；看到"委员长会议"就意味着这事儿发生在**常委会**当中——**这两种灵活的、特殊的表决形式只发生在常委会当中；人大当中只有一般表决。**

### 暂不交付表决

* 单独表决条款经常委会会议表决后，**委员长会议**根据表决情况可以交付表决，也可以决定**暂不交付表决**，交给宪法和法律委员会、有关的专委会进一步审议研究。

* > **结论**：暂不交付表决就是在单独表决之后**没有继续推进表决、把表决稿压下来**了，试水失败意味着分歧没有解决；把表决稿压下来后交给宪法和法律委员会和有关专委会进一步研究，取得一致意见就继续往前推进交付表决。

## 终止审议

* 列入常委会议程的法律案，出现三种情形之一，**委员长会议**可以决定**终止审议**并向常委会作报告，也可以决定**延期审议**：

    * 各方对制定该法律的**必要性、可行性等重大问题有较大的意见分歧**；

    * **搁置满两年**；

    * **单独表决条款试水失败后暂不交付表决满两年**，没有再次列入到常委会议程的。

* > **结论**：一个草案在常委会当中也有**保质期**，两年都没有继续推进、没有正式成为法律，这个法案就终止了；两年都没搞定就交给下届人大常委会继续解决，这届常委会不会再为它浪费时间。

* 定为两年是因为人大常委会任期是**五年**，两年已接近过半任期，且不可能任期第一天就接触到这个草案。

* > **易错点**：**中止**和**终止**不一样——**中止是暂停**的意思，**终止是 over 了、结束了、终结了**；看到"终"是**终结的"终"**。

* > **结论**：**两年可终止，可以终止，必要时延长。**谁说"必要"？常委会当中的当家人**委员长会议**说了算。

## 通过与公布

### 通过与公布方式

* **宪法修正案**：绝对多数，**三分之二以上**。

* **法律**：相对多数；再次强调相对多数是**过半数**，而**不是二分之一以上**。

* **法律**由**国家主席签署主席令**公布；**宪法修正案**由**全国人大主席团发布全国人大公告**公布。

* 口诀：**法律主席相对多，宪法主席团绝对多。**

### 公布对象

* 不单公布已经通过的法律法规，一些非常重要的**立法资料**也要公布：人大、人常开会时听取的**提案说明**，以及**宪法和法律委员会**针对草案给出的**审议报告**（修改稿、表决稿、审议报告中的审议报告）。

* 这些内容公开意义很大：参考提案说明和审议报告，**能够让我们正确理解立法机关的立法意图**，是做**主观目的解释或立法者目的解释**时必须参考的立法资料。

### 公布渠道

* 三个渠道覆盖线上线下、体制内体制外：

    ```text
       公布渠道（三条）

       1) 机关公报 —— 本机关自己办的，权威性最高
            全国人大常委会公报 / 国务院公报 / 地方政府公报

       2) 普通报纸
            中央立法 -> 全国大报
                        （民法典、刑法典 -> 人民日报、光明日报）
            地方立法 -> 地方小报
                        （河南省地方性法规 -> 河南日报、大河报）
                        （郑州市规章       -> 郑州日报、郑州晚报）

       3) 官方网站
            人大系统 -> 中国人大网
                        （全国人大常委会的法律、
                          河南省人大常委会的地方性法规）
            政府系统 -> 中国政府法制信息网（法制网）
                        （国务院的行政法规）

       三个渠道口径不一致怎么办？
            -> 机关公报才是标准文本
            -> 口诀：文件报网，公报为准
    ```

* **渠道一，本机关的机关公报**：全国人大常委会有公报、国务院有公报、地方政府有地方政府公报；通过的法律法规和相关文件首先要在本机关的公报上公布。机关公报很权威，但一般人对它不感兴趣。

* **渠道二，普通报纸**：分为**地方小报**和**全国大报**，选哪一种不随便选，关键看法律文件的层级或生效范围。

    * **中央立法**全国有效，要约束全国人民，**上全国大报**，如民法典、刑法典上人民日报、光明日报。

    * **地方性立法**只在地方有效，没必要浪费公共资源让全国人民都知道，**上地方小报**，如河南省地方性法规上河南日报、大河报。

    * 再往下，**郑州市的规章**连全省的都没必要上，上郑州日报、郑州晚报这种本地报纸。

* **渠道三，官方网站**：纸质媒体衰落，普通人了解信息多数通过网络，公开渠道要与时俱进。

    * **人大系统**对应**中国人大网**；**政府系统**对应**中国政府法制信息网**（法制网）。

    * 国务院的行政法规上法制网；全国人大常委会的法律、河南省人大常委会的地方性法规上中国人大网；这两个网站是官方授权的公布渠道。

    * > **提示**：很多平台发布法律时标注"转载"，转载的就是这两个网站。

* 三个渠道口径不一致即公布的法律法规**在文本上有差异**时，权威性最高的是**本机关自己办的公报**。

* > **结论**：概括为八个字——**文件报网，公报为准**。文件指法律法规连同伴随的**提案说明和审议报告**都要同步公开；报网指在**报纸**和**官方网站**上都要公布；公报为准指不同渠道版本不一致时**机关公报才是标准文本**。

* > **结论**：法律当然要尊重民意、体现民主精神，但**舆论和所谓的民意是摇摆的**，法律中的意见和要求是经过严谨科学的立法程序才出台的，才是民意的结晶、才是稳定的民意；**法律本身就是最大的民意，法律也不应该被舆论所裹挟、所绑架**。

## 备案

### 普通备案与变通备案

* **备案**

    * > **定义**：就是通知。下级立法机关制定法律文件后，把它通知给上级；下位法制定完成后报备给上级，把法案原封不动报上去没什么特别考点。

* **重要的特殊的备案**：针对有变通权的地方立法或下位法，它们报备时**不单要报制定的法律文件，同时还要对变通情况作出单独的解释和说明**——为什么和上级不一样、为什么变通，对变通的**必要性、合理性**专门作出说明，让上级核验或检查。

    * > **结论**：不能滥用上级对你的信任，要让上级针对变通部分去检查。

    * 特殊备案针对的是**有变通权的下位法**，也就是可以明目张胆跟中央立法不一致的地方立法；当代中国就两类：**自治条例、单行条例**，以及**三区法规**。

## 立法审查

### 事前审查与事后审查

* **立法审查**

    * > **定义**：把所有有**权利**或者有**职责**的国家机关全都纳入其中——针对下级立法机关所发布的法律文件；中国虽以全国人大为主，但所有国家机关包括地方国家机关都意味着必须保障**下位法的合宪性**。

* **事前审查**：下级立法机关制定了法律文件，在**制定完成、但生效之前**由上级介入审查，发现问题干脆不批准生效，没问题才放行。

    * 通俗讲是"**我不让你先斩后奏**"——对下级信任程度相对低，我先看看，你说没问题你再生效；本质是**批准制**。

* **事后审查**：针对**已经生效**的法律文件，等出问题再纠正；通俗讲是**允许先斩后奏**，默认信任程度高、出问题概率低，但事后出问题再纠正。

* > **结论**：核心区别就一句话——**一个是不让先斩后奏，一个是允许先斩后奏**，体现上级对下级信任程度不同。

* > **结论**：领导不会太放心的是两类下属——**经验不足、能力太次**的，和**能力很强、独立性太强**（容易闯祸、容易架空上级）的；这两类都需要**严格的事前把关**。

### 事前审查只盯两类

* 虽条文上列了四类，实际上就两类：

    * **第一类，地级市的法规——能力太次**。地级市是中国常规状态下级别最低的立法主体，上级已明确它只能规定小事和杂事（五项"城乡生态历史基"），小事杂事也还要先经上级批准才能生效。

    * **第二类，所有的自治条例和单行条例——自治区、自治州、自治县通通囊括**。它们有**变通权**，除了"宪民基专"其他都能变，范围比三区法规（主要在经贸层面）大得多，权利太大必须严格把控，否则就把上级架空、严重破坏法制统一。

* > **易错点**：就两类——要么是**地级市的法规**，听清楚了，是**市法规，没有规章**。不管规章是因为规章往往是**执行地级市法规**的，把法规控制好了规章自然就得到控制。

* **批准的规律**：

    * 地级市的地方性法规由地级市人大、人大常委会发布，需经**省人大常委会**批准——市到省，提**一级**。

    * **自治区**（省一级）的自治条例、单行条例需经**全国人大**批准——省到全国，提**一级**。

    * **自治州**（地级市一级）的自治条例、单行条例提**一级**。

    * **自治县**（县一级）往上提，**不是**提到地级市，而是提到**省、自治区、直辖市**，提**两级**。

* > **结论**：规律是——**区、州、市提一级，自治县提两级**；不管提一级还是两级，都是提到**人常**去批，不是提到人大去批；原因是**人大不干活**，一年只开一次会，会期间还有别的工作要处理。

* **自治县为什么提两级**：只提一级就相当于提到自治州或地级市，但**地级市里头不一定是自治的**；地级市一级的人大常委会本身就不被信任，它自己搞的法规还需要被批准，自己都还需要被批准有什么资格去批别人——相当于两个小朋友，五岁的还要被爸爸妈妈照顾，又怎么可能照顾弟弟妹妹。

* > **结论**：事前审查只看**合法性**，有没有和上位法相矛盾，**没有触及合不合理**的问题。

    * 因为合不合理要结合**实施效果**才能评估，而这玩意还没生效、没实施，**不具备评估合理性的前提**；这是统一规律。

### 批准当自己

* 经事前批准已生效的法律文件，事后发现有问题、其实不应该批准生效、应该被纠正的，**当初批准它生效的那个主体脱不了干系**。

    * 河南省人大常委会批准时完全有可能批错了，人非圣贤孰能无过；事前只看了合法性，生效后也可能发现它本身不合理。

    * > **结论**：**批准不是白批准的**——我基于对你的信任让你事前把关，你还是把有问题的东西放行生效了，只能说明你的批准有问题、不负责任；我批准的事儿就意味着出了问题需要我兜着，所以**批准的法就要当作批准机关自己的立法来对待**，简称"批准当自己"。

* 代入到具体情形：地级市法规出问题追究**省人大常委会**；自治区自治条例、单行条例出问题追究**全国人大**；自治州和自治县的自治条例、单行条例出问题通通追究**省、自治区、直辖市人常**的审查责任。

* > **结论**：完整规律叫**区州提一级，自治县提两级，批准当自己**；一旦经过批准，这个法的地位和承担责任的主体就跟制定机关没关系了，已经成为批准机关的事。

## 审查内容与处理结果

### 2+2 与 1+1

* 事前审查与事后审查最核心的区别是被审查对象**到底有没有生效**；事后审查针对已生效的法律文件，**不合法就撤销，不合理就改变**。

    * > **结论**：事后审查不是事前的批准，而是一个事后的**改变或者撤销**的问题。

* 事后审查的表格复杂有三个原因：**审查对象范围特别多**（最低层次的规章基本全都囊括）；**不是任何人都有资格审查**（不是你等级比我高就一定能审查我）；**上级审查下级时审查内容和处理方式不一样**（有时既审合法性又审合理性，有时只审合法性；有时既改变又撤销，有时只撤销不能改变）。

* 要依次搞清楚三件事：**谁能审查、能够审查什么、能够做出什么处理**。

* > **结论**：宏观总体规律是**上级对下级的审查内容和处理结果形成数量上的对应**。

    * 既能审查合法性又能审查合理性，处理结果就是既能够改变又能够撤销；

    * 只能够审查一个，就只审查最基础最底线的那个性——**合法性**，处理结果只能够**撤销**，不能改变。

    * 合法是底线问题；合法性出问题处理结果没别的只能撤销，只是不合理没有触及不合法这个底线还可能改改——**不合理才会有改变，不合法只能撤销**。

    * 记成数就是：**领导关系是 2+2，监督关系是 1+1。**

### 领导关系

* > **结论**：关键取决于上下级在立法审查中**有没有关系**、**是什么关系**；有关系才能审查，没有关系就不能审查。

* **领导关系**意味着上级对下级有完全的指挥能力，下属相对于上级没有独立性；对下属指挥权强，**所以是 2+2**——既审合法性又审合理性，既能改变又能撤销。

* 领导关系一共三个，可概括为**两横一竖**：

    * **横一：同级人大对同级人大常委会**——人常是给人大值班的，如全国人大对全国人大常委会、省人大对省人常。

    * **横二：政府对自己的工作部门**——省政府对公安厅、市政府对公安局。

    * **一竖：政府系统内部**——上级政府及其工作部门对下级政府及其对应的工作部门，如省政府对市政府、市政府对县政府、上级部门对下级部门。

* > **易错点**：这里**不能拐弯**——政府对政府、部门对部门、上级政府对下级政府、上级部门对下级部门，必须一一对应，**不能政府管部门、部门管政府**。

* > **结论**：领导关系三句话：**人大人常、政府部门、政府内部。**

### 监督关系

* **监督关系**意味着下属相对于上级有相对比较强的自主性，审查时只能看行为有没有挑战合法性这个底线；合不合理只有下属自己根据实际工作需要自主判断——**1+1**，只审合法性、只能撤销、不能改变。

* 监督关系也是三个：

    * **第一，同级人大常委会对本级同级政府**——省人大常委会监督省政府、市人大常委会监督市政府、县人大常委会监督县政府，一对一。

    * **第二，上级人大常委会对下级人大及其常委会**——一对二，上级人常同时监督下级人大和下级人常。

    * **第三，授权机关对被授权机关**——你的权力是我授予的，当然可以监督有没有妥善行使、有没有滥用我的信任；主要针对**相对保留授权**和**三区法规的授权**（经济特区、浦东新区、海南自贸港）。

        * > **提示**：这一条单列是因为全国人大、全国人大常委会本来与下级就有领导关系，领导关系能做更多事、能吸收这个监督关系。

* > **结论**：要记住"**监督关系看人常**"——不管横向还是纵向的都锁定人常监督。一府一委两院隶属于本级人大，同级肯定是人大系统监督政府系统；而人大系统里两个主体中只能是**人常**，因为人大是个会、开会时间非常有限，能把自己的人常领导好已很不容易。

* > **结论**：监督关系三句话——**监督关系看人常、同级政府你别狂、下一级人大和人常**；再补一句**授权关系不要忘**（三区法规和相对保留授权）。

* 两套关系的全貌：

    ```text
                    人大系统                            政府系统
              ┌───────────────┐                   ┌────────────────┐
              │     人大       │════领导════▶│    政府          │
              │   （同级横一）  │◀═══领导════│  （同级横二）     │
              │  人大常委会     │                   │    工作部门     │
              └───────────────┘                   └────────────────┘
                     │                                       │
                     │            ┌──────────┐              │
                     └─监督(纵向,一对二)─▶ 下级人大、人常      │
                                                     │
            ┌──────────────────────────────────────────┘
            │  领导（一竖）：上级政府及工作部门 ──▶ 下级政府及工作部门
            └──────────────────────────────────────────

      人大系统 ──监督(横向)──▶ 本级政府        （1+1）
      上级人大常委会 ──监督(纵向,一对二)──▶ 下级人大及其常委会
      授权机关 ──监督──▶ 被授权机关（相对保留授权、三区法规授权）
    ```

### 三个例外

* > **易错点**：三个原则能搞定 80% 以上的题目，但要求不能只定在 80%。

    * 命题人喜欢考原则的同时必考例外，例外针对的情形不到 20%，在考题中出现的概率却非常高。

    * 这像法理学中法律规则适用的 **all or nothing**——掌握 80% 剩下 20% 没搞定，考原则又考那 20% 例外时，这 80% 换来的分数回报是零。

* > **提示**：例外可以理解为**法律的特别规定**；按原则得出的结论与法律规定不一致时，毫无疑问按法律的规定来把握。

* **例外一：以地方人大常委会为主体的监督**——不管是对本级政府的，只要以地方人常为主体的监督，通通不是 1+1，而变成 **2+1**：审查内容**既有合法又有合理**，但处理结果**只撤销**。

    * > **结论**：地方人常的监督是一个经过**强化之后的特别监督**。

* **例外二：全国人大对全国人大常委会批准的自治区自治条例**——自治区的自治条例和单行条例经全国人大常委会批准后视为全国人大常委会的立法（批准当自己），但本级人大对本届常委会是领导关系，按原则应是 2+2，却是特例。

    * > **结论**：**全人大对全国人大常委会所批准的自治区的自治条例和单行条例变成 1+1**——只能审查合法性、只能撤销，不能审查合理性、不能改变；这是整个中国法律体系当中**有且仅有的这一个例外**。

* **例外三：自治州和自治县的自治条例、单行条例**——即州县民族法规。

    * > **结论**：它**只能由全国人大常委会来审查**。

    * > **易错点**：这个不是审查内容或处理结果的例外，它是一个**审查主体的例外**。

* **为什么省人大不能审**：自治州、自治县的自治条例、单行条例都要经省人大常委会批准，按"批准当自己"视为省人常的立法；省人常有两个上级，省人大是领导、全国人大常委会是监督关系上级，正常两者都能管，但这里**排除了省人大的管辖权**。

    * **没有发现问题的能力**：自治条例、单行条例的核心是变通权，变通主要涉及对**中央立法**的变通；当初基于信任已批准生效，就默认你认为它没问题，事后发现问题的概率是没有的。省人常的人是来自于省人大，省人大把综合工作能力最强的人放到人常里，人常基本代表了本级人大最强的日常工作能力和审查能力；这些精英代表组成的人常都没发现的问题，一般代表汇聚起来的人大更不可能发现。

    * **没有纠正问题的动力**：就算某个代表闭会后能力提高发现了问题，也没有动力——自治州、自治县的自治条例、单行条例主要涉及对中央立法的变通，本身就跟省人大关系不大；何况省人常是省人大最亲密的下属，省人大才把日常工作放心交给它。他的更多动力是**替自己最亲密的下属遮掩这个问题**，而不是纠正——对中央的立法变通错误，只能说明你领导无方。

    * > **结论**：再让省人大审查没有意义，干脆**地方就别管了，直接由全国人大常委会来审查**——我基于对你地方的信任已经让你进行过事前审查，事后你就别介入了，事后由我负责。

* > **结论**：三个例外名义上是三个，其实就是**两类**：一类是**地方人大常委会为主体的监督**（2+1），另一类是**所有的自治条例、单行条例**（全人大对全国人大常委会批准的自治区自治条例变成 1+1；自治州、自治县的民族法规只能由全国人大常委会审查）。

### 三步走

* > **结论**：**三步走：第一步看批准，第二步看关系，第三步看例外。**像套数学公式一样一步步套出来，最后推导出的结果一定和法律规定一致。

* **第一步，看批准**——"批准当自己"：看这个法律文件是不是需要经过事前批准，需要就当作**批准机关自己的立法**对待；需要批准的就两类：地级市的法规，民族地方的自治条例和单行条例。

* **第二步，看关系**——看审查主体和被审查对象到底是什么关系：领导关系（人大人常、政府部门、政府内部）是 2+2；监督关系（看人常、同级政府你别狂、下一级人大和人常、授权关系不要忘）是 1+1；两者都不是就是 **0+0**。

* **第三步，看例外**——属不属于两类例外：地方人大常委会的监督是 2+1；自治条例、单行条例类中，全人大对全国人大常委会批准的自治区自治条例变成 1+1，自治州、自治县的自治条例和单行条例只能由全国人大常委会审查。

* > **结论**：这与直觉最不符的地方在于——**不是说级别越高能干的越多，关键看有没有关系；有关系才能介入，没关系就是 0+0**。法不授权即禁止，你权力再高也不能大得过法；全国人大虽不能直接出手，但可以让全国人大常委会出手，**有关系才能搞**。

* **演练示例**（可套用同一方法）：

    * **市法规**：省级人常对同级省级人大是领导关系 2+2；全国人大常委会对省人常有监督关系 1+1；市人大与省人常之间是**下级看上级**，既非领导也非可审查的监督关系，为 **0+0**；国务院、中央政府工作部门对地方人常均为 **0+0**；国监委不在任何口诀中，也是 **0+0**；全国人大对省人常为 **0+0**。

    * **省级政府规章**：省人常对省政府是监督关系，但属例外，改为 **2+1**；国务院对省政府规章是政府内部的领导关系 **2+2**；省人大对省政府规章 **0+0**；全国人大、全国人大常委会对省政府规章 **0+0**——级别太高了，中间隔着级别。

    * **一般机关决议**（如县人大常委会发布的决定、决议，县长无法立法但可以发决议）：市人大对县人常是**人大人常领导关系 2+2**；市人大常委会对县人常是监督关系 1+1 且属例外，改为 **2+1**；市人大对县人常 **0+0**。

* > **结论**：这套方法把针对**规范性法律文件**、一般国家机关**决定或者决议**的审查也一并搞定了，命题时已出现过命题区人大常委会发布的《外来务工管理办法》。

## 被动审查

* 针对司法解释、行政法规、地方性法规、自治条例和单行条例（还可以加上军事法规这一类），**两央两高一委**——中央政府、最高法、最高检、国监委——向全国人大常委会提**要求**；其他主体提**建议**。

* 范围总结就是**法律以下**，其实还没有列完，军事法规都可以加上去。

* > **结论**：两句话概括——**法律以下，两央两高一委向全国人大常委会提要求，其他主体提建议；如果法律以下的是规章，记住规章只有建议。**

* 规章都是由行政机关制定的，要么省级政府，要么地级市一级地方政府，都是行政机关；行政机关的头儿是人大及其常委会。

## 备案四句话

* 备案都是**30 天**，自**公布之日**起的 30 日内报备给相应主体；**备案赶早不赶迟**，以更早的公布时间计算而不是以生效时间计算。

* 这个规律不管立法法如何变动、也不管法律文件体系如何增加新类型都不变，逻辑是**备案找上级**但要**报所有上位法的制定机关**，不是报领导关系或监督关系的上级。

* **第一句：批准当自己。**

    * 一个法律文件如果经过事先批准，这件事跟制定机关没有关系，要把它当作**批准机关的立法**对待。

* **第二句：备案找上级。**

    * 报备时要找**所有的上位法的制定机关**。

    * > **提示**：因为备案的本质是**通知**——通知效力等级比你高的主体，让他知道你下级机关制定了什么法律文件，看有没有和他上级的立法相冲突。

    * 地方人大和国务院是两套系统、看起来没关系，但地方性法规**不能和行政法规相冲突**，因为行政法规是排老三、效力等级高于地方性法规，它就是你的上位法的制定机关。

* **第三句：人大不备案。**

    * 找到上位法的制定机关后，**如果找到的是人大，把人大划掉就行**——人大不接受备案，他是个会；更高级的全国人大、全国人大常委会是不接收关于规章的报备的。

* **第四句：他是不是规章。**

* > **结论**：所以它是个**排除的规律**——先把所有上位法的制定机关找到，紧接着开始对它进行排除。

* **演练示例**：

    * **地级市人大制定的地方性法规**：批准当自己，市法规需批准、提一级，**视为省人大常委会的立法**；备案找上级得到省人大、行政法规的制定机关（国务院）、全国人大、全国人大常委会；人大不备案排除省人大和全国人大；他不是规章，第四句无用。剩下**省人大常委会、国务院**。

    * **地级市政府制定的规章**：市规章不需要批准（需要批准的是地级市的**法规**不包括规章，法规是人大、人常搞的，规章是政府搞的）；备案找上级得到市人大、市人大常委会、省政府、省人大、省人大常委会、全国人大、全国人大常委会；人大不备案排除市人大、省人大、全国人大；他是规章，更高级的全国人大常委会又给排除。剩下**市人大常委会、省政府**。

    * **自治区人大制定的民族法规**（自治条例或单行条例）：自治区的要经全国人大常委会批准，一旦批准**视为全国人大常委会的立法**；备案找上级——全国人大常委会的上位法制定机关，严格来讲**法律和全国人大常委会制定的特别法效力一样高**（普通法内容不同但效力一样高，都是法律），所以第二句就打住、不需要报备，全国人大常委会批准之后直接实施即可，因为它没有上位法的制定机关了。

    * > **提示**：想不到"第二句打住"没关系，就算找到全国人大，第三句"人大不备案"马上就打住；但不能比全国人大常委会还要大，那没办法。

* **报给行政法规到底有没有意义**：两央两高一委可以对法律以外、除规章以外的法律文件向全国人大常委会提审查要求；如果中央政府制定的行政法规与地方性法规抵触，中央政府完全可以**去告状**——向全国人大常委会提审查要求，由全国人大常委会纠正；**它能引发审查要求、引发被动审查程序**。

## 立法审查浓缩

* 掌握的内容可概括成**三个原则、三个例外、三步走**。

* 浓缩表：

| 浓缩说法 | 它管的是什么 |
| :--- | :--- |
| 领导关系 = 2+2 | 既审合法＋审合理，可改变＋可撤销 |
| 监督关系 = 1+1 | 只审合法，只能撤销 |
| 批准当自己 | 事先经过批准的法律文件，当作批准机关自己的立法来对待 |
| 区州提一级，自治县提两级 | 提一级或两级都是提到人常去批，不是提到人大去批 |
| 地方人常是 2+1 | 审查内容既审合法又审合理，处理结果只撤销 |
| 自治条例、单行条例是例外 | 全人大对全国人大常委会批准的自治区自治条例变 1+1；自治州、自治县只能由全国人大常委会审查 |
| 三步走 | 第一步看批准，第二步看关系，第三步看例外 |
| 备案四句话 | 批准当自己、备案找上级、人大不备案、他是不是规章 |
| 法律以下、两央两高一委 | 提要求，其他主体提建议；规章只有建议 |
| 备案都是 30 天 | 自公布之日起 30 日内报备，赶早不赶迟 |
| 法律主席相对多，宪法主席团绝对多 | 法律相对多数过半数、国家主席签署主席令；宪法修正案三分之二以上、主席团发布全国人大公告 |
| 文件报网，公报为准 | 提案说明和审议报告也要公开；报纸和网站都要公布；机关公报才是标准文本 |
| 人大一个月，常委一星期 | 避免偷袭；人大提前一个月发给代表，常委会提前一星期 |
| 撤回提案须同意 | 人大是主席团，人常是委员长会议 |
| 两年可终止，必要时延长 | 两年没推进就终止，必要时可延长 |

* > **结论**：无法靠经典口诀一劳永逸地应对考试——明知或应知某种行为会发生某个结果且希望或放任该结果发生，在法理学上叫**故意**；多数人考不上是**间接故意**，通过对重点知识点的疏忽或偷懒放任了不想看到的结果发生；立法审查是**考点、重点、难点、热点四点合一**的内容，命题人不仅考审查内容和处理结果，还考到规范性文件。
