# 法律责任与法律制裁

## 法律责任的概念与功能

### 法律责任

* **法律责任**

    * > **定义**：行为人由于违法、违约或法律规定，而承担的某种不利后果。

    * 来源是"违法、违约**或**法律规定"三选一，不是二选一。

    * "违法、违约"大致对应口语里的"坏人、坏事"；"法律规定"则对应公平责任、无过错责任。

    * "法律规定"所致的责任举例：车辆失控撞伤行人，当事人无过错也应给予适当补偿；拴好的狗挣脱咬人，狗主人无过错仍要承担补偿甚至赔偿责任。

    * 由三选一的来源可反推：**承担了责任，不等于他一定是坏人**，也不等于一定做了什么坏事。

    * "不利"二字必须勾出：法律责任必然给行为人带来不利后果，法律义务则未必。

    * 履行交货义务换来价款，履行付款义务换来使用价值或交换价值，都能从中获益，不属于不利。

    * 法律义务是享受权利的前提，其履行会带来利益；这一差别是辨析法律责任与法律义务的第一个得分点。

    * 法律责任的关键是"依照法律来承担"，因此**具有国家强制力**；法律责任的追究本身就是国家强制力的一种实现方式。

### 法律责任的功能

* **法律责任的功能**

    * 正常行使权利、履行义务受阻时，需要一股国家强制力把阻碍搬开，这种搬开的方式就是责任。

    * > **结论**：三大功能——惩罚坏人（抓坏人）、救济受害人（救好人）、预防所有人（备所有人）。

    * 教材中"消除未来受侵害的可能性"的表述不必背，要背的是"惩罚坏人、救济受害人和预防所有人"这一句结论。

## 法律责任的分类

法律责任按部门法分为四类：刑法上的刑事责任、民法上的民事责任、行政法上的行政责任、宪法上的违宪责任。是否还有其他责任不必考虑，掌握大纲这四种即可。

### 刑事责任

* **刑事责任**

    * > **定义**：行为人因其犯罪行为所必须承受的，由司法机关代表国家来确定的否定性法律后果。

    * 定义中的两个人称是关键词：一方为犯罪人，一方为司法机关。

    * 刑事责任必须由**司法机关**确立，执法机关没有这个权限：杀人后到公安局自首，公安局不能以自首为由减免其刑事责任。

    * 追究刑事责任时双方不是平权关系，而是隶属关系、隶属性法律关系。

    * 特征一：刑事责任是**犯罪人向国家所负**的责任，不是犯罪人与受害人之间的责任；把他人打伤后追究刑责，是国家介入而非行为人对受害人负责。

    * 特征二：具有**惩罚性**，是最严厉的责任；刑事责任本身没有直接的救济属性，不是为了救济受害人。

    * 刑事责任由个人或单位承担，因为刑法上还有单位犯罪。

    * 被害人另行提起民事赔偿诉讼时，产生刑事附带民事诉讼；不在刑事案件期间提起也行，刑案处理完毕后再提同样可以。被害人不提，法院不主动处理赔偿。

    * 特征三：讲究**严格的罪刑法定**，刑法是追究刑事责任的唯一根据。

    * 三个特征的推导链条：刑罚手段太狠，不能交给个人掌握，否则容易激出兽性；因此国家垄断，由司法机关追究；但国家掌握了狠手段也可能滥用，轻易适用会毁掉一个人乃至一个家庭；所以必须规定严格的罪刑法定。

    * 口诀：国家、惩罚、罪刑法定。

### 民事责任

* **民事责任**

    * > **定义**：因违反民事法律规定（如侵权行为、违约行为），或由于民法规定（如公平责任、无过错责任）而承担的责任。

    * 可分为违约和侵权两类。

    * 特征一：**主要是救济**功能，通过赔偿或补偿损失实现当事人救济；也有惩罚功能，如违约金、定金罚则，但"主要是救济"是重点。

    * 因为以救济为目的，民法一般不区分加害人是故意还是过失——无论故意还是过失，受害人的损失可能就是同一笔钱，再区分对赔偿数额没有实际意义。

    * 特征二：主要是一种**财产性责任**，即动你的钱，如赔偿损失、支付违约金。

    * 注意"主要"二字：也有其他类型，如赔礼道歉属于**行为责任**，要求行为人做出赔礼道歉的行为。

    * 特征三：主要是一方当事人对另一方当事人的责任，即加害人与受害人之间，属于平等主体间的关系，形成**平权型法律关系**。

    * 双方平等因而可以**协商解决**民事责任，协商减免即属此列。

    * 口诀：有财产、救济当事人。

### 行政责任

* **行政责任**

    * > **定义**：因违反行政法的规定，或者因行政法规定而承担的责任。

    * "违反行政法规定"指违法，如超速、卖淫嫖娼；"因行政法规定"指无过错责任。行政责任因此包含过错领域和无过错领域两类。

    * 承担主体有两类：行政主体（行政机关）与行政相对人（普通人）。

    * 追究主体是行政机关及其工作人员；追究对象既可能是别的行政机关（行政机关违法也要受行政警告），也可能是行政相对人（闯红灯被扣分、罚款）。

    * 只要行为人实施了行政法上的违法行为就要承担行政责任，属于**过错推定**；行政机关领导人承担的领导责任（如疫情造成重大损失、工厂爆炸事故后被警告、记过、记大过）属于**无过错责任**。

    * 领导责任举例背后的标准：治理范围内的老百姓受到损害，作为"父母官"也应承受一定不利后果，否则无法回答"为什么受伤的总是我们"。

    * 领导责任比较少，主要还是过错推定责任。

    * 最明显的特征是承担方式最多、**多样化**，根源在于行政执法具有广泛性，执法机关管的事太多，手段必须更多。

    * 精神责任又叫思想责任，就是把违法人骂一顿、对行为人的精神思想实施强制；**它只存在于行政责任中**，民事责任和刑事责任都没有。

    * 民事上的赔礼道歉是让违法者对受害人做出的**行为责任**，不是国家机关把违法者骂一顿；精神损害赔偿是对被害人的赔偿，也不是精神责任；刑事责任只有主刑和附加刑，没有国家骂你一顿这一说。

    * 民事上赔礼道歉、精神损害赔偿的存在，不能推翻"精神责任只存在于行政责任"。

    * "拘留"是一个大筐，只有**行政拘留**才属于行政责任；看到"拘留"二字要先判断是哪一个拘留。

    * 公安机关的拘留可能是行政拘留，也可能是刑事拘留，判断依据是公安机关为什么而拘留：嫖娼被抓是行政拘留，组织卖淫、故意伤害、故意杀人、抢劫绑架是刑事拘留。

    * 法院在审案时对咆哮公堂、辱骂法官的人可以自己采取司法拘留，不必让公安机关介入；司法拘留不属于行政责任。

| 承担方式 | 典型手段 | 实质 |
| :--- | :--- | :--- |
| 行为责任 | 不让你干这个事、那个事，限制从业 | 限制行为自由 |
| 精神责任 | 警告、通报批评 | 折磨精神与心理 |
| 财产责任 | 罚款 | 从口袋里掏钱 |
| 人身责任 | 行政拘留 | 直接拿人 |

### 违宪责任

* **违宪责任**

    * 指有关国家机关制定的法律与宪法相抵触而构成的立法机关责任等，定义不必背。

    * 在我国，承担违宪责任的主要是**国家机关及其领导干部**，不包括私人。

    * 定义中虽写有"国家机关、社会组织或公民"，那是世界范围内的通行定义；我国没有让社会组织和普通老百姓承担违宪责任的规定。

    * 承担方式如立法机关的立法被撤销、领导干部的职务被人大罢免。

    * 我国的责任就是刑事、民事、行政、违宪这四类，只不过违宪责任的主体资格被限定得很窄。

## 法律责任的构成要件

国家机关追究一个人的责任需要一定标准，这个标准就是构成要件。

### 构成要件与犯罪构成要件的对应

* **法律责任的构成要件**

    * > **定义**：承担法律责任必须具备的各种条件，或者必须符合的各种标准；采分点是"必须具备"与"必须符合"。

    * 五个要件：主体、行为、结果、因果关系、主观过错。

    * 与刑法上的犯罪构成要件有对应关系：责任主体对应主体，违法行为与损害结果、因果关系对应客观方面，主观过错对应主观。

    * 法理上的责任构成要件**不包括客体**，这是与犯罪构成要件的关键差异。

```text
   五大构成要件  ←──对应──→  犯罪构成要件
  ┌──────────┐            ┌──────────┐
  │  责任主体  │ ────────▶ │   主体    │
  ├──────────┤            ├──────────┤
  │  违法行为  │ ────────▶ │  客观方面  │
  │  损害结果  │            │  ├ 行为   │
  │  因果关系  │            │  ├ 结果   │
  ├──────────┤            │  └ 因果关系│
  │  主观过错  │ ────────▶ │   主观    │
  └──────────┘            ├──────────┤
                          │  客体    │ ← 法理上的责任构成不包含客体
                          └──────────┘
```

### 责任主体

* **责任主体**

    * 承担法律责任的主体，必须具有**法定的责任能力**。

    * 权利能力、行为能力是泛泛而言，指参加各种法律关系的能力与资格；责任能力仅指在**追究责任环节**承担责任的资格，三者不能混。

    * 举例：12 周岁以下的行为人没有刑事责任能力，但在民法上却具有限制行为能力；不满 12 周岁的人犯罪不承担任何刑事责任。

    * 有权利能力不等于有责任能力，三岁小孩有权利能力却没有责任能力，因而不用承担责任。

    * 自然人成为违法主体需达到法定年龄并有责任能力；组织则必须是能够独立承担民事责任或刑事责任的法人或组织。

    * 对应法律格言：**无主体则无责任**。

### 违法行为

* **违法行为**

    * > **定义**：违反了法律所规定的义务，即不履行义务、超越权力界限（滥用权力），是各种泛泛的侵权行为的总称。

    * 广义的违法包括一切法律所否定的行为：违反行政法（卖淫嫖娼、闯红灯）、违反民法（侵权行为、违约行为）、违反刑法（犯罪行为）、违反宪法（违宪行为）。

    * 狭义的违法仅指除犯罪以外的一般违法，约等于"不太严重"的违法，包括违约、侵权、违反行政法以及违宪行为。

    * 法理上"违法行为"一词相当混乱：有时等于一般违法加违约加犯罪，有时又吸收了违约。

    * "法律责任"定义中的"违法"包括行政违法、侵权、犯罪、违宪，却不包括违约，因为违约已被单独拎出来写。

    * > **结论**：定义中的"违法"既不是广义的违法，也不是狭义的违法，属于混用。

```text
                        法律所否定的行为
        ┌───────────────────────────────────────────────┐
        │            广 义 的 违 法                       │
        │  ┌────────┬────────┬────────┬────────┐        │
        │  │违 宪   │ 犯 罪  │ 侵 权  │ 违 约  │        │
        │  │违反宪法│违反刑法│违反民法│违反民法│        │
        │  └────────┴────────┴────────┴────────┘        │
        │        ▲                                   │  │
        │        │            狭 义 的 违 法           │  │
        │        └───────────────────────────────────┘  │
        │      （除犯罪以外的一般违法 ≈ "不太严重"）      │
        └───────────────────────────────────────────────┘
```

    * 一般情况下，违法行为是责任的前提，没有违法就没有责任，所以才叫构成要件。

    * 特殊情况下，法律责任的承担**不以违法行为为构成要件**，即公平责任和无过错责任。

    * 法律格言：无主体则无责任。

### 损害结果

* **损害结果**

    * > **定义**：违法行为所导致的损失和伤害的事实，包括人身损失、财产损失、精神损失。

    * 损害应当具有**确定性**，如被打伤后可确定的医疗费、误工费。

    * 财产损害一般包括实际损害、所得利益以及可预期的利益。

    * "预期"不能无限外推，必须是**确定的预期利益**：合同约定转卖标的但受让人尚未确定，转卖能否实现、能否获利都不确定，因此只能就实际投入部分承担责任。

    * 有些责任的承担不以实际损害结果为条件，最典型的是**行为犯、危险犯**，其既遂标准不以实际结果为条件。

### 因果关系

* **因果关系**

    * > **定义**：行为与结果之间的因果关系。

    * 教材的表述并不全面。完整的因果关系包含两组：主观到行为、行为到结果。

    * 举例：主观上想杀人（第一段因果）→ 实施了杀人行为 → 实现了死亡结果（第二段因果）。

```text
   完整链条（两组因果关系）

   ┌──────────┐      ┌──────────┐      ┌──────────┐
   │ 主观意志  │ ───▶ │  行为    │ ───▶ │ 损害结果  │
   │  （想杀）  │  第一段│（实施）  │第二段 │ （死了）  │
   └──────────┘      └──────────┘      └──────────┘
        主观 ──到──▶ 行为 ──到──▶ 结果
```

### 主观过错

* **主观过错**

    * > **定义**：主观上的故意或过失。

    * 刑法领域：故意与过失是决定此罪与彼罪、犯罪与否的重要依据，区分非常细致。

    * 民法领域：故意和过失都统称**过错**，因为目的是救济，受害人关心的是自己的损失而非行为人的主观恶性。

    * 行政法领域：主要是**过错推定**。涉及行政机关担责时，被害人不可能反过来证明行政机关错了，只能先推定行政机关有过错，再由其自证无错；例如被拘留时进出身体状况明显不同，只能由公安机关证明其未施暴，证明不了即推定有过错。

    * 涉及普通人被处罚时，违法行为一经作出即推定行为人有过错，行为人只能反证自己没有过错；特殊情况如嫖娼者被抓、司机超速被抓，不能以"没有故意也没有过失"来推卸，否则执法机关无法办案。

    * 主观过错是构成要件，但允许例外，即**无过错责任**。

    * 无过错责任主要存在于民法、行政法中，**刑法中没有无过错责任**；刑罚是惩罚坏人的手段，对无过错者施以最严厉的惩罚说不通。

### 构成要件的例外

* **构成要件的例外**

    * 违法行为、损害结果、主观过错这三个要件都存在例外；责任主体与因果关系是必备的，没有例外。

| 构成要件 | 例外情形 |
| :--- | :--- |
| 违法行为 | 公平责任不需要违法行为 |
| 损害结果 | 行为犯、危险犯不需要实害结果 |
| 主观过错 | 还有无过错责任 |

    * 责任主体必备无例外：11 岁的小孩杀人也不承担刑事责任，呼应"无主体则无责任"。

    * 因果关系必备无例外：危险犯没有后半段，不要求"行为到结果"，但要求前半段"主观到行为"；无过错责任不要求前半段"主观到行为"，但要求后半段"行为到结果"。

    * 结论：因果关系是必然存在的，要么有前半段，要么有后半段，要么全都有。

## 责任的归结

* **责任的归结**

    * > **定义**：由特定的国家机关或者国家授权的组织，依法对行为人的责任进行判断、确认并追究，在实现责任的过程中还要考虑有无从轻、减轻、从宽等情节。

    * 主体是"特定的国家机关"，最典型的是执法机关、司法机关；后半截"国家授权的机关"严格说应是**国家授权的组织或机构**，考试写"机构"没问题，心里要记着它不是国家机关；最常见的例子是大学可以吊销、撤销学位。

    * 客体是对行为人的责任。

    * 内容是四个环节：判断有没有责任 → 确认是哪一种责任（民事／刑事／行政）→ 追究即把责任落实 → 减免即在实现过程中考虑从轻、减轻、从宽。

    * 判断是入口，追究是落点，减免贯穿在实现的全过程；后面所有的规则原则与免责条件都长在"追究"这一格上。

```text
      追究主体：特定的国家机关 / 国家授权的组织（机构）
                            │
                            ▼
        ①  判断  ── 有没有责任？
                            │
                            ▼
        ②  确认  ── 是哪一种责任？
                            │
                            ▼
        ③  追究  ── 把责任实现出来（惩罚、救济、预防）
                            │
                            ▼
        ④  减免  ── 有无从轻、减轻、从宽的情节？
```

## 归责的规则原则

### 规则原则

* **规则原则**

    * > **定义**：指导有关法律责任的立法，指导法律实施的基本原则。

    * 一半指导立法，一半指导法律实施（执法、司法等等）。

    * 立法机关同样适用规则原则：立法时不能对轻罪施以重罚，也不能随随便便、乱七八糟地分配法律责任；题干中只要出现"立法"两个字，就把这一点点出来。

    * 规则原则整体上是在限制公权力的。

    * 大纲只要求掌握四类具体原则。

### 责任法定原则

* **责任法定原则**

    * 法律责任应当**预先有法律规定**，"法定"即法律规定。

    * 教材用"二位阶"写法：核心是法律责任与现有法律规定；规定在法律规范的逻辑结构中；出现了违法行为或法定事由时使用；按事先规定的责任性质、范围、方式来用。

| 事先规定的三个词 | 具体指什么 | 举例 |
| :--- | :--- | :--- |
| 责任性质 | 归哪个部门法 | 民法、刑法、行政法 |
| 责任范围 | 主体的范围、赔偿的范围 | 赔谁、赔多少 |
| 责任方式 | 更具体的承担方式 | 赔礼道歉，徒刑、死刑等 |

    * 派生内容一：刑法是追究刑事责任的唯一根据，讲究严格的罪刑法定。民法也是责任法定，只是不能像刑法那样讲严格法定，因为民法在追究责任时除法律外还可在特殊情况下按习惯、按公序良俗处理。

    * 派生内容二：由特定的国家机关或授权的机构来追究。

    * 派生内容三：反对责任擅断，即反对轻罪重罚、重罪轻罚、主观臆断。

    * 派生内容四：反对有害追溯。法律一般不溯及既往，溯及既往只有在对当事人有利时才有例外。

    * 派生内容五：允许法院行使自由裁量权，执法机关也有自由裁量权，写"允许规则机关行使自由裁量权"同样正确。

    * 五条的关键词口诀：害了山鸡是死刑（害、责任擅断；山鸡、主体特定；是死刑、罪刑法定与自由裁量）。

    * 自由裁量第一类：法律已规定裁量幅度，如量刑规定三年到七年，只能在三年到七年之间裁，具体是三年、四年还是五年可以裁。

    * 自由裁量第二类：法律根本没有规定、靠具体场景判断，如外卖员送外卖可在一周内交罚款而不用立即交。立法者不会把"外卖员"写进法律，写了外卖员还有快递员和其他各种情况。

    * > **结论**：第二类自由裁量不是任意裁量，即使没有具体条文依据，仍要遵守合理性、遵守法的精神，不能违背法律的基本价值。

    * 自由裁量与责任法定并不必然冲突，这与执法上的合理行政原则与依法行政、严格执法不必然冲突是同一个道理。

### 因果关系原则

* **因果关系原则**

    * 分两层：先确定**行为与结果**之间的因果关系，在此基础上再确定**意志等主观因素与行为**之间的因果关系。

    * 第一层举例：对他人身体施加力量导致其受伤；第二层举例：主观上是伤害故意还是杀人故意。同样捅死人但只有伤害故意，只能定故意伤害致人死亡；带着杀人故意下手却只把人弄伤，则为故意杀人未遂。

    * 还要区分这种因果关系是必然的还是偶然的、直接的还是间接的。

    * 法理上并不要求判断必然性与直接性，这一点不是法理的考察角度；刑法上对因果关系判断考察较多，知道包含这一项即可。

### 责罚相称原则

* **责罚相称原则**

    * 又叫责任相称，是正义价值在归责规则上的体现。

    * 责任性质要与**行为性质**相称。

    * 责任的轻重和种类要与**危害结果**相称。

    * 责任的轻重和种类还要与**主观恶性**相称。

    * 合起来即：**行为决定责任性质；主观过错以及危害结果决定责任的轻重和种类**。

    * 责任性质指"是刑事责任、民事责任还是行政责任"这一大的部门法分类，只与行为性质相称，不与主观恶性相称，也不与危害结果相称。

    * 对比：盗窃 5000 元，危害结果是 5000 元财产损失、行为性质是犯罪；因违约致对方损失 5000 万，行为性质是民事违约、危害结果是 5000 万。不能因损失达 5000 万就认定构成犯罪，那仍然是民法上的违约行为。

    * 民事违约导致损失甚至上百亿（房屋交不了致众多买房户每户损失上百万上千万）的情况完全可能，但不能因此就认为必须抓人枪毙，这不是专业结论。

    * 这个点既是难点也是重要考点。

### 责任自负原则

* **责任自负原则**

    * 行为人应当对自己的违法行为负责，不能让没有行为的人承担责任，即**反对株连**。

    * 同时保障责任人受追究、保障无责任者不受追究。

    * 两句可简化为"不枉，也不纵"：第一句强调不冤枉别人，第二句强调不放纵违法者。

    * 某些情况下会产生**责任转承**，又叫替代责任，最典型的是监护人替被监护人承担责任、单位替自己的劳动者承担责任，以及各种连带责任。

    * 连带责任与替代责任都是责任自负原则允许的，不违反责任自负，因为连带或替代是基于特定关系，并未让任何无关的人来替代责任。

## 免责与减免

### 免责

* **免责**

    * 标题叫"免责"，但其外延既包括免除也包括从轻，所以**免责在这里指的其实是减免**，即从轻、减轻和免除的合称。

    * > **定义**：免责，是指出现了法定事由，而被部分或全部免除；部分的免除就是从轻减轻，全部免除才是免除。

    * 免责的前提是**有责**：没有责任就谈不上免责。正当防卫、紧急避险属于无责任而非免责；11 岁小孩杀人属于无责，因为根本没有责任主体。

    * 免责不等于不负责任。

    * 免责并不意味着被免责的那个行为是对的，行为仍然是错的，只是不追究，基于其他角度的考虑。

    * 免责条件很多，大纲列了六种且没有列全，但主要考察的就是这六种。

### 六种免责事由

| 免责事由 | 定义要点 | 体现的价值 |
| :--- | :--- | :--- |
| 时效免责 | 违法行为发生一定期限后，不再承担强制性法律责任 | 效率 |
| 不诉免责 | 当事人不控告，国家就不会归结于违法者 | 自由 |
| 自首立功免责 | 有自首或立功表现的，免除其全部或部分责任 | 正义 |
| 有效补救免责 | 已造成伤害，但在国家机关追究之前及时补救 | 正义 |
| 自助免责 | 因自助行为而引起的责任减免 | 正义 |
| 协议免责 | 加害人与受害人依法协商，减免责任 | 自由 |

    * 六个标题之间没有明显内在逻辑，靠口诀记忆：不时助手笑一笑（时效、不诉、自助、自首立功、有效补救、协议）。

### 时效免责

* **时效免责**

    * 违法行为发生一定期限后，不再承担强制性法律责任；违反法律的行为超过一定期限就不再被国家追究，因时间流逝而消失。

    * 民法上称**诉讼时效免责**，一般诉讼时效三年；刑法上称**追诉时效**。

    * "法律不保护权利上的睡眠者"：借了 10 万元三年不催不还，时效届满后债权人请求还款，债务人有权理直气壮地拒绝。

    * 免掉的是**国家的追究**，即国家的义务、是国家不管了；责任本身仍然存在，债务仍然应当清偿。

    * 债务人在时效届满后主动还款，不构成不当得利，因为这 10 万元本来就该还，只是国家不再强制管这件事。

    * 国家之所以设定时效，是因为时间过去太久许多事无法确定、劳民伤财；年限如何确定是立法者综合衡量的结果。

    * 刑法追诉时效分三档：5 年以下的追诉时效是 5 年，10 年以下的是 10 年，10 年以上的是 15 年；没有核准追诉的，届满后可以不追诉。

    * 体现的是**效率价值**。

### 不诉免责

* **不诉免责**

    * 即"不告不理"：只要当事人不控告，国家就不会归结于违法者，其责任实际上被免掉。

    * 今天不告意味着今天被免，明天告明天不免，只要仍在时效内。

    * 民法上的违法行为基本上都是告诉才处理；刑法上也有，最典型的是**亲告罪**，如虐待、遗弃、轻伤、暴力干涉婚姻自由等。

    * 有两个侵权人时只告甲不告乙，法院只判断甲侵权的那一部分，乙相当于不诉被免。

    * 体现的是**自由价值**。

### 自助免责与正当防卫的界限

* **自助免责与正当防卫的界限**

    * 自助免责指因自助行为而引起的责任减免。

    * 关键收尾：正当防卫是**无责**的，自助是**有责但减免**。

| 区分点 | 自助行为 | 正当防卫 |
| :--- | :--- | :--- |
| 保护对象 | 仅限保护自己 | 既保护自己，也保护他人、集体或国家 |
| 情境前提 | 情势紧迫，不能及时请求国家救助 | 一般的人身侵害正在发生 |
| 行为指向 | 针对财产，或限制人身自由的扣押、拘束 | 一般针对身体 |
| 责任性质 | 有责，但减免 | 无责 |

    * 反例：甲把电动车停放后去打乙，乙绕到车旁把车推倒转移注意力，电动车摔坏，这称不上正当防卫，因为不是"你打我、我打你"，而是毁坏财产、转移注意力并含有限制身体自由的意味。

    * 饭店对不付钱的顾客扣押财产或限制人身自由可以，但扣押、拘束等措施必须保持在一定限度内；把人关进房间拴上链子即超过必要限度。

### 自首立功免责与有效补救免责

* **自首立功免责与有效补救免责**

    * 自首立功免责：有了违法行为之后，有自首或立功表现的，免除其全部或部分责任；坦白也属于这一类，只是大纲没有写。

    * 体现正义价值：自首说明主观恶性在降低，立功说明行为人与国家站到了一起，同样是主观恶性在降低。

    * 有效补救免责：实施违法行为造成伤害后，在国家机关追究之前采取了及时补救，例如积极把受害人送到医院并垫付医疗费。

    * 重大立功可以免除全部或部分责任。

### 协议免责

* **协议免责**

    * > **定义**：加害人与受害人在法律范围内，依法通过协商方式减免责任。

    * 关键点是"协商方式"；协议包括口头的与书面的，不一定非得签书面协议，协议在这里就是协商。

    * 因民事责任中加害人与被害人平等，所以协议免责**一般适用于民事违法行为**，不适用于犯罪行为和行政违法行为。

    * 但犯罪与行政违法中并非绝对没有：被害人谅解后主动赔偿十万元，法院可从轻减轻处罚；行政违法中有行政调解、行政和解；只是不常见。

    * 协议包括全协议与半协议，法院主持的原告人与被告人之间的调解归根到底也是双方商量，只是由法院主持。

    * 体现的是**自由价值**。

## 法律制裁的概念

### 法律制裁

* **法律制裁**

    * > **定义**：特定的国家机关对违法违约者，依责任而实施的强制性惩罚措施，简称**国家搞坏人**。

    * 主体是特定的国家机关；"特定国家机关"还包括经授权的机构，这一条大纲漏写了，但责任是国家的事、主体是国家没有例外。

    * 对象只限**违法违约者**，不是任何人。

    * 做法是**强制性惩罚措施**，关键词是惩罚。

    * 三个要素必须同时成立：主体是国家机关、对象是违法违约者、做法是惩罚；任一要件不成立就不是法律制裁。

    * 反过来推也成立：不是国家机关搞的、不是对坏人搞的、或者不叫惩罚的，都不能叫法律制裁。

    * 在这一层意义上，法律制裁的范围看上去比法律责任还要小一些。

### 不属于法律制裁的三种情形

* **不属于法律制裁的三种情形**

    * 法院判决因感情破裂而准许双方离婚：主体是国家机关，但过不到一起就离不是惩罚，而且并非坏人；这是一种**拯救**，不叫法律制裁。

    * 法院判决承担公平赔偿责任（也叫公平补偿责任）：是法院判的，但公平责任意味着加害人没有过错，**根本没有坏人**，国家凭什么收拾他。

    * 侵权人与受害人私了，甲主动赔偿乙的损失：**连国家都没出现**，更不能叫法律制裁。

    * 记住五个字即可：国家收拾坏人。

## 责任与制裁的关系

* **责任与制裁的关系**

    * 法律责任包括刑事责任、民事责任、行政责任与违宪责任；法律制裁同样分为刑事制裁、民事制裁、行政制裁、违宪制裁，种类几乎一一对应。

    * 第一条：**责任是制裁的前提**。没有责任一定没有制裁，责任先确定，然后才有制裁。

    * 第二条：**制裁是责任的实现方式之一**，即承担责任的"结果、体现"或干脆就叫实现。

    * 故意杀人举例：法院判决构成故意杀人罪并判处刑罚，这个"判"的过程属于责任的归结；判完落实到判决书并予执行，才是制裁。

    * 法律责任属于**应然阶段**——某某人应当承担什么责任；法律制裁属于**实然阶段**——被国家机关落实到判决书上、落实为具体的惩罚。

    * 制裁是一种实现方式，责任是一种应然方式；对应到刑法即：**刑罚是刑事责任的实现阶段、实现方式**。

    * 第三条：二者**不是完全一一对应关系**，法律责任不能完全等同于制裁。

    * 有制裁，一定倒推出有责任；有责任，不一定倒推出有制裁。

    * 典型反例是公平责任：法院把公平责任落实了、执行了，也不叫制裁；被免除的责任国家更不需要制裁。

    * 两个方向不能记反：**公权力不能随随便便搞一个人**，只有应当被归结出那种责任的时候国家机关才会出手。

## 四类法律制裁

### 刑事制裁

* **刑事制裁**

    * > **定义**：司法机关对犯罪人，根据其刑事责任而施加的强制性惩罚措施；刑事责任应当是无期，就把它施加成判无期徒刑。

    * 定义结构与法律制裁一致：把"国家机关"换成"司法机关"，把"坏人"换成"犯罪人"即可。

    * 特征是以刑罚为主、是最严厉的；被制裁的人既可能是自然人也可能是单位，因为刑法上有单位犯罪。

    * 刑罚分两类：主刑五个，为管制、拘役、有期徒刑、无期徒刑、死刑；附加刑为罚金、剥夺政治权利、没收财产等等。

    * 罚金是刑法上的附加刑，罚款是执法机关搞的行政制裁，二者不能混。

    * 没收财产不等于没收非法所得，二者要区分。

    * 主刑、附加刑在法院归结过程中属于应然的责任，归结完毕才成为制裁。

    * 刑法的非刑罚方法即非责任方法，是否属于刑事制裁学界有争议，**通说认为属于**；刑法学科本身没有做责任与制裁的拆分。

### 民事制裁

* **民事制裁**

    * > **定义**：法院对民事责任主体，实施的强制性惩罚措施；三个要素各收窄一层，国家机关仅限法院，坏人即民事责任主体。

    * 民事责任主体主要指**违法违约的人**，即侵权人和违约人，**不包括**承担公平责任的人和承担无过错责任的人。

    * 特征一：以**财产**为核心，因为民事责任主要是一种财产责任。

    * 特征二：适用范围**最为广泛**，因为民事关系最广泛。

    * 制裁方式主要有停止侵害、排除妨碍、消除危险以及支付违约金、消除影响等，可以单独适用也可以合并适用。

    * 法院审理民事案件时还可采取训诫、责令具结悔过、收缴非法活动的财物和非法所得，这属于**非民法方法**，与民法方法一并构成民事制裁。

    * 民事责任也处于应然阶段，民事制裁处于实然阶段；民事制裁除对应民事责任的部分外，还包括训诫、责令具结悔过、收缴等非民法方法，与刑法上的非刑罚方法一一对应。

    * 边界一：民事责任可以私了，当事人之间主动承担民事责任不能叫法律制裁，因为国家没有出现。

    * 边界二：公平责任不具有惩罚性，因此不叫民事制裁。

    * 责任与制裁是**交叉关系**而不是包含关系：责任处在应然阶段，制裁处在实然阶段，交叉的那一块就是"民事责任被制裁化"的部分，公平责任、无过错责任落在只在责任里、不在制裁里的位置。

### 行政制裁

* **行政制裁**

    * > **定义**：行政机关对行政违法者实施的强制性惩罚措施。

    * 分两类：**对内的行政处分**与**对外的行政处罚**。

    * 行政处分的主体是行政机关或经授权、委托的其他组织；对象是**违法失职的国家公务员及其所属人员**，即国家公务员、公务员以及按公务员待遇的那部分事业单位人员。

    * 行政处罚的主体是特定机关（行政机关及经授权、委托的机构）；对象是**违反行政法规定的公民或社会组织**。

    * 两个定义不必背，牢牢记住**行政处分是对内、行政处罚是对外部**即可，千万不能用混。

    * 行政处罚的方式按性质分为：警告、通报批评；财产罚（罚款、没收违法所得或非法所得、没收非法财物）；暂扣证件、降低资质等级、吊销许可证件；行为罚（限制开展生产经营活动、责令停产停业等）；人身罚（行政拘留）。

    * 大纲把行政处罚的对象写成"违反行政**法规**"不准确，行政法规只是专指国务院制定的那一部分，违反行政法规定也可能承担行政责任。

    * 警告对外部人有、对内部人（行政处分）也有。

    * 罚款不等于罚金。

    * 没收非法财物不等于没收财产，行政处罚上根本没有"没收财产"这个说法。

    * 行政拘留不等于刑事拘留，**只有行政拘留才叫行政处罚**。

### 违宪制裁

* **违宪制裁**

    * 是对**违宪行为**实施的一种强制性惩罚措施。

    * 进行违宪制裁的机关**只有两个**：全国人大及其常委会。

    * 对象**也只有两个**：一个国家机关，一个领导干部。

    * 对象不是"国家机关及其公职人员"，**仅限领导干部**。

### 四类制裁总表

| 制裁种类 | 主体 | 对象 | 特征 | 具体种类 |
| :--- | :--- | :--- | :--- | :--- |
| 刑事制裁 | 司法机关（法院、检察院） | 犯罪人 | 以刑罚为主，最严厉 | 刑罚（主刑、附加刑）＋非刑罚方法 |
| 民事制裁 | 仅限法院 | 侵权人、违约人 | 以财产关系为核心，适用范围最广 | 与民事责任重合的制裁措施＋非民法方法 |
| 行政制裁 | 行政机关（含经授权、委托的） | 行政违法者（含国家公务员及所属人员） | 对内是处分，对外是处罚 | 警告、罚款、没收违法所得或非法财物、暂扣证件、行政拘留等 |
| 违宪制裁 | 全国人大及其常委会 | 国家机关、领导干部 | — | — |

## 否定性法律后果与制裁的界限

* **否定性法律后果与制裁的界限**

    * 法律规则的逻辑结构为假定、行为模式、法律后果；法律后果分**肯定后果**与**否定后果**。

    * 否定后果中只有一部分是追究责任，追究责任才有可能落实为制裁；此外还有其他否定后果，例如不受理、驳回等，**不属于法律责任**。

    * 既然不属于法律责任，就更不属于法律制裁。

    * 暗刷流量合同案：法院认为暗刷流量行为侵害不特定利益、损害公共利益，判决合同无效并驳回诉讼请求。驳回诉讼请求没有对任何一方制裁，也没有追究责任，因此不属于法律制裁。

    * 该判决有利于净化网络环境：法院不保护违约方、不支持其诉请，交付服务的一方活白干，暗刷流量这一行当会慢慢萎缩。

    * 流量属于数据信息，可以成为法律关系的客体；契约行为应当受法律规范约束。

```text
                          法律规则的逻辑结构
                                   │
        ┌──────────────────────────┴──────────────────────────┐
      假定                                                  行为模式
                                   │
        ┌──────────────────────────┴──────────────────────────┐
    肯定后果                                                  否定后果
                                                              │
                                             ┌────────────────┴────────────────┐
                                         追究责任                            其他否定后果
                                             │                        不受理、驳回 …
                                        落实为制裁                        （不属于法律责任）
                                             │
                                         法律制裁
```
