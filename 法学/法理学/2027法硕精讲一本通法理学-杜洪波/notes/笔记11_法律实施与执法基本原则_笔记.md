# 法律实施与执法基本原则

## 法律实施的概念与特征

* **法律实施（法的实施）**

    * > **定义**：法律在社会生活中被人们实际施行，简称"实施"。

    * "人们的实际施行"指哪些人在施行：政府叫执法，法院、检察院叫司法，普通人叫守法，法律通过执法、司法、守法等方式得到落实。

    * 考试中"法律"与"法"混用，"法律事实""法的实施"指的是同一个东西。

* **法律实施的特征**

    * > **提示**：法律实施是由"书本上的法"变成"行动中的法"，要背成"行动中的法"，不要背成"行动的法"之类的变体。

    * 顺着这组对仗往下是三层转化：

    ```text
          书本上的法    ──────▶   行动中的法

          抽象的行为模式 ──────▶   具体的行为

             应  然      ──────▶    实  然
    ```

    * 抽象的行为模式转为具体的行为：法律普遍规定人人有财产权，落到某甲对其名下别墅享有的财产权即为具体化。

    * 应然转为实然：赡养父母是法律规定的义务（应然），每月实际给付 2000 元即为实然。

    * 该表述主要用于主观题，答上去会让答案增色不少。

* **法律实施的分类**

    * 法的遵守、法的执行、法的适用，分别对应守法、执法、司法三个环节。

## 法律实施的意义与亚里士多德的格言

* **法律实施的三条意义**

    * 法律实施是实现法的作用的必备环节、前提条件。

    * 法律实施是实现法的价值和立法目的。

    * 法律实施是建设法治国家的必备条件。

    * 第三条成立的理由是：法治由立法、执法、司法、守法四大环节构成，实施占的是后三个环节，立法同样是必备条件。

* **亚里士多德关于法治的两重含义**

    * > **结论**：法治包含两重含义：一是已成立的法律获得普遍服从；二是人们所服从的法律，又应该是本身制定良好的法律。

    * 前半句"普遍服从"讲的是实施环节：政府的普遍服从叫依法行政，法院、检察院依法服从叫依法办案，老百姓普遍服从叫全民守法。

    * 后半句"本身制定良好的法律"讲的是立法环节，关键词是"良法"。

    * 两个层次合起来是四个字：良法善治——立法环节是良法，执法司法守法是善治。

    * > **提示**：这句格言是论述题的万能结尾。凡与法治有关的论述题都跑不出立法、执法、司法、守法四个环节，用它收尾效果特别好。

    * 套用模板：总之，正如亚里士多德所言，法治包含两重含义：已成立的法律获得普遍服从，而人们所服从的法律又应该是本身制定良好的法律。必须坚持严格执法，这样才能使成立的法律获得普遍服从。

* **主体在四环节中的分布**

    ```text
                            法 律 实 施（法的实施）
                                     │
            ┌──────────────┬─────────┴─────────┬──────────────┐
            │              │                   │              │
        行 政 机 关     审 判 机 关        检 察 机 关      社 会 公 众
         （政府）        （法院）            （检察院）       （百姓）
            │              │                   │              │
          执  法          司  法              司  法          守  法
            └──────────────┴─────────┬─────────┴──────────────┘
                                     │
                               监 督 机 关
                                  监  督
    ```

    * 谁来实施决定了法律实施的名称：政府叫执法，法院、检察院叫司法，普通人叫守法。

## 意义类论述题的万能原理与扩写方法

* **万能原理**

    * > **提示**："某某某有利于实现法的作用，有利于实现法的价值，有利于建设法治国家"是考意义类论述题的万能原理，只需要扩写。

    * 填入处随题目更换：考论法律实施填"法律实施"，考严格执法填"严格执法"，考司法公正、考基层立法联系点同样往上套。

    * 扩写只有两种方法：概念扩写和种类列举。

* **以"法的作用"为例的扩写结构**

    ```text
    某某某有利于实现法的作用
    │
    ├─ 概念：法的作用 = 法律对人们的行为和社会产生的影响
    │
    └─ 分类
       │
       ├─ 规范作用（概念：法律对人们行为的直接影响）
       │   ├─ 指引作用
       │   ├─ 评价作用
       │   └─ 预测作用
       │
       └─ 社会作用（概念：对政治和社会生活的影响）
           ├─ 阶级统治在政治上的作用
           └─ 社会公共事务方面的作用
    ```

* **使用方法的边界**

    * 概念法与分类法是两套方法，不是一套模板：法的作用完全可以不写概念、直接从分类切入，法的价值也可以直接写分类。

    * 背过就写，没背过就不写：想到秩序写秩序，想到安全写安全，想到平等写形式平等与实质平等，不必凑齐全部价值。

    * 写出的条目数量不一，反而显得写作结构多样化，不是僵化模板。

    * > **提示**：能不能把方法拎出来，取决于脑子里有没有货，只有复盘过大章节、重点章节才拎得出来。鱼塘里一只鱼都没有，用什么饵都钓不上来。

## 法律实施的评价标准

* **评价标准只能从自身寻找**

    * > **结论**：评价标准只能从执法、司法、守法三大环节本身去找答案。

    * 问"中国的执法情况怎么样"，答案只能来自执法环节，法院不是执法机关，不能作为执法的评价标准。

    * 评价法理课讲得好不好，就看法本身的本质、特征、价值、作用讲得怎么样；讲者是哪个法学院毕业的、法理学博士，虽能影响讲课效果，但不是评价标准。

* **评价标准与对应环节**

    | 评价标准 | 对应环节 |
    | :--- | :--- |
    | 刑事案件的发案率、案件种类 | 守法状况（发案率即犯罪率，恶性案件多还是普通案件多） |
    | 破案率 | 执法情况 |
    | 制裁情况 | 司法情况 |
    | 各种合同的履约率和违约率 | 守法情况 |
    | 人们按照法律规定的行为模式去行为的程度 | 守法情况 |
    | 人们对法律的了解程度以及法律意识等 | 守法情况 |
    | 社会大众对于法律价值的感受 | 守法状况，感受好就守得好，感受不好就守不好 |
    | 法律的功能到底实现了没有 | 执法、司法、守法的结果 |
    | 效率 | 法的七大价值之一，属于价值角度 |

    * 这一块重理解、不重记忆，多选题能复选出来就够了，核心抓手只有一句：执得怎么样、司得怎么样、守得怎么样。

* **不要把自己锁死在这几条里**

    * > **提示**：多选题不一定拘泥于书上列出的标准，要掌握书本之外的辐射性知识点。

    * "政府依法行政的情况"书上并没有写，但当然是执法的评价标准。

    * 检察院对刑事案件的抗诉率、监狱减刑假释的情况、法院对法官问责的情况，同样都没写，但都算评价标准。

    * > **结论**：只要是执法、司法、守法这三大环节里面的关联标准，都是评价标准；不能从立法环节中寻找，也不能从经济、政治、社会、文化等方面寻找。

## 法律实现与法律实效

* **法律实现**

    * > **定义**：法律实现是指法律的规定在社会生活中被转化为现实，达到了法律设定权利义务的目的。

    * 关键词是"转化为现实"，法律实施的目的是为了实现。

    * 签买卖合同付了钱对方交货、公安把人抓到，都是实现；对方收钱不卖甚至行骗，就没实现。

    * 如果说"实施"是落实的过程，那么"实现"就是落实了。

* **实施、实现、实效的分工**

    ```text
       实 施 ──→ 实  现 ──→ 实  效
       （过程）   （目的）   （状态和程度）
    ```

    * > **结论**：实施叫"过程"，实现叫"目的"，实效叫"状态和程度"。

    * 法律实施是从应然到实然的过程和一系列具体动作，合称"活动"；看到红灯停下是实施，真停下是实现，法律实现是法律实施的直接目的。

    * 法律实效也叫法律效果，指被人们实际实行的状态和程度。

    * "状态"指主观状态、主观态度：公安机关怀着为人民、维持社会秩序的崇高想法去抓人是状态好，人抓到了但精神萎靡不振、心里骂骂咧咧是状态不好。

    * "程度"指实现了多少：共同犯罪十个人一下抓到九个就是实现了 90%；以 100 万买下卖方陪伴多年的豪车，卖方心里不高兴、不想卖，说明实效不好。

    * 教材另有说法：实现是将实施的过程性与实施的结果性相结合的概念。

* **法律实现的意义**

    * 法律实现意味着抽象的规定真正转化为现实的权利义务，才能发挥其功能；功能即作用。

    * 法律的实施并不必然能够实现，可能有多种因素阻碍着法律实现。

    * 要让它实现并产生实效，就要加强法律监督，盯住执法机关防止滥用权力。

    * > **提示**：主观题写到法律实现的意义时，直接套"一作用、二价值、三法治"即可，不必另背。

## 从法律制定到社会效果的推导链

```text
   法 律 制 定
       │
       ├──▶ 公 布 ──▶ 生 效      （应然约束力：法的效力）
       │                  │
       │                  ▼
       │              实  施        （过程 · 活动：从应然到实然）
       │                  │
       │                  ▼
       │              实  现        （目的：规定被转化为现实）
       │                  │
       │                  ▼
       │              实  效        （状态与程度：实然约束力）
       │                  │
       └──────────────▶ 社 会 效 果   （法律之外的大众评价与社会影响）
```

* **各环节的含义**

    * 法律制定后要公布、生效，生效后才能实施，实施后实现，实现的状态与程度就是实效，再往下还有社会效果。

    * 社会效果指大众的社会评价以及产生的社会影响，等于法律之外的因素对法律的评价。

    * > **提示**：依法办案而且特别开心，实施得好、实现得好、实效也好，但老百姓认为你不该抓这个人，那就是社会效果不好。这块稍稍超纲，但主观题确实考过。

* **法律格言与前提链**

    * 制定、公布、生效、实施全都排在实效前面，因而都是实效的前提。

    * 未经实施，不生效效；法不生效，则无实效。

    * "法未公布，则无遵守之义务"比前两句多一个前提：不公布就不生效，不生效不可能产生实效。作答时既写应然状态上的"我没有遵守的义务"，也写实然状态上的"不可能产生实效"，就把应然与实然打通了。

    * 法律生效意味着有"应然约束力"，法律实效意味着有"实然约束力"，二者正好与法的效力等级、效力范围衔接。

## 影响法律实现的因素

* **影响因素与评价标准的区别**

    * > **注意**：影响因素 ≠ 评价标准，影响因素的范围大得多。

    * 评价某人宪法课讲得好不好，不以他炒股炒得好不好为标准，但后者确实影响前者：炒股炒得越不好，他越安心讲课。

    * > **结论**：凡是与法律实施相联系的各种因素，都会影响法律实现。

* **因素的具体范围**

    * 外部因素有经济状况、政治状况、文化状况、立法状况等；内部因素有执法者、司法者、守法者，内外两部分都有。

    * 国家的阶级本质属政治角度；法律法规反映阶级意志的程度属政治、本质、立法角度；现行法律与经济属经济角度；国家机关遵守法治的程度属法律角度、文化角度。

    * > **结论**：所有与法律有关的事项都是影响法律实现的因素，掌握到这一步就完全够用；但只有内部的才能做评价标准。

## 执法的概念

* **执法（法的执行）**

    * > **定义**：狭义的执法是指国家行政机关以及授权机关、委托的机关或组织，依照法定权限和程序，行使管理职权、实施法律的活动。

    * 定义骨架是主体、权限和程序、内容三块：主体是国家行政机关以及授权、委托的机关或组织，权限与程序指"依照法定权限和程序"，内容是行使管理职权、履行职责、实施法律。

* **执法的广狭义之分**

    * > **定义**：广义的执法是指国家的行政机关、司法机关以及授权和委托的组织等，依照法定权限实施法律的活动。

    * 广义执法 = 狭义执法 + 司法。

    * 广义执法因多了一个司法机关，表述上只能改用"实施法律的活动"这个大词，而不能写"履行行政管理职权"。

    * 广义执法平时不常用，考试中常用的也是狭义；狭义执法的概念需要背诵，广义执法形象理解即可。

## 执法主体的三种来源

```text
执法主体
├── 行政机关
│     例：工商局、公安、税务等
├── 法律法规授权的非行政机关
│     例：大学——授予学位
│         地铁公司——处罚扰乱乘车秩序的乘客
└── 行政机关委托的其他组织
      例：拆迁公司——拆除违建
          税务公司——代扣代缴个税
```

* **授权执法**

    * 法律、法规直接把权力授予特定主体，主体是固定的：法律授权大学授予学位，法律授权地铁公司处罚扰乱乘车秩序的乘客。

* **委托执法**

    * 行政机关自己找个帮手代为执法：政府委托拆迁公司拆除违建，税务局委托公司代扣代缴个人所得税。

    * 委托执法是最常见的情形，行政机关人员中文职较多；即使是公安这样的武职机关，也无权去拆除违建。

* **授权与委托的分界**

    * > **易错点**：授权和委托是两回事。授权是法律、法规直接把权力给出去，主体固定；委托是行政机关自己找个帮手，言外之意是平时反正不养着，有事了委托你去干。

* **为什么只有执法权可以委托出去**

    * 立法权、司法权不能委托给非国家机关；人大、法学院帮忙写个法条、出个稿，充其量叫"委托打草稿"，不能叫委托立法。

    * 底层逻辑是执法管的事太多，都让政府的人去管真管不过来；而扩大公务员数量会导致国家税负加重，税负过重可能激发民变。

## 执法的三大特征

| 对比点 | 执法 | 司法 |
| :--- | :--- |
| 主动性 | 大多主动采取执法措施，少数为依申请的行政行为 | 被动性，不告不理 |
| 单方性 | 执法机关单方的意思表示和处分行为具有决定意义 | 交涉性，保证当事人充分参与，大量质证辩论 |
| 广泛性 | 以国家名义对社会实行全方位的管理 | 特定性，只管特定案件，成不了案的不处理 |
| 灵活性 | 裁量权相对较大 | 裁量权相对较小，最高法院有详细的量刑梯度 |

* **主动性**

    * 执法活动大多由行政机关主动采取各种执法措施：发现违建不用申请就主动拆除（可委托拆迁公司去拆），发现街头两人打架不能蹲着看热闹，那样可能构成玩忽职守或滥用职权。

    * 也有少数是被动的：在人大门口摆摊卖羊肉串要向工商局提出申请，这叫依申请的行政执法行为。

    * 司法是被动性，也可叫"不告不理"；法官与警察同时下班骑车回家，看到街头打架，法官可以旁观，警察旁观至少会受到内部纪律处分。

* **单方性**

    * 执法机关单方的意思表示和处分行为具有决定意义。

    * 听取申辩不等于辩论：执法机关听你陈述，采纳与否不与你商量、不与你辩论，由自己定；法院则是双方反复的质证辩论。

* **广泛性**

    * 执法是以国家名义对社会实行的、全方位的管理，关键词是"全方位"。

    * 红绿灯前停车就是政府完成的一次广义执法行为；准生证决定你能否合法来到世上，墓地安葬、墓地平迁也都由政府说了算，这些都不是法院、检察院的事。

* **其他特征**

    * 还有主体法定性、国家权威性、国家强制性，其中国家强制性执法与司法共有。

    * 灵活性也是执法与司法的区别：司法涉及量刑，最高法院已制定非常详细的量刑梯度，法官裁量权相对较小——不是没有，是比较小；执法机关裁量权相对较大。

* **三大特征推出的结论**

    * 三大特征说明执法行为对老百姓影响比较大：单方可决定、主动可随时发起、全方位管得宽。

    * > **提示**：法制建设中政府应该当排头兵，法治政府建设是重中之重。前面三个特征必须背下来，国家权威性、国家强制性、灵活性可以一笔带过。

* **执法与司法的共同点**

    * 执法与司法的共同点比区别更多：都要依法办案（依法性、法定性），都要公正廉洁、忠诚、都要为人民服务，也都受监督。

    * > **易错点**：有选项说"与司法相比执法具有主动性、单方性，不具有受监督性"，错在不具有受监督性，执法同样受监督。

## 依法行政原则

* **依法行政原则**

    * > **定义**：依法行政原则是指行政机关在法治精神的指引下，依照法定权限、法定程序进行执法活动，是执法的最基本的原则。

    * 扣掉"法治精神"这层修饰，定义剩下的采分点是主体、权限、程序，三项具体要求则展开为主体及权限合法、内容合法、程序合法。

    * "法治精神"指要考虑法律的价值，这句考到写不写都不要紧。

    * > **提示**：它排第一是因为它是基本原理。依法行政在行政领域的地位，相当于依法办案在司法领域的地位。

    ```text
            依法行政原则
            ├─ 主体及权限要合法 ── 设立有依据、职权有依据；越权即违法无效
            ├─ 执法内容要合法 ── 分两层：执法活动（要不要启动）＋ 具体内容
            └─ 执法程序要合法 ── 步骤、顺序、时限
    ```

* **主体及权限要合法**

    * 行政机关的设立以及相应的职权，都必须有法律依据。

    * 设立要有依据，解决的是地方政府"私设公堂"、自设一批没有法律依据部门的问题，该取缔。

    * 职权也要有依据：行使治安拘留权的是公安机关，教育局不能去拘留人；人家孩子没去上学，你把人家父母拘留了肯定不行。

    * 越权即违法无效。

* **执法内容要合法**

    * 内容合法包含启动层面与具体内容层面两层。

    | | 执法活动要合法 | 执法的具体内容要合法 |
    | :--- | :--- | :--- |
    | 所在层面 | 启动之前：要不要启动、启动哪一类 | 启动之后：具体怎么处理 |
    | 关键词 | 什么时候启动、从事哪一类执法活动 | 罚多少分、怎么罚 |
    | 例子 | 交警看到超速车辆，启动交通执法 | 按法律规定扣分、罚款 |

    * 启动层面强调什么时候启动、从事哪一类执法活动：交警看到超速的车启动交通执法是合法的，因为符合法定条件；看见一辆车漂亮就拦人，执法活动的启动本身就违法。

    * 具体内容层面指启动之后按法定标准处理：确实超速了，超速比例不同，就按法律规定扣多少分、罚多少款。

* **执法程序要合法**

    * 程序是操作的步骤或顺序，程序合法就是执法严格按法定的步骤、顺序以及时限进行。

    * 数值：治安拘留最长不能超过 15 天；作出拘留处罚应当自发现违法活动之日起 6 个月内作出，第 7 个月才做就违法了。

    * > **易错点**：本项采分点在第一句——步骤、顺序、时限，背下第一句基本就够。

* **程序合法的具体表现**

    * 《行政处罚法》规定执法人员在调查或者检查时应当主动出示证件，检查之前得亮证，紧急情况除外。

    * "我怎么罚你"要提前告知：想拘留人家就得告诉依法作出拘留五天的行政处罚或治安管理处罚，不能嘴上说"我要罚你了"却不说依据什么、罚什么。

    * 把人弄上车、人问"我这是去哪"、执法者答"一会儿你就知道了"，是典型的违反程序。

    * 听证、论证、申辩等都是正当程序的表现。

## 合理行政原则

* **合理性原则**

    * > **定义**：合理性原则是指执法主体在遵循依法行政的前提下，行使自由裁量权时要适当、要公正，既符合法律价值和法律精神，符合社会生活常理。

    * 关键采分点五个：自由裁量、适当、公正、价值和精神、生活常理；顺序颠倒过来写也可以。

    * "合理"在解释时又冒出个"合理"，不符合逻辑学上定义的要求，所以要记成"适当""公正"。

    * "法律精神和目的"勾在一起就是法律价值，对应公正、公平正义；"社会生活常理"对应合理、社会公理。

    * 定义中间插进的"具有客观的、充分的事实依据和法律依据"是按执法动作顺序插进来的，用意是提示合法是合理的前提，可圈注"依法行政是前提"。

* **只做到依法行政为什么不够**

    * > **提示**：执法机关权力比较大、管的内容比较多，所以在依法行政的基础上还要提出附加性的、补充性的要求。

* **平等对待行政相对人**

    * 实施了同类行为的相对人，要给予同类的对待，即同等人、同等待遇，对应平等价值。

    * 反例：交警查交通违章、查酒驾不能只查 50 万以下的车，看见开跑车的、开劳斯莱斯闪灵的就放过，这就违反平等了。

* **考虑相关因素、兼顾各方利益**

    * 行使自由裁量权要以法律精神为指导，法律精神即法律价值，要考虑保障人权，比如保障人的财产权。

    * 违法情节轻微时不宜重罚：只赚了 20 块钱，犯得着一下罚 10 万吗。

    * 相关因素不是无关因素，包括主观恶性、违法行为、危害结果以及紧急避险等特殊情况，且特殊情况必须与该违法行为相关才算数。

    * 查酒驾吹出 100ml 含量超过 20 确实构成酒驾，但相关因素是：酒是昨晚喝的，急着开车是因为父母生病住院要交手术费，超得也不多；这种完全可以作出警告，没必要搞行政拘留。

    * 反过来对人家说"行了你走吧"，考虑的就是无关因素。

    * 各方利益不只是执法者与相对人两方，还要兼顾相对人周边的相关人员。

    * 抓捕犯罪嫌疑人时对方家里正围着，嫌疑人却在辅导自己三岁小孩写作业。当着孩子面把人扑倒带走虽然合法但不合理，会形成童年阴影；应温和地告诉小孩爸爸有重要任务要出去一段时间。

    * 若相关人员是 80 岁的老父亲同样要兼顾，否则民警要承担纪律责任，非常严重的还可能有法律责任。

    * > **结论**：这一切都是为了合情合理，采分点是相关因素、兼顾各方利益、合情合理。

    * "禁止偏袒谋私"是对前述要求的限制：打着"兼顾各方利益"的旗号搞偏袒、搞谋私就是它。

* **法律有漏洞时往哪儿找依据**

    * 适用于法律只有原则规定，或者连原则规定都没有的情形。

    * 规则没规定而只讲原则，叫规则漏洞，可以用原则填补；规则和原则都没有规定，叫法律漏洞。

    ```text
            ┌─────────────────────────────┐
            │  法律之外                   │
            │  非正式渊源：伦理、道德、习惯 │  ←  公理、善良风俗、公序良俗
            ├─────────────────────────────┤
            │  法律价值与精神             │  ←  公平、合理、公正
            ├─────────────────────────────┤
            │  原则                       │  ←  规则有漏洞时用来填补
            ├─────────────────────────────┤
            │  规则                       │  ←  起点：有规定就按规则办
            └─────────────────────────────┘
    ```

    * 自下往上读：有规定就按规则办；规则没规定就考虑原则；法律整个都没规定就继续往上考虑法律价值与精神；再往外还有伦理、道德、习惯这类非正式渊源。

    * 法律精神和目的其实就是法律价值；公平合理对应公平正义；社会公理和善良风俗对应的就是非正式渊源。

    * 法律之外要考虑的远不止伦理道德习惯，还有判例、指导性案例、党的政策等。

* **综合例证：外卖员闯红灯**

    * 外卖员闯红灯，交警考虑到他马上要超时、超时会有差评、差评影响收入的特殊情况，同时考虑公序良俗，选择让他先去送餐、把身份证押在这儿、一周内接受处罚。

    * 既兼顾了各方利益，处理手段也符合社会公理，容易让人们接受，这就是合理性原则。

* **记忆口诀**

    * 关键词是平等、兼顾、善良风俗、社会公理、法律精神、公平正义，口诀作"等着照顾善良公公"，把六个词装进去，考场上就不会空着。

## 严格执法原则

* **适用对象与任性执法**

    * 严格执法就是指执法者通过严格执法维护法律权威，顺延下去是反对任性执法。

    * 任性执法就是主观臆断，高兴就执一下、不高兴就不执；毕恭毕敬递根烟就放人，一根烟就把法律的权威换了过来。

    * > **易错点**：适用对象不包括法律法规授权的组织，也不包括行政机关委托的组织。执法机关人员受过执法训练能实现这些更高要求，委托收税的公司之类的组织没有受过这种训练。

* **选择性与钓鱼执法**

    * 选择性执法违反的是平等原则。

    * 钓鱼执法就是引诱违法再抓人：人家本来没有违法，先放个饵让人变成"鱼"再抓过来；极少数派出所曾让女警深夜穿得暴露到偏僻地点或酒店、发廊门口引诱嫖客以多罚款。

    * > **易错点**：钓鱼执法要和抽查区分。工商局随机抽查摊贩、只查编号 1、3、5、7、9 这些奇数摊位也是抽查，因为它不管怎么样也是统一标准；但如果查到编号 5 的是"我家的亲戚"就不执法了，这是选择性执法。

### 具体要求：严谨、严肃、严明、公正

* **严谨与依法裁量**

    * 严谨就是严格地遵守法律，在此基础上依法进行裁量。

    * 依法裁量包含两步：先准确判断是否符合法律规定、是否构成违法，再判断是否达到了处罚的标准，因为违法的也可能是轻微违法、不需要处罚。

    * 前提还有"准确理解法律精神"，即理解法律价值，可写可不写。

* **严肃、严明、公正**

    * 严肃指执法者的态度要严肃，不能嘻嘻哈哈；有人到公安局报警说被性骚扰，接警的警察捂着嘴笑就已经严重失态。

    * 严明指执法者的内部纪律要严明，执法者还受内部纪律规范约束：着装要整洁、正规、规范，便衣属特殊情况；不能穿警服到酒吧喝酒，喝都不行，坐在那儿也不行——你坐在那儿别人怎么做生意。

    * 公正即要符合公平正义的价值追求。

### 与依法行政、合理行政的关系

```text
        严格执法的要求范围
        ├─ 内层：依法行政（主体 · 权限 · 程序 · 内容）
        └─ 外层：在依法行政之外，另加三条更高要求
             ├─ 态度  → 严肃
             ├─ 纪律  → 严明
             └─ 价值  → 公正（其中也涉及一点"合理"）
```

* **与依法行政**

    * > **结论**：严格执法与依法行政属于同一范畴但不能完全划等号；大体而言，严格执法除了要求依法行政以外，还要求遵守纪律、保持形象。

    * 主体上二者在"政府的人"这一块重合，内容和程序上也重合，除依法的内容和程序外，严格执法还多了严肃、严明、公正三条更高要求，其中公正也涉及一点"合理"。

* **与合理行政**

    * 严格执法与合理行政并不矛盾：严格执法是合理的前提，合理是严格的补充，二者都要求公正、都要求符合法律精神。

    * 合理除了要求符合法律精神，还要求公序良俗、道德、善良风俗，所以二者在"法律精神"这一点上有交叉。

* **违反场景的判断**

    * 民警在执法时滥用执法权，违反了依法行政原则，也违反了严格执法原则，因为主体是民警、属于政府的人，且没做到依法行政。

    * 民警在执法时违反程序，既违反依法行政原则，也违反严格执法原则，做多选题时要注意这一点。

    * 执法者不公正、不公平，既违反严格执法，也违反合理行政。

    * > **提示**：出单选题问谁更强调公正，选合理，因为合理主要针对法律价值与精神、非正式渊源（公序良俗、善良风俗）这两点。

## 讲究效率原则

* **效率原则的定义与两个采分点**

    * > **定义**：行政机关在依法行政前提下讲求效率。

    * 两个采分点：主动有效地行使权力、低成本高收益。

* **主动有效**

    * 主动有效就是不消极被动、不拖拖拉拉、不拖沓，推诿和拖沓都违反主动有效，接到报警以后一定要尽快主动出警。

    * "主动有效"的另一个词就是及时高效。

    * > **提示**：要求对违法行为 6 个月内处罚是程序时限，违法行为发生后 1 小时内就处罚已不只是合规而是效率；行政许可 1 个月内办结是程序时限，优化审批流程、通过 App 把审批期缩短到 1 周才是效率。

    * 这种效率是在合法前提下的，不能打着效率的旗号违反法律规定。

* **低成本高收益**

    * 一个普通违法行为，两个民警就能作出处罚，特殊情况下一个民警也能作出处罚，没必要把全公安局的民警都派过去。

    * 执法力量的分配上也要体现低成本高收益。

### 更强调效率与及时反应

* **更强调效率的准确含义**

    * 具体要求第一条是：与立法机关、司法机关相比，行政机关更强调效率。

    * 强调效率不否认公平、正义或公正，执法机关同样追求公平正义。

    * 立法环节和司法环节公正与效率的比例大约是八比二，执法环节大约是六比四，效率的比重更大。

    * > **易错点**：不能认为执法机关打着效率旗号、违背法律不行，违背公平正义也不行。

* **两句及时反应要求的区别**

    | | 对各项请求及时作出反应 | 对各种行政事务及时作出反应 |
    | :--- | :--- | :--- |
    | 针对对象 | 相对人提出来的请求 | 不需要相对人申请的行政事务 |
    | 行为性质 | 依申请的行为，如行政许可 | 主动的行为，如行政处罚 |
    | 形象理解 | 别人提出申请，你要及时办结 | 不用等别人申请，你要主动出手 |

    * 前一句说的是依申请的行为，后一句说的是主动的行为，行政处罚不需要对方申请。

    * 教材只解释了"主动有效"这一项，对"低成本高收益"并没有展开解释。

* **边界**

    * > **结论**：搞效率不能违法，任何原则的执行都不能违反法律，因为依法行政是首要原则。

## 正当程序原则

* **正当程序**

    * > **定义**：正当程序是指执法机关在实施行政执法行为的过程中，要遵循法定的步骤、顺序、时限。

    * 关键在步骤、顺序、时限，与依法行政中的程序合法完全一样；"方式、形式"讲义上写不写都无所谓。

    * > **结论**：正当程序是写书的人为强调程序而从依法行政或严格执法中剥离出来的专门一节，因此不按程序执法既违反依法行政原则，也违反严格执法原则，还违反正当程序原则。

* **两条具体要求**

    * 第一条，不得单方面私下接触行政相对人：一旦单方接触就可能发生利益交换，别人就会怀疑勾兑。

    * 非接触不可时，接触了就必须避嫌，所以由"不单方接触"派生出回避原则。

    * 第二条，不能在事先未告知、也未听取行政相对人申辩意见的情况下作出不利处理：不能偷偷摸摸地罚人家，也不能不听意见就罚，否则可能真的处罚错了。

    * 对方说了听不听得进去是执法者的事，因为执法本身具有单方性；但程序上必须让人把话说完。

    * > **结论**：正当程序一节，定义最关键是步骤、顺序、时限，具体要求只有两条——不私下接触（派生回避）、告知并听取申辩（派生公开、告知、辩论）。

## 比例原则

* **比例原则**

    * 比例原则是从合理原则里面抽出来的，行政法专业里比例原则就放在"合理"里面。

    * > **定义**：行政机关实施行政行为，行政目的与相对人可能遭受的不利影响处于冲突状态，此时应当使不利影响被限制在尽可能小的范围和程度内，并使二者处于适当比例（也叫适度比例、均衡的比例）。

    * 关键词记一个就行：尽可能小的范围。

    * 均衡说到底就是责罚相称、重罪重判轻罪轻判，背后的价值仍然是正义。

    ```text
    第一层  手段要配套
            │  什么样的手段才能实现行政目的？
            ▼
    第二层  配套手段中挑伤害最小的          →  必要性
            │  能达到目的的手段有很多种，挑最轻的那一档
            ▼
    第三层  连最轻的这一档手段，也要控制幅度  →  均衡性
               同为罚款，罚多少才与违法程度相称？

    三个角度各管一段：
      配套性管「该不该用这一类手段」
      必要性管「该用哪一档手段」
      均衡性管「这一档手段的力度要多大」
    ```

### 妥当性：手段必须和目配套

* **定义与例子**

    * 妥当性也叫适当性，指行政行为对于实现行政目的是适当的，这个"适当"就是配套。

    * 企业欠税，配套的执法手段应该是催缴；把欠税的法定代表人枪毙太不配套，还没催缴就上去直接抓人、拘留也不配套。

    * 配套手段是有梯度的：催缴、警告、批评，催缴不成可以罚款，所有措施都不行才可能上升为拘留。

    * > **易错点**：配套不等于"只能用最轻的"，也不能"哪个手段狠就上哪个"。欠税这件事上催缴、警告、批评、罚款、拘留都属于配套措施，配套解决的是手段与目的对不对一的问题。

    * 反例：申请文明城市就让所有门头牌匾统一成白色或黑色，都属不配套，管得太宽。

### 必要性：让对方的伤害小到不能再小

* **定义与算法**

    * 必要性原则是指只要能实现目标就行，行政手段只能限制在必要的程度，尽可能是对方权益遭受最小伤害。

    * 最小伤害即变相最大限度保护对方利益：利益是十，罚一还剩九，罚二只剩八，所以选择对影响最小的配套手段就是最大限度保护你的利益。

    * 简言之就是：让老百姓受益的事想办法让他多赚点，让老百姓损失的事想办法让人家遭受最小损失。

* **执法中的适用**

    * 欠税的催缴、警告、批评、罚款、拘留都行，但不能一上来就拘留，应先警告并同时催缴，仍不听再继续催缴并罚款，逐个往上上升。

    * > **易错点**：不能先打折他的腿。警械的使用应当随着危险性的增加而往增加，一般情况下人家不开第一枪、没有明显举动的举动，咱不能开枪。

    * > **提示**：警匪片里警察拿枪指住杀人犯、对方站住放下武器趴下之后不该再开一枪，是因为警察权力太大，若允许其选择伤害较大的方式，遭殃的会是更多普通老百姓。

### 均衡性与比例原则的边界

* **均衡性：连最轻的手段也得控制幅度**

    * 均衡性是指行政行为实施时，要使二者处于均衡比例。

    * 欠税十万者，催缴回来收益就是十万，可以先罚两万、一万，传达的信息是现在交加上罚款共十一万，否则可能十二万、十三万往上加。

    * 无照经营卖芹菜卖了二十块钱被罚六万，已经严重违反均衡性原则。

    * > **结论**：均衡性防的就是极轻极重。

    * 治理货车超载可完整走三步：配套手段有罚款、拘留、吊销驾照；罚款对司机在一定阶段伤害最小，拘留限制人身自由、吊销驾照还得重新考；罚款幅度也要控制，超载 30% 犯得着罚 100 万甚至 10 万吗。

* **与合理原则的区分**

    * 比例原则本来就属于合理，分不出界限是正常的；要能区分得了，说明学得不对。

    * 如果一定要区分：合理原则比较宏观，比例原则比较具体；合理是宏观的合理或宏观的比例，比例是微观的合理。

## 诚实守信原则

* **信息真实**

    * > **定义**：信息真实原则是指行政机关的信息要全面、要准确、要真实。

    * > **易错点**：名称里只有"真实"，实际要求却是全面、准确、真实三个维度，名不副实。

    * 演变逻辑：最初只要求真实，政府就只公布真实的那一部分，剩下的不公布；于是加上全面；政府又以打马虎眼应付，于是再加上准确。

    * 三个维度可以各自单独成立：说"不到一个亿"是又真实又全面但不准确；说"和同学聚会了"真实准确但不全面，隐去了前女友、隐去了唱歌。

    * 结论要点是全面、准确、真实，加上承担法律责任：公布的信息不真实、不全面、不准确的，行政机关应当对信息的真实性承担法律责任。

* **保护信赖利益**

    * > **定义**：非因法定事由并经法定程序，行政机关不能撤销、变更已经生效的决定，也叫公定力。

    * 例子：政府告诉老百姓蜂窝煤炉子改天然气有补贴 3000 元，全改完之后补贴没了；承诺置换一块地建政府办公大楼，办完手续后翻脸不认账，几十亩地价值近八千万拖了二十年不解决；承诺引进外地企业投资给奖励，投资者到位后奖励没了。

    * 两条要点：不要老是变；确实需要变的话，条件必须严格。

    * 变的三项前提条件：法定事由是国家利益、公共利益或其他法定事由；依法而变，依照法定权限、法定程序，并对相对人遭受的财产损失予以补偿。

    * > **易错点**：是补偿不是赔偿。补偿是"我正当地变"，不管是否正当，让相对人遭受了损失总要给点补偿；叫赔偿就说明政府有错。

## 权责统一原则

* **权与责**

    * > **定义**：权责统一原则指行政机关履行相关管理职责、由法律法规赋予其相应执法手段，同时又要合理行使职权，违法或不当行使职权的要承担相应的行政责任，合称"有权有责"。

    * "权"的关键点是必须有执法手段：手铐、脚镣、警棍、通信记录等都是执法手段。

    * "责"就是行政机关既要依法行使权力，又要合理地行使职权，违法或不当行使职权要承担相应责任。

    * 权责统一其实就是前面讲过的权利和义务具有一致性。

* **逻辑方向**

    * 正常逻辑是人民给你权利，同时配套责任。

    * > **易错点**：不能倒果为因。已经给了权力才强化你的责任，不能再以"强化行政责任"为借口又去要更多权利。

## 执法基本原则的分类图景

```text
      执法基本原则（八项）
                  │
  ┌───────────────┴─────────────┐
  │                             │
  侧重法律角度            侧重法外角度
  │                             │
  依法行政                      合理
  严格执法                      比例（由合理派生）
  正当程序                      诚实守信：别骗人
  权责统一                      效率：别拖沓
  │                             │
  维护法律稳定与确定            兼顾各方利益、公平正义
  权利与义务要一致              手段适当、伤害最小
```

| 原则 | 侧重角度 | 一句话内核 |
| :--- | :--- | :--- |
| 依法行政 | 法律 | 主体与权限合法、内容合法、程序合法 |
| 严格执法 | 法律 | 严谨、严肃、严明、纪律、公正、谨慎 |
| 正当程序 | 法律 | 法定步骤、顺序、时限；不私下接触、告知与申辩 |
| 权责统一 | 法律 | 有执法手段，也有法律责任（权利义务一致性） |
| 合理 | 法外 | 平等对待、兼顾各方利益、考虑相关因素、法律精神与善良风俗 |
| 比例 | 法外（由合理派生） | 妥当性、必要性、均衡性 |
| 诚实守信 | 法外 | 信息真实（全面、准确、真实）＋保护信赖利益 |
| 讲究效率 | 法外 | 主动有效、低成本高收益、及时反应 |

* **两个角度的用法**

    * 这两个角度是侧重而不是截然分开的，八项原则在法条里都有规定，极特殊情况下没规定的除外。

    * 法条里也有合理行政、兼顾各方利益的规定，但不能因为法条写了就都归为依法行政，那样会把这些原则自己的个性抹杀。

    * 依法行政、严格执法强调维护法律的稳定性与确定性，权责统一侧重法律上权利与义务的一致；合理就是兼顾各方利益、公平合理，比例就是手段适当、伤害最小，诚信就是别骗人，效率就是别拖沓。

* **口诀**

    * 顺序是比例、严格、诚信、权责统一在前，程序、讲究效率、依法行政、合理在后。

    * 口诀作"比个心，全程讲法理"（后半句也说作"全程讲法律"），前半句罩住比例、严格、诚信、权责统一，后半句罩住程序、效率、依法、合理。

* **判题要点**

    * 做题标准就一条：只要不是一刀切，往往就符合比例；一刀切往往就违反比例。

    * 问比例原则时，体现正当程序（处罚前听证、听取申辩）的选项要排除。

    * 执法的突出特点是主动、非终局，被动和终局是司法的特点。

    * 正当程序与讲究效率不矛盾：讲了正当程序出错就少，出错少效率就变相提高，也不至于老是回过头纠正；二者统一与协调是主流，但断言一点冲突没有也是错的。

    * 严格执法的四项要求严谨、严肃、严明、公正只适用于行政机关及其人员，不是适用于所有执法主体。
