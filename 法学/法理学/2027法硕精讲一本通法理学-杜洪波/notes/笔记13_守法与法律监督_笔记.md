# 守法与法律监督

## 守法的概念

* **守法**

    * > **定义**：国家机关以法律为行为准则，即依法行使权利、依法履行义务。

    * 守法是法律实施的第三个环节。

    * 「以法律为行为准则」能转化成权利和义务，是因为法律本身就是以权利义务为内容。

* **法的遵守（守法）**

    * 守法可简称为"法的遵守"，"法的遵守"又有广义与狭义之分，这个区分是理解后面一切的地基。

    * 广义：执法 + 司法 + 守法。执法要依法行政、司法要依法办案，老百姓依法办事、政府依法办事、法院依法办事，在这个意义上都叫依法办事。

    * 狭义：除执法和司法领域之外其他领域的守法，不再包括执法和司法。

    * 教材使用"守法"一词时取的是狭义口径。

* **积极守法与消极守法**

    * 分类依据是**主观态度**：有人很开心地行使权利，有人心里骂骂咧咧地行使着权利；有人心甘情愿地履行义务，有人不情愿、被迫地履行义务。

    * > **易错点** ⚠️：这里的积极和消极说的是主观态度，与"守法内容"里作为/不作为意义上的积极和消极正面撞车，两组词必须拆开。

## 守法的意义

* 意义表述**直接套用「法律实施的意义」**，不必另背。

    * 有利于法律作用的发挥。

    * 有利于法律价值的实现。

    * 有利于法制环节。

    * > **提示**：只有真正落实到老百姓守法，法的作用（指引、教育、评价等）和法律价值（正义等）才能实现；万一考到守法的意义，把这一段勾出来直接套用。

## 守法的要素

* 守法的要素就是守法的要件，包括**主体、客体、内容**；客体在教材中用词是"守法范围"，有的题目写作"守法客体"，是一回事。

### 守法主体

* **守法主体**

    * > **定义**：国家、社会中应当遵守法律的主体，简称"守法"，即守法行为的实施者。

    * 第一类：一切国家机关、武装力量、政党、社会团体、企事业组织和公民，简称"境内各种人"；这一类前面**没有**"我国领域内"这个定语。

    * 第二类：在我国领域内的外国组织、外国人、无国籍人。

    * 整体范围是**属地主义与属人主义的结合**：境内的所有人、所有组织属地，境外的中国人属人——中国人在美国旅游，仍是我国法律的守法主体，因为他没有入美国国籍。

    * > **易错点**：外交豁免权的全称是"某些外交人员在**责任**上的豁免"，豁免的是法律责任，不是守法义务；即便外国国家元首来我国访问，守法义务一点也没有被豁免，在境内访问时打人一耳光同样构成违法。

### 守法客体

* **守法客体（守法范围）**

    * 关键在"法"这个词：这里的"法"指的是**有法律效力的意思**，只要有法律效力的都得遵守。

    * > **定义**：守法范围是指**必须遵守的行为规范**的种类，即有国家强制力保障的、法律领域内的东西。

    * 包括规范性法律文件。

    * 包括有法律效力的非规范性法律文件。

    * 不包括法律领域之外的文件，即不包括非正式渊源。

    * 守法范围**直接决定于一个国家的法的渊源**。

    * > **易错点**：⚠️ 不要由"决定于法的渊源"顺势推出"非正式渊源也是守法范围"——道德不是法、不是守法客体，政策不是法、不是守法客体，习惯不是法、也不是守法客体。

### 守法内容

* **守法内容**

    * 内容 = 履行法律义务 + 行使法律权利；措辞要摆正：义务说"履行"，权利说"行使"，不用"履行权利""行使义务"这种说法。

    * **履行消极的法律义务**：履行不作为的义务，对应**禁止性规则**（"勿为"）；如刑法分则规定的四百多个罪名一个都不犯。

    * **履行积极的法律义务**：遵守**命令性规则**（"应为"），即作为的义务；如赡养父母、依法纳税。

    * **行使法律权利**：一是自己做出一定行为（也可以不做），二是要求他人做出或不做出一定行为；如撤销权是自己决定干不干，请求权是要求他人干或不干。

    * "作为/不作为"的对立在义务上有表现，在权利上也有表现——行使权利做了就是作为，不做就是不作为。

    * > **注意**：权利要依法行使、义务要依法履行，实质是说**不得滥用权利**；甲依法行使选举权是守法，先把被继承人杀了再行使继承权不是守法，签合同有权利但不能欺诈。

## 守法的状态

* 守法的状态分最低、中间、高级三层，说的是**主观状态**，不是权利义务。

| 状态 | 内容 | 形象说法 | 内心戏 |
| :--- | :--- | :--- | :--- |
| 最低状态 | 不违法犯罪 | 被迫型（忍气吞声型） | 憋着自己受委屈也不主张权利，反正我不干坏事 |
| 中间状态 | 依法办事 | 无感型（行尸走肉型） | 也没觉得是被迫守法，但也不怎么积极 |
| 高级状态 | 外在行为与内在动机结构都符合法律精神 | 开心型（主动型） | 法律义务百分百履行，法律权利充分行使 |

* 最低状态往往是碍于面子或害怕被抓，可以理解为**被动守法**；高级状态的例证是企业及时、足额、完税。

* > **易错点（重点）** ⚠️：守法的"状态"里积极/消极指主观态度，守法的"内容"里积极/消极指作为/不作为——所以可以"积极地履行消极义务"（主观上本就不想杀人），也可以"消极态度地履行积极义务"（赡养父母但心里骂骂咧咧）；权利一侧同理。

## 守法的理由

* 守法的理由就是人们为什么守法，不同的人有完全不同的角度。

### 四种带学派指向的理由

| 理由 | 关键词 | 学派指向 | 内容 |
| :--- | :--- | :--- | :--- |
| 社会契约论 | 同意与承诺 | 自然法学派 | 公民想象出一种契约，共同委托政府管理、让国家立法执法，所以应服从；国家不依法立法执法，可以撕毁契约重新订立，这就是革命 |
| 功利主义 | 利益、减少损失、防范风险 | 功利主义 | 法律带来更多利益，或防范风险、减少损失；本来损失十，守法后只损失五，等于变相赚到五；代表人物是边沁 |
| 暴力威慑论 | 国家强制力的威慑 | 分析法学派 | 守法理由归结为国家强制力的威慑，主张国家定的就得服从，就是命令 |
| 法律正当论 | 信仰与拥护 | — | 从公民信仰法律的角度解释，关键词是"信仰" |

* **法律正当论的要害是形式上好加内容上好。**

    * 形式上：由我们认同的国家机关依法定程序制定、认可，出身有权威。

    * 内容上：与我们的价值、道德等相符。

    * 格言："法律必须被信仰，否则将形同虚设"（美国法学家博尔曼），这句格言指明的是守法理由中的法律正当论。

    * > **易错点**：守法原因**不仅仅只有正当论**，还有暴力威慑论、功利论、契约论等多种理由，不能因为这句格言就说只有正当论一种。

* **习惯论：可以增补的第五种理由。**

    * 基于**家庭习惯或社会习惯**而守法：不因法律好，不因害怕惩罚，也不因守法能获利益，只因从小被教育要遵守各种规矩。

    * 例子：看到红灯就停，理由不是红灯好，而是"我妈从小告诉我，就停就行"；这属于基于习惯的守法。

    * 学派指向是**社会法学派**。

* 这五种解释**每一种都不全面**，因为社会中人各有不同，人们守法往往是多方面考虑的结果。

* 五种理由中最高级的守法状态是**法律正当论**——法律就是个好东西，发自内心地喜欢、出于真爱而守法。

## 法律监督的性质与范围

* 法律监督被教材放在"法律实施"这一章里。

    * > **结论**：说法律实施包括执法、司法、守法三种，对；说包括执法、司法、守法、法律监督四种，也对——**两种答法都对**，不用纠结。

    * 原因是教材在章节安排上摇摆：章节分布上它被塞进实施这一章，可"法律实施"的定义里偏偏没写监督。

* 标题"法律监督"本来应该装两块：**对立法的监督**和**对实施的监督**；本节只是**侧重**讲后面那一块。

    * 对立法的监督也叫法律监督，宪法上的**合宪性审查**就是专门审查立法机关制定的规范对不对。

    * > **易错点**：本节只侧重讲对实施的监督，不代表法律监督仅仅限于此；学宪法时再碰到合宪性审查，它一样属于法律监督。

## 法律监督的广义与狭义

* **广义的法律监督**

    * > **定义**：一切主体对一切法律活动的监督。

    * 老百姓把视频传到抖音上搞舆论监督，属于广义监督，不属于狭义。

* **狭义的法律监督**

    * > **定义**：特定国家机关，依照法定权限和法定程序，对立法、执法、司法等活动的监督。

    * 四个要素要能拆开：主体是特定国家机关；权限是法定权限；程序是法定程序；对象是立法、执法、司法等活动。

    * 专指**公对公**——公权力对公权力，立法机关、执法机关、司法机关的活动全在点名范围内。

    * > **易错点**：狭义的法律监督**不能简称"国家监督"**。国家监督里还装着一块"对相对人的监督"，比如行政处罚一个老百姓属于国家监督但不叫狭义的法律监督；狭义的范围比国家监督**还要小一圈**。

## 法律监督的意义

* 教材自己只写了三条：民主政治的重要保障、对市场经济、法治环节；补上"法的作用"和"法律价值"后成五大意义，再按三大段展开即**十一段万能结构**。

| 角度 | 意义 | 怎么落地理解 |
| :--- | :--- | :--- |
| 本体论 | 有利于法律的作用 | —— |
| 本体论 | 有利于法律的价值 | —— |
| 社会论 | 有利于经济 | 监督搞好了政府不胡作非为，民营企业的日子才好过 |
| 社会论 | 有利于民主政治 | 选举、议政这些民主程序才有保障，各级政治机关都好了 |
| 社会论 | 有利于文化建设 | 政府好好办案，老百姓才真觉得法治是个好东西，法律信仰就是这么养出来的 |
| 社会论 | 有利于生态 | 监督硬了，破坏环境的人就少了 |
| 社会论 | 有利于社会治理 | 即社会文明、社会和谐那一层 |
| 法治论 | 有利于立法 | 监督好了立法，就提高立法质量 |
| 法治论 | 有利于执法 | 监督好了执法，就促进依法行政 |
| 法治论 | 有利于司法 | 监督好了司法，就保障司法公正 |
| 法治论 | 有利于守法 | 监督好了老百姓，就推动全民守法 |

* > **提示**：意义类问答题不用现编，把十一段按"本体论—社会论—法治论"三组往下一摆；真正要临场组织的只有文化建设那段，其余都是"监督好 X 就有利于 Y"的直推。

## 中国法律监督体系

* **法律监督体系**

    * > **定义**：法律监督体系是由法律监督构成的有机联系的系统；答题时把"有机联系的系统"勾出来即可。

    * 体系一分为二：**国家监督**和**社会监督**；社会监督就是**非国家监督**。

    * 两边各四种，4 + 4 = 8，合成守护中国法治的"八大金刚"。

* **国家监督**

    * > **定义**：国家监督，就是以国家机关为主体进行的监督。

    * 最常见的国家机关就是四大：权力机关、行政机关、司法机关、监察机关。

    * > **易错点**：常被塞进来的两个要排除——军事机关负责打仗，一般不属于监督体系；国家主席是一个国家的象征，没有监督实权。排除后只剩这四个。

* **社会监督**

    * > **定义**：非国家监督，是指政党、人民团体、社会组织、人民群众等非国家机关依法对各种法律活动的合法性进行的监督。

    * 主体都不是国家机关，对象是各种法律活动的合法性——既监督国家机关，也监督普通人。

    * 既然不是国家机关，就没有国家强制力，**不具有法律效力**；但**民主性很高**，因为人民群众有十几亿人。

### 八类监督一览

| 系统 | 类别 | 主体 | 主要形式与抓手 |
| :--- | :--- | :--- | :--- |
| 国家监督 | 权力机关监督 | 人大及其常委会 | 法律监督（执法检查、专题汇报）＋工作监督（听取工作报告）；核心主导地位 |
| 国家监督 | 检察机关监督 | 检察院 | 专门法律监督机关；两把剑：抗诉、退补 |
| 国家监督 | 审判机关监督 | 法院 | 法院对法院、法院对检察院、法院对政府 |
| 国家监督 | 行政机关监督 | 行政机关 | 行政系统内部（上下级、审计、复议、监管）＋对相对人（行政处罚） |
| 国家监督 | 监察机关监督 | 监察机关 | 对行使公权力的公职人员；国企、教、群众都仅限管理人员 |
| 社会监督 | 政党监督 | 共产党 | 党组织监督＋纪检委监督，纪委有双重属性 |
| 社会监督 | 社会组织监督 | 组织名义 | 政协、民主党派、社会团体、依法登记的社会组织 |
| 社会监督 | 社会舆论监督 | 传媒 | 借助传媒手段；最广泛、最公开、最民主 |
| 社会监督 | 人民群众监督 | 个人名义 | 直接进行 |

* 八条线不必死记，串成故事即可：某国企董事长拉着秘书的手在成都街头走了一走，被张三拍下传到抖音，随即有群众监督、舆论监督、监察委调查、检察院与法院的司法监督、书法协会免其会长职务、被开除党籍。

* 权力机关监督在这条链上没有出现（人大未介入这条新闻线索）——八条线不是每件事都齐，判断标准仍是**看主体是谁，看有没有具体相对人和具体案件**。

### 权力机关监督

* **权力机关监督**

    * > **定义**：是指以各级人大及其常委会为主体，对其产生的国家机关进行的监督。

    * 定义要背且是常考点，拆开就是"主体 + 对象"两截：主体是人大及其常委会，对象是它产生的机关，含行政机关、司法机关、监察机关及其他机关。

    * 在整个监督体系中处于**核心和主导地位**——我国实行人民代表大会制度，人大是政体，政体盯着政府、法院、检察院干活。

    * **法律上的监督**：纯法律领域，如全国人大及其常委会搞执法检查，全国人大常委会要求国务院、最高法、最高检就法律相关情况作专题汇报。

    * **工作上的监督**：听取政府、检察院、法院的工作报告；虽名为工作监督，但政府干的活儿里肯定有一大块跟法律有关，仍属法律监督体系。

    * > **结论**：国务院向全国人大常委会提出审查要求，仍属**权力机关监督**；国务院只是启动这扇门的一把钥匙，不能因为是国务院主动提出来的就改口叫行政监督。

### 检察机关监督

* **检察机关监督（检察监督）**

    * > **定义**：检察机关监督，简称检察监督，是一种专门法律监督。

    * 司法机关监督以司法机关为主体，而司法机关包括检察机关和审判机关，所以天然分成检察监督和审判监督两块。

    * 正式称谓是**专门法律监督机关**，只能用在检察院身上，不能滥用——靠两个定语理解："专门"说明它不干别的，没有执法权、没有审判权，就只管监督这一件事；"法律监督"说明它在监督领域里权力最广泛，监督公安、监督环保局，凡是用到公权力的地方它都管得着。

    * 检察院不能监督人大，所以人大的监督它干不了，覆盖的是监督领域的**绝大部分**而不是全部。

    * 监察委不能叫专门法律监督机关，因为监察只是整个监督领域里的一小块；监察委的准确称谓是**专门的监察机关**。

    * 范围按诉讼类型有刑事诉讼监督、民事诉讼监督、行政诉讼监督等，其实还不限于这些，不用死背，背到"是一种专门监督"为止。

    * 两把剑：**抗诉**——地方检察院认为法院判得有错误，向上一级法院提起抗诉；**退补**——检察院审查案件认为需要补充侦查的，可以退回公安机关补充侦查。

### 审判机关监督

* **审判机关监督（审判监督、法院监督）**

    * **法院系统内的监督**：市法院发现县法院的判决有错误，可以指令它再审；"指令"这个动作本身近似命令，命令你重审就是监督。

    * **法院对检察院的监督**：检察院起诉到法院，法院觉得起诉不对、不构成犯罪，这就是监督。

    * **法院对政府的监督**：政府被人告到法院，法院通过审理审政府、判政府败诉，这就是对政府的监督。

    * 检察院提抗诉形式上是在监督法院，同时它还在行使司法权、在办一个具体案件——重合关系见「监督与执法司法的重合」一节。

### 行政机关监督

* **行政机关监督**

    * 特征句式是"以行政机关为主体进行的监督"，管两片：行政系统内部、行政相对人。

    * **一般性的监督**：上下级监督，如上级政府撤销下级政府的执法决定。

    * **专门监督**：指行政机关内部的专门机关，完整称谓是"专门的**行政**监督机关"，典型是**审计**；审计机关主要审钱，没有公安那样直接抓人、直接罚款的执法权，是专门在政府内部搞监督的机关。

    * **行政复议**：复议机关对政府的行为做出评判，看看你做得对不对。

    * **行政监管**：对辖区内特定事务的管控，如期货监督管理机构对人员谈话、提示，安装违章摄像头；摄像头本身没有具体执法人员、也没有具体执法对象，只是采集证据，属于管控措施，不算执法。

    * 前四类都属**行政系统内部**的监督，不针对特定的老百姓；对相对人的那一块典型是**行政处罚**。

    * > **易错点**：⚠️ 行政机关监督也可能是执法行为——公安机关对小偷小摸行为处以处罚，既是执法也是监督。

* **执法与监督的分水岭**

    * 判定只看一条：有没有**具体的行政相对人、有没有具体案件**。

    * 有具体相对人与具体案件 → 既是执法，也是监督（行政处罚、治安处罚）。

    * 没有具体案件、只是笼统管控（如安装违章摄像头） → 属于监督但不属于执法，因为没有相对人，无从执行。

### 监察机关监督

* **监察机关监督**

    * > **定义**：监察机关监督，是指以监察机关为主体，对行使公权力的公职人员的监督。

    * "行使公权力的"这个定语不是随便加的：公职人员有行使公权力和私生活两个场景，监察委一般情况下不监察其私生活；反过来读就是"公职人员行使公权力的时候，我才监察你"。

    * 界限举例：市长贪污受贿与公权力有关，归监察；市长强奸了一个人属于普通犯罪，归公安机关立案侦查，不归监察。

    * 公职人员的范围**比刑法上"国家工作人员"的范围要大**。

        * 各类党政机关的公职人员：党的机关（党委、书记等）、人大及常委会机关、政府、法院、检察院、监察委、政协委员会机关、其他民主党派机关、工商联机关（全国工商业联合会的会长、副会长等）。

        * 法律法规授权或受国家机关委托管理公共事务的人员，如大学里管理学校国有资产的资产处人员。

        * 国有企业的管理人员。

        * 公办教科文体卫单位的管理人员：公办学校、科研单位（社科院各研究所）、公办文化单位（相声协会、扇子协会的会长副会长及管理人员）、公立医院、足协。

        * 基层群众自治组织中的管理人员：村长、副村长。

    * > **易错点**：⚠️ **人大代表不在监察范围内**——教材写的是"人大机关中的公职人员"，不等于人大代表，我国人大代表都是兼职的；人大代表若同时是市长，则按市长身份进入监察范围，普通村民同样不在。

    * > **结论**：国企、教、群众三类都**仅限管理人员**——中石油、中石化十几万人管不过来，董事长、总经理、高管、中层管理人员在内，小组长不在；复习压缩成"国企、教、群众"三个字即可，重点仍是背定义。

### 政党监督

* **政党监督**

    * 在这个标题下**专指共产党监督**，不包括其他民主党派——民主党派放在社会组织监督里讲；共产党是执政党，监督地位当然重要。

    * **党组织监督**：最常见的是党委，如谁要当选市长，当选之前党委都要审查他的资格。

    * **纪检委监督**：纪检委**不属于党委**，党下面有党委、有纪检委，相对并列，只不过纪委书记比党委书记矮半级，地方上总是有党委书记和纪委书记。

    * > **结论**：纪委与监察委**合署办公，成为国家监督的组成部分**，纪检委监督具有**双重属性**，这正是它被留在社会监督这一侧的原因。

    * 双重属性的分界：既是党员又是公职人员的，纪委与监察委**一套人马、两套牌子**联合办案，党的问题和公职人员的问题一起解决，属于**国家监督**；只是党员、不是公职人员的，纪委单独办案，不需要监察委介入，属于**社会监督**。

### 社会组织监督

* **社会组织监督**

    * 这一大类必须以**组织的名义**进行监督，政协、民主党派、人民团体等都如此。

    * **政协监督**：政协在政治协商、民主监督上有重要作用，作为一个机关可以批评政府。

    * **民主党派监督**：民主党派是参政党，也可以向国家机关提意见、提建议，形式多种多样。

    * **社会团体监督**：共青团、妇联、居委会、村委会、消协等，各种团、各种会、各种协会；消费者协会监督厂家产品是否侵害消费者权益，环保联合会监督环保，演员协会发现哪个演员有问题可以举报。

    * **其他组织监督**：指依法登记的社会组织，"依法登记"就是在**民政部门**登记；社会组织在民政局登记，企业在工商局登记，这是两码事；基金会属于这一兜底条款。

    * > **易错点**：⚠️ 政协委员首先是个人、其次才有政协委员这个身份，以个人名义搞监督就不叫社会组织监督；**政协委员以个人名义的批评，和政协对政府的批评，这是两码事**。

### 社会舆论监督

* **社会舆论监督**

    * 又叫**新闻舆论监督**，这两个是同一回事；它是人民群众监督在新闻出版领域的体现，借助传媒手段进行。

    * > **结论**：舆论监督最能体现**广泛性、公开性、民主性**；之所以是舆论最广泛而不是人民群众最广泛，是因为人民群众自身的传播力度不够，传到抖音上一夜之间可能全网皆知，广泛、公开、民主归根到底是因为**易传播**。

### 人民群众监督

* **人民群众监督**

    * 人民群众直接进行的监督，以**个人名义**进行。

    * 不上网，直接找到政府的人批评你一下，这就是人民群众监督；与舆论监督的分界在于是否借助传媒传播。

## 监督与执法司法的重合

* 通则：**具体案件中的监督，同时也就是执法或司法本身。**

    * 司法一侧：检察院提抗诉是在监督法院，但它同时在行使司法权、在办一个具体案件；退补侦查在监督公安，也是在办具体案件；法院提审政府、审一个具体案件，也是办案。

    * 行政执法一侧：公安机关对相对人处罚，既是执法也是监督；判据是有没有具体行政相对人、有没有具体案件。

    * 归纳：行政机关的行为怎么定性——有具体相对人、具体案件就是既是执法又是监督；笼统管控（安摄像头）就只是监督。

    * > **结论**：司法监督和司法本身大量重合，行政监督和行政执法也会大量重合，记住这条线索就够：**看主体是谁，看有没有具体相对人和具体案件**。

## 监察委与监察法

* 监察委是 2018 年宪法修正案之后才有的新机关，教材围着《监察法》单独讲了一段。

### 设置监察委的意义

* 第一，贯彻党中央关于深化监察体制改革的**重大举措**——原来政府里下设监察局，让政府的监察局监察政府等于让儿子监督我；加上检察院反贪局、党的纪检委等力量，主要是前面三个合并为监察委，其他力量一并吸收进来。

    * 合并之后，中国公权力分类在西方传统的立法权、执法权、司法权之外**又加了监察权**。

* 第二，有利于加强**党对反腐败工作的领导**，构建集中统一权威高效的监察体系——这么多机构集中到一块就统一了，省得互相扯皮、互相移送案件麻烦，权威和效率自然上来。

* 第三，有利于实现**党的监督和国家监察的统一**，是中国特色社会主义监察道路的创新——对应纪委与监察委的"一套人马、两套牌子"。

* 第四，有利于**加强宪法实施**、**丰富人民代表大会制度**、实现**国家治理体系和治理能力现代化**。

    * 加强宪法实施：宪法的实施就是宪法规定的公权力需要受监督，监督得更充分、更权威、更高效，这就是控权以保民。

    * 丰富人大制度：人大多了一项权力——选举监察委主任，也必然多了一项任务——监督监察委。

    * 治理体系：国家进行治理的各种制度体系，在法律上体现为立法体系、立法环节。

    * 治理能力：国家使用制度治理的能力，在法律上对应执法能力、司法能力，**没有"守法能力"这种说法**，守法不算能力；立法机关里的公职人员被监察好、政府被看好、法院被看好，立法质量自然提高。

* 写作逻辑：第一、二、三条是"党说一段 → 监察体制说一段 → 二者统一说一段"，口诀"党、统、一、体制"；第四条的三个小项口诀"法、代表、能力"。

### 监察法的立法原则

* 坚持党的领导，正确政治方向。

* 合宪——肯定要合宪。

* 问题导向——问题导向就是从实际出发。

* 民主科学、依法立法——这一条是第二、三条的融合：合宪就是合法性立法，问题导向就是科学立法里的从实际出发，理解一下即可。
