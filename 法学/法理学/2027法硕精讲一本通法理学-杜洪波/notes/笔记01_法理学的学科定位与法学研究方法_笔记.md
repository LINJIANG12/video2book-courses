# 法理学的学科定位与法学研究方法

## 法治底层逻辑与法理学的学科定位

### 法理学讲的是一件事

* **法理学**

    * > **定义**：法理学讲的就是法治的底层逻辑。

    * 别人问"法理学是干啥的"，不要去背法理学的定义，要从更高层次告诉他——法理学给出的是法治的底层逻辑。

    * 教材的章节编排与这张底层逻辑图顺序完全一致：为什么好 → 怎么定出来 → 怎么用起来 → 出了事怎么办 → 对社会有什么用 → 它又有哪些做不到的地方。

* **五个法治环节**

    * 政府用叫执法，法院和检察院用叫司法，老百姓用叫守法，用得怎么样有人盯着叫监督。

    * 加上立法，五个环节合称"立执司守监"，简称"立执司守"也行，这五个都是法治的环节，被概括为"法治五连鞭"。

### 法律为什么是好东西

* **本性之好：法的本质**

    * "本性好"好在哪，取决于认为法律好在哪里，由此产生不同学派。

    * 自然法学派特别像中国道家，主张天道，认为法律好在于它有内在的道德品质。

    * 有的学派不谈内在的道德品质，认为法律好在于它有权威的地位——地位高、层次高。

    * 有的学派认为这既不是权威地位的问题、也不是道德的问题，而是老百姓认它——这就是社会现实。

    * 到了马克思这儿，法律好就好在它受到物质的根本决定。

* **外在之好：法的特征**

    * "外在好"就是长得漂亮，这叫法的特征这一章。

        | 观察角度 | 法律"漂亮"在哪 | 记住的关键词 |
        | :--- | :--- | :--- |
        | 产生主体 | 来自国家 | 国家性 |
        | 调整对象 | 调整的是人们的行为，而不是人们的思想 | 行为，而不是思想 |
        | 内容 | 权利与义务得配套 | 一致性 |
        | 程序 | 有国家强制力，还有程序性 | 强制性（就是权限的意思）、程序性 |

* **功能之强：法的作用**

    * 法律可以对个人行为带来各种调整作用，即规范作用；刑法规定故意杀人是死刑，就没人敢杀人。

    * 一个人一个人加起来又组成整个社会，所以法律影响了人，必然会影响整个社会——这就是规范作用的两层：对人行为的作用，对整个社会的作用。

* **满足需求：法的价值**

    * 人们的要求有成千上百个，大纲认为能代表大多数人一般性要求的大要求，就是法律要提供的。

        | 价值 | 说的是什么 |
        | :--- | :--- |
        | 秩序 | 希望有一个稳定的生活环境，不希望国家处于战乱之中 |
        | 安全 | 走在街上不至于被骚扰，拿着钱包占座不用担心被偷；人身安全、财产安全 |
        | 自由 | 在合法前提下想说什么就说什么、想干什么就干什么 |
        | 平等 | 大家都希望不互相看不起，因为大家都是平等的 |
        | 人格权的保障 | 每个人能像人一样正常生活，生命权、健康权等人格权受到保护 |
        | 利益的正当分配 | 干得多就应多分配，对社会利益进行正当分配 |
        | 正义 | 保护弱势群体，整体上虽是弱肉强食，但希望对弱者有更多关怀 |
        | 效率 | 找政府办事、立案、审判不要拖拖拉拉 |

### 定出来还得用起来：立法与实施

* **立法与立法原则**

    * 立法是立法机关的行为，不是私人行为；合起来就是一句话——要对立法构成限制。

    * 不能某一个人说了算，否则就成了专制、成了君主国家。

    * 立法要说科学一点，不能说"你这企业都在污染环境，因此你搬到月球上去"。

* **法条的三种写法**

    * 立法产生出来的东西叫法条，按抽象程度分成三种。

        | 法条类型 | 抽象程度 | 例子 |
        | :--- | :--- | :--- |
        | 规则型法条 | 特别具体 | 故意杀人处死刑 |
        | 原则性法条 | 比较宽泛 | 罪刑法定原则、罪刑相适应原则——只说罪行和责任要保持一致，不说具体罪名和责任 |
        | 概念性法条 | 名词解释式 | 为了犯罪准备条件，制造工具的是犯罪预备 |

* **立法的两个观察角度**

    * 纵向看高低：立法机关有大有小，大机关立的效力层级更高，由此产生法的正式渊源——排第一是宪法，第二是法律，第三是行政法规，等等。

    * 横向看部门：法律归哪个部门，如民法部门、刑法部门、行政法部门。

    * 类比学校：纵向是校长副校长、院长副院长、班主任，有高低；横向是法学院、文学院、工学院、财务处、招生就业处，只分管的事不同，没有高低。

* **实施的四个环节**

    * 政府用叫执法，执法有一堆执法原则；法院、检察院用叫司法，司法也有一堆原则；老百姓用叫守法；有人盯着叫监督。

    * 监督包括国家机关监督——检察院发现法院案子判得不对就抗诉；以及老百姓的监督——认为判决不对就贴到网上发动社会力量。

> **易错点**：守法谈不上原则。立法有立法原则、执法有执法原则、司法有司法原则，唯独守法没有，不要回去找"守法原则"，因为它没有原则。

### 闭环跑完：法律关系、法律责任与社会发展

* **法律运行的闭环**

    * 正常状态下人与人之间建立法律关系，比方说买卖合同、运输合同。

    * 不正常状态下、建立法律关系出现阻碍，就追究法律责任，恢复被破坏的关系。

    * 法律的产生和运行由此形成一个完整闭环，闭环跑一圈对整个社会有好处，有利于社会发展。

* **法理学说的"社会"**

    * 法理学提到"社会"，一般包括经济、政治、文化，还有生态，相当于宪法上讲的五大文明；教材另辟一大章讲法律对这几大文明的能动反作用。

        | 法理学说的"社会" | 对应宪法上的文明 |
        | :--- | :--- |
        | 经济 | 物质文明 |
        | 文化 | 精神文明 |
        | 政治 | 政治文明 |
        | 生态 | 生态文明（大纲没有列） |
        | 社会治理 | 社会治理 |

    * 教材展开的体系很统一：先讲法与该领域的一般关系，再讲两个具体现象。

    * 经济：先讲整体关系，再讲市场经济和科技；科技是生产力，生产力属于经济领域，直接有利于经济发展。

    * 政治：先讲法与政治的宏观关系，再讲政党和国家——在中国提到政治也是一政党、二国家。

    * 文化：先讲一般关系，再讲道德和宗教、意识。

    * 社会治理：主要讲一个意义、一个措施。

### 但法律也没那么好：固有局限与价值冲突

* **"局限性"不是贬义**

    * 它指法律本来自带、客观就存在的东西，不是有毛病的病；"法律没有那么好"这个土话，既包括本来客观存在的局限性（男性怀不了孕），也包括确实有点毛病的东西（太胖了不健康）。

* **法律的五种局限**

    * 调整范围上的局限：法律不是什么事都能管；道德、党的政策同样有很多事管不了，没有哪个规矩一放全世界都听，这种局限都是客观存在的。

    * 与社会现实生活有矛盾：社会发展很快，法律就有滞后性，跟不上跑得慢；由此派生出要对法律进行解释、进行法律推理等章节内容，比如开设赌场罪已扩大到网络赌场。

    * 人本身也有局限：立法者、执法者、司法者、守法者都是人，必然受影响；立法者可能犯糊涂、想不明白，对大数据、AI 怎么立法规范就想不到——技术发展太快，立法者本来又不懂数据、不懂计算机、不懂代码。

    * 受外在政治、经济、文化条件的制约：经济条件好时马路上安满摄像头，交通违章就一定减少；安不起摄像头的路上，超速违停就多。

    * 各种价值之间会有冲突：秩序、安全、自由、平等、正义之间会打架，比如表达自由可能侵犯他人隐私。

> **提示**：价值冲突是客观存在的。学物理学就知道，同一个空间内存在两个以上原子就必然碰撞，社会科学也是如此。

## 备考方法：关键词与复盘

### 听课方式与课程阶段

* **听课**

    * 任何人都有局限性，押题也有个别押不到的题，所以完全可以从头到尾只跟一个老师，那是够的。

    * 第二种方式是以一个为主再辅助一个，但只能再加一个；找多了内心会受到冲击——体系不同、逻辑不同、重点考点强调的点也不同，同一门课听三个版本越听越乱。

    * 关键是"跟得完整"：既然选了跟着这个课，就尽量完整地跟下来。

* **五个阶段**

    * 导学课：约六小时，给法理学设一个大框架；非法学的学生要听一遍，法学学生大部分也是零基础，大学里法理学学不了什么，也要听一遍；听一遍能熟悉整个课程体系和授课风格。

    * 精讲阶段：相当于筑基，把重点考点掰开揉碎讲，是大框架下的细化和深化。

    * 刷题：讲得再好、听得再懂，不练也不行，因为最后都要形成题目，重视刷题。

    * 背诵阶段：包括逻辑概念拆解、联想记忆、导图记忆，甚至口诀记忆，哪个合适用哪个。

    * 写作阶段：应对主观题，主观题在各科目分值里最高，70% 以上；写出来的东西要能感动阅卷人，而不是感动自己。

* **阶段性区分**

    * 学习是走上坡路，肯定要累，到 12 月份才不累；精讲侧重打基础、深化对每个关键词的理解，背诵阶段加入前后串联的体系，写作阶段补充社会热点和马工程的内容。

> **易错点**：不能放弃考试分析直接转马工程。虽然出现了从马工程命题的趋势，但仍有大量题目在考试分析里能找到，考试分析占比更大；也不建议专门去看马工程，理由是马工程会在一定程度上影响你对于法理的热情。

### 复盘流程与纪律

* **复盘流程**

    * 知识索引不是在讲之前讲的，是把每一章讲完以后返回来用它复盘；复盘比刷题在某种意义上还重要。

    * 每一章、每一节前面都画了复盘用的思维导图，每节讲完用大概两到三分钟带着把这一盘复一遍，节大的稍微长一点，节短的稍微短一点。

    * 顺序不能颠倒：先把正文吃透，再做复盘且要自己动手复，最后才轮到刷题。

        ```text
          听 完 一 天 的 课
                  │
                  ▼
          把正文讲的重点考点过一遍
          （重点、例子、形象理解，都要过）
                  │
                  ▼
          跟着我的复盘再过一遍
          —— 最好自己再独立复一遍
                  │
                  ▼
          剩下时间再去刷题
        ```

    * 掌握复盘后第一轮真题正确率能到 80% 以上，学得好的能到 90% 以上；不懂复盘、不懂课后复习的只有 50% 到 60%。

* **三化**

    * 底层逻辑、推导逻辑和例子，让人实现"理解化"。

    * 关键词拆解，让人实现"重点化"。

    * 复盘，让人实现体系化掌握。

* **复盘纪律**

    * 讲义是一个知识索引，一般只列到三级标题，有的地方内容多就列到四级；还需要自己往下再细化一级、再细化一级。

    * 作者故意没有把所有注解都替读者加好，一次全给虽然容易，但那样没有参与感，复盘效果会打折；复盘的活必须自己干。

    * 既要注意体系完整，同时又要抓重点。

> **易错点**：千万不要逐字逐句把讲义抄一遍——抄一遍看着累，还以为记住了，实际上什么也没进脑子。

### 关键词掌握，不是全文背诵

* **关键词的要求**

    * 要求的是关键词掌握，"全文掌握"本身就是一个错误的说法；所谓"必须全文背诵"从来不需要。

    * 关键词就是命题点，关键词就是阅卷采分点。

    * 关键词的解释要比考试稍微难一点点：考试只命到第三层，就把它解释到第四层；他可能还有第五、第六层，不搞那么多。

    * 其他词不背没关系，只要能自己把它串成一句话就行。

* **阅卷的实际标准**

    * 阅卷看的就是关键词有了没有、句子马马虎虎说得算通顺，只要别太口语就行；比如写"政府依法行政"不能写成"政府的当官的依照法律去干点事"。

    * 书上写"政府依法行政"，写成"行政机关依法行政"，没有任何差别。

    * 参加阅卷的老师 99% 都不知道书上怎么写。

* **目标定位**

    * 法理学满分平均就是 60 分，有的年份多、有的年份少，作者希望这一科拿到 50 到 55 分，所以要求稍微高一点。

## 法学的含义、性质与研究对象

* **法学（legal science，法律科学）**

    * > **定义**：法学是以法及其规律为研究对象的人文社会科学。

    * 两个关键词：法及其规律、人文社会科学。

    * 跟化学一样——化学是研究化合物的科学，法学就是法律的科学；跟物理学一样，定义方式都是"某某学"。

### 研究对象的层次性

* **研究对象的层次性**

    * > **定义**："研究法及其规律"展开后出现的分类，由小到大、由浅入深。

    * 规则层面：以法律规则为核心的制定、实施的方法和技术，如立法技术、解释方法。

    * 原则层面：研究法律原则和法律原理，如罪刑法定原则。

    * 规律层面：世界法律发展的一般规律、英美法系法律发展的一般规律、中国法律发展的一般规律。

    * 研究对象越小层次越浅：只研究一个故意杀人罪的构成要件，少量材料就够；研究罪刑法定原则，还得研究背后支撑它的那么多具体规则；研究"中国法律发展的一般规律"得看大量材料。

    * 立法技术、解释方法这类特别具体的技术和方法，是最浅层次的研究对象。

* **层次性的形象例子**

    * 甲学者研究正当防卫构成要件——浅层次。

    * 乙学者研究民法中的公序良俗原则——中间层次。

    * 丙学者研究中国古代到现代刑法发展的一般规律——深层次。

### 社会与人文的两种性质

* **社会科学**

    * > **定义**：社会科学研究的东西看得见，即客观角度。

    * 历史角度：法律产生发展的规律，唐朝有什么刑法、宋朝有什么、明朝有什么、清朝有什么，客观存在、看得见。

    * 制度本身：各种法律规范及其关系，即内部联系、调整机制，如正当防卫的构成要件。

    * 法与其他社会现象的关系：法律怎么促进经济发展、有了法律以后 GDP 上升多少，法律怎么促进政府发展、依法行政比重提高多少。

* **人文科学**

    * > **定义**：人文科学研究看不见的角度，即意义、精神、价值。

    * 推导链：法律是人们生活意义的规则体现 → 法律要解决人们面临的问题 → 法学要为人们在规则下生活提供精神导向。

    * 把"精神导向"拎出来就是价值角度——研究法律制度背后的精神和价值。

    * 识别方法只有一条：落在看得见的构成要件、事实层面是社会科学；落在意义、精神、价值层面是人文科学。

    * 判别示例：研究正当防卫的构成要件是社会科学；研究正当防卫的价值或精神、研究故意杀人罪要保障的价值或法益是人文科学。

## 法学体系：法学的分类

* **法学体系**

    * > **定义**：法学体系指由各个法学分支学科构成的系统。

    * "学"就是"学科"，所以法学体系本意其实就是法学分类、学科分类；分类就有不同的分类标准，四种标准彼此独立，不是一套东西的四种叫法。

        | 分类标准 | 具体分类 | 复习定位 |
        | :--- | :--- | :--- |
        | 一般的分类 | 立法学、执法学、司法学等 | 了解，属一般性考点 |
        | 认识论角度 | 理论法学、应用法学 | 偶尔考考 |
        | 法学与其他学科的角度 | 法教义学、交叉学科 | 偶尔考考 |
        | 法律部门角度 | 搞民法的、搞刑法的等 | 了解即可 |

### 认识论角度：理论法学与应用法学

* **区分标准**

    * 认识论角度问的是：你认识的这个东西、你认识的这些结论，能不能被法院直接用；能就是应用，不能就是理论。

    * 理论法学认识的是法背后的原理，理论不能被法院直接用；法理学属于理论法学——法院不会拿着法理学来判案。

    * 应用法学研究的就是某个具体的法，研究出来法院能直接拿它判案。

* **归属判断**

    * 应用法学：刑法学、民法学、行政法学、刑诉法学、民诉法学、经济法学、国际经济法学。

    * 理论法学：法经济学、法社会学、法哲学、法史学。

    * 语序就是归属信号："某某法学"（部门法在前）偏应用，"法某某学"（法在前）偏理论。

        ```text
          某某法学  ──大概率──→  【应用法学】
                        刑法学 / 民法学 / 行政法学
                        刑诉法学 / 民诉法学 / 经济法学 / 国际经济法学 …

          法某某学  ──大概率──→  【理论法学】
                        法经济学 / 法社会学 / 法哲学 / 法史学 …
        ```

> **易错点**：经济法学和法经济学不能划等号。经济法学是研究经济法法条的学科；法经济学是用经济学的观点研究法，是理论性的东西；法经济学、法社会学都是理论性的东西。

> **易错点**：法医学是法学和医学的交叉学科，但属于应用法学——这是语序技巧的例外；例外不多，基本上就这一个。

> **易错点**：不要把"理论法学／应用法学"和"人文科学／社会科学"划等号。理论法学既有研究客观角度的也有研究主观角度的，应用法学也有研究客观角度的（如正当防卫的构成要件）和研究主观角度的（如正当防卫背后的价值）；这是两个不同角度，彼此没有对应关系。

### 学科关系角度：法教义学与交叉学科

* **法教义学**：研究法律本身。

* **交叉学科**：用别的学科；法哲学是法和哲学，法史学是法和历史，都属于交叉学科。

* **交叉学科为什么难**：国内有学者从《易经》里研究正当防卫；本科是经济学、哲学、历史学甚至计算机的，都特别容易和法学交叉，写论文时交叉学科的论文比纯法学的论文更好发。

## 法学的产生与发展

### 产生的条件与中西方分野

* **法学的产生**

    * > **定义**：法学是在法律发展到一定阶段后才产生的。

    * 先有法律，后有法学；如果世界上只有一条法律，谁都看得懂，根本用不着专门有人研究；法律越来越多，一般人看不懂了，才需要有一帮人把它研究下去。

    * 条件一：先有法律现象，材料积累到一定程度才有研究对象。

    * 条件二：还要有学者阶层，有了法律还得有一帮人专门研究它，学科才搭得起来。

        ```text
           法律材料的积累  +  学者阶层出现
                          ↓
              先有法律（与国家同时）  ──→  再有法学  ──→  再有法学流派
        ```

> **易错点**：并不是有了法就有了法学。法学不是伴随着法律出现、或者伴随着国家出现而出现的，法律必须复杂到一定程度、需要专门的人去研究，这一门学科才会产生。

* **中国古代**

    * 春秋战国时期中国古代就有法学，出现儒家、法家、道家、墨家等直接或间接探讨法律问题的学派：儒家探讨法与道德、礼法结合，法家探讨严刑峻法，道家探讨道法自然。

    * 儒家、法家、道家、墨家不是专门吃法律这碗饭的，吃的是政治饭、哲学饭，只是顺带讨论了法律问题，因此不能叫法学派。

    * 西汉时期儒家占统治地位，叫礼法结合，法学被压在别的学科下面成了"婢女"。

    * 鸦片战争以后，西方思想传入法学领域，才慢慢地出现了一些法学流派。

* **古希腊**

    * 法学最早源于古希腊；古希腊出现了法学这个学科，但同样没有出现法学流派。

    * 法学诞生之初中国并没有落后——古希腊的处境跟春秋战国差不多，古希腊有法学，中国古代也有法学。

* **古罗马**

    * 分水岭出现在古罗马：古罗马时期法学才成为独立学科，出现了法学派别。

    * 时间：大体相当于公元前 500 年到公元后 500 年，公元前 500 年是共和国时期，公元后 500 年是帝国时期；法学成为独立学科、出现法学派别是在共和国时期。

    * 原因一：民事交往非常发达——买卖、借贷、运输、承揽、风险转移是当时真实发生的经济关系，不给它做出规定它自己就要出乱子。

    * 原因二：罗马的皇帝们以懂得民法为荣，还编纂了大量专门的法学著作，比如查士丁尼法典；皇帝精通民法，民法典又被系统化整理，法研究者从"读法条"变成了"有体系地讨论问题"，派别才出得来。

    * 整体时序如下。

        ```text
          中国  春秋战国        ......  有法学，无法学流派
          西方  古希腊          ......  有法学，无法学流派
          西方  古罗马          ......  法学成为独立学科，出现法学派别

          中国  西汉中期以后    ......  儒家占统治地位，礼法结合，法学成附庸
          西方  中世纪          ......  法学成为神学的分支，法学院并入神学院

          西方  12-16 世纪      ......  罗马法复兴，注释法学派居功至伟
        ```

### 中世纪与罗马法复兴

* **中世纪**

    * 中世纪一般叫基督教统治的世纪，法学成为神学的分支，法学院直接放到了神学院里，搞法学研究的都是教士、修女，普通人根本没有资格研究法学。

    * 和中国西汉中期以后放在一起看特别像：两边的法学都成了"婢女"，中国被儒家压住，西方被基督教神学压住，于是又一次回到同一个起跑线上。

* **十二至十六世纪的罗马法复兴**

    * 12 世纪到 16 世纪是罗马法复兴时期，出现了一个以研究和恢复罗马法为核心的法学流派——注释法学派；名字里的"注释"两个字要单独记住，注释就是解释。

    * 12 世纪罗马法的一些规定、一些书突然重现江湖，老百姓一看罗马法这些规定比神学下的法、比教会立的法好多了。

    * 复兴的原因是商品经济的发展：12 世纪以后西方国家对外扩张、对外掠夺，得开着船出去，造船就得买东西，钱不够还得借钱，别人不愿意借，就创造了有限责任公司这种东西，这些公司形态的规定很多是从古罗马法抄过来的。

    * 罗马法在人们心目当中特别神圣，这帮人的任务就是不去改造罗马法，只要好好解释罗马法，所以起名叫注释法学派。

## 近代西方三大法学流派

* 三大流派出现于西方资产阶级的文艺复兴和资产阶级革命时期，是影响最大的三大学派，客观题主观题几乎年年有相关题目。

### 自然法学派

* **自然法学派（natural law school）**

    * "历史悠久"的意思是它的观点在古希腊时期就有萌芽，但那时连学派都还没有，还不能叫自然法学派。

    * 真正的古典自然法学派出现在十七、十八世纪；考试中说的"自然法学派"一般指古典自然法学派，因为它影响最大，而十七、十八世纪恰恰就是资产阶级革命时期。

    * 关键考点：它充分体现了自然法、自然权利和社会契约等人本主义。

* **自然法**

    * 自然法就是自然界存在的那些规律、自然而然的规矩；中国有个更贴切的词叫天道。

    * 不能随便杀人、看到人家有钱不能过去抢过来（不能抢劫）、不能奸淫、不能上去猥亵——抬头只能看见天，看不见天道，但大家都觉得"这个不能随便杀人"好像是对的，这就是自然法。

    * 由此推出关键一步：人是可以制定法律的，但人定法必须符合自然法、符合天道；自然法学派主张的自然法就是指法律之上有天道存在。

    * 考试中自然法有时候又叫应然法、天道、道德、正义。

* **天赋人权与自由平等**

    * 自然法天然给了人权，所以又叫天赋人权；天赋人权其实就是自然权利的意思：自然而然就应该有生命、健康、人格。

    * 崇尚自由平等这两条不是随便挑的，是冲着封建社会来的：自由用来反抗封建的专制，平等对抗封建等级。

    * 结论：老天爷给了我自由和平等，而封建社会的法在搞等级、反平等、搞专制，那我就有权代表老天爷去推翻现有的封建社会。

    * 自然法学派实际上为资产阶级革命提供了一个良好的借口，就像中国古代农民革命也是打着老天爷的旗号推翻现有制度。

* **社会契约与人本主义**

    * 契约就是合同的意思；社会契约指国家和政府是怎么产生的——是人民和他们签订的一份委托合同，委托国家和政府来管理我们。

    * 既然是委托，你就应该按天道那样去管我们；不按天道管我们，我就要推翻你，这就是更换被委托人。

    * 人本主义：把人像人一样去对待，不要把我们像动物一样对待，动不动就专制我、还不平等、还歧视我。

    * 整条推导链如下。

        ```text
           法律之上有天道
           （自然法 / 应然法 / 道德 / 正义）
                    |
                    v
           自然权利 = 天赋人权
           （生命、健康、人格）
                    |
                    v
           崇尚自由平等
           （自由反专制，平等反等级）
                    |
                    v
           签订委托合同（社会契约）
           人民把国家、政府委托出去管理自己
                    |
                    v
           旧法违反天道：专制、等级、不让参加议会
                    |
                    v
           革命 = 替天行道
        ```

* **观点一：法应当是人的理性**

    * 人既是理性的动物，也是感性的动物；自然法学派认为法只能是人的理性，而人的理性跟自然法是一致的。

    * 因为人有感性，立法者立法时不可避免会掺入感性因素：理性因素告诉你别人开车别了你不要去跟他找麻烦，而是按社会契约请有关国家机关处理，拍个照片告诉他违章了；但感情上可能是"你敢别我，我非得别你呢"。

    * 所以如果法条写上"对方开车别你，你有权别回来"，这个规定就不是理性的法，既不符合天道，也不符合自然法。

* **观点二：自然法普遍永恒，高于人定法**

    * 天道是普遍永恒的，天不变道亦不变；在任何社会，故意杀人、故意盗窃、故意奸淫都是被禁止的。

    * 反过来讲，人定法只有符合自然法才是真正的法律，于是推出"恶法非法"。

    * 得名原因：主张法律应当顺从自然规律，因此推出自然规律高于法律。

* **恶法非法怎么落地**

    * 例：机动车闯红灯应受处罚；如果为了救一个危重病人而闯红灯，按自然法学派救人是天道，闯红灯在天道面前就不算什么，所以不应该处罚。

    * 于是"闯红灯的都要受处罚"这条规定在这个具体的事上就成了恶法，我有权不遵守——自然法学派由此主张支持善良违法。

* **采分点与口诀**

    * 采分点一：自然法、自然权利、社会契约、人本主义；口诀"自然人等着约"——自然法、自然权利就是"自然天赋"，人权是"人"，自由平等是"等"，社会契约是"约"。

    * 采分点二：人的理性；普遍永恒、高于人定法；恶法非法；口诀"理性恒久远，高于人定法"。

* **代表人物**

    * 近代典型代表是洛克、孟德斯鸠、卢梭；这里不需要背，后面还有其他代表人物。

    * 现代三位要留意：富勒提出法律的道德性，自然法会替换成"道德"；罗尔斯提出正义论，会替换成"正义"；德沃金提出平等论（自由与平等），会替换成"平等"。

    * 口诀：富尔多金哈。

### 分析法学派

* **分析法学派（analytical legal school）**

    * 产生于 19 世纪：因为资产阶级革命已经结束、资产阶级已经掌握国家政权，不希望老百姓成天嚷嚷"国家法律制度不符合天道，我要推翻你"。

    * 基础是实证主义哲学：实证主义以客观存在为研究对象，就是研究看得见、摸得着的东西，属社会科学层面的研究。

* **反对的三件事**

    * 反对形而上学："形"是能有形、看得见的，往上不就是天道吗；他们只要形而下的东西，反对追求终极真理。

    * 反对超越现行法律制度：现行法律制度就是人定法，是有形的、看得见的。

    * 由此推出：人定法之上没有天道，国家写的法条是什么就是什么，即使违反了天道，它也是法。

* **具体观点**

    * 试图将价值排除在法理学之外：法律制度就是人定法、实际存在的制度，法理学就是研究实在的法律制度。

    * 落到结论上就是"恶法也是法"：救人闯红灯应该处罚，因为法律规定应该处罚；至于天道是什么他不承认，不用看天道。

    * 分析法学派主要为了搞垮自然法学派，结论就是老老实实遵守国家的法条，不要老是拿着道德、正义去否定现行法律制度；这种观点当然受掌握政权的人喜爱。

* **口诀与代表人物**

    * 口诀：反对形而上学、没价值。

    * 早期两位：边沁、奥斯丁都说法律就是国家给你发的命令；20 世纪新代表：开尔森说法律就是一堆规矩，哈特说法律就是一种规则。

    * 口诀：亲亲丁二哈；共同点都是法律是看得见、摸得着的制度。

    * 法律格言（属了解内容）：法律与道德之间没有必然关系；法律就是一个一个的体系，用逻辑就能得出正确判决，不要考虑天道。

> **易错点**：这和自然法学派正好相反。自然法学派说违反天道的法不是法，分析法学派说违反天道的法也是法。

### 社会法学派

* **社会法学派（sociological legal school）**

    * 同样产生于 19 世纪，看名字就知道是从社会现实出发的。

    * 强调现实的法，研究法的现实；反对分析法学派仅仅进行形式逻辑研究——法条研究不就是形式逻辑吗，形式逻辑主要就是写语法、研究字词语法。

    * 侧重宣扬法的社会性；四个关键词是现实的法、法的现实、逻辑、法的社会性，但归根到底就是一件事——法的实效，有实际效果的才是法。

    * "现实的法"和"法的现实"含义一样，一个说的是哪些东西算数，一个说的是从哪个角度切入研究。

* **现实中的法就是正在被用的法**

    * 国家可能定了 100 条，其中 50 条老百姓在用，那这 50 条就是法；剩下那 50 条老百姓不用，那就不是法。

    * 法的社会性就是社会实效，对社会有用就是法：吃婚宴掏红包是老百姓的社会习惯，按国家认可的这一套它不是法，但在社会法学派占统治地位的国家就认为这些就是法。

    * 例：吃了婚宴不掏红包构不构成不当得利？按民法典的规定不构成，因为这不属于调整范围；但按社会法学派的观点构成，因为去人家婚宴掏红包是现实中老百姓都在用的规矩，法官就应该用这个来判断。

* **代表人物**

    * 艾利希（又叫埃尔利希，这两种写法都无所谓）、霍姆斯、庞德，还有一个狄季——选择题会出现。

    * 狄季认为法律就是社会连带关系；连带关系不是民法上的连带责任，翻译成"连带"其实应该叫社会合作关系；有利于社会合作的就是法。例如相邻权人之间还有相互容忍的义务，就来自"法律要促进社会合作"。

    * 霍姆斯："法律的生命不是逻辑，而是经验"；庞德："法律是社会控制手段"；艾利希：法律发展的重心不是立法、不是法理、不是司法，而是社会本身。

* **口诀**

    * 社会现实，反逻辑——重视社会的法、重视社会现实、重视社会实效，反逻辑。

### 三派放在一起看

* **三派并排的样貌**

    * 站的角度：自然法学派上天了（看天道），社会法学派入地了（看老百姓用什么、认什么），分析法学派保持中介（盯着国家）。

        | 学派 | 它主张的"法"是什么 | 站的角度 | 一句话立场 | 口诀 |
        | :--- | :--- | :--- | :--- | :--- |
        | 自然法学派 | 天道（自然法、应然法、道德、正义） | 上天 | 人定法之上还有天道，违反天道就不是法 | 自然人等着约；理性恒久远，高于人定法 |
        | 分析法学派 | 人定法（国家法、实在法） | 国家 | 法条是什么就是什么，恶法也是法 | 反对形而上学，没价值；亲亲丁二哈 |
        | 社会法学派 | 社会现实（社会实效、社会习惯） | 老百姓 | 老百姓在用的才算数 | 社会现实，反逻辑 |

* **三派的标准其实不高深**

    * 法理学高深就高深在那些语言上，背后的原理没有那么高深。

    * 三个学派界定法律的标准，和找老公或者找老婆的标准没有什么差别：女生 A 要找一个道德水平高的，女生 B 要找一个有国家给他撑腰的，女生 C 要找一个生活习惯好、对家里边有实际帮助的。

## 其他法学流派

* **历史法学派（19 世纪）**

    * 法律是随着民族的历史变化而变化的，所以要体现民族的历史演变——民族精神；这一段时间需要 A 法律，那一段时间需要 B 法律。

    * 它是为了反对制定统一的民法典而提出的：法国拿破仑时期想把法国民法典直接拿到德国，遭到德国一帮学者极力反对，历史学派就提出法律是本民族的精神，维护本国民俗传统。

    * 后来影响力慢慢下去了，后来德国还是制定了德国民法典。

* **哲理法学派（19 世纪）**

    * 产生于 19 世纪的五大法哲学派之一。

* **经济分析法学派（20 世纪以后）**

    * 法律应当进行经济学分析：低成本、高收益的规定才是法律，违背了这个就不能叫好的法律。

    * 目前在美国影响最大的两大学派之一，大本营是芝加哥法学院。

    * 过错的判定标准：不是按自然法、天道，也不是你脑子里感觉"我已经告诉你别摸了你非得摸"，而是选择高成本低收益措施的就是过错，只有选择低成本高收益的才是正确的。

    * 动物园例：现状只在笼子外贴告示、不加装防护，咬伤人赔 100 万、咬伤概率 10%、预期成本 10 万，是高成本的选择；给笼子加装一层钢丝网只要 5 万，明明有低成本的选择摆在眼前，所以过错在动物园，必须全额赔偿。

    * 对法律的贡献不限于这里，还包括违约责任的计算、侵权责任的分配，甚至刑法上有些责任的分配是不是违反了成本收益。

* **批判法学（20 世纪以后）**

    * 在美国影响最大的两大学派之一，大本营是耶鲁法学院、哈佛法学院；美国比较喜欢标新立异。

    * 认为法律是缺点为主的，没什么优点。

    * 否定法律具有确定性："多次盗窃"里"多次"是什么意思、两年内三次多还是十次不多，"暴力、胁迫、其他方法"里打一耳光算不算暴力，都没有确定答案。

    * 否定法律是中立的：法律保护的都是有钱人的利益。

* **女权主义法学派（20 世纪以后）**

    * 就是女性视角，认为现在用的制度都是男性视角；一个国家的议员绝大部分都是男的，立法时不可避免是男性视角。

    * 批评强奸罪的既遂标准——接触说、插入说，认为对女性来讲都是强奸；认为区分强制猥亵罪和强奸罪没有意义；看到美女眼都盯着、口水往下流，对女性来讲也是一种强奸；主张从女性视角去改造现有的一些法律制度。

    * 女性受侵害后在审判环节还要提供证据、描述当时是怎么被侵害的，他们认为这是二次伤害，应该让对方证明他没有伤害我。

* **后现代法学（法语文学，20 世纪以后）**

    * 标一个"文学视角"：法律没有神圣性，就是一个文学活动；法院是个剧院，法官是演员，律师也是演员，坐在下头听审的人是观众，谁胜诉、谁败诉取决于谁演技好。

    * 后现代指的是颠覆传统观点，所以批判法学和法语文学都属于后现代；女权主义不是颠覆，是在男性视角之下用女性视角修复一些东西，所以没有归到后现代。

## 马克思主义法学的形成

* **19 世纪的时间轴**

    * 马克思主义法学也产生于 19 世纪；19 世纪实在是个法学派辈出的世纪。

        | 学派 | 产生时间 |
        | :--- | :--- |
        | 自然法学派 | 17、18 世纪 |
        | 分析法学派 | 19 世纪 |
        | 社会法学派 | 19 世纪 |
        | 历史法学派 | 19 世纪 |
        | 哲理法学派 | 19 世纪 |
        | 马克思主义法学 | 19 世纪 |
        | 经济分析法学派、后现代主义法学 | 20 世纪以后 |

> **易错点**："分析、历史、自然、经济分析都是 19 世纪"是错的——经济分析是 20 世纪的，自然法学派是 17、18 世纪的；19 世纪的是分析、社会、历史、哲理。

### 从理性主义到唯物主义

* **马克思主义法学的形成路线**

    * 走了一条从抽象理性走向具体物质生活条件的路：不太成熟的时期叫理性主义时期，后面是唯物主义时期，而唯物主义又分初期和成熟期。

    * 理性主义时期（年轻马克思）：受过康德和黑格尔的影响，落在理性主义里；"理性"本身就是主观时期的东西，所以理性主义这一段说到底还停留在主观、带一点唯心。

    * 唯物主义初期：《黑格尔法哲学批判》先批判年轻时自己迷恋的黑格尔——黑格尔是唯心主义，批判黑格尔就等于把唯心主义那只手从自己身上剁掉了，剁掉唯心就只能往唯物那边站，由此确立了唯物主义；核心观点是根源于物质关系。

    * 唯物主义成熟期：《共产党宣言》向资产阶级开炮，明确提出资产阶级的法就是资产阶级的意志，而这种意志归根到底受他们物质条件的支配。

    * 《资本论》：法的关系是经济关系的反映；"资本"就是各种各样的钱、各种经济因素，看到"资本"两个字就自动对应到经济。

    * 恩格斯时期的著作也提到了一些人名，扫一眼、了解即可。

* **马工程的通行表述**

    * > **定义**：唯物主义，也叫历史唯物主义。

    * > **结论**：法是统治阶级的意志，这种意志受制于物质生活条件或经济基础——这一句考点权重最高，比前面的"根源于物质"还要重点。

    * 经济基础一句话就是：重要物质归谁所有；比方说大片土地归谁所有，土地这个物质太重要了，归谁所有就是经济基础。

    * 归谁所有这件事需要由法律确认下来，统治阶级肯定要宣布归我们所有，这就是统治阶级意志；这个阶级意志一旦写成法律，就被固定下来了。

> **易错点**：资产阶级和资本不是一回事。资产阶级有资本，但资产阶级不能完全等于资本——社会主义也有资本；这一条理解到位了，《共产党宣言》和《资本论》的位置就不会搞混。

* **从物质条件理解法的解释力**

    * 唐朝法律里没有计算机犯罪的规定，不是因为当时人的理性想不到，而是物质上还没出现计算机，"计算机犯罪"这个行为都还没发生，立法者当然无从规定。

    * 秦朝执行死刑没有枪决，表面上是理性上想不到，实际上是物质上还没有手枪这类东西。

    * 立法的边界，很多时候不是理性划的，是物质条件划的。

### 四个特征

* **马克思主义法学的四个特征**

    * > **定义**：实践性、人文性、批判性、历史性。

    * 口诀：践人批历史。

        | 特征 | 一句话抓手 |
        | :--- | :--- |
        | 实践性 | 实践决定意识（实践本体论） |
        | 人文性 | 关注现实具体的人 |
        | 批判性 | 批资产阶级 |
        | 历史性 | 时间（纵向变化）＋空间（横向分布） |

* **实践性**

    * 马克思法学创立了实践本体论：实践决定意识，实践是检验真理的唯一标准；这个实践主要是改造物质的实践。

    * 实践本体论和唯物主义相伴相生：既然世界的本源是物质，那么认识这个世界的起点也只能是改造物质的活动。

    * 法律是人类实践活动的产物，而不是某种悬在概念天国的抽象理性；不要去问"法是什么"，要看人们的实践到底在干什么——改造土地就有土地相关的法律，当司机拉货开车就有运输合同相关的法律。

> **易错点**：这里有两个用词要盯住。"实践本体论"对应的是开创者；人文性那个"西方人文主义法律思想的继承者"对应的是继承者。开创和继承，一字之差，别记反。

* **人文性**

    * 马克思法学是西方人文主义法律思想的继承者；人文主义最直接的体现就是自然法学派说的"法律是人的理性"，人文主义的意思就是重视人。

    * 他关注的不是抽象的人，而是现实的具体的人——人们的具体生存需要，而不是某种抽象理性。

    * 例子：他需要车，法律就想办法通过什么方式能让他买上这辆车，不外乎是让他能挣到钱；你需要考上研究生，国家立法者就得想办法用什么样的方式选拔出这些研究生。

* **批判性**

    * 所谓批判就是批判资本主义，这一句话就行；在《共产党宣言》中对资本主义进行了非常全面的批判。

* **历史性**

    * 时间性：法律随时间变化而变化，因为物质在变，物质条件变了法律当然跟着变。

    * 空间性：不同国家有不同法律，因为面临的物质生活条件不一样。

    * 空间性反例：美国有公民使用枪支的专门规定而中国没有；中国古代农业发达，所以民商法不发达，反而是保护财产、保护人身这类刑法的规定比较发达；古罗马农业不发达但商业发达，它的民商法就相应更发达一些。

* **特征是从基本立场里推出来的**

    * 与其死背四个特征，不如记住它们是怎么来的——主张摆在前面，特征是自然长出来的。

        ```text
                主张唯物主义（历史唯物主义）
                            │
                ┌───────────┴───────────┐
                │                       │
           唯物性 ──→ 实践性      物质在变 ──→ 历史性（时间性＋空间性）

                主张阶级论
                            │
                ┌───────────┴───────────┐
                │                       │
          批判资产阶级 ──→ 批判性   解放全人类 ──→ 人文性
        ```

* **为什么用马克思主义研究法学**

    * 中国不是自然法学派，也不是社会法学派，也不是分析法学派，我们是马克思主义学派；这并不是说不研究别的学派，也不是说不能借用别的学派的方法，只是我们的立场在这儿。

    * 坚持马克思主义为指导，是中国区别于其他法学的根本标志——中国法学、法理学是姓"马"的。

    * 马克思法学揭示了法律发展的普遍规律，普遍规律就是物质决定意识。

    * 要解放全人类，这叫人文学性；方法论落点是不能等法律躺那儿不动，而要积极改变世界，让世界越来越体现人民的意志、对人民越好。

    * 马克思的唯物主义是根本的标签；唯物是马克思的标签，马克思又是我们中国的标签，所以中国的标签可以说就是唯物主义。

## 马克思主义中国化与习近平法治思想

### 毛泽东时代：国体、政体与法制思想

* **国体**

    * 毛泽东关于国体的一些学说主要见《新民主主义论》《论政策》等论著；考点是《论人民民主专政》这篇文章指出，我们的国体就是人民民主专政。

* **政体**

    * 我国的政体是人民代表大会制度；政体也叫政治体制，说的是横向的国家权力怎么分配——人民产生人大，人大再产生其他机关。

* **社会主义法制思想**

    * 这里的"法制"的"制"是制度的"制"，那时还没有提出良法善治的大思想。

    * 包括原则性、灵活性相结合（立法不要立得太死，既要有制度，同时照顾一些特殊的灵活性）、"有法可依，有法必依，依法办事"、平等、"以事实为根据，以法律为准绳"等等。

### 邓小平、江泽民、胡锦涛

* **邓小平理论**

    * 创立了中国特色社会主义法制理论；背景是 78 年以后要解放思想，在 82 年宪法中提出"中国特色社会主义"这样的词，并随之提出了一些法制理论。

* **江泽民与胡锦涛**

    * 江泽民是"三个代表"，胡锦涛是"科学发展观"；后两者是对邓小平法制理论的丰富，最终形成了体系。

    * 命题点主要在"创立"和"邓小平的首创"这两个说法上；重要观点里包含民主、党的领导等等，了解一下就行。

### 习近平法治思想的核心要义

* **集大成者与十一个坚持**

    * 习近平同志是中国特色法治理论的集大成者。

    * 核心要义是 11 个；现在中央又提出了 12 个，但大纲目前还没改，所以按大纲记 11 个。

    * 简答题"简述习近平法治思想的核心要义"，答案的简称就叫"十一个坚持"。

        | 要义 | 关键词 |
        | :--- | :--- |
        | 坚持党对法治的领导 | 党 |
        | 坚持以人民为中心 | 人民 |
        | 坚持走中国特色社会主义法治道路 | 道路 |
        | 坚持依宪治国、依宪执政 | 宪法 |
        | 坚持在法治轨道上推进国家治理体系和治理能力现代化 | 现代化 |
        | 坚持建设中国特色社会主义法治体系 | 体系、总抓手 |
        | 坚持依法治国、依法执政、依法行政共同推进 | 依法执政对执政党，依法行政对政府 |
        | 坚持"立、执、司、守"四大法治环节 | 立、执、司、守 |
        | 坚持国内法治和涉外法治 | 国内法治、涉外法治 |
        | 坚持建设高素质的法治工作队伍 | 队伍 |
        | 坚持抓住领导干部这个"关键少数" | 领导干部 |

* **内在逻辑与口诀**

    * 党是司机、把着方向，人民是乘客，得有条路；路修好了，治理国家要先有宪法（母法）；有了宪法还得在法治轨道上搞现代化；现代化要建体系，体系是"总抓手"；体系建起来，党、政府、老百姓三个层面都得依法来；依法要落到具体环节；国内还得兼顾国外；活儿得有人干，干活儿的队伍还得有人带头。

    * 前三条是一组：党解决方向问题，人民解决目的问题（为了人民、依靠人民），道路解决走什么路的问题。

    * 依法执政是说给执政党听的，依法行政是说给政府听的，三者共同推进；第八条把法治进一步具体化成了"立、执、司、守"四大环节。

    * 这 11 条主要解决两类问题：党、人民、道路解决"为了谁、谁来定、走哪条路"；第四到第十一解决"怎么落地、谁去干"。

    * 口诀：党和人民建队伍，外环路上抓干部，一体建设靠宪法。"外环路"对应国内法治和涉外法治，"一体建设"是法治国家、法治政府、法治社会一体建设，"靠宪法"是依宪治国、依宪执政。

> **提示**：第三句"一体建设靠宪法"确实不太顺口，不用在它身上纠结，前两句先背过就够了；这些内容后边章节都有详细讲解。

### 习近平法治思想的伟大意义

* **四条意义**

    * 是适应了中华民族伟大复兴要求而产生的重大理论成果——伟大复兴。

    * 是马克思主义法治理论中国化的最新成果——最新。

    * 是习近平新时代中国特色社会主义思想的重要组成部分——重要组成；习近平新时代中国特色社会主义思想可简称"习近平思想"，法治只是其中一部分，所以叫"重要组成部分"。

    * 是我们搞法治的根本遵循和行动指南——遵循和指南。

* **口诀**

    * 新媳妇很重要，要听话（新＝最新，妇谐"复兴"＝伟大复兴，重要＝重要组成，要听话＝根本遵循和行动指南）。

## 法理学：法学的一般原理与方法论

* **法理学（jurisprudence）**

    * 它站在整个法学的门口，对整个法学这个学科、以及法理学自己这个学科做一次全景式的介绍；整节就三个问题：研究对象是什么、有什么用是什么地位、方法及其意义。

### 研究对象是一般意义上的法

* **研究对象**

    * > **定义**：法理学的研究对象是一般意义上的法，即法的全部现象及其规律。

    * 一是法的整个领域或全部的法律现实：立法、执法、司法、守法、监督五个环节都研究，刑法、民法、行政法、诉讼法也都研究。

    * 二是古今中外的法：中国古代的、外国古代的，中国现代的、外国现代的，都研究。

    * 三是各部门的法：研究它们的规律、共同特征、共同范畴，为部门法提供指南；共同的比如背后都得有一个逻辑结构存在，再比如刑法、民法都分具体规则和不太具体的原则。

    * 三层压成两组八个字：研究法的一切，和一切的法。

* **边界的坑**

    * > **易错点**：这里说的是"研究结论应能解释法的一切现象"，不是说从法理学后边随便拿出一个结论来就能解释刑法、民法、行政法、刑诉、民诉。

    * 真正的意思是：假定法理学研究出了一百个原理，装在一个"百宝箱"里，你总能从中找出解释某一个部门法某些现象的理论来；但并不意味着这 100 个里的任何一个都能解释所有学科。

    * 法理学研究的东西大而全，什么都研究，所以就比较空、比较空洞，研究得没那么准确和精确——它是"广"，不是"准"；可以聊正当防卫背后的价值、制度的整个历史，但千万不要问正当防卫的构成要件。

    * 它真正能解释的样子：法理学研究安全价值，就能解释刑法分则里那些罪名在保护安全价值上承担的角色是什么，能解释民法当中侵权责任、违约责任如何保护安全价值——是某个特定原理去解释某块具体现象。

### 地位：与部门法是一般与特殊

* **法理学的地位**

    * 法理学是法学的一般原理，既是基础的原理，也是基础的方法论；这句话点出它有两个属性：理论性和方法性。

    * 它与部门法的关系是一般与特殊，为部门法的研究提供理论依据和研究方法。

    * 与法史学是"论"与"史"的关系；跟其他学科的关系了解即可，主要就是一般和特殊这个关系，再加上方法论。

* **公因式而不是零件**

    * 法理学跟部门法不是整体与部分的关系，而是把各个部门法的公因式提取出来——可以理解成公分母，提取的是各部门法里一般性的东西、他们共同的那些规律。

    * 它是"一般"从一堆"特殊"里被提出来的那个东西，而不是整体被拆下来的一个零件。

> **易错点**：是一般与特殊，不是整体与部分。整体与部分像"我"和"我这条胳膊"；法理学跟部门法不是这种关系，法理学是把各个部门法的公因式提取出来（可理解成公分母），提取的是各部门法里一般性的东西、共同的规律，是"一般"从一堆"特殊"里被提出来的那个东西，而不是整体被拆下来的一个零件。

### 方法论：根本方法与法学方法

* **根本方法**

    * 法理学告诉我们，要用马克思的方法去研究法律——辩证唯物主义、历史唯物主义；它对部门法同样有指导，搞刑法研究、搞民法研究也一样得落脚到唯物主义。

    * 立法上的唯物主义：前几年制定民法典时自媒体、大数据正在发展，不可能一劳永逸地制定出非常完善的有关数据的民法规定，立法者就得考虑物质现实的变动性，只能做一些宽泛的规定，不能拿当时的科技水平把以后的事写死。

    * 刑法解释上的唯物主义：现在开设赌场有了网络赌场，刑法的解释上就得注意这个变化，必须把开设赌场罪的打击范围扩大到网络赌场；遇到新形态要跟着物质变化去调整规范，而不是抱着老条文硬套。

> **注意**：这不等于用马克思主义哲学代替法学。除了马克思的唯物主义这个根本立场以外，还得有法学自己的一些具体方法。

* **法学自身的方法与流派对应**

    * 法学自身方法论和法学流派是具有对应关系的。

        | 方法 | 哪个学派创的 |
        | :--- | :--- |
        | 社会调查方法——看看社会现实是什么 | 社会法学派 |
        | 历史调查方法 | 历史学派 |
        | 价值分析方法——价值、精神、正义、道德 | 自然法学派 |
        | 阶级分析方法 | 马克思 |
        | 分析比较法、语义分析——分析制度里的词语、分析制度本身 | 分析法学派 |
        | 社会效益、经济效益 | 经济分析法学派 |

    * 分析法学派的研究读起来就像高中的语法书；语义分析就是分析制度里面的词语、分析制度本身。

    * 三大门派对我们既有理论上的启发，也有方法论的启发，对中国的法制建设、制度建设都有非常大的启发。

* **研究一套制度要看三样东西**

    * 一个完善的法律制度的研究，习惯上得包含三个角度——除非用经济分析法去研究制度。

        | 研究角度 | 问的是什么 |
        | :--- | :--- |
        | 制度 | 外国有什么制度 |
        | 价值 | 这个制度背后的价值和精神是什么，对人们的意义是什么 |
        | 实效 | 它在现实当中到底怎么运行的 |

    * 反面例子是"外国有这么一些制度，我们中国没有，所以我们中国应该把这个制度抄过来"——这种说法是贬义的、幼稚的，它有制度但运行得不好，拿过来有什么用。

> **结论**：研究一套制度，"国外有"只是起点，"国外跑得通"才是落点；只看到"有"、不研究它凭什么有、跑不跑得动，这样的研究是低档次的。

* **《民法典》第十条与三派融合**

    * 原文：民事法律行为应当依照法律，法律没有规定的，可以适用习惯，但不得违背公序良俗。

        | 原文 | 对应流派 |
        | :--- | :--- |
        | 应当依照法律 | 分析法学派 |
        | 法律没有规定的，可以适用习惯 | 社会法学派 |
        | 但不得违背公序良俗 | 自然法学派 |

    * 《民法典》第十条其实就是三大法学派的融合，所以考得多。
