# 法律职业与法律职业伦理

## 法律职业的含义

* **法律职业（legal profession）**

    * > **定义**：以法官、检察官、律师为代表，受过法律专业训练、具有娴熟的法律技能和法律伦理，而组成的自治性共同体。

    * 定义每一块都埋着后面的特征：以法官、检察官、律师为代表（这三种人接触法律最多、通常最专业）；受过专业训练与娴熟的法律技能同属「才」的一面；法律伦理即「德」；自治性共同体即自治。
    * 位置由来：法制建设「立、执、司、守、监」每个环节都离不开这批专业人员，专业人员除知识外还有解释、推理、论证等专业方法，故在立执司守监之后插入法律职业与法律方法。

### 三个口径

| 口径 | 范围 |
| :--- | :--- |
| 广义 | 一切受过训练、从事法律工作的人，过不过法考不重要 |
| 中义 | 以法官、检察官、律师为代表、需要过法考的那些人 |
| 狭义 | 只包括法官、检察官、律师这三种最专业的人 |

* 狭义就三个：按狭义口径，仲裁员不是狭义法律职业，公证员也不是。
* 广义的界标是「从事法律工作」：有些法律工作不需要过法考，如法考培训、法硕培训从业者只属广义，既不属中义也不属狭义。
* 教材采用的是中义观点。

> **结论**：作为概念主要背第一段定义；三口径部分知道有这么个区分、能对上号即可。

## 法律职业的四大特征

四大特征不是凭空列的，是从定义里一步步拆出来的，与概念本身同构：

```text
  技能（才）        最首要，一切由它派生
    ├─ 系统的法学教育 → 统一的法律知识 → 统一的法治观念
    ├─ 系统的法律实践 → 理论联系实际
    │
    ├─→ 伦理（德）
    │     受法律活动规律的制约
    │     受职业技能的影响
    │     ↕ 二者相互影响
    │
    ├─→ 自治
    │     自主：独立办案 · 协会自主管理
    │     独立：形成独立的知识传统
    │     ↕ 又反过来影响德才，尤其是才
    │
    └─→ 准入（门槛）  认真考察 · 获取许可证
```

### 特征之间的推导顺序

* 四个特征依次是专业性（技能）、道德性（伦理）、自治性、准入特征（门槛性），合起来就是「德才兼备」。
* 技能与伦理合称德才兼备；既然都要求德才兼备，自然推出门槛——无才之人不行。
* 德才兼备且有门槛，就进一步要求自治性，比如独立办案；之所以能独立办案，是因为别人不懂。

> **易错点**：因果方向不能倒。是技能派生了自治、派生了准入；自治和准入对技能有反哺作用，但不能说「因为有了自治，所以我有了技能」。看到因果关系的选项先查方向。

### 专业性

* 法律职业技能需要系统的法学教育：法学教育提供统一的法律知识，这是统一技能的前提；有了统一的法律知识，才有利于形成统一的法治观念。
* 法律职业技能还需要系统的实践：除学理论外还要实习、参加实务，做到理论联系实际。

### 道德性

* 法律职业伦理的特殊性在于同时受两头牵制，这是它区别于一般职业伦理之处。
* 头一头是受法律活动（职业活动）规律的制约：法律职业规律重视正义、重视程序正义。表现如律师不能因委托人罪大恶极就拒绝接受委托；证据不充分只能作无罪推定、不能作有罪推定。明知对方几乎必判死刑仍为其辩护、必要时还由国家出钱，这正是职业规律的制约。
* 另一头是受职业技能的影响：想追求正义但无法律知识，就当不成合格的法官、检察官、律师。网民判刑「死刑起步」不是缺道德，而是缺技能，不知道刑罚的层级分配问题。
* 反向也成立：道德会影响技能。专业能力学不好，追求公平正义只是口号；专业能力很高但道德素质低下，则该扩大解释时做小、该缩小时扩大，也没有用武之地。
* 职业伦理可增加职业内部的道德感、荣誉感，使法律人在内部薪火相传。

> **易错点**：技能与道德是相互影响，不是单向。凡选项只讲「技能影响道德」或只讲「道德影响技能」一半的，都要警惕。

### 自治性

* 自治包括自主和独立。
* 个人层面的自主：法律人从事法律活动有自主性，如法官独立办案、律师独立办案。
* 组织层面的自主：律协、法官协会等对律师群体、法官群体的自主治理，如对未认真办案的律师作出通报批评等纪律处分。
* 之所以必须在管理上自主：法律人有特殊专业与特殊道德，非普通人所能评判。律师为罪大恶极者辩护，交给普通人评判会人人喊打，而律协理解其专业特殊性。自治不是唱高调，是专业性必然带来的后果。
* 独立指形成独立的知识传统：自治管理造就一批专业法律人，进而形成独立的知识传统；自治又反过来影响技能和伦理，尤其是「才」。

### 准入特征

* 准入即认真考察、获取许可证，许可证就是门槛的意思。
* 常见门槛有两个：法考；上级法院遴选法官，要求德才兼备并有 5 年工作经验。

## 法考的准入范围

* 需要过法考的一共 8+1=9 类。

    * 法官、检察官、律师——最常见的三类。
    * 公证员。
    * 仲裁员。
    * 行政机关中的行政处罚决定的审核人员。
    * 行政复议人员。
    * 行政裁决人员。
    * 另 1 类是特殊的法律顾问，有在企业的也有在政府的；政府公务员中担任法律顾问的叫公职律师，其实属于广义的律师。

* 政府里只有行政处罚决定的审核人员、行政复议人员、行政裁决人员这三类需要过法考。

> **易错点**：行政处罚那边是「审核人员」不是「决定人」。公安做处罚决定本身不需过法考，但处罚决定要交法制大队审核，正式说法才是「行政处罚决定的审核人员」。

### 不得报考法考的情形

* 故意犯罪。
* 被开除公职的公务员，被吊销律师执业证、公证员执业证的。
* 被吊销法律职业资格证的，如法考证系他人代考被查出的，且被吊销后再不能考。
* 两年内不能考法考，这两年内也就从事不了法律职业。
* 严重失信、被列为联合惩戒对象的。
* 兜底条款。

> **结论**：前三条一旦出现即终身禁止考法考，也终身禁止从事法律职业。记法就两句话：故意犯罪、被开除或被吊销证照，这三条是终身。

> **注意**：这六条里没有过失犯罪。过失犯罪可以考法考，考后也能从事法律职业，但只能做律师，做不了法官、检察官。犯罪分子不一定就是坏人——防卫过当、交通肇事等未必有恶意，不能因为犯罪就断了其法律上的生路。

> **易错点**：第一条必须把「故意」两个字抠出来，这是命题点。

## 法律职业伦理的含义

* **法律职业伦理（legal professional ethics）**

    * > **定义**：法律人在职业实践中必须遵守的道德规范。

    * 伦理是人类生活关系中各种规范的总称，主要建立在良心、舆论以及习惯的基础上；本课程语境中「伦理」基本等同于「道德」。
    * 关键落在「道德」二字：它主要不靠国家强制力保障，本质是一种道德律。法律有强制力、可用制裁逼人守法；道德没有，靠的是良心、舆论、习惯。
    * 落地方式是细化为内部纪律：《法官行为规范》《检察官行为规范》《律师行为规范》用内部规范的形式，把一整套道德要求落成可操作的纪律。
    * 违反它的后果形态：往往不体现为「违法」而体现为「违纪」，落点是警告、记过这类处分，不会直接把人送进法院。

> **易错点**：《法官行为规范》《检察官行为规范》《律师行为规范》都不是法律，而是本系统的内部工作规范（最高院并非立法机关），效力来自行业纪律而不是国家强制力。

## 法官职业道德

* **法官的范围**：可以行使审判权的人员，包括各级法院的院长、副院长、审委会委员、庭长、副庭长这五类领导，以及审判员。口语里窄，制度里宽。
* **法官的根本职责**：参加合议庭。合议庭由三个以上法官，或法官加陪审员等组成；另有独任庭，由一个法官办案。

### 五德与核心三项

| 职业道德 | 切入角度 | 难度来源 |
| :--- | :--- | :--- |
| 忠诚 | 政治 | 做起来比较容易 |
| 公正 | 专业领域 | 含实体公正与程序公正，是专业要求，需大量学习与大量实践 |
| 廉洁 | 经济领域 | 在金钱与经济利益面前，一般人抵御不了诱惑 |
| 为民 | 急人之所急 | 为老百姓解决燃眉之急、提供各种便利，不容易 |
| 文明 | 形象 | 做起来比较容易，指维护司法形象 |

* 五个职业道德依次是忠诚司法事业（忠诚）、保证司法公正（公正）、确保司法廉洁（廉洁）、坚持司法住民（为民）、维护司法形象（文明）。
* 核心是中间三个：公正、廉洁、为民。忠诚与文明同样重要，但做起来比较容易。
* 「为民」的难度举例：农民工春节前起诉欠薪，按规定 30 天内审结即可，法官 3 天审结也合法；但法官要急人之所急，须加班加点、哪怕下班时间不走，熬到半夜把案件处理完。

> **结论**：五德为忠诚、公正、廉洁、为民、文明；核心是中间三个；切入角度是忠诚看政治、公正看专业、廉洁看经济、为民看急人之所急、文明看形象。

### 从案例反推角度

* 法官在企业兼职担任法律顾问：直接违反的是廉洁。兼职确实可能带来不公正，但直接违反项是廉洁。
* 法官认为自己能中立办案，因而对邻居的案件未申请回避：违反公正。回避本身就是程序公正问题；不允许质证、不允许辩论、重罪轻判、轻罪重判也都属公正问题。
* 法官在案件审结之后接受当事人宴请：仍违反廉洁。职业伦理要求全天候二十四小时有效，不能只在办案期间廉洁，否则当事人送礼完全可以拖到审结之后再送。
* 法官在任职期间接受政治理论业务培训：体现的是文明，而不是花天酒地的法官和检察官。

### 法官义务

* 控权：依法接受监督，监督包括国家监督和社会监督。
* 保民：依法保障当事人的诉讼权利，即程序公正；维护当事人的合法利益，即实体公正。
* 守法：严格遵守宪法和法律；依法办案、秉公办案；通过办案以案释法，增强全民法治观念。
* 保密：遵守纪律，如保密，保守国家秘密、商业秘密、个人隐私。

## 检察官职业道德

* **检察官的范围**：行使检察权的检察人员，包括各级检察院的检察长、副检察长、检委会委员，以及检察员。检察院不设民庭、刑庭，没有庭，故没有庭长；其余三项与法院对应，再往下同样是检察员。
* **检察官的职责**：法律监督，检察院因此是专门法律监督机关。监督手段包括提起公诉（对刑事案件）、抗诉等，以及依法对特定刑事案件自行侦查。

### 五德与「多担当少文明」

| 职业道德 | 含义 |
| :--- | :--- |
| 忠诚 | 忠诚于党、忠诚于人民、忠诚于国家；不能白天依法办案、晚上回家发帖子骂中国法律 |
| 为民 | 与法官的为民一致 |
| 担当 | 法官没有此项要求，检察官有 |
| 公正 | 与法官一致 |
| 廉洁 | 与法官一致 |

* 检察官的五德是忠诚、为民、担当、公正、廉洁；与法官的五德相比，多一个担当、少一个文明。
* 检察官的「文明」被吸收进「为民」，换来一个「担当」，写成五五对仗是为了掐掉形式上的误读：若写成六条，就会让人从形式上觉得检察官比法官多一条、要求更高。
* 所以并不是检察官可以不文明，文明维度已被并入为民。

### 担当

* > **定义**：担当主要指勇气，两句话——敢办案，敢认错。

* 敢办案：案件很难很复杂、别人都不想办（政法委书记打电话、省委书记打电话、涉黑社会性质组织犯罪），有人说一句「这案子我办了」。
* 敢认错：办着办着出了错，「错误是我的」。
* 见义勇为：法官与检察官在路上遇到有人偷钱，检察官必须挺身而出，法官可以在旁边看且不受纪律处分；检察官若同样看热闹则要受纪律处分。
* 法官同样要敢办，只是没有被专门拎出来提出更高要求。

## 律师的定位与特征

* **律师（lawyer）**

    * > **定义**：取得律师执业证以后，接受委托或指定，为当事人提供法律服务的执业人员。

    * 两个关键词：委托或指定、服务。律师属于服务人员，不是公务员。
    * 案件来源两种：当事人自己委托，即签署委托合同；指定辩护，用于可能被判死刑、无期徒刑以及未成年人、残疾人等当事人未委托的案件。
    * 指定辩护的链条：法院告诉法律援助机构（各地法律援助中心，主管机关是司法局），由法律援助机构给当事人指定律师。法院任何情况下都不能直接给当事人介绍律师。
    * 特征三条：有技能特征，是有专业技能的人；有准入特征，持律师执业证——过法考还不够，还须在律所实习满一年、再经律协考核；为社会提供法律服务的人，属专业服务行业。

## 律师义务

* **不能害自己与对方的当事人**

    * 不得私自接受委托、私自收钱，简称收私钱。当事人只能与律所签合同，再由律所委派律师，以形成律所的单位行为；律师因故意或重大过失致当事人损害的，由律所承担赔偿责任，赔完再向律师追偿，等同单位侵权责任。律所与律师是用人单位与劳动者关系，钱应打到单位账户。
    * 不得利用提供法律服务的便利，牟取当事人争议的利益。例：代理一起奔驰车归属争议，却约定结案后按市场价十万买下该车——没有不公平也不允许，因为律师一旦牟取争议利益就不再是代理人，而成为潜在当事人，身份改变会影响服务质量，甚至催生歪门邪道。
    * 不得接受对方的钱并与对方恶意串通，侵害委托人权利，即收黑钱、吃里扒外。
    * 不得故意搞假证据等，妨害对方当事人取得证据；自己的委托人不能搞，对方当事人也不能搞。

* **不能害裁判人员**

    * 不得违反规定会见法官、检察官、仲裁员等，即不得私下接触。理由是可能发生利益交换；即使没有利益交换也违反道德，会被人怀疑，而违反职业道德会转化为单位纪律处分（警告、记过）。法官与律师双向适用，检察官等同样在内。
    * 避无可避时的处理顺序：第一，能避就得避，譬如换桌；第二，避不了也得立即向所在单位报告，否则可能受纪律处分。案例：法官与正在办同一案件的律师在同学婚礼上被安排同坐一桌，正确做法是换桌；装作不认识坐下就吃全程不说话、可以聊天但不聊案子，都不行。
    * 不得向法官、检察官、仲裁员等行贿、介绍贿赂、诱使行贿；反向地，法官、检察官也不得索贿。

* **不能害社会**

    * 不得煽动、教唆当事人以扰乱公共秩序等方式解决争议。例：怂恿当事人「国家司法环境不好，明天到法院门前自焚」，将受纪律处分；真自焚还要承担放火等法律责任。
    * 不得扰乱法庭、仲裁庭秩序。咆哮公堂不行；法官、检察官批评几句后愤而退庭同样违反职业道德——有义务使法庭、仲裁庭顺畅走完，被批评的事可以休庭后再举报。

## 律师职业道德

* 忠诚：忠诚于政治上的道德，律师虽是维护当事人利益的群体，也不能反党、反社会、反国家。
* 执业为民：即为民、便民的意思。
* 信仰法治：包含法律至上、依法办案，以及业务能力精湛、技能高超、技能专业。
* 维护正义：接近公平正义，同样属专业角度。
* 诚信：不要骗人。
* 爱岗敬业。

> **结论**：这六个大致对应四个侧面——政治角度（忠诚）、便民角度（执业为民）、专业角度（信仰法治中的法律至上与技能专业、维护正义）、日常操守角度（诚信、爱岗敬业）。

## 同质性与行业特殊性

* **同质性**：法律职业伦理的第一个性质，即相同。忠诚、便民、依法办案、技能专业、诚信、敬业，法官检察官都有对应要求，只是换了词表述；律师职业道德与法官职业道德大量重合，重合才是对的，因为大家都是法律职业人。

| 职业 | 职业道德 | 行业特殊性 |
| :--- | :--- | :--- |
| 法官（5 项） | 忠诚、公正、廉洁、为民、文明 | 行使审判权，必须中立；另有「文明」（维护司法形象） |
| 检察官（5 项） | 忠诚、公正、廉洁、为民、担当 | 行使检察权，必须中立；以「担当」替下「文明」，不写成 6 项 |
| 律师（6 项） | 忠诚、执业为民、信仰法治、维护正义、诚信、爱岗敬业 | 无中立要求，须在合法前提下最大限度维护委托人利益 |

* 律师没有中立要求：收了委托人的钱就必须维护委托人利益，声称在双方之间保持中立等于不履行职责。
* 法官、检察官则不能站在原告人或被告人任何一拨。

> **易错点**：检察官那一格里的「担当」是拿「文明」换来的，不是凭空多一条，不要被「6 比 5」的形式唬住。

## 兼职与伦理判定规则

* 法官、检察官在兼职问题上的规则：营利组织兼职绝对禁止，非营利组织兼职相对禁止；相对禁止即不得收取报酬。
* 在高校兼职当硕导、博导可以，领取报酬不行；律师不是公务员，可以领取报酬，高校因此更愿意请法官、检察官兼职。
* 检察官在刊物上发表文章评论正在审理的案件：干扰中立性，违反公正。
* 命题已从死记硬背职业伦理名称转为给出小案例反推角度，依据正是公正看专业、廉洁看经济、为民看急人之所急这套切入角度。
