# 立法制度：概念、原则与程序

## 立法的概念

### 立法动作的四个内容

* **立法（又称法的制定、法的创制、法的创立）**

    * > **定义**：有立法权的国家机关或经授权的国家机关，依照法定权限和程序，创制、认可、修改、废止法律和其他规范性法律文件的专门活动。

    * 概念骨架＝主体、权限、程序、内容，再加一个本质。

    * 内容的四个动作简称"立改废认"：创制（造一个新的出来）、认可（把原来就有的如习惯法认下来、赋予法律地位）、修改（改完出来的仍是一个"新的"，所以修改本身就是立法）、废止（废掉之后要不要再立新的取决于社会需要）。

    * 本质：法律是国家意志的体现，国家意志是法律的外套外衣。

    * > **易错点**：题干问"立法就是指法的创制这个动作"并说它正确——错。名称上只叫创制，动作上却是"立改废认"四个。

```text
立法的概念
├─ 主体：有立法权的国家机关 / 经授权的国家机关
├─ 权限：依照法定权限
├─ 程序：依照法定程序
├─ 内容：创制、认可、修改、废止  →  简称"立改废认"
└─ 本质：法律是国家意志的体现，国家意志是法律的外套外衣
```

* **名称与动作的不对称**

    * 定义里动作有四个，起名字时却只叫"法的创制"，属于名不副实。

    * 原因是四个动作中**创制是主流的、是最常见的**，所以拿它当了名字。

    * 类比：炒股有涨有跌，但因为跌占主流，被形象地叫作"马爹"；涨的时候也有，只不过不是主流。

### 立法主体的两条边界

* **两类立法机关**

    * 一类是有立法权的国家机关，另一类是经授权的国家机关，即授权立法。

    * 授权立法绝不限于经济特区，举例时不要只举一个。

* **国家意志这一道门槛**

    * 只有上升为国家意志的活动才配叫立法，披上国家这件外衣才叫立法。

    * 没披上国家外衣的只是机关内部文件，立法机关的内部工作、内部流程都不能叫立法。

    * > **易错点**：立法机关发的所有文件都是立法——错。比如本机关春节放假期间的轮流值班规定，是内部工作文件，跟立法八竿子打不着。

* **指导性案例的效力定位**

    * 指导性案例属于判例中的一种，是判例里"战斗机中的战斗机"、判例中的"歼-20"。

    * 判例没有普遍的法律约束力，有普遍约束力的只能是规范性法律文件。

    * 指导性案例对法院只有参照力，不具有普遍的法律效力，所以连广义的立法都算不上。

* **关于立法主体的常见错项**

    * 把立法主体说成"国家机关和社会组织"是错的，立法主体是特定的国家机关，而且并非所有国家机关都有立法权。

    * 社会组织在一定条件下可能有执法权，但不会有立法权，因为立法权是决策权、是最根本的权力。共青团、工会、红十字会都没有立法权。

    * "最高国家权力机关依照法定权限和程序，制定规范性法律文件的活动"仅仅涵盖狭义立法，不全面。

    * 正确表述是：在我国，依照法定权限和程序制定法律的活动。

    * "在现代社会不产生国家意志的活动也叫法律制定"是错的。

    * "从本质上讲，法律制定就是国家机关运用专门技术"是错的，本质是意志上升为国家意志。

    * 背景补充：中央机关既有党的机关也有中央国家机关，构成国家机关的双线体系。省委是党的机关，省人大常委会是人大的大管家；最高院称院长、最高检称检察长、中央军委称主席。

### 广义立法与狭义立法

* **法律有广义与狭义之分，立法概念随之对应划分**

    * 狭义的立法＝制定狭义法律即宪法和国家法律的活动。

    * 广义的立法＝制定广义法律的活动，既包括制定，也包括认可、废止。

    * 这两组概念是对应关系，选择题常从对位关系设题，对不上的直接排除。

## 立法的特征

### 六大特征的推导结构

* **特征＝四件套＋技术＋本质**

    * 立法概念里的主体、权限、程序、内容构成常用四件套，教材在特征这一栏又把立法技术单独拎出来一项，于是成为六个特征。

    * 到特征的推导逻辑就闭合了：本质＋四件套，只不过四件套这里又加了一个技术，用来强调语法、逻辑、体例。

    * 备考应透过后面的规律自己捋一遍，再用教材内容完善，不要死记硬背。

```text
立法的概念（四件套 + 本质）
        │
        ├──▶ 特征 1 国家的一项专门活动    ← 权限
        ├──▶ 特征 2 主体是特定的国家机关  ← 主体
        ├──▶ 特征 3 依照法定（严格）程序  ← 程序
        ├──▶ 特征 4 运用专门技术        ← 四件套之外单拎出来
        ├──▶ 特征 5 多层次、系统的活动  ← 内容
        └──▶ 特征 6 本质                ← 本质
```

### 国家的一项专门活动

* **"专门"指有独立性**

    * 立法不是辅助活动，不是一边干本职工作一边顺便干干的事。

    * 国家的专门活动大致有立法、执法、司法几块，我国还有监察，都是专门的。

* **立法权属于决策权**

    * 立法机关先设计好制度框架，再交给政府执行、交给法院判断执行得怎么样、老百姓遵守得怎么样。

    * 决策权、执行权、判断权构成国家的基本结构，是当今世界通行的权力设计模式。

    * 对应我国：决策权除少数特殊立法机关外一般是人大级别，最常见的是人大体系；执行权最常见的是政府及政府部门；判断权最简单的是法院，此外还有检察院。

    * 决策权是前提，我定好了你才能去执行，我定好了你才能拿着我的东西去判断他们执行得怎么样。

* **立法职能的地位**

    * 国家职能主要包括立法职能、行政职能、司法职能，我国还有监察职能。

    * 其中立法职能最根本，是其他职能的前提和基础，具体表现为为其他职能提供了制度前提、制度基础。

### 主体是特定的国家机关

* **立法权由特定机关专有**

    * 立法权是国家权力当中最核心的权力，只有特定的国家机关专有。

    * 一个国家里不是所有机关都有立法权，有立法权的是本来就有立法权的机关，加上本来没有但被授权的机关。

    * 要背的是标题加后面这句：立法权是最重要、最核心的权力，只能由特定的国家机关专有。

    * > **易错点**：最高院、最高检没有立法权，因此它们做司法解释这个活动不能叫立法；虽然作出的司法解释有法律一样的效力，但活动本身不叫立法。

### 依照法定程序

* **关键词是"严格"，写"固定"也行**

    * 立法机关虽是决策机关，但毕竟是公权力机关，都要受法定程序的制约，不能滥用立法权。

    * 要达到的效果是保证社会关系的稳定性。

    * 现代法治国家都注重立法程序的规范化、格式化；"格式化"其实就是"法定化"，规范化和格式化是一回事。

    * > **易错点**：立法解释不是按立法程序做的，因此立法解释也不能叫立法，因为它既不是创造一个新条文，也不是废掉一个条文，只是对现有条文作说明。

### 运用专门技术

* **立法技术是单独拎出来的一项**

    * 要背的一句：立法技术的运用直接关系立法效果好坏。

    * 教材强调立法技术不仅是形式问题，它直接关系立法效果的好坏。

    * 举立法表达技术的例子：表达技术分语法、逻辑，还分体例如篇、章、节、条、项。

    * 立法者不讲语法就谈不上立法，不讲逻辑就无法表达法律规则的逻辑结构，体例也必须统一：《民法典》一路排到"编、章、节、条、项"，《刑法》只排到"编、章、节、条"，这样法律的体例才统一。

    * 体例不统一当然会直接影响立法效果。

### 多层次系统的活动与本质

* **内容的多样性**

    * 既包括创制新的，也包括认可原来的，还包括修改、补充以及终止，终止就是废止的意思。

    * "补充"也是一种修改的方式，修改立法就是对立法的补充，这个"补"可写可不写。

    * 在内容这一栏里，最起码的四大动作"立改废认"跑不掉。

* **立法的本质**

    * 立法的目的必须得产生具有普遍性的、国家强制性的法律规范。

## 立法体制

### 立法权限的划分

* **立法体制的含义**

    * 立法体制就是立法权的配置制度，其核心是立法权限的划分。

    * "体制"记住它的意思就行，即分配，或者说分工。同构的例子：经济体制是国家的大量资源分配给谁，执法体制是执法权怎么分配，立法体制就是立法权怎么分配。

    * 在我国它分成人大的立法权、国务院的立法权、地方人大的立法权、地方政府的立法权等等。

* **划分的两个方向**

| 划分方向 | 具体所指 | 例 |
| :--- | :--- | :--- |
| 纵向划分 | 中央国家机关与地方国家机关之间的立法权划分 | 全国人大与省人大 |
| 横向划分 | 中央国家机关之间、地方国家机关之间的立法权限划分 | 全国人大、国务院、中央军委；省人大及常委会 |

* **要背的落点**

    * 这块要背的是"核心是立法权限的划分"，纵向、横向顺便记一下，整体属于理解性内容。

### 决定立法体制的因素

* **国家性质即国家的本质**

    * 我国本质是人民民主专政，人民民主专政就是人民主权，人民是老大。

    * 既然人民是主人，而立法权又是最根本的权力，那最高的立法权肯定归人民所有，由此派生出人大的立法权限。

    * 人民不可能十四亿人都来立法，人民派代表组成人大，由人大行使立法权限，这就是国家性质在起作用。

* **国家结构即纵向的央地关系**

    * 央地关系是父子关系，所以中央的法律一般情况下肯定高于地方法律。

    * 用省人大打比方：省人大及常委会的"亲爹"是全国人大及常委会，上面还有个"叔叔"叫国务院，还有最高院、最高检；上面这些机关级别肯定比它高，只不过不是亲爹、不是直接机关，一般情况下不能直接管它。

    * > **提示**：这里用土话讲是父子关系，写到卷面上要换成书面用语——中央统一领导。

* **文化传统等因素**

    * 中国的文化传统是大一统的文化传统，从秦以来就是民族大一统；大一统意味着中央和地方是一个统一整体。

    * > **注意**：原文"文化传统"后面有个"等"字，影响立法权分配的不止这几个因素，比如经济因素；其中影响最明显的是国家结构。

### 政体与立法体制的对应

* **单一制配一元**

    * 单一制就是父子关系，中央一个爹，地方上各有各的孩子，地方服从中央。

    * 单一制国家一般是一元立法体制。

* **联邦制配多元**

    * 联邦制下中央和地方不是父子关系，而是兄弟关系；弟弟不必完全服从大哥，何况还不是近亲兄弟。

    * 以美国为例：联邦有联邦，还有 50 个州，联邦管联邦的事、州管州内的事；涉及全美意义的事由联邦管，如公民基本权利保障、关税；州内的事由本州管，如律师资格考试通过率有的州 90% 有的州 40%，教育上给学校拨多少款、扶持公立还是私立。

    * 美国是联邦加 50 个州，所以有 51 部宪法、51 套议会，联邦有联邦最高法院，州有州最高法院。

    * 众议院和参议院是美国的联邦立法机关，州也有自己的议会，州内的事州自己定。

    * 这种立法体系不能叫统一，至少是二元、多元，甚至 51 元，所以有"二元、多元立法体制"的说法。

* **落到一句结论**

    * 单一制对应一元，联邦制对应二元以上；一个国家的立法体制受多种因素影响，其中国家结构的影响非常明显。

### 我国立法体制的内容

* **既统一又分层的立法体制**

    * 我国是单一制，但不能叫一元立法体制；一元立法体制指只有中央有立法权、地方全听中央的，朝鲜属于这种情况。

    * 我国在这个基础上叫既统一又分层的立法体制，既要统一，又要分层，这是重点。

    * > **注意**：按 2016 年之前的考试分析，我国立法体制叫"一元"；2017 年之后改叫"统一又分层"。做 2016 年之前的真题时说"我国实行人民代表大会制度主导的一元立法体制"那时没错，现在不能这么说。

* **各类主体的立法权限**

| 行使主体 | 可以立什么 |
| :--- | :--- |
| 全国人大及常委会 | 统一行使国家立法权 |
| 国务院 | 制定行政法规 |
| 中央军委 | 制定军事法规 |
| 省级和市级人大及常委会 | 制定地方性法规 |
| 民族自治地方人大 | 民族自治法规，即自治条例、单行条例 |
| 经济特区所在的省市人大及常委会 | 经济特区法规 |
| 其他 | 省市规章、监察法规、特别行政区等 |

    * 第一项要死死盯住五个字：国家立法权。国家立法权专指狭义的法律。

    * 后几项属于授权立法。

    * > **易错点**：说"国务院有国家立法权"是错的。言外之意是国务院的立法权限将来有可能没有，而人大及常委会的立法权一直有，因为它是最正牌的立法机关；教材下边就不这么写，下边叫"赋予国务院制定行政法规的权利"。

* **与正式渊源分类的关系**

    * 对具体立法体制的罗列和前面的正式渊源分类基本等同，只说"基本"是因为宪法不能算作普通的立法体制。

    * 这还是不完全列举：只列举了法律、行政法规、地方性法规、民族法规和经济特区法规，没有罗列监察法规、军事法规、规章、特别行政区等，没罗列的当然也属于我国立法体制。

    * 两者重合是因为正式渊源不就是立法的产物，立法权的分工产生了不同的正式渊源。

    * 掌握办法：在教材这一串旁边标一个"约等于正式渊源分类"即可；万一考到就顺着往下列。

### 既统一又分层的理由

* **第一，我国是单一制国家，决定了立法权必须集中于中央。**

    * 书面语写作中央统一领导。

* **第二，我国又实行人大制度，决定了立法权必须集中于国家权力机关。**

    * 人大制度指国家的公权力来源：人民给人大，人大产生常委会，再由人大给政府、法院、检察院、监察委等其他机关。

    * 既然是人大，在同级机关里人大就是带头大哥、是老大哥，立法权当然要集中在人大。

    * 这解释了"一集中在中央，二集中在人大"。

* **第三，我国地域辽阔、人口众多，各地经济政治文化社会情况不相同，因此要赋予地方国家机关立法权。**

    * 同时还有少数民族的特殊情况，要给民族自治地方立法权。

    * > **注意**："地域辽阔、人口众多、经济、政治、文化、社会"这几个词看着平淡但必须背，它回答的正是为什么要给地方特殊立法权限。

    * 这一条能倒过来用：地方既有差异也有相同，论述地方联合立法时答案就在经济、政治、文化、社会这几个词里，再加上生态就是五大文明全了——有利于两地经济共同发展、有利于政治上的统一、有利于文化上的交流、有利于实现社会和谐、有利于生态文明。

* **第四，我国还搞改革开放，法律并不完备，决定了不能仅仅集中在人大手里。**

    * 还要给某些行政机关（注意是某些不是所有）以及某些地方或者经济特区立法权限。

    * 理由是行政机关效率更高、反应比较及时：人大一年开一次会，一年 365 天就 5 天上班；有常委会但它两个月开一次会，一年才开六次。

    * 经济变化太快了，所以还要给行政机关以及部分经济特区立法权限，以适应改革开放的需要，它叫体制改革和对外开放。

* **记忆线索**

    * 单一制派生出中央，人大体制派生出人大，第三地方有特殊性，第四改革开放变化快。

    * 三和四都是特殊情况：地方特殊性给地方立法权，民族特殊性给民族立法权，变化快就给政府和经济特区立法权。

### 党领导立法与人大主导立法

* **党领导立法：五个动作都是外围**

    * 党的领导本来就要贯彻到立法的全过程各方面，党要领导立法、领导执法、领导司法没什么大惊小怪。

    * 党在立法上的领导主要是政治领导，具体包括五件事：确定立法工作的方针即政策；批准立法规划；提出立法工作建议；明确立法工作的重大问题；加强立法队伍建设。

    * 批准立法规划是因为全国人大常委会的立法规划不一定写得那么好，由党的组织把关，既体现民主又能弥补局限性。

    * 提出立法工作建议如告诉常委会立法时一定要让老百姓畅所欲言、可以建立基层立法联系点。

    * 加强立法队伍建设是让搞立法的人常学党的政策、国家政策，知道下一步往哪个方向走。

    * > **易错点**：党领导立法，但党自己不立法。

    * 五件事都是外围的，一件都不是立法权限；人大是行使立法权的，球往哪个方向滚才是党的领导。

    * 简记为方针政策、规划、建议、明确问题、队伍建设；这一段近乎万能原理，党对立法的领导、党对其他什么的领导都是这几个动作，按题目替换关键词即可，例如论述党的领导和法治政府建设的关系，就把立法换成政府、把立法队伍换成执法队伍。

    * 客观题可考点少，主观题上很好用。

* **人大主导立法**

    * 人大主导里最高的是全国人大：因为我国是单一制所以集中在中央，因为实行人大制所以集中在中央的人大，即全国人大。

    * 后文说全国人大及常委会处于核心地位，说"根本地位"也行。

    * 表现有两行：全国人大及常委会行使的叫国家立法权；省级人大和市级人大及常委会行使地方性法规的立法权。

* **两者的关系**

    * 党领导立法和人大主导立法是统一关系，不是矛盾关系。

    * 加强党对立法工作的领导和人大主导立法是我国立法工作的根本原则，同时也是一个科学总结，它是党的领导以人民当家作主的表现，往下再看"相辅相成、并不矛盾"就够了。

## 立法原则

### 原则的定位与通用拆法

* **原则是宏观层面的要求**

    * "原则"指基础的、本源的、综合的、稳定的大的要求。

    * 执法原则、司法原则都存在，它们既包括主体上的限制，也包括权限、程序这些限制，在实践中往往写成具体规则或者笼统的宏观原则。

    * 立法原则的本质是在限制和规范立法权的行使。

    * 普通老百姓守法没有原则，因为原则这个板块是给掌握权力的人设的，国家把法写好、老百姓照着做就行。

    * > **提示**：整套体系里有立法原则、执法原则、司法原则，偏偏在守法这一环没有"原则"这个板块，这不是教材漏掉，是权力配置的逻辑本来如此。

* **大纲规定的三条立法原则**

    * 合宪和国家法制统一。

    * 反映人民利益、要求和愿望。

    * 科学。

    * 合宪和国家法制统一又简称立法的合法原则。

* **通用拆法：主体、权限、程序、内容**

    * 法理学里几乎所有原则的定义，拆开来都是同一副骨架。

    * 主体特指立法机关，是广义的立法机关，既包括人大，也包括有立法权的行政机关等。

    * 权限是在创制法律过程中行使立法权。

    * 程序是创制法律时既要行使立法权，也要遵守程序。

    * 内容写的是"规定、原则和精神"，写成"规则、原则和价值"是同义词。

    * > **提示**：数量最多的是规则，规则是原则的具体化，原则又是价值和精神的具体化；法条写"原则和精神规定"，讲的就是这个层级的下移。

```text
┌────────────┬──────────────┬────────────┬──────────────────┐
│    主体    │     权限     │    程序    │       内容       │
├────────────┼──────────────┼────────────┼──────────────────┤
│  立法机关  │  行使立法权  │  遵守程序  │ 规定/原则/精神   │
└────────────┴──────────────┴────────────┴──────────────────┘
```

### 合宪与依法立法

* **合法性原则的含义**

    * 行使立法权要符合法律的规定、不能滥用，同时还要遵守国家的法律，保证法制统一。

    * 它是保障立法合法性的重要原则，位置排在首要。

* **合宪：符合宪法**

    * "合"就是符合，合宪就是符合宪法。

    * 定义里之所以出现主体、权限、程序，是因为立法活动本身就是立法机关在创制法律的过程中行使立法权、同时遵守程序，定义只不过把"规则"换成了"规定、原则和精神"。

    * 例：某省地方法规为服务当地经济建设，规定省法院和省检察院要设立招商引资部门——它不能规定国家机关的组织和权力，因为这属于法律保留领域，是法律保留给国家机关组织法去规定的东西，这条地方性法规超越了权限。

    * > **易错点**：合宪这条要求落到题目里就是判断主体、权限、程序、内容这四项有没有越界；超越权限、违反法律保留、违反程序，都可以在合宪这条线上挂上。

* **依法立法：遵守立法法但不限于立法法**

    * 之所以单独把《立法法》拎出来讲，是因为立法法是粗线条的宏观规定，而光有粗线条的宏观规定还不够，还得有细化的法律跟上。

    * 现行《立法法》里广泛规定了立法原则、主体、权限、程序等一大堆东西；说要遵守母法的粗线条规定当然要遵守，但真正落到操作上还得遵守那些把粗线条细化了的一部部具体法律，这就是依法立法要分成层次理解的原因。

    * > **易错点**：依法立法的这个"法"不限《立法法》。说立法机关应当遵循《立法法」对，说应当仅仅遵循《立法法》错，《行政法规制定条例》就比《立法法》又更细化了一层。

    * 要背的是第一行：遵守《立法法》。

### 国家法制统一

* **含义与由来**

    * 合宪原则自然而然地派生出了法制统一原则。

    * 拆开仍是那副骨架：主体是立法机关，权限是法定权限，程序是法定程序，内容是"统一"。

    * 怎么统一：在维护国家统一的前提下，维护国家整体利益（也可说国家统一利益），从而维护法制的统一、尊严和权威。

    * > **提示**："统一、权威"和"统一、尊严和权威"两种写法可互换，法治的尊严与法治的权威没什么差别；维护了统一，不就有权威了吗，权威肯定不是四分五裂的。

* **三种统一的表现**

| 表现 | 又叫什么 | 具体指什么 |
| :--- | :--- | :--- |
| 纵向的统一 | 渊源统一 | 宪法是老大，法律其次，行政法规再次；下位法不能违反上位法 |
| 横向的统一 | 部门统一 | 刑法、民法、行政法等各法律部门之间相互协调一致 |
| 内部的和谐统一 | 要素统一 | 一部法律内部的零件（法律要素）之间要和谐，规则和原则之间形成统一 |

    * "立法机关创设的法律应该内部和谐统一"，内部和谐指的就是要素统一。

    * "整个体系内各项法律法规之间衔接统一"既包括纵向之间也包括横向部门之间要相互统一，衔接、协调、一致其实都是统一的意思。

    * 讲国家法制统一原则，实际上就是要素统一、渊源统一、部门统一这三条的汇总，三样最终都统一到一处：维护国家整体利益，从而维护法制的统一、尊严和权威。

* **名称的三个层次**

    * 合宪和国家法制统一原则简称"合宪和统一原则"，又简称合法原则。

    * 它包括合宪、立法法、统一三个要求，这三个定义都要背。

### 反映人民利益、要求和愿望

* **两条关键句**

    * 从最广大人民的最根本利益出发，体现人民意志，背到这两句就够用。

    * 定义的骨架顺序被换了一下：内容叫反映人民利益、要求和愿望；立法机关要与群众相结合把主体框出来；下面的立法活动就是权限和程序。

* **内容：法律的目的是保民**

    * 法律的目的在于保障人民的自由，而不是立法者想方设法地怎么限制公民；有了权利在先才谈得上一些限制措施，这个顺序不能倒过来。

    * 教材引的那条法条写得比教材本身更丰满，里面还有"全过程……促进公平正义"的表述，教材没有采用但仍要留意，因为客观题甚至主观题都有可能直接考法条。

    * "公平正义"正是人民利益、要求和愿望的具体化：老百姓最关心的就是要公平、要正义，但不能让一部分人一直那么富、让另一部分人一直那么穷。

    * > **易错点**：别因为"我们背的教材上没有"就不敢选。想减轻背诵压力，就把"全过程"和"公平正义"两点一勾、连在一起，记住它们属于人民利益的具体化。

* **主体：立法机关不是人民**

    * 立法权的行使主体是立法机关，立法机关不可能是某一个人，也不可能是某个专制的组织，所以要选举产生。

    * > **易错点**：人民不叫立法主体。考试特别爱在这里设选项，说某人、某组织是立法主体就是错的。

    * 落在主体上就是"立法主体的产生"，特指立法机关。

* **权限与程序：公开、审议、参与**

    * 公开：《立法法》规定法律草案及其起草、修改的说明要向社会公布征求意见，特殊情况下除外；征求意见的时间一般不少于 `30 天`。

    * 征求意见的情况还得向社会反馈，把"反馈"一勾就是"向社会通报"，有来有往双方才能感受到被尊重；不吸收总得让老百姓知道，否则下次他就没有参与的动力了。

    * 审议的时候要决定哪些意见要吸收。

    * 参与：人民群众通过各种途径参与立法，如设基层立法联系点、老百姓信箱、立法热线、立法的征求意见电子邮箱；立法活动要为公民参与提供方便的途径，我国《立法法》据此规定了基层立法联系点制度，它是用来听取老百姓意见的。

    * > **提示**：`30 天` 这类细节属于超纲，但考过主观题，所以要记。

    * > **注意**：区分"公开"和"保障参与"这两层。公开是草案征求意见以及反馈、审议表决，保障参与是给老百姓提供便利的渠道。

* **可作例证的立法**

    * 反家庭暴力法就是老百姓提出来的：光警告不听话就罚款，表面看是对的，但生活条件困难的家庭，孩子宁愿被打也不愿让罚他爹妈的钱。

### 科学原则的出发点

* **为什么科学原则必须单列**

    * 光讲反映人民利益还不够，有时候老百姓的一些认识可能科学性不足。

    * 例：普通老百姓普遍认为拐卖妇女儿童一律处死刑，但不科学。刑法只有设置了由轻到重的层级，才能及时挽救那些被拐卖的妇女儿童，也给犯罪分子一条再生之路。

    * 真规定一律处死，犯罪分子感受到自己要被抓的危险，立马会把妇女儿童都杀掉，反正也是一死，多拉几个垫背的他还赚了。

* **总要求**

    * 科学原则主要包括立法要从实际出发、尊重客观规律，从而保证立法的科学性。

    * 马克思说，立法者应该把自己看作自然科学家，他不是在创造法律，也不是在发明法律，而仅仅是在表述法律。

    * "仅仅是在表述法律"就是立法者把客观规律翻译成法条、把客观需要转化成法律，法律不是凭空产生的，要立足于社会的实际需要。

    * > **易错点**：这句话不要理解成立法者都应该懂自然科学知识。它讲的是工作上的类似——立法者也是把客观规律、客观需要翻译成法条而已，没有要求立法者都懂自然科学。

* **第一条：从我国现实国情出发**

    * 适应经济社会以及改革要求。

    * "现实国情"怎么具体化？就是五大文明的角度：经济、政治、文化、社会、生态。

    * 例：经济状况跟前些年相比在放缓或呈现一定程度低迷，这就是现实国情在经济上的表现；立法者就要考虑是让大家多存点钱还是少存点、多花钱，什么样的立法才是从实际出发的。

* **第二条：尊重和反映客观规律**

    * 客观规律同样是这五大文明的规律，可以加个注解：五大文明规律。

    * > **易错点**：从实际出发不等于尊重客观规律，这是两件事。环境受到污染破坏所以要通过立法保护环境，但不能立法说所有有污染的企业都到月球上去，那违背客观规律；"只要有过污染的企业一律关停"同样违背客观规律。

### 科学原则的内在要求

* **第一，坚持权利本位**

    * 把保障权利作为权利义务的出发点。

    * "权利本位"意味着保障自由和人权。法律目的是保民、保障人民的自由，而不是想方设法限制公民；应该是为了保障权利从而有一些限制措施，不能倒过来。

    * 最典型的权利本位就是民法：民法立法者上来肯定先说公民有哪些权利，而不是一上来说这个不能干、那个不能干。

    * 反例：某市人大因食品安全问题严重，规定凡在本市开饭店的先交 5 万元食品安全保证金。这不是以权利为本位，而是增加了经营者的义务；开个小饭店卖饺子馄饨炒饼面条先交 5 万保证金，谁还去做这些小生意，老百姓日常生活的便利性会受到极大影响。

    * 立法者应该想的是如何鼓励人们开饭店、商场、小店并提供方便，食品安全问题可以再想别的办法，而不是先留买路财；这与黑社会收保护费没有区别，权利本位就是要把人当人看。

* **第二，考虑权利义务的平衡**

    * 也就是权利义务的一致性。

    * 以权利为本位不能只规定权利不规定义务，也不能规定太重的义务使义务压过权利。

    * 谁违法都得要承担责任，这就是平等，平等是权利义务一致性主要表现之一。

* **第三，考虑弱势群体的实际承受能力**

    * 这就是对弱者的特殊保护，最典型的是正义、实质平等。

    * 立法就是把法律的价值和精神翻译成原则、规则，所以翻译成权利义务时必然要考虑：把人摆在首位、以权利为本位，权责要相平衡，保护少数的弱势群体。

* **第四，权责统一**

    * 这也是权利义务一致性的表现，只不过是在公权力领域中的表现。

    * 不能给国家机关的权力很大而责任很小，那样它肯定是放飞自我。

### 科学原则的外在要求

* **第一，立法语言要有明确性、平实和严谨**

| 要求 | 说的是什么 | 反面 |
| :--- | :--- | :--- |
| 明确 | 写清楚 | 模糊 |
| 平实 | 人们看得懂，词儿不能生编硬造 | 晦涩、生造 |
| 严谨 | 把这个词的边界界定清楚 | 边界含混 |

    * "严谨"跟"不模糊"有点像，约等于不模糊，所以"明确"和"严谨"是近义词；记住"明确和平实"或者"平实和严谨"其中一组就够了。

    * 原来立法不太讲究语言的平实性，出现过很多晦涩表达，如"表见代理"，刑法上的"行为无价值""结果无价值"，这些词大概率不能写到法条里。

    * 草案版本："损害中华民族感情的行为，公安机关有权罚款拘留。"写得很平实、老百姓能读懂，但不明确也不严谨——什么叫"损害中华民族感情"？有人觉得去吃日本料理就损害了，有人觉得开日本车就损害了，这样执法者怎么执法。

    * 修改后："在特定纪念日，美化侵略战争行为，罚款和拘留。"这个就相对明确、严谨，因为"侵略"比笼统的"损害中华民族感情"具体得多。

    * 这两个条文出自《治安管理处罚法》起草：草案一公布老百姓就提意见，什么叫"损害中华民族感情"、这也太模糊了；改后穿日本和服、穿日本木屐、拿日本小扇子跳舞可能被罚款，组织一帮人边跳边唱日本歌曲有可能被拘留。

    * > **结论**：以立法者立法模糊之时，就是执法者狂欢之时；条文写得越模糊，执法的边界就越大，受到的限制就越小。

* **第二，立法内容具有针对性、可行性**

    * 针对性就是针对现实问题，可行性就是我可以做到，它其实是从实际出发、尊重客观规律的另一种说法。

    * > **提示**：这一点教材放在下面，掌握即可；从逻辑上它其实应该放在"出发点"那一层，勾"针对性、可行性"就是"实际＋客观规律"，考试写到上面去也没关系。

    * > **注意**：立法语言明确、严谨并不排斥概括立法，但要注意概括立法不等于模糊立法；概括立法是褒义词，模糊立法是贬义词，而"法律原则有一定模糊性"里的"模糊"是中性词。

    * 概括立法指在明确、严谨的前提下加入一些兜底条款，如"暴力、胁迫或者其他方法"里的"其他方法"就是兜底条款；不能说它是模糊立法，因为前边有"暴力、胁迫"这两个词给"其他方法"设了标杆。

    * 概括立法除了兜底条款还有别的形式，比如后面再写一个"法律原则"作为兜底，写"等"字也行。

    * > **注意**：针对性、可行性并不排斥立法的超前性，也叫预见性和前瞻性，也就是允许适度超前立法。

    * 例：制定《民法典》时人工智能还不像今天这么发达，但制定者预见到人工智能未来几年可能有飞速发展，所以对数据相关问题的保护做了初步规定，这就是一定的预见性、允许适度超前。

    * "适度"的具体判断标准不是现在要考虑的问题。

* **三个层次合起来**

    * 科学立法简单讲就是要立出好法：出发点好——一出身好；内在好——内容好；外在好——长得也好，三样齐备才是好法。

    * 在立法当中，科学是目的，而这一切都要在合法的前提下来完成，合法是它的保障；不能打着科学的旗号去违反法律。

## 立法程序

### 广义与狭义立法程序

* **广义立法程序**

    * 立法机关（也叫有法律制定权的国家机关）在创制、认可、修改、废止规范性法律文件时，简称在立法时或立法活动中，所需要遵循的步骤和方法。

* **狭义立法程序**

    * 仅指最高权力机关（全国人大，也包括全国人大常委会）在立法时需要遵循的程序，写成"步骤与方法"也是一样的。

* **对位逻辑**

    * 广义的国家机关在制定广义的法律时应当遵守的步骤和方法，就是广义立法程序；全国人大及常委会在制定狭义的法律时要遵循的步骤和方法，就是狭义立法程序。

    * 这一概念要了解的是背后这套对位逻辑，不是背两段定义。

* **我国全国人大及常委会立法程序的四步**

    * 法律案的提出、法律案的审议、表决和通过、公布。

### 立法程序的三个特征

* **第一，立法程序是法定化的**

    * 立法程序是法律规定的程序。

    * 只有法律把这些程序规定下来，这些程序才有了国家强制力；如果法律不规定就凭自觉去遵守，在立法时谁有那么高的自觉性。

    * 只有以法律形式确立的立法程序，才能对立法活动有国家强制力，或者叫高度约束力。

* **第二，立法程序包括步骤和方法**

    * 立法步骤就是对先后顺序的规定或安排，第一步干什么、第二步干什么、第三步干什么，关键词是"先后顺序"。

    * 立法方式即立法方法，是对立法活动运作方法的规定，"怎么立"，比如审议的时候怎么审、表决的时候怎么表决；写成"操作方法"也行。

* **第三，立法程序是所有立法环节必须遵守的程序**

    * 它由第一条法定化推导出来。

    * 复习时可以倒着顺：程序要法定，所以必须遵守，程序又拆解为步骤和方法。

    * > **易错点**：立法程序不等于立法中的工作程序。原文"立法活动工作程序"这八个字是可以省略的。工作程序是立这个法时会议本身的过程，比如上午 9 点讨论还是 9 点 30 讨论、11 点表决还是 12 点表决，法律不可能事先规定，因为有的讨论得很快 10 点就表决，有的可能到下午两三点才表决。

* **立法程序与程序正义**

    * 立法程序就是程序正义在立法环节的投射。

    * 公权力都要讲程序，后面执法环节会有执法程序，司法环节也会遇到司法程序；论正义价值时把立法程序、执法程序、司法程序凑在一起就能写成高分答案。

    * > **提示**：立法程序只有三个标题，每个标题下面扩一两句就完了，不用全文背诵。

### 法律案的提出

* **法律案的定义**

    * 法律案又叫法律议案，等于立法案。

    * 它是指有立法提案权的主体（包括国家机关或者人员）向全国人大提出的立法的提案、建议。

    * 考试中用"法律案""法律议案""立法案"都是一回事，三个词随便写哪个都对。

    * 关键点是有立法提案权，由此可推出立法提案权是法定的，提案主体也是法定的。

* **向全国人大提案的十个主体**

    * 一个代表团，或者三十名以上全国人大代表联合。

    * 全国人大主席团、全国人大常委会、全国人大专门委员会。

    * 国务院，还有监察委、最高院、最高检。

    * 中央军委。

    * 记忆形象：向人大提法律案就是向人大反映情况，有资格的是人大的自己人加人大自己的小弟。

    * 自己人五个：人大代表（个人）、代表团（临时，代表组团）、主席团（临时，服务员天团、负责安排会议流程组织协调开会）、专门委员会（常设，工程师团队）、全国人大常委会（大管家，常设）。

    * 五大机关五个：国务院、中央军委、监察委、最高院、最高检，它们在实际工作中能发现法律问题所以也能提。

    * 一共十个，没有了。

    * 监察委、最高院、最高检可简称为"三法司"，因为监察委相当于法制史上的御史台、最高院相当于大理寺、最高检相当于刑部，法制史上它们并称三法司；记忆上可称"三个守护法律的机关"。

    * 人大有十大专门委员会，除宪法和法律委员会外还有经济委员会、民族委员会、华侨委员会等一共十个，不必硬背，举例感受即可。

* **既能向人大提又能向常委会提的六大机关**

    * 五大机关加一个专门委员会，共六个：专门委员会、国务院、最高院、最高检、监察委、中央军委。

    * 逻辑是五大办实事的机关肯定能向常委会提，专门委员会在人大不在时归常委会领导所以也能提。

* **越级提案的边界**

    * 常委会自己还有个委员长会议，替常委会服务，它跟常委会的关系相当于主席团与人大的关系，是做日常服务的一个组织；它既然是服务天团，当然可以向常委会提，但不能越过常委会向人大提，因为委员长会议是常委会家的。

    * 全国人大常委会委员有一百来个，也能向常委会提，但不能向全国人大提——你是常委会的人当然向常委会提，人大代表是人大的人当然向人大提。

* **为什么是 30 名**

    * 如果让一个代表就提，会导致全国人大开会的日程太长；所以要找一个小范围的先讨论讨论，有了"30 名以上"代表。

    * 至于为什么是 30 而不是 29、31，这是法律规定的，得硬记。

    * 一个代表团就代表了当地的风土人情，所以向人大反映情况相当于上达天听：这个法律在我们广东用的时候有些问题，广东代表团提；在上海地区不合适，上海代表团提。

    * 背景：全国人大代表团一共 35 个，原来是 32 个；35 个就是 31 个省、自治区、直辖市，加上香港、澳门、台湾是 34 个，再加一个解放军。

    * > **提示**：这一块重点要背两样，一是法律案的定义与"立法提案权"这个关键词，二是向人大提案的十个主体，加上"既能向人大又能向常委会提的六大机关"。

### 法律案的审议

* **审议的定义与阶段**

    * 法律案的审议就是立法机关对法律案的审查和讨论，简称"审议"，关键词是"立法机关"还有"审查、讨论"。

    * 三个审议阶段：一、专门委员会审议，并由宪法和法律委员会统一审议；二、全体会议审议；三、代表团审议。

* **审议的实际流转**

    * 法律案先落到主席团，往下分、往上交都是它。

    * 十个专门委员会各审各的，另外九个审完都汇总到宪法和法律委员会，由它统一审议；代表团是接地气的，因为代表团都是从地方来的，审完也得交给法律委员会统一把关。

    * 十大工程师团队会提出十个甚至十个以上的理由，众说纷纭，所以要并都交给宪法和法律委员会统一审议，谁最专业谁统。

    * 宪法和法律委员会统揽够了交给主席团，再由主席团转交大会全体会议，近三千人坐在人民大会堂里看，这就叫大会审议。

    * > **提示**：这张图是为应对超纲考点准备的。法条原文把这些步骤写出来读起来特别繁琐，但看图就明白——主席团发挥的就是服务功能，干的全是服务工作。

```text
          各方提案
              │
              ▼
           主席团        ← 法律案先落在这里，往下分、往上交也都是它
              │
       ┌──────┴─────────────┐
             ▼              ▼
    专门委员会           代表团        ← 各审各的 / 接地气地审
       └──────────┬──────────┘
                  ▼
     宪法和法律委员会     ← 谁最专业谁统稿，汇总后统一审议
                  │
               主席团
                  ▼
         大会全体会议        ← 2987 人，人民大会堂
```

* **审议的内容：全面审查**

    * 审议法律案过程中，机关要对立法的合宪性、立法动机、立法精神、协调问题、立法技术等进行检查，这份清单不要背。

    * 审议法律案只要和立法有关的内容都得审，所以只要记四个字：全面审查。

    * > **易错点**：考"该立法与经济发展情况相适应不适应"要不要审，背的那份清单里没有经济问题，但只要和立法有关就得审，所以要选。

* **人大审议的两种结果**

    * 一是没什么大问题或者小问题已经解决，交给大会审议并表决，进入下一步。

    * 二是有问题，授权常委会进一步审议。

    * 之所以授权常委会，是因为人大会期短：人大除了立法还得听国务院、最高院、最高检汇报上一年成就并展望明年成就，立法只是这五天当中的一个环节；浩瀚如《民法典》一千零五十多条，也就是短短半天时间，没有那么长的时间让你们吵架辩论。

    * 人大该走还得走，因为提前安排了会期、告诉了人大代表就开五天会，代表早都把返程机票都订好了。

### 常委会审议的搁置与终止

* **三种结果**

    * 没毛病，还是交付表决。

    * 有点毛病，大家有争论有讨论，那就暂停，叫搁置。

    * 吵得很凶，那就终止。

    * 不授权某个机关进一步审议，是因为主人可以授权给管家，管家再往哪授就无从授权了，所以只能暂停。

* **搁置的触发条件与期限**

    * 因各方面对制定法律的必要性、可行性等重大问题存在较大意见，搁置审议满两年的；或者暂不交付表决经过两年也没有再列入议程审议的。

    * 关键词是重大问题、较大意见。

    * 一般不会导致无限暂停，因为常委会两个月开一次会，一年六次；这次一月吵得挺凶就搁置，回去研究，两个月后三月继续，还吵就五月继续。人大可没有搁置审议，一搁置就一年出去了。

    * "搁置审议满两年"意味着吵了十二次；"暂不交付表决经过两年没有再列入议程审议"指一年多都没人再提这件事，已经被晾了两年，两种情形都是审了两年没得出结论或者这两年内谁也不敢碰。

    * 形象记忆简称"分居满两年"，主观题不能这么写。

* **终止与延期**

    * 委员长会议可以决定终止审议，必要时也可以决定延期。

    * 满两年一般都是终止了，特殊情况下也可延期；就像夫妻分居满两年一般情况下会让你离，但不一定必须让你离。

    * > **提示**：这一段虽然超纲但比较重要，是要掌握的。

* **掌握落点**

    * 三样：审议的阶段；审议内容不背清单但记住叫"全面审查"；人大审议结果与常委会审议结果的区别，尤其是常委会搁置审议的规定。

### 表决与通过

* **表决及通过的地位**

    * 表决及通过是立法程序中具有决定意义的一步，前面折腾半天如果走不到这一步就没有用，永远通过不了。

    * 表决就是这些人对法律案的最终态度：赞成、反对还是弃权；这一点没有要背的，把"决定意义"勾出来就好。

* **通过门槛**

| 通过门槛 | 适用对象 | 三千人中需要 |
| :--- | :--- | :--- |
| 三分之二以上 | 宪法的修改 | 2000 人以上 |
| 过半数 | 各类法律 | 1500 人以上 |

    * 计算以三千人为基数，实际 2987 人。

    * 在人大体系内，需要三分之二的仅有修宪这一件事，再也没有了，其他都是过半数。

    * 同理，国家主席的当选，最高法院院长、最高检察院检察长的当选，也是 1500 人通过就行；罢免也是 1500 人通过就行。

### 法律的公布

* **公布与生效的关系**

    * 公布是生效的前提：没有公布不可能有效力，反过来讲，只要生效它一定是公布的。

    * 法律格言是"未经公布之法律无遵守之义务"；要想生效必须公布，为人所知才可以。

    * 但公布的法律不一定立即生效，因为还有公布就生效、附期限生效、附条件生效三种情形。

* **公布的主体**

    * 法律的公布必须由特定机关或人员来进行的，注意"机关或人员"这四个字：有的公布由机关进行，有的由人员进行。

* **各种法律文件的公布**

| 文件种类 | 制定／批准机关 | 公布主体 |
| :--- | :--- | :--- |
| 法律 | 全国人大及全国人大常委会 | 国家主席签署公布 |
| 行政法规 | 国务院 | 总理签署公布 |
| 监察法规 | 国家监察委 | 国家监察委公布 |
| 部门规章 | 国务院部门（部、委、行、署等） | 部门首长签署公布 |
| 国际条约 | 全国人大常委会批准 | 国家主席签署公布 |
| 地方政府规章 | 省级、市级人民政府 | 政府首长签署公布 |
| 特别行政区的法律 | 立法会 | 行政长官签署 |
| 地方性法规（省级） | 省人大或省常委会 | 省人大定的由主席团公布；省常委会定的由常委会公布 |
| 地方性法规（市级） | 市级人大及常委会 | 均由该市（自治州）常委会公布 |
| 民族自治法规 | 自治区、州、县人大 | 区、州、县人大常委会公布 |
| 立法解释 | 全国人大常委会 | 常委会公布 |
| 司法解释 | 最高院、最高检 | 最高院、最高检自己公布 |

* **个人签署的三条规律**

    * 首长负责制的都是首长签署。国务院叫首长负责制，行政法规由总理签署；部门规章也一样，公安部就部长签子，民政部就民政部部长签子，中国人民银行就央行行长签子；地方政府规章同理，省政府的规章就省长签子，市政府的规章就市长签子。老大一签子就说明这个机关的老大认可他们立这个法了。

    * 国家主席替全国人大和常委会签子。法律由全国人大及常委会制定但由国家主席签署公布，因为他代表了人民、象征着国家，象征着全体人民和整个国土，大家都认这个法律。国际条约也是这个原理：常委会批准的国际条约就相当于常委会认可了这个立法。

    * 行政长官替立法会签子。明明是立法会的立法却由行政长官签署，这在我国大陆不可能出现，但香港、澳门就是；行政长官即特首，是特别行政区的代表，书面用语叫特别行政区的代言人，代言人签不签子就代表我们香港人民同不同意。

* **人大制与三权分立制衡的差别**

    * 大陆是人大制，典型特征是先有人大然后才有政府然后才有司法，法院、检察院以及监察委构成三角关系。

    * 三权分立体制下立法会、行政长官、法院地位平等、没有谁比谁大，背后就是要相互制衡、相互牵扯，美国模式、香港模式都是这样的。

    * 既然要相互制衡，议会的立法就可能有毛病，所以要长官签子，底层逻辑就是政府要牵扯一下议会；相应的政府一些重要决定还得议会批准，政府决定哪天放假不需要议会批。

```text
        ┌──────────┐
        │ 全国人大 │
        │   老大   │
        └─────┬────┘
              │  授权
        ┌─────┴─────────────┐
             ▼              ▼
        ┌───────────┐ ┌───────────┐
        │  国务院   │ │法院 检察院│
        └───────────┘ └───────────┘
     三角关系：先有人大，再有政府，再是司法
```

```text
┌──────────┐ ⇄ ┌──────────┐ ⇄ ┌──────┐
│  立法会  │ ⇄ │ 行政长官 │ ⇄ │ 法院 │
│ （议会） │   │（代言人）│   │    │
└──────────┘   └──────────┘   └──────┘
 ▲  议会立法须它签子公布（政府要牵制议会）
 └─ 法院反过来可司法审查政府的各项决定
  三角地位平等，谁也不比谁大
```

* **不需要个人签子的情形**

    * 国家监察委公布的监察法规没有人签子，监察委自己公布。

    * 省级地方性法规：省人大制定的由主席团公布，省常委会制定的由常委会公布，没有人签子。主席团公布是因为它是从头到尾安排人大会议流程的服务员天团，见证了人大的立法、是人大立法的见证者和全程参与者；常委会会期比较密，常委会这个机关自己公布就好。

    * 市级地方性法规：均由该市级常委会公布。省人大的是由主席团这个全程见证者公布，市人大却由市常委会公布，原因是市人大的立法要省人大常委会批准，批准以后把结果返给市常委会，而市人大就开五天会已经散会了，返不回去只能由市常委会公布；市常委会定的当然还是市常委会自己公布。

    * 民族自治法规：由自治区人大、州人大、县人大制定，公布机关却是区、州、县人大常委会自己公布，同样是因为相应常委会批准耽误时间、下面人大已经散会了。

    * 这两处的底层逻辑就是批准后才能生效但人大已散会，短记为"批准后才能生效，但人大已散会"。

    * 立法解释是常委会做的，当然由常委会公布，不用国家主席，因为它毕竟不是新的法律，只是一个理解、一个说明。

    * 司法解释由最高院、最高检自己公布，不需要院长、检察长签字，是因为它不是首长负责制；首长负责制就两个机关，政府机关和军事机关。

* **总结**

    * 我国不是谁制定谁公布，制定机关与公布机关或公布的人不一定是同一个。

* **三个判断题**

    * "法律案自表决之日起就产生效力"是错的，公布以后还不一定有效力呢，更不要说表决之日。

    * "起草法律案是第一步"是错的，起草不属于立法程序，那属于立法外的程序，立法程序第一步就是启动立法机关，就是提案。

    * "现代法治国家未经公布必然不能生效"是对的。
