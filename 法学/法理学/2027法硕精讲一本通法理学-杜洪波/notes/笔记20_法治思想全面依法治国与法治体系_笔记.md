# 法治思想、全面依法治国与法治体系

## 核心要义的六个"指明"骨架

全面依法治国的核心要义可以理解成一组连续的"指明"：在方向、地位、布局、任务、关系、保障六个维度上被一一框定，后面所有小标题都是这根骨架上挂下来的东西。

* **六个"指明"的总轮廓**

    ```text
                         ┌─────────────────────────┐
                         │   全面依法治国 的总轮廓   │
                         └────────────┬────────────┘
                                      │
             ┌───────────┬───────────┬────┴────┬───────────┬───────────┐
             ▼           ▼           ▼         ▼           ▼           ▼
          政治方向    重要地位    工作布局   重点任务   关系问题   重要保障
           党领导     基本方略     三体      宪法优先   六对关系    关键少数
          以人民      五位一体            立执司守
          中国特色    深刻革命
    ```

### 政治方向：党、人民、中国特色

* **全面依法治国的政治方向**

    * > **定义**：全面依法治国的政治方向决定法治建设的成败得失。

    * 政治方向由三组圈构成：党——由谁领导；人民——为了谁、依靠谁；中国特色——走什么样的路。

    * 坚持党的领导，是习近平法治思想十一个坚持里的第一个坚持。

    * 坚持以人民为中心：人民既是目的，也是依靠力量。

    * 坚持中国特色的法治道路。

        * > **注意**：这一条的第二行写明是"**唯一正确道路，没有别的**"，就这一条。

* **中国特色社会主义法治道路的三条内容**

    | 内容 | 展开方向 |
    | :--- | :--- |
    | 坚持党的领导 | 与政治方向重复，后专章展开 |
    | 坚持中国特色社会主义制度 | 政治制度层面：国体与政体 |
    | 贯彻中国特色社会主义法治理论 | 简称"习思想"，即习近平法治思想 |

    * 制度这条要挂钩：政治上中国特色社会主义制度主要表现为国体和政体——国体是人民民主专政，政体是人民代表大会制度。

    * 法治理论这条展开就是习近平法治思想中的十一个坚持。

    * 掌握到这个层次即可，足以支撑论述"法治道路"这类大题。

### 重要地位：基本方略、深刻革命、固根本稳预期利长远

* **基本方略**

    * > **定义**：全面依法治国是我们建设新时代中国特色社会主义的基本方略。

    * "基本方略"意味着法治不再只是建设工具，而上升到基本方略的高度。

    * 法治在"五位一体"总体布局、"四个全面"等格局中具有基础、引领和支撑作用。

        * 基础：奠定制度基础，即制度前提；五大文明建设必须有制度兜底。

        * 引领：指引作用。

        * 支撑：同为制度基础，与"基础"同义。

* **深刻革命**

    * > **定义**：全面依法治国是国家治理领域的深刻革命。

    * 深刻革命指法治各个环节都要大范围改革：立法体制改革、执法体制改革、司法体制改革等。

    * 变动大，不是做个小整容手术，而是大手术。

    * 从这一侧反证坚持党的领导的必要性：这么大的变化需要党中央把握方向。

* **本质要求与重要保障**

    * > **定义**：全面依法治国是本质要求，也是重要保障。

    * > **提示**：论述题的**万能结语**是"重视法治、厉行法治，更好发挥法治固根本、稳预期、利长远的保障作用"。

    * 不要用"没有共产党就没有新中国"一类口号收尾，它与法治的距离相对较远。

### 工作布局的"三体"与重点任务

* **工作布局三条**

    * 在法治轨道上推进国家治理体系和治理能力现代化：把法治贯穿国家治理的全过程各方面，这就是"全面布局"。

    * 坚持中国特色社会主义法治体系。

    * 依法治国、依法执政、依法行政共同推进。

    * 三条都带一个"体"字——治理体系、法治体系、一体建设，故称"**三体**"。

    * > **提示**："三体"常以多选题形式出现，三个选项都要选。

* **重点任务**

    * 全面贯彻实施宪法是法治的**首要任务**。

    * 科学立法、严格执法、公正司法、全民守法，对应立、执、司、守四大环节。

    * 宪法排在前面，因为搞立、执、司、守的前提是有宪法——先把法中"老大"搞好。

    * 四环节合称法治建设的**关键环节**。

### 关系问题：六对关系

* **需要处理好的六对关系**

    | 关系 | 对应考点 |
    | :--- | :--- |
    | 政治与法治 | 与政治方向呼应 |
    | 民主与专政 | 民主与法治部分 |
    | 改革与法治 | 与"深刻革命"呼应 |
    | 发展与安全 | 安全价值部分 |
    | 依法治国与以德治国 | 基本原则中的法治德治相结合 |
    | 依法治国与依规治党 | 党内法规体系 |

    * 历年大型题目（分析题、论述题、简答题）必然涉及其中一到两处，有的年份涉及三道。

    * 已考过的有：法治与政治、法与民主、法与改革、安全价值；依法治国与以德治国连续考查；依法治国与依规治党。

### 重要保障：领导干部是关键少数

* **保障的种类**

    * 政治保障：党的领导。

    * 制度保障：立、执、司、守。

    * 思想保障：法治思想。

    * 人员保障：**人才强法**，必须重视法治工作队伍建设；法治工作队伍建设本身是命题点。

* **领导干部**

    * 队伍中领导干部这一种特别重要：火车快不快全凭车头带，必须紧紧抓住领导干部这个"关键少数"。

    * 领导干部要带头尊崇法治、敬畏法律、了解法律、掌握法律，做尊法学法守法用法的模范。

## 全面依法治国的总目标

* **总目标**

    * > **定义**：建设**中国特色社会主义法治体系**，建设**社会主义法治国家**。

    * > **易错点**：⚠️ 总目标是"**法治体系**"，不是"法律体系"。法律体系仅指立法环节，而总目标把整个法治问题作了宏观框架。这是选择题爱挖的坑。

    * > **注意**：总目标中含有**党内法规体系**。党内法规体系属于总目标的组成部分，但党内法规本身不是法律，不是正式渊源。

    * 党内法规能进总目标的原因：实现法治建设总目标必须加强党的领导，而党内法规能提供法律之外更高更严的约束。

    * 总目标是将近十年前中央提出的，此后虽有完善但大纲未写出，被考为大题背诵的可能性不大；主要记第一句加两个注意点。

* **总目标的展开**

    ```text
    总目标：建设中国特色社会主义法治体系，建设社会主义法治国家
    │
    ├─ 道路 ── 党的领导 + 中国特色社会主义制度 + 中国特色社会主义法治理论
    │           （与"中国特色社会主义法治道路"完全对应）
    │
    ├─ 体系 ── 法律规范体系 / 法治实施体系 / 法治监督体系
    │           / 法治保障体系 / 党内法规体系
    │
    ├─ 布局 ── 依法治国、依法执政、依法行政共同推进
    │        + 法治国家、法治政府、法治社会一体建设
    │
    ├─ 环节 ── 立、执、司、守
    │
    └─ 落点 ── 国家治理体系和治理能力现代化
    ```

## 五项基本原则

五项基本原则是主观题最爱考的一块。速记口诀"**党和人民等得急**"——党、人民、平等、法治德治、实际出发；亦作"**党、人、等、德、基**"。

* **中国五原则与世界四原则的关系**

    * > **定义**：中国法治五大基本原则与世界法治建设四大基本原则是普遍与特殊的关系。

    * 世界四大基本原则：法律至上、控权、保民、正当程序。

    * 搞中国法治建设，既要守中国的五原则，也要符合世界的四原则。

### 坚持党的领导

* **党的领导**

    * > **定义**：党的领导是中国特色社会主义最本质的特征——即最重要的特征。

    * 之所以最本质：中国是大国、面临的问题复杂，需要群众中的先进分子带路，而先进分子入了党。

    * > **定义**：党的领导是社会主义法治最根本的保证——保方向，能判断出朝哪个方向走。

    * 因此要把党的领导**贯彻到全面依法治国的全过程和各方面**。

* **贯彻到全过程（对应立、执、司、守）**

    * 全过程即步骤，步骤即立、执、司、守。

    * 党领导立法；党保证执法；党支持司法；党带头守法。

    * 四个动词都可概括成"领导"，换成"保证""支持"只是语言丰富性，与"领导"无实质差别。

    * 只有四件事都做好，才能把**依法治国同依法执政统一起来**。

* **贯彻到各方面（对应国家机关与人民群众）**

    * 党总揽全局、协调各方，同人大、政府、监察委、法院、检察院依法依章程履行职能相统一。

    * 机关名称不必背，写"总揽全局、协调各方与国家机关依法履职相统一"即可。

    * 党领导人民制定实施宪法法律，同党带头守法统一起来（在宪法法律范围内活动即带头守法）。

    * > **易错点**：⚠️ **不是党直接立法**。党是领导力量，人民是参与力量；具体立法行为由立法机关完成，执法司法行为由执法和司法机关完成。党带着人民参与到立、执、司、守各环节。

    ```text
                 全过程（步骤）              各方面（对象）
              ┌────────────────┐      ┌────────────────────────┐
              │  立 ─ 领导立法  │      │  国家机关 → 依法履职    │
              │  执 ─ 保证执法  │      │    （人大/政府/监委/法院/检察院）
              │  司 ─ 支持司法  │      │           总揽全局、协调各方
              │  守 ─ 带头守法  │      │                        │
              └────────────────┘      │  人民群众 → 参与制定实施 │
                     │                │      同"带头守法"相统一  │
                     ▼                └────────────────────────┘
          四环节都做好 → 依法治国
            与依法执政相统一
    ```

### 坚持人民主体地位

* **人民主体地位**

    * 人民主体地位与以人民为中心是一个意思，原理可以互换。

    * > **定义**：人民是依法治国的主体和力量源泉。

    * "主体"指法治的来源和本原，本原来自人民。

    * > **易错点**：人民是法治主体，**不意味着人民可以直接行使立法权、执法权、司法权**。公权力由人民授权的组织或机关行使，如同所有权与使用权的分离。

    * 人大制度是保障人民的根本政治制度。

    * > **提示**：**根本制度是社会主义**，社会主义在政治上的表现才叫**人大制度**。根本制度是大框，人大制度是其中的政治表现，两个"根本"不能混。

* **以人民为中心的四条要求**

    * 法治建设必须**为了人民、依靠人民、造福人民、保护人民**，以保障人民根本利益为出发点和落脚点。

        * 出发点：想问题时首先从人民想；落脚点：政策执行完毕后的效果仍以人民的需要衡量，二者形成闭环。

        * 简记"**为、依、造、保、保**"。

    * 保证人民享有广泛的权利和自由，并承担义务——权利与义务具有一致性。

    * 维护公平正义，实现共同富裕。

        * "共同富裕"的重点在"共同"二字，与公平正义放在一起。

        * 落脚点是**先富带动后富**，而不是先富者都润了。

        * 它不单单是经济领域问题："富裕"属经济领域，"共同富裕"是对富裕加了限定。

    ```text
    人民是主体、人民是力量源泉
            ↓
    出发点在人民，落脚点也在人民
            ↓
    为、依、造、保、保（人民重要，所以要为依造保保）
            ↓
    口号具体化为权利和义务：保障广泛权利 + 承担应尽义务
            ↓
    最终目标：公平正义、共同富裕，让所有人都富起来
    ```

### 坚持法律面前人人平等

* **法律面前人人平等**

    * > **定义**：法律面前人人平等是社会主义法律的基本属性。

    * 平等本是法律的基本价值之一，自由、人权、正义同样是，此处侧重平等。

    * 强调平等**并未否定**人权、正义、自由等价值。

    * 侧重平等的理由：社会中不平等事项较多（特权、特供、贫富差距等）冲击法律的平等价值。

* **全民守法万能句（四句）**

    * 任何人都必须**尊重宪法法律权威**。

    * 在**宪法法律范围内活动**。

    * **依照宪法行使权利、履行义务**。

    * **不得有超越宪法法律的特权**。

    * 推导逻辑：内心上平等地尊重宪法法律权威 → 外在活动上在宪法法律范围内活动 → 内容上平等地行使权利、履行义务 → 由此排斥特权。

### 坚持法治、德治相结合

* **法治德治相结合**

    * 原话是"一手抓法治、一手抓德治"——都要抓。

    * 既重视法律的**规范作用**（指引、教育、评价、预测、强制等），又重视道德的**教化作用**，最终相辅相成、相得益彰。

    * > **易错点**："既……又……"是并列连词，等于**同样重视**，不是"法治优先、法治压过德治"。

    * 在都重视的前提下说更重视法治可以；说更重视德治不行，那会让道德压过法律、违背法律至上。

* **两条具体机制**

    * 以法治体现道德理念，强化法律对道德的保障或者促进作用。

        * 例：合理行政体现道德理念；立法时把**重要**的道德问题上升为法律，不是全部。

        * 例：因自愿实施紧急救助行为造成受助人损害，救助人不承担民事责任。

    * 以道德滋养法治精神，强化道德对法治的支撑作用。

        * 例：家庭伦理与家风建设（夫妻真心相爱、父慈子孝、兄弟姐妹和睦）降低发案率。

    * 速记："**都要抓、都重视；你养我、我促你**"，"促进"用"保障"也行。

### 坚持从中国实际出发

* **从中国实际出发的六项内容**

    * 从我国**基本国情**出发。

    * 与**改革开放**相适应。

    * 总结党领导人民实行法治的**成功经验**。

    * 围绕法治建设重大的**理论和实践问题**推出理论创新。

    * 汲取**中华法律文化精华**。

    * 借鉴国外法治经验，但**不照搬**外国理念和模式。

    * > **易错点**：⚠️ **从国情出发不等于从传统文化出发**。秦朝有传统文化，汉朝也有，治理今天的中国不能以秦汉为出发点。出发点只能是基本国情、现实情况。

    * > **提示**："汲取中华法律文化精华"不是出发点，只是有可用的地方；前面几项才是出发点。"借鉴国外经验"与"不照搬外国理念和模式"捆在一起，后者不能丢。

    * 形象记法"**古今中外**"：古＝中华传统文化精华；今中＝今天的基本国情、改革开放；外＝外国有益经验。

## 基本格局：立执司守加人才

* **基本格局的构成**

    * 法治环节——立法、执法、司法、守法，排开是"立、执、司、守"；再加上人才，共"**立、执、司、守、人**"五件事。

    * 考试常要求把整个格局默出来。

    * 判断能否平替的标准：意思一样、表述换一套写法的，就用背熟的那一套去顶。

    * 立法、执法、司法三块与基本原则几乎一一对应，真正的新增量只有两处——**守法新增的四条实现途径**、**人才部分的小细节**。

### 科学立法的五个要求

| 科学立法的要求 | 与立法基本原则的对应 |
| :--- | :--- |
| 尊重客观规律 | 尊重客观规律 |
| 体现民意 | 程序民主 / 开门立法 |
| 符合实际 | 从实际出发 |
| 完善程序 | 程序民主 |
| 符合科学 | 内容科学：明确、严谨、针对、可行 |

* **尊重客观规律**

    * 最核心的一句：尊重客观经济规律，尤其是市场经济规律，或市场与自由关系的内在规定性。

    * 还要反映社会建设规律、文化规律、政治方面的规律、生态文明发展规律，正好对着五大文明。

    * 简化记忆即可，不要照原话硬背。

* **体现民意**

    * 体现人民群众的利益和要求，回应人民群众的真实关切和心愿，不能部门利益至上。

    * 举例如河北省立法不能只保护河北省：若为保护本土产业禁止外地啤酒运入，同时损害外省人民和本省人民喝外省啤酒的需求。

    * > **易错点**：人民性是法律的**最根本特征**；"最根本保证"是党保方向。两者一为特征、一为保证，不能串。

* **符合实际（从实际出发）**

    * 立足现实、解决现实问题和现实利益诉求，立法要有针对性。

    * 针对性不否定适度超前：既要有预见性、超前性，又要有针对性、务实性。

* **完善程序**

    * 拓宽立法渠道，加强开门立法——立法公开，不要关着门让老百姓提意见。

* **符合科学**

    * 按科学的原理来完善，增强可操作性，立得要明确，克服权利义务关系不明的局限。

* **与立法基本原则表的关系**

    * 两张表基本一一对应；区别只在于这里把科学立法的"明确、严谨、针对、可行"重新排了顺序，并省略了民主立法中的主体组成。

    * 前面讲的是**基本原理**，这里是把基本原理落到全面依法治国语境中的**结合表述**，主要精力放在科学立法原则与民主立法原则上。

### 严格执法

* **严格、严明、严肃**

    * 严格：行政机关及其工作人员（执法人员）严格遵守法定标准和程序，即权限法定、程序法定，讲的是实质标准与程序。

    * 严明：纪律严明，不能违反内部纪律。

    * 严肃：执法的态度和精神要严肃。

    * 三词解释与严格执法的基本原则完全一致，两边可以互相平替。

* **实现严格执法的四条改革措施**

    * 严格执行重大执法决定的法制审核制度——确保执法决定的合法性，如公安机关的拘留决定书由法制部门专门审核，本质是用法律限制执法者。

    * 依法惩处各类违法行为，加大对关系群众利益的重点领域的执法力度。

        * 重点领域找最简单的入口：入鼻的空气（环境保护）、入口的食品药品、影响身体健康的（安全生产）。

    * 完善执法程序，建立执法全过程记录制度——执法记录仪该开就得开，不能想罚谁就开、打完再关。

    * 明确具体的执法流程——重点规范行政许可、行政处罚，这两类领域权力大、是腐败高发区。

    ```text
    实体法定（权限法定）  →  依法惩处侵犯群众切身利益的违法行为
                                  │
                                  ▼
    程序法定            →  执法程序要完善 + 具体执法流程要完善
    ```

    * 权限法定管住实体上的越权，配的措施是依法惩处各类违法行为、加大重点领域执法力度。

    * 程序法定管住程序上的随意，配的两条是完善执法程序（全过程记录）和明确具体执法流程（规范行政许可、行政处罚）。

### 公正司法

* **公正司法**

    * 内容与司法公正的基本原理一致，没有新的东西。

    * > **提示**：记住引文——"**司法是正义的最后防线，司法不公则权力受损、社会不稳、法治不存**"。

### 全民守法

* **全民守法**

    * 定位：法治建设中的**基础**，因为老百姓是基础。

    * > **提示**：卢梭名言值得背——"最重要的法律既不是铭刻在大理石上，也不是刻在铜表上，而是铭刻在公民的内心里"。

    * > **定义**：全民守法指一切人都必须尊重、崇尚宪法法律，在现有法律范围内活动，依照宪法法律行使权利、履行义务，不得有超越宪法法律的权利或特权。

    * 与法律面前人人平等原则的表述是同一套，可直接互换。

* **实现全民守法的四条途径**

    * 国家机关依法惩恶扬善——执法机关严格执法、司法机关公正司法，才能形成"守法光荣、违法可耻"的社会氛围；不严格执法就会反转成"守法可耻、违法光荣"。

    * 国家机关工作人员学法用法，领导干部还要带头学法、模范守法，发挥率先垂范的带动效应，使全体人民成为法治的忠实崇尚者、遵守者、捍卫者。

    * 开展法制宣传教育——灌输法律知识，弘扬法治精神、建设法治文化，增强守法的积极性。

    * 引导人们依法表达诉求、依法维护权益。

    * 第三条是普及知识，第四条是让人主动会用；光普及不会用没有用。

    * 一句话概括：实现全民守法要**上下其动**。

    ```text
                    实 现 全 民 守 法
                      上下其动·两个层面
            ┌─────────────────┴─────────────────┐
            ▼                                   ▼
         国家层面                            公民层面
      ┌───────────┬───────────┐         ┌───────┴───────┐
      ▼           ▼           ▼         ▼               ▼
    严格执法    公正司法   工作人员及    普法宣传        依法表达
               （领导干部带头守法）    （提升法律文化）    依法维权
    ```

    * 立法、执法、司法三块大量重复，真正要下功夫的是守法的四条途径。

### 人才强法

* **人才强法**

    * 内涵：加强法治人才建设，建立一支忠于党、忠于国家、忠于人民、忠于法律的法治工作队伍。

    * 理由一：从法律大国向法治大国的转变需要人才，法治人才是**主体性力量**。

        * > **易错点**：人民是法治主体，法治人才是主体性力量。"主体"指所有权人——法治主体的所有权归人民，人才只是主要力量。说"法治人才就是整个法治主体"是错的。

    * 理由二：法治与人治相对，但法治不否定人的作用——立法离不开立法者，执法离不开执法者，司法离不开司法者。

## 基本途径：三依与三治

* **"三一三制"的双重身份**

    * 三一：依法治国、依法执政、依法行政。

    * 三制：法治国家、法治政府、法治社会一体建设。

    * "三一三制"既属于工作布局中的一部分，又属于基本途径；两组词是交叉的，不是两套东西，选择题里要能选出来。

### 依法治国

* **依法治国**

    * > **定义**：依法治国是党和人民治国理政的根本方略——以法律至上为核心，以权力制约为机制。

    * 概念组成就是法治四原则：法律至上、权力制约、权利保障；原文漏掉了正当程序，补写也没毛病。

    * "根本方略"与"基本方略"几个表述没有本质差别。

    * > **注意**：这个定义要重义不重词，不必追求每个字完全一样。

### 依法执政

* **依法执政的"法"从哪来**

    * 既要依据**宪法法律**（正式渊源），又要依据**党内法规**（非正式渊源），这是它的特殊性。

    * "治国理政"含两层：在党的领导下治理国家、搞好政治（对外），以及治党管党（对内）。

* **对外：治国理政**

    * 立法环节——**领导立法**，其中一条是保证党的主张和意志通过法定程序上升为国家意志。

        * "党的意志"主要就是政策，党的意志法律化其实就是**党的政策法律化**；操作上由党向人大提建议、经提案等法定程序成为国家意志。

    * 执法和司法环节——教材写作"**保证和支持**"，对应严格执法、司法公正。

    * 守法环节——**带头守法**。

* **对内：治党管党（三条，由小到大）**

    * 依法保障和规范党组织和党员干部运用**公权力**的行为，反对以言代法、以权压法、徇私枉法；关键是"依法保障和规范"五个字——对党的机关和党员干部**既要保障又要限制**。

    * 依法推进执政体制改革，自觉提升党的机关、党员干部的法治思维和法治工作方式；党中央可以向立法提建议，但不能直接行使立法权、执法权和司法权。

    * 依照宪法法律，实现党的宗旨目标和任务——宗旨、目标、任务即全心全意为人民服务，又叫以人民为中心。

    * 逻辑顺序：党员干部 → 党的执政体制 → 党的更宏观的宗旨目标和任务。

* **依法治国与依法执政的统一**

    * 统一在哪？统一在两条朴素的道理里：**搞法治离不开党，搞党的时候也离不开法**。

    * 所以要依法推进执政体制改革，同时依法提高党员干部和党组织遵守宪法的能力，依法实现党的宗旨目标和任务。

    * > **定义**：依法治国与依法执政的统一，是习近平同志明确要处理好的重大关系。

### 依法行政

* **依法行政**

    * 与依法行政原则没有本质差别：行政机关及其执法人员依照法定职权和法定程序执行法律的活动。

    * 另有表述"各级政府在党的领导下依法行使行政管理权、执行法律"，不必背。

    * 法定职责必须为——针对**不作为**。

    * 法无授权不可为——针对**乱作为**。

    * > **易错点**：对"干得少就错得少"、按时上下班回家不处理政务的区长，应强调**法定职责必须为**；他本来什么都不干，再强调法无授权不可为属于答非所问。

* **实现依法行政的三条改革措施**

    * 改革执法体制——推进综合执法，构建权责统一、权威高效的执法体制。

        * 综合执法与**分散式执法**相对：分散执法是工商局、消防局、食药监局等轮流检查；综合执法是各机关各派一人同来一趟，目的是提高执法效率。

    * 推进严格执法。

    * 树立权力来自于人民、权力为了人民、受人民监督等法治观念。

    * 三条相互联系、相辅相成；"价值一致、基本要求统一"这类套话没有考点。

## 三制：法治国家、政府、社会一体建设

### 法治国家

* **法治国家**

    * > **定义**：法治国家是全面依法治国的根本目标。

    * > **定义**：法治国家指依法赋予、运行和制约公权力，通过公正司法、严格执法，维护法律权威并保障人民权利的国家形式。

    * 拆解："依法赋予、运行和制约公权力"＝权力制约；"公正司法、严格执法、维护法律权威"＝法律至上；"保障人民权利"＝权利保障。

    * > **注意**：法治国家与依法治国的定义没有区别，不要去找区别；只有落脚点不同——依法治国是一种治理方式／治国方略，法治国家是一种国家**存在形式**，要素完全一样。

* **法治国家六项工作要求**

    * 法律机制（法律之治）：国家权力之间以及国家权力与公民权利的关系，均纳入法律的调控范围。

        * > **易错点**：这与"法律调整对象具有局限性"**不矛盾**。它有定语——说的是"国家权力之间"和"与公民权利的关系"，本质是控权与保民；不等于所有社会关系都要有法律调整。简化背法：关于权力制约和权利保障的事项，均要由法律调控。

    * 法律权威：法律权威高于领导者个人权威，是人治与法治的根本区别。

    * 权力制约：即坚持权力制约原则，内容不需另背。

    * 人权保障：即权利保障原则。

    * 注重程序：即正当程序原则。

    * 良法善治：特征上的良法（普遍性、规范性、权威性）＋价值上的良法（公开公正、控权保民）。

    * > **结论**：**法治四大基本原则 + 良法善治 = 法治国家**。

### 法治政府

* **法治政府**

    * > **定义**：法治政府指政府要依法设立，政府的权力要法定，政府的决策和政府行为要依照法定程序，并对其后果承担责任的政府。

    ```text
    法治政府 = 主体（依法设立）
             + 权限（权力法定）
             + 程序（决策与行为依法定程序）
             + 责任（对后果承担）
    ```

    * 背这个概念就按主体、权限、程序、一个责任的顺序拆。

* **法治政府六大标准**

    | 标准 | 对应或不对应 |
    | :--- | :--- |
    | 有限政府 | 依法行政原则、严格执法原则 |
    | 责任政府 | 权责统一的执法原则 |
    | 人民政府 | 执法原则中**没有**"民主执法" |
    | 程序政府 | 正当程序执法原则 |
    | 阳光政府 | 诚实守信（诚实那一面） |
    | 诚信政府 | 诚实守信 |
    | （未列入标准的）合理行政、比例、讲效率 | 是执法原则，但不在这六项之内 |

    * 有限政府——受法律界定的政府，各级政府的权力受法律界定，对应依法行政原则和严格执法原则。

    * 责任政府——坚持有权必有责、有责必担，对应权责统一的执法原则。

    * 人民政府——各级政府以人的基本权利和自由为依归，对应人民主体地位／以人民为中心。

    * 程序政府——重大决策和行为必须通过公众参与（民主性）、集体讨论（民主性）、专家论证、风险评估（科学性）、合法性审查（合法性），对应正当程序执法原则。

    * 阳光政府——实施信息公开，尊重社会大众的**知情权**和**参与权**，落脚在民主决策和民主监督上。

    * 诚信政府——对应诚实守信，要点是一句"维护公民信赖利益"。

    * 速记口诀"**信仰光序，人人有责**"（亦作"信仰光绪，人人有责"），六项全在其中。

* **标准与原则的错位**

    * > **注意**：人民政府是法治政府的标准，但执法原则中**没有**"民主执法"。执法是执法机关的，执法中虽有一些民主制度，民主执法不能上升为基本原则。

    * > **注意**：合理行政、比例、讲效率是执法原则，但法治政府标准里没写这三条。**这不代表法治政府不要求合理、比例和效率**——它们仍然是评价法治政府的标准，只是没写出来，原因是前面六项更迫切。

    * 选择题里有人把"合理行政"列入法治政府标准，应当选上；被追问"什么是标准、什么是原则"时说不清就掉坑。

    * 六大指标仍要背：表述极具中国特色，回答主观题好用。

### 法治社会

* **法治社会**

    * > **定义**：法治社会指社会成员崇尚法治、信仰法治，社会组织依法自治，从而建立社会秩序稳定和谐。

    * 即"社会依法治理"的简称；治理者是政府，同时叠加社会自治——法治社会强调**政府治理社会 + 社会自治**。

    * 定义包含三个层面：社会成员、社会组织、整个社会的秩序稳定和谐。

* **五条具体措施**

    * 社会成员角度——全社会树立法治意识：法律权威来自人们的真诚拥护和信仰；背到"弘扬法治精神、建设法治文化，增强人们守法的积极性"即可。

    * 社会成员角度——强化法律的权威地位：引导人们依法表达诉求、依法维护权益。

    * 社会成员角度——建设完备的服务体系：即覆盖城乡的公共法律服务体系，含加强民生领域法律服务、法律援助制度（国家出钱替你解决法律难题）。

        * 现有法律服务体系城市较完善、农村欠缺，如送法下乡、进村普法、提供法律咨询。

        * 加这一条的理由：光靠普法和依法表达，不必然让人真心爱法，法律还得能解决自己的实事。

    * 社会组织角度——社会组织多层次、多领域依法治理（依法自治），提高社会治理法治化水平，支持各类社会组织自我约束、自我管理（如协会管好会员，减轻法律压力）。

    * 整个社会治理角度——党和国家依法治理社会，实现社会治理法治化，可加"建设和谐社会"。

* **与全民守法的平替关系**

    * 全民守法实现途径中的法制宣传教育／弘扬法治精神／建设法治文化，与引导人们依法表达诉求、依法维护权益两条，同法治社会建设的第一、二条完全一致。

    * 全民守法途径中的"建设完备的服务体系"也可以搬过来，大纲没并入只是讲话场合不同、编写时未合并。

    * > **结论**：把"全民守法的实现途径"直接当五条来记。

* **三制之间的关系**

    * 法治国家是大框，分成法治政府与更基础的法治社会两个角度，二者都为实现法治国家的目标服务。

## 法治体系：标准与内容是同一套

* **法治体系的五项内容**

    * 标题虽写"标准和内容"，但两者已被混到一起，**考标准＝考内容＝考这五项**，不存在两个版本。

    ```text
    建设中国特色社会主义法治体系（五个体系）
      │
      ├── 得有法 .......... 完备的法律规范体系（立法角度）
      ├── 得能运行 ........ 实施体系：严格执法、公正司法、全民守法
      ├── 得有人来运行 .... 法治工作队伍 + 党的领导（保障体系）
      ├── 还得党 .......... 党内法规体系（从严治党）
      └── 还得有监督 ...... 法治监督体系：立、执、司、守、监
    ```

    * 答题按此次序铺开，既有逻辑又不遗漏。

### 完备的法律规范体系

* **完备的法律规范体系**

    * > **定义**：完备的法律规范体系也叫"完备的法律体系"，两种叫法完全一样，写哪个都得分。

    * 内涵：建设完备的法律规范体系，也就是**建立良法，以良法促进发展**。

    * 立法角度的四条工作，本身按从大到小排列：

    * 健全宪法的实施和监督制度。

        * 对应立法原则中"**合宪和法制统一**"一组：宪法是母法，违宪立法被清理废止，下位法被清掉一层，整部法律的合宪性就提升了。

    * 完善我国的立法体制——"体制"讲权力分工，立法体制即立法权的分工问题，指**既统一又分层的立法体制**；地方协同立法是它往下具体化的措施。

    * 科学立法、民主立法——民主立法的具体抓手如建立**基层立法联系点**。

    * 加强重点领域立法——重点领域就是**关系人民切身利益**的领域，如食品安全、药品安全、生态环境、公共安全、生产安全等，考场上可放开写。

    * 速记"**宪体制学科重点**"（顺过来念"重点学科宪体制"）。

* **概念阶梯上升法**

    * 用法主要在主观题，套路固定：左边放最小的具体情境，每往上一级换成一个更大的概念，一级一级爬到全面依法治国总目标，句与句自然串成逻辑。

    ```text
    常委会废掉某部地方性法规
            │
            │ 意义是什么
            ▼
    有利于健全宪法实施和监督
            │
            │ 上位概念：完备的法律规范体系（法律体系）
            ▼
    有利于完善中国特色法律体系
            │
            │ 上位概念：法治体系
            ▼
    有利于建设法治体系
            │
            │ 上位概念：全面依法治国总目标之一
            ▼
    落到全面依法治国总目标
    ```

    * 地方协同立法 → 既统一又分层的立法体制 → 完备的法律体系 → 法治体系 → 全面依法治国总目标之一。

    * 基层立法联系点 → 民主立法 → 深入推进科学立法、民主立法 → 法律体系 → 法治体系 → 总目标。

    * 某个重点领域的立法 → 加强重点领域立法 → 完善法律体系 → 完善法治体系 → 总目标。

    * 所谓"纲举目张"不是文采好，是概念层级搭对了；几层话像穿糖葫芦一样用一根签子串起来。

### 高效的实施体系

* **实施体系**

    * 光有立法没有实施不行；实施就是执法、司法、守法，推进**严格执法、公正司法、全民守法**。

    * 这三条中没有一条需要单独背，只需框架性掌握。

* **执法五条**

    * 依法全面履行政府职能——两个定语要抠清："依法"指法无授权不可为，"全面"指法定职责必须为。

    * 健全决策机制——公众参与、专家论证、风险评估、合法性审查、集体讨论。

    * 行政执法体制改革——如推进综合执法。

    * 严格规范公正文明执法——简称严格执法。

    * 政务公开——尊重人民群众的知情权、参与权、监督权，**以公开为常态、不公开为例外**。

    * > **提示**：执法领域具体措施与法治政府六大标准基本重合，择一背即可；六大标准是考察重点，背那个即可平替此处。

* **司法六条**

    * 与提高司法公信力的措施**完全一样**，不是平替而是一样：人民群众参与、加强司法监督、司法职权配置、独立、严格公正。

    * 口诀"**全民监职独严**"，六条一条都对得上；只标注原理出处即可划掉。

* **守法**

    * 全民守法的几大措施已有，此处无任何展开。

    * 框架性掌握：实施体系＝执、司、守；执法用法治政府六大标准，司法用"全民监职独严"，守法用实现全民守法的四大措施。

### 严密的法治监督体系

* **法治监督体系**

    * 对应法治环节的第五个"监"：立、执、司、守、监，**法治五连鞭**。

    * 监督要全面：既对立法监督，也对执法、对司法监督；中央文件只说了两段，这两段需单独掌握。

* **重点一：特别强化对行政权的监督**

    * 加强行政权的党内监督、人大监督、民主监督、司法监督、监察、审计、社会舆论等建设，形成科学有效的权力监督体系，增强**监督合力**。

    * 国家监督按四项写即可：人大及其常委会监督、司法监督、监察监督、审计（教材未写行政监督，按四项写背诵压力最小）。

    * 社会监督包括党的监督、社会组织监督、社会舆论监督、人民群众监督，即守护中国法治的八类监督形式。

    * 掌握角度只有一条：国家监督、社会监督，形成监督合力。

* **重点二：尤其加强对政府内部权力的制约**

    * 内部权力没有行政相对人（普通人），**不容易被公众发现**，一旦滥用老百姓也难察觉，如三公消费拿矿泉水瓶灌茅台。

    * 完善政府的内部层级监督和专门监督：

        * 层级监督——上级对下级监督，下级有做得不好的，上级机关得尽快处理。

        * 专门监督——纠错、问责这类，包括对官员的处理处分、审计各部门怎么花钱；可列举道歉、停职、辞职等方式。

    * 把行政权制约监督列为重点的理由：**执法具有广泛性、单方性、主动性等特征**，管得宽。

    * 第一条可用法治政府那套原理平替；第二条掌握到层级（上下级）与专门（纠错、问责，审计也属专门监督）两块即可。

### 有力的保障体系

* **法治工作队伍的三个层次**

    * 专门队伍：专指吃国家饭的法律人员——立法者、执法者、司法者。

    * 服务队伍：法律领域的服务人员，如律师（特别是律师队伍建设）、仲裁员、公证员、调解员。

    * 人才队伍：理论人才和实践人才。

    * > **易错点**：⚠️ 不要把律师纳入专门队伍。律师属于"**游击队**"，属于服务人员，不吃国家饭。

    * 人才队伍与专门队伍、服务队伍会有重合：律师也要讲理论和实践，执法者主要是实践人才但也要懂理论。

* **加强和改进党对全面依法治国的领导**

    * 三条：把党的领导贯彻到法治的**全过程和各方面**；强化**依法执政**，让党组织领导干部认识到依法执政是关键；完善党内法规。

    * 三条可用党的领导的基本原则平替（全过程、各方面、依法治国与依法执政相统一），只需保留标题。

### 完善的党内法规体系

* **党内法规体系**

    * 定位：党中央对全面从严治党提出的主张，是**依法治国与依规治党相结合的具体体现**。

    * 两层逻辑：

        * 党内法规首先要**与法律相衔接**，衔接好了才有利于依法治国。

        * 党内法规的标准**高于法律**，有利于从严治党（有利于依法执政）；如党员干部包二奶、违规吃喝，不违法但违反党内法规。

    * 所以党内法规这个产物一方面衔接法律、有利于依法治国，另一方面高于法律、有利于从严治党，这就是二者相结合的具体表现。

## 法治轨道上的中国式现代化

* **中国式现代化的五个特征**

    | 特征 | 一句话理解 |
    | :--- | :--- |
    | 人口规模巨大的现代化 | 不同于小国治理，是大国治理 |
    | 全体人民共同富裕的现代化 | 即以人民为中心 |
    | 物质文明和精神文明 | 两者都要 |
    | 人与自然 | 即生态文明 |
    | 和平发展 | 了解即可，没有可考点 |

    * 含义不属于背诵内容，属政治学科要讲的内容。

* **在法治轨道上实现中国式现代化**

    * 实质是把习近平法治思想贯彻到位，**列十一个坚持就够了**。

    * 教材另列的四项概括只从十一个坚持中挑出四个：党的领导（第一坚持）；紧扣现代化国家推进法治建设（对应法治国家、法治政府、法治社会一体建设）；围绕公平正义（对应以人民为中心／人民主体地位）；以系统观念谋划法治建设（对应法治体系）。

    * > **结论**：哪一坚持都不敢不用于建设现代化，所以考到时列十一个坚持即可覆盖。
