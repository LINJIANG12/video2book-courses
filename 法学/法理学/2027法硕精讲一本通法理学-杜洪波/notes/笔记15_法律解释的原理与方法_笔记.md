# 法律解释的原理与方法

## 法律解释的概念与任务

* **法律解释**

    * > **定义**：一定的人或组织对法律规定的含义所作的说明。

    * 定义本身即含"人人可解释"：理解谁都可以解释法律，不专业者解释的可能是错的。
    * 区别只在有无效力：最高人民法院的解释可能有效力；张三、街头说书人对刑法、民法的解释同样是法律解释，只是没有效力。
    * 法律解释、法律推理、法律论证三者合称法律方法。

* **法律解释的任务**

    * > **定义**：通过研究法律文本及附随情况，探求它们所表现的法律意志。

    * "法律意志"与法律精神、法律目的、法律价值同指一物，是同一章内交替使用的说法。
    * 附随情况指解释时的参照材料不限于文本，如结合立法时的实际情况、结合他国情况解释法条。
    * 关键词：对象是法律规定；路径是"文本＋附随情况"；目标是法律意图。

## 法律解释的四个特征

### 以法律为对象，靠附随情况才读得懂

* 第一个特征从字面即可推出：解释对象必是法律。
* 任务是通过研究法律文本及附随情况探求法律意志。
* 附随情况实例：宪法规定总统是海军陆战队的总司令、未写空军；当时立法只有海军和陆军，于是该条真实意思是总统为美国所有军事力量的总司令，条文中"海军、陆军"指代所有军事力量。
* 该例即一次扩大解释，扩大依据正是立法当时的背景。

### 与具体案件密切相关

* 第一个含义：法律解释**往往**由案件引起——"往往"是"大部分"而非"全部"。
* 办案环节的解释必然由案件引起，没有案件就没有效力；少数例外是最高院凭专业理解对民法典所作的解释。
* 第二个含义：解释时还须与案件事实相结合，才能做出与案件配套的解释。
* 案例：甲趁乙不在家把鱼放归大海，不构成盗窃罪（无非法占有目的、损人不利己），应构成故意毁坏财物罪；法官须说明"毁坏"既包括财物本身被毁，也包括使用价值被毁。
* 配套性反证：若判决只写"毁坏指使财物物理形状发生损毁"，当事人必然不服，因为放归大海并未损毁物理形状，说明与案件不搭。
* > **易错点**：法律解释与案件相关，但不是所有解释都根据案件作出，最高院对民法典的解释就是反例；"与具体案件密切相关"主要说的是办案环节。

### 解释过程就是一场价值衡量

* > **定义**：法律解释的过程是一个价值判断与选择的过程，也就是价值的衡量。

* 衡量的是法律背后的价值：保障自由、守护秩序等立法目的。
* 解释者本人也有价值衡量，因为探求立法目的必然涉及解释者自己的理解；最理想状态是解释者的价值与立法者价值保持一致。
* 但不能因此说法律解释是纯主观活动，因为法律价值本身是主客观统一体。
* 案例：按一般理解小型出租车也是公共交通工具，最高院解释"公共交通工具上抢劫"时把范围限于中大型交通工具；理由是中大型工具对社会秩序的潜在危害更大。
* 掌握点是标题之外的后半句：法律解释过程是价值判断和选择的过程。

### 受解释学循环制约

* > **定义**：解释学循环的中心问题是，对整个法律的理解只有通过理解它的部分才能实现，而对法条的理解又只能通过理解整体来实现。

* 学者概括：法律人的目光要在事实与规范之间、前提与结论之间来回流转。
* 双重目的：既避免只见树木不见森林（有具体法条而忽视整体精神），也避免只见森林不见树木（懂整体精神而对法条一窍不通）。
* 甲案对照：入写字楼盗窃、拒捕时施暴致保安重伤，按构成要件直接转化为抢劫罪并适用致人重伤的升格法定刑，10 年至死刑，甲不是疑难案件。
* 乙案对照：先入室抢劫、抢得财物后拒捕又致保安重伤。普通抢劫与故意伤害致人重伤并处最低 3 年、最高 20 年，而更温柔的甲却判 10 年至死刑，罪责刑相称与罪行不相称被质疑。
* 循环落地：把乙的第一个行为只评价"抢夺"部分（抢夺是对物暴力，抢劫是对人暴力，抢劫升格后成为抢劫），以凑合"盗窃、诈骗、抢夺"的法条，从而适用转化型抢劫一罪及致人重伤的升格法定刑——这样才能把法条解释通。
* 能力前提：只有整体把握了本学科的精神，才能主动发现案件中隐含的问题，进而实现循环、对法条作出创造性解释；只会盯单个法条、忽略原则与价值的法官无法主动实现这一循环。
* 后果提示：很多法官办案只见法条、只见规则，忽略原则、价值和精神，案件结论因此出错。
* 判断顺序由此确定：解释学循环的成败决定裁判结论，裁判结论又要反过来检验解释方法。

```text
  ┌──────────────────┐             ┌──────────────────┐
  │ 法律整体（精神） │── 理解部分 ─│ 具体法条（部分） │
  │ 价值 · 正义 · 原则│             │ 条文 · 构成要件  │
  │                  │── 理解整体 ─│                  │
  └──────────────────┘             └──────────────────┘
                                ↓  解释
  ┌──────────────────┐          ┌──────────────────┐
  │ 案件事实（个案） │─ 结合 ── │ 解释方法 A/B/C/D │
  └──────────────────┘          └──────────────────┘
                                ↓
  ┌──────────────────┐          ┌──────────────────┐
  │ 选择解释方法     │←─回头─→  │ 解释结论         │
  └──────────────────┘          │ 合法？合理？     │
                                └──────────────────┘
```

## 法律解释的必要性

### 五个理由

* **抽象的法条撞上具体的案件**

    * 法律是概括的、抽象的，案件事实是具体的、特定的。
    * 所有规范都必然遇到抽象与具体、概括与特定的不对称，解释因而必然存在。
    * 即使已有立法解释、司法解释，判案时仍需再解释：只要是文字，法条也好、解释也好，相对案件事实都具有抽象性。
    * > **提示**：法律格言"法律未经解释，不得适用"。

* **认识不统一需要权威解释**

    * 人们的认识能力、认识水平、动机存在差别，需要有权威性的解释统一理解，保证法的统一性。
    * 例："暴力、胁迫或者其他方法"中的"暴力"——有人认为打一耳光即暴力，有人认为必须拿刀指人才算。
    * 关键词是**统一性**。
    * > **提示**：权威性不限于国家机关，学术权威也可，但其解释没有直接效力。

* **立法存在漏洞或矛盾**

    * 规范冲突例：想象竞合择一重，择一重本身就是一种解释。
    * 漏洞形态："该规定不规定"或"规定得不清楚"。
    * 漏洞例：开设赌场罪是否包括网络赌场——立法者原本想不到这种事，须通过解释填入。

* **法律存在滞后性**

    * 需通过解释解决稳定性与发展之间的矛盾。
    * 滞后性指社会的发展导致法律新漏洞出现，属广义漏洞。
    * > **注意**：法律解释可以赋予法律规定新含义，法律落后时修改立法并不是唯一手段。

* **普法教育的需要**

    * 关键词是**法制教育（宣传）**。
    * 例：刑法条文的"多次盗窃""数额较大"对非专业者模糊，最高院解释"数额较大"为 3000 元以上（有的地区 800 元以上）、"多次"为两年内三次后才看得懂。

### 记忆口诀与内在外在之分

* 五个理由可分两个方向：法律本身的毛病（冲突、漏洞、滞后）与法律同外界的毛病（事实太具体、人们理解不一致、人需要被教育），即内在矛盾与外在矛盾。
* 口诀对照表：

| 要记住的关键词 | 取这个字 |
| :--- | :--- |
| 抽象 | 象 |
| 统一 | 一 |
| 漏洞 | 漏 |
| 矛盾 | 矛 |
| 宣传教育 | 毛 |

* 口诀：大象露出一角毛。大象即抽象，露即漏出，一即统一，角是顶牛的角即矛盾，毛是大象脚上的毛。
* > **易错点**：两个"矛盾"不是一回事——前面的矛盾指法条之间的冲突，后面的矛盾指法律与社会发展之间的冲突。

## 按解释主体与效力的分类

### 正式解释

* > **定义**：正式解释，也叫法定解释、有权解释，是指有法律依据的特定国家机关、官员或其他有解释权的人所作的具有法律约束力的解释。

* 拆解："法定"指有法律依据；"特定"指特定国家机关、官员或其他有解释权的人；"法律约束力"即**普遍效力**。
* 有普遍效力的正式解释称为**规范性法律文件**，与正式渊源并列，同属两大类。
* 是否属于正式渊源学界有争议，**通说认为属于正式渊源**。
* 我国现阶段的正式解释只有立法解释、司法解释、行政解释三种，全部是规范性法律文件。
* > **易错点**：定义宽而现实窄。我国现阶段正式解释不包括官员或个人，但定义含三类主体，因为法理学要研究古今中外的共性问题——张斐、杜预注释晋律而得"张杜律"，古罗马以乌尔比安为代表的五大法学家，判例法国家法官在判案中对法律与判例的解释，都是历史上的正式解释。
* 相关判断：法学教授结合现行制度解释《未成年人保护法》，既属体系解释（从上下文、相关制度找理由），也属非正式解释即学理解释。

### 非正式解释

* > **定义**：非正式解释，也叫学理解释，是指由学者或者其他人和组织所作的不具有法律约束力的解释。

* 大纲曾用"无权解释"这一名称，后被删除，但做旧真题仍可能遇到。
* 主体不限于学者，还包括其他人和组织。
* > **易错点**：学理解释不一定真的具有学术性，它也可能是常识性的、歪理的。

### 非正式解释不等于非正式渊源

* 正式解释与正式渊源长得像且都有普遍法律效力；非正式解释与非正式渊源则千差万别，只有一点点交叉关系。
* 交叉点仅两处：非正式解释中的法律学说、判例中的解释，同时又是非正式渊源中的法律学说与判例。
* 不交叉的部分：非正式渊源还有道德、伦理、习惯、政策；非正式解释还有学者的个人解释、普通人的土话解释乃至胡说八道的瞎解释。
* 结论：不要把非正式解释纳入非正式渊源之中。

```text
  ┌──────────────────┐          ┌──────────────────┐
  │ 非正式解释       │          │ 非正式渊源       │
  │ 无普遍法律效力   │          │ 无普遍法律效力   │
  │ 法律学说 ※       │←─交叉─→  │ 法律学说         │
  │ 判例中的解释 ※   │←─交叉─→  │ 判例             │
  │ 学者的个人解释   │          │ 道德 · 伦理      │
  │ 普通人的土话解释 │          │ 习惯 · 政策      │
  └──────────────────┘          └──────────────────┘
```

* 本节复习重点：分类标准以及由标准派生的两个定义——主体是谁、有没有效力。

## 按解释尺度的分类

* 分类标准是解释的尺度：尺度大、尺度小、不大不小。
* > **定义**：限制解释（缩小解释、缩减解释、搜查解释）指为贯彻立法意图或反映社会需要，作出比字面含义**窄**的解释。
* > **定义**：扩大解释（扩充解释）指为贯彻立法目的或反映社会需要，作出比字面含义**广**的解释。
* > **定义**：字面解释指严格按照字面的通常含义来解释法律，不大不小。
* 记忆感觉：法律字面意思即字面解释，往里缩是限制解释，往外扩是扩大解释，中间是不大不小。

| 类型 | 又称 | 尺度 | 关键词 | 例子 |
| :--- | :--- | :--- | :--- | :--- |
| 限制解释 | 缩小解释（缩减、搜查） | 比字面含义窄 | 往里缩；加定语 | "子女对父母有赡养义务"中的"子女"专指成年子女 |
| 字面解释 | — | 与字面含义相当 | 不大不小 | "机动车"不包括人力车、畜力车；"妇女"不包括男性 |
| 扩大解释 | 扩充解释 | 比字面含义广 | 往外扩 | "开设赌场"是否包括网络赌场；"金融机构"是否包括 ATM 机 |

* **加定语是缩小解释的典型特征**，因为定语正是为了限制后面的关键词。
* 扩大解释的典型是把新型事物读入旧概念，如网络赌场、ATM 机归入金融机构。
* 字面解释给人的感觉是废话型解释，但正是这种"照字面办"保证了确定性。
* > **注意**：扩大解释不是任意扩大，缩小解释也不能随意做小，二者都要以立法目的、立法意图、反映社会需要为限。
* > **易错点**：两种分类是交叉的。正式解释可能作扩大、缩小或字面解释，非正式解释同样如此，因为分类角度不同，不要把它们绝对对立。

## 法律解释方法：六种理由出处

* > **定义**：解释方法是在进行解释时为了实现解释目标而使用的方法。

* 主线：这六种方法说到底是**六种不同的理由出处**；理由出处不同，解释结果就可能不同。
* 该部分命题频率较高，识别方法要从"理由出处"入手，不能凭感觉。

### 文义解释

* > **定义**：文义解释是指遵循法律规范字面含义的解释。

* 又名语法解释、文法解释、文理解释；文义即文字之意，文理即文字的道理，文字由语法连缀而成。
* 理解上可等同于字面解释（在刑法上称平义解释），二者没有差别。
* 找理由的四个角度：
    * **字义本身**，就词论词，如"妇女"不包括男性。
    * **语法**，如"国家机关有权依法征收征用，并给予补偿"——"依法"是状语，修饰两个并列动词，故补偿也须依法进行，标准取决于法律规定的是市场价还是政府评估价。
    * **通用表达方式**，按一般人理解，如买车含轮胎、买手机含充电器。
    * **逻辑表达**，主要是文字顺序，如"故意杀人的，处死刑、无期或者十年以上"是由重到轻的排列，故既遂的故意杀人应从死刑往下找从轻情节；而刑法一般刑罚条款是由轻到重的写法。
* 必背特征二条：
    * 目的是使人们理解法律规范中**立法语言的含义**。
    * 焦点集中在语言上，**不顾及结果是否公正合理**——结果可能公正也可能不公正。
* > **提示**：文义解释并非一无是处，它对法律的冲击力度最小，最大限度实现法律的确定性与可预测性；法律格言"法律的最好解释者是法律本身"即指此。

### 历史解释

* > **定义**：历史解释是指通过法律文件制定的时间、地点、条件等历史背景材料，或者将所解释的法条与历史上同类法律规范相比较，来阐明法律规范的内容和含义。

* 两个切入点：历史背景与历史上同类法律规范，概括为**老背景、老法条**。
* 之所以要研究背景：不同历史背景下同一词语含义不同，如"我讨厌你"须联系说话时的具体情境才知真意。
* 关键词是**延续性**：探讨某一法律词语如何进入法条、当初基于什么考虑。
* 案例：某男在大街上以追逐、推搡等方式骚扰不特定女性，构成流氓罪；流氓罪的大部分规定已被寻衅滋事罪吸收，故应定寻衅滋事罪——从老法条或老背景为今天的法条找理由。
* 判断应用：解释者依据最高院 1985 年的案例作解释，既非老想法也非老背景、老法条，而是老案例，归纳不到大纲规定的六种方法内，属**类推解释**；若改为"结合立法时的社会背景"则是历史解释。

### 系统解释

* > **定义**：系统解释（又叫体系解释）是指通过分析某一规范在整个法律体系和法律部门中的地位和作用来解释这个规范。

* "地位和作用"实质是指这一规定**与其他规定的关系**——是补充其他规范还是与其他规范冲突。
* 一句话概括：**联系上下文**；同一个词上下文不同含义不同，日常说话也不能断章取义。
* 例：想象竞合择一重；法条竞合特别法优先（用合同方式骗人定合同诈骗罪而不定诈骗罪）。
* 关键词：法律规范之间在**相互配合下发挥作用**，理解本条款还须联系其他关联条款。
* 判断应用：结合上下文作出的解释即体系解释；结合现行相关制度解释某法条（如同现行制度解释《未成年人保护法》）也属体系解释。

### 目的解释

* > **定义**：目的解释是指从制定某一法律的目的来解释法律。

* 本质是从法律的价值与精神中找理由。
* 第一个坑：目的不仅指制定该法时的目的（**立法者的主观目的**，简称**老目的**），也可以探求该法律在当前条件下的需要，即发现法律的新价值（**新目的**）。
* 老目的的参照物通常是立法释义、立法说明、立法者的相关言论（如人大代表在人大会议上的发言、讨论法条时的发言）。
* 新目的的参照物是新的价值和精神，如原立法者为保障秩序，今日该条更应偏向保障人权。
* 第二个坑：目的既可指整部法律的目的（**大目的**），也可指个别法条、制度的目的（**小目的**）。
* 大目的实例：刑法具有谦抑性，两年内偷舍友五次外卖虽已满足两年内三次以上的盗窃标准，仍不应定盗窃罪。
* 小目的实例：私密状态下的聚众淫乱不构成聚众淫乱罪，因为该罪的立法目的是保护公众的性感情。
* 高铁厕所抢劫案：按文义解释应属公共交通工具上抢劫，但封闭厕所内抢劫不影响他人、无公共秩序风险，仍如此定罪量刑违反罪刑相适应精神，这是目的解释。
* 新老目的的识别：题干出现"立法者的意图"指向老目的；只笼统说"法律的精神、法律的原则"指向客观目的即新目的；考试一般不要求细分。
* 消费法例：消费者指为生产和生活而购买商品的人。A 法官据常委会立法说明（老目的）认为知假买假者不是消费者；B 法官认为知假买假再索赔在食品药品领域有利于打假，应附条件承认其在该领域也是消费者，理由出处是保障群众健康权这一新的价值。

### 社会学解释

* > **定义**：社会学解释是基于社会效果的预测和社会利益的衡量来解释法律。

* 与其他方法的分野：不是从法律本身的价值与精神出发，不是从立法者原来的想法出发，不是从别的法条出发，而是从**社会影响好不好**出发。
* 所属学派：由**社会法学派**贡献的解释方法。
* 案例一：冒充军警人员抢劫是十年以上至死刑（既侵犯财产又损害军警形象与权威）。若真警察抢劫，按字面不是"冒充"，反而是普通抢劫三到十年，但真警察抢劫对警察权威的危害更大、连解释空间都没有，不升格则老百姓接受不了——这就是社会学解释。
* 案例二：甲乙开枪致丙死亡但无法查明谁开的枪。甲法官从目的解释出发主张疑罪从无，定故意杀人未遂；乙法官认为人都死了却都定未遂社会大众无法接受，应定故意杀人既遂——由此产生社会一般看法与专业法律价值及精神之间的冲突。

### 比较解释

* > **定义**：比较解释是比较外国的立法和判例、原则、经验等来解释本国的法律。

* 本质是**从外国找理由来解释本国法律**。
* 案例：开饭店者对醉酒后在本店休息的顾客是否负有照顾义务，我国法律没有规定，而外国很多国家的判例认为应当履行。
* 之所以能取自外国：各国虽不同，毕竟都属于搞法律的，仍有参照与借鉴意义。

### 六种方法的选择顺序

* 顺序是：文义 → 体系 → 目的 → 历史 → 社会现实 → 比较。
* 递进逻辑：就文字谈文字说不清，就去找上下文；上下文在制度内解决不了，就去找法律的价值与精神；价值和精神上找不到理由，就回到立法者的生活环境与历史；历史也不行，就从当前社会现实找；现实还不行，就只剩外国。
* 规律：越往后对既有法律的冲击越大，参照系越来越远，可操作性越来越大。
* 文义解释做出来的就是字面解释（平义解释）；其余方法可能作扩大解释、也可能作缩小解释、也可能作平移。

```text
   理由出处  ──►   文义          就文字谈文字
                     │  文义解决不了
                     ▼
                 体系/系统        上下文、其他规定
                     │  体系解决不了
                     ▼
                  目的          法律的价值与精神
                     │  目的解决不了
                     ▼
                  历史          老背景、老法条
                     │  历史解决不了
                     ▼
            社会现实/社会学        老百姓答不答应
                     │  现实也解决不了
                     ▼
                  比较          外国立法与判例
```

### 两组最容易混的方法

* **历史解释与老目的解释**

    * 相同点：都是去推敲、推测立法者当时的想法。
    * 不同点：历史解释从过去的外在社会条件出发，理由出处是**老背景**、旧社会条件；老目的直接来自立法者的**言论**。
    * 距离上老目的解释离立法者原意更近，因为它就是相关言论。
    * 变式判断：结合该法律**当前**的社会背景 → 社会学解释；结合**当前条件下法律的新价值** → 新目的解释。

* **社会学解释与新目的解释**

    * 相同点：都受社会影响，都联系了社会现实需要。
    * 不同点：社会学解释直接从"社会影响好不好"出发；新目的解释从更专业的法律价值出发，而这种价值老百姓可能不认同。
    * 一句话：老百姓认同什么就怎么解释，是社会学解释；从专业法律价值出发，是新目的解释。

### 洗碗故事：六种方法的完整串联

* 事实：受爱人指令只洗了两个人的碗，筷子、盘子、锅一律未动，晚上因此发生争论。

| 争论中说出的话 | 理由的出处 | 落到哪种解释 |
| :--- | :--- | :--- |
| 你清楚地发了一个指令，我完全执行了 | 指令的字面意思 | 文义解释 |
| 我的真实意思是把碗在内的所有餐具 | 她把真实想法说出来 | 老目的解释 |
| 以前让我洗碗，别的都是你收拾的 | 前后的变化、当年的老背景 | 历史解释 |
| 隔壁老王是英国人，又洗碗又收拾还挣钱 | 外国的做法 | 比较解释 |
| 这样不公平、没有正义 | 新的价值与精神 | 新目的解释 |
| 我好歹是个老师，在家没地位影响不好 | 社会观感好不好 | 社会学解释 |

* 方法论意义：解释方法就是理由的出处，理由出处不同可能导致解释结果不同，这也是辩论与质证的技巧。

## 中国法律解释体制

* 解释体制就是**解释权限的划分**。
* 我国体制：以**全国人大常委会为核心和主体**，各机关分工配合。
* > **提示**："各机关"的"各"不是泛指所有其他机关，准确说法是"**其他特定机关**"，一字之差即考点。
* 正式解释据此切分为立法解释、司法解释、行政解释三种。

### 立法解释的三个层次

* 广义、狭义、最狭义的层次差异：

| 层次 | 谁在解释 | 解释什么 |
| :--- | :--- | :--- |
| 广义 | 有权制定法律法规的国家机关或授权机关 | 自己制定的法律法规 |
| 狭义（较宽的一种观点） | 全国人大常委会 ＋ 地方人大常委会 | 宪法、法律 ＋ 地方法规 |
| 最狭义 | 全国人大常委会 | 宪法、法律 |

* 广义一句话：**谁制定谁解释**。
* 因此国务院解释行政法规，按广义属于立法解释；但教材的分类把它叫作**行政解释**。选项问"国务院对行政法规所作的解释属于什么"，答案是行政解释或广义的立法解释，绝不是狭义的立法解释。
* 狭义的两种观点：最狭的一种专指全国人大常委会对宪法、法律的解释；不太狭的一种还包括地方人大常委会对地方法规的解释。
* 教材采用的最狭义是**一个主体、一个对象**：全国人大常委会解释法律。
* "地方人大常委会"指**省级人大常委会**，不指设区的市人大常委会——设区的市有立法权但立法水平较差，其法规由省级人大常委会批准；故省级人大常委会解释的是自己制定的省法规加上自己批准的市法规。
* 三个连带的判断：
    * 全国人大常委会解释的对象是**狭义的法律**，即全国人大及其常委会自己制定的法律。
    * 全国人大常委会对**地方法规**所作的解释不能叫立法解释，只能算非正式解释。
    * 全国人大常委会对**宪法**的解释，按学界通说属于**宪法解释**，不属于立法解释。
* 结论：选择题中"立法解释"只能理解为对**现有法律**的解释。
* 典型判断：全国人大常委会认为刑法关于文物的规定也可适用于化石，这是扩大解释；全国人大代表、法学教授另提解释，性质上是非正式解释中的学理解解释，一人兼两职不代表一份解释有两种性质；立法解释的效力与法律相等。
* 效力判断顺序：先定方法（扩大还是限制）→ 再定性质（正式还是非正式）→ 最后定效力。

### 立法解释的地位

* > **定义**：立法解释处于核心和主导地位，与法律有同等效力。

* 出身决定效力：效力高低看制定机关，立法解释出自全国人大常委会，故与全国人大及其常委会的立法有同等效力。
* 人大体制决定核心：人大是政体，常委会是人大的常设机关即"大管家"，其解释最符合政治体制。
* 效力推论：立法解释高于行政法规、高于司法解释。

### 立法解释的任务

* **其一，凡法律条文本身需要明确界限或补充的，由常委会解释，或者用法律来立法**

    * "本身"即条文自身有毛病，类比药品说明书本身有毛病，谁写谁解释。
    * 第一层：阐明法律实施中产生的异议，即法律规定本身不清楚、不明确。
    * 第二层：法律条文虽然清楚，但用法律的人不了解立法者的立法精神，需要立法者再说一遍。
    * 归纳为**制度不清楚、精神不清楚**两条路。
    * 分寸感：毛病不大就以解释处理，毛病大就等修改立法，两条路都通。
* **其二，适应社会发展，赋予法律规定以新含义**

    * 即通过解释补充法律，可表现为扩大解释、缩小解释。
    * 关键在第一句"赋予新含义"。
* **其三，解决法条冲突以及司法解释之间的冲突**

    * 特别法优于一般法、新法优于旧法不合适时（如旧法更合适），需立法机关出面。
    * 最高检与最高院各自作出的司法解释可能打架，能同时管住二者的机关是全国人大常委会。
    * > **易错点**：常委会以立法解释方式废掉错误的司法解释，不等于常委会自己做司法解释——是它们打架，凭地位高去管。

* 口诀：一心冲一冲，内容即两块疑义、一块新含义、两块打架——条文本身不清楚、立法精神没说明白、赋予新含义、法条冲突、司法解释冲突。

### 谁能提要求：七大直系

* 设置启动程序的理由：常委会自己主动发现自己的法律有毛病较难，由其他机关帮它发现。
* 可向全国人大常委会提法律解释要求的机关：

| 身份 | 具体机关 |
| :--- | :--- |
| 亲小弟（中央的直系） | 国务院、中央军委、最高人民法院、最高人民检察院、国家监察委员会 |
| 亲大儿子（嫡长子） | 省级人大常委会 |
| 自己人 | 全国人大专门委员会 |

* 专门委员会归常委会领导，是全国人大留下的专业队伍。
* > **易错点**：设区的市人大常委会不能提要求（"二儿子"），它有意见应通过省级人大常委会转达。

### 司法解释的定义与对象

* > **定义**：司法解释是最高司法机关对司法中具体应用法律问题的解释。

* 关键词一"最高"：不是"司法机关的解释"的简称，地方法院不能作司法解释，只有最高院、最高检。
* 关键词二"司法工作中的"：最高院、最高检不能替国务院解释行政管理上的事。
* 关键词三"具体应用"：具体应用问题不同于法律本身问题——说明书本身有毛病由制定者解释，本身没毛病而是用的人看不懂才是具体应用环节。
* 判断句：**本身问题找制定机关，具体应用问题找应用机关**。
* 对象只限**狭义的法律**，即全国人大及其常委会制定的法律，不含广义法律。

### 司法解释的种类

* **审判解释**：最高院对审判中具体应用法律问题的解释，关键词是最高院、审判中。
* **检察解释**：最高检对检察工作中具体应用法律问题的解释，关键词是最高检、检察工作。
* **联合解释**：最高院和最高检为协调配合可采用联合解释方式，如关于非法证据排除的有关规定，公安机关所取非法证据在两机关均应排除。
* 复习重点是司法解释、审判解释、检察解释、联合解释四个定义，记忆抓手是主体。

### 司法解释出毛病的救济

* 最高院的司法解释、最高检的检察解释或两者打架时，全国人大常委会有三种处理：
    * 作出立法解释，用上位法把错误的司法解释废掉。
    * 依法予以撤销——撤的是那个解释，不是撤机关。
    * 要求最高院或最高检修改、废止。
* 无论毛病在最高院、最高检还是两高一起，上述三条路都留着。
* 判断："最高院、最高检具体应用法律的解释没有毛病的，全国人大常委会有权撤销"——**正确**，它问的是权力范围，不要求先有毛病才使得上该权。
* 冲突报请对象：最高院与最高检的司法解释打架，应报请**全国人大常委会**，不是全国人大。

### 司法解释的作用

| 共同机理 | 法律解释的必要性 | 司法解释的作用 |
| :--- | :--- | :--- |
| 抽象到具体 | 第一条 由抽象到具体、从概括到特定 | 第 1 条 规定不够具体、执行有困难时赋予具体内容 |
| 适应变化 | 第四条 解决法律与社会发展的滞后性矛盾 | 第 2 条 通过解释适应变化了的新社会情况、赋予新含义 |
| 统一认识 | 第二条 统一人们的理解和认识 | 第 3 条 统一人们的理解 |
| 弥补立法不足 | 第三条 解决法律漏洞和冲突 | 第 5 条 弥补立法的不足 |
| 独有项 | 第五条 法制教育（宣传） | 第 4 条 程序性解释：法院之间相互配合、管辖等 |

* 两者是平替关系：共有四条一一对应，解释的必要性多一条宣传教育，司法解释多一条程序性解释。
* 第 1、2、3、5 条不必单独背，把解释的必要性讲扎实即可。

### 行政解释

* > **定义**：行政解释是最高国家行政机关对法律法规的解释，即国务院及其主管部门对法律法规的解释。

* 按说最高国家行政机关只是国务院，但文件表述含主管部门。
* 两个主体：国务院、主管部门（部委行署）；两个对象：法律、法规。
* 两类表述：国务院及其主管部门对不属于审判、检察工作的法律所作的解释；国务院及主管部门对自己制定的法规所作的解释。
* 两主体乘两对象至少可拆出四类：

| :--- | :--- | :--- |
| :--- | 解释法律 | 解释行政法规 |
| 国务院 | 解释法律 | 解释行政法规 |
| 主管部门（部委行署） | 解释法律 | 解释行政法规 |

* > **提示**：行政解释在我国比较少见，见得最多的是司法解释，其次是立法解释。

### 正式解释对象的通则

* > **结论**：正式解释的对象（客体）仅限"**比自己级高的**"和"**自己制定的**"。

* 全国人大常委会：比自己级高的是法律。
* 国务院：比自己级高的是法律，加上自己制定的行政法规。
* 最高院、最高检：比自己级高的是法律，但二者没有立法权，因此谈不上"解释自己"这一路。
* 由通则可推出：**国务院不解释规章**——规章不是它自己制定的（那是部委行署制定的），也不是比它级高的（只有法律比它高）。
* 由此判断"规章需要解释的，应报请国务院"为**错误**。
* 地方性法规的具体应用问题一律由**省级政府（及其主管部门）**处理，不再区分是司法领域还是行政领域；地方上没有省高院、省检察院什么事，地方上只有本身的省人大常委会和应用的省政府两方。
* 反面推论：把"制定法规的常委会"安到"具体应用问题"上是错的，具体应用问题应由相应的政府部门处理。

## 解释方法识别与判断顺序

* 识别规则：从"理由的出处"判断，不要凭感觉，也不要见"过去"就一律判为历史解释。
* 选项常见变形对照：
    * 依据最高院 1985 年案例解释 → 老案例，归纳不到六法，属类推解释。
    * 结合立法时的社会背景 → 历史解释。
    * 结合该法律当前的社会背景 → 社会学解释。
    * 结合当前条件下法律的新价值 → 新目的解释。
    * 结合上下文 → 体系解释。
    * 按法律条文字面含义 → 文义解释。
* 综合判断三步：先定方法（扩大还是限制）→ 再定性质（正式还是非正式）→ 最后定效力；选项最爱在这三步上做手脚。
* 分类复习收口：按主体与效力分正式与非正式，按解释结果与字面含义的关系分限制、字面、扩大，按解释方法分文义、历史、系统、目的、社会学、比较。
* 特征收口：一个对象（大前提即法律规定），三个影响（大前提背后的价值、小前提案件事实、结论）。
