# 2027 法硕《精讲一本通》法理学（杜洪波）

众合杜洪波老师的法硕法理学精讲。课程从法理学的学科定位与法学研究方法切入，依次讲法的概念、本质、起源与法系格局，法的功能、局限与价值体系，法律渊源、效力与分类，以及法律规则、法律原则与法律体系；再落到立法、执法、司法、守法与法律监督的制度层面，最后收在法律职业、法律解释与法律方法，以及法治的内涵与法与社会。

- **原视频**：https://www.bilibili.com/video/BV1HuPKzLEhE — Bilibili，BV1HuPKzLEhE
- **68 集**，已产出 12 册模块全书、21 篇复习笔记、68 份逐字稿

## 怎么学

- **学科定位** → 模块 01 先把法理学在整个法学体系中的位置讲清，避免与各部门法混同
- **法的本体** → 模块 02~04 讲法的概念本质、起源法系，以及功能局限与价值体系，是全课的概念基础
- **形式与体系** → 模块 05~06 讲法律渊源、效力与分类，以及法律规则与法律原则的体系构成
- **制度运行** → 模块 07~08 覆盖立法、执法、司法、守法与法律监督，回答法如何被实施
- **方法论** → 模块 09 讲法律职业、法律解释与法律方法，是简答与论述题的高分点
- **法治观** → 模块 10~12 收在法律关系与法律责任、法治原则与法与社会互动，串联全课
