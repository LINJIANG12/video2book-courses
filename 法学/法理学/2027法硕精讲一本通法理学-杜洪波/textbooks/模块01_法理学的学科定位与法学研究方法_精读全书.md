## 备考心法与法治底层逻辑：法理学开篇两课
> 对应块：BLK01 | 覆盖分集：P01-P02 | 块标题（分集名）：《前言》

2027 届的各位法硕考生朋友们，大家好。正式开始法理学精讲一本通之前，我想先花十几分钟，跟大家聊一点跟考试没那么直接相关、但比考试更重要的东西——这门课该怎么备考。

为什么开篇要讲这个？因为我自己当年就是这么熬过来的。

### 我为什么反复刷《凡人修仙传》

先说《凡人修仙传》。这部剧我反复刷过很多遍。最初刷它，是因为国漫竟然能做到这么好；后来真人版出来，我又刷了一遍。每一次看完都觉得自己被触动了，因为里面有很多地方能看到我自己的影子，能找到情感上的共鸣。

比如我和韩立前半程是一样的：相貌平平、资质平平、资源也平平。说白了，真的，我们都是凡人之躯。我敢说在座绝大部分同学也都是凡人之躯。

但同时，我们又都有一颗不甘平庸的心，都不太愿意保持现状的生活，所以我们都在进行各种各样的努力。考法硕研究生，这就是努力的一种方式。

所有来听课的同学，最直接的愿望那就是考上。那考上以后有什么好处？在一定程度上可以实现阶层的跨越。当然你要说跨越多大，那不一定，但至少会让你的人生上一两个台阶。这个社会大家是知道的，虽然不是弱肉强食的社会，但确实是强者通吃、赢者通吃。所以我猜，我们之所以这么努力，可能还是希望自己的人生高度能更有所提升。

### 韩立身上最该借的两样东西

这部剧里有几点让我印象很深，对备考法硕也很有启发。

#### 目标明确：走出家门那一刻就定了

第一个，他目标非常明确。从走出家门那一刻起，他就想：我就是要修仙，别的东西什么东西都干扰不了我。所以他不是三天打鱼两天晒网。

我们也一样。既然明确了考研究生的目标，就心无旁骛地走下去。目标一钉死，别的都可以排到后面去。

#### 意志坚定：把路上的弯道全砍掉

第二个，他意志也非常坚定，不受很多外界的诱惑——包括情感上的诱惑，还有其他门派的诱惑，"哎呀，你又多了一个法宝"。

我突然就想到，这跟我们备考的同学是一样的。我们现在可能受到的诱惑挺多的。比方说很多自媒体上，你突然看到"我这里有一个什么绝招，能记住这个东西"，你就打开去看一看、看一看着再背一背，可能对你是有帮助的。但是你整个流程是这样的：刷到以后，阅读完，阅读完之后把你原来的知识体系颠覆，颠覆完之后再把这个进行重新背诵。你想想这里边兜兜转转耗掉了多少时间？

它就像我们开车走路一样。人家走直线，你老是时不时拐个弯、拐个弯、拐个弯，走的是曲线、是螺旋式的路，那你的整个进度肯定会降低。

我自己备考的时候，目标有多明确呢？我用了六个月的时间，考上了人大的法理学硕士。但是我的本科说实话是比较一般的，我们那一届属于"第一级本科"——在这之前都没有本科，所以可以说基础为零。从 7 月份开始学，那时候考试还在 1 月份。

成功当然有偶然因素，但我想其中"目标明确"这一条，我没有丝毫动摇过——有啊，当然有。比方说找工作，同学们都去人才市场了，我的心里也痒痒的。再比方说打篮球，我大学的时候是我们院篮球队的主力中锋，看我这个体格也知道是主力中锋，每年一度的院系篮球赛想不想参加？想。但是摁住自己。还有玩音乐，我大学的时候是校摇滚乐队的主音吉他手，当时我也是长发飘飘的，看到他们排练的时候，想不想？想。但是把自己摁住。

这就是在目标明确的前提下，意志要坚定：放弃所有能影响你考试、影响你备考的这些爱好，包括外界的这些影响因素。我记得我在备考的时候，我妈说来看我，我都不让她来，我说不用；挂下电话就没事了，好好学就行了。

所以同学们，你既然走上这条路，希望你能记住一句话：这条路主要是要由你一个人走下去的。老师只是给你一点推力，其他的是别人谁也帮不了你。

很多同学会说，"哎呀，不要太累了""不要这么卷""顺其自然吧"。你注意，说这些话的人一般都是高阶层的人——高阶层的人对咱们低阶层的人说。而我自己是从低阶层慢慢往上走的，反正我现在也不算多高的阶层，我是有这样的经历的。所以我希望同学们在该努力学习的年纪就好好学习；至于以后那种所谓好的生活、骄奢淫逸的生活，是等着你的。该干什么事的年纪，就要干什么事。

我们资质平平，我们不怕。我可以输在起跑线，但我一定要赢在转折点。转折点就是我们现在报考了法律硕士考试，进入到法硕的学习当中。

### 听课这件事：跟一个，或者以我为主再配一个

这一节先回应一个很实际的问题。有人会说："杜老师，你也有局限性啊，那我要不要再听一个别的老师的法理学的课？"

对于这个我并不否认。任何人都有局限性。比方说押题，每年也有个别我押不到的题，是不是？

所以你完全可以从头到尾只跟我一个课，那是够的。第二种方式呢，以我为主，再辅助另外一个——但是只能再找一个了，不能再找多了。找多了，你们这个内心会受到冲击。什么冲击？体系上的不同，甚至逻辑上的不同，甚至重点考点强调的点都不同。同一门课你听三个版本，越听越乱。

> **提示**：要么就从头到尾跟我一个课；要么以我为主，再辅助一个，但只能再加一个。关键是"跟得完整"——你既然选择了跟着我的课，就尽量能够完整地跟下来。

### 课程怎么走：五个阶段

下面把这个教材和课程做一个介绍，其实它也就是备考的基本规划。

#### 导学课：先见森林

第一个是导学课，用了大概六个小时的时间，给大家设一个法理学的大框架。

我建议非法学的学生，导学课还是要听一遍。法学的学生——其实法学的学生大部分也是零基础，大学里法理学学不了什么东西——那么如果你是法学零基础，导学课也要听一遍。听一遍能让你熟悉整个课程体系，以及我的授课风格。

当然，不同老师有不同的授课风格，那并不一定说每一个同学都能够满意，你要尽量适应这种授课风格。老师我也会听从学生们的建议，也会主动地做一些提升，这是要教学相长。

#### 精讲、刷题、背诵、写作：上山就是上坡路

第二个是精讲阶段，也就是我们现在这个阶段——这就相当于修仙当中的筑基阶段。我们会掰开了、揉碎了，把这些重点考点讲给你听。所以这一个阶段就是在大框架下的细化和深化。

第三个就得刷题了。讲得再好、听得再懂，不练也不行，因为最后都要形成题目才可以。所以要重视刷题。

第四个是背诵阶段。包括逻辑概念拆解、联想记忆、导图记忆等等，甚至还有口诀记忆——多种记忆方法。有的考点适合逻辑拆解，有的适合口诀背诵，有的适合联想记忆，哪个合适咱们就用哪个，争取让大家把这些重点考点都能背过。

第五个是写作。写作主要是应对主观题的。导学阶段我已经给大家说过，主观题占的分值在各个科目里面都是最高的，70% 以上。所以你最后能不能写出来、写出来的东西能不能感动阅卷人——而不是感动你自己——那这也是重中之重。加入众合的授课团队以后，市面上流传的"法律大轮盘"，我把它纳入到了写作体系当中。

很多同学在学习的过程中会觉得："第一阶段学的还可以，刷题也还可以，怎么到了背诵阶段还是这么累？到了写作阶段怎么越来越累了？"

注意，同学们，因为在我看来学习是走上坡路的，肯定是要累的。到什么时候你不累？到 12 月份。因为我的课程阶段性区分非常明显：现在讲的精讲阶段，侧重打基础、深化对每一个关键词的理解；到了背诵阶段，除了那些拆解性背诵以外，我还会加入一些前后串联的体系；到了写作阶段，我甚至还会补充一些社会热点、马工程的东西。

### 马工程：补可以，替代不行

这里我要专门插一句。

现在国家也都在全面地重视马工程教材，所以我们这本书里已经参考了马工程的一些内容。而且确实出现了从马工程当中命题的这样的趋势。

那么有的同学问：我是不是放弃考试分析，直接转马工程，行不行？

> **结论**：不行。这是我要明确地告诉你的。原因就在于：虽然我们现在的考试题目有个别题目出自马工程，但还是有大量题目在考试分析当中能找到，考试分析其实占的比重更大。

那同学问：我是不是也要看看马工程？我的建议是不要专门去看。你要看了，马工程会一定程度上影响你对于法理的热情。

这是关于我讲课之前，简单做的学习方法上的介绍，以及学习阶段性安排的介绍。总而言之，我们是凡人，但是都有一颗不甘平庸的心，所以也希望大家最终能够约见光明。这个书、这个课，也是敬献给每一位不甘平凡的韩立。

### 法理学讲的是一件事：法治的底层逻辑

好，现在我们正式开始法理学的课程。

你先不要看目录。我们大纲对于目录的编排，相对来说逻辑不是那么通畅。所以我们打开教材的第一页——导论部分，我给了一个法理学的学科体系。导学阶段我给过大家一个更大的、更宏观的体系；在这里我给的是一个相对比较微观的体系。

法理学说到底干了就是一件事。所以当别人问你"法理学是干啥的啊"，你不要去背法理学的定义，你应该是从更高层次去告诉他：法理学给我们讲的就是法治的底层逻辑。

那么法治的底层逻辑是什么？看这张图。

这张图就是主干，读法是从上往下顺着箭头走：法律是个好东西，所以要把它定出来（立法）；定出来没人用就只是个死法条，所以关键还得用起来（执法、司法、守法、监督）；用起来以后，正常状态下人与人之间建立法律关系，比方说买卖合同、运输合同；不正常状态下、建立法律关系出现阻碍，那就追究法律责任。这样法律的产生和运行形成一个完整闭环，而闭环跑一圈，对整个社会有好处，有利于社会发展。

### 法律为什么是好东西

那么法律好，好在哪里？分三层来看：内在的好、外在的好、功能的强，再加上能满足需求的价值。

#### 本性之好：法的本质

第一层，本性是好的。这就对应法的本质这一章。

可"本性好"，好在哪呢？本性也有好多种嘛：乐于助人也是本性，生活习惯也是本性。那法律的本性到底好在哪？这就产生了不同的学派。

自然法学派特别像中国的道家，主张天道，认为法律好在于它有内在的道德品质。

有的学派不谈内在的道德品质，认为法律好在于它有权威的地位——地位高、层次高。还有的学派认为这既不是权威地位的问题、也不是道德的问题，而是老百姓认它——这就是社会现实。

到了马克思这儿，法律好就好在它受到物质的根本决定——有钱。

初次听课的同学可能这些派别都没听说过，这个不用着急，我们后面都会讲。在这里先上来讲学科体系，就是希望大家既见树木又见森林。你要不然学完这么厚厚的一本书，学完以后整个的感觉就是一团浆糊，不知道它的体系是什么。

#### 外在之好：法的特征

第二层是外在的好。外在好好在哪？长得漂亮。这就叫法的特征这一章。

漂亮体现在哪？你看下面这张表：

| 观察角度 | 法律"漂亮"在哪 | 记住的关键词 |
| --- | --- | --- |
| 产生主体 | 来自国家 | 国家性 |
| 调整对象 | 调整的是人们的行为，而不是人们的思想 | 行为，而不是思想 |
| 内容 | 权利与义务得配套 | 一致性 |
| 程序 | 有国家强制力，还有程序性 | 强制性（就是权限的意思）、程序性 |

怎么记？我们在后面具体讲考点分布的时候再说。

#### 功能之强：法的作用

第三层，它的功能还很高级。这就叫法的作用这一章。

第一，它可以对我们的个人行为带来各种调整作用，也就是规范。比方说刑法规定了故意杀人是死刑，那我就不敢杀人了呗——这不就是对我们的行为带来了规范吗？

而我们一个一个人加起来，又组成了整个社会。所以法律影响了人，它必然会影响整个社会。这就有了规范作用的两层：对人行为的作用，和对整个社会的作用。这就是法律有它特殊的功能。

#### 满足需求：法的价值

另外，法律还能满足我们各种各样的要求。下面就是法的价值。

我们的要求有很多，不同的人可能有不同的要求，可能有成千上百个要求。但是大纲认为，能代表大多数人一般性要求的、这样一些大的要求，就是法律要提供的：

| 价值 | 说的是什么 |
| --- | --- |
| 秩序 | 我们都要求一个稳定的生活环境，我们都不希望这个国家处于战乱之中 |
| 安全 | 走在大街上不至于老被人骚扰；到食堂吃饭，我拿着钱包在桌子上占座，也不用担心会被人偷走。人身是安全的，财产也是安全的 |
| 自由 | 希望在合法的前提下，我想说什么就说什么、想干什么就干什么，而不至于说我在不违法的情况下还说了某句话就被抓了 |
| 平等 | 大家都希望不要你看不起我、我看不起你，因为大家都是平等的 |
| 人格权的保障 | 希望我们每一个人能像人一样正常地生活，生命权、健康权等人格权都能受到保护 |
| 利益的正当分配 | 我干得多，你就应该给我多分配一些——这就是按劳分配，对社会利益进行正当分配 |
| 正义 | 社会能保护我们这些特殊的凡人们，尤其是弱势群体；整体上虽然是弱肉强食，但希望对弱者有更多关怀 |
| 效率 | 希望找政府办点事儿、找公安立个案、到法院立个案，不要老是拖拖拉拉 |

法律同时满足这些要求——所以这就是法律是个好东西。内在好、外在好、功能强大、还能满足需求。

### 有了好东西，就得定出来：立法

既然这么好，那因此就得把它定出来。定出来是什么？是立法机关得搞立法，而不是咱们的私人行为。所以就有了立法原则。

#### 立法得守住几条底线

比方说，第二，立法的时候是不是得问问老百姓的意见呀？不能某一个人说了算吧？某一个人说了算，那不就成了专制了吗、成了君主国家了吗？

第三，立法的时候说你要科学一点。你不能说，"你这企业都在污染环境，因此你搬到月球上去吧"。你要立法者这么立法，那这就是科学，对不对？

这些合起来就是一句话：要对立法构成限制。

#### 法条的三种写法

立法产生出来的东西叫法条。法条有的写得特别具体，比方说"故意杀人处死刑"，多具体啊。那这种我们给它起个名字，叫规则型法条。

除了规则型法条，还得有比较抽象的大法条，那就是原则。比如刑法中的罪刑法定原则、罪刑相适应原则。罪刑相适应原则会告诉你定罪和责任应该保持一致，但它不会告诉你具体什么罪名、具体什么责任，它就笼统地说你的罪行和责任要保持一致。那这就是比较宽泛的，我们给它起个名字叫原则性法条。

再往下还有概念性法条。比方说刑法规定"为了犯罪准备条件，制造工具的是犯罪预备"——这一句话、一个法条就是一个名词解释。那这种就叫概念性法条。

| 法条类型 | 抽象程度 | 例子 |
| --- | --- | --- |
| 规则型法条 | 特别具体 | 故意杀人处死刑 |
| 原则性法条 | 比较宽泛 | 罪刑法定原则、罪刑相适应原则——只说罪行和责任要保持一致，不说具体罪名和责任 |
| 概念性法条 | 名词解释式 | 为了犯罪准备条件，制造工具的是犯罪预备 |

你看，立法者立法的产物是法条，法条又有三种分类：特别具体的规则性法条、不太具体的原则性法条，还有名词解释类的概念性法条。

#### 纵向看高低，横向看部门

这是立法的内容。立法的另外两个角度，是外在的产物：一个是纵向的，一个是横向的。

纵向是什么？就是不同立法机关在立法。立法机关有大有小，大机关立的那就效力层级更高，小机关立的那就是效力更小。所以就产生了所谓的法的正式渊源——排第一的叫宪法，排第二的叫法律，排第三的叫行政法规，等等。

除了纵向研究"谁大谁小"，还有横向的研究：你归哪个部门。比方说咱们民商的，学过民法了，也学过刑法了，对不对？那这就是两个部门——民法部门、刑法部门、行政法部门。

> **提示**：想象一下同学们在学校里观察你们的老师、学校的工作人员，是不是也是从这两个角度观察的？纵向是校长副校长、院长副院长、班主任，这是有高低的；横向是法学院、文学院、工学院、理学院，还有什么教务处、财务处、招生就业处——这叫部门，**没有高低**，就是管的事不同。你们管着学法律的，那就是法学院；你管着学文学的，那文学院；你管着报账的，那就是财务处。

一个法条的具体分类，一个法律文件的高低，一个法律文件归哪一摊、哪一个部门——这就是立法环节。立法机关在立法原则的前提下，立出来这些产物。

### 定出来还得用起来：执法、司法、守法、监督

立出来以后，关键还得用。没人用，你立出来这个法条不就是个死法条吗？

所以用起来，我们有一个名词叫"实施"。其中政府用有个词叫执法，法院用有个词叫司法，我们老百姓用——俗称屌丝们用——那就叫守法。你们用得怎么样？有人盯着就叫监督。

这就是这四个的实施环节。再加上前面的立法，我们一般俗称"立执司守监"，立、执、司、守、监这五个都是法治的环节。说"立执司守"也行，说"立执司守监"也行。我们亲爱的马峰老师把它概括成"法治五连鞭"，他特别喜欢甩五连鞭。

这里多插一句。马峰老师在法理学的这个授课上也是非常好的。虽然现在法硕的法理学的课从今年开始由我主讲，他不讲——主要是因为现在股市不大好，他可能还有精力得炒炒股，不能让他损失太多；另外法考等等授课占的精力也太大了，太累了，也是为他身体考虑，所以让我来讲法理学的课。

那他这些年积累的特别好的一些东西，我也征得他的同意，有些我也会使用过来，比方说"法治五连鞭"这种。你也可以用"立执司守"四个环节，也可以用五个环节，都可以。这样有一个好的效果：马峰老师虽然离开了法理学的课堂、离开了我们，但是他的音容笑貌仍然会时不时地出现在我们的眼前、我们的耳边。

好，回到用起来。政府用叫执法，执法那就得有一堆执法的原则——这些原则你现在不用看。下面司法，就是法院、检察院用，那也得有一堆原则。

> **易错点**：守法谈不上原则。因为守法是老百姓们的事儿。所以你回去回忆相关考点的时候，不要说"守法也有原则"然后去找一个"守法原则"——你找不着，因为它没有原则。你看，立法有立法原则，执法有执法原则，司法有司法原则，唯独守法没有，主要是他们老百姓的事。

后边还有监督。包括国家机关监督——比方说检察院发现法院的案子判得不对，抗诉，这是国家机关的监督；还有老百姓的监督——比方说我认为法院这个判决不对，我把这个判决贴到网上，来发动社会力量来监督你。

其实"立执司守"或"立执司守监"，是法治的最核心环节。

### 闭环走完：法律关系、法律责任与社会发展

好，到后边。如果正常状态下法律关系就建立起来了；不正常状态下，还得需要追究有关责任。这样基本上法律的产生和运行就完了——形成一个完整闭环。而这个闭环跑一圈，会有利于社会发展。

法理学上提到"社会"这两个字，一般都是包括经济、政治、文化，还有生态。所以这个社会，基本上相当于宪法上讲的五大文明。

| 法理学说的"社会" | 对应宪法上的文明 |
| --- | --- |
| 经济 | 物质文明 |
| 文化 | 精神文明 |
| 政治 | 政治文明 |
| 生态 | 生态文明（大纲没有列，所以这里就没有写） |
| 社会治理 | 社会治理 |

所以教材又专门辟出一大章，去讲法律对这几大文明的能动的反作用。

在经济上，他先讲整体上是什么关系，再具体讲了两大经济现象：一个是市场经济，一个是科技。有的同学说科技怎么能叫经济呢？因为科技是生产力呀，生产力当然属于经济领域了，它直接有利于经济发展。

再往下政治，也是先讲法与政治的宏观关系，再具体讲政治现象：一个就是政党——在中国你提到政治，那也是一政党、二国家；所以又讲了法与政党、法与国家的关系。再往下文化，这也是先讲一般关系，然后找了两个具体的文化现象：道德和宗教、意识等等。

你这么回忆的时候，就会发现它整个体系特别统一：先是一般关系，然后再讲两个具体的事儿。法语经济是这样，你再看法与政治是不是也是这样，再往看法与文化是不是也是这样。所以我们去回忆的时候，整个框架是统一的，回忆起来内在规律可循，相对来说就不至于那么困难。

再往下社会治理，这块主要讲了一个意义、一个措施。好，这就是整个法治的一般流程。

### 但法律也没那么好：固有局限与价值冲突

当然，我们还说后边法律也有各种各样的毛病。

第一个，作用上、功能上有局限性。前面我们说法律有好多功能、很强大，但这边又说它的功能其实也没有想象的那么强大。

> **提示**："这个局限性不是贬义词的意思。" 它指的是法律本来自带的、客观就存在的东西，不是个贬义，不是有毛病的病。有时候我们讲课会说"它没有那么好啊"，你不要因此就理解成"原来法律也不是什么好东西"。

比方说杜洪波有没有局限性？有。这个局限性包括：一，我怀不了孕——我男性怀不了孕，这算贬义吗？不算。二，我岁数大了——这算毛病吗？不算。三，我的局限性是长太胖了，不太健康——这个算有点毛病了，是不是？

所以"法律没有那么好"，它既包括那些本来客观存在的局限性，也包括那些确实有点毛病的东西。我们说土话的时候可以这么说，但当我们真正精确地表达的时候要知道：没有那么好，它既包括本来客观的局限性。比方说男性怀不了孕，那是客观局限性；女性在同等条件下，整个力量就不如男性——这能叫毛病吗？这可不能。

那么法律具体在哪些地方有局限性？

**第一，调整范围上有局限性。** 法律不是什么事都能管的。说实话，这句话我感觉像个废话似的。为什么呢？有哪个规范是什么事都能管的吗？道德也有很多事管不了，党的政策也有很多事管不了。哪有一个规矩放到这儿，全世界就都听了？没有。所以这种局限性都是客观存在的。

**第二，与社会现实生活有矛盾。** 比方说现实生活发展很快，那法律就有可能产生滞后性，跟不上、跑得慢。因此又派生出来了一些章节内容：要对法律进行解释。比方说你们学刑法学"开设赌场罪"，现在已经扩大到网络赌场了——这就是通过法律解释来缓解法律与社会现实之间的矛盾。再往后还有法律推理等等。这些具体内容我们讲到具体课的时候再说。

**第三，人本身也有局限性。** 立法者也是人，执法者也是人，司法者也是人，守法者也是人，那么他必然受到人的影响。比方说立法者有时候在立法的时候，有没有可能脑子犯糊涂呢？当然有可能了。有没有可能有些事想不明白呢？那太有可能了。比方说，立法者对于这种大数据、AI 到底怎么进行立法规范，他现在都想不明白。为什么？因为这些技术发展太快了。立法者本来又不懂技术，他不懂数据、不懂计算机、不懂代码，你让他去对它做规定，他还得学；好不容易学到这儿了，人家技术已经到这儿了，是不是？

**第四，还要受到外在的政治、经济、文化条件的制约。** 比方说经济条件：如果经济发展状况好，马路上、公路上都安了密密麻麻的摄像头，那你说交通违章的人一定会减少。如果经济条件不好，连个摄像头都安不起，那在这个路上超速的、违停的一定多。说实话，有的时候我自己开车，如果有急事，遇到没有摄像头的时候，有时候我也超个速什么的；但一看到摄像头，我也是老老实实的，是不是？

**第五，法律的各种价值之间会有冲突。** 你说法律有好多价值，是不是？有秩序、有安全、有自由、有平等，但它们之间会有冲突，会打架呀。那我要的是秩序，你要自由，我要你的正义，对不对？那就有可能产生冲突。比如我的表达自由可能侵犯你的隐私。

> **提示**：这种冲突是客观存在的。因为我们学物理学就知道，只要同一个空间内存在两个以上的原子，它就必然会产生碰撞——社会科学也是如此。

### 既见树木，又见森林

这就是法理学的法治基本逻辑，也是法理学的整个体系，基本上也相当于章节分布的情况。

下去以后，你其实不用用章节来来回回顾它的考点，你就用这张图来回顾。

我相信，把这个课跟下来，既见树木又见森林——对法理学既有微观的掌握，又有宏观的掌握，为你刷题、为后期更高层次的背诵，打下坚实的基础。

## 法学是什么，以及这门课该怎么听
> 对应块：BLK02 | 覆盖分集：P03 | 块标题（分集名）：《第01章 第01节：法学（01）》

### 先解释一件事：这本教材为什么这么厚

拿到书一看——我天呐，对吧，快 250 页了，这就是个二百五。官方教材人家才一百来页，你家伙干到 250 页，你想干什么呀？

这个我要做个说明。之所以把它写厚，主要就是为了让大家理解透彻，并且提高教材的可读性。所以我加了特别多的推导逻辑、底层逻辑的板块；底层逻辑之外，又加了大量的例子、案例、事例，就是为了方便大家下去复习的时候看到这些东西，能理解得更透彻一些。

因为我就说过，法理学最典型的特征就是不说人话。光看那些纯硬货干货，你受不了。

> **结论**：厚度不是在增加大家的备考压力，而是在减轻大家的备考压力。

### 关键词与复盘：听懂不等于拿分

第二块，我在授课过程当中会在重要考点里圈出它的关键词。做笔记的时候要注意，把关键词都圈出来。圈出来以后，我会对关键词进行解释：一个是从理解角度，一个是从命题角度。这个解释，如果命题他只命到第三层，我只把它解释到第四层，他可能还有第五层、第六层——我们不搞那么多，就比考试稍微难一点点就可以了。

有同学问：为什么非要难一点点呢？你就不能比考试简单一点，或者相当于考试的难度吗？

不能。因为听我们这个法理学课程的学生，法理学满分平均就是 60 分，有的年份多、有的年份少。我希望大家在这一科上能够拿到 50 到 55，所以我给大家提的要求是比较高的。当然这种高要求不会使课程变得特别难，稍微难一点点就好了。到了背诵阶段、主观题阶段，我可能再进行一点提升。

第三件事，一定要注意每一章讲完以后，前面的那个**知识索引**。它不是在讲之前讲的，是把每一章讲完以后，我们再返回来，用知识索引给大家复盘。

请注意"复盘"两个字——复盘比刷题在某种意义上还重要。

复盘怎么复？大家其实都不知道。正是基于这个考虑，我在每一章、每一节前面都画了复盘用的思维导图；每一节讲完以后，会用大概两到三分钟，带着大家把这一盘复一遍。有的节大就稍微长一点，有的节短就稍微短一点。

那你把这个盘复完了，晚上回去看什么呢？我给你一个顺序：

```text
听 完 一 天 的 课
        │
        ▼
把正文讲的重点考点过一遍
（重点、例子、形象理解，都要过）
        │
        ▼
跟着我的复盘再过一遍
—— 最好自己再独立复一遍
        │
        ▼
剩下时间再去刷题
```

读图：顺序不能颠倒。先把正文吃透，再做复盘（且要自己动手复），最后才轮到刷题。

这个工作你要是能做完，我保证你第一轮真题正确率就能达到 80% 以上，学得好的同学甚至能干到 90% 以上。而不懂得复盘的同学、不懂得课后复习的同学，第一轮真题正确率也就 50% 到 60%。我第一轮就要把你干到 80% 以上。

我虽然输在起跑线——我不是 985，我也不是 211，我就一个普通学生——但是我要实现弯道超车，那 OK，我要赢在转折点。你们上 985、上 211 的学生，你也不一定最后考分考得高。我就是要把该得的分全都得到。

> **结论**：底层逻辑、推导逻辑和例子，让你实现"理解化"；关键词拆解，让你实现"重点化"；复盘则是体系化掌握。这三化做到位，分数就来了。

### 关键词掌握，从来不是全文背诵

讲到关键词，这里要说一个小问题，就是大家学习当中的误区。

记住，我要求的是**关键词掌握**，我从来没要求全文掌握。"全文掌握"这本身就是一个错误的说法。

所以很多人在介绍经验的时候说"必须全文背诵"，从来不需要。你就背这些考点里边的重点词。

那其他词不背怎么办？你只要能自己把它串成一句话就行了。

为什么？因为阅卷的时候，不是拿着这个考试分析或者教材逐字逐句地去阅。

我参加过法律硕士的两年阅卷——当然当时还是在人大读博士期间。我们阅卷的时候，看的就是关键词有了没有，句子马马虎虎说得也算通顺，只要别太口语就行了。比如你写"政府依法行政"，别写成"政府的当官的依照法律去干点事"，别这么写就行。书上写"政府依法行政"，你写成"行政机关依法行政"，没有任何差别。

> **提示**：阅卷的时候，"众议不中立"——意思是到了就可以了。说实话，参加阅卷的老师 99% 都不知道书上怎么写。我们知道，是因为我在讲法理学的课；那不讲，谁看这个呀？

所以前两年网上有个帖子说"必须全文背诵，老师阅卷就是逐字逐句地去阅"。我一看到很震惊，更让我震惊的是，下边竟然有个评论说："原来是这样，怪不得去年没考上。"

你要是有这么个评论、这么个智商，我估计党和人民不太放心把法制建设的任务交给你。你想想怎么可能这么去干。

那同学接着问：为什么他会发这种帖子呢？我估计他发这种帖子可能是为了卖书。当然这个也没有证据，也只能这样猜测。

所以我才说，在讲课过程当中，除了逻辑的梳理、案例的举例，还有复盘，其中**关键词拆解**这个是要跟上的。关键词就是命题点，关键词就是阅卷采分点。

### 知识索引：第一章要解决什么

下面正式进入第一章，法学和法理学。

先把这个位置摆清楚：第一章严格来讲，它不属于我们法治的这种环节，它是整个学科的一个介绍——法学是个什么东西，法理学是个什么东西，这就是第一章要干的事。它和我们后边讲法治基本逻辑，是"两张皮"：第一章是**学科角度**，从第二章开始一直到后边，整体才是**法治角度**。

先看知识索引。第一节"法学"就讲三块：

```text
法学（第一节）
   │
   ├── 法的概念        ── 法学是什么
   │
   ├── 法学体系        ── 法学怎么分类（从什么角度分成什么）
   │
   └── 法学历史        ── 中国法律史  +  西方法律史
```

读图：第一节的三块是并列的，第三块内部再按地域一分为二。

> **提示**：文科经常干的事儿就是"概念、特征、分类"，历史有的时候有、有的时候没有。有的地方再加上"意义"。大概知道这个套路，考场上你就知道一个知识点该从哪几个角度去答。

### 法学的概念及其性质

#### 法学的含义：研究法及其规律的人文社会科学

第一个标题叫法学的含义。其实这个标题应该叫"法学的含义及其分类"更准确，但因为大纲就是这么写的，没办法，我们和它保持相对一致。

那么，什么叫法学？法学又叫**法律科学**。那什么叫化学？化学就是研究化合物的科学呗；那法学就是法律的科学呗。

具体来看，法学是**以法及其规律为研究对象的人文社会科学**。简单来讲，就是研究法律的人文社会科学。

这里面的关键词就两个：**法及其规律**、**人文社会科学**。圈出来就好了。

#### 研究对象的层次性：由小到大，由浅入深

"研究法及其规律"这句话一展开，就出现了研究对象的分类，也叫**层次性**：

- 以法律规则为核心的制定、实施的方法和技术——规则层面；
- 研究法律原则和法律原理；
- 研究整个规律——比如世界法律发展的一般规律、英美法系法律发展的一般规律、中国法律发展的一般规律。

> **结论**：层次性什么意思？就是由浅入深、由小到大。研究对象越小就越浅，研究对象越大他就越深。

为什么？你要研究"中国法律发展的一般规律"，得需要看多大量的材料，才能总结出那么点规律。你要是只研究一个故意杀人罪的构成要件，需要那么多材料吗？少量材料就可以了，那就是最浅层次。你要研究罪刑法定原则，是不是还得研究背后支撑它的那么多具体规则？那就是中间层次。

```text
  研究对象 ── 越小 ──→ 层次 ── 越浅
      │
      ├── 制定、实施的方法与技术（立法技术、解释方法）
      ├── 法律原则、法律原理（罪刑法定原则）
      └── 各种法律发展的一般规律（世界 / 英美法系 / 中国）

  研究对象 ── 越大 ──→ 层次 ── 越深
```

读图：三条从具体技术到一般规律，箭头向下就是层次加深。

形象理解：给某个学科下定义，都是"某某学"——物理学就是研究物理现象的学科。只不过由于研究的层次不一样，才产生了层次性。研究越小越表面就越浅，研究东西越多那就越深。

举个例子感受一下：甲学者研究的是正当防卫构成要件——浅层次；乙学者研究的是民法中的公序良俗原则——中间层次；丙学者研究的是中国古代到现代刑法发展的一般规律——深层次。理解了吧。

#### 性质之一：社会科学：看得见的角度

法学的性质，不就是上面那一行"人文社会科学"嘛。所以法学的性质这个考点，解释的就是人文社会科学这两个词。先看社会科学。

社会科学怎么理解？就是研究的东西**看得见**。

比方说，我们能看见什么？刑法的法条能看见吗？当然能看见了。有同学说我看不见——那是因为你没给我拿过来。就是说研究客观存在的东西。

```text
                 社会科学 = 研究的东西「看得见」
                              = 客观角度
                              │
      ┌───────────────────────┼───────────────────────┐
      │                       │                       │
   历史角度                制度本身              法与社会
法律产生发展的规律      各种法律规范及其      法与其他社会现象的关系
（唐、宋、明、清各朝      关系，即内部联系、   （法律怎么促进经济发展，
  有什么刑法——客观存在）  调整机制，如正当      依法行政比重提高多少）
                          防卫的构成要件）
```

读图：三个角度归为一类，共同点都是"客观存在、看得见"。

中国从古代刑法到今天整个发展——唐朝有什么、宋朝有什么、明朝有什么、清朝有什么，哪朝代有什么也是能看得见的，那是客观存在的。各种法律规范及其关系，也就是研究制度，比如正当防卫的构成要件。法与其他社会现象的关系，比如法律怎么促进经济发展，有了法律以后 GDP 上升了多少；法律怎么促进政府发展，有了法律以后政府依法行政的比重提高了多少——这都能看得见。

所以第一是历史角度，第二是法律制度本身，第三是法与社会角度。这就叫看得见的角度，所以在"看得见"后面再加一个小括号：客观角度。这就叫社会科学角度。

#### 性质之二：人文科学：看不见的角度

人文科学研究什么？往下是这样一条推导：

法律是人们生活意义的规则体现 → 法律要解决人们面临的问题 → 因此，法学要为人们在规则下生活提供精神导向。

把"精神导向"拎出来，也就是**价值角度**——研究法律制度背后的精神和价值。

| 研究者与研究内容 | 归属 |
| --- | --- |
| 甲学者研究正当防卫的构成要件 | 社会科学（看得见） |
| 乙学者研究正当防卫的价值，或者正当防卫的精神 | 人文科学（看不见） |
| 丙学者研究故意杀人罪要保障的价值，或者法益 | 人文科学（看不见） |

读表：判别标准只有一条——落在看得见的构成要件、事实层面，是社会科学；落在意义、精神、价值层面，是人文科学。

> **结论**：社会科学就是看得见的角度；人文科学就是看不见的角度——意义、精神等等。记住这个识别方法就够了。

### 法学体系：本意其实就是学科分类

法学体系，指由各个法学分支学科构成的系统。

看这个标题——"学"不就是"学科"嘛。所以法学体系本意其实就是**法学分类**，就是学科分类。法学是个一级大学科，下边分了很多具体学科；既然是分类，那就有不同的分类标准。

| 分类标准 | 具体分类 | 复习定位 |
| --- | --- | --- |
| 一般的分类 | 立法学、执法学、司法学等 | 了解，属一般性考点 |
| 认识论角度 | 理论法学、应用法学 | 偶尔考考 |
| 法学与其他学科的角度 | 法教义学、交叉学科 | 偶尔考考 |
| 法律部门角度 | 搞民法的、搞刑法的等等 | 了解即可 |

读表：四种标准彼此独立，不是一套东西的四种叫法；后两种才是"偶尔考考"的重点。

#### 认识论这个角度到底在说什么

什么叫认识论角度？就是你认识的这个东西、你认识的这些结论，**能不能被直接被法院用**。能，就是应用；不能，就是理论。

所以这里可以画个小圈小箭头：应用就是直接用，尤其是被法院直接用；而理论法学认识的是法背后的原理，理论这个东西不能被直接被法院用。能直接用还是不能直接用，就分出了理论法学和应用法学。

形象理解：一般而言应用法学能够直接用，理论法学不能直接用。比方说法理学——你见法院判案拿着法理学来判案吗？不能吧。那刑法学呢？刑法学研究的就是刑法，刑法那个东西研究出来，法院能直接用，拿刑法判、拿民法判、拿行政法判、拿刑诉法判、拿民诉法判、拿经济法判——这些都叫应用法学。

这里有个特别容易划错的地方，必须单独拎出来：

> **易错点**：**经济法学**和**法经济学**不能划等号。经济法学是研究经济法法条的学科；法经济学是用经济学的观点研究法的学科，它是理论性的东西。法经济学、法社会学都是理论性的东西。

#### 法教义学与交叉学科

什么叫法教义学？就是研究法律本身。交叉学科就是用别的学科。

比如**法哲学**，是法和哲学；**法史学**，法和历史——对不对，这都叫借助了其他学科，所以属于交叉学科。

#### 做题的一般规律，以及它的例外

形象理解里给了一条非常好用的做题技巧：

```text
  某某法学  ──大概率──→  理论？不对，是【应用法学】
                 刑法学 / 民法学 / 行政法学
                 刑诉法学 / 民诉法学 / 经济法学 / 国际经济法学 …

  法某某学  ──大概率──→  【理论法学】
                 法经济学 / 法社会学 / 法哲学 / 法史学 …
```

读图：命名语序就是归属信号——"某某法学"（部门法在前）偏应用，"法某某学"（法在前）偏理论。

注意，这只是一条做题的一般技巧。国际经济法学研究的是国际上那些经济类的规定，属于应用法学；刑法学、刑诉法学也都是应用法学；但法经济学就属于理论法学。

那有没有例外？有。

> **易错点**：**法医学**是法学和医学的交叉学科，但它属于**应用法学**。这是例外。不过例外不多，基本上就这一个。

另外两个点，一并记下来。

> **提示**：不要把"理论法学 / 应用法学"和前面的"人文科学 / 社会科学"划等号。有人以为理论法学就属于人文科学、应用法学就属于社会科学——不一定。理论法学也有研究客观角度的，也有研究主观角度的；应用法学也有研究客观角度的，比方说正当防卫的构成要件；也有研究主观角度的，比方说正当防卫背后的价值。**这是两个不同角度，它们之间没有对应关系。**

> **结论**：立法技术、解释方法这类特别具体的技术和方法，是**最浅层次**的研究对象。这个好理解——你大学学的东西，和蓝翔技校教的东西就不一样，人家技校教的就是技术方法，那很具体。

#### 顺带说说交叉学科为什么难

咱们国内有学者从《易经》里研究正当防卫，有多狠。同学们，这一听就很难。那当然难了，交叉学科本来就难嘛。

所以如果你本科学经济学的、学哲学的、学历史学的，甚至学计算机的，都特别容易和法学交叉。而且写论文的时候，交叉学科的论文会比纯法学的论文要好些——因为它会给人眼前一亮的感觉，给那些本身就学法律的人眼前一亮。

到这里，"法学"这个标题的主要内容就讲完了：法学的定义、研究对象的分类（层次性），还有法学本身的分类（法学体系）。

### 本讲提到的题目

**题目**：关于刑法哲学，下列说法正确的是（　）。

- A. 刑法哲学研究的是刑法背后的哲学问题，属于理论法学
- B. 刑法哲学研究刑法和哲学，属于交叉学科
- C. 刑法哲学研究刑法的一些终极价值问题，侧重人文科学（价值类、精神类）
- D. 刑法哲学研究刑法背后的一般性规律，属于最深层次的研究对象

**答案**：ABCD，四项全对。

**解析**：

这道题综合性很强，把前面几个考点全串了一遍。破题的关键是：刑法哲学可不等于刑法学——刑法哲学研究的是刑法背后的哲学问题。

- **A 项正确**。刑法哲学研究的是哲学问题，研究出来的东西法院没法用，人家不可能拿刑法哲学去判案，所以属于理论法学。
- **B 项正确**。刑法和哲学是两种学科的结合，属于借助其他学科的交叉学科。
- **C 项正确**。哲学不就是研究终极价值的吗，所以它侧重人文科学、价值类、精神类，属于看不见的角度。
- **D 项正确**。刑法哲学研究的是刑法背后的那些哲学规律，是最深层次的研究对象；哲学层面的东西，层次总是比较深的。

## 法学的产生与发展：从“有法无法学”到近代三大流派
> 对应块：BLK03 | 覆盖分集：P04 | 块标题（分集名）：《第01章 第01节：法学（02）》

### 法学的产生：先有法律，才有法学

先说个我们都亲身经历过的例子：全国如果只有一个考研的学生，那根本用不着有考研机构，也用不着再出那么多考研书——书也卖不动，机构也挣不到钱。法学这门学科的诞生，用的是同一个道理。

教材第一句话就是：**法学是在法律发展到一定阶段后才产生的**。所以这里先得推出一个结论——先有法律，后有法学。

为什么法律多了才需要学科？你想，如果这个世界上只有一条法律，谁都看得懂，那根本用不着专门有人去研究它。法律越来越多，一般人看不懂了，才需要有一帮人把它研究下去。

恩格斯有过一段很贴切的话：随着立法发展成为越来越复杂，出现了社会分工的必要性，形成了法学者阶层，产生了法学。这句话你倒不用背。真正要记的是他背后点出来的**两个条件**：

- 先有法律现象——材料得积累到一定程度，才有研究对象；
- 还要有学者阶层——有了法律，还得有一帮人专门去研究它，学科才搭得起来。

> **易错点**：并不是有了法就有了法学。法学不是伴随着法律出现、或者伴随着国家出现而出现的，它必须复杂到一定程度、需要专门的人去研究，这一门学科才会产生。

### 中国古代：有法学，无法学流派

春秋战国时期，中国古代就有法学了——这本身就是考点。出现的是儒家、法家、道家、墨家等直接或间接探讨法律问题的学派。

所谓“直接或间接”，看他们各自在琢磨什么就明白了：儒家探讨的是法与道德、礼法结合；法家探讨的是严刑峻法；道家探讨的是道法自然。他们名义上都是搞哲学、搞政治的，实际上都直接摸过法律问题。

但这句话后面有坑。教材把“学派”两个字勾起来做了个标记：**“有法学”不等于“有法学派”**。因为儒家、法家、道家、墨家不是专门吃法律这碗饭的，他们吃的是政治那碗饭、哲学那碗饭，只是顺带着讨论了法律问题，因此不能叫法学派。

> **结论**：中国古代有法学，而没有法学流派。

后面两条也顺带记住：西汉时期儒家占统治地位，我们叫**礼法结合**——这一块后面还会再展开，这里不作考点要求；鸦片战争以后，西方思想传入法学领域，才慢慢地慢慢出现了一些**法学流派**。这一段的考点就这两句结论。

### 西方古代与中世纪的法学

#### 古希腊有法学，古罗马才有法学派

西方这边，**法学最早源于古希腊**。这是个命题点：古希腊出现了法学这个学科，但同样**没有出现法学流派**。所以你会发现，法学在诞生之初中国并没有落后——古希腊的处境跟春秋战国差不多，古希腊有法学，中国古代也有法学。

分水岭出现在古罗马：**古罗马时期，法学才成为独立学科，出现了法学派别**。这里要记时间——古罗马大体相当于公元前500年到公元后500年，公元前500年是共和国时期，公元后500年是帝国时期；法学成为独立学科、出现法学派别，是在共和国时期。

那为什么偏偏是古罗马冒出了法学派别？两个原因。

一是**民事交往非常发达**。买卖、借贷、运输、承揽、风险转移——这些是当时真实发生的经济关系，你不给它做出规定，它自己就要出乱子。

二是罗马的皇帝们还以懂得民法为荣，甚至编纂了大量专门的法学著作，比如查士丁尼法典。皇帝精通民法，民法典本身又被系统化整理了——法研究者从“读法条”变成了“有体系地讨论问题”，派别才出得来。

这一点使得西方在“法学派别”这个问题上领先于中国了。

#### 中世纪：法学成了神学的附庸

中世纪一般叫**基督教统治的世纪**，那时候**法学成为神学的分支**——法学院直接放到了神学院里，搞法学研究的都是教士、修女这些，普通人根本没有资格研究法学。

你把中世纪的欧洲和中国西汉中期以后放在一起看，会发现特别像：两边的法学都成了“婢女”，都被别的学科压在了下边。中国是被儒家压住，西方是被基督教神学压住。于是又一次回到了同一个起跑线上。

#### 十二至十六世纪：罗马法复活与注释法学派

然后第三件事，古罗马“又复活了”。12世纪到16世纪是**罗马法复兴时期**，出现了一个以**研究和恢复罗马法**为核心的法学流派——**注释法学派**。名字里的“注释”两个字要单独记住，注释就是解释。

12世纪，罗马法的一些规定、一些书突然重现江湖。老百姓一看，罗马法这些规定可比神学下的那些法、比教会立的法好多了。为什么？因为12世纪以后西方国家在对外扩张、对外掠夺，得开着船出去——要造船就得买东西，钱不够还得借钱，而别人不愿意借给你，于是就创造了有限责任公司这种东西。这些公司形态的规定，很多都是从古罗马法那儿抄过来的。所以12到16世纪罗马法为什么会复兴？**就是因为商品经济的发展**——你可以说那是掠夺经济，但不管怎么说，它也是一种商品经济。

罗马法在人们心目当中特别神圣，于是这帮人的任务就是：我们不要去改造罗马法，我们只要好好解释罗马法就行了。**所以起名叫注释法学派。**

> **结论**：考法就是“以研究和恢复罗马法为核心的”这个定语，加上“注释法学派”里的“注释”两个字。

```text
  中国  春秋战国        ......  有法学，无法学流派
  西方  古希腊          ......  有法学，无法学流派
  西方  古罗马          ......  法学成为独立学科，出现法学派别

  中国  西汉中期以后    ......  儒家占统治地位，礼法结合，法学成附庸
  西方  中世纪          ......  法学成为神学的分支，法学院并入神学院

  西方  12-16 世纪      ......  罗马法复兴，注释法学派居功至伟
```

读图要点：古代中西两边都有法学，但只有西方在古罗马甩开了中国；中世纪两边又一起把法学压在了别的学科下面；真正让西方的法学派别传统接续下来的，是罗马法的复兴。

### 近代西方三大流派：自然、分析、社会

近代就是西方资产阶级的文艺复兴和资产阶级革命时期。这个时期**出现了大量法学流派**，其中**影响最大的三大学派**是自然法学派、分析法学派和社会法学派。

这三家是重中之重，无论是客观题还是主观题，几乎每年都有相关题目——因为它们影响太大了。下面挨个来看。

#### 自然法学派：法律之上还有天道

**它是怎么来的。** 自然法学派历史悠久——“历史悠久”的意思是，它的观点在**古希腊时期就有萌芽**，你可以简单记成“萌芽于古希腊”。但古希腊那会儿还不能叫自然法学派，因为那时连学派都还没有。真正的**古典自然法学派**出现在**十七、十八世纪**；考试中说的“自然法学派”，一般指的就是古典自然法学派，因为它影响最大。而十七、十八世纪，恰恰就是资产阶级革命时期。

这一段要划重点，关键考点是它充分体现了**自然法、自然权利和社会契约等人本主义**。

**自然法是什么。** 简单讲，自然法就是自然界存在的那些规律，自然而然的规矩。中国其实有个更贴切的词叫**天道**。比如不能随便杀人，这就是天道；看到人家有钱了，你不能过去给他抢过来，不能抢劫；不能奸淫；看人家漂亮你不能上去猥亵人家——这都叫天道。你抬头只能看见天，看不见天道，但大家都觉得“这个不能随便杀人”好像是对的——这就叫自然法。由此推出关键一步：人是可以制定法律的，但**人定法必须符合自然法、符合天道**。所以自然法学派主张的自然法，其实就是指**法律之上有天道存在**。

**天赋人权与自由平等。** 自然法天然给了我们人权，所以又叫**天赋人权**——我们人权的标准从哪儿来的？老天爷给的。老天爷让我们像个人一样生活，而不是像禽兽一样生活。天赋人权其实就是**自然权利**的意思：自然而然就应该有生命、健康、人格。

它还**崇尚自由平等**。这两条人权不是随便挑的，是冲着封建社会来的：**自由用来反抗封建的专制**（你老整天专制我、老是剥夺我自由，不行），**平等对抗封建等级**（封建等级反平等，封建专制反自由）。所以结论就出来了：老天爷给了我自由和平等，而你封建社会的法在搞等级、反平等、搞专制，那我就有权代表老天爷去推翻现有的封建社会。

想象一下中国古代的农民革命，是不是也挺像这个？也是打着老天爷的旗号来推翻现有制度。**自然法学派实际上为资产阶级革命提供了一个良好的借口。**

**社会契约。** 契约就是合同的意思。社会契约指的就是：国家和政府是怎么产生的？是人民和他们签订的一份**委托合同**——委托国家和政府来管理我们。中国我们说国家公务员是公仆；西方这套说法的意思是，国家是我们人民委托你们来管好我们。既然是委托，你就应该按天道那样去管我们；你如果不按天道管我们，我就要推翻你——这就是**更换被委托人**。

**人本主义**又是怎么回事？就是把人像人一样去对待，不要把我们像动物一样对待，动不动就专制我、还不平等、还歧视我。你也是人，我也是人——王侯将相宁有种乎。

把这一整条逻辑串起来你就明白了：

```text
   法律之上有天道
   （自然法 / 应然法 / 道德 / 正义）
            |
            v
   自然权利 = 天赋人权
   （生命、健康、人格）
            |
            v
   崇尚自由平等
   （自由反专制，平等反等级）
            |
            v
   签订委托合同（社会契约）
   人民把国家、政府委托出去管理自己
            |
            v
   旧法违反天道：专制、等级、不让参加议会
            |
            v
   革命 = 替天行道
```

读图要点：教材上自然法、天赋人权、社会契约、人本主义这几句话看着是并列的，其实是一条推导链——正因为法律之上有天道、而旧法违反天道，所以革命才是“替天行道”。这里的社会契约是一份逻辑上推导出来的合同，并不是真的存在过这样一个合同，它类似于委托合同，委托政府去保护自由和平等——这就是**控权和保民**的理论依据。

**观点一：法应当是人的理性。** 人既是理性的动物，也是感性的动物。自然法学派认为法只能是人的理性，而人的理性跟自然法是一致的。但人是有感性的，所以立法者在立法时不可避免就会掺入感性因素。举个例子：我在开车，别人开车别了我一下——理性因素应该告诉我，不要去跟他找这个麻烦，而是按社会契约去请有关国家机关来处理，拍个照片告诉他违章了、恶意别车。但感情就有可能是：你敢别我，我非得别你呢。所以如果法条写上“对方开车别你，你有权别回来”，这个规定就不是理性的法，它既不符合天道，也不符合自然法。

**观点二：自然法普遍永恒，高于人定法。** 天道是普遍永恒的，天不变，道亦不变，天下人就变不了——在任何社会，故意杀人、故意盗窃、故意奸淫都是被禁止的。所以自然法普遍永恒、高于人定法；反过来讲，**人定法只有符合自然法才是真正的法律**，于是就推出了“**恶法非法**”。

**推导逻辑。** 自然法学派之所以得名为“自然”，主要是因为它主张**法律应当顺从自然规律**；因此推出**自然规律高于法律**。也就是说，人们制定的法律要符合自然法。考试中自然法有时候又叫应然法，有时候又叫天道，有时候又叫道德，又叫正义——反正都是一堆我们用肉眼看不见的东西。

**恶法非法怎么落地。** 举我们前面用过的那个例子：机动车闯红灯应受处罚。那么我如果为了救一个危重病人而闯红灯，应不应该处罚呢？按自然法学派的观点，救人是天道，我闯红灯在天道面前就不算什么，所以你就不应该处罚我。于是“闯红灯的都要受处罚”这条规定，在这个具体的事上就成了**恶法**，所以我有权不遵守。自然法学派由此主张**支持善良违法**。类比一下：这就类似于“只有好人才是人，坏人不是人”这种观点。

到这里理解上应该差不多了，接下来是强化背诵的部分。

> **采分点一**：自然法、自然权利、社会契约、人本主义。
> **采分点二**：人的理性；普遍永恒、高于人定法；恶法非法。

口诀化一下，别再抄教材：采分点一是**自然人等着约**——自然法、自然权利就是“自然天赋”，人权是“人”，自由平等是“等”，社会契约是“约”；采分点二是**理性恒久远，高于人定法**。你下去复盘的时候千万别把教材再抄一遍，用这种口诀化的简化背诵，既加强了背诵，又给你复盘省时间。

**代表人物。** 近代自然法学派的典型代表是**洛克、孟德斯鸠、卢梭**——这一块在这里其实并没有要背的，因为后面还有自然法学派的其他代表人物，好多呢。真正要留意的是现代的三位：**富勒**提出了法律的**道德性**，所以考试中自然法也会被替换成“道德”这个词；**罗尔斯**提出了**正义论**，考试中会替换成“正义”；**德沃金**提出了**平等论**（自由与平等），考试中会替换成“平等”。口诀是**富尔多金哈**——“德沃金这个人有钱又有金呗”，反正是走两遍就记住了。

#### 分析法学派：法条是什么就是什么

**19世纪是考点。** 为什么是19世纪？因为19世纪资产阶级革命已经结束了，资产阶级已经掌握国家政权了。他们不希望老百姓成天嚷嚷“国家法律制度不符合天道，我要推翻你”，不希望你天天闹革命——于是这帮掌握政权的人创造出了一个新学说，还把它推广出去了。自然法学派就慢慢被淡化了，产生了一个新学派叫**分析法学派**。

它的**基础是实证主义哲学**，关键词就是这个。**实证主义**指的是以客观存在为研究对象，简单说就是研究看得见、摸得着的东西，属于社会科学层面的研究。既然以实证主义哲学为基础，分析法学派就开始说：你不要搞那些看不见、摸不着的东西。

他们反对的对象很具体：

- 反对**形而上学**。什么叫形而上学？“形”是能有形、看得见的，往上不就是天道吗？天道就是看不见的东西，就是自然而然存在的规矩。他们只要形而下的东西，反对追求终极真理；
- 反对**超越现行法律制度**。现行法律制度就是人定法，是有形的、我们看得见的；
- 于是推出：**人定法之上没有天道**。国家写的法条是什么就是什么，它就算违反了天道，它也是法。

> **易错点**：这一点和自然法学派正好相反。自然法学派说违反天道的法不是法，分析法学派说违反天道的法也是法。

**具体观点**：试图将**价值排除在法理学之外**。关键点就是“价值排除在法理学”——法律制度就是人定法，就是实际存在的制度；法理学就是研究实在的法律制度。

说白了，分析法学派主要就是为了搞垮自然法学派，所以它发展出了自己的一套原理：你讲的那些天道都是终极真理、是形而上学、超越了人定法，少搞什么道德、正义、平等、自由这些价值。所以我们这些学法律的人啊，不要再异想天开地去看天道，你就看法条就好了。

还是用救人闯红灯那个例子：分析法学派认为**应该处罚**，因为法律规定应该处罚；至于说天道是什么，他不承认，所以不用看天道，按照法律规定来就好了——所以**恶法也是法**。

口诀化一下，他反对的就是那几个词：**反对形而上学，没价值**。结论就是老老实实遵守国家的法条，不要老是拿着道德、正义去否定现行法律制度。这种观点当然受掌握政权的人喜爱——你不用老是去批判他了。

**代表人物。** 早期两位：**边沁**说法律就是国家给你发的命令，**奥斯丁**也是这么说的。20世纪的新代表：**开尔森**说法律就是一堆规矩，**哈特**说法律就是一种规则。不管怎么说，他们观点的共同点都在于——**法律是看得见、摸得着的制度**。口诀是**亲亲丁二哈**（边沁、奥斯丁、开尔森、哈特），“丁二哈”还就是一种狗的品种呢，背起来顺嘴。

**法律格言**（属于了解内容，不是背诵内容）：法律与道德之间没有必然关系；法律就是一个一个的体系，我们用逻辑就能得出正确判决，不要考虑天道。格言、举例、逻辑这些材料都是为了让你理解得更全面更深刻，我们的背诵内容还是正文的东西。

#### 社会法学派：老百姓用的才算数

**同样是19世纪。** 别的——什么欧洲、什么乱七八糟的——不用管。看它的名字就知道了：社会法学派肯定是从**社会现实**出发的。

**观点。** 强调**现实的法**，关键点就在这儿；研究**法的现实**，也就是法律的现实各个方面；**反对**分析法学派仅仅进行**形式逻辑**研究——法条研究不就是形式逻辑吗？形式逻辑主要就是写一个语法、研究字词语法。那社会法学派就问了：你研究那个字、那个词、那个语法有什么用啊？老百姓都不用的东西，它都不是法，研究它干什么？所以他侧重宣扬**法的社会性**。

这里出现的四个关键词是**现实的法、法的现实、逻辑、法的社会性**。但这四个词归根到底就是一件事——**法的实效**。就看疗效、看效果，有实际效果的才是法；没有实际效果的，那就不是法，不管你是不是国家定的。

> **提示**：“现实的法”和“法的现实”含义一样，一个说的是哪些东西算数，一个说的是从哪个角度切入研究。

**现实中的法就是正在被用的法。** 国家可能定了100条，其中50条老百姓在用，那这50条就是法；剩下那50条老百姓不用，那就不是法。这就叫“现实的法”。

**什么叫法的社会性？** 就是**社会实效**，对社会有用就是法。举个例子：吃婚宴掏红包，这是我们老百姓的一种社会习惯。这是法吗？按照我们现在国家认可的这一套，它不是法；但在社会法学派占统治地位的国家，他就认为这些就是法。

再看一个具体例子：吃了婚宴不掏红包，构不构成不当得利？按照民法典的规定，不构成——因为这不属于我们调整的范围，我们不管这事。但按照社会法学派的观点，则构成——因为去人家婚宴掏红包，是现实中老百姓都在用的规矩；既然是大家都在用的规矩，它就是法，法官就应该用这个来判断。

**代表人物。** **艾利希**（又叫埃尔利希，这两种写法都无所谓）、**霍姆斯**、**庞德**，还有一个**狄季**——这个要记住，选择题会出现。

**狄季**认为法律就是**社会连带关系**。这里要解释一下，连带关系不是民法上的连带责任，它翻译成“连带”，其实应该叫**社会合作关系**。狄季认为法律就应该促进社会合作，有利于社会合作的就是法。这个观点影响也挺大的，而且对民法上的贡献还挺大。举个例子：相邻权是一种权利，也属于物权，但为什么相邻权人还有相互容忍的义务？因为相互容忍的义务就来自于“法律要促进社会合作”——你稍微对邻居不满就骂人家一顿，那你就违反了社会合作，你干的那个事就不能叫法。有利于社会合作的就是法。

**法律格言**（理解即可）：**霍姆斯**说“法律的生命不是逻辑，而是经验”——“经验”勾出来不就是社会习惯吗；**庞德**说“法律是社会控制手段”，意思还是对社会有用就是法；**艾利希**说法律发展的重心不是立法、不是法理、不是司法，而是**社会本身**，强调的还是现实的重要性。

口诀化：社会法学派就用“社会”打头——重视**社会**的法、重视**社会现实**，重视**社会实效**，反逻辑。合起来就是：**社会现实，反逻辑**。

### 三派放在一起看：一个上天，一个入地，一个做中介

为了让大家对这三大学派理解得更透彻，我们重新梳理一遍：

| 学派 | 它主张的“法”是什么 | 站的角度 | 一句话立场 | 口诀 |
| --- | --- | --- | --- | --- |
| 自然法学派 | 天道（自然法、应然法、道德、正义） | 上天 | 人定法之上还有天道，违反天道就不是法 | 自然人等着约；理性恒久远，高于人定法 |
| 分析法学派 | 人定法（国家法、实在法） | 国家 | 法条是什么就是什么，恶法也是法 | 反对形而上学，没价值；亲亲丁二哈 |
| 社会法学派 | 社会现实（社会实效、社会习惯） | 老百姓 | 老百姓在用的才算数 | 社会现实，反逻辑 |

你会发现，这三大学派的**着眼点高度完全不一样**：自然法学派的眼光最高，看的是天道；社会法学派最低，研究的是社会中的老百姓——老百姓用什么、认什么，什么就是法；分析法学派在中间，因为它盯的是国家。所以自然法学派上天了，社会法学派入地了，分析法学派保持着中介。

这三种立场听起来抽象，其实切入点一点都不高深。我们说法理学高深，高深就高深在那些语言上，其实背后的原理没有那么高深——**这三个学派界定法律的标准，和我们找老公或者找老婆的标准没有什么差别**。

```text
   三个女生凑在一块讨论"要找什么样的老公"
   ----------------------------------------------------------------
     女生 A   我要找一个道德水平高的      自然法学派（上天）
     女生 B   有国家给他撑腰              分析法学派（国家）
     女生 C   要找个生活习惯好的，
              对家里边有实际帮助          社会法学派（入地）
```

读图要点：三个标准对应三家学派，差别只在于“以什么为权威”——老天爷、国家，还是老百姓的实际生活。

放到咱们众合的老师身上那就更好记了：道德水平最高的自然是大海老师，人品好、道德水平高，那就是自然法学派；官二代——马毕老师，村长的儿子也生儿子——那就是分析法学派；生活习惯好的就是岳老师，不抽烟不喝酒、按时上班、按时下班、天天在家做家务，那就是社会法学派。有同学问：杜老师您相当于什么？我这三个条件都具备，综合学派——人品也不错，有点官方背景，关键是生活习惯好。

### 其他影响力稍弱、但同样有分量的学派

除了三大学派，还有一些相对影响力弱一点、但同样有重要地位的学派：19世纪的**历史派**、**哲理派**，20世纪的**经济分析法学派**、**女权主义法学派**、**批判法学**，以及**法语文学**（后现代法学派）。这几个词我们得给大家解释一下，要不然到这儿就彻底疯了。哲理法学派后面还会再讲，这里就不做增补了，免得大家记笔记的压力太大。

#### 历史法学派：法律是民族精神

历史法学派认为，法律是随着民族的历史的变化而变化的，所以法律就要体现民族的历史演变——也就是**民族精神**。民族的精神肯定是在变化的：这一段时间可能需要A法律，那一段时间可能需要B法律，民族们需要什么，它就是什么。

它是**为了反对制定统一的民法典**而提出的观点。当时法国拿破仑时期比较强势，想把法国的民法典直接拿到德国来，遭到了德国一帮学者的极力反对，其中历史学派就提出来：法律是本民族的精神，你少拿着你们法国那个东西来讨我们德国。目的就是反对制定统一民法典，维护本国民俗传统。

当然，历史法学派后来慢慢地慢慢影响力下去了，后来德国还是制定了德国民法典。

#### 批判法学：没那么确定，也没那么中立

批判法学这名字一听就知道很有性格——对天对地。我们讲的法律的那些优点，在批判法学者看来根本就不是优点，他认为法律是缺点为主的，没什么优点。

你推测一下，批判法学在哪个国家影响比较大？**美国**——因为美国比较喜欢标新立异，学者研究也是这样。

他们主要否定两件事：

- **法律具有确定性**——“骗人的啊，这只是你们的梦，一个幻想”。你刑法规定“多次盗窃是盗窃”，那“多次”是什么意思？你认为两年内三次多，我认为两年内十次都不多；还有什么“暴力、胁迫、其他方法”，什么叫暴力？我打你一耳光叫不叫暴力？
- **法律是中立的**——他们认为法律根本就不中立，法律保护的都是有钱人的利益。

这些属于拓展内容，了解就行了。

#### 经济分析法学派：低成本、高收益才算好法

经济分析法学派认为，**法律应当进行经济学分析**：低成本、高收益的规定才是法律；违背了这个，那就不能叫好的法律。

这个学派也是目前**在美国影响最大的两大学派之一**，另一个就是批判法学。批判法学的大本营是**耶鲁法学院、哈佛法学院**，经济分析法学派的大本营是**芝加哥法学院**。经济分析法学派对我们的启发其实是很大的，所以本科是经济学这些相关学科的同学，你研究法律问题特别容易出成果。

举个例子。动物园要给动物搬家，搬家就得把动物装到笼子里，拉着笼子的车要经过闹市区。人家怕围观的市民去挑逗动物、或者离这个动物很近，动物可能会咬伤你甚至抓伤你，所以人家在笼子外面倒贴了好多“动物危险，请勿靠近”的提示。但仍然有人要作死，非要把手伸到笼子里，给狼握握手、给老虎握握手——你的手在老虎面前，这就是一顿可口的午餐。结果有的人手被咬断了，有的人手被抓伤了。

这个时候动物园要不要承担赔偿责任？

按照我们的传统观点、也是现在民法上采用的观点：这是**受害人被咬的人有重大过错**——你去挑逗动物了；而且动物人家也没有从笼子里跑出来，是你自己把手伸进去，生怕人家不咬你。所以应当**减轻甚至免除动物园的赔偿责任**。

但经济分析法学派认为：**过错就是动物园的**。他界定过错不是按自然法、天道，也不是你脑子里感觉“哎呀我已经告诉你别摸了你非得摸”——应该这么判断：**如果你选择高成本低收益的措施，你就是过错；只有选择低成本高收益的才是正确的**。

我们算一笔账就明白了：

| 方案 | 成本 | 评价 |
| --- | --- | --- |
| 只贴告示，不加装防护（现状） | 咬伤人赔 100 万，咬伤概率 10%，预期成本 10 万 | 高成本的选择 |
| 给笼子加装一层钢丝网 | 5 万 | 明明有低成本的选择摆在眼前 |

动物园明明有低成本的事儿你不选，非得选冒着高成本的风险——那你动物园脑子进水了，你就是有过错。所以赔吧，必须全额赔偿，是你自己非得选过错的。

你会发现，经济分析法学派这种分析的东西给人一种眼前一亮的感觉，它在一定程度上挑战了我们一些传统的观点，而且人家说的是不是也挺有道理的。当然人家对法律的贡献可不仅仅限于这里，包括违约责任的计算、侵权责任的分配，甚至刑法上有些责任的分配是不是违反了成本收益，他们都有非常深入的研究。学经济学的同学，毅然决然地去选“经济学和某个制度的结合”，你一定会好发论文，硕士毕业好毕业，读博士也好读——他就是需要这样的人才，多搞法律的，搞民法的、搞刑法的都不懂这个。

#### 女权主义法学派：女性视角

女权主义就是**女性视角**。这一帮人认为我们现在用的制度都是**男性视角**。其实他说的也有道理，因为一个国家的议员，那确实绝大部分都是男的，所以他们在立法的时候不可避免地就是男性视角。

他们的批评举起来都挺狠。比如你们这一帮臭男人，还天天探讨什么强奸罪的既遂标准，什么接触说、什么插入说——说“这就是你们的男性视角”：接触也好，插入也好，对我们来讲，我们都认为都是强奸；还说你区分什么强制猥亵罪和强奸罪，强制猥亵对我这个心理造成的伤害，那相当于被强奸；还有人看到美女以后眼都盯着，哗啦哗啦的口水往下流，他说这对我们来讲也是一种强奸——对女性的伤害是很大的。他们觉得这就叫要**从女性视角去改造现有的一些法律制度**。

再比如，女性受到侵害以后，在审判环节还需要提供一些证据，还需要去描述当时是怎么被侵害的。女权主义法学派就认为，你这是对我们**二次伤害**——你应该让对方证明他没有伤害我，而不是让我再重新描述一下他怎么伤害我的。嗯，挺有道理的。

#### 法语文学：法院就是一座剧院

你勾出“法语文学”四个字，后面标一个**文学视角**。

什么意思呢？我们平时宣扬法律是有神圣性的，法语文学则认为没有什么神圣的，就是一个**文学活动**。文学不都是虚构的吗？法院就是个剧院，法官就是演员，律师也是演员，坐在下头听审的人就是观众。你们只是想向我们表演，只是向我们表演；谁胜诉、谁败诉，取决于谁演技好。生活就是一场戏，全部靠演技。

你会发现，法语文学运动和批判法学**对法律的冲击是比较大的**：我们说法官那么神圣、那么庄严，他告诉我这就是个演员，就是表演的、演给我们看的而已，所以也没什么可神圣的；律师也都是演员，有点演技而已。

所以他们叫**后现代法学**。后现代指的就是**颠覆传统观点**——所以批判法学肯定叫后现代，法语文学肯定叫后现代。那有的同学问：女权主义呢？女权主义它倒不是颠覆，它是在男性视角之下，用女性视角来修复一些东西而已，所以没有归到后现代。后现代就是颠覆得比较狠。

这就是关于西方近现代法学发展——三大学派，再加其他几个偶尔考考的学派。当然重中之重还是三大学派。

## 唯物主义的立场：马克思主义法学的形成、特征与中国化
> 对应块：BLK04 | 覆盖分集：P05 | 块标题（分集名）：《第01章 第01节：法学（03）》

### "19 世纪"这个关键词先记牢

马克思主义法学也是产生于 19 世纪的。

你只要留个心就会发现，"19 世纪"这四个字在我们这张复习版图上会反复冒出来。为什么？因为 19 世纪实在是个法学派辈出的世纪。把 19 世纪的法哲学派捋一遍，其实主要就是五个：分析法学派、社会法学派、历史法学派、哲理法学派，再加上马克思。而自然法学派不算，它是 17、18 世纪的东西；经济分析、后现代这一批更是 20 世纪以后才登场。

| 学派 | 产生时间 |
| :--- | :--- |
| 自然法学派 | 17、18 世纪 |
| 分析法学派 | 19 世纪 |
| 社会法学派 | 19 世纪 |
| 历史法学派 | 19 世纪 |
| 哲理法学派 | 19 世纪 |
| 马克思主义法学 | 19 世纪 |
| 经济分析法学派、后现代主义法学 | 20 世纪以后 |

> **提示**：这张表是判断题的地基。后面"分析、历史、自然、经济分析都是 19 世纪"那句话为什么错？因为"经济分析是 20 世纪的"这一条就足以把整句否掉。

至于马克思主义法学的定义——不用背——就是用马克思主义来研究法律的。

### 从理性主义到唯物主义

马克思主义法学不是一上来就成熟的，它走了一条从抽象理性走向具体物质生活条件的路。分两段看：不太成熟的时期叫理性主义时期，后面是唯物主义时期，而唯物主义又分初期和成熟期。

#### 年轻马克思：理性主义时期

马克思年轻的时候也走过弯路。他受过康德和黑格尔的影响，落在理性主义里。

为什么理性主义听起来"理性"，其实却带一点唯心？因为"理性"本身就是主观时期的东西——所谓人的理性，不就是人的一些理智的、主观的想法和看法吗。所以理性主义这一段的表现，说到底是还停留在主观，带一点唯心。这是他年轻时候的样子。

#### 《黑格尔法哲学批判》：把法从理性拉回物质

唯物主义初期，第一个重量级的动作是《黑格尔法哲学批判》。

这本书干的是一件很有名的事：**先批判年轻时自己迷恋的黑格尔**。你想想这个逻辑链有多顺——黑格尔是唯心主义，那我批判黑格尔，就等于把唯心主义那只手从我身上剁掉了；剁掉了唯心，剩下的就只能往唯物那边站。于是马克思在这里确立了自己的唯物主义。

落到具体观点上，记住那句话：**根源于物质关系**。

> **结论**：从理性理解不了法，应该从物质条件来理解法。

这个观点我个人觉得还是相当正确的，因为它能解释那些特别顺嘴的历史疑问。

比方说，为什么唐朝的法律里没有计算机犯罪的规定？有的同学会说，那是当时人的理性想不到。理性想不到？——那我再问你，他为什么想不到？归根到底还是因为物质上还没出现计算机这个东西，连"计算机犯罪"这个行为都还没发生过，立法者当然无从规定。

再比方说，秦朝执行死刑为什么没有枪决？表面上看是理性上想不到，但实际上是因为物质上还没有手枪这类东西。

你看，马克思这个"从物质条件理解法"的眼光，一下就把"想不到"这个借口给拆穿了。立法的边界，很多时候不是理性划的，是物质条件划的。

#### 《共产党宣言》：向资产阶级开炮

唯物主义成熟期的代表，是《共产党宣言》。

这本书的立场摆在那儿：共产党是为了批判资本主义的。所以在这里马克思明确提出——**资产阶级的法，就是资产阶级的意志**，而这种意志归根到底受他们物质条件的支配。

甚至从书名上你就能把内容背过来：共产党，共产党干的不就是解放全人类、推翻资本主义嘛。所以《共产党宣言》宣称的就是：我要搞掉你们资产阶级；你们资产阶级的法，说的是你们的意思，不是我们工人的意思，不是我们穷人的意思。

> **易错点**：资产阶级和资本不是一回事。资产阶级有资本，但资产阶级不能完全等于资本——社会主义也有资本。这一条理解到位了，《共产党宣言》和《资本论》那两本书的位置就不会搞混。

#### 《资本论》：法的关系是经济关系的反映

再往下是《资本论》。

"资本"是什么？资本就是各种各样的钱、各种经济因素。所以到这一步，马克思提出的观点是：**法的关系是经济关系的反映**。又是经济。

这甚至不用背，你看到"资本"两个字，就自动对应到经济——尤其是经济里的金融。再联想一下，社会主义国家为什么也有资本？道理就通了。

#### 恩格斯时期与马工程教材的通行表述

第四块，恩格斯时期的著作也提到了一些人名，扫一眼、了解即可，考不到什么。

回头把马克思本人这一段捋一遍：他的思想经历了从**不成熟到成熟**的过程，走的是**从最抽象的理性到具体的物质生活条件**的路线，由此形成了马克思法学的最根本立场——**唯物主义**。

> **定义**：唯物主义，也叫历史唯物主义。

在其他版本的教材里——也就是马工程——往往会把成熟时期的马克思观点浓缩成一句话：

> **结论**：法是统治阶级的意志，这种意志受制于物质生活条件或经济基础。

**这句话的考点权重最高**，前面的"根源于物质"要勾，这句更要勾，倒数第二行那一句是这一块考得最多的。

我们把这句话拆开，用一个例子就能打通什么叫经济基础、什么叫统治阶级意志。

```text
   重要物质归谁所有  ──→  经济基础
        │                      │
     归统治阶级所有        统治阶级意志
        │                      │
        └──────────┬───────────┘
                   ↓
            这个意志写成法律
                   ↓
              被固定下来
```

所谓**经济基础**，一句话就是：重要物质归谁所有。比方说大片土地归谁所有——土地这个物质太重要了，归谁所有就是经济基础。

那归谁所有这件事，需要由法律确认下来嘛。而统治阶级肯定要宣布归我们所有——这就是**统治阶级意志**；这个阶级意志一旦写成法律，就被固定下来了。

> **提示**：经济基础这个概念，宪法那一科会正式讲，这里只是先提一句，但"重要物质归谁所有"这个抓手足够你做题用了。

### 马克思主义法学的四个特征

马克思主义法学的主要特征，是一般性重点，不是绝对重点，但必须能张口就来：**实践性、人文性、批判性、历史性**。

#### 实践性：创立了实践本体论

第一是实践性。有一句话要划重点：**马克思法学创立了实践本体论**。

什么叫实践本体论？就是**实践决定意识**——你的经历决定了你脑子里怎么想。它强调实践是检验真理的唯一标准，而不是什么天道，也不是说人们的习惯，而是人们的实践；而且这个实践，主要是**改造物质的实践**。

> **易错点**：这里有两个用词要盯住。"实践本体论"对应的是**开创者**；后面人文性那个"西方人文主义法律思想的**继承者**"，对应的是**继承者**。开创和继承，一字之差，别记反。

实践本体论和唯物主义是相伴相生的：既然世界的本源是物质，那么认识这个世界的起点也只能是改造物质的活动。

后面那半句——把法律的基础从概念拉到人类生活、从意识拉到实践——**不用背**，只背前半句"创立了实践本体论"就够。后面那半句是它在说人话：法律离不开实践，法律是实践的产物。什么实践？改造世界，尤其是物质世界的实践。

我改造土地，那土地相关的法律就得有；我当司机给人拉货、开车，那运输合同相关的法律就得有。

所以，法律是人类实践活动的产物，而不是某种悬在概念天国的抽象理性。马克思的意思是：不要去问"法是什么"，要看**人们的实践到底在干什么**——你的经历决定了法律。

#### 人文性：是继承者，不是开创者

第二是人文性：马克思法学是**西方人文主义法律思想的继承者**。

人文主义最直接的体现就是自然法学派——自然法学派说法律是人的理性，这不就是人文主义嘛。所以人文主义的意思就是**重视人**。但请注意用词：马克思是**继承者**，不是开创者；开创的是实践本体论。

在人文性上，马克思还把关注点往前推了一步：**他关注的不是抽象的人，而是现实的具体的人**。

什么意思？抽象的人的理性，那是自然法学派的落点；马克思看的是人们在现实生活中的具体需求——具体的生存需要。

法律要满足的是人民的需要，而不是某种抽象理性。理性在马克思看来太唯心了，但你把"重视人"这件事做对了，只是归错了地方——不该归到理性上，该归到人们在现实生活中实际需要什么上。

举两个例子你就有体感了：他需要车，法律就想办法看看通过什么方式能让他买上这辆车——不外乎是让他能挣到钱；你需要考上研究生，国家立法者就得想办法看看用什么样的方式能选拔出这些研究生。

> **结论**：人文性这一栏，后两句记这两条就够——**西方人文主义法律思想的继承者**、**关注现实具体的人**。

#### 批判性：一句话

第三是批判性。所谓批判，就是**批判资本主义**，这一句话就行了。他在《共产党宣言》当中对资本主义进行了非常全面的批判。

#### 历史性：时间与空间

第四是历史性，要划的是**法律的时间性和空间性**。

- **时间性**：法律随着时间的变化而变化。为什么？因为物质在变。物质条件变了，法律当然跟着变。
- **空间性**：不同国家会有不同的法律，因为不同国家面临的物质生活条件也不一样。

> **易错点**：这一条最好用的是举空间性的反例。美国有公民使用枪支的专门规定，我们中国没有——不是我们理性想不到，是我们两边的物质条件不一样。中国古代农业发达，所以民商法不发达，反而是保护财产、保护人身这类刑法的规定比较发达；古罗马农业不发达但商业发达，它的民商法就相应更发达一些。

这就是所谓的空间性和时间性。

#### 四个特征是从基本立场里推出来的

与其死背四个特征，不如记住它们是怎么来的——马克思的主张摆在前面，特征是自然长出来的：

```text
        主张唯物主义（历史唯物主义）
                    │
        ┌───────────┴───────────┐
        │                       │
   唯物性 ──→ 实践性      物质在变 ──→ 历史性（时间性＋空间性）

        主张阶级论
                    │
        ┌───────────┴───────────┐
        │                       │
 批判资产阶级 ──→ 批判性   解放全人类 ──→ 人文性
```

两条推导线读下来就是：唯物主义推出历史性加唯物性，唯物性就是实践性；批判阶级推出批判资产阶级，批判的是资产阶级对劳动人民的压榨，所以我批判了你，我就解放全人类了——于是又推出批判性和人文性。

当然，你也可以用口诀把它压成一句，随时在脑子里过一遍：

> **口诀**：**践人批历史**（践、人、批、历、史——实践性、人文性、批判性、历史性）。

对照关系也很整齐：

| 特征 | 一句话抓手 |
| :--- | :--- |
| 实践性 | 实践决定意识（实践本体论） |
| 人文性 | 关注现实具体的人 |
| 批判性 | 批资产阶级 |
| 历史性 | 时间（纵向变化）＋空间（横向分布） |

### 为什么要用马克思主义来研究法学

下面这一块是"我们要坚持用马克思主义的观点去研究法学"。理由其实很朴素：我们中国不是自然法学派，也不是社会法学派，也不是分析法学派，我们是**马克思主义学派**。

当然，这并不是说不研究别的学派，也不是说不能借用别的学派的方法——只是我们的立场在这儿。

四个要点按顺序看：

1. **坚持马克思主义为指导，是中国区别于其他法学的根本标志**。这一条要划。我们的中国法学、法理学是姓"马"的，就是马克思的那个"马"。这是**根本标志**。
2. 马克思法学揭示了法律发展的**普遍规律**。什么普遍规律？就是物质决定意识——物质。
3. 要**解放全人类**。这叫人文学性。
4. 马克思的**唯物主义是根本的标签**。唯物是马克思的标签，马克思又是我们中国的标签，所以中国的标签可以说就是唯物主义。

> **结论**：看到第一个根本标志、第三个解放全人类、第四个根本方法论，这几个词要看一看、勾一勾；第二个相对可以宽松。

> **提示**：第三条不是空话。前面讲实践性时说，法律是人们改造物质实践的产物；那么要满足人民在现实中的需要，就不能等着法律躺那儿不动，而是要**积极地改变世界，让世界越来越体现人民的意志、对人民越好**。这就是"解放全人类"在方法论上的落点。

### 马克思主义中国化的历史进程

这一块从往年考试来看没出过题，所以主要看要点、看框架。

#### 毛泽东时代：国体、政体与法制思想

第一个产物肯定是**毛泽东思想**。

毛泽东同志的论述主要从三个角度切入：**国体、政体、法制**。这里"法制"的"制"是**制度的"制"**，这个要划出来。因为那个时候还没有提出三点水那个"良法善治"的大思想。

- **国体方面**：毛泽东关于国体的一些学说，主要见《新民主主义论》《论政策》等论著。考点在第二项——**《论人民民主专政》这篇文章指出，我们的国体就是人民民主专政**。真考起来大概就是个小选项：毛泽东在哪篇文章里指出我们是人民民主专政？答《论人民民主专政》。好背，名字和文章是一样的。
- **政体方面**：**我国的政体是人民代表大会制度**。政体也叫政治体制，说的是横向的国家权力怎么分配。我们国家是人民产生人大，人大再产生其他机关，这就是人民代表大会制度这个政体。这主要是宪法里的考点。
- **社会主义法制思想**：看第二块。比方说**原则性、灵活性相结合**——立法不要立得太死，既要有制度，同时还要照顾一些特殊的灵活性；再有"有法可依，有法必依，依法办事"；还有平等；以及"以事实为根据，以法律为准绳"等等。

#### 邓小平、江泽民、胡锦涛：从创立到体系

毛泽东之后是邓小平，邓小平之后是江泽民，江泽民之后是胡锦涛——就"邓、江、胡"三个。

- **邓小平理论创立了中国特色社会主义法制理论**。注意，"**创立**"这两个字要划。背景是 78 年以后要解放思想，然后在 82 年宪法中提出了"中国特色社会主义"这样的词，并随之提出了一些法制理论。
- 江泽民是"**三个代表**"，胡锦涛是"**科学发展观**"。后两者是对邓小平法制理论的**丰富**，最终形成了体系。

> **提示**：命题点主要在"创立"和"邓小平的首创"这两个说法上。重要观点里包含民主、党的领导等等，了解一下就行。

#### 习近平法治思想：中国特色法治理论的集大成者

第三，现任领导人习近平。**习近平同志是中国特色法治理论的集大成者**。这个好记，习大大嘛，当然是集大成者了。

主要内容是习近平法治思想的 **11 个核心要义**。要说明一句：现在中央又提出了 12 个，但大纲目前还没改，所以我们就按大纲来，一共 11 个。新出来的那个，等新大纲出来以后再加上，后续的图书里会给大家补。

> **结论**：这 11 个是有可考性的。比如简答题"简述习近平法治思想的核心要义"，答案的简称就叫"**十一个坚持**"。

它有一条自己的内在逻辑。党是司机、把着方向，人民是乘客，那总得有条路；路修好了，治理国家要先有宪法（母法）；有了宪法还得在法治轨道上搞现代化；现代化要建体系，体系是"总抓手"；体系建起来，党、政府、老百姓三个层面都得依法来；依法要落到具体环节；国内还得兼顾国外；所有这些活儿得有人干，干活儿的队伍还得有人带头。所以我们先记关键词，再顺逻辑：

| 要义 | 关键词 |
| :--- | :--- |
| 坚持党对法治的领导 | 党 |
| 坚持以人民为中心 | 人民 |
| 坚持走中国特色社会主义法治道路 | 道路 |
| 坚持依宪治国、依宪执政 | 宪法 |
| 坚持在法治轨道上推进国家治理体系和治理能力现代化 | 现代化 |
| 坚持建设中国特色社会主义法治体系 | 体系、总抓手 |
| 坚持依法治国、依法执政、依法行政共同推进 | 依法执政对执政党，依法行政对政府 |
| 坚持"立、执、司、守"四大法治环节 | 立、执、司、守 |
| 坚持国内法治和涉外法治 | 国内法治、涉外法治 |
| 坚持建设高素质的法治工作队伍 | 队伍 |
| 坚持抓住领导干部这个"关键少数" | 领导干部 |

前三条是一组：**党**解决了方向问题，**人民**解决了目的问题（为了人民、依靠人民），**道路**解决了走什么路的问题。

第七条要特别拎出来说：依法执政是说给执政党听的，依法行政是说给政府听的，三者**共同推进**。第八条则是把法治进一步具体化成了"立、执、司、守"四大环节。

> **结论**：这 11 条主要解决两类问题——**党、人民、道路**解决"为了谁、谁来定、走哪条路"；**第四到第十一**解决"怎么落地、谁去干"。

逻辑梳理完就回到口诀上。把顺序打乱之后压成一句：

> **口诀**：**党和人民建队伍，外环路上抓干部，一体建设靠宪法**。

"外环路"对应的是国内法治和涉外法治，"一体建设"是法治国家、法治政府、法治社会一体建设，"靠宪法"是第四项依宪治国、依宪执政。

> **提示**：前两句比较好背，第三句"一体建设靠宪法"确实不太顺口——**不用在它身上纠结，前两句先背过就够了**。这些内容后边章节都有详细讲解，不要把补充精力全耗在这儿。

#### 习近平法治思想的伟大意义

这块主要看第一小点就够。四条，每条一个关键词：

| 意义表述 | 关键词 |
| :--- | :--- |
| 是适应了中华民族伟大复兴要求而产生的重大理论成果 | 伟大复兴 |
| 是马克思主义法治理论中国化的最新成果 | 最新 |
| 是习近平新时代中国特色社会主义思想的重要组成部分 | 重要组成 |
| 是我们搞法治的根本遵循和行动指南 | 遵循和指南 |

第三条要理解一下层级关系：习近平新时代中国特色社会主义思想可以简称为"习近平思想"，而**法治只是习近平思想中的一部分**，所以才叫"重要组成部分"。第四条则是"根本遵循和行动指南"。

这四个关键词也压成一句口诀：

> **口诀**：**新媳妇很重要，要听话**。新＝最新，妇（媳妇谐"复兴"）＝伟大复兴，重要＝重要组成，要听话＝根本遵循和行动指南。

到这一层，这个表格的考点就算掌握了。

### 本讲提到的题目

讲完理论我们做几道判断题。注意这五道题问的都是**归属**，也就是"这是谁的立场"。

**第一题**：按照马克思主义法学的基本观点，法学是伴随着国家的产生而产生的。

**错误**。总结一下时间先后顺序：先是法律和国家同时产生，然后经过一段时间才有了法学，再往后才出现法学流派。有了国家就有了法，但有了国家不等于立刻就有法学。

**第二题**：分析法学派、历史法学派、自然法学派、经济分析法学派都是 19 世纪的。

**错误**。19 世纪的是分析、历史、社会、哲理；经济分析是 20 世纪的；自然法学派更是 17、18 世纪的。这道题和开头那张表正好对着看。

**第三题**：社会法学派倡导法学应当关注法律现实。

**正确**。"法律现实、现实的法、社会实效"都是社会法学派的关键词。

**第四题**：自然法学派认为法律应当与社会的主流道德、人性的正义标准保持一致。

**正确**。主流道德、正义标准，换个说法就是**天道、自然法**，这正是自然法学派的立身之本。

**第五题**：分析法学派认为法学应当研究法与道德的内在关系。

**错误**。分析法学派是"就法律谈法律，不搞别的事"——它反对的是价值上的研究和分析，不去纠缠法与道德的内在关系。

### 复盘示范：怎么把讲义补成自己的知识索引

理论部分告一段落，我们把讲义翻回第一节前面的那几页，做一次快速的整体复盘，顺便演示一下**该怎么复盘**。

#### 复盘到什么程度才算够

讲义是一个**知识索引**，我一般只列到三级标题，有的地方内容多，就列到四级。但**你需要自己往下再细化一级，再细化一级**——这就是"再细化一级、再细化一级"的意思。

要注意的是，我**故意没有把所有注解都替你加好**。其实我一次全给你加上非常容易，但那样你就没有一点点参与感，复盘的效果肯定会打折。所以复盘的活儿必须你自己干。

下面我做示范，你就照着这个颗粒度往下填。

#### 示范：法学的概念与分类

法学的**概念**是研究法律现象的人文和社会科学。

"人文和社会"这四个字直接生出两件事来：第一是**研究对象的层次性**——研究法律现象有高有低，浅层次以**规则**为核心，中间层次是**原则**类，深层次是**规律**类。你复盘的时候要把这个层次性自己加上去，这就是关键词式复盘。

法学的**性质**分为人文科学和社会科学，这两条你自己加小注解：

- **人文科学**：涉及主观角度、主观层面，又叫精神层面——研究一个制度背后的精神。
- **社会科学**：研究客观层面的角度，例如研究历史、研究制度、研究社会现象。

到这里我多问一句，这已经不算复盘内容了，是比较难的内容：**自然法学派更侧重人文科学还是社会科学？**

当然更侧重人文科学——它探讨的是法律的价值和精神。那**分析法学派**更侧重什么？当然是社会科学，它研究制度。**社会法学派**呢？研究社会。

这一轮问答串下来，这一节的性质部分就彻底活了。

再往下是**法学体系**，它是从不同角度切出来的不同分类：

| 分类角度 | 分类结果 |
| :--- | :--- |
| 从制定到实施的角度 | 立法学、司法学等 |
| 认识论角度 | 理论法学、应用法学 |
| 学科关系角度 | 法教义学、交叉学科 |
| 法律部门角度 | 民法学、刑法学等 |

> **提示**：理论法学和应用法学的区分，**最核心的标准就是"能不能直接用"**——这是做题标准。

从历年真题来看，考得相对比较多的是**理论与应用的分类**，以及**法教义学、交叉学科的分类**。

#### 示范：法学的产生与历史

**产生条件**有两个：一是**法律材料的积累**，二是**有研究法律的一方学者阶层**（学者群体）。

由此推出一个结论性的链条，这个你复盘的时候要自己写上去：

```text
   法律材料的积累  +  学者阶层出现
                  ↓
      先有法律（与国家同时）  ──→  再有法学  ──→  再有法学流派
```

**法学的历史发展**，分几条线。

- **中国**：一句话就够了——**中国古代有法学，但无法学流派**。春秋战国那些细节你可以不背。
- **西方古代和中世纪**：古希腊有了法学，但没有学派；古罗马有了学派；中世纪法学成为婢女；再到罗马法复兴时期的注释法学派。这一段我已经全写在讲义上了，你**不用再填任何东西**。
- **西方近现代**：这部分才需要你自己补口诀。

**自然法学派**，两个口诀：**"自然人等个约"**和**"理性永远高"**。

```text
  自然人等个约
    │    │  │  └─ 社会契约 → 产生新的国家和政府
    │    │  └──── 平等
    │    └─────── 天赋人权（自由、平等）
    └──────────── 自然法、自然权利

  理性永远高
    └─ 人的理性：永恒、永恒不变、高、高于人定法
```

**分析法学派**的主要观点，看这个口诀就行：**"反对中超，上学没价值"**。

> **易错点**：这里的"中超"就是中超联赛——踢球踢得还不如苏超，还谈什么价值。

拆开就是四条反对：**反对终极真理、反对超越现行制度、反对形而上学、反对价值上的研究和分析**。

**社会法学派**的要点是**"社会现实反逻辑"**：倡导法的社会属性、倡导法的现实，反对仅仅做逻辑研究。

再往下还有历史学派、哲理学派、经济分析学派、后现代主义（主要是批判和文学方向），加上女权主义也可以。

> **易错点**：**经济分析法学派和分析法学派没有直接关系**，别看到都带"分析"就混为一谈。经济分析指的是**用经济学来分析法律**；上面那个分析法学派指的是**仅仅分析现行制度**。

#### 示范：马克思主义法学这一块怎么复盘

- **产生与发展**：写上三本书就差不多了——批黑格尔的《黑格尔法哲学批判》提出**物质**；《共产党宣言》提出**批判资产阶级**；《资本论》提出**经济决定论**。
- **特征**：记"**践人批判历史**"，每条后面补四个字就够——实践性补"实践决定意识"；人文性补"**具体的人**"；批判性补"批资产阶级"；历史性补"时间和空间"，时间就是纵向的发展，空间就是横向的分布。
- **要用马克思主义研究法学**：其实只有两个关键要点——**马克思主义法学是我们国家的标签**；**马克思主义自己的标签就是唯物**。
- **中国化**：包括毛泽东时代、邓小平时代、江泽民时代、胡锦涛时代，但**主要考点集中在习近平法治思想**。这一块你只要把两个口诀写上就行：**党和人民建队伍，外环路上抓干部，一体建设靠宪法**；**新妇重要要听话**。

## 法理学：法学的一般原理与它的方法论
> 对应块：BLK05 | 覆盖分集：P06 | 块标题（分集名）：《第01章 第02节：法理学》

理论法学下面有一个叫**法理学**的。法理学是看知识的，所以它相对就简单一些。走到这一节，也就当成一个小结来听：它站在整个法学的门口，把"法学是什么"、法理学自己研究什么、它对别的学科有什么用、我们研究法律又该用什么方法，全过一遍。**它对整个法学这个学科、以及法理学自己这个学科，做的是一次全景式的介绍。**

整节就三个问题：法理学的研究对象是什么；法理学有什么用、是什么地位；法理学的方法及其意义。

### 研究对象是一般意义上的法

第一个问题，其实就是"什么叫法理学"。

> **定义**：法理学的研究对象，是**一般意义上的法**——即法的全部现象及其规律。

"全部法律现象及其规律"这句话听着挺大，其实是三块拼起来的。

**一是法的整个领域，或者说全部的法律现实。** 立法、执法、司法、守法、监督，五个环节我都研究——我给它们编了个顺口溜，叫"立直四守监，五连鞭"。刑法、民法、行政法、诉讼法，我都研究。

**二是古今中外的法。** 中国古代的、外国古代的，中国现代的、外国现代的，都研究。

**三是各部门的法。** 研究它们的规律、共同特征、共同范畴，为部门法提供一些指南。所谓共同的地方，比如不管刑法法条还是民法法条，背后都得有一个逻辑结构存在，这个逻辑结构是共同的；再比如刑法、民法都分具体规则和不太具体的原则，这也是共同点。

把这三层压缩一下，就是两组八个字：**研究法的一切，和一切的法。**

### 边界在哪：什么都研究，也就比较空

紧跟着这句话，有个特别容易踩的坑。

> **易错点**：这里说的是"研究结论应能解释法的一切现象"。你不要产生误解——不是说我在法理学后边随便拿出一个结论来，就能解释刑法、民法、行政法、刑诉、民诉。**不是这个意思。**

真正的意思是：假定法理学研究出了一百个原理，这一百个装在一个"百宝箱"里，你**总是能**从中找出解释某一个部门法某些现象的理论来；但并不意味着这100个里边的**任何一个**，都能解释所有学科。

那这个"解释一切现象"到底到什么程度？我拿正当防卫给你试一下就知道了。

我跟大海、岳岳、马屁他们聊什么问题，我都能聊——我可以聊正当防卫背后的价值，可以聊正当防卫制度的整个历史。但你**千万不要**跟我聊你这个学科里特别具体的那些问题。你比方说真的问我正当防卫的构成要件——那我就歇菜了。

为什么？因为法理学研究的东西大而全，什么都研究，所以就比较空、也就比较空洞，研究得就没有那么准确和精确。它是"广"，不是"准"。

反过来看，它真正能解释的东西长什么样？我举**安全价值**这个例子。法理学会研究安全价值，那么对于安全价值的研究，就能解释刑法分则里那些罪名在保护安全价值上承担的角色是什么，能解释民法当中侵权责任保护安全价值是什么，也能解释违约责任保护安全价值。**是某个特定原理去解释某块具体现象，不是随便一个法理学结论就能解释所有部门法。**

那要真是随便一个法理学结论都能解释所有部门法，那还考什么刑法、民法呢？就都考法理不就行了。所以这句话你要注意，不要从它表面意思去理解。

### 与部门法是一般与特殊，不是整体与部分

第二个问题：法理学有什么用，它是什么地位。

法理学是**法学的一般原理**，既是基础的原理，也是基础的方法论。这句话一说，就点出它有了**两个属性**：一个是理论性的东西，一个是方法性的东西。方法论体现在哪儿？往第三个问题走你就看到了。

它跟部门法的关系，是**一般与特殊**的关系，为部门法的研究提供了一些理论依据和研究方法。

> **易错点**：是**一般与特殊**，**不是整体与部分**。

这两个我特别要说一下，因为太容易混了。

比方说整体与部分——我杜洪波站在这儿，我是个整体，我这条胳膊是个部分，这是它们的关系。胳膊就是"我"的一部分。

法理学跟部门法**不是**这种关系。法理学是把各个部门法的**公因式提取出来**——你可以理解成公分母，提取的是各部门法里一般性的东西、他们共同的那些规律。它是"一般"从一堆"特殊"里被提出来的那个东西，而不是整体被拆下来的一个零件。

再往下，法理学与**法史学**是"论"与"史"的关系。跟其他学科也有关系，这个**了解即可**。主要的就是一般和特殊这个关系，再加上上面那个方法论。

### 法理学给的是方法论

第三个问题：法理学的方法及其意义。

前面说了，法理学两个属性里的那个"方法"属性，就落在这一节。方法论体现在哪里？体现在两个层面——一个是根本方法，一个是法学自己的一套方法。

#### 根本方法是马克思的唯物主义

法理学告诉我们，要用马克思的方法去研究法律——也就是**辩证唯物主义、历史唯物主义**。

它对部门法同样有指导：你搞刑法研究、搞民法研究，也一样得落脚到唯物主义。

什么叫落脚到唯物主义？看两个例子。

一个是**立法**。我们说现在自媒体、大数据正在发展。前几年制定民法典的时候，能一劳永逸地制定出一部非常完善的、有关数据的民法规定吗？肯定不能。所以立法者在立法的时候，就得考虑这种**物质现实的变动性**，只能做一些宽泛的规定，你没有办法做特别具体的规定——你不能拿当时的科技水平，把以后的事写死。

另一个是**刑法解释**。现在开设赌场有了网络赌场，那么刑法的解释上就得注意到这个唯物主义的变化，必须把开设赌场罪的打击范围扩大到网络赌场。遇到新形态，就得跟着物质变化去调整规范，而不是抱着老条文硬套。

> **注意**：但这不等于用马克思主义哲学代替法学。搞法学研究，除了用马克思的唯物主义这个根本立场以外，还得有法学自己的一些具体方法。所以紧接着这一句要记住——**不能用马克思主义哲学代替法学。**

#### 法学自己还有一套具体方法

法学自身方法论，和法学流派是**具有对应关系**的。这张表你直接记住就行：

| 方法 | 哪个学派创的 |
| :--- | :--- |
| 社会调查方法——看看社会现实是什么 | 社会法学派 |
| 历史调查方法 | 历史学派 |
| 价值分析方法——价值、精神、正义、道德 | 自然法学派 |
| 阶级分析方法 | 马克思 |
| 分析比较法、语义分析——分析制度里的词语、分析制度本身 | 分析法学派 |
| 社会效益、经济效益 | 经济分析法学派 |

分析法学派这个我要多说一句：他们基本上就是这样的研究，你看他的书，里边就像**高中的语法书**一样，读起来特别难。语义分析就是分析制度里面的词语、分析制度本身。

所以我们才说法理学它既是理论，同时也给了我们研究方法的启发。自然法学派，首先它是理论，其次它是价值分析法；社会法学派，首先它告诉我们一些原理，其次告诉我们社会调查的方法。**正因为如此，才有了前面那个说法——法理学既是一般理论，也是方法论。**

那最后这一句"研究西方法哲学流派对方法论的启发"，这句话要划出来重点看：是因为这三大门派对我们，**既有理论上的启发，也有方法论的启发**；这三大门派对我们中国的法制建设，甚至制度建设，都有非常大的启发。

### 一套制度，要看三样东西

三大流派的启发，具体体现在哪儿？体现在我们研究一个外国的制度的时候。

一个完善的法律制度的研究，习惯上得包含三个角度——除非你用经济分析法去研究制度，一般就是下面这三个：

| 研究角度 | 问的是什么 |
| :--- | :--- |
| 制度 | 外国有什么制度 |
| 价值 | 这个制度背后的价值和精神是什么，对人们的意义是什么 |
| 实效 | 它在现实当中到底怎么运行的 |

这三个你得都研究。相对成熟的一种研究是这样的：外国有这种制度，那这个制度背后蕴含的价值是什么，对人们的意义或者价值是什么，以及它在现实当中是怎么运行的。

反面例子就是我们去看有的学术论文：哎呀，外国有这么一些制度，我们中国没有，所以我们中国应该把这个制度抄过来。**这种说法是贬义的，就是比较幼稚**——那它有制度，但运行得不好，你把它拿过来有什么用啊？

> **结论**：研究一套制度，"国外有"只是起点，"国外跑得通"才是落点。只看到"有"，不研究它凭什么有、跑不跑得动，这样的研究是低档次的。

那反过来看，成熟的研究对我们自己的制度有没有启发？有。我举一个你们肯定背过、也肯定考的——

**《民法典》第十条**：民事法律行为应当依照法律，法律没有规定的，可以适用习惯，但不得违背公序良俗。

你把这三句话拆开看：

| 原文 | 对应流派 |
| :--- | :--- |
| 应当依照法律 | 分析法学派 |
| 法律没有规定的，可以适用习惯 | 社会法学派 |
| 但不得违背公序良俗 | 自然法学派 |

**《民法典》第十条其实就是三大法学派的融合。** 好了，这一条现在知道了——为什么说他考得多，你也就明白了。

### 三个考点，八个字

这一节我们快速复盘一遍，就三个考点。

**法理学的研究对象**，就是一般意义上的法：所有的部门法及环节，以及古今中外一切的法。压成八个字——**"法的一切""一切的法"**，就这八个字就行了。

**法理学的地位**，主要就是一个考点：它与部门法的关系是一般和特殊关系，**而不是**整体与部分关系。

**法理学本身还能提供方法论。** 包括我们的根本方法，那就是马克思的唯物主义——后面加"唯物"就可以了；再往下是法学还有自身方法，社会调查啊、语义分析等等，后面跟"对应学派"四个字就行了。

这就是第一章的内容：它对于整个法学这个学科，以及法理学这个学科本身，做了一个全景式的介绍。
