# 民事法律行为与意思表示

## 民事法律行为在民法中的位置

* **民事法律行为（民事法律关系的变动事实）**
    * > **定义**：民事主体通过意思表示来设立、变更、终止民事法律关系的行为。
    * 不是生活概念，而是从千千万万种具体的表意行为中"提取公因式"抽掉个别差异后剩下的共同骨架
    * 讲的是各种具体民事法律行为的**一般理论与共性规则**，在民法典各分编都有适用余地
    * 道理是反过来的：得先有总则的一般规定，才谈得上学分编的具体制度
    * > **易错点**：它是理解民法学是否入门的试金石，分则学完第二轮回看本章，好多问题会迎刃而解

* **理论层与规范层的两段式**
    * 理论层：概念、特征、分类
    * 规范层分两步走：
        * 第一步定"有没有一个民事法律行为"，即**成立**——一般要件 + 特别要件，核心要件是意思表示
        * 第二步定"法律上如何评价"，即**生效**——有效 / 可撤销 / 效力未定 / 无效

| 效力形态 | 含义 |
| :--- | :--- |
| 有效 | 完全被法律所认可 |
| 可撤销 | 原则上有效，但有被撤销的可能性 |
| 效力未定 | 效力处于不确定状态，需要相关权利人的决定才能确定 |
| 无效 | 相当于被法律给否定了，直接打不及格 |

* **特别要件（仅符合一般要件不够，还得符合它才生效）**
    * 约定的特别要件：附条件或附期限，行为能否生效取决于将来确定发生或者不发生的不确定事实
    * 法定的特别要件：审批手续，主要在合同领域
    * > **提示**：法定的特别要件到合同编再讲

* **准民事法律行为**
    * 典型如宽恕、谅解一类的表示
    * 根本就不属于民事法律行为，不能与单方、双方行为并列选择

## 概念的三个关键词

* **主体—意思表示—内容**
    * > **定义**：三个关键词连起来就是民事法律行为的概念，这个表达逻辑在背诵和学习相关内容时会反复用到
    * 关键词一**民事主体**：行为得以受主体意志支配为前提，所以必须得有主体；自然事实与主体意志无关，不要求有主体
    * 关键词二**意思表示**：这是民事法律行为和事实行为最大的区别，必须包含一个"我愿意"的成分
    * 关键词三**内容**：民事法律行为毕竟是民事法律事实，必须包含一个导致民事法律关系发生变动的内容

* **合法性要件从必需要件到被删除**
    * 1986 年《民法通则》明确规定：民事法律行为必须是合法行为，不合法就不能构成民事法律行为。
    * 制定民法典时把这一要件**删掉了**：认定民事法律行为时不再考虑合不合法
    * 只要符合主体、意思表示、内容三个要求，即使不合法也属于民事法律行为的范畴
    * 类比：人有好人坏人、时好时坏，但不管是好人坏人都是人；民事法律行为同理
    * > **易错点**：效力有瑕疵、甚至根本无效，不影响"它是一个民事法律行为"这个定性，效力与定性是两件事
    * 例：小学生甲以 2000 元把手机卖给同班同学乙——甲欠缺相应民事行为能力，**效力**存在瑕疵；但有主体、有意思表示、有内容，**仍是民事法律行为**

## 两个特征

* **特征一：以意思表示为基本要素**
    * 意思表示是民事法律行为的**必要但不充分条件**
    * 没有意思表示，民事法律行为不能成立
    * 有了意思表示，民事法律行为不一定成立
    * > **提示**："必要但不充分"这五个字是后面大量判断题的底层工具

    ```text
    没有意思表示  ──────▶  ✗  民事法律行为不成立
                            （必要条件）

    有了意思表示  ──────▶  ?  未必成立
                            （不充分条件）
                            │
                            ├─ 双方行为：还要双方意思表示达成一致
                            ├─ 诺成行为：意思表示一致即可成立
                            └─ 实践行为：意思表示一致 + 交付标的物
    ```

    * 不能用单个意思表示成立的情形：
        * 双方民事法律行为（合同）：甲"我这个手机 2000 块钱卖给你如何"是**要约**，乙"没问题"是**承诺**，两个意思表示达成一致才形成合同
        * 实践合同：保管合同中甲提出代为保管宠物狗（要约）、乙说"没问题"（承诺），双方意思表示已一致，但还要**交付标的物**才成立

* **特征二：以设立、变更、终止民事法律关系为目的**
    * 强调内容的"变动"体现当事人意愿，是当事人希望发生的
    * 与**情谊行为**界分：甲说"周末我请你到家里来坐坐，我请你吃大餐"虽有意愿表达，但可能只是客气，没有使双方产生法律关系的意图
    * 与**事实行为**界分：甲开车不慎撞乙，法律后果体现的是**法律的意思**，不是甲希望和乙产生损害赔偿关系的意图
    * 这两个特征正是概念中"意思表示"和"内容"两个关键词的展开

## 分类总表

* **九种分类的区分标准**

| 分类 | 区分标准 |
| :--- | :--- |
| 单方 / 双方 / 多方行为 | 意思表示的数量 |
| 有偿 / 无偿行为 | 是否有对价 |
| 诺成 / 实践行为 | 成立是否已交付标的物或完成其他给付 |
| 要式 / 非要式行为 | 行为成立是否必须依照某种特定形式 |
| 主行为 / 从行为 | 两个民事法律行为之间的相互关系 |
| 财产 / 身份行为 | 法律后果是财产性质还是人身性质 |
| 负担 / 处分行为 | 财产行为的效果是负担义务还是发生权利变动 |
| 有因 / 无因行为 | 原因行为无效是否影响结果行为的效力 |
| 独立 / 辅助行为 | 有没有独立的实质性内容 |

* **分类的现实意义**
    * 实践中民事法律行为五花八门，不可能指望一个规范解决所有问题，所以要分门别类设置不同规则。
    * 考试要求：掌握专业术语 + 记几个典型例子

## 意思表示的数量

* **单方法律行为**
    * 仅由一方当时的意思表示就能成立，一个意思表示即可，一个人说了算
    * 例：订立遗嘱——处分遗产不需要别人同意；抛弃债权、抛弃所有权
    * **形成权的行使都是单方行为**：形成权基于一方意思表示即可使双方法律关系变动，无需他人同意

* **双方法律行为**
    * 双方意思表示达成一致才能成立
    * 例：合同（要约 + 承诺）；结婚，一方愿娶、一方愿嫁

* **多方法律行为**
    * 多个意思表示达成一致才能成立
    * 例：甲乙丙签订合伙合同一起开公司

* **决议行为**
    * 也是一种民事法律行为，但**不需要意思表示达成一致**，采少数服从多数原则。
    * 例：股东会决议过半数股东同意即可；物权编的业主大会按法律规定的比例同意即可。
    * > **易错点**：决议与多方行为不同——多方行为要求意思表示**达成一致**，决议走**比例多数**

## 有无对价

* **有偿行为**
    * 一方从对方获得利益时须向对方支付对价
    * 例：买卖（付钱取得物）、租赁（付租金取得居住使用）

* **无偿行为**
    * 一方获得利益时无需向对方支付对价
    * 例：赠与合同（明星向基金会捐款）；遗赠
    * 遗赠的定性：无偿行为，且是**单方行为**，因为它本质上就是一个遗嘱，老王一个人即可做决定
    * 受遗赠人应在 60 天内表示接受才取得遗产
    * > **易错点**：受遗赠人的接受只是**取得遗产的要件**，不是**遗赠行为成立的要件**；受遗赠人拒绝接受，不影响遗赠行为本身已经成立

* **可以有偿也可以无偿的行为**
    * 例：借款约定利息的是有偿，未约定利息可认定为无偿；委托可以给报酬也可以不给

* **无偿行为的责任规则**
    * > **结论**：在民法中凡是无偿的行为，基本上都只对故意和重大过失负责——他是纯粹付出的一方，法律对他的要求不能太高

## 是否交付

* **诺成行为**
    * 只需要意思表示达成一致就可以成立，一诺而成
    * 例：买卖，双方意思表示一致时合同即成立，后来没有交付标的物也不影响成立

* **实践行为**
    * 意思表示达成一致之外，还需交付标的物或完成特定给付行为
    * 民法典只规定三种实践合同：**定金合同、保管合同、自然人之间的借款合同**
    * 自然人之间借款：既需双方意思表示达成一致，还需出借方实际交付金钱；达成一致但未交付金钱的，合同不成立

* **同一借钱事实因主体不同而定性不同**
    * 陈某请老马吃饭并借款 100 万，老马当场同意并签字，未交付金钱；后老马以妻子不同意为由拒借——**不能追究违约责任**，因为双方都是自然人，属实践合同，根本没有成立
    * 陈某另向众合公司借 200 万，公司同意并签订书面合同，后公司以资金紧张拒借——**主张违约责任可以成立**，因为出借方不是自然人，不属于自然人之间的借款，只能是诺成合同，书面合同签订即已成立生效

* **作此区分的理由**
    * 对应的是"人情世故"四个字：自然人之间相互帮忙，为了面子可能嘴上答应甚至签字，但若一签字就必须给钱，不符合生活常理
    * 法律给对方一个反悔的台阶，对当事人也公平
    * 公司从事经营行为，别人打交道时很难相信它只是客气一下，所以意思表示一致合同即成立

## 形式要件

* **要式行为与非要式行为**
    * 区分标准：行为的成立是否必须依照某种特定形式
    * 要式行为：必须以某种特定形式做出来；非要式行为：形式由当事人当时自行决定
    * > **提示**：民法要尊重意思自治，不要求形式是**原则**，要求形式是**例外**；法律没有明确规定的，原则上就是非要式行为。

* **要式行为的典型**
    * 结婚：双方同意还不够，必须办理结婚登记才能成为夫妻，因涉及身份变动，要慎重、要有仪式感
    * 遗嘱：必须符合法律规定的形式要件，因为人死无对证，要确保是真实意思
    * 重要商事交易要求书面形式：建设工程合同（标的额大、履行周期长）、商品房买卖合同（价值重大、便于举证的书面形式）

## 彼此关系

* **主行为与从行为**
    * 区分标准涉及的是**两个**民事法律行为之间的相互关系
    * 主行为：不需要其他行为存在为前提，能独立自主
    * 从行为：从属于主行为，具有从属性

* **担保合同是最典型的从行为**
    * 甲买房向银行贷款形成主债权债务关系（主合同，可独立成立）
    * 甲把房子抵押给银行签订抵押合同，为担保该债权实现而设，从属于主债权债务合同
    * 甲一次性还清银行贷款后主合同因履行完毕而消灭，即使抵押合同未办理解除手续、未办理抵押权注销登记，也随之失去效力
    * 皮之不存，毛将焉附

## 财产行为与身份行为

* **财产行为**
    * 法律后果是财产关系发生变动
    * 例：甲乙签订买卖合同形成债权债务关系；甲抛弃所有权把东西扔掉；债权人免除债务

* **身份行为**
    * 法律后果是身份关系发生变动
    * 例：结婚形成夫妻关系、协议离婚使夫妻关系消灭；签订收养协议并办理登记形成养父母与养子女关系

## 负担行为与处分行为

* **定位**
    * 区分标准：以财产行为发生的效果是**负担义务**还是发生**权利变动**
    * 这是**财产行为的进一步区分**，与身份行为是**并列关系**，不是包含关系
    * 我国民法典没有采纳这一概念或分类，但法硕考试大纲有考点，所以必须学

* **负担行为（债权行为）**
    * 只产生债权债务关系
    * 例：甲把房子卖给乙签订买卖合同，甲有义务转移所有权、乙有义务支付价款，签订合同只产生债权债务关系
    * 所以甲乙签订离婚协议、和平分手，既不是负担行为也不是处分行为——那是身份行为。

* **处分行为**
    * 直接导致权利发生变动
    * 例：买卖合同签订后甲把房子过户登记到乙名下，登记使所有权从甲转移到乙

    ```text
    签买卖合同  ──▶  负担行为（债权行为）：在甲乙之间产生债权债务关系
                      甲有义务转移所有权 / 乙有义务支付价款

    办理过户登记  ──▶  处分行为：直接引起权利变动
                      ├─ 物权变动    ──▶  物权行为
                      └─ 其他权利变动 ──▶  准物权行为
    ```

* **处分行为的进一步区分**
    * 导致**物权**变动的叫**物权行为**
    * 导致**其他权利**变动的叫**准物权行为**
    * 例：甲与乙签订股权转让合同是负担行为（甲负转移股权义务、乙负支付对价义务）；甲到工商部门办理股权转移登记，股权直接发生变动，是准物权行为。
    * > **易错点**：签了一个合同（负担行为）和要发生权利的变动（处分行为）不要混，办理登记导致房屋所有权变动的才是处分行为。

* **我国不采纳的原因**
    * 生活角度讲，买房签约后配合过户是一个完整交易，甲不会平白无故把房子过户到乙名下，这个理论把简单的生活问题复杂化了。
    * 我国事实上区分的是**合同的效力**和**物权变动的效力**：合同效力按民法典判断，有没办登记主要决定物权有没有发生变动；我国不区分负担行为与处分行为。
    * 官方教材在事实行为部分也写明"作为债权标的的给付行为，如交货、付款，属于事实行为"，并未把办理登记当成独立的物权行为。

## 有因行为与无因行为

* **区分标准的正确理解**
    * 它讲的不是"这个行为有没有原因"，而是"**原因行为如果无效了，会不会影响这个结果行为的效力**"
    * 该概念从负担行为与处分行为的区分中延伸而来，负担行为是处分行为的原因行为。

* **有因行为**
    * 原因行为无效，作为结果的行为也随之无效，二者荣辱与共、一荣俱荣一损俱损

* **无因行为**
    * 原因行为无效，不影响结果行为的效力，二者相互独立、各自为政

    ```text
    原因行为 = 负担行为（买卖合同）
    结果行为 = 处分行为（物权行为：登记；票据行为：出票）

    有因行为：原因无效  →  结果也无效      （我国主流）
    无因行为：原因无效  →  结果依然有效    （德国民法；我国票据行为）
    ```

* **德国民法立场**
    * 区分负担行为与处分行为的目的，恰恰是为了强调二者的**无因性**——否则区分就没有意义
    * 既认可物权行为的独立性，也认可物权行为的无因性

* **我国主流采有因观点**
    * 甲把房屋卖给乙并办理登记，后合同被认定无效，则乙**不能**取得房屋所有权，物权变动结果受合同效力影响
    * 德国民法式处理下乙虽可取得所有权，但已丧失法律上的原因，构成不当得利应返还给甲，实质结果与我国做法无本质区别
    * > **提示**：这一组概念是思考工具，不要用它来分析我国现行民法典的规范

* **我国采无因观点的例外：票据行为**
    * 票据包括汇票、本票、支票
    * 例：甲公司向乙公司订购货物，约定以 10 万元银行汇票支付，甲公司开出汇票；后买卖合同被认定无效，乙仍可凭汇票到银行兑付
    * 这样规定的目的是**确保汇票正常流通、保护后续票据权利人的信赖利益**——票据可能已转让给上游供货商等多人，若一遇合同无效就作废会损害后续持票人
    * 但乙从银行兑得的 10 万元已丧失法律上的原因，构成不当得利，仍须返还给甲
    * 我国是**以有因为原则，以无因为例外**

## 独立行为与辅助行为

* **区分标准**
    * 民事法律行为有没有独立的实质性内容：有的是独立行为，没有的是辅助行为。
    * 多数民事法律行为都是独立行为，重点关注辅助行为

* **独立行为**
    * 例：大学生甲用 1 万元国家奖学金购买手机并签订买卖合同，会在甲与手机店之间形成买卖合同关系，有独立的实质内容

* **辅助行为**
    * > **定义**：不具有独立内容、只辅助其他行为生效的民事法律行为。
    * 典型例子是**追认行为**：10 周岁的小学生甲用 3 万元奖金购买手机签订买卖合同，该合同是独立行为，但甲欠缺相应民事行为能力，属**效力未定**而非直接无效
    * 甲的家长乙同意并追认，使效力未定的合同确定地发生效力
    * 追认是行使**形成权**，追认本身无独立实质内容，其价值是辅助买卖合同生效、补齐效力的最后一块拼图
    * > **提示**：考试角度重点记"追认"这一个例子

* **辅助行为与从行为是两回事**
    * 从行为虽然从属于主行为，但它首先自己就是一个独立行为，有独立实质内容（抵押合同、保证合同、地役权合同）
    * 类比：小弟跟着大哥混，大哥赚钱他吃肉、大哥倒霉他遭殃，但依然是个独立存在。
    * 辅助行为则完全没有独立实质内容，如同打石膏只是辅助恢复，不是有独立意义的存在。

## 意思表示的概念

* **意思表示**
    * > **定义**：民事主体将意欲表达于外部的行为
    * 关键词一"**意欲**"：内心必须有那个意思，即希望和对方发生一定法律上效果、设立变更或终止某种法律关系
    * 关键词二"**表达于外部**"：外在还得有一个表示行为，光心里想着不行
    * 两个关键词缺一不可：只有内心没有外在表示的是"心里想想"；只有外在动作而没有任何意欲指向的只是一项事实行为。

* **三个例子（载体不同，定义全对得上）**
    * 甲公司向乙公司发出订单，以 1000 元单价求购某型号零件 1 万件——载体是数据电文
    * 甲生重病已无药可治，深夜手书遗嘱，将存款 30 万元捐给某爱心基金会——载体是手书
    * 某东网站某米旗舰店在网页上标注新款手机详情及销售价格——载体是公开展示，属于**要约**

* **三个特征**
    * 特征一：内容要**指代发生某种法律关系的变动**，即必须包含使法律关系发生变动的意图（与定义中"意欲发生一定法律上效果"是同义替换）
    * 特征二：是一个**意思由内到外的表示过程**，光在内心不够，一定要通过一定方式表达于外部
    * 特征三：依据是否符合生效要件**赋予其不同的效力**
    * > **提示**：第三条更像一条"效力规则"而非概念本身的属性，要到"生效"部分才真正展开

## 意思表示的作出

* **作出方式三分（民法典第 140 条）**
    * 行为人可以明示或者默示作出意思表示，沉默只有在有法律规定、当事人约定或者符合交易习惯时，才可以视为意思表示
    * 明示和默示是**原则**，沉默是**例外**

    ```text
                        意思表示的作出
                              │
            ┌─────────────────┼─────────────────┐
          明示               默示               沉默
         （原则）           （原则）          （例外）
            │                 │                 │
       ┌────┴────┐       作为的默示        不作为的默示
      口头      书面      特定行为间接表示      单纯不作为
       │         │                              │
      简便易行   留下字据                   原则上不构成
      直接迅速  双方权利更明确            法律规定/当事人约定/
      口说无凭   交易成本升高            符合交易习惯时"视为"
    ```

### 明示

* **口头形式**
    * 用语言做意思表示，如当面说"我看你这个手机 2000 块钱能不能卖给我"、打电话问"你这个房子 200 万能不能卖给我"
    * 优点：简便易行、直接迅速
    * 缺点：没有留下文字根据，争议时容易口说无凭

* **书面形式**
    * 以文字做意思表示，发短信、发微信、发律师函都属书面形式
    * > **注意**：书面形式的范围大于日常说的"文字形式"。此前民法典对书面形式有规范定义，关键是"**有形表现**"四个字——电报、电传、传真本身是无线电讯号，不严格算文字，但同样能以有形方式表现所载内容，属于书面形式
    * 分为一般书面形式与特殊书面形式；做公证、做登记等落实到文字上的属于特殊书面形式
    * 优点：能留下字据，双方权利相对明确
    * 缺点：会增加交易成本

* **两者的现实权衡**
    * 甲愿以 210 万买乙的房并在格式合同上签名——是明示、也是书面，内容明确，但需打印合同文本，交易成本高
    * 在水果摊口头买个西瓜就解决了，方便得多；为 30 块钱坚持签书面合同反而增加交易成本
    * 各有利弊，这就是形式选择的现实

### 默示

* **作为的默示**
    * > **定义**：虽未通过语言或文字明确表示意见，但通过**特定的行为**间接表示其意思
    * 例：去自助餐厅自己取餐；去超市把想买的衣服、猪肉直接放进购物车——这个动作本身就是购买的意思；坐公交、地铁直接刷卡上车
    * 默示比明示更好理解，因为它是**可见的**

### 沉默

* **不作为的默示**
    * > **定义**：当事人既没有明确表示（不是明示），也没有通过特定行为表明意图（不是作为的默示），而只是单纯选择了不作为。
    * 单纯不作为原则上**不能**作为意思表示的作出方式，不能推定作出了意思表示
    * 例：甲向乙发微信表白求结婚，乙不好意思直接拒绝，选择置之不理；一天后甲认为"没拒绝就是同意"——不符合生活常理，在成年人的世界里不回复本身就是一种态度

* **视为意思表示的三项条件**
    * > **注意**："视为"是**法律拟制**的立法技术——只要符合条件，不管本人当时有没有这个意思，法律都认为作出了意思表示
    * 条件一：**有法律规定**。例《民法典》第 638 条试用买卖，约定了明确试用期（如平板七天），试用期届满未明确表示买或不买，视为同意购买
        * 试用买卖中约定了试用期的，当事人对买不买**有回复义务**，不回复即推定同意购买、须支付价款
    * 条件二：**当事人约定**。例视频平台首月六元开通会员的优惠附带"开通自动续费"条款，约定不操作即推定同意续费、下个月照常扣费
        * > **注意**：以双方在意思表示上达成一致为前提
    * 条件三：**符合交易习惯**（简单理解即可）

### 两套框架的对应

* **官方教材的思路**：口头形式、书面形式、作为的默示、不作为的默视，一共四项
* **《民法典》的思路**：明示（下分口头、书面）— 默示（即作为的默示）— 沉默（即不作为的默视），共三层
    * > **注意**：口头书面跟作为/不作为的默视根本不是一个层次的概念
    * 主观题写法：先按《民法典》展开大框架（第一层明示分口头、书面两小点；第二层默示即作为的默示；第三层沉默即不作为的默示），既思路清晰，又把官方教材和民法典两套说法结合起来

### 天气预报服务短信案

* **案情**
    * 甲收到乙通讯公司短信："本公司为您提供实时的天气预报服务，每月收费五块钱。如果不接受此服务，请回复 N。"甲看后未予理睬，后被收取该费用，请求返还

* **三步分析**
    * 第一步，乙的短信包含服务名称、价格和联系方式并表明一经接受即订约，可构成**有效的邀约**
    * 第二步，甲既未明示"我要订阅"，也未以行为表明（不是作为的默示），只是**单纯的沉默**，原则上不能作为意思表示
    * 第三步，"当事人约定"这个例外不能适用：短信是乙通讯公司**单方面**提出的要求，甲从未表示接受这一安排，双方未就此形成合意
    * 三个例外情形均不成立，甲的沉默不能视为作出了意思表示
    * 结论：**合同没有成立**

* **"不成立"与"无效"的界分**

| | 客观上是否存在合同 | 法律评价的对象 | 后续处理 |
| :--- | :--- | :--- | :--- |
| 不成立 | 不存在合同 | 无从评价 | 无合同可管，甲可请求返还已收费用 |
| 无效 | 存在合同 | 评价该合同的效力 | 合同被法律否定，效力瑕疵需另行处理 |

    * > **易错点**：一定要把"不成立"和"无效"分开选——判断有效无效的前提是**已经成立**的民事法律行为。
    * 在章体系上，这个短信只走到"成立"这一步就结束了，连有效无效的判断入口都进不去

## 意思表示的生效

* **三种类型**
    * **无相对人的意思表示**：不需要别人受领，做出来即可
    * **有相对人的意思表示**：需要有人受领
    * **公告方式作出的意思表示**：向不特定的多数人作出

    ```text
                         意思表示的生效
                              │
       ┌──────────────┬───────┴────────┬──────────────────┐
     无相对人       有相对人                      公告方式
     完成时生效   ┌────┴────┐                 发布时生效
       │         对话      非对话             （推定已处于
       │          │         │                不特定多数人
       │        知道主义   到达主义            可随时查看的状态）
       │      相对方知道   到达相对方
       │       其内容时   （可随时查看时）
       │
       └── 例外：遗嘱等死因行为，
           以死亡为生效要件
    ```

### 无相对人的意思表示

* **生效规则**
    * 不需要别人受领，无需考虑别人感受，**完成时即发生效力**
    * 例：小花把男友送的手镯、项链、衣服全部丢进垃圾桶表达情绪，属抛弃所有权，直接扔就成立，所有权归于消灭

* **例外：遗嘱**
    * 遗嘱也是无相对人的意思表示，不需要本人受领，深夜写完封存、死后打开即可。
    * 但它是**死因行为**，完成时不能发生效力，要以遗嘱人的死亡作为生效要件
    * 例：老王 2020 年 1 月 1 日立遗嘱把全部财产归众合公司，必须等到老王死亡时该遗嘱才生效

### 对话方式与知道主义

* **对话与非对话的区分标准是意思表示能不能实现即时的沟通**
    * 对话方式：能及时沟通的，如面对面交谈、打电话、打视频
    * 非对话方式：不能及时沟通的，如发律师函、发微信、发电子邮件——虽然可以即时到达，但对方可能不能随时查看
    * > **易错点**：区分标准**不在于双方距离远近**。打电话时双方可能相隔几千公里，仍是对话；大学生宿舍六个人却靠微信群约饭，有人正专心听课没看到消息，不能及时回复，仍是非对话

* **生效规则：自相对人知道其内容时发生效力**
    * 采**知道主义**立法模式，不能一出口就生效
    * 例：甲乙协商签约细节，一南一北方言口音悬殊需翻译转达；会见阿拉伯客户需翻译帮助，都要等对方了解表意内容时才发生效力
    * 理由是要考虑相对方的感受

### 非对话方式与到达主义

* **生效规则：到达相对方时发生效力**
    * 采**到达主义**立法模式
    * > **注意**：这里的"到达"**不是指相对方要查看内容**，而是该意思表示处于相对方**可以随时查看的状态**时即已到达
    * 例：律师函已到达对方公司收发室、负责人一周后才取出查看——到达收发室时意思表示就已生效
    * 例：电子邮件只要到达对方信箱、处于其随时可查看状态，就认为已到达已生效

### 数据电文

* **定性**
    * 数据电文虽可及时到达，但对方不能随时查看、无法及时沟通，仍属非对话方式，采到达主义

* **指定的接收系统**
    * 相对人指定了特定接收系统（如约定订单发到指定邮箱）的，要到达指定的接收系统才能生效

* **未指定接收系统**
    * 按《民法典》：**相对人知道或者应当知道该数据电文进入其系统的时候**发生效力
    * > **提示**：与原《合同法》不同——《合同法》规定未指定时进入**任何**接收系统即生效，不合理，因为很多人有多个邮箱，不能要求相对方时时查看全部邮箱；《民法典》改为"知道或应当知道"
    * 例：岳某把订单发到车某名片上的电子邮箱，属进入指定接收系统
    * 例：名片上只有电话号码没有邮箱，岳某从其他途径找到其 QQ 邮箱发过去并打电话告知——车某**知道或应当知道**数据电文进入其系统，即使还没点开，意思表示就已生效

### 公告方式

* **生效规则：自公告发布时发生效力**
    * 面向不特定的多数人，发布即推定其处于不特定多数人可以随时查看的状态
    * 例：某人在微信朋友圈发寻物启事，指向不特定多数人，从发布时即生效

## 意思表示的撤回

* **撤回的含义**
    * 在意思表示**生效之前**消灭其效力
    * 撤回通知应当在意思表示**到达相对方之前，或者与意思表示同时到达相对方**——必须在到达之前的这段时间里完成

* **有无撤回时机的判断**
    * **无相对人的意思表示**原则上完成即生效，常常没有撤回机会；**遗嘱是例外**，因为它是死因行为，从完成到死亡这段时间未生效，可以撤回
    * **公告方式**发布即生效，没有撤回时机
    * **有相对人中的对话方式**可及时沟通，常常没有撤回时机
    * **只有非对话方式**采到达主义才有撤回时机——从做出到到达之间的时间差给了当事人撤回的机会
    * 悬赏广告也是典型意思表示，属有相对人的可以撤回（撤回规则到合同编讲）

## 意思表示的解释

* **两个核心根据与三种模式**
    * 解释意思表示含义的两个核心根据：当事人内心的意思、外在表示的行为。
    * 以内心意思为最终目标或根据，叫**意思主义**；以当时的外在表示为解释根据，叫**表示主义**
    * 我国《民法典》采**折中主义**，区分有无相对人适用不同解释原则，具体问题具体分析

* **无相对人：意思主义**
    * 法条表述：解释时**不能拘泥于所使用的词句**，外在表示不具有决定意义，应结合有关条款、行为的性质和目的、习惯以及诚信原则确定行为人的**真实意思**
    * 理由：既不需要别人受领，就无需考虑相对方的信赖，主要考虑表意人内心真实的意思
    * 例：张某自住 302（301 由儿子小张居住），自书遗嘱却写"我一直住的 301 号房，要赠与给好友刘某"
        * 遗嘱是典型的无相对人意思表示，张某的真实意思具有决定性
        * 其真实意思是把**自己住的 302 号房**给刘某，只是把房号写错了。
        * 同一层门对门的两套房都是自己买来，门对门常常分不清号，只记得哪头是儿子住的；张某一想"我是老子肯定住 301"就把符号写错
        * 文书写错并不当然否定真实意思，即"无害于真意"
    * > **提示**：这就是"不拘于文义、真意优先"，签合同或作意思表示写错有笔误，能确定真实意思就按真实意思确定——这类问题不必去走重大误解等撤销路径，直接用解释解决

* **有相对人：表示主义**
    * 法条表述：**应当按照所使用的词句**，再结合相关条款、行为的性质和目的、习惯以及诚信原则确定意思表示的含义
    * 需要别人受领，就得考虑对方接收到的讯息，外在表示更重要；最终确定的含义**可能与当时内心的真实意思不能划等号**，要保护相对方的信赖利益
    * 例：车某向岳母借 10 万元，借条写"为一分利"，借期一年
        * 车某认为是一分钱利息，岳母认为指每月 1%、12 个月共 12% 即 1.2 万元
        * 第一步定性：借款合同属有相对人的意思表示，采表示主义，按"一分利"这一词句结合其他因素解释
        * 第二步逐项考虑：借款行业惯例中"一分利"代表每月 1% 的利息；按生活常理若真是一分钱应写"一分钱"而非"一分利"；基于诚信，一分钱连象征性利息都算不上
        * 结论解释为**每月 1%** 更合适，应付 1.2 万元利息；不管车某签合同时怎么理解，发生纠纷时解释出的含义对双方都有约束力

## 常见题型的落点

* **民事法律行为与相关行为的判定**

| 情形 | 定性 | 理由 |
| :--- | :--- | :--- |
| 到烈士陵园缅怀先烈 | 不是民事法律行为 | 不包含设立、变更、终止民事法律关系的目的 |
| 开车不慎将行人撞倒 | 事实行为 | 法律后果体现法律的意思，不是行为人的意愿 |
| 邀请朋友到自家聚餐 | 情谊行为 | 虽有意愿表达，但无产生法律关系的意图 |
| 向同事转让一架钢琴 | 民事法律行为 | 体现所有权转移的意图与支付合理价格的意思 |
| 13 周岁学生把书包扔掉 | 是民事法律行为，但效力有瑕疵 | 有限制民事行为能力欠缺不妨碍定性：主体是甲、有抛弃的意思表示、有内容 |
| 租赁 | 双方行为 | 属合同关系，需对方同意 |
| 订立遗嘱 | 单方法律行为 | 一方意思表示即可成立 |
| 宽恕、谅解 | 准民事法律行为 | 根本就不属于民事法律行为 |
| 侵权行为 | 事实行为 | 后果不受行为人意志支配 |
| 定金合同、保管合同、自然人之间借款合同 | 实践合同 | 成立以交付标的物为要件 |
| 天气预报短信中的甲 | 合同不成立 | 沉默原则上不构成意思表示 |

* **判定路径小结**
    * 先问"有没有意思表示"——没有则不成立
    * 再问"意思表示够不够"——双方行为要一致，诺成行为一致即可，实践行为还要交付
    * 成立之后再问"法律怎么评价"——才有有效、可撤销、效力未定、无效之分
    * 效力有瑕疵、根本无效，都不改变"它是一个民事法律行为"的定性
