# 知识产权概述

## 本编定位与考查走势

* **第四编的法典地位**

    * 知识产权在民法典中没有独立成编，而是通过单行法的方式加以规范。
    * 法硕民法的考察范围包括但不限于民法典的内容，知识产权仍属必考范围。
    * 全编四章：第一章概述共性问题与理论问题，第二、三、四章依次介绍著作权、专利权、商标权。
    * 概述章真正要啃的三块：知识产权的含义和特征、商业秘密的法律保护、知识产权法与《反不正当竞争法》的关系。

* **考查走势**

    * 知识产权部分曾经考过八次简答题。
    * 2021 年起重要性下降，原因有二：考试大纲对这一编内容作了删减，删除了不少考点；自 2021 年起该部分主要通过客观题考察。
    * 2025 年，一些已被删除的考点又陆续加回考试大纲。
    * > **结论**：知识产权依然保有考到主观题的可能性，对这一部分仍要给予相应重视。

## 知识产权的含义

### 概念三要素

* **知识产权（Intellectual Property）**

    * > **定义**：知识产权指民事主体就某项创作性质的智力成果依法享有的专有的权利。
    * 关键词为三个要素加一个限定语：主体、客体、内容，再加"依法"。
    * "依法"一层是它作为绝对权、采取法定主义立法模式留下的印记；法定主义意味着权利的种类和内容都由法律作出规定，因此法律的明确规定是本编学习的重中之重。

    ```text
    ┌────────────┬────────────┬────────────┬────────────┐
    │  主体      │  客体      │  内容      │  依法      │
    ├────────────┼────────────┼────────────┼────────────┤
    │  民事主体  │  智力成果  │  专有      │  法定主义  │
    │ 自然人      │  作品      │  排他性    │  权利种类与│
    │ 法人、      │  发明创造  │  独占性    │  内容由法律│
    │ 非法人组织  │  商标等    │  法律赋予的│  规定      │
    │             │            │            │            │
    └────────────┴────────────┴────────────┴────────────┘
    ```

* **主体与客体**

    * 主体没有特殊性，就是民事主体：自然人、法人、非法人组织都可以享有知识产权。
    * 客体体现为某项创造性智力成果，可以是作品、某项发明创造，也可以是一个商标等等。

* **内容：专有**

    * 内容是两个字"专有"，体现为法律赋予权利人对某项智力成果的控制权。
    * 未经权利人同意，他人不能随便利用这个智力成果。

### 广义与狭义

* **划分标准与两种含义**

    * 区分标准是涵盖的智力成果范围不同。
    * 狭义仅指三种经典知识产权：著作权、专利权和商标权。
    * 广义泛指对各种智力成果而相应的权利，包括但不限于上述狭义的三种。

* **民法典采广义**

    * 民法典虽未让知识产权独立成编，仍通过一个条文描述了知识产权的概念，认可它是民事权利大家庭的一员。
    * 《民法典》第 123 条的客体清单：作品型的客体（作品）、专利权型的客体（发明、实用新型、外观设计）、商标型的客体（商标），以及地理标志、商业秘密、集成电路布图设计、植物新品种等其他智力成果。
    * > **易错点**：民法典颁布之后考知识产权概念，只能考民法典规定的广义版本，不能答狭义的三种。

## 知识产权的四项特征

### 特征来源与归属

* **主体项**

    * 知识产权的主体是一般主体，没有特殊性，所以没有形成独立的特征。

* **保护限制的来源**

    * 知识产权作为民事权利要受法律保护，但保护体现出特殊性——保护要受到相应的限制，法律对它的保护是有所克制的。
    * 克制的原因是这一成果的推广和利用可以促进社会发展进步，为了社会发展进步，保护就要受限。
    * 限制有两个：一个地域的限制叫地域性，一个时间的限制叫时间性，即"天时地利"。

* **四项的归属**

    * 客体体现无形性、内容体现专有性，这两项从概念中的要素角度描述。
    * 地域性、时间性从保护应当受到限制的角度描述。
    * 四项合起来才是知识产权的完整特征。

### 无形性与专有性

* **无形性（客体项）**

    * 智力成果看不见摸不着，具有无形性的特点。
    * 与物权形成鲜明对比：物权同为绝对权、同为专有权，但其客体指向特定的物，动产与不动产都体现有体财产的属性；知识产权的客体是无形的。
    * 一个有体，一个无形。

* **专有性（内容项）**

    * 概念里用的就是"专有"二字，民法典也把"专有"作为专业术语明确规定下来。
    * 专有性的一层是排他性：知识产权也是绝对权，同样体现"一山不容二虎"；同一智力成果上不能存在两个以上内容相冲突的知识产权，否则没法保证权利人专有权的行使。
    * 专有性的另一层是独占性：权利人对该知识成果有一个独占的使用权，别人没有经过许可不能擅自利用。
    * > **结论**：排他性 + 独占性，等于民法典所称的"专有"这个专业术语。

### 地域性与时间性

* **地域性**

    * 知识产权专有权的行使范围是在特定的国家或者地区领域内，超出这个范围就不能主张专有权。
    * 专利权体现得最明显：美国某公司就某项技术申请了专利，可以在美国范围内主张独占使用权，但不能禁止中国某公司在中国领域内使用该技术。
    * 专有权的效力范围有限，只能在申请专利的美国范围内主张；要在中国范围内也主张专有权，得在中国同样去申请专利。

* **时间性**

    * 保护要受到期限限制，超出保护期限该智力成果即进入公共领域，任何人可以自由使用，权利人不再有独占的使用权。
    * 专利权指向某项发明创造，期限相对较短，一过期限该技术就变成公共资源；商标权 10 年保护期届满后可自由续展；著作权期限相对长，自然人作者为作者终身加死后 50 年。
    * 一部分特殊知识产权不受时间限制，商业秘密即属此类——只要能够保守这个秘密，就可以一直获得保护。
    * > **易错点**：时间性要具体问题具体分析，不能一概而论。驰名商标虽然届满可以自由续展，但要不续展就没有商标权，仍受时间限制。
    * 地理标志同样不受时间限制。

    | 权利类型 | 保护期限 |
    | :--- | :--- |
    | 发明专利 | 20 年 |
    | 实用新型专利 | 10 年 |
    | 外观设计专利 | 15 年 |
    | 商标权 | 10 年，届满以后可以自由续展 |
    | 著作权（自然人作者） | 作者终身 + 死后 50 年 |
    | 商业秘密 | 不受时间限制 |

## 商业秘密

### 概念的关键词拆解

* **商业秘密（Trade Secret）**

    * > **定义**：商业秘密指不为公众所知悉、具有商业价值，并经权利人采取相应保密措施的技术信息、经营信息等商业信息。
    * 内容主要规定在《反不正当竞争法》这部特别法里面。
    * 理解方法是拆解关键词法，拆开就两个字：第一个是"商业"，第二个是"秘密"。
    * "商业"体现为具有商业价值这一属性，即在商业竞争中可以给权利人带来某种优势。
    * 例：肯德基的配方就是商业秘密，它能给权利人带来竞争上的优势、可以帮它赚钱。
    * "秘密"的第一项要求是非公知性，即不为公众所知悉，一般人不知道；众所周知的事实不属于商业秘密的范畴。
    * "秘密"的第二项要求是保密性：权利人特别采取一些措施防止别人知道，使它一直处于非公知状态。
    * 保密性的时间结构是现在不为公众所知悉，同时采取保密措施确保将来也不被公众所知悉。

* **三项要求合流**

    * 从"商业"角度要体现价值性，从"秘密"关键词延伸出非公知性和保密性，三者共同构成商业秘密的成立要求。
    * 以保密配方形式存在的商业秘密不受时间限制，只要能一直守住这个秘密即持续受保护。

* **与专利权的分野**

    * 专利权具有公开性特点，专利技术都是向社会公开的，不需要买通员工来窃取。
    * 商业秘密正因不公开，其保护才依赖非公知性与保密性两项要求。

### 保护范围

* **技术信息与经营信息**

    * 范围既有技术信息，也有经营信息。
    * 技术信息一侧，肯德基的配方属于技术信息，《大宅门》里白加药丸的配方也属于技术信息，是有一定技术含量的。
    * 经营信息一侧同样纳入保护，公司的特殊进货渠道、客户名单也属于商业秘密，可获法律保护。

* **法律列举的客体**

    * 设计程序、产品配方、制作工艺、制作方法、管理诀窍、客户名单、货源情报、产销策略、招投标中的标底及标书内容等，都可以纳入商业秘密的保护范围。

* **在民法典中的定位**

    * 商业秘密是《民法典》第 123 条知识产权客体清单上的一项，属于广义知识产权而非狭义三种。

### 侵犯商业秘密的行为形态

* **两层次结构**

    * 第一个层次是直接侵权行为，即直接实施了侵犯商业秘密的行为。
    * 第二个层次是间接侵权，虽未直接实施侵权行为，但利用了别人的侵权成果，也属于侵犯商业秘密的行为。
    * 规范依据是《反不正当竞争法》第十条。

    ```text
    侵犯商业秘密（反不正当竞争法第十条）
    │
    ├─ 直接侵权
    │   ├─ 经营者实施的行为
    │   │   ├─ 没有合法持有商业秘密
    │   │   │    ├─ ① 非法获取（盗窃/贿赂/欺诈/胁迫/电子侵入）
    │   │   │    └─ ② 非法利用（在①的成果之上再非法利用）
    │   │   └─ 已经合法持有商业秘密
    │   │        ├─ ③ 违反保密义务或保密要求，擅自披露/使用/
    │   │        │   允许他人使用已掌握的商业秘密
    │   │        └─ ④ 教唆、引诱、帮助他人违反保密义务或保密
    │   │            要求 → 有意思联络，构成共同侵权
    │   └─ 其他主体实施上述行为的，也"视为"侵犯
    │
    └─ 间接侵权
        └─ 第三人明知或应知权利人的员工、前员工或其他主体实施
           上述违法行为，仍然获取、披露、使用或允许他人使用该
           商业秘密的
    ```

* **为什么按主体分层**

    * 《反不正当竞争法》主要规范经营者的行为，那是它的地盘范围；经营者实施这类行为会破坏公平的竞争秩序，是该法的核心规范内容。
    * 其他主体虽不是经营者，实施相关行为也可能构成侵犯商业秘密，所以法律一并作了规定。

### 经营者的四种行为

* **没有合法持有：非法获取**

    * 获取他人商业秘密的途径本身就是非法的，包括通过盗窃、贿赂、欺诈、胁迫、电子侵入等方式获取。

* **没有合法持有：非法利用**

    * 通过前述途径获得商业秘密以后继续实施非法利用，也构成独立的侵权行为。
    * > **易错点**：非法利用是单独一层，不能被"非法获取"吸收掉。

* **已经合法持有：违反保密义务**

    * 在商业交往中通过合法途径取得对方商业秘密的，依诚信要求应当尽到保密义务。
    * 具体表现为违反保密义务或相关保密要求，擅自披露、使用或者允许他人使用已经掌握的商业秘密。

* **已经合法持有：教唆、引诱、帮助**

    * 通过教唆、引诱、帮助他人违反保密义务或者保密要求的方式，获取、披露、使用或者允许他人使用商业秘密的，也构成侵权。
    * 行为人与合法持有商业秘密者存在共同故意或过失、有意思联络，构成共同侵权时同样承担侵权责任。

    | 层次 | 情形 | 通俗理解 |
    | :--- | :--- | :--- |
    | 没有合法持有 | 非法获取 | 靠盗窃、贿赂、欺诈、胁迫、电子侵入等非法途径拿到 |
    | 没有合法持有 | 非法利用 | 拿到之后还继续非法用，是独立的一档 |
    | 已经合法持有 | 违反保密义务 | 合法拿到，但擅自披露、使用或允许他人使用 |
    | 已经合法持有 | 教唆、引诱、帮助他人违反保密义务 | 与负有保密义务者有意思联络，构成共同侵权 |

### 其他主体与第三人

* **其他主体**

    * 其他主体虽然不是经营者，实施上述行为的也构成侵权。
    * > **注意**：法条在这里用的词是"视为"。这部分内容本来不属于《反不正当竞争法》管辖的范围，该法主要管经营者的行为，只是其他主体实施上述行为也要承担侵权责任，所以法律一并作出规定。

* **第三人（间接侵权）**

    * 第三人明知或者应知商业秘密权利人的员工、前员工或者其他主体实施上述违法行为的，仍然获取、披露、使用或者允许他人使用该商业秘密的，也可以视为侵犯商业秘密的行为。
    * 虽然没有直接实施上述侵权行为，但别人实施侵权行为获得的成果自己同时享用，同样要承担侵权责任。

### 买通内部员工型侵权的判断

* **案情**

    * 甲公司买通乙公司的员工，获得乙公司的产品制造方法以及客户名单等保密信息；其后以乙公司的名义和乙公司的客户进行交易。

* **侵害商业秘密**

    * 甲公司买通内部员工取得保密信息，属于与负有保密义务的主体有意思联络、构成共同侵权的方式，这种联络体现为共同故意。

* **同时侵害名称权**

    * 甲公司擅自以乙公司的名义和乙公司的客户进行交易，属于擅自冒用他人名称实施民事活动，以冒用方式侵权、假冒他人。

* **不侵害专利权**

    * 题干根本没有提到专利权；且专利权具有公开性特点，专利技术向社会公开，不需要买通员工窃取。

* **不侵害隐私权**

    * 隐私权的主体仅限于自然人，乙公司作为公司不可能享有隐私权。

## 知识产权法与反不正当竞争法的关系

### 保护面向

* **追究不正当竞争行为人的责任**

    * 侵犯他人的知识产权、特别是侵犯商业秘密，会构成不正当的竞争行为；通过追究不正当竞争行为人的责任即体现对知识产权的保护。
    * 侵犯商业秘密的行为人承担侵权责任，一方面维护了商业秘密权利人的权利，另一方面也维护了公平的竞争秩序。

* **混淆行为兼具双重性质**

    * 2025 年修订《反不正当竞争法》时对混淆行为作了相应修订。
    * 混淆行为一方面是侵犯知识产权的，另一方面也是一种不正当的竞争行为。
    * 混淆行为的现实成因是流量经济时代粉丝多、影响力大的 IP 很值钱；通过蹭热点、蹭流量、搭便车的方式与他人发生混淆、给自己带来消费者关注，即构成此类行为。
    * 让实施混淆行为的人承担责任，就是对知识产权的一种保护。

* **混淆行为的四类表现**

    1. 擅自使用和他人有一定影响的商品名称、包装、装潢等相同或者相近似的标识。
    2. 擅自使用他人有一定影响的名称、姓名。名称既包括全称，也包括简称、字号；姓名既包括正式姓名，也包括笔名、艺名、网名等别名。
    3. 擅自使用他人有一定影响的域名主体部分、网站名称、网页、新媒体账号名称、应用程序名称或者图标等。
    4. 擅自将他人的注册商标、未注册的驰名商标作为企业名称中的字号使用，或者将他人的商品名称、企业名称、注册商标、未注册的驰名商标等设置为搜索关键词。

* **与民法典人格权相对接**

    * 2025 年修订把简称、笔名、艺名、网名纳入保护范围，是与民法典相对接的体现。
    * 民法典姓名权的保护范围既包括正式的登记名称，也包括具有一定社会影响力的简称；被他人误用从而导致混淆的这些别名，同样在保护范围之内。
    * > **注意**：第 3 类中的"新媒体账号名称"要特别留意，微博上的大V、B 站的 up 主，包括小红书上粉丝比较多的账号名称，被他人蹭流量、蹭热点同样可能构成不正当竞争行为。

### 限制面向

* **保护过于周全的代价**

    * 知识产权是绝对权，如果对它的保护过于周全，必然会影响技术的推广和利用，进而有损社会公共利益的实现。
    * 所以法律对知识产权也要进行限制：萝卜和大棒要一起用。

* **垄断状态下不再保护**

    * 如果对某项技术已经构成某种垄断，法律这时就没法对它进行保护，行为人不能再主张所谓的专有权。

* > **结论**：理解这两部法的关系就抓住两个关键词——一面是保护，一面是限制，两手都要用，缺一不可。
