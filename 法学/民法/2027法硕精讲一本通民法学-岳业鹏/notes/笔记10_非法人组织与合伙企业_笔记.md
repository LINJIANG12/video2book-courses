# 非法人组织与合伙企业

## 非法人组织的概念与特征

* **非法人组织**

    * > **定义**：不具有法人资格，但是依法能够以自己的名义从事民事活动的组织。

    * 三个关键词连起来写构成概念，拆开写构成特征。

        * 「以自己的名义」体现它是《民法典》上的民事主体；能否以自己的名义对外从事民事活动，是判断一样东西是不是民事主体的第一道门槛。

        * 「组织」是与自然人的区别所在，说明它不是若干个自然人的简单相加。

        * 「不具有法人资格」也可以说成「不能独立地承担责任」，这是它与法人的分界线。

* **三个特征**

    * 具有相对稳定的成员构成，是真正的组织而非自然人的简单叠加。

    * 具有相应的民事权利能力和民事行为能力，因此得以为民事主体。

    * 不能完全独立地承担民事责任，这一项体现它与法人的区别。

## 非法人组织在民事主体体系中的位置

* 它以组织的形式出现，是《民法典》新增加的具体民事主体类型，新增的规定需特别留意。

* 组织这一支向下分成法人与非法人组织两半，非法人组织这一支又向下分为三种法定类型。

    ```text
    民事主体（民法上的人）
    ├── 自然人
    │   └── 个体工商户（自然人参与工商业经营的特殊形式）
    └── 组织
        ├── 法人：有限责任公司、股份有限公司
        │        以及特别法人（居民委员会、农村集体经济组织等）
        └── 非法人组织
            ├── 个人独资企业
            ├── 合伙企业
            └── 不具有法人资格的专业服务机构
    ```

## 组织财产与成员责任的先后顺序

* 对外以组织的名义、盖组织的章，对内财产不足就要穿透到人，这是它与法人最大的区别。

    ```text
          甲合伙企业（以自己的名义签合同、盖公章）
                            │
            ①  先以组织自己的财产清偿
                            │
                            ▼
                   甲合伙企业的财产
                            │
            ②  清偿不了的部分，由人兜底
                            │
                            ▼
           车、马、跃三人的个人财产 ──连带──▶ 债务最终了结
    ```

* 先以组织自己的财产承担；承担不了的部分，由成员以自己的个人财产连带负责到底。

* 正因为合伙企业承担不了的部分要由合伙人负责到底，才能说明它没有独立承担责任的能力。

* ⚠️ **易错点**：判断一个组织是法人还是非法人组织，不必背一堆定义差异，抓住「责任最终落在谁头上」这一条就够了。

## 非法人组织的法定类型

* **三种法定类型**

    * 个人独资企业。

    * 合伙企业。

    * 不具有法人资格的专业服务机构。

* 三个名称都是法言法语，首先要把类型名称记牢。

### 个人独资企业与合伙企业

* 两者都是企业、都具有经营属性，区别只在于投资人的人数：一个人投资的是个人独资企业，两个人以上一起投资的是合伙企业。

* 读懂两者的概念只需关注三个词：谁投资、谁的收益、谁承担风险。

* 我国有单独的《个人独资企业法》和《合伙企业法》分别规范，所以《民法典》对它们事实上只有一个最基础的概念性规定。

| | 个人独资企业 | 合伙企业 |
| :--- | :--- | :--- |
| 谁投资 | 一个自然人 | 各个合伙人，两人以上 |
| 谁的收益 | 该财产为投资人个人所有，收益都是投资人的 | 收益是共同的，共同经营 |
| 谁承担风险 | 投资人以其个人财产对企业债务承担无限责任 | 所有合伙人都要为合伙企业债务承担无限连带责任 |
| 特别之处 | 我国有单独的《个人独资企业法》 | 我国有单独的《合伙企业法》 |

* 债务得让投资人无限负责，就体现了它没有独立承担责任的能力。

### 不具有法人资格的专业服务机构

* 第一个关键词是「不具有法人资格」，即不满足登记为法人的条件；若满足了这些条件，就登记为法人，可以独立承担责任。

* 第二个关键词是「专业」：通过专业知识、专门技能提供专业服务，比如律师事务所、会计师事务所、私人诊所。

### 一个人做生意：三种组织形式的选择

* 实践中选个体工商户的最多，只因税收最优惠，只需缴纳个人所得税；个人独资企业与一人有限责任公司都是企业，先缴企业所得税，个人分到的红利、赚的钱还得再缴一次个人所得税。

| | 个体工商户 | 个人独资企业 | 一人有限责任公司 |
| :--- | :--- | :--- | :--- |
| 性质 | 自然人参与工商业经营的特殊形式 | 非法人组织 | 公司，具有法人资格 |
| 能否独立担责 | 长文未说明 | 不能独立承担责任 | 可以独立承担责任 |
| 讲在哪一侧 | 放在自然人那一章 | 放在非法人组织这一章 | 属于法人那一侧 |
| 税收 | 只需缴纳个人所得税 | 企业所得税，之后红利再缴个人所得税 | 企业所得税，之后红利再缴个人所得税 |

* 全国注册了 1.25 亿家个体工商户。

* 2025 年单选题「下列选项中属于非法人组织的是」，答案只有个人独资企业：居民委员会与农村集体经济组织都属于特别法人即法人的类型；个体工商户是自然人参与工商业经营的特殊形式，落在自然人那一侧。

## 非法人组织的解散

* **章程终止型事由**：章程规定的存续期间届满，或者章程规定的其他终止事由出现，体现的是当事人提前作出的安排。

* **自治型事由**：出资人或者设立人决定解散，同样体现当事人的意思自治，只不过是一个临时的决定。

* **兜底型事由**：法律规定的其他终止情形，例如合伙企业实施违法行为被吊销执照、被责令关闭、被撤销，也会导致解散。

* > **提示**：到期型、自治型、兜底型三者与法人的解散事由几乎是一一对应的。

## 合伙企业的概念与类型判断

* **合伙企业**

    * > **定义**：两个以上的合伙人基于合伙协议，共同出资、共同经营、共享收益、共担风险的营利性组织。

    * 合伙人是广义的：可以是自然人，可以是法人，也可以是非法人组织。

    * 合伙企业是非法人组织三种类型中最重要的那一种，法条把它单独拎出来讲一节。

    * 法考里合伙企业由商经法老师讲，法硕考试中它属于民法的考察范围，所以民法老师还要讲《合伙企业法》这类特别法。

* **原则与例外的判断规则**

    * 普通合伙企业是原则性规定，有限合伙企业是例外情形、特别制度。

    * 题目只告诉你甲乙丙丁一起设立一家合伙企业而没说类型，就按普通合伙企业处理，理由就是它属于原则。

    * 区分两种合伙企业只抓两个关键信息：合伙人由什么样的人组成、这些合伙人如何承担责任。

    * 「出现了承担有限责任的合伙人」这件事本身，就叫有限合伙企业。

| 对比点 | 普通合伙企业 | 有限合伙企业 |
| :--- | :--- | :--- |
| 法律地位 | 原则性规定 | 例外情形、特别制度 |
| 合伙人构成 | 全部都是普通合伙人，性质一样 | 普通合伙人与有限合伙人并存，两种身份 |
| 普通合伙人责任 | 无限连带责任 | 无限连带责任 |
| 有限合伙人责任 | 无此身份 | 只在认缴出资额范围内承担有限责任 |

## 普通合伙企业的设立条件

* **人数**：两个以上的合伙人。这一条正好是和个人独资企业的分界线，只有人愿意干、没人跟你合伙，那就只能去设个人独资企业。

* **合伙人资格**：法人、非法人组织都可以成为合伙人；若合伙人是自然人，则必须具有完全民事行为能力，因为要承担无限连带责任、得从家里拿钱填窟窿，限制民事行为能力人与无民事行为能力人没有资格签订合伙协议。

* **书面合伙协议**：靠协议确定怎么投资、怎么经营、怎么收益、怎么承担风险。

* **出资**：要有合伙人认缴或者实缴的出资，这是合伙企业开展经营活动的物质基础。

* **出资方式不受限制**：货币、实物、知识产权、土地使用权等财产权利都可以，只要值钱就行；还可以用劳务出资，因为合伙人本来就要承担无限连带责任，只要各个合伙人相互认同就可以。

* **名称和生产经营场所**：这是人格基础，合伙企业作为非法人组织也是个民事主体，得有自己的名称才能对外从事民事活动。

* **其他法定条件**：必须办理登记手续、拿到营业执照才能从事经营活动，且登记时必须明确标明「普通合伙」字样，藉此公示以保障交易安全——别人知道这是一家普通合伙企业，才知道每个合伙人都要负责到底。

## 普通合伙企业的责任规则

* 没明确说是特殊的普通合伙企业，就按一般规定处理，仍是原则与例外的关系。

* **对外关系**

    * 先执行合伙企业自己的财产，因为它是一个独立主体。

    * 企业财产执行完毕以后依然清偿不了债务的，每一个普通合伙人都负有承担无限连带责任的义务，债权人可以向其中任意一人主张全部。

    ```text
            合伙企业债务
                 │
                 ▼
       ①  先执行合伙企业自己的财产
                 │   独立主体，先找它
                 │   企业财产执行完毕仍不足清偿
                 ▼
       ②  任一普通合伙人承担无限连带责任
                 │   债权人可以向其中任意一人主张全部
                 ▼
       ③  关起门来算内部账：追偿
                 │
                 ▼
          承担额超出自己应分担比例的，
          可以向其他合伙人追偿
    ```

* **对内关系**

    * 某个合伙人对外把钱都还清了，合伙人之间可以算账；承担的责任超出他应当分担比例的，可以向其他合伙人追偿。

    * 内部应当分担的比例按先后顺序确定：先由当事人约定；没有约定的根据出资额确定；出资额也无法确定的直接等额，大家平均承担。

    * 例：甲乙各占二分之一份额经营餐饮，欠债权人 60 万元且企业已无财产可执行，债权人执行了更有钱的甲的财产拿到 60 万元，债权归于消灭；此时甲乙关起门来内部清算，甲把 60 万都还了，就得向乙追偿 30 万。

* > **提示**：对外债权人可以要求甲乙承担连带责任，对内才轮到甲向乙算账。

## 入伙与退伙

* 入伙退伙的规范虽不在考试大纲内，但真题中出现过，属于超纲考点。

* **入伙**

    * 新的合伙人要加入，原则上应当经过全体合伙人的一致同意，因为全体合伙人要承担连带责任、共担风险，需要较强的互相信任基础。

    * 新入伙的合伙人对于入伙之前的债务也要承担无限连带责任，入伙本身就代表了对之前债务的认可。

* **退伙**

    * 合伙人退伙，对退伙之前产生的债务承担无限连带责任；退伙之后新产生的债务与他无关。

    * 例：甲乙各占一半份额欠债权人 60 万元，丙入伙须经甲乙一致同意并为此前 60 万承担无限连带责任；后甲退伙，仍要为退伙之前产生的 60 万负责，之后新产生的债务由乙、丙承担连带责任。

* > **结论**：入伙人背负「过去」，退伙人只对「过去」负责。

## 特殊的普通合伙企业

* 这是一个专业术语而非简单的描述，实践中有些律师事务所的营业执照上登记的营业性质就叫「特殊的普通合伙企业」。

* **行业上的特殊**：以专业知识和专门技能为客户提供有偿服务的专业服务机构，比如律师事务所、会计师事务所，可以选择登记为特殊的普通合伙企业。

* **责任规则上的特殊**，关键在于看损失后果是因为什么原因造成的：

| 情形 | 责任承担 |
| :--- | :--- |
| 归责于某个合伙人的故意或者重大过失 | 实施该行为的合伙人承担无限连带责任；其他合伙人只在合伙企业的财产份额内承担有限责任 |
| 非因故意、重大过失而造成 | 全体合伙人都承担无限连带责任，与一般普通合伙企业的一般规则一致 |

* 让其他合伙人承担有限责任是现实考虑：所内都是律师、会计师、医师等专业人士，各自做什么业务相互不关注、不了解，最多在年会碰个杯；若某合伙人犯罪或故意造成损害，其他人全担无限连带责任职业风险太大，为了适当降低专业人士的职业风险，他们只需承担有限责任。

* ⚠️ **易错点**：不能绝对地说普通合伙企业的合伙人一定承担无限连带责任，特殊的普通合伙企业里其他合伙人承担的正是有限责任。

* 即便大家都是专业人士，仍要为其他普通合伙人的一般过失负无限连带责任，所以入伙才需要全体合伙人的一致同意——对方水平太差、人品太差时，让他加入是有风险的。

* > **提示**：题目只告诉你甲乙丙丁设立一个普通合伙企业而没说是特殊的，就不考虑这个考点；真要考，案情描述中一定出现「特殊的普通合伙企业」这个词。

* > **提示**：一旦出现「特殊的普通合伙企业」，接下来一定得有个合伙人因故意、重大过失造成合伙企业损失，否则特殊性体现不出来。

## 有限合伙企业的特殊设立条件

* **人数**

    * 两人以上、五十人以下，两个以上是为确保满足合伙企业的最基本要求、区别于个人独资企业。

    * 至少得有一个普通合伙人；如果大家全都只承担有限责任，那还不如直接设公司，与非法人组织、合伙企业的本质背离太远。

    * 50 这个上限是因为有限合伙企业的合伙人组成比较复杂，人数太多则债务清算规则可能过于复杂；至于为什么是 50 而不是 40 或 60，本身没有本质区别，法律选定了就按 50 操作。

* **普通合伙人的负面清单**

    * 国有独资公司、国有企业不能做普通合伙人，因为可能造成国有资产流失，给当事人操作、转移国有资产提供方便。

    * 上市公司不能做普通合伙人，因为其债务风险太大，会严重影响小股东的合法权益，债务越多股价越无保障、股权更不值钱。

    * 公益单位不能做普通合伙人，因为承担无限连带责任会严重影响公益事业的发展。

    * 法律没有限制的就是允许的，个人独资企业不属于被禁止的范畴，可以成为普通合伙人。

* **出资方式**

    * 有限合伙人只能用可作价的财产出资，包括货币、实物、知识产权等其他财产权利，不能以劳务出资。

    * 原因是有限合伙人承担有限责任，出资必须能够变现，劳务无法拍卖变卖，这跟普通合伙人可以用劳务出资是最大的一个区别。

* **名称**

    * 名称中应当标明「有限合伙」字样，营业执照上也必须载明，同样是通过公示保障相对方的知情权。

## 有限合伙人的行为限制与对外责任

* **有限合伙人不能代表合伙企业**：只承担有限责任，没有和合伙企业共进退，只出资、等着分红，不得执行合伙事务，不得对外代表合伙企业从事活动。

* 禁止的原因是：若代表企业对外经营，产生的债务他只担有限责任，却让其他合伙人承担无限责任，等于别人的命运掌握在你手里。

* **经授权对外代表时的例外**

    * > **结论**：假如第三人有理由相信有限合伙人是普通合伙人，而与其进行交易的，该有限合伙人对该笔债务承担无限连带责任。

    * 有限合伙人本来就没有资格代表企业来谈，合伙企业一旦授权他对外签约，相对方就会产生合理信赖——你竟敢代表企业来谈，就有理由相信你是普通合伙人、要负责到底；只有这样才能保护相对方的信赖利益。

    ```text
          有限合伙人（只出资、只分红）
            不执行合伙事务、不对外代表企业
                      │
                      │  经合伙企业授权对外签约
                      ▼
         第三人产生合理信赖：
         "你敢代表企业来谈，你就是普通合伙人"
                      │
                      ▼
             就"这一笔债务"承担无限连带责任
                      │
                      ▼
             其他债务 —— 依然以认缴出资额为限
    ```

    * ⚠️ **易错点**：上述规则的前提是有限合伙人对外代表合伙企业经过合伙企业授权；若是擅自以合伙企业名义对外签订合同，构成无权代理，法律后果完全不同。

    * 无限连带责任只限「这一笔债务」，其他债务依然以认缴出资额为限。

## 两个需要否定的绝对化判断

* 普通合伙企业中合伙人一定承担无限连带责任——错的，特殊的普通合伙企业中若某合伙人因故意、重大过失造成损失，其他合伙人承担的是有限责任。

* 有限合伙企业中有限合伙人承担的一定是有限责任——也是错的，经授权对外代表企业、第三人产生合理信赖时，就那一笔债务他也要承担无限连带责任。

* 这两条一正一反、位置刚好对称：普通合伙企业不是铁板一块的无限连带，有限合伙企业的有限责任也不是铁板一块的有限责任。
