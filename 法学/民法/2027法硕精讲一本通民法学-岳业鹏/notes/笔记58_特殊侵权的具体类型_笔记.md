# 特殊侵权的具体类型

## 特殊侵权的识别框架

### 通用侵权公式的偏离

   * **通用侵权公式**

       * > **定义**：行为人有错、行为与损害有因果，于是行为人赔偿。

   * **特殊侵权的规则变动**

       * 《民法典》设专章规定的特殊侵权，规则原则都特别，不能把通用侵权的框架直接往上套。

       * 偏离方式一：把"过错"这一环砍掉，改为无过错责任或过错推定。

       * 偏离方式二：把责任主体从"实施行为的人"挪到"控制风险的人"身上。

       * 偏离方式三：让一个没有动手的人替动手的人掏钱。

       * 每种类型只需重新确认两件事：规则原则怎么定，责任主体是谁。

### 保有人责任

   * **保有人责任（liability of the possessor）**

       * > **定义**：谁控制这个物的风险，由谁承担因此产生的赔偿责任。

       * 凡是和物相关产生的侵权责任，基本上都采取保有人责任。

       * 机动车交通事故责任按保有人责任确定责任主体。

       * 高度危险物品致人损害适用保有人责任。

       * 饲养动物、建筑脱落坠落、物件致人损害都以保有人责任为主线。

### 七种类型的基本定位

| 侵权类型 | 规则原则 | 责任主体的特别之处 |
| :--- | :--- | :--- |
| 产品责任 | 无过错责任，只查客观要件 | 生产者与销售者连带，另有最终责任人 |
| 机动车交通事故责任 | 过错责任、不超过 10% 的无过错责任、受害人故意则免责三层 | 先保险、后侵权人；沿保有人规则定主体 |
| 医疗损害责任 | 过错责任，四要件齐备 | 医务人员个人不赔，由医疗机构替代承担 |
| 环境污染和生态破坏责任 | 无过错责任，三要件，因果关系举证责任倒置 | 污染者对外连带，对内按有无第三人过错定最终责任人 |
| 高度危险责任 | 无过错责任，对合法行为也担责 | 高度危险物走保有人责任，所有人有过错则连带 |
| 饲养动物损害责任 | 一般无过错，动物园过错推定，禁止饲养的危险动物绝对责任 | 饲养人或管理人；遗弃逃逸由原饲养人、管理人担责 |
| 建筑和物件损害责任 | 原则上过错推定，公共道路上堆放物品的行为人无过错 | 保有人；建筑倒塌按原因定，质量缺陷时建设与施工单位连带 |
| 高空抛物 | 查不明侵权人时由可能的加害人适当补偿 | 四类主体各负其责，查不明时建筑管理人成为主力 |

## 产品责任

### 对外连带与对内最终责任人

   * **产品责任（product liability）**

       * > **定义**：因产品存在缺陷造成的损害应当承担的侵权责任。

       * 立法理由：有缺陷的产品一旦进入流通领域就会给社会带来某种危险，危险既然被放出来，就得有人承担更重的责任。

   * **对外层**

       * 适用无过错责任规则，只查客观要件。

       * 承担主体只有两个：产品的生产者、产品的销售者。

       * 即使他们没有过错也应当赔偿。

       * 二者对外是连带关系：被侵权人可以起诉生产者，可以起诉销售者，也可以一并起诉。

   * **对内层的三条追偿规则**

       * 缺陷系生产者造成的：生产者承担最终责任，适用无过错责任；销售者对外赔后可向生产者全部追偿。

       * 缺陷系销售者的过错造成的：销售者承担最终责任，适用过错责任；生产者对外赔偿后可向该有过错的销售者全部追偿。

       * 缺陷系运输者、仓储者等第三人的过错造成的：第三人承担最终责任，适用过错责任；生产者或销售者对外赔偿后可向该第三人全部追偿。

   * **不真正连带责任**

       * 对外连带，对内有终局的责任人兜底，不存在对外责任人与内部责任人的分担。

       * 第三人即使有过错也不需要对外承担责任，第三人只承担内部的最终责任。

       * 被侵权人不能直接向运输者、仓储者等第三人主张赔偿。

```text
   被侵权人（花 100 元买电热壶，漏电灼伤手臂）
          │
          │  对外——无过错责任，生产者与销售者连带
          ▼
   生产者 乙厂 ──────┐
                     ├── 可起诉生产者，也可起诉销售者，也可一并起诉
   销售者 甲商场 ────┘
          │
          │  对外赔完之后，关起门来找最终责任人
          ▼
   缺陷系生产者造成 → 生产者最终担责（无过错责任）
   缺陷系销售者过错造成 → 销售者最终担责（过错责任）
   缺陷系运输者、仓储者等第三人过错造成 → 第三人最终担责（过错责任）
```

### 构成要件与产品缺陷

   * **客观三要件**

       * 加害行为、损害后果、因果关系，不需要考虑主观过错。

       * 加害行为在产品责任中被具体化为"产品要有缺陷"。

       * 损害后果是他人的人身、财产遭受损害。

       * 因果关系要求缺陷产品与损害之间有因果链条。

   * **产品缺陷（product defect）**

       * > **定义**：产品的存在危及人身、财产安全的不合理的危险，体现为一种"危险"，而不是一种"故障"。

       * 兜底判断标准：产品有保障人体健康和人身财产安全的国家、行业标准的，不符合该标准即为有缺陷的产品。

       * 电热壶按道理不应漏电，漏电即是不合理的危险；零食食用后中毒即说明食品有缺陷。

### 承担方式

   * **赔偿损失**

       * 缺陷产品造成的损害当然要赔。

       * 缺陷产品本身的损害也可以纳入赔偿范围。

       * 例：手机在正常充电时因电池缺陷爆炸，旁边电脑的损害与这部手机本身的毁损都可以主张。

   * **停止侵害、排除妨碍、消除危险**

       * 这三项是一般侵权就有的常规责任方式。

   * **警示、召回等补救措施**

       * > **定义**：产品投入流通以后发现存在缺陷的，生产者、销售者应当及时采取停止销售、警示、召回等补救措施，防止损害的发生。

       * 没有及时采取补救措施或者采取措施不力造成损失扩大的，对扩大部分也要承担赔偿责任。

       * 采取相应措施产生的费用由生产者、销售者承担。

   * **惩罚性赔偿**

       * 条件一：主观上存在故意——明知产品缺陷，或者没有采取停止销售、警示、召回等补救措施而放任损失扩大。

       * 条件二：造成他人死亡或者健康严重受损的后果。

       * 两个条件同时满足才可以主张，缺一不可。

       * 例：汽车制造商发现已投入流通的某款车刹车系统存在缺陷，通过媒体发布召回通知，购车人看到通知后驱车途中因刹车缺陷撞树重伤的，不能主张惩罚性赔偿，因为该制造商及时召回、不存在恶意。

## 机动车交通事故责任

### 三层规则原则

   * **规则来源**

       * 这一类型的规则原则没有规定在民法典里，而是规定在《道路交通安全法》第 76 条。

   * **第一层：过错责任**

       * 主要适用于机动车之间发生事故的情形，谁有过错谁承担责任。

   * **第二层：不超过 10% 的无过错责任**

       * 主要适用于机动车和行人、非机动车发生交通事故的情形。

       * 即使机动车一方没有过错，也要承担不超过 10% 的责任。

       * 理由：机动车一方避免风险的能力更强，相对处于比较优势地位——你是铁的，人家是肉的。

       * 这一层主要由保险来承担，目的是方便社会人的损害救济。

       * 这不是当然承担 10%，承担 2%、承担 3% 都叫"不超过 10%"；题干出现"机动车一方承担 10% 的责任"这类绝对表述要警惕。

   * **第三层：免责情形**

       * 事故是因受害人故意造成的，机动车一方可以主张免责，不承担责任。

### 责任主体的承担顺序

   * **先保险、后侵权人**

       * 按交强险、商业三者险、侵权人本人的顺序依次承担。

       * 交强险是强制购买的保险，承担责任时冲到第一线。

       * 商业三者险按保险合同约定赔偿，前提是侵权人投了这个险种。

       * 只要保单额度够用，实际上轮不到侵权人自己掏钱；即便他是全责方也不必自己承担责任。

   * **交强险与商业三者险**

       * 交强险本身也是一种第三者责任保险，与商业三者险都以驾车人对交通事故受害人应当承担的赔偿责任作为标的。

       * 区别是交强险必须购买，商业三者险按自愿购买。

       * "第三者"指被保险车辆发生事故遭受损失的人，保障的是他的请求权。

       * 不包括被保险人和保险车辆的车上人员：车主与驾车人是第一者，被保险车辆是第二者。

   * **交强险赔偿限额**

| 交强险赔偿限额 | 金额 |
| :--- | :--- |
| 死亡伤残 | 18 万元 |
| 医疗费用 | 1.8 万元 |
| 财产损失 | 0.2 万元（2000 元） |
| 合计 | 20 万元 |

       * 交强险的限额由法律直接规定，总共 20 万，并且有分项限制。

       * 总额不超过 20 万的同时，每一项也不得超过 18 万、1.8 万和 0.2 万，超出的部分交强险可以不赔。

       * 商业险的赔偿限额由当事人在合同中约定，可以投保 100 万、200 万、300 万，不同的赔偿数额对应的保费也不一样。

```text
   乙开车撞伤甲，乙负全责，甲是受害人
          │
          ▼
   ① 交强险保险公司 —— 强制大家买的保险，承担责任时要冲到第一线
          │  赔偿不足
          ▼
   ② 商业三者险保险公司 —— 按保险合同约定赔偿，前提是乙投了这个险种
          │  赔偿仍不足
          ▼
   ③ 侵权人乙自己赔 —— 但只要保单额度够用，实际上轮不到他自己掏钱
```

### 所有人与使用人不是同一人的责任分配

| 情形 | 承担赔偿责任的主体 | 所有人（车主）的责任 |
| :--- | :--- | :--- |
| 经允许驾驶他人机动车 | 使用人 | 对损害发生有过错的，承担相应责任 |
| 未经允许擅自驾驶他人机动车 | 擅自驾驶人 | 有过错的，同样承担相应责任 |
| 盗抢人驾车肇事后 | 盗抢人（实际使用人） | 通常不认为车主有过错 |
| 盗抢人与使用人不是同一人 | 使用人与盗抢人承担连带责任 | 车主不担 |
| 车辆已交付但未办理所有权转移登记 | 受让人 | 登记人不承担责任 |
| 转让拼装、报废机动车 | 所有参与交易的人承担连带责任 | 即使不知情也要连带 |
| 挂靠 | 挂靠人与被挂靠人承担连带责任 | 被挂靠人收取挂靠费，属违法行为 |

   * **车主过错的表现**

       * 知道或应当知道机动车存在缺陷，而且该缺陷是发生事故的原因之一。

       * 知道或应当知道驾驶人欠缺相应驾驶资质。

       * 知道或应当知道对方饮酒，或者注射麻醉药品等。

       * 其他应当认定为过错的情形。

   * **经允许驾驶他人机动车**

       * 车辆由使用人控制，使用人就是保有人，由使用人承担赔偿责任。

       * 所有人对损害的发生有过错的，承担相应责任。

       * 例：甲乙相约聚餐，饭后甲犹豫再三仍把车借给饮酒的乙，乙驾车撞伤行人丙；由乙承担，甲明知乙饮酒仍出借，对事故发生有过错，也要承担相应责任。

   * **未经允许擅自驾驶他人机动车**

       * 擅自驾驶人上车即成为保有人，由擅自驾驶人承担赔偿责任。

       * 所有人有过错的，也要承担相应的赔偿责任。

   * **盗抢机动车发生交通事故**

       * 由盗窃人承担赔偿责任，车主通常不认为有过错。

       * 盗窃人与使用人不是同一人的，由使用人与盗抢人承担连带责任。

       * 车辆已投保的，交强险保险公司在责任限额内垫付抢救费用的，可以向责任主体追偿，因为垫付是为了保障受害人的救济权益。

       * 例：车主丙的车被丁盗走、丁又把车借给乙驾驶，货车乙负全责撞伤甲的，由丁与乙承担连带责任，车主丙不能被请求赔偿；该车未投保的，保险公司没有垫付抢救费用的义务。

   * **已交付但未办理所有权转移登记**

       * 机动车作为特殊动产，交付发生物权变动，未登记不得对抗善意第三人，甲乙之间受让人已取得所有权。

       * 受让人同时是真正的保有人，由受让人承担赔偿责任；登记人没有责任。

   * **转让拼装、报废机动车**

       * 报废、拼装机动车禁止上路行驶，由所有参与交易的人承担连带责任。

       * 即使某个转让受害人不知道、也不应当知道该车是拼装或报废机动车，也得承担责任，目的是保障受害人的损害救济。

       * 例：甲把已达报废标准的车卖给乙，乙担心安全性能又原价卖给不知情的丙，丙驾车上路撞伤丁的，甲、乙、丙承担连带责任。

   * **挂靠机动车**

       * 挂靠人因是机动车保有人而承担责任。

       * 被挂靠人允许他人挂靠并收取挂靠费属违法行为，与挂靠人承担连带责任。

### 逃逸与保险缺位

   * **机动车驾驶人逃逸**

       * 仍可请求交强险保险公司赔偿：在撞击发生的那一刻保险公司的责任已经产生，不因后来逃逸而故意消灭；交强险制度的目的正是保障受害人的赔偿请求权。

       * 机动车不明或者没有投保交强险的，支付受害人的人身伤亡抢救、丧葬等费用，由道路交通事故社会救助基金垫付。

       * 救助基金垫付以后可以向责任人追偿。

   * **没有投保交强险**

       * 未投保的，保险公司不承担赔偿责任。

       * 投保义务人与事故责任人不是同一人时，投保义务人应在交强险的赔偿限额内承担相应的责任。

       * 理由：应当投保而未投保属违法行为，使受害人的赔偿面临风险，投保义务人就在限额内"做保险公司"。

   * **"相应的责任"的四项内容**

       * 全部责任主体是乙，承担全部责任。

       * 部分责任主体是甲，只在交强险责任限额内承担相应责任。

       * 丙从甲、乙手里面拿到的赔偿金总额不得超过他的实际损失。

       * 部分责任主体甲先行赔付的费用超过其应担部分的，超出部分可以向全部责任主体乙追偿。

### 车上人员与好意同乘

   * **机动车车上人员损害**

       * 交强险与商业三者险都是三者险，车主与驾车人是第一者，不受保障。

       * 例：车主驾车时未拉手刹，车把车主自己撞伤，不能请求交强险与商业三者险赔偿。

       * 投保了车上人员责任保险的，可以基于保险合同请求赔偿；驾乘险、座位险保的就是车内人员损害赔偿请求权。

   * **好意同乘（good Samaritan ride）**

       * > **定义**：非运营机动车发生交通事故，然后造成无偿搭乘人损害的情形。

       * 搭乘人属于车上人员、是第二者的范围，不能请求交强险或商业三者险赔偿。

       * 未投保车上人员责任保险的，损失由车主亲自赔偿，但承担责任时应当减轻其赔偿责任。

       * 例：下班顺路搭载同事的车辆发生事故致同事当场死亡，法院认定车主承担 70% 的赔偿责任、减免 30%，仍需赔偿 90 万元。

       * 但书：机动车使用人有故意或者重大过失的，不能主张减轻。

       * 例：驾驶人喝了酒仍让同事搭车顺路回家而发生交通事故的，不能主张减轻。

## 医疗损害责任

### 规则原则与责任主体

   * **医疗损害责任（medical damage liability）**

       * > **定义**：医疗机构以及医务人员因过错导致患者在诊疗活动中受到损害的，要由医疗机构承担赔偿责任。

       * 原则上适用过错责任，以医疗机构或者医务人员有过错作为前提。

       * 适用替代责任的规则：医务人员执行医疗机构的工作任务，最终由医疗机构承担赔偿责任。

   * **"飞刀"的规范拓展**

       * 医疗机构邀请本单位以外的医务人员对患者进行诊疗，因受邀医务人员的过错导致患者损害的，由邀请医疗机构承担赔偿责任。

       * 医务人员既包括和医院有人事关系的医务人员，也包括临时请来的医务人员。

       * 例：S 市人民医院邀请北京某知名专家刘主任做白内障手术，刘主任手术失误致张某失明，向 S 市人民医院主张赔偿。

### 构成要件

   * **完整的四要件**

       * 加害行为：医疗机构及医务人员实施了具有违法性的医疗行为，误诊、不当手术、延误治疗等都属于违法性的医疗行为。

       * 损害事实：患者要遭受非正常的损害。

       * 属于诊疗活动正常创伤范围的不赔：阑尾炎手术要把肚子切开、术后需住院休养属正常创伤；手术中把肾脏切除才属非正常损害。

       * 因果关系：要求患者的损害与医疗行为之间存在因果关系。

       * 主观过错：包括三个层次，见下条。

### 过错的认定

   * **医疗技术层面的过失**

       * 医疗机构及其医务人员没有尽到与当时的医疗水平相应的诊疗义务。

       * 按当时的医疗水平，该级别的医生应当预见到这个后果而没有尽到注意义务，即属过失。

   * **程序层面的过失**

       * 没有尽到告知同意义务，如患者或者家属没有签字就把手术做了。

       * 手术成功不代表人就免责，程序上依然有过失。

   * **推定过失的三种情形**

       * 违反法律、行政法规、规章以及其他有关诊疗规范的规定。

       * 例：注射青霉素按规定应做皮试而未做，致患者严重过敏反应；输液未核对姓名把甲的药输到乙的身体里。

       * 隐匿或者拒绝提供与纠纷相关的病历资料。

       * 遗失、伪造、篡改或者违法销毁病历资料。

       * 三条的共同点是都跟白纸黑字的文件相关。

### 免责事由

   * **三项免责事由**

       * 患者或者近亲属不配合医疗机构进行符合诊疗规范的诊疗。

       * 例：需要做手术而患者或者近亲属不签字，医疗机构不承担责任。

       * 医务人员在抢救生命垂危的患者等紧急情况下，已经尽到合理诊疗义务。

       * 限于当时的医疗水平难以诊疗。

   * **不配合规则的例外**

       * 因抢救生命垂危的患者等紧急情况不能取得患者或者近亲属意见的，经相关负责人批准，可以立即采取相应的医疗措施。

       * 例：交通事故伤者送医时已昏迷且找不到近亲属的，可以直接先抢救病人。

### 医疗产品责任

   * **医疗产品（medical product）**

       * > **定义**：医疗产品存在缺陷造成患者损害的责任；医疗产品包括药品、消毒产品、医疗器械，还包括血液。

       * 承担责任的规则结合产品责任理解，同样区分对外和对内两个层次。

   * **对外的四类主体**

       * 药品的上市许可持有人。

       * 生产者。

       * 血液的提供者，如血站。

       * 医疗机构，与前三者一起对外承担连带责任。

       * 医疗机构进入责任主体的原因是长期以来的以药养医体制：它把医疗产品加价卖给患者、通过销售利润弥补医疗事业经费不足，实质扮演销售者。

   * **对内追偿**

       * 医疗机构赔偿后可以向上市许可持有人、生产者或者血液提供者追偿。

       * 让医疗机构对外担责，主要是为了方便患者的损害救济——先让患者拿到钱，再去找最终责任人。

```text
   患者（输血感染丙肝的张某）
          │
          ▼
   药品上市许可持有人 ──┐
   生产者 ───────────────┤
   血液提供者（如血站）──┼── 对外连带，患者可选其一，也可一并请求
   医疗机构 ─────────────┘
          │
          │  医疗机构对外赔完之后，对内追偿
          ▼
   向上市许可持有人 / 生产者 / 血液提供者 追偿
```

   * **齐二案**

       * 广东中山三院先后出现多例急性肾衰竭患者，均使用齐齐哈尔第二制药厂生产的亮菌甲素注射剂；中山三院上报卫生部后该药被全国紧急停用，此时已有 14 人死亡。

       * 法院判决中山三院与齐二药厂承担连带责任，理由是中山三院把药品加价卖给患者，实质是该药品的销售者。

       * 中山三院赔偿以后可以向齐二药厂追偿。

       * 正是基于这起案件，我国才在侵权责任法中确立医疗产品责任的相关规则，该规则后来被民法典完全继承。

## 环境污染与生态破坏责任

### 无过错责任与三要件

   * **环境侵权（environmental infringement）**

       * > **定义**：污染环境、破坏生态造成他人损害的责任，适用无过错责任原则——不管污染者有没有过错，都要承担责任。

       * 无过错责任意味着只用三要件：加害行为要件、损害后果要件、因果关系要件。

   * **加害行为**

       * 要有污染环境、破坏生态的行为。

       * 即使排污行为是经过许可的、符合相关标准的，也要承担无过错责任。

       * 理由：污染行为给社会带来某种危险，而排污者从这个排污行为中获得了利益。

   * **损害后果**

       * 包括人身损害，也包括财产损害。

   * **因果关系**

       * 采取举证责任倒置的方式认定。

       * 不是由原告提供"因果关系成立"的证据，而是由加害方提供"因果关系不能成立"的证据。

   * **抗辩示例**

       * 甲公司投产以后对周边地区陆续造成污染、排放各种污染物导致村民损失，辩称排污符合相关标准且原告未提供损害由其排污导致的证据，该抗辩不能成立。

```text
              环境污染和生态破坏责任
                        │
          ┌─────────────┼─────────────┐
          ▼             ▼             ▼
       加害行为       损害后果       因果关系
   污染环境、破坏    人身损害、      举证责任倒置
     生态（即使经     财产损害           │
    过许可、合标）         │             │
          └─────────────┴─────────────┘
                        ▼
             符合客观要件即成立责任
```

### 多污染者的责任分担

| 因果关系类型 | 含义 | 责任形态 |
| :--- | :--- | :--- |
| 累积的因果关系 | 每个排污者的行为都足以造成全部损害 | 连带责任 |
| 共同的因果关系 | 每个污染者的行为都不足以造成全部损害，而是结合在一起共同造成一个损害后果 | 按份责任 |

   * **分担的基本取向**

       * 按份责任为原则，连带责任为例外。

       * 案情没有出现"每个污染者的行为都足以造成全部损害"的，就按共同因果关系对待。

       * 三个排污者排放的污水均经过处理、符合国家排放标准，不影响按份责任的适用。

       * 符合标准从来不是环境侵权的免责事由。

   * **内部份额的确定因素**

       * 污染物的种类、浓度、排放量。

       * 破坏生态的方式、范围、程度。

       * 行为对损害后果所起的作用。

   * **分担示例**

       * 甲乙丙三家公司生产场地排污口相连，当地大旱导致水位大幅下降，三家污水共同造成下游丁养殖场鱼类大量死亡。

       * 题干没有称每家污水都足以造成损害，顺应共同因果关系，甲乙丙承担按份责任。

### 污染物相互作用与连带责任

   * **司法解释的新规定**

       * 两个以上的侵权人分别排放的物质相互作用，产生污染物，造成他人损害的，被侵权人请求侵权人承担连带责任的，人民法院应予支持。

       * 法律依据是共同侵权行为：多个排污者构成共同侵权行为的，承担连带责任。

   * **共同的过失**

       * 民法所称无过错责任不是"没有过错才承担责任"，而是"不管当时有没有过错都得承担责任"。

       * 分别排污且违反规定意味着各自有过错，双方的过失形成不可分割的有机整体，个别的过失转化为共同的过失。

       * 例：甲排放 2800 多吨含硫化钠等金属硫化物的废碱液，乙排放 30 余吨废盐酸，两者均未处理、未使用专用管道而直接排入城市下水管道。

       * 例中的化学过程：Na₂S + 2HCl → H₂S↑ + 2NaCl，硫化氢经下水管网挥发到地面，李某经过此地死亡。

       * 双方并无合谋与共同故意，但各有重大过失，合并为不可分割的有机整体，符合共同侵权构成要件，甲乙承担连带责任。

       * 这起案件催生了生态环境侵权司法解释第九条的规定。

```text
   甲：废碱液 2800 多吨                  乙：废盐酸 30 余吨
   （含硫化钠等金属硫化物）              （未处理、无专用管道）
              │                                     │
              └──────────► 城市下水管道 ◄──────────┘
                                  │
                   Na₂S + 2HCl → H₂S↑ + 2NaCl
                                  │
                    硫化氢经下水管网挥发到地面
                                  │
                          李某经过此地 → 死亡
                                  │
            双方并无合谋、不存在共同故意，但各有重大过失
                    ↓
        双方过失结合成一个不可分割的有机整体
                    ↓
        个别过失 → 共同的过失 → 符合共同侵权构成要件
                    ↓
                甲、乙承担连带责任
```

### 第三人过错的不真正连带责任

   * **对外层**

       * 被侵权人可以找第三人承担责任，因为第三人是有过错的。

       * 也可以请求污染者承担责任，因为污染者承担的是无过错责任。

       * 对外是连带关系。

   * **对内层**

       * 污染者承担责任以后可以向第三人追偿，第三人是造成损害发生的真正原因。

       * 整体上是不真正连带责任：对外连带，对内有最终的责任人。

   * **示例**

       * 甲公司施工时不慎挖断乙公司的输油管道导致燃油泄漏，丙的庄稼大量死亡。

       * 甲公司存在过错而乙公司是污染物排放者，丙对外可以找甲也可以找乙，属连带；乙公司赔偿以后可以向有过错的第三人甲公司追偿。

```text
        对外（受害人视角）：连带，被侵权人可择一或一并请求
   ┌──────────────┬────────────────┬──────────────┐
   ▼              ▼                ▼              │
 第三人        污染者（无过错）   被侵权人          │
（有错）           │                                │
   └──────┬───────┘                                │
          ▼                                        │
        对内（关起门来）：最终责任在第三人            │
   污染者赔偿后 ──► 向第三人追偿 ◄────────────────┘
```

### 责任形式与可承担的内容

   * **三种责任形式**

       * 损害赔偿。

       * 惩罚性赔偿：排污者有故意、违反法律规定的排污，并造成严重后果时适用。

       * 生态环境的修复责任，是恢复原状在环境侵权领域的体现。

       * 生态环境能够修复的，有关机关或者组织可以请求侵权人在合理期限内承担修复责任。

       * 侵权人没有修复的，有关机关或者组织可以自行或委托他人进行修复，所需费用由侵权人承担，属于替代履行。

   * **损失与费用的区分**

       * > **定义**：损失是负资源的不利，是虽然不愿意但仍然遭受的不利后果；费用是主动的支出，是自己主动花的钱。

       * 五项可由侵权人承担的内容既包括损失也包括费用，二者性质不同。

   * **损失对应前两项**

       * 生态环境能够修复的，赔偿生态环境受到损害到修复完成期间功能丧失的损失。

       * 造成永久性损害、不能修复的，赔偿永久性的损失。

   * **费用对应后三项**

       * 生态环境损害调查鉴定评估的费用，是修复前的前期支出。

       * 清除污染、修复生态环境的费用，是开始干活的中期支出。

       * 为防止损害的发生和扩大所支出的其他合理费用，是后期支出。

```text
                        五项可由侵权人承担的内容
        ┌───────────────────────────┴───────────────────────────┐
        ▼                                                       ▼
   损失（被迫承受的不利）                              费用（主动花出去的钱）
        │                                                       │
   ┌────┴────┐                                        ┌─────────┼─────────┐
   ▼         ▼                                        ▼         ▼         ▼
能修复   不能修复                              调查鉴定评估  清除污染、   防止损害发生
功能丧失  永久性                               的费用       修复生态的    和扩大所支出
的损失    损失                                   （前期）    费用（中期）   的其他合理
                                                                             费用（后期）
```

## 高度危险责任

### 类型与四个特征

   * **高度危险责任（liability for ultra-hazardous activities）**

       * > **定义**：包括从事高度危险作业造成的损害与保有高度危险物造成的损害两种类型。

   * **四个特征**

       * 危险责任：高度危险作业与高度危险物都有可能给社会带来某种危险。

       * 对合法行为承担责任：即使行为是合法的也得承担责任。

       * 无过错责任规则原则：既然带来某种危险就要承担更重的责任，即使没有过错、行为合法也要担责。

       * 自己责任：为自己的行为承担责任。

       * 口诀是"自己合法无危险"。

### 高度危险作业

| 作业类型 | 责任主体 | 免责事由 | 减轻责任事由 |
| :--- | :--- | :--- | :--- |
| 民用核设施致人损害 | 民用核设施的营运单位 | 战争、受害人故意 | — |
| 民用航空器致人损害 | 经营者 | 仅受害人故意 | — |
| 高空、高压等高度危险作业致人损害 | 经营者 | 受害人故意、不可抗力 | 被侵权人重大过失 |

   * **责任主体的确定**

       * 三种类型都是"谁控制风险谁担责"，都是无过错责任，区别只在抗辩事由的宽窄。

       * 营运单位与经营者之所以成为主体，是因为他们在控制这个风险。

   * **免责事由的宽窄**

       * 民用核设施：战争加受害人故意两项。

       * 民用航空器：只有受害人故意一项。

       * 高空高压等高度危险作业：受害人故意加不可抗力两项。

       * 不可抗力的待遇并不一致：民用核设施与民用航空器的免责事由里没有不可抗力，只有高空高压等高度危险作业把不可抗力列为免责事由。

       * "被侵权人重大过失可以减轻责任"只出现在高空高压等高度危险作业这一类型。

### 高度危险物

| 情形 | 责任主体 | 免责事由 | 减轻 / 连带规则 |
| :--- | :--- | :--- | :--- |
| 占有或者使用高度危险物致人损害 | 占有人、使用人（即保有人） | 受害人故意、不可抗力 | 被侵权人重大过失可以减轻责任 |
| 抛弃高度危险物致人损害 | 所有人；交给别人管理的，由管理人 | — | 所有人有过错的，与管理人承担连带责任 |
| 非法占有高度危险物致人损害 | 非法占有人 | — | 所有人、管理人不能证明已尽到高度注意义务且有过错的，承担连带责任 |
| 未经许可进入高度危险区域致人损害 | 管理人 | — | 能证明已采取足够安全措施并尽到充分警示义务的，可以减轻或不承担责任 |

   * **保有人担责的展开**

       * 原则上由保有人承担责任，谁控制物谁承担责任。

       * 保有人与所有人不是同一人的，看所有人有没有过错；有过错的就与保有人承担连带责任。

       * 抛弃场合所有人自己就是保有人。

       * 非法占有时保有人换成非法占有人。

       * 未经许可进入危险区域时根本不是物致害，主体直接落到管理人身上。

       * 例：甲公司委托乙公司运输氯气，装运时甲未按规定使用专用容器，运输途中一罐氯气滚落马路、乙公司司机曾某未察觉泄漏致数人中毒；乙公司是保持有人要担责，甲公司是所有人且有过错，两者承担连带责任。

## 饲养动物损害责任

### 规则原则与管理职责

   * **饲养动物损害责任（liability for damage caused by domesticated animals）**

       * > **定义**：饲养的动物造成他人损害的侵权责任，原则上适用无过错责任，因为饲养的动物会给社会带来某种危险。

       * 例外可以适用过错推定的责任，主要是动物园的动物造成他人损害，动物园能够证明自己没有过错的有一个免责机会。

   * **动物园的管理职责**

       * 事前：告知相关风险。

       * 事中：发生动物伤人事件后及时采取相关措施防止损失扩大。

       * 事后：提供相应的救济措施。

       * 事前、事中、事后全过程都要做到足够好，才能说尽到管理职责、能够主张免责。

   * **赠马例证**

       * 赵某将一匹易受惊吓的马赠给李某但未告知此马习性，李某用该马拉货时雷雨大作、马受惊狂奔撞伤行人王某。

       * 这是典型的饲养动物造成的损害，由饲养人、管理人承担无过错责任；李某作为饲养人、管理人，即使不知道马的习性也要负责。

### 六种具体类型

| 类型 | 责任主体 | 规则原则 | 抗辩事由 |
| :--- | :--- | :--- | :--- |
| 一般饲养动物 | 饲养人或者管理人 | 无过错责任 | 被侵权人故意则不承担；重大过失则减轻 |
| 第三人过错致动物侵权 | 饲养人、管理人 + 第三人 | 不真正连带责任 | 对外连带，对内第三人最终担责 |
| 动物园饲养的动物 | 动物园 | 过错推定 | 证明尽到管理职责则不承担 |
| 违反管理规定的动物 | 饲养人、管理人 | 无过错责任，且罪加一等 | 只能主张减轻，不能主张免除 |
| 禁止饲养的危险动物 | 饲养人、管理人 | 绝对责任 | 既不能减轻，也不能免除 |
| 遗弃、逃逸动物 | 原来的饲养人、管理人 | 无过错责任 | — |

   * **一般饲养动物**

       * 也是保有人责任：谁控制这个动物的风险谁承担无过错责任，体现为动物的饲养人或者管理人。

       * 偶然喂养流浪猫、流浪狗不足以形成管控的，不是法律上的保有人，不需要承担责任。

       * 能证明损害是被侵权人故意造成的不承担责任；能证明对方有重大过失的可以减轻责任。

       * 例：8 岁女孩甲与 12 岁男孩乙明知回家途中丙家买了狗仍不绕道而被狗咬，不能因此认定其存在故意或重大过失——不能因为别人家有狗就要求他人绕道而行，所以不属于抗辩事由。

   * **第三人过错致动物侵权**

       * 对外连带：有过错的第三人要承担，饲养人、管理人因承担无过错责任也要承担。

       * 对内由有过错的第三人承担最终责任，饲养人、管理人承担责任后可以向第三人追偿。

       * 例：甲途经养狗的丙家时乙故意逗狗，狗被激怒咬伤甲；甲可以请求第三人乙赔偿，也可以请求饲养人丙赔偿，丙赔偿后可向乙追偿。

   * **违反管理规定的动物**

       * 例：小区遛狗未拴绳、未对动物采取安全措施，狗咬人仍需承担赔偿责任。

       * 即使采取了安全措施、狗还是咬人的，也要承担赔偿责任，因为动物侵权适用无过错责任原则。

       * 违反管理规定在先存在明显过错，要限制抗辩事由：即使能证明损害是被侵权人故意造成的，也只能主张减轻而不能主张免除。

   * **禁止饲养的危险动物**

       * 例：禁止饲养的烈性犬等危险动物造成损害的，饲养人、管理人承担绝对责任。

       * 这是民法里面比较少见的绝对责任，没有任何免责事由，既不能减轻也不能免除。

       * 例：甲年底手头拮据混入乙的别墅行窃，翻墙入院后被藏獒咬成重伤，可以请求别墅主人承担赔偿责任，尽管甲存在重大过失。

   * **遗弃、逃逸动物**

       * 由原来的饲养人、管理人承担无过错责任，因为动物不能随便丢弃，仍会给社会带来危险。

       * 例：乙因小狗患皮肤病将其丢弃，后甲在旅游地被该流浪狗咬伤，由乙承担责任；此时虽已不再实际饲养，仍是原来的饲养人、管理人。

## 建筑和物件损害责任

### 基本定位

   * **建筑和物件损害责任**

       * > **定义**：建筑等不动产与一般动产造成他人损害的侵权责任；物件致人损害虽由物造成，但最终要由人承担责任。

       * 物既包括不动产（建筑），也包括动产（一般的物件）。

       * 适用替代责任，由物的保有人对物造成的损害负责。

       * 原则上适用过错推定的规则。

   * **建筑致人损害的两条路径**

       * 建筑等发生倒塌导致损害。

       * 建筑虽没有倒，但建筑及其搁置物、悬挂物发生脱落、坠落造成他人损害。

### 建筑倒塌

| 倒塌原因 | 对外责任主体 | 免责事由 | 对内 |
| :--- | :--- | :--- | :--- |
| 因质量缺陷倒塌 | 建设单位和施工单位承担连带责任 | 能够证明工程质量不存在缺陷的，不承担连带责任 | 对工程存在缺陷有过错的人可追偿 |
| 其他原因 | 所有人、管理人、使用人或第三人 | — | 冤有头债有主，谁的原因导致倒塌谁承担责任 |

   * **质量缺陷倒塌的连带基础**

       * 豆腐渣工程代表建设单位和施工单位联袂向社会提供了有缺陷的工程产品，两者对外连带负责。

       * 连带的前提是工程质量存在缺陷；能够证明工程质量合格、不是豆腐渣工程的，就不承担连带责任。

       * 确有缺陷但系设计单位设计缺陷造成的，建设单位、施工单位不能主张免责——只要是豆腐渣工程就要对外连带。

   * **质量缺陷倒塌的对内追偿**

       * 对工程存在缺陷有过错的人可以追偿，如缺陷由勘察单位的过错或设计单位的设计过错造成。

       * 例：某水电站在试水运行时过水明渠倒塌，造成五人死亡、两人受伤；经查建设时没有地质勘测报告、工程设计存在缺陷、施工又有偷工减料，工程质量存在缺陷，由建设单位和施工单位对外连带，内部可追偿。

   * **其他原因倒塌**

       * 责任人可能是所有人、管理人、使用人，也可能是第三人。

       * 例：疫情期间红星酒店被政府征用为隔离场所，隔离期间酒店倒塌致甲受重伤；经调查建筑本身没有缺陷，是酒店装修时擅自改变承重结构、打掉承重墙导致倒塌，由红星酒店承担赔偿责任。

### 建筑脱落坠落

   * **保有人责任与内部追偿**

       * 适用保有人责任，谁控制物谁承担责任。

       * 对外由保有人承担过错推定责任，保有人包括所有人、管理人或者使用人；能够证明自己没有过错的可以主张免责。

       * 对内有其他责任的，保有人对外赔偿以后可以找其他责任人追偿。

       * 例：大华商场委托飞达广告公司制作并安装广告牌，某日风大广告牌被吹落砸伤过路行人郑某；保有人大华商场承担过错推定责任，赔偿后可向飞达公司追偿。

### 物件致人损害

   * **按空间顺序的三个层次**

       * 空中——林木折断、果实坠落：由林木的所有人、管理人承担过错推定责任。

       * 地面私人空间堆放物品：由保有人即堆放人承担过错推定责任。

       * 地面公共道路上堆放物品：行为人承担无过错责任且无免责事由；公共道路管理人承担过错推定责任。

       * 地下地面施工：由施工人承担过错推定责任。

       * 地下窨井等既有设施：由保有人即管理人承担过错推定责任。

   * **林木折断、果实坠落**

       * 例：张某出差时在街上正常行走，被近 10 米高的大王椰树上掉下的树叶砸伤；该树叶有 2 米长、几十斤重，由林木的管理人即市政林木管理部门承担过错推定责任。

   * **公共道路上堆放物品**

       * 行为人没有免责事由，承担无过错责任，因为公共道路上本来就不允许堆放私人物品，很难证明自己没有过错。

       * 公共道路管理人承担过错推定责任，能够证明已经尽到清理、防护、警示等义务的，可以不承担责任。

   * **地面施工致害**

       * 不能证明已经设置明显标志并采取安全措施的，要承担侵权责任；两个条件缺一不可。

       * 例：乙公司为小区维护地下管线，施工时设置了"前方施工注意安全"的警示牌但未对周边进行必要隔离，丙经过时跌入坑里受伤；只设标志而未采取安全措施的，施工人仍要承担责任。

   * **窨井等既有地下设施致害**

       * 例：四名行人正常经过北方牧场时跌入粪坑，一人获救、三人死亡；当地牧场往往挖有三四个粪坑、深者达三四米且此前发生过同类事故，管理人不能证明尽到管理职责的要承担侵权责任。

   * **总体例外**

       * 物件致人损害全方位涵盖空中、地面、地下，原则上都是保有人承担过错推定责任。

       * 唯一的例外是公共道路上堆放物品的行为人承担无过错责任。

```text
   空中 ──── 林木折断、果实坠落            → 林木的所有人、管理人   过错推定
     │
     ├─ 地面 ── 私人空间堆放物品           → 堆放人（即保有人）      过错推定
     │         公共道路上堆放物品           → 行为人：无过错责任、无免责事由
     │                                        公共道路管理人：过错推定
     │
     └─ 地下 ── 地面施工                   → 施工人：过错推定
               窨井等既有地下设施          → 管理人（即保有人）：过错推定
```

## 高空抛物

### 与共同危险行为的界分

   * **重庆烟灰缸案**

       * 2001 年，郝某在街上与朋友谈事情，楼上突然掉下一个烟灰缸砸中其头部，造成严重损害。

       * 穷尽各种方法都无法找到谁是具体的加害人，损害救济陷入困境。

   * **与共同危险行为的区分**

| 区分点 | 高空抛物 | 共同危险行为 |
| :--- | :--- | :--- |
| 加害人状况 | 无法找到实施加害行为的人 | 确定数人都实施了加害行为 |
| 困境所在 | 不知道是谁干的 | 不知道是谁的行为最终导致后果 |
| 责任形态 | 可能加害人适当补偿 | 投掷者等承担连带责任 |

       * 高空抛物说的是只有一个人扔了烟灰缸，其他人什么都没干，只是不知道是谁扔的。

       * 例：郝某扰邻，每个窗户里都扔下一个烟灰缸，砸中他的那个不知是谁扔的，扔烟灰缸的人都得承担连带责任，这是共同危险行为而非高空抛物。

### 四类主体的义务

   * **公安等机关**

       * 依法及时调查、查清责任人。

       * 理由：救济的最大困境就是找不着加害人，公安等机关的侦查手段更加丰富，该行为还有可能承担行政责任或刑事责任。

   * **找到的侵权人**

       * 由侵权人承担赔偿责任，这就是个一般侵权行为。

   * **可能的加害人**

       * 经调查还是找不到侵权人的，由可能的加害人给予适当的补偿。

       * 是"补偿"而不是"赔偿"，基于公平产生的补偿义务：可能加害人里可能 99% 都是无辜的，但被害人遭受了 100% 的损害。

       * 例外一：能够证明自己不是侵权人的就不用补偿，例如能证明发生损害时全家都在国外旅行。

       * 例外二：已给予补偿后找到真正侵权人的，可以向其追偿，补偿并不是替这个侵权人买单。

   * **物业服务企业等建筑的管理人**

       * 采取必要的安全措施防止上述情形的发生，比如架设防护网。

       * 没有采取安全措施的，要在其过错范围内承担相应的责任。

       * 建筑的管理人承担责任，以其存在过错为前提。

### 管理人责任的顺位

   * **能够确定侵权人**

       * 至少首先由侵权人承担赔偿责任，他排在第一位。

       * 建筑的管理人在过错范围内承担相应的补充责任。

       * 这个顺序要求相当于一个先诉抗辩权：要先执行侵权人的财产，不足部分才有建筑的管理人补充。

   * **难以确定侵权人**

       * 首先由管理人承担责任，因为管理人是有过错的，此时他是主力。

       * 承担不了的部分，由可能的加害人给予适当补偿，可能加害人排到第二个顺位，也享有一个类似于先诉抗辩权的权利。

   * **两条通则**

       * 能确定侵权人时建筑的管理人是替补，无法确定时变成主力。

       * 能确定侵权人的，可能加害人不再承担补偿——补偿是以无法确定侵权人为前提的。

       * 这套救济规则出自民法典第 1254 条。

```text
                    公安等机关：依法及时调查、查清责任人
                                     │
                       ┌─────────────┴─────────────┐
                 能查明责任人                  查不明责任人
                       │                             │
              ① 侵权人（全额赔偿）           ① 建筑管理人（过错范围内）
                       │                             │
              ② 建筑管理人：补充责任          ② 可能加害人：适当补偿
                 （过错范围内，类似先诉抗辩）      （能证明自己不是侵权人的可免）
```

## 真题辨析

   * **送酒致人失明**

       * 题干：甲从超市买两瓶白酒送给朋友乙，乙饮用后双目失明，经鉴定该酒是工业酒精勾兑而成，哪些行为与乙的失明存在相当因果关系。

       * 答案：生产者的勾兑行为与销售者的销售行为。

       * 甲赠送白酒、乙方饮用白酒都欠缺相当因果关系：正常送酒、正常喝两口不会导致双目失明。

   * **借车与酒后驾车**

       * 题干：甲将汽车借给乙使用，某日乙酒后驾车撞伤丙，丙的损害由谁赔偿。

       * 答案：由使用人乙赔偿。

       * 注意时间顺序：先借车、某日乙才喝酒的，与甲无关；乙喝过酒后甲知情仍出借的，甲才有过错。

   * **手术遗留纱布**

       * 题干：医生张某做手术时把一块纱布遗留在患者李某腹腔，李某的损害找谁主张赔偿。

       * 答案：找医院。

       * 医务人员个人不赔，由医疗机构承担赔偿责任；即使该医生可能有重大过失甚至故意，医院也先赔偿再关起门来向该医生追偿。

   * **输血感染丙肝**

       * 题干：张某被违章驾驶的李某撞伤后送医急救，因输血感染丙肝病毒，后查明血液由某血站提供，张某可向谁请求赔偿。

       * 答案：血液提供者（血站）与医疗机构。

       * 血液也属于医疗产品，存在缺陷的可以同时请求二者。

       * 不能请求李某：其行为与张某被感染丙肝病毒之间不存在相当因果关系。

   * **甲乙工厂的废水**

       * 题干：甲、乙工厂分别位于某河流上游和中游，单独排放的废水均不造成损害，汇集后导致下游丙鱼塘的鱼大量死亡。

       * 答案：甲、乙承担按份责任。

       * 废水汇集后没有发生化学反应、产生新物质，所以与司法解释那条连带责任的新规定无关。

   * **航空器免责与氯气运输**

       * 民用航空器造成损害的，免责事由只有受害人故意一项。

       * 甲公司未按规定使用专用容器装运氯气，乙公司司机曾某未察觉泄漏致数人中毒，甲、乙承担连带责任。

       * 乙公司是保有人要担责；甲公司是所有人且未按规定使用专用容器有过错，故与乙公司连带。

   * **动物园动物致害**

       * 不承担责任的情形是动物园能够证明尽到管理职责。

       * 能证明损害是被侵权人重大过失造成的只是减轻责任，不能免除。

       * 能证明该饲养动物并非危险动物不能免责，动物园是可以饲养危险动物的。

       * 能证明损害是第三人过错造成的也不能免责，此时承担的是不真正连带责任。

   * **暴雪中的公交站台顶棚**

       * 题干：多日暴雪，甲在公交站等车时站台顶棚因积雪过多塌落将甲砸伤，站台是构筑物，由乙公司设计、丙公交公司管理。

       * 答案：由丙公交公司承担。

       * 倒塌原因是管理者管理不当、积雪未及时清理，不是质量缺陷，不适用建设单位和施工单位承担连带责任的规则。

   * **阳台上被风吹落的剪刀**

       * 题干：甲租住乙的房屋，在阳台修剪花草后把剪刀放在阳台边上，被大风吹落砸伤行人丙。

       * 答案：由甲单独赔偿。

       * 这是物件致人损害，由物件的保有人即控制剪刀的甲承担；房东乙没有过错，不承担责任。
