# 名誉权、荣誉权、隐私权与个人信息保护

## 具体人格权内容的三个模板

### 模板的划分与归属

绝大多数具体人格权的内容都逃不出"维护 + 支配"这个底子，差别只在于这两项之外还挂不挂第三项。

| 模板 | 内容三关键词 | 落在谁身上 |
| --- | --- | --- |
| 保护人格标志的人格权 | 维护 + 支配 + 取得人格标志 | 姓名权、肖像权 |
| 保护人格尊严的人格权 | 维护 + 支配 + 保有尊严 | 名誉权、荣誉权、隐私权 |
| 其余多数具体人格权 | 维护 + 支配 | 其余具体人格权 |

* **维护权（对外）**

    * 防止他人不法侵害，是各类具体人格权共有的第一层内容。

* **支配权（对内）**

    * 支配自己这份人格利益，是各类具体人格权共有的第二层内容。

* **取得人格标志**

    * 只挂在保护人格标志的人格权上；肖像权人有权决定自己长什么样、拿不拿出去用。

* **保有尊严**

    * 只挂在保护人格尊严的人格权上；隐私一旦被外人撬开，丢的是人格尊严本身。

* **模板的来源**

    * 这个划分不是自行编的，命题人自己编题时是有思路的；理解这一点比死记十一个条目管用。

## 名誉权

### 名誉权的要素

* **名誉权**

    * > **定义**：名誉权是民事主体对自己这种名誉利益所享有的相应的人格权。

    * 主体是一般主体，自然人、法人、非法人组织都可以享有名誉权。

    * 客体是名誉这种人格利益。

    * 内容上体现为绝对权。

* **社会评价**（名誉的构成特征）

    * 名誉体现为对民事主体的品德、声望、才能、信用等的社会评价。

    * 名誉是一种社会评价，"誉"就是评价的意思。

    * 该评价由不特定主体作出，是一种广泛的、一般性的评价。

    * 评价内容包含品德、声望、才能、信用等等，是一个综合评价。

    * > **注意**：信用也属于名誉权的保护范围。我国民法典没有单列"信用权"这种具体人格权，信用本身就是一种评价，放到名誉权中保护。

* **名誉与财产利益的联系**

    * 名誉和一定的财产利益相联系。

    * 好的名誉能带来更多社会交往机会，进而有可能转化成财产收入。

    * 名誉坏了，别人不愿与之打交道，财产收入方面同样会减少，所以侵犯名誉权也可能造成财产损失。

### 名誉权的权能

```text
                    名誉权
                      │
        ┌─────────────┼─────────────┐
        │             │             │
      保有权        维护权        支配权
      （前提）      （对外）      （对内）
```

* **名誉的保有权**

    * 民事主体通过自己的行为改变自己的社会评价，甚至提高自己的社会评价。

    * 它是享受这种利益的前提，所以每个人都要注意自己的言行，保持良好名誉。

* **名誉的维护权**

    * 别人通过侮辱、诽谤等不法手段毁损其名誉时，可以用法律手段主张救济。

* **名誉利益的支配权**

    * 自己有好的名声时，可以利用名誉从事各种活动。

### 诽谤

* **诽谤**

    * > **定义**：诽谤是以虚假的事实来指责他人，造成不良影响，导致他人社会评价降低的行为。

    * 核心词是"虚假的事实"。

    * 识别抓手：案情出现"伪造""编造""虚构""杜撰"这类词，即提示存在虚假事实并导致社会评价不当降低。

    * 披露的事实真实时，即使导致他人社会评价降低，也不构成名誉权侵权。

    * 披露事实真实而对方社会评价降低的，评价降低由其自身不当行为造成，不能归责于披露事实者。

### 侮辱

* **侮辱**

    * > **定义**：侮辱是以违背善良风俗的方式，通过行为或者言论来贬损他的人格。

    * 言论形态：污言秽语辱骂他人。

    * 行为形态：给别人挂铁牌子、游街，当众贬损人格。

* **诽谤与侮辱的区分**

| | 诽谤 | 侮辱 |
| --- | --- | --- |
| 核心要件 | 以**虚假的事实**指责他人 | 以**违背善良风俗**的方式贬损人格 |
| 手段 | 编造出并不存在的"事实" | 言论或行为 |
| 典型形态 | 伪造、编造、虚构、杜撰 | 污言秽语辱骂他人；给别人挂铁牌子、游街 |
| 识别抓手 | 案情里出现"编造事实"类表述 | 行为方式当众贬损人格 |

* > **易错点**：主要考察的是诽谤的认定，一定要盯住"虚假事实"这个前提；侮辱的内容生活化，一般不会单独出题。

### 抗辩事由：新闻报道与舆论监督

* **公共利益报道的免责**

    * 行为人为公共利益而实施新闻报道、舆论监督等行为的，即使影响他人名誉的，也不承担民事责任。

    * 此类行为很可能披露他人实施违法犯罪行为的事实，而这些事实确实影响其名誉，但实施目的是公共利益这一正当目的。

* **三项例外情形**

    * 捏造歪曲事实：明知是假却打着新闻报道、舆论监督的旗号贬损他人名誉，主观上有故意，已偏离公共利益这一正当目的。

    * 对他人提供的严重失实内容未尽合理核实义务：这一项主要对应实践中的转载行为。

    * 使用侮辱性言辞来贬损他人名誉：可以批评别人，但不能通过侮辱的方式贬损别人的名誉。

* > **易错点**：转载者不能以"我不是内容的首发者"抗辩，因为转载事实上使被虚构事实的扩散范围变大，也要承担相应的法律责任；转发时同样负核实义务。

### 合理核实义务的六项因素

认定是否尽到合理核实义务，应当综合考虑六种因素，这属于典型的动态系统论的立法模式。

| 考量因素 | 归属维度 | 判断要点 |
| --- | --- | --- |
| 内容来源的可信度 | 报道内容 | 源越权威，核实义务越低；转载官方公众号义务相对轻，转载匿名账户爆料义务更高 |
| 对明显可能引发争议的内容是否进行了必要的调查 | 行为人 | 某些内容一旦爆出来对名誉影响极大，必须做必要调查才算尽到义务 |
| 内容的时限性 | 报道内容 | 事情越紧急法律越宽容；不着急的事情必须先核实再转载或公布 |
| 内容和公序良俗的关联性 | 报道内容 | 涉及公共利益的可以适当扩大讨论范围；只涉及特定个人私事的注意义务更高 |
| 受害人名誉受贬损的可能性 | 受害人 | 披露违法犯罪事实对名誉杀伤力更大；鸡毛蒜皮的小事没必要花很多精力核实 |
| 行为人的核实能力和核实成本 | 行为人 | 既要核实，也要考虑处理者的实际能力和核实成本 |

```text
报道行为
  │
  ├─ 行为人这一侧： 你做了什么（必要调查）+ 你能不能做（能力与成本）
  ├─ 报道内容这一侧： 来源可不可信 + 急不急 + 与公序良俗关联有多深
  └─ 受害人这一侧： 这次报道会不会真的砸掉他的名誉
```

* 这组考量因素会成为主观题考点，记住三个维度的归属比背六条更好用。

### 特别救济：消除影响、恢复名誉

* **媒体报道失实的救济**

    * 民事主体有证据证明报刊、网络等媒体报道的内容失实侵害其名誉的，有权请求该媒体及时采取更正或者删除的必要措施。

    * 适用前提是能够证明媒体报道内容失实，体现的是诽谤侵权。

    * 删除不实消息可以最大限度消除影响；查清真相也可以采取更正措施帮别人恢复已受损的名誉。

* **信用评价不当的救济**

    * 民事主体查询自己的信用评价时发现评价不当，可以提出异议，并及时采取更正、删除的必要措施。

    * 提供评价的人或者机构也应当及时核查，经核查属实的要采取必要措施。

    * 本无信用卡逾期记录而信用评价错误记载的，可以请求删除该记录；记录内容有错误的，可以请求更正。

## 荣誉权

### 荣誉权的要素

* **荣誉权**

    * > **定义**：荣誉权是民事主体对自己荣誉所享有的相应的人格权。

    * 主体是一般主体，自然人、法人、非法人组织都可以成为荣誉权的主体。

    * 客体是民事主体获得的荣誉。

    * 荣誉权是为了保护人格尊严而设置的。

* **荣誉**（客体的构成特征）

    * 荣誉是特定人从特定组织获得的一种专门化、确定化的积极评价。

    * 荣誉也是一种评价，因为它含着一个"誉"字。

    * 这个评价由特定组织作出；不同组织颁发的荣誉含金量不同，颁发组织级别越高、越权威，含金量越高。

    * 这是一份专门化、确定化的评价，只对某个特定的特定部分进行评价。

    * 荣誉体现的是一种光荣，只有积极的评价才能称之为荣誉。

* > **易错点**：判断一个东西是不是荣誉，就看它是不是由特定组织作出的、对特定方面的、确定化的积极评价，三条缺一不可；带着"奖"字但评选内容是"最差"的，不构成法律意义上的荣誉。

### 荣誉与名誉的四个区别

| 比较点 | 荣誉 | 名誉 |
| --- | --- | --- |
| 评价来源 | **特定组织**授予，来源具有特定性 | **不特定公众**作出，来源广泛一般 |
| 评价内容 | 专门的、确定化的**积极**评价（光荣） | 综合评价，**有褒有贬** |
| 评价范围 | 对**某个特定方面、某个部分**的评价 | 对品德、声望、才能、信用的**综合性**评价 |
| 能否剥夺 | 可以依照一定的程序**剥夺或者撤销** | **不能**被剥夺或撤销，只能尽力去改变 |

* 记忆抓手：来源描述评价的主体，范围体现评价什么内容，内容体现评价结果是积极还是消极，能否剥夺体现变动或消灭层面的特殊性。

* 名誉不能被剥夺的原因：生活在社会当中很难避免被别人评价，名誉不可能被剥夺或者撤销。

* 这一对比曾以简答题形式考过，属于可能再考主观题的内容。

### 荣誉权的权能与保护

* **荣誉的获得权**

    * 保有荣誉的权能，要先获得荣誉才能享受荣誉带来的尊严方面的利益。

* **荣誉的维护权**

    * 别人侵犯自己的荣誉时，可以主张法治上的救济。

* **荣誉利益的利用权**

    * 支配权，利用荣誉给自己争取更多的社会交往机会。

* **侵权认定**

    * 任何组织或者个人，不得非法剥夺他人的荣誉称号，不得诋毁、贬损他人的荣誉。

    * 非法剥夺或者诋毁、贬损他人荣誉的，都构成侵权。

    * 当年应当记载而没有记载的，可以请求记载；记载错误的可以请求更正。

* > **易错点**："剥夺"前面加了"非法"两个字，这意味着符合规定的、合法地剥夺荣誉称号不构成侵权；事后发现不符条件而收回属于合法剥夺。

## 隐私权

### 隐私权的要素

* **隐私权**

    * > **定义**：隐私权是自然人对自己的隐私这种人格利益所享有的权利。

    * 是民法典新增加的一种人格权，《民法通则》中没有这一权利。

    * 主体仅限于自然人，法人、非法人组织没有隐私权。

    * 客体是隐私。

    * 内容上体现为支配权，同时属于绝对权。

* **隐私**（客体的两个方面）

    * 第一，自然的私人生活安宁属于隐私的范畴，它让人能够有一个独处的、安静的空间。

    * 第二，不愿为他人知晓的私密生活领域，包括私密空间、私密活动以及私密信息。

    * 核心词是"不愿为他人知晓"，既然不愿意被别人知道，就属于隐私的保护范畴。

### 隐私权的权能

* **隐私的保密权**

    * 保有尊严、保有隐私的权能，要防止隐私泄露出去。

    * 给电脑、手机设开屏密码，给手机贴防偷窥膜，都是在保守隐私。

* **隐私的保护权**

    * 维护的权能，别人侵犯隐私时可通过法律手段维护自身合法权益。

* **隐私的支配权**

    * 可以支配自己的隐私，决定隐私要不要公开、私人生活方式怎么安排。

    * 自愿把私生活展示给别人，是法律所允许的行使方式。

* **许可利用权**

    * 支配权的内容里还包含许可他人使用自己隐私的功能。

    * 如明星在访谈节目中披露大量私事，即属于许可他人利用自己的隐私。

* > **易错点**：许可利用权不得违背公序良俗；把自己裸体展示给公众不成立，因为违反公序良俗。

### 侵害私生活安宁

* 私生活安宁是隐私的第一个方面内容，通俗讲就是"我想静静"。

* 通过短信、电话、即时通讯工具、电子邮件、传单等方式侵扰他人私生活安宁的，构成侵权。

* 侵扰私生活安宁的行为常常都是通过现代通讯手段实施的，人在千里之外也能随时被侵扰。

* 通讯手段越发达，私人生活安宁的空间反而越小。

```text
                        侵害隐私权
                            │
        ┌───────────────────┴───────────────────┐
        │                                       │
   第一层：私生活安宁                      第二层：私人生活领域
  （我不想被打扰）                        （我有秘密，不想被知晓）
        │                                       │
   短信 / 电话 / 即时通讯               ┌──────┼──────┬─────────┐
   电子邮件 / 传单 ……                    │      │      │         │
                                   私密空间  私密活动  私密部位  私密信息
                                                     +
                                            以其他方式侵害（兜底）
```

### 侵害私人生活领域

* **私密空间**

    * 擅自进入、窥视、拍摄他人的住宅、宾馆房间等私密空间，构成侵犯隐私权。

    * 宾馆房间：某间房被顾客订下、办理入住之后，这间房就变成该顾客的私密空间，服务员不打招呼直接进入同样构成侵权。

    * 在宾馆房间内安装摄像头本身就侵犯顾客隐私权。

* **私密活动**

    * 未经许可擅自拍摄、公开、窥视、窃听他人私密活动的，构成侵犯隐私权。

    * 明星全家出游戴墨镜戴口罩就是不想被认出来，狗仔队一直跟拍即侵犯其隐私。

* **私密部位**

    * 擅自拍摄、窥视他人身体私密部位的，同样构成侵犯隐私权。

* **私密信息**

    * 通过各种手段获得私密信息以后，未经许可进行处理（存储、转发、传播等）的，构成侵权。

* **兜底条款**

    * 以其他方式侵害他人的隐私权：前面几类没有列进去的，只要实质上侵入了他人的私人生活领域，也一并算进来。

```text
   镜头一：拍到私密空间（房间）
        │  继续放大
        ▼
   镜头二：拍到私密活动
        │  继续放大
        ▼
   镜头三：拍到私密部位
        │  镜头记录下来的，就是私密信息
        ▼
   处理（存储 / 转发 / 传播）—— 同样构成侵权
        │
        ▼
   整条链条，全过程都落在"不愿为他人知晓的私人生活领域"里
```

* 一个偷拍摄像头就占满了私密空间、私密活动、私密部位、私密信息这四类对象。

### 抗辩事由

* 抗辩事由的表述是"除法律另有规定，或者权利人明确同意"。

* "法律另有规定"涉及特别法的问题。

* > **注意**：光是"同意"还不行，必须是明确的同意。

* 情侣之间经对方明确同意后拍摄私密情趣照片，不构成侵权；没有明确同意的，构成侵权。

* 员工因不满上司不提拔自己，在私家车装追踪器、在私家车库装摄像头并寄给纪委，同样因侵入他人不愿被知晓的私人生活领域而构成侵犯隐私权。

## 个人信息保护

### 个人信息的法律地位

* **个人信息**

    * 个人信息不是一种独立的人格权，它只是民法所保护的一种人格利益。

    * 法律对它的保护并没有提升到具体人格权的高度，因此表述上应用"个人信息权益"，不能写成"个人信息权"。

* 不立为独立人格权的理由

    * 民法典要同时做两件事：保护自然人的个人信息，以及方便个人信息和数据的处理与流通、促进信息产业的发展。

    * 对自然人的保护水平太高，对自然人一方固然有利，但数据产业相关企业获取信息的合规成本会大大增加，进而限制网络数据产业的迅速发展。

* 除民法典外，我国还单独颁布了《个人信息保护法》，2021年颁布；其中部分问题已被纳入考试分析。

### 个人信息的构成要件

* > **定义**：个人信息是以电子或者其他方式记录的，能够单独或者与其他信息结合起来识别特定自然人的各种信息。

* 形式要件

    * 要以电子或者其他方式记录。

    * 其他方式记录的信息只要符合法定条件，同样纳入个人信息保护范围；例如个人档案中记载的、尚未电子化的信息。

* 实质要件

    * 要能够发挥识别特定自然人的功能，识别可以是单独识别，也可以是与其他信息结合起来识别。

* 身份证号码

    * 每个人独一无二，可以单独发挥识别功能，属于个人信息的保护范畴。

* 姓名

    * 很难单独识别，实践中同名同姓的人太多；把姓名跟出生日期结合起来就可以发挥识别功能。

* 生物识别信息

    * 识别性非常强，包括指纹、虹膜、DNA 鉴定、人脸识别等。

* 行踪信息

    * 行踪信息也属于个人信息，可以发挥识别功能。

    * 疫情期间调查并公布某人过去七天的行踪，足以大致推出其生活状态与为人。

### 个人信息与隐私权的关系

* 个人信息中有些私密信息可能同时符合隐私权的规定。

* 至少在这种情况下可以优先适用隐私权的规定，因为隐私权是独立的人格权，保护水平更高。

* 隐私权没有规定的，再适用个人信息保护的相关规定。

* > **结论**：隐私权的规定相对于个人信息保护的规定有优先适用的效力。

### 处理的范围

* **个人信息的处理**

    * 个人信息处理是广义概念，包括个人信息的收集、存储、使用、加工、传输、提供、公开等等。

    * 收集本身就是一种处理方式，而不是收集在前、处理在后的两个独立环节。

* > **易错点**：考试问"下列行为中属于个人信息处理的有哪些"时，一定要把收集选进去。

### 处理的条件：合法、正当、必要

* 处理个人信息应当遵循合法、正当、必要三项原则，不得过度处理。

* 条件与原则的对应关系如下：

| 条件 | 对应的原则 |
| --- | --- |
| 征得该自然人或者其监护人的同意 | **合法** |
| 公开处理信息的规则（便于相关部门监督） | **正当** |
| 明示处理信息的目的、方式、范围 | **必要**（不得超出） |

* 同意是合法原则的底线合规要求；公开处理规则是为了方便相关部门监督，体现目的的正当性；明示目的、方式、范围，体现的是必要原则。

* 再加上"不违反法律、行政法规的规定以及当事人的约定"，就形成了处理个人信息应当满足的完整条件。

### 免责情形

存在下列情形之一的行为，不承担民事责任。

| 免责情形 | 与"同意"的关系 |
| --- | --- |
| 在该自然人或者其监护人同意的**范围内合理处理**个人信息的 | **已经同意** |
| 合理处理该自然人**自行公开**的或者通过其他途径**合法公开**的信息（但该自然人明确拒绝、或者处理该信息侵害其重大利益的除外） | **推定同意** |
| 为维护**公共利益**或者该自然人**合法权益**合理实施的其他行为 | **无需同意** |

* 第一种是已经同意，第二种是推定同意，第三种是无需同意，三种免责事由都与"同意"这个条件直接挂钩。

* 第二种情形中的"重大利益"是考点。

    * 在求助平台公开病历资料、身份证照片以及病床照片虽属主动、合法公开，但涉及该自然人的重大利益，别人不能随便利用。

* 第三种情形的常见场景

    * 为疫情防控而公布某些人的行踪信息，是为了维护公共利益。

    * 为寻找走丢的儿童或老人在网上发寻人启事，同样涉及个人信息处理，但不需要承担法律责任。

### 敏感个人信息

* > **定义**：敏感个人信息是一旦泄露或者非法使用，容易导致该自然人的人格尊严受到侵害，或者人身、财产安全受到危害的个人信息。

* 通俗讲就是一旦泄露以后可能后果很严重的那种信息。

* 生物识别信息、银行卡账户密码等泄露后可能导致严重后果，属于敏感个人信息。

* 不满十四周岁的未成年人的个人信息，通通都属于敏感个人信息，这是为强化对未成年人的保护作出的规定。

* 处理规则

    * 只有在具有特定的目的和充分的必要性，并采取严格保护措施的情形下，个人信息处理者方可处理敏感个人信息。

    * 处理敏感个人信息还应当取得该自然人的单独同意，一项一项地授权，不许打包。

    * 一般个人信息的处理只要经过"同意"即可，且该同意可能还是格式条款里的概括同意；一旦涉及敏感个人信息，就得单独同意。

* > **易错点**：判断标准不是"这个信息对当事人来讲是否敏感"。女生的体重、男人的收入在生活中都觉得敏感，但与法律上的敏感个人信息不是一回事。

```text
   ┌───────────────────────────────────────────────┐
   │  隐私权：明确同意                               │  最高
   │  不但要单独，还得明确就是同意"这件事"本身         │
   ├───────────────────────────────────────────────┤
   │  敏感个人信息：单独同意                          │  居中
   │  一项一项地授权，不许打包                        │
   ├───────────────────────────────────────────────┤
   │  一般个人信息的处理：同意                         │  相对最低
   │  格式条款里概括地同意一下即可                     │
   └───────────────────────────────────────────────┘
```

* 敏感个人信息的单独同意仍然没有达到隐私权的保护标准，三层台阶层层递进。

### 侵权认定与归责规则

* 侵权认定

    * 只要处理个人信息不符合处理规则要求，都属于侵犯个人信息的行为。

    * 任何组织和个人需要获取他人个人信息的，应当依法取得并确保信息的安全。

    * 不得非法收集、使用、加工、传输，也不得非法买卖、提供、公开他人的个人信息。

* 归责规则

    * > **结论**：个人信息保护适用过错推定——处理个人信息侵害个人信息权益造成损害的个人信息处理者，不能证明自己没有过错的，应当承担损害赔偿的侵权责任。

    * 处理者必须证明自己的处理符合法律规定的要求，证明不了自己没有过错就要承担侵权责任。

### 处理者的义务

| 义务类型 | 具体内容 |
| --- | --- |
| **经请求而应当履行的义务** | 自然人有权依法查阅、复制其个人信息；发现错误的，有权提出异议并请求及时采取更正的必要措施 |
| **不作为义务** | 不得泄露、篡改其收集存储的个人信息；未经同意不得非法向他人提供 |
| **积极义务** | 采取技术措施和其他必要措施，确保收集存储的个人信息安全，防止泄露、篡改和丢失 |
| **保密义务** | 国家机关及其工作人员对公民个人信息负保密义务 |

* 自然人提出查阅或复制请求时，处理者有配合义务；发现个人信息有错误的，处理者有及时更正的义务。

* > **注意**：不作为义务有一个出口——经过加工已经无法识别特定个人且不能复原的除外；去识别化之后该信息已无法发挥识别功能，变成单纯的数据，可以依法进行流转。

* 积极义务的来源是一起真实案例：考生高考志愿信息被不法分子窃取后用于实施诈骗。主管部门收集志愿信息本身合法，但收集后未采取必要措施防止信息泄露，没有尽到安全保障义务，造成的损失也要承担赔偿责任。

* 保密义务之所以要强化：国家机关掌握大量公民个人信息且相当准确权威，个人信息交易的黑色产业链中常常有国家机关工作人员参与。

## 权利竞合的真题辨析

### 公开他人照片并声称其不是

* 案情：甲将乙的照片和联系方式发到自己的微信朋友圈，声称乙欠钱不还是骗子；经查甲所言与事实不符。

* 答案：名誉权。

* 认定路径是诽谤——以虚假事实指责他人，导致他人社会评价降低。

* > **易错点**：按现行民法典，擅自把乙的照片发到朋友圈确实也构成肖像权侵权，因为肖像权侵权行为包含"未经许可擅自公开他人肖像"；但该题考于民法典出台之前，当时单纯披露照片而没有使用照片不侵犯肖像权，所以当年答案里没有肖像权这个选项。单选题遇到争议要选最切合题目核心的选项。

* 答题方法：民法典出来后遇到"公开他人照片 + 声称其不是"这类混合题，要分两层想——名誉权（捏造虚假事实贬损社会评价）与肖像权（未经许可擅自公开他人肖像）。题目问哪个就答哪个；问"构成侵权"但不限于一种的，两层都要写。

### 公开绰号、结婚照并散布虚假婚外情

* 案情：甲将乙的绰号、未公开的结婚照和家庭背景等信息发布到网络上，并散布乙有婚外情的虚假信息，导致乙遭受非议。

* 答案：肖像权、隐私权、名誉权三项。

* 姓名权不成立：题干中并不存在盗用、冒用、干涉姓名的行为，仅仅公开可能涉及隐私权，不会涉及姓名权侵权；绰号即便具有广泛知名度，也完全没必要由甲来公开。

* 肖像权成立：未公开的结婚照上必然包含乙的肖像，擅自公开构成侵权；该题考于民法典出台之后。

* 隐私权成立：绰号、未公开的结婚照和家庭背景都属于不愿与他人知晓的私密信息。

* 名誉权成立：散布婚外情的虚假信息属于诽谤。

### 打包出售购房信息

* 案情：甲公司将售房过程中收集到的购房者的姓名、身份证号码、电话、家庭住址等信息打包出售。

* 答案：个人信息权益。

* > **易错点**：不能表述为"个人信息权"，因为个人信息不是一种独立的人格权，它只是受保护的人格利益。

* 未侵犯身份权：题干涉及的都是财产方面的信息。

* 未侵犯信用权：我国没有"信用权"这样一种独立的人格权，信用要通过名誉权来保护。

* 未侵犯姓名权：仅披露姓名，没有盗用、冒用、干涉行为。
