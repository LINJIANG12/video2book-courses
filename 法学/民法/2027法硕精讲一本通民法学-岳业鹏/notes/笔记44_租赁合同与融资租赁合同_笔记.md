# 租赁合同与融资租赁合同

## 租赁合同的含义与特征

* **租赁合同**

    * > **定义**：当事人约定在一定期限内转移租赁物使用收益权的合同。

    * 双方当事人：出租人一方负交付义务，承租人一方负支付对价（租金）义务。

    * 租赁标的物既可以是动产（租车、租充电宝），也可以是不动产（租房）。

* **特定物**

    * > **定义**：与"种类物"相对应，体现独一无二、不可替代属性的物。

    * 租赁物必须是特定物，租期届满须原物返还，不能用同种类物代替。

    * 例：甲租了乙的一辆车，还车时不能另还一辆。

* **非消耗物**

    * > **定义**：与"消耗物"相对应，可以反复使用的物；消耗物是一次使用后价值即消灭的物。

    * 租赁物在使用后还要返还出租人，故必须具备可重复使用属性。

    * 消耗物不能充当租赁标的：核酸检测的取样棉签、医院输液器都是一次性的。

* **要素定位**

    * 主体：无特殊性，自然人、法人、非法人组织均可担任出租人或承租人。

    * 标的物：具有两重特殊性，即特定物与非消耗物。

    * 内容：有期限地转移使用收益权，与买卖转移所有权形成鲜明对比。

* **性质定位**

    * 双务、有偿、诺成三项均符合。

    * 要式与否不能一概而论：租期在六个月以上的应当采用书面形式；租期不满六个月的，口头、书面均可。

    * > **易错点**：租期六个月以上未采用书面形式的，后果不是合同不成立，而是先通过其他方式确定租期；确实确定不了的，视为不定期租赁。

* **特征模板**

    ```text
    要素定位：主体 → 无特殊性
              标的物 → 特定物 + 非消耗物
              内容 → 有期限地转移使用收益权（对比买卖：转移所有权）
    性质定位：双务 ✓  有偿 ✓  诺成 ✓  要式 → 视租期而定（6 个月为界）
    ```

## 典型合同的效力：出租人的义务

出租人一方的义务按"交付、转移、瑕疵"三层次展开。

* **交付义务**

    * 出租人应按约定将租赁物交付给承租人。

    * 在租赁期间保持租赁物符合约定的用途。

* **转移占有使用收益权**

    * 承租人按约定方法或租赁物性质正常使用租赁物，即使导致租赁物损耗，出租人也不承担损害赔偿责任。

    * 例：婚房出租三年后变得陈旧，承租人按房屋性质正常使用，出租人不得要求赔偿。

    * 因出租人原因导致租赁物无法使用的，承租人可以解除合同，因为转移使用收益权既是出租人的主给付义务，也代表对方订立合同的目的。

* **权利瑕疵担保责任**

    * 目的是把租赁物的使用收益权完整、无瑕疵地转移给承租人。

    * 第三人主张权利致承租人不能对租赁物使用收益的，承租人可以减少租金或者不支付租金。

    * 表现为补救措施：因第三人权利主张导致一周无法开车，可请求出租人减少这一周的租金。

    * 第三人主张权利的，承租人应当及时通知出租人，由出租人介入解决纠纷。

    * 例：乙租用甲的车期间，丙上门主张车属于自己，乙可追究甲的违约责任。

* **质量瑕疵担保责任**

    * 交付时租赁物应当符合约定的使用用途，交房时即为危房即构成违反。

    * 使用收益权的转移处于持续状态，整个租期内出租人都要保证租赁物符合约定用途。

    * 期间产生新问题的，出租人负有维修义务，没有明确约定时由出租人修。

* **出租人该修却不修的后果**

    * 维修义务不适合强制履行，承租人可以自行维修，维修费用作为金钱之债可强制执行，由出租人承担。

    * 因维修影响承租人使用的，承租人可以请求相应减少租金或者延长租期。

    ```text
    出租人该修却不修
            │
            ▼
    承租人自行维修 ──► 维修费用由出租人承担
       （维修费用是金钱之债，可以强制执行）

    因维修影响承租人使用的
            │
            ├──► 相应减少租金
            └──► 或延长租期
    ```

    * 例：暴雨导致房子漏雨无法居住，承租人住酒店一周，可请求减少这一周租金或延长租期。

## 典型合同的效力：承租人的义务

承租人的各项义务可按双务合同的对价关系推导。

* **受领租赁物并按正确方法使用**

    * 使用方法先看约定；没有约定或约定不明确的，按照租赁物的性质使用。

    * 例：未约定用途的住宅只能居住不能开饭店；私家车属非运营机动车，不能开去跑网约车。

    * 未按约定方法或租赁物性质使用致租赁物损失的，出租人可以解除合同并请求赔偿损失。

    * > **注意**：因该行为会使出租人订立合同的目的不能实现，出租人优先选择解除合同，不要只依赖赔偿损失。

* **不得擅自转租**

    * 未经出租人同意，承租人不得擅自转租。

    * 擅自转租有可能增加租赁物灭失的风险，出租人可以解除合同。

* **按照约定支付租金**

    * 这是承租人的主给付义务，与取得使用收益权相对价。

* **妥善保管租赁物，不得擅自改善或增设他物**

    * 承租人占有的是他人财产，应尽妥善保管义务。

    * 未经出租人同意擅自改善的，出租人可以请求恢复原状或者赔偿损失。

    * 例：承租人嫌装修老土，拆除原装修并全面装修，仍属擅自改善。

* **返还租赁物**

    * 承租人只取得一定期限内的使用收益权，合同终止时应当返还租赁物。

## 不定期租赁中的任意解除权

以持续履行的债务为内容的合同，期限无法确定时双方都有任意解除权；不定期租赁适用该规定。

* **判断前提与漏洞填补**

    * 没有约定租期的，先走漏洞填补规则：先由双方协议补充；达不成协议的，按合同的有关条款和交易习惯确定。

    * 能确定租期的，依然是定期租赁，租期内不存在任意解除权。

    * 例：债务人以月租金 1 万抵 100 万货款，租金即为 100 个月，据合同有关条款可确定租期，仍属定期租赁。

* **构成不定期租赁的三种法定情形**

    * 第一种：对租期没有约定或者约定不明确，依照漏洞填补规则仍然不能确定。

    * 第二种：租期在六个月以上，当时没有采用书面形式，而且也无法确定租期。

    * 第三种：租期届满后承租人继续使用租赁物，出租人没有提出异议；此时承租人可随时终止，出租人有新承租人时也可通知其搬离。

    ```text
                    租期是否已经确定？
                            │
            ┌───────────────┴────────────────┐
          已确定                           未确定
       （哪怕没签书面）              ┌──────┴──────┐
            │                    租期 ≥ 6 个月      租期 < 6 个月
            │                         │                │
            │                    是否采用书面？         │
            │                   ┌─────┴─────┐          │
            │                 是           否          │
            │                  │            │          │
            │            定期租赁      仍先走漏洞填补      │
            │                           规则找租期        │
            │                        ┌────┴────┐        │
            │                     找到        找不到     │
            │                      │            │        │
            │                 定期租赁    ┌────┴────┐   │
            ▼                              │         │   ▼
       ❌ 任意解除权                不定期租赁   不定期租赁
                                    （法定）    （法定）
    ```

    * > **易错点**：没约定租期就一定是不定期租赁吗？不是，必须先走漏洞填补规则仍不能确定才构成不定期租赁；租期达到六个月以上又没采用书面形式，也不一律构成不定期租赁。

## 买卖不破租赁

* **买卖不破租赁**

    * > **结论**：租赁物在承租人按照合同占有期间发生所有权变动的，不影响租赁合同的效力（民法典第725条）。

    * 承租人可以请求新的所有权人继续履行原来的租赁合同。

    * 例：甲把房子租给乙并交付，租期内甲把房子卖给丙并办理过户登记，丙不能以"我现在是房东"为由清退乙。

    * 性质：属于物权优先于债权的例外制度，又称租赁权的物权化，因为租赁市场中的承租人处于相对弱势地位。

* **适用范围**

    * 名为"买卖"但适用范围包括但不限于买卖，只要租期内发生所有权变动即可适用。

    * 继承同样使租赁物所有权发生变动，承租人可请求继承人继续履行原租赁合同。

    * 既适用于不动产租赁，也适用于动产租赁。

    * > **提示**：不需要把"买卖不破租赁"改称"转让不破租赁"，记住虽名为买卖但适用范围更宽即可。

* **承租人不得主张买卖不破租赁的两种例外**

    * 例外一：房屋在出租之前已经设立抵押权，因抵押权实现导致所有权变动的，承租人不能主张。

    * 例外二：房屋在出租之前已被人民法院依法查封的，承租人不能主张。

    * 查封通过在房屋登记簿上记载的方式进行，具有公示效力，可以对抗在后的承租人；实践中承租人可能租到已被查封甚至房东撕掉封条出租的房屋。

    * 归纳：承租人不能主张的例外情形主要体现为先抵后租且抵押权办了登记这一种。

* **抵押权与租赁权的冲突顺位**

    * 冲突表现为实现抵押权、拍卖变卖抵押财产时承租人能否主张买卖不破租赁，取决于先来后到。

    ```text
                  抵押权 与 租赁权 冲突：谁优先？
                                │
              ┌─────────────────┴──────────────────┐
           先租后抵                               先抵后租
     （先签租赁合同 + 已交付占有）          （先设抵押，后签租赁）
              │                                       │
       承租人优先                             ┌─────────┴─────────┐
       可对抗在后的抵押权人              抵押权已登记？          未登记
       —— 无论该抵押权有没有办登记              │                  │
       —— 都不得向承租人主张买卖不破租赁         是                 否
              │                                   │            （主要涉及动产）
              ▼                                   ▼            抵押权不得对抗
          ❌ 抵押权人优先                 承租人不得主张         善意第三人
                                            买卖不破租赁              │
                                                         善意承租人依然可以
                                                         主张买卖不破租赁
    ```

    * 区分登记的原因：动产抵押不转移占有，要靠登记定顺位；未登记的动产抵押权不得对抗善意第三人，而善意的承租人正是该善意第三人。

    * 例外一对应房屋出租前已设抵押，抵押标的是不动产，一定办了抵押登记，故承租人不能主张，实现抵押权拍卖房屋时可以清退承租人让其参与拍卖。

    * > **易错点**："先租后抵"中的"先租"指先签订租赁合同**同时**已占有租赁物；只签合同未转移占有的，承租人不能主张买卖不破租赁。

## 房屋租赁的效力特别规则

* **违法建筑租赁合同的效力**

    * 违法建筑指没有取得规划许可，或者没有按照规划许可建设、手续有瑕疵的房屋。

    * 对违法建筑签订的租赁合同应当认定无效，属于合同无效的一种特殊情形。

    * 在一审辩论终结之前补齐建筑规划手续的，合同可以补正，自始有效。

    * 例：出租临街房屋和院子作汽车维修场所，扩建报批时发现全部房屋未经规划许可，合同无效；能补齐手续的转为有效。

* **违法建筑的使用费**

    * 合同被认定无效的，当事人可以请求参照合同约定的租金标准支付房屋使用费。

    * 合同无效不等于承租人可以免费使用，已实际占有使用的期间仍要付费。

* **一房数租的履行顺序**

    * 出租人就同一房屋签订数份租赁合同的，各份合同原则上均合法有效，因为债权没有排他性。

    * 房屋只有一套，只能满足一个承租人的履行请求，履行顺序为：已合法占有房屋者优先，其次是已办备案登记者，最后是合同成立在先者。

    * 已办备案不影响合同效力，但在一房数租的履行顺序上处于相对优先顺位；实践中住宅租赁很少备案，商铺租赁因涉及消防、安全等责任主体认定必办。

    * 已预付租金的承租人不进入顺位，先付钱反而承担了最多风险。

    * 不能取得租赁房屋使用权的承租人，只能主张解除合同并追究对方违约责任。

    ```text
    同一套房 → 出租人先后与 甲、乙、丙、丁 签订数份租赁合同
                           │
           ┌───────────────┼───────────────┐
      ① 已合法占有房屋  ② 已办备案登记   ③ 合同成立在先
           │               │               │
           ▼               ▼               ▼
          丁               乙               甲
       （丁已办理入住）（乙先去备案）（甲最先签合同）

    丙虽然预付了租金，但不进入顺位
    → 只能主张解除合同、追究对方违约责任（订立合同的目的不能实现）
    ```

    * 占有排在最前的理由是"请神容易送神难"，已占有的承租人被清退很难执行。

* **转租的三方关系**

    ```text
        出租人甲                承租人乙                 次承租人丙
         所有权人            （转租人）              （实际使用人）
            │                     │                        │
            │   租赁合同 ①        │      转租合同 ②         │
            ├────────────────────►├───────────────────────►│
            │                     │                        │
            │                     │◄────── 租金 ───────────┤
            │     租金            │                        │
            │◄────────────────────┤                        │
            │                     │                        │
            │  合法转租：经甲同意   │  非法转租：未经甲同意    │
            │  两份合同均有效       │  甲可解除合同 ①          │
            │  → 适用合同相对性     │  → 六个月内不异议即转正   │
            └─────────────────────┴────────────────────────┘
    ```

* **合法转租**

    * 合法转租指转租经出租人同意，两个租赁合同都可以合法有效。

    * 履行中遵循合同相对性：出租人不能直接向次承租人收取租金，也不能追究次承租人的违约责任（但可追究其侵权责任）。

    * 谁追究次承租人的违约责任：转租人追究次承租人的，出租人追究转租人的，各找各的合同当事人。

    * 转租期限不能超过转租人的剩余租期，超过部分的约定对出租人不具有法律约束力。

    * 例：房屋租期5年，转租时只剩3年却签了5年转租合同，次承租人不能用5年对抗房东，只能占用3年被收房，但可向转租人追究违约责任。

* **非法转租**

    * 未经出租人同意签订转租合同的，属于非法转租，因增加租赁物灭失风险，出租人可以解除合同。

    * 解除权是形成权，受除斥期间限制：出租人应当在知道或者应当知道转租之日起六个月内提出解除。

    * 六个月内没有提出异议的，视为出租人同意转租，非法转租转为合法转租。

    * > **提示**：出租人的沉默在此被视为同意转租的意思表示，是沉默作为意思表示例外情形的典型。

## 承租人的特别权利

* **优先购买权的行使条件：同等条件**

    * 出租人在租期内出卖租赁房屋的，承租人在同等条件下有优先购买权。

    * 同等条件不能只看价款，要综合考虑价款、履行期限、履行方式等一系列因素。

    * 例：第三人全款支付100万，承租人需贷款60万，因履行方式不同，承租人不能主张优先购买权。

    * 制度意义：特别保护承租人，同时最大限度发挥已由承租人占有的房屋的使用效益。

* **承租人不得主张优先购买权的例外情形**

    * 房屋的共有人行使优先购买权的：共有人是物权人，承租人只是债权人，基于物权优先于债权的一般规则应先让共有人取得所有权。

    * 出租人将房屋卖给近亲属的：亲情价不属于同等条件。

* **优先购买权的合理期限**

    * 优先购买权性质上属于形成权，受除斥期间限制，须在合理期限内行使。

    | 出售方式 | 期限性质 | 期限 | 起算点 | 承租人未行动的后果 |
    | --- | --- | --- | --- | --- |
    | 出租人委托拍卖人拍卖租赁房屋 | 出租人通知承租人的时间 | 提前 5 天通知 | 拍卖前 | 未在拍卖当天参与竞买，视为放弃优先购买权 |
    | 通过其他方式出卖租赁房屋 | 通知承租人后的考虑时间 | 15 日内表态 | 通知之日 | 15 日内未表态的，视为放弃优先购买权 |

    * > **易错点**：5 天与 15 日性质完全不同。5 天是出租人通知承租人的时间（须在拍卖前五天通知），15 日是通知之后给承租人的考虑期；参加拍卖要当场决定，非拍卖方式则 15 天内不表态即过期不候。

* **优先购买权被侵害的救济**

    * 出租人未通知承租人即出卖房屋并已办理过户登记的，出租人属于有权处分，第三人仍可取得房屋所有权。

    * 承租人只能主张损害赔偿，不能主张出租人与第三人签订的买卖合同无效。

    * 对应真题：甲售房通知乙，乙超期未表态，甲卖丙并过户，乙可主张租赁合同对丙继续有效；不能主张买卖合同无效，也谈不上甲承担违约责任。

* **优先承租权**

    * 租期届满时，房屋承租人享有同等条件优先承租的权利。

    * 同样须在同等条件下主张，且只能适用于房屋的租赁。

    * 制度意义：承租人无需搬家，且在租赁市场中对承租人提供与优先购买权类似的保护。

* **承租人死亡的法定概括承受**

    * 承租人死亡不导致租赁合同无效，与承租人生前共同居住的人或者共同经营的人可按原合同继续租赁该房屋。

    * 例一：情侣合租，其中一方猝死，另一方作为共同居住人可直接承受租赁合同中的权利义务。

    * 例二：合伙开办健身中心，一方为完成出资义务以个人名义租赁经营性用房，租期5年；该方第2年死亡，其他合伙人作为共同经营人可按原合同继续租赁。

    * > **注意**：以个人名义租赁的，租赁合同当事人是该个人；其死亡后由共同经营人承受租赁合同的权利义务，构成法定的概括承受。

## 融资租赁合同的概念与特征

融资租赁形式上是租赁关系，实质是向企业提供融资，发挥类似银行贷款的作用，属于金融领域中的一种交易，而不是租赁领域中的交易。

### 交易模型

* **融资租赁合同**

    * 例：航空公司急需三架波音客机但无资金、也不具备银行贷款的担保条件，与融资租赁公司约定由其按承租人选定的机型购买后再租出，租金付清则飞机归承租人。

    ```text
            承租人乙                    出租人甲                    出卖人波音
                │                           │                           │
                ├──────────────────────────>│                           │  ①
                │                           ├──────────────────────────>│  ②
                │                           ┤──────────────────────────<│  ③
                │<──────────────────────────┤                           │  ④
                ├──────────────────────────>│                           │  ⑤
    ```

    * ①承租人选定机型、提出要求；②出租人依其选择向出卖人购买租赁物；③出卖人把租赁物交付给出租人；④出租人把租赁物租给承租人使用；⑤承租人按期支付租金，付清后租赁物归承租人所有。

    * > **易错点**：①和⑤的方向最容易记混——承租人是提出要求的一方，也是付钱的一方；出租人只做两件事，即花钱买租赁物、把租赁物租出去。

* **双方当事人的义务结构**

    * 出租人两项义务：根据承租人对出卖人、租赁物的选择向出卖人购买租赁物；把租赁物提供给承租人使用。

    * 承租人一项义务：支付租金，本质是把出租人购买租赁物所花的钱通过分期还款方式返还，租金付清即取得租赁物所有权。

* **售后回租**

    * 法律允许向承租人自己购买租赁物，承租人将自有物出卖给出租人后再租回，构成售后回租型融资租赁。

    * 例：承租人把一架旧飞机卖给融资租赁公司，约定价款5000万元，取得资金后继续租用该飞机。

    * 完成方式是占有改定：承租人先卖出再租回，融资租赁公司借此取得租赁物所有权并发挥担保租金债权的功能。

    * 出租人必须实际花钱购买租赁物，否则就抢了银行的饭碗。

    * 承租人将自有物出卖给出租人再租回的，构成占有改定；不应仅以承租人和出卖人是同一人为由，认定不构成融资租赁法律关系。

* **出租人取得所有权的目的与合同底线**

    * 出租人取得租赁物所有权不是为了占有、使用、收益、处分，而是为了担保租金债权的实现，租赁物毁损时可收回并变卖以降低融资风险。

    * 融资租赁合同本质上是非典型担保物权制度，功能与物权保留买卖类似，都发挥担保功能。

    * 出租人对租赁物的所有权未经登记，不得对抗善意第三人，效力类似动产抵押权。

    * 以虚构租赁物的方式订立融资租赁合同、掩盖非法目的的，该融资租赁合同无效。

### 要素定位与性质定位

* **主体与标的物**

    * 出租人须取得从事融资租赁业务的资格，融资租赁属特许经营行业。

    * 标的物是按照承租人的要求购买的，通常是价值较高的固定资产；价值过低则不值当通过成本较高的融资租赁融资。

    * 对比普通租赁合同标的常常是出租人自由的财产，这是两者明显的分水岭。

* **内容：租金的性质**

    * 合同也包含支付租金的义务，但租金不是使用租赁物的对价，而是获得对方融资的对价。

    * 租金标准比一般租赁合同高得多，应相当于出租人购买租赁物的大部分甚至全部成本，并包含出租人的合理利润，即通过租金还本付息。

* **性质定位**

    * 双务、有偿、诺成、要式四项均符合，须通过书面形式订立。

## 融资租赁合同的效力

### 出租人一方的义务

* **交付与转移**

    * 第一层次是交付，比一般租赁合同多出一个购买行为：出租人须先按承租人的要求购买租赁物，再交付租赁物。

    * 第二层次是转移：把租赁物交给承租人使用，保证承租人占有和使用租赁物。

* **瑕疵担保：原则上没有，两条例外**

    * 原则上出租人对租赁物不承担瑕疵担保责任，其最核心的义务只是出钱、收租金。

    * 承租人发现租赁物有瑕疵，应直接向出卖人索赔而不能向出租人索赔；出租人作为法律上的买受人负有协助义务。

    * 例：按承租人选定从飞机制造商购入的飞机有瑕疵无法起飞，承租人向出卖人索赔，出租人负协助义务。

    * 例外一：承租人依赖出租人的技能来确定租赁物的，出租人承担瑕疵担保责任。

    * 例外二：出租人干预选择租赁物的，即对找谁买、买什么标的物提出参考意见的，出租人承担瑕疵担保责任。

    * 例外情形下租赁物有瑕疵的，承租人可以请求减免相应的租金。

### 承租人一方的义务

* **按约定及时接受租赁物**

    * 承租人选定的租赁物已由出租人出资买下，承租人负有及时接收义务。

    * 租赁物有瑕疵的，承租人直接向出卖人索赔，不能向出租人索赔。

* **妥善保管、使用、维修租赁物**

    * 租赁物交付后即由承租人负担这些义务。

* **按约定支付租金**

    * 这是承租人的主给付义务，对价是对方提供的融资，标准相当于出租人购买租赁物的成本加合理利润。

    * 承租人被催告后在合理期内仍不支付租金的，出租人可以请求其支付全部剩余租金，也可以解除合同、收回租赁物，两项只能择一行使。

    * 该具体措施与分期付款买卖中出卖人未收全部价款时的处理类似。

* **承担租赁物毁损、灭失的风险**

    * 承租人占有租赁物期间致第三人损害的，由承租人承担赔偿责任。

    * 例：承租人使用期间飞机坠毁砸塌他人房屋，由承租人航空公司赔偿。

    * 租赁物毁损、灭失的风险由承租人承担，即使租赁合同解除，出租人依然可以请求承租人继续支付租金。

* **租期届满未取得所有权时返还租赁物**

    * 当事人未约定租期届满取得所有权，或因各种原因未付清租金而未取得所有权的，承租人应返还租赁物。

    * 已依约定取得对应所有权的，不负返还义务。

## 融资租赁的特别制度：租赁物归属

### 合同有效时的归属

* **租期内所有权归出租人**

    * 租期内承租人未付清全部租金，租赁物所有权归出租人，因为是出租人出钱购买。

    * 该所有权主要为担保租金债权的实现而存在，未经登记不得对抗善意第三人，效力类似动产抵押权。

    * 该所有权担保的是租赁物的价款债权，因此只要在10天内办理登记，出租人即可享受超级优先的保护顺位，即"插队"特权。

* **与动产抵押权的受偿顺位**

    * 例：甲以动产浮动抵押向银行借款并办理登记，后向丙融资租赁公司租入一套大型设备，约定付清租金后取得所有权。甲既不还贷也不付租金时，银行与丙都要拍卖设备受偿。

    | 融资租赁出租人所有权的登记状态 | 能否对抗银行 | 设备拍卖价款的受偿顺位 |
    | --- | --- | --- |
    | 未办理登记 | 不得对抗善意第三人 | 银行第一，融资租赁公司第二 |
    | 10 日以内办理登记 | 租金债权属价款债权，且在期限内登记，享受超级优先 | 融资租赁公司第一，银行第二 |
    | 10 日以后办理登记 | 不符合插队特权要求，按登记先后定顺位 | 银行第一，融资租赁公司第二 |

    * 所以要具体问题具体分析，关键看融资租赁出租人有没有在10日内办理登记。

* **租期届满时尊重意思自治的三种约定**

    * 第一种：约定租期届满承租人仅需支付象征性价款的，视为租金义务履行完毕，租赁物所有权归承租人。

        * 象征性价款不具有实质意义，承租人即使不付该价款，也视为租期届满时租赁物直接归承租人。

        * > **易错点**：出租人事后以象征性价款显失公平为由反悔的，法院不予支持。

        * 这种约定的用意在于消除当事人对法律规则的不信任，通过买卖方式取得所有权更安心。

    * 第二种：约定租期届满归承租人所有，但承租人已付大部分租金、无力支付剩余租金的，承租人不能取得所有权。

        * 出租人可以解除合同、收回租赁物，理由是承租人未还清购买租赁物的款项。

        * 收回后拍卖、变卖租赁物所得价款，出租人优先清偿承租人欠付的租金；有剩余的应当返还承租人。

        * 出租人享有的实为类似担保物权的优先受偿权，先把钱拿够，多余部分要还给承租人。

    * 第三种：约定租期届满租赁物归出租人所有的，因毁损、灭失或因混合、附合于他物不能返还的，承租人应给予适当补偿。

        * 理由是此类约定下承租人支付的租金不足以涵盖全部购买成本，返还不能时需补偿以保护出租人利益。

* **没有约定或约定不明时**

    * 当事人对租赁物归属没有约定或约定不明确，经合同漏洞填补规则仍不能确定的，租赁物所有权依然属于出租人。

    * 没有特别约定时，法律没有理由剥夺出租人的所有权。

### 合同无效时的归属

* **原则：仍属出租人，承租人返还**

    * 因承租人原因使融资租赁合同被认定无效的，当事人没有约定或约定不明的，租赁物依然属于出租人，承租人应返还租赁物。

* **例外：可归承租人并给予合理补偿**

    * 出租人也可以选择不请求返还租赁物；或者虽请求返还但会显著降低租赁物利用效率的，租赁物所有权例外地归承租人。

    * 理由是该租赁物是按承租人选择购买的，对出租人可能没什么用处，对承租人更有价值，属于物尽其用的体现。

    * 归承租人所有的，承租人应给予出租人合理补偿，以补足出租人本来要靠租金收回的成本。

## 融资租赁与普通租赁的对比

* **要素对比**

    | 比较点 | 融资租赁合同 | 租赁合同 |
    | --- | --- | --- |
    | 主体 | 出租人须取得从事融资租赁业务的资格，属特许经营 | 无此资格限制 |
    | 标的（物） | 按承租人的选择专门购买，通常是价值较高的固定资产 | 常常是出租人自由的财产 |
    | 租金 | 获得融资的对价，标准相当于购买成本的大部分甚至全部加合理利润 | 使用租赁物的对价 |
    | 租期届满 | 可约定由承租人取得所有权 | 不能取得所有权 |

* **区分要点**

    * 融资租赁的每一个要素都在强调同一件事：替承租人融资，而不在于交付使用权。

    * 效力边界：租期届满由承租人取得所有权是融资租赁合同才有的效力，一般租赁不能取得所有权。

    * 与所有权保留买卖的界分：所有权保留买卖本质是买卖，出卖人直接向买受人保留所有权待价款付清再转移；融资租赁中出租人已向出卖人付清价款取得所有权，再租给承租人，租赁环节不发生所有权变动。

    * 与借款合同的界分：借款合同是直接把资金交给对方使用，融资租赁是出租人自己出资向出卖人购买租赁物。
