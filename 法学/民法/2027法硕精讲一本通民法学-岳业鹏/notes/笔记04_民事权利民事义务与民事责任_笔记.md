# 民事权利、民事义务与民事责任

## 民事权利的概念与特征

### 民事权利的定义与关键词

* **民事权利（civil right）**

    * > **定义**：民事主体为了实现某种利益，依法为或者不为某种行为的自由。

    * 概念由三要素搭成——主体、客体、内容，再加上"依法"两个字。

    * 三项特征按"拆解关键词"的思路展开：概念里每一个关键词，都对应着一项特征。

    * 民事权利是法律概念，而不是生活概念。

| 关键词 | 出自概念的哪一部分 | 展开出的特征 |
| :--- | :--- | :--- |
| 权 | "权利"的"权" | 特征一：法律赋予权利人的某种自由 |
| 利 | "权利"的"利" | 特征二：这种自由是为了保证实现某种民事利益 |
| 民事 | "民事"权利 | 特征三：自由具有法定性，是有保障的自由 |
| 依法 | "依法"二字 | 同上，即特征三 |
| 主体 | 主体要素 | 没有特殊性，教材未单列特征 |

### 三项特征

* **特征一：法律赋予权利人的某种自由**

    * 抓住"自由"二字，既对应"权"字，也对应概念三要素中的"内容"——内容体现为"为或者不为某种行为的自由"。

    * 法律把这个自由给了权利人，权利人既可以为某种行为，也可以不为某种行为。

* **特征二：这种自由是为了保证实现某种民事利益**

    * 对应"权利"里的"利"字，也对应概念三要素中的"客体"。

    * 自由不是漫无目的的，它始终指向某种利益。

* **特征三：这种自由是有保障的自由**

    * 体现法律属性：受到侵害时，国家机关可以给予保护。

    * 对应"民事权利"里的"民事"两个字；民法中以"民事"为前缀的专业术语都包含同一属性——民法规范所确认或者保护的法定性。

    * 三要素中"主体"没有特殊性，教材因此把"依法"两个字单独拎出来作为一项特征展开。

```text
民事权利的基础理论
├─ 静态：民事权利的分类（性质与类型）
│   ├─ 客体不同   → 人身权 / 财产权 / 其他权利
│   ├─ 作用不同   → 支配权 / 请求权 / 形成权 / 抗辩权
│   ├─ 效力范围   → 绝对权（对世权）/ 相对权
│   ├─ 相互关系   → 主权利 / 从权利
│   └─ 成立要件   → 既得权 / 期待权
│
└─ 动态：民事权利的行使与保护
    ├─ 行使途径   → 民事法律行为 / 事实行为
    └─ 行使原则   → 自愿原则 + 三道限制
```

## 民事权利的分类

### 网购案例模型

* 同学小马为备考 2027 法硕，在网站下单买了两本书：车老师所著的《刑法一本通》与岳母所著的《民法一本通》。

* 三天后两本书寄到小马学校，小马亲自签收。《民法一本通》质量有保障；《刑法一本通》上标着的作者是"车润梅"，与作者"车润海"一字之差，实为盗版书。

* 小马申请退货退款，但因没有把盗版书寄回去，A 网站拒绝退款，双方僵持。

* A 网站承诺：购买图书的考生法基考到 130 分，可获 1000 元奖金；网店老板龚某对该奖金的支付承担保证责任。

* 分类的原因是民法规定的权利非常多，不可能指望一条规则解决所有问题，须分门别类地设置不同规范；分类是规则精细化、科学化的基础。

### 基于权利客体：人身权、财产权与其他权利

* **人身权**：以人身利益为内容的权利，包括人格权与身份权；人格权以人格利益为客体，身份权以身份利益为客体，两者分别规定在《民法典》第四编和第五编。

    * 案例中盗版书商把作者署成"车润梅"，侵犯了车润海的署名权；署名权属于著作权当中的人身权。

    * 车润海不缺钱，但把名字署到封面上这种精神满足他在意——同学们的爱戴被错付给了车润梅。

* **财产权**：以财产利益为内容的权利，包括物权与债权；物权规定在《民法典》第二编，债权的规定在第三编。

    * 小马与网站签订买卖合同，双方各取得一个合同债权：小马可以请求网站交付图书，网站不发货小马可以催发货。

    * 书交到小马手中时，小马取得两本书的所有权，可以占有、使用、收益、处分。

* **其他权利**：兼具人身与财产双重属性的权利。

    * 继承权：基于特定身份而取得继承遗产的权利，兼具双重属性。

    * 知识产权：主要体现为财产权，但某些权利中包含人身内容，特别是著作权。

    * 股权：甲乙丙各出资 30 万设立 A 公司，三人均依法享有股权；参与分红体现财产属性，出席股东会进行表决体现人身属性。

* 这一分类实质上基于民事利益类型的不同，也正是我国《民法典》分则编展开的理论基础。

### 基于权利作用：支配权、请求权、形成权、抗辩权

* 区分标准是法律赋予当事人的自由的强弱，四个词是标准的法言法语。

| 类型 | 权利内容 | 实现条件 | 典型 |
| :--- | :--- | :--- | :--- |
| 支配权 | 可直接支配权利客体，并排除他人干涉 | 不需要相对人配合 | 物权、人身权、知识产权 |
| 请求权 | 可请求对方为或者不为一定行为 | 必须有相对人配合 | 债权 |
| 形成权 | 依权利人一方意思表示，使双方法律关系发生变动 | 相对人受领即生效力 | 解除、撤销、追认、抵销、选择 |
| 抗辩权 | 对抗对方请求权或者其他权利 | 与请求权相对应，用于防守 | 诉讼时效抗辩、三种履行抗辩、先诉抗辩 |

#### 支配权

* **支配权**

    * 权利内容体现为"支配"二字：可以直接支配权利客体并排除他人干涉。

    * 实现不需要相对人配合，效力非常强大——我的地盘完全由我来做主。

    * 民法中有三项权利是支配权：物权、人身权、知识产权。

    * 案例中所有权由小马自行决定占有、使用、收益、处分；人格权中的身体权也是如此，头发剪不剪、剪多长、剪什么发型完全由本人决定。

#### 请求权

* **请求权**

    * 内容或者作用体现为"请求"二字：可以请求对方为或者不为一定行为，实现必须有别人配合。

    * 典型是债权。甲借给车某 10 万元，可以请求车某还款，但不能支配车某的人身，也不能支配车某那 10 万元现金，所以这种权利的自由相对较弱。

    * 案例中网站未及时发货，小马不能直接去仓库拿走那两本书——法律赋予他的只是请求对方交付图书的权利。

#### 形成权

* **形成权**

    * > **定义**：依照权利人一方的意思表示，而使得双方法律关系发生变动的权利。

    * 双方法律关系的走向由一个人说了算，爱和恨由一个人操纵；效力强大，赋予权利人决定对方命运的权利。

    * 要么基于当时的约定，要么基于法律的规定，才能产生。

    * 《民法典》规定的五种典型形成权：解除权、撤销权、追认权、抵销权、选择权。

    * 案例中小马申请退货即在行使解除权，双方合同就解除了，不需要经过网站同意。

    * > **易错点**：网购系统里确实有"商家确认"流程，但法律角度上行使的是形成权，申请退货时合同就已解除。商家的确认没有法律上的意义，只是确认一下合同已被解除这个事实。

#### 抗辩权

* **抗辩权**

    * > **定义**：对抗对方请求权或者其他权利的权利，核心内容体现为"对抗"和"拒斥"。

    * 只用来防守，与请求权相对应；请求权是矛、是进攻，抗辩权是盾、是防守。

    * 理论上还可以对抗形成权的行使，这一点非常"个性"。

    * 五种典型抗辩权：总则编的诉讼时效抗辩权；合同编的先履行抗辩权、不安抗辩权、同时履行抗辩权；一般保证中的先诉抗辩权。

* **抗辩权对抗形成权**：甲对乙有 10 万元到期债权，同时乙基于买卖合同对甲享有 7 万元货款的抵销权。甲通知乙在 7 万范围内相互冲抵，是行使形成权；乙可以提出诉讼时效抗辩权对抗，导致抵销权的法律后果不能正常发生，7 万元债权不能同时被消灭。

* **案例中的同时履行抗辩权**：小马退货后有义务把书寄回，网站有义务把钱退回，两者存在对价关系；小马没有寄书，网站据此拒绝退款，行使的就是同时履行抗辩权。

* 教材对概念表述为"对抗对方请求权或者其他权利的权利"，其中"其他权利"体现的正是形成权。

### 绝对权与相对权

* 区分标准是权利人可以对抗的义务人范围有所不同，与绝对法律关系、相对法律关系的区分相对应。

* **绝对权（对世权）**：可以对抗不特定多数人、可以向全世界主张的权利；物权、人身权、知识产权是典型的绝对权。案例中小马的所有权可以向小马以外的任何人主张"这两本书是我的"。

* **相对权**：只能向特定的义务人主张、在债权人与债务人之间发生效力的权利；债权是典型的相对权。小马因下单取得的合同债权只能向该网站主张，不能要求其他网店发货。

* > **易错点**：配偶权属于绝对权。甲乙是夫妻关系，但甲的配偶权体现的不是对乙的人身权的权利，而是甲基于配偶身份取得的一系列权利，可以向包括配偶在内的不特定多数人主张。

### 主权利与从权利

* 区分标准是两种权利的相互关系。

* **主权利**：可以独立存在的权利。

* **从权利**：不能独立存在、而要从属于主权利的权利，像寄生虫一样附属某项权利而存在；主权利消灭或者转让时，从权利随之转让或者消灭——皮之不存，毛将焉附。

* 担保权是典型的从权利，从属于所担保的主债权：甲向银行贷款并以房屋抵押（按揭），银行取得抵押权；甲一次性还清贷款，主债权消灭，抵押权随之直接消灭，即使抵押权还没办注销登记。

* 案例中龚某的保证责任是主债权的从权利：网站把 1000 元奖金打到小马账户、兑现承诺后，奖金债权消灭，龚某的保证债务随之归于消灭。

### 既得权与期待权

* 区分标准是权利成立要件是否齐备。

* **既得权**：成立要件已经全部具备、权利已被当事人实际取得，民事利益已经落袋为安。

    * 图书交到小马手中时，小马取得所有权，成立条件已经具备。

    * 买卖合同成立的那一刻，买受人就已经取得请求网站履行的债权；尽管当事人可能约定了一定的履行期限，期限到来之前也不影响债权已经取得。

* **期待权**：成立条件尚未完全齐备、将来有可能实现的权利，法律也给予相应保护。

    * 两个制度体现期待权：所有权保留买卖中买受人的权利；附生效条件合同中当事人的权利。

    * 案例中 130 分奖金在小马考试之前就是期待权：即使他不一定考得到 130 分，考试之前这种期待法律也要保护，网站不能以"考到 130 分的人可能太多、本网站无力承受"为由直接撤销此前的承诺。

### 五种分类标准对照

| 分类标准 | 分类结果 |
| :--- | :--- |
| 权利客体不同 | 人身权、财产权、其他权利 |
| 权利作用不同 | 支配权、请求权、形成权、抗辩权 |
| 可以对抗的义务人范围不同 | 绝对权（对世权）、相对权 |
| 权利之间的相互关系 | 主权利、从权利 |
| 成立要件是否齐备 | 既得权、期待权 |

## 民事权利的行使

### 行使途径：民事法律行为与事实行为

* 民事权利的行使体现民事权利内容的实现，分成两条途径。

* **通过民事法律行为行使**：把自己希望变更法律关系的意思通知对方，进而使权利实现。案例中小马申请退货，是通过民事法律行为行使解除权。

* **通过事实行为行使**：小马拿到书后拿它听一本通课程、学习民法，是通过事实行为行使所有权中的使用收益权。

* 同一项权利也可以通过民事法律行为行使：选择把书送给好朋友，是把转移所有权的意愿付诸实施，同样是行使所有权。

### 行使原则与限制

* **自愿原则**：民事主体按照自己的意愿来依法行使民事权利，不受限制——既然民事权利是法律赋予当事人的自由，怎么行使由自己看着办。

* **三道限制**：

    * 受国家法律的限制，是合法原则的体现：国家对城市的土地享有所有权，但这个所有权不能卖给私人，国家再缺钱也不能卖。

    * 受社会公共利益的限制，是公序良俗的限制：自然人依法享有人身权，但双方不能形成卖淫嫖娼协议来"行使人身权"。

    * 受诚信原则的限制：可以行使权利，但不能把自己的幸福建立在别人的痛苦之上。

| 限制 | 对应的民法基本原则 |
| :--- | :--- |
| 受国家法律的限制 | 合法原则 |
| 受社会公共利益的限制 | 公序良俗 |
| 受诚信原则的限制 | 诚信原则 |

## 权利滥用的限制、认定与后果

### 绿色原则的补充

* 禁止权利滥用的原则：权利不得滥用来损害他人的合法权益，这条限制与民法的基本原则密切相关。

* 教材在写民事权利行使原则时只讲到三道限制，没有讲到绿色原则，代表写得不全面，需要自己补上。

* 民事权利的行使也要受到绿色原则的限制：虽然对某标的物享有所有权，行使所有权时仍要注意节约资源、保护生态环境。

* > **提示**：有原则有限制才完整，享有所有权不是可以为所欲为的。

### 认定规则的两个层次

* **第一层次（兜底条款）**：人民法院可以根据权利行使的对象、目的、时间、方式、造成权利人利益失衡的程度等因素，认定构成滥用民事权利。

    * 这一层把裁量权交给法院，须在具体个案中综合衡量；实践中只有出现比较极端的案例时，法院才会把当事人行使权利的行为认定为滥用民事权利。

* **第二层次（典型情形）**：以损害国家社会公共利益或者他人合法权益为主要目的来行使权利的，应当认定构成滥用民事权利——即以损害他人利益作为主要目的，完全损人，同时又不太利己。

* > **易错点**：两个层次是"具体列举 + 兜底条款"的关系，列举不等于全部。即使不符合第二项的规定，法院依然可以在具体个案里面依照第一项的规定作出认定；不能反过来说"不以损害他人为主要目的就不构成滥用"。

### 把祖母赶出孙子名下的房子

* **案情**：何甲与杜某结婚，夫妻共同购买房产一套；何甲又与吴某结婚，生子何乙；何乙再生子何丙。

* 何甲立遗嘱，将共有房产中属于自己的部分隔代赠与孙子何丙；杜某表示自己的一半也赠与何丙并配合办理变更登记，房屋登记至何丙名下，何丙取得所有权（时年 4 岁，无民事行为能力）。

* 何甲死亡后杜某继续在该房屋内居住九个月；其间何乙与吴某离婚，何丙由吴某实际抚养。

* 吴某以法定代理人身份起诉，要求 65 岁的杜某搬离房屋，杜某拒绝；法院认定吴某构成滥用民事权利，驳回诉讼请求，但何丙取得的所有权本身不受影响。

* **权利行使的对象**：吴某要把赠与房子给孩子的祖母赶走；祖母能通过正当方式体现对孙子的疼爱，孩子的妈妈却把祖母赶走，不符合社会伦理。

* **权利行使的时间**：要求杜某搬离发生在房屋过户到孙子名下不满一年（刚过九个月）时，法院感受到权利人行使权利的恶意。

* **当事人之间利益失衡程度**：杜某基于对孙子的疼爱赠与房产却被赶出，且刚丧偶、无处居住，权利行使的后果严重损害其合法权益。

* 吴某符合了规则行使权利的表面要件，但背离了权利行使的精神，法律将不再给予强制保护。

### 构成滥用之后：两项法律后果

* 构成滥用民事权利的，该权利的行使将不再产生相应的法律效力——既然认定是滥用所有权，就不能发生所有权行使的正常后果。

* 造成他人损害的，要承担侵权责任。

## 民事权利的保护

### 公力救济与私力救济

* **公力救济（国家保护）**：通过民事诉讼或者仲裁的方式实现，例如合法权益受侵害后去法院起诉。

* **私力救济（自我保护）**：通过自己的力量维护合法权益，是实体法重点强调的内容。

* 私力救济包含三项制度、两个层次：自卫行为（正当防卫、紧急避险）与自助行为；三项制度各自构成一条路径，概念都是"前提—起因—后果"三段式。

```text
民事权利的保护
├─ 公力救济（国家保护）—— 民事诉讼、仲裁
└─ 私力救济（自我保护）—— 实体法重点
   ├─ 自卫行为
   │  ├─ 正当防卫：以合法对抗不法

   └─ 自助行为：远水解不了近火
```

### 正当防卫

* **正当防卫（self-defense）**

    * > **定义**：以合法对抗不法，体现邪不压正的观念；刑法上是刑事责任的免责事由，民法上同样是民事责任的免责事由。

    * 昆山"龙哥"被反杀案：龙哥驾车与骑自行车的于海明争执，取砍刀砍向对方，于海明夺刀将龙哥捅死。于海明既不承担刑事责任，也不承担民事赔偿责任。

    * 适用前提（保护的利益范围）：国家利益、社会公共利益，本人或者他人的人身财产等合法权益受到侵害时可以启动，保护范围非常广泛。

    * 起因条件：为了免受正在进行的**不法侵害**。

    * 后果要求：在必要限度内实施制止不法侵害行为的措施，受到比例原则的限制。

    * 必要限度内的后果：因正当防卫造成损害的，防卫人不承担民事责任。

    * 超过必要限度的后果：构成防卫过当，正当防卫人应当承担适当的民事责任；是否超过必要限度只能在具体个案中判断。

* **判断是否超过必要限度的考量因素**（司法解释规定，已写进考试分析，可考多选或法条分析）：

    * 第一层次是正当防卫所面临的不法侵害的具体情况：不法侵害的性质、手段、强度、危害程度。

    * 第二层次是防卫措施的具体情况：防卫的时机、手段、强度、损害后果等因素。

    * 例证：小孩闯入果园偷食苹果侵犯了他人财产权，果园主人可以言语驱赶，但不能把小孩抓起来暴打——防卫手段与侵害方式没有形成比例对应关系，构成防卫过当。

### 紧急避险

* **紧急避险（necessity）**

    * > **定义**：体现两害相权取其轻的价值观，允许牺牲价值位阶较低的利益来保全价值位阶较高的利益，即弃车保帅。

    * 司马光砸缸：小孩爬上水缸掉进去，司马光搬石头砸碎水缸救下小孩，砸碎的缸是他人合法财产，但相较小孩生命显然微不足道，不必承担赔偿责任。

    * 适用前提：与正当防卫一样，保护范围同样广泛，包括国家利益、社会公共利益，本人或者他人的人身财产等合法权益。

    * 起因条件：为了免受正在发生的**急迫危险**，危险可能是人为原因造成，也可能是自然原因造成。

    * 后果要求：不得已而采取的紧急措施，同样受比例原则限制，否则构成避险过当。

* **紧急避险的损害救济路径**：

    * 避险人自己不承担法律责任，因紧急避险造成损害的，由**引起险情发生的人**承担民事责任——如有人把小孩推入水缸，推人者就是险情人；小孩自己掉进去的，其监护人因未尽监护职责成为引起险情发生的人。

    * 危险由自然原因引起、找不到险情人的，避险人仍不承担赔偿责任，但基于公平考虑应给予适当补偿，**因紧急避险而受益的人应当给予适当补偿**。

    * 例证：甲被恶狗追咬，夺过路过的乙的名牌包打狗，甲的人身安全高于名牌包，甲无需赔偿；损失向恶狗的饲养人、管理人主张。若是流浪狗则没有险情人，甲仍不赔偿，但要向乙适当补偿。

    * 避险过当：采取措施不当或超过必要限度、造成不应有的损害，避险人承担适当的民事责任。

* **判断避险是否超过必要限度的考量因素**（司法解释规定，已写进考试分析）：

    * 第一层次是紧急避险所面临的危险的具体情况：危险的性质、急迫程度等。

    * 第二层次是采取避险措施的相关因素：避险行为所采取的措施、所保护的权益、造成的损害后果等。

### 自助行为

* **自助行为（self-help）**

    * 民法典新增的制度，容易考到；体现"远水解不了近火"的尴尬，先解燃眉之急。

    * 例证：马某宴请后声称"我爸是马云"拒付餐费要吃霸王餐，饭店服务员揪住他不让他走；表面看限制了人身自由，但构成自助行为，不承担法律责任。坐公交车不投币、要求投币否则不准下车，同属自助行为。

    * 适用前提：**自己的**合法权益已经受到侵害，属事后救济。这与正当防卫、紧急避险形成鲜明对比：前两者除保护自己外还可保护他人、国家利益、社会公共利益，且具有"免受"的提前预防功能。

    * 起因条件（远水解不了近火）：情况急迫、来不及；不采取措施将使合法权益受到难以弥补的损害。

    * 后果要求：在保护自己合法权益的必要范围内采取扣留侵权人财物等合理措施。

    * 必要限度内的后果：即使限制了别人的财产乃至人身自由，也不需要承担侵权责任。

    * 特殊附加义务：采取合理措施以后，应当**立即请求有关国家机关来处理**——私力救济是例外。正当防卫、紧急避险没有这一义务。

    * 超过必要限度的后果：采取措施不当、造成不应有的损害，承担相应的侵权责任。例如可以把吃霸王餐的人扣下不让他走，但没必要扒光捆在饭店门口示众。

* **分水岭示例**：无票乘公交被司乘人员控制在车内直到终点站，属自助行为；到终点站后令其在调度室反省四个小时，做得过了——到站后报警即可确定逃票人身份，已无"茫茫人海找不到"的风险，超过必要限度，要承担侵权责任。

### 三项私力救济制度对照

| 制度 | 体现的价值观 | 适用前提：保护的利益范围 | 起因条件 | 后果：行为的要求 |
| :--- | :--- | :--- | :--- | :--- |
| 正当防卫 | 以合法对抗不法，邪不压正 | 国家利益、社会公共利益，本人或者他人的人身财产等合法权益 | 免受正在进行的不法侵害 | 在必要限度内实施制止不法侵害行为的措施 |
| 紧急避险 | 两害相权取其轻，弃车保帅 | 同上，范围同样广泛 | 免受正在发生的急迫危险（人为或自然原因均可） | 不得已而采取的紧急措施 |
| 自助行为 | 远水解不了近火，先解燃眉之急 | 只能是自己已经受到侵害的合法权益，属事后救济 | 情况急迫来不及，不采取措施将受到难以弥补的损害 | 在必要范围内采取扣留侵权人财物等合理措施，并立即请求国家机关处理 |

| 制度 | 必要限度内的后果 | 超过必要限度的后果 |
| :--- | :--- | :--- |
| 正当防卫 | 防卫人不承担民事责任，是民事责任的免责事由 | 防卫过当，承担适当的民事责任 |
| 紧急避险 | 避险人不承担责任；损害由引起险情发生的人赔偿，自然原因引起的由避险人适当补偿，因避险而受益的人应适当补偿 | 避险过当，承担适当的民事责任 |
| 自助行为 | 即使限制了他人财产、人身自由也不承担侵权责任；但应当立即请求国家机关处理 | 措施不当、造成不应有损害的，承担相应的侵权责任 |

* 三者在法律后果上都遵循"在必要限度内不担责、超过必要限度要担责"的同一条逻辑，但免责之后各自还拖着一串附加义务。

## 民事义务

### 民事义务的概念与特征

* **民事义务（civil obligation）**

    * > **定义**：义务人为了满足权利的利益而应当为或者不为某种行为的约束，同样由主体、客体、内容三要素形成。

    * 特征一：义务受到约束，是为了满足权利人的利益，对应民事权利中的"利"。

    * 特征二：义务人只承担法定或约定范围内的义务，强调"约束"这个关键词，对应概念中的"内容"，也可与民事权利中的"权"形成对应——法律要保障当事人的自由，不能随便约束他人。

    * 特征三：民事义务要受国家强制力的约束，体现法定属性，对应民事权利中的"法"；不履行要承担法律责任。

### 民事义务的两种分类

* **按发生根据：法定义务与约定义务**

    * 基于法律规定产生的义务是法定义务，基于当事人约定产生的是约定义务。

    * 违反法定义务，承担侵权责任；违反约定义务，产生违约责任。

* **按主体行为方式：作为义务与不作为义务**

    * 作为义务是一定行为的约束，如车某欠 10 万元债务的内容是实施按约还款的行为。

    * 不作为义务是应当不为某种行为的义务，如竞业禁止条款产生的独家授课约束即属此类。

## 民事责任

### 民事责任的概念与特征

* **民事责任（civil liability）**

    * > **定义**：民事主体因违反民事义务而应当承担的不利法律后果；关键词是"违反民事义务"与"不利法律后果"。

    * 例：甲驾车追尾撞坏乙的豪车，乙修车花 2 万元，甲赔偿损失的责任即民事责任。

* **相对性**：民事主体一方对他方应当承担的责任，发生在特定主体之间；乙只能找违反民事义务的甲赔偿，不能找别人。

* **补偿性**：功能是补偿权益的损失，原则上不具有惩罚功能；乙只能获赔 2 万元，不能要求甲赔 20 万元来体现惩罚。

    * > **易错点**：原则之外存在例外，例外时也可以产生惩罚性的赔偿责任，但原则上仍是补偿的。

* **规则性**：归责原则有的是过错责任，有的是无过错责任。侵权责任适用过错责任原则；违约责任是无过错责任，不管有没有过错，只要违反合同义务就得承担。

    * 例：北京嫣然天使儿童医院作为非法人组织仍是民事主体，签订租赁合同后未付租金即承担违约责任，与其有无过错无关。

* **任意性**：责任的内容允许当事人在法律允许的范围内协商，但"任意"不是可以随便承担责任。

    * 侵权责任可以协商免除：乙看甲送外卖不容易且有保险而自行修车，可以免除甲的侵权责任。

    * 违约责任原则上不能通过协商直接免除，双方不能以协商变更该责任的内容。

* 四项特征合起来是"对偿责任"：民事责任就是对对方的损失进行赔偿的责任。

### 财产责任与非财产责任

* 区分标准是责任的承担有没有财产的内容。

* **财产责任**：有财产内容，如赔偿损失、赔钱。

* **非财产责任**：没有财产内容，如赔礼道歉、消除影响。

* 二者都属于民事责任的范畴。

### 违约责任、侵权责任与其他民事责任

* 区分标准是违反的义务的种类不同。

* **违约责任**：违反的是合同义务。

* **侵权责任**：违反的是法定义务。

* **其他民事责任**：介于违约与侵权之间的责任，如缔约过失责任，以及无因管理、不正当得利产生的责任。

* 缔约过失为例：发生在合同的缔结过程中，此时双方还没有签订有效合同、尚未产生真正的合同义务，所以不是违约；但又与合同的订立相关，所以不是真正意义上的侵权，于是由其他民事责任兜着。

### 无限责任与有限责任

* 区分标准是承担民事责任时的财产范围。

* **无限责任**：民事主体要为自己的全部财产承担责任，有多少财产都得拿出来，倾家荡产也得还。

* **有限责任**：以自己有限的财产来承担责任，超出该财产范围的不再承担。

* 按民法的责任原则，**原则上都是无限责任，有限责任才是例外**。

* **例一：股东对法人债务承担有限责任**。老马投资 50 万成为 A 公司股东，A 公司欠银行 500 万——银行首先找 A 公司（无限责任，以全部财产清偿）；A 公司倾家荡产仍还不清的，银行不能找老马要求偿还，因为老马只在认缴的 50 万范围内承担责任。

  * 制度目的是鼓励投资：收益（分红）不设上限，风险最多锁定在 50 万；若股东要倾家荡产还债，投资风险太高，就无人敢投资。

* **例二：限定继承**。甲因还不起贷款自杀，把烂摊子留给儿子乙；甲死亡后债权债务本应概括地由乙承受，但乙只在接受遗产的价值范围内对甲的债务负清偿责任——只继承 10 万元遗产，就只在 10 万元范围内承担清偿责任。

  * 民法不采纳"父债子偿"的观念：否则上一代人的不当行为会使下一代人一辈子翻不了身，对下一代人不公平。

```text
银行 ──要 500 万──▶ A 公司    无限责任：拿自己的全部财产清偿，
                                       倾家荡产也得还这 500 万
             还是还不清
             ↓
银行 ─────要────▶ 股东老马    有限责任：只在认缴的 50 万以内承担
```

### 单独责任与共同责任

* 区分标准是承担民事责任的主体人数：只有一个人承担责任的是单独责任，两人以上的是共同责任。

* 两个以上的责任主体共同承担责任时，因承担方式不同进一步分为四种类型。

#### 按份责任

* **按份责任（proportional liability）**

    * 两个以上的责任主体按照一定的份额各自承担自己的责任。

    * 无法确定份额的，平均承担：甲乙对丙负 10 万元按份赔偿责任，甲承担 5 万、乙承担 5 万。

    * **只有对外关系，没有对内关系**，相对简单。

    * 甲已还自己那 5 万后，丙不能再找甲，也不能向乙追偿。

```text
丙 ──要 5 万──▶ 甲      ┐
丙 ──要 5 万──▶ 乙      ┘  各还各的，互不相干
甲已还 5 万 → 丙不能再找甲，也不能向乙追偿
```

#### 连带责任

* **连带责任（joint and several liability）**

    * 对外关系：数个责任主体作为一个整体承担，每个责任主体都义务承担全部的责任，对外代表全体。

    * 对内关系：关起门来仍按各自份额分摊，超出自己份额的部分可以向其他人追偿。

    * 例：甲乙对丙承担 10 万元连带还款责任，丙找甲可以要 10 万，找乙也可以要 10 万；内部份额各 5 万，甲对外还了 10 万，超出的 5 万可以向乙追偿。

* 连带责任既涉及对外关系，也涉及内部关系，因而产生追偿关系。

```text
对外：丙 ──要 10 万──▶ 甲
      丙 ──要 10 万──▶ 乙    整体对外，谁都欠 10 万

对内：甲 5 万 ／ 乙 5 万
      甲多付的 5 万 ──追偿──▶ 乙
```

#### 不真正连带责任

* **不真正连带责任（untrue joint and several liability）**

    * 与连带责任的相同之处在于对外关系：数个责任人作为一个整体承担，任何一个责任主体对丙都负有全部责任，任一人清偿 10 万都导致对外关系消灭。

    * 不同之处在对内关系：不是按份额分担，而是由**一个**责任主体扛下所有，存在一个最终承担人。

    * 例：由乙承担最终责任，则内部 10 万全由乙承担、甲不承担内部责任。乙对外还了 10 万后不能向甲追偿；甲对外还了 10 万导致对外关系消灭后，可以向乙**全额追偿 10 万**，而不是按份额追偿 5 万。

    * 这是与连带责任最大的区别：连带中存在份额分担，不真正连带中对外扛雷的人在关起门来的内部没有责任。

```text
对外：丙 ──要 10 万──▶ 甲
      丙 ──要 10 万──▶ 乙    与连带完全一样

对内：乙 扛 10 万 ／ 甲 0   只有乙是"最终承担人"
      甲对外还了 10 万 ──全额追偿──▶ 乙   （不是 5 万）
      乙对外还了 10 万 ──不能向甲追偿
```

#### 补充责任

* **补充责任（subsidiary liability）**

    * 数个责任主体承担责任时有先后顺序，有主力、有替补；先顺位的责任人先承担，承担不了的部分再由补充责任人承担。

    * 例：甲乙对丙承担 10 万元赔偿责任，甲是第一顺位，丙必须先找甲，能要多少算多少。甲赔满 10 万时第二顺位的乙没有责任；甲只赔 7 万时，丙还能找乙要 3 万。

    * 顺位之间不发生追偿。

```text
第 1 顺位 甲：丙先找他，能要多少算多少
        ├─ 要到了 10 万 ──▶ 第 2 顺位的乙无责任（他只是替补）
        └─ 只拿到 7 万 ──▶ 丙还能找乙要 3 万
```

#### 四种共同责任对照

| 类型 | 对外关系 | 对内关系 | 能否追偿 |
| :--- | :--- | :--- | :--- |
| 按份责任 | 各人各还各的份额 | 无内部分配 | 不能 |
| 连带责任 | 作为整体，每个人对外都负全部 | 按份额分摊 | 超额部分可向他人追偿 |
| 不真正连带责任 | 同连带，每个人对外都负全部 | 由一个最终承担人扛下全部 | 只有"最终承担人"之外的人对外还了才能全额追偿 |
| 补充责任 | 有先后顺位，先找第一人 | 承担前一人承担不了的部分 | 顺位之间不发生追偿 |

* 何时用按份、何时用连带、什么是不真正连带责任、什么是补充责任属于分则内容；此处只描述四种共同责任的具体承担规则。

### 承担民事责任的具体方式

* 承担方式是一个"大拼盘"，把违约责任、侵权责任等各自的方式汇总，分则还会再见到。

| 承担方式 | 例子 |
| :--- | :--- |
| 停止侵害 | 侵犯他人财产权或人身权时，可要求停止侵害，防止损失扩大 |
| 排除妨碍、排除妨害 | 甲把车停在饭店门口，出来时前面被乙的车挡住，可请求乙挪车 |
| 消除危险 | 甲要在自家院里打井且位置离乙的房子后墙很近，乙可要求换一个远一点的位置 |
| 返还财产 | 甲的手机被乙偷了，甲可请求返还 |
| 恢复原状 | 甲撞坏乙的车，乙可请求甲修车恢复到被撞之前的状态 |
| 修理、重作、更换 | 甲在乙网站买的手机寄到时屏幕破损，可要求修好或更换一部合格手机 |
| 继续履行 | 甲嫌房子卖低了不想卖，乙可请求甲交付房屋并配合办理过户登记 |
| 赔偿损失 | 因违约造成对方损失要赔偿，因侵权造成对方损失也得赔偿 |
| 支付违约金 | 当事人提前约定任何一方违约要支付 10 万元违约金 |
| 消除影响、恢复名誉 | 甲把乙的裸照发到网上侵犯隐私权要消除影响；侵犯名誉权还可要求发布声明恢复名誉 |
| 赔礼道歉 | 救济人身损害，不仅是道德上的义务，也是法律责任的承担方式 |

* > **提示**：名称上的细节要分清——在**人格权**里叫"排除妨碍"，在**财产权**里叫"排除妨害"。

* 各种方式可以单独适用，也可以合并使用：侵犯名誉权既可恢复名誉又可赔礼道歉，造成财产损失还要赔偿损失。

* **适用范围**：

| 适用范围 | 承担方式 |
| :--- | :--- |
| 违约、侵权都能用 | 赔偿损失 |
| 只能用于违约 | 继续履行、支付违约金 |
| 只能用于侵权 | 赔礼道歉 |
| 只能救济人身权益损害 | 消除影响、恢复名誉、赔礼道歉 |

* 消除影响、恢复名誉、赔礼道歉只能救济人身权益损害，不能救济财产损失。

* 责任承担方式主要目的是弥补对方损失，只有在例外的时候才适用惩罚性赔偿的规定，惩罚性赔偿在侵权责任编展开。

### 总则编的四项免责事由

* 广义上的免责事由是"抗辩事由"的概念，既包括不承担责任的情形，也包括减轻责任的情形；此处只讲《民法典》总则编规定的四项。

* **不可抗力**

    * > **定义**：不能预见、不能避免且不能克服的客观情况——"三个不能，一个客观"。

    * 最典型的是自然灾害，如地震、泥石流、洪水。

    * 在我国民法典中既是违约责任的免责事由，也是侵权责任的免责事由。

    * 侵权例证：甲的房子在地震中倒塌压坏乙停放在路边的豪华轿车，损害后果由不可抗力造成，甲不承担赔偿责任。

    * 违约例证：甲已支付房款但房屋在交付前因地震倒塌，乙无法履行交付义务，不承担违约责任。

    * > **易错点**：法律另有规定的依照其规定——合同编与侵权责任编都有特殊场景，即使发生不可抗力、没有履行相应义务也仍要承担法律责任，先要记住它是有例外的。

* **正当防卫**：属于权利的自力救济方式，是民事责任的免责事由，详见前述。

* **紧急避险**：同样属于权利的自力救济方式，详见前述。

* **紧急救助行为**

    * 因自愿实施紧急救助行为造成受助人损害的，救助人不承担民事责任。

    * 例：好心人用心肺复苏对素不相识者实施紧急救助，救回一条命但致其几根肋骨被压断，不承担肋骨损害的赔偿责任。
