# 担保权的竞合与占有制度

## 混合担保

```text
  同一债权挂了好几把担保
                        主债权 100 万
                    （乙公司 对 甲公司）
                              │
         ┌────────────────────┼────────────────────┐
         │                    │                    │
    甲公司提供           丙公司提供           丁公司提供
   机器设备抵押         保证（人保）        房产抵押＋登记
   ＝债务人自保           ＝第三人             ＝第三人
         └─────第 1 顺位──────┴─────第 2 顺位──────┘
                              │
                       乙公司在此挑选
                              │
  先实现甲的设备抵押 → 不足部分：先找丙  或者  先找丁
  若乙放弃甲的物保 → 丙、丁可在乙“丧失优先受偿权”的范围内免责
```

* **混合担保（mixed security）**

    * > **定义**：同一项债权上有数个担保，而且数个担保中既有人保、也有物保。

    * 模型结构：甲公司欠乙公司货款 100 万，乙对甲享有 100 万的主债权；甲以机器设备设定抵押（债务人自保），丙公司提供保证（人保），丁公司以房产设定抵押并办理登记（第三人物保）。一个主债权配三个担保，即混合担保。

    * 要解决两个层次的问题：债权人面对多个担保先选哪个、后选哪个；实际承担责任的担保人如何行使追偿权。

### 担保权的行使顺序

* **行使顺序的三步规则**

    * 第一步按约定来：当事人对清偿顺序有明确安排的，按当事人的安排办，尊重意思自治。
    * 第二步没有约定或者约定不明确的，看有没有债务人提供的物保；有的话必须先实现债务人提供的物保。
    * 第三步：实现完债务人物的物保后，不足的部分才能向其他担保人主张担保责任，此际债权人享有选择权。

* > **注意**：债务人提供的物保优先是对债权人行使担保权的一种限制，不能越过债务人直接选择第三人（丙或丁）承担担保责任。

* **模型案例的展开**

    * 甲到期不能清偿时，乙先实现甲的设备抵押；不足部分既可以先让丙承担保证责任，也可以先实现丁的房产抵押，选择权在乙手里。
    * 其他担保人只有在乙先实现甲的物保之后才进入候选名单。
    * 变体：甲以自己价值 50 万的房产抵押、丙以自己价值 50 万的房产抵押、丁提供保证，甲不能履行到期债务的，乙应当先实现甲的房屋抵押权；剩余 50 万再在丙的抵押与丁的保证之间选择。

* **放弃债务人物保的后果**

    * 债权人放弃债务人提供的物保的，其他担保人可以在债权人丧失优先受偿权的范围内主张免责。
    * 该规则与"未经登记不得对抗善意第三人"是同一思路：分配权利人自己放弃利益所带来的后果——前者是债权人放弃登记利益、其他担保人按比例免责，这里是债权人放弃债务人自物的担保、其他担保人在相应范围内脱身。

### 担保人的追偿

* **追偿的基本规则**

    * 提供担保的第三人承担责任以后，有权向债务人追偿。
    * 原则上担保人之间不能相互追偿：哪个担保人被债权人挑中了，谁就得扛下全部责任，自己去找债务人追偿，其他担保人责任就地解脱。
    * 模型案例中乙最终选择丁承担，丁还清后可以找甲追偿，丙的担保责任随之解脱。

* **禁止相互追偿的立法理由**

    * 担保人之间往往根本没有共同分担的意思：实践中一个债权可能挂着三个抵押权、五个保证人，担保人之间可能根本不知道彼此存在；即便知道，因没有明确约定，同样难认定有分担担保责任的意思；而与债权人签订担保合同时就已经作出了单独承担该担保责任的意思表示。
    * 允许相互追偿会让更多民事主体掉进诉讼泥潭：三个担保物权人、五个保证人相互追偿会产生大量官司，要么被别人告要么去告别人，严重影响企业正常经营活动。
    * 立法机关在这里做了一次权衡——牺牲一个，幸福千万家。

* **可以相互追偿的例外情形**

    * 以下四类由担保制度司法解释规定，属于例外；不存在这些情形的，担保人只能找债务人追偿。

    | 情形 | 能否相互追偿 | 附带的限制 |
    | :--- | :--- | :--- |
    | 担保人之间约定了相互追偿，且明确约定了分担的份额 | 可按约定的份额追偿 | 无 |
    | 约定了相互追偿但没有约定份额 | 可以相互分担损失 | 必须先找债务人追偿，追偿不能的部分再找其他担保人分担 |
    | 约定了承担连带共同担保，只是没有明确具体份额 | 可以相互分担损失 | 同上 |
    | 没有约定相互追偿，也没有约定连带共同担保，但各担保人在同一份合同书上签名（按指印） | 可以相互分担损失 | 同上 |

    * > **易错点**：四条例外中，只有"约定了相互追偿且约定了分担份额"这一条没有顺序限制，可以直接按份额找对方追偿；其余三条都必须"先找债务人、后其他担保人"。

    * 立法逻辑：禁止相互追偿主要考虑的是担保人之间常常没有分担的意思；一旦当事人明确约定相互追偿且约定了份额，这意思表示不能再明确，必须尊重意思自治，按约定份额追偿。
    * 第二、三、四条加同一顺序限制，是为了最大限度避免担保人被拖进诉讼纠纷——先让债务人扛一波，实在扛不住了再在担保人之间分摊。
    * 第三种情形对后签的担保人其实也是一种保护：先让债务人挡一波，毕竟最终该承担责任的是债务人。

* **例外套回模型案例**

    * 丙与丁明确约定各自承担 50% 的担保责任：丙承担责任后可以找丁追偿一半，丁也可以找丙追偿一半；丙、丁最终当然都还可以向债务人甲公司追偿。
    * 丙与丁约定相互分担但没有约定份额，或者只约定连带负责：可以相互追偿，但丙必须先找债务人甲公司追偿，追偿不能的部分再找丁公司分担。
    * 丙与丁没有约定相互追偿或连带担保，但在同一份合同书上签名盖章、按指印：丙可以请求丁分担，仍须先找债务人甲公司追偿，追偿不能的部分再找丁分担。
    * 不属于上述任何一种：丙承担责任以后，只能向债务人甲公司追偿。

## 同一动产上数个担保物权的受偿顺位

* **竞合的成因**

    * 担保物权没有严格的排他性，同一项财产上完全可能出现数个担保，物权人之间就必然要确定优先顺位。

* **两条边界**

    * 同一种类担保的顺位（以抵押权为例，抵押权没有排他性，同一财产上完全可能出现数个抵押权）：都办理登记的按登记的先后；一个登记、一个未登记的，登记的优先于未登记的；都没有办理登记的按比例清偿。
    * 不同种类担保的顺位只可能出现在动产上：不动产只能设定抵押；动产可以设定抵押、质押、留置，才会出现不同种类担保物权的竞合。

### 顺位三档

```text
  同一动产上的担保物权顺位（三档）

  ┌──────────────────────────────────────────────┐
  │ 第 1 顺位   留 置 权                         │
  │ 法定担保物权，最后设立也最优先               │
  ├──────────────────────────────────────────────┤
  │ 第 2 顺位   抵押物价款的超级优先权           │
  │ 价款债权＋交付后十日内登记                   │
  │ （唯一能插到浮动抵押权人前面的人）           │
  ├──────────────────────────────────────────────┤
  │ 第 3 顺位   一般的抵押权 与 质权 并存        │
  │ 只看谁先完成公示（登记 / 交付）              │
  │ 两个以上价款优先权之间：按登记先后           │
  └──────────────────────────────────────────────┘
```

* **留置权占据第一顺位**

    * 留置权是法定的担保物权，因此尽管这份财产上先设立了抵押、质押而后才被留置，留置权最后出现却要最优先实现；法定担保一律最优先。
    * 留置权是唯一的例外，没有人能插到它前面。

* **三档结论**

    * 第一位是留置权（法定担保，最后设立也最优先）；第二位是抵押物价款的超级优先权；第三位看抵押权和质权谁先完成公示，谁先公示谁更优先。

* **三档叠加的真题例证**

    * 甲向乙借款并把汽车抵押给乙且办理登记；后甲又向丙借款并把该车质押给丙；质保期间车有故障送到丁厂修理未付钱被丁留置。三种担保物权并存时，留置权排第一（最后设立但属法定担保），抵押权与质权看谁先完成公示，抵押权登记在先、质权后来才交付，故抵押权优先于质权。

### 抵押物价款的超级优先权

* **抵押物价款的超级优先权（super-priority for purchase-money security interest）**

    * > **定义**：《民法典》第 416 条——动产抵押担保的主债权是抵押物的价款，标的物交付后十日内办理抵押登记的，该抵押权人优先于抵押物买受人的其他担保物权人受偿，但是留置权人除外。

    * 名称辨析：有的教材称"超级抵押权"，称"超级优先权"更严谨，因为其适用范围包括但不限于抵押。
    * 这是《民法典》里理解起来最难的条文之一，但抓住"再融资"这个词，整个制度就通了。

* **构成条件**

    * 条件一：动产抵押担保的主债权是抵押物的价款，即价款债权——主要指甲公司购买新财产时付不出价款、提供融资的债权人。
    * 条件二：标的物交付后 10 日内办理抵押登记。

* > **易错点**："十日内"包括本数，第十天办登记也能赶上、仍有插队机会；十天内没有办登记的，尽管动产抵押权在合同成立时即可设立，也只能作为普通的抵押权人按顺序排队受偿。这十天内办登记，就是插队的一个宽限期。

* **效力定位**

    * 拿到这张"VIP 卡"的价款债权人不受普通担保权人一般清偿顺序的限制，可以直接插到其他担保权人之前；它主要插的是动产浮动抵押权人与银行的队。
    * 能不能插到留置权人之前：不能。超级优先权是"一人之下、万人之上"的权利，除了卷不过留置权以外，其他担保权统统排在它后面。

### 超级优先权的立法目的

* **两层次立法目的**

    * 一是方便企业再融资，二是建构一个可操作的适用模型。

* **再融资困境的形成**

    * 甲公司值钱的房产、设备等优质财产都已抵押出去，只剩零零碎碎的原材料、半成品、产品，单个拿出来不值钱但打包还值点钱，于是把现有财产与将有财产一起设定动产浮动抵押获得融资。
    * 在《民法典》生效之前，动产浮动抵押是绝大多数企业从银行获得融资的最后一次机会；甲公司想扩大经营、购买新设备再融资就非常难，因为他新买的任何财产都会落进银行浮动抵押的财产范围（属于将有财产）。
    * 即使有人再提供融资，设定担保时也只能屈居第二顺位——第一顺位已被办了登记的银行占住，顺位毫无保障，自然没人再敢借钱。
    * 超级优先权制度就是用来破这个局的：谁敢给处在困境中的甲公司提供融资、让新标的物扩大生产，法律就出手给予额外保障。

* **可想象的图景**

    * 甲公司付不起对丙公司的设备价款，丙要求以该设备设定抵押并担保欠付价款债权，丙属于价款债权人且三天内办理登记；后甲既不还银行的钱也不还丙的欠款，拍卖这台刚买的设备，丙更优先——尽管登记顺序上银行办理在先，但丙是拿着 VIP 卡的人，可以插队到银行之前。

* **适用场景的常见形态**

    * 实践中出现频率最高的场景是"先有一个动产浮动抵押，然后购买新财产"；但这并非绝对，保留所有权的出卖人没有动产浮动抵押权设立时也会出现价款优先权的情形，只是相对少见。

### 价款债权人的范围

* **司法解释展开的三类价款债权人**

    | 价款债权人的类型 | 通俗理解 | 对应的例子 |
    | :--- | :--- | :--- |
    | 在该动产上设立抵押权或者保留所有权的出卖人 | 东西卖出去了、钱没收，还顺手留了一手担保 | 例一、例二 |
    | 为价款的支付提供融资而在该动产上设立抵押权的债权人 | 买家差的那笔钱，是别人借给他的 | 例三、例四 |
    | 以融资租赁方式出租该动产的出租人 | 钱本来就是出租人出的 | 融资租赁关系中的出租人 |

* **第一类：出卖人**

    * 形态一是在转移所有权以后于该动产上设定抵押权：如甲公司从丙公司购买设备未付款，丙把设备交付给甲，只要求"你得把刚买的这个设备抵押给我"。
    * 形态二是没有转移所有权、保留所有权的出卖人：如甲公司向乙公司购买一批设备，约定一年内分四期付款、付清价款后再取得所有权。
    * 乙公司保留所有权的目的不是占有、收益、处分设备，而是担保自己未收到的价款债权，故仍是价款债权人。
    * 保留所有权的出卖人也能插队：甲收到设备第二天就把设备抵押给丙银行取得借款，此时甲未取得所有权，抵押属于无权处分，银行善意的可以善意取得该抵押权；办理登记三天后甲乙才办了所有权保留的登记（所有权保留也可以办理登记）。后拍卖设备，乙公司优先受偿——它既是价款债权人中保留所有权的出卖人，又确实在十天内办了登记。

* **第二类：为价款支付提供融资的债权人**

    * 通俗讲就是"抵押人"：支付价款时钱不够，别人借钱给你你才付的价款，那借钱给你的人也是价款债权人；只要在十天内办理登记，同样可以插队。
    * 例证：甲向银行借款设定动产浮动抵押，后为扩大生产要向丙购买一套生产设备但丙不赊账，甲向丁借 50 万才付清价款，丁要求以该设备设定抵押并在交付后三天办理登记。后卖掉设备，丁优先受偿——丁借钱的用途正是支付购买设备的价款，且十天内办理了登记，可排在动产浮动抵押权人之前。

* **第三类：以融资租赁方式出租该动产的出租人**

    * 融资租赁中购买租赁物的钱实际都由出租人支出，所以出租人的债权也是价款债权；只要在十天内办理登记，同样可以插队。
    * 融资租赁本身就是一种非典型担保制度，可以发挥担保功用，其规则在合同编展开。

### 数个价款优先权并存

* **顺位规则**

    * 同一动产上出现多个价款优先权时，按登记的时间先后确定受偿顺序：都在十天内办了登记、都能插队的人当中，登记更早的排得更优先。

* **例四的推演**

    * 甲向乙银行借款设定动产浮动抵押并办理登记；后向丙购买一套新设备，总价款 100 万，先付 70 万（其中自己只有 40 万，向丁借了 30 万），剩余 30 万半年内付清。
    * 丙与丁都要求以购得的设备设定抵押，设备交付后第三天甲先后为丙、丁办理抵押登记，丙登记在先、丁登记在后。

* **三种主体的最终位次**

    * 丙是在动产上设立抵押的出卖人，丁是为支付价款提供融资的债权人，两人都是价款债权人都能插队。
    * 丙与丁之间按登记先后，丙公司登记在先，丙排在丁前面。
    * 丁虽然在这场 PK 里输了，仍然优先于乙银行，因为他满足了这个优先权的保障条件。
    * 最终受偿顺序：丙公司先拿钱，丁再拿钱，银行最后拿钱。

### 抵押权与质权并存

* **公示先后决定顺位**

    * 抵押权与质权并存时，看公示的先后：抵押权先办登记的抵押权优先，质权先完成交付的质权优先。
    * 例一：车某为买学区房向老马借款 100 万，把爱车抵押给老马并办理登记；后又向岳母借款 100 万并把车交付给岳母设定质权。卖车后老马优先——抵押权先完成了公示。
    * 例二：车某先向老马借 100 万并把车抵押给老马但未办理登记，后又向岳母借 100 万并把车交付给岳母。岳母调查后发现车辆已抵押给老马仍接受并完成交付，卖车后岳母优先——老马的抵押虽设立在先但没有登记，岳母的质权虽在后但完成了交付。

* **不考虑知情，规则是《民法典》新设置的**

    * 抵押权与质权并存时只看谁先完成公示，不考虑排在后面的质权人知不知情。
    * 理由：实践中排在后面的质权人如果一点风险意识都没有、也不作任何调查，他是不知情的，可以获得保护；反倒是谨慎调查后发现未登记事实仍接受设定质权的当事人处在不利地位，不利于鼓励交易当事人在交易时进行相应调查。

* **不能套用"未经登记不得对抗善意第三人"**

    * "未经登记不得对抗"的四类情形是抵押物的善意受让人、抵押物的善意承租人、已经对抵押物采取强制措施的债权人、破产程序中的债权人，没有一项涉及其他担保物权人。
    * 担保物权发生竞合时，要按担保物权的顺位规则解决权利先后，而不是套用"未经登记不得对抗善意第三人"的规则。
    * 抵押权人之间的顺位同样适用抵押权顺位规则：登记的优先于未登记的，不要求未登记的人善意——只要我办了登记而你没办，我当然就优先于你。
    * 例证：车某先把车抵押给老马未办登记，后又抵押给谨慎调查过的岳母且办了登记，属知情的抵押权人。卖车后岳母优先，因为这里解决的是抵押权顺位问题，与"未经登记不得对抗善意第三人"无关。

## 占有的性质与构成

* **占有（possessio, possession）**

    * > **定义**：占有不是一种权利，只是一种事实；描述的是物在事实上被某人以管理力加以控制的状态。物在你的控制之下，就叫这个物在你的占有之下。

    * 特征一：占有的客体仅限于有体物。物权的客体可以是特定的物，也可以是法律规定的权利；占有的对象只能是有体物。对权利的控制叫准占有。
    * 占有的对象还可以是物的组成部分：一套三居室中的单个卧室只是组成部分、不是独立的物，不能成为物权的客体（物权客体只能是独立完整的物），但可以成为占有的对象。
    * 特征二：占有必须是对物产生了事实上的支配和控制，即在实际地控制着它。

* **占有入编物权编的理由**

    * 占有虽然不是物权，甚至标题里都没有"物权"二字，但民法典把它放在物权编最后：它描述的是"这个物在谁的控制之下"这种状态，与物权的支配效力非常相像；同时它也是物权行使的一种表现形式。

* > **易错点**：物权客体是独立完整的物（外加法律规定的权利），占有客体是有体物且可以是物的组成部分，两者的范围不一样。

## 占有的分类

### 有权占有与无权占有

* **区分标准是本权**

    * 有本权、有根据的占有叫有权占有；没有本权的就是无权占有。
    * 本权不限于物权：质权人、留置权人占有的本权就是质权、留置权；债权也可以成为占有的根据，借来的手机、租来的房子、帮别人保管的财产都是有权占有；其他法律关系或者法律规定的根据也可以，监护人占有被监护人的财产即依法律规定的根据而产生的有权占有。
    * 小偷偷来的手机虽有适当控制，但没有占有的本权，是无权占有。

* **区分的意义**

    * 返还原物请求权的行使对象是现实的无权占有人，这意味着物权人不能对有权占有人主张返还原物。
    * 无权占有不能享有留置权，留置权以合法占有作为前提。

### 善意占有与恶意占有

* **适用前提是无权占有**

    * 区分标准是无权占有的心理状态：不知道自己是无权占有、也不应当知道的，是善意占有人；知道或者应当知道自己没有占有本权的，是恶意占有人。
    * 借来的手机属于有权占有，与善意、恶意占有没有关系，不能归入其中任何一类。
    * 分水岭不是"是不是在占有"，而是"知不知道自己没有本权"。

* **善意与恶意的法律后果不同**

    | 比较项目 | 善意占有人 | 恶意占有人 |
    | :--- | :--- | :--- |
    | 返还占有时的范围 | 返还原物，并返还原物产生的孳息 | 同左，二者无本质区别 |
    | 使用占有物造成损害 | 不需要赔偿 | 承担无过错赔偿责任 |
    | 占有期间支出的费用 | 可向权利人主张返还必要费用 | 不能主张返还任何费用 |
    | 占有物已毁损、灭失 | 只返还现存利益；没有现存利益的就不用赔偿 | 返还现存全部利益，并承担赔偿责任 |
    | 能否善意取得 | 有可能善意取得 | 不可能善意取得 |

* **差异的起点与理由**

    * 既然大家都是无权占有人，返还的范围没有本质区别，真正开始出现区别是从"使用造成损害"这一栏往下。
    * 善意占有人使用造成损害不用赔，是因为他当初以为这是自己的东西：用自己东西难免马虎，开自己的车就放松；不能怪他马虎就不能让他赔。恶意占有人明知是别人的还拿去用，应当承担无过错赔偿责任。
    * 费用一栏的关键词是"必要费用"：善意占有人可主张返还必要费用（如修车费），恶意占有人一分钱都主张不回来。

* > **易错点**：善意占有人是"有可能"善意取得，不是"都能"善意取得；善意只是善意取得的要件之一，其他要件还得同时满足。

* **善意与恶意会转化**

    * 丙错认他人自行车：起初把乙车当成甲车骑走，不知情，是善意占有；后来甲告知他骑错了而他不予理睬，从此变为恶意占有人。
    * 同一件纠纷在不同时间点上可能适用完全不同的规则：刚开始是善意就适用善意规则，知道以后转为恶意就适用恶意规则。
    * 反向转化（原来知道自己无权占有、后来失忆）在实践中很少发生。

* **判断示例**

    * 甲将拾得的手表赠与不知情的乙：乙的占有没有本权（拾得人不能取得所有权，无权赠与），属无权占有；乙不知情故为善意占有；手表在乙的控制之下属直接占有；乙以取得所有权的意思在占有属自主占有。
    * 丙误将他人的自行车当作保管人的遗产继承并在使用中致损：丙不知情即为善意占有，但仍是无权占有人，负有返还原物的义务；丙与真正的车主之间没有合同关系不成立违约责任；损害是使用占有物造成的，善意占有人对此不承担赔偿责任。

### 直接占有与间接占有

* **直接占有（direct possession）**

    * 占有人可以对物进行直接控制的，是直接占有；生活中理解的占有其实都是直接占有。

* **间接占有（indirect possession）**

    * > **定义**：对直接占有人基于特定的法律关系有返还请求权，也可以构成间接占有人。

    * 例证：甲把手机出租给乙，手机在乙的控制之下，乙是直接占有人；但甲并未丧失占有，因为租赁合同终止时甲对乙有返还请求权，甲通过租赁合同对物进行间接的控制，是间接占有人。
    * 这个词是纯粹法律上的概念，体现了占有的观念化：判断一个人是不是占有人，不能只从事实上看他有没有直接控制这个物，而要从观念上看他对这个物有没有控制力。

    ```text
         甲 ──── 租赁合同（到期返还请求权）────> 乙
       间接占有                                  直接占有
         │                                          │
         └────────────── 物：手机 ─────────────────┘

      甲的手没有碰到这台手机，但他凭租赁合同产生的返还请求权，
      在观念上仍然能支配它 —— 这就是间接占有
    ```

* **间接占有的两项意义**

    * 其一，占有的保护范围被扩大：像甲这样的间接占有人也可以主张民法典关于占有保护的相关规定。
    * 其二，使得物权编里的"观念交付"形态得以成立：交付就是转移占有，转移直接占有是交付，转移间接占有同样是交付。

* **观念交付的两种形态**

    * 指示交付（先租再卖）：甲先把手机租给乙，后又把手机卖给丙。甲把对乙的返还请求权转让给丙来代替交付；甲虽把手机租给了乙但仍是间接占有人，转让返还请求权就相当于把间接占有的地位转移给了丙。
    * 占有改定（先卖后租）：甲先把手机卖给乙，双方约定甲租用该手机两个月、到期再交付。交付通过签订两个合同完成——签订租赁合同时，乙对已成为直接占有人（原所有权人）的甲取得了返还请求权，乙取得间接占有。

### 自主占有与他主占有

* **区分标准是占有人有无所有的意思**

    * 以所有权的意思而占有的是自主占有；非以所有的意思而占有的是他主占有。
    * 这里只看当事人自己的主观意思，其他人心里怎么想一概不予考虑。

* **典型情形**

    * 甲自己买的手机是自主占有；手机被乙偷了，乙虽不能取得所有权，但说服自己"我偷来的当然就是我的"，主观上以所有的意思占有，同样构成自主占有。
    * 甲把房子租给乙，乙的占有是他主占有——他知道这房子是租的；他同时是有权占有。
    * 甲的手机丢了被乙捡到，乙积极寻找失主：既是他主占有，同时因实质上对手机没有占有的本权而是无权占有。

* **与其他分类维度可以自由交叉**

    * 自主占有、他主占有都可以是有权占有，也都可以是无权占有；它们与"有权/无权""善意/恶意"是完全不同的分类维度。

## 占有的效力

```text
     事前 ─────────────> 事中 ─────────────> 事后
   权利推定              权利取得               保护效力
   占有 ⇒ 推定权利人    善意取得 / 取得时效     被侵夺后可主张保护
```

* **权利推定的效力**

    * 谁是占有人，就推定谁是权利人。看到某同学拿着一部新手机，不能上去要求他"证明一下"；东西在其占有之下就推定他是权利人。

* **权利取得的效力**

    * 占有人有可能取得这个物上的权利：占有的事实状态加上主观上的善意，可以善意取得物权。
    * 当代民法里占有的取得效力最典型的例子是取得时效制度——无权、善意、公开、和平地占有某个物达到一定期间，可以取得所有权。

* > **注意**：取得时效我国民法典没有规定，它又叫消灭时效，与取得时效正好相对应。

* **保护效力**

    * 占有被侵夺的，可以主张法律上的保护。

## 占有的保护制度

* **为什么保护占有**

    * 占有虽然不是一种民事权利，但占有的状态代表和平的社会秩序，法律给予保护。

* **三层保护框架**

    * 第一层通用的保护制度：侵害人格权可以主张损害赔偿，侵害物权可以主张损害赔偿，侵害别人的占有并造成损害的同样可以主张损害赔偿。
    * 第二层绝对权的保护：通用的绝对权保护方法叫绝对权请求权；占有虽然不是绝对权，但对物的控制也是支配效力的体现，民法里有"占有侵权"来保护它，有点类似物权侵权。
    * 第三层特别的保护制度：这一层主要是模板，重点实际落在前两个层次上。

* **两项具体请求权**

    * 占有物的返还请求权：外观上对应物权请求权里的原物返还请求权，配套还有排除妨害请求权和消除危险请求权——妨害已经发生的主张排除妨害，有可能发生的主张消除危险。
    * 损害赔偿请求权：占有虽不是民事权利，但也是法律保护的民事利益，侵夺或妨害占有造成损害的，占有人可以主张损害赔偿。

* > **结论**：从考试角度讲，重点掌握占有请求权的形式要件。

## 占有返还请求权

* **它与原物返还请求权是两项完全不同的制度**

    * 外观上非常像，但考试里问"能不能主张返还原物"就按物权请求权的要件判断，问"能不能主张返还占有"就按占有返还请求权的要件判断，别混。

* **四个要件**

    * 请求人是占有人：有权、无权，善意、恶意，直接、间接，自主、他主，各种占有人都可以主张。
    * 占有必须被侵夺：一定是违反占有意思、通过积极的不法行为来侵夺他人的占有才适用；东西被偷、被抢属于占有被侵夺。
    * 相对方得是现实的无权占有人：首先是现实的，其次是无权占有人。
    * 行使期间：自侵占发生之日起一年内行使。

* **期间是不变期间**

    * 一年从侵占发生之时开始计算，期间不给中止也不给中断，期满即消灭。
    * 理由：占有返还请求权保护的是一种和平的社会秩序，侵占已满一年，新的社会秩序已经形成，就不能再通过占有的方式获得保护。

* **相关边界的判断**

    * 强行拉走他人仓库中货物的行为不属于自助行为，自助的适用前提是情势紧迫；也不属于行使留置权，留置权的适用前提是合法占有债务人的动物。

---

## 占有返还请求权与原物返还请求权

* **例证：甲出租手机给乙，租赁期间手机被丙抢走**

    * 甲是间接占有人，丙抢夺乙的占有同时也侵夺了甲的间接占有，所以甲可以主张占有返还请求权。
    * 甲同时是这部手机的物权人，丙是现实的物权占有人，所以对丙主张原物返还请求权也可以。
    * 乙虽不是物权人，但他是这部手机的占有人且占有被侵夺，可以主张占有返还请求权，同样受一年不变期间限制；乙不能主张原物返还请求权，因为他不是物权人。

* **两道门的区别**

    | 比较项目 | 占有返还请求权 | 原物返还请求权 |
    | :--- | :--- | :--- |
    | 请求人资格 | 任何占有人（含间接占有） | 必须是物权人 |
    | 相对人 | 现实的无权占有人 | 现实的物权占有人 |
    | 占有状态要件 | 须被"侵夺"：违反占有意思、通过积极不法行为 | 物被他人占有（须为无权处分之外的现实占有） |
    | 行使期间 | 一年，不变期间 | 三年诉讼时效，可中止、中断 |
    | 特点 | 门槛低、期限短 | 门槛高、期限长 |

* **哪一道门更好走**

    * 占有返还请求权更好行使，只要证明自己是占有人就可以，缺点是期限只有一年；原物返还请求权门槛高、期限长，适用三年诉讼时效且可以中止、中断。
    * 假设侵占发生已满一年，就只有物权人可以主张原物返还请求权；必须证明自己是物权人，才能享受更长期限的保障。
