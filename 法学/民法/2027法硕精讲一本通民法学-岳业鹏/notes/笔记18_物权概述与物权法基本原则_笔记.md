# 物权概述与物权法基本原则

## 物权与债权的分野

* **物权（Real Right）**

    * > **结论**：物权从静态角度描述财产的归属关系；债权从动态角度规范财产的流转关系。一静，一动。
    * 规定在民法典第二编，规定的是财产的归属
    * 管的是归属，可以向不特定的多数人主张，物权人以外的所有人都是义务人
    * 性质上属于绝对权，也叫对世权，效力非常强大
    * 采取法定主义的立法模式，种类和内容都要由法律规定，相当于给它带了个紧箍咒，把效力圈定在可控范围内
    * 学习物权的第一件事是树立物权法定观念：学哪些内容主要看法律规定了哪些；每种物权当时能不能取得、取得后产生什么效力，都要回到法律规定判断
    * > **易错点**：不要把过多生活经验或朴素的正义观塞进物权判断里，因为常常靠不住，最靠得住的还是法律的规定。

* **债权（Claim）**

    * > **结论**：债权从动态角度规范财产的流转关系，只牵涉特定当事人，属相对权、对人权。
    * 规定在民法典第三编
    * 只能对特定当事人主张，效力范围仅局限在特定义务人身上，第三人不承担给付义务，救济与保护强度都相对温和。
    * 相对权更看重当事人的约定，走意思自治的路子，立法模式是任意主义
    * 债权的取得最主要通过当事人签订的合同

* **物权编在民法中的分量**

    * 物权编既是学习的重点，也是学习的难点
    * 过去二十年：简答题考过 10 次，法条分析题考过 7 次，论述题考过 5 次
    * 案例分析题和客观题几乎年年必考

## 物权编的框架结构

* **公因式提取与五分编格局**

    * 物权采取法定主义立法模式，类型由法律规定。按照现行民法典，物权主要包括三大种：所有权、用益物权、担保物权
    * 民法典规范时没有从所有权直接开写，而是先做一次公因式提取，把各种物权的共性内容抽出来形成物权通则，通则因此能适用于全部物权类型。
    * 然后在具体分编展开三种物权的具体规则，最后在物权编中规定了一项叫占有的制度
    * 占有虽然不是独立的物权类型，但占有人对物的适当控制跟物权的效力非常类似，所以被放进物权编规定

    ```text
    第一分编  通则 ───── 各类物权的共性规则：三要素 + 变动 + 保护
    第二分编  所有权  ┐
    第三分编  用益物权 ├─ 三大类 · 11 小类
    第四分编  担保物权 ┘
    第五分编  占有 ───── 不是独立物权类型，但控制效力近似物权
    ```

    * 学习顺序先走通则，再分头展开各分编
    * 通则部分围绕五个基本点展开：先是三要素（主体、客体、内容），再是变动和保护

* **11 小类的类型树**

    ```text
    物权 ── 3 大类 / 11 小类
    │
    ├─ 所有权（3）
    │   ├─ 一般所有权
    │   ├─ 建筑物区分所有权
    │   └─ 共有
    │
    ├─ 用益物权（5）
    │   ├─ 土地上的用益物权（3）
    │   │   ├─ 土地承包经营权
    │   │   ├─ 宅基地使用权
    │   │   └─ 建设用地使用权
    │   └─ 其他用益物权（2）
    │       ├─ 居住权
    │       └─ 地役权
    │
    └─ 担保物权（3）
        ├─ 意定：抵押权、质权
        └─ 法定：留置权
    ```

### 所有权

* **一般所有权**

    * > **定义**：所有权体现为权利人对自己动产或不动产的全面支配。
    * 甲买了一部手机就取得对这部手机的所有权，可以占有、使用、收益、处分
    * 是三种物权中唯一可以对自己财产进行全面支配的，效力最为强大

* **建筑物区分所有权**

    * 特殊性体现在客体比较多元
    * 甲买了某个小区的商品房成为业主，基于业主身份同时拿到三项权利：对自己套房的所有权、对小区公共设施的共有权、对小区重大事项参与管理的权利（开业主大会、参与投票）
    * 法律把三项权利打个包，取名建筑物区分所有权，既包括自己的房屋，也包括小区的公共设施和共同事项

* **共有**

    * 特殊性体现在主体是两人以上
    * 甲乙是夫妻，用夫妻共同财产买了一套商品房，对该房子取得所有权，主体是复数就构成共有状态
    * 共有要解决两个方向的问题：对外如何行使所有权（甲乙之间谁做主），关起门来甲乙之间内部也会形成一些权利关系

### 用益物权

* **土地承包经营权**

    * 体现为权利人对他人财产使用价值的支配
    * 农村农业用地采取包产到户政策，某村耕地 A 地块承包给农户，农户可以对这块地占有、使用、收益，从事农业生产
    * 地块所有权仍归属于集体，农户是在对所有权的地上进行使用价值的支配，这就是用益物权存在的价值

* **宅基地使用权**

    * 农户向村集体申请一块宅基地 B 地块并取得权利，在上面建造住宅，满足自己居住需求
    * 同样是对集体享有所有权的 B 地块的使用价值进行支配

* **建设用地使用权**

    * 开发公司 X 在北京拿 C 地块用来开发商品房，开发商对 C 地块取得的权利，可以在上面建造建筑物及附属设施
    * 是对国家享有所有权的土地的使用价值进行支配

* **居住权（Right of Residence）**

    * > **定义**：在他人住宅里面进行居住的权利。
    * 老王有两个儿子大王和小王，只有一套房子；可以把所有权留给聪明能干能保值增值的大王，同时给小王设定一个终身的居住权
    * 只要小王活着就可以一直住在这个房子里：所有权人是大王，小王却能终身居住

* **地役权（Easement）**

    * > **定义**：利用他人不动产来提高自己不动产效益的权利。
    * 甲公司和乙公司分别取得相邻地块的建设用地使用权开发商品房，乙公司地块靠海可以建海景房，甲公司的房子是不是海景房主要取决于乙公司盖得有多高
    * 甲公司以一次性支付 5000 万现金、换取乙公司建房不超过三层为条件，双方签订合同后甲公司取得地役权
    * 甲公司基于不让乙公司在自己土地上盖高楼这一方式，提升了自己土地的使用效益

### 担保物权

* **抵押权**

    * 体现为权利人对他人财产交换价值的支配，核心特点是不转移占有
    * 按揭贷款：甲付首付后向银行贷款，银行要求甲把房子抵押给自己，银行对甲的房子取得抵押权
    * 房子抵押给银行时不需要交付，甲依然可以在自己买的房子里居住，担保物权人并不占有担保财产
    * 银行享有的优先受偿权体现为：当甲不还贷款时，银行可以请求拍卖房子、就卖得价款受偿，不管甲还欠别人多少钱都由银行先拿

* **质权**

    * 体现为权利人对他人财产交换价值的支配，最大的特点在于要转移占有
    * 岳母借给车某 10 万元金钱债权，车某交一块名表作为担保，车某不还钱时岳母可卖掉名表实现优先受偿
    * 手表控制在岳母手中，担保物权人占有担保财产

* **留置权**

    * 体现为权利人对他人财产交换价值的支配，是法定的担保物权
    * 甲的手表坏了找乙修理厂修理，修好后甲不给钱，乙扣下手表，催告宽限期后甲仍不付钱，乙对手表取得留置权
    * 乙可拍卖变卖手表，优先清偿自己的修理费债权
    * > **易错点**：留置权的取得不需要甲乙就留置事项达成一致，只要符合法律规定的条件乙就可以直接取得，所以它是法定的担保物权。

## 物权的概念

* **物权（Real Right）**

    * > **定义**：权利人依法对特定物直接支配和排他的权利。（民法典第 114 条第 2 款）
    * 概念通过要素描述形成，要抓三个关键词：主体、客体、内容，另外还要注意一个"依法"
    * 掌握时按民法典第 114 条第 2 款的原文这一表述，相对更规范

* **主体：权利人**

    * 自然人、法人、非法人组织都可以成为物权的主体，范围比较广泛

* **客体：特定的物**

    * 既包括动产也包括不动产
    * 法律规定的权利也可以成为物权的客体，这是例外
    * 甲买房子抵押给银行时，抵押权的客体一方面是甲的房屋所有权，另一方面是相应范围内土地的建设用地使用权
    * 像建设用地使用权这种用益物权，可以成为抵押权这种物权的客体

* **内容：直接支配加排他**

    * 直接支配体现为物权内能实现，不需要别人帮助自己就可以直接实现
    * 甲买了手机行使所有权不需要别人配合，别人不干涉，这个手机怎么用、要不要送人完全由甲决定
    * 排他体现"一物一权"属性，原则上同一个物上不能存在两个内容相冲突的物权，特别是一个物上不能有两个所有权

* **依法**

    * 出现在概念里是因为物权效力比较强大，所以采取法定主义立法模式
    * 限定了物权必须由法律来设定

```text
            物权内容 = 直接支配 + 排他
            │
      ┌─────┴─────┐
    对人          对物
      │             │
   优先效力      追及效力
      │             │
  同物上遇到     物被占有人带离时，
  他人权利，     权利人追至物之所在
  物权人优先

  排他效力：同一物上不得并存两项内容相冲突的物权
```

## 物权的特征

* **比较框架：1 个体系定位 + 5 个基本点**

    * > **结论**：物权和债权的区别 = 1 个体系定位（性质）+ 5 个基本点（主体、客体、内容、变动、保护）。
    * "物权的特征""债权的特征""物权和债权的区别"这三个题目展开的内容是一样的，作答时可以互相替换使用。
    * 物权的特征是从与债权的比较中形成的，兄弟概念之间的区别常常就体现为你的特征
    * 描述一种权利特征的两个层次：先描述这种权利的性质即体系定位（上位概念是什么、属于哪个领域的概念），再从要素角度展开五个基本点

| 比较维度 | 物权 | 债权 |
| :--- | :--- | :--- |
| 一、性质（体系定位） | **支配权**，行使权利不需要别人配合 | **请求权**，需债务人配合方能实现 |
| 二、主体（效力范围） | 义务主体**不特定**，绝对权 / 对世权，可向全世界主张 | 义务主体**特定**，相对权 / 对人权，仅对特定债务人主张 |
| 三、客体 | **特定的物**（法律规定的权利为例外） | 债务人特定的仅为或不为一定行为 |
| 四、内容（权利效力） | 优先、追及、排他——"卷王派"，争强好胜 | 平等、相对、相容——"佛系派"，强调平等 |
| 五、变动 | **法定主义**，类型与内容由法律规定 | **任意主义**，重当事人意思自治 |
| 六、保护 | 物权请求权（恢复物权圆满状态）+ 损害赔偿 | 违约责任：继续履行 + 赔偿 |

* **性质**

    * 物权属于支配权，概念里出现了"直接支配"，行使权利不需要别人配合
    * 债权属于请求权，内容是请求特定义务人履行特定的不为行为，实现需要债务人配合才能达成目的，效力相对弱一些

* **主体**

    * 这一栏描述的不是权利主体，而是义务主体，体现的是权利效力范围不同
    * 物权的义务主体是不特定的多数人，物权人以外的所有人都是义务人，权利效力范围广
    * 债权的义务主体是特定的相对方，效力范围仅仅局限在特定的义务人身上

* **客体**

    * 物权的客体主要是特定的物，法律规定的权利在例外时也可以成为客体
    * 债权的客体指债务人特定的给付行为，即债务人仅为或不为一定行为，与物权客体的"特定的物"正好构成对照。

* **内容（权利效力）**

    * 优先效力：物权具有"卷王"属性，争强好胜，处处讲一个优先
    * 追及效力：物在哪里，物权就可以追到哪里去行使
    * 排他效力：一个物上原则上不能存在两个以上内容相冲突的物权，有我就不能有别人，唯我独尊
    * 债权强调平等性，是"佛系"，讲一个躺平，大家都是平等的
    * 债权仅有相对性，只能对特定的人主张，不能追及
    * 债权具有相容性（非排他性），同一个物上可以存在内容上冲突的数个债权

| 物权效力 | 口诀 | 债权效力 |
| :--- | :--- | :--- |
| 优**先**效力 | 先 | **平**等性 |
| **追**及效力 | 追 | **对**对性 |
| 排**他**效力 | 他 | **相**容性 |

* **变动**

    * 主要从权利发生角度分析
    * 物权采取法定主义的立法模式，类型与内容由法律规定
    * 债权更多强调当事人的意思自治，采取任意主义的立法模式，取得最主要通过当事人签订的合同

* **保护**

    * 物权的保护除损害赔偿以外，还包括旨在回复物权圆满状态的物权请求权，相当于物权自带的免疫系统，用来恢复物权的原本状态
    * 债权通过违约责任进行救济，既包含要求继续履行的内容，也包含赔偿

## 物权的三项效力

* **概念与效力的对应关系**

    * > **结论**：优先效力和追及效力都是从"直接支配"里面延伸出来的，排他效力是从"排他"延伸出来的。
    * 对人：既然我是直接支配，同一个物上有物权人、有债权人时，物权人要优先于债权人，体现优先效力
    * 对物：物因各种原因脱离所有人的控制时，物权没有消灭，依然可以追及物之所在来直接支配
    * 可以把物理解为一个风筝，权利就是通过一条线控制风筝的线，风筝飞得再远也能拉回来

### 优先效力

* **第一层：物权对债权的优先效力**

    * 原则性规定：物权是支配权、债权只是请求权，两者权利效力的强弱非常明显，物权原则上更加优先，学理上概括为物权优先原则。
    * 例：车某的劳力士先以 10 万卖给马某并签订合同，后以 12 万卖给岳母并当场完成交付
    * 岳母已交付取得手表所有权，是物权；马某只签订合同取得债权，岳母当然可以优先于马某获得保护
    * 结论：卷王派可以轻松卷倒躺平派
    * 债权取得优先于物权的效力属于例外情形，必须以法律作出明文规定为前提
    * 例外例证：买卖不破租赁（民法典第 725 条），承租人按租赁合同占用期间发生所有权变动，不影响租赁合同的效力
    * 例外例证：车某把别墅租给马某租期 5 年，一年后出卖给岳母并办理过户登记，岳母取得物权但承租债权优先受保护
    * 岳母此时已成为别墅新的出租人，可以向马某收取租金
    * 区分原则与例外的意义：法律没有规定债权优先的特别制度时，适用物权优先的一般性规定

* **第二层：物权相互之间的优先效力**

    * 同一物上产生的两项权利都是物权时，谁更优先要看法律的规定，仍然体现物权法定原则，法律没有排出顺序时不得自行推定。
    * 民法典第 456 条：同一动产上已经设立抵押或者质押，该动产又被留置的，留置权人可以优先受偿
    * 同一动产上可能并存抵押、质押、留置三种担保物权，因为它们效力不相冲突，这是物权排他效力的例外情形
    * 例：车某向岳母借 10 万设抵押并办理抵押登记；又向马某借 50 万未设担保；豪车送修后公某扣车并给两个月宽限期，取得留置权
    * 马某只是普通债权人，对这辆车没有物权可言，立即出局
    * 岳母的抵押权与公某的留置权都是物权，卷王与卷王之间要按法律规定优中选优，留置权人优先受偿
    * 结论：抵押、质押、留置并存时的效力强弱，法律已经把顺序排好队了，按序适用即可无须另行论证。

### 追及效力

* **追及效力（Tracing Effect）**

    * > **定义**：作为物权客体的物，无论辗转流向何处，权利人均有权追及物之所在而行使其权利。（民法典第 312 条）
    * 是物权对特定物直接支配效力的延伸
    * 通俗讲就是物到了哪里，物权就可以追到哪里去行使权利；物如同孙悟空的筋斗云，也逃不出物权的手掌心

* **例：千里追手机**

    * 甲的手机丢失被乙捡到，乙送给丙，丙又送给丁，最后在 300 公里外
    * 丁不能拒绝返还：手机被丢弃、辗转转手过程中所有权没有发生变动，依然属于甲
    * 手机脱离甲的直接控制被送到 300 公里以外，甲仍可追及物之所在，要求丁返还，重新实现对手机的支配权

### 排他效力

* **排他效力（Exclusivity）**

    * > **定义**：同一物上不能存在两个以上内容相冲突的物权。
    * 因为物权效力强大、要直接支配，若同一物上有两个所有权人各自主张直接支配，这种矛盾法律无法解决，所以法律不允许
    * 一个物上不允许有两个以上的所有权，这叫一山不容二虎

* **并存例外**

    * 法律允许例外：两个以上的物权效力不相冲突时，可以在同一个物上并存
    * 同一个动产上可以并存抵押权、质权、留置权三类担保物权
    * 车某对车享有所有权、岳母对该车享有抵押权、公某对该车享有留置权，三者效力不相冲突可以并存
    * 法律作出先后规定的前提是大家首先可以并存，一山不容二虎但一公一母可以和平相处

## 物权的五种分类

### 完全物权与定限物权

* **完全物权**

    * 区分标准是对标的物的支配范围有所不同
    * 对标的物进行永久、全面的支配，民法中主要体现为所有权
    * 效力最为强大，可以对自己的物进行占有、使用、收益、处分

* **定限物权（限制物权）**

    * 在特定范围内支配标的物，支配范围仅限特定范围，是受到限制的
    * 定限物权与限制物权是同义词
    * 常常体现为在他人财产上取得的物权，所以又称为他物权

* **自物权与他物权**

    * 对自己的物进行全面支配的所有权，叫自物权
    * 对他人的物只能部分支配的，叫他物权
    * > **结论**：对自己的物全面支配 → 自物权（所有权 / 完全物权）；对他人的物只能部分支配 → 他物权（定限物权 / 限制物权）。

### 用益物权与担保物权

* **用益物权**

    * 是对定限物权（他物权）所得的进一步区分，标准是看对他人标的物的支配内容
    * 支配他人标的物的使用价值的，叫用益物权
    * 重在使用，民法典一共规定五种：土地承包经营权、宅基地使用权、建设用地使用权、居住权、地役权

* **担保物权**

    * 支配他人标的物的交换价值的，即拍卖变卖所得价款可以优先受偿的，叫担保物权
    * 重在把标的物卖掉以后优先受偿，民法典规定三种：抵押权、质权、留置权
    * 两者都是他物权，支配范围都受到限制，区别只在支配的内容不同

### 动产物权、不动产物权与以权利为客体的物权

* **动产物权与不动产物权**

    * 按物权客体种类的不同来区分，物权的客体首先是特定的物，而特定的物既包括动产也包括不动产
    * 动产物权走公示方式是交付，不动产物权走公示方式是登记

* **以权利为客体的物权**

    * 本来叫"权利物权"，前两年考试分析修订时改称"以权利为客体的物权"
    * 改名原因可能是修订者觉得物权本来就是一种权利，权利怎么能够作定语，容易产生争议；这个定语其实多余
    * 例：开发商取得建设用地使用权后，因开发缺钱把这个权利抵押给银行融资，银行对该建设用地使用权取得抵押权
    * 例：知识产权也可以质押给债权人来获得融资，质权的客体可以是知识产权这样的权利

### 主物权与从物权

* **主物权**

    * 基于两个物权之间有没有从属关系来区分
    * 能够独立存在的物权称为主物权，学习的绝大多数物权都可以独立存在，不以担保他人债权的实现为前提。

* **从物权**

    * 不能独立存在、要从属于其他权利而存在的物权
    * 担保物权不能独立存在，其存在价值是为了担保一个主债权的实现
    * 例：银行先取得借款债权，再接受抵押取得抵押权；一次性还清贷款、借款债权消灭时，抵押权虽然还没办注销登记，在法律上已经消灭
    * 结论：皮之不存，毛将焉附；主物权归于消灭或转让时，从物权跟着消灭或转让
    * 用益物权中的地役权也具有同样的从属性，要从属于相应的权利

### 意定物权与法定物权

* **意定物权**

    * 区分标准是以物权产生原因不同
    * 基于当事人的意思表示或民事法律行为而产生，通过签订合同的途径取得的，叫意定物权
    * 抵押权和质权虽然也是担保物权，但取得要通过签订合同的途径，所以是意定物权

* **法定物权**

    * 按照法律规定而直接取得的，不需要当事人签订合同，叫法定物权
    * 留置权只要符合法律规定就可以直接取得，是法定物权

* **与物权法定原则的关系**

    * 物权法定原则说的是物权的种类和内容要由法律来规定：有多少种物权、每种物权有哪些权能，种类与内容两项都要法定。
    * 意定物权说的是：当要取得法律已规定的物权类型时，需要通过什么途径，需要通过签订合同的途径
    * 两者描述的角度完全不一样，不冲突，不要混为一谈
    * 例：抵押权这一类型由民法典规定，这是物权法定；而银行通过签订抵押合同取得抵押权，这是取得途径即意定

## 物权法的四条基本原则

* **基本原则的来源**

    * 物权法比较独特的价值追求一共四条：平等保护原则、物权客体特定原则、物权法定原则、公示公信原则，依次对应主体、客体、内容、变动。
    * 四条原则不是背下来的清单，从民事法律关系的基本点切进去就自然长出来

    ```text
       主体          客体          内容          变动
         │             │             │             │
         ▼             ▼             ▼             ▼
     平等保护      客体特定      物权法定      公示公信
       原则          原则          原则          原则
    ```

    * 从左到右就是一条对应关系：主体对应平等保护，客体对应物权客体特定，内容对应物权法定，变动对应公示公信
    * 之所以没有"保护"原则：保护在民法里是贯穿性的、各部门法共有的，没有体现物权法自己独有的价值追求

### 平等保护原则

* **原则内涵**

    * 是民法总则编平等原则在物权法领域的具体体现，总则编的平等原则是从主体角度描述的，在物权领域强调各类主体一律平等对待。
    * 差别在主体的范围：物权的主体首先是自然人、法人、非法人组织，与一般民事主体没有区别
    * 物权法领域的特殊性在于：特殊情况下主体还可以是国家或者集体
    * 实质是讲国家、集体、私人这些主体的物权要受到平等保护

| 体现 | 时点 | 内容 |
| :--- | :--- | :--- |
| 法律地位平等 | 事前 | 国家、集体、私人在物权规范中的法律地位平等 |
| 适用规则的平等 | 事中 | 各类主体在适用物权规则上平等 |
| 保护的平等 | 事后 | 受到侵害后，各类主体获得的是平等的保护 |

* **三点的内在逻辑**

    * 三点串起来是一条时间线，不必死记硬背
    * 事前先强调法律地位平等
    * 事中产生法律关系了，强调适用规则的平等
    * 事后受到侵害了，再强调保护的平等

* **与宪法位阶的界限**

    * "公民的合法私有财产受法律保护""任何组织或者个人不得侵犯"从字面上看是一种不平等，但民法仍强调平等保护
    * 答案是两个不同法域的价值判断，不能混在一起看
    * 在宪法层面、在公法领域，确实要对国家财产、集体财产给予更优先的保障，甚至单独制定了国有资产保护法
    * 一旦进入民法这个司法领域、参与了民事法律关系，在这个具体关系里国家、集体和私人就是受平等保护的，不能再主张位阶上的优先。
    * 公法上的位阶优势不带进私法关系里来
    * 围绕国家、集体财产所设置规范的论述题，最核心考点就是国家和集体的物权受到平等保护

### 物权客体特定原则

* **客体特定（站在物权的角度）**

    * 强调的是物权的权利和它的客体即特定的物之间的关系，这个关系有两个方向
    * 物权的客体限于经济上和法律上完整的、独立的物
    * 推论：物的组成部分不能成为物权的客体
    * 原因：物权要对物进行支配，假如一个物的不同组成部分由不同人支配，会严重影响这个物的效能发挥
    * 例：油门的支配权归甲、刹车的支配权归乙，这辆车没法开，加油要经乙同意，刹车由乙决定，甲想停都停不下来
    * 所以这个车只能整体上属于一个人

* **一物一权（站在物的角度）**

    * 一个物上不能存在两个以上内容相冲突的物权，原则上一个物上只指定有一个物权
    * 物权客体特定原则又叫一物一权原则
    * 两个词从不同角度描述同一件事：站在物权的角度描述为"物权客体特定"，站在物的角度描述为"一物一权"
    * > **易错点**：理解物权客体特定原则，一定要和"一物一权"关联起来记，这两个表述指向同一原则的两面，考题里换着出。

* **例外一：多人共享同一项物权**

    * 甲乙是夫妻，用共同财产买了一套商品房，甲乙能对这套房子取得所有权
    * 这没有违反一物一权：这房子上依然只有一个所有权，只不过这个所有权由甲乙两个人共享
    * 权还是那一个权，只是主体不止一个人

* **例外二：内容不冲突的物权并存**

    * 甲把房子抵押给银行，银行对这套房子取得的抵押权也属于物权
    * 甲的所有权与银行的抵押权效力并不冲突，可以并存于同一套房子上
    * 合起来看：一物一权划的是"完整、独立地支配整个物"那条线，只有物的部分被拆出去、或者两个物权的内容互相打架才叫违反

### 物权法定原则

* **原则含义与"法律"的范围**

    * 民法典第 116 条：物权的种类和内容由法律来规定，这就是物权法定
    * 意味着物权的种类和内容不能由法律以外的其他规范创设，也不能由当事人通过约定创设
    * 正面界定：这里的"法律"仅指狭义上的法律，包括《民法典》，也包括《海域使用管理法》《海商法》等民事特别法
    * 对照民法典第 10 条关于民法渊源的规定，那里所讲的"法律"是广义范围，涵盖民事法律、行政法规规章、地方法规、司法解释以及国际公约
    * 反面排除：国务院制定的行政法规、规章、地方性法规等等虽属民法渊源范畴，但不属于狭义上的法律，不能设定物权的种类和内容
    * 例证：2005 年联合颁布的《典当管理办法》用来规范典当行运营，基于这个部门规章不能让典当行取得物权的地位，因为规范级别不够
    * 法硕考研中学习的物权主要是《民法典》里规定的物权类型，考题不会跑到特别法里去设一个新类型

* **类型强制**

    * 物权的种类由法律规定，有多少种类型的物权是法律说了算
    * 《民法典》规定的物权类型就是三大类，用字母 ABC 表示：A 是所有权，B 是用益物权，C 是担保物权
    * 当事人约定设立物权时不能设定第四种类型，实践中取得的物权只能是 A、B 或 C

* **内容强制**

    * 每一种物权的内容由法律规定，规定的三种物权分别包含什么内容是法律说了算
    * 例：A 这种物权包含三项权能 A1、A2、A3，当事人依法取得 A 后不能主张 A4 第四项权能，超出法定范围的权能不受保护。
    * 尽管种类符合物权法定要求，但主张的内容超出了法律规定的范围
    * > **结论**：种类要法定，内容也要法定——这就是物权法定原则的两条底线。
    * 直接推论：物权人只能在法律规定的权能范围内行使权利，不能行使其他权利

* **后果一：违反类型强制**

    * 当时约定的物权种类不符合法律规定，后果是不发生物权效力，也就是取不到这个物权
    * 例：车某向岳母借款 10 万元，把一套佘山别墅交到岳母手中设定质押，约定不还款即可卖掉别墅优先受偿
    * 车某真的没按约定还款，岳母不能就佘山别墅实现优先受偿权
    * 民法典规定的质权只包括动产质权和权利质权，没有在不动产上设定质权这样的选项，约定违反类型强制
    * 岳母对别墅拍卖变卖取得的价款没有优先受偿的身份，不能优先于同样欠款的普通债权人老马受偿

* **后果二：违反内容强制**

    * 物权种类是法律规定的，但约定的内容超出了法律规定的范围，后果是这个约定本身无效
    * 例：车某向岳母借款 10 万元，把一块劳力士手表交到岳母手中设定质押，手表是动产、动产质权是法定类型，符合类型强制
    * 但双方特别约定车某不还款时岳母可直接取得手表所有权，这是典型的流质条款
    * 法律赋予质权人的权利只是支配交换价值、拍卖变卖后优先受偿，不包含直接取得所有权，该约定无效
    * 岳母不能依约定直接取得手表所有权，但对手表取得了质权，仍优先于老马受偿
    * > **结论**：物权依然设立，只是得按照法律规定来行使这个物权，而不是用当时的特别约定。
    * > **易错点**：违反类型强制和违反内容强制最容易混的是"物权到底成没成立"。一句话分清：种类不对，物权根本没生出来；内容超了，约定那一块作废，但物权本身照样成立。

* **后果三：区分原则（Separation Principle）**

    * 违反物权法定原则的行为导致物权不能设立，但合同的效力常常不受影响
    * 要把合同效力和物权变动的效力区分开来，这叫区分原则
    * 例：车某把别墅交到岳母手中约定设定不动产质权，物权不能设立，但双方签订的质押合同效力依然有效，岳母仍可依合同主张违约责任。
    * 合同是否有效，要回到总则编讲的民事法律行为有效要件去判断，这是另一层判断

    ```text
      ┌──────────────────────────────┐
      │  违反物权法定 ≠ 合同无效       │
      └──────────────────────────────┘

       合同效力 ──▶ 仍按总则编的民事法律行为有效要件判断
       物权效力 ──▶ 类型强制：不能设立
                    内容强制：超出的那部分约定无效
    ```

| 违反类型 | 违反的那部分 | 法律后果 | 物权能否设立 | 合同效力 |
| :--- | :--- | :--- | :--- | :--- |
| 类型强制 | 约定的物权种类 | 不发生物权效力 | 不能设立 | 不受影响 |
| 内容强制 | 超出法律范围的权能约定（流质条款） | 该约定无效 | 可以设立 | 不受影响 |
| 区分原则 | 合同效力与物权变动效力 | 两者分开判断 | —— | 仍按有效要件判断 |

### 公示公信原则

* **公示原则：让人知**

    * 物权要通过一定的方式进行公示，让公众知悉物权变动的事实
    * 物权属于卷王派、效力比较强大，当卷王得有资本，你得把实力展示给别人看
    * 按照法律规定，不动产通过登记方式公示，动产通过交付方式公示
    * 例：车某把佘山别墅和劳力士名表一并卖给岳母并签订买卖合同，签约时岳母不能取得所有权，因为没有公示、没有把实力亮出来
    * 车某把别墅登记到岳母名下，等于岳母拿着房产证向全世界宣布这套别墅是她的，这是公示
    * 车某把手表交付到岳母手中，公示的效果是让全世界知道她成为了新的物权人
    * 公众承认卷王身份，权利人才能取得优先受偿权和排他效力

* **公信原则：让人信**

    * 物权变动符合法定公示方式的，就具有了可信赖的法律效力
    * 通过登记或交付展示出来后，大家会产生信赖，法律也要保护这种信赖
    * 即使展示出的实力并不代表真正的实力，法律也要保护当事人对公示内容的信赖
    * 民法典设立善意取得制度来体现公信原则

* **例：质押手表被转卖后的追及与信赖保护**

    * 车某向岳母借 10 万元并把劳力士手表质押给岳母，质权以转移占有为前提，岳母取得质权，完成交付即完成公示
    * 岳母未经许可按市价把手表卖给不知情的马某，马某善意相信手表是岳母的并付了合理价格
    * 车某主张物权的追及权，要"千里追手表"、追及权所在行使物权
    * 马某买表时亲眼看到手表戴在岳母手上、手在岳母控制之下，这已经形成公示方式并产生信赖
    * 公示内容并不反映真实归属（岳母不是真正的所有权人），但法律保护的是相对方的信赖利益
    * 马某可以善意取得这块手表的所有权，取得后车某的所有权归于消灭，追及效力被法律直接切断，相当于法律亲手把风筝线剪断

* **两项原则的区别**

    * > **易错点**：公示原则和公信原则是两项原则，一定要把它们区别开来。
    * 公示解决的是"外界能不能看见"，公信解决的是"看见了之后要不要信、信了要不要保护"
    * 两者不能混为一谈，作答时必须先拆成两项原则分别展开
