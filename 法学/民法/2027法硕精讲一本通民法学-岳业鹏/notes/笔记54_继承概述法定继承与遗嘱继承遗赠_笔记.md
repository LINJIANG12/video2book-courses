# 继承概述、法定继承与遗嘱继承遗赠

## 继承的概念与要素

### 继承的含义与范围

* **继承**

    * > **定义**：自然人死亡时遗留的个人合法财产依法转移给他人的制度。

    * 民法上的继承只指财产继承，封建社会的皇位、身份承继在现代民法中已不存在。

    * 制度功能：解决被继承人死亡后其未处分的个人合法财产如何分配的问题。

### 三个核心术语

* **被继承人**：死亡时遗留个人合法财产、遗产由其合法转移的那个人。

* **遗产**：被继承人死亡时遗留的、可以依法转移的个人合法财产。

* **继承人**：依法定继承或有效遗嘱可以取得遗产、有继承资格的自然人。

* **受遗赠人**：基于遗赠取得遗产的主体，没有继承资格；既可以是组织，也可以是国家、集体。

    * > **易错点**：主体是组织时不能称"继承人"。遗嘱把财产捐给单位，该单位只能叫受遗赠人。

```text
                自然人死亡
                    │
                    ▼
        ┌───────────────────────┐
        │       被 继 承 人      │  ← 死亡时遗留的个人合法财产 = 遗产
        └───────────┬───────────┘
                    │  遗产转移：财产权利的变动
          ┌─────────┴─────────┐
          ▼                   ▼
   ┌─────────────┐     ┌─────────────┐
   │   继 承 人   │     │  受 遗 赠 人  │
   │  有继承资格   │     │  无继承资格   │
   │ 沉默 = 接受   │     │ 60日 = 放弃   │
   └─────────────┘     └─────────────┘
```

### 继承的四个要素

| 要素 | 内容 | 指向 |
| :--- | :--- | :--- |
| 因 | 因自然人死亡而发生 | 变动的**基础**：须有自然人死亡的事实 |
| 主体 | 被继承人一定范围内的近亲属 | 凭什么近亲属可以取得遗产 |
| 客体 | 死亡时遗留的个人合法财产 | 即遗产 |
| 内容 | 财产权利的变动 | 遗产权利从被继承人转移到继承人 |

* 遇"某制度有什么特征"的设问，一律往"因、主体、客体、内容"四格子里填。

## 继承的开始

### 死亡时间的确定

* **生理死亡**

    * 顺位：第一，看死亡证明记载的时间。

    * 第二，没有死亡证明的，看户籍注销的时间。

    * 第三，有其他证据足以推翻上述时间的，以证据证明的时间为准。

* **宣告死亡**

    * 一般以法院作出判决的时间为死亡时间。

    * 因意外事件被宣告死亡的，以意外事件发生的时间视为死亡时间。

* 继承从被继承人死亡时开始；生理死亡与宣告死亡都产生继承开始的效果。

* > **易错点**：安葬之日、清理遗产并确定份额之日、分割完毕之日，都是遗产**处理**的节点。继承开始的唯一判断标准是被继承人死亡的时间。

### 同一事件中数人死亡

* **真实时间优先**：本着实事求是原则先确定真实的死亡时间，再确定先后。

* **确定不了真实时间时**，才按下列顺序推定。

    * 第一步，推定**没有其他继承人的人先死亡**——没有其他继承人就无人可继承，这一层落空。

    * 第二步，**辈分不同的，推定长辈先死亡**，晚辈先继承长辈遗产后再死亡。

    * 第三步，**辈分相同的，推定同时死亡**，相互之间不发生继承关系。

* > **易错点**：推定有先后顺序——先查真实时间，查不出才推定；先看有无其他继承人，有才看辈分。

### 继承开始后的通知义务

* 第一层：**知道被继承人死亡的继承人**，要及时通知其他继承人和遗嘱执行人。

* 第二层：**无人知道，或知道的人无法通知的**，由被继承人生前所在单位或住所地的居委会、村委会负责通知。

    * 生前所在单位承担通知职责的现实例证：报丧布告由逝者生前所在单位发布。

## 继承的接受与放弃

### 沉默推定的两套规则

| 主体 | 法律要求 | 未作任何表示的推定 |
| :--- | :--- | :--- |
| 继承人（有继承资格） | 未表示放弃 | 视为**接受**继承 |
| 受遗赠人（无继承资格） | 知道受遗赠之日起 60 日内作出接受或放弃的表示 | 60 日届满仍未表示，视为**放弃**受遗赠 |

* 差别根源在资格有无：继承人本就有资格，沉默即不反对；受遗赠人本无资格，须主动表示接受，不表示即不要。

* 60 日的起算点是**知道受遗赠之日**，不是被继承人死亡之日。

* 放弃受遗赠是终局的，不能反悔；对一部分遗产表示放弃，不影响其他部分遗产的处理。

### 放弃的时间与方式

* **时间**：必须在**继承开始以后、遗产分割之前**作出。

    * 遗产分割完毕后再放弃的，放弃的是遗产的所有权，不是继承权。

    * 继承开始之前作出的放弃意思表示无效。

* **方式**：必须以**书面形式**作出。

    * 制度理由：放弃是单方行为，但仍须留下固定证据。

* > **易错点**：子女出具"若父亲乙死去，遗产一分都不要"的声明，此时父亲尚未死亡，声明无效；父亲被该声明气死也不构成故意杀害，子女仍可继承。

### 放弃的效力限制

* **基本规则**：因放弃继承权导致其不能履行法定义务的，该放弃行为无效；未导致不能履行法定义务的，有效。

* **夫妻共同财产**：一方以另一方可继承的遗产为夫妻共同财产、主张对方放弃继承无效的，人民法院不予支持。

    * 放弃使夫妻共同财产未增加，不等于不能履行法定义务。

* **例外**：有证据证明放弃继承导致放弃一方不能履行法定抚养义务的，放弃无效。

* **约定义务不构成障碍**：放弃继承只导致无法履行约定的债务时，放弃仍然有效。

    * 合同编配套规则：债务人放弃继承权的，债权人不能行使撤销权——放弃只使财产未增加，未使财产不当减少。

* > **结论**：法定义务是硬约束，约定义务是软约束。

### 效力的溯及与反悔

* **溯及**：放弃继承的效力溯及到继承开始时发生，效果是放弃人自身自始没有取得该遗产的权利。

* **反悔的两种情形**

    * 在遗产处理之前，或在诉讼进行中作出反悔意思的，由人民法院根据其提出的理由决定是否承认；理由正当的可以承认。

    * 遗产已经处理完毕后再反悔的，直接不予承认。

## 继承权

### 概念拆解

* **继承权**

    * > **定义**：自然人按照有效的遗嘱或者法律规定，取得被继承人遗产的权利。

| 要素 | 内容 |
| :--- | :--- |
| 主体 | 自然人 |
| 客体 | 被继承的遗产 |
| 内容 | 取得遗产的权利 |
| 发生原因 | 有效遗嘱或者法律的规定 |

* 核心内容是"取得"遗产的权利；四项连起来即继承权的完整概念。

### 五项特征

| 要素 | 内容 |
| :--- | :--- |
| 主体 | 仅限于自然人 |
| 客体 | 遗产 |
| 内容 | 取得遗产的权利 |
| 时间 | 到被继承人死亡时才能实际享有 |
| 变动 | 因法律规定或有效遗嘱的指定而产生，产生后不能随便转让，具有专属性 |

* 被继承人死亡前，即使对这笔遗产抱有期待，也不能实际取得该遗产。

### 丧失继承权的五种情形

* **完全列举，无兜底条款**，当事人不得以五种以外的其他情形主张丧失继承权。

| 序 | 情形 | 关键限定 |
| :--- | :--- | :--- |
| 一 | 故意杀害被继承人 | 既遂与未遂都丧失 |
| 二 | 为争夺遗产而杀害其他继承人 | 须以"争夺遗产"为目的；既遂与未遂都丧失 |
| 三 | 遗弃被继承人，或者虐待被继承人情节严重 | 虐待须达情节严重 |
| 四 | 伪造、篡改、隐匿或者销毁遗嘱，情节严重 | 亲自上手干扰遗嘱 |
| 五 | 以欺诈、胁迫手段迫使或者妨碍被继承人设立、变更、撤回遗嘱，情节严重 | 间接干扰遗嘱自由 |

* **情节严重的认定**

    * 虐待情节严重：综合考虑虐待行为的时间、手段、后果和社会影响；不以构成犯罪为前提。

    * 遗嘱类情节严重：继承人为掩盖真实财产、逃避债务等，实施上述行为，侵害了缺乏劳动能力又没有生活来源的继承人的利益、造成其生活困难的。

* > **易错点**：第二种情形有目的上的限制。为争夺女朋友而相互残杀与丧失继承权无关；单纯因盗窃被判刑，不属于任何一种丧失继承权的情形。

### 绝对丧失与相对丧失

* **绝对丧失（2 种）**：故意杀害被继承人；为争夺遗产杀害其他继承人。

    * 被继承人即使表示宽恕，或事后将其列为遗嘱继承人，仍无权继承，绝无复得可能。

* **相对丧失（3 种）**：遗弃被继承人；虐待被继承人情节严重；伪造、篡改、隐匿、销毁遗嘱情节严重；以欺诈、胁迫手段迫使或妨碍设立、变更、撤回遗嘱情节严重。

    * 情形一：继承人自己有悔改表现，且被继承人表示宽恕。

    * 情形二：被继承人事后在遗嘱中将其列为继承人。

* **被继承人的宽恕是准民事法律行为**：体现被继承人的内心意思，但法律后果已超出其控制范围，按法律规定确定。

* 分岔点在于行为的性质差别：故意杀害最恶劣，无法挽回；其他不当行为尚有悔改空间。

### 丧失的三项效力

* **第一，自继承开始时发生效力**。查明丧失事由晚于继承开始的，溯及到继承开始时，丧失人自始没有取得遗产的资格。

* **第二，只对特定被继承人生效**。杀害父亲的儿子，对母亲的遗产仍可继承——杀谁就丧失对谁的遗产的继承权。

* **第三，丧失继承权的人，其晚辈直系血亲不得代位继承**。否则剥夺被剥夺人继承权将落空。

## 遗产

### 含义与五个特征

* **遗产**

    * > **定义**：自然人死亡时遗留的个人合法财产。

| 特征 | 拆解来源 |
| :--- | :--- |
| 时间上的特定性 | 是在人死亡时遗留的财产 |
| 内容上的财产性 | 仅限于财产 |
| 范围上的限定性 | 强调是个人的部分 |
| 性质上的合法性 | 必须得是合法财产 |
| 法律上的可转让性 | 补充特征：遗产须发生权利变动，故须可转让 |

### 可以纳入遗产的财产

* 范围是广义范围：动产、不动产、具有财产价值的权利，甚至虚拟财产，都可以成为遗产。

* 纳入规则只有一条：**只要是死亡时遗留的**即可纳入；下面的排除规则都是从这一原则里往外抠的例外。

### 不能纳入遗产的财产

* **第一类：本来就不属于死者的**，最典型的是死亡赔偿金。

    * 丧葬费、死亡赔偿金是赔给近亲属的损失，不是死者遗留的财产。

    * 判断其意义的实质：这笔钱不能用来偿还被继承人的债务——不是遗产，无须先清偿债务再继承。

* **第二类：依法律规定或依其性质不得继承的**。

    * 国有自然资源的使用权。

    * 土地承包经营权：主体是农村承包经营户，包产到户，不属于死者个人财产，不适用遗产继承；承包地由村集体依法收回。

    * 具有抚恤、救济性质的财产权利：具有专属性，不能由继承取得。

* **土地承包经营权的两项补充**

    * 基于土地承包经营权取得的收益可以继承，属天然孳息。

    * 承包人死亡时尚未取得的收益被收走的，可依死者生前对承包地的投入（含增值和孳息）由发包方和接收承包合同的人合理折价补偿，折价部分视为遗产。

## 法定继承概述

### 概念与双重定位

* **法定继承**

    * > **定义**：直接根据法律规定的继承范围、继承顺序以及遗产分配原则，继承被继承遗产的法律制度。

    * "法定"指不依当事人意思，法律已规定好继承范围与顺序，具法定性与强行性。

    * "继承"指取得被继承人的遗产；凭的是与被继承人之间的身份关系，故法定继承人常具有近亲属身份。

* **对遗嘱继承是补充**：分配遗产时先适用遗嘱，遗嘱未作安排或无法适用的部分才由法定继承补充。

* **对遗嘱继承是限制**：遗嘱继承以取得遗产者具有法定继承人身份为前提；没有该身份者只能是遗赠，故法定继承的范围限制了遗嘱继承的适用范围。

```text
        ┌──────────────────────────────────────┐
        │  分配遗产时的顺序                    │
        └──────────────────────────────────────┘
                        │
              ┌─────────┴─────────┐
              │                   │
        有有效遗嘱            遗嘱解决不了的部分
              │                   │
        先适用遗嘱            法定继承来"补充"
                                  │
                    ┌─────────────┴─────────────┐
                    │                           │
          遗嘱里指定的人不行            遗嘱本身不行
```

### 五种适用情形

* 全部可理解为"遗嘱解决不了遗产分配"的情形。

| 层次 | 情形 |
| :--- | :--- |
| 遗嘱里指定的人不行 | 遗嘱继承人放弃继承，或者受遗赠人放弃受遗赠 |
| 遗嘱里指定的人不行 | 遗嘱继承人丧失继承权，或者受遗赠人丧失受遗赠权 |
| 遗嘱里指定的人不行 | 遗嘱继承人、受遗赠人先于遗嘱人死亡或者终止 |
| 遗嘱本身不行 | 遗嘱无效部分所涉及的遗产 |
| 遗嘱本身不行 | 遗嘱未处分的遗产 |

* > **易错点**：前三项盯的是"人"，后两项盯的是"遗嘱本身"；做题时先判断是哪一类再往里套。

## 法定继承的顺序

### 第一顺序的构成

* **配偶**：仅限合法配偶。已离婚、仅同居未登记、婚姻被确认无效或被撤销的，均无继承权。

    * 特别情形：配偶一方在**离婚诉讼中死亡，或在离婚冷静期内死亡**，另一方仍可继承——此时婚姻尚未解除。

* **父母**：包括生父母、养父母，也包括有抚养关系的继父母。

    * 生父母与养父母不能同时继承，形成养父母子女关系后二选一。

    * 继父母须以有抚养关系为前提；抚养采广义概念，含长辈对晚辈的抚养、晚辈对长辈的赡养、平辈之间的抚养。

* **子女**：包括生子女、养子女、有抚养关系的继子女。

    * 生子女既含婚生子女，也含非婚生子女。

    * 生子女、养子女、有抚养关系的继子女可以同时继承。

* > **易错点**：配偶与甲同时死亡时，相互之间不发生继承；已离婚的前妻不具继承资格；甲与继子女之间无抚养关系的（对方子女已成年才再婚），不产生继承关系。

### 中国好儿媳与中国好女婿

* **规则**：丧偶儿媳对公婆、丧偶女婿对岳父岳母尽了主要赡养义务的，无论是否再婚，均作为第一顺序法定继承人。

* **身份来源**：儿媳、女婿属**姻亲**，不属于近亲属，原则上不是法定继承人；法律对丧偶且尽主要赡养义务者特别赋予第一顺序身份。

* **尽了主要赡养义务的判断**：对公婆生活提供了主要经济来源（出钱多），或在劳务等方面给予了主要辅助（出力多）。

* **对照判断**：无抚养关系的继子不能继承；丧失劳动能力的养子可以继承（养子女身份本身即够）。

* 第一顺序法定继承人＝配偶、父母、子女，再加上中国好儿媳、中国好女婿。

### 第二顺序的构成

* **兄弟姐妹**：指两代以内的旁系血亲，即父或母有一个共同。

    * 含同父同母、同父异母、同母异父；**异父异母不行**。

    * 含养兄弟姐妹、有抚养关系的继兄弟姐妹；继兄弟姐妹同样以有抚养关系为前提。

* **祖父母、外祖父母**：含生祖父母、生外祖父母、养祖父母、养外祖父母。

    * **没有继祖父母、继外祖父母**——继祖孙之间不产生法律上的权利义务关系。

* > **易错点**：孙子女、外孙子女**不是**第二顺序法定继承人。祖辈立遗嘱让孙辈取得遗产的，孙辈取得属于**遗赠**；孙辈自知道遗嘱之日起 60 日内未表态即视为放弃受遗赠。

## 代位继承

### 三方关系模型

* 模型一（子女先死）：甲为被继承人，乙为其子先于甲死亡，丙为乙之子。乙是**被代位继承人**，丙是**代位继承人**。

* 模型二（兄弟姐妹先死）：甲未婚未育且无其他近亲属，乙为其兄弟姐妹先于甲死亡，乙有子丙。丙代乙之位继承甲的遗产。

* 民法典把代位继承的适用范围从"子女先死亡"扩张到"兄弟姐妹先死亡"，使被继承人的遗产不至于在无继承人时收归国有或集体所有。

* 模型二丙取得遗产的两个条件同时具备：除父母外，叔伯姑舅没有其他亲属；且该父母先于叔伯姑舅死亡。

### 四个条件

* 条件一：被代位继承人要先于被继承人**死亡**。

* 条件二：被代位继承人既包括**子女**，也包括**兄弟姐妹**。

* 条件三：被代位继承人**没有丧失继承权**。

* 条件四：要有**适格的代位继承人**。

* 前三项是被代位继承人的要求，第四项是代位继承人的要求。

### 适格代位继承人

* 子女先死亡的：代位继承人是**子女的直系晚辈血亲**，不受代数限制（四世同堂，最末一代仍可代位）。

* 兄弟姐妹先死亡的：代位继承人**仅限兄弟姐妹的子女**，受到代数限制，兄弟姐妹的子女的后代不能代位。

* **三类子女的矩阵**

| 层次 | 角色 | 类型 |
| :--- | :--- | :--- |
| 第二列 | 被代位继承人（先死亡） | 生子女、养子女、有抚养关系的继子女——任一种先死亡都可启动代位继承 |
| 第三列 | 代位继承人（直系晚辈血亲） | 生子女 ✓、养子女 ✓、有抚养关系的继子女 ✗ |

* > **易错点**：第三列的代位继承人一定不能是有抚养关系的继子女——他与被继承人之间是继祖孙关系，不产生法律上的权利义务关系。

* 被代位继承人若本人是有抚养关系的继子女，先死亡后同样可以启动代位继承制度；只是此时代位的人仍不能是有抚养关系的继子女。

### 代位继承的三项效力

* **第一，一般只能继承被代位继承人有权继承的遗产份额**。

    * 甲另有子女戊的，丙代位只能与戊平均分配，不能当然取得全部。

    * 代位继承**只适用于法定继承，不适用于遗嘱继承**。遗嘱指定的继承人先于遗嘱人死亡的，遗嘱相应部分认定无效，不以代位继承补足；此时只能走法定继承。

    * 差异示例：甲有乙、丁（子女）与配偶戊，遗嘱指定乙继承全部。乙未先死时，乙取得全部，丁、戊无份；乙先死导致遗嘱无效后，丙代位，丁、丙、戊各得 $1/3$。

* **第二，丧偶儿媳、丧偶女婿无论是否再婚、只要尽了主要赡养义务的均可作为第一顺序继承人，且不影响其子女代位继承**。

    * 两者是不同的法定继承人身份，互不影响。

* **第三，丧失继承权的人，其代位继承人不得代位继承**。

* > **提示**：拒不赡养属"不孝子女"，可以少分或不分，但未达到"遗弃"程度，不影响法定继承人的身份。

## 遗产的分配

### 基本规则

* **依次继承**：有第一顺序继承人的先用第一顺序，没有第一顺序继承人的才轮到第二顺序。

* **均等分配**：同一顺序继承人有数人的，原则上均等分配。

* **例外结构**：均分是原则，不均等是例外；不均等既包括当事人协商形成的不均等，也包括法律直接规定的不均等。

### 应当多分与可以多分

* **应当多分**：对生活有特殊困难的、缺乏劳动能力的继承人，应当予以照顾。

* **可以多分**：对被继承人尽了主要抚养义务的，或者与被继承人共同生活的继承人，可以多分。

    * > **提示**：尽抚养义务本是应尽之责，所以是"可以"而非"应当"；这个"应当"与"可以"的区分是常考点。

* 司法解释规定的例外：继承人愿意履行抚养义务，但被继承人**有固定收入和劳动能力**且**明确表示不要求其抚养**的，分配遗产时一般不应减少其份额。

### 应当少分或不分的情形

* 有抚养能力和抚养条件却不尽抚养义务的继承人，**应当不分或者少分**。

    * 未分到遗产也不影响其法定继承人身份或资格，除达到丧失继承权的程度。

* 对故意隐匿、侵吞或者争抢遗产的继承人，可以**酌情减少**其继承份额。

### 没有继承资格的人分得遗产

* **第一种：继承人以外、依靠被继承人抚养的人**，可以分得适当的遗产。

    * 例：唐某收养 6 岁孤儿丁但未办理收养登记，丁不具法定继承人资格；唐某死亡后丁可分得适当遗产。

    * > **注意**：这是"分得遗产"不是"继承"，丁自始没有继承资格。

* **第二种：继承人以外的对被继承人扶养较多的人**，可以分得适当的遗产。

    * 例：郑女士自 1986 年起每月探望退休老师，照顾 29 年，老师去世无遗嘱、无其他亲人，法院将 48 万元存款判归郑女士。

    * 规范拓展：被收养人对养父母尽了赡养义务、同时对生父母扶养较多的，除可继承养父母遗产外，还可以分得生父母的遗产——适用第二种情形，而非继承。

* **权益救济**：可以分得遗产的人，其取得遗产的权利被侵害时，可以**以自己的名义向法院提起诉讼**。

## 遗嘱的概念与效力

### 三个关键词

* **遗嘱**

    * > **定义**：自然人生前依法处分自己的财产并安排有关事务、于死后发生效力的民事法律行为。

    * 主体：仅限于自然人，只有自然人可以立遗嘱。

    * 意思表示：生前作出、死后生效，三者叠加即**死因行为**。

    * 内容：一是处分自己的财产（核心内容），二是安排有关事务（如遗嘱监护、指定孩子的监护人，可理解为临终托孤）。

### 四项特征

| 特征 | 含义 |
| :--- | :--- |
| 单方行为 | 凭遗嘱人一方的意思表示即可成立；受遗赠人是否接受属"取得"问题，不影响遗嘱成立 |
| 死因行为 | 以遗嘱人的死亡为生效要件，人没死遗嘱不生效 |
| 人身专属性 | 必须由遗嘱人亲自设立，不得由他人代理；代书人不是代理人 |
| 要式行为 | 必须符合法律规定的形式要件才能发生效力 |

* 记忆口诀"死要单身"，对应死因、要式、单方、人身专属。

### 效力的形态与有效要件

* > **结论**：遗嘱的效力形态只有"有效"和"无效"两种，不存在"可撤销"遗嘱，也不存在"效力待定"的遗嘱。

* **实质要件**

    * 主体：立遗嘱人必须具有遗嘱能力，只能是完全民事行为能力人。

    * 意思表示：真实。

    * 内容：合法，不违反法律，不违背公序良俗。

* **形式要件**：遗嘱是要式行为，形式要件是硬门槛，不符合即不发生效力。

### 六种无效情形

| 层次 | 无效情形 |
| :--- | :--- |
| 主体 | 无民事行为能力人、限制民事行为能力人所立的遗嘱 |
| 意思表示 | 受胁迫、欺诈所立的遗嘱 |
| 意思表示 | 伪造的遗嘱 |
| 意思表示 | 遗嘱被篡改的部分 |
| 内容 | 内容违背公序良俗 |
| 内容 | 处分了属于国家、集体、他人财产的部分 |

* > **易错点**：受胁迫、欺诈所立遗嘱是"无效"而非"可撤销"；一般民事法律行为遇欺诈胁迫给的是"可撤销"。

* > **易错点**：无权处分的处理遗嘱与合同完全相反。无权处分他人财产的合同效力不因此受影响（靠善意取得补足）；无权处分他人财产的遗嘱直接无效。

* 意思表示层三条的共同道理：均不体现遗嘱人的真实意思。

## 遗嘱的形式

### 六种形式与要件

| 形式 | 内容 | 关键形式要件 | 见证人 |
| :--- | :--- | :--- | :--- |
| 自书遗嘱 | 遗嘱人亲笔书写 | 亲笔书写全部内容、亲笔签名、注明年月日 | 不需要 |
| 代书遗嘱 | 遗嘱人口述、他人代书 | 两个以上见证人在场；代书人、见证人均签名并注明年月日 | 两名以上 |
| 打印遗嘱 | 电脑等设备打印 | 两个以上见证人在场；内容代表真实意思；见证人在**每一页**签名、注明年月日 | 两名以上 |
| 录音录像遗嘱 | 录下口述遗嘱或带有肖像的口述遗嘱 | 两个以上见证人在场；见证人在录音录像中记录姓名或肖像及年月日 | 两名以上 |
| 口头遗嘱 | 危急情况下的口述 | 危急情况消除后能立其他形式遗嘱的，自动失效 | 两名以上 |
| 公证遗嘱 | 公证机关公证 | 符合公证机关人员的要求 | 不需要 |

* 形式口诀"自带印录口供"，民法典规定遗嘱形式的顺序恰与口诀顺序一致。

### 各类形式的特别规则

* **自书遗嘱**：不能盖章、不能按指印。

    * 合同签完还要履行、当事人还在，可以站出来抗辩主张鉴定；自书遗嘱没有后续环节，是彻底的死无对证。

    * 遗书中涉及死后个人财产处分的内容，确为本人真实意思表示、并由本人签名注明年月日的，可以作为自书遗嘱对待。

* **代书遗嘱**：代书人只管照遗嘱人所说的写，遗嘱人口述什么就写什么；代书人不是代理人，人身专属性靠这一对比撑起。

* **打印遗嘱**：民法典新增形式。

    * > **易错点**：见证人漏签某一页的后果要具体分析——该页内容具有独立性的，只有该页无效，其他页照常有效；该页是不可分割的组成部分的，可能导致整份遗嘱全部无效。

* **录音录像遗嘱**：录音是继承法规定，录像是民法典新增；见证人的姓名或肖像在此发挥类似签名的功能。

* **口头遗嘱**：同样是"要式行为"，只能在遗嘱人处于危急情况下使用。

    * 危急情况的一般指认：遗嘱人生命垂危、在战争中或发生意外灾害、随时对生命危险而来不及或没有条件立其他遗嘱。

    * 危急情况消除后能立其他形式遗嘱的，口头遗嘱自动失效，此后即使死亡也只能按法定继承分配。

### 见证人资格

* 一般要求：有见证能力、没有利害关系。

* **不能见证**：无民事行为能力人、限制民事行为能力人，以及其他不具有见证能力的人。

* **存在利害关系、不宜见证**

    * 继承人、受遗赠人——他们要参与遗产分配，法律难以期待其公正见证。

    * 与继承人、受遗赠人有利害关系的人：继承人、受遗赠人的债权人、债务人，以及共同经营的合伙人。

* > **易错点**："不能见证"与"不宜见证"同在"不得作为遗嘱见证人"的大范围内，但层次不同，答题时宜分两层写。

## 遗嘱的变更与撤回

* 遗嘱是死因行为，遗嘱人未死亡前可以撤回、变更；方式分三种。

| 方式 | 含义 | 典型表现 |
| :--- | :--- | :--- |
| 明示 | 另立新遗嘱，明确声明变更或撤回原遗嘱 | 明确表达撤回、变更的意思 |
| 默示 | 通过行为变更、撤回 | 立遗嘱后的行为内容与遗嘱相抵触 |
| 推定 | 遗嘱人死亡后留下数份内容抵触的遗嘱 | 以后立的为准 |

* **默示示例**：甲立遗嘱把唯一一套房子留给儿子，立完不久就把房子挂到中介网上卖，卖房行为与遗嘱内容相冲突。

* **推定规则**：数份遗嘱内容相抵触的，以最后所立的遗嘱为准，视为在后的遗嘱变更或撤回在先遗嘱中相互冲突的部分。

* **沿革**：继承法以最后所立的**公证遗嘱**为准，公证遗嘱具有最高效力；民法典改为以最后所立者为准，**公证遗嘱不再具有更优先的效力**——两份遗嘱只是形式不同，具有决定意义的是当时的真实意思。

* > **提示**：继承法称"撤销"，民法典改为"**撤回**"更准确——遗嘱尚未发生效力，未生效的东西谈不上撤销。

## 遗嘱继承与遗赠

### 遗嘱继承

* **遗嘱继承**

    * > **定义**：基于被继承人所立的合法有效的遗嘱，继承被继承人遗产的制度。

    * 沿用术语：立遗嘱的人称遗嘱人（立遗嘱人），被指定的人称遗嘱继承人。

* **三个特征**

    * 前提是存在有效的遗嘱，没有遗嘱就谈不上遗嘱继承。

    * 体现被继承人的遗愿；法定继承人取得遗产依据的是身份关系，遗嘱继承依据的是被继承人的意思。

    * 与法定继承的关系是"排斥"和"效力优于"：有有效遗嘱时先执行遗嘱，排斥法定继承的适用。

* **三个适用条件，缺一不可**

    * 被继承人生前有合法有效的遗嘱。

    * **没有遗赠扶养协议**——遗嘱虽优先于法定继承，但排不到遗赠扶养协议前面。

    * 被遗嘱指定的继承人享有继承权；绝对丧失继承权者即使被事后指定，该遗嘱也无效。

### 遗赠

* **遗赠**

    * > **定义**：自然人以遗嘱的方式，将个人财产赠与国家、集体、法定继承人以外的个人或者组织。

    * 术语变化：作出赠与的人称**遗赠人**，取得财产的人称**受遗赠人**。

    * 特征与遗嘱相同，也是"死要单身"。

### 三个区别

| 比较项 | 遗嘱继承 | 遗赠 |
| :--- | :--- | :--- |
| 取得者的法律地位 | 有继承资格，是法定继承人 | 没有法定继承资格 |
| 主体范围 | 只能是自然人 | 自然人、法人、非法人组织，甚至国家、集体 |
| 权利行使方式 | 未作任何表示，视为接受继承 | 知道受遗赠之日起 60 日内未作表示，视为放弃遗赠 |

* > **易错点**：受益者虽同为沉默，法律认定结果完全相反——遗嘱继承人什么都不用干遗产就是他的；受遗赠人什么都不干，60 天一过遗产就与他无关。

* 记忆口诀"地主形"：地指法律地位，主指主体范围，行指权利行使方式。

### 遗托

* 遗嘱继承或遗赠可以负有义务，民法理论上称**遗托**——通过遗嘱把某事托付给某人。

* 继承人或受遗赠人应当履行该嘱托；无正当理由不履行的，经利害关系人或者有关组织请求，人民法院可以取消其接受附义务部分遗产的权利。

* 例：遗嘱将 50 万元留给妹妹甲并限定全部用于资助贫困大学生；甲取得后不履行义务且无正当理由，其他继承人有权请求取消其相应的继承权利。

## 遗赠扶养协议

### 协议结构

* **遗赠扶养协议**：遗赠人与扶养人之间的协议，由扶养人负责遗赠人的生养死葬，遗赠人死后将财产转移给扶养人。

    * 遗赠人：把财产转移给对方的一方。

    * 扶养人：尽生养死葬义务的一方；规范用字是"扶养"的扶。

    * 双方各得其所：遗赠人解决生前身后事，扶养人取得遗产。

* **典型形态**：甲病故膝下无子女，与邻居乙签订协议约定由乙负责甲的生养死葬、甲死后遗产归乙所有——乙本嫌麻烦，但想到可取得甲的万贯家财便勉为其难。邻居不愿的，也可以与村民委员会签订。

### 特征定位

* **要素定位——主体**：扶养人可以是个人，也可以是组织（如村民委员会）。

    * 法定继承人不能做扶养人：近亲属对对方本有法定抚养义务，履行生养死葬与取得遗产之间不形成对价关系。

    * 国家不能做扶养人：国家负责生养死葬意味着享受国葬待遇。

* **要素定位——内容**

    * 双方义务的履行在时间上具有**错时性**，中间有时间差；扶养义务自协议签订起履行，财产转移在被继承人死亡后才发生。

    * 在遗产分割时具有**最优先的适用效力**：既优先于法定继承，也优先于遗嘱继承、遗赠——扶养人是支付过对价的。

* **性质定位**

    * 双方行为（与遗嘱的单方行为相对），须双方达成一致。

    * 双务有偿行为，与受遗赠人无偿取得遗产形成对比。

* > **易错点**：法定继承人负责生养死葬并取得全部遗产的，不构成遗赠扶养协议，只能认定为**附义务的遗嘱继承**；附义务遗嘱无优先于后立遗嘱的效力。

### 与遗赠的五个区别

| 比较项 | 遗赠 | 遗赠扶养协议 |
| :--- | :--- | :--- |
| 行为性质 | 单方、单务、无偿 | 双方、双务、有偿 |
| 行为形式 | 遗嘱的形式 | 协议的形式 |
| 主体范围 | 受遗赠人可以是个人、组织，也可以是国家 | 扶养人可以是个人、组织，但不能是国家 |
| 主体资格要求 | 受遗赠人无民事行为能力的要求，只需遗赠人具有相应民事行为能力 | 属双方行为，双方都须具有完全民事行为能力 |
| 法律效力 | 与遗嘱继承效力相同，只能优先于法定继承 | 既可优先于法定继承，也可优先于遗嘱继承 |

* 口诀：遗赠"单单无"，遗赠扶养协议"双双有"。

* > **易错点**：考试分析中"遗赠扶养协议采取合同的形式"的说法不严谨。民法典的"合同"是狭义概念，遗赠扶养协议不能适用合同编，它首先适用继承编的规定，只能参照适用合同编相关规则；准确说法是"协议形式"。

* **效力**：协议不以其他继承人的同意为生效要件，子女不认可不影响其效力。

### 解除的两种情形

| 情形 | 解除权 | 后果 |
| :--- | :--- | :--- |
| 扶养人无正当理由不履行生养死葬义务 | 遗赠人可解除协议 | 扶养人丧失受遗赠的权利；已支付的供养费用一般不予补偿（半途而废，过错在己） |
| 遗赠人生前擅自把财产赠与他人 | 扶养人可解除协议 | 扶养人可请求补偿已支付的供养费用（自己没有过错） |

* 分野全在"谁有过错"上。

## 遗产管理人

### 确定的顺位

```text
第一步  遗嘱中有遗嘱执行人
          └─ 有 ──▶ 由遗嘱执行人担任

第二步  没有遗嘱执行人的
          └─ 继承人应及时推选遗产管理人

第三步  继承人都没有推选的
          └─ 由继承人共同担任

第四步  没有继承人，或者继承人都表示放弃继承
          └─ 由被继承人生前住所地的基层组织（村民委员会）担任

兜底    对遗产管理人的确定有争议的
          └─ 利害关系人可向人民法院申请指定
```

* 遗嘱执行人排在第一，源于私法自治；被指定的遗嘱执行人**可以拒绝**，因为它不是法定义务。

* 第二档的关键词是"**及时**"，继承人不推选、拖着不办，法律不会一直等待。

* > **易错点**：基层组织中只写了**村民委员会**，没有居委会。无人继承的遗产原则上归国家所有，死者若是村集体成员也可归集体所有；村委会代表集体接受财产有活干有钱接，居委会没有这个发挥机会。

* 丁拒绝担任遗嘱执行人、且乙丙未推选的，由乙、丙共同担任遗产管理人。

### 六项职责

1. 清理遗产并制作遗产清单——处理遗产的前提，先得有本账。

2. 向继承人报告遗产的情况——清理完发现无可供分配财产的，全体解散不再往下走。

3. 在分割遗产之前，采取必要措施防止遗产毁损、灭失。

4. 在分割遗产之前，先处理被继承人的债权债务。

5. 按照遗嘱或者法律的规定分割遗产。

6. 实施与管理遗产有关的其他必要行为——兜底条款。

### 尽责标准与报酬

* 遗产管理人应依法履行职责；因**故意或者重大过失**造成继承人、受益人、债权人损害的，承担民事责任。

* 法律只要求尽一般普通的注意义务，不苛责过重。

* 遗产管理人可以依法律规定或按约定获得报酬；**即使获得报酬，也只对故意和重大过失负责**。

    * 这项优待的立法用意在于鼓励有威望、有能力的人担任遗产管理人——继承人众多时，没有威望和能力压不住这个场。

## 遗产的分割

### 先析产后继承

* 我国采取"先析产后继承"原则：遗产只包括死者遗留的个人合法财产，须先从共同财产中分离出死者的部分，再进行分配。

    * 夫妻共同所有的财产：先分一半归配偶所有，另一半才是死者的个人财产。

    * 家庭共有财产：先分出其他家庭成员的财产，剩余部分才是死者的个人财产。

    * 其他共有：先分出其他共有人的财产，剩余部分才是死者的个人财产。

### 适用顺序

```text
① 遗赠扶养协议    ── 最优先效力（扶养人付出过对价）
② 遗嘱继承、遗赠  ── 尊重当事人意思自治
③ 法定继承        ── 只管前两项处理后剩余的部分
```

### 分割的五项原则

* **先遗嘱继承后法定继承**——遗嘱可以优先于法定继承，先尊重当事人意思自治。

* **执行遗嘱之前的必留份**——执行遗嘱前先给缺乏劳动能力又无生活来源的继承人保留必要份额，先保障生存权再保障意思自治。

    * 判断基准是**遗嘱生效时**，而遗嘱生效时指**遗嘱人死亡时**。

    * > **易错点**：基准时点是死亡时，不是订立遗嘱时；两个时点得出的结论可能完全相反。

* **保留胎儿的继承份额**——涉及遗产继承时，即使胎儿未出生也视为已取得民事权利能力，按独立继承人对待并保留必要份额。

* **互谅互让、协商分割**。

* **物尽其用**——尽量维护遗产的使用效益。

### 无人继承的遗产

* 无人继承、无人受遗赠的遗产，原则上归国家所有并用于公益事业，也可归村集体所有。

* 民政部门代表国家接受，村委会代表村集体接受。

### 胎儿的份额

* **胎儿出生后不久即死亡**：已取得主体资格，可以取得为其保留的份额；该部分由刚刚出生的孩子的继承人继承。

* **胎儿娩出时即为死体**：自始没有取得主体资格，为其保留的份额由被继承人的其他继承人重新分配。

* **龙凤胎验算**：熊某死亡未立遗嘱，母亲健在，配偶杨某怀有龙凤胎。四位第一顺序法定继承人各预留 $1/4$。男婴死体，其 $1/4$ 由其余三人平分各得 $1/12$，此时三人各为 $1/3$；女婴活产后旋即死亡，其 $1/3$ 归其法定继承人杨某（母亲为第一顺序继承人，祖母无机会继承）。最终杨某 $2/3$，熊某之母 $1/3$。

* > **结论**：考试时务必分清孩子是**出生时即为死体**，还是**出生后一段时间才死亡**，两种情形后果完全相反。

## 转继承

### 模型与称谓

* **转继承**：被转继承人在继承开始以后、遗产分割之前死亡，其已继承的遗产由转继承人再次继承；因连续发生两次继承，又称"二次继承"。

* **祖孙三代的两种死亡顺序**

| 死亡顺序 | 适用制度 | 遗产怎么走 |
| :--- | :--- | :--- |
| 甲先死，乙紧接着死 | 转继承 | 乙已继承的份额，由丙再继承一次 |
| 乙先死，甲后死 | 代位继承 | 丙代乙之位，直接继承甲的遗产 |

* **三个称谓**：甲是被继承人；乙站在与甲的关系上是继承人，站在与丙的关系上是**被转继承人**；丙是**转继承人**。

### 五个要件

1. 被转继承人在被继承人死亡以后、遗产分割之前死亡。

2. 被转继承人没有丧失、也没有放弃继承权——否则第一次继承都完成不了。

3. 被转继承人已经取得了相应的应继承份额（尚未实际分到遗产）。

4. 被转继承人生前未立其他遗嘱来安排相关事务——转继承中的丙是基于乙的法定继承人身份取得遗产。

5. 转继承人没有丧失、也没有放弃继承权，才能完成第二次继承。

* > **结论**：官方教材只写第一、第二、第五三个要件；应答简答题时须拓展到五个采分点。

### 遗赠的转继承

* 继承开始以后受遗赠人表示接受遗赠、并在遗产分割之前死亡的，接受遗赠的权利可以转移给他的法定继承人。

* 例：甲立遗嘱由孙子丙取得，丙无第一顺序继承人资格故属遗赠；丙表示接受后、分割前意外死亡，其基于受遗赠取得的部分由其法定继承人（父乙）取得。

## 债务清偿

### 四项原则

* **按时间轴分**

    * 遗产分割**之前**适用**连带责任原则**：继承人概括承受被继承人的权利义务，数名继承人对遗产构成共同共有，因共有物产生的债务共有人连带负责。

    * 遗产分割**完毕以后**适用**限定继承原则**：每个继承人只在自己**实际分得的遗产价值范围内**清偿，最多拿出自己分得的全部，不够的没有清偿义务。

* > **结论**：民法典不采纳"父债子偿"；不能因上一代人的失败使下一代一辈子翻不了身。

* > **提示**：超出应继份额的自愿清偿虽无法定义务，但有道德义务，清偿后不能请求返还。

* **按顺位分**：必留份优先于债务清偿，债务清偿优先于执行遗嘱——先保障生存权，再保障债权，剩余财产才按遗嘱分配。

### 分割之后的清偿顺位

* 既有法定继承又有遗嘱继承、遗赠的，**先由法定继承人来清偿**被继承债务。

    * 法定继承人分割时排在最后、清偿时却第一个出来还债，恰恰因为其享受限定继承的保护。

* 法定继承人所得全部拿出来仍不足的，由遗嘱继承人、受遗赠人**按比例**清偿；二者地位平等。

* **40 万元之例**：甲依遗嘱分得房屋 180 万元、乙以遗赠分得字画 40 万元、丙依法定继承分得现金 60 万元，债权人请求清偿 40 万元。丙分得的 60 万元足够，甲、乙不承担清偿义务。

* **140 万元之例**：丙最多拿出 60 万元，剩余 80 万元由甲、乙按 $180 : 40$ 的比例清偿，即甲约 $80 \times \frac{180}{220} \approx 65.45$ 万元、乙约 $80 \times \frac{40}{220} \approx 14.55$ 万元；甲乙拿出全部财产仍不足的，不足部分由债权人自行承担风险。

* **自愿履行之例**：甲生前借亲友 500 万元、身无分文无力偿还而自杀，独生子乙用 20 年还清。乙无法定清偿义务（甲未留任何财产，限定继承下遗产为零则无义务），但也不能就已清偿部分请求返还。
