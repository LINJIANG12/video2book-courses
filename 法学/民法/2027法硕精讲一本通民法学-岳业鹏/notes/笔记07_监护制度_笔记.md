# 监护制度

## 监护的概念与体系

* **监护**

    * > **定义**：对无或者限制民事行为能力人的合法权益进行监督和保护的制度。

    * "监"即监督，"护"即保护，监督加保护就是监护。

    * 被监督和保护的对象只有两类人，即无民事行为能力人和限制民事行为能力人；这两类人既可能欠缺独立从事相应民事活动的能力，对自身合法权益的保护水平也不足。

    * 监护关系的双方当事人：被监护人是被监督和保护的对象，监护人是履行监护职责的人。

* **监护的分类**

    * 第一条线索是被监护人的身份，据此分为未成年人监护与成年人监护，成年人监护针对的多为精神障碍者。

    * 第二条线索是监护权的取得途径，据此分为法定监护、指定监护、其他监护三类。

    * 其他监护按相关当事人的意愿确定，具体包括遗嘱监护、协议监护、意定监护三种。

* **监护规则的时间线索**：设立、履行职责、终止是一条时间线索，设立一步又分法定监护、指定监护、其他监护三个层次。

```text
  设立 ──────────────► 履行职责 ──────────────► 终止

  设立：先确定谁来当监护人
  履行职责：确定以后怎么履行这个职责
  终止：监护关系在什么情况下结束

  设立一步又分三个层次：
    法定监护 —— 按法律规定直接确定
    指定监护 —— 对担任监护人有争议时由相关组织指定
    其他监护 —— 按相关当事人的意愿确定
                协议监护 / 遗嘱监护 / 意定监护
```

## 监护能力

* **监护的人数**：监护可以是一人，也可以是数人，父母双方分别都可以担任未成年子女的监护人，父母一方死亡后另一方也可以单独担任。

* **完全民事行为能力**

    * 监护人首先必须是完全民事行为能力人，自己都欠缺行为能力、需要他人监督保护的人，不可能去监督保护别人。

    * > **易错点 ⚠️**：完全民事行为能力只是底线而非充分条件，并非所有完全民事行为能力人都能做监护人，还要进一步判断有没有监护能力。

* **认定自然人监护能力的因素**

    * 年龄：八九十岁的高龄者，监督和保护别人的能力会有所下降，可能不具备监护能力。

    * 身心健康状况：身患绝症者精神虽正常，仍欠缺监督和保护他人的能力。

    * 经济条件：自己都负担不起生活的人，无从监护保护他人。

* **认定组织监护能力的因素**：资质、信用、财产状况；国家机关的资质优秀，其信用与财产状况还应优于普通单位。

## 监护人的设定

### 法定监护

* **未成年人的法定监护**

    * 父母是未成年子女的当然监护人，排在第一位。

    * "当然"有两重含义：他人不得质疑父母的监护资格，父母也不得推脱自己的监护职责。

    * 父母双方离婚时，未与子女共同生活的一方的监护资格不受影响，双方都是该子女的法定监护人。

    * 只有父母死亡或者没有监护能力时，才轮到其他人担任监护人。

    * 顺位表如下。

    | 顺位 | 未成年人的法定监护 |
    | :--- | :--- |
    | 特殊地位 | 父母是当然监护人，不受质疑、不容推脱 |
    | 第一顺位 | 祖父母、外祖父母 |
    | 第二顺位 | 兄姐 |
    | 第三顺位 | 其他愿意担任监护人的个人或者组织 |

    * 祖辈为孙辈担任监护人符合伦理本观念，兄姐虽属平辈也可为弟妹担任监护人。

    * "按顺序"包含两层意思：顺位在前者有优先担任监护人的机会，顺位在前者也负有优先担当监护人的义务。

    * 第三顺位的"其他个人或者组织"须同时满足两个条件：本人自愿担任，因为其没有担任监护人的义务，法律不得强迫；还要经过未成年人住所地的居民委员会、村民委员会同意，由基层组织把关其动机是否有利于未成年人权益的维护。

    * 例外情形：父母双亡且祖辈均已离世时，成年且有监护能力的兄姐取得监护资格；非近亲属的姑妈若不愿担任，即使对侄儿疼爱有加也可以不做监护人，法律不强迫。

* **成年人的法定监护**

    * 针对精神障碍的成年人，直接由下列人员中有监护能力的人按顺序担任监护人。

    * > **易错点 ⚠️**：成年人没有"当然监护人"，必须顺位确定。

    | 顺位 | 成年人的法定监护 |
    | :--- | :--- |
    | 第一顺位 | 配偶 |
    | 第二顺位 | 父母、子女 |
    | 第三顺位 | 其他近亲属，含兄弟姐妹、祖父母、外祖父母、孙子女、外孙子女 |
    | 第四顺位 | 其他愿意担任监护人的个人或者组织 |

    * 配偶在民法中是最亲密的人，排在父母子女这一有直接血缘联系的关系之前。

    * 第四顺位的主体同样须同时满足本人自愿与基层组织同意两个条件。

    * 顺位考查例：精神病人甲的母亲 75 周岁瘫痪在床无监护能力，女儿 17 周岁属限制民事行为能力人不得担任监护人，20 周岁在校大学生有监护能力，故甲的监护人为其儿子；弟弟 48 周岁虽是近亲属，但父母子女的顺位优先于其他近亲属。

* **国家兜底监护**

    * 按上述规则仍无法确定适格监护人时，由居民委员会、村民委员会等基层组织兜底监护。

* **法定监护体系的三句话**：以亲属监护为基础，以社会监护为补充，以国家监护兜底。

```text
  以亲属监护为基础
    父母 → 祖辈 → 兄姐 …
    （顺序本身是一种筛选）
            |
            v
  以社会监护为补充
    其他愿意担任监护人的个人或者组织
    条件：① 本人愿意  ② 基层组织同意
            |
            v
  以国家监护兜底
    无法确定适格监护人时由基层组织兜底
    目的：确保每一个被监护人都有人监督、保护
```

### 指定监护

* **指定监护**

    * > **定义**：在对担任监护人有争议时，由相关组织通过指定来确定监护人的监护方式。

    * 适用前提是对担任监护人有争议，既包括有监护能力的人都争着当，也包括大家都不想当这两种情形。

    * > **易错点 ⚠️**：未成年父母的监护资格不能成为争议对象，父母是当然监护人；父母之外的其他顺位主体之间发生监护权争议，才适用指定监护。

    * 有指定权的机关共四类：未成年人住所地的居民委员会、村民委员会，以及人民法院。

    * 人民法院有最终决定权，对基层组织的指定结果不服可以请求法院最终确定，也可以直接请求法院指定，一步到位。

    * 指定的两项基本原则：主观上尊重被监护人的真实意愿，客观上最有利于被监护人。

    * 人民法院指定时应参考的因素：与被监护人生活情感联系的密切程度；依法具有监护资格的人的监护顺序；是否有不利于履行监护职责的违法犯罪等情形；依法具有监护资格的人的监护能力、意愿和品行。

    * 监护顺序只是数个可能因素之一，不是绝对标准；没有特别情节时顺位在前者仍有优势。

    * 例：外祖父母年纪已高、照顾孩子压力大，兄姐精力旺盛，法院可以指定兄姐担任监护人；纵使有监护资格且愿意担任，但有猥亵儿童前科的，不适合担任。

* **临时监护人制度**

    * 指定监护人之前存在监护人空白的空档期，由基层组织和保护弱势群体的公益组织担任临时监护人。

    * 该制度既填补被监护人无人监护的空白，也在督促基层组织尽快指定，否则基层组织自己就是监护人。

* **指定后不得擅自变更**

    * 被相关组织指定后即须上岗履职，擅自变更不免除被指定人的监护责任。

    * 例：法院指定外祖父母为监护人后，外祖父母擅自把职责转给祖父母，此后孩子在校将他人打成重伤的，赔偿责任仍由外祖父母承担。

### 协议监护

* **协议监护**

    * > **定义**：依法就在有监护资格的人之间通过协议来确定监护人的监护方式，体现的是相关当事人的意思自治。

    * 一团和气、已达成一致时无需再经指定，直接由协议确定的人担任监护人。

    * 规则一：协议确定监护人时应当尊重被监护人的真实意愿。

    * 规则二：未成年子女的父母有监护能力的，不能通过协议免除其监护责任。

        * 父母与外祖父母约定"我们不养这个孩子，你们来当监护人"，无效，因为父母是当然监护人，不得推脱。

        * 但父母可以通过协议为子女确定替补监护人，如父母双双身患绝症、与外祖父母约定身后将孩子托付给他们，该约定有效。

    * 规则三：约定协议监护的人可以属于同一顺序，也可以属于不同顺序，只要都是对未成年子女具有法定监护资格的人；未成年人的父母除外。

    | 协议内容 | 是否有效 | 理由 |
    | :--- | :--- | :--- |
    | 母亲与外祖父约定放弃对儿子的监护权，由外祖父担任 | 无效 | 母亲是父母、系当然监护人，不得通过协议转移监护职责 |
    | 母亲与外祖父约定当母亲意外死亡时由外祖父担任监护人 | 有效 | 属于为子女确定替补监护人 |
    | 母亲死亡后，姐姐与外祖父签订协议由姐姐担任监护人 | 有效 | 二人虽非同一顺序，但都是具有法定监护资格的人 |

### 遗嘱监护

* **遗嘱监护**

    * > **定义**：被监护人的父母通过设立遗嘱来指定监护人的监护方式，又称临终托孤。

    * 规则一：只有被监护人的父母可以立遗嘱指定监护人，其他人可以做监护人但无此权限。

        * 精神病人的配偶立遗嘱指定好友担任监护人，无效，因为配偶没有立遗嘱指定监护人的资格。

        * 成年精神病人由其父母担任监护人的，父母立遗嘱指定朋友担任监护人，有效，这里的父母既包括未成年人的父母，也包括成年人的父母。

    * 规则二：遗嘱生效时被指定人不同意担任监护人的，适用法定监护确定监护人；有争议的再走指定监护程序。

    * 规则三：未成年人的监护人由父母担任，一方通过遗嘱指定监护人、另一方在遗嘱生效时仍有监护能力的，另一方的监护资格不受影响。

    * 组合结论：父母双方立遗嘱指定姑妈而姑妈不愿担任，父母均死亡后按法定监护顺位确定，祖辈没有了则由姐姐担任；父亲单方立遗嘱指定姑妈且姑妈自愿，父亲病逝后监护人仍是母亲，只要母亲有监护能力即优先于其他任何人。

### 意定监护

* **意定监护**

    * > **定义**：具有完全民事行为能力的成年人与其近亲属或者其他愿意担任监护人的个人或者组织，事先协商，以书面形式确定自己的监护人，待其未来丧失或者部分丧失民事行为能力时由该监护人履行监护职责的制度。

    * 规定在《民法典》第 33 条，口语中常被讲成"议定监护"，是同一个制度。

    * 实践中主要是老年人的需求，因为老年人不知道哪一天会突然丧失民事行为能力，需要未雨绸缪地挑选信得过的个人或者组织。

    * 例：上海独居老人老马邀请常照顾他的水果摊摊主小刘一家住进老房子，在公证处做了意定监护协议与遗赠扶养协议两份公证，两者都有效。

    * 两份协议解决不同问题：意定监护协议解决丧失民事行为能力时由谁做监护人的问题，只有这份协议则老人死亡时小刘不能取得遗产，因为他没有继承资格；遗赠扶养协议补充这一空白，小刘负责生养死葬并取得老人的遗产。

    * 有效的意定监护协议优先于法定监护第四顺位：当事人与侄子签订意定监护协议后，好友虽表示自愿并已取得居委会同意，仍应按协议由侄子担任监护人。

* **意定监护协议的解除**

    * 协议以双方高度的信赖为基础，信赖丧失时应允许解除，司法解释以该成年人是否已经丧失民事行为能力为界限。

    | 阶段 | 解除权 | 要点 |
    | :--- | :--- | :--- |
    | 签订协议后，该成年人尚未丧失或部分丧失民事行为能力 | 任何一方都有任意解除权 | 被指定人尚未上岗履职，信赖丧失即允许终止协议关系 |
    | 该成年人已经丧失民事行为能力 | 无正当理由不能解除 | 既已丧失民事行为能力就得上岗履职，不能随意撂挑子 |

* **协议监护与意定监护的区分 ⚠️**

    * 两者都有协议、都体现意思自治，但签订主体有本质区别。

    * 协议监护由具有监护资格的人之间签订，双方都是潜在的监护人，被监护人不参与，是监护人这一方内部的约定。

    * 意定监护协议由未来的被监护人与潜在监护人签订，该当事人在丧失行为能力之前签订，丧失后即成为被监护人。

## 监护人的职责与履行

* **监护职责的两个方面**

    * 对外：监护人作为法定代理人，代理被监护人实施民事法律行为，弥补被监护人民事行为能力的不足。

    * 对内：监护人保护被监护人的人身、财产等合法权益。

    * 两项合起来就是对外代理、对内保护。

    * 父母收走孩子的压岁钱是合法的，因为父母作为法定监护人有权保护被监护人的财产权益，保管这笔钱本身就是保护。

* **客观的尺子：最有利于被监护人**

    * 监护人可以管理被监护人的财产，但只有为了维护被监护人的利益才能处分该财产。

    * 判断标准只有一个，即是否为了维护被监护人的利益；通常表现为保护被监护人的人身权益、这笔钱非花不可的情形，可花可不花的原则上不得处分。

    * 童星案例中开设账户投资股市遭遇大跌不符合规定，投资股市并非非处分不可；按法律规则管理财产造成的损失由监护人承担赔偿责任。

    * 童星案例中动用孩子个人积蓄支付 100 万元以上手术费可以，尽快手术治病是为保护被监护人的人身健康，属于非处分不可。

    * 免除他人欠被监护人的债务不属于维护被监护人利益，被监护人因此仍可追索。

    * 用被监护人的存款支付监护人自己发生的医疗费属于依法履行职责，因为支付医疗费是为了维护被监护人的利益。

    * 用铁链将被监护人锁在家里防止其出门，侵害人身自由，明显过分，不属于依法履行职责。

* **登记在未成年子女名下的房屋**

    * 父母双方以法定代理身份、用夫妻共同财产购买并登记在未成年子女名下的房屋后，不得再以损害未成年子女利益为由主张该民事法律行为无效。

    * 房屋登记在谁名下不等于财产就归谁：主观上只是借用子女名义购买的，仍可能被认定为夫妻共同财产；确有赠与子女意思的，可成为子女的个人财产。

    * 父母以法定代理人身份卖掉该房屋后，事后不得以损害被监护人利益为由主张买卖合同无效，法律要保护善意相对方的信赖利益与交易安全。

    * 处分确实损害被监护人利益的，被监护人可以请求父母承担赔偿责任，但不能主张与买受人的买卖合同无效。

* **主观的尺子：尊重被监护人的真实意愿**

    * 对未成年人的监护人：作出与被监护人权益有关的决定时，应当根据其年龄和智力状况尊重其真实意愿，孩子大了就不能替他直接决定升学之类的事项。

    * 对成年人的监护人：应当最大程度地尊重被监护人的真实意愿，保障并协助其实施与智力、经济状况相适应的民事法律行为；被监护人能够独立处理的事务，监护人不得干涉。

* **委托监护**

    * > **定义**：监护人因患病、外出务工等原因在一定期限内不能完全履行监护职责，将全部或者部分监护职责委托给他人的情形。

    * 监护职责虽由他人履行，监护人的地位不受影响；留守儿童实际由祖辈抚养的，法定监护人仍是父母。

    * 被监护人在校致人重伤的赔偿责任由父母承担而非实际抚养的祖辈；受托人除存在过错外不需要承担责任。

* **不履行职责的后果**

    * 主观上不履行或不适当履行：监护人不履行监护职责，或者侵害被监护人合法权益的，应当承担法律责任，如遗弃、虐待被监护人。

    * 客观上无法履行适用临时照护制度：因突发事件等紧急情况监护人暂时无法履行监护职责、被监护人生活处于无人照料状态的，由被监护人住所地的居民委员会、村民委员会等有关组织为其安排必要的临时生活照料措施。

    * > **易错点 ⚠️**：基层组织提供临时生活照料措施并不因此成为监护人，监护人依然是父母。

    * 该空白期内被监护人致人损害的，侵权责任仍由被监护人的父母承担，基层组织只负责生活照料、不承担监护人责任，这与指定监护和临时监护人制度不同。

## 监护的撤销与恢复

* **监护的撤销**

    * > **定义**：监护人存在法定情形，人民法院根据有关人员和组织的申请撤销其监护资格的制度。

    * 撤销的三种情形。

    | 不当行为 | 作为或不作为 | 要点 |
    | :--- | :--- | :--- |
    | 实施严重损害被监护人身心健康的行为 | 作为 | 法律本要求保护被监护人，反而严重侵害其人身权益 |
    | 怠于履行监护职责，或者无法履行职责时拒绝将职责委托他人，导致被监护人处于危困状态 | 不作为 | 在其位不谋其政，怠于履职或拒绝找人帮忙 |
    | 实施其他严重侵害被监护人合法权益的行为 | 兜底条款 | 也包括侵犯财产权益，如父母有赌博恶习将孩子财产挥霍殆尽 |

    * 案例对应：长期虐待女童的父亲属第一种作为，不闻不问的母亲属第二种不作为，法院撤销双方监护资格并指定民政局担任监护人。

* **申请撤销的主体**

    * 第一类是有关人员，即其他有监护资格的人，如祖父母、外祖父母认为父母逼迫孩子过度可以申请撤销。

    * 第二类是有关组织，包括居民委员会、村民委员会等基层组织，以及学校、医疗机构、残疾人联合会、未成年人保护组织、老年人保护组织等保护弱势群体的公益组织。

    * 有关人员和组织均未申请的，人民法院可以指定有关组织作为申请人；公益组织发表谴责声明不能代替程序的启动。

* **撤销的三项后果**

    * 原监护人丧失监护权。

    * 被撤销监护资格者的法定义务不因此免除，剥夺权利但不免除义务；依法负担被监护人抚养费、赡养费、扶养费的父母、子女、配偶仍须履行该义务。

    * 原监护资格被撤销后出现监护空白，由人民法院安排必要的临时监护措施，并按最有利于被监护人的原则依法指定新的监护人。

* **监护资格的恢复**

    * 只有被监护人的父母或者子女才有恢复监护资格的机会；非血亲关系担任监护人被撤销后没有恢复机会。

    * 恢复须非常慎重：确有悔改表现并主动提出申请，同时人民法院尊重被监护人的真实意愿后视情况恢复，避免被监护人再入险境。

    * 对被监护人实施故意犯罪行为而导致监护资格被撤销的，没有改过自新的机会；遗弃罪虽属不作为，同样落在故意犯罪的范畴内。

    * 监护资格依法恢复的，此前指定的监护人的监护关系随之终止。

* **撤销与恢复的流程**

```text
  监护资格存续
        |
        | 法院依法撤销
        v
  资格被撤销 ──► 法定义务不免除（抚养费照付）
        |
        |  出现监护空白
        v
  临时监护措施 + 按最有利于被监护人原则
          指定新的监护人
        |
        |  符合条件时可恢复
        |  （限于父母 / 子女，且无故意犯罪）
        ◄──────────────┘
        |
        v
  恢复后，原监护关系终止
```

## 监护关系的终止

* **终止事由**

    * 民法典规定的终止事由顺着当事人这条线索展开，一方是被监护人，一方是监护人，有的双方均可适用，有的仅限一方。

    | 终止事由 | 适用的一方 | 说明 |
    | :--- | :--- | :--- |
    | 被监护人或者监护人死亡 | 双方均可 | 任何一方死亡，监护关系当然终止 |
    | 被监护人取得或者恢复完全民事行为能力 | 仅被监护人 | 取得主要指未成年人总有成年的一天，恢复主要指精神有障碍的成年人 |
    | 监护人丧失监护能力 | 仅监护人 | 想干也干不了了 |
    | 其他情形 | 兜底 | 具体问题具体分析 |

    * 监护关系终止后，被监护人仍然需要监护的，要依法另行确定监护人，如监护人死亡或丧失监护能力时即需另行确定。

    * 监护制度整体掌握三个层次：监护人的设定规则、监护人的职责与履行、监护关系的终止；监护的撤销本质上也是监护关系终止的一种类型。
