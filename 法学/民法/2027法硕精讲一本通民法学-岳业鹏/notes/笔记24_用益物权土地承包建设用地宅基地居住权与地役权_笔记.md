# 用益物权：土地承包、建设用地、宅基地、居住权与地役权

## 用益物权的含义与特征

### 概念三要素

* **用益物权**

    * > **定义**：权利人对他人所有的动产或不动产**依法**享有的占有、使用、收益的物权。

    * **主体**：权利人，为一般主体，自然人、法人、非法人组织均可取得。

    * **客体**：他人所有的动产或不动产，以不动产为主。

    * **内容**：占有、使用、收益，支配的是他人财产的**使用价值**。

    * 概念中的关键词是"**依法**"，用益物权具有绝对权属性，加上"依法"概念才成立。

    * > **易错点**：《民法典》只规定了五种用益物权、客体实际都指向不动产，但定义时仍写入"动产"，这是给未来法律发展保留的空间。

### 体系定位与要素定位

* **体系定位**这一层只说两句

    * **他物权**：用益物权是对他人财产取得的物权，与自物权的所有权形成鲜明对比。

    * **限制物权**：支配范围仅限于他人财产的**使用价值**。

* **要素定位**这一层把概念里的三要素再摊开

    * 主体对应权利人，为一般主体。

    * 客体对应他人的动产或不动产，以不动产为主。

    * 内容对应占有、使用、收益，指向对使用价值的支配。

    * 描述一个权利的特征，要分体系定位与要素定位两个层次，概念里已经有要素，在前面再加一层体系定位即描述权利的性质。

```text
描述一个权利的特征
      │
      ├── 体系定位：它在更大的体系里处在什么位置
      │     用益物权 ──▶ 他物权（对他人财产取得的物权）
      │              └──▶ 限制物权（支配范围受限）
      │
      └── 要素定位：把概念里的要素再摊开
            主体 ──▶ 权利人（一般主体）
            客体 ──▶ 他人的动产或不动产（主要是不动产）
            内容 ──▶ 占有、使用、收益（支配使用价值）
```

### 用益物权的类型

* **《民法典》规定的五种**

    * 在**土地上设立**的用益物权：土地承包经营权、建设用地使用权、宅基地使用权。

    * 为**特定目的**设定的用益物权：居住权，为保障特定人的居住需求；地役权，为提升特定土地的使用价值。

    * 土地所有权只能由国家和集体取得，普通民事主体要利用土地只能通过设定用益物权的方式实现，这一层次的存在是为了缓解土地所有权不能转让对土地利用效率产生的不利影响。

* **特别法规定的用益物权**，又称**特许物权**、**准物权**，体现为对自然资源的使用权

    * | 特别法 | 规定的使用权 |
      | :--- | :--- |
      | 《海域使用管理法》 | 海域使用权 |
      | 《矿产资源法》 | 探矿权、采矿权 |
      | 《水法》 | 取水权 |

    * 性质上也属于用益物权，但规定在特别法中，不在法硕考试需要展开的范围。

* **物权法定原则**要求物权的**种类和内容**都要有法律规定，因此类型要分《民法典》与特别法两个层次理解，特别法也是法律。

### 讲述每种用益物权的固定框架

* **概念和特征**：重点关注每一种权利的三要素，即主体、客体、内容。

* **变动规则**：掌握如何设立、如何发生变动。

* **主要内容**：物权的种类和内容有法律规定，要掌握《民法典》给这种用益物权规定了哪些主要权能。

* 三个层面落到要素上，就是主体、客体、内容、变动、保护这五个基本点。

* 因为后四种权利都可以套用物权保护的一般性规则，用益物权在"保护"这一块的特殊性并不明显，不像担保物权需要单独讲一堆问题；真正要花力气的是每种权利各自的设立要件和特殊限制。

## 土地承包经营权

### 概念与要素

* **土地承包经营权**

    * > **定义**：权利人**依据承包合同**，对其承包经营的耕地、林地、草地等农业用地依法享有的占有、使用、收益，并从事种植业、林业、畜牧等农业生产的用益物权。

    * **主体**：承包人，原则上是**农村承包经营户**。

    * **客体**：农业用地，主要是集体享有所有权的农业用地，例外时可以是国家所有、由集体使用的农业用地。

    * **内容**：占有、使用、收益，主要是**农业生产**这四个字。

    * 概念在三要素之外多加"**依据承包合同**"，因为该权利是基于村集体与农户签订承包合同的方式取得的。

    * 农村承包经营户以土地承包经营权为**存在的基础**；四荒用地的土地经营权主体不受限制。

* **农业生产类型与农业用地的对应**

    * | 农业生产类型 | 对应的农业用地 |
      | :--- | :--- |
      | 种植业 | 耕地 |
      | 林业 | 林地 |
      | 畜牧业 | 草地 |

* **期限**：土地承包经营权是一种**有期限的物权**，与具有恒久性的所有权形成对比，但期限相对较长

    * | 承包地类型 | 承包期 |
      | :--- | :--- |
      | 耕地 | 30 年 |
      | 草地 | 30 至 50 年 |
      | 林地 | 30 至 70 年 |

    * > **易错点**：期限很长但终究是有期限的，不设期限则集体或国家的所有权形同虚设。承包期届满后还可以继续承包，"到期"不等于"失权"，但不等同于所有权的永续。

### 一手取得：与发包人签订承包合同

* **设立时点**：从**承包合同生效时**设立，采取**债权意思主义的物权变动模式**。

* **登记的效力**：既不是物权变动的要件，也不是取得对抗效力的条件；只要签订有效的承包合同，既可取得物权，同时可对抗善意第三人。

* **登记的作用**主要发挥**确认物权**的效力，既非生效要件，也非对抗要件。

* **不采登记生效的三个原因**

    * 交易安全保护的需求并不是那么高：土地承包经营权不能自由流转，最多只能在村集体内部流转。

    * 在农村地区登记很难发挥预期的公示功能：哪个农户在哪块土地上从事农业生产大家看得到，当时事实上也没人去县里查询登记。

    * 对农户特殊利益保护的需求：若须办完登记才能取得权利，农户取得物权要看村长的脸色，容易滋生腐败。

### 二手取得：与原承包人签订互换、转让合同

* **设立时点**：在**互换、转让合同生效时**发生物权效力，同样是债权意思主义的物权变动模式。

* **登记的效力**：此时登记变成**对抗要件**，未经登记不得对抗善意第三人；因为土地承包经营权已进入流通领域，要适当兼顾交易安全。

* **与一手取得的差异只落在一处**

    * | 对比项 | 一手取得（与发包人签约） | 二手取得（与原承包人签约） |
      | :--- | :--- | :--- |
      | 合同相对方 | 发包人（村集体） | 原承包人（同村农户） |
      | 物权设立时点 | 承包合同生效时 | 互换、转让合同生效时 |
      | 物权变动模式 | 债权意思主义 | 债权意思主义 |
      | 登记的效力 | 既非生效要件，也非对抗要件 | 对抗要件，未经登记不得对抗善意第三人 |

    * > **结论**：两种情形都不要求登记才能设立物权，但一手取得不登记也能对抗善意第三人，二手取得则不能。

* > **易错点**：官方教材与考试分析把两种方式称为"原始取得"和"继受取得"，这个说法不严谨。原始取得指非基于他人的既存权利而取得物权；农户取得土地承包经营权是基于村集体的所有权而来的，应称**创设的继受取得**，农户之间通过流转取得的才叫**移转的继受取得**。

### 权利人的权利内容

* **第一个层次：对客体的支配**

    * 正常情况下：占有、使用、收益承包地并从事农业生产。

    * 非正常情况下：承包地被依法征收、征用占用时，集体土地所有权可能归于消灭、农户的土地承包经营权受影响，农户可以获得相应的补偿。

* **第二个层次：对权利本身的处分权能**

    * 对**内的流转**：在村集体内部进行互换和转让，即"肥水不流外人田"。

    * 对**外的流转**：《民法典》新增制度，土地承包经营权人可以向村集体以外的个人、组织流转**土地经营权**，不受村集体内部的限制。

## 土地经营权

### 定性以五年为界

* 《民法典》对土地经营权属物权还是债权采取折中的观点，具体问题具体分析，看流转期限有多长。

```text
土地经营权定性：五年为界
      │
      ├── 流转期限 ≥ 5 年
      │     └──▶ 取得用益物权，发生物权效力
      │           变动模式：债权意思主义（合同生效时设立）
      │           登记：对抗要件，未经登记不得对抗善意第三人
      │
      └── 流转期限 < 5 年
            └──▶ 不必上物权，直接适用租赁合同的相关规定（债权）
```

* 期限**五年以上**的，取得的是**用益物权**，合同生效时设立，未经登记不得对抗善意第三人。

* 期限**不满五年**的，通过**租赁合同、以债权的方式**规范，直接适用租赁合同的相关规定。

* **土地经营权是一种相对权利**：土地经营权人对农业用地的使用价值进行支配，在合同约定期限内占有土地、自主开展农业生产经营并取得收益，依赖合同相对方的配合。

* 设计目的是鼓励设定长期的土地经营权：期限够长给予物权层面的保障，期限太短通过债权规范就够。

### 家庭承包土地的三权分置

* 乙农户取得土地承包经营权后，可以通过**出租、入股或者其他方式**向他人流转土地经营权，且**不受村集体内部的限制**。

* 同一块耕地上出现三种权利：村集体的**所有权**、乙农户的**土地承包经营权**、丙公司的**土地经营权**，即**三权分置**格局。

```text
【家庭承包的土地】三权分置

  甲村集体                 乙农户                    丙公司
  ────────                ───────                    ───────
  所有权  ──承包合同──▶  土地承包经营权 ──流转经营权──▶  土地经营权
     │                          │                            │
     └───────────── 同一块耕地 A ────────────────────────────┘
```

* **制度意义**

    * 最大限度释放土地承包经营权的财产价值：流转限于村集体内部时土地没有稀缺性、难以体现财产价值，对外流转面向开阔市场可最大限度实现其财产价值。

    * 给农户留下后路：农户流转出土地经营权后仍保留土地承包经营权这一用益物权，外出务工可以先拿到一笔钱，打工失败回来地还是他的。

* **四荒用地的两权分置**

    * 四荒用地指荒山、荒沟、荒丘、荒滩，其流转在《民法典》之前就不受村集体内部限制，因此没有必要先承包给农户再流转。

    * 村集体可以**一步到位**直接设立土地经营权，不必经过土地承包经营权人这一层，形成**两权分置**。

```text
【四荒用地】两权分置

  甲村集体                          丁公司
  ────────                          ───────
  所有权  ──先登记确权、再对外流转──▶  土地经营权（一步到位）
     │
     └───────────── 同一块荒地 ────────┘
              （不必先经过土地承包经营权人这一层）
```

    * 四荒用地流转不受村级内部限制，是因为其开发**所需成本比较高**，一般农户难以承担，需要引入村集体外的市场主体开荒。

    * 为保护交易安全，村集体对外流转四荒用地**必须先办理登记**，办完登记才能对外流转，即先确权、再流转；流转方式包括出租、入股、抵押或者其他方式。

    * 丁公司取得的土地经营权同样按期限区分：达到五年以上才取得物权，合同生效时设立，未经登记不得对抗善意第三人；不满五年通过租赁合同以债权规范。

### 对外流转的程序要件

* 这是《农村土地承包法》的规定：村集体把四荒用地发包给村集体以外的单位、个人时的要求，仍然秉持"肥水不流外人田"的观念。

* **程序上的要求**要完成"民主"和"集中"两方面，顺序上先民主程序、后批准程序

    * 民主程序：经本集体经济组织的村民会议 **2/3 以上的成员**，或者 **2/3 以上的村民代表**同意。

    * 批准程序：报**乡镇人民政府**批准。村民朴实，给小好处就会投票，故须由乡镇人民政府把关是否符合村集体整体利益。

* **实际上的要求**：同等条件下，本集体成员有**优先承包权**。

### 真题辨析：承包合同生效还是成立

* 真题"根据我国民法规定，土地承包经营权的取得时间是什么时候"，答案为**承包合同生效时**。

* > **易错点**：选项若写"承包合同**成立**时"不能选。债权意思主义说的是**合同生效时**发生物权变动；生效与成立在民法上性质不同，属于不同的问题。

## 建设用地使用权

### 概念与特征

* **建设用地使用权**

    * > **定义**：权利人依法对国家或者集体的土地享有的占有、使用、收益，并利用该土地**建造并保有**建筑、构筑物及其附属设施的用益物权。

    * **主体**：权利人，为一般主体，自然人、法人、非法人组织均可成为建设用地使用权人。

    * **客体**：国家或者集体所有的土地，主要是国有土地，例外时也可以是集体土地。

    * **内容**：对该土地使用价值的占有、使用、收益，用于建造并保有建筑、构筑物及其附属设施。

    * 概念中的关键词是"**依法**"：它是一种物权、一种绝对权，得依法取得、依法行使。

    * **"构筑物"**指桥梁、高速公路、纪念碑、花园等，不限于房屋。

    * **"建造"与"保有"要读清楚**：建造是开发商行使的权能；买受人同样可以取得建设用地使用权，但通常只有保有建筑的权利，没有建造权。

* **要素定位的四个角度**

    * 主体是一般主体；买商品房既取得房屋所有权，也取得占用范围内土地的建设用地使用权。

    * 客体主要是国有土地，例外时为集体土地。这与土地承包经营权正好相反：后者原则上在集体土地上设置，例外时为国有土地。

    * 内容是占有、使用、收益，强调准用于建造并保有建筑及其附属设施。

    * 变动上强调**排他性**：同一块土地上不能设立两个以上的建设用地使用权，称"一山不容二虎"；但可以在地表地上和地下分别设立，这叫**土地的空间利用权**，并不违反排他性。

```text
   ┌────────────────────────────────────────────────┐
   │  高空层：架设高压线 / 建造空中花园              │  ← 甲的建设用地使用权
   ├────────────────────────────────────────────────┤
   │  地表层：建小区、盖商品房                        │  ← 乙的建设用地使用权
   ├────────────────────────────────────────────────┤
   │  地下层：地下 50 米、100 米处由市政公司建造地铁  │  ← 丙的建设用地使用权
   └────────────────────────────────────────────────┘

   三个权利人并存，各占一层，互不冲突。
   排他性禁止的是"同一层设两个"，不是"整个立体空间只许一个"。
```

    * > **提示**：分层设定恰恰是排他性的实现方式，每一层各自独占；地铁正走在这张图的第三格。

* > **易错点**：住宅商品房的开发只能在国有土地上设立。村集体想盖商品房，须先由国家征收集体土地并给集体补偿，再由国家对外设立建设用地使用权。没走这个流程盖出来的房子叫**小产权房**，房主对土地本身没有权利，建造行为也很难说得上合法。村级组织盖小学、乡镇企业厂房则属集体土地上的例外情形。

### 设立：划拨与出让

* **国有土地上的两种设立方式**

    * **划拨**：通过**行政手段无偿**取得建设用地使用权，通过审批拿到批文才能取得。

    * **出让**：通过**民事手段有偿**取得，通过招标、拍卖、协议等方式从国家取得，与政府签订国有土地使用权出让合同。

* **只能通过公开竞价取得的两种情形**

    * 工业、商业、旅游娱乐和商品住宅等**经营性用地**，由经营主体通过公平竞争取得，谁出价高、谁资质更好谁取得。

    * 同一土地上有**两个以上的意向用地者**。

* **划拨与出让的三点区别**

    * **性质不同**：出让是民事方式，因出让合同发生纠纷提起民事诉讼；划拨是行政手段，因划拨土地发生纠纷提起行政诉讼。

    * **适用范围不同**：划拨的适用范围严格限于法律规定的四类具体情形，为防止行政权力滥用；出让适用范围较广泛，除划拨用地外均可。

    * 划拨的法定适用情形：国家机关用地和军事用地；城市基础设施用地和公益事业用地；国家重点扶持的能源、交通、水利等基础设施用地；法律、行政法规规定的其他用地。

    * **权利内容不同**：划拨是无偿取得，权利内容只能是自己使用而不能处分；出让是有偿取得，可以通过转让、出租、抵押等方式流转。

    * | 对比维度 | 划拨 | 出让 |
      | :--- | :--- | :--- |
      | 性质 | 行政手段 | 民事手段 |
      | 取得方式 | 审批、拿批文 | 招标、拍卖、协议，与政府签订国有土地使用权出让合同 |
      | 对价 | 无偿 | 有偿 |
      | 纠纷解决 | 提起行政诉讼 | 提起民事诉讼 |
      | 适用范围 | 严格限于法律规定的四类具体情形 | 较广泛，除划拨用地外均可 |
      | 权利内容 | 只能自己使用，不能处分 | 可转让、出租、抵押等方式流转 |

    * > **提示**：三点区别中"性质"一栏有出口效应，记住它就不会在诉讼路径上选错。

### 变动与续期

* **变动采取登记生效主义**：以登记作为物权变动的要件，办理登记才发生物权效力，未办理登记不发生物权效力，适用不动产物权变动的一般性规定。

* 通过**划拨**方式取得的建设用地使用权，也**必须办理登记**才发生物权效力。

* > **易错点**：拿到批文不等于物权设立，划拨和出让在变动环节走的是同一条路，都要登记。

* **期限与续期**要区分住宅用地与非住宅用地

    * | 对比项 | 住宅用地 | 非住宅用地 |
      | :--- | :--- | :--- |
      | 是否自动续期 | 自动续期，无须申请 | 不能自动续期，须主动申请 |
      | 是否需要交钱 | 费用有减免空间，具体依法律、行政法规 | 一定要交钱 |
      | 出处 | 民法典专门规定，体现保障民生 | "依照法律规定办理" |

    * 出让方式取得的建设用地使用权有期限，长文举例：住宅用地 70 年、商业用地 50 年、工业用地常为 40 年。

    * 住宅用地期限届满**自动续期**，不需要申请即直接续上；至于续多少年、续期费用怎么处理，《民法典》没有表态，只写明续期费用的缴纳或者减免依照法律、行政法规的规定办理。

    * 非住宅用地按法律规定办理，不能自动续期，须主动申请，且一定要交钱。

    * > **易错点**：从字面文义看《民法典》仍保留了续期费用，只是规则待定；不要把"保障民生"读成"法定免费"。住宅用地的 70 年不是从买房时起算，而是从开发商取得土地时起算。

### 权利内容与房地一体

* **第一个层次：对客体的支配**，包含占有权、使用权、收益权；对土地可以占有、可以使用来盖房子，盖好的房子权利人可以取得所有权并有收益的权利。

* **第二个层次：对权利本身的处分权**

    * 建设用地使用权人**不能处分土地**——连国家作为所有权人都不能卖土地，开发商更不可以；这个"处分"不是对客体土地的处分，而是对权利本身的处分。

    * 表现形式：卖房子时可以把建设用地使用权一并卖给买房人；资金不够时可以把它抵押给银行融资。

* **房地一体原则**：建设用地使用权和上面的建筑要一并处分，不能分开

    * **房随地走**：建设用地使用权转让、互换、出租、赠与的，上面的建筑一并处分。

    * **地随房走**：建筑、构筑物转让、互换、出资、赠与的，其占有范围内的建设用地使用权必须一并处分。

    * > **结论**：不要让"房盖在别人的地上"这种矛盾出现，消灭问题就是房地一体原则的目的。

```text
        房  地  一  体
   ┌──────────────────┬──────────────────┐
   │  房随地走         │  地随房走         │
   ├──────────────────┼──────────────────┤
   │  建设用地使用权   │  建筑、构筑物     │
   │  转让/互换/出租   │  转让/互换/出资   │
   │  /赠与            │  /赠与            │
   ├──────────────────┼──────────────────┤
   │        ↓ 必须一并处分 ↓                │
   ├──────────────────┼──────────────────┤
   │  地上面的一切都跟着走                   │
   └──────────────────┴──────────────────┘
```

## 宅基地使用权

### 概念与特征

* **宅基地使用权**

    * > **定义**：农村集体经济组织的成员依法对集体所有的土地享有的**占有和使用**的权利，用来建造住宅及其附属设施的用益物权。

    * **主体**：农村集体经济组织成员，城镇居民不可能取得。

    * **客体**：集体所有的土地，只在集体土地上设置，国家土地上没有所谓的宅基地使用权。

    * **内容**：对该土地使用价值的**占有、使用**，**没有收益权能**——土地只能用于建造住宅、满足基本生活需求，且是无偿提供给村民的。

    * **用途限定**：只能建造住宅及其附属设施，如建车库、建厕所等，都要服务于居住需求。

* **与建设用地使用权的镜像对照**

    * | 概念要素 | 建设用地使用权 | 宅基地使用权 |
      | :--- | :--- | :--- |
      | 主体 | 一般主体：自然人、法人、非法人组织 | 仅限农村集体经济组织成员 |
      | 客体 | 国有土地为原则，集体土地为例外 | 集体所有的土地 |
      | 权能 | 占有、使用、收益 | 占有、使用（无收益权能） |
      | 建造范围 | 建筑、构筑物及其附属设施 | 只能是住宅及其附属设施 |
      | 是否有期限 | 有期限：住宅 70 年、商业 50 年、工业 40 年 | 不受期限限制 |

    * > **提示**：最容易忽略的一格是"权能"——建设用地有收益权能，宅基地没有，收益权能的有无是第一个考点。

* **变动与保护上的特殊之处**

    * **无偿取得**：农户不需要向村集体支付对价。

    * **不受期限限制**：只要这一户有人，可以祖祖辈辈使用下去。

    * > **结论**：无偿加不受期限限制等于社会福利性，这也正是它没有收益权能的原因。城镇居民买的商品房建设用地使用权有期限，70 年从开发商拿到地时起算，老房可能已过四五十年；农村住宅不存在这个问题。

### 取得与变动

* **两条取得途径**

    * **一手取得**：依法律规定或者申请，由村集体授予给农户，农户直接申请取得。

    * **继受取得**：农户转让住宅时一并取得，农户转让住宅只能**在村集体内部**进行。宅基地使用权本身不能卖，但上面盖的房子可以卖，卖房子时适用房地一体原则，受让人随之取得宅基地使用权。

* **物权变动时点**：《民法典》没有规定，《土地管理法》也没有作出规定；原则上农户从村集体拿到批建时即取得该权利，**不以登记作为发生物权效力的要件**。

* > **易错点**：建设用地使用权是"登记生效"，宅基地使用权是"批建即设立"，两者正好相反，别串。

* 考试分析把这两条途径称为"原始取得和继受取得"同样不严谨：农户是基于村集体的所有权取得，应称**创设的继受取得**，农户之间通过流转房屋使权利变动的叫**继受的继受取得**。

### 权利内容

* **第一个层次：对客体的支配**

    * **占有**：可以占有该宅基地。

    * **使用**：可以使用该宅基地建造住宅及其附属设施。

* **第二个层次：对权利本身的处分权**

    * **不得抵押**。

    * **不得单独转让**：村集体批准用地是让农户建造住宅、满足居住需要，未支付对价；若允许原封不动转手卖出，等于把集体的无偿福利当成牟利商品。

    * 但合法建造的**房屋所有权可以转让**；转让时基于房地一体原则，占用范围内的宅基地使用权一并转让，且只能在村集体内部流转，"肥水不流外人田"。

    * 一旦通过转让取得宅基地使用权，此后申请宅基地**不再批准**，免费的福利只有一次。

* > **结论**：宅基地使用权等于无偿取得（不交钱）加不受期限（不会没）加只占不收（不生财）加不得抵押加不得单独转让，四道闸门全指向"保障居住、不许变现"。

* 考试分析写的"取得因行使宅基地使用权而获得的收益"**不是《民法典》的规定**。《民法典》只规定占有、使用两个权能；该项收益只能理解为附属性权能，如农户在自家宅基地上建房子开小卖部、开理发店、开小饭店，通过个体工商户方式经营取得收益。

## 居住权

### 概念与七项特征

* **居住权**

    * > **定义**：**为了满足生活居住的需要**，**自然人按照合同的约定**，对他人的住宅享有占有、使用的**用益物权**。

    * **主体**：自然人，只有自然人才有生活居住的需要。

    * **客体**：他人的住宅，客体仅限住宅。

    * **内容**：支配住宅的使用价值，具体是**占有、使用**两项权能。

    * **设立目的**：满足生活居住的需要，带有社会福利功能，保障"住有所居"。

    * > **易错点**：内容里没有收益权能。因为设立目的是满足生活居住需要，居住权人只管住，不从房子上生钱。

    * > **提示**：一般物权概念里都有"依法"两个字，居住权不是"依法"而是"**按照合同的约定**"。居住权人怎么用、能用多久法律没法规定，只能按约定，这在一定程度上缓和了物权法定原则。

* **特征先过体系定位**：居住权是他物权、是**《民法典》新增**的用益物权，制度可靠性比一般用益物权更强。

* **要素定位展开出七项特征**

    * 主体为自然人，客体是他人的住宅，内容是按合同约定占有、使用。

    * 设立目的"满足生活居住需要"向外延伸出三项特殊特征，编成口诀**无数期**：**无**偿性、**属**（人身专属性）、**期**（期限性）。

    * **无偿取得**：原则上无偿，但当事人当时约定有偿的法律也不反对；没有特别约定即为无偿。

    * **人身专属性**：不得转让，也不得继承，专属性只能由本人行使；本人死亡后权利归于消灭，继承人不能继承。

    * **期限性**：居住权是有期限的物权，若不设期限限制，所有权人将形同虚设；期限可以当时约定，没有约定则到权利人死亡时消灭。

    * 真题考法上直接从要素切入就够用，把"他物权、用益物权"这一体系定位也加上来同样正确。

* **权能边界对照**

```text
  ┌────────────────────────────┬────────────────────────────┐
  │          所有权             │          居住权             │
  │        归 张 甲            │        归 张 乙            │
  │   占有·使用·收益           │      仅占有·使用            │
  │   可处分·可继承             │    不得转让·不得继承        │
  └────────────────────────────┴────────────────────────────┘
             同一套房子，权能边界完全不同
```

### 设立方式与变动要件

* **方式一：书面居住权合同**

    * 合同是书面的，居住权人这一方只能是自然人。

    * 合同的主要现实功能是解决**以房养老**：丙年老有房、子女在国外，把房子低价卖给养老中心，同时签订居住权合同，养老中心通过登记取得房屋所有权后为丙设定居住权，丙终身居住直到离世。

    * 老人在世时拿到大笔现金且生活环境不变，去世后居住权消灭、房屋归养老中心。

* **合同一般应当包括的条款**（法律只作提示，不是强制性规定）

    * | 合同一般应当包括的条款 | 讲什么 |
      | :--- | :--- |
      | 当事人的姓名或者名称和住所 | 主体信息 |
      | 住宅的位置 | 客体，即在哪一套住宅上设定 |
      | 居住的条件和要求 | 内容，即"占有、使用"具体怎么行使 |
      | 居住权的期限 | 期限性特征 |
      | 解决争议的方法 | 纠纷解决条款 |

    * > **易错点**：第一个条款里出现"名称"与"居住权主体只能是自然人"并不打架。居住权人一方只能是自然人，但居住权合同的当事人还包括所有权人一方，他完全可以是法人或其他组织，如以房养老案例里的养老中心。

    * 某些内容未约定不一定影响合同效力，例如未约定居住权期限不影响取得居住权，此时居住权人可以**终身居住**。

* **方式二：设立遗嘱**

    * 遗嘱是**单方行为**，由所有权人设立，不需要经过居住权人的同意。

    * 更适用于居住权人本身是无民事行为能力人或限制民事行为能力人、不具备亲自签订合同的民事行为能力的情形。

* **变动要件只有一个**：居住权是在不动产上设立的，**自登记时设立**，采取登记生效主义。

* > **结论**：方式有两种（书面居住权合同、设立遗嘱），要件只有一个（登记生效）。

### 权利与义务

* **居住权人的权利分两个层面**

    * 对客体：按合同约定占有、使用他人的住宅，满足生活居住需要，主要是占有和使用，**没有收益权能**。

    * > **结论**：没有收益权能即**原则上不得出租**——出租收租金属于收益，超出"为了自己生活需要"的设立目的；但当事人约定可以出租的，法律没有必要的反对。

    * 对权利本身：**不能处分**，这与其设立目的直接相关；但享有**保护的权能**，可主张物权请求权或者侵权责任项下的损害赔偿请求权。

    * 例如房屋被第三人侵占可主张原物返还，隔壁邻居把房子租给 KTV 天天噪音可主张排除妨害，因为居住权人同样是物权人。

* **居住权人的义务分两个方面**

    * **消极义务**：行使居住权时妥善使用他人住房，避免对住宅造成损害。

    * **积极义务**：当事人约定有偿设立时按约定支付费用。

    * > **结论**：原则无偿，例外有偿；支付该费用以当事人有约定为前提。

### 消灭

* **两项消灭事由**

    * **当事人约定的期限届满**：期限一到权利归于消灭，居住权人不能以仍然居无定所为由主张继续居住。

    * **居住权人死亡**：设立目的是保障权利人的生活居住需要，人已死亡则目的无法实现，权利归于消灭。

    * 未约定使用期限的，居住权人可以终身居住，何时死亡何时消灭；约定期限而居住权人提前死亡的，虽期限未届满，权利照样归于消灭。

* **消灭的法律后果**

    * 继承人不得继续居住，因为居住权具有人身专属性，不得转让、不得继承。

    * 权利归于消灭后要及时办理**注销登记**手续。

```text
                            居住权
                              │
              ┌───────────────┴───────────────┐
              │                               │
        约定的期限届满                   居住权人死亡
              │                               │
              └───────────────┬───────────────┘
                              │
                        权利归于消灭
                              │
                  ┌───────────┴─────────────┐
                  │                         │
          及时办理注销登记           继承人不得继续居住
                                       （人身专属性：不得转让、
                                         不得继承）
```

* > **易错点**：居住权可以**通过设立遗嘱取得**与居住权**不得继承**不冲突——前者说的是居住权的**取得**途径（进门），后者说的是取得之后本人死亡继承人不能继续居住（出门），是两个不同问题。

* 真题"下列关于居住权的表述正确的是"答案为 ABC：A 居住权人只能是自然人；B 设立以无偿为原则、有偿为例外；C 居住权人死亡时期限尚未届满的，居住权消灭。D 项错在后半句，居住权只能为满足生活居住的需要设立，不存在为满足生产需要设立的情形。

## 地役权

### 概念、两方当事人与分类

* **地役权**

    * > **定义**：不动产的权利人**按照合同的约定**，利用他人不动产以提高自己不动产使用效益的权利。

    * **设立目的**：为自己使用不动产的便利，或者提高自己不动产的效益，两个例子里都是服务于自己的不动产。

    * **主体**：不动产的权利人，也包括使用权人。

    * **客体**：他人的不动产，可以是建筑，也可以是土地。

    * **内容**：利用，指向支配他人财产的使用价值。

    * "役"在这里**不是奴役的意思，是服务的意思**——让别人的不动产服务于自己。

    * > **提示**：这又是一处"按照合同的约定"来行使物权的情形，同样缓和了物权法定原则：到底如何利用别人的不动产，有人要通行、有人要眺望，法律无法直接规定。

* **通行地役权**是抄近道的权利：甲小区业委会每年付乙小区五万元，请求开通门禁权限使居民直接穿过乙小区到地铁站，每天多睡十到十五分钟；利用方式体现为通行。

* **眺望地役权**是不盖高楼的权利：甲一次性付乙四万元，请求乙不在自己土地上盖高层建筑，使自己的房子也能眺望公园美景、提升财产使用效益。

* **需役地与供役地**两方当事人

    * **需役地**：需要被服务的一方，即效益得到提升的不动产，对应需役地权利人。

    * **供役地**：服务于别人、给别人提供便利的一方不动产，对应供役地权利人。

    * > **提示**：更直观的判断标准是**谁付钱谁就是需役地权利人**——花钱才能买来便利。

* **积极地役权与消极地役权**的区分标准是地役权的内容是积极的内容还是消极的内容

    * | 模型 | 地役权的内容 | 性质 |
      | :--- | :--- | :--- |
      | 通行地役权 | 甲小区居民可以从乙小区通行——积极的行为 | 积极地役权 |
      | 眺望地役权 | 甲可以不让乙在自己土地上盖高楼——不作为 | 消极地役权 |

### 六项特征：任意性与从属性

* 要素定位展开：主体是不动产的权利人，也包括使用权人；客体是他人的不动产，可以是建筑也可以是土地；内容是利用；目的是自己不动产的使用便利或效益提高，分别对应通行地役权与眺望地役权。

* 基于这个特殊目的延伸出两个特殊特征

    * **任意性**：权利内容由当事人约定而非由法律规定，有通行、有眺望、有取水等，因为不同权利人对使用便利和效益提升的需求不一样。

    * **从属性**：从属于需役地，需役地转让出去了地役权也随之转让，跟着需役地走。

* 地役权与居住权的对称关系

    * 居住权从属于特定的居住权人，跟着人走，称"人役"性权利；地役权从属于需役地的权利人，跟着需役地走，称"地役权"。

    * 地役权的六项特征即概念里的主体、客体、内容、目的四个关键词，加上基于特殊目的延伸出的任意性和从属性。

```text
  居住权                          地役权
  ──────                          ──────
  跟着「人」走                     跟着「地」走
  从属于特定的居住权人              从属于需役地的权利人
  人死亡 → 居住权消灭               需役地转让 → 地役权随之转让
  居住权人 → 只能特定本人            需役地受让人 → 当然取得地役权
  （人役性）                        （从属性 / 地役性）
```

* > **结论**：一个服务于人，一个服务于地，名字由此而来。人死了但只要地在，地役权依然存续，这是它与居住权不同的地方。

### 与相邻关系的区分

* **立法目的的差异**

    * 相邻关系中的通行、用水、排水体现的是权利人**最基本的需求**，是一个温饱问题，不让通行就出不去、用水排水不照顾就会渴死或被淹死。

    * 地役权解决的是**小康社会的需求**，是为了提升效益、享受更好的生活；不设定地役权也能到地铁站，无非每天多绕点路。

    * > **结论**：相邻关系是法律直接规定的温饱问题，当事人无从谈判；小康的生活要靠自己争取，**一个是基本需求，一个是小康标准**。

* **四个比较角度**

    * | 比较角度 | 地役权 | 相邻关系 |
      | :--- | :--- | :--- |
      | 体系定位 | 属于用益物权范畴，体现为对他人财产使用价值的支配 | 不是一种独立的权利，体现为对所有权的一种限制 |
      | 客体 | 不以相互毗邻为前提，不相邻但能提供服务、能出得起钱即可谈判，调整对象没有特别限制 | 调整对象一定是相互毗邻的不动产，且必须行使该权利，体现必须的需求 |
      | 内容 | 由当事人自主约定而产生，而且多数时候是有偿的 | 以无偿为原则、无偿为例外，因为它解决的是温饱问题 |
      | 变动 | 基于当事人的约定而产生，双方得谈 | 基于法律规定直接产生，不需要谈判，可以直接行使 |

    * 相邻关系体现为对一方所有权的限制、另一方所有权的有所扩张；地役权则必须通过约定才能产生，没有跟别人签订合同就没有这个权利，也不能直接要求对方"你不能盖高楼"。

* > **结论**：五个基本点掐头去尾——前面没有主体，后面没有保护——中间客体、内容、变动三个方面都存在区别。

* > **结论**：选择题里怎么区分看题干就够了：出现"双方有约定"或"支付对价"的情节，成立地役权关系；出现"必须得怎么样怎么样"，成立相邻关系。

* 取水真题辨析：甲村每年付乙村 4000 元、在乙村水库取水 1 万立方米、期限 20 年并办理权利登记，性质为**地役权**。不构成租赁权，因为租赁权要转移占有、使用、收益，而基于合同取水即可；不构成土地承包经营权，因为该权利在农业用地上设立而水库不是农业用地。

* > **提示**：取水是**甲村**的基本需求，与乙村无关；乙村的水库是自己花钱建的，不能要求其无偿提供。

### 取得：两条途径

* **途径一：签订地役权合同**

    * 属于基于民事法律行为的物权变动，合同是要式行为，要签订**书面合同**。

    * **在合同生效时发生物权变动效力**，采取**债权意思主义的物权变动模式**；**未经登记不得对抗善意第三人**，登记是**对抗要件**。

    * 模型：甲乙签订地役权合同约定乙不得盖高于 20 米的建筑，甲一次性支付 20 万元但未办理登记。未登记**不影响甲取得地役权**，但若乙把建设用地使用权转让给不知情的丁，甲不能向丁主张，因为丁是供役地的善意受让人，需要保护其信赖利益。

    * > **提示**："未经登记不得对抗的善意第三人"主要指**供役地的善意受让人**，比如相邻地块的建设用地使用权人。

* **途径二：从属性带来的当然取得**

    * 需役地转让时地役权跟着走，使需役地的受让人**直接取得地役权**。

    * 模型：甲设定地役权后把需役地的建设用地使用权转让给丙，丙虽与乙没签过合同，基于从属性**当然成为地役权人**；对乙可以主张，因为乙是合同相对方不属于第三人；但若该土地已转让给丁，丙不能主张，未经登记不得对抗善意第三人。

```text
  需役地一侧发生变动  ──▶  从属性起作用
  ┌──────────────┐            ┌──────────────────────────┐
  │ 甲（订约人）   │  转让 / 继承 │ 丙（新的需役地权利人）      │
  │ 与乙签合同     │ ─────────▶ │ 当然取得地役权（未办登记）   │
  └──────────────┘            └───────────┬──────────────┘
                                            │
        对乙（合同当事人）可以主张 ✅          │  对丁（善意第三人）不能主张 ❌
        乙是合同相对方，不属于"第三人"            │  未登记 → 不得对抗善意第三人
```

    * > **提示**：考试角度一定先确定谁是需役地权利人、谁是供役地权利人。**需役地一方发生转让考从属性；供役地一方发生转让考未经登记不得对抗善意第三人的效力问题。**

* **真题合用两条线索**：甲为自己房屋使用便利与乙签订地役权合同约定 5 年内乙不得盖楼房，支付 5 万元并办理登记；3 年后甲去世房屋由丙继承，同年乙将楼房卖给丁。答案为 **B、C**。

    * 丙能取得地役权：甲死亡后房屋归丙，丙取得需役地上的权利，基于从属性成为地役权人；供役地虽已转让，但该地役权**办了登记**，丁购房时应当看到地役权登记、知道自己没有盖高楼的权能，故丙可以对抗丁。

    * 丙的取得途径是**从属性（继承）取得**，不是签订合同取得的，故 B 正确、C 正确、A 错误。

    * 丁不能请求乙承担违约责任：地役权内容已记载于房屋登记簿，丁购房时应当知悉，其所付价款也是"不能加盖楼房"的价款。

### 权利与义务

* **需役地权利人的权利分两个层次**

    * 对客体的支配：按合同约定利用供役地，利用方式由合同区别，有通行、有眺望。

    * 对客体的**附属性权能**：实施地役权的附属行为。取得取水权后当然可以通行去取水；通行地役权中穿过小区时可以在长椅上休息一分钟。

    * 对权利的权利主要是**消极**的：地役权**不能单独转让**、**不能单独申请抵押**，因为它具有从属性、不具有独立意义；受到侵害时可主张物权请求权或损害赔偿。

* **供役地权利人的义务分两个方面**

    * 消极义务之一：行使地役权应尽量减少对供役地权利人物权的限制。通行地役权中只要开设门禁、能通过即可解决需求，无权要求乙小区把路修宽。

    * 消极义务之二：利用相关设施时不得妨碍供役地全体人使用相关设施；取得取水权可以利用该设施，但不妨碍供役地权利人利用。

    * 积极义务：约定有偿利用供役地的，按约定支付费用；地役权**有偿为原则、无偿为例外**。

### 消灭：三种事由

* **当事人约定的期限届满**

    * 例如两个小区约定支付的 5 万元是一年通行费，一年到期不续费则取消门禁、权利归于消灭；眺望地役权约定 5 年不盖高楼，5 年一到就可以盖。

* **需役地灭失**

    * 基于从属性决定：地役权从属于需役地、是为需役地的使用便利或效益提升而设，需役地灭失则目的无法实现。

    * 甲小区房屋全部倒塌，或者甲小区整体拆迁、被国家征收，都构成需役地灭失。

    * > **易错点**：甲小区原居民后来住到别的小区，不能以"当初凑过钱可以在乙小区通行"为由继续穿行，需役地已经灭失。

* **地役权合同被解除**

    * 权利因合同生效而设立，也因合同解除而消灭；解除事由均由**供役地权利人**行使。

    * | 解除事由 | 内容 |
      | :--- | :--- |
      | 第一种 | 违反法律规定或者合同约定，滥用地役权的 |
      | 第二种 | 有偿利用供役地的，在约定的付款期限届满后合理期内经两次催告仍不支付费用 |

    * 滥用地役权不能产生正常行使权利的后果，造成损害的还要承担赔偿责任。

    * > **提示**：第二种事由注意"**两次催告**"这个前提。催告属于**准民事法律行为**——包含当事人催告的意思，但法律后果由法律规定，使供役地权利人取得一个解除合同的权利。

## 五种用益物权对照

* 掌握方法完全一致，都从概述、物权变动规则、主要内容三方面切入，但各自有各自的性格。

    * | 权利 | 含义中"利用"如何确定 | 物权变动生效时点 | 内容的两个层次 |
      | :--- | :--- | :--- | :--- |
      | 土地承包经营权 | 依法设立 | 合同生效（债权意思主义） | 对客体使用价值的支配 + 对权利的处分权 |
      | 建设用地使用权 | 依法设立 | 登记时发生物权变动效力 | 对客体使用价值的支配 + 对权利的处分权 |
      | 宅基地使用权 | 依法设立 | 取得批准文件时（特殊处理） | 对客体使用价值的支配；原则上不能单独处分该权利（例外） |
      | 居住权 | 按合同约定 | 登记时发生物权变动效力 | 居住权人的权利 + 居住权人的义务（消极义务与积极义务） |
      | 地役权 | 按合同约定 | 合同生效（债权意思主义） | 需役地权利人的权利 + 供役地权利人的义务（消极义务与积极义务） |

* > **结论**：前三种跟土地相关的用益物权是**依法设立**的，居住权和地役权是基于特殊目的设立的，用的是"**按照合同的约定**"；后两者基于合同设立，所以内容要同时讲权利和义务，义务又都分消极义务与积极义务。

* 特征的完整板块是主体、客体、内容、变动加上保护。

* **变动规则总表**

    * | 权利 | 是否登记生效 | 登记的角色 |
      | :--- | :--- | :--- |
      | 土地承包经营权（一手取得） | 否，合同生效时设立 | 既非生效要件也非对抗要件 |
      | 土地承包经营权（二手取得） | 否，互换、转让合同生效时设立 | 对抗要件 |
      | 土地经营权（期限五年以上） | 否，合同生效时设立 | 对抗要件 |
      | 建设用地使用权 | 是 | 生效要件，划拨与出让均须登记 |
      | 宅基地使用权 | 否，批建即设立 | 不以登记为生效要件 |
      | 居住权 | 是 | 生效要件 |
      | 地役权 | 否，合同生效时设立 | 对抗要件 |
