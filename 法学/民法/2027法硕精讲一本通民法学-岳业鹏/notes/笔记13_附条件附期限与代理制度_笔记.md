# 附条件、附期限与代理制度

## 附条件附期限属于约定的特别生效要件

* **约定的特别生效要件**

    * > **定义**：当事人可以约定某个民事法律行为附条件或者附期限，一旦这么约定，这个行为的效力就取决于条件的成就与否，或者期限的到来与否。

    * 民事法律行为的成立与生效是两个层次：成立解决"有没有一个民事法律行为"的构成问题，生效解决已成立行为"行不行"的评价问题。

    * 特别生效要件分为两支：约定的特别要件是附条件、附期限；法定的特别要件是合同以审批为生效要件。

    * 附条件、附期限的争议几乎全部集中在判断上，关键只有一条：所附事实是不是确定会发生。

---

## 条件与期限的分界

* **条件**

    * > **定义**：当事人在民事法律行为中设定某项事实为条件，以条件的成就与否来决定民事法律行为的效力是发生还是解除。

    * 该事实可能发生、也可能不发生。

    * 条件成就与否不确定，产生纠纷的可能性高，是本部分学习重点。

* **期限**

    * > **定义**：当事人约定一定的期限，以期限的到来来决定民事法律行为的生效或者失效。

    * 该事实确定会发生，一定会到来。

    * 期限必然到来，产生纠纷的可能性相对小。

* 区分标准只有一个：这个事实是不是确定会发生，不能凭感觉。

* 常见判断陷阱是"看起来像时间的东西反而是条件"，因为它未必真能到来。

| 约定 | 附加的是 | 理由 |
| :--- | :--- | :--- |
| 甲的年迈父亲去世后，把祖传清代铜壶以 5 万元卖给你 | 期限 | 人终有一死，这一天一定会到来 |
| 甲的年迈父亲 80 大寿时，将其祖传清代铜壶赠与给乙 | 条件 | 父亲未必活得到 80 大寿，这一天不一定会有 |
| 甲在乙公司工作到 65 周岁，乙公司奖励甲现金 10 万元 | 条件 | 可能活不到 65 岁，也可能在 60 岁之前就被裁员 |

* 延迟退休的正确理解：要工作到 65 周岁才能领取退休金，但 60 岁之前是否有工作无人保证，可能 40 岁就被裁掉。

## 依其性质不得附条件附期限的民事法律行为

* **身份行为不得附条件**

    * > **定义**：为维护公共利益，婚姻、收养、认领等具有身份属性的行为不允许附加条件。

    * 身份关系要求明确，附加条件会使法律关系长期处于不确定状态。

    * 实例：男女朋友先办结婚登记，再约定婚姻效力要待一方考上研究生才发生。办完登记即为合法夫妻，该约定不允许。

* **形成权的行使不得附条件**

    * > **定义**：解除权、撤销权、追认权等形成权的行使不允许附加条件，行使还是不行使必须明确表示。

    * 后果本来已由对方承受，附加不确定条件会使对方更无所适从。

    * 实例：通知解除合同，同时附"今年考研没上岸则解除生效"，相对人无法确定自己处于何种状态。

* **两个例外**

    * 附加条件经过相对方同意的，法律允许——禁止的本意是保护相对方，相对方无异议则无干涉必要。

    * 条件的成就与否纯粹由相对方决定的，允许——决定权在对方手中，条件成就与否也在对方掌控之中，不损害其利益。

    * 实例：通知解除合同并附"你三天内不道歉就生效"，道歉与否完全由对方决定。

## 条件的四项构成要件

* **非法定性**

    * > **定义**：条件必须是当事人约定的，不能是法律规定的。

    * 附条件体现意思自治，由当事人自行决定附加这一限制。

    * 反例：国有资产转让导致国家丧失控制权时须经履行出资人职责的机构决定，这是法律规定而非约定，构成法定特别生效要件，不属于附条件。

* **合法性**

    * > **定义**：民事法律行为所附加的条件必须指向合法的事实。

    * 违反者整个民事法律行为认定无效。

    * 实例：赠与合同附"你把丙打残了房子就是你的"，条件指向侵权行为，合同无效。

* **未来性**

    * > **定义**：条件必须是未来的事实，已经发生的事实不能作为条件。

    * 即使双方当事人不知道该事实已经发生，也不能附为条件。

    * 实例：2023 年约定"若梅西夺得大力神杯则赠手机"，而梅西已在 2022 年卡塔尔世界杯夺冠，条件已发生，不能附。

* **或然性**

    * > **定义**：条件可能发生也可能不发生；确定会发生的是期限，确定不可能发生的不能作为条件。

    * 实例：附"太阳从西边出来时"赠与房屋，该条件永远不可能成就。

| 口诀 | 对应要件 |
| :--- | :--- |
| 合法 | 合法性 |
| 非法 | 非法定性 |
| 未 | 未来性 |
| 然 | 或然性 |

### 或然性不满足时的后果

* 条件永远不可能成就，等于效力开关本身坏了，后果取决于坏在哪个开关上。

```text
条件永远不可能成就时
  ├─ 开关 A「打开效力」= 生效条件   开关坏了  →  行为确定不发生效力
  └─ 开关 B「关闭效力」= 解除条件   开关坏了  →  视为未附条件，效力照常维持
```

* 例一：房屋买卖合同附"太阳从西边出来时生效"，打开的开关坏了，行为不发生效力。

* 例二：房屋买卖合同约定"该合同将失去效力"，关闭的开关坏了，视为未附条件，效力照常维持。

> **易错点**：不满足或然性要求意味着条件永远不可能成就，后果不能一概而论，必须区分当时附加的到底是生效条件还是解除条件。

## 条件的两种分类

### 按条件决定效力的走向

* **生效条件**

    * > **定义**：条件的成就将导致民事法律行为发生效力。

    * 同义表述：延缓条件、停止条件。《民法典》用"生效条件"，考试分析用"延缓条件"，命题中哪个词可能出现要看命题人，所以都要掌握。

    * 条件成就则法律行为发生效力，条件不成立则法律行为不能发生效力。

    * 实例：若乙 2027 年考取人大法学院研究生则赠予《王泽鉴全集》精装版一套。

* **解除条件**

    * > **定义**：条件的成就将导致民事法律行为丧失效力。

    * 同义表述：失效条件。

    * 实例：甲赠与《王泽鉴全集》，约定乙考不上人大就退还该书，条件成就时赠与合同失效。

* 上述两例结果都是"考上有书、考不上无书"，但约定方式不同，条件类型完全不同。

### 按条件内容

* **积极条件**

    * > **定义**：条件的成就要求某个事实发生。

    * 同义表述：肯定条件。

    * 实例：乙在一年内结婚则赠与房屋一套。

* **消极条件**

    * > **定义**：条件的成就要求某个事实不发生。

    * 同义表述：否定条件。

    * 实例一：乙 2027 年未能考取人大则退还赠书，条件成就是"考不上"这一消极事实。

    * 实例二：丙不和甲的儿子结婚则赠与丙 50 万元，条件成就是"不结婚"这一消极事实。

> **易错点**：结婚、收养这类行为不能成为"被附条件的民事法律行为"，但可以成为"条件的内容"。分析时先确定哪个是民事法律行为、哪个是条件。

* 以"丙不与甲的儿子结婚则赠与 50 万元"为例，民事法律行为是甲赠与丙 50 万元的赠与合同，条件才是丙不与甲的儿子结婚。

* 此类约定不侵犯婚姻自主权：丙既可选择结婚放弃 50 万元，也可选择不结婚而与他人结婚。

## 条件成就的妨碍与期待利益

* **期待利益**

    * > **定义**：附加条件时，一方对将来取得某种利益所抱有的期待，法律对该期待予以保护。

    * 保护路径是不利推定：谁干预条件成就的自然走向，就对谁作不利推定。

* 一方为自己的利益不正当**阻止**条件成就的，视为条件已成就。

    * 实例：约定甲考上北大法学院则乙赠轿车并办了公证，乙在考试前夜故意打扰甲休息致其发挥失常，视为条件已成就，乙必须给车。

* 一方为自己的利益不正当**促成**条件成就的，视为条件不成就。

* 依据是诚信原则，惩罚不诚信行为并保护另一方的期待利益。

---

## 附期限的分类

* **附生效期限**

    * > **定义**：某个期限的到来将导致民事法律行为发生效力。

    * 同义表述：延缓期限。相当于打开效力的开关。

* **附终止期限**

    * > **定义**：某个期限的到来将导致民事法律行为失去效力。

    * 同义表述：解除期限。相当于关闭效力的开关。

## 代理的含义与三方结构

* **代理**

    * > **定义**：代理人在代理权限范围内，经过授权和相对人实施民事法律行为，而该法律后果由被代理人来承担。

    * 基于意思自治，民事法律行为通常由当事人亲自实施形成双方关系；借他人之手实施就形成三方结构。

    * 制度价值有两个：弥补某些人民事行为能力的不足；通过委托授权扩张某些人参与民事活动的范围。

    * 判断一件事是不是代理，第一个问题永远是这里有没有三方。

```text
        乙 保险公司 = 被代理人（本人）
        幕后参与交易，是本来参与交易的人
                 │
                 │  ① 委托授权
                 ↓
        甲 保险代理人
        以乙的名义对外实施行为
                 │
                 │  ② 与丙签订保险合同
                 ↓
        丙 = 相对人（有的教材称"第三人"）

        后果：合同约束 乙 与 丙
        丙出险后主张保险金 → 找 乙，不找 甲
```

* **被代理人**（本人）——幕后参与交易的本尊，本来就参与交易的人。

* **代理人**——借他人之手扩大民事活动范围的人。

* **相对人**——交易的相对方；与"第三人"是通用表述。

* 三方关系最大的特点：实施行为的是代理人与相对人，承担后果的是被代理人与相对人。

* 实例：甲受乙保险公司委托对外卖保险给亲戚丙，丙出险后找乙保险公司主张保险金，不找甲。

### 代理后果的归属

* 员工甲受公司委托为全公司买电影票，意外抽中 3700 元黄金并发朋友圈炫耀。

* 公司老板点赞并评论要求甲下周把黄金交到公司，甲以"凭运气抽中"为由拒绝。

* 分析：交易相对方是公司和电影院，行为由甲实施，后果由公司承担；买票款可向公司财务报销。

* 由公司承担义务，则交易所产生的权益当然由公司享有，行为人拿走的收益只要是代理行为的产物就应交给被代理人。

* 同类真题：学校委托教务人员王某采购教学设备，王某在百货公司抽中数码相机，答案归学校，理由同样是"后果由学校承担，收益也归学校"。

### 代理与传达人、中介人的区分

* **传达人**只负责传达意思，别人说什么就传什么，相当于鹦鹉学舌，不能决定和改变意思表示的内容。

* **中介人**只负责撮合双方、牵线搭桥，不能参与或决定交易的具体内容。

* 代理人只要不超出授权范围，就可以决定与相对人实施的民事法律行为的内容，如买哪部电影、到哪家影院、哪个场次。

| | 传达人 | 中介人 | 代理人 |
| :--- | :--- | :--- | :--- |
| 干的是什么 | 传达意思 | 撮合双方 | 直接与相对人实施民事法律行为 |
| 能否决定意思表示的内容 | 不能，鹦鹉学舌 | 不能，只牵线搭桥 | 能在授权范围内决定 |
| 有无代理权 | 无 | 无 | 有，且受权限约束 |

### 直接代理与间接代理

* 以**被代理人**名义实施的是直接代理，以**自己**名义实施的是间接代理。

* 《民法典》总则编规定的代理都是直接代理；《合同编》委托合同部分同时规定了间接代理制度。

* 考试分析和官方教材把两者合称广义上的代理概念；讲代理权、无权代理规则时用的都是直接代理口径。

### 代理实施的内容

* 代理实施的是民事法律行为，通常体现为签订合同。

* 事实行为不适用代理制度，如带人算账、带人抄写、带人驾车，涉及的仍是双方当事人。

> **易错点**：代驾把人撞了也出了第三人，但并未形成三方结构，而是产生了一项新的侵权损害赔偿法律关系。委托代驾的范围不可能包括替你撞人，所以代驾不是代理。

### 违法行为的代理

* 违法行为当事人自己都不能实施，也不能借他人之手实施。

* 代理人知道或应当知道代理事项违法仍实施，或者被代理人知道或应当知道代理人实施违法行为而未作反对表示的，双方都有过错。

* 一方实施违法、一方知情，造成的后果由双方承担连带责任，构成共同侵权。

## 代理的适用范围

* **本人亲自实施**

    * > **定义**：依照法律规定、当事人约定，或者依照民事法律行为的性质，应当由本人亲自实施的民事法律行为不得代理。

* 第一个层次是依民事法律行为的性质必须本人亲自实施，主要是人身性质的行为：登记结婚、离婚、生养子女、立遗嘱。替身可以替演员演戏，但离婚必须亲自办手续。

* 第二个层次是依法律规定或当事人约定由本人亲自实施，如公司请某名人演讲，基于约定只能由该名人本人前往。

| 行为 | 能否代理 | 理由 |
| :--- | :--- | :--- |
| 立遗嘱 | 不能 | 具人身专属性和身份属性，须本人亲自实施 |
| 申请商标注册 | 能 | 法律未禁止，实践中可由商标代理人、专利代理人代办 |
| 订立合同 | 能 | 代理适用的最核心范围 |
| 参加行政诉讼 | 能 | 法律不禁止，只归入诉讼代理范畴，不属于民事代理，但并非不得代理 |

* 考"可以还是不可以代理"时，考点是法律规定不得代理的特别情形。

## 代理的分类

```text
分类标准            类型                        区分的关键
─────────────────────────────────────────────────────────────
代理权的来源        法定代理 / 委托代理          法律规定的权力，还是本人授权
代理人的产生方式    本代理 / 副代理              本人直接授权，还是代理人二次授权
实施行为的名义      直接代理 / 间接代理          被代理人名义，还是自己名义
代理人的数量        单独代理 / 共同代理          一个人，还是两人以上共同行使
```

### 法定代理与委托代理

* **法定代理**

    * > **定义**：代理权直接来源于法律规定的代理。

    * 主要适用于限制或无民事行为能力人，由法定代理人代为实施民事法律行为以弥补其行为能力不足。

* **委托代理**

    * > **定义**：代理权来源于被代理人委托授权的代理。

    * 体现当事人意思自治，又称议定代理。

* 委托授权通常分成两个民事法律行为。

```text
第一步：委托合同（双方行为）
  甲公司  ←── 乙 ──→   约定委托事项、权限、行使方式、报酬
  · 必须双方意思表示达成一致
  · 要求双方当时都具有相应的民事行为能力

第二步：授权委托书（单方行为）
  甲公司 ──→ 相对人/第三人   载明代理人姓名名称、代理事项、权限、期限
  · 只需被代理人（甲公司）单方实施即可
  · 由被代理人签名或者盖章
  · 代理人不必签名盖章
```

| | 委托合同 | 委托授权（授权委托书） |
| :--- | :--- | :--- |
| 行为性质 | 双方行为 | 单方行为 |
| 由谁实施 | 保险公司与代理人双方 | 只需被代理人一方 |
| 法律效果 | 约定彼此的权利义务 | 代理人取得代理权 |
| 对主体的要求 | 双方当时都须有相应的民事行为能力 | 被代理人签名或盖章即可 |

* 授权委托书是给相对人看的，实施民事法律行为时须向对方表明有代理权。

> **易错点**：委托合同是双方行为，缺一方意思表示一致就不成立；委托授权是单方行为，被代理人一方的意思表示就够，代理人签不签都不影响其成立。

* 法硕考试大纲和考试分析都没有职务代理，但《民法典》有明确规定，且法硕在非法学法条分析题中考过；命题人并不只看考试分析。

* **职务代理**

    * > **定义**：基于行为人所担任的职务而产生的代理，代理权来源于当事人所担任的职务。

    * 例：商场销售员有销售服装的权限，办公室主任有以公司名义采购办公用品的权限，饭店前台有接受客户预订包间的权限。

    * 效力规则：执行法人或非法人组织工作任务的人员，就其职权范围内的事项以该组织名义实施的民事法律行为，最终可对该组织发生效力。

    * 性质：不是独立的代理——按代理权来源分类只有法定代理和委托代理；它不是来自法律规定而是来自委托授权，所以属于委托代理的一种具体类型，是一种默示的授权。

| | 一般的委托代理 | 职务代理 |
| :--- | :--- | :--- |
| 授权的范围 | 一事一授权，零售，一个一个来 | 职权范围内的概括授权，批发 |
| 授权的方式 | 明示：单独出具一份委托授权书 | 默示：安排岗位这个行为本身就是授权 |
| 双方当时的关系 | 平等主体，合作关系（民法典委托合同） | 雇佣关系、从属性关系（受劳动合同法规范） |

* 职务代理实例：服装店老板甲聘用乙任销售员，消费者丙选中羽绒服，乙承诺年底促销七折并以服装店名义售出，构成有权代理。

* 被代理人可要求销售员出具授权书吗？不能——把员工安排在这个岗位上本身就代表有授权。

### 本代理与副代理

* **本代理**

    * > **定义**：由本人或被代理人亲自选定的代理人，以及依照法律规定产生的代理。

* **副代理**

    * > **定义**：代理人通过二次授权而产生的代理，又称再代理或转委托。

* 实例：甲公司派销售员乙参加广州博览会，乙经甲公司同意转委托给更专业的丙去采购，乙的代理权来自甲公司直接授权，是本代理；丙的代理权来自乙的二次授权，是副代理人；甲公司仍是被代理人。

* 无论本代理还是副代理，他们都是被代理人的代理人；副代理下丙以甲公司名义与丁订约，后果由甲公司承担。

* **构成合法副代理的两种情形**

    * 基于被代理人的事先授权，或者事后追认。

    * 法定情形：没有经过同意，但在紧急情况下为维护被代理人利益需要转委托。

* 紧急情况认定（司法解释）包含三个方面要件。

```text
┌──────────┬─────────────────────────────────────────────┐
│ 适用前提 │ 出现特殊原因：疾病、通讯中断、疫情防控等   │
├──────────┼─────────────────────────────────────────────┤
│ 起因条件 │ ① 自己办不了代理事项                       │
│          │ ② 同时联系不上被代理人，取不到被代理人的意见│
├──────────┼─────────────────────────────────────────────┤
│ 后果     │ 不及时转委托，将给被代理人造成损失或扩大损失│
│          │ ——先斩后奏正是为了被代理人的利益           │
└──────────┴─────────────────────────────────────────────┘
```

* 完整实例：乙到广州突生疾病住院，联系甲公司领导一直关机，博览会只剩最后一天，不转委托将错过博览会造成更大损失，故紧急委托当地朋友丙处理，丙取得副代理权。

* 题目未出现紧急情况情节的，一律按必须经同意或追认处理。

* **副代理的法律后果**

    * 构成合法副代理的，丙是甲公司的代理人，后果由甲公司承担；转委托的代理人乙原则上不承担责任，只在对第三人的选任和指示存在过错时承担相应责任。

    * 不构成合法副代理的（既无同意追认又无紧急情况），丙不是甲公司的代理人，后果由擅自转委托的乙承担。

* 真题：甲委托乙购买手机并预付购机款，乙未将购机款交给丙也未征求甲意见，丙购机后甲拒绝接手。结论是乙转委托无效、不构成合法副代理，乙未对外实施行为故未形成三方关系，只存在甲乙之间的委托合同关系，甲有权依委托合同请求乙返还购机款；民法典已无"指定代理"之说。

### 直接代理与间接代理

* 区分标准是代理人实施代理行为时使用的名义：以被代理人（本人）名义为直接代理，以自己名义为间接代理。

* 民法典总则编规定的是直接代理；间接代理的规则在合同编的委托合同部分。

* 讲代理规则时用的都是直接代理口径。

### 单独代理与共同代理

* **单独代理**：代理人只有一个人。

* **共同代理**：代理人由两人以上共同行使代理权，如一个复杂案件委托三个律所分别承担民事、行政、刑事部分。

## 代理权的产生

* **两条来源**

    * > **结论**：法定代理的代理权来自法律的直接规定；委托代理的代理权来自被代理人的委托授权。

* 委托授权是意思自治的产物，所以有一整套围绕信任展开的解除与终止规则；法定代理是法律直接赋予的，终止事由要回到监护制度里去找。

## 代理权的行使

* **积极方面两条硬要求**

    * 第一，在代理权限范围内行使，不能越界；一旦超出范围，性质变成无权代理。

    * 第二，行使代理权时须维护被代理人的利益——后果最终由被代理人买单，代理权行使的最高原则就是把被代理人的利益放在第一位。

    * 凡是没有做到这一点的，就构成滥用代理权。

* 《民法典》为代理权专设三种滥用形态，共同点都是代理人行使代理权时没有把维护被代理人的利益放到第一位。

* **恶意代理**

    * > **定义**：代理人与相对人恶意串通，损害被代理人的合法权益。

    * 被代理人可以主张不承担民事责任；造成损失的，代理人与相对人构成共同侵权，承担连带责任。

    * 实例：员工唐某受公司委托向乙公司订购空气净化器，私下把单价提高 200 元，乙公司每台回扣唐某 100 元。

* 恶意代理合同效力存在无效说与效力未定说两种理论观点。《合同编通则司法解释》第 23 条只规定"法人、非法人组织可以主张不承担民事责任"，未涉及合同效力——因为合同无效或效力未定未获追认都能产生不承担责任的后果。

* 法硕官方教材、考试分析和真题采用的是无效说，考试中按无效说掌握；案情中没有出现被代理人明确认可串通行为情节的，合同依然认定无效。

* **自己代理**

    * > **定义**：代理人以被代理人的名义，和自己进行民事活动。

    * 本质是利益冲突，代理人无法把被代理人的利益放在第一位，法律不允许。

    * 后果是被代理人可拒绝承担代理后果；例外是被代理人同意或者追认的，代理行为依然可以有效。

    * 实例：教师甲受学校委托订购作业本，甲自家开文具店，从自家店购买；学校明确同意直接从甲家买则可发生代理后果。

* **双方代理**

    * > **定义**：代理人以被代理人的名义，和自己代理的其他人进行民事活动，交易的双方当事人都由一个人代理。

    * 本质是一仆难为二主，顾此失彼，难以同时兼顾两个被代理人的利益，法律不允许。

    * 后果是 C 公司或乙均可拒绝承担该行为的后果。

> **易错点**：双方代理要发生代理后果，需要两个被代理人都表示同意；其中任何一个不同意，都不能发生代理后果。

| 类型 | 行为特征 | 恢复代理后果的条件 | 后果 |
| :--- | :--- | :--- | :--- |
| 恶意代理 | 代理人与相对人恶意串通，损害被代理人合法权益 | 原则上无；被代理人明确认可的除外 | 被代理人可主张不承担民事责任；代理人与相对人构成共同侵权，承担连带责任 |
| 自己代理 | 代理人以被代理人的名义与自己进行民事活动 | 被代理人同意或者追认 | 被代理人可拒绝承担代理后果 |
| 双方代理 | 代理人以被代理人的名义与自己代理的其他人进行民事活动 | 两个被代理人都同意 | 任一被代理人均可拒绝承担代理后果 |

* 共同代理不改变定性：甲公司委托魏某、董某购药，魏某背着董某与卖方乙公司串通购回假药，构成恶意代理；连带责任范围看谁实际实施了串通行为，只有魏某与乙公司承担连带责任，未串通的董某不承担。

## 代理权的终止

### 委托代理的终止情形

* **五项法定情形**

    * 代理期限届满或者代理事务完成。

    * 被代理人取消委托或者代理人辞去委托。

    * 代理人丧失民事行为能力。

    * 代理人或者被代理人死亡。

    * 作为代理人或者被代理人的法人、非法人组织终止。

* 取消委托与辞去委托是双方任意解除权，源于委托合同以双方信任关系为基础。

* 按主体线索重排，五项情形的归属如下。

```text
委托代理终止的五种情形
│
├─ 双方均可适用
│   ├─ 意思自治：被代理人取消委托 / 代理人辞去委托   （第 2 项）
│   └─ 主体资格消灭
│       ├─ 自然人死亡：代理人或被代理人死亡         （第 4 项）
│       └─ 组织终止：法人或非法人组织终止           （第 5 项）
│
├─ 仅适用于被代理人
│   └─ 代理期限届满 / 代理事务完成                  （第 1 项）
│      └─ 期限与事务均记载于被代理人单方出具的授权书
│
└─ 仅适用于代理人
    └─ 丧失民事行为能力                            （第 3 项）
```

* 期限与事务只归被代理人一方，是因为二者均记载在被代理人单方出具的授权书中，体现被代理人的意思。

### 被代理人死亡后的四种例外

* 原则是被代理人死亡则委托代理终止，理由是其债权债务由继承人承受，而继承人与原代理人常常不具备天然的信赖基础。

* 法律留了四道口子，分别保护三类主体利益。

```text
被代理人死亡后，代理行为仍然有效的四种例外
│
├─ 保护被代理人的遗愿：授权中明确，代理权于代理事务完成时终止
├─ 保护代理人的信赖利益：代理人不知道且不应当知道被代理人死亡
├─ 保护继承的利益：死亡前已经开始实施，死亡后为继承利益继续代理
└─ 保护继承的利益：被代理人的继承人予以承认
      └─ 继承人为两人以上时，须全体继承人一致同意
```

* 第一种保护被代理人的遗愿：授权书中明确"不管我活没活着，只要代理任务没完成就帮我完成"。

* 第二种保护代理人的信赖利益：代理人不知情且不应知情，仍在兢兢业业完成事务，后果由继承人承受。

* 第三种保护继承利益：死亡前已开始实施，死亡后为继承利益继续完成，避免半途而废。

* 第四种保护继承利益：继承人承认意味着委托关系重新搭建；继承人为两人以上时须全体一致同意。

* 实例：老王有房委托甲代卖，老王死亡后由三个儿子共同继承。三人都同意则甲的代理权继续有效；只有老大同意而老二老三不同意，则不构成例外，甲无代理权——因为该房产是共同共有，处分本身就需要全体一致同意，连老大自己都不能单独卖。

> **提示**：出现"被代理人已经死亡"而未落入这四种例外的，代理关系应当认定终止，原则与例外要区分清楚。

### 法定代理的终止

* 法定代理主要指监护人的法定代理权，其终止与监护关系的终止情形一致。

```text
法定代理的终止事由
│
├─ 双方均可适用：任何一方当事人死亡
│   └─ 双方均为自然人，没有「组织终止」这一说
│
├─ 仅适用于被代理人（被监护人）
│   └─ 取得或者恢复完全民事行为能力
│
└─ 仅适用于代理人（监护人）
    └─ 丧失民事行为能力，另设兜底条款
```

* 与委托代理的明显差别：法定代理中双方都是自然人，所以只有死亡，没有"组织终止"这一说。

* 委托代理终止看的是信任这条线，法定代理终止看的是主体资格这条线，这是代理权产生方式不同带来的分野。

## 无权代理的形态与保护顺序

* **无权代理**

    * > **定义**：欠缺代理权，却以被代理人的名义从事民事活动的行为。

    * 核心在"欠缺代理权"四个字，共四种形态：《民法典》明确三种，司法解释补充一种。

| 情形 | 界定 | 实例 |
| :--- | :--- | :--- |
| 未经授权 | 从来没有授过权，但确是以其名义代理 | 求职者想先卖保险证明自己，未经许可以保险公司名义销售 |
| 超越代理权限 | 本有代理权，但在权限范围内行事之外越界 | 受托买电影票的员工改去订火锅 |
| 代理权终止后仍代理 | 之前有过，但期限届满或人已被开除 | 离职员工继续以公司名义行事 |
| 共同代理中擅自行动 | 数个代理人共同行使代理权必须协商一致 | 共同代理人中一人擅自径行行使 |

```text
                    甲（被代理人）
                   ／             ＼
               代理关系              法律关系
                 ／                    ＼
        乙（无权代理人）            丙（相对人）
```

* 法律关系直接落在甲与丙身上，乙与甲之间是代理关系。

* 乙是闯祸的一方，丙多数时候无辜，甲完全不知情，所以既保护甲也兼顾丙。

* 原则上先保护被代理人的利益——没有经过授权，凭什么让甲承担后果；结果是无权代理行为效力未定。

* 例外地先保护相对人：相对人对无权代理人有高度信赖时，由表见代理制度例外保障。

| | 狭义无权代理 | 表见代理 |
| :--- | :--- | :--- |
| 保护顺序 | 先保护被代理人 | 例外地先保护相对人 |
| 体现的价值观 | 被代理人的利益 | 交易安全 |
| 合同效力 | 效力未定 | 代理有效 |
| 相对人地位 | 无过错也要自己承担损失 | 信赖受保护 |

* 两者加起来构成广义上的无权代理。

## 狭义无权代理的处理规则

```text
    乙以甲之名与丙订约，但乙欠缺代理权
                            │
                            ▼
                     合同效力未定
                            │
                ┌───────────┴───────────┐
                ▼                       ▼
          甲：追认                  甲：拒绝追认
        合同对双方生效            合同对甲不发生效力
                                        │
                                        ▼
                                  丙是否善意？
                           ┌──────────┴──────────┐
                           ▼                     ▼
                    丙是善意相对人            丙非善意
                        有选择权                无选择权
            （请求乙履行 / 请求乙赔偿）     乙与丙按过错分担
```

* **追认是形成权**；甲追认的，合同生效，甲照约履行。

* **善意相对人的选择权**

    * 适用前提是相对人确实善意，即不知道对方是无权代理人；不善意的人没有这个待遇。

    * 请求履行：请求无权代理人乙履行债务，突破合同相对性，是对善意相对人的特殊保护——既然祸是你闯的，被代理人不追认就要你履行。

    * 请求赔偿：请求无权代理人乙赔偿损失，以信赖利益为限，本质是缔约过失责任，赔偿范围不得超过代理行为有效时所能获得的利益。

    * 两个主张二选一，不能一并主张。

* **非善意的后果**：相对人知道或应当知道的，没有选择权，无权代理人乙与相对人丙按各自过错分担损失。

* **老干妈与腾讯案**

    * 2019 年 3 月曹某等三人伪造公章，未经授权以老干妈公司名义与腾讯公司签订 1624 万元推广合作协议。

    * 老干妈是三方关系中的被代理人，曹某等人为无权代理人，腾讯为相对人；腾讯已在 QQ 飞车植入广告但迟迟未收到价款，申请冻结了老干妈 1624 万元财产。

    * 老干妈发声明从未授权并报警，合同构成效力未定；老干妈不追认则不承担 1624 万元债务，保护了被代理人的利益。

    * 若腾讯善意，可选择向曹某等人主张赔偿信赖利益损失，或选择请求曹某等人履行合同支付 1624 万元；但曹某等人赔不起。

    * 若腾讯非善意，则没有选择权，双方按过错分担。

> **易错点**：该案中很难说腾讯完全没有过错——与老干妈这样有名的公司签 1000 多万标的的合同，都没有派人去核实洽谈，未尽到应有的注意义务。

## 表见代理

* **表见代理**

    * > **定义**：虽以无权代理为适用前提，但符合《民法典》第 172 条的，构成代理有效。

    * 相对人不仅不知道对方是无权代理，而且有积极的理由相信其有代理权，法律强化对相对人的保护。

    * 制度逻辑是牺牲一个合法的被代理人来成全交易安全；正因为是牺牲，才必须符合构成要件才能适用。

    * 案情没有出现可能构成表见代理的特殊情节的，一律按狭义无权代理处理为效力未定。

* **四道门槛**

    * 适用前提：代理行为本身必须是无权代理；本来有代理权的按正常代理规定处理。

    * 客观要件——被代理权的外观：无权代理人得有被授予代理权的外表，如离职业务员手中盖有公章的空白合同和工作证件；比喻是自己把自己包装成高富帅。

    * 外观必须是真实的外观；伪造的文件只是假象，不构成表见代理的外观。

    * 主观要件——相对人不知道且没有过失：不仅要求不知道，还要求没有过失；因过失而不知情的不能构成有理由相信，标准是已尽到善良管理人应尽的注意义务。

    * 后果要件——相对人基于信任实施了民事法律行为：对方伪装再深但被识破，或根本没签合同，都不构成本要件。

* 老干妈案中曹某等人所持公章系伪造，腾讯不能主张表见代理——假章只是假象。

* 这不等于腾讯不值得保护，而是先保护被代理人是原则；主张交易安全优先是例外，例外的理由要更充足。若私刻公章的合同都要让被代理人背锅，企业经营风险过大。

* 实例：保险公司业务员甲离职后公司未及时收回其盖有公章的空白合同和工作证件，甲持此与乙签订保险合同，构成表见代理；保险公司即使不追认、未收到保险费，发生保险事故仍须赔付，之后可向甲追偿。

* **举证责任分配正好相反**

    * 存在代理权的外观，由相对人承担举证责任。

    * 主观要件（相对人知情或有过失），由被代理人证明。

* **善意与有理由相信的差别**

| | 善意相对人 | 有理由相信 |
| :--- | :--- | :--- |
| 主观状态 | 单纯不知情，最多再尽到一点注意义务 | 不仅不知道，而且没有任何过失 |
| 客观外观 | 不要求 | 要求存在代理权的外观 |
| 信赖程度 | 较低 | 较高 |

* 有理由相信的相对人肯定是善意相对人，但善意相对人不一定有理由相信。

* **三种常见表见代理场景**

| 无权代理情形 | 常见的表见代理场景 |
| :--- | :--- |
| 根本没有经过授权 | 表见授权 |
| 超越代理权限 | 授权不明 |
| 代理关系终止后仍代理 | 代理关系终止后没有采取任何措施 |

* 表见授权：甲公司领导在签约晚宴上明确告知对方将派小王代表本公司负责项目，小王敬酒三杯，之后公司经研究未实际授权；对方可能已产生信赖。

* 授权不明：本有代理权但边界不清，一不小心越界，越界后符合要件即可能构成表见代理。

* 代理关系终止后未采取措施：应收回的文件没有收回，才使离职员工有招摇撞骗的机会。

* 法律后果是代理有效：即使被代理人不追认合同也要履行并对合同负责，其损失可向无权代理人主张赔偿。

## 职务代理中的越权与追偿

* **内部限制不得对抗善意相对人**

    * > **定义**：法人或者非法人组织对执行其工作任务的人员职权范围的限制，不得对抗善意相对人。

    * 工作人员超越职权范围实施无权代理行为的，相对人善意的仍可让法人或非法人组织承担后果。

    * 相对人非善意的，法人或非法人组织可以不承担合同后果。

    * 职务代理中的无权代理，被代理人要不要履行，取决于相对人是不是善意。

* **认定善意：区分超越的是法定通常权限还是内部权限**

    * 核心意义在于分配举证责任，与法定代表人超越代表权限的判断思路一致。

* **超越法定或通常权限：推定相对人知情**

    * 权限规定在法律中，相对人稍有法律常识就应当知道普通工作人员无此权限；连普通法律常识都没有的，不能主张善意。

    * 还包括不属于通常情况下该一级职权可以处理的事项，如前台小姑娘签食材长期供应合同、服装店销售员以公司职员名义对外借款。

    * 原则后果：相对人无权主张该合同对法人或非法人组织发生效力。

    * 例外：能构成表见代理的，仍由法人或非法人组织承担后果。

* 例一：服装厂商后勤部经理老马未经同意以公司名义为客户联营公司向银行提供 20 万元担保，《公司法》第 15 条要求对外担保须由董事会或股东会决议，连法定代表人董事长都没有此权限，推定银行知情，甲公司原则上可拒绝承担担保责任；若老马拿出的是套打出来的股东会决议（签名真实但决议内容是后来套打上去的），银行已尽注意义务仍无法查明来历，可构成表见代理，甲公司须担责。

* 例二：马某擅自以合伙企业名义聘用"更聪明的岳母"任经营管理人员，《合伙企业法》第 31 条要求全体合伙人一致同意，推定该"岳母"非善意，合伙企业有权拒绝履行；除非她能证明构成表见代理。

* **超越内部权限：推定相对人不知情**

    * 内部权限外人难以知道，推定相对人善意且不知情，法人或非法人组织应当承担合同后果，不能对抗善意相对人。

    * 例外：法人或非法人组织能举证证明相对人知情的，则不承担后果。

* 例三：公司章程规定部门经理签订超过 20 万元的合同须报董事会批准，后勤部经理老马未经批准签订 25 万元订单，原则上对方公司可请求甲公司履行；若甲公司能证明对方知情（两家公司打交道十几年、早已知道该内部文件），则不承担。

| | 超越法定或通常权限 | 超越内部权限 |
| :--- | :--- | :--- |
| 权限来源 | 法律明文规定，或生活常识可知 | 章程、内部文件等自定规则 |
| 对相对人的推定 | 推定其知道或应当知道 | 推定其不知情 |
| 举证责任所在 | 相对人（须证明自己善意） | 法人或非法人组织（须证明相对人知情） |
| 原则后果 | 相对人无权主张合同对法人或组织生效 | 法人或非法人组织应承担合同后果 |
| 例外 | 能构成表见代理的，仍由法人或组织担责 | 能证明相对人知情或应知的，法人或组织不担责 |

* **追偿权**

    * 法人或非法人组织承担了民事责任后，可向有故意或过失的工作人员追偿。

    * 普通工作人员只有故意或重大过失时才被内部追偿，一般过失属于尽到注意义务，可宽容。

    * 法定代表人只要有过错就会被内部追偿，董事长、老板要承担更重的责任。

## 民事法律行为效力的评价层次

* 民事法律行为的规范分成立与生效两个层次：成立解决构成问题，生效解决法律评价问题。

* 一般要件是否满足，效力评价为四种形态：有效、可撤销、效力未定、无效。

* 特别要件分两支：约定的特别要件是附条件和附期限；法定的特别要件是合同以审批为生效要件。
