# 民事法律事实

## 民事法律事实的含义

* **民事法律事实**

    * > **定义**：依法能够引起民事法律关系产生、变更、消灭的客观现象。

    * 三个关键词分别承担不同功能：「依法」强调**法定性**，即须带有民法规范认可、或者民法规范确认的属性；「事实」体现**客观现象**；「法律」用来与生活事实对照划界。

    * 生活事实是梳洗打扮、穿衣吃饭、出去逛街遛弯一类现象，不会导致民事法律关系变动；法律事实则会导致法律关系发生变动，这是二者最干净的分界。

    * 签订合同、办理结婚登记、发生交通事故等事实都会让某个民事法律关系产生、变更或消灭，因而都是民事法律事实。

* **依法要件的约束力**

    * 客观现象要引起法律关系变动，必须以得到法律认可为前提；法律不认可，即使当事人有此意愿，也不能发生该法律后果。

    * 父母子女关系不能因当事人的单方声明而被故意消灭；退一步说，双方也不能以协议方式断绝父母子女关系，法律对这两种做法都不认可。

    * 一项客观现象只有同时满足「依法」和「能够引起民事法律关系产生、变更、消灭」两个要求，才构成民事法律事实。

* **同一组事实的三种关系变动**

    | 案例中的事实 | 引起的关系变动 | 归类理由 |
    | --- | --- | --- |
    | 网上买手机（签订买卖合同） | 产生买卖合同关系 | 有民事法律关系产生 |
    | 办理结婚登记 | 产生夫妻关系 | 有民事法律关系产生 |
    | 小王出生 | 产生父母子女关系 | 有民事法律关系产生 |
    | 驾车撞伤外卖员 | 产生侵权损害赔偿之债 | 有民事法律关系产生 |
    | 创作十五万字文稿 | 产生一项著作权 | 有民事法律关系产生 |
    | 立遗嘱把财产留给小王 | 遗嘱所涉及的继承安排发生效力 | 有民事法律关系变更 |
    | 王某死亡 | 民事主体归于消灭，同时启动继承法律关系的适用 | 有民事法律关系消灭 |

## 民事法律关系变动的三项条件

* **三项必备条件**

    * 民事法律关系要在实践当中真的发生变动，必须**同时**满足三个条件，缺一不可。

    * 第一，要有**民事法律规范**——客观现象要能导致法律关系变动，必须是被法律所认可的，这正是概念中「依法」二字的意义。

    * 第二，要有**现实的民事主体**——这样才能在实践当中现实地发生一个法律关系的变动。

    * 第三，要发生一个**民事法律事实**——得有这个客观现象提供动力。

* **继承场景下的逐项检验**

    * 老王有房产一套、存款一百万，除儿子小王外无其他继承人，老王因意外死亡后小王依法取得遗产，遗产所有权从老王转移至小王。

    * 缺规范：假如民法典规定任何人死亡后遗产一律充公，制度上就不认，小王不能取得。

    * 缺主体：法律里就算有继承制度，现实中人都不在了，也谈不上法律关系的变动。

    * 缺事实：老王不死，小王只能眼巴巴地看着，财产也不能由他直接取得。

* **两项最不可或缺的条件**

    * 最不可或缺的是**主体制度**与**民事法律事实（变动制度）**这两项。

    * 制定民法典时正是把这两方面共计的规则提取出来，形成一般性规定，即**民法总则**。

    * 民法总则因而分为两个层次：主体制度讲三类主体——自然人、法人、非法人组织；变动制度讲三项内容——民事法律行为、代理、诉讼时效。

    * 主体制度对应总则编第三、四、五章，变动制度对应第六、七、八章，这八章的编排有理论依据，并非偶然。

## 事实构成

* **事实构成**

    * 一个事实即可导致某项法律关系变动的，该事实就是民事法律事实。

    * 需要两个以上民事法律事实组合在一起才能发生法律关系变动的，就叫**民事法律关系的事实构成**。

    * 例：被继承人除子女外还有配偶和女儿的，子女要取得全部遗产只能基于遗嘱继承——一方面要发生被继承人死亡的事实，另一方面还要有「有效遗嘱」这样一个事实，两个事实同时发生才导致遗嘱继承全部遗产。

* **各法律关系所需事实数**

    | 法律关系 | 需要的法律事实 | 数量 |
    | --- | --- | --- |
    | 动产抵押关系 | 签订有效的抵押合同；未经登记只是不得对抗善意第三人，不影响抵押权产生 | 一个 |
    | 遗嘱继承关系 | 有效遗嘱（民事法律行为）＋被继承人死亡（自然事实中的事件） | 两个 |
    | 侵权赔偿关系 | 侵权行为一个事实即可（属行为中的事实行为） | 一个 |
    | 婚姻关系 | 双方办理结婚登记一个事实即可发生效力 | 一个 |

## 行为与自然事实的划分

* **两大类的划分标准**

    * 民法首先把民事法律事实分成**行为**与**自然事实**两类，二者都是法言法语，必须抓住。

    * 区分的标准是**看是否与主体意志有关**，即看这个客观现象是否受人的大脑所控制。

    * 与主体意志有关的，必须以受主体意志支配作为构成要件，叫行为；与主体意志无关的，不管受不受意志支配都可以构成并导致法律关系变动，叫自然事实。

* **行为（behavior）**

    * > **定义**：受主体意志的支配，能够引起法律关系发生变动的客观现象。

    * 受人的意志支配是行为的**构成要件**，缺这个要件就不能构成行为，也就不能产生相应的法律后果，通俗讲是「没你不行」。

    * 被打晕后由他人拉着按手印，不受本人意志支配，不能构成法律上的合同行为，不能产生合同权利义务关系。

    * 侵权行为同样以主体意志支配为前提，梦游状态下打伤室友不构成侵权行为，不承担侵权责任。

    * > **易错点**：梦游打人不构成侵权行为，但受伤害者并非白挨打——法律仍会给予公平考虑、给予适当补偿，只是**承担的不是侵权责任**。

* **自然事实**

    * 自然事实与人的意志无关，不以意志支配作为构成要件，体现的是「没你也行」。

    * 人的死亡导致继承法律关系启动，不需考虑是否受意志支配：受意志支配的死亡（如自杀）与不受意志支配的死亡（如因病昏迷后死亡）都能导致继承法律关系发生。

    * 出生也是自然事实：顺产显然费了人的力气，剖腹产则可能与意志无关，但不考虑这一因素，只要孩子出来即可形成父母子女关系。

* **一组事实的归位**

    | 民事法律事实 | 行为 / 自然事实 | 理由 |
    | --- | --- | --- |
    | 签订买卖合同 | 行为 | 必须以受意志支配为前提 |
    | 办理结婚登记 | 行为 | 也得以受意志支配为前提 |
    | 撞伤外卖员（侵权行为） | 行为 | 必须以意志支配作为构成要件 |
    | 创作作品 | 行为 | 需要受意志支配 |
    | 立遗嘱 | 行为 | 也得以意志支配为前提 |
    | 小王出生 | 自然事实 | 不需要考虑是否受人的意志支配 |
    | 王某死亡 | 自然事实 | 无论是否受意志支配，死亡事实发生即可导致相应法律后果 |

## 民事法律行为与事实行为

* **意思表示（declaration of intention）**

    * > **定义**：体现为当事人表达了一个希望发生某种法律后果的意愿，通俗讲就是行为里面要包含一个「我愿意」的因素。

    * 民事法律行为与事实行为的区分标准，是看这个行为里面**需不需要包含一个意思表示**。

    * 「意志支配」强调举动是否受大脑控制；「意思表示」强调受大脑控制的举动里有没有包含「我愿意」，两者不可混同。

* **民事法律行为（civil juristic act）**

    * > **定义**：民事主体通过意思表示来设立、变更、终止民事权利关系的行为。

    * 意思表示是构成要件，不满足就不能构成民事法律行为；意思表示存在瑕疵时，法律给予相应的救济，例如受胁迫签合同时赋予对方**撤销权**。

    * 典型例子：合同、婚姻、遗嘱、收养，都是民事法律行为。结婚须双方合意才形成夫妻关系，设立遗嘱须有当时的意思表示，收养须当事人达成合意。

    * 产生的法律后果体现**当事人的意愿**，即当事人意愿的实现。

* **事实行为（factual act）**

    * 事实行为不考虑当事人的意愿，不以「我愿意」作为发生相应法律后果的前提。

    * 典型例子：侵权行为、作品创作。甲撞了乙的车，不管甲乙愿不愿意都要承担侵权损害赔偿；创作完成即取得著作权，不考虑行为人有无取得著作权的意愿。

    * 产生的法律后果体现**法律的意志**。

    * > **易错点**：甲拿刀逼着乙签合同，乙虽然受胁迫，但在恐惧之下仍会权衡利弊并在合同上签字，这一举动依然**受乙的大脑支配**，仍构成行为；其中也依然包含「我愿意」的因素，可以构成民事法律行为，只是这个「我愿意」的做出存在瑕疵、被外界不当干扰，需通过**撤销权**救济。

* **两类行为的分野**

    | | 民事法律行为 | 事实行为 |
    | --- | --- | --- |
    | 意思表示 | 是构成要件 | 不是构成要件 |
    | 法律后果体现谁的意志 | 当事人的意愿 | 法律的意志 |
    | 例子 | 合同、结婚、遗嘱、收养 | 侵权、作品创作 |

## 准民事法律行为

* **准民事法律行为（quasi civil juristic act）**

    * 这是一个**理论概念**，民法典没有规定；民法典中能导致法律关系变动、又无法被民事法律行为和事实行为涵盖的行为，用这个「大口袋」统一装进去。

    * 「准」字的含义是：你还不是民事法律行为（否则不必加「准」），但很多规范可以适用民事法律行为的规定，可以把你当成这种情况来对待。

    * 共同特征有两面：一方面需要包含当事人的意愿、包含「我愿意」的意思，这一点像民事法律行为；另一方面产生的后果不按当事人的意愿发生，而是体现**法律的意志**，这一点又像事实行为，因此处于中间状态。

* **意思通知**

    * 意思通知只是把内心的某种意思通知给相对方，教材列举三项：邀约拒绝、履行催告、选择权行使的催告。

    * **邀约**是订立合同时的术语：甲对乙说「这台手机一千块卖给我」是邀约；乙说「没问题」是**承诺**，邀约与承诺达成一致时合同成立。

    * 老板粗暴拒绝「一百五卖不卖」的报价后又说愿意赔钱卖一百五，这个新的表示构成**新的邀约**，买不买仍由买方完全决定，可以接着砍价。

    * 拒绝的法律后果是：原一百五报价**失去效力**，交易重新启动谈判。该后果由法律直接规定，并非老板意愿的实现，故属意思通知。

* **观念通知**

    * 观念通知又称事实通知，是把某个已经发生的**既定事实**告知对方，教材举例：承诺迟到的通知、发生不可抗力的通知、瑕疵通知、债权让与的通知、债务的承认。

    * 债权让与的例子：车某向岳母借十万元到期不还，岳母把债权转让给马某并通知车某。车某收到通知后不能再向岳母还款，只能向马某偿还。

    * 该通知包含岳母的意思在里面（希望车某知道已转让、自己不再纠缠），但后果「债权让与对债务人生效」体现的是法律意志——既不体现岳母的意思，也不体现车某的意思，故属准民事法律行为。

* **感情表达**

    * 感情表达指表达某种情感上的意思，民法中的典型制度是**丧失继承权以后的宽恕表示**。

    * 依民法典第 1125 条，**故意杀害被继承人**属于继承权的**绝对丧失**，即使被继承人表示宽恕也不能恢复；**遗弃被继承人或者虐待被继承人情节严重**属于**相对丧失**，被继承人后来表示宽恕的可以恢复继承权。

    * 例子：老王的两个儿子，王一聪蓄意杀害老王（绝对丧失，不可能取得遗产），王一鸣长期虐待老王情节严重（相对丧失，可被宽恕）；老王立遗嘱让二人平分遗产即**宽恕的表示**。

    * 宽恕表示包含老王的意愿，但「能否被原谅」由法律决定：法律对故意杀害绝不原谅，对虐待情节严重则认许宽恕，故其法律后果体现法律意志。

* **不能单独发生效力**

    * 准民事法律行为常常**不能单独发生**法律后果变动的效力，它只是某个制度适用时其中的一个考量因素或辅助因素。

    * 民事法律行为（合同、结婚、遗嘱、收养）与事实行为（侵权、作品创作）都可以单独导致法律关系变动，准民事法律行为不行。

    * 三个实例都只是某个制度的环节：邀约拒绝是**合同订立过程**当中的一个环节；债权让与通知是**债权让与这个法律关系**当中的一个环节；被继承人的宽恕是**丧失继承权制度**里的一个环节。

## 事件与状态

* **自然事实的二级划分**

    * 自然事实进一步分为**事件**与**状态**两种类型。

    * **事件**体现为某种客观现象的**发生**，不管是否有人意志支配都可以产生相应法律后果，例如人的出生、人的死亡、发生自然灾害。

    * **状态**体现为某种客观现象的**持续**，更强调时间段概念：某种客观现象持续达到一定时间时可能产生新的法律后果。

* **状态的典型例证**

    * 下落不明的状态持续**两年**，可以被宣告失踪；持续**四年**，可以被宣告死亡。

    * 精神失常、对物的占有也属于状态类现象。

    * 对权利持续不行使构成诉讼时效：债权**三年内**持续不行使权利，债务人取得拒绝履行债务的抗辩权。

* **一组选项的归位**

    | 选项 | 归类 | 理由 |
    | --- | --- | --- |
    | 战争爆发 | 自然事实（事件） | 不需要考虑意志支配，可能对双方构成不可抗力 |
    | 时间的经过 | 自然事实（状态） | 自然人的意志影响不了时间的经过 |
    | 人的出生 | 自然事实（事件） | 顺产或剖腹产，只要出生事实发生即可产生父母子女关系 |
    | 侵权行为 | 行为中的事实行为 | 必须以人的意志支配作为前提 |

    * > **易错点**：最常见的坑是把「事实行为」与「自然事实」混为一谈。事实行为是「行为」下面的分支，仍然要求受意志支配；自然事实恰恰是「和意志无关」。两个词都带「事实」二字，却分属截然不同的两支。

## 民事法律事实的法律后果

* **三类后果**

    * 民事法律事实产生的后果就是导致民事法律关系的变动，包括产生、变更、消灭。

    * **产生**：甲乙签订手机买卖合同，在甲乙之间产生债权债务关系。

    * **变更**：甲借十万元约定一年还款，到期无力还款，双方协商「再延期一年」，即履行期限的变更。

    * **消灭**：某个事实发生导致双方的法律关系不再存在，理论上又分为绝对消灭与相对消灭。

* **消灭的两种形态**

    * **绝对消灭**：法律关系被消灭后，当时没有产生其他民事法律关系，双方自此没有关系。如甲对乙的十万元债权因乙还清而消灭。

    * **相对消灭**：原法律关系被消灭的同时产生其他民事法律关系，由新关系取代原关系。如甲的手机被乙摔毁，所有权关系归于消灭，同时在甲乙之间产生侵权损害赔偿关系，乙赔偿甲的损失。

## 类型体系全景

```text
民事法律事实
├── 行为 ── 以"受主体意志支配"为构成要件（没你不行）
│   ├── 民事法律行为 ── 以"意思表示"为构成要件
│   │                   → 法律后果体现当事人的意愿
│   ├── 事实行为 ── 不以意思表示为要件
│   │                   → 法律后果体现法律的意志
│   └── 准民事法律行为 ── 含意思表示，但后果体现法律意志
│                       （"大口袋"；且常常不能单独发生效力）
└── 自然事实 ── 与意志支配无关（没你也行）
    ├── 事件 ── 客观现象的"发生"：出生、死亡、自然灾害
    └── 状态 ── 客观现象的"持续"：失踪、死亡宣告、诉讼时效
```

## 判定要点的记忆路径

* 行为与自然事实的分水岭，是「意志支配」是否构成要件；行为内部三分的分水岭，是「有没有意思表示」。

* 准民事法律行为之所以是「准」，在于它跨在中间地带：有人的意愿，但后果由法律说了算。

* 复习方法上有两条：一是掌握判断标准；二是记住教材列举的典型例子——考题基本不会超出教材所列例子的范畴，记典型例子性价比最高。

* 三道典型题型的答案口径：需要两个法律事实才能产生的是**遗嘱继承关系**；属于事实行为的是**创作作品**（承认债务属准民事法律行为）；不属于自然事实的是**侵权行为**。

## 所在章节的位置

* 「民事法律事实」属于动态制度中的变动部分，讨论的是民事法律关系怎么被推着走，而不是关系本身长什么样。

* 第二章整体框架是一个中心、五个基本点。

```text
第二章  民事法律关系
│
└─ 一个中心：民事法律关系
   （含义、特征、具体成立规则）
   │
   ├─ 静态三要素
   │   ├─ 主体：谁享有权利、承担义务
   │   ├─ 客体：民事权利和民事义务所指向的对象
   │   └─ 内容：民事权利和民事义务的基础理论
   │
   └─ 动态两个制度
       ├─ 保护
       │   ├─ 公益救济：民事责任的基础理论
       │   └─ 私力救济：正当防卫、紧急避险、自助行为
       └─ 变动：民事法律事实的基础理论
```

* 静态角度用主体、客体、内容三要素讲清「关系长什么样」；动态角度先讲「关系受侵害了怎么保护」，再讲「关系本身怎么发生变动」。

* 前两章是理论，较为抽象；自第三章起进入具体规则，学习难度下降。
