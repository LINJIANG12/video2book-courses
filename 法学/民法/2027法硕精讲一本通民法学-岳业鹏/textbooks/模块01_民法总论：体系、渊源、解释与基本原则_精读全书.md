## 民法怎么学，以及民法是什么

### 备考的三个阶段

2027法硕民法的备考，从今天正式进入一本通的基础精讲阶段。先跟大家分享一句话：前方虽然拥堵，但你仍在最优路线上。法硕竞争越来越激烈，命题方式也越来越灵活，但它承载着我们每一个普通考研人的英雄梦想。只是"想要"和"得到"之间还隔着两个字——**做到**。"做到"这两个字，就是我们整个考试需要共同完成的使命。

在进入具体内容之前，先强调两个宏观问题：一个是法硕专业课的备考阶段，另一个是民法这个学科的框架体系。

#### 学得明白、背得下来、写得出来

无论大家学习基础如何、学习多么细致，都不可能指望一轮的学习解决所有备考问题。法硕专业课的备考要依次经历三个核心阶段：要依次完成"学得明白""背得下来""写得出来"的备考任务。

| 阶段 | 任务 | 定位 |
|---|---|---|
| 精讲 | 学得明白 | 背诵的基础 |
| 背诵 | 背得下来 | 写作的基础 |
| 写作 | 写得出来 | 最终得分的保障 |

三个阶段环环相扣、层层递进。我们的图书和课程也会分成这三个阶段来依次展开。希望大家跟上节奏和进度，不懈怠、不掉队，相信大家可以学好民法、考好民法，甚至爱上民法，让民法成为大家的优势学科。

#### 基础精讲为什么要听两遍三遍

我们现在要一起学习的阶段，是整个系列课程的第一个阶段——基础精讲阶段。这是打基础的阶段，所以涉及考点最全、讲授范围最广，当然耗时也最长。

在这个阶段，我会全面系统、地毯式地给大家讲解民法的考试大纲，以及配套考试分析当中的全部考点；同时结合现在的命题趋势，以及马工程教材，给大家补充一些超纲的考点。

> **提示**：因为是打基础的阶段，大家一定要给予足够的耐心和重视——**基础不牢，地动山摇**。

所以要做好听第二遍、甚至第三遍课程的准备。不少初学者在第一轮学习时遇到的困惑，常常会在第二轮学习的时候迎刃而解。

### 民法的体系骨架：一个中心、五个基本点

大家学民法的时候会发现，民法涉及的考点又多又杂，和隔壁兄弟学科刑法那非常清晰的体系形成了鲜明对比。其实民法也是有体系的，只是民法的体系太过庞大，初学者在第一轮学习时很难完全掌握或者把握。所以先给大家描绘一个民法这个学科的大致框架。

整个民法体系要围绕一个词来展开，这个词叫**民事法律关系**。我能把它称之为"一个中心"，这个词会贯穿我们学习民法的全过程。

#### 六种民事法律关系

从外延角度讲，民事法律关系主要包含两种核心的类型：一种叫财产关系，一种叫人身关系。

```text
                     民事法律关系（一个中心）
                              │
       ┌──────────────────────┼──────────────────────┐
    财产关系               人身关系              其他民事权利
   基于财产利益          基于人格/身份利益        兼具双重属性
       │                      │                      │
    ┌──┴──┐               ┌──┴──┐               ┌──┴──┐
   物权  债权          人格权  身份权          继承权 知识产权
   静态  动态          生命名誉 婚姻家庭领域     民法典外
   归属  流转          名誉隐私 配偶父母子女     特别法
      一动一静
```

财产关系是基于财产利益而产生的法律关系，主要包含两项核心制度：物权制度是从**静态**角度描述财产的归属关系，债权制度是从**动态**角度描述财产的流转关系。一动一静，这叫财产关系。

人格权关系规范的是基于生命健康、名誉、隐私等人格利益而产生的法律关系；而基于特定的身份利益产生的法律关系，我们称之为身份权法律关系，主要产生于婚姻家庭领域，比如基于配偶、父母或者子女的身份产生的权利。

当代民法中，基于特定的身份还会产生一种财产权，叫继承权。同时民法对于无形知识成果也给予保护，进而产生一种权利，叫知识产权。尽管民法典没有设置独立的知识产权编，但是在法硕考试中，知识产权也是一个独立的知识板块。由于继承权和知识产权可能会涉及人身、财产的双重属性，是具有综合性的，我们称之为其他民事权利。

这样就形成了六种具体的民事法律关系类型。而民法这个学科的任务，就是要解决这六种民事法律关系当中产生的相关纠纷。

#### 五个基本点与三十个知识板块

要从五个方面来展开，我把它称之为"五个基本点"：从静态角度涉及民事法律关系的三要素——主体制度、客体制度以及内容。

- **主体**，描述的是谁来享有民事权利、承担民事义务；
- **客体**，描述的是民事权利和民事义务所指向的对象；
- **内容**，要展开权利义务它包含的具体规则。

这是静态角度描述三要素。然后从动态角度涉及民事法律关系的变动和保护这两个方面：变动讲的是各种民事法律关系的产生、变更、转让以及消灭各个环节；而保护制度讲的是当民事权利受到侵害以后，应当如何给予救济的问题。

```text
                        民事法律关系
                              │
          ┌───────────────────┴───────────────────┐
          │                                       │
      静态：是什么                            动态：变与护
     ┌────┼────┐                          ┌──────┴──────┐
    主体   客体   内容                   变动          保护
   谁享有  指向   权利义务             产生·变更        权利受侵害
   权利   什么   的具体规则            转让·消灭        如何救济
```

一动一静，形成了五个规范的角度。所以我把民法的体系总结为"**一个中心、五个基本点**"：一个中心就是民事法律关系，五个基本点就是主体、客体、内容、变动，加上保护。

这五个词希望大家有点印象，因为在后期进行民法这个学科背诵的时候，这五个关键词常常成为民法主观题的表达逻辑。六种民事法律关系，每一种都从五个角度来进行规范，这样就形成了整个民法的**三十个知识板块**。

#### 提取公因式与民法典七编

我国在制定民法典的时候，并没有把这三十个知识板块依次展开——因为这样会使整个民法的篇幅更加臃肿庞杂，而且会出现大量的重复性规定。

所以我们用了一种立法技术，叫**提取公因式**。大家在小学学数学的时候应该会听过这个词，就是把六种具体法律关系当中、和五个基本点相关的规则当中的共性问题，给它提取出来，形成一个独立的板块，我们叫民法的总则部分。

所以你们看，我国民法典第一编就叫总则编，它是可适用于各种具体法律关系的共性、一般性规则。然后各种民事法律关系的具体、特殊的规则再展开，形成民法典的各分编。

- 第二编物权编；
- 第三编合同编，讲的是债权制度；
- 第四编人格权编，讲的是人格权制度；
- 第五编婚姻家庭编，讲的是身份权制度；
- 第六编继承编，讲的是继承权制度。

当然我国民法典又往前走了一步：把各种民事法律关系当中、和保护相关的共性规则也提取出来，形成了一个独立的侵权责任编，作为民法典的第七编。这就是我国民法典七编制展开的一个基本逻辑。

知识产权虽然没有作为独立一编规定在民法典当中，而是作为特别法而存在，但是在法硕考试中也属于大家需要掌握的知识板块。这样就形成了民法的**八大知识板块**：民法典的七编内容，再加上知识产权。

#### 教材顺序为什么不一样

了解了这样一个大致的体系以后，再看教材的目录就比较清楚了——它涵盖的正是民法学习时需要我们掌握的八大知识板块。只是婚姻家庭和继承这两个板块，都是家庭领域当中产生的法律问题，所以我在写教材的时候把这两个板块放到一起来写。教材里面体现的是七编，但它涵盖的是八大知识板块。

写教材的时候，我对八大知识板块的顺序做了一个微调，主要是把人格权跟知识产权放到了合同编之前。这样的调整事实上不会影响大家实质的学习，主要是考虑到大家学习信心的一个保障。

因为民法的八大知识板块中有三个部分难度是比较大的：总则、物权以及合同。这三个板块的知识体量会占到整个民法考点的 75% 以上，绝大部分的民法难点都集中在这三个板块。假设按照民法典的顺序来讲——先讲总则，再讲物权，再讲合同——不少同学可能合同编还没学完，整个信心都崩溃了。关键上了考场以后发现，考的主观题是后面小板块的内容：2020年简答题考的是人格权和继承权部分的考点，论述题里也出现过婚姻家庭和继承编。

所以为了使大家整个民法学习有充足的信心，我对学习的板块顺序做了一个调整，形成了民法学习的上下两个半场：

```text
          上半场                        下半场
  ┌──────────────────┐         ┌──────────────────┐
  │ 总则（为全典奠基） │         │ 合同             │
  │ 人格权            │         │ 婚姻家庭          │
  │ 物权              │         │ 继承             │
  │ 知识产权          │         │ 侵权责任          │
  └──────────────────┘         └──────────────────┘
   难点前置，信心在握             时间与难度分配均衡
```

这样学习的时间和难度分配会相对均衡一些。我相信这样一个节奏的调整，有利于大家能够坚持学完民法、学好民法。

### 总则编的地位与八章脉络

接下来我们进入第一编总则编。在前面提到，总则编是通过提取公因式的方式而形成的板块，既包括民法的基础理论，也包括各种民事法律关系的共性规则。因为总则编要为整部民法奠基，所以它的重要性是不言而喻的。

教材里我专门写了一个本编导言，大家可以自行阅读。这里我要重点强调两个问题：一个是总则编的逻辑导图，第二是总则编在法硕考试中的考察情况。

#### 理论在前，规则在后

在教材中，总则编包含八章内容，需要大家学习。我们把这八章分成两个层次：第一个层次是理论问题，涉及民法的基础理论；第二个层次是民事法律关系的一般性规则。

基础理论部分包含两章内容：第一章民法绪论，介绍民法这个部门法的基础理论；接着第二章介绍民事法律关系的基础理论，也就是要建构整个民法的理论逻辑——"一个中心、五个基本点"。这是理论层面。

第二个层次就是一般性的规定，也就是通过提取公因式的方式形成的各种民事法律关系的共性规则。我国民法典总则编主要是把**主体**和**变动**中的共性规则提取出来。主体部分要讲三类通用的民事主体：自然人、法人及非法人组织，对应我们教材的第三章、第四章和第五章的相关内容。变动中的共性规则涉及三项制度：民事法律行为、代理和诉讼时效，对应我们教材的第六章、第七章和第八章的相关考点。

```text
                    总则编（为整部民法奠基）
                                │
        ┌───────────────────────┴───────────────────────┐
     理论层（绪论、民事法律关系）              规则层（共性规则）
   ┌──────────┬──────────────┐            ┌──────────┬───────────┐
  民法绪论  民事法律关系      │            │  主体     │   变动    │
  部门法     民法理论逻辑      │            │ 自然人    │ 民事法律行为
  基础理论    一个中心五个基本点│            │ 法人      │ 代理
             │                │            │ 非法人组织│ 诉讼时效
             └────────────────┘            └──────────┴───────────┘
```

所以我们要先学理论、再学规则。先学的理论部分相对比较抽象，也不怎么接地气，同时还涉及大量的专业术语，会在这部分遇到一些困难——当然这也是我们学习民法的必经之路，我希望大家一定要坚持下去。当你学到进入具体规则部分的时候，可能会相对容易一些。

#### 二十年的主观题数据

在法硕考试中，总则编既是绝对的重点，也是绝对的难点。无论是客观题还是主观题，是每年一定会考的。

我在教材里重点总结了过去20年总则编考察主观题的情况：简答题考了14次，辨析题考了5次，法条分析题考了4次，论述题考了8次。当然现在已经没有辨析题了，但是大家可以感受到总则编它考察主观题的频率还是非常高的。所以大家学习的时候一定要重视理解，要为后续的背诵打下坚实的基础。

### 民法的自我介绍：一次高空抛物引出的三个关键词

绪论讲的是民法这个部门法的基础理论，这一章包含三节内容：第一节民法概述，第二节民法的调整对象，第三节民法的基本原则——都是理论问题，当然越是理论问题越容易在主观题里面考到。

接下来我们要花很多的时间学习民法、和民法打交道、和民法做朋友，所以先让民法给大家做一个自我介绍，这就是民法概述部分要完成的任务。当然这一节也是理论问题，相对来讲比较抽象，同时也不接地气，所以民法的自我介绍要从一起高空抛物的案例讲起。

#### 同一件事，刑法管一半，民法管另一半

高空抛物关涉人民头顶上的安全，是一个社会热点问题。教材里面写的这个案例是新闻里面报道过的：发生在吉林长春，一位28岁的女子小楼从外地来长春探望朋友，在正常经过某个小吃街的时候，被高空抛掷的砖头砸中，人当场就死亡了，可以说是飞来横祸。后来查明，是一位年轻人周某自己生活不顺，为了报复社会，就从高空上往下抛掷砖头。

大家看新闻里面看到这个报道的时候，都知道周某摊上事了，因为他违法了，法律要对这个事件进行调整。关键是哪些法律要对这个事件进行调整呢？

首先是**刑法**。他从高空往下抛掷砖头，是不是对公众的安全造成了严重的威胁？所以把他抓起来、给他定罪判刑。后来周某是以危险方法危害公共安全罪被判处死刑、立即执行。你看，这是刑法要调整的问题。

当然他被判处死刑以后，这个事情是不是就完了呀？当然不是。因为受害人小楼的家属是需要救济的，所以在小楼的家属和周某之间会产生一个侵权损害赔偿的问题。

这个问题是**民法**要调整的对象。因为双方是平等主体——你是普通老百姓，你不容易，其实大家都不容易；在平等主体之间产生的这种社会关系，就由民法这个部门法来调整。

> **结论**：任何一个部门法都不可能单独地完成社会调整的任务，每个部门法都选择其中的一个部分来进行调整。而民法关注的，是**平等主体之间的社会关系**。

#### 民法概念的三个关键词

民法在做定义描述的时候，是通过描述它的调整对象来形成的。

> **定义**：民法是调整平等主体之间的人身关系和财产关系的法律规范的总和。

理解的时候我们要关注三个关键词。

**第一，平等。** 民法调整的是平等主体之间的社会关系。事实上，主体的平等性也是民法和其他兄弟部门法的一个本质的区别。比如刚才讲到的刑法，要对犯罪嫌疑人进行定罪量刑而形成的社会关系，完全是碾压的这样一个状态，双方并不是平等的主体；但民法所调整的社会关系，双方主体地位是平等的。就像刚才高空抛物的案例中，小楼的家属跟周某，他们都是普通老百姓，是平等的主体，双方的地位是势均力敌的。

所以我们学习民法的时候会有种感觉，就像是一位慈祥的老母亲在调解子女之间的相关纠纷——手心手背都是肉，要一碗水端平。所以民法是平衡的艺术。当然因为民法涉及平等的主体，同学们在学习的时候可能会自动代入其中一方当事人的立场来思考这个问题，选择学习民法特别容易产生争执或者争论；当然当你觉得双方都跟你无关的时候，学民法又容易犯困。这是民法它调整平等主体之间社会关系这一点所决定的。

**第二，社会关系既包括人身关系，也包括财产关系。** 财产关系它是基于财产利益而产生的，通俗地讲就是可以用钱来摆平的。我们生活当中平等主体之间产生的多数纠纷都可以用财产来解决，比如房屋的买卖、汽车的租赁、房屋的抵押等等，都是跟财产相关的。

同时，一些光靠钱解决不了的人身关系，也属于民法的调整范围。比如很多年前发生了艳照门这个事件，有些女明星的私房照被披露到网上——对这些明星来讲，其实她们是不缺钱的，所以光靠钱是解决不了这个问题的；她们的隐私受到了侵犯，而这个隐私关乎的是人的尊严，是人身关系要关注的问题。再比如前段时间我看的一部电影，易烊千玺饰演的刘春河是一位脑瘫患者，他能去一家咖啡店应聘，后来被录取了。剧里有一句台词我觉得特别让人感动，他说自己找这个工作不是为了钱，而是为了尊严。你看"尊严"这两个字就不是光靠钱能够解决的，它正是人身关系要关注的对象。

所以民法调整的社会关系，既包括靠钱可以解决的财产关系，也包括光靠钱解决不了的人身关系。

**第三，民法是调整上述社会关系的法律规范的总和。** 注意这个"总和"，它涉及到一系列规范。而这个规范既包括行为规范，也包括裁判规范。所谓行为规范是写给老百姓看的，要告诉老百姓在参与民事活动的时候应当如何来实施行为；而裁判规范是写给法官看的，在发生民事纠纷让法官去解决的时候，法官如何来解决，要靠裁判规范。

| | 行为规范 | 裁判规范 |
|---|---|---|
| 写给谁 | 老百姓 | 法官 |
| 作用 | 指导民事活动的实施 | 提供裁判依据 |
| 典型条文 | 民法典第1043条 | 民法典第153条第2款 |

民法典第1043条是一个典型的行为规范：它写着"夫妻应当互相忠实、互相尊重、互相关爱"，接着是"家庭成员应当敬老爱幼、互相帮助，维护家庭关系"。告诉夫妻怎么来维护婚姻关系，告诉家庭成员如何来维护家庭关系——这样的规范是写给老百姓看的，是老百姓的行为指南，所以叫行为规范。

而民法典第153条第2款"违背公序良俗的民事法律行为无效"，就是典型的裁判规范。举个例子：甲乙是夫妻，在夫妻关系存续期间，怎么来维护这个夫妻关系呢？法律说了，你们双方要互相忠实、互相尊重、互相关爱，才能够维护一个和谐稳定的婚姻关系。你看，这是讲行为规范的作用。

但假如说一方不老实，比如甲出轨了、后面有了人，然后他把夫妻共同财产就赠与给了后面的情人丙。后来原配乙知道以后当然不答应了，于是就把这个情人给告了，要求丙返还其所受赠的财产，这就产生了一个民事纠纷。那法院在审理这个案件的时候，就要确认甲把这个财产赠给丙的合同到底效力如何。在判断这个问题的时候，就要用到民法典第153条第2款了——因为这样的赠与破坏了家庭关系，是违背公序良俗的，所以依法应当被认定为无效的合同。认定无效的依据就是第153条第2款，这叫裁判规范。

被认定无效以后，丙取得的财产就丧失法律根据了，所以乙当然可以请求返还这个财产，这样就解决了这样一个民事纠纷。

> **易错点**：从考试角度来讲，民法典当中的裁判规范是大家学习的重点和难点，特别是民法的案例分析题主要考的是裁判规范的适用。但这并不意味着行为规范不重要，只是它相对来讲比较简单而已——比如2025年法硕同学考的论述题，就涉及了第1043条这个行为规范。

### 民法典从哪里来

两种民法分类讲完，大家会发现它们都指向一部规范的文件——民法典。那我国现在有没有民法典？答案是有的。

#### 一部很年轻的法典

我国的民法典在2021年1月1日正式实施，也就是说民法典生效也就才5年的时间，是一部非常年轻的法典。这部法典包含七篇内容、总共1260个条文，非常庞杂。

尽管在法硕考试中民法、刑法都考75分，但是民法的规范的数量大致是刑法的两到三倍——这是大家学民法的时候感觉内容特别多的一个原因，因为它的法律条文确实很庞杂。当然这1000多个条文也是我们学习民法的最核心的任务：把这1000多个条文学完了，我们的民法也就学完了。

#### 第一部以"法典"命名的规范性文件

民法典同时也是我国第一部以"法典"来命名的规范性文件。什么叫以"法典"命名？大家学习法律之前可能也关注过我国的一些法律文件，但是民法典是以"典"字结尾、以"法典"命名的规范性文件。

刑法老师并不完全认同这个说法。我记得2020年颁布民法典的时候，民法学界都在强调民法典是我国第一部以法典命名的规范性文件，刑法老师专门跟我说过："你们民法学界也太自负了，明明刑法典颁布时间更早，怎么你们就是第一部啊？"我安慰她说："我知道你很急，但是你先别着急。"

所以刑法的法典和地位其实也很高，但是刑法的法典地位是刑法学界自封的，而民法的法典地位是官方认可的，这就是区别。当然这不影响刑法学者在做理论研究的时候，也把刑法称之为"刑法典"。

#### 出台意义与我国民法典的特色

教材里关于民法典有两段话需要大家稍微学习学习。这两段话虽然通俗易懂，但都高屋建瓴、意义深远。

第一段讲的是颁布民法典的重要意义，涉及四个方面：法治层面的"推进全面依法治国"，经济层面的相关意义，民生层面的"依法维护人民的权益"，以及治理层面的"推进国家治理体系和治理能力的现代化"。

第二段讲的是我国民法典的特色：要与资本主义国家的民法典形成鲜明的对比；要符合人民的利益和愿望，体现的是民法典的**实践特色**——民法典不能光画饼，要把人民的利益和愿望落到实处，强调它的实践属性；还要顺应时代的发展要求，体现出民法典的**时代特色**——我国民法典颁布于21世纪、颁布于网络数据时代，所以在民法典中有大量和网络数据相关的法律规则。

### 民法的性质：私权神圣，民商合体

接下来是民法的性质和价值，也就是让民法来介绍下自己的性格和三观如何。

#### 五个词和一副口诀

民法的性质讲的是和兄弟部门法相比，民法有哪些特殊的品质。在2014年曾经考到过论述题，官方教材里用了五个词来描述民法的性质。既然是主观题的考点，大家先把这五个词记住。

我编了一个小口诀，叫"**私权神圣，民商合体**"：

- "私"的**私**讲的是民法是私法；
- **权**讲的是民法是权利法；
- "民商合体"的**民**讲的是民法是市民社会的百科全书；
- **商**体现的是民法是商事领域的基本法；
- **体**讲的是民法是实体法。

| 性质 | 对照的兄弟部门法 | 一句话区分 |
|---|---|---|
| 私法 | 公法（刑法、行政法） | 规范私人私事，允许私了 |
| 权利法 | 刑法 | 确认保障权利 vs 限制剥夺自由 |
| 市民社会的百科全书 | — | 从摇篮到坟墓的保护 |
| 商事领域的基本法 | 商法（特别法） | 民法是一般法 |
| 实体法 | 诉讼法（程序法） | 权利义务存否 vs 如何实现 |

#### 私法：公事公办，允许私了

"私法"是和"公法"相对应的概念，所以大家和公法对比起来理解民法的性质。大家学的刑法、行政法都属于公法的范畴，强调要公事公办；而私法规范的是私人私事，所以是允许私了的，要尊重当事人的自主决定权。

> **结论**：民法属于私法，它主要体现为**任意性规范**。

注意这个词。任意性规范体现为可以通过当事人的约定来排除的规范，大家学法理学的时候也会学到。所以大家在阅读民法的法条时经常会看到：写完规则以后，后面跟上一句话"但是当事人另有约定的除外"。允许当事人通过特别的约定来排除法律规范的适用，最大限度地尊重当事人意思自治——这是民法是私法这个属性所决定的。

#### 权利法：确认和保护民事权利

这一点体现的是民法和刑法的区别。大家学习刑法知道，刑法是要限制或剥夺人的自由的，甚至要剥夺人的生命的；而民法是权利法，是要确认和保障民事权利、保障人的自由的，形成了鲜明的对比。

从历史上、从起源上来看，老百姓很难有广泛的自由权利，那就很难产生真正的民法。大家学习法制史，在封建时代法制的特点叫做"重刑轻民"；1949年建国以后到改革开放之前，老百姓的市场自由也是受到极大的限制的——不能有自己的私产，不能自由进行交易，男女不能自由恋爱，所以也很难产生真正的民法。

我记得有部老电影非常好看，叫《芙蓉镇》，是刘晓庆主演的。刘晓庆饰演的胡玉音，能通过卖米豆腐发家致富、盖了新房子，却被强制扫了十几年的大街，受尽了屈辱；在她即将陷入绝境的时候，想要和相依为命的秦书田结婚，都遇到了非常大的阻碍。你看在这个时代，是很难有真正的民法可言的。放到今天这个时代，或者说改革开放以后的年代，胡玉音妥妥是个勤劳致富的典范，但是因为她生在了那个时代，导致她的一生都被毁掉了——应了那句话，时代的一粒灰落到一个人的头上，那就是一座山。

所以我们能生活在一个保障人民的自由、保障财产权、保障婚姻自由的年代，其实是非常幸福的。这就是民法在排除公权的干预，这是历史视角。

而从现实的视角看，我国现代民法的体系，就是以民事权利为基本的逻辑基点来展开的。民法典的分则编就是以权利的类型作为线索来展开的，包括物权、债权、人格权、身份权、继承权等等；同时这些权利的共性规则提取出来，形成民法的总则编；最后还有侵权责任编来体现对于权利的保护。

> **结论**：民法最基本的职能在于对民事权利的确认和保护。我国民法典从第二编到第六编，都是在确认民事主体有哪些权利，而第七编讲的是民事权利的保护问题。

#### 百科全书、基本法与实体法

"民法是市民社会的百科全书"这句话听起来有点抽象，其实举个例子是很容易理解的。每个同学在这个社会当中都有两重身份：在国家政治领域，我们都是中国的公民，享有选举权和被选举权——这是我们在公法上的身份；而在市民社会当中，我们每个人都是一位普通的老百姓，都希望自己身体健康、心想事成、合家欢乐——这就是在市民社会中的一个基本地位。

这句话是在颁布民法典的时候，官方的文件里面明确讲的。因为民法涉及老百姓的生老病死、衣食住行等等方方面面，对老百姓的保护是一种从摇篮到坟墓的保护。甚至你学了民法会知道，出生的胎儿状态以及死后的人格利益，民法也会给予保护。实际上我们这个社会的运行规则，基本上都写在民法当中。

当然不少年轻的同学还没有走向社会，还没有领略过社会的险恶、没有感受过人性的复杂，对这个社会了解不多，所以有些规则再学习起来可能会有点难度。但你反过来讲，既然社会运行的规则都写到了民法当中，那其实我们学习民法也是快速地去学习这个社会规则的一个过程。等你把民法学完以后，你会更了解这个社会，也会更了解人性——这就是学习民法的一个重要的意义，不只是为了考试。

"商法"这一点体现的是民法和商法的区别。大家知道市场经济关系其实就是商品交易，体现为商法规范的范畴。但商法是民法的特别法，而民法是商事领域的一个基本法或者一般法。

从历史发展角度来看，民法始终和商品经济、市场经济的发展相联系，也就是民法随着商品经济、市场经济的发展而不断完善的，这叫经济基础。比如我国建国以后并没有赋予老百姓很多的自由和权利，所以那个时候其实没有真正意义上的民法；我们确立了要发展商品经济这样一个道路以后，民法才逐渐成长壮大起来。特别是1986年我们颁布了民法通则，1999年因为要加入世贸组织而颁布了统一的合同法；那为什么后来颁布民法典呢？因为我们的市场经济发展到了一个新的阶段、进入了新时代，需要新的更加完善的民法制度来适应经济发展的需求。

从现实的视角看，现代民法制度调整的财产关系，既包括财产的归属关系，也包括财产的流通关系——物权制度是从静态角度描述财产的归属，先要确定财产的归属才能够保障财产的流通；债权制度规范的是财产的流转关系，一静一动来规范这个市场经济。

"实体法"体现的是民法和诉讼法的区别：诉讼法是程序法，而民法是实体法。实体法解决的是实体上你有没有这个权利、有没有这个义务；而程序法解决的是权利义务如何实现的问题。通俗地讲，实体法解决的是"这个钱你该不该拿"，而程序法解决的是"这个钱如何能够拿到手"。

举个例子：有人借了我10万块钱，那我对它就有一个借款债权。基于生活经验大家也能理解，实体法解决的问题是：既然我有这个债权，那我就有权请求他来还钱，这个钱是我该拿的。但是当我找他要这个钱时，他理直气壮地给我拒绝了，说："我凭实力借来的钱，凭什么还你啊？"虽然他很有实力，但是这样的回复竟让我无言以对。

这个时候我只能采取法律行动了，我可以去法院起诉他，来要求他还我这个钱。尽管实体法确认这个钱该我拿，但是我找他要钱他不给，我这钱怎么能拿到手？这就是民事诉讼法解决的问题，是程序法的范畴了。

我们学习民法，主要学的是实体上你有没有这个权利、你应不应当承担这个义务；至于这些权利和义务怎么在现实当中实现，那更多是程序法来解决的问题。民法它管不了那么多，大家把这个实体法和程序法做一个区分。

### 核心价值观：民法典的精神灵魂

有同学可能会有疑问：既然是政治课的内容，那讲民法为什么也要讲？因为政法不分家。不少同学可能考过"五院四系"，五院是五大政法院校——中国政法、华东政法、西南政法、中南财经政法以及西北政法，你看它们都叫"政法大学"，所以这个政和法是不分家的。而且 politics 放到法律之前，我们不叫"法政大学"，就叫"政法大学"。所以在中国这样一个社会背景下，你要不懂政治是很难学好法律的，或者说在法律的道路上很难走得远。大家要重视政治，学好政治才能够学好法律。

政治课里面讲过，社会主义核心价值观包含三个层次、12个词、24个字：国家、社会、个人三个层面。

```text
        国家层面              社会层面              个人层面
  富强 民主 文明 和谐   自由 平等 公正 法治   爱国 敬业 诚信 友善
                        ↓ 价值同源 ↓
     民法基本原则：平等、自愿、公平、诚信 ……
```

而在民法里面，教材用了这么一句话来描述它，注意"精神灵魂"这四个字——这个定位还是很高的。前面讲民法的五个性质时，那五个词是全世界各个民法都具备的特点；那我国的民法和其他资本主义国家民法相比，有什么特殊之处呢？核心价值观就是最重要的一个点，所以它是我国民法的显著特征，也是民法当中的一个考点，而且是主观题的考点。

#### 从立法宗旨到司法实践的四个层面

主要体现为四个方面，教材里是按照一条从宏观到微观的线索展开的。

**立法宗旨上宣誓。** 立法宗旨体现的是立法目的。我国在制定法律的时候有个惯例，基本上第一条讲的都是这部法律的立法目的。民法典也是一样，民法典第一条规定的立法目的就是"为了保护民事主体的合法权益，调整民事关系，维护社会经济秩序"。这跟资本主义国家的民法形成一个鲜明的对比。

**基本原则上恪守。** 确定立法目的以后，每部法律都会有自己的基本原则，也就是最核心的价值追求。比如民法典确立的基本原则有平等、自愿、公平、诚信等——大家发现这些词跟社会主义核心价值观是不是高度相似？教材里用了一个词叫做"**价值同源**"，就是民法跟你的价值观、三观是一致的，它这个价值是同源的，都包含自由、公平、诚信等。

**具体制度上体现。** 确立基本原则以后，就要设置具体的制度来落实这些原则。教材举的例子是民法典第185条规定的英雄烈士保护条款，体现的是爱国这个核心价值观。按照民法典的规定，如果有人侵害了英雄烈士的人格利益，他不仅伤害了英雄烈士的近亲属，同时也伤害了社会公共利益，所以检察机关是可以提起公益诉讼来维护这个公共利益的。包括去年9月3号的阅兵，以及抗日战争胜利80周年的阅兵，都是在强调爱国这个核心价值观；包括我国各个地方对于爱国主义教育基地的建设，也是在弘扬爱国的核心价值观。

可能这一点其他的国家不太能够完全理解。因为从1840年鸦片战争到1949年新中国成立，这一百年可以说是中华民族最屈辱的一百年，甚至面临着灭族的风险。我觉得我们现在的幸福生活是革命先烈用鲜血换来的，我们不能好了伤疤忘了疼，所以要强调英雄烈士人格利益的保护。

**司法实践中运用。** 民法典里面设置了各种各样的制度，那在具体个案当中去运用它的时候，也得把核心价值观考虑进来。人民法院在审理具体案件的时候，符合核心价值观的就要支持，不符合核心价值观的就要否定。

```text
  立法宗旨上宣誓  →  基本原则上恪守  →  具体制度上体现  →  司法实践中运用
      （宏观）                                            （微观）
```

从最宏观的立法宗旨到最具体的个案当中去运用，都要把核心价值观纳入进来。所以它体现的是民法典的精神灵魂，这个定位是非常高的。

> **提示**：可能有同学听起来觉得有点抽象、不太接地气，但是越是这样的问题，在考试中越容易考到大题，大家一定要注意理解。

## 民法的渊源：法官去哪里找裁判依据
> 对应块：BLK02 | 覆盖分集：P03 | 块标题（分集名）：《第01编 第01章 第01节：民法概述（02）》

接着往下走，第三个问题：民法的渊源。

这个概念我们在法理学里已经见过——"法律的渊源"，指的是法律的外在表现形式。把它平移到民法上，意思就很具体了：法官要用民法规范来解决纠纷，那这个民法规范去哪里寻找啊？他的表现形式包括哪些呀？这就是民法的渊源要解决的问题。

换句话说，"渊源"不是问你法理上有哪几种法源，而是问一个非常实务的问题：**法官手里到底握着哪些东西，可以拿来当裁判依据。**

我国《民法典》第十条对这个问题给出了回答。我们先把条文摆出来：

> 处理民事纠纷，应当依照法律，法律没有规定的，可以适用习惯，但不得违背公序良俗。

### 一条法条，拆出两个来源

你看这一句话，就那么两行，拆开看里面藏了两条路径：**处理民事纠纷，应当依照法律，法律没有规定的，可以适用习惯。**一个"法律"，一个"习惯"，就是法官可以伸手去拿的两样东西。

官方教材里的术语跟法条的说法不完全一样，这个对应关系一定要记牢：

- 法条里说的"**法律**"，教材里称为**制定法渊源**；
- 法条里说的"**习惯**"，教材里称为**非制定法渊源**。

一个来自官方，一个来自民间。

这里顺带说一句方法上的事。我们非法学的同学要考一种题型叫**法条分析题**，考的就是这种能力：给你一段法条，你能不能把它拆成一个个可以填空、可以判断对错的知识点。刚才这个第十条，你拆出了两样东西、两层结构，这就是一次完整的拆解。会拆，法条分析题就基本会做一半了。

把整个结构画出来，其实是这样的：

```text
民法的渊源
├─ 制定法渊源（法律）：来自官方
│    宪法 · 民事法律 · 行政法规 · 地方性法规
│    规章 · 司法解释 · 国际条约（国际层面）
└─ 非制定法渊源（习惯）：来自民间
     "习" 民间习俗 → 主要适用于民事领域
     "惯" 惯常做法 → 更多适用于商事交往
```

下面就顺着这张图，一层一层往下走。

### 制定法渊源：来自官方的七种类型

制定法渊源是什么？看《民法典》第十条里"法律"这两个字怎么解释：它指的是经过**具有立法权或者准立法权的国家机关**，**以条款形式加以编撰**，而制定成文件的法律或者法规。

这一句话里有两个关键词，每一个都限定了一种排除标准，考试里判断某个东西是不是制定法渊源，就拿这两条去卡。

#### 两个关键词：国家机关、以条款形式编撰

**第一个关键词：国家机关制定的。**注意这个词——**国家机关**。它体现的是"官方"这个渊源。

那"国家机关"包括哪些？既包括具有立法权的国家机关，也包括具有准立法权的国家机关。

立法权相对好理解——立法机关才有立法权。**准立法权**这个词要琢磨一下：它指的是一个国家机关虽然不是立法机关，但也有制定规范的权限。

比如国务院。他是行政机关，不是立法机关，但他有制定规范的权限，我们就说国务院具有**准立法权**。这个词你记住，考试判断题里就靠它。

**第二个关键词：以条款形式加以编撰。**注意这个"条款形式"。你去看《民法典》的条文，是通过第一条、第二条、第三条、第四条这样的方式呈现出来的，这就叫以条款形式呈现。

那一部规范文件的内部结构分成几个层次？在编撰一部规范文件的时候，它要分成六个层次，记住这六个字：**编、章、节、条、款、项**。

```text
一部规范文件
 └── 编 ── 民法典共七编
      └── 章 ── 总则编共八章
           └── 节
                └── 条 ── 第一条、第二条、第三条……
                     └── 款
                          └── 项
```

比如《民法典》分成七编，这是"编"的结构；往下，总则编里面又包括八章内容，这是"章"；每一章里可能会设节；每一节下面会有若干条；每一条下面会设数款；每一款里面可能会设数项。编、章节条款项，就这么一层套一层。

大家掌握这个结构，后面是有用的。我们讲民法解释方法的时候会讲到**体系解释**——按体系解释，就是看这个条文处于哪一节、哪一章、哪一编，来决定它的准确含义。到那时候你再来回看这张图，就知道它为什么重要了。

**只有"国家机关以条款形式编撰"同时满足，才是制定法渊源。**这两个关键词之外的东西，都进不了这一扇门。

#### 宪法与民事法律

满足条件的国家机关不止一个，制定法渊源因此被拆成了七种类型。前六项来自国内，第七项来自国际层面。

排在第一位的**宪法**，它具有最高的法律效力。它的精神，当然对于民法的适用会有指导作用——这是排在最前面的原因。

第二项**民事法律**，体现为立法机关制定的规范性文件。它是**处理民事纠纷依据最主的来源**。我们正在学的《民法典》，就是处理民事纠纷依据最主要的来源。

但这里所说的"民事法律"，除了《民法典》以外，还包括一些民事特别法：比如公司法，比如知识产权领域的著作权法、专利法、商标法等等。

所以这个地方所称的"民事法律"，它是一个**广义上的民法**的概念——我们在前面讲过广义和狭义民法的区分，这里正好用上。

#### 行政法规与地方性法规

第三项**行政法规**，是国务院制定的规范性文件。行政法规怎么也会跑进民法的渊源里来？关键在这个转折：**如果涉及民事主体之间权利的调整了，它也会成为处理民事纠纷的依据。**

举一个特别典型的例子。办理结婚登记，是取得夫妻关系的一个**形式要件**。所以结婚登记这个制度，对于民事主体之间、特别是夫妻之间权利的调整，一定会发挥相应的作用，会成为处理民事纠纷的依据。

这里还有一个现实的例子，就在去年。国务院专门修订了《婚姻登记条例》，明确规定男女双方办理结婚登记**不再需要户口本**了。

为什么专门改这一条？你想：在此之前我们当然也一直在保障民事主体的婚姻自由——父母不得干涉子女的婚姻自由。但在登记程序上，你要办结婚登记，得有户口本，而这个户口本常常在户主手里、在家长手里。你想，这就无形之中给了家长一个事实上去影响子女婚姻自由实现的机会。

所以《婚姻登记条例》这一修，也是进一步去保障民事主体的婚姻自由。你看，绕了一大圈，还是跟民法相关。**一部行政法规之所以成为民法的渊源，是因为它触碰了平等主体之间的权利关系。**

第四项**地方性法规**，也就是地方人大制定的规范性文件。教材里通常表述为"地方人大"，记住这个制定主体就行。

它成为民法渊源，靠的也是同一招。你看《北京市突发公共卫生事件应急条例》——什么叫突发公共卫生事件？像前几年发生的新冠疫情就是。基于这样一个地方性法规，当地政府是可以采取相应的管控措施的；而这些管控措施，是有可能影响平等主体之间民事交往的。

给你一个完整的场景。疫情期间，当地政府采取防控措施，不允许经营机构从事公开的经营活动，比如饭店不允许堂食。大家想想，这样一来，对于饭店经营者和他的房东签订的租赁合同的履行会产生什么影响？

政府不让我开业，我拿什么给你付租金呢？如果能严格按照原来的租金去支付，可能会导致**显失公平**。所以这个时候他可以主张变更这个租金。

你看，在处理这个纠纷的时候，就有可能用到当地出台的应急条例，进而成为处理这个民事纠纷的相关依据。**地方性法规离老百姓的生活往往比民法典还近，原因是它直接插进了本地交易的具体条件里。**

#### 规章与司法解释

第五项**规章**，是行政机关或者部门制定的，包括**部门规章**和**地方政府规章**两种。部门规章是中央部委制定的，地方政府规章是当地政府制定的。

举一个大家可能听过的例子：典当行。典当行业其实也属于金融行业，为了管理这个行业，也会有相应的规范性文件，它同样可能成为处理民事纠纷的依据。

这里给大家补充一个小花絮。典当管理办法是 2004 年颁布的，时任公安部部长是周某某，由他们两个人联合颁布。后来这两个人都因为违法犯罪锒铛入狱了。

那问题来了：这部典当管理办法现在还有效力吗？

**依然有。**为什么？因为他们实施的是**职务行为**。

这个道理你换个场景就秒懂了。就像你通过努力考过了法考，拿到了法律职业资格证书——但是如果当初在上面给你签名的那个人被抓起来了，会不会影响你手里这张证书的效力？当然不会。签字人后来怎么样，和他当时以什么身份作出的行为，是两回事。

第六项是**司法解释**。这个内容大家学刑法的时候也接触过——学刑法时你会发现，有的机关也可以制定司法解释。而在民事领域，最高人民法院的相关司法解释同样可以成为民法的渊源，而且它是我们学习民法非常重要的内容。

为什么重要？民法典颁布以后，民法典的各编都陆续出台了相应的司法解释：总则编、物权编、合同编、婚姻家庭编、继承编、侵权责任编等等。这些司法解释的规定，也是我们法硕考试要掌握的内容。

考试里凡是遇到"某某情形如何处理"，先回去看有没有对应的司法解释，这是最省时间的检索习惯。

#### 国际条约

第七项是**国际条约**，这是国际层面的民法的渊源。

为什么民法要管到国际上去？因为民法里面所讲的**平等主体**，既包括国内主体，也包括外国的主体。

比如一个中国人跟外国的一家公司来从事贸易活动，这个时候就有可能用到一些国际公约来解决这个纠纷，所以国际条约也可能成为处理民事纠纷的依据。

举两个例子。

一个是《联合国国际货物销售合同公约》，1980 年通过，国际上通行的简称是 **CISG**。学法学的同学，包括学国际贸易的同学，对这个公约可能比较了解。

顺便说一个学讲座的窍门。有些教师在做讲座的时候会提到"CISG 第几条规定了什么"，不明真相的同学听了以后觉得，这个教授好牛啊，张口就是英文的简称。实际上这是一种凡尔赛式的表达方式，你花点心思也很容易记住 CISG 这五个字母。

> **易错点**：CISG 常常被人顺口叫成"巴黎公约"，那其实是另一份国际公约的名字（工业产权领域的《保护工业产权的巴黎公约》）。这里只需要认准 CISG 就是《联合国国际货物销售合同公约》，别在讲座里听个响动就记岔了。

另一个是 **PICC**——国际商事合同通则。顺带说一声，这个缩写不是保险公司那个 PICC，这里指国际商事合同通则。

它也是我们学民法的时候经常会听到的一个国际文件。因为我国 1999 年颁布的《合同法》，包括我们现在民法典的合同编，大量的规则都来自于 CISG，同时也借鉴了国际商事合同通则（PICC）当中的一些条文。

所以你看，国际条约在民法里不是个摆设，它是我国合同法规则的一条重要"上游水源"。

到这里，制定法渊源的七项就凑齐了：前六项来自国内，第七项来自国际层面。

### 习惯：来自民间的另一半

现在进入第二个层次，**习惯**，也就是非制定法渊源，来自民间。

讲到这儿要先感慨一句：**这一点体现的是民法的特色。**

大家学习刑法也要讲刑法的渊源。处理刑事案件，能不能以习惯作为依据？当然不能。但处理民事案件就可以。

为什么会有这么大的差别？因为刑法的底线是罪刑法定，习惯不能拿去造罪；但民法的很多领域本来就长在交易习惯里，交易习惯本身就是当事人之间的默示约定，它离生活更近，离制定法更远。

要搞懂习惯，得解决两个问题。

#### 习惯这两个字怎么认定

第一个问题是，"习惯"这两个字到底怎么认定。

首先，这个"习惯"是个**法言法语**，跟我们生活当中所说的习惯还不太一样。比如有的同学有早起的习惯，有跑步的习惯，有追剧的习惯等等，这些都是生活习惯。而我们这个地方讲的"习惯"，是**可以作为处理民事纠纷依据的习惯**，两者不太一样。

司法解释里面专门对这个习惯的认定做出了明确的规定。这个定义在非法学同学的法条分析题里面曾经考到过，所以需要大家扎实地掌握。

怎么记？拆字最好使：

| 字 | 对应 | 适用场景 |
| :--- | :--- | :--- |
| 习 | 民间习俗 | 主要适用于民事领域 |
| 惯 | 惯常做法 | 更多适用于商事交往 |

**"习"叫民间习俗，"惯"叫惯常做法。**民间习俗主要适用于民事领域，惯常做法更多适用于商事交往。

那么，满足什么要求的民间习俗和惯常做法，才能称得上民法意义上的习惯？司法解释规定了两个方面。

**第一，客观上要在一定地域、行业范围内长期实施。**

你客观上得存在这个做法。既包括一定地域内的做法，也包括行业范围内的做法。

为什么是地域和行业两个维度？因为大家听过一个词叫**"入乡随俗"**——不同的地区会有不同的风俗；同时也听过**"隔行如隔山"**——不同的行业会有不同的行规。所以既包括一定地域的习惯，也包括一定行业的习惯。

来看地域的例子。全国各地都存在房屋租赁这样一种民事交往，那在房屋租赁里面会涉及一个问题：这个房子的物业费，包括冬天的取暖费，由哪一方当事人来承担？

当然，首先可以当时来约定。当时如果没有约定的话，也可以按照当地的习惯来确定。据我了解，在北京，如果当时没有做特别约定的话，物业费也好、取暖费也好，都是由房东来承担的。而在我的老家山西，如果当时都没有做特别约定的话，那取暖费甚至包括物业费，是由承租人来承担的。

你看，不同的地方会有不同的惯常做法。不知道大家所在的地区，在租房子的时候，物业费和取暖费由谁来承担？**这叫入乡随俗。**

再看行业的例子。大家可能都住过酒店，不管一个人也好、两个人也好，可能都住过酒店。酒店业有一个惯常做法：你前天晚上入住，不管你是几点入住的，那你要在第二天的 12 点或者 2 点来退房。你能不能说"我交了一天的房费，我要住满 24 个小时啊"？这个是不行的。**这就是酒店业的惯常做法。**

**第二，主观上要为一般人从事民事活动所普遍遵守。**

也就是大家都在自觉或者不自觉地去遵守这样一个惯常做法。这是主观层面的要求。

客观上长期存在，主观上普遍遵守，两条都满足，才能成为民法意义上的习惯。

#### 习惯要成为依据，得先过这两道关

习惯构成只是入场券。构成习惯之后，还要满足什么条件，才能成为处理民事纠纷的依据呢？两个要求，这个要求是写到《民法典》当中的。

**第一，法律没有规定。**

这意味着：法律有规定的，要优先适用法律。习惯只是**补充性的**民法渊源。

注意"补充"这两个字的分量。法律缺位的时候，习惯才顶上；法律说了话，习惯就得靠边。法官不能拿"我们这儿都是这么办的"去对抗一个明文有效的规定。

**第二，不得违背公序良俗，也不得违背社会主义核心价值观。**

有些习俗呢，虽然大家普遍遵守，但如果它是封建陋习，那显然不能作为处理民事纠纷的依据。

前面说了"普遍遵守还不够"，原因就在这里。

#### 一个反例：拉帮套为什么不被认

我举一个大家都知道的电视剧。有一部 90 年代的电视剧叫《情债》，虽然很老，但拍得还挺不错的。里面讲到某地区常常存在的一种民间习俗，叫**拉帮套**。

它讲的是一个什么场景呢？一个家庭的成员，常常是男性成员，因为疾病、意外等原因完全丧失了劳动能力，在当时的条件下，这个家庭的生计都难以维系了。那这时候就会选择一个有劳动能力、但是娶不起媳妇的后生来加入这个家庭，让他们三个人共同生活来维持生存——这就叫拉帮套。

在《情债》当中，李幼斌饰演的朱四，就加入了老七和七嫂的家庭，给人拉帮套，三个人一起共同生活来维持生计。

其实这种民间习俗，是特定历史条件下为了维持生计、为了生存的一种无奈之举。这里面的每一个人，都是放弃了自己的一部分尊严来维持生存的。

那问题来了。假如说在现代社会，有人也愿意拉帮套，觉得三个人生活在一起很幸福、很和谐，这个时候能不能以拉帮套这个民间习俗为依据，让法律认可他们合法夫妻的身份？

**答案是不可以。**

因为这样的习俗呈现的是一种一妻多夫的状态，它是违反一夫一妻原则、违背公序良俗的，所以它不能成为处理民事纠纷的依据。

你看，"普遍遵守"这一条它过了——当地确实世世代代这么干；但"不得违背公序良俗"这一条它过不去。**一个被普遍遵守的落后习俗，照样不能被法律接住。**这正是要设第二道关的原因。

### 民间法第一案：顶盆过继

讲义里给大家写了一个案例，是我们国家实践中发生的**第一起以习惯作为法院裁判依据的案件**，民法里把它称为**民间法第一案**。尽管它发生的年代比较久远，但因为它是第一案，具有开创意义的，所以大家得学。

我们学民法的时候经常会碰到各个领域的"第一案"，这类案例几乎每考一次就重复一次。

这个案件发生在山东青岛，涉及一种民间习俗，叫**顶盆过继**。

#### 案情：一份顶盆过继，埋下八年后的祸

先把这个习俗讲清楚，不然案情看不懂。

**顶盆发丧**，是传统葬礼当中的一个环节：常常由死者的长子来完成，要把一个盆举过头顶，给它重重地摔碎，然后就正式发丧出殡了。大家看过《大宅门》吧，里面有白家二奶奶出这样一个宏大的场景，那摔盆的环节就由二奶奶的长子白景琦来完成。

那假如说这个死者他自己没有子嗣呢？那摔盆这个环节，就由同辈的晚辈、常常是侄子来完成。

完成以后呢？这个**职责**就会过继到这个死者的名下，成为死者的子女。

注意"职责"这两个字——摔盆只是一个象征，象征的是**权利义务的整体转移**。一方面，他可以继承死者的遗产；另一方面，未来清明节的时候，你要去祭奠的是过继后的父母，而不是自己的生父母。这就叫顶盆过继。

来看案情。

1997 年 12 月，石某因病去世。因为他的妻子、儿女均已去世，无人料理后事，家族的长辈就按照当地顶盆过继的习俗，从死者的晚辈中选中了被告石甲。石甲是石某二哥的儿子，相对来说就是石某的侄子。由他来为石某带孝发丧，相当于过继到了石某的名下，将来继承石某留下来的房子。

石甲入住了石某的房屋，本来相安无事。但是 8 年以后，这个房子要拆迁了，有可能获得一笔 30 万元的补偿款。

这个时候，原告石乙跳出来了。石乙是石某的三哥。他拿出一份经过公证的房屋赠与合同，显示石某曾经把这个房子要赠与给自己——双方签订了赠与合同，而且办理了公证。

石乙说：你看这个房子，之前石甲没地方住，我没跟你计较；但是现在房子要拆迁了，这个房子是石某要送给我的，那这个补偿款当然应由我来取得。于是石乙就把石甲给起诉了，就产生了本案当中的纠纷。

#### 判决：一间房子，两个继承人

法院要解决的问题是：石某留下来的房子，到底应当给谁？

**先看石乙：他没有取得房屋的所有权。**

尽管双方签订了有效的赠与合同，而且还办理了公证，但是石乙并没有请求石某以及继承人来履行这个合同。所以实际上，他只是想要一个**合同债权**，他并没有取得房屋的所有权。

那他能不能直接请求把房子要过来？法院驳回了石乙的诉讼请求。

理由是：你尽管有债权，但是 8 年当中你都没有站出来主张权利，特别是在石某死亡、无人料理后事的时候，你也没有站出来。**你在自己的权利上睡觉，法律将不再给你保护**，因为你主张权利的诉讼时效期间已经届满了。

这一段是这个案子最有价值的地方。公证过的合同、有效的债权，摆在那里八年不动，等房子要拆迁增值了才来主张——法律对这种"权利休眠"是不给保护兜底的。

**再看石甲：他可以取得房屋所有权。**

尽管石甲是石某的侄子，他不是近亲属，但是基于当地的顶盆过继习俗，石甲已经过继到了石某的名下。这个时候，他可以作为**第一顺序法定继承人**继承遗产，因为他取得的是子女的身份。

当地的法院就以当地的习俗作为依据，认可了石甲第一顺序法定继承人的资格，把房子判给了石甲。

你看，这个案件就是以习惯作为处理民事纠纷的依据，依据的就是顶盆过继这个民间习俗。

#### 两个常见疑问

这里有几个疑问，我们一个一个解决。

**疑问一：习惯要成为依据，首先要以"法律没有规定"为前提。可不可以理解成，石乙虽然主张赠与合同的履行已经过了诉讼时效，但他也是石某的兄弟，是第二顺序法定继承人，那在法定继承的时候，他是不是可以优先于石甲？**

**答案是否定的。**

尽管石乙有第二顺序法定继承人的身份，但是石甲通过顶盆过继的习俗，取得的是**子女**的身份，他在法律上是第一顺序的法定继承人，所以当然可以优先于石乙。

**疑问二：《民法典》里面规定，收养指的是收养未成年人。石甲都已经成年了，怎么能适用收养制度呢？**

注意，"未成年人"这个限定，是 2020 年制定民法典的时候**新修改的规定**。而这个案件发生在 1997 年。在当时的法律体系中，收养当中是可以适用成年人的，并没有这个"未成年人"的限制。

所以，大家不能以现代的法律规定去衡量 1997 年这样案件的解决。当时的《收养法》之所以允许成年人收养，就是为了认可或者尊重不少地方存在的过继习俗。

#### 为什么 2020 年的民法典不再认它

既然当年《收养法》就是为了尊重过继习俗，那为什么 2020 年制定民法典的时候，就不尊重这个过继习俗了呢？

因为我们实行了几十年的独生子女政策，男女平等的观念早已经深入人心了。其实现在，即使有的死者他自己没有儿子，那这个**女儿**也可以完成顶盆发丧这个过程了。

现在的风俗变了。你不能说，你摔了个盆儿，就把全部地产都给你。可能站在现代社会的角度来讲，这并不是那么的公平。所以民法典里面就没有再考虑过继这个习俗，把收养制度限定在了未成年人的范围内。

你看，一个习惯能不能成为民法的渊源，不只是"有没有法律明文"这一件事，它本身也在随着社会变迁不断被重新评价。**八十年前被认为天经地义的事情，今天可能已经不再被接受——这不是法官的自由裁量，是整个社会的观念在移动。**

所以看这个案件，我们也要站在历史的眼光去看它，站在特定的历史场景下去理解当时这样一个案件的处理。

## 徒法不足以自行：民法的解释
> 对应块：BLK03 | 覆盖分集：P04 | 块标题（分集名）：《第01编 第01章 第01节：民法概述（03）》

有一句话大家可能听过，叫"徒法不足以自行"——法律只有在具体实施的时候，才能够体现它的价值。这句话对法考太贴切了：法条背得再熟，条文里的字你全都认识，真案子摆到面前，还是懵。法律不是在书柜里躺着的，它是在实施过程中活起来的；而法律一实施，问题就来了。

法律实施过程里冒出来的问题，这一讲处理第一个：**民法的解释**。开篇说过，这个节要讲两件事，一个是民法的解释，一个是民法的适用，先看解释，适用顺着往下走。

先给这一块定个位。很多人听过"授人以鱼，不如授人以渔"。第一个"鱼"是什么？老师把一个考点教给你，把一条民法规则讲给你，就是把这条能吃的鱼交到你手上。而加了三点水的那个"渔"，代表的是一种方法。**民法的解释就是那个"渔"**——它不直接给你答案，它教的是举一反三，所以它是具有方法论意义的。

从法硕考试的角度讲，大家先简单掌握民法解释当中一些最基本的规则就够了；至于基于这些解释方法做灵活运用，那是研究生上岸以后需要不断学习、不断深入的一个课题。今天这一讲的目标很实在：把七种解释方法是什么、怎么用，弄明白。

### 什么是民法的解释

> **定义**：民法解释，是指当民法规范不明确的时候，特定的解释主体运用一定的方法和原则，并遵循法定的权限和程序，来探求民法规范含义的活动。

通俗地讲，民法的规范，它的含义不明确，我们把这个含义具体搞清楚的过程，就是民法解释。

有些同学会问：立法机关已经通过法律条文来表达了立法者的意思，直接拿来用不就行了，为什么还需要民法解释？这个问题，正好引出下一节。

### 为什么非要解释不可

民法解释的必要性，要**从立法的局限性当中**去理解。立法当然很重要，但立法有它自己的局限。教材里写了三项，正好对应立法机关的三种"说不"。

#### 说不清：法律必须通过解释才能适应

现在立法机关制定法律的时候，试图通过文字把规则描述清楚，但中国的语言博大精深，有时候你确实想说清楚，客观上就是不能完全说清楚——有说不清的风险，所以必须通过解释才能够适用。

特别是民法，它是由一堆民法的专业术语，也就是法言法语形成的，而法言法语，普通老百姓看了都不知道什么意思。我们前面讲过民法典第 153 条第二款：违背公序良俗的民事法律行为无效。这个条文很短，但里面一口气出现了三个法律术语——公序良俗怎么理解？民事法律行为怎么理解？无效怎么理解？没学过法律的人，可能一个都搞不清楚。虽然都是汉字，但你也不知道它在说什么。

法理学里也讲法律的解释必要性，把立法的这种局限称为**模糊性**——就是有可能说不清。大家未来学法理学的时候，会再遇到这一组概念。我当年跟马老师交流的时候也聊过这个：法理学里讲的"法律解释的必要性"，和民法里讲的"民法解释的必要性"，是同一个道理。

#### 说不全：梳理内在结构以弥补法律漏洞

第二项必要性，体现为通过梳理法条的内在结构和逻辑关系，从而弥补法律漏洞。

还是因为立法有说不全的风险。尽管立法机关要尽可能把规范制定得更加完善，但总有漏案的风险，总有你想不到的情形，总会存在法律的漏洞。法理学把这种局限称为立法的**空白性**。这时候就要通过民法的解释，把这个漏洞填上。

#### 说不准：在个案中通过法官的创造性适用实现公正

第三项必要性，是法律解释也是法官创造性地适用法律、充分实现司法公正的要求，也就是在个案当中实现公平正义。

这一项对应的是立法的"说不准"。大家听过一句话，叫智者千虑必有一失。尽管立法机关希望自己想得更加周全，让制定出来的规范在 99% 的案件当中都能公平合理地解决纠纷，但总有那 1% 的特殊案件，或者实践中新出现的案件，用之前的规范来解决，未必能得到公平合理的结果。这时候就需要通过法官的解释工作，在这个个案中实现公平正义。法理学把这种局限称为立法的**滞后性**——后面出现的新情况、特殊案例，你之前的立法解决起来可能就没那么得心应手了，那就通过法官的能动性，通过民法的解释，让个案能够公平合理地解决。

> **结论**：基于立法有说不清、说不全、说不准这三种风险，民法才需要通过解释才能够适应。大家可以结合法理学里"法律规范本身具有模糊性、空白性、滞后性"这些局限，来理解民法解释的必要性。

### 七种解释方法的骨架

第二个问题，也是这部分的核心内容：民法解释的方法。教材里主要写了七项——文义解释、体系解释、历史解释、目的解释、当然解释、扩张解释、限缩解释。

在法硕考试中，大家重点是掌握每一种解释方法的含义是什么，以及基于这个方法怎么去运用；更深入的运用，要随着民法学习的深入去不断研究和学习。

讲义里我画了一张体系图，先给大家梳理这几种方法内在的逻辑关系。读这张图之前，先想明白一件事：民法解释要解释的是民法**规范**的含义，而规范是通过**文字**写成的。所以最核心要确认的，是法律规范当中所使用的文字应该怎么理解。理解文字，一层是尊重文字本身，一层是可以突破文字，于是分成两个层次，正好形成对应。

```text
                        民法解释：探求民法规范的含义
                                     │
                    规范以文字写成 → 文字该怎么理解
                                     │
             ┌───────────────────────┴───────────────────────┐
        层次一：以文义为核心                        层次二：不拘泥于文义
        （尊重立法机关使用的文字）                （透过现象看本质）
             │                                               │
    ┌────────┼────────┐                        依据合理的立法目的 → 目的解释
    │        │        │                                     │
 文义解释  体系解释  历史解释                  ┌──────────┼──────────┐
 （字面）  （位置）  （时间）              当然解释     扩张解释      限缩解释
                                 （读出潜台词）（超出文义）（小于文义）
```

读这张图：第一个层次是以文义为核心，最主要的体现就是文义解释；把这个文义放到特定的时空背景下去理解，放到特定的空间位置、结合上下文，就是体系解释；放到特定的时间背景、特别是放到制定规范时的那个时间点去理解，就是历史解释。第二个层次是不拘泥于文义，关键要看法律规范所要实现的目的，于是有了目的解释；目的解释可以突破文义，解释出的结果有可能大于文义，就叫扩张解释，有可能小于文义，就叫限缩解释；如果是解释出了文字背后的潜台词——虽然没明讲，但它肯定包含这个意思——就叫当然解释。

为什么第二个层次可以突破文义？因为法律制定规范不是为了玩文字游戏，而是为了规范现实的社会生活，我们要透过现象去看本质，不能拘泥于文意，而要基于立法的目的去解释它，这才是制定法律规范最终的意义所在。

下面一个一个看。我每讲一种，都会举一个具体的民法问题，演示这个方法到底怎么操作。

### 七种方法一个一个看

#### 文义解释：不是你以为的，是法律以为的

先看第一种，文义解释。它是最基础、也是最重要的民法解释方法，以文义解释为核心，其实只体现了对立法机关的尊重。

> **定义**：文义解释，又称文理解释，是根据民法规范中所使用的文字的字面意义进行解释的方法。

这里"文字的字面意义"要抠一下：它不是生活意义上的字面意义，而是**法律规范意义上的**字面意义。通俗地讲，规范里所使用的某个词，它指的是什么，不是根据你以为它是什么来界定的，而是要知道法律赋予它的含义到底是什么——**不是你认为，而是法律认为**。

举个例子。民法里经常用一个术语叫"近亲属"。哪些人可以纳入这个范畴？看哪些亲戚跟你走得更近吗？不是。要看在法律的眼中，哪些人可以纳入近亲属的范畴。按照民法典的规定，近亲属包括八种人：配偶、父母、子女，接着是兄弟姐妹、祖父母、外祖父母、孙子女、外孙子女。只有这八种人可以称之为法律上的近亲属，尽管在生活当中，有些人跟自己的舅舅、姑妈、叔叔等走得很近，但他不能纳入法律上的近亲属范畴。这是一个封闭的范围。

> **易错点**：学习民法的时候，大家要切忌望文生义，不能根据自己的主观理解来解读法律的含义，要去了解法律在设置这个条文的时候，到底赋予了它什么样的意义。这是我们学习的内容。

我们用一个案例来说明文义解释怎么操作。这个案例涉及一项制度叫离婚损害赔偿，跟民法典第 1091 条相关：有下列情形之一导致离婚的，无过错方有权请求损害赔偿。它是婚姻家庭编离婚制度中的一个考点，但我们在这里不是讲这个考点，而是通过它来演示文义解释到底怎么操作。

案例：王某是著名影星，发布微博称其妻马某和经纪人宋某存在不正当的关系。相信大家能猜出这是哪个新闻事件——就是大家非常熟悉的宝马离婚案。之后王某提起离婚诉讼，同时提起损害赔偿诉讼，要求马某承担损害赔偿责任：你们和我的经纪人搞到了一起，共同花我的钱，太过分了，宝宝很受伤。

法院要不要支持？就要看马某有没有法律规定应当承担离婚损害赔偿责任的情形。民法典第 1091 条列举了具体情形：重婚、与他人同居、实施家庭暴力、虐待遗弃家庭成员，以及其他重大过错的情形。这个案件发生的时候还没有民法典，当时的《婚姻法》只规定了前四项。

逐一排除：重婚？肯定不至于，还没那么明目张胆。家庭暴力？也没有。虐待遗弃？也没有。所以这个案件的核心是：马某的行为到底符不符合第 1091 条所称的"与他人同居"？约定说两人都有不正当的关系、都搞在一起了，那肯定是与他人同居啊——这就是**你以为的含义**。可法条里的"与他人同居"到底指什么，要看法律赋予它什么样的含义。

最高人民法院关于适用民法典婚姻家庭编的解释（一）对"与他人同居"作了专门规定，这是有权机关作出的解释：指的是与婚外异性、不以夫妻名义、持续稳定地共同居住。也就是说，这里的"与他人同居"需要同时满足三个条件。

- 第一，必须是与婚外异性。假如说发现老公跟另外一个男人住在一起了，这不构成法律意义上的与他人同居。
- 第二，不以夫妻名义。没有明目张胆，而是私自在一起。
- 第三，持续稳定地共同生活，要达到持续稳定的程度。

回到宝马离婚案：前两个条件马某是符合的，但她没有形成持续稳定的共同居住状态，所以她并不构成法律上的"与他人同居"。那马某要不要承担离婚损害赔偿责任？答案是**不需要**。我相信法官也很同情王某，但因为不存在法律规定的情形，只能忍痛驳回王某的损害赔偿诉讼请求。

这个案件发生以后，网友纷纷为宝强鸣不平：都这么欺负人了，还不能主张损害赔偿，那是不是法律有问题？所以制定民法典的时候，立法机关赶紧反思了一下：民法里面规定的离婚损害赔偿到底有没有问题？经研究决定，给适用的情形加了一个兜底条款，也就是第五项"其他重大过错的情形"，相当于把这个封闭的范围改造成了一个开放的范围。这意味着，假如宝马离婚案发生在民法典生效以后，宝强有没有可能获得损害赔偿？是有可能的，因为他有可能具备"其他重大过错的情形"。

所以民法典这一处完善，实际上是受了宝马离婚案的影响。也算是宝马离婚案对我国法治发展所做的贡献吧——它推动了这个法律的完善。

这个案件就涉及到"与他人同居"这五个字的文义解释。所以我们学民法，会学到大量文义解释的内容：法条里某个词语到底指什么，你要了解法律赋予它什么样的含义。

#### 体系解释：这个条文处在哪个位置

第二种解释方法叫体系解释，它是从文义解释里面延伸出来的。

> **定义**：体系解释，是指根据民事法律规范在法律体系中的位置，也就是和其他规范的关联，来确定其含义和内容的解释方法。

核心词是**位置**这两个字：看这个法条处在哪个位置，结合上下文来确定它的含义。

还是通过一个案例。涉及到特殊动产物权变动，是物权编的考点。甲把一辆宝马轿车以 10 万的价格卖给乙，双方签订买卖合同，乙支付了一半价款，甲就把车交到了乙手中，但没有办理过户手续。这意味着这辆车行驶证上依然写的是甲的名字，但车已经到了乙手里。这个场景能理解吧？那车到底现在属于甲还是属于乙？这也是法律问题，涉及物权编讲的财产归属。

我们找到了相关条文，民法典第 225 条：船舶、航空器和机动车等物权的设立、变更、转让和消灭，未经登记，不得对抗善意第三人。机动车就跟宝马车相关。这个案件中双方没有办理登记，所以肯定是不得对抗善意第三人。**但是这个条文没有讲：这个时候车到底属于谁。**光看第 225 条，不能完全回答这个问题。所以我们要考虑这个条文所处的位置，来确定机动车的所有权到底什么时候能发生变动。

我们发现这个条文出现在物权编第二章物权变动当中的第二节，这一节叫**动产交付**。这一节第一个条文是第 224 条：动产物权的设立和转让，自交付时发生效力，但是法律另有规定的除外。它讲的是动产以交付这一公示方式发生物权变动的基本规则。

那机动车这样的特殊动产，能不能适用第 224 条？既然立法者把机动车物权变动的规则放到了"动产交付"这一节下面，那这个位置就决定了：虽然你特殊，但依然是动产，你得适用动产物权变动的一般性规定。所以第 224 条中所称的"动产"，既包括普通动产，也包括机动车这样的特殊动产，是在交付的时候发生物权变动的效力。

结论就是：甲既然已经把车交到乙手中，是不是已经完成交付？能不能发生物权变动？可以。只是没办理登记的话，乙的所有权不能对抗善意第三人，但不影响他已经取得所有权。

这就是体系解释——运用它要考虑条文所处的位置，来决定法律适用的规则。

#### 历史解释：回到立法的那个时间点

第三种解释方法叫历史解释，它也是从文义解释中延伸出来的，是把这个规范所使用的文字放到特定的历史时间点来理解。

> **定义**：历史解释，又称立法解释，是通过探求立法者在制定民法规范时的立法意图，进行民法解释的方法。

核心词是立法者在制定民法规范时的立法意图：当时制定这个条文的时候，为什么用这个词？立法者当时到底是怎么想的？

当然，立法者当时到底是怎么想的，只能通过一些立法文献来确认，包括法律的草案、立法的理由书等等立法资料。

我们用民法典第 184 条来演示：因自愿实施紧急救助行为造成受助人损害的，救助人不承担民事责任。这是紧急救助的免责条款。

比如甲开车不慎冲到了河里，经过的乙慷慨相助，跳到河里把车窗砸碎，把甲救出来了。后来甲找到乙表示感谢，说要送他一个果篮，但同时你把我的车窗砸碎了，咱俩一码归一码，这个车窗的钱你得赔。甲能不能请求乙赔偿车窗的损失？根据第 184 条，当然不能。因为乙对甲实施的紧急救助造成甲的损害，不需要承担赔偿责任。你想想，人家为了救你的命才砸你的车，你找人家索赔也太不要脸了。

这个问题相对简单。我们再讲一个特别情形：如果救助人因故意和重大过失给被救助者造成了**不应有的损害**，要不要承担赔偿责任？举教材里的例子。车某开车在街上遛弯，路遇一个小姑娘当街晕倒在地。车某是个有正义感的人，瞬间想起自己学过心肺复苏的急救方法，人工呼吸、心肺复苏的套餐直接就上去了，把小姑娘的 12 根肋骨都压断了。小姑娘生生被疼醒了，很委屈地说：大哥，我就是没吃早饭、低血糖晕倒了，你犯得着把我的肋骨都压断吗？

那小姑娘能不能请求车某承担赔偿责任？车某固然是紧急救助，但是你没有去查看一下别人晕倒的原因，就直接上人工呼吸和心肺复苏的套餐——先不谈这个性骚扰的问题，就是把别人肋骨压断这个事情，虽然不能说是故意，但你是有重大过失的。要不要承担赔偿责任？

民法典第 184 条对此没有明确规定，但是法官得解决这个纠纷。假设通过历史解释的方法来确定这个规则，怎么操作？就需要查阅立法资料，看看当时立法机关在设置这样一个条文的时候，到底是怎么考虑"故意或重大过失造成损害要不要承担赔偿责任"这个问题的。

我替大家查到了：当时民法典总则编出台的最后一版草案是这么写的。第一句话"因自愿实施紧急救助行为造成损害的，救助人不承担民事责任"，跟现在的说法完全一样；但草案里还有后面这句话：

> 受助人能够证明救助人有重大过失，造成自己不应有的重大损害的，救助人应当承担适当的民事责任。

当时的草案里是有这个内容的，也就是想让有重大过失的救助者承担赔偿责任。但后来法条通过的时候，后面这半句话被删掉了。删除的原因，是部分人大代表对后面这句话提出了意见，这个意见我也写进了教材：

> 难以消除见义勇为者的后顾之忧，不利于倡导培育见义勇为、乐于助人的良好社会风尚，建议删除。

因为在现代社会，一个人摔倒了，到底扶还是不扶，大家都得慎重考虑一下。假如法条里设置了一个需要承担责任的特别情形，那在对别人进行救助的时候，这个行为到底会不会被法官评价为重大过失，可能是存在疑虑的。那这个时候多一事不如少一事，可能就不去实施这个救助行为了。同时人大代表的建议也是有分量的，立法机关就听从了这个建议，把后面这半句话删掉了，希望这样可以让救助者免去后顾之忧，去勇敢地救人——法律都会免除你的责任。

通过这样一个从立法草案到正式条文的变化，我们可以看出，出台这个法条的时候，立法机关的意图是：**即使存在重大过失造成损害，也不需要承担责任**，这样才能够完全消除救助者的后顾之忧。这就是立法者的立法意图。

那意味着，基于历史解释得出的结论是：即使车某是有重大过失造成的损害，他也不需要承担赔偿责任。车某这么莽撞，把别人的肋骨压断，真的不需要承担赔偿责任吗？

注意，我们这个地方只是讲基于历史解释的方法得出的结论是不需要承担责任。那这个案件到了法院以后，法官要不要采取历史解释的方法，他是有自由裁量权的。所以每一种解释方法，可能得出的结论是有所不同的。

这就使得法律的适用存在一定的弹性，方便法官的自由裁量，同时也使得原被告双方的律师，有一些为自己的当事人争取更多利益的空间。所以民法的解释，是大家未来一定要深入去钻研的一个板块。

#### 目的解释：透过现象看本质

第四种解释方法叫目的解释。它就不拘泥于规范所使用的文义了，要透过现象看本质。

> **定义**：目的解释，是指不拘泥于民法规范的字面含义以及立法者制定法律时的立法意图，要从现实的社会关系发展要求来出发，依据合理的目的来进行法律的解释。

核心是**依据合理的目的**。法律规范的制定不是为了玩文字游戏，而是为了规范现实的社会生活，所以我们站在法律想要规范的社会生活的目的角度去理解它的含义。这叫透过现象看本质。所以这种解释方法其实更高级，也更难于操作，因为你需要了解每一项制度真正的立法目的。

涉及民法典第 1007 条，这是人格权编的一个条文：禁止以任何形式买卖人体细胞、人体组织、人体器官、遗体，违反前述规定的买卖行为是无效的。基于生活经验，大家也能理解这个条文。比如人体器官像心脏、肝脏、肾脏，包括血液等等，能不能买卖？不能，这是违反公序良俗的。

但接下来的案例，用这个条文能不能很好解决？我们来看。村里有个姑娘叫小芳，长得好看又善良——这是很早的一首歌曲里的词，一双美丽的大眼睛，辫子粗又长。后来因为失恋，希望从头开始新的生活，于是决定把辫子剪下来剪成短发。某假发制作公司希望以 3000 块钱的价格买下小芳的这个辫子。实践中这样的交易非常常见，双方都签订了买卖合同。我们判断一下这个买卖合同的效力如何，它是不是一个法律所认可的交易。

有些同学说，在没有阅读第 1007 条之前，我肯定认为这个交易是有效的，因为生活当中很常见。但刚才讲了第 1007 条的规定以后，反而有所疑惑了：头发也属于人体组织的范畴，而法律明确讲了，违反前款规定的买卖行为是无效的。那记住这个字面含义，应当认定买卖头发的交易是无效的。这个结果好像跟生活常理不符。

这里给大家强调一个观点：**帮你分析一个民法问题，基于法律规定得出的结论明显违反生活常理的，一定不是法律出了问题，是你对法律的理解出了问题。**因为法律是不能违背生活的一般常理的。这一点希望大家在学习法律之前就有这样的思想准备——不能说学了一套法律以后，把自己的生活常理都学没了，那就适得其反了。

这个案件里的买卖在生活当中是被广泛认可、也广泛运用的，但按第 1007 条的字面规定去理解，反而会否定这个交易的效力。所以我们要反过头来反思一下：对这个条文的理解是不是准确？或者说，第 1007 条是不是必须按照字面含义去理解？这个时候就要反思这个制度设立的目的了：为什么法律不允许买卖这些人体细胞、组织器官？

这个制度的立法目的我写在教材当中了：

> 本条规定旨在防止人体组织或者器官成为交易的商品，进而构成对人格尊严的严重贬损，进而违反公序良俗。

血液、心脏、肾脏这些器官可以买卖的话，有些经济条件比较差的人可能就会选择去卖血、去卖器官来维持生存，那样是违背公序良俗的，所以法律不允许。这是它的立法目的。

那就意味着，本条禁止交易的细胞、组织、器官，要局限在那些和人的生理机能或者人格尊严的维护紧密相关的部分。而本案涉及的头发是小芳自愿剪下来的：一方面和人的生理机能的维护无关，另一方面也跟人的尊严的维护无关，所以要把它排除出第 1007 条的适用范围。这就是基于目的解释得出的结论——可以不拘泥于规范所使用文字的字面含义。当然，得出的结论比字面含义要小，所以又称为限缩解释。我在前面提到，无论是扩张解释、限缩解释还是当然解释，都是从目的解释当中延伸出来的。这样一个案件当中我们用的解释方法，也可以称之为是**目的性限缩解释**。一方面维护了第 1007 条的有效性和权威性，另一方面也可以使这样一个个案得以圆满地解决——这就是解释方法运用的意义所在。

有些同学可能会有个疑问：头发被剪下来以后，它就变成一个单纯的物了，它不是人体组织，怎么就不能交易了？这个理解是不对的。因为这里所讲的人体细胞、组织、器官甚至遗体，和人分离以后都会展示出具有物的属性。比如血液从人身上抽取出来以后，它也变成物；包括精子、卵子这样的细胞，和人分离以后也会变成物。那为什么这些组织、细胞、器官不允许交易？因为它关涉人的生理机能的发挥和人格尊严的维护。

所以这里所讲的"有没有和人的生理机能以及人格尊严的维护相关"，要看它在**与人分离之前**能不能发挥这个作用。你像头发，在与人分离之前，一方面它对生理机能的维护没有什么实质的意义，同时它和人格尊严的维护也没有什么本质的关系，所以它和人体分离以后才可以进行交易。

但有些同学说，有些人的头发是关涉尊严的，比如文革期间给别人剃阴阳头，包括电视剧《乡村爱情》里谢广坤的头发，那就关涉尊严了。如果没有经过别人的同意擅自剪别人的头发，可能侵犯身体权；剃阴阳头这种方式有一定的侮辱属性，有可能侵犯人格尊严。但是——它都跟第 1007 条没什么关系。第 1007 条讲的是**你主动剪下的头发能不能卖给别人**，它跟前面是完全不同层次的问题，大家不要混为一谈。

#### 当然解释：连他都行，那我更行

第五项是当然解释。它体现的是"举重以明轻、举轻以明重"这样一个解释原则。

> **定义**：当然解释，是指虽然法律没有明文规定（这是前提），但是依据规范的目的进行衡量，某一事实比法律规定的事实更有适用的理由——连它都行，那它更应当行——所以这个时候可以直接将法律规定适用于该事实。

这就是发现了法律背后的潜台词。

我们用民法典第 499 条的悬赏广告来演示。条文内容是：悬赏人以公开方式声明对完成特定行为的人支付报酬的，完成该行为的人可以请求其支付。

这个规定其实很好理解：发宣传广告的人，相当于向社会公众做出了一个邀约；完成该行为的人，有一个承诺的意思。双方的意思表示达成一致，就可以形成一个悬赏合同。悬赏合同成立，完成行为的人当然可以请求悬赏人支付报酬。这是这个条文的意义所在。

但这个条文能不能解决我们接下来这个案件？车某将其电脑遗失在了火车站。车某是个丢三落四的人，经常丢东西。前段时间我们一起去外地开会，办酒店入住的时候大家都用身份证，而车某拿着户口本来办入住，我就知道他的身份证又丢了。因为电脑里面有新修改的 2027 年法硕《一本通》的书稿，所以他非常着急，于是通过微博发了一个悬赏广告，声明：谁拾得电脑归还给他，会给付 1 万块钱的悬赏金。

岳某在火车站捡到了这个电脑，而且看到了电脑上贴的大头照，迅速认出这是车某的电脑，于是就把电脑还给了车某。当然，因为那段时间车某和岳某有点小矛盾，岳某在微博上把车某拉黑了，他就没有看到这个悬赏广告。过了好多天，岳某对车某的微博重新进行关注的时候，才发现车某当时发了悬赏广告，于是要求车某兑现承诺：你得给我这 1 万块钱的悬赏金。

车某说：我固然发了悬赏广告，算是一个邀约；你固然也把电脑还给了我，但是你在还给我电脑的时候，根本就不知道有这个悬赏广告的存在，也就在法律上，你并不存在一个对悬赏广告进行承诺的意思，我们之间没有达成意思表示合意的状态，你凭什么找我要这个悬赏报酬呢？

听起来好像有点道理，但是大家发现这个结论可能是违背生活常理的。所以我们要回归到悬赏广告的立法目的当中去寻找答案：为什么法律允许完成行为的人可以请求对方支付报酬？是为了奖赏这些拾金不昧的行为。捡到东西主动归还，是不是弘扬了这样的价值观？同时悬赏人自己都做出声明要支付报酬，那法律当然要认可这个归还遗失物的人取得悬赏金的权利，这是对拾金不昧的一种鼓励和奖赏。

而本案当中的岳某，一方面实际上归还了遗失物，同时在归还的时候根本不知道有这个悬赏广告，他都进行了归还。是不是岳某的道德水平更高？那比那些制造了悬赏广告、为了拿这 1 万块钱而归还的人，是不是更有鼓励和奖赏的意义？使得法律完全没有必要把岳某排除出去——连知道的人都可以拿到悬赏金，不知道悬赏广告就归还遗失物的人，那他更有资格拿这个悬赏金。

这就是当然解释的运用：连它都行，那我更行，所以这个案件可以基于当然解释得出这个结论。

这里也有个延伸问题。有人认为悬赏广告是合同，还有人认为是单方允诺。如果是单方允诺，不就没有这么多复杂的事情了吗？既然你已经做出承诺了，你就应当给付这个报酬。

这个悬赏广告到底是合同还是单方允诺，是民法典颁布之前产生的争议问题。民法典颁布的时候，已经做出定论了，它就是一个合同，最高人民法院也把悬赏当成是一种合同。实践中完成行为的人起诉主张悬赏报酬的，立案的案由就叫悬赏合同，你必须要选这个案由才能去法庭起诉。所以现在我们会把悬赏广告认定为合同，延伸出的特别问题，可以通过当然解释等解释方法来解决。

有同学看到教材上写"悬赏广告是单方允诺"，要说明一下：那是民法典之前的观点了。实际上在民法典的背景下，你把悬赏广告认定为单方允诺，怎么来适用法律？单方允诺自己都没有法律依据，它都得指望借用合同的规则来解决相关纠纷。把它认定为单方允诺，其实一点意义都没有，对法律的适用没有任何帮助。

#### 扩张解释：把字面装不下的装进来

第六项是扩张解释，它也是从目的解释中延伸出来的。

> **定义**：扩张解释，是指民事法律规范的条文中所使用的文字、词语的文义过于狭窄——当时立法机构想得太狭窄了，不足以涵盖立法者所欲调整的范围——为了符合立法本意，要对文义进行扩张，将排除在适用范围之外的案件纳入调整范围的解释方法。

简单说，就是把规范所使用文字的字面含义给它做一个扩张，把一些其他的案件纳入进来。

涉及民法典第 1012 条，是姓名权的行使问题：自然人依法享有姓名权，有权依法使用、变更或者许可他人使用自己的姓名，但是不得违背公序良俗。这里面讲到姓名，它是一种受法律保护的人格利益。

那"姓名"指的是什么？首先要用文义解释来界定：它指的是自然人的登记姓名，比如每个自然人都有身份证，户口本上写的那个姓名，就是正式姓名，是姓名权所保护的对象。

关键是实践当中，还有有些人在社会交往的时候没有用自己登记的姓名，而是用别名——比如有些作家是有笔名的，有些明星是有艺名的，有些网络大 V 是有网名的，这叫别名。那这些别名能不能受到姓名权的保护？也就是说，别人没有经过你的许可擅自使用你的别名时，你能不能主张侵权责任？

来看一个实践当中真实发生的案例。前身是延安鲁迅学院的沈阳鲁迅美术学院，要注册一个商标，对"鲁迅美术学院"等校名进行注册。这个消息传出以后，鲁迅之子周海婴就以鲁迅的姓名权被侵犯为由要求维权。

这个时候，沈阳鲁迅美术学院能不能提出说"我用的是鲁迅的文字，你是周海婴啊，你姓周的和人家姓鲁对有什么关系，你们是一家子吗"这样的抗辩？从生活经验的角度讲，他肯定不能。因为众所周知，鲁迅是笔名，他的本名叫周树人，人家本来就姓周，只是"鲁迅"这个笔名影响力更大。而且你把这个姓名注册成商标的话，普通老百姓会不会认为这肯定是经过鲁迅后人允许的，说不定还拿了钱？完全有可能产生这些误解或者联系。那这个时候如果不允许周海婴提起诉讼，显然是不符合生活常理的。

所以这个时候我们要去反思：民法典对于姓名这种人格利益保护的立法目的，既然决定它的适用范围，是不是只能仅仅局限于登记姓名？姓名发挥的是什么作用？它发挥的是社会交往当中人格识别的功能——一说这个姓名就知道指的是哪个人。而实践中有一些别名，特别是有一定社会影响力的别名，在社会交往当中也可以发挥人格识别的功能，如果被他人误用，也会导致混淆。那基于法律保护姓名的立法目的，如果仅仅局限于登记姓名，显然是太过于狭隘了，所以要把一些别名纳入进来。

所以民法典里面专门设立了一个条文，第 1017 条：具有一定知名度、被他人使用足以导致公众混淆的笔名、艺名、网名、译名、字号以及简称等，可以参照适用姓名权、名称权保护的相关规定。是不是把这个别名纳入进来了？扩张了姓名权保护的"姓名"的范围，这是个典型的扩张解释。

所以在这个案件当中，当然可以。可能有同学看过影视剧里面有一句很有意思的台词：相关部门去抓鲁迅，他就提出"你抓鲁迅，关我周树人什么事"。这样的抗辩能不能成立？不能。因为鲁迅和周树人就是一个人，都在发挥人格识别的功能。

> **提示**：这还算民法的解释吗？注意，实践当中发生鲁迅这个案件的时候，还没有民法典。当时的法律就是用扩张解释的方法来解决这个案件，支持了周海婴的诉讼请求。后来民法典的制定者觉得这样的问题具有普遍性，就把它固定成了一个条文。但那个条文的来源本身，体现的就是扩张解释的方法。所以大家注意到第 1017 条里面所讲的别名，它在保护的时候是**参照适用**姓名权的保护——你注意这个词，它不是直接适用，而是参照适用。也就是说，它本来其实不属于姓名权的保护范围，但是基于这个立法目的，也把你纳入保护的范畴，所以叫参照适用。

#### 限缩解释：把字面装多了的拿出去

第七种解释方法叫限缩解释。

> **定义**：限缩解释，是指规范所使用的文字含义过于宽泛，包含了本应该排除在调整范围之外的案件时，为了符合立法本意，要对文义进行限制，将不应适用该文义的案件排除在外的解释方法。

就是当时立法机关用这个词的时候用得有点太大了，让一些本来不应当适用的情形都纳入了这个文义的范围，所以要基于限缩解释把它排除出去。

这个案例涉及民法典物权编的一项制度：按份共有人的优先购买权。民法典第 305 条规定：按份共有人可以转让其相应的共有的不动产或者动产的份额，其他共有人在同等条件下享有一个优先购买的权利。

案例：车某、马某、杜某等五个人是同一个单位的同事，关系都非常的好——至少表面上很好。五个人每人出了 40 万，购了迈巴赫轿车一辆，然后每人占 1/5 的份额，谁需要的时候谁开，构成按份共有的状态。

后来车某嫌弃迈巴赫的性能，因为他开了宾利之后就觉得迈巴赫不香了。他想要退出这个共有关系，自己单独买一辆宾利，他觉得自己已经是宾利级别的名人了，于是决定把这个份额转让出去。假如他转让给另外一个人王某，按照民法典第 305 条的规定，其他共有人在同等条件下享有一个优先购买的权利。

这样一个优先购买权，事实上是对共有人权利的一种限制。虽然是你自己的份额，你 10 万块钱卖给王某，但法律说了，如果其他四人愿意出这个价，那你这份只能优先卖给其他共有人。这些共有人是不是对自己权利的一种限制？这是优先购买权的基本适用方式。可以看出，这样可以避免让陌生人加入到共有人的队伍当中来，进而破坏共有人内部和谐的氛围。

但是本案例有所不同。车某是将这个份额以 10 万块钱卖给了好友岳某，不是卖给第三人王某。有同学说，车某是不是数学是体育老师教的？他花了 40 万出资取得的份额，为什么 10 万块钱就卖给岳某，是不是脑子有问题？

当然不是脑子有问题。车某是通过这样的行为来表达他对岳某深深的爱，法律当然没必要禁止。这个时候，马某、杜某三人要主张优先购买权吗？也要主张平等地爱，不能只爱这个岳某——虽然你们是一张卷子上的。这个主张能不能成立？

如果直接适用民法典第 305 条的规定，车某是在转让其相应的份额，这个转让从字面含义上来看，肯定既包括对内的转让，也包括对外的转让，都可以纳入这个字面含义范围。但是如果把对内的转让也纳入适用范围，进而允许其他共有人主张优先购买权，显然是不符合车某的意愿的——因为车某对岳某的爱是独一无二的，不允许别人来分享。

这时候我们就要反思这个制度的立法目的了：为什么要限制转让的权利、允许其他共有人优先购买？前面提到过，是为了维护共有人之间的相互信赖关系，而不让陌生人随随便便加入共有人队伍当中来。而车某如果把份额转给共有人岳某的话，是不是体现的是内部转让？他并没有新人进来，不会破坏原来共有人内部和谐稳定的氛围，那这个时候就没有必要限制车某的权利了。

所以最高人民法院的司法解释，对民法典的第 305 条作了一个限缩解释。教材里面写的是物权编解释（一）的第 13 条：共有人之间转让共有份额的，其他共有人主张优先购买权的，人民法院不予支持。也就是说，这里面所称的"转让"只能是对外转让，内部转让不会产生优先购买权。

你看这个结论的范围，是不是要小于民法典第 305 条文义的范围？所以这叫限缩解释。这跟这个制度的立法目的也是相关的。是不是岳某就可以独享车某的爱了？得不到的永远在骚动，只有被偏爱的才有恃无恐。这就是限缩解释的运用方式。

这一讲教材里的七种解释方法就讲完了。还有几种解释方法，比如和合解释、比较法解释、社会学解释等等，这里简单了解一下，大家学法理学的时候老师应该会展开。比较法解释在民法当中有可能用到，它讲的是在理解我国民法规范的含义时，可以参考其他国家的相关制度来理解。

需要重点掌握的还是前面这七种：一方面了解概念，另一方面结合我今天给大家举的这些例子，来感受这个解释方法到底怎么用。而再往前一步——开篇说过的第二个问题，也就是民法的适用——是解释之后紧接着要处理的内容：法条含义明确之后，究竟按什么顺序、依据什么规则把它用到具体案件上。那是下一讲的事情。

## 民法的效力范围：时间、空间与对人
> 对应块：BLK04 | 覆盖分集：P05 | 块标题（分集名）：《第01编 第01章 第01节：民法概述（04）》

接着第二个问题，是**民法的适用**，也就是民法的效力范围。

本来这是一个法理学层面的问题，但因为民法典里面有相应的规定，所以在民法里我们也要做一次简单介绍。民法的效力分成三个层次：第一人，第二地，第三对人——天时地利人和，三个层次。我们就顺着这个顺序往下走。

```text
民法的效力范围（天时 · 地利 · 人和）
│
├── 时间效力（时）—— 管"什么时候"
│     ├── 生效与失效的时间：规范从哪一天起、到哪一天止
│     └── 溯及力：能不能回过头去管生效之前发生的事
│
├── 空间效力（地）—— 管"在哪里"
│     ├── 中央机关制定的规范 → 全国领域
│     └── 地方机关制定的规范 → 只在本地区
│
└── 对人的效力（人）—— 管"对谁"
      ├── 划分标准：国籍（中国人/外国人） × 地点（境内/境外）
      └── 核心原则：属地原则
```

读图可知，这三个层次里"时"这一层最长、也最绕，它又分成"规范本身的生死时间"和"能不能溯及既往"两件事。下面先啃时间效力。

### 时间效力之一：生效与失效的时间

先来看第一个方面，民法规范的生效与失效时间的认定。这是**时间点**的概念。

#### 生效时间：民法规范从什么时候开始发生效力

有两种规范模式。

第一种是**颁布就生效**。这种立法模式更多适用于公法。

第二种是**明文规定在公布以后的某个具体时间生效**——常常是颁布的时候不生效，过一段时间再生效。民法采取的恰恰是后一种。

> **注意**：民法典在 2020 年 5 月 18 日就颁布了，但要等到 2021 年 1 月 1 日才生效。

中间这半年多，是留给老百姓和法官学习新法律、慢慢适应的。所以民法规范的生效时间，通常要往后留一段缓冲。

#### 失效时间：失去效力的时间，一般有三种规范方式

| 失效方式 | 怎么理解 |
|---|---|
| 自然失效 | 规范是为特定的规范目的而出台的，当这个规范目的实现时，该规定自然失效，讲得俗一点叫"寿终正寝" |
| 部分失效 | 新法颁布后，之前与新法相抵触的部分终止其效力；不相抵触的部分继续有效 |
| 修改并重新公布 | 修改后的新法公布实施，同时宣布原法律的效力终止。这种模式更为常见 |

**部分失效**的例子最好懂。1995 年我国颁布了《担保法》，里面规定了抵押、质押、留置这三种担保物权；2007 年又颁布了《物权法》，物权法里也有抵押、质押、留置的规定，有些规定是不一致的。于是物权法里专门有一个条文：讲到《担保法》和本法规定相抵触的，以本法为准。凡是与物权法相抵触的担保法条文，自物权法施行之日起就失去效力了。

**修改并重新公布**的例子就是我们脚下这部法。教材里我给大家列了整部民法典的最后一条，也就是第 1260 条：一方面讲民法典自 2021 年 1 月 1 日实施，同时讲明九部法律同时废止——

- 《婚姻法》
- 《继承法》
- 《民法通则》
- 《收养法》
- 《担保法》
- 《合同法》
- 《物权法》
- 《侵权责任法》
- 《民法总则》

这叫**立一废九**。民法典的生效，意味着这些民事单行法同时失去效力。

> **提示**："立一废九"是常考的一句话。答题时要注意它的方向性：是民法典**立**一部，同时把**九**部单行法**废**掉，别把方向记反了。

### 时间效力之二：溯及力

第二个问题是民法溯及既往的效力，强调的是一个**时间段**的概念：民法对哪段时间发生的民事法律事实有约束力？

主要是对民法典颁布**以后**发生的事实具有约束力。那对之前的事实有没有约束力？在理论里把它称为民法的**溯及力**。

#### 原则上不溯及既往

原则上，法律没有溯及既往的效力。

> **结论**：金朝的法不能管前朝的事。这是一个生活常识，法律上也不例外。

当然，有原则就必有例外。最高法专门公布了一个司法解释，叫《民法典时间效力的司法解释》，专门讲哪些情形下民法典可以对之前发生的事实有约束力，也就是民法典溯及既往效力的范围。

所以大家记住：原则上没有溯及力，但例外情形就规定在时间效力司法解释当中。

这里顺带说一句考试上的事。这个时间效力司法解释，**并没有纳入我们法硕考试的考纲范围**，但是法硕考试中已经考过多项选择题了。这说明考试大纲、考试分析对命题人并没有法律上的约束力，即使超纲，你也不能说这个命题是无效的。所以我们讲课的时候会结合司法解释、结合马工程教材，给大家补充一些超纲考点——超纲不等于不考。

#### 四种例外情形

第一种，**持续性事实**。

尽管这个事实发生在民法典生效之前，但它一直持续到了民法典生效以后，坚持到了民法典颁布，那就进入民法的效力所及范围了。

比如，侵权行为虽然发生在 2019 年，但损害后果一直延续到了 2021 年。这时人民法院审理相关侵权案件，是可以适用民法典新规定的——因为这个事实虽然是从民法典生效之前开始的，但它一直持续到了生效以后。持续性事实，是具有溯及既往效力的。

第二种，**有利溯及原则**。

尽管事实发生在民法典生效之前，但如果民法典的规定更有利于保护民事主体合法权益、更有利于维护社会经济秩序、更有利于弘扬社会主义核心价值观，那么民法典就具有溯及既往的效力。这叫**有利溯及**。

> **定义**：有利溯及原则，就是拿上面那三个"更有利于"当标尺，事实发生在前、但新法更有利的，让新法管。

这个例证非常好记：**要让老百姓能够享受法治进步的成果**。

比如民法典第 1254 条明确规定了高空抛物的救济规则，可以说比以前的规则完善多了。那假设某起案件发生在 2019 年，当时发生了高空抛物，但当事人起诉的时候已经是 2021 年了，能不能适用民法典的规定来给当事人相关的救济？当然可以。因为民法典的规定更有利于受害人的损害救济，更有利于社会秩序的维护，更有利于弘扬核心价值观。

第三种，**空白填补原则**。

法律事实虽然发生在民法典生效之前，但当时没有相关规定，而民法典有相关规定，这时就可以用民法典的规定去解决之前发生的纠纷。

比如民法典里明确规定了**添附**制度，我们到物权篇会讲到：比如甲家的地板被铺到了乙家的地板上，会发生一个添附。这属于一方面要解决这个地板归属于谁，另一方面还要解决补偿或者赔偿的问题。尽管这个案件发生在 2019 年，是在民法典生效之前，但民法典生效之前是没有相关规范来解决这个纠纷的，而民法典把这个空白给补充上了，那民法典的规定就可以适用于之前发生的案件了。

第四种，**旧法只有原则规定、新法把它具体化**。

民法典实施之前的法律事实也有相关规定，只是按那个规定是一个原则性的规定，而民法典把它给具体化了、做了具体展开。这种情形下，**首先还是要适用原来的法律规定**；只是人民法院在写判决书时，可以通过民法典的具体规定来进行裁判说理——说理部分可以用民法典的新规定。

比如之前的《侵权责任法》也规定了环境侵权，比如污染环境、破坏生态的要承担损害赔偿责任。民法典里也有环境侵权的规定，只是更加具体了，特别是民法典明确规定了破坏生态以后赔偿损失的具体项目。

假设某个破坏生态的案件发生在 2019 年、民法典生效之前，按当时的法律也要承担赔偿责任，只是当时的规定比较笼统——你要承担损害赔偿责任，但哪些损失要赔偿，当时的法律没有展开。而在民法典里都展开了。这个时候，反而在写判决书的时候，你可以把民法典这个细化的规定作为理由来阐述：这些项目得纳入赔偿的范围，因为民法典明确规定了——**可以**作为理由来援引。

这四种情形，都是司法解释规定的、使民法典具有溯及既往效力的比较重要的例外情形，大家要有所了解。

```text
法律事实发生在民法典生效前，先顺着这条线往下走
│
├── 事实持续到了生效以后？
│      是 → 适用民法典（持续性事实）
│
├── 旧法、司法解释完全没有规定？
│      是 → 适用民法典（空白填补）
│           但明显减损当事人合法权益、增加法定义务
│           或背离当事人合理预期的，不得溯及
│
├── 旧法只有原则性规定，民法典把它具体化了？
│      是 → 仍适用旧法；
│           裁判说理（理由部分）可用民法典的新规定
│
└── 旧法已有具体规定？
       是 → 适用旧法（这是原则，也是一般情形）
```

#### 一道真题里的陷阱：一刀切的说法要警惕

教材里我写了一道典型真题，就是这一节的最后——2025 年这道多项选择题：关于民法典实行之前的法律事实引起的民事纠纷，相关案件的法律适用，下列说法正确的是？

**A 项**：法律事实持续到民法典实行以后，可以适用民法典的规定。这个说法能不能成立？当然可以，这是持续性事实。**A 正确**。

**B 项**：当时的法律、司法解释有规定的，一律适用当时的规定。对不对？**太过于绝对了**，有例外情形。**B 错误**。

**C 项**：当时的法律、司法解释没有规定，而民法典有规定的，一律适用民法典规定。这个说法呢，也**太过于绝对**。尽管在之前的法律有空白的时候可以具有溯及力，但是大家稍微注意一下，它也是有例外的：**明显减损当事人的合法权益、增加当事人的法定义务，或者背离当事人的合理预期的除外**。**C 错误**。

**D 项**：当时的法律、司法解释仅有原则性的规定，而民法典有具体规定，可以适用当时的法律、司法解释规定，但可以依据民法典的具体规定来进行裁判说理。这个说法是**正确的**。**D 正确**。

所以应该选的是 **A、D** 两个选项。

> **易错点**：从考试角度讲，凡是用"一律""都""全部"这种绝对化的说法，常常是有问题的。法理是——不能因为民法典的实施，让当时的状况变得更糟糕了。明显减损权利、增加义务、背离合理预期的场合，就不能让新法溯及。

### 空间效力：领域内的民事活动，适用我国法律

第二个问题是民法的空间效力。民法典第 12 条明确规定：**中华人民共和国领域内的民事活动，适用我国法律的规定**。

这里面要重点关注"**领域**"这两个字。我们分成两个层次来理解。

#### 中央机关的规范：全国领域内都有效力

由全国性的机关制定的规范文件，会在全国领域范围内发生效力。

| 层次 | 规范来源 | 效力范围 |
|---|---|---|
| 第一层次 | 全国性（中央）机关制定的规范文件 | 全国领域 |

这里边"全国领域"包括三块内容：领土、领空、领海；还包括按照国际法以及国际法惯例，视为我国领域的其他领域。

比如中国的航空器，就可以视为我国的领域。像国航、南航的飞机，尽管停到了美国的国土上，但因为它悬挂着中国的国旗，那么这个航空器内发生的相关事实，都要适用我国法律的规定。

我国的驻外使领馆，按照国际法的惯例，也可以视为我国的领域，相关的纠纷也适用我国法律来解决。

#### 地方机关的规范：只在本地区有效力

| 层次 | 规范来源 | 效力范围 |
|---|---|---|
| 第二层次 | 地方机关出台的规范文件 | 仅在该地方 |

前面提到过地方性法规，包括地方政府规章，它也可以作为民法的渊源，但它只能在该地区发生效力。

比如前面提到的《北京市突发公共卫生事件应急条例》，它就只能是在北京市范围内发生效力，对上海市发生的事情是没有管辖权的。

这就是民法的空间效力。

### 对人的效力：属地原则

第三个方面是民法对人的效力：到底哪些人的行为可以受民法的规范？

我们以两个标准来划分：一个是**国籍**，可以是中国人的，也可以是外国人的；另一个是他所处的**地点**，是在国内还是在国外。

无论国籍还是地点，都各有两种情况，排列组合就出现了四种情形。

| 情形 | 适用哪国法 | 要点 |
|---|---|---|
| 中国人在中国境内实施的行为 | 适用我国民法 | 没有任何争议 |
| 居住在我国境内的外国人或者无国籍人 | 适用我国民法 | 原则适用，但**有外交豁免权的人除外**，比如外交官 |
| 居住在外国的我国公民 | 原则上适用居住国的民法，不适用我国民法 | 但依照我国法律或相关国际条约以及我国认可的国际惯例，应适用我国民法的除外 |
| 外国人在外国 | 与我国法没有关系，适用居住国的法律 | 民法典根本没有做出规定 |

大家看到底要不要适用我国的民法，核心的判断因素是什么呀？**主要是看地点**。

> **结论**：所以叫**属地原则**——主要是在我国境内的行为，不管你是中国人还是外国人，都得适用我国的民法。这是一个基本原则。

### 回头看一眼：民法这一节的自我介绍

到这里，我们就把第一节"民法概述"介绍完了。相对于民法的静态内容，前面花了更多篇幅做了一次比较详细的自我介绍。我们简单回顾一下，民法一共介绍了哪些方面。

首先是民法的定义，主要是通过它的调整对象来界定的。

然后再展开民法的自我介绍，分成两个层次：一个是从**静态**角度来观察民法，一个是从**动态**角度来描述民法。没事，让民法给走两步。

**静态角度**下又分两个层次：第一个层次是民法内在的性质与价值，内在的品质、三观；然后是民法外在的表现形式，叫做民法的渊源。既要看品质如何，也要看长得如何。

**动态角度**下讲了两个方面：一个是民法的解释，也就是在适用的时候如何理解它的含义；另一个是民法的适用，也就是民法的效力范围——我们这一讲就停在这里。

这就是民法给大家做的自我介绍。

## 民法的外延：谁和谁之间发生了法律关系
> 对应块：BLK05 | 覆盖分集：P06 | 块标题（分集名）：《第01编 第01章 第02节：民法的调整对象》

接下来我们看第二节，民法的调整对象。它其实讲的是民法的**外延**——民法到底管哪些事情。这一节相对来讲比较简单，主要是理论层面的问题：概念、边界，看过一遍基本就清楚了。

### 《民法典》第二条，与一个位置上的微调

民法的调整对象，在《民法典》第二条有明确的规定。我们先看这个规定：

> 民法调整平等主体的自然人、法人和非法人组织之间的人身关系和财产关系。

这句话其实已经把骨架给全了：主体是"平等主体的自然人、法人和非法人组织"，内容是"人身关系和财产关系"。这意味着民法调整的对象，既包括平等主体之间的**人身关系**，也包括平等主体之间的**财产关系**。

这里给大家补充一个小问题。尽管当年的《民法通则》也规定了民法的调整对象，同样是人身、财产两个方面；但是按《民法典》呢，它做了一个小小的调整——**它把人身关系放到了财产关系之前**。

尽管这个位置的调整好像没有什么实质意义，但是它在**观念**上有非常重要的意义：它体现了我国的民法典把人身关系放到了比财产关系更重要的位置上来对待，体现民法的人文关怀，体现以人为本的观念。

> **提示**：这一点也和我们国家把人格权独立成编的精神是一致的——不能光关注财产，也得关注人本身。

接下来我们把人身关系和财产关系这两个方面展开。主要是从理论上了解它们的**概念**以及**特征**。整体的结构是这样的：

```text
民法的调整对象（《民法典》第二条）
│
├─ 人身关系 —— 基于「人身利益」产生的权利关系
│   ├─ 人格关系 —— 基于人格利益的实现而产生
│   │                 生命健康、身体、名誉、隐私……
│   └─ 身份关系 —— 基于特定身份利益而产生
│                     配偶身份、父母身份、子女身份……
│
└─ 财产关系 —— 基于「财产利益」产生的权利关系
    ├─ 归属关系 —— 静态：财产归属于谁 → 物权制度
    └─ 流转关系 —— 动态：流转中产生的权利关系 → 债权制度
```

这张图就是全节的骨架：横向看是两类关系，纵向看是各自的两个分支。下面我们顺着它一个个走。

### 人身关系：基于人身利益的权利关系

> **定义**：人身关系，是基于**人身利益**而产生的权利关系，具体又包括**人格关系**和**身份关系**。

我们在前面也提到过这两个概念。

人格关系，是基于**人格利益的实现**而产生的权利关系。像生命健康、身体、名誉、隐私等等，都属于人格利益。

第二是身份关系，体现为基于**特定的身份利益**而发生的权利关系。而这个身份利益呢，主要是婚姻、家庭领域当中产生的——比如基于配偶的身份、基于父母的身份以及基于子女的身份产生的权利关系。

### 人身关系的三个特征

人身关系的特征，要从**法律关系的三要素**角度来描述：主体、客体以及内容，通过这三个角度来体现它的特征。

#### 主体：强调平等性

民法的调整对象是平等主体之间的权利关系吗？是的。所以人身关系的主体具有**平等性**。

#### 客体：人身利益，以及"不可分离"

客体其实体现为人身利益。你看这个概念里出现的关键词——既包括人格利益，也包括身份利益。那这个人身利益有个特殊性：**它和人身不可分离**。

> **易错点**：注意这个"不可分离"的属性。也就是说，这样的利益**不能转让、不能放弃、也不能继承**。

人能不能放弃自己的生命，允许别人来随便伤害自己的生命？当然是不可以的。因为它具有**人身专属性**。

再举一个例子：甲乙结婚以后，甲能不能把基于配偶的身份取得的权利转给别人呀？你也太大方了——即使你很大方，法律也不允许你这么大方。因为这样的利益具有人身专属性，是不能够转让的。

#### 内容：没有"直接"的财产内容

> **易错点**：注意，人身关系里面是**可以**有财产内容的，只是不能有**直接的**财产内容。

比如说夫妻关系当中，也要解决夫妻财产归属谁的问题；父母子女之间也有可能产生给付抚养费的问题，这些都跟财产相关。但是呢，它是**附属于身份关系**的，不是直接的财产利益。

那同时呢，侵犯这个人身关系以后，也有可能产生财产的损失。比如说侵犯他人的肖像权——没有经过明星的同意，就用明星的肖像来做广告，那是有可能给这个明星造成财产损失的。

所以呢，我们也不能把人身和财产完全区隔开来，它们还是有一些**交叉的领域**的。总的来看，在人身关系里面，**人身利益是核心，财产利益处于一个附属的地位**。从这三个方面去理解人身关系的特征。

### 财产关系：归属与流转

> **定义**：财产关系，指的是基于**财产利益**而产生的权利关系，既包括财产的**归属关系**，也包括财产的**流转关系**。

财产的归属关系，主要是**从静态**来描述的——这个财产归属于谁，这是**物权制度**要解决的问题。

而财产的流转关系，是**从动态**角度来描述的——财产流转当中产生的权利关系，主要通过**债权制度**来实现。

我们用一个例子把静态和动态的区别看明白：甲有一套房子，他要卖给乙，签订了买卖合同，但是没有办理过户登记手续。

你看双方之间有个财产关系的交往，会产生一个财产法律关系。这里面首先要确定的是：这个时候房子它归属于谁呢？是归甲还是归乙呢？按照**物权编**的规定，如果双方签了合同以后没有办理登记手续，那房子依然归属于甲。你看，这是从**静态**角度描述财产的归属。

那同时呢，乙呢，签订买卖合同，可能已经付了部分价款了。他没有取得所有权，他可以取得什么权利啊？他可以取得一项**合同债权**。基于这个合同债权，他可以请求甲来继续履行，协助他办理这个登记的手续。假如甲不配合办理这个手续，乙可以追究甲的**违约责任**。

你看，这是在双方签订合同、流转这个财产的时候产生的权利义务。也就是说，法律给乙的是**债权性质的保障**。这属于财产流转当中产生的流转关系，同样属于财产关系的范畴。

### 财产关系的三个特征

接下来还是要了解财产关系的特征。它也是个理论问题，还是要从**三要素**的角度来进行描述。

#### 主体：地位具有平等性

因为它也是民法调整的对象，所以说主体地位具有**平等性**。

#### 客体：财产利益，是"身外之物"

客体是**财产利益**。那这个财产利益能跟人身利益相比，它就属于**身外之物**了，是可以按照当事人的意思来进行流转的，所以要**保障当事人的自由**。

这里可以跟前面的人身利益对照着看：人身利益跟主体不可分离，所以法律不允许你转让人身利益；但是财产利益因为是身外之物，所以法律保障当事人的**意思自治**——你想要转让的话，法律也尊重你。你买房法律尊重你，卖房法律也尊重，强调的是**意思表示的自由**。

#### 内容：归属加流转，且原则上有偿

内容这一层，一方面它既包括归属关系（通过物权制度来实现），也包括流转关系（从动态角度来描述，主要通过债权制度来实现），都属于财产关系的范畴。

同时呢，民法所调整的财产关系，**原则上具有有偿性的特点**。为什么说原则上有偿？因为这个市场交往常常体现为财产关系，而这个市场交易行为呢，常常是体现一个等价有偿的关系。

> **提示**：原则上有偿，例外的时候也可以无偿。比如民法当中有一种合同叫**赠与合同**；有些热心的人士给公益基金进行捐助——你看这是一个无偿的行为，只要是你自己决定的，那法律呢也会予以尊重。

我记得前两天网上有一个报道，李亚鹏和王菲发起设立的**嫣然天使儿童医院**，在经营中呢遭遇了一些困惑——付不起租金了。那广大的网友呢，纷纷慷慨解囊，给这个医院来捐钱。你看这个行为呢，他是无偿的，但是只要是当事人自愿实施的，那法律就是保障的。所以呢，虽然原则上有偿，但是也允许例外存在。

### 两类关系放在一起看

最后我们把这一节收一下。民法的调整对象相对来讲比较简单，主要是**从理论层面**来了解人身关系、财产关系的**含义和特征**——它们其实都是从**三要素（主体、客体、内容）**的角度来展开的。放在一起对照，差别其实很清楚：

| 三要素 | 人身关系 | 财产关系 |
| --- | --- | --- |
| 主体 | 平等性 | 地位具有平等性 |
| 客体 | 人身利益（人格利益、身份利益），与人身**不可分离**，专属性强，不能转让、放弃、继承 | 财产利益，属**身外之物**，可按当事人意思流转 |
| 内容 | **没有直接**的财产内容，财产利益处于**附属**地位，但与人身有交叉 | 归属关系（物权制度，静态）＋流转关系（债权制度，动态） |
| 价值取向 | 强调人文关怀、以人为本 | **原则上等价有偿**，但允许自愿无偿的例外 |

记住"人身利益不可处分、财产利益意思自治"这一组对照，两类关系的边界就再也不会混了。

## 民法基本原则：两条价值观统领下的八项原则
> 对应块：BLK06 | 覆盖分集：P07 | 块标题（分集名）：《第01编 第01章 第03节：民法的基本原则》

接着往下讲第三节。这一节说的是民法这个部门法所追求、所保障的重要价值。从考试角度看，这一节的分量不轻——主观题经常考到，法学的论述题已经考过好几次了。

所以这一节我们不能只求"背下来"，得能讲出道理。

### 什么是基本原则

#### 概念：两个"贯穿"

民法基本原则，体现为一种基本准则，是根本性的、原则性的问题。那什么样的东西才算得上"根本准则"？得同时满足两个"贯穿"。

第一个贯穿是纵向的：**效力贯穿始终**。一场民事活动，事前、事中、事后，每一个阶段都要体现出民法的基本原则。

第二个贯穿是横向的：对民事立法、民事司法和民事主体的行为，都具有普遍指导意义。注意，这三个对象一个都不能少——它不仅可以指导立法机关，还可以指导司法机关，也可以指导民事主体的行为。

```text
纵向：效力贯穿始终
  民事活动 ····· 事前 ──▶ 事中 ──▶ 事后
                    每个阶段都适用基本原则

横向：普遍指导意义
  民事立法 ····· 指导立法机关
  民事司法 ····· 指导司法机关
  民事主体行为 ·· 指导当事人怎么做
```

两个贯穿同时满足，才叫民法的基本原则。

#### 功能：指导、约束、补充

这是一个纯理论的问题，教材里用了三个词来描述：指导、约束、补充。这三个词其实可以按一条时间线索来理解，而且指导、约束、补充的对象都既包括立法，也包括司法，还包括民事主体的行为。

| 时点 | 功能 | 落点 |
| --- | --- | --- |
| 事前 | 指导 | 立法、司法、民事主体行为，三端都照着它做 |
| 事中 | 约束 | 已经定下来的事，谁都不能甩开 |
| 事后 | 补充 | 立法和约定没覆盖到的地方，由它兜底 |

**指导功能**，以自愿原则为例。民法典里有一项基本原则叫自愿原则，它可以指导立法、指导当事人的行为，也可以指导法院来审理案件。立法这一层怎么体现？民法典制定的时候，立法机关就要想到：自愿原则是民法基本原则之一，那我在设置规范的时候，就必须想到要尊重当事人意思自治。可法条里怎么写出来呢？只能写成"但是当事人另有约定的除外"。这就是立法机关接受指导而产生的结果。

**约束功能**，约束立法、约束司法、约束民事主体的行为。还是自愿原则，它意味着法院在审理一起合同时，首先要看当事人有没有相应的约定；如果有约定，那就只能基于当时的约定来确定双方的权利义务，而不能脱离约定去按照法律规定作判决。你看，这体现的就是对法官的一种约束。

**补充功能**，可以补充立法的不足，也可以补充当事人约定的不足。比如有些合同，有的事项作出了约定，有的没有作出约定。假设没有作出约定的事项不影响合同成立，那这个事项怎么履行？按照法律规定，首先让当事人来补充协议——没谈上的，你们接着去谈。你看，没谈上的接着去谈，就同时体现了自愿。所以三个功能是一体的：事前指导、事中约束、事后补充。

> **结论**：指导、约束、补充三个功能，对象都是立法、司法与民事主体行为这三端，不是各管一段、各管一端。

### 八项基本原则的逻辑骨架

民法典里规定了七项基本原则，我们的官方教材又增加了一项禁止权利滥用，加起来是八项。那这八项是按照什么思路展开的？这里给大家做一个简单的梳理。

在制定民法典的时候，要重点关注两种价值的冲突和平衡。

一种是**保障当事人的意思自治**。因为民法是私法，所以法律要保障当事人的意思自治，让当事人自己来做决定。

另一方面也体现**国家的强制**——不能由着当事人来，国家也有自己的态度，国家也要体现一些强制。

这两种价值都会投射到民法的基本原则中。

落实意思自治这一侧有三项：自愿直接保障当事人的意思自治；平等是自愿的基础、是前提——只有认可双方是平等的主体，才能实现真正的意思自治，假如一方的法律地位明显高于另一方，法律说"保障另一方的意思自治"，那就是虚伪的；公平是对自愿的补充——尽管表面上看当时是自愿的，但实质上并不代表当时的真实意思，就要通过公平原则来进行补充。

体现国家强制这一侧有五项：诚信要求当事人在实现自己利益的时候也不能损害别人的利益，你得厚道；合法意味着你只能在法律允许的范围内进行意思自治，不能违反强制性的规定；公序良俗比如一方把财产赠与给了婚外的情人，尽管自己是心甘情愿的，但这样的赠与没有社会底线，是突破公序良俗的，那就是法律所不允许的；绿色要求从事民事活动的时候要注意节约资源、不能污染环境；禁止权利滥用则是尽管法律赋予你某项权利、你有行使权利的自由，但你不能滥用权利去损害他人的合法权益。

```text
意思自治（民法是私法，当事人自己决定）
  自愿            —— 保障意思自治本身
  平等            —— 意思自治的基础与前提
  公平            —— 自愿的必要补充

国家强制（国家也有自己的态度，不能由着当事人来）
  诚信            —— 实现自己利益时不得损害他人
  合法            —— 不得违反法律的禁止性规定
  公序良俗        —— 守住国家与社会的底线
  绿色            —— 节约资源、保护生态环境
  禁止权利滥用    —— 不得滥用权利损害他人合法权益
```

大家大致有这么个印象就行。接下来进入具体的基本原则内容。每一项基本原则，大家重点掌握两个问题：第一是它的含义，第二是它的具体体现。前面不是提到基本原则要效力贯穿始终、要具有普遍指导意义吗？那它必然要有所体现。

### 平等原则

#### 含义：抓住两个关键词

平等原则的概念规定在《民法典》第四条：民事主体在民事活动中法律地位一律平等。

平等讲的是要一视同仁——在民法里面，不能对不同的主体进行区别对待。所以平等常常是从主体角度来描述的。理解民法中的平等，要强调两个关键词。

**第一个关键词是"民事活动"。** 注意第四条里这个词。比如大家未来研究生毕业以后会考公务员，在国家机关里面，干部会有不同的级别，科级、处级，不同级别的领导干部可以享受的办公面积、住房面积，包括报销差旅费的标准都是不一样的。能不能说这样的制度违反了平等原则？不能。因为国家机关给领导干部提供住房、提供办公场所、提供差旅费的报销服务，它并不是民事活动，所以跟民法里面讲的平等原则是无关的。你不能说出差"凭什么领导能坐商务座、一等座，而我只能坐二等座"——这个跟民法里面的平等是没有关系的。你自费的话当然可以做商务座，只是说行政机关在给你报销的时候只给你报销二等座，这个部分它并不是一个民事法律关系的问题。

**第二个关键词是"法律地位"。** 民法只能保障法律地位的平等，而不能确保双方市场地位的平等。比如我为了追剧充了一个腾讯视频的会员，这样我和腾讯视频之间会有一个服务合同关系。双方当时的法律地位是平等的，但我们双方的市场地位平不平等？当然不平等——腾讯多有钱啊，我才几个钱。可是我们的法律地位是平等的：虽然我只是一个普通的消费者，但是腾讯你作为合同的相对方，你得尊重我在合同中的各项权利。

> **易错点**：平等不等于市场地位的平等。市场地位可以悬殊，法律地位必须平等；抓住"民事活动"和"法律地位"这两个关键词，《民法典》第四条才算读懂。

#### 体现：事前、事中、事后

平等原则在民法里怎么体现？他也是要效力贯穿始终的，包括四个方面：民事权利能力一律平等、法律地位平等、平等协商、平等保护。理解这四方面要记一条时间线索：参与一个民事活动，自始至终双方都是平等的。

```text
  事前 ── 有没有资格来参与
        ① 民事权利能力一律平等

  事中 ── 进场交易，权利义务怎么定
        ② 法律地位平等（平起平坐，不能你坐着我站着）
        ③ 平等协商（不能把自己的意志强加到对方头上）

  事后 ── 受到损害以后怎么救济
        ④ 平等保护
```

第一个层次是**事前**。在参与民事活动之前，先要确定有没有资格来参与，这是民事权利能力解决的问题。双方当事人参与这个法律活动的资格都是平等的。

第二个层次是**事中**。你有资格参与交易了，那进场交易的时候也要平等。首先是双方的法律地位平等，参与交易的时候要平起平坐，不能说你坐着我站着。接着是平等协商，在参与这个交易的时候双方要平等协商，你不能把自己的意志强加到对方的头上，要尊重对方的决定。

第三个层次是**事后**。参与民事活动以后受到损害了，在主张救济的时候也要平等，体现的是保护的平等。是不是平等的观念要贯穿始终——从事前到事中到事后，都得落实"平等"这两个字。

#### 拓展：形式平等与实质平等

掌握上面两个基本问题以后，再补充一个理论拓展问题。这个理论思想问题更多是法学同学需要特别关注，因为基本原则特别考论述题，对于论述题来讲，你的认识就要比普通简答题更深入一些。

**第一个方面是平等原则的意义。** 平等是民事法律关系的本质特征，它反映的是市场经济的本质特点。我们在前面讲民法概念的时候，就讲到了"平等"两个字——它就是民事法律关系跟其他法律关系的一个本质区别。落实到部门法层面，就意味着"平等"这两个字反映的是民法跟其他法律之间一个比较重大的区别。

**第二个方面是平等原则的发展：形式上平等与实质上平等的关系。**

我们前面讲的平等更多的是形式上的平等，就是一视同仁、不做区别对待。但在实践当中，双方实质的力量是有差异的；如果你一味支持一视同仁，那就不能实现真正意义上的平起平坐。所以这时候法律要对弱势的一方给予倾向性的保护，这样才能实现实质的、真正的平等。

《民法典》第128条：法律对未成年人、老年人、残疾人、妇女、消费者等民事权利有特别保护规定的，依照其规定。这个条文里提到的这些人，虽然也属于民事主体的范围，但是在相关的民事活动中处于一个相对弱势的地位，那法律就要对他们进行倾向性的保护，适当地扶他们一把，才能实现跟对方的真正平等。

所以，对这一方进行倾向性的保护，有没有违反平等原则？没有的，相反它是真正意义上的平等的实现。

> **结论**：在民法里面，一方面坚持形式上的平等，另一方面也不能放弃实质上的平等。对弱势群体进行倾向性保护的制度，体现的正是实质平等的观念——这在我们的学习中也经常成为考试内容。

比如法学的同学有一年就考过一道论述题，论《民法典》总则编对未成年人予以特别保护的相关规定，这是一道15分的论述题，考的就是实质平等观在《民法典》中的体现；还有一年考婚姻家庭编当中注重家风家教的相关规定。在婚姻家庭领域、在继承制度里，对妇女、对未成年人、对生存没有保障的弱势群体给予倾向性的保护，实质上也是在实现真正意义上的平等——它是一个实质的平等观。

### 自愿原则

#### 含义：自愿就是意思自治

《民法典》第五条：民事主体从事民事活动应当遵循自愿原则，按照自己的意思设立、变更、终止民事法律关系。

通俗地讲就是"我的地盘由我来做主"，体现的就是自愿的价值观。包括《哪吒》里有句台词叫"我命由我不由天"，体现的也是自愿或者自由的价值观。

在教材里我给大家写了一句话：**自愿原则又称意思自治原则**，注意这个说法。因为自愿体现的是保障当事人自由的价值观，但从文字的使用上来看，自愿跟自由极差，不能完全划等号。自由强调的是一种完全的自主决定，是可以排除他人不当干涉的——通俗地讲，是可以勇敢地说"不"的，就是 say NO，这叫自由。而自愿常常只是表现一种没有被强迫的状态，他不一定有说不的底气或者资格。

比如去年有一部非常好看的电视剧叫《藏海传》，里面有个情节：修建皇陵的工匠，在把皇陵修完以后要"自愿"殉葬。你看"自愿"这个词用得就非常传神——一方面没有强迫你，但是另一方面，这些工匠能不能说不？"我不想殉葬，行不行？"那也是不行的。所以他没有达到这种自由的状态。

生活当中也是：有些员工每天要"自愿加班"，老板呢虽然没强迫，但是你也不敢不加班，那就不是真正的自由；小学的学生每天都是"自愿"完成课后作业，老师没强迫，但是你也不敢说我不完成，因为第二天要讨论检查。

所以这个自愿跟自由还不太一样。但是毕竟从1986年的《民法通则》开始，我们在法律里面用的就是"自愿"这两个字，所以民法典依然保留了这个说法，只是在解释的时候特别强调：这个自愿指的就是意思自治原则，它要保证的是当事人的自由。

> **提示**：解释《民法典》里的"自愿"两个字，其实就要结合前面讲过的历史解释方式，不能光从字面上去理解。立法机关使用"自愿"这两个字，表达的就是保障当事人自由的价值观。

我们的考试分析里面也特别写了"自愿原则又称意思自治原则"。答主观题的时候，你光答"自愿"这两个字好像看起来没什么水平，但是把"意思自治"这四个字写出来了，那你的水平就高了啊，一看就是研究生。

教材里我写了一个小案例，让大家感受这个自愿原则其实很好理解。

**案例一：凶宅拍卖。** 大家学刑法的时候，老师可能也会讲到发生在南京的那个惨案：在一套别墅内，房主父女两人把女婿给杀害了，而且还将其肢解了，非常的残忍。那这样的行为就使得这套别墅变成了凶宅。后来由于房主欠了别人钱没还，要拍卖这个别墅。拍卖的时候做了一个市场估价，大概值1236万元，但是起拍价只有435万元，因为凶宅常常会影响交易的价格。本来大家想这样的房子谁敢买，没想到竞拍的过程非常激烈，一共经历了93轮的加价，最终某个买主以786万的价格买下了这套别墅。

尽管在别人看来，花786万买个凶宅简直是疯了，但是从民法角度来讲，只要当时自己是愿意的，那法律就要予以尊重。

**案例二：82岁与28岁。** 去年一位伟大的物理学家杨振宁先生离开了我们。杨振宁先生是在82岁的时候和28岁的翁帆结婚，当时好多人说"你们俩不太般配"。但从民法的角度来讲，只要双方当时是自愿的，你未娶我未嫁，那这个婚姻自由就要受到法律的保障。

这就是民法保障当事人意思自治的价值观——人家的事情让人家自己去做主。这是自愿原则的基本含义。

#### 体现：自主、协商、负责

自愿原则的具体体现也是效力贯穿始终，包括三个方面。

第一，民事主体可以自主决定是否参与民事活动以及如何参与。比如说你去逛商场，到底要不要买衣服、在哪家买、买哪一件，都是你自己说了算。

第二，民事主体要以平等协商的方式来从事民事活动。比如进行交易的时候，你想买这件衣服，人家不想卖，特别是以你的报价人家不想卖，你能不能强迫？不能。你是意思自治的，你也得尊重别人的意思自治。

第三，在法律允许的范围内，当事人依据其意愿做出决定以后，要对自己自由表达的真实意思而负责任。注意，"负责"也是自愿原则的一个体现。有人说"合同我随便签"，签完以后我不履行，那这个也不是意思自治——这里面包含着你得为自己的行为负责任的观点。包括男女在要不要结婚的时候，你是有完全的自主决定权的，但是结了婚以后，你能不能说"我想离就离"呀？那也不行。你得为自己的行为负责，得尽到婚姻关系当中当时的义务。

```text
  事前 ── 自主决定是否参与、如何参与
  事中 ── 与对方平等协商，尊重别人的决定权
  事后 ── 为自己真实表达的意思负责
          签的合同你得履行，结了婚你得负责
```

> **易错点**：自愿不是"想干什么就干什么"。它有两层边界——一层是必须在法律允许的范围内，另一层是做了决定就得为它负责。

#### 拓展：它在八项原则中的位置

这个理论拓展还是法学同学要特别关注的，有可能成为论述题的内容：自愿原则和其他基本原则的关系。

这个关系我们在前面讲民法基本原则逻辑体系的时候其实已经介绍过了：在基本原则体系当中，自愿原则处于一个最核心的地位；平等是它的基础或者前提；公平是对它的补充；而剩下的五项基本原则——诚信、合法、公序良俗、绿色、禁止权利滥用——都体现的是对意思自治的限制。这就是它们之间的关系。

### 公平原则

#### 含义：合理确定权利义务

公平原则的概念规定在《民法典》第六条：民事主体从事民事活动应当遵循公平原则，合理确定各方的权利和义务。核心词就是"合理确定"，强调一个收益和风险相一致。

前两年有部剧非常火，叫《狂飙》，里面高启强有一句名言叫"风浪越大，鱼越贵"——体现的就是公平的理念。我冒的风险越高，那我的预期收益当然也会更高了。

我们来看一个小例子，案例来自于去年的一部电视剧，叫《生万物》，是杨幂演的。宁学强的女儿宁秀秀在结婚当天被土匪给绑架了，被索要5000大洋的赎金。尽管宁学强还是有点钱的，但一下子拿出5000大洋来，压力还是山大的。

同村的风儿觉得宁学强一定会卖地去救自己的女儿，于是他上门要趁机以低价来购买宁学强位于村西古路井旁的那十亩地。这块地是块好地，风儿比较抠门，但是作为一个种地的好手，哪块地好、哪块地不好他是门清的；当然电视剧里的宁学强更抠门，他都不愿意卖地去救女儿。

假如这个宁学强愿意卖地去救女儿，他无奈和风儿签订了合同——毕竟你现在差钱嘛。尽管表面上合同上签了字，但是心里面不是那么愿意，甚至有可能在心里会骂娘。那么，假设把这个地卖了、把女儿救回来了，能不能显示公平，撤销合同，把这个地追回来？

我们站在现代法律角度来看，答案是可以的。因为这个宁学强的女儿被绑架了，是不是处于一个危困状态？急缺钱。而这个时候风儿趁机低价买别人的好地，是不是双方的权利义务是不平衡的？违反了公平原则。所以法律上设置显失公平制度，来给宁学强提供救济。这就是民法里面的公平原则。

#### 体现：民事主体与司法机关

教材里写了两点：一是民事主体从事民事活动的时候，要本着公平的理念来参与民事活动；二是司法机关在处理民事纠纷的时候，也要本着公平的理念来解决纠纷。

这两点事实上是一个横向的贯穿：民事主体要体现公平原则，司法机关要体现公平原则。那大家深度了解一下，它落了哪一个呀？立法机关是不是也得体现公平原则？

**民事主体体现公平理念**，在民法里面要讲一个制度叫格式条款，也就是一方来提供条款，另一方只能选择同意或者不同意。比如我们去银行办业务，都是银行把这个业务单给你拿出来，跟你说"这个地方签字"。你能不能说"我刚刚学了法律，我来看看你们这个合同条款公不公平"？对方会跟你说：你要办就办，不办就赶紧走人，后面还有很多人排队呢。你看这种缔约方式，就是一方提供全部的条款，对方只能选择同意或者不同意。

那法律要求，提供格式条款的一方在拟定条款的时候，就不能光想着自己，不能把利益都分配给自己、把风险都让对方来承担——那就是法律要给受损的一方提供救济的。

**司法机关体现公平**，大家可以了解一个例子，叫做情势变更，我们在合同编都会讲这个制度。比如甲开一家饭店，和房东签订了租赁合同，约定了合同租期，然后装修好了，饭店刚刚打算要大干一场的时候，新冠疫情来了，政府不让开门营业。假设还是按照原来的租金标准来支付租金的话，是不是对甲来讲压力有点太大了呀？所以他请求人民法院基于情势变更来变更这个租金。这样可以公平地分配，因为疫情所带来的这个当事人无法预见的风险。你看，法院在以情势变更为由变更租金及支付方式的时候，就是在落实公平原则。

#### 拓展：为什么是"必要补充"

**首先是公平原则的意义。** 公平原则在民法里面有什么用？它是市场经济活动中公平交易和公平竞争的道德准则法律化的一个体现。特别是在财产法律关系中、在交易当中，要秉持公平交易和公平竞争的观念，那在法律上就要通过公平原则来进行落实。这就是它存在的价值。

**第二个问题，也是更容易被问到的：这个公平原则怎么来适用？** 能不能说双方的结构失衡了，就启动公平原则来调整这个权利关系？**是不能的。** 注意它只是自愿原则的**必要补充**，注意"必要补充"这个词。什么意思呢？就是在适用的时候，自愿原则是主力，公平原则呢，你是替补，还是替补的——意思就是自愿原则的实现遇到障碍的时候，才能够启动公平原则。

这就意味着：如果是当事人自愿签订的合同，即使双方的权利失衡了，能不能主张公平原则来救济？答案是不可以。

举个例子。实践当中有些门店会挂一个牌子叫"假一罚十"，大家听过吧，特别是烟酒专卖店容易出现这个牌子，因为这个行业假货太多了。假设某个消费者一看，这家挂着假一罚十的牌子，想必对自己的产品品质是有信心的，于是买了三瓶茅台；后来经鉴定发现都是假的，要求商家赔偿十倍。商家能不能说"太欺负人了，你这我能卖给你一个假货，你让我赔十倍，还让不让人做生意了"？

这个时候商家能不能说"假一罚十"的条款违反公平原则？答案是不可以。因为"假一罚十"是商家自己主动做出的承诺，是自己自愿做出的，也就是说你自己打肿脸来充胖子，那法律就要把你当成胖子来对待，你不能主张显失公平来撤销这个合同。

就像前面提到的《生万物》里宁学强那种情形：处于一个危困状态、别无选择的时候被别人给利用了。尽管当时宁学强在合同上签了字，但是他可能并不愿意，甚至心里面还在骂娘——那这个时候法律才会启动公平原则来进行补充。

> **结论**：自愿实现了，就没有必要让公平来补充。公平原则是自愿原则的必要补充，而不是可以随时启动的第二原则。

### 诚信原则

#### 含义：厚道

《民法典》第七条：民事主体从事民事活动应当遵循诚信原则，秉持诚实，恪守承诺。注意这八个字——"秉持诚实，恪守承诺"是民法典里文采最好的八个字。通俗地讲，诚信就是做人你得厚道，不能把你的幸福建立在别人的痛苦之上。

教材里写了一个小案例，帮大家理解这个原则，这种案例叫做**价格刺客**的案例，是侵犯消费者合法权益的典型案例中的一种类型。

某个同学去超市买根雪糕吃，因为天太热，冰柜里面放着各种各样的雪糕，然而这个同学就在其中选了一支跟自己更有眼缘、看起来更顺眼的雪糕去结账。结账的时候老板说："你的眼光太好了，满冰柜的雪糕都是五块钱，就你选的这一种是30块钱的高级雪糕。"

你会觉得这是在夸你吗？这个时候这个同学可能会很郁闷或者很尴尬。因为你要把这个雪糕的价格明码标出来，我不一定选这个；但现在我已经结账了，你告诉我这个雪糕30块钱。一方面如果换一个五块钱的雪糕，好像显得我不配吃30块钱的贵族雪糕、只配吃五块钱的雪糕，面子上感觉过不去；但同时如果咬牙买下来的话，虽然那30块钱也能吃得起，但是就是很不爽——一方面是吃雪糕没必要花30块，另一方面是感觉被背刺了，就是被别人给套路了。

你看这种情况下，这个商家他就是违反诚信原则的，他摆了个心眼，不太厚道。这就是价格刺客。这种案件没有明码标价，是不是不够秉持诚实？是不是把自己的幸福建立在别人的不爽之上？

#### 体现：如实告知、重合同守信用、防止损失扩大

第一，实施民事法律行为的时候，要将有关事项和真实情况如实告知对方。就像价格刺客这个案件中，这个雪糕到底值多少钱，你要明码标价出来，让消费者能够自由进行选择。有的人一看"哎这个雪糕30块钱，什么雪糕这么值钱啊"，非得吃一吃感受一下，那这是消费者自己做的决定；你不说、我以为这个雪糕平平无奇、也就五六块钱的样子，结果结账的时候你跟我说这只雪糕很高贵——这就是没有及时告知相关的情况，是违反诚信原则的。

第二，在交易当中要重合同、守信用，要正当行使权利、履行义务。"重合同、守信用"就是诚信的体现，要恪守承诺，不能签订合同以后老是这山望着那山高，老是想着通过违约的方式再抬高价格——这就是不诚信的表现。

第三，民事活动中受到损害了，当事人应当采取合理的措施来防止或者避免损失的发生。你不能说，因为对方的违约造成了你的损失，你固然可以请对方来赔偿，但是你也不能直接选择摆烂，因为你摆烂的后果都让对方来承担，那这个就不太厚道了。所以你要采取必要的措施，防止损失的发生过大。你没有采取措施就是不诚信的，那么损失扩大的部分你就没有资格主张赔偿了，法律要惩罚你的。

当然了，大家也可以用时间线索来做一个梳理，同样是以一个民事活动作为线索，它的事前、事中、事后都可以体现诚信。

```text
  事前 ── 如实告知重要事实（雪糕得明码标价）
  事中 ── 重合同、守信用，说话算话
  事后 ── 采取合理措施防止损失扩大（不真正义务）
```

我们在合同编会讲到"采取这个措施的义务"，我们叫**不真正义务**。你没尽到这个义务、不厚道，那损失扩大的部分你就没有资格主张赔偿了。

#### 拓展：为什么被称为"帝王条款"

诚信原则在民法里面有什么用？它是市场经济活动中基本道德准则的法律化。在商业交往当中，特别是在做生意的时候，诚信是一项非常重要的品质，以诚为本。

同时，诚信原则是现代民法的**帝王条款**。这个词语听起来有点邪乎，但是它是民法学当中经常用的一个表述：诚信原则是民法当中的帝王条款。但这个"帝王条款"不是说它效力最高，而是说它的适用范围非常广泛——普天之下莫非王土嘛。你看一个交易，从事前到事中到事后都有诚信原则适用的余地，特别是在合同领域。

### 合法原则

#### 含义："应当遵守"与"不得违反"的底层逻辑

《民法典》第八条前段：民事主体从事民事活动不得违反法律，也就是只能是在法律允许的范围内进行意思自治。

这里要给大家强调一个问题：在之前的《民法通则》里也有合法原则，但原来的说法是"民事主体从事民事活动**应当遵守法律**"。民法典把它改成了"民事主体从事民事活动**不得违反法律**"。

大家看这两个说法有没有区别？听上去好像都差不多。其实它们所表达的意思虽然很相像，但是它们的底层逻辑是不一样的。

> **提示**："应当遵守法律"是**白名单**的规范方式——你得符合法律的要求；"不得违反法律"是**黑名单**的规范方式——只要没有踩雷，那我就是允许的。

既然民法是私法，要保障当事人的意思自治，那就要坚持"法无禁止即自由"的原则：我只要没有违反法律的禁止规定，那我就是意思自治的范围。所以民法典这个说法其实更符合民法的精神，更能够保障当事人的意思自治。特别是民法里面有好多规定是任意性规范，你不用去遵守这个法律，甚至可以通过特别的约定来排除这个任意性规范的使用——从这个角度说，"不得违反法律"这个禁止性的规定可能是更加严谨的说法。

#### 体现：权利受限与行为效力

第一，民事主体在行使权利的时候要受到国家法律的限制。也就是说，法律赋予你的权利，你在行使的时候也不是可以随心所欲地行使的。比如国家对城市的土地是享有所有权的，按道理所有权包含着占有、使用、收益、处分完整的权能，但是国家能不能把城市的土地卖给私人呀？这个是不可以的，也是违反《土地管理法》规定的。这就是行使权利要受到国家法律的必要限制，只能在法律允许的范围内实现意思自治。

第二，当事人的民事法律行为如果违反法律、行政法规的强制性规定的，应当认定是无效的。比如买卖枪支的交易，违反了《枪支管理法》的强制性规定，是无效的。

### 公序良俗原则

这一项需要大家重点关注了，因为"公序良俗"这个词听起来就很法言法语。

#### 含义：公序与良俗的拆解

《民法典》第八条后段：民事主体从事民事活动不得违背公序良俗。

公序良俗是"公共秩序"和"善良风俗"的合成，所以先给他做一个关键词拆解：**公序**指的是公共秩序，是从国家角度来定义的；**良俗**指的是善良风俗，是从社会层面来定义的。

```text
公序良俗
├── 公共秩序（从国家角度定义）
│   ├── 政治的公序
│   │   ├── 保护国家的公序 —— 危害国家安全，如间谍交易
│   │   └── 保护家庭的公序 —— 违反一夫一妻原则，如"拉帮套"协议
│   └── 经济的公序
│       ├── 指导的公序 —— 反不正当竞争法、反垄断法，维护竞争秩序
│       └── 保护的公序 —— 劳动法、消费者权益保护，劳动者与消费者的权益
└── 善良风俗（从社会层面定义）
    └─ 一国或一地区占主导地位的一般道德观念与伦理要求
       —— 社会的底线：可以不要脸，法律还是要脸的
```

**保护国家的公序**，保护的是国家安全。你像间谍行为，把情报卖给外国，那就危害了国家安全，这样的交易是违反公序良俗的，是无效的。

**保护家庭的公序**，有国有家。比如前面讲到的一种民间习俗叫"拉帮套"，假设现在有人自愿地拉帮套，双方还签订了协议，这样的协议效力如何？无效。因为它违反了一夫一妻原则，会破坏家庭领域的公共秩序。

**指导的公序**，体现的是国家对于经济发展的一种指导、一种宏观调控。比如《反不正当竞争法》是在维护正当的竞争秩序，《反垄断法》也是。

**保护的公序**，比如保护劳动者的合法权益、保护消费者的合法权益。员工在入职的时候"自愿"签订了放弃五险一金的协议，尽管双方是自愿的，但是法律不认可，因为它违反了《劳动法》的相关规定；包括"自愿"的996、007，都是违反这个保护的公序的。

**善良风俗**主要是从社会层面来定义的，它指的是一国或者一地区占主导地位的一般道德观念和伦理要求。注意"一般"这两个字，它其实体现的是一个社会的底线：虽然法律保障当事人的自由，但是你也不能太没有底线了——你可以不要脸，但是法律还是要脸的。所以善良风俗就是守住这个一般的道德观念和伦理要求。像卖淫嫖娼，尽管双方当时你情我愿、各取所需，但是这个交易是突破了社会的底线的，法律认为你们也太不要脸了，这样的交易我法律是不认可的，因为它违反了公序良俗。

**案例：公序良俗第一案——"二奶继承案"。** 这个案例发生在1963年前后，年代也挺久远了，但是它是具有开创意义的，所以大家还是要有所了解。

蒋某与黄某在1963年登记结婚，本来感情很好，但是在1996年的时候，黄某有了外遇，就和情人张某在外面租房非法同居。后来黄某查出患了癌症，在她生命的最后一段时间，这个情人还是有情有义，一直陪伴黄某离开人世。但黄某也觉得找的这个情人很靠谱，于是她立下了一纸遗嘱，要把自己的遗产全部留给这个情人，然后就去世了。

后来这个情人拿着这份遗嘱，要求原配转移财产，原配当然不答应了，还把她轰出去了。后来这个情妇就向法院提起诉讼，要求法院判决这个遗产归自己——这就是民法里面赫赫有名的"二奶继承案"。

法院在审理这个案件的时候，首先要确认黄某留下的这一纸遗嘱，也就是把遗产留给这个情人这个行为，到底有效无效？尽管相信这是黄某真实的意思表示，但是你把财产留给情人，是不是也太没有道德底线了？违反了公序良俗。所以法院认定这个遗嘱是无效的，也就是情人不能凭这个遗嘱来取得遗产。

这样的案件其实在实践中原来还是有些争议的，有些人觉得还是要保障当事人意思自治的。但是婚姻家庭编的解释二里面，专门就这类案件做出了明确规定：一方当事人把财产赠与婚外的第三人、破坏家庭关系的，或者说为了维持非法同居关系的，这样的行为应当认定是无效的。也就是在这类案件的审理时，也得考虑核心价值观、得考虑社会风尚——这种没有底线的行为，法律当然不予保护了。

#### 体现：两类违法行为清单

教材里专门写了违反公序良俗的具体行为，这部分可以跟我们前面讲到的公序良俗的展开内容关联起来看。

| 层次 | 具体行为 | 破坏的是 |
| --- | --- | --- |
| 违反公序 | 危害国家公序 | 保护国家的公序 |
| 违反公序 | 危害家庭关系 | 保护家庭的公序 |
| 违反公序 | 限制营业自由 | 指导的公序 |
| 违反公序 | 违反竞争秩序 | 指导的公序 |
| 违反公序 | 侵犯消费者与劳动者保护 | 保护的公序 |
| 违反良俗 | 违反两性道德（卖淫嫖娼） | 善良风俗 |
| 违反良俗 | 赌射幸行为 | 善良风俗 |
| 违反良俗 | 侵犯人格尊严（"赌"与"毒"） | 善良风俗 |
| 违反良俗 | 暴利行为（高利贷） | 善良风俗 |

限制营业自由、违反竞争秩序这两项，是跟指导的公序相关的。建构一个公平、合理、自由的竞争秩序，那是国家宏观调控里面非常重要的一个任务。而侵犯消费者与劳动者保护的行为，破坏的是保护的公序，这个比较好理解。

这里有两个专业术语要辨析，因为它们是民法里关于民事法律行为性质的分类：

| 概念 | 成立时权利义务的状态 | 例子 |
| --- | --- | --- |
| 射定行为 | 双方的权利已经确定 | 买卖合同 |
| 射幸行为 | 一方的权利义务取决于一个偶然事件 | 保险合同 |

保险合同就是典型的射幸合同。你买了车以后，每年都得给这个车投保交强险，甚至还要求投保商业险；你跟那个保险公司签订合同以后，你的义务是确定的——你要缴这个保险费；但是保险公司有没有义务，主要取决于有没有发生约定的保险事故。假设车开了一年、平安驾驶、没有发生过任何事故，那这个保险公司就拿了你这个钱，它对你就没有义务了。但是假如发生了交通事故，尽管你只交了2000块钱的保险费，它闯的祸可能得50万，只要是在保险金额的范围内，那保险公司都得赔偿——可能不用出钱，也有可能出很多钱，这叫射幸行为。

但保险呢是法律所允许的，它是合法的。而赌博这种射幸行为，他就是违反公序良俗的了。因为如果大家都不好好工作，都去赌博，那这个不劳而获之风会蔓延，会影响整个社会创造财富的积极性，所以它是无效的。

侵犯人格尊严的行为，你可以理解为是"赌"和"毒"——你看这个买卖人吸了毒以后就不成样子了，没有尊严了。最后还能加上一个暴利行为，这个大家可以记个例子，叫做**高利贷**：把钱借给别人、让他收取高额的利息，这叫暴利行为，也是违反公序良俗的。

#### 拓展：守住国家和社会的底线

公序良俗原则在民法里面有什么用？它是要维护国家的一般利益和一般道德观念的，就要守住这个国家和社会的底线——这就是公序良俗存在的价值。所以实践当中，违反公序良俗的行为常常是没有底线的行为。

### 绿色原则

绿色原则是我国《民法典》特别规定的基本原则，所以在考试里面容易考到，曾经两度在论述题里面考过绿色原则。

《民法典》第九条：民事主体从事民事活动应当有利于节约资源、保护生态环境。其实就是对民事主体行为自由的一种限制。

我记得上小学的时候常常讲一个理想：等我有钱了，买两杯牛奶，我喝一杯，然后倒一杯；或者等我有钱了，我买两辆汽车，一辆奔驰、一辆宝马，奔驰拖着宝马开。你看这样的想法，其实体现的是你对自己所有权的一种完全的支配。但是你的牛奶喝一杯倒一杯，是不是浪费资源？不够绿色。所以民法说了：你要节约资源、保护生态环境，不要浪费。所以很多年前有所谓的"光盘行动"，讲的就是绿色原则。

绿色原则的意义和适用，我们通过理论拓展的方式给大家做一个补充。

首先是**代际正义**的要求，注意这个词——就是要给子孙后代留点优美的环境、留点资源，不要你这代人就把这个资源给用尽了。同时绿色原则也是**社会可持续发展**的要求，这个可持续发展大家学政治课的时候应该都会做展开的。

在法律上，绿色原则主要体现为**倡导性规范**，注意这个词，这是官方教材的原文。说白了就是鼓励你要遵循绿色原则——其实你不绿色，法律也不能把你怎么样。比如有同学去饭店吃饭，点了三个菜，后来发现这几个菜都像预制菜、很难吃，就不想吃了。服务员能不能说"这么多菜你没有光盘，你又违反绿色原则，你要承担法律责任"？当然不行了。因为绿色只是倡导性规范，鼓励大家绿色；你不绿色的话，事实上并没有法律责任。

### 禁止权利滥用原则

最后一项基本原则叫禁止权利滥用，这是我们考试分析里面特别增加的规定。《民法典》第一百三十二条：民事主体不得滥用民事权利损害国家利益、社会公共利益或者他人的合法权益。其实它本质上是诚信原则的一个体现——不能把你的幸福建立在别人的痛苦之上。

教材里给大家写了一个小案例，大家感受下什么叫做权利的滥用。

**案例：越界的宅基地。** 甲乙两家宅基地相邻，但是素来不和。乙在建造住房的时候不慎越界了，占用了甲的0.5米的宅基地。甲呢虽然发现了，但是没有予以制止，等乙的错误犯得更严重的时候他再去追究。

后来乙就把这个房子建完了，然后甲找到乙说："你盖的房子侵犯了我的宅基地使用权，我要求你把房子拆掉，把侵占的土地还给我。"

这个时候法院会不会支持甲的诉讼请求？第一，甲对于这块地他是有宅基地使用权的，乙呢实际上也确实是越界了——他把房子的一小部分建到了别人的宅基地上，构成侵权。关键是这个时侯，甲如果要求乙把房子拆掉、把这一小块宅基地还给自己，是不是损人利己、不怎么利己？甚至是自己虽然获得了利益，但是他非常小，但是会给对方造成巨大的损失。那你行使权利的方式，法律认为就不太厚道了，就是在滥用权利去损害别人的合法权益，那这个法律将不保护你——也就是甲不能请求乙来拆除这个房屋。

但是能不能请求乙赔偿损失呢？这个是可以的。这就是禁止权利滥用原则的基本体现。

#### 构成要件

教材里面写了民事权利滥用的构成要件，大家简单了解三个：第一，当事人要有权利存在——你首先得有权，然后你才有机会滥用，假设你连权利都没有的话，那就叫不上滥用民事权利了。像刚才这个案件里面，对于乙越界的这一块宅基地，人家甲确确实实有这个宅基地使用权。第二，权利人要有行使权利的行为——你得去行使权利，才有可能滥用。第三，这个行使权利行为具有违法性、不符合法律的精神，那这时候法律就不予保护了，这才叫民事权利的滥用。

### 本讲提到的题目

**论述题（曾考，15分）：论《民法典》总则编对未成年人予以特别保护的相关规定。**

解析方向：这道题考的是实质平等观在《民法典》中的体现。未成年人属于民事主体的范围，但在相关民事活动中处于相对弱势地位，法律对其民事权利有特别保护的，依《民法典》第128条依照其规定。这种倾向性保护有没有违反平等原则？没有，相反它是真正意义上的平等的实现。答题时应当把"形式平等—实质平等"这条线索立起来，再落到具体制度上，答案才立得住。

**论述题（曾考）：论《民法典》婚姻家庭编中注重家风家教的相关规定。**

解析方向：与上一题是同一条线索。在婚姻家庭领域、在继承制度里，对妇女、对未成年人、对生存没有保障的弱势群体给予倾向性的保护，实质上也是在实现真正意义上的平等，属于实质平等观的体现。

此外，绿色原则曾经两度在论述题里考到、绿色原则在我国《民法典》中的地位与适用，属于同一批被点名的论述题方向，但这里没有展开具体的题干，就不另行命题了。

## 一个中心：民事法律关系到底管到哪儿
> 对应块：BLK07 | 覆盖分集：P08 | 块标题（分集名）：《第01编 第02章 第01节：民事法律关系概述》

接下来我们看第二章，民事法律关系。

这一章讲的也是理论问题，要建构整个民法的理论逻辑，概括起来就是**一个中心，五个基本点**。

第一个中心，就是第一节要讲的民事法律关系概述。接下来依次展开五个基本点的基础理论：先是三要素——主体、客体加内容；然后是民事法律关系的保护，也就是民事责任的基础理论；最后是民事法律关系的变动，也就是民事法律事实的基础理论。

先看第一个问题，民事法律关系的概念和特征。

### 概念：能被民法装下的那类社会关系

> **定义**：民事法律关系，是指由民事法律规范所确立的、以民事权利和民事义务为内容的社会关系。

通俗地讲，凡是可以纳入民法调整的社会关系，都可以称之为民事法律关系。所以这个词涵盖的范围是非常广泛的。

### 特征：特殊就特殊在两处

这是一个理论问题，重点是它**相对于其他法律关系**的特殊之处。教材分两个层次展开：第一层强调它是一种**特殊的社会关系**；第二层强调它的**保障措施具有特殊性**。

看定义就知道门道：上位概念本是"社会关系"，前面却加了一串定语——"民事法律"。这些定语不是白加的。

#### 它是一种特殊的社会关系

特殊体现在四个方面。

| 方面 | 特殊之处 |
| --- | --- |
| 主体 | 主体平等。因为是受民法调整，主体平等是民法的社会关系与其他法律所调整的社会关系之间的**本质区别** |
| 内容 | 以民事权利和民事义务为内容，体现为一方有什么权利、一方有什么义务——这就是民法调整的规范方式 |
| 客体 | 某项民事利益，可以是人身利益，也可以是财产利益，都可以纳入进来 |
| 变动 | 更多取决于当事人的意思。民法要尊重当事人意思自治，以自愿原则为核心，所以关系的变动更多体现当事人的意愿 |

主体、客体、内容、变动，这几个词都是后面基本点里的关键词，缺一不可。少了哪一项？少了**保护**。而保护呢，不在这里讲，被放到了第二个层次。

#### 保障措施：以补偿为原则

第二层是保障措施的特殊性，主要体现为**补偿**的功能。

你看刑事责任，它还体现一个惩罚的功能，要惩罚犯罪。而民事法律关系不行——双方的法律地位是平等的，那你是没有资格来惩罚我的。所以民事这边，主要是补偿当事人所造成的损失。当然，民事责任在个别场合也会带有点惩罚的成分，但总体上是以补偿为原则。

> **提示**：概念和特征这一块，更多是主观题的考点。真要下功夫的，是下面那道题。

### 具体认定：这一节最要紧的考点

第二个问题，民事法律关系的具体认定。这是本节**最为重要**的一个考点：拿到具体案情，要能够辨识出哪些社会关系可以用民法来调整，进而构成一个民事法律关系。法硕考试的选择题特别爱考它，而且常常就是民法部分的**第一道题**。

怎么界定范围？回到概念：民事法律关系，体现为民法调整的**平等主体之间的人身和财产关系**。这里面需要强调三个关键词——第一个叫"平等主体"，强调主体的平等性；第二个是"之间"，意味着要涉及两个以上的民事主体；第三个强调既包括人身关系，也包括财产关系。

把这三个词做成三道关口就非常好用了：

```text
   某一项社会关系
    |
    v
     关口一  主体地位平等？       --否-->  行政法律关系，提起行政诉讼
    | 是
    v
     关口二  两个以上民事主体？   --否-->  组织内部事务，谈不上法律关系
    | 是
    v
     关口三  能形成权利义务？     --否-->  情谊行为，不受民法调整
    | 是
    v
     民事法律关系，受民法调整
```

读图：三道关口依次设卡，任意一道过不去，这个社会关系就落到了民法管不着的地方。

#### 关口一：地位不平等的，划给行政法去

这也是民事法律关系和行政法律关系之间的**核心区别**。行政法律关系中双方的地位是不平等的，特别是行政机关或者经授权的单位在行使行政职权的时候，和相对方并不是平等的主体，那形成的就不是民事法律关系。

比如税务机关征缴税款、交警罚款、城管执法等等，都是行政机关在行使行政职权，和相对方不是平等主体，双方形成的是行政法律关系。如果产生纠纷，提起的应该是行政诉讼，而不是民事诉讼。

**例一：赵C 的名字**

S 市的市民赵某给儿子取了个名字，叫赵C。这名字取得还是很个性的，可能是爱学英语。派出所以"姓名不符合办理户口登记"为由，拒绝为其办理户口登记。这个赵某我们就很生气——给儿子取这么洋气的名字，居然不给办登记，于是就把派出所、公安部门给告了。

他提起的应该是民事诉讼还是行政诉讼？答案是**行政诉讼**。因为对方是在行使行政职权，和这个申请办理登记的人不是平等的主体，双方形成的是一个行政法律关系。

（这个案件是实践中真实发生的案例。）

**例二：于某的博士学位**

于某是北京大学的博士研究生，在读博期间撰写的论文在某学术期刊发表，后来在 2013 年取得了博士学位——跟我是同一年博士毕业——然后入职某研究院。但后来发现，他发表在学术期刊上的论文是抄袭的，被期刊给撤销了。撤销以后，他就不符合获得博士学位的条件了：你要获得博士学位，是得有相应的学术成果的。于是北京大学就撤销了授予于某的博士学位，把学位证书收回。于某不服，向法院提起诉讼。

他能把北大告上法庭，提起的是民事诉讼还是行政诉讼？注意双方是不是平等的主体。北京大学尽管不是行政机关，它是一个事业单位，但它经过教育主管部门的授权，在行使授予学位这样的行政职权，所以在这一点上，它和学生并不是平等的主体。

大家想想，学校要授予学生学士、硕士、博士学位的时候，会不会找学生来商量一下？当然不会了。学术委员会经过讨论、确定结论以后，直接就通知你了。这就是在行使行政职权。

所以于某应当提起的是**行政诉讼**，而不是民事诉讼。这就是经授权的单位在行使行政职权。

> **易错点**：判断标准不是"看对方是不是行政机关"。行政机关也可以成为民事主体，判断的关键是——**它此刻是不是在行使行政职权**。

第二层次要反过来看：是不是行政机关参与的活动都是行政法律关系、不可能构成民事法律关系？也不是。如果行政机关是以**平等主体的身份**来参与民事活动的，这时候双方形成的还是民事法律关系。

比如公安机关发布悬赏广告、来悬赏破案线索，这时候它不是在行使行政职权，而是以平等主体的身份发布悬赏广告，希望社会公众能给你提供帮助。某市的财政局去购买办公用品也是一样，是以平等主体的身份来参与买卖这一市场交易。

所以民事主体当中有一种类型叫**机关法人**，它也可以成为民事主体。

**例三：10 万元的悬赏**

某市发生一起入户凶杀案件，犯罪嫌疑人畏罪潜逃，公安机关称：提供破案线索的话，将给予 10 万元的奖励。朝阳群众李某提供了线索，使得犯罪嫌疑人被抓获，但公安机关拒绝兑现悬赏上的报酬。李某提起诉讼的话，应该提起的是**民事诉讼**——因为公安机关在发布悬赏广告的时候，不是在行使行政职权，而是以平等主体的身份参与民事活动。

#### 关口二：一个组织的内部事务，不是法律关系

"之间"这两个字，意味着要有**两个以上**的平等主体，才会形成民事法律关系。假如只是某一个民事主体，涉及的是它自己的内部事务，那就不属于民事法律关系了。比如公司的内部事务、集团内部的事务等等，都不可能构成民事法律关系。

**例四：画出来的那张饼**

甲公司是某知名图书经销公司，在双 11 来临之际，向各地的分公司下发通知：销售额最高的分公司，全体员工可获得三亚 7 日游的奖励。这是给分公司的员工来画饼——大家拼命地卖货。后来该公司广东分公司夺得了销售冠军，但是总公司以财务紧张为由拒绝兑现承诺，只说给你们发个奖状、口头鼓励一下。

广东分公司能不能提起民事诉讼来要求总公司兑现承诺？你得说话算话啊。答案是不可以。因为总公司跟分公司是某一个组织的内部事务，是这个公司的家务事，并不是平等主体之间的问题，所以不会形成民事法律关系。

所以这个领导给你画的饼啊，想了想就完了，它在法律上没有效力，你不能付诸执行。

#### 关口三：只为增进情谊的，不是法律关系

这一条要强调的是**人身关系和财产关系**——要形成民事权利、民事义务，才能够构成民事法律关系。假如当事人实施的是情义行为，只是一种好意社会关系，目的是为了增进情谊，而不是为了形成权利义务的，那就不构成民事法律关系了。

生活当中情侣恋爱、朋友相处、师生交往、相约旅游等等，这些生活交往行为都是为了增进情谊，而不是为了形成法律关系。

比方说，甲跟好朋友说：咱俩多年不见了啊，这个周末我要请你吃大餐，好好聚一聚。乙说没问题啊，这几天天天盼着周末的到来。结果呢，甲压根就没把这个承诺当回事。这个时候乙很受伤，能不能要求甲承担违约责任，说你说话不算话、我都等你好久了？不能。因为甲跟你说周末请你吃饭，只是为了增进情谊，只是客气一下，你还当真了。双方并没有形成一个民事法律关系，不会产生法律上的权利和义务。

所以生活当中，别人说要请你吃饭，你可千万不要当真，他在法律上属于情谊行为。包括情侣恋爱时是不是许下了海誓山盟、对方感动得不行，但后来发现对方说话不算话、又跟别人好了，能不能追究违约责任？不能。恋爱的时候所做的承诺主要是为了增进情谊，而不是为了形成法律上的权利关系。所以谈恋爱的时候啊，也不能"恋爱脑"，对方说什么你就信什么。

**例五：被踢出群的律师**

这个案例是实践当中真实发生的，后来还被改造成了一道法硕的真题。

案件发生在山东青岛平度市，当地有一名法官姓于，他建了个微信群，叫"诉讼服务群"，把当地的律师、法律工作者通过相互邀请的方式邀请入群，来讨论跟诉讼立案相关的专业问题。群主还发了一个群公告，主要内容是群的宗旨：为了讨论和诉讼立案有关的问题，违者一次警告，二次踢群。

律师刘某也是被邀请入群的。他们经常在群里面发布和主题无关的视频。相信大家都加了不少微信群，每个群常常有那么几个显眼包，每天有事没事就发几个视频进来，好像显得自己很积极，但在别人眼中这样的行为是很无聊的。群主多次提醒，但牛马不把群主当领导，依然我行我素。后来群主就把刘某给踢出群了，群页面就显示刘某被移出群聊。

刘某呢，也是当地的著名律师，觉得自己被移出群聊、在当地的法律同事面前丢了面子，于是提起诉讼，要求法院判决群主重新邀请自己入群，并要求群主在群里面公开给自己赔礼道歉。面子还挺大。

法院受理以后，我们要确认群主和群主之间有没有形成民事法律关系。显然是没有的。因为这个入群、退群的行为都是一种情谊行为，是为了增进情谊，而不是为了形成权利义务关系。这意味着人家群主把你踢出群、不想跟你玩，你并不能获得法律层面的救济。告他也告不了，你只能自己气。

不过的话，你也可以自己建个微信群，把当地的法律同仁都邀请进来，包括这位于法官，邀请进来以后直接把他再踢出去，感受感受群主的这份权力也是没问题的。但你不能通过法律途径来进行救济。

其实这也体现了一句法谚，叫**法律不理生活琐碎之事**。对这些鸡毛蒜皮的小事，如果都提到法院让法院来审理的话，那法院会更加地不堪重负。谁能划到情谊关系、而不受民法所调整的范围里来？

把这三个关键词套上去，一道考过的真题就很好做了——题干和解析放在文末《本讲提到的题目》。

### 分类：三种切分角度

第三个问题，民事法律关系的分类，也是理论问题。大家简单了解几种分类，关注几个专业术语。

#### 按调整对象：人身与财产

第一种分类是基于调整对象的不同，区分人身法律关系和财产法律关系。在前面讲民法的调整对象的时候，也是区分人身关系和财产关系，所以这个区分大家非常熟悉。

含义很简单：人身法律关系，是基于**人身利益**而产生的法律关系；财产法律关系，就是基于**财产利益**而产生的法律关系。

教材里面写了两项区别。

| 区别 | 人身法律关系 | 财产法律关系 |
| --- | --- | --- |
| 权利性质 | 产生的是人身权，具有人身专属性：不能转让、不能放弃、不能继承 | 产生的是财产权，可以依法进行转让 |
| 客体 | 人身利益，和人身不可分离，具有不可让与性 | 财产利益，体现当事人意思自治，可以依法转让 |
| 保护方法 | 主要通过非财产性的责任方式救济，如赔礼道歉、恢复名誉 | 主要通过财产责任方式救济，特别是赔偿 |

第一项区别是权利的性质不一样。人身权具有人身专属性，是不能转让、不能放弃、不能继承的；财产权则可以依法进行转让。包括前面讲人身关系和财产关系的特征时也讲过，人身关系的客体具有不可让与性、和人身不可分离；而财产法律关系的客体是财产利益，它体现当事人的意思自治，可以依法转让——是不一样的意思。

第二项区别是保护方法不一样。财产法律关系的救济主要通过财产责任方式、特别是赔偿的方式；人身法律关系要通过非财产性的责任方式来救济，比如赔礼道歉、恢复名誉等等。当然，造成财产损失的也可以主张损害赔偿。所以人身法律关系的具体措施更加多元化，而财产法律关系的具体措施主要是财产性的民事责任。

#### 按义务主体的范围：绝对与相对

第二种分类是绝对法律关系和相对法律关系的区分。就这两个专业术语，区分的标准是**义务主体范围**的不同。

```text
   绝对权(一对多)               相对权(一对一)
   权利人 ----> 不特定的所有人  权利人 ----> 特定的那一个
   买手机取得所有权             买房人的价款请求权
   对抗一切不特定的人           换个人就不灵了
```

**绝对法律关系**的权利人是特定的，但义务人是不特定的，多数人，也就是一对多的关系，这叫绝对法律关系。在绝对法律关系当中，该权利是可以向全世界来主张的。比如物权法律关系、人身权法律关系、知识产权法律关系，产生的都是绝对权，是不是可以向全世界主张？比如某个同学买了一部手机，是不是可以取得这个手机的所有权？天王老子来了，这个手机也是你的，你可以行使所有权、可以对抗全世界。这就叫绝对法律关系。

**相对法律关系**的义务主体是特定的当事人，也就是一对一的关系。你这个权利只能向特定的人主张，换个人就不灵了。最典型的就是债权法律关系。比如甲和乙签订了房屋买卖合同，签订合同以后甲没按照约定去向乙支付房款，这时候乙可以找谁来主张房款？只能找甲。能不能找到甲的朋友，说"你好哥们买了我房子不给钱，你来给这个钱行不行"？不行。这个权利只能对特定的义务人主张，这就叫相对权、相对法律关系。

#### 财产法律关系里的物权与债权

第三种分类是区分物权关系和债权关系。在财产法律关系当中，以物为客体所形成的法律关系叫物权关系，而物权关系它也是一种绝对法律关系；债权关系就只能向特定的义务人主张，所以它是一种相对法律关系。

所以大家也可以把它理解为：在财产法律关系当中，凡是绝对权法律关系，那就是物权关系；凡是相对法律关系，那就是债权关系。还可以通过我们前面讲过的一个说法来理解——物权关系规范的是**财产的归属**，债权关系规范的是**财产的流转关系**。从这个角度理解也是可以的。

### 本讲提到的题目

#### 下列属于民法调整的是（答案 D）

- A. 甲与网友相约电子竞技，约好一起出去玩，被别人给放鸽子了。
- B. 乙大学拒绝授予范某硕士学位。
- C. 丙和王母在相亲会上成功牵手。
- D. 丁关局提出办案线索，将奖励 300 块钱。

**答案：D。**

**解析：**

- **A 项**是情谊行为。约好一起打游戏然后被放鸽子，目的是增进情谊，并没有要形成民事权利义务，不受民法调整。
- **B 项**是乙大学在行使行政职权。它经教育主管部门授权行使授予学位的职权，与学生并非平等主体，形成的是行政法律关系。
- **C 项**没有形成民事法律关系。相亲会上牵手，相亲会结束后可以立马放手；或者压根没相亲成功，牵牵手也行——这个牵手在法律上并没有什么意义。
- **D 项**应当选。尽管公安局是一个行政机关，但它发布悬赏广告是在参与民事活动，以平等主体的身份悬赏，所以要受民法所调整。

#### 下列民事法律关系中属于绝对法律关系的是（答案 A）

- A. 人身法律关系
- B. 无因管理法律关系
- C. 不当得利
- D. 合同

**答案：A。**

**解析：**

- **A 项**人身法律关系，产生的是人身权；人身权具有人身专属性、不能转让，可以向全世界主张，属于绝对法律关系，选。
- **B 项**无因管理法律关系是债权法律关系，属于相对法律关系。
- **C 项**不当得利、**D 项**合同，都是债权的发生原因，同样属于相对法律关系，不能选。

## 民事法律关系的要素：主体、客体与内容
> 对应块：BLK08 | 覆盖分集：P09 | 块标题（分集名）：《第01编 第02章 第02节：民事法律关系的要素》

上考场之前，不少同学都去庙里面拜一拜，拜托佛祖菩萨，拜托各路神灵，保佑自己取得一个好成绩、顺利上岸。

那问题来了：佛祖菩萨、神灵，能不能成为民法中的主体？

当然不能。它们不是客观存在，只存在于人的想象当中。奥特曼、变形金刚这些耳熟能详的形象也一样，它们塑造得再鲜活，法律面前依然不是人。

这个看似调侃的问题，其实正是今天这一节的开头。民事法律关系这一章，我们依次展开五个基本点：既包括从静态角度描述的三要素——主体、客体、内容，也包括从动态角度描述的变动和保护。静态的三要素今天这一节一次讲完，动态的部分后面再展开。

先看三要素长什么样：

```text
            民事法律关系
      ┌─────────┼─────────┐
      ▼         ▼         ▼
    主体       客体       内容
   谁的       指向什么    权利与义务
  权利义务     民事利益    自由   约束
  承担者     物/利益/行为 可能性  必要性
```

三个要素是配套的：主体去"享受"和"承担"，享受与承担的对象是客体，享受和承担的具体内容是民事权利与民事义务。下面一个一个来。

### 民事法律关系的主体

民事法律关系的主体，也就是民事主体制度，指的是**在民事法律关系中，可以享有民事权利并承担民事义务的人**。

通俗地讲，它解决的就是"在民事法律关系中，哪些人可以享有权利、承担义务"的问题。这个问题要从四个方面来展开。

#### 主体资格的两个要件

第一个方面是一个理论问题：民法中的主体应当满足什么条件？教材给了两个要件——**客观存在**、**为法律所承认**。两个条件必须同时具备，才能成为民法中的主体。

第一个要件是客观存在。走在大街上，形形色色的人，男女老少、高矮胖瘦，每个人都是客观存在，都会成为民法中的主体。研究生毕业的时候，很多单位来招聘毕业生，这个单位也是客观存在，同样可以成为民法中的主体。但是如果只是存在于人的想象当中，那就不能进入主体的范围——开头说的佛祖菩萨、神灵、奥特曼、变形金刚，都属于这一类。

第二个要件是为法律所承认。有些东西客观存在，但法律不承认它的主体资格，它照样不是民法中的主体。

动物是人类的好朋友，不少同学养宠物猫、宠物狗，它们给人温馨的陪伴，但这些动物不能成为民法中的主体，因为现行法律并没有认可它们的主体资格。

现在更火的是 AI 人工智能。DeepSeek、千问、豆包，这些人工智能尽管也可以写文章、创作歌曲、陪你聊天，但目前的法律并没有认可人工智能的主体资格，所以它们也不是民法中的主体。

> **结论**：一方面得是客观存在，同时还得被法律所承认。两个要件缺一不可。

#### 主体是一个历史范畴

注意一个词：民法中的主体是一个**历史范畴**。学政治课的时候大家也听到过这样的说法。它意味着我们描述主体范围的时候，必须站在特定的历史条件之下来描述——不同的历史时期，民事主体的范围也会有所不同，因为各个时期法律的规定存在差异。

举两个例子。

第一个是奴隶社会。大家学法制史的时候接触过：奴隶也是客观存在，也是人，但他并不能成为民法中的主体，因为奴隶社会的法律不认可奴隶的主体资格，奴隶只是被交易的客体。

第二个是我国现代法律内部的发展。1986 年的《民法通则》主要规定了两类主体：自然人和法人。但随着社会发展，人们发现一些非法人性质的组织在社会中扮演着重要角色，所以在 2017 年制定民法典总则编的时候，我们认可了非法人组织的主体资格。今天的民法典里，除了自然人、法人，还认可非法人组织，它也是一种民事主体。

你看，这就是法律的发展，它会使得民事主体的范围呈现不同的状态。

那么顺着"历史范畴"这个思路往下想一层：随着社会发展，未来有没有可能出现新的民事主体？当然有可能。比如随着人工智能发展完善，法律有可能认可它的主体资格；未来假如我们真的发现了外星人的存在，能不能认定外星人也具有民事主体资格？也是有可能的。

所以要站在历史发展的角度来看待民事主体的范围。

#### 现行法承认了哪些主体

既然民法中的主体需要法律的认可，那我国现行民法典认可了哪些主体？主要是**自然人、法人、非法人组织**三种类型。在接下来的第三章、第四章、第五章，我们会分别介绍这三种民法典所认可的民事主体。

同时，特殊情况下，**国家和集体**也可以成为民事主体。比如国家对城市的土地享有所有权，就成为所有权的主体；集体对于集体土地也可以取得所有权，集体也可以成为民法中的主体。当然，这是特殊情形。

#### 既是权利主体，也是义务主体

第三个方面：民法中的主体既包括权利主体，也包括义务主体，都属于民事主体的范畴。而且在多数法律关系中，当事人既是权利主体，也是义务主体，二者是对立统一的。

举个例子。一个买卖合同中，甲把自己的房子卖给乙，甲是出卖人，乙是买受人，这是我们生活中非常常见的一种交易。

站在甲的角度看：作为出卖人，他享有请求买受人支付价款的权利，从这个角度讲他是权利主体；但同时他又有义务交付房屋并转移所有权给乙，从这个角度讲他又是义务主体。

站在乙的角度看：他有支付价款的义务，所以他是义务主体；同时他可以请求出卖人甲交付房屋并转移所有权，他又成了权利主体。

所以在多数法律关系中，双方当事人既是权利主体也是义务主体。

> **提示**：既然有"多数"，那就必然有"少数"。在一些少数的民事法律关系中，可能一方只作为权利主体或者只作为义务主体而存在。

比如甲和乙签订赠与合同，甲要把自己的一套房子赠与给乙。在这个赠与关系中，甲作为赠与人有交付赠与物的义务，是义务主体，但他有没有相应的权利？其实没有，所以他只是义务主体。而站在乙的角度，他是无偿取得财产的，是权利主体，同时他原则上不需要负担义务，就不是义务主体。

#### 单一与多数、特定与不特定

第四个方面，是从主体人数角度来区分的单一主体和多数主体。

甲把房子卖给乙，双方都是一个人，这叫单一主体。假如买房的乙已经结婚了，他和丙是两口子，那买房子的时候乙和丙能不能都作为买受人签订合同？当然可以。这时候买受方就是两个人了，叫多数主体。

另外，民法中的主体还区分特定主体和不特定主体。特定的主体，指的是到底是一个人还是数个人、是确定的。甲把房子卖给乙，双方都是一个人，是特定主体；甲把房子卖给乙丙两口子，乙丙这两个人也是确定的，同样是特定主体。

但有的法律关系中，主体是一个不特定的范围。比如甲对一套房子享有所有权，甲作为权利主体是特定的，而对应的义务人是谁？是甲和乙之外的所有其他人——他是一个可以对不特定多数人主张的权利，所以这个义务主体就是不特定的多数人。又比如甲的手机丢了，他在网上发一个悬赏广告，这个悬赏广告法律关系中，他面向的就是不特定的多数人。

所以在民法中，主体可以是特定的，也可以是不特定的。

> **结论**：不特定的常常都是义务人，而权利主体必须是特定的。

这一条要和我们前面讲过的一种民事法律关系分类连起来：如果义务是特定的义务主体，形成的是相对法律关系；如果义务是不特定多数人的，形成的是绝对法律关系。

### 民事法律关系的客体

民事法律关系的客体，指的是民事法律关系中权利、义务所指向的对象。

这部分从真题数量上看，在考试中考查的频率还是比较高的。

#### 客体指向的是民事利益

民事法律关系指向的对象，主要体现为各种各样的民事利益。大家可能听过一句话——"天下熙熙皆为利来，天下攘攘皆为利往"。民事法律关系指向的对象，就是各种各样的民事利益。

而民事利益既包括人身利益，也包括财产利益。教材里是从不同法律关系、不同权利的角度来描述的。民法中的权利既包括人身权，也包括财产权，同时还包括其他民事权利。不同的法律关系、不同的权利，指向的对象是不同的。

**人身权利指向人身利益**。现在的人格权，客体就是人格利益——人的生命、健康、隐私、名誉等等，都属于人格利益。既然产生的是人格权，那么相应的身份权指向的就是各种各样的身份利益，比如配偶的身份、父母的身份、子女的身份，都可以成为身份权的客体。

**财产权包括物权和债权这两种最基本的类型**。物权描述财产的**归属关系**，债权描述财产的**流转关系**。

物权的客体指向特定的物。比如某个同学买了一部新手机、一台新电脑、一辆新车、一套房子，那个手机、电脑、车子、房子都属于特定的物，可以成为所有权的客体。同时，法律规定的权利也有可能成为物权的客体。比如甲买房子时钱不够，付了首付以后，剩下部分去银行办了贷款，银行为了确保债权能收回来，要求甲提供物的担保，甲就把买到的房子抵押给了银行。银行取得的抵押权也是一种物权，它这个物权的客体一方面是甲的这套房子，另一方面还包括相应范围内的建设用地使用权——建设用地使用权本身是一种权利，它就成为抵押权的客体。所以物权客体主要指特定的物，同时也包括法律规定的一些权利。

债权的客体指向债务人特定的支付行为。比如我借给陈某 10 万块钱，基于这个借款合同，我能取得一个借款债权。这个债权指向的对象是什么？是陈某这个人吗？当然不是，他不还钱的时候我也不能把他这个人怎么样。是陈某家里的 10 万块钱现金吗？也不是，他不还钱的时候我也不能去他家里直接把现金拿走。我的权利只是请求陈某来实施一个还款的行为。所以债权的客体指向的是**债务人履行债务的特定给付行为**。这个行为对债权人来讲是有财产利益的，所以它也可以成为民事法律关系客体的范畴。

**其他权利**包括继承权和知识产权，它们具有人身、财产的双重属性。

继承权指向的对象是被继承的遗产。比如甲和乙是父子关系，当甲死亡的时候，按照现行法律规定，只要甲没有立有效遗嘱，他的遗产就由法定继承人乙来继承。乙可以继承遗产的权利，我们称之为继承权，它指向的对象就是甲的遗产。

知识产权的客体指向的是一个智力成果，它是一个无形的客体。比如甲写了一本书，或者某个公司研发出了有效治疗慢性白血病的药品并申请了专利，这些作品和发明创造都属于智力成果，要通过知识产权来获得保护，都可以成为民事法律关系的客体。

所以不同的权利指向的客体有所不同，但它们本质上都是一种民事利益。这是理论层面的框架。

在具体的法律关系里，我们还会进一步展开客体的认定。这一部分我们重点讲的是民法当中的"物"，因为在实践中，各种物质资源也是民事法律关系当中最常见的客体类型。

#### 民法上的物要满足四个要件

"物"这个字，大家在生活中经常听到；但在它前面加上"民法上的"，它就变成民法中的概念了——它指的是可以成为民事法律关系客体的物。它跟物理学上的物是不一样的。

那要成为民法上的物，需要满足什么条件？四个方面的要件。

**第一，存在于人体之外。** 身外之物。人体组成部分不能成为物的范畴——人的五脏六腑、四肢、大脑，都是人体的组成部分，不是民法上的物。但人的身体组织如果和人分离了，它就具有民法上物的属性：人的头发剪下来了，血液抽出来了，都会成为民法意义上的物。

这意味着什么呢？有人装了一个心脏起搏器，在打架的时候别人把这个心脏起搏器打坏了，侵犯的是对方的什么权利？是财产权还是人身权？答案是人身权。尽管那个心脏起搏器安装的时候花了很多钱，但它装到人身上以后，就变成了人身的组成部分，不属于民法中物的范畴了，它受人身权的保障，而不是受财产权的保障。

**第二，能够为人力所支配，具有可支配性。** 人力无法支配的，就不能成为民事法律关系的客体。像日月星辰，物理学上也是物的范畴，属于天体物理，但人力无法支配，所以不能成为民法中的物。比如某个网站上出卖月球上的土地，"这 100 亩地 10 万块钱卖给你"，这个月球上的土地能不能成为买卖的客体？答案是不能。因为如果认为它是民法中的客体，权利没有实现时就应该可以通过法律途径来救济，法院能帮你强制执行吗？当然不能——人力无法支配。

有些同学会说，我看了科幻小说、看了电视剧，《三体》里面日月星辰就可以支配。那是科幻，法律规范的是现实世界的问题，大家要区别开来。

**第三，能够满足人类的某种需要。** 只有满足某种需要，才有可能产生民事纠纷，进而才有法律进行规范的必要性。一滴水、一粒米、一个分子、一个原子，尽管在物理学上也是物的范畴，但它们无法满足人类的某种需求，所以不会成为民法上物的范畴。

**第四，具有稀缺性。** 只有稀缺的物质资源才有可能产生民事纠纷，法律才有必要进行规范。假设某项物质资源取之不尽、用之不竭，大家自取所需，那就不会产生民事纠纷，没有必要成为民事法律关系的客体。比如阳光和空气，在现在这个社会背景下依然是取之不尽、用之不竭的，所以大家可以尽情地享受阳光的沐浴、尽情地呼吸新鲜空气，法律是管不了这种事情的。

> **结论**：民法上的物必须同时满足四个条件——存在于人体之外、为人力所支配、能够满足人的需要、具有稀缺性。

#### 物的成分：看的是能不能分离

物的成分也是一个法律上的概念，指的是物的构成部分。基于生活经验，大家也知道物可以由不同的成分构成。物的成分要进一步区分重要成分和非重要成分。

这两个词也是法律上的术语，区分采用的是**法律标准**而不是生活标准。一个物的成分到底是重要还是非重要，不是看它在生活中对物质作用发挥的重要程度，而是看这个成分**从物当中分离的特性**。

假设这个成分非经毁损不能从物中分离出来，或者分离耗费比较高，这样的成分叫重要成分；假设这个成分可以从物中分离出来而独立存在，就叫非重要成分。

用一辆车来检验一下。

有同学说，车当然要靠轮胎才能跑起来，没有轮胎这个车就没法用了，所以轮胎是重要成分。这个说法对不对？不对，因为这是从生活角度出发的。从法律角度看，轮胎从车上卸下来以后，依然是一个轮胎，它可以独立存在，所以它是非重要成分。

车的发动机，虽然对车来讲很重要，但这是生活观念的角度。从法律角度讲，发动机从车上拆下来能不能独立存在？可以，它依然是一个发动机，所以它也是非重要成分。

那车漆是重要还是非重要成分？尽管车漆对车性能的发挥不是那么重要，车漆蹭了也不影响开，但是车漆非经毁损能不能跟车分离出来？答案是不可以。所以车漆属于重要成分。

一定要掌握它法律上的认定标准，也就是分离的特性。

> **提示**：为什么法律上的这个概念跟生活概念不一样？因为它是为了方便法律规则的适用。

我们前面提到的物权编的添附制度就是典型例子。添附是所有权的一种原始取得方式，其中一种情形叫附合：一个物的成分成为另一个物的重要成分时，就会发生添附。比如甲的车漆喷到了乙的车上，这个车漆成为乙车的重要成分，就会触发民法上的添附制度，乙取得这个车漆的所有权，甲的车漆损失随之消灭，甲只能请求乙给予适当的补偿或者赔偿。

但如果是甲的轮胎装到了乙的车上呢？这个轮胎有没有成为车的重要成分？没有，因为它依然可以卸下来独立存在。这时就不会触发添附制度，装到乙车上的这个轮胎依然归甲，甲可以请求把轮胎卸下来。

这就是法律上区分重要成分和非重要成分的意义所在。我们讲到物权编的添附制度时，还会再讲这个问题。

#### 不动产与动产

分类不止一种，而且分类越细致，我们法律设置的规范也会更加精细科学。所以大家不要害怕分类，我们要拥抱分类。这一节最后一块，是民法上物的分类，也是这一部分最为重要的考点。

因为在实践中可以作为民事法律关系客体的物五花八门，不同的物在法律进行规范时有可能适用不同的规则，所以要对它进行分类。

**第一种分类是不动产和动产。** 它们都是法律术语，区分的标准是这个物能否移动，以及移动是否影响其经济价值。

不动产指的是不能移动，或者虽然可以移动但会影响经济价值的物。土地是典型的不动产，海域也是不动产，房屋、林木等地上定着物同样是不动产。

这里有个很有意思的例子。现在技术非常发达，有些房屋确实可以移动。比如上海音乐厅，在修虹桥机场的时候，就把上海音乐厅整体平移了几百米。虽然耗费巨大，但它确实实现了平移。我们能不能说这个上海音乐厅是动产？不能。虽然它可以移动，但它耗费巨大，而且有可能影响不动产的价值，所以它仍然属于不动产的范畴。所以这里不是从技术角度判断，而是从法律角度判断的。

还有一个是陵墓。陵墓给他换个地方栽也能活，但从生活观点讲叫"人离原地活，树离原地死"——把树挖起来移动，有可能导致树死亡。所以从生活角度看，移动这个陵墓会影响其价值，它依然属于不动产的范畴。

动产就好理解了，指的是可以移动、而且移动不会影响其价值的物。手机、电脑、汽车都可以移动，属于动产；网上买的东西基本都是动产，因为通过快递物流交付给你，它必须具备可移动的属性。

到物权编我们还会进一步区分普通动产和特殊动产。特殊动产指的是需要办理登记手续的动产，像航空器、船舶、机动车，作为交通工具当然可以移动，但因为价值比较高，所以常常需要办理登记手续；不需要办理登记手续的，像手机、衣服、电脑，属于普通动产。

**那不动产和动产的区分有什么意义？** 教材写了两个方面。

第一，物权法规范上，两种物的物权变动公示方式要求不一样。不动产要办理登记才能发生物权变动，动产的公示方式是交付。这是最核心的一点。

第二，两种类型的物上可以设定的物权种类不一样。不动产上只能设定抵押权，而动产可以设定抵押、可以设定质押，还可以成为留置权的客体。

**顺便问一个：** 房车是动产还是不动产？也有人说房是不动产、车是动产，房车既是动产也是不动产。这个说法不对——房车本质上是一台"车"，而不是"房"，所以它属于动产的范畴。

#### 主物与从物

**第二种分类是主物和从物的区分，标准是两物之间的关系。**

注意"两物"这个词，这意味着从物首先得是一个独立的物，而不能是物的成分。一辆车的四个轮子能不能成为从物？不能，因为它是车的组成部分，它不是独立的物。

那从物的认定需要满足三个方面的要求。这是考试中比较爱考的考点，重点掌握。

**第一，必须是独立的物，而不能是物的组成部分。** 刚才提到了，四个轮子是车的组成部分，它不可能成为从物。但这个车的备胎，它就不是车的组成部分了，它就可以成为从物的范畴。

**第二，存在的价值是为了辅助主物功能的发挥，从属的地位发挥的是辅助功能。** 换句话说，有这个从物以后，主物的功能能够得以最大限度地发挥。

像手机的充电器：它是一个独立的物，但存在的价值是为了让手机的使用价值能够充分发挥——手机没电了，充上电以后依然可以使用，这就是从物。电视机的遥控器：没有遥控器它也是一台电视机，所以它不是组成部分，但有了遥控器以后，躺在沙发上就可以换台追剧，电视机的使用效能可以最大限度发挥，所以遥控器也是从物的范畴。笔记本电脑配的蓝牙鼠标：有了它使用起来更方便，但不影响笔记本电脑正常使用，它也是从物。

还有大家学过的"卖椟还珠"的典故：里面的珠是主物，外面的礼盒就是从物。给礼物包一个更精美的礼盒，送给别人别人会更开心。而"卖椟还珠"恰恰是搞错了主次。

**第三，依照习惯，从物与主物要同属一人。** 充电器虽然是手机的从物，但甲的手机没电了，借了乙的充电器来充电，能不能说这个充电器变成了手机的从物？不能，因为它们没有同属一人。只有甲的手机和甲自己的充电器，才是主物和从物的关系。

**认定从物的价值在哪里？** 主要是解决物权变动规则的问题。

民法典第 320 条规定，主物转让的，从物随之转让，但是当事人另有约定的除外。

去商场买一部手机，我们谈的价格是手机的价格，但如果双方没有特别约定，你把手机交出去的同时，得把原装充电器也交付给受让人。你不能说"我们刚才谈的是手机的价格，你要充电器还得再付 300 块"——行不行？不行。因为充电器既然是从物，主物所有权转移的时候，从物所有权会随之转移。二手车开了很多年要卖掉，甲把二手车卖给乙的时候，这辆车配置的备胎要不要交付给乙？也得交付给乙，除非当时有特别的约定。

**但注意从随主是一个原则性规定**，法律允许当事人约定例外的情形，也就是"当事人另有约定的除外"。为什么允许？因为从物虽然发挥辅助功能，但它在法律上也是个独立的物，既然是独立的物，就应当允许当事人通过特别的约定来单独进行交易。

比如甲赚了一笔钱想改善生活，去乙商场买手机。通常情况下充电器是手机的从物，买手机的同时也会拿到充电器，这是从随主的一般规则。但乙商场明确跟甲讲了：我们这个标价是手机的价格，你要再获得一个充电器，得额外付 200 块钱，是另外的价格。这时假设没问题——双方有约定，充电器虽然是从物，但就不会当然地随主物一并转让了，你得单独付 200 块才能拿到它。

实践中苹果手机率先推出了这种操作。其实这个理念还是比较先进的，它体现的是民法中的一项原则——**绿色原则**，即节约资源、保护生态环境。因为实践中很多人在买电子产品时喜欢买同一个品牌，而同一品牌电子产品的充电器配置几乎都是一样的标准，那假如每买一个都配个充电器，会导致资源浪费。所以苹果率先推出：买手机时的价格就是手机的价格，你要充电器还得额外付一笔钱。

当然这种操作虽然很绿色，但也得保护消费者的合法权益——在标这个手机价格时，要把充电器的价值扣除出去。你不能说给消费者的东西少了，但价格一分都不少，那对消费者来讲也是不公平的。现在有些手机品牌也跟进了苹果这个操作。包括实践中去买一个礼物的时候，不同的礼盒价格可能也是不一样的。

这就是通过当时的特别约定，使从物具有独立交易的价值。如果没有特别约定，那买到主物的同时也会买到从物，从物会随同主物一并发生物权变动。

#### 原物与孳息

**第三种分类是原物和孳息的区分，标准是两物之间的派生关系。**

首先注意，原物、孳息之下都是单独的物。它们是两物，能产生收益的物我们称之为原物。母鸡可以下蛋，母鸡是原物，下的蛋就叫孳息——孳息是原物所生的物或者其他收益。奶牛身上可以挤牛奶，奶牛是原物，挤出的牛奶就是孳息。这个很容易理解。

既然它们是两个物，就意味着只有和原物相分离、成为独立的物，才能够成为孳息；在和原物分离之前，它不能成为孳息。比如母鸡要下蛋，但它还没想好把蛋下在哪里，正在到处找下蛋的地方——这个时候有没有产生一个孳息？没有，这个蛋还没下来，它就是原物的组成部分。牛奶必须从牛身上挤下来的时候，才能产生一个孳息。树上结的果实也属于孳息的范畴，但必须跟原物相分离、采摘下来的时候，才成为孳息。

考试的时候特别爱考这个：苹果从树上掉下来，在牛顿的眼中看出了万有引力定律，但在法律人的眼中，苹果掉下来意味着什么？一个崭新的孳息产生了。

**孳息又进一步区分天然孳息和法定孳息。** 有些同学听说"天然"应该和"人工"相对应、"法定"应该跟"约定"相对应，其实大家没有必要纠结这种文字上的使用——"天然孳息"和"法定孳息"是法学前辈给它们取的名字，正常使用就可以了。

**天然孳息**指的是果实等物的出产物，以及按照物的使用方法所获得的出产物，通俗地讲就是基于自然原因而产生的孳息。比如母鸡会下蛋，奶牛可以挤牛奶，都是基于物的自然原因产生的收益。"种瓜得瓜，种豆得豆"，苹果树上就会结苹果，橡胶树上就会流橡胶，这都属于天然孳息。

**法定孳息**指的是利息以及其他因法律关系而获得的收益，它是因为法律关系而产生的收益。比如把钱存到银行，储户跟银行之间存在一个储蓄合同关系，这个合同约定每年的 6 月 30 号银行给你结算利息，这个利息就是法定孳息。再比如甲有一套房子租给乙使用，基于双方签订的租赁合同，乙得给甲支付租金，这个租金就是房子的法定孳息。

> **注意区分**：天然孳息跟法定孳息，法律上区分它们主要是为了确定物权归属，因为孳息是产生的新物，这个新物到底归属于谁。

**天然孳息产生出来应当归谁？** 要分成三步走。

```text
天然孳息归谁？（三步走）
   │
   ├─ 第1步  当事人有没有约定？
   │        ├─ 有  ──► 按约定，归约定的人
   │        └─ 无
   ▼
   ├─ 第2步  有没有用益物权人？
   │        ├─ 有  ──► 归用益物权人
   │        └─ 无
   ▼
   └─ 第3步  归所有权人
```

第一步先看当时的约定，尊重约定。比如甲有一只名贵的公宠物犬，想要个后代，于是和乙签订合同，跟乙的母宠物犬进行交配，双方约定生下来的宠物归甲，然后甲给乙一笔费用。那生下来的小狗，天然孳息归谁？按照双方的约定是归属于甲的，因为甲给钱了。

第二步，如果当时没有约定，就看有没有用益物权人，如果有就归用益物权人。用益物权是物权编会讲的一个专业术语。举个例子：甲村有一块耕地，承包给了乙农户，这叫包产到户。乙农户对这块农用地取得一个权利，叫土地承包经营权，它就是一种用益物权——要支配集体所有的土地的使用价值。乙农户承包这块土地以后，在地里面种了玉米、种了小麦，到秋天收割的时候，这个玉米也好、小麦也好，从地里面收割回来就成为孳息了。它归谁？如果双方没有做特别约定，由乙农户取得这个孳息的所有权是更合适的，也就是农户取得这个农产品的所有权。这叫有用益物权人的，归用益物权人。

第三步，如果没有用益物权人的，就归这个地方的所有权人。比如甲村有一块荒地，荒地上长出一棵苹果树，或者长出一棵山楂树，秋天会结苹果、会结山楂，摘下来或者掉下来，它会成为天然孳息。那这个苹果或山楂归谁？因为是荒地，没有承包给别人，所以没有用益物权人，那就由原物的所有权人——村集体来取得这个所有权，是更合适的。

**法定孳息归谁呢？** 分两步。

```text
法定孳息归谁？（两步走）
   │
   ├─ 第1步  当事人有没有约定？
   │        ├─ 有          ──► 按约定取得
   │        └─ 无 / 约定不明
   ▼
   └─ 第2步  按交易习惯取得
```

第一步还是先看当时的约定。既然当时存在法律关系，就要看你在法律关系里面是怎么约定的；如果当时没有约定，那就按照交易习惯来取得。这意味着交易习惯可以成为处理民事纠纷的依据，按照交易习惯来确定归属。

所以天然孳息和法定孳息这一块，一方面要掌握孳息的认定，另一方面要掌握孳息的归属。

#### 种类物与特定物

**第四种分类是种类物和特定物的区分，标准是物是否具有特定的属性，或者是否被特定化。**

假如这个物具有共通的属性、可以被同种类物所代替，这样的物叫种类物；假如这个物是独一无二的，或者在交易中被特定化了，它就叫特定物。

比如去买一部新手机，华为新出的 mate80，一生产几十万台，是不是都一模一样的？可以被同型号、同种类的手机所代替，所以它是种类物。包括大家现在正在学习的民法精讲一本通，我们印刷的时候会印几万册，每一本书都是完全一样的，都可以相互代替，这样的物也叫种类物。这些非常好理解。

**关键要掌握特定物的概念**，它包括两个方面。

第一是独一无二的物，它本身具有特殊的属性。像文物，每一个文物都是独一无二的；包括私人定制的物品，它也是独一无二的。

第二是本来是种类物，但在某一个交易当中被特定化了，它也会成为特定物。比如甲在小米的官网上购买了一辆小米 SU7，现在挺火的。这辆车本来是种类物，一下子生产几千几万台，都可以相互替代。但是双方在系统里签订合同以后，假如按照双方的约定，把某辆车的车架号写在了这个买卖合同当中，那这辆车就在这个交易当中被特定化了。

大家知道什么叫车架号吧？相当于车的身份证号，每辆车的前挡风玻璃上一个特定区域会体现这个车架号，和人的身份证一样，也是 18 位。假设把这个号写到了甲乙的买卖合同当中了，尽管甲还没拿到这辆车，但这辆车已经特定化到甲乙的买卖合同中，它就变成特定物了。

所以特定物包括两种类型：一种是它本来就具有特殊特征、独一无二；一种是她本来是种类物，但在某个交易当中被特定化了。注意区分这两个概念。

> **结论**：所有的**不动产都是特定物**。不动产都是独一无二的。尽管一个小区开发完成、开发商卖房子的时候，同户型的有几百套，但我们依然采取"一房一价"——户型虽然相同，但每套房子的楼层、朝向、位置有所不同，它的价值也会有所区别。所以不动产都是特定物，大家记住这个结论。

**那民法中区分种类物和特定物，有什么意义？** 教材写了两个方面。

**第一，在物权法规范中的意义。** 在交易中，种类物的所有权只能在交付以后发生转移。因为物权的客体指的是特定的物，如果你买的是种类物，没有进行交付，就不能成为物权的客体，必须交付以后变成特定物，才能够发生物权变动的结果。

但对特定物，所有权转移时间允许当事人约定，特别是允许当事人约定保留所有权的条款。比如甲有一辆二手车要卖给乙，双方约定乙分期付款。假如当时没有做特别约定，甲把这辆车交到乙手中的时候，乙就可以取得所有权。但因为甲没有拿到全部的价款，他担心把车交出去以后对方就不付款，于是双方特别约定：尽管我把车的所有权交付给你乙了，但是乙只有在付清全部价款的时候，才能够取得该车的所有权——这叫保留所有权的条款。

这里也意味着，当时约定保留所有权的话，**能不能保留种类物的所有权？不可以**。种类物没有被特定化的话，它在交易当中不能成为保留所有权的对象。

**第二，从债权规范层面来描述**，区分的意义主要是从违约责任承担方式角度来讲的。

如果债的标的是特定物，而这个特定物发生了毁损、灭失，因为它是独一无二、不可替代的，标的灭失意味着债的履行将陷入履行不能。这时候对方不能主张继续履行，只能通过赔偿的方式弥补损失，所以适用的是损害赔偿的违约责任承担方式。

举个例子：甲有一辆二手车要卖给乙，双方签订了买卖合同约定了交付时间，但在交付之前这辆二手车因意外毁损灭失了。这时乙能不能说"虽然车毁损灭失了，但是你必须负责给我找一辆一模一样的车来交付给我"？行不行？不行。因为特定物独一无二不可替代，这辆车毁损灭失了，就意味着甲的债务已经无法履行，乙逼着甲继续履行就是强人所难，只能主张赔偿，不能主张继续履行。

那假如双方交易的标的物是一个种类物呢？因为种类物可以被同种类物所代替，所以某些物发生毁损灭失不会导致履行不能，这时向对方依然可以请求继续履行，适用继续履行的违约责任承担方式。

比如甲公司是小米公司，卖小米汽车，乙在网上订购了一台车。双方在买卖合同里只是确定要买某一个型号的某款车，那这个标的是种类物。在这某辆车特定化之前，甲公司生产的一批车全部因为意外毁损灭失了。这时能不能跟乙说："本来这批车里面有一辆是要交给你的，但不幸它们都毁损了，所以我们赔你钱，就不交给你车了"？行不行？不行。因为双方交易的标的是种类物，尽管这一批车发生毁损灭失了，但是下一批车如果是同型号的车，你交给我是不是依然可以实现它的目的？所以这个时候乙可以请求甲来继续履行。

当然，前面提到过，假如某辆车的车架号已经写在了甲乙的合同当中，那就是种类物在交易中被特定化了，双方买卖合同的标的变成特定物了，这个就不太一样了。刚才举的例子，是在标的被特定化之前种类物发生毁损灭失的情形。

这就是区分种类物和特定物的两个层次。

### 民事法律关系的内容

民事法律关系的内容，也就是民事法律关系当中当事人享有的民事权利和应当承担的民事义务。

民事权利和民事义务相当于是描述民事法律关系内容的基本单位。就像大家之前学过物理：长度的单位是米或者千米，重量的单位是克或者千克，力的单位是牛，功率的单位是瓦，电压的单位是伏——那么描述民事法律关系的单位，就是民事权利和民事义务。它们的重要性不言而喻。

#### 权利与义务：同一副三要素模板

既然民事权利和民事义务是民事法律关系内容的基本单位，就仍然要从主体、客体、内容这三个角度来描述它们。

**民事权利**指的是：民事主体为实现某种利益，而依法为或者不为某种行为的自由。这里需要掌握三个关键词。

主体是民事主体，包括前面提到的自然人、法人、非法人组织，都可以享有民事权利。客体是某种民事利益——它指向的是为了实现某种民事利益。内容体现为"依法为或者不为某种行为的自由"，核心词是"自由"两个字。所以权利相当于是法律赋予当事人的自由：他可以为某种行为，也可以不为某种行为。

比如甲买了部手机，通过交付取得了所有权，取得所有权以后，对这部手机相关利益的实现，法律是赋予你非常充分的自由的——你可以用它，也可以不用它，你可以送人，也可以把它卖掉。这就叫"为"或"不为"某种行为的自由，这就叫民事权利。

**民事义务**与它相对应，指的是：义务人为了满足权利人的利益，而应当为或者不为某种行为的约束。

主体是义务人，客体指向权利人的利益，指向的也是某种民事利益，内容体现为"应当为或者不为某种行为的约束"。权利的内容是自由，而义务的内容是约束——你应当为或者不为某种行为。

比如陈某借我 10 万块钱，在这个法律关系中我是债权人，陈某是债务人。对于陈某来讲，他被赋予的义务是什么？他得把这 10 万块钱还给我，以实现我的某项债权利益。陈某是应当实施一个还款的行为，这就是一种约束，这就是民事义务。

所以民事权利和民事义务都是从主体、客体、内容三个角度来讲的，而且它们形成一个对应关系。

#### 对立统一

教材里用一句话来描述民事权利和民事义务的关系：相互对立、相互联系，或者我们可以用一个词来表示——**对立统一**。学政治课的时候会听到这个词。

**一方面二者是相互对立的**，特别是在一个民事法律关系中：你的权利对应我的义务，你的权利越多，我的义务就越多，所以双方的利益处于一个对立的状态。

**但同时又要体现统一的关系。** 为什么我要负担义务？因为同时我对你们也享有权利。

教材里写了一个小例子：甲和乙签订买卖合同，甲将二手车出卖给乙，甲是出卖人，乙是买受人。站在甲的角度，他一方面享有请求乙支付价款的权利，同时有一个把车交付给乙并转移所有权的义务。站在甲的角度，我之所以负担这个义务，是因为我从你手里面拿到了价款——所以甲的权利跟义务是统一的关系。

但站在甲乙双方的角度：甲可以请求乙支付价款，同样地，乙就得负担向甲支付价款的义务。双方约定价款越高，甲的利益越大，而乙的负担越重，所以双方的利益处于一个对立的状态。

所以这个**对立**是站在民事法律关系双方当事人的角度来描述的——你们的利益是相互对立的；而这个**统一**是站在一方当事人的角度来描述的——因为既享有权利，同时也得负担义务，有得也有失。

> **提示**：听起来比较抽象，如果你不理解，那就是政治课没学好，是政治老师教得不好，不是法律老师教得不好。

#### 必要性与可能性

最后再补充教材里的一个说法。

**民事义务体现的是主体行为的必要性。** 就是你"应当为或者不为某种行为"，这叫必要性——你要违反这个义务，是要承担不利后果的。

**而民事权利体现的是主体行为的可能性。** 因为权利是一种自由嘛，你可以去行使，也可以不行使，所以它只代表一种可能性。稍微注意一下。

在民事法律关系的三要素当中，内容可以说是最为重要的，所以我们要在下一节对民事权利和民事义务做一个单独的展开。这一部分大家先简单了解这两个基本的概念。

### 本讲提到的题目

#### 主物与从物的认定

2012 年单选题：下列各组财产中，构成主物和从物关系的是（　）

A. 赵某的房屋与房门
B. 李某的手表与孙某的表带
C. 电视机与遥控器
D. 周某的汽车与车轮

**答案：C**

**解析：**

A 项不构成主物与从物关系。房门是房屋的组成部分，不是独立的物，所以它只能是物的成分。进一步判断，房门是房屋的**非重要成分**——房门卸下来可以独立存在。

B 项不构成主物与从物关系。原因是手表和表带分属于不同的当事人，不满足从物认定的第三个要件——主物与从物应当同属一人。

C 项构成主物与从物关系，是标准的主从搭配：电视机是主物，遥控器是独立的物、发挥辅助功能、且与主物同属一人。

D 项不构成主物与从物关系。车轮是汽车的组成部分，不是独立的物；而且车轮同样是非重要成分——卸下来可以独立存在。

#### 原物与孳息的关系

下列选项中，构成原物与孳息关系的是（　）

A. 水库与水库里的鱼
B. 果树与果上的果实
C. 名画的原件与复制件
D. 母牛与生产下来的牛犊

**答案：D**

**解析：**

A 项不构成原物与孳息关系。因为鱼并不是水库派生出来的——有些水库里就没有鱼，水库只是鱼的生存环境。这就跟我们都生活在空气里，不能说自然人是空气的孳息一样，这是不符合生活常理的。

B 项不构成原物与孳息关系。因为这个果实还在果树上，没有摘下来，没有和原物相分离，所以它依然是原物的组成部分。

C 项不构成原物与孳息关系。复制件本身也是独立的物，它并不是由原件派生出来的。像我们买的图书，其实每一本书都是复制件，相互之间都是独立的。

D 项构成原物与孳息关系。母牛是原物，牛犊是原物产生的收益，并且已经产下来了、和原物相分离，符合孳息"必须是两个物"的要求。
