## 知识产权概述：绝对权的共性规则与商业秘密保护
> 对应块：BLK72 | 覆盖分集：P68 | 块标题（分集名）：《第04编 第01章：知识产权概述》

接着看第四编，知识产权。

这一编在民法典里其实没什么"地位"——它没有独立成编，而是通过单行法的方式来做规范。但法硕民法的考察范围是包括但不限于民法典的内容，所以知识产权仍然属于我们必考的盘子。这一编我们要重点讲三种比较重要的知识产权：著作权、专利权和商标权。不过在介绍这三种具体的权利之前，我们先做一次公因式的提取，把它们共同的骨架抽出来，这一章就是干这件事的。

### 为什么还是要重视它

知识产权体现为对某种无形智力成果的相应权利。和我们前面讲的人格权、物权一样，知识产权也属于绝对权的范畴。既然是绝对权，采取的也就是法定主义的立法模式——这意味着权利的种类和内容都由法律作出规定。那么法律的明确规定，就是我们这一编学习的重中之重。

它在法硕考试里不是"陪跑"的。知识产权部分曾经考过八次简答题，这可不是一个小数字。只是因为编撰民法典时它没有独立成编，从 2021 年开始，它在法硕考试中的重要性有所下降。原因有两个：一方面，考试大纲对这一编的内容做了相应的删减，删除了不少考点；另一方面，从 2021 年开始，这一部分主要通过客观题的方式来考察。

但是请注意时间点：在 2025 年的时候，一些已经被删除的考点，又陆续加回到了考试大纲当中。也就是说，被删掉的考点又复活了。

所以我的判断是：在一个鼓励创新的时代，知识产权不会在沉默中死亡，它一定会在沉默中爆发——只是不知道是在哪一年爆发，说不定就是 2027 年。

> **结论**：知识产权依然保有考到主观题的可能性，大家对这一部分还是要给予相应的重视。

### 本编的骨架

这一编一共四章：第一章是概述，讲一些共性的问题和理论的问题；然后第二、三、四章分别介绍三种具体的知识产权，著作权、专利权、商标权，依次登场。

第一章概述里真正要啃的，是三块：知识产权的含义和特征、商业秘密的法律保护、还有知识产权法和反不正当竞争法的关系。

### 知识产权的含义

知识产权也是一种民事权利。既然是民事权利，它的概念就可以通过三要素来描述。大家要关注三个关键词：主体、客体、内容，再加上一个限定语"依法"。

#### 三个要素和"依法"两个字

**主体**没什么特殊性，就叫民事主体。自然人、法人、非法人组织，都可以享有知识产权。

**客体**体现为某项创造性智力成果。"智力成果"这个词是核心。我们前面讲民事法律关系的客体时就提过：客体叫智力成果，可以是作品，可以是某项发明创造，也可以是一个商标等等。

**内容**是两个字：专有。它体现为法律赋予权利人对某项智力成果的控制权——没有经过他的同意，别人不能随便利用这个智力成果。

```text
        ┌────────────┬──────────────┬──────────────┬────────────┐
        │  主体      │  客体        │  内容        │  依法      │
        ├────────────┼──────────────┼──────────────┼────────────┤
        │  民事主体  │  智力成果    │  专有        │  法定主义  │
        │ 自然人/法人│ 作品/发明创造│ 法律赋予权利人│ 权利的种类 │
        │ /非法人组织│ /商标 等     │ 对成果的控制权│ 与内容由   │
        │            │              │ 他人不得擅用 │ 法律规定    │
        └────────────┴──────────────┴──────────────┴────────────┘
```

读图：前三栏是民事权利的通用三要素，因为知识产权是绝对权，概念里还要多一个"依法"——第四栏就是它作为绝对权、采取法定主义立法模式留下的印记。

> **定义**：知识产权，指民事主体就某项创作性质的智力成果依法享有的专有的权利。

#### 广义与狭义：民法典站在哪一边

当代民法当中，知识产权的概念区分广义和狭义两个层次，区分的标准是涵盖的智力成果范围不同。

狭义上的知识产权仅指三种经典的知识产权：著作权、专利权和商标权。

广义上的知识产权泛指对各种智力成果而相应的权利，包括但不限于上述狭义的三种。

需要大家关注并且记住的是：民法典里面规定的知识产权概念是**广义**上的。尽管知识产权在民法典中没独立成编，但民法典还是通过一个条文来描述了知识产权的概念，认可了知识产权也是民事权利大家庭当中的一员。

> **结论**：《民法典》第 123 条规定，知识产权是权利人依法就下列客体享有的专有的权利。这个客体清单里，除了作品型的客体（作品）、专利权型的客体（发明、实用新型、外观设计）、商标型的客体（商标）以外，还包括其他智力成果：地理标志、商业秘密、集成电路布图设计、植物新品种等等。

所以民法典对于知识产权概念的规定，采的是广义的概念。这一条要记牢。

### 知识产权的四项特征

既然知识产权是一种民事权利，我们也可以通过要素角度来描述它的特征。对应着概念当中的关键词往下推，再补上从保护角度生出来的两项，一共四项。

主体这一项：知识产权的主体是一般主体，没什么特殊性，所以没有形成独立的特征。

#### 从要素里长出来的两项

**客体**这一项有特殊性，体现为客体的**无形性**。注意这个词。智力成果是看不见摸不着的，具有无形性的特点。

这一点和物权形成了鲜明的对比。物权也是绝对权，也是专有权，但物权的客体主要指向的是特定的物，不管是动产还是不动产，都体现为有体财产的属性；而知识产权的客体是无形的。一个有体，一个无形，这张对比牌一定要摆清楚。

**内容**这一项也有特殊性，体现为**专有性**。注意这个词——一方面我们在概念里用的就是"专有"这两个字，另一方面民法典也明确规定了"专有"这个专业术语。怎么理解？要分成两个方面：

一方面，专有性体现为**排他性**的要求。知识产权也是一种绝对权，所以也要体现"一山不容二虎"的观点。我们讲物权特征时也用过排他性这个词，叫"一物一权"；在知识产权领域也是一样的：同一智力成果上，不能存在两个以上内容相冲突的知识产权，否则就没法保证权利人专有权的行使了。

另一方面，是**独占性**的要求。权利人对这个知识成果是有一个独占的使用权的；别人没有经过许可，是不能擅自利用这个智力成果的。

> **结论**：排他性 + 独占性，就等于民法典里面所称的"专有"这个专业术语。

#### 从保护限制里长出来的两项：天时地利

知识产权作为一种民事权利，法律当然要对它进行保护。只在保护的时候会体现出个特殊性——保护要受到相应的限制。也就是说，法律对于知识产权的保护是有所克制的。

为什么有所克制？因为这一成果的推广和利用，是可以促进社会发展进步的。为了社会发展进步，知识产权的保护就要受到限制。限制有两个：一个地域的限制，叫地域性；一个时间的限制，叫时间性。这就是我常说的"天时地利"。

**地域性**，指知识产权专有权的行使范围，是在特定的国家或者地区领域内；超出这个范围，你就不能主张专有权了。这一点专利权体现得最明显：比如美国的某个公司就某项技术申请了专利权，他可以在美国范围内主张独占的使用权。但他能不能禁止中国的某个公司在中国领域内使用这个技术？不能。因为专有权的效力范围是有限制的，只能在申请专利的美国范围内去主张。假如你要在中国范围内也主张专有权，那得在中国也得去申请专利。

**时间性**，强调这种权利的保护要受到期限的限制。超出保护期限，这个智力成果就进入到了公共领域，任何人可以自由使用了，你就没有这个独占的使用权了。

不同的知识产权受到的时间限制会有所不同：

| 权利类型 | 保护期限 |
| --- | --- |
| 发明专利 | 20 年 |
| 实用新型专利 | 10 年 |
| 外观设计专利 | 15 年 |
| 商标权 | 10 年，届满以后可以自由续展 |
| 著作权（自然人作者） | 作者终身 + 死后 50 年 |
| 商业秘密 | 不受时间限制 |

专利权指向的是某项发明创造，法律对它的保护期限相对来讲是比较短的：一过了这个期限，这个技术就变成公共资源，大家可以随便利用了。商标权的保护期限相对来讲也比较短，10 年保护期，届满以后可以自由续展。著作权的保护期限相对来讲会长一些，像作者如果是自然人的话，是作者终身加死后 50 年。

当然，还有一部分特殊的知识产权，它可以不受时间的限制——比如商业秘密，只要你能够保守这个秘密，你就可以一直获得保护。所以知识产权的时间性，要具体问题具体分析，不能一概而论。

> **结论**：客体体现无形性，内容体现专有性，这两项是从概念中的要素角度描述的；而地域性、时间性，是从保护应当受到限制的角度描述的。加起来是四项特征。

### 商业秘密的含义：拆开两个关键词

知识产权这一块，还有一个广义上的东西我们必须重点补充——商业秘密的法律保护。

它的内容主要是规定在《反不正当竞争法》这部特别法里面。

商业秘密是一个专业术语，我们理解它的时候要用一个方法：拆解关键词法。拆开就两个字——第一是"商业"，第二是"秘密"。

**"商业"怎么理解？**体现为具有商业价值这个属性，也就是在商业竞争中可以给权利人带来某种优势，它是有价值的。举个例子，肯德基的配方就是一个商业秘密。尽管大家都知道肯德基这种快餐不健康，但是它吃起来就是很美味、很好吃，它可以给这个权利人带来某种竞争上的优势，可以帮他赚钱——这就是具有商业价值的属性。

**"秘密"怎么理解？**它包含两个方面的要求。

第一个要求是**非公知性**，也就是不为公众所知悉。通俗地讲就是一般人不知道。这意味着，如果是众所周知的事实，那就不属于商业秘密的范畴了。

第二个要求是**保密性**。这不仅是"现在不知道"，而且是权利人特别采取一些措施防止别人知道，使它一直处于一个非公知的状态。也就是：现在不为公众所知悉，同时采取保密措施，确保将来也不被公众所知悉。

所以理解商业秘密，重点关注三个方面：第一个，从"商业"角度要体现价值性；第二个和第三个，从"秘密"这个关键词延伸出非公知性和保密性。

> **定义**：商业秘密，指不为公众所知悉、具有商业价值，并经权利人采取相应保密措施的技术信息、经营信息等商业信息。

它的范围既有技术信息，也有经营信息。技术信息这一侧，肯德基的配方属于技术信息；像《大宅门》里面那个白加药丸的配方，它也属于技术信息，是有一定技术含量的。经营信息这一侧同样可以纳入保护范围，比如一个公司它特殊的进货渠道、它的客户名单，这也是一种商业秘密，也可以获得法律的保护。

法律当中还作了一些列举，包括设计程序、产品配方、制作工艺、制作方法、管理诀窍、客户名单、货源情报、产销策略、招投标中的标底及标书内容等等，都可以纳入商业秘密的保护范围。

把上面这个概念中的关键词做一个拆解，也就形成了商业秘密的特征。

### 侵犯商业秘密的情形

哪些行为会侵犯他人的商业秘密？我们来看教材里的内容，它分为两个层次：第一个层次是直接侵权行为，即直接实施了侵犯商业秘密的行为；第二个层次是间接侵权，虽然你没有直接实施侵权行为，但是你利用了别人的侵权成果，那也属于侵犯商业秘密的行为。

```text
侵犯商业秘密（反不正当竞争法第十条）
│
├─ 直接侵权
│   ├─ 经营者实施的行为
│   │   ├─ 没有合法持有商业秘密
│   │   │    ├─ ① 非法获取（盗窃/贿赂/欺诈/胁迫/电子侵入）
│   │   │    └─ ② 非法利用（在①的成果之上再非法利用）
│   │   └─ 已经合法持有商业秘密
│   │        ├─ ③ 违反保密义务或保密要求，擅自披露/使用/
│   │        │   允许他人使用已掌握的商业秘密
│   │        └─ ④ 教唆、引诱、帮助他人违反保密义务或保密
│   │            要求 → 有意思联络，构成共同侵权
│   └─ 其他主体实施上述行为的，也"视为"侵犯
│
└─ 间接侵权
    └─ 第三人明知或应知权利人的员工、前员工或其他主体实施
       上述违法行为，仍然获取、披露、使用或允许他人使用该
       商业秘密的
```

读图：先分"直接"和"间接"两支；直接侵权再按主体分成经营者和其他人两支；经营者这一支按"有没有合法持有"分成两层，一共四种情形。记住这个展开的思路。

#### 直接侵权：先看经营者的四种行为

为什么法律要把主体单独拎出来做区分？因为《反不正当竞争法》主要规范的是经营者的行为，那是它的地盘范围。经营者实施这类行为会破坏一个公平的竞争秩序，所以这是反不正当竞争法的核心规范内容。但其他主体实施相关行为的，也有可能构成侵犯商业秘密，所以法律一并作了规定。

先看**经营者**实施的行为，法律总共列举了四种情形。理解的时候要分成两个层次。

第一个层次是经营者**没有合法持有商业秘密**的情形，分两种行为：

一是**非法获取**他人的商业秘密。你获取这个别人商业秘密的途径本身就是非法的，包括通过盗窃、贿赂、欺诈、胁迫、电子侵入等方式来获取，这属于侵权行为。

二是**非法利用**。通过前述途径获得商业秘密以后，如果你实施非法利用的行为，那也属于独立的侵权行为。注意这是单独一层，不能被"非法获取"吸收掉。

第二个层次是经营者**已经合法持有商业秘密**的侵权，主要体现为违反保密义务的行为。比如在商业交往中，你是通过合法的途径取得了对方的商业秘密，但根据诚信的要求，你应当尽到保密义务；当时如果违反了保密义务，也可能侵犯别人的商业秘密。具体包括：违反保密义务或者相关的保密要求，擅自披露、使用或者允许他人使用已经掌握的商业秘密。

这一层次里的第四种情形是：通过教唆、引诱、帮助他人违反保密义务或者保密要求的方式，来获取、披露、使用或者允许他人使用商业秘密的，也构成侵权。也就是虽然他合法持有这个商业秘密了，但他和这个合法持有商业秘密的人存在共同的故意或者过失，有意思联络，构成共同侵权的时候，那他也得承担侵权责任。

这四种情形对照着看会更清楚：

| 层次 | 情形 | 通俗理解 |
| --- | --- | --- |
| 没有合法持有 | 非法获取 | 靠盗窃、贿赂、欺诈、胁迫、电子侵入等非法途径拿到 |
| 没有合法持有 | 非法利用 | 拿到之后还继续非法用，是独立的一档 |
| 已经合法持有 | 违反保密义务 | 合法拿到，但擅自披露、使用或允许他人使用 |
| 已经合法持有 | 教唆、引诱、帮助他人违反保密义务 | 与负有保密义务者有意思联络，构成共同侵权 |

再来看**其他主体**实施的行为。如果其他主体虽然不是经营者，但是实施上述行为的，也构成侵权。这里要注意法条用的一个词：叫"视为"。为什么法律要单独做出规定，不能把它写到一起吗？因为这部分内容本来不属于《反不正当竞争法》管辖的范围——那部法主要是管经营者的行为——只是如果其他主体实施上述行为，也需要承担侵权责任，所以这个法律就一并作出规定了。

#### 间接侵权：第三人

第三人明知或者应知商业秘密权利人的员工、前员工或者其他主体实施上述违法行为的，仍然获取、披露、使用或者允许他人使用该商业秘密的，也可以视为侵犯商业秘密的行为。

虽然你没有直接实施上述侵权行为，但别人实施侵权行为获得的成果，你同时也享用了，那你也得承担侵权责任。这就是间接侵权。

### 知识产权法与反不正当竞争法的关系

这是一个理论问题。要从两个角度来理解。

#### 保护：追究不正当竞争行为人的责任

第一个角度是《反不正当竞争法》要对知识产权进行保护。因为侵犯别人的知识产权，特别是侵犯别人的商业秘密的行为，会构成一个不正当的竞争行为；通过追究这个不正当竞争行为人的责任，就体现出了对知识产权的保护。

比如刚才讲的侵犯商业秘密的行为，当事人要承担侵权责任——一方面维护了商业秘密权利人的权利，另一方面也维护了公平的竞争秩序。

在 2025 年修订《反不正当竞争法》的时候，对混淆行为作了相应的修订。混淆行为一方面是侵犯知识产权的，另一方面也是一种不正当的竞争行为。

什么叫混淆行为？因为现代社会是一个流量经济时代，一些粉丝比较多的 IP 是很值钱的。假如你能通过蹭热点、蹭流量、搭便车的方式跟别人发生混淆，给自己带来一些消费者的关注，那会构成一种不正当的竞争行为，同时也是侵犯别人知识产权的行为。

教材里补充了混淆行为的具体类型，也是去年考试分析里新修订的内容，分为四个方面：

1. **擅自使用和他人有一定影响的商品名称、包装、装潢等相同或者相近似的标识**——这就是蹭别人的流量，属于不正当的竞争行为。

2. **擅自使用他人有一定影响的名称、姓名**。这里要拆开看：名称既包括全称，也包括简称、字号；姓名既包括正式姓名，也包括笔名、艺名、网名等别名，都可以纳入保护的范围。这一点其实也是我们 2025 年修订《反不正当竞争法》的一个体现——把简称、笔名、艺名、网名等等纳入进来，是和民法典相对接的。我们在前面讲人格权的时候提到过，姓名权的保护范围既包括正式的登记名称，也包括具有一定社会影响力的简称；那被他人误用、从而导致混淆的这些别名，同样在保护范围之内。

3. **擅自使用他人有一定影响的域名主体部分、网站名称、网页、新媒体账号名称、应用程序名称或者图标等等**。这里面要特别注意"新媒体账号名称"——比如微博上的大V、B站的 up 主，包括小红书上粉丝比较多的一些账号名称，如果别人蹭这个流量、蹭这个热点，也可能构成一种不正当的竞争行为。

4. **擅自将他人的注册商标、未注册的驰名商标作为企业名称中的字号使用**，或者将他人的商品名称、企业名称、注册商标、未注册的驰名商标等设置为搜索关键词——是不是也是想蹭别人的流量？同样属于不正当的竞争行为。

让这些实施混淆行为的人承担责任，也就是对知识产权的一种保护，这是第一个层次。

#### 限制：萝卜和大棒一起用

第二个角度是《反不正当竞争法》对于知识产权还要进行相应的限制。既要保护，也要限制，萝卜和大棒要一起用。

原因在于：知识产权是绝对权，如果对知识产权的保护过于周全，那必然会影响技术的推广和利用，进而有损社会公共利益的实现。所以法律对知识产权也要进行限制——如果你对这个技术已经构成某种垄断了，那这个时候法律就没法对你进行保护了，你就不能再主张所谓的专有权了。

> **结论**：理解这两部法的关系，就抓住两个关键词——一面是保护，一面是限制。两手都要用，缺一不可。

### 本章要掌握的三块内容

回到这一章的骨架：首先是知识产权的含义和特征；然后是商业秘密的法律保护；最后是知识产权法和《反不正当竞争法》的关系。后面第二、三、四章的著作权、专利权、商标权，都是在这块公因式的地基上往上盖的具体房子。

### 本讲提到的题目

#### 题目：哪些属于知识产权的客体

**题目**：下列选项中，属于知识产权客体的是（　）。

A. 地理标志
B. 植物新品种
C. 商业秘密
D. 集成电路布图设计

**解析**：民法典里面规定的知识产权是广义上的，所以这个客体包括但不限于狭义知识产权的客体。除了作品、发明、实用新型、外观设计、商标之外，还包括其他智力成果：地理标志、商业秘密、集成电路布图设计、植物新品种等等。四个选项全都在这个清单里。

> **提示**：这道题是在民法典颁布以后考察的。民法典颁布之后考知识产权概念，只能考民法典里面规定的那个概念，也就是广义的这一版。

**答案**：A、B、C、D 全选。

#### 题目：哪些知识产权没有时间限制

**题目**：下列知识产权中，对其法律保护没有时间限制的是（　）。

A. 甲公司的保密配方
B. 乙制作的电影《问道昆仑》
C. 丙企业的驰名商标"云南白药"及其图形
D. 丁行业协会的"阳澄湖大闸蟹"地理标志

**解析**：这道题问的是时间性的例外情形。

- A 项，保密的配方属于商业秘密，可以不受时间的限制——只要能一直守住这个秘密。
- B 项，电影是一个视听作品，是要受到保护期限的限制的。
- C 项，驰名商标也受到保护期限的限制。尽管届满以后可以自由续展，但是你要不续展的话，那就没有商标权了，所以还是受时间限制。
- D 项，地理标志同样是不受时间限制的。

**答案**：A、D。

#### 题目：甲公司买通乙公司员工

**题目**：甲公司买通乙公司的员工，获得乙公司的产品制造方法以及客户名单等保密信息。其后，甲公司以乙公司的名义和乙公司的客户进行交易。甲公司的行为侵害了乙公司的哪些权利（　）？

A. 专利权
B. 商业秘密
C. 名称权
D. 隐私权

**解析**：

- A，没有侵犯专利权。一方面这里面根本没有提到专利权；同时专利权它是具有公开性特点的，专利技术都是向社会公开的，不需要买通员工来窃取。
- B，侵犯了商业秘密。而且它属于和负有保密义务的主体有意思联络、构成共同侵权的方式：买通内部员工，这属于有意思联络的共同故意。
- C，侵犯了名称权。因为甲公司擅自以乙公司的名义和乙公司的客户进行交易，这是擅自冒用别人的名称来实施民事活动，是通过冒用的方式来侵权、假冒他人。
- D，没有侵犯隐私权。因为隐私权的主体仅限于自然人，乙公司是不可能享有隐私权的。

**答案**：B、C。

## 著作权的第一层地基：含义、特征与作品边界
> 对应块：BLK73 | 覆盖分集：P69 | 块标题（分集名）：《第04编 第02章：著作权（01）》

前面把知识产权的通用制度过完了，从第二章开始，我们依次介绍三种比较重要的知识产权：著作权、专利权和商标权。

著作权这个词，生活当中你可能也听过——它还有个名字，叫**版权**。作家余华写了一部小说叫《活着》，余华对这部小说享有著作权；李健写了一首歌曲叫《传奇》，李健对这首音乐作品也享有著作权。权利人针对某一个作品所享有的相应权利，就是我们这一章要谈的东西。

### 知识产权的考查框架：两个层次、五个考点

每一种权利的学习都要分成两个层次。

第一个层次从理论层面，了解它们的含义和特征；第二个层次从法律规范层面，关注每一种权利的主体、客体、内容，加上保护这四个基本点。

```text
著作权　　专利权　　商标权
   |
   +-- 第一层：理论层面
   |      含义、特征
   |
   `-- 第二层：法律规范层面
          +-- 主体
          +-- 客体
          +-- 内容
          `-- 保护（2025 年考试分析新增考点）
```

有一点先提醒：知识产权的变动制度目前还没有纳入法硕的考查范围。但保护制度是例外，它是 2025 年修订考试分析的时候新加进来的考点，其实也是一个"复活"的考点，所以后面我们会重点讲。

> **结论**：每一种知识产权都是五个考点——理论层面掌握含义与特征，规范层面掌握主体、客体、内容、保护这四个基本点。

### 著作权的含义：主体、客体、内容

既然著作权是一种民事权利，界定它的概念就要走三要素。大家关注三个关键词：主体、客体、内容。

> **定义**：著作权，是指著作权人对于文学、艺术和科学领域内的作品依法享有的各项专有权利。

| 关键词 | 对应概念 | 说明 |
| --- | --- | --- |
| 主体 | 著作权人 / 权利人 | 没什么特殊性，体现为一般主体：自然人、法人、非法人组织都可以成为著作权人 |
| 客体 | 作品 | 一种智力成果，限于文学、艺术和科学领域内 |
| 内容 | 专有 | 著作权属于绝对权，概念中还要带上"依法"二字 |

客体这两个字要展开说。作家写的小说，这是文学作品；作曲家写的音乐，这叫艺术作品；教授写的论文，这叫科学领域内的作品。包括你们写的本科毕业论文，以及未来要写的研究生毕业论文，都是一个作品，可以依法取得著作权。

内容呢，体现为"专有"两个字——我们在前面讲知识产权概念的时候，内容也是"专有"这两个词。因为著作权本身也是一种绝对权，所以它的概念当中还会包含"依法"两个字。权利人依法对文学、艺术、科学领域内的作品享有的各项专有权利，就是著作权的概念。

### 著作权的特征：通用四项，特殊两项

著作权作为一种知识产权，首先得具备知识产权的通用特征。但和专利权、商标权相比，它有两处非常特殊的地方，重点就在这两处。

#### 知识产权的通用特征

从要素层面看，客体具有无形性，内容具有专有性；从权利保护的角度看，它要受到两个方面的限制，一个是地域的限制，一个是时间的限制。著作权当然也具备这些。加上前面讲过的两项，通用特征一共四项。

#### 特殊之处一：内容上的双重性

著作权既包含人身权，也包含财产权。理解这个"双重性"，最好的办法是看两个词的分量。

"版权"这个词常常是在英美法系国家使用，它体现的是对于权利当中财产价值的一种重视；而大陆法系国家更喜欢用"著作权"这个词，因为它还强调里面人身权的属性——毕竟这个作品是作者思想的一种表达，它是具有某种人身属性的。我国用的是"著作权"，所以既包含人身权，也包含财产权。而专利权和商标权主要体现为财产权。

| 权利类型 | 习惯用语 | 体现的侧重 |
| --- | --- | --- |
| 著作权（英美法系） | 版权 | 只突出财产价值 |
| 著作权（大陆法系） | 著作权 | 人身权与财产权并重 |
| 专利权、商标权 | —— | 主要体现为财产权 |

#### 特殊之处二：取得上的自动产生

注意这个词，叫**自动产生**。也就是说，作品只要创作完成，就可以直接取得著作权，既不需要发表这个作品，也不需要办理什么登记的手续。

> **提示**：这正好接上前面讲民事法律事实时的那条线——作品的创作行为是一个事实行为，只要创作行为完成，就可以依法取得著作权。

相较而言，专利权和商标权都必须通过申请的方式，由相关的主管部门去授予权利，才能够取得知识产权。所以专利权和商标权都具有行政授予性的特点，跟著作权的自动取得形成了鲜明的对比。

我们来看一个小例子。李某于 2023 年 8 月 4 日创作完成小说《别来烦我》，2024 年 3 月 5 日发表在某文学刊物，后来被张某改编成了剧本。那么，李某什么时候可以取得对这部小说的著作权？

```text
  2023-08-04            2024-03-05           其后
  创作完成《别来烦我》    某文学刊物发表      张某改编成剧本
        `-- 著作权在此刻自动产生，不待发表，也无须登记
```

读图：时间轴上真正起作用的只有第一个节点。后面发生的发表和被改编，都不影响著作权产生的时间点。

答案是 2023 年 8 月 4 日创作完成的时候就直接取得，这叫自动产生。

> **结论**：著作权的特征一共六项——前四项是知识产权的通用特征（客体无形性、内容专有性、地域限制、时间限制），后两项是著作权相较于专利权、商标权所特有的内容双重性与取得上的自动产生。

### 作品：三个要件层层设卡

说完理论层面的含义与特征，接下来进入著作权的相关规范，第一个基本点是客体，也就是作品的认定。

"作品"这个词生活当中也听到过，但从法律角度讲，它是著作权领域的一个专业术语。

> **定义**：作品，是指文学、艺术和科学领域内具有独创性并能以一定的形式表现的智力成果。

这个定义里的三个关键词，正好就是作品应当满足的三个要件。三道关卡要一道一道过：

```text
待判断的对象
        |
        v
    (1) 是人的智力创造活动产生的成果吗？
        |
        +-- 否 --> 不是作品
        |
       是 |
        v
    (2) 能以一定的形式表现出来吗？
        |
        +-- 否 --> 不是作品
        |
       是 |
        v
    (3) 是自己思想观念的表达、而非抄袭吗？
        |
        +-- 否 --> 不是作品
        |
       是 |
        v
     成立作品
        |
        +-- 违法与否，不影响它成为作品
```

读图：三道关卡是递进的，前一道过不去就不用往下看；最后一根支线说明，成立作品和内容是否合法是两件事。

#### 要件一：智力成果

第一个要件，作品是人的智力创造活动产生的成果。毕竟作品也属于知识产权客体的范围，所以它属于智力成果。

> **易错点**：这意味着单纯的劳动不受著作权的保护。

比如说有的同学在复习法硕的时候没有掌握科学的方法，想要死记硬背，就把这个不薄的教材认真地抄写了一遍，花了好几个月的时间。尽管这个抄写的版本付出了很多的劳动，能不能构成一个作品？答案是不能，因为它不是智力活动产生的成果。

同样的，纯粹的自然风光和声音尽管极具欣赏价值、可以说是大自然的杰作，也不能纳入作品的范畴。比如甘肃张掖的七彩丹霞，看起来非常绚丽；包括我去年去的贵州织金洞这个大溶洞，里面的景观也是非常壮观。但这些能不能成为著作权保护的对象？不能，因为它不是人的智力成果。

#### 要件二：可表现性

作品要通过一定的形式表现出来。这意味着单纯的思想不能成为著作权保护的对象。

比如奥运会开幕式火炬点燃仪式的创意，如果没有表达出来，就不能够成为著作权保护的对象，因为它只是头脑当中的思想。包括某个教授对某个学术问题的研究构思了一个非常完整的框架体系，但他述而不作，没有把这个思想表达出来、没有写成论文，那这样的话也不能成为著作权保护的对象。

所以作品必须要具有可表现性。但这个表现的形式可以是多种多样的：小说通过文字的形式来表现，音乐通过音符的方式来表现，照片通过图像的方式来表现，电影通过视频的方式来体现——都是通过不同的方式表现作者的某种表达。

#### 要件三：独创性

第三个是实质要件：作品要具有独创性。

> **易错点**：独创性跟创造性不一样。它体现的是形式上的独创——只要不是抄袭的结果，是你自己思想观念的一种表达，就可以成为著作权保护的对象。所以这个门槛相对来讲还是比较低的。

比如四岁的小女孩，结合平时父亲做饭的形象创作了一幅画，叫《我的爸爸》，作为生日礼物送给了爸爸。这幅画从艺术角度讲不一定水平那么高，但它体现的是四岁小女孩一种独特的思想的表达，同样可以成为著作权的客体。

包括你们写毕业论文，在装订的时候第一页叫独创性声明——你要做出一个承诺：这个论文是你自己写的。你看学校有没有让你做一个独创性的声明？学校对大家的期待不敢那么高，因为不要说学生写的论文了，好多教授写的论文在学术上也没什么创新性。所以从法律角度讲，只要是具有独创性的作品，就可以取得著作权。

不过，独创性虽然门槛比较低，但它也是有门槛的。我们看第二个例子。

甲出版了一本图书，叫《舌尖上的中国》，汇编了六篇关于美食的散文——当然这个"舌尖上的中国"这个名字是甲自己取的。后来中央电视台制作了同名纪录片《舌尖上的中国》，来介绍全国各地的美食，我相信不少同学可能都看过这个纪录片。后来甲就把中央台给告了，说你在创作这个纪录片的时候用的名字"舌尖上的中国"这六个字是我先想出来的，你用的时候也不跟我打个招呼，也不给我付钱，侵犯了我的著作权。

我们来看一下，"舌尖上的中国"这六个字能不能成为一个作品？尽管它也是智力成果——得有点文化才能想得出来；而且具有可表现性；关键是这六个字有没有独创性？

法院的最终认定是没有独创性。

> **易错点**：理由在于——"舌尖上的中国"只是六个汉字，它只是一个词，甚至都不构成一句话，它缺乏相应的长度和必要的深度，所以不具备独创性的要求，进而不能享受著作权的保护。

这意味着中央台用这六个字，不需要经过甲的许可并支付报酬。

为什么？因为汉语是要表达人的思想的，有的时候在表达某个意思的时候，可选择的汉语其实是有限的。假设把作品的范围给他扩充得过于宽泛的话，会影响汉语表达的这样一个功能的发挥。比如每年在网络上都有很多热词，像"人间不拆""不明觉厉"等等——它们不是成语，是网友创造出来的。这些词汇能不能享有著作权？当然不能。网友可以随便去用，如果能允许某个人垄断享有专有权的话，它会影响汉语的正常功能的发挥。

所以"舌尖上的中国"这六个字，即便你想了很久才想出来，因为它缺乏必要的长度和深度，它并不具备独创性的要求，进而不能成为一个著作权保护的作品。

> **结论**：作品应当符合三个要件——它是智力成果，它具有可表现性，它具有独创性。三个要件，缺一不可。

### 违法作品能不能取得著作权

这里给大家补充一个理论上的特点问题：违法作品能不能取得著作权？这个问题也是我在讲导学阶段课程的时候，最后留的一道思考题。当时举的例子是《欲望都市》——好多情节描写得非常生动形象，如果没有一定的想象力和阅历，是写不出这样的小说的。老马写出的这样一个小说，就是一个违法作品。

我国著作权法的规范，对这个问题经历了一个变化的过程。

**第一个阶段是 2010 年之前。** 著作权法第四条第一款曾经规定：依法禁止出版传播的作品，不受本法的保护。这意味着根据当时著作权法第四条的规定，它是不能取得著作权的，体现的是对公序良俗的维护。

后来这个条文被美国起诉到了 WTO，认为这样的规定不符合《伯尔尼公约》中有关作品应当自动获得保护的一般规定。理由很清楚：一个作品是不是违法作品，不同的国家可能会有不同的评判——比如这个淫秽作品在日本可能是合法的，但在中国可能就是违法的；那就不符合国际公约当中作品应当自动获得保护的规定了，因为你某个国家可能会进行审查。

而且，同一个国家在不同的时期，对一个作品是不是违法，也会有不同的评判标准。比如在七八十年代，像邓丽君的歌曲就是靡靡之音，都是些淫词艳曲；但是放到现代的社会背景下去看，相比一些网络歌曲，邓丽君的歌是多么的清新脱俗。所以给作品增加一个违法性的要件审查，是不符合国际公约当中"作品应当自动获得保护"的相关规定的。

后来 WTO 争端解决机构裁决我国败诉。2010 年 2 月，我国专门修订了著作权法，把刚才讲到的第四条第一款这个条文删除了。

> **结论**：在现行著作权法中，违法作品当然可以成为著作权保护的作品。也就是说，作品的认定不需要符合"合法性"这个要件，它也可以依法取得著作权。

这就带来一个应用场景。假设车某看了这个小说以后觉得写得太好了，于是就把这个小说上传到网络上来传播。马某能不能追究车某的侵权责任？可以。因为车某的行为侵犯了马某的信息网络传播权——这种著作财产权。也就是说，违法作品它也是作品。

> **易错点**：但违法作品享有著作权，不等于违法作品可以随便传播。

著作权法规定，国家可以禁止或者限制这类作品的出版传播。换句话说，你自己私下鉴赏一下就可以了，能不能公开进行出版或者传播？是不可以的。这仍然是出于对公序良俗的维护。

这就是违法作品能不能取得著作权，也正式回应了我们在导学阶段给大家留下的那个疑问。

### 作品的范围：正面九类，反面三类

讲完了作品的概念，接下来从法律规范层面了解作品的具体范围。这个范围我们要从正反两个方面来界定：先从正面界定受保护的作品范围，再从反面排除不受著作权保护的对象。

```text
作品的范围
├─ 正面：受著作权法保护
│    ├─ 作品本身
│    ├─ 作品的数字化形式
│    └─ 九类作品
└─ 反面：明确排除
     ├─ 官方文件及官方正式译本
     ├─ 单纯的事实消息
     └─ 历法、通用数表、通用表格和公式
```

读图：正面回答"什么算作品"，反面回答"什么看着像成果却不给保护"，两头一夹，边界才完整。

#### 正面：作品本身和它的数字化形式

根据著作权法的规定，作品及其数字化形式受著作权保护。一方面作品本身受著作权保护，同时它的数字化形式也受著作权保护——这是数据网络时代一个特殊的规范需求。

现在大家看书的时候，好多同学都不喜欢看纸质书了，喜欢看电子书，这就叫作品的数字化形式。我记得我在上中学的时候，听音乐要买那个磁带；那现在大家听音乐，是不是在手机里面直接听这个数字化的版本？所以数字化的形式也可以受到著作权的保护。

那作品又包含哪些具体的类型呢？著作权法里面专门做了列举，总共列举了九项。

| 序号 | 类型 | 身边的例子 |
| --- | --- | --- |
| 1 | 文字作品 | 小说、论文、本科及研究生毕业论文 |
| 2 | 口述作品 | 即兴的演讲报告、授课、律师法庭辩论的发言 |
| 3 | 音乐、戏剧、曲艺、舞蹈、杂技艺术作品 | 歌曲、京剧豫剧等剧种作品、春晚的小品相声、舞蹈、杂技 |
| 4 | 美术、建筑作品 | 绘画、书法；中国人民大学的明德楼 |
| 5 | 摄影作品 | 手机拍照 |
| 6 | 视听作品 | 电影、电视剧、短视频等其他视听作品 |
| 7 | 工程设计图、产品设计图、地图、示意图等图形作品和模型作品 | 理工科同学的毕业设计；古建筑模型 |
| 8 | 计算机软件 | WPS 办公软件 |
| 9 | 符合作品特征的其他智力成果 | 人工智能创作的文章、音乐、视频 |

有几项要特别说一下。

**曲艺不属于口述作品。** 第三项虽然表面上看起来也是通过口头方式呈现的，但它并不属于口述作品的范畴——比如说德云社的相声，它就是一个曲艺作品，而不是一个口述作品。毕竟相声讲究说学逗唱，它是一种艺术表现形式。相声、快板、大鼓、评书这些，都是以说唱为主要表现形式的曲艺作品。

**视听作品的名称变了。** 第六项，在 2020 年之前，这种作品叫"电影作品和以类似摄制电影的方式创作的作品"，听起来很啰嗦，所以在 2020 年修订著作权法的时候，把它改称为"视听作品"，非常地言简意赅。电影相对来讲比较好理解，大家春节期间可能去看了一些新的电影；包括我们喜欢追的剧，电视剧作品它也是视听作品，同时还包括其他视听作品，像现在一些视频平台上的短视频，它本身也可以成为一个视听作品。

**模型作品是单独的作品。** 第七项，图形作品方面，像工程师画的产品设计图，包括我们理工科同学在毕业的时候做的毕业设计，它都可以成为一个图形作品。模型作品也可以称为作品——在这个寒假期间我带孩子去了趟先农坛，那里的北京古建筑博物馆里面就有北京天坛，包括山西应县木塔这些比较经典的古建筑的一些模型，那这个模型本身它也是一个单独的作品。

**软件享受自动保护的优待。** 第八项，计算机软件也属于作品的保护对象。大家用电脑、用手机会经常遇到各种各样的软件，我生活当中用得最多的软件是 WPS，这个办公软件是由北京金山公司开发的，它也可以成为作品的范畴。计算机软件通过著作权进行保护，一个好处就是它可以享受这个自动保护的优待——只要软件开发完成了，即使没有进行版权的登记，也可以依法取得著作权。它保护的是码农的这样一个劳动成果。

**第九项是为 AI 准备的。** "符合作品特征的其他智力成果"是一个独立条款，是 2020 年修订著作权法时特别增加的，用来应对我们现在人工智能所创作的作品。现在人工智能非常发达，不仅写文章写得好，作曲做得也很棒，包括那些 AI 软件还可以做视频。那只要符合这个作品的构成要件的，也可以成为作品的具体范畴。

#### 反面：三类不受著作权法保护的对象

以下三种情形，尽管可能付出了某种智力成果，但不受著作权法保护——立法意图就是鼓励这些成果的传播。

| 排除类型 | 具体所指 | 为什么要排除 |
| --- | --- | --- |
| 官方文件及官方正式译本 | 法律法规，国家机关的决议、决定、命令和其他具有立法、行政、司法性质的文件，以及官方正式译本 | 方便法律文件的传播 |
| 单纯的事实消息 | 正在发生的重大事件本身的消息 | 既方便消息广泛传播，也方便新闻报道正常开展 |
| 历法、通用数表、通用表格和公式 | 化学元素周期表、数理化公式 | 属于公共的知识财富 |

**官方文件与官方正式译本。** 法律法规、国家机关的决议、决定、命令和其他具有立法、行政、司法性质的文件，以及官方正式译本。注意"官方"这个词——它可以是指立法性质、行政性质和司法性质的文件。法律凝聚了社会各界以及法学专家的智力成果，但这个法律一旦颁布，它有没有著作权？没有，网上可以随便下载，出版社也可以随便出版，因为这是为了方便法律文件的传播。行政性质的文件同样没有著作权，在网上公开以后可以随便下载传播。

司法性质的文件也一样。比如人民法院作出的生效判决——我记得前两年我在研究一个关于担保的问题的时候，看到的那个判决总共有六万字，相当于两篇硕士论文的篇幅。大家想想，法官在写这个判决的时候肯定是倾注了大量的心血，甚至比写他自己的硕士论文都用心。但是这个判决一旦做出，有没有著作权？没有的，网上可以直接下载，写论文的时候可以直接引用，因为这是司法性质的文件、是官方文件。

至于官方的正式译本，注意只有官方的正式译本不受保护。比如民法典颁布以后，把民法典翻译成了英文、日文、韩文等不同文字的版本，来方便国际社会了解中国的民法典，这个官方的正式译本它就没有著作权，可以随便下载——大家可以下载一个民法典的英文版本，一边学法律一边学英语。但是如果是某个教授自己把这个民法典翻译成了韩文或者其他文字，那这个时候就有著作权了，因为某个教授翻译的版本它并不是官方正式译本。

> **易错点**：所以"官方"这两个字要盯紧，判断的落点始终在这里。

**单纯的事实消息。** 大家经常看一些新闻报道，里面会涉及一些正在发生的重大事件，这些事实消息本身是没有著作权的。一方面可以方便这个消息的广泛传播，另一方面也可以方便新闻报道的正常开展——不能说这个事实消息是你先披露出来的，别人就不能跟进报道了，这个是不合适的。但是如果是要传播报道别人采编的时事新闻，应当注明出处，要尊重一下别人的劳动成果。

这里我特别想和大家分享一个例子。前段时间召开的米兰冬奥会上，中国运动员谷爱凌获得了自由式滑雪的冠军，非常的厉害；而且她也是中国家长非常期待的那种德智体美劳全面发展的典范。在接受采访的时候，谷爱凌讲了一句话，我觉得很经典，可以和大家一起来分享。她是用英文讲的：

> "I train like I never won, and I compete like I never lost."

尽管讲的不是那么标准，但是我想大家可以听懂这个意思——像从未赢过那样去训练，然后像从未输过那样去参加比赛。

其实啊，不仅是体育运动，大家做任何事情，包括复习考研，也都得具备这样的心态。就是我们在平时复习的时候，要把自己当成什么都不懂的一个状态去复习，每一个考点都要扎扎实实地去理解学习；然后在参加考试的时候呢，得轻装上阵，得一种舍我其谁的霸气，你心里面要暗示自己：我就是研究生啊，北大清华五院四系，我值得拥有。要有这种心态，才能够考出最好的成绩。

> **易错点**：这里讲的不受保护的对象主要指的是单纯的事实消息。假如说是新闻评论——你看这里面它就包含着作者的观点了——那它就不是单纯的事实消息了，就可以依法享有著作权了。

**历法、通用数表、通用表格和公式。** 特别是"通用"这个词，非常核心。要点是通用的，它体现为一种公共的知识财富。比如大家学习数理化的时候，经常要学习一些数理化的公式，包括我们在学习化学的时候都见过的化学元素周期表。你看，尽管这里面也包含着相关研究人员的智力成果，但是它既然是通用的知识，那就没有著作权了，为的是方便这个知识的广泛运用和传播。

### 真题演练：把摄影作品临摹成油画参赛

正反两面都讲完了，我们简单看一道典型的真题。

> **题目**：甲未经乙的许可，将乙的摄影作品临摹成一幅相同主题的油画。甲在临摹的时候对背景做了细微的改动，然后将这幅油画参加比赛并获奖。请判断：甲以该油画参赛的行为是否合法？该油画是否能够取得著作权？

先来看甲创作的油画能不能取得著作权，就要看它能不能符合作品的构成要件。

第一，它是智力成果吗？当然是，它是一个美术作品。第二，它有可表现性吗？当然有，是通过绘画的方式来表现的。第三，它具有一定的独创性吗？也就是说，甲在创作这幅油画的时候是临摹了乙的摄影作品，而且只对背景做了细微的改动，能不能认为它没有独创性？

注意，是不能的。尽管它只是对背景做了细微改动，但是甲创作的油画和乙的摄影作品是完全不同的作品表现形式——乙的作品是一个摄影作品，而甲创作的是一个油画，是一个美术作品，是完全不同的表现形式，所以当然具有独创性了。

这里可以联想到去年一个非常火爆的新闻：河南有个村子里有一位非常优秀的青年画家，把照片里的场景画成油画，从表现的结果来看，可能跟照片拍出来几乎是一模一样。但大家想想，油画本身和照片是完全不同的作品表现形式。只要你有手机就能拍，这是摄影作品；特别是在把照片里的画面一笔一笔画成油画这件事上，尤其的难。所以油画和摄影作品是不同的作品表现形式，它当然具有独创性。

所以这幅油画可以具有独创性，受到著作权的保护。

> **结论**：注意，这两个结论是不冲突的。

一方面，甲创作的油画本身可以成为一个作品，受到著作权的保护。这意味着别人擅自要去复印、发行他的油画的话，甲可以追究对方的侵权责任。

但同时呢，因为甲在创作这个作品的时候借鉴了别人的作品，改编了乙的摄影作品，所以要经过乙的同意并支付报酬。而甲没有经过一定的许可，就在乙的摄影作品基础上进行再创作，那侵犯了乙的著作权——我们后面会讲到，侵犯的是乙的改编权和获得报酬的权利。所以甲的行为同时又是一个侵权行为。

这道题应该选的是 C 选项。

这里可以跟我们前面讲过的一个问题关联起来，就是违法作品有没有著作权。违反公序良俗的作品是违法作品，侵犯别人合法权益的作品也是违法作品，但都不影响它取得著作权。

### 本讲提到的题目

**导学阶段留下的一道思考题：违法作品能不能取得著作权？**（以《欲望都市》为例，情节生动，需要想象力和阅历才能写出）

答案：可以取得。理由有两条，一条是规范变迁，一条是后果推演。

- 规范上，2010 年之前著作权法第四条第一款曾规定"依法禁止出版传播的作品不受本法的保护"，但这一款因不符合《伯尔尼公约》中作品应当自动获得保护的一般规定，在美国诉我国的 WTO 争端中败诉后，已于 2010 年 2 月修订时删除。现行法下，合法性不是作品的构成要件。
- 后果上，违法作品是作品，其信息网络传播权这类著作财产权照样受保护，他人擅自上传传播的，权利人可以追究侵权责任。

同时别忘了另一半：国家可以禁止或者限制这类作品的出版传播，私下鉴赏可以，公开出版传播不行。

**典型真题：甲未经乙许可临摹乙的摄影作品参赛**（背景做了细微改动，油画获奖）

答案：C。

解析分两问。第一问，油画能不能取得著作权——能。智力成果、可表现性、独独创性三个要件都满足；即便只是临摹并对背景做了细微改动，油画与摄影作品在表现形式上完全不同，因此具有独创性，受著作权保护。第二问，参赛行为是否合法——不合法。甲是在乙的摄影作品基础上进行改编再创作，未经许可即行使，侵犯了乙的改编权和获得报酬权。

关键在于两个结论并不矛盾：自己享有著作权，和自己构成侵权，可以同时成立。

## 著作权主体与特殊作品的著作权归属
> 对应块：BLK74 | 覆盖分集：P70 | 块标题（分集名）：《第04编 第02章：著作权（02）》

著作权的内容前面已经捋完了，接下来我们看主体。这一块要回答一个特别朴素的问题：一部作品摆在那儿，到底谁有权、有哪些权。

主体这块的讲法是三步走：先看分类，再看原始主体怎么确定，最后是各类特殊作品的归属规则。分类是个纯理论问题，好记；真正要下功夫的是原始主体的确定规则——作品出来了，谁能原始取得著作权，这一条判断不清楚，后面特殊作品那一堆归属规则就没有落脚点。

### 著作权主体的三种分类

著作权主体的类型是个理论问题，基于不同的标准会有不同的分类，一共三种分法。

**第一种，按著作权的取得方式，分原始主体和继受主体。**

> **定义**：原始主体是基于作品的创作行为而直接取得著作权的人。余华写小说《活着》，这个小说的创作行为，他可以直接取得著作权；李健创作歌曲《传奇》，基于这个创作行为，李健原始取得著作权。都叫原始主体。

> **定义**：继受主体是通过受让、继承、受赠等方式来取得著作权的人。

要说清继受主体为什么只能沾著作财产权这一边，得回到著作权的内容双重性。前面讲过，著作权既包含人身权，也包含财产权；人身权具有专属性，是不能转让的，所以人身权原来只有原始主体享有。而财产权就没有人身专属性了，它是可以自由进行流转的——这就是继受主体存在的空间。

> **注意**：继受主体仅限于著作财产权的主体。

举个例子就清楚了。余华创作小说《活着》，可以依法取得著作权，那这里面的著作人身权只能由余华来享有；但是余华可以把部分著作财产权转让给别人，比如说他可以把这本小说的改编权转移给某个公司来拍电影、拍电视剧。这个公司取得了余华这部小说的改编权，它就是一个继受主体。

更接地气的例子是《凡人歌》。正午阳光出品的一部讲中年危机的电视剧，为了方便这个作品在网络上传播，正午阳光就把《凡人歌》这部电视剧的信息网络传播权独家转让给了腾讯视频平台。腾讯这个视频平台取得了《凡人歌》的信息网络传播权，它就是一个继受主体。

**第二种，按著作权人所具有的国籍，分本国主体和外国主体。**

通俗地讲，中国人包括中国的公司创作的作品，著作权人就是本国主体；外国人包括外国的公司创作的作品，著作权人就是外国主体。很好理解。

**第三种，按主体享有著作权的完整程度，分完整主体和部分主体。**

如果权利人享有的著作权是完整的，既包含人身权又包含著作财产权的，这叫完整主体；如果只享有某种著作财产权，那就是部分主体。原始主体常常都是完整主体，而继受主体常常只享有某种著作财产值，他就是个部分主体。

| 分类标准 | 主体类型 | 判断要点 |
| --- | --- | --- |
| 著作权的取得方式 | 原始主体 | 基于创作行为直接取得，如余华《活着》、李健《传奇》 |
| 著作权的取得方式 | 继受主体 | 通过受让、继承、受赠取得，**仅限于著作财产权** |
| 著作权人的国籍 | 本国主体 | 中国人、中国的公司创作的作品 |
| 著作权人的国籍 | 外国主体 | 外国人、外国的公司创作的作品 |
| 享有著作权的完整程度 | 完整主体 | 人身权 + 著作财产权俱全，原始主体常属此类 |
| 享有著作权的完整程度 | 部分主体 | 只享有某种著作财产值，继受主体常属此类 |

### 原始主体的确定：一般规则

接下来是大家掌握的重点了。原始主体的确定规则，回答的就是：一个作品创作出来了，谁可以原始取得著作权？

#### 自然人：创作行为怎么认定

先看一般规定。作品的原始主体可以是自然人，也可以是法人、非法人组织。

自然人这一侧，规则很干脆：创作作品的自然人是作者，作者就是作品的原始主体。所以"作者"这个词在这里也是一个专业术语，体现为作品的原始主体。

那什么样的自然人可以成为作者呢？叫创作作品的自然人。要成为作者，必须实施一个创作作品的行为——这是核心。

那这个创作行为怎么来认定呢？要从正反两方面来界定。

正面是什么？创作行为指的是**直接产生**文学艺术和科学作品的智力活动。

> **易错点**：注意"直接产生"这四个字，它是后面所有判断题的钥匙。

小说是你亲自写的，照片是你亲自拍的，论文也是你亲自写的——这叫直接产生作品的智力活动，这叫创作行为，进而可以成为作者来取得著作权。

反面是从排除的角度。以下三种情形就不是创作行为，既然不是直接产生作品的肢体活动，就不能成为作者。

第一种，**为他人创作进行组织工作的**。组织、联络工作确实也为作品的创作做出了贡献，但是他不是直接产生作品的智力活动，所以不能成为作者。

第二种，**提供咨询意见和物质条件的**。同样没有实施直接产生作品的智力活动。

第三种，**进行其他辅助工作的**。既然是辅助工作，那就不是直接产生作品的智力活动。

辅助工作离我们最近的一个例子，就摆在研究生上岸以后。大家如果跟的是一位高产作者的老师，常常要帮老师校对书稿。假设说经过你的认真校对，老师新写的著作里有 1000 多个错别字、有 500 多个专业性的错误都被你给看出来了——大家看你能不能成为这本图书的作者呀？当然不能。因为校对本身只是一个辅助性的工作，没有直接产生作品。

> **提示**：著作权判断的是"表达"是不是你落笔写出来的，不看你出了多少力、熬了多少夜。

我记得我在上研究生的时候，经常帮老师校对书稿。老师新书出版的书啊，我都会翻开这个后记，看看老师有没有感谢我在校对中付出的辛苦劳动，当时觉得挺光荣的。后来想想，其实校对本身只是一个辅助性的工作，这个贡献其实很小的。直到后来跟老师一起去写论文、一起写书，我的名字出现在封面上的时候，这个成就感就满满的——因为我也是作者了，我也是直接产生作品。

来一个例子，把正反两面一起串起来：

> **例**：甲提供资金，乙组织丙和丁以乡村教师戊为原型创作了一部小说。在这个小说的创作过程中，丙写了提纲，丁写了初稿，丙进行了修改，戊提供了生活素材，乙提供了咨询意见。大家共同努力完成了一部小说，谁是这部小说的作者呢？就要看谁实施了创作作品的行为。

逐个过一遍：

- **甲**：没有创作，只是出钱提供资金——不是作者。
- **乙**：也没有创作，只是进行了组织——不是作者。
- **丙、丁**：进行了创作。丙写提纲、后来修改，丁写初稿，都是直接产生作品的智力活动——可以成为作者。
- **戊**：不能成为作者。戊提供了生活素材，并没有实施直接产生作品的智力活动。

所以这部小说的作者只能是丙和丁，其他人都付出了劳动，但是不能成为作者。当然，丙丁在写这个小说的时候，后记当中可以感谢一下戊的努力。

#### 法人与非法人组织：视为作者

第二方面，是法人、非法人组织成为原始主体。

因为这个作品是一个智力活动，而法人也好、非法人组织也好，他只是一个组织，他能不能真的实施智力活动？不能。所以他成为原始著作权人，只能是**视为作者**。

> **易错点**：注意"视为作者"这个词，非常的精准。它指的是法律拟制的一种立法技术——尽管你没有实施真正意义上的智力活动，但是法律认为你跟实施智力活动差不多，也可以把你当成作者来对待。

视为作者需要满足三个方面的条件：

| 序号 | 条件 |
| --- | --- |
| 一 | 作品由法人或非法人组织来主持 |
| 二 | 按照法人或非法人组织的意志来创作，体现组织的意志 |
| 三 | 由法人或非法人组织来承担责任 |

满足这三个条件的法人或者非法人组织，也可以视为作者。

大家都看过正午阳光出品的优秀电视剧，像《琅琊榜》、前面提到的《凡人歌》，还有《山海情》等等。你看这些电视剧都按照正午阳光的意志在创作，由它来主持，最终由它来承担责任，所以正午阳光可以成为这些电视剧的作者。包括去年一部非常优秀的电影叫《哪吒2》（魔童闹海），它是由光线传媒这个公司来制作的，由它来主持，按它的意志来创作，由它来承担责任，那光线传媒这个公司就可以成为著作权人。

#### 署名推定

当然，到底是哪些自然人的创作、哪些组织来主持、体现意志和承担责任呢，要通过署名的方式来体现。这意味着：作品上署的是谁的名字，那就推定谁是这个作品的著作权人。

金庸的武侠小说封面上写着"金庸著"，那就推定这个小说是金庸创作的；韩寒写过一部小说叫《三重门》，封面上写着"韩寒著"，那就推定韩寒是这部小说的著作权人。那别人想要挑战说"这个小说到底是不是你写的呀"？挑战者得提出充足的证据。

包括大家看电影、电视剧的时候，片头出现的这个出品公司，也是通过署名的这种方式来体现著作权的。

到这里，确定原始主体的一般性规则就讲完了。

### 特殊作品的著作权归属

一般规则之外，还有一些特殊作品，各自有专门的归属规则。这些特殊作品包括演绎作品、合作作品、汇编作品、视听作品、职务作品以及委托作品。

#### 演绎作品

第一种特殊作品叫**演绎作品**，体现为改编、翻译、注释、整理已有作品而产生的作品。通俗地讲，就是在别人的作品基础上进行再创作而形成的作品。

金庸创作了一部小说《笑傲江湖》，于正在这个基础上把它改编成了电视剧的剧本——你看于正这个剧本，他就是在金庸的小说基础上进行的再创作，这叫演绎作品。包括外国人写的小说或者学术专著，给它翻译成中文，你看是不是也是在别人的作品基础上进行再创作？它也是一个演绎作品。

这意味着演绎作品和原作品是两个独立的作品。像刚才举的例子，金庸创作的小说《笑傲江湖》是一个作品，于正改编成的剧本是第二个作品。既然是两个作品，那每个作品都有自己的著作权人。谁创作这个作品，谁就可以成为著作权人。原作品的著作权人，按照我们前面讲的一般性规则来确定；而这个演绎作品，要由演绎作者来取得著作权——也就是改编者、翻译者、注释者、整理者。你进行了再创作，你来取得著作权。

这里有三点必须记住。

**第一，演绎必然借鉴了别人现成的智力成果，所以要经过许可并支付报酬。** 你没有经过许可擅自改编别人作品的话，别人是可以追究你的侵权责任的。就像我们前面讲过的一个典型真题：乙创作了一个摄影作品，甲在这个摄影作品基础上要创作一个油画作品——是不是借鉴了别人现成的智力成果啊？那你要经过许可；擅自去改变别人作品，是要承担侵权责任的。

**第二，即使未经许可而进行演绎、进行改编，虽然要承担侵权责任，但不影响你取得演绎作品的著作权。** 还是金庸这个例子：假如说于正没有经过许可就把这个小说改编成了剧本，首先我们看于正——他没有经过许可就改编别人的作品，是不是未经许可擅自利用别人的智力成果啊？那于正是要承担侵权责任的。但是，即使是未经许可而改编完成的剧本，于正能不能取得著作权？是可以的。因为这个剧本它符合作品的构成要件，所以这个改编者取得著作权，和他应当承担侵犯他人著作权的侵权责任，二者是不冲突的。

教材里还写了一个例子，这个例子来自一部电影叫《年会不能停》，是大鹏主演的一部电影。电影里面有个公司叫"众和集团公司"——当然，此"和"非彼"和"，这个"和"是平和的"和"。在这个公司的年会上，大鹏饰演的胡建林等人把励志歌曲《我的未来不是梦》改编成了《打工人之歌》。我相信不少同学可能看过这个电影。你看改编别人的歌曲的时候，是不是借鉴了别人的智力成果啊？是要经过许可并支付报酬的。那假如说这些人没有经过许可就改编别人作品，是要承担侵权责任的。但是只要改编后的歌曲满足作品的构成要件、具有独创性，也可以依法取得著作权。注意，二者是不冲突的。

> **结论**：侵权责任的承担与作品著作权的取得，是两条平行的线，可以同时成立、互不排斥。这个思路在汇编作品那里还会再出现一次。

**第三，将来要利用这个演绎作品，需要双重许可。** 既要经过原作者的同意，也要经过改编作品著作权人的同意。假如说于正经过金庸的许可，把这个《笑傲江湖》改编成了剧本，那接下来湖南卫视要利用这个剧本拍一部电视剧《笑傲江湖》，湖南卫视一方面得经过原作品著作权人金庸的许可，另一方面还得经过剧本的著作权人于正的许可，要经过双重许可并支付报酬。因为湖南卫视拍电视剧的时候，他所利用的这个剧本上既包含着金庸先生的智力成果，也包含着于正的智力成果。

#### 合作作品

第二种特殊作品叫**合作作品**，也就是两人以上共同创作的作品。

这里要再强调一个前提：合作作品要求合作者都参与了作品的创作，而且还得具有共同创作的合意。

比如甲、乙两个教授商量好了，一起写一本民法的教材——你写总则，我写分则，是不是商量好了各自分工来撰写呀？这就是个合作作品。包括大家都知道，杨振宁和李政道共同发表了一篇文章，讲宇称不守恒的原理，也获得了诺贝尔奖。你看这篇文章就是杨振宁和李政道的合作作品——一方面两个人都参与创作，同时呢他们还得有共同创作的合意，志同道合的人才能够一起创作作品。

那假如说两个人以上没有共同创作的合意的，就不能构成合作作品了。比如《红楼梦》，通说观点认为前 80 回由曹雪芹所著，后 40 回由高鹗所著。我们能不能说《红楼梦》是曹雪芹和高鹗的合作作品呀？不能的。因为他们俩人根本就不认识，他们并没有共同写这个小说的合意——实际上曹雪芹不一定看得上这个高鹗。所以它并不是一个合作作品。

**先说归属。** 合作作品著作权归属于合作作者，由他们共同享有。既然合作作者都参与了创作，他们都可以享有著作权，共同享有。

> **易错点**：成为合作作者的前提是要参与创作。假设一方只是提供了资金、参与组织工作的，是不是实质上不是创作行为？那就不能成为合作作者。

还是老师的书这个例子。我的老师写的书，写完以后我进行了校对，能不能说这部书是我跟老师一起写的呀？当然不能。因为校对工作只是一个辅助性的工作，它不是创作行为，那这个作品就不是合作作品。所以我只能是在后记里面被感谢一下，而不能出现在封面上。

**再说行使规则。** 假如作者只有一个人的话，权利由他一个人说了算。但是如果合作作者有两人以上，到底这个权利怎么来行使，就可能产生冲突了。所以法律要规定合作作品著作权的行使规则。怎么行使？我们要看这个作品能不能分割使用。

```text
        合作作品著作权的行使规则
                     │
                     ▼
       问：这个作品能不能分割使用？
                     │
        ┌────────────┴────────────┐
        │                         │
        ▼                         ▼
   可以分割使用              不可分割使用（常态）
        │                         │
        ▼                         ▼
 各作者对自己创作的部分    这三项权利须全体一致：
  可以单独行使著作权        ① 转让著作权
  但不得侵犯其他合作        ② 许可他人专有使用
  作者的权益，也不得        ③ 质押著作权
  损害作品整体权益                 │
        │                 其余权利：无正当理由，
        │                 任何一方不得阻止他方
        │                 行使
        └────────────┬────────────┘
                     ▼
     行使权利产生的收益，要与其他合作作者分享
```

读图说明：先问"能不能分割使用"这一个事实问题，可分割就各管各的、单独行使；不可分割（这是常态，比如合著的论文根本分不清哪部分是谁的成果），就走右边的规则——三项关键权利锁死，其余权利任何一方无正当理由都不得阻止他方行使，但赚的钱要分给大家。

**可以分割使用的情形。** 各个作者对自己创作的部分可以单独行使著作权。比如甲乙丙丁四个教授一起写了一本《民法学原理》，甲写总则，乙写物权，丙写合同，剩下的由丁来写。你看每个人创作的部分是不是相互独立的呀？是可以分割使用的。这意味着丙能不能把自己写的合同编部分，单独出一本合同法教材呀？也是可以的。所以作者可以单独行使著作权，但是你不得侵犯其他合作作者的权益，不能损害作品整体的权利。

**不可分割使用的情形，是大家掌握的重点，而且其实是常态。** 比如杨振宁和李政道共同完成了论文《宇称不守恒原理》，你看这个论文能不能分得清哪部分是杨振宁的成果、哪部分是李政道的成果啊？是分不开的。这个是合作作品的常态。那这个时候著作权到底怎么来行使？要与作者协商一致——你看有一点类似于我们在物权编讲到的共有制度，首先协商一致再行使著作权。

关键是协商不一致怎么办。能不能说协商不一致这个作品就不能利用了呀？那也不太合适，因为这个作品的利用可以促进社会的发展，所以法律也要设置这样的规则，来鼓励这个作品能够被利用。

按照法律规定，如果双方协商不一致的，同时也没有正当理由的，任何一方不得阻止他方行使著作权转让、许可他人专有使用、质押以外的其他权利。什么意思呢？就是有三种权利想要行使，必须得达成一致，任何一方都不能单独行使——因为这些权利对这个其他合作作者来讲是至关重要的。

> **易错点**：这三项权利是——第一，转让著作权；第二，许可他人专有使用；第三，质押著作权。必须达成一致，达不成一致的，谁都不能行使。特别注意第二项里的"专有"这两个字。

那其他的权利呢？任何一方无正当理由都不能阻止他人来行使，这意味着他人是可以单独行使的，不需要经过全体一致就可以单独行使。这样来方便这个作品的利用和传播。只是啊这个时候也得尊重下别人的劳动成果，也就是行使权利产生的收益，要和其他合作作者来分享这个收益——你可以单独决定去行使这个权利，但是呢如果赚钱了，你得给大伙分钱。

来看一个具体例子。大家看教材 240 页这个示例：甲乙丙丁四个人合作创作了一部小说。甲欲将小说许可给电影制片厂来拍电影，乙想上网来传播，丙对两种做法都表示反对，丁则不置可否——"爱咋咋地"，不知道这四个人怎么一起写的小说。

既然是共同参与的创作，那他们共同享受这个作品的著作权。那这个著作权怎么来行使呢？

首先，**甲能不能单独决定许可电影制片厂来独家改编拍成电影呢？** 大家看什么叫独家改编，就是许可电影制片厂专有使用。你看这样的权利，甲能不能单独行使啊？不能单独行使，必须要经过其他人的一致同意。

接着，**乙呢想把这个小说发到网上来传播**，有了流量以后再变现，可能能变更多的钱，这是乙的思路。大家看乙能不能不经其他人同意，把这个小说传到网上去呀？答案是可以的。因为这在行使信息网络传播权，它并不是需要经过全体一致同意才能行使的权利，所以乙可以单独行使。当然，把这个小说发到网上以后，网友纷纷给予打赏，那取得的收入呢，要和其他合作作者来分享。

也就是你可以单独拍板把这个作品上传到网站上，但是呢赚的钱得和大家来共享。这就是合作作品权利行使的规则。

#### 汇编作品

第三种特殊作品叫**汇编作品**，体现为汇编若干作品、作品的片段，或者不构成作品的数据、其他材料而形成的作品。

汇编作品呢，可以是汇编其他的作品，也可以是汇编作品的片段，或者不构成作品的数据、其他材料。

大家上岸以后，为了要搞一些理论问题的研究，要参考一些法学的知名期刊。法学领域有三大顶级期刊，首先是《中国社会科学》，第二是《中国法学》，第三个是《法学研究》。大家未来做研究论文的时候，要多参考这些水平比较高的期刊的文章，不要老是参考那些垃圾期刊。大家看这些期刊的每一期，上面都刊登着几篇文章，每一篇文章都是一个独立的作品，所以它是汇编作品。只要对内容的选择和编排具有独创性，那这个期刊本身就可以成为一个独立的汇编作品——每个期刊都有自己的征稿标准，也就是你的选择具有独创性；同时每一期的编排都有特定的栏目，也会体现一个独创性。整本期刊本身就会成为一个汇编作品。

同时有些汇编作品呢，他汇编的内容是作品的片段，或者不构成作品的数据、其他材料。比如大家备考法硕或者备考法考的时候，手里面可能会买一本法律法规汇编。你看这个法律法规汇编，他汇编的内容是法律法规，而这个法律法规呢是官方文件，它是没有著作权的。但是啊这些汇编的图书，它对内容的选择、编排是有一定独创性的——它是要服务于特定的考试的——实际上它本身也可以成为一个独立的汇编作品。

先掌握它的概念。那接下来看汇编作品它的著作权归属：**只要这个汇编者对内容的选择和编排具有独创性，他就可以取得对汇编作品的著作权。** 也就是汇编作品，它本身是一个独立的作品。

当然，这里有个分寸问题：假设你汇编的内容如果是法律法规这样不构成作品的材料或数据，那你可以随便汇编；但是啊，你要把别人的作品汇编到你的作品当中的，那这个时候你必须要经过别人的许可并支付报酬。比如某位教授写的文章发表在自己的刊物上，你想编进自己的一本书里，你得经过人家作者的同意，事后呢还得给人家支付这个版税。

假设这个汇编作者他没有经过许可，就把别人的作品汇编到自己的作品当中，他是要承担侵权责任的，侵犯了别人的汇编权——我们在后面讲这个著作财产权的时候，会讲到汇编权。但是啊，即使你这个汇编构成了侵权，只要你作品的选择和编排具有独创性、眼光还是比较独到的，那你依然可以取得汇编作品的著作权。

看一个例子。法学教授甲创作了文章《民法的未来》，发表在某个知名期刊。那出版社呢要汇编出版《新时代的民法学研究概览》这本书，觉得甲写的这个文章很有代表性，想要编入这本书当中来。你看是不是要把别人的作品汇编到自己的作品当中来啊？这时候呢，出版社有没有经过甲的同意？当然有了。你要没有经过同意就把别人的文章编到你的书中的话，你是要承担侵权责任的。但是啊，即使你要承担侵权责任，只要汇编的作品对内容的选择和编排具有独创性，这个时候依然可以取得汇编作品、也就是《新时代的民法学研究概览》这本书的著作权。二者是不相冲突的。

> **结论**：这个思路跟我们前面讲的演绎作品的规范思路是相同的——即使你的行为构成侵权了，也不一定影响你依法取得汇编作品的著作权。

#### 视听作品

第四种特殊作品叫**视听作品**，包括电影作品、电视剧作品以及其他视听作品，也就是通过视频方式呈现的作品。

那这样的作品著作权由谁来取得呢？我们要分成两个层次。

**第一个层次，电影作品和电视剧作品，著作权由制作者来行使。**

> **易错点**：注意"制作者"这个词，它跟电影电视剧当中呈现的制片人不是一个概念。制作者呢，指的是这部电影电视剧的投资方，或者叫出品方——由你来主持拍摄，按照你的意志来创作，最终由你来承担责任，这叫制作者，常常是法人或者非法人组织。

因为这个电影电视剧的拍摄制作成本是非常高的，所以呢由制作者来统一取得著作权，体现的是著作权法的特别规定。尽管这个电影电视剧的完成凝聚了导演、编剧、摄影、配音等等好多人的智力成果，但是按照法律规定，由制作者统一来行使著作权。这样的话呢可以鼓励投资电影、投资电视剧——你投钱拍的，由你说了算。

那这个编剧、导演、摄影、作词、作曲等等这些参与者，享有署名权，还是要保障他们的人身权的：享有署名权，而且呢可以按照和制作者签订的合同来获得报酬。当然这个电影呢，它在上映以后可以获得很多的票房，体现的是这个作品在传播中产生的收益。那这个票房，像一般的导演、编剧、演员能不能分成啊？多数是不能的。你拿的是固定的报酬，而这个票房的收入呢，主要是由于制作者来取得的。除非是制作者跟这个知名导演或者知名演员签订合同，里面约定了这个票房的分成，否则的话，你就是根据合同拿一个固定的报酬就可以了。

**第二个层次，其他视听作品，主要是现在网络平台上的短视频作品，著作权的归属由当事人约定。**

你看这个时候啊，首先要尊重当时的一些约定。因为这些短视频作品啊，它其实投入并没有那么的高，好多博主啊可能一小时能创作好几个。那这种短视频作品到底谁来取得著作权？由当事人约定。如果当时没有约定，或者约定不明确的，也是由制作者来享有——你看也是要鼓励投资。但是呢，作者呢享有署名权和获得报酬的权利。

这是视听作品著作权的归属。那在做题的时候啊，要注意这第三点：**视听作品当中的剧本、音乐等可以单独使用的作品，作者呢可以单独行使著作权。** 有些电影电视剧的片头曲、片尾曲、插曲，可能是一个独立的音乐作品，那这个音乐作品的著作权人可以单独行使著作权。

教材里面啊给大家写了两个例子。第一个例子是这个动画电影《哪吒2》（魔童闹海），它是由光线传媒来出品的，那光线传媒就是这部电影的制作者，它可以依法取得著作权；然后导演啦、配音啦等等，可以根据合同来取得相应的报酬，当然享有署名权。第二个例子是一部电视剧《藏海传》，去年非常的火，这部电视剧是由优酷出品的，优酷公司就是这部电影的制作者，可以取得著作权；而这个导演啦、演员啦等等，可以根据合同来取得相应的报酬，同时享有署名权。

#### 职务作品

第五项特殊作品是**职务作品**，这个需要大家特别关注，是 2025 年新增加的内容，到目前为止还没有考过。

它指的是自然人为了完成法人或非法人组织的工作任务而创作的作品。核心词是"完成工作任务创作的作品"。

比如说报社的记者撰写了评论作品——你看那个记者啊，他是拿这个报社的工资的，写这个文章就是你的工作任务，那写的这个评论文章就是职务作品。包括这个电影制片厂的专职编剧改编的剧本，也是完成工作任务而创作的作品，都叫职务作品。

那这里面需要大家重点掌握的是，职务作品的著作权由谁来享有呢？这个职务作品啊，可能有单位取得著作权，也可能有创作者、作者来取得著作权。那关键是哪个原则、哪个例外？注意下：**由创作作品的作者取得著作权是原则，而由单位取得著作权是例外。** 这一点大家一定要特别注意。

为什么呢？尽管这个作品是为了完成工作任务完成的、是拿工资的，但是这个作品本身，它主要体现的是作者个人思想的表达，所以呢作者取得著作权是原则。但是啊，毕竟呢单位给你发工资的，所以呢单位在立法的时候也可以取得著作权。

需要大家重点掌握单位取得著作权的例外情形，在著作权法里面规定了三种情形。

| 序号 | 单位取得著作权的例外情形 | 说明 |
| --- | --- | --- |
| 一 | 主要利用单位的物质技术条件创作，并由单位承担责任的工程设计图、产品设计图、地图、示意图、计算机软件等职务作品 | 即"四图一件"。四图为工程设计图、产品设计图、地图、示意图，一件为计算机软件。常常需要付出较大的人力物力，单位贡献较大 |
| 二 | 报社、期刊社、通讯社、广播电台、电视台的工作人员创作的职务作品 | 2020 年修订著作权法时特别增加 |
| 三 | 法律、行政法规规定或者合同约定由单位享有著作权的职务作品 | 兜底条款，体现为"其他" |

先来看第一种情形。主要利用单位的物质技术条件创作，并由单位承担责任的工程设计图、产品设计图、地图、示意图、计算机软件等职务作品，这叫**"四图一件作品"**。四图呢，指的是工程设计图、产品设计图、地图和示意图；而这个"一件"说的是计算机软件。大家看这些作品啊，他常常需要付出较大的人力物力，单位的贡献还是比较大的，所以由单位来取得著作权。

第二种情形，是 2020 年修订著作权法的时候特别增加的：报社、期刊社、通讯社、广播电台、电视台的工作人员创作的职务作品，主要是新闻媒体单位的工作人员创作的作品，由单位来取得著作权。

> **提示**：当时为什么要增加这个特殊的情形呢？主要是为了方便新闻报道的顺利进行。大家都知道新闻报道是有时效性的，你得尽快报道才有价值，好多媒体都会派这个记者去采访。假如说这个记者呢，他拍摄的照片、他写的这个新闻稿，有他自己取得著作权的话，那这个报社要刊登这篇报道、想要利用这个照片，还得和这个作者来谈怎么合作，那便会影响到新闻报道的时效性。遵从法律规定，新闻媒体的工作人员创作的作品原则上由单位取得著作权——这样的话，单位可以直接用你的稿件、直接用你拍摄的照片，当然事后呢要给你支付报酬，这样可以方便新闻报道的正常进行。

第三种情形是兜底的：法律、行政法规规定或者合同约定由单位享有著作权的职务作品，体现为"其他"。所以从考试角度来讲，大家重点掌握前两项明确列举的就行。

来看两个例子。

**例一**：甲公司的游戏软件工程师刘某根据公司的要求，开发《三国演义》的游戏软件。大家看这个游戏软件它是一个计算机软件，是不是主要利用了单位的物质技术条件来创作的呀？那可以由甲公司来取得著作权，是"四图一件"当中的一件。

**例二**：乙报社委派该市的摄影师参加某新闻发布会，拍摄现场的新闻照片。大家看这个照片呢，他的著作权归属于谁呀？归属于乙报社。报社可以直接使用这个照片。

那假设不存在上述特别规定的，即使是职务作品，也由作者来取得著作权。当然，单位呢毕竟给你发工资了，所以呢单位在业务范围内可以优先使用。

再来看一个小例子。小张是某教培机构的员工，担任演讲与口才这门课的教学任务。按照机构的教学计划和教学要求，小张用一个寒假完成了课程的讲义。假如当时没有做特别约定的话，该讲义的著作权归谁呀？注意，是归小张。因为这个按照要求所撰写的课程讲义，它既不是法律规定的"四图一件"作品，也不是新闻媒体的工作人员创作的作品，所以呢由作者来取得著作权。当然这个单位呢，它有优先使用的权利——毕竟人家给你发工资呢。

所以职务作品的著作权归属，大家掌握原则和例外两个方面就够了。

#### 委托作品

第六种特殊作品叫**委托作品**，也就是受委托而创作的作品，常常这个创作者跟他人之间有一个委托合同。

那这个作品的著作权归属谁呢？既然双方签订了合同，那这个著作权的归属，首先当时有约定的，尊重约定。当然如果当时呢没有约定，或者根本就没有签订合同的，这个时候著作权呢要归属于受托人。因为是受托人完成了作品的创作，由他来取得著作权，也是符合生活的常理的。

举一个例子：韩寒委托朴树为电影《后会无期》创作主题曲，那这个朴树呢盛情难却，创作了《平凡之路》——"我曾经跨过山和大海"，这首歌相信大家都听过啊。这首歌呢就是受委托而创作的作品。如果双方当时没有做特别约定的话，谁来取得著作权啊？由受托人朴树来取得著作权。

但这首歌呢，他作为电影的片尾曲，是不是可以单独使用的作品啊？那这个朴树呢能不能发一个唱片来发表这首歌曲啊？当然也是可以的。

到这里，给大家补充的几种特殊作品的著作权归属规则就讲完了。

### 本讲提到的题目

#### 题目一：小说改编为剧本、电视剧与话剧

> **题干**：王某的小说发表以后，甲公司经过王某的同意，将小说改编成了剧本，并拍摄成同名电视剧，该剧在某电视台播出；丙剧团经王某授权以后，将该小说改编成了同名话剧，在投入资金排练以后公开演出。

大家看这个案情当中出现了几个作品啊？出现了四个作品。首先是小说，这是文字作品；接着剧本也是一个文字作品；然后呢电视剧它是一个视听作品；最后这个话剧它是一个戏剧作品。有四个作品，既有四个作品，那每个作品就分别有自己的著作权人。

- **A 选项：王某对小说享有著作权。正确。** 因为小说是王某他撰写的。
- **B 选项：甲公司对电视剧的剧本享有著作权。正确。** 因为这个剧本呢，他是甲公司改编的，而且甲公司在改编的时候经过了王某的同意，所以这个行为是合法的。

  > **提示**：我们在前面讲过，即使甲公司没有经过王某的同意，就把小说改编成了剧本，一方面他要承担侵权责任，另一方面也不影响他取得剧本的著作权。

- **C 选项：某电视台作为播放者享有著作权。错误。** 因为这个电视剧是甲公司制作的，甲公司是制作者，甲公司享有著作权；而这个电视台，他只是传播者，他享有的权利啊，叫做邻接权。

  > **提示**：邻接权保护的是作品的传播者的权利，比如作品的出版者（出版社）、录音录像的制作者、广播电台电视台这些广播组织者。这个考点目前没有纳入到我们法硕考试的大纲范围，但著作权法里是有规定的。

- **D 选项：丙剧团作为表演者享有邻接权。正确。** 因为丙剧团公开表演这个作品，是在传播这个作品，表演者也是传播者，所以他享有邻接权。同时这个丙剧团呢，是不是他把这个小说改编成了同名话剧啊？所以这个丙剧团同时又是这个话剧作品的著作权人。

  > **提示**：很多作品都是作者亲自创作、亲自表演的。比如李健创作了一首歌曲叫《传奇》，李健是著作权人，同时呢李健也亲自演唱这首歌曲，他对（该作品）同时也享有邻接权。二者是不冲突的。

那这道题正确答案应该选的是 A、B、D 三个选项。

#### 题目二：受托创作肖像画的复制与出售

> **题干**：甲受乙的委托，为乙画了一幅肖像，双方未约定该画著作权的归属。乙去世以后，其继承人丙将该画卖给了丁。丁未经任何人的同意，将该画复制出售。问：丁的行为侵犯了谁的著作权？

**答案**：侵犯的是甲的著作权。

**解析**：我们首先判断一下这幅画的著作权人是谁。既然当时没有约定，那由受委托创作作品的受托人来取得著作权；既然是甲呢创作的肖像，那就由甲来取得著作权。那么丁擅自将该画复制出售，侵犯的是甲的著作权。

至于侵犯的是甲的什么权：首先，丁未经同意复制这幅画，侵犯的是复制权；然后呢，出售这幅画侵犯的是发行权。都属于著作财产权的范围。

## 著作权的内容：四项人身权与十三项财产权
> 对应块：BLK75 | 覆盖分集：P71 | 块标题（分集名）：《第04编 第02章：著作权（03）》

著作权这一块是重点，也是难点。它难在哪？难在两件事：一是著作权作为一种知识产权，它是**绝对权**，著作权人对作品享有专有权；二是它的内容采取的是**法定主义的立法模式**——著作权人想要哪些专有权，不是他本人说了算，而是由法律作出规定的。也就是说，你无法通过合同去"约定出"一项本来不存在的著作权。

所以，法考这里不考你情不情愿，只考你法律把哪些权利写给了著作权人。既然是法律写死的，那就只有一条笨办法：**把规定的规则一条一条掌握住**。

### 权利是"别人没有许可不能做什么"

著作权的内容具有双重性——既有人身权益的内容，也有财产权的内容。这个前面讲概述的时候已经说过，著作权人既享有诸多著作人身权，也享有诸多著作财产权，这是它特殊的地方。按照著作权法的规定：**人身权四项，财产权十三项**，大家要一一去掌握。

但在展开具体内容之前，我要先强调一个观点。这个观点不理解，后面每一条权利都会读得别扭：

> **定义**：法律规定的著作权人享有的权利内容，不是说"著作权人可以做什么"，而是说"别人没有经过许可，不能做什么"。

哪些行为是法律专有地留给著作权人的，别人未经许可实施了，就侵犯了著作权人的权利。所以著作权的内容和著作权侵权的行为是紧密相关的——你要判断侵权，第一步就是回到"这属于哪一项权利的规范范围"。

同时要记住两组差别：

- 著作人身权常常具有**专属性**，原则上不能转让；
- 著作财产权原则上**可以转让**。

> **提示**：由此也能推出前面讲过的一个结论——著作权客体发生继承时，作为遗产被继承的只能是**著作财产权**，著作人身权不在其中。

把这两句话放在心里，接下来我们看具体内容。

### 四项著作人身权

法律规定的四项著作人身权，分别是发表权、署名权、修改权和保护作品完整权。这四项仍然有可能考到主观题，所以名字必须准确，不能含糊。

#### 发表权：公之于众，一次用尽

发表权指的是**决定作品是否公之于众的权利**。

理解发表权，最容易犯的一个错误是把它理解成"法律赋予作者公之于众的权利"。不是的。作者想发就发、不想发就不发，这是他本来就有的自由，是不需要法律赋予的自然选择。我们这里所说的发表权，说的是**别人未经许可不能把这个作品公之于众**，体现的是专有权的属性。如果别人未经你的许可把你的作品公之于众了，那就是侵犯了你的发表权。

那"公之于众"怎么理解？核心词就是这四个字：**将作品向不特定的人公开**。它有两个要点：

- 是著作权人自行或者经他人许可公开的，别人擅自公开不算；
- 向的是不特定的人。

> **易错点**：公之于众**不以公众知晓为构成要件**。只要作品向不特定的人公开了，即使公众根本不知晓，也不影响这个作品已经发表的认定。

举个例子。甲完成了一篇微小说，发在自己的微博上，三天过去了没人阅读，因为他只有一个粉丝，还是自己的小号。这个作品发表了吗？已经发表了。因为它已经处于一个"向不特定的人公开"的状态，随时可能产生新粉丝，都可以看到这个作品。到此为止，即使没有任何其他人看到、公众完全不知晓，这个作品也已经发表了。

这一条理解到位了，还要再往前走一步，是一个理论拓展：**发表权属于一次行使即用尽的权利**。它保护的是什么？保护的是这个作品的传播范围从 0 到 1 的那个质变。一旦作者自行或者经其许可把作品公之于众了，这个权利就用尽了，别人就不可能再侵犯它。

还是刚才那个微博的例子。甲的微小说被某个微博大V发现了，大V觉得写得好，未经许可转载了它，使阅读量大增——传播范围确实变广了。但大V转载侵犯甲的发表权了吗？没有。因为甲的发表权已经行使完毕了，他已经自行把作品向不特定人公开了，别人再传播就不再侵犯发表权。

> **结论**：发表权管的是"从 0 到 1"，也就是一一生二、二生三的那一下；三生万物以后、作品此后的传播，就不是发表权规范的范围，而属于其他著作财产权规范的范围了。比如大V的转载，就可能侵犯信息网络传播权。

#### 署名权：署与不署，作者说了算

署名权指的是**表明作者身份、在作品上署名的权利**。

在作品上署自己的名字，这本身带有某种人身属性。前不久我跟一个老师一起写了一篇文章，文章发表的时候署的是我和老师两个人的名字，我的虚荣心得到了巨大的满足——很光荣，很有成就感。这就是署名权的人身属性。

署名权既包括**积极权能**，也包括**消极权能**，这一点必须掌握。

所谓积极权能，就是作者可以决定在作品上署名。这其实是常态——一个人创作的作品，不希望署上自己的名字、不让别人知道这是自己的成果，这完全符合人之常情；这正属于积极权能。所以积极权能有两层意思：**别人不能擅自把你的名字拿掉**（要不要署名由作者决定，你不能擅自做主），以及**作者可以选择署真名，也可以选择署笔名、艺名等别名**。

> **结论**：擅自在别人的作品上署上自己的名字，侵犯的是**作者的署名权**，不是你的。

教材里我举过几个例子。像《科幻小说三体》的作者刘慈欣，是我的山西阳泉老乡，他写小说时用的就是真名，这是作者的权利；有些作家署的才是笔名，比如《明朝那些事儿》的作者当年明月，一看就是个笔名，《苍兰诀》的作者九鹭非香也是。这些都属于作者署名权的行使，属于积极权能。

所谓消极权能，就是作者也有权决定在作品上不署名，这同样是他的权利。大家小时候背唐诗宋词，有些的作者叫"无名氏"，或者写个"佚名"——可能是作者已经无法确定了，也可能是作者写完以后不想让别人知道这是他写的诗，选择用无名氏或者笔名的方式来发表作品，这同样是可以的。

> **易错点**：单从考试角度讲，只要没有特别说明，我们要**推定作者是有署名的意愿的**。你擅自把别人的名字拿掉，侵犯署名权；你擅自改变了作者的署名决定——人家想署笔名，你给改成了真名——同样是侵犯署名权。

所以署名权也是一种专有权，由作者自己来独断专行，别人不能擅自干涉。

来看一个实践中真实发生的小例子。某作者创作完成了儿童题材小说《森林之歌》，为了吸引儿童阅读、增添小说的离奇色彩，作者使用的笔名叫"翠雪"。结果出版社编辑在编校的时候认为，作者连自己的名字都能写错，估计是不分翘舌音和平舌音，于是就把这个"翠雪"改成了本名。

编辑这个行为构成侵权吗？当然构成。因为作者有权决定署笔名，这是作者专有权的范围；编辑擅自改变了作者的署名决定，就是侵犯了别人的署名权。这叫什么？这叫自作聪明。当然，生活当中确实有人写拼音的时候分不清卷舌还是翘舌音，我要是"车"和"车哈"都分不清，那另说。

#### 修改权：能不能动别人的作品

修改权指的是**修改或者授权他人修改作品的权利**。换句话说，别人未经许可擅自修改作品的，就侵犯了修改权。

举一个大家都熟悉的例子：《红楼梦》。有的人觉得它的结局不好，那出版社在出版的时候，能不能擅自把这个结局给改了呀？不能，侵犯了修改权。

#### 保护作品完整权：能不能把别人的作品改坏

保护作品完整权，体现为**保护作品的内容不受歪曲、篡改的权利**。

> **易错点**：即使是经过作者同意的修改，你也不能实质改变作品的内容。作者同意你改，不等于授权你改坏。

还是《森林之歌》这个作者。还是他，为了吸引儿童阅读、增添离奇色彩，特意把小说当中的狗熊写成了三只脚的动物。出版社编辑在编辑的时候，觉得作者一点生活常识都没有——动物园里的狗熊都是四只脚的，哪有三只脚的？——于是就把这个狗熊统一改成了四只脚的动物。

编辑这个行为构成侵权吗？构成。因为未经同意擅自篡改了作品的内容。人家写的三只脚的狗熊是童话故事，是很可爱的；你改成四只脚的狗熊，那就变成《动物世界》了，是很吓人的。它实质地篡改了作品的内容，所以侵犯了保护作品完整权。

它有没有同时侵犯修改权？也侵犯了，因为未经许可修改了别人的作品。所以修改权和保护作品完整权常常一起被侵犯，只是这两项权利描述问题的角度有所不同，我在这里给大家做一个理论拓展：

> **提示**：修改权更多是站在**作者的角度**来描述的——你有权修改自己的作品，只要作品还没有发表，你都可以修改；而保护作品完整权是站在**作者以外的其他人的角度**来理解的——别人的作品，你未经许可不能擅自去篡改它的内容。

到这里，四项著作人身权就讲完了。名字要准确，也别忘了我的口诀：

> **提示**："**保修名表**"——保是保护作品完整权，修是修改权，名是署名权，表是发表权。注意这个口诀是**倒着来**的。知道为什么吗？大家都知道陈老师有一块名表，这块名表是有保修服务的，一听就好记。一并记住。

### 十三项著作财产权

著作权法规定了 13 种著作财产权。数量比较多，这意味着从考试角度来讲，更多是从**客观题**角度来考察的——13 种权利要考主观题，除非命题人疯了。

不过还是要再次强调，接下来讲到的这些财产权的内容，核心意义同样**不在于著作权人自己可以做什么事情，而在于别人没有经过许可不能做什么事情**。别人一旦实施了著作权人专有的权利，就侵犯了著作财产权。所以，跟侵犯著作权的行为是紧密相关的。

#### 复制权：一份或者多份都算

复制权体现为控制作品复制行为的权利。注意，它说的不是作者自己可以复制作品，而是**别人未经许可不能够随便复制这个作品**，体现专有权的属性。

那什么叫"复制作品的行为"？这是掌握的一个重点。**印刷、复印、拓印、录音、录像、翻拍、翻录、数字化**等方式，将作品制作成一份或者多份，都叫做复制行为。这些行为如果没有经过作者同意就实施，会侵犯作者的复制权。

举个例子。某位老师出版了个人畅销书《刑法学精讲一本通》，他是享有著作权的。盗版书商未经许可把这本书扫描成 PDF 电子版——看这个行为构不构成侵权？构成。因为把作品数字化本身就是一种复制方式。同样，未经许可盗印 2 万册，这是印刷行为，印刷也是复制行为，也侵犯复制权。复印更是生活当中经常见到的，用复印机复印别人的作品，都是复制。

还有"拓印"。注意这个字不念"拓（tuò）"，念"拓（tà）"。可能学过书画的同学对这个比较熟悉。我上小学的时候学过书法，写毛笔字要临字帖，很多字帖都是**黑底白字**。我小时候就特别好奇：按道理写毛笔字应该是白底黑字，怎么字帖都是黑底白字呢？后来才知道，那个字帖上的字不是人直接写的，而是从石碑上拓印下来的。学过书法的同学可能去过西安的碑林博物馆，里面就有一些有名的书法碑帖，像颜真卿的《多宝塔碑》、柳公权的《玄秘塔碑》，包括张旭的《肚痛帖》，从石碑上可以拓印下来——这也是一种复制方式。

录音录像也是复制方式。比如我们在剧场看演出、在听演唱会，未经许可擅自录音录像的，同样侵犯复制权。翻录、翻拍也是，比如看电影的时候拿个摄像机把电影翻拍翻录下来，这也是复制行为。

#### 发行权：不碰载体的物权，就不是发行

发行权指的是**以出售或者赠与的方式，向公众提供作品的原件或者复制件的权利**。别人未经许可擅自通过出售、赠与方式提供作品载体的原件或者复制件的，就侵犯了发行权。还是从"别人不能做什么"这个角度来理解。

> **结论**：发行权一定要涉及**作品载体的物权转移**。假如没有涉及载体的物权转移，尽管它可能扩大了作品的传播范围，也不会侵犯发行权。

这一点特别容易搞错。还是那本书的例子。书商老马盗印了 2 万册盗版书——印刷这个行为侵犯**复制权**；然后老马把这批盗版书在网店公开出售，这个行为是不是在向公众提供作品的复制件？是，未经许可，侵犯了作者的**发行权**。

那如果换个做法呢？教材 245 页最下面的例二：老马未经许可把某老师的图书扫描成 PDF 电子版，数字化这个行为侵犯的是**复制权**；然后他把这个电子版上传到网上供网民下载——这个行为有侵权吗？有，但**侵犯的不是发行权**。因为让网民下载电子版，并没有涉及作品载体的物权转移，它是通过网络的方式来扩大作品的传播范围，所以侵犯的是作者的**信息网络传播权**。这一点一定要和发行权区别开来。

发行权还有第二个特点：它跟前面讲的发表权一样，也是**一次用尽**的权利。

假如说这个作品的原件或者复制件是经过作者允许而公开发行的，也就是正版书，它是经过作者同意的发行。那么消费者买到这本书以后，或者书商进货以后再销售正版书，会不会侵犯发行权？不会。尽管卖旧书也涉及作品载体的物权转移，但因为你买的是正版书，这本书作者的发行权已经行使过了，他已经拿过钱了，权利已经行使完毕了，所以不会再构成侵犯发行权的行为。

看教材 246 页的例三。还是某老师出版了个人畅销书，依法取得著作权。小月购买了一本正版书要努力复习考研，因为这本书质量上乘、内容编写得非常好，所以经过努力，小月考上了人大法学院。后来小月通过小红书把自己用过的这本旧书卖给了即将参加考研的学弟——一方面这本书还有利用价值，另一方面这是上岸人大的小月用过的书，可能给学弟学妹带来好运气。

小月出卖二手书的行为，是不是也涉及作品载体的物权转移了？是。但是她有没有侵犯发行权？没有。因为小月买的是正版书，这本书是经过作者同意发行的，作者的发行权已经行使完毕了，那小月再卖这个二手书就不再构成侵权了。

但是，这个规定的**适用前提是这本书上作者已经行使过发行权**。假设这本书是盗版书呢？看例四。小月这次买的是盗版书，因为正版书买不起；但盗版书质量上乘，内容都是一样的，不影响复习，所以小月经过努力依然上岸了人大法学院。后来她觉得这部盗版书可以给学弟学妹带来好运气，于是通过小红书把这本盗版书卖给了即将参加考研的学弟。

小月出卖这本二手书的行为构成侵权吗？构成。因为这本书从来没有经过作者同意而发行，作者在这本书上没有行使过发行权，所以就不存在"一次行使而用尽"的问题。盗版书每转手一次，都会侵犯作者的发行权——因为每一本盗版书的流通，都有可能影响正版书的销量。

> **易错点**：发行权"一次行使即用尽"的原则，**只能适用于正版产品**。盗版书不适用。

#### 出租权：只有视听作品和软件才有的权利

出租权指的是**有偿许可他人临时使用视听作品、计算机软件的原件或者复制件的权利**。它控制的其实是作品载体的出租行为。

这里有三层需要你注意：

第一，不是所有著作权人都享有出租权。只有**两类作品的著作权人**享有：一个是视听作品，一个是计算机软件作品。其他作品的著作权人没有出租权，别人出租这个载体不需要经过你的同意。

大家看我中学的时候，学校门口有一家"芳草书屋"——这个名字我记得很清楚，就出租金庸小说，每天五毛钱，好多小说都得排着队看。这家书店出租图书时，肯定没有经过金庸先生的许可，会不会侵犯金庸的出租权？不会。因为小说是文字作品，文字作品的著作权人没有出租权。你不能控制别人未经许可的出租行为——我买的书，凭什么不能租给别人？

但如果是视听作品或者是计算机软件作品，这个出租行为就必须经过许可了。看例二。甲购买了 97 版正版的《神雕侠侣》电视剧的 VCD（我觉得 97 版是非常经典的版本，古天乐和李若彤演的，那时候我正在上初中），开了一个影像店，未经许可出租该 VCD 盈利。甲的行为构成侵权吗？构成。因为这个电视剧的 VCD 是视听作品的载体，未经许可出租会侵犯著作权人的出租权。

当然，尽管视听作品的出租权在法律上依然有规定，但在实践中它的意义已经微乎其微了。像我上中学的时候特别流行去录像厅租录像带来看——当然我租的都是健康的、绿色的录像带。现在已经很少有人去音像店租录像带了，因为视频网站非常发达，你一个月交几块钱就能享受全平台的高清视频服务。**视听作品的出租权，其实是被网络给淘汰了**。但法律上它依然有这个权利。

第二，计算机软件的著作权人也享有出租权，但有一个例外规定：**如果计算机软件不是出租的主要标的物，就不构成侵犯出租权的行为**。有的出租标的可能会顺带把这个软件也一起出租出去，但如果软件不是出租的主要标的物，就不侵权。

看一个小例子。甲有一台电脑，里面安装着正版 office 办公软件；甲把这台电脑租给了乙。甲把电脑租给乙的时候，必然也把正版计算机软件的使用权一并转移给了乙。那这个行为有没有侵犯软件著作权人的出租权？没有。因为双方签订的租赁合同标的主要是电脑这个动产，而不是里面装着的软件，所以不构成侵权。

#### 展览权：买了画，不等于成了画家

展览权体现为**公开陈列美术作品、摄影作品的原件或者复制件的权利**。它同样跟作品载体相关，只是体现为一个公开陈列的行为。你没经过许可擅自公开陈列别人的美术、摄影作品，就侵犯了展览权。

这里有三个细节要抓住。

第一，不是所有著作权人都有展览权。只有**美术作品和摄影作品**的著作权人才有展览权，才可以禁止别人未经许可的公开展览行为。比如某个图书出版社过年的时候办一个图书展销会，展示一下新出版的优秀图书，这个公开展示图书的行为要不要经过作者的同意？不需要。因为出版的图书是文字作品，文字作品根本就没有展览权。

第二，**展览权的行使不能侵犯他人的合法权益**。比如某个摄影师给模特拍了好多写真照片，都是私房照。当时如果没有特别约定，摄影师取得摄影作品的著作权。他能不能做一个展览？原则上可以。但他展览的时候不能侵犯别人的合法权益：假设这些照片涉及别人的隐私权，那展览的时候就要经过别人的同意，否则会侵犯别人的人格权。

第三，也是展览权里面最重要的一个规则：**作品原件所有权转移，不会导致作品著作权的转移**。

像收藏家购买名人字画，名人字画是美术作品，收藏家可以通过购买取得原件的所有权，藏品归他所有。但收藏家能不能成为这幅美术作品的著作权人？当然不能。不是说你有钱买一幅画，你就可以成为画家；你有钱买一幅字，你就可以成为书法家——这不符合生活常理。所以原件所有权的转移不导致著作权的转移。

但是，**原件的所有权人可以行使原件的展览权**。既然你取得了原件的所有权，法律允许你公开展览一下你的藏品，来体现一下你有多有钱、你多有品位。看一个例子：甲创作了美术作品《千里马》，然后把这个作品卖给了收藏家乙。乙取得了原件的所有权，乙虽然不能成为这幅画的著作权人，但他可以行使原件的展览权，可以把自己的藏品搞一个盈利性的展览来公开展示，这没问题。

现实中的例子是马未都先生。他自己搞了一个私人博物馆，叫观复博物馆，陈列自己收藏的一些艺术品。尽管这些艺术品的所有权归马未都先生，但他不能成为这些美术作品的著作权人，只是可以展览这个原件。而且这里一定注意：**原件所有权人只有原件的展览权**——你能不能搞一个复制件来展览？不能，只能展览原件。

> **结论**：著作权法里还专门加了一个规则：如果作者将**未发表的美术作品**的原件转移给他人的，那么所有人展览该原件不会侵犯作品的发表权。因为你把未发表的作品卖给别人，就使得这个作品进入流通领域了，已经向不特定的多数人公开了，你的发表权已经行使完毕了，后续的展览行为不再构成侵犯发表权。

看刚才那个例子。甲创作了美术作品《千里马》，刚刚创作完成就当场被收藏家乙买走了。乙取得了原件所有权，同时享有原件的展览权。甲能不能说"这幅画除了咱俩没有任何人见过，你擅自展览不就是把我的东西都公开了吗，侵犯了我的发表权"？这个说法不能成立。因为法律认为，甲一旦把画卖给乙，这幅画既然进入流通领域了，它就已经合法发表了，乙再展览就不会侵犯甲的发表权。

#### 表演权：要找的是词曲作者，不是原唱

表演权是一个难点问题，体现为**公开表演作品，或者通过各种手段公开播送作品表演的权利**。它控制的是作品的表演行为。换句话说，你要是表演别人的作品，是要构成侵权的。

它所称的"表演作品的行为"包括两类。

一类叫**现场表演**，即在现场公开表演别人的作品，需要经过许可，否则侵犯表演权。像歌星开演唱会，肯定要演唱别人的歌曲，你必须事先经过许可；没有经过许可的歌曲，在演唱会上是不能演唱的，否则构成侵权。包括王菲在春晚上演唱李健创作的《传奇》——这首歌要不要经过李健的同意？要，而且要支付报酬。

另一类叫**机械表演**。虽然你没有进行现场的表演，但通过各种手段公开播送别人作品的表演，也要经过许可。最典型的例子就是 KTV。

我上大学的时候，大家搞娱乐活动，要么去棋牌室打牌打麻将，要么去 KTV 唱歌，那时候娱乐方式还是比较有限的。KTV 的经营者就是在通过设备公开播送别人作品的表演，然后自己获得利润，所以必须经过许可并支付报酬。我记得那时候去 KTV 唱歌还比较便宜，我们学校旁边有个 KTV，唱六个小时总共 20 块钱——当然我们通常也唱不了六个小时，常常唱两个小时就唱不动了，然后叫同学"你来唱吧，我唱不动了"，总共花 20 块钱。所以当时好多 KTV 可能不一定给著作权人交这个版权费，但是现在的 KTV 经营都是要交这个版权费的。大家现在觉得唱歌比以前贵，不是因为更费电了，而是因为要交版权费了，否则会侵犯著作权人的表演权。

> **易错点**：机械表演也好、现场表演也好，需要经过的是**著作权人**的同意——也就是**谁写的这首歌，你要经过谁的同意**，而不是"这首歌的原唱是谁，你要经过谁的同意"。这个是不对的。

比如王菲在春晚上演唱了《传奇》，被中央电视台录制下来了，这个录像在 KTV 里也可能播放。那么要播放王菲这个《传奇》的版本，要经过谁的同意？**要经过李健的同意**，因为这首歌的著作权人是李健，你播放的是李健写的歌曲。

包括航空公司在飞机上播放歌曲，也要付这个版权费；一些盈利性的酒店、咖啡厅放一些背景音乐，也得交版权费。那他们真的都交了吗？他们有没有交，跟他们**应当**交，是两个不同的问题。从法律角度讲，他们是应当交的，不能说"好多人没交，那法不责众，都是合法的"——不能这么理解。如果去维权，那肯定是官司一打一个准：未经同意在盈利场所播放别人歌曲的，肯定要交钱。

那"要播放李健的歌，到哪里去找李健交钱呢，我都不认识李健"？注意，在我国，音乐著作权主要采取**集体管理模式**：我们国家有一个音著协——音乐著作权协会，音乐作品的著作权人统一到这个地方来获得授权，然后由音著协把这些版权费带给这些音乐作品的作者来分。

看教材里的两个例子。第一个：李健创作的歌曲《传奇》，王菲在商业演出中要演唱该歌曲，必须经过李健的许可，否则侵犯李健的现场表演权。第二个：李健创作的歌曲《传奇》，在演唱会上演唱，时代公司经过许可录制成了 DVD 公开发行；甲饭店购买了正版 DVD，在自己的饭店里面播放——这叫机械表演，也要经过著作权人李健的许可，否则会侵犯李健的机械表演权。

#### 放映权与广播权

**放映权**指的是通过放映机、幻灯机等技术设备来公开再现美术、摄影、视听作品等的权利。比如电影院放新上映的电影，是必须经过许可的，否则就侵犯了电影作品制片者的放映权。

我到 4S 店给车做保养，因为保养要好几个小时，前台工作人员就告诉我说，我们这个放映厅在放电影，你要想看的话可以去看。我就去看了——放映厅有个大屏幕，正在播一部老电影，叫《非诚勿扰》。这个 4S 店在放映厅放电影，要不要经过视听作品著作权人的同意？要的，否则会侵犯放映权。我猜他估计是没有经过同意。所以我在看电影的时候，就想到了这个考点，叫放映权。这叫职业病。

**广播权**指的是通过有线或者无线的方式公开传播或者转播作品，以及通过扩音器或者其他传送符号、声音、图像等类似工具向公众传播广播作品的权利。也就是说，你要通过广播的方式来传播别人的作品，是要经过许可的，否则侵犯广播权。

广播可以是有限的，也可以是无限的。大家可能看过《爱情公寓》，里面非常搞笑的曾小贤就主持过广播节目，叫《你的月亮我的心》。假设在这个节目上要播放别人的歌曲，要不要经过许可？要，你这是通过广播的方式来传播别人的作品。包括农村、有些学校用的扩音器——我上中学的时候还记得，课间的时候广播里会播放一些歌曲或者音乐，这也是通过扩音器的方式来广播别人的作品，也是要经过同意的。

#### 信息网络传播权：能不能回看，是分水岭

信息网络传播权是重点，通俗讲就是通过网络传播别人的作品，必须经过许可。定义是：**通过有线或者无线的方式向公众提供，使公众在选定的时间地点获得作品的权利**。

注意"公众可在选定的时间和地点获得作品"这个限定，它体现的是一种**交互式**的传播方式。

最常见的例子就是视频网站，大家都在视频网站上看过电影电视剧，包括我们在 B 站上听课，它也是一种信息网络的传播方式，是一种交互式传播——你可以在自己选定的时间和地点获得这个作品。比如看某集电视剧的时候觉得情节太拖沓，你可以自己拉进度条；或者听课的时候觉得老师讲得太慢，可以启动倍速；学到难的地方可以暂停下来做个笔记；学习累了想上个厕所，也可以暂停。这就是在自己选定的时间地点获得作品。没有经过许可就把别人的作品传播到网上、供网友在自己选定时间地点获得作品的，就侵犯了信息网络传播权。

这里要补充一个理论拓展：**把信息网络传播权跟广播权做一个区分**。它们都可以是有线的，也都可以是无线的，那什么时候是广播权的规范范围，什么时候是信息网络传播权的规范范围？

> **结论**：二者区分的核心在于——**公众能不能在选定的时间和地点来获得作品**。如果公众只能在特定的时间、特定的地方获得作品，不能自己选择，这是**广播权**的规范对象。

像曾小贤主持的《你的月亮我的心》，这个节目只能在特定的时间点播出——只能是后半夜，你想提前追这个节目，你是听不到的。这就是广播的传播方式。包括去年的一部电视剧《致 1999 年的自己》，里面那个角色萧寒在电台里点播了一首歌曲，这首歌曲只能在某个特定的频道、某个特定的时间播出，所以他必须守在收音机前才能够听到。但这个时间点上他家里面有人生病了，他去了医院，就错过了这个节目——你错过了就是错过了，听起来有点悲凉，有些事情真的是错过就是错过了，没有弥补的机会。这就是广播权的传播方式。

而信息网络传播权是有弥补机会的。比如你在网站上追剧，今天没空看，明天看也来得及，甚至昨天看过的觉得不过瘾还可以重看。它是有挽回机会的，这就是信息网络传播权。这是二者最本质的区别。

你看我们在春晚的时候看的**直播**，这是广播权的传播方式；你要在这个有线电视的经营平台上**回看**，回看就属于信息网络传播方式了。所以不是所有的电视节目都一定提供回看服务——有线电视的经营者要给公众提供回看服务的话，得给著作权人重新交一笔钱。包括我微博直播的时候，你看直播是广播的传播方式，我说的某句话你可能走神了或者网络不佳，错过就是错过了；那假设这个直播是有回看的，那就涉及信息网络传播权了，是不一样的。

> **易错点**：所以能不能说"在网络上传播，就一定是信息网络传播权的规范对象"？**不能**。**能够回看的才是信息网络传播权的规范对象；不能回看、只能实时观看的，是广播权的规范对象。**

我印象里前两年在微信视频号里，李健做过一场线上演唱会，那你就只能在当时观看，它没有回看——所以这里面涉及的是**广播权**的规范对象。一定要把两种权利区别开来，这是第一个方面：先掌握概念。

第二个方面是信息网络传播权的主体。著作权人享有信息网络传播权，同时按照法律规定，**表演者和录音录像者**也有信息网络传播权。尽管表演者和录音录像者属于邻接权人，他们也享有信息网络传播权。这意味着，要通过信息网络的方式传播别人的作品，需要经过**著作权人、表演者和录音录像者的三重许可并支付报酬**。

看教材例一。甲创作了歌曲《秋意浓》，由著名歌星乙演唱，丙公司录制成了 CD 公开发行——这是音乐作品传播的一个常见的产业链。甲是作品的著作权人，他写的歌；乙是表演者，是传播者；丙公司是录音录像者，也是作品的传播者。丁购买以后，把这个 CD 里的音乐文件上传到网络上供网民免费下载。丁的行为侵犯了什么权利？侵犯了**信息网络传播权**——因为你把音乐作品上传到网站以后，公众可以在自己选定的时间地点来获得这个作品。

关键是他侵犯了**谁**的信息网络传播权？他侵犯了著作权人甲、表演者乙以及录音录像者丙公司的信息网络传播权。也就是说，在事前的角度，你一定要把这个作品上传到网站上的话，需要经过甲、乙、丙公司的**三重许可并支付报酬**。

还补充一个结论：这三个主体一方面可以同时享有信息网络传播权，同时他们还**同时享有复制权和发行权**。也就是说，三类主体同时享有三项权利：复制权、发行权加上信息网络传播权。

看教材例二。还是创作歌曲《秋意浓》，由歌星乙演唱，丙公司录制 CD 公开发行。丁购买了正版 CD 以后，复制了大量盗版 CD——这个行为侵犯什么权利？侵犯**复制权**。同时在某网络交易平台公开出售这个盗版 CD——这个出售行为是不是涉及作品载体的物权转移？所以侵犯的是**发行权**。关键仍然是：丁的行为侵犯了谁的复制权和发行权？侵犯了著作权人甲、表演者乙和录音录像者丙公司的发行权和复制权，因为这三个主体都享有复制权和发行权。

> **结论**：记住这个结论——**三类主体，同时享有三项权利**（复制权、发行权、信息网络传播权）。

#### 设置权

设置权指的是**以设置视听作品的方法将作品固定在载体上的权利**。把别人的作品设置成视听作品来进行固定，就涉及设置权。

比方说，甲写了一个剧本，要拍摄成电视剧——这就是通过视频的方式把作品进行固定，那必须要经过著作权人的同意，否则会侵犯作者的设置权。

来看一个实践中真实发生的案例。北大的"满哥"创作了关于小满节气的原创诗句和视频文案。2022 年 5 月 21 日节气小满当天，奥迪公司通过各官方渠道发布了由刘德华主演的视频广告《人生小满》，这就涉嫌侵犯满哥的视频文案——人家写的文案，你奥迪公司没经过同意就把它拍成了广告视频，当然侵犯了满哥的权利，侵犯的是满哥的**设置权**。这样一个案例后来也被改编成了一道法硕真题。

#### 改编、翻译、汇编与获得报酬权

这四项放在一起讲，因为它们的共同点是"在原作品上再做一点文章"。

**改编权**指的是改变作品、创作出具有独创性的新作品的权利。我们前面讲演绎作品的时候说过，演绎的方式里面就包含着改编——在别人作品的基础上创作出新的行为，是要经过许可的。比方说李健参加《歌手》想演唱《父亲写的散文诗》这首歌，演唱首先要经过许可，否则侵犯表演权；他在演唱的时候想改变一下这首歌，把风格调整一下，这个改编行为也需要经过同意，否则侵犯别人的改编权。

> **提示**：即使李健没有经过同意就改变了别人的作品，是不是就要承担侵权责任呢？要。但是，只要他改编后的版本具有独创性，他也可以取得这个改编作品的著作权——就是我们前面讲演绎作品时涉及的问题。

**翻译权**说的是把一个作品从一种语言转换成另外一种语言。翻译本身也是一种演绎行为，是一种再创作行为，也要经过著作权人的同意。举个例子：德国著名民法学家弗鲁梅创作了德文学术专著《法律行为论》，这是一本民法著作，非常有名；迟教授把这部德文著作翻译成了中文，现在已经公开出版，翻译过来有 900 多页。迟教授在翻译这部学术专著的时候，要不要经过弗鲁梅的同意？当然要，否则会侵犯别人的翻译权。

**汇编权**指的是把别人的作品或者作品的片段，通过选择或者编排汇编成新作品，也要经过许可并支付报酬。前面讲汇编作品的时候我就提到过，汇编别人作品要经过许可，否则侵犯别人的汇编权。看一个例子：某出版社出版一本学术论文集，专门收集国内学者公开发表的关于民法典编撰的有关论文或者论文摘要。出版社在收录这些论文或者摘要的时候，要不要经过作者的同意？要的，否则就侵犯了原来论文作者的汇编权。

**获得报酬权**要放在最后讲，但它是前面全部权利的一个兜底。前面所有的财产权，涉及的行为你要实施都要经过许可；经过许可以后，你还得支付报酬，因为作者还有获得报酬权。比如余华写了小说《活着》，据说每年可以拿到上千万的版税，这就是著作财产权中获酬权的体现。余华自己戏称，靠《活着》这部小说而活着。

### 十三项财产权的体系图

13 项权利看起来庞杂，学起来也容易觉得杂乱，所以我在教材 245 页给大家画了一张体系图，供大家参考。这 13 种著作财产权大致可以分成四个层次：

```text
著作权法规定的 13 种著作财产权
│
├─ 第一层：最基础的财产权（2 种）
│    ├─ 复制权
│    └─ 获得报酬权
│
├─ 第二层：与作品载体的利用相关（3 种）
│    ├─ 发行权 ── 控制载体的物权转移
│    ├─ 出租权 ── 控制载体的使用权转移
│    └─ 展览权 ── 控制载体的公开陈列
│
├─ 第三层：与作品传播相关（4 种）
│    ├─ 表演权
│    ├─ 放映权
│    ├─ 广播权
│    └─ 信息网络传播权
│
└─ 第四层：与作品演绎相关（4 种）
     ├─ 改编权
     ├─ 设置权
     ├─ 翻译权
     └─ 汇编权
```

读这张图，从上往下看：最基础的是**复制权**和**获得报酬权**两项，其他权利其实更多的是从基本权利当中延伸出来的；著作财产权要保障的就是作者获得报酬的权利。与**作品载体的利用**相关的有发行、出租、展览三项权利，利用别人的作品，常常就是从载体上下手。作品在**传播**过程中产生的利益应当由著作权人享有，不同的传播方式产生不同的权利：表演、放映、广播、信息网络传播。最后是**作品演绎**相关的权利，即在原作品基础上进行再创作：改编、设置、翻译、汇编。

2 + 3 + 4 + 4，正好是 13 种权利。到这里，著作权的内容就齐了：**4 项著作人身权，13 项著作财产权**。

### 本讲提到的题目

讲著作权的内容，一定离不开真题检验。这一讲我们做了两道，一道考人身权，一道考财产权。

#### 题目一（人身权）

甲与乙约定，由甲从乙拍摄的照片中选择 150 幅供出版之用，为出版的必要。出版社将甲选出的部分照片做了修剪，出版物封面标明"甲著"，封底标明"乙摄影"。本案中出版社的行为应当如何认定？

**答案**：侵犯了乙的**保护作品完整权**，没有侵犯署名权（按本讲所讲选项为 D）。

**解析依据**见上文"保护作品完整权"与"署名权"两节的权能界定：出版社未经许可擅自修剪了别人创作的照片，改变了作品的内容，侵犯的是保护作品完整权；但在使用这些照片时封底已标明"乙摄影"，尊重了乙的署名权，所以署名权没有被侵犯。

#### 题目二（财产权）

A 公司委托 B 公司为其推出的新车制作视频广告，并同意 B 公司和 C 公司合作完成委托事项。C 公司让委托演员赵某出演该视频广告。C 公司制作完成以后，B 公司对该广告稍加改动，就交给了 A 公司，A 公司未严格审核，就在网络上公开发布。大学生王某发现该视频广告中采用的文案与自己公开发表的文章内容完全相同，但视频广告中并没有标明。侵犯了王某的哪些权利？

**答案**：侵犯了署名权、设置权、信息网络传播权，没有侵犯发表权（按本讲所讲应选 B、C、D 三项）。

**解析依据**见上文"发表权"与"信息网络传播权"两节：

- **发表权**：王某的文章已经自行在网上公开发表，发表权在发表时即已行使完毕，后续再传播不再侵犯发表权。
- **署名权**：视频广告利用了王某的作品却未作署名，侵犯了署名权（默认推定作者有署名意愿）。
- **设置权**：王某发布的是文字作品，A 公司把这个文案拍摄成视频广告，是通过视听作品的方式固定，属于设置行为，未经许可即侵犯设置权（北大"满哥"《人生小满》案即此情形）。
- **信息网络传播权**：该广告发布到网络上公开传播，公众可以在选定的时间和地点获得作品，侵犯信息网络传播权。

## 著作权的保护：侵权、期限与限制
> 对应块：BLK76 | 覆盖分集：P72 | 块标题（分集名）：《第04编 第02章：著作权（04）》

著作权这块，主体、客体、内容我们都已经过完了，剩下最后一块——著作权的保护。这个考点是 2025 年修订考试大纲时新加进来的内容，所以从今天这段开始，大家要打起精神。

它其实就三个问题：侵权怎么认定，保护期到底有多长，以及权利在什么情况下要被限制住。

### 责任方式：为什么会赔礼道歉

先看侵权成立之后怎么承担责任。著作权法给的方式包括：停止侵害、消除影响、赔礼道歉、赔偿损失。

这里面最需要留神的是「消除影响」和「赔礼道歉」。

> **易错点**：很多人一看著作权就默认是「赔钱」，但著作权法里明明白白写着消除影响、赔礼道歉。

为什么著作权法会有救济人格权的责任方式？因为著作权本身就包含着人身权的内容。著作权法不是一部纯粹调整财产关系的法律，它既管财产权，也管人身权——署名权、发表权、保护作品完整权都是作者的人格利益。既然有人身权在里头，就得通过消除影响、赔礼道歉的方式去救济。

而赔偿损失呢，主要救济的是财产损失那一头。

> **结论**：消除影响 + 赔礼道歉 → 救济人身权（人格权）；赔偿损失 → 救济财产权。两条线在著作权法里是并行的。

### 十一项侵权行为的分层拆解

侵犯著作权的具体行为，法律里列举了 11 项。

先说清楚一件事：这 11 项**并不是一个完全的列举**。前面讲著作权内容的时候我就提过，凡是未经许可实施的、落在著作权内容范围内的行为，都会构成侵权。我们讲过 4 项著作人身权、13 项著作财产权，每一项都能延伸出侵权行为来。11 项只是把最常见的拎了出来。

展开的思路很简单，就是按权利类型分三层看：

```text
              著作权法列举的 11 项侵权行为
                           │
        ┌──────────────────┼──────────────────┐
        ▼                  ▼                  ▼
     第 1～4 项         第 5～8 项        第 8～11 项
     著作人身权          著作财产权           邻接权
     发表权              剽窃                出版者版式设计权
     署名权              展览摄制/改编翻译     表演者权利
     修改权              注释等方式使用        （兜底条款）
     保护作品完整权      获得报酬权
                         出租权
```

第一层是第 1 项到第 4 项，侵犯的是著作人身权。

第 1 项，未经许可发表其作品的，侵犯的是发表权。

第 2 项，未经合作作者许可，将与他人合作创作的作品当作自己单独创作的作品发表的——这里要抓住「应当给别人署名而没有署名」，侵犯的是署名权。

第 3 项侵犯的也是署名权：没有参加创作，为谋取个人名利，在他人作品上署名。在别人的作品上，本来不应当署你的名字却署上了，这也是侵犯别人署名权的行为。

所以第 2 项和第 3 项是一体两面：一个是应当给别人署名而没有署名，一个是不应当给自己署名却署上了。

第 4 项，歪曲、篡改他人作品的，侵犯的是修改权和保护作品完整权。

第二层是第 5 项到第 8 项，侵犯的是著作财产权。

第 5 项是剽窃他人作品的，这一下侵犯的是整个著作权。

第 6 项是未经许可，以展览摄制视听作品的方法使用作品，或者以改编、翻译、注释等方式使用别人作品的。这说白了就是擅自利用别人的作品。

第 7 项，使用他人作品应当支付报酬而没有支付的，侵犯的是获得报酬权。

第 8 项就要特别注意了，它**既涉及侵犯著作财产权，也涉及侵犯邻接权**。未经视听作品、计算机软件、录音录像制品的著作权人、表演者或者录音录像制作者许可，出租其作品或者录音录像制品的原件、复制件的——这里面既有著作权上的出租权，也有邻接权上的出租权。

第三层是第 9 项到第 11 项，讲的是侵犯邻接权的行为。

第 9 项，未经许可使用出版者出版的图书、期刊的版式设计的，侵犯的是出版者这个作品传播者的邻接权。

第 10 项，未经表演者的许可，从现场直播或者公开传送其现场表演，或者录制其表演的，侵犯的是表演者的权利，表演者同样是邻接权人。

第 11 项是兜底，把上面没列到的其他侵犯著作权以及与著作权有关权利的行为一并兜进来。

```text
 读图：三层是从「权利类型」切开的
       人身权 1-4 ｜ 财产权 5-8 ｜ 邻接权 8-11
       注意第 8 项横跨财产权与邻接权，是唯一一项同时踩两条线的
```

大致有这么一个思路就可以了。不过话说回来，最全面的理解还是要回到前面讲过的著作权内容上去——把权利清单和侵权清单对起来看，比死记这 11 条有效得多。

### 保护期限：哪些权利会被时间吃掉

保护期限体现的是著作权作为知识产权的一个特点：它的保护要受到时间限制。

但「受不受限制」这件事，在著作权内部并不是一刀切。第一个层次的分界就在人身权内部。

#### 只有三项权利永不过期

著作人身权一共有四项：发表权、署名权、修改权、保护作品完整权。

其中署名权、修改权、保护作品完整权，**不受期限限制**。这是著作人身权里最核心的那三项，跟着作者一辈子，也跟着作品一直存在下去。

> **易错点**：发表权虽然也是著作人身权，但它受期限限制。

这一点一定要单独拎出来说。前面我们把人身权四项背成"发、名、改、保"，一紧张就容易以为人身权统统不过期。不是的。

为什么发表权要设期限？因为发表权是让作品向不特定的人公开的一个行为。假设发表权的保护不受期限限制的话，一些优秀的作品可能永远无法合法地向世人公开了——这显然不合理。所以发表权也要受到期限的限制。

把这一层捋清楚，就是：

```text
  署名权 · 修改权 · 保护作品完整权 ─────────────►  不受期限限制
  发表权 ───────────────────────────────────────►   受期限限制
  著作财产权（13 项）───────────────────────────►   受期限限制
```

#### 到底保护多久：看作者是自然人还是组织

再往下算年限，就要区分作者是自然人还是组织，两套规定。

**作者是自然人的**，保护期限是作者终身，加上死后的 50 年。

这意味着两件事：第一，只要作者活着，他的发表权、著作财产权就一定受到保护；第二，他死后还会再追加 50 年的保护期。

而且这个 50 年**不是整算 50 年**，要保护到第 50 年的 12 月 31 号。

举个例子。金庸先生写了很多部非常优秀的武侠小说，这些小说的发表权以及著作财产权保护到什么时候？首先，金庸先生终身都获得保护；其次，金庸先生是在 2018 年 10 月 30 日去世的，死后追加 50 年，要保护到 2068 年，而且是保护到 2068 年的 12 月 31 日，不是整算 50 年。

讲义里还有一个例子，琼瑶阿姨也写了很多部优秀的小说，她作品的财产权以及发表权的保护期限同样是作者终生加死后 50 年。琼瑶阿姨是在 2024 年 12 月 4 日去世的，那保护期限就延长 50 年，要到 2074 年的 12 月 31 日。

> **结论**：只要能确定作者是哪一年去世的，就可以确定保护期限，**不用去纠结到底哪一天去世的**。

**作者是组织的**，就是那些满足法律规定、能够以自己的意志承担责任的，可以视为作者的情形。法人作品、非法人组织的作品属于这一类。这样的作品，保护期限是自作品首次发表后第 50 年的 12 月 31 日。

区别就在这：作者是个组织，就没有「终身」这一说了，直接从作品首次发表开始算。

### 合理使用与法定许可：一句话的差别

作品的传播是可以促进社会进步的，所以法律对著作权的保护也是有所克制的。著作权法专门设置了两项制度来限制著作权——**著作权的合理使用**和**著作权的法定许可**。

这两个词是 2025 年修订考试大纲时新加进来的。考试大纲里只用了一句话描述它们：「著作权法第 24 条和 25 条，规定了著作权保护的限制制度。」就这么一句。

所以大家感觉这个考点到底增加了没有增加？说没增加吧，它确实告诉你第 24 条、第 25 条有这个规定；说增加了吧，它又没有涉及法律条文的具体规定。这个考试大纲的编写者还是比较狡猾的。

> **结论**：既然写了这么一句话，我还是希望大家把这两项制度真正了解清楚。

两者对著作权的限制方式不一样：

```text
                    过车闸（需权利人许可？）   买票（支付报酬？）
   合理使用                  不需要                  不需要
   法定许可                  不需要               事后必须补上
```

**合理使用**：在符合法律规定的情形时利用作品，既不需要经过许可，也不需要支付报酬。相当于你可以随便上车，而且不用买票。

**法定许可**：利用作品时不需要经过许可，但得支付报酬。相当于你可以直接上车，但事后得补票。

### 合理使用：不经许可，也不必付报酬

#### 门槛：公共利益优先

合理使用基本上快把著作权的权利给剥夺了，所以必须要有充足的理由才能够启动。教材里补充了一个理论拓展上的问题：什么时候才可以启动合理使用制度？

主要是涉及公共利益维护的时候。公共利益优先获得保护，著作权就要退居其次。

在限制的时候，通常要遵循以下原则：

- 合理使用常常**仅限于已经发表的作品**。作品没有发表的，常常不能适用合理使用制度；
- 通常**限于非商业性的使用**。既然是为了公共利益，那就不能是为了经营目的或者商业目的；
- 使用的**程度必须适当**，不得超过合理的限度；
- 通常**不会给著作权人的利益造成重大的损害**。

要同时满足这些条件，才能适用合理使用制度。

另外著作权法在第 24 条里专门设了一个很长的条文来规定适用情形，总共有 13 项内容。你看到这个条文就知道为什么考试大纲没有把它写进教材了——太占地方了。

条文的结构是：存在下列情形之一的使用作品，可以不经许可，而且也不需要向其支付报酬，这就是对著作权进行相应的限制。**但应当指明作者的姓名或者名称以及作品的名称**——合理使用还是要尊重著作权人的人身权利，保障他的署名权。

#### 个人学习与适当引用

第 1 项，是为了个人学习、研究或者欣赏，使用他人已经发表的作品的。核心词是**个人目的**。

看教材例一：刀郎创作了歌曲专辑《山歌寥哉》，甲购买了正版的录音制品，用于个人欣赏，在家里面用 DVD 播放这个唱片——这其实也是通过其他方式来播送别人作品的表演。这样的行为要不要经过许可或者支付报酬？当然不需要，基于生活常理也就能理解，这是个人欣赏的目的。

但这里面只能涉及**他人已经发表的作品**。作品没有发表的，不适用合理使用制度。

顺着这个思路再问一句：有同学自己买了一本盗版书，通过学习这个盗版书来备考法硕，算不算侵权行为？注意，答案是**不构成侵权行为**，因为你是为了个人学习的目的来使用作品。

第 2 项，为介绍、评论某一作品或者说明某一问题，在作品中适当引用他人已经发表的作品的。

比如我们写毕业论文要做文献综述，研究问题的时候也得参考别人已经完成的研究，难免要去引用别人已经发表的作品。尽管这一段是复制粘贴过来的，但它并不构成侵权，因为这是合理使用。

> **注意**：当然引用别人的作品得受到程度的限制，你只能是「适当引用」。

说到这个「适当」，我们可以拿论文重复率来直观感受一下。据我所知，本科毕业论文的重复率不能超过 20%，我记得我在上博士的时候，博士论文的重复率不能超过 10%。

所以有同学在写论文的时候参考了很多文献，引用了别人作品中的观点，同时还加上了脚注，看起来比较规范，但一查重发现重复率达到了 30%。能不能抗辩说「虽然是重复的，但我不是抄的，我都加了脚注」？**不行。**

因为我们查重查的是重复率，而不是抄袭率。尽管引用的内容都加了脚注，但你引用的部分超过了限度，你这个论文的独创性标准就达不到，就不让你答辩了。所以在提交论文之前一定要先查重——即使你援引了别人的作品、加了脚注、符合学术规范，比例也不能超过限度。

#### 新闻报道、公共服务与馆藏

第 3 项到第 5 项都跟新闻报道相关。

第 3 项，为了报道新闻，在报纸、期刊、广播电台、电视台等媒体中不可避免地再现或者引用已经发表的作品的。这是新闻报道的需要，体现为公共利益的目的。

第 4 项，新闻媒体刊登或者播放其他媒体已经发表的关于政治、经济、宗教问题的时事性文章的，可以适用合理使用制度。既然是时事性文章，它必然包含着公共利益，为了新闻报道的需要可以直接利用。

第 5 项同样是新闻报道场景下的媒体使用。它之所以也能直接利用，而且不需要支付报酬，原因还是一样：这类利用本身包含着公共利益，是为了新闻报道的需要。

第 6 项，为学校课堂教学或者研究需要，翻译、改编、汇编、播放或者少量复制已经发表的作品的，只要是供教学科研人员使用，也可以适用合理使用。

比如大家考研上岸以后，很多专业课会通过研讨课的方式进行。某一堂课要组织大家讨论名誉权保护的问题，那就要把一些已经发表的民法相关的著作或者文章收集起来，每个同学打印一份，大家来讨论——这样的行为也可以受到合理使用制度的保护，既不需要经过许可，也不需要支付报酬。

当然，在讨论名誉权相关文章的时候，你很可能会下载到我写过的文章，一样可以适用合理使用制度。

第 7 项，国家机关为执行公务，在合理范围内使用已经发表的作品的。既然是国家机关执行公务，它也必然包含着公共利益。比如人民法院在做判决的时候，也有可能援引知名学者的观点，这个时候也可以构成合理使用。

第 8 项，图书馆、档案馆、纪念馆等为陈列或者保存版本需要，复制本馆收藏的作品的。像一些古籍文件比较珍贵，如果读者去借的时候都把原件拿出来的话，那不利于古籍的保护，所以可以制作一些复制品让大家去查阅，把古籍更好地保护起来——这也是合理使用。

#### 免费表演：双向免费才算数

第 9 项是考试当中比较容易考到的：**免费表演**。

它构成合理使用要同时满足几个条件——免费表演已经发表的作品；该表演未向公众收取费用，也未向表演者支付报酬；而且不以盈利为目的。

这叫**双向免费**的表演：表演的人没有拿钱，观看表演的人也不需要付钱。

看教材例二：甲参加同学聚会，在 KTV 演唱《死了都要爱》——别人唱歌要钱，他唱歌要命。甲在 KTV 里给他的好朋友唱歌，他自己没有拿钱，同时他的好朋友听他唱歌也不需要付钱，所以构成合理使用。乙在女友的生日宴会上演唱《爱你一万年》，这也是完全免费的表演。丙下班以后跳广场舞的时候播放音乐《最炫民族风》，也是在公开播送别人作品的表演，但同样是完全免费的，所以都可以构成合理使用。

但是大家看例三：如果是在**赈灾义演**的晚会上演唱歌曲，那这个时候就不能适用合理使用了。因为赈灾义演意味着，虽然唱歌的人没拿钱，但听歌的人是要买票的。这相当于用别人的作品来做慈善、借花献佛，这是法律所不允许的。所以在这种公益晚会上演唱别人歌曲的，照样得支付报酬。

再看一个现在很常见的场景：有些网红在网络直播的时候演唱别人的歌曲，能不能适用免费表演的合理使用？**通常是不可以的。**因为网络直播，特别是这种网红直播，它不是完全免费的——他是为了让粉丝给他打赏的。你不能说你唱了别人的歌，然后让粉丝再给你去打赏，里外都是你赚。法律不给你这样的机会，这要构成侵权。

> **提示**：判断免费表演，核心就盯住「双向免费」这四个字。

#### 公共场所艺术作品与翻译

第 10 项，对设置或者陈列在公共场所的艺术作品进行临摹、绘画、摄影、录像的，也可以构成合理使用。

比如大家去一些网红景点参观的时候，会和一些网红建筑、网红雕塑合影拍照留念，这样的行为是合理使用，既不需要经过同意，也不需要支付报酬。前面提到的那个例子也是——河南有一个村子的油画挂在墙上，好多游客慕名而来，跟这幅油画拍个照片作为纪念，这个拍照的行为不需要经过作者同意并支付报酬，属于合理使用。

第 11 项，把中国公民、法人或者非法人组织已经发表的、以国家通用语言文字创作的作品，翻译成少数民族语言文字作品在国内出版发行的，也可以构成合理使用。

这项规定是为了方便汉语言文字的作品在少数民族地区传播而设置的。里面有几个限定词，缺一不可：

| 限定维度 | 具体要求 | 越界会怎样 |
| --- | --- | --- |
| 作者身份 | 必须是中国的作者，包括中国公民、中国法人或非法人组织 | 作者是外国人的，不能用这个制度——人家外国人没有让作品在少数民族地区传播的义务 |
| 发表状态 | 必须是已经发表的作品 | 未发表的作品不适用 |
| 翻译方向 | 只能从国家通用语言文字（汉语）翻译成少数民族语言文字 | 翻成英语不行；从少数民族语言翻回汉语也不行 |
| 出版地点 | 只能在国内出版发行 | 拿到国外出版不行 |

只有同时满足这些条件，才能适用合理使用制度。

看教材例四：某大学中文系的英籍留学生马克用汉语创作了一篇小说，发表在文学杂志上，乙未经同意也没有支付报酬，就把这部小说翻译成了藏语，然后在中国出版发行。乙的行为构成侵权吗？构成。关键在于不构成合理使用——因为作者是英籍留学生马克，他不是中国人，不适用这个合理使用制度。未经同意翻译别人的作品，侵犯的是著作财产权中的翻译权，要承担侵权责任。

第 12 项是为了保护阅读障碍者的权利而设置的：以阅读障碍者能够感知的无障碍方式，向其提供已经发表的作品的，可以构成合理使用。

这一项和第 11 项形成了非常鲜明的对比：作者**不限于中国人**了，语言文字**也不受限制**，而且**不限于在国内出版**。因为保护阅读障碍者的阅读权利，是全世界都应当履行的义务。

还是教材例四，还是马克的那篇小说，乙未经同意也没有支付报酬，把小说改编成了**盲文**在中国出版。改编成盲文这个行为要不要承担责任？不需要。因为改编为盲文是为了保障阅读障碍者的阅读权利，即使作者是外国人，也一样受到合理使用制度的限制。

第 13 项是兜底条款。

> **结论**：著作权法第 24 条规定的这 13 种情形，一旦成立，利用作品一方面不需要经过许可，同时还不需要支付报酬，但更多的是为了公共利益的需要。

### 法定许可：先上车，事后补票

法定许可的适用情形，常常涉及优秀作品，要鼓励它多传播。所以传播这些作品的时候不需经过许可，降低了门槛；但既然是优秀的作品，法律要保障作者取得报酬的权利，是得付钱的。

#### 教科书法定许可

这是著作权法第 25 条规定的：编写出版教材时适用的法定许可。

为实施义务教育和国家教育规划而编写的教材，可以不经著作权人同意，在教科书里面汇编已经发表的作品片段或者短小的文字作品、音乐作品，或者单幅的美术作品、摄影作品、图形作品，但应当向著作权人支付报酬。

> **易错点**：这里对「教科书」有严格的限定——只能是为了实施义务教育和国家教育规划而编写的教科书。

我们从小学到中学到大学，教材里都有一些比较优秀的作品。把这些作品编到教材当中，一方面可以服务于教育事业，另一方面可以促进这些优秀作品更加广泛的传播，所以适用法定许可：编入教材不用经过同意，但事后得支付报酬。

看教材里的例子：著名散文家梁衡创作了文章《青山不老》，有同学可能读过，人教版六年级的语文教材就把它编进去了。教材的编写者要不要找作家来取得许可？**不需要**，可以直接把文章编进来，但事后得支付报酬——因为人家的作品很优秀，你用了以后得付钱。

这就意味着，如果不是义务教育或者国家教育规划教材，就不适用这个法定许可制度了。比如课外的教培材料，它就不是为国家教育规划而编写的教材，这时就不能适用法定许可。你要用别人的文章，得经过许可并支付报酬，**经过同意你才能上车。**

#### 报刊转载法定许可，以及网络转载为什么不行

这是著作权法第 35 条规定的。

作品刊登以后，除了作者声明不得转载以外，其他报刊可以转载或者作为文摘资料来刊登，但事后要向著作权人支付报酬。

《读者》《青年文摘》这样的杂志大家都读过，它们上面的文章很多都不是原发的，而是从其他杂志转载过来的。转载的时候不需要经过同意，但事后得支付报酬——因为常常只有优秀的作品才会被转载，这可以促进优秀作品的传播。

说到这个，我讲一个我自己的真实经历。我有一篇学术论文发在法学类期刊上，题目是研究英国的诽谤法。后来这篇文章被中国人民大学复印报刊资料《民商法学》2015 年的第 12 期全文转载了。过了不知道多久，我突然收到了一笔汇款——人大复印资料给我转来了 300 块钱的稿费。

你看，转载其实也是一个复制发行的过程，但它没有经过作者的同意。那作者是什么感受呢？作者其实也很荣幸，可以多多转载，但事后得支付报酬。这就是法定许可。

> **易错点**：报刊转载的法定许可，**只能适用于作品刊登以后其他报刊进行转载，它不能适用于网络转载。**

比如某个同学有个人网站或者个人公众号，觉得别人的文章写得很好，能不能直接转载过来？**不行。**能不能说「我给你钱呀」？**也不行。**因为网络转载不属于「其他报刊的转载」，它就不能适用这个法定许可制度。

你在网上转载别人的文章，涉及的是作品的信息网络传播权。有没有经过同意就擅自转载，是要承担侵权责任的——不是说你事后给钱就完了，你是要承担赔偿责任的。这个性质是不一样的。

### 一道真题把三块内容串起来

2024 年考过一道单选题，题干是这样的：

> 某公司利用人工智能技术生成虚拟歌手 X，并将 X 演唱甲的成名歌曲的音频上传到了互联网。该歌曲由乙作词作曲。问：该公司的行为是否构成侵权，侵犯了谁的著作权？

答案是构成侵权，关键在于侵犯了谁的著作权。那就要看这个歌曲的著作权人是谁——是作词作曲的乙，所以选 B 选项。

为什么不是甲？尽管这首歌是甲的成名曲，由甲来演唱，但甲是**表演者**，他并不是著作权人。

顺便说，现在一些音乐软件当中确实有 AI 生成的歌曲，有些唱得还不错。但这道题里，选项还涉及合理使用和法定许可，我们顺手也排掉：显然不属于合理使用，因为它不属于法律规定的情形，特别是它完全没有涉及公共利益维护的问题；也不是法定许可，因为它是在网上传播作品。

> **结论**：著作权这块的内容全在这儿了。一方面从理论角度把握著作权的法律特征——人身权与财产权的二元结构、权利的时间性、权利本身还要受到限制；另一方面从规范层面重点关注四个基本点：主体、客体、内容，加上保护制度。

### 本讲提到的题目

**例一（个人欣赏）**：刀郎创作专辑《山歌寥哉》，甲购买正版录音制品用于个人欣赏，在家用 DVD 播放该唱片。甲的行为构成侵权吗？
不构成。属于合理使用第 1 项，核心是「个人学习、研究或者欣赏」的个人目的，且作品已经发表。详见「个人学习与适当引用」。

**例二（免费表演）**：甲在同学聚会 KTV 演唱《死了都要爱》、乙在女友生日宴会演唱《爱你一万年》、丙下班后跳广场舞播放《最炫民族风》，是否构成侵权？
均不构成。三个场景都是双向免费——表演者没拿钱，观众也不用付钱，符合免费表演的合理使用。详见「免费表演：双向免费才算数」。

**例三（赈灾义演）**：在赈灾义演晚会上演唱他人歌曲，是否构成合理使用？
不构成。表演者虽未获报酬，但听歌的人需要买票，只满足单向免费，不满足「未向公众收取费用」的条件，照样应支付报酬。详见「免费表演：双向免费才算数」。

**例四（翻译的两个变体）**：英籍留学生马克用汉语创作小说并发表，乙未经同意也未付报酬：（1）翻译成藏语在国内出版发行；（2）改编成盲文在国内出版。
（1）构成侵权，侵犯著作财产权中的翻译权——第 11 项合理使用要求作者为中国公民、法人或非法人组织，马克是外国人，不适用；（2）不构成侵权，属于第 12 项无障碍合理使用——作者国籍、语言文字、出版地均不受限制。详见「公共场所艺术作品与翻译」。

**2024 年单选题**：某公司利用人工智能技术生成虚拟歌手 X，将 X 演唱甲的成名歌曲（乙作词作曲）的音频上传至互联网，该公司的行为是否构成侵权，侵犯了谁的著作权？
构成侵权，选 B，侵犯乙的著作权。甲只是表演者，不是著作权人；该行为也不属于合理使用或法定许可。详见「一道真题把三块内容串起来」。
