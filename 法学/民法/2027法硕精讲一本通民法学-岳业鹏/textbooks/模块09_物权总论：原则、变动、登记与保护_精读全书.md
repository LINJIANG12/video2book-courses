## 物权概述：概念、效力与分类
> 对应块：BLK45 | 覆盖分集：P42 | 块标题（分集名）：《第03编 第01章 第01节：物权概述》

### 一静一动：物权与债权为什么长得不一样

从第三遍开始，我们正式进入民法的财产权部分。

前面讲民事权利分类的时候提到过，民法中的财产权有两大支柱：一种叫**物权**，一种叫**债权**。物权规定在民法典第二编，债权规定在第三编。这两根柱子撑起了现代财产法。

而它们的性格完全不一样：

> **结论**：物权从**静态**角度描述财产的**归属**关系；债权从**动态**角度规范财产的**流转**关系。一静，一动。

正因为物权管的是归属，它可以向不特定的多数人主张——说人话就是"全世界都是义务人"；所以物权性质上属于**绝对权**，也叫**对世权**，效力非常强大。债权管的是流转，只牵涉特定的当事人，只能对特定当事人主张，属于**相对权**，也叫**对人权**，效力相对温和。

效力强弱不同，法律规范它们的思路也就完全不同。物权采取**法定主义的立法模式**：物权的种类和内容都要由法律来规定。讲师打了个比方，这相当于法律给它带了个紧箍咒，把效力圈定在一个可控的范围内。债权是相对权，更看重当事人的约定，走的是意思自治的路子。

所以学习物权，第一件事是树立**物权法定**的观念：一方面，物权这一部分要学哪些内容，主要看法律规定了哪些；另一方面，每一种物权当时能不能取得、取得以后产生什么效力，都要回到法律的规定去做判断。

> **易错点**：不要把你过多的生活经验、或者所谓朴素的正义观塞进物权判断里。因为常常靠不住。最靠得住的，还是法律的规定。

顺便说下考情。物权编既是学习的重点，也是学习的难点。过去二十年里，简答题考过 10 次，法条分析题考过 7 次，论述题考过 5 次，案例分析题和客观题也几乎是年年必考。分量摆在这里，一定要高度重视。

### 物权编的框架：三大类，十一小类

物权采取法定主义立法模式，类型由法律规定。按照现行民法典，物权的类型主要包括三大种：**所有权、用益物权、担保物权**。注意这几个词都是标准的法言法语。

但民法典在规范时并没有从所有权直接开写，而是先做了一次**公因式的提取**，把各种物权的共性内容抽出来，形成**物权通则**；然后在具体分编里展开三种物权的具体规则；最后在物权编中还规定了一项叫**占有**的制度——它虽然不是独立的物权类型，但占有人对物的适当控制跟物权的效力非常类似，所以被放进物权编来规定。

```text
第一分编  通则 ───── 各类物权的共性规则：三要素 + 变动 + 保护
第二分编  所有权  ┐
第三分编  用益物权 ├─ 三大类 · 11 小类
第四分编  担保物权 ┘
第五分编  占有 ───── 不是独立物权类型，但控制效力近似物权
```

读图：通则是从三类物权里提取出来的"公因式"；所有权、用益物权、担保物权是三大主类；占有制度单列一编兜底。学习顺序上先走通则，再分头展开各分编。

通则部分要围绕那个"五个基本点"展开——先是**三要素**（主体、客体、内容），再是**变动**和**保护**。这两个层次我们在后面讲特征时还会再遇到。

在钻进具体考点之前，先把逻辑导图里的核心概念补齐——非法学的同学、以及法学基础比较薄弱的同学，第一轮要靠这几个概念才能跟上节奏。

```text
物权 ── 3 大类 / 11 小类
│
├─ 所有权（3）
│   ├─ 一般所有权
│   ├─ 建筑物区分所有权
│   └─ 共有
│
├─ 用益物权（5）
│   ├─ 土地上的用益物权（3）
│   │   ├─ 土地承包经营权
│   │   ├─ 宅基地使用权
│   │   └─ 建设用地使用权
│   └─ 其他用益物权（2）
│       ├─ 居住权
│       └─ 地役权
│
└─ 担保物权（3）
    ├─ 意定：抵押权、质权
    └─ 法定：留置权
```

#### 所有权：对自己东西的全面支配

这个词生活里经常听到，不学民法也认识。甲买了一部手机，就取得对这部手机的所有权——"这个手机是我的"，可以占有、使用、收益、处分。**所有权体现为权利人对自己动产或不动产的全面支配。**

民法典在"所有权"下面又展开出两种比较特别的所有权，都是标准的法言法语。

**建筑物区分所有权**，特殊性体现在**客体比较多元**。这个词听起来抽象，生活里却经常见到：甲买了某个小区的商品房，成了这个小区的业主。基于业主这个身份，他同时拿到三项权利：一是对自己那套房子的**所有权**，二是对小区公共设施的**共有权**，三是对小区重大事项**参与管理的权利**（开业主大会、参与投票）。这三项权利法律上给他打了个包，取个名字就叫建筑物区分所有权。既包括自己的房屋，也包括小区的公共设施，还包括小区的共同事项。

**共有**，特殊性体现在**主体是两人以上**。比如甲乙是夫妻，用夫妻共同财产在某个城市买了一套商品房，对这个房子取得所有权。主体是复数，就构成共有状态。共有的特别问题在于：在一个所有权关系里，一方面要解决对外如何行使所有权（甲乙之间谁做主），另一方面关起门来，甲乙之间内部也会形成一些权利关系。

#### 用益物权：对他人财产使用价值的支配

**用益物权体现为权利人对他人财产的使用价值的一种支配。**

举个例子。我国农村的农业用地采取包产到户的政策：假设某村有一块耕地叫 A 地块，承包给了某农户，这个农户就对 A 地块取得了**土地承包经营权**。农户可以对这块地占有、使用、收益，从事农业生产。注意，这块地的**所有权仍然归属于集体**，但农户对这块有所有权的地可以进行使用价值的支配——这就叫用益物权。

民法典一共规定了五种具体的用益物权，我们按"是否发生在土地上"分成两大类。

先看在**土地上**设立的用益物权，农村和城市各来几个。农村的土地原则上归集体所有，但集体常常不亲自利用，民事主体要通过取得用益物权的方式对集体的土地进行利用——这就是用益物权存在的价值。

- **土地承包经营权**：农业用地承包给农户，农户对集体享有所有权的 A 地块占有、使用、收益，从事农业生产，支配土地的使用价值。
- **宅基地使用权**：某农户向村集体申请一块宅基地，比如 B 地块，取得宅基地使用权，在 B 地块上建造住宅，满足自己居住的需求。同样是农户对集体享有所有权的 B 地块的使用价值进行支配。
- **建设用地使用权**：某开发公司 X 在北京拿了块地叫 C 地块，用来开发商品房，开发商对 C 地块取得的权利就叫建设用地使用权，可以在 C 地块上建造建筑物及附属设施。它同样是对国家享有所有权的土地的使用价值进行支配。

再看不基于土地、而是为特定目的设立的**其他用益物权**，主要有两种。

**居住权**，就是在他人住宅里面进行居住的权利。看老王的故事：老王有两个儿子，大王和小王。老妈奋斗一辈子只买了一套房子，这套房留给谁，老王很纠结。一方面从情理上他希望留给大儿子大王，因为大王聪明能干，能让房子保值增值；另一方面小王有先天疾病，生活没有保障，他怕自己去世后小王无家可归。民法典的居住权制度正好化解这个担忧：老王可以把房子的**所有权**留给大王，同时给小王设定一个**终身的居住权**——只要小王活着，他就可以一直住在这个房子里。房子的所有权人是大王，小王却能终身居住，这叫居住权。

**地役权**，体现为利用他人不动产来提高自己不动产效益的权利。甲公司和乙公司分别取得相邻地块的建设用地使用权开发商品房，乙公司的土地位置比较优越、靠海，可以建海景房。甲公司的房子是不是海景房，主要取决于乙公司盖得有多高。于是甲公司找乙公司谈判：你们盖房子的时候不要那么卷，不高于三层，然后我一次性给你 5000 万现金。乙公司一想，一方面盖的房子不超过三层成本也低，另一方面还能一次性拿到 5000 万现金，何乐而不为？双方签订合同后，甲公司就取得了地役权——基于不让乙公司在自己土地上盖高楼这一方式，提升了自己土地的使用效益，使自己地上盖的房子也能卖海景房、卖更好的价格。

#### 担保物权：对他人财产交换价值的支配

**担保物权体现为权利人对他人财产的交换价值的支配。**

还是按揭贷款买房这个最常见的例子。甲要买房子，付了首付后向银行贷款，银行为了确保债权能够收回，要求甲把房子抵押给银行，银行就对甲买到的房子取得了一个**抵押权**。主体是银行，客体是甲的房子，内容则体现为：当甲不还贷款时，银行可以请求拍卖这个房子、就卖得的价款受偿——不管甲还欠别人多少钱，都是银行先来拿。银行能享有一个**优先受偿权**，这就是对他人财产拍卖变卖所得价款进行优先受偿的物权。

民法典规定了三种担保物权：**抵押权、质权、留置权**。前两种基于当事人约定设立，第三种由法律规定直接设立。

**抵押权**的核心特点是**不转移占有**。还是刚才按揭贷款：房子抵押给银行时，不需要把房子交给银行，甲依然可以在自己买的房子里居住。所以抵押这个担保物权的取得，担保物权人并不占有担保财产。

**质权**跟抵押权相比，最大的特点在于**要转移占有**。老岳母借给车某 10 万块钱，这是一个金钱债权。为了担保债权实现，车某把自己的一块名表交到老岳母手中作为担保。车某不还钱时，老岳母可以卖掉这块名表实现优先受偿。老岳母对这块名表取得的权利就叫**质权**。手表在老岳母的控制之下，是不是比较有安全感？

**留置权**是法定的担保物权。甲的手表坏了，找乙修理厂修理，双方成立一个以修理为内容的承揽合同。乙把手表修好以后，甲只是不给钱，乙就把手表扣下来了。催告宽限期后甲仍然不付钱，按照法律规定，乙对手表取得**留置权**，可以拍卖变卖手表，优先清偿自己的修理费债权。

> **易错点**：留置权的取得**不需要甲乙就留置事项达成一致**，只要符合法律规定的条件，乙就可以直接取得。所以它是法定的担保物权。

三类 11 小类，就是物权编的学习任务。这就完了。

### 什么是物权：沿着三要素把概念读一遍

现在进入第一章物权通则。这一章讲物权领域的基础理论以及各种类型物权的共性规则，内容相对抽象、不那么接地气，所以一定要结合教材里给的例子去理解。

先解决第一个问题：什么叫物权。

教材里写的这个定义，跟我们官方考试分析有点不太一样。掌握的时候还是按照教材里写的概念来掌握，因为它是**民法典第 114 条第 2 款的原文**，相对来讲更规范。物权的概念要通过**要素描述**来形成，所以要关注三个关键词：**主体、客体、内容**，另外还要注意一个"依法"。

> **定义**：物权是指**权利人依法对特定物直接支配和排他的权利**。（民法典第 114 条第 2 款）

拆开看：

**主体**叫权利人，范围比较广泛，自然人、法人、非法人组织都可以成为物权的主体。

**客体**体现为四个字：**特定的物**。也就是民法中的"物"——特定的物，它既包括动产，也包括不动产：甲买了套房子，客体是不动产；甲买了部手机，客体是动产。当然，法律规定的**权利**也可以成为物权的客体，这是例外。比如甲买到的房子，一方面他取得房屋的所有权，另一方面还相应取得该土地的建设用地使用权。当甲把这个房子抵押给银行时，银行抵押权的客体一方面是甲的房屋所有权，另一方面是相应范围内的土地的**建设用地使用权**。可见像建设用地使用权这种用益物权，它可以成为抵押权这种物权的客体。

**内容**体现为两个词：**直接支配**加**排他**。物权经常属于支配权，要直接支配这个物；同时因为效力强大，体现"一物一权"的属性，所以还具有排他性。

**依法**这两个字为什么出现在概念里？因为物权效力比较强大，所以采取法定主义立法模式。

三要素加上"依法"，就形成了物权的概念。概念的要素思路非常清晰，建议大家就按这个来掌握。

```text
                    物权内容 = 直接支配 + 排他
                    │
          ┌─────────┴─────────┐
        对人                对物
          │                   │
      优先效力             追及效力
          │                   │
     同物上遇到他人权利    物被占有人带离时，
     物权人优先            权利人追至物之所在

     排他效力：同一物上不得并存两项内容相冲突的物权
```

读图：概念里只写了"直接支配 + 排他"两个词；后面讲效力时展开成优先、追及、排他三项，其中优先与追及都是从"直接支配"里延伸出来的。

**直接支配**怎么理解？体现为物权**内能实现**，不需要别人的帮助，自己就可以直接实现，所以效力非常强大。甲买了一部手机取得所有权，行使所有权需不需要别人配合？不需要，别人不干涉，这个手机怎么用、要不要送人，完全由甲自己决定。这就叫直接支配。

**排他**体现为"一物一权"的属性。既然物权效力这么强大，原则上**一个物上不能存在两个内容相冲突的物权**，特别是一个物上不能有两个所有权——不能，这叫**一山不容二虎**，体现排他的效力。

### 物权的特征：教材那六个比较维度

第二个问题是物权的特征，这是一个理论问题。

物权的特征是从**它和债权的比较**当中形成的。你和你的兄弟概念之间的区别，常常就体现为你的特征。所以"物权的特征""债权的特征""物权和债权的区别"，这三个题目展开的内容是一样的。教材里对物权和债权的区别做了一个比较详细的展开，是主观题，非常重要的考点。

教材从**六个方面**来比较。这六个方面要注意掌握它展开的思路——后期背诵时经常会用到这个表达的逻辑：民法在描述某种权利的特征时，常常分成两个层次，第一个层次**描述这种权利的性质**，也就是你的上位概念是什么、你属于哪个领域的概念，这叫**体系定位**；第二个层次是从**要素角度**来展开，涉及我们一直强调的五个基本点：三要素（主体、客体、内容）+ 变动 + 保护。

> **结论**：教材里物权和债权的区别 = 1 个体系定位（性质）+ 5 个基本点（主体、客体、内容、变动、保护）。

| 比较维度 | 物权 | 债权 |
| --- | --- | --- |
| 一、性质（体系定位） | **支配权**，行使权利不需要别人配合 | **请求权**，需债务人配合方能实现 |
| 二、主体（效力范围） | 义务主体**不特定**，绝对权 / 对世权，可向全世界主张 | 义务主体**特定**，相对权 / 对人权，仅对特定债务人主张 |
| 三、客体 | **特定的物**（法律规定的权利为例外） | 债务人特定的仅为或不为一定行为 |
| 四、内容（权利效力） | 优先、追及、排他——"卷王派"，争强好胜 | 平等、相对、相容——"佛系派"，强调平等 |
| 五、变动 | **法定主义**，类型与内容由法律规定 | **任意主义**，重当事人意思自治 |
| 六、保护 | 物权请求权（恢复物权圆满状态）+ 损害赔偿 | 违约责任：继续履行 + 赔偿 |

读表：第一行是体系定位，后面五行是五个基本点，这正是背诵时的展开逻辑。

逐行看要点。

**性质**。物权属于**支配权**——概念里出现了"直接支配"，行使权利不需要别人配合。债权属于**请求权**，内容体现为请求特定义务人履行特定的不为行为，债权的实现需要债务人配合才能达成目的，所以效力相对弱一些。

**主体**。注意这一栏描述的不是权利主体，而是**义务主体**，体现的是权利的效力范围不同。物权的义务主体是**不特定的多数人**，所以属于绝对权、对世权，可以向全世界主张，物权人以外的所有人都是义务人，权利效力范围广。债权这边是特定的相对方，所以属于相对权、对人权，效力范围仅仅局限在特定的义务人身上。

**客体**。物权的客体主要是特定的物（法律规定的权利在例外时也可以成为客体）。债权的客体指的是债务人特定的**给付行为**，即债务人仅为或不为一定的行为。

**内容**，也就是权利的效力。这一栏要重点记，后面会单独展开。物权的效力体现为三个关键词：

- **优先效力**——物权是具有"卷王"属性的，争强好胜，处处讲一个优先；
- **追及效力**——物在哪里，物权就可以追到哪里去行使；
- **排他效力**——一个物上原则上不能存在两个以上内容相冲突的物权，有我就不能有别人，唯我独尊。

相比之下债权的效力就温和多了：债权强调**平等性**（"佛系"，讲一个躺平，大家都是平等的）；物权有追及性，债权仅有**相对性**，只能对特定的人主张，不能追及；物权有排他性，债权具有**相容性**（非排他性），同一个物上可以存在内容上冲突的数个债权。

正好一一对应。后期背诵时我给大家编个小口诀来记：

| 物权效力 | 口诀 | 债权效力 |
| --- | --- | --- |
| 优**先**效力 | 先 | **平**等性 |
| **追**及效力 | 追 | **对**对性 |
| 排**他**效力 | 他 | **相**容性 |

口诀连起来是"**先追他**"和"**等对相**"，两组正好对仗。有同学刚开始复习法硕的时候问过我：老师，我是应该先学这个民法，还是先追车老师的刑法课呀？我说你可以先追他的课——**先追他**。

**变动**，主要从权利发生角度分析。物权采取**法定主义的立法模式**；债权更多强调当事人的意思自治，所以叫**任意主义的立法模式**，债权的取得最主要通过当事人签订的合同。

**保护**。物权的保护除了损害赔偿以外，还包括旨在**回复物权圆满状态的物权请求权**——它相当于物权自带的免疫系统，用来恢复物权的原本状态。债权则是通过**违约责任**进行救济的，既包含要求继续履行的内容，也包含赔偿。

这六个方面整体掌握，后期背诵非常方便：先从体系定位描述权利的性质（上位概念），再从五个基本点展开——主体、客体、内容、变动、保护。这就是物权的特征。

### 物权的三项效力

优先、追及、排他，这三个词听起来都很学术，得单独展开。

在展开之前，先回答一个疑问：前面讲物权概念时，物权的内容是"直接支配和排他"，怎么这里就变成"优先、追及、排他"了？它们是什么关系？

> **结论**：优先效力和追及效力都是从**直接支配**里面延伸出来的，排他效力则是从**排他**延伸出来的。

权利人对于特定物的直接支配体现在两个方面。第一层次是**对人**的：既然我是直接支配，那同一个物上有物权人、有债权人的时候，物权人要**优先于**债权人，体现物权的**优先效力**——我物权人，我来优先支配。第二层次是**对物**的：物在你手上时你可以直接支配；关键在于物因为各种原因脱离了所有人的控制，物权有没有消灭？没有消灭，物权依然可以**追及物之所在**来进行直接支配——物在哪里我就追到哪里，体现**追及效力**。

你可以把这个物理解为一个**风筝**，而这个权利就是通过一条线来控制风筝的。尽管风筝飞得很远了，但基于这条风筝线，我依然可以把它拉回来。这就是直接支配效力的延伸：**对人体现为优先效力，对物体现为追及效力**；而排他则延伸出排他效力。

#### 优先效力：卷王之间的排位赛

物权是卷王派，喜欢争强好胜。所以同一物上产生数个权利时，得让权利人 PK 一下，看谁更优先、谁才是真正的卷王。这意味物权优先效力又分两个层次。

**第一层：物权对于债权的优先效力。**

先看原则性规定。从性质上讲，物权是支配权，债权只是请求权，两者权利效力的强弱之分非常明显，所以物权原则上可以更加优先，体现**物权优先原则**。

看一个小例子。车某有一块劳力士手表，马某看上并与车某签订买卖合同，以 10 万的价格买下。后来岳母得知也喜欢这块表，愿意出 12 万。车某见钱眼开，又与岳母签订了买卖合同。岳母熟读民法，知道交易的核心是要完成交付、要拿到手表，于是车某当场把手表交给了岳母，完成了交付。

马某知道以后肯定不答应：你居然横刀夺爱我想买的手表？但岳母和马某之间就产生了冲突——手表上的权利，是岳母的还是马某的？

看他们取得权利的性质：岳母既已交付，取得了手表的所有权，取得的是**物权**；马某只签订了一个合同，取得的只是一个**债权**。高下立判，岳母当然可以优先于马某获得保护。这就是物权优先于债权的第一个层次、原则性规定的体现：**卷王派可以轻松卷倒躺平派**。

有原则就必然有例外。为了实现特定的规范目的，某些债权也可能取得优先于物权的效力，所以债权优先属于例外情形，**必须以法律作出明文规定为前提**。举个例子：民法典第 725 条规定的**买卖不破租赁**制度（合同编还会讲到），指的是在承租人按照租赁合同占用期间，如果发生所有权变动，不影响租赁合同的效力。

还是举例。车某有别墅一套，租给马某，租期 5 年。一年以后，车某将别墅出卖给岳母，岳母通过买卖方式取得别墅所有权，双方都办理了过户登记手续。岳母要求马某赶紧搬离，说这别墅现在是我的了。马某肯定不答应：我已经签了租赁合同，而且签的是 5 年，现在还没到期呢，我拒绝搬出。

岳母取得的是**物权**，马某虽然合同签得更早，但基于租赁合同只取得了一个**合同债权**。通常情况下物权效力更强，能卷倒躺平派债权，但这个案例有所不同：马某签订的租赁合同租期是 5 年，如果房东一换人，承租人的居住就会严重受到损害。你想一想，在买房之前可能要先租房，签了租赁合同以后，房东把房子卖掉，然后说赶你走就赶紧走，是不是明显损害了承租人的合法权益？所以民法典设置了"买卖不破租赁"这样一个特别制度，要优先保障承租债权人马某的利益。这是**债权可以优先于物权**的例外制度——虽然马某是躺平派，但偶尔也能捡漏获得一个优先的机会。

> **提示**：此时的岳母已经成为别墅新的出租人。她能不能找马某收租金？可以。办理完登记手续以后，这个房租就不是交给车某了，要交给新的房东岳母。岳母多少也挽回一点面子，起码能收租。

区分原则与例外的意义在于：如果法律没有规定债权优先的特别制度，那就适用**物权优先**的一般性规定。

**第二层：物权相互之间的优先效力。**

假如同一物上产生的两项权利都是物权，大家都是卷王，那也得相互 PK 确定谁更优先。但这时候谁更优先，**要看法律的规定**——还是体现物权法定原则。

比如民法典第 456 条的规定：同一动产上已经设立抵押或者质押，该动产又被留置的，**留置权人可以优先受偿**。这个条文涉及担保物权的效力冲突——同一动产上可能出现抵押、质押、留置三种担保物权，因为它们的效力不相冲突，所以在一个物上可以并存；这是物权排他效力的例外情形。这三种权利发生冲突以后，按照法律的规定，留置权人优先受偿——法律已经把你们的效力强弱排好队了。

举个例子。车某因买房向岳母借款 10 万，岳母对这个债权有风险意识，要求以车某的豪车设定抵押，双方签订抵押合同并办理了抵押登记，岳母对车取得抵押权。后来车某又缺钱，向马某借了 50 万；马某民法意识比较淡薄，又轻信车某的信誉和人品，没有要求设定担保。再后来车某的豪车无故熄火，被拖到公某修理厂修理。公某把它修好以后，车某拒付修理费，扬言"我的迈巴赫让你来修是你的荣幸，你还好意思收钱呀"。公某很生气，直接把车扣下了，并给了车某两个月的宽限期，说两个月内你再不给修理费，我就把这辆车卖掉来优先受偿。这时候公某可以对车取得**留置权**。

后来车某既不还岳母的 10 万，也不还马某的 50 万，同时也不还公某的 1 万块钱修理费，而且除了这辆车没有其他财产——穷得只剩一辆车了。卖掉这辆车取得的价款，三个人都要争着去拿，谁先谁后就涉及权利的优先效力问题。

先看三人权利的性质：岳母取得的是**抵押权**，属于物权；公某取得的是**留置权**，也是一种物权；马某只是借出 50 万，对这辆车没有物权可言，只是一个**普通债权人**。

那么谁会立马出局？马某。他排到老末，因为他只是个债权，人家岳母和公某都是卷王、都是物权，可以轻松卷倒这个普通债权人。

接下来轮到岳母和公某进行第二轮 PK：你是物权，我也不差，我也是物权。卷王和卷王之间怎么确定先后？要按照法律规定来优中选优——抵押、质押、留置并存时，留置权人优先受偿。这意味公某按法律的规定**勇夺冠军**，岳母作为抵押权人只能屈居亚军。

岳母虽然在考研中是卷王派，可以优先于躺平派的老马，但公某是**保研派**——不考研就可以上岸的——所以他当然能处在一个更优先的位置上。卷王和卷王之间也要进行 PK 来确定谁更优先，这叫**物权相互之间的优先效力**。至于其他物权之间的优先效力，我们在后续规则里会具体讲，这里只是举个例子。

#### 追及效力：物在何处，权追至何处

相对简单一些，体现为物权对特定的物直接支配效力的延伸。

> **定义**：物权的追及效力，是指作为物权客体的物，无论辗转流向何处，权利人均有权**追及物之所在**而行使其权利。（民法典第 312 条）

通俗讲就是：物到了哪里，物权就可以追到哪里去行使权利。就像孙悟空神通广大，一个筋斗云十万八千里，但逃不出如来佛的手掌心；这个物也逃不出物权的手掌心。

讲个"千里追手机"的例子。甲有一部手机，后来给丢了，被乙捡到，这个手机变成了遗失物。乙后来把手机送给了丙，丙不想用二手手机，于是又送给了丁。一部被嫌弃的手机。后来甲通过手机定位发现手机跟自己距离 300 公里，送了这么远，于是通过定位找到了手机的占有人丁，说这是我的手机，我要拿回来，要求丁返还。

丁能不能拒绝？答案是**不能**。尽管手机被甲弄丢了，而且乙又送给丙、丙又送给丁，但这个过程当中，手机的所有权有没有发生变动？没有。所以这部手机的所有权依然属于甲，甲依然是物权人、是所有权人，可以对这部手机进行支配。尽管现在手机脱离了甲的直接控制，被送到了 300 公里以外的地方，但甲可以追及物之所在——手机在哪里我就追到哪里，要求丁返还，重新实现对手机的支配权。300 公里差不多就是十万八千里，这就是追及效力。

#### 排他效力：一山不容二虎

排他效力体现为：**同一物上不能存在两个以上内容相冲突的物权**。

因为物权效力比较强大、要直接支配。假如同一物上有两个所有权人，每个所有权人都要主张直接支配，那这样的矛盾法律是无法解决的，所以法律就不允许这样的现象出现。一个物上不允许有两个以上的所有权，这叫**一山不容二虎**：有我作为物权人，就不能让别人也做物权人，体现的是物权争强好胜的属性。

有原则就必有例外。虽然原则上是一物一权，但法律也允许例外存在：假设两个以上的物权**效力不相冲突**，就可以在同一个物上并存。因为虽然一山不容二虎，但如果是一公一母，那就没问题——两虎也可以和平相处。

比如前面提到的同一个动产上可能存在抵押权、质权、留置权这三类担保物权；再比如前面举的那个例子：车某对这辆车享有所有权，岳母对这辆车享有抵押权，公某对这辆车享有留置权。大家都是物权，但效力不相冲突，可以和平相处。只是哪个先、哪个后，法律也得做出规定；而法律作出先后规定的前提是什么？是**大家首先可以并存**。这就是物权排他效力的例外情形。

### 物权的五种分类

第三个问题也是理论问题——是不是又见到老朋友了：学习不停，分类不止。民法典里规定的物权类型虽然有限，但也不少，而不同类型的物权适用不同的规范，所以要先进行分类。

#### 完全物权与定限物权

区分的标准是**对标的物的支配范围**有所不同。这两个词我们在讲它们的下位概念特征时经常会用到。

如果是对标的物进行**永久、全面**的支配，叫**完全物权**，体现一种全面的支配。在民法中完全物权主要体现为**所有权**，效力最为强大，可以对自己的物进行占有、使用、收益、处分。

**定限物权**（又称**限制物权**）是指在特定范围内支配标的物，它的支配范围仅限于特定的范围，是受到限制的。这两个词是同义词。另外，限制物权常常体现为在**他人财产**上取得的物权，所以又称为**他物权**；相应的，对自己的物进行全面支配的所有权，又叫**自物权**。

> **结论**：对自己的物全面支配 → **自物权**（所有权 / 完全物权）；对他人的物只能部分支配 → **他物权**（定限物权 / 限制物权）。

#### 用益物权与担保物权

这是对**定限物权**所得的进一步区分（或者说对他物权所得的进一步区分），区分的标准是看定限物权对他人标的物的**支配内容**到底是什么。

- 支配他人标的物的**使用价值**的，叫**用益物权**；
- 支配他人标的物的**交换价值**的（也就是拍卖变卖所得价款可以优先受偿），叫**担保物权**。

所以这两类物权都是他物权，支配范围都受到限制，但一个支配的是使用价值，**重在使用**；一个支配的是交换价值，**重在把标的物卖掉以后优先受偿**。支配的内容不同。

#### 动产物权、不动产物权与以权利为客体的物权

这一种是按**物权客体**种类的不同来分的。物权的客体首先是特定的物，而特定的物既包括动产也包括不动产，于是产生了动产物权和不动产物权的区分。这里要重点强调**以权利为客体的物权**。

它其实本来叫"**权利物权**"，但前两年考试分析修订的时候，把"权利物权"改成了"以权利为客体的物权"。为什么这么改？可能是修订者觉得，物权本来就是一种权利，权利怎么能够作你的定语呢，容易产生争议。但其实这个定语是多余的——"权利物权"是一个约定俗成的概念，它指的就是以权利为客体的物权。现在写成"以权利为客体的物权"当然也没问题，只是不那么学术了。

举个例子。我们前面提到过，建设用地使用权是可以成为抵押权客体的：开发商拿到一块地来开发商品房，和政府签订国有土地使用权建设用地使用权出让合同、办理登记以后，可以取得建设用地使用权；但是搞开发没钱，于是把这个权利抵押给银行获得融资，银行对这个建设用地使用权就取得了一个抵押权——这就是以权利为客体的物权。同样，**知识产权**也可以质押给债权人来获得融资，质权的客体也可以是知识产权这样的权利。

#### 主物权与从物权

这是基于**两个物权之间有没有从属关系**来区分的。能够独立存在的物权称之为主物权。大家学习的绝大多数物权都可以独立存在，所以重点关注**从物权**的概念：它指的是**不能独立存在**、要从属于其他权利而存在的物权。

比如刚才提到的担保物权，它能不能独立存在？不能。它存在的价值是为了担保一个**主债权的实现**。还是前面讲的按揭贷款：银行先把钱借给你，对你取得一个借款债权；然后为了担保这个借款债权的实现，你把房子抵押给银行，银行对房子取得抵押权。这个抵押权没有独立存在的意义，它存在的意义是为了担保主债权的实现。这意味着当你某天挣到一大笔钱，把银行贷款一次性还清了，借款债权被消灭了——那么这个抵押权，尽管这时候还没有办理注销登记，在法律上已经消灭了。**皮之不存，毛将焉附。**

这就是从物权命运的体现：主物权归于消灭或转让的时候，从物权就得跟着消灭或转让。另外，用益物权当中的**地役权**也具有同样的从属性，它同样要从属于相应的权利，这一点在地役权部分我们还会再强调。

#### 意定物权与法定物权

区分的标准是**以物权产生原因**不同来做的分类。

如果物权是基于当事人的意思表示、或者基于民事法律行为而产生的，通俗讲就是通过**签订合同的途径**取得的，这叫**意定物权**；如果是按照法律规定而直接取得的，不需要当事人去签订合同，那就是**法定物权**。比如**留置权**就是法定物权，只要符合法律规定就可以直接取得；而前面提到的**抵押权和质权**，虽然也是担保物权，但它们的取得要通过签订合同的途径，所以是意定物权。

讲到这里，可能有同学会产生疑问：我前面一直强调物权法定的观念，那怎么还会存在意定物权这个说法？

> **提示**：二者**不冲突**，他们描述的角度完全不一样。我们前面所称的**物权法定原则**，说的是物权的**种类和内容**要由法律来规定——有多少种物权、每种物权有哪些权能，这些由法律来规定。而**意定物权**说的是：当要取得法律已规定的物权类型时，需要通过什么途径呢？需要通过签订合同的途径。

比如抵押权，这种物权的类型是由民法典来规定的——这是物权法定原则的体现；但是某个特定当事人（比如银行）通过什么途径来取得法律规定的抵押权这种物权类型呢？是要通过签订合同的方式取得的，银行得跟抵押人签订抵押合同，才有可能取得这个抵押权。所以他取得的途径是签订合同，这就叫意定物权。

二者描述的角度完全不一样，大家不要把它们混为一谈。

## 从主体到变动：物权法的四条基本原则
> 对应块：BLK46 | 覆盖分集：P43 | 块标题（分集名）：《第03编 第01章 第02节：物权法的基本原则》

上一节我们把物权的定义、效力体系这些基础概念过了一遍，这一节往上抬一层，看物权法这个部门法自己有一套什么样的价值追求。

比较独特的，一共有四条：平等保护原则、物权客体特定原则、物权法定原则、公示公信原则。

那这四条是按什么思路串联起来的？这个问题不解决，背起来就是四块互不相干的砖头，一上考场还是懵。答案仍旧落在我们一直强调的那几个东西上——民事法律关系的基本点。主体、客体、内容、变动，你从哪个角度切进去，物权法就长出哪条基本原则来。

```text
     主体          客体          内容          变动
       │             │             │             │
       ▼             ▼             ▼             ▼
   平等保护      客体特定      物权法定      公示公信
     原则          原则          原则          原则
```

读图：从左到右就是一条对应关系——主体对应平等保护，客体对应物权客体特定，内容对应物权法定，变动对应公示公信。四条原则不是背下来的清单，是从民事法律关系的四个基本点里自然长出来的。

先解释一下为什么是这四个、偏偏没有"保护"。因为我们确实还要讲物权的保护制度，但保护这件事在民法里是贯穿性的、各部门法共有的，并没有体现出物权法自己独有的价值追求。既然不"独特"，它就成不了一节要单独讲的基本原则，只是一个制度而已。所以我们这一节的四条，全是物权法自己长出来的。

---

### 平等保护：进了民法，国家集体就得放下"优先一等"

第一条，平等保护原则。

先把它和总则里的平等原则对上号。我们在总则编讲平等原则的时候，是**从主体角度**来描述的，强调各类主体一律平等。而平等保护原则，就是平等原则在物权法领域的具体体现。

那它跟总则那条有什么不一样？差别在主体的范围上。物权的主体，首先可以是自然人、法人、非法人组织，这些和一般民事主体没有区别；但物权法领域还有一个特殊性——特殊情况下，主体还可以是**国家或者集体**。

所以物权编讲的平等保护，实质上是在讲：国家、集体、私人这些主体的物权，要受到平等保护。教材里写了三个方面的具体体现，都比较简单，但有一条暗线。

| 体现 | 时点 | 内容 |
| :--- | :--- | :--- |
| 法律地位平等 | 事前 | 国家、集体、私人在物权规范中的法律地位平等 |
| 适用规则的平等 | 事中 | 各类主体在适用物权规则上平等 |
| 保护的平等 | 事后 | 受到侵害后，各类主体获得的是平等的保护 |

顺着这张表往下看，你会发现它其实是一条时间线：事前先强调法律地位平等；事中产生法律关系了，强调适用规则的平等；事后受到侵害了，再强调保护的平等。三点串起来读，就不用死记硬背了。

> **提示**：这里还有一个特别值得想一想的问题。我们以前学过，"公民的合法私有财产受法律保护""任何组织或者个人不得侵犯"，从字面上看，这明明是一种不平等啊——公民的财产怎么跟国家财产平起平坐？怎么民法里头还要强调平等保护？

答案是：**这是两个不同法域的价值判断，不能混在一起看**。

在宪法层面、在公法领域，我们确实要对国家财产、集体财产给予更优先的保障，我们甚至还单独制定了国有资产保护法。但那是一回事。一旦进入民法这个司法领域，参与了民事法律关系，那么在你这个具体关系里，国家、集体和私人就是受平等保护的——**你不能再主张"优先一等"**。公法上的位阶优势，不带进私法关系里来。

去年我们法学同学就考过一道论述题，题目指向的正是物权编中围绕国家、集体财产所设置的相关规范。那道题最核心的考点就是平等保护原则，就是"国家和集体的物权受到平等保护"这件事。这是一个非常重要的问题，看到论述题，先想想它是不是踩在这里。

好，第一项原则讲完。

### 客体特定：一物一权，以及它的两个例外

第二项原则，物权的客体特定原则。

它强调的是**物权的权利和它的客体，也就是特定的物之间的关系**。这个关系有两个方向，所以产生两个方面的体现。

#### 站在物权的角度：客体只能是一个独立的、完整的物

第一个方面，站在物权的角度描述：物权的客体，限于经济上和法律上完整的、独立的物。这句话有个推论：**物的组成部分，能不能成为物权的客体？不能。**

为什么？因为物权是要对物进行支配的。假如一个物的不同组成部分由不同人支配，那会严重影响这个物的效能发挥。

举个特别直观的例子：有辆车，这辆车的油门归甲，刹车归乙。大家想一想这个时候这车能开吗？没法开的。加油还得经过乙的同意；遇到突发情况要刹车，是不是由乙来决定？甲想停都停不下来。这辆车是没法开的。所以这个车只能是整体上属于一个人。

这就是物权客体特定原则——**物权的客体指向的是独立的、完整的物**。

#### 站在物的角度：一个物上不能有两个以上内容相冲突的物权

第二个方面，从"物"这个角度来描述：**一个物上不能存在两个以上内容相冲突的物权。** 原则上，一个物上只指定有一个物权。

所以物权客体特定原则又叫**一物一权原则**。这两个词其实是从不同角度描述同一件事：站在物权的角度，描述为"物权客体特定"；站在物的角度，描述为"一物一权"。你跟别人聊物权和物之间的关系，就会有那种"你是我的唯一的"这种感觉。

> **易错点**：理解物权客体特定原则，一定要和"一物一权"关联起来记。这两个表述指向同一原则的两面，考题里换着出。

#### 有原则就有例外

教材里给大家补充了两个例外制度，两个都不违反一物一权。

**第一，多人对同一物可以共享一项物权。**

前面讲共有制度的时候我们提到过：甲乙是夫妻，用共同财产买了一套房子。甲乙能对这套房子取得所有权吗？能。这有没有违反一物一权？没有。因为这房子上依然只有一个所有权，只不过这个所有权由甲乙两个人共享。**权还是那一个权，只是主体不止一个人。**

**第二，两个以上的物权，如果内容不相冲突，也可以在同一个物上并存。**

比如甲把房子抵押给了银行。银行对这套房子取得的是抵押权，也属于物权。那么甲的所有权和银行的抵押权，效力并不冲突，所以可以并存于同一套房子上。这个也不违反一物一权。

把这两条例外合起来看就清楚了：一物一权划的是"完整、独立地支配整个物"的那条线，越过这条线（物的部分被拆出去、或者两个物权的内容互相打架）才叫违反；所有权由数人共享、以及内容不冲突的物权并存，都没有越过这条线。

### 物权法定：种类强制、内容强制，和违反它的三种后果

第三条原则，物权法定原则。这一条比较重要。

在正式讲物权之前，我们其实已经提前给大家强调过：学习物权的时候，一定要树立物权法定的观念。到底有没有物权、取得的物权怎么行使，都是按照法律规定的规则来落实的。

#### "法律"只认狭义

《民法典》第 116 条：物权的种类和内容由法律来规定。这就是物权法定。

它意味着两件事：物权的种类和内容，**能不能由法律以外的其他规范来创设？不能**；**能不能由当事人通过约定来创设？也不能**。强调物权法定的观点就是——物权由法律说了算。

那"法律"到底指什么？要从正反两面展开，这一点最容易考。

**正面界定：这里的"法律"仅指狭义上的法律。**

我们在哪里见过广义上的法律？前面讲民法的渊源讲过，《民法典》第十条：处理民事纠纷应当依照法律，法律没有规定的可以适用习惯，但不得违背公序良俗。那里面所讲的"法律"就是一个广义范围，涵盖民事法律、行政法规规章、地方法规、司法解释以及国际公约等等。

而物权法定这里讲的是狭义上的法律。这样的法律既包括《民法典》，也包括民事特别法——比如《海域使用管理法》，比如《海商法》。它们能不能设定物权的种类和内容？当然可以，因为它们都属于法律的性质。

> **提示**：只是我们法硕考研当中学习的物权，主要是《民法典》里规定的物权类型，考题不会跑到特别法里去给你设个新类型。

**反面排除：狭义的法律以外的其他规范，就不能设定物权的类型和内容。**

比如国务院制定的行政法规，虽然可以成为民法的渊源，但它不能创设物权的种类，也不能规定物权的内容；规章、地方性法规等等也是如此——它们虽然都属于民法渊源的范畴，但不属于狭义上的法律范畴，所以不能规定物权的种类和内容。

我们在前面讲过一个例子：2005 年联合颁布了《典当管理办法》，用来规范典当行的运营。问题是，基于这个部门规章，能不能让典当行取得物权的地位？答案是不能——**这个规范的级别不够**。

所以"法定"这个理解，两面都要抓：正面强调仅限于狭义上的法律，包括但不限于《民法典》；反面要排除其他规范性文件，它们不能设定物权的种类和内容。

#### 两条底线：类型强制与内容强制

第二个方面，物权法定原则的具体内容，或者说它的具体体现，分为两个方面。

**第一，物权的种类由法律规定——这就是类型强制。**

有多少种类型的物权，是法律说了算。前面提过，《民法典》规定的物权类型就是三大类，用字母 ABC 表示：A 是所有权，B 是用益物权，C 是担保物权。

那么问题来了：当事人约定设立物权的时候，能不能设定第四种类型？**不可以。** 民法典给你设的种类就是 A、B、C 三种，实践中取得的物权只能是 A、B 或者 C。你要说我要取得第四种物权，不行，因为法律没有规定这种类型。

**第二，每一种物权的内容由法律规定——这就是内容强制。**

《民法典》规定的三种物权，它们分别包含什么内容，是法律说了算的。比如 A 这种物权，它包含三项权能，分别是 A1、A2、A3。那么当事人依法取得了 A 这种物权以后，能不能说"我要主张 A4 第四项权能"？**不可以。** 尽管你这个**种类**是符合物权法定的要求的，但你主张的**内容**超出了法律规定的范围。你只能在 A1、A2、A3 这些法律规定的范围内去主张你的物权，你不能说我有 A4。

所以你看清楚这一个是两条底线：

> **结论**：种类要法定，内容也要法定——这就是物权法定原则。

它的直接推论是：物权编会给大家详细讲每一种物权包含哪些内容，除了我们讲到的这些内容以外，你这个物权人就不能行使其他权利了。

#### 违反物权法定原则的三种后果

第三方面，违反物权法定原则的后果。后果是跟前面两个体现一一对应的。

**后果一：违反类型强制——物权不能设立。**

当时约定的物权种类不符合法律规定，违反类型强制，后果是**不发生物权效力**，也就是你取不到这个物权，因为民法典没有规定这样的物权类型。

教材里有个例子。**车某向岳母借款 10 万元**，为了担保债权实现，车某把自己的一套**佘山别墅**交到岳母手中来设定质押。双方约定：如果车某不还岳母的钱，岳母可以把别墅卖掉来优先受偿。

现在假想一下：车某真的没有按约定还款，岳母能不能就佘山别墅来实现优先受偿权？**答案是不可以。**

尽管民法典规定了质权，但民法典里面规定的质权只包括**动产质权和权利质权**，没有在别墅这样的不动产上设定质权这样的选项。也就是说，当时的约定违反了类型强制的规定，后果就是岳母取不到物权了。岳母对别墅拍卖变卖取得的价款，是没有优先受偿的身份的。

那如果车某还欠了老马 20 万元，老马也是普通债权人，卖掉别墅的钱，岳母能不能优先于老马来受偿？**不能。** 因为岳母这个时候并没有取得对别墅的物权身份。这就是违反类型强制的法律后果。

**后果二：违反内容强制——超出的约定无效，但物权本身仍能设立。**

当时的物权种类是法律规定的，但约定的内容超出了法律规定的范围。比如约定了 A4 这个内容，后果是：**这个约定本身无效。**

教材的例子还是上面那个案子。车某还是向岳母借款 10 万元，同时为了担保债权实现，把**一块劳力士手表**交到岳母手中来设定质押。

先看这个质押符不符合类型强制的要求？符合。因为劳力士手表是动产，民法典里规定了动产质权这种物权类型，所以符合类型强制。

但双方还特别约定：如果车某不还款，岳母可以直接取得这块劳力士手表的所有权，手表直接归岳母所有。这个约定有效吗？

这个约定就是典型的**流质条款**。按照民法典的规定，你取得质权这种担保物权以后，法律赋予你的权利是——你可以支配这个标的物的交换价值，拍卖变卖以后可以实现优先受偿权，这是法律赋予你的权利，内容就体现在 A1、A2、A3 当中。而当时约定的"债务人不履行债务时岳母将直接取得质押财产的所有权"，这一点是法律没有规定的内容。所以，**这样的流质条款应当认定是无效的**。

那岳母能不能依这个约定直接取得手表的所有权？不能。但是岳母对这块手表有没有取得质权？**取得了**，因为这个种类是符合法律规定的，所以她依然可以取得物权。只是在行使物权的时候，只能按照法律规定的权利来行使——比如她可以就拍卖变卖手表以后取得的价款来优先受偿。尽管车某还欠了老马 20 万，但卖掉手表这个钱，岳母是物权人，是优先于老马受偿的。

所以这里结论很清楚：**物权依然设立，只是得按照法律规定来行使这个物权，而不是用当时的特别约定。**

**后果三：区分原则——物权不设立，不影响合同的效力。**

尽管违反物权法定原则的行为导致物权不能设立，但是**合同的效力常常不受影响**。要把合同效力和物权变动的效力区分开来，这叫**区分原则**。

还是第一个案例。车某把别墅交到岳母手中，双方约定给岳母设定一个不动产质权。我们前面讲了，这样的约定违反类型强制，岳母对别墅不能取得物权。**但是，双方签订的质押合同效力如何？依然是有效的。** 这就叫区分原则——物权虽然不能设立，但不影响合同的效力。这个合同是不是符合总则编讲到的民事法律行为的有效要件，那是另一层判断。

```text
  ┌──────────────────────────────┐
  │  违反物权法定 ≠ 合同无效       │
  └──────────────────────────────┘

   合同效力 ──▶ 仍按总则编的民事法律行为有效要件判断
   物权效力 ──▶ 类型强制：不能设立
                内容强制：超出的那部分约定无效
```

读图：这就是区分原则的分工图。合同这条线走的是总则编的判断标准，物权这条线走的是物权法定，两条线各走各的，不要把"物权没成立"顺手推成"合同无效"。

把三项后果摆在一起对比，这是本节最该记牢的一张表：

| 违反类型 | 违反的那部分 | 法律后果 | 物权能否设立 | 合同效力 |
| :--- | :--- | :--- | :--- | :--- |
| 类型强制 | 约定的物权种类 | 不发生物权效力 | 不能设立 | 不受影响 |
| 内容强制 | 超出法律范围的权能约定（流质条款） | 该约定无效 | 可以设立 | 不受影响 |
| 区分原则 | 合同效力与物权变动效力 | 两者分开判断 | —— | 仍按有效要件判断 |

> **易错点**：违反类型强制和违反内容强制，最容易混的就是"物权到底成没成立"。记住一句话分清：**种类不对，物权根本没生出来；内容超了，约定那一块作废，但物权本身照样成立。**

### 公示公信：你敢亮出肌肉，法律就保护别人的信赖

最后是公示公信原则。这是**在物权变动中产生**的基本原则。

要特别注意：公示原则和公信原则是**两项原则**，一定要把它们区别开来。我们 2016 年考过一道论述题，就是"试论民法中的公示公信原则"。

#### 公示原则：让人知

什么叫公示原则？它体现为物权要通过一定的方式进行公示，进而让公众知悉物权变动的事实。体现的是"让人知"的价值观。

为什么物权需要公示？因为我们在前面提到过，物权属于"卷王"派，效力比较强大。这意味着你当卷王，你得有资本——**你得把你的实力展示给别人看，要公示出来**。

按照法律规定，不动产要通过**登记**的方式来公示，动产要通过**交付**的方式来公示。只有公示出来了，亮出你的肌肉，法律才认可你的"卷王"属性。

看个例子。**车某有一套佘山别墅，还有一块劳力士名表，要一并卖给岳母**，于是双方签订了买卖合同。

双方刚签这个买卖合同的时候，岳母能不能取得别墅和手表的所有权？**不能。** 因为你没有进行公示，没有把你的实力亮出来给大家看。

等车某把别墅登记到岳母名下的时候，这就叫**进行了公示**——是不是相当于岳母拿着房产证向全世界宣布，这套别墅是她的？这是"让人知"的一个过程。同时，车某把手表交付到岳母手中时，这个公示的效果是让全世界来感受一下岳母的实力，让大家知道她成为了新的物权人。

所以公示原则体现的就是"让人知"的观念：你有实力、你有物权，就要亮出来，让大家看得到。这样大家才承认你的卷王身份，你才能够取得前面讲到的**优先受偿权、排他效力**。

#### 公信原则：让人信

第二种原则叫公信原则。它指的是：**物权变动符合法定公示方式的，就具有了可信赖的法律效力。** 体现的是"让人信"的观念。

你通过登记或者交付把实力、把物权展示给大家看，大家看了以后会产生一个信赖，法律也得保护这种信赖。即使有的时候，展示出的实力并不代表真正的实力，但这个时候法律要保护当事人对这种公示内容的信赖。

怎么来体现呢？民法典设立了一项制度，叫**善意取得**，这个善意取得体现的就是公信原则。我们在所有权部分会正式讲这个制度，这里先看个小例子，感受一下。

还是教材中的例二。**车某向岳母借款 10 万元**，这意味着岳母对车某有一个 10 万的债权。为了担保这个债权的实现，车某把一块劳力士手表质押给了岳母。我们前面讲过，质权是以转移占有为前提的，所以手表会交到岳母手中，岳母对这块手表取得质权。因为完成交付了，是不是实力亮出来了？法律认可岳母的物权人身份。

后来的岳母未经许可，把这块手表按市价卖给了**不知情的马某**。双方签订了合同，马某善意地相信这块手表就是岳母的，他付了合理的价格。

这时候车某又主张什么权利？要主张**物权的追及权**——虽然手表现在在马某手中，我要"千里追手表"，追及权所在，行使我的物权。

但这时候马某是不是也很冤枉？他说：我买这块手表的时候，我亲眼看到手表是戴在岳母手上的，是岳母在控制这个手表，这已经形成了一个公示的方式。我有新的这种公示方式形成的信赖，我相信那块手表是岳母的。因为它手背上又没有写着车某的名字。

那法律至少要保护马某对这种公示内容的信赖利益。尽管公示内容并不反映权利的真实归属——虽然戴在岳母的手上，但岳母并不是真正的所有权人——法律要保护的是相对方的信赖利益。

所以马某依法律规定，可以**善意取得这块手表的所有权**。他取得所有权以后，车某的所有权将会归于消灭。你要为信赖力的保护而做出牺牲——车某的追及效力被法律直接给切断了，**相当于法律亲手把你的风筝线给剪断了**，你就不能再进行追及了。

这项制度体现的就是物权的公信原则。既然你敢公示，法律就要保护相对方对这个公示内容的信赖利益。

到这里，平等保护原则、物权客体特定原则、物权法定原则、公示公信原则，四条基本原则就齐了。回头再看开头那张对应图：主体、客体、内容、变动——物权法自己的那点价值追求，全都落在这四个基本点上了。

### 本讲提到的题目

本节没有新编的练习题，只有两处真题回顾，我把它们还原在这里。

**第一道（去年法学同学考过的论述题）**

> 试论物权编中围绕国家、集体财产所设置的相关规范。

> **提示**：这道题的题干在本节字幕中略有残缺，以上按现场可辨信息还原。

**解析与答案**：这道题最核心的考点，就是**平等保护原则**，也就是国家和集体所受的物权保护与私人所受的保护是平等的。要点在于区分两个法域的价值判断：宪法与公法领域（体现在国有资产保护法等）对国家财产、集体财产给予更优先的保障；但在民法这个司法领域，一旦国家、集体参与民事法律关系，就与私人受平等保护，不能再主张"优先一等"。

**第二道（2016 年考过的论述题）**

> 试论民法中的公示公信原则。

**解析与答案**：必须先把公示原则与公信原则拆成两项原则分别作答。

- **公示原则**，体现的是"让人知"的观念：物权要通过法定方式（不动产登记、动产交付）进行公示，让公众知悉物权变动的事实。因为物权效力强大、是对世权，属于"卷王"派，当"卷王"就得把实力亮出来给公众看，公众认可才有优先受偿权与排他效力。
- **公信原则**，体现的是"让人信"的观念：物权变动符合法定公示方式的，就具有可信赖的法律效力。即使公示出的内容并不反映真实的权利归属，法律也要保护相对方对该公示内容的信赖利益。这一原则在民法典上体现为**善意取得制度**：符合条件的后手可以善意取得所有权，真权利人的所有权归于消灭，其物权的追及效力被切断（"法律亲手把风筝线剪断"）。

两者不能混为一谈：公示解决的是"外界能不能看见"，公信解决的是"看见了之后要不要信、信了要不要保护"。

## 物权变动怎么发生的
> 对应块：BLK47 | 覆盖分集：P44上 | 块标题（分集名）：《第03编 第01章 第03节：物权的变动（01）》

物权变动的判断，落到最后永远是同一句话：**三个条件，缺一不可**。有权处分、合同有效、完成法定公示方式。记牢这句话，后面所有的例子——房子、手机、汽车、贷款担保——都只是往这三个格子里填东西。填不满，物权就不动。

但这句话不是从天上掉下来的。为什么是三个而不是两个？凭什么公示方式非要不可？为什么"合同有效"单独一个还不够？这些得从头说。

### 物权变动：一个覆盖全流程的广义概念

物权变动是一个广义概念，指的是物权的**设立、变更、转让、消灭**各个阶段的总称。

设立、变更、转让、消灭——一个都不少，全算物权变动，全都适用物权变动的相关规范。这一点先钉住：它不只管"从无到有"，还管"改朝换代"和"归于消灭"。

物权变动这个部分，是物权通则里面最为重要的一个板块，需要大家重点掌握。

### 按取得的形态分：原始取得与继受取得

物权变动有两种相关的分类，都偏理论，但考试里经常拐着弯考。这一刀是冲着"物权怎么来的"下的。

切分标准只有一个：当事人取得这个物权，**要不要依托他人既存的权利**。

#### 不用看别人的脸色：原始取得

不需要依托他人既存权利的，叫原始取得。不用看别人的脸色，可以一手直接取得。

原始取得常常是法律直接规定取得物权。选择题里面，首先要把这些典型例子记牢：**生产、收取孳息、先占、没收、善意取得**。

比如一家公司生产出的产品，直接取得这个产品的所有权，不需要基于别人的权利；农民辛苦一年种的庄稼，秋天收割，收取孳息以后也可以直接取得所有权，同样不需要基于别人的权利。

> **提示**：这一串例子不是随口举的，它们背后是同一个道理——压根儿没有一个既存的权利可以"转让"给你。

**善意取得是原始取得，这一点特别容易考。** 上一节我们举过那个例子：车门把手表质押给了岳母，来担保主债权的实现，手表在岳母的占有之下。这意味着岳母能把这块手表卖给不知情的马某，她属于无权处分。那马某可以基于善意取得的规定取得所有权。

问题是，马某取得所有权，是不是基于前手岳母既存的权利？**当然不是。** 岳母压根儿就没有对手表的处分权。法律之所以让马某取得所有权，是基于交易安全的保护，是为了保护马某对公示内容的信赖利益。

所以你取得所有权，是不是要感谢岳母？当然不是——你需要感谢的是法律。是法律创设了善意取得制度，直接让马某取得了所有权。

> **结论**：马某取得所有权是基于法律的直接规定，而不是基于前手的既存权利，所以它叫原始取得。

> **易错点**：判断原始还是继受，看的是"权利链条上有没有前手"，不是看"取得的时候有没有付钱、有没有经过别人手上"。善意取得里前手根本没有处分权，权利链条是断的，所以是原始取得。

#### 移转与创设：继受取得的两种类型

继受取得就是基于他人既存的权利取得物权，在别人的权利基础上取得一个新的物权。它进一步分成两种类型，区别只在于：你取得的物权，和前手那个物权，是不是同一个东西。

```text
原始取得
  不依托他人既存权利
  生产 / 孳息 / 先占 / 没收 / 善意取得

继受取得 —— 依托他人既存权利
  ├─ 移转：前手是什么，拿到手还是什么
  │  甲的所有权 ──交付──> 乙的所有权
  └─ 创设：在前手权利上另立一项新物权
     甲的所有权 ──设定质权+交付──> 乙的质权
```

读图：上支是原始取得，权利链条上没有前手；下支是继受取得，看两条箭头两端的权利类型——完全一样的是移转，多出一个新类型的是创设。

**移转的继受取得**，指的是从他人处取得了他人原有的物权。别人原来是什么物权，这个物权就直接转移到了你手中，取得物权的种类是一样的。

比如甲有部手机，他送给乙作为生日礼物。交付到乙的手中时，乙可以取得所有权。乙取得这个所有权，是不是要基于甲给予的权利？现在所有权原封不动地转移到了乙手中——这叫移转的继受取得。很好理解。

**创设的继受取得**，说的是在他人的原有物权基础上，设立了一个新的物权。

还是那部手机。甲向乙借钱以后，把手机质押给乙，也交到了乙的手中。这时候乙对这部手机取得的是什么权利？动产质权。乙取得质权，是在甲的所有权基础上取得的。假如没有这个所有权，你也难以把这个手机质押给乙。所以它同样是继受取得，只不过乙取得的物权，是在甲的所有权基础上**创设**出来的一种新的物权——甲那边是所有权，乙这边是质权。创设一种新的物权，这就叫创设的继受取得。

> **概念提醒**：这两个概念都是法言法语，但识别方法极其朴素——问自己一句：这个物权是从前手那里"搬"过来的，还是在前手权利之上"长"出来的？

### 按变动的原因分：公示原则的分水岭

第二种分类是冲着"物权为什么动"下的：基于民事法律行为的物权变动（基于合同或者交易行为而发生），以及非基于民事法律行为的物权变动（基于事实行为、基于事件）。

这两类的规范取向截然不同。

基于民事法律行为的物权变动，是交易行为在民法里面的具体体现。既然涉及交易，就要保护交易安全，就要坚持民法里面所称的**公示原则**——只有完成公示的手段以后，才能够发生物权变动。

非基于民事法律行为的物权变动，它并不涉及交易行为，跟交易安全的保护没有什么必然联系，所以**无需公示**就可以发生物权变动。

> **结论**：这是这种分类最大的意义所在——一个要坚持公示原则，一个不需要坚持公示原则。所以接下来讲物权变动的相关规范时，就必须把这两类分开处理。

### 物权变动模式：只管基于民事法律行为的那一半

先补充一个理论问题，叫**物权变动模式**。

这个概念有个坑必须先点破：物权变动模式**仅针对因民事法律行为而引起的物权变动**，也就是要基于一个交易行为发生的物权变动。

尽管"物权变动模式"这几个字从字面上好像涵盖的范围很广，但是民法在使用这个概念时，把它的范围做了一个限缩。至于非基于民事法律行为的物权变动，和物权变动模式**没有任何关系**。一定注意这个前提。

> **注意**：虽然物权变动模式的立法力是纯理论问题，但也需要大家掌握。因为考试分析对这个问题做了非常详细的展开，连马工程教材都没写得这么详细。所以大家的民法理论知识这么渊博，要感谢考试分析。

#### 一个小模型和两个通用要件

所谓物权变动模式的立法力，说的是一个国家在制定物权变动相关规范的时候，有哪几种立法模式可供选择。理论上说是三种。不同的模式，对于基于民事法律行为发生物权变动所需要满足的条件，要求是不一样的。

为了方便理解，我们设置一个小模型，借这个模型案例来理解。

甲有房屋一套，要卖给乙，双方签订了买卖合同。这套房子要基于交易行为、基于民事法律行为发生物权变动，那乙要取得这个房子的所有权，需要满足什么条件？不同模式会设置不同的要求。

其中，**有两个要件是三种模式通用的**，不管哪一种模式都得满足：

**其一，有权处分。** 甲得是有权处分。因为如果甲不是有权处分，那就不是一个正常的交易了，那就要转去适用善意取得的规定。

**其二，当时签订的债权合同有效。** 基于民事法律行为的物权变动，其实主要指基于合同行为发生的物权变动，那要求这个债权合同必须是有效的。

```text
【甲有房屋一套 → 卖给乙，双方已签买卖合同】
  │
  ├─ 通用两要件（三种模式都必须满足）
  │  ① 甲有权处分          ② 债权合同有效
  │
  ├─ 债权意思主义   满足 ①② 就发生物权变动
  ├─ 物权意思主义   满足 ①② + ③ 独立物权行为有效
  └─ 物权形式主义   满足 ①② + ③ 完成法定公示方式
```

读图：三条腿都站在同一块地基（①②）上，区别只在第三条腿要不要、那条腿长什么样。

#### 债权意思主义：意思到位即可

第一种立法模式叫**债权意思主义**，也叫意思主义。

基于这种模式，要想发生物权变动的结果，只要满足有权处分和债权合同有效这两个条件就够了，不需要符合其他条件。模型案例当中，乙要取得房子所有权，只需要甲有权处分、双方签订的买卖合同有效，就直接取得了房屋的所有权。

法国民法、日本民法采的就是这种模式。

#### 物权意思主义：还得有一个独立的物权行为

第二种立法模式，在有权处分、债权合同有效之外，还得再加一个条件：**物权行为有效**。

大家发现这种立法模式是认可物权行为的独立性的，也就是承认我们前面讲到的负担行为和处分行为的区分。

但这个物权行为作为一个独立的民事法律行为，它要有效，也需要满足两个具体的条件：首先，双方得达成一个发生物权变动的意思——既然是独立的民事法律行为，当然得有自己的意思表示；其次，还得通过特定的形式来做出来，就是通过登记或者交付的形式。满足这两个条件，我们说有一个独立的物权行为有效，这时才可以发生物权变动的结果。

德国民法典、我国台湾地区民法采这种模式。这种模式的特殊之处在于：要区分债权行为和物权行为，认可物权行为的独立性，甚至认可它的无因性。

落到模型上，乙要取得这个房屋的所有权，需要满足：甲有权处分；甲乙之间签订一个有效的买卖债权合同；甲乙之间还有一个独立的物权合同——一方面包含甲要把所有权转给乙的意思，另一方面这个行为要通过办理登记的方式来完成。

#### 物权形式主义：还得多走一步公示

第三种立法模式叫**物权形式主义**。同样是先满足有权处分、债权合同有效这两个通用条件，然后在此基础上还得完成法定的公示方式——不动产是登记，动产是交付。满足这个条件，就可以发生物权变动的结果。

瑞士民法采这种模式。模型中，甲乙把房子过户登记到乙的名下，乙就取得所有权了。

#### 后两种模式的分歧：登记算什么

| 立法模式 | 通用两要件之外还需要 | 代表立法 | 登记的法律性质 |
| --- | --- | --- | --- |
| 债权意思主义（意思主义） | 不需要 | 法国民法、日本民法 | 意思到位即变动，登记不是要件 |
| 物权意思主义 | 独立物权行为有效：物权变动的意思 + 登记或交付的形式 | 德国民法典、我国台湾地区民法 | 本身就是民事法律行为 |
| 物权形式主义 | 完成法定公示方式：不动产登记、动产交付 | 瑞士民法 | 只是公示方式，属于事实行为 |

后两种立法模式都要求办房屋登记手续，这是它们的共同点。它们的核心区别在于：**登记这个过程，是不是一个独立的民事法律行为**。物权意思主义认为物权行为具有独立性，登记本身就是个民事法律行为；物权形式主义认为登记只是一个公示方式，不是一个独立的民事法律行为，它只是一个事实行为而已。

> **结论**：这两种立法模式最本质的区别，就是怎么来评价登记这个行为。

三种模式相比较而言，债权意思主义是处于一个折中的状态——既没那么简单，也没有复杂得那么夸张，非常符合中国的国情。

### 我国的选择：以债权意思主义为原则，少数物权为例外

讲到这里，大家发现我们国家采的是哪一种模式了？就是看民法典的态度。

在民法典里采取的，是**以债权意思主义为原则、少数特定物权为例外**的物权变动模式。原则上意思表示到位就发生物权变动；但某些特定物权，只需要满足债权意思主义这一层，就可以发生物权变动。

刚才讲的那个甲把房子卖给乙，是原则性的规定：乙要取得房屋所有权，除了甲有权处分、买卖合同有效以外，还得完成登记这个公示手段。

而像**土地承包经营权**这种物权，采的就是债权意思主义的物权变动模式。当村集体和农户签订有效的土地承包合同时，农户就直接取得了土地承包经营权这种用益物权，不以公示作为物权变动的要件。

教材里面还列举了**地役权**。按照民法典的规定，它也是债权意思主义的物权变动模式：地役权合同生效时就可以发生物权变动效力，只是未经登记不得对抗善意第三人。

既然债权意思主义是例外，那就意味着在民法典当中，哪些物权的变动采纳这种立法模式，我们都是要单独规定的，要特别给大家讲。**没有特别讲过的，一律适用原则。** 这就是区分原则和例外的意义所在。

> **提示**：这也回头印证了前面讲过的一个结论。我们国家不认可物权行为的独立性，所以作为合同履行行为的交付、登记等行为，只是一个**事实行为**，并不是民事法律行为。学到这里，你应该能理解前面讲"登记、交付属于事实行为"这个属性的意义所在了。

### 不动产：第三个条件是登记

既然我国原则上采债权意思主义，那意味着要发生物权变动的结果，要满足三个条件：第一，有权处分；第二，合同要有效；第三，要完成法定的公示方式。

公示方式要区分动产和不动产分别看：不动产是登记，动产是交付。先看不動产——公示方式登记被满足，加上有权处分、合同有效，三个节点同时满足，就可以发生不动产物权变动的结果了。

这个公示方式要掌握：**第三个条件是缺一不可的。** 而且这个登记不是一个独立的物权行为，它只是一个事实行为。

对应的法条表述就是：不动产物权的设立、变更、转让和消灭，经依法登记发生效力；未经登记不发生效力。

#### 例一：合同签了，登记也办了

甲乙签订房屋买卖合同，出卖A房，双方签订合同以后办理了登记手续。乙能不能取得房屋所有权？就看物权变动的要件有没有被全部满足。

首先，甲是不是有权处分。当然是。接着，双方签订的合同效力如何。有效。有没有办理登记。有。

三个节点同时具备，乙可以取得所有权。

那假如说双方签订了合同，但没有办理登记手续呢？乙就**不能**取得所有权。前两个条件也符合，但因为没办理登记，三个条件没有同时具备。

#### 例二：登记办了，合同却无效

甲乙还是签订房屋买卖合同，签订并办理了登记手续，但后来查明，签订合同时出卖人甲是无民事行为能力人。这意味着什么？双方签订的合同是无效的。

那乙能不能取得房屋所有权？还是照旧看要件：甲是不是有权处分？是的——尽管甲是无民事行为能力人，他是有处分权的，这两件事并不冲突。接着看双方签订的买卖合同效力如何？无效，因为甲是无民事行为能力人。

尽管办了登记手续，但三个条件有一个没满足，照样不能发生物权变动的结果。

> **易错点**：例二和"甲根本没有处分权"是两回事。"有权处分"和"合同有效"是两条独立的线，不要顺手把"无民事行为能力人导致合同无效"写成"无权处分"。

#### 例三：借200万并约定过户作担保

甲向乙借200万，同时约定甲要把自己的C房过户到乙的名下作为担保。双方签订合同，乙提供借款以后，双方办理了过户登记手续。

先判断：乙能不能取得房屋的所有权？有权处分，有；虽然双方签订的合同是有效的，但**这个合同里面有没有包含一个转移所有权的意思？没有**。所以债权合同有效这一点，并没有完全满足。双方虽然办了登记手续，但因为合同里不包含转移所有权的意思，不能发生物权变动的结果。

接着判断：乙能不能取得让与担保权？让与担保权也是物权，也要判断要件。甲有权处分，有；双方签订了有效的让与担保合同——约定甲把房子过户到乙名下作为担保，这个债权合同是有效的，有；办理了登记手续，有。三个节点都满足，乙可以取得让与担保权。

所以，当时到底取得哪一种物权，取决于债权合同里约定的是什么。买卖里面包含的是所有权变动的意思；让与担保里面没有把所有权真的转给对方的意思，要做一个区分。

> **结论**：从考试角度来讲，不动产物权变动如果考这个考点，超不出我们讲的这个案例的范围。至于"有权处分"这个要件——如果当时甲不是有权处分，那就直接适用善意取得的规定了，跟这个考点无关。所以考试要么考有没有完成公示，要么考合同有效无效。

### 区分原则：合同有效是必要而不充分条件

既然说到这里，就得给大家分析合同有效和物权变动之间的关系。

假如因为没办理登记手续而使得物权不能发生变动，能不能反过来影响合同的效力？**不影响合同的效力。** 回到例一的那个变体：当事人没有办理登记，导致乙不能取得所有权，但不影响合同的效力。因为合同的效力是按照我们前面讲过的规则来判断的。

既然乙没有取得所有权，而合同也是有效的，那乙能不能请求甲来继续履行合同？**可以。** 请求继续履行合同、办理登记手续，是不是登记这个条件就被满足了？届时乙就可以取得房屋的所有权了。

> **定义**：这就是**区分原则**。物权变动与合同效力各走各的判定线；合同有效而物权未变动的，可以通过对合同债权的强制履行，促成物权变动要件被补齐。这也是让合同有效这个规则的意义所在。

那合同有效和物权变动到底是什么关系？两头都要说清楚：

其一，合同有效是发生物权变动当中**其中一个**条件。合同有效这个条件不满足的话，能不能发生物权变动的结果？不能。所以它是发生物权变动的**必要条件**。

其二，光合同有效，能不能发生物权变动的结果？不能——还得完成登记。所以它又是一个**不充分条件**。

> **结论**：通俗来讲就是，没有合同有效肯定不行，这叫必要条件；但光有合同有效你还不够，还得完成登记，这叫不充分条件。**必要而不充分条件**，这个结论一定要掌握。

我们曾经考过法条分析题，让你分析合同效力和物权变动的区分原则。真题放在文末，这里先把判断路径交给你：抵押合同有效、没办登记，抵押权没设立，但合同的效力完完整整不受影响，创富公司还能反过来请求甲配合办理登记。

### 动产：把登记换成交付

接下来是动产物权变动的规则。只是动产的公示方式换了个样子，从登记变成交付。

基于交易行为发生动产物权变动结果，需要满足的也是三个条件：第一，有权处分；第二，合同要有效；第三，要完成交付这样的公示方式。三个条件同时具备，就可以发生动产物权变动结果。

从考试角度来讲，考察这个考点时主要考察的也是**交付**和**合同有效**这两个要件有没有满足。因为如果有权处分都不满足，那就不适用物权变动模式的规则了，直接适用善意取得的规定。

#### 例一：合同签了，手机也交了

甲乙签订手机买卖合同，双方签订合同以后完成了交付。乙能不能取得这个手机的所有权？当然可以——有权处分、合同有效、完成交付都符合。

但如果双方签订合同，却没有交付手机，那就不能发生物权变动的结果了。因为你既然没有完成交付这个公示方式，就有一个条件没满足。结果非常简单。

#### 例二：手机交了，合同却无效

还是甲乙签订买卖合同并完成了手机的交付，但后来查明，签订买卖合同时出卖人甲是无民事行为能力人，这就意味着双方签订的合同应当认定是无效的。

这个时候，乙尽管拿到了手机，尽管有权处分、交付这两个条件满足了，但是合同有效没满足，那就不能发生物权变动结果。三个条件是缺一不可的。

#### 例三：手机交了，但约定了保留所有权

甲乙签订手机买卖合同，签订合同并马上交付，而且特别约定：乙分三期来付款，支付全部价款以后才能取得所有权——有一个保留所有权的特别约定。

这个时候乙能不能取得手机的所有权？先看甲是不是有权处分。是的。再看双方的合同是不是有效的。合同是有效的，但因为在合同里面约定了保留所有权，所以这个合同里面并没有包含一个把所有权转移给乙的意思，债权合同有效这一点并没有完全被满足。当然，即使完成了交付，是不是也不能发生物权变动的结果？

就像甲不是把这个手机卖给乙，而是把这个手机**租**给乙。能取得物权吗？答案是不能。尽管甲有权处分、合同是有效的、而且完成了交付，但双方签订的是租赁合同，在租赁合同当中根本就没有把所有权转给乙的意思，那他当然不能发生物权变动结果。

> **易错点**：这是一个特别容易踩的坑——**合同有效 ≠ 合同有效且包含处分意思**。买卖合同里只写货款分期、没写所有权保留，交付时所有权就转了；一旦加了"付清价款前所有权仍归出卖人"，交付也只能交付占有，不能变动物权。

> **结论**：所以这个债权合同里面，还需要包含一个当事人有转移该物权的意思。

#### 例四：借2000块并以所有权转移作担保

甲向乙借款2000块，同时约定甲把所有权形式上转移给乙作为担保。双方签订合同以后，甲把手机交付到了乙的手中。

乙能不能取得所有权？看要件有没有满足。首先假设甲有权处分；同时双方虽然签了合同，但大家看这个合同，包含的意思是要给乙设定一个担保，没有转移所有权的意思，所以这个条件并没有完全被满足。因此尽管完成了交付，乙不能取得所有权。

但接着判断：乙能不能取得担保物权呢？这个担保权是一个让与担保。一方面甲有权处分；另一方面双方签订了有效的让与担保合同；同时也完成了交付。那这个时候乙可以取得让与担保权。

> **提示**：例三和例四的判断套路是同一套——先别急着问"手续做没做齐"，先问"这个合同到底处分了什么"。物权变动的要件里，"合同有效"这一格填的从来不是"合同签了没"，而是"合同有效，并且有效的内容指向相应的物权变动"。

> **提示**：看起来这么简单的问题，为什么我们要搞得这么复杂、列这么多例子？作为初学者，在学习的时候一定要把**判断过程写得非常规范**。就像学数理化的时候，虽然有的题目可能一步就能看到结果，但我们还是一步一步地去推导，形成一个比较严谨的逻辑推导过程。这样的话，在遇到难题的时候，你才不会错过比较隐蔽的考点。

### 交付方式：现实交付与观念交付

最后把"交付"单独拎出来说一说。民法里面所称的交付，既包括现实交付，也包括观念交付。

#### 现实交付：按生活的一般观念来判断

现实交付相对来讲比较好理解，就是把物转移给他人来占有，那就是完成了交付。比如甲把手机卖给乙，怎么交付呀？把手机交到乙的手上，就是完成了交付。

但这个交付有没有完成转移，是要根据生活经验来判断的。比如甲把自己的车卖给乙，是不是也需要交付？那这个车怎么交付到乙的手中？需不需要甲把车开到乙的面前，自己下来说"乙，这个车归你了，请你上去"？没必要搞得这么复杂。只要甲把车钥匙交到乙的手中，按照生活的一般观念，这个车的占有已经在乙的控制之下了。这也是现实交付。

> **提示**：现实交付的判断标准不是物理位移，而是**生活的一般观念**——物的占有与控制是否已经转移到对方。钥匙交出去、车在原地、交车人还坐在驾驶座上，观念上都已经完成交付了。

#### 观念交付：通过"脑补"来完成

这里要重点讲观念交付的问题。观念交付就是虽然没有现实交付的过程，但法律在观念上认为已经完成交付，也可以发生物权变动。

也就是说，这个交付的过程，要通过脑补的方式、通过观念想象的方式来实现。

所以这是标准的法言法语了。

### 本讲提到的题目

**题目（法条分析题）**

甲与金科公司约定，甲委托金科公司为自己提供出借人信息。甲与出借人签订合同以后，向金科公司支付报酬——相对而言金科公司是个贷款中介。后来根据金科公司提供的信息，甲从创富公司借款36万，并且以房产设定抵押，但一直没有办理抵押登记手续。请问：甲和创富公司之间签订的房产抵押合同效力如何？

**答案：有效。**

**解析：**

这个抵押合同完全符合民事法律行为的有效要件，所以它是有效的。尽管双方签订合同以后没有办理抵押的登记手续，这意味着创富公司不能取得抵押权这种物权，**但不影响抵押合同的效力**。这叫区分原则。

正是因为这个抵押合同依然是有效的，创富公司能不能请求甲来继续履行合同？当然可以。而继续履行合同，就表现为甲要配合创富公司办理登记手续。等登记手续办完了，创富公司就可以取得抵押权了。

**回到本讲的框架：**抵押权属于不动产物权，它的变动同样要过"有权处分 + 合同有效 + 完成登记"这三关。抵押合同有效，只解决了第二关；登记这一关没走完，所以抵押权没能设立。但第一关和第二关的结论已经足够支撑合同本身的效力——这正是区分原则要处理的那条分界线：**合同效力与物权变动各有各的判定线，物权没动，不等于合同无效。**

> **承前启后**：上一节讲完「物权变动怎么发生的」，下一节接着讲「观念交付三形态,以及特殊动产为什么还要登记」。

## 观念交付三形态,以及特殊动产为什么还要登记
> 对应块：BLK48 | 覆盖分集：P44下 | 块标题（分集名）：《第03编 第01章 第03节：物权的变动（01）》

简易交付、指示交付、占有改定——三个标准的法言法语。民法典里规定了动产物权的三种观念交付形态,用的就是这三个词。

> **提示**：法言法语这种东西,光念名字谁也记不住。我们在理解这三种观念交付形态的时候,一定要结合一个典型的交易模型去理解。模型记住了,条文自然就长在模型上了。

### 三种形态,三个模型

```text
一、简易交付 —— 先租后买(出租人就是买受人)

     甲 ──租──▶ 乙(占有电脑)──买──▶ 乙(取得所有权)

     交付时点:买卖合同生效之时,电脑不必来回搬


二、指示交付 —— 先租再卖(出租人不是买受人)

     甲 ──租──▶ 乙(第三人,一直占有该车)      甲 ──卖──▶ 丙
                  ▲                                    │
                  └──────── 返还请求权 ────────────────┘
                        (甲把对乙的返还请求权让与丙)

     交付时点:甲、丙关于让与返还请求权的协议生效之时
     丙取得的:间接占有(有权请求乙返还该车)


三、占有改定 —— 先卖后租(买受人回头把东西租回给出让人)

     甲 ──卖──▶ 乙(取得所有权)──租回──▶ 甲(继续开车)

     交付时点:租赁合同生效之时
     甲的占有:自主占有 ──▶ 他主占有
```

把这三个模型排在一起看,差别会非常刺眼:

| 形态 | 交易模型 | 条文上的适用前提 | 交付何时完成 |
| --- | --- | --- | --- |
| 简易交付 | 先租后买 | 动产物权设立和转让前,权利人已经占有该动产 | 买卖这一民事法律行为生效时 |
| 指示交付 | 先租再卖 | 动产物权设立和转让前,第三人占有该动产 | 甲、丙关于转让返还请求权的协议生效时 |
| 占有改定 | 先卖后租 | 动产物权转让时 | 租赁合同生效时 |

请特别注意最后一列和倒数第二列:前两个写的是"设立和转让",第三个只有"转让"。这一字之差,就是后面一整节的内容。

### 简易交付:先租后买

看例一。甲将他的电脑要租给乙来使用,这样会把电脑交到乙的手中,这叫**先租**。等乙使用以后觉得电脑非常不错,想要花市价把这个电脑买下来,甲也表示同意,双方达成了一个买卖合同,这叫**后买**。

大家看乙,他也是通过买卖来取得电脑的所有权,那就需要完成交付。那怎么来交付呢?需不需要等租赁合同到期后,乙先还给甲,甲再继续买卖交给乙啊?显然没必要搞这么麻烦。

因为交付的最终目的是什么呀?是让乙取得对这个电脑的占有。那现在基于这个之前的租赁合同,乙已经占有该电脑了,那就不用来来回回再浪费时间了。在法律上会认为交付已经完成,乙基于简易交付的方式取得了电脑的所有权。

这就是先租后买的模型。你看这个交付过程,是要通过"脑补"的方式才能够实现的,所以它叫观念交付的形态。

> **定义**（简易交付）：动产物权设立和转让前,权利人已经占有该动产的,物权自该民事法律行为生效时发生效力。

我们把这个定义对照模型来看。"动产物权设立和转让前",讲的是前面这个先租——权利人(甲)已经占有该动产;而"民事法律行为",讲的是双方后面成的这个买卖合同。所以物权是在买卖合同生效的时候发生物权变动效力。

**另外还要补充一个变化:占有的合法性,民法典已经不管了。**

先租呢,意味着权利人已经要占有该动产了。那这个占有该动产,需不需要以合法占有为前提呢?

我们以前在物权法时代,是要求合法占有的。但是民法典删掉了这个要件。这意味着在民法典的背景下,不需要这个权利人合法占有该动产,只要占有就可以适用简易交付的规定。

> **结论**：只要占有,就可以适用简易交付。不问占有的合法性。

我们来看例二。甲将电脑丢失,电脑被乙所盗——你看乙那不是租来的,而是偷来的电脑。后来甲联系到乙的时候,要求返还,这个时候很尴尬:乙表示希望以2000块钱把这个电脑买下来。假如说没问题,双方达成了买卖的合意。那这个时候,乙能不能取得电脑的所有权?答案是**可以**。

尽管他最初占这个电脑并不是合法占有,是偷来的电脑,但是他也是占有了这个电脑。只要双方后来达成了买卖的合意,就可以基于简易交付的方式来完成交付。

为什么?因为不管这个权利人是合法还是不合法地占有该动产,简易交付都可以发挥简化交易、节约交易成本的功能。所以都可以适用简易交付的规定。

### 指示交付:先租再卖

第二种叫做指示交付,也是个专业术语。它对应的交易模型叫做先租再卖——也就是租的人跟买的人,他不是一个人。

看例一。甲有辆车,他能租给好友乙来使用,车交到乙的手中,这叫先租。当然,如果是乙要买这个车,双方可以通过简易交付完成交付,进而使乙取得所有权。但是人家乙没有想要买这个车的意思,那这个甲就把这个车卖给了丙,这叫再卖——你看,是卖给了另外一个人。

既然丙也是基于买卖来取得车的所有权,要完成交付才能够取得物权。那甲怎么把这个车交给丙呢?需不需要等和乙的租赁期满以后收回车来,再继续履行买卖合同交给丙啊?当然不需要了。一方面是没有必要搞这么复杂,浪费时间;另一方面,丙也不一定愿意等那么久。

所以在法律上,给这个甲提供了一个交付的方式:甲可以把对乙的返还请求权转让给丙,以代替交付。

这里头有个概念要说清楚。这个车现在在乙的占有之下,但是甲他没有丧失占有,只是在法律上他叫**间接占有人**——这个概念我们在占有部分会讲。也就是甲对直接占有人乙有一个返还请求权:"我租给你的车,在租赁合同终止的时候,你得把这车返还给我。"这样一个返还请求权,他把这个权利让与给了丙,使得丙有权请求乙返还该车。

是不是相当于甲把自己间接占有的地位让给了丙?而交付不就是转移占有吗?转移直接占有是交付,那转移间接占有也算是一种交付。所以这个时候,丙可以取得间接占有地位,有权请求乙返还该车。这就是指示交付的操作方式,是不是也可以节约这个交易成本?

> **定义**（指示交付）：动产物权设立和转让前,第三人占有该动产的,负有交付义务的人可以通过转让请求第三人返还原物的权利代替交付。

还是把这个定义对照模型来读。"动产物权设立和转让前"讲的是后面这个再卖;"第三人占有该动产"讲的是这个先租的乙——因为买卖发生在甲、丙之间,那这个先租的乙就是第三人了,他已经占有该动产了;"负有交付义务的人"也就是甲,他可以通过转让请求第三人返还原物的权利来代替交付。

那指示交付这个过程,在法律上会认为什么时候完成交付呀?按照司法解释的规定,是自转让人和受让人有关转让返还请求权的协议生效的时候,发生物权效力。也就是当甲和丙达成一个"把返还请求权转让给对方"的协议、这个协议生效的时候,指示交付就完成了。

至于它的适用前提——第三人占有该动产,这个占有有没有限定为合法占有啊?答案是**没有**。这点也是和以前物权法的一个区别。

> **结论**：指示交付同样不要求第三人是合法占有,只要是占有的就可以发生指示交付。

我们来看例二。甲将电脑丢失,被好友乙所盗,乙也是偷来的电脑。本来可以找乙来主张返还原物的,但是好朋友偷自己的电脑,去找乙的话,感觉面子上有点过不去,会觉得乙不好意思。只能为了给乙点面子,甲就把这个电脑卖给了丙,让丙去找乙来要这个电脑。双方约定丙可以直接请求乙返还电脑。请问,双方达成这个约定的时候,丙能不能这么要?答案是**可以**。

你看乙呢,虽然也是偷来的电脑,他并不是合法占有,但是他也是占有了这个电脑;而甲呢,也是把这个电脑卖给了别人,这个时候也可以通过转让返还请求权的方式来代替实际交付。那丙又不认识乙,他甚至都可能不知道这个电脑是乙偷的,所以这个时候他去找乙要求返还电脑,乙那也不至于那么尴尬。只能甲是个好人。

### 占有改定:先卖后租

第三种观念交付形态叫做占有改定,也是个标准的法言法语。理解它还是要记一个交易模型,叫做先卖后租——先卖出去,而后再租回来。

同样结合教材里面的案例来理解。

甲2025年升职涨薪,要换辆新车——顺便说一句,也希望各位研究生毕业以后能找到工作了,每年都升职涨薪。他在2026年1月5号和某4S店签订了新车的买卖合同,预计一个月以后能够提车。于是2月1号的时候,甲和乙签订买卖合同,把自己这辆旧车就卖给了乙,这叫先卖。

正常情况下,甲应当把这个车交到乙的手中。但是甲能了解到,他的新车要推迟到4月份才能够到货。假设这个时候把车交出去的话,甲就没车开了。于是他和乙商量,能不能把这个车租回来,租两个月、可以付租金。乙说没问题,反正我也不着急用这个车。于是双方成立一个租赁合同,这叫后租。

基于这样的操作,尽管这个车一直在甲的手中,但是法律认为,双方已经通过占有改定的方式完成了交付。这就是占有改定的交易模型。

大家发现,通过这两个合同的签订,使得乙取得了一个**间接占有**的地位。本来的先卖后租,应当是甲先把车交到乙的手中,然后签订租赁合同以后,乙再把车交还给甲;但是在生活当中显然没有必要这么折腾。大家签订合同的时候,就认为乙已经取得了间接占有的地位,相当于把那个交来交去的过程给他省掉了。

那对甲来讲呢?他之前开这个车,知道是自己的车,这叫**自主占有**。但是在签订买卖和租赁合同以后,甲再开这个车,他的主观意思就变了:他变成开别人的车了,得小心点了,变成了一个**他主占有**。

> 所以占有改定其实体现为甲从这个自主占有变成一个他主占有的过程。

> **定义**（占有改定）：动产物权转让时,双方又约定由出让人继续占该动产的,物权自该约定生效时发生效力。

对照着模型看："动产物权转让时",讲的是先卖;"双方又约定由出让人继续占该动产",讲的是后租。物权自该约定生效时发生效力——也就是后面这个租赁合同生效的时候,占有改定就完成了。

大家发现在占有改定这个交易当中,双方当时是形成了两个合同:第一个是买卖合同,先卖,转移所有权;第二个是租赁合同,后面租回来,让转让方甲可以继续占有开这个动产。这是占有改定的一个特点:双方要形成两个合同。

### 占有改定为什么不能设立物权

当我们在理解占有改定的定义时,还要注意它的适用前提。

它的适用前提叫"动产物权转让时",适用场景是动产物权的转让。而前面两种观念交付形态,简易交付和指示交付,它们的适用前提是"动产物权设立和转让时"。有没有发现有什么不同啊?就是占有改定只能适用于动产物权的转让,它不能适用于动产物权的设立。这部分的一个难点问题需大家特别注意。

> **易错点**：三个条文里,前两个写的是"动产物权设立和转让",第三个只有"动产物权转让"。一字之差,就是"能转让、不能设立"的分界线。

我专门给大家补充一个规范拓展。在民法当中,动产物权的设立,主要表现为两种形态:一个是动产质权的设立,一个是动产善意取得。这是设立动产物权的两种典型情形。从考试角度来讲,大家掌握这两个例子也就够用了。

既然动产物权的设立不能适用占有改定,那如果在设立的时候,当事人约定这样交付的话,那就是:你没有完成交付,进而不能发生物权变动。

#### 动产质权:约定占有改定,质权不成立

在规范拓展当中,大家可以看一下教材当中的例子。

甲向乙借款2000块钱——大家看这里面有个2000块钱的借款债权,然后双方约定,甲要把自己的小提琴一把质押给乙,双方签订了质押合同。按照物权法定原则的要求,甲得把这个小提琴交到乙的手中,乙才能够成为动产质权人。

但甲需要用这个小提琴来备战比赛,于是双方约定:甲租用该小提琴两个月,可以支付租金300块钱。乙表示同意。

大家看当事人约定的交付方式,非常明显是一个占有改定的交付方式。本来甲应当交到乙的手中,但是呢双方签订租赁合同,相当于乙再交还给甲。签了两个合同,通过占有改定的方式完成交付。

但是我们刚才提到了,甲是要给乙设立一个动产质权的,这是动产物权的设立,它不能通过占有改定的方式来完成交付。既然甲乙约定的是占有改定,那就意味着你不符合民法典规定的交付的要求,意味着乙能不能取得动产质权?答案是不可以。

这意味着什么呢?假设甲还欠了丙、丁的钱,后来甲只有这一把小提琴还值点钱,卖掉小提琴以后,乙能不能主张优先于丙、丁受偿?答案是不可以。因为你乙并没有取得一个动产质权人这样的物权身份,你也是普通债权人,要和丙、丁来公平受偿。

#### 善意取得:约定占有改定,视为未交付

第二个例子:动产善意取得的交付,不能通过占有改定来完成。

甲将小提琴借给好友乙,用于新年演出的练习。但是乙因手头拮据,擅自把小提琴出卖给了不知情的丙。大家看这个乙,它属于无权处分。那丙还能不能正常取得该动产的所有权?不能了,他得适用善意取得制度——假设秉持善意、支付合理对价,那他就有机会善意取得。

但是按照法律规定,你要善意取得的话,还得完成交付。大家看有没有完成交付?双方约定,小提琴仍由乙租用两周,以代替交付。你看乙、丙之间做了一个什么约定啊?做了一个占有改定的约定:首先是卖出去,然后再租回来。

那这个时候就要判断了:丙能不能善意取得小提琴的所有权?注意,答案是不可以。因为这个乙是无权处分,必须满足善意取得的构成要件,而其中一个要件就是要完成交付;同时呢,这个善意取得它是一种原始取得方式,它属于动产物权的设立。所以交付的时候,就不能通过占有改定的方式来交付——你约定占有改定的,那法律就认为你没有完成交付,所以丙不能善意取得该小提琴的所有权。

#### 为什么厚此薄彼

有同学呢可能会有个疑问:说大家都是观念交付的形态,那法律凭什么要厚此薄彼呢?凭什么占有改定就没有资格设立一个新的物权呢?

对这个问题,大家要注意有两个方面的理由。

第一,是**形式上的理由**,叫做物权法定原则。你看在讲本篇之前我就告诉大家,在学习物权变相关规则的时候,我们学习的最全面的标准就是法律是怎么规定的:法律说你行你就行,法律说你不行你就不行。占有改定只能适用于动产物权的转让,这个是民法典明文规定的,这就意味着我们基于物权法定原则的要求,你就没有资格设立一个动产物权。

第二是**实质上的原因**,也就是法律为什么要做这样的规定?是因为考虑到占有改定,它所形成的公示外观实在是太弱了,法律认为你达不到一个设立新的物权的程度。

比如在动产质权设立的案例当中,尽管甲和乙签订了两个合同,但是小提琴自始至终都在甲的手中,是不是你乙没有取得过任何占有?在动产善意取得的例子里,尽管乙、丙也签订了两个合同,但是这个丙呢,他是不是没有取得任何占有?小提琴自始至终都在乙的手中。你看当时他公示的外观太弱了,所以法律并不认可你可以创设一个新的物权出来。

还有些同学会产生疑问:这个占有改定不是公示外观比较弱吗?那怎么它就可以转让一个物权呀?注意,这个转让和设立它有什么区别呢?核心区别在于,在转让物权的时候,主要涉及的是双方当事人的利益。

我们来看甲换车的这个案例,它也是通过占有改定的方式完成交付的,但是这个案例当中是不是只涉及到甲和乙的利益?而对于甲、乙来讲,他们之间这个约定双方都是非常清楚的,他常常并不涉及到第三人。

但是动产物权的设立就不一样了,它会涉及到第三人。

| | 动产物权的转让 | 动产物权的设立 |
| --- | --- | --- |
| 能否用占有改定 | 可以 | 不可以 |
| 主要涉及谁 | 交易双方当事人 | 交易双方以外的第三人 |
| 典型例子 | 先卖后租的换车 | 动产质权、动产善意取得 |
| 立法理由 | 减少交易成本,双方意思清楚 | 公示外观太弱,不足以对抗第三人 |

比如动产质权的设立,让乙取得这个动产质权,目的是什么呀?是不是为了对抗甲?不是的。乙取得质权,是为了优先于丙、丁这样的普通债权人——你看是不是涉及到了交易双方以外的第三人了?

包括动产的善意取得,让丙善意取得的意义在哪里呀?是不是对抗乙?不是的,是为了对抗所有权的甲。因为你丙善意取得以后,甲的所有权将会归于消灭。

后面这两个案例当中,如果允许你取得物权,都涉及到了交易双方以外的第三人的切身利益了。既然你秀出的肌肉不是那么强大,那法律就认为你不配取得一个可以明确对抗第三人的物权;假如说只是在你们特定双方之间发生相关的效力,那基于减少交易成本、节约交易成本的考虑,也允许你转让物权,但是你不能得寸进尺,你不能设立一个新的物权。

当然,不管我刚才讲的理由能不能说服各位同学,大家都一定要记住这个结论:动产物权的设立,不能通过占有改定的方式来完成交付。你要约定占有改定的话,那就不能发生动产物权设立的效力。实际上你仔细琢磨一下,会发现我们的立法者想得还是比较周到的。

### 特殊动产:它还是动产,公示方式还是交付

接下来我们来看第三个问题:特殊动产的物权变动规则。

首先回顾一下什么叫特殊动产,包括船舶、航空器、机动车等等。因为这些动产在实践中常常需要办理登记,所以呢我们又称之为准不动产;但是它本质上还是什么呀?还是动产,所以又称为特殊动产。

在前面讲这个体系解释方法的时候,曾经讲到过这个问题。

**第一点,特殊动产它也是动产**,这意味着在交付的时候可以发生物权变动的效力。

我们先来看这个例:甲把汽车卖给乙并完成了交付,然后乙又把这个车卖给了丙,也完成了交付,但是都没有办理登记手续。这意味着这个时候,车依然登记在甲的名下。答案是谁呢?答案是丙。因为甲把车卖给乙的时候完成了交付,乙再把车卖给丙的时候,他是**有权处分**的(他自己的车),完成了交付,没有办理登记,并不影响物权发生变动。因为交付是特殊动产物权的公示方式。

接着看第二个例:甲将其汽车卖给了乙并完成了交付,后来甲、乙和丙签订买卖合同并完成了登记。你看甲呢,是不是一辆车卖了两次?车在乙的手中,但是登记在丙的名下。虽然乙完成了交付,但是人家丙把登记都办完了,而这个登记比交付更加正式——这个说法能不能成立?这个说法不能成立。

在判断谁取得物权的时候,不能根据生活经验去判断,一定按照物权法定原则的要求,看看谁符合了法律的规定。既然特殊动产它的公示方式是交付,那就看谁完成交付来决定谁取得物权。已完成交付,乙成为了新的物权人;对于丙来讲,他尽管办了登记手续,但是他依然只是一个普通债权人。

那这个时候呢,大家看乙的车登记在丙的名下,是不是使得乙对车的所有权的行使受到了某种妨害呀?所以至少,乙可以请求丙把车登记到自己的名下,这叫**排除妨害**,请求权我们在后面会讲到。

> **结论**：特殊动产物权的公示方式是交付,不是登记。

### 登记只是对抗要件,不是生效要件

**第二个方面,对于特殊动产来讲,交付以后没办理登记的,不得对抗善意第三人**,也就是登记是一个对抗要件。尽管他没有办理登记,不影响发生物权变动,但是因为你没有办登记,那你的对抗效力会受到影响,不得对抗善意第三人。

怎么来理解这个交付跟登记的功能呢?给大家做一个比喻。

我们在疫情期间都打过这个新冠疫苗。这个交付啊,它是物权发生变动的要件,所以呢有点类似于这个基础免疫:打了前两针就完成基础免疫了,就可以对抗这个正常的病毒了。而这个登记呢,它相当于我们后面打的那个加强针。你看虽然不打加强针也可以取得基础免疫,但是呢你对抗的这个病毒是不是范围有限的呀?遇到一个更强大的病毒,可能就扛不住了。但是打了加强针以后,这个效力就更强大了,可以面临更强大的病毒。

所以这个交付,它解决的是雪中送炭的问题,要解决你有没有物权;而这个登记啊,它是锦上添花的问题,需要通过加强针来进一步强化这个物权的对抗效力。那从法律角度来讲,登记会发挥对抗善意第三人的效力。

```text
        交付                            登记
   ┌────────────┐                 ┌────────────┐
   │  基础免疫  │                 │   加强针   │
   │  生效要件  │                 │  对抗要件  │
   └─────┬──────┘                 └─────┬──────┘
         │                              │
   解决"有没有物权"               解决"能对抗谁"
       雪中送炭                        锦上添花
         └──────────────┬───────────────┘
                        ▼
          特殊动产物权变动的完整效力结构
```

### 善意第三人:正反两面来界定

那接下来要给大家补充一个问题了:这里面"未经登记不得对抗的善意第三人",到底应当如何来认定呢?这个难点问题,我在理解的时候要从正反两个方面来理解:一方面我们要从反面来排除谁不是这里所称的善意第三人;另一方面还要从正面来去界定,未经登记不得对抗的善意第三人到底指的是谁。

#### 反面:普通债权人不是善意第三人

因为特殊动产已经完成交付了,即使没有办理登记手续,是不是已经取得物权了呀?那他能不能对抗普通债权人呀?当然可以。所以呢,普通债权人并不是未经登记不得对抗的善意第三人,因为人家是物权人,当然可以优先于你这个债权人了。

我们来看这个物权法解释一第六条的规定:转让人转移特殊动产的所有权,受让人已经支付合理对价并取得占有,未办理登记,但是呢转让的债权人主张其为善意第三人的,人民法院不予支持。既然人家完成交付、成为物权人了,当然可以对抗这个转让的普通债权人。即使没打加强针,对付一个小小的债权人还是绰绰有余的。

大家看这个小例子。

甲有A车,A车呢就是一个特殊动产。甲要把这个车卖给乙方,签订了合同并完成了交付,但是没有办理登记手续,这意味着车依然登记在甲的名下。

我们先来看一下乙,他有没有取得这个车的所有权啊?答案是已经取得所有权了,因为已经完成交付了,他已经成为物权人了。那之后呢,甲欠丙10万块钱未还,丙经查询发现甲名下登记有A车一辆,因为没完成登记嘛,车依然登记在甲的名下。那丙就请求人民法院查封该车、强制执行来清偿债务,这个时候乙就站出来了,说丙啊,你不能申请执行这辆车,因为这个车虽然登记在甲的名下,但是它已经是我的车了。

大家看乙能不能对抗这个丙啊?答案是可以的。因为这个乙对车已经取得物权了,而这个丙对该车有没有物权可言?没有,所以丙只是个普通的债权人。瘦死的骆驼比马大,没落的贵族那也是贵族。你看那个乙呢,虽然没有办理登记手续、没打加强针,比较地瘦弱,但他本质上是骆驼,而这个丙呢,只是个马而已。

包括我们前面讲的那个甲卖两次车的例子,甲先把车卖给乙完成了交付,后来甲又和丙签订买卖合同,把车登记到丙的名下。我们来看一下丙呢,是不是未经登记不得对抗的善意第三人?首先这个乙即交付取得了所有权,他是物权人;而这个丙和甲签订了买卖合同,但是他没有完成交付,所以丙并没有成为物权人,他也是一个普通债权人。所以呢,乙的所有权虽然没有办理登记,但能不能对抗丙呀?当然是可以的——人家的物权,你只是债权而已。所以这个乙可以请求丙来配合办理这个车辆的变更登记手续,以排除其登记所造成的所有权行使上的妨碍。

#### 正面:必须是已办理登记的物权人

那么"未经登记不能对抗的善意第三人"到底指的是谁?他指的是**已经办理登记的物权人**。所以这个物权编里面讲到的登记对抗的问题,指的是物权人之间的对抗:你是物权人,我也是物权人,然后你没办登记,但我办登记了,那这时候你就不能对抗我了。

我们来看这个教材里面的例子。

甲有B车一辆,也是一个特殊动产,卖给乙完成了交付,但是没有办理登记手续。这意味着乙能不能取得车的所有权?当然可以,他已经是物权人了。然后呢,因该车存在质量问题,乙把车交给甲来修理。大家看这个时候乙再把车交还给甲,甲能不能取得所有权?不能,因为所有权已经转移给乙了。那甲呢,又将该车出卖给不知情的丙,又卖了一次,但这个时候啊,甲他就属于无权处分了。

这意味着丙要取得该车所有权,必须符合善意取得的构成要件。大家看丙在买该车的时候,一方面车在甲的手中,另一方面因为甲、乙没有办理登记手续,车也登记在甲的名下。那这个丙可以构成善意的相对人,他支付了合理价格,而且甲把车交付给了丙。你看这个时候,丙可以善意取得该车的所有权,那丙也会成为物权人。

后来呢,被乙给知道了,他认为说这个车是我的,凭什么你可以取得所有权?这就涉及到了乙跟丙之间的优先效力的问题了。虽然大家都曾经是物权人,但是呢谁更值得保护呀?显然,办理了登记的丙要更值得保护。因为他不仅完成了交付,而且办理了登记;而这个乙呢,只是完成交付、没有办理登记。那至少丙呢,显然会更胜一筹。

所以,"未经登记不得对抗的善意第三人",主要指的是因信赖特殊动产的占有以及登记状况而进行交易的第三人,其实也是要对这个车取得物权的人,才有资格称之为是未经登记不得对抗的善意第三人。

```text
              "未经登记不得对抗的善意第三人"
                              │
            ┌─────────────────┴─────────────────┐
            ▼                                   ▼
    反面:把谁排除在外                 正面:把谁框进来
    普通债权人                       已就该特殊动产取得物权
   (乙凭交付已是物权人,              (取得方式不限,善意取得也算)
    瘦死的骆驼比马大)                        │
            │                              并且已办理登记
            └─────────────────┬─────────────────┘
                              ▼
          这里讲的是物权人与物权人之间的对抗:
          你是物权人,我也是物权人,你没登记、我登记了,
          这时你就不能对抗我。
```

这样我们就从正反两个方面来界定善意第三人了:首先正面强调,不得对抗的善意第三人是已经对这个特殊动产取得物权而且办理了登记的第三人;反面要排除的,是那些即使没办理登记、也可以对抗的普通债权人。

这样的话,我们就把基于民事法律行为而发生的物权变动,给大家全部介绍完了。

## 非基于民事法律行为的物权变动：生效文书、继承与事实行为
> 对应块：BLK49 | 覆盖分集：P45 | 块标题（分集名）：《第03编 第01章 第03节：物权的变动（02）》

那接下来我们进入第二个板块——**非基于民事法律行为的物权变动**，也就是非基于交易行为发生的物权变动。

这里的判断标准其实只有一个。既然它不是交易行为，那就不涉及交易安全的保护。既然没有人可能因为公示上的瑕疵而受到损害，那就没有必要把公示抬成物权变动的要件。民法典因此规定：不动产的物权变动不需要办理登记，动产也不需要交付，法律规定的条件一成就，物权就变。

但法律并没有一律放开。整块内容最后还有一条限制性规定，把"处分权能"卡住——这是最容易考、也最容易漏的收尾。

民法典一共规定了三种情形：一个是基于生效文书发生物权变动，第二是因继承发生物权变动，第三是因事实行为设立或者消灭物权。我们分别来看。

---

### 因生效文书发生物权变动

规定在《民法典》第229条：

> 因人民法院、仲裁机构的法律文书导致物权设立、变更、转让或者消灭的，自法律文书生效时发生效力。

**记住"生效文书"这五个字**，发生物权变动的就不需要公示了。不动产不需要登记，动产不需要交付，只要文书一生效，就可以直接发生物权变动的效力。为什么可以这么干脆？因为它不是基于交易行为，没什么交易安全需要保护。

但这里面我们要**重点强调**：能够导致物权变动效力的法律文书，到底包括哪些。

整体上，民法典规定了两类文书。第一类是人民法院、仲裁机构的法律文书——这两家都属于司法机构；第二类是征收决定，那是政府这个行政机关作出的。这两类不在一个系统里，认定逻辑也不一样，下面分开处理。

#### 哪些文书能发生物权变动

司法解释对司法机构这一类专门做了界定，又具体包括两种类型：

- 在**审判程序**当中做出的法律文书；
- 在**执行程序**当中做出的法律文书。

这两类都可以导致物权变动。一个在明面上、一个在执行环节，但共同点是：它们都是司法机关的公文，都有权威性，所以不需要当事人再去跑一遍公示程序。

#### 审判程序中的文书：必须是形成判决

审判程序这一类，对应司法解释的第一点：人民法院、仲裁机构在**分割共有物的案件**当中，作出的依法生效并改变原有物权关系的**判决、裁决、调解书**。

这一句里藏了三个关键词，一个都不能少：

> **关键词一**：主要是在**分割共有物的案件**中做出的。最典型的就是离婚案件——一方面法院判决双方要不要离婚，另一方面双方离婚的话，法院还得分割夫妻共同财产。这类案件常常会直接发生物权变动。
>
> **关键词二**：必须**依法生效、改变原有物权关系**。"改变原有物权关系"这六个字意味着这是一个**形成判决**，才能发生物权变动的效力。如果是确认判决或者给付判决，就不能发生物权变动效力了。
>
> **关键词三**：文书形式包括**判决、裁决，也包括调解书**。判决、裁决好理解；调解书为什么也可以？因为在离婚案件中，法院经过调解，双方就共同分割达成了一致协议，人民法院基于这个调解结果做出民事调解书，它同样可以直接发生物权变动的效力。

这三个关键词，我们拿几个典型案例来感受一下怎么适用。

**例一：离婚分割共有房产。** 甲乙是夫妻，婚后共同购买了房产一套，但登记在甲的名下。这房子是甲乙的共同财产还是甲的个人财产？答案是夫妻共同财产。后来甲在婚内出轨，二人因感情破裂诉讼离婚，法院判决登记在甲名下的夫妻共同财产归乙个人所有。判决生效以后过了十天，乙才办理了变更登记手续。

问：乙是什么时候取得房屋所有权的？是判决生效的时候，还是办完变更登记手续的时候？

**注意，是在判决生效的时候。** 这是一个典型的分割共有物案件，同时它又是一个形成判决——原来房子归甲乙共有，现在归一个人所有了，原有物权关系被改变了，所以可以直接发生物权变动的效力。

有些同学会问：为什么法院的判决可以让乙直接取得物权，而不需要等到办理登记手续的时候？两个理由。

第一，从**形式**上看，法院判决分割共有物并不是交易行为，所以不涉及交易安全需要保护，也就没有必要逼着当事人非得去办登记。

第二，法律让乙直接取得所有权，也是对乙一种**更加周全的保护**。大家想想：如果乙拿到生效判决，还得办完登记手续才能取得所有权，那他是不是还得请求甲来配合办理变更登记？甲不配合，乙还得再去法院打一个官司，请求甲配合办理登记。是不是把问题搞得更复杂了？

所以为了**防止夜长梦多**，法律对乙提供一步到位的保护——乙一个人拿着判决，就可以到登记部门把这个房产变更登记到自己名下。这样乙的合法权益是不是受到了最大限度的保护？

**例二：确认之诉。** 甲乙是夫妻，婚后共同购买了房产一套，登记在甲一人名下。甲婚内出轨，乙请求在房本上加名，遭到甲的拒绝，于是向法院提起确认之诉，法院作出确认房屋共有人（确认该房屋为甲乙共有）的判决。

这样的判决是不是发生物权变动的判决？**不是。** 因为它是确认判决。法院作出确认判决意味着什么？意味着这套房子自始至终都属于甲乙两个人共有，并没有改变原有物权关系，不属于形成判决，所以不能发生物权变动的效力。

当然，乙拿到这个判决以后，可以在房本上加上自己的名字。但这个时候他办的是**更正登记**，因为原来的登记是有错误的。

**例三：给付判决。** 甲乙离婚协议约定：乙补偿甲 50 万元，登记在甲名下的共有房产归乙所有。甲离婚以后拒绝办理登记手续，于是乙诉至法院，法院判决甲应当履行这个协议、办理登记手续。

这个判决能发生物权变动吗？**不可以。** 记住这个协议：法院判决你甲应当履行这个协议，这是个**给付判决**，不能直接发生物权变动的效力。要等甲配合办理完登记手续，才发生物权变动。因为双方签订的协议只代表当事人的意思，不够权威，不能直接发生物权变动的效力。

三个例子走下来，规律就出来了：**能发生物权变动效力的，必须得是形成判决；给付判决、确认判决都不能。**

| 文书类型 | 是否改变原有物权关系 | 能否发生物权变动效力 | 之后怎么办 |
| --- | --- | --- | --- |
| 形成判决 | 改变（如共有分割为单独所有） | 能，自判决生效时发生 | 拿着判决直接去办变更登记 |
| 确认判决 | 不改变（自始至终认定为共有） | 不能 | 去办**更正登记**，把错误登记改过来 |
| 给付判决 | 不改变，只是判对方履行 | 不能 | 等对方配合办完登记时才发生变动 |

> **易错点**：判断标准只看一件事——**这份文书有没有改变原有物权关系**。不要看当事人主张的是什么、案件是什么类型。确认之诉打的是确认判决，就只能是确认；判令对方去办登记的是给付判决，也不能直接变动物权。

#### 执行程序中的文书：裁定书直接生效

第二类是在执行程序中做出的法律文书。注意一个限定：执行程序当中**只有人民法院**可以作出法律文书。

具体是：人民法院在执行程序中作出的**拍卖成交、变卖成交和以物抵债的裁定书**。这些裁定可以直接发生物权变动的效力。

**例四：司法拍卖。** 甲向乙借了 10 万块钱，汽车设定了抵押——既有债权，又有担保。后来甲拒不还款，乙申请人民法院拍卖该车来实现抵押权。在实现抵押权期间，丙以 12 万元通过拍卖的方式取得该车，法院作出了拍卖成交的裁定书。五天以后，丙受领该车并完成登记。

丙什么时候可以取得该车的所有权？**原则上在人民法院作出拍卖成交裁定的时候，就可以发生物权变动。** 他不需要等到交付或者登记的时候。

尽管拍卖好像也是买卖，但司法拍卖并不是市场交易，不以公示为要件，所以基于这个拍卖成交的裁定就可以发生物权变动。

但是反过来记：如果是执行程序当中当事人**私自达成的以物抵债协议**，而不是人民法院作出的裁定书，那就不能发生物权变动效力。

**例五：执行中的以物抵债协议。** 甲向乙借了 10 万块钱没有还，法院判决以后依然没有履行，于是乙申请强制执行。在强制执行期间，甲乙达成了以名表抵债的协议。后来乙撤回了执行申请。

甲乙达成的这个以名表抵债的协议，能不能直接发生物权变动的效力？**不能。** 因为这是当事人私自达成的协议，并不是法院作出的裁定，并不是司法机关的公文，所以不能直接发生物权变动效力。要等甲把名表交到乙手中的时候，乙才能够取得所有权。

大家看清楚了，这是基于协议、也就是基于民事法律行为发生物权变动的一般情形，前面刚讲完，再退回来一步。

#### 征收决定：什么时候才算"生效"

第二类文书是征收决定。比如为了公共利益的需要，当政府作出征收决定的时候，尽管被拆迁人还没有腾退，也不影响国家已经取得所有权了。

国家为什么这么着急？这里要解决一个**时间问题**。

假如征收决定生效了，被拆迁人拒绝腾退，这个时候能不能申请强制执行？可以。那要强制执行的时候，强拆的是谁的房子？

**强拆的是国家的房子。** 因为文书生效，国家就取得所有权了；你不搬离，是你侵占了国家的财产，所以国家拆的是自己的房子。

反过来推：假设必须等到被拆迁人腾退以后才能够发生物权变动，那在强制执行的时候，强拆的就是老百姓的房子了，这个在正当性上是很难成立的。所以在技术上，要先让国家取得这个所有权——征收决定生效时就可以发生物权变动的效力。

那征收决定什么时候生效？是不是政府发了这个征收决定的公文，就直接发生物权变动？

如果这么理解，对老百姓的保护可能就有点不周。假如作出的征收决定虽然里面有给老百姓补偿，但补偿明显不合理，或者压根就没提补偿的事，这个时候直接让国家取得所有权，对老百姓的财产就保护不周了。

所以在解释"征收决定生效"的时候，我们一般认为：**一方面要做出这个文书，另一方面同时得做出合理的补偿；只有合理补偿也满足了，才认为这个征收决定已生效**，进而发生物权变动的效力。

这就是对征收决定做一个**目的性的限缩解释**：它不仅要求要做出这个征收决定这个法律文书，还要求要进行合理的补偿。这也是马工程教材的观点，我觉得还是非常具有合理性的。

### 因继承发生物权变动

规定在《民法典》第230条：

> 因继承取得物权的，自继承开始时发生效力。

通过继承途径取得物权，它也不是交易行为，所以不动产不需要登记，动产不需要交付，自继承开始就可以发生物权变动的效力。

这里要强调两个问题。第一，**继承开始时既包括法定继承，也包括遗嘱继承**，两者都可以适用。第二，继承开始的时间怎么认定。

#### 继承开始的时间怎么认定

要区分是自然死亡还是被宣告死亡。

**自然死亡**，死亡时间的确定规则我们在前面讲过，大家还记得吧？三步走：

1. 首先按照死亡证明记载的时间为准；
2. 第二，没有死亡证明的，以户籍注销时间为准；
3. 第三，有其他证据足以推翻上述时间的，以证据证明的时间为准。

死亡时间其实就是**继承开始的时间**。

**被宣告死亡**，自然人被宣告死亡，也可以启动继承程序。那宣告死亡的死亡时间怎么认定？人民法院作出判决之日；假如说是因意外事件被宣告死亡的，那就是意外事件发生之日。这就是发生物权变动的时点。

#### 无缝衔接：为什么死亡之日就已取得

我们来看一个小例子。

老王因突发疾病，于 2023 年 4 月 1 日在家中去世。他唯一的儿子与新婚妻子正在迪拜度蜜月，4 月 8 日回到家中才发现老王的遗体。

```text
  4月1日   老王在家中突发疾病去世
           └─ 主体资格消灭 ──▶ 丙已成为所有权人（万贯家财到手）
               │
               │   这 7 天里，丙人还在迪拜度蜜月，什么也不知道
               │
  4月8日   儿子回家发现遗体
           └─ 物权变动早已完成，这一天什么也没发生
```

问：儿子什么时候可以取得老王的遗产？需不需要等到 4 月 8 日发现遗体的时候？

**不需要。** 只要 2023 年 4 月 1 日老王一死亡，即使这个时候小王还不知道，他其实已经取得了老王的万贯家财了——不知不觉已经很有钱了。

那法律为什么要做这样的规定？主要是让**财产的归属实现一个无缝的衔接**。

因为你看，2023 年 4 月 1 日老王死亡的时候，他的主体资格已经被消灭了。假设这个时候继承人不直接取得所有权的话，那这个财产的归属将会存在一段空窗期，就可能使得这个财产变成**无主物**了——这显然是不符合生活常理的。

所以在被继承人死亡的时候，不管继承人知不知道，他都会直接成为这个财产新的所有权人，这样可以实现一个无缝的衔接。

### 因事实行为设立或消灭物权

规定在《民法典》第231条：

> 因合法建造、拆除房屋的事实行为设立或者消灭物权的，自事实行为成就时发生效力。

因事实行为发生物权变动，它也不是交易行为，所以不动产不需要登记，动产不需要交付，**只要实施行为成就，就可以发生物权变动的效力**。

这里要抓两件事：一是事实行为什么时候"成就"；二是它的适用前提。

#### 建造何时算"成就"

事实行为什么时候成就，就按照社会的一般观点来判断。

在城市里要建造房屋，这个建造行为什么时候成就？**是建筑完成封顶的时候成就。** 需不需要等到把门窗都安好，或者完成内装修的时候？不需要。只要完成封顶，这个建筑就建造完成，进而取得所有权了。

所以大家在生活中可能见过这样的大标语：一个楼封顶了，拉一个大条幅，写着"热烈庆祝某某项目封顶成功"。这其实就是宣示——我已经取得所有权了。

那假如是在农村盖房子呢？这个建造完成的时间常常是**上梁的时间**。在农村待过的同学可能了解这个过程，包括一些农村题材的电视剧里面也常常会有上梁的场景，比如《山海情》《平凡的世界》里面都有。

你看这个上梁，它意味着房子的建造完成，代表着向乡亲们宣誓："哥也是有房的人了，我已经取得房屋的所有权了。"所以在上梁这一天是要宴请亲朋好友的，是个喜庆的日子。

#### 合法建造是取得所有权的前提

事实行为的适用前提包括合法建造、拆除房屋等。这里特别注意：**建造房屋取得所有权，要以合法建造为前提。**

什么叫合法建造？就是建房子的手续必须得齐全：一方面取得了相应的土地使用权，同时办理了报建手续和规划手续，才代表你是合法建造。

那如果当时是违法建造的话，能不能取得违章建筑的所有权？**答案是不能。**

**例一（合法建造）**：甲公司依法取得某地块的建设用地使用权，并办理了报建审批手续——这意味着这是一个合法建造。开始房屋建设，并完成了房屋的外装修。问：什么时候该公司可以取得房屋所有权？

答案：建造完成，也就是**封顶的时候**可以取得所有权。外装修做没做完，不影响。

**例二（违法建造）**：某小区王某未获得规划许可证和施工许可证，便在自住房前面扩建了一个门面房，挤占了小区的人行通道。什么叫未获得规划许可证和施工许可证？这是个违法建筑。那这个门面房王某能不能取得所有权？**不能取得所有权。**

所以请注意"合法"这两个字的认定。

但**拆除房屋需不需要以合法作为前提？就不需要了。** 只要这个房子被拆掉了，他的客体都不存在了，那所有权当然归于消灭了。只是如果你是违法拆除的话，就要承担侵权责任——但是不影响这个房子已经因拆除而丧失所有权了。

> **易错点**：**建**和**拆**在这里是不对称的。合法建造是取得所有权的要件，违法建造一无所有权；违法拆除虽然要担侵权责任，但拆除本身照样让所有权消灭。"违法"在这两个方向上的后果完全不同。

### 未办理登记的法律效力

以上三种都讲完了，最后补充一个限制性规定——未办理登记的法律效力：

> 依照上述规定取得的不动产物权的，应当依法办理登记；未经登记的，不发生物权效力。

什么意思？假设基于生效文书、基于继承或者基于事实行为取得不动产物权，是不是不办理登记也可以取得物权？

**是的。只是如果你不办登记的话，你的物权效力没那么齐全——你不能行使处分权。** 你要处分的话，就必须先登记。因为这个处分行为会涉及交易安全的保护，你要是不登记就处分，后果就是不能发生物权效力。

具体规则有三层。

#### 不登记不影响你成为物权人

首先，符合我们前面讲到的因生效文书、继承和事实行为取得物权的规定时，即使不办登记，也不影响你成为物权人。所以，**办登记并不是发生物权变动的要件**。

#### 但处分的权能被卡住

既然已经取得物权了，当别人侵犯你的物权的时候，能不能通过物权请求权和侵权损害赔偿来获得救济？

**当然可以，可以主张物权请求权。** 比如：甲死亡了，留下房产一套，这个房子由他的继承人乙来继承。在乙办理完继承登记手续之前，丙侵占了这个房子，请问乙能不能请求丙返还房屋？

**答案是可以。** 尽管乙没有办理登记手续，但是基于继承，他已经是新的物权人了，可以行使物权请求权来获得救济。包括丙的行为造成房屋损害的，乙还可以请求丙承担侵权责任，可以主张救济。

第三，没有办理登记的是**不能行使处分的权能**。比如说你不能卖这个房子，不能把房子送给别人，不能在房子上设立抵押等等，不能实施处分行为。如果当时是处分行为的话，后果是**不发生物权效力**，不能发生物权变动的结果。

但是——**影不影响合同的效力？不影响。**

```text
  生效文书 / 继承 / 事实行为
            │
            ▼
   物权已变动 ── 你是物权人（不需要登记，不需要交付）
            │
      ┌─────┴─────┐
      ▼           ▼
  别人侵犯你    你要处分
      │           │
      ▼           ▼
  物权请求权    未办登记 → 权能欠缺
  + 侵权赔偿    处分不发生物权效力
  均可主张      （买卖合同本身仍然有效）
```

我们来看这个示例。甲死亡以后，登记在其名下的房产由唯一的继承人乙来继承。乙要把这个房子卖给丙的话，能不能直接卖？

**不能。** 尽管你已经取得房屋所有权了，但是你没有办理登记，并没有取得处分这最后一项权能。必须先办理继承登记，把这个房子过户到乙的名下，然后乙才能够卖这个房子。

那假如乙没有办理继承登记，就把房子卖给了第三人丁，丁能不能取得物权？

**不能**，因为乙没办登记的话，他不能处分这个房产。但是影不影响乙和丁签订的买卖合同的效力？**不影响，合同依然是有效的。** 因为当乙办完这个继承登记手续以后，丁可以请求乙来继续履行合同，使自己还有机会取得这个房屋的所有权。

这就是"未经登记不得处分"这样一个特别的规定。

#### 动产没有这条限制：指示交付

大家发现没有，法律只是限制了**未办理登记的不动产物权**的处分权。那有没有限制未完成交付的动产的处分权？没有。

这意味着基于生效文书、基于继承、基于事实行为取得动产所有权的，即使没有进行交付，能不能进行处分？**可以，而且可以发生物权变动的效力。**

举个例子：甲家里有个祖传的瓷瓶，他借给乙来把玩，瓷瓶在乙的手中。然后甲因意外而死亡，他唯一的继承人是丙。

```text
  甲 ──借出（现实交付）──▶ 乙    瓷瓶在乙手里，乙是直接占有人
   │
   └──甲因意外死亡──▶ 丙继承所有权   丙不必先把瓷瓶从乙手里要回来

  丙 ──指示交付──▶ 丁
        把"对乙的返还请求权"直接转给丁
        丁自己去乙处取瓶，交付完成，所有权随之转移
```

问：丙能不能取得这个瓷瓶的所有权？可以，因继承而发生物权变动。那关键是，丙取得这个瓷瓶所有权以后，能不能直接把这个瓷瓶卖给丁？

尽管瓷瓶还在乙的手中，丙都没有实际拿到这个瓷瓶，**但在法律上不影响他把瓷瓶卖给丁**，只是需要完成交付才能够发生物权变动。

那丙怎么把这个瓷瓶交给丁？需不需要先从乙的手里面收回来？**不需要。** 因为动产的交付除了现实交付以外，还包括关联交付。这个场景可以通过**指示交付**来完成：丙对乙是有个返还请求权的，相当于他取得了间接占有的地位；那丙可以把对乙的返还请求权直接转让给丁，说丁你直接去找乙要这个瓷瓶就可以了，这样也可以完成交付。

所以正是因为动产的交付包括指示交付这样的形态，取得物权的人即使没有实际拿到这个动产，也不影响他处分，并通过指示交付的方式把物权转移给别人。**所以法律只是限制了不动产物权的处分权。**

---

### 两条线索摆在一起看

这一节我们重点介绍了**两个层次**的物权变动规则，把它们并到一起看就清楚了：

| | 基于民事法律行为的物权变动 | 非基于民事法律行为的物权变动 |
| --- | --- | --- |
| 是否交易行为 | 是 | 否 |
| 是否涉及交易安全保护 | 涉及 | 不涉及 |
| 取得方式 | 公示：不动产登记、动产交付 | 法律规定的条件成就即可 |
| 是否需要公示 | 必须 | 不需要 |
| 唯一的例外 | — | 已取得但未登记的**不动产**，不能行使处分权能 |

基于民事法律行为发生的物权变动，因为它涉及交易行为，为了保证交易安全，需要通过公示的方式才能够取得物权——不动产进行登记，动产要完成交付。

而这个非基于民事法律行为的物权变动，既然不是交易行为，不涉及交易安全的保护，所以直接按照法律规定就可以取得物权，不需要进行公示。

> **结论**：判断一个物权变动要不要公示、要不要登记或交付，先问一句——**它是不是交易行为？** 是，就老老实实走公示；不是，文书生效、继承开始、事实行为成就，物权当场就变。唯一的例外留了个尾巴：不动产已经取得但还没登记的，处分的权能被卡住，**不过合同效力不受影响**。

### 本讲提到的题目

**真题（甲在宅基地建房未办登记，过继承后由乙卖给丙）**

甲经政府主管部门批准，在宅基地上盖了一栋楼房，没有办理房屋的登记手续。

---

**第一步：甲能不能取得房屋所有权？**

**可以。** 既然他取得了宅基地使用权，意味着他是一个合法建造；只要建造完成就可以取得房屋的所有权，不需要等到办理登记的时候。

**第二步：3 年后甲死亡，其唯一继承人乙能不能取得房屋所有权？**

**可以。** 自继承开始时，乙就基于继承取得了房屋所有权，同样不以登记为要件。

**第三步：乙把房屋卖给同村丙，并完成了交付。丙能不能取得所有权？**

**不能。**

理由是：甲死亡的时候，尽管乙可以继续继承取得所有权，但是因为没有办理登记，所以乙不能处分这个房屋。他要处分的话，后果是不能发生物权效力——**那么房屋所有权依然属于乙**。

**第四步：这影响乙和丙签订的买卖合同的效力吗？**

**不影响。** 合同依然有效。所以当乙办完这个登记手续以后，丙可以请求乙来履行买卖合同，继续配合办理登记手续。

所以应该选的是 **C 选项**。

---

**解析依据**（对应正文各节）：

- "合法建造 + 建造完成即取得所有权，不需要等登记"——《事实行为设立或消灭物权》一节，以及例一、例二。
- "乙经继承取得所有权"——《因继承发生物权变动》一节。
- "乙未办继承登记 → 不能行使处分权能 → 处分不发生物权效力"——《未办理登记的法律效力》一节第三层规则。
- "合同效力不受影响，乙办完登记后丙可请求继续履行"——同节示例部分。
- 另可对照的完整模拟：甲家祖传瓷瓶借给乙，甲死亡，丙继承后直接卖给丁，通过**指示交付**完成物权转移（动产无"未办登记不得处分"的限制）——《动产没有这条限制》一节。

## 登记簿上的那本账：不动产登记的效力、类型与责任
> 对应块：BLK50 | 覆盖分集：P46 | 块标题（分集名）：《第03编 第01章 第04节：不动产登记》

前面讲交付，我们把动产公示的各种形态捋了一遍。转到不动产这边，情况要复杂一些——所以才有单独一节来展开。

复杂在哪儿？一句话：不动产靠登记公示，动产靠交付公示。动产交付的方式我们在前面已经分类讲过了，不动产登记的门道要另开一节才说得清。

### 不动产登记是什么：抓住三个关键词

先把概念摆正。所谓不动产登记，是指**不动产登记机构依法将不动产的权利归属和其他法定事项记载于不动产登记簿的行为**。

这个定义里埋着三个关键词，每一个都可能在考场上单独拿出来问你。

**第一，主体是"不动产登记机构"。** 它是一个机关法人。好多地方把不动产登记局叫法不一，像北京那边就称作不动产登记中心——名字有差别，法律人格是一回事。

**第二，事项是"权利归属 + 其他法定事项"。** 右边这一半最容易漏。不动产物权发生变动时，登记的是权利归属；但还有一些事项，虽然**不会导致物权变动**，同样属于登记的范畴，比如后面要讲的更正登记、异议登记、预告登记。它们不是物权变动的要件，却是登记簿上实实在在的一栏。

**第三，载体是"不动产登记簿"。** 记到簿子上，才叫登记。

> **易错点**：不少人一想到"现实中那么多房子"，就替不动产登记簿的厚度发愁——"那这个登记簿不得多厚啊？"这样的想法也太过于朴素了。我们现在的登记是通过**电子登记系统**实现的，不是那厚厚的一摞册子。一方面纸质的确实很不方便，另一方面也不太绿色。

### 登记簿与权属证书：到底以谁为准

刚才说到办登记要把事项记到登记簿上，这里就冒出一个天然需要区分的问题：不动产登记簿和权利人手里的权属证书，哪个算权威？

看一组对照就清楚了。

| 比较点 | 不动产登记簿 | 权属证书 |
| --- | --- | --- |
| 归谁 | 由登记机构管理 | 由登记机构发给权利人 |
| 典型形态 | 登记系统中的记载 | 房产证 |
| 物权归属的依据 | **有权威性** | 不能与登记簿相抵触 |

你办完登记，物权变动情况记到了登记机关的登记系统里，这是登记簿；同时登记机关会给买房人发一个房产证，这个房产证就是权属证书。

那二者记载不一致的时候听谁的？

> **结论**：不动产登记是**不动产物权的公示方式**，登记簿才是确定物权归属的依据。**二者记载不一致的，以不动产登记簿为准**；除非能够证明登记簿的记载本身有错误，否则就按登记簿的记载来。

### 登记的效力：生效还是对抗

这是一个纯理论问题，但却是本节的骨架。民法典采用的是**登记生效与登记对抗相结合**的模式。结合起来，就意味着办理不动产登记可能发生两种效力。

**登记生效**：办理登记会发生物权变动的效力。登记是物权发生变动的**要件之一**，未经登记就不发生物权效力。

**登记对抗**：即使当时没有办理登记，也可以发生物权变动的效力，只是没有登记就不能对抗善意第三人。此时登记发挥的是对抗效力。

> **结论**：在我国，**以登记生效为原则，以登记对抗为例外**。哪些登记发挥的是对抗效力，需要特别掌握；凡是**没有作特别规定的**，一律都属于登记生效的模式。

在教材里我把两种效力的适用情形做了一个总结，考试时按这张表来认：

| 权利类型 | 适用情形 | 效力类型 |
| --- | --- | --- |
| 所有权 | 基于买卖、赠与、互易等行为发生的不动产所有权变动 | 登记生效 |
| 用益物权 | 建设用地使用权的设立 | 登记生效 |
| 用益物权 | 居住权的设立 | 登记生效 |
| 担保物权 | 不动产抵押权 | 登记生效 |
| 用益物权 | 土地承包经营权的互换、转让 | **登记对抗** |
| 用益物权 | 地役权的设立 | **登记对抗** |

几个要点要交代清楚。买房子什么时候取得所有权？办完登记手续的时候。建设用地使用权还记得这个词吧，就是在城市的土地上盖房子的权利。居住权也是一种用益物权，设立同样要登记。

土地承包经营权这里要特别小心：**设立**和**流转**的规则不一样。设立我们在后面物权那一章会讲到，不办登记也可以对抗第三人；这里说的登记对抗，落在**流转**上——互换、转让。

至于地役权，先有个印象。等讲到每一种具体物权的时候，我都会特别强调登记对它发生的效力。

### 物权变动的四类登记

民法典规定的不动产登记，整体分成两大类。第一类是**发生物权变动的登记**，第二类是**不能发生物权变动的登记**，也就是我们后面要讲的"其他登记"。先看第一类。

因为物权变动是**广义**的概念——包括物权的设立、变更、转让和消灭，所以不动产物权的变动登记同样是广义的，展开就是四类：

```text
           物权变动（广义）
                  |
   +--------------+--------------+---------------+
   |              |              |               |
  设立           变更           转让            消灭
   |              |              |               |
 首次登记       变更登记       转移登记        注销登记
```

- **首次登记**对应设立，第一次登记。
- **变更登记**对应变更，某些登记事项发生变更时进行的登记。比如权利人姓名变了，之前叫张三，后来因各种原因要改成李四——跟着母亲的姓。改了名字，登记簿上的权利主体也得跟着改成李四。但这是**同一个人**，主体没变，只是姓名变了，这就叫变更登记。
- **转移登记**对应转让。甲把房子卖给乙，双方办的过户登记手续就是转移登记。
- **注销登记**对应消灭，从"有"到"无"的过程。

四类里，转移登记是考试最常考的，因为它天然接着"物权变动规则"这条主线。

### 更正登记：有错必改

第二种属于"其他登记"——虽然不发生物权变动，但也发挥着重要作用。更正登记、异议登记、预告登记，这三个词都是标准的法言法语，考察点集中在两件事上：**什么时候可以办理**，以及**办完之后产生什么后果**。

更正登记体现的是"有错必改"的观念：申请人要求对登记簿当中的错误记载事项予以更正。原来登记有错误，就把它改过来，使得登记状况跟真实情况相符合——这也符合公信原则的要求。

#### 谁可以申请

两个主体：**权利人**（就是登记簿上记载的名义人），以及**利害关系人**。

#### 什么条件下才能办

民法典给了两种情形。

| 申请人身份 | 条件 | 登记机构要不要调查 |
| --- | --- | --- |
| 登记簿记载的权利人（登记名义人） | 书面同意更正 | **不用调查**，直接更正 |
| 利害关系人 | 有证据证明登记确有错误 | 要看证据 |

第一种的逻辑特别顺：登记名义人自己同意更正，那登记机构连调查都省了——你的权利你自己都同意改，法律当然也同意。

第二种就不一样了。举个经典的例子。

甲乙结婚以后，用夫妻共同财产买了一套房产，登记在甲一个人名下。这个房子明明是夫妻共同财产，登记簿上却只写着甲——登记簿的内容没能反映权利的真实归属，登记存在错误，这时候就需要更正。

问题是：满足什么条件，登记机构才会把乙的名字加上去？

**情形一，甲同意。** 登记簿上记载的甲出个书面声明：这个房子是我和配偶的夫妻共同财产，现在只登记了我一个人的名字，我书面同意更正。这时登记机构可以直接把乙的名字加上去。

**情形二，甲不同意。** 你想得挺美——"他觉得就我一个人在登记簿上挺宽敞的，带着一个人有点拥挤"，他就是不干。那乙就是典型的**利害关系人**：他虽然也是房屋的共有人，但没有记载到登记簿上。乙要去办更正登记，就得拿出**确切的证据**。

这个确切的证据，主要体现为**人民法院的确权判决**。乙可以向法院提起确权之诉，请求法院确认他也是房屋的共有人；法院作出确权判决后，乙相当于拿到了确切的证据，直接去登记机构办更正即可。

> **结论**：更正登记的两个条件，抓"名义人同意"和"利害关系人举证"这两条就够。

### 异议登记：先把登记簿的公信力打断

利害关系人对不动产登记簿记载的事项有异议的，可以在登记簿上注明"你对登记事项提出了异议"。

#### 谁能申请

> **易错点**：申请异议登记的主体是**利害关系人**。**权利人不需要办异议登记**——因为如果你是权利人，觉得登记上有问题，你直接用书面声明的方式更正就行了，没有必要对自己的权利提出异议。

利害关系人就不一样了。他要申请更正登记得有确切的证据，而证据在拿到之前，是办不成更正登记的。但这时候可以先办一个**异议登记**，来提供临时保护：把登记簿的公信力打破了，提醒交易的相对方——你要买这个财产的话，你得悠着点，它的权属是有争议的。

#### 四条规则

**第一，异议登记打的是"临时保护牌"。** 因为它只是个临时的救济措施，所以**申请时不需要充足的证据**，不需要你一申请就给你注明。真要是"一申请就注明"，那它就不是临时的了。

**第二，它的核心作用是防止第三人善意取得。** 打破登记内容的公信力，这个财产就不可能被第三人善意取得——这等于**预留了比较充足的时间**给权利人去走确权之诉。

**第三，15 日内不起诉，异议登记自动失效。** 既然是临时措施，法律就要求你在**异议登记之日起 15 日内**去法院起诉——因为法院才能真正解决你们之间的纠纷。15 天没起诉的，异议登记自动失效。

> **提示**：但**异议登记失效，不影响当事人提起诉讼的权利**。因为本来你就可以不办异议登记直接去起诉，失效只是把你拉回原点而已。真正的代价是：失效以后，这个财产就有可能被第三人善意取得了。

**第四，事后要秋后算账。** 因为申请异议登记不需要充足证据，那事后完全有可能证明你这一登记是没有依据的、是无理取闹的。如果异议登记给权利人造成了损害，申请人是要承担赔偿责任的。

什么损害？人家本来要卖这个财产，好不容易等到一个合适的买主，结果因为你的异议登记，买主不敢买了，房子没卖出去——这个损失可能要赔。**毕竟现在的房价在不断地下跌，早点卖早点止损吧。**

#### 一个案例看规范作用

还是前面那个甲乙的房子。我们把时间轴拉直：

```text
 03-01  乙提出把房子登记为共有人（加名），遭到甲的拒绝
 03-10  甲未经乙的同意，与不知情的丙签订房屋买卖合同，要卖掉房子
 03-12  乙申请异议登记（证据不足，还办不了更正登记）
 03-20  乙向法院提起确权之诉 —— 在 15 日内，及时
 03-25  丙认为乙的证据不足，仍配合甲办理了过户登记手续
        结果：房屋登记到丙名下
```

到这里就得判断了：**甲到底是有权处分还是无权处分**？

- 有权处分，办完登记就发生物权变动；
- 无权处分，那丙要取得所有权，就得符合**善意取得**的构成要件，特别是**善意**要件。

那就分成两种情况来看。

**第一种：法院最终确认这房子是甲婚前一个人买的。** 那它就是甲的个人财产，甲当然有权处分。甲能把房子过户登记到丙名下，丙就能取得房屋所有权——物权变动可以发生。

**第二种：法院最终认定房子是甲乙婚后共同购买的，归双方共有。** 那当初甲单独卖这个房子就属于**无权处分**。丙要取得所有权，就得符合善意取得的构成要件。

丙符合"善意"要件吗？

> **结论**：**不符合。** 因为在丙和甲办理过户登记手续的那一天，登记簿上还记载着**有效的异议登记**——利害关系人乙正在对甲的权利资格提出异议。这相当于在提示交易的相对方：你买的时候悠着点，卖方不一定有资格卖这个房子。既然如此，**丙就应当知道甲属于无权处分**，因而不构成善意。

从法律角度讲，异议登记防止的就是财产被第三人善意取得。所以丙不能取得房屋所有权。**尽管房屋登记在丙名下，但此时乙可以请求办理变更登记手续**，因为丙并不是房屋的所有权人。

这就是乙当初办这个异议登记的价值所在——**给自己后来打官司赢得了时间**。

### 预告登记：提前披上物权的皮肤

预告登记在考试当中比较重要，而且也是个标准的法言法语。它首先是跟"**本登记**"相对应的：本登记就是本来当时要办理的物权变动登记。而预告登记，是当事人签订合同以后，为了保障将来能够实现物权，而向登记机构申请的**预先的登记**。

说白了：虽然我现在还没取得物权，但这个物权马上就要归我了，我作为新的物权人马上就要闪亮登场了——敬请期待，不要走开。发挥一个**预告**的功能，这就叫预告登记。

#### 为什么需要预告登记

有些同学会问：为什么不直接办理物权变动登记，先预告一下？

因为实践中**当时办理本登记的条件尚未满足**。举个例子。

甲要购买某科公司（开发商）开发的预售商品房一套，双方签订买卖合同，约定两年以后交房。

记住这个**买卖合同**。甲能不能直接请求开发商办理过户登记？答案是**不能**。因为这是预售商品房，房子还盖不出来，开发商自己都还没取得所有权呢，当然不能转移给甲。

所以，签了这个合同，甲只取得了一个**债权人的身份**——这个地位非常不稳固。为了防止开发商把这套房再次卖给别人，这时候甲可以先办一个预告登记。假如开发商真把房子再卖给别人，因为甲只是普通债权人，只要乙先办理了过户登记，乙就可以优先取得房屋所有权，甲买房的目的就落空了。

所以要**先向大家预告一下：虽然现在这房子还不归我，但是马上就要归我了**。这就是预告登记存在的价值。办完预告登记以后，开发商再把房子卖给别人，别人就不可能取得这个房屋的所有权了。

#### 申请规则：要约在先、双方申请

第一项规则：预告登记**需要事先在合同里面进行约定**，并且由**双方共同申请**。

甲不能单方面宣布"接下来这个所有权就要归我了，我要闪亮登场了呀"——**你单方面宣布，那是没有任性可言的**。所以要由开发商作为出卖人和买受人甲，两个人共同申请。

> **易错点**：这一点跟更正登记、异议登记不一样。更正登记和异议登记在具备条件的时候，**可以单方提出申请**；但预告登记需要合同双方一起申请。

#### 办完之后：锁住的是处分权

第二项规则是办完预告登记后产生的后果——**限制权利人的处分权**。

甲办了预告登记之后，开发商**未经甲的同意，不能处分这个不动产**。要处分的话，后果是**不发生物权效力**，别人不可能取得物权。这是不是让甲取得了"第一替补"的身份？我要登场，我不登场，别人也登不了场。

那么，**这里面的"处分"怎么理解**？这是司法解释作出的明确规定。

办完预告登记以后，原权利人也就是开发商，就不能再处分这个不动产了。这个"处分"主要体现为**发生物权变动的行为**：

- 包括**转移所有权**——开发商你不能再卖这个房子了；
- 也包括**设定建设用地使用权、居住权、抵押权**等物权行为。像前面那个案例中，既然你已经给甲办了预告登记，那你还能不能把这套房抵押给丙银行？**也不可以**，因为这也是处分行为，后果同样是不发生物权效力。

> **结论**：违反的后果是**物权不发生变动，但合同效力不受影响**。乙、丙仍然可以追究开发商的违约责任——合同还在，只是拿不到物权。

由此还可以推出一个更重要的结论：办了预告登记的甲，取得了一个**对抗第三人（比如后来的买受人乙、抵押权人丙）的效力**。本来他取得的只是债权，只能对抗特定的相对方，也就是开发商；自从办了预告登记，就取得了对抗第三人的效力。

> **提示**：可以理解为，**预告登记使得甲披上了一个物权的外衣**——通过预告登记取得一个"物权皮肤"，进而取得对抗第三人的效力，提前感受一下物权的感觉。

#### 失效的两种情形

第三方面是预告登记的失效。既然它只是物权变动的预告，就不能一直预告下去，你总得有转正的一天。转不了正，预告登记也会被消灭。民法典规定了两种情形。

**第一种：自能够进行不动产登记之日起 90 日内没有办理登记的，预告登记失效。**

> **易错点**：**注意这个 90 日的期限，它不是从办理预告登记之日起计算的，而是从"能够办理不动产登记之日"起算。** 什么时候可以启动转正手续了，就从这一天开始算 90 天。90 天内没有完成本登记的，预告登记失效。

也就是说，你只是取得了 **90 天的物权体验卡**。一旦过期，你就重新回到普通债权的身份了，这意味着原权利人就可以再处分这个不动产。

**第二种：债权消灭的，预告登记失效。**

这个跟预告登记存在的价值直接相关。预告登记是为了保障一个**债权将来能够实现物权**，也就是要完成一个从债权到物权的**质变**。假设债权都消灭了，还怎么可能转换成物权？不可能了，预告登记也就没有存在的意义了。

**关键是什么叫"债权消灭"？** 司法解释专门作出了规定——我们曾经考到过法条分析题。它指的是：**买卖不动产物权的协议被认定无效、被撤销，或者预告登记的权利人放弃债权的**。

#### 一个案例：7 月 1 日签约，7 月 19 日抵押

甲有一套房屋要卖给乙。双方在 2023 年 7 月 1 日签订买卖合同，同时约定：9 月 1 日付清全款，9 月 10 日办理过户登记手续。9 月 10 日，乙付清全款，通过办理登记取得房屋所有权。

但从签订合同到约定的过户时间，中间**相差两个月之久**。这两个月里，什么事情都有可能发生。假如房价上涨，甲见钱眼开，把房子再次卖给别人怎么办？

为了防止这种情况，确保乙能取得物权，双方约定在 **7 月 5 日办理预告登记**——乙把"第一替补"的身份占下来，向世界宣告：虽然现在这房子不是我的，但马上就是我的了，你们都不要惦记了。

然后到了 **7 月 19 日，甲把房屋抵押给了银行**。

> **提示**：从考试角度讲，**一旦出现预告登记的信息，题目的下一步一定是权利人再次处分这个不动产**。否则预告登记这个考点就没法考了。

我们来判断两个问题。

**问题一：银行能不能取得抵押权？**

不能。尽管银行签了合同、也办了登记手续，但**已经有别人先把这个位置占下来了**。甲未经乙的同意处分不动产，不发生物权效力。所以银行即使办了登记，也不能发生物权效力。

这里法律保护的是乙的利益——乙通过预告登记取得了对抗第三人（银行）的效力。所以**虽然乙本质上是债权人，但凭这个预告登记，她获得了物权皮肤，可以行使一部分物权人才有的对抗效力**。

**问题二：如果后来发现乙在签订买卖合同时是无民事行为能力人呢？**

比如乙是精神病人。那意味着双方签订的买卖合同是**无效的**。此时银行能不能取得抵押权？**能。**

因为买卖合同无效，意味着乙取得的债权已经消灭了；那么预告登记想要发挥的"保证这个债权实现物权"的目的，还有没有机会实现？没有了。所以**预告登记失去效力，物权皮肤直接失效**。甲重新取得再次处分这个不动产的权利，属于**有权处分**；既然办了登记，银行（丙）就可以取得抵押权。

这就是预告登记存在的意义：它是一个**有期限的、有条件的物权皮肤**。

### 一道考过的真题：预告登记的存续与丙能否取得所有权

我们来看一个考过的真题，2016 年的单选题。

2014 年 3 月 12 日，甲乙签订房屋买卖合同，并于**当日办理了预告登记**——提前把"第一替补"的身份占下来了。合同约定：乙要在 3 月 15 日支付全款，双方应于 3 月 30 日之前办理过户登记手续，也就是最晚 3 月 30 日得办完过户。乙按约支付了房款以后，因甲出差，双方一直没有办理登记手续。这意味着**乙有没有取得物权？没有，她只是取得了一个替补的身份**。

7 月 10 日，甲又将该房屋卖给了丙，并办理了过户登记手续。

```text
 03-12  甲乙签订房屋买卖合同，当日办理预告登记
 03-15  乙按约支付全部房款
 03-30  合同约定最迟此日办理过户登记（甲出差，未办）
 06-30  90 日期限约在此日届满（自 03-30 起算 3 个月）
 07-10  甲将房屋卖给丙，并办理过户登记手续
 08-01  乙将甲诉至法院
```

**第一问：关于两份买卖合同的效力，下列说法正确的是？**

同一套房子，甲先和乙签了合同，后来又和丙签了合同，两个买卖合同的效力如何？

**两份合同都是有效的**，所以选 A。理由是：**债权没有排他性，具有相容性**，内容相冲突的两个债权可以并存。

**第二问：2014 年 8 月 1 日，乙将甲诉至法院，此时预告登记还有效无效？**

选"**预告登记失效的情形**"。

怎么算的？题目里冒出了"8 月 1 日"这个信息，就说明它**有可能考察预告登记的存续**。那 90 天的期限从什么时候起算？**从能够办理本登记之日起计算。** 按合同约定，3 月 30 日之前就要办理登记，那么 90 日的有效期最晚也要从 3 月 30 日开始计算。从这时起算，三个月大约到 **6 月 30 日**期限就届满了。所以在 8 月 1 日的时候，预告登记已经过期，没有效力了。

**第三问：丙能不能取得房屋所有权？**

**能，所以选 C。** 既然预告登记已经失效，那就使得甲重新取得了处分这个不动产的权利，属于**有权处分**；既然他给丙办了登记手续，丙就可以取得房屋的所有权。

> **易错点**：这个题目部分同学会有个疑问——双方没有办理登记，不是乙的错，而是因为甲一直出差，才导致没能办理登记。这点**不影响**预告登记失效的效力。
>
> 还是那句话：我们在学习物权变动的规范时，**不要把你生活当中的所谓"朴素正义观"考虑进来，一定按照法律规定来判断。** 前面讲 90 日有效期的时候，有没有讲过"因为什么原因经过才导致预告登记失效"？**没有。只要期限届满，预告登记一律失效。**
>
> 有同学会说"这对你来讲也太不公平了呀"。**没有什么不公平可言。** 法律让预告登记失效，是为了保护自己的利益，保护像丙这样的交易相对方的利益——因为丙在买房时会发现，**你的预告登记已经失效了；我有没有义务去查询你的预告登记失效的原因？是没有的**。法律要保护的是相对方的信赖利益。
>
> 实际上对乙来说，法律已经仁至义尽了：你办了登记，法律给你 90 天的物权体验卡；这 90 天里，你作为普通债权人可以获得一部分对抗第三人的物权效力。**但是不要披上了物权的皮肤，就忘了自己本来是个债权人。** 这 90 天的物权体验期，是法律额外给你提供的保障。你没能在期限内转正的，那不好意思，法律对你的额外保障只能到此为止——你要重新打回原形，以债权的身份去跟别人 PK 了。

### 登记机构做什么、不做什么

第三个问题：不动产登记机构的职责和登记错误的责任。

官方教材里其实只写了**登记错误的责任**，我们按照民法典的规定以及马工程教材，给大家补充了**登记机构的职责**——因为你首先得知道登记机构有哪些职责，然后才能确定它登记错误时的法律责任。

#### 应当履行的职责

民法典明确规定，登记机构应当履行以下职责：

1. **查验**申请人提供的权属证明和其他必要材料；
2. 就有关登记事项**询问**申请人；
3. **如实及时**地登记有关事项；
4. **办理登记**（这是核心职责）；
5. 法律、行政法规规定的其他职责。

> **结论**：原则上，登记机关主要尽到的是**形式审查义务**，只承担一个**柜台责任**——我坐在柜台里，你提交了什么资料，我就查验这些资料；我有疑问就询问你，问清楚、办完，职责就在柜台里完成了。

但有一个例外：**必要的时候可以实地查看**。而且民法典第二款还规定，有关情况需要进一步证明的，可以要求申请人补充材料——你觉得材料不够，让他来补，这也在柜台里就能完成。

所以第一方面的结构是：**以形式审查为主，以实地查看为例外**。

#### 不得实施的行为

不属于职责范围的，也就是**不要越界**：

1. **不得要求对不动产进行评估。** 你的任务是把不动产权属搞清楚，至于这房子值多少钱，跟你没关系——办一套 1000 平米的豪宅过户，和办一套 30 平米的学区房过户，手续是一样的。
2. **不得以年检名义进行重复登记。** 一方面增加当事人的负担，另一方面重复登记也可能导致权属不明，给交易安全带来破坏。
3. **不得实施超出登记职权范围的其他行为。** 不能越界。

### 登记出错，谁赔

第三方面是登记错误的责任，涉及两个主体的责任。

**第一，当事人的责任。** 申请登记时提供了虚假材料，造成他人损害的，应当承担赔偿责任。**本质上这属于侵权行为**，要承担侵权责任。

**第二，登记机构的责任。** 假设登记错误给他人造成损害的，登记机构应当承担赔偿责任。

> **结论**：登记机构承担赔偿责任的前提是**登记错误**，**不需要考虑登记机构自己有没有过错**——登记错了就得赔。至于责任内部的划分，登记机构承担赔偿责任以后，可以向造成登记错误的人**追偿**，比如向提交虚假材料的当事人追偿。

> **提示**：注意顺序——**登记机构先对外承担赔偿责任，然后才向有过错的当事人内部追偿**。这个"先赔后追"的顺序是常考的。

### 本讲提到的题目

#### 2016 年真题（单选题，三问）

**题干**：2014 年 3 月 12 日，甲、乙签订房屋买卖合同并于当日办理了预告登记。合同约定：乙于 3 月 15 日支付全款，双方于 3 月 30 日之前办理过户登记手续。乙按约支付了房款后，因甲出差，双方一直未办理过户登记。7 月 10 日，甲又将该房屋卖给丙并办理了过户登记手续。2014 年 8 月 1 日，乙将甲诉至法院。

**问一**：关于两份买卖合同的效力，下列说法正确的是（　）。
**问二**：2014 年 8 月 1 日，乙将甲诉至法院，此时预告登记是否有效（　）。
**问三**：丙能否取得房屋所有权（　）。

**答案与解析**：

- **问一：A（两份合同均有效）**。债权没有排他性，具有相容性，内容相冲突的两个债权可以并存，故甲乙、甲丙两份买卖合同均有效。
- **问二：预告登记已失效**。90 日期限**自能够办理本登记之日起计算**，而非自办理预告登记之日起计算。本案按合同约定最迟 3 月 30 日应办理过户登记，90 日自该日起算，约于 6 月 30 日届满，故 8 月 1 日时预告登记已失效。
- **问三：能取得房屋所有权**。预告登记失效后，甲重新取得处分该不动产的权利，属于有权处分；已为丙办理过户登记，丙可取得房屋所有权。

**依据（详见正文）**：预告登记 90 日起算点与失效后果见「预告登记：提前披上物权的皮肤」中「失效的两种情形」；债权无排他性、相容性的判断见该节真题分析；甲出差不构成免责事由的法律理由见该节「易错点」提示。

#### 法条分析题（曾考过，司法解释关于"债权消灭"的规定）

## 物权的保护：三个层次与三种物权请求权
> 对应块：BLK51 | 覆盖分集：P47 | 块标题（分集名）：《第03编 第01章 第05节：物权的保护》

这一节讲的是各类物权在保护上的**共性规则**——注意，是"提取公因式"之后剩下来的那部分一般性规定。前面讲物权变动的时候也是这个路子：不管你是所有权、用益物权还是担保物权，变动的规则都可以提炼成几条通用的线；保护也一样。

### 保护物权的三个层次

我们在讲人格权保护的时候提过，民法对某种权利提供保护的时候，它形成的框架常常分成三个层次。物权这边，一模一样。

```text
┌──────────────────────────────────────────────┐
│ 第三层  物权特有的保护制度                   │
│ · 恢复原状请求权                             │
│ · 确认物权请求权（其他制度的前提）           │
├──────────────────────────────────────────────┤
│ 第二层  绝对权通用的保护方法 —— 物权请求权   │
│ （物权自带的"免疫系统"）                     │
│ 返还原物 · 排除妨害 · 消除危险               │
├──────────────────────────────────────────────┤
│ 第一层  各种权利通用的保护规则               │
│ · 侵权损害赔偿                               │
└──────────────────────────────────────────────┘
```

从下往上读：最底下那层是**任何权利**都能用的，物权当然也能用，那就是侵权损害赔偿；中间那层是**绝对权**通用的保护方法，物权作为一种绝对权，可以适用绝对权通用的保护方法，这套方法在物权里就体现为物权请求权——你可以理解成物权自带的免疫系统；第三层才是物权自己特有的两样东西，恢复原状和确认物权。

> **定义**：物权请求权——依附于物权、与物权不可分离，请求恢复对物之圆满支配状态的保护方法。

这套东西的展开顺序，我们是从后往前讲的。因为确认物权常常是其他保护制度适用的前提——你得先确定自己到底是不是物权人，才有资格去主张返还、排除妨害。所以顺序是：先讲物权特有的制度，再讲绝对权通用的物权请求权，最后讲各种权利通用的损害赔偿。

### 确认物权请求权：先把"我是物权人"定下来

民法典第234条：**因物权的归属和内容发生争议的利害关系人，可以请求确认权利。**

适用前提只有一句话：**物权的归属和内容产生争议**。你要主张物权保护，首先得确定你是物权人；如果连这一点都有争议，那就得先走确权程序，把自己确认成物权人。

提出请求的主体是**利害关系人**——这是法条里面直接体现的关键词，不用另找标准。

具体规则有两项。

第一项，**不动产登记簿记载的情况和真实权利状况不符，而自己是不动产物权真实权利人的，可以请求确认物权**。请求确认进来，确认这个登记簿的记载是有错误的，然后就可以去办理更正登记手续。

举个例子：甲、乙结婚，以夫妻共同财产买了一套房产，只登记在甲一个人名下。登记簿的记载和真实的权利状况不符，这时候乙是房屋真实的权利人，乙可以提起确认物权之诉。法院作出确权判决，认定乙是房屋共有人，这份判决本身就代表登记簿的记载是有错误的。乙拿着这份判决，就可以去办更正登记。

第二项，**请求确认物权的范围，既包括确认所有权，也包括确认其他物权**。甲、乙都是某村的村民，两家承包的土地相邻，结果对承包地的界限产生了争议——不管是甲还是乙，都可以请求法院确认自己承包经营权的范围。所以确认的客体不限于所有权，他物权的归属同样可以确认。

> **提示**：这一项是**确认之诉**，不是给付之诉——法院只是确认一个归属事实，不是判你把东西交给我。所以它不受诉讼时效限制。

### 物权请求权：物权自带的免疫系统

前面讲物权效力的时候反复说，物权是绝对权，法律关系的内容是"权利人可以直接支配物"。既然可以直接支配，那这份支配力就天然带着一套保护机制：外界一入侵，它自动启动，把对物的圆满支配状态恢复回去。这就是物权请求权。

它在民法典里规定了三种类型。选哪一种，取决于你的物受到了什么程度的影响：

```text
    物受到了什么程度的影响？
    │
    ├── 已经被侵占                  ► 返还原物（235 条）      把东西要回来
    │
    ├── 没被侵占，只是行使受到了影响► 排除妨害（236 条）      让物还能用起来
    │
    └── 将来有可能发生妨害          ► 消除危险（236 条）      把隐患掐掉
```

#### 返还原物请求权

民法典第235条：**无权占有不动产或者动产的权利人，可以请求返还原物。**

判断它能不能用，就看两个要件：

```text
                         返还原物请求权                          
                       ╱      ╲
请求权人这一侧              相对方那一侧
│                           │
要件一：请求人是物权人      要件二：相对方是现实的无权占有人
并且要有占有的权能          曾经占有、现在已不占有的，
地役权人、抵押权人没有      一律不能对他主张
这个权能；构成共有的，      每个共有人都能行使
```

**要件一：请求人得是物权人。** 既然它属于物权请求权，行使这个权利首先得具备物权的身份。假如不是物权人，就不能行使原物返还请求权。

举个例子：甲有部手机，借给了乙一直用着，后来这部手机被丙偷了。乙能不能请求丙返还原物？**不能**。虽然这部手机是在乙的手里被偷走的，但乙是借来的手机，乙对这个手机并没有物权，乙只是一个债权人，不具备行使原物返还请求权的条件。反过来，甲当然可以请求丙返还。

> **提示**：这时候乙能主张的是**占有返还请求权**——注意，这是另外一套制度，跟原物返还请求权是两码事，不能混为一谈。

法条里说的"物权人"，范围要比我们直觉的宽。**用益物权人、担保物权人，只要具备占有的权能，都可以作为物权人来主张返还原物。**

再举个例子：树哥家承包了村里的 A 地块（这个情形我们前面讲过），村长的小舅子二猪要开矿建厂，擅自侵占了树哥家的承包地。树哥家作为土地承包经营权人，能不能请求二猪返还 A 地块？当然可以。尽管树哥家是用益物权人，但他对这块不动产是有占有的权能的，可以行使返还原物请求权。

那么哪些物权人没有占有的权能？记两个例子就够了：

- **地役权人**——地役权常常没有占有的权能，所以地役权人常常没有原物返还请求权；
- **抵押权人**——因为抵押权本来就不转移占有。

其余的物权人，只要具备占有的权能，基本上都能行使原物返还请求权。还有一种情况要单独拎出来：**如果当时构成的是共有，每一个共有人都可以行使返还原物请求权。** 比如夫妻一起买了一辆车，这辆车是夫妻共同财产，后来被别人偷了——无论是甲还是乙，都可以主张返还原物请求权，因为他们作为共有人都是物权人。

**要件二：相对方必须是现实的无权占有人。** 这里有两个关键词，一个都不能少。

第一，他首先得是**无权占有人**——因为原物返还请求权的适用前提就是无权占有。第二，他还得是**现实的**物权占有人——假如曾经是、但现在已经不是无权占有了，就不能对他主张。

举个例子：甲的手机遗失了，被乙捡到；在乙占有期间，丙把手机抢走了。甲作为物权人，找谁主张返还原物？

找丙可以，因为丙是现实的无权占有人。那能不能找乙？**不能**。尽管乙曾经无权占有过、曾经拥有过，但乙现在已经丧失占有了，他不是现实的无权占有人了。

为什么不能？道理很直白：既然乙已经丧失占有，那即使法院判决乙应当返还原物，这个判决他也履行不了。判决都无法履行，就没有向他主张的必要。

#### 排除妨害请求权

民法典第236条：**妨害物权的，权利人可以请求排除妨害。**

和返还原物不同，这里物**并没有被侵占**，只是行使受到了影响。什么叫"物权被妨害"？指的是以侵占以外的不法方式，使得物权行使的可能性受到影响。物被侵占了，用返还原物；物没被侵占但行使受到了影响，这个就叫物权被妨害了。

很好理解：甲去饭店吃饭，把车停在饭店门口，吃完饭出来发现车前面停了一辆车，挡住了去路，车开不走了。尽管这个车还在自己的占有之下，但因为前面停了一辆车，使得车没法正常使用了——这时候就可以要求对方挪车。要求挪车就是在主张排除妨害请求权。

这种妨害还有一种形态容易被忽略：**登记簿上出现了错误的登记**。我们在前面讲机动车登记的时候提过：一辆车先卖给了乙、完成了交付，后来又卖给了丙、完成了登记手续。乙虽然完成了交付，但车登记在丙名下，这不就使得乙的物权的实现遇到了障碍吗？所以乙可以请求丙配合办理变更登记的手续——这同样是排除妨害请求权。

主张排除妨害请求权，条件有四个。

**条件一：请求人首先是物权人。** 排除妨害也是物权请求权，得是物权才可以行使。

**条件二：前提是物权被妨害。** 也就是上面说的，侵占以外的不法方式导致行使可能性受到影响。

**条件三：相对方既可以是行为妨害人，也可以是状态妨害人。** 这一条讲的是相对人的要求，分两类。一方面，谁实施了妨害的行为，那我就找谁主张；另一方面，虽然你没有实施妨害行为，但**你对妨害的状态有除去的能力的**，我也可以找你主张。

看教材里这个小例子：甲将其住宅出租给乙，双方订立租赁合同；乙违法从事 KTV 经营，天天鬼哭狼嚎，导致隔壁邻居丙生活的安宁受到严重影响。丙的房子有没有被别人侵占？没有。只是隔壁天天鬼哭狼嚎，使得丙在这个房子里居住遇到了障碍，丙的物权行使受到了妨碍，这时候他可以请求排除妨害。

关键来了，丙找谁主张？

```text
    丙的住宅安宁受到了妨害      
                              │
                ┌───────────┴─┐
                  行为妨害人    状态妨害人                       
          亲手实施了妨害行为    自己没动手                       
     ＝违法开 KTV 的承租人乙    但房子是你的，                 
        乱子是他自己搞出来的    对妨害状态有除去能力            
                            │   │
                └───────────┬───┘
                              ▼
      丙找乙行，找甲也行       
   最大限度地保障物权的利益    
```

- 找**乙**可以。乙是实施妨害行为的人，这叫**行为妨害人**——你闯的祸，我当然可以找你来请求排除妨害，让你停止经营；
- 找**甲**也可以。甲虽然没有实施这个妨害行为，但房子是你家的，你的住宅都租给别人去从事经营活动了，你对这种状态是有除去能力的，这叫**状态妨害人**。

对丙来说，乙能找，甲也能找——这是在最大限度地保障物权的利益。

**条件四：这个妨害要具有不法性。** 假如别人对你的物形成的妨碍是具有正当理由的，那就不能主张排除妨害了。

我们在总则编学过**自助行为**，还记得吧——吃霸王餐不给钱、坐公交车不投币，这叫自助行为。

看这个例子：甲驾车前往乙酒店就餐，用餐完毕以后甲乙大醉，且以未带钱包为由拒付餐费。酒店的经理就指挥服务员，把酒店的接待用车停放在甲的车前，以阻止甲驾车离去。这时候甲汽车的正常行驶受到了妨碍，车开不走了。他能不能请求别人排除妨害？**不能**。因为别人不让你走，是在行使自助行为——人家的合法权益受到侵害了，如果不采取措施的话，将使得合法权益受到难以弥补的损害。这时候他采取限制你车离去的措施，是一个正当的行为。既然这个妨碍不具有不法性，你就没有资格请求别人来挪车。

#### 消除危险请求权

物权请求权里紧跟着排除妨害的还有一种，规定在民法典第236条：因可能妨害物权的，权利人可以请求消除危险。

它发挥的是一个**预防的功能**。虽然现在还没有妨害，但如果将来有可能妨害，就可以提前提出措施，把这个危险消除掉。

但这里有个门槛：这个危险必须是**有可能出现的危险**，不能是杞人忧天。

看两个小例子。第一个：甲、乙是邻居，甲要在贴近乙房屋后墙的地方打一口水井。尽管现在这口井还没打，但按照社会一般观念，这口井一旦打下去，有可能使得乙的房屋面临倒塌的危险。所以在甲开始打这个水井**之前**，乙就可以请求甲来消除这个危险——打井可以，你换个地方。

第二个：甲公布了自己的建设规划图，假设按照这个规划建起房屋来，会完全挡住乙房屋的采光，这就是有可能发生的危险。这时候乙可以提前请求甲来消除这个危险。

防患于未然——这就是这套制度背后的价值观。

### 恢复原状请求权：它到底算不算物权请求权

物权保护编里再往下的一条，即民法典第237条：造成不动产或者动产毁损的，权利人可以请求修理、重作、更换或者恢复原状。

很好理解：甲不小心把乙的车给撞了，别人的动产发生了毁损，这时候乙可以请求甲来修车，恢复到这个车受损之前的现状，这叫恢复原状请求权。

但这里有一个**理论拓展问题**：恢复原状请求权，是不是一个独立的物权请求权？实际上这个问题是**存在争议**的。

- 马工程教材认为，恢复原状请求权也是一项独立的物权请求权；
- 法硕官方教材（考试分析）认为，它不是独立的物权请求权。

我们这个教材采的是法硕官方教材、也就是考试分析的观点：**物权请求权主要是前面那三项**，返还原物、排除妨害、消除危险；而恢复原状请求权，主要是**债权性质的请求措施**。

这个定性不是学术洁癖，它有直接的法律后果：

| 请求权 | 性质 | 诉讼时效 |
| --- | --- | --- |
| 返还原物 | 物权请求权 | 原则上不受诉讼时效限制 |
| 排除妨害 | 物权请求权 | 不受诉讼时效限制 |
| 消除危险 | 物权请求权 | 不受诉讼时效限制 |
| 恢复原状 | 债权性质的请求措施 | 要受到诉讼时效的限制 |

> **易错点**：物权请求权原则上不受诉讼时效限制，但**有一个例外**——**未登记动产**主张返还原物，是要受到诉讼时效限制的。除此之外，其他的物权请求权都不受诉讼时效限制。而恢复原状请求权既然是债权性质的请求措施，就得受诉讼时效的限制。

### 侵权损害赔偿：最通用也最兜底的一层

这是各种权利通用的保护方法，物权当然也可以适用：侵害物权造成损害的，要承担损害赔偿责任。

除此之外还有两条经常考的。

第一，**当事人承担损害赔偿责任，不影响其承担其他民事责任**。比如物权请求权跟损害赔偿，侵权能不能一并主张？当然可以。甚至因为侵犯物权产生了民事责任，承担民事责任以后，要不要承担刑事或者行政责任？当然有——这叫**民事责任的独立性**。

第二，**责任人的财产不足以承担全部责任的，要先承担民事责任**——这叫**民事责任的优先性**。

到这里，物权的保护制度就齐了。

第一章物权通则讲完了，这一章讲的是**物权领域的基础理论**以及**各种物权的共性规则**。这一章的考点分成两个层次，我们回顾一下。

**第一个层次，基础理论，主要是前两节。**

第一节讲概述，主要是物权的三要素——主体、客体、内容中的基础理论。特别地，把物权的效力也就是内容做了一个展开，包括优先效力、追及效力，同时还讲了物权的分类。

第二节讲的也是理论问题：物权法的基本原则，体现的是物权领域最核心的价值观，分别是**平等保护物权客体原则**、**特定物权法定原则**以及**公示公信原则**。

**第二个层次，各项物权的共性规则**，是通过提取公因式的方式而形成的一般性的规定，重点讲了**物权变动**和**物权保护**这两个方面。

- **第三节讲物权变动**。这里区分了两种类型来给大家讲共性的规则。一种是**基于民事法律行为而发生的物权变动**，主要是物权变动模式的问题：要发生物权变动，除了要有一个有效的、有权处分的合同以外，还要完成法定的公示方式。公示方式这块，动产的是交付，不动产的是完成登记。动产的交付既包括现实交付，也包括**观念交付**形态；不动产的登记我们在**第四节**做了专门的展开，除了物权变动登记以外，还包括一些特殊的登记制度，像**更正登记、异议登记和预告登记**。另一种是**非基于民事法律行为的物权变动**，这种就不需要公示了，直接按照法律规定就可以取得物权，包括因生效文书发生的物权变动、因继承发生的物权变动，以及基于事实行为发生的物权变动。
- **第五节讲物权的保护**，就是我们刚讲的，分三个层次：第一层是通用的保护规则，侵权损害赔偿；第二层是物权请求权，包括返还原物、排除妨害、消除危险三种；第三层是物权特有的保护制度，一个是恢复原状，一个是确认物权请求权。

### 本讲提到的题目

#### 二〇一三年多选：古琴、油画与电脑

甲出国前，将古琴、油画、电脑交给他保管（甲、乙之间是一个保管合同）。乙将古琴**出借**给了丙，将油画**赠与**给了丁，将电脑**出质**给了戊。甲回国以后发现了以上事实。下列说法正确的是（多选）：

- A. 甲可以请求丙返还古琴
- B. 甲可以请求丁返还油画
- C. 甲可以请求戊返还电脑
- D. 甲可以请求乙承担违约责任

> **答案**：ABD。

**A 项正确。** 甲把古琴交给乙保管，**不发生物权变动**；乙把古琴借给丙，丙不能取得物权。再看丙是不是现实的无权占有人——是的，因为乙借古琴给丙并没有经过甲的同意，所以丙的占有并不能对抗甲，在甲面前丙依然是无权占有人。两个要件都齐了。

**B 项正确。** 甲把油画交给乙保管，而乙却赠与给了丁，丁能不能取得所有权？不能。因为乙是无权处分，而丁是**无偿取得**，不符合善意取得的构成要件。这意味着甲依然是物权人。而丁呢，当然是现实的无权占有人，因为乙赠与丁也没有经过甲的同意。两个要件同样都齐了。

**C 项错误。** 甲是不是物权人？是的，尽管乙把电脑出质给了戊，并不会使得甲的所有权消灭，他依然是物权人。问题出在第二个要件上：戊**不是**现实的无权占有人。尽管乙出质给戊是无权处分，但戊可以通过**善意取得**的途径来取得动产质权（这一点我们在讲质权的时候也会提到，质权是可以善意取得的）。戊取得动产质权以后，因为质权也是物权，设立物权就可以对抗不特定的多数人，所以他可以对抗包括甲在内的不特定多数人。这意味着戊占有这个电脑就不是无权占有了，属于**有权占有**。所以甲无权请求戊返还电脑。

**D 项正确。** 乙违反了保管合同的义务，要承担违约责任。

> **易错点**：这道题最容易栽跟头的就是 C 项。别忘了**动产质权是可以善意取得的**——出质人即使是无权处分，质权人仍可能取得质权。而一旦质权设立，质权人的占有就是有权占有，原所有权人就再也主张不了原物返还。

#### 二〇一五年多选：别墅加高与邻居的采光

甲、乙约定，甲租住乙的别墅十五年。租赁期间，甲将房屋加高，使邻居丙的房屋采光受到严重影响。对此，丙可以提出什么主张（多选）？

- A. 丙可以请求甲排除妨碍
- B. 丙可以请求乙排除妨害
- C. 错误
- D. 丙可以以侵害建筑物区分所有权为由请求排除妨害

> **答案**：AB。

**A 项正确。** 房屋的采光受到了影响，这当然也是被妨害的一种情形。而甲擅自把房屋加高，是实施妨害行为的人，所以丙可以请求甲排除妨害。

**B 项正确。** 尽管乙没有实施妨害行为，但房子是乙的，乙对这个妨碍状态是有除去的能力的，这叫**状态妨害人**，所以 B 项也对。

**D 项错误。** 丙固然可以请求排除妨害，但不是"因为乙侵犯了甲的建筑物区分所有权"。建筑物区分所有权通常适用于**一个建筑里面有多套房屋**的情形，而本题中乙的房子是别墅，他跟丙的房子并不在一个建筑当中，所以这里并不涉及建筑物区分所有权的问题。

> **提示**：AB 两个选项在表述上其实还有个小瑕疵——它们讲的是"以**侵害了相邻权**为由"来请求排除妨害。我们民法典里面并没有"相邻权"这样一个概念，它并不像民事权利那样的独立权利。我国民法典规定的是**相邻关系**，就是在相邻的不动产权利人之间产生的关系，一方权利得以扩张，另一方权利受到限制。所以严格说起来，不存在一项独立的"相邻权"，这个说法不太严谨。
