## 民事法律行为：概念、特征与九种分类
> 对应块：BLK25 | 覆盖分集：P25 | 块标题（分集名）：《第01编 第06章 第01节：民事法律行为概述》

三类民事主体制度学完之后，我们正式进入民事法律关系的变动板块。这个板块要用三章的篇幅，依次介绍三种比较重要的民事法律事实——民事法律行为、代理、诉讼时效。

先看第六章，民事法律行为。

> **注意**：这一章从考试角度来讲非常重要，是每年一定会考的板块。主观题、客观题考点都非常多，大家必须高度重视。

### 这一章的格局，以及两个关键提醒

在进入考点之前，有两个观念层面的问题必须先摆清楚，否则后面会一直别扭。

第一个，**民事法律行为不是一个生活概念**。它是通过"提取公因式"的方式形成的抽象概念——你把千千万万种具体的、各不相同的表意行为归纳起来，抽掉它们的个别差异，剩下的那个共同骨架，才叫民事法律行为。这也正是"民法博大精深"、民法典总则编之所以能成立的理论基础。所以大家民法学得如何，民事法律行为这一部分是非常重要的试金石。

第二个，这里讲的是**各种具体民事法律行为的一般理论以及共性规则**。它在民法典的各分编都有适用余地，但道理是反过来的：得先有一般规定，才谈得上学分编的具体制度。

这也意味着，非法学的同学、包括法学专业基础比较薄弱的同学，在第一轮学习的时候一定会遇到一些困难。我希望你们一定要坚持下去——等你后面把分则学完，第二轮回过头再看这部分内容，好多问题都会迎刃而解。

#### 两个层次，一张逻辑导图

这一章内容非常多，总共有七节，所以先掌握整体框架。这章的问题分两个层次展开：

```text
第六章 民事法律行为（共七节）
│
├─ 理论层（第1节）
│    概念 · 特征 · 分类
│
└─ 规范层（第2~7节）
     │
     ├─ 成立：有没有？（第2节）
     │    一般要件 + 特别要件
     │    核心要件——意思表示
     │
     └─ 生效：法律上如何评价？（第3~7节）
          ├─ 一般要件 → 有效 / 可撤销 / 效力未定 / 无效
          └─ 特别要件
               ├─ 约定的：附条件、附期限（第7节）
               └─ 法定的：审批手续（主要在合同领域）
```

层次一是我们今天要解决的**理论问题**：概念、特征、分类。层次二是学习的重点——**规范问题**，而且规范问题分两步走。

第一步，先确定"有没有一个民事法律行为"，这叫**成立**。成立既要符合一般要件，也要符合特别要件，而这里面的核心要件是**意思表示**。我们在前面讲民事法律事实类型的时候讲过，民事法律行为的概念是以意思表示为核心的，必须包含一个"我愿意"在里面。判断民事法律行为是否成立，意思表示是最重要的问题。

第二步，有了民事法律行为之后，再确定法律上如何评价它，这就是**生效**。基于它是否符合一般要件，会产生四种可能的评价：

| 效力形态 | 含义 |
| --- | --- |
| 有效 | 完全被法律所认可 |
| 可撤销 | 原则上有效，但有被撤销的可能性 |
| 效力未定 | 效力处于不确定状态，需要相关权利人的决定才能确定 |
| 无效 | 相当于被法律给否定了，直接打不及格 |

另外，有些民事法律行为光符合一般要件还不够，还得符合特别要件才能发生效力。这个特别要件既包括**约定的特别要件**（附条件或者附期限，行为能不能生效取决于将来确定发生或者不发生的不确定事实），也包括**法定的特别要件**（主要在合同领域，有些合同需要办理审批手续才能发生效力）。

#### 七节是怎么铺的

对着这张图，目录就清楚了：第1节讲的是理论问题，也就是我们现在站的这一节；第2节讲成立当中意思表示的相关问题；从第3节开始进入生效的规范；四种效力形态分别在第3、4、5、6节展开；特别要件里约定的部分——附条件或附期限的民事法律行为——放在第7节；法定的特别要件因为主要在合同里才展开，我们放到合同编再讲。

### 概念与特征

这一节要解决的第一个问题，就是民事法律行为的概念和特征。

#### 三个关键词把概念搭起来

概念我们前面讲过：**民事主体通过意思表示来设立、变更、终止民事法律关系的行为**。它必须包含一个意思表示，必须包含一个"我愿意"的成分在里面——像签合同、结婚、设立遗嘱、收养等等，如果没有"我愿意"这个因素，那是不可能成立的。

从法律角度描述这个概念，需要关注三个方面的关键词。

第一个关键词是**民事主体**。因为民事法律行为首先是一个行为，而行为得以受主体意志支配为前提，所以它必须得有主体，才可能由主体意志支配。相比之下，自然事实就和主体的意志无关，所以它不需要非得有主体。

第二个关键词是**意思表示**。这一点是民事法律行为和事实行为最大的区别，它必须包含一个"我愿意"的成分在里面。

第三个关键词是**内容**。民事法律行为毕竟是一种民事法律事实，所以必须包含一个导致民事法律关系发生变动的内容。

三个关键词连起来就是它的概念。**"主体—意思表示—内容"**这个表达逻辑大家一定要有印象，后面背诵和学习民事法律行为的相关内容时会反复用到。

#### 合法性：从必需要件到被删除

这里有个教材里的理论拓展问题：涉及民事法律行为的概念时，要不要包含"合法性"这样一个要素？

实际情况是，在1986年的《民法通则》中明确规定，民事法律行为必须是合法行为，不合法就不能构成民事法律行为，这是当时的要求。但是制定民法典的时候，把这个要件删掉了。这意味着在民法典的背景下，我们认定民事法律行为的时候**不再考虑合不合法的问题**——即使是不合法的行为，只要符合主体、意思表示、内容这三个要求，它也是民事法律行为的范畴。

打个比方大家就能理解这个意思：人是有好坏之分的，有好人也有坏人，有人自认为是好人，有人时好时坏，有的好坏不明——但不管是好人也好、坏人也好，他都是人。民事法律行为也是一样，有合法的、有不合法的，但即使是不合法的，它也是一个民事法律行为。

> **易错点**：这个变化大家一定要注意。效力有瑕疵、甚至根本无效，不影响"它是一个民事法律行为"这个定性；两件事要分开。

来看一个小例子。小学生甲以2000块钱的价格，把他的手机卖给了同班同学乙，我们来判断这是不是一个民事法律行为。

前面讲过，小学生甲肯定是限制或者无民事行为能力的，他有没有以2000块钱卖手机的民事行为能力？那肯定是没有的，所以这个行为的**效力**是肯定存在瑕疵的。

但这影不影响它是一个民事法律行为？不影响。因为一方面有主体——小孩也是主体；同时有**意思表示**——甲确实希望把这个手机卖给乙；同时有**内容**——会导致债权债务关系的产生。所以甲乙签订的合同，也是法律上的民事法律行为，尽管它的效力存在瑕疵，不一定是合法有效的，但允许我们首先把它看成一个民事法律行为。

#### 意思表示是必要条件，但远不是充分条件

第一个特征：**民事法律行为以意思表示为基本要素**。这一点就和事实行为存在核心区别了。

什么叫意思表示？这也是一个专业术语，我们在本章第2节会用一整节的篇幅讲意思表示的基本理论，这里只简单强调概念：**民事主体将设立、变更、消灭一定民事法律关系的内在意思，通过一定的方式表达于外部的行为**。

回到刚才的例子，甲跟乙说"我这个手机2000块钱卖给你如何呀"——这就是一个意思表示，它既希望成立一个法律关系，又表达于外部了。

那意思表示能不能等于民事法律行为？**当然不能。**意思表示只是民事法律行为当中的一个要素。举两个例子。

第一个例子是双方民事法律行为，比如合同。甲跟乙说"我这个手机2000块钱卖给你，你看如何"，这是一个意思表示，民法上把它称为**要约**（我们在合同编会讲）。尽管有甲的这份要约，合同这个民事法律行为成立了吗？没有，它需要乙表示同意。乙说"没问题"，这个意思表示我们称之为**承诺**，这两个意思表示达成一致了，才能形成一个民事法律行为，也就是合同——你愿买、我愿卖，达成一致才能成立合同。光有"我愿意卖"或者"我愿意买"的意思表示，不能形成民事法律行为。所以意思表示只是合同当中的一个成立要素。

第二个例子更典型。有些民事法律行为，不仅要求双方意思表示达成一致，还要求交付标的物。按照民法典的规定，保管合同就是**实践合同**。甲要出国，宠物狗没人照看，于是他找到好朋友乙说"我这个宠物狗能不能帮我保管，希望跟对方订立一个保管合同"——这是一个意思表示，也是一个要约。假设乙说"没问题"，这是承诺，双方意思表示是达成一致的了。但这个时候，保管合同这个民事法律行为成立了吗？没有。按照法律规定，还需要交付标的物；什么时候甲把这个宠物狗真的交到乙的手里了，双方之间才会形成一个保管合同。

```text
没有意思表示  ──────▶  ✗  民事法律行为不成立
                        （必要条件）

有了意思表示  ──────▶  ?  未必成立
                        （不充分条件）
                        │
                        ├─ 双方行为：还要双方意思表示达成一致
                        ├─ 诺成行为：意思表示一致即可成立
                        └─ 实践行为：意思表示一致 + 交付标的物
```

所以结论很明确：**没有意思表示，民事法律行为不能成立**；但有了意思表示，民事法律行为不一定就能成立。意思表示是民事法律行为的**必要但不充分条件**。

> **提示**："必要但不充分"这五个字建议好好理解一下逻辑学，这是后面大量判断题的底层工具。

#### 目的要素：与情谊行为、事实行为的界分

第二个特征：**民事法律行为以设立、变更、终止民事法律关系为目的**。这里强调的是它的"内容"——它毕竟是民事法律事实，要包含一个导致民事法律关系发生变动的内容，而且这个变动体现的是当事人的意愿，是他希望发生的。

这里要做两个界分。

第一，跟**情谊行为**区别开来。情谊行为虽然也有意愿表达，但它没有包含一个法律关系发生变动的意思。比如甲跟你说"周末我请你到家里来坐坐，我请你吃大餐"，虽然也有个意愿的表达，但可能只是客气一下，并没有使得双方之间产生一个法律关系的意图，所以它不是民事法律行为。

第二，跟**事实行为**区别开来。事实行为不一定非得包含一个意思表示，不一定包含当时的意愿在里面。比如甲开车不慎把乙给撞了，按照法律规定是不是甲就得赔偿给乙造成的损失？这个法律后果体现的是**法律的意思**，体现的不是甲希望和乙产生一个损害赔偿关系的意图。

所以，这两个特征其实就是概念中"意思表示"和"内容"这两个关键词的展开。

### 九种分类

又见到我们的老朋友——分类。学习不停，分类不止。

实践中民事法律行为可以说是五花八门、多种多样，我们很难指望一个规范能解决所有的问题，所以要分门别类设置不同的规则。从考试角度来讲，一方面需要我们掌握这里涉及的专业术语，另一方面要记几个比较典型的例子。

先看总表，九种分类的标准一目了然：

| 分类 | 区分标准 |
| --- | --- |
| 单方 / 双方 / 多方行为 | 意思表示的数量 |
| 有偿 / 无偿行为 | 是否有对价 |
| 诺成 / 实践行为 | 成立是否已交付标的物或完成其他给付 |
| 要式 / 非要式行为 | 行为成立是否必须依照某种特定形式 |
| 主行为 / 从行为 | 两个民事法律行为之间的相互关系 |
| 财产 / 身份行为 | 法律后果是财产性质还是人身性质 |
| 负担 / 处分行为 | 财产行为的效果是负担义务还是发生权利变动 |
| 有因 / 无因行为 | 原因行为无效是否影响结果行为的效力 |
| 独立 / 辅助行为 | 有没有独立的实质性内容 |

#### 按意思表示的数量：单方、双方、多方

**单方行为**，指仅由一方当时的意思表示就能成立的民事法律行为，一个意思表示就可以成立，一个人就可以说了算。比如订立遗嘱——一个人订立遗嘱的时候，处分遗产需不需要别人同意？不需要，自己就可以做主，所以它是单方行为。抛弃债权、抛弃所有权，也可以单方做主。

要稍微注意的是**形成权的行使**。我们在前面讲权利分类的时候提到过，形成权指的是基于一方意思表示就可以使得双方的法律关系发生变动的权利。这意味着行使形成权的时候，只需要自己决定就可以了，不需要别人的同意，所以它也是一个单方行为。也就是说，在民法当中，形成权的行使都是单方行为。

**双方行为**，指双方意思表示要达成一致才能够成立的民事法律行为。比如合同，一方发出要约、对方作出承诺，你愿买我愿卖，然后才能成立合同。结婚也是一样，一方愿意娶、另一方愿意嫁，双方意思表示达成一致才能够成立，这叫双方行为。

**多方行为**，指多个意思表示达成一致才能够成立的民事法律行为。比如甲乙丙三个人签订合伙合同，决定一起开个公司，合伙合同的当事人有三个，需要达成一致，这叫多方行为。

这三者的区分标准就是意思表示的数量。

最后补充一个问题：**决议行为**。决议也是一种民事法律行为，只不过它不需要意思表示达成一致，它采取的是少数服从多数的原则。比如公司当中有股东会，股东会做出决议的时候，是不是只要过半数股东同意就可以了？不需要全体一致同意，只要少数服从多数就可以。包括在物权编我们会讲业主大会，要也都是决议的话，也不需要全体一致同意，只要符合法律规定的比例的业主同意就可以了。

> **易错点**：决议跟多方行为可不一样。多方行为要求意思表示**达成一致**，决议走的是**比例多数**，这个区别是常考的。

#### 按有无对价：有偿与无偿

一方从对方获得利益的时候，要向对方支付对价的，叫**有偿行为**。比如买卖——你拿别人的东西是要付钱的；包括租赁——你住别人的房子也是要付租金的。这是典型的有偿行为。

一方获得利益的时候无需向对方支付对价的，叫**无偿行为**。比如赠与合同，某个明星给一个基金会捐钱，基金会取得了这个财产，但是不需要向对方支付对价。还有遗赠。

拿遗赠举个例子。老王立下了遗嘱，他死后万贯的家财都留给众合公司，来服务于法硕的培训。众合呢，因为没有法定继承资格，所以它基于老王的遗嘱取得遗产，这属于遗赠。

这里有个点要特别注意。遗赠是无偿行为，而且它是**单方行为**，因为遗赠本质上就是一个遗嘱，只要老王一个人就可以做决定——按照继承法的规定，受遗赠人要在60天内表示接受才可以取得遗产。

但是：受遗赠人的接受，只是取得遗产的**要件**，并不是遗赠这个行为**成立**的要件。即使众合公司拒绝接受这份财产——因为它觉得自己已经够有钱了——那也不影响老王这个遗赠行为本身已经成立。这二者还是要区别开来的。

另外，有些行为可以有偿也可以无偿。比如借钱给别人，约定利息的是有偿的，没有约定利息的可以认定为无偿的；包括委托别人帮自己处理事务，可以拿报酬也可以不拿报酬。

> **结论**：在民法中，凡是无偿的行为，基本上都只对故意和重大过失负责。既然没有从对方手里拿到对价，法律对他要求就不能太高——毕竟他是纯粹付出的一方。

#### 按是否交付：诺成与实践

这是标准的法言法语。区分标准是：民事法律行为的成立是否已交付标的物，或者完成其他给付。

**诺成行为**，只需要意思表示达成一致就可以成立，一诺而成。比如买卖，双方意思表示达成一致的时候买卖合同就可以成立，即使后来没有交付标的物，也不影响买卖合同已经成立了。

**实践行为**就有点个性了：它指该行为的成立除了要求意思表示达成一致以外，还需要交付标的物或者完成特定的给付行为。

从民法角度讲，**诺成行为是原则，实践行为是例外**。民法典里规定了三种实践合同：定金合同、保管合同、自然人之间的借款合同。

保管合同的例子前面举过了。这里讲讲自然人之间的借款。两个自然人在生活当中常常会有资金拆借的行为，那这样的借款合同什么时候成立？一方面需要双方意思表示达成一致——你想借别人的钱，别人也愿意把钱借给你；同时还需要出借方实际交付这个金钱。如果达成一致了但没有交付金钱，那借款合同是不能成立的。这是自然人之间借款合同的一个特殊性。

来看一个例子。

陈某为了买别墅，邀请好友老马来吃饭，并希望借他100万。因为老马是吃货嘛，你请他吃饭，基本上找他帮什么忙他都可以答应。在吃饭的时候，陈某提出能不能借我100万。马某呢也是要脸的人——你正吃着别人的饭呢，怎么好意思拒绝？于是当场表示同意。那陈某也是有备而来，直接从口袋里面掏出了已经写好的借款合同，说直接签字就可以了，老马顺势也在合同上签了字。

同时，陈某又向众合公司借200万，因为光老马的100万不够。众合的老板当即也表示同意，双方也签订了借款合同。陈某觉得这事摆平了。

但是后来，老马回家跟他老婆商量，他老婆觉得陈某这个人不太靠谱，这个钱借出去的话那就打水漂了，无论如何不能借。老马没办法，就跟陈某说："兄弟不好意思，虽然我想借给你这个钱，但我们家的事我做不了主，我老婆不同意借。"陈某很生气，说："你这个废物啊，100万你都决定不了。"

在这个案例当中，陈某能不能追究马某的违约责任呢？饭都吃了，合同也签了，怎么能够说话不算话？

**不能。**因为双方都是自然人，所以这个借款合同是一个实践合同，要成立一方面双方意思表示要达成一致，同时还需要实际交付这个金钱。尽管双方签了书面合同，但马某有没有把这个钱交到陈某的手中？没有。那意味着这样一个实践合同根本就没有成立。既然合同没有成立，那马某当然不需要承担违约责任。

后来呢，众合公司知道马某不借钱给陈某——你们关系那么好你都不借，那陈某肯定不靠谱——于是众合公司的老板也通知陈某："公司最近资金紧张，也没法借这个钱给你了。"陈某也很生气，要求众合公司承担违约责任。

**这个主张能成立。**因为出借方众合公司是一个公司，它不是自然人，所以这个合同就不是自然人之间的借款，那意味着它只能是一个诺成合同，只要双方当事人意思表示达成一致，合同就可以成立。既然双方签订了书面的合同，那意味着借款合同已经成立并生效。众合公司现在要拒绝提供借款，是要承担相应责任的。

所以大家看，虽然都是借钱，但如果双方都是自然人，这个合同需要以交付借款作为成立要件，因为它是实践行为；但如果一方当事人不是自然人，它就变成诺成合同了，只要双方意思表示达成一致合同就可以成立。

有些同学会问，为什么要做这样的区分呢？都是借钱啊。大家考虑四个字，叫做**人情世故**。

在生活当中，自然人之间的借款常常有相互帮忙的功能。有时候对方张了口，你虽然心里面不太愿意借这个钱，毕竟借出去是有风险的，但是有的时候为了面子上能够过得去，可能嘴上会答应，甚至在对方的要求下还不得不签个字据，因为架在这里了嘛。但是假如一答应或者一签字据就必须要把钱借出去，是不是也不符合生活的常理？人家没有把这个钱借给你，就代表着当初只是跟你客气一下，他还是符合我们的生活常理的。这样的话，就给了当时一个台阶下，给了他一个反悔的机会。不要因为吃了别人的饭、不好意思答应了，就必须要兑现——那对当事人讲也是不公平的。这就是法律设置实践行为这样一个制度的意义所在，体现的是人情世故。

但是如果一方当时是公司的话，那就不一样了。公司从事的是经营行为，别人跟你打交道的时候，很难相信你只是客气一下而已。所以意思表示达成一致合同就可以成立。

#### 按形式要件：要式与非要式

区分标准是：行为的成立是否必须依照某种特定形式。必须以某种特定形式做出来的，叫**要式行为**；不需要特定形式、用什么形式当时由你自己决定的，叫**非要式行为**。

从民法角度讲，不要求形式是原则，要求形式是例外。既然民法要尊重当事人的意思自治，那这个民事法律行为到底通过什么方式做出，应当让当事人自己决定。所以非要式行为是原则，要式行为是例外。

有些特殊的行为需要点仪式感。举几个例子。

比如说结婚。甲向乙求婚，乙已经同意了，双方能不能成为夫妻？不能，必须要办理结婚登记才能够成为夫妻。也就是你同意和对方结婚的意思，要通过办理登记的方式来做出，才能够发生结婚的效力，因为它涉及到身份的变动，所以要慎重一点，得有点仪式感。

包括遗嘱，它也是要式行为，必须要符合法律规定的形式要件。否则的话这个人死了死无对证，到底是不是他真实的意思都说不清楚了，所以要符合法律规定的形式要件来确保是你的真实意思。

包括在实践中一些比较重要的商事交易，常常要求通过书面形式来订立。比如说建设工程合同，标的额比较大，履行周期也非常长，按照法律规定它应当采用书面形式来订立；包括商品房买卖合同，价值比较大，对当事人来讲是重大的交易，通过书面形式订立合同是不是显得慎重一些？而且发生纠纷的时候也容易找到证据。

但是如果法律没有做出明确规定的，那原则上这个行为就是非要式行为。

#### 按彼此关系：主行为与从行为

区分标准是两个民事法律行为之间的相互关系。注意这里涉及的是**两个**行为。

不需要其他行为存在为前提的，叫**主行为**，自己能够独立自主。从行为则指要从属于主行为的民事法律行为，它具有从属性，要附属于其他的行为。

在民法里面，**担保合同**是非常典型的从行为。比如甲去买房，钱不够，付了首付以后要找银行贷款，这个场景非常熟悉。银行借钱给这个买房人，双方之间会有一个债权债务关系，这是主合同，可以独立成立。为了担保这个债权的实现，甲就把自己的房子抵押给了银行，双方签订了抵押合同。这个抵押合同是为了给这个主债权设定一个担保，所以它是具有从属性的，要从属于这个主债权债务合同。

这意味着什么呢？如果甲买彩票中奖了，拿到一大笔钱，一次性把欠银行的钱都还清了，是不是意味着主合同归于消灭了，因为履行完毕了？那这时即使这个抵押合同没有办理解除手续、没有办理抵押权的注销登记，这个抵押合同也会随之失去效力。**皮之不存，毛将焉附**——这就是从行为的特点。

#### 按变动对象：财产行为与身份行为

区分标准是民事法律行为所发生的法律后果是财产性质还是人身性质。如果财产关系发生变动，叫**财产行为**；如果身份关系发生变动，叫**身份行为**。

财产行为比如：甲乙签订买卖合同，在他们之间形成一个债权债务关系，这是纯粹的财产问题；甲抛弃所有权，把家里的东西扔掉，只涉及财产的变动，只是使得自己丧失这个所有权；债权人免除债务，主要也是财产上的后果。

身份行为比如：甲乙结婚会形成夫妻关系，然后甲乙协议离婚会导致夫妻关系消灭；当事人签订收养协议、办理登记，会形成一个养父母与养子女的关系。这些都是身份关系的变动，叫身份行为。

#### 财产行为的进一步区分：负担行为与处分行为

这部分是难点，而且我要先说清楚：**它是一个纯粹的理论问题**。它讲的是什么，没必要用它来分析我国现行民法典的规定，因为我国民法典没有采纳这样的概念或者分类。

有些同学会问，民法典都没采纳，为什么我们还要学？因为**法硕考试大纲有它这个考点**，所以大家得学。实际上接下来我们讲的剩下三种分类，连马工程教材里面都没有，所以在有些理论问题上，考试分析还是想"卷一卷"的。

区分标准是：以财产行为发生的效果是**负担义务**还是发生**权利变动**来区分。所以负担行为和处分行为是**财产行为的进一步区分**，这一点要特别注意。

这意味着：甲和乙签订了一个离婚协议、双方和平分手，请问这是负担行为还是处分行为？答案是**都不是**——因为签订离婚协议是身份行为，而负担行为和处分行为是财产行为的进一步区分，它跟身份行为是**并列关系**，不是一个包含关系。

那什么是负担行为？如果只是产生债权债务关系，我们称之为负担行为；如果直接导致权利发生了变动，这样的行为我们叫处分行为。

举一个生活当中非常简单的例子，就是买房。甲和乙签订买卖合同，甲要把自己的房子卖给乙。双方签订的这份买卖合同，后果是什么？是在甲乙之间产生了一个债权债务关系——甲有义务把房子所有权转移给乙，乙有义务把价款支付给甲。签订合同的后果是产生了一个债权债务关系，所以这样的行为叫**负担行为**，也叫债权行为，因为它产生的是债权债务关系。

那签订合同以后呢？甲后来就把那个房子过户登记到了乙的名下，双方办了个过户。办理登记这个行为，会使得房子的所有权从甲的手中转移到乙的手中，发生了权利变动——这个登记的行为就称为**处分行为**。

```text
签买卖合同  ──▶  负担行为（债权行为）：在甲乙之间产生债权债务关系
                  甲有义务转移所有权 / 乙有义务支付价款

办理过户登记  ──▶  处分行为：直接引起权利变动
                  ├─ 物权变动    ──▶  物权行为
                  └─ 其他权利变动 ──▶  准物权行为
```

注意这两种行为不要混了：一个是"签了一个合同"，一个是"要发生权利的变动"。比如办理登记会导致房屋所有权的变动，这样的行为才叫处分行为。

处分行为还要做一个进一步的区分：如果它导致的是**物权**发生变动，就叫**物权行为**；如果发生的是其他权利的变动，就叫**准物权行为**。大家看，又看到这个"准"字了。比如甲持有某公司的股权，然后又和乙签订了股权转让合同。双方签的股权转让合同是不是产生一个债权债务关系？是的，甲负有把股权转移给乙的义务，乙负有支付对价的义务，所以这个合同是个负担行为。但是后来甲把这个股权转移登记到了乙的名下、去工商部门办了股权的转移登记，这个登记行为会使得股权这种权利直接发生变动，它叫**准物权行为**。

大家可能会问，我们国家为什么没有采纳这样的分类？实际上这两种行为的区分，多少有点脱离我们的生活常理。你想，甲乙签订一个买卖合同，后来甲配合乙去办理过户登记手续，在我们生活当中这是一个交易，它不应该是两个交易——甲会平白无故地把这个房子过户到乙的名下吗？不会的，他是在履行前面这个买卖合同。所以从生活角度来讲，这两个行为事实上是一个完整的交易，没有必要把它们割裂成两个独立的民事法律行为。这是我们国家没有采纳这个理论的一个最根本的原因：**这个理论把一个简单的生活问题给它复杂化了。**

那我们国家怎么评价这两个问题呢？我们国家事实上区分的是**合同的效力和物权变动的效力**。甲乙签订买卖合同的时候，我国民法典认为要判断他们的合同效力如何；有没有办登记，主要决定物权有没有发生变动，要看物权变动的结果有没有发生。所以我们区分的是合同的效力和物权变动的结果，**我们不区分负担行为和处分行为**。

这里补一个我之前特意没讲、因为当时讲你们肯定也听不懂的点。在教材第39页讲民事法律事实的类型时，在事实行为部分，也就是第二点，最后一句话说"作为债权标的的给付行为，如交货、付款，属于事实行为"。大家看到这句话了吧——在我国民法当中，履行合同的行为，像办理登记手续、交付标的物、支付价款等等，并不是一个独立的民事法律行为，它只是一个事实行为而已。所以官方教材、考试分析实际上也没有采纳负担行为和处分行为的区分，他并没有把办理登记的行为当成一个独立的物权行为来对待，而是把它当成一个事实行为，只要完成了就可以发生物权变动的结果。

还是那句话：这一组概念主要是个理论层面的东西，大家能够从理论层面搞清楚什么叫负担行为、什么叫处分行为就可以了，它跟我国民法典的规范实际上还是有一些距离的。

#### 原因与结果：有因行为与无因行为

这个就更抽象了，同样主要是理论层面的概念。而且它是从负担行为和处分行为的区分当中延伸出来的。

区分标准是**民事法律行为和它的原因行为的关系**。这里要注意一个很有意思的点：它讲的**不是"这个行为有没有原因"**，而是"**原因行为如果无效了，会不会影响这个处分行为的效力**"——是从这个角度来讲的。

先补个背景。民法里面如果要区分负担行为和处分行为的话，那负担行为明显是处分行为的原因行为。甲为什么要把自己的房子过户到乙的名下？原因在于甲和乙签订了一个买卖合同。所以前面的负担行为会成为后面处分行为的原因行为。

那么**有因行为**：如果原因行为无效了，作为结果的那个行为也会随之无效。举个例子，如果我们认定甲乙签订的买卖合同无效了，但实际上当时已经办完登记手续了，那乙能不能取得房屋的所有权？如果作为处分行为的物权行为也无效，那就说明这样一串行为是**有因行为**——作为结果的这个行为，它的效力要受到原因行为的影响，二者是**荣辱与共**的，一荣俱荣、一损俱损，是密切相关的。

**无因行为**则相反：假如甲乙签订的买卖合同被认定无效，如果它不影响后面这个物权行为的效力，也就是登记的物权行为依然有效、依然可以取得所有权，那这样的行为就叫无因行为。也就是甲乙之间的物权行为效力不受原因行为瑕疵的影响，二者是相互独立的、各自为政的、互不影响的。

```text
原因行为 = 负担行为（买卖合同）
结果行为 = 处分行为（物权行为：登记；票据行为：出票）

有因行为：原因无效  →  结果也无效      （我国主流）
无因行为：原因无效  →  结果依然有效    （德国民法；我国票据行为）
```

在**德国民法**当中，认定负担行为和处分行为是区分的，主要是为了强调二者的无因性——前面的负担行为无效了，不会导致处分行为也无效，否则你把它们区分开就没有意义了。所以德国民法一方面把负担行为和处分行为区别开来，把它们当成两个行为来看；另一方面强调它的无因性，效力判断也是相互独立的。即使前面的、作为原因的负担行为被认定无效了，也不会影响作为结果的物权行为的效力。德国民法不仅认可物权行为的独立性，也认可物权行为的无因性。

但是要强调：**我国民法没有采纳德国民法这一套。**我们要强调制度自信、理论自信，不能说外国的月亮就比中国圆，他们的东西我们不一定要借鉴。这意味着在我们国家的法律体系中，我们区分的不是负担行为和处分行为的效力关系，我们区分的是**合同的效力和物权变动之间的关系**——合同被认定无效了，会不会影响物权变动的结果。在我国民法当中，有因无因就是从这个角度来讲的。

我国的主流观点认为，我们主要采的是**有因**观点。这意味着在我们现行民法典当中，如果双方签订的买卖合同被认定无效，即使办理了登记，能不能发生物权变动的结果？答案是**不能**。物权变动结果受到合同效力的影响。

来看例子。**例一**：甲将自己的房屋卖给乙，双方签订了买卖合同，而且办理了登记。后来发现甲乙签订的买卖合同是无效的，判断乙能不能取得房屋的所有权。

- 如果按照我国民法典采有因观点，既然作为原因的买卖合同被认定无效了，那它必然会影响结果，因为二者荣辱与共、密切相关。所以即使办了登记，也不能取得房屋的所有权。
- 如果按照德国民法里面所谓无因性的观点，那意味着甲乙签订的买卖合同作为原因行为虽然被认定无效了，但它不影响作为结果的物权行为的效力，也就是乙依然可以取得房屋的所有权。

有人说这做法太炸裂了吧，合同都无效了，怎么还可以取得所有权？当然，认可这个无因，只是说乙从逻辑上可以取得这个所有权；但是他取得的所有权已经丧失原因了，那意味着乙取得的所有权会构成一个不当得利，他得把这个取得的所有权作为不当得利返还给甲。所以从实质角度来讲，实际上跟我国民法典这个做法没什么本质的区别。但是大家有没有发现，德国民法这个做法把一个相对看起来简单的问题给它复杂化了。所以大家重点是从理论层面来理解这个概念，它只是我们思考的一个工具，不要用它来分析我国现行民法典的规范，否则你会走火入魔的。

那么，我国有没有采纳无因观点的情形呢？有，举个**例二**。

在我国有一种行为叫**票据行为**，它采的就是无因的观点。大家知道什么叫票据吧，我国票据法规定了汇票、本票、支票三种票据。甲公司和乙公司签订了买卖合同，以10万的价格向乙公司订购一批货物。按照这样一个约定，甲公司应当向乙公司支付10万价款。价款可以给现金、可以银行转账，实践中也可以通过票据的方式来进行支付。双方约定这个价款通过银行汇票的方式来支付，于是甲公司给乙公司开出了一张10万元的银行汇票。按照票据法的规定，乙拿这个票据可以到银行去把钱兑出来。

后来，甲公司和乙公司签订的合同被认定无效了，这时候就涉及到一个问题：乙拿到这张汇票，还能不能从银行兑到钱？

- 如果按照**有因**的观点，因为原因行为无效了，那这个作为后果的行为也会无效，乙就没法从银行兑到钱了。
- 如果是**无因**的观点，即使这个买卖合同作为原因而无效了，它也不影响这个票据行为本身的效力，乙依然可以从银行兑得这个钱。

我们国家采取的是第二种观点，认为这个票据行为具有独立性，它的效力不受原因行为效力瑕疵的影响。尽管想想，甲乙要不签订这个买卖合同，是不是也不会给乙开这个银行汇票——这个票据行为的原因行为确实是甲乙之间签订的买卖合同，但现在买卖合同被认定无效了，按无因性的观点，它并不影响这个票据行为的效力，乙拿这个票据依然可以从银行兑到钱。

那么凭什么乙可以拿到这个钱？实际上认定乙能够拿到这个钱，主要是为了**确保这个汇票能够正常流通，保护后续票据权利人的信赖利益**，不是为了让你实质拿到这个钱。因为你看，乙从银行兑得这10万块钱，但他拿这10万块钱，是不是已经丧失法律上的原因了呀？实际上已经构成不当得利了，他得把这10万块钱作为不当得利返还给甲。

那这跟有因有什么区别呢？因为在实践中，乙拿这个汇票以后，不一定直接从银行去兑钱，有可能他在给他的上游供货商付款的时候，就又把这张汇票转让给了丙。可能确认甲乙合同无效的时候，这个票据都不知道转了多少手了。如果说前面这个合同无效，那最终这张票据就作废、从银行取不到钱，是不是影响了票据本身的流通性？也会损害后续这些票据权利人的合法权益。所以我们要基于无因性的观点，让拿着票据的人依然可以从银行兑到钱；但是从乙的角度来讲，他因为没有资格拿这个钱了，构成不当得利，要把这个钱返还给甲。

这是我国民法当中比较少见的采纳无因性观点的问题——**票据行为**。在多数情况下，如果原因行为无效，常常影响这个法律后果的发生。所以我们国家是**以有因为原则，而以无因为例外**。

> **提示**：能感受到这是个理论问题了吧？需要大家能够有这个推导的能力。听不的同学一定要返回去好好听一听，不要倍速，要跟上这个思考的过程。实际上这样的理论问题虽然不能解决实践问题，但可以训练我们的民法思维。

#### 按有无独立内容：独立行为与辅助行为

区分标准是：民事法律行为有没有独立的实质性内容。有，就叫**独立行为**；没有，就叫**辅助行为**。

实际上多数的民事法律行为都是独立行为，都可以独立存在，有它实质的内容，所以大家重点关注辅助行为这个概念。

**辅助行为**指不具有独立内容，而只是辅助其他行为生效的民事法律行为，主要是辅助别人发生效力。

看两个例子。

**例一，独立行为**：大学生甲成绩优异，获得了国家奖学金1万块钱，到华为专卖店购买遥遥领先手机一部，双方签订了买卖合同。这个买卖合同是独立的，因为它有独立的实质的内容，会在甲跟手机店之间形成一个买卖合同关系。

**例二，辅助行为**：尽管听起来有点抽象，但从考试角度来讲，大家一定要记住一个最为典型的例子——**追认行为**。

小学生甲十周岁，因为成绩优异获得了某市科技创新奖以及奖金3万块钱，于是也到华为专卖店买了遥遥领先手机一部，同样和这个手机专卖店签订一个买卖合同。先看这个买卖合同：它是一个独立行为，因为它是有实质的独立的内容的。只是甲呢是限制民事行为能力人，欠缺买手机的民事行为能力，那会使得这个行为的效力存在瑕疵，但这个合同本身是一个独立行为。

在民法里，这样的合同效力我们称之为**效力未定**——它不是直接无效的。到底能不能发生效力，取决于甲的法定代理人有没有追认这个合同。

甲的家长乙觉得，这个手机性能良好，而且自己的孩子这么优秀，配得上遥遥领先的手机，于是他选择**追认**这个合同，说同意了、没问题。追认会使得甲和手机店之间效力未定的合同确定地发生效力。

所以大家看，乙的这个追认，他是在行使一个权利，叫**形成权**——基于一方的意思表示，可以使得当时的法律关系发生变动，这是形成权。而这个追认的行为，它就是典型的**辅助行为**。追认本身是没有独立的实质内容的，它存在的价值是为了辅助甲和手机店的买卖合同能够发生效力，来**补齐这个效力的最后一块拼图**，它发挥的是这个作用，所以叫辅助行为。

最后要区分一下，这里讲的辅助行为跟之前讲的**从行为**是什么关系？注意它们是完全不同的概念。

从行为虽然要从属于主行为、具有从属性，但是从行为它首先自己就是一个独立的行为，它是有独立的实质的内容的。比如当事人签订的抵押合同、保证合同、地役权合同，都是有自己独立的内容的，所以它是独立行为，只是它的效力要从属于主行为。

可以把它理解为一个小弟跟着大哥混：如果大哥赚钱了，这个小弟可以跟着吃肉；如果大哥倒霉了，这个小弟也会跟着遭殃。但尽管有从属的地位，它依然是个独立的存在，它是个独立行为。

而辅助行为是没有独立的实质的内容的。打个比方：大哥出去跟别人抢地盘，给打伤了，需要打个石膏来帮忙恢复——这个辅助行为也只是打了个石膏，它不是一个具有独立意义的存在，只发挥一个辅助的功能。

到这里，民事法律行为的**九种分类**就全部讲完了。单从考试角度来讲，辅助行为大家重点记**追认**这个例子就可以了。

## 意思表示：从一个词到一条完整的规则链
> 对应块：BLK26 | 覆盖分集：P26 | 块标题（分集名）：《第01编 第06章 第02节：意思表示》

意思表示这个词，本身也是个标准的法言法语。但它恰恰是民事法律行为最核心的构成要素——一个民事法律行为之所以能成立，靠的就是有人"表示"了什么。所以这一节我们把它单独立出来讲。

接下来的讲法，我按时间线索走三步：**第一步，这个意思表示是由内而外怎么"做"出来的（作出的形式）；第二步，做出来以后什么时候开始发生效力（生效）；第三步，生效以后怎么来读懂它的内容（解释）**。三个阶段层层递进，前面是后面的前提。

### 意思表示是什么：定义、三个例子与三个特征

#### 概念里的两个关键词

定义很短，就一句话：**民事主体将意欲表达于外部的行为**。这句话里藏着两个关键词。

第一个关键词是"意欲"，也就是**内心**必须有那个意思——希望和对方发生一定法律上效果的意思，希望设立、变更或者终止某种法律关系。

第二个关键词是"表达于外部"，也就是**外在**还得有一个表示行为。光是心里想着不行。

意思加表示，合起来就是意思表示。两个关键词缺一不可：只有内心没有外在表示的，那叫"心里想想"；只有外在动作而没有任何意欲指向的，那只是一项事实行为。

#### 三个例子

概念光看定义容易空，我们看三个例子。

**例一：甲公司向乙公司发出订单**，希望以 1000 块钱的单价来求购某型号的零件 1 万件。甲把希望订立买卖合同的意思，通过发送订单的方式表达于外部，这就是一个意思表示。

**例二：甲生重病已无药可治，深夜手书遗嘱**，承诺将其存款 30 万元捐献给某爱心基金会。甲通过这个遗嘱的方式，表达其捐赠的意思，也是一个意思表示。

**例三：某东网站某米旗舰店出售新款手机**，标注商品详情及其销售价格。旗舰店通过网页展示的方式，表达了一个希望与消费者订立买卖合同的意思——你只要选中商品下单，合同就可以成立。所以这个网页展示的销售信息，它也属于一个要约，同样是意思表示。

三个例子，载体完全不同：订单是数据电文，遗嘱是手书，网页是公开展示。但套进定义里全都对得上：**都有意欲，都表达于外部**。

#### 三个特征

教材上给意思表示列了三个特征，看起来抽象，其实还是拆关键词。

**第一个特征：意思表示的内容，要指代发生某种法律关系的变动。**注意，这里说的又是"意欲"那个关键词——必须要包含一个使法律关系发生变动的意图。定义里"意欲发生一定法律上效果"这句话，和"指代使法律关系发生变动的意图"，其实是同义词。

> **提示**：为什么要绕这么一个弯子？因为考试分析的编写者如果直接用定义里的原话来表述，显得没水平，所以在这里做了一个同义词的替换。你以后写论文、答主观题的时候，也会经常做这种同义替换，这很正常。

**第二个特征：意思表示是一个意思由内到外的表示过程。**这一条体现的还是"表示"这个关键词——光在内心里面是不够的，一定要通过一定的方式表达于外部。

**第三个特征：意思表示依据是否符合生效要件，赋予其不同的效力。**能不能发生效力，要看它有没有符合法律规定的要件。这一条有点像凑数的——它确实重要，但它更像是一条"效力规则"，而不是意思表示这个概念本身的属性。我们讲到后面第三部分"生效"的时候，它才真正展开。

### 意思表示怎么做出来：明示、默示与沉默

《民法典》第 140 条专门作了规定：**行为人可以明示或者默示作出意思表示，沉默只有在有法律规定、当事人约定或者符合交易习惯时，才可以视为意思表示。**

把条文读一遍，意思表示的作出方式就三种：明示、默示、沉默。这里面的关系是——**明示和默示是原则，沉默是例外**。

```text
                    意思表示的作出
                          │
        ┌─────────────────┼─────────────────┐
      明示               默示               沉默
     （原则）           （原则）          （例外）
        │                 │                 │
   ┌────┴────┐       作为的默示        不作为的默示
  口头      书面      特定行为间接表示      单纯不作为
   │         │                              │
 简便易行   留下字据                   原则上不构成
 直接迅速  双方权利更明确            法律规定/当事人约定/
 口说无凭   交易成本升高              符合交易习惯时"视为"
```

#### 明示：心直口快，不藏着掖着

所谓明示，就是表意人将内心意思以**明确的方式**表达以外部——心直口快，不藏着掖着。

这个"明确的方式"还要再往下分成两种：口头和书面。

**口头形式**，就是用语言来做意思表示。甲给乙明确说"我就看你这个手机了，看看你 2000 块钱能不能卖给我"，是口头；甲给乙打电话说"你这个房子啊，200 万能不能卖给我"，也是口头。

它的优点是**简便易行、直接迅速**，有什么说什么；缺点是**没有留下文字的根据**，一旦发生争议，容易口说无凭。

**书面形式**，是以文字来做意思表示。给对方发短信、发微信、发律师函，其实都是文字方式，都属于书面形式。

> **注意**：书面形式的范围，其实要大于我们日常说的"文字形式"。在之前的民法典里，对书面形式还有一个规范定义，包括合同书、信件、电报、电传、传真等"可以有形表现所载内容的形式"。关键在"有形表现"这四个字。像电报、电传、传真，它本身是无线电讯号，不严格算文字，但同样可以以有形方式表现所载内容，所以也属于书面形式。

书面形式里又分**一般书面形式**和**特殊书面形式**。做公证、做登记等等，也都是落实到文字上的，属于特殊的书面形式，这个简单了解就行。

书面形式的优点是**能留下字据，双方的权利相对来讲比较明确**；缺点是**会增加交易的成本**。

对比一下就很直观：甲向乙表示愿以 210 万的价格买对方的房子，在乙提供的格式合同上签上自己的名字——一方面这确实是明示、确实是书面形式，意思表示的内容都用白纸黑字写下来，比较明确；但另一方面，你还得打印这个合同文本，交易成本明显高一点，也比较麻烦一些。

反过来，甲在小区门口水果摊买个西瓜，口头形式就解决了，方便得多。要是甲学了法律，非要跟摊主说"我买你这个西瓜好几十呢，我们还是签个书面合同吧，以后发生问题容易解决"——摊主会说你疯了啊，30 块钱你至于吗。因为口头形式简便易行，很快就能解决交易；如果非要搞一个书面形式，反而增加了当时的交易成本。**各有利弊**，这就是形式选择的现实。

#### 默示：不说话，用行为表态

默示又叫**作为的默示**。它指的是：虽然没有通过语言或者文字明确表示意见——这一块跟明示是不一样的——但是通过**特定的行为**来间接地表示其意思。内心的意思，通过这个举动也可以体现出来。

生活里的例子特别多：

- 去自助餐厅吃饭，不用讲话吧？你想吃什么就自己取。
- 去超市购物，想买这件衣服、想买那块猪肉，不用跟人家说，直接把它放进购物车里——**这个动作本身就是购买的意思**。
- 坐公交车、坐地铁，直接刷卡就可以上车，你的这个行为就表明了你内心的意思。

默示这种方式，比明示更好理解，因为它是可见的。

#### 沉默：原则上什么都不算

沉默又称**不作为的默示**，这个特别"冷静"。一方面，当事人没有明确表示其意思，不是明示；同时也没有通过特定行为来表明自己的意图，不是作为的默示；而只是单纯地选择了不作为。这就叫沉默。

按照我们生活的一般观念，单纯的不作为，能不能成为意思表示的作出方式？**不能。**

举个例子：甲乙是好朋友，长期相处，甲喜欢上了乙，于是发微信表白，说"我喜欢你，我们结婚吧，我们在一起吧"。乙收到信息后觉得莫名其妙——虽然我们是异性，但我把你当好兄弟，你怎么能对我有这样的想法呢。可是乙又不好意思直接回信息来拒绝甲、驳甲的面子，于是乙就没有回复，选择了置之不理。

过了一天，甲有点兴奋了，心想：都一天了，她都没有拒绝我，那她就是同意的呀，我们这事成了。

这个想法符合生活常理吗？显然不符合。因为在成年人的世界里，**不回复本身就是一种态度**——就是你想的美。

所以，沉默原则上不能作为意思表示的作出方式，当时的沉默我们不能推定他作出了意思表示。

但是，有原则就会有例外。《民法典》规定的例外条件有三个：**有法律规定、当事人约定，或者符合交易习惯**。大家注意"**视为**"这两个字——这又是法律拟制的立法技术。只要符合前面讲到的条件，不管当时你本人有没有这个意思，法律都认为你作出了相关的意思表示。

这里要给大家强调两个方面。

**第一，法律可以规定沉默视为意思表示。**比如教材里的例子，涉及《民法典》第 638 条规定的**试用买卖**——我们在合同编会讲，这种特殊的买卖合同叫试用买卖：按约定你可以先试用，然后你再决定买还是不买。试用以后即使满意，也可以选择不买，你完全有决定权。

但是，如果当时约定了明确的试用期——比如"这个平板给你七天的试用期"——那么试用期届满了，买还是不买，你没有明确表示的，按照法律规定就视为你同意购买了。也就是说，在试用买卖当中，当事人约定了试用期间的，你在试用期间内对买不买是**有义务表态**的。你要是不表态、选择沉默，法律就推定你是同意购买的，推定出一个购买的意思出来。尽管你可能只是忘了，并没想要买，但你的沉默会让法律推定你有购买的意思，你得支付价款。

所以在试用买卖当中到期的时候，**你是有回复的义务的**，你不回复，那就是同意购买。

**第二，当事人约定也可以使沉默视为意思表示**，当然这要以双方达成意思表示上的一致为前提。

给大家举个我身上的例子。我那个爱好不是读书，而是**追剧**。追剧常常是在视频平台上，但我不会一直购买某个平台的会员，因为成本有点高。我基本上是想看哪个剧了，这个剧在哪个平台，我就去开通这个平台的会员。开通的时候常常会有首月优惠，比如爱奇艺首月六块钱就可以开通，能用一个月。

但是这个首月优惠常常伴随着一个条件：**你得开通自动续费**。乡下不少同学都透露过吧？自动续费，那下个月这个费用肯定就不是六块了。人家也是通过这种方式来吸引消费者的。

那在看到这个自动扣费项目的时候，需要点击一系列"同意"的按钮。你可以好好看一看那个条款里面就有：**如果你不操作，那就推定你是同意续费的**，下个月直接把钱给你扣了。

你看，你开通这个项目，意味着按照双方的约定，在首月优惠到期之前，你如果什么都没做，那就推定你是同意续费的，人家就可以正常扣你的费了。这就是按照双方约定，沉默可以视为意思表示的情形。

> **提示**：为了防止后来忘掉，我一般是开通自动续费、取得这一个月优惠的权益以后，会马上关闭这个自动续费，这样还可以提高追剧效率——要尽快看完，否则下个月还得花钱。所以我是一个省钱小能手。

第三个条件"符合交易习惯"，大家简单理解即可。

#### 考试分析与民法典的两种框架

这里要补充一个问题，因为这个很容易在考场上吃亏。

**官方教材**写意思表示的作出形式，用的不是上面这个思路，它列的是：口头形式、书面形式、作为的默示、不作为的默视——一共四项。

**而《民法典》的展开思路**是：明示（下面分口头、书面）— 默示（即作为的默示）— 沉默（即不作为的默视），一共三层。

其实**口头书面跟作为/不作为的默视，根本就不是一个层次的概念**。所以我把《民法典》的这个展开思路也写进讲义里，方便大家对应起来。

考场上如果真考到主观题，你可以先按照《民法典》的规定来展开大框架：第一层"明示"，分第一小点口头、第二小点书面；第二层"默视"，也就是作为的默示；第三层"沉默"，也就是不作为的默示。这样做一方面思路比较清晰，另一方面就把官方教材和《民法典》的两套说法结合起来了，阅卷人一看就知道是个高手。

### 一道真题：短信里那句"请回复 N"

讲完形式，我们看一个典型真题。

甲收到乙通讯公司的短信，内容是："本公司为您提供实时的天气预报服务，每月收费五块钱。如果不接受此服务，请回复 N。"这就是我们日常收到的垃圾短信。甲看后未予理睬，后来发现乙公司向自己收取了该费用，于是请求返还。请问甲乙之间的天气预报服务合同有没有成立？

我们分三步走。

**第一步，看乙的短信。**乙通讯公司给甲发的这个短信，可以构成一个有效的邀约，希望跟对方订立一个服务合同。这一步没有问题。

**第二步，看甲有没有做出承诺，有没有做出同意的意思表示。**甲既没有明确表达"我要订阅"，也没有通过行为来表明他要订阅，而是选择了**单纯的沉默**。沉默能不能是意思表示？当然不能。

**第三步，排除"当事人约定"这个例外。**这里是最容易出错的地方。有人会说，人家短信都告诉你了，你不接受的话你得回复 N 啊，这不是基于双方的约定吗？显然不是。因为"视为意思表示"需要以**双方达成一致**作为前提，而这个案例当中，是乙通讯公司**单方面**给甲提出的要求。凭什么你给我发个垃圾短信，我就有回复的义务？我是懒得理你。所以甲的沉默不能视为作出了意思表示。

结论：**合同没有成立**。

> **易错点**：一定要把"不成立"和"无效"这两个选项区分开。尽管从结果角度来讲好像差不了太多，但从法律角度讲，这是完全不同的问题。"不成立"代表根本就没有一个合同存在，客观上都不存在一个合同，那就谈不上判断它有效无效的问题；"无效"说的是有合同存在，但是这个合同不被法律所认可。所以这道题只能选 A 选项。等我们后面讲民事法律行为的有效性时再强调一遍——判断有效无效，首先得是**已经成立**的民事法律行为。

### 意思表示什么时候生效

不管通过什么方式做出了意思表示，那这个意思表示如何来发生效力？《民法典》把它分成了三种类型分别作规定：

- **无相对人的意思表示**——不需要别人来受领的意思表示，你做出来就可以，不需要别人受领；
- **有相对人的意思表示**——需要有人来受领的意思表示；
- **公告方式作出的意思表示**——向不特定的多数人作出的意思表示。

这三种类型的生效时间是不一样的。

```text
                     意思表示的生效
                          │
   ┌──────────────┬───────┴────────┬──────────────────┐
 无相对人       有相对人                      公告方式
 完成时生效   ┌────┴────┐                 发布时生效
   │         对话      非对话             （推定已处于
   │          │         │                不特定多数人
   │        知道主义   到达主义            可随时查看的状态）
   │      相对方知道   到达相对方
   │       其内容时   （可随时查看时）
   │
   └── 例外：遗嘱等死因行为，
       以死亡为生效要件
```

#### 无相对人：完成即生效，但遗嘱是例外

既然它不需要别人来受领，那就不需要考虑别人的感受，**只要意思表示完成时就可以发生效力**。

比如例一：小花发现男友小马脚踩两条船，伤心欲绝，宣布分手，而且回家以后把小马曾经送自己的手镯、项链、衣服等全部丢到垃圾桶，表达一种情绪。这样的行为叫做抛弃所有权的行为——需不需要找邻居来见证一下？"这些东西我都不要啦，我要扔垃圾桶了。"显示不需要的，你直接扔就可以了。对这种无相对人的意思表示，只要完成的时候就可以发生效力：当你把那些曾经见证你们爱情的礼物都扔到垃圾桶的时候，你对它们的所有权就归于消灭了。

但条文后面还有半句话：**法律另有规定的，依照其规定**。注意它是有例外情形的。

这个例外主要说的是**遗嘱**。遗嘱也是无相对人的意思表示——在写遗嘱的时候需不需要别人来受领？不需要。夜里深深人静的时候，你把遗嘱写完、封存起来，等死后打开就行了，不需要本人来受领。但遗嘱在完成的时候不能直接发生效力，因为它同时是一个**死因行为**，要以遗嘱人的死亡作为它的生效要件。

看例二：老王于 2020 年 1 月 1 日立下遗嘱，声明其死后全部财产要归众合公司所有（只是举个例子，大家不要当真）。老王在写这个遗嘱的时候需不需要本人来受领？不需要，夜里深深人静的时候自己写完就行。但完成的时候这个遗嘱并不能发生效力，必须要等到老王死亡的时候才能够发生效力——它以遗嘱人的死亡作为生效要件。这就叫死因行为，我们继承编会讲这个问题。

有原则，有例外。

#### 有相对人（一）：对话方式与知道主义

有相对人的意思表示需要别人来受领，那什么时候发生效力，就不能光看你做出意思表示的一方了，还得看相对方的状态。这里进一步区分**对话方式**和**非对话方式**——注意这是法律术语。区分的标准是：**意思表示能不能实现即时的沟通**。

能实现及时沟通的，叫对话方式。比如面对面交谈，有什么问题当场可以提出；包括打电话沟通、打视频电话沟通等等，当场都可以沟通。

不能实现即时沟通的，叫非对话方式。比如给别人发律师函，或者给别人发微信、发电子邮件。你看尽管微信、电子邮件可以即时到达，但**对方有可能不能随时查看**，所以不能及时沟通，它依然是非对话方式作出的意思表示。

> **易错点**：对话与非对话的区分标准，**不在于双方距离的远近**。你在打这个电话的时候，可能双方相差几百几千公里，但现在通讯手段这么发达，可以及时沟通，那依然是对话；有的时候尽管双方离得很近，但不能及时沟通的，也依然构成非对话。比如现在好多大学生的宿舍总共只有六个人，却搞了八个微信群——本来大家都在宿舍里要吃饭的话，喊一声就行了，但现在喜欢在群里说"我们去吃饭吧"，有人说"再等 15 分钟"，另一个说"中午就别吃了吧，要减肥"等等。尽管空间上距离很近，但你通过这种微信群的方式沟通，可能有一个同学正专心听民法一本通的课程，他没看到你这个微信，不能及时地回复——那依然是非对话方式。

再看对话方式的生效规则：**自相对人知道其内容时发生效力**。注意这八个字，"知道其内容"，采取的是**知道主义的立法模式**。

不能一出口就发生效力。比如甲乙两个商人在协商签约的具体细节，但一个南方人、一个北方人，双方的方言口音相差甚远，根本就听不懂对方在说什么，需要借助翻译来转达。这个时候，尽管他们是对话方式作出的，但能不能一说出口就发生效力？不能，要对方知道的时候才能发生效力。

教材里还有个小例子：某商人会见阿拉伯客户，因语言不同需要翻译的帮助。虽然是对话方式，但是一方的意思表示什么时候才能发生效力？要经过翻译、了解表意内容的时候才能够发生效力。是不是要考虑相对方的感受？知道主义。

#### 有相对人（二）：非对话方式与到达主义

非对话方式采取的是**到达主义的立法模式**：到达相对方的时候发生效力。

但这里最关键的一个限定是——**这个"到达"不是说相对方要查看这个内容**，而是这个意思表示处于**相对方可以随时查看的状态**的时候，就已经到了。

看这个例子：甲通过寄信的方式给对方发一个律师函。这个律师函已经到达对方公司的收发室了，但相关负责人员一直没有及时地同事故意把这个信件取出来查看，直到一周以后才交给相关负责人。问：意思表示什么时候发生效力？**到达对方的收发室的时候就已经发生效力了。**尽管你还没有看，但它已经处于你随时可以查看的状态了。

发电子邮件也是一样，是不是**发送即到达**？尽管对方不知道什么时候才能看到这个邮件，但只要信件到达对方的信箱，处于他随时可以查看的状态，那这个时候我们就认为意思表示已经到达、已经发生效力了。

《民法典》里还特别规定了**通过数据电文的方式**作出意思表示的生效规则。数据电文虽然可以及时到达，但因为对方不能随时查看，无法及时沟通，所以它依然属于非对话方式作出的意思表示，采取的也是到达主义的立法模式。

只是在确定有没有到达的时候，我们要区分两种情况。

**相对方指定了特定的接收系统。**比如沟通时都说了，订单要发到指定的这个邮箱当中来——这个时候，要到达指定的接收系统才能够生效。这个比较好理解。

**关键是没有指定特定接收系统怎么办。**按照《民法典》的规定：**相对人知道或者应当知道该数据电文进入其系统的时候**，才能发生效力。

> **提示**：这一点跟以前《合同法》的规定是不一样的。《合同法》规定的是，如果没有指定接收系统，进入**任何**接收系统的时候都可以发生效力。这样的规定明显不合理——实践当中有些人会有好几个方便联系的途径，比如电子邮箱，好多人肯定有好几个。我们不能指望交易相对人时时刻刻都要查看他所有的邮箱，所以进入任何系统都可以生效，对相对人来讲是不公平。所以《民法典》修改了这个规则，要求相对人**知道或者应当知道**进入某个系统的时候才生效。

看教材里的这个小例子：甲公司生产部经理车某和乙公司市场部经理岳某互留名片。

说到名片，我记得我上博士的时候还专门印了个名片，在从事一些社会交往的时候主动把名片交给对方、换取对方的名片，这样我们就算成为朋友了，以后有什么事情可以通过名片上的联系方式来联系。但是现在几乎已经没人用名片了——微信二维码一扫，就可以取得这个联系的途径。

那么，如果岳某将乙公司所需的产品订单发到车某名片上的电子邮箱，是不是就进入对方指定的这个接收系统了？是的。

那假如这张名片上**没有邮箱地址，只有电话号码**呢？电话号码没法接收电子文件。于是岳某从其他途径找到了车某的电子邮箱，把订单发了进去，然后特别给车某打了个电话，说"我已经发到你的 QQ 邮箱了，赶紧查收一下"。

这时候的车某，他**知道或者应当知道**这个数据电文进入他的系统了。即使车某还没有点开那个 QQ 邮箱，意思表示就已经发生效力了。实际上采取的还是到达主义的立法模式，只是要求"知道或应当知道已到达"。

#### 公告方式：发布即生效

公告方式作出的意思表示，是面向不特定的多数人作出的意思表示，**自公告发布时发生效力**。因为你一发布，法律就推定它处于不特定多数人可以随时查看的状态了。

比如某人丢了行李，在微信朋友圈里发了一条寻物启事——你看指向不特定多数人，通过公告方式作出意思表示，从他发布时就可以发生效力。

到这里，意思表示的生效规则就走完了：无相对人的完成即生效，有相对人的再分对话和非对话，公告方式发布即生效。

### 撤回：只有一段"时间差"才留得住

所谓**撤回**，说的是在意思表示**生效之前**来消灭它的效力。

那么，哪些意思表示实际上没有撤回的机会？我们回过头去看刚才那三种生效规则，就一目了然了。

- **无相对人的意思表示**，原则上完成时就发生效力，常常没有撤回的机会。**但遗嘱是例外**——因为它是死因行为，从完成之后到遗嘱人死亡的这一段时间里，遗嘱并没有生效，这段时间是可以撤回的。遗嘱的撤回，我们会在继承编讲。
- **公告方式**，发布就发生效力了，常常也没有撤回的时机。
- **有相对人的意思表示中，对话方式**可以及时沟通，所以常常也没有撤回的时机。
- **只有非对话方式作出的意思表示**，采取到达主义的立法模式时，才**有撤回的时机**——从做出意思表示到到达相对方之间得有个时间差，这个时间差就给了当事人撤回意思表示的机会。

《民法典》上的规定是：**行为人可以撤回意思表示，撤回意思表示的通知应当在意思表示到达相对方之前，或者与意思表示同时到达相对方。**

换句话说，**必须要在到达之前的这段时间里完成撤回**。

另外，**悬赏广告**也是一种典型的意思表示，如果是有相对方的意思表示，也可以撤回。我们到合同编会讲到邀约撤回的规定。

### 意思表示怎么读：折中主义的解释规则

意思表示生效以后，我们如何来理解它的含义？这叫**意思表示的解释**。

在理解意思表示含义的时候，有两个最为核心的根据：**一个是当事人内心的意思，一个是外在表示的行为**。

- 如果以当事人的内心意思作为解释的最终目标或根据，这叫**意思主义的解释模式**；
- 如果是以当时的外在表示作为解释根据，这叫**表示主义**。

那大家猜一猜，我国《民法典》采取的是哪一种解释立场？**折中主义**——具体问题具体分析，不能一概而论。我们要区分无相对人和有相对人的意思表示，适用不同的解释原则。

#### 无相对人：意思主义，词句可以让位于真意

按照《民法典》的规定，无相对人的意思表示用的是**意思主义的解释模式**。因为既然不需要别人来受领，那就不需要考虑相对方的信赖，主要考虑的是表意人内心真实的意思。

法条上的表述是：在解释的时候**不能拘泥于所使用的词句**。注意"不能拘泥于所使用的词句"这几个字——就是外在的表示它不具有决定意义，而是应当结合有关条款、行为的性质和目的、习惯以及诚信原则，来确定行为人的**真实意思**。最终目标是要确定行为人当时到底内心是怎么想的，这就是解释所需要实现的最终目标。

看一个例子。张某在某小区同单元有两套房子，301 和 302，门对门。有些人会问，为什么要门对门买两套？因为有钱呗。301 号房是 120 平米的三居室，由儿子小张居住；302 室是 80 平米的两居室，由张某自己居住——中国好父母，把大房子留给年轻人来住。

张某的多位好友均证明，张某曾多次表示：死后愿意将自己居住的房子赠给好友刘某，而且称"我已经写好遗嘱了，你们到时候等着看"。后来张某死亡了，发现他确实立了一份自书遗嘱，上面写着"我一直住的 301 号房，要赠与给刘某"。

这个遗嘱是典型的无相对人的意思表示——立遗嘱的时候不需要别人来受领。现在刘某提出：张某都说了，三居室的大房子要给我，要取得这个所有权。但小张提出异议：遗嘱所称的"我一直住的 301 号房"根本就不存在，因为 301 号房不是老张住的，是小张住的，老张住的是 302。

双方产生了争执。假如诉至，法院就要确定遗嘱里写的"我一直住的 301 号房"应当怎么理解。

既然是无相对人的意思表示，解释的最终目标是什么？要确定张某内心到底是怎么想的，**他的真实意思才是具有决定性的**，而不用拘泥于当事人所使用的词句。

尽管遗嘱里写的是"我一直住的 301 号房"，但事实上他自己居住的是 302 号房，而且他之前曾多次表示，自己住的这套房子要给好友刘某。所以他内心的真实意思就是：**把自己住的 302 号房给刘某**，只是在写遗嘱的时候写错了房号，把 302 写成了 301。

为什么同一层门对门的两套房都是自己买来的，会把房号写错呢？因为大家想想，同一层的两套房子门对门、都是你买来的话，你常常不会关心哪头是 301、哪一头是 302——你只记得左手边是儿子住的，右手边是你自己住的。张某在写这个遗嘱的时候可能也犹豫过，但他一想：我是老子啊，我肯定住 301，儿子才住 302，可能就把这个符号给写错了。

但我们不拘泥于他使用的词句，只要确定张某的真实意思是把自己住的 302 号房给刘某的，那在解释这个内容的时候，就得按照他的真实意思来解释。**文书写错，并不当然否定真实的意思**——这就是所谓的"无害于真意"。

> **提示**：这就是在民法里常说的"不拘于文义、真意优先"——有的时候在签合同或者做出意思表示的时候写错了、有笔误，但如果能够确定当时的真实意思，那还是按照当时的真实意思来确定。这就带来一个很实际的好处：像刚才遗嘱写错房号这种情况，就**不用通过什么重大误解等等来撤销合同**了，直接通过解释的方式就把问题解决了。

#### 有相对人：表示主义，词句本身就是约束

有相对人的意思表示，既然需要别人来受领，那在解释的时候就不能光考虑你做出表示的一方内心是怎么想的，你得考虑**对方接收到的讯息是什么**。这个外在的表示就更加重要了。

所以法条上的表述变成了：**应当按照所使用的词句**，然后结合相关条款、行为的性质和目的、习惯以及诚信原则，来确定意思表示的含义。注意最终确定的是"意思表示的含义"，这个含义**很有可能跟当时内心的真实意思不能划等号**，但要优先考虑外在表示所呈现的意思，保护相对方的信赖利益。

同样举个例子。车某因为买房，向岳母借了 10 万块钱。双方约定的利息"为一分利"这三个字是写在借条上的，借期是一年。期限到期以后车某要还款，对 10 万的本金双方并无争议，但对要还多少利息，双方产生了争议。

车某认为"一分利"就是一分钱利息的意思，所以岳母应还他 0.01 元。岳母认为这个"一分利"指的是每月 1% 的利息，12 个月应该是 12%，应该还的是 1.2 万元的利息。双方理解差距很大。

假设产生争执诉至法院，法院就要去解释这个"一分利"怎么理解。

**第一步，先定性。**双方签的是借款合同，这是一个有相对人的意思表示，所以要采用**表示主义的解释立场**——按照当时所使用的词句，也就是"一分利"，然后结合其他条款、行为的性质、交易习惯、诚信原则来确定这个意思表示的含义。

**第二步，逐项考虑。**首先，"一分利"在借款的行业惯例当中，代表的是每个月 1% 的利息，它是一个约定俗成的含义。其次，按照生活常理，如果是一分钱的利息，那应该写的是"一分钱"，而不是写"一分利"。再次，基于诚信的考虑——一分钱，这叫利息吗？连象征性的利息都算不上。

所以综合考虑，把它解释为**每个月 1% 的利息**是更加合适的。不管车某在签合同的时候是怎么去理解这个"一分利"的，发生纠纷的时候解释出的意思表示含义，对双方都是有约束力的。这样的话，车某应该付 1.2 万元的利息。

这就是表示主义的解释立场。

> **结论**：意思表示的解释规则，就是区分有相对人和无相对人，做出不同的认定，这叫**折中主义**，要具体问题具体分析。

到这里，第二节"意思表示"就给大家介绍完了。一方面需要大家掌握意思表示的含义和特征，这是一个理论问题；同时按时间线索掌握三个层次的问题：第一，意思表示作出的方式包括哪些；第二，作出以后如何发生效力；第三，意思表示如何来解释它的含义。

### 本讲提到的题目

#### 天气预报服务短信案

甲收到乙通讯公司的短信，内容为："本公司为您提供实时的天气预报服务，每月收费五块钱。如果不接受此服务，请回复 N。"甲看后未予理睬。后来甲发现乙公司向自己收取了该费用，于是请求返还。请问甲乙之间的天气预报服务合同有没有成立？

**解析：**

第一步，看乙通讯公司发出的短信。这条短信包含商品（天气预报服务）的名称、价格和联系方式，并表明一经接受即订约，因此可以构成一个**有效的邀约**，希望与甲订立一个服务合同。

第二步，看甲有没有作出承诺。甲既没有明确表达"我要订阅"（不是明示），也没有通过任何行为表明要订阅（不是作为的默示），而是选择了**单纯的沉默**。按照本讲的规则，沉默原则上不能作为意思表示的作出方式。

第三步，考察"当事人约定"这个例外能否适用。表面上看，短信里说"如果不接受此服务，请回复 N"，似乎约定了甲要回复。但"视为意思表示"以**双方就沉默的意思达成一致**为前提，而这里只是乙通讯公司**单方面**向甲提出的要求，甲从未表示接受这一安排。双方并未就此形成合意，因此不构成"当事人约定"。

三个例外情形（法律规定、当事人约定、符合交易习惯）均不成立，甲的沉默不能视为作出了意思表示。

**答案：合同没有成立，应选"未成立"的选项。**

**注意区分"不成立"与"无效"：**

| | 客观上是否存在合同 | 法律评价的对象 | 后续处理 |
| --- | --- | --- | --- |
| 不成立 | 不存在合同 | 无从评价 | 无合同可管，甲可请求返还已收费用 |
| 无效 | 存在合同 | 评价该合同的效力 | 合同被法律否定，效力瑕疵需另行处理 |

判断有效无效，前提是**已经成立**的民事法律行为。本题中合同根本没有成立，客观上都不存在一个合同，那就谈不上判断其有效无效的问题，所以只能选"未成立"。

## 民事法律行为的成立与生效
> 对应块：BLK27 | 覆盖分集：P27 | 块标题（分集名）：《第01编 第06章 第03节：民事法律行为的成立》

先给大家一个画面：一个行为，它先成立，然后再过 0.01 秒，然后发生效力。这 0.01 秒，我们叫它**法学上的 0.01 秒**。这两个问题必须掰开，不能混。

```text
[ 成立 ] --0.01 秒--> [ 生效 ]
事实判断               价值判断
客观上能否构成         在法律上作何评价
```

读图：左边只回答"客观上凑不凑得起来"，右边才回答"法律上认不认它"，中间那道缝就是 0.01 秒。

成立，解决的是民事法律行为在客观上**能否构成**；生效，解决的则是已经构成的民事法律行为**在法律上作何评价**。一个管"有没有"，一个管"行不行"。

> **结论**：原则上只有已经成立的民事法律行为，才有评价其效力的必要——效力判断的前提是行为已经成立。尽管在实践中，多数民事法律行为、特别是合同在成立时就可以发生效力，但从法律规范的角度看，**成立与生效仍然是两个不同的问题**。

### 用考试打个比方

这个区分我们用考试来理解，比什么都形象。

我们在上大学，包括未来上研究生的时候，都会学很多门课程，学完以后要参加考试，然后由老师对我们进行评分。

那么，**课程学完以后你有没有参加考试**——这就是成立要解决的问题。你看这是一个事实判断问题：参加了就是参加了，没参加就是没参加，没有模棱两可的空间。它的结果只有两个：要么行为成立，要么行为不成立。

接下来，把卷子交上去，老师拿你的卷子跟评分标准对比，"诶，你这个卷子和这个评分标准有多大的差距"，给出一个评价——这个就类似于生效。这个评价**带有一定的主观性**，是个价值判断问题，所以结论会更多元：优良、中、差等等不同的等级。

法律上对一个民事法律行为做出评价的时候，结果同样是多元的，一共四个方面：

| 效力评价 | 对应的评分类比 | 意思 |
| --- | --- | --- |
| 有效 | 优 | 完全符合评分标准 |
| 可撤销 | 良 | 大体上也不错，但略有点小瑕疵 |
| 效力未定 | 中 | 虽然不至于挂科，但离优良还有距离 |
| 无效 | 不及格 | 相当于不及格，被法律打了叉 |

这就是效力判断的四个等级，是一个典型的价值判断问题。成立与生效，到这里就彻底区别开来了。

> **易错点**：成立是事实判断，解决"有没有"；生效是价值判断，解决"行不行"。这两个问题不要揉成一团。

### 成立要件：一般要件与特别要件

成立解决的是"客观上能否构成"，那就要看它有没有符合**成立要件**。在民法当中，民事法律行为的成立要件我们要区分**一般成立要件**和**特别成立要件**：一般成立要件是所有民事法律行为都得符合的，而特别成立要件是某些民事法律行为才需要符合的。

#### 一般成立要件：三个关键词

一般要件涉及三个关键词，正是我们前面讲民事法律行为概念时提到过的那三个：主体、意思表示、内容。

| 一般成立要件 | 具体要求 | 强调的是什么 |
| --- | --- | --- |
| 主体 | 要有行为人 | 只强调客观存在 |
| 意思表示 | 行为人作出了意思表示 | 只解决客观上有无的问题 |
| 内容 | 要有标的 | —— |

大家注意，主体这一层只要"有"就可以了，强调的是客观存在；意思表示这一层，也只是解决客观上有没有的问题。**成立阶段一律不谈价值判断**，只看客观上能不能凑齐这三样。

#### 特别成立要件：交付标的物

特别要件，原则上大家记一个例子就可以了，那就是**实践行为**：它除了一般要件以外，还需要**交付标的物**这样一个特别要件。

我们在前面讲过，保管合同、定金合同，包括自然人之间的借款合同，都有这个特别的成立要件。

符合这个要件，一个民事法律行为在客观上就可以构成了。这是第一个层次。

### 有效要件：实质要件与形式要件

接下来是第二个层次，民事法律行为的生效问题。那在判断效力时，评分标准是什么呢？——就涉及民事法律行为的**有效要件**了。它分为实质要件和形式要件两个层次。

这又回到考试的比喻上：老师在评分的时候，一方面要看你**内容写得如何**，另一方面呢也得看你**卷面如何**。内容如何，体现的是实质要件；卷面如何，体现的是形式要件。

#### 实质要件：主体、意思表示、内容

实质要件同样是从主体、意思表示、内容三个方面作评价，而且表达逻辑是一脉相承的——**这三个层面大家一定要掌握**。

**主体方面：主体得合格，得具有"相应"的民事行为能力。**

请大家注意"**相应**"这三个字。这意味着民事法律行为有效，是不是必须得有完全民事行为能力？**不一定！** 固然，完全民事行为能力人肯定是具有相应的民事行为能力的；但是如果当时是限制民事行为能力人，是不是也可以实施一部分行为？——可以，包括纯获利益的行为，也包括和他的年龄、智力、经济状况相适应的行为。这些也可以体现为具有相应的民事行为能力。

当然，无民事行为能力人就欠缺相应的民事行为能力了，效力就存在瑕疵。这是主体的要求。

**意思表示方面：意思表示要求真实。**

这个"真实"怎么来理解？分为两个方面的要求：第一，**意思和表示要一致**——内心的意思和外在的表示要保持一致；第二，**意思表示要自由**——没有受到外界的不当干扰。这就叫意思表示真实。

相应的，如果意思表示不真实，那就存在瑕疵，而这个瑕疵又分成两种情况：一种是意思与表示不一致，一种是意思表示不自由。至少意思表示存在瑕疵的话，它的效力呢也会受到影响。这是第二个层次。

**内容方面：内容要合法。**

一方面不违反法律、行政法规的强制规定，另一方面不违背公序良俗。这里体现的是**合法原则**和**公序良俗原则**，是法律对当事人意思自治的限制——你得符合内容合法的要求。

#### 形式要件：形式要符合法定或约定

第二个层次是形式要件。民事法律行为呢，它的形式还得符合法律规定，或者当事人约定的形式。

这一点其实对应我们前面讲过的要式行为：它得符合形式要件。如果是非要式行为的话，那其实就没有形式要件可言了。

现在回头看整体：法律对一个民事法律行为进行评价，**如果全部都符合有效要件，就被评价为有效；如果某个要件不具备，这个民事法律行为的效力就会存在瑕疵**，而这个瑕疵表现为可撤销、效力未定以及无效。

这就是成立和生效的一个完整关系。把它并起来看是这样的：

```text
       成立要件                    有效要件
   一般成立要件                  实质要件
     · 主体  · 意思表示  · 内容          · 主体  · 意思表示  · 内容
   特别成立要件                  形式要件
     实践行为：交付标的物                法定形式或约定形式
```

读图：左右两栏是同一副骨架——主体、意思表示、内容；左边多出"特别成立要件"，右边多出"形式要件"，而"形式"这一格在后面马上要单独拎出来说事。

### 形式究竟是成立要件还是有效要件

在这部分还要给大家补充一个理论问题了：**民事法律行为的形式，它到底是成立要件还是有效要件的问题？**

为什么会冒出这个问题？因为在前面讲民事法律行为的分类的时候，我们提到要式行为和非要式行为的区分，区分的标准是民事法律行为在**成立**上有没有满足特定的条件；但这个地方呢，形式又变成了**有效要件**。这怎么来理解？

我们通过一个小例子来说明。

**比如说，甲有一套商品房要卖给乙。** 按照法律规定，商品房买卖合同是要通过书面形式来订立的，也就是这是一个要式合同。但是甲乙呢，只是口头上达成了商品房买卖的合意，并没有按照法律规定去完成这个书面形式的要件。产生的后果是什么呢？有以下三个方面的观点。

**第一种观点**：如果甲乙没有签订这个书面的合同，那这个合同啊就不能成立。这种观点认为，**形式要件是民事法律行为的成立要件**——你不满足，那民事法律行为就不能成立。

**第二种观点**：既然甲乙没按照法律规定签订书面形式的合同，那这个合同可以成立，只是它不能发生效力。这种观点认为，**形式要件是民事法律行为的有效要件**——既然双方意思表示达成一致了，那不影响成立，但是不能发生效力。

**第三种观点**：尽管双方没有签订书面合同，但是毕竟意思表示达成一致了，合同可以成立并生效。只是因为当时没有签这个书面合同，到时候发生纠纷的时候，会欠缺证据，使自己处于一个不利的地位。这种观点认为，**形式要件只是发挥一个证据效力的功能**，它不影响成立生效，只是你手里面的证据可能会有所欠缺。

这就是理论上的三种观点。那我国采取的是哪一种观点？

> **结论**：《民法典》采取的是**第一种观点**。在民法典当中，民事法律行为的形式，它属于**成立要件**——形式既然不能满足，那后果就是民事法律行为不成立。

我给大家以脚注的方式列了一个条文，大家可以参考看《民法典》**第 490 条第一款**：当事人采用合同书形式订立合同的，自当事人均签名、盖章或者按指印时，合同成立。你看那个合同书的形式，它就是合同成立的要件；如果没有满足这个要件，后果就是合同不成立。这是民法典的观点。所以我们前面讲要式行为和非要式行为的区分，标准就是看这个民事法律行为在**成立**上有没有符合相应的形式，这是符合民法典规定的。

**但是考试分析呢，在写民事法律行为的要件的时候，它采取的是第二种观点。** 我们在讲这个有效要件的时候，会单独把这个形式要件列出来，代表着在考试分析的眼中，有没有满足这个特定的形式，是民事法律行为的有效要件。

那这样的话，考试分析的观点就跟民法典的规定稍稍有点冲突了。也就是考试的时候怎么来解决？我的建议是：

- 考到**简答题**这样的主观题，大家按照**考试分析**的观点来写。比如考你一个简答题——实际上之前也考过，"简述民事法律行为的有效要件"——大家既要写实质要件，也要写形式要件，因为官方教材里面有这个条件，你**要不写的话是有被扣分的风险**的；
- 考的是**选择题**或者**案例分析题**，那大家还是按照**民法典**的观点来作答，也就是形式要件没满足之后，后果是这个民事法律行为、或者说合同他是**不能成立**的。

要做这么一个区分，因为官方教材的观点跟民法典稍稍有点出入，所以要做一个理论拓展来给大家做解释。

### 本讲提到的题目

这一讲最后看了一道考过的典型真题，是 2017 年的单选题。

> 公司职员甲办理了某银行的信用卡，在商场的持卡消费了 2 万元。在向银行还款之前，甲突患精神病。

**解析**：题目让人判断两个合同的效力如何，是不是主要涉及这个主体的行为能力的问题？

大家看这里面其实有两个合同关系：一个是甲和银行之间的**信用卡合同关系**，第二个是甲和商场之间的**消费合同关系**。

当然大家也注意到，甲突患精神病，是**发生在向银行还款之前**，这意味着在办信用卡和持卡消费的时候，甲依然是正常人，也就是**实施行为的时候他仍然是完全民事行为能力人**。完全民事行为能力人当然是具有相应的民事行为能力的，那么当时这个行为的效力受不受影响？不受影响。

> **易错点**：这里容易搞错的是拿"后来"的状态去套"当时"的行为。突患精神病影响的是此后的行为能力，评价已发生行为的效力，看的始终是**实施该行为当时**的状态。

**答案**：两个合同都是有效的，应当选 A 选项。非常简单。

> **承前启后**：上一节讲完「民事法律行为的成立与生效」，下一节接着讲「可撤销的民事法律行为：意思表示不真实时，法律给你一次反悔的机会」。

## 可撤销的民事法律行为：意思表示不真实时，法律给你一次反悔的机会
> 对应块：BLK28 | 覆盖分集：P28上 | 块标题（分集名）：《第01编 第06章 第04节：可撤销的民事法律行》

### 效力瑕疵的第三种形态

一个已经成立的民事法律行为，如果没有完全符合有效要件，它的效力就会存在瑕疵。瑕疵一共三种形态：**可撤销、效力未定、无效**。

这三种制度在学习上有一个共同的老套路，你在民法里学任何一项制度，完整的知识板块永远是三块：**概述**（含义、特征）、**适用情形**、**法律后果**。所以可撤销这一节，咱们也按这三块走：先看概述，再看适用情形，最后看法律后果。

先把整个判断链条摆在脑子里：

```text
      民事法律行为已经成立（主体合格 · 意思表示一致 · 有标的）
                              |
                  是否完全符合有效要件？
                    /                  \
                  是                    否
             （有效）            （效力存在瑕疵）
                                        |
              ┌──────────────┬───────────────┬──────────┐
          可撤销          效力未定           无效
              |
     主要因意思表示不真实
              |
   决定权交回给当事人自己：
   行使撤销权 → 自始失去效力；不行使 → 依然有效
```

### 一块名表惹出来的官司

什么样的民事法律行为会被评价为"可撤销"？先听一个例子。

车某有一块名表，因为急需用钱，想把这块表卖给岳某。岳某不喜欢这种名表，不肯买。车某就胁迫岳某，说："这表你要是不买的话，我就把你的裸照发到网上去。"岳某心生恐惧，惹不起你，虽然不情不愿，还是签下了合同、付了钱，买下了这块表。

我们来看车某和岳某之间的这个名表买卖合同：这个民事法律行为**已经成立**了——有双方，有意思表示一致，有标的。接下来看它能不能发生效力，就要看它有没有符合有效要件。

双方都是完全民事行为能力人，主体是合格的。但岳某在签订合同时，是不是意思表示不真实？他受到了外界的不当干扰，是被胁迫签的合同。**意思表示真实**这个要件没有满足，那就意味着这个合同的效力存在瑕疵。这时法律说：这是一份可撤销的合同，要赋予岳某一个撤销权，由他来决定这个合同的命运走向何方。

对岳某来讲，如果他咽不下这口气，绝对不能被车某欺负，绝对不能善罢甘休，于是他选择行使这个撤销权，行不行？可以。他行使这个权利以后，这个合同将自始失去效力。

那假设岳某觉得"哎，这块手表还是物有所值的"，他选择不行使撤销权，行不行？也可以。这样的话，合同依然是有效的。

所以这个合同处于一个"可以被撤销或者可能被撤销"的状态——这就是可撤销的民事法律行为。法律把决定权交到了意思表示存在瑕疵的岳某手中：**你来决定这个合同的命运。**

> **定义**：**可撤销的民事法律行为**，是指欠缺有效要件（主要是意思表示不真实这个要件），当事人有权依照法律规定请求人民法院或者仲裁机构予以撤销的民事法律行为。适用前提是它已经成立并生效。

这个概念包含三个关键词：**适用前提、起因条件、法律后果**。其实我们在讲前面一些制度的时候也提过，民法里描述任何一个制度的完整表述，都是先讲前提，再讲起因条件，最后讲后果。

逐字对一下：

| 概念关键词 | 具体内容 |
| --- | --- |
| 适用前提 | 民事法律行为已经成立并生效 |
| 起因条件 | 欠缺有效要件，主要是意思表示真实要件没有满足 |
| 法律后果 | 当事人有权请求人民法院或者仲裁机构予以撤销 |

> **结论**：连起来就是——**前提 + 起因条件 + 后果**。

### 特征就是概念的关键词展开

概念讲清楚了，特征其实不用另起炉灶，把三个关键词各展开一句就出来了：

1. **适用前提已经满足**：可撤销的民事法律行为已经成立，而且在被撤销之前它是**有效的**。就像车某和岳某签完合同以后，如果岳某什么都不做，这个合同就已经发生效力了。
2. **主要适用于意思表示不真实的情形**：对应概念里的"起因条件"。
3. **需要由撤销权人主动行使撤销权**：对应"法律后果"。法律赋予当事人这个权利，当事人行使，这个行为才会被撤销；如果不行使，这个行为依然是有效的。

> **提示**：概念和特征的关键词是**一一对应**的。考场上概念忘了、特征忘了互相补就行，别把它们当成两套要分别背的东西。

### 适用情形：真题里的绝对主力

可撤销的民事法律行为主要适用于**意思表示不真实**这个场景。

从真题数量上你应该能感受到这个考点的重要性：无论主观题、客观题，还是案例分析题，都经常考到。

那意思表示不真实包括哪些？一方面是**意思表示不一致**，意思表示本身直接有瑕疵；另一方面是**意思表示不自由**，受到外界的不当干扰。意思表示不一致，民法里主要规定了一种类型，叫**重大误解**——这是一个专业术语；意思表示不自由，民法典规定了三项制度：**欺诈、胁迫、显失公平**。

所以可撤销的民事法律行为主要适用于这四种情形：**重大误解 + 欺诈 + 胁迫 + 显失公平**。依次来看。

### 重大误解：误解的是交易要素，不是动机

重大误解体现的就是意思表示不一致，也就是意思表示存在错误。

这里有一个术语问题。"错误"这个词在民法里其实是个专业术语，考试分析里也是有的，但**《民法典》没有采纳这个说法**——因为"错误"这个词太日常了，我们生活里经常讲"你说得对""你说错了"，不具备法言法语的素质。所以《民法典》用了一个词来描述，叫**重大误解**。你完全可以把"重大误解"理解成民法里所称的"意思表示的错误"。

重大误解的具体概念是**总则编司法解释的明文规定**。虽然它跟考试分析的说法不一样，但我建议大家按照司法解释的原文来记：因为这是司法解释的原文，更加规范、准确；特别是考试的时候容易考法条分析题，你写司法解释的规定，肯定比考试分析那个不严谨的说法更靠谱。

司法解释的定义是：行为人对行为的性质、对方当事人或者标的物的品种、质量、规格、价格、数量等产生错误认识，**按照通常理解，如果不发生该错误认识，行为就不会做出相应意思表示**的情形。

这个定义非常长，我们做一次关键词拆解。其实这里面讲了两个核心内容：

- 第一，当时得有个**误解**；
- 第二，这个误解还得足够**重大**。

满足这两个条件，就构成重大误解。

#### 层次一：当时存在一个错误认识

"错误认识"就是搞错了、误解了。关键问题来了：**对什么事项产生错误认识，才会构成重大误解？**司法解释了三个方面。

**对行为的性质产生认识错误**，体现的是对**内容**的错误认识。本来的交易内容是买卖，当时误以为是赠与；本来是租赁，当时误以为是借用——行为性质搞错了，会构成重大误解。

**对对方当事人产生错误认识**，体现的是对**主体**的错误认识。把甲认成了乙，把张三认成了李四，把对方当事人给搞错了。

**对标的物的一系列属性产生错误认识**，体现的是对**客体**的错误认识，包括标的物的品种、规格、数量、质量、价款等等。比如双方交易的标的本来是一条镀金的项链，当时以为是纯金的；或者标的物本来是国产商品，当事人以为是原装进口的。

顺带说一个大家肯定有印象的例子。教材里有个"误以为荔枝鲜为荔枝树"的案例——这个名字是不是很眼熟？它来自《长安的荔枝》，那部小说很火，被拍成了电影，也拍成了电视剧：电影是大鹏主演的，电视剧是雷佳音主演的。里面那个悲催的李善德，在接这个任务的时候，是不是误以为标的物是荔枝鲜？实际上他要去弄的是荔枝鲜。

> **提示**：我知道"荔枝鲜"到底是个什么玩意儿，但在当时的背景下，李善德要搞定荔枝鲜还是比较容易的；如果他要搞到的是荔枝树，那可以说是难于上青天，因为当时交通并没有那么发达。所以他对这个任务的标的，实际上是有重大认识错误的。

三类错误认识，正好对应我们非常熟悉的民事法律关系三要素，这么记就非常好记了：

| 错误认识的对象 | 体现为 | 例子 |
| --- | --- | --- |
| 行为的性质 | 内容错误 | 买卖误以为赠与、租赁误以为借用 |
| 对方当事人 | 主体错误 | 把甲认成乙、把张三认成李四 |
| 标的物属性 | 客体错误 | 镀金当纯金、国产当进口、1 万标价误设 1000 |

> **注意**：**对标的物价格的错误认识**，这一点要特别留心。之前的重大误解具体范围**并不包括**标的物价格的错误认识，是**总则编司法解释专门把它增加进来的**。

这个价格错误主要解决的是实践中**网络标价错误**产生的纠纷。比如某个网店在网上销售商品，本来这商品是要卖 1 万块钱的，但后台设置参数的时候因为失误，把标价设置成了 1000 块钱。老板以为是以 1 万块钱的价格在卖，实际上他标的是 1000 块钱——对标的物的价格存在错误认识，也可以通过重大误解来获得救济。

#### 动机错误不在救济范围之内

这里给大家补充一个理论拓展：民法中的重大误解，救济的是对**交易当中要素**的错误认识，**不包括行为动机的错误**，也就是**动机错误**。动机错误不能纳入重大误解的救济范围。

什么叫动机？就是我们实施交易的时候，常常是**基于一些动机**去实施的。在动机层面发生的错误认识，法律是不给救济机会的。

第一个例子，教材里的"因惦记女友生日而订购蛋糕"。某甲下班时突然想起来"哎，今天好像是女友的生日"，赶紧去蛋糕店买个蛋糕，想回家给女朋友一个惊喜。结果呢，女朋友非常生气——因为这一天他刚好把事儿给记错了，5 月 16 日其实不是女友的生日。这时甲能不能回去找到蛋糕店说："你看我买了个蛋糕是为了给我女朋友过生日，但事实上今天不是她的生日，我搞错了，能不能基于重大误解把这个蛋糕退回去？"

答案是**不可以**。因为"给女朋友过生日"是甲买这个蛋糕的**动机**。尽管这个动机上确实有错误认识，但这样的错误认识，法律是不给当事人救济机会的。为什么？因为在生活当中，你基于什么样的目的去实施这个交易，对方是很难去查明的。买蛋糕可能是给自己过生日，可能是给别人过生日，也可能就是想吃蛋糕了，甚至有可能买个蛋糕回来学习一下制作蛋糕的技术——每个人有不同的动机，对方没有办法判断你是基于什么动机来买这个蛋糕。所以即使你自己搞错了动机上的认识，这个后果就由你自己承担：世上虽然没有生日，但也不妨吃个蛋糕嘛，庆祝一下。

第二个例子是"**误信**房价上涨而投资购房"，其实也包括误信股票上涨而购买股票。像老马每次买股票的时候都笃定这支股票一定得涨，然后实施购买行为——他觉得这个股票会涨，这是他买股票的动机。结果后来发现是认识错误：每次老马觉得股票要涨的时候，从他买完以后就开始狂跌。老马能不能说我买这个股票是有重大误解的呢？当然不能，这属于动机层面的错误。

> **易错点**：重大误解的**具体范围不包括动机的错误认识**，这一点特别注意。

#### 层次二：错误认识要足够重大

光有错误认识还不够，第二个层次是跟"重大"相关的条件——这个认识错误要**足够重大**，法律才给予救济的机会。

在**之前的**司法解释里面曾经规定过：如果能发生错误认识并造成较大的损失，那就是重大误解。但这个标准已经被**新的司法解释给否定了**。也就是说，你的认识错误是不是足够重大，**不是看有没有造成财产上的较大损失**，而是看另一句话：

> 按照通常理解，如果不发生该错误认识，行为就不会做出相应意思表示。

听起来很抽象，简单讲就是八个字：**早知今日，何必当初**。也就是我如果当初没有发生这个错误认识，我就不会做出现在这样的意思表示——这意味着当时这个认识对当事人做出意思表示具有**决定性作用**，从这个角度讲，他的误解才是重大的。

比如甲买一条项链，他以为是纯金的才买，但实际标的物是镀金的。假如当初知道它是镀金的，就绝不会选择购买——这样一个认识上的错误，对当时来讲就是足够重大的，法律应当给他救济的机会。同样的道理放到《长安的荔枝》里：如果李善德当初知道这是荔枝鲜，他会不会接下这个任务？当然不会。从这个角度讲，他的错误认识就是足够重大的，应当给予相应救济。

教材里还写了一个小案例，特别典型：**甲的祖传名画一幅，甲的朋友乙看到以后提出愿意以市价购买并成交**，甲乙之间有一个名画买卖合同。后来经鉴定，得知该画是赝品。

这意味着乙在购买时对标的物的品质是有错误认识的：以为这个名画是真迹，实际上是赝品。接下来判断这个错误认识是不是足够重大——如果当初你知道这是赝品，还会不会花这个市场价格来购买？按照通常理解，当然不会，所以乙的错误认识足够重大，法律应赋予他撤销的权利。

那甲有没有重大误解？有。甲也以为自己家里面祖传的宝贝是真品，后来发现是赝品——甲对标的物品质也有错误认识。那甲的错误认识够不够重大？如果甲当初要知道这个名画是赝品，还会不会以市价卖给自己的好朋友？按照通常理解，甲不会这么干：一方面你不能这么坑爹的好朋友，另一方面自己祖传几代的名画是赝品，多么丢人。所以这时候甲也不会做出相应的意思表示，**甲也存在重大误解**。

所以这个案例里，**双方都有撤销合同的机会**。

> **补充**：这是司法解释新增加的规定——意思表示存在**第三人转达错误**的，也可以适用重大误解的规定。假设这个意思表示不是直接到达相对方的，而是经由第三人的转达到相对方，那在转达的时候肯定存在一些偏差，这个时候也可以适用重大误解的规定，让当事人行使撤销权。

#### 撤销的路径与交易习惯这道门槛

由重大误解实施民事法律行为的，行为人有权请求人民法院或者仲裁机构予以撤销——因为当时的意思表示存在瑕疵，不是他内心真实意愿的完整表达，法律给他一个救济的机会。

> **注意**"**行为人**"这三个字，指的就是**发生重大误解的一方**。

另外，撤销权要通过**诉讼或者仲裁**的方式来行使，能不能通知对方就撤销合同？**不可以**，必须走诉讼和仲裁。

然后是例外情形：**如果能根据交易习惯等认定行为人无权知悉的，那就不适用撤销权了。**这就是"交易习惯"所具有的**否定当事人撤销权**的作用。怎么理解？来看一个例子。

甲在某旅游地的纪念品商店购买了秦始皇兵马俑的复制品——相信大家能猜到是在哪里的旅游商店。买完以后他才了解到，他买到的只是一个复制品而不是真品，于是要向法院提起诉讼，请求撤销这个买卖合同。

先看甲有没有重大误解：他有错误认识，他以为是真品但实际是仿制品，对标的物品质有错误认识；这个误解够不够重大？如果他当初知道这是仿制品，还会不会买？假如甲是真的以为他买到了正品，如果是仿制品，他可能看不上，那也有可能符合"重大"的要求。关键这个时候——**甲能不能撤销这个合同？按照交易习惯是不可以的。**

为什么？你在旅游商店买个纪念品，那肯定是复制品或者仿制品啊，真品怎么可能拿出来卖给你？这是一个正常的交易人都应当知道的。所以按照交易习惯，法律这个时候就不保护甲的这种认识错误了：即使你确实有重大误解，法律也不给你这次机会。

同样的逻辑还适用于**古玩交易市场**，比如北京的潘家园。有的同学可能去过。古玩爱好者会去淘点东西，在这个古玩交易市场里，大家都是**各凭本事、运气来吃饭**的——有时候你会高价买到一个赝品，也有可能花低价买到一个价值连城的宝贝。大家各凭本事吃饭。能不能说你买的时候觉得这东西肯定是真的，花大价钱买过来，后来多方鉴定求证发现是赝品，能不能通过重大误解来撤销合同？**不可以**。因为基于古玩交易市场的交易惯例，大家都是各凭本事吃饭，即使你发生了错误认识，也不能通过重大误解获得救济，否则这个古玩交易市场就没法开了。

那前面那个祖传名画的例子为什么就可以撤销？注意，前面的例子是甲把祖传名画卖给乙，是**朋友之间的交易**，不是在古玩交易市场进行的交易，所以它不受这个限制。假如乙是到古玩交易市场里认准一幅名画想买，最后发现是赝品，这个时候按照交易习惯他就不能主张撤销了——**你既然敢逛这种市场，那就要玩得起。**

```text
        同一幅"名画是赝品"的事实
                      |
        ┌─────────────┴─────────────┐
   朋友之间私下成交              古玩交易市场成交
   （交易习惯不否定）            （各凭本事、运气）
        |                            |
  双方均可撤销                  依交易习惯不适用撤销权
```

### 欺诈：把"欺"和"诈"拆开看

先说术语。"欺诈"是一个标准的法言法语，要和**刑法中的诈骗**以及**生活中所说的欺骗**区分开来。

它的定义也是《民法典》总则编司法解释的明文规定，同样跟考试分析不一样，但还是建议按司法解释的规定记，因为它更准确、更权威。

这个概念包含两个方面的因素，还是要拆关键词。

**第一，"欺"的因素**，体现为**一方的行为**：故意告知虚假情况，或者**负有告知义务的人故意隐瞒真实情况**。一方要实施一个欺诈行为，这是第一个方面。

**第二，"诈"的因素**，体现为**后果**：要致使当时**基于错误认识而做出意思表示**。基于错误认识代表着意思表示存在瑕疵，被对方给"炸"了。

> **提示**：这两个因素是**同时要求**的。假如一方实施了欺诈行为，但另一方比较聪明，明察秋毫，知道你是在骗人，看破不说破，不和你一般见识，还是配合你完成了这个交易——事后他能不能以受欺诈为由主张撤销？**不能**。因为尽管一方有欺诈行为，但没有导致对方陷入错误认识，你的意思表示没有存在瑕疵，所以就不能基于受欺诈主张撤销。

从考试角度来讲，大家重点掌握的是**第一个要件**——欺诈行为的认定。

#### 积极欺诈：故意告知虚假情况

司法解释规定了两种欺诈行为：一种叫**积极欺诈**，一种叫**消极欺诈**，都是欺诈。先看积极欺诈，体现为**故意告知虚假情况**——以假充真、以次充好、以不合格产品冒充合格产品，那就是告知对方虚假情况来欺诈，对方可以撤销合同。

包括**伪称国产车辆是原装进口**，或者**回调代售车辆的公里数**。什么叫回调代售车辆的公里数？看一个例子：

甲以 23 万的价格将一辆机动车卖给乙，该车实际行驶了 8 万公里，市值是 16 万。但为了卖出更高的价格，甲通过技术手段回调了这个车辆的公里数，使里程表显示只行驶了 4 万公里。乙信以为真。事后乙知道真相，能不能要求撤销合同？**当然可以**。甲通过技术手段回调公里数，相当于告知对方一个虚假的情况——把一辆已经行驶了 8 万公里的车，伪装成只行驶了 4 万公里的车来出售，当然构成欺诈。

包括实践中存在的：饭店把**预制菜当成现成的菜**卖给顾客，这肯定也是一种欺诈行为。本来到饭店吃饭是因为在家里不想做饭，没想到饭店的厨师也不想做饭——所以这个世界啊，真的是一个草台班子。

> **理论拓展**：这里所称的"故意告知对方虚假情况"，一定指向的是一个**可以被查证的事实**，而不能只是一种**观点上的、夸张的表达**。
>
> 比如很多巧克力广告里的夸张表述，"吃了以后如此丝滑"。你买了以后发现没有那么丝滑，能不能说对方欺诈？不能。因为丝不滑只是一种主观感受，它不是一种客观事实。包括很多洗发水广告，明星或者模特洗完以后头发相当飘逸，某消费者买了以后发现飘不起来——因为后面没有吹风机，当然飘不起来。这时候能不能主张对方欺诈、撤销合同？**不可以**。因为广告常常会以夸张的表述体现一种主观感受来激发你的购物欲望，不是在告诉你一个客观上可以被核实的事实，所以它不适用欺诈。

这个领域有一个特别经典的案例，一定要讲：**教材里的例二，旺旺雪饼。**

有个哥们儿姓谢，叫谢某，有段时间非常不顺，喝凉水都塞牙。后来有一天他看电视，看到了旺旺雪饼的广告，终于知道自己问题出在哪了——因为旺旺雪饼的广告词是"吃了旺旺，运气会旺"。他突然想起来好几年没吃旺旺了，于是网上下单买了几箱，每天定时定量地吃。结果两箱吃完了，**人都长胖了，运气一点都没有变好**，于是他就去投诉这个旺旺雪饼，说欺诈消费者。

那这个广告里所称的"吃了旺旺运气会旺"，有没有欺骗期待？显然没有，因为这是广告给你营造的一种消费感受，它不是一个可以被查实的事实。但这个投诉到工商部门实际上也不是无理取闹：因为按照当时《食品安全法》的规定，怎么认定虚假广告呢？法条里面写的是虚假广告**不得有虚假的事实和夸张的表达**。尽管"吃了旺旺运气会旺"不能说是一个虚假的事实，但说它是一个夸张的表达，应该也不算冤枉。

但按照生活的常理，我们很难认定这样的行为是虚假广告或者是欺诈。所以因为这个事件，《食品安全法》专门启动了一次修改，把虚假广告的表述方式改了，**把"夸张的表达"这个表述给删掉了**——因为它不太合适，哪有广告不夸张的。所以你今天再看《食品安全法》关于虚假广告的描述，就只是说广告当中不得有虚假的事实，已经没有"不得有夸张的表达"那一项了。

这就是谢某的贡献。虽然他看起来是个很不靠谱的人，但他的这种较真，事实上促进了《食品安全法》的完善，促进了虚假广告认定标准的科学化。

#### 消极欺诈：负有告知义务的人故意隐瞒真实情况

消极欺诈体现为**故意隐瞒真实情况**——该讲的没有讲。在法律上也有可能构成欺诈，但这种"故意隐瞒"前面还有一个前缀：**负有告知义务的人**。

也就是说，在交易中，原则上交易情况当事人得自己去查明，你不能什么都指望别人告诉你；**只有负有告知义务的人隐瞒了这种情况的，才构成法律上的消极欺诈**。

怎么认定有没有告知义务？**根据法律规定、根据诚信原则、根据交易习惯**来认定当时有没有这个告知义务。

一个非常典型的例子就是**凶宅的买卖**。大家听过什么叫凶宅吧？注意，不是死过人的就是凶宅——**一定是发生过非自然死亡事件的，才能称之为凶宅**。因为生老病死是自然现象，只有非自然的死亡才会影响房屋的交易价值。

假如这个房子是凶宅，在买卖的时候要不要告知对方？**当然要**，因为发生过非自然死亡这个事实，会严重影响房屋的交易价值，实际上也会严重影响对方做出购买决定的真实性和真实性——如果对方知道，你再便宜人家也不会买。这是一个**积极的告知义务**。

那卖方能不能说："在协商签订合同的时候，你又没有问我；你要问我的话我就会告诉你，你要没问我的话，我干嘛要多此一举？"这个主张能不能成立？**不能成立**。按照诚信原则、按照交易习惯，你有主动告知的义务，你没告知，那就是欺诈。

包括**二手车的买卖**。假如这辆二手车曾经发生过重大的交通事故，甚至撞死过人，那这个车也会变成"凶车"。卖这个车的时候要不要积极告知对方？当然要。这也是基于诚信原则和交易习惯产生的告知义务。

教材里给了两个例子。第一个例子来自一部网剧叫《漫长的季节》，范伟演得非常好的一部剧，建议大家看一看。这部剧第一集的第一个场景就讲龚彪（秦昊演的），他从酒友王某手里买了辆出租车，想找好哥们儿王响（范伟演的）来显摆显摆。结果王响是个老手，他一看这个车就觉得有问题：**发动机泡过水，而且进行过大修**。但在卖这个车的时候，肯定没有把这个情况告知给龚彪。

那龚彪能不能基于受欺诈来撤销这个合同？**答案是可以的**。因为这辆二手车发动机泡过水、进行过大修，基于交易习惯、基于诚信原则，是不是你也得告知对方？因为它会影响这个标的的交易价格。你没有告知，那就构成欺诈——因为你有告知义务。

那反过来讲，如果基于法律规定、交易习惯、诚信原则，当时**没有**这个告知义务的，即使他隐瞒了一些事实，也不会构成欺诈。

第二个例子来自电视剧《繁花》。剧中林红搞一些小零售，她 260 块钱进了一条项链，然后 2600 块钱卖给自己的好闺蜜玲子；玲子更狠，能以 2 万 6000 块钱的价格卖给宝总。

考试版的表述是这样的：甲出售一款精美的珍珠项链，标价 2600 元，乙明知该项链系甲以原价买下（实际上进价只有 200 元）——甲隐瞒了进价只有 200 元这个事实。这算不算消极欺诈？就要看他有没有如实告知这个商品进价的义务。按照生活的一般观念、按照交易习惯，买卖双方当事人中，出卖人有没有告知给买受人进价的义务？**当然没有**，这是人家的商业秘密，要不的话怎么赚你的钱呢。

所以尽管他隐瞒了商品的进价，但因为他**没有告知义务**，这个行为不能构成欺诈。虽然在闺蜜之间你这么干有点不太靠谱，但在法律上他并没有可责难的地方。这就是告知义务存在的意义。

> **提示**：尽管商家没有告知义务，但如果商家**诚信地**把进价告知给消费者，那是道德水平比较高。比如胖东来，好多商品都明确告诉你进价、我赚你多少钱，都写得清清楚楚，不藏着不掖着——这道德水平高，所以人家胖东来做得好、诚信。但是即使别的商家没有公布这个进价，你也不能说人家在法律上有问题，因为本来就没有这个义务。我们也给胖东来点个赞。

#### 第三方欺诈：多一道"知道或应当知道"的门槛

因欺诈撤销具体分为两个方面。

**第一，当事人欺诈**——欺诈行为发生在交易的当事人之间。比如甲在和乙签订合同时对乙实施了欺诈，这时受欺诈方乙有权请求人民法院或者仲裁机构予以撤销。乙的意思表示存在瑕疵，法律给他救济的机会，这相对比较好理解。

**第二，第三人欺诈**——实施欺诈行为的人是交易双方以外的第三人。这一种是掌握的重点。

法律规定：第三人实施欺诈行为，使一方在违背真实意思的情况下实施民事法律行为，而**对方知道或者应当知道该欺诈行为的**，受欺诈方有权请求人民法院或者仲裁机构予以撤销。

什么意思呢？如果第三人丙对当事人乙实施了欺诈，那乙要签这个合同，是以乙的相对方（也就是甲）**知道或者应当知道**为前提的。换句话说，如果甲不知道、也不应当知道的，那即使乙受欺诈了，他也不能主张撤销合同。

看一个例子：

甲拟以 5 万的价格出售一块手表。甲的朋友乙发现该表是高仿品，但没有告诉甲。丙看见该表有意购买，乙为了让丙买下该表，对丙声称该表是绝版正品。丙信以为真，于是以 5.5 万的价格买下该表。

这个案例里，交易双方是谁跟谁？是不是甲把自己的表卖给了丙，**甲、丙是买卖合同的双方当事人**。签订合同时，是谁实施欺诈行为？是甲的朋友乙。所以乙不是买卖合同的当事人，**他叫第三人**，他对丙实施了欺诈。

那丙虽然是受欺诈方，他能不能主张撤销？取决于什么？取决于**和丙交易的相对方甲，对第三人乙的欺诈行为知不知情**。如果甲知道或者应当知道，丙就可以主张撤销；但如果甲对乙的欺诈行为不知情，丙就不能主张撤销。

```text
            甲（出卖人，5 万）
                  |
                  |  手表买卖合同
                  v
            丙（买受人，5.5 万）
                  ^
                  |  谎称"绝版正品"
            乙（甲的朋友，第三方）
            知道是高仿，但没有告诉甲

   丙能否撤销？  --->  取决于：甲是否知道或者应当知道乙的欺诈
                       甲不知情  -->  丙不能撤销
```

> **结论**：设置这样的规则是为了**保护甲的合法利益**。虽然第三人乙实施了欺诈、丙的意思表示确实存在瑕疵，但"是我跟你进行交易啊，你怎么能听第三人的呢"——假如我甲完全不知情，你丙要撤销合同，那对我甲来讲是不公平的。

这个现象在实践中还是比较常见的。比如各行各业中存在的**"托"**：一方直接欺诈另一方的话，一方面需要脸皮很厚、技术很高，另一方面是你在架（压）对方的时候，对方警惕性比较高，成功率就要低一些。但如果找一个看起来非常老实的托来配合，欺诈对方成功的概率是不是会更高？这个托就是第三人欺诈。

包括我们网购的时候，大家都不看商家提供的商品详情描述，都喜欢看**评价**——因为你觉得这个评价是第三人做出的，是比较客观的。但你有没有想过，评价里面也有**水军**？那好多好评，可能是花钱买来的。你以为评论区里的人跟你是一伙的，实际上人家有可能跟商家是一伙的。所以消费者买了一个商品本来很不满意，要发个评论吐槽一下的时候，先想想清楚：你确定那个跟你站在同一边的人，不是对面派来的吗？

> **承前启后**：上一节讲完「可撤销的民事法律行为：意思表示不真实时，法律给你一次反悔的机会」，下一节接着讲「可撤销的民事法律行为：意思表示瑕疵与撤销权」。

## 可撤销的民事法律行为：意思表示瑕疵与撤销权
> 对应块：BLK29 | 覆盖分集：P28下 | 块标题（分集名）：《第01编 第06章 第04节：可撤销的民事法律行》

### 第三人欺诈：五块钱换一条五星好评

先说一件我们都干过的事。买完东西，接到商家的电话："亲呀，货物收到以后体验如何呀？要给个晒图的五星好评的话，我们可以返你五元的现金哦。"

本来这个消费者是要吐槽、给差评的，但一看对方给得太多了——五块。你说让我怎么来评论？你写的那条评论，说实话就有可能对别人形成一种误导。

所以第三人欺诈在实践中也是随处可见的。包括我们在备考法硕的时候，有些同学特别喜欢去所谓的小某书上搜经验帖，那个经验帖有可能给你推荐去哪个地方学习，但有可能是托儿，有可能是水军——这都是欺诈的问题。

那接下来呢，是第三种适用情形：**胁迫**。

### 胁迫：一个要挟，换一份恐惧

先来看定义。胁迫也是一个标准的法言法语，它的定义是总则编司法解释的原文。尽管跟考试分析里写的不一样，我还是建议大家按照司法解释的规定来掌握。

> **提示**：不知道为什么，司法解释明明已经有明确规定了，考试分析还是想要用自己的话来描述一些定义。一方面不太准确，另一方面如果不太严谨，大家后期背的时候就很难背。你会发现，有逻辑、有规律的东西相对来讲是比较好背的，因为他可以举一反三；没有规律的、随便写的一句话，即使它再短，你背起来也会很难。所以大家掌握规范的定义。

> **定义**（胁迫）：胁迫是指一方以给自然人及其亲属的人身、财产或者其他合法权益造成损害，或者以给法人、非法人组织的名誉、荣誉、财产等造成损害相要挟，迫使对方基于恐惧心理作出不真实的意思表示。

这个胁迫实际上也是分为两个方面的要求：

- **第一，一方得有个胁迫的行为。** 注意法条里用的是"要挟"这个词——"要挟"里面的"挟"，体现为胁迫的行为；有写的写啊，就不是这个胁迫的"胁"了，是"挟天子以令诸侯"的"挟"。
- **第二，恐惧心理这个因素，体现一个结果**：迫使对方基于恐惧心理作出不真实的意思表示。

> **结论**：胁迫的核心，就是迫使对方基于恐惧心理而作出不真实的意思表示。这两个方面的关键词连起来，就形成了胁迫的定义。

你跟对方说："我这个房子，你要买下来；你要不买的话，我就杀你全家。"你看，以伤害别人的亲属作为要挟，对方是不是胆子比较小，有可能心生恐惧——我怕了你了，虽然不情不愿，但是还是签下了合同。是不是意思表示不真实？所以法律要给当事人撤销权来进行救济。

#### 要挟手段不合法，或者手段合法却用错了地方

从生活角度来讲，胁迫行为其实还是比较好认定的。我们从两个层次做一个学习的拆解。

要挟行为常常通过**不合法的手段**来进行。比如甲跟你说："你不买我的房，我就杀你全家"——你伤害别人，这肯定是不合法的手段；再比如甲跟乙说："你要不跟我结婚，我就把你的裸照放到网上去"——这叫披露别人的隐私，也是不合法的手段。那当然构成不法胁迫。

但关键在于，**有些要挟行为可能是基于合法的手段来实施的**。

比如以举报犯罪相要挟，这在实践当中非常常见。甲跟你说："你这个房子卖给我。"乙说"没门，想都别想"。这时候假如说我手里面有你贪污受贿的资料，你要不卖我的话，你等着瞧。

大家看，这时候乙有没有可能心生恐惧？有可能。那他基于恐惧心理而签订合同，也可以构成胁迫啊。

尽管你这个举报犯罪的手段是合法的——举报犯罪既是公民的权利，也是公民的义务——但是，举报他的犯罪，和你想要买他的房子，有没有关系？没有关系。既然二者没有关联，那就意味着法律不允许你通过举报别人犯罪的方式去干扰别人的交易自由。所以这样的行为也会构成不法胁迫。

> **易错点**：判断不法胁迫，不能只盯着手段本身违不违法。手段确实可能是不合法的，这个比较好认定；但手段也有可能是合法的，特别是举报犯罪相要挟。判断标准是：**举报的犯罪和你要实现的交易目的之间有没有直接关联**。有直接关联的，那就不是不法胁迫了；没有直接关联的，即便举报本身合法，仍然是不法胁迫。

#### 第三人胁迫：不需要相对人知情

接下来是第二个方面：因胁迫可撤销的具体情形。

首先，交易双方当事人之间，一方胁迫另一方的，那受胁迫方当然可以主张撤销了。关键在于，按照法律规定，除了一方胁迫以外，还包括第三人以胁迫手段使对方在违背真实意思的情况下实施民事法律行为的——受胁迫方有权请求人民法院予以撤销。

> **易错点**：第三人胁迫产生的撤销权，要不要像前面讲的第三人欺诈那样，需要对方知道、应当知道？**不需要。** 这恰恰是第三人胁迫和第三人欺诈的一个重大的区别。

举个例子。甲想把这块表卖给丙，在卖表给丙的时候，乙不是来欺诈，而是来胁迫甲——"不买的话，我杀你全家"。但是甲对此根本就不知情。那受胁迫方丙能不能撤销这个合同？答案是可以的。

尽管有可能使得甲的信赖利益遭受一定的损失，但是相对于甲的信赖利益来讲，法律认为每天生活在恐惧当中的丙，更有保护的价值，或者说保护的需求会更强烈一些。所以这个时候应当允许受胁迫方丙来行使撤销权。是不是跟第三人欺诈不太一样？

教材里面写了一个小例子，很形象。

车小花开设生活小超市，但是经营惨淡，整日愁眉不展。她爱慕着马壮壮，马壮壮要挟帅气的岳小帅，要求他必须每日在该店消费500块钱以上，否则的话将杀光其全家。岳小帅虽然很帅，但是胆子也确实小，他心生恐惧，于是每天去车小花的店里面进行消费。车小花呢喜出望外：一方面卖了货能赚钱，另一方面这么帅的岳小帅暗恋自己，那也是心中欢喜。

我们来看这个案例。交易双方当事人，一方是车小花，一方是岳小帅，每天都有消费行为。岳小帅的消费行为他不是自愿的，他是被谁给胁迫了呀？被这个马壮壮给胁迫了。

那假如后来马壮壮因为其他原因被抓起来了——因为不太靠谱嘛——那这时候岳小帅就不再恐惧了，突然之间勇敢起来了，因为他不再被威胁了嘛。于是他找到这个车小花说："我从你这里每天的消费都是被别人逼的，我是受胁迫的，所以主张撤销这些交易行不行啊？"

答案是行。尽管这个车小花可能根本就不知道马壮壮胁迫岳小帅实施交易行为，但是从法律角度来讲，有优先保证质利益，要优先保障整日生活在恐惧当中的岳小帅的利益。即使车小花对此不知情，也不影响岳小帅可以行使撤销权。这就是**第三人胁迫**。

> **提示**：有些同学会问，那马壮壮是咋想的呀？他喜欢这个姑娘，她天天自己去买东西不就完了吗？为什么还要胁迫别人？——一方面马壮壮自己没钱天天去消费；另一方面呢，即使有钱，他也觉得直接去买的话反而显得太直接了，不够含蓄。所以他胁迫别人去帮自己的女神。实践中也是有这种可能性的。

当然，无论是第三人欺诈还是第三人胁迫，如果符合条件，受欺诈方、受胁迫方撤销了合同，那是给别人造成损失的，是要承担赔偿责任的。

就前面这个案例，岳小帅可以请求撤销这一系列交易行为，从而保障他的意思自治能够得以实现。但车小花对这个胁迫是不知情的，所以这些交易撤掉以后，车小花肯定会很受伤，会遭受一些信赖利益的损失。那这是她的损失怎么办？她可以**请求第三人承担赔偿责任**——你给我闯的这个祸，你得赔我钱。

### 欺诈还是胁迫：灰色地带怎么分

刚才讲的欺诈和胁迫，因为有的时候二者之间还是有一些灰色地带的。

举个例子。某校长甲欲将一套住房以50万来出售，某报记者乙找到甲，出价40万想要购买，但是被甲拒绝了。这时候乙对甲提出："我有你贪污的材料，不答应我就举报你。"甲呢信以为真，以40万元的价格把这个房子卖给了乙。

那后来查明，乙实际上并没有甲贪污的材料——甲被乙给玩了。同时，甲在订立合同的时候意思表示真不真实？不真实，因为他本来是不愿意以40万的低价来卖这个房子的。

那关键是我们要判断：乙的行为构成的到底是欺诈还是胁迫？

> **结论**：欺诈和胁迫，都体现为当事人意思表示存在瑕疵的形态。所以要从**当时的意思表示存在什么瑕疵**作为出发点来认定：
> - **欺诈**——意思表示存在瑕疵，是因为**收到了错误的信息**而作出了错误的意思表示，就是被骗了；
> - **胁迫**——受胁迫方是**基于恐惧**而不得已作出了一个不真实的意思表示，是被别人要挟了。

> **提示**：遇到拿不准的情形，判断顺序就是：先问相对人是不是**基于恐惧**——是，就定胁迫；不是，再问是不是**基于错误信息**——是，就定欺诈。

要区分这个案例中的欺诈与胁迫，就看甲到底是因为**基于错误的信息**做出错误的判断，还是**基于新生的恐惧**而不得已签订的合同。非常明显，甲是因为心生恐惧，害怕别人去举报自己而签订的合同，甲他属于受胁迫的情形。

特别是这个甲，即使他有贪污的事实，是不是也和把房子卖给乙没关系啊？所以这个乙呢他依然属于不法胁迫，那甲可以撤销这个合同。

大家想想，当乙对甲说"我有你贪污的材料，你不答应我就举报你"的时候，这个甲自己到底有没有贪污，他自己心中有数。你要是没干这个违法乱纪的事情，你正不怕影子歪，你就不会被别人骗到。所以这个案例当中，甲是心虚了，心生恐惧，害怕这个乙把贪污材料举报到相关部门。所以甲属于受胁迫的情形。

那有人会问：不管是被骗了还是被胁迫了，后果不都是请求法院来撤销这个合同吗？有必要搞这么认真吗？

答案是**有必要**。因为考试会考，同时从法律角度来讲，构成欺诈和构成胁迫，他的后果有可能是有区别的。

- **第一，受害人不知情时的撤销条件不一样。** 比如甲乙在签合同的时候，不是乙去欺骗或者要挟甲，而是第三人丙站出来跟甲说："我有你贪污的材料，你如果不把这个房子40万低价卖给我的好朋友的话，我就举报你。"你看，如果认定这个丙的行为是胁迫，那不管乙知不知情，甲都可以撤销；但如果把丙的行为认定为欺诈的话，那甲行使撤销权就以乙知道或应当知道为前提了。这后果是不一样的。
- **第二，有些法律行为，欺诈和胁迫法律给予的规范模式是不一样的。** 比如在婚姻家庭编里面，只有因胁迫而成立的婚姻才是可撤销的婚姻，当时才有撤销婚的权利。那意味着如果因欺诈而成的婚姻，只要不是隐瞒重大疾病，这个婚姻依然是有效的。后果也会不一样。

比如甲呢喜欢上你了，然后希望跟乙结婚，但是乙不同意。甲跟乙说："我有你贪污的材料，你要是不跟我结婚的话，我就给你举报。"乙不得已跟甲结婚。如果认定甲的行为是胁迫，那乙是可以撤销的；如果认定甲的行为是欺诈，那乙就不能撤销这个婚姻。

所以这个欺诈和胁迫的区别，在法律上是有它的意义的：一个是**被骗了**，一个是**基于恐惧不得已做出意思表示**。

### 显失公平：主客观两个要件都得满足

接着看最后一种意思表示瑕疵的形态：**显失公平**。这个词呢，它也是一个法言法语。

> **定义**（显失公平）：一方利用对方处于危困状态、缺乏判断能力等情形，致使民事法律行为成立时显失公平的，受损害方有权请求人民法院或者仲裁机构予以撤销。

这个定义的认定，需要**同时满足主客观两个方面的要件**：

- **客观要件**：结果是显失公平的——双方的权利义务失去了平衡；
- **主观要件**：这个结果一定是**因为一方利用对方处于危困状态，或者缺乏判断能力等情形造成的**。

> **结论**：显失公平一定是主客观同时满足，缺一不可。

#### 危困状态：乘人之危被并进了显失公平

先说什么叫"利用对方处于危困状态"。

人这一生啊，难免有落难的时候。在你落难的时候，其实你的选择会受到极大的限制——因为你先得救急，先得度过这个危难的时期。如果别人利用你这个危困状态做交易，那就是一个不公平的交易，法律要给当时一个救济的机会。

实际上"利用对方处于危困状态"，我们在以前的法律当中叫做**乘人之危**。只是在制定民法典的时候，把这个乘人之危并到了显失公平当中。

举个例子。甲的父亲患癌症，急需用钱；乙趁机以低价来收购甲收藏的一幅名画，甲无奈和乙签订了买卖合同。

你看甲乙之间虽然有一个买卖合同，但是乙买到这个名画是以低价来购买的，代表着什么呀？代表着双方的权利义务并没有体现一个公平的状态。那是不是一方利用对方处于危困状态而形成的合同呢？答案是是的。甲的父亲患癌症急需用钱，是不是处于一个危困状态呀？那至少你乙没有施以援手就罢了，你还要趁机以低价来购买别人收藏的名画，是不是相当于趁火打劫？利用了对方这个危困状态，进而导致双方的交易权利失衡。那至少等甲渡过难关以后，法律还给甲一个机会，他可以请求撤销这个合同来收回自己的名画。

#### 缺乏判断能力：只有自然人适用

第二种情形是一方能利用对方**缺乏判断能力**。

这个"缺乏判断能力"，有的时候跟当时的年龄啦、阅历啦，包括对某个行业的熟悉程度等等有关——他可能对这种交易认识得不够清楚，缺乏判断能力。那如果对方利用了你这一点，签订的合同也是违反公平原则的，也可以通过显失公平来撤销。

那什么叫做缺乏判断能力？我们在合同的司法解释中做了专门的规定。

> **定义**（缺乏判断能力）：当事人在订立合同时缺乏判断能力，是指当事人在订立合同时**一方是自然人**，根据其当时的年龄、智力、知识、经验，并结合交易的复杂程度，能够认定其对合同的性质、合同订立的法律后果或者交易中存在的特定风险缺乏应有的认知能力。

> **易错点**：注意这个前提——**只有自然人**才能说自己缺乏判断能力。这意味着，法人、非法人组织尽管刚刚成立的时候，肯定也是新手、刚入行，对这个行业的险恶认识较浅，但是不能主张显失公平。法律认为，建立形成一个组织来在市场当中从事经营活动，那你就得有相应的判断能力。所以这个规定仅限于自然人可以适用。

尽管这个当事人他也是完全民事行为能力的——一方面年满18周岁了，另一方面精神也没问题——但是，我们国家在判断民事行为能力的时候只考虑这两个因素，而其他的因素啊，也有可能影响这个自然人的社会交往能力，所以就可以通过显失公平制度来给予救济。

教材例二。某银行的经理甲向文化水平较低的独居老人乙推销理财产品。这个理财产品的合同权利就比较复杂，而这个乙呢，他是个独居老人，而且文化水平较低，是不是显然对这种交易是缺乏一定的判断能力的？他不知道前面有什么万丈深渊等着他。乙因欠缺金融知识，以高昂的价格购买了实际收益极低的理财产品。

大家看在这个案例当中，乙能不能请求撤销这个合同？当然可以。因为一方面乙是缺乏判断能力的，基于他的年龄及教育水平，以及这种交易的复杂程度，我们很难指望一个文化水平很低的独居老人能够预判到理财合同里面潜在的风险；而实际的银行投资经理，也正是利用了这一点来给他推销产品。之前有些投资顾问，他就是打这种认知上的差异，给你去推荐这个产品。那这也可以基于显失公平为由来撤销该合同。因为他的意思表示不真实，他要知道真相的话，可能是不愿意签订这样的一个合同的。

#### 看着失衡，却不构成显失公平

教材例三是一个**不构成**显失公平的情形：虽然符合客观要件，但如果主观要件不符合——一方没有利用对方处于危困状态或者缺乏判断能力等情形的，那当时就不能主张显失公平。

烟酒专卖店门口立一块木板，"假一赔十"四个醒目大字——大家生活当中应该见过这样的标识吧。乙从该店购买了一瓶茅台酒，因为他觉得既然这个专卖店敢竖"假一赔十"的牌子，那想必这个商品是货真价实的。但是没想到，经鉴定后买到的茅台酒是假冒产品。于是乙就要求甲来履行假一赔十的承诺。

这个时候甲能不能说"我就卖给你一瓶假茅台酒，你让我赔偿十倍，你也太欺负人了"，因此而主张显失公平行不行？

答案是**不可以**。尽管卖一瓶假酒赔十倍，好像表面看起来权利并不平衡，但是在签订合同时，乙有没有利用甲处于危困状态或者缺乏判断能力来签这个合同啊？当然没有了。是不是甲自己打肿脸充胖子，自己主动做出的承诺啊？所以它不符合显失公平的主观要件，就不能主张显失公平。

> **结论**：既然你甲自己打肿脸充胖子，那法律就把你当胖子来对待，你活该。

#### 显失公平的特点

接着看第二个问题：显失公平的特点。这是一个理论问题，虽然看起来会比较务虚一点，但是它是一个**主观题的考点**，所以需要大家掌握这几点。

这个思路展开来是这样：

- **第一点，讲的是发生的原因**：一方要利用对方处于危困状态，或者缺乏判断能力等情形；
- **第二点，体现的是结果**：行为的结果对一方当事人来讲明显不利，而且对方取得了超出正常情况下的利益；
- **第三点，强调因和果之间是有关系的**：一方的实施行为并非其本意，意思表示存在瑕疵，是由于处于危困状态或者缺乏判断能力而导致的；
- **第四点**：这个不公平是法律所不允许的。

> **口诀**：因果关系，不公平就是显失公平——有因、有果、有关系，然后它不公平。

这四点大家简单了解就可以了。

到这里，可撤销民事法律行为的四种适用情形就齐了：重大误解、欺诈、胁迫、显失公平，都是法言法语。

### 撤销权归谁：看意思表示，不看谁吃亏

接下来说第三个问题：可撤销的民事法律行为的后果。后呢就是"可撤销"三个字。

先看第一个问题：撤销权人是谁？

可撤销，指的主要是意思表示存在瑕疵的地方。因为这个可撤销的民事法律行为，它主要是不符合要件里的**意思表示真实**——谁的意思表示不真实，法律就给谁撤销权来进行救济。

| 适用情形 | 撤销权人 |
| --- | --- |
| 重大误解 | 重大误解的当事人 |
| 欺诈 | 受欺诈方 |
| 胁迫 | 受胁迫方 |
| 显失公平 | 被显失公平受到损害的一方 |

> **结论**：谁的意思表示存在瑕疵，谁享有撤销权；而不是看谁在这个交易里面吃亏、受到的损失。

我们来看一个小案例。甲胁迫乙以100万的价格买下一套房屋，并办理了过户登记手续。此后因国家出台调控政策，这个房子啊暴涨至150万——也就这个甲，你聪明反被聪明误。后来甲不甘心，于是向法院提起诉讼，要求撤销这个买卖合同，理由说：一方面我有胁迫行为，另一方面现在房子暴涨至150万，我能直接亏了50万，我也主张撤销，行不行啊？

答案是**不行**。因为在胁迫的情形下，谁的意思表示存在瑕疵啊？是乙的意思表示存在瑕疵——他基于恐惧而作出不真实意思表示。你这个甲呢，签订合同时你的意思表示是真实的，所以只有乙享有撤销权，这个甲是没有的。

当然对于乙来讲，他可以选择撤销，也可以选择不撤销。交完钱一看，虽然当时买这个房子的时候非常不情愿，但是一下子涨了50万，非常开心，欣然收下，行不行啊？可以，他可以选择不撤销。那如果乙咽不下这口气，或者说房子再涨，他也不喜欢住在这个小区，他能不能选择撤销？当然是可以的。

> **结论**：法律把这个决定权交给了**意思表示存在瑕疵的一方**，而不是交给交易当中吃亏的一方。

### 形成诉权：不能靠一纸通知撤销

当事人取得这个权利以后，怎么来行使呢？

首先是通过**诉讼、仲裁**的方式来行使。所以这两项权利，我们称之为**形成诉权**。

- 撤销权是个**形成权**：基于一方的持续的意思表示，可以使得双方的法律关系归于消灭；
- 同时因为要通过诉讼或者仲裁的方式来行使，所以称为**形成诉权**。

> **易错点**：这意味着撤销权人**不能通过通知的方式**来撤销该合同。

既然是形成权，它也受到**除斥期间**的限制。因为基于一方的表示就可以使得双方法律关系发生变动，对方当事人处于一个法律关系极不稳定的状态呀，所以说你撤销不撤销，法律也给你设定一个期限，过了这个期限以后，对方才可以高枕无忧。

这个期间我们分成两个层次：第一个层次是主观期间，第二层次是客观上的最长期间。

#### 主观期间与客观最长期间

主观期间是基于当事人知道或者应当知道开始计算的，原则上是**知道或者应当知道撤销事由之日起一年**。这是原则性的规定。

这个地方还需要大家关注两个特别的规定。

**一是胁迫，这一年的起算时间不是"知道或者应当知道"，而是从胁迫行为终止之日起开始计算。**

因为有的时候，一方胁迫另一方，那受胁迫方他肯定是知道自己被胁迫了；但是有的时候呢，胁迫行为处于持续状态的话，这个受胁迫方他是很难有实际行使这个权利的可能性的呀，所以这个时候你不能计算这个时间，要从胁迫行为终止之日起开始计算。

就像前面车小花、岳小帅、马壮壮这个三角关系中的胁迫案例：马壮壮每天都胁迫岳小帅，岳小帅一直处于恐惧当中，而且他是被胁迫了的——但是只要马壮壮没被关进去，这个胁迫就属于一个持续状态，危险随时有可能发生。所以对岳小帅来讲，这一年期限又从什么时候起算呢？要从胁迫行为终止之日起算。比如说马壮壮被抓起来了，岳小帅的威胁才被解除，这个时候他才具备实际行使撤销权的可能性，才能够计算这一年的时间。

**二是重大误解，这个期间只有90日。** 这一点一定要特别注意。虽然它同样是从知道或者应当知道之日起算，但是只有90天。

为什么其他情形都是一年，而重大误解是90天？

> **结论**：欺诈、胁迫、显失公平，它属于**意思表示不自由**的情形，是你的意思表示受到了对方的不当干扰、受到了外界的不当干扰，你是**被欺负的一方**，所以法律给你的时间要长一些。而重大误解体现的是**意思表示不一致**，常常体现为这一方当事人自己的问题，所以法律给你的时间就会短一些——这样也可以保护相对方的信赖利益。

第二层次是**客观上的最长期间**，是从民事法律行为发生之日起开始计算的，要计算5年。这意味着不管当事人知不知道、结果如何，这个行为发生满5年了……

```text
  [客观最长期间]
         │  自民事法律行为发生之日起算, 5 年
         │
         │  自知道或应当知道撤销事由起算
         │
         ├─ 主观期间: 1 年 ──► 届满, 撤销权即归于消灭
         │     重大误解: 仅 90 日
         │     胁迫:     自胁迫行为终止之日起算
         │
         └─► 先届满者胜: 任一期间届满, 撤销权即归于消灭
```

比如甲呢对乙实施欺诈行为，这个合同签订以后啊，都4年半了，乙才知道自己被欺诈了，这时候他要行使这个撤销权还有多长时间啊？尽管从主观期间角度来讲是知道或应当知道之日起一年啊，但是因为已经过了4年半了，距离最长期间届满只有半年的时间了，所以乙只有半年的时间来行使这项权利。

那如果乙是在3年半的时候发现被欺诈了呢？这个时候他有一年的时间——知道或应当知道之日起一年还在最长期间内，所以有一年。有些同学说这个时候5年还没到呀，所以客观期间没到；但是呢，主观期间先到了，那也会导致这个权利归于消灭。

> **结论**：主观期间跟客观期间，哪个先到，都会导致撤销权归于消灭。

#### 撤销权的两种消灭情形

撤销权作为一种形成权，怎么消灭？两种情形。

**第一，除斥期间届满**，那这个权利当然就归于消灭了。

**第二，当事人知道这些情况以后，明确表示或者以自己的行为表明放弃撤销权**，那撤销权也可以放弃。

明确表示比较好理解。就像我们前面讲到的欺诈或胁迫等情形，撤销权人可以选择撤销，也可以选择不撤销，如果他明确表示，或者以自己的行为表明他要放弃这个权利了，那这个权利也会归于消灭。

那什么叫"通过自己的行为来表明放弃撤销权"？比如甲呢胁迫乙来买下自己的房子，签订合同以后，乙享有撤销权。但是乙觉得这个房子啊买得还是挺值的，于是他请求甲履行合同——"请你交付房屋，办理房屋的过户手续"。你看，从这个乙请求甲履行行为的举动来看，他是不想要这个合同了，他希望维持这个合同的效力，那撤销权也会被消灭。

### 撤销之后：一切回到从前

假设撤销权人依法行使了撤销权，那会使得民事法律行为**自始没有法律约束力**。就一切回到从前了，等于双方当时没有签过这个合同。

### 本讲提到的题目

#### 2024年真题：第三人胁迫，受胁迫方能否撤销

甲在乙胁迫下将首饰低价卖给了丙。丙对甲被胁迫一事毫不知情。

**问**：甲能否撤销该合同？

**解析**：这里涉及到三方当事人，首先要确定交易双方当事人是谁——是甲呢把自己的首饰卖给了丙，所以交易双方是甲与丙；而在合同订立过程中，乙对此实施了胁迫，对甲实施了胁迫，所以乙是第三人的身份。大家一定要把这个法律关系搞清楚，否则规则就白掌握了。甲呢属于受胁迫方，他在撤销这个合同的时候，需不需要考虑相对方丙知不知情？**不需要。** 第三人胁迫产生的撤销权，不以相对人知道或应当知道为前提。所以这个"丙毫不知情"啊，它就是个陷阱、迷惑信息。

**答案**：选 C，即甲可以撤销该合同。

#### 理论拓展问题：到底构成欺诈还是胁迫

某校长甲欲将一套住房以50万来出售，某报记者乙找到甲出价40万想要购买，但是被甲拒绝了。这时乙对甲提出："我有你贪污的材料，不答应我就举报你。"甲信以为真，以40万元的价格把这个房子卖给了乙。后来查明，乙实际上并没有甲贪污的材料。

**问**：乙的行为构成欺诈还是胁迫？

**解析**：意思表示瑕疵的出发点是"受到了错误的信息"还是"基于恐惧"。这个案例当中非常明显，甲是因为心生恐惧、害怕别人去举报自己而签订合同的，所以甲属于受胁迫的情形。而且即使甲真的有贪污的事实，也和把房子卖给乙没关系，所以乙依然属于不法胁迫。

**答案**：构成**胁迫（不法胁迫）**，甲可以撤销这个合同。

#### 小案例：撤销权人是谁

甲胁迫乙以100万的价格买下一套房屋，并办理了过户登记手续。此后因国家出台调控政策，该房屋暴涨至150万。甲向法院提起诉讼，要求撤销这个买卖合同，理由是：一方面自己有胁迫行为，另一方面现在房子暴涨至150万，自己直接亏了50万。

**问**：甲能否撤销？乙又该怎么选？

**解析**：撤销权人是意思表示存在瑕疵的一方。胁迫情形下，瑕疵在乙的意思表示上——他是基于恐惧而作出不真实意思表示；甲的意思表示是真实的，所以甲没有撤销权。

**答案**：甲**不能**撤销。乙可以自由选择——可以撤销，也可以不撤销（一下子涨了50万，非常开心，欣然收下）。法律把决定权交给了意思表示存在瑕疵的一方，而不是交易中吃亏的一方。

#### 小案例：撤销权还能不能行使

甲在首饰店购买钻石戒指两枚，标明该钻石为天然钻石。甲买回以后被人告知是人造钻石——意味着什么呀，被骗了。甲多次和首饰店交涉，历时一年零六个月未果。现在甲以受欺诈为由请求撤销该合同，法院支不支持？

**解析**：固然甲是基于受欺诈而签订的合同，意思表示存在瑕疵，但是因为双方交涉一年六个月，是不是假如早就知道被欺诈了，那他在一年内没有行使撤销权的，权利就归于消灭了。

**答案**：**不支持。** 主观期间一年已经届满，撤销权消灭。这样的话，法律就可以保护已经形成的交易秩序了——不能老是回过头去算旧账，要往前看，别回头哈。

#### 案例分析题：标价错了能不能算显失公平

某网店销售某白酒，这个白酒呢价值8万块钱（也不知道什么酒值这么多钱），然后在标价的时候，因为工作人员的失误标成了8000。某个消费者呢是识货的，他觉得这个酒好便宜，赶紧下单购买。后来呢被这个网店的老板给发现了。

**问**：他能不能以显失公平为由请求撤销这个买卖合同？

**解析**：尽管8万的酒被8000块钱拍下，好像双方的权利失去了平衡（客观要件符合），但这个结果是不是乙利用甲处于危困状态或者缺乏判断能力造成的呀？那显然不是，所以不符合主观要件。这是一个与标价错误相关的考点。

**答案**：**不能**，不构成显失公平。

#### 真题：下列属于可撤销民事法律行为的是

下列选项中属于可撤销民事法律行为的是：

- A. 甲将租赁的一辆汽车转让给乙
- B. 甲在某网店购得国家禁止销售的窃听器
- C. 某公司误将甲当成乙而与之签订委托合同
- D. 甲谎称未婚，乙信以为真与之结婚

**解析**：就是判断有没有存在我们前面讲过的意思表示瑕疵形态。

A 项：没有意思表示瑕疵形态，所以不选。尽管甲欠缺对这个汽车的处分权，但是在我们国家民法中，无权处分不影响合同的效力，它只影响相对方能不能取得这个标的的所有权。

B 项：什么叫禁止销售？违反了强制性的规定，这个合同是无效的合同。

C 项：什么叫误将甲当成乙呀？就是因为对对方当事人存在一个错误认识，构成重大误解，可以撤销。

D 项：尽管这里面好像有个欺诈行为，但一方面在婚姻家庭编里边，一般的欺诈行为常常不会影响婚姻效力；同时这个"谎称未婚"意味着他已经结婚了，他再和别人结婚的话，那就构成重婚了，而这个重婚是违反一夫一妻原则的，应当认定是无效的婚姻。所以这一项也不能选。

**答案**：**C**。

## 效力未定的民事法律行为：一份等着别人点头的合同
> 对应块：BLK30 | 覆盖分集：P29 | 块标题（分集名）：《第01编 第06章 第05节：效力未定的民事法律》

效力瑕疵这一章里，"无效"和"可撤销"我们已经讲过了。接下来要讲的这一种形态特别有意思——它既没有被直接判死刑，也没有把命运交给相对人，而是悬在半空中，等另一个人表态。

它叫效力未定。先看一个例子，把这个感觉建立起来。

### 十四岁少年的一箱茅台酒

张某，女，一子张甲，14 周岁，初二学生。14 周岁意味着什么？意味着张甲是一个限制民事行为能力人。张甲因为缺少零花钱，把家中茅台酒一箱，以 5000 块钱的价格出卖给了乙。

这里有个买卖合同，出面的是张甲，买方是乙。可张甲是个限制民事行为能力人，他能不能实施出卖一箱茅台酒这样的交易？显然不能——一方面不是纯获利益，另一方面和他的年龄、智力也不相适宜。既然这个主体欠缺相应的民事行为能力，那这个合同的效力肯定存在瑕疵。这样的瑕疵，我们就叫效力未定。

那"效力未定"具体体现在哪儿？体现在这个合同能不能发生效力，要取决于张甲的法定代理人张某的态度。

```text
            张甲（14 周岁 · 限制民事行为能力人）
                            │
              卖家中茅台酒一箱，价 5000 元
                            │
                            ▼
                       乙（买受人）
                            │
             合同是否发生效力？——看法定代理人张某
                            │
        ┌───────────────────┴───────────────────┐
        ▼                                       ▼
 张某觉得太便宜了：                    张某觉得：5000 块卖掉
 "起码得卖 5 万"                        也没什么不行
        │                                       │
        ▼                                       ▼
    拒绝追认                                  追  认
        │                                       │
        ▼                                       ▼
  合同不发生效力                        合同发生效力
```

一句话读图：同一份合同、同一箱酒，因为张某的一个念头而走向两个完全不同的结局。这就是"效力未定"——它可能走向有效，也可能走向无效，现在到底走向何方，还不太确定。

### 概念里的三个关键词

效力未定这个概念，其实只有三个关键词：**前提、起因条件、后果**。

**前提**是：民事法律行为已经成立。只有已经成立的行为，才有资格被判断效力。

**起因条件**是：欠缺某个要件，主要是主体资格这个要件。这一条教材里其实没有写出来，大家可以自己把它补充上，这样逻辑会更完整。

**后果**是：效力未定。教材用两句话来描述它——第一句，现在能否发生效力尚不确定；第二句，将来怎么确定，要有待享有形成权的第三人，通过追认或者拒绝的意思表示来确定其效力。追认，合同就发生效力；拒绝，合同就不能发生效力。

> **定义**：效力未定，又叫效力待定——这两个词是完全一样的意思。考试分析里用的是"效力未定"，法硕真题里基本用"效力待定"，说的是同一回事。它是指：民事法律行为已经成立，但欠缺某个有效要件（主要是主体资格），导致效力处于不确定状态，须由享有形成权的第三人以追认或拒绝的意思表示来确定其效力的民事法律行为。

考试分析的编写者在这儿偷了个懒，把"起因条件"这一句给省掉了。但大家把它补完以后，整个概念的逻辑链条才是完整的：前提、起因、后果，一个不缺。

顺着这个思路往下展开，就得到四个特征——四个特征恰好对应三个层次关键词，只是"后果"这一层里出现了两个关键词，所以拆成了两条。

| 特征 | 内容 | 对应的关键词 |
| --- | --- | --- |
| 第一个特征 | 民事法律行为已经成立 | 前提 |
| 第二个特征 | 主要是因为欠缺民事行为能力或者代理权所致，即主体不合格 | 起因条件 |
| 第三个特征 | 效力如何处于一个不确定的中间状态 | 后果之一：尚不确定 |
| 第四个特征 | 将来有待于其他行为或者事实来确定，主要是有待于享有形成权的第三人来决定 | 后果之二 |

前两个特征是一眼可见的：第一个对应"前提已成立"——行为都已成立了，才谈得上效力未定；第二个就是起因条件，无论欠缺的是民事行为能力还是代理权，归根结底都是主体不合格。第三、第四个特征从后果里拆出来：现在到底能不能发生效力，处于一个不确定的中间状态；将来怎么定，有待于享有形成权的第三人来决定。这个思路，非常清晰。

### 适用情形：瑕疵都出在主体身上

效力未定主要适用于主体不合格的行为。所谓主体不合格，无非两个方面：**欠缺相应的民事行为能力**，或者**欠缺代理权**。

#### 限制民事行为能力人自己签的合同

先说第一种。我们知道，限制民事行为能力人只能实施两种行为：一个是纯获利益，另一个是与他的年龄、智力相适应。如果他实施了其他行为，那就不具备相应的民事行为能力了，这样的行为就是效力未定的行为。

举个例子：甲 11 周岁，擅自通过手机在某游戏网站充值了 3 万块钱。假如这个网站之间存在一个游戏充值的合同关系——非常明显，甲有没有充值 3 万元的民事行为能力？显然没有。所以这个合同是一个效力未定的合同。能不能发生效力，由甲的法定代理人，也就是父母来决定。父母追认的，合同有效；父母不追认的，合同就不能发生效力。

> **易错点**：既然欠缺民事行为能力，那为什么不干脆直接宣告这个合同无效？注意，效力未定和无效之间有个很大的区别——它**保留了让这个合同有效的可能性**。
>
> 假如甲的父母不认可这个行为，合同不能发生效力，这跟无效其实没什么本质区别。但是，如果父母觉得自己的孩子打游戏打这么好、很有天赋，花 3 万块钱支持一下孩子的兴趣和天赋是没问题的，这个钱也花得起——那显然没有必要简单粗暴地认定合同无效，是不是也可以允许这样的交易成立并生效？
>
> 所以效力未定实际上是把决定权交给民事主体，让他自己来决定。这里体现的，正是民法尊重当事人意思自治的价值观。

#### 无权代理：以别人的名义签合同

再说第二种情形：欠缺代理权，也就是无权代理。

什么叫代理权？代理权就是**以别人的名义实施民事法律行为的权利**。

举个例子。甲公司是一个保险公司，它当然可以自己去卖保险、跟别人签订合同；但是为了扩大业务范围，甲公司有可能会授权一些保险代理人来帮它卖保险。假如乙获得了授权，可以甲公司的名义去卖保险，那乙就享有一个代理权——乙把保险卖给别人，后果是要由甲公司承担的，因为你授权乙以你的名义来卖保险。

但是，假如这个乙根本没有经过任何授权，就是单纯地热爱保险事业，就以甲公司的名义把保险卖给了丙。这个时候，乙在签订合同时欠缺代理权，他的主体存在瑕疵——这就是**无权代理**的行为，它同样是效力未定的合同。只有经过保险公司、也就是甲公司的追认，才能发生效力。

甲公司说："你主动用我们公司的名义来卖保险，还多了一单吗？何乐而不为？"于是进场追认——可不可以？可以。那就在甲公司和丙之间形成一个保险合同。

甲公司也可以说："你乙也配卖我们的保险啊？太不靠谱了。"于是选择拒绝追认——可不可以？也是可以的。把决定权交给被代理人甲公司，这就是无权代理效力未定的情形。

教材里还给大家写了一个案例，来自于一部非常好看的电视剧——《藏海传》。藏海成为侯爷的幕僚以后，好多人都给他送礼、来巴结他。他不想收这个礼，但又不知道是谁送的，没办法退还给别人。于是他想了个办法：他都没有经过许可，就擅自以侯爷（庄鲁隐）的名义，向穷困的百姓来施粥。

这个场景大家看过吧？藏海把这个粥送给百姓，是**以谁的名义**？是以侯爷的名义。但是他没有经过授权，所以他就是一个无权代理行为。如果侯爷觉得藏海太靠谱了，认可这个行为、点头表示追认，那这个行为也会对侯爷发生效力。这是一个无权代理被追认的行为。

这就是效力未定民事法律行为的两种适用情形——都是主体层面的瑕疵：要么欠缺民事行为能力，要么欠缺代理权。

#### 拓展一下：无权代理和无权处分的区别

这是一个非常容易混的理论问题，我们通过两个例子来把它彻底分开。

先搭一个模型：甲有一部手机，借给乙来使用；乙未经许可，就把这手机卖给了第三人丙。在这个模型之下，乙在卖手机的时候，可能是以甲的名义卖的，也可能是以乙的名义卖的。差别就在这里。

**例一**：乙谎称是经过甲的授权，以甲的名义把手机卖给丙。这个行为我们称之为**无权代理**。因为要以别人的名义来签合同，你得取得代理权；乙没有取得代理权就以甲的名义来签合同，这叫无权代理。

**例二**：乙谎称手机是自己的，以自己的名义把这手机卖给丙。这个叫**无权处分**。首先，乙有没有资格以自己的名义来签合同？当然有。他欠缺的是对这部手机的**处分权**——手机不是你的，你没有资格处分，所以这叫无权处分。

> **结论**：无权代理与无权处分的区别，就在于**是以谁的名义实施行为**。以别人名义实施而欠缺代理权的，构成无权代理；以自己名义实施而欠缺处分权的，构成无权处分。

那这两个合同的效力如何？

| | 无权代理（以甲的名义） | 无权处分（以乙的名义） |
| --- | --- | --- |
| 合同上的当事人 | 甲、丙 | 乙、丙 |
| 合同效力 | 效力未定 | **有效** |
| 理由 | 合同上显示的当事人甲根本没有授权签这个合同，能否发生效力取决于甲有没有去追认 | 它完全符合民事法律行为的有效要件：主体合格（乙可以自己的名义签合同）、意思表示真实（他真的想卖这部手机）、内容也不违反强制性规定 |
| 后续处理 | 甲追认则发生效力；甲不追认则不发生效力 | 只是因为乙欠缺处分权，所以不一定能把手机所有权转移到丙手中，但这是物权变动的问题，跟合同有效无效没什么必然联系；即使后来甲不追认，也不影响乙和丙所签合同的效力，只是丙不能取得手机所有权，乙要向丙承担违约责任 |

所以要记住一句话：**无权处分是合同效力上的规范问题**。合同有效，物权变动是另一回事。

### 法律后果：追认，以及相对人的反击

效力未定的后果就是一句话：可能走向有效，也可能走向无效。为了方便大家理解这套规则，我们建构两个模型，分别对应两种适用情形。

**模型一（欠缺民事行为能力型）**：甲一是限制民事行为能力人，他和一个乙一签订了一个超出自己行为能力范围的行为，这个行为就是效力未定的。它最终能不能发生效力？取决于甲一的法定代理人丙一的意思。

**模型二（欠缺代理权型）**：甲二没有经过丙二的同意，就以丙二的名义来和乙二签订一个合同，欠缺代理权，这个合同也是效力待定的。它最终能不能发生效力？取决于被代理人丙二的意思。

两个模型建构起来，都涉及三方关系。

#### 追认：走向生效的唯一途径

什么样的民事法律行为可以走向生效？唯一的途径就是**追认权人进行追认**。

追认权现在属于**形成权**。我们在前面讲民事权利分类的时候，在形成权部分提到过追认权的概念：如果丙一或者丙二行使追认权，会使得之前效力未定的合同最终发生效力，所以它具有形成权的性质。

既然是形成权，丙一也好、丙二也好，在行使追认权的时候，基于自己一方的意思表示就可以成立，所以它属于**单方民事法律行为**。还记得这个词吧？讲民事法律行为分类的时候我就提到过，行使形成权的行为都属于单方行为，追认权也是一样。

那么要确定一下：谁在行使这个追认权？

- 如果实施行为的人是甲一这样的限制民事行为能力人（模型一），追认权人就是他的法定代理人，也就是丙一。
- 如果实施行为的人是甲二这样的无权代理人（模型二），追认权人就是被代理人，也就是丙二。

**追认通过什么方式作出？**要通过意思表示的方式来作出。尽管追不追认，丙一也好、丙二也好，可以单独决定，是单方行为；但这个意思表示得向谁作出？得向甲一或者乙二作出。所以它是一个**有相对人的意思表示**。

- 通过**对话方式**作出的，比如当面跟乙说"我要追认"：这个意思表示在相对方知道其内容的时候发生效力，这叫**知道主义**。
- 通过**非对话方式**作出的，比如给对方发一个微信、或者发一个律师函：意思表示**到达**相对人时发生效力，采取的是**到达主义**的立法模式。

这跟我们前面讲的意思表示的生效规则是一样的。明确的方式做出没问题，默示的方式做出实际上也没问题——你可以主动履行这个合同。

> **易错点**：能不能通过**沉默**的方式作出追认？**不可以**。如果追认权人未作表示的，视为拒绝追认。所以追认不能通过沉默的方式作出。

#### 追认之后，合同对谁生效

这一点上，两个模型是存在区别的。

- **模型一**：如果是限制民事行为能力人甲一实施行为的，被丙一追认以后，这个合同对**甲一和乙一**发生效力——他俩是合同当事人。
- **模型二**：如果是无权代理人甲二实施行为、被代理人丙二追认的，这个合同对**丙二和乙二**发生效力——他俩才是合同当事人，甲二自己可不是。

#### 相对人的催告权与撤销权

赋予丙一或者丙二追认权，是保护了丙一和丙二的利益。但这时候法律得考虑保护相对人的合法权益，也就是模型当中的乙一和乙二。法律把追认权赋予丙一或者丙二，是不是使得相对人处于一个被别人决定命运的状态、只能看丙一或丙二的脸色？

所以法律也得考虑保护乙一或者乙二的合法权益，为此赋予了相对人两项权利。

**第一项权利是催告权。**相对人可以催告追认权人：到底追不追认？赶紧给个痛快话，尽快把这个法律关系给确定下来——这就叫行使催告权。但这个催告属于哪一种民事法律事实？它属于**准民事法律行为**。还记得这个词吧。

**第二项权利是撤销权。**在被追认之前，善意相对人有一个通知撤销合同的权利。因为在被追认之前，合同处于被别人决定命运的状态；至少法律给他一个机会主动出击、先下手为强："我不管你追不追认，反正我是不干了。"可以选择，完全可以。

但这个撤销权的形式得符合条件：

1. **只有在被追认之前才能行使。**假如丙一、丙二已经行使追认权，合同已经发生效力了，那这个相对方就不能再撤销。
2. **只有善意的相对人享有撤销权。**什么叫善意的相对人？相对方不知道、也不应当知道对方是限制民事行为能力人或者无权代理人。假如乙知道甲一是未成年人、乙二是无权代理人，你就不是善意的相对人，你就没有撤销权了。
   > **提示**：但是，即使是知情的相对人，**仍然享有催告权**——只有撤销权才受善意的限制。
3. **以通知的方式行使。**我们在前面讲可撤销的民事法律行为时，也讲过撤销权；但那个撤销权要以**诉讼和仲裁**的方式来行使。而这里，善意相对人的撤销权要通过**通知**方式行使。
   > **易错点**：同样叫"撤销权"，这两个制度之间**没有任何关系**——它们就是名字一样而已。就像你生活当中两个人重名了，能说他们就一定是亲戚吗？当然不能了。

通过这样一个制度设计，一方面保护了追认权人的利益，另一方面也兼顾了相对人的利益。民法是要平衡各方当事人利益的——手心手背都是肉，都得考虑。

到这里，效力未定的民事法律行为就讲完了。法律要求我们掌握的无非就是三层：**概述**（含义与特征）、**适用情形**、**法律后果**。

### 本讲提到的题目

#### 关于未成年人几笔开销的效力判断

2015 年单选题。

甲，16 周岁，无业，依靠父母来生活——这意味着他是一个限制民事行为能力人。某日甲向朋友乙借款 2 万元，用其中的 1 万元买了名牌包送给男友，用 200 块钱给自己的手机充值，用余款购买了一张美发店的消费卡。请判断合同效力。

消费卡花了多少钱？2 万减 1 万再减 200，是 9800 块钱——这个生活还是挺奢侈的。

原题以这四项行为的效力判断作为选项，我们逐项看：

**借款 2 万元的行为。**甲有没有这个行为能力？显然没有，所以它是**效力未定**的合同——不是无效。这一项判断错了。

**用 1 万元买名牌包送给男友的行为。**甲有没有这个行为能力？答案也是没有的，因为 1 万块钱太贵了，跟他 16 周岁无业靠父母供养的身份不相适应。当然，即使甲欠缺民事行为能力，会不会直接导致这个赠与合同无效？不会的，它是**效力未定**的。假如甲的父母一看："你这个小男友不错，买个包送给他，我们支持。"这个时候赠与合同就可以成为有效的合同了。

**给手机充值 200 元的行为。**给手机充 200 块钱，交易风险比较小，标的额也比较小，我们一般认为甲 16 岁了，他是有这个行为能力的，所以这个合同是**有效**的。这一项判断错了。

**购买 9800 元美发消费卡的行为。**甲显然欠缺购买 9800 块钱美发卡的民事行为能力，所以是**效力待定**的。这意味着甲的父母如果觉得这个消费卡还是物有所值，可以选择追认这个合同，使之发生效力。

> **答案**：D。

#### 伪造公章签合同后相对人的权利

2024 年单选题。这道真题改编自自己的新闻案例，就是老干妈和腾讯那个案子。

甲用伪造的 A 公司的公章，以 A 公司的名义，和不知情的 B 公司签订了产品推广合同。关于该合同，下列说法正确的是：

- A．A 公司追认之前，B 公司有权通知 A 公司撤销合同
- B．A 公司追认以后，B 公司有权通知 A 公司解除合同
- C．无论 A 公司是否追认，B 公司均有权请求甲来履行合同
- D．无论 A 公司是否追认，B 公司均有权请求法院来撤销合同

先定性：甲用伪造的 A 公司公章，意味着他没有经过 A 公司的授权，就和不知情的 B 公司签订了产品推广合同——这是一个典型的**无权代理**行为。既然是无权代理的合同，那就是**效力未定**的。

**A 选项：对的。**效力未定的合同在被追认之前，善意的相对人 B 公司当然有通知撤销的权利。而且 B 公司是不知情的，是善意的。

**B 选项：错的。**一方面，追认以后这个合同就已经发生效力了；另一方面，人家相对人 A 公司并没有违约行为，你当然不能解除。**解除跟撤销是不一样的。**

**C 选项：错的。**如果 A 公司进行追认，B 公司只能向 A 公司主张履行，因为合同的当事人是 A 公司，而不能请求甲来履行。但如果 A 公司拒绝追认，这个合同对 A 公司不发生效力，按照民法典的规定，这个时候善意的 B 公司可以请求无权代理人甲来履行（这一点我们后面讲代理制度时会讲到）。所以 C 选项里"无论"两个字是错的。

**D 选项：错的。**如果 A 公司追认了合同，善意相对人 B 公司就没有撤销权了，所以不能"无论是否追认"都有权请求法院撤销。

> **答案**：A。

## 无效：被法律直接打不及格的那一种效力
> 对应块：BLK31 | 覆盖分集：P30上 | 块标题（分集名）：《第01编 第06章 第06节：无效的民事法律行为》

无效也是民事法律行为的效力，是效力瑕疵的一种。学它跟学前面那些一样，还是三个方面：先讲概述，再讲适用情形，最后讲法律后果。这一讲我们把前两个层次过完，第三个层次的法律后果，放在后面的内容里单独处理。

### 先拿一笔买卖试试水温

在拆概念之前，先给大家一笔交易感受一下什么叫"无效"。

李四是个吸毒者。张三和李四做买卖，达成一个交易，约定价款3万元。

这笔交易里头有两件事要分开看。第一件是：双方意思表示达成一致了，合同关系成立，**成立**这一关它是过的——你不能说它没成立。没成立的东西压根轮不到谈效力，"只有成立的行为才有资格被判断效力"。

第二件是：这个交易是法律禁止的。突破了社会的底线，内容不合法。内容不合法是什么后果？法律直接打不及格。

所以无效最直观的画面就是这句话：**合同成立了，但是无效。**

> **结论**：无效是效力瑕疵中最严重的一种类型——法律对当事人的民事法律行为效力完全不认可，等于被法律判了个不及格。

### 三个关键词，撑起"无效"这个概念

回到教材上对无效的定义，它也是从三个关键词来描述的。**前提、起因条件、法律后果**。这个三段式大家要熟悉，后面每一块内容都从它长出来。

**第一个词：适用前提。**强调的是民事法律行为**要已经成立**。哪怕是一个无效的行为，它也是一个已经成立的行为。这一层不是废话，它把"不成立"和"无效"彻底分开：合同没签成是不成立，签成了但违法才叫无效。

**第二个词：起因条件。**指的是**严重欠缺要件**。请你咬住"严重"这两个字。欠缺不严重，法律不至于一票否决；之所以要直接打不及格，就是因为欠缺得够狠。回到刚才那笔买卖：双方之间的内容是违法的，违反了法律的强制性规定——这就是严重欠缺。

**第三个词：法律后果。**无效两个字体现为：**不能按照当时的预期来发生效力**。

这里"预期"这个词极其关键。什么叫不能按预期来发生效力？看刚才那笔买卖：张三签合同的预期是什么？希望从李四手里拿到3万块钱的价款。法律判无效以后，这3万他拿不到了，预期落空。李四签合同的预期呢？希望从张三手里拿到那批货，判无效以后他也拿不到，预期同样落空。

> **提示**：无效**不等于**没有法律后果。恰恰相反，它照样有法律后果——要返还财产、要赔偿损失。它只是说，**不能按照当时的预期来产生后果**，你的意思自治意图实现不了。

三个词连起来写，就是无效的民事法律行为的概念。到这儿你回头再看刚才那笔买卖，成立、内容违法、预期落空、但财产要返还，一整条线全串上了。

### 四个特征：绝对确定，自始当然无效

概念说完说特征，特征也是拆关键词。

**特征一：无效的行为具备成立要件，但是严重欠缺要件。**注意这个表述——它是"既有前提，也有起因"，直接对应概念里的前两个关键词。行为成立了，要件也审查了，但是严重欠缺，所以效力归零。

**特征二：无效的行为不能发生当事人预期的法律后果。**这一条对应概念里的第三个关键词。教材用四个字来描述这个结果，这四个字你必须张口就来：

> **绝对确定、自始当然无效。**

这四个字是分两层递进的：

| 四个字 | 说的是什么 | 讲的是哪一头 |
| --- | --- | --- |
| 绝对确定 | 无效的程度——不附带任何条件，当时你不要抱任何幻想 | 程度 |
| 自始当然 | 无效的时间——从一开始就注定了 | 时间 |

"自始当然无效"讲的就是：不能按预期产生后果，这一点从一开始的时候就已经注定了，不需要任何人去行使什么权利、做什么动作才能把它变成无效。

所以教材的四个特征是这样来的：前两个直接搬运概念里的关键词（成立且严重欠缺要件、不能发生预期后果），后两个展开"不能达成预期效力"这一条，把它拆成"绝对确定"和"自始当然"两段。

### 无效 vs 可撤销：三个维度分家

第二个理论问题：无效的民事法律行为和可撤销的民事法律行为有什么区别。

这个区别必须分清楚，因为可撤销的民事法律行为在被撤销以后**也可能不能发生效力**，看起来跟无效有点像。但两者存在明显区别，教材从三个方面展开对比：**如何无效、何时无效、何人可以提出主张**。

| 对比维度 | 可撤销的民事法律行为 | 无效的民事法律行为 |
| --- | --- | --- |
| 如何无效 | 相对无效、有条件的无效——只有撤销权人实际行使撤销权的时候，才能走向无效；他不行使，就走不到无效 | 绝对确定无效，不附带任何条件 |
| 何时无效 | 在被撤销之前是有效的，撤销以后才能认定无效；所以它的适用前提是已经成立**并发生效力** | 自始当然无效，从一开始就注定无效 |
| 何人主张 | 只有法律规定的撤销权人可以提出主张——也就是意思表示存在瑕疵的那一方当事人 | 任何人都可以主张，人人得而诛之；人民法院还有权依职权认定其无效 |

这三条差异你会发现，全都是上面那四个字和特征的延伸："绝对确定"对应如何无效，"自始当然"对应何时无效，"任何人可主张"对应主张主体。这就是我说的——**一个制度的特征，必然体现为它和兄弟概念之间的区别**。你把无效的特征记住，可撤销的特征不用额外背，它自己就站在对面。

> **易错点**：记忆抓手就一个词——**撤销权人**。记住谁是撤销权人：意思表示存在瑕疵的当事人。只有他有权提，别人都无权。可撤销的效力是握在他手里的开关；无效的效力是法院和任何人都能直接宣判的判决。

### 部分无效：一块坏肉，要不要污染整锅汤

第三个问题是部分无效。它是和"全部无效"相对应的概念。前面说无效是"不能按当时的预期发生效力"，那么问题来了：**到底是全部预期不能实现，还是只有部分预期不能实现？**这个区分就分出了全部无效和部分无效。

现在民法中，民事法律行为的无效**原则上是不分无效**的。这一点跟民法的基本原则是相统一的：既然民法以自愿原则为核心，那就要最大限度地尊重当事人的意思自治。一份合同动辄几十个上百个条文，哪些部分突破了法律底线，那就只否定哪部分的效力，剩下部分还是要尊重当事人意思自治的。这就是部分无效。

法条的规定是：民事法律行为部分无效，不影响其他部分效力的，其他部分仍然有效。

反过来读这句话更有用：**只有部分无效波及、影响到了其他部分的效力，才会导致全部无效。**这就像一块坏肉，只有它污染了整锅汤，才有必要把整锅都倒掉。

我们来看一个例子。甲被乙打成重伤，医药费5万元，甲乙达成如下协议：乙向甲赔偿医药费5万元，甲不得告发乙。

我们在实践中管这个叫**封口协议**——我给你钱，你闭嘴。

这个协议里有两块内容，要分开评价。

**第一块：乙向甲赔偿医药费5万元。**这一部分有效。你把人打伤了，当然要赔偿对方损失；而且我们前面讲过，民事责任具有任意性的特点，允许当事人在一定范围内协商。而且大家看，甲即使被封口了，他也只拿了自己应拿的医药费5万块钱——君子爱财，取之有道，这部分完全有效。

> **提示**：这里的边界是数额。甲只拿自己应得的5万，这叫损害的填补；反过来，如果他跟乙开口要10万、20万，那性质就完全不一样了。

**第二块：甲不得告发乙。**这部分无效。乙把甲打成重伤，依法是要承担刑事责任的，刑事责任能不能通过当时的一个约定给你免除掉？不能。同时，举报犯罪既是公民的基本权利，甚至都是公民的基本义务——你给点钱就想把这条免了，这是违反公序良俗的，应当认定无效。

无效的后果落到事实上就是：乙付5万块钱封住甲的嘴，这个预期不能实现了——甲有权报案，而且他不需要承担违约责任。

所以这个协议是**部分有效、部分无效**：封口的部分无效，赔偿5万的部分依然有效。

### 独立条款：众人皆醉吾独醒

第二个点是合同中的独立条款。有些条款的生命力非常强大，整个合同因为严重欠缺要件被认定无效了，它却不因合同的无效而失去效力。这种条款我们叫**独立条款**——众人皆醉吾独醒。

法条的规定是：合同的不生效、无效、被撤销或者终止，不影响合同中有关解决争议方法的条款的效力。

独立条款在法条中体现为**解决争议方法的条款**，它主要具有程序上的意义。道理也很顺：即使整个合同无效了，"这个纠纷由谁来解决"这个问题依然存在，而当事人当初的约定依然是有效的。

最常见的就是双方约定的**法院管辖条款**。比如双方约定好，因本合同发生纠纷，要到北京海淀区人民法院管。即使这个合同存在无效的情形，这个案件的审理还是要到海淀区人民法院去起诉，这个条款依然有效。**仲裁条款**也是一样的，因为仲裁本身就是一种解决争议的方法。

我们来看例二：甲乙签订了一份货物购销合同，其中约定因本合同发生纠纷，由北京仲裁委仲裁，通过仲裁方式来解决纠纷。后来双方发现合同存在无效的情形，涉及退款、退货的纠纷。

那么这个纠纷到哪里解决？**还是得按约定到北京仲裁委去解决。**尽管合同被认定无效，但合同中的仲裁条款具有独立性，生命力很强大，不因合同的不生效、无效、被撤销或者终止而失去效力。

> **结论**：从考试角度看，独立条款主要就考这两种——**管辖法院的约定**和**仲裁条款**。记住这两条就够了。

### 五种无效情形：从要件这个根上长出来

第二个层次：无效民事法律行为的适用情形。哪些民事法律行为会被法律打不及格？

要理解这个，最好的方式就是回到前面讲过的民事法律行为的**要件**。因为无效的本质就是"严重欠缺要件"，那我们就从要件的层次去推。从实质角度讲，要件分三个层次：**主体要合格、意思表示要真实、内容要合法**。

任何一层严重欠缺，都可能导致民事法律行为无效。民法典据此规定了五种无效情形：

```text
民事法律行为的要件（三个层次）
│
├─ 主体要合格
│    └─ 严重欠缺：无民事行为能力人实施的民事法律行为
│
├─ 意思表示要真实
│    └─ 严重欠缺：双方以虚假的意思表示实施（完全虚假）
│
└─ 内容要合法
   ├─ 违反法律、行政法规的强制规定→ 体现合法原则对意思自治的限制
   ├─ 违反公序良俗                → 体现公序良俗原则对意思自治的限制
   └─ 恶意串通，损害他人合法权益  → 体现诚信原则对意思自治的限制

            以上任一层次严重欠缺
                        │
                        ▼
            效力瑕疵最严重  →  无效（五种）
```

读图的方法是从上往下走：三个层次各自向下长出一种或几种无效情形，主体层长一种、意思表示层长一种、内容层长三种，合计五种；只要任意一个层次落到"严重欠缺"，效力就一路滑到最严重那一档。

所以五种情形其实是三层次的一次展开：主体层面出一种（无民事行为能力人实施的），意思表示层面出一种（虚假表示），内容层面出三种（违反强制性规定、违反公序良俗、恶意串通损害他人合法权益）。

我们依次展开。先看第一种。

### 无民事行为能力人实施的

无民事行为能力人实施的民事法律行为无效。这一点相对好理解。

按照民法典的规定，无民事行为能力人**不能独立实施任何民事法律行为**。你可能会想：纯获利的行为总行吧？接受奖励、赠与、报酬，这些也不能独立实施——都得由法定代理人来代理。理由很简单：他严重欠缺民事行为能力，这就是典型的"严重欠缺要件"。

### 虚假表示：双方一起演戏给第三人看

第二种情形和意思表示的瑕疵相关：当事人实施的**虚假行为**，应当认定无效。法条表述是：行为人与相对人以虚假的意思表示实施的民事法律行为无效。

请注意这个表述的分量——**不仅意思表示不真实，而且是完全虚假的**。这就是"严重欠缺"的所在：不是不真实，是压根就是假的。行为人和相对人商量好了，共同做出一个虚假的表示，常常是**双方一起演戏给第三人看**。既然是戏，那肯定是假的。人生如戏，全靠演技。

我记得很多年前有一部非常经典的小品叫《不差钱》。里面赵本山想请老毕吃顿大餐，既想要面子，又不想多花钱，于是提前到餐厅，和服务员小沈阳两个人商量好：到时候我点菜的时候你得给我点面子，太贵的你别让我点上。然后给了小沈阳100块钱的红包。等到老毕来的时候，赵本山就装模作样地点菜："来四斤的龙虾一只。"小沈阳说："没有。"——双方提前约定好了，演戏给老毕看。这就是典型的以虚假意思表示实施民事法律行为。

在实践中，这样的行为最常见于各行业都存在的**黑白合同**（也叫**阴阳合同**）当中。

#### 白合同无效，黑合同不一定

看例一。甲是知名影星，乙公司要投资一部电影，双方约定甲出演女一号，片酬约定3000万元，双方形成了一个合同关系。后来为了避税，双方又签署了一份片酬为1000万元的演出合同——1000万方便甲去报税，可以省一笔钱，剩余的2000万由乙公司再通过其他方式支付给甲。

那么事实上甲跟乙公司之间有两份合同吗？**是的。**各方当事人手里都是两个合同。这就是很多行业都存在的黑白合同。

- **白合同**：1000万那份。它是可以拿出来给税务机关看的，主要是为了掩人耳目。
- **黑合同**：3000万那份。它是双方当事人真实的交易，是要放在抽屉里的。

后来甲拿着1000万去报完税，乙公司就提出主张：说我们报税合同约定好了，片酬只是1000万，而这1000万我全部付给你了，剩余部分我就不付了。

甲肯定不答应。这个主张能不能成立？**答案是不能成立。**

尽管双方确实签了一份标的额为1000万的演出合同，但双方都知道，这不是他们真实的意思表示——这个合同签出来是干嘛的？用来演戏，给税务局看的。所以它是双方当事人以虚假的意思表示实施的民事法律行为，应当认定无效。既然不是当时的真实意思，当然不能按照这个合同来执行。**白合同因虚假而被认定无效。**

但是大家想想，**虚假的合同背后常常会隐藏一个真实的交易**，明修栈道是为了暗度陈仓。那么放在抽屉里那份3000万的合同，有效无效？**这就要看它有没有符合有效要件了。**因为3000万元是双方当事人真实意思表示的体现，符合有效要件，所以应当认定有效。这就意味着甲可以请求乙公司支付总共3000万元的片酬。

> **易错点**：既然虚假行为一律无效，那隐藏行为是不是一律有效？**当然不是。**按照法律规定，隐藏行为到底有效无效要具体问题具体分析：它符合有效要件的，认定有效；它不符合有效要件、存在无效情形的，同样会被认定无效。

例二就是把这条钉死的。甲乙达成一个卖淫嫖娼的协议——乙提供"卖淫服务"，帮助甲"学外语"，甲支付2000块钱。服务提供完了，甲翻脸不给了，说：我刚刚学完外语，突然想起来在我国嫖娼是违法的，我要是把这个钱给你，我就真成嫖娼了、就违法了；我不给你钱，我就不是嫖娼、就不违法了。逻辑鬼才，自己还挺得意。

这个时候一定会有两个彪形大汉让甲去付这个钱：人在江湖走，你得守江湖规矩——江湖的规矩是靠力量，而不是靠逻辑。甲一看，逻辑的力量果然抵不过力量的逻辑。但他实在是没钱，于是按对方的要求写了一个字据，上面写着：**甲向乙借款2000元，一周内偿还。**

一周到了，甲还是没付。乙就拿着这个字据向法院起诉，要求甲还借自己的2000块钱。

这个字据有效无效？**答案是无效的。**尽管上面写着"甲向乙借款2000元"，但双方都知道，他们之间根本没有一个真实的借款关系。这个借条也是做出来以后掩人耳目、给别人看的，它是个虚假的表示，所以应当认定无效。

那么这个虚假借条背后暗度的陈仓是什么？是一个卖淫嫖娼协议，是一个"学外语"的协议——而这个"学外语"是要打上引号的。这个行为的效力如何？**也是无效的，因为它违反公序良俗。**

所以在黑白合同这样的现象中，规律是这样的：**白合同常常因为虚假而被认定无效；黑合同（双方当事人隐藏的民事法律行为）则要具体问题具体分析，符合有效要件的认定有效，不符合有效要件、存在无效情形的也会被认定无效。**

#### 单方虚假行为与戏谑表示

这里补充一个理论拓展，它是一个超纲考点，也是一个纯理论问题：单方虚假行为的效力。

前面讲的虚假行为，主要指的是**双方当事人**以虚假意思表示实施的民事法律行为，也就是双方一起演戏给第三人看。而**单方虚假行为**指的是一方演戏给对方看，只有一方的意思是虚假的。

这里要重点补充一个概念：**戏谑表示**（这个是个理论概念）。

戏谑表示指的是，当时基于**游戏的目的**做出了相应的表示。但这里的"游戏"是一个比较广义的说法，它包含各种非正式的目的——包括夸张、开玩笑、炫耀、修辞、吹牛等等，都可能做出一个虚假的表示。

举个例子。乡下不少同学小时候都经历过这样的场面：小王和小李本来是好朋友，后来两个人因为小事翻脸了，小王就恶狠狠地对小李说："你今天让我很生气，我以后再也不和你玩了。我要再和你玩的话，我就不姓王。"或者"我的脑袋拿下来给你当球踢。"

你看小王做这个表示的内心真实意思，是将来再和对方玩就真不姓王吗？当然不是。他的真实意思是表达一个**坚决不跟对方玩**的坚决态度。而"不姓王"也好、"脑袋给别人当球踢"也好，都只是一个修辞手法，是基于游戏的目的而做出的表示。

所以这个表示虽然是一个虚假的意思，但对方**预期当然会知道**，而且希望他识破自己的内心真意——小王希望通过这种方式传达给小李的重点是什么？"我很生气，我不跟你玩了，给你划重点。"而"不姓王"、"脑袋给你当球踢"只是修辞手法，希望对方你也别太当真。

这就是戏谑表示。它规范什么问题？我们来看一个实践中真实发生的案例，在民法里非常有名的案例——**逃亡夸口案**。

这个案件涉及一位制陶艺人邢某（邢良坤），据说他的作品在故宫还做过展览。他参加中央七套当年的一个访谈节目，非常红。在这个节目上，他展示了自己的一个作品，叫**五层吊球**，制作得非常精妙。他说这个五层吊球是前无古人、后无来者的——"前100年没人做出来，后100年也不会有人做出来"，非常地狂。

然后主持人就追问他说：如果有人做出来的话怎么样？这个邢大师就接着吹，说有人做出来的话，我全部家产都给他。主持人接着问：哪些家产，你给大家说清楚。这位邢大师就说：首先是我的三层商铺，位于大连市的闹市区，而且包括里面全部的古董。当时现场估了一个价，估值人民币2000万元。现场报以热烈的掌声，都佩服邢大师的自信和高超的技艺。

当然当天这个节目，多数人看完洗洗就睡了。但是河南洛阳一位水电工人叫孙振，他看了以后失眠了——觉得干水电工太没前途了，不如搞这个五层吊球。于是他辞掉工作，专心地去搞这个五层吊球。大概半年的时间，还真把这个五层吊球给做出来了，还是有点天赋的。

然后他就联系邢良坤，要求对方来转移全部的家产。邢良坤肯定不答应。后来孙振就把邢良坤给起诉了，在洛阳基层法院审理。一审法院审理后认为：邢良坤你在中央电视台公开悬赏五层吊球的制作，而这个孙振按照你的要求完成了五层吊球，双方的悬赏合同成立，你有义务转移这2000万的资产。

这个判决出来以后，网上一片哗然，好多吃瓜群众——假如说这个案件放在现在，那是妥妥的热搜案例。邢良坤当然不同意，于是提起上诉。

在洛阳中院经审理以后，二审法院认为：邢良坤他在电视上做出的承诺，不是他真实的意思表示，他只是为了夸张、为了吹牛，应当认定是无效的。这意味着他没有必要向孙振转移这2000万的全部家产。**两审判决完全不一样**，相当于孙正到手的2000万瞬间就没了，然后又引发网友的一波关注。

那么两审判决，哪个更符合民法的法律？我明确告诉大家：**二审法院的认定是更符合民法法理的。**

因为邢良坤在电视上所做的表示，其实就叫戏谑表示。他虽然说了"有人做出来的话，我把全部家产都给他"，但我们在理解的时候，要放到特定的语境下去理解。在他之前，邢大师主要强调的是他这个五层吊球是前无古人、后无来者的——这话其实说得很绝对；后面这个悬赏的问题，是在主持人的追问下一步一步说出来的。其实他是通过这种夸张的口气来表达对自己陶艺水平的一种自信，并不是真的在悬赏制作一个五层吊球。

> **结论**：戏谑表示这个理论，使得我们在生活当中开点小玩笑、做点夸张的表述，而不至于都要去承担法律责任。生活已经够苦了，要允许大家开开玩笑，让生活稍微轻松一下——这就是戏谑表示存在的价值。**戏言不一定是承诺，吹牛也难以构成一个合约。**

### 违反强制性规定：每个字都认识，读完不知所云

第三个层次是内容上的瑕疵，内容不合法分成三种类型。先看第一种：违反强制性规定。

民法典第153条第一款：「违反法律、行政法规的强制规定的民事法律行为无效。但是，该强制规定不导致该民事法律行为无效的除外。」

这个条文，大家看每个字都认识，但是读完以后好像不知所云。我记得当时颁布民法典的时候，有学长还调侃：这个条文可以用来考察外国人的汉语水平，让他读这个法条，然后问他"违反强制规定到底法律后果如何"。

其实这条条文就表达一个意思：既然民事法律行为要求内容合法、不得违反法律和行政法规的强制规定，那么如果你违反了，效力就会存在瑕疵，应当认定无效。但是，这只是**原则性**的规定——有原则的同时，也必须允许例外的存在。

为什么要有例外？因为我国现行法当中的强制规定范围实在是太广了。原则上是违反即无效，但也确实存在一些强制规定，被违反了却不会导致民事法律行为无效。"除外"两个字表达的就是：有原则，有例外。

#### 规范范围：只认法律和行政法规

理解这个规范，第一要点是：**能够导致民事法律行为无效的规范范围，仅限于法律和行政法规。**就这两个级别的规范，才能作为认定民事法律行为无效的依据。

这意味着像地方性法规、包括规章，尽管里面也有强制规定，但违反以后常常不会导致民事法律行为直接无效——因为地方法规也好、规章也好，你们这个规范的级别不够，不足以导致一个民事法律行为无效。

我们看例一，这是一个实践中真实发生过的案例。西安商行和剑桥证券签订了一个资金拆借合同，也就是借款合同，约定西安商行为剑桥证券提供拆借资金3603万元，约定了期限和利息。合同到期后剑桥证券没有按期还款，协商后就向法院提起了诉讼。

这时候剑桥证券提出一个主张，说这个拆借合同超过了中国人民银行关于禁止银行资金违规流入股票市场的通知。剑桥证券想以中国人民银行颁发的这个通知（它顶多属于行政规章）来主张合同无效。

这个主张能不能成立？**不能成立。**首先，这个双方的借款合同所违反的规范是不是法律和行政法规？不是的。虽然你被违反了，但是你的级别太低了，不足以导致合同无效这么严重的后果。**这个合同依然是有效的。**

所以大家记住：导致民事法律行为无效的规范，**只能是法律和行政法规，而不能是其他层级的规范性文件。**

#### 越了级的强制规定，不等于没事

那么我们能不能反过来说：只要违反的是地方法规或者规章里面的强制规定，都不会导致合同无效？**也不能这么说。**

因为"违反强制规定导致无效"只是无效情形中的一种。**合同无效的情形包括但不限于这一种。**假设这个合同还存在其他无效情形、踩了其他红线，照样会导致合同无效。

例二。有夫之夫甲委托未婚女乙代孕，双方签订协议，约定事成以后甲补偿乙50万元。事后甲拒绝兑现，理由是双方签订的代孕协议是无效的。

可能大家也都知道我国是禁止代孕的，但大家知不知道禁止代孕的规定，是写在哪个文件里面的？我把这个文件写到了教材当中——它是**卫生主管部门颁布的一个部门规章**，是个部门规章。其第三条明确规定：禁止以任何形式买卖配子、合子、胚胎，医疗机构及人员不得实施任何形式的代孕技术。这就是关于代孕的明确禁止性规定。

结果乙提出这个文件，说甲的合同违反了它。乙的这个主张能不能成立？**答案是不能成立的。**固然这个禁止的规则写到了部门规章当中，他并没有触碰"违反法律、行政法规的强制规定"这条红线。但是合同无效的情形**包括但不限于**这一种——这个代孕协议同时违反了公序良俗，它踩了另外一条红线，所以依然应当被认定无效。

> **易错点**：部门规章的效力层级不够，不能单独成为认定合同无效的依据——这一条要记牢。但"不能作为依据"和"合同因此有效"是两回事。判断合同效力的落脚点始终是那几条红线本身。

#### 代孕为什么又踩了公序良俗

那问题来了：代孕怎么就违反公序良俗了呀？

我们站在提供方和委托方的角度想一想：不想回应的一方，花点钱让别人来帮这个忙；提供的一方呢，肯定在家没什么事，还能赚点钱花。为什么法律要禁止？

主要有两个方面的考虑。

**第一，代孕的本质是出租。**你把自己的身体都给别人使用，让别人来有偿利用自己的身体，只把人当成客体来对待，这是违反公序良俗的。而且怀孕本身会对代孕女性的健康带来一些不确定的危险——这是法律不允许的。

**第二，如果允许代孕协议有效，它会破坏我们国家现行的父母子女关系的认定规则。**你看，在认定父母子女关系的时候，父亲和孩子的关系可能得打一个问号——有证据的话得做亲子鉴定。但是母亲和孩子的关系认定是非常明确的，就是以出生的事实作为判断标准。而代孕一旦被允许，这条确定性就无从落地了。

## 无效的民事法律行为：判定路径与法律后果
> 对应块：BLK32 | 覆盖分集：P30下 | 块标题（分集名）：《第01编 第06章 第06节：无效的民事法律行为》

我们接着往下讲。代孕这件事，法律上判断谁是母亲，用的是"出生事实"这个标准——谁身上生下来的孩子，谁就是孩子的母亲，而不是看所谓的"原材料"是谁提供的。当然，"原材料"这三个字得打上引号。

假如代孕协议有效，那就意味着代孕女有义务把这个孩子交还给委托人。可这个孩子是从代孕女身上生下来的，按照现行法律规定，她就是孩子的法律上的母亲。那你让她执行这个协议，就是让法律上的母亲交出自己的孩子——这是公序良俗绝对不能容忍的。所以代孕协议违反公序良俗，这是第一点。

这里还要顺带补一条：导致民事法律行为无效的规范，仅限于法律和行政法规。违反其他规范当中的强制规定——注意是"其他规范"，不是法律、行政法规——如果能同时违反公序良俗，一样会被认定无效。红线有好几条，不管踩到哪一条都算无效。

```text
        民事法律行为违反强制性规定
                    │
                    ▼
        ┌───────────────────────────┐
        │ 这条强制规定出自哪里？      │
        └───────────────────────────┘
          │              │
    法律 / 行政法规    其他规范
          │              │
          ▼              ▼
       认定无效      是否同时违反公序良俗？
                          │
                 ┌────────┴────────┐
                 ▼                 ▼
             仍然无效        不因此项无效
                              （另看他因）
```

> **结论**：能让民事法律行为无效的效力性强制规定，只存在于法律和行政法规之中；其他规范里的强制规定不足以直接导致无效，但一旦它同时踩到公序良俗这条红线，无效照样成立。

### 不导致无效的四类强制规定

接着看第二个问题：不导致民事法律行为无效的强制规定。

我们前面讲了，我国的强制规定非常的多，可以说是多如牛毛。不是说只要是法律、行政法规当中的强制规定不违反了，都会导致合同无效——法律允许例外情形的存在。这个例外情形就是合同编通则司法解释的第 16 条。

但这个例外情形是通过"列举"的方式来规范的。既然是列举，它可不可能列举完全？完全不可能。所以司法解释列举了哪些，你掌握哪些就可以了。它主要列举了四种情形。

> **提示**：这四种情形其实"没什么逻辑"，它是成熟一个、列举一个。所以大家在学习的时候也不要费尽心思去琢磨它们内部有什么逻辑关联——没什么逻辑。大家主要是基于教材当中的四个案例，去理解司法解释列举的这四种情形就可以了。

在进入四种情形之前，先记住那条总的思路。合同违反了法律、行政法规的规定，会产生公法上的责任——行政责任或者刑事责任。假如当时已经承担了行政责任、刑事责任，能够实现强制规定的立法目的了，那就不用再认定合同无效了。通俗地讲：虽然他违反了法律、行政法规的强制规定，但是行政责任、刑事责任已经惩罚过他了，民事上就不用再惩罚了，不用赶尽杀绝，非得认定合同无效。

#### 情节显著轻微，认定无效反而不公平

强制规定虽然旨在维护社会公共秩序，但是合同的实际履行对于社会公共秩序造成的影响显著轻微，认定合同无效将导致案件处理结果有失公平公正的，那合同将被认定为有效。

这个规定的精神其实来自于刑法。大家学刑法的时候应该会有个条文说：有些犯罪行为如果情节显著轻微、社会危害性不大的，也可以不作为犯罪来处理。是不是情节都轻微了，就没必要去赶尽杀绝了？那在民法里面也是一样。如果违法的情节显著轻微，认定合同无效反而会导致结果有失公平公正，那就通过行政处罚解决问题就可以了，没必要认定合同无效。

来看例一。

甲为了谋生，在 A 市街区摆摊出卖山东煎饼。好多地方对摆摊的经营者是有许可要求的，但这个卖煎饼的甲并没有办相关许可手续，大学生乙扫码支付价款，购买了两个煎饼。就在乙拿到煎饼刚刚准备要吃的时候，城管执法大队前来巡查，以甲违法经营为由，没收了这个煎饼摊，并处罚款 500 块钱。

我们来判断甲乙签订的煎饼买卖合同效力如何。

首先，甲没有经过许可违法经营，肯定是违反法律、行政法规的强制规定了。违反强制规定，首先要承担行政方面的责任——所以城管大队要没收他的煎饼摊，还要处罚款 500 块钱。是不是已经承担行政责任了？这个责任的承担已经能够实现强制规定的立法目的了——惩罚这个违法行为。

而这个煎饼买卖合同的履行，对社会的危害性大不大呀？当然不大。尽管他有违法经营的行为，但是说破天，当时只是买了两个煎饼而已，让他吃能咋样？所以这样一份合同的履行，对社会公共秩序造成的影响可以说是显著轻微的。这时候就不用认定煎饼买卖合同无效了。大学生乙和甲签订的煎饼买卖合同依然是有效的，你依然可以放心大胆地把这个煎饼吃掉。

这就是第一种情形：情节显著轻微，承担行政责任已经实现立法目的了，民法上就不再惩罚了，就不再认定合同无效。

#### 规范保护的是国家利益，不是当事人

强制规定旨在维护政府的税收、土地出让金等国家利益，或者其他民事主体的合法权益，而非合同当事人的民事利益，认定合同有效不会影响该规范目的实现的，合同有效。

是不是看完条文以后基本上还是不知所云？所以大家要结合案例去理解。

来看例二，这是真实发生过的事情。

某市居然之家举办年底回馈顾客大酬宾活动，承诺购买家具超过 10 万即可参与抽奖：一等奖是奔驰轿车一辆，二等奖是笔记本电脑一台，三等奖是 iPad 一台。我在网上查过居然之家相关的案例，一等奖基本上都是奔驰轿车，可能是有什么合作。某顾客消费 16 万参与抽奖，运气爆棚，直接抽中了一等奖。

其实我原来都不相信这种抽奖的，我觉得都是骗人的。但后来我真的有个朋友抽到了一等奖，抽到了奔驰轿车——后来发现是我自己狭隘了。

这个朋友就要求对方兑现承诺，交付这辆奔驰轿车。这时居然之家提出：我们这里所称的"奔驰轿车一辆"不是把车给你，而是给你提供 5 年的免费使用权。我这朋友当然不答应，因为他自己也有车。于是居然之家请出他们的法律顾问来解释：车我们也想给你，但是法律不允许。

我这朋友一听就说：中国还有这么混账的法律啊！于是法律顾问拿出一部法律来——《反不正当竞争法》，第 11 条有个明确规定（我写到了教材的角注当中）：经营者进行有奖销售不得存在下列情形。注意"不得"两个字，体现为一种强制性的禁止性规定。其中第四项是：抽奖式的有奖销售，最高奖的金额超过 5 万元的，为法律所不允许。所以法律顾问解释说，之所以只提供 5 年的奔驰车使用权，就是不能超过 5 万块钱的上限。

我朋友听完以后好像觉得有点道理，但又觉得哪个地方不太不对劲。他知道我是学法律的，就打电话来咨询我。我首先是表面上恭喜他中奖，其实心里面满满的羡慕。我跟他讲：你回去跟居然之家说，第一，我只要车，不要车的使用权；第二，如果你们不给我车，后果是我们要打官司，最终车肯定归我，然后你们还会受到相关部门严厉的处罚。讲到这个地方我说你就别讲了，再讲就露馅了。然后他就回去这么跟居然之家讲，对方一看这是个"门清"的人，最后还是把这辆车给了他。

当然，我这个朋友成都要请我吃大餐，后来也没有兑现。

我们来分析一下我为什么敢给他这个结论。

首先，这个抽奖活动确确实实违反了《反不正当竞争法》。但是我们要问：《反不正当竞争法》为什么不允许奖金超过 5 万块钱？是为了维护一个公平的竞争秩序，让竞争者把主要精力都放到提高产品的品质、提高服务的水平上，而不要在奖品上去卷来卷去。它是为了维护公平的竞争秩序，并不是为了保护合同当事人——也就是居然之家——的民事权益。

法律不是心疼这个搞抽奖的经营者，说他一次性拿 5 万压力太大了，不是为了保护他的利益，而是为了保护这个公平的竞争秩序。而当时实施这个抽奖活动，是不是违反了这个规定？它是违反的。它产生的后果是承担行政责任——因为你破坏了公平竞争秩序，所以要对你进行罚款、停业整顿等等处罚。实际上通过这样一个行政处罚，已经能够实现《反不正当竞争法》第 11 条的立法目的了。既然没有必要再认定合同无效——因为认定合同无效以后，反而便宜了这个实施不正当竞争行为的居然之家，反而会破坏这个立法目的的达成。

既然考虑到这一点，尽管违反了这个强制规定，但它不会导致无效。那么如果双方真的打官司，这件事公开化以后，当地的工商管理部门就不能坐视不管了，就会启动行政处罚的程序。居然之家觉得这个中奖者是"门清的"，他知道这里面的套路，最后还是把这辆车给了我朋友。

你看第二种情形对应的就是这种案例。这里面涉及的强制规定，旨在维护国家的税收等国家利益——前面我们提到过黑白合同的问题：明星和电影投资公司签订黑白合同，1000 万的片酬用来报税，3000 万的片酬是真实的意思表示。

那为什么不能说，当事人签订这个 3000 万的合同，其目的是规避缴纳税款的义务，因而认定它无效呢？一般禁止偷逃税款的强制规定，它的立法目的是为了保护国家利益，而不是为了保护合同当事人的利益。偷逃税款的话，你通过行政责任把税款追回来就可以了，没必要非得认定这个合同无效。

而且，认定这个合同无效以后，反而会损害国家利益：认定这 3000 万的合同无效，甲就没有资格拿这 3000 万了，那他也没有义务去缴纳这个税款了，反而会影响国家税收的收益。所以这个时候，3000 万的合同没有必要因为当事人有这样一个逃税的操作而认定无效——你认定这个合同有效，反而是有助于这个规范目的的实现的。这样你是不是就可以理直气壮地要求甲把没缴税的那部分税款补上？

这是第二种情形。

#### 规范只要求一方加强风控，对手方无从审查

强制规定只要求当事人一方加强风险控制、内部管理等，对方的没有能力或者没有义务审查合同是否违反强制规定，认定合同无效将使其承担不利后果的。

是不是又看完以后不知道它在说什么？所以一定要结合教材里面的案例去理解。我们来看例三，这也是实务当中真实发生的案例。司法解释里之所以写这一项，就是因为例三这个案例。

某信用社和甲公司签订贷款合同，约定信用社给借款人甲公司提供贷款 1200 万元，由乙公司提供担保。信用社给甲公司转账 1200 万。后来在该信用社内部审查的时候，发现该贷款的数额已经超过了信用社资本余额的 10%，违反了《商业银行法》第 39 条关于资产负债比例管理的规定。

我把这个条文也写到了教材的角注当中：商业银行贷款，应当遵循下列资产负债比例管理的规定——对同一借款人的贷款余额与商业银行资本余额的比例不得超过 10%。

那为什么有这个不得超过 10% 的规定呢？是为了降低这个金融机构的风险。假如你一个银行给一个企业提供的贷款余额，超过你资本额的 10%，这意味着你跟这个企业绑定的有点太深了。假如这个企业的经营出现问题的话，你这个商业银行是有可能要跟着倒霉的，风险太大了。你像前面提到恒大公司欠了 2 万亿的债务，这规模是相当大的。假如某个银行跟这个恒大绑定太深，恒大现在倒闭了，这个银行就会面临巨大的金融风险。所以《商业银行法》才要求对同一个借款人的贷款余额不能超过资本余额的 10%——也就是鸡蛋不能放到一个篮子里，要分开放，这样某一个企业倒闭了，也不至于影响这个银行的资金安全。

他这么一个考虑。大家看这个时候，信用社能不能以此为由来主张贷款合同无效呢？答案是不能。

尽管信用社的贷款确确实实违反了这个规定，超过了 10% 了，但是回头来看司法解释第三项：这条"比例不得超过 10%"的强制规定，他的目的是要求这个银行这一方要加强风险控制、内部管理，主要是为了降低这个银行的风险。那对方——甲公司——没有能力也没有义务来审查合同是否违反该规定。就这个案例当中，甲公司在找这个信用社贷款的时候，他有没有这个能力去审查一下：你给我的贷款余额有没有超过你自己资本余额的 10%？他没这个能力。

而且，认定合同无效将使其承担不利后果。也就是说在这个案例当中，如果你认定合同无效的话，信用社就没有权利请求甲公司来支付约定的利息了——因为合同无效了，只需要返还本金加上个法定利率就可以了，反而会损害这个银行的利益。那这样的话，认定合同无效就是好心办坏事了。

所以这个时候借款合同依然得是有效的。只是你这个信用社违反了《商业银行法》的规定，你是需要承担行政责任的。但是这个行政处罚事实上已经能够实现规范的立法目的了，所以就没有必要再认定合同无效。

这是第三种情形。

#### 已具备补正条件却恶意不予补正

当事人一方虽然在订立合同时违反强制规定，但是在合同订立以后已经具备补正违反强制规定的条件，却违反诚信原则不予补正的，合同也不能认定无效。

是不是看完以后还是不知所云？所以大家结合这个例子去理解。这条司法解释的规定，就是为了解决例四这样的案例。

甲公司是知名房地产开发商，开发某住宅项目。当时虽然没有取得预售许可证，但是因为名气够大、广受欢迎，小马等业主通过私人关系获得了抢购资格，和甲公司签订了房屋买卖合同来买甲公司开发的房屋。但是后来房价大涨，甲公司有点后悔了，觉得这个房子卖得有点太便宜了。但是毕竟合同签了，公然撕毁合同他也不敢这么明目张胆。

于是甲公司想了一个办法：他马上暂停了预售许可证的办理手续，然后向小马等业主提出：本公司在跟你们这些业主签订合同时，并没有取得预售许可证，违反了《城市房地产管理法》第 45 条的规定，这个合同应当认定是无效的。既然合同是无效的，那就废弃这个合同，然后再高价出卖这个房子——打这么一个如意算盘。

我们先来看一下甲公司卖房的行为，有没有违反《城市房地产管理法》的规定？当然有了。你没有取得预售许可证，是不能够对外销售这个房子的。而在此之前，如果你签订买卖合同的话，在法律上确实应当认定是无效的。表面看起来，甲公司的主张是有道理的。

但是，我们法律其实是允许这样的合同补正它的效力的：只要甲公司后来补办了这个预售手续，那这个合同将转换成有效。也就是虽然你们先上车了，但只要后来补票，法律也认可这个买卖合同的效力。

而对于甲公司来讲，事实上他已经具备办理这个预售许可证的条件了，但是他为了自己的利益恶意地暂停了手续的办理，使得这个买卖合同没有机会被补正——这明显违反了诚信原则。所以这个时候法律就不认可你的主张了，这个合同可以认定是有效的合同。

你可以对应一下司法解释第四项的规定：当时在签订合同时确实违反了强制规定，开发商确实是没有取得预售许可证就签订买卖合同；但是合同订立以后，是不是已经具备了补正违反强制规定的条件了呀？你可以办这个预售许可证的呀；但是却违背诚信原则不予补正，为了自己的利益暂停了这个手续。那这个时候法律当然不能去保护你了——不能说合同因为你的甲公司的违法行为而导致无效，最终还使得你取得了一个以更高的价格来卖房子的机会，通过自己的违法行为反而获益了。这个是违反法律的精神的，所以这个时候合同不会被认定是无效的。

好，这样就把司法解释列举的四种不导致合同无效的情形讲完了。还是那句话：这四种情形就是实践当中已经成熟的典型情形的列举，它内部并不存在什么逻辑关系。所以学习的时候只需要结合教材里面列举的四个案例，去理解这四项规定说的是什么就可以了。

### 限制性、赋权性规定：为什么不适用无效规则

接着看第三个问题：违反限制性规定或者赋权性规定的效力，这也是合同司法解释的规定。

规则是这样的：法律、行政法规的规定虽然有"应当""必须""不得"等表述，也就是表面上看它也是一个强制性规定，但是该规定如果旨在限制或者赋予民事权利，而行为违反该规定的后果《民法典》已经有特别规定了，那这时要适用《民法典》的特别规定，而不再适用"违反强制规定导致无效"的规则。其实这也是《民法典》第 153 条第 1 款的一个例外情形。

比如说无权处分、无权代理、越权代表等行为，都违反了某个带有"不得"或者"应当"的规范，但是它们的后果在《民法典》里已经做出明确的规定了。比如无权代理的后果就是效力未定的，那这时候要适用《民法典》的特别规定，而不再适用无效的规则了。

听起来很抽象，我们来看一个小例子。

甲乙系夫妻双方，共有房屋一套，但是只登记在甲的名下——这意味着这套房子依然是夫妻共同财产。甲未经乙的同意，擅自以自己的名义和丙签订了买卖合同，将房子卖给了丙。

我们来看《民法典》第 301 条（物权编也要讲这个规定）：处分共有的动产或者不动产，应当经占份额 2/3 以上的按份共有人或者全体共同共有人同意。你看这里面有两个字叫做"应当"。

在这个案例当中，这套房子是甲乙共同共有的房产，那意味着甲要卖这个房子的话，是应当经过共有人乙的同意的。但是甲擅自把房子卖给了丙，是不是违反了第 301 条这个带"应当"的规定啊？

但是我们要考虑，这个规定的立法目的是在限制民事权利——限制某个共有人（甲）的处分权。所以《民法典》事实上对这种行为的效力已经做出相应规定了，就是无权处分行为的效力。记住这个规定：限制某个共有人甲的处分权，你违反这个规定，构成的是无权处分。而在《民法典》当中，无权处分是不影响合同的效力的。所以这个合同依然是有效的合同——尽管它违反了带"应当"的强制规定，但它不会导致合同无效，因为《民法典》对违反这种规定的后果已经有特别的安排了。

这样就把违反强制规定导致无效的情形讲完了。还是把握那个原则：原则上违反强制性规定导致无效，但是存在例外。实际上我们讲的绝大部分内容，都是在讲这个例外——它到底包括哪些。

### 违反公序良俗的三种情形

违反公序良俗也是内容违法的一种体现，其体现的是公序良俗原则对自愿原则的限制。但公序良俗的内容我们在总则编给大家做过详细的展开，所以这里就不再做深入的讨论，重点补充一个司法解释的规定：有下列情形之一的合同，因违反公序良俗而被认定无效——这是合同编通则司法解释列举的三种情形。

#### 危害国家安全：公共秩序的一面

合同影响政治安全、经济安全、军事安全等国家安全的，体现的是国家的公序。

大家看例一：董某是我国某报社评论部的副主任，在日本留学期间被轻易策反——"轻易"这两个字啊，伤害性不大，侮辱性极强——然后和某间谍组织达成合议，董某负责搜集情报和国家机密提供给间谍组织，该组织给董某提供相应的回报。

你看双方的合同是不是危害了国家的安全？那这样的合同就是因违反公序良俗而无效的，破坏了公共秩序。

#### 破坏社会稳定与公平竞争

合同影响社会稳定、公平竞争秩序或者损害社会公共利益等，违反社会公共秩序的也会导致无效。比如垄断协议，它是破坏这个公平的竞争秩序的，也是违公序良俗的。

大家看例二：甲乙签订劳动合同，约定"工伤概不负责"，或者"员工入职 5 年不得结婚生子"。你看是不是违反了保护劳动者合法权益的公共秩序啊？应当认定是无效的。

#### 背离社会公德与善良风俗

合同背离社会公德、家庭伦理或者有损人格尊严等，违背善良风俗的，会导致无效。

你看这一点讲的是违反善良风俗的情形，前两项讲的是违反公共秩序的情形。但这个违反善良风俗的行为，我们在总则编给大家讲过四种——黄赌毒加上高利贷，还记得吧？

大家看例三：甲乙的离婚协议里面约定，乙未经甲的同意，不得和他人再婚。是不是限制了别人的婚姻自由啊？是违反善良风俗的。

这里还给大家补充了一个规范拓展内容，这是去年新增加的婚姻家庭编解释二的内容。虽然是新增的，但很好理解：夫妻一方为了重婚、与他人同居，以及其他违反夫妻忠实义务等目的，将共同财产赠与给他人，或者以明显不合理的价格处分共同财产，另一方可以主张该法律行为违背公序良俗而无效。也就是把财产赠与给情人的，是为了维持非法同居关系的，破坏了正常的家庭秩序的，当然应当认定无效。

比如大家看例四：甲乙结婚以后，甲和丙产生了婚外情并同居在一起。为了维持甲和丙的共同生活，甲在两年间共给丙转账 20 万。大家看这个赠与合同有效还是无效？无效——因为它是为了维持非法的同居关系，是背离善良风俗的。

> **提示**：咱们从考试角度来讲，违背公序良俗的情形基本上都比较好辨识。只要大家有点生活常识和正常的三观，基本上都可以判断出来。

### 恶意串通损害他人合法权益

最后是恶意串通损害他人合法权益，这也是内容存在瑕疵的情形之一。

按照法律规定，行为人与相对人如果恶意串通，损害他人合法权益的，民事法律行为应当认定无效。因为"恶意串通"这四个字本身就代表了当时的恶意，他违反了诚信原则。

但这个恶意串通里面有两个强调：一方面强调主观上得是恶意，就是为了伤害别人，很多时候是损人还不怎么利己的；同时呢强调客观上当时得有一个通谋的行为，双方一个串通的行为。

我们简单看一个例子。甲与乙，甲以 300 万的价格购买甲的房子，双方签订了书面的合同。按道理签订合同以后，双方都得去履行合同，来满足对方订立合同的期待。但是后来因为学区政策的调整，甲的房屋价格大涨，甲有点后悔了——300 万卖这个房子，要求提高价款，被乙给拒绝了。

于是甲为了防止该房屋被乙取得，和他的父亲丙商量，先将房屋赠与丙，随后马上办理过户登记手续。

大家看甲和丙之间虽然有一个赠与合同，但是这个赠与合同的目的是什么呀？就是为了损害乙的利益，就是从法律上把这个房屋所有权转移到丙的手中，使得乙丧失一个请求甲继续履行的机会。这就叫恶意串通损害第三人的合法权益。那甲丙的合同应当认定是无效的。即使甲把房子过户登记到丙名下，丙能不能取得房屋所有权？不能。

我们在前面讲过，登记本身具有独立的形式效力——但这里不一样：这个合同本身就是无效的民事法律行为，无效的民事法律行为自始无效，所以即使办了过户登记也不能发生物权变动。对乙来说，甲不配合办理过户手续的话，乙是可以请求甲继续履行的；甲不履行的话，乙是可以请求强制执行的。这样就可以维护自己的合法权益。这就叫恶意串通，也是比较好认定的。

但讲到这里，我给大家补充一个问题：前面我们讲过一个制度叫第三人欺诈。当时在找这个"托"的时候，是不是常常也商量好了去骗别人呀？它和恶意串通有什么区别呢？

大家注意，它们虽然都涉及到"商量着如何害人"，但是商量的主体之间有没有合同关系，存在本质的区别。

| | 恶意串通 | 第三人欺诈 |
| --- | --- | --- |
| 谁在商量着骗人 | 一方当事人与第三人 | 一方当事人与第三人 |
| 商量的主体之间有没有合同 | 有——串通双方之间签订了一个明确的合同（如甲与丙的赠与合同） | 没有——甲丙之间不存在一个需要我们认定效力的合同 |
| 合同的当事人 | 甲丙 | 只有甲乙，丙只是个"托"（水军） |
| 法律后果 | 该串通合同无效 | 适用欺诈的规则（可撤销） |

所以在恶意串通当中，相互串通的当事人之间有一个明确的合同，要认定这个合同的效力；而第三人欺诈当中，只有甲乙之间有合同，丙只是甲请来的水军，甲跟丙之间并不存在一个明确的合同。别把它跟恶意串通搞混淆了。

### 五种情形，三个层次

这样就把民事法律行为的无效情形全部讲完了：总共是五种情形，分成三个层次。

```text
无效的民事法律行为（五种情形）
│
├─ 主体瑕疵
│   └─ 无民事行为能力人实施的
│
├─ 意思表示瑕疵
│   └─ 行为人与相对人以虚假的意思表示实施的
│
└─ 内容瑕疵（内容不合法）
    ├─ 违反法律、行政法规的强制性规定
    ├─ 违反公序良俗
    └─ 恶意串通，损害他人合法权益
```

第一个层次跟主体瑕疵相关，对应的是无民事行为能力人实施的行为，是无效的。第二个层次还是跟意思表示瑕疵相关，主要指行为人与相对人以虚假的意思表示实施的民事法律行为是无效的。第三个层次是内容瑕疵，内容不合法，分为违反法律、行政法规的强制规定，违反公序良俗，以及恶意串通损害他人合法权益三种情况。

### 无效的法律后果

接着进入最后一个板块：无效的法律后果。但这个无效的后果，跟民事法律行为不成立、被撤销以及不发生效力的后果是一样的，所以能放到一起来讲。

这里大家注意区分"无效"跟"不发生效力"这两个不同的专业术语。"无效"讲的是存在法律规定的无效情形，直接被法律判了不及格了。而"不发生效力"，它只是客观上描述有效要件最终没有被全部满足。

比如说限制民事行为能力人签订了一个超出他行为能力范围的合同，这个合同是效力未定的合同，还记得吧？那假如说他的法定代理人拒绝追认，那这个合同啊叫不发生效力。也就是在效力未定的基础上，第三人选择了拒绝，那他最终不能够发生效力。

这叫不发生效力。我们能不能说他是无效的呢？不能说。因为它并不存在法律规定的无效情形。所以"不发生效力"只是客观地描述一个结果，而"无效"是带着某种价值评价在里面的——你这样的合同是不行的，法律是对你持否定态度的。所以《民法典》把它们并列出来。

《民法典》把无效的后果分成三个方面。

第一，返还财产。既然合同被认定无效了，那就意味着通过这个合同取得的财产就丧失法律上的根据了，你得返还财产。

第二，赔偿损失。假设在签订这个合同的时候，一方当事人存在过错，那合同被认定无效以后，有过错的一方是要承担赔偿责任的。它的本质其实属于我们在合同编会给大家讲的缔约过失责任。双方都有过错的，各自承担相应的责任。

第三，收缴财产。假如说当时恶意串通，损害了国家、集体、第三人利益了，那要追缴双方的财产，当然追缴的财产要返还给国家、集体或者第三人。

> **易错点**：注意第一项里面的"返还财产"和第三项的"收缴财产"，二者有什么区别。第一项里面的返还财产，是返还给交易的相对方。比如说甲乙签订合同，甲给乙支付了 10 万块钱，后来这个合同被认定无效了，乙取得这 10 万块钱就丧失法律根据了，那甲可以请求交易的相对方乙来返还财产——这是第一项里面解决的问题。而假如说甲乙签订的合同是恶意串通损害第三人丙利益的合同，使得乙取得了应当归属丙的财产，那收缴的财产要还给谁？还给丙。所以到底是返还给相对方还是返还给第三人，主要看这个财产原来属于谁——原来属于相对方的，就返还给相对方；原来属于国家、集体或第三人的，就返还给国家、集体或第三人。很好理解。

> **注意**：第三项法律后果"收缴财产"，实际上在《民法典》里已经被删除了。为什么教材里面还有？因为官方教材、考试分析里面没有删。所以我依然把它保留下来，毕竟这是一个主观题的考点——如果官方教材有你不写，也有可能会被扣分。但是你要知道《民法典》已经把它删掉了。
>
> 有人说为什么要删掉呢？因为这个收缴财产所针对的行为，往往违反了强制性的规定，要产生行政法上的责任或者刑事责任，那就不属于民法调整的范围了，应当属于行政法调整的范围。所以《民法典》就把它删掉了，把行政法的问题交还给行政法来规范，各个部门法各司其职。所以《民法典》的边界意识还是比较强的——不归我管的事情我就不管。

好，这样无效的民事法律行为这一部分就全部介绍完了。这一部分算是大家掌握的一个难点板块，包括概述、适用情形以及法律后果三个层次。

## 悬而未决的效力：附条件与附期限
> 对应块：BLK33 | 覆盖分集：P31 | 块标题（分集名）：《第01编 第06章 第07节：附条件和附期限的民》

我们接着看第七节，附条件和附期限的民事法律行为。

这一节讲的是民事法律行为的**特别生效要件**，而且是基于当时约定产生的特别生效要件。什么意思呢？就是当事人可以约定某个民事法律行为附条件或者附期限——一旦这么约定，这个行为的效力就取决于条件的成就与否，或者期限的到来与否。

先给你们提一个问题：“甲的父亲去世后我把房子卖给你”和“甲的父亲80大寿时我把房子送给你”，这一字之差，一个叫期限，一个叫条件。差在哪儿？为什么有些看起来明明是时间的东西，它反而是条件？这一节的坑基本都坑在这个判断上，所以我们把它放在最前面讲。

### 条件还是期限，只差“确定会发生”这四个字

条件和期限都可以体现为某个未来的事实，但两者的核心区别在于：条件的发生与否是不确定的，可能发生也可能不发生，这个才叫条件；而期限是确定会发生的，它一定会到来。

> **结论**：区分条件与期限，不能凭感觉，一定要基于这个标准——这个事实是不是确定会发生。

我们来看三个例子，一起判断。

第一例，甲乙约定：甲之年迈父亲去世以后，即做出违背祖宗的决定，将祖传的清代铜壶以5万的价格卖给你。这里甲乙之间有一个买卖合同。这个合同要发生效力，一方面得符合我们前面讲过的一般要件，但同时按照双方的约定，它的效力还有一个特别的限制：要在甲的年迈父亲去世的时候，合同才能发生效力。那当事人附加的到底是条件还是期限？虽然我们不知道甲的年迈父亲什么时候去世，但人终有一死，这一天是一定会到来的。所以，附的是**期限**，不是条件。

第二例，甲乙约定：甲之年迈父亲80大寿的时候，将其祖传的清代铜壶赠与给乙。这里甲乙之间有一个赠与合同，这个赠与合同的效力附加了一个特别的限制，就是要等到甲的年迈父亲80大寿之时。

有同学说：80大寿，那肯定是期限了。注意，这个理解就错了。尽管听起来像是一个时间，但是“甲之年迈父亲80大寿”这天是不一定会有的——有可能甲的年迈父亲在80大寿之前就去世了。所以它的发生与否是不确定的，它只能是条件。

第三例，甲和所在单位乙公司约定：若甲能在乙公司工作到65周岁，乙公司奖励甲现金10万元。这个奖励10万元的约定增加了一个限制，那就是甲要在乙公司工作到65周岁。一看就是个时间，但这个理解又错了。因为“甲在乙公司工作到65周岁”这个事实是有可能发生、也有可能不发生的：有可能甲活不到65岁，也有可能在60岁之前就离开乙公司了——被乙公司给裁了，是不是也有这种可能？所以它的发生与否不确定，那就只能是一个条件。

| 约定 | 附加的是 | 理由 |
| --- | --- | --- |
| 甲的年迈父亲去世后，把祖传清代铜壶以5万元卖给你 | 期限 | 人终有一死，这一天一定会到来 |
| 甲的年迈父亲80大寿时，将其祖传清代铜壶赠与给乙 | 条件 | 父亲未必活得到80大寿，这一天不一定会有 |
| 甲在乙公司工作到65周岁，乙公司奖励甲现金10万元 | 条件 | 可能活不到65岁，也可能在60岁之前就被裁员 |

说到延迟退休，相信大家都在网上看到过相关报道。不出意外的话，包括我以及各位同学都要赶上延迟退休。我看网上有同学表达一种担忧，说一想到得工作到65周岁，就有点惆怅。

其实这样的想法多少还是乐观了点。延迟到65周岁退休，它的正确理解方式是：你要到65周岁的时候才能够领取退休金。没人能够保证你在60岁之前都是有工作的——很可能在40岁的时候就被裁掉了，你还得找新的工作，必须等到65岁才可以领退休金。有些同学听完以后更惆怅了啊。

### 有些行为，天生就不能附条件

按照法律规定，依照其性质不得附条件和期限的民事法律行为，就不得附条件和期限。也就是：什么样的民事法律行为，依照其性质不得附加条件、期限？这是两类行为。

#### 出于公共利益，身份行为不允许附条件

第一类是公益上不允许附条件，也就是为了维护公共利益，不允许你附条件。它主要体现为婚姻、收养、认领等身份行为。这个身份行为要求必须明确，如果附加条件的话，就处于一个不确定的状态，这是不符合公共利益要求的。

举一个实例。甲男乙女是大学同班同学，而且是男女朋友。甲选择北大考研，乙全力支持。但是乙听说考研圈流行“上岸第一剑，先斩意中人”，于是他希望先和甲确定婚姻关系。可是先结婚，他又担心这个不争气的他考不上北大的话，耽误自己另择佳偶。

于是他想了个办法：我们先办一个结婚登记，然后在登记的时候特别约定双方的婚姻效力，要到甲上岸北大的时候才发生效力。

你们看，双方实施了一个结婚行为，而且给这个结婚行为附加了一个限制：甲上岸北大的时候，婚姻行为才生效。甲能不能上岸北大是不确定的，所以他这个是条件。但是假如给婚姻附加这个条件，是不是使得双方的婚姻关系处于一个非常不稳定的状态？甲会时常怀疑：我到底结婚没？我跟你到底是什么关系？我能不能找别人啊？它会使这个婚姻关系处于一个不稳定的状态。

所以基于公共利益的要求，这样的行为不得附条件——你只要办理了结婚登记，那就是合法的夫妻。

#### 形成权的行使不能附条件

第二种情形，是形成权的行使不允许附条件，主要体现为解除权、撤销权、追认权等等。这些形成权的行使不能附条件，也就是行使还是不行使，必须要明确表示。

比如甲和乙签订一个合同，乙有严重违约行为，所以甲有一个合同的解除权。这个解除权就是一个形成权。甲行使这个形成权，是不是使得甲乙合同的未来甲一个人就可以说了算？那乙的命就处于被别人决定的状态，处于不稳定当中：今天还有合同，可能明天一觉醒来收到短信，合同解除了。

假如甲在行使这个形成权的时候，再附加一个条件——因为这个条件本身发生与否又不确定——那就使得乙更无所适从了，他无法确定自己处于一个什么样的状态。比如甲通知乙说“我要解除合同”，但是有个条件：今年我如果考研没有上岸的话，这个解除权才发生效力。你要是乙的话，你现在这个合同处于什么状态？是不是很难确定啊？一方面本来命运就掌握在别人的手中，同时甲能不能上岸，谁知道什么时候能够确定。

所以为了保护这个乙的私益，让他的法律关系能够明确下来，形成权的行使不能附条件。

当然，理论上有两个例外。

第一个例外是附加条件经过相对方同意的话，法律就允许了。因为法律不允许形成权的行使附条件，主要是为了保护相对方的利益；相对方没意见的话，那法律也没意见。

第二个例外是条件的成就与否纯粹是由相对方来决定的，也就是这个决定权在相对方的手中，那这个附上的条件也不会损害他的利益。比如甲通知要解除合同，行使这个权利，但是他附了一个条件：如果你乙三天内不给我道歉，就发生合同解除的效力——我就要你一个态度。你看乙三天内可能道歉，也可能不道歉，所以是一个条件；但是它完全处于乙的掌控当中，道歉还是不道歉完全由你乙来决定，那合同能不能发生解除的后果也在你乙的掌控之下，那就不会损害你乙的利益。所以这个时候就允许附加这样一个条件。

### 附条件：条件必须直接决定效力

那接下来我们分别来看附条件和附期限的民事法律行为。先看附条件的民事法律行为。

这部分是大家学习的重点。因为条件的发生与否不确定，产生纠纷的可能性就会高一些。

所谓附条件的民事法律行为，指的是当事人在民事法律行为中设定某项事实为条件，以条件的成就与否来决定民事法律行为的效力是发生还是解除。

> **注意**：在附条件的民事法律行为当中，这个条件的成就与否，一定要决定民事法律行为的效力。

我们来看一个小例子。车某为他的豪车购买了交强险和商业险，在保险合同里面约定，发生保险事故的时候，保险公司得赔偿保险金。我们来看这个保险合同是不是附条件的合同？答案是——不是。

尽管这个保险事故可能发生、也可能不发生，但是保险事故的发生只是保险公司赔付保险金的条件，它并不决定保险合同的效力。当车某投保的时候，双方的保险合同已经确定地发生效力了；即使后来没有发生保险事故，也不影响保险合同的效力。就像一年到了没有出现这个保险事故，保险公司用不用把这个保费退给你？当然不用了，因为保险合同它依然是有效的。

那就意味着保险事故发生与否，它不影响保险合同的效力，那就不是附条件的合同。这一点一定要特别注意。

### 条件要同时满足四个特征

在民法里面，条件需要满足以下四个方面的要求：非法定性、合法性、未来性、或然性。

#### 非法定性：条件是约定的，不是法定的

这个条件是当事人约定的，而不能是法律规定的。因为附条件的民事法律行为体现的是当事人的意思自治，是当事人决定给他附加这个限制的。

我们来看一个例子。根据《企业国有资产法》的规定，履行出资人职责的机构决定要转让全部国有资产或者转让部分国有资产，导致国家对该企业丧失控制权的，正因如此，国有企业的股权转让作为特别生效要件。

但这个是不是附条件的合同？不是的。因为这个条件是法律规定的，它体现的不是当事人的意思自治，体现的是国家的意志。我们在合同编会讲这种以审批为生效要件的合同，它是法定的特别生效要件。

#### 合法性：条件必须指向合法的事实

也就是民事法律行为所附加的条件，必须得出合法的事实。

甲给乙说：你要是把丙打残了，这套房子就是你的。你看赠与合同里面附加的条件是，对方要把别人给打残了——这是侵权行为，那这个合同应当认定为无效。

#### 未来性：条件必须是未来的事实

强调这个条件必须是未来的事实，已经发生的事实不能附条件，即使双方当事人不知道这个事实的发生。

比如甲乙在2023年的11月11号约定：若梅西有朝一日能够带队夺得大力神杯的话，甲赠予最新款的华为手机一部。实际上在2022年的卡塔尔世界杯上，梅西已经带领阿根廷夺得大力神杯了。只是甲乙两个人都不看新闻，不知有汉、无论魏晋。尽管甲乙都不知道这个事实已经发生了，但毕竟它是已经发生的事实，所以不能作为条件。

#### 或然性：可能发生，也可能不发生

这个条件可能发生，也可能不发生，这叫或然性。确定发生的那叫期限；如果确定不可能发生的，也不能作为条件。

比如甲跟你说：我这套房子送给你吧。你说：太好了。附加一个条件——太阳从西边出来的时候。大家看太阳有没有可能从西边出来？当然不可能了，所以它不具备或然性的要求，那就不能成为附条件的民事法律行为。

> **易错点**：不满足或然性要求，意味着这个条件永远不可能成就。此时产生的法律后果，要区分当时附加的到底是生效条件还是解除条件。

```text
条件永远不可能成就时
  ├─ 开关 A「打开效力」= 生效条件   开关坏了  →  行为确定不发生效力
  └─ 开关 B「关闭效力」= 解除条件   开关坏了  →  视为未附条件，效力照常维持
```

两个开关对应两类条件：一个负责开启效力，一个负责关闭效力。条件永远不可能成就时，开关本身就是坏的——坏在哪个开关上，后果就落到哪一格。

打个比方。如果当时约定这个条件是生效条件，也就是条件的成就将使得合同或者民事法律行为发生效力，那意味着这个条件是效力“打开的开关”。假如这个事实是不可能发生，那就意味着这个打开的开关是不是坏掉了？那这个民事法律行为将确定地不发生效力，因为开关坏了，不可能打开效力了。

那第二种情形，还是当时约定条件的成就将解除的，也就是它是合同效力关闭的开关。假如这个条件不可能发生，也就是关闭效力的开关坏了，那就意味着——民事法律行为未附条件，就当没有这个条件。

我们来看两个例子。例一：甲乙签订房屋买卖合同，约定当太阳从西边出来的时候，该合同发生效力。合同效力上所附加的是“打开的开关”，因为条件成立的时候该合同发生效力；但太阳不可能从西边出来，这个打开的开关坏了，效力将无法开启，该行为不发生效力。

例二：甲乙签订房屋买卖合同，约定该合同将失去效力。你看按照当时的约定，它是一个效力关闭的开关。这个条件不可能发生，是不是意味着关闭效力的开关坏了？那就视为没有这个开关，也就是视为未附条件，合同依然可以正常维持效力。

所以，或然性这个条件不能满足时，它产生的法律后果，取决于这个条件是生效条件还是解除条件。

最后给这四个要件编个口诀，方便大家去记忆——这是个主观题的考点：**合法非法，防患未然**。这个行为是合法的还是非法的，要防患于未然。

| 口诀 | 对应要件 |
| --- | --- |
| 合法 | 合法性 |
| 非法 | 非法定性 |
| 未 | 未来性 |
| 然 | 或然性 |

### 条件的两种分类

学习不停，分类不止。我们又见到了分类。

| 分类标准 | 类型 | 同义表述 | 条件成就的后果 |
| --- | --- | --- | --- |
| 按条件决定效力的走向 | 延缓条件 | 生效条件、停止条件 | 民事法律行为发生效力 |
| 按条件决定效力的走向 | 解除条件 | 失效条件 | 民事法律行为丧失效力 |
| 按条件内容的不同 | 积极条件 | 肯定条件 | 要求某个事实发生 |
| 按条件内容的不同 | 消极条件 | 否定条件 | 要求某个事实不发生 |

#### 按效力走向分：生效条件与解除条件

假如这个条件的成就将会导致法律行为生效的，这叫延缓条件；实际上这个延缓条件也叫生效条件，《民法典》里用的是“生效条件”，考试分析里用的是“延缓条件”——这是理论上的说法，显得自己很有学问。同时，这种导致法律行为生效的条件，还可能称之为“停止条件”。它们都是同义词。

这意味着，当条件成就的时候，法律行为发生效力；条件不成立的时候，法律行为就不能发生效力。

我们来看一个例子：甲乙约定，若乙2027年考取人大法学院的研究生，将赠予其《王泽鉴全集》精装版一套。大家看双方之间是一个赠与合同，而这个赠与合同能不能生效，取决于什么？取决于乙2027年能不能上岸人大。条件成就，赠与合同发生效力，所以这是一个生效条件，或者叫延缓条件、停止条件，都是一样的意思。

有同学问，考试的时候用哪个词？考试的时候，哪个词最有可能出现，看命题人的心情，所以大家都要掌握。

第二种类型条件叫解除条件，主要指条件的成就将决定民事法律行为丧失效力，也就是条件已成就，民事法律行为失去效力。这叫解除条件，又叫失效条件，它们是完全一样的意思。

比如甲赠给乙《王泽鉴全集》精装版一套，但是按双方约定，乙要考不上人大就要把这个书退还给甲。双方之间有个赠与合同，实际上这个条件成就，也就是乙考不上人大的时候，赠与合同会失去效力，所以他是一个解除条件或失效条件。

你看，尽管这两个例子当中都是考上人大了、有学上有书拿，考不上人大就没书拿也没学上，但是约定方式不一样，那这个条件的类型是完全不同的。

#### 按条件内容分：积极条件与消极条件

主要是看这个条件的成就，是要求某个事实的发生还是不发生。如果条件的成就体现为某个事实的发生，这叫积极条件，或者叫肯定条件。

比如甲乙约定，乙如果在一年内结婚的话，就赠给他房屋一套。你看那个赠与合同中附加了一个条件，那就是“乙在一年内结婚”。这个条件的成就是需要积极事实的发生，必须要有这个结婚的事实发生，所以它叫积极条件。

相应地，如果条件的成就要求某个事实不发生，那就叫消极条件，或者叫否定条件。比如我们刚才举的例子：甲把书赠与乙，双方约定好了，乙2027年未能考取人大研究生的要退还该书，条件的成就体现为乙2027年考不上人大——这是一个消极的事实，叫消极条件或否定条件。

还有一种情形，也是大家在影视剧里面经常看到的情形：甲和某女丙约定，你离开我儿子、不跟我儿子结婚，我就赠给你现金50万。你看甲和丙之间有个赠与合同，而这个赠与合同附带的条件是丙不要和甲的儿子结婚，是不是一个消极的事实？所以它也是一个消极条件。

讲到这里，有同学可能会有个疑问：前面不是讲了吗，结婚、收养这种身份行为是不能附条件的呀？

注意，这里可不是给“结婚”这种行为附加条件。在这个附条件的民事法律行为当中，首先有一个条件，然后还有一个民事法律行为——大家一定要先确定哪个是民事法律行为，哪个是条件。

我们来看这个案情：甲和某女丙约定，若丙不和甲的儿子结婚，则赠与丙现金50万元。你看哪个是民事法律行为啊？不是这个结婚，而是甲赠与给丙50万的现金，这个是民事法律行为。相对于这个赠与合同，我们附加了一个条件：丙不和甲的儿子结婚。而这个丙是不是跟甲的儿子结婚，他发生与否是不确定的，所以他是条件。

我们前面主要是讲结婚行为不能成为被附条件的民事法律行为，但是结不结婚可以成为条件的内容。

有同学问，那这样的约定会不会侵犯丙的婚姻自主权？当然不会了。因为即使甲和丙签了这样的协议，对于丙来讲，他能不能选择就是要跟甲的儿子结婚、我不要你这50万、我要跟你儿子结婚？完全可以。同时，即使丙选择不和甲的儿子结婚，是不是他还可以跟别人结婚？不会影响丙的婚姻自主权。

包括这个积极条件里面的例子：甲和其子乙约定，如果乙在一年内可以结婚，那就赠与乙房产一套。谁是民事法律行为？是甲把房子赠与给乙，这个赠与合同；对他附加的条件是“乙在一年内结婚”。结婚与否发生与否不确定，所以它可以作为条件。而且这样的约定会侵犯乙的婚姻自主权吗？当然不会了——你一年如果不想结婚，那就放弃这个房子不就完了吗？所以它并不影响婚姻自主权。

> **易错点**：结婚不能成为“被附条件的民事法律行为”，但可以成为“条件的内容”。这两件事别搞混了。

### 期待利益：谁动手脚，谁吃亏

如果当时对某个民事法律行为附加了条件，因为这个条件的成就与否是不确定的，那当时对于取得某种利益可能有一种期待——这种期待利益要受到法律的保护。我们在前面讲权利分类的时候，讲到过期待权的概念，这里就涉及到期待权的保障。

如果一方当时为了自己的利益，不正当改变这个条件成就的自然状况，那就侵犯了对方的期待权，至少法律要做出对你不利的推定。

一方如果为了自己的利益不正当地**阻止**条件成就，是不是剥夺了对方取得这个期待利益的机会？那就视为条件已成就。你想方设法地阻止条件成就，法律直接视为条件已成就——就是不能随你的愿，因为你违反了诚信原则。

那假如说当事人为自己的利益不正当地**促成**条件成就，是不是也有可能侵犯对方的一种期待？那这时候要视为条件不成就。

总之，谁不断地干预这个条件成就与否的自然发展趋势，那就做出对谁不利的推定。这是在保护另一方当事人的期待权。

我们来看一个例子：甲乙约定，如果甲2027年考上北大法学院，乙就赠给甲轿车一辆。我相信，如果有人跟你签订这样的协议，你的考研动力肯定会更强——因为通过甲的努力，如果上岸北大，一方面有学上，另一方面呢有车拿，他对合同的未来是有所期待的。双方还对这个合同办理了公证手续，是不是进一步加深了甲的信赖？他觉得只要我好好努力上岸北大，什么都会有的。

后来呢，乙见甲备考训练用功，一想：他要是考上的话，我车都没了啊。甚至熟人之间、亲戚之间，巴不得你考不上。于是他在考试的前夜故意打扰甲休息，导致甲发挥失常，名落孙山。

大家看，尽管从结果角度来讲，甲没有满足“考上北大”这个条件，但是在这个过程中，乙是不是在恶意地阻止这个条件的成就？你在别人考试的前夜去恶意打扰，这明显是一种不诚信的行为。为了自己不赔这辆车，就去破坏别人的前途，法律要对它进行惩罚。即使你不打扰甲，他正常考试也有可能上不了岸，但是因为你乙实施了不正当的行为，使得甲在正常情况下能不能上岸，是不是只有天知道了？所以这个时候要视为条件已成就——就势必他上岸，车你必须要给他。你看这是不是体现对乙不诚信行为的惩罚、对甲期待利益的保护。

### 附期限：一定会到来的那把开关

接下来的是附期限的民事法律行为，相对来讲就比较简单了。它指的是当时约定了一定的期限，以期限的到来来决定法律行为的生效或者失效。因为这个期限它是一定会到来的，所以产生纠纷的可能性相对要小一些。

大家简单了解附期限的民事法律行为的分类：

- **附生效期限的民事法律行为**，也叫**延缓期限**：某个期限的到来会导致民事法律行为发生效力，也就是打开效力的开关。
- **附终止期限的民事法律行为**，也叫**解除期限**：某个期限的到来会导致民事法律行为失去效力，也就是关闭效力的开关。

到这里，这一节就全部讲完了。

### 回头看一眼：第六章讲完了

随着这一节的结束，我们非常漫长的第六章“民事法律行为”也就全部讲完了。

整体上我们讲了两个层次。第一个层次是理论问题，大家要了解民事法律行为的含义、特征以及分类，特别是分类，是一个特别重要的考点。

第二个层次，我们展开了民事法律行为的规范。这个规范分成了成立和生效两个层次。

- **成立**，解决的是“有没有一个民事法律行为”这个构成问题，重点给大家讲了成立要件，以及其中意思表示的相关规则。
- **生效**，解决的是已经成立的民事法律行为在法律上作何评价，也就是“行不行”的问题。生效要件又进一步区分一般要件和特别要件。一般要件有没有满足，我们把民事法律行为的效力评价为四种形态，分别是有效、可撤销、效力未定以及无效。
- 特别要件，我们重点给大家讲了约定的特别要件，也就是附条件和附期限的民事法律行为。当然还有一个法定的特别要件，也就是合同以审批为生效要件的问题，我们放到合同编再给大家介绍。

### 本讲提到的题目

#### 甲的儿子去外地工作，房屋租赁合同即行生效

甲乙约定：甲的儿子如果去外地工作，甲乙之间的房屋租赁合同即行生效。

**解析**

先确定这个民事法律行为，是甲乙之间的房屋租赁合同；所附的条件，是“甲的儿子去外地工作”。

第一步，判断是解除条件还是延缓条件。看条件成就时会导致法律行为生效还是失效——既然是“甲的儿子去外地工作，甲乙的租赁合同即行生效”，那意味着这个条件是打开效力的开关，它是**延缓条件**。选择 A、B 都是错的。

第二步，判断是积极条件还是消极条件。要看条件的成就是要求某个事实发生还是不发生。条件内容是“儿子去外地工作”，它是一个积极的事实要发生，所以应该是**积极条件**。

**答案：D，即积极的延缓条件。**
