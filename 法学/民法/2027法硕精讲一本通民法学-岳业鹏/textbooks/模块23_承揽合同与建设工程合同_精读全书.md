## 完成工作交付成果的两种合同
> 对应块：BLK110 | 覆盖分集：P106 | 块标题（分集名）：《第05编 第02章 第03节：完成工作交付成果的》

### 一个从"修电脑"讲起的故事

咱们先从一个生活里再常见不过的场景讲起。

车某的电脑因为浏览有害网页中了病毒，怎么也开不了机，于是找到经验丰富的老马修理厂来修。你把这个修理合同拎出来看一眼：老马把电脑修好之后再交还给车某，这叫**完成工作交付成果**；车某则要付修理费。这两个动作凑在一起，就是**承揽合同**。

别小看这个例子。前咱们讲留置权的时候举的修理例子，标的物压根儿不是什么"物"，而是"活儿"。这一节我们讲两种典型的"完成工作交付成果"的合同——**承揽合同**和**建设工程合同**。两种合同都是三个层次往下推：先看概述（概念与特征），再看效力（双方各自的合同义务），最后看特别制度。承揽合同是基础，建设工程合同是本节的难点。

### 承揽合同的定义：记住"做"字别写成"人"

理解承揽合同的定义，还是要盯着**双方当事人及其合同义务**这两头。

先把当事人对上号。车某这一方是任务的提供者，叫**定作人**——注意，是"定作人"。讲师特别提醒过，"做"这个字是"作业"的做，来自承揽人"做工作"的意思，**千万不要写成"做人"**。而"定作"里的"定"，取的是"你给提供任务、我按你的要求去做"的意思。老马修理厂这一方则叫**承揽人**，同样是专业术语，指完成工作并交付成果的一方。

对上号之后看义务，会发现极其简单：

- **承揽人**：按照定做的要求完成工作，交付工作成果。第一是完成工作——老马得把电脑修好；第二是交付成果——修好的电脑得交还给车某。两步都做完，车某才又能继续去浏览那些有害网页。
- **定作人**：支付报酬，也就是付修理费。就这么简单。

> **定义**：承揽合同是承揽人按照定作人的要求完成工作，交付工作成果，定作人支付报酬的合同。

这里的"工作"是个大口袋，**加工、定作、修理、复制、测试、检验等等，都可以纳入承揽合同的规范范围**。疫情期间我们去做核酸检测找检测机构或医院，那个合同也是典型的承揽合同：检测机构完成检测工作，交付一份核酸报告；我们支付检测费用。结构和老马修电脑一模一样。

### 承揽合同的特征：要素定位加性质定位

特征的展开还是老模板：先做**要素定位**（主体、标的或标的物、内容），再做**性质定位**（双务有偿诺成要式这几个标识到底符合几个）。这个模板咱们已经用过很多次了，大家应该已经掌握。

#### 要素定位

**主体方面没有特殊性。** 但教材在这里补充了一个特征，强调**合同的目的**：承揽合同是以**完成工作并交付成果**为目的的。还记得吗？前面讲合同的特征时会体现目的，比如供用水气热力合同的目的具有公益性，保证合同的特征里强调其担保性，也都是跟目的相关的。

这里的关键在于：**不仅要完成工作，更要交付成果**。回到开头的案例，老马一看车某这台中毒太深，修不好了，能不能请求车某支付修理费？当然不能。因为你没有完成工作并交付成果。

**标的物方面具有特定性。** 标的问的是承揽人应当向定作人交付的工作成果，它具有特定性——体现的是一种**私人定制**的工作任务。你看这个案例里：车某来找老马修电脑，故障是浏览有害网页中毒；而岳母的电脑也坏了，因为她天天写稿子，电脑超负荷运转也坏了。虽然都是"电脑坏了"，但你找老马来修，不同的电脑就是不同的问题。**每一个工作成果都是特定的**，都要按照定做的要求来完成特定的成果。

**内容方面，承揽人的义务具有不可让与性**，体现的是**专属性**。这意味着承揽人不能随便把这个合同义务转给别人来履行——这样就辜负了定作人的信赖了。你想想，车某的电脑坏了，为什么不找岳母来修，而要找老马？因为他觉得老马修这种电脑更有经验，岳母没这个经验、技术水平不行，他更信赖经验丰富的老马。那这时候老马能不能把这个业务直接转让给别人？不能。

> **易错点**：不可让与性说的是**合同义务本身**不能让与，不是说标的物不能转让。定作人完全可以把修好的电脑转手卖给岳母——那是处分所有权，与承揽合同无关。

#### 性质定位

按双务有偿诺成要式这几个标识逐条检索，承揽合同**四个全部符合**。

> **结论**：承揽合同是典型的同时履行抗辩权适用、双务、有偿、诺成、要式（实践）合同，也就是说，**口头形式和书面形式都可以成立**。

### 承揽合同的效力：双方各自的合同义务

看效力依然以"完成工作交付成果"这一方的义务为主线展开。在承揽合同中，完成工作交付成果的是**承揽人**，所以先看承揽人。

这里我给大家建构一个表达的模板，一方面方便理解，另一方面也方便后期背诵。同样是三个层次：

```text
┌────────────────────────────────────────────┐
│ 层次一  完成工作的过程中产生的义务            │
│         材料 · 亲自完成主要工作 · 接受监督    │
├────────────────────────────────────────────┤
│ 层次二  与交付成果相关的义务                 │
│         交付工作成果                          │
├────────────────────────────────────────────┤
│ 层次三  与瑕疵担保相关的义务                 │
│         瑕疵担保 + 妥善保管                   │
└────────────────────────────────────────────┘
```

这个模板在后面讲建设工程合同的时候会再用一次，所以现在务必记牢。

#### 承揽人的义务

**先看层次一：完成工作的过程中产生的义务。**

第一项是**按照约定提供材料或者妥善处理定作人提供的材料**。材料在完成工作过程中，涉及跟材料相关的义务；而材料既可以是承揽人提供，也可以是定作人提供。举个例子：某同学要去裁缝店做一套西装，这是典型的承揽合同，那做这套西装就涉及谁提供布料的问题。布料当然可以由裁缝店按约定提供；也可以由这位同学自己提供，那这时候承揽人就得**妥善处理定作人提供的材料**。都是完成工作过程中跟材料相关的义务。

第二项是**用自己的设备、技术和劳力来完成主要工作，要亲自完成承揽工作**。因为承揽合同体现的是定作人对承揽人技术的信赖。假设承揽人擅自把主要工作交给第三人来完成，是不是辜负了定作人的信任？**这时候定作人可以解除合同**。还是车某找老马修电脑的例子，因为他相信老马的经验和技术；老马擅自把业务交给别人来完成，那就辜负了车某的信赖，车某可以解除合同。

但这里有个细节特别容易搞错：**即使经过了定作人的同意**，承揽人把工作交给第三人完成，那瑕疵担保责任依然要遵循**合同的相对性原理**。设想老马经过车某的同意，因为觉得那位修理师经验也很丰富，把电脑交给他来修，结果那人争气，**电脑给修坏了**。请问车某找谁来主张违约责任？**要找老马。**因为老马是合同的当事人，尽管是第三人实际履行的，第三人履行不符合约定的，违约责任仍由合同当事人（承揽人老马）承担。这叫合同的相对性原理。

第三项义务是**接受监督**。定作人可以监督承揽的工作有没有满足特定的要求。

**再看层次二：与交付成果相关的义务。** 成果完成了，要把成果交付给定作人——老马得把修好的电脑交给车某。

**最后是层次三：瑕疵担保责任。** 承揽人对交付的成果要负一个瑕疵担保义务和妥善保管的义务。假如老马把电脑交给车某的时候，电脑还是开不了机，车某能不能请求老马继续履行？当然可以，这就是瑕疵担保的义务。

#### 定作人的义务

定作人的义务要通过**对价关系**来推导或理解，同样是三个层次：完成工作、交付成果、瑕疵担保。

**层次一是完成工作的过程中产生的义务。** 第一项是**按照约定提供材料**——如果双方约定由定作人提供原材料的，定作人得按约定提供，方便承揽人完成工作。第二是**协助义务**——承揽工作需要定作人协助的，定作人负有协助的义务。比如你让别人给你做西装，裁缝店得先量体才能够裁衣，你不肯配合量体，对方没法履行义务。

**层次二是与交付成果相关的义务。** 承揽人把工作成果交付给定作人，作为对价，定作人得**支付报酬**，也就是修理费。

**层次三是瑕疵担保义务。** 既然承揽人对瑕疵负担保义务，那就要求定作人得**按时接受并验收这个工作成果**——你得确定成果到底有没有瑕疵，来方便对方履行瑕疵担保的义务。

这样双方的三层义务就形成一个漂亮的对价结构：

```text
     定作人                              承揽人
 ┌──────────────┐                   ┌──────────────┐
 │ 提供材料      │                   │ 提供材料 /    │
 │ 协助履约      │ ── 承揽合同 ──▶  │ 处理定作材料 │
 │ 支付报酬      │                   │ 亲自完成主要工作│
 │ 验收工作成果  │                   │ 接受监督      │
 │              │                   │ 交付工作成果  │
 │              │                   │ 瑕疵担保+保管 │
 └──────────────┘                   └──────────────┘
```

### 承揽合同的特别制度

承揽合同有三项特别制度。

#### 承揽人的留置权与拒绝交付权

前面讲留置权的时候提到过，承揽合同中债权债务是**可以属于同一法律关系**的，所以有可能产生留置权。法律规定：**定作人未向承揽人支付报酬或者材料费等价款的，承揽人对于完成的工作成果享有留置权或者有权拒绝交付。**

这个留置权相对好理解，但"有权拒绝交付"是什么意思？**这是民法典里面特别增加的**，主要针对承揽人行使抗辩权的情形。请看清这个裁缝店的例子——

甲同学要参加面试，需要一套西装，于是和裁缝店乙签订合同，让乙给他做一套西装。双方成立的是承揽合同。

**情形一：原材料由甲提供，乙只负责加工、收点加工费。** 乙按要求把西装做完了，这时西装的所有权归属于谁？**归属于甲**，因为原材料是甲提供的。那么甲如果不付加工费，裁缝店能不能留置这件服装？当然可以，他可以行使留置权——因为他是在**合法占有债务人甲的动产**，满足行使留置权的条件。留置之后，在宽限期内甲还不付加工费，乙能不能卖掉西装优先清偿自己的加工费？**当然可以**，因为留置权具有**担保**的功能。

**情形二：原材料（布料）由裁缝店提供。** 做完的衣服所有权归属于谁？**归属于裁缝店。**那甲不付相关费用，裁缝店能不能行使留置权？**注意，答案是不能。**一方面**，裁缝店占的是**自己的动产**；讲留置权时我们提到过，行使留置权时也可以占有第三人的动产，但**绝对不包括债权人占有自己动产**的情形，不符合行使留置权的条件。**另一方面**，即便给了甲宽限期，宽限期内甲依然不付加工费，裁缝店能不能卖掉西装优先清偿加工费？**当然不能。**为什么？因为这件西装是你的，凭什么卖掉西装替甲还加工费？**它并不具备担保的功能。**

这时候裁缝店只是**有权拒绝交付**这个西装。所以你看，民法典增加的后面这句话"有权拒绝交付"，跟"行使留置权"正好形成了对比。但要具体问题具体分析：**这里的"拒绝交付"体现为履行抗辩权的行使**——因为双方的债务是形成对价关系的，你不付钱，我当然可以不交付这个西装。但裁缝店**不是在行使留置权**。

> **结论**：承揽人对完成的工作成果享有留置权**或者**有权拒绝交付——前者是担保物权，后者只是履行抗辩权，性质完全不同，不要混为一谈。

#### 定作人的任意变更权与随时解除权

**注意：变更权和解除权只有定作人这一方有，承揽人是没有的。**

**任意变更权。** 定作人中途变更承揽工作要求，造成承揽人损失的，应当赔偿损失。也就是说定作人中途**能不能**变更工作要求？可以，只是这个变更有代价——给对方造成损失的要承担赔偿责任。来看案例：何女士提供了三块木料给一个家具厂来制作衣柜，双方成立承揽合同，何女士是定作人，家具厂是承揽人。老马开工后不久，何女士觉得衣柜样式不够新潮，于是要求家具厂停止制作、换一个款式。但家具厂认为这是无理的要求——**开工了，哪有什么回头箭啊**，于是执意按原来的款式做完了家具。

请问何女士有没有中途变更工作要求的权利？**答案是有的。**因为承揽合同是按照定做的要求来完成工作的，成果具有特定性——假如定作要求变了，承揽人依然按照原来的要求完成工作，对定作人来讲可能已经没有意义了。所以应当允许定作人中途变更工作要求，享有任意变更权。这意味着：**家具厂不顾何女士的变更要求而按原款式完成家具的，要承担违约责任。**而何女士行使这个任意变更权是要付出代价的——给对方造成损失的，要承担赔偿责任。

**随时解除权。** 法律规定：**定作人在承揽人完成工作之前，可以随时解除合同。** 因为承揽合同是基于定作人对承揽人的信赖而产生的。假如在工作完成过程中定作人对他失去了信任，应当允许他解除合同——因为对方这时候再去干这个工作，有可能不符合订立合同的目的了。

这里要强调**三个细节**：

1. **只有定作人这一方享有随时解除权**，承揽人原则上没有。合同是基于你对于定作人的信赖产生的吗？不是，是基于定作人对你的信赖产生的，是从事某种经营活动，所以承揽人这一方没有任意解除权。
2. **行使权利的前提是承揽人完成工作之前**。假设承揽人已经把工作完成了，这时定作人就不能再行使任意解除权了。
3. **这个权利的行使也是有代价的**，给对方造成损失的要承担赔偿责任。

#### 数个承揽人的连带责任

假设承揽人有数人，是不是数个承揽人要共同完成工作，然后对定作人承担连带责任？所以注意，**共同承揽人对定作人承担连带责任**。

承揽合同的规则讲完了，也是三个层次：概念特征、效力、特别制度。最后还有一个典型真题，放在文末。

### 建设工程合同：本节的难点

建设工程合同是我们这一节的难点问题，整体上同样是三个层次：概述、典型合同的效力、特别制度。

#### 从中建八局说起

某个开发商取得了某地块的建设用地使用权，要开发一个住宅项目，这个项目由中建八局来承建。开发商和中建八局签订的合同就叫**建设工程合同**。

理解定义还是看双方当事人及其主体为义务。一方是**承包人**，他的合同义务是进行工程建设、完成工作并交付成果；另一方叫**发包人**，他的合同义务是支付**工程价款**。

这里有个范围问题：所谓"进行工程建设"，**既包括工程勘察设计，也包括工程施工**。所以民法典所称的建设工程合同，既包括建设工程的**勘察设计合同**，也包括建设工程的**施工合同**。只是施工合同是大家掌握的重点，也是难点。

> **提示**：司法解释一我们前面已经讲过了，**司法解释二很有可能在今年颁布，大家做好思想准备。**

#### 建设工程合同的特征

还是要素定位加性质定位。

**要素定位。**

**主体具有限定性。** 特别是承包人这一方，**他必须是经过批准的、具有相应资质的单位**。你得有工程资质才能进行工程建设——因为建设完成的工程是关乎公共安全的，没有资质是不允许签订建设工程合同的。

**标的具有特殊性。** 建设工程合同本质上**也是承揽合同**，也是要完成一个工作并交付成果，只是这个成果比较特别，是一个**基本建设工程**。

**内容强调合同的管理具有严格性。** 特别是订立要通过**招标投标**方式来订立，合同的履行也需要进行严格的管理。按照我国民法典的规定，**建设工程合同履行必须得有独立的工程监理人来监督工程的质量**。

**性质定位。** 按双务有偿诺成要式逐条检索，**前三个都是符合的**。所以这里要重点记最后一项：建设工程合同是典型的**要式合同**，必须通过书面形式来订立。特别是建设工程施工合同，履行周期非常长，要通过书面形式来明确当事人的合同义务。

对比一下这两种合同的特征差异：

| 要素 | 承揽合同 | 建设工程合同 |
| --- | --- | --- |
| 主体 | 无特殊性 | 有限定性，承包人须经批准、有相应资质 |
| 标的 | 工作成果，具有特定性（私人定制） | 基本建设工程，本质上也是承揽 |
| 内容 | 承揽人义务具有不可让与性 | 管理严格：招标投标订立 + 独立工程监理人监督 |
| 形式 | 口头、书面均可 | 要式合同，须书面订立 |

#### 订立规则：招投标与阴阳合同

建设工程合同订立中要掌握两项规则。

**第一项是订立原则上要采取招标投标的方式**，也就是采取公开缔约的方式，保证缔约过程的公开、公平、公正。

通过招投标程序成立合同以后，当事人要把这个合同进行**备案**——只能有一个中标的备案合同。但在实践中，当事人有可能私下另行签订一个合同，这样就出现了建设工程领域的**黑白合同或阴阳合同**现象。这是司法解释的规定：招标人和中标人另行签订的建设工程施工合同，约定的**工程范围、工期、质量、价款等实施内容**和**中标合同不一致**的，**要以备案的中标合同为准**。

```text
            招投标（公开缔约）
                  │
        ┌─────────┴──────────┐
        ▼                    ▼
   中标合同              另行私下签订
   → 备案                （锁在抽屉里）
   → 阳合同              → 阴合同
   拿得出来、见得了光    见不了光
        │                    │
        └──── 内容不一致 ────┘
                  │
                  ▼
        以备案的中标合同为准
```

你看，中标备案合同是**阳合同**，可以拿出来看；而双方另行签订的合同是放在抽屉里面的，常常是**见不了光**的，这就叫**阴合同**。两个合同约定内容不一致的，要以中标备案合同为准。这条规则体现的是**招投标程序的权威性**。

看教材实例：甲公司和乙公司签订建设工程施工合同，甲公司把工程发包给乙公司施工。经备案的中标合同约定的**工程造价是 1 亿元**，但双方私下约定的**工程造价是 8000 万**——相当于承包人要给开发商 2000 万的回扣。合同履行中双方对应当支付的工程款数额产生争议时，以哪个为准？**要以备案的中标合同为准**，也就是以 1 亿元这个工程造价为准。

**第二项是分包问题**，也就是承包人把拿到的工程中一部分交给别人来完成。民法典实际上**并没有完全禁止分包**——只要满足法律规定的条件，就是合法的分包。合法分包需要**同时满足**四个条件：

| 序号 | 条件 | 立法理由 |
| --- | --- | --- |
| 一 | 经发包人同意 | 发包人不能全盘信任你才把工程交给你，你要让一部分别人完成，得经过发包人同意 |
| 二 | 分包人具有相应的建筑资质 | 分包人负责建设的话，得有相应资质 |
| 三 | 分包只能是非主体工程 | 主体工程还得由承包人亲自完成 |
| 四 | 分包人不得再行分包 | 分包只能是一次 |

同时满足四个条件的，是合法分包，应当认定为**有效**；**欠缺任何一个条件的，就是违法分包，应当认定为无效**。

#### 建设工程合同的无效：五种情形

因为建设工程关涉公共安全，这个领域强制性规定比较多，所以要了解它的无效情形。民法典及司法解释总共规定了**五项**：

1. **承包人没有取得建筑资质，或者超越资质等级**签订合同的，无效——主体不合格，欠缺资质就很难保障工程建设质量。
2. **无资质的实际施工人借用他人名义**签订的，无效——你自己没有资质却亲自建设，无法确保工程质量。
3. **未招标或者中标无效**的，无效——前面讲了原则上要以招投标方式公开缔约。
4. **承包人非法转包**签订建设工程合同的，无效。**注意"转包"这个词，它跟分包不一样**：转包说的是承包人拿到工程以后自己什么都不干，直接转手给别人，自己作为中间商只赚一个差价。转包行为是法律所禁止的，所以叫**非法转包**，一律认定为无效。比如甲公司把工程承包给乙公司，乙公司什么都不干，直接转手让丙公司来干这个活，那乙、丙签订的合同就叫转包合同，应当认定无效。
5. **违法分包**建设工程的合同，也是无效的——前面讲过，分包只是把工程中一部分拿出来给别人干，符合要件的是合法分包，欠缺任一要件的就是违法分包。

这五种情形大致也可以按照**主体—意思表示—内容**的思路展开：我们在总则编讲民事法律行为的无效情形时就是这个思路，建设工程合同本身也是民事法律行为。**前两项**是跟主体相关的（无资质、借用资质）；**第三项**未招标或中标无效，是意思表示方面的无效（法律要求公开缔约）；**后两项**非法转包、违法分包，是内容层面的无效。

看教材实例：甲公司将一个工程发包给了乙建筑公司，经过甲公司同意以后，乙公司将**部分非主体工程**分包给了丙建筑公司；接着丙公司又将其中一部分分包给了丁建筑公司。判断这两个分包合同的效力：

- **乙与丙签订的分包合同有效。**逐条检验合法分包的四个要件：有没有经过发包人甲公司同意？经过了。丙公司作为建筑公司有没有建筑资质？有。是不是非主体工程的分包？是。分包是不是第一次？是。**完美符合了合法分包的四个要件**，应认定为有效。
- **丙与丁签订的分包合同无效。**因为丙自己已经是分包人了，**分包只能是一次**，再分包的话这个合同就是无效的。

#### 合同无效之后：活到底能不能白干

虽然合同被认定无效了，但工人已经辛辛苦苦把活干完了，能不能拿到工程款？要具体问题具体分析，**也不能说合同无效就一律不给钱**，这不太合适。

按照民法典的规定，**关键是要看这个建设工程有没有验收合格——关键是看活干的怎么样。**

```text
            建设工程合同被认定无效
                      │
                      ▼
              工程是否验收合格？
            ┌─────────┴─────────┐
            ▼                   ▼
          合格                 不合格
            │                   │
            ▼                   ▼
  参照合同约定的工程价款      先修复；修复费用
      补偿给承包人            由承包人自己承担
  （活不白干，毕竟干得不错）        │
                             ┌─────┴─────┐
                             ▼           ▼
                           合格        仍不合格
                             │           │
                             ▼           ▼
                       参照合同约定     无权主张工程款
                          补偿工程款
```

验收合格的，即使合同无效，也可以**参照合同约定的工程价款**来补偿给承包人——活不白干，毕竟干得还不错。

验收不合格的，这时候就要进行修复了。之前没干好，那就继续补救，**修复的费用由承包人自己来承担**——因为你之前没干好，现在要返工了，这费用由你来承担。经修复以后工程合格了，可以参照合同的约定来补偿工程款，也能拿到钱。但**经过修复以后仍然不合格的，就无权主张工程款**了。

有些同学会问：那建筑工人这个活就白干了？是不是对建筑工人不公平？**也不能这么讲。**因为你站在发包人的角度来讲，你们干的活不合格，这个建筑**工程**是不能够交付使用的——开发商前期的投入可能全部都打水漂了，他的损失更惨重。所以建筑工人这个时候是无法取得工程款的。当然，**如果发包人对工程质量不合格也有过错的，也得承担相应的责任**。

看一个典型真题：某建筑队借用 A 建筑公司的资质，以 A 公司的名义和 B 公司签订建设工程施工合同。什么叫建筑队借用 A 公司的资质？这意味着**实际履行合同、实际签订合同的建筑队没有建筑资质**。该施工合同效力如何？**应当认定是无效的合同**，因为主体不合格。但是——假如建筑队把这个活给干完了，是不是一定拿不到钱？**也不一定**。只要工程验收合格的，可以参照合同的约定来主张工程款。

### 建设工程合同中双方的义务

这里要区分勘察设计合同和施工合同分别介绍，两者都以**承包人**（完成工作交付成果的一方）的义务作为主线，同样是"完成工作—交付成果—瑕疵担保"这三层模板。

#### 勘察设计合同

**承包人的三层义务：**

- 完成工作的过程中：**按照合同约定按期完成勘察设计工作**，同时**按照合同约定完成协作事项**。
- 与交付成果相关：**向发包人提交勘察设计成果**——你得有成果。
- 与瑕疵担保相关：**对勘察设计成果负瑕疵担保责任**。

**发包人的三层义务**（通过对价关系推导）：

- 完成工作的过程中：按照合同约定**全面、准确、及时地提供开展勘察设计工作所需要的基础资料和技术要求**，并**按照合同约定提供必要的协助事项和工作条件**——就是配合对方完成勘察设计工作。
- 与成果交付相关：**支付勘察设计费**，体现对价关系。
- 与瑕疵担保相关：**维护勘察设计成果**。既然承包人要负瑕疵担保责任，就要求发包人也得维护勘察设计成果——双方形成一个对价关系。

#### 建设工程施工合同

这是要掌握的重点了，同样以承包人的义务为主线展开。

**承包人的三层义务：**

- 完成工作的过程中：**应当按时开工**，开工以后**按照要求来施工**，而且整个过程**接受发包人的必要监督**。
- 与交付成果相关：**按期按质完工并交付建设工程**，这是**主给付义务**。
- 与瑕疵担保相关：**对工程质量的安全负担保责任**，确保工程质量。假如因为承包人原因导致工程质量有缺陷、造成他人损害的，承包人要承担赔偿责任。

**发包人的三层义务**（对价推导）：

- 完成工作的过程中：承包人主要负责施工，发包人负责配合。第一项是**做好施工前的准备工作**，按约定提供材料设备、场地、资金等；第二项是**为承包人提供必要的条件，保证工程建设的顺利进行**。
- 与交付成果相关：承包人按期按质完工、交付建设工程，作为对价，发包人**支付工程价款**，这是发包人的主给付义务。
- 与瑕疵担保相关：**组织工程验收并接收建设工程**——确认承包的工程到底有没有符合约定的品质。

### 工程价款的优先受偿权

建设工程合同的特别制度主要讲一项：**工程价款的优先受偿权**。这个制度比较重要，司法解释的法条分题这样的主观题里面考过。

《民法典》第 807 条的构造是这样的：在建设工程合同中，发包人的主给付义务就是给付工程价款；如果发包人没有给付，承包人可以**催告其在合理期限内支付**；假如说**逾期仍不支付的**，承包人可以跟发包人**协议将工程折价**，或者**请求人民法院将工程依法拍卖**，并就折价或者拍卖取得的价款来**优先受偿**。

那么，工程价款本质上是一个**债权**，法律为什么赋予它优先受偿的效力呢？因为**工程价款体现的是建筑工人的辛苦钱**，从政策角度来讲要给予更加优先的保障——所以法律设置了工程价款的优先受偿权制度。

#### 规范性质：强制性规定

这个规范性质属于**强制性规定**。这意味着工程价款的优先受偿权**能不能通过当事人的约定来随便排除？不可以。**

如果当事人约定放弃或限制工程价款的优先受偿权，**损害了建筑工人的利益**，这个约定应当认定是**无效**的。认定无效的核心就在于它损害了建筑工人的利益——因为保障弱势群体的合法权益，本身也是**公序良俗**的组成部分。当然，如果约定放弃或限制优先受偿权**没有损害建筑工人利益的**，这个约定也可以认定是有效的。

> **结论**：判断"放弃优先受偿权"条款效力的核心标准只有一个——**是否损害建筑工人的利益**。

#### 权利保障的顺位

承包人有优先受偿权，那么在和其他权利产生冲突的时候，它处于优先地位，就要确定权利保障的顺位。

按照相关司法解释的规定，**建设工程承包人的优先受偿权要优于抵押权和其他债权**。注意，它**可以优先于抵押权这样的担保物权**。为什么？因为抵押权主要是银行在从事经营活动中设立，担保的是银行的债权；而工程价款保障的是建筑工人的辛苦钱，抵押权可以先于普通债权，但让位给工程价款优先受偿权。

教材还补充了一个**拓展内容**：这个司法解释确立了一个**更加优先的保障对象——商品房消费者的请求权**。

为什么？近几年房地产市场不太景气，好多地方都出现了**烂尾楼**。实际上我们现在好多住宅项目都是通过**预售**的方式出售的——卖房子的时候房子还没建起来，只要符合相关规定就可以跟买方签订买卖合同。买方已经支付了价款，而且开始还房贷。可现在房屋烂尾了，买房人拿不到房子：不仅是之前交的房款有可能打水漂，**未来的 20 年到 30 年还有可能得背负房贷**——可以说是房地产领域**最惨的一类群体**。既然你最惨，司法解释就要给你最优先级别的保障。

司法解释规定：**商品房消费者以居住为目的购买房屋**——注意这个前提，消费者必须得是以居住为目的购买，才能够获得更加优先的保障。这意味着一句话：**炒房者赔钱活该。**消费者有权主张其房屋的交付请求权**优先于建设工程价款的优先受偿权**。

理由摆在这里：工程价款的优先受偿权保障的是建筑工人的辛苦钱，拿不到钱只是活白干了；而这个消费者拿不到房，意味着**鸡飞蛋打**——不仅之前的收入都砸进去了，为了房子还得背负债务。所以他要优先于工程价款的优先受偿权。这意味着，**即使开发商没有付清工程款，在拍卖这个工程的时候，已经卖给消费者的房子就不能进行拍卖了**，先保障消费者的房屋交付请求权。当然，如果房屋不能交付、根本没有实际交付的可能——就是烂尾烂透了，商品房消费者可以主张解除合同；解除合同以后可以请求开发商退还价款。这个退还价款的请求权**本质上也是一个债权请求权，但它同样优先于工程价款的优先受偿权**——还是要优先保障商品房消费者的权利，因为他是最惨的。

看这个案例串起整个顺位。恒某公司在 2021 年 3 月份取得了某地块的建设用地使用权，用于开发花园洋房。8 月份，恒某公司向甲银行申请贷款 1 亿元，甲银行享有一个贷款债权，同时以该地块的建设用地使用权申请抵押、办理了抵押登记，所以甲银行是**抵押权人（担保物权人）**。9 月份，恒某公司向土豪老马融资 1000 万，老马虽然很有钱，但法律意识淡薄，没有设定任何担保，所以他是个**普通债权人**。10 月份，恒某公司和金城公司签订了建设工程合同，工程价款 2000 万。2022 年 1 月份，恒某公司经过预售许可对外销售商品房，张某买了一套房子、签订合同并支付了价款。后来恒某公司资金链断裂，工程烂尾了，张某就主张解除合同、要退还房款。经查，银行的贷款没还，工程价款也没付，恒某公司就这么倒下了。

这里出现了**四个主体**都想要找恒某公司要钱，而恒某公司现在只剩土地使用权和在建工程值点钱。拍卖在建工程取得的价款要先还哪一个债权人？

```text
   恒某公司倒下后，只剩土地使用权与在建工程值钱。
   拍卖／变价款按下列顺序分配：

   ┌────────────────────────────────────────────────┐
   │ ①  商品房消费者张某 —— 退还房款请求权（最优先） │  最惨，先保
   ├────────────────────────────────────────────────┤
   │ ②  承包人金城公司 —— 工程价款优先受偿权        │  建筑工人辛苦钱
   ├────────────────────────────────────────────────┤
   │ ③  抵押权人甲银行 —— 担保物权                │  让位，但仍先于普通债权
   ├────────────────────────────────────────────────┤
   │ ④  普通债权人老马 —— 无担保债权                │  最后收场
   └────────────────────────────────────────────────┘
```

第一位是**商品房消费者张某**，先得把房款退给他，因为他是最惨的；第二位是**承包人的工程价款**，要保障建筑工人的辛苦钱；第三位是**抵押权人甲银行**，因为他享有物权；第四位是**普通债权人老马**。

#### 行使范围

是不是欠承包人的钱都可以纳入优先受偿的范围？**当然不是。**所以要确定哪些价款部分可以享受优先受偿权的保障。

**首先得按照相关主管部门的规定来确定**，主要指向的是**最基本的工程价款部分**，比如垫付的材料款以及建筑工人的报酬等等。

而**逾期支付建设工程价款的利息、违约金、损害赔偿金是不能纳入优先受偿范围的**。因为这部分体现的是**因发包人违约给承包人造成的损失**，这个损失赔偿其实并不体现为建筑工人的辛苦钱，所以不能享受优先受偿的保障。

说白了也是变相地保护排到后面的抵押权人和普通债权人：**虽然可以让你插队优先出场，但是你不能没完没了**，所以要确定优先受偿的具体范围。

#### 行使期限

优先受偿权是有行使期限的。假如这个工程价款的优先受偿权无期限地行使，那后面的抵押权人都不知道什么时候能行使权利了，所以要受到行使期限的限制。

- 首先应当在**合理期内行使**；其中具有可操作性的标准是，**最长期限最长不得超过 18 个月**。
- 这 18 个月**从发包人应当给付工程价款之日起算**，也就是发包人的工程价款**逾期期满**的时候，就要开始计算这 18 个月的最长期限。
- 如果期限届满、优先受偿权依然没有行使的，这个权利就**自然消灭**了。这个时候，抵押权人就可以启动实现抵押权的程序了。

至此，完成工作交付成果的两种合同就介绍完了。整体上也是先掌握概述，再关注典型合同的效力，最后是特别制度。

### 本讲提到的题目

#### 承揽合同中的转委托

A 公司和 B 公司签订合同，约定 A 公司为 B 公司制作家具 100 套，价款 100 万元。双方成立承揽合同，B 公司是定作人，A 公司是承揽人。双方约定：B 公司预付价款，A 公司提供制作家具所需的木材，B 公司提供设计图纸。然后 A 公司未经 B 公司同意，委托 C 公司来制作其中的 50 套家具。C 公司制作完毕，且家具质量符合 A 公司和 B 公司之间合同的约定。

判断下列说法正确的是：

- A. B 公司有权解除与 A 公司之间的合同
- B. B 公司不得拒绝接受 C 公司制作的家具
- C. B 公司有权请求撤销 A 公司和 C 公司之间的合同
- D. B 公司事后追认转包行为的，A 公司无需就 C 公司制作的家具向 B 公司负责

**答案：A。**

**A 正确。** A 公司作为承揽人擅自把主要工作交给第三人完成，辜负了定作人 B 公司对它的信任，定作人可以解除合同。

**B 错误。** A 公司是擅自把任务交给 C 公司来完成的，B 公司当然有权拒绝接受。尽管 C 公司制作的家具是合格的，但我 B 公司要的是你 A 公司做的家具。

**C 错误。** B 公司作为定作人并不具备撤销权（撤销权属于意思表示受欺诈、胁迫、重大误解等情形的当事人及撤销权人），这个位置出不了撤销权。

**D 错误。** 即使 B 公司事后追认了这个转包行为，仍然要遵循**合同的相对性原理**——C 公司制作的家具如果不合格，B 公司是要找**A 公司**追究违约责任的。

> **对应正文**：承揽人"用自己的设备、技术和劳力完成主要工作、要亲自完成主要工作"的义务，以及合同的相对性原理（参见"承揽合同的效力"一节）。

#### 借用资质订立的建设工程施工合同

某建筑队借用 A 建筑公司的资质，以 A 公司的名义和 B 公司签订建设工程施工合同。该施工合同的效力如何？建筑队能不能拿到工程款？

**答案：合同无效；但工程验收合格的，可以参照合同的约定主张工程款。**

"建筑队借用 A 公司资质"意味着，实际签订并履行合同的建筑队**没有建筑资质**，属于建设工程合同的第五项无效情形中"无资质的实际施工人借用他人名义"那一类，主体不合格，合同应认定为无效。

但合同无效不等于一律不给钱。**无效的法律后果**取决于工程是否验收合格：验收合格的，参照合同约定的工程价款补偿给承包人；验收不合格的先由承包人承担费用修复，修复后合格仍可补偿，修复后仍不合格则无权主张工程款。

> **对应正文**：建设工程合同无效的五种情形与"合同无效的法律后果"（参见"建设工程合同的无效"一节）。
