## 租赁合同：把使用权租出去
> 对应块：BLK104 | 覆盖分集：P100 | 块标题（分集名）：《第05编 第02章 第01节：转移财产权的合同（》

应试还得技术流，每一科你都值得更好的。

接着看第四种转移财产权的合同——**租赁合同**。这一块比前面几种都重要，无论是客观题还是主观题都容易考到，而且生活当中也经常见到。我们学习它同样分三个层次：先是概述，讲含义和特征；再是典型合同的效力，也就是双方的合同义务；最后是典型合同的特别制度，这是难点。

### 租赁合同的含义与特征

#### 双方当事人：一个交使用收益权，一个付租金

> **定义**：租赁合同是当事人约定在一定期限内转移租赁物使用收益权的合同。

概念本身要好理解，但必须盯住双方当事人以及他们的合同义务这两个专业术语。一方叫**出租人**，一方叫**承租人**；出租人的义务是把租赁物交付给承租人使用收益，也就是转移使用权；承租人的义务是支付租金，支付对价。

生活里到处都是它的影子：租房子，外地旅游租辆车，甚至去饭店吃饭时租个充电宝。所以租赁的标的物可以是动产，也可以是不动产。

#### 要素定位：主体、标的物、内容

描述一个典型合同的特征，套路就两条——**先要素定位，再性质定位**。要素定位看三样：主体、标的物、内容。租赁合同在这里能形成两个特征。

**主体有没有特殊性？没有。** 自然人、法人、非法人组织都可以成为出租人或承租人。

**标的物有没有特殊性？有，而且是两重。**

> **定义**：**特定物**，与"种类物"相对应，体现独一无二、不可替代的属性。租赁物必须是特定物——交给承租人使用以后，租期届满你还得原物返还，所以这个物不能被同种类物代替。比如甲租了别人的一辆车，开完以后还车时能不能还另外一辆？不行，租了哪辆就只能还哪辆。

> **定义**：**非消耗物**，与"消耗物"相对应。消耗物是一次使用之后价值就消灭的物，非消耗物是可以反复使用的物。租赁物在你使用以后还得返还给出租人，所以它必须具备可重复使用的属性。

消耗物为什么不能当租赁标的？疫情期间大家做过无数次核酸检测，取样用的那根棉签就是消耗物，用一次就得扔掉；总不能为了体现绿色原则，让一个小区的居民取样时共用同一根棉签——想想就有点恶心。再比如去医院打点滴，输液器能不能重复使用？不能。同理，它们都不能成为租赁合同的标的物。

**内容上的特殊性是：有期限，转移的是使用收益权。** 这一点和买卖形成了鲜明的对比——买卖转移的是所有权，租赁转移的是使用收益权。

#### 性质定位：双务有偿，要式却不能一概而论

双务、有偿、诺成，租赁合同都符合，这比较简单。关键在于：它到底是要式合同还是不要式合同？

答案要具体问题具体分析。按照法律规定，**租期在六个月以上的，应当采用书面形式**，代表它是要式合同；但如果租期不满六个月，口头、书面都可以，所以又不是一律的要式。不要把这个当成一个模板去套。

> **易错点**：租期六个月以上没有采用书面形式的，后果**不是合同不成立**。而是先通过其他方式确定租期；确实确定不了的，**视为不定期租赁**——这就牵出了双方随时解除合同的权利，后面专门讲。

所以把要素定位和性质定位合起来，租赁合同的特征模板就是：

```text
要素定位：主体 → 无特殊性
          标的物 → 特定物 + 非消耗物
          内容 → 有期限地转移使用收益权（对比买卖：转移所有权）
性质定位：双务 ✓  有偿 ✓  诺成 ✓  要式 → 视租期而定（6 个月为界）
```

### 典型合同的效力：出租人的义务

出租人这一方是在转移财产权，先看他的义务。还是那三个层次：**交付、转移、瑕疵**。这个模板用多了，大家就自然而然记住了。

#### 交付：先把租赁物交到承租人手上

出租人得按照约定将租赁物交付给承租人，并在租赁期间保持租赁物符合约定的用途。

理由很朴素：你要转移使用收益权，前提是先把租赁物交付给相对方。第一层义务就是"交"。

#### 转移：正常损耗不赔，因出租原因用不了可以解约

第二项义务是转移占有使用收益权。

> **结论**：承租人按照约定的方法或者租赁物的性质正常使用租赁物，即使导致租赁物受到损耗，出租人也不承担损害赔偿责任。

举个例子：甲把自己的房子租给乙，房子很新，是婚房，只是因为工作原因自己住不了。租了三年以后乙把房子归还，甲一看我的婚房怎么变得这么旧，能不能要求乙承担损害赔偿责任？原则上不能。只要乙是按照租赁物性质正常使用，租赁发生的损耗就由出租人承担——因为任何东西使用以后都会慢慢变旧，甚至这个房子你不住它也会变旧。

反过来，如果**因出租的原因导致租赁物无法使用**，承租人是可以解除合同的。因为转移使用收益权是出租人的主给付义务，同时也代表着对方订立合同的目的。我租了你的房子，但你的房子是危房、不具备居住条件，或者有害气体严重超标威胁健康，那这时候我根本无法取得租赁物的使用收益权，就可以解约。

#### 瑕疵担保：权利瑕疵与质量瑕疵

出租人的瑕疵担保责任包含两个层次。

**权利瑕疵担保责任**，是确保把租赁物的使用收益权完整、无瑕疵地转移给承租人。假设在此期间第三人上门主张权利，是不是有可能影响承租人对租赁物占有、使用、收益？所以至少出租人要承担违约责任。

比如甲有一部车租给乙，乙使用期间丙找上门来说"这车是人家丙的，让他别开"。这是第三人上门主张权利，有可能影响承租人使用租赁物，这时承租人可以追究甲的违约责任：

- 因第三人主张权利导致承租人不能对租赁物使用收益的，承租人可以**减少租金或者不支付租金**；
- 其表现为采取**补救措施**——比如因丙的权利主张导致一周无法开车，承租人可以请求甲减少这一周的租金；
- 第三人主张权利的，承租人应当**及时通知出租人**，让出租人介入来解决纠纷。

**质量瑕疵担保责任**，是确保交付给承租人的租赁物质量没有瑕疵。

一方面，交付时租赁物要符合约定的使用用途——甲把房子租给乙，交房时房子就得是能住的；交给你时就是危房，就没有尽到质量瑕疵担保义务。

另一方面，使用收益权的转移处于**持续状态**，所以法律要求出租人在整个租期内保证租赁物符合约定用途；期间产生新问题的，出租人得负责维修，这就是**出租人的维修义务**。甲把房子租给乙，乙住了一个月房子漏水了，谁修？没有明确约定的话由房东修。

那承租人能不能请求强制执行维修义务？显然不现实——这样的义务不适合强制履行。所以：

```text
出租人该修却不修
        │
        ▼
承租人自行维修 ──► 维修费用由出租人承担
   （维修费用是金钱之债，可以强制执行）

因维修影响承租人使用的
        │
        ├──► 相应减少租金
        └──► 或延长租期
```

举个小例子：甲把房子租给乙，前一个月相安无事；一个月后当地连续下了好几天暴雨，房子每天像水帘洞一样漏雨，乙没法居住，于是找房东来修。修房子期间乙住了酒店，住了一个星期——乙能不能请求房东减少租金或者延长租期？当然可以。这一周内承租人没有实际享有使用收益权，所以可以请求减少租金或者延长租期。这实质上也是"采取补救措施"的思路。

### 典型合同的效力：承租人的义务

承租人的义务不用背——租赁合同是双务合同，按对价关系推导就行了，一项一项来。

**受领租赁物并按正确方法使用。** 出租人把租赁物交付给承租人，承租人就得受领，而且要按正确方法使用。方法怎么确定？先看当时的约定——租赁合同里可以约定"你租这个标的物就用来干什么"。假如当时没约定或者约定不明确，就**按照租赁物的性质来使用**。

比如甲的住房租给乙，合同里没约定乙租这房子干什么，那乙只能按租赁物性质使用——这房子是住宅用房，就只能用来居住，不能开饭店。再比如甲的私家车因为要出国半年租给了好朋友，乙能不能开这车跑网约车经营？不能。私家车是非运营机动车，双方没约定用途时只能按租赁性质使用。

> **结论**：承租人没有按照约定方法或者租赁物性质使用租赁物，造成租赁物损失的，出租人可以**解除合同并请求赔偿损失**。

因为这会使出租人订立合同的目的不能实现——甲把车租给乙是给个人开的，乙却拿去跑滴滴网约车，对车的损耗程度和风险都不一样。所以这时候出租人**优先选择解除合同**，不要只依赖赔偿损失。

**不得擅自转租。** 擅自转租有可能增加租赁物灭失的风险。法律明确规定：未经出租人同意，承租人不得擅自转租；如果擅自转租，出租人可以解除合同，同样是对方订立合同的目的不能实现。

**按照约定支付租金。** 这是承租人的主给付义务——你取得了对方租赁物的使用收益权，就要支付对价，也就是租金。

**妥善保管租赁物，不得擅自改善或增设他物。** 在租期内，你占有的是别人的财产，要尽到妥善保管义务。同时，未经出租人同意，承租人不得擅自对租赁物进行改善或者增设他物；擅自改善的，出租人可以请求其恢复原状或者赔偿损失。

举个例子：甲租了乙的房子，乙交付时觉得房子装修太老土，于是直接把原装修拆除并进行了全面装修。尽管这个装修有可能让房屋面貌焕然一新，但没有经过出租人同意，出租人可以请求其恢复原状并赔偿损失。

**返还租赁物。** 承租人只是取得了一定期限内租赁物的使用收益权，所以租赁合同终止时应当返还租赁物。

这几项义务其实完全基于生活经验就能理解。

### 不定期租赁中的任意解除权

我们在合同的解除部分讲过：以持续履行的债务为内容的合同，如果期限无法确定，双方都有任意解除合同的权利。不定期租赁也适用这个规定。关键是什么条件能构成不定期租赁，民法典规定了三种情形。

**第一种：对租期没有约定或者约定不明确，依照漏洞填补规则仍然不能确定的。**

> **易错点**：没约定租期就一定是不定期租赁吗？当然不是。

没有约定租期的，首先要走漏洞填补规则：先由双方协议补充；达不成协议的，还可以按照合同的有关条款和交易习惯来确定。能够确定租期的，它依然是一个定期租赁。

看个例子：刘某欠何某100万，欠款已到期却没有归还，而且刘某不知所踪、失踪了。刘某之子小刘为了替父还债，与何某签订书面租赁合同，约定月租金1万，用租金来抵货款；如果刘某出现并还清货款，本合同终止，双方再行结算。这个合同没有明确约定租期。

它是不是不定期租赁？尽管双方没有明确约定租期是多久，但可以通过漏洞填补规则确定：结合合同的有关条款看，这个租赁合同不是单纯的租赁，是用租金来抵货款的，月租金1万抵100万货款——那意味着如果不出其他特殊情况，租金就是100个月。所以通过合同的有关条款是可以确定租期的，它依然是个定期租赁，在这个租期内没有所谓的任意解除权。

**第二种：租期在六个月以上，当时没有采用书面形式，而且也无法确定租期的。**

同样，是不是"租期达到六个月以上又没采用书面形式"就一律构成不定期租赁？当然不是。即使没采用书面形式，也要先通过其他方式确定租期，实在确定不了，才构成不定期租赁。

**第三种：租期届满了，承租人继续使用租赁物，出租人没有提出异议的。**

比如甲把房租给乙，双方约定期限一年；一年到期后，乙继续住这个房子并给甲交房租，甲也按照惯例继续收这个房租。这时候租赁的期限就变成不定期租赁了。乙找到新房子以后可以随时终止合同；甲有新的承租人时，也可以通知乙搬离。

```text
                租期是否已经确定？
                        │
        ┌───────────────┴────────────────┐
      已确定                           未确定
   （哪怕没签书面）                 ┌──────┴──────┐
        │                    租期 ≥ 6 个月      租期 < 6 个月
        │                         │                │
        │                    是否采用书面？         │
        │                   ┌─────┴─────┐          │
        │                 是           否          │
        │                  │            │          │
        │            定期租赁      仍先走漏洞填补      │
        │                           规则找租期        │
        │                        ┌────┴────┐        │
        │                     找到        找不到     │
        │                      │            │        │
        │                 定期租赁    ┌────┴────┐   │
        ▼                              │         │   ▼
   ❌ 任意解除权                不定期租赁   不定期租赁
                                （法定）    （法定）
```

### 买卖不破租赁

这个制度前面讲到过，它是**物权优先于债权的例外情形**，规定在民法典第725条：租赁物在承租人按照合同占有期间发生所有权变动的，不影响租赁合同的效力。

模型还记得吧：甲乙签订房屋租赁合同，把房子租给乙，并交付到乙的手中。租期内甲把房子卖给了丙——甲跟丙签订合同、办了过户登记手续。这时候丙（新的所有权人）能不能把乙赶走，说"我现在是房东了，我不想租给你"？行不行。不行。因为在租期内发生租赁物所有权变动的，不影响租赁合同的效力，这意味着承租人可以请求新的所有权人来履行原来的租赁合同。

按道理说，承租人乙只是租赁合同的债权人，丙是通过买卖加登记取得所有权的物权人，但乙的租赁权可以对抗他——所以它是物权优先于债权的例外制度，也因此又被称为**租赁权的物权化**。通过这种方式强化对承租人利益的保护：毕竟在租赁合同中、在租赁市场当中，承租人处于相对弱势的地位。

#### 名为"买卖"，实则不止买卖

适用范围包括但不限于买卖——只要在租期内发生所有权变动的，都可以适用。

比如甲把房子租给乙，租期内甲死亡了，他唯一的继承人是丙，丙取得了房子的所有权。这时能不能适用买卖不破租赁？当然可以，乙可以请求继承人丙来履行原来的租赁合同，因为继承同样使租赁物所有权发生了变动。

> **提示**：所以一听到"要不要把买卖不破租赁改成'转让不破租赁'"，答案是不需要。因为"买卖不破租赁"只是一个约定俗成的术语，你只要知道**虽然名为买卖，但适用范围包括但不限于买卖**就行。

第二点：买卖不破租赁**既可以适用于动产租赁，也可以适用于不动产租赁**。甲把房子租给乙又卖给丙，可以适用；甲把车租给乙又把车卖给丙，照样可以适用。

#### 承租人不得主张买卖不破租赁的两种例外

这两条是司法解释规定的。

**例外一：房屋在出租之前已经设立抵押权，因抵押权实现导致所有权变动的**，承租人不能主张买卖不破租赁。

这里涉及抵押权和租赁权的冲突。抵押权跟租赁权发生冲突，主要体现为实现抵押权、拍卖变卖抵押财产的时候，承租人能不能主张买卖不破租赁？如果能，意味着承租人优先受保护；如果不能，意味着抵押权人也受保护。谁更优先？**要看先来后到。**

```text
              抵押权 与 租赁权 冲突：谁优先？
                            │
          ┌─────────────────┴──────────────────┐
       先租后抵                               先抵后租
 （先签租赁合同 + 已交付占有）          （先设抵押，后签租赁）
          │                                       │
   承租人优先                             ┌─────────┴─────────┐
   可对抗在后的抵押权人              抵押权已登记？          未登记
   —— 无论该抵押权有没有办登记              │                  │
   —— 都不得向承租人主张买卖不破租赁         是                 否
          │                                   │            （主要涉及动产）
          ▼                                   ▼            抵押权不得对抗
      ❌ 抵押权人优先                 承租人不得主张         善意第三人
                                        买卖不破租赁              │
                                                     善意承租人依然可以
                                                     主张买卖不破租赁
```

> **易错点**：先租后租的表述要准确——"先租"指的是**先签租赁合同，同时已占有租赁物**。只是签了合同没有转移占有的，承租人不能主张买卖不破租赁。

先抵后租为什么还要区分登记？因为**动产抵押不转移占有**，所以要靠登记来定顺位：办了登记的抵押权可以对抗在后的承租人，承租人不能主张买卖不破租赁；没办登记的抵押权（主要是动产）不得对抗善意第三人，而善意的承租人就是那个"未经登记的动产抵押权不得对抗的善意第三人"，他依然可以主张买卖不破租赁。

回到例外一本身：房屋在出租之前已设立抵押权，是不是就是先抵后租？而抵押的标的是房屋，是不动产，所以**一定办理了抵押登记**——于是承租人不能主张买卖不破租赁。这意味着在实现抵押权拍卖抵押房屋时，可以清退承租人，让其参与拍卖。

**例外二：房屋在出租之前已被人民法院依法查封的。** 也就是房子先被查封而后再租给别人的，承租人就不能主张买卖不破租赁了。

> **提示**：有同学会问，房子都被查封了，怎么租得出去？

我们法律上讲的查封，不是像大家想象中那样贴两个封条就完事。查封是通过登记方式进行的——要在房屋登记簿上记载这个房子处于查封状态，这样房子就过不了户。既然通过登记查封，它就有公示效力，所以可以对抗在后的承租人。生活中租房子的人很少去查询登记簿，所以也可能不小心租到已被查封的房屋，甚至有些房东直接把法院贴的封条撕掉就把房子租出去，承租人也有可能租到已经被查封的房屋。

把这两条例外放回整个规范体系看，承租人不能主张买卖不破租赁的例外情形，主要就体现为**先抵后租且抵押权办了登记**这一种情形。

### 房屋租赁的特别规定

在实践中，租赁合同领域发生最多的是房屋租赁纠纷，所以最高人民法院专门出台了城镇房屋租赁合同司法解释。这里再补充几条重要规则。

#### 违法建筑的租赁

什么叫违法建筑？没有取得规划许可，或者没有按照规划许可来建设、手续有瑕疵的房屋。对这样的建筑签订的租赁合同，应当认定无效——这是合同无效的一种特殊情形。

但这个无效不是绝对的无效：在**一审辩论终结之前**，如果补齐了建筑规划手续，合同会转化成有效。先上车后补票的也是好同志。

其次，如果租赁合同被认定无效，当事人可以请求**参照合同约定的租金标准支付房屋使用费**。虽然房子是违法建筑，但并不意味着承租人可以免费使用。当然，可以参照合同约定的租金标准来支付。

举个例子：甲将其临街的房屋和院子出租给乙作为汽车维修场所，乙在扩建报批的过程中发现，甲出租的全部房屋均没有经过城市部门的规划许可，属于违法建筑。这意味着一旦甲乙签订的租赁合同效力如何——应当认定是无效的。但假如说在一审辩论终结之前补齐了建筑手续，这个合同可以被补正，进而自始有效。当然，在确认合同无效的时候，承租人已经使用违法建筑一段时间了，这段时间要不要支付使用费？当然要，可以参照约定的租金标准来支付使用费。

#### 一房数租：履行顺序怎么排

这一条有点类似买卖合同里讲的**多重买卖**：出租人就同一套房子签订了数个租赁合同。比如老王有房屋一套，先后和甲、乙、丙、丁四个人签订了租赁合同。实践中房屋租赁不至于这么多人抢着租，但为了剧情的需要，我们就要设计这样一个场景。

先判断第一个问题：数个租赁合同的效力如何？原则上都是合法有效的，因为债权没有排他性。既然数个租赁合同都有效，那就意味着甲乙丙丁四个承租人都有权请求出租人履行合同。但房子只有一套，只能满足一个承租人的履行请求——先满足谁？

```text
同一套房 → 出租人先后与 甲、乙、丙、丁 签订数份租赁合同
                       │
       ┌───────────────┼───────────────┐
  ① 已合法占有房屋  ② 已办备案登记   ③ 合同成立在先
       │               │               │
       ▼               ▼               ▼
      丁               乙               甲
   （丁已办理入住）（乙先去备案）（甲最先签合同）

丙虽然预付了租金，但不进入顺位
→ 只能主张解除合同、追究对方违约责任（订立合同的目的不能实现）
```

为什么占有排在最前？**请神容易送神难**——他已经占有这个房子了，你不保护他、要把他清走，是很难执行的。第二是已经办理备案登记的承租人。按照我国房地产管理法的规定，房屋租赁是要办理备案登记手续的，只是没办备案不影响合同效力，但在**一房数租的履行顺序上会处于相对优先的顺位**。实践中住宅租赁很少去办备案，但商铺租赁肯定会办，因为涉及消防、安全等责任主体的认定。第三才是合同成立在先的承租人。

所以记住三个顺序：**先看占有，再看备案登记，最后看先签订合同**。不能取得租赁房屋使用权的承租人，只能主张解除合同、追究对方的违约责任，因为订立合同的目的不能实现了。

套进刚才的例子里：老王和甲乙丙丁都签了合同，甲最先签合同，乙先办了备案登记，丙预付了租金，丁已经办理入住，四个人各忙各的。如果四个人都请求老王履行合同——先保护已经合法占有房屋的承租人，所以丁排第一位；假如谁都没合法占有，就看谁先办理了备案登记，乙排第二位；都没办备案，就看先来后到，先签合同的甲处于优先地位。唯有丙，他虽然付了钱，但在履行顺序中**先付钱是没有意义的**，反而先付钱承担了最多的风险。

#### 转租：合法转租与非法转租

转租涉及三方关系，所以是难点。先把模型建起来：

```text
    出租人甲                承租人乙                 次承租人丙
     所有权人            （转租人）              （实际使用人）
        │                     │                        │
        │   租赁合同 ①        │      转租合同 ②         │
        ├────────────────────►├───────────────────────►│
        │                     │                        │
        │                     │◄────── 租金 ───────────┤
        │     租金            │                        │
        │◄────────────────────┤                        │
        │                     │                        │
        │  合法转租：经甲同意   │  非法转租：未经甲同意    │
        │  两份合同均有效       │  甲可解除合同 ①          │
        │  → 适用合同相对性     │  → 六个月内不异议即转正   │
        └─────────────────────┴────────────────────────┘
```

**合法转租**，就是转租经过了出租人甲的同意。既然经过了甲的同意，意味着两个租赁合同都可以是合法有效的。

在履行的时候要遵循**合同的相对性原理**：

- 假如丙一直支付租金，而乙没有给甲付租金，甲能不能直接找丙收租金？不可以，因为甲和丙之间没有合同关系。
- 丙在使用房屋时造成房屋毁损，甲能不能追究丙的违约责任？不能，因为甲丙之间没有合同关系（当然甲可以追究丙的侵权责任）。
- 谁追究丙的违约责任？乙追究丙的，甲追究乙的——各找各的合同当事人。

关于租期的约定同样具有相对性。转租期限不能超过承租人乙的剩余租期，但如果超过了，法律后果是：**超过部分的约定对出租人不具有法律约束力**。

举个例子：甲的房子租给乙，约定租期5年。乙刚住两年就换工作了，住这里不方便，但房东又不同意退房，于是乙把房子转租给丙，甲表示同意转租，合同里也约定5年。按道理说乙转租时只剩下3年租期，原则上转租合同的期限不能超过乙的剩余租期，但乙还是签了5年的租赁合同。这时候丙能不能说"我跟前房东签的是5年，我才住了3年，能不能对抗甲"？不可以——这也是合同的相对性，你跟乙签的5年租期约定只能对乙主张，不能对房东甲主张。这意味着丙才用了3年房子就被房东收走了，他能不能追究乙的违约责任？可以，因为这5年租期的约定在乙丙之间还是发生效力的，丙可以向乙追究违约责任。

所以合法转租主要适用合同相对性，各找各的合同当事人。

**非法转租**，就是乙未经甲的同意就和丙签订转租合同。是不是必然增加租赁物灭失的风险？所以出租人甲可以解除合同。

但解除权是形成权，**受到解除期间的限制**：甲应当在知道或者应当知道转租之日起**六个月内**提出解除。假如六个月内没有提出异议，就视为出租人同意转租了。甲都知道了还睁一只眼闭一只眼，拖满六个月，就推定你是同意转租的，乙丙的转租就"转正"了，从非法转租转变成了合法转租。

> **提示**：出租人的沉默，在这种情况下被视为做出了同意转租的意思表示——这也是**沉默作为意思表示例外情形**的一个典型。

#### 承租人的优先购买权

这个考点比较重要，考试当中考察频率非常高。简单建个模型：甲把房子租给了乙，在租期内甲要卖这个房子，比如要卖给丙。按照法律规定，承租人在**同等条件**下有优先购买的权利——这是对承租人的一种特别保护。同时赋予乙优先购买权，还可以最大限度地发挥房屋的使用效益，毕竟房子已经在他的占有之下了。

**行使条件：同等条件。**

怎么理解"同等条件"？不能光看价款，要综合考虑价款、履行期限、履行方式等一系列因素。我们前面讲按份买受人优先购买权的时候，也讲到过同等条件的认定，规则是差不多的。

举个例子：甲把房子卖给丙，价款100万，丙对乙全款支付；乙说100万我也能买得起，只是我得贷款60万。这个时候是不是同等条件？不是。因为履行方式不一样，乙就不能主张优先购买权。

**例外情形。** 存在下列情形之一的，承租人不能主张优先购买权：

- **房屋的共有人行使优先购买权的**。共有人是物权人，而承租人只是债权人，基于物权优先于债权的一般规则，此时承租人不能主张优先购买权——得先让共有人取得房屋所有权。
- **出租人将房屋卖给近亲属的**。假如丙是甲的近亲属，是不是可以享受亲情价？比如甲要把价值100万的房子卖给自己的儿子，可能儿子只需要付2万块钱。乙能不能说"你要2万块钱卖这个房子的话，我也能当你儿子行不行"？当然不行。因为人家有某种血缘、亲属关系，你不可能是同等条件。

**合理期限的认定。**

优先购买权性质上属于形成权，所以要受到除斥期间的限制，要在合理期限内行使。掌握两种情形：

| 情形 | 期限 | 起算点 | 承租人未行动的法律后果 |
| --- | --- | --- | --- |
| 出租人委托拍卖人拍卖租赁房屋 | 提前 5 天通知 | 拍卖前 | 未在拍卖当天参与竞买，视为放弃优先购买权 |
| 通过其他方式出卖租赁房屋 | 15 日内表态 | 通知之日 | 15 日内明确表示购买的，视为放弃优先购买权 |

> **易错点**：一个是 5 天，一个是 15 天，性质完全不同。5 天是**出租人通知承租人的时间**（要在拍卖前五天通知）；15 天是**通知承租人以后给其考虑的时间**。要参与拍卖的话，你要当场做决定；不是拍卖的话，承租人有 15 天考虑期，过期不候。

**侵害与救济。**

假设出租人没有通知承租人就把房子卖掉了，而且已经给第三人办了过户登记手续。首先，第三人能不能取得房屋的所有权？可以。尽管他侵犯了承租人的优先购买权，但出租人依然属于有权处分，只要办理了登记，第三人丙可以取得房屋的所有权。

只是甲的行为侵犯了乙的优先购买权，乙怎么救济？他**只能主张损害赔偿，而不能主张合同无效**。乙可以主张甲侵犯其优先购买权、要求赔偿损失，但没有资格主张甲丙签订的买卖合同无效。

#### 承租人的优先承租权

这是民法典新增加的制度：在租期届满的时候，房屋的承租人享有**同等条件优先承租**的权利。

实践中承租人买下自己租的房子概率并不是那么高——毕竟你有钱买房的话，没必要非得买这个租着的房子，你可选择的余地很大。但这个制度的意义相当重大：租期届满时，如果承租人想继续租，他不用搬家，非常省事，所以法律要保障他的这个权利。

同样是在同等条件下主张，而且也只能适用于房屋的租赁。

#### 承租人死亡：法定的概括承受

在租期内假设承租人死亡了，会不会直接导致租赁合同无效？不会。此时与承租人生前**共同居住的人或者共同经营的人**，可以按照原来的合同继续租赁该房屋——这会发生一个**法定的概括承受**。

看两个例子。

第一个：甲乙是情侣，大学毕业后在 B 市工作，二人合租了丙的房屋。甲为了多赚钱每天加班，在第3年不幸猝死（是个悲伤的故事）。这个时候乙能不能请求按照原来租赁合同继续租赁该房屋？当然可以。尽管甲乙不是夫妻，他们只是共同居住的人，但按照法律规定，可以直接承受租赁合同当中的权利义务。

第二个：甲乙合伙开办健身中心，甲以建设场地出资，乙以现金80万出资，合伙期限5年。甲为了完成对合伙合同的出资义务，以个人名义租赁了丙的经营性用房，租期5年。第2年甲因病去世。乙能不能按照原来的合同继续租赁该房屋？可以，因为乙是和甲共同经营的人。不能说某一个合伙人死亡了，直接健身房就得关门，这也不太合适，其他合伙人可以按照原来的租赁合同继续租赁该房屋。

> **提示**：有同学会问，甲乙合伙开办的健身中心，那这个租赁合同的当事人难道不应该是甲乙两个人吗？案例里特别告诉你——甲是为完成出资义务、以**个人名义**租赁的，所以租赁合同的当事人是甲；甲死亡后，与他共同经营的乙可以继续租赁该房屋，承受这个租赁合同当中的权利义务。相当于一个法定的概括承受。

### 本讲提到的题目

**题干**：甲将房屋出租给乙，租期5年。半年以后，甲通知乙要出售该房屋。20天内乙没有表态，甲于是将房子卖给丙，并办理了过户登记手续。看乙可以提出什么主张。

A. 主张甲丙的买卖合同无效
B. 请求甲承担违约责任
C. 主张租赁合同对丙继续有效
D. 主张优先购买权

**答案：C**

**解析**：

- **A 错。** 甲丙的买卖合同是有效的。甲属于有权处分，只要办理了登记，丙可以取得房屋所有权。优先购买权被侵害只产生损害赔偿请求权，不能拿来否定合同的效力。
- **B 错。** 甲已经通知要卖房子了，乙自己过了 15 天（本题为 20 天）没有表态，是自己放弃了优先购买权。既然没主张优先购买权，就谈不上甲承担违约责任。
- **C 对。** 这就是**买卖不破租赁**——房子的所有权虽然从甲变成了丙，但乙可以请求丙继续履行租赁合同（民法典第725条）。
- **D 错。** 因为乙已经放弃了优先购买权。

> **结论**：租赁合同这一块需要大家掌握的考点，就是概述、效力加上特别制度这三层。真题里四个选项，四个制度各考一个：**优先购买权有合理期限、买卖不破租赁、承租人只能索赔不能主张合同无效**——把这三条摆正了，题目就不会错。

## 融资租赁合同：名为租赁，实为融资

五种转移财产权的合同讲到第五种。前四种你多半在生活里见过、听过，第五种不一样——融资租赁合同是我们这一节的难点问题。整体上也要分成三个层次：第一是概念和特征，第二是典型合同的效力，第三是典型合同的特别制度。

先把它的身份交代清楚。融资租赁虽然形式上看起来是个租赁关系，但是实质上发挥的是向企业提供融资的功能，发挥着有点类似于银行贷款的作用——所以这个融资租赁，他是金融领域中的一种交易，不是租赁领域中的一种交易。

不少同学在生活中没有接触过这种合同类型，那我们只能通过一个小案例来建构它的交易模型。

### 从一架波音客机说起

乙公司是一家航空公司，为了扩大经营需要，急需某型号的波音客机三架，但没有钱，需要通过融资途径来解决。

第一个想到的当然是找银行贷款——找银行贷款是获得融资成本最低的方式。但是你找银行贷款得符合银行的条件，得有相应的担保物。乙公司自己不具备这个条件，此路不通。

于是乙公司又找到了融资租赁公司甲公司，说我需要一笔钱来买三架飞机。甲公司表示：有的是钱，你想要什么我就给你买什么，霸道总裁的感觉。双方签订合同约定：甲公司按照乙公司的选择，向波音公司购买三架客机；然后再把这三架飞机租给乙公司使用；乙公司支付租金，什么时候把约定的租金还清了，第三架飞机就可以归乙公司。

这样的合同，我们叫融资租赁合同。

```text
        承租人乙                    出租人甲                    出卖人波音
            │                           │                           │
            ├──────────────────────────>│                           │  ①
            │                           ├──────────────────────────>│  ②
            │                           ┤──────────────────────────<│  ③
            │<──────────────────────────┤                           │  ④
            ├──────────────────────────>│                           │  ⑤
```

① 乙公司选定机型、提出要求；② 甲公司依其选择向波音公司购买三架客机；③ 波音公司把飞机交付给甲公司；④ 甲公司把飞机租给乙公司使用；⑤ 乙公司按期支付租金，租金付清后飞机归乙公司所有。

> **易错点**：这个流程图最容易记混的就是①和⑤的方向。乙公司是提出要求的一方，也是付钱的一方；甲公司从头到尾只干两件事——花钱买飞机、把飞机租出去。

尽管这里面包含一个"甲公司把飞机租给乙公司"的行为，但是双方交易的本质是：甲公司给乙公司提供了购买三架飞机所需要的资金的融通服务。所以核心是提供融资。

在融资租赁合同中提供融资的一方甲公司，我们叫**出租人**；有融资需求的一方乙公司，我们叫**承租人**。这个表述跟租赁合同完全一样。这里还涉及到一个波音公司，叫**出卖人**、第三人。融资租赁合同的双方当事人是出租人和承租人。

#### 交易结构：出租人两项义务，承租人一项

我们要通过描述双方当事人的主要义务，来体现融资租赁合同的概念。

出租人的合同义务有两个方面。第一个方面，是根据承租人对出卖人、租赁物的选择，向出卖人购买租赁物——其实就是来买单的、来出钱的。买了飞机以后，第二个方面是把它提供给承租人使用，要租给乙公司。所以出租人的两项义务就是：先购买飞机，再把飞机租给乙公司。

承租人的义务是什么？就是支付租金。但他支付的租金，本质上是得把甲公司购买飞机花的钱，通过分期还款的方式还给甲公司。什么时候把这个租金还清了，这个飞机就可以归乙公司了。这就是融资租赁合同的交易方式。

#### 售后回租：也可以向承租人自己买

在实践中，绝大多数融资租赁合同都是向第三方来购买租赁物。但是法律上也允许向承租人自己来购买租赁物，签订融资租赁合同，这叫售后回租型的融资租赁。

还是乙公司，它需要通过融资方式拿到一笔资金，于是又找到了甲公司。甲公司表示：这次你需要买什么，我还是买给你。乙公司说：我需要钱，但不需要买新的东西。

问题来了——对融资租赁公司来讲，他的业务需求就是必须得花钱买点什么，不能直接给钱，否则的话你就抢了银行的饭碗了。

于是双方约定：乙公司把自己一架旧飞机卖给甲公司，这样甲公司可以把约定好的价款 5000 万元转给乙公司。乙公司拿到了钱；甲公司买这架飞机，目的同样不是要对飞机进行占有、使用、收益、处分，于是他又把这架飞机租给了乙公司，让乙公司继续使用。

大家看这个操作，甲公司能不能取得飞机的所有权？答案是可以的。但是大家要判断一下：他们是通过什么方式来完成交付的？

我们在前面是讲过的，这叫**占有改定**。乙公司先把飞机卖给甲公司，然后又通过租赁方式再租回来，通过占有改定完成交付，进而使得甲公司取得了租赁物的所有权。当然乙公司用这架飞机就得付租金了；什么时候把租金付清了，这架飞机又重新属于乙公司。乙公司同样实现了一个融资的目的，而且通过这个占有改定的交易，进而可以发挥担保租金债权的功能。所以甲乙签订的也是一个融资租赁合同。

民法典相应规定：承租人将自有物出卖给出租人，再通过融资租赁合同将租赁物出租回的，构成占有改定；不应仅以承租人和出卖人是同一人为由，认定不构成融资租赁法律关系。

> **结论**：融资租赁合同可以是向第三人购买，也可以向承租人自己购买租赁物。

#### 出租人为什么非要拿到所有权

大家注意，在这个交易当中，甲公司可以通过购买的方式取得飞机的所有权，但是他取得所有权，不是为了对飞机进行占有、使用、收益、处分——因为也没人会开这个飞机。他取得所有权的目的是为了**担保租金债权的实现**。

假如有一天乙公司没按照约定支付租金，那甲公司可以收回自己的飞机，把飞机卖掉。这是不是大大地减少了甲公司对外提供融资的风险？

所以融资租赁合同，它本质上是一种**非典型担保物权**制度。我们在物权篇讲过这个词，非典型担保物权，它的功能跟我们买卖合同部分讲的物权保留买卖有点类似，发挥的都是担保功能。

正因如此，民法典明确规定：出租人对租赁物的所有权未经登记，不得对抗善意第三人。你看他的效力，有点类似于动产抵押权。

这就是融资租赁合同的交易本质：**名为租赁，实为融资**。

#### 底线：必须得有一个租赁物

不管是找第三人买，还是找这个承租人自己买，总之必须得有一个租赁物。假如说当时是以虚构租赁物的方式来订立融资租赁合同、掩盖非法目的的，该融资租赁合同是无效的。这也是对融资租赁公司从事这项业务的一个底线要求。

### 要素定位与性质定位

#### 要素定位：主体、标的（物）与内容

**主体是有资格限制的**，特别是出租人这一方：他得取得从事融资租赁业务的资格，才能够签订这种合同。所以这个融资租赁也是一个特许经营的行业。所以你身边有朋友在融资租赁公司上班的话，你不要觉得人家是倒腾设备的——人家是搞金融的。

**标的物是按照承租人的要求购买的，通常是价值较高的固定资产。**一方面，它常常是按照承租人的选择专门购买的，因为你去购买租赁物，才涉及到融资公司出钱的行为；另一方面，价值相对来讲会比较高一些，因为这个融资租赁它的成本是比较高的——杀鸡焉用宰牛刀，如果这个价值比较低的话，也不值当通过融资租赁的方式来获得融资。

对比一下，我们在前面讲的租赁合同，他的标的物常常是出租人自由的财产。这是两者一个很明显的分水岭。

**内容上也包含支付租金的义务，但是这个租金不是使用租赁物的对价，而是获得对方融资的对价。**所以这个租金的标准，比一般的租赁合同要高得多。因为你支付的租金，应当相当于出租人购买租赁物的大部分甚至全部成本，而且还要包含出租人的合理利润。其实就是通过租金的方式来还本付息——这是融资租赁的本质。

#### 性质定位：双务、有偿、诺成、要式

用我们前面讲过的模板来展开，性质定位要检索双务、有偿、诺成、要式这几个标识。融资租赁合同前三个都是符合的，大家重点关注第四条：他是要式合同，要通过书面形式来订立。

### 效力：出租人一方的义务

第二个层次是融资租赁合同的效力，要关注双方当时的合同义务。因为是出租人这一方转移财产权，所以我们以出租人的义务作为主线来展开。还是要包含三个层次：第一是交付，第二是转移，第三是瑕疵。

#### 交付与转移：比普通租赁多出一次"购买"

第一项义务跟交付相关。在交付之前呢，出租人得先按照承租人的要求来购买租赁物——先买到租赁物，再交付租赁物。你看这第一个层次，他比一般的租赁合同多了一个购买的行为。

第二个层次跟转移相关：要把租赁物交给承租人使用，保证承租人占有和使用租赁物。

#### 瑕疵担保：原则上没有，但有两条例外

第三个层次跟瑕疵担保相关。原则上出租人对租赁物没有瑕疵担保责任，他不承担租赁物的瑕疵担保责任。也就是说对出租人来讲，他最核心的义务是出钱，他只要出了钱就等着收租金就完了，这个租赁物有没有瑕疵他是不管的。

那假如说承租人在使用的时候发现租赁物有瑕疵，他要直接向出卖人索赔，而不能向这个出租人索赔。但这个时候呢，出租人有个什么义务啊？有个**协助的义务**——毕竟出租人是法律上的买受人。在我们前面讲的模型中，如果甲公司按照乙公司的选择从波音公司买入的飞机有瑕疵、飞不起来，他要直接向波音公司索赔，只是这个时候甲公司有一个协助的义务。

注意，出租人的核心业务是出钱，他是金融公司，但是有原则必有例外。哪些情况属于例外？

一是承租人依赖出租人的技能来确定租赁物的；二是出租人干预选择租赁物的——也就是说找谁买这个标的物、买什么标的物，你给人参考了意见的。

这个时候你就得承担瑕疵担保责任了。如果根据你的意见买来的租赁物有瑕疵，承租人可以请求减免相应的租金。也就是说你不懂事你就少发言；你要给别人参考意见，别人听了你的意见都损失的，你要承担法律责任的。

### 效力：承租人一方的义务

承租人的合同义务，我们通过对价关系来推导，一共五项。

**第一项，按照约定及时接受租赁物。**承租人选定的租赁物，出租人已经出钱给你买来了，你有个及时接收的义务。而且有瑕疵的话，你要直接向出卖人索赔，而不能向这个出租人索赔。

**第二项，妥善保管、使用、维修租赁物。**出租人把租赁物交付给承租人以后，承租人就负这些义务。

**第三项是他的主给付义务：按照约定向出租人支付租金。**但这个租金不是使用租赁物的对价，而是你使用了对方融资的对价，所以前面讲的租金标准在这儿落地——相当于出租人购买租赁物的成本加上合理利润。假如承租人被催告后，在合理期内仍不支付租金的，出租人可以请求其支付全部租金，相当于要求你一次性把剩余的租金全部付给我；也可以主张解除合同、收回租赁物。当然，这两项主张只能是择一行使。

大家看在分期付款买卖当中，如果出卖人没有收到全部的价款而产生风险，是不是也可以让对方一次性支付剩余价款，或者解除合同？这个具体措施有点类似。

**第四项，承租人需要承担租赁物毁损、灭失的风险。**一方面，在承租人占有租赁物期间，租赁物造成第三人损害的，要由承租人承担赔偿责任。比如甲公司按照乙公司的选择买来的飞机，在乙公司使用期间给坠毁了，把老百姓的房子给砸塌了，谁承担赔偿责任？承租人航空公司承担赔偿责任，因为是在你使用这个租赁物期间造成的损害。

同时，租赁物发生毁损、灭失的风险，由承租人承担，原则上不可以——即使租赁合同解除了，出租人依然可以请求承租人继续支付租金。毕竟买飞机的钱我已经一次性花出去了，尽管飞机没了，但是我还是要等着收租金的。比如按照融资租赁方式买来的飞机，像马航一样给消失了，出租人能不能请求这个航空公司继续支付租金？当然可以。

**第五项，租期届满以后，如果承租人没有取得租赁物所有权的，应当返还租赁物。**尽管在绝大多数的融资租赁合同中，当时会约定租期届满支付租金的时候承租人可以取得所有权，但是，如果当事人没有这样的约定，或者因为各种原因承租人没有把这个租金付清、没有取得所有权的，那你就有返还租赁物的义务。如果基于约定已经取得对应所有权了，就不负这个返还义务了。

### 特别制度：租赁物到底归谁

第三个层次是特殊制度，主要给大家讲租赁物的归属规则。租赁物归谁，我们要区分两个层次：第一个层次是融资租赁合同有效时租赁物的物权归属，第二个层次是融资租赁合同无效时租赁物的归属。

#### 合同有效、租期内：所有权在出租人

这是大家掌握的核心。

第一，租期内。租期内意味着承租人并没有支付全部的租金，这时租赁物所有权归谁？归出租人，因为是人家花钱买来的租赁物。前面讲到出租人的所有权，它主要是为了担保租金债权的实现，发挥的是担保功能，所以未经登记不得对抗善意第三人，这个效力有点类似于动产抵押权。

第二，这个所有权担保的债权，是租赁物的价款债权。我们在讲这个超级优先权的时候提到过这个说法——这意味着只要是在 10 天内办理登记的，出租人也可以享受一个超级优先的保护顺位，可以享受一个"插队"的特权。

#### 与动产抵押权掰手腕：三种登记情形下的顺位

我们来看一个例子，就这个例子来理解出租人所有权的存在意义。

甲公司为向银行借款，将其名下及现有的生产设备、原材料等为银行设立抵押——你看这是一个动产浮动抵押，而且办了抵押登记，那就意味着银行是一个登记的抵押权人。

后来为了扩大生产的需要，甲公司需要购买一套大型的设备，因资金不足，寻求丙融资租赁公司的融资。于是甲公司和丙公司签订了融资租赁合同：丙公司按照甲公司的选择，向丁公司购买这套生产设备，租给甲公司，双方约定在甲公司付清租金以后可以取得设备的所有权。甲丙公司之间签订的合同就是融资租赁合同，丙公司对这个设备享有所有权，来担保租金债权的实现。

后来甲公司既没有归还银行的贷款，也没有按照约定来支付租金。这时银行和丙公司都会站出来，请求拍卖刚买的设备来优先受偿。关键是他们两个谁更优先？要看丙公司有没有办理登记。

| 丙公司的所有权 | 能否对抗银行 | 设备拍卖价款的受偿顺位 |
| --- | --- | --- |
| 未办理登记 | 不得对抗善意第三人 | 银行第一，丙公司第二 |
| 10 日以内办理登记 | 租金债权属于价款债权 + 期限内登记，享受超级优先 | 丙公司第一，银行第二 |
| 10 日以后办理登记 | 不符合插队的特权要求，按登记先后定顺位 | 银行第一，丙公司第二 |

所以要具体问题具体分析。

#### 合同有效、租期届满：尊重意思自治的三种约定

接下来是租期届满的时候。到底租赁物归谁？先看当时的约定，这叫尊重意思自治。当时可能约定由承租人取得所有权，也可能约定出租人继续享有所有权。

**第一种：约定租期届满时，承租人仅需向出租人支付象征性价款的，视为约定的租金义务履行完毕，租赁物所有权归承租人。**

注意这个象征性价款。比如在前面讲的模型中，甲公司和乙航空公司约定：你按约定来支付租金，当租金给付完毕的时候，我甲公司用 100 块钱的价格把这个飞机卖给你，你给我支付一个象征性的价款，这个飞机就可以归你。

如果当时有这样的约定，法律直接视为租期届满的时候承租人可以取得所有权。这意味着，假如在租期届满的时候，乙公司拿 100 块钱付给甲公司，甲公司说"你跟我开什么玩笑，100 块钱想买飞机，你也太天真了吧"，认为这个合同是显失公平的——甲公司的主张能不能成立？不能成立。因为这 100 块钱只是象征性的价格，它不是真正的对价。事实上，乙公司即使不付这个象征性的价款，按照法律规定，也要视为当时约定租期届满时租赁物直接归承租人。

> **易错点**：象征性价款不具有实质意义。甲公司事后以显失公平为由反悔的，法院不支持。

那当时为什么不直接约定"租期届满时由承租人取得所有权"，而非要搞一个象征性的价款呢？这反映了实践中有些当事人对这个法律制度的不信任：甲公司和乙公司可能会怀疑"我们约定租期届满乙公司可以取得所有权，法律认可这样的约定吗？"双方不太有信心，于是约定一个象征性的价款，起码通过买卖的方式交付、取得所有权，心里更有底一些。而这个象征性价款也不会太多地增加当时的负担。这样可以消除对法律规则不信任的顾虑——但其实啊，是你们想多了。

**第二种：约定租期届满时租赁物归承租人所有，而承租人已经支付了大部分租金、但无力支付剩余租金的，承租人不能取得所有权。**

这时候出租人可以解除合同、收回租赁物："你没有把我买飞机的钱都还给我，所以我可以解除合同、收回租赁物。"只是收回租赁物以后呢，拍卖、变卖租赁物的价款，要优先清偿承租人欠付的租金。假如付完这个欠付租金还有剩余的，你得返还给承租人。

所以出租人收回租赁物以后，拍卖变卖取得的价款，他享有的其实是一个类似于担保物权的优先受偿权——你可以先拿钱，但是拿够以后，你把肉吃了，汤呢还得还给承租人。

**第三种：约定租赁期届满时租赁物归出租人所有的。**

这代表着承租人付的租金可能相对来讲比较少，不足以涵盖购买租赁物的成本。这时因租赁物毁损、灭失，或者因混合、附合于他物导致不能返还的，承租人得给予适当补偿。

为什么？当时约定承租人不能取得所有权，是因为你付的租金数额并不足以涵盖全部的购买租赁成本。所以说如果租期届满的时候承租人返还不了租赁物了，那你得给予适当补偿，这样才能够保护出租人的利益。

#### 没有约定或约定不明：依然属于出租人

以上是当事人特别约定的情形。那从考试角度来讲，大家重点掌握的是：当事人对租赁物的归属没有约定，或者约定不明确，根据合同的漏洞填补规则仍然不能确定的，租赁物所有权依然属于出租人。

如果当时没有特别约定的话，法律没有任何理由剥夺出租人的所有权。所以大家记住这个结论：当时没有约定或者约定不明确的，租赁物仍然属于出租人。

#### 合同无效时：原则上返还，例外归承租人并补偿

假如说因为承租人的原因，融资租赁合同被认定无效了，这个时候租赁物到底归谁？

首先看当时的约定。当事人没有约定或者约定不明确的，租赁物依然属于出租人，所以承租人得返还租赁物——毕竟是出租人花钱购买来的租赁物。这是原则性的规定。

当然有原则，就必然会有例外的情形。假如说因承租人的原因导致合同无效了，出租人本来是享有请求返还租赁物的权利的，但是大家想一想，这个租赁物是按照承租人的选择购买的，对出租人来讲可能没什么用处。所以这个时候，出租人也可以选择不请求返还；或者呢，他虽然请求返还，但是会显著降低租赁物的利用效率的，租赁物的所有权可以例外地归承租人。

这是物尽其用的一个体现——意味着这个租赁物对承租人来讲是更有价值的，所以由承租人取得所有权。但是你得给予出租人合理的补偿。毕竟是出租人花钱买来的，本来呢要指望这个租金来收回这个成本，但是现在不是融资租赁合同无效了吗？你这个承租人就没有给付租金的义务了，那你要通过合理补偿的方式，把这个钱补给出租人。

### 融资租赁和普通租赁，差在哪儿

| 比较点 | 融资租赁合同 | 租赁合同 |
| --- | --- | --- |
| 主体 | 出租人须取得从事融资租赁业务的资格，属特许经营 | 无此资格限制 |
| 标的（物） | 按承租人的选择专门购买，通常是价值较高的固定资产 | 常常是出租人自由的财产 |
| 租金 | 获得融资的对价，标准相当于购买成本的大部分甚至全部加合理利润 | 使用租赁物的对价 |
| 租期届满 | 可约定由承租人取得所有权 | 不能取得所有权 |

把这张表横过来看就会发现，融资租赁的每一个要素都在强调同一件事：它在替承租人融资，而不在交付使用权。

### 本节收束：五种合同，一个模板

到这里为止，第一节涉及的五种转移财产权的合同，就给大家全部介绍完毕了。

回头看整体的知识结构，每一种典型合同都包含三个层次。第一是概念和特征：概念要通过描述双方当事人的合同义务的方式来体现；而特征常常分成两个层次，第一层是要素定位，包括主体、标的（物）以及内容三个方面；第二层是性质定位，要检索双务、有偿、诺成，必要时的还要检索"要式"。第二是典型合同的效力，我们会用一个统一的表达模板来展开，就是交付、转移、瑕疵。第三是特别制度，这部分要具体问题具体分析——今天讲的租赁物归属规则，就是一个典型的例子。

### 本讲提到的题目

#### 题目

A 公司急需机床，因资金不足，与 B 公司签订合同，约定：B 公司按照 A 公司的要求向 C 厂购买十台机床，出租给 A 公司，由 C 厂向 A 公司交付；租金 800 万元，每年年末 A 公司向 B 公司支付 80 万元；租期届满时，租赁物的所有权归 A 公司。

问：该合同属于什么性质的合同？

#### 解析与答案

**答案：融资租赁合同。**

这个案例描述的交易结构非常明显：这个合同使得 A 公司实现了从 B 公司获得相应融资的需求。融资租赁合同考的就是一个基本概念。下面逐一排除三个干扰项。

**不能选租赁合同。**尽管这里面也有租赁，但是一般的租赁，在租期届满的时候你能取得租赁物的所有权吗？当然不能啦。比如说甲租了乙的房子，租期是 3 年，3 年到期的时候，甲能不能说这个房子归我了？当然不能。租期届满时由承租人取得所有权，这是融资租赁合同才有的效力。

**不能选所有权保留的买卖合同。**所有权保留买卖它本质上是买卖合同，要一方交付标的物、转移所有权，另一方要支付价款。假如说 A 公司他直接找到了 C 厂，说"我要买你的设备，但是我我要分期付你钱"，那 C 厂说"那我要保留所有权，你什么时候把价款付清了，我再把所有权转给你"——这个才叫所有权保留买卖。而这个案例当中，B 公司是直接把价款给 C 厂给付清了的，进而使得 B 公司直接取得了所有权，并不涉及到保留所有权的问题；然后 B 公司把这个设备租给 A 公司，它还不涉及所有权变动。所以不能选。

**不能选借款合同。**因为不是直接把钱交给对方来使用的。
