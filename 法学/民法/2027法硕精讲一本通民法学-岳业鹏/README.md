# 2027 法律硕士《精讲一本通》民法学（众合法硕 岳业鹏）

岳业鹏老师的 2027 法硕民法学精讲。课程按《民法典》七编通讲：总则、人格权、物权、知识产权、合同、婚姻家庭与继承、侵权责任，逐节展开法条要件、体系关系与判断步骤。

- **原视频**：https://www.bilibili.com/video/BV1AuPKzjEFs — Bilibili，BV1AuPKzjEFs
- **128 集 / 93.2 小时**，已产出 29 册模块全书、58 篇复习笔记、132 份逐字稿

## 怎么学

- **先建框架** → 模块 01~07 打通总则：渊源解释与效力、民事法律关系、主体制度、民事法律行为、代理、诉讼时效与期间
- **分编攻坚** → 模块 08~29 依次过人格权、物权、知识产权、合同、婚姻家庭与继承、侵权责任
- **要件拆解** → 每个制度都落到「构成要件 + 效力范围 + 顺位 + 消灭」的判断顺序
- **考前冲刺** → `notes/` 的 58 篇按知识主题归类，跨块聚合，便于横向对比易混制度
