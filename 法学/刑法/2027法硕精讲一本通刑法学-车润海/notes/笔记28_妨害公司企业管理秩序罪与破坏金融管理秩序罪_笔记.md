# 妨害公司企业管理秩序罪与破坏金融管理秩序罪

## 非国家工作人员受贿罪

* **非国家工作人员受贿罪**
    * > **定义**：公司、企业或者其他单位的工作人员，利用职务便利索取他人财物，或者非法收受他人财物，为他人谋取利益，数额较大的行为。
    * 简称"非受罪"，本质是权钱交易——一方有权、一方有钱，用财物去交换他人的权利。
    * 客观行为分两型：索取型（利用职务便利索取他人财物）与收受型（利用职务便利非法收受他人财物）。
    * 主体是特殊主体，限于公司、企业或者其他单位的工作人员；主观方面为故意。
    * 索取型与收受型都必须同时满足两个必备条件：利用职务便利、为他人谋取利益。

### 主体中的其他单位

| 组织类型 | 判定标准 | 典型形态 |
| :--- | :--- | :--- |
| 常设性组织 | 稳定存在，不会干一票就散伙 | 事业单位、社会团体、村委会、居委会、村民小组 |
| 非常设性组织 | 为某项正当活动临时组建，活动结束即解散 | 体育赛事、文艺演出等活动的组委会、筹委会、工程承包队 |

* **常设性组织**
    * > **定义**：稳定存在、不会干一票就散伙的组织。
    * 具体包括事业单位、社会团体、村民委员会、居民委员会、村民小组，其工作人员完全可能构成本罪。
    * 事业单位要再拆成国有事业单位与非国有事业单位；非国有事业单位中相关工作人员实施本罪行为可以构成本罪。
* **非常设性组织**
    * > **定义**：为组织体育赛事、文艺演出等文体事业，或为其他正当活动而成立的临时组织。
    * 包括组委会、筹委会、工程承包队，其工作人员利用职务便利权钱交易可以构成本罪。
* > **易错点**：其他单位不含国家机关与人民团体——这两类单位中从事的工作人员本身就是国家工作人员，收钱办事要定受贿罪而不是非受罪。
* > **提示**：做题按"稳定存在 / 一活动一散"两条线去套即可。

### 客观要件

* **利用职务便利**
    * > **定义**：利用职务给自己带来的权利。
    * 实质是职务范围内的权利，即利用自己主管、负责或者承办某项事务的职权，以及该职权形成的便利条件。
    * 例：上市公司高管组织面试时向面试者索取财物，利用的正是其主管、负责面试事务形成的职权。
* **为他人谋取利益**
    * 内容上既包括谋取正当利益，也包括谋取不正当利益。
    * 只要求**承诺**为他人谋取利益即可，不要求实际谋得利益。
    * 承诺本身就是权钱交易的证明：一方有权、一方出钱，只要承诺交换到权利，主观上即已成立。
* > **结论**：索取型与收受型都必须"利用职务便利 + 为他人谋取利益"，缺一不可。

### 财物范围与数额标准

* 数额较大为 **3 万元以上**。
* 这条 3 万的线同时适用于贪污受贿、挪用公款（含挪用公款进行非法活动）与本罪。
* **金钱**——最基本形态。
* **实物**——如古董、名画。
* **可以用金钱计算数额的财产性利益**——如提供房屋装修、含金额的会员卡、代币卡、旅游费用。
* > **注意**：请人旅游、替对方花钱属于这一类，同时也构成对非国家工作人员行贿罪这一对象犯。

### 犯罪形态

* **既遂** = 承诺为他人谋取利益 + 实际收受数额较大的财物。
    * "好的好的，我替你办"是承诺牟利；实际收到 3 万元以上财物才达既遂。
* **未遂** = 承诺牟利但因意志以外原因未收到财物。
    * 例：采购主管与供货商约定回扣后正常交易，供货商爽约未付回款，采购主管成立本罪未遂。
* > **结论**：毕竟是权钱交易，收到钱才构成本罪的既遂形态。

### 通谋收受财物的定罪

* 非国家工作人员与国家工作人员通谋、共同收受他人财物的，必然构成共犯。
* 区分标准是**利用了谁的职务便利**，即利用了谁手中的权力，谁通常就是实行犯。

```text
          两人通谋、共同收受他人财物
                      │
         ┌────────────┴────────────┐
         │                         │
   只利用国家工作人员          只利用非国家工作人员
   的职务便利（张三）          的职务便利（李四）
         │                         │
   ┌─────┴─────┐            ┌──────┴──────┐
   │ 张三=受贿罪 │            │ 李四=非受罪   │
   │ 李四=受贿罪 │            │ 张三=非受罪   │
   │    共犯     │            │     共犯     │
   └────────────┘            └─────────────┘
```

* **各自利用各自职务便利且能分清主次**
    * 按主犯性质定：张三作用大则张三、李四均定受贿罪共犯；李四作用大则均定非受罪共犯。
* **各自利用各自职务便利但分不清主次**
    * 司法解释规定：可以按照受贿罪追究刑事责任。
* **国有控股单位场景**
    * 国有控股意味着国家是大股东、社会资本是小股东；代表国家资本被委派来管理人员具有国家工作人员身份，代表社会资本的一方只是公司工作人员。
    * 主要利用国家工作人员手中的权力，国家工作人员定受贿罪、对方定受贿罪共犯；主要利用非国家工作人员的职务便利，对方定非受罪、国家工作人员定本罪共犯。

### 与受贿罪的分野

* 两罪都是收钱办事、权钱交易，区分的关键是**利用职务便利的内容不同**，即职务便利的本质不同。
* 受贿罪的主体是国家工作人员，权力来自国有单位赋予；非受罪凭借的是私权利授权。

| 公权（受贿罪） | 私权（非受罪） |
| :--- | :--- |
| 权力直接来自国有单位的赋予，具有行政职责性 | 管理民营单位形成的职权，如民营公司的采购权 |
| 在管理国有财产，如高校财务处会计 | 基于知识或技术形成的权利，如医生开处方 |

* **四种主体的填格**
    * 国家工作人员利用公权收钱，构成受贿罪。
    * 非国家工作人员利用私权利收钱，构成本罪。
    * 国家工作人员利用私权力收钱，只能定非受罪。
    * 国家工作人员之外还有非国家工作人员参与的，后者可以构成受贿罪的教唆犯、帮助犯。
* **公立医院院长的双向判断**
    * 出诊时利用给病人开处方的便利收取医药代表财物，用的是医生基于知识、技术形成的权利，定非受罪。
    * 在全院大会上要求各科室必须使用指定品牌药并收受巨额财物，用的是公立医院院长赋予的决定权，定受贿罪。
* **委派型职务便利的判断**
    * 国有单位委派老师去外地负责招生，权利来自国有单位的委派、代表国有单位招生，具有行政职责性，认定为国家工作人员，收受财物定受贿罪。
* **村委会主任的判断**
    * 绝大多数场景下村委会主任不属于国家工作人员，特定情形下可能属于。
    * 从事精准扶贫、抗震救灾、国有土地征收和补偿、税收代扣代缴、征兵、户籍、计划生育等工作时，是协助政府完成具有公共性的事务，属于国家工作人员。
* > **易错点**：⚠️ 区分受贿与非受**千万不要只看主体**。主体是重要参考但不是唯一因素，最关键的是行为人利用的是什么权利。
* > **结论**：具有行政职责性（权力直接来自国有单位赋予）或正在管理国有财产的，用这种权利收受财物定受贿罪；私权利要么来自管理民营单位，要么来自自己的知识权、技术权，用这种权利收受财物定非受罪。

### 司法解释摘要的四种情形

* **第一，医疗机构的医务人员利用开处方的职务便利**
    * 开处方是知识或技术形成的私权利，成立本罪。
* **第二，学校及其他教育机构中的非国家工作人员**
    * 在教材、教具、校服或其他物品采购中，利用职务便利索取销售方财物或非法收受销售方财物并为其谋取利益，数额较大，成立本罪。
    * 既非来自国有单位直接赋予，也不在管理国有财产，典型如班主任要求学生购买某出版社指导用书并收受回扣。
* **第三**，原理与第二项完全相同。
* **第四，依法组建的评标委员会、竞争性谈判采购中谈判小组、询价采购中询价小组的组成人员**
    * 在招标、政府采购等事项的评标或采购活动中索取、非法收受他人财物并为其谋取利益，数额较大，成立本罪。
    * 评标委员会由政府从高校等院校抽取专家组成，逐项查看标书后向政府**推荐**人选，由政府作最终决定。
    * 以专家身份出席者只有知识权、技术权、推荐权，无决定权，收受财物定非受罪。
    * 以政府代表身份出席、可一锤定音决定采购谁的，权利来自国家机关直接赋予，定受贿罪。
* > **易错点**：⚠️ 看到"专家"二字要警觉——专家身份行使的是知识权、技术权与推荐权，定非受罪；政府代表身份行使决定权，定受贿罪。

### 真题：下列情形中构成非受罪的有

* **答案**：ABD。
* **A 项（当选）**——医务人员收受药企财物后开具处方给予优选，利用的是作为医生基于知识、技术形成的私权利，非院长的决定权，定本罪。
* **B 项（当选）**——教师收受出版社财物后在教学中指定学生购买该社教辅，是利用知识权作推荐，既非国有单位直接赋予也不在管理国有财产，构成本罪。
* **C 项（不选）**——生育指标管理即计划生育，属于行政职权，村委会主任在此情形下按立法解释具有国家工作人员身份，收受财物构成受贿罪。
* **D 项（当选）**——评标委员会中的特邀专家在评标中为某企业竞标创造条件，行使的只是知识权、技术权与推荐权，构成本罪。

## 非法经营同类营业罪

* **非法经营同类营业罪**
    * > **定义**：公司、企业的董事、监事、高级管理人员利用职务便利，自己经营或者为他人经营与其所任职公司、企业同类的营业，获取非法利益或者致使公司、企业利益遭受重大损失的行为。
    * 客体是公司、企业的管理制度以及董监高人员的职务廉洁性（其对单位负有忠实勤勉义务）。
    * 主体是特殊主体，即公司、企业的董事、监事和高级管理人员；主观方面为故意。
    * 本质是**拿本单位的资源与本单位进行竞争，排挤本单位，谋求不正当的竞争优势**——吃着公司的饭，砸着公司的锅。

### 两款法条，两个结果要求

| 主体 | 结果要求 | 立法侧重 |
| :--- | :--- | :--- |
| 国有公司、企业的董监高 | 获取非法利益，数额巨大 | 侧重肥私，让自己获利 |
| 其他公司、企业的董监高 | 致使公司、企业利益遭受重大损失 | 侧重损公 |

* 董监高掌握本公司的各种资源，背着单位另行经营同类营业，属于典型不正当竞争。
* 第二款表明国有与民营公司企业一视同仁、平等保护。

### 职务便利即"资源"

* **职务便利**
    * > **定义**：董监高在任职公司掌管的有关公司整体经营发展的职权，以及职权地位形成的便利条件。
    * 可掌握的资源包括材料、物资、市场计划、销售客户，以及人力、资金、物资、信息资源、客户渠道。
    * 利用这些信息优势在市场竞争中占据有利地位，损害所任职公司、企业利益。
    * 例：众合公司高管掌握名师信息、发展思路与经营方案、客户群体、印刷渠道，私自另设机构与本公司竞争。

### 经营与同类营业的认定

* **经营**
    * > **定义**：实际的经营管理活动，具有盈利性和风险性。
    * 表现之一：本人负责、亲自管理实际的经营管理。
    * 表现之二：虽不亲自管理，但参与公司重大决策或指挥，对整个经营起定向作用、发挥实质作用。
* **自己经营**
    * 独立开办公司、企业，或者与他人联合开办，目的是获取全部或部分市场利润。
* **为他人经营**
    * 董监高被其他公司、企业聘任，与本单位的竞争对手合作，为其提供咨询、服务等并获取劳务收入。
* **同类营业**
    * 违背竞业禁止义务，在兼营公司经营与其任职公司实际经营同一类别的业务。
    * "类"指国家统计局《国民经济行业分类》中的**小类**。

### 与贪污罪、受贿罪的区分

| 比较项 | 非法经营同类营业罪 | 贪污罪 | 受贿罪 |
| :--- | :--- | :--- | :--- |
| 有无经营行为 | 有，且属同类营业的经营行为 | 无，空手套白狼 | 一般无 |
| 是否承担市场风险 | 承担，会赔钱 | 无市场风险 | 不投入，不会亏钱 |
| 利益来源 | 经营利润 | 非法占有公共财物 | 权钱交易 |

* **与贪污罪**：关键看有没有经营行为。贪污是空手套白狼、无市场风险；本罪是市场竞争，有赔钱可能。
* **与受贿罪**：获利方式与来源不同。本罪需投入成本、承担风险、所得为经营利润；受贿无实际投入，利润来自权钱交易。
* **入库案例（钱某成立 C 公司）**
    * A、B 公司均为从事命题业务的国有公司，钱某先后任 A 公司执行总经理、B 公司总经理。
    * 钱某为把命题业务转为个人经营，伙同副总经理孙某以他人名义注册成立 C 公司，由 C 公司从上海某考试院承接命题业务。
    * 钱某负责洽谈业务、签订合同、安排收入分配使用；孙某负责联系命题专家、交接考试命题、发放专家命题费；非法获利 177 万余元。
    * 钱某、孙某作为国有公司直接负责命题业务的高管，本应忠实履行义务、恪守竞业禁止规定，将本单位的同类业务转移至自己成立的公司，非法利益数额巨大，构成本罪。
    * 不构成贪污罪，因为这是市场经营行为而非空手套白狼；不构成受贿罪，因为利润来自正常经营活动的市场竞争与利润分配。

## 为亲友非法牟利罪

* **为亲友非法牟利罪**
    * > **定义**：国有公司、企业、事业单位的工作人员利用职务上的便利，实施法条列举的特定行为，致使国家利益遭受重大损失的，处三年以下有期徒刑。
    * 末款规定：其他公司、企业的工作人员违反法律、行政法规的规定实施同样行为，致使公司、企业利益遭受重大损失的，依照前款处罚。
    * 客体是国有公司、企业、事业单位及其他公司、企业的管理制度与合法权益。
    * 主体为特殊主体，包括国有公司、企业、事业单位工作人员以及其他公司、企业工作人员，国有与非国有平等保护；主观方面为故意。

### 法条列举的三类行为

* **第一，将本单位的盈利业务交由自己的亲友进行经营**
    * 简称"转业务"，"盈利业务"有独立认定标准。
* **第二，以明显高于或明显低于市场的价格与亲友经营管理的单位交易**
    * 以明显高于市场的价格从亲友经营管理的单位采购商品、接受服务，简称"高价买"。
    * 以明显低于市场的价格向亲友经营管理的单位销售商品、提供服务，简称"低价卖"。
* **第三，从自己的亲友经营管理的单位采购、接受不合格的商品、服务**
    * 简称"采购不合格"，除单位受损外还面临赔偿消费者的问题。
* > **结论**：四字口诀"转业务、高价买、低价卖、采购不合格"，法条为完全列举。

### 盈利业务的认定

* **盈利业务**
    * > **定义**：肯定能够获得利润的业务。
    * 判断标准是"确定能盈利"，能否盈利取决于经营得好坏的业务不属于盈利业务。
    * 例：某国有景区整体不挣钱，唯独缆车项目确定挣钱，总经理把该业务交给亲友经营则单位必受损、亲友必获益。
* > **易错点**：⚠️ "盈利业务"指**确定能盈利**的业务，不是"可能盈利"的业务。

### 与贪污罪的界限

| 比较项 | 为亲友非法牟利罪 | 贪污罪 |
| :--- | :--- | :--- |
| 客体 | 公司、企业、事业单位的管理制度与合法权益 | 公共财物的所有权、国家工作人员职务的廉洁性 |
| 客观行为 | 利用职务便利为亲友非法牟利，致使单位遭受重大损失 | 利用职务便利侵吞、窃取、骗取或以其他手段非法占有公共财物 |
| 主体 | 国有公司、企业、事业单位工作人员，及其他公司、企业工作人员 | 国家工作人员，受委托管理经营国有财产的人员 |
| 主观方面 | 为亲友谋利 | 以非法占有公共财物为目的 |

* 区分标准只看**为谁谋利**：单纯为亲友谋利构成本罪；为自己谋利构成贪污罪。
* **高价买案例的两条走向**
    * 国有公司总经理解除与 A 公司的供货合同，改由表弟成立的 B 公司供货，市场价 1000 元/吨而按 1500 元/吨采购，多付的 500 元留在表弟口袋，单位白白多付，构成为亲友非法牟利罪。
    * 若表弟将多付的 500 元/吨以其他方式返还给总经理，该 500 元转入自己口袋，公共财物被掏空据为己有，构成贪污罪，表弟为共犯。
* > **结论**：非国家工作人员实施同样情形的，构成职务侵占罪。

### 入库案例：转包给七弟

* 某国有机电安装公司下设项目部，负责本单位中标项目的施工；甲利用担任该公司处长、执行董事等职务便利，在公司中标后个人决定将一个项目违法转包给七弟乙。
* 乙在上述工程中至少获利 765 万元。
* 经查，该公司参与投标并中标的项目均含有预期利润，且大多是短平快、利润高的项目，属于确定能盈利的业务。
* 甲将本单位盈利业务交给亲友经营，致使国家利益遭受重大损失，构成为亲友非法牟利罪。

## 伪造货币罪

* **伪造货币罪**
    * > **定义**：违反货币管理法规，仿照真货币的种种特征（包括形状、色彩、图案等），以各种方法非法制造出外观上足以乱真的假货币，破坏货币的公共信用和金融管理秩序的行为。
    * 客体是国家的货币管理制度，特别是其中的**货币的公共信用**；"公共信用"是后面每一道关卡共用的尺子。
    * 主体仅限自然人——本章其他罪原则上单位可以构成，伪造货币罪不行。
    * 客观行为是非法制造假币；主观方面为故意，且一般具有使用的目的。
    * 犯罪形态是典型的行为犯。

### 在所不问与唯一硬门槛

* **四项在所不问**
    * 本币与外币——伪造假美元同样构成本罪。
    * 硬币与纸币。
    * 普通币与纪念币。
    * 伪造手段——使用什么方法非法制造都行。
* **唯一硬性要求：伪造的货币必须是正在流通中的货币。**
    * 理由是公共信用——只有正在流通才具有公共信用。
    * 伪造乾隆通宝不构成本罪；伪造第四套人民币因已停止流通、没有公共信用，同样不构成本罪。
* > **易错点**：伪造停止流通的货币并使用的，按诈骗罪论处；尚未使用的，充其量只是诈骗罪的一个预备行为。

### 以假为真与使用目的

* **效果要求**
    * 仿照真货币特征进行伪造，若不足以使一般人物假为真，就不可能侵害货币的公共信用。
    * 例：把个人照片贴到假钞上给别人用，属恶作剧，定不了伪造货币罪。
* **使用目的**
    * 一般须具有使用的目的，既包括自己使用，也包括让他人使用。
    * 行为人须认识到所伪造的货币可能进入流通领域、充当真币被使用。
    * 单纯为个人收藏，或伪造后拿去上坟、祭祖，一般不构成本罪，因为不破坏公共信用。

### 追诉标准与犯罪形态

* **追诉标准**：伪造货币金额 2000 元以上，或者币量 200 张以上，应当追诉。
* **犯罪形态**：行为犯，伪造出货币即构成既遂；因意志以外原因未伪造出来的构成未遂，完全可能成立未遂的共同犯罪。

### 真题：直播手绘百元人民币

* **答案**：不构成犯罪。
* 不构成伪造货币罪：手绘人民币没有置于流通领域，也没有自己使用或让他人使用的目的，不可能侵害货币的公共信用，只是才艺表演。
* 不构成非法经营罪：非法经营要求特许经营，自己画人民币练技巧或向别人展示不构成该罪；非法利用信息网络罪同样不构成。

## 伪造货币罪与变造货币罪的区分

* **分水岭只有一个：货币有没有丧失同一性，即是否丧失了真币的主体部分。**
    * 丧失主体部分即"大改"，认定为伪造；仍然具备主体部分即"小动"，才可能是变造。

```text
          行为人对货币动手加工
                    │
                    ▼
          ┌──────────────────────────┐
          │  真币的"主体部分"还在吗？│
          └──────────────────────────┘
                  │                 │
                已丧失           仍然具备
                （大改）           （小动）
                  │                 │
                  ▼                 ▼
              伪造货币罪          变造货币罪
         （真伪拼凑也归这里）   （只做局部加工）
```

* 类比：室友割了双眼皮是变造；变成"好兄妹"是伪造。
* 大量收购梅花五角后熔化成水重新铸成更多、更轻更薄的五角，是伪造——真币主体部分已不存在。

### 变造货币的四种常见情形

* **改变面额**——只改面额不动其他，如把 100 改成 50，50 改成 100。
* **改变年份**——如把 2015 年的纸币改成 1997 年的，只改年份。
* **改成错版**——错版人民币本身是真币，系印刷过程中有瑕疵、与大多数真币有细微差别；有人把完全无错的纸币改成错版。
    * 前三种的共同目的在于**增加货币的收藏价值**，物以稀为贵。
* **减少金属含量**——如刮取纪念金币上的金粉再用出去，只属局部加工。
    * 与熔化重铸的前提不同：熔化后真币主体基础已丧失，定伪造；只有在仍具备真币主体基础的前提下减少金属含量才定变造。

### 司法解释额外补充的两点

* **真伪拼凑一律定伪造。**
    * 同时采用伪造和变造手段制造真伪拼凑的货币，直接认定伪造货币罪。
    * 真币与假币各剪一半拼成一张，真币已经少了一半，真币基础已不存在。
* **剪贴、挖补、揭层、涂改、移位、重印等加工，改变真币形态价值的，以变造货币罪定罪处罚。**
    * 揭层例子：用化学药水浸泡纸币后从中间撕为两层，上下层都当作两张钱使用，揭开后上下层都是真币的内容，定变造。
    * 重印只能是局部的重印；全部重印必然是大改，认定为伪造货币罪。

### 五组情形的定性

| 行为 | 定性 | 理由 |
| :--- | :--- | :--- |
| 大量收购梅花五角，熔化成水后铸成更多、更轻更薄的五角 | 伪造货币 | 真币主体部分已不存在 |
| 把日元改成欧元 | 伪造货币 | 颜色、防伪特征、主权标志全变，改动太大 |
| 把真币改成"一眼未睁"的错版 | 变造货币 | 真币主体部分仍在，只改局部细节 |
| 用药水浸泡后把真币撕成上下两层，分别当两张钱用 | 变造货币 | 揭开后上下层都是真币的内容 |
| 真币与假币各剪一半拼成一张 | 伪造货币 | 真币已少一半，属真伪拼凑 |

## 货币犯罪的罪数

* 伪造货币后又**持有、使用、运输、出售同一宗假币**的，以伪造货币罪从重处罚，不实行并罚。
    * 这四个动词针对的都是同一宗假币，与伪造紧密相关：伪造之后必然持有，持有之后或使用或运输出售。
* 针对的不是同一宗假币的，数罪并罚——例如先伪造货币，又购买、运输他人的假币，两宗假币之间无关联，是两个独立行为。
* 走私类罪名用顿号隔开，表明是选择罪名，选择对象不同也不并罚——购买假美元、运输假英镑不并罚。
* 犯罪数额均将外币按外汇汇率折合成对应人民币计算。
* > **易错点**：本罪对象仅限于**伪造**的货币，不包括变造的货币——"假币"默认指伪造货币。走私假币罪中的"假币"只能是走私伪造的货币；走私变造的货币定走私国家禁止进出口的货物品罪。

## 高利转贷罪

* **高利转贷罪**
    * > **定义**：以转贷牟利为目的，套取金融机构信贷资金，高利转贷给他人，违法所得数额较大的行为。
    * 客体是金融机构信贷资金的管理秩序。
    * 主体是一般主体，包括单位；主观方面为故意，且以**转贷牟利**为目的。
    * 本罪是目的犯，最重要的考法就是这一目的要件。

* **套取金融机构信贷资金**
    * 实质是**虚设贷款用途**——贷款须专款专用，银行对贷款用途有监管职责。
* **高利转贷给他人**
    * 取得信贷资金后以更高利率转贷给他人，赚取中间的利率差；这笔本应属于银行的利差被行为人挣走。
* **不要求欺骗性质**
    * 成立本罪不要求行为人具有一定欺骗性质；甲与金融机构负责人乙共谋转贷牟利、明知真相仍发放贷款的，甲仍构成本罪，乙可能构成违法发放贷款罪。
* **与贷款诈骗罪的区别**
    * 一句话：目的不同。以转贷牟利为目的、挣利率差的构成本罪；以非法占有为目的、套出来不打算还的构成贷款诈骗罪。
* **转贷必须贷给别人**
    * 例：甲从 A 银行贷款 1000 万元、利率 1.5%，又存入利率 3% 的 B 银行，这是存款而非贷款，不构成本罪。
* > **提示**：题目问"存入另一家银行"时，先问一句是贷款给银行还是存款——存款不属于转贷。

## 骗取贷款、票据承兑、金融票证罪

* **骗取贷款、票据承兑、金融票证罪**
    * > **定义**：以欺骗手段骗取银行或者其他金融机构的贷款、票据承兑、信用证、保函等，给银行或者其他金融机构造成重大损失的行为。
    * 客体是金融秩序和金融安全；主体是一般主体，包括单位；主观方面为故意。
    * 骗即欺骗、取即取得；票据承兑包括汇票、本票和支票，金融票证是"既有票又有证"，指信用证、保函等。
    * 本质是**不符合使用贷款的条件，采用欺骗手段获取了贷款**。

* **行为方式**：必须采用欺骗手段，即虚构事实、隐瞒真相。
* **结果要求**：必须给银行或者其他金融机构造成重大损失，司法解释要求在 **50 万元以上**。
    * 本罪是典型的**结果犯**。
    * 历年真题很少考具体数额，通常用"获利巨大""违法所得巨大"表明符合入罪条件，数额了解即可。
* **罪名性质**：本罪同时是选择罪名，可拆为骗取贷款罪、骗取票据承兑罪、骗取金融票证罪，重点是骗取贷款罪。
* **典型情形**：张三征信有问题、银行正常不可能放贷，他伪造材料证明征信无问题取得贷款并用于生产经营，后因生意亏损无法偿还——构成骗取贷款罪。

| 罪名 | 主观目的 | 题眼 |
| :--- | :--- | :--- |
| 高利转贷罪 | 必须以转贷牟利为目的 | 低息从银行贷款，高息再贷给别人 |
| 骗取贷款罪 | 不要求特定目的，但不得有非法占有目的 | 不符合贷款条件而骗取，拿到后用于生产经营 |
| 贷款诈骗罪 | 必须以非法占有贷款为目的 | 套出来就不打算还 |

* > **结论**：与贷款有关的犯罪通常靠主观目的区分——骗取贷款罪不具有非法占有目的或其他特定犯罪目的。

* **真题：伪造产权证明作担保借款 3000 万**
    * **答案**：骗取贷款罪。
    * 用伪造的产权证明作担保，表明以欺骗手段取得贷款。
    * 借款 3000 万元用于生产经营，表明没有非法占有贷款的主观目的，诈骗类选项被排除。
    * 后因经营不善无法归还，说明损失真实发生，符合给金融机构造成重大损失的结果要件，"无罪"同样被排除。

## 非法吸收公众存款罪

* **非法吸收公众存款罪**
    * > **定义**：违反金融管理法规，非法吸收公众存款或者变相吸收公众存款，扰乱金融秩序的行为。
    * 客体是国家的金融管理秩序；主体包括单位；主观方面为故意且不以非法占有为目的。
    * 成立的关键在于这笔资金一旦失控会关涉社会上不特定多人的资金安全。

### 四个条件须同时具备

```text
  非 法 吸 收 公 众 存 款 四 项 条 件
  四项须同时满足，缺一即不成立

   ┌────────────────────────────┐
   │ 一 未经许可                 │
   ├────────────────────────────┤
   │ 二 公开宣传                 │
   ├────────────────────────────┤
   │ 三 面向公众                 │
   ├────────────────────────────┤
   │ 四 承诺还本付息             │
   └────────────────────────────┘
```

* **未经许可**——未经有关部门依法许可，或者借用合法经营的形式吸收资金。
* **公开宣传**——通过网络媒体、推介会、传单、手机信息等途径向社会公开宣传。
* **面向公众**——向社会公众及社会不特定对象吸收资金。
* **承诺还本付息**——承诺在一定期限以内，以货币、实物、股权等方式还本付息或者给付回报。
* > **注意**：四项是同时满足关系，有一点不满足就不构成本罪。

### 亲友与单位内部：出罪的安全区

* **司法解释的提示**：未向社会公开宣传，在亲友或者单位内部针对特定对象吸收资金的，不构成本罪。
* 例：在面授课堂上对 200 名学生说可以把钱放在我这儿、年底给利息并签借款协议，不构成本罪——既未公开宣传，对象又是特定的人。
* 朋友之间、亲戚之间、单位内部同事之间的相互借贷是民间借贷，不构成犯罪。

### 两个例外

* **明知并放任亲友或单位内部人员向不特定对象吸收资金**
    * 例：学生从亲戚朋友处借钱再放到行为人处涨利息，行为人明知而接受。
    * 学生对行为人是特定的人，但学生的亲戚朋友对行为人就是社会不特定的人。
* **以吸收资金为目的，将社会人员吸收为单位内部人员并向其吸收资金**
    * 假装把不特定人发展为内部员工再向其借钱，属逃避刑事制裁；这些人既不实际从事工作也不领取实际报酬，实质上并非内部人员，成立本罪。
* > **结论**：能否成立的关键看**有没有突破那个小圈子**——小圈内是民间借贷，突破到社会不特定人则完全可能构成本罪。

### 数额与集资诈骗罪的界限

* **与集资诈骗罪**：诈骗类犯罪都以非法占有为目的，有非法占有目的的构成集资诈骗罪，没有的构成本罪。
* **数额全额计算，不因归还而扣减。**
    * 例：5 月非法吸收公众存款 100 万，6 月又吸收 200 万并用后者归还前者，数额仍为 300 万。
    * 理由是每一笔资金吸收时都已扰乱金融秩序，归还不改变既成的扰乱事实。

## 妨害信用卡管理罪

* **妨害信用卡管理罪**
    * > **定义**：违反信用卡管理法规，妨害信用卡管理的行为。
    * 客体是金融秩序；主体只能是自然人，不能是单位；主观方面为故意。
    * 法条共列举四项内容，除对法条不熟外无其他考查原因。

```text
  手中无卡
      │
      ▼ ① 骗领
  使用虚假的身份证明骗领信用卡的
      │
      ▼ ② 持有
  非法持有他人信用卡，数量较大的
      │
      │  × 不能"使用"——一使用即带出
      │    非法占有目的，超出本罪范围
      │
      ▼ ③ 运输
  明知是伪造的信用卡而持有、运输的；
  明知是伪造的空白信用卡而持有、
  运输，数量较大的
      │
      ▼ ④ 出售
  出售、购买、为他人提供伪造的信用卡，
  或以虚假身份证明骗领的信用卡的
```

* **骗领**——手中总要有卡，卡从无到有只能靠使用虚假的身份证明骗领。
* **持有**——骗领之后必然持有；非法持有他人信用卡、数量较大即可构成本罪。
    * 例：张三盗窃多张信用卡交给李四保管，李四即非法持有他人信用卡数量较大。
* **运输**——持有不是终极目的，终极目的是使用但**不能使用**，使用即超出本罪构成要件范围，只能出售；从持有到出售之间是运输环节。
* **出售**——出售的反义词是购买，同义词是"为他人提供"；有偿是出售，无偿是为他人提供。
    * 行为人手中此时已有两种卡：以虚假身份证明骗领的信用卡、伪造的信用卡。
* > **提示**：做题按体系定位，把四项带进去逐项试，符合其中之一即构成本罪。

### 牵连关系往上走一级

* 以虚假身份证明骗领信用卡后再使用的，构成妨害信用卡管理罪与信用卡诈骗罪，手段行为与目的行为形成牵连关系，**择一重认定为信用卡诈骗罪**。
* 伪造信用卡后再使用的，伪造信用卡构成**伪造金融票证罪**，使用构成信用卡诈骗罪，两者同样是牵连关系，择一重认定为信用卡诈骗罪。

## 窃取、收买、非法提供信用卡信息资料罪

* **窃取、收买、非法提供信用卡信息资料罪**
    * > **定义**：违反信用卡管理法规，窃取、收买、非法提供他人信用卡信息资料的行为。
    * 对象是信用卡信息资料，不是卡片本身。
    * 客体是信用卡管理秩序；主体是一般主体，但既然与信用卡有关，只限自然人、不包括单位；主观方面为故意。

### 对象边界

| 属于信用卡信息资料 | 不属于信用卡信息资料 |
| :--- | :--- |
| 持卡人账户、账号、密码 | 普通电话号码 |
| 验证码 | 家庭住址 |
| 背面六个数字（安全码） | 职业状况 |

* 信用卡信息资料必须是信用卡本身所展示出的信息，家庭联系方式、电话号码类不属于。
* 单纯窃取电话号码、身份证号码的，构成侵犯公民个人信息罪。

### 三个延伸考查点

* **为信用卡申请人制作、提供虚假的财产状况、收入职务等资信证明材料**
    * 资信证明材料用于证明申请人的还款能力与征信；提供材料常涉及盖章，自行刻章或伪造公司、企业、事业单位、人民团体印章的，按证件、印章类犯罪追究。
* **中介组织或者人员出具虚假证明文件**
    * 承担资产评估、验资、验证、会计审计、法律服务等职责的中介组织或人员，故意出具虚假证明文件的构成提供虚假证明文件罪；审查不慎的构成出具证明文件重大失实罪。
    * 前者是故意犯罪，后者对应过失。
* **牵连关系**
    * 先窃取、收买他人信用卡信息资料，再通过互联网通讯终端使用，即冒用他人信用卡信息资料，手段行为构成本罪、目的行为构成信用卡诈骗罪，牵连犯择一重认定为信用卡诈骗罪。

## 妨害公司企业管理秩序罪与破坏金融管理秩序罪的题眼速记

* **非受罪**：其他单位含常设性与非常设性组织；两必备要件是职务便利与谋取利益（只须承诺）；3 万元起；既遂＝承诺牟利＋收到钱；区分受贿罪不看主体看权利来源。
* **非法经营同类营业罪**：国有董监高看"非法利益数额巨大"，其他董监高看"公司企业利益重大损失"；判断口径是单位资源与本单位竞争。
* **为亲友非法牟利罪**：转业务、高价买、低价卖、采购不合格；盈利业务指确定能盈利；与贪污罪之别在于为谁谋利。
* **伪造货币罪**：四项在所不问，但伪造对象必须是正在流通的货币；效果须足以以假为真；2000 元或 200 张起追诉。
* **伪造与变造**：大改是伪造、小动是变造，分水岭是有没有丧失真币的主体部分；真伪拼凑定伪造；变造常见四种加司法解释补充的加工方法。
* **高利转贷罪**：目的犯，须套取信贷资金后高息贷给他人；存入银行不算转贷；不要求欺骗性质。
* **骗取贷款罪**：结果犯，重大损失 50 万元以上；不符合贷款条件而骗取、用于生产经营。
* **非法吸收公众存款罪**：未经许可、公开宣传、面向公众、承诺还本付息四项同时具备；亲友与单位内部不公开宣传的出罪，放任与假招人两个例外；数额全额计算。
* **妨害信用卡管理罪**：骗领、持有、运输、出售四段链条，不能使用；牵连后一律择一重定信用卡诈骗罪。
* **窃取收买非法提供信用卡信息资料罪**：对象是信息资料而非卡片；伪造证章、提供虚假证明文件、冒用后使用均为延伸考点。
