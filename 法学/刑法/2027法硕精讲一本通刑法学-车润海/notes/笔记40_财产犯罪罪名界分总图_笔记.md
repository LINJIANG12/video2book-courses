# 财产犯罪罪名界分总图

## 罪名关系图

* 盗窃罪是财产犯罪的**核心罪名**，它上连抢夺罪、下连故意毁坏财物罪，牵动整个板块的骨架。

* 盗窃罪左手牵着诈骗罪，右手关联侵占罪；诈骗罪再往下要区分敲诈勒索罪、侵占罪。

* 故意毁坏财物罪要区分破坏生产经营罪；抢夺罪往上要区分抢劫罪。

* 抢劫罪的左手是绑架罪，右手是非法拘禁罪。

```text
抢劫罪 ──左手──→ 绑架罪        抢劫罪 ──右手──→ 非法拘禁罪
   ↑
   │（抢夺罪向上要区分抢劫罪）
抢夺罪
   ↑
   │（盗窃罪向上要区分抢夺罪）
盗窃罪  ← 全图核心
   ├── 左手 ──→ 诈骗罪
   │                ├──→ 敲诈勒索罪
   │                └──→ 侵占罪
   ├── 向下 ──→ 故意毁坏财物罪 ──→ 破坏生产经营罪
   └── 右手 ──→ 侵占罪
```

> **提示**：图上每一个箭头都对应一条被讲解过的区分关系，做题时真正要用的就是“某某罪要区分某某罪”这一串箭头本身。

## 夺命十问

* 财产犯罪界限判断可以压缩成十组罪名对的固定尺子，每组只问一个问题。

| 对比的两个罪 | 区分标准 | 结论走向 |
| :--- | :--- | :--- |
| 绑架 / 抢劫 | 有无利用第三人对人质安危担忧的意思 | 有→绑架；无→抢劫 |
| 绑架 / 敲诈勒索 | 有无控制人质 | 控制→绑架；未控制→敲诈勒索 |
| 绑架 / 非法拘禁 | 有无勒索财物的目的 | 有→绑架；无→非法拘禁 |
| 抢劫 / 诈骗 | 被害人有没有选择的余地 | 有→可能处分财物→诈骗；无→抢劫 |
| 抢劫 / 敲诈勒索 | 被害人有没有选择的余地 | 有→敲诈勒索；无→抢劫 |
| 盗窃 / 诈骗 | 受骗人有无处分财物的意识和行为 | 有→诈骗；无→盗窃 |
| 盗窃 / 侵占 | 实行行为时财物由谁占有 | 他人占有→盗窃；本人占有或无人占有→侵占 |
| 盗窃 / 抢夺 | 明抢暗偷 | 自以为秘密→盗窃；公然→抢夺 |
| 诈骗 / 侵占 | 非法占有目的产生的时间 | 骗取前有→诈骗；合法占有后才有→侵占 |
| 诈骗 / 敲诈勒索 | 被害人眼中行为人是好人还是坏人 | 认为好人→诈骗；认为坏人→敲诈勒索 |
| 普通抢劫 / 事后抢劫 | 使用暴力或以暴力相威胁的目的不同 | 继续取得财物→普通抢劫；窝藏赃物、抗拒抓捕、毁灭罪证→事后抢劫 |

> **结论**：把这张表和“两个当场”记住，财产犯罪的界限判断基本够用；真正拉开分数差的不是背下来，而是回到生活里去检验它。

## 两两对比、逐项排除

* 不要从正面论证“它构成何罪”，而要逆向思维，走**两两对比、逐项排除**。

* 读完题干先看四个选项，把所有“有可能成立”的罪名列出来，任取两个用夺命十问里对应的那条标准去对比，一次排掉一个。

* 判断标准是“我从来不想它构成何罪，我只想能排除谁”；排掉一个就跳出一次命题陷阱，成功的概率就高一分，最后剩的那一个一定是正确结论。

* 直接从正面下结论风险极高：读完题干还没看选项就认定一个罪名，大概率只是条件反射，等于找着命题陷阱往里跳。

```text
读完题干
    │
    ▼
列出所有"有可能成立"的罪名（诈骗 / 敲诈 / 侵占 / 盗窃 / 抢夺 …）
    │
    ▼
任取两个，用夺命十问里对应的那条标准去对比
    │
    ▼
排掉一个 ──► 成功概率 +1，跳出一次命题陷阱
    │
    ▼
重复：一次排一个
    │
    ▼
最后剩的那一个，一定就是正确结论
```

> **提示**：排除没有严格的先后顺序，擅长谁、熟悉谁就从谁开始；先比盗窃与侵占、先比盗窃与抢夺、先比盗窃与诈骗都可以。

> **提示**：怎么对比？就是拿这十项内容当尺子，碰到疑难的财产犯罪也不怕。

## 处分意识与处分行为

* > **定义**：“处分”要求主观上有**处分意识**、客观上有**处分行为**；谈到处分的前提，是被害人要有**相对的意志自由、他要有选择的余地**，连选择的余地都没有就谈不上处分。

* 诈骗、敲诈勒索属于**交付性犯罪**：被害人基于认识错误或恐惧心理把财物交出去。

* 盗窃、抢夺属于**夺取性犯罪**：完全违反被害人意志，被害人不可能有处分意识和处分行为。

```text
诈骗 = 交付性犯罪：被害人基于认识错误／恐惧，"自愿"交付
              ▲
              │ 关键：有没有处分意识 + 处分行为
              │
抢夺 = 夺取性犯罪：完全违反被害人意志，被害人不可能有处分行为
```

* 判别处分有无的实用办法是看**有无形成新的外部特征**：按数量交易、按重量交易，称重之后都会形成一个新的外部特征；凡在新的外部特征以内的，受骗人都会形成整体的处分意识。

* 把人打倒在地取走财物不叫处分财物，这叫**被劫取财物**——被害人没有选择的自由，没有相对意志自由。

> **提示**：处分意识的前提，是受骗人要认识到“我在占有这个财物”；只有认识到自己在占有，才可能有处分它的意识。

> **提示**：“借多久”是一条好用的尺度。当场打电话、一会儿就还、对方还站在现场，明显没有处分占有权；说“手机借我用五天”对方同意了，肯定有处分占有权。关键是有没有允许对方在一段时间内独立支配这个东西。

## 绑架罪

### 与抢劫罪：从一重与并罚的两种情形

* **先绑又抢**：司法解释明确规定，在绑架过程中当场劫取人质财物的，从一重罪处罚；这种情形可以简化为四个字。

* > **注意**：“抢”发生在绑架过程之中，所以是从一重；而且通常情况下绑架罪更重。

* **先抢后绑**：拦路抢劫、压制反抗后搜身只有 200 块，抢劫行为已经结束、构成抢劫罪既遂，行为人不甘心又继续控制被害人向其家人要钱，后面的行为构成绑架罪，数罪并罚。

### 与抢劫罪：区分的本质

* 客观上两者高度相似：都要控制被害人、都要压制他的反抗，单纯从客观区分实在太难，只能把目光转向主观。

* > **定义**：主客观相统一，犯罪客体决定定性，主观罪过优先认定。

* > **定义**：绑架罪的基本结构是**非法拘禁 A ＋ 敲诈勒索 B**；控制住 A 就能向 B 要到钱，是因为 B 有担忧 A 的可能性。

* 行为人千方百计让第三人知道人质在自己手中，主观上有**利用第三人对人质安危担忧的意思**；翻译成刑法用语就是有利用第三人对被害人担忧的意图，这是绑架的故意。

* 抢劫的场合，行为人通常**刻意隐瞒被害人被控制的事实**，缺乏利用第三人对被害人担忧的意思。

* > **结论**：区分绑架与抢劫的本质，就是**有无利用第三人对人质担忧的意思**——有，构成绑架罪；没有，构成抢劫罪。

* 辅助说法是“看向谁要钱”：向被害人本人要钱是抢劫，向第三人要钱是绑架；但两个对比案例套这条规则分不清，必须抓住上面的本质。

* 两个案例只差一个细节：张三用刀劫持李四到偏僻之地，李四谎称“做生意要投钱，请求老娘支援”，把张三的卡号说成自己的合伙人，老娘把钱转给张三——构成**绑架罪**。

* 同一场景改成张三对李四说“按照我讲的内容去要钱，如果错一个字我就弄死你”，李四照张三的要求说做生意要投钱，老娘转 5 万被张三取走——构成**抢劫罪**。

### 两个当场

* **第一个当场**：当场使用暴力，或者当场以暴力相威胁。

* **第二个当场**：当场取得财物。

* 做题时一旦发现满足了两个当场，**直接定抢劫**。

* 理由在于绑架罪是“非法拘禁 A ＋ 敲诈勒索 B”，控制人质之后**再**向人质家人要钱，通常都会给家人留一些**准备钱的时间**，取财不具有当场性；司法解释规定满足两个当场一般定抢劫罪。

* 2023 年入库案例采取同一观点：妈妈带着儿子在汽车里，行为人用刀控制住小孩，指着小孩向妈妈要钱并说“不给钱就杀了你儿子”，既当场以暴力相威胁又当场取得财物，直接定抢劫罪；绑架是要给人质家人留准备财物的时间的。

* > **注意**：满足两个当场就定抢劫这一点和法考观点略有不同。

* 同一标准下，被害人还能“选择跑”不构成有余地：以当场杀死其孩子相威胁向母亲要钱，足以压制她的反抗——按“可以跑”的理解，小孩也可以选择收尸。

### 与敲诈勒索罪：有无控制人质

* 区分关键看**有无控制人质**：控制人质定绑架罪，没有控制人质构成敲诈勒索罪。

* 控制住被害人、剥夺其自由后向其家人要钱，构成绑架罪；根本没有控制被害人，只是给其父亲打电话**谎称**控制住了他，缺少“非法拘禁 A”，只剩“敲诈勒索 B”，只能定敲诈勒索罪。

* 边界一：带走一个三岁的孩子向其家人要钱，**可以定绑架罪**，因为带走意味着已经对他进行了控制。

* 边界二：带走的是成年人，谎称带他出去旅游，他很安心地睡觉、手机关机，再向他父亲谎称“孩子在我手上，不给钱就撕票”，没有对成年人实施非法拘禁，只是谎称绑架，只能定敲诈勒索罪。

* > **注意**：这类谎称绑架不能定诈骗，这一点和法考观点不一样。

### 与非法拘禁罪：有无勒索财物的目的

* 绑架罪是“非法拘禁 A ＋ 敲诈勒索 B”，非法拘禁罪只是“非法拘禁 A”，两者之分就在有没有“敲诈勒索 B”。

* 区分标准是**有无勒索财物的目的，即有无非法占有目的**：有则构成绑架罪，没有则构成非法拘禁罪。

## 抢劫罪

### 与诈骗、敲诈勒索：被害人有没有选择的余地

* 军大衣加啤酒瓶案例：行为人闯进储蓄大厅，虚构手榴弹并当场威胁“给老子 20 万”，工作人员为保命数了 20 万递过去，行为人取钱就跑，啤酒瓶掉在原地。

* 抢劫罪的结构是**强制手段压制反抗、取得财物**：工作人员担心被炸死而不敢反抗，财物被取走，构成抢劫罪没有争议。

* > **结论**：抢劫罪所威胁的内容**是否真的要发生，不影响**定罪。

* 黑夜持刀说“不给钱我马上砍死你”，而行为人内心其实打算不给钱也会放对方走——照样构成抢劫罪：被害人不知情，行为人主观上仍有压制反抗的故意，客观上仍有压制反抗的行为并取走了财物。

* 诈骗罪的五步结构是：欺骗行为；对方产生（维持）认识错误；对方基于认识错误处分财物；行为人取得财物；被害人遭受损失。

* 军大衣案例带进五步结构**全部符合**：谎称有手榴弹是欺骗行为，工作人员误以为真形成认识错误，亲自数了 20 万递出是基于认识错误的处分，行为人取得财物，被害人遭受损失——但仍然不构成诈骗罪。

* 不构成诈骗的核心理由是**被害人没有选择的余地**，根本谈不上处分：行为人并不是想让对方基于认识错误去处分财物，而直接就是想**劫取财物**。

* 冒充警察案例：穿假警服、持假警官证骗取张三信任后说出“老子要抢劫”，张三逃跑，行为人追上把张三打倒抢走财物，定**冒充军警人员抢劫**；不再定招摇撞骗罪，因为招摇撞骗也是骗，被害人已被打倒、没有选择余地，谈不上处分。

* > **结论**：抢劫和诈骗、抢劫和敲诈的区分就是一句话——**被害人有没有选择的余地**；有选择余地才可能处分财物，才可能构成诈骗或敲诈勒索，没有选择余地就只能构成抢劫罪。

### 普通抢劫与事后抢劫：暴力的目的

* 区分两者的根本是**使用暴力或者以暴力相威胁的目的不同**。

* **普通抢劫**：使用暴力、以暴力相威胁，是为了**继续取得财物**。

* **事后抢劫**（转化型抢劫）：犯盗窃罪之后，为**窝藏赃物、抗拒抓捕、毁灭罪证**而**当场**使用暴力或以暴力相威胁。

* 事后抢劫成立需要三个条件同时具备：前置行为是盗窃罪；暴力发生在现场（当场）；目的落在窝藏赃物、抗拒抓捕、毁灭罪证三项之内。

* 掏手机进自己口袋、走出 5 米被发现，回身把被害人打倒并压制反抗后离开——犯的是盗窃罪，目的明显是抗拒抓捕和窝藏赃物，构成**事后抢劫**。

* 抢包时被害人紧抓不松手，行为人抡拳把其打倒夺走包——使用暴力的目的不是窝藏赃物（尚未取得）、不是抗拒抓捕（对方是在保护自己的财物）、不是毁灭罪证，三个法定目的全不符合，构成**普通抢劫**。

* 一行为兼有两说的情形：入室盗窃时主人返回要抓他，行为人掏出匕首说“不抓我我就带着东西离开，抓我我就弄死你”，被害人害怕而允许其带走家中财物。

* 此种情形**两重抢劫都成立**：从普通抢劫角度看是持匕首压制反抗并取得财物，从事后抢劫角度看是为抗拒抓捕而使用暴力、以暴力相威胁；行为人可能同时存在抗拒抓捕与取得财物等多个目的。

* 冲突时**一般优先认定为普通抢劫**，因为普通抢劫是基本规定，事后抢劫是特殊规定。

* > **易错点**：这里不是法条竞合。它与“一个犯罪既能通过作为构成、又能通过不作为构成时优先认定为作为”是同一个道理——作为是常见情形，两个都能解释通时先按基本规定来定。

### 拘禁型抢劫

* 非法拘禁罪与抢劫罪之分，看**有没有非法占有目的**：带着非法占有目的控制他人的构成抢劫罪，没有的只定非法拘禁罪。

* 为索取债务而非法拘禁、扣押他人，因为没有非法占有他人财物的目的，只能定非法拘禁罪。

* **拘禁型抢劫**：做客时把主人锁在对方自己家的卧室里，然后大摇大摆拿走其财物；主人想出来制止却没有能力开门，行为人压制了其反抗并取走财物，同样构成抢劫罪。

## 诈骗罪

### 与盗窃罪：有无处分意识和处分行为

* 区分关键是**受骗人有无处分财物的意识和行为**：同时具备构成诈骗罪，反之构成盗窃罪。

* 判别有无处分意识与处分行为，看**有无形成新的外部特征**；按数量交易、按重量交易称重之后形成新的外部特征，新外部特征以内的部分会产生整体的处分意识。

### 与侵占罪：非法占有目的产生的时间

* 诈骗类犯罪的共性是**先有非法占有目的**，带着非法占有目的去骗人，然后**再**取得对方财物，即非法占有目的产生在前、取得对方财物发生在后。

* 侵占罪一定是**先合法占有了他人财物**，在占有（委托保管）期间才产生非法占有目的。

* 邻居出国留学托我保管祖传古董，委托时我内心窃喜“马上就是我家的祖传古董”，表明非法占有目的在取得财物之前就已产生；邻居有处分意识和处分行为，直接把古董占有权处分给我保管一年，据此排除盗窃，定**诈骗罪**。

* 真想替他保管，半年后天天看古董产生深厚感情才想把文物转移走、拒不承认拒不退还，非法占有目的产生在合法占有期间，构成**侵占罪**。

### 与敲诈勒索罪：好人坏人

* 诈骗是被**认识错误**哄住了，敲诈是被**恐惧心理**压住了；外在表现就是被害人在交钱那一刻给行为人贴的标签是“好人”还是“坏人”。

* 判断标准是**“被害人认为”**，不是“客观上是不是”。客观上确实存在危险的行为人，只要被害人的危险认知不指向他，照样可能只成立诈骗。

* > **结论**：被害人认为你是好人，说明他被骗了，是诈骗；认为你是坏人，说明他被你吓住了，是敲诈勒索。

* 黑老大案例之一：谎称“你是不是得罪了黑老大，他要绑架你儿子”，被害人害怕但认为眼前人是好人（人家主动帮忙、还愿意去摆平），给 5 万块代为摆平，行为人什么也没干——构成**诈骗罪**。

* > **提示**：该案危险被认为来自那个“所谓的黑老大”而不是来自行为人本人；敲诈要求危险源指向行为人本人，而本案行为人在被害人的主观世界里只是跑腿传话的，甚至还是个善意的传话人。

* 黑老大案例之二：改成“给我 5 万块钱，如果不给钱，两天后我就让黑老大绑架你儿子”，危险直接从行为人嘴里说出来，被害人马上知道危险就来自他——构成**敲诈勒索罪**。

* 女婿案例之一：说“儿子、孙子被人家绑了，要钱 50 万，不给钱就撕票”，岳父觉得女婿是好人（这么顾家），构成**诈骗罪**。

* 女婿案例之二：说“限明天中午 12 点之前转 50 万，晚一分钟、少一分我就杀了我儿子，我断子你绝孙”，构成**敲诈勒索罪**。

* 情人案例之一：说“咱俩约会的照片被人家拍到了要公开”，对方甚至认为行为人是好人，构成**诈骗罪**；改口“你给我 10 万块，不给我就把隐私照片、隐私视频全部公开”，构成**敲诈勒索罪**。

* 三种人设的共同规律是：**保护者人设、好姑爷人设都只在虚构出一个“第三方”或者把危险推给别人时才成立；一旦危险被收回到自己身上，标签立刻翻脸**。

## 敲诈勒索罪

### 与诈骗罪不能成立想象竞合

* 诈骗罪要求受骗人**自愿地**交付财物，敲诈勒索罪要求受骗人心生恐惧、**被迫地**交付财物；自愿和被迫两种心态不可能同时存在于同一次交付行为中。

* 法考 2011 年、2012 年、2017 年三年主观题的案例分析题认为诈骗与敲诈可以成立想象竞合；本土观点不承认，司法实践判例和最高法权威案例也不承认。

* 最高法第 259 号案例指出：将被害人杀死后以绑架为名向被害人的亲属索要钱财，其亲属尽管完全可能相信被告人虚构被害人被绑架的事实，但**绝不会自愿地向被告人交付钱款**；交出也只能是在精神上受到胁迫、无奈才交出的，故不构成诈骗罪，两罪不能想象竞合。

* 本土结论是定敲诈勒索罪即足以全面评价：一是“自愿”与“被迫”不能并存，二是“敲诈”二字既有“敲”又有“诈”，“诈”本身即包含虚假成分。

* > **注意**：有些点研究生考试和法考的观点确实不一样，比如诈骗与敲诈的关系、绑架与抢劫的关系。

### 与抢劫罪：被害人还有没有选择的余地

* 区分标准是**被害人有没有选择的余地**：有则构成敲诈勒索罪，没有则构成抢劫罪。

| 情形 | 被害人有没有选择余地 | 结论 |
| :--- | :--- | :--- |
| 先杀死被害人，又劫取其财物 | 没有 | 抢劫罪（抢劫致人死亡） |
| 扇两个耳光，声称不给钱 3 日内杀死被害人 | 有——3 日内可以选择逃跑 | 敲诈勒索罪 |
| 持刀威胁，不给钱就杀人，被害人给 2 万 | 没有——是“当场”杀 | 抢劫罪 |
| 持刀威胁，不给钱明天就杀人，被害人给 2 万 | 有——还有一天可以逃跑 | 敲诈勒索罪 |

* 持刀杀人两案是最妙的一组对照：都是持刀、都是“不给钱就杀人”，只是一句“就杀”和一句“明天就杀”，被害人的选择余地就天差地别。

* > **结论**：同时满足“当场使用暴力”和“当场取得财物”两个条件，被害人就没有选择的余地，应认定为抢劫罪。

* 扇耳光案虽然也用了暴力、也威胁杀人，但给了 3 天；次日杀人案虽然当场拿到了钱，但给了 1 天——都不满足“当场”这个条件，所以都是敲诈勒索罪。

## 盗窃罪

### 与侵占罪：实行行为时财物由谁占有

* > **定义**：盗窃罪与侵占罪的分界是**实行行为时，财物由谁占有**。

* 实行行为时财物由**他人占有**，是打破旧占有、建立新占有，才能构成盗窃罪。

* 实行行为时财物由**本人占有**，是变合法占有为非法所有，只能构成侵占罪；财物处于**无人占有**（遗忘物、埋藏物）时同样是侵占罪。

* 借摩托车案例：借车时把钥匙给对方、骑到 5 公里外的超市，骑出约 3 公里后起意把车藏起来、再把钥匙还给对方——构成**侵占罪**。

* 该案中的“实行行为”不是产生想法的那一刻，而是**把摩托车藏起来**的那一刻；此时摩托车已由她骑出 3 公里、处于她的支配之下，属于本人占有，所以她没有打破他人占有。

* 借手机案例：接过手机后假装信号不好，让对方走远一点，然后悄悄溜走——实行行为是**悄悄溜走**，此时手机仍由主人在现场支配，属他人占有，被害人没有处分所有权也没有处分占有权，构成**盗窃罪**。

* > **易错点**：**握有不等于占有**，占有要作规范判断，关键看谁支配——**谁占有谁支配**；人就在旁边打电话时，明显是物主在支配。

```text
实行行为时，财物由他人占有 ──► 打破旧占有、建立新占有 ──► 盗窃
实行行为时，财物由本人占有 ──► 变占有为所有           ──► 侵占
实行行为时，财物处于无人占有（如遗忘物）───────────► 侵占
```

### 与抢夺罪：明抢暗偷

* 区分只有一句话——**明抢暗偷**：行为人自以为秘密的是盗窃，公然夺取的是抢夺。

* > **易错点**：盗窃罪里的“秘密窃取”指的是**形容人自以为秘密的方法**，是行为人自己以为没人发现，不是客观上真的没被发现。

* 候车室案例：某人在候车室见前排人已睡着、旁边看报的人膝前有包，因包离睡着的人更近而认定是睡着者的包，见其睡着才快速拿起混入人群——认定为**盗窃罪**；包其实属于旁边看报的人，但主客观相统一，客观归属不影响其秘密窃取的故意。

* 桌上手机案例：手机就放在被害人身边的桌面上，行为人瞄准时机一把抓走就跑，被害人受惊追赶——构成**抢夺罪**；被害人必然会当场发现，行为人根本没有秘密窃取的故意，只有公然夺取的故意。

* 心理层面的区别是**尊不尊重被害人**：盗窃中行为人蹑手蹑脚、东张西望、找机会下手，不想让被害人立马发现，是对被害人有基本的尊重；抢夺中是“我看上就是我的”的藐视心态。

### 与故意毁坏财物罪：排除意思与利用意思

* 区分看**有没有非法占有目的**，具体说是主观上只有**排除意思**、还是有**排除意思加利用意思**。

* 只有排除意思而无利用意思的，定**故意毁坏财物罪**；有排除意思又有利用意思的，属盗窃。

## 侵占罪与职务侵占罪

* 侵占罪与职务侵占罪是**法条竞合**，同时构成两罪的，**优先认定职务侵占**。

* 职务侵占罪**必须利用职务便利**。

* 职务侵占罪是盗窃罪、诈骗罪、侵占罪的**特别法条**，它是“利用职务便利的盗窃”“利用职务便利的侵占”“利用职务便利的诈骗”。

## 故意毁坏财物罪与破坏生产经营罪

* 区分关键是所破坏的对象**是不是用于生产经营的生产工具、生产资料**。

* 是的，定**破坏生产经营罪**；不是的，定**故意毁坏财物罪**。

## 案例逐项排除

### 名画装裱：诈骗还是侵占

* 题干关键信息是行为人看到名画就“想将名画据为己有”，即非法占有目的在取得对方财物之前就已产生；对方把画交给行为人装裱并约定三天，既有意图转移占有权的处分意识，也有客观转移三天占有权的处分行为。

* 先列可能罪名：诈骗罪、侵占罪，以“名画三个月内会发霉”相威胁还可能构成敲诈勒索罪，行为人也可能构成盗窃罪。

* 第一刀诈骗对敲诈：被害人在发现真相之前肯定认为对方是好人，**排除敲诈勒索**，剩三个。

* 第二刀诈骗对侵占：非法占有目的产生在取得对方财物之前，**排除侵占**。

* 第三刀诈骗对盗窃：受骗人既有处分意识也有处分行为，**排除盗窃**，只剩**诈骗罪**。

* 变式：若行为人真的想替对方装裱，第二天发现画好便藏起来、拒不承认拒不退还，则是非法占有目的产生在占有他人财物之后，构成**侵占罪**。

### 地铁上的包：遗忘物归谁

* 行为人见地铁座位上有一个贵重包，问旁边人是否是对方的包、请对方拿一下；对方意识到这只是前一个乘客遗落的，便谎称是自己的包并放到腿上，下一站带着包逃离。

* 可能罪名是诈骗、盗窃、侵占三个。

* 第一刀诈骗对盗窃：包的原主已经下了地铁，不可能处分；被欺骗者对包既无处分意识也无处分行为，**排除诈骗**。

* 第二刀盗窃对侵占：实行行为是“把包拿过来放到自己腿上”，此时原主不占有（对他而言是遗忘物），地铁管理方也不占有（公共空间），包处于**无人占有**状态，**排除盗窃**。

* 结论是**侵占罪**，即将他人的遗忘物非法据为己有、数额较大、拒不交出。

### 摩托车的四道题

* 题一：行为人骑着所有权人的摩托车载着对方，路过不平地段让对方下车，过了那段再上来，对方下车后行为人一加油跑掉——**抢夺罪**（按研究生考试观点；法考另有不同观点）。排除诈骗是因为对方既未处分所有权也未处分占有权；排除侵占是因为实行行为时摩托车仍由他人占有；排除盗窃是因为明知车系他人所有仍公然夺取。

* 题二：摩托车丢失的一方想据为己有，请对方吃饭，席间谎称“你的摩托车借我用一下，我骑到 5km 外的超市买点东西，一会儿回来”，对方同意，行为人骑到一半把车藏起来——**诈骗罪**。对方允许行为人独立支配 5 公里，有处分占有权的意识和行为，**排除盗窃**；非法占有目的产生在取得财物之前，**排除侵占**；对方有处分行为而抢夺的被害人不可能有处分行为，**排除抢夺**；谎称借用、名为借实为骗，定诈骗。

* 题三：预谋的“画圆”——车主特别谨慎，只同意“以我为中心画圆，不能骑出去”，行为人围着车主转圈、圈越来越大后蹭地跑掉——**抢夺罪**。车主既未处分所有权也未处分占有权，**排除诈骗**；实行行为时摩托车由车主占有，属他人占有，**排除侵占**；公然夺取，**排除盗窃**；车主站在中间时才真正是占有人、才能支配。

* 题四：正常借出摩托车，骑出 3 公里后才产生非法占有目的——**侵占罪**，属于变合法占有为非法所有。

* 诈骗与敲诈属于交付性犯罪，被害人基于认识错误或恐惧“自愿”交付；盗窃与抢夺属于夺取性犯罪，被害人不可能有处分意识和处分行为——判断摩托车系列题时先确定这一前提，再逐项排除。

### 拘禁致死后的虚构绑架

* 行为人为索取赌债伙同他人把被害人关进地下室构成非法拘禁，期间在默许下多次对其拳打脚踢致其死亡——拘禁过程中使用暴力致人死亡的，转化为**故意杀人罪**。

* 被害人死亡后，谎称其被绑架、向其家人索要巨额赎金，不可能构成绑架罪，因为绑架要求控制人质。

* 家人认为对方是坏人，对方说的是“不给钱就杀人”“绑架要求支付赎金”，故不成立诈骗，成立**敲诈勒索罪**；前后两罪数罪并罚。

* 最高法第 259 号案例亦指出被害人亲属“绝不会自愿交付”，只能是精神上受胁迫而被迫交付；教育部官方答案中“诈骗罪”三个字只字未提。

## 观点分歧与练习取舍

* 观点分歧要在教材角注里写清法考坚持什么观点、本土理论坚持什么观点，这些区分不写清则观点错了、题目就全错了。

* 不要轻易做来路不明的模拟题，辛苦积累的正确观点有可能被一个模拟题带偏，到最后都不知道哪个观点才是研究生考试的观点。

* 最好的状态是学会了底层逻辑、基本原理，不管怎么考都能推导出来；押题不押题都是赌。

* 非法学专业的优势是首次接触到的就是研究生考试的观点；法学同学的优势只是有点基础、可能更好理解，但拆掉茅草屋、重建高楼，任务更重。

* 刑法争议问题很多，法条竞合、想象竞合争议尤其大，能被过滤提炼出来的重点要牢牢掌握。
