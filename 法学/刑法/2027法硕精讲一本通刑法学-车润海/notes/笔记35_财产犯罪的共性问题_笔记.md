# 财产犯罪的共性问题

## 财产犯罪的类型体系

### 四类客观行为

财产犯罪的分类分界线只有一个：行为人主观上有没有非法占有目的。

| 类型 | 主观上 | 典型罪名 |
| :--- | :--- | :--- |
| 取得型 | 有非法占有他人财物的目的 | 抢劫、盗窃、诈骗、抢夺 |
| 挪用型 | 没有非法占有目的，只是挪用公私财产 | 挪用资金罪、挪用特定款物罪 |
| 毁弃型 | 没有非法占有目的，以毁坏他人财物为目的 | 故意毁坏财物罪、破坏生产经营罪 |
| 不履行型 | 以"不履行"为标志 | 拒不支付劳动报酬罪，单位也能构成 |

* **取得型财产犯罪**

   * > **定义**：行为人主观上以非法占有为目的，意图非法占有他人财物的财产犯罪。

   * 属于本章重中之重，后文所有罪名都挂在这个目的犯定位之下。

   * 是最常见的一类，抢劫、盗窃、诈骗、抢夺都归在这里。

* **挪用型财产犯罪**

   * > **定义**：行为人没有非法占有目的，只是挪用公私财产的财产犯罪。

   * 典型形态是"我先用着，不是要占为己有"。

   * 只侵犯了所有权中的部分权能，没有把单位财物变成自己的。

* **毁弃型财产犯罪**

   * > **定义**：行为人对财物本身没有非法占有目的，只以毁坏财物为内容的财产犯罪。

   * 典型形态是"我不是要你的东西，我只是要它坏掉"。

* **不履行型财产犯罪**

   * > **定义**：以不履行特定义务为标志的财产犯罪。

   * 除自然人外，单位也能构成。

### 取得型的逻辑结构

```text
侵犯财产罪
│
├─ 取得型（主观上以非法占有为目的）★ 重中之重
│   │
│   ├─ 夺取型：财物不是被害人自愿交到你手上的
│   │   │
│   │   ├─ 暴力型
│   │   │   ├─ 对人使用暴力、压制其反抗 ──────→ 抢劫罪
│   │   │   └─ 只对物使用暴力、一把夺走 ──────→ 抢夺罪
│   │   │
│   │   └─ 平和型
│   │       ├─ 转移占有：打破旧占有、建立新占有 ──→ 盗窃罪
│   │       └─ 不转移占有：变占有为所有 ─────────→ 侵占罪
│   │
│   └─ 交付型：被害人主动把财物交出来
│       ├─ 因认识错误而处分自己的财物 ──────────→ 诈骗罪
│       └─ 因恐惧心理而交付财物 ────────────────→ 敲诈勒索罪
│
├─ 挪用型（如挪用资金罪）
├─ 毁弃型（主观上只想毁坏，并无非法占有目的）
└─ 不履行型（如拒不支付劳动报酬罪）
```

* **夺取型财产犯罪**

   * > **定义**：被害人的财物不是自愿交到行为人手中的取得型财产犯罪。

   * 暴力型中对人使用暴力、压制其反抗的，成立抢劫罪。

   * 暴力型中只对物使用暴力、一把夺走的，成立抢夺罪。

   * 平和型中"转移占有"的，打破旧占有、建立新占有，成立盗窃罪。

   * 平和型中"不转移占有"的，变占有为所有，成立侵占罪。

* **交付型财产犯罪**

   * > **定义**：被害人主动把财物交出来的取得型财产犯罪。

   * 被害人因认识错误而处分自己财物的，成立诈骗罪。

   * 被害人因恐惧心理而交付财物的，成立敲诈勒索罪。

   * 两者都是"被害人经手把钱物给了我"，分水岭是财物是骗出来的还是吓出来的。

* **转移占有**

   * > **定义**：打破他人对财物的占有，建立自己对同一财物的占有。

   * 把你口袋里的手机偷走，属于平和型中的转移占有，构成盗窃罪。

   * 基于委托保管关系本来就在自己占有之下，事后产生非法占有目的据为己有，属于不转移占有，构成侵占罪。

* **威胁的内容**

   * 交付型中的恐惧心理可以来自"不给钱就打断你的腿"这类以暴力、伤害相威胁的内容。

### 本章的构成特征

* **罪名数量**

   * 考纲要求掌握的罪共 11 个，按取得型、毁弃型、不履行型、挪用型四类分下去。

* **犯罪客体**

   * 本章之罪侵害的是公私财产所有权。

   * "公"指公共财产，"私"指公民私人财产。

* **客观方面**

   * 故意非法占有他人财物，即取得型。

   * 挪用公私财物，如挪用资金罪、挪用特定款物罪。

   * 故意破坏生产经营、毁坏公私财物，即毁弃型。

* **犯罪主体**

   * 多数是一般主体，少数是特殊主体。

   * 职务侵占罪、挪用资金罪属于特殊主体。

   * 原则上要求年满 16 周岁。

   * 普通抢劫罪的主体要求年满 14 周岁。

   * 个别罪名单位也能构成，如拒不支付劳动报酬罪。

* **主观方面**

   * 故意。

## 所有权的四项权能与刑法重心

### 所有权与四项权能

* **所有权（ownership）**

   * > **定义**：对财物享有占有、使用、收益、处分四项权能的物权、绝对权、对世权。

   * 具有排他性，可以排他性地对抗任意第三人。

* **四项权能**

   * 占有：可以支配财物，按自己的意愿把它带到任何想去的地方。

   * 使用：按财物的用途使用它。

   * 收益：把财物租出去取得利益。

   * 处分：把财物送人、卖给别人。

### 民法看处分，刑法看占有

* **民法上的重心**

   * 非所有权人同样可能取得对财物的占有、使用、收益，唯独没有处分权。

   * 擅自处分在民法上讨论的是无权处分。

   * 所以民法最看重四项权能里的处分。

* **刑法上的重心**

   * 刑法重视的是所有权，在四项权能中实际盯住的是占有。

   * 民法盯处分、刑法盯占有，是本章最关键的一次视角切换。

### 全部权能与部分权能

* **侵犯全部权能**

   * 偷走他人手机，占有权、使用权、收益权、处分权四项同时被侵犯。

* **侵犯部分权能**

   * 公司出纳利用职务便利把本单位资金转出归个人使用、数额巨大、半年后归还的，只侵犯占有权、使用权、收益权，未侵犯处分权。

   * 半年后归还意味着没有把单位财物变成自己的，只是借用，所以仅侵犯部分权能。

## 占有状态之间的对抗

### 三者的定性

* **非法占有**

   * > **定义**：一种状态、一个事实，不是一项权利。

* **合法占有**

   * 是权利的形态。

* **所有权**

   * 是权利的形态。

* > **易错点**：三者定性不同，混不清这一点，后面所有占有判断都会塌。

### 合法占有

* **对抗所有权人**

   * 租赁期间受领人对财物的占有受法律保护，可以正当拒绝所有权人返还的要求。

   * 所有权人在他人合法占有财物期间把财物悄悄偷回来并要求赔偿，完全可能构成财产犯罪。

   * "买卖不破租赁"由此打通。

* **对抗非法占有人**

   * 合法占有人对被非法占有人取走的财物悄悄取回，在刑法上叫自救行为，不构成财产犯罪。

   * 理由是主观上没有非法占有他人财物的目的，属于恢复被侵害的法益。

### 所有权人的占有

* **对抗非法占有**

   * 所有权人通过定位把被偷走的财物悄悄取回，构成自救行为，不构成财产犯罪。

   * 例子：甲偷走乙的手机，乙是所有权人、甲是非法占有人，乙把手机偷回不构成盗窃罪。

* **对抗合法占有**

   * 所有权人不能对抗合法占有人，无权要求合法占有人返还财物。

* > **易错点**：⚠️ 书上"所有权具有排他支配性、所有权人可以对抗第三人"是民法角度的原则表述。从刑法角度看，所有权人不能对抗合法占有人，考试最爱在这里下坑。

### 非法占有

* **对抗所有权人与合法占有人**

   * 两者都不能对抗。

* **对抗第三人**

   * 对所有权人、合法占有人以外的任意第三人完全可以对抗。

   * 甲把手机租给乙，乙的手机被丙偷走；丁明知是丙偷的又从丙处取走，丁构成盗窃罪，因为他破坏的是丙对财物的占有关系。

### 对抗矩阵

| 占有状态 | 对抗所有权人 | 对抗合法占有人 | 对抗非法占有人 | 对抗其他第三人 |
| :--- | :--- | :--- | :--- | :--- |
| 所有权（所有权人的占有） | —— | 不能 | 能 | 能 |
| 合法占有 | 能 | —— | 能 | 能 |
| 非法占有 | 不能 | 不能 | —— | 能 |

* **威力排序**

   * 合法占有威力最大，能对抗所有权人、能对抗非法占有人。

   * 所有权人次之，除合法占有人之外都能对抗。

   * 非法占有人最弱，只对第三人有效。

* **表中"能"的刑法评价**

   * 表中所有的"能"，在刑法上都不构成犯罪，因为主观上没有非法占有他人财物的目的，属于恢复被侵害法益的自救行为。

### 非法占有对第三人的效力

* **受保护的是占有状态本身**

   * 哪怕是非法占有这一事实、这一状态，未经法定程序任何人也不得随意改变其占有状态。

   * 理由是若允许随意改变，经济社会秩序会一片大乱。

* **违禁品的推论**

   * 李四持有的毒品属于非法占有，他人不能抢走、骗走、偷走。

   * 李四生产销售的伪劣产品属于非法占有，他人同样不能抢走、骗走、偷走。

* **与执法的区别**

   * 警察通过执法行为缴获他人持有的毒品、生产销售的伪劣产品，是有法定程序的，区别就在这里。

## 财物按占有状态的分类

| 占有状态 | 财物性质与情形 | 能否成为财产犯罪的对象 |
| :--- | :--- | :--- |
| 本人占有，本人所有 | 自有财物，如自己口袋里的手机 | 不是本人的犯罪对象，摔毁、送人都是自己的处分行为 |
| 本人占有，他人所有 | 委托保管物 | 可以成为侵占罪的对象，占有期间变占有为所有、拒不退还 |
| 他人占有 | 取得型犯罪的客体 | 可以成为盗窃、抢夺、诈骗、抢劫、敲诈勒索的对象 |
| 无人占有，无人所有 | 无主物，如从垃圾桶翻出的东西 | 不是财产犯罪的对象，属先占先得的物权变动方式 |
| 无人占有，他人所有 | 遗忘物、埋藏物 | 可以成为侵占罪的对象，权利人未知但肯定存在 |

* **本人自有财物不是本人的犯罪对象**

   * 自己的手机在自己口袋里，摔毁它、送人都是自己的处分行为，不构成刑法意义上的财产犯罪。

* **侵占罪的对象就三类**

   * 委托保管物、遗忘物、埋藏物。

   * 捡到钱包据为己有、拒不退还，权利人是谁不知道但一定存在，成立侵占。

* **占有状态直接决定罪名**

   * 财物的占有状态直接决定行为人偷的是"别人的东西"还是"没人要的东西"，也直接决定罪名是盗窃还是侵占。

## 刑法上的占有判断

### 刑法上的占有与支配

* **刑法上的占有**

   * > **定义**：对财物事实上的、现实的支配。

   * 全部占有判断都围着"支配"两个字转。

   * 占有分为事实上的占有和观念上的占有两部分。

* **支配**

   * > **定义**：可以按照自己的意愿，把财物带到任何想去的地方。

   * 所有权是物权、绝对权、对世权，具有排他性；占有作为所有权的一项权能也具有排他性。

   * "排他"转换成刑法用语，就是支配。

   * > **结论**：谁支配，谁占有；谁占有，谁支配。

   * 说到底就是秉持一个正常的三观和社会一般观念。

### 事实占有与观念占有

* **相互补强**

   * 事实占有和观念占有可以相互补充、相互补强。

   * 事实占有越强，对观念占有的要求就越弱。

   * 家里财物很多但记不清有什么、放在哪里，仍然是自己的占有物，因为事实占有表现得很强。

   * 钥匙套在手上而毫无察觉，仍是自己占有的财物，因为事实占有就在身上。

   * 事实占有变弱时观念占有必须补强，不补强就可能变成遗忘物。

* **课堂上的手机**

   * 手机在最后几排充电，人在讲台上每隔十分钟声明一次所有权，是靠观念占有对事实占有进行补强。

   * 事实占有和观念占有之间并不矛盾。

### 观念占有的两种形态

* **自己观念占有**

   * > **定义**：权利人有非常清晰、具体的占有意思。

   * 只要求概括占有，不要求记得财物有多少、放在什么位置。

* **社会观念占有**

   * > **定义**：根据社会一般观念推定财物是谁占有、是他人遗忘物还是他人占有的财物。

   * 共享单车：这些自行车是他人特意停放在这个位置的、需扫码才能骑乘，属他人占有，取走定盗窃罪。

   * 酒店房间：被子、枕头、烧水壶、热水器按社会一般观念都属他人占有，取走定盗窃罪。

   * 自动售货机：无人看守也要砸开取走饮料，社会一般观念推定为他人占有，定盗窃罪。

   * 寺庙投币：水池里的硬币按社会一般观念属寺庙管理者占有，捞取定盗窃罪而不是侵占。

### 寺庙贡品案

* **案情**

   * 2020 年疫情后，浙江小华多次到自家附近的寺庙，取走香客拜佛后放在佛像前桌上的水果。

   * 香客发现后没有追究，大和尚因反复被拿而报警，警方通过监控查到多次作案。

* **定性**

   * 这根本不是香客遗忘的财物。

   * 水果被置于寺庙支配的空间范围内、放在寺庙的桌子上，香客即便处分也是处分给寺庙，不能认为处分给了小华。

   * 构成盗窃罪，属于多次盗窃，两年以内三次以上。

## 事实占有的形态

事实占有不要求随身携带，财物可以与权利人保持一定距离；离权利人越近，越容易被控制、支配、占有。

```text
离权利人由近到远
──────────────────────────────────────────
  实力占有 → 短暂离开 → 辅助占有 → 存款占有
  → 占有转化（转化占有）→ 封缄物占有 → 死者占有
──────────────────────────────────────────
```

### 实力占有

* **范围**

   * 处于主人实力控制范围内的占有，财物离主人距离最近，权利人通常可以左右财物、支配财物，对财物的支配没有任何障碍。

   * 和身体部位现实接触的财物（手提、肩扛、口袋里装的）属于实力占有。

   * 与财物保持一定距离但仍在实力控制范围内的，也属于实力占有。

* **高铁行李箱**

   * 放在行李架上、不抱着也不摸着的行李箱，仍是主人占有的财物。

   * 他人下车顺手牵羊取走，构成盗窃罪：行李箱是主人占有的财物，取走后变成他人占有，属于打破旧占有、建立新占有。

* **试衣间里的新衣服**

   * 顾客穿着新衣服溜走，衣服仍是店主占有的财物，因为只有店主才能支配、处分。

   * 店主只会在付过钱之后才允许顾客任意支配。

* **借手机看一看**

   * 手机在自己手上，但对方不同意就不能带走，说明自己没有取得支配权，不属于自己的占有。

   * 酒店提供的睡衣可穿一天、穿一夜，仍是他人占有的财物，因为充其量只能短暂使用。

* > **结论**：握有不等于占有。

### 短暂离开

* **界定**

   * 主人还在现场，只是暂时走开，财物仍由主人占有。

   * 跟遗忘不是一回事。

* **校园占座的书**

   * 把书放在桌子、餐桌上再去打饭，是短暂离开而不是遗忘。

   * 他人拿走构成盗窃罪：这不是遗忘物，权利人对它才有支配权，未经同意别人不能拿走。

* **收银台边的随身包**

   * 起身去饭店收银台付款时把包放在餐桌上，虽与财物有距离但仍在控制范围内，仍属主人占有。

* **反例：公共交通工具上的遗忘**

   * 乘客下车后公交车已经开走，遗忘在车内的皮包对主人而言是遗忘物。

   * 这类典型的遗忘物不属于主人占有。

### 辅助占有

* **定义**

   * 原则上财物由上位者占有，下位者仅起辅助作用。

* **秘书提包案**

   * 领导把包递给秘书"帮我提一会儿"，不构成委托保管关系。

   * 未经领导同意秘书不能带包去任何想去的地方，支配权仍在领导。

   * 秘密拉开拉链取走现金，是打破旧占有、建立新占有，构成盗窃罪而不是侵占罪。

* **高铁站的小红帽**

   * 付费请人搬运行李的旅客是占有人，搬运行李的小红帽只是辅助。

   * 小红帽携行李混入人群跑走，构成盗窃罪或者抢夺罪，不可能构成侵占罪。

* > **易错点**：⚠️ 辅助占有的场合财物在上位者，判断标准仍是"未经上位者同意，下位者能否带它去任何想去的地方"。

### 存款占有

* **定义**

   * 现金交到银行以后，现金的占有人是银行。

   * 储户取得的是对银行的债权，储户占有的是财产性利益而不是现金。

* **侵入银行系统转走存款**

   * 甲侵入银行计算机信息系统把乙的存款转入自己账户，侵害对象是乙的财产性利益。

   * 将他人占有的财产性利益转移为自己占有，可以构成盗窃罪。

* **银行被抢**

   * 现金处在银行的占有状态之下，被害人是银行而不是储户。

   * 储户没有财产损失，因为其占有的是对等的财产性利益。

### 占有转化

* **定义**

   * > **定义**：权利人丧失了对财物的占有，但在特定条件下财物转化为第三人的占有，仍属他人占有的财物。

* **遗忘不等于无人占有**

   * 是遗忘物并不意味着财物已经丧失占有状态、已经无人占有。

   * 包忘在你家时，财物已经自动地、无缝衔接地转化为你的占有状态。

   * 小偷进来偷走破坏的是你的占有关系，构成盗窃罪。

* **转化标准**

   * 封闭空间有明确的管理者，可以转化为第三人的占有。

   * 开放场所、无人排他支配，不能转化，财物处于无人占有状态。

   * 你家对内部空间有排他性支配权；公园进出不要求任何资质、不要求任何人同意，管理者也不可能立马发现，排他性支配不成立。

* **后果分岔**

   * 包被别人偷走，成立盗窃罪。

   * 包被管理者之外的他人捡走拒不退还，只能成立侵占罪。

* > **易错点**：⚠️ 不要因为"我确实是所有权人"就把财物一路护到底。行为人破坏的从来不是所有权人对财物的占有关系，而是当时实际占有人的占有关系。

### 封缄物占有

* **定义**

   * > **定义**：装入容器之内然后封口之物，即主人将财物放置在采取密封措施的器具之中，如上锁的保险柜、加锁封锢的集装箱。

   * 封缄物中的财物称为内容物，封缄行为代表着主人强烈的占有意思。

   * 打开封缄物取走内容物，破坏主人对财物的占有关系，一般认为构成盗窃罪。

* **委托保管的保险柜**

   * 保险箱整体由受托人占有，受托人负有保管义务，双方存在委托保管合同关系。

   * 保险柜里的内容物由委托人占有，因为钥匙和密码在委托人手中，委托人才是内容的支配者。

   * 受托人擅自撬开取走内容物，构成盗窃罪。

* **划分标准**

   * 没有采取特殊密封措施时，里面的财物仍然由受托人占有。

   * 特殊密封措施其实指特殊的防盗措施，必须有特殊防盗措施才能评价为刑法意义上的封缄物，这与民法的观点不大一样。

* **干洗店口袋的反例**

   * 把衣服交出去干洗，占有权已经转移给干洗店，对方可以带衣服离开现场。

   * 口袋外面的普通拉链不是封缄物，拉开拉链发现里面的钱并据为己有，只构成侵占罪。

* **名画例**

   * 乙将封缄物整体据为己有、拒不退还，构成侵占罪，因为他对整体有占有权，是变合法占有为非法所有。

   * 乙撬开封缄物取走里面的名画，构成盗窃罪。

* > **易错点**：整体归受托人、内容物归委托人，前提是采取了特殊防盗措施，这一节最容易绕进去。

### 死者占有

* **规定来源**

   * 这是司法解释做出的特殊规定，不符合一般原理：按一般原理，人去世后已无能力支配自己生前的财物。

* **规则**

   * 实施故意杀人犯罪后临时起意拿走他人财物的，应当以此前所实施的犯罪和盗窃罪实行数罪并罚。

   * 既然并罚，就表明司法解释认为死者可以有限制地占有其剩余财物。

   * 可以简化为当场杀，当场拿，定盗窃。

* **适用前提**

   * 行为人杀人时不能有非法占有目的。

   * 一开始就带着非法占有目的、先杀人后取财的，直接定抢劫罪，按抢劫致人死亡的结果加重处理。

   * 典型情形是因报仇杀人后见财物临时起意顺手牵羊，故意杀人与盗窃数罪并罚。

## 遗忘物与占有转化的判断

### 失物招领处的两案

* **甲上交**

   * 张三在公园发现疑似遗忘的包，没有顺手牵走，而是上交公园失物招领处并登记。

* **李四偷取**

   * 李四明知失物招领处有东西，直接把这台电脑偷走，构成盗窃罪。

   * 电脑当然属于张三，但张三遗忘后不会自动转给"这个场地"去占有。

   * 其他游客捡起交给管理者后，管理者有明确的占有意思、客观上也能支配和保管，这时才发生占有转化。

   * 李四破坏的是管理者对财物的占有关系，所以是盗窃。

### 公共空间与非公共空间

```text
        同一个包，同一个主人
                │
      ┌─────────┴─────────┐
      │                   │
  忘在非公共空间        忘在公共空间
  （别人家里）          （公园 / 公交车）
      │                   │
  有明确的财物管理人    没有明确的财物管理人
  空间相对封闭          上下客流动、无管理者
  可被排他性支配        排他性支配不成立
      │                   │
  占有自动转化          关键看管理者有没有
  仍是「占有物」         明确的占有意思
      │              ┌────┴────┐
      │              │         │
      │          他发现了      他没发现
      │          并保管登记    一直放着
      │              │         │
      │        转化为占有物   仍是遗忘物
      │              │         │
   他人偷走         他人偷走    他人捡走
   → 盗窃罪        → 盗窃罪    拒不退还 → 侵占罪
```

* **判断分界**

   * 两个案例的差别不在"是不是忘的"，而在忘在什么地方。

   * 忘在非公共空间的，空间相对封闭、有明确的财物管理人、可被排他性支配，占有自动且无缝衔接地转化，财物仍是占有物，他人偷走定盗窃罪。

   * 所有者据为己有的是在自己的占有状态下变占有为所有，构成侵占罪。

   * 忘在公共空间的，没有明确的财物管理人，能否转化要看管理者有没有明确的占有意思。

   * 管理者发现并保管登记的，转化为占有物，他人偷走定盗窃罪。

   * 管理者一直放着没人发现的，仍是遗忘物，他人捡走拒不退还定侵占罪。

### 非公共空间的三个特征

```text
① 有明确的财物管理人   ←── 最关键
        ↓
② 场所相对封闭
        ↓
③ 管理者可以支配这个空间，而且是「排他地」支配
```

* **特征一：有明确的财物管理人**

   * 这是核心中的核心。

   * 包忘在你家里面，你是这个家的主人，对空间内的财物当然有占有权。

* **特征二：场所相对封闭**

   * 排他性支配得以成立的前提条件。

* **特征三：管理者可以排他地支配这个空间**

   * 光说"可以支配"不够，必须是排他性支配，别人进不来也动不了，才谈得上占有转化。

* **重要性递减**

   * 三个特征的排列顺序即重要性顺序。

### 公共交通工具上的遗失物

* **公交车**

   * 公交是公共空间，也没有明确的财物管理人。

   * 司机的职责是安全驾驶，不可能对车上每一位乘客的财物负有管理义务和责任。

   * 若有这种义务，意味着司机开车时要不时回头查看有没有人丢东西，会分心甚至导致危险驾驶。

   * 更要命的是乘客找不到钱包时是否可以要求司机赔偿，整车乘客的财物风险都压给正在开车的司机显然不合适。

* **高铁与地铁**

   * 不是每节车厢都有乘务员，人来人往，开放性极强，地铁更是如此。

* **结论**

   * 公交、高铁、地铁上遗失的财物，处理逻辑与公园完全相同。

   * 管理者发现并保管的转化为其占有物，他人再偷走是盗窃罪。

   * 始终无人发现的就是彻头彻尾的遗忘物，捡走拒不退还只构成侵占罪。

* > **易错点**：⚠️ 不能认为财物可以无缝衔接地自动转给高铁管理者占有——否则找不到时就可以主张让管理者民事赔偿，理由是"这是在你的占有状态之下把我的东西搞丢的"，这显然不合理。

### 修正的二重控制说

```text
            判断一个财物是不是「遗忘物」
                        │
        ┌───────────────┴───────────────┐
        │                               │
  第一重控制：主人是否              第二重控制：相关空间的
  已经丧失了对财物的控制            管理者是否也控制不了它
        │                               │
   离开 → 突破                      未发现 / 无明确占有意思 → 突破
        │                               │
        └───────────────┬───────────────┘
                        │
          两重都突破 → 遗忘物（无人占有）
          只破第一重 → 发生占有转化，仍是他人占有物
```

* **第一重控制**

   * 主人是否已经丧失了对财物的控制。

* **第二重控制**

   * 相关空间的管理者是否也控制不了它，即未发现或者没有明确的占有意思。

* **判断后果**

   * 两重控制全部突破的，才是遗忘物，处于无人占有状态。

   * 只突破第一重的，发生占有转化，仍是他人占有物。

* **两个场景**

   * 包忘在你家、我走了：突破第一重控制但没有突破第二重控制，主人丧失占有而你仍控制着这个包，它只是"我的"遗忘物，对你而言仍是你的占有物，他人偷走定盗窃罪。

   * 包忘在公园长椅上：主人已离开，公园管理者也没有发现、没有明确占有意思，两重控制全部突破，这才是真正的遗忘物。

   * 别的游客捡起后交给公园失物招领处，说明它重新落入工作人员的支配范围，没有突破两重控制。

* > **提示**：法考的观点在这里与中国本土观点有点不一样，做题前先想清楚自己站在哪一边。

### 失而复得与遗忘物

* **为什么找得回来还能叫遗忘物**

   * 正因为它属于遗忘物，权利人才能主张"失而复得"把它取回来。

   * 这个动作本身就恰恰证明了它属于遗忘物；如果它已被评价为"他人占有的财物"，权利人伸手拿回来才叫事。

* **高铁行李箱**

   * 高铁终点站是天津，按座位号由列车长和工作人员取出，因为主人已经丧失控制，对主人而言是遗忘物。

   * 行李箱被拖到河北后又经其他高铁运回天津，对主人而言仍是遗忘物。

   * 它不能自动转给高铁管理者占有：高铁封闭性不强、开放性很强，也没有明确的财物管理人。

   * 其他旅客要是捡走，只能构成侵占，不能构成盗窃。

### 出租车的后备箱

* **甲去乙家做客**

   * 甲离开时把包忘在乙家，该包自动转给乙占有。

   * 因为它遗落在非公共空间，主人对房子里的财物可以排他性支配，乙是这个家明确的管理者。

   * 小偷把包偷走构成盗窃罪，乙自己据为己有构成侵占罪。

* **乙下出租车忘取后备箱行李**

   * 后备箱这个空间有明确的财物管理人（司机）、场所相对封闭，行李箱可以转化给出租车司机占有。

   * 司机将行李箱据为己有是变占有为所有，构成侵占罪。

   * 后面那一位乘客下车取走行李箱，破坏的是司机对财物的占有关系，构成盗窃罪。

* **与公交的差异**

   * 出租车是狭小、相对封闭的空间，司机是这个空间的排他性支配者。

   * 即使车门不关、东西随手放在车里，那也是自己占有的财物。

   * 后面那位乘客也一定认知得到：这是忘在他人支配空间范围内的财物。

   * 主流判例把后一位乘客取走行李箱定为盗窃罪。

* **机场登机口的包与行李箱**

   * 这首先不是遗忘的财物，而是刻意放在那儿的，属事实占有中短暂离开的情形，权利人的占有意思非常明确。

   * 登机口虽也是公共空间，但飞机还没登机，此刻摆放在那里的行李必然是正在等登机的旅客放好的。

   * 即使退一步交给社会观念占有判断，社会一般观念同样会推出这是他人特意放在这里的、他人支配的财物。

   * 被他人擅自取走构成盗窃罪。

## 财产犯罪的对象

### 财物的扩大解释

* **有体物**

   * 有形物，手机、电脑、自行车等。

* **无体物**

   * 电、偷电：撕拉一根电线不经过自己的电表直接用掉，这些电力符合条件也可能构成盗窃罪。

   * 通信信号：蹭别人的 WIFI、蹭别人的流量，消耗的其实是他的财产，完全有可能构成犯罪。

* **虚拟财产**

   * Q 币、游戏装备之类。

* **债权凭证**

   * 购物卡、存折。

* **不动产**

   * 土地、房屋。

   * 敲诈勒索罪甚至可以针对不动产实施，如威胁他人把房子过户给自己。

* **违禁品**

   * 禁止黑吃黑：抢违禁品构成抢劫罪，偷违禁品构成盗窃罪，骗违禁品构成诈骗罪，分别定罪处罚。

* **财产性利益**

   * 拦路抢劫把人打倒在地、逼其把支付宝里的钱转到自己账户，抢劫的不是现金本身，而是他人占有的财产性利益。

   * 把他人占有的财产性利益转移给自己占有，可以构成抢劫罪。

### 财物价值决定保护力度

财物虽然客观上具有经济价值、交换价值，但价值必然有大小之分，价值大小直接决定刑法保护的力度。

```text
        财 物 价 值 由 低 到 高
                    ▲
                    │   数额较大：1000 元以上（诈骗罪要到 3000 元以上）
                    │   → 全部财产犯罪罪名全面保护
                    │
                    │   数额一般：约 200 元
                    │   → 只有四种情形保护：抢劫罪、特殊盗窃、
                    │     特殊抢夺、多次敲诈勒索
                    │
                    │   价值极其低廉 / 无价值
                    │   → 刑法不保护，拿走与不拿走效果一样
                    │
                    └────────────────────────────────────
                       刑法的注意力，止步于此
```

* **数额较大：全面保护**

   * 全部财产犯罪罪名都保护，偷走定盗窃、骗走定诈骗、抢走定抢夺或抢劫、敲诈定敲诈勒索。

   * 数额较大通常指 1000 到 3000 元以上，每个罪有细微区别：盗窃罪一般认为 1000 元以上，诈骗罪要达到 3000 元以上。

* **数额一般：部分保护**

   * 约 200 元左右，刑法意义上仍值得保护，但只有四种情形保护：抢劫罪、特殊盗窃、特殊抢夺、多次敲诈勒索。

* **价值极低：完全不保护**

   * 一张纸、一张名片、一支铅笔，刑法根本不关注。

   * 犯罪要满足形式和实质：形式上具有刑事违法性，实质上具有严重社会危害性，情节显著轻微、危害不大的不认为是犯罪。

* **举轻以明重**

   * 数额一般都保护，数额较大当然更保护。

   * 多次抢夺已经保护了数额一般，多次抢夺数额较大的财物更是重罪中的重罪。

### 法条用语与保护门槛

判断方法就是看法条用语：法条写了"数额较大"的只保护数额较大；法条不写数额限制、只写"多次""入户""扒窃"的，保护的就是数额一般。

| 法条 | 罪名 | 普通情形的门槛 | 不设数额限制的情形 | 保护的财物价值 |
| :--- | :--- | :--- | :--- | :--- |
| 第 263 条 | 抢劫罪 | 无 | 无 | 数额一般即保护 |
| 第 264 条 | 盗窃罪 | 数额较大 | 多次、入户、携带凶器、扒窃 | 普通情形数额较大；特殊情形数额一般 |
| 第 266 条 | 诈骗罪 | 数额较大 | 无 | 数额较大 |
| 第 267 条 | 抢夺罪 | 数额较大 | 多次抢夺 | 数额较大 / 数额一般 |
| 第 270 条 | 侵占罪 | 数额较大 | 无 | 数额较大 |
| 第 271 条 | 职务侵占罪 | 数额较大 | 无 | 数额较大 |
| 第 274 条 | 敲诈勒索罪 | 数额较大 | 多次敲诈勒索 | 数额较大 / 数额一般 |

* **抢劫罪**

   * 法条只写"以暴力、胁迫或者其他方法抢劫公私财物"，没有写"数额较大的公私财物"。

   * 所以抢劫罪保护数额一般的财物，拦路抢劫抢走 200 元也构成抢劫罪既遂。

* **盗窃罪**

   * "盗窃公私财物，数额较大"是普通盗窃，只保护数额较大的财物，偷走桌上的 50 元不构成盗窃罪。

   * 特殊盗窃指多次、入户、携带凶器、扒窃，没有数额较大限制，保护的是财物本身本身即可，200 元左右即可。

   * 公交车上扒窃掏出 200 元也构成盗窃罪既遂。

* **诈骗罪**

   * 法条没有规定特殊诈骗，只保护数额较大的财物，对数额一般的财物实施诈骗不构成本罪。

* **抢夺罪**

   * 普通抢夺保护数额较大；多次抢夺没有数额较大限制，保护数额一般。

   * "多次"指两年以内三次以上，三次各抢 100 元也构成抢夺罪既遂。

* **侵占罪与职务侵占罪**

   * 均为数额较大，没有不设数额限制的情形。

* **敲诈勒索罪**

   * 普通敲诈保护数额较大；多次敲诈勒索没有数额较大限制。

   * 第一次 200、第二次 100、第三次 200 多，合计 500，单看每次都够不上数额较大，构成多次敲诈勒索罪既遂。

### 针对数额较大的财物

* **总立场**

   * 主客观相统一，犯罪客体决定定性，主观罪过优先认定。

   * 一定先考虑主观罪过：主观上只是占个小便宜、根本没有财产犯罪故意的，直接不构成财产犯罪。

* **成立条件**

   * 主观上有取得数额较大以上财物的故意。

   * 客观上有可能取得数额较大以上的财物。

   * 两点主客观相统一，犯罪成立。

* **既遂与未遂**

   * 既遂条件就是一句话：实际取得数额较大的财物。

   * 成立条件与既遂条件是一体的，部分罪名有例外。

```text
  法条写着"数额较大"
          │
          ▼
  主观：有无取得数额较大以上财物的故意？
          │ 有
          ▼
  客观：有无可能取得数额较大以上的财物？
          │ 有
          ▼
  ──► 主客观相统一 ──► 犯罪成立
          │
          ▼
  有无实际取得数额较大以上的财物？
        │ 有           │ 无
        ▼              ▼
       既遂           未遂
```

* **铅笔案**

   * 趁同桌不注意偷走价值两元的铅笔，不构成盗窃罪。

   * 主观上根本没有取得数额较大财物的故意，缺乏犯罪故意，不用再往下分析。

* **天价葡萄案**

   * 农民工翻墙进入农科院摘葡萄，造成直接经济损失约 10 万元，不构成盗窃罪。

   * 不属于入户盗窃：户是供他人生活使用的住所，他进的是单位而不是生活场所，属普通盗窃。

   * 主观上认为这就是普通葡萄，没有取得数额较大以上财物的故意。

   * 客观虽造成重大损失，但主客观不能统一，不能认定为盗窃罪。

* **博物馆金元宝案**

   * 砸开展柜取走一枚标价 30 万元、实为镀金价值 500 元的金元宝。

   * 主观上有取得数额较大以上财物的故意，客观上有可能取得（另外两枚是真的），盗窃罪成立。

   * 没有实际取得数额较大的财物，只能定盗窃罪未遂。

* **电信诈骗案**

   * 电信诈骗指挥老大爷输密码、输验证码，欲骗 500 万元，因家属夺手机而未得逞。

   * 主观有取得数额较大以上财物的故意，客观有可能取得但未实际取得，定诈骗罪未遂。

* **借 500 元案**

   * 虚构事实骗取同学 500 元且不打算归还，不构成犯罪。

   * 法条要求诈骗数额较大的财物，主观上没有取得数额较大以上财物的故意，主客观不能统一，只能行政处罚。

* **明星封口费案**

   * 行为人威胁明星给 100 万封口费，否则公开关系，明星给了钱，构成敲诈勒索罪既遂。

   * 若明星直接报警、行为人未拿到钱，仍构成敲诈勒索罪未遂；数额特别巨大的未遂完全可能。

### 针对数额一般的财物

* **保护范围**

   * 数额一般约 200 元，只有抢劫罪、特殊盗窃、特殊抢夺（多次抢夺）、多次敲诈勒索四种情形保护。

   * 判断原理与数额较大完全一样，只把门槛换成"数额一般"。

```text
  法条只写了"多次""入户""扒窃"……
          │
          ▼
  主观：有无取得数额一般以上财物的故意？
          │ 有
          ▼
  客观：有无可能取得数额一般以上的财物？
          │ 有
          ▼
  ──► 主客观相统一 ──► 犯罪成立
          │
          ▼
  有无实际取得数额一般以上的财物？
        │ 有           │ 无
        ▼              ▼
       既遂           未遂
```

* **拦路抢劫搜出 200 元**

   * 抢劫罪保护的是公私财物，不要求达到数额较大，只要值得保护即可。

   * 主观上多多益善，客观上压制反抗搜身完全可能取得，实际取得 200 元，构成抢劫罪既遂。

* **拦路抢劫搜出身无分文**

   * 未造成轻伤的，成立上主观与客观仍然相统一，但未实际取得，构成抢劫罪未遂。

* **公交扒窃掏出卫生纸**

   * 把手伸进别人口袋属扒窃，是特殊盗窃，只需财物值得保护即可。

   * 主观上多多益善，客观上完全可能取得，扒窃成立。

   * 实际取得的只是一团擦过鼻涕的卫生纸，未取得数额一般以上财物，构成盗窃罪未遂。

* **扒窃得款数额的档次**

   * 卫生纸里包着 200 元的，扒窃既遂，即盗窃罪既遂。

   * 里面只有十元的，十块钱本身不作犯罪评价，但拿走、不拿走都是盗窃罪未遂，因为他主观与客观仍符合数额一般的标准。

* **入户盗窃家徒四壁**

   * 入户盗窃是特殊盗窃，偷一张稿纸回去打草稿用，也构成盗窃罪。

   * 主观有取得数额一般以上财物的故意，客观进入别人家里边有财物再正常不过，犯罪成立。

   * 一个也没有实际取得，构成盗窃罪未遂。

* **入户盗窃提走果篮**

   * 从厨房提走一个大榴莲、几个芒果、几串葡萄，一个榴莲约 200 元。

   * 已实际取得数额一般的财物，构成盗窃罪既遂。

* **入户盗窃只拿牙刷**

   * 卫生间洗漱台上取走一支用旧卷毛的牙刷，价值达不到数额一般。

   * 主观、客观均符合入户盗窃的成立条件，未实际取得数额一般以上财物，构成盗窃罪未遂。

* **抢劫一张餐巾纸**

   * 行为人索要餐巾纸被拒后打倒女大学生并抢走餐巾纸，不构成抢劫罪。

   * 针对的就是这一张餐巾纸，没有取得数额一般以上财物的故意，根本没有侵犯他人财产的故意。

   * 对方在意的是被打倒，打伤人的定故意伤害。

* **偷外卖大爷案**

   * 退休大爷五次趁外卖员上楼时打开外卖箱随机抓取一份，每次约 50 元，合计约 250 元。

   * 两年以内三次以上盗窃成立盗窃罪，每次都能评价为盗窃行为，综合盗窃数额约 250 元值得保护。

   * 赔钱不影响定罪。

* **抠出口中香蕉**

   * 室友睡着时把其口中没咽完的香蕉抠出来吃掉，不构成盗窃罪。

   * 这一根香蕉已被嚼成那个样子，连扒窃所要求的数额一般以上财物都不满足，无从讨论。

## 非法占有目的

### 非法占有目的的构造

* **非法占有目的**

   * > **定义**：取得型财产犯罪的共同主观要件，由排除意思和利用意思两大意思组成。

   * 取得型财产犯罪的共同点就是行为人主观上有非法占有他人财物的目的。

   * 两者兼备才能评价为刑法意义上的非法占有目的。

```text
  取得型财产犯罪的共同主观要件
  ┌──────────────┬──────────────┐
  │   排除意思   │   利用意思   │
  ├──────────────┴──────────────┤
  │  二者兼备：取得型财产犯罪 │
  │  缺一不可：毁弃型财产犯罪   │
  └─────────────────────────────┘
```

### 排除意思

* **含义**

   * > **定义**：排除权利人的占有，将财物转移给自己或者第三人占有。

   * 也就是打破旧占有、建立新占有。

* **程度要求**

   * 排除意思要严重妨害他人对财物的使用。

   * 达到刑事可罚的程度，在刑法上才具有可罚性。

* **使用意思与返还意思**

   * 只有一时使用的意思但没有返还的意思，必然会严重妨害权利人对财物的使用。

   * 有返还的意思但严重妨害了他人对财物的使用，同样成立。

* **摩托车兜风案**

   * 钥匙没插，骑走摩托车兜风 10 分钟又停回原位。

   * 虽然妨害了车主使用，但没有达到"严重妨害"的程度，定不了盗窃罪。

* **偷考研资料案**

   * 偷走他人详细备考笔记，考试结束当天又悄悄送回。

   * 既有排除意思又严重妨害了权利人对资料的使用，又有利用意思，构成盗窃罪。

* **偷车后丢弃案**

   * 偷车开出 20 公里后直接丢弃，虽不要了但有排除意思，开车也是利用意思，构成盗窃罪。

### 利用意思

* **含义**

   * > **定义**：对财物进行使用。

   * 利用要求遵从财物的可能用途进行使用。

* **只要求可能用途**

   * 只要求遵从财物的可能用途使用，不要求按照通常用途使用。

   * 把红木家具全部劈碎抱走当柴火烤火取暖：木头能烤火是可能用途，构成盗窃罪。

   * 偷女生内衣回来挂满四面墙和天花板欣赏：欣赏、观看也是利用，构成盗窃罪。

   * 把同学的书当枕头、垫屁股、垫桌子腿：都是可能用途，构成盗窃罪。

   * 抱走邻居的大电视挂在自己家看整个赛季的世界杯、看完再放回邻居家门口：构成盗窃罪。

* **隐匿的界限**

   * 隐匿、毁坏以外的意思都可以评价为利用意思。

   * 把手机埋在地下 5 米的单纯隐匿与毁坏一样，没有利用意思。

### 仅有排除意思的后果

* **只有排除没有利用**

   * 只有排除意思而没有利用意思的，不构成取得型财产犯罪。

   * 把他人新手机抓起来当场摔碎：有排除意思、无利用意思，定故意毁坏财物罪。

   * 持斧头砍坏他人家具、电视后离去：没有任何使用，定故意毁坏财物罪。

* **夺过手机当场摔碎**

   * 甲伤害乙，乙拿手机报警，甲夺过手机并为防止其报警而当场摔碎。

   * 对手机只有排除意思没有利用意思，不构成抢劫罪，定故意毁坏财物罪。

* **取得型与毁弃型的分界**

   * 取得型财产犯罪与故意毁坏财物罪的关键区别，在于行为人主观上有没有对财物加以利用、加以使用的意思。

   * 缺乏利用意思就缺乏非法占有目的，不能构成取得型财产犯罪，只能构成故意毁坏财物罪或者破坏生产经营罪。
