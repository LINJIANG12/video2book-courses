# 刑法的解释方法

## 刑法解释的定位

* **刑法解释**

    * > **定义**：反过来解释刑法，也就是对刑法条文含义的说明。

    * 刑法解释之所以必要，是因为刑法是通过文字作出规定的，而文字本身可能存在争议，即一词多义。

    * 暴力干涉婚姻自由罪是典型的一词多义：父亲禁止女儿嫁给某人而打了女儿一巴掌，可以评价为本罪中的暴力；而以"你不同意，以后我再也不理你了"相要挟，是否属于本罪中的暴力，实践中会产生争议。

* **定罪的两只手**

    * 左手是案件事实，负责归纳发生了什么；右手是法律规定，负责解读法条本身。

    * 左手归纳出的事实能否满足右手的规定，决定了结论：符合则犯罪成立，不符合则只能得出无罪。

    * 而"是否符合法律规定"这一判断，必然要对法条本身作出解读。

```text
定罪要靠两只手
      │
      ├── 左手：案件事实 —— 归纳发生了什么
      │
      └── 右手：法律规定 —— 解读法条本身
                    │
                    ▼
        左手的事实能否满足右手的规定？
              ┌─────┴─────┐
              ▼           ▼
           符合          不符合
              │           │
              ▼           ▼
          犯罪成立       无罪
```

* **法律人的基本功**

    * 法官写判决书，其实就是在解释法律；检察官发表公诉意见、律师提出辩护意见，也都在对法条本身作说明。

    * 刑法解释要追求的是合理的、公平的结论。

## 解释效力的三分

* **三分标准与框架**

    * 刑法解释按解释效力分为立法解释、司法解释、学理解释。

    * 三者的名称本身即可望文生义：谁作的解释、有什么效力，一目了然。

| 类型 | 作出主体 | 法律效力 | 又称 |
| :--- | :--- | :--- | :--- |
| 立法解释 | 全国人大、全国人大常委会 | 等同于法律 | 有权解释、正式解释 |
| 司法解释 | 最高人民法院、最高人民检察院 | 有法律效力，必须遵守 | 有权解释、正式解释 |
| 学理解释 | 上述机关以外的机关、团体、个人 | 无法律效力 | 无权解释、非正式解释 |

### 立法解释

* **主体与效力**

    * 立法解释是由立法机关对刑法作出的解释，在我国即全国人大和全国人大常委会两者对刑法条文作出的解释。

    * 立法解释不是法律本身，但效力等同于法律。

    * ⚠️ **易错点**：立法解释的主体在我国仅限于全国人大、全国人大常委会，**不包括它们的内部机构和分支机构**。全国人大常委会的内设机构所作的解释，不叫立法解释；立法解释的主体只能是立法机关。

* **三种形式与时间顺序的对应**

    * 三种形式不是随意排列的，是按照法律在时间上的推进顺序对应出来的。

| 时间阶段 | 对应形式 | 例子 |
| :--- | :--- | :--- |
| 起草、修订 | 在起草说明或修订说明中作出的解释 | 1997年刑法，立法机关对九七刑法作出的说明 |
| 通过并生效 | 生效的刑法条文以专条形式解释有关术语 | 第90—98条 |
| 司法适用中出现争议 | 全国人大常委会以决议形式对刑法条文的含义作出说明 | "信用卡"的含义、国家工作人员的含义 |

* **专条解释的常用条文**

| 条文 | 解释的术语 |
| :--- | :--- |
| 第90条 | 民族自治地方刑法适用的变通 |
| 第91条 | 公共财产的范围 |
| 第92条 | 公民私人所有财产的范围 |
| 第93条 | 国家工作人员的范围 |
| 第94条 | 司法工作人员的范围 |
| 第95条 | 重伤 |
| 第96条 | 违反国家规定的含义 |
| 第97条 | 首要分子的范围 |
| 第98条 | 告诉才处理的含义 |

### 司法解释

* **主体与识别**

    * 司法解释是指由最高司法机关作出的解释，在我国即最高人民法院和最高人民检察院。

    * ⚠️ **易错点**：司法解释的主体只能是最高司法机关。识别诀窍在于其规范性文件的名称落脚点是"解释"两个字，例如"……适用法律若干问题的解释"。

* **效力**

    * 司法解释是有法律效力的，必须遵守。

    * 立法解释和司法解释原则上不能冲突；一旦司法解释与立法解释发生冲突，因立法解释效力更高，该司法解释即归于无效。

### 学理解释

* **概念与名称**

    * 学理解释采取反向列举排除的方法得出，即立法解释、司法解释之外的解释，都属于学理解释。

    * 其概念可以表述为：有权进行立法解释、司法解释的机构以外的机关、团体、个人对刑法条文的解释；个人对刑法条文的解释就是学理解释。

    * 立法解释和司法解释有法律效力，称有权解释、正式解释；学理解释无法律效力，称无权解释、非正式解释。

* **价值**

    * 学理解释并不意味着不重要：科学合理的学理解释，对于促进立法解释、司法解释乃至立法活动都有重要意义。

    * 典型情形是某位学者先以学理解释的方式说明了"信用卡"的含义，后来立法机关将其引用入法，它就变成了立法解释。

## 文理解释与论理解释的分工

* **两条分类标准**

    * 按解释效力分，得到立法解释、司法解释和学理解释。

    * 按解释方法分，得到文理解释和论理解释。

```text
刑法解释 —— 解释刑法、解释法条、解释刑法的用语
 │
 ├── 按效力分
 │     ├── 立法解释 ： 立法机关
 │     ├── 司法解释 ： 司法机关
 │     └── 学理解释 ： 无法律效力（又称非正式解释、无权解释）
 │
 └── 按方法分
       ├── 文理解释 ： 按字面含义得出结论（具有优先性）
       └── 论理解释 ： 按立法目的和精神
             ├── 目的解释 ： 考察法条所保护的目的
             ├── 扩大解释 ─┐
             │             ├ 一大一小
             ├── 缩小解释 ─┘
             ├── 历史解释 ─┐
             │             ├ 一横一纵
             └── 比较解释 ─┘
```

### 文理解释

* **定义与依据**

    * "文"就是文字，"理"就是道理；按文字的道理作解释，就是按刑法条文的字面含义作出说明。

    * 文字本身有共性的含义，例如拐卖妇女儿童罪中的"儿童"，解释为包括男童和女童，按字面含义当然成立，这就是文理解释。

* **能力边界**

    * 一旦存在一词多义，仅凭字面含义很难得出正确、合理的结论。

    * 暴力干涉婚姻自由罪中的"暴力"范围太广，既有语言暴力、网络暴力，也有对身体进行击打，字面含义就有多种含义。

* **优先性**

    * 结论：如果根据字面含义没有任何争议，就按文理解释、按字面含义得出结论；一旦存在争议，就需要通过论理解释进行补强。

    * 文理解释具有优先性，原因在于刑法就是通过文字作出规定的。

    * 只有当字面含义给出"唯一答案"时文理解释才收工；一旦字面给不出唯一答案，才轮到论理解释上场补强。

    * 这样的例证很多：抢劫罪"持枪抢劫"的"枪"按字面含义即指真枪，不包括玩具枪，因为假枪根本不是枪；故意杀人罪的"人"按字面含义只能是活人，死人在法律意义上称为尸体；猥亵儿童罪的"儿童"解释为男童和女童，没有任何争议。

    * > **注意**：如果立法者真要在法条后面加括号注明"枪（真枪）""人（活人）"，那立法就成了笑话。

```text
        刑法条文的字面含义
                │
                ▼
  按字面含义解释，结论是唯一的、确定、没有争议吗？
                │
        ┌───────┴───────┐
        ▼               ▼
       是               否
        │               │
        ▼               ▼
       文理解释解决     进入论理解释补强
       不再考察论理     目的 · 扩大/缩小
                        历史 · 比较 · 当然
```

### 论理解释的方法体系

* **定义与角度**

    * 论理解释在本质上就是讲道理的解释，因此它是从字面含义以外的角度讲道理。

| 论理解释的方法 | 它在做什么 |
| :--- | :--- |
| 目的解释 | 看这个罪名到底在保护什么 |
| 扩大解释 | 把刑法用语作大于字面含义的解释 |
| 缩小解释 | 把刑法用语作小于字面含义的解释 |
| 历史解释 | 向上看，看罪名的来龙去脉 |
| 比较解释 | 横向比，看别的国家怎么处理 |
| 当然解释 | 根据事物的逻辑进行推论 |

* **记忆口诀：一大一小，一横一纵**

    * "一大一小"指扩大解释与缩小解释：扩大解释是对刑法用语作出更大范围的理解，也叫大于字面含义的解释；缩小解释是作出小于字面含义的解释。

    * "一纵"指历史解释，向上挖掘罪名的来龙去脉：这个罪名何时开始被立法者关注、被规定为犯罪，此后司法实践有何变化。

    * "一横"指比较解释，把中国刑法与其他国家的刑法作对比，看其他国家对同类情况如何处理、本国能否参照。

    * 当然解释则根据事物的逻辑进行推论。

* **目的解释的地位**

    * 每一个罪名都有自己保护的目的，构成该罪必然是因为相关行为侵害了本罪保护的目的，因此目的解释同样重要。

* **形式解释与实质解释**

    * 文理解释从字面含义角度讲道理，更偏向一种形式解释，从形式、从字面含义出发。

    * 论理解释更偏向从实质上解释，要考虑法条的目的、立法目的和精神。

    * 刑法由此呈现为形式与实质的统一。

* **同义异义**

    * > **定义**：同义异义指同义词语在不同罪名中具有不同含义。

    * 抢劫罪（第263条）与强奸罪（第236条）的法条都写了"暴力、胁迫"，字完全相同、写法完全一样，但两罪中"暴力"的含义并不相同。

    * 抢劫罪中的暴力可以包含直接致人死亡的内容：行为人将被害人砍倒、取走财物，构成抢劫致人死亡，一罪处理。

    * 强奸罪中的暴力不能包含直接致人死亡的内容：行为人先压制反抗实施强奸，中途杀人后又奸淫的，应当以强奸罪、故意杀人罪、侮辱尸体罪数罪并罚。

    * 背后法理是所保护法益的差异，性权利属于人身权、依附于生命权。

| 对比项 | 抢劫罪（第263条） | 强奸罪（第236条） |
| :--- | :--- | :--- |
| 所保护的法益 | 他人的财产权 | 妇女的性权利（人身权） |
| 暴力能否包含致人死亡 | 能 | 不能 |
| 杀人之后的评价 | 抢劫致人死亡，一罪 | 强奸罪＋故意杀人罪＋侮辱尸体罪，数罪并罚 |

## 目的解释

* **定义与运行方式**

    * > **定义**：目的解释指根据刑法条文、也就是刑法规范的目的进行解释；要求行为有可能侵害该罪所保护的目的，否则罪名不成立。

    * 强奸罪保护的是妇女的性自主权，因此张三强奸男性李四，不可能被认定为强奸罪，因为其行为不可能侵害强奸罪所保护的利益。

* **盗伐林木罪的推导**

    * 盗伐林木罪位于刑法分则第六章"妨害社会管理秩序罪"之下第六节"破坏环境资源保护罪"，第345条规定盗伐森林或者其他林木数量较大的，处三年以下……

    * 由章节位置可知这一节之下的罪名都和环境保护有关，涉及国家的环境资源。

    * 结论：张三趁李四不备偷走李四已经伐倒的树，不构成盗伐林木罪，因为本罪保护的是国家的森林资源，而该行为只是单纯侵害他人的财产权，只能构成盗窃罪。

* **非法经营罪的玉米案**

    * 最高人民法院第97号指导性案例具有法律效力，案情发生在内蒙古。

    * 王立军是农民，农闲时从农民手中收购玉米再转手卖给国有粮库，在政府指导价以内收、指导价以内卖，被当地法院一审认定为非法经营罪，理由是玉米关乎国计民生、擅自收购扰乱市场秩序情节严重。

    * 该罪位于刑法分则第三章第八节"扰乱市场秩序罪"，第225条要求"违反国家规定"实施非法经营行为之一、扰乱市场秩序情节严重。

    * 再审的判决理由指出：非法经营罪目的在于保护市场经济秩序，王立军的行为并非通常意义的囤积居奇，没有破坏市场交易秩序，没有侵害本罪所保护的法益，不能被认定为犯罪。

* **论理解释的补强顺序**

    * 当文理解释对具体案件的推理产生争议时，必须通过论理解释补强，而补强的第一步就是目的解释。

    * 如果本罪保护的目的不可能被某个行为所侵害，该行为就不能构成这个罪名。

## 刑法的目的：三种观点

* **主观解释论**

    * 该论认为刑法解释的目的是探求立法者立法时的意图。

    * 弊端在于立法者难以预见后来的技术发展：1997年刑事立法时电脑尚未普及，立法者不可能预见到有人花钱去买游戏中的皮肤。

    * 只单纯探求立法者立法时的意图，类似于刻舟求剑。

* **客观解释论**

    * 该论认为刑法解释的目的是发现或者适应社会发展的需要，即司法实践在变化，刑法条文要适应司法实践的变化。

    * 据此，游戏的皮肤、装备、武器等可能具有财产价值，也可以解释为财物。

    * > **注意**：一般而言客观解释较为稳妥，考试分析更赞同客观解释论的立场。

* **折中解释论**

    * 该论居于前两者之间，认为刑法解释要兼顾阐明立法者的立法意图与社会的客观需要。

## 李宁案：解释方法的综合运用

* **案情要点**

    * 李宁是男子，在南京电线杆上张贴广告招聘"男公关"，条件可用16个字概括：肤白貌美、体型健硕、谈吐儒雅、善于沟通，待遇也很好。

    * 培训前期讲孔孟之道，中期李宁先鼓励学员再宣布招他们不是做公关，结业典礼上又说明不是为女性提供性服务，导致部分学员迎难而上。

    * 由此形成的事实是：李宁组织一批男子，向不特定多数男子提供有偿性服务。

    * 南京市秦淮区公安机关以涉嫌组织卖淫罪立案侦查并报请批准逮捕，检察机关以刑法规定的组织卖淫罪指组织女性为男性提供有偿性服务、本案组织男子对男子提供有偿性服务、法无明文规定不为罪为由不批捕，公安机关不服，双方争议一路报至全国人大常委会法制工作委员会。

* **文理解释的三个术语**

    * 第358条规定组织卖淫罪、强迫卖淫罪，属选择罪名，与组织卖淫罪有关的就六个字：组织、他人、卖淫。

    * "组织"：李宁把一批年轻帅气的小伙子聚在一起培训、安排上岗，且对他们有管理、有控制、有一定的纪律性，符合"组织"。

    * "他人"：从字面含义看，自己以外的都是他人，李宁以外的小伙子当然是他人。

    * "卖淫"：男对男是否属于卖淫确实有争议，若属于则字面含义即可解决本案。

* **卖淫的层次**

    * "卖淫"有广义与狭义之分，也有刑法意义上的卖淫与行政法意义上的卖淫之分。

    * 组织女性为不特定男性提供手淫服务是否构成组织卖淫罪，历来争议很大，南方判例较多，判决并不统一：有的法院定罪判刑，有的法院宣告无罪。

    * 行政法意义上的卖淫范围很大，组织女性提供手淫服务属于行政法意义上的卖淫，可以给予行政处罚。

    * 刑法意义上的卖淫只能是最狭义的。

    * 刑法意义上的卖淫只能是**进入式**的卖淫嫖娼，不能是接触式的卖淫嫖娼。

* **论理解释的补强**

    * 目的解释：组织卖淫罪保护良好的社会风尚。社会风尚是在一定时期内广大公民坚持和追求的、体现主流价值取向的道德规范。组织女性为男性提供有偿服务会侵害良好社会风尚，组织男子为男子提供有偿服务同样会侵害。

    * 扩大解释：老百姓通常理解的卖淫是女性对男性提供有偿服务，把男对男也解释为卖淫，扩大了"卖淫"的含义，但仍能被接受。

    * 判断规则：老百姓想一下说"我能接受"，通常就是扩大解释；不管怎么想都接受不了，那就是类推。

    * 佐证：老百姓把女性提供有偿性服务称为"鸡"，把男性提供有偿性服务称为"鸭"，chicken 与 duck 在心目中都是卖淫。

    * 历史解释：从1979年刑法的组织卖淫到现行刑法的组织卖淫，当时的观念没有那么开放、多元，卖淫通常表现为女性对男性，男对男很少；向上看来龙去脉，结合司法实践的客观变化，男对男解释为卖淫能够解释得通。

    * 比较解释：韩国、德国、日本、法国、英国、美国的卖淫都包含男对男。

* **结论**

    * 综合文理解释与目的解释、扩大解释、历史解释、比较解释，李宁构成组织卖淫罪。

    * 为了论证得出一个结论，理由越多，论证越充分。

## 扩大解释

* **定义与操作对象**

    * > **定义**：扩大解释又称扩张解释，指对刑法用语作大于字面含义的解释。

    * 解释的对象是刑法用语、刑法法条中的文字，而不是对整部刑法的解释。

* **抢劫银行的例子**

    * 第263条抢劫罪规定有"抢劫银行"，像名词解释一样需要说明其含义。

    * 字面意义上的抢劫银行，是抢劫大街上银行营业网点，这属于文理解释。

    * 抢劫送钱取钱的运钞车、取走其中现金，也认定为抢劫银行，其范围比字面含义大，属于扩大解释。

    * 之所以不是类推：抢劫银行抢的是银行资金，抢劫银行正在使用中的运钞车抢的也是银行资金，最终指向的对象统一，社会危害性一致，因而能被接受。

* **判断规则**

    * 刑法解释解释的是法条文字，因此关键看解释以后能够适用该法条的人是变多了还是变少了。

    * 大和小的参照物就是字面含义，也就是文理解释。

| 解释之后适用人群 | 对应的解释类型 |
| :--- | :--- |
| 变多了 | 扩大解释（大于字面含义） |
| 变少了 | 缩小解释（小于字面含义） |
| 不多不少 | 文理解释（就是字面含义） |
| 打得很离谱、接受不了 | 类推解释（指鹿为马） |

```text
        解释之后，适用这个法条的人是……
                    │
        ┌───────────┼───────────┐
        ▼           ▼           ▼
      变多了       变少了      不多不少
        │           │           │
        ▼           ▼           ▼
     扩大解释     缩小解释    文理解释
   （大于字面） （小于字面）  （就是字面）
        │
        │  大得很离谱，怎么想都接受不了
        ▼
   类推解释 —— 指鹿为马
```

* **常考例证**

    * "审判的时候怀孕的妇女不适用死刑"中的"审判的时候"，解释为包括侦查、起诉时怀孕的妇女，适用人群变多；侦查、起诉都是为了审判、是为审判做准备，这同时也是司法解释的规定。

    * 破坏交通工具罪中的"汽车"，解释为包括从事交通运输的大型拖拉机；大型拖拉机与汽车的原理、驱动方式一致，上路从事运输时破坏的同样是公共安全。

    * 第196条信用卡诈骗罪中的"信用卡"，立法解释把普通银行借记卡也解释为信用卡，指由商业银行或者金融机构发行的、具有转账支付、存取现金、信用贷款、消费透支等全部功能或者部分功能的电子支付卡；有部分功能即可，范围明显变大。

    * 拐卖儿童罪中的"儿童"解释为既包括男童又包括女童，构成该罪的人不变多也不变少，既未扩大也未缩小，属于文理解释。

## 缩小解释

* **定义与操作方式**

    * 缩小解释与扩大解释相对，指对刑法条文的含义进行限缩、限制，缩小到它最核心的含义。

    * 操作方式相当于在刑法用语前面加上一个定语，定语越多，范围越小。

* **为境外窃取情报罪**

    * 第111条规定为境外窃取、刺探、收买、非法提供国家秘密、情报罪，本罪属于危害国家安全的犯罪。

    * "情报"种类很多，如商业情报、国家安全情报、娱乐情报、社会情报，但本罪既然属于危害国家安全的犯罪，"情报"就一定要求与国家安全有关系。

    * 若为境外窃取的是娱乐情报，行为不可能危害国家安全，因此应把"情报"解释为"关系国家安全和利益，尚未公开或者依照有关规定不应公开的事项"。

    * 这样处理后构成该罪的人变少，属于缩小解释。

* **共同犯罪中的"人"**

    * 第25条规定共同犯罪是指二人以上共同故意犯罪，字面上所有人都是"人"。

    * 依我国刑法理论及现行规定，这里的"人"必须具有刑事责任能力，这要求精神正常且达到特定年龄。

    * 在"人"前面加上"具有刑事责任的"这一限定，意味着并非所有人都有资格成为共同犯罪人，构成该罪的人变少，属于缩小解释。

## 类推解释

* **定义与禁止**

    * "类"是类似，"推"是推理；类推解释指在刑法没有明文规定的情况下，比照最相类似的条文进行推理、适用。

    * 类推解释是典型的违法：法律没有把某行为规定为犯罪，立法者没有将其规定为犯罪，通过解释按犯罪处理就违背了立法原意。

    * ⚠️ **易错点**：立法机关与司法机关也不能进行类推解释，因为类推解释本身是违法的。

    * > **注意**：教材在此处附有脚注称有利于被告人的类推可以允许，这一点留到罪刑法定原则部分再讲。

* **并列关系是红线**

    * 结论：并列关系是类推。

    * 男女是并列关系，有共同的上位概念"人"，男与女共同组成人的全部，因此将男解释为女、将女解释为男都是类推。

    * 人体与尸体同样是并列关系，人体一定是活着的，尸体一定是已经死亡的，所以不能把尸体器官解释为人体器官；刑法规定了组织出卖人体器官罪而未规定组织出卖尸体器官，实践中出现摘取去世者器官贩卖的情形，不能类推适用。

    * 选择罪名是明文列举的并列关系：引诱、容留、介绍卖淫罪有三个并列的动词，引诱、容留、介绍之间不得相互解释；走私、贩卖、运输、制造物品罪有四个并列的动词，不能以"运输的目的是为了贩卖"为由将运输解释为贩卖，否则运输罪就被架空、被废掉了。

* **飞船票的偷换概念**

    * 刑法只规定了倒卖船票罪，没有规定倒卖飞机票罪，而倒卖飞机票的社会危害性通常更大。

    * 有学生提出论证：飞机在天上飞时看起来很小、像飞船，飞船票就是船票，所以倒卖飞机票可以定倒卖船票罪。

    * 该论证是典型的偷换概念：像飞船并不等于就是飞船，即使它是飞船，飞在天上的飞船也不是船；飞机与船是并列关系的交通工具，不得相互解释。

    * > **结论**：只要 A 与 B 之间存在并列关系，就不要犹豫，肯定是类推。

## 扩大解释与类推解释的边界

* **吹气球的比喻**

    * 吹气球越吹越大，只要不爆炸它依然是气球；再吹一气就炸了，炸过之后那就不再是气球。

    * 扩大解释与类推解释的界限就是那个爆炸的边缘：爆炸之前不管多大都是气球，爆炸以后再说是气球就是类推。

* **举例辨析**

    * 醉酒驾驶机动车构成危险驾驶罪，那么醉酒驾驶飞机能否构成危险驾驶罪？将飞机解释为机动车，而飞机与机动车是并列关系，属于类推。

    * 拐卖儿童罪中"偷盗婴幼儿"，解释为以欺骗、利诱等手段使婴幼儿脱离监护人、看护人，可以解释得进去，一般认为是扩大解释。

    * 高空抛物罪的法定表述是"故意从建筑物或者其他高空抛掷物品，情节严重的"，关键字是"抛掷"和"物品"。

    * ⚠️ **易错点**：甲将乙从十楼推下致乙被摔死，仅构成故意杀人罪，不构成高空抛物罪。把人解释为物，不管怎么想都接受不了，属于把马蜂当物的胡扯八道与指鹿为马，构成高空抛物罪的人的确变多了，但变到爆炸边缘之外。

    * 对照之下，将狗解释为"物品"则没问题，可以构成高空抛物罪。

* **两条可靠判据**

    * 判据一是关系：看 A 与 B 之间有没有并列成分，有并列关系就不能相互解释。

    * 判据二是接受度：想一想还能接受的是扩大解释，怎么想都接受不了的是类推解释。

    * 把男对男解释为卖淫是想一想能接受的扩大解释；把男解释为女则一想就接受不了，强行解释就是胡扯八道。

## 当然解释

### 定义与逻辑基础

* **定义**

    * > **定义**：当然解释指刑法虽然没有明文规定，但该行为的含义其实已经包含在法律条文之中，按理所当然的方式对刑法条文作出解释。

    * 老百姓天天挂在嘴边的"理所当然""不言自明"就是当然解释的通俗形态。

* **生活里的当然解释**

    * 公园牌子上写着"禁止采摘花朵"，连根刨起把整束花带走同样违反规定——摘一朵都违反，连根刨走更违反。

    * 道路交通安全法规定骑自行车后排不能带一个成年人，带成年人违规可被警告或罚款；那么李四不坐后座而是站在后座上、双手扶着张三肩膀如巡游一般，比坐一个成年人更危险，更应当处罚。

* **"当然"的两层含义**

    * 第一层是生活中的当然，如"我当然会好好学习""马蜂当然是一个好人"，不属于当然解释。

    * 第二层是逻辑上的当然，要求存在轻与重的对比，举轻以明重、举重以明轻。

    * > **注意**：当然解释的"当然"指法律逻辑意义上的当然，务必要与生活中的当然区分开。

* **解释后的含义是否合乎道理**

    * 当然解释是根据逻辑来论证，解释后的含义要符合当然的道理。

### 适用前提

* **前提一：法律没有明文规定**

    * 当然解释适用的前提是法律没有直接规定、没有明文规定；如果法律有明文规定，就只能按照规定处理。

    * 刑法明文规定了故意杀人罪和故意伤害罪，不能因为伤害都构成故意伤害罪，就推导出杀害他人也按故意伤害罪处理——那会使故意杀人罪被架空、被废除。

    * 同时，没有明文规定并不意味着该行为的含义已经包含在法律条文之中，这正是当然解释可以展开的前提。

* **前提二：性质相同、程度不同**

    * 举轻以明重、举重以明轻要求对比具有可比性，性质不同就无法对比。

    * 不能因为盗窃都构成犯罪就推导出强奸更构成犯罪。

    * 张三打倒小花抢走狗，可以把狗解释为财物，构成抢劫罪；但第二天张三抢走小花三岁的孩子，若以"抢狗都能定抢劫、抢孩子更要定抢劫"推导，就是拿人和财物作对比，性质完全不同，对比不了。

    * 多次盗窃经司法解释明确为两年以内三次以上盗窃，那么两年以内盗窃四次、一年以内盗窃三次当然也都是多次盗窃。

* **规则总览**

    * 适用前提是法律没有明文规定、对比事项性质相同而程度不同；在两者满足的基础上，适用规则只有两条：入罪时举轻以明重，出罪时举重以明轻。

### 入罪时举轻以明重

* **规则内容**

    * 在论证构成犯罪、论证入罪时举轻以明重：社会危害性轻的行为都构成犯罪，社会危害性重的行为理应构成犯罪。

    * 打一拳都构成犯罪，打一拳再加踢两脚就更构成犯罪。

* **文物与国有档案的例子**

    * 文物分为一级、二级、三级，一级最珍贵；故意损毁二级文物即构成故意损毁文物罪，故意损毁一级文物更应认定为故意损毁文物罪。

    * 刑法规定了抢夺国有档案罪而未规定抢劫国有档案罪。单纯一把夺走国有档案当然构成抢夺国有档案罪；若先将工作人员打倒在地再劫走几份国有档案，按无罪处理显然不合适。

    * 关键看能否将抢劫国有档案的行为解释到抢夺国有档案罪中去，能被抢夺国有档案所包含就可以定罪。

* **A 与 A＋B 的包含关系**

    * 抢夺是一把夺走，抢劫是压制反抗然后取走；抢夺是 A，抢劫是 A＋B。

```text
   抢夺  =  A
   ┌──────────────────────────┐
   │  A   一把夺走：取走财物  │
   └──────────────────────────┘

   抢劫  =  A + B
   ┌──────────────────────────┐
   │  A   取走财物            │
   ├──────────────────────────┤
   │  B   打倒、压制反抗      │
   └──────────────────────────┘
```

* **三个条件的核对**

    * 法律没有明文规定：没有直接规定抢劫国有档案罪，只是满足了前提。

    * 性质相同、程度不同：都是针对国有档案的侵犯，只是一个是夺，一个是打倒、压制反抗、取走。

    * 入罪时举轻以明重：单纯的抢夺行为都能构成抢夺国有档案罪，打倒的抢劫行为自然更能构成。

* **结论**

    * A 能构成这个罪，A＋B 包含 A 的全部内容，因而更能构成这个罪，这就是入罪时举轻以明重。

### 出罪时举重以明轻

* **规则内容**

    * 在排除犯罪、出罪时举重以明轻：社会危害性重的行为都不构成犯罪，轻的行为更不构成犯罪。

* **抢劫近亲属财物**

    * 司法解释规定，抢劫近亲属的财物数额不大、未造成严重后果的，不定抢劫罪。

    * 同样是数额不大、同样未造成严重后果，儿子盗窃老子的财物比抢劫更轻，因此更不应定罪。

* **索取赌债**

    * 司法解释规定以索取赌债为对象实施抢劫的不构成抢劫罪。

    * 赌博不受法律保护，所欠的赌债属于非法债务，连非法债务都不构成抢劫罪，抢劫合法债务就更不构成抢劫罪。

* **因被勒索给予财物**

    * 第389条第三款规定，因被勒索给予国家工作人员财物、没有获取不当利益的，不构成行贿。

    * 该情形须同时满足被勒索、没有获得不当利益两个条件才不定罪，且立法对此有明文规定。

    * 第164条对非国家工作人员行贿罪没有类似规定。

    * 因此因被勒索给予非国家工作人员财物、没有获得不正当利益的也应当无罪：两个前提完全相同，而给国家工作人员送钱的社会危害性明显更大，重者都不定罪，轻者更不应定罪。

### 没有明文规定为何仍能定罪

* **成立犯罪的两个统一**

    * 任何一个犯罪都是两个统一：形式与实质的统一、主观与客观的统一，少一个都不行。

    * > **结论**：成立犯罪要同时满足主观与客观统一、形式与实质统一，这是学习犯罪论的底层逻辑。

* **形式与实质的统一**

    * 第13条规定了犯罪的定义，其中"以及其他危害社会的行为""依照法律"是最核心的内容。

    * "依照法律"指形式上要有法律规定，法律没有规定的就不能定罪。

    * "危害社会的行为"指实质上该行为要具有社会危害性；杀人、放火、强奸、抢劫会侵害他人利益、有严重社会危害性，故被规定为犯罪，吃饭睡觉旅游是纯粹的生活行为，不会侵害任何利益，故不可能被规定为犯罪。

    * 抢劫罪即为一例：实质上具有严重社会危害性，形式上第263条有明文规定。

* **主观与客观的统一**

    * 主观上要有犯罪的故意和过失，只有主观没有客观不能定罪——思想是无罪的，思想本身不会侵害他人利益。

    * 客观上要实施特定的严重危害社会的行为，只有客观没有主观同样不合适：正常行车时有人从天桥跳下落在车头被撞死，客观上似乎撞死了人，但驾驶人没有故意也没有过失，属于意外事件。

* **没有明文规定不等于没有法律依据**

    * 当然解释对比的是社会危害性，从实质角度出发；而成立犯罪还要看形式上有没有明文规定，二者表面上似乎矛盾。

    * 第一种可能是：法律没有明文规定、直接规定，并不意味着该行为没有法律依据。

    * 西方国家有立法规定了遗婴罪，我国刑法没有规定遗婴罪；北京曾出现遗婴案，辩护律师以我国刑法没有规定遗婴罪、法无明文规定不为罪作无罪辩护。

    * 问题在于我国刑法规定了故意杀人罪，可以将溺死婴儿的行为评价为故意杀人；婴儿当然是人，因此该行为能解释到已有罪名中去，仍然是有法律依据的，既满足实质也满足形式。

    * 结论：法律虽无明文规定，但并不意味着行为不能解释到其他罪名中去；能解释进去的，仍有法律依据，解释不进去的，最终不能定罪。

* **能否解释进已有罪名**

    * 倒卖飞机票具有严重社会危害性，但能将飞机票解释为船票吗？解释不进去，因此不能定倒卖船票罪。它仅满足犯罪的实质，不满足形式：立法上没有直接规定倒卖飞机票罪，也不能解释到倒卖船票罪，强行解释就变成类推。

    * 抢劫国有档案没有直接规定的罪名，但可以解释到抢夺国有档案罪中去，因为 A＋B 包含 A，因此最终可以定抢夺国有档案罪。

```text
刑法没有直接规定重行为
           │
           ▼
能否解释进已有的罪名？
           │
           ├── 能解释进去 ──► 取得法律依据，形式与实质统一，可以定罪
           │  （A + B 包含 A：抢劫 ⊃ 抢夺）
           │
           └── 解释不进去 ──► 强行解释即类推，不能定罪
                              （马蜂不是"东西"：马蜂 ⊄ 物品）
```

* **毒驾不能定罪的原因**

    * 第133条之一危险驾驶罪列举的情形中只有醉酒驾驶机动车，没有毒驾。

    * 单纯的毒驾既没撞人也没有严重超速，被交警查获，目前定不了罪。

    * 要定罪就得定危险驾驶罪，但毒驾不是追逐竞驶、不是从事校车业务、不是违反危险化学品安全管理规定；将毒驾解释为醉驾也解释不进去，醉酒显然不等于刚吸过毒。

    * 司法实践调研显示，是否将毒驾规定为危险驾驶罪的行为之一至今未被立法机关采纳，理由之一是醉驾常见且案发率高，而刚吸过毒的人一般不会再开车，毒驾案发率太低。

* **三句话小结**

    * 第一句，法律没有直接规定；法律有直接规定的就按规定处理，杀人归杀人、伤害归伤害。

    * 第二句，在法律没有明文规定的前提下，入罪时举轻以明重，出罪时举重以明轻；既然要比较轻重，就要求性质相同、程度不同，财物之间可以比价值大小，人与财物之间不能比。

    * 第三句，具体怎么比：入罪时社会危害性轻的行为要定罪、重的行为更应该定罪，但只是"应该"定罪，最终能否定罪还要看能否解释到其他罪名中去；出罪时重的行为都不构成犯罪、轻的行为更不构成犯罪。

## 比较解释与历史解释

* **比较解释**

    * > **定义**：比较解释指根据域外，即中国大陆以外的刑事立法、判例作为参考，阐述本国刑法规定的含义。

    * 李宁案中参照比较解释，查文献发现其他国家男对男都可以解释为卖淫，我国刑法也可以。

    * 谈到盗窃罪，中国本土观点一般认为盗窃罪是秘密窃取他人财物，但不少国家、地区认为公开也能构成盗窃，遂有学者以他国公开窃取可构成盗窃为参照主张我国也应如此，这就是比较解释。

    * > **注意**：公开窃取在研究生考试中没有被采纳。

* **历史解释**

    * > **定义**：历史解释指从历史发展的眼光、从历史严谨的角度，为解释的结论提供合理性。

    * 1979年刑法规定了流氓罪，1997年刑法对流氓罪进行分解，分解出四个罪名，其中包括聚众斗殴罪、寻衅滋事罪、强制猥亵侮辱罪。

    * 据此有人主张构成强制猥亵侮辱罪要求行为人主观上具有流氓动机，理由就是这个罪是从流氓罪中分解出来的。

    * 认定李宁构成组织卖淫罪时也考察了历史解释：从1979年刑法到1997年刑法，组织卖淫罪的司法实践与人的观念出现了新变化。

* **与文理解释的配合**

    * 碰到刑法解释题，先想到的解题规则是看解释以后适用人群变多还是变少，再考虑论理解释各方法能否补强。

## 真题应用

* **题面**

    * 某刑法教科书提出"盗窃行为并不限于秘密窃取"，这种属于何种解释？

* **选项辨析**

    * 教科书提出的解释显然不是立法解释、司法解释，因此属于学理解释，又称无权解释、非正式解释。

    * 属于文理解释吗？法条规定的是"盗窃公私财物，数额较大"，按字面含义得不出"盗窃行为并不限于秘密窃取"，所以不能选。

    * 属于类推吗？类推是法律没有明文规定时比照最相类似的条文进行推理适用，而该主张并没有比照最相近的条文进行推理，所以与类推无关。

    * 它属于论理解释，具体是其中的比较解释，即参照国外的立法判例来阐述本国刑法的含义。

* **答案**

    * ① 学理解释　④ 比较解释。
