# 犯罪故意、犯罪过失与无罪过事件

## 犯罪主观方面

* **犯罪主观方面**

    * > **定义**：犯罪主体对其实施的危害行为及其造成的危害结果所持有的心理态度，是追究行为人刑事责任的主观基础。

    * 圈定对象只有两项：危害行为、危害结果。既含对行为的心理态度，也含对结果的心理态度。

    * 四大心理因素：犯罪故意、犯罪过失、犯罪目的、犯罪动机。

    * 故意和过失是任何罪名成立都必须具备的，犯罪目的只是特定犯罪的必备要素，犯罪动机通常只影响量刑。

    * 特征一：是支配行为人实施危害行为的心理状态，与危害行为的"意识性"一致——行为是意识支配的产物。

    * 特征二：由于概念限定在对行为和对结果，故主观方面表现为对结果的心理状态。

    * 特征三：是刑法明文规定的内容。

    * 特征四：是一切犯罪的必备要件，犯罪构成四要件少一个都不行。

    * > **易错点**：不能说"犯罪动机不是任何犯罪的构成要件"，个别犯罪确实要求具备特定动机，如徇私枉法罪的"徇私、徇情"。

* **罪过**

    * > **定义**：犯罪故意与犯罪过失的统称。

    * 与日常语义中的"罪过""罪责"不同，刑法上的罪过专指故意与过失两种心理状态。

    * 主观恶性程度：犯罪故意深于犯罪过失，这是故意与过失分流刑责轻重的根据。

* **犯罪目的**

    * 典型立法例：绑架罪以勒索财为目的，拐卖妇女儿童罪以出卖为目的。

* **犯罪动机**

    * 极少数犯罪中有所要求，出现的主要作用是影响量刑。

### 三大板块

* 正面：满足什么条件才算符合主观方面的要求。
* 反面：不满足主观方面要求的情形，最终都是无罪。
* 关联面：主观方面所关联的两大认识错误，即法律性错误与事实性错误。

## 主观责任原则与结果责任

* **主观责任原则**

    * > **定义**：承担刑事责任必须满足主观上的要求，行为人对自己的危害行为必须具有罪过，即主观上具有故意或过失。

    * 我国刑法认定犯罪坚持的基本立场。

* **结果责任**

    * > **定义**：只要造成危害结果，不论行为人主观上有无故意、有无过失都追究刑事责任，即客观归罪。

    * 我国刑法坚决摒弃。

    * 例：父母带孩子和朋友到浴室休息，客观上确属猥亵儿童，但主观上无猥亵故意，不成立猥亵儿童罪。

## 主客观相统一

* **主客观相统一**

    * > **定义**：认定犯罪时既不能主观入罪，也不能客观归罪；主观方面（故意或过失）必须对客观方面的内容有所认识。

* **罪过与犯罪行为的同时性**

    * > **定义**：有没有犯罪故意、有没有犯罪过失，必须站在行为时的立场判断，行为与罪过一般同时存在。

    * 事后产生的念头不能倒推为犯罪时的故意：张三驾车撞伤李四后天天焚香祷告盼其死亡，仍只成立过失犯罪，不成立故意杀人罪。

    * > **提示**：做刑法题目时题目怎么说就怎么想，不要加戏地怀疑题干信息的真实性。题干给的信息都是证据已经证成的信息，"他是不是在狡辩"不是实体法要解决的问题。

* **行为与责任同时存在**

    * 责任侧共六项内容，要求行为与之同时存在：刑事责任年龄、精神状况、犯罪故意、犯罪过失、犯罪目的、犯罪动机。

    * 刑事责任年龄以行为时为准，犯罪之后再患病不影响已成立的责任。

    * 精神状况是否异常以犯罪时为准：精神正常时犯罪、犯罪后发病的，仍要承担刑事责任。

    * 例：张三把熟睡的孪生妻妹当成妻子发生性关系，无强奸故意，不构成强奸罪。

## 主客观相统一原则在立法中的体现

| 条文 | 内容 | 体现的主客观相统一 |
| :--- | :--- | :--- |
| 刑法第14条、第15条 | 故意犯罪、过失犯罪 | 成立犯罪要么有故意要么有过失，主观罪过是犯罪必备要件 |
| 刑法第16条 | 客观上造成损害结果但不是出于故意和过失的，不负刑事责任 | 满足客观不满足主观，最终不是犯罪，禁止客观归罪 |
| 刑法第18条 | 精神病人在不能辨认或不能控制自己行为时造成危害结果，经法定程序鉴定确认的，不负刑事责任 | 无故意无过失，自然不能追究刑责 |
| 刑法第20条 | 正当防卫 | 行为本身无社会危害性，主观目的也无犯罪故意或过失，目的是保护正当权利 |
| 刑法第21条 | 紧急避险 | 原理与正当防卫相同 |
| 刑法第22～24条 | 犯罪预备、犯罪未遂、犯罪中止 | 都要求客观上有相应举动，排除犯意表示的犯罪，我国刑法不惩罚思想犯 |

* **思想犯的排除**

    * 刑法第22条犯罪预备要求"为了犯罪准备工具、制造条件"，客观上必须有相应举动，单纯的犯意、犯罪思想不构成犯罪。

* **分则中的主客观相统一**

    * 拐卖妇女、儿童罪：以出卖为目的偷盗婴幼儿的，以出卖为目的使用暴力、胁迫或者麻醉方法绑架妇女、儿童的，处十年以上有期徒刑或者无期徒刑。

    * "以出卖为目的"即对主观方面的描述，成立本罪要求主观上以出卖为目的。

## 罪过的法条结构

```text
                 罪过（犯罪故意 / 犯罪过失）
                            │
              ┌─────────────┴─────────────┐
              │                           │
          认识因素                      意志因素
    明知自己的行为会发生             希望结果发生
      危害社会的结果                     │
    （明知行为 + 明知结果        直接故意：明知必然或可能 + 希望
      + 明知结果的危害性）      间接故意：明知可能 + 放任
```

* **犯罪故意（criminal intent）**

    * > **定义**：明知自己的行为会发生危害社会的结果，并且希望或者放任这种结果发生的心理态度（刑法第14条）。

    * 结构由认识因素与意志因素两部分组成。

    * 认识因素：明知自己的行为会发生危害社会的结果，要求达到"明知"的程度。

    * 意志因素：希望或者放任这种结果发生的行为态度。

    * 认识因素再拆为三层：明知行为、明知结果、明知结果具有危害社会的性质。

    * 立法立场：以惩罚故意犯罪为原则，只要构成故意犯罪就应当负刑事责任。

* **结果责任的排除**

    * 主观方面是行为的动力来源，行为的"意识性"有两层含义：它是意识支配的产物，也是意识的表现——能证明行为人的主观意识。

## 生活中的故意与刑法上的故意

| | 生活中的故意 | 刑法中的故意 |
| :--- | :--- | :--- |
| 指向 | 对"行为"的描述，干这件事是故意还是过失 | 对"行为+结果"的描述，侧重对"结果"本身的态度 |
| 判断 | 行为人是有意这么干的 | 对结果是积极追求，还是听之任之 |
| 例子 | 渴了喝水、困了睡觉；看见红灯还闯；点火照亮油箱 | 明知自己的行为会发生危害结果，并且希望或放任这种结果发生 |

* **例：闯红灯**

    * 张三看到红灯仍一加油闯过去，撞死了一个人。闯红灯在生活中是有意为之，但对死亡结果后悔、反对，成立过失犯罪。

* **例：点火照亮油箱**

    * 工厂停电，工人拧开汽油发电机油箱盖想看有没有油，黑灯瞎火便点燃打火机照亮，汽油遇火瞬间燃烧爆炸。点火在生活中是有意为之，但对爆炸结果不希望发生，仍是过失。

* **例：正当防卫**

    * 甲为制止持刀歹徒的追杀，在搏斗中将其打成重伤。生活中是故意打伤，但刑法上是正当防卫，因为他只想保护正当权利，不具有犯罪故意。

* **例：假想防卫**

    * 晨跑时有人一直紧跟、动作姿势像要出手，一转身将其打成重伤。客观上不存在不法侵害，行为人误认为有。

    * 行为人主观目的是保护正当权利，认为自己的行为是合法的好行为，不明知其社会危害性，故没有犯罪故意。

## 犯罪故意与故意犯罪

* **犯罪故意**

    * 只是犯罪主观方面这一个要件的内容。

* **故意犯罪**

    * 主客观相统一的结论，既满足客观也满足主观。

    * 构成故意犯罪必然要有犯罪故意；有犯罪故意未必构成故意犯罪——主观上产生了杀人故意但客观上没有任何行为，仍然无罪。

## 认识因素：主客观相统一要求认识什么

* **认识范围的总规则**

    * > **结论**：凡属于某罪客观方面的内容，原则上要求主观上有所认识；客观方面以外的要素不要求行为人有认识。

    * 犯罪构成四要件中，客观方面的具体内容有五个点：危害行为、犯罪对象、危害结果、因果关系、时间地点方法。

    * 犯罪主体与客观方面是并列的两个要件，犯罪主体不在客观方面之内。

    * 例：受贿罪中"国家工作人员"属于犯罪主体，不属于客观方面，故不要求行为人认识到自己是国家工作人员。

* **不要求认识违法性**

    * 只要求认识到行为具有社会危害性，不要求认识到自己的行为违反刑法。

    * 若要求认识违法性，意味着越是精通法律越容易构成犯罪，越是法盲文盲越安全，明显反进步。

* **认识程度的宽严**

    * 对客观方面只需有概括的认识，不要求认识到具体细节、数值、过程。

### 对危害行为的认识

* 要明知自己实施的是危害行为，明知其具体内容及意义。

* 例：文盲农民工在外国人聚居的小区门口摆摊卖外文书籍，书籍被指为淫秽物品。他不认识汉字更不懂外文，没有认识到自己实施的是贩卖淫秽物品的行为，不构成该罪。

### 对犯罪对象的认识

* 某个罪有对象，就必须认识到对象；没有对象则不作要求。

* 例：猥亵儿童罪的对象是儿童，只有认识到对方是儿童才有猥亵儿童的故意。

* 例：故意杀人罪的对象是人，不明知对面是人，只能定过失致人死亡——打猎时误击模仿猪叫拱地的马蜂致死。

* 例：窝藏罪、包庇罪要求"明知是犯罪的人而窝藏、包庇"。

* 例：奸淫幼女型强奸罪要求明知对方是幼女或者可能是幼女。若已满12周岁不满14周岁的幼女身材高大、发育成熟，行为人不知其年龄且经其同意发生性关系，对对象缺乏认识，没有奸淫幼女的故意。

* **只要求概括认识**

    * 奸淫幼女型强奸罪只需认识到对方是幼女，至于是12岁还是13岁零六个月不影响故意成立。

    * 贩卖淫秽物品牟利罪只需认识到自己贩卖的是淫秽物品，至于有多淫秽不要求认识。

    * 盗窃罪只需认识到被自己盗窃的是财物，财物到底值2000元还是2500元不重要。

    * 故意毁坏财物罪只要求认识到被毁坏的是财物，不要求认识到数额较大，因为财物价值要经价格鉴定、司法鉴定才能得出。

    * 传播淫秽物品罪中淫秽物品属于本罪对象，在客观方面之内，必须有认识。

* **例：偷换对象**

    * 行为人主张"我没有认识到自己是个犯罪主体"是偷换概念。成立故意杀人罪要求认识的是"对象是人"，与"自己是不是人"无关。

### 对危害结果的认识

* 某个罪有危害结果，就必须明知自己的行为可能造成该危害结果；没有危害结果的（如行为犯）不作要求。

* 例：故意杀人罪要求行为人明知自己的行为可能造成死亡结果，仍然决意实施。

### 对因果关系的认识

```text
   危害行为  ──────────  危害结果
   （要认识）  因果关系  （要认识）
      起点                 终点

   两端之间的「发展过程」—— 不要求认识
```

* 因果关系是危害行为与危害结果之间的引起与被引起关系，像桥梁一样连接两头。

* 只要求认识起点（行为）和终点（结果），不要求认识因果关系发展的具体样态。

* 例：张三想杀李四，打算推他下井淹死，井里无水李四摔死。已认识推人下井、已认识可能致死，足以成立故意杀人罪；不要求认识到是淹死还是摔死。

* 若要求认识到具体过程才能证明故意，等于放纵犯罪人。

### 对社会危害性的认识

* 法条说的是"危害社会的"结果，故须认识到自己的行为、结果具有社会危害性。

* 认为自己的行为是正当的、合法的，表明想实施的是合法行为，没有犯罪故意。

* 例：假想防卫。行为人误认为存在不法侵害而实施"防卫"，认为自己是合法行为，不明知社会危害性，故无犯罪故意。

### 五点过滤总表

| 客观方面的内容 | 主观是否要求认识 | 要认识到什么程度 |
| :--- | :--- | :--- |
| 危害行为 | 必须认识（所有犯罪都有行为） | 明知行为的具体内容及其意义，必须明知自己实施的是危害行为 |
| 犯罪对象 | 有对象就必须认识，没有对象不要求 | 只要求概括认识到对象，不要求具体细节 |
| 危害结果 | 有危害结果就必须认识，没有结果不要求（如行为犯） | 明知自己的行为可能造成该危害结果 |
| 因果关系 | 有结果时原则上要认识两端 | 只认识起点（行为）和终点（结果），不要求认识中间发展的具体样态 |
| 时间、地点、方法 | 属于客观方面的内容，原则上要求认识 | —— |
| 社会危害性 | 必须认识 | 认识到行为、结果具有社会危害性；不要求认识到"违反刑法"的违法性 |

* 过滤方向：只有落在客观方面之内的要素才进入这张表要求认识；客观方面之外的一律不要求认识。

* 把握的宽严：表格右列一律是"程度"而非"精确内容"——对象只需概括、数值不需精确、过程样态不需具体、只要求认识社会危害性而不要求认识违法性。

## 意志因素

* **意志因素（volitional element）**

    * > **定义**：行为人希望或者放任危害结果发生。

    * "希望"是对结果的积极追求，对应直接故意。

    * "放任"是听之任之、任其发展：不积极追求，但也不设法避免；结果发生能接受，不发生也能接受，是一种麻木不仁的心态。

    * 犯罪故意由此分为直接故意与间接故意。

### 直接故意

* > **定义**：明知自己的行为会发生危害社会的结果，并且希望危害结果发生的心理态度。

* **明知必然 + 希望**

    * 例：马蜂坐在身边，举枪顶住其脑袋，明知一开枪它必死仍然扣动扳机，构成故意杀人罪。

* **明知可能 + 希望**

    * 例：与张三有仇，张三站在50米外，瞄准开枪，心手发抖但仍积极追求死亡结果，一枪命中，构成直接故意杀人。

* 两个案例只在认识因素上有别，意志因素完全相同。

* > **结论**：直接故意 = 明知必然或可能 + 希望。

### 间接故意

* > **定义**：明知自己的行为可能会发生危害社会的结果，并且放任危害结果发生的心理态度。

* 认识因素上只能认识到危害结果发生的可能性，不能认识到必然性。

* > **易错点**：放任的前提是结果可能发生、也可能不发生。只要认识到结果必然发生，依然实施并造成结果，那就只能认定为直接故意。

* **例：砍断绳子**

    * 与马蜂有仇，见其在18楼窗外擦玻璃，砍断绳子可致其坠落；发现绳上还系着好兄弟岳跃鹏，纠结后想"兄弟一定会支持我"仍然砍断，二人同时坠亡。

    * 对马蜂是直接故意；题目真正会考的是对岳跃鹏——已认识到砍断绳子岳跃鹏必死无疑，不可能放任，仍只能是直接故意。

* **例：手榴弹**

    * 五人围坐，马蜂坐中间，张三与马蜂有仇，掏手榴弹扔向中间，坐中的马蜂被炸死，四人也全部炸死。对另外四人的死亡同样只能是直接故意——手榴弹一死一大片，行为人已认识到结果必然发生。

* **例：运输假烟遇检查**

    * 张三用小货车运假烟，检查人员李四脚踩踏板、手抓车门把手欲登车，张三突然加速夺路而逃，行进中突然急刹车，李四被甩出头部着地身亡。

    * 急速行驶中急刹车，李四被甩出的概率很高，造成严重后果的概率相当高，认定张三为间接故意。

* > **结论**：间接故意 = 明知可能 + 放任。

### 间接故意常见的三种情形

* **其一，为实现某个犯罪意图或目的而放任另一犯罪结果发生**

    * 例：丈夫为毒死妻子在妻子食物中投毒，明知孩子可能吃可能不吃，放任孩子死亡。对妻子是直接故意，对孩子是间接故意。

* **其二，为实现某个非犯罪目的或意图而放任犯罪结果发生**

    * 例：为打猎追赶野兔，兔子跑累卧倒在睡着的马蜂旁边，明知枪法不准仍开枪，兔子跑了、马蜂被打死。追求的是非犯罪的打猎目的，放任犯罪结果发生，成立间接故意杀人。

* **其三，突发性故意、不计后果，放任结果出现**

    * 即激情杀人。例：甲乙斗殴，甲临时起意、不计后果捅乙一刀后扬长而去，致乙死亡。

    * 原则上会造成伤害结果，对伤害结果是直接故意、积极追求；对死亡结果未积极追求，属间接故意。

### 直接故意与间接故意的异同

* **相同点**

    * 认识因素：都明知自己的行为会发生危害社会的结果，都达到"明知"的程度，认识程度较高。

    * 意志因素：一个"希望"、一个"放任"，但共性是两者都不排斥危害结果发生。

* **不同点**

    * 认识因素不同：直接故意可以认识到必然性也可以认识到可能性；间接故意只能认识到可能性。

    * 意志因素不同：直接故意是积极追求，间接故意是听之任之、任其发展。

    * 结果要求不同：直接故意追求的特定结果未实际发生，通常仍可追究犯罪预备或未遂的罪责；间接故意若没有实际造成危害结果，不成立犯罪。

* > **结论**：间接故意只有结果实际发生、而且是实害结果发生以后，犯罪才成立——本土刑法理论的立场。

* 例：打兔子时真打中兔子，马蜂只是被吵醒未受任何伤害，对马蜂不成立犯罪。

## 犯罪过失

* **犯罪过失（negligence）**

    * > **定义**：行为人应当预见自己的行为可能发生危害社会的结果而没有预见，或者已经预见而轻信能够避免，以致发生这种结果的心理态度（刑法第15条）。

    * 立法定位：过失犯罪，法律有规定的才负刑事责任。

    * 两大特征：主观上没有犯罪故意；有过失。

    * 过失的本质是没有保持必要小心谨慎的态度。

    * 两种类型：应当预见而没有预见是疏忽大意的过失；已经预见而轻信能够避免是过于自信的过失。

* **罪、刑、法定三句话**

    ```text
    +------------------+------------------+------------------+
    |       罪         |       刑         |       法定       |
    +------------------+------------------+------------------+
    | 只造成严重结果   | 法定刑明显轻于   | 法律有规定的     |
    | 才负刑事责任     | 故意犯罪         | 才负刑事责任     |
    |                  |                  |                  |
    | 结果没发生       | 同样是引发火灾   | 没有规定         |
    | 犯罪就不成立     | 故意放火  死刑   | 言下之意无罪     |
    |                  | 过失失火  最高7年|                  |
    +------------------+------------------+------------------+
    ```

    * 罪：过失犯罪只有造成严重后果的才负刑事责任。死亡结果没发生就不成立过失致人死亡罪。

    * 过失犯罪只有"成立"与"不成立"两档，没有中间状态。故意犯罪则存在预备、未遂、中止等未完成形态。

    * 刑：过失犯罪的法定刑明显轻于故意犯罪。同样引发火灾烧死多人，故意放火最高死刑，过失失火最高七年。

    * 法定：没有法律规定的，即使真的造成损害结果，仍然无罪。

* **方向不对称**

    ```text
            同样的犯罪事实
                    |
         +----------+----------+
         |                     |
      过失能成立            故意能成立
         |                     |
      故意一定能成立        过失未必成立

      过失致人死亡  ->  故意杀人        盗窃罪        故意才有
      过失致人重伤  ->  故意伤害        毁坏财物罪    故意才有
      玩忽职守罪    ->  滥用职权罪      抢劫罪        故意才有
    ```

    * 针对相同的犯罪事实，过失能成立，故意肯定也能；反过来，故意能构成的过失未必能。

    * 有强奸罪没有过失强奸罪；有盗窃罪没有过失盗窃罪；有抢劫罪没有过失抢劫罪；有故意毁坏财物罪没有过失毁坏财物罪。

    * > **易错点**：过失犯罪是典型的结果犯，只有成立与不成立两档，不要拿故意犯罪的"未遂"思路去套过失。

    * > **结论**：我国刑法是以惩罚故意犯罪为原则，以惩罚过失犯罪为例外。

## 两种过失的分水岭

| | 疏忽大意的过失 | 过于自信的过失 |
| :--- | :--- | :--- |
| 法条表述 | 应当预见，因疏忽大意没有预见 | 已经预见而轻信能够避免 |
| 别称 | 无认识的过失 | 有认识的过失 |
| 心理状态 | 极端马虎草率 | 极端轻率、过于自信 |
| 注意义务 | 没有履行法律、法规、社会生活准则要求的注意义务 | 已预见，但在应当积极避免且能够避免的情况下竟然没有避免 |
| 结果发生前 | 结果压根没进过大脑 | 结果进了大脑，但被"能躲过去"盖过去了 |
| 对结果的态度 | 反对、不希望发生 | 反对、不希望发生 |

### 应当预见而没有预见

* > **定义**：行为人应当预见自己的行为可能发生危害社会的结果，因为疏忽大意没有预见，以致发生了这种结果。

* 三层递进：行为人有预见的义务，也有预见的能力，本来可以预见，但因粗心没有预见。

* 内核是没有履行法律、法规、社会生活准则所要求的注意义务，对应当预见且能够预见的危害结果没有预见。

* **注意义务的来源**

    * 法律、法规：交通肇事罪是过失犯罪，驾驶机动车通过路口要减速、观察周围交通环境，这是法律规定的义务；科目三路考上车前绕车一圈检查危险状况，写进驾考即为一条实在的注意义务。

    * 社会生活准则：抽烟随手扔烟头，应当预见可能引发火灾，这是每个正常人都有的风险意识。

* 例：张三开车未仔细检查周围交通环境，直接倒车，撞死两个小孩。应当预见会造成严重后果，因疏忽大意没有预见，未履行法定注意义务。

### 已经预见而轻信能够避免

* > **定义**：行为人已经预见自己的行为可能发生危害社会的结果，但轻信能够避免，以致发生这种危害结果的心理态度。

* "轻信能够避免"包含两层：能够避免，指行为人希望并相信能够避免危害结果发生；轻信，指轻率地相信，行为人没有确实可靠的客观根据。

* 例：张三在柴火堆旁抽烟，随手把烟头扔了，低头看见烟头没灭，踩了一脚转身离开，最后引燃柴火引发大火。

* 低头看、踩一脚、转身离开恰恰表明结果已在大脑中预见，只是轻信踩一脚就能避免，属典型的过于自信的过失。

* > **易错点**：区分两种过失，看的不是行为人最后做了什么补救动作，而是他从头到尾有没有把危害结果放进过大脑。踩一脚、回头看一眼、事后报警，都可能是"轻信能够避免"的外化动作，而不是"没有预见"的证据。

### 判断顺序

```text
   行为人大脑中闪现过危害结果吗？
              │
        ┌─────┴─────┐
        │           │
       没有         有
        │           │
        ▼           ▼
  应当预见      已经预见
  没有预见      轻信能避免
        │           │
        ▼           ▼
   疏忽大意的过失   过于自信的过失
```

* 第一个标准通常就够用：大脑中有没有闪现过危害结果。闪现过、有认识，是过于自信；从未闪现过，是疏忽大意。

* 第二个标准是辅助的：关键看有没有采取避免措施。已采取避免措施说明对结果必然有所预见，此时仍倒向过于自信。

* **垃圾袋案**：张三在十楼扔生活垃圾，站在窗前往下看确认没人后扔下，一个孩子恰在此时跑出被砸死。结果已在大脑闪现，属过于自信。

* **烟灰缸案**：张三与小花吵架，抡烟灰缸砸向小花，小花躲开后烟灰缸飞出窗外砸死一人。大脑未闪现可能砸死楼下人的念头，属疏忽大意。

* **随手扔烟头案**：扔前查看烟蒂未熄灭、踩一脚转身走，最终仍引发火灾，属过于自信并成立失火罪；若抽完随手一扔、大脑毫无意识、扔完就走成习惯，则属疏忽大意，违反社会生活上的注意义务。

* **护士查房案**：护士见六个月大婴儿侧躺、脸鼻贴被单，拍拍屁股离开，一小时后婴儿窒息死亡。对死亡结果没有思考和判断，属疏忽大意。

### 入水案：甲踹沈某入河

* 甲与朋友聚餐，男友沈某饮啤酒数瓶，餐后在河边喝酒，甲两次劝其回家未果，遂用脚踹其背部致其落河。甲踹完返回车内，几分钟后回河边发现沈某不见，拨打其手机发微信、打电话、托朋友联系并报警。经查：甲知道沈某会游泳，以为踢下去他会上岸；沈某案发前虽饮酒但精神状态尚可；落水地点距岸边较近；两人系恋爱关系平时关系较好。沈某系生前溺水死亡。

* **第一步排除直接故意**：案卷证据"两人系恋爱关系，平时关系较好"表明甲没有杀人动机，不可能追求男友死亡。

* **第二步排除间接故意**：过失的法条表述是"轻信能够避免"，表明过失行为人对结果是反对、否定的态度，结果一旦发生会违背其主观意愿。间接故意则无所谓，谈不上不开心。事后立刻打电话、发微信、找人帮忙、报警求助，充分表明甲反对结果出现，没有放任的余地。

* **结论**：认定为过于自信的过失，构成过失致人死亡罪。"经查甲知道沈某会游泳，以为踢下去之后沈某会爬上来"表明她已预见可能造成严重后果，只是轻信能够避免。

* **致死概率的判断**：沈某会游泳、距岸边近、精神状态尚可，题目也没有说其严重醉酒或断片。被踹入水中致死的概率低，通常能够自救。致死概率低，只能解释为过失致人死亡，不能把低致死概率的行为拔高为故意杀人。

* > **提示**：同类案子的判断顺序是：先看致死概率，再看主观证据，最后才谈结论。

## 无罪过事件

* **无罪过事件**

    * > **定义**：行为在客观上造成了损害结果，但不是出于故意或过失，而是由于不能抗拒或者不能预见的原因所引起的，不属于犯罪（刑法第16条）。

    * 两种法定情形：意外事件（不能预见）、不可抗力（不能抗拒）。

    * 一种理论情形：无期待可能性。

    * 严格讲，刑法讨论任何现象都以前提"疑似犯罪"为限，看着与犯罪毫无关系的行为（如端起杯子喝水）没有用刑法理论讨论的必要。

    * 疑似犯罪若最终无罪：四项指标（主观、客观、形式、实质）一个都不能全缺。不满足主观一定满足客观，不满足客观一定满足主观，不满足形式一定满足实质，不满足实质一定满足形式。

    * 无罪过事件缺的是主观，故必然满足客观——这正是第16条的来源结构。

```text
                 疑似犯罪（客观上看着像犯罪）
                            |
        +-------------------+-------------------+
        |                                       |
     最终有罪                                最终无罪
  主客观相统一                        主客观、形式实质中
  形式实质相统一                      必有且只缺一项
        |                                       |
  故意犯罪 / 过失犯罪        四项一个都不能全缺；全缺就不是
                            疑似犯罪，只是"端起杯子喝口水"
                                     |
                    无罪过事件 = 缺主观，故必满足客观
```

### 意外事件

* > **定义**：行为客观上造成了损害结果，对造成的结果既无故意也无过失，是由于不能预见的原因所引起的。

* "不能预见"意味着行为人没有预见，而且根据当时的客观情况和行为人的主观认识能力，也不可能预见。

* 例：甲开车时突然癫痫发作撞死两人，其癫痫从未发过病、系首次发病，事后不知情，不可能预见到自己有这种疾病，属意外事件。

* 例：小区工作人员乙、丙躺在车库甬道距入口5米处休息，丙躺在车辆视觉盲区。甲驶入甬道将丙碾压致死。正常人无法预见到这个位置会并排躺着两个人，且位于视觉盲区。

* > **易错点**：视觉盲区意味着甲根本发现不了。不能认为甲有义务下车用手电筒逐处检查——若如此，进地库都要先停车照一圈，如同扫雷，明显不合适。检察院主张过失致人死亡被法院否定，法院认定为意外事件、无罪。

* **突发疾病**

    * 之前患病但自己不知情、首次发病就造成严重后果的，属意外事件。

    * 发过病后仍隐瞒病情继续开车，五年后再次发病造成严重后果的，认定其主观上有过失；已知患有癫痫不符合申领驾驶证条件。

### 不可抗力

* > **定义**：行为在客观上造成损害结果，但不是出于故意或过失，而是由于不能抗拒的原因所引起的。

* "不能抗拒"指行为人遭遇到了特定力量，即使用全部智慧、全部主观力量也无法抗衡、不可能阻止危害结果发生，即无可奈何：明知结果要发生，但没有能力阻止。

* 例：警察正要制止正在杀人的歹徒，自己的心脏病发作，捂胸躺地，眼睁睁看着被害人被杀，未能履行职务。警察主观上既无故意也无过失，结果是由不能抗拒的原因引起，属不可抗力。

### 期待可能性

* **期待可能性（Erwartbarkeit）**

    * > **定义**：行为人在实施犯罪的具体场合，期待其实施适法行为而不实施违法行为的可能性。

    * 有期待可能性：根据行为时的具体情况，可以期待行为人遵守法律、不实施违法行为。

    * 无期待可能性：根据行为时的具体情况，不可能期待行为人继续遵守法律，即使其实施违法行为也不构成犯罪。

    * 理论前提：精神正常的成年人可以选择犯罪也可以选择不犯罪，有选择余地、有相对意志自由，故可以被期待遵守法律。

* **德国癖马案**

    * 18世纪，马夫发现所驾两匹马喜欢用尾巴缠住缰绳（缰绳是控制方向和速度的关键），告知雇主并要求换马，雇主称"我宁愿换掉你，也不会换掉这两匹马"。马夫继续驾车运货，闹市区两马受惊冲撞致人受伤。一审认定过失犯罪，**德国帝国法院**终审改判无罪，理由是马夫已如实向雇主尽到报告义务，不能期待他宁愿丢掉养家糊口的职业仍坚持换马。

    * 该判决产生期待可能性理论的萌芽，其法理是法律不能强人所难。

    * 例：被拐卖的妇女小花已与他人登记结婚，被拐卖后又被李四控制并形成事实婚姻，前有法定婚、后有事实婚，对她不按重婚罪追究刑事责任，否则她可能面临更严重的侵害。

* **马工程教材的警惕**

    * 期待可能性本身比较模糊，构成要件、界限并不明确。

    * 若作为一般的责任阻却事由大规模适用，会导致法的不安定性；在我国刑法明文规定之外，因缺乏期待可能性而阻却责任的情形较为罕见。

    * 无期待可能性只有五个点，五个点之外不要再去拓展，再拓展就是对期待可能性理论的滥用。

* **法条中的投影**

    | 条文 | 体现期待可能性的理由 |
    | :--- | :--- |
    | 刑法第16条 | 不能抗拒、不能预见，既无法抗拒也无法预见，就不能要求行为人遵守法律，惩罚即违反人性 |
    | 刑法第17条 | 不满12周岁的人不具有刑法意义上的辨认能力和控制能力；已满14周岁不满16周岁的人具备辨别大是大非的能力，可期待其遵守禁止杀人、禁止伤害致人重伤死亡、禁止抢劫等禁止性规范 |
    | 刑法第19条 | 精神病人在不能辨认或不能控制自己行为时造成危害结果，经法定程序鉴定确认的不负刑事责任，因其无辨认能力、无控制能力 |
    | 刑法第21条、第22条 | 正当防卫、紧急避险。"紧急之时无法律"，不能要求行为人等着警察救助；法不得向不法让步，正不得向不正让步 |

    * **正当防卫的法理**：张三拿刀砍人时，除了跑，跑不掉被追上一定会反击；通过反击将对方打成轻伤重伤不追究刑责。不能要求行为人站在那儿任人砍伤砍死。

    * **紧急避险的法理**：野狗追咬危及生命，未经同意闯入他人住宅并从里面关门挡狗，表面上是非法侵入住宅、扰乱住宅安宁，但保护的是生命权、损害的是住宅安宁权，保护利益大于损害利益，成立紧急避险。不能要求行为人先去敲门求人开门。

### 无期待可能性的五个点

```text
            犯罪之后的"善后"行为
                      |
        +-------------+-------------+
        |                           |
   单纯毁灭证据                 单纯销赃
 (掩埋、抛尸、擦拭指纹、      (把赃物卖掉)
  伪造足迹、扔进马桶)
        |                           |
   没有期待可能性              没有期待可能性
   不单独构成                  不构成掩饰、隐瞒
   证据类犯罪                  犯罪所得罪
        |                           |
        +-------------+-------------+
                      |
        但如果换一个"罪名"当手段去做
                      |
     +----------------+----------------+
     |                                 |
  放火毁证                       诈骗销赃
  手段本身有期待可能性            手段本身有期待可能性
  盗窃罪 + 放火罪 数罪并罚         盗窃罪 + 诈骗罪 数罪并罚
```

* 概括为一句话：不能期待你不做这个动作，但可以期待你换一个更严重的手段去做。

* **其一，犯罪后毁灭、伪造证据**

    * 不能要求一个人犯罪之后保护现场、保存证据、保护尸体、等着警察来侦查；犯罪后破坏现场、毁灭证据才是人之常情。可以惩罚其杀人行为，不能再单独处罚后面的毁坏证据行为。

    * 例：杀人后掩埋尸体、伪造足迹，仅构成故意杀人罪，不再定故意毁坏尸体罪。杭州杀妻案丈夫杀人后分解尸体经马桶冲入下水道，最终只定故意杀人罪。

    * 例：入户盗窃后担心指纹足迹被发现，一把火烧了房子还殃及邻居、危害公共安全。构成盗窃罪，毁证行为本身不构成证据类罪，但放火这个手段本身有期待可能性，以盗窃罪与放火罪数罪并罚。

    * > **易错点**：没有期待可能性只是说不能再单独构成与证据相关的犯罪；该行为所使用手段如果构成其他罪，该定罪还是要定罪。否则单放火定重罪、偷完再放火毁证反定轻罪，奖励犯罪。

* **其二，财产犯罪后的销赃**

    * 小偷偷完东西本就是为了销赃，若销赃再定掩饰、隐瞒犯罪所得罪并一律数罪并罚，既不合理也违背人性。理论上主张后续单纯销赃不构成掩饰、隐瞒犯罪所得罪，只按前面的财产犯罪定罪。

    * 例：甲偷两台电脑卖给知情的丙，只定盗窃罪。

    * 例：甲盗窃文物仿制品（假文物但价值可能数额较大），谎称是汉代文物卖给丙骗取巨额财物。前行为构成盗窃罪（侵害仿制品所有权人的所有权），后行为通过欺骗手段骗取丙的财物构成诈骗罪，以盗窃罪与诈骗罪数罪并罚，仍不构成掩饰、隐瞒犯罪所得罪。

* **其三，受迫的重婚行为**

    * 因强迫包办婚姻、婚后受虐待而外逃、已婚妇女被拐卖后与他人形成事实婚姻的，属受客观条件所迫，没有期待可能性，不构成重婚罪。

* **其四，无罪人的脱逃行为**

    * 司法机关错拘、错捕、错判后，行为人逃离羁押场所的，不构成脱逃罪——他本来就是被冤枉的。

* **其五，共犯人之间的窝藏包庇**

    * 共同犯罪人之间互相实施窝藏、包庇，不以窝藏、包庇罪定罪处罚；对共同犯罪人以外的犯罪人实施窝藏、包庇的，所犯之罪与窝藏、包庇罪数罪并罚。

    * 例：与马蜂共同抢劫后将其藏在自己乡下老宅避风头，不定窝藏罪。共犯如同绳上的蚂蚱，只要马蜂被抓自己也跑不了。

    * 若对与自己无共犯关系的另外两人实施窝藏，则可以定窝藏罪，按抢劫罪与窝藏罪数罪并罚。

* **亲亲得相首逆**

    * 法制史上确有朝代对一定亲等关系的人相互窝藏包庇不按犯罪处理，但本土观点与法考观点不同。

    * 本土观点主张：具有一定亲等关系的人相互之间窝藏包庇不构成犯罪。

    * 经过实证研究，全球190多个国家和地区中"亲亲得相首逆"绝大部分仍按犯罪定罪处罚，我国也不例外。哪怕儿子犯罪老子去窝藏，对老子同样按窝藏罪定罪处罚，真题中已有反映。

### 适用上的两个极端

* **第一个极端：完全不承认期待可能性**

    * 理由是"于法无据"——法律上没有"期待可能性"这几个字。这个理论没有价值。立法上第16条、第17条、第19条、第21条、第22条都体现了这一精神。

* **第二个极端：大面积推广期待可能性**

    * 会导致期待可能性理论被滥用。

    * 例：乞丐饥饿难耐，撬开小商店门偷吃偷喝偷钱，能否主张无期待可能性而免责？若如此，只要饥饿难耐就可以偷、抢、骗，再通过期待可能性理论排除犯罪，否则不用工作即可免责。会产生法的不安定性。

* > **结论**：坚决不承认的有可能问题，导致它被滥用的更有问题。

## 主观状态的交叉对撞

| 主观状态 | 认识因素 | 意志因素 | 对法益的态度 | 法律后果 |
| :--- | :--- | :--- | :--- | :--- |
| 直接故意 | 明知结果必然或可能发生 | 希望结果出现，积极追求 | 敌视、蔑视 | 故意犯罪 |
| 间接故意 | 明知结果可能发生 | 放任结果发生 | 漠视、麻木不仁 | 故意犯罪 |
| 过于自信的过失 | 已经预见 | 反对结果发生 | 轻视 | 过失犯罪 |
| 疏忽大意的过失 | 应当预见而没有预见 | 反对结果发生 | 轻视 | 过失犯罪 |
| 意外事件 | 不能预见 | 反对结果发生 | —— | 不构成犯罪 |
| 不可抗力 | 已经预见，但无能力避免 | 反对结果发生 | —— | 不构成犯罪 |

* 直接故意对法益是敌视、蔑视的态度；间接故意是漠视、麻木不仁；过于自信与疏忽大意都是反对结果出现，一个已经预见、一个应当预见没预见，意志因素相同，都是轻视。

### 过于自信的过失与间接故意

| 比较面 | 间接故意 | 过于自信的过失 |
| :--- | :--- | :--- |
| 认识因素 | 明知结果，明知自己的行为会造成结果，造成结果的概率大 | 对结果仅仅是一种预见，造成结果的概率小 |
| 意志因素 | 放任结果发生 | 排斥、否定结果发生 |

* **相同点**

    * 认识因素：都认识到危害结果可能发生，过于自信是已经预见，间接故意达到"明知"的程度。

    * 意志因素：过于自信反对结果出现，间接故意放任结果出现，归纳起来两者都不追求结果出现，对结果都没有积极追求的心理态度。

* **不同点**

    * 认识因素：间接故意明知结果，认识程度相当高；过于自信只是预见，认识程度相对较低。

    * 意志因素：间接故意放任，过于自信反对、否定、避免。

* **形式标准**

    * 关键看有没有采取避免措施。过于自信反对结果，结果将出现时行为人若有能力一定会采取措施；间接故意放任，不会去避免。

    * 题目中行为人采取了避免措施的，通常是过失犯罪；没有避免措施的，有可能是间接故意。

    * > **易错点**：形式标准有时不可靠，因为它可能与本质标准产生冲突。

* **本质标准**

    * > **定义**：构成要件行为的类型化原理——只有致死（或致严重后果）概率高的行为才能解释为故意犯罪，概率低的只能解释为过失犯罪。

    * 判断抓手是行为有没有**明显的加害性**。间接故意的行为具有明显的加害性，导致结果的概率高；过于自信所实施的行为本身危险性没有那么大，没有明显的加害性，导致结果的概率低。

    ```text
       行为有明显的加害性  ──►  致结果概率高  ──►  主观明知  ──►  间接故意
       行为无明显的加害性  ──►  致结果概率低  ──►  主观仅预见  ──►  过于自信的过失
    ```

    * 例：持枪对准扣扳机，知道大概率会打死对方，行为有明显的加害性、概率高，对结果的认识达到明知，只能是间接故意。

* **飞镖案**

    * 与马风玩笑，声称祖传绝技：固定在五米外的墙上蒙眼掷飞镖，两镖分别扎在左耳、右耳附近都不会伤人。二人互相蒙眼后投掷，两镖正中双眼，造成重伤。

    * 行为人有明显加害性，造成严重后果的概率高，只能解释为故意伤害，认定为间接故意。

* **违章闯卡案**

    * 张三违章驾驶遇前方交警设卡，刻意与前车拉开五十米等前车先接受检查。交警招手后，他心想突然加速就能提上来，交警也是人、也会怕，肯定会让开，于是一脚油门冲出，两个交警一死一伤。

    * 50米在快速行驶中可能只有几秒，0百加速一般需八九秒，留给交警的时间不多，行为有明显加害性、概率高，认定为间接故意。

* **毒西瓜案**

    * 瓜农的西瓜老被人偷，先敲锣喊"西瓜打毒了"，无人相信；心想"这次真打"就向西瓜注射剧毒农药并插牌提示，结果仍有人偷吃并毒死数人。

    * 形式标准看：有避免措施，敲锣提醒、竖提示牌。

    * 本质标准看：西瓜仍被人偷，误食致死概率高，前述警告无效，插的牌子不足以使人相信此瓜有毒。

    * 形式与本质冲突时以本质标准为准，认定为间接故意。检察官的反驳逻辑是：过失犯罪是反对危害结果发生的，既然行为人反对结果发生，为什么实施一个很可能导致结果发生的行为？这正是口是心非，矛盾解不开。

* **高空抛物案**

    * 张三在十楼扔生活垃圾，低头看楼下没人后扔下，孩子突然跑出被砸死。致死概率低（孩子突然出现是小概率事件），故认定为过于自信的过失而非间接故意杀人。

* **桂圆案**

    * 保姆小花照顾六个月大的小明，孩子抓桂圆要吃，小花剥开放进孩子嘴里，桂圆被直接吞下卡在支气管中，孩子呼吸困难。

    * 形式标准看：确实送往医院了，但这个避免措施微不足道，没有让孩子得到及时救助，也没有说出真相。

    * 本质标准看：第一时间就应直接送医院而不是先找药店，且磨磨蹭蹭送医至为时已晚，此时致死概率高，认定为间接故意。

    * 参照：成年人卡住一颗花生米都可能需要多家三甲医院抢救、面临切开支气管的风险，六个月大的婴儿卡住一颗桂圆极度危险，不及时送医完全可能死亡。

* > **结论**：形式与本质冲突时，一律看本质。

### 疏忽大意的过失与意外事件

* **相同点**：都未预见到结果可能发生——疏忽大意是应当预见没预见，对结果没有认识；意外事件对结果更没有认识。

* **不同点**：在于是否**应当**预见。疏忽大意中行为人应当预见、有能力预见，只是马虎大意没预见；意外事件中行为人是不可能预见。

* **责任不同**：疏忽大意的过失可以构成过失犯罪，意外事件不构成犯罪。

* > **区分标准**：把"可能性"圈起来——只要有预见到的可能性，有能力而未预见，是疏忽大意；连预见到的可能性都没有，是意外事件。

* **判断基准**：以行为人的认识能力为标准，以一般人的认识能力为参考。

    * 前半部分考察张三本人的主观认识能力；做题时题目一般不会细致交代张三的认识水平，后半部分反而更重要。

    * 声称"这对我而言是意外事件"时 police 的思路是：和我经历相同、年龄相仿的人能否预见到？能预见而偏偏我没预见，说明我有过失；一般人都不可能预见而我也没预见，才是意外事件。

* **地库案**：两个工作人员躺在车库入口5米处的视觉盲区睡觉，一般人不可能预见到该位置会有人睡觉，认定为意外事件。

* **硫酸案**：甲为报复乙把硫酸装入水杯带到学校，课间争吵时想泼乙但未能拧开瓶盖。丙误将甲的水杯当成自己的杯子，拧开时硫酸淋洒一身灼成重伤。甲把如此危险物品带到公共场所、人员密集的地方，就应当预见到可能伤害他人，属疏忽大意，可构成过失致人重伤罪。

* **滴滴司机矿泉水瓶案**：网约车司机把自己应急用过的矿泉水瓶随手放在车上，李四拧开就喝，事后才发现异味。若造成严重后果，司机是专业网约车司机，自己的物品不及时处理就应当预见到可能被其他乘客误饮，属过失。

* **康师傅冰红茶案**：与朋友合租搬行李时临时用饮料瓶应急解决，放在书桌上忘了处理，次日朋友口渴拿起就喝，发现异味后当场喷吐。若造成严重后果，行为人明知自己的物品可能被他人饮用而未处理，属过失。李四不直接对着瓶口喝、不事先询问也对结果有一定过错。

### 过于自信的过失与不可抗力

* **相同点**：对结果都有认识。过于自信是已预见但轻信能够避免，不可抗力是知道结果要发生但无能为力；两者都反对结果出现。

* **不同点**：关键看有没有避免结果的可能性。连任何避免的可能性都没有，是不可抗力；有避免的可能性却没避免，是过于自信的过失。

* 判断要综合考虑行为人的避免能力和客观条件。

* 例：警察正要制止歹徒时心脏病发作、躺地不起，意识到歹徒可能要杀人但已无能力履行职务，属不可抗力。

* **超市门口汽车案**：张三开六岁儿子停在超市门口不熄火去购物，嘱咐孩子千万别动。孩子挂挡把车开走，张三出来后拉车门、推车阻止但无能为力，最终撞死人。

    * 他有避免的可能性而没有避免——要么熄火，要么把孩子带下去，两者都没做，所以是过于自信的过失。

    * 之所以不是疏忽大意，因为他对结果已有思考：他专门嘱咐孩子不要碰、不要动这辆车。

    * > **易错点**：不能说"这是不可抗力，因为他力气小，不可能阻止汽车前进"。这是孤立地看一个细节，没有把整个案件放在考察范围内。应站在起因、过程、结果的全过程判断——这个案件原本是可以避免的。

## 犯罪目的

* **犯罪目的（purpose）**

    * > **定义**：行为人希望通过实施某种犯罪行为，实现某种犯罪结果的心理态度。

    * 本质与生活目的一致，都是通过行为实现结果：通过砍这一行为实现杀人的结果。

    * > **结论**：犯罪目的只能存在于直接故意中，它决定犯罪的方向。

    * 间接故意中不可能有犯罪目的：犯罪目的表明对结果是积极追求，间接故意是放任。

    * 过失犯罪更不可能有：疏忽大意与过于自信都是反对危害结果发生，不是追求结果发生。

* **目的犯**

    * > **定义**：以行为人主观上具有一定的犯罪目的作为犯罪构成要件的犯罪。

    * 特定的犯罪目的是该罪的成立条件，有目的即成立，没有目的即不成立。

    * **成文的目的犯**：刑法明文规定目的的，包括贩卖淫秽物品牟利罪（以牟利为目的）、拐卖妇女、儿童罪（以出卖为目的）、走私淫秽物品罪（以牟利或者传播为目的）、高利转贷罪（以转贷牟利为目的）、侵犯著作权罪（以营利为目的）。大纲内刑法明文规定的目的犯一共十个。

    * **不成文的目的犯**：法条未规定目的，但依刑法理论解释必须具备特定目的的，如抢劫罪必须具有非法占有他人财物的目的。买了新手机被一把夺走当场摔毁，对手机无非法占有目的，既不构成抢劫罪也不构成抢夺罪。

* **构成要件要素的两分**

    * > **定义**：成文的构成要件要素指法条明文规定的构成要件要素。

    * > **定义**：不成文的构成要件要素指法律虽未明文规定，但犯罪成立必不可少的构成要件要素。

    * 相同点是都是犯罪成立必须具备；区别在于法条上是否看得见。

    * 非法占有目的在抢劫罪中虽无法条明文，但成立抢劫罪必须具备，因此是不成文的构成要件要素。这不是立法者遗忘，而是众所周知的事实。

## 犯罪动机

* **犯罪动机（motive）**

    * > **定义**：推动行为人实施犯罪行为的内心起因。

    * 隐藏得更深，解释行为人基于何种心理原因实施犯罪行为。

    * 与犯罪目的的先后关系：先有犯罪动机，然后才有犯罪目的。动机产生在前，目的产生在后。

    * > **结论**：犯罪动机也只能存在于直接故意中。间接故意与过失犯罪既没有犯罪目的，也没有犯罪动机。

    * 一般不是犯罪构成的主观要素，但能反映犯罪人的主观恶性，对量刑具有重要意义，且往往是重要的法定或酌定量刑情节：滥用职权罪与玩忽职守罪中，徇私舞弊犯这两罪的量刑要更重。

    * 例外：极少数犯罪要求具备特定动机。徇私枉法罪中"司法工作人员徇私枉法、徇情枉法"的"徇私""徇情"就是动机，如果不是为了徇私、徇情，不可能构成本罪，动机对徇私枉法罪而言就是构成要件。

## 犯罪目的与犯罪动机的关系

### 联系有两点

* 两者都是行为人在犯罪时的心理活动，都能反映行为人的主观恶性。

* 犯罪动机是犯罪目的的基础，先有动机再有目的；犯罪目的是犯罪动机的具体化。看到张三放火、爆炸，就可以推测其动机是为了报复社会。

### 区别有四点

* **形成时间顺序不同**：动机产生在前，目的产生在后。

* **内容和表现不同**：动机是犯罪的内心起因，比较抽象；目的可以通过行为人所追求的危害结果反映出来，相对具体。偷走手机、造成财产损失即可推导出非法占有的目的；妇女被拐卖即可推导出出卖的目的。同一盗窃罪，非法占有目的相同，动机却可以是为生活、为治病、为嫖娼、为赌博、为报复、为追求刺激，千奇万怪。

* **对应关系不是一一的**：同一犯罪目的可以出于不同的犯罪动机（抓到100个小偷，非法占有目的都相同，但盗窃理由千奇万怪）；同一犯罪动机也可以导向不同的犯罪目的（同一报复社会动机，可以指向杀人、放火、强奸、抢劫、绑架、爆炸）。

* **定罪量刑中的地位不同**：犯罪目的偏重于影响定罪，犯罪动机偏重于影响量刑。

* **口诀**

    * 关：都体现了主观恶性程度（联系）。

    * 基：犯罪动机是犯罪目的的基础，犯罪目的是犯罪动机的具体化（联系）。

    * 表：内容和表现不同，动机抽象，目的具体。

    * 用：作用不同，目的偏重影响定罪，动机偏重影响量刑。

    * 于：出于，同一目的可出于不同动机，同一动机也可导致不同目的。

    * 时：产生的时间和顺序不同，动机在前，目的在后。

* **投毒案**

    * 甲与乙有仇想杀乙，明知乙晚上可能请客吃饭仍向其酒瓶投放毒药，丙应乙邀请饮酒后中毒身亡。

    * 甲对乙是直接故意，目的是追求乙死亡，动机是报仇；先产生报仇的心理动机，然后产生犯罪目的，然后实施行为。

    * 甲对丙至多是间接故意，间接故意本身没有犯罪目的——甲不是追求丙死亡而是放任。既然不是追求丙死亡，对丙既没有犯罪目的，也没有犯罪动机。

* > **结论**：犯罪目的、犯罪动机只能存在于直接故意中；间接故意和过失犯罪既没有目的，也没有动机。
