# 犯罪中止

## 犯罪中止的定位与形态公式

### 犯罪中止的定义与条文

    * **犯罪中止**

        * > **定义**：在犯罪过程中自动放弃犯罪，或者自动有效地防止犯罪结果发生的形态。

        * 规范依据是《刑法》第24条第1款。

        * 条文用"或者"连接两种类型：自动放弃犯罪；自动有效地防止犯罪结果发生。

        * 中止以成立犯罪为前提，在犯罪过程中仍要满足"主观＋客观＋A＋责任"结构。

        * 形态公式：着手之前无未遂，着手以后无预备，中止存在于全过程。

        * 据此中止分为预备阶段的中止与实行阶段的中止。

        * 责任规定在第24条第2款：没有造成损害的，应当免除处罚；造成损害的，应当减轻处罚。

        * 没有造成损害时是"应当免除"而非"可以免除"，法律与政策在鼓励行为人及时浪子回头、及时终止犯罪。

    * **犯罪形态的排他性与终局性**

        * 排他性：一个行为最终只能有一种形态，已归于未遂就不能再转成中止。

        * 终局性：犯罪行为彻底停止下来，是句号而不是逗号。

        * 犯罪形态本质上是时间推进，答题应当从前向后按顺序找第一个终局性停止点。

        * 暂时的停顿只是逗号，不产生形态；能够继续实施时主动停止才是终局性停止。

        * 事后的补救行为只能是犯罪既遂或未遂以后的态度，至多是酌定的量刑情节。

        * > **易错点**：倒着找形态最容易掉进命题陷阱，例如把邻居夺刀之后才发生的送医救活当成中止。

## 消极中止与积极中止

### 消极中止

    * **消极中止**

        * > **定义**：自动放弃犯罪即成立的中止，只要求行为人放弃犯罪，不要求再采取其他行动。

        * 之所以称"消极"，是因为只要"不干这件事"就能成立，不需要任何额外举动。

        * 投毒前例：想杀李四买了毒药尚未投毒，只要不投毒，中止即成立。

        * 预备阶段例：想买砍刀杀人，买回后一想放弃，虽已进入故意杀人罪预备阶段，仍成立预备阶段的中止。

        * 实行阶段例：潜入李四房间掏出毒药举向杯子（已着手实行），犹豫后把手撤回，放弃投即成立中止。

        * 实行阶段例：杀马蜂连砍两刀未中，见马蜂躲得可爱而于心不忍不再砍，着手后只要放弃继续砍即可成立。

### 积极中止

    * **积极中止**

        * > **定义**：自动有效地防止犯罪结果发生的中止，单纯放弃不够，还要额外采取行动把结果防住。

        * 成立场合：犯罪行为实行终了、犯罪结果尚未发生的特定场合。

        * 投毒例：李四已喝下毒药，放弃犯罪之外还必须把李四送医院救活，才可能成立杀人中止。

        * 反例：投毒后声称"我要放弃"转身逃跑，李四毒发身亡，杀人行为与死亡结果之间的因果关系未被切断，成立故意杀人罪既遂。

        * 单纯放弃即成立的是消极中止；须再加上一个防止结果出现的额外举动才成立的是积极中止。

### 按犯罪进程的中止分类

    * **预备阶段的中止**

        * > **定义**：发生在犯罪预备过程、着手实行犯罪以前的终止，例：拿刀砍人，砍下去之前自动放弃。

    * **实行阶段的中止**

        * > **定义**：发生在着手实行犯罪以后的终止，拆为未实行终了的中止与实行终了的中止。

        * 未实行终了的中止：犯罪行为还没实施终了，人就自动放弃；例：拿枪杀人三枪没打中就放弃，从张三角度看杀人行为未实施完毕。

        * 实行终了的中止：犯罪行为已实施终，但在既遂以前自动有效地防止了结果发生；例：投毒杀人后把李四送医院救活。

        * 量刑差异：预备阶段的中止量刑通常很轻甚至免除处罚；未实行终了的中止社会危害性较轻；实行终了的中止相对更重。

## 成立条件之一：时间性

### 可以成立中止的时点

    * **犯罪过程的时间区间**

        * > **定义**：犯罪中止必须发生在犯罪过程中，起点是进入预备阶段、实施预备行为，终点是犯罪既遂。

        * 可发生在预备阶段：买了毒药被朋友劝阻，听劝后把毒药也扔掉，自动放弃犯罪而未推进到实行阶段。

        * 可发生在实行阶段：用刀砍成轻伤后觉得对方可怜而放弃杀人，死亡结果也没有发生。

        * 可发生在实行终了之后、犯罪既遂以前：投毒后李四已经中毒、心生悔意，将其送往医院救活。

        * 行为犯只要法定行为实施完毕即既遂，不存在"实行终了的未遂"；结果犯即危险状态犯行为终了也未必既遂，所以实行终了的中止才有存在空间。

```text
        犯罪中止可以发生的"全过程"
  <──────────────────────────────────────────>

  开始实施预备行为        着手(实行行为开始)        犯罪既遂
        │                      │                    │
        │                      │                    └─ 过了这一点，形态已定，
        ▼                      ▼                       事后再补救也不叫中止
   ┌─────────┐          ┌──────────────┐
   │ 预备阶段  │          │ 实行阶段       │
   │ 的中止    │          │ 的中止         │
   └─────────┘          └──────────────┘
                               │
                               └─ 实行终了之后、犯罪既遂之前，仍可中止
                                  （投毒后送医救活）

  着手之前 → 无未遂        着手以后 → 无预备        中止 → 贯穿全过程
```

### 不能成立中止的时点

    * **归于未遂之后的事后补救**

        * 犯罪明显告一段落、已经归于未遂后再作补救，不能成立中止。

        * 杀妻案：张三在家用刀砍妻子，邻居李四冲进来把他摁倒在地、夺回刀。张三被摁倒、刀被夺走时杀人行为即因客观障碍停止，是被迫放弃，成立故意杀人罪未遂。

        * 此后李四批评教育下张三与李四一起把小花送医救活，属于犯罪未遂以后的态度，是酌定的量刑情节。

    * **未进入犯罪过程的情形**

        * 产生杀人故意后转念一想"算了别杀了"随即放弃，从生起到消除没有任何危害行为，本身无罪，不存在犯罪中止问题。

### 自动放弃可重复加害的行为

    * **自动放弃可重复加害**

        * > **定义**：行为人着手实行犯罪一次或多次后，未造成构成要件规定的结果，认识到可以继续实施侵害而自动放弃该侵害，成立犯罪中止。

        * 属于未实行终了的中止。

        * 三枪案：张三对着李四连开三枪未中，念及"事不过三"而收枪离开，整体只成立一个故意杀人罪中止，不能按三未遂加一中止数罪并罚。

        * 前三枪不成立未遂的理由：杀人行为并未终局性停止，只是逗号式的暂时停顿；六发子弹才用三发，他能够继续。

        * 与杀妻案的分界：杀妻案是客观障碍造成的停止（被迫放弃），本案是无障碍而自动放弃。

        * > **易错点**：⚠️区分点有两个——主观上行为人是否自愿停止，客观上是否能够继续实施侵害行为。

## 成立条件之二：自动性

```text
  标准一  主观说：行为人自认为能不能继续犯罪？
            自以为能而放弃 → 中止；自以为不能而放弃 → 未遂
              │  题目未交代其心理活动，说不清 → 跳过
              ▼
  标准二  客观说：彼时彼刻，一般人会不会放弃？
            一般人不会放弃、行为人也放弃 → 中止
            一般人  会放弃、行为人也放弃 → 未遂
              │  存在争议、形成不了广泛共识 → 跳过
              ▼
  标准三  他放弃是担心"当场被抓"，还是"日后受罚"？
              │  两者皆非 → 跳过
              ▼
  标准四  兜底：假设他不放弃，能不能较轻松地成功？
              │
        ┌─────┴─────┐
    能轻松成功    未必能成功
   （无较大障碍）（有较大障碍）
        │             │
       中止          未遂
```

### 两种中止的"自动"内涵

    * **自动放弃犯罪**

        * > **定义**：犯罪分子在自以为能够完成犯罪的情况下，由本人自主决定放弃犯罪。

        * 例：入室抢劫推门后看见被害人在看庭审纪录片，担心日后上电视而鞠躬退走；主观有抢劫故意、客观已进入抢劫预备阶段，此处只要放弃即成立抢劫罪中止。

    * **自动有效地防止犯罪结果发生**

        * > **定义**：在犯罪行为实施终了、犯罪结果尚未发生的特定场合，行为人自动采取有效的行动或者积极行动，实际防止了犯罪结果发生。

        * 被害人已经服毒时说"我放弃杀人"远远不够，必须把被害人送往医院并且救活。

### 主观说：弗兰克公式

    * **弗兰克公式**

        * > **定义**：能达目的而不欲的，为犯罪中止；能欲达目的而不能的，为犯罪未遂，可简化为"能而不欲"是中止，"欲而不能"是未遂。

        * 判断角度只有一句话：行为人自以为能不能，而不是"我认为我认为"。

        * 自以为能而放弃是中止：以为肯定能撬开保险柜，虑及撬开偷走量刑太重而放弃；即使事后鉴定再坚持五小时十小时也打不开，也不影响中止。

        * 自以为不能而放弃是未遂：垂头丧气说"肯定撬不开"就放弃，事后查明再坚持十分钟就能撬开，站在张三立场上是自以为不能完成而放弃。

        * 适用范围很窄：题目必须清楚、具体、确定地交代行为人的主观想法和心理活动，只有据题干能得出确定结论才适用。

        * > **易错点**：⚠️这个板块特别容易加戏，一定要看题目怎么描述就怎么想，不能把自己的主观想法加入题目再反馈给自己，那会改变出题意图。

### 客观说：一般人标准

    * **一般人标准**

        * > **定义**：判断彼时彼刻一般人会不会放弃；一般人不会放弃而行为人特意放弃是中止，一般人会放弃而行为人也放弃是未遂。

        * 适用条件：在"一般人会不会放弃"这一点上能形成广泛共识、得出几乎没有争议的结论。

        * 缺陷是标准模糊：有的说自己是"一般人"，有的认为一般人也会放弃，个案常有争议。

        * 认错人案：张三瞄准后才发现面前不是仇人李四而是路人王五，主观活动只字未提；一般人不会杀害与自己无冤无仇的路人，一般人会放弃、行为人也放弃，成立故意杀人罪未遂。

        * 强奸碰到亲妈案：彼时彼刻一般人几乎无争议地会放弃，行为人也放弃，成立强奸罪未遂。

    * **客观说的适用边界**

        * 生理期案存在争议：有人说"对方都生理期了还去强奸，禽兽不如"，马上有人反驳"那既然禽兽不如，你干嘛还去产生强奸念头、把人摁住反抗"。

        * 抢劫警察案存在争议：有人说对方是警察一般人当然放弃，也有人说"老子就是喜欢抢警察"；实务上正因为有对警察动手的情况才规定袭警罪。

        * 强奸校友案存在争议：有人说"那可是校友怎么能强奸校友"，也马上有人反驳"为什么不能强奸校友"；强奸案大多发生在熟人之间，客观说更得不出结论。

### 辅助标准三：担心当场被抓还是担心日后受罚

    * **辅助标准三**

        * > **定义**：以放弃动机的来源区分——担心当场被抓而放弃是犯罪未遂，担心日后受到惩罚而放弃是犯罪中止。

        * 理由：当场被抓意味着犯罪当场无法继续；日后受罚是日后的事情，不影响当下实施犯罪。

        * 适用评价：比较好用。

        * 未遂例证一：抢劫中压制被害人反抗时听到警笛由远及近、警车越来越近，拔腿逃跑。

        * 未遂例证二：入室盗窃翻箱倒柜时听到脚步声越来越近而翻窗逃跑，事后才知道来人是送外卖的。

        * 中止例证一：为报复社会而向学生食堂投毒，买了毒药后担心自己可能被判处死刑而放弃，成立投放危险物质罪中止。

        * 中止例证二：三人伺机抢劫，喷辣椒水、摁倒被害人后被害人喊"老子可是派出所的"，三人相视后分头逃窜，成立抢劫罪中止。

        * 可验证性：若警察此时已被三人控制住、眼睛被喷过辣椒水，他们本可轻而易举完成抢劫，可见其并非担心当场被抓。

        * 强奸校友案：已制服小花、脱衣卡脖子压制反抗，显然不是担心当场被抓，而是担心日后受罚，成立强奸罪中止。

### 兜底标准：假设不放弃能否较轻松成功

    * **假设检验**

        * > **定义**：纯客观的假设检验——不问行为人心里怎么想，只问"客观上他继续下去到底难不难"；无较大障碍是中止，有较大障碍是未遂。

        * 生理期案：假设他决定继续强奸，能不能成功？能，而且比较轻松，无较大障碍，成立强奸罪中止。

        * 硫酸脸案：扑倒、脱衣、卡脖子压制反抗后，借月光看见小花整张脸被硫酸灼伤，说"对不起，我错了"而放弃；假设继续能成功，成立强奸罪中止。

        * 互卡脖子案：与小花互卡脖子，被激烈反抗并被踢中要害后说"妈的，碰到你真倒霉，滚吧"而松手；假设继续强奸也未必能成功，面临较大障碍，成立强奸罪未遂。

        * 客观细节的作用：松手后张三又朝小花脸上打了一巴掌，这一记细微的客观证据证明其放弃强奸是心不甘情不愿，并非心甘情愿，进一步印证未遂。

        * > **注意**：判断有无较大障碍永远不要推演行为人的心理活动，案例事实越清楚障碍判断越准；障碍判断要贴合常识常理，不能凭"理论上再坚持一下也许能成"去虚构可能性空间。

        * 舌头案也印证常理：被咬掉舌头涉及大动脉出血，一般人面对此种情形必然会放弃，第二步客观说即可出活；即使认为仍有争议，向后推到第四步也因"舌头都被咬掉了"而存在较大障碍，结论仍是强奸罪未遂。

### 四步递进的适用规则

    * **过滤器而非投票器**

        | 判断标准 | 判断角度 | 什么时候能用 | 结论指向 |
        | :--- | :--- | :--- | :--- |
        | 主观说（弗兰克公式） | 行为人自以为能不能完成 | 题目清楚、具体地交代了主观心理活动 | 自以为能而放弃→中止；自以为不能而放弃→未遂 |
        | 客观说（一般人标准） | 一般人会不会放弃 | 能形成广泛共识、几乎没有争议 | 一般人也会放弃→未遂；一般人不放弃而行为人特意放弃→中止 |
        | 辅助标准三 | 行为人担心什么 | 前两步用不了时兜底 | 担心当场被抓→未遂；担心日后受罚→中止 |
        | 兜底标准 | 假设不放弃能否较轻松成功 | 前三步全部失灵 | 无较大障碍→中止；有较大障碍→未遂 |

        * 前三步只要有一步能给出确定答案，就地定案；只有前三步全部失灵才轮到第四步兜底。

        * 适用上不可跳跃：第一步能解决就不考虑第二步，第二步能解决就不考虑第三步，与因果关系"有因、有果、有关系"逐项判断同理。

        * 理论上没有任何一个观点能解决所有案例，每一步都有适用条件，所以必须一步步往后走。

### 动机、认识错误与遇到熟人

    * **放弃的动机**

        * 动机不重要，只要是自动放弃就可以。

        * 敌方一侧：对被害人怜悯、觉得她可怜而放弃，成立中止。

        * 我方一侧：出于真诚的悔悟而放弃，成立中止。

        * 第三方：犯罪过程中受别人规劝而放弃，成立中止。

        * 害怕受罚：担心犯罪后被追究、被鬼怪纠缠、被神灵谴责而放弃，属于"日后受罚"动机，成立中止。

    * **认识错误的排除**

        * 犯罪实际上能够进行到底，行为人误以为遭遇客观障碍、不可能进行到底而放弃的，不具有自动性。

        * 这属于行为人的认识错误，与主观说相通：自以为不能而放弃，成立犯罪未遂。

    * **遇到熟人**

        * 犯罪时遇到熟人而放弃，通常成立中止；但与熟人之间存在重大的伦理关系时，认定为未遂。

        * 强奸亲妈案：扑倒、脱衣、卡脖子压制反抗后借着月光发现是自己的亲妈，扶起亲妈道歉回家，一般人会放弃、行为人也放弃，成立强奸罪未遂。

        * 抢劫父亲案：偏僻之地伺机抢劫，把对方打倒、压制住反抗，借着月光发现是亲爸，把父亲扶起来；一般人不会继续抢，几无争议，人伦亲情构成自然而然的屏障，放弃完全是出于自动，成立抢劫罪中止。

## 成立条件之三：客观有效性

### 客观有效性的要求与阶段分界

    * **客观有效性**

        * 中止不仅仅是一种良好愿望，要求主客观相统一：客观上实施了中止行为，并有效防止了犯罪结果发生。

        * 犯罪行为所处阶段不同，成立中止所要求满足的条件必然有别。

```text
            张三毒杀李四（投毒杀人）

   A 点           B 点            C 点          D 点
  买毒药  ───▶  潜入房间  ───▶   投 毒  ───▶  毒发身亡
                    │
                    │  掏毒药、举向杯子
                    ▼
                 着手实行
  ────────────────────────────────────────────────────────
   着手之前放弃 ......... 预备阶段的中止（消极中止）
   着手之后、投毒之前放弃  实行阶段的中止（消极中止）
   投毒之后放弃 ......... 仅靠放弃不够，须另有积极举动
                          阻止结果发生（积极中止）
```

    * 分界在投毒之前与投毒之后。

        * 投毒之前：中止太简单，只要放弃投毒就能成立，是消极中止。

        * 投毒之后：毒药已经进去，单纯放弃不够，放弃以后还要有效防止李四被毒死、阻止犯罪结果发生，额外须有积极举动，是积极中止。

### 消极中止的彻底性

    * **彻底性**

        * > **定义**：彻底性指彻底放弃当次犯罪、本次犯罪，而不是暂时的中断；中止应当是彻底、无条件的，不能因条件、时机不成熟或环境不利而暂时中断。

        * 成立要件：客观上有放弃犯罪的行为、主观上有放弃犯罪的意图，且该放弃具有彻底性。

        * 休战十分钟案：压制反抗未果后提议"咱俩都休息十分钟，一会看谁能制服谁"并松手，属暂时中断，犯罪行为未终局性停止，此刻无从讨论形态；终局停止点是被趁机打晕，因意志以外原因未得逞，成立强奸罪未遂。

        * 杀马蜂案：抡刀冲进马家砍马蜂，一刀未中正想继续砍，见小马驹可爱、心生不忍而放弃，表明彻底放弃当次犯罪，成立故意杀人罪中止。

        * > **易错点**：⚠️彻底放弃不是要求行为人保证以后再也不犯罪，只要求彻底放弃当次、本次、当天那个具体犯罪；日后另起犯意实施的是独立犯罪（如一年后再杀马蜂成立故意杀人罪既遂），不影响前次中止的成立。

### 积极中止的双重要求

    * **积极中止的要求**

        * 主观上要尽到真挚的努力，即已尽力去防止结果发生。

        * 客观上要足以避免犯罪结果发生，这个行为从性质上、从程度上都要足以避免结果发生。

        * 创可贴案：砍断马腿刺中马腹致其流血不止后悔，买两个创可贴扔给马蜂让他自己动手，马蜂死在血泊中；扔创可贴不足以避免死亡结果，主观上也没有真正努力（应当送医院抢救），成立故意杀人罪既遂。

        * 爬山毒蛇案：与同学争执后把他推向毒蛇，见其腿部发紫变黑又背他下山赶往医院，途中对方死去；该行为本身根本不足以避免结果出现，成立故意杀人罪既遂。

        * 投毒案：甲投毒、李四已服毒，甲的杀人行为已经实行终了，单纯放弃不可能成立中止，必须采取积极举动如送医；李四被救活才成立故意杀人罪中止，抢救无效毒发身亡仍成立既遂。

### 有效性与因果关系

    * **有效性**

        * > **定义**：有效性指行为人必须有效地防止法定的犯罪结果发生，这个法定结果就是既遂结果。

        * 故意杀人罪对应的法定结果是死亡结果；有效防止死亡结果发生即成立中止，至于造成其他结果在所不问。

        * 砍成重伤后送医救活：重伤不是故意杀人罪的既遂结果，杀人过程中自动采取了积极行动并有效防止死亡结果发生，仍成立故意杀人罪中止。

        * "从性质上足以避免"之外，还要求从客观角度实际有效地防止既遂结果出现。

    * **因果关系要求**

        * 行为人自动放弃犯罪或者自动有效地防止犯罪结果发生，"结果没发生"要求中止行为对结果没发生要起到作用。

        * 中止行为与结果没发生之间没有因果关系，就根本不具备有效性，不符合中止特征，只能成立悔罪行为，在量刑时可以从宽考虑。

        * 投毒后借口买药递毒、事后索药未果而毒发身亡：主观上确实想放弃，但客观上没有采取积极行动有效防止死亡结果出现，杀人行为与死亡结果之间仍有因果关系，成立故意杀人罪既遂。

    * **两类中止的检验要点**

        * 消极中止看放弃犯罪的彻底性，具备彻底性即成立中止；没有彻底性就只是一种暂时的中断。

        * 积极中止看防止结果的有效性，要求行为对结果没发生起到作用；不满足有效性就不能成立中止，充其量在量刑时作为量刑情节考虑。

## 中止与预备、未遂的界分

### 界分规则

    * **界分规则**

        * 自动放弃，成立中止。

        * 被迫放弃看阶段：在预备阶段被迫放弃，成立犯罪预备；在实行阶段被迫放弃，成立犯罪未遂。

        * 归根结底关键还是对"自动性"的判断。

### 骗到宾馆并以散布不雅照相威胁

    * **真题案例**

        * 贾某将女同事汪某骗到宾馆，要求发生性关系，否则在网上散布其不雅照；汪某破口大骂，贾某觉得无趣，打消奸淫念头离去。

        * 以散布不雅照相威胁是强奸罪客观行为中的"胁迫"手段，强奸行为已经着手；着手以后无预备，排除预备。

        * 没有实际发生性关系，不可能构成既遂，排除既遂，只剩中止与未遂二选一。

        * 第一步：题目没有清楚交代贾某的主观心理活动，主观说得不出确定结论。

        * 第二步：面对破口大骂，一般人会不会放弃存在争议，"这么脏她就不做了""骂归骂我仍可继续"并存，得不出广泛共识。

        * 第三步：与担心当场被抓、日后受罚无关，看不出来。

        * 第四步：对方只是破口大开骂、未造成实质性障碍，且已把汪某骗到宾馆房间内，假设继续强奸能够成功。

        * 结论：自动放弃，成立犯罪中止。

### 同伙一个电话叫停撬保险柜

    * **真题案例**

        * 丁正在撬保险柜，其同伙打电话来告知保险柜中没有值钱的东西，丁离去。

        * 第一步：题目未清楚交代丁的主观心理活动，主观说解决不了。

        * 第二步：一般人正在偷东西时得知柜中无值钱之物，都会放弃，行为人也放弃，属于被迫放弃，成立未遂；到这一步即可定案。

        * 后续两步无需再走：放弃并非因为面临障碍，也不是担心被抓才放弃。

        * 结论：成立盗窃罪未遂。

        * > **注意**：不要加戏，不能设想"同伙是不是骗了丁"；题目怎么说就怎么想，偷东西时只能相信自己的同伙，不会去相信被害人。

## 中止犯的处罚

### 造成损害的两道门槛

    * **造成损害的含义**

        * 第一道门槛：必须是既遂结果以外的结果；损害若属既遂结果，直接认定为犯罪既遂。

        * 第二道门槛：必须是刑法明文规定的结果，而不是泛指一切结果；针对哪个罪名都可以，只要是该罪名刑法规定的结果。

    * **典型案例的解释**

        * 两个耳光案：砍人未中后朝被害人脸上打两个耳光，被害人说脸疼，因怕脏刀而放弃杀人；刑法没有哪个罪名保护一个人的脸，脸疼不是刑法规定的结果，属于没有造成损害的中止。

        * 免除的是刑事处罚，还可能有非刑罚的处理方法，免除刑罚不等于对行为人一概不处理。

        * 扒光衣服案：脱衣卡脖子时衣服已被扒光，因对方说恨他一辈子、次日结婚而道歉并给600元红包后放弃；扒光衣服本身就是刑法保护的一项内容，可构成强制猥亵、侮辱罪，造成了性羞耻感的侵害，属于造成损害的中止，应当减轻处罚。

        * > **易错点**：⚠️若认为扒光衣服后放弃不造成损害，等于为"沿街先扒光女性衣服、扒完即自动停止、反复实施且每次免除处罚"开辟一条绿色之路。

        * 敲诈案：敲诈他人财物，对方心生恐惧，交付财物时行为人悔意拒绝接受；敲诈要拿到钱才既遂，本罪尚未既遂，属本罪中止；仅让对方产生心理恐惧，单纯心理恐惧不是刑法规定的结果，属于没有造成损害的中止。

### 造成损害的原因

    * **原因要求**

        * 损害必须是先前的犯罪行为本身造成的。

        * 不能是终止行为造成的，也不能是中止以后的其他行为造成的。

        * 杀人罪造成损害的中止，损害一定是杀人行为本身造成；抢劫罪造成损害的中止，损害一定是抢劫行为本身造成。

    * **时序案例**

        * 砍成重伤后送医：杀人行为造成重伤在前，送医救活的终止行为在后，评价为故意杀人罪中止·造成损害·减轻处罚。

        * 放弃抢劫后逃跑踩伤：抢劫行为只把被害人打倒、压制反抗而无伤害，放弃在前，逃跑踩成粉碎性骨折在后；前半段评价为抢劫罪没有造成损害的中止（免除处罚），后半段评价为过失致人重伤罪，两个行为两个罪数罪并罚，最起码还要按过失致人重伤罪量刑。

        * 入户抢劫见十岁小孩：主动放弃，抢劫行为没有造成财产损失，但终止行为以前的犯罪行为已构成非法侵入住宅罪的结果，属于造成损害的中止，应当减轻处罚。

        * 女律师案：强奸中止以后，被害人才从包中拿出1000元交给行为人；该给钱不是强奸行为本身造成的，属于没有造成损害的中止。

        * 该1000元属民法上的不当得利——一方受损、一方获益，损益之间有因果关系但没有法律依据，不能直接评价为刑法意义上的"造成损害的中止"。

    * **中止行为本身不是犯罪行为**

        * 犯罪中止的中止行为是法律所鼓励的行为，其本身不是犯罪行为，而是对中止犯免除或者减轻处罚的依据。

        * 构成犯罪的是前面的犯罪行为加主观犯罪故意；把砍成重伤的被害人送往医院救活这类终止行为不是犯罪行为。

        * 这正是"损害只能由先前的犯罪行为造成"这一要求的原因所在。

## 危险犯的形态边界

### 放火罪的形态阶梯

```text
放火罪（危险犯）进程阶梯

  ①  买汽油、捡干柴
      准备工具、制造条件 —— 尚未着手
      ▼
  ②  泼汽油、掏打火机
      开始制造现实危险 —— 放火罪着手
      ▼
  ③  点着这堆干柴
      媒介物已燃，目标物尚未独立燃烧 —— 着手后未既遂
      ▼
  ④  目标物（房屋、门）能够独立燃烧
      制造出现实危险 —— 放火罪既遂
```

    * **阶梯的分界**

        * 危险犯有预备、未遂、中止、既遂的完整形态。

        * ①到②之间是"有没有着手"的分界，着手的标准是开始制造现实危险。

        * ②到④之间是"有没有既遂"的分界，既遂的标准是制造出现实危险。

        * > **易错点**：千万不要混淆"开始制造危险"和"制造出危险"，前者是危险犯的着手，后者才是它的既遂。

### 成立、着手、既遂三个层次

    * **三个层次**

        * 成立：客观上有可能制造出现实危险；不可能制造出现实危险的行为不构成该罪，如在空旷的水泥广场捡干柴点火烤火不可能危害公共安全，不构成放火罪。

        * 着手：开始制造现实危险，如汽油泼好、打火机掏出准备点火；开始制造危险与制造出危险之间仍有时间间隔。

        * 既遂：目标物已经脱离这堆干柴、能够独立燃烧；即便刚被点燃就被扑灭，也成立既遂。

        * 继续燃烧并造成严重后果的，构成结果加重犯。

    * **马蜂放火案的走向**

        * 刚把干柴堆在对方家门口即被抓：仍是准备行为，成立放火罪预备。

        * 干柴堆好后后悔抱柴离开：成立放火罪预备阶段的中止。

        * 掏出打火机第一声没点着、第二声就被抓，火都没点着：成立放火罪未遂。

        * 点着干柴但对方家的门尚未独立燃烧时被抓：成立放火罪未遂；此时后悔而把火浇灭，成立放火罪实行阶段的中止。

        * 已经引燃对方家的门：目标物可独立燃烧，成立放火罪既遂。

    * **破坏交通设施罪的情形**

        | 情形 | 评价 |
        | :--- | :--- |
        | 脱轨装置刚买回来就被抓 | 破坏交通设施罪预备 |
        | 买回来之后后悔，把脱轨装置给扔了 | 预备阶段的中止 |
        | 正在安装、还没装好就被发现 | 本罪未遂（已开始制造现实危险） |
        | 正在安装、还没装好时后悔又拆走 | 实行阶段的犯罪中止 |
        | 脱轨装置已经装好，刚装好走出去五米被抓 | 本罪既遂（火车随时可能经过，公共安全的现实危险已经造成） |

        * 破坏交通工具罪、破坏交通设施罪均属危险犯。

        * 危险犯的罪名范围：放火罪、决水罪、爆炸罪、投放危险物质罪、以危险方法危害公共安全罪、破坏交通工具罪、破坏交通设施罪、破坏电力设备罪、破坏易燃易爆设备罪。

### 各类犯罪的形态配置

    * **形态配置表**

        | 类型 | 典型 | 预备 | 未遂 | 中止 | 既遂 |
        | :--- | :--- | :--- | :--- | :--- | :--- |
        | 普通行为犯 | 绑架罪 | 有 | 有 | 有（预备中止、实行中止） | 有：法定行为实施完毕 |
        | 特殊行为犯·举动犯 | 煽动分裂国家罪 | 理论上有 | 无 | 只有预备阶段中止，无实行中止 | 有：一煽动即既遂 |
        | 特殊行为犯·情节犯 | 以"情节严重、情节恶劣"为构成要件的犯罪 | 不适用 | 不适用 | 不适用 | 只解决是否成立犯罪 |
        | 危险犯 | 放火罪 | 有 | 有 | 有（预备中止、实行中止） | 有：制造出现实危险 |
        | 实害犯 | 故意杀人罪 | 有 | 有 | 有（预备中止、实行中止） | 有：造成被害人死亡 |

    * **要点**

        * 普通行为犯形态齐全：购买绑架工具后被抓是预备，控制李四过程中被反绑是未遂，买了工具后主动放弃或抓住手腕又后悔是预备中止与实行中止，控制住李四即既遂。

        * 举动犯理论上可能有预备与预备阶段中止（写好演讲稿走向广场途中后悔回家），但没有未遂，也没有实行阶段的中止，因为一煽动就既遂。

        * 情节犯把"情节严重""情节恶劣"作为构成要件，只解决是否成立犯罪的问题，没有犯罪的未完成形态。

        * 实害犯形态齐全：买毒药是预备，砍两刀未中被抓是未遂，买后扔掉或中毒后送医救活是中止，造成被害人死亡是既遂。

        * 复习分则具体罪名时用总则理论直接推导：先看它是行为犯、危险犯还是实害犯，形态问题便可自行推出。
