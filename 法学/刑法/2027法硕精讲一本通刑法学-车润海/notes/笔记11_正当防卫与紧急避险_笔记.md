# 正当防卫与紧急避险

## 正当化事由的判断骨架

* **正当化事由**

    * > **定义**：虽然形式上符合某些犯罪的客观构成要件，但因不具有犯罪的社会危害性，依法不成立犯罪的情形。

    * 讨论一种现象在刑法上是否有罪，必须先"疑似犯罪"——看着要像犯罪；判断靠**主观、客观、形式、实质**四个指标。

    * 有罪要求两个统一同时满足：主观与客观相统一、形式与实质相统一。

    * 无罪只需一个统一不满足：主观或客观不满足，形式或实质不满足。

    * 四个指标不可能全部不满足，否则就不是疑似犯罪；于是无罪只剩"形式符合 + 实质不符合"。

    * > **结论**：入罪看形式，出罪看实质；入罪要合法，出罪要合理。

    * > **结论**：貌似犯罪，本质无罪；长着一张犯罪的脸，有着一颗善良的心。

    * 论证正当化事由的入口是"客观上长着犯罪的脸"；连犯罪外观都没有的行为，形式上即不符合任何构成要件，直接无罪。

* **正当化事由的分类**

    * 理论上的正当化事由五个：依照法律的行为、执行命令的行为、正当业务行为、经权利人承诺的行为、自救行为。

    * 法定的正当化事由两个：正当防卫、紧急避险。

| 口诀 | 事由 | 一句话 |
| :--- | :--- | :--- |
| 权利人 | 经权利人承诺的行为 | 有权者的有效承诺，使行为不再违法 |
| 执行 | 执行命令的行为 | 执行上级依法发布的命令 |
| 法律 | 依照法律的行为 | 有法律的明文依据 |
| 正当 | 正当业务行为 | 行业、职业、职务范围内的业务行为 |
| 自救 | 自救行为 | 等不及国家救助时，自己动手恢复法益 |

## 五个理论正当化事由

### 依照法律的行为

* 有法律的明文依据或明确依据而实施的行为。

    * 主观上要与客观相统一，行为人主观具有有益于社会的正当目的。

    * 实施的行为必须在法律规定的范围之内。

    * 彩票本质上是赌博，基于国家财政政策和法律规定发行即合法，不得认定为赌博罪。

    * 警察抓小偷、抓捕犯罪嫌疑人表面像非法拘禁罪，实为执法行为，不构成非法拘禁罪。

### 执行命令的行为

* 基于执行上级命令而实施的行为，条件不松。

    * 命令须由所属上级**依照职权并经法定程序依法发布**。

    * 执行命令以前，行为人已明确认识到该命令的合法有效性及对国家、社会的有益性。

    * 执行的行为必须在命令的范围之内。

    * 战场上消灭来犯敌人、执行死刑，均不构成故意杀人罪。

### 正当业务行为

* 为从事合法的**行业、职业、职务**活动而实施的行为；三个词范围由大到小、层层细分。

```text
  行业（最大）    法律行业：法院、检察院、律师事务所……
      |  按性质与分工往下分
      v
  职业（具体工种）  法官 / 检察官 / 律师 / 书记员
      |  再按职级与岗位往下分
      v
  职务（具体岗位）  主任 / 副主任 / 庭长 / 书记员
```

    * 所从事的业务必须合法。

    * 主观目的要具备正当性。

    * 不得超出必要的限度。

    * 医生遵守医疗规则对患者截肢，不构成故意伤害罪；拳击比赛遵守规则打伤对方，不构成故意伤害罪。

    * 反例：不遵守拳击规则咬掉他人耳朵，构成故意伤害罪；记者正常报道无罪，捏造事实诽谤他人则可能构成犯罪。

### 经权利人承诺的行为

* **经权利人承诺的行为**

    * > **定义**：得到权利人的承诺，对其实施的行为不再违法；经我的同意取走我的手机，不构成盗窃罪。

    * 五个条件可记为口诀"自愿、授权、合法、有益"；"权"含两层，故四字对五点。

| 关键词 | 具体要求 |
| :--- | :--- |
| 权 | 权利人有权处理其合法权益（含处分能力与处分限度） |
| 自愿 | 权利人的同意出于真实的意思表示 |
| 合法 | 权利人的同意合法或者合乎道德 |
| 授权 | 行为在权利人的授权范围内，且没有超出必要限度 |
| 有益 | 权利人的同意有益于社会 |

    * 自愿、合法、有益三项都在修饰权利人那一句同意；"授权"这项的"权"是行为人一侧的要求。

```text
  有权处分该利益 ──否──> 承诺无效，照常定罪
          |是
  有处分能力     ──否──> 同上
          |是
  未超必要限度   ──否──> 同上
          |是
  同意出于自愿真实 ──否──> 同上
          |是
  同意合法且有益  ──否──> 同上
          |是
  授权范围内且未超限 ──否──> 同上
          |是
  承诺在先未被撤回 ──否──> 事后承诺，无效
          v
    正当化：满足形式 + 缺乏实质
```

#### 权：有权处分且在限度之内

* 权利人没有同意的权利，该同意即无效；经无处分权者的同意侵入他人财产，仍构成盗窃罪。

    * > **结论**：任何人都不能处分国家、社会和他人的利益，只有权利处分自己的利益。

    * 经本人同意烧掉自己的房子，若危害邻居即危害公共安全，公共安全属社会利益，任何人无权承诺，仍认定为放火罪。

    * **财产、自由、名誉可以自由处分**：经同意取走全部财产不构成财产犯罪；经同意把人关进小黑屋一周不构成非法拘禁罪；经本人事先同意的辱骂不构成侮辱罪。

    * **身体权只能在轻伤范围内处分**，对重伤、死亡的承诺无效。

    * 按《人体损伤程度鉴定标准》，大拇指为**功能性手指**，缺失影响远大于小拇指。

    * 案例：妻子依"发现一次赌博砍掉一根手指"的保证书先后砍掉小拇指、中指、食指、大拇指，前四次每天的承诺均有效，第五次砍大拇指属重伤，承诺无效，妻子构成故意伤害罪。

    * > **易错点**：⚠️ 小拇指缺失属于轻伤，而轻伤的承诺是有效的，因此不能对小花认定为故意伤害罪。

    * 安乐死在我国未合法化，患者签了字也不影响医生成立故意杀人罪，因为对死亡的承诺无效。

    * 通过合法途径捐献人体器官可能出现重伤结果，该承诺有效，允许捐献。

| 法益 | 承诺的效力 |
| :--- | :--- |
| 自己的财产 | 自由处分，怎么处分都可以 |
| 自己的自由 | 可以承诺（如承诺关小黑屋一周） |
| 自己的名誉 | 可以承诺 |
| 身体：轻伤及以下 | 有效 |
| 身体：重伤、死亡 | 无效（合法途径捐献器官的除外） |
| 国家、社会、他人的利益 | 任何人无权承诺处分 |

#### 权：没有处分能力的人同意是空的

* 精神病人和幼儿没有处分能力；经精神病人同意发生性行为仍可能构成强奸罪。

    * 现行刑法规定未满 14 周岁的幼女没有性承诺能力，征得同意亦构成强奸罪。

    * 立法明文规定未成年人不能处分自己的身体器官，经其同意摘除器官仍认定为故意伤害罪、故意杀人罪。

#### 自愿：被骗、被迫都不算数

* 同意须出于真实的意思表示；基于被骗、被迫或开玩笑作出的承诺一律无效。

    * 以"选择死还是脱衣服"相胁迫取得的同意，行为人仍成立强奸罪。

    * 断电谎称全市停电、乘电梯被困者表面同意脱困，实为受骗，承诺无效。

    * 上海真实案例：冒充丈夫与睡梦中的妇女发生性行为，妇女一度以为是丈夫并应声"嗯"，系受骗，行为人构成强奸罪。

#### 合法、有益：同意本身也要干净

* 权利人的同意必须合法或合乎道德，不合法则该同意无效。

    * 权利人的同意还必须有益于社会。

#### 授权：不越权、不超限度，更不能先斩后奏

* 行为须在权利人的授权范围内且未超出必要限度。

    * **事后承诺无效，不能先斩后奏**：先取走手机事后被原谅的，仍构成盗窃罪；被害人谅解至多是酌定量刑情节，不影响定罪。

    * > **提示**："事后"要从事法规定的构成要件角度理解。

    * 夜跑女子遭强奸后反身骑在对方身上致其胯骨粉碎性骨折：强奸已既遂，事后同意不影响强奸罪成立；对该女子须主客观相统一，女子无法预见强壮男子胯骨如此脆弱，认定为意外事件，不构成过失犯罪。

    * 若对方事先明言自己骨质疏松、女子仍试坐致重伤，则可能构成过失致人重伤罪。

#### 承诺可以撤回

* 涉及人身利益的承诺可以变更，以**最后一次**为准。

    * 酒店初次见面时女方后悔反悔，男方仍违背其意志实施奸淫的，成立强奸罪。

### 自救行为

* **自救行为**

    * > **定义**：合法权益受到侵害的人，依靠自己的力量及时恢复法益，以防止其法益今后难以恢复。

    * 手机被偷后通过定位第二天守候截获小偷、夺回手机，成立自救行为；报警已来不及，若对方再逃跑手机可能被处理掉。

    * 与正当防卫的分界：当场发现、当场追上摁倒夺回财物的是正当防卫；非当场发现而事后追回的是自救行为。

    * 条件一：不法侵害已对自救人的合法权益造成损害。

    * 条件二：合法权益来不及或不可能自己恢复，情况比较紧急。

    * 条件三：主观上具有自救目的。

    * 条件四：自救行为具有相当性，未超出必要限度、只造成特定损害。

## 正当防卫的概念与条件体系

* **正当防卫（justifiable defense）**

    * 《刑法》第二十条第一款：为了使国家、公共利益，本人或者他人的人身、财产和其他权利免受**正在进行的不法侵害**，而采取的**制止不法侵害**的行为，对不法侵害人造成损害的，不负刑事责任。

    * 概念表述：为了使国家、公共利益，本人或者他人的人身、财产和其他权利免受正在进行的不法侵害，而对实施侵害的人所采取的合理的防卫行为。

    * 只能用于"长着犯罪脸"的行为：飞贼受惊坠亡时受害人在自家喊一声，直接按无罪处理；面对冲撞车辆单纯躲避，形式上本就无罪。

    * > **结论**：刑事入罪是实质出罪；形式上都不符合任何构成要件的，不需要正当防卫来出罪。

* **一般防卫的五项成立条件**

    * 起因条件：要有现实的不法侵害行为发生。

    * 时间条件：不法侵害要正在进行。

    * 对象条件：只能针对不法侵害人本人实行。

    * 主观条件：主观上具有保护合法权利的目的。

    * 限度条件：没有明显超过必要限度、造成重大损害。

```text
              限 时 观 象 起
              │  │  │  │  │
              │  │  │  │  └─ 起因条件：有现实的不法侵害行为发生
              │  │  │  └──── 对象条件：只能针对不法侵害人本人
              │  │  └──────── 主观条件：保护合法权利的目的
              │  └─────────── 时间条件：不法侵害正在进行
              └────────────── 限度条件：不明显超过必要限度、
                                 且造成重大损害
      谐音：限时观象棋 / 限制观象棋
```

    * 四个条件出自第一款： "正在进行"是时间条件，"不法侵害"是起因条件，"制止不法侵害的行为"推出对象条件，"为了使……免受"推出主观条件。

    * 限度条件出自第二款：不能明显超过必要限度、造成重大损害。

## 起因条件

* 客观上存在现实的不法侵害行为；既可以是侵犯生命健康的侵害，也可以是侵害自由、财产的侵害。

    * 司法解释要求不能把不法侵害不当限缩为暴力侵害或者犯罪行为；**违法行为同样可以成为防卫对象**。

    * 理由：违法行为与犯罪行为一线之隔，可能前两分钟是违法、紧接着发展为犯罪；也不能要求防卫人在现场精确判断这是违法还是犯罪。

    * "现实的不法侵害"须同时具备三大特征：**现实性、不法性、侵害性**。

### 现实性：假想防卫

* 客观上没有不法侵害、行为人误认为有，构成**假想防卫**，属于对行为性质的认识错误。

    * > **结论**：假想防卫无故意，不能构成故意犯罪；有过失的可能构成过失犯罪；无过失的属意外事件。

    * 甲见乙（自称执行公务的便衣警察）将丙摁倒地，误认为乙要伤害丙而将乙打成重伤，客观上无不法侵害，甲应审核对方身份却未审核，成立**过失致人重伤罪**。

    * > **易错点**：⚠️ 此案与"课题错误"案例极像但结论相反，核心区别在主观认识：误认为"斗殴"时行为人把双方视为对等侵害人、有伤害故意，定故意伤害罪；误认为"乙正在伤害丙"时行为人把乙视为侵害人、丙为受害人，无伤害故意，定过失致人重伤罪。

    * 甲夜班回家目睹男子将女子拉进小巷，推开男子后男子心脏病发作死亡；一般人无从预见，认定**意外事件**。

### 不法性：正对不正

* 只能对不法行为防卫，对合法行为不能防卫；正当防卫的本质是**正对不正**。

    * 警察抓小偷，小偷不能对警察正当防卫；否则社会秩序大乱。

    * 但并非对所有不法行为都能防卫：还须同时具备**进攻性、破坏性、紧迫性**，其中关键是**紧迫性**。

    * 两个法律谚语支撑紧迫性要求：**紧急时无法律**——紧急状态下可以实施通常被禁止的行为；以暴制暴，理所当然——对方使用暴力即可暴力反击。

    * 反例：行贿受贿只有行贿人与受贿人当场面对面时才具有紧迫性，刑法将其作为平和性犯罪处理，因此不能对该行为实行正当防卫；重婚罪同此。

    * > **结论**：紧急时无法律；不紧急就不能行使正当防卫权。

    * 正例：甲发现乙偷走自己手机立即上前夺回，具有紧迫性——若不制止，财物之后可能很难挽回。

    * 防卫人不限于本人：见义勇为保护他人利益，阻止他人强奸行为而踢成重伤，成立正当防卫。

    * 不法侵害可以针对本人、针对他人，也可以危害国家、公共利益；乘客殴打正在驾车的司机危害公共安全，将其制服成立正当防卫。

    * "黑吃黑"可以防卫：明知对方运输假币而抢走，运输者仍可对该抢劫行为正当防卫。

### 侵害性：对故意、过失、不作为都能防卫

* 该行为须具有社会危害性；对**故意**的不法侵害能防卫，对**过失**的不法侵害同样能防卫。

    * 张三在李四（聋哑人）即将扣动扳机时开枪打伤其胳膊，制止其误伤他人，成立正当防卫。

    * 对不作为犯罪，满足紧迫性也能防卫：父亲会游泳却溺毙儿子，路人不会游泳只能逼其施救，对父亲使用暴力成立正当防卫。

    * 司法解释规定：对未达刑事责任年龄的人、精神病人的不法侵害，可以实行正当防卫。

## 时间条件

* **正在进行**：不法侵害已经开始、尚未结束，且对客体造成了**紧迫的危险**。

```text
      A 点                              B 点
       ●━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━●
       │                                │
   【起点】已经着手                【终点】尚未完全结束
  对客体形成现实紧迫的危险      客体仍面临紧迫危险
       │                                │
       │◀━━━━━━━━ 防卫适时 ━━━━━━━━━━━━▶│
       │
   事前防卫                        事后防卫
  （防卫不适时）                  （防卫不适时）
  A 点之前不能防卫                 B 点之后不能防卫
```

### 起点：现实紧迫的危险才是"已经着手"

* 已经开始的标准是**不法侵害已对客体形成现实紧迫的危险**；仍处预备阶段或犯意表示阶段则不能防卫。

    * 预知他人今晚来杀而中午守候门口、其一出门即开枪，属**事前防卫**，认定为故意杀人罪。

    * 尾随被害人、举刀要砍时才形成现实紧迫危险，被害人此时可以防卫。

    * > **易错点**：⚠️ 不能提前**防卫**，但可以提前**做准备**；在家提前备刀不违反时间条件，等对方来侵害时再反击仍成立正当防卫。

    * 防卫装置成立正当防卫须同时满足：**手段要相当**、**不能危害公共安全**。

    * 防盗门后装弩、按自己的身高把弩调到对方腿部，致来人轻伤，成立正当防卫；把弩调到心脏位置致人死亡，盗窃本是平和性犯罪而手段致人死亡，成立防卫过当。

    * 在公共空间拉高压电网并挂"随时通电"牌子，致小孩触电死亡，危害公共安全，认定为以危险方法危害公共安全罪。

### 终点：必须站在行为时立场判断

* 侵害人**确已丧失侵害能力**或者**确已放弃不法侵害**的，认定不法侵害已经结束。

    * 结束的判断须**站在行为人的立场**，结合**社会公众的一般认知**作出合乎情理的判断；不能苛求防卫人，更不能站在事后的立场判断。

    * > **结论**：事后判断是一种"上帝视角"；不法侵害是否结束必须站在行为人行为时的立场、按社会公众的一般认知判断。

    * 江苏昆山宝马车案：男子持 59 厘米双面开刃砍刀攻击骑车人并夺刀，被害人捡刀反击，一刀伤及其大动脉；对方转身跑向白色宝马时被追砍致死。检察机关提前介入、两天后认定成立正当防卫并无罪释放。

    * 该案之所以不能认定为事后防卫或防卫过当：站在防卫人立场，对方跑回宝马仍可能取出其他凶器、驾车逃逸或撞击报复，主动权随时可能易手，紧迫危险并未解除。

    * 若要求事后判断，等于要求防卫人精确区分哪一刀砍中、砍中后伤情如何，等于要求其每次反击前先问对方安好——这将架空正当防卫制度。

    * 正当防卫在判案中援引概率不高，历来被称为"**僵尸法条**"：认定防卫意味着民事上也不承担赔偿责任，与被害方家属的期待冲突；其制度激活上承山东于欢案、下启福建赵宇案。

### 财产犯罪的例外：时间具有持续性

* 财产犯罪中侵害人虽已取得财物，但通过**追赶、阻击**等措施能够追回的，**视为不法侵害正在进行**，可以实行防卫。

    * 第一条件：时间具有持续性——当场发现当场追，哪怕追出 10 公里仍属正在进行。

    * 第二条件：现场具有延伸性——次日靠定位找到小偷夺回财物，时间无持续性，只能评价为自救行为。

### 暂时中断的侵害仍然算正在进行

* 不法侵害虽暂时中断或被暂时制止，但侵害人**仍具有实施不法侵害的现实可能性**的，认定为正在进行。

    * 张三拳打脚踢打伤李四后自称"休息 5 分钟接着揍"，侵害并未结束。

### 防卫不适时的处理

* A 点之前防卫为事前防卫、B 点之后防卫为事后防卫，合称**防卫不适时**。

    * 可能构成故意犯罪、过失犯罪，也可能构成意外事件。

    * 故意犯罪中最常见的是抓小偷：小偷已被抓在手里甚至捆起来后继续殴打，属事后防卫，打伤即构成故意伤害罪。

    * 过失犯罪的例子：乙持刀尾随丁，为制止丙行凶本想驾车将丙撞成轻微伤，误将油门当刹车撞成重伤；因不法侵害尚未形成现实紧迫危险，属事前防卫，认定为过失致人重伤罪。

    * 若上述情形中改为刹车突然失灵，一般人难以预见，认定为意外事件。

## 对象条件

* 防卫行为**只能针对不法侵害人本人**实施。

    * 既可针对不法侵害人的人身，也可针对其使用的工具；恶狗是主人犯罪意志的载体、是**犯罪工具**而非共犯，打死恶狗与殴打主人同样成立正当防卫。

    * 共同不法侵害中，对现场所有不法侵害人原则上均可防卫：两人分持砍刀左右夹击，对其中任何一人的反击都成立正当防卫。

---

## 主观条件

* 必须基于**保护合法权利、免受不法侵害**的目的；防卫目的的正当性既是成立正当防卫的**首要条件**，也是行为人不负刑事责任的重要根据。

    * 缺乏防卫意图则不成立正当防卫，典型有防卫挑拨、相互斗殴、偶然防卫、滥用防卫权。

### 防卫挑拨

* > **定义**：以正当防卫为名行故意犯罪之时；名义上像防卫，本质仍是故意犯罪，行为人主观上只有加害目的而无保护目的。

    * 故意先激怒对方、待对方先动手后假借防卫之名打伤打死对方的，成立故意伤害罪或故意杀人罪。

### 相互斗殴

* 相互斗殴原则上不成立正当防卫，谚语称"**斗殴无防卫**"；原因是斗殴各方主观目的都是加害对方。

    * 例外一：因琐事争执、双方均不能克制引发打斗，有过错一方先动手且手段明显过激，或一方先动手而在对方努力避免冲突时仍继续侵害的，还击方一般认定为正当防卫。

    * 例外二：因琐事冲突结束后一方又实施不法侵害，对方还击（包括使用工具环节）一般认定为防卫行为；提前准备工具不影响防卫意图的认定，如警察到场将双方隔离后再实施击打，对方仍可反击。

### 偶然防卫

* > **定义**：行为人在实施侵害他人的行为时，其客观行为制止了他人正在进行的不法侵害。

    * 客观上制止了不法侵害，主观上没有制止意图，主客观在此处不统一，因不满足主观条件而不能成立正当防卫。

    * 例一：与他人共同杀人时一刀砍死同伙、致同伙另一同伙逃走，客观制止了不法侵害但无防卫意图；按主客观相统一，认定为故意杀人既遂。

    * 例二：抢劫时砍伤同伙致死，认定抢劫致人死亡。

### 滥用防卫权

* 对**显著轻微的不法侵害**，行为人在可以辨识的情况下直接使用足以致人重伤、死亡的方式制止的，不能认定为防卫行为。

    * 侵害须从性质上看是不法侵害但显著轻微；行为人须处于可以辨识状态；手段直接致重伤或死亡。

    * 常见情形是打耳光：对方打一巴掌泄愤并准备离开，被害人一刀捅成重伤的，不具有防卫性质，认定为故意伤害罪。

    * 司法解释第二点：不法侵害由行为人的**重大过错**引发，行为人在可以使用其他手段避免侵害的情况下，仍故意使用足以致人重伤或死亡的方式还击的，不能认定为防卫行为；如捉奸在床者手无寸铁只打耳光打拳，被害人升级手段还击即不得认定为防卫。

## 限度条件

* 防卫行为不能**明显超过必要限度**、造成**重大损害**。

    * 判断应综合考虑两方面的情节，并考虑双方的力量对比。

    * 立足防卫人防卫时所处情境，结合社会公众的一般认知作出判断。

    * 危害程度的判断**不仅**考虑已造成的损害，还要考虑进一步损害的**紧迫危险性和现实可能性**。

    * 不能苛求防卫人采取与不法侵害基本相当的方式和强度；经综合考量，相差悬殊、明显过激的，也认定为明显超过必要限度。

    * "造成重大损害"指造成不法侵害人**重伤、死亡**；造成**轻伤及以下**不属于重大损害。

    * > **结论**：**轻伤无过当**；仅造成轻伤不可能构成防卫过当。

    * 一般防卫中造成死亡结果不必然是防卫过当：如对方殴打时只推一把致其后脑着地摔死，防卫手段未明显超过必要限度，仍成立正当防卫。

| 防卫手段（质） | 防卫结果（量） | 结论 |
| :--- | :--- | :--- |
| 明显超过必要限度 | 未造成重大损害 | 仍成立**正当防卫** |
| 未明显超过必要限度 | 造成重大损害 | 仍成立**正当防卫** |
| 明显超过必要限度 | 造成重大损害 | **防卫过当**，应负刑事责任，但应当减轻或者免除处罚 |

    * 对方撬锁偷自行车时，行为人直接举枪射击未打中：手段明显超过必要限度，但未造成重大损害，仍成立正当防卫。

## 防卫过当与事后防卫

* **防卫过当**

    * > **定义**：正当防卫明显超过必要限度、造成重大损害的行为。

    * > **结论**：防卫过当仅仅是不满足正当防卫的**最后一个条件（限度条件）**，其余起因、时间、对象、主观四条件全部满足，因此仍具有防卫的性质。

    * 罪过可以对造成的重大损害为**过失或间接故意，但不能是直接故意**；防卫目的正当与直接故意的坏目的相互排斥、水火不容。

    * > **结论**：防卫过当是法定的从宽处罚情节（应当减轻或者免除处罚），但不是独立的罪名；符合哪个罪的构成就定哪个罪，如故意杀人罪、故意伤害罪。

    * > **结论**：防卫过当不可能构成意外事件；意外事件无罪过、不构成犯罪，而防卫过当以成立犯罪为前提。

* **事后防卫**

    * 不满足正当防卫的**时间条件**，不法侵害已彻底结束后仍加害对方的行为。

    * 例：强奸结束后女方为报复抡砖头将对方砸成重伤，认定为事后防卫，成立故意伤害罪；因案件由被害方重大过错引发，量刑可作酌定区别。

| 比较项 | 防卫过当 | 事后防卫 |
| :--- | :--- | :--- |
| 不满足的条件 | 限度条件 | 时间条件 |
| 罪过 | 故意或过失均可 | 通常是故意犯罪 |
| 责任 | 法定的量刑情节，应当减轻或免除处罚 | 酌定的量刑情节 |

---

## 特别防卫

* **特别防卫（special defense）**

    * 法条：对正在进行行凶、杀人、强奸、抢劫、绑架以及其他严重危及人身安全的暴力犯罪，采取防卫行为，造成不法侵害人伤亡的，不属于防卫过当，不负刑事责任。

    * > **结论**：特别防卫仍须满足一般防卫的起因、时间、对象、主观条件，唯独不要求满足限度条件。

    * > **结论**：**特别防卫无过当**；符合特别防卫条件的，当场将人打死也成立正当防卫。

### 适用条件：罪名不重要，本质是关键

* 只有同时满足两个本质特征才可特别防卫：**严重危及人身安全**、**属于暴力犯罪**。

    * "严重危及人身安全"指具有导致**死亡或者重伤的紧迫危险性**；没有这种紧迫危险即不能特别防卫。

    * "暴力犯罪"指对人的身体使用暴力；对非暴力犯罪只能一般防卫，如骗奸、迷奸、昏奸。

    * 前提是不满足特别防卫条件的，可以进行一般防卫。

* **行凶**

    * > **定义**：杀伤界限不明（到底想杀人还是想伤害不清楚），但严重危及人身安全的侵害行为。

    * 使用致命性凶器严重危及人身安全。

    * 未使用凶器或未使用致命性凶器，但依各种情况已严重危及人身安全。

    * 虽未造成伤害，但已对人身安全造成严重紧迫危险。

    * > **易错点**：⚠️ 行凶**未必要求使用凶器**；朝人头部拳打脚踢、力度较大，同样严重危及人身安全，同样是行凶。

* **五类罪名的边界**

    * **杀人**：不包括非暴力手段的故意杀人，如投毒杀人只能一般防卫；包括转化型故意杀人，如非法拘禁过程中使用暴力致人死亡，符合条件可特别防卫。

    * **抢劫**：不包括非暴力手段的抢劫，如麻醉抢劫、迷药或灌醉后取财，只能一般防卫；包括以暴力方式抢劫枪支、弹药、爆炸物；不包括携带凶器抢夺拟制的抢劫——该行为本质是抢夺，只夺走财物未对身体直接使用暴力，只能一般防卫。

    * **强奸**：不包括非暴力强奸（昏奸、迷奸、骗奸）；包括拐卖妇女中的暴力强奸。

    * **绑架**：仅限于暴力绑架。

    * **其他严重危及人身安全的暴力犯罪**：指与杀人、抢劫、强奸、绑架行为相当，具有致人重伤或者死亡的紧迫危险、现实可能的暴力犯罪；司法解释举出以暴力手段抢劫枪支弹药爆炸物、以绑架手段拐卖妇女儿童。

    * > **提示**：某行为"法律上被拟制为抢劫罪"，不等于它就是条文所说的"抢劫"这一行为；特别防卫的适用始终要回到"严重危及人身安全 + 暴力犯罪"两个实质条件。

    * > **结论**：千万不要记罪名，**罪名不重要，本质是关键**。

* **同类解释规则**

    * 法条把行凶、杀人、强奸、抢劫、绑架并列，表明它们属于同一类，须共同满足"严重危及人身安全"与"暴力犯罪"两个指标。

    * > **提示**：法条所列"行凶、杀人、强奸、抢劫、绑架"指的是**具体的犯罪行为**，而不是**具体的罪名**。

## 正当防卫的判断步骤

* **三步判断框架**

```text
第一步  客观上有无不法侵害？
        ├─ 有 ──► 排除假想防卫
        │          假想防卫 = 客观上没有不法侵害，行为人误认为有
第二步  不法侵害是否正在进行？
        ├─ 是 ──► 排除防卫不适时
        │          事前防卫（尚未开始）／事后防卫（已经结束）
第三步  质和量是否过当？
        ├─ 质：防卫手段有没有「明显超过必要限度」
        └─ 量：有没有造成重大损害（致人重伤、死亡）
                 ├─ 质不过当 或 量不过当 ──► 正当防卫
                 └─ 质过当 且 量过当   ──► 防卫过当
```

    * 第一步排除假想防卫；第二步排除事前防卫与事后防卫。

    * 第三步中量的问题简单：造成重大损害指致人重伤、死亡，故**轻伤无过当**，重伤、死亡才可能出现防卫过当。

* **逆向思维判定"质"**

    * 司法解释只给出"综合对比、明显过激、相差悬殊"等精神，缺乏细化指标，"在制止不法侵害必需的范围内"等理论表述也无可操作性；正面推导很难突破，应采取**逆向思维**。

    * > **定义**：特殊防卫手段，指只能在特别防卫时使用的手段，具有高度危险性，致死致伤概率相对较高。

    * 第一步：先锁定防卫手段的性质，判断是一般防卫手段还是特殊防卫手段。

    * 第二步：若为一般手段，不可能明显超过必要限度，故"质"不过当；即使造成严重后果也仍成立正当防卫（如只是推一把致对方摔死）。

    * 第三步：若为特殊手段，看所面对的是一般侵害还是特殊侵害（严重危及人身安全的暴力犯罪）。

    * 特殊手段 + 特殊侵害 → 不过当，特别防卫无过当。

    * 特殊手段 + 一般侵害 → 手段明显过激、相差悬殊，"质"过当；再结合量判断。

| 防卫手段 | 所针对的侵害 | 手段（质）是否过当 | 最终结论 |
| :--- | :--- | :--- | :--- |
| 一般手段 | 一般侵害 | 不过当 | 即使重伤、死亡，也是正当防卫 |
| 特殊手段 | 特殊侵害 | 不过当 | 特别防卫无过当，仍是正当防卫 |
| 特殊手段 | 一般侵害 | 过当 | 轻伤→正当防卫；重伤、死亡→防卫过当 |

* **推演：被拘禁十几个小时后的一刀**

    * 债权人王某伙同他人将债务人甲关在办公室长达十几个小时并持续辱骂，甲求救未果后持水果刀将王某刺成重伤。

    * 第一步：客观上存在不法侵害，至少构成非法拘禁，排除假想防卫。

    * 第二步：非法拘禁是持续过程，不法侵害正在进行，排除防卫不适时。

    * 第三步看量：致人重伤，属重大损害，量可能过当；关键看质。

    * 手段：持水果刀故意捅刺，属特殊手段；所针对的侵害只有关押、辱骂，未动手、未殴打，不属于严重危及人身安全的暴力犯罪，属一般侵害。

    * 特殊手段 + 一般侵害 → 手段明显过当、相差悬殊，质过当；质和量都过当，成立**防卫过当**。

    * > **提示**：甲求救未果是为了恢复人身自由，主观上有保护合法权利的意图，故不成立偶然防卫；全题唯一有争议的只有"防卫手段有没有明显超过必要限度"这一点。

* **推演：夺刀反击后追砍致死**

    * 行凶者持刀攻击骑车人并夺刀，被害人捡刀反击致其大动脉受伤；行凶者跑回白色宝马，被害人追砍两刀。

    * 第一步：客观上面临不法侵害，排除假想防卫。

    * 第二步：站在行为人行为时的立场，行凶者一旦控制白色宝马即可选择继续侵害，紧迫危险仍在，排除防卫不适时。

    * 第三步：防卫手段是直接持刀砍击，属特殊手段；所针对的行凶是严重危及人身安全的暴力犯罪，属特殊侵害，特殊手段针对特殊侵害无过当。

    * > **结论**：成立**正当防卫**；只有"质过当"**且**"量也过当"才属于防卫过当。

## 缺哪个条件就叫什么

* 缺乏**起因条件** → **假想防卫**。客观上没有不法侵害而误认为有，可能构成过失犯罪或意外事件，结论固定无争议。

* 缺乏**时间条件** → **防卫不适时**，含事前防卫与事后防卫；它并不是法定的从宽处罚情节，只是酌定情节。

* 缺乏**对象条件** → 不成立正当防卫。防卫人因对方强壮而逃到对方家中殴打其妻，起不到制止不法侵害的效果，与防卫无关。

* 缺乏**主观条件**而实施防卫 → 偶然防卫、防卫挑拨、相互斗殴、滥用防卫权，可能构成故意、过失或意外事件。

* 缺乏**限度条件** → **防卫过当**，可能构成故意犯罪或过失犯罪，但不可能是直接故意。

    * > **结论**：上述五种情形中，**只有防卫过当属于法律规定的法定从宽处罚情节**，其他都至多是酌定情节。

    * > **结论**：防卫过当不可能构成意外事件——《刑法》第二十条第二款明确规定其应当负刑事责任，故以成立犯罪为前提。

* **前后两段两个定性的入库案例**

    * 持刀者边追边掷刀、击伤对方手臂，被害者持铁棍反击将其打倒在地——此段成立正当防卫。

    * 被害人随后离开现场寻找掉落手机，表明其防卫行为已经结束；找回手机后持铁棍返回现场，见对方起身即在围观群众多次阻拦下仍连续击打致其头部出血倒地，经鉴定造成轻伤——此段成立**事后防卫，定故意伤害罪**。

    * > **易错点**：⚠️ 后一段为什么不是假想防卫？假想防卫是**事实认识错误**（客观上无侵害而误认为有）；本案行为人并未产生认识错误，只是侵害已经结束后仍继续加害。

## 紧急避险的概念与条件体系

* **紧急避险（necessity）**

    * 《刑法》第二十一条第一款：为了使国家公共利益、本人或者他人的人身、财产和其他权利免受正在发生的危险，**不得已**采取的紧急避险行为，造成损害的，不负刑事责任。

    * 概念表述：为了使国家公共利益、本人或者他人的人身和其他权利免受正在发生的危险，**不得已**而采取的损害**另一较小合法利益**的行为。

    * 命门在"**不得已**"三个字：不是"情况紧急就可以"，而是"除了这条路没有别的路才可以"。

    * 本质是**正对正**：为保护较大的正当利益，不得不损害他人较小的正当利益，综合评价对社会整体有益，因而没有社会危害性。

    * 比喻：疯狗咬人时闯入张三家躲避、关狗于门外，牺牲住宅安宁权保全生命权，不构成非法侵入住宅罪；保全价值 100 万的财物而损害他人价值 20 万的财物，同样成立紧急避险。

    * > **提示**：刑事责任上不赔，民事上该赔还是要赔；紧急避险免除的是刑事责任，不是民事赔偿责任。

    * 成立条件是 **5＋2**：与正当防卫同构的五项基本条件，加上紧急避险独有的两项限制条件。

```text
                 紧急避险的成立条件
                         │
        ┌────────────────┴────────────────┐
   五项基本条件                       两项特别限制
  起因 / 时间 / 对象 / 主观 / 限度   ① 迫不得已（唯一途径）
                                     ② 职务、业务特定责任人排除
```

    * 多出的第一项正源于"正对正"：要损害的是他人正当利益，值得法律保护，故要求迫不得已。

## 紧急避险的成立条件

### 起因条件：面临现实的危险

* > **定义**：危险，指某种有可能立即对合法权益造成危害的紧迫事实状态，即对合法利益造成紧迫的危险。

    * 危险来源多样，人的不法侵害、动物侵袭、生理病患、自然力量（火山、地震、海啸、龙卷风）都可能成为诱因。

    * 面对人的不法侵害：正面反击成立正当防卫，躲入他人家里构成紧急避险——同一个危险，两条出路。

    * 动物侵袭以**自发侵袭**为限：野狗自发咬人，打死它成立紧急避险；被主人驱使的恶狗，打死它成立正当防卫，因为是在制止马蜂的不法侵害。

    * 杀伤特定人的动物仍可能成立紧急避险：野生动物资源属国家所有，打死袭击自己的老虎是为保护生命权而牺牲国家合法利益。

    * 没有侵犯任何人的正当利益则无从正当化：打死一只蚊子看着不像犯罪，直接无罪，不需要紧急避险评价。

    * 人的生理病患同样可成为诱因：为救突发心脏病的父亲砸开他人车窗取出车内除颤器，保全生命权、毁坏他人财产，成立紧急避险，不构成故意毁坏财物罪；为抢救重伤员强行拦截、开走他人汽车送医的，同理。

* **假想避险**

    * 客观上没有危险、行为人误认为有，构成**假想避险**，与假想防卫同理。

    * > **结论**：假想避险与假想防卫都没有犯罪故意；有过失的可能构成过失犯罪，无过失的可能成立意外事件；且过失犯罪须法律有规定才负刑事责任。

    * 被普通蛇咬后误认为毒蛇而抢夺他人摩托车就医，医生查出无毒：客观上无生命危险，构成假想避险，没有抢夺故意，法律又无过失抢夺罪，故无罪。

### 时间条件：危险正在发生

* 危险须已经开始、尚未结束，客体正遭受紧迫危险；不满足时称为**避险不适时**，分事前避险与事后避险。

    * 可能构成故意犯罪、过失犯罪，也可能构成意外事件。

    * 邻居家失火无人，张三从楼上往其家泼水灭火是为保护公共安全，成立紧急避险；火扑灭后仍继续泼水致楼下邻居家具、电器泡坏，属**事后避险**，后半段认定故意毁坏财物罪。

### 对象条件

* 只能损害**第三人的合法利益**；这是"正对正"的直接推论。

    * 通过损害无辜者的合法利益，保全更大的国家公共利益、本人和他人的合法利益。

    * 针对不法侵害人本人进行反击的，与紧急避险无关，直接认定正当防卫。

### 主观条件

* 必须具有保护合法权利、免受危险的目的，包括**避险认识**与**避险意志**。

    * > **易错点**：⚠️ 为保护非法利益不可能成立紧急避险；歹徒为躲避警察抓捕闯入他人住宅，保护的不是合法利益，可构成非法侵入住宅罪。

* **偶然避险**

    * 客观上避免了危险、主观上没有避险意图的，主流观点不成立紧急避险。

    * 例：为报复砸坏他人迈巴赫车窗，砸后才发现车内有将闷死的儿童并恰巧救出——主观只有毁坏财物故意，无避险意图，成立故意毁坏财物罪。

    * 研究生考试采取本土通说，观点简单：主观有犯罪故意、客观毁坏财物造成他人财产损失，缺乏避险意图即构成故意毁坏财物罪。

### 迫不得已

* > **定义**：迫不得已，指采取紧急避险是唯一途径、别无选择。

    * 只要还有其他方法能避免危险，就不能采取紧急避险方法，因为所损害的第三人合法利益值得保护。

    * 不满足迫不得已的，该定罪定罪，可能构成故意犯罪、过失犯罪。

### 限度条件

* 避险行为不能超过必要限度、造成不应有的损害；超过的应负刑事责任，但**应当减轻或免除处罚**。

    * 避险造成的损害**大于或等于**所保护的利益，即超出必要限度、造成不应有的损害；等于也不行。

    * 利益大小比较规则：

    * 人身权利大于财产权利。

    * 人身权利内部生命权最高；每个人的生命平等等价、不可交换，不能以牺牲他人生命来保全自己的生命。

    * 巨轮沉没只有一块木板，杰克把 rose 推下自己躺上，rose 淹死杰克幸存，不能成立紧急避险，起因、时间、对象、主观条件均满足而唯独不满足限度条件，认定为**避险过当**，按故意杀人罪减轻或免除处罚。

    * 财产权利按价值大小比较，并须综合判断：为扑灭仓库大火抽用邻居鱼塘之水，救下价值 5 万财物并同时保护了仓库本身与公共安全，保护的利益大于造成的损害，成立紧急避险；不能只看 5 万这一个数额。

    * 公共利益并非永远高于个人利益；公共利益与个人利益不能两全时，依权益的性质及其内容确立大小。

    * 醉酒者驾驶他人摩托车把重伤昏迷的两人送往医院，侵害公共安全，但保护的是二人生命，且只造成抽象危险，成立紧急避险。

    * 同样情形若两人已当场身亡，运往殡仪馆可等待数小时或一天，不须急速醉驾，不成立紧急避险，认定为**危险驾驶罪**。

    * 正当防卫的损害可以大于不法侵害人可能造成的损害（200 元钱包的盗窃被反击打成轻伤仍成立正当防卫，轻伤无过当）；紧急避险则必须**严格小于**所保护的利益。

### 主体例外

* 第一款关于避免**本人危险**的规定，不适用于**职务上、业务上负有特定责任的人**。

    * 因为其职务内容就是与该危险作斗争：军人面对敌人、警察面对歹徒、医生面对手术感染风险、消防员面对火灾、民航客机机组成员面对坠机危险，均须坚守岗位，不能率先逃生避险。

### 避险过当

* **避险过当**：避险行为超过必要限度、造成不应有的损害。

    * 成立结构与防卫过当几乎一样：客观上造成不应有的损害（损害大于或等于所保护的利益），主观上对不应有的损害存在应受责备的罪过。

    * 罪过形式与防卫过当相同：可能是**过失**、可能是**间接故意**，但**不能是直接故意**；避险意图是正当目的，与直接故意水火不容。

    * > **易错点**：⚠️ 防卫过当与避险过当都要求有罪过，要么间接故意、要么过失，都不能是直接故意。

    * 本身不是罪名，没有防卫过当罪、避险过当罪；性质上属于**法定的减轻和免除处罚情节**。

| | 正当防卫 | 紧急避险 |
| :--- | :--- | :--- |
| 限度表述 | 不能**明显**超过必要限度 | 不能超过必要限度 |
| 损害结果 | 造成**重大**损害 | 造成**不应有**的损害 |

    * 立法者对防卫人更宽容：防卫是正对不正、**法不得向不法让步**；紧急避险是正对正，损害的也是正当利益，要求更严，避险人更容易过当。

## 防卫与避险的对照

| | 正当防卫 | 紧急避险 |
| :--- | :--- | :--- |
| 危险来源 | 只能是人的不法侵害 | 人的不法侵害、动物侵袭、生理病理、自然力量等 |
| 损害对象 | 不法侵害人本人 | 第三人的合法利益 |
| 限制条件 | 没有"迫不得已"的限制 | 必须迫不得已（唯一途径、别无选择） |
| 损害程度要求 | 造成的损害可以大于不法侵害人可能造成的损害 | 损害的合法利益必须小于所保护的合法利益 |
| 主体限定 | 每个公民的权利 | 不适用于职务上、业务上负有特定责任的人 |

* 三个相同：前提相同、目的相同、责任相同；五个不同：对象、损害程度要求、危害来源、主体限定、限制条件不同。

* **条件对照总表**

| 条件 | 正当防卫 | 紧急避险 |
| :--- | :--- | :--- |
| 前提 | 面临人的不法侵害 | 面临现实危险（来源多样） |
| 起因条件 | 客观上没有不法侵害而人为有：假想防卫 | 客观上没有危险而人为有：假想避险 |
| 时间条件 | 防卫不适时：事前防卫、事后防卫 | 避险不适时：事前避险、事后避险 |
| 对象条件 | 只能针对不法侵害人本人 | 只能针对第三人的合法利益 |
| 主观条件 | 防卫挑拨、互殴、偶然防卫、滥用防卫权等 | 偶然避险（主流观点不成立） |
| 限度条件 | 防卫过当；特别防卫（不要求限度） | 避险过当；有特别防卫，但**没有特别避险** |
| 限制条件 | 无 | 迫不得已 |
| 主体 | 每个公民 | 排除职务、业务上负有特定责任的人 |

    * 假想防卫与假想避险均无犯罪故意，充其量构成过失犯罪；防卫不适时与避险不适时可能构成故意犯罪、过失犯罪或意外事件；防卫过当与避险过当均不成立罪名，均属法定的减轻或免除处罚情节。

* **竞合：一个行为同时构成防卫与避险**

    * 甲追杀乙，乙情急闯入丙家，乙拿起丙的青花瓷砸向甲，甲头被砸开花、古董粉碎、丙又抡棍砸开乙的头。

    * 乙拿花瓶砸向不法侵害人甲，成立正当防卫；对丙的财产造成损害，成立紧急避险。

    * 拿起与砸出是一个连贯行为，不拆为两个行为；只在花瓶实际粉碎时才需评价对丙的紧急避险。

    * 触及的是两个正当化事由而非想象竞合，**应认定对行为人更有利的制度**，最终对乙只认定为正当防卫。

    * 丙主观上认为乙是不法侵害人，客观上乙并非不法侵害人，丙属**假想防卫**；事发突然且发生在丙家中，丙有合理理由认为乙是坏人，主观无过失，认定为**意外事件**。
