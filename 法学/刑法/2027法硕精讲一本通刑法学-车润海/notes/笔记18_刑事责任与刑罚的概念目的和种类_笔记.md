# 刑事责任与刑罚的概念、目的和种类

## 刑事责任的学说与定义

### 五种学说

* **五种学说（中外刑法理论）**

    | 序号 | 学说名称 | 关键词 |
    | :--- | :--- | :--- |
    | 一 | 法律责任说 | 责任 |
    | 二 | 法律后果说 | 后果 |
    | 三 | 否定评价说 | 评价 |
    | 四 | 刑事义务说 | 义务 |
    | 五 | 刑事负担说 | 负担 |

* **记忆口诀**

    * **负担义务，评价后果，责任。**——按五到一倒着数回，负担对刑事负担说、义务对刑事义务说、评价对否定评价说、后果对法律后果说、责任对法律责任说。

* **通说态度**

    * > **定义**：上述学说都从不同侧面揭示了刑事责任的特征和内容，但从表述科学性来看，也都有不同程度的缺陷，所以我国刑法理论对刑事责任的概念有着不同的定义。
    * 我国刑法理论的态度很明确：五种学说都没有道理，都存在缺陷、都有问题。
    * 只需记住学说名称与关键词，不需复述各自的论证脉络；论述题若要求，可依此结论展开。

### 定义与拆解

* **刑事责任（criminal liability）**

    * > **定义**：刑事责任，是指行为人因其犯罪行为应当承受的、由代表国家的司法机关根据刑事法律对该行为所作的否定评价和对行为人进行谴责的**可能性**。
    * 旧版表述结尾是「责任」，新版改为「可能性」，呼应「有责可免刑」：承担刑事责任是一种可能性，落到实处到什么程度、在哪个环节落地，看后面的解决方式。
    * 拆句方法照搬英语长难句的处理办法：先记主谓宾，再挂定状补。

* **定义的四个提问**

    * 第一，谁来承担——主体是**行为人**。
    * 第二，凭什么承担——因为**犯罪行为**。
    * 第三，怎么承担——由**代表国家的司法机关**（检察官代表国家提起公诉）**根据刑事法律**追究。
    * 第四，承担的内容是什么——对该**行为**所作的否定评价，以及对**行为人**的谴责。
    * 主体结构是「**行为人 + 应当承受的**」，先记住这个壳子，其余细节都是往里填的补充成分。

    > **易错点**：法律评价的是人的**行为**，不是人的**思想**。行为无罪不等于思想无罪，评价对象自始至终是「该行为」。

* **有罪必有责，有责可免刑**

    * 前半句指理论上只要有罪就应当承担刑事责任；后半句指承担刑事责任不等于一定被判刑。
    * 既存在定罪判刑，也存在定罪免刑。犯罪中止没有造成损害的应当免除处罚，造成损害的应当减轻处罚；此处的「免除处罚」即免除**刑罚处罚**，也就是定罪免刑。

### 四项特征：非法必严

* **非法必严**

    | 口诀 | 特征 | 由来 |
    | :--- | :--- | :--- |
    | 非 | 非难性与谴责性 | 非难就是对行为的否定评价 |
    | 法 | 社会性与法律性 | 犯罪是刑事责任的前提，犯罪的本质特征是严重的社会危害性 |
    | 必 | 必然性与平等性 | 有罪必有责，没有例外，一视同仁 |
    | 严 | 严厉性与专属性 | 严厉到可以剥夺人的生命，正因如此不能对大多数人使用 |

* **各项特征的具体机理**

    * 非难性：宣告行为是不好的、是个犯罪行为；谴责性则是针对**行为人本人**的责难。
    * 社会性与法律性同源：犯罪是刑事责任的前提，犯罪都具有社会性，作为其法律后果的刑事责任当然具有社会性；是否承担、怎么承担要有法律的明文规定，这就是法律性，落脚于罪刑法定。
    * 必然性与平等性是刑法面前人人平等、刑法适用平等原则的体现。
    * 专属性由严厉性推出：只能针对犯罪人适用，由犯罪人自己承担。

## 刑事责任的地位

### 在刑事立法中的地位

* **三个表现**

    * 刑法条文中多次提到「刑事责任」：罪责刑相适应原则规定刑罚轻重应当与犯罪分子所犯罪行和承担的**刑事责任**相适应；分则第 347 条走私、贩卖、运输、制造毒品罪，无论数量多少都应当追究刑事责任、予以刑事处罚。
    * 总则第二章把「犯罪与刑事责任」作为第一节的标题，直接用一节标题把二者并列挂上去。
    * 规定了罪责刑相适应原则，意味着刑事责任在立法上被提到了与「罪行」「刑罚」**并列的地位**。

* **范围界定**

    * 这一块整体重要性一般，了解即可，其中值得展开的是理论地位里立法角度与司法角度的差别。

### 刑法理论中的地位

* **三种学说（对刑事责任地位的判断依次下降）**

    * **基础理论说**：刑事责任在价值功能上具有基础理论的意义；犯罪论、刑罚论和罪刑各论（分则规定）都只是**刑事责任理论的具体化**，应从体系上赋予其刑法学基本原理地位并放在犯罪论之前。
    * **罪责平行说**：犯罪、刑事责任、刑罚三者平行，两分天下。意义不大。
    * **罪责刑相适应说**：犯罪、刑事责任、刑罚是**各自独立又相互联系的三个范畴**；因总则存在罪责刑相适应原则，考试分析认为此说**更为可取**。

* **基础理论说的评价**

    * 从刑事司法角度看不成立：审理案件总是先有犯罪才有刑事责任，把刑事责任放在犯罪论之前是本末倒置，等于「先有儿子后有老子」。
    * 但从**刑事立法**角度看有一点点道理，道理就在角度不同。

* **责任与刑罚的中间位置**

    ```text
          犯罪  ──────▶  刑事责任  ──────▶  刑罚
          前提            纽带              实现方式
    ```

    * 纽带作用体现在四个方向：犯罪是刑事责任的前提；刑事责任是犯罪的法律后果；刑事责任又是刑罚的前提；刑罚是实现刑事责任的基本方式。
    * 由此刑法学体系应当按 **犯罪论 → 刑事责任论 → 刑罚论** 的框架建构。

### 立法角度与司法角度

* **两个角度结论相反**

    * > **结论**：从刑事立法角度看，**刑事责任是第一位的**；从刑事司法角度看，一定是**犯罪在第一位，然后是刑事责任，最后才是刑罚**。
    * 立法流程：先形成**刑事责任观**（价值目标、规制范围、适用模式），再在该观念指导下确定犯罪观和刑罚观——有必要处罚、需要承担刑事责任的规定为犯罪，不规定为犯罪。刑事责任观形成在前，影响刑法的制度设计，决定犯罪构成和刑罚的适用。
    * 马工程教材：**从刑事司法角度来看，犯罪行为是刑事责任产生的原因**，行为是否构成犯罪决定是否承担刑事责任。

## 刑事责任与刑罚的关系

### 找区别的推理链条

* **从「根」上找**

    * 方法论：找区别时最好从「根」开始找，找到根之后一步一步向上推理就会形成逻辑体系；「根」就是**前提**。

    ```text
          前提不同
             │
             ▼
          性质不同
             │
             ▼
          内容不同
    ```

    * 考试分析列出的三种区别并非按此顺序排列，顺序经调整后内容不变。

### 三点区别

* **前提不同**

    * 刑事责任的前提是**犯罪**，因犯罪而产生，有了犯罪才有刑事责任。
    * 刑罚的前提是**以法院的定罪判刑宣告生效而出现**，量刑判决已经生效，刑罚才出现。

* **性质不同**

    * 刑事责任的本质是一种**法律责任**；法律责任除刑事责任外还有民事责任、行政责任。
    * 刑罚的本质是一种**制裁方法**（强制方法），全称「刑事处罚」，也称「刑罚处罚」；除刑罚外还有行政处罚、民事处罚。

* **内容不同**

    * 刑事责任的内容是三项，刑罚的内容是以**实际剥夺犯罪人的一定权益**为内容。

### 刑事责任的内容

* **三项内容**

    * **刑事处罚**：最常见的形式，如张三构成犯罪被判处 5 年有期徒刑。
    * **非刑罚处理方法**：刑法以外的处理方法，如责令赔礼道歉、责令赔偿损失、训诫等。
    * **单纯的否定性法律评价**：既不判刑也不适用非刑罚处理方法时只剩下的一项，最易被忽略。典型情形是张三犯抢劫罪、中止犯罪且未造成损害，判决书只写「犯抢劫罪，但具有中止情节且未造成损害，因此免除刑事处罚」。

* **三项内容的轻重排序**

    * 最重是**定罪判刑**，如判处主刑、判处死刑、判处无期徒刑。
    * 其次是**定罪免刑但适用非刑罚处理方法**，如从业禁止、训诫、责令具结悔过、责令赔礼道歉、责令赔偿损失、行政处罚、行政处分。
    * 最轻是**单纯的否定性法律评价**，既不判刑也不适用非刑罚处理方法。

### 刑罚的内容

* **实质内容**

    * 无论主刑还是附加刑，都以实际剥夺犯罪人的一定权益为内容，如死刑剥夺的是犯罪人的生命。
    * 归为两大类：五种主刑（管制、拘役、有期徒刑、无期徒刑、死刑）与四种附加刑（罚金、没收财产、剥夺政治权利、对外国人驱逐出境）。

### 三点联系

* **前提关系（刑事责任对刑罚的作用）**

    * 刑事责任是适用刑罚的前提，没有刑事责任就不能适用刑罚。

* **决定关系（刑事责任对刑罚的作用）**

    * 罪责刑相适应意味着刑罚轻重要与犯罪分子所犯罪行和承担的**刑事责任**相适应，由此推出**刑事责任可以决定刑罚**：刑事责任大刑罚必重，刑事责任小刑罚必轻。

* **实现方式（反向讨论刑罚对刑事责任的意义）**

    * 刑事责任的三项内容中，**最主要的内容仍是刑罚**，故**刑事责任主要通过刑罚实现**。
    * 非刑罚处理方法等虽然也是实现方式，但属于**次要的实现方式**。

## 刑事责任的根据

### 质与量的统一

* **两个层面的问题**

    * 马工程教材认为，确定刑事责任要解决**质**和**量**的问题，刑事责任是二者的统一。
    * 解决**质**的问题是判断是否存在刑事责任；解决**量**的问题是刑事责任的大小。

* **法律根据的分布**

    * 刑法规定的**犯罪构成**既是决定刑事责任**存在与否**的法律根据，也是决定刑事责任**程度**的主要法律根据。
    * 犯罪构成之外规定的**量刑情节、刑罚执行制度**，也是决定刑事责任程度的重要法律根据。
    * > **结论**：符合犯罪构成才能成立犯罪，成立犯罪才能承担刑事责任。

* **相关学说**

    * 理论上对刑事责任根据有犯罪构成唯一根据说、罪过说、犯罪行为说、社会危害性说，考试分析删减较多，了解即可。

### 哲学根据：相对的意志自由

* **相对的意志自由**

    * > **定义**：刑事责任的哲学根据是行为人在实施犯罪行为时所具有的**相对的意志自由**。
    * 意志自由指有**辨认能力**、有**控制能力**，简言之是有**选择的能力**；精神正常的成年人可以选择犯罪，也可以选择不犯罪，选择犯罪就要对选择负责。
    * 具备相对意志自由即意味着具备**刑事责任能力**，应当为自身选择承担刑事责任。

* **两类排除情形**

    * 三岁的孩子干坏事不承担刑事责任：没有辨认能力、没有控制能力，连分辨是非的能力都没有。
    * 精神病人干坏事不承担刑事责任：有精神障碍，要么没有辨认能力，要么没有控制能力，没有选择余地。

### 法学根据：一个设定，两个确定

* **两个步骤**

    * 法学根据指从法律制度上，行为人承担或国家追究其刑事责任的决定因素，对应立法、司法两个步骤。
    * **一个设定**：立法层面作出规定，设定刑事责任的根据。立法上没有规定，法官也不能凭空造出罪名，否则构成徇私枉法。
    * **两个确定**：司法层面以事实为根据，确定刑事责任的**事实根据**；以法律为准绳，确定刑事责任的**法律根据**。

* **两个确定的落地示例**

    * 查明事实：某被告人是否有强制猥亵的事实存在，这是确定刑事责任的事实根据。
    * 确定法律：对应适用强制猥亵、侮辱罪、刑法第 237 条，这是确定刑事责任的法律根据。

## 刑事责任的解决方式

* **概念**

    * 刑事责任的解决方式又称**刑事责任的实现方式**，指刑事责任可以通过哪些方法被实际承担。
    * 该问题的各种学说对选择题没有影响，表述上以四项表格为准。

* **四种解决方式**

    | 解决方式 | 含义 | 例子 |
    | :--- | :--- | :--- |
    | 定罪判刑 | 定罪＝对犯罪人作出有罪判决；判刑＝宣告适用相应的刑罚 | 判处 5 年有期徒刑 |
    | 定罪免刑 | 对犯罪人作出有罪判决，同时决定免除刑罚处罚 | 中止犯没有造成损害，应当免除处罚 |
    | 消灭处理 | 行为已成立犯罪且应当负刑事责任，但因阻却刑事责任事由的存在使责任归于消灭，国家不再追究、行为人也不再承担 | 超过追诉时效 |
    | 转移处理 | 责任不由本国司法机关直接处理，而通过外交途径解决 | 享有外交特权和豁免权的外国人的刑事责任 |

* **两个边界的澄清**

    * 消灭处理：犯罪人确实犯罪、行为确实成立犯罪且应当负刑事责任，只是因法律规定的阻却刑事责任事由（如追诉时效已过）而不再追究。
    * 转移处理**不是不解决**，而是通过外交途径解决，同样是一种解决方式。

    > **易错点**：「免除刑罚处罚」不等于「不承担刑事责任」。判了罪就已经在承担刑事责任，只是没有实际判处刑罚。

## 刑罚论的展开顺序

* **法官视角的六个问题**

    * ① 量何种刑——可以量主刑，可以量附加刑。
    * ② 量刑情节——从严情节如累犯应当从重处罚；从宽情节如自首、立功、坦白。
    * ③ 开始量刑——一罪一罚；数罪并罚，涉及数罪如何并、刑期怎么算。
    * ④ 并罚后公开宣告——法槌一敲「现判决如下」；不实际执行则宣告缓刑、设置考验期，实际执行则交付执行机关羁押执行，表现好的适用减刑、假释。
    * ⑤ 不能无限期追诉——规定特殊的刑罚消灭：追诉时效、赦免。

    ```text
      起点：这个被告人为什么要被判刑？
            │
            ├── ① 量何种刑 ── 主刑 / 附加刑
            │
            ├── ② 量刑情节 ── 从严（累犯从重）
            │                  从宽（自首、立功、坦白）
            │
            ├── ③ 开始量刑 ── 一罪一罚；数罪并罚
            │                  （数罪如何并、刑期怎么算）
            │
            ├── ④ 并罚后公开宣告 ──「法槌一敲：现判决如下」
            │        │
            │        ├── 不实际执行 → 宣告缓刑、设置考验期
            │        └── 实际执行   → 交付执行机关羁押执行
            │                                  │
            │                                  └── 表现好 → 减刑、假释
            │
            └── ⑤ 犯罪之后不能无限期追诉
                   → 特殊的刑罚消灭：追诉时效、赦免
    ```

* **两次铺垫**

    * 刑罚论要做两次铺垫才能进入具体内容：第一个铺垫是刑罚是什么、目的是什么、有什么功能，第二个铺垫是量刑量何种刑、刑罚种类与体系。

## 刑罚的概念

### 法律制裁体系

* **五类法律制裁方法**

    * **民事制裁**：赔礼道歉、赔偿损失、恢复原状等。
    * **刑事制裁**：刑法判处主刑、附加刑。
    * **行政制裁**：如嫖娼被行政拘留十天、闯红灯被罚款 20 元。
    * **经济制裁**：主要发生在商事领域，如违反反不正当竞争法被罚款 500 万。
    * **对妨害诉讼的强制措施**：开庭审理时旁听席上的人大喊大叫、大哭大闹，法官可要求法警强制将其带离出庭，符合条件的还可给予相当程度的处罚。
    * 刑罚只是诸多制裁手段中的一种。

### 概念与六个特征

* **刑罚（penalty）**

    * > **定义**：刑罚是指**刑法明文规定的**，由**国家审判机关依法**对**犯罪人**适用的，**剥夺或限制其某项权益**的，**最严厉的法律制裁方法**。

* **概念中五个词的拆解**

    | 概念用词 | 拆解 |
    | :--- | :--- |
    | 刑法明文规定 | 基于罪刑法定原则的要求 |
    | 国家审判机关 | 才有权利去量刑，即法院 |
    | 依法 | 依据实体法（刑法）也依据程序法（刑事诉讼法） |
    | 对犯罪人适用 | 适用的对象是犯罪人 |
    | 剥夺或限制其某种权益 | 具体内容，主刑、附加刑都如此 |

* **六个特征（前五项直接来自概念）**

    | 特征 | 拆解来源 |
    | :--- | :--- |
    | ① 刑罚的种类和适用标准，必须以刑法明文规定为根据 | 刑法明文规定 |
    | ② 适用的主体只能是国家审判机关 | 国家审判机关 |
    | ③ 必须依照刑事诉讼法的规定 | 依法 |
    | ④ 适用的对象是犯罪人 | 对犯罪人适用 |
    | ⑤ 以限制或剥夺犯罪分子权益为内容的最严厉的法律制裁方法 | 剥夺或限制其某种权益 |
    | ⑥ 刑罚的执行由国家强制力作保障 | 概念之外，单独记一记 |

* **第六项特征的例证**

    * 法院判处张三死刑，张三不反抗，是因为他没有能力反抗；刑罚的执行以国家强制力作保障。

### 与其他法律制裁方法的区别

* **五点区别**

    | 区别维度 | 刑罚 | 其他法律制裁方法 |
    | :--- | :--- | :--- |
    | 适用的根据和程序 | 判刑必须以刑法为根据，并依照刑事诉讼法规定的刑事诉讼程序进行 | 分别以民法、经济法、行政法等实体法为根据，依照民事诉讼法等相关程序进行 |
    | 适用的机关 | 只能由国家审判机关的**刑事审判部门**适用，如法院的刑一庭、刑二庭 | 民事制裁、经济制裁对应民事审判、经济审判等部门；行政制裁由行政机关依法适用 |
    | 适用的对象 | 只能适用于**犯罪**的人 | 只能适用于违法、但不构成犯罪的人 |
    | 严厉程度 | 最严厉，可以剥夺人的生命、自由、财产、资格 | 不能剥夺生命，通常也不能剥夺自由，即使剥夺期限也较为短暂 |
    | 法律后果 | 被适用刑罚的人重新犯罪可能构成**累犯** | 以后又实施犯罪不可能构成累犯 |

* **记忆锚点**

    * 口诀是「**法院依法判处累犯马峰死刑**」，五个词依次对应五点区别。

    ```text
      法院依法判处累犯马峰死刑
        │      │     │      │   │
        │      │     │      │   └── 死刑 ──→ 第四点：严厉程度不同
        │      │     │      └────── 累犯 ──→ 第五点：法律后果不同
        │      │     └───────────── 马峰 ──→ 第三点：适用的对象不同
        │      └─────────────────── 依法判处 → 第一点：适用的根据和程序不同
        └────────────────────────── 法院 ──→ 第二点：适用的机关不同
    ```

## 刑罚的目的

* **刑罚目的的含义**

    * 刑罚目的与犯罪目的同为**对结果的追求**，具体指国家制定刑法（立法）以及通过对犯罪分子适用、执行刑法（司法、执法）所期望达到的结果。
    * 例：某被告人被判处死刑，刑罚目的思考的是「为什么对他判处死刑、判处死刑能起到什么效果」。
    * 理论上刑罚目的有两项内容：**刑罚报应观念**和**预防犯罪的目的**。

### 报应观念

* **刑罚报应观念**

    * > **定义**：刑罚报应观念认为，刑罚是对犯罪的公平报应；在对犯罪人判处刑罚的时候，不应当抱有防止犯罪等目的性考虑。
    * 非常古老，以牙还牙、以眼还眼、杀人偿命、欠债还钱都是典型形态，体现同态复仇。
    * 解释的是**刑罚的根据**，即国家为什么对犯罪人动用刑罚的原因之一。
    * 纯粹性体现在：就是因为行为人犯了罪，此外**没有其他任何理由**。

### 预防犯罪的目的

* **预防犯罪的目的**

    * 主张适用刑罚除对罪犯进行报应外，还应当具有预防再次犯罪的目的。
    * 其根据在于：刑罚在广义上是出于防止犯罪的目的而判处的一种**预防、教育手段**。

    ```text
       报应观念：  因为犯罪  ──→  所以要判处刑罚
       预防目的：  为了不再犯罪 ─→  所以要判处刑罚
    ```

* **两种预防的划分**

    * 刑罚目的所预防的犯罪**既包括已然之罪，也包括未然之罪**：前者针对已经犯罪的人，后者针对尚未犯罪的人。
    * 依预防对象不同，划分为**特殊预防**与**一般预防**。

### 特殊预防

* **特殊预防**

    * > **定义**：通过适用刑罚，预防**犯罪人重新犯罪**。
    * 三个要点：针对**已经犯罪的人**；预防他**再次犯罪**；再次犯**什么罪没有限制**。
    * 机理一是**心理上的强制**：罪犯会回想自己先前服刑的经历，从而遏制内心的犯罪冲动。

* **特殊预防的实现路径**

    * **改造**：教育改造犯罪人弃恶扬善、成为守法的公民。刑罚执行期间进行劳动改造与教育；除死刑剥夺生命外，大多数刑罚都采取强制劳动改造。
    * **剥夺**：剥夺犯罪分子再次犯罪的能力，使之不能危害社会。

* **剥夺的四条梯度**

    * **生命刑**：如判处死刑，永久性地消灭其再犯罪能力，最狠。
    * **自由刑**：如判处无期徒刑、10 年有期徒刑，将罪犯和社会隔离开，同时在服刑期间进行教育改造。
    * **财产刑**：如对经济类、财产类犯罪适用罚金、没收财产，剥夺其重新犯罪的物质基础，使其得不偿失、不敢不愿。
    * **资格刑**：如剥夺政治权利、对外国人驱逐出境，剥夺外国人再次入境的机会。

    > **结论**：教育改造犯罪人成为守法的公民，是我国刑法特殊预防（或特别预防）的主要内容。

### 一般预防

* **一般预防**

    * > **定义**：通过对犯罪人适用刑罚，预防**尚未犯罪的人**实施犯罪。
    * 不是所有尚未犯罪的人都是对象，重点是三组人。

* **三类重点对象**

    * **危险分子**：具有犯罪危险的人，如游离于违法和犯罪边缘、有过几次违法行为的人，违法与犯罪一线之隔。
    * **不稳定分子**：具有某种犯罪倾向的人，通常法制观念淡薄、自制力低、容易受到犯罪诱惑，俗称「街溜子」。
    * **具有私力复仇倾向的被害人及其家属**：被害人被他人打伤后家属抡刀报复，虽未构成犯罪，但有严重犯罪倾向或犯罪危险。

    > **易错点**：不能说**人民群众**是一般预防的对象——人民群众是**依靠**的对象，不是**预防**的对象。三类人即使未实施犯罪，也因具有犯罪危险才成为预防对象。

### 特殊预防与一般预防的关系

* **不可偏废**

    * 两者紧密结合、相辅相成，刑事司法活动应做到法律效果和社会效果的统一。
    * 对任何一个人适用刑罚，都同时包含特别预防和一般预防的目的，如车之两轮、鸟之双翼、马之四蹄。

### 两种理念的立法侧重

* **偏重不同导致法定刑设置不同**

    * 有的国家在立法时更偏重刑罚报应观念，有的更偏重预防犯罪的目的，偏重不同导致**法定刑设置**明显有别。
    * 例证：财产刑通常规定在**贪利性犯罪**中——通过犯罪挣钱，就剥夺其财产，这体现的是刑罚报应观点。
    * 哪一国以谁为主没有对错之分，受一个国家的历史文化、民众思维等多个维度影响。

* **南京灭门案（2000 年）**

    * 德国人浦方受梅赛德斯奔驰公司委派到中国参与中外合资项目，与一双儿女（女儿 15 岁、儿子 13 岁）租住南京一套别墅；某晚浦方被声音惊醒出门查看，四名年轻人正在盗窃，发现主人出来后大喊大叫，结果一哄而上，即所谓「南京灭门惨案」。
    * 按当时司法判例几乎无争议，判处死刑、立即执行；四人很快被抓，最年轻的一名刚成年 18 周岁，来自江苏苏北的贫困地区、贫困家庭。
    * 浦方的亲友致信中国法院：痛恨凶手，但作为基督徒认为只有上帝才能赐予或剥夺生命，请求不判死刑、判处无期徒刑即可让他们在监狱忏悔余生；面对发布会提问，发言人回答一定会依法处理，最终四人死刑立即执行。
    * 事后成立**浦方协会**（又称浦方基金会），认为犯罪不只是个人问题，更是家庭教育、社会教育的缺失，预防犯罪要消灭产生犯罪的土壤，只有教育、尤其是良好教育才能改变或成就一个人的一生；该组织在外国群体募集资金资助苏北贫困家庭孩子完成基本甚至良好教育，后覆盖安徽部分地区，至今仍存在，前后资助 1000 多户贫困家庭。

    > **提示**：这个案子最大的启发是，各国注重的环节不同只是基于文化、历史原因产生的细微差别，**没有对错之分**；在惩罚犯罪人之外还应多考虑如何预防类似现象的出现。

## 刑罚的功能

* **刑罚的功能**

    * > **定义**：刑罚的功能是指国家正确制定和执行刑法，对社会个体以及整体所产生和可能产生的积极作用。
    * 概念本身不要记，容易考超纲题的是下面三个面向的功能措辞。

| 面向谁 | 功能 |
| :--- | :--- |
| 对犯罪人 | **惩罚** + **改造**：判处 5 年有期徒刑是惩罚；服刑期间的教育改造、强制劳动改造是改造，使其成为守法的公民 |
| 对被害人 | **安抚**：法院对凶手判处死刑，对被害人及其家人确有安抚功能 |
| 对社会 | **威慑** + **教育鼓励**：威慑预防不稳定分子、危险分子实施犯罪；教育鼓励鼓励公民见义勇为 |

## 刑罚的种类

### 九种刑罚方法

* **主刑与附加刑**

    * **主刑五种**：管制、拘役、有期徒刑、无期徒刑、死刑——口诀「**管、拘、有、无、死**」。
    * **附加刑四种**：罚金、没收财产、剥夺政治权利、驱逐出境——口诀「**罚、没、剥、驱**」。
    * 合计我国共有**九种刑罚方法**，量刑量何种刑就是量这九种。

### 学理上的分类

* **分类标准**

    * 考试分析原文为「以剥夺犯罪分子的权利和利益的性质为标准」，可简化为**以剥夺或者限制犯罪分子的权益为标准**；「权益」既包括权利，也包括利益。

* **四类及其对应刑种**

    * **生命刑**：死刑。
    * **自由刑**：无期徒刑、有期徒刑、拘役、管制。
    * **财产刑**：罚金、没收财产。
    * **资格刑**：如剥夺政治权利。

### 立法上的分类

* **分类标准**

    * 标准是某种刑罚方法**只能单独适用**还是**可以附加适用**。

* **主刑与附加刑的适用方式**

    * **主刑**：只能单独适用，不能附加使用。
    * **附加刑**：既能独立适用，也能附加使用。
    * 由此可得：从适用范围的角度看，**附加刑比主刑适用的范围还要大**。

* **两套分类的对应关系**

    ```text
            剥夺或限制犯罪分子的权益（既包括权利，也包括利益）
            │
            ├── 学理上的分类 ─────────────────────
            │     生命刑 ── 死刑
            │     自由刑 ── 无期徒刑、有期徒刑、拘役、管制
            │     财产刑 ── 罚金、没收财产
            │     资格刑 ── 如剥夺政治权利
            │
            └── 立法上的分类 ─────────────────────
                  主刑   ── 只能单独适用，不能附加使用
                           管制、拘役、有期徒刑、无期徒刑、死刑
                  附加刑 ── 既能独立适用，也能附加使用
                           罚金、没收财产、剥夺政治权利、驱逐出境
    ```

### 非刑罚处理方法

* **适用范围包含两种情形**

    * 定罪判刑、判处刑罚之外，还有定罪免刑时适用非刑罚处理方法。

| 情形 | 非刑罚处理方法 |
| :--- | :--- |
| 在定罪判刑的基础上附带适用（只有 2 种） | 判处赔偿经济损失、从业禁止 |
| 定罪免刑（共 6 种） | 训诫、责令具结悔过、责令赔礼道歉、责令赔偿损失、行政处罚、行政处分 |

## 刑法体系

* **刑法体系**

    * > **定义**：刑法体系指的是刑法规定的、按照一定次序排列的各种**刑罚方法的总和**——指九种刑罚方法之和，不是一种或两种。
    * 由此可推出三项内容：它是**根据概念拆解出来的**各种刑罚方法的总和；它**必须有刑法规定**（罪刑法定必然要求）；它是**按照一定次序**将各种刑罚编排起来，轻重相互衔接、构成一个统一整体。
    * 例：主刑的排列顺序是管制、拘役、有期徒刑、无期徒刑、死刑，从轻到重依次排序、相互衔接。

* **我国刑法体系的特点**

    * 体系完整、结构严谨。
    * 方法人道、内容合理。
    * 宽严相济、目标统一（更偏向刑事政策的表述）。
