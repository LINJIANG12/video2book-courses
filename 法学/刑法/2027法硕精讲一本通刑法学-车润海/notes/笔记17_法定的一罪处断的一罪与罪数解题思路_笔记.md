# 法定的一罪、处断的一罪与罪数解题思路

## 法定的一罪与处断的一罪

* **法定的一罪（Statutory Single Offense）**

    * > **定义**：原本是数罪，但立法上把它规定成一罪，以一罪定罪处罚。

    * 依据来源是刑法的**明文规定**；法条只要写了"依照某罪定罪处罚"，讨论即告结束。

    * 读法不同：看到"法定的一罪"，第一反应不是"这个行为怎么评价"，而是"法条里有没有明文规定"。

    * 主要形态有三：结合犯、集合犯、转化犯。

* **处断的一罪（Single Offense by Adjudication）**

    * > **定义**：行为人犯了数罪，仅按照一罪定罪处罚的情形。

    * **缺乏法律上的明文规定**，基于刑法理论上的认可。

    * 具体包括连续犯、牵连犯、吸收犯，此外补充一种情形——事后不可罚。

* **共同点**：都实施了数个行为，也都按照一罪定罪处罚；最大不同在"按一罪定罪处罚"这一结论的来源。

| 对比项 | 法定的一罪 | 处断的一罪 |
| :--- | :--- | :--- |
| 行为数量 | 实施了数个行为 | 实施了数个行为 |
| 定罪处罚 | 按照一罪定罪处罚 | 按照一罪定罪处罚 |
| 依据来源 | 刑法的明文规定 | 无法律明文规定，基于刑法理论的认可 |
| 常见类型 | 结合犯、集合犯 | 连续犯、牵连犯、吸收犯（另补充事后不可罚） |

## 结合犯

* **结合犯（Combined Offense）**

    * > **定义**：两个以上各自独立成罪的犯罪行为，根据刑法的明文规定结合成另一个独立的新罪的犯罪形态。

    * 公式只有两种写法：

      $$\text{A罪} + \text{B罪} = \text{C罪}\quad\text{或}\quad \text{A罪} + \text{B罪} = \text{AB罪}$$

    * 三个特征由公式拆出：C 罪的行为是由数个可分别构成其他犯罪的行为结合而来；结合成新罪是刑法的明文规定（等号即规定本身，甲乙之间无天然吸附关系）；C 罪区别于被结合之罪，具有自己独立的犯罪构成。

    * A 罪、B 罪、C 罪在刑法条文中各自都有规定，所以这个"结合"不是评价出来的，是立法者明文写上去的。

    * 单选题的典型界限只有"A 罪 + B 罪 = C 罪"；"甲罪 + 乙罪 = 甲罪"与"甲罪 + 乙罪 = 乙罪"表达同一意思须同时排除，"甲罪 + 甲罪 = 甲罪"根本不存在数个各自独立成罪的行为，也排除。

* **立法例**

    * 1935 年刑法同时规定强盗罪、故意杀人罪与强盗故意杀人罪，第三个罪即由强盗罪与故意杀人罪结合而来。

    * 罪名对应方向容易记反：古代的强盗罪对应现行刑法的抢劫罪，古代的窃盗罪对应现行刑法的盗窃罪。

    * 日本 2017 年前的刑法规定强盗罪、强奸罪与强盗强奸罪，行为人实施强盗罪时强奸受害人的，按强盗强奸罪论处；日本的强盗罪即中国大陆的抢劫罪。

* **结合犯与结果加重犯**

    * 两者都有刑法明文规定，唯一分水岭是**行为的数量**。

    * 结合犯客观上实施了**两个以上**独立的犯罪行为，属于实质的数罪、法定的一罪，因此不实行数罪并罚。

    * 结果加重犯客观上仅实施了**一个**犯罪行为，属于实质的一罪。

## 非典型结合

* **非典型结合（Non-typical Combination）**

    * > **定义**：数个犯罪按刑法的明文规定只定一个罪，且被结合的罪名不产生新的独立罪名。

    * 公式：$$\text{甲罪} + \text{乙罪} = \text{甲罪}$$

    * 典型例：拐卖妇女过程中强奸妇女，$$\text{拐卖罪} + \text{强奸罪} = \text{拐卖罪}$$；因等号右边仍是甲罪本身、罪名没变，所以只能叫"非典型"。

    * 与结合犯背后的法理相同，所以理论上仍有必要研究——听懂法理，分则里的一堆特殊规定就不用硬背。

    * 我国刑法没有规定结合犯，一个都没有；刑法学理上把这种结构称为非典型结合。

* **三个成立条件**

    * **实践根据：两罪必须在司法实践中高度并发。**这不是从法条推出来的，是从"犯罪人通常会怎么干"推出来的。

    * **法律依据：必须有刑法的明文规定。**没有规定就什么都不是，此时只能数罪并罚。

    * **目的：越结合越重**，法定刑反而变得更重。

* **并发性（Concurrence）**

    * > **定义**：两个罪名在司法实践中一起出现的概率相对较高，甲罪往往伴随乙罪而发生。

    * 甲罪出现时通常就捎带出乙罪，立法者才会关注"甲乙罪一起出现"而专门立罪；两罪基本不可能一起出现时，立法上不可能把它们规定为结合。

    * 常见情形的两罪并发性高低：

| 组合 | 并发性 | 理由 |
| :--- | :--- | :--- |
| 绑架 + 杀人或故意伤害致重伤、死亡 | 高 | 撕票，绑架后为索赎金常伤害、杀害人质；先绑架又杀人指定绑架罪一罪 |
| 拐卖妇女 + 强奸 | 高 | 被害人已处行为人完全控制之下，想侵害易如反掌 |
| 走私、贩卖、运输、制造毒品 + 妨害公务、袭警 | 高 | 毒品法定刑极重，涉毒犯罪人拼命反抗 |
| 盗窃 + 强奸 | 低 | 图财与满足性欲动机不同，被发现通常先跑 |
| 拐卖妇女 + 强制猥亵、侮辱 | 低 | 已能强奸时绝大多数选择强奸；猥亵过程中还可能升级为强奸 |

* **毒品法定刑与并发性的推导**

    * 刑法第 347 条：走私、贩卖、运输、制造毒品无论数量多少均应追究刑事责任；鸦片 1000 克以上、毒品 50 克以上，处 15 年有期徒刑、无期徒刑或者死刑，并处没收财产。

    * 50 克的参照物：一个手机可能就要 200 多克；带 5 公斤毒品被查获，反抗成功率低而代价是死刑。

    * 由此可反推：法定刑越重，妨害公务、袭警越常伴随出现；以暴力抗拒检查、拘留、逮捕情节严重的，仍定走私、贩卖、运输、制造毒品罪一罪。

* **越结合越重**

| 处断方式 | 罪名 | 法定刑 |
| :--- | :--- | :--- |
| 数罪并罚 | 拐卖妇女罪 + 强奸罪 | 各自最高 10 年，法定刑幅度为 10 年以上 20 年以下 |
| 非典型结合 | 拐卖妇女罪一罪 | 10 年以上有期徒刑、无期徒刑或者死刑 |

    * > **易错点** ⚠️：很多人认为"定两个罪量刑重，定一个罪量刑轻"。未必要，非典型结合只定一个罪，法定刑反而更重。

    * 立法者的用心是：拐卖过程中强奸本应并罚，但因并罚量刑轻，索性不并罚而直接指定拐卖妇女罪一个罪并加重法定刑，以体现对妇女的格外保护。

* **罪名立法史**

    * 七九刑法规定的是"拐卖人口罪"，九七刑法修订改为"拐卖妇女儿童罪"；调研发现司法实践中要么拐妇女要么拐小孩，很少出现拐卖成年男子，因为卖不掉。

## 集合犯

* **集合犯（Collection Offense）**

    * > **定义**：主客观相统一，行为人以实施不定次数的同种犯罪行为为目的、客观上实施了数个同种犯罪行为，而刑法规定以一罪论处的犯罪形态。

    * 属于法定的一罪，同时又属于同种数罪；同种数罪原则上不并罚。

    * "集合"即把性质相同的人或物有顺序地集合在一起。

* **四个特征**

    * **主观**：以实施不定次数的同种犯罪行为为目的——一次还是多次是多次，多少次不知道，被抓住时才结束。

    * **客观**：一般也是实施了数个同种犯罪行为。"一般"二字说明存在例外。

    * **罪名**：所触犯的罪名必须相同，数个同种犯罪行为触犯同一罪名。

    * **处断**：刑法将数个同种犯罪行为规定为一罪，故属法定的一罪，不实行数罪并罚。

* **两大典型**

    * **职业犯**：非法行医罪。张三非法行医很多年、很多次，最终仍只定一个非法行医罪，行医一千次不能按一千个罪并罚。

    * **营业犯**：开门营业、主观上有盈利目的，典型是赌博罪，法定为聚众赌博或者以赌博为业；常年赌博多次也只定一个赌博罪。

* > **易错点** ⚠️：客观要件后面的"一般"是命题陷阱——只要主观上以实施不定次数的同种犯罪行为为目的，客观上哪怕只实施一次也可能成立犯罪。例如以非法行医为职业，只看一个病人就将其治死，成立非法行医致人死亡的结果加重犯；制作、复制、出版、贩卖、传播淫秽物品牟利罪，客观上只卖一次、符合条件同样构成该罪。

    * 绝对不能打破的一条：主观上必须以实施不定次数的同种犯罪行为为目的。

## 转化犯

* **转化犯（Converted Offense）**

    * > **定义**：行为人在实施犯罪的过程中，因为具备了法定的条件，而从一罪转化为另一罪的犯罪形态。

    * 公式：$$\text{A罪} \;\longrightarrow\; \text{B罪}$$

    * 箭头指"在实施 A 罪的过程中，因为符合法定条件而从 A 罪转化为 B 罪"，是有法定条件的，不是从轻罪向重罪随意跳。

    * 典型例：刑法第 269 条，犯盗窃、诈骗、抢夺罪，为窝藏赃物、抗拒抓捕或者毁灭罪证而当场使用暴力或以暴力相威胁的，依照第 263 条抢劫罪的规定定罪处罚；刑法第 292 条，聚众斗殴致人重伤、死亡的不再定聚众斗殴罪，转化为故意伤害罪或故意杀人罪。

* **两大特征**

    * **法定性**：必须有法律的明文规定，法条通常写成"犯某某罪，然后满足什么什么条件的，依照某某罪定罪处罚"。

    * **趋重性**：从此罪向彼罪、从轻罪向重罪转化。

* **与结果加重犯的分水岭**

    * 看法条措辞"依照他**定罪处罚**"，不是"依照他处罚"——"定罪处罚"四字连用说明罪名都变了。

    * 以刑法第 238 条非法拘禁罪为例：

```text
  刑法第 238 条 · 非法拘禁罪

  非法拘禁他人，处 3 年以下                    ← 基本犯
  犯前款罪，致人重伤 → 3 年以上 10 年以下
  犯前款罪，致人死亡 → 10 年以上
        ↓ 罪名仍是「非法拘禁」，本条另设更重法定刑
        ◆ 结果加重犯

  使用暴力致人伤残、死亡 → 依照 234 条、232 条定罪处罚
        ↓ 罪名变为「故意伤害罪」「故意杀人罪」，本条无独立法定刑
        ◆ 转化犯
```

    * 第 247 条是同一结构且两个罪共用一个法条：刑讯逼供罪与暴力取证罪处 3 年以下，致人伤残、死亡的依照 234 条、232 条定罪处罚，罪名改变且本条无独立法定刑，属转化犯。

    * 第 263 条抢劫罪"抢劫致人死亡的，处 10 年以上有期徒刑、无期徒刑或者死刑"，言下之意仍认定抢劫罪、定原罪名而法定刑更重，属结果加重犯，不可能理解成转化犯。

    * 区分只看两点：罪名是否发生改变、法定刑有无专门规定。

* **分则转化犯清单**

| 序号 | 条文 | 转化情形 | 转化为 |
| :--- | :--- | :--- | :--- |
| 之一 | 第 238 条 | 非法拘禁使用暴力致人伤残、死亡 | 故意伤害、故意杀人 |
| 之二 | 第 247 条 | 刑讯逼供致人伤残、死亡 | 故意伤害、故意杀人 |
| 之三 | 第 247 条 | 暴力取证致人伤残、死亡 | 故意伤害、故意杀人 |
| 之四 | 第 248 条 | 虐待被监管人致人伤残、死亡 | 故意伤害、故意杀人 |
| 之五 | 第 589 条 | 聚众打砸抢致人伤残、死亡 | 故意伤害、故意杀人 |
| 之六 | 第 292 条 | 聚众斗殴致人重伤、死亡 | 故意伤害、故意杀人 |
| 之七 | 第 333 条 | 非法组织卖血、强迫卖血致人伤害 | 故意伤害 |
| 之八 | 交通肇事 | 肇事后不救助，将被害人转移至隐蔽处所遗弃、藏匿，致其无法得到救助而死亡 | 故意伤害、故意杀人 |

    * > **易错点** ⚠️：第四项不是虐待罪，是第 248 条"虐待被监管人罪"；名称相似但罪名完全是两回事，与刑讯逼供、暴力取证一样出现重伤、死亡即转化为故意伤害、故意杀人。

    * 前六项均转化为故意伤害、故意杀人，所以转化犯通常转成这两个罪；第七项偏超纲，了解即可。

    * 财产犯罪中还有第 269 条转化为抢劫，交通肇事罪中也会讲转化为故意伤害、故意杀人的情形。

    * 选择题问"法定的一罪包括哪些"，只能选结合犯和集合犯，**不能选转化犯**——考试大纲和分析题并未对转化犯作专门表述，且转化犯未必存在两个独立的犯罪行为，有可能只有一个行为就完成了转化。

## 连续犯

* **连续犯（Serial Offense）**

    * > **定义**：行为人主观上基于同一或概括的犯罪故意，连续多次实施犯罪行为，触犯相同罪名的犯罪。

    * 属处断的一罪，实质上是数罪，只按一罪定罪处罚，不实行数罪并罚。

* **主观：同一故意与概括故意**

    * "同一"指完全一致；"概括"指行为人脑中有一个**总犯意**。

    * 危害行为具有意识性，是意识支配的产物和表现：先有罪过，再在罪过支配下实施行为。所以连续犯意味着先产生一个总犯意（犯罪的计划），在该总犯意支配下实施的行为才可能被评价为连续犯。

    * > **易错点** ⚠️：连续意图在数个同种犯罪行为**开始之前**就已形成，由它制约的各个具体犯罪故意都属于有预谋的故意，因此过失犯罪不能成立连续犯，连续犯只能发生在故意犯罪之中。

    * 计划之内是连续犯，计划之外是另起犯意：甲为报复乙计划杀死乙的妻子、儿子，在计划内分别杀死，对每个被害人都成立故意杀人罪，但属连续犯，只按故意杀人罪一罪定罪处罚；偶遇的乙父不在计划内，杀死乙父属另起犯意，不认定连续犯，但仍按故意杀人罪一罪处理。

    * 真实案例：张扣扣为报复邻居，除夕夜持砍刀冲入邻居家砍死三人，主观上先产生连续杀人的概括故意，客观上在总犯意支配下实施，对每个人都成立故意杀人罪，因同种数罪原则上不并罚且故意杀人罪最高刑即为死刑，最终只定故意杀人罪一罪并执行死刑。

* **客观三个小点**

    * **触犯相同罪名**：为报复李四先杀人后放火，前行为故意杀人罪、后行为放火罪，数罪并罚。

    * **每个行为都独立构成犯罪**：连续杀人杀三人，对每个被害人都单独成立故意杀人罪。

    * **只实施一个行为不可能成立连续犯**，这种理论上称为**接续犯**：多次少量投毒积累至毒发身亡，每次投毒单独都不能独立定罪，合并才达到致人死亡的程度；接续犯同样要求数个行为之间具有连续性。

* **连续性的判断**

    * 主观上看行为人有没有连续实施某种犯罪行为的故意与计划，计划内的才可能，连续计划外的一律不是。

    * 客观上看数个行为**性质相同、手段类似、时间上前后具有连续性**。

    * "手段类似"不要管得太死：只要触犯相同罪名即可。先用暴力压制反抗、后以持刀威胁压制反抗，手段不完全相同但都是抢劫行为，仍成立连续犯，定抢劫罪一罪。

* **三个不成立的例子**

    * 杀人灭口：为报仇杀死乙，逃离现场后因路人丙看到而临时起意杀丙灭口，属另起犯意，非连续犯；构成故意杀人罪与故意杀人罪，属不并罚的同种数罪。

    * 间隔多年的反复盗窃：5 年前偷一次、3 年前偷一次、今年又偷一次，主观上难以认定有连续盗窃故意，客观上也无连续关系，不成立连续犯，认定为不并罚的同种数罪。

    * 触犯不同罪名的一串行为：甲一天之内既盗窃又抢劫，故意不完全相同，数罪并罚；丙一个月内先后贪污和受贿，罪名不同，属不同种数罪并罚；丁将父亲赶出家致其沿门乞讨构成遗弃罪、一周后溺死女婴构成故意杀人罪，数罪并罚。

* **连续犯与同种数罪**

    * 连续犯也是数个行为触犯同一罪名，所以连续犯本身属于同种数罪；广义同种数罪分三种：集合犯（法定的一罪）、连续犯（处断的一罪）、狭义同种数罪（如隔年三次盗窃，犯罪数额累计相加量刑）。

    * 连续犯对定罪几乎没有意义：有连续关系不并罚，没有连续关系也不并罚。

    * 我国刑法理论认为，对判决宣告以前的同种数罪不实行数罪并罚，但对刑罚执行期间的同种数罪应当并罚。甲因诈骗被判三年有期徒刑，服刑期间又在监狱诈骗其他犯人，属刑罚执行期间的同种数罪，数罪并罚。

* **连续犯的意义**

    * **追诉时效的起算**：刑法第 89 条，犯罪行为有连续状态的，追诉时效从犯罪行为终了之日起计算；连续盗窃三次的，从第三次盗窃行为实施完毕之日起算。

    * **溯及力**：连续犯和继续犯可能跨越新旧法，一律适用新法。

    * **"多次"的认定**：刑法第 263 条"多次抢劫"指三次以上，此时成为情节加重犯，适用更重的法定刑；司法解释规定，基于同一故意、在同一地点连续抢劫（如在同一地点连续对途经此地的多人抢劫），一般认定为一次抢劫，不认定为多次抢劫。

    * "多次"有两个含义：一是犯罪的成立条件（多次盗窃、多次抢夺、多次敲诈勒索），二是量刑情节与法定刑升格条件（多次抢劫、多次聚众斗殴）。

## 牵连犯

* **牵连犯（Implicated Offense）**

    * > **定义**：实施某个犯罪，作为该犯罪的手段行为或者结果行为，又触犯其他罪的情况。

    * 牵连即关系紧密，牵连犯可以按处断的一罪处理，紧密程度从概念中即可体现。

```text
        手段行为                  目的行为                  结果行为
    ┌──────────┐               ┌──────────┐              ┌──────────┐
    │  A 罪    │ ───────────> │  B 罪    │ ───────────> │  C 罪    │
    └──────────┘               └──────────┘              └──────────┘
      为实施 B 罪而为之            追求 B 罪                  B 罪所导致
                               （最终犯罪目的）

    左半段 A ←──→ B ：手段与目的的牵连
    右半段 B ──→ C ：原因与结果的牵连
```

* **四个特征**

    * **主观上有一个最终的犯罪目的**：该目的能制约着前后的两个行为，伪造印章时就有骗人的目的，实施骗人时同样有诈骗目的。

    * **客观上实施两个以上的犯罪行为**：原因行为、结果行为、手段行为、目的行为都能分别独立构成犯罪。

    * **触犯两个以上不同的罪名**：触犯相同罪名的充其量是连续犯。盗窃后把赃物藏起来，窝藏赃物是盗窃既遂后的状态、不能独立成罪；杀人后抛弃尸体，我国没有遗弃尸体罪，两者都只涉及一个罪，均不构成牵连犯。

    * **两个罪名之间具有牵连关系**，这是最重要的要求。

    * > **易错点**：牵连犯本质上是数罪，行为人主观上有**两个犯罪故意**。伪造国家机关印章用于诈骗，既有伪造印章的故意也有诈骗的故意，只不过这两个故意在主观上受同一个最终目的（非法占有他人财物）统摄；不能因为"有一个最终的犯罪目的"就理解成只有一个犯罪故意。

* **牵连关系的判断**

    * 主观上行为人对实施的数个行为具有**牵连意图**。

    * 客观上数个行为之间具有**通常的方法或结果关系**，即类型化——甲罪往往伴随乙罪而发生；"通常"要求两个罪一起出现的概率相对较高，需用经验判断，这一板块略有争议。

    * 主观客观必须同时满足：只满足主观、缺乏客观不行；只满足客观、缺乏主观也不行。

    * 正面例：甲以非法占有为目的先伪造信用卡再用该卡诈骗，主观有牵连意图，客观上伪造信用卡之后大概率会去用，伪造金融票证罪与信用卡诈骗罪成立牵连犯，择一重罪处罚。

    * 反面例一：想杀李四就去买枪杀人，主观有杀人目的支配，但我国对枪的管制严格，产生杀人故意时一般不会先去买枪，"买枪杀人"一起出现的概率低，客观上无牵连关系，数罪并罚。

    * 反面例二：强奸后为防止报警而杀死被害人，主观上可能有牵连意图，但强奸之后通常不会杀人，客观上无牵连关系，数罪并罚。

* **杀人骗保**

    * 保险分财产保险与人身保险两类：财产保险可自行制造保险事故后虚假理赔，与杀人无关。

    * 人身保险中，骗取保险金通常要靠故意造成被保险人死亡、伤残来实现，因为被保险人不死不伤，骗保目的不可能实现；刑法第 198 条第五项正是"投保人、受益人故意造成被保险人死亡、伤残、疾病，骗取保险金"。

    * 人身保险中通过杀人骗保具有类型化特征，刑法分则具体罪名的规定是类型化的，故杀人骗保属于牵连犯。

* **处断原则与例外**

    * 原则是择一重罪定罪处罚，法律和司法解释另有规定的从其规定。

    * 刑法第 198 条：有前款第四项、第五项所列行为同时构成其他犯罪的，依照数罪并罚的规定处罚，所以先杀人再骗取保险金实行数罪并罚。

    * > **易错点**：不能因为该情形数罪并罚，就反向否定它是牵连犯。牵连犯本身就有两种处理模式：择一重罪处罚，以及法律有特别规定时的数罪并罚。

    * 牵连犯主观上有一个最终犯罪目的，客观上实施数个行为且行为间有牵连关系，主观恶性与客观危害性比单纯的一罪大、比数个独立的犯罪小，因而不发生数罪并罚是容易理解的。

* **考试分析的两个例子**

    * 例一：先伪造公文、证件、印章再诈骗，手段行为触犯伪造国家机关公文、证件、印章罪，目的行为触犯诈骗罪，属手段与目的的牵连。

    * 例二（争议）：盗窃他人皮箱后发现其中有枪支而加以藏匿，前行为构成盗窃罪、后行为构成非法持有枪支罪，作为盗窃结果的占有枪支又触犯了非法持有、私藏枪支、弹药罪，属原因与结果的牵连，认定为盗窃罪的牵连犯。

    * 判断角度的转换：讨论的不是"偷到枪的概率高不高"（到大街上偷普通财物，偷到枪的概率非常低），而是"**如果偷到了枪，持有枪支的概率高不高**"——答案是比较高。

    * 考试分析如与立法、司法解释冲突，可以大胆指出其有问题；不冲突而只是一种学术观点或观点争议时，作为官方教材一定要以它为准。

* **常考牵连犯一览**

| 常考情形 | 牵连类型 |
| :--- | :--- |
| 一、先伪造（印章、信用卡等）再诈骗 | 手段与目的 |
| 二、伪造身份证后代替他人考试 | 手段与目的 |
| 三、先虚开增值税专用发票再逃税 | 手段与目的 |
| 四、先打伤看守再脱逃 | 手段与目的 |
| 五、先杀人再骗保 | 原因与结果 |
| 六、先制造保险事故再实施保险诈骗 | 手段与目的 |
| 七、盗窃财物后发现有枪然后持有 | 原因与结果 |
| 八、先受贿后徇私枉法 | 原因与结果 |
| 九、收钱替人办事构成渎职罪 | 原因与结果 |
| 十、先提起虚假诉讼又侵占他人财物 | 手段与目的 |

    * 第七项的理由同前述角度转换；第八、九项同为"正因为收了钱所以替人办事"，构成原因与结果的牵连。

    * 哪些择一重、哪些有特别规定须并罚，到分则再讲；特殊规定在书的最后附录里都已列出。

## 吸收犯

* **吸收犯（Absorbed Offense）**

    * > **定义**：一个犯罪行为是另外一个犯罪行为的必经阶段、组成部分或者当然结果，而被另外一个犯罪行为所吸收的情形。

    * 属处断的一罪、实质的数罪、不同种数罪；四个特征是：数个危害行为、实质的数罪、不同种数罪、一个行为吸收其他行为。

    * 前两种情形意味着前后两个行为关系非常紧密。

* **三种类型**

    * **吸收必经阶段**：刑法第 263 条抢劫罪的入户抢劫，"入户"是入户抢劫的必经阶段，入户本身可构成非法侵入住宅罪。甲入户抢劫先后触犯非法侵入住宅罪和抢劫罪，非法侵入住宅被抢劫罪吸收，只定抢劫罪一罪。

    * **吸收组成部分**：甲伪造增值税专用发票同时伪造发票专用章，印章是发票的组成部分，伪造印章行为被吸收。

    * **吸收当然结果**：明知是枪而盗窃构成盗窃枪支罪，偷到手后必然持有，持有被盗窃枪支罪吸收；非法制造枪支后持有，持有被非法制造吸收；伪造出 200 万假币后必然持有，持有是伪造货币的当然结果，整体定伪造货币罪一罪。

* **明知与不知的分野**

| 情形 | 定性与理由 |
| :--- | :--- |
| 甲明知乙皮包内是枪而盗窃，偷到手后持有 | 主观上已不是盗窃普通财物的故意而是盗窃枪支罪的故意；偷到手必然持有，持有是密不可分的当然结果，整体定**盗窃枪支罪**（吸收非法持有枪支罪） |
| 乙不知包内是枪而盗窃，偷到手后发现是枪并持有 | 就是以为普通财物而偷；正因为"偷错"这个原因导致了持有枪支的结果，构成**牵连犯**，不是吸收犯 |

* **实行行为吸收非实行行为**

    * 教唆他人实行犯罪而本人不参与犯罪实行，是教唆犯的特征；教唆他人抢劫后又与之共同实施抢劫，实行行为吸收非实行行为，对教唆者不再定抢劫罪的教唆犯，直接认定共同正犯。

* **同一素材才谈得上吸收**

    * 对于吸收犯仅以吸收之罪论处，不实行数罪并罚，切记没有例外。

    * 对比记忆：牵连犯原则择一重罪处罚，法律和司法解释另有规定的从其规定（可并罚）；认定为吸收犯则一律不并罚。

    * 能这么绝对，是因为吸收犯要求前后行为紧密相关、指向同一素材。

| 行为组合 | 素材关系 | 处理 |
| :--- | :--- | :--- |
| 伪造一批假币，又持有这一批假币 | 同一批假币 | 吸收，定伪造货币罪一罪 |
| 伪造假币，又持有别人伪造的另一批假币 | 不同素材 | 数罪并罚：伪造货币罪 + 持有假币罪 |
| 非法制造一把枪，又持有这把枪 | 同一把枪 | 吸收，定非法制造枪支罪一罪 |
| 非法制造枪支，又持有他人制造的枪支 | 不同素材 | 数罪并罚：非法制造枪支罪 + 非法持有枪支罪 |

## 吸收犯与牵连犯的分水岭

* **官方教材的立场**

    * 考试分析承认两者确难区别：牵连犯与吸收犯都是数行为犯，数罪都是实际的数罪、处断的一罪，都是不同种数罪；牵连犯不并罚是因为使用了"吸收"的概念，吸收犯不并罚是因为二行为之间存在某种牵连关系——牵连中有吸收，吸收中有牵连。

    * 根源在于两个概念作用相同（都解决数罪但不并罚的问题），在学术上仍同时保留所以不得不区分；考试分析给出的区分方法是掌握牵连犯和吸收犯的具体类型与典型例子。

* **第一步：是否密不可分**

    * 必经阶段与组成部分都达到了密不可分的程度：不构成非法侵入住宅罪就不可能构成入户抢劫；既然是组成部分就分不开。

    * 当然结果包含两种：**密不可分的当然结果**（伪造货币后一定会持有、制造枪支后一定会持有）与**可以分开的当然结果**。

    * 伪造货币后运输假币是"可以分开的当然结果"：伪造之后未必运输，运输也不必以伪造为前提。

    * 判断规则：**凡是达到密不可分程度的，一律认定为吸收犯**；可以分开的才进入第二步。

    * 牵连犯虽紧密但达不到密不可分，如杀妻骗保、先伪造印章再诈骗，伪造印章未必用于诈骗（也可能拿去吓唬人、盖章发布虚假消息），诈骗也未必先伪造印章。

* **第二步：同一素材与相同直接客体**

    * 罪数判断的标准是犯罪构成，要求全面评价、禁止重复评价。

    * 禁止重复评价包含两项法理：禁止重复评价一个行为；禁止重复评价一个法益、一个客体。

    * 必经阶段、组成部分、密不可分的当然结果已达到分不开的程度，并罚就会重复评价一个行为。

    * 可以分开的当然结果仍不并罚，是因为前后行为针对同一对象、同一素材，侵害相同的直接客体，并罚就是重复评价一个客体。伪造货币罪与运输假币罪侵害的都是货币的公共信用，针对的是同一批假币。

    * 牵连犯不存在这个问题：先杀妻再骗保，杀人侵害生命权，骗保侵害保险公司财产权与保险制度，客体完全独立，且杀人未必骗保、骗保也未必杀人。

* **判定流程**

```text
              前后两个行为（数行为犯）
                        │
                        ▼
            第一步：是否"密不可分"？
              │                    │
            是                    否（可以分开）
              │                    │
              ▼                    ▼
       一律认定为吸收犯        第二步：两项指标
           （只定一罪）         ① 是否针对同一个素材
                               ② 是否侵害相同的直接客体
                                  │              │
                             都满足          有一项不满足
                                  │              │
                                  ▼              ▼
                            仍是吸收犯        已不是吸收犯
                             （只定一罪）           │
                                                     ▼
                                       是否存在牵连关系？
                                         │              │
                                        有              无
                                         │              │
                                         ▼              ▼
                                    牵连犯           数罪并罚
                          （原则择一重，例外并罚）
```

* **常考例子的套用**

    * 非法制造枪支后持有这把枪：制造后一定持有、分不开，第一步即定为吸收犯，只定非法制造枪支罪一罪。

    * 杀妻骗保：杀妻未必为了骗保、骗保未必杀妻，可分开；第二步杀妻针对妻子身体侵害生命权，骗保侵害保险制度与保险公司财产权，直接客体不同，不是吸收犯；杀害作为手段指向骗保这一目的，属手段目的牵连，原则择一重、例外并罚。

    * 伪造货币后运输同一批假币：未必运输、也未必以伪造为前提，可分开；第二步同一批假币是同一素材，伪造货币与运输假币都侵害货币的公共信用，直接客体相同，仍是吸收犯，属"可以分开的当然结果"，只定伪造货币罪一罪。

    * 先伪造国家机关印章再诈骗：两向均可分；印章与被害人财物不是同一素材，伪造印章罪侵害国家机关的正常活动、诈骗罪侵害他人财产权，直接客体不同，不是吸收犯；"用伪造印章去诈骗"在诈骗中较常见、不罕见，有牵连关系，属牵连犯。

    * 先伪造信用卡再使用该卡实施信用卡诈骗：伪造后可以卖掉，不必亲自使用，使用伪造卡也不必由本人先伪造，可分；第二步伪造出来的是信用卡本身，而信用卡诈骗罪的犯罪对象是他人的财产而非自己手中的卡，不是同一素材，不是吸收犯；伪造后通常会用于诈骗、信用卡诈骗通常有伪造举动，成立牵连犯，择一重罪处罚。

    * 明知他人包内有枪而盗窃并持有：偷到手一定持有，密不可分，第一步即定为吸收犯，整体定盗窃枪支罪一罪。

## 事后不可罚

* **事后不可罚（Post-Offense Immunity from Punishment）**

    * > **定义**：某个犯罪已经既遂，又实施另外一个犯罪行为，但第二个行为（事后的行为）不需要处罚。

    * 只有两个原因：要么没有侵害新法益，要么没有期待可能性。

* **没有侵害新法益**

    * 盗窃李四价值 6000 元的手机，用五天发现不好用就将手机摔毁：前行为盗窃罪、后行为故意毁坏财物罪，但前后针对同一部手机，被害人只遭受一份财产损失，没有侵害新法益，不并罚，直接认定盗窃罪一罪。

    * 盗窃乙的文物仿真品（价值 5000 元）后又冒充文物卖给丙并骗得钱财：事后侵害了新法益，数罪并罚，以盗窃罪与诈骗罪并罚。

    * 盗窃淫秽光盘后又出售：违禁品也能成为盗窃对象，前行为构成盗窃罪，后行为构成贩卖淫秽物品牟利罪，侵害新法益，数罪并罚。

* **没有期待可能性**

    * 先偷手机又去销赃：不能要求小偷不销赃，违背人性，只定盗窃罪一罪，不能另定掩饰罪。

    * 甲杀人后分尸毁灭证据：只定故意杀人罪一罪，不能按杀人罪与毁坏尸体罪数罪并罚。

## 罪数层级与易混类型

* **三个层级**

| 层级 | 包含的类型 |
| :--- | :--- |
| 实质的一罪 | 继续犯、想象竞合犯、结果加重犯 |
| 法定的一罪 | 结合犯、集合犯（此外补充了转化犯） |
| 处断的一罪 | 连续犯、牵连犯、吸收犯、事后不可罚 |

    * 想象竞合犯关联法条竞合问题；共讲了九种"犯"，加上法条竞合与转化犯共十一个。

* **各类型的速览**

    * **继续犯**：最重要的特征是实行行为与不法状态同时存在、同时开始、同时结束，典型如非法拘禁罪。

    * **想象竞合犯**：一个行为触犯数个罪名，从一重罪处罚。

        > **定义**：行为人在数个不同的具体罪过支配下实施的一个危害行为。与法条竞合的区别关键看有没有满足全面评价的要求——满足全面评价的就是法条竞合，要全面评价客体、结果和主观；特别法比一般法多一点内容、多一点要素，如一杯白开水与一杯加茶叶的白开水，一般法法条中有结果，特别法肯定也有结果。

    * **结果加重犯**：公式是基本行为 + 加重结果 = 基本罪名 + 加重处罚；故意犯罪和过失犯罪都有构成结果加重犯的可能。

    * **结合犯**：我国刑法没有规定，但有非典型结合 A + B = A、B 的形式，且必须有立法明文规定。

    * **转化犯**：A 转化成 B，转化成 B 之后不实行数罪并罚。

    * **集合犯**：分职业犯和营业犯。

    * **连续犯**：要求触犯相同罪名，主观上有同一的或概括的故意，先有总犯意，客观实施行为在计划范围内的才可能是连续犯，超出计划的一律不是。

    * **牵连犯**：手段目的牵连、原因结果牵连，原则择一重、例外并罚。

    * **吸收犯**：吸收必经阶段、组成部分、当然结果，一律以吸收之罪论处不并罚。

    * **事后不可罚**：第二个行为不可罚的两大原因是没有侵害新法益、没有期待可能性。

* **几组容易混的**

    * **继续犯与想象竞合犯**：本质一样，客观上只有一个行为，区别是触犯的罪名数不同；继续犯触犯一个罪名（非法拘禁不论多久只有一个罪），想象竞合犯是一个行为触犯两个罪名。

    * **想象竞合犯与结果加重犯**：关键看刑法是否明文规定了一个更重的法定刑，有则是结果加重犯，没有则是想象竞合犯；两者如双胞胎，结果加重犯因取得法律认可而被称为"第一长子"。

    * **转化犯与结果加重犯**：结果加重犯罪名不变、法定刑上升，转化犯罪名改变；关键看罪名是否发生改变。

    * **集合犯与连续犯**：相同点都是数罪、触犯相同罪名；区别看有没有法律的明文规定，有法律规定的是集合犯。集合犯下分职业犯与营业犯，非法行医是职业犯（行医在生活中确是职业），赌博只是营业犯，连续杀五个人不可能是职业犯或营业犯，故称连续犯；两者区分意义不大，因为都是同种数罪、触犯相同罪名。

    * **牵连犯与吸收犯**：区分最困难，官方教材本身也在打太极。

    * > **提示**：想象竞合与法条竞合、牵连犯与吸收犯这两组争议极大，不要在争议区域消耗精力；把官方教材的典型例子掌握到位即可。

    * 罪数这一章的真题、模拟题正确率要等分则结束之后才会明显提高——罪数要考察具体罪名，而罪名本身当时还没讲。

## 罪数解题顺序

* **三步走**

    * 罪数板块唯一重要的切入点是**判断行为数量**：一个行为只能是实质的一罪，两个行为才可能是法定的一罪或处断的一罪；后期训练案例分析题、以及以小案例形式出现的选择题都走同一套路。

```text
  案件事实
    |
    |  第一步  归纳事实：标出全部有刑法意义的相关举动 A1 A2 A3 A4 A5
    v
  相关举动清单
    |
    |  第二步  这些举动能否合并？标准：是否落在一个罪名之内
    |
    +--- 能合并 ----> 一个行为 ----> 定一罪（不再讨论）
    |
    +--- 不能合并 --> 数个行为
                        |
                        |  第三步  先找例外，而不是先想并罚
                        |
                        +-- 牵连犯    -> 按牵连处理，定一罪
                        +-- 吸收犯    -> 按吸收处理，定一罪
                        +-- 特殊规定  -> 依专门条款处理
                        |
                        有例外 -> 依例外处理
                        无例外 -> 数罪并罚
```

* **归纳事实**

    * 第一步找出案件事实中的相关举动：既包括积极举动（作为犯罪的内容），也包括消极举动（不作为犯罪的内容），有多少标多少。

    * > **易错点**：不作为不是"没动作"就可以不标，消极举动同样是犯罪内容，遗漏它行为数量一定数错。

* **判断合并**

    * 合并标准是相关举动是否落在一个罪名之内：能落在一个罪名之内就能合并成一个行为，不能被一个罪名包含就一定是两个行为。

    * 买刀、尾随、举刀砍、砍死四个举动都在杀人罪的构成要件内容之内，合并为一个杀人行为；提刀、等候、砍人、取走财物都在抢劫罪的范围之内，合并为一个抢劫行为。

* **得出结论**

    * 数个行为原则是数罪并罚，但不要先想原则，要先考虑有没有例外。

    * 例外清单顺序：排除实质的一罪（想象竞合犯、继续犯、结果加重犯都只有一个行为）→ 排除法定的一罪中的结合犯（我国立法没有）与集合犯（触犯相同罪名，题目问的是几个罪，不需要讨论）→ 排除处断的一罪中的连续犯（触犯相同罪名）与事后不可罚（两个原因都看得出来）→ 只剩牵连、吸收与特殊规定；没有例外就适用原则数罪并罚。

    * 特殊规定即情节加重犯：我国虽无结合犯，但有非典型结合，如先拐卖再强奸、先绑架再杀人、先走私贩卖运输制造毒品又妨害公务情节严重，这些情形最终仍只定一罪；书末附录已列出全部特殊规定。

## 行为数量的判断方法

* **主观犯意认领客观举动**

    * > **定义**：先确定行为人主观上是什么犯意，再看哪些举动是这些犯意的产物；是它的产物就放在一起，变成一个行为。

    * 根子是危害行为的**有意性**——危害行为是意识支配的产物和表现。先有主观犯意，后有客观举动。

    * 强奸故意认领扑倒、脱衣服、卡脖子压制反抗，构成一个强奸行为；杀人故意认领掐死，构成一个杀人行为。犯意一变，行为就断。

    * 偏僻之地看到小花本身在刑法上没有意义，不标为举动。

* **动词的含义**

    * **动词**指的是实行行为，即那个罪名中最重要的行为，不是"举动"的意思。

    * 着手的判断：主观上要有着手的意思（随时着手、计划着手），客观上要有着手的行为；着手的行为形式上要开始实施罪名中的动词，实质上是**客体遭受紧迫危险**。

| 罪名 | 罪名中的动词 | 着手长什么样 |
| :--- | :--- | :--- |
| 诈骗罪 | 骗 | 开始骗 |
| 盗窃罪 | 偷 | 开始偷 |
| 杀人罪 | 杀 | 开始杀 |
| 挪用公款罪 | 挪 | 开始挪 |

* **犯意乘以动词的四张底牌**

    * **犯意**是罪过的意思，不只指犯罪故意，过失也是，因为过失也能支配下实施过失犯罪的行为。

| 主观罪过 | 客观动词 | 行为数量 | 结论 |
| :--- | :--- | :--- | :--- |
| 一个犯意 | 一个动词 | 一个行为 | 定一罪 |
| 一个犯意 | 多个动词 | 不必细究 | 集合犯、连续犯，不是难点 |
| 两个犯意 | 一个动词 | 一个行为 | 想象竞合，从一重 |
| 两个犯意 | 两个动词 | 数个行为 | 原则数罪并罚，先找例外 |

    * 一个犯意多个动词：主观上有非法行医的犯意、客观上多次实施"非法行医"这个动词，是集合犯；主观上有连续杀人的犯意、客观上砍很多人，是连续犯。

    * 两个犯意一个动词：一枪打死宠物狗又打死了一个人，对狗的死亡有故意毁坏财物的故意、对人的死亡有过失，两个罪过；客观上只有"开枪"这一个动词，该动作既是毁坏财物的实行行为也是过失致人死亡的行为，成立想象竞合犯。

    * 两个犯意两个动词：杀人骗保中故意杀人故意支配下把人杀死、保险诈骗故意支配下实施保险诈骗，"杀"与"骗"两个动词对应两个犯意，是两个行为。

* **买枪也算动词**

    * 买枪的"买"是动词，开始"买"即着手实施非法买卖枪支的行为；"杀"也是动词。

    * 为杀人并骗保而购枪、一枪打死李四：两个犯意、两个动词，是两个行为，数罪并罚。

* **人还没杀就被抓**

    * 主观上两个犯意（买枪是为杀人，计划是先买枪再杀人）；客观上只有一个动词"买"，买到手即被抓，尚未开始"杀"。

    * 非法买卖枪支罪已既遂；就故意杀人罪而言属于预备行为。

    * 结论：故意杀人罪（预备）与非法买卖枪支罪（既遂）**想象竞合，从一重**。

* **杀完没来得及骗**

    * 给妻子买人身意外险、打算先杀再骗，杀死小花后未及索赔即因杀人被抓：主观两个犯意，客观只有"杀"一个动词。

    * "杀"对故意杀人罪是实行行为，对保险诈骗罪只是预备行为。

    * 结论：故意杀人罪和保险诈骗罪（预备）**想象竞合，从一重**。

* **杀完再去索赔**

    * 杀死小花后到保险公司索赔，被保险公司察觉报警：主观两个犯意（杀人故意、保险诈骗故意），客观"杀"与"骗"两个动词都开始了，只是保险诈骗未成功。

    * 两个犯意对应两个动词，是两个行为；虽属牵连犯，但基于刑法特别规定，按**故意杀人罪和保险诈骗罪（未遂）实行数罪并罚**。
