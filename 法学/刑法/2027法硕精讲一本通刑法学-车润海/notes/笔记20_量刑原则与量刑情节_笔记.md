# 量刑原则与量刑情节

## 量刑的概念、特征与功能

* **量刑（刑罚裁量）**

    * > **定义**：人民法院根据刑事法律，在认定犯罪人构成犯罪的基础上，确定对犯罪人是否判处刑罚、判处何种刑罚、判处多重的刑罚，并决定对所判刑罚是否立即执行的刑事司法活动。

    * 落脚点永远在"认定构成犯罪"之后，定罪是量刑的前提。
    * 由四个首尾相接的决定组成。
    * 第一步定"判不判"：判，即定罪量刑；不判，即定罪免刑。
    * 第二步定"判哪一种"：主刑还是附加刑。
    * 第三步定"判多重"：如判有期徒刑，到底判几年。
    * 第四步定"是否立即执行"：立即执行则交付执行，不立即执行则宣告缓刑、设考验期。

    ```text
       犯罪事实 -> [认定构成犯罪] -> 是否判处刑罚
                                           |
                              +------------+------------+
                              |                         |
                         判（定罪量刑）          不判（定罪免刑）
                              |
                              v
                     判处何种刑罚（主刑 / 附加刑）
                              |
                              v
                     判处多重刑罚
                              |
                              v
                     是否立即执行？
                        /            \
                   立即执行         不立即执行
                  交付执行      宣告缓刑 + 考验期
    ```

* **量刑的特征**

    * 主体只能是人民法院。
    * 内容是对犯罪人确定刑罚。
    * 性质是一种刑事司法活动。

* **量刑的功能**

    * 是使法定的罪刑关系变成实在的罪刑关系的必要条件，在整个刑事诉讼过程中承前启后。
    * 法条只给出法定刑区间（如抢劫罪三年以上十年以下），这是法定的罪刑关系；量刑后才得出具体刑期，这是实在的罪刑关系。
    * 承前是定罪，启后是交付执行，之后才有减刑、假释与刑罚消灭。

    ```text
       抢劫罪：三年以上十年以下            <- 法定的罪刑关系（纸面刑）
            |
            |  量刑
            v
       张三：处五年有期徒刑，并处罚金        <- 实在的罪刑关系

       定罪 ---> 量刑 ---> 交付执行 ---> 减刑、假释 ---> 刑罚消灭
                 (承前)      (启后)
    ```

## 量刑原则

* **以犯罪事实为根据，以法律为准绳**

    * 刑法第61条可以劈成两半：前半"根据犯罪的事实、性质、情节和对于社会的危害程度"即以犯罪事实为根据；后半"依照本法的有关规定判处"即以法律为准绳。
    * 犯罪事实是产生刑事责任的基础，也是对犯罪人量刑的根据。
    * 没有犯罪事实就没有刑事责任，更不可能对犯罪人裁量刑罚。
    * 以法律为准绳同时是罪刑法定原则的要求；刑事法律无非是总则与分则两块。

* **以法律为准绳的三条具体要求**

    * 其一，必须依照刑法关于各种刑罚方法的适用条件和各种刑罚裁量制度的规定。
    * 其二，必须按照刑法关于各种量刑情节的适用原则和各种量刑情节的规定，既守总则也守分则。
    * 其三，必须依照刑法分则和其他刑法规范（如单行刑法）所规定的法定刑量刑幅度，针对具体犯罪选择判处适当的刑罚。

## 量刑情节的含义与特征

* **量刑情节（刑罚裁量情节）**

    * > **定义**：人民法院对犯罪分子裁量刑罚时，应当考虑的、据以决定量刑轻重或者免除处罚的各种情况。
    * 要加两个定语：人民法院应当考虑的、影响刑罚轻重或者免除处罚的。

* **量刑情节与定罪无关**

    * 量刑情节不能影响定罪；即使完全不考虑该情节，行为人也成立犯罪。
    * 检验办法很干脆：把所谓的量刑情节拿掉，拿掉之后剩下的事实还能构成犯罪，它才是量刑情节；拿掉之后构不成犯罪，它就是定罪条件。
    * 报复陷害罪的"情节严重"不是犯罪成立条件，未达该程度也构成基本犯，故属量刑情节。
    * 侮辱罪、诽谤罪的"情节严重"是成立条件，属构成犯罪的条件。
    * > **易错点**：一个情节不能在定罪中评价一次、又在量刑中评价一次，否则构成重复评价。

* **对量刑结果的直接影响与法理基础**

    * 量刑情节对处刑轻重或者是否免除处罚具有直接影响，如犯罪中止且没有造成损害的应当免除处罚。
    * 凡是能影响刑罚轻重的情节，都表明犯罪人的人身危险性和社会危害性，与罪责刑相适应原则挂钩。

## 法定情节与酌定情节

* **法定情节**

    * 怎么来的：刑法明文规定的。
    * 怎么用：量刑时应当予以考虑的情节。

* **酌定情节**

    * 怎么来的：人民法院从审判经验中总结出来的。
    * 怎么用：量刑时灵活掌握、酌情适用的情节。

* **总则性情节与分则性情节**

    * 划分标准是规定法定情节的刑法规范的性质以及法定情节的适用范围。
    * 总则性情节由刑法总则规定，对各种犯罪共同适用，如中止犯、未成年人犯罪应当从轻或者减轻处罚、自首。
    * 分则性情节由刑法分则规定，只对特定犯罪适用，如刑法第386条索贿从重处罚只针对受贿罪。
    * > **注意**：索贿从重只针对受贿罪，不是所有罪都有这条。

* **按功能划分的四种法定情节**

    * 从重处罚、从轻处罚、减轻处罚、免除处罚。

## 从重处罚与从轻处罚

* **从重处罚**

    * > **定义**：在法定刑幅度内选择判处比没有该情节的类似犯罪相对较重的刑种或刑期。
    * 参照物是"没有该情节的类似犯罪"，不是一个抽象基准。
    * 例：甲乙构成共同犯罪，作用相同、分赃数额相同，原本同判一年；甲具有累犯情节判一年两个月，即为从重。

* **从轻处罚**

    * > **定义**：在法定刑幅度内选择判处比没有该情节的类似犯罪相对较轻的刑种或刑期。
    * 例：法定刑三年以上十年以下，按事实本应判十年，因自首判九年六个月，仍然是从轻处罚。

* **法定刑的限度以内**

    * 刑法第62条：具有从重、从轻处罚情节的，应当在法定刑的限度以内判处刑罚。
    * 刑法第99条：本法所称以上、以下、以内包括本数，故"限度以内"含本数。
    * 从轻的底线是法定最低刑整，有从轻情节最低可以判到该最低刑整。
    * 从重的天花板是法定最高刑整，有从重情节最高只能到该最高刑整。
    * > **易错点**：从重与从轻跟法定刑幅度的所谓"中间线"没有任何关系，判在中线以下不一定是从轻，判在中线以上也不一定是从重。

* **法定刑幅度的确定**

    * 法定刑幅度指与具体犯罪相适应的那个法定刑幅度；一个罪名可能规定两档甚至三档，不能乱找。
    * 诈骗罪三档：数额较大处三年以下；数额巨大处三年以上十年以下；数额特别巨大处十年以上或无期徒刑。
    * 甲诈骗数额巨大即对应第二档，其从重从轻只能在 3 到 10 之间。
    * > **易错点**：不能因为要从轻就挑最低那档、要从重就挑最高那档，要找行为应当适用的那一档。

## 减轻处罚

* **法定减轻处罚（一般减轻）**

    * > **定义**：犯罪分子具有本法规定的减轻处罚情节的，应当在法定刑以下判处刑罚；本法规定有数个量刑幅度的，应当在法定刑幅度的下一个量刑幅度内判处刑罚。
    * 法定减轻情节的例子：防卫过当、造成损害的中止犯、刑法第27条从犯、第28条胁从犯。

* **酌定减轻处罚（特殊减轻）**

    * > **定义**：犯罪分子虽不具有本法规定的减轻处罚情节，但根据案件的特殊情况，经最高人民法院核准，也可以在法定刑以下判处刑罚。
    * 成立条件三条：犯罪分子不具有法定减轻处罚情节；案件有特殊情况；经最高人民法院核准。
    * 核准权放在最高人民法院，是因为它属于量刑问题，特殊情况须找最高法。

* **减轻处罚的四条共性边界**

    * 其一，在法定刑"以下"判处刑罚，"以下"必须理解成"之下"，必须判处低于法定最低刑的刑罚。
    * 其二，法定最低刑是与行为人所实施的特定具体犯罪相适应的那个量刑幅度的最低刑。
    * 其三，只能在法定量刑幅度的下一个量刑幅度内判处刑罚，不能跨档。
    * 其四，既包括刑种减轻，也包括刑期减轻。

* **"以下"不含本数的补正解释**

    * 刑法虽规定以上、以下、以内包括本数，但减轻处罚中的"以下"不能包括本数。
    * 若"以下"含本数，判出法定最低刑整就同时构成从轻与减轻，两个情节在同一点上撞车。
    * 诈骗数额巨大对应三年以上十年以下：判三年整只能是从轻，判两年十个月、两年十一个月才是减轻。
    * 故意伤害法定刑三年以上十年以下，具有减轻情节则必须低于三年，判三年整即造成减轻与从轻的混淆。
    * 这属于补正解释，把法条用语的正确含义表达出来。

    ```text
       法定刑幅度：三年以上十年以下

       从轻处罚：法定刑"以内" -> 以内含本数 -> 可以判 3 年整
       减轻处罚：法定刑"以下" -> 以下若含本数 -> 也能判 3 年整
                                              |
                                              v
                                    从轻与减轻在 "3 年整" 处撞车
                                              |
                                              v
                                    判 3 年整，到底是从轻还是减轻？
                                              |
                                              v
                                    补正解释：把"以下"解释为"之下"
    ```

* **减轻只能逐档不能跨档**

    * 诈骗罪数额特别巨大对应第三档十年以上至无期，减轻后只能进入第二档三年以上十年以下。
    * 从第三档直接减到第一档判三年以下不被允许；立法明文规定只能逐档减轻。
    * 允许跨档则法律失去稳定性，权力过大。
    * 过失致人死亡罪第一档三年以上七年以下，法定最低刑即三年；减到第三档以下须在第二档三年以下有期徒刑内判处。

* **刑种减轻与刑期减轻**

    * 刑种减轻：绑架罪杀害被绑架人处无期徒刑或者死刑，具有减轻情节时无期以下不含无期，只能改判有期徒刑。
    * 刑期减轻：诈骗数额特别巨大本应判十五年有期徒刑，减轻后在第二档判九年，刑种未变而刑期缩短。
    * 故意杀人罪处死刑、无期徒刑或者十年以上有期徒刑，减轻后在下一档判且不得判到十年整，判出的仍是有期徒刑。

## 免除处罚

* **免除处罚**

    * > **定义**：对犯罪人作有罪宣告，同时决定免除刑罚处罚，即定罪免刑。
    * 立法情形：中止犯没有造成损害的应当免除处罚；胁从犯应当减轻处罚或者免除处罚。
    * 适用条件三条：已经构成犯罪；犯罪情节较轻、轻微；因犯罪情节轻微不需要判处刑罚。
    * 免除的是刑罚处罚，是不判刑，不等于什么也不做；符合条件的可以适用非刑罚处理方法。

## 酌定情节

* **七种酌定情节**

    * 犯罪动机：为给自己看病而盗窃与为嫖娼而盗窃，数额相同，后者动机卑劣，量刑更重。
    * 犯罪手段：一枪将人打死与将人折磨致死，手段会影响量刑。
    * 犯罪的时间和地点：偏僻之地深夜杀人与人群中杀人，后者引起不特定多数人恐慌并破坏氛围。个别犯罪的地点是法定的，如抢劫罪中的"入户抢劫"。
    * 犯罪侵害的对象：将孕妇打成轻伤与将马蜂打成轻伤，同为轻伤二级，侵害孕妇更可恶，量刑更重。
    * 犯罪造成的损害结果：偷十万被害人平安无事与偷十万被害人自杀，后者量刑更重。
    * 犯罪分子的一贯表现：一贯表现好而激情犯罪较轻，一贯恶贯满盈较重。
    * 犯罪后的态度：认罪悔罪、积极赔偿、取得谅解较轻，扬言报复较重。

* **七项的记忆维度**

    * 主观：犯罪动机；过去：犯罪分子的一贯表现；现在：犯罪后的态度。
    * 客观：犯罪手段、犯罪时间和地点、犯罪侵害的对象、犯罪造成的损害结果。
    * 客观项的联想顺序是行为、对象、结果、时间、地点、方法；行为由法律规定不考虑，因果关系也不考虑，"方法"即犯罪手段。
    * 故意伤害罪的对象"他人身体"是法定的，但"他人"是孕妇还是健康人这一细微差别法律不可能规定，所以对象可以是酌定的。

* **酌定情节的适用要求**

    * 全面准确、公正合理，四组关键词。
    * 准确：准确认定酌定情节的性质，酌定情节同样包含从严情节与从宽情节。
    * 全面：全面把握酌定情节的内容。
    * 合理：合理协调法定情节与酌定情节的关系，法定情节优先适用。
    * 公正：公正适用酌定情节。

## 累犯

* **累犯**

    * > **定义**：因犯罪受过一定的刑罚处罚，在刑罚执行完毕或者赦免以后，于法定期限内再犯一定之罪的罪犯。
    * 分为一般累犯与特别累犯（又称特殊累犯）。
    * 从重处罚的根据：累犯所犯之罪往往具有更严重的一般社会危害性，主观恶性和人身危险性较初犯更严重。
    * 同时体现罪责刑相适应原则（对任何犯罪人考虑刑罚都必须符合）与刑罚个别化原则（同一共同犯罪中是否构成累犯要因人而异）。

* **一般累犯的成立条件（五、有、十八、故）**

    * 五：后罪发生在前罪刑罚执行完毕或者赦免以后五年以内。
    * 有：前罪被判处的刑罚与后罪应当判处的刑罚都必须是有期徒刑以上刑罚。
    * 十八：前罪、后罪发生的时候都必须已满十八周岁。
    * 故：前罪、后罪都必须是故意犯罪。
    * 四个条件必须同时满足，有一个不符合即不构成。

* **一般累犯的刑度与罪名对应**

    * 主刑排序为管制、拘役、有期徒刑、无期徒刑、死刑；"有期徒刑以上"包括有期徒刑、无期徒刑、死刑，不包括管制与拘役。
    * 前后罪存在数个罪名时，构成累犯的对应关系逐个罪名计算，不是整包成立。
    * 例：前罪故意伤害判三年，后罪为盗窃罪（应处四年有期徒刑）与使用虚假身份证件罪（应处管制），只就盗窃罪构成累犯。
    * > **易错点**：甲因诈骗判三年，刑满释放第二年又犯失火罪判一年，失火罪是过失犯罪，不构成累犯。

* **一般累犯的时间与刑罚执行**

    * 五年以内从刑满释放之日起算，不往前延伸。
    * "刑罚执行完毕"仅指主刑执行完毕，不包括附加刑；附加刑尚未执行完毕不影响成立累犯。
    * 被假释的犯罪分子，五年期限从假释期满之日起计算。
    * 赦免指特赦减免，由全国人大常委会作出决定、国家主席发布特赦令，法院没有权力决定赦免。
    * 后罪发生在前罪刑罚执行期间的，不构成累犯，应数罪并罚。
    * 有期徒刑以上刑罚包括死刑缓期执行，但不包括死刑立即执行。

    ```text
       前罪：故意伤害罪，判三年有期徒刑
            |
            +--- 刑罚执行期间 ---> 后罪落在此段：数罪并罚，不构成累犯
            |
            |    刑满释放日 <--- 五年期限从这一天起算
            |
            +--- 5 年以内 -------> 后罪落在此段：可构成一般累犯
            |
            +--- 5 年以后 -------> 后罪落在此段：一般累犯不成立
    ```

* **特别累犯**

    * > **定义**：危害国家安全犯罪、恐怖活动犯罪、黑社会性质组织的犯罪分子，在刑罚执行完毕或者赦免以后，在任何时候再犯上述任一类罪的，以累犯论处。
    * 罪名条件：前罪、后罪都属于危害国家安全、恐怖活动、黑社会性质组织"国、恐、黑"三类之一，不要求一一对应，可以交叉。
    * 刑度条件：刑种及其轻重不受限制，只要求前罪被判处刑罚，哪怕单独判处附加刑也行。
    * 时间条件：任何时候再犯都成立，不受五年期限限制。
    * 前后罪有一方不属于"国、恐、黑"三类之一即不成立。

* **两个易混罪名**

    * 故意泄露国家秘密罪属于渎职罪，不属于危害国家安全犯罪。
    * 非法获取国家秘密罪属于妨害社会管理秩序罪，不属于危害国家安全犯罪。

* **特别累犯的定罪免刑陷阱**

    * 前罪被免除处罚（定罪免刑）时，不存在"刑罚执行完毕"或者"赦免"，一般累犯与特别累犯都不能成立。
    * 例：参加黑社会性质组织罪情节轻微被免除处罚，判决生效第3年又犯分裂国家罪（应处3年有期徒刑），不构成特别累犯。
    * > **易错点**：特别累犯刑度上只要求前罪被判刑，哪怕只判附加刑也行，唯独不能定罪免刑。

* **未成年人能否构成累犯**

    * 理论上存在争议，司法实践观点也不一样。
    * 多数观点认为未成年人既不能构成一般累犯，也不能构成特别累犯。

* **累犯与再犯的四个区别**

    * 罪名：累犯要求特定犯罪（一般累犯为故意犯罪，特别累犯限于国、恐、黑）；再犯对前后罪没有限制。
    * 刑度：累犯一般要求前后罪被判处或应当被判处一定的刑罚；再犯不要求。
    * 时间：累犯要求后罪发生在前罪刑罚执行完毕或赦免后的法定期限之内（主要指一般累犯的五年）；再犯无时间限制。
    * 后果：累犯更重，再犯相对较轻。

* **累犯的四大后果**

    * 应当从重处罚。
    * 不能适用缓刑。
    * 不能假释，不能提前释放。
    * 被判处死缓的可以限制减刑。

* **"应当从重处罚"的三层含义**

    * 必须从重处罚，这是刚性的，没有裁量空间。
    * 要比照不构成累犯的人从重处罚，参照系是"不构成累犯的人"。
    * 具体判处的刑罚必须根据犯罪的事实、性质、情节、社会危害程度确定，不能毫无事实根据地对累犯一律判处法定最高刑。
    * > **易错点**：法定刑 3 到 10 年时原判 3 年、考虑累犯判 3 年半即已是从重，不是一定要判法定最高刑。

## 一般自首的自动投案

* **一般自首**

    * > **定义**：犯罪分子犯罪以后自动投案，如实供述自己罪行的行为。
    * 两大条件缺一不可：自动投案、如实供述自己罪行。

* **自动投案**

    * > **定义**：犯罪事实或者犯罪嫌疑人尚未被司法机关发觉，或者虽被发觉但犯罪嫌疑人尚未受到讯问、未被采取强制措施时，主动直接向公检法投案。
    * 判断本质是要体现"我想坐牢"的精神；方式千变万化，只能抓本质，不能看形式。
    * 投案动机不影响认定：认罪悔罪、迫于无奈、慑于法律威严、经亲友规劝而醒悟等动机都不影响。
    * 投案必须发生在犯罪以后；犯罪嫌疑人在被讯问或被采取强制措施之前都可以自动投案。
    * 投案对象可以是司法机关、有关单位，也可以是相关个人。
    * > **易错点**：询问证人一般叫"询问"，对嫌疑人用"讯问"；一旦被讯问即属被动归案，主动的前提是人身自由未受限。

* **不成立自动投案的典型情形**

    * 被亲友捆绑送到公安机关，不能认定为自动投案；可以参照自首的规定酌情从轻处罚。
    * 匿名退还赃物或者匿名报案而没有将自己置于司法机关控制下的意思，充其量是犯罪后的态度与表现。
    * 报警后随即服毒自杀，他人报警是让警察来收尸，不能成立自首。
    * 向单位领导投案并请求领导不要移送司法机关，缺乏主动性，不成立自动投案。
    * 随机拦住路人要求向其投案属于迫不得已，不能认定为自动投案。

* **先报案后自杀与先自杀后报案**

    * 犯罪后先报警、随即服毒自杀，表明其不想坐牢，不成立自首。
    * 犯罪后先自杀未死、改变主意再打电话投案并如实供述，体现"我想坐牢"，应认定为自首。

* **首次归案最关键**

    * 首次归案是被动归案的，不能成立一般自首，其后再回来投案也救不回来。
    * 甲抢劫后被抓获并取保候审，无故拒不到案被网上追逃，两年后再投案，不能成立自首。
    * 首次归案是主动的、投案后又逃跑、再回来投案的，仍有可能成立自动投案。
    * 若把被抓后逃跑再回来投案认定为自首，等于鼓励犯罪人逃跑。
    * 取保候审虽让人身自由，但首次归案时自动性已丧失。

    ```text
    行为人归案
        |
        +-- 是否体现我想坐牢的精神 -- 否 --> 被动归案，不能成立自首
        |
        +-- 是否被讯问或被采取强制措施 -- 是 --> 自动性已丧失
        |
        +-- 首次归案主动还是被动 -- 被动 --> 之后再回来投案也救不回来
        |
        +-- 首次归案主动 --> 自动投案成立 --> 再看是否如实供述自己罪行
    ```

* **职务犯罪的被动归案**

    * 贪污贿赂、渎职等职务犯罪中，在办案机关调查谈话、讯问、采取调查措施或强制措施期间，如实交代办案机关已掌握线索所针对的事实，属于被动归案，不能认定为自首。
    * 上级纪委监委直接带走并谈话调查、记录后要求签字确认的，参与调查谈话属于被动归案。
    * 由他人以"配合调查"为由把嫌疑人骗到单位的，属于诱捕式被动归案。

* **醉驾与交通事故现场投案**

    * 犯罪嫌疑人醉驾被现场查获后，经允许离开，在经公安机关通知到案或者主动到案，不能认定为自动投案。
    * 造成交通事故后保护现场、抢救伤者，向公安机关报告并配合调查的，认定为自首。

* **自动投案的八种方式**

    * 其一，先以信电投案，只要在约定的时间内去投案即可。
    * 其二，向其所在的单位、城乡基层组织或者其他有关负责人员投案。
    * 其三，仅因形迹可疑被盘问教育后主动交代。
    * 其四，犯罪后逃跑，在被通缉追捕过程中主动投案。
    * 其五，经查实确已准备去投案，或者正在投案途中被公安机关捕获。
    * 其六，因病伤或者为了减轻犯罪后果，委托他人先代为投案；受托人过去不是做人质，交代后可以出来。
    * 其七，公安机关通知犯罪嫌疑人的亲友，或者亲友主动报案后，将嫌疑人送去投案；送去投案不能捆绑。
    * 其八，并非出于犯罪嫌疑人主动，而是经亲友规劝、陪同投案。

* **视为自动投案的五种情形**

    * 其一，犯罪后主动报案，虽未表明自己是作案人，但没有逃离现场，在司法机关询问时交代自己罪行。
    * 其二，明知他人报案而在现场等待，抓捕时无拒捕行为，供认犯罪事实。
    * 其三，在司法机关未确定犯罪嫌疑人、尚在一般性排查询问时主动交代，如高铁站、地铁站逐人排查。
    * 其四，因特定违法行为被行政拘留、司法拘留、强制隔离戒毒等期间，主动向执行机关交代尚未被掌握的犯罪行为。
    * 其五，其他符合立法本意、应当视为自动投案的情形。
    * 行政拘留、司法拘留针对的是行政违法而非犯罪，行为人未被讯问、未被采取刑事强制措施，所以仍可成立自动投案。

* **形迹可疑与犯罪嫌疑的分水岭**

    * 形迹可疑是走路鬼鬼祟祟、畏畏缩缩、眼神飘忽不定，但没有任何犯罪证据。
    * 在其身上、随身携带物品、驾乘交通工具处发现与犯罪有关的物品，即为犯罪嫌疑，属于被动归案。
    * 实质意义的检验：即便不交代，公安机关也能通过常规工作掌握犯罪证据的，不认定为自动投案；靠常规手段找不到，主动交代对确定犯罪嫌疑人身份有实质意义的，可以认定为自动投案。
    * 例一：设卡例行检查发现神色慌张而盘问，随后从其行李箱当场查获，公安本来就能掌握证据，交代无实质意义，不认定自动投案。
    * 例二：发现前方五百米有检查站而将赃物埋在路边，被盘问后交代并带领找到埋藏物，常规手段找不到，可认定自动投案。
    * > **易错点**：只有"仅因形迹可疑"被盘问教育后主动交代才能认定为自动投案；只要已搜出犯罪证据，就不再是形迹可疑。

## 如实供述自己罪行

* **如实供述自己罪行**

    * > **定义**：如实供述自己实施、并应由本人承担刑事责任的罪行；既可以是单独犯罪也可以是共同犯罪，既可以是一罪也可以是数罪。

* **主要犯罪事实的两条硬指标**

    * 一是影响定罪的事实必须如实供述。
    * 二是严重影响量刑的事实，即重要的量刑情节，也必须供述。
    * 隐瞒抢劫时持刀，既不影响定罪也不严重影响量刑，仍属如实供述。
    * 把故意杀人说成擦枪走火，连犯罪性质都改变，不成立自首。
    * 抢劫三次只供述两次，隐瞒第三次不影响抢劫罪成立，但隐瞒后失去"多次抢劫"这一情节加重，影响量刑很严重，不成立自首。
    * 抢劫三次中第三起为抢劫致人死亡，属结果加重犯，隐瞒后充其量只是普通抢劫，不成立自首。

* **身份信息的如实供述**

    * 身份信息包括姓名、年龄、前科等。
    * 供述的身份情况与真实情况有差别但不影响定罪量刑的，仍认定为如实供述。
    * 隐瞒自己真实身份等情况、影响定罪量刑的，不能认定为如实供述。
    * 谎报真实姓名不影响定罪量刑，仍可认定为自首。
    * 谎报年龄为 17 岁会适用未成年人从轻或者减轻处罚、影响量刑，不能认定为如实供述。

* **合理辩解、推诿罪责与翻供**

    * 合理辩解不影响如实供述的认定；犯罪人对事实问题和法律适用可以提出自己的见解，但不能撒谎。
    * 供述中推诿罪责、意图逃避制裁，或者大包大揽庇护同伙、意图包揽罪责的，不能认定为自首。
    * 共同犯罪下要如实供述自己，还要供述自己知道的同伙；只交代自己而隐瞒同伙是撒谎。
    * 自动投案并如实供述后又翻供的，不能认定为自首。
    * 自动投案并如实供述后翻供，但在一审判决前又能如实供述的，应当认定为自首。
    * > **易错点**：一审阶段翻供、二审阶段又如实供述的，不能认定为自首。

* **供述的时间**

    * 自动投案时没有交代主要犯罪事实，但在司法机关掌握其主要犯罪事实之前主动交代的，仍可认定为如实供述自己罪行。

## 特别自首

* **特别自首**

    * > **定义**：被采取强制措施的犯罪嫌疑人、被告人和正在服刑的罪犯，如实供述司法机关还未掌握的本人其他罪行的，以自首论。
    * 三类主体都已丧失自动投案的可能，因此对如实供述的要求高于一般自首；否则只要如实供述即可，对一般自首不公平。
    * 成立要同时满足两个指标：司法机关尚未掌握；属于本人其他罪行。

* **特别自首的三类主体**

    * 被采取强制措施的犯罪嫌疑人；刑事强制措施包括拘传、拘留、逮捕、取保候审、监视居住。
    * 被告人。
    * 正在服刑的罪犯，指已经人民法院判决、正在执行所判刑罚的罪犯。
    * > **易错点**：正在服刑未必是在监狱服刑，管制执行期间同样属于正在服刑的罪犯。

* **第一个指标：司法机关尚未掌握**

    * 司法机关已经掌握的罪行不属于"其他罪行"，不能成立特别自首，充其量是坦白。
    * 甲因诈骗被通缉，潜逃期间又盗窃被当场抓获，如实供述此前的诈骗事实，该事实已被通缉已被掌握，就诈骗而言充其量是坦白。
    * "司法机关已经掌握"指有证据证明的罪行；办案机关掌握的线索所针对的犯罪事实并不成立时，不算数。
    * 甲因涉嫌受贿被采取强制措施，办案人员查证发现证据不足，甲在掌握线索之外又交代了能构成受贿罪的新事实，可以成立自首。

* **第二个指标：本人其他罪行**

    * > **结论**：其他罪行 = 罪名不同且关系不密切。
    * 罪名相同的即为同种罪行，不能成立特别自首。
    * 罪名不同但属于选择罪名，或者在法律和事实上具有密切关联的（吸收犯、牵连犯），也按同种罪行处理。
    * 甲因受贿被逮捕，又供述因受贿而实施的滥用职权罪，两者属原因与结果的牵连关系，不能成立特别自首，充其量是坦白。
    * 拐卖妇女与拐卖儿童属于"拐卖妇女、儿童罪"的选择罪名，法律上密切关联，不能成立特别自首。
    * 如实供述的同种罪行，可以酌情从轻处罚。

    | 供述的内容 | 认定 | 法律后果 |
    | :--- | :--- | :--- |
    | 司法机关尚未掌握，且罪名不同、关系不密切的罪行 | 本人"其他罪行" | 以自首论，成立特别自首 |
    | 司法机关已经掌握的罪行 | 不属于"其他罪行" | 不能成立特别自首，充其量是坦白 |
    | 尚未掌握，但罪名相同的罪行 | 同种罪行 | 不能成立特别自首 |
    | 尚未掌握，罪名不同但关系密切（选择罪名、吸收犯、牵连犯）的罪行 | 同种罪行 | 不能成立特别自首，充其量是坦白 |
    | 如实供述的同种罪行 | —— | 可以酌情从轻处罚 |

* **过失犯罪也能自首**

    * 过失犯罪之后自动投案、如实供述的，同样成立自首；如交通肇事撞死人后自动投案并如实供述。

## 自首的关联问题

* **共同犯罪人自首的供述范围**

    * 如实供述的范围与其在共同犯罪中的作用和具体分工相适应，大的方向是先交代自己、再交代同伙。
    * 首要分子须供述其组织、策划、指挥作用下的全部罪行。
    * 其他主犯但头上有首要分子的，须供述在首要分子组织、策划、指挥作用下单独实施的共同犯罪行为。
    * 与首要分子无关系的一般共同犯罪中的主犯，须供述自己与其他共同犯罪人共同实施的犯罪行为。
    * 次要实行犯（从犯）须先交代自己实施的犯罪，再交代与自己共同实施犯罪的主犯和胁从犯的犯罪行为。
    * 帮助犯（从犯）须先交代自己的帮助行为，再交代自己所帮助的实行犯的犯罪行为。
    * 胁从犯须先交代自己在被胁迫情况下实施的犯罪，再交代所知道的同伙以及胁迫自己犯罪的人所实施的犯罪行为。
    * 教唆犯须先交代自己实施的教唆行为，再交代所知道的被教唆人产生犯罪意图后实施的犯罪行为。
    * 供述范围限于自己实施并应由本人承担刑事责任的罪行；供出与己罪责无关的他人犯罪属于揭发，可能成立立功。
    * 只交代自己、刻意隐瞒同伙是大包大揽、搞个人英雄主义，不能认定为如实供述。

    | 行为人的身份 | 必须如实供述的内容 |
    | :--- | :--- |
    | 首要分子 | 其组织、策划、指挥作用下的全部罪行 |
    | 其他主犯，但头上有首要分子 | 在首要分子组织、策划、指挥作用下单独实施的共同犯罪行为 |
    | 与首要分子无关系的一般共同犯罪中的主犯 | 自己与其他共同犯罪人共同实施的犯罪行为 |
    | 次要实行犯（从犯） | 先交代自己实施的犯罪，再交代与自己共同实施犯罪的主犯和胁从犯的犯罪行为 |
    | 帮助犯（从犯） | 先交代自己的帮助行为，再交代自己所帮助的实行犯的犯罪行为 |
    | 胁从犯 | 先交代自己在被胁迫情况下实施的犯罪，再交代所知道的同伙以及胁迫自己犯罪的人所实施的犯罪行为 |
    | 教唆犯 | 先交代自己实施的教唆行为，再交代所知道的被教唆人产生犯罪意图后实施的犯罪行为 |

* **数罪一般自首**

    * 认定的难点不在自动投案，而在是否如实供述所犯全部数罪。
    * 全部供述的，全案均成立自首。
    * 异种数罪部分供述的，供述之罪成立自首，未供述的犯罪不是自首，效力仅及于供述之罪。
    * 同种数罪供述与未交代部分在犯罪的事实性质、情节和社会危害程度上大致相当，供述之罪成立自首，效力仅及于供述之罪。
    * 大致相当要求供述的要多一点、隐瞒的要少一点；盗窃十次一百万元只供述五次五十万元，一般认为尚不成立自首。
    * 因主客观原因只供述主要或基本罪行的，全案成立自首。
    * 数罪特别自首即把特别自首概念列上去：三类人如实供述司法机关未掌握的本人非同种罪行，以自首论。
    * 特别自首往往涉及数个罪，如因盗窃被抓又交代未掌握的抢夺事实，就抢夺罪成立特别自首，此时已构成数罪中的自首。

    ```text
    数罪一般自首（自动投案已成立）
    +-- 全部供述 --> 全案均成立自首
    +-- 部分供述
        +-- 异种数罪 --> 供述之罪成立自首，效力仅及于供述之罪
        +-- 同种数罪
            +-- 大致相当（供述要多一点） --> 供述之罪成立自首，效力仅及于供述之罪
            +-- 因主客观原因只供述主要或基本罪行 --> 全案成立自首
    ```

* **单位犯罪自首的主体与效果**

    * 可以代表单位体现单位意志去自首的三种情形：单位集体决定；单位负责人决定；单位直接负责的主管人员自动投案并如实交代单位犯罪事实。
    * 单位已自首，直接负责的主管人员和直接责任人员未自动投案但如实交代自己实施的犯罪事实的，可以视为自首，因为他们已被代表。
    * 上述人员拒不交代或者逃避法律追究的，不成立自首。
    * 单位没有自首、只是直接责任人员自动投案并如实交代的，只能对这一人认定自首，单位不成立自首。

## 坦白

* **坦白**

    * > **定义**：犯罪分子被动归案以后，如实供述自己罪行，并接受司法机关审查和裁判的行为。
    * 前提是不成立自首；构成自首的直接认定自首，不再考虑坦白。
    * 自首本身包含坦白，有自首情节优先认定，没有自首情节才可能认定为坦白。
    * 法律后果：可以从轻处罚；因如实供述自己罪行，避免特别严重后果发生的，可以减轻处罚。
    * 通常可把坦白区分为一般坦白与重大坦白，但这两个名称并非法定术语。

* **自首与坦白的相同点**

    * 记忆逻辑是"犯罪后交代，审判时从宽"。
    * 一、都以实施犯罪行为为前提。
    * 二、都是归案以后如实交代自己的犯罪事实。
    * 三、都是审判时从宽，都有接受国家司法机关审查和裁判的行为。
    * 四、都是法定的从宽处罚情节。

* **自首与坦白的不同点**

    * 概念不同：自首要自动投案或供述司法机关未掌握的本人其他罪行，坦白只是被动归案后如实供述。
    * 所反映的人身危险性程度不同：自首较轻，坦白较重；自首的从宽幅度通常大于坦白。
    * 法律后果不同：自首可以从轻或者减轻处罚，犯罪较轻的可以免除处罚；坦白一般从轻，避免特别严重后果发生的可以减轻处罚。

## 立功

* **立功**

    * > **定义**：犯罪分子揭发他人犯罪行为，查证属实，或者提供重要线索，从而得以侦破其他案件等行为。
    * 分为一般立功与重大立功两档。

* **立功的主体与时间**

    * 立功的主体只能是犯罪分子本人，谁犯罪谁立功。
    * > **易错点**：亲友不能代为立功，没有犯罪的人谈不上刑法意义上的立功。
    * 立功的时间是到案以后，不是犯罪以后。
    * "到案"作扩大解释，包括司法机关在内的所有国家机关、党群组织、所在单位等一切能够接触、约束犯罪嫌疑人的主体。
    * 自首是犯罪以后随时可成立，立功一定要到案以后才能成立。
    * 例：甲因挪用公款被单位领导约谈，甲主动联系监委揭发他人受贿事实，已属到案，查证属实可以成立立功。
    * 例：甲乙共同伤害他人，警察误将甲当作目击证人，甲指认乙逃跑方向导致乙被抓，甲既未到案也未表明犯罪人身份，不构成立功。

* **立功从宽处罚的两个指标**

    * 法律上看，行为人揭发或者阻止他人犯罪，表明其对犯罪行为的痛恨，人身危险性、再犯可能性降低。
    * 政策上看，行为人揭发或者阻止他人犯罪，有利于节约司法资源。
    * 和这两个指标无关的，不得认定为立功。
    * 犯罪后为获得从宽而提出捐款一千万元，既不节约司法资源也不体现人身危险性降低，不构成立功。
    * 揭发其父贪污事实，查证属实，成立立功。

* **立功的四种表现**

    * 揭发型：检举揭发他人犯罪行为。
    * 线索型：提供侦破其他案件的重要线索。
    * 协助型：协助抓捕其他犯罪嫌疑人。
    * 其他型：兜底的其他有利于国家和社会的突出表现，如阻止他人实施犯罪活动。
    * 一般立功与重大立功都是这四个方向，每一项都有各自细节。

* **揭发型立功：揭发的必须与自己无关**

    * > **定义**：犯罪分子到案后，检举揭发他人犯罪行为，包括共同犯罪案件中的犯罪分子揭发同案犯共同犯罪以外的其他犯罪，经查证属实，认定为立功。
    * 要点一：揭发的内容必须是犯罪行为；他人有没有被实际追究刑事责任并不重要。
    * 要点二：揭发同案犯的共同犯罪事实属于如实供述，不构成立功，可以酌情从轻处罚。
    * 要点三：只有揭发同案犯共同犯罪以外、与自己无关的其他犯罪，才构成立功。
    * 甲乙共同盗窃后甲揭发乙参与盗窃的事实，不成立立功，充其量是坦白。
    * 甲向官员行贿后自动投案并如实供述行贿经过，就行贿罪成立一般自首；再揭发该官员收受李四、王五的贿赂，与己无关，可以成立立功，既自首又立功。

* **对象犯不构成立功**

    * 行贿罪与受贿罪属于对象犯，一方的犯罪行为以相对方的行为为条件。
    * 供述自己行贿必然涉及受贿人的犯罪行为，揭发收受自己贿赂不构成立功，成立的是自首。
    * 司法解释明确：行贿人揭发受贿人与其行贿无关的其他犯罪行为，经查证属实的，才属于立功。

* **揭发型立功不成立的三种情形**

    * 教唆李四醉酒驾驶后举报李四，张三是危险驾驶罪的教唆犯，前后罪数罪并罚，不构成立功。
    * 揭发犯罪集团小弟的杀人行为，犯罪集团首要分子对集团所犯全部罪行负责，无从"揭发"，不构成立功。
    * 故意连累他人构成窝藏罪（连累犯），再揭发这四人以制造立功机会，不构成立功。

* **揭发型立功的判断结论**

    | 揭发的内容 | 是否构成立功 | 理由 |
    | :--- | :--- | :--- |
    | 李四杀人，但李四两年前已死亡 | 成立 | 只要求揭发的是犯罪行为，不要求他人被追究刑责 |
    | 乙故意毁坏财物，但属于紧急避险 | 不成立 | 紧急避险是合法行为，不是犯罪行为 |
    | 甲揭发乙参与共同盗窃 | 不成立 | 共同犯罪事实即如实供述，充其量是坦白 |
    | 甲揭发官员收受自己的贿赂 | 不成立 | 对象犯，属于如实供述，成立的是自首 |
    | 甲揭发乙单独实施的抢劫 | 成立 | 与己无关的其他犯罪 |
    | 甲揭发乙收受其他人的贿赂 | 成立 | 与己无关，成立立功，同时构成自首 |
    | 教唆李四醉驾后举报 | 不成立 | 本身是危险驾驶罪的教唆犯，数罪并罚 |
    | 揭发犯罪集团小弟的杀人 | 不成立 | 首要分子对集团全部罪行负责，无从"揭发" |
    | 揭发故意窝藏自己的四个朋友 | 不成立 | 连累犯，不符合立功的价值取向 |

    * > **结论**：揭发他人犯罪行为，切记一定是和自己无关，自己不能参与。

* **线索型立功：线索来源必须合法**

    * > **定义**：犯罪分子提供侦破其他案件的重要线索，经查证属实。"其他案件"指与己无关的其他案件。
    * 正面要求：来源必须合法。
    * 反面排除之一：通过贿买、暴力胁迫等非法手段，或者被羁押后与律师、亲友会见时违反监管规定获取的线索，来源本身非法，不能认定为立功。
    * 反面排除之二：本人履历中查办犯罪职务活动时掌握的线索，不能认定为立功。
    * 反面排除之三：从负有查办犯罪监管职责的国家工作人员处获取的线索，不能认定为立功。
    * 正面情形：偶然听到的线索（同监室吹牛、饭店听闻）来源合法，可以立功。
    * 亲友等事先告知的线索来源不影响立功认定。
    * 公安局局长被抓获后交出自己任职时刻意隐瞒的线索，不能认定为立功，甚至可能构成徇私枉法。

    | 线索来源 | 能否构成立功 |
    | :--- | :--- |
    | 贿买、暴力胁迫等非法手段获取 | 不能，来源本身非法 |
    | 被羁押后与律师、亲友会见时违反监管规定获取 | 不能，来源本身非法 |
    | 本人在查办犯罪职务活动中掌握的 | 不能，没有节约司法资源 |
    | 从负有查办犯罪监管职责的国家工作人员处获取 | 不能，没有节约司法资源 |
    | 偶然听到（同监室吹牛、饭店听闻） | 能，来源合法 |
    | 亲友等事先告知的 | 不影响立功认定，可以成立 |

* **协助型立功：协助抓捕且包括同案犯**

    * > **定义**：犯罪分子协助司法机关抓捕其他犯罪嫌疑人；包括同案犯，协助抓捕同案犯同样会节约司法资源。
    * 方式一：按司法机关的安排，以打电话、发信息等方式将其他嫌疑人（含同案犯）约到指定地点。
    * 方式二：按司法机关的安排，当场指认、辨认其他犯罪嫌疑人（含同案犯）。
    * 方式三：带领侦查人员抓获其他犯罪嫌疑人（含同案犯），简称"带捉"。
    * 方式四：提供司法机关尚未掌握的其他案件犯罪嫌疑人的联络方式、藏匿地址，司法机关据此将其抓捕。

* **提供同案犯基本情况不构成立功**

    * 提供同案犯的姓名、住址、体貌特征等基本情况，或者提供犯罪前、犯罪中掌握的同案犯联络方式、藏匿地址，司法机关据此抓捕的，不能认定为立功。
    * 法理：这些是犯罪人应当如实供述的内容，充其量是坦白。
    * 甲与马峰共同抢劫，描述马峰"很壮、国字脸、短头发、戴眼镜、近视"并给出其电话与家庭住址，均属如实供述义务范围，不是立功。
    * 只有提供犯罪后新的联络方式、新的藏匿地址，才有可能构成立功。
    * 甲归案后提供公安机关尚未掌握的同案犯杨某作案之后使用的手机号与 QQ 号，司法机关据此将其抓捕，成立立功。

* **立功与坦白的区分方法**

    * 坦白是 A，立功是 A＋，立功一定要比坦白多出一点。
    * 属于如实供述义务范围之内的内容是坦白；超出坦白范围多交代的那一部分、且对协助抓捕起到实质作用的，才是立功。
    * 不成立例：张三临时起意与李四共同抢劫，李四事后逃跑，张三被抓后描述李四瘦高个、国字脸、右臂残疾并指出其东行方向，警方据以抓人；描述内容是犯罪前、犯罪中掌握的，属坦白，不构成立功。
    * 成立例：张三与马峰抢劫后，马峰在北京用别人身份证办了新号并告知张三住址；张三被抓获后供述犯罪前、犯罪中的旧号码已关机，再提供新号码，警方据以定位抓获马峰；新号码是犯罪后使用的，超出如实供述范围，立功成立，同时构成坦白。

    ```text
    如实供述义务范围之内              -->  坦白      A
            +
    超出坦白范围的那一部分            -->  立功      A +
    （且对协助抓捕起到实质作用）
    ```

* **重大立功**

    * 与一般立功在主体、时间、本质上完全相同，表现同样分揭发型、线索型、协助型、其他型，只是各加"重大"二字。
    * 情形一：揭发他人重大犯罪行为，查证属实。
    * 情形二：提供侦破其他重大案件的重要线索，查证属实。
    * 情形三：协助司法机关抓捕其他重大犯罪嫌疑人。
    * 情形四：阻止他人重大犯罪活动。
    * 情形五：对国家和社会有其他重大贡献。
    * 标准：所谓重大犯罪、重大案件、重大犯罪嫌疑人，一般指犯罪嫌疑人、被告人可能被判处无期徒刑以上刑罚，或者案件在本省、自治区、直辖市或者全国范围内有较大影响。
    * 只要求"可能"判处无期以上；被揭发者最终只判十五年，只要其行为对应的法定刑有无期徒刑选项（如入户抢劫为十年以上有期徒刑、无期徒刑、死刑），仍成立重大立功。

    | 情形 | 法律后果 |
    | :--- | :--- |
    | 一般立功 | 可以从轻或者减轻处罚 |
    | 重大立功 | 可以减轻或者免除处罚 |

## 四种法定情节的归位

* **法律后果的表述差别**

    * 累犯是唯一用"应当"表述的，即应当从重处罚。
    * 自首、立功、坦白的后果都是"可以"从宽。
    * 一般立功可以从轻或者减轻处罚；重大立功可以减轻或者免除处罚。

* **自首与立功的效力范围**

    * 自首基于本罪，后果只针对成立自首的那个罪名使用。
    * 立功基于全罪，可以适用于行为人所有没有被判决的犯罪。
    * 例：张三犯盗窃、诈骗、抢夺三罪，自动投案后只交代盗窃，盗窃罪可适用自首，诈骗、抢夺不能；若有立功情节，则可适用于三个罪名。
    * 表述上一般说"就某某罪成立自首"，不说"就某某罪成立立功"。

* **按归案方式与供述内容的归位**

    * 虚假陈述的，三种情节都不成立。
    * 自动投案、如实供述自己或共同罪行（已掌握与否均可）的，成立一般自首；自己的罪行与共同的罪行可以放在一起评价。
    * 被动归案、如实供述本人或共同犯罪的罪行的，成立坦白。
    * 被动归案、如实供述本人或共同的本罪且司法机关尚未掌握的，成立准自首。
    * 如实供述他人罪行且司法机关已经掌握的，不构成立功，因为它不会节约司法资源。
    * 如实供述他人罪行、司法机关未掌握且与己无关的，成立立功。

    | 归案方式 | 供述内容 | 情节认定 |
    | :--- | :--- | :--- |
    | 自动投案 | 虚假陈述 | 三种情节都不成立 |
    | 自动投案 | 自己或共同罪行（已掌握与否均可） | 一般自首 |
    | 自动投案 | 他人罪行（司法机关已掌握） | 不构成立功 |
    | 自动投案 | 他人罪行（司法机关未掌握） | 立功 |
    | 被动归案 | 虚假陈述 | 三种情节都不成立 |
    | 被动归案 | 本人或共同犯罪的罪行（司法已掌握） | 坦白 |
    | 被动归案 | 本人或共同的本罪（司法尚未掌握） | 坦白 |
    | 被动归案 | 本人或共同的他种罪行（未掌握） | 准自首 |
    | 被动归案 | 他人罪行（司法机关已掌握） | 不构成立功 |
    | 被动归案 | 他人罪行（司法未掌握）且与己无关 | 立功 |
