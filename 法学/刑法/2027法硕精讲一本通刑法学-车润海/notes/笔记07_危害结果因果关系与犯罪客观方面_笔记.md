# 危害结果、因果关系与犯罪客观方面

* **危害结果**
    * > **定义**：危害行为对犯罪直接客体造成的实际损害或者现实危险状态。
    * 关键词组是"危害行为造成结果"——对谁造成？是对犯罪直接客体造成，不是对犯罪对象造成。
    * 任何犯罪都有客体、都有直接客体，但并非任何犯罪都有对象，所以定义里只能写直接客体。
    * "结果"二分：要么是实害结果，要么是危险结果。
    * > **易错点 ⚠️**：关键词是"犯罪**直接客体**"而非"犯罪对象"，一字之差即考场上送分与失分的区别。

## 危害结果的五种分类

* 五种类型彼此之间没有较强的逻辑关联，因为是站在不同角度切出来的，所以靠记忆而不是推导。
* 分类依据是 2014 年官方答案，口诀为"要脸重表现"。

```text
要 —— 是否属于构成要件 —— 构成要件结果 / 非构成要件结果
脸 —— 行为与结果的关联 —— 直接结果 / 间接结果
重 —— 严重程度及其意义 —— 标准的犯罪构成结果 / 派生的犯罪构成结果
表 —— 表现形式 —————— 实害结果 / 危险结果
现 —— 现象形态 —————— 物质性危害结果 / 非物质性危害结果
```

| 口诀 | 分类标准 | 两种类型 |
| :--- | :--- | :--- |
| 要 | 是否属于构成要件 | 构成要件结果 / 非构成要件结果 |
| 脸 | 行为与结果的关联方式 | 直接结果 / 间接结果 |
| 重 | 严重程度及其意义 | 标准的犯罪构成结果 / 派生的犯罪构成结果 |
| 表 | 表现形式 | 实害结果 / 危险结果 |
| 现 | 现象形态 | 物质性危害结果 / 非物质性危害结果 |

## 构成要件结果与非构成要件结果

* **构成要件结果（狭义的结果）**
    * > **定义**：由犯罪的实行行为造成的、根据刑法分则规定，对成立犯罪或者犯罪既遂具有决定意义的结果。
    * 判定只看一件事：它是不是犯罪成立的必要条件，或者是不是犯罪既遂的必要条件。
    * 特征一：只能是危害行为对犯罪直接客体造成的结果，即只能是直接结果，间接结果不可能是。
    * 特征二：有刑法规定，依刑法规定属于构成要件的一部分。
    * 特征三：作为构成要件，对定罪具有重要意义。
    * 例：张三诈骗李四 200 万，李四发现被骗后自杀身亡。财产损失是构成要件结果；自杀身亡是间接结果，不影响诈骗罪成立，也不影响既遂。
    * 例：过失致人死亡罪只有出现死亡结果才成立，该死亡结果即构成要件结果；过失致人重伤罪同理。
* **非构成要件结果**
    * > **定义**：构成要件以外的结果，既不影响犯罪成立，也不影响犯罪既遂。
    * 后果：一旦出现会影响社会危害性与刑事责任大小，即既不影响定罪、也不影响既遂，但影响量刑。
    * 类型一：行为犯造成的结果。间谍罪（《刑法》第 110 条）只要参加间谍组织、接受间谍组织及其指派的任务、为敌人指示轰击目标，行为实施完毕即既遂，即使没有任何后果；诬告陷害罪捏造事实举报完毕即既遂，被害人是否被实际追究刑事责任不影响成立与既遂。
    * 类型二：预备犯、未遂犯、终止犯造成的结果。张三开枪杀李四打成轻伤，既不影响故意杀人罪成立，也不是既遂结果（既遂须死亡），但同为未遂，量刑有区别。
    * 类型三：间接结果。间接结果都是非构成要件结果。强奸后五日被害人羞愤自杀，既不影响强奸罪成立也不影响既遂。
    * 类型四：精神损害。侮辱罪、强奸罪导致被害人羞耻羞愧难耐；受贿罪一般认为也会造成这种精神损害。
* > **结论**：区分标准只有一个——决定犯罪成立吗？决定犯罪既遂吗？决定即构成要件结果，不决定即非构成要件结果，且只影响量刑。

## 直接结果与间接结果

* **直接结果**
    * 分类标准是危害行为与危害结果之间的关联方式，指危害行为本身直接造成的结果。
    * 未必是构成要件结果：张三开枪杀李四一枪打成轻伤，轻伤是直接结果，但只影响量刑。
* **间接结果**
    * 由直接结果进一步引起的结果。
    * 不影响定罪，也不影响犯罪完成、既遂形态的认定，所以都是非构成要件结果。
    * 长链条：拐卖小花 → 丈夫精神失常 → 孩子辍学无人照顾 → 流浪 → 被车辆撞死，系列结果均由间接结果引起。
* > **易错点**：构成要件结果**只能是**直接结果；但直接结果**未必**都是构成要件结果，推导是单向的，不能反着推。
* 多数刑法条文对间接结果不做规定，也有做的；只要发生间接结果，量刑时就应该予以考虑。
* 案例分析题碰到被害人自杀，答题理由中必须论证对自杀结果在量刑时应当予以考虑；自杀通常情况下都是间接结果。

| 判断 | 对错 | 理由 |
| :--- | :--- | :--- |
| 构成要件结果都是直接结果 | 正确 | 构成要件结果只能是直接危害结果 |
| 直接结果都是构成要件结果 | 错误 | 轻伤是杀人行为的直接结果，但只影响量刑 |
| 间接结果不可能是构成要件结果 | 正确 | 间接结果只影响量刑，不影响成立与既遂 |

## 物质性危害结果与非物质性危害结果

* **物质性危害结果（有形结果）**
    * 分类标准是危害结果的现象形态。
    * 特点：具体可见、可以计量，如死亡人数、重伤人数、财产损失金额。
    * 既可能是构成要件结果，也可能是非构成要件结果。
    * 正面交叉例：甲违章作业造成重大事故，致两人死亡、10 万元机器报废——死亡与机器报废是物质性结果、构成要件结果、直接结果。
    * 反面交叉例：同一事故中因设备损坏停工停产损失利润 15 万元、赔偿他人 5 万元，也是物质性结果，但属非构成要件结果、间接结果。
    * 反面交叉例：小花被拐卖后丈夫精神失常、孩子流浪被车撞死，孩子的死亡是物质性结果，但显然是非构成要件结果。
* **非物质性危害结果（无形的结果）**
    * 抽象、看不见，只能凭人的思维感知。
    * 例：侮辱罪、诽谤罪败坏他人名誉，名誉权损害很难观察，无法量化损害到什么程度。
    * 虽看不见但客观存在，人们可以通过一定方式感知其存在，如同天然气、电力之于民法上有体物与无体物之分。
* > **提示**：物质性强调"看得见、摸得着"；非物质性是"看不见、摸不着，但可以感知到"。

## 实害结果与危险结果

* **实害结果**
    * 分类标准是危害结果的表现形式，指对犯罪客体造成了实际的损害。
    * 绝大多数实害结果其实都是物质性结果：死亡有尸骸，财产损失可计量。
    * 部分实害结果可以表现为非物质性结果：侮辱罪、诽谤罪败坏他人名誉，名誉被贬低败坏确实是实害，同时是非物质性结果。
* **危险结果**
    * 指造成了现实的危险状态。
    * 例：《刑法》第 116 条破坏交通工具罪"破坏火车、电车、船、航空器，足以使其发生倾覆、毁坏危险的"，该危险状态就是本罪的构成要件结果。
    * 表述方式是"已发生某种危害结果的危险状态"，如"具有造成死亡结果的危险"。
* > **提示**：题目中谈到"危害结果"时通常默认指实害结果；危险结果会被格外强调。

## 标准的犯罪构成结果与派生的犯罪构成结果

* **标准的犯罪构成结果（基本结果）**
    * 分类标准是危害结果的严重程度及其意义，指犯罪作为犯罪构成要件的结果，即犯罪行为对犯罪直接客体造成的侵害。
    * 对应标准犯罪构成，通常是罪，通常单处刑罚。
    * 例：过失致人死亡罪的死亡结果对于该罪而言是标准结果，同时是构成要件结果、实害结果。
* **派生的犯罪构成结果**
    * 指实施基本行为、造成基本犯罪以外的结果，刑法对其规定了较重的法定刑，即结果加重犯。
    * 例：抢劫致人死亡、非法拘禁致人死亡；故意伤害致人死亡对故意伤害罪而言即派生结果。
* 广义的结果与狭义的结果
    * 广义结果包罗万象，指犯罪行为造成的一切损害，即对刑法保护的社会关系所造成的损害，既包括构成要件结果也包括非构成要件结果。
    * 狭义结果就是构成要件结果；它可能既是标准结果又是派生结果，既是实害结果又是危险结果。

## 分类之间的关系：同类排斥，异类交叉

* 同一分类之内相互排斥，不同分类之间原则上可以交叉。
* 构成要件结果与直接／间接结果：构成要件结果只能是直接结果，不能是间接结果；间接结果不可能是构成要件结果，推导方向是单向的。
* 构成要件结果与物质性／非物质性：既可能是物质性结果（死亡结果），也可能是非物质性结果（侮辱罪、诽谤罪败坏他人名誉，不可观察不可测量，仍属构成要件结果）。
* 构成要件结果与实害／危险：既可能是实害结果（过失致人死亡罪的死亡结果），也可能是危险结果（破坏交通工具罪的倾覆、毁坏危险）。
* 构成要件结果与标准／派生：既可能是标准结果（过失致人死亡罪的死亡结果），也可能是派生结果（故意伤害致人死亡的结果加重犯）。
* 其余交叉：直接结果既可能是物质性结果也可能是非物质性结果（名誉权受损），既可能是实害结果也可能是危险结果，既可能是标准结果也可能是派生结果。
* 危害结果是决定行为社会危害性的最根本的因素，但危害结果不是一切犯罪的必要条件——间谍罪等行为犯只要行为实施完毕即可既遂。

## 危害结果的意义

### 实害结果的三项意义

* **定罪上的意义**：它是某些犯罪的构成要件。绝大多数过失犯罪都要求发生法定的物质性危害结果才构成犯罪，如过失致人死亡罪要出现死亡结果；有些故意犯罪也要求法定结果，如生产、销售劣药罪立法明文要求对人体健康造成严重损害。
* **刑态上的意义**：它是某些犯罪既遂的条件，如发生死亡结果才能构成故意杀人罪既遂。
* **量刑上的意义**：它是某些犯罪加重法定刑的条件，如抢劫致人死亡、非法拘禁致死的结果加重犯须有加重结果出现才成立。
* 讨论任何概念在刑法理论中的意义，角度无非是定罪、量刑、刑态、罪数关系（罪与非罪、此罪彼罪、一罪数罪、重罪轻罪）。

### 危险结果与诉讼程序的意义

* **危险结果的意义**：危险结果是某些犯罪的既遂标志或既遂条件，如破坏交通工具罪只有发生"足以使交通工具发生倾覆、毁坏的危险"才构成本罪既遂。
* **诉讼程序上的意义**：危害结果还决定某些案件的诉讼程序。虐待罪通常是亲告罪、告诉才处理，一旦虐待致人重伤、死亡出现重伤死亡结果，即转为公诉案件。
* 多选题"关于危害结果在犯罪构成中的地位"，A 危害结果是某些犯罪成立的必备要件、B 是某些犯罪既遂的必备要件、C 行为犯既遂不要求危害结果实际发生、D 危险犯的既遂不要求实害结果发生，四项全选 ABCD。

## 因果关系的概念与功能

### 三个层次与定义

* **刑法中的因果关系**
    * > **定义**：危害行为和危害结果之间一种客观的引起和被引起的联系。
    * 三个层次：因＝危害行为（起点），果＝危害结果（终点），关系＝引起与被引起。
    * 强调"客观"：因果关系本身是客观方面的内容，不以人的意志为转移。
    * 认定理论一直有争论：有条件说、相当因果关系说、危险现实化原理，以及从国外引进的客观归责理论。
    * > **提示**：考研与法考在因果关系认定上区别明显，考研的范围通常比法考大一点，分析思路也不同，不要拿法考思路直接套考研题。

### 因果关系管三件事

* **决定绝大多数过失犯罪的成立**：过失犯罪原则上要求造成特定的物质性危害结果，如过失致人死亡罪必须证明是过失行为造成了死亡结果，无因果关系即不成立。
* **影响某些故意犯罪的形态**：故意杀人罪既遂要有因（杀人行为）、有果（死亡结果），还要证明二者之间具有刑法上的因果关系。
* **影响结果加重犯的成立**：故意伤害致人死亡、非法拘禁致人死亡、强奸致人死亡，都必须证明基本行为与死亡结果之间有因果关系。
* > **易错点**：马蜂强奸小花时小花激烈反抗，马蜂为报复掐死她——前段确有强奸故意、强奸已着手，后段另起新犯意，此时强奸行为与死亡结果之间没有因果关系，不成立强奸致人死亡的结果加重犯，应以故意杀人罪和强奸罪实行数罪并罚。
* 同样一个"致人死亡"的死法，因果关系在不在，结果加重犯还是数罪并罚，完全是两回事。

### 归因而非归责

* 因果关系不是用来找责任的，是用来找原因的，关键结论是"归因而非归责"。
* "有因果关系就要承担刑事责任"——错误。15 岁的孩子实施盗窃，盗窃行为与财产损失确有因果关系，但盗窃罪要年满 16 岁才承担刑事责任。
* "要承担刑事责任必然要求有因果关系"——错误。行为犯不要求造成结果，结果都没有自然谈不上因果关系；持枪瞄准他人开枪未打中，没有实害结果因而不存在刑法上的因果关系，但仍要承担故意杀人罪（未遂）的刑事责任。
* 三行案例的客观栏全部是"有"，差别全在主观罪过栏。
* > **结论**：结果发生后到底算在谁的头上，因果关系只负责找原因；是不是算在这个人头上（归责），还得考察行为人主观上的认知。

| 场景 | 客观因果关系 | 主观罪过 | 处理结果 |
| :--- | :--- | :--- | :--- |
| 不知情地左胸右胸各打一拳并拥抱 | 有 | 无故意、无过失，属意外事件 | 不构成犯罪，不承担刑事责任 |
| 他已明说患严重心脏病，我仍"试一试" | 有 | 对死亡结果有过失，未尽谨慎义务 | 过失致人死亡罪 |
| 医生当面确诊严重心脏病，我仍坚持打两拳 | 有 | 间接故意，明知并放任 | 故意杀人罪 |

## 因果关系的特点

* 四个特点口诀是"相对、客观、必然、复杂"，也可记"没有绝对客观的东西，相对客观必然复杂"。

### 相对性与客观性

* **客观性**
    * 指危害行为与危害结果之间的因果关系是不以人的意志为转移的客观存在，认定时采取客观说。
    * 认定不受行为人主观认识影响：正确的表述是"客观上有因果关系，但主观上没有过错"，不能以"无法预见"来否认客观因果关系。
    * 例：甲用力将乙推倒，乙的头刚好撞在桌角上当即死亡，甲的行为与乙的死亡之间有客观因果关系。
* **相对性**
    * 抽取起点危害行为、终点危害结果，只研究这一对现象之间的引起与被引起关系。
    * 刑法上的因果关系具有顺序性：原因在前、结果在后，不能颠倒，也不能无限向上追溯。
    * 哲学上事物处于普遍联系中，甚至存在原因与结果互为因果的情形，刑法上的因果关系只是其中一部分。
    * 小花控诉小红"你当年结婚才生小明，不生小明小明就不会砍死我丈夫"——不成立，小红结婚、生小明都不是危害行为；起点只能是小明砍死张三，终点是张三死亡。
    * 甲欠乙 1 万元，乙多次逼债，甲抢劫杀死丙——乙的逼债是正当民事权利，不是危害行为；起点是甲的抢劫，终点是丙死亡。
    * > **易错点 ⚠️**：颠倒顺序就成了因果循环、反果为因；起点终点只能研究危害行为与危害结果这一对。

### 必然性与复杂性

* **必然性**
    * 因果关系一般表现为两种现象之间内在的、必然的、合乎规律的引起和被引起关系。
    * 提问方式不是"这个行为像不像杀人行为"，而是"为什么这个行为可以造成这个结果"——答案在于该行为本身具有造成结果的高度危险。
    * 毒药毒死人、绳子勒死人、砖头砸死人、十楼推下去摔死人，都是经过经验法则和规律验证的致人死亡方法，是因果关系的主要和基本形式。
* **复杂性**
    * 表现为**一因多果**：张三开枪一枪打死一条值钱的狗，又击中路过行人致其死亡；只有一个开枪行为，同时构成故意毁坏财物罪与过失致人死亡罪。
    * 表现为**一果多因（多因一果）**：我与岳鹏互不知情、各向马峰的杯子投 5 克毒药，马峰喝下 10 克毒发身亡，两个行为都促进死亡结果的发生。

## 因果关系的两种类型

* **必然因果关系**
    * 危害行为和危害结果之间有着内在的、必然的、合乎规律的引起和被引起关系，中间没有介入因素。
    * 例：张三抢劫李四，李四发现后张三追、李四跑，这个过程一般不会致人死亡，所以追赶行为本身并不包含致人死亡的内在必然性。
* **偶然因果关系**
    * 某种行为本身不包含造成某种危害结果的内在必然性，通常不会造成这样的结果；在其发展过程中偶然地有其他原因加入，由后来介入的原因合乎规律地引起危害结果。
    * 例：追赶过程中李四下楼梯一脚踩空、头部着地当场摔死，追赶行为与死亡结果之间是偶然联系。
* 二者的分水岭就是中间有没有一个介入因素。

```text
  必然因果关系：   [ 前行为 ] ──合乎规律地──▶ [ 危害结果 ]
                                  （中间没有介入因素）

  偶然因果关系：   [ 前行为 ] ──▶ [ 介入原因 ] ──合乎规律地──▶ [ 危害结果 ]
                     通常不会              偶然地半路杀出
                     致人死亡              （例如踩空摔倒）
```

## 因果关系的三步检验

* 碰到疑难问题要逐项检验，顺序固定：**有因 → 有果 → 有关系**。
* 因是危害行为并要求是实行行为；果是危害结果并要求是实害结果；关系是引起和被引起。
* 三个勾全打才具有刑法上的因果关系，任一步打叉都表明没有刑法上的因果关系。

```text
第一步：有因吗 ─── 要有「实行行为」（危害行为中的一种）
              满足 √
              不满足 ×  →  起点即丧失，没有刑法上的因果关系

第二步：有果吗 ─── 要有「实害结果」
              满足 √
              不满足 ×  →  没有刑法上的因果关系

第三步：有关系吗 ─  实行行为与实害结果之间是「引起和被引起」
              满足 √
              不满足 ×  →  没有刑法上的因果关系

三个 √ 全打，刑法上的因果关系才成立
```

### 第一步：有因——要落实行行为

* **实行行为**
    * > **定义**：刑法分则条文所规定的、某个犯罪的基本构成要件行为。它相对于非实行行为而言，本质上会对法益或者对客体造成现实紧迫的危险；没有紧迫危险的就不可能是实行行为。
    * 判断规则：任何一个罪名，罪名中通常都有动词，绝大多数这样的动词一般而言都是实行行为。
    * 动词之前通常都是在为这个动词做准备，称预备行为。买毒药（A 点）、潜入房间（B 点）是为杀人做准备；向杯子投毒（C 点）时杀人行为着手，实行行为成立，李四毒发身亡（D 点）是实害结果。
    * 实行行为看分则，非实行行为看总则；关键是刑法分则有没有规定。
    * 例外提示：故意犯罪和过失犯罪其实都有实行行为。交通肇事罪闯红灯快撞到人，这一过失行为就是实行行为。
    * 推论：因果关系要求造成"果"，而只有实行行为才能造成"果"，故因果关系概念中的"危害行为"只能是实行行为。
* **非实行行为**
    * 范围更广：实行行为以外、对实行行为起各种作用的危害行为，如指使、教唆、帮助等补充作用，具体包括犯罪的预备行为、教唆行为、帮助行为。
* 两种没有因果关系的"因"
    * 第一种：生活行为造成结果。送女朋友一双溜冰鞋致其摔成重伤；打电话请马峰吃饭，马峰赴宴途中被撞身亡——请吃饭属好意施惠、情谊行为。
    * 第二种：降低危险的行为。花盆马上砸中岳鹏时推他一把致其摔成轻伤；被遗弃在偏僻之地的婴儿贾某被转移到医院门口后离去。
    * 这两种情形下行为缺少社会危害性，起点即不成立，不可能有刑法上的因果关系。

### 第二步：有果——要落实害结果

* **必须是实害结果**：这是考试的通说观点、中国通说观点，不包括危险结果。
    * 理由一：因果关系要求原因在前、结果随后，两者之间有时间间隔；而危险结果下行为和结果完全可能同步出现（举枪瞄准时危险已经存在），讨论因果关系没有过多意义。
    * 理由二：危险结果是评价意义上的结论，很难固定；实害结果可以固定下来研究。
    * 张三朝李四开一枪没打中：有因（杀人行为已着手，是实行行为），无果（没有实际侵害特定客体），不讨论刑法因果关系，直接定故意杀人未遂。
* **必须是现实存在的结果**：因果关系具有客观性，因是客观的、果是客观的，因果关系也是客观的，不能做假想的结果。
    * 张三把李四从十楼推下，王五瞄准坠落中的李四开枪爆头，法医鉴定李四不是摔死的——死亡结果算在王五头上；"如果我不打中他，他也会摔死"只是假想结果。
    * 日本教学案例：甲在丙水壶投毒后离开，乙与甲互不知情、在水壶下钻小孔渗水，丙带着水进沙漠渴死——算在乙头上，甲只定故意杀人罪未遂，乙定故意杀人罪既遂。
* > **结论**：因果关系中的"果"要同时满足客观存在与实害结果两个要求，我们从来不讨论假设的结果。

### 第三步：有关系——引起和被引起

* 实行行为与实害结果之间存在引起和被引起的关系，行为在前、结果在后。
* **没有介入因素**
    * 发展非常顺利，中间没有任何突发情况，公式是"实行行为 ──→ 实害结果"；只要能证明实行行为引起了实害结果，两者之间必然有因果关系。
    * 例：开枪一枪打死；马峰跳楼自杀时砸中别人致人死亡，虽然概率低，但没有跳楼行为就不可能砸中别人。
    * 判断特别简单，从来不是命题关注的重点。
* **有介入因素**
    * 因果关系发展过程中基于种种原因出现突发情况，介入因素就是中途加入、半路杀出个程咬金。
    * 存在介入因素时，结果到底算在实行行为头上、介入因素头上，还是同时算在两者头上，一定会成为命题重点。
    * 核心公式：关键看介入因素的出现是正常还是异常；正常则不能中断前面的实行行为与后面的实害结果之间的因果关系，异常则有可能中断。

```text
【没有介入因素】                      判断简单，不是命题重点

    实行行为 ──────────→ 实害结果


【有介入因素】                        ★ 真正的命题重点 ★

    实行行为 ──→ 介入因素 ──→ 实害结果
                  （半路杀出个程咬金）
```

## 介入因素

### 三层分叉：正常、异常与作用大小

```text
存在介入因素
     │
     ▼
 正常还是异常
     │
     ├── 正常 ──→ 不中断因果关系
     │             （但仍可能是多因一果）
     │
     └── 异常 ──→ 看它对实害结果的作用
                   │
                   ├── 作用大 ──→ 中断因果关系
                   │                （能独立造成结果，接近 100%）
                   ├── 作用小 ──→ 不中断因果关系
                   └── 作用相当 ─→ 多因一果
                                    （结果同时算在实行行为与介入因素头上）
```

* **正常介入因素——不中断**
    * 张三将李四砍成重伤昏迷，误以为已死，为毁尸灭迹捆石头沉尸大海，法医鉴定李四是溺水身亡。犯罪后处理尸体、破坏现场、毁灭证据概率高，属正常介入因素，张三构成故意杀人罪既遂。
    * 放火案：甲为报复高某，在村民聚居区准备放火工具、切断高压电源后向高某锁住的房屋门窗及屋内泼洒汽油；高某被惊醒后用警用手电照明并开启具有电击功能的设备打出电火花引发火灾，造成一死一伤。放火危害公共安全、涉及不特定多数人；高某惊醒后查找原因、甚至拿出打火机照明都正常，不能中断因果关系。
* **异常作用大——中断**
    * 张三将李四砍成重伤，住院期间医院发生火灾被活活烧死。火灾与伤害行为无关、独立出现、概率低，属异常；李四确实被烧死，作用大，中断因果关系。张三只构成故意伤害罪重伤，本有杀人故意的构成故意杀人罪未遂；死亡结果算在引发火灾者头上。
    * 张三将李四砍成轻伤送医，医生未检查即注射致其过敏的药物，李四过敏死亡。介入因素异常且作用大，中断因果关系，张三仅构成故意伤害罪（轻伤），死亡结果算在医生头上。
    * 张三拿刀砍伤腿部后不去医院，焚香祷告并把香灰敷在伤口上，当场止血，次日感染截肢。概率低、老百姓接受不了，属异常；砍成轻伤一般不包含截肢的危险，截肢的危险由介入因素造成，作用大，中断因果关系。
* **异常作用小——不中断**
    * 我羞辱被砍成重伤的马峰，拍拍他的脸，马峰气绝身亡。我的行为与前面的伤害行为无关、独立出现，属异常介入因素；但只是拍脸羞辱，不可能独立造成结果，作用小，不能中断，死亡结果仍算在张三头上——有杀人故意构成故意杀人既遂，只有伤害故意则构成故意伤害致人死亡。
    * 书上的例：甲重伤乙，乙已濒临死亡，乙的仇家丙路过，乙向丙求救，丙趁机辱骂，乙气绝身亡。辱骂不可能独立造成结果，作用非常小、几乎可以忽略，不能中断因果关系。
* **作用相当——多因一果**
    * 我与岳鹏互不知情，各向马峰杯中投 5 克毒药，马峰喝下 10 克毒发身亡。我的行为在前，岳鹏的投毒是介入因素；岳鹏独立出现、概率极低，对我而言属异常；但 5 克不足以致死、也非小到可以忽略，作用相当，死亡结果同时算在两人头上，双方均有杀人故意则均构成故意杀人罪既遂。
* **正常介入因素也可能多因一果**
    * 甲深夜驾车将丙撞伤后逃逸，丙昏迷在路中间；2 分钟后乙超速行驶发现丙来不及刹车，直接从丙身上碾压过去致丙当场死亡。
    * 丙深夜昏迷在路中间被碾中的概率高，乙的碾压属正常介入因素，不中断甲与丙死亡结果之间的因果关系。
    * 死亡结果同样算在乙头上，因为题目给了限定条件——超速行驶违反交通运输管理法规；甲属过失，乙也属过失。
    * 甲的行为给丙的生命造成极大危险，乙经过把危险现实化为实害；丙具有被碾压的高度危险，所以乙的碾压行为并不异常，甲、乙的行为与丙的死亡都有因果关系。

### 判断正常与异常的两把尺子

* **第一把尺子：自然事件看概率，社会事件看评价。**
    * 自然事件看概率：介入因素出现的概率越高越正常，概率越低越异常。
    * 社会事件看评价：看老百姓能不能接受、符不符合一般观念；能接受通常正常，不能接受通常异常。
    * 杀人之后去处理尸体——正常，犯罪后大概率破坏现场、毁灭证据。
    * 火山、地震、海啸——异常，概率低，有人一辈子遇不到；即便川渝地区地震相对频繁也不会天天震，概率仍低。考的是中国研究生考试，在中国通常认为地震异常。
    * 交通事故——异常，真正发生在身边的比较罕见；说天天发生那是新闻传播速度快。
    * 冲进火场救自己的孩子——正常，作为父母通常会冲进去救孩子，老百姓能接受，不能中断因果关系。
    * 李四在船上钓鱼，张三举枪瞄准，李四为躲避纵身一跃跳入水中溺死——正常，躲避概率高且老百姓能接受，不能中断因果关系。
* **第二把尺子（辅助标准）：关键看实行行为和介入因素之间是引发关系还是独立关系。**
    * 正常、异常是相对于实行行为而言的。
    * 实行行为通常会引起一个介入因素，就表明实行行为"制造"了它；既然是实行行为制造的，对实行行为而言当然正常，不能中断因果关系，如同母亲生下孩子要对孩子的侵害承担监护人责任。
    * 异常介入因素的出现和实行行为无关、是独立出现的；相较于实行行为就是异常的，对实害结果作用较大就有可能中断因果关系。
* 两把尺子不矛盾，可结合综合运用。
* > **提示 ⚠️**：正常、异常一定要放在特定的场景之中讨论，必须案例化、情景化，绝不能脱离案例抽象讨论。

| 场景 | 判断 | 理由 |
| :--- | :--- | :--- |
| 一拳打来时快速扭脖子躲闪 | 正常 | 紧急情况来不及慢慢转，只能快速躲 |
| 不会游泳仍纵身跳水灭火 | 正常 | 紧急火情，来不及理性思考 |
| 学骑车紧张中撞上站定不动的老人 | 正常 | 紧张状态下不能要求如此理性的反应 |
| 逆行车辆冲来时呆立不动 | 正常 | 犹豫时身体停住是正常反应 |
| 生活里去错卫生间 | 随场景变化 | 女生受引导误导，走错的概率相对较大 |

* 扭脖子：紧急躲避时把对方脖子扭断是正常的，认定正常介入因素，不中断因果关系；大爷大妈都会认为"你不打他那一拳，他就不会这样躲"。
* 跳水灭火：被泼汽油点燃后明知不会游泳仍跃入小河，灭火但溺死；正常人完全可能采取这种灭火方法，紧急时刻不能要求非常理性的思考，故由前面的杀人行为引发出来。
* 走错卫生间：单独看概率低、通常异常；在机场凭"男左女右"冲进左边又冲出，正好一位女生看见他从左边出来就毫不犹豫进右边，站在女生角度她走错的概率相对较大，因为受了引导和误导。
* 同一动作在不同场景里正常与异常可以互换，所以要案例化、情景化地讨论。

### 有没有介入因素：先看实行行为有没有直接造成结果

* 第一步先锁定实行行为是什么，确定实行行为以后，第二步判断实行行为有没有"直接"造成实害结果。
* 直接造成了——通常不需要考虑介入因素，直接有因果关系。
* 没有直接造成——必然存在介入因素；结果已经发生却又不是实行行为直接造成的、又拿不出介入因素，就根本解释不了这个结果是怎么出现的。
* 案例：张三想杀李四，用刀砍成重伤昏迷，误以为李四已死而捆石头沉尸大海，法医鉴定溺水身亡。实行行为是杀人行为；李四不是被直接砍死的，必然存在介入因素，即捆石头沉尸大海；正常，不中断。
* 案例：张三想枪杀在船上钓鱼的李四，李四在开枪这一刻纵身跃入水中躲避溺死。实行行为是开枪杀；不是被直接打死的，必然有介入因素，即跳入水中躲避；正常，不中断，构成故意杀人既遂。

```text
第一步：锁定实行行为是什么
            │
            ▼
第二步：实行行为是否【直接】造成实害结果？
            │
     ┌──────┴───────┐
     │ 是            │ 否
     ▼              ▼
通常不需要考虑      必然存在介入因素
介入因素            （否则解释不了结果怎么出现）
     │              │
     ▼              ▼
有因果关系        再判断这个介入因素
                  正常/异常？作用大/小？
```

### 介入因素的出现时点与提炼规则

* **只能发生在实行行为以后、实害结果以前。**
    * 介入因素是"实行行为的介入因素"，是中途加入；某种因素若在实行行为以前就已存在，就不能称为介入因素。
    * 井案：张三想把李四推入井中淹死，井下没有水，李四被摔死。"井下没有水"是在杀人行为之前就已存在的状态，不是介入因素；本案没有介入因素，杀人行为与死亡结果之间有因果关系。
* **被害人特殊体质原则上不是介入因素。**
    * 严重心脏病、白血病、血友病等生理性疾病通常在犯罪行为以前就已具备、一直都有，不是中途加入的。
    * 例：张三拿刀朝李四胳膊砍一刀，本不会致死，但李四有血友病，一点小伤口都流血不止难以止血而死亡；血友病不是介入因素，砍伤行为与死亡结果之间有因果关系。
    * 这也表明因果关系是客观存在的，不以行为人的主观认识、主观意志为转移；做题按"特殊体质不是介入因素"这条思路走，与法考观点有轻度不同。
* **提炼介入因素时不能把结果本身算进去。**
    * 若把结果也包含进介入因素之内，结果就出现两遍、两头沾，很明显不合适；提炼只能到"摔倒"，不能到"摔死"。
    * 真题：甲非法拘禁乙，乙逃跑时不慎摔倒死亡。实行行为是非法拘禁，直接造成死亡吗？不是，必然存在介入因素；正确提炼是"为了逃跑而摔倒"，逃跑时慌张、摔倒很正常，且是由拘禁行为引起的，故为正常介入因素，不中断因果关系。
    * 介被害人的行为例一：甲点燃乙的衣服，乙跳入水中灭火时溺死。介入因素是"跳入水中灭火"，不能说成"跳入水中灭火溺死"；正常，不中断。
    * 介被害人的行为例二：乙在悬崖旁被强奸致昏迷，苏醒后因头昏跌入悬崖死亡。介入因素是"昏迷中苏醒走两步然后头昏跌入悬崖"，被强奸地点就在悬崖旁，属正常，不中断。
    * 介特定自然事实：甲杀乙致重伤、一小时内必死无疑，却因地震被坠落石头砸中死亡。介入因素是"地震导致石头坠落、砸中乙"，不能说"砸死"；概率极低、独立出现，异常作用大，中断因果关系，甲构成故意杀人罪未遂。泥石流同理。

### 介入因素的四种类型

* **介入行为人的行为**：如捆石头沉尸大海，与前述案例完全相同。
* **介入被害人的行为**
    * 甲点燃乙的衣服，乙跳入水中灭火溺死——正常，不中断。
    * 乙在悬崖旁被强奸致昏迷，苏醒后因头昏跌入悬崖死亡——正常，不中断。
* **介入第三人的行为**
    * 例一：甲在高速公路上将同车人乙推下车，乙跌落后被正常行驶的丙压死。不是推下车直接摔死的，必然有介入因素，即乙被其他车辆碾压；高速公路上被碾压概率高，属正常，不中断。
    * 例二：放火烧伤马蜂后送医紧急手术，抬人时主治医生催促太急，咔嚓一下扭断了马蜂的脖子。不是放火直接烧死的，必然有介入因素，即医生扭断脖子；太异常且对死亡作用大（直接致死），中断因果关系，死亡结果算在医生头上。
* **介入特定的自然事实**：地震坠石砸中乙（甲杀乙致重伤后），异常作用大，中断，甲构成故意杀人罪未遂；泥石流同理。

| 类型 | 案例 | 正常/异常 | 是否中断 |
| :--- | :--- | :--- | :--- |
| 行为人的行为 | 捆石头沉尸大海 | 正常 | 不中断 |
| 被害人的行为 | 跳入水中灭火 | 正常 | 不中断 |
| 被害人的行为 | 悬崖旁昏迷苏醒后头昏跌落 | 正常 | 不中断 |
| 第三人的行为 | 高速公路上被丙压死 | 正常 | 不中断 |
| 第三人的行为 | 医生抢救中扭断马蜂脖子 | 异常·作用大 | 中断 |
| 特定的自然事实 | 地震坠石砸中乙 | 异常·作用大 | 中断 |

## 因果关系的四种具体情形

* 情形一：没有介入因素——实行行为直接造成实害结果。
* 情形二：有介入因素——实行行为、介入因素、实害结果，盯住介入因素三连问：正常还是异常？正常不中断；异常看作用，作用大就中断，作用小就不中断。
* 后面四种具体情形都是从这个公式里长出来的，没有新的知识点。

```text
【情形一】没有介入因素
    实行行为 ──────────────────→ 实害结果
    行为直接造成结果，不必再想别的

【情形二】有介入因素
    实行行为 ──→ 介入因素 ──→ 实害结果
                       │
                       └─ 三连问
                          正常 ────────────→ 不中断
                          异常 ──→ 作用大 ──→ 中断
                                     作用小 ──→ 不中断

不管哪种情形，因果关系的判断思路还是老三步：
    一有因：要有实行行为
    二有果：要有实害结果
    三有关系：要有引起和被引起
```

| 情形 | 一句话抓住 | 典型例子 |
| :--- | :--- | :--- |
| 假定 | 没有这个行为，结果也会照样发生 | 沙漠旅行案：一人投毒，一人钻孔 |
| 重叠 | 谁都单独不够，两个合起来才够 | 两份毒药合并毒死马峰 |
| 二重 | 谁都单独够，而且还撞在了一起 | 张三李四同时开枪都打中心脏 |
| 不作为 | 不作为也是危害行为，造成结果即有因果关系 | 父亲见儿子落水不救助，眼看其淹死 |

* **假定的因果关系**
    * > **定义**：虽某个行为导致结果发生，但即使没有该行为，其他情况也会同样产生这个结果。
    * 沙漠旅行案：张三投毒、李四钻孔，被害人渴死；李四的辩护是"即使我不钻孔，他也会被毒死"。
    * 书上例：被害人父亲甲在警察对罪犯乙执行死刑之前推开警察，亲自扣动扳机将乙击毙。即使没有甲的行为，乙也会死，但那只是假设的结果；问乙是怎么死的，当然是被甲打死的。警察执行死刑是执法行为，甲没有执法权，其行为本身就是危害行为。
    * > **易错点**：最容易错在"结果不是已经出现了吗"。本研究只处理已经出现的客观结果，假设里那个"如果没有他也会死"的世界与归责无关。
* **重叠的因果关系**
    * > **定义**：每一个人的行为都不能独立造成结果，两个人的行为合并在一起才造成结果。
    * 例：岳鹏投 5 颗毒药不足以独立致死，我也在不知情下投 5 颗，两份合并导致马峰死亡，两人的行为与死亡结果都有因果关系。
* **二重的因果关系**
    * > **定义**：每一个人的行为都可以独立造成结果，但这几个行为还是竞合在一起造成了结果。
    * 例：张三和李四互不知情，同一时间、同一地点从不同方向同时向王五开枪且都打中王五心脏；事后查明各自这一枪都足以致死，去掉任何一个人结果同样发生。
    * > **提示**：重叠和二重只差在"单独够不够"。做题先问一句"单独能不能致死"，这两类就分得开。
* **不作为的因果关系**
    * > **定义**：不作为的行为造成了危害结果，两者之间仍然有因果关系。
    * 法理只有一句：不作为也是危害行为；既然是危害行为，造成了实害结果且存在引起与被引起的关系，当然具有因果关系。
    * 例：儿子落水，父亲不救助，眼睁睁看着儿子淹死，父亲不履行作为义务的不作为与儿子的死亡结果之间同样具有刑法上的因果关系。

## 条件关系与刑事责任

* **条件关系不等于刑法上的因果关系。**
    * 条件关系讲"没有这个条件，结果就不会发生"；刑法上的因果关系讲行为与结果之间存在引起和被引起的关系，两者不是一回事。
    * 反证：拿刀砍伤腿部致轻伤、用香灰敷伤口后感染截肢——条件关系清清楚楚（不砍伤就不会去敷伤口，不敷就不会截肢），但"拿香灰敷伤口"本身并不是刑法上要评价的行为，故没有刑法上的因果关系。
    * 在有介入因素的场景下，条件关系反而是最容易骗人的地方。
* **因果关系不是承担刑事责任的充分条件。**
    * 充分条件指"有A就有B"，通过A就能推导出B；但有因果关系就要承担刑事责任显然不对。
    * 因果关系充其量只在客观方面说明行为与结果之间存在引起和被引起的关系；最终承担刑事责任，还要考察主观上有没有犯罪故意、过失，年龄上有没有达到法定年龄。
* 多选题"关于因果关系的说法"，答案 D。
    * A 因果关系的认定必须考虑行为的主观认识——错误，因果关系具有客观性，不以人的主观意志为转移。
    * B 因果关系的存在是行为人承担刑事责任的充分条件——错误，因果关系只解决客观归因。
    * C 行为结果之间的条件关系，有条件关系就可以认定为有因果关系——错误，条件关系再强也生不出刑法上的因果关系。
    * D 犯罪中不作为与危害结果之间的因果关系是客观存在的——正确，不作为也是危害行为。

## 犯罪的时间、地点与方法

* 时间、地点、方法在绝大多数罪名里只是"背景"，只有在少数罪名里才从背景升格为犯罪的"成立条件"。
* 例：现在北京杀人、两天后上海杀人，同样都构成故意杀人罪，对定罪没有任何影响。
* 判别顺序是先用"是否影响定罪"作第一道分水岭，越过去再看是否影响量刑。

### 作为构成要件的时间、地点与方法

* **构成要件型时空方法**
    * 刑法分则把特定的时间、地点、方法写进罪状，缺少这些条件犯罪就不能成立。
    * 《刑法》第 340 条非法捕捞水产品罪：禁渔期是时间要件，禁渔区是地点要件，禁用的工具和方法是方法要件；三者齐备才构成本罪，任何一项落空都不构成本罪。
    * 第 341 条非法狩猎罪结构完全相同。
    * 作用是区分罪与非罪：满足这些特定的时间、地点和方法犯罪成立，不满足犯罪不成立。
* **法定量刑情节**
    * > **定义**：刑法分则明文规定的、不影响定罪但影响量刑的特定时间、地点、方法。
    * 例：《刑法》第 263 条抢劫罪的"入户抢劫"，"户"是地点；入不入户都能构成抢劫罪故不影响成立，但入了户就要使用更重的法定刑即影响量刑。
    * > **提示**："法定"两个字不是说着玩的，看的是刑法分则有没有明文规定，这一点没有例外。

### 与犯罪构成无关

* 例：抢劫罪中的犯罪时间。凌晨两点去抢劫、下午三点去抢劫都能构成抢劫罪，立法上并未把时间规定为抢劫罪法定的从重处罚情节或加重处罚情节，故既不影响定罪也不影响量刑。
* > **易错点 ⚠️**：一看到"时间"就担心它会不会影响量刑——时间当然有可能影响量刑，但那一定属于酌定的量刑情节，绝不可能是法定的量刑情节，抢劫罪上尤其如此。

```text
时间／地点／方法 → 问自己两句话
  │
  ├─ 第一问：影响定罪吗？
  │     ├─ 是 → 构成要件（刑法分则明文规定的特定时空方法）
  │     └─ 否 ↓
  │
  └─ 第二问：影响量刑吗？
        ├─ 是 → 法定的量刑情节（须刑法分则明文规定）
        └─ 否 → 与犯罪构成要件无关
```

| 身份 | 影响定罪吗 | 影响量刑吗 | 法律依据 | 例子 |
| :--- | :--- | :--- | :--- | :--- |
| 构成要件 | 是 | — | 刑法分则明文规定的罪状 | 非法捕捞水产品罪的禁渔期、禁渔区、禁用的工具和方法 |
| 法定量刑情节 | 否 | 是，适用更重法定刑 | 刑法分则明文规定 | 抢劫罪的入户抢劫 |
| 与犯罪构成无关 | 否 | 否 | 分则无明文规定 | 抢劫罪中的犯罪时间 |

* 三种身份的差别只在一件事上——刑法分则有没有对所说的时空条件开口。
* > **注意**：最硬的底座始终是"法定一定要有刑法分则明文规定"；排除构成要件和法定量刑情节这两种身份之后，剩下的只能归进"与犯罪构成无关"，没有第四种可能。
