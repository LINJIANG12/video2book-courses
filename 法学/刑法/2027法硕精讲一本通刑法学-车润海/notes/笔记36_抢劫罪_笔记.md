# 抢劫罪

## 抢劫罪的四张面孔

| 类型 | 法条依据 | 内容 |
| :--- | :--- | :--- |
| 普通抢劫 | 第263条 | 以暴力、胁迫或者其他方法抢劫公私财物的 |
| 携带凶器抢夺定抢劫 | 第267条第2款 | 携带凶器抢夺的，依照抢劫罪定罪处罚 |
| 转化型抢劫（事后抢劫） | 第269条 | 犯盗窃、诈骗、抢夺罪，为窝藏赃物、抗拒抓捕或者毁灭罪证，当场使用暴力或者以暴力相威胁的，依照第263条定罪处罚 |
| 聚众打砸抢 | 第289条 | 聚众打砸抢，毁坏或者抢走公私财物的，除判令退赔外，对首要分子定抢劫罪 |

* **聚众打砸抢（第289条）**

    * 属于特殊规定：哪怕只是**毁坏**公私财物，在聚众打砸抢的情况下，对首要分子也要定抢劫罪。

    * 适用范围限于首要分子，且以除判令退赔之外另行定罪为内容。

## 抢劫罪的构成要件

* **抢劫罪（robbery）**

    * > **定义**：以非法占有为目的，以暴力、胁迫或者其他方法强行劫取公私财物的行为。

    * 客体是**复杂客体**："强行劫取"决定了它要先压制反抗再取走财物，压制反抗必然侵害人身权利。**主要客体是公私财产所有权，次要客体是他人人身权。**

    * 主体是一般主体，**年满14岁即可成立本罪**。

    * 主观方面是故意，且**以非法占有为目的**。

* **复合实行行为**

    * 抢劫由两个动词组成："抢"与"劫"，**抢是手段，劫是目的**，两者合并才构成抢劫罪。

    * 行为人开始对被害人使用暴力、胁迫或者其他足以压制反抗的手段，即开始实施人身强制时，抢劫行为**着手**。

## 抢劫四步曲

```text
   第一步   使用强制手段        暴力 / 胁迫 / 其他方法
            │
            ▼
   第二步   足以压制被害人反抗  对方根本没有选择的余地
            │
            ▼
   第三步   被害人因无法反抗而被迫放弃财物
            │
            ▼
   第四步   行为人取得财物      含财物、财产性利益、违禁品
            │
            ▼
           抢劫罪既遂
```

四步走完才能构成抢劫罪既遂；不满足四步，或者不能成立本罪，或者不能成立既遂。

### 强制手段的三种形态

* **暴力**

    * 指对被害人实施有形力，使其不能反抗。

    * 典型：先将对方捆绑起来再取其财物；先打倒再取财。

    * 压制反抗的终极手段是**当场杀死**：先杀死再取财，对方彻底丧失反抗能力，构成抢劫罪，且是**抢劫致人死亡**。

* **胁迫**

    * 指实施精神强制，使其不敢反抗。

    * 只包括**暴力胁迫**，不包括非暴力胁迫。暴力胁迫的全称是"以实施暴力相威胁"——是"以"实施暴力相威胁，不是实施暴力本身。如把刀放在对方脖子上说"给钱，不然我就杀了你"。

    * > **易错点**：本罪中的"胁迫"只包括暴力胁迫，不包括非暴力胁迫。区分标准不在于"有没有威胁"，而在于**被害人还有没有选择的余地**。以公开裸照相威胁只能让对方产生恐惧心理，够不上压制反抗，**只能认定为敲诈勒索罪**。

* **其他方法**

    * 指达到**与暴力胁迫相当的程度**——足以压制被害人反抗。典型是昏醉抢劫和拘禁抢劫。

    * 昏醉抢劫：频频劝酒使对方饮醉后摘走其财物，行为人使对方陷入无法反抗的状态，构成抢劫罪。

    * 拘禁抢劫：进入被害人家中后把卧室门从外面用铁条缠住使其从里面打不开，再搬走财物。行为人并未直接对被害人人身使用暴力，仍构成抢劫罪。

    * > **结论**：强制手段导致他人不能反抗、然后取走其财物，定抢劫；该强制手段须在效果上足以压制被害人反抗。

    * > **结论**：强制手段与压制反抗之间要有关系——正是因为我的强制手段导致对方无法反抗，再取走其财物，才符合抢劫的结构。

* **无法反抗状态的来源**

    * 分水岭在于对方无法反抗的状态是谁造成的：是我行为导致的，是压制反抗加取走财物，成立抢劫；是与己无关的既存状态，是单纯利用该状态，成立盗窃或者抢夺。

    * 例：被害人已被他人捆绑非法拘禁并呼救，行为人打跑捆人者后摸走被害人财物，研究生考试的观点认定为**抢夺罪**；最新入库案例也印证此种行为不可能定盗窃罪。

    * 例：被害人在饭店自行喝醉趴桌，行为人进入饭店摘走其金项链，行为人只是单纯利用既存状态，成立**盗窃罪**。

```text
   对方无法反抗的状态是谁造成的？——这才是分水岭

   是我的行为导致的   →  压制反抗 + 取走财物  →  抢劫
   与我无关的既存状态 →  单纯利用该状态     →  盗窃 / 抢夺
```

### 压制反抗的判断标准

* 抢劫罪的暴力、胁迫程度要求很高，须达到**足以压制对方反抗**的程度。所谓压制，意味着对方**根本没有选择的余地**，只能放弃财物。

* 相关司法解释明示的判定规则是**两个当场**：当场使用暴力（也包括当场以暴力相威胁）＋当场取得财物。

    * 当场使用暴力，意味着被害人没有选择的余地；当场取得财物，即为抢劫。

    * 以当场加害相威胁要钱，定抢劫；以日后加害相威胁，被害人仍有选择的余地，只能定敲诈勒索罪。

| 例子 | 威胁的内容 | 被害人还有选择的余地吗 | 定性 |
| :--- | :--- | :--- | :--- |
| 例一 | "给不给钱？当场杀死你" | 没有，当场就得给 | 抢劫罪 |
| 例二 | "给钱2万，不给钱，五天后我杀了你" | 有——可以当场给，也可以当场不给，何况还有五天可以跑 | 敲诈勒索罪 |
| 例三 | 揭发你的隐私，向你索取财物 | 有——给与不给都是他的选择 | 敲诈勒索罪 |

* > **提示**：根据司法解释，对未成年人使用或威胁使用**轻微暴力**、强抢**少量财物**，一般不定抢劫；符合寻衅滋事的，定寻衅滋事罪。

### 取得财物与既未遂

* **第三步的"放弃财物"**

    * 指的是被迫放弃、别无选择、只能放弃。若不是因为无法反抗而放弃财物，不能构成抢劫罪既遂。

    * 例：抢劫对象身强体壮、格斗能力强，本可轻易制服却因爱惜对方而主动交付5000元。客观上取得了财物，但对方并非基于现实的压制反抗而放弃，构成抢劫罪**未遂**。

    * 例：持刀抢劫，被害人逃跑时钱包掉落，行为人捡走钱包后未再追赶。取得财物并非基于压制反抗，构成抢劫罪**未遂**。

* **第四步的"取得财物"**

    * 包括有体物、**财产性利益**和**违禁品**。抢劫他人的毒品也能构成抢劫罪；把人打倒逼其把支付宝里的钱转到自己的支付宝，抢的是财产性利益。

    * 司法解释规定：被告人以暴力、胁迫手段强行夺回欠款凭证，并让债权人在其已经写好的收条上签字以消灭债务，符合抢劫特征的，定抢劫。

* **既遂条件**

    * 复杂客体，主要客体与次要客体**有一项被实际侵害即可成立既遂**。

    * 表述为二选一：**或取得财物**（指值得保护的财物），**或造成被害人轻伤以上后果**。例：打倒被害人打成轻伤、一搜身身无分文，虽未取得财物，仍构成既遂。

* **因果关系**

    * 成立抢劫既遂，一定要求**压制反抗和取得财物之间有因果关系**——正是基于压制反抗才取得其财物。

    * 没有因果关系，可以构成抢劫罪，但不能成立既遂。

## 携带凶器抢夺定抢劫

* **携带凶器抢夺定抢劫（第267条第2款）**

    * 从本质上看**仍然是抢夺**。

    * 不能向被害人显示凶器，更不能直接使用凶器；一旦明示、暗示或使用，就是当场以实施暴力相威胁，直接定普通抢劫。能定普通抢劫就要定普通抢劫。

### 三步公式

| 条件 | 内容 | 怎么检验 |
| :--- | :--- | :--- |
| 主观 | 有随时使用凶器的意思 | 问自己：他带着它，是不是为了随时动手打人 |
| 客观 | 有随时使用凶器的可能性 | 问自己：能不能随时掏出来用（藏在袖中、让同伙递过来） |
| 客观 | 没有向被害人显示凶器 | 一旦明示、暗示或使用，直接定普通抢劫 |

* 三步都满足构成携带凶器抢夺定抢劫；有一步不满足，只能定**抢夺罪**。

* 例（木匠案）：木匠背着装满刀子、斧子、锤子的背包路过，见他人打电话，百米冲刺夺走手机。主观上没有随时使用的意思——若真打算动手不必藏得如此**隐蔽**；客观上也没有随时使用的可能，不能定抢劫，仍定抢夺罪。

* 例：夺走手机前对被害人说"嘘，别喊，给我十秒钟"，同样没有随时使用的意思和可能，定抢夺罪。

### 携带的含义

* **携带**指一种**现实的支配行为**——人可以随时使用自己所携带的物品。

* 携带方式既可以由本人携带，也可以**让第三人携带**。让同伙站在身边、口袋装着凶器，被害人敢追就让同伙递过来，仍成立携带凶器抢夺定抢劫。

* "携带"要求行为人同时具备随时使用凶器的**意思**与**可能性**。例：把匕首藏在袖中抢夺，心想"他敢反抗就用"，符合该要求。

* > **结论**：不能明示或者暗示使用凶器，一旦如此即属于以实施暴力相威胁，直接认定普通抢劫罪。

### 凶器的类型

| 类型 | 范围 | 举例 | 推定规则 |
| :--- | :--- | :--- | :--- |
| 性质上的凶器 | 国家禁止个人携带的器械 | 枪支、爆炸物、管制刀具、弹簧刀、三棱刀 | 生活上几乎无合法用途，携带即为犯罪目的，**原则上直接定抢劫罪** |
| 用法（功能）上的凶器 | 为实施犯罪而携带的其他器械 | 砖头、菜刀、铁棒 | 生活上有合法用途，**需有证据证明是为犯罪准备**，否则定抢夺罪 |

* **性质上的凶器**：生活上几乎没有用途，既然如此，携带它的目的就是为了犯罪，携带此类凶器抢夺的，原则上直接定抢劫罪。

* **用法（功能）上的凶器**：又叫功能上的凶器。司法解释规定，行为人随身携带国家禁止个人携带的器械以外的其他器械抢夺，但有证据证明该器械确实不是为了犯罪准备的，不构成抢劫。

    * 例：老人菜刀坏了、为烧饭新买一把菜刀放在自行车前篮里，骑车途中一把夺走他人背包。携带目的是抢夺吗？不是，只能定抢夺罪；经调查确属临时起意，不构成抢劫。

    * 例：专门携带水果刀用于实施抢夺，属于携带凶器抢夺定抢劫。

### 凶器的两个特征

* **凶器（凶器，凶器认定标准）**

    * > **定义**：凶器须同时具备**杀伤力**与**危险感**两个特征。

    * 杀伤力指具有致人死亡、致重伤的能力。

    * 危险感的标准是一般人的一般标准——一般人都会感觉这个东西用于犯罪时很危险。

    * 杀伤力与危险感**同时具备**，才是凶器；只有杀伤力而无危险感的，充其量是**作案工具**。作案工具的范围更大，凶器只是作案工具的一种。

| 物品 | 杀伤力 | 危险感 | 是否凶器 |
| :--- | :--- | :--- | :--- |
| 枪、菜刀 | 有 | 有 | 是 |
| 硫酸 | 有 | 有 | 是 |
| 领带 | 有（可勒死） | 无 | 否，充其量是作案工具 |
| 汽车 | 有（可撞死） | 无 | 否 |
| 腰带 | 有（可勒死、砸死） | 无 | 否 |
| 马蜂 | —— | —— | 否，凶器首先得是"东西" |

* 马蜂不是凶器，因为凶器首先得是"东西"。

## 转化型抢劫

* **转化型抢劫（事后抢劫，第269条）**

    * 犯盗窃、诈骗、抢夺罪，为窝藏赃物、抗拒抓捕或者毁灭罪证，当场使用暴力或者以暴力相威胁的，依照第263条定罪处罚。

    * 本规定属于**特殊规定**。客观上行为人有两个行为（先盗窃后故意伤害），本可数罪并罚，立法按抢劫罪定罪处罚。

* **特殊规定的法理**

    * 立法依据是：**对客体的侵害具有相同性或者相似性。**

    * 与普通抢劫的相同性：普通抢劫是先打倒再取财，同时侵犯财产权与人身权；事后抢劫是先取走财物再当场打倒，站在被害人的身体感受上并无区别，只是**顺序微调**。

    * 与携带凶器抢夺的相似性：一把夺走当场就会被发现，被害人大概率追赶，行为人带着匕首正是为防止被抓捕、被追赶，对被害人人身危险性相当高，达到与普通抢劫相当的程度。

* **成立结构**

```text
   一大前提   犯盗窃、诈骗、抢夺罪，且已着手（不必既遂）
               三类罪，不是三个罪；敲诈勒索不在其内
                  │
                  ▼
   三大目的   窝藏赃物 ｜ 抗拒抓捕 ｜ 毁灭罪证
               法定目的，缺一不可，不为此三者不能转化
                  │
                  ▼
   两种行为   当场使用暴力 ｜ 当场以暴力相威胁
               强度须与普通抢劫相当，足以压制反抗
```

### 一大前提

* **必须着手**，预备阶段不能转化为抢劫罪。

    * 司法解释要求行为人已经着手实施盗窃、诈骗、抢夺行为，**一般不考察是否既遂**。

    * 例：入户盗窃正在偷、尚未偷走时主人回来，为抗拒抓捕当场使用暴力，转为抢劫罪。

    * 例：进入小区见他人家门未锁，正在犹豫是否入户盗窃，因形迹可疑被保安发现后抗拒抓捕将保安打伤——犹豫表明尚未着手，连盗窃罪都不构成，只能定**故意伤害罪**。

* **指三类罪，不是三个罪**：既包括盗窃、诈骗、抢夺三个具体罪名，也包括它们的特别法条；法条竞合时符合条件可以转化，但**不能推而广之**。

    * 敲诈勒索罪不能转化为抢劫。

    * 盗窃罪的特别法可以转化，如**盗伐林木罪**（林木本身是财物），盗伐林木过程中被发现而抗拒抓捕当场使用暴力，可以转化为抢劫罪。

    * 诈骗罪的特别法可以转化，如**信用卡诈骗罪**。

    * 抢夺罪的特别法可以转化，如**抢夺枪支罪**（枪支本身是财物），抢夺枪支过程中被发现而抗拒抓捕当场使用暴力，可以转化为抢劫罪。

    * > **注意**：转化型抢劫是**按照抢劫罪定罪处罚**。抢夺枪支转化为抢劫，只能按抢劫罪定罪处罚，不能说转化成"抢劫枪支罪"。

    * 反例：**盗窃国家机关印章罪**不是盗窃罪的特别法。印章本身几乎没有财产属性，不能评价为刑法意义上的财物，所以不能转化。盗窃国家机关印章过程中被发现而将人打伤，只能定盗窃国家机关印章罪与故意伤害罪，数罪并罚。

* **携带凶器抢夺后再使用暴力**

    * 携带凶器抢夺后在逃跑过程中，为窝藏赃物、抗拒抓捕、毁灭罪证而当场使用暴力或者以暴力相威胁的，直接定第267条第2款"携带凶器抢夺定抢劫"。

    * 理由是此种行为**不能再转化为抢劫罪**：不能说从抢劫罪转化为抢劫罪。

### 三大目的

* **法定目的（窝藏赃物、抗拒抓捕、毁灭罪证）**

    * > **定义**：**窝藏赃物**指保护已经取得的赃物不被追回；**抗拒抓捕**指拒绝司法工作人员的拘留、逮捕，还有一般公民的扭送；**毁灭罪证**指毁灭盗窃、诈骗、抢夺的犯罪证据。

    * 三项为**法定目的，缺一不可**。目的不符合，不能转化为抢劫罪。

    * 例：夺走的项链本是镀金，夺路人恼羞成怒停步打对方两耳光并把项链甩还回去——目的是羞辱，不是窝藏赃物、抗拒抓捕、毁灭罪证，不能转化。打两耳光本身不能独立定罪，前面视数额与情节定抢夺既遂或未遂。

    * 例：扒窃得手后被追，跑出十公里得知追赶者是马拉松冠军，头也不回把手机向后甩出，恰好砸中对方额头致死——直接还回不是窝藏赃物，逃跑中未主动攻击他人身体不符合抗拒抓捕，人不是"东西"不能解释为罪证，不能转化；后段充其量是过失致人死亡，甚至可能是意外事件。

    * 例：入户盗窃后被十岁女孩目睹，为防止日后指认而将女孩杀死——目的不是窝藏赃物、抗拒抓捕、毁灭罪证，不能转化。前面定盗窃，后面定故意杀人，数罪并罚。

    * 例：在公交车上偷手机被破口大骂，恼羞成怒扇了对方两个耳光——恼羞成怒是为了羞辱对方，不属法定目的，不能转化。

### 两种行为与犯意升级

* **两种行为**为当场使用暴力、当场以暴力相威胁。

* 例：诈骗被当场识破，为抗拒抓捕持刀威胁——诈骗已着手且当场以暴力相威胁，成立转化型抢劫。

* **普通抢劫与转化型抢劫的关键区别在于目的**：

    * 被害人死死抓着包不松手，财物仍在被害人手中，行为人抡起拳头威胁"再不松开我打死你"——财物尚未取得，谈不上窝藏赃物，也不是抗拒抓捕、毁灭罪证。此为**犯意升级**，从抢夺故意升级为抢劫故意，构成**普通抢劫**。

    * 财物已经到手，被害人追上抱住腿，行为人抡起拳头威胁"再不松开我打死你"——为窝藏赃物、抗拒抓捕，构成**转化型抢劫**。

    * > **结论**：使用暴力或以暴力相威胁的目的是**继续取得财物**的，是压制反抗、取得财物，从抢夺升级为普通抢劫；只有为了窝藏赃物、抗拒抓捕、毁灭罪证，才是转化型抢劫。

```text
   被害人死死抓着包不松手
        └─ 财物仍在被害人手里 → 谈不上窝藏赃物
           → 犯意升级：抢夺 → 抢劫（普通抢劫，第263条）

   财物已经到手，被害人追上抱住腿
        └─ 为窝藏赃物、为抗拒抓捕
           → 转化型抢劫（第269条）
```

### 当场

* **当场（time condition）**

    * > **定义**："当场"指在盗窃、诈骗、抢夺的现场，以及行为人刚离开现场即被发现并抓捕的情形。

    * "当场"**并不是对案发现场的表述**，更侧重对**时间**的要求。

    * 简化为两种情形：**正在犯罪的时候被发现**；**刚离开现场就被发现**。

    * 要求三类罪的行为与当场使用暴力或以暴力相威胁，在时间上具有紧密联系。

    * 追捕具有持续性：甲偷走乙的手机，乙立刻追赶，不管追多久，只要行为人当场使用暴力或以暴力相威胁，都能转化。

    * 短暂的时间间隔不影响认定。追捕过程可以"接力"——被害人追着嫌疑人，途中把追捕任务交给巡逻警察由其接续，追捕并未中断；此时对警察使用暴力即为抗拒抓捕，从盗窃转化为抢劫，同时构成**袭警罪**，一个行为两个罪，想象竞合从一重，抢劫更重。

    * 反例：张三盗窃后已离开现场两个小时，因想起包落在现场而返回，偶遇李四后为抗拒抓捕将其打伤——不符合"当场"，前面定盗窃、后面定故意伤害，数罪并罚。

### 暴力的强度

* 当场使用暴力或者以暴力相威胁，须达到**与普通抢劫相当的程度**，足以压制被害人反抗。

* 司法解释规定：**以摆脱的方式逃脱抓捕**，**暴力强度较小**，**未造成轻伤以上后果**的，可以不认定为使用暴力，不宜以抢劫论处。

    * "摆脱的方式"指行为人即将被控制、几乎没有选择余地时的轻度反击行为。

    * 三个条件中后两个必须**同时满足**，少一个仍要定抢劫。

    * 例：被追时本可继续跑却偏不跑，拿起网吧门口炉子上的开水泼向追赶者——不属于摆脱的方式，暴力强度大，转化为抢劫罪。

    * 例：翻墙逃跑时一条腿已在院外，被害人拽住该腿，行为人顺势踢一脚后继续逃跑——属于以摆脱的方式逃脱，暴力强度较小，未造成轻伤以上后果，可以认为不属于使用暴力，不定抢劫罪。

    * 例：掏出一把枪瞄准被害人开枪但未打中——不属于即将被控制的摆脱情形，且暴力强度很大，转化为抢劫罪。

    * > **结论**：暴力程度较高时，即使未造成轻伤以上后果，也要转化为抢劫罪。

### 暴力的对象

* 转化型抢劫当场使用暴力或者以暴力相威胁，对象**没有特别限定**，但**必须是特定自然人**。

* 可以对被害人使用暴力，也可以对抓捕的警察或见义勇为的其他公民使用暴力。

* 例：唆使自己的狗追赶，捡砖头将狗砸死——虽然当场使用暴力，但压制的是狗的反抗，没有侵害复杂客体，**不能转化为抢劫罪**。前行为构成抢夺罪，后行为构成故意毁坏财物罪，数罪并罚。

* 例：入户盗窃后刚出门遇执勤警察，一拳将警察打成重伤——能转化为抢劫罪，且是抢劫致人重伤；同时构成袭警罪，想象竞合从一重，定抢劫致人重伤。

### 对象错误与打击错误

* **认错人（对象错误）**

    * 例：深夜在小区撬门开锁的甲，被初到当地、正想找人问路的乙拍了肩膀，误以为是房主归来，一刀将乙捅死。甲盗窃已着手，主观上为抗拒抓捕，当场使用暴力致人死亡，转化为抢劫罪，属抢劫致人死亡。

    * 理由在于法条表述中的**目的存在于主观即可**。

* **打偏了（打击错误）**

    * 例：甲盗窃李四的钱包被发现后逃跑，李四追赶，甲拿枪瞄准李四开枪，子弹打偏把路人王五打死。

    * 按法定符合说，性质相同、一视同仁，甲在扣动扳机这一刻已从盗窃转化为抢劫，抢劫的一部分致人死亡，成立抢劫罪，属抢劫致人死亡。

    * > **结论**：认错了人、打偏了，均可转化为抢劫罪。

### 主体条件与犯罪形态

* **主体条件：年满16周岁。** 抢劫罪普通犯年满14岁即可构成，但司法解释对转化型抢劫作特殊规定，要求行为人年满16岁。

    * 已满14周岁不满16周岁的人犯盗窃、诈骗、抢夺，为法定目的当场使用暴力，故意伤害致人重伤或者死亡，或者故意杀人的，只能定**故意伤害罪**或者**故意杀人罪**，切记不能转化为抢劫罪。

* **犯罪形态与普通抢劫相同**：取得财物或造成轻伤以上后果，二选一；有一个满足即既遂，两个都不满足即未遂。

* **条件总表**

| 条件项 | 具体要求 |
| :--- | :--- |
| 前提条件 | 犯盗窃、诈骗、抢夺罪；要求**着手**，不要求既遂；指的是**三类罪**，不是三个罪 |
| 目的条件 | **法定目的**三项：窝藏赃物、抗拒抓捕、毁灭罪证 |
| 客观条件 | **当场**使用暴力或以暴力相威胁；强度须与普通抢劫相当，足以压制反抗 |
| 主体条件 | 根据司法解释要求，**年满16周岁** |
| 犯罪形态 | 与普通抢劫相同：取得财物或造成轻伤以上后果，二选一 |

## 八项加重情节

### 情节类型与转化路径

* **加重犯（情节加重犯与结果加重犯）**

    * 第263条一口气规定八项加重处罚情形：入户抢劫、在公共交通工具上抢劫、抢劫银行或者其他金融机构、多次抢劫或者抢劫数额巨大、抢劫致人重伤、死亡、冒充军警人员抢劫、持枪抢劫、抢劫军用物资或者抢险救灾、救济物资。

    * 八项之中**只有第五项"抢劫致人重伤、死亡"是结果加重犯，其他七项都是情节加重犯**。

    * > **口诀**：冒充军警人员，持枪抢劫交通银行，致户内多人死伤。

| 口诀片段 | 对应加重情节 | 教材位置 |
| :--- | :--- | :--- |
| 户 | 入户抢劫（第一项） | 428 页 |
| 交通 | 在公共交通工具上抢劫（第二项） | 429 页 |
| 银行 | 抢劫银行或者其他金融机构（第三项） | 430 页 |
| 多人 | 多次抢劫或者抢劫数额巨大（第四项） | 430 页 |
| 死伤 | 抢劫致人重伤、死亡（第五项） | 430 页 |
| 冒充军警人员 | 冒充军警人员抢劫（第六项） | 430 页 |
| 持枪 | 持枪抢劫（第七项） | 430 页 |
| 军（第二层含义） | 抢劫军用物资或者抢险救灾、救济物资（第八项） | 432 页 |

* 口诀中的"军"字管两项：前面"冒充军警人员"的军是第六项；后面"抢劫军用物资或者抢险救灾、救济物资"的军是第八项。

* > **易错点**：第269条表明，**转化型抢劫既可能转成抢劫罪的基本犯，也可能转成抢劫罪的加重犯**——因为八项内容本身就是第263条的正文。

### 入户抢劫

* **入户抢劫（aggravated robbery in dwelling）**

    * > **定义**：以侵害户内人员的人身、财产为目的，入户后实施抢劫，包括入户实施盗窃、诈骗等犯罪而转化为抢劫的。

    * 因此普通抢劫可以具备入户情节，转化型抢劫同样可以。

* **"户"的认定**

    * > **定义**：户＝供家庭生活使用（功能特征）＋ 与外界相对隔离（场所特征）。

    * 两项同时满足才能解释为"户"。

    * 不是户：集体宿舍、旅店、宾馆、工人临时搭建的工棚——它们不是供家庭生活使用。几个人关系再好，过的仍是**集体生活**而非家庭生活。

    * 是户：封闭的院落、牧民的帐篷、作为家庭生活场所的渔船、为生活租用的房屋。翻墙进入北京四合院的院子内实施抢劫即已入户，进入房间实施抢劫更是入户；为家庭生活租住的房屋，他人擅自从门闯入实施抢劫同样是入户。

* **商住两用场所：先看区域，再看时间**

    * 经营和生活起居场所有明确隔离（如前半部分经营、后半部分生活、中间隔一道门）的，进入生活场所抢劫的一律是入户抢劫。

    * 两者之间没有明确隔离的，营业时间入内抢劫的不是入户抢劫，非营业时间入内抢劫的才是入户抢劫。

    * 司法解释另规定：部分时间经营、部分时间生活起居的场所，在**非营业时间强行入内抢劫**，或者**以购物为名骗开房门入内抢劫**的，都是入户抢劫。

```text
                    进入该场所实施抢劫
                            │
              ┌─────────────┴─────────────┐
              │                           │
         进入生活区域                  进入经营区域
              │                           │
     不用看时间，看区域              区域不是生活场所
     不管营业时间还是非营业时间             │
     一律是入户抢劫              ┌────────┴────────┐
                                  │                 │
                            营业时间内          非营业时间内
                                  │                 │
                             普通抢劫           入户抢劫
```

* **入户的两个硬条件**

    * **入户时必须具有非法目的。** 入户后临时起意实施抢劫，不认定为入户抢劫，应评价为"在户抢劫"，属普通抢劫；因访友、办事经户内人员允许入户后临时起意实施抢劫，或临时起意实施盗窃、诈骗犯罪而转化为抢劫的，同样是"在户抢劫"。

        * 例：甲出租房屋，乙前来查看房屋，发现屋内有贵重物品而临时起意抢劫。乙入户前没有非法目的，定为在户抢劫。

        * 例：甲在乙家做客时临时起意偷走乙的贵重邮票，为窝藏赃物当场对乙使用暴力。入户时没有非法占有目的，只能转化为抢劫罪的**基本犯**。

    * **抢劫行为必须发生在户内。** 站在普通抢劫角度，暴力、胁迫必须发生在户内。

        * 例：先打电话把被害人骗出家门，在外面打倒在地压制反抗后再入户取财物，暴力发生在户外，不能评价为入户抢劫。

        * 例：甲拦路抢劫，乙跑进出租房内躲避，甲追赶入内实施暴力，暴力发生在他人住宅之内，可以评价为入户抢劫。

    * 转化型抢劫的判断标准一模一样：入户实施盗窃、诈骗、抢夺被发现后为法定目的当场使用暴力，暴力**发生在户内**的认定为入户抢劫，发生在**户外**的不能认定为入户抢劫，只能转成基本犯。

    * > **结论**：不论普通抢劫还是转化型抢劫，评价为入户抢劫一律要求暴力或者胁迫**发生在户内**。

### 在公共交通工具上抢劫

* **在公共交通工具上抢劫（aggravated robbery on public transport）**

    * 范围上指在从事旅客运输的各种公共汽车、大中型出租车、火车、地铁、轻轨、轮船、飞机等**正在运营中**的机动公共交通工具上，对旅客、司售乘务人员实施抢劫。

    * 两类"视为"公共交通工具：接送职工的单位班车、接送师生的校车等大中型交通工具。

    * **小型出租车不包括，拼车也不算。** 公共交通工具上乘坐的人通常不特定且彼此不熟悉，抢劫容易引起不特定多人的心理恐慌甚至逃生踩踏，社会危害性更重；小型出租车上只能抢司机一个人，拼车也只针对特定的一两人，故只能认定为普通抢劫。

* **状态上的四项规则**

    * 在处于运营状态的公共交通工具上，对旅客、司售乘务人员实施抢劫。

    * 拦截运营途中的公共交通工具，对旅客、司售乘务人员实施抢劫。

    * **不包括**在未运营的公共交通工具上，针对司售乘务人员实施抢劫——公交车司机躺在座位上等待发车、尚未开始运营时被打倒取财，只能认定普通抢劫。

    * 以暴力、胁迫、麻醉手段对公共交通工具上特定人员实施抢劫的，一般也要定在公共交通工具上抢劫。

* **对象而非车辆**

    * > **定义**：在公共交通工具上抢劫，指的是抢劫**公共交通工具上的人**——乘客、司机、售票员、乘务员的财物，而不是抢走公共交通工具本身。

    * 例：以枪指着司机，令其把全部乘客带下来后登车开走公交车——不属于本项。

    * 例：以刀逼停公交车，令乘客排队从自己面前经过逐个搜身拿钱，行为人始终没有登上公交车——属于本项。**不看行为人的身体有没有登上公交车，要看对象是不是针对公共交通工具上的司乘人员。**

    * 例：登上公交车只抢坐在旁边的那一个乘客——该人仍是公共交通工具上的旅客，属于本项。

| 环节 | 认定标准 | 不算的情形 |
| :--- | :--- | :--- |
| 范围 | 公共汽车、大中型出租车、火车、地铁、轻轨、轮船、飞机等；接送职工的单位班车、接送师生的校车等大中型交通工具视为公共交通工具 | 小型出租车、拼车 |
| 状态 | 处于运营状态：车上直接抢劫，或拦截运营途中的交通工具抢劫 | 站点上尚未发车、司机躺在座位上休息的未运营车辆 |
| 对象 | 车上旅客、司机、售票员、乘务员的财物 | 公共交通工具本身（如把公交车开走） |

* **转化型抢劫看地点**

    * 司法解释规定：在公共交通工具上实施盗窃、诈骗、抢夺被发现，为法定目的当场使用暴力或者以暴力相威胁，**暴力发生在公共交通工具上**的认定为在公共交通工具上抢劫，**发生在车外**的不能认定，只能转化为基本犯。

    * 例：在公交车上扒窃被发现，当场在车上为抗拒抓捕将对方打伤——先转成抢劫，再转成在公共交通工具上抢劫的加重情节。

    * 例：扒窃被发现时公交车恰好到站，冲下车后在大街上被追上并当场对追捕者使用暴力——能转成抢劫罪，但不能转成在公共交通工具上抢劫。

    * > **结论**：在公共交通工具上抢劫，普通抢劫**看对象**，事后抢劫（转化型）**看地点**。

### 抢劫银行或者其他金融机构

* **抢劫银行或者其他金融机构**

    * 司法解释规定，指的是抢劫银行的**经营资金、有价证券、客户资金**。

    * > **定义**：客户资金指**属于银行所有、由银行占有**的资金，即客户把钱存到银行后，银行所收取、所吸收的资金。

    * 例：在储蓄大厅打倒刚取完5万元的老太太并取走这5万元——钱已由老太太占有、所有，属普通抢劫。

    * 例：冲进经理办公室打倒经理扛走两个沙发——不是银行的钱，属普通抢劫。

    * 例：冲进银行逼工作人员拿钱——抢的是银行的钱，属于本项。

    * 抢劫**正在使用中的**银行或者其他金融机构的运钞车，视为抢劫银行或者其他金融机构。这属于总则的扩大解释，构成抢劫银行的人变多。

    * > **结论**：不包括抢劫银行的**办公用品**，也不包括抢劫**储户身上的资金**——储户身上的资金是储户的资金，不是银行的资金。

### 多次抢劫与数额巨大

* **多次（multiple robbery）**

    * 按司法解释指**三次以上**。

* **数额巨大（huge amount）**

    * 参照盗窃罪数额巨大的标准，一般认为3万元以上可评价为抢劫数额巨大；最高法划的底线是要在3万元以上，但**每个省可以灵活调整**，各地标准不一样。

* **特别规则**

    * 抢劫**博物馆重要文物**，直接认定为抢劫数额巨大，适用10年以上直到死刑的法定刑。

### 抢劫致人重伤、死亡

* **抢劫致人重伤、死亡（aggravated result of causing serious injury or death）**

    * 八项加重情节中唯一的**结果加重犯**。

    * 要求抢劫行为与重伤、死亡结果之间具有**因果关系**；对重伤、死亡既可故意也可过失。

* **只有一个抢劫行为致死**

    * 例：为压制反抗先将被害人杀死再取走财物——抢劫致人死亡，属抢劫故意致人死亡。

    * 例：抢劫后逃跑未解开被害人身上的绳子，致其被饿死——抢劫行为与死亡结果之间具有因果关系，仍定抢劫致人死亡。

    * > **结论**：如果某个加重结果可以评价为前罪的结果加重犯或者更重的罪名，就没有必要单独认定不作为犯罪。撞过人之后不救助导致被害人失血过多死亡同理，因为立法已规定"逃逸致人死亡"。

* **两个行为致死则不构成加重犯关系**

    * 例：抢劫得手后为灭口把被害人杀死——不可能认定为抢劫致人死亡，前面定抢劫、后面定故意杀人，数罪并罚。

    * 例：抢劫后逃跑，遇到仇人已将其杀死——第二个行为致死，前行为抢劫、后行为故意杀人，数罪并罚。

    * 例：抢劫后逃跑不慎将乙撞死——逃跑行为致死，前行为抢劫、后行为交通肇事罪，数罪并罚。

* **范围与故意上比强奸、拐卖宽**

| | 客观行为 | 结果加重犯的范围 | 死亡结果能否是直接故意 |
| :--- | :--- | :--- | :--- |
| 抢劫罪 | 暴力、胁迫、其他方法 | 致人重伤、死亡，既包括被害人死亡，也包括**其他人**死亡 | 可以（为压制反抗先杀人再取财） |
| 强奸罪 | 暴力、胁迫、其他手段 | 强奸致人重伤、死亡**仅限于被害人** | 不可以，一律数罪并罚 |
| 拐卖妇女儿童罪 | 拐卖行为 | 拐卖致人重伤、死亡**仅限于被害人** | 不可以，一律数罪并罚 |

    * 范围上不限于财物的主人。转化型抢劫中警察来抓、行为人为抗拒抓捕把警察打死，也能转为抢劫致人死亡。

    * 故意上可以是直接故意。强奸罪中若致人死亡限于被害人，李四来制止被行为人打死，李四不是被强奸致死的，应定强奸罪与故意杀人罪数罪并罚；且强奸致人重伤、死亡对死亡结果不能是直接故意——既已直接杀死就不可能再实现强奸目的。

    * 拐卖妇女儿童罪原理相同：既然要卖掉对方，总归要留条命，拐卖过程中故意杀人的是两个行为，数罪并罚。

    * > **结论**：在强奸和拐卖罪中，对造成的死亡结果绝对不能是直接故意；只有在抢劫罪中，直接故意杀人可以作为结果加重犯被吸收。

* 转化型抢劫的结果加重犯也能转成抢劫致人重伤、死亡——认错人的对象错误与打偏了的打击错误同样成立。

### 冒充军警人员抢劫

* **冒充军警人员抢劫（aggravated robbery by impersonating military or police personnel）**

    * > **定义**："冒充"的实质就是一句话——**和自己的真实身份不符合**。

    * 两种冒充：一是无身份者冒充有身份者；二是此种身份冒充彼种身份（警察谎称自己是军人，或军人谎称自己是警察）。两者都属冒充。

    * 司法解释要求综合判断行为人是否穿着军警制服、携带枪支、是否出示军警证件等情节，判断是否**足以使他人误认为是军警人员**。

    * 例：警察向被害人指明自己就是警察并取走财物——利用的是自己的真实身份，与身份相符，不能评价为冒充军警人员抢劫。

    * > **易错点**：根据司法解释，**军警人员利用自己的真实身份实施抢劫，不属于冒充**，只能依法从重处罚。

### 持枪抢劫

* **持枪抢劫（aggravated robbery with a firearm）**

    * 指行为人**使用枪支，或者向被害人显示持有、佩带的枪支**进行抢劫。

    * 立法理由是持枪抢劫成功率接近百分之百，且容易造成严重后果。

    * 限制一：**枪是真枪。** 按文理解释，刑法意义上的"枪"是枪支，玩具枪根本不是枪，拿玩具枪抢劫不能认定为持枪抢劫。

    * 限制二：**必须向被害人使用或者显示枪支**，让被害人知道自己带着枪，并利用枪支压制其反抗。

    * 转化型抢劫可以转成持枪抢劫，且不构成重复评价：犯盗窃为抗拒抓捕携带枪支逃离，被害人追赶时掏出枪威胁"再追我一枪打死你"，在转化型抢劫的基础上又多出持枪情节。

        * 检验方法：设想不考虑这把枪，抡起拳头说"再追我当场打死你"已经能转化型抢劫；把枪拿回来，只是在此基础上多加一个持枪情节。

    * 反面：口袋中装着一把枪未露出来，看到他人背包后一把夺走——枪未被显示、未被用来压制反抗，只能评价为携带凶器抢夺定抢劫。**枪已作为"抢夺中的凶器"被评价过，不能再当成持枪抢劫的那把枪。**

    * > **结论**：普通抢劫和转化型抢劫在持枪问题上要求相同——一定要向被害人显示枪支，让被害人知道自己带着枪，要利用枪支压制其反抗。

### 抢劫军用物资或者抢险救灾、救济物资

* **抢劫特殊物资**

    * 特殊物资包括军用物资以及抢险救灾物资、救济物资。

    * 主客观相统一，针对特定对象、特殊物资，要求行为人**明知**自己抢劫的对象是上述物资。不明知就表明没有犯本项情节的故意，只能认定为基本犯。

        * 例：拦路抢劫时以为是普通物资，事后查明是救灾物资，不得适用抢劫救灾物资这一加重情节。

        * 例：本想抢救灾物资，抢到手发现是救济物资——主观上有抢劫特殊物资的故意，客观上有抢劫特殊物资的行为并已抢到，可以适用加重法定刑。**误把A种特殊物资当作B种特殊物资的，认定为这一加重情节。**

    * 犯罪客体决定定性，**主观罪过优先认定**：看他想抢的是什么。

    * > **易错点**：如果抢劫的是枪支、弹药、爆炸物，有更特殊的**抢劫枪支弹药爆炸物罪**，不要再定"抢劫军用物资"这一加重情节，直接认定抢劫枪支弹药爆炸物罪。

### 加重情节的既未遂

* 抢劫罪的八种加重情形中，**除抢劫致人重伤、死亡外，其他七种同样存在既遂与未遂**。

* 属于抢劫未遂的，应根据加重情节的法定刑结合未遂犯的规定量刑。

* 排除致人重伤、死亡的原因：抢劫罪的既遂条件要么是取得财物、要么是造成被害人轻伤以上，已经致人重伤、死亡的必然构成既遂，不可能再有未遂。

* 例：持枪拦路抢劫并压制了反抗，对方搜身身无分文——构成抢劫罪（未遂），同时具有持枪抢劫的情节。加重情节（10年以上直到死刑）与未遂情节（可从轻或减轻）两个情节综合评价。

* 例：以数额巨大的财物为目标，因意志以外的原因未得逞，或者实际抢到的财物数额不大——适用抢劫数额巨大的法定刑，同时具有未遂情节，两个情节综合评价。

## 抢劫罪的罪数

### 特殊对象

* **抢劫违禁品**：以假币、淫秽物品等违禁品为对象实施抢劫的仍定抢劫罪，抢劫违禁品的数量作为量刑情节考虑。抢劫违禁品后又以该违禁品实施其他犯罪的，数罪并罚，如抢劫毒品后又贩卖、先抢劫假币后又卖出。

* **抢劫赌资**

    * 抢劫赌资、犯罪所得的赃款赃物，构成抢劫罪。

    * 行为人**仅以其所输赌资或者所赢赌债为抢劫对象**的，一般不以抢劫罪定罪处罚；将对方打伤的，定故意伤害罪。

        * 例：赌博输给对方5万元现金后将钱抢回，赌资已归对方占有，不定抢劫。

        * 例：对方欠自己5万元赌债，将其打倒只抢走这5万元，属以所赢赌债为对象，不定抢劫；打伤的可构成故意伤害。

    * > **易错点**：这是特殊规定，不能推而广之。

* **抢劫近亲属的财物**

    * 为个人使用，以暴力、胁迫手段取得家庭成员或者近亲属财产的，一般不定抢劫罪，构成其他罪就定其他罪。

    * 但教唆、伙同他人抢劫家庭成员、近亲属财产的，肯定构成抢劫罪——如教唆他人抢劫自己家人，成立抢劫罪的共犯。

* **抢劫机动车**

    * 为实施抢劫以外的目的，劫取机动车作为犯罪工具或者逃跑工具的，**使用被劫机动车的价值计入抢劫数额**。此类情形构成两个抢劫罪，属同种数罪，不并罚，犯罪数额累计相加。

    * 为实施抢劫以外的其他犯罪而劫取机动车的，**以抢劫罪和其他犯罪实行数罪并罚**。如为绑架而先抢一辆车作交通工具，抢劫机动车构成抢劫罪，之后实施绑架，数罪并罚。

### 飞车抢夺

* **飞车抢夺（snatching by vehicle）**

    * 驾驶车辆夺取他人财物，**原则上定抢夺罪**；达到压制反抗程度的，定抢劫罪。

    * 司法解释列出的三种情形都属于对人实施了暴力、足以压制反抗，本来就应定抢劫，是提醒性规定：

        * 夺取他人财物时，因被害人不放手而强行夺取——如骑车抓住被害人的包后加大油门，拖着被害人跑出十几米致其手腕骨折，这已不是单纯对物暴力而是对人暴力。

        * 驾驶车辆逼挤、撞击或者强行逼倒他人，夺取财物。

        * 明知会致人伤亡，仍然强行夺取并放任造成财物持有人轻伤以上后果的。

    * 第三种情形须三项**同时满足**：

        * "明知"表明主观上达到犯罪故意的认识程度，即明知会致人伤亡。

        * "仍然强行夺取并放任"表明是间接故意。

        * "造成财物持有人轻伤以上后果"，轻伤后果必须**实际发生**——既然声称是放任，结果就必须真的出现，否则间接故意不能成立犯罪。

        * 例：骑车高速行驶，明知夺包后惯性会使步履蹒跚的老太太摔伤摔死仍放任，夺包致其头部着地当场摔死——有压制反抗的故意、客观也起到压制反抗的效果并造成死亡，定抢劫罪、抢劫致人死亡。

        * 例：骑车一把夺走壮汉的包，对方未摔倒、未受伤——不符合"明知＋放任＋轻伤以上后果"的结构，只能定抢夺罪。

### 与相似犯罪的界限

* **与盗窃罪的界限**

    * 司法解释：

        * 行为人实施伤害、强奸等犯罪行为，在**被害人未失去知觉**的情况下，利用被害人不能反抗、不敢反抗的处境临时起意劫取他人财物的，以此前所犯之罪和**抢劫罪**实行数罪并罚。

        * 在**被害人失去知觉或者没有发觉**的情况下，以及实施故意杀人犯罪行为后临时起意拿走他人财物的，以此前实施的犯罪和**盗窃罪**实行并罚。

    * 该解释可以佐证：中国本土观点仍坚持**盗窃必须具备秘密性**——被害人失去知觉或者没有发觉时的窃取正是秘密窃取。

* **特殊认知（special cognition）**

    * > **定义**：一个人主观认识越清晰、越具体，对客观行为的要求就越低。

    * 例：通常情况下拿小刀朝胳膊划一刀只能评价为故意伤害，涉及构成要件的**类型化原理**。

    * 例：偏僻之地偶遇仇人，明知其有白血病或血友病（一个小伤口即流血不止）且地处偏僻，划一刀即致其流血过多死亡——可评价为故意杀人。

    * 例：与对方是发小，对方自小怕自己、言听计从，看到其戴金项链后拍拍肩膀说"哥们儿，金项链送给我"，对方主动递上——拍拍肩膀压制不了普通人的反抗，但行为人对此有特殊认知，构成抢劫罪。

    * 例：强奸既遂后，行为人已确信对方不敢反抗，说一句"闭嘴""把眼睛也闭上"即可取走金项链——前一个压制反抗的故意指向强奸，后一个指向抢劫，**是两个行为**，以强奸罪与抢劫罪数罪并罚。

        * 排除重复评价的疑问：强奸行为已经结束，后行为可以单独评价；行为人明知一句话就足以压制这个特定被害人的反抗，没有必要再动手殴打。

        * 例：强奸既遂后趁被害人在床上哭泣不注意，取走床头柜上的金项链——没有二次压制反抗的故意，以强奸罪与盗窃罪数罪并罚。

        * 概括为"当场杀，当场拿，定盗窃"。

* **索取债务型伤害**

    * 行为人为索取债务，使用暴力、暴力威胁等手段的，一般不构成抢劫罪——其目的是实现自己的债权，没有非法占有他人财物的目的。符合构成的定故意伤害等相关犯罪。

    * 但若主观上具有非法占有目的，先将对方打伤压制其反抗再取走财物，构成抢劫罪；致人重伤、死亡的，成立抢劫罪的结果加重犯。

* **冒充型犯罪**

    * 警察属于国家机关工作人员，冒充国家机关工作人员抓赌抓嫖、没收赌资、罚款的构成招摇撞骗罪；在此过程中使用暴力压制反抗的，构成抢劫罪，且属于**冒充军警人员抢劫**。

    * 治安联防队员不是国家机关工作人员（有的在村委会、居委会下面），冒充他们抓赌抓嫖不能定招摇撞骗罪；符合条件没收赌资、罚款的，充其量构成敲诈勒索；使用暴力压制反抗的，定抢劫罪。

    * > **结论**：冒充国家机关工作人员抓赌抓嫖并招摇撞骗，压制反抗则定抢劫；冒充治安联防队员的，不能构成招摇撞骗，符合条件只能定敲诈勒索，使用暴力压制反抗的定抢劫罪。

### 与绑架罪的区别

* **抢劫罪与绑架罪的四个区别**

    * **客体不完全相同。** 抢劫罪是复杂客体，主要客体是财产、次要客体是人身；绑架罪也是复杂客体，刚好反过来。

    * **行为不完全相同。** 抢劫要满足"两个当场"，劫取财物一般具有当场性；绑架是以杀伤人质相威胁，向第三人勒索赎金、提出不法要求，劫取财物一般不具有当场性——总得给对方家属留出准备赎金的时间。

    * **目的不同。** 抢劫罪以非法占有为目的；绑架罪以勒索财物或者劫持他人作为人质为目的。

    * **主体不同。** 抢劫罪普通抢劫年满14周岁；绑架罪要求年满16周岁。

* **绑架过程中当场劫取被害人财物的从一重处罚**

    * 绑架是**继续犯**，绑架控制人质、压制反抗的行为持续存在、并未结束，此时又劫取其财物，原则上从一重处罚；并罚才有重复评价之嫌。

    * 这与"强奸既遂后再劫取财物"不是一回事：强奸行为已经结束，后行为可以单独评价。
