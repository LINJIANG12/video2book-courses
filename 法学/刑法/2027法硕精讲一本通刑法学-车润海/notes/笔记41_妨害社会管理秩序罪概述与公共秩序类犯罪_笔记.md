# 妨害社会管理秩序罪概述与公共秩序类犯罪

## 本章体系与罪名分布

* **妨害社会管理秩序罪**

    > **定义**：违反国家规定，妨害国家机关对社会的管理活动，破坏社会正常秩序，情节严重的行为。

    * 客体是国家机关对社会的管理秩序。之所以卡住"国家机关"四个字，是因为只有国家机关才具有执法权，才能对社会进行管理。

    * 主体上多数是一般主体，少数是特殊主体，极个别犯罪还可以由单位构成——计算机网络类的犯罪单位也能构成。

    * 主观方面多数是故意犯罪，少数是过失犯罪，如医疗事故罪。

    * 与破坏社会主义市场经济秩序罪的第一把钥匙：市场秩序那一章的罪名通常都和钱有关，行为人以谋取非法利益为目的；本章之罪一般和钱没有关系，妨害的是社会管理秩序。

    > **提示**：罪名拿不准归属时，先问一句——它和钱有没有关系。

* **九个小类**

    * 大纲共考察 50 个罪名，比法考范围大很多；采取"大类拆小类"的方法拆成九个小类。

```text
第23章 妨害社会管理秩序罪（大纲共 50 个罪名 → 九个小类）
  |
  +-- 一 扰乱公共秩序 ....... 第 1-25（占半壁江山，含计算机网络类 12-16）
  +-- 二 妨害司法秩序 ....... 第 26-33（重点：28 掩饰、隐瞒犯罪所得罪）
  +-- 三 妨害国（边）境管理 .. 大纲只要求掌握组织他人偷越国边境罪
  +-- 四 妨害文物管理 ....... 新增小类
  +-- 五 公共卫生秩序
  +-- 六 环境资源保护
  +-- 七 犯罪
  +-- 八 卖淫相关犯罪
  +-- 九 淫秽物品相关联的犯罪
```

    * 扰乱公共秩序共 25 个罪名，从第 1 个高空抛物到第 25 个，这一小类讲完即解决全章一半内容。

    * 计算机网络类犯罪排在第 12 至第 16 个，第 16 个帮信罪司法实践中案发率相对较高。

    * 妨害司法秩序排第 26 至第 33 个，重点是第 28 个掩饰、隐瞒犯罪所得罪，它与第 16 个帮信罪及相关犯罪共犯之间的界限可能是本章唯一的难点。

    * 妨害国（边）境管理大纲只要求掌握组织他人偷越国边境罪；妨害文物管理是新增小类。

## 妨害公务罪

* **妨害公务罪**

    > **定义**：以暴力、威胁方法阻碍国家机关工作人员依法执行职务的行为。

    * 客体：国家机关工作人员依法执行职务的活动。

    * 主体：一般主体。第四种情形下的主体另有讲究。

    * 主观方面：故意，要求明知对方正在依法执行职务。

    * 第一款法定刑为三年以下有期徒刑，整体量刑比较轻。

* **四个法条情形的形态分野**

    * 前三款法条均写明"以暴力、威胁方法"，故均为行为犯，不要求造成严重后果，但行为必须表现为暴力、威胁。

    * 第四款不要求使用暴力、威胁方法，但要求造成严重后果，是典型的结果犯。

    > **易错点**：前三款行为犯、第四款结果犯。这条是本罪最容易被绕进去的地方，后面所有考法都从这里长出来。

| 法条情形 | 行为对象 | 行为手段 | 形态 | 关键要求 |
| :--- | :--- | :--- | :--- | :--- |
| 第一款 | 国家机关工作人员依法执行职务 | 暴力、威胁 | 行为犯 | 不要求造成严重后果 |
| 第二款 | 同为国家机关工作人员依法执行职务 | 暴力、威胁 | 行为犯 | 不要求造成严重后果 |
| 第三款 | 红十字会工作人员依法履行职责 | 暴力、威胁 | 行为犯 | 须发生在自然灾害或突发事件中 |
| 第四款 | 国家安全机关、公安机关依法执行国家安全任务 | 未使用暴力、威胁 | 结果犯 | 必须造成严重后果 |

* **认定的三道关**

    * 必须发生在执行公务的过程中：张三入户盗窃惊醒主人李四，李四是城管，张三为抗拒抓捕将城管打伤，不发生在李四执行公务过程中，不构成本罪，而从盗窃转化为抢劫罪。

    * 第四种情形第一种考法：使用了暴力、威胁方法又造成严重后果，可以适用第四款，这叫当然解释，入罪时举轻以明重。

    * 第四种情形第二种考法：使用暴力、威胁方法但未造成严重后果，不能适用第四款，但并不意味着无罪——国家机关包括国家安全机关与公安机关，最起码可回落第一款以妨害公务罪追究刑事责任。

    * 对象不包括军人。阻碍军人执行职务的，适用更特殊的阻碍军人执行职务罪。

* **主观上的假想防卫**

    * 警察乙暗访时，甲以为乙是正在盗窃的小偷，当场将其打伤控制。客观上并不存在不法侵害，甲误认为有不法侵害，属于假想防卫。

    * 假想防卫不能构成故意犯罪，有过失的可能构成过失犯罪，但无论如何不构成妨害公务罪，因为他根本没有妨害公务的故意。

* **罪数**

    * 一个行为想象竞合从一重：以暴力抗拒执法把执法人员打成轻伤，通常仍定妨害公务罪；打成重伤定故意伤害罪；活活打死的定故意杀人罪；过失致人重伤、死亡同样从一重处罚。

    * 数个行为原则上数罪并罚：先犯生产、销售伪劣产品罪，走私，非法经营，拐卖妇女儿童等罪，后又妨害公务。

    > **提示**：原则能推导出来，例外才是考点。有三个罪例外不并罚。

| 例外不并罚的三个罪 | 处理 |
| :--- | :--- |
| 组织他人偷越国边境罪 | 妨害公务情节严重时被规定为情节加重犯，只定本罪并适用更重法定刑 |
| 运送他人偷越国边境罪 | 原理完全相同 |
| 走私、贩卖、运输、制造毒品罪 | 以暴力抗拒检查、拘留、逮捕且情节严重时，只定本罪，把"情节严重"圈起来 |

* **真题落点：私刻公章骗回被暂扣的三轮车**

    * 题干：甲为逃避处罚，私刻交警部门公章，伪造取车单，将其因违章被暂扣的电动三轮车骗回，问构成何罪。

    * 答案：伪造国家机关印章罪。

    * 解析依据：本人所有但被他人合法占有的财物能否成为本人财产犯罪的对象，关键看主观上有没有非法占有他人财物的目的。有则可构成财产犯罪，没有则不构成，改按其他罪处理。甲没有非法占有相关单位财物的目的，也没有要求相关单位赔偿，先排除盗窃罪，再排除诈骗罪，只剩伪造国家机关印章罪。

    > **易错点**："为了逃避处罚当然有非法占有目的"的说法站不住：电动三轮车被暂扣，罚钱能罚多少，达不到财产犯罪的程度；他要的是不交罚款，不是拿走交管单位现实存在的财物。此题与法考观点不一样。

## 袭警罪

* **袭警罪**

    > **定义**：暴力袭击正在依法执行职务的人民警察的行为。

    * 客体：人民警察依法执行职务的活动，还包括他的人身安全。

    * 主体：一般主体。主观方面：故意。

    * 要求动手，单纯辱骂不构成本罪；不要求击中。抡起砖头砸向警察头部而警察躲开的，构成既遂——本罪是行为犯，不是结果犯。

    * 法定刑：暴力袭击处三年以下有期徒刑；使用枪支、管制刀具或者以驾驶机动车撞击等手段严重危及人身安全的，处三年以上七年以下，明显重于妨害公务罪。

* **与妨害公务罪的竞合**

    * 构成袭警罪一定构成妨害公务罪，两者是法条竞合。虽在法理上本罪是妨害公务罪的特别法，但司法解释规定依照处罚较重的规定定罪处罚。

| 情形 | 定罪结论 |
| :--- | :--- |
| 袭警行为造成警察轻伤 | 想象竞合从一重，定袭警罪 |
| 故意造成警察重伤、死亡 | 定故意伤害罪 / 故意杀人罪 |
| 过失造成警察重伤、死亡 | 想象竞合从一重，只有一个行为不能并罚 |
| 同时构成妨害公务罪 | 依处罚较重规定，袭警方定刑更重，定袭警罪 |

    * 数个行为数罪并罚，例外同样是组织他人偷越国边境罪、运送他人偷越国边境罪、走私、贩卖、运输、制造毒品罪——犯袭警罪是这三个罪的情节加重犯。

    * 加重情节与以危险方法危害公共安全罪的界限：驾车冲撞特定警察、虽致其死亡也不定以危罪，因为没有危害公共安全；警察在人群中而行为人开车冲撞人群的，同时构成袭警罪与以危险方法危害公共安全罪，想象竞合从一重定以危罪。

* **司法解释补上的三块拼图**

    * 什么算"依法执行职务"：人民警察遇有其职责范围内的紧急情况应当履行职责。负责治安工作的警察看到他人打架斗殴、故意伤害有制止义务，下班时间遇到职责范围内的紧急情况也视为执行职务。

    * 对非执行职务的人民警察实施报复性暴力袭击的不构成袭警罪，符合条件的定故意伤害罪、故意杀人罪。张三把李四骗出打成重伤的，只能定故意伤害罪。

    * 对行为人一般不作为犯罪处理：警察插手经济纠纷本身存在严重过错、执法丧失正当性，既不能构成妨害公务罪也不能构成袭警罪；执法过错较大、袭警暴力程度较轻危害不大的一般不作为犯罪处理；造成严重后果确实要追究责任的依法从宽。

* **对象只到警察，辅警另作处理**

    * 人民法院、人民检察院的司法警察属于人民警察。

    * 辅警全称"警务辅助人员"，本身没有执法权，单独执法不成立；配合警察执法时属于国家工作人员、从事公务。

    * 单纯袭击辅警不能构成袭警罪，充其量定妨害公务罪；同时袭击警察和辅警的，以袭警罪从重处罚——行为人只有一个故意，客观上也只有一个行为。

* **暴力袭击的两种形态**

    * 对人施暴：撕咬、掌掴、踢打、抱摔、投掷物品等造成轻微伤以上，以及使用枪支、管制刀具等足以危及人身安全的行为。

    * 对物施暴：推倒执法摩托车、掀翻警车、驾车冲撞警车。唯一尺度是是否足以危害警察的人身安全。警车停在楼下、车里无人时砸警车不构成袭警罪。

    * 一般性抗拒行为不认定：为了摆脱抓捕、约束而实施的甩手、挣脱、蹬腿等危害不大，以及仅仅辱骂、讽刺的言语攻击，都不算暴力袭击。警察把小偷摁倒后小偷挣扎几下属一般性摆脱抓捕，没有期待可能性。

    * 未使用暴力袭击但符合妨害公务罪条件的，以威胁方法仍可定妨害公务罪。

## 招摇撞骗罪

* **招摇撞骗罪**

    > **定义**：冒充国家机关工作人员招摇撞骗，谋取非法利益的行为。

    * 客体：国家机关的威信及其正常活动。

    * 主体：一般主体。主观方面：故意，且具有谋取非法利益的目的。

    * 冒充人民警察招摇撞骗的，依照前款规定从重处罚。

* **冒充的学问**

    * 冒充对象只能是国家机关工作人员，包括各级权力机关、司法机关、行政机关、军事机关以及监察机关。

    * 不能包括冒充军人。冒充军人招摇撞骗的，适用冒充军人招摇撞骗罪这一特别法，要优先适用。

    * 不包括国有企业、事业单位的人员和外国官员。冒充高校校长、电视台台长、新闻记者去骗钱的，充其量定诈骗罪。

    * 冒充的标准是"和真实身份对不上"：以非国家机关工作人员冒充国家机关工作人员最常见；职务低的冒充职务高的或反向冒充也行；此种冒充彼种也算。

    > **易错点**：若行为人本身就是警察，利用真实身份骗钱，没有冒充任何人，只能定诈骗罪，不能定招摇撞骗罪。

* **撞骗的范围**

    * 招摇撞骗的范围远大于诈骗罪：可以骗钱、骗色、骗名誉、骗地位、骗感情、骗待遇。

    * 必须有撞骗行为。甲身着警装招摇过市、群众认为是警察但未实施撞骗的，不构成本罪。

    * "骗"要求被害人有相对的意志自由和选择余地：冒充警察将人打倒取走财物的，定冒充军警人员抢劫罪——利益被截取而非处分；冒充警察压制反抗实施强奸的，定强奸罪。

* **与诈骗罪的从一重安排**

    * 两罪是法条竞合，本罪是特别法，但司法解释明确规定：冒充国家机关工作人员进行诈骗，同时构成诈骗罪和招摇撞骗罪的，依照处罚较重的规定定罪处罚。研考观点是特别法优先，与法考观点不同。

    * 冒充军人招摇撞骗罪同样是诈骗罪的特别法，同时构成时也从一重。

    * 三罪并存时只有一种情况特别法优先：招摇撞骗罪与冒充军人招摇撞骗罪同时出现时，定冒充军人招摇撞骗罪；招摇撞骗罪与诈骗罪、冒充军人招摇撞骗罪与诈骗罪同时出现，一律从一重。

    * 冒充国家机关工作人员骗取数额巨大或特别巨大财物的，一般认为定诈骗罪，因为诈骗罪法定刑更重。考试一般不考数额，骗的钱不多时通常定招摇撞骗罪。

* **冒充型犯罪六条落点**

    * 冒充军警人员抢劫的，是抢劫罪的情节加重犯。

    * 冒充警察招摇撞骗的，定招摇撞骗罪，从重处罚。

    * 冒充军人（包括武警，武警属于军人）招摇撞骗的，定冒充军人招摇撞骗罪。

    * 冒充执法人员执法骗取钱财的，同时构成本罪和诈骗罪，从一重。

    * 冒充正在执行公务的人民警察抓赌抓嫖、没收赌资罚款的，定招摇撞骗罪并从重，因为冒充的是警察；压制反抗的定抢劫罪，属冒充军警人员抢劫。

    * 冒充治安联防队员抓赌抓嫖、没收赌资罚款的，治安联防队员没有国家机关工作人员身份，冒充对象不符合本罪要求，只能定敲诈勒索；压制反抗的最终定强奸罪。

## 伪造、变造、买卖国家机关公文、证件、印章罪

* **伪造、变造、买卖国家机关公文、证件、印章罪**

    > **定义**：伪造、变造、买卖国家机关公文、证件、印章的行为。

    * 选择罪名。客体是国家机关公文、证件、印章的公共信用。

    * 犯本罪通常只是前奏，行为人一定拿伪造、变造、买卖的公文证件印章去干别的坏事，因此罪数关系是重点。

* **三个动词的边界**

    * 有形伪造：没有制作公文、证件、印章权限的人，冒用国家机关名义制作。如应聘者托人用手机软件生成无犯罪记录证明、用印章生成器加盖一个章，生成者构成伪造国家机关公文罪。

    * 无形伪造：有制作权限的人，未经法定程序擅自以国家机关名义制作与事实不符合的公文、证件、印章。如四川省江安县法官李某伪造民事调解书，被认定为伪造国家机关公文罪。

    * 伪造印章与伪造印影：没有制作权限的人制造国家机关印章即私刻公章；没有私刻公章而用红墨水描绘出与国家机关印章一模一样的图样盖在纸上，是伪造印影，同样属于伪造国家机关印章的一项内容。

    * 变造：对真实的国家机关公文、证件、印章进行涂抹、涂改、拼接，变更原来真实内容。变造不得改变本质内容，大改是伪造、小动是变造——擅自修改公文发布日期一般认定变造，擅自修改公文关键内容直接定伪造。

    * 买卖：包括单纯买、单纯卖、先买后卖三种形态。本罪是选择罪名，同时实施上述行为只定一罪，不实行数罪并罚。行为人伪造后出卖的，定伪造、买卖国家机关印章罪；甲将刻好的印章卖给乙，甲是单纯卖、乙是单纯买，两人均构成买卖国家机关印章罪。

* **伪造与变造的分野**

```text
        真实的公文 / 证件 / 印章（真的这个主体在）
                          |
             +------------+------------+
             |                         |
            小动                      大改
   （涂抹涂改拼接，变更       （动了本质内容，
     原来真实内容）             不再是真家伙）
             |                         |
          变 造                     伪 造
```

* **犯罪对象的范围**

    * 对象范围既包括真实的，也包括伪造、变造的公文、证件、印章，伪造、变造的还是更常见的。

    * 真印章同样可成为对象：否则意味着市政府今天刻个章卖掉、明天再刻一个接着卖、后天再刻一个还卖疯了。

    * 公文：国家机关在职权范围内以名义制作的、用以指示工作、处理问题或联系事务的各种书面文件，如决定、命令、公告、通告、通知、通报、报告、请示、电文、会议纪要等。公文大部分盖章，内部会议纪要一般不盖。

    * 证件：国家机关制作颁发的、用以证明身份、权利义务关系有关事实的凭证，如工作证、户口证、营业执照、结婚证、驾驶证等。

    * 印章：刻有国家机关组织名称的公章，或某种特殊用途的专用章。

    > **提示**：买卖机动车号牌（前后挂的蓝牌或绿牌）不构成买卖国家机关证件罪，因为它不是用于证明身份的。最高法已明确这种情况不定罪。

* **罪数**

    * 与伪造、变造、买卖身份证件罪是法条竞合。身份证由公安机关制作发放，本身属于国家机关证件，伪造身份证、驾驶证同时构成两罪，身份证件罪是特别法，要优先适用。

    * 伪造高等院校印章、制作学历学位证明的，高等院校不是国家机关，不构成本罪，定伪造公司、企业、事业单位、人民团体印章罪，因为大学属于事业单位。

    * 先伪造再实施诈骗类犯罪的，是牵连犯，择一重罪定罪处罚：手段行为构成本罪，目的行为构成招摇撞骗罪或者诈骗罪。

## 伪造、变造、买卖身份证件罪

* **伪造、变造、买卖身份证件罪**

    > **定义**：伪造、变造、买卖居民身份证、护照、社会保障卡、驾驶证等依法可以用于证明身份的证件的行为。

    * 客体：国家对居民身份证件的管理制度。制作主体必须是国家机关。

    * 主体：一般主体。主观方面：故意。

    * 身份证件必须是对外使用的：仅在机关内部作证明使用的不能认定。国家机关工作人员的工作证、出入证不属于本罪的身份证件，因为它代表的不是公共信用。

    * 与伪造、变造、买卖国家机关证件罪是法条竞合，本罪是特别法，要优先适用。

    * 牵连犯：先犯本罪又利用虚假身份证件实施诈骗等犯罪的，择一重罪处罚。甲购买乙遗失的身份证构成买卖身份证件罪，再用乙的名义实施合同诈骗，属牵连犯择一重。

* **伪造**

    * 有形伪造：没有制作权限的人非法制作身份证。如请人办假身份证，办假证的人因伪造后又卖出而构成伪造、买卖身份证件罪，委托方只是单纯购买。

    * 无形伪造：有制作权限的人擅自制作与事实不符合的身份证件。如户籍警察为好友制作身份证件，但姓名、号码用的是另一个真实存在的身份，与事实不对应，仍属伪造。

* **变造**

    * 只能是对身份证件非本质部分的小修小改。如把超过有效期的身份证改成仍在有效期内，属变造。

    * 修改姓名、照片属于改变本质内容的大改，定伪造身份证件罪。

* **买卖**

    * 单纯买、单纯卖、既买又卖都可以，范围与前述国家机关公文证件印章罪完全一致。

* **使用虚假身份证件罪与盗用身份证件罪（超纲）**

    * 在依照国家规定应当提供身份证明的活动中（结婚、服兵役等），使用伪造、变造或者盗用他人的身份证件：证是假的定使用虚假身份证件罪；证是真的定盗用身份证件罪。

    * "盗用"应解释为"冒用"：它不是针对身份证持证人而言，而是针对相应的登记机关、检察机关而言。甲经乙同意用乙的身份证与小花登记结婚，对婚姻登记机关而言仍然是盗用，甲构成本罪，乙构成本罪的共犯。

## 冒名顶替罪

* **冒名顶替罪**

    > **定义**：盗用、冒用他人身份，顶替他人取得高等学历教育入学资格、公务员录用资格以及就业安置待遇的行为。

    * 客体是复杂客体：冒名妨害社会管理秩序，顶替侵害被冒名顶替公民的人身权利。

    * 主体：一般主体。主观方面：故意。

    * 典型的行为犯，只要行为实施到一定程度即构成既遂。

* **两个资格与一个待遇**

    * 冒名：盗用、冒用能够证明他人身份的证件，比如身份证、身份证明文件、学籍证明、身份档案、个人信息资料等；以自己冒充并替代他人的社会或者法律地位，行使他人的相关权利。

    * 高等学历教育入学资格：指经过考试等程序依法获取的资格，范围包括专科、本科、硕士研究生、博士研究生教育。

    * 公务员录用资格：指根据公务员法等法律规定的公务员录用程序取得的资格。

    * 就业安置待遇：指由各级人民政府对符合条件的退役军人、英雄烈士遗属等特定人员予以安排就业、照顾就业等优惠待遇。

    > **提示**：冒名顶替的不是上述"两个资格、一个待遇"的，不构成本罪。冒名顶替他人结婚的可能构成重婚罪；冒名顶替他人领取社会保障金、医保待遇的可能构成诈骗罪。

* **法定情节与罪数**

    * 组织、指使他人实施本罪行为的，依照前款规定从重处罚。顶替入学要打通就读高中、当地教育局、省教育厅、录取高校四部关系，几乎一定有国家工作人员参与——负责高考报志愿的中学老师、大学招生办人员、负责录用公务员的工作人员、负责就业安置的人员。

    * 国家工作人员犯本罪又构成其他犯罪的，数罪并罚。即使是牵连犯、具有牵连关系也要并罚。例：国家工作人员组织指使他人实施本罪行为同时收受贿赂构成受贿罪，两罪并罚；国家工作人员在组织指使过程中又伪造、变造身份证件，也并罚。

    * 普通人伪造他人身份证件又犯冒名顶替罪的，两罪高度并合、一起生的概率相当高，认定为牵连犯，从一重罪处罚。

    > **易错点**：国家工作人员犯本罪又犯其他罪一律并罚，普通人从一重——这一条带有特殊规定的成分，是本罪的采分点。

## 非法获取国家秘密罪

* **非法获取国家秘密罪**

    > **定义**：以窃取、刺探、收买方法非法获取国家秘密的行为。

    * 客体：国家的保密制度。主体：一般主体。主观方面：故意。最高刑为七年有期徒刑。

    * 客观行为是封闭的：法条列举"窃取、刺探、收买"三个方法，后面没有"等"字。用其他手段非法搞到国家秘密的，不能往本罪上靠。

    * 查不清行为人非法获取国家秘密到底为了什么的，一般认定为非法获取国家秘密罪——本罪具有兜底性。

| 罪属关系 | 处理 |
| :--- | :--- |
| 构成间谍罪，又构成本罪 | 定间谍罪，间谍罪可以包含其他涉密类犯罪，对行为人可作全面评价 |
| 目的是提供给境外 | 定境外窃取、刺探、收买非法提供国家秘密、情报罪；本罪是一般法，该罪是特别法，特别法优先 |
| 目的不明、查不清 | 定本罪，兜底 |

    > **提示**：做题时一旦觉得某个罪名"好像什么都管"，八成它就是兜底罪。

## 投放虚假危险物质罪

* **投放虚假危险物质罪**

    > **定义**：投放虚假的爆炸性、毒害性、放射性、传染病病原体等物质，扰乱社会秩序的行为。

    * 客体：正常的社会秩序。主体：一般主体。主观方面：故意。

    * "虚假"意味着不会危害公共安全，但会引起社会恐慌、严重扰乱社会秩序。

    * 罪名中多出"爆炸性"三个字的原因：危害公共安全犯罪中另有爆炸罪，投放真实爆炸性物质的直接定爆炸罪；扰乱公共秩序犯罪中没有投放虚假爆炸物罪，故把爆炸性物质纳入本罪范围。

| 比较项 | 投放虚假危险物质罪 | 投放危险物质罪 | 爆炸罪 |
| :--- | :--- | :--- | :--- |
| 客体 | 正常的社会秩序 | 公共安全 | 公共安全 |
| 投放物 | 虚假的爆炸性、毒害性、放射性、传染病病原体 | 真实的毒害性、放射性、传染病病原体等 | 真实的爆炸性物质 |
| 主观 | 意图扰乱公共秩序 | 意图危害公共安全 | 意图危害公共安全 |

* **投放举动与对象范围**

    * 行为方式要求是"投放"。某人不满拆迁政策，让新闻单位都去寄信，信中装的是白色粉末，检测为碳酸钙即白石灰粉。接收单位误以为是有强大传染性的物质而隔离人员，行为人构成投放虚假危险物质罪——写信同样是投放。

    * 只能针对不特定人。针对特定人投放虚假危险物质的不构成本罪。如为报复在乙的食用面粉中投淀粉并谎称是毒鼠强，一般很难定罪。

    > **易错点**："虚假"不减损社会秩序法益——恐慌本身就是法益侵害。

## 编造、故意传播虚假恐怖信息罪

* **编造、故意传播虚假恐怖信息罪**

    > **定义**：编造爆炸威胁、生化威胁、放射威胁等恐怖信息，或者明知是编造的恐怖信息而故意传播，严重扰乱社会秩序。

    * 客体：正常的社会秩序。主体：一般主体。主观方面：故意。

    * "编造"既包括无中生有的完全捏造，也包括对某些信息进行加工修改，只要是不真实的信息即可。

* **编造与传播的分水岭是告知对象**

    * 编造本身即包含着要告诉特定的人；只有告诉社会不特定人，才成立"编造、故意传播"。

    * 魏学臣案：其背着另一位导游悄悄给大连周水子国际机场值班室打电话，称某航班上有几个恐怖分子。值班员通报领导后报警，警方带警犬地毯式搜索并核查全部登机人员，未发现恐怖分子，致飞机晚点 33 分钟。只定编造虚假恐怖信息罪——他只告诉了特定的值班员。

    * 反之，编造后在机场拿大喇叭喊或在网上散布、面向社会不特定人的，构成编造、故意传播虚假恐怖信息罪。若只自己编造、写在日记里不告诉任何人，不可能扰乱社会秩序，这说明"编造"必然包含告知特定人这一层。

* **虚假恐怖信息的构成**

    > **定义**：以发生爆炸威胁、劫持航空器威胁、重大灾情、重大疫情等严重威胁公共安全的事件为内容，可能引起社会恐慌或者公共安全危机的不真实信息。

* **超纲罪名编造、故意传播虚假信息罪**

    > **定义**：编造、故意传播虚假的险情、灾情、疫情、警情，在信息网络或者其他媒体上传播，或者明知是上述虚假信息而故意在信息网络或者其他媒体上传播，严重扰乱社会秩序。

    * 与虚假恐怖信息罪的差别就在"重大"两个字：编造、故意传播重大灾情、重大疫情的，定编造、故意传播虚假恐怖信息罪；一般灾情、一般疫情不会引起社会恐慌，定编造、故意传播虚假信息罪。

    * 陈某案：她为测试丈夫是否关心儿子而将儿子藏匿，报警求助并假装配合警方搜寻，又通过微信朋友圈发布求助信息引发群众转发。这属于编造、故意传播虚假警情并在信息网络媒体上传播，定编造、故意传播虚假信息罪。

    * 反向印证：袁老去世时媒体公开宣称并引起全国愤慨，但"袁老去世"不沾险情、灾情、疫情、警情任何一项，客观上定不了罪。

* **与投放虚假危险物质罪的界分**

    * 客观行为不同：投放虚假危险物质罪一定要有"投放"的举动；本罪没有投放，只是编造、故意传播。

    * 商场放了一包东西谎称是爆炸物，商场人员一哄而散——只有投放，定投放虚假危险物质罪。

    * 安检排队时把一团卫生纸包着朝天一扔，大喊"有炸弹，卧倒哇"——有投放举动，定投放虚假危险物质罪。

    * 向警察声称"我已在超市装好了定时炸弹"，警察疏散人群后地毯式搜索、警犬搜索，发现是假的——无投放举动，定编造、故意传播虚假恐怖信息罪。

    > **结论**：有投放就定投放虚假危险物质罪，没有投放、只是编造故意传播，就定编造、故意传播虚假恐怖信息罪。这才是解题的标准。

* **虚假信息类罪名的三级递进**

```text
┌────────────────────────────────────────────────────────┐
│  虚假信息类罪名的三级递进：按顺序往下走，命中即定罪     │
└────────────────────────────────────────────────────────┘

  ① 这条信息的内容是虚假恐怖信息吗？
        ├─ 是 → 编造、故意传播虚假恐怖信息罪
        └─ 否 ↓

  ② 是虚假的险情、灾情、疫情、警情吗？
        ├─ 是 → 编造、故意传播虚假信息罪
        └─ 否 ↓

  ③ 一也不是、二也不是
          → 寻衅滋事罪
```

* **与敲诈勒索罪：想象竞合从一重**

    * 袁某因经济拮据，编造已在上海太平洋百货徐汇店放置炸弹的虚假恐怖信息，以不给钱就引爆炸弹自杀相威胁，要求一小时内向指定账户汇款 5 万元。构成编造虚假恐怖信息罪与敲诈勒索罪，想象竞合从一重。

    * 竞合理由：敲诈勒索罪是恐吓行为加索取财物；"我在商场已经装了炸弹"本身就是编造，与恐吓内容完全重合，是一个行为触犯两个罪。检察机关曾认为这是两个行为，被最高法否定。

    > **易错点**：结论是想象竞合从一重，不是数罪并罚。

## 组织考试作弊罪

* **组织考试作弊罪**

    > **定义**：在法律规定的国家考试中，组织作弊或者为他人组织作弊提供作弊器材或者其他帮助。

    * 客体：国家的考试制度。主体：自然人。主观方面：故意。

    * 属于情节犯，处罚较轻，但存在数罪并罚的特殊规定。

* **成立范围**

    * 只能发生在法律规定的国家考试中，"法律规定"四个字是限定条件。

    * 高等学历考试：普通高等学校招生考试、研究生招生考试、高等教育自学考试、成人高考等。

    * 公务员考试：中央和地方公务员都可以。

    * 重要资格考试：法律职业资格、教师执业资格、医师执业资格、会计师和注册会计师、会计专业技术资格考试等，可简称"法师"。

    * 兜底条款：其他依照法律，由中央或者地方主管部门以及行业组织的国家考试。如机动车驾驶证考试由《道路交通安全法》规定，组织他人作弊可以构成本罪。

    > **提示**：特殊类型招生、特殊技能测试、面试、体能测试都属于法律规定的国家考试的组成部分，笔试可以、面试可以、体能测试也可以。涉及的体育运动中，组织考生非法使用兴奋剂的也能构成本罪。

* **行为方式与形态**

    * "组织作弊"指组织、策划、指挥进行考试作弊。组织者可以是一人也可以是多人；本罪是任意共犯。

    * 被组织者原则上应当是多人。为特定的应考人寻找替考人、没有组织多人替考的，不构成本罪。甲介绍乙代替丙参加研究生入学考试，因未组织多人替考，对甲可定代替考试罪的共犯。

    * 单纯的作弊本身无罪，充其量成绩宣告无效、在一定期限内禁止再参加该考试。

    * 本罪作为行为犯，通常要组织行为实施完毕才构成既遂。在考试开始之前被查获的通常定未遂；但已经非法获取考试试题答案，或者具有其他严重扰乱考试秩序情形的，认定为既遂。

    > **提示**：该形态的特殊规定出自司法解释，需要重点关注。

* **罪数：数罪并罚的明文规定**

    * 单位问题：本罪主体仅限自然人。单位犯本罪，不能追究单位的责任，只能对相关自然人按本罪定罪处罚。

    * 数罪并罚（司法解释明文规定）：以窃取、刺探、收买方法非法获取法律规定的国家考试的试题和答案（构成非法获取国家秘密罪，因为试题开启前属于国家秘密），又组织考试作弊或者非法出售、提供试题答案的，数罪并罚。

```text
【数罪并罚】——司法解释明文规定

  窃取、刺探、收买
  考试试题和答案
          │
          ▼
  非法获取国家秘密罪
  （真题开启之前属于国家秘密）
          │
          ├── 又组织考试作弊 ──► 组织考试作弊罪        ══ 并罚
          │
          └── 又非法出售、提供 ──► 非法出售、提供试题答案罪 ══ 并罚
```

    * 牵连犯：为组织考试作弊而伪造、变造身份证件的，手段行为构成伪造、变造身份证件罪，目的行为构成本罪，择一重罪处罚，一般认为本罪更重。

## 非法出售、提供试题答案罪

* **非法出售、提供试题答案罪**

    > **定义**：为实施考试作弊行为，向他人非法出售或提供法律规定的考试试题和答案。

    * 超纲罪名，只抓两个细节。刑法意义上的考试类犯罪，包括与考试相关的试题和答案，都只能发生在法律规定的国家考试中——大学期末考试提前拿到试题答案不构成犯罪。

    * 时间要求：行为必须发生在考前或考试过程中。考试都结束了才把试题答案公开出来，这叫真题书，不构成本罪。

    * 真实性要求：试题不完整、答案与标准答案不完全一致，不影响本罪认定。考前只提供"一半靠谱"的试题答案，仍然构成本罪。

    > **易错点**：若声称出售"完整的法基"试题答案、索取 10 万元并要求到考场才能拆封，考生付款后打开发现内容是"乘法口诀，一一得一，一二得二"，则提供的内容没有任何真实性，主客观相统一，行为人主观上并非想出售或提供试题答案，构成诈骗罪。

## 代替考试罪

* **代替考试罪**

    > **定义**：代替他人，或者让他人代替自己参加法律规定的国家考试。

    * 客体：国家的考试管理制度。主体：替考者（枪手）与应考者两类人。主观方面：故意。

    * 单纯作弊无罪，但代替他人或让他人代替自己参加考试的构成本罪。

    * 原则上双方均为实行犯、构成共犯。法条明文规定"让他人代替自己参加法律规定的国家考试"，所以对象犯不排除极端情况下只有一方构成犯罪。

    * 极端情形：某考生考前住院，其父找人代考并伪造身份证件，考生本人坚持要参考，其父遂将其打晕，考生直至考试结束才知真相。结论是考生被打晕、无犯罪故意，不构成本罪；其父构成代替考试罪的教唆犯；替考者构成实行犯。

    * 牵连犯：为代替他人参加考试而伪造、变造身份证件的，成立本罪与伪造、变造身份证件罪的牵连犯，择一重罪处罚。

## 计算机网络类犯罪的体系划分

| 罪名 | 实行行为 | 对象与关键限定 | 形态 |
| :--- | :--- | :--- | :--- |
| 非法侵入计算机信息系统罪 | 非法侵入 | 国家事务、国防建设、尖端科学技术领域的计算机信息系统 | 行为犯，侵入即既遂 |
| 破坏计算机信息系统罪 | 破坏 | 系统功能 / 数据与应用程序 / 病毒等破坏性程序 | 结果犯，后果严重 |
| 拒不履行信息网络安全管理义务罪 | 不履行义务而拒不改正 | 特殊主体：网络服务提供者 | 纯正不作为，有前置责令程序 |
| 非法利用信息网络罪 | 非法利用 | 设立网站通讯群组、发布信息、为实施违法犯罪发布信息 | 情节犯，处罚较轻 |
| 帮助信息网络犯罪活动罪 | 提供帮助 | 概括明知即可；帮助犯正犯化 | 情节犯，处罚较轻 |

## 非法侵入计算机信息系统罪

* **非法侵入计算机信息系统罪**

    > **定义**：违反国家规定，侵入国家事务、国防建设、尖端科学技术领域的计算机信息系统的行为。

    * 记忆口诀"两国一尖端"：两个是"国家事务"和"国防建设"，一个是"尖端科学技术领域"。

    * 客体：国家对计算机信息系统的安全管理秩序，以及上述领域计算机信息系统的正常运行。

    * 主体：单位和自然人均可构成。主观方面：故意。

    * 典型的行为犯，只要非法侵入即构成既遂，侵入后"到此一游"、看一看又出来同样既遂。

    > **易错点**：罪名听着宽，对象其实窄，仅限"两国一尖端"三个领域；侵入普通计算机系统不构成本罪。

* **认定的三道关**

    * 要求违反国家规定：包括违反法律、行政法规，因为只有法律和行政法规才代表国家级层面的规定，此外还有《计算机信息网络国际联网管理暂行规定》等。

    * 行为方式是非法侵入：未经国家有关主管部门合法授权或批准，通过计算机终端访问国家重要计算机信息系统，或者进行数据拦截。

    * 主观要明知：明知是国家事务、国防建设、尖端科学技术领域的计算机系统而非法侵入。过失侵入没有犯罪故意，不构成本罪。

    * 构成本罪通常要委托司法鉴定，鉴定相关系统能否评价为"两国一尖端"领域的计算机信息系统。

* **计算机信息系统的范围**

    * 刑法中的"计算机信息系统""计算机系统"指具备自动处理数据功能的系统，要把"自动处理数据"圈起来。

    * 包括计算机、网络设备、通信设备以及自动化控制设备；智能手机、网站，甚至有些大型机械都可以评价为计算机信息系统。

* **与非法获取数据、非法控制两罪的界限**

```text
  侵入某个计算机信息系统
          │
          ├── 目标 = 国家事务 / 国防建设 / 尖端科学技术领域的系统
          │      └──→ 非法侵入计算机信息系统罪（行为犯，侵入即既遂）
          │
          └── 目标 = 上述领域以外的系统
                 ├── 侵入后获取其数据，情节严重
                 │      └──→ 非法获取计算机信息系统数据罪
                 └── 侵入后实施非法控制，情节严重
                        └──→ 非法控制计算机信息系统罪
```

    * 非法获取计算机信息系统数据罪、非法控制计算机信息系统罪的对象是"两国一尖端"领域以外的系统，公式是"侵入 + 获取或控制"，且要求情节严重。

    * 提供侵入、非法控制计算机信息系统程序、工具罪（超纲）：只需知道罪名存在，结构是动宾——"提供"是动词、"程序工具"是名词，中间加限定词"专门用于侵入、非法控制计算机信息系统的"。行为人卖程序工具给李四，李四实施控制的，李四定非法控制计算机信息系统罪，卖方定本罪。

    * 利用计算机实施后续犯罪（刑法第 287 条）：利用计算机实施金融诈骗、盗窃、贪污、挪用公款、窃取国家秘密或者其他犯罪的，依照有关规定处罚。侵入银行系统转账的直接定盗窃罪，前面的侵入罪要么被后罪牵连、要么被后罪吸收，结论是只定后面的罪。

## 破坏计算机信息系统罪

* **破坏计算机信息系统罪**

    > **定义**：违反国家规定，破坏计算机信息系统的功能、数据与应用程序或者传播破坏性程序，造成严重后果的行为。

    * 客体：计算机信息安全。主体：单位和自然人均可构成。主观方面：故意。

    * 本罪是结果犯，三款都要求后果严重；第一款的法定刑最重，起点即五年以上有期徒刑。

    * 计算机信息系统的范围与非法侵入罪一致：具有自动处理数据功能的系统，智能手机、网站、大型机械的远程监控系统均可评价在内。

| 法条 | 破坏或影响的对象 | 后果要求 | 法定刑特点 |
| :--- | :--- | :--- | :--- |
| 第一款 | 计算机信息系统的功能 | 造成系统不能正常运行，后果严重 | 最重，五年以上起 |
| 第二款 | 系统中存储、处理、传输的数据和应用程序 | 后果严重，不要求系统不能正常运行 | — |
| 第三款 | 病毒等破坏性程序 | 影响系统正常运行，后果严重 | — |

* **破坏系统的功能**

    * 行为样态是"增加、删除、修改、干扰"，记忆逻辑顺序为增加—删除—修改—干扰。增加与删除是反义词，但都是修改；增加、删除、修改必然会干扰。

    * 第 33 号李秉龙案：以修改大型互联网网站域名解析指向的方法劫持互联网流量至赌博网站获取境外广告提成，致使网站不能正常运行，构成破坏计算机信息系统罪。输入网址发现目标网站打不开、被引导到另一网站，充分表明该网站的访问功能已被破坏。

    * 最高法第 102 号案例：通过修改路由器、浏览器设置，锁定主页、弹出新窗口等技术手段强制用户访问指定网站，属破坏功能。

* **破坏数据和应用程序**

    * 某"协警"并非警察，仅协助处理事务，盗用干警账号密码，删除交警部门计算机信息系统中储存的交通违章信息并收钱，构成破坏计算机信息系统罪。

    * 认定为"破坏"的依据：他根本没有访问权和处理权限，未经合法批准或授权擅自进入并删除数据；虽未导致系统不能正常运行，但可评价为造成其他严重后果。

* **制作、传播计算机病毒**

    * 法条要求是"影响计算机信息系统正常运行"，只要影响即可；造成不能正常运行的，举轻以明重，更能构成本罪。

    * 熊猫烧香案：编写病毒在网上大面积传播，暗中盗取用户账号密码出售牟利，并控制受感染电脑访问特定网站获利，构成破坏计算机信息系统罪。

* **三个经典案例**

    * 曾兴亮案：冒充年轻女性聊天，诱骗被害人注销苹果手机原有 ID，改用其提供的 ID 及密码登录，远程锁定多名被害人的苹果手机。智能手机终端具备自动处理数据功能，锁定导致不能正常使用属破坏功能。

    * 中联重科案：出卖泵车安装 GPS 信息服务系统并在买卖合同中约定停机锁机、付清货款前所有权归出卖人，徐强用 GPS 干扰器为多名违约者解除锁定。企业的机械远程监控系统属于具有自动处理数据功能的计算机系统，解除锁定破坏系统功能，造成不能正常运行、后果严重。

    * 环境检测仪案：地方为躲避北京监测，在环保部门安装的环境检测仪上做手脚，戴 N95 口罩或塞棉花，致使传输的 PM2.5 数据严重失真。破坏的是系统中存储、处理、传输的数据，后果严重。

* **罪数**

    * 先非法侵入"两国一尖端"领域的系统又实施破坏行为的，前后针对的是同一个对象，直接定破坏计算机信息系统罪，司法解释有明文规定；本罪更重，理论上牵连犯与吸收犯之争不影响结论。

## 拒不履行信息网络安全管理义务罪

* **拒不履行信息网络安全管理义务罪**

    > **定义**：网络服务提供者不履行法律、行政法规规定的信息网络安全管理义务，经责令后拒不改正，情节严重的。

    * "拒"字的理解与拒不支付劳动报酬罪一致：必须先被责令，被责令之后还不改，才叫"拒"。

    * 主体是特殊主体，限于网络服务提供者，包括自然人和单位。

    > **易错点**：网络服务提供者的范围很广，不要只想到中国联通、中国电信、中国移动。百度公司、腾讯公司、百度网盘都是网络服务提供者。

* **四种情形加一个兜底**

    * 拒不履行义务，致使违法信息大量传播。

    * 拒不履行义务，致使用户信息泄露，造成严重后果。

    * 拒不履行义务，致使刑事案件证据灭失，情节严重。

    * 有其他严重情节的，这是兜底。

    * 口诀：三条例外情形分别对应"违法""用户""刑事"，再加第四项兜底。法定刑三年以下，单位也能构成本罪。

* **性质与前置程序**

    * 纯正不作为，以不作为的方式构成本罪。

    * 有前置程序：电信、公安等依照法律、行政法规承担信息网络安全监管职责的部门，以责令通知书或者其他文书的形式，责令网络服务提供者采取改正措施。

    * 例：张三利用百度网盘链接分享公民个人信息，网监部门责令百度网盘的提供者停止分享，拒不改正造成用户信息泄露、后果严重的，直接认定本罪。

    * 罪数：以牟利为目的利用互联网传播淫秽物品而不改正的，一个行为既构成传播淫秽物品牟利罪又构成本罪，想像竞合从一重——不改正本身就是在继续传播。

## 非法利用信息网络罪

* **非法利用信息网络罪**

    > **定义**：利用信息网络实施设立用于违法犯罪活动的网站、通讯群组，发布有关违法犯罪信息，为实施诈骗等违法犯罪活动发布信息，情节严重。

    * 客体：信息网络的安全管理秩序。主体：一般主体，包括单位。主观方面：故意。

    * 法定刑三年以下，甚至可以单处罚金；犯本罪同时构成其他犯罪的，依照处罚较重的规定定罪处罚。

    * 非法利用不等于全部入罪：浏览淫秽视频、翻墙等非法利用未被纳入刑事处罚范围，只有刑法规定的部分行为方式才构成犯罪。

* **三种行为方式**

    * 设立用于实施违法犯罪活动的网站、通讯群组。口诀"诈骗方法，制售违禁管制物品"：诈骗对应第一，传授对应传授犯罪方法，制是制作、售是销售，违禁是违禁物品，管制是管制物品。通讯群组包括 QQ 群、微信群、钉钉群。司法解释明确指以实施违法犯罪活动为目的而设立，或者设立后主要用于实施违法犯罪活动的网站、通讯群组。

    * 发布有关违法犯罪的信息。口诀"制售黄、暴、毒等违禁管制物品"：黄是制作、销售淫秽物品，暴是暴力犯罪信息（典型是枪支），毒是毒品，以及违禁物品、管制物品或者其他违法犯罪信息。微信朋友圈也是信息网络。

    * 为实施诈骗等违法犯罪活动发布信息。

* **"发布"的含义与违法行为的缩小解释**

    * 司法解释明文规定：利用信息网络提供信息的链接、截屏、二维码、访问账号密码以及其他指引访问服务，都认定为发布信息。甲在多个微信群中发布二维码诱导被害人下载某 APP，致多名被害人险些被骗的，构成本罪。

    * 司法解释规定：本罪中的"违法犯罪"包括犯罪行为，以及属于刑法分则规定的行为类型、但尚不构成犯罪的违法行为。

    * 判断标准是这个违法行为"能不能长大"：通过时间积累、次数增加，以后能否变成犯罪行为——能在刑法分则条文里找到对应犯罪行为的，才属于本罪的"违法"。

    * 卖淫是纯粹的违法行为，单纯卖淫无论多久都不可能变成犯罪行为，"长不大"。卖淫者在网上发布招嫖信息、贴出照片的，不构成本罪。

    * 侵犯公民个人信息刚开始三条五条十条达不到立案标准，但可以"长大"成侵犯公民个人信息罪。设立多个窃取公民个人信息的网站、非法获取公民个人信息若干条未达立案标准的，构成本罪。

* **入罪标准与罪数**

    * 属于情节犯，一般不直接考数量。设立用于实施违法犯罪活动的网站数量三个以上、注册用户账号 2000 个以上才能定罪。

    * 设立用于实施考试作弊的网站、通讯群组，发布有关考试作弊信息，情节严重，同时构成组织考试作弊罪、非法出售提供试题答案罪、非法获取国家秘密罪的，依照处罚较重的规定定罪处罚。

    * 设立用于实施相关犯罪的网站、通讯群组，同时构成贩卖毒品罪、传授犯罪方法罪的，依照处罚较重的规定定罪处罚。

    * 设立用于非法获取、出售、提供公民个人信息的网站、通讯群组，情节严重，同时构成侵犯公民个人信息罪的，定侵犯公民个人信息罪，因为它更重。

    * 例：发布有关制造犯罪方法的信息，同时构成本罪与传授犯罪方法罪的，定传授犯罪方法罪；设立多个窃取公民个人信息的网站、非法获取公民个人信息一万条的，定侵犯公民个人信息罪。

## 帮助信息网络犯罪活动罪

* **帮助信息网络犯罪活动罪（帮信罪）**

    > **定义**：明知他人利用信息网络实施犯罪，而为其犯罪提供互联网接入、服务器托管、网络存储、通讯传输等技术支持，或者广告推广、支付结算等帮助，情节严重。

    * 技术支持四项的记忆口诀是"接管网通"：接是互联网接入，管是服务器托管，通是网络存储、通讯传输，网是网络。

    * 客体：信息网络的正常管理秩序。主体：一般主体，包括单位。主观方面：故意。

    * 法定刑较轻，甚至可以单处罚金；犯本罪同时构成其他犯罪的，依照处罚较重的规定定罪处罚。

    > **定义**：立法将帮助犯规定为独立罪名，即帮助犯的正犯化（实行化）。构成帮信罪的直接按本罪法定刑定罪量刑，不能再拿总则中的从犯规定对其从宽处罚。

* **明知的程度决定定罪**

    * 帮信罪只要求主观上概括明知：明知他人利用信息网络实施犯罪即可，至于实施的具体是什么罪不要求达到这种程度。

    * 马峰案：马峰托人组建一个非实名认证的局域网，说"我管那么多干嘛，知道得越少越安全"。组建人只是概括不明知具体是贩卖毒品，对其定帮信罪；马峰本人构成贩卖毒品罪，可能同时构成非法利用信息网络罪，最终定贩卖毒品罪。

    * 真实案例：某人在台湾受指派进入大陆办理 12 张银行卡并开通网银，谎称来大陆投资，明知可能被用于网络犯罪仍然办理，实质是提供支付结算，构成帮信罪。

    > **结论**：罪数完全取决于明知程度——概括明知只能定本罪；具体明知构成帮信罪与相关犯罪的共犯，从一重处罚。例：明知乙要实施网络诈骗仍主动提供网络推广帮助的，既构成本罪又构成诈骗罪共犯，从一重。

* **收买银行卡：一个牵连犯**

    * 甲收买银行卡及有关信息资料，为他人实施信息网络犯罪提供支付结算帮助，有两个行为。

    * 收买后必然持有，非法持有他人信用卡数量较大的，构成妨害信用卡管理罪；提供给他人作支付结算，构成帮信罪。

    * 支付结算在实践中通常表现为供卡，两个罪并发概率高，具有牵连关系，牵连犯择一重罪处罚。

    > **提示**：牵连犯在理论上有一定争议，不要任意扩大范围。

* **被帮助人未被追责不影响本罪**

    * 被帮助对象是否被追究刑事责任，不影响本罪成立。被帮助人潜逃的，只要现有证据足以证明行为人明知其利用信息网络实施犯罪而提供帮助，就可追诉。

    * 确因客观条件限制无法查证被帮助对象是否达到犯罪程度，但支付结算金额达到特定标准或造成严重后果的，同样构成本罪——被帮助人所实施的犯罪比较轻微、未必入罪，行为人自己达到入罪标准即可定帮信罪。

    * 被帮助对象实施的行为可以确认，但尚未到案、尚未依法裁判，或者因没有达到刑事责任年龄等原因依法未被追究刑事责任的，不影响帮信罪的认定。

* **司法解释的两条入罪规则**

    * 明知他人利用信息网络实施犯罪而为其提供帮助，具有下列情形之一即构成本罪：为三个以上对象提供帮助；支付结算金额二十万元以上等。

    * 明知他人实施电信网络诈骗犯罪，具有下列情形之一的以共犯论处，但法律和司法解释另有规定的除外。注意"实施"二字——正在实施或即将实施，不能是他人犯罪结束之后。明知他人即将实施而提供帮助是事前通谋的共犯；明知他人正在实施而提供帮助是事前无通谋的共犯，又称承继共犯。

## 聚众斗殴罪

* **聚众斗殴罪**

    > **定义**：出于报私仇、争霸或者其他不正当目的，成帮结伙打架斗殴，破坏公共秩序。

    * 客体：公共秩序。主体：一般主体，但仅限首要分子和积极参加者。主观方面：故意。

    * 动机是本罪最容易被绕过去的一道关——动机不对，罪名根本不成立。报私仇（情仇、杀父之仇）、争霸、争"校园小霸王"均可能构成本罪，唯独不能是报公仇（如以聚众斗殴方式解决与别国的争端）。

* **主体范围**

    * 首要分子：在整个聚众斗殴过程中起组织、策划、指挥作用的人员。

    * 积极参加者：除首要分子以外，其他积极参加斗殴活动的人员。

    * 一般参加者不够格，但绝不是没事——聚众斗殴中把人打成轻伤的，按其实际行为定故意伤害罪。

    * 本罪属于必要共犯，分则已独立规定法定刑，不再讨论从犯问题，直接按本罪规定处罚。

* **聚众与斗殴的两个连续行为**

    * 聚众指纠集三人以上。汉字"重"上面一个人、下面两个人，凑成三个，就是记号。

    * "重"的关键限定：不要求每一个人都达到刑事责任年龄、具备刑事责任能力。两人带着一群精神病人去聚众斗殴仍可构成，对二人即可认定。

    * 不要求双方都在三人以上：一方带三人殴打对方单独一人，仍可构成聚众斗殴罪。也不要求双方都有首要分子。

    * 欠缺聚众、仅实施斗殴的不构成本罪：五人聚餐时临时起意把人打伤，一般定故意伤害罪或故意杀人罪。

    * 但一方已实施聚众行为、因其他情况召集的人没及时赶到斗殴现场的，该方仍构成本罪。

```text
  主观上其中一方为了显示、炫耀武力、争霸、一方抢占地盘
  客观上纠集多人结伙殴打另外一方
  ──────────────────────────────────────────────
  不论对方是否与之互殴，该方的积极参加者都可以构成本罪
```

* **主观方面**

    * 动机包括逞强斗狠、炫耀武力、称王称霸，并具有公然藐视社会公德和国家法律秩序的故意。

    * "社会公德"就是社会的主流价值观。该罪底色始终是前面三个动机，因为它是从流氓罪中分解出来的。

* **加重情形与持械的解释之争**

    * 加重情形处三年以上十年以下有期徒刑，共四种：多次聚众斗殴的；聚众斗殴人数多、规模大、社会影响恶劣的；在公共场所或者交通要道聚众斗殴，造成社会秩序严重混乱的；持械聚众斗殴的。

    * "械"是木字旁，指没有生命的东西：枪支等武器、管制刀具，也包括生活中有合法用途的器械如锄头、斧头。

    * 一般认为不包括活体动物。聚众斗殴时带几条狗过去，不能认定为持械聚众斗殴，有类推嫌疑。

| "持械"的理解 | 主张 | 含义 |
| :--- | :--- | :--- |
| 第一种观点 | 事先准备与就地取材都算持械 | 空手去的，斗殴中抢过对方刀枪棍棒继续殴打也算 |
| 第二种观点 | 只有事先准备才算持械 | 斗殴中从对方手中夺得或现场随手找到器械使用，行为人缺乏持械聚众斗殴的故意 |
| 考试口径 | 采纳第二种观点 | 就地取材不算持械聚众斗殴，必须提前准备 |

* **罪数：轻伤定本罪，重伤死亡转转化犯**

    * 聚众斗殴致人轻伤的，既构成本罪又构成故意伤害，但轻伤法定刑较轻，仍定聚众斗殴罪。

    * 出现重伤、死亡结果的，转化为故意伤害罪、故意杀人罪。例：甲、乙、丙持铁棒将丁追至河边，丁跳水逃跑后又持石头扔向丁头部致其溺水身亡，对甲等人认定故意杀人罪。

    * 转化犯的三个限制：转化也只发生在首要分子和积极参加者身上，一般参加者按其符合的犯罪构成要件定罪；查不清是谁直接造成重伤、死亡结果的，只能对首要分子认定为故意伤害、故意杀人，因为首要分子起组织、策划、指挥作用，须对整个聚众斗殴过程中出现的结果负责；转化犯是 A 罪转 B 罪，转成故意伤害致人重伤或故意杀人后就不再定聚众斗殴罪。

* **动机是把双刃剑：划出本罪与多人共同伤害的界**

```text
  动机筛查
     │
     ├─ 逞强斗狠 / 炫耀武力 / 称王称霸
     │  + 公然藐视社会公德与国家法律秩序的故意
     │        │
     │        ├─ 具备 → 进入行为与主体的下一轮筛查
     │        └─ 不具备 → 多人施暴：故意伤害（罪）/ 故意杀人（罪）
     ▼
  行为筛查：聚众 + 斗殴
     │
     ├─ 欠缺聚众（临时起意群殴）→ 故意伤害（罪）/ 故意杀人（罪）
     ├─ 齐备但小弟未到现场     → 仍成立本罪
     └─ 齐备                   → 进入主体筛查
     ▼
  主体筛查
     │
     ├─ 一般参加者 → 不构成本罪，另按其实际构成的罪名处理
     └─ 首要分子 / 积极参加者 → 进入结果筛查
     ▼
  结果筛查
     │
     ├─ 轻伤         → 仍定聚众斗殴罪
     └─ 重伤、死亡   → 转化为故意伤害罪 / 故意杀人罪（不并罚）
                        查不清具体行为人 → 由首要分子承担
```

    * 甲因乙与自己的妻子有染，纠集三人将乙打伤。动机不是逞强斗狠、炫耀武力、称王称霸，不构成聚众斗殴罪，认定故意伤害罪。

    * 张三怀疑妻子与李四有奸情，带几个兄弟把李四打伤。他没有公然藐视社会公德的意图，恰是在"维护社会公德"，不构成聚众斗殴罪。

    > **易错点**：带人多不等于聚众斗殴，动机才是分水岭。带人过去动手只能满足"聚众 + 斗殴"的行为要件，得先过了动机这一关。

## 寻衅滋事罪

* **寻衅滋事罪**

    > **定义**：行为人为寻求刺激、发泄情绪、逞强耍横等无事生非，进行扰乱破坏，情节恶劣。

    * 客体：公共秩序。主体：一般主体，可为单个人或二人以上。主观方面：故意，具有寻求精神刺激的动机。

    * 立法明文规定客观行为只有四个点——人物地地方的地：第一、二点对"人"，第三点对"物"，第四点是特定的"场所"。

* **四种客观行为**

    * 对人（其一）：追逐、拦截他人，情节恶劣。

    * 对人（其二）：辱骂、恐吓他人，情节恶劣。行为链通常是从追逐到拦截再到辱骂，不顺从就恐吓。

    * 对人（其三）：随意殴打他人，情节恶劣。这是最常见的情形，即无事生非、事出无因。

    * 对物：强拿硬要、任意损毁、占用公私财物，情节恶劣（情节严重）。

    * 对场所：在公共场所起哄闹事，造成公共场所秩序严重混乱。司法解释列举的公共场所为车站、码头、机场、商场、公园或其他公共场所。因产妇不符合剖宫产条件，丈夫家在医院大闹、推搡医务人员，造成就医秩序严重混乱的，也可构成本罪。

```text
  追逐 → 拦截（挡住去路，不让走）→ 开口辱骂 → 恐吓
                                            │
                                     恐吓仍无效
                                            │
                                            ▼
                                  随意殴打他人（情节恶劣）
                                            │
                                            ▼
                                  事出无因，找乐子、发泄情绪
```

* **"随意"的含义**

    * 随意殴打他人指出于耍威风、取乐等目的，无故无理殴打他人。

    * "随意"指不受限制、任凭自己的意思、随心所欲，对法律和社会生活共同准则毫无顾忌。

    * 例：小花见某人长得特别像前男友，二话不说把脸抓破——对方没有任何过错，殴打理由仅仅是长相，这正是"随意"。

* **三种最常见的情形**

    * 无事生非：为了寻求刺激、发泄情绪、逞强耍横，无事生非，扰乱破坏，情节恶劣。

    * 借故生非（小题大做）：因日常生活中的偶发矛盾纠纷借故生非，但矛盾是由被害人故意，或者被害人对矛盾激化负有主要责任的除外。例：被踩了皮鞋后揪住不放，逼对方下跪舔鞋上的脏东西，对方不从即予殴打。

    * 累教不改：因婚恋家庭、邻里、债务等纠纷实施殴打、辱骂、恐吓他人或者损毁、占用他人财物，一般不定寻衅滋事；但经有关部门批评制止或者处理处罚后，处罚表明事情已经了结，仍然继续实施前款行为的，后续行为认定为寻衅滋事罪。

    > **结论**：婚恋、家庭、邻里、债务纠纷这类事出有因的行为一般不定寻衅滋事，只有经批评制止或处罚后仍然继续的后续行为才转为寻衅滋事。

* **与其他罪一律从一重**

| 本罪类型 | 可能同时构成的其他罪 |
| :--- | :--- |
| 随意殴打他人 | 故意伤害罪、故意杀人罪 |
| 追逐、拦截、辱骂他人 | 侮辱罪 |
| 强拿硬要、任意损毁、占用公私财物 | 抢劫罪、抢夺罪、敲诈勒索罪、故意毁坏财物罪 |

    * 司法解释明文规定：既构成寻衅滋事又构成其他罪的，一律从一重。

    * 量刑落点：寻衅滋事把人打成轻伤的仍定本罪——本罪比故意伤害轻伤要重；把人家打成重伤或者活活打死的，定故意伤害罪、故意杀人罪。

    > **易错点**：公然追逐、拦截女性可以构成寻衅滋事罪，但不能构成强制猥亵、侮辱罪——拦住女性而未动手，一般不侵害其性权利。

* **虚假信息与网络空间**

    * 虚假信息类罪名按三级递进处理。看到"公共秩序严重混乱"这一题眼，就要想到寻衅滋事罪。

    * 利用信息网络辱骂、恐吓他人，情节恶劣，破坏社会秩序的，构成寻衅滋事罪；编造虚假信息，或者明知是编造的虚假信息而在信息网络上散布，或者组织、指使人员在信息网络上散布、起哄闹事，造成公共秩序严重混乱的，构成寻衅滋事罪。

    * 该项司法解释把网络空间解释为本罪规定的"公共场所"。研考认为这是扩大解释，也有部分学者认为是类推，一般认为扩大解释更妥当。

    * 真实案例：吉林某地地震期间，江苏傅某在微博上公然辱骂东北同胞并逐条回复评论引发网民报警，东北三省警情汇集后转交江苏警方，傅某被抓获，认定为寻衅滋事罪。

* **两个特别的入罪场景**

    * 已满 16 周岁不满 18 周岁的人，出于以大欺小、以强凌弱或者寻求精神刺激，随意殴打其他未成年人；多次对其他未成年人强拿硬要、任意损毁公私财物，扰乱学校及其他公共场所秩序，情节严重的。

    * 在预防、控制突发性传染病疫情等灾害期间，强拿硬要、任意损毁、占用公私财物，或者在公共场所起哄闹事，造成公共场所秩序严重混乱的。

* **与聚众斗殴罪的分野**

| 比较项 | 聚众斗殴罪 | 寻衅滋事罪 |
| :--- | :--- | :--- |
| 共犯形态 | 必要共犯，仅首要分子和积极参加者 | 任意共犯，单个人或二人以上均可 |
| 人数要求 | 需纠集三人以上 | 无人数限制 |
| 起因 | 事出有因：争霸、报私仇或者其他不正当目的 | 事出无因：寻求刺激、发泄情绪、逞强耍横 |
| 主观故意 | 公然藐视社会公德和国家法律秩序 | 同样具有这种性质 |

    * 相同点：两罪都有公然藐视社会公德和法律秩序的故意，因为都是从流氓罪中分解出来的。

    * 关键在"事出无因"：因宅基地纠纷将邻居家的电视机砸毁，事出有因，充其量定故意毁坏财物罪；因感情纠纷随意殴打路人，路人是无关第三人，情节恶劣，定寻衅滋事罪；因债务纠纷率众拿走债务人的财物，事出有因，不定寻衅滋事；因医患纠纷将主治医师困在办公室，可定非法拘禁，事出有因，不定寻衅滋事。

## 催收非法债务罪

* **催收非法债务罪**

    > **定义**：使用暴力、胁迫、限制人身自由、侵入住宅、恐吓、跟踪、骚扰等非法手段，催收高利放贷等产生的非法债务，情节严重。

    * 客体：社会公共秩序，还包括他人的人身权、财产权。主体：一般主体。主观方面：故意。

    * 本质是"两个非法"：非法手段加非法债务。口诀是"暴力侵入、恐吓他人"。

```text
  暴力侵入 ← 使用暴力、胁迫方法 / 限制人身自由 / 侵入他人住宅
  恐吓他人 ← 恐吓 / 跟踪 / 骚扰他人

  用这些手段，催收高利放贷等产生的非法债务，情节严重
                          ↓
                    催收非法债务罪
```

* **非法债务的范围**

    * 指法律不予保护的债务，不仅限于高利贷，还包括赌债、风流债（嫖娼之后不付钱形成的债务）。

| 手段 | 债务 | 是否构成本罪 | 实际处理 |
| :--- | :--- | :--- | :--- |
| 非法手段 | 非法债务 | 构成 | 催收非法债务罪（情节严重） |
| 非法手段 | 合法债务 | 不构成 | 按实际行为定故意伤害、非法拘禁等罪 |
| 合法手段 | 非法债务 | 不构成 | 一般定不了罪 |
| 合法手段 | 合法债务 | 不构成 | 无罪 |

    * 岳鹏欠 10 万元到期不还（合法债务），以"打断你的腿"方式催收，真打断只能定故意伤害，拘禁只能定非法拘禁。

    * 岳鹏欠 10 万元赌债（非法债务），只打电话催收（合法手段），不构成本罪。

    * 债务必须客观存在。小流氓以刀相胁凭空捏造债务，声称"你欠我 5 万"骗得 5 万元的，双方之间客观上不存在债权债务关系，构成抢劫罪。

    * 对照：甲为向乙催收赌债持刀将乙刺成轻微伤，非法手段加非法债务，构成本罪；甲为向乙索要合法借款非法剥夺乙自由的，借款是合法债务，只定非法拘禁罪。

* **罪数与唯一的争议点**

    * 犯本罪同时构成其他犯罪的，从一重罪处罚。如李四欠赌债不还，张三逼债将李四打成重伤，既构成本罪又构成故意伤害致人重伤，想象竞合从一重定故意伤害致人重伤。

    * 争议点：本罪与非法拘禁罪的关系。用拘禁手段催收非法债务时，是本罪优先适用还是两罪从一重处罚，存在理论争议。

    * 现行有效的司法解释规定：为索取债务非法拘禁、扣押他人的，定非法拘禁罪，且该"债务"既包括正当债务也包括不当债务。这是针对单纯索取型非法拘禁的解释，并没有回答两罪同时构成怎么办。

    > **提示**：目前司法解释没有规定，权威判例尚未出现，理论上没有主流观点。

## 组织领导参加黑社会性质组织罪

* **组织领导参加黑社会性质组织罪**

    > **定义**：组织领导、参加黑社会性质组织的行为。

    * 客体：正常的经济社会生活秩序，直接来自刑法条文的表达。

    * 主体：一般主体。组织者、领导者、参加者都构成本罪，参加者既包括积极参加者也包括一般参加者——这一点与聚众斗殴罪不同。

    * 必要共犯：黑社会性质组织本身就是犯罪集团，分则已独立规定法定刑，不再适用总则的从犯、胁从犯规定。

    * 主观方面：故意。行为方式有组织、领导、参加三种。

* **黑社会性质组织的四个特征**

    * 归纳为"有人、有钱、有手段、有影响"，与总则中犯罪集团的特征重合，因为黑组织是犯罪集团的一种类型。

| 特征 | 法条要求 |
| :--- | :--- |
| 有人 | 形成较稳定的犯罪组织，人数较多，有明确的组织者、领导者，骨干成员基本固定 |
| 有钱 | 有组织地通过违法犯罪活动或者其他手段获取经济利益，具有一定的经济实力，以支持该组织的活动 |
| 有手段 | 以暴力、威胁或者其他手段，有组织地多次进行违法犯罪活动，为非作恶，欺压残害群众 |
| 有影响 | 通过实施违法犯罪活动，或者利用国家工作人员的包庇、纵容，称霸一方，在一定区域或行业内形成非法控制或者重大影响，严重破坏经济社会生活秩序 |

* **恶势力：黑组织的雏形**

    > **定义**：经常纠集在一起，以暴力、威胁等手段，在一定区域、行业内多次实施违法犯罪活动，为非作恶，扰乱经济社会生活秩序，造成较为恶劣的社会影响，但尚未形成黑社会性质组织的犯罪团伙。

```text
        恶势力（黑组织的雏形）
        ├─ 经常纠集在一起，三人以上
        ├─ 以暴力、威胁等手段
        ├─ 在一定区域或行业内多次实施违法犯罪活动
        ├─ 造成较为恶劣的社会影响
        └─ 尚未形成黑社会性质组织的犯罪团伙
                          │
                          │ 继续做大：
                          │ 有组织地敛财 + 常态化暴力
                          │ + 称霸一方 + 形成非法控制
                          ▼
        黑社会性质组织：有人 + 有钱 + 有手段 + 有影响
```

* **犯罪形态与罪数**

    * 行为犯：只要有组织行为、领导行为、参加行为，加入进去即成立既遂。

    * 犯本罪之后又实施杀人、绑架、爆炸的，实行数罪并罚。

    * 对组织的领导者按黑组织所犯的全部罪行处罚，不是按集团成员所犯的全部罪行处罚；对参加者按其所参与的全部犯罪处罚。

    * 罪与非罪的第一条边界：参加黑社会性质组织而没有实施违法犯罪活动的，或者受蒙蔽、胁迫参加黑组织、情节轻微的，可以不作为犯罪处理。

    * 第二条边界，与组织领导、参加恐怖组织罪的区别在于目的不同：恐怖组织具有政治目的，本罪具有经济目的。

## 传授犯罪方法罪

* **传授犯罪方法罪**

    > **定义**：故意使用各种方法向他人讲解、教授犯罪方法的行为。

    * 客体：正常的社会治安管理秩序。主体：年满 16 周岁。主观方面：故意。

    * 法定刑最重，最高刑是无期徒刑。

    * 开锁师傅拒绝把开锁方法教给他人的理由即在于此：开锁、开保险柜的方法有朝一日可能被用于犯罪，会在社会上制造不稳定因素，妨碍正常的社会治安管理秩序。

* **客观方面的三个要素**

    * 行为是"传授"，方式在所不问：口头、书面、画连环画都行，公开传授可以，秘密传授也行。

    * 必须传授"犯罪方法"，范围较大：实施犯罪的一切经验、技巧、手段，甚至包括反侦查、逃避审判、预备犯罪、犯罪后逃匿、销毁罪证的方法。只要和犯罪有关的方法都可以，但不包括一般的违法行为——如工程师将嫖娼的方法告诉他人，嫖娼本身不是犯罪，不构成本罪。

    * 传授对象在所不问、没有限制：把开锁、开保险柜的方法告诉一个 12 岁的孩子也构成本罪。本罪惩罚的是传授这一行为，不要求双方构成共犯。

    * 传授的犯罪方法限于实施直接故意犯罪的方法：间接故意是放任结果、不需要提前准备方法，过失犯罪更不可能。

* **行为犯**

    * 只要传授行为实施到一定程度即构成既遂，学生有没有学会在所不问，传授行为实施完毕即既遂。

    * 正在传授、尚未讲解完毕即被抓的，完全可能构成本罪的未遂。

* **与教唆犯的六个区分点**

| 区分点 | 传授犯罪方法罪 | 教唆犯 |
| :--- | :--- | :--- |
| 犯罪客体 | 社会治安管理秩序 | 没有固定客体，依所教唆的内容确定 |
| 对象 | 不要求达到刑事责任年龄、具备刑事责任能力 | 原则上要求被教唆者达到特定年龄、具备责任能力 |
| 犯罪行为 | 向他人传授犯罪方法 | 使他人产生犯罪决意 |
| 主体 | 年满 16 周岁 | 依所教唆的犯罪确定，如普通抢劫 14 岁即可构成教唆犯 |
| 故意内容 | 有传授犯罪方法的故意 | 对所教唆的犯罪具有引起其实施的故意 |
| 定罪量刑依据 | 独立罪名，定罪量刑均按本罪法定刑 | 不是独立罪名，依所教唆的罪名决定 |

* **既教唆又传授的处理**

```text
[既教唆 + 又传授]
        │
        ├── 针对不同对象 → 教唆甲、传授乙 → 无任何关联 → 数罪并罚
        │
        └── 针对同一对象 → 教唆内容与传授内容有无牵连关系？
                                ├── 有牵连关系 → 从一重罪处罚
                                └── 无牵连关系 → 数罪并罚
```

    * 有牵连关系的例：教唆马某去抢劫，马某说不敢使用暴力也不会威胁，于是教给他用麻醉方法抢劫，传授药物剂量。传授手段是为了教唆抢劫，构成牵连，从一重处罚。

    * 无牵连的例：将抢劫方法传授给马某，又教唆马某去危险驾驶，两者无任何关联，以传授犯罪方法罪和危险驾驶罪的教唆犯数罪并罚。

    * 针对不同对象的例：教唆马某抢劫，把抢劫方法传授给某工程师，肯定并罚。

## 赌博罪

* **赌博罪**

    > **定义**：以盈利为目的，聚众赌博或者以赌博为业的行为。

    * 客体：国家对社会风尚的管理秩序。社会风尚指一定时期内国家多数国民所提倡、推崇的价值观念；赌博滋生不劳而获的心理，缺乏赌资还可能产生盗窃等边缘犯罪。

    * 主体：一般主体。主观方面：故意，且以盈利为目的。法定刑较轻，处三年以下有期徒刑。

* **两种行为方式与入罪标准**

| 聚众赌博的情形 | 入罪标准 |
| :--- | :--- |
| 组织三人以上赌博，抽头渔利 | 数额累计 5000 元以上 |
| 组织三人以上赌博，赌资数额 | 累计 5 万元以上 |
| 组织三人以上赌博，参赌人数 | 累计 20 人以上 |

    * 聚众赌博的行为人称"赌头"，即召集、纠集多人赌博。三种情形的共同点都是"组织三人以上"。

    * 抽头渔利指两种形态：自己也参赌，赌赢的人分给自己好处；本人不实际参赌，把人聚过来后提供后勤服务，从中分成。

    * 以赌博为业的行为人称"赌棍"，天天赌、年年赌，以赌博作为自己生活和挥霍的主要来源。

    > **易错点**：既没有聚众赌博也没有以赌博为业，只是偶尔参赌的，不构成本罪。过年回家赌一把不能定赌博罪。

    * 盈利目的的体现有两种：在赌博活动中赢钱；通过抽头渔利或者收取各种名义的手续费、入场费获取财物。不以盈利为目的、只是带有少量财物输赢的娱乐活动不构成本罪，如过年与七大姑八大姨打麻将赢五六十元。

* **赌博本质是射幸行为**

    * 赌博本质上是一种射幸行为，输赢具有偶然性，要看运气好坏。人为控制了输赢的结果，就不能再叫赌博了。

    * 诱骗参赌：仍定赌博罪。通过欺骗方法引诱他人参加赌博，没有改变输赢的偶然性。例：以"钱输光了我借给你、玩小一点"诱骗同学参赌，实则想玩大的且不会借钱，仍属聚众赌博。

    * 赌博诈骗：定诈骗罪。利用赌博形式设置骗局、在赌博过程中出老千，人为改变输赢的偶然性，让对方陷入认识错误并处分财产的，构成诈骗罪。

    * 赌博贿赂：表面是赌博，实质是行贿受贿。领导找下级打麻将，下级自摸不胡、把赢的牌打出去，一方故意输一方故意赢，已改变输赢的偶然性。

* **设置圈套诱骗他人参赌的司法解释**

    > **提示**：根据司法解释规定，行为人设置圈套诱骗他人参赌获取钱财，属于赌博行为，构成犯罪要定赌博罪。

    * "诱骗他人参赌"指以诱惑、欺骗等手段使他人愿意参与赌博，它本质是促使他人参与赌博的手段，并非赌博过程中的诈骗。

    * 参赌者识破骗局要求退还所输钱财，行为人使用暴力或以暴力相威胁拒绝退还的，以赌博罪从重处罚——此时虽然使用了暴力，但没有构成第二个罪，仍在赌博罪的范畴之内。

    * 使用暴力致参赌者伤害或死亡且达到轻伤以上的，是两个行为，前面构成赌博罪，后面构成故意伤害罪，数罪并罚。

    * 以非法占有为目的控制赌博输赢、结果骗取他人财物的，定诈骗罪。使用专门工具设备或者其他手段诱使他人参赌、人为控制赌局输赢的，构成诈骗罪；网上开设赌场人为控制赌局输赢或无法实现提现的，同样构成诈骗罪。

    * 姚某案：黄某伙同刘某请姚某斗地主，以欺诈手段控制打小牌致使姚某输掉现金 1 万、欠债 10 万，后又鼓动改玩"闷鸡"，仍以欺骗手段控制牌局，姚某又输 58 万。该行为已经不是赌，定诈骗罪。

* **三类关联罪名**

    * 赌博共犯：明知他人实施赌博犯罪，为其提供资金、网络费用结算等帮助的，构成相关赌博犯罪的共犯。

    * 发行彩票：未经批准擅自发行、销售彩票的，定非法经营罪，不再定赌博罪。

    * 抢劫赌资：行为人仅以其所输赌资、所赢赌债为对象实施抢劫的，不构成抢劫罪；构成其他犯罪的按其他罪处理。

## 开设赌场罪

* **开设赌场罪**

    > **定义**：为赌博提供场所、设定赌博方式、提供赌具、筹码资金等，组织赌博的行为。

    * 客体：正常的社会管理秩序。主观方面：故意，且以盈利为目的。

    * 社会危害性远大于赌博罪，最高刑可到十年。

    * "赌场"既包括开设专门用于赌博的实体场所，也包括网络赌场，甚至微信群都有可能被认定为赌场。

* **网络赌场的五种认定情形**

| 序号 | 情形 | 认定理由 |
| :--- | :--- | :--- |
| 一 | 建立赌博网站、应用程序并接受投注 | 赌博网站本身就是赌场，接受投注表明他在坐庄、是庄家 |
| 二 | 建立赌博网站、应用程序，并提供给他人组织赌博 | 该网站本身就是特定的场所 |
| 三 | 购买或者租用赌博网站、应用程序，组织参与赌博 | 相同道理 |
| 四 | 参与赌博网站、应用程序利润分成 | 参与赌场利润分成，至少是该赌场的股东 |
| 五 | 担任赌博网站、应用程序代理并接受投注 | 以代理名义坐庄 |

    * 指导案例 106 号：以盈利为目的，通过邀请人员加入微信群，利用微信群进行控制、管理，以抢红包的方式进行赌博，在一段时间内持续组织赌博的，构成开设赌场罪——群主自行设定接龙规则并有权只抢不发。

    > **提示**：提供棋牌室等娱乐场所并收取正常的场所和服务费用的，是正常经营行为，不构成本罪。

* **共同犯罪与罪数**

    * 明知他人实施开设赌场犯罪，为其提供场地、技术支持、资金支付结算等服务的，以本罪的共犯论处。

    * 为赌博犯罪提供相关帮助，同时构成非法利用信息网络罪、帮信罪的，依照处罚较重的规定定罪处罚。

    * 为实施赌博犯罪非法获取公民个人信息，同时构成侵犯公民个人信息罪的，也是从一重——聚众赌博找人、开设赌场招揽赌徒都要拿到他们的信息。

    * 为赌博犯罪提供资金、信用卡支付结算，构成赌博犯罪共犯，同时又构成非法经营、妨害信用卡管理、洗钱等相关罪的，从一重处罚。

    * 实施赌博犯罪后为强行索要赌债实施杀人、伤害、拘禁、毁坏财物、寻衅滋事，构成犯罪的数罪并罚。

* **与聚众赌博的区分**

    > **结论**：只看两个指标——第一，谁来设定赌博方式；第二，谁来坐庄。大家共同商量设定规则、通常轮流坐庄的，是聚众赌博；规则已提前设定好且由他坐庄的，是开设赌场。司法解释的区分规则共五项，重点关注"赌博方式由谁设定"和"赌博时由谁来坐庄"。

## 组织参与国境外赌博罪

* **组织参与国境外赌博罪**

    > **定义**：组织中国公民参与国境外赌博，数额巨大或者有其他严重情节。

    * 刑法修正案增设：赴国境外赌博的人越来越多，危害不限于社会治安管理秩序，还会导致资金外流，并延伸出洗钱、地下钱庄等黑灰产业。

    * 主体是一般主体——行为人是中国人还是外国人不重要，外国人组织中国公民参与国境外赌博也能构成本罪。

    * 对象是特定对象：只能组织中国公民参与国境外赌博。组织日本人参与美国赌场不构成本罪。

* **三种行为方式**

    * 直接组织，或者以旅游、公务的名义，组织中国公民赴国境外赌博。

    * 以提供赌博场所、提供赌资、设定赌博方式等，组织中国公民赴国境外赌博。

    * 利用信息网络、通讯终端等传输赌博视频数据，组织中国公民参与国境外赌博。

    * 第三种表明不要求中国公民离开国境：在境外赌场架上手机现场直播、看着直播压大压小，也属于参与国境外赌博。

    > **提示**：被组织者是否出境不影响本罪认定，既包括前往国境外的赌场参与赌博，也包括在境内通过网络电信等方式参与国境外赌博。

## 高空抛物罪

* **高空抛物罪**

    > **定义**：从建筑物或者其他高空抛掷物品，情节严重。

    * 客体：社会公共秩序，守护人民群众头顶上的安全。主体：一般主体。主观方面：故意。

    * 行为犯中的情节犯，法定刑非常轻：处一年以下有期徒刑、拘役、管制，并处或者单处罚金，甚至可能单处罚金。

* **高空、抛掷与方向**

    * "其他高空"指距离地面有一定高度的空间：建筑物（站在二楼向一楼抛一般即属刑法意义上的高空），还包括直升飞机、热气球、脚手架、井架，过山车在高处时向下扔物品也有可能构成。

    * "抛掷物品"指向外投、扔、丢，须是故意为之。物品因刮风下雨等原因从建筑物上高空坠落的，不构成本罪。

    > **易错点**：在广场上向天空抛砖头砸死人的，构成故意杀人，不构成高空抛物罪——方向反了。高空抛物是 from 高空抛下，不是抛到高空，即 "from…not to"。

* **罪数判断路径**

    * 高空抛物原则上不危害公共安全：站在十楼扔一个烟灰缸，即使砸中人也只砸一个人，不存在砸中后再反弹砸中第二个、第三个的情形，那叫蹦蹦球，不特定多数人的生命健康、重大公私财产安全无从实现。

```text
[从高空抛掷物品]
        │
        ├─ 是否危害公共安全？
        │   （下方有多人 + 连续高抛 ／ 下方有多人 + 一次抛特定物质）
        │        │
        │        ├─ 是 → 想象竞合从一重 → 以危险方法危害公共安全罪
        │        └─ 否
        │
        └─ 是否造成严重后果？
                 │
                 ├─ 否 → 高空抛物罪
                 └─ 是 → 对结果故意 → 与故意杀人 / 故意伤害 / 故意毁坏财物
                 │             想象竞合，从一重 → 定故意犯罪
                 │       对结果过失 → 与过失致人死亡 / 过失致人重伤
                 │             想象竞合，从一重 → 定过失犯罪
```

* **危害公共安全的两个限定条件**

    * 下方有多人加连续高空抛物：长春案周某因厌世仇视社会，预谋从高层多次投掷物品危害地面不特定人员，六天内先后向地面投掷两桶 5L 装矿泉水、三罐未开封可乐、八块砖头，砸中楼下小吃街三名食客及摊主，致一死一伤。楼下小吃街摊主、食客众多、人来人往，连续抛物必然危害不特定多数人，最高法以以危险方法危害公共安全罪核准其死刑。

    * 下方有多人加一次抛特定物质：张三因楼下广场舞噪音扰民，买好多硫酸倒入大盆，待跳舞的大妈大爷到齐后端盆天女散花般泼下，无辜者被灼伤。硫酸一旦进眼睛有可能导致双目失明，危险达到与放火、决水、爆炸、投放危险物质相当的程度，一次实施有可能造成多人严重后果。

    * 入库案例：甲在小区五层阳台先后将摔坏的床头柜上的 11 块木板（共 9.3kg）抛向楼下人行道，只构成高空抛物罪。人行道客观上没有很多人在活动，不能危害不特定多数人。关键区别不在于是否造成严重后果，而在于下方客观上是否有很多人在活动。

    > **结论**：下方有多人是一个必备要件。下方有多人时还要么连续高抛、要么一次抛特定物质，才能定以危险方法危害公共安全罪。下方没人，或者人虽多但只扔一个烟灰缸，都不危害公共安全。

* **未危害公共安全时的罪名**

    * 没有危害公共安全也没有造成严重后果的，定高空抛物罪。如站在八楼朝窗下扔了一个烟灰缸，没有砸中任何人。

    * 造成严重后果且对结果是故意的，构成故意杀人、故意伤害或故意毁坏财物罪，与本罪想象竞合从一重。例：小花见前男友站在楼下，抱起大榴莲瞄准其头部抛下当场砸死。

    * 造成严重后果且对结果是过失的，构成过失致人死亡、过失致人重伤罪，想象竞合从一重。例：某人确认楼下无人后扔下一包含碎玻璃的生活垃圾，恰有小孩跑出被砸死，属于构成要件行为的类型化原理，砸死人的概率较低。

    * 明知楼下有人故意抛一把菜刀致人死亡的，构成高空抛物罪与故意杀人罪的想象竞合，从一重定故意杀人罪；对死亡结果至少是间接故意。不构成以危险方法危害公共安全罪，因为一把菜刀通常只能针对下面的一个人。
