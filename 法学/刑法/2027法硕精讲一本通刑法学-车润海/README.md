# 2027 法硕《精讲一本通》刑法学（车润海）

众合车润海老师的法硕刑法学精讲。课程从刑法的性质、目的与基本原则出发，沿「总论—分论」主线逐层推进：先打通犯罪构成、正当化事由、犯罪停止形态、共同犯罪与罪数形态等总论体系，再按章节逐罪名精讲危害公共安全、破坏市场秩序、侵犯人身权利、侵犯财产、妨害社会管理秩序、贪污贿赂与渎职各罪，兼顾法条记忆与案例分析训练。

- **原视频**：https://www.bilibili.com/video/BV1ZqPNzTEss — Bilibili，BV1ZqPNzTEss
- **122 集**，已产出 26 册模块全书、46 篇复习笔记、129 份逐字稿

## 怎么学

- **总论先行** → 模块 01~02 讲刑法的性质、目的、解释方法与效力范围，是全课的底层框架
- **构成体系** → 模块 03~06 打通犯罪概念、客观构成要件、犯罪主体与主观方面，务必按「客体—客观—主体—主观」四层反复过
- **阻却与形态** → 模块 07~10 覆盖正当防卫、紧急避险、犯罪预备未遂中止、共同犯罪与罪数形态
- **责任与刑罚** → 模块 11~13 讲刑事责任、量刑原则情节，以及数罪并罚、缓刑与刑罚执行
- **分论攻坚** → 模块 14~26 按章节逐罪名推进，配合案例练习巩固罪名界分
- **考前速查** → `notes/` 下的笔记按罪名归类，适合最后冲刺
