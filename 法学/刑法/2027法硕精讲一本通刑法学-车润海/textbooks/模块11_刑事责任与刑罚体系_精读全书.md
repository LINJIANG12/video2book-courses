## 有罪必有责，有责未必受罚
> 对应块：BLK55 | 覆盖分集：P55 | 块标题（分集名）：《第12章：刑事责任》

进入总则的第三个板块，我们讨论**刑事责任**。

先说小提醒的第一点，这一句是整章的钥匙：**有罪必有责，有责可免刑**。

前半句"有罪必有责"，指的是理论上只要有罪，就应当承担刑事责任。但请注意后半句——承担了刑事责任，**并不等于一定要被判刑**。我们既有定罪判刑，也有定罪免刑。前面讲犯罪中止的时候说过：中止犯没有造成损害的，应当免除处罚；造成损害的，应当减轻处罚。举个完整的例子，张三构成犯罪中止且没有造成损害，那就应当免除处罚；这里的"免除处罚"指的是**免除刑罚处罚**，也就是定罪免刑。

所以你看，即使构成了犯罪，也有可能实际上不被判处刑罚。构成犯罪却真的没判，是"有罪必有责"；有罪有责却免了刑，是"有责可免刑"。这两句话合起来，才是这一章真正的气质。

这一章整体来讲比较抽象，但抽象不等于不重要——它考的是体系感，不是细节。整章我们要过六大块：刑事责任的概念与特征、刑事责任在刑法中的地位、**刑事责任与刑罚的关系**、刑事责任的解决方式、刑事责任的根据。其中"根据"比较简单，就几句话。真正要花力气的是"与刑罚的关系"和"解决方式"，这是本章为数不多的两块硬骨头，也是我们一轮课必须拿下的部分。

先做个预告，等我们走到章节末尾再回来看：

- 第一个重点：刑事责任和刑罚的关系——三点区别、三点联系；
- 第二个重点：刑事责任的解决方式——四种。

一轮课掌握这些就够，背诵课我会带着你们把所有问题一网打尽。刑法的确不好背，但我们是有方法的，可以把整个刑法背得相对理想。

### 刑事责任是什么：五种学说的名字，和我们自己下的定义

在开始之前，先要明确一个问题：刑事责任到底是什么？

#### 五种学说：只要记住名字

在中外刑法理论里，关于刑事责任是什么，一共五种观点。法学专业的同学要关注它们的名字，因为论述题可能会让你谈：

| 序号 | 学说名称 | 关键词 |
| :--- | :--- | :--- |
| 一 | 法律责任说 | 责任 |
| 二 | 法律后果说 | 后果 |
| 三 | 否定评价说 | 评价 |
| 四 | 刑事义务说 | 义务 |
| 五 | 刑事负担说 | 负担 |

怎么记？把五个关键词圈出来——**责任、后果、评价、义务、负担**——从五倒着数回一到五，就得到一句口诀：

> **负担义务，评价后果，责任。**

负担就是刑事负担说，义务就是刑事义务说，评价就是否定评价说，后果是法律后果说，责任是法律责任说。这五个名字你只要关注一下就行，具体内容等到背诵阶段我会告诉你们怎么创建一个模板，到时候照着背就行。

> **提示**：为什么这里不展开讲五种学说的内容？因为我国刑法理论的态度很明确——**这五种学说都没有道理，或者说都有缺陷、都有问题**。所以我们不需要在课堂上去复述它们各自的论证脉络，抓住名字即可。你只要理解这个"都不行"的结论从何而来，后面的定义才是顺理成章的。

有了这个提示，你再看定义就顺了：既然中外五种学说从不同角度都有各自的毛病，那怎么办？我们国家就得专门给刑事责任下一个定义。所以考试分析里才有这么一段提示：

> 上述学说都从不同侧面揭示了刑事责任的特征和内容，但从表述科学性来看，也都有不同程度的缺陷，所以我国刑法理论对刑事责任的概念有着不同的定义。

#### 长句怎么拆：先抓主体结构

我们来看这个定义：刑事责任是指……

先问三个问题，从最外层往里剥。

**第一，谁来承担？** 当然是行为人承担。主体是"行为人"，所以先记住主体结构。

**第二，凭什么承担？** 因为犯罪行为。

**第三，怎么承担？** 由代表国家的司法机关（检察院检察官代表国家提起公诉），根据刑事法律来追究。

**第四，承担的内容是什么？** 是对该行为所作的否定评价，以及对行为人的谴责。

> **易错点**：这里要特别小心——**法律评价的是人的行为，不是人的思想**。行为无罪不等于思想无罪，我们评价的对象自始至终是"该行为"。

把这四问串起来：

> **定义**：刑事责任，是指行为人因其犯罪行为应当承受的、由代表国家的司法机关根据刑事法律对该行为所作的否定评价和对行为人进行谴责的**可能性**。

这里还有一个技术性的提醒，别小看它。过去考试分析写的是"责任"，现在改成了"**可能性**"。这个"可能性"三个字很关键，它呼应了本章开头的"有责可免刑"——承担刑事责任是一种可能性，具体承担到什么程度、由谁在什么环节落地，要看后面怎么解决。

怎么记这么长的一句？我教你们一个和英语学习打通的方法。英语里有"长难句"，处理办法是**先记主谓宾，再去挂定状补**——定语、状语、补语如果比较长，还可能形成定语从句、状语从句。汉语的语法结构其实是相通的，刑事责任这个定义就是典型的一句汉语长难句。

所以第一步，先死死抓住主体结构：**行为人 + 应当承受的**。记住这个壳子，剩下的细节都是往里填的补充成分。抓住主体结构之后，紧跟着讨论补充细节——为何承担、怎么承担、什么内容，一层层往里塞。

讲到这儿，你把这个定义默写出来，把"责任"两个字替换成新版的"可能性"，就搞定了。

#### 四项特征：非法必严

概念讲完，讲特征。一共四项，给个口诀：**非法必严**。

| 口诀 | 特征 | 为什么 |
| :--- | :--- | :--- |
| 非 | 非难性与谴责性 | 非难就是对行为的否定评价：宣告你这个行为是不好的、是个犯罪行为 |
| 法 | 社会性与法律性 | 犯罪是刑事责任的前提，而犯罪的本质特征是严重的社会危害性 |
| 必 | 必然性与平等性 | 有罪必有责，构成犯罪就应当承担，没有例外，一视同仁 |
| 严 | 严厉性与专属性 | 严厉到可以剥夺人的生命，正因为严厉，不能对大多数人使用 |

把这四行拆开说透。

**非难性与谴责性。** 非难性，其实就是对行为的否定评价。什么叫"非难"？就是宣告你这个行为是不好的、是个犯罪行为，我们要对它进行否定评价。谴责性则是针对行为人本人的责难。

**社会性与法律性。** 这两个词一出来，你会不会想到 CCTV-12 那个频道——**社会与法**，这名字起得真是太好了，社会性、法律性。为什么有社会性？因为犯罪是刑事责任的前提，构成犯罪才能承担刑事责任；而犯罪的本质特征就是严重的社会危害性——犯罪都具有社会性，那么作为它的法律后果，刑事责任当然一定具有社会性。为什么又有法律性？因为刑事责任要不要承担、怎么去承担，那肯定要有法律的明文规定——罪刑法定。

**必然性与平等性。** 有罪必有责，构成犯罪就应当承担刑事责任，没有例外。任何人都一样，法律面前人人平等，刑法适用人人平等，这本身就是刑法适用平等原则的体现。要是对所有人都一视同仁，那不就是平等吗？

**严厉性与专属性。** 刑事责任甚至可以剥夺人的生命，它很严厉；正因为很严厉，它就不能对大多数人使用，所以它具有**专属性**——只能针对犯罪人适用，让犯罪人来承担。

"非法必严"四个字，对应"非难性与谴责性、社会性与法律性、必然性与平等性、严厉性与专属性"，特征这块就结束了。

### 刑事责任的地位：立法上在前，司法上在后

概念和特征讲完，接着讲地位。地位分两点讲：**在立法中的地位**，和**在理论中的地位**。

这一块整体没有那么重要，大致看一看、记一记就行，但里面有一个特别值得琢磨的角度差别，我给你展开讲透。

#### 在刑事立法中的地位

从我国刑事立法来看，刑事责任占据着重要地位，这一点有三个表现。

**第一，刑法条文中多次提到"刑事责任"。** 的确有。比如罪责刑相适应原则里，刑罚的轻重应当与犯罪分子所犯罪行和承担的刑事责任相适应。再比如分则第 347 条的走私、贩卖、运输、制造毒品罪，这条法条我们分则带大家看过：无论数量多少，都应当追究刑事责任、予以刑事处罚。条文里反复出现，地位当然重要。

**第二，总则第二章把"犯罪与刑事责任"作为第一节的标题。** 这是直接用一节的标题把二者并列挂上去的。

**第三，我们还规定了罪责刑相适应原则。** 这条原则意味着，刑事责任在立法上被提到了和"罪行""刑罚"**并列的地位**。

三点合起来，就是"在立法中的体现"，了解即可。

#### 在刑法理论中的地位：三种学说

理论上对刑事责任的地位有三种说法，依次是**基础理论说**、**罪责平行说**、**罪责刑相适应说**。这三种学说对刑事责任地位的判断是**依次下降**的。

**基础理论说**认为，刑事责任在价值功能上具有基础理论的意义，是"老大"。它认为犯罪论、刑罚论和罪刑各论（罪刑各论就是刑法分则的规定）都只不过是**刑事责任理论的具体化**；因此要从体系上赋予刑事责任作为刑法学基本原理的地位，并把它放在犯罪论之前。

这种学说有没有道理？有，但也不多。你想象一下犯罪和刑事责任是什么关系——先有谁先有犯罪？站在我们司法实务的角度看，你审理一个案子，肯定是先有犯罪才有刑事责任。如果把刑事责任放在犯罪论之前，这不是本末倒置吗？这就意味着"先有儿子后有老子"。

但请注意，**它有那么一点点道理，因为角度不一样**。如果你站在立法的角度来看，它有点道理。

#### 为什么立法角度刑事责任在先

我们看看马工程教材的原文表述：**在刑事立法层面，刑事责任是第一位的。** 请注意它的前提——是立法角度。

我打个比方你立刻就懂了。抬头看我，不要看书：如果现在我们国家没有刑法典，你就是立法者，你就是"刑法之父"，让你制定一部刑法典，你会怎么想？

你脑子里第一个冒出来的念头是什么？是：**哪些行为要承担刑事责任**。你首先要想清楚哪些行为要定罪、要量刑、要处罚多重，你的大脑中首先会有一个"刑事责任"的概念。举个小例子：毒驾要不要构成犯罪？毒驾要不要承担刑事责任？你得先回答这个问题，才能往下走。

所以站在刑事立法角度，刑事责任的确是第一位的，它影响着刑法的制度设计，决定着犯罪构成和刑罚的适用。

具体流程是这样的：

> **结论**：从立法层面讲，**刑事责任观形成在前**，然后立法者在刑事责任观的指导下制定刑法、规定犯罪与刑罚。

展开说：立法者要先形成一个刑事责任观——比如刑事责任的价值目标、规制范围、适用模式；然后在这个观念的指导下，确定具体的犯罪观和刑罚观。我要先想哪些行为有必要处罚、有必要让他承担刑事责任，在这种理念的指导下，需要承担刑事责任的我把它规定为犯罪，不需要的不规定为犯罪。

你看，**刑事责任是先行的那一步**，犯罪和刑罚是在它指导之下产生的。

#### 罪责平行说与罪责刑相适应说

**罪责平行说**认为，犯罪和刑事责任两者平行，两分天下——犯罪、刑事责任、刑罚三者是平行的。这一说的意义不大，咱们就不细说了，背诵的时候带着看一看。

**罪责刑相适应说**要特别提醒一下。为什么？因为我们总则毕竟存在罪责刑相适应原则，所以考试分析认为这种观点**更为可取**。

该说认为，犯罪、刑事责任、刑罚是**各自独立又相互联系的三个范畴**。既然罪责刑相适应，你就会发现刑事责任处在一个**中间位置**：

```text
      犯罪  ──────▶  刑事责任  ──────▶  刑罚
      前提            纽带              实现方式
```

读图：三个范畴被"刑事责任"这个中间项串了起来，它像一条**纽带**、一个**桥梁**。

纽带作用体现在四个方向上：

- **犯罪是刑事责任的前提**——有犯罪才有刑事责任；
- **刑事责任是犯罪的法律后果**——它是犯罪带来的结果；
- **刑事责任又是刑罚的前提**——承担刑事责任才能对他量刑；
- **刑罚是实现刑事责任的基本方式**。

犯罪和刑罚就这样通过"刑事责任"这个纽带联系在了一起。所以我们的刑法学体系，就应当按照**犯罪论 → 刑事责任论 → 刑罚论**的框架来建构。

> **提示**：这不就是我们目前讲课的思路吗？先讲犯罪论，然后是刑事责任论，接下来马上讲刑罚论。所以这一套说法，本身就是我们这套讲义的编排逻辑。

马工程教材的对应表述是：**从刑事司法角度来看，犯罪行为是刑事责任产生的原因**，行为是否构成犯罪决定了是否承担刑事责任，没有犯罪就没有刑事责任。这个当然如此。

> **结论**：理论上要同时盯住两个看起来有点别扭的角度——**从刑事立法角度看，刑事责任是第一位的；但从刑事司法角度看，一定是犯罪在第一位，然后是刑事责任，最后才是刑罚。**

同一个问题，两个角度，答案相反。基础理论说之所以"有那么一点点道理"，就道理在这儿。到这里，刑事责任的地位就讲完了。

### 刑事责任与刑罚：三点区别，三点联系

这是本章为数不多的重点，很重要。两者的关系是既有区别又有联系，我们先找区别。

#### 找区别，从"根"上找起

先说方法论，这一条对文科类专业（也包括刑法）非常有用：**在找区别的时候，最好是从"根"开始找。你只要找到这个根，一步一步向上推理，就会形成一个逻辑体系。**

而"根"就是**前提**。你可以设想一下：前提都不一样，性质必然不同；性质不同，那内容肯定不同。所以顺序应该是这样的：

```text
      前提不同
         │
         ▼
      性质不同
         │
         ▼
      内容不同
```

考试分析列出的三种区别（前提不同、性质不同、内容不同）**不是按这个顺序排的**，这是我调整之后的顺序，虽然内容一样。

那我们就按这个顺序往下走。

**前提不同。** 刑事责任的前提是谁？是**犯罪**。所以刑事责任因犯罪而产生，有了犯罪才有刑事责任。而刑罚的前提呢？一个人被判处 5 年有期徒刑，这是刑罚。刑罚的前提用八个字分开记：**以法院的定罪判刑宣告生效而出现**。有罪的判决、量刑的判决已经生效了，刑罚才出现。

所以：刑事责任因犯罪而产生，刑罚则以法院定罪判刑宣告生效而出现。

**性质不同。** 刑事责任的本质是一种**法律责任**。法律责任除了刑事责任以外，还有民事责任、行政责任，所以刑事责任是法律责任的一种。而刑罚呢？它是一种**制裁方法**，或者叫**强制方法**。刑罚的全称是"刑事处罚"，也有人称"刑罚处罚"，都行。除了刑罚以外，还有行政处罚、民事处罚，所以刑罚的本质是一种强制方法。

**内容不同。** 这一条最重要，下面单独展开。

#### 责任的内容三项，刑罚的内容一类

先看**刑事责任的内容**，一共三项：

第一，**刑事处罚**。比如张三构成犯罪了，最常见的就是定罪判刑——判处 5 年有期徒刑，这就是刑事处罚。

第二，**非刑罚处理方法**。也就是刑法以外的处理方法，后面会讲到，包括责令赔礼道歉、责令赔偿损失、训诫等等。

第三，**单纯的否定性法律评价**。这一项最容易被忽略。什么情况下既不判刑、也不适用非刑罚处理方法？那就只剩"单纯的宣告一下他有罪"这一件事了。举个例子：张三构成抢劫罪，中止犯罪且没有造成损害，法院怎么判决？

```text
   法槌一敲，判决如下：

   张三犯抢劫罪，但具有中止情节且未造成损害，
   因此免除刑事处罚。
```

就这么一句话。如果判决书只写到这里，意味着既没有判处刑罚，也没有适用非刑罚处理方法——这就是**单纯的否定性法律评价**。

再看**刑罚的内容**。刑罚是以**实际剥夺犯罪人的一定权益**为内容。具体分两大类：五种主刑（管制、拘役、有期徒刑、无期徒刑、死刑），四种附加刑（罚金、没收财产、剥夺政治权利、对外国人驱逐出境）。不管哪一种，它都以实际剥夺犯罪人的权益为内容——比如死刑，剥夺的是犯罪人的生命。

顺手把刑事责任的内容做个小结，按轻重排一排：

- 比较重的是**定罪判刑**，比如判处主刑、判处死刑、判处无期徒刑；
- 其次是**定罪免刑**但适用了非刑罚处理方法，比如从业禁止、训诫、责令具结悔过、责令赔礼道歉、责令赔偿损失、行政处罚、行政处分等等，后面都会讲，不着急；
- 最轻的是**单纯的否定性法律评价**，既不判刑，也不适用非刑罚处理方法。

到这里，三点区别就齐了：前提不同、性质不同、内容不同。

#### 三点联系：前提、决定、实现

区别说完说联系。大家首先想到的一定是**罪责刑相适应**：刑罚的轻重要和谁相适应？要和犯罪分子所犯罪行和承担的**刑事责任**相适应。

> **结论**：既然刑罚要和刑事责任相适应，就表明**刑事责任可以决定刑罚**。

由此推出前两点联系。

**第一，前提关系。** 刑事责任是适用刑罚的前提，没有刑事责任就不能适用刑罚。张三如果不承担刑事责任，就不可能对他适用刑罚。

**第二，决定关系。** 因为刑罚要和刑事责任相适应，所以刑事责任的大小直接决定刑罚的轻重——刑事责任大，刑罚必然重；刑事责任小，刑罚必然轻。

**第三，实现方式。** 前两点——前提关系、决定关系——都是在讨论"**刑事责任对刑罚有什么作用**"；而实现方式不一样，它是**反向**讨论的：**刑罚对刑事责任有什么意义**。

刑事责任的内容虽然有刑事处罚、非刑罚处理方法、单纯的否定性法律评价三项，但**最主要的内容还是刑罚**。一个人承担刑事责任，最常见的就是定罪判刑，也就是刑罚处罚。所以**刑事责任主要通过刑罚来实现**；非刑罚处理方法等虽然也是实现刑事责任的方式，但属于**次要的实现方式**。

> **结论**：三点区别、三点联系，这是本章的一个重点，请大家注意。

### 刑事责任的根据：一个哲学根据，一个法学根据

接下来讲根据。先看看考试分析是怎么写的——"国家基于何种前提基础决定因素追究犯罪人的刑事责任，或者犯罪人基于何种前提基础决定因素承担刑事责任"。

说实话，这句话写得真的挺要命的。翻来覆去其实就一句话：**国家凭什么追究犯罪人的刑事责任，或者说犯罪人凭什么承担刑事责任。**

理论上对刑事责任的根据还有不同的学说，这块考试分析删得差不多了，稍微了解就行：包括**犯罪构成唯一根据说、罪过说、犯罪行为说、社会危害性说**。了解即可，到背诵阶段我们再大致提一提。

#### 质与量的统一

马工程教材认为，确定刑事责任要解决**质**和**量**的问题，也就是刑事责任是质和量的统一。

- 解决**质**的问题：是否存在刑事责任；
- 解决**量**的问题：刑事责任的大小问题。

刑法规定的**犯罪构成**，既是决定刑事责任**存在与否**的法律根据，也是决定刑事责任**程度**的主要法律根据。但是只在犯罪构成之外，规定的量刑情节、刑罚执行制度，也都是决定刑事责任程度的重要法律根据。

这一段不用死磕，记一句话就够了：

> **结论**：**符合犯罪构成才能成立犯罪，成立犯罪才能承担刑事责任。**

#### 哲学根据：相对的意志自由

我们本土理论认为，刑事责任的根据有两大块，这个要稍微注意。

第一个根据是**哲学根据**。根据马克思主义哲学的观点：一个人干了坏事，为什么要承担刑事责任？因为他在实施犯罪行为时所具有的**相对的意志自由**。

意志自由指什么？指他有**辨认能力**，有**控制能力**。简而言之，他有**选择的能力**。作为一个精神正常的成年人，我可以选择去犯罪，我也可以选择不去犯罪。当我选择去犯罪的时候，我就要对自己的选择承担责任。

对比一下就明白边界在哪：

- **为什么三岁的孩子干了坏事不承担刑事责任？** 因为他没有辨认能力，没有控制能力，他没有相对的意志自由，他连分辨是非的能力都没有。
- **为什么精神病人干了坏事不承担刑事责任？** 因为精神病人有精神障碍，他要么没有辨认能力，要么没有控制能力，他没有选择的余地，同样没有相对的意志自由。

所以马克思主义的观点就是：**一个人一旦具有相对的意志自由，那就意味着他具备了刑事责任能力**，当然要为自己的选择承担刑事责任。

#### 法学根据：一个设定，两个确定

第二个是**法学根据**。法学根据指的是：从法律制度上，行为人承担、或者国家追究其刑事责任的决定因素。

从法律制度上看，它的决定因素是什么？分**立法、司法两个步骤**。要让一个人承担刑事责任，要满足两件事——**有法可依**，还有**有法必依**。

**有法可依**，指的是在立法上你要做出规定。立法上都没做出规定，你怎么能让行为人承担刑事责任？

**有法必依**，指的是在立法上作出规定以后，在司法层面必须按照立法的规定，准确地适用法律、准确地查明事实。也就是我们熟悉的**以事实为根据，以法律为准绳**。

我给你讲个段子，你就明白为什么司法层面这两个都不能少。你是个法官，开庭审理的时候，你发现"哎哟，这被告人看着好眼熟"——再一看，**马峰**！你天哪，那不是我读研、考研时候的那个宪法老师吗？他竟然成为了我的被告人。你作为法官，是不是内心会一阵窃喜？

但是你调查清楚之后会发现：天哪，马峰干的事，法律上没有规定，刑法中没有相关规定。那怎么办？你只能**宣告马峰无罪**，你不能追究他的刑事责任，否则你就是**徇私枉法**。所以，立法层面必须有法可依——没有规定，法官再怎么，也不能给你造一个罪名出来。

司法层面呢？你要不要查明事实？当然要；要不要准确适用法律？也要。一句话：立法层面要有法可依，司法层面要以事实为根据、以法律为准绳。

所以法学根据可以简化成一个记忆口诀：

> **结论**：一个设定，两个确定。**一个设定**是立法层面设定刑事责任的根据，**两个确定**是司法层面——以事实为根据，确定刑事责任的**事实根据**；以法律为准绳，确定刑事责任的**法律根据**。

再举个例子把"两个确定"走一遍。还是马峰，这回他犯了强制猥亵、侮辱罪，成了你的被告人。你开庭审理，查明事实，意识到马峰犯罪了，说：马峰，你所犯之罪是强制猥亵、侮辱罪，我国刑法第 237 条有明文规定。那这时候你追究他的刑事责任就**有法可依**了，因为立法上已经设定了刑事责任的根据。

那这个时候你作为司法工作人员、作为法官，只要做两件事：

- **查明事实**：马峰有没有强制猥亵的事实？有。这就是确定刑事责任的**事实根据**；
- **确定法律**：对应着适用哪个罪？强制猥亵、侮辱罪，第 237 条。这就是确定刑事责任的**法律根据**。

至此，一个设定、两个确定，法学根据就走通了。哲学根据一块、法学根据一块，刑事责任的根据作为一个比较偏的问题，到此结束。

### 刑事责任的解决方式：四项

最后一个板块，也是本章的第二个重点：**刑事责任的解决方式**。

先明确它是什么。刑事责任最终怎么去承担？张三犯了罪要承担刑事责任，怎么样才算让他承担了刑事责任？所以刑事责任的解决方式，又称**刑事责任的实现方式**，指的是刑事责任可以通过哪些方法来实际承担。

理论上对这块还有不同的学说。这些学说**都不要管它**，原因是三条：

- 第一，选择题通常不会这样考；
- 第二，主观题通常是法学专业的论述题；
- 第三，对我们做选择题没有影响。

到背诵阶段我们再去管它。现在讲得再清楚、再细致，到背诵阶段你们肯定会忘，索性一网打尽。

所以这个板块的重点就是表格里的内容：刑事责任到底怎么去解决，具体包括四项。

| 解决方式 | 含义 | 例子 |
| :--- | :--- | :--- |
| 定罪判刑 | 定罪＝对犯罪人作出有罪判决；判刑＝宣告适用相应的刑罚 | 判处 5 年有期徒刑 |
| 定罪免刑 | 对犯罪人作出有罪判决，同时决定免除刑罚处罚 | 中止犯没有造成损害，应当免除处罚 |
| 消灭处理 | 行为已成立犯罪且应当负刑事责任，但因阻却刑事责任事由的存在使责任归于消灭，国家不再追究、行为人也不再承担 | 超过追诉时效 |
| 转移处理 | 责任不由本国司法机关直接处理，而通过外交途径解决 | 享有外交特权和豁免权的外国人的刑事责任 |

四项稍微记一记。

**定罪判刑**自己都可以下个概念：定罪是对犯罪人作出有罪判决，判刑是宣告适用相应的刑罚。比如判处 5 年有期徒刑，这就是定罪判刑。

**定罪免刑**是对犯罪人作出有罪判决，同时决定免除刑罚处罚。比如中止犯没有造成损害，应当免除处罚——注意，这里的"免除处罚"就是免除刑罚处罚。

**第三种也是解决方式，叫消灭处理。** 行为人的行为已经成立犯罪且应当负刑事责任，但是由于**法律规定的阻却刑事责任事由**的存在，使刑事责任归于消灭，国家不再追究行为人的刑事责任，行为人也不再承担刑事责任。

抬头看屏幕——它的意思是我们后面会讲的**追诉时效**。比如张三犯了罪，但是很多年都没被发现，被发现的时候已经超过了追诉时效。张三犯罪了吗？的确如此，所以其行为成立犯罪且应当负刑事责任；但是由于超过了法律规定的追诉时效，就不能再追究他的责任了。国家不再追究，行为人也不再承担——这就是消灭处理。

**最后是转移处理。** 这个在总则绪论就讲过了：享有外交特权和豁免权的外国人的刑事责任，通过外交途径解决。言下之意是不是"不解决"？不是，是**通过外交途径解决**，所以它同样是一种解决方式。这一点要知道。

到这里，刑事责任作为一个比较偏的板块就讲完了。两大重点：**刑事责任与刑罚的关系（三点联系、三点区别）**，以及**刑事责任的解决方式**。

### 本讲提到的题目

我们在最后还剩一道真题，请各位看一看。

**题目**：下列情形中追究的是行为人承担刑事责任的有（　）。

- A. 甲被判犯盗窃罪，处 5 年有期徒刑
- B. 乙被判犯侵犯通信自由罪，责令赔礼道歉
- C. 丙被判犯重婚罪，免予刑事处罚
- D. 丁被判犯诈骗罪，责令具结悔过

**答案**：ABCD（四项全选）。

**解析**：

A 项，甲被判犯盗窃罪并处 5 年有期徒刑，这是标准的**定罪判刑**，属于刑事处罚，是刑事责任最主要的内容，当然承担刑事责任。

C 项，丙被判犯重婚罪、免予刑事处罚，这是**定罪免刑**。这里最容易掉坑：请注意，"免除刑罚处罚"不等于"不承担刑事责任"，判了罪就已经在承担刑事责任了，只是没有实际判处刑罚——这正是本章开头"有责可免刑"那句话的落地。

B 项与 D 项，乙被判犯侵犯通信自由罪并责令赔礼道歉、丁被判犯诈骗罪并责令具结悔过，这两项判了罪、又免了刑罚，但同时适用了**非刑罚处理方法**。责令赔礼道歉、责令具结悔过，指的就是非刑罚处理方法。还记得刑事责任的三项内容吗？刑罚处罚、非刑罚处理方法、单纯的否定性法律评价——B 和 D 落在第二项上。

所以这四项全部都在承担刑事责任的范围内，一道不落。

**引申提示**：这个题目里个别专业名词不懂是很正常的——什么叫责令赔礼道歉、什么叫责令具结悔过，下一个板块进入刑罚论就会讲。现在只要抓住"**刑事责任有三项内容**"这一条，就足以判断了。

## 你是法官：刑罚的概念、目的与种类
> 对应块：BLK56 | 覆盖分集：P56 | 块标题（分集名）：《第13章 第01-02节：刑罚的概念和目的、种类》

刑法论是总则的最后一个板块了。难度系数不大，细节问题较多——刚开始做题正确率可能没那么高，但从某种意义上来讲，这块主要是偏背诵的：**你能记得住，就能做对题**。所以我们先看框架，再逐个板块拆解。

整个刑罚论围绕着刑罚展开，具体而言是围绕着**量刑**展开的。要以法官为中心，以时间推进为序列进行讨论。各位，你就是法官——想一想整个庭审的流程。

### 你是法官：刑罚论要解决的六个问题

如果你是法官，第一步让你去对被告人量刑，你总归要知道**量何种刑**，所以第一个问题是量何种刑——可以量主刑，可以量附加刑。当我们知道可以量何种刑，第二步就要去讨论**量刑情节**：哪些情节会影响量刑轻重。量刑情节包括从严情节和从宽情节这两种，从严情节比如累犯应当从重处罚，从宽情节比如自首、立功、坦白。

知道了量何种刑，也知道了量刑情节，下一步就可以开始量刑了。一罪一罚没什么好说的；数罪并罚，犯数罪如何去并罚？他的刑期又怎么算？这就是第三个问题。

第四，并罚以后要公开宣告——你要法槌一敲，"现判决如下"。宣告之后，如果不实际执行、所犯之罪比较轻，我们可以对他设置考验期，宣告缓刑；如果实际执行，那就交付羁押，交付给执行机关去执行。但一个人在服刑过程中表现比较好的话，可以对他适用一些制度给他奖励，比如减刑、假释。

最后，一个人犯罪之后我们不能无期限地追诉，所以我们规定了特殊的**刑罚消灭**——追诉时效和赦免。

```text
  起点：这个被告人为什么要被判刑？
        │
        ├── ① 量何种刑 ── 主刑 / 附加刑
        │
        ├── ② 量刑情节 ── 从严（累犯从重）
        │                  从宽（自首、立功、坦白）
        │
        ├── ③ 开始量刑 ── 一罪一罚；数罪并罚
        │                  （数罪如何并、刑期怎么算）
        │
        ├── ④ 并罚后公开宣告 ──「法槌一敲：现判决如下」
        │        │
        │        ├── 不实际执行 → 宣告缓刑、设置考验期
        │        └── 实际执行   → 交付执行机关羁押执行
        │                                  │
        │                                  └── 表现好 → 减刑、假释
        │
        └── ⑤ 犯罪之后不能无限期追诉
               → 特殊的刑罚消灭：追诉时效、赦免
```

这就是刑罚论要讨论的六大问题。

> **提示**：当然不可能一上来就直接讲"量何种刑"。正常情况是先做铺垫，引申出量和种刑；再做铺垫，引申出量刑情节。所以整个刑法论要做**两次铺垫**，然后才能进入它的具体内容。第一个铺垫就是这一讲要解决的：刑罚到底是什么、目的是什么、有什么功能。

### 第一个铺垫：刑罚是什么

这个板块主要讨论刑罚到底是什么意思、有哪些特征、目的又是什么，都是一些铺垫性的问题、几个共性问题。

#### 从概念拆出六个特征

先看概念。**罪刑法定**，刑罚也必须有刑法明文规定。所以从概念上看：

> **定义**：刑罚是指刑法明文规定的，由国家审判机关依法对犯罪人适用的，剥夺或限制其某项权益的，最严厉的法律制裁方法。

这个概念理解即可，但每一个词都要能拆开说：

- **刑法明文规定**——这是基于罪刑法定原则的要求；
- **国家审判机关**——谁才有权利去量刑？当然是法院；
- **依法**——要依据他的实体法（刑法），也要依据他的程序法（刑事诉讼法）；
- **对犯罪人适用**——这是适用的对象；
- **剥夺或限制其某种权益**——这是具体内容。不管是主刑还是附加刑，都是如此。

我们前面讲刑事责任和刑罚之间的关系，从区别上看是前提不同、性质不同、内容不同。这里正好接得上：从内容上看，刑罚必然以实际剥夺犯罪分子的某项权益为内容；从性质上看，刑罚是法律制裁方法。

正是从这个概念出发，可以拆解出六个特征——**前五项直接来自概念，第六项要格外关注**：

| 特征 | 拆解来源 |
|---|---|
| ① 刑罚的种类和适用标准，必须以刑法明文规定为根据 | 刑法明文规定 |
| ② 适用的主体只能是国家审判机关 | 国家审判机关 |
| ③ 必须依照刑事诉讼法的规定 | 依法 |
| ④ 适用的对象是犯罪人 | 对犯罪人适用 |
| ⑤ 以限制或剥夺犯罪分子权益为内容的最严厉的法律制裁方法 | 剥夺或限制其某种权益 |
| ⑥ 刑罚的执行由国家强制力作保障 | 概念之外，单独记一记 |

第六点为什么单独记？举个例子：法院判处张三死刑，张三怎么不反抗？因为他没有能力反抗。所以刑罚的执行是以国家强制力做保障的。

#### 刑罚和其他法律制裁方法差在哪

既然刑罚是"法律制裁方法"之一，那就得先抬头看一下我们**整个法律制裁体系**：

- **民事制裁**：赔礼道歉、赔偿损失、恢复原状等等；
- **刑事制裁**：刑法判处主刑、附加刑；
- **行政制裁**：比如马峰去嫖娼被行政拘留十天；工程师闯红灯被罚款 20 元——这也是行政制裁、也是行政处罚；
- **经济制裁**：主要发生在商事领域，比如违反了反不正当竞争法被罚款 500 万；
- **对妨害诉讼的强制措施**：法庭开庭审理的时候，旁听席上坐着张三，法官正在审理案子，张三在旁听席大喊大叫、大哭大闹，此时法官就可以要求法警将他强制带离出庭，符合条件的甚至可以对他进行相当程度的处罚。

所以这就意味着，**刑罚其实只是诸多制裁手段中的一种**。由此需要对比刑罚和其他法律制裁方法的区别。这个区别主要是背诵，从理解角度其实不难。

| 区别维度 | 刑罚 | 其他法律制裁方法 |
|---|---|---|
| 适用的根据和程序 | 判刑必须以刑法为根据，并依照刑事诉讼法规定的刑事诉讼程序进行 | 分别以民法、经济法、行政法等实体法为根据，依照民事诉讼法等相关程序的规定进行 |
| 适用的机关 | 只能由国家审判机关的**刑事审判部门**适用，比如法院中的刑一庭、刑二庭 | 民事制裁、经济制裁对应国家审判机关的民事审判、经济审判等部门；行政制裁由行政机关依法适用 |
| 适用的对象 | 只能适用于**犯罪**的人 | 只能适用于违法、但不构成犯罪的人 |
| 严厉程度 | 最严厉，可以剥夺人的生命、自由、财产、资格 | 不能剥夺人的生命，通常也不能剥夺人的自由，即使剥夺期限也较为短暂 |
| 法律后果 | 被适用刑罚的人如果重新犯罪，可能会构成**累犯** | 以后又实施了犯罪，不可能构成累犯 |

这个口诀大家一起来看，就记住这一句话：**"法院依法判处累犯马峰死刑。"**

```text
  法院依法判处累犯马峰死刑
    │      │     │      │   │
    │      │     │      │   └── 死刑 ──→ 第四点：严厉程度不同
    │      │     │      └────── 累犯 ──→ 第五点：法律后果不同
    │      │     └───────────── 马峰 ──→ 第三点：适用的对象不同
    │      └─────────────────── 依法判处 → 第一点：适用的根据和程序不同
    └────────────────────────── 法院 ──→ 第二点：适用的机关不同
```

> **提示**：现在一本通阶段只要理解它、记住这几个标题就够了；到我们背诵阶段，才需要对这些细节问题进行整合。没到那个时候，现在就带你们背，到时候还是会忘的。

### 刑罚的目的：报应与预防

这个板块大家重在理解，有可能在选择题中直接考察。

我们前面讲过，犯罪目的指的是对结果的追求——行为人希望通过实施某种犯罪行为，实现某种犯罪结果的心理态度。**刑罚的目的同样是对结果的追求**：具体而言，指的是国家制定刑法（立法），以及通过对犯罪分子适用、执行刑法（司法、执法）所期望达到的结果。

比如马峰犯罪了，被判处死刑，请问刑罚的目的到底在思考什么角度、什么问题？那就是——为什么对马峰判处死刑？对他判处死刑能够起到什么效果？这就是刑罚目的要解决的问题。

理论上关于刑罚目的有两项内容：**刑罚报应观念**和**预防犯罪的目的**。

#### 报应观念：为报应而报应

刑罚报应观念非常之古老，大家听过的那些——以牙还牙、以眼还眼、杀人偿命、欠债还钱——就是典型的报应观念。它解释了刑罚的根据，也就是国家为什么对犯罪人动用刑罚的原因之一。核心词当然是"**报应**"。

> **定义**：刑罚报应观念认为，刑罚是对犯罪的公平报应；在对犯罪人判处刑罚的时候，不应当抱有防止犯罪等目的性考虑。

简单讲这种理念非常之纯粹：为什么对犯罪人判处刑罚？就是为了报应，就是为了报复他。就是因为行为人犯了罪，除此之外**没有其他任何理由**。它体现的就是以牙还牙、以眼还眼、同态复仇。这种观念在我们国家是非常古老的，这个点我就不做过多的铺垫了，大家肯定能听得懂。

#### 预防犯罪的目的：为不再犯罪而判处

预防犯罪的目的主张：适用刑罚除了是对罪犯进行报应以外，还应当具有预防再次犯罪的目的。

为什么刑罚可以预防再次犯罪？因为刑罚在广义上是出于防止犯罪的目的而判处的一种预防、教育手段——认为判处刑罚就是对犯罪人进行教育、对他进行预防。

对照着记最好记：

```text
   报应观念：  因为犯罪  ──→  所以要判处刑罚
   预防目的：  为了不再犯罪 ─→  所以要判处刑罚
```

刑罚目的所预防的犯罪，**既包括已然之罪，也包括未然之罪**。已然之罪就是针对已经犯罪的人去预防，未然之罪就是针对尚未犯罪的人也要去预防。由此，根据预防对象不同，预防犯罪的目的就可以分成**特殊预防**和**一般预防**。

##### 特殊预防：让已经犯罪的人不再犯罪

特殊预防指的是通过适用刑罚，预防**犯罪人重新犯罪**。这句话要圈起来，三个要点：针对的是**已经犯罪的人**；预防他**再次犯罪**；再次犯**什么罪没有限制**。

比如张三因盗窃罪被判处 5 年有期徒刑，服刑结束之后：

- 第一，他在刑罚执行期间已经对他进行了教育改造，教育他成为一个守法的公民，因此能够从某种意义上起到预防犯罪的作用；
- 第二，他会有一种**心理上的强制**。如果张三再想犯罪，他就会想一想自己先前那 5 年的经历——服刑的经理可不好受啊。所以这也能遏制犯罪人内心的犯罪冲动。

这里再把机理补全一层。特殊预防主要是从**两个方面**来实现"预防再次犯罪"的目的的：**一是剥夺，二是改造**。

**改造**，是教育改造犯罪人弃恶扬善、成为守法的公民。在刑罚执行期间，对罪犯是要进行劳动改造、进行教育的。像我们国家规定的各个刑种，除了死刑是剥夺生命的以外，大多数刑罚都采取强制劳动改造，都有劳动改造。马克思主义的观点认为，**劳动可以改造一个人**。

> **结论**：教育改造犯罪人成为守法的公民，是我国刑法特殊预防的主要内容。如果考到选择题——我国刑法特殊预防或者特别预防的主要内容是什么——就是这句话。

**剥夺**，是剥夺犯罪分子再次犯罪的能力，使之不能危害社会。怎么剥夺？

- 最狠的当然是**生命刑**，比如直接对张三判处死刑，永久性地消灭他的再犯罪能力；
- 其次是**自由刑**，比如判处无期徒刑、判处 10 年有期徒刑，这样的话将罪犯和社会隔离开来，同时在服刑期间对其进行教育改造；
- 还可以判处**财产刑**，比如对一些经济类、财产类犯罪适用财产刑，剥夺其重新犯罪的物质基础，使其得不偿失、不敢不愿再去犯罪。比如他通过犯罪挣了 5000，然后我们通过对其惩罚罚他 5 万，他就知道了：通过犯罪去谋取非法利益不划算，他以后也不愿意这样去做；
- 除此之外还有**资格刑**，比如剥夺他的政治权利，还有对外国人驱逐出境——外国人在中国犯罪了，直接把他赶出去，剥夺他再次入境的机会。

##### 一般预防：盯住这三类人

一般预防指的是通过对犯罪人适用刑罚，预防**尚未犯罪的人**实施犯罪。

是不是所有尚未犯罪的人都是一般预防的对象？当然不是。要重点关注三组名词：

**第一，危险分子**，指具有犯罪危险的人。比如游离于违法和犯罪边缘的人，有了几次违法行为，虽然还没有构成犯罪，但违法和犯罪有时候就一线之隔，他们非常容易构成犯罪，成为一般预防关注的重点。

**第二，不稳定分子**，指具有某种犯罪倾向的人。这种人通常是法制观念淡薄、自制力低，容易受到犯罪的诱惑。有种现象老百姓称之为"街溜子"：平常没啥事，辍学以后十七八岁，穿个紧身裤、穿着豆豆鞋，周围聚集着一群这样的人，没事的时候一起起哄，见到女生吹口哨，做什么事说做就做，甚至发誓赌咒谁不去。这种人那就是不稳定分子，他是有犯罪的倾向、有犯罪的可能，因此要成为预防的重点关注。

**第三，具有私力复仇倾向的被害人及其家属**。比如李四的儿子被张三打伤了，李四听完之后很生气，要替儿子报仇，抡起刀就去找张三。这时候虽然还没有构成犯罪，但是他一定是有严重的犯罪倾向或者犯罪的危险，针对此类人同样也成为了一般预防的对象。

> **易错点**：切记，你**不能说人民群众是一般预防的对象**——那就犯了政治错误了。人民群众是我们**依靠**的对象，而不是我们**预防**的对象。这三类人即使没有实施犯罪，但他是有犯罪的危险，因此才成为我们预防的对象。

##### 两者关系：不可偏废

特殊预防和一般预防的关系肯定是紧密结合、相辅相成的。我们经常讲，刑事司法活动应当做到法律效果和社会效果的统一，要体现一般预防和特别预防。

以后我讲课会有一些"马言马语"，谈到类似问题通常表述为：**如车之两轮、鸟之双翼、马之四蹄，不可偏废**。所以对任何一个人适用刑罚，都包含着特别预防和一般预防的目的。到这一步就够了。

#### 一桩旧案里的两种理念

不同国家的立法理念可能不同：有的国家在立法时更偏重刑罚报应观念，有的国家更偏重预防犯罪的目的。偏重不同，就会导致它的**法定刑设置**明显有所区别。

比如我们对哪些犯罪通常会判处财产刑——判处罚金、判处没收财产？各位翻翻刑法典就会发现，通常都是那些**贪利性犯罪**，什么叫贪利性？就是通过犯罪挣钱。既然你想通过犯罪挣钱，那我就剥夺你的财产，这就是对你的报应。所以在经济财产类犯罪、在贪利型犯罪中规定这些财产刑，主要体现的就是刑罚报应的观点。

那到底以谁为主，没有对错之分，因为它其实受一个国家的历史文化、民众的思维等多个维度的影响。这里有一桩旧案可以看看。

**2000 年，南京。**一位名叫浦方的德国人，受梅赛德斯奔驰公司委派到中国，参与一项中外合资项目。他和一双儿女租住在南京的一套别墅里。某天晚上浦方被声音惊醒，出门查看，发现四名年轻人正在盗窃。正常情况下小偷发现主人出来应该选择逃跑，但不知道什么原因——有可能是语言不通、沟通不畅——他们大喊大叫，结果四名年轻人一哄而上。浦方的女儿年仅 15 岁，儿子 13 岁。当时影响非常之大，称之为"南京灭门惨案"。

案件发生之后，按照中国当时的司法判例，这个案子几乎没有任何争议，肯定会判处死刑、立即执行。四名年轻人也很快被抓，经查最年轻的一名刚成年 18 周岁。如何处理这四名凶手，引起了很多人的关注。

出人意料的是，**浦方的亲友竟然寄给中国法院一封信**，信的大致内容是：我们痛恨这些凶手，他们从我们身边夺走了我们的挚爱，给我们造成了难以弥补的伤痛；但作为基督徒，我们认为只有上帝才能够赐予或者剥夺一人的生命，因此请求中国法院不要判处他们死刑，判处他们无期徒刑，即可让他们在监狱忏悔自己的余生吧。

当有人在新闻发布会上提问说中国会如何处理这四名凶手的时候，发言人回答：我们一定会依法处理——最终判处四名凶手死刑、立即执行。这四名年轻人来自江苏苏北，来自贫困地区、贫困家庭。

案件本身到此已经结束了。但是浦方的亲戚朋友同事为了纪念浦方，成立了**浦方协会**，又称浦方基金会。他们认为犯罪它不光是一个个人的问题，更是家庭教育、社会教育的缺失——因此预防犯罪就要消灭产生犯罪的土壤，而只有教育、尤其是良好的教育，才能够改变或者成就一个人的一生。然后就在外国群体中开始募集一些资金，去资助苏北地区的一些贫困家庭，让他们的孩子去完成基本的甚至良好的教育。后来这个项目又覆盖到了安徽的部分地区。浦方协会、浦方基金会至今还存在，前前后后应该资助了 1000 多户贫困的家庭。

> **提示**：这个案子给我们最大的启发是什么？每一个国家基于自己的传承、历史文化、民众思维，可能注重的点是不同的：有的国家更偏重预防犯罪的目的，有的国家更偏重刑罚报应的观念。**没有对错之分**，只是基于文化、历史原因不同而产生的细微差别。

所以希望大家在关注这个案情本身的同时，如果以后从事法律工作，即使面对着犯罪人，我们在惩罚他的同时，还是要多考虑一下怎么样能够预防类似现象的出现。当然这是个多维度、甚至跨学科才能够完成的一个工作；大家在读研期间要是有这样一个能力，可以多思考一下。

### 刑罚的功能：三个维度看

概念先放着：**刑罚的功能**是指国家正确制定和执行刑法，对社会个体以及整体所产生和可能产生的积极作用。这个功能其实类似于"机能"一样——它有可能发挥哪些积极的作用。概念本身不要记，主要记的是下面三个，怕的就是考超纲的题：一个选择题问"刑罚有什么功能"，你能把它选出来。

| 面向谁 | 功能 |
|---|---|
| 对犯罪人 | **惩罚** + **改造**。判处 5 年有期徒刑，这是惩罚；服刑期间会对他进行教育改造、强制劳动改造，这是改造功能。通过惩罚改造，使其成为一个守法的公民 |
| 对被害人 | **安抚**。比如李四的家人被杀死，法院对凶手判处死刑，这对被害人或者被害人的家人确有安抚的功能 |
| 对社会 | **威慑** + **教育鼓励**。威慑功能就是预防一些不稳定分子、危险分子实施犯罪；教育鼓励功能就是鼓励公民可以见义勇为 |

就注意这几个措辞就可以了。

### 第二个铺垫：量刑量何种刑

铺垫了这几个问题之后，就可以引申出我们量刑到底可以量何种刑。刑罚的概念和特征、刑罚与其他法律制裁方法的区别、刑罚的目的、刑罚的功能——到这一步，我们知道了刑罚到底是什么、刑罚到底有什么作用，那下一步当然就要讨论**刑罚的种类和体系**。

按照现行刑法规定，刑罚可以分为主刑和附加刑。

- **主刑有五种**：管、拘、有、无、死——管制、拘役、有期徒刑、无期徒刑、死刑；
- **附加刑有四种**：罚、没、剥、驱——罚金、没收财产、剥夺政治权利、驱逐出境。

所以我们国家总共是有**九种刑罚方法**。

#### 两套分类：一一对应

刑罚的种类从学理上分类和从立法上分类，其实是有对应关系的。

```text
        剥夺或限制犯罪分子的权益（既包括权利，也包括利益）
        │
        ├── 学理上的分类 ─────────────────────
        │     生命刑 ── 死刑
        │     自由刑 ── 无期徒刑、有期徒刑、拘役、管制
        │     财产刑 ── 罚金、没收财产
        │     资格刑 ── 如剥夺政治权利
        │
        └── 立法上的分类 ─────────────────────
              主刑   ── 只能单独适用，不能附加使用
                       管制、拘役、有期徒刑、无期徒刑、死刑
              附加刑 ── 既能独立适用，也能附加使用
                       罚金、没收财产、剥夺政治权利、驱逐出境
```

**学理上**的分类标准，考试分析原文写的是"以剥夺犯罪分子的权利和利益的性质为标准"，写得有点啰嗦了——那就是**以剥夺或者限制犯罪分子的权益为标准**。"权益"这两个字既包括权利，也包括利益。

**立法上**的分类标准是：某种刑罚方法是只能单独适用，还是可以附加适用。所以主刑只能单独使用，不能附加使用；而附加刑既能独立适用，也能附加使用。因此从适用范围的角度来看，**附加刑比主刑适用的范围还要大**——因为主刑只能独立使用，不能附加使用，而附加刑两种都可以。

#### 非刑罚处理方法：六种

如果定罪判刑，判处刑罚；如果定罪免刑，则有可能适用**非刑罚处理方法**。而非刑罚处理方法的适用范围包含两种可能：

| 情形 | 非刑罚处理方法 |
|---|---|
| 在定罪判刑的基础上附带适用 | 判处赔偿经济损失、从业禁止（只有 2 种） |
| 定罪免刑 | 训诫、责令具结悔过、责令赔礼道歉、责令赔偿损失、行政处罚、行政处分（共 6 种） |

注意这只是个框架，每一个细节问题后面都会讲。

#### 刑法体系与它的特点

**刑法体系**指的是刑法规定的、按照一定次序排列的各种刑罚方法的总和。注意"各种刑罚方法"就是刚刚讲的这九种——它是指这九种的**总和**，不是指一种或两种刑罚方法。

由此可以推出刑法体系的三项内容：

- 第一，它是根据概念拆解出来的，是各种刑罚方法的总和；
- 第二，它必须有刑法规定——当然了，罪刑法定必然要求有刑法规定；
- 第三，它是按照一定次序将各种刑罚编排起来，各种刑罚轻重相互衔接，构成一个统一的整体。比如以主刑为例，我们的排列顺序是管制、拘役、有期徒刑、无期徒刑、死刑，从轻到重依次排序，相互衔接，构成了一个统一的整体。

紧接着是**我国刑法体系的特点**，这三项了解就行了：

- 体系完整、结构严谨；
- 方法人道、内容合理；
- 宽严相济、目标统一。

第三个更偏向的是刑事政策的表述，我就不多说了。

到这一步，刑罚的种类分两种，这是重点：一个是学理上的分类——生命刑、自由刑、财产刑、资格刑；第二个是立法中的分类——主刑和附加刑，主刑有五种，附加刑有四种。所以**量刑量何种刑，就是量这九种：五种主刑、四种附加刑**，我们都要分门别类地进行讨论：先从主刑开始，讨论管制一直到死刑；再从附加刑开始讨论。

讨论完量刑量何种刑之后，然后再去分析**非刑罚处理方法**——因为有定罪判刑，还有定罪免刑，定罪免刑完全有可能适用非刑罚处理方法。

> **承前启后**：上一节讲完「你是法官：刑罚的概念、目的与种类」，下一节接着讲「管制到死刑：五种主刑的内容、期限、义务与权利」。

## 管制到死刑：五种主刑的内容、期限、义务与权利
> 对应块：BLK57 | 覆盖分集：P57 | 块标题（分集名）：《第13章 第03节：主刑》

主刑这块我们正式开始。为什么单独拎出来讲？因为它是刑罚体系里最好用、也最容易出细节题的一块——概念不难，难的是那些零碎的期限数字和执行规则。做选择题的时候，概念你往往会，真正能把题做对的是细节。所以我今天讲主刑，会花不少时间在"记细节"上。

先把整个图景摊开。

### 主刑的体系与解题框架

主刑分成两大块：**生命刑**和**自由刑**。生命刑只有一个，就是死刑，而且死刑有两种执行方法，要么死刑立即执行，要么死刑缓期两年执行。自由刑包括管制、拘役、有期徒刑和无期徒刑。

这里有个分界一定要记牢：**管制只是限制自由，没有剥夺自由**；剥夺自由的是拘役、有期徒刑、无期徒刑这三种。

```text
                    主刑（只能独立适用，不能附加适用）
                                  │
            ┌─────────────────────┴─────────────────────┐
            │                                           │
         生命刑                                    自由刑
       （剥夺生命）                          （限制或剥夺人身自由）
            │                                           │
      ┌─────┴─────┐                                     │
      │           │                      ┌──────────────┼──────────────┐
   死刑立即执行  死刑缓期二年执行          │              │              │
    （死立执）      （死缓）           管制          拘役         有期徒刑      无期徒刑
                                          │              │              │              │
                                      限制自由      剥夺自由      剥夺自由     剥夺终身自由
                                     不关押     短期，就近执行   监狱执行      监狱执行
```

> **注意**：主刑是**只能独立使用、不能附加适用**的刑罚方法。这一点务必注意——它和后面讲的附加刑正好是反着的，附加刑是可以附加适用的。

再往下，还有一个框架性的东西，比主刑的分类本身更重要。我们讨论任何一个刑种，通常是从四个维度展开的：

- 第一，这个刑种的**内容**是什么；
- 第二，如果有刑期，必须关注它的**期限**；
- 第三，犯罪人要承担什么**义务**；
- 第四，他享有什么**权利**。

```text
                 任何一个刑种 = 四个维度
                          │
        ┌─────────────────┼─────────────────┐
        │                 │                 │
      内容              期限              义务 / 权利
   到底剥夺或         有没有期限、      要承担什么、
   限制了什么         多长、怎么算      还剩下什么
```

这四个维度我等下每一个刑种都会用一遍，各位心里先挂着这根线。

还有一个下定义时的通用提醒：五种主刑加四种附加刑，一共是九种刑罚方法。不管你给谁下定义，**落脚点都是"刑罚方法"**。这个"刑罚方法"很关键——它是一个刑种，不是执行方式，更不是矫正措施。后面讲到社区矫正的时候，我会专门回来敲一下这一点。

好，下面从管制开始。

### 管制：唯一不剥夺自由的刑种

#### 法条三款拆开看

我们回归到书本，先看法条。

**第一款是期限**：管制的期限为三个月以上、二年以下。所以一个人被判处管制，他的刑期最低三个月，最高只能到两年。

**第二款是禁止令**：判处管制，可以根据犯罪情况同时禁止——同时禁止意味着它是**和管制的刑期一起开始执行**的，禁止犯罪分子在执行期间从事特定活动（简称"事"）、进入特定区域场所（简称"地"）、接触特定的人（简称"人"）。所以禁止令包括**人、地、事**三个方面。

**第三款是执行**：对判处管制的犯罪分子依法实行社区矫正。如果违反禁止令的规定，由公安机关根据治安管理处罚法的规定进行处罚。

> **定义**：**管制**是对罪犯不予关押，但限制其一定人身自由，依法实行社区矫正的刑罚方法。

它在我国是比较轻的刑罚方法，而且只属于限制自由刑——犯罪人**仍然有一部分人身自由**，只不过对其自由有所限制而已。

#### 内容：不关押，但要守规矩

回到概念本身，管制的第一个特征是**对犯罪分子不予关押**；第二个特征是**限制一定人身自由**，他要遵守各种规定。既然是限制自由，就不可能限制一辈子，总归有期限，所以我们待会儿要讨论期限问题；第三个特征是**可以适用禁止令**，根据犯罪分子所犯之罪的具体情况，禁止其在管制执行期间从事特定活动（事）、进入特定区域场所（地）、接触特定的人（人）。

举个具体例子：张三被判处管制，根据情况我们可以对他使用禁止令，禁止他去接触被害人——你不能离被害人那么近，因为我们担心他对被害人进行报复。这种情况在实践中确实有可能出现。

#### 期限：323，以及 1 比 2 的折抵

管制的期限为三个月以上、二年以下，**数罪并罚最高不能超过三年**。

有的同学会问：为啥是三个月以上，不是四个月以上？

> **提示**：没有法理依据，就是参照世界各国的通行规定，认为三个月就可以了，仅此而已。

所以一个罪判管制，单罪最低三个月、最高两年；如果是 A 罪判管制、B 罪也判管制、C 罪也判管制，三个罪都被判处管制，那就要数罪并罚，数罪并罚最高也不能超过三年。管制的刑期可以简化为 **323**：三个月以上、两年以下、数罪并罚不超过三年。

期限从**判决执行之日起计算**。判决执行以前先行羁押的，**羁押一日折抵刑期两日**。

为什么羁押一日可以折抵刑期两日？这主要是我们刑事诉讼的流程决定的。我做个简单的说明：各位请看，一个刑事案件有人报案之后，公安机关决定立案，然后对犯罪人采取强制措施，可能将犯罪人拘留——叫刑事拘留。比如 4 月 1 号，张三因犯罪被刑事拘留。各位这个时候还不能说张三有罪，只能称"犯罪嫌疑人"。公安会把张三关在看守所羁押，各位注意，羁押那可是**剥夺自由**。之后公安侦查终结，把案卷移交检察院，检察院提起公诉，送到法院审判。如果认定张三有罪，判处两年管制——大家是不是发现，判处两年管制，这是他的刑期；但是张三从 4 月 1 号被羁押到 10 月 1 号判决生效，他已经被羁押了六个月，而且是被剥夺自由六个月，但他所判的管制只是**限制自由**。剥夺自由肯定比限制自由更严厉，因此我们立法上规定：剥夺自由一天，可以折抵他的刑期两天。

```text
        张三 4 月 1 日因犯罪被刑事拘留
                        │
        公安机关立案 → 采取强制措施（刑事拘留）
                        ▼
             看守所羁押（剥夺人身自由）
                        │
        侦查终结 → 案卷移交检察院 → 提起公诉 → 法院审判
                        ▼
      10 月 1 日判决生效：判处管制 2 年
                        │
        回头一算：4/1 → 10/1，羁押 6 个月
                        ▼
        羁押 6 个月 = 剥夺自由 6 个月
                        │
        但管制只是「限制自由」，剥夺 > 限制
                        ▼
        立法规定：羁押 1 日 折抵管制刑期 2 日
                        ▼
        6 × 2 = 折抵管制刑期 1 年
                        ▼
        判 2 年管制 → 实际执行 1 年
```

所以请各位注意：**判决执行以前先行羁押的，羁押一日折抵刑期两日**，也就是说剥夺自由一天要折抵管制刑期两天。

#### 权利：除了被限制的，什么都没丢

被判处管制的犯罪分子，享有各种权利——被限制以外的各种权利。如果没有附加剥夺政治权利的，他依然享有政治权利。还有一条要切记：**在劳动中还要同工同酬**。

所以管制是个非常轻的主刑。

#### 社区矫正：它不是刑种，是一种执行方式

管制怎么执行？第一点，对判处管制的犯罪分子依法实行社区矫正。

什么叫社区矫正，各位抬头看我。

首先从**性质**上看，它不是刑种——我们只有五种主刑、四种附加刑，没有所谓的"社区矫正"。所以社区矫正是一种**非监禁的刑罚执行方式**。它指的是把罪犯置于社区之内，由社区矫正机构来矫正其犯罪心理和他的行为恶习。

社区矫正作为一种刑罚的执行方式，是为了让犯罪人能够重归社会，感受到这个生活的美好。大家可以设想一下，或者说有没有看过一些电影电视剧，尤其是外国的一些影片——有老外犯罪之后，胸前可能还挂个牌子，然后到社区去打扫卫生、去做好事、做义工，这种情况就是典型的社区矫正。要让他感受到人间的温暖。

其实这个有一定的道理。我拿我自己举例吧：工作平常比较忙，我有时候也会有压力，心情也会不好。怎么办呢，我有两条途径可以让自己心情好起来。第一，我会去回忆我小的时候——小时候真的好开心啊，在外婆家很开心，在自己家也很开心，那个时候也没有那么卷，压力也没那么大，天天就是玩，养成了自己的这种性格，就很开心。所以现在回忆童年，的确会让我感觉到轻松很多。有人说一个幸福愉快的童年可以治愈成年人心灵上的压力，我感觉这个是有一定道理的。

第二个，如果你真的心情不好，你去人多的地方——比如到一些大型的商超，到超市里面，你可以看一看，会发现好多人，男女老幼都有，然后看看他们买着各种东西，你会发现生活气息非常重，这个时候你的心情的确会开心一点，压力会小一点。有人说我到超市之后，为了解压，基本上都是捏别人的方便面，把方便面给他捏碎——各位，疯了，不要这样做啊，损人不利己。你到超市之后如果想买点东西，花个 100 块，可能会发现 100 块可以买好多自己喜欢吃的东西，你心情当然会好一些。所以一定要找一个能让自己开心的方式解压的渠道。

社区矫正其实就有这方面的考虑：把罪犯置于社区之内，矫正他的犯罪心理和行为恶习。

> **结论**：社区矫正只是一种**刑罚执行方式**，并不是一种新的刑种。

那对哪些犯罪人要进行社区矫正？根据社区矫正法的相关规定，四类人：管制犯、缓刑犯、假释犯、暂予监外执行的犯罪分子。

> **易错点**：切记只针对这四类人进行社区矫正，除此之外不要再拓展——管制、缓刑、假释、暂予监外执行，就这四类。

从本质上看，这四类人有个共性：**刑期还没结束，但又有人身自由**。

#### 管制的义务

被判处管制的犯罪分子在执行期间还要遵守如下规定，这是第 39 条的立法原文：

1. 遵守法律、行政法规，服从监督；
2. 未经执行机关批准，不得行使本法规定的政治权利；
3. 按照执行机关的规定报告自己的活动情况；
4. 遵守执行机关关于会客的规定；
5. 离开所居住的市、县或者迁居，应当报经执行机关批准。

这第二项我要多说一句：它指的是**被限制**了这一项政治权利。言下之意，如果经过执行机关批准，其实还是可以行使的，因此他并没有被剥夺这项权利，只是被限制了。

这五项先了解，等我们讲到缓刑的时候一块做对比，我会给个口诀，一次性把它搞定。

#### 禁止令：人、地、事，以及不可随便用的理由

禁止令是指人民法院对犯罪分子判处管制、宣告缓刑的同时（注意我们现在讲的是管制，后面会讲缓刑），针对这两类犯罪分子判令禁止其从事特定活动、进入特定区域场所、接触特定人的命令。这个**概念可以不记**，但是后面的内容要理解。

人民法院宣告禁止令，要根据犯罪分子的犯罪原因、性质、手段、悔罪表现、一贯表现，**充分考虑与犯罪分子所犯行为的关联程度**。

各位，重点。这就表明什么？**禁止令不是随便用的**，一定要考虑和它犯罪行为的关联程度。和犯罪行为有关联，我们就可以禁止。比如张三经常出入网吧，在网吧犯罪了，然后被判处管制——那进入网吧打游戏，就可能会成为他犯罪的诱因；如果被宣告管制，我们就可以对他使用禁止令，禁止他在管制执行期间进入网吧，因为它和犯罪行为有关联。就是要考虑行为的关联程度，有针对性地决定禁止在管制执行期间、缓刑考验期间从事特定活动、进入特定场所区域、接触特定的人。

而且这三项，既可以禁止其中一项，也可以三项同时禁止都行。

> **易错点**：但是一定要考虑，禁止令的内容必须和犯罪行为有关联，你才能禁止；没有关联，你就不能随便禁止。各位想想，能不能对张三宣告缓刑或判处管制，然后同时禁止他进入公共厕所、禁止他进入医院？疯了，不可能啊，这就明显违背了基本的人道主义精神。

| 简称 | 禁止的内容 |
| :--- | :--- |
| 事 | 从事特定活动 |
| 地 | 进入特定区域、场所 |
| 人 | 接触特定的人 |

接下来是一个特别值得记的细节：对**两类人**可以适用禁止令——管制犯和缓刑犯；但对**假释犯不能适用**禁止令。

原因是什么？因为禁止令是在**判决的时候**做出来的。法槌一敲，宣判如下，那就可以包含着禁止令。管制和缓刑为什么能够适用禁止令？因为发生的阶段相同，都是判决的时候做出来的。但是假释可不是——假释是犯罪人在比如监狱服刑期间，因为表现好提前释放，因此假释不是发生在判决阶段，而是发生在后面的**刑罚执行阶段**。发生的时间节点，就决定了对假释犯不能使用禁止令。书上表述也是这样：管制与缓刑都是在判决的时候作出的，禁止令也是在判决的时候做出的，时间一致，因此管制和缓刑有可能适用禁止令；但是假释是在刑罚执行过程中作出的，正因如此，它没有禁止令的问题。

#### 禁止令由谁执行、期限多长

管制的细节比较多，最后再补两点。

**执行主体**：禁止令由司法行政机关指导管理的社区矫正机构负责执行。所谓司法行政机关，指的就是司法厅、司法所。

**期限**：禁止令的期限既可以与管制执行、缓刑考验期限相同，也可以短于管制执行、缓刑考验期限。但判处管制的，禁止令不得少于三个月；宣告缓刑的，禁止令不得少于两个月。

为什么这样定？很好记——管制的刑期最低就是三个月，缓刑的考验期最低不能低于两个月，都和它们各自的底线保持一致。缓刑为什么是两个月，后面讲到缓刑的时候我们再展开。

#### 把管制按四维度收一遍

从理解角度讲，管制难吗？不难，就是细节问题比较多。但是我建议大家像这种问题，在听得懂的基础之上稍微记一下它的细节，那你做选择题一定能做得对。我问大家来回答：

- **内容**：剥夺自由吗？不剥夺。限制自由吗？限制，要遵守各种规定。
- **期限**：管制的期限多久？三个月以上、两年以下，数罪并罚不超过三年——**323**。判决宣告以前先行羁押的，羁押一日折抵刑期**两日**。
- **义务**：一、依法进行社区矫正；二、可以适用禁止令；三、遵守各种规定。
- **权利**：被限制以外的各种权利，未被附加剥夺政治权利的仍享有政治权利，劳动中同工同酬。

管制的义务那块再补两句，然后就结束管制：社区矫正是什么？是刑种吗？不是，它只是刑罚执行方式，把犯罪人置于社区之中，矫正其犯罪心理和行为恶习；对四类人适用——管制犯、缓刑犯、假释犯、暂予监外执行的犯罪分子，为什么本质都在于他们刑期没结束，但又有人身自由，所以要对他们实行社区矫正。禁止令的内容是三个关键字：**人、地、事**；由司法行政机关指导的社区矫正机构负责执行；两类人可以适用（管制犯、缓刑犯），假释犯不能，因为它不是在判决的时候做出来的；期限上，判处管制最低不能少于三个月，宣告缓刑最低不能少于两个月。

你这样梳理一遍，就会发现这些细节能记住，你就很棒了。等到后期做选择题能搞定，到后期我们背诵的时候，这些问题还都要再去重复。

### 拘役：短期剥夺自由，待遇还优于有期徒刑

拘役的法条更短。**拘役的期限为一个月以上、六个月以下**，所以拘役是个**短期自由刑**。注意他是剥夺自由，最低一个月，最高六个月。

第 43 条：被判处拘役的犯罪分子，由**公安机关就近执行**；在执行期间被判处拘役的犯罪分子，**每个月还可以回家一天到两天**；参加劳动的，**还可以酌量发给报酬**。

这足以证明它也是一个比较轻的主刑。每个月回家一天到两天——有的地方还创新了一下，这个月不回家，那下个月我让你回家两到四天，积攒这几个月不回家、回家一次，就是个国庆小长假。各位这个也挺好，是不是？

参加劳动的还可以酌量发给报酬。注意是"**酌量**"发给报酬。

第 44 条：拘役的刑期从判决执行之日起计算，判决执行以前先行羁押的，**羁押一日折抵刑期一日**。

> **易错点**：注意它和管制**不一样**哦。管制是羁押一日折抵刑期两日，而拘役是羁押一日折抵刑期一日。

为什么？因为拘役是剥夺人身自由，他后面的刑期也是剥夺自由，因此只能一比一去折抵。而管制不一样，管制前面是羁押（剥夺自由），后面判处管制（限制自由），所以剥夺自由一天可以折抵管制刑期两天。

> **定义**：**拘役**是短期剥夺人身自由、就近执行、实行劳动改造的刑罚方法。它的落脚点仍然是"刑罚方法"。

拘役的特征：第一，剥夺自由；第二，期限较为短暂，一个月以上六个月以下，注意数罪并罚的时候最高不能超过**一年**。因此管制是 **323**，拘役是 **161**——一个月以上、六个月以下、数罪并罚不能超过一年。比如犯了两个罪都被判处拘役，两个拘役并罚最高不能超过一年；三个拘役并罚也不能超过一年。第三，被判处拘役的犯罪分子在执行期间具有某些**优于有期徒刑的待遇**——的确如此，因为他每个月可以回家一天到两天，参加劳动还可以酌量发给报酬。

拘役怎么执行？由公安机关就近执行。第二点社区矫正刚才讲了好几次了，不说了。所以拘役的议题超级简单，细节问题也比较少。我问大家来回答：拘役是限制自由还是剥夺自由？剥夺。剥夺自由就要有期限，最低一个月，最高六个月，数罪并罚不超过一年，判决执行以前先行羁押的，羁押一日折抵刑期一日。搞定。

### 有期徒刑：适用范围最广的主刑

**有期徒刑**是剥夺犯罪分子一定期限的人身自由，强制其参加劳动，接受教育改造的刑罚方法。特征跟拘役的逻辑结构一样。

第一，剥夺自由。第二，有期限。注意有期徒刑的期限：基于立法规定，最低六个月——它刚好和拘役有衔接，拘役是一个月到六个月，封顶六个月（我指的是单罪，不是数罪并罚）；有期徒刑最低六个月，最高 15 年。但是数罪并罚的时候：有期徒刑总和刑期不满 35 年的，最高不超过 20 年；总和刑期在 35 年以上的，最高不超过 25 年。这个后面我们在数罪并罚这个板块都会再讲。

我们总结一个公式：**有期徒刑的刑期为六个月以上、15 年以下；数罪并罚的时候不超过 20 年或者不超过 25 年。**

这一点也是显著区别于西方一些国家的地方。大家可能看电视剧也知道，西方国家有的判 200 年监禁，就 200 年有期徒刑——疯了，那跟判无期徒刑不就一样了吗？我们国家不允许，我们国家哪怕是数罪并罚，有期徒刑最高也不能超过 25 年。当然你要说最厉害的还是我们国家，我们国家曾经对人判了 500 年。谁，各位知道吗？孙悟空啊，《西游记》里面被压在五指山下，是不是 500 年。

第三，执行机关为**监狱或其他执行场所**。第四，强制有劳动能力的罪犯参加劳动，接受教育改造。

所以有期徒刑是适用范围**最广、最主要**的主刑——管制、拘役、有期、无期、死刑这五种主刑里，适用概率最高的就是有期徒刑，我们绝大多数犯罪的规定里面都有有期徒刑。

有期徒刑的期限问题也很简单，细节问题也很少。注意"进行教育改造"：凡是有劳动能力的，都要强制其参加劳动、接受教育改造。

> **易错点**：判处拘役的罪犯参加劳动，可以获得酌量报酬；而已期徒刑**没有**这个待遇，最起码从立法规定上是没有这个待遇的。

我问一下大家来回答：第一，有期徒刑是限制自由还是剥夺自由？剥夺。第二，有期限吗？有，最低六个月，最高 15 年，数罪并罚最长不超过 25 年。第三，判决执行以前先行羁押的，羁押一日折抵刑期**一日**——反正前后都是剥夺自由，一比一折抵。第四，在什么地方执行？监狱或者其他执行场所。

### 无期徒刑：严厉程度仅次于死刑

**无期徒刑**顾名思义是剥夺犯罪分子终身自由，强制其参加劳动，接受教育改造的刑罚方法。在五种主刑中，它的严厉程度排名**第二**，仅次于死刑。

#### 四个特征

**第一，它没有刑期限制**，罪犯要被剥夺终身自由。

**第二，它不存在刑期折抵的问题**。我们前面讲管制、拘役和有期徒刑都有刑期折抵，在无期徒刑中，你可千万不能说"判决执行以前先行羁押的羁押一日折抵刑期一日"，没有这个说法。因为无期徒刑本身就没有期限，因此没有刑期折抵的问题。

**第三，非常重要——对被判处无期徒刑的犯罪分子必须剥夺政治权利终身。** 这一点一定要注意。大家哪怕看新闻，稍微留意一点都知道，判决如下：处无期徒刑，剥夺政治权利终身——**必须剥夺，终身**。

**第四，对于被判处无期徒刑的罪犯，符合条件的是可以减为有期徒刑的。** 注意：无期徒刑减为有期徒刑之后，这个有期徒刑的刑期**自裁定减刑之日起计算**。比如张三被判处无期徒刑，因为表现好被裁定减为有期徒刑，那这个有期徒刑的刑期从哪天算呢？切记，**从裁定减刑之日起计算**——法院哪一天做出裁定，就从哪一天开始算。

#### 无期徒刑与终身监禁是两回事

谈到无期徒刑，就会想到一个关联概念叫终身监禁。但是**无期徒刑不能等于终身监禁，这是两回事**。而且终身监禁只能适用于两个罪名：一个是贪污罪，一个是受贿罪，没有第三个罪名。

请看法条：犯贪污罪有第三项规定的情形，被判处死刑缓期执行的——就贪污罪被判处死缓——人民法院根据犯罪情节等情况，可以同时决定在其死刑缓期两年期满依法减为无期徒刑后**终身监禁，不得减刑、不得假释**。这表明终身监禁只是因为贪污罪被判死缓、然后减为无期徒刑之后的一种特殊执行方法。受贿罪也是如此，看第 386 条。

> **结论**：请大家务必注意，只有贪污罪、受贿罪才有可能适用终身监禁，这种制度不要再拓展了，没有第三个罪名。

两者的区别归纳为三点：

| 维度 | 无期徒刑 | 终身监禁 |
| :--- | :--- | :--- |
| 适用范围 | 可以适用于很多犯罪 | 只能适用于贪污罪、受贿罪两种犯罪 |
| 法律性质 | 独立的刑种，五大主刑之一 | 不是独立刑种，是死缓减为无期后的特殊执行措施 |
| 法律后果 | 符合条件可以减刑或假释 | 不得减刑、不得假释 |

现在这个阶段只要求理解，不要背，等我们后期背诵宝典怎么背，我们是有方法的。

#### 未成年人与无期徒刑

对未成年人不得判处死刑（在死刑那一块我们会展开讲），所以未成年人即使罪行极其严重，充其量只能判处无期徒刑。而且根据司法解释规定，对已满 14 周岁、不满 16 周岁的未成年人，**一般**不判处无期徒刑——我们前面也讲过，只是一般不判处，符合条件的依然有可能判处。这个点要注意。

无期徒刑怎么执行？它和有期徒刑一样，都是在监狱或者其他执行场所执行；凡是有劳动能力的都要参加劳动，接受教育改造。

小结一下：无期徒刑是剥夺自由；没有期限，所以不能折抵刑期；可以减刑，减为有期徒刑，有期徒刑的刑期从裁定减刑之日起计算。

### 死刑：保留死刑，坚持少杀慎杀

下面进入最重要的一个刑种——五大主刑中最重要的死刑。死刑又称生命刑或极刑，是剥夺犯罪人生命的刑罚方法，包括两种执行方法：死刑立即执行、死刑缓期执行。

我们国家对死刑的态度是：**保留死刑，但坚持少杀慎杀的刑事政策**。所以现行刑法在不少罪名中规定的还有死刑，但是在判处死刑的时候，一定要特别慎重。因此对死刑有必要进行限制。怎么去限制？从四个角度进行限制：

- 第一，限制死刑的**适用条件**；
- 第二，限制死刑的**适用对象**；
- 第三，限制死刑的**适用程序**；
- 第四，限制死刑的**执行制度**。

我们逐项讨论。

#### 适用条件：只能针对罪行极其严重

按照立法规定，**死刑只能适用于罪行极其严重的犯罪分子**。

各位，罪行极其严重，所以死刑判决书通常会有一些封顶的词汇去形容犯罪人。比如对马某判处死刑，判决书中通常有这种话："马某所犯之罪，社会危害性极为巨大，主观恶性极深，人身危险性极强。现判决如下：处死刑，剥夺政治权利终身。"——他有这种封顶的词汇。

而"罪行极其严重"指的是犯罪行为对国家和人民利益的危害特别严重、社会危害性极为巨大。因此只有对罪行极其严重的犯罪分子才能适用死刑，达不到罪行极其严重，不能适用死刑。

#### 适用对象：老少孕

三类人不适用死刑：**老、少、孕**。老年人有例外。

法条规定：**犯罪的时候不满 18 周岁的人**和**审判的时候怀孕的妇女**，不适用死刑——这个"不适用"指的是**绝对不能适用**；**审判的时候已满 75 周岁的人**，除非以特别残忍的手段致人死亡，一般也不适用死刑。

| 对象 | 时间节点 | 是否绝对禁止 |
| :--- | :--- | :--- |
| 不满 18 周岁的人 | **犯罪时** | 是 |
| 怀孕的妇女 | **审判时**（扩大解释到整个羁押期间怀过孕） | 是 |
| 已满 75 周岁的人 | **审判时** | 否，特别残忍手段致人死亡除外 |

**第一，犯罪时不满 18 周岁的人不适用死刑。** 注意它强调的是**犯罪时的年龄**，不是审判时的年龄。如果犯罪时不满 18 周岁，哪怕审判的时候已满 18 周岁，也是不能适用死刑的。举个例子：甲 17 周岁的时候杀人，犯罪时不满 18 周岁；19 岁的时候被抓获——同样对甲不能适用死刑，最重也只能判处无期徒刑。这是对未成年人的保护，因为我们国家参与了保护妇女儿童的国际公约，国际公约里面有规定，对怀孕的妇女、对未成年人不得适用死刑。

未成年人的时间节点，他的判断是**以犯罪时为准**，请各位务必注意。

**第二，审判的时候怀孕的妇女不适用死刑。** 首先对"审判的时候"要做**扩大解释**——它包括整个羁押期间，既包括审前羁押期间，也包括审判期间，还有判决以后的执行期间。换句话说，只要在羁押期间怀过孕——怀过孕，这就属于审判的时候怀孕的妇女，依法不得适用死刑。之所以对审判的时候怀孕的妇女不适用死刑，主要目的是为了保护胎儿，各位，胎儿是无辜的。

所以，**怀孕的妇女指的是在整个羁押期间怀过孕，即使又流过产，仍然要视为怀孕的妇女。** 这一点请务必注意。你就牢牢抓住一个点：在羁押期间有没有怀过孕？只要怀过孕，哪怕是流产了，也要认定为怀孕的妇女，不得适用死刑。

我举两个例子，大家对比一下。

第一个，小花怀孕了，怀孕期间杀了个人，把人杀死之后她一紧张流产了，流产以后警察过来把她抓走了。请问这是审判的时候怀孕的妇女吗？当然不是。她流产是发生在羁押之前，她是先流产后才被羁押的，在羁押期间她没有怀过孕——这种情况是可以适用死刑的。

那如果小花怀孕的时候杀了个人，杀过之后公安就把小花抓走了，抓走以后在看守所里那么一紧张、一焦虑，流产了。问这个时候对小花能不能适用死刑？不可以。只要在羁押期间怀过孕，都可以解释为审判的时候怀孕的妇女，不得适用死刑。

**第三**，怀孕的妇女在羁押期间流产后，又因同一事实被起诉交付审判的，**要视为审判的时候怀孕的妇女，不适用死刑**。所以简而言之就一句话：关键看在羁押期间有没有怀过孕，只要怀过孕，都属于怀孕的妇女，不得适用死刑。

这一点要注意，因为司法实践中出现过在我看来很难接受的案例。警察说小花涉嫌严重犯罪，对其刑事拘留；拘留过之后一检查发现小花怀孕了。警察也知道怀孕的妇女不能适用死刑，然后就感觉小花这个所犯之罪比较严重——那没关系，先把小花给放了吧，怀了孕肯定要生孩子了，先把她放了；然后派人密切监视小花，在小花附近，只要她不跑就行；等小花生过孩子之后再把她抓回来。这个时候你不属于怀孕的妇女了吧？然后再交付审判，判处死刑。疯了，各位，这针对性也太强了吧。所以司法解释才规定，哪怕是怀孕的妇女在羁押期间流产，如果又因同一事实被起诉交付审判的，仍然要认定为审判的时候怀孕的妇女，不能适用死刑。

> **易错点**：所以这两类人的时间节点不一样。针对未成年人，我们强调的是**犯罪时**——因为他犯罪时心智毕竟还没有成年人如此成熟，所以犯罪时不满 18 周岁不得适用死刑；审判时怀孕的妇女不适用死刑，对"审判的时候"要做扩大解释，只要在羁押期间怀过孕，不管流产不流产，都认定为审判时怀孕的妇女。

大家还是要有点基本的善念和良心的。我曾经看过一份文件，这个文件我就感觉匪夷所思，各位我找到了，一起来欣赏一下。来源是国家法律法规数据库，到目前为止，这个文件是现行有效的——《关于怀孕的妇女不适用死刑问题的电话答复》，直接打个电话答复她，答复的对象是广东省高级人民法院：

> 在羁押期间已是孕妇的被告人，无论其怀孕是否违反国家计划生育政策，也不论其是否自然流产或者经人工流产，以及流产后移送起诉或审判期间的长短，仍然要执行原答复。对于这类案件应当按照相关规定办理，即人民法院对审判的时候怀孕的妇女不适用死刑。如果人民法院在审判时发现在羁押受审时已是孕妇的，要参照上述规定，不适用死刑。

各位想一想，为什么有这几个字——"是否违反计划生育政策"？只是因为他们审理的一个案件，认定被告妇女小花罪行极其严重，想判处死刑，但是法律规定了审判的时候怀孕的妇女不能适用死刑，然后又一查呢，小花怀孕是违反计划生育政策的，然后就开始请示最高法，说他违反计划生育政策，怀孕了啊，那能不能对他判处死刑？各位，疯了，还有点良心吗？还有点良知吗？我们法律清清楚楚写出来，审判的时候怀孕的妇女不适用死刑。有区分怀孕的原因吗？有区分怀孕是计划内还是计划外吗？没有。所以还是那句话：只有良心，除了良心之外没有。这就是为什么我要求我们要有一个正常的三观。

> **易错点**：还有一点要注意——"不适用死刑"指的是**既不能适用死刑立即执行，也不得适用死刑缓期执行**。

#### 特别残忍的手段怎么判断

第三种对象，审判的时候已满 75 周岁的人不适用死刑，但是**以特别残忍的手段致人死亡的除外**。言下之意，如果手段特别残忍，完全是可以适用死刑的。

"以特别残忍的手段致人死亡"包括以特别残忍的手段故意杀人，也包括以特别残忍的手段实施其他犯罪致人死亡。比如以特别残忍的手段实施爆炸、造成多人死亡，完全有可能适用死刑。但是通常情形的致人死亡，如果不是以特别残忍手段，那就不得适用死刑。

我举个例子。各位抬头看我：张三 76 周岁，和自己的老伴发生争执，张三一生气，拿出一把匕首，朝着老伴的肚子噗一刀，把老太太捅死了。问：对张三能不能适用死刑？

这其实要进行价值判断了。法条规定的是"以特别残忍的手段致人死亡的除外"，问：拿着一把刀朝着别人的肚子捅一刀致其死亡，这能否评价为以特别残忍的手段致人死亡？可以吗？如果有人说这好残忍啊，都把人弄死了——但是你想一想，在所有的故意杀人罪中，如果你认为这都残忍，那所有的杀人手段都残忍，没有不残忍的；一刀捅死，这其实是比较常规的杀人手段。

哪些情况属于特别残忍手段致人死亡？它指的是**故意使用极端的手段致人死亡**——就通常情况已经可以致人死亡了，他偏偏不选择通常手段，他选择非常极端的手段。各位想一想中国法制史，中国古代那些执行死刑的方法：大家都知道有腰斩，有凌迟处死，还有头上凿洞——那个叫什么来着，各位工程师，那小子经常举例子说对我执行死刑，凿开我的脑袋，突然发现里面有一部刑法典，他是不是讲过这种例子？那大家可能对更熟的是凌迟处死。

凌迟处死在中国古代，你残忍吗？很残忍啊，这就属于以特别残忍的手段致人死亡。比较有名的凌迟处死的案子是对一个太监凌迟处死。凌迟处死一般怎么做呢？就是他要求有刀数的限制，不让他死那么痛快。而且呢，为了行刑方便，其实如果一个人特别瘦，对他执行凌迟处死可能还挺难的；但是如果胖胖乎乎的——你们是不是想到了谁啊？想到了某位故人是吧。

然后这个时候，你要对马某凌迟处死，在中国古代一般怎么做？知道吗？用个渔网把马某套起来——马某不是胖乎乎的吗，这一套起来之后呢，稍微勒紧一点，然后它的肉就会凸出来，从渔网中凸出来；凸出来之后拿着那个很锋利的刀子——各位，你们见过那个北京烤鸭吧，就切烤鸭的时候一片一片的知道吧，切、切、切。今天比如剐了 200 刀，好，不能让他死啊，放回监狱；第二天拉出来接着剐、接着剐。各位，特别残忍啊，这就是特别残忍的手段致人死亡。

#### 适用程序与执行方法

限制死刑的适用程序：**判处死刑立即执行的，由最高人民法院核准**。有同学说，那死刑缓期执行怎么办？死刑缓期执行可以由高级人民法院判决或者核准，高院就有这个权利。

看法条第 48 条：死刑只能适用于罪行极其严重的犯罪分子；对于应当判处死刑的犯罪分子，如果不是必须立即执行的，可以判处死刑，同时宣告缓期两年执行——这就是死立执和死缓。缓期执行是缓期两年。再看第二款：可以由高级人民法院判决或者核准。高级人民法院指的就是省这一级的法院，比如上海市高级人民法院、北京市高级人民法院、山东省高级人民法院——省级法院是可以判决或核准死刑缓期执行的。

限制死刑的执行制度，就是刚才说的《刑法》第 48 条：对于应当判处死刑的犯罪分子，如果不是必须立即执行的，可以判处死刑同时宣告缓期两年执行。各位，这就是我国对死刑的政策态度——**保留死刑，但坚持少杀慎杀**。

```text
              对应当判处死刑的犯罪分子
                          │
        ┌─────────────────┴─────────────────┐
        │                                   │
   死刑立即执行                        死刑缓期执行
    （死立执）                            （死缓）
        │                                   │
  由最高人民法院核准          高级人民法院判决或核准
        │                                   │
  枪决或者注射等方法执行        仍要在监狱服刑，缓期二年
```

> **提示**：死刑的执行方法，包括**死立执**和**死缓**。判处死刑立即执行的，采用枪决或者注射等方法执行——让罪犯跪在那，对着他的脑袋砰一枪，这是枪决；有同学说"注射"我以前问过一个学生，一是什么枪决，二呢——不是"真觉"啊，叫**注射**。注射过之后，先是心脏停止跳动，然后大脑死亡。

#### 死缓的适用与四条出路

死立即执行简单，直接验明正身、执行死刑就可以了。但是如果判处死缓呢？死缓是死刑缓期两年执行，这表明**死缓犯仍然要在监狱服刑**。死缓犯大概率是死还是不死？各位，只要不找死，一般不会死。所以死缓我们总归要给他一条出路、给他一个结局。

> **定义**：**死刑缓期执行制度**，简称死缓，是指对犯罪分子判处死刑同时宣告缓期两年执行，强迫其劳动，以观后效的死刑执行方法。

死缓的**适用条件**有两个。第一，**罪该处死**——就论罪当死，言下之意它也符合了死刑的适用条件：罪行极其严重，要求犯罪行为对国家和人民利益的危害特别严重、社会危害性极为巨大。第二，**不是必须立即执行**——为什么呢？因为从他的社会危害性角度来看的确是应当判处死刑，但是从行为的主观恶性和人身危险性的角度来看，他还有改造的余地，可以不立即执行。这就是死缓背后的法理。

举个例子：比如以危险方法危害公共安全罪，如果造成一个人死亡，原则上是可以判处死刑的；但如果行为人主观上是间接故意，以危险方法危害公共安全罪通常都不判处死刑立即执行，一般也是死缓。因为他的主观是间接故意，间接故意就表明他的主观恶性比直接故意要低一些，所以通常是死缓。

死缓的适用机关刚刚也讲了，它可以由高级人民法院判决或者核准。第三，死缓是缓期两年执行，那两年期满之后怎么办？它有四条出路，就是表格中的第三项"死缓变更"。我建议大家跟我一起先看看法条，然后我们再做总结。看第 50 条的规定：判处死刑缓期执行的，在死刑缓期执行期间（就是两年期间），如果没有故意犯罪，2 年期满以后**减为无期徒刑**；如果确有重大立功表现，2 年期满以后**减为 25 年有期徒刑**；如果故意犯罪情节恶劣的，核准执行死刑；故意犯罪但未被执行死刑的，死刑缓期执行的期间**重新计算**。

这表明死缓犯有四条结局。这四个结局我已经做了调整，请各位看一看，从 1 到 4，是结果从好到坏依次递进：

| 死缓期间的表现 | 2 年期满后的结果 |
| :--- | :--- |
| 确有重大立功表现 | 减为 **25 年有期徒刑**（最好） |
| 没有故意犯罪 | 减为 **无期徒刑** |
| 故意犯罪（未被执行死刑） | 死缓期间**重新计算** |
| 故意犯罪，情节恶劣 | **执行死刑**（最差） |

所以判处死刑缓期执行的，在死缓期间最好的结果是什么？那就是确有重大立功表现，2 年期满以后减为 25 年有期徒刑。再差一点呢，如果没有故意犯罪，2 年期满以后减为无期徒刑。再差一点呢，故意犯罪但未被执行死刑，重新计算。最差的结果就是故意犯罪情节恶劣，执行死刑。

各位一定按照这个顺序来记，一次性就差不多能搞定了。

我们国家关于死缓的规定其实有三种类型：第一种是**普通死缓犯**；第二是**限制减刑的死缓犯**（马上讲）；第三种是**附带终身监禁的死缓**——刚刚讲了吧，因贪污罪、受贿罪被判处死缓、死刑缓期执行期满减为无期徒刑后终身监禁、不得减刑假释，那是附带终身监禁的死缓。

#### 限制减刑：只针对三种特殊的死缓犯

哪些情形可以限制减刑？根据《刑法》第 50 条第二款的规定，人民法院根据犯罪情节等情况，可以同时决定对以下死缓犯限制减刑。

第一个陷阱：**只能针对死缓犯限制减刑**。切记一个人如果被判处无期徒刑，那是绝对不能限制减刑的；只能针对死缓犯限制减刑。而且只能针对**三种特殊的死缓犯**限制减刑——这个点一定要注意，如果考到了就是个细节，你知道就能做对。

三种特殊死缓犯是哪三种？

- **第一，被判处死缓的累犯**；
- **第二，因七种罪被判死缓**：故意杀人、强奸、抢劫、绑架、放火、爆炸、投放危险物质。这七种怎么记？各位，两两在一起记可能更简单一点——杀人绑架（我们经常讲绑架和杀人在一起）、强奸抢劫、放火爆炸（他们都是危害公共安全的犯罪），再加上一个投放危险物质；
- **第三，有组织的暴力性犯罪被判处死缓**。

> **易错点**：这"有组织的暴力性犯罪"几个字怎么理解？之前上课有个同学问我什么意思，我说什么意思，他说你看"有组织啊"，我对"有组织的暴力性犯罪"——他是这样断句的："有组织的／暴力性犯罪被判处死缓"。同学，你这个语文好感人啊，不是这样断句的。是"有组织的暴力性犯罪／被判处死缓的罪犯"——比如像黑社会有组织地打打杀杀，那这种情况如果被判处死缓，对其可以决定限制减刑。这个理解不能出问题。

所以针对这三种特殊的死缓犯才能限制减刑。限制减刑不是不能减，仍然能减，只不过要从严把握，换句话说他在监狱待的时间会更长。我们之后会讲到减刑，那个板块我们会详细讲这个制度的关系。

#### 死缓的两个细节考点

我们紧接着看两个小问题。

**第一，死缓不是独立的刑种**，它只是死刑的执行方式。

**第二**，死刑缓期执行期间如果有重大立功表现，2 年期满是可以减为 25 年有期徒刑的。这个 25 年有期徒刑的刑期**从哪天算**？注意它是从**死刑缓期执行期满之日**起计算——各位把期满之日圈起来。判决以前的羁押时间**不能折抵**缓期两年执行的期间。

我举个例子，大家听懂就可以：比如 2015 年 6 月 1 号，张三被送到监狱执行死缓。我们知道死缓是缓期两年执行，然后要到 2017 年 5 月 31 号结束，到 5 月 31 号他就满了两年。那假如在这个期间，比如到了 2015 年 12 月 6 号，张三在服刑期间有重大立功表现。我们知道在死刑缓期执行期间，如果有重大立功表现，2 年期满后要减为 25 年有期徒刑，那么这个 25 年有期徒刑从哪一天算呢？注意，**要从死刑缓期执行期满之日起**，也就是从 2017 年 5 月 31 号，从这一天开始计算他 25 年有期徒刑的刑期。这一点请大家务必要注意。

| 情形 | 减下来的有期徒刑从哪天起算 |
| :--- | :--- |
| 无期徒刑减为有期徒刑 | 自**裁定减刑之日**起计算 |
| 死缓期满减为 25 年有期徒刑 | 自**死刑缓期执行期满之日**起计算 |

判决以前的羁押时间不能折抵这两年。为什么？因为这不是刑期——各位，无期徒刑都没有刑期，那死刑肯定没有。所以我们这个折抵，指的是"判决宣告以前羁押一日折抵刑期多少"，而死刑立即执行和死刑缓期执行，其实没有刑期的问题，它只是个执行方式而已，因此不能折抵。

比如他前面从公安立案侦查一直到法院判决生效，比如他已经羁押了一年，羁押了一年，然后呢结果他被判了死缓、缓期两年执行——那能不能拿他前面的这一年羁押，去折抵死刑缓期执行的两年期间，折抵之后说"哎那他的死缓在监狱里待一年就行了"？不能这样。这个死刑缓期两年执行期间，这个两年是**雷打不动**的，因为它不属于刑期，所以就不存在折抵的问题。

#### 把死刑的考点串一遍

死刑这块终于结束了。我问大家来回答，我专门给大家做一个串联，就是希望大家能够对细节问题大致记一记。你说难吗？它真的不难，它跟前面讲的作为不作为、因果关系、正当防卫比起来太简单了。

- **第一**，死刑从性质上看是自由刑还是生命刑？生命刑。
- **第二**，我们国家对死刑什么态度？保留死刑，少杀慎杀。对死刑要限制，如何限制？
  - 限制死刑适用的**条件**：只能针对罪行极其严重的人适用；
  - 限制死刑适用的**对象**：三类人不适用死刑，老少孕，谁有例外？老——审判时已满 75 周岁的人不适用死刑，但以特别残忍的手段致人死亡的除外；
  - 限制死刑适用的**程序**：死刑立即执行由最高人民法院核准，死缓由高级人民法院判决或核准；
  - 限制死刑的**执行制度**：有死立执，还有死缓执。死立执不讨论了，死缓就是死刑缓期执行。
- **第三**，死缓的适用条件是什么？第一罪该处死，第二不是必须立即执行。死缓是缓期两年执行，两年期满之后怎么办？四条出路，从好到坏：25 年有期徒刑、无期徒刑、重新计算、执行死刑。
- **第四**，针对特殊的死缓犯是可以限制减刑的，三种特殊死缓犯：被判处死缓的累犯；七种罪判死缓——杀人绑架、强奸抢劫、放火爆炸、投放危险物质；有组织的暴力性犯罪被判处死缓。此三类死缓犯可以同时决定对其限制减刑。
- 最后关注两个细节问题：首先死缓不是独立的刑种；其次，死缓如果在死刑缓期两年执行期间有重大立功表现，2 年期满后要减为有期徒刑 25 年，它的刑期是自**死刑缓期执行期满之日**起计算，而且没有刑期折抵问题。这不就是它的难点吗。

其他几个细节我就不重复了，比如怀孕的妇女不适用死刑——它强调的是审判的时候怀孕的妇女，只要在羁押期间怀过孕，都不得适用死刑。切记，切记。

| :--- | :--- | :--- | :--- | :--- | :--- |
| 管制 | 限制自由，不关押 | 3 个月以上 2 年以下，并罚不超 3 年（**323**） | 1 日折抵 **2 日** | 社区矫正 | 可并用禁止令；同工同酬 |
| 拘役 | 剥夺自由，短期 | 1 个月以上 6 个月以下，并罚不超 1 年（**161**） | 1 日折抵 **1 日** | 公安机关就近执行 | 每月可回家 1—2 天，劳动酌量发给报酬 |
| 有期徒刑 | 剥夺自由 | 6 个月以上 15 年以下；并罚不超 20 年（总和不满 35 年）／25 年（35 年以上） | 1 日折抵 **1 日** | 监狱或其他执行场所 | 适用范围最广；无酌量报酬 |
| 无期徒刑 | 剥夺终身自由 | 无期限 | 不存在折抵 | 监狱或其他执行场所 | **必须**剥夺政治权利终身；符合条件可减为有期 |
| 死刑 | 剥夺生命 | 无刑期（死立即执行、缓期两年执行两种执行方法） | 不存在折抵 | 监狱（死缓）／枪决、注射（死立执） | 保留但少杀慎杀，老少孕不得适用 |

四条期限口诀摆在这里：**管制 323、拘役 161、有期 6-15-20/25、无期无期、死刑无期**。前面四个刑种都是"剥夺/限制自由 + 有期限"的组合，唯独无期徒刑和死刑跨出了这个框架——**无期没有刑期，死刑没有刑期**，所以它们都不存在折抵刑期的问题。这一条想通了，管制"1 比 2"、拘役和有期"1 比 1"、死缓"两年雷打不动不能折抵"，就全都通了。

### 本讲提到的题目

讲完无期徒刑，紧接着我们看 202 页的这道真题。

> **题目**：下列关于无期徒刑的表述中，正确的有（　　）
>
> A. 对不满 16 周岁的人不得适用无期徒刑
> B. 被判处无期徒刑的犯罪人，在判决执行以前的羁押时间不得折抵刑期
> C. 对被判处无期徒刑的犯罪人不得适用假释
> D. 对被判处无期徒刑的犯罪人可以附加剥夺政治权利 10 年以上

**答案：B。**

逐项来看。

**A 项错误。** 对已满 14 周岁、不满 16 周岁的未成年人，司法解释规定的是**一般不判处**无期徒刑，只是一般不判处，符合条件的依然有可能判处。所以"不得适用"这个说法太绝对了。同一逻辑在前面也出现过——口诀是老少孕"不适用"死刑指的是绝对禁止，而这里针对未成年人的无期徒刑只是一条"一般不判处"的司法解释尺度，两者不能混为一谈。真正绝对不得判处死刑的是未成年人，这一点本身是确定的；不得适用的是死刑，不是无期徒刑。

**B 项正确。** 无期徒刑**本身就没有期限**，既然没有刑期，就根本不存在折抵刑期的问题。前面讲管制的时候我们说过，管制、拘役、有期徒刑才有"判决执行以前先行羁押的，羁押一日折抵刑期几日"的问题；无期徒刑是刑事诉讼法上明确不折抵的。这一点跟死刑的逻辑是相通的——折抵规则只对"有刑期"的主刑有意义。

**C 项错误。** 假释这一块我们还没讲，后面会讲。但就无期徒刑本身而言：对被判处无期徒刑的罪犯，**符合条件的是可以减刑或者假释的**。真正不得减刑、不得假释的是终身监禁，而终身监禁不是独立的刑种，只是贪污罪、受贿罪死缓减为无期后的特殊执行措施。这个选项把无期徒刑和终身监禁搞混了。

**D 项错误。** 这个选项错得最离谱。刚刚讲过：对被判处无期徒刑的犯罪分子，**应当剥夺政治权利终身**——注意是"必须剥夺，终身"。D 项既说成"可以附加"（法律上是应当，不是可以），又说成"10 年以上"（法律上是终身，没有 10 年这个选项）。所以正确表述是：对被判处无期徒刑的犯罪分子**必须附加剥夺政治权利终身**。

一道题四个选项，四个陷阱各不相同：A 项在"一般"和"不得"之间做文章，C 项在无期徒刑和终身监禁之间做文章，D 项在"应当"和"可以"、"终身"和"10 年"之间做文章。只有 B 项踩的是无期徒刑最核心的特征——没有刑期。

## 附加刑怎么判：罚金、没收财产、剥夺政治权利与驱逐出境
> 对应块：BLK58 | 覆盖分集：P58 | 块标题（分集名）：《第13章 第04节：附加刑》

主刑讲完，后面还站着四种刑罚方法，它们叫附加刑。附加刑的定位很特别——**既能独立适用，又能附加适用**。独立适用，就是不判主刑，光判这一种；附加适用，就是判了主刑，再往上加这一种。至于到底是"只能单来""可以选""必须加""两可都行"，这四种附加刑各有各的门道，而且它们跟主刑最大的区别在于：罚金、没收财产都能在判决执行阶段继续出状况，一判下去并不是句号。

四种附加刑，顺口溜四个字：**罚莫剥屈**——罚金、没收财产、剥夺政治权利、驱逐出境。

> **结论**：主刑是管、拘、有、无、死，附加刑是罚、没、剥、驱。定罪量刑这条主线上，主刑、附加刑都归法官裁量。

### 罚金：适用、缴纳与数额

#### 适用方式有四种

> **定义**：罚金是指人民法院判处犯罪分子或者犯罪的单位，向国家强制缴纳一定数额金钱的刑罚方法。

从本质上看，罚金属于**财产刑**，内容就是向国家缴纳一定数额的金钱。围绕怎么适用，立法上分四种情形。

| 适用方式 | 含义 | 立法例 |
| --- | --- | --- |
| 单处罚金 | 只判罚金，不判主刑 | 单位犯罪——对单位只能判处罚金 |
| 选处罚金 | 判不判罚金由法官根据案情裁量；判了就只能独立适用 | 故意毁坏财物罪：处三年以下有期徒刑、拘役**或者**罚金 |
| 并处罚金 | 一定判罚金，且只能附加适用，不能单独使用 | 倒卖文物罪：处五年以下有期徒刑或者拘役，**并处**罚金 |
| 复合式 | 独立适用、附加适用都可以 | 假冒专利罪：处三年以下有期徒刑或者拘役，**并处或者单处**罚金 |

选处罚金最好懂。故意毁坏财物罪那条法条，语文水平正常都能读明白：要么三年以下有期徒刑，要么拘役，要么罚金，三选一。**这个罚金可以不用**；但一旦用了，就只能独立使用，没法再往上附加。这点要注意。

并处罚金是"顾名思义"——判处主刑的同时必须附加罚金，它自己不能单跑。不管主刑最后是有期徒刑还是拘役，罚金都得上。

复合式最容易考在单位犯罪上：最轻的判决只判一笔罚金（单处），重一点的既判三年有期徒刑又并处罚金，两种判法都合法，所以叫"复合"。

#### 缴纳方式有六种

罚金怎么收，第 53 条规定得很清楚，可以归成六个点：

- 限期一次缴纳
- 限期分期缴纳
- 强制缴纳
- 随时追缴
- 延期缴纳
- 减免缴纳

这六种落脚点都落在"缴纳"上，只有第四种"随时追缴"是例外。

> **提示**：这六个词不用硬背，想想还信用卡、还花呗就全明白了。

这个比方相当贴切。花呗账单日一到，你下个月是一次还清，还是分期还？站在支付宝的角度，它当然希望你分期——分期能收手续费、涨利息，利润更高。罚金跟还花呗，真的一样。

（顺便说个读音梗：花呗这个字我一直读"花吧"，读了好几年。有个学生说：老师，你别"花"了。我说怎么回事？他说，读"花呗"不是读"花吧"。行吧，不好意思啊，各位，花呗。）

那下个月还花呗，怎么还？依次缴纳，能不能分期？能。还有更"聪明"的做法：我小学同学回家聚会，现在很多年轻人都用网贷——你们未必有，但那些没好好读书、早就进社会的，可能身边就有，我小学同学里就有用网贷的，还咨询过我法律问题。套路是这样的：

```text
第一步  养号：先正常使用、正常还款，额度越用越高
第二步  套现：额度高到 1 万、2 万，一次性全部刷掉
第三步  断供：钱花完了，账号也不还了
第四步  换号：怕支付宝联系自己，把 App 从手机上卸载
              ↓
        卸载了就找不到了？  怎么可能
```

这就是**强制缴纳**：你不还，他会查你所关联的银行卡里有没有钱，有就直接划走。如果一查没钱呢？也不会放过你——那就等，什么时候有钱什么时候给你划过来，这叫**随时追缴**。你跟他玩卸载，他跟你玩追踪。

特殊情况可以延期或者减免。比如疫情那个阶段，支付宝发过通告，对上个月的花呗可以延期；极为特殊的情况还可能减免，而且不影响芝麻信用分。大家想想这几种情形，跟还信用卡是不是一模一样？

#### 数额确定有五种

立法规定"判处罚金，应当根据犯罪情节决定罚金的数额"。犯罪情节主要看三件事：

- 违法所得的数额——你通过犯罪挣了多少钱，挣得越多罚金越高
- 给被害人造成的财产损失大小
- 犯罪分子的实际经济负担能力

> **易错点**：第三点必须考虑实际经济负担能力。一个人支付能力一般，法院判了他一笔巨额罚金，他心里想的是"反正老子这一辈子也付不起了，无所谓，索性一分钱不交"——这恰恰会搞坏刑罚的执行。所以数额要参照他的支付能力。

具体怎么定，拓展出来有五种（这一块考试分析没考，属于我们多讲的一个点）：

**限额罚金制**——既有下限又有上限，脚踩地板、头顶天花板。比如持有、使用假币罪，并处或单处 1 万元以上 10 万元以下罚金。

**无上限罚金制**——有下限，没有上限，额度交给法院自由裁量。典型是第 170 条伪造货币罪，处三年以上十年以下有期徒刑，并处罚金。

> **提示**：这里容易被问一句——"并处罚金"既没写下限也没写上限，怎么能说有下限？我们在总则刑事责任年龄那一节讲过：**对未成年人判处罚金不能低于 500 元，对成年人犯罪判处罚金不能少于 1000 元**。这个 500 和 1000 就是下限。所以成年人犯伪造货币罪，最低 1000 元，最高上不封顶。

> **结论**：有下限无上限的叫无上限罚金制；既有下限又有上限的叫限额罚金制。**根本不存在"无下限罚金制"——罚金永远有下限。**

**倍数罚金制**——按犯罪金额的倍数定罚金。比如内幕交易、泄露内幕信息罪，规定并处或单处违法所得 1 倍以上 5 倍以下罚金。假设通过内幕交易挣了 200 万，就在 200 万的 1 倍到 5 倍之间判：

$$罚金数额 = 违法所得 \times 倍数（1 \sim 5 倍）$$

**比例罚金制**——按犯罪金额的比例定。比如虚报注册资本罪，规定并处或单处虚报注册资本金额 1% 以上 5% 以下罚金：

$$罚金数额 = 虚报注册资本金额 \times 比例（1\% \sim 5\%）$$

**倍比罚金制**——倍数和比例叠在一起，既有比例又有倍数。比如生产、销售伪劣产品罪，规定并处或单处销售金额 50% 以上二倍以下罚金，50% 以上是比例，二倍以下是倍数：

$$罚金数额 = 销售金额 \times 比例与倍数（50\% \sim 200\%）$$

前两种是一组（限额、无上限），后三种是一组（倍数、比例、倍比）。

#### 只能动合法财产，由法院执行

罚金从本质上是财产刑，是刑罚，无论是罚金还是后面要讲的没收财产，**针对的都是个人（被告人）的合法财产**。如果是违法所得，那要追缴，不是罚金能碰的。

看这个例子：甲盗窃乙 5 万元，被判处两年有期徒刑，并处 2 万罚金。他偷的这 5 万怎么办？这 5 万不是他的合法财产，是他通过犯罪的违法所得，由此要对违法所得 5 万追缴，追缴之后返还给被害人、退给乙。除此之外，甲还要在自己的合法财产范围内缴纳 2 万罚金。

```text
                 甲的全部财产
                       |
        +--------------+--------------+
        |                             |
   违法所得 5 万                  合法财产
   （偷自乙）                      |
        |                        罚金 2 万
   追缴 → 返还被害人乙            （上缴国库）
```

另外，罚金和没收财产这类财产刑，**由人民法院负责执行**。我们常讲那句话：叫"要钱要命，找法院"。找法院要钱、要命，所以罚金的执行（以及死刑的执行）都是法院来负责的。

> **提示**：罚金这一块回头自查三句就够——适用方式四种（单处、选处、并处、复合式）刚讲过；缴纳方式就是还花呗那六种，不重复了；数额确定五种刚讲过；对象只能是被告人的合法财产；**执行主体是人民法院**。

### 没收财产：从"抄家"到偿还正当债务

#### 适用方式有三种

> **定义**：没收财产是指将犯罪分子个人所有财产的部分或者全部，强制无偿收归国有的刑罚方法。八个字分开记：**强制无偿收归国有**。中国古代俗称"抄家"。

现行规定包括三种：

- **并处没收财产**——一定要判，没得商量。比如绑架罪：如果故意伤害被绑架人致人重伤、死亡，或者杀害被绑架人，处无期徒刑或者死刑，并处没收财产，这时候没收财产是必判的。
- **可以并处没收财产**——交给法官自由选择，根据犯罪事实情节决定判还是不判。比如间谍罪规定"可以并处没收财产"，需要就判，不需要就不判。
- **在罚金和没收财产中择一适用**——并处罚金或者没收财产，二选一，但财产刑一定要有。比如抢夺罪，抢夺公私财物数额特别巨大，处十年以上有期徒刑或者无期徒刑，并处罚金或者没收财产。

一句话记住这两个"并处"的差别：讲到"并处"指的是**应当并处**；讲到"可以并处"才是法官自由选择。

#### 范围：部分、全部与家属的财产

概念里已经写明，没收财产是没收个人所有财产的**部分或全部**，一共两种。

如果没收全部，有一条底线：必须为犯罪分子**个人及其抚养的家属保留必要的生活费用**。你不能把人家饿死，得留一些基本的生活费。

既然谈到家属，紧接着就是这一条：没收财产的时候，**不得没收属于犯罪分子家属所有或应有的财产**。言下之意，谁犯罪就没收谁的财产，不能株连无辜。

#### 执行：法院来没收，正当债务先偿还

第一，没收财产同样由人民法院执行，还是那句"要钱要命找法院"。

第二，以没收的财产偿还债务。这是**超纲题**，但刑法第 60 条要了解：没收财产以前犯罪分子所付的正当债务，需要以没收的财产偿还的，**经债权人请求，应当偿还**。

举个例子。假定小马同学炒股缺钱，找我借 100 万块去炒股票。人家的原话大概是："大海呀，你能不能借我 100 万，我去炒股票。"我同意了，我们之间是正当的债权债务关系。结果他拿着这 100 万去犯罪了，而且被判没收全部财产。

那对我的债权有没有影响？当然有。他的财产全被没收了，他拿什么钱还我？而且注意时序——我和马峰的债权债务关系产生在**前**，国家没收他的财产发生在**后**。正是基于这个原理，要体现**国家不能与民争利**，才有第 60 条这一款。

适用条件有三个：

- 必须是没收财产**以前**所负的债务
- 必须是**正当债务**
- 债权人要**提出请求**——谁没收了马峰的财产，我就去找谁，我去找法院提出请求

> **易错点**：法条说的是"**应当**偿还"，切记是"应当"。

但法院最多只能在没收的财产范围内偿还。假设法院没收了马峰 200 万，我拿 100 万的债权去请求，法院说可以还；我再问为什么不能还 100 万？法院答：没收的时候马峰身上只有 10 万块钱，这 10 万全部没收了，就这么多。我能不能问法院要 100 万？疯了，法院怎么可能会做赔本的买卖。

至于非法债务，根本不能找法院。比如赌债，我跟马峰赌博他欠我钱，我去请求法院用没收的财产偿还，法院会说：什么债务？赌资对吧？法院会理我吗？不但不理，还可能把我移送公安，追究我赌博的责任。

### 罚金与没收财产差在哪

| 比较项 | 罚金 | 没收财产 |
| --- | --- | --- |
| 内容 | 强制缴纳一定数额的金钱，只针对**钱** | 没收个人所有财产的一部或全部，既可以是钱，也可以是汽车、股票等其他财物 |
| 适用方式 | 既可附加适用，也可独立适用 | 实际上**仅附加于主刑适用** |
| 执行方式 | 限期一次缴纳、限期分期缴纳都行 | **只能一次性执行完毕**，针对当下已有的财产 |
| 适用对象 | 通常适用于情节较轻的**贪利性犯罪** | 主要适用于危害国家安全、破坏市场经济秩序、侵犯财产、贪污贿赂犯罪中**情节较重**的犯罪 |

罚金那条"既可附加也可独立"没问题，但没收财产为什么说仅附加于主刑适用？因为没收财产太重了，是非常严重的财产刑，只针对严重犯罪才能用。既然是严重犯罪，想一想，怎么可能不判主刑？肯定要判。所以你翻遍整个刑法典，会发现**没收财产从立法规定上没有独立使用的**，都是先判个主刑，再附加适用。罚金则不同，它可以分期缴、随时缴，没收财产不行，只能一次性执行当下已有的财产。

适用对象那一栏的落点也在这里：没收财产主要针对重罪，罚金通常针对情节较轻的贪利性犯罪——贪利性就是要靠犯罪来挣钱。

### 追缴与责令退赔：赃物还在不在

罚金、没收财产只能动合法财产，这句话不是空话，它是从另一组制度里反推出来的。这组制度叫**追缴与责令退赔**。

看这段法条：犯罪分子违法所得的一切财物，**应当予以追缴或者责令退赔**；对被害人的财产应当及时返还；违禁品和供犯罪所用的本人财物应当予以没收；没收的财物和罚金一律上交国库，不得挪用和自行处理。

一句话把这四组财产的去向画清楚：

```text
                 行为人 / 犯罪单位名下的财物
                                |
      +-------------------------+-------------------------+
      |                         |                         |
   违法所得              供犯罪所用的本人财物         合法财产
 （赃物及其收益）        （工具、组成物、相当物）    （未用于犯罪的）
      |                         |                         |
  追缴  or  责令退赔             没收                  罚金 / 没收财产
  （找不到就退赔）           （违禁品 + 犯罪工具）      （一律上交国库）
      |                         |                         |
  被害人财产及时返还        通常销毁                   归国家
```

回到前面追缴和责令退赔这两个词，它们的关系只取决于一句话：**赃物还能不能找到**。找得到就追缴，找不到就责令退赔。

#### 赃物找得到，就追缴

小马同学喜欢骑摩托车，他那辆摩托车很值钱，价值 2 万（这是真的）。我把它偷走了，构成盗窃罪，就停在我家院子里。马峰报警之后，警察找到我，一看摩托车就在院子里面。

请问这辆摩托车对我而言属于违法所得的财物，叫盗窃所得，属于赃物。赃物还能找到，怎么办？追缴——警察扣押这辆车，追缴回去。追缴以后，因为这毕竟是被害人的财产，要及时返还，把摩托车还给马峰。

那有人说：老师，教材上写上交国库，那马峰怎么办？他真的是一个彻彻底底的被害人了。不能啊——这个时候有被害人，就要及时退还给被害人。

#### 赃物找不着，就责令退赔

如果我把摩托车偷走之后卖掉了，而且卖给谁找不到了，怎么办？你想追缴这辆摩托车，已经追不到了，那就只能对摩托车的价值进行评估，然后责令我退赔，比如退赔现金给马峰。

所以违法所得的财物，要么追缴，要么责令退赔；如果有被害人，对被害人的合法财产要及时返还。

这里还要注意**违法所得的范围**：既包括违法所得的财物本身，也包括它产生的收益。比如甲贪污 50 万，又利用这 50 万炒股挣了 20 万——前者是违法所得，后者是违法所得产生的收益，两个都要追缴。

追缴的对象是**现实存在的**违法所得，既包括行为人自己占有的，也包括转移给他人占有的。比如甲把集资诈骗的财物交给乙保管，交给乙保管并没有改变这笔钱的性质，它仍然是违法所得，对这笔钱仍然要追缴。

责令退赔针对的是另一头：违法所得已经被用掉、毁掉、挥霍，无法追回时，责令退赔给被害人。比如盗窃的 10 万全部拿去赌博输光了，这 10 万找不到了，那只能责令甲退赔给乙 10 万。

> **结论**：赃物在不在，是唯一的分水岭。赃物在，追缴；赃物不在，责令退赔。

### "没收"不是"没收财产"：违禁品与供犯罪所用的本人财物

法条里还接着一句：违禁品和供犯罪所用的本人财物应当予以没收。这个"没收"跟前面讲了半天财产刑的"没收财产"，完全是两码事，千万别混。

#### 违禁品：法律禁止个人持有的物品

枪支弹药、爆炸物、淫秽光盘，都是违禁品。在查处犯罪过程中发现这些东西，一律没收，这一点没有任何争议。

#### 供犯罪所用的本人财物：专为犯罪准备

问题来了：是不是只要在犯罪过程中用到财物，都要没收？我举几个例子，大家自己判断。

张三醉酒驾驶机动车，不小心撞死一个人，构成交通肇事罪。问：这辆机动车要不要没收？它不就是供犯罪所用的本人财物吗？有人说不能没收，因为这是过失犯罪。那我换个问法：如果张三醉酒驾驶机动车**没撞死人**，构成危险驾驶罪，这是故意犯罪了，这辆机动车要没收了吧？可你一没收就发现问题来了——撞死人的过失犯罪不没收，没撞死人的故意犯罪反而没收，这显然不合理。是都没收，还是都不没收？

再比如，我心情不错买了一双新皮鞋，尖头的，锃亮锃亮。第一天穿出门儿趾高气扬心情很好，结果张三这小子不长眼，走路的时候一脚踩到我的新皮鞋，把鞋头都踩扁了，半天没弹回来。我一生气，抡起脚两脚把他踢死了。我犯罪了，请问这尖头皮鞋要不要没收？有人说要没收，理由是"鞋头太尖了，很危险"。也有人说不能没收。

最后一个。我毕竟造成了他人死亡，背着一条人命，我也怕，就潜逃外地捡垃圾、捡破烂为生，感觉活着好难。捡垃圾卖了 20 块。我想一想不行，我要干一票大事——用这 20 块买了一双丝袜，丝袜套在头上，拿着一把匕首冲进银行要抢钱，被抓住了。请问匕首要不要没收？丝袜要不要没收？

那没收之后要不要上交国库？国库不要这些东西，怎么办？

> **结论**：这就得用**同类解释**来解决了。违禁品和供犯罪所用的本人财物既然被规定在一起，就要求它们具有相同的性质——放在一起是一类，就得满足共同的特征。能没收的财物，要达到**与违禁品相当**的程度，也就是**专门为犯罪准备**。

把上面几个例子套进这条标准：

| 例子 | 是不是专为犯罪准备 | 结论 |
| --- | --- | --- |
| 醉驾撞死人的车 | 我买车是为了撞人吗？是为交通出行 | 不没收 |
| 醉驾没撞死人的车 | 我买车是为了醉驾吗？也不是 | 不没收 |
| 踢死人用的尖头皮鞋 | 我买鞋是为了踢人犯罪吗？是为了自己穿 | 不没收，充其量是犯罪证据，可以扣押 |
| 抢银行用的匕首 | 带着匕首冲进银行，表明它就是为实施抢劫作准备 | 没收 |
| 套头用的丝袜 | 丝袜买来是套头的吗？表明专为此次犯罪准备 | 没收 |

所以丝袜和匕首都要没收，没收之后上交国库；国库不要的，通常都会销毁。

> **易错点**：那个尖头皮鞋达不到与违禁品相当的程度，不能没收——它是**犯罪证据**，扣押即可，没收干嘛呢。

另外三类情形要一并记：

- **犯罪工具**——杀人用的刀、走私用的船、非法行医用的相关器材，这些都是专门为犯罪做准备的，肯定要没收。
- **犯罪的组成之物**——比如赌资、行贿中的财物。行贿的 10 万块可不是通过犯罪获益得来的收益，它是用于行贿的非法所得财物，所以要没收。

  有人会问：张三送给局长 10 万块，这 10 万对张三而言是什么？它不是通过犯罪挣来的收益，而是他用于行贿的非法所得财物。

- **与违禁品具有相当性的财物**——比如非家庭生活使用的长刀、铁棒，主要用于窃听、窃照的器材。

这一类不用记那么细，**记住"专为犯罪准备"这一句就够了**。我买丝袜的目的不是自己穿，是抢银行；我买匕首的目的不是削苹果，是抢银行——这种就达到了与违禁品相当的程度，应当予以没收。

顺便回到前面那道走私的真题：被告人收受的贿赂款属于违法所得，应当予以追缴，追缴之后上缴国库，不可能退给行贿人。因为行贿人一旦把钱送给受贿人，这笔钱对受贿人而言是违法所得；可对行贿人而言，这是他行贿的财物，行贿人并不是受害人，所以不可能退还给他。

### 剥夺政治权利：四项权利、两类对象、一张期限表

#### 它是资格刑，剥夺四项权利

政治权利是宪法和法律赋予公民的权利，核心内容就两项：参加国家管理、参加政治活动。剥夺政治权利，就是剥夺这两项。

> **定义**：剥夺政治权利是指剥夺犯罪分子参加国家管理与政治活动权利的刑罚方法。它属于**资格刑**，被剥夺的就是这项资格。

具体内容是四项，**同时被剥夺**：

- 选举权和被选举权。失去这项权利，连村委会主任都当不了——别说当，连投票的权利都没有。人大代表也不行。
- 言论、出版、集会、结社、游行示威自由的权利。这一串怎么记？两两成对：**言论出版、集会结社、游行示威**。出版是把文字加工编辑公示于众；集会就是聚在一起；结社是成立一个新政党，在我们国家结社可不容易；游行示威两个又在一起。
- 担任国家机关职务的权利。简单讲就是不能做公务员、不能考公务员；领导职务和一般职务都不能担任。如果在职的公务员被剥夺政治权利，是要开除的。
- 担任国有公司、企业、事业单位、人民团体领导职务的权利。这几种单位的**领导**不能当了，但**一般职务**可以担任。

> **提示**：这四项能大致记住就很棒了，现在能记住、选择题正确率就高；等到背诵阶段我们肯定还带着大家一条一条背。

> **易错点**：注意区分"限制"和"剥夺"。前面讲管制犯时提到，管制犯要遵守的规定中有一项是"未经执行机关批准，不得行使言论、出版、集会、结社、游行、示威自由的权利"。言下之意，**经过批准仍然可以行使**——所以管制犯只是被**限制**了这一项政治权利，并没有被**剥夺**。

#### 两类对象：应当剥夺与可以剥夺

**应当剥夺的有两类人：**

- 危害国家安全的犯罪分子。只要是危害国家安全犯罪，一律都要剥夺——这跟前面讲国事犯的"应当剥夺"是同一条线。
- 被判处**死刑、无期徒刑**的犯罪分子，一律剥夺政治权利**终身**。

**可以剥夺的是一类人：**故意杀人、强奸、放火、爆炸、投毒、抢劫等**严重破坏社会秩序**的犯罪分子，可以附加剥夺政治权利。注意，这是"可以"，要根据案情决定。

#### 期限与起算：记那张从重到轻排好的表

文字版教材这一块写得有点乱、没有顺序，强烈建议直接看表格，我已经按从重到轻排好了：

| 主刑 | 剥夺政治权利的期限 |
| --- | --- |
| 死刑、无期徒刑 | 终身，自主刑执行之日起剥夺 |
| 死缓重大立功期满减为有期徒刑、无期徒刑减为有期徒刑 | 改为 3 年以上 10 年以下 |
| 有期徒刑、拘役附加剥夺政治权利 | 1 年以上 5 年以下 |
| 独立适用剥夺政治权利（不判主刑） | 1 年以上 5 年以下 |
| 管制附加剥夺政治权利 | **与管制期限相等，同时执行** |

用阶梯图看更直观：

```text
 主刑从重                                        剥夺政治权利期限
 ─────────────────────────────────────────────────────────────

  死刑 / 无期徒刑  ────────────────────────▶  终身
        │  死缓重大立功期满、无期符合条件，减为有期徒刑
        ▼
  减为有期徒刑    ────────────────────────▶  3 年以上 10 年以下
        │
        ▼
  有期徒刑 / 拘役  ───────────────────────▶  1 年以上 5 年以下
  附加剥夺
        │
        ▼
  独立适用（只判剥夺政治权利） ────────────▶  1 年以上 5 年以下
        │
        ▼
  管制 + 附加剥夺  ───────────────────────▶  与管制刑期相等，同时执行
                                                  （最重要）
```

几处细节要单独说：

- **死缓也是死刑的一种**。死缓重大立功、两年期满后减为二十五年有期徒刑，无期徒刑符合条件也可以减为有期徒刑。他们本来被剥夺政治权利终身，一旦减为有期徒刑，"终身"就要改成 3 年以上 10 年以下。
- **管制犯是重中之重**。管制犯未必要剥夺政治权利，但如果适用了，就意味着管制的期限多久、剥夺政治权利的刑期就多久。管制三个月以上、二年以下，判管制一年就剥夺一年，判管制六个月就剥夺六个月，而且是**同时执行**。

刑期从哪天起算？

- 判**管制**附加剥夺的，与管制刑期相等，**同时计算、同时执行**。
- 判**拘役**附加剥夺的，从拘役执行完毕之日起计算，在拘役执行期间当然不享有政治权利。
- 判**有期徒刑**附加剥夺的，从有期徒刑执行完毕之日**或者假释之日**起计算。拘役没有假释的问题，这一点后半部分讲假释时会再说。
- 死缓减为有期徒刑后改成 3 年以上 10 年以下，**从有期徒刑执行完毕之日或者假释之日起计算**，主刑执行期间当然也不享有政治权利。

举个具体的：甲因犯 A 罪被判处三年有期徒刑，附加剥夺政治权利两年。他在监狱服刑这三年当然不享有政治权利；出狱之后再计算附加剥夺的两年，所以他**实际被剥夺了五年政治权利**。

> **结论**：主刑执行期间，剥夺政治权利的效力当然适用；从执行完毕之日起，再往外挂附加剥夺的那几年。

#### 执行

- 由**公安机关执行**，考试分析明确指明了这一点。
- 剥夺政治权利的**独立适用**（单独适用、不判主刑）由刑法分则加以规定。**分则条文中如果没有规定独立适用剥夺政治权利，那就不能独立使用**——所以独立适用必须回头看刑法分则有没有明文规定。
- 被剥夺政治权利的犯罪分子，在执行期间要遵守法律、服从监督，不得行使刚才讲的第 54 条那四项权利。

#### 一问一答自查

- 剥夺政治权利的内容？刚才那四项。
- 适用对象？应当剥夺两类：危害国家安全的犯罪分子、被判死刑无期徒刑的犯罪分子（终身）；可以剥夺一类：严重破坏社会秩序的犯罪分子。
- 刑期怎么算？按从重到轻：死刑、无期——终身；减为有期徒刑——3 年以上 10 年以下；有期徒刑拘役附加剥夺或独立适用——1 年以上 5 年以下；管制附加剥夺——与管制期限相等，同时执行。

难不难？不难。记不住很正常——你要是听一遍就全记住了，各位，你那是天才，绝对的天才，怎么可能过目不忘？这些细节听完课要稍微看一看、整理一下。理解上没有难度，主要是记好。

### 驱逐出境：只管没有我国国籍的人

最后一个附加刑，是强迫犯罪的外国人离开中国国（国）边境的刑罚方法。

它适用的对象只能是**犯罪的外国人**。这个"外国人"我们一般认为还包括**无国籍人**——只要没有我国国籍的，对我们而言都是外国人。所以只能针对外国人，才谈得上附加适用或者独立适用。

问一句：马峰犯罪了，我们能不能把他驱逐出境？可以。现在中国服刑，判决书写明有期徒刑 15 年，刑罚执行完毕后驱逐出境。执行完毕以后，你把他赶到哪儿去？赶到日本去？让他去当日本的天皇？各位，疯了，不可能。

驱逐出境有两种方式：

- **独立适用**——通常指犯罪比较轻，不判处主刑了，直接单独判处驱逐出境，**从判决生效之日起**执行——判决生效，"请离开吧"。
- **附加适用**——既判主刑，也判附加刑。前些年有个顶流明星是加拿大籍的，在中国大陆涉嫌强奸罪，最后被北京法院判处 12 年有期徒刑，从涉嫌犯罪变成了罪犯，还附加了驱逐出境。言下之意，他在北京监狱服刑 12 年之后，**出狱的那一天起**还要被驱逐出境。

> **结论**：附加适用驱逐出境的，从主刑执行完毕之日起开始执行。

### 定罪量刑之外，还挂着一个小尾巴

到这里，作为法官，量什么刑就讲完了：主刑可以量——管、拘、有、无、死；附加刑也可以量——罚、没、剥、驱。

但定罪量刑毕竟是一条主线，在这条主线之外还挂着一个**小尾巴**，那就是非刑罚处理方法。我们刚刚讲的刑罚方法，刑罚、刑罚，包括主刑和附加刑；那么非刑罚处理方法还有几种？这几种掌握精度的要求没有那么高，难度系数可能更低——先歇几分钟，回来我们接着讲。

### 本讲提到的题目

#### 题目一

关于没收财产，下列可以没收的有（多选）：

- A. 被告人收受的贿赂
- B. 被告人持有的股票
- C. 被告人的土地承包经营权
- D. 被告人作案使用的电脑

**答案：B、D**

**解析：**

- **A 错**。收受的贿赂是违法所得，应当予以**追缴**，而不是没收财产。
- **B 对**。股票是合法财产，没收财产作为财产刑，可以针对被告人的合法财产。
- **C 错**，两个理由。其一，土地承包经营权是一种**权利**，不是财产，而没收财产必须针对财产本身；其二，在我们国家，个人不可能对土地拥有所有权，土地要么国有、要么集体所有（比如农村的耕地属于集体），对土地承包经营权进行没收，制度上存在障碍——都没收了给谁用？
- **D 对**。作案使用的电脑属于供犯罪所用的本人财物，依规定应当予以没收。注意，这个"没收"不是"没收财产"刑：它之所以被没收，是因为它达到与违禁品相当的程度——**专门为犯罪准备**。而没收财产只能针对被告人的合法财产，且是**没有用于犯罪的**合法财产。

只要把"违法所得—追缴/退赔""违禁品与供犯罪所用—没收""合法财产—罚金/没收财产"这三套制度听懂了，这道题就很简单。

#### 题目二

甲武装掩护走私，法院判其构成走私罪，处无期徒刑，并处没收财产。下列哪些财产可以纳入没收财产刑的范围（多选）？

- A. 甲在走私中使用的枪支
- B. （当场只说明它同样属于违禁品，未念出选项名称）
- C. 甲在银行账户上的 500 万存款
- D. 甲所有的两辆豪华轿车

**答案：C、D**

**解析：**

- **A 错**。枪支是违禁品，违禁品应当予以**没收**，但那是法条第 64 条意义上的没收，不是"没收财产"刑。B 项同理。
- **C 对**。题目没有说这笔存款是违法所得，那就只能默认它是合法财产，可以由没收财产刑没收。
- **D 对**，同理。

> **提示**：这里给大家一个考试直觉：不要加戏。不要想"这两辆豪华轿车说不定是他贩毒挣的钱买的"——题目没有这样交代，你就不能这样想。题目一定会把非法所得明确交代出来，题目怎么说，你就怎么想。

## 非刑罚处理方法：八种手段与一个时间点
> 对应块：BLK59 | 覆盖分集：P59 | 块标题（分集名）：《第13章 第05节：非刑罚处理方法》

量刑的时候，我们脑子里蹦出来的是"量何种刑"——主刑、附加刑，对吧？但你有没有想过，定罪量刑之后，法院手里其实还有一整套动作没用上。判了刑，不等于事情就结束了：该赔的钱要赔，该禁的生意要禁，该挨的训诫要挨。这一整套"刑法以外的处置"，就是本节要讲的东西。

### 非刑罚处理方法：刑法之外的处置手段

> **定义**：非刑罚处理方法，是指人民法院对犯罪分子适用的、刑法以外的处理方法。

名字起得朴素，理解也就两步。顾名思义，"非"就是"不"——不在刑法里面；"刑罚"就是刑法规定的那些刑罚。所以整个概念就是一句话：**刑法以外的处理方法**。

这里有两个限定词不能丢。

第一，**由人民法院适用**。这是法院手里的牌，不是公安机关的行政处罚、也不是律师协会的行业处分，但后面那两项又确实由主管部门来做——别急，一会儿会说到。

第二，**适用对象依然是犯罪分子**。它不是对一般人适用的普通管理手段，它的前提仍然是"这个人犯了罪"。这就是它被放在"刑罚论"里讨论、而不是放在"行政法"里的原因。

具体包括哪些？判处赔偿经济损失、责令赔偿经济损失、训诫、责令具结悔过、责令赔礼道歉、行政处罚、行政处分、从业禁止，还有一长串专业名词。**其中很多是不需要背的，能理解就可以。**真正要下功夫的是后面那个从业禁止，它是本节乃至整个刑罚论的重点。

先把最根本的边界划清楚：非刑罚处理方法**既不是主刑，也不是附加刑**。刑罚一共就九种，主刑、附加刑两栏摆完就到底了，从业禁止、赔偿损失这些统统不在表内。"非刑罚"这三个字不是文学修饰，是身份声明。

### 判处赔偿经济损失与民事优先原则

先看《刑法》第36条：

> 由于犯罪行为而使被害人遭受经济损失的，对犯罪分子除依法给予刑事处罚外，并应根据情况**判处赔偿经济损失**。

这里立刻有个高频错点。各位，**"判处赔偿经济损失"是刑罚吗？**当然不是。刑罚只有主刑和附加刑那几种，"判"这个字容易让人误会它是判出来的刑罚——它恰恰是**判了刑之后，还要额外判的一笔赔偿**。

举个例子。我把马峰那辆值两万块的摩托车给砸了，构成故意毁坏财物罪。法院不光要给我定罪判刑、判刑期，还要我赔马峰修车的钱。前面那部分是刑罚，后面这一部分是判处赔偿经济损失。两个"判"字长得一样，身份完全不同。

第36条还有第二款，这一条常考：

> 承担民事赔偿责任的犯罪分子，同时被判处罚金，其财产不足以全部支付的，或者被判处没收财产的，**应当先承担对被害人的民事赔偿责任**。

为什么？**因为被害人的损失发生在前，罚金或者没收财产发生在后。** 损失在前、处罚在后，那就先赔被害人。这在理论上叫**民事优先原则**。

> **结论**：财产不足以同时支付罚金（或被没收财产）与赔偿被害人的损失时，先赔被害人。

它背后体现的是一句话：**国家不能与民争利**。本来人家就是被害人，被你的犯罪行为打伤了、损失了，你倒好，刑罚里还要再罚一笔钱，那这笔钱当然先给他。道理就这么朴素。

### 免予刑事处罚之后：六种方法两两成对

第36条讲完了，看第37条：

> 对于犯罪情节轻微不需要判处刑罚的，**可以免予刑事处罚**。

各位停一下，先分清它和第36条的差别，这是本节的第一个岔路口。

- 第36条的前提是"**除依法给予刑事处罚外**"——先定罪判刑，再适用刑法以外的方法，这叫**定罪判刑**；
- 第37条的前提是"犯罪情节轻微，不需要判处刑罚"——定了罪但免了刑，这叫**定罪免刑**。

一个判刑，一个免刑，后面挂上去的东西自然不一样。第37条接着规定：免予刑事处罚的，**根据不同情况**予以训诫、责令具结悔过、赔礼道歉、赔偿损失，或者由主管部门予以行政处罚、行政处分。

六个方法，怎么记？我给你一句口诀：**两两在一起，口头对书面，精神对物质，对外和对内。** 三组配对，十二个字背下来。

| 配对 | 左边 | 右边 |
| --- | --- | --- |
| 形式 | 训诫（口头） | 责令具结悔过（书面） |
| 内容 | 责令赔礼道歉（精神） | 责令赔偿损失（物质） |
| 对象 | 行政处罚（对外） | 行政处分（对内） |

**训诫**是当庭批评。比如张三犯了侮辱罪，但情节轻微、不需要判处刑罚，法官可以认定他构成侮辱罪，但免予刑事处罚，然后当庭训诫他：以后不能这样做了。**训诫就是一句话的口头批评。**

**责令具结悔过**是书面的。大家看古装剧的时候，那个县太爷审案审到最后会说什么？"让他**具结画押**"——那个具结画押，签字，是书面的。所以责令具结悔过就是写个保证书，被告人写个保证书，保证以后不再犯罪，要对自己的罪行进行忏悔。

> **提示**：训诫是口头，责令具结悔过是书面。一句话区分，别把"具结悔过"记成"具结改过"。

**责令赔礼道歉**管的是精神。张三的侮辱罪情节轻微、不需要判处刑罚，但毕竟对李四造成了伤害，法官就可以责令张三向李四赔礼道歉。**赔偿损失**管的是物质，就是赔他点钱。

最后两个是行政色彩的东西。**行政处罚是对外**的：比如警察看到张三闯红灯，交警对张三罚款二十块，这叫行政处罚。**行政处分是对内**的内部追责，处分的是内部工作人员。

六种方法，好记了。而且注意一个原则：**第37条是以定罪免刑为前提的，第36条是以定罪判刑为前提的。**

### 判处赔偿与责令赔偿：一字之差

上面反复出现"判处赔偿经济损失"和"责令赔偿损失"，有同学问：老师，这俩有什么区别？

区别就在"判处"后面跟着"责令"，你把注意力放到"责令"上，就会发现不一样。

**判处赔偿经济损失**，程序上有要求：**被害人要提起刑事附带民事诉讼。** 还是那个例子：我砸了马峰的摩托车，马峰报了警。法院开庭审理的时候，马峰可以提起刑事附带民事诉讼，举证我这辆摩托车值多少钱，请求法院作出判决。法官在对我定罪量刑之外，判处我赔偿马峰的财产损失。**被害人得自己提出来。**

**责令赔偿损失**则不要求被害人提起附带民事诉讼。**这个责令是法官以职权作出来的**——法官有权这么做，即使被害人没有提出来，法官也可以根据案件的具体情况，责令被告人赔偿被害人一部分损失。

> **结论**：**判处赔偿经济损失**针对被**定罪判刑**的犯罪分子；**责令赔偿损失**针对被**定罪免刑**的犯罪分子。前者靠被害人的附带民事诉讼，后者靠法官职权。

一个要被害人自己开口，一个法官主动替被害人主张；一个前提是判了刑，一个前提是免了刑。四个区别，够用了。

至于训诫、责令具结悔过、责令赔礼道歉、行政处罚与行政处分，书上是我自己写的，考试分析连解释都没有，就不往深里挖了。

### 从业禁止：非刑罚处理方法里最重的一味药

到了从业禁止，情况就不一样了。**它又称职业禁止，是非刑罚处理方法里面最重要的一个。**请看法条：

> 因**利用职业便利**实施犯罪，或者实施**违背特定义务的犯罪**（职业要求的特定义务），犯罪被判处刑罚的，人民法院可以根据犯罪情况和预防再犯罪的需要，禁止其**自刑罚执行完毕或者假释之日起**，从事特定的职业，**期限为三至五年**。

#### 适用条件：所犯之罪必须与职业有关

先抓条件。既然"被判处刑罚"，就说明**从业禁止以定罪判刑为前提**。

更要紧的是"利用职业便利实施犯罪"和"实施违背职业要求的特定义务的犯罪"这两个限定。它们合起来说明一件事：**他所犯之罪，一定和自己的职业是有关系的。**

全国首例发生在南京。一个中学的老师利用业余时间给孩子补课，在补课的时候实施了猥亵儿童的行为，家长根据监控发现了，报案，认定这个老师构成猥亵儿童罪，判处五年有期徒刑，同时从业禁止三年。

各位注意这里头的层次：他在监狱要服刑五年；判决书上写的禁止期是"自**刑罚执行完毕**，也就是有期徒刑执行完毕或者假释之日起，从事婴幼儿、儿童的教育辅导工作"。他其实是被从业禁止了八年。

为什么？因为他在监狱服刑那五年，怎么可能去从事婴幼儿、儿童的教育辅导工作？他只能辅导犯人，不可能。所以等他出狱以后，还要再从业禁止三年，通常是三到五年。

**职业便利的范围，比职务便利要大。**我们整个刑法的职务犯罪，像贪污罪、受贿罪，都是"利用**职务**上的便利"；而职务上的便利只是一种**权利**——它要求你在这个位置上才有的便利。**职业便利**的范围更广，它可以包含职务上的便利，但还不止于此，比如他**更容易接触某个人**，这也是职业便利。

> **易错点**：适用从业禁止要求"利用职业便利"或"违背职业要求的特定义务"，不是"利用职务上的便利"。这两个词的范围不一样。

#### 期限、违反后果与"从其规定"

期限通常是**三到五年**，自**刑罚执行完毕之日或者假释之日起**计算。

这里必须插一句极其重要的提醒，因为它是选择题的经典陷阱。

> **易错点**：如果有个选项说"从业禁止的期限**一律**为三到五年"或者"**均为**三到五年"，**错**。

因为法条第三款还规定：**其他法律、行政法规对其从事相关职业另有禁止或者限制性规定的，从其规定。**言下之意——听清楚了——其他的法律有可能对从业禁止的要求**更严格**。比如食品安全法可以把一个人从业禁止十年，证券法可以从业禁止终身，律师法也是如此。

所以准确的说法是：**从业禁止通常是三到五年，但其他法律另有规定的，要按照规定来处理。**

违反从业禁止的后果，看第二款：被禁止从事相关职业的人，违反法院依照前款作出的决定的，**由公安机关依法给予处罚**（通常是指行政处罚）；但**情节严重的，依照《刑法》第313条的规定定罪处罚**——313是**拒不执行判决、裁定罪**。

为什么能扯上这个罪？各位想想：**从业禁止是写在判决书里的。**如果张三违反了从业禁止，意味着他没有履行判决书要求的义务，那就属于情节严重，可以构成拒不执行判决、裁定罪。

把法条合起来，业禁止的概念就完整了：

> **定义**：从业禁止（职业禁止），是指人民法院对因利用职业便利实施犯罪、或者实施违背职业要求的特定义务的犯罪而被判处刑罚的人，根据犯罪情况和预防再犯罪的需要，禁止其在一定期限内从事相关职业。

从性质上看，它**既不是主刑，也不是附加刑**，只是一种非刑罚的处罚措施；适用的前提是**刑罚执行完毕或者假释以后，仍然有必要预防其再次犯罪**。

### 人身自由之日起：禁止令、剥夺政治权利与从业禁止

前面讲了从业禁止从"刑罚执行完毕之日或者假释之日起"算。为什么是"假释之日"，不是"假释期满之日"？这个问题一旦想通，好几个制度的起算点就全通了。

各位，请注意它背后的潜在逻辑。我们可以问自己三个问题：

- 一个人在**什么时候**有可能违反禁止令的内容？
- 在**什么时候**有可能去行使政治权利？
- 在**什么时候**有可能去**重操旧业**？

答案是同一个：**有人身自由的时候。**只要他有人身自由，就可能违反禁止令、就可能去行使政治权利、就可能重操旧业。**抓一个点，所有的问题都解决了。**

我们刑法里恰好有三套制度的期限都跟着这个点走。

**第一套是禁止令。**《刑法》第37条第3款：对于被判处管制的犯罪分子，人民法院根据犯罪情况，可以**同时**禁止在执行期间从事特定活动、进入特定区域场所、接触特定的人。管制犯有人身自由吗？有——**他本来就没有被羁押，他只是被限制自由。**所以法条才写"**同时决定**"。今天开始执行管制的刑期，今天就开始执行禁止令的内容，同时执行；**不是说先把管制执行完毕，然后再去执行禁止令**，那就有问题了。禁止令的期限不能少于三个月。

**第二套是剥夺政治权利。**一个人有人身自由的时候，就有可能去行使政治权利。所以有期徒刑如果附加剥夺政治权利，**剥夺政治权利的刑期从这个人有人身自由之日起开始计算**。他的人身自由无非通过两种途径恢复：一是刑罚执行完毕，二是假释（提前释放）。

举个例子：判处五年有期徒刑，附加剥夺政治权利两年，结果在监狱执行了四年，因为表现好被提前释放，这叫假释。那剥夺政治权利的**两年，就从假释之日起开始计算**。这就是为什么法条规定的是"自**有期徒刑执行完毕或者假释之日起**计算"。

**第三套就是从业禁止。**有人身自由，就有可能重操旧业，所以从业禁止同样是自**刑罚执行完毕之日或者假释之日起**计算。

> **提示**：这里说的"刑罚"指的是**主刑**，不包括附加刑。为什么？因为只有主刑才可能剥夺自由，附加刑不会剥夺自由。**被假释的，自假释之日起计算，不是自假释期满之日起计算。**

所以法理可以一句话说完：**有人身自由之日起，就要执行禁止令的内容、就要执行剥夺政治权利的内容、就要执行从业禁止的内容。**

```text
  管制犯（人身自由始终未被剥夺）        监禁犯（人身自由一度被剥夺）
  ├──────────────────────▶        ├──── 在监狱服刑 ────┤ 执行完毕 / 假释 ├──────▶
  │                                  │        │
  ├ 禁止令（不少于 3 个月）            │        └── 人身自由恢复，从这一天起：
  │   与管制刑期同一天开始             │              · 剥夺政治权利（附加的 N 年）
  │                                   │              · 从业禁止（3 至 5 年）
  └ （缓刑犯：与缓刑考验期同日起，       │
     不得少于 2 个月）                   └── 服刑期间谈这些毫无意义：人都不自由，
                                            谈不上违反，也谈不上重操旧业
```

### 从业禁止与禁止令：五个维度上的差别

有同学问：老师，那禁止令和从业禁止到底啥关系？这一节是本讲最后一块拼图，也是最容易混的地方。法条是分开写的，法理上是同一个源头，但**适用对象、内容、时间、目的、违反后果，五个维度都不一样。**

| 对比维度 | 从业禁止 | 禁止令 |
| --- | --- | --- |
| 适用对象 | 利用职业便利实施犯罪，或者实施违背职业要求的特定义务的犯罪，被判处刑罚的人 | 无特别要求。管制犯、缓刑犯都可以，但因何罪被判处管制、被宣告缓刑**不受限制** |
| 禁止内容 | 禁止从事**相关职业** | 范围更宽：禁止从事特定**活动**、进入特定**区域场所**、接触特定的**人** |
| 时间与期限 | 刑罚执行完毕之日或假释之日起算，通常 **3 至 5 年**；其他法律另有规定的从其规定 | **刑罚执行期间同时执行**，可与管制执行期、缓刑考验期相同，也可更短；管制不得少于 **3 个月**，缓刑不得少于 **2 个月** |
| 目的 | 防止刑罚执行完毕或假释后**利用职业便利再次犯罪** | 促进犯罪分子在执行期间的**教育矫正**，维护社会秩序 |
| 违反后果 | 公安机关给予处罚；情节严重构成**拒不执行判决、裁定罪** | 由公安机关给予**治安处罚**；缓刑犯违反禁止令且情节严重的，**撤销缓刑、执行原判刑罚**（这一条讲缓刑时再展开） |

**内容**这一行差别最明显：从业禁止只管"职业"这一个维度，禁止令管的是"活动、区域场所、人"三个维度，所以禁止令的内容更宽。

**目的**这一行也值得多想一层：从业禁止是"出去以后别重操旧业"，禁止令是"在里面老实接受教育矫正"。

至于"违反后果"里的缓刑犯撤销缓刑，这个是后面的知识点，刑法论讲到缓刑的时候会讲，现在听不懂没关系。

那这张表要不要现在背？**不要。能听懂就可以了。**到背诵课的时候，我带着你们背。而且这些东西不是死记硬背的，它是有规律、有方法的，现在没法讲——如果讲的话，就把我们一阶段的理解课和背诵课串在一起了，那就不知道什么时候才讲完，也讲不完，效果还不好。**没到背诵的时候不要背诵，分阶段完成任务，现在能听懂就不错了。**

### 收尾：定罪之后，还有两类人和八种手段

非刑罚处理方法讲完了，回归我们这个板块的主线：量刑，量何种刑及其关联问题。

**定罪量刑之后，量什么刑——主刑、附加刑，这是第一条线。**

**除了定罪量刑以外，还有可能适用非刑罚处理方法，这是第二条线。**这两条线合起来，就是量刑环节的完整工具箱。

最后把对象这一点再钉一遍，因为它是最容易被忽略、也最容易出选项的地方。

```text
                        非刑罚处理方法
                              │
          ┌───────────────────┴───────────────────┐
          │                                       │
   定罪判刑（已判处刑罚）               定罪免刑（免予刑事处罚）
      第36条 ＋  从业禁止                       第37条
          │                                       │
    ┌─────┴─────┐                    ┌──────┬──────┬──────┬──────┬──────┬──────┐
    │           │                    │      │      │      │      │      │      │
  判处赔偿  从业禁止              训诫  责令    责令    责令    行政   行政
  经济损失                      口头  具结    赔礼    赔偿    处罚   处分
    │                             /      悔过    道歉    损失    对外   对内
   对外                            书面    精神     物质
                                          赔礼    赔偿
```

**第一类人，被定罪判刑的犯罪分子。**对他适用非刑罚处理方法只有两种：要么是**判处赔偿经济损失**，要么是**从业禁止**。

**第二类人，被定罪免刑的犯罪分子。**对他适用的非刑罚处理方法有六种：口头对书面（训诫、责令具结悔过）、精神对物质（责令赔礼道歉、责令赔偿损失）、对外对内（行政处罚、行政处分）。

**重中之重是从业禁止。**期限三到五年，其他法律另有规定的从其规定；它**既非主刑，也非附加刑**，而是非刑罚处理方法；从哪一天开始执行？**有人身自由之日起**，也就是自刑罚执行完毕之日或者假释之日起执行。

到这里，我们刑法论的第一个板块——量刑，量何种刑及其关联问题——就全部讲完了。

按照我们的体系框架，量刑量何种刑还不够，接下来还要继续往后推进：作为一个法官，你不光要知道量刑可以量何种刑、有哪些非刑罚处理方法，**第二步你还要知道哪些情节会影响量刑轻重**。这正是我们接下来要进入的量刑情节问题。
