### 量刑的概念：定罪之后，一串首尾相接的决定

先把定义说清楚。量刑，又称刑罚裁量。

这个概念的原句很长，但它是递进的，不是并列的。拆开看：

> 量刑是指人民法院根据刑事法律，在认定犯罪人构成犯罪的基础上，确定对犯罪人是否判处刑罚、判处何种刑罚、判处多重的刑罚，并决定对所判刑罚是否立即执行的刑事司法活动。

定罪和量刑的关系大家都熟——定罪以后才能量刑。所以量刑的落脚点永远在"认定构成犯罪"之后，是一串接一串的决定：

```text
   犯罪事实 -> [认定构成犯罪] -> 是否判处刑罚
                                       |
                          +------------+------------+
                          |                         |
                     判（定罪量刑）            不判（定罪免刑）
                          |
                          v
                 判处何种刑罚（主刑 / 附加刑）
                          |
                          v
                 判处多重刑罚（判几年有期徒刑）
                          |
                          v
                 是否立即执行？
                    /            \
             立即执行           不立即执行
            交付执行          宣告缓刑 + 考验期
```

第一步，定的是"判不判"。这一步分岔：判，就是定罪量刑，也就是定罪判刑；不判，就是定罪免刑。

第二步，既然判了，那就得定"判哪一种"，是主刑还是附加刑，比如判有期徒刑。

第三步，定了种类，还得定"判多重"——如果判的是有期徒刑，到底判几年。

第四步，刑期定了，最后还要决定"是不是马上执行"。马上执行就交付执行；不马上执行，就宣告缓刑、设考验期。

概念本身讲完了，但概念里藏着的比概念更有用。

### 量刑的特征与功能：法院、刑罚，以及那座桥

先看特征。特征不用背，是从概念里直接抄出来的，三条：

- **主体只能是人民法院**。只有法院才有权力定罪判刑。
- **内容是对犯罪人确定刑罚**。
- **性质是一种刑事司法活动**。

再看功能。功能那一栏，概念抄完之后只补了一句话，而这一句才是重点：

> **结论**：量刑作为刑事司法活动，是使法定的罪刑关系变成实在的罪刑关系的必要条件，在整个刑事诉讼过程中起着承前启后的重要作用。

这句话听着抽象，我们用最容易懂的那个例子把它拆开。

张三犯了普通抢劫罪。翻开法条，法定刑是"三年以上十年以下"。这个"三年以上十年以下"，就是法律规定的罪和刑的关系——罪是抢劫罪，刑是三年以上十年以下。这叫**法定的罪刑关系**。

可法条只规定了一个区间，它没告诉我们张三到底判几年。最低三年、最高十年，我们只能在这个区间里选。要选，就必须经过量刑。

量刑之后作出判决：张三犯抢劫罪，处五年有期徒刑，并处罚金。这"五年有期徒刑"就是**实在的罪刑关系**——实实在在的张三要去服的那个刑期。

```text
   抢劫罪：三年以上十年以下
        |
        |   法定的罪刑关系 —— 纸面刑，写在法条里
        |
        |   量刑
        v
   张三：处五年有期徒刑，并处罚金
        |
        |   实在的罪刑关系 —— 张三实际要服的那五年
```

再说"承前启后"。前是什么？前是定罪。启的是什么？启的是刑罚的执行。

```text
   定罪 ---> 量刑 ---> 交付执行 ---> 减刑、假释 ---> 刑罚消灭
             (承前)     (启后)
```

量刑判了五年，才能把这五年交给监狱去执行；交付执行了，才有后面减刑、假释的问题。所以量刑在整条链子上是卡口，上承定罪，下启执行。

> **提示**：这个点听懂了，整个量刑的地位就清楚了。法条给的是区间，量刑给的是具体刑期；没有量刑，罪刑关系永远停在纸面上。

到这里，量刑是什么已经解决了——它是一种刑事司法活动。下面进入量刑的原则。

### 两条准绳：以事实为根据，以法律为准绳

看第61条：

> 对于犯罪分子决定刑罚的时候，应当根据犯罪的事实、性质、情节和对于社会的危害程度，依照本法的有关规定判处。

这句话在罪责刑相适应原则那里已经讲过。正是因为讲过，我们现在可以在这里划一刀竖杠，把这句话劈成两半：

```text
   对于犯罪分子决定刑罚的时候，应当
   |
   +-- 根据犯罪的事实、性质、情节和对于社会的危害程度
   |        = 以犯罪事实为根据
   |
   +-- 依照本法的有关规定判处
            = 以法律为准绳
```

所以量刑原则可以简化为八个字：**以事实为根据，以法律为准绳**。这个阶段记住这两句就够了。

先说以犯罪事实为根据。为什么要强调它？看书：犯罪事实是产生刑事责任的基础，也是对犯罪人量刑的根据。

链条是这样的：有了犯罪事实才能构成犯罪，构成犯罪才能量刑。如果没有犯罪事实，就没有刑事责任，更不可能对犯罪人裁量刑罚。所以量刑必须以犯罪事实为根据。

再说以法律为准绳，这同时也是罪刑法定原则的要求。

"法律"指什么？刑事法律无非是总则和分则。问自己：要不要遵守总则的规定？当然要；要不要遵守分则的规定？也要。翻开刑事法律抬头一看，无非是这两块。

于是拆出三条具体要求：

- **其一，必须依照刑法关于各种刑罚方法的适用条件和各种刑罚裁量制度的规定**。比如刑法规定了累犯、自首、立功、坦白，符合条件当宽则宽、当严则严，这些规定你必须遵守。
- **其二，必须按照刑法关于各种量刑情节的适用原则和各种量刑情节的规定**。比如总则规定未成年人犯罪应当从轻或者减轻处罚，分则里有那么多罪名，只要犯罪主体是未成年人——比如一个十七岁的人，不管犯的是哪一个罪，都要按总则这一条办。既守总则，也守分则。
- **其三，必须依照刑法分则和其他刑法规范（如单行刑法）所规定的法定刑量刑幅度**，针对具体犯罪选择判处适当的刑罚。刑法规定犯某罪处三年以上十年以下，这明显是分则的规定。量刑时就只能在三年以上十年以下这个框里，除非有特殊情况。

> **提示**：这三条理解就行，现在别背。到背诵阶段再记，考场上要的是你真懂，不是你记得住字。

### 量刑情节：它管轻重，不管定罪

铺垫该做的都做完了，进入量刑情节。

> **定义**：量刑情节，又称刑罚裁量情节，指人民法院对犯罪分子裁量刑罚时（也就是量刑时），应当考虑的、据以决定量刑轻重或者免除处罚的各种情况。

一句话概括：量刑情节就是各种情况，但这个"各种情况"要加两个定语——**人民法院应当考虑的**、**影响刑罚轻重或者免除处罚的**。

再说特征。特征同样是从概念里拆出来的，三条。

第一条最反直觉，也最容易被考：**量刑情节与定罪没有关系**。

怎么理解？抬头看，定罪以后才能量刑，这就意味着量刑情节不能影响定罪。换句话说，即使完全不考虑这个量刑情节，行为人也成立犯罪；只有在成立犯罪的基础上，才能单独讨论这个情节。

再换一种说法：一个情节不能既在定罪中评价一次，又在量刑中评价一次。定罪评价过了，量刑再评价一遍，这就叫重复评价。检验办法很干脆——把所谓的量刑情节先拿掉，拿掉之后剩下的事实还能构成犯罪，它才是量刑情节；拿掉之后构不成犯罪，它就是定罪条件。

来看一个特别典型的对比。

报复陷害罪（第254条）：国家机关工作人员滥用职权、假公济私，对诉讼人、控告人、申诉人、批评人、举报人实行报复陷害的，处二年以下有期徒刑或者拘役；情节严重的，处二年以上七年以下有期徒刑。

请注意：即使没有达到"情节严重"的程度，它也能构成基本犯。所以"情节严重"不是犯罪成立的条件，它就是一个量刑情节。

再看侮辱罪、诽谤罪：以暴力或者其他方法公有人侮辱他人或者捏造事实诽谤他人，情节严重的，处三年以下有期徒刑、拘役或者管制。

这里的"情节严重"非常明显是成立条件，是构成犯罪的条件。你不能说它同时又是量刑情节——你要是这么说，就是承认一个情节在定罪里评价了一次、在量刑里又评价一次。

> **易错点**：所谓量刑情节，一定和定罪没有关系。凡是拿掉之后行为人就构不成犯罪的，那它是定罪条件，不是量刑情节。

第二条：**对量刑结果，也就是处刑轻重或者是否免除处罚，具有直接影响**。

比如张三构成犯罪中止，没有造成损害，就应当免除处罚——"犯罪中止"就是非常重要的量刑情节，它直接决定张三会不会去坐牢。

第三条：既然涉及刑罚轻重，背后必然和罪责刑相适应原则挂钩。凡是能影响刑罚轻重的情节，都表明了**犯罪人的人身危险性和社会危害性**。

> **提示**：三条特征的关系是：第一条划边界（不属于定罪），第二条讲作用（直接影响结果），第三条讲机理（背后是人身危险性与社会危害性）。

### 法定情节与酌定情节：怎么来的，怎么用

量刑情节的第一个分类标准，是刑法有没有明文规定。据此分成法定情节和酌定情节。

这两个概念听起来有点绕，其实不难。你抬头看我，问自己两个问题就全出来了：

1. 这个情节**怎么来的**？
2. 这个情节**怎么用**？

| | 怎么来的 | 怎么用 |
| --- | --- | --- |
| 法定情节 | 刑法明文规定的 | 量刑时**应当**予以考虑的情节 |
| 酌定情节 | 人民法院从审判经验中总结出来的 | 量刑时**灵活掌握、酌情适用**的情节 |

法定情节好办：既然是刑法明文规定的，那怎么用？既然法条写了，量刑的时候就**必须考虑**，是"应当考虑"的情节。

酌定情节想反着想：既然它一定不是刑法明文规定的，那它就是法院从审判经验里总结出来的；那怎么用？不是"应当"，是**灵活掌握、酌情适用**，这八个字要记牢。

法定与酌定的界限到此就清楚了。往下我们集中讨论法定情节，酌定情节放在后面单独讲。

法定情节本身还可以再分类。第一个标准是**规定法定情节的刑法规范的性质以及法定情节的适用范围**。

刑法规范的性质无非两种：总则规范或者分则规范。总则规范管全局，适用范围当然广；分则规范针对具体罪名，范围就窄。

于是有了这一对概念：

| | 来源 | 适用范围 |
| --- | --- | --- |
| 总则性情节 | 刑法总则规定 | 对各种犯罪共同适用 |
| 分则性情节 | 刑法分则规定 | 对特定犯罪适用 |

具体说。总则性情节，像中止犯规定在总则，未成年人犯罪应当从宽处罚也规定在总则——分则里有那么多罪名，只要犯罪主体是个未成年人，他就必然适用总则关于未成年人犯罪的规定：对已满十四周岁不满十八周岁的人犯罪，应当从轻或者减轻处罚。这就是"对各种犯罪共同适用"。

自首也在总则。立法规定对自首的犯罪分子可以从轻或者减轻处罚，其中犯罪较轻的可以免除处罚。分则那么多罪，只要犯罪以后自首，都要适用总则关于自首的规定。

分则性情节，举第386条：索贿的从重处罚。这个规定只针对受贿罪，所以它是分则性情节。

> **提示**：请务必注意。索贿从重只针对受贿罪，不是所有罪都有这条。

第二个标准是**功能**。按功能，法定情节分为从重处罚、从轻处罚、减轻处罚、免除处罚四种。

总则性、分则性这两个概念，认个脸熟就够了；按功能分的这四种，是接下来的重头戏。

### 从重与从轻：法定刑以内，天花板和地板都在

先看第62条：

> 犯罪分子具有本法规定的从重、从轻处罚情节，应当在法定刑的限度以内判处刑罚。

那么问题来了：什么叫"限度以内"？第99条又规定，本法所称以上、以下、以内包括本数。

也就是说，"以内"是含本数的。举张三犯A罪，法定刑三年以上十年以下。具有从重情节或者从轻情节，都应当在这个限度以内判刑——限度以内，最低三年，最高十年，含本数。

- 如果有从轻处罚情节，最低也不能低于三年，可以判到三年整。
- 如果有从重处罚情节，最高也只能到十年整，不能突破十年。

那"从重处罚"到底是什么？原句是这样的：

> 从重处罚，是指在法定刑幅度内选择判处比没有该情节的类似犯罪相对较重的刑种或刑期。

这是个典型的汉语长难句。断句的技巧我教你们，很实用：**先把它划掉**。

我先说一句原话——你们千万不要把它给划掉。我把它划掉，一会儿我还有橡皮擦，可以把它擦掉。你看是这样的，先把它划掉，划掉之后你读一遍，看通顺吗？

```text
   原句：
   从重处罚是指在法定刑幅度内选择判处
   比没有该情节的类似犯罪  相对较重的刑种或刑期
                |______________|
                   先划掉这一截

   划掉之后读一遍：
   从重处罚是指在法定刑幅度内选择判处相对较重的刑种或刑期
                                          -> 通顺

   再把那一截请回来，追问一句：
   "较重"是和谁比？
   -> 和"没有该情节的类似犯罪"比
```

所以完整的理解是：从重处罚，指在法定刑幅度内，选择判处**比没有该情节的类似犯罪**相对较重的刑种或刑期。较重的参照物，就是那些没有这类情节的同类犯罪。

来一个具体例子。甲和乙两个人构成共同犯罪，作用一样，分赃数额一样，正常情况下的量刑也一样。经调查发现甲是累犯，立法规定对累犯应当从重处罚。

原本判甲一年、判乙一年，他俩完全相等。现在甲是累犯，乙不是，甲就具有了从重处罚情节。所以量刑结果不能再是一年，考虑累犯因素，比如给甲判一年两个月——这就是相对较重的刑种或刑期。

从重处罚一理解，从轻处罚就简单了：**在法定刑幅度内选择判处比没有该情节的类似犯罪相对较轻的刑种或刑期**。

> **结论**：从重、从轻都不能突破幅度。它有天花板（法定最高刑），也有地板（法定最低刑）。

既然是"幅度内"，这里还有两个容易被绕进去的问题。

**第一个问题：法定刑幅度怎么找？**

法定刑幅度，指的是**与具体犯罪相适应的那个法定刑幅度**。你不要乱找，因为有些犯罪规定的法定刑幅度不止一个，可能两个甚至三个。

以诈骗罪为例，它规定了三档，也就是三档法定刑：

- 第一档，诈骗数额较大，处三年以下有期徒刑；
- 第二档，数额巨大，处三年以上十年以下有期徒刑；
- 第三档，数额特别巨大，处十年以上有期徒刑或者无期徒刑。

如果甲诈骗数额巨大，他对应的是第二档，第二档就是他的法定刑幅度。这时候对他从重、从轻，最低不能低于三，最高不能高于十，只能在 3 到 10 里挑。

> **结论**：如果一个罪规定有数个量刑幅度，你要找的是犯罪行为**应当适用的**、与之对应的那一个幅度，不能从轻就挑最低那档、从重就挑最高那档。

**第二个问题是个命题陷阱，一定要注意：从重处罚、从轻处罚，跟法定刑幅度的中间线没有任何关系。**

看这张图：

```text
   法定刑幅度：三年以上十年以下有期徒刑

   3 年 |----------------------------------------| 10 年
        <------------- 6.5 年 ------------------>
             所谓"中间线"：纯属想当然

   判 3 年 6 个月  ->  完全可能是从重
   判 9 年          ->  完全可能是从轻
```

有人会说，从重一定是在中间线以上那半段，从轻一定是在中间线以下那半段。这是胡扯，这种观点一定是错的，它和中间线一点关系都没有。

举个例子。甲犯盗窃罪，按照他的犯罪事实、性质、情节、数额，正常情况下判三年就行了。但甲具有累犯情节，考虑累犯判了三年六个月。这三年六个月已经是从重了，哪怕它还没到那条所谓的中间线。

反过来，乙正常情况下要判十年，但他自首了。自首是可以从宽处罚的，考虑自首情节判了九年六个月。九年六个月都快到顶了，但它仍然是**从轻处罚**。

书上的例子也是同一个道理：甲所犯之罪为三年以上十年以下，根据甲的事实应当判三年，若甲还具有累犯情节，对其判了四年，这就是从重；甲所犯之罪法定刑三到十年，根据事实应当判八年，但考虑其自首情节判了七年，这就是从轻。

> **易错点**：从重与从轻是"与同类案件相比"，不是"与那条中间线相比"。

### 减轻处罚：法定刑之下

从重从轻讲完了，轮到减轻。减轻是这一块里最绕的，也是最容易出错的地方。看第63条：

> 犯罪分子具有本法规定的减轻处罚情节的，应当在法定刑以下判处刑罚；本法规定有数个量刑幅度的，应当在法定刑幅度的下一个量刑幅度内判处刑罚。
>
> 犯罪分子虽然不具有本法规定的减轻处罚情节，但是根据案件的特殊情况，经最高人民法院核准，也可以在法定刑以下判处刑罚。

先说为什么核准权在最高人民法院。因为这是量刑问题，特殊情况就得找最高法。

言下之意很清楚：第一款是一档一档地向下减，不能跨档减刑。

#### 两种减轻：法条写明的，和特殊情况核准的

把法条两款一分，两种减轻处罚就出来了。

**第一款**：犯罪分子具有本法规定的减轻处罚情节 → **法定减轻处罚情节**，又称**一般减轻**。指刑法明文规定的减轻处罚情节。

举两个例子。总则规定防卫过当应当负刑事责任，但应当减轻或者免除处罚——如果我们选择"应当减轻处罚"，这就是法定的减轻处罚情节。还有，对于造成损害的中止犯，应当减轻处罚，这也有法律明文依据。此外，第27条规定的从犯、第28条规定的胁从犯，都包含着减轻处罚情节。

**第二款**：犯罪分子不具有法定减轻情节，但案件有特殊情况，经最高人民法院核准 → **酌定减轻处罚情节**，又称**特殊减轻**。它之所以成立，是因为刑法缺乏明文规定，但案件又有特殊情况。

它的适用条件其实就是把法条拆开重说一遍，三条：

1. 犯罪分子不具有法定减轻处罚情节；
2. 案件有特殊情况；
3. 经最高人民法院核准。

#### 减轻的边界：法定最低刑、不能跨档、刑种与刑期

接下来讲两种减轻处罚的共性。这是重点，一共四条。

**第一条，也是最关键的一条：减轻处罚是在法定刑以下判处刑罚，"以下"必须理解成"之下"，必须判处低于法定最低刑的刑罚。**

为什么这里要较真？看诈骗罪（第266条）：数额较大，三年以下；数额巨大，三年以上十年以下；数额特别巨大，十年以上或者无期徒刑。

假设张三诈骗数额巨大，他的法定刑幅度原本是三年以上十年以下。假如他具有减轻处罚情节，就要在这三年以下判处刑罚——最高也不能到三年整。

这里有同学要问了：老师，你刚讲第99条说"以上、以下、以内包括本数"，那减轻处罚的"以下"是不是也包括本数？

你能想到这一点，非常好。这恰恰说明刑法的用语在这里有瑕疵。那怎么处理？看第215页最下面那段话：

> 减轻处罚不能判处法定最低刑，只能在法定最低刑之下判处刑罚。虽然刑法规定本法所称以上、以下、以内包括本数，但是减轻处罚中的"以下"不能包括本数。

我们做个笔记，一起来分析就明白了：

```text
   法定刑幅度：三年以上十年以下

   从轻处罚：法定刑"以内"  ->  以内含本数  ->  可以判 3 年整

   减轻处罚：法定刑"以下"  ->  以下若也含本数  ->  最高也能判 3 年整
                                          |
                                          v
                              从轻与减轻在 "3 年整" 处撞车
                                          |
                                          v
                              判 3 年整，到底是从轻还是减轻？
                                          |
                                          v
                              补正解释：把"以下"解释为"之下"
```

这个"撞车"的后果很具体。你想想看，如果减轻处罚也能判出三年整，会发生什么：你在法庭上对被告人讲，"你具有从轻处罚情节，最低按法律规定可以判你三年整。但本院决定优待你一点，对你减轻处罚——减轻处罚是在法定刑以下判处刑罚，那我也可以判你三年整。"你对他是既从轻又减轻。

这不成了吗？所以不能让"以下"包括三年整。一旦判到三年整，只能认为这是从轻处罚，不能认为这是减轻处罚。比如判两年九个月、两年十个月，都可以，只要不到三这个数字，那就都是减轻处罚。

这就叫**补正解释**——小修小补，把法条用语的正确含义表达出来。

回到诈骗罪：数额巨大，量刑幅度三年以上十年以下。张三有从轻处罚情节，判三年整，这是从轻处罚。张三有减轻处罚情节，把"以下"解释为"之下"，就是三年之下判处刑罚，只能判两年十个月、十一个月。凡是不到三年这个数字的，才是减轻处罚。

还有一个例子：甲故意重伤乙，法定刑三年以上十年以下。如果甲具有减轻处罚情节，对其判处的刑罚必须低于三年。假如真判了三年整，就意味着减轻处罚和从轻处罚产生混淆了。

> **结论**："从轻"是"以内"（含本数），可以压到法定最低刑整；"减轻"是"之下"（不含本数），必须低于法定最低刑。判到法定最低刑整，只能叫从轻。

**第二条：法定最低刑怎么找？**

法定最低刑，是指与行为人所实施的特定具体犯罪相适应的量刑幅度的最低刑。

这句确实有点拗口，但说白了就是：考虑他的犯罪事实，找到他对应的那一个量刑幅度，那个幅度的最低刑就是法定最低刑。

比如过失致人死亡罪规定了两档法定刑：第一档三年以上七年以下，第二档三年以下有期徒刑。如果甲的犯罪事实应当适用第一档，那法定最低刑就是第一档的最低刑，也就是三年有期徒刑。所以甲如果有减轻处罚情节，判的刑罚必须低于三年。

**第三条：减轻处罚只能在法定量刑幅度的下一个量刑幅度内判处刑罚，不能跨档。**

还是诈骗罪的三档。第一档数额较大三年以下，第二档数额巨大三年到十年，第三档数额特别巨大十年以上直至无期徒刑。

如果甲诈骗数额特别巨大，他的行为对应第三档。假如甲具有减轻处罚情节，只能在下一个量刑幅度内判——下一个是第二档，三年以上十年以下。

你可千万不要从第三档直接跨过第二档减到第一档，判到三年以下。那是不允许的。

要是不直观，我们看法条那张 PPT 就更清楚：甲因为诈骗数额特别巨大，量刑幅度是十年以上直至无期，法定最低刑就是十年。他有减轻处罚情节，只能在下一个幅度里判，也就是第二档，而且不能到十年整。你不能从第三档十年以上直接越过第二档减到第一档判他两年——那法律就没有稳定性了，权力也太大了。

所以立法上明文规定**只能逐档减轻**：从第三档减到第二档行，从第二档减到第一档行；从第三档直接跨到第一档，不行。

> **提示**：这些理解就行，千万别背。从主观题角度不可能这么考，主要是理解，好做选择题。

**第四条：减轻处罚既包括刑种的减轻，也包括刑期的减轻。**

两种减轻处罚情节（法定的和酌定的），只要符合条件，都可以减轻刑种或者减轻刑期。

看刑种减轻的例子。立法规定犯绑架罪杀害被绑架人的，处无期徒刑或者死刑，并处罚金或者没收财产。假设根据甲的犯罪事实，对甲应当判处无期徒刑，可甲有减轻处罚情节，怎么办？减轻处罚是在法定刑以下判处刑罚，无期徒刑以下不能包括无期徒刑——你不能说"从无期徒刑减轻处罚到无期徒刑"吧？所以这时候只能变更刑种，改判有期徒刑。这属于刑种的减轻。

刑期减轻的例子。诈骗罪数额特别巨大是十年以上有期徒刑到无期徒刑。假如张三诈骗数额特别巨大，根据他的犯罪事实本应判十五年有期徒刑，但他有减轻处罚情节，那只能在下一个量刑幅度里判——下一个是三年以上十年以下。假如判了九年，这就是减轻处罚，而且是刑期的减轻：原本十五年，现在九年，刑种没变，都是有期徒刑，只不过刑期缩短了。

书上的例二原理相同。第232条故意杀人罪：处死刑、无期徒刑或者十年以上有期徒刑；情节较轻的，处三年以上十年以下有期徒刑。如果根据甲的犯罪事实本应判十五年有期徒刑，但他有减轻处罚情节，那就要在法定量刑幅度的下一个量刑幅度内判处刑罚，在十年以下。此时只能在三年以上十年以下这个幅度内判，而且不能包括十年整。判出来的还是有期徒刑，所以这只是刑期的减轻。

至此，减轻处罚就搞定了。回头收个尾，问大家一个问题：减轻处罚有几种？两种。

- **法定减轻处罚**：犯罪分子具有本法规定的减轻处罚情节，应在法定刑以下判处刑罚，"以下"补正解释为"之下"；本法规定有数个量刑幅度的，应在法定量刑幅度的下一个量刑幅度内判处刑罚，不能跨档。
- **酌定减轻处罚**：犯罪分子不具有法定减轻情节，但根据案件特殊情况经最高人民法院核准，也可以在法定刑以下判处刑罚。

共性还是那四条：在法定刑之下（之下不含本数）；法定最低刑是与具体犯罪相适应的那个幅度的最低刑；只能降到下一个幅度，不能跨档；既可减刑种，也可减刑期。还有一句要记牢：所谓"在法定刑以下"，指的是这个犯罪所对应的那一个量刑幅度，找到之后在其最低刑以下判刑；**别去管中间线，跟中间线一点关系都没有**。

### 免除处罚：定罪而不判刑

按功能分类的第四种法定情节，免除处罚。这个简单。

免除处罚就是定罪免刑：对犯罪人作有罪宣告，同时决定免除刑罚处罚。

为什么要免除？因为有的情形是立法规定的，比如中止犯没有造成损害的，应当免除处罚；再比如胁从犯，应当按照他的犯罪情节减轻处罚或者免除处罚——它也包含着免除处罚。

免除处罚的适用条件有三条：

1. 已经构成犯罪了；
2. 犯罪情节较轻、轻微；
3. 因为犯罪情节轻微，不需要判处刑罚。

> **注意**：免除处罚免除的是刑罚处罚，是不判刑，但不等于什么也不做。根据案件情况，符合条件的可以适用非刑罚处理方法。免除处罚就是定罪免刑，定罪免刑之后仍可适用非刑罚处理方法。

到这里法定情节就结束了。两类分法大家再捋一遍：一、按总则性情节与分则性情节；二、按功能分为从重处罚、从轻处罚、减轻处罚、免除处罚。其中有点难的是减轻处罚。

### 酌定情节的七把尺

下面进入酌定情节。还是问那两个问题：怎么来的，怎么用。答案是——人民法院从审判经验中总结出来的；在裁量刑罚过程中灵活掌握、酌情适用的情节。

酌定情节一共有七种情况。好记，不要怕。2009年考过一道简答题，问酌定情节有几种，你只要把这七个点列上去就满分了。当然是道比较老的真题了。

> **提示**：既然酌定情节一定没有法律明文规定，否则它就变成法定情节了。正因为没有明文规定，这七项才需要你从理解和判断力上拿分。

**第一，犯罪动机。**

同样是盗窃，有人盗窃是为了给自己看病，有人盗窃是为了去嫖娼。盗窃数额相同的情况下，对谁的量刑会更重？很明显是那个嫖娼的人，动机太卑劣。为自己看病的人虽然也是犯罪，虽然我们也接受不了，但想一想，这个人真的还有点可怜，他的主观恶性没有那么深。盗窃的目的竟然是嫖娼，量刑肯定会重一些。所以动机通常是酌定情节。

**第二，犯罪的手段。**

同样是杀人。张三一枪把人打死，李四是活活把别人折磨死，像凌迟处死一样。犯罪手段会不会影响量刑？当然会。

**第三，犯罪的时间和地点。**

时间、地点通常都不是法定情节。当然个别犯罪是——比如抢劫罪中的"入户抢劫"，那个地点就是法定情节。但在大多数犯罪中，时间、地点都不是刑法明文规定的，只不过它们确实会影响量刑。

举个例子。偏僻之地，周围没人，大半夜，张三杀死了个日本人（我说这个不是说不构成犯罪，更不是在鼓励犯罪，大家不要过多联想）。再对比一下：国庆节，天安门广场前，老百姓在庆祝、在游行，张三在人群中持刀砍死一个人，血染天安门。

同样都是构成故意杀人罪，量刑会不会有差别？当然会。偏僻之地杀人，没有引起周围人的恐慌；人群中杀人，引起不特定多数人的恐慌，还破坏了过节的氛围。第二种显然会影响量刑，虽然影响可能没那么大。这就是酌定情节。

**第四，犯罪侵害的对象。**

张三把一个孕妇打成了轻伤，构成故意伤害罪；李四把马蜂打成了轻伤，也构成故意伤害罪。都是轻伤，也都是轻伤二级。量刑会不会有区别？当然会。哪一个更可恶？很明显，打孕妇的更可恶，我们绝对接受不了。

（这里不是说你能接受打马蜂打成轻伤，只不过因为侵害对象有特殊性，第一种情形的量刑肯定会重一些。）

**第五，犯罪造成的损害结果。**

张三偷了十万块，没有造成其他后果；李四偷的也是十万块，但被害人损失十万块之后自杀了。这个结果当然不是盗窃罪的构成要件结果。你是法官，量刑会不会有区别？当然会。张三偷了十万块被害人没事，李四偷了十万块被害人自杀了，对李四量刑肯定会重一些。这就是造成的结果。

**第六，犯罪分子的一贯表现。**

一贯表现好，然后只是激情犯罪、没有预谋，量刑肯定会相对轻一些。但如果一贯恶贯满盈，量刑肯定会重一些。

**第七，犯罪后的态度。**

有人犯罪之后认罪悔罪、积极赔偿被害人，甚至取得被害人的谅解，量刑肯定会轻一些。有人犯罪之后还扬言报复，量刑肯定会重一些。

这种情况实务中真出现过，电视上都播报过类似新闻。张三犯罪之后，检察官过去提审他，前面警察，后面检察官，两个女检察官——可能是一个检察官、一个检察官助理。他就说："我犯的事有多严重吗？啊？不就是强制猥亵了别人吗？你们能不能判我死刑？如果能判我死刑我认了；如果判不了我死刑，等着吧，等我出去的时候，你们都是女性吧，是不是？"

这是真实案例。你想想，这种人犯罪后的态度怎么样？通过他的表述我们知道，他的危险性比较高，量刑通常都会重一些。

七项到这里就讲完了。那怎么记？看看背诵逻辑：**主观加客观，加过去加现在**，就这四个维度。

- 主观 → 犯罪动机；
- 过去 → 犯罪分子的一贯表现；
- 现在 → 犯罪后的态度；
- 客观 → 第 2 到第 5 项。

客观这四项怎么记？联想客观方面：行为、对象、结果、时间、地点、方法。"行为"是法律规定的，不考虑；因果关系也不考虑了。剩下时间、地点、方法，把"方法"拿出来——方法不就是犯罪手段吗，对应第二项。再加侵害的对象、造成的损害结果、时间和地点，四个点就齐了。

有人说对象也是法定的，没错，比如故意伤害罪的对象是他人身体，这肯定是法定的。但"他人"的特点不一样，有孕妇、有健康人，这个细微差别法律不可能规定。所以对象可以是酌定的。

> **结论**：酌定情节一共七项——犯罪动机、犯罪手段、犯罪时间和地点、犯罪侵害的对象、犯罪造成的损害结果、犯罪分子的一贯表现、犯罪后的态度。

### 酌定情节怎么用：全面准确，公正合理

最后讨论酌定情节的适用。这个点现在了解就行，到背诵阶段我带着你们记一记。对选择题基本没影响；主观题里它算一个特别偏的点。

怎么记标题？给大家简单说四组关键词：**全面准确，公正合理**。

- **准确**，是要准确认定酌定情节的性质。它和法定情节一样，也包括从严情节和从宽情节，包含这两种，你要准确认定它的性质。
- **全面**，是要全面把握酌定情节的内容。
- **合理**，是要合理协调法定情节与酌定情节的关系。如果一个案件既有法定情节又有酌定情节，很明显法定情节要优先适用——法定情节是法律规定的、量刑时应当考虑的情节，优先适用。
- **公正**，是要公正适用酌定情节。

前面做的铺垫到这里就结束了。

**题目**：下列选项中，**应当**从轻或者减轻处罚的有：

- A. 犯罪后自首
- B. 教唆他人犯罪被他人拒绝
- C. 已满十四周岁不满十八周岁的人犯罪
- D. 尚未完全丧失刑事责任能力的精神病人犯罪

**解析**：题干的关键在于"应当"，不是"可以"。逐项看：

- **A 项**：犯罪后自首的，可以从轻或者减轻处罚，其中犯罪较轻的可以免除处罚。这是"可以"，不选。
- **B 项**：教唆他人犯罪被他人拒绝，这就是教唆未遂。未遂犯可以比照既遂犯从轻或者减轻处罚，是"可以"，不选。
- **C 项**：已满十四周岁不满十八周岁的人犯罪，应当从轻或者减轻处罚。这是"应当"，**当选**。
- **D 项**：尚未完全丧失刑事责任能力的人犯罪，应当负刑事责任，但是可以从轻或者减轻处罚。是"可以"，不选。

**答案**：C。

## 累犯：从再犯到从重处罚
> 对应块：BLK61 | 覆盖分集：P61 | 块标题（分集名）：《第14章 第03节：累犯》

「累」这个字，在汉语里有“又”和“再”的意思。累犯其实就是再犯——只不过它是一种特殊的再犯，得符合一整套特定的条件才成立。

这一节我们集中讨论六种重要的量刑制度：累犯、自首、立功、坦白，还有数罪并罚和缓刑。其中前四项又称量刑情节，而量刑情节本身就是量刑制度的内容。累排在第一个，我们从它开始逐项拆解。

### 累犯的概念，以及为什么值得单列一种制度

> **定义**：累犯，是指因犯罪受过一定的刑罚处罚，在刑罚执行完毕或者赦免以后，于法定期限内再犯一定之罪的罪犯。

累犯包括一般累犯和特别累犯（又称特殊累犯）。

对累犯之所以从重处罚，是因为累犯所犯之罪往往具有更严重的一般社会危害性，其主观恶性和人身危险性相较于初犯而言也是更为严重。正因如此，对累犯应当从重处罚——它同时体现了两大原则，书上也是这么写的：

> **定义**：罪责刑相适应原则。这个原则具有普遍性，对任何一个犯罪人考虑其刑罚，都必须符合罪责刑相适应原则。
>
> **定义**：刑罚个别化原则。这一原则要求要考虑具体犯罪人本身具有的特点。

刑罚个别化举个数就明白了：张三、李四构成共同犯罪，作用相当，分赃数额完全一样，正常情况下对他们的量刑是相同的。但你不能说张三是累犯，李四就一定是累犯。我们知道在共同犯罪中是部分实行全部责任、一人既遂全部既遂，**可是在累犯这种情节上要因人而异**：张三具有累犯情节，未必李四也具有。所以经过分析认为张三是累犯、李四不是，对张三的量刑就会更重一些——这就是刑罚个别化原则。

### 一般累犯：五、有、十八、故

刑法第65条规定：被判处有期徒刑以上刑罚的犯罪分子，刑罚执行完毕或者赦免以后，在五年内再犯应当被判处有期徒刑以上刑罚之罪的，是累犯，应当从重处罚，但是过失犯罪和不满十八周岁的人犯罪的除外。

这里还有一个附带规定：前款规定的期限，对于被假释的犯罪分子，从假释期满之日起计算。这个点先放一放，后面讲假释的时候专门说。

所以一般累犯的概念是：被判处有期徒刑以上刑罚，并在刑罚执行完毕或者赦免以后，在五年内再犯应当被判处有期徒刑以上刑罚之罪的犯罪分子。

构成要件就这四个条件。凑成一句口诀——**五、有、十八、故**：

| 口诀 | 条件 |
| --- | --- |
| 五 | 五年以内 |
| 有 | 有期徒刑以上刑罚 |
| 十八 | 年满十八周岁 |
| 故 | 故意犯罪 |

这个口诀当年也是费了劲的。「吾」通文言字，有“我”的意思，“吾有十八姑”。我以前备考的时候就想，一般累犯的成立条件怎么记呢？就想如果我有十八个姑姑，多累啊，十八个姑姑天天和你聊天，肯定很累。后来我讲课的时候有学生说：“老师，你这个口诀真的很一般。”我说：“有没有更好的理解？”他说：“有啊——如果你要理解成‘我有十八个姑娘，好累啊’。”各位，好像也能说得通。但不管怎么讲，只要这个口诀能还原出它的四个条件就够了：**五年以内、有期徒刑以上刑罚、年满十八周岁、故意犯罪**，四个条件同时满足就构成一般累犯，只要满足这四个条件，都能够构成一般累犯。

下面逐项拆。

#### 主体：前罪、后罪都得年满十八周岁

要求犯罪主体年满十八周岁。**前罪和后罪发生的时候都必须年满十八岁**。如果前罪不满十八、后罪满了十八，同样不构成累犯。这是第一个条件——十八。

#### 主观：前罪、后罪都必须是故意犯罪

必须**同时**都是故意犯罪。前过失后故意、前故意后过失，都不能构成累犯，这点要注意。

> **易错点**：甲因诈骗被判三年，刑罚执行完毕后的第二年，又因失火罪被判处一年。失火罪很明显是过失犯罪，所以不可能构成累犯。

#### 刑度：前罪、后罪都得是有期徒刑以上刑罚

我们主刑的排序是：管制、拘役、有期徒刑、无期徒刑、死刑。“有期徒刑以上刑罚”意味着包括有期徒刑、无期徒刑、死刑，都可以，**但不包括管制，也不包括拘役**。

要卡两点：第一，构成累犯，前罪被判处的刑罚和后罪应当被判处的刑罚，必须都是有期徒刑以上刑罚；第二，如果两者都低于有期徒刑，或者其中有一个低于有期徒刑，那都不能构成累犯。

所以“五、有、十八、故”里的那个“有”——**前后罪都必须是有期徒刑以上刑罚**。但此时请各位关注一个例子，在具体认定的时候一定要严格坚持这个规则，不要凭着感觉来进行理解：

> 甲犯故意伤害罪，被判处三年有期徒刑。刑罚执行完毕后的第四年，又犯盗窃罪和使用虚假身份证件罪。其中，盗窃罪应处四年有期徒刑，使用虚假身份证件罪应处管制。

对着“五、有、十八、故”过一遍。前罪故意伤害罪，是故意犯罪，判了三年——合格；后罪有两个罪，一是盗窃，二是使用虚假身份证件，两个都是故意犯罪，“故”满足；“五”满足，第四年，在五年以内；“十八”题目没交代，我们默认当然是成年人。“有”这一项卡住了：后罪里**只有盗窃罪**应处有期徒刑以上刑罚，使用虚假身份证件罪应处管制，是低于有期徒刑的。

从对应关系上说，前有伤害罪，后有盗窃罪和使用虚假身份证件罪，线要这么连：伤害罪连盗窃罪，**甲只就盗窃罪构成累犯**；使用虚假身份证件罪不构成累犯，因为它应处管制，不是有期徒刑以上刑罚。

> **结论**：前后罪存在数个罪名时，构成累犯的对应关系是逐个罪名计算的，不是“整包”成立。

#### 时间：五年以内，从刑满释放之日起算

要求后罪发生在前罪的刑罚执行完毕或者赦免以后五年以内。这里有两个问题要抠清楚：五年从哪一天开始算？“刑罚执行完毕”指主刑还是包括附加刑在内？

```text
   前罪：故意伤害罪，判三年有期徒刑
        │
        ├─── 刑罚执行期间 ──► 后罪落在此段：数罪并罚，不构成累犯
        │
        │    刑满释放日 ← 五年期限从这一天起算
        │
        ├─── 5 年以内 ────► 后罪落在此段：可构成一般累犯
        │
        └─── 5 年以后 ────► 后罪落在此段：一般累犯不成立
```

读图：后罪落在哪个位置，法律后果完全不同。“刑罚执行期间”那一段是数罪并罚的领地，不是累犯的领地；只有刑满释放日之后才是五年期限的适用范围，而且这个期限只从刑满释放日起算，不往前延伸。

**第一，五年以内从刑满释放之日起计算。** 比如张三因盗窃罪被判处三年，服刑到5月1号结束，这一天把他放了；从5月1号向后推，如果五年内他又犯了一个故意犯罪且应处有期徒刑以上刑罚，就能够构成一般累犯。这也是最高人民检察院做出的规定。

**第二，“刑罚执行完毕”仅指主刑执行完毕，不包括附加刑。** 理由就在前面第三点：构成一般累犯要求前罪被判处有期徒刑以上刑罚，而后罪要发生在前罪的“刑罚执行完毕”以后，言下之意是要发生在这项有期徒刑以上刑罚执行完毕以后。所以即使附加刑还没有执行完毕，同样是构成累犯的。

**第三，赦免。** 赦免不光可以发生在前罪刑罚执行完毕以后五年以内，还可以发生在前罪被赦免以后五年以内。这里的赦免指的是**特赦减免**，由全国人大常委会做出决定、国家主席发布特赦令——注意，法院是没有权力决定赦免的。我们在总则最后一个板块会讲到。

**第四，后罪发生在前罪的刑罚执行期间，不构成累犯。** 因为成立条件要求后罪要发生在前罪刑罚执行完毕或者赦免以后五年以内。落在执行期间就是数罪的情况：这种数罪首先不构成累犯，其次要实行数罪并罚。书上的例子：甲因强奸被判处三年有期徒刑，在服刑期间又因强制猥亵他人应处两年有期徒刑——后罪发生在前罪的刑罚执行期间，因此不构成累犯，要数罪并罚。

**第五，有期徒刑以上刑罚包括有期徒刑、无期徒刑和死刑缓期执行，但不包括死刑立即执行。** 你想一想，张三犯个前罪被判处死刑立即执行，他还有犯后罪的可能吗？自然没有，都被剥夺生命了，怎么可能再犯后罪。所以站在**前罪**的角度来讲，有期徒刑以上刑罚包括有期徒刑、无期徒刑和死刑缓期执行，但切记不能包括死刑立即执行。

一般累犯就这么简单，四个条件同时满足才成立，有一个条件不符合就不构成。

### 一道把几个条件同时用上的真题

2010年的一道题：

> 甲15周岁，因琐事放火烧毁邻居家房屋后逃走。2014年，因多次盗窃被抓获。2014年时他已经成年了，年满18岁。下列选项中正确的有：
>
> A. 甲构成累犯，应当从重
> B. 对甲最重只能判处无期徒刑
> C. 对甲的放火行为应当从轻或减轻处罚
> D. 甲的行为构成放火罪和盗窃罪，应当数罪并罚

我们一个一个看。

**A，错。** 累犯要求“五、有、十八、故”，前罪、后罪都要年满18岁。他前罪时不满18周岁，因此不可能构成一般累犯。

**B，对。** 放火罪的法定最高刑是死刑，只不过他是未成年人，犯罪时不满18周岁的人不能适用死刑，所以放火这一头出不了死刑；后面多次盗窃更不可能判处死刑，盗窃罪最高也就是无期徒刑。所以最重只能判处无期徒刑。

**C，对。** 未成年人犯罪应当从轻或者减轻处罚。

**D，对。** 15岁对放火要不要承担刑事责任？要。已满14不满16周岁的人对八种行为承担刑事责任，放火就在其中。而盗窃的时候他已经成年了，自然也要承担刑事责任。两个行为，侵害两个客体，两个犯意，同时符合两个犯罪构成，既没有牵连关系，也没有吸收关系，所以数罪并罚。

因此本题选 B、C、D。

> **提示**：一旦题干里冒出年龄，在做题的时候一定要用得到。“十八”这个条件是这类题最常用的抓手。

### 特别累犯：只认“国、恐、黑”

刑法第66条规定：危害国家安全犯罪、恐怖活动犯罪、黑社会性质组织的犯罪分子，在刑罚执行完毕或者赦免以后，在任何时候再犯上述任一类罪的，都以累犯论处，我们称之为特别累犯。

所以特别累犯的前罪和后罪真的很特别。为什么特别？**仅限于三类罪**，简称为“国、恐、黑”：危害国家安全、恐怖活动、黑社会性质组织。

概念是：因这三类罪受过刑罚处罚，在刑罚执行完毕、赦免以后，在任何时候再犯上述任一类罪的犯罪分子。

那它的成立条件特殊在哪？特别累犯之所以特别，一定是相对于一般累犯而言的。抬头看——一般累犯的成立条件是“五、有、十八、故”，你就拿这四个条件去对比，找出特别累犯的特殊之处，特别累犯的成立条件就出来了。

对比“五”（时间）：一般累犯要求前罪后罪间隔5年以内，特别累犯**不要求**。不要求5年以内，10年、20年都能构成特别累犯，所以在任何时候再犯上述任一类罪，都以累犯论处。

对比“有”（刑度）：一般累犯要求前罪和后罪都要被判处有期徒刑以上刑罚，特别累犯同样**不要求**。

对比“十八”：不考虑。

对比“故”（故意）：一般累犯要求前罪和后罪都是故意犯罪，特别累犯更特殊——它不光要求是故意犯罪，而且必须是三类特殊的故意犯罪：国、恐、黑。

所以特别累犯就可以拆解成三大条件来讨论。

#### 罪名条件特殊：前后罪都是“国、恐、黑”之一，不要求一一对应

构成特别累犯，要求前罪后罪都是国、恐、黑犯罪，都属于这三类之一。如果行为人实施的前后两罪都不是国、恐、黑，或者其中之一不是，就不构成特别累犯。

> **易错点**：只要求前罪和后罪都是“国、恐、黑”之一就可以，它**不要求一一对应**。不是说前罪是危害国家安全犯罪，后罪就必须是危害国家安全犯罪。哪怕前罪是危害国家安全犯罪、后罪是黑社会性质组织犯罪，它同样也能成立特别累犯。

不过这个板块有两个罪得先记一记，我们到分则再讲：有两个罪看着特别像危害国家安全犯罪，第一反应容易搞错——**故意泄露国家秘密罪属于渎职罪**；还有**非法获取国家秘密罪，它属于妨害社会管理秩序罪**。这两个罪都不属于危害国家安全犯罪，因此不能构成特别累犯。

| 前罪 | 后罪 | 构成特别累犯 | 理由 |
| --- | --- | --- | --- |
| 危害国家安全犯罪 | 恐怖活动犯罪 | 是 | 前后罪同属“国、恐、黑”，不要求对应 |
| 危害国家安全犯罪 | 黑社会性质组织犯罪 | 是 | 同上，可以交叉 |
| 危害国家安全犯罪 | 危害国家安全犯罪 | 是 | 同上 |
| 参加黑社会性质组织罪 | 恐怖活动犯罪 | 是 | 同上 |
| 故意泄露国家秘密罪 | 危害国家安全犯罪 | 否 | 故意泄露国家秘密罪属渎职罪，不属于“国、恐、黑” |
| 非法获取国家秘密罪 | 危害国家安全犯罪 | 否 | 非法获取国家秘密罪属妨害社会管理秩序罪 |
| 参加黑社会性质组织罪 | 盗窃罪 | 否 | 后罪不属于“国、恐、黑”三类之一 |

#### 刑度条件特殊：刑种及其轻重一律不受限制

一般累犯要求前后罪都必须被判处有期徒刑以上刑罚，特别累犯不要求。我们立法规定的是：只要因三类罪被判处刑罚，在刑罚执行完毕或者赦免以后、在任何时候再犯上述任一类罪的，都以累犯论处。

所以**只要求前罪被判处刑罚即可，至于判处的是主刑还是附加刑并不重要**。哪怕前罪被单独判处附加刑，符合条件同样能构成特别累犯。

考试分析中的表述是：构成特别累犯，前罪被判处的刑罚和后罪应当被判处的刑罚，**刑种及其轻重不受限制**（断句：刑种，就是种类，及其轻重）。

所以即使前后两罪、或者其中之一被判处或者应当被判处管制、拘役，或者单处某种附加刑，也不影响特别累犯的成立。例子很清楚：甲因叛逃罪被单处剥夺政治权利2年，这是附加刑，刑罚执行完毕后又犯参加黑社会性质组织罪，同样构成特别累犯。

但这里有一个命题陷阱，抬头看一下。

张三犯参加黑社会性质组织罪，但是因为情节较轻，被法院免除处罚，就是定罪免刑。之后第6年，张三又犯分裂国家罪。请问：犯分裂国家罪时能否成立特别累犯？前罪是“黑”，后罪是“国”，能否构成特别累犯？

**当然不行。** 请各位特别注意这个命题陷阱。再看看法条第66条本页最上面那句话：危害国家安全犯罪、恐怖活动犯罪、黑社会性质组织犯罪的犯罪分子，在**刑罚执行完毕或者赦免以后**……“刑罚执行完毕”是什么意思？一定是因前罪被判刑了。虽然说不要求有期徒刑以上刑罚，但前罪至少被判刑。言下之意，如果前罪是被定罪免刑，那是绝不可能构成累犯的，包括一般累犯和特别累犯都不能构成。

一般累犯要求后罪要发生在“前罪的刑罚执行完毕以后”，特别累犯也要求后罪发生在“前罪的刑罚执行完毕以后”。既然要发生在前罪的刑罚执行完毕以后，这表明前罪至少要被判刑。所以在特别累犯中，前罪确实可以判一个附加刑，或者判管制、拘役，这都可以，但**至少要被判刑**。

> **易错点**：前罪被免除处罚（定罪免刑）的，后罪不构成累犯。例如参加黑社会组织情节轻微不处罚，属于定罪免刑，判决生效后的第3年又犯分裂国家罪（应处3年有期徒刑）——因为前罪根本没有被判处刑罚，也就不存在所谓“刑罚执行完毕”或者“赦免”的可能，因而不能构成累犯。这个点是重大命题陷阱，请一定要掌握。

#### 时间条件特殊：任何时候

因三类罪被判处刑罚，在刑罚执行完毕或者赦免以后，**任何时候**再犯上述犯罪都成立。任何时候，anytime，这表明什么？不受时间限制的。只要前罪被判处刑罚，在刑罚执行完毕以后或者赦免以后，5年、10年、15年、20年，再犯这些罪，都能构成特别累犯。这表明特别累犯在时间上也是特殊的。

> **结论**：特别累犯小结——第一，只有三类罪：“国、恐、黑”；第二，刑度条件不要求，但要求前罪被判刑，哪怕只判附加刑也行，唯独不能定罪免刑；第三，时间条件不受限制，不要求后罪发生在前罪刑罚执行完毕或赦免以后五年以内，任何时候再犯上述罪都能构成特别累犯。

> **提示**：为什么对比“五、有、十八、故”时唯独没有对比年龄？未成年人能否构成特别累犯，理论上存在着争议，司法实践中的观点也不一样。那在考试中怎么办？确实存在着争议，但要注意，大多数观点认为**未成年人既不能构成一般累犯，也不能构成特别累犯**——换句话说，构成累犯要求年满18周岁。这是多数观点，了解一下。

### 累犯与再犯，差在四个地方

再犯指的就是再次犯罪，具体而言，是两次或者两次以上犯罪的人。累犯和再犯的区别，同样是对着“五、有、十八、故”做对比，得出了四个不同点：

| 比较项 | 累犯 | 再犯 |
| --- | --- | --- |
| 罪名 | 前后实施的犯罪必须是特定的犯罪：一般累犯要求是故意犯罪，特别累犯不光是故意犯罪，而且仅限于国、恐、黑三类罪 | 前后实施的犯罪没有限制，哪怕前罪是过失犯罪、后罪也是过失犯罪，这也是两次以上犯罪、再次犯罪，同样可以称之为再犯 |
| 刑度 | 一般必须以前后两罪被判处或者应当被判处一定的刑罚为要件 | 不要求 |
| 时间 | 后罪必须发生在前罪刑罚执行完毕或者赦免以后的法定期限之内（这主要指一般累犯的五年） | 对前后两罪之间没有时间方面的限制 |
| 后果 | 后果更重 | 后果相对较轻 |

这四点先了解，等到背诵阶段我会带着你们去背。

### 累犯的四大后果

累犯的后果更重，体现在刑法规定的四大后果上：

第一，对累犯应当**从重处罚**；第二，对累犯**不能适用缓刑**；第三，对累犯**不能假释**，不能提前释放；第四，对于被判处死缓的累犯还可以**限制减刑**——这一条我们前面讲过，三种特殊的死缓犯是可以限制减刑的。

#### 从重，但不是一律顶格

“对累犯应当从重处罚”这句话包含三层含义。

**第一，必须从重处罚。** 这是刚性的，没有裁量空间。

**第二，要比照不构成累犯的人从重处罚。** 为什么？因为累犯是一种量刑情节、从重情节。从重情节是指**在法定刑幅度内**，选择判处比没有该情节的类似犯罪相对较重的刑种或刑期。所以参照系是“不构成累犯的人”。

**第三，具体判处的刑罚必须根据犯罪的事实、性质、情节、社会危害程度确定，不能毫无事实根据地对累犯一律判处法定最高刑。** 比如法定刑是3到10年，张三原本判3年就够了，但基于累犯情节判了3年半——3年半对3年而言同样是从重处罚。

> **提示**：千万不要认为对累犯要一律判处法定最高刑。也不要去看所谓的“中间线”——从重是相对于同类犯罪人的量刑比较，不是要求你机械地选一个中间刑期。

至于另外三个后果：不能适用缓刑，我们在缓刑里讲；不能假释，我们在假释里讲；死缓限制减刑，前面已经讲过了。

到这里，一般累犯和特别累犯就全部结束了。各位是不是感觉还比较轻松？难度系数没那么大。

**2010年真题**

甲15周岁，因琐事放火烧毁邻居家房屋后逃走。2014年，因多次盗窃被抓获。2014年时甲已年满18周岁。下列选项中正确的有：

- A. 甲构成累犯，应当从重
- B. 对甲最重只能判处无期徒刑
- C. 对甲的放火行为应当从轻或减轻处罚
- D. 甲的行为构成放火罪和盗窃罪，应当数罪并罚

**答案：B、C、D。**

| 选项 | 判断 | 依据 |
| --- | --- | --- |
| A | 错 | 一般累犯“五、有、十八、故”要求前后罪均年满18周岁，甲前罪时15岁，不成立累犯 |
| B | 对 | 放火罪法定最高刑为死刑，但不满18周岁的人不适用死刑；盗窃罪最高为无期徒刑，故最重只能判处无期徒刑 |

| D | 对 | 已满14不满16周岁的人对放火等八种严重行为承担刑事责任，盗窃时已成年；两个行为侵害两个客体、出于两个犯意，无牵连与吸收关系，数罪并罚 |

## 一般自首：自动投案与如实供述
> 对应块：BLK62 | 覆盖分集：P62 | 块标题（分集名）：《第14章 第04节：自首与坦白（01）》

### 一般自首的两大条件

上一节讲累犯，累犯分一般累犯和特别累犯；自首同样分一般自首和特别自首。这一讲先从一般自首入手。

为什么先讲一般自首？因为"一般自首"是这一部分的大概念——它是把一般自首和特别自首合在一起构成的，所以从它入手，特别自首那一层自然就被带出来了。

《刑法》第67条第1款规定得清清楚楚：

> 犯罪以后自动投案，如实供述自己罪行的，是自首。对于自首的犯罪分子，可以从轻或者减轻处罚，其中犯罪较轻的可以免除处罚。

> **定义**：一般自首，是指犯罪分子犯罪以后自动投案，如实供述自己罪行的行为。

从法条就能直接读出，成立一般自首要满足两大条件，缺一不可：**第一，自动投案；第二，如实供述自己罪行。**

下面按这两道关分别拆。

### 自动投案：一切为了"我想坐牢"

#### 自动投案的法定含义

自动投案是指：犯罪事实或者犯罪嫌疑人尚未被司法机关发觉，或者虽然被司法机关发觉，但犯罪嫌疑人尚未受到讯问、未被采取强制措施时，主动直接向公检法投案。

这段话要从最理想的状态看起。最理想的状态是：犯罪事实、犯罪嫌疑人都还没有被司法机关发觉。比如张三杀了一个流浪汉，就地掩埋，也一直没有人报警——他的杀人事实没有被司法机关发觉，他作为嫌疑人也没有被司法机关发觉。在这种状态下张三选择去投案，这很明显是自动投案、主动投案，是最好的状态。

稍微再差一点：比如张三杀人之后已经被列为嫌疑人，但是警察一直没有抓到他。此时就是"虽然被发觉，但犯罪嫌疑人尚未受到讯问、未被采取强制措施"。

> **易错点**：法条里"讯问"这两个字一定要盯住。询问证人一般叫"询问"，对嫌疑人通常用"讯问"；一个人一旦被讯问，我们认为那是被动归案，不是主动归案。自动投案要求"主动"，而主动的前提是他有人身自由——没有被采取强制措施，没有受到讯问。

自动投案的方式多种多样，后面司法解释规定了很多种。千万不要死记，一定要抓住它的本质。**自动投案的本质就四个字：要体现"我想坐牢"的精神。**

这四个字以前书上没有，是我要求同学们做笔记、记在旁边写的。有人说这四个字不吉利、不记，那就不记，我把它写在黑板上。要体现"我想坐牢"的精神——好多疑难的问题用"我想坐牢"这四个字一检测，你会发现结论非常清楚。

凡是体现这种精神的，才有可能被认定为自动投案；千万不要去怀疑这几个字。

> **提示**：自动投案的动机不影响自动投案的认定。开头有的人投案的确是认罪悔罪、心生悔意；有的人投案是迫于无奈——比如衣食无着、患有疾病，他想去投案，最起码在警察的监控之下、在看守所还能吃饱饭，生病了还能看看病。有的出于真诚悔罪，有的慑于法律的威严，有的为了宽大处理，有的潜逃在外生活无着，有的经亲友规劝而醒悟。这些动机我们从来不关注，只关注他有没有自动投案。

#### 投案意愿：用"我想坐牢"逐案检测

所谓投案的意愿，就是主动、自动，愿意主动将自己置于司法机关的控制之下，等待进一步交代犯罪事实。司法解释列举的几个案例，我们一个一个拿"我想坐牢"这四个字检测过去。

**例一：被亲友捆绑送到公安机关。** 张三犯罪之后被自己的亲友捆绑，然后送到公安机关，到案后如实供述自己罪行。请问有没有体现"我想坐牢"的精神？没有。他体现的是"我的亲友想让我坐牢"的精神。所以这种情况不能认定为自动投案，不能成立自首。司法解释是明文规定不能认定为自动投案的；同时它又规定，这种情形可以参照法律对自首的有关规定酌情从轻处罚——注意，仍然不成立自首，只是从轻。

**例二：经亲友规劝后投案。** 张三犯罪之后告诉了自己的父亲，父亲说"你赶快去投案"，张三说"我不去，我坚决不去投案"；父亲紧接着劝他，说"这件事情躲不过去的，去投案还能争取一个宽大处理的机会"。张三想一想同意了，到案之后如实供述自己罪行。能成立自首吗？能。他刚开始的确没有体现"我想坐牢"的精神，但是他被别人规劝之后产生了投案的意愿，仍然是从被动转化为主动，仍然体现了"我想坐牢"的精神，能够成立自首。所以投案的方式多种多样，大家一定要抓住它的本质，用这四个字进行检测。

**例三：匿名退还赃物、匿名报案。** 犯罪人匿名将赃物送到司法机关，或者把赃物送到原主、被害人处，然后用电话、书信等方式匿名向司法机关报案，并指出赃物的位置，但没有将自己置于司法机关控制下的意思。这肯定不属于自动投案。为什么？它恰恰体现了"我不想坐牢"，所以我才匿名。此时将赃物退回，充其量是犯罪后的态度、犯罪后的表现。

**例四：报警后服毒自杀。** 这个案例真的挺重要。张三刚刚把别人打成了重伤，就打电话报警："我刚刚把人打成了重伤，我在某某桥，你们赶快来抓我，我在这等你们哦。"警察听完之后连忙出警。张三挂了电话，立马服毒意图自杀，买了毒药吃下去。等警察过来的时候发现他已经中毒了，但还没毒死，警察又连忙把他送往医院，紧接着救活了。问张三的行为属于自动投案吗？不是。他报警不是为了让警察来方便自己投案，他是让警察过来替自己收尸的。他没有体现"我想坐牢"的精神，所以此种情形不能成立自首。

> **提示**：例四把顺序颠倒过来，结论就完全反过来。如果他犯罪之后先自杀、没死，觉得很疼不想死了，才打电话说"你们赶快来救我，我犯罪了，我要向你们投案"，警察过来之后他如实供述自己罪行——这就体现了"我想坐牢"的精神，应当认定为自首。**先报案后自杀，和先自杀后报案，明显不同。** 先报案再自杀，表明他根本不想坐牢；先自杀没死又想清楚了才报案，才体现了"我想坐牢"。这个细微的区别请大家一定要注意。

这就是为什么我讲，自首的方式千千万万，千万不要看形式，要抓住本质；本质就是要体现"我想坐牢"的精神，只有满足"我想坐牢"的精神，这个时候才有可能被评价为自动投案。

#### 投案时间：被讯问和强制措施之前

第一层，投案必须发生在犯罪以后。如果都不构成犯罪，你谈什么投案？比如张三现在根本没犯罪，他跑到警察局说"我要投案，疯了"——这不是闹着玩吗？这不是浪费警力吗？所以自动投案必须发生在犯罪以后，如果没有犯罪也就没有投案的问题。法条明文规定的就是"犯罪以后自动投案"，比如张三和别人通奸，通奸之后他自认为犯罪了，去找警察自首，请问是自首吗？自然不是。

第二层，也是最要紧的：**犯罪嫌疑人在被讯问或者被采取强制措施之前，都可以自动投案。** 比如张三杀了人潜逃外地，逃了五年、十年，只要他没有被抓、没有被受到讯问，一旦他去投案，那都是满足自动性的，都体现了他"我想坐牢"的精神。因为行为人一旦被讯问或者被采取强制措施，这就是被动归案了，他就没有体现自动投案的那个自动性。

> **提示**：贪污贿赂、渎职等职务犯罪的犯罪分子，如果没有自动投案，表明其不符合自动投案的前提，在办案机关调查谈话、讯问、采取调查措施或者强制措施期间，如实交代办案机关掌握的线索所针对的事实，不能认定为自首，因为这属于被动归案。

有人不理解的是：为什么"调查谈话"竟然也算被动归案？举两个例子你们就明白了。

张三是个官员，被别人举报了，组织上就给张三发个函，问这些线索你怎么解释。张三这个时候如果交代了，一般认为可以成立自首，可以认定为自动投案。但如果张三看到这些线索之后矢口否认，说"这都是诬告的材料，和我一点关系都没有"——他否认过之后，上级纪委监委来到张三的单位，说"张三同志，我们要聊一聊这个问题，请跟我们一起到办公室"。到了办公室之后，通常工作人员至少两名甚至更多，有人负责和张三谈话，有人负责记录，而且记录之后还要求张三签字确认。请问张三这个时候参与调查谈话，他是主动找组织去谈还是被动的？当然是被动，他不去行不行？当然不行。这就是直接带走加谈话调查，所以此种情形属于被动归案。

我们司法实践中碰到这种职务犯罪，甚至还出现过类似情况，在入库案例里面都有：张三是个官员，组织上决定对其进行调查，但又担心他潜逃外地，如果一跑，可能造成的社会影响就不太好了。这时候上级组织找到李四，李四和张三是同事关系，让李四把张三骗过来。李四给张三打电话说："哎，那个上级要调查王五的事情，你和王五的关系还挺好，你对他的情况了解吗？你赶快来一趟，到单位，你把你知道的王五的情况告诉组织。"张三一想：反正是调查别人嘛，对吧，很轻松，心态很轻松，他就回到单位，刚回单位就被抓了。你认为他这时候回单位是来投案的吗？有体现"我想坐牢"的精神吗？当然没有。这种情况不可能认定为一般自首，因为他不属于自动投案，这叫被动归案，这叫诱捕——把他骗过来，把他抓起来。

> **提示**：犯罪嫌疑人醉驾被现场查获后，经允许离开，在经公安机关通知到案或者主动到案，不能认定为自动投案。因为"犯罪以后自动投案"要求他首次投案一定是主动的、一定是自动的，而醉驾被现场查获本身就表明这是被动归案，所以他不可能再成立一般自首了。

> **提示**：造成交通事故后保护现场、抢救伤者，向公安机关报告并配合调查的，要认定为自首。比如张三醉酒驾驶造成事故，第一没有逃离现场，而是在保护现场、抢救伤者，而且向公安机关及时报告——这肯定是自动投案。

#### 首次归案最关键：跑了两年再回来不算数

这是一个总结：**首次归案最关键。如果首次归案是被动归案，不能成立一般自首。**

司法解释的入库案例：甲抢劫洪某330元现金被抓获归案，然后被取保候审。取保候审指的是他有自由了、随传随到。甲假经依法传唤无故拒不到案，公安机关对其网上追逃。两年后，甲又向公安局投案。请问甲首次归案是主动还是被动？被动归案。既然是被动归案，那就不可能再成立自首。

```text
行为人归案
    │
    ▼
┌──────────────────────────────┐
│    是否体现我想坐牢的精神    │
└──────────────────────────────┘
    │
    ├─ 否 ──▶ 被动归案，不能成立自首
    │
    ▼ 是
┌──────────────────────────────┐
│  是否被讯问或被采取强制措施  │
└──────────────────────────────┘
    │
    ├─ 是 ──▶ 自动性已丧失，不能成立自首
    │
    ▼ 否
┌──────────────────────────────┐
│    首次归案是主动还是被动    │
└──────────────────────────────┘
    │
    ├─ 被动 ──▶ 之后再回来投案，也救不回来
    │
    ▼ 主动
自动投案成立 ──▶ 再看是否如实供述自己罪行
```

读图：判断自动投案就三问——有没有"我想坐牢"的精神、有没有被讯问或被采取强制措施、首次归案是主动还是被动。任一关过不去，自动投案都不成立。取保候审虽然让人身自由了，但已经是首次归案，自动性在那时就已丧失。

顺着这个案例再推一步，问题就来了。各位可以思考这样一个模型：比如甲犯罪之后先是被抓获——这个被抓当然是被动归案；然后紧接着他趁警察不注意又逃跑，跑了两年之后回来投案。这能成立自动投案吗？

有人说：是呀，他跑完之后又投案，这后面投案是主动的、是自动的呀。当然是自动投案。可你摸着良心想想，如果此种情形认定为自动投案、成立自首，会出现什么现象？

那就是：一个人如果刚开始被抓了，他如果不跑，他不能成立一般自首，没问题吧？因为是被动归案。那言下之意就是，一个人如果被抓了，我们就可以安慰他说："没关系，虽然你被抓了，不属于自动投案，不能成立自首，**但你还有机会**——你趁人不注意跑啊，你只要有本事跑掉，你跑过之后过两天你再回来投案，这不自首了吗？"如果这种情况都认定为自动投案、进而认定为自首，这不就是在鼓励犯罪人逃跑吗？

反过来再看一个新闻上的真实案例。有一个内蒙古的犯人跑到了其他省份，实在跑不动了，想一想算了，决定去投案。他来到一个派出所说："警察同志你好，我要投案。"正常情况来讲，如果你是警察，碰到这种情况，你不要对人家那么凶，对吧，你正常按照办案流程走就行了；对人家不能说热情，但最起码不要凶巴巴的——人家好不容易都跑过来投案了，你还要干嘛？

但这个警察是个话痨，当时可能有点不耐烦，一边登记张三的信息一边摇头，说"姓名""张三犯了啥事，说呀，你不说我怎么记"。张三就把自己怎么样怎么样说了一遍。这个警察一边记录一边摇头说："哎呀，哎哎呀呀呀，我的天哪，你小子，你这至少十年啊。"张三一听，妈的这么重，拔腿就跑，警察追没追上。那这个张三还能成立自首吗？肯定不成立，因为他跑了。当然我感觉这个警察要受处分。

但是你别忘了：如果张三跑了两个月，他又去投案了，是不是自动投案？各位你看他的第一次——他首先是不是主动找警察？是主动投案；然后紧接着是逃跑；跑过之后他又回来投案。他从来没有被动归案过，所以这种情况才有可能成立自动投案。

同样是"投案之后又跑了"，前一个案子首次归案是被动的，后一个案子首次归案是主动的，结论就完全相反。所以我们要看首次归案是主动还是被动，不要看他后来那一次。书上这个点大家一定要深刻理解：**首次归案最关键，首次归案属于被动归案的，不能成立一般自首。**

#### 投案对象：向谁投案才算数

犯罪分子可以向司法机关投案，可以向有关单位投案，也可以向相关个人去投案，这都行，后面讲投案方式的时候包含着这些内容。

比如张三挪用公款以后，可以向公检法投案，也可以向单位的领导投案。但是像下面这样行吗？他对领导说："领导你好，我们单位的公款2000万被我挪出去了，我向你投案。"领导大吃一惊，说"你小子有能耐啊，挪出去2000万"。张三接着说："领导，我求求你，千万不要把这件事情告诉别人，千万不要报警，也不要告诉其他人，我一定会想办法把钱还回来。"

这种情况能不能体现"我想坐牢"的精神？他是想和领导私聊，这就不叫投案，所以此种情形不能认定为自动投案，不成立一般自首。司法解释的入库案例说得很清楚：甲挪用公款后向单位领导投案，请求领导不要将自己移送司法机关，这就不满足自首的主动性，没有体现"我想坐牢"的精神；恰恰相反，他提出的这个要求表明他不想坐牢，自然不能构成自动投案。

#### 投案方式：司法解释划定的八种情形

这一块大家最起码要掌握，因为案例分析题如果问"有什么情节，假如具有自首情节"，通常都是在这八个点之间出一个。给个口诀——你可以不记，就是：

> **电信负责人被司法通缉，准备委托亲友去规劝。**

我们顺着这个口诀，从第一个点开始拆。

**其一，先以信电投案。** 指的是犯罪之后，先给司法机关发个信息、打个电话，表明自己投案的意思，只要在约定的时间内去投案，那都可以认定为自动投案。所以自动投案的底线已经很低了，理由在于我们从政策上一定是鼓励自动投案的，自动投案可以节约司法资源。疫情期间甚至出现过这种情况：某地被封控了，张三想投案，但是投案过去之后警察也不敢接收啊，于是给警察先加个微信、给警察视频一下："你好警察，我要投案，但是我们被封控了，出不去，等这边一解封立马去找你。"警察说"好的，我等你"。只要解封之后去找警察，这一定是自动投案；如果如实供述以后，就能够认定为自首。

再比如我杀了个人，打电话："喂你好警察，我是陈润海，我杀了个人，我想去投案。"警察说"你来呀"。我说"现在不行，手头上有点事儿啊，我的课还没录完，等我录完课之后立马去找你们，而且你们不要对我的手机进行定位"——挂了电话之后马上把手机卡取出来扔了，手机也毁了，你们找不到我，我在一个小黑屋里。等我录完课之后去找警察投案，算数吗？当然算数，这就是先以信电投案。

**其二，向其所在的单位、城乡基层组织或者其他有关负责人员投案。** 注意"所在的"单位、"所在的"城乡基层组织或者有关负责人员。比如张三犯罪之后向自己所在的居委会、村委会投案，这都可以，都能认定为自动投案，相关单位一定会联系警察，然后他同样体现了"我想坐牢"的精神，因此自动投案的确底线已经很低了。

但是如果这个单位、这个城乡组织、这个负责人和自己没有关系，想认定为自动投案就没那么容易。比如张三犯罪之后一直跑、一直跑，警察在后面追他，突然感觉自己好像跑不掉了，他随机把路人李四拦住了，说"不要动"。李四吓一跳，说"你要干嘛"，张三说"我要向你投案"——这可不能认定为自动投案，他是迫不得已。

**其三，仅因形迹可疑被盘问教育后主动交代。** 注意圈起"仅因"两个字。形迹可疑指的是走路鬼鬼祟祟、长相畏畏缩缩、眼神飘忽不定，一看好像有点事，但是又没有直接的犯罪证据。比如张三形迹可疑，警察找到他说"你是不是干什么坏事了，老实交代"，他说"没有啊，什么坏事都没干"，警察一搜身，包括他的车里面，没有任何犯罪证据，那你说怎么办？警察也没有办法呀，只能放他走。所以如果仅因形迹可疑、身上没有任何犯罪证据的情况下，他主动交代，我们认为属于自动投案。但是如果从他身上搜出了一些犯罪的证据，那就明显不叫形迹可疑，那叫犯罪嫌疑。这个点后面还会重点讲。

**其四，犯罪后逃跑，在被通缉追捕过程中主动投案。** 为什么通缉一定是因为犯罪后逃跑？你如果不跑，也不会被通缉。所以犯罪后逃跑、在被通缉追捕过程中，表明他还没有被动归案——第一没有受到讯问，第二没有被采取强制措施，所以在通缉过程中如果主动投案，都能认定为自动投案。

**其五，经查实确已准备去投案，或者正在投案途中被公安机关捕获。** 注意司法解释这里用的是"捕获"，像抓个小猎物一样。"确已准备去投案"要有相关的证据能证明，比如已经向亲戚朋友都告别了，短信也发了，告别仪式也结束了，正要准备去投案，还没出门警察过来把他抓了——古人这种情况就是确已准备去投案，他仍然体现了"我想坐牢"的精神。

我们新闻曾经报道过一个小伙子去投案。他来到公安局门口就很犹豫——那肯定犹豫啊，一旦走进这个门，可能自己就丧失人身自由了；想来想去，不投案又不行，但投案自己可能生活就会变得很差，那最后再享受一把吧。于是他点了两份奶茶，而且做了个备注，备注是"麻烦小哥赶快送过来，我马上就投案了"。小哥一看这个单子很特殊嘛，快马加鞭送过来。张三一口气喝了两杯奶茶，喝过之后一抹眼泪，转身走进去了——这当然能成立自动投案。我的问题是，如果他一抹眼泪还没有走进去就被抓了，是自动投案吗？同样能认定，因为他经查实确已准备去投案，你看平台上那个备注都有，所以这种情况要认定为自动投案。

**其六，因病伤或者为了减轻犯罪后果，委托他人先代为投案。** 比如我犯罪之后，因为身体不舒服嘛，或者各种原因我想去投案但不能亲自去，我就找到马峰，我说"马哥，你做我的代理人好不好，关系那么好，你替我去投案"。马峰说好，他呢就走进公安局，然后就把我的犯罪事实如实地向公安进行了交代。那如果在约定的时间内我去找公安投案，我能不能认定为自首？属于自动投案，当然可以。当然大家要注意，马峰过去不是做人质的，他交代之后是可以出来的，这一点要知道。

**其七，公安机关通知犯罪嫌疑人的亲友，或者亲友主动报案后，将嫌疑人送去投案。** 请问为什么是公安机关通知呢？因为抓人通常都是公安。亲友主动报案后把嫌疑人送去投案——注意这个"送去投案"可不能捆绑。比如警察找到张三的亲友，然后说"你赶快劝一劝，让他来投案吧"，其实这也是受到规劝之后投案，它和前面说的有相同之处。切记这个送去投案不能捆绑，一旦捆绑，那就没有体现"我想坐牢"的精神，而是被动归案。

**其八，并非出于犯罪嫌疑人主动，而是经亲友规劝、陪同投案。** 劝一劝，嫌疑人同意了，然后亲友陪着他一块去投案，那这个时候仍然要认定为自动投案，因为他体现了主动性、自动性。这是司法解释规定的常见的八种自动投案情形。

#### 视为自动投案：司法解释的补充情形

最后看司法解释的另一块内容：犯罪嫌疑人具有下列情形之一的，视为自动投案。各位，仍然要体现"我想坐牢"的精神，我们一个一个看。

**其一，犯罪后主动报案，虽然没有表明自己是作案人，但是没有逃离现场，在司法机关询问时交代自己罪行。** 请问有没有体现"我想坐牢"的精神？当然有。他能不能选择逃跑？完全有机会有可能啊。他犯罪之后主动报案，而且在现场等待司法机关询问的时候就如实交代了，充分体现了"我想坐牢"的精神，所以认定为自动投案。

**其二，明知他人报案而在现场等待，抓捕时无拒捕行为，供认犯罪事实。** 注意这个"在现场等待"的前提是"明知他人报案"。张三犯罪之后，他亲眼看到、亲耳听到别人正在报警，他仍然在现场等着；等警察过来抓人的时候，他没有任何拒捕行为。请问有没有体现"我想坐牢"的精神？有啊。当他看到别人报警的时候，他能不能选择逃跑？可以，他没有选择逃跑，而是留在现场等待，这充分表明体现了"我想坐牢"的精神。

**其三，在司法机关未确定犯罪嫌疑人、尚在一般性排查询问时，主动交代自己罪行。** 什么叫"一般性排查询问"？指的是没有什么针对性。高铁站、地铁站，见一个人查一个，这就是一般性的排查询问。各位你一看警察在前面一个一个查，然后你走过去说"大哥别查了，那个我我我投案，我认罪啊，是我干的，我之前偷了别人的东西"——这就是一般性排查询问，因为你身上没有任何犯罪嫌疑，也没有任何犯罪证据，警察看不到你的犯罪证据。这一点要注意。

**其四，因特定违法行为被行政拘留、司法拘留、强制隔离戒毒等行政司法强制措施期间，主动向执行机关交代尚未被掌握的犯罪行为。** 有人说他都已经被抓了，怎么可能还是自动投案？各位，他是因为犯罪被抓的吗？不是，他是因为特定的行政违法行为被行政拘留或者司法拘留。各位想一想，投案的时间要发生在什么之前？被讯问、被采取强制措施之前。而这个"强制措施"指的是刑事强制措施，比如刑事拘留、逮捕、监视居住、取保候审等等。在这个案例中，他的确是被限制了自由或者剥夺了自由，但他并不是因为犯罪嫌疑被剥夺自由，他是因为普通的违法行为。

举个例子：某工程师因为嫖娼被行政拘留十天，进了拘留所之后一看，哎，有熟人，马峰也在，两个人就聊聊天。工程师问"你怎么也进来了"，马峰说"嫖娼，拘留了十天"，工程师说"我也是啊"，两个人在里面还挺开心，还聊聊法制史、聊聊法理和宪法。眼看着这个行政拘留十天就快结束了，各位，如果正常情况来讲，他们两个都可以顺利出来。

但这个时候马峰受到了某种感化，他找到了管教，说"管教啊，这些天我认真反思，然后我要向你们如实交代，其实我还有严重性病"。工程师一听说"我也是"，那性质就不一样了——因为明知自己患有严重性病而卖淫嫖娼，那是构成传播性病罪的，那可不是一个普通的行政违法行为。所以各位你可以想，他们两个之前的确被行政拘留，但他们受到讯问了吗？没有，讯问是针对犯罪嫌疑人；他们被采取刑事强制措施了吗？也没有。所以此时主动交代办案机关尚未掌握的犯罪行为，司法解释才规定视为自动投案。

**其五，兜底条款：其他符合立法本意、应当视为自动投案的情形。** 所以大家一定要牢牢注意"我想坐牢"这几个字，只要符合这个精神的，可以认定为自动投案。刚才马峰和工程师那两个人，他们行政拘留期间主动交代，行政拘留不叫坐牢，它和犯罪没有关系的，眼看着自己都快出去了还主动交代，这同样体现了"我想坐牢"的精神，属于自动投案。

#### 形迹可疑与犯罪嫌疑：一条必须分清的分水岭

**其六要重点讲，它和前面投案方式里的第三种其实是同一条规则：** 罪行未被有关部门、司法机关发觉，仅因形迹可疑被盘问教育后，主动交代犯罪事实的，应当视为自动投案。

形迹可疑就是走路鬼鬼祟祟、长相畏畏缩缩、眼神飘忽不定。但如果有关部门、司法机关在他身上、随身携带的物品、驾乘的交通工具处发现了与犯罪有关的物品——各位，一旦发现犯罪证据，表明他已经不是"仅因形迹可疑"了，这叫犯罪嫌疑。

我自己身上就出现过真实案例。2021年，当时疫情还没有解封，我坐高铁去出差，刚落座。我们知道高铁上都有乘警，一个警察就过来了。当时我是坐着的，他是站着的，那他很明显是俯视我，我是仰视他。他看我的时候就一直盯着我看，我还戴着口罩呢——当时戴口罩是必须要戴的呀——他眼睛也没那么大，就盯着我看。我当时第一反应是：我形迹可疑吗？我干了什么事吗？我不就戴个口罩吗。我想他要干嘛呢，他就这样俯视着我。

紧接着我是仰视他，我就是这么四目相望。各位我紧张吗？我不紧张。为什么？因为我没有犯罪嫌疑，我甚至都没有形迹可疑。我就这样很自然、很放松地看着他，你不讲话，我也不讲话。就这样，然后警察紧接着就走过来了，说"你好，你是那个陈润海老师吗？"哎哟，我当时懵了一下，说"你是……"。他说"哦，我是你之前的学生，大概两三年前的学生了"。我一听"哦"，然后我们两个就在高铁上开始聊天了，他还给我泡了杯茶，特别热情、特别好。

聊的过程中，因为刚开始聊工作聊了好长时间，我问他"你抽烟吗"，他说"我不抽，陈老师，高铁上可不能抽烟啊，我们前面拘留了好几个了"。我说"拘得好，拘得好，我也不抽"。各位看职业敏感性多强啊。他又跟我说"我戴着口罩，您怎么认出来我呢"，他说很简单，"我们这种职业是有敏感性的，只要长时间看过一个人，他基本上就忘不掉，他看到你的特征之后，就立马能够联想起来"。这真的好厉害啊。

各位你可以想：如果警察俯视我一直盯着我看，我心里有点发毛，但是我身上没有任何犯罪证据，我说"警察同志别这样看我了，我招，我干的，两年前我骗了人，三年前我盗窃"——这一定是自动投案呀。我两年前诈骗、三年前盗窃，各位你想一想，我身上有任何犯罪证据吗？没有。仅因形迹可疑被司法机关盘问教育后主动交代自己罪行，自动投案。

但如果他这样看着我，然后我假装很镇定，其实我已经形迹可疑了，然后我也这样看着他。看着他看着看着，他说"你包里面什么东西啊？"，包打开一看，警察说"这是不是你干的"，我说"不是不是，怎么在你包里面，我不知道"。各位想一想，我这还是形迹可疑吗？不是，这是犯罪嫌疑了。即使我矢口否认，警察也会把我带走继续侦查的，因为他有犯罪嫌疑，因为发现了和犯罪有关的物品。这样讲不就清楚了吗？

所以我们司法解释才规定：如果有关部门、司法机关在其身上、随身携带的物品、驾乘的交通工具处发现与犯罪有关的物品，那就不能认定为自动投案，我是被查获的，我是被动归案。如果仅因形迹可疑，我仍然是主动交代的；如果被查获，他根本没有体现"我想坐牢"的精神。

我讲课之前还特意查了查，当时印象中还发了一个微博，2021年1月18号的事了。当时那个警察还跟我讲"老师能不能一起合张影"，我说可以啊，然后我俩还一起合了张影。但合影的时候我告诉大家：你们以后一定要注意跟警察合影，千万有些动作不要做。我当时比了个手势，做了那个举动之后发了这个微博，紧接着就有评论说"你这是在指认犯罪现场吗"——哇，气死我了，这就不是指认犯罪现场。

这个故事可以充分表明何为形迹可疑，何为犯罪嫌疑。**形迹可疑就是单纯地看着有问题，没有任何犯罪证据；而犯罪嫌疑是指在形迹可疑的基础之上，从他的身上、周围、交通工具等处发现了和犯罪直接有关的物品。既然发现了犯罪证据，那他就是被动归案。**

下面两个例子都来自于《人民法院报》，对照着看最清楚：

| 判断要点 | 例一 | 例二 |
| --- | --- | --- |
| 盘查起因 | 公安机关设卡例行检查，发现甲神色慌张、形迹可疑并盘问 | 甲运输时发现前方500米有检查站，将赃物埋在路边，到检查站时因神色慌张被盘问 |
| 交代之后 | 公安人员随后从其携带的行李箱里面当场查获 | 甲交代了犯罪事实，并带领公安人员找到了埋藏物 |
| 交代的实质意义 | 没有——即便甲不交代，公安照样能掌握犯罪证据 | 有——通过一般的常规工作手段，公安根本找不到 |
| 定性 | 已有犯罪嫌疑，属于被动归案 | 仍属仅因形迹可疑 |
| 结论 | 不能认定为自动投案，不可能成立一般自首 | 可以认定为自动投案 |

所以关键就在这里：**例一中，即便甲不交代，公安机关仍可掌握犯罪证据，此类情形下的交代对确定嫌疑人不具有实质意义，所以不能认定为自动投案；例二中，如果不交代，公安通过通常的、常规的手段是找不到的，所以此时的主动交代对确定犯罪嫌疑人的身份具有实质意义，因此可以认定为自动投案。** 大家可以在例二这种场景下想一想，如果他矢口否认——"我没干，我是好人，我从来没干过坏事"——公安拿他没办法的。所以此种情形属于"我想坐牢"，例一没有体现"我想坐牢"的精神，例二是有的。

只有"仅因形迹可疑"被盘问教育，才能认定为自动投案，这一点请注意。

### 如实供述自己罪行

成立一般自首要满足两个条件：一是自动投案，二是如实供述自己罪行，缺一不可。

> **定义**：如实供述自己罪行，指的是如实供述自己实施、并应由本人承担刑事责任的罪行。如实供述的犯罪既可以是单独犯罪，也可以是共同犯罪；既可以是一罪，也可以是数罪。

#### 主要犯罪事实：两条硬指标

首先要如实供述自己的主要犯罪事实，这是最起码的要求。主要的犯罪事实有两个指标：

> **定义**：一是影响定罪的事实，必须如实供述；二是严重影响量刑的事实，也就是重要的量刑情节，也必须要供述出来。

**例一：隐瞒持刀，不影响定罪也不影响量刑，仍属如实供述。** 假如张三供述自己抢劫的事实，但是隐瞒了自己持刀。警察说"抢了吗"，他说"抢了，怎么抢的"，然后就把他打倒、取走其财物，但是他没有提自己拿刀的事。各位，抢劫中持刀是一个重要的量刑情节吗？当然不是。赤手空拳将别人打倒，和拿着刀去威胁别人、压制其反抗，那都是构成抢劫罪的基本犯。因此即使隐瞒了持刀的情节，这个情节它影响定罪吗？不影响；影响量刑吗？也不影响。所以仍然是如实供述。

**例二：把故意杀人说成擦枪走火，连性质都变了，不成立自首。** 张三一枪将李四打死，故意杀人，然后去投案。首先他是自动投案，警察说来，你描述一下这个案件经过。他说"我当时拿起枪的时候正在把玩，然后不小心碰到了扳机，擦枪走火，不小心把他打死了"。各位，这是如实供述还是撒谎？当然是撒谎，不能认定为自首。本来是故意杀人，但他表述为擦枪走火，那就认定为过失致死了。这表明他的表述严重影响定罪，连犯罪的性质都发生了改变，因此不能成立自首。

**例三：隐瞒同种犯罪，严重影响量刑，不成立自首。** 张三总共抢劫三次，投案以后如实供述自己罪行，警察说要老实交代，说好抢了几次？他说两次，隐瞒了第三次抢劫。请问隐瞒第三次抢劫会影响抢劫罪的成立吗？不影响。但会影响抢劫罪的量刑吗？会，而且影响很严重。因为一旦是三次抢劫，即可被认定为多次抢劫，多次抢劫属于情节加重犯，处十年以上直到死刑。而如果隐瞒了第三次，那只有两次抢劫，那就是普通抢劫，三年以上十年以下。

入库案例也是这样：甲一共三次抢劫，其中第三起还是抢劫致人死亡，他投案以后只交代了前两起，隐瞒了最后一起。抢劫致人死亡是结果加重犯，要处十年以上直到死刑。隐瞒第三起以后，这就意味着他所交代的剩下两起充其量就是个普通抢劫。由于隐瞒的事实严重影响量刑，所以他没有如实供述，不能成立自首。

#### 身份信息：撒谎与否，关键看是否影响定罪量刑

除了如实供述自己的主要犯罪事实外，第二个要求是如实供述自己的身份信息。司法解释规定，如实供述自己的罪行，除供述自己的主要犯罪事实外，还应当如实供述自己的姓名、年龄、前科等情况——这些内容我们统称为身份信息。那如果身份信息没有如实供述、撒谎了，怎么办？要一分为二来看待：

> **结论**：犯罪嫌疑人供述的身份情况与真实情况有差别，但是不影响定罪量刑的，仍然认定为如实供述；犯罪嫌疑人自动投案后隐瞒自己真实身份等情况，影响定罪量刑了，就不能认定为如实供述。

第一个例子：我犯了诈骗罪，骗了别人很多钱，我担心之后被处罚更重，所以我想去投案。自动投案、如实供述，成立自首，争取自首情节。找到警察之后，那警察肯定会问我一些问题：作案经过、主要犯罪事实，还会问我的身份信息。问到"姓名"的时候，我突然一想，我不能把自己的真实名字说出来——那么多人认识我，多丢人啊。我灵机一动，他问姓名，我说"我叫陈润海"。哎，你这一说，警察说"你这名字我知道啊"，我说"不是不是，我叫车润海"。警察一脸狐疑："车润海？你是外国人吗？"我顺势说"啊对，我是国际友人"。

紧接着我被定罪判刑了，该怎么量刑？各位，我就仅仅一个名字撒了谎。请问我第一，如实供述了主要犯罪事实，影响定罪的事实和影响量刑的事实都说了；第二，我的身份信息的确撒了谎，没有敢说自己的真实姓名，而报了一个假名。各位，这影响定罪量刑吗？不影响。所以我还是可以认定为自首。

第二个情况就不一样了：那如果警察找到我、问我姓名之后，又问"年龄"，我想天哪，这么大年龄了还骗人还犯罪，好丢人啊，那怎么办呢？我就说"17岁，花季少年"。警察就看看我，说"你这个长相……17？"我说"对呀，17岁，真的是17岁，花季少年，如果你不信，我可以给你变个魔术"，比了个手势，警察才信了我的说法，17岁，然后按照未成年人犯罪对我进行处理。我想问：我谎报了自己的年龄，会不会影响定罪量刑？会。未成年人犯罪应当从轻或者减轻处罚。这就不得认定为如实供述，不能成立一般自首了。

当然这个情况太极端了，一般比如19岁谎称17岁还有可能，像我这个年龄肯定不可能了。

#### 合理辩解、推诿罪责与翻供

在"如实供述"这个点上，还要关注几个小问题。

**其一，合理辩解不影响如实供述的认定，关键看是否合理。** 不能狡辩、不能撒谎——所以合理辩解这件事，取决于是否合理。犯罪人他是有自我辩护的权利的，他甚至可以委托律师去辩护，所以就事实问题、就法律的适用问题，他可以发表自己的见解和想法。

举个例子：张三犯罪之后找到警察去投案，自动投案，而且如实供述了整个犯罪的经过，到这一步正常情况就要认定为自首了。但警察说"你这个情况是抢劫呀"，张三说"不，警察同志，我认为我这是抢夺，不是抢劫罪"。警察说"不，你这肯定是抢劫"。张三说"我法律职业资格考试都通过了，这一定是抢劫"。警察说你疯了吗。张三一生气，一刀把警察捅死了——各位，这案子很极端，就是让大家记住这个考点。捅死警察构成故意杀人罪，这没有任何争议；但是他丝毫不影响前面抢劫或抢夺自首的认定，他可以辩解，我认为我这就是抢夺，没问题的。他只要把自己案发的经过如实交代出来就可以。所以切记，合理辩解不影响。

书上举的例子也是：假如如实供述杀死乙的事实，但他认为自己属于正当防卫，他说"我就是正当防卫呀"——不影响，他可以辩解、合理辩解；但是不能撒谎，案件事实不能撒谎，就性质他可以提出自己的意见。

**其二，推诿罪责、大包大揽庇护同伙的，不能认定为自首。** 如果犯罪人在供述犯罪的过程中推诿罪责、意图逃避制裁，或者大包大揽庇护同伙、意图包揽罪责，不能认定为自首。比如我和马峰一块犯罪，构成抢劫罪的共犯，警察把我抓了，我找到警察去自首。警察说"就你一个人吗"，我说"对，要杀就杀，要剐就剐，悉听尊便，就我一个人，与他人无关"。请问我有没有如实供述主要的犯罪事实？没有。在共同犯罪的情况下，要如实供述自己、还有自己同伙的，才能认定为自首。这一点要注意，这是逞个人英雄主义，不能认定为如实供述。

**其三，翻供的，只给一次机会，而且时间点要记牢。** 犯罪嫌疑人自动投案并如实供述自己罪行后又翻供的，翻供表明他就没有如实供述了，不能认定为自首。但是给一次机会：**自动投案并如实供述自己罪行后又翻供，但在一审判决前又能如实供述的，应当认定为自首。** 切记是"一审判决前"。

> **易错点**：如果是在一审阶段翻供、在二审阶段又如实供述的，不能认定为自首。所以先如实供述又翻供，不能成立自首；只给一次机会，在一审判决前又能如实供述的，可以认定为自首。

#### 供述的时间：掌握主要犯罪事实之前

最后是如实供述自己罪行的时间。这一点从来没考过，请大家要留意一下。

根据司法解释规定，犯罪嫌疑人自动投案的时候没有交代自己的主要犯罪事实，但是在司法机关掌握其主要犯罪事实之前主动交代的，还是可以认定为如实供述自己罪行，这一点要注意。

比如张三犯罪之后去投案，但投案的时候他避重就轻，说的是比较轻的部分，主要的犯罪事实没交代。但这个时候呢，因为他毕竟投案了，案件还没有被发现，司法机关也不掌握。那么如果张三在第二次讯问、第三次讯问的时候把主要的犯罪事实交代出来了，而且这个时候公安机关还没有掌握，他仍然可以成立自首。

### 一般自首的完整判断链

这一讲的内容比较重要，我最后多说几句，把两条线并到一起。

第一条线是自动投案。自动投案要求主动、自动，要体现"我想坐牢"的精神；投案的方式，司法解释规定的就是那句口诀——电信负责人被司法通缉，准备委托亲友去规劝，只要满足"我想坐牢"这种精神，都可以认定为自动投案。除此之外我们还补充了司法解释的其他规定，比如明知他人报案而在现场等待抓捕时无拒捕行为、如实供述自己罪行的，同样可以成立自首；只要体现"我想坐牢"的精神就可以。

这条线上尤其要注意的是首次归案是自动还是被动——如果首次归案是被动的，那就不可能认定为自动投案，也就没有一般自首的可能了。我们还重点分析了形迹可疑和犯罪嫌疑的关系：就在他的身上、周围有没有找到犯罪证据，找到了那叫犯罪嫌疑，找不到那叫形迹可疑；只有在形迹可疑的情况下，经盘问教育后才有可能认定为自动投案。

第二条线是如实供述。在自动投案的基础上，还要如实供述自己罪行。首先，如实供述主要犯罪事实，这是绝对不能撒谎的，一旦撒谎，不能成立一般自首——注意判断标准是"影响定罪的事实"和"严重影响量刑的事实"这两条硬指标。其次，如实供述身份信息，身份信息撒谎了怎么办？一分为二：不影响定罪量刑的没关系，还可以认定为自首；影响定罪量刑的不能认定为自首。第三，如实供述以后又翻供怎么办？不成立自首，但给一次机会，在一审判决前又能如实供述的，成立自首。最后，合理辩解不影响如实供述的认定，这一点非常重要。

> **结论**：一般自首 = 自动投案 + 如实供述自己罪行。自动投案看"我想坐牢"的精神、看有没有被讯问或强制、**看首次归案是主动还是被动**；如实供述看主要犯罪事实、看身份信息、看是否翻供、看供述是否在司法机关掌握之前。

> **承前启后**：上一节讲完「一般自首：自动投案与如实供述」，下一节接着讲「特别自首、共犯与数罪自首、单位自首与坦白」。

## 特别自首、共犯与数罪自首、单位自首与坦白
> 对应块：BLK63 | 覆盖分集：P63 | 块标题（分集名）：《第14章 第04节：自首与坦白（02）》

下面进入特别自首。先看法条：

> 被采取强制措施的犯罪嫌疑人、被告人和正在服刑的罪犯，如实供述司法机关还未掌握的本人其他罪行的，以自首论。

由此，特别自首的概念是**三类人**——被采取强制措施的犯罪嫌疑人、被告人和正在服刑的罪犯，加上**如实供述**，加上**两个指标**：一是司法机关还未掌握，二是本人其他罪行。

所以"特别"自首的成立条件就分成两项：第一是主体条件，第二是内容要求。

### 特别自首的主体：只能是这三类人

站在主体条件上看，特别自首的主体只能是这三类人，切记切记，主体条件讲完我们才往下看内容。

第一类，**被采取强制措施的犯罪嫌疑人**。强制措施根据《刑事诉讼法》的规定，包括拘传、拘留、逮捕、取保候审、监视居住——这五种属于刑事强制措施。

第二类是**被告人**。

第三类是**正在服刑的罪犯**。指的是已经人民法院判决、正在执行所判刑罚的罪犯。

> **易错点**：正在服刑，未必是在监狱服刑。比如张三被判处管制，在管制执行期间——这同样是在执行所判刑罚，仍然属于正在服刑的罪犯。

三类人以外的犯罪分子不能成立特别自首。

### 为什么特别自首的供述要求更高

要求各位先不要看书，听懂背后的法理。

请问怎么样才能成立一般自首？两个条件：不但要自动投案，而且要如实供述。注意这个时候他如实供述的内容，司法机关掌握不掌握**不重要**。只要在自动投案的基础之上又如实供述，那都能成立一般自首。

比如张三杀了人，公安机关立案侦查，公安机关也知道就是张三杀的人，其实张三的犯罪事实公安已经掌握了。那张三潜逃外地期间选择投案，首先是自动投案，其次如实交代自己杀人的过程——虽然这个过程已经被公安机关掌握了，但张三仍然能构成一般自首。

现在各位想一想特别自首：特别自首的主体是那三类人。以被采取强制措施的犯罪嫌疑人为例，他都已经被羁押了，换句话说他丧失了自动投案的可能，他不能自动投案，而且是被采取了刑事强制措施。那这个时候他成立特别自首，就只能靠如实供述。

那么各位能不能说他只要如实供述，都能成立自首？**不可以**，否则的话他对一般自首的人就不公平啊。一般自首要满足自动投案加如实供述两个条件，而这三类人如果只要如实供述就能成立自首，这就表明自首的条件其实不要求自动投案了——如实供述不就可以了吗？只要如实供述就成立自首，很明显不合理。

所以，既然这三类人不能自动投案了，他想成立自首，我们对他如实供述的要求就会更高一点。

> **结论**：要满足两个条件才能认为是特别自首。第一，供述的内容是司法机关还没有掌握的；第二，必须是本人的其他罪行。

### 第一个指标：司法机关尚未掌握

被采取强制措施的犯罪嫌疑人、被告人和正在服刑的罪犯，如实供述司法机关尚未掌握的罪行——他强调**尚未掌握**，而且与司法机关已经掌握或者判决确定的罪行属于**不同种罪行**。一"还未掌握"，二"不同种"，才能以自首论。拆开来，两个指标一个一个看。

先看第一个指标。如果司法机关已经掌握了，那就不能成立特别自首。

**例一**：甲因盗窃被判 3 年，服刑期间如实供述自己的杀人事实，且该事实司法机关尚未掌握。他满足第一个主体条件——正在服刑的罪犯；也满足内容条件，他所供述的杀人事实，一是司法机关未掌握，二是与先前的盗窃属于不同种罪行。所以就故意杀人罪而言，他能成立特别自首。

**例二**：甲因诈骗被通缉，在潜逃期间又盗窃被当场抓获，如实供述了此前的诈骗事实，但这个事实已经被通缉、已经被司法机关掌握了。虽然和盗窃属于不同种罪行，但他供述的这部分已经被司法机关所掌握，因此也不能成立自首，就诈骗而言，它充其量是坦白。

大家一定要牢牢注意，特别自首必须满足这两个指标：如实供述，一司法机关尚未掌握的，二本人其他罪行。

> **提示**：还有一个点特别重要——"司法机关已经掌握"指的是**有证据证明**的罪行。如果司法机关掌握的线索所针对的犯罪事实并不成立，那就不算数。

举个案例大家就明白了。甲因涉嫌受贿罪被采取强制措施，办案人员找到甲说：你涉嫌构成受贿罪。结果一顿操作猛如虎，一查发现证据不足。各位，证据不足怎么办？正常情况就只能把他给放掉了。但这个时候甲说了一句："哎呀你们办案人员辛苦了，我再交代一点东西哈。"然后在办案人员掌握的线索之外，他又交代了自己受贿的事实，能够成立受贿罪。

这就是主动供述了新的受贿事实。就刑法而言，他是可以成立自首的。所以切记，一定是在办案机关掌握的线索以外，他又提供了新的线索、能证明犯罪成立，这个时候是可以认定为自首的。**它体现了我想坐牢的精神。**

### 第二个指标：本人其他罪行——罪名不同且关系不密切

再看第二个指标：如实供述的必须是不同种罪行。

何为不同种罪行？如果你不想看那么多的字，来记一个公式就可以了：

> **其他罪行 = 罪名不同 且 关系不密切**

罪名相同的，一定是同种罪行。那么如果罪名不同，但两个罪的关系密切呢？司法解释规定，也按照同种罪行来处理，换句话说不能成立特别自首。只有罪名不同**且**关系不密切，才能认为属于"其他罪行"。

#### 罪名相同：即为同种罪行

犯罪嫌疑人、被告人在被采取强制措施期间，如实供述本人其他罪行，该罪行与司法机关已经掌握的罪行属于同种还是不同种罪行，一般应当以罪名区分。罪名相同的即为同种罪行，不能成立特别自首。

比如甲因盗窃被刑事拘留，又交代了公安机关尚未掌握的其他盗窃事实。这个事实虽然是公安机关尚未掌握的，但它属于同种罪行，而并非"本人其他罪行"，所以不能成立特别自首。

#### 罪名不同但关系密切：也是同种罪行

司法解释有明文规定：虽然如实供述的其他罪行，罪名与司法机关已经掌握的罪名不同，但如实供述的其他犯罪与司法机关已经掌握的犯罪，属于**选择罪名**，或者在**法律和事实上具有密切关联**的，应当认定为同种罪行。

注意这个"法律和事实上有密切关联"，比如像吸收犯、牵连犯。

书上第一个例子直接来自司法解释：甲因为受贿被逮捕，又供述因受贿而实施的滥用职权罪。抬头看我——即使这个滥用职权罪是司法机关尚未掌握的罪行，他也不能成立特别自首。因为特别自首要满足两个指标，一司法机关未掌握，二本人其他罪行；"其他罪行"要求罪名不同**且**关系不密切，才是其他罪行。而受贿罪和这个滥用职权罪，在本案中关系很密切，他们是原因和结果的牵连关系：正因为收钱构成受贿，所以才替别人办事构成了滥用职权。所以司法解释就规定，此种情形不能认定为特别自首，就滥用职权罪而言，他充其量也就是个坦白。

第二个例子：甲因拐卖妇女被逮捕，然后又供述了自己拐卖儿童。刑法规定的罪名是"拐卖妇女、儿童罪"，所以拐卖妇女和拐卖儿童属于**选择罪名**，在法律上是具有密切关联的。因此即使交代了司法机关尚未掌握的拐卖儿童的事实，就拐卖儿童罪也不可能成立特别自首。这一点请大家要注意。

#### 一正一反的小结

从内容要求上看，一正一反：

| 供述的内容 | 认定 | 法律后果 |
| --- | --- | --- |
| 司法机关尚未掌握、且罪名不同关系不密切的罪行 | 本人"其他罪行" | 以自首论，成立特别自首 |
| 司法机关已经掌握的罪行 | 不属于"其他罪行" | 不能成立特别自首，充其量是坦白 |
| 尚未掌握，但罪名相同的罪行 | 同种罪行 | 不能成立特别自首 |
| 尚未掌握，罪名不同但关系密切（选择罪名、吸收犯、牵连犯）的罪行 | 同种罪行 | 不能成立特别自首，充其量是坦白 |
| 如实供述的同种罪行 | —— | 可以酌情从轻处罚 |

一句话总结：特别自首的主体是三类人，要如实供述；因为它没有自动投案，所以对如实供述的要求肯定更高——第一，司法机关尚未掌握；第二，本人其他罪行，而"其他罪行"要求罪名不同且关系不密切。罪名相同是同种罪行，罪名不同但关系密切也认为是同种罪行，这一点要知道。

### 自首的法律后果，以及过失犯罪也能自首

自首基本问题全部结束。翻到 226 页，看两种自首的法律后果：

> 对自首的犯罪分子，可以从轻或者减轻处罚，其中犯罪情节较轻的可以免除处罚。

接下来讨论自首的其他问题，主要是自首所关联的几种制度。请问一个人如果犯的是过失犯罪，过失犯罪之后能不能自首？当然可以。比如交通肇事撞了人，把人撞死之后，他自动投案、如实供述，也能成立自首。所以故意犯罪后能自首，过失犯罪后也能自首。

### 共同犯罪人自首：先交代自己，再交代同伙

集中讨论三种情形，第一种是共犯人的自首。

按照前期讲的，共同犯罪的分类是**作用为主、兼顾分工**：作用为主分成主犯、从犯、协同犯，兼顾分工还要把教唆犯单列出来。整个共同犯罪人在这个过程中如果想成立自首，要满足什么条件呢？我们认为，自动投案的认定不难，所以共同犯罪人能否成立自首，关键取决于**如实供述**。

而如实供述的范围，是与其在共同犯罪中的**作用和具体分工相适应**的——这再次体现了"作用为主、兼顾分工"。所以我们可以分类讨论：主犯要如实供述什么，从犯、胁从犯、教唆犯又要如实供述什么。

抬头看我。我们知道自首的成立既要自动投案，又要如实供述，而这个如实供述就是如实供述主要的犯罪事实以及身份信息——当然，身份信息如果不影响定罪量刑，仍然认为是如实供述。共同犯罪人一定是多人犯罪，这就意味着共犯人想自首，大的方向就是：先要交代出来自己干了啥事，还要交代出来自己知道的同伙，把同伙的犯罪事实也交代出来。

如果只交代自己、刻意隐瞒同伙，这叫大包大揽，这叫搞个人英雄主义，这根本不能评价为如实供述——**这叫撒谎**。

其中主犯略微复杂，从从犯开始都很简单。我们来看主犯如何自首。

> **提示**：这里说的供述范围，限于**自己实施并应由本人承担刑事责任的罪行**。把跟自己罪责无关的他人犯罪供出来，那是揭发，可能成立立功，不能成立自首。

| 行为人的身份 | 必须如实供述的内容 |
| --- | --- |
| 首要分子（如犯罪集团的首要分子） | 其组织、策划、指挥作用下的**全部罪行** |
| 其他主犯，但头上有首要分子 | 在首要分子的组织、策划、指挥作用下**单独实施**的共同犯罪行为 |
| 与首要分子无关系的一般共同犯罪中的主犯 | 自己与其他共同犯罪人**共同实施**的犯罪行为 |
| 次要实行犯（从犯） | 先交代自己实施的犯罪，再交代与自己共同实施犯罪的主犯和胁从犯的犯罪行为 |
| 帮助犯（从犯） | 先交代自己的帮助行为，再交代自己所帮助的实行犯的犯罪行为 |
| 胁从犯 | 先交代自己在被胁迫情况下实施的犯罪，再交代所知道的同伙以及胁迫自己犯罪的人所实施的犯罪行为 |
| 教唆犯 | 先交代自己实施的教唆行为，再交代所知道的被教唆人产生犯罪意图后实施的犯罪行为 |

表里第二行为什么要强调"单独实施"？比如各位，黑老大给黑老二下了个命令，让黑老二去把张三打死，黑老二一个人单枪匹马将张三干掉。各位你从表面看，这好像是个单独犯罪，是黑老二一个人把人杀死；但实则不然，他是共同犯罪的内容，因为他是受黑老大的指令。所以黑老二作为主犯想去自首的时候，他必须要如实供述他在首要分子的组织、策划、指挥下单独实施的犯罪行为。

那当然了，如果头上没有黑老大呢？比如张三入户盗窃、李四望风，那张三就是主犯，那张三这个时候想成立自首，必须要如实供述他和其他共同犯罪人共同实施的犯罪行为。

所以共同犯罪自首大的方向就是：先交代自己，再交代同伙。如果刻意地包庇自己的同伙，大包大揽、搞个人英雄主义，那叫撒谎，不得认定为自首。

### 数罪自首：关键在如实供述

数罪自首，顾名思义，指的是一个人犯了数个罪，哪些罪能成立自首、哪些不能成立自首。数罪自首也分数罪一般自首和数罪特别自首。

先看数罪一般自首的逻辑结构。请大家盯着这张图看，不要看我——**数罪自首认定的难点不是自动投案**，因为自动投案太容易认定了、太容易理解了，所以关键就在于他是否如实供述了所犯的全部数罪。

因此数罪一般自首一定是建立在自动投案的基础之上，去研究他如实供述的情况；而如实供述无非分两种：全部供述，全案都能成立自首；如果只供述一部分、隐瞒一部分，又怎么办？分情况处理。逻辑结构就是这个样子：

```text
数罪一般自首（自动投案已成立）
├─ 全部供述
│  └─ 全案均成立自首
└─ 部分供述
   ├─ 异种数罪
   │  └─ 供述之罪成立自首，未供述的犯罪不是自首，效力仅及于供述之罪
   └─ 同种数罪：看如实供述的程度
      ├─ 大致相当（供述的部分要多一点）
      │  └─ 供述之罪成立自首，效力仅及于供述之罪
      └─ 因主客观原因只供述了主要或基本罪行
         └─ 全案成立自首
```

先看异种数罪。一种罪，供述谁谁自首。比如张三犯盗窃、诈骗、抢夺三个罪，这是一种异种数罪。他自动投案之后，仅仅交代了盗窃，诈骗和抢夺只字未提——这就是部分供述。他供述的是盗窃，因此就盗窃罪可以成立自首，诈骗和抢夺不是自首，自首的效力仅基于如实供述之罪。异种数罪太简单了。

那同种数罪怎么办？同种看程度，就是看他如实供述的程度。如果供述的犯罪和未交代的犯罪在犯罪的事实性质、情节和对于社会的危害程度上**大致相当**，就意味着供述的那一部分可以成立自首。

比如张三偷了十次，每次 10 万，价值 100 万。他投案以后交代了六次 60 万，隐瞒了四次 40 万——那么 60 万的范围内可以成立自首，40 万的范围内不能成立自首，自首的效力仅及于如实供述之罪。

当这个"大致相当"，一定要求**供述的要多一点**。为什么供述的要多一点？各位想一想，何为一般自首？是指犯罪以后自动投案、如实供述自己罪行；而按照司法解释的规定，如实供述自己罪行，要求如实供述**主要的犯罪事实**。什么叫主要的犯罪事实？主要的事实一定要因为供述的要多一点，隐瞒的要少一点——简单讲，你说出来的东西一定比隐瞒的东西要多一点。

那如果我偷了十次、总共 100 万，自动投案以后交代了五次 50 万，隐瞒了五次 50 万，在 50 万的范围内能成立自首吗？这个是有争议的，认为不成立。原因就是：你没有如实供述主要的犯罪事实，主要的事实一定要多交代一点。所以这个时候一般认为还不成立自首。但是如果我供述了六次 60 万、隐瞒了四次 40 万，毕竟供述的多了一点、隐瞒的少了一点，可以认定为主要事实，因此在 60 万的范围内能够成立自首。各位这个点很细，大家注意。

那如果由于主客观方面的原因，比如他想尽办法只想起来九次 90 万，剩下一次 10 万真的记不清了、偷的次数太多怎么办？司法解释认为，**全案都可以成立自首**。所以各位，这样的话逻辑就非常清楚了。再看一看这张图，我再梳理一遍他的逻辑：数罪一般自首当然建立在自动投案的基础之上，自动投案不难认定，关键取决于如实供述；如实供述分两种，一全部供述，全案自首；二部分供述，看种类——异种数罪供述谁谁自首，同种数罪看程度，程度有两种，大致相当，供述谁谁自首；主要罪行，全案都自首。看这个逻辑多么的清楚。

这张图一旦你理解了，放在自己的大脑中，到后面的背诵，基本上就是看图说话，直接就能够复盘出来了，所以这张图一定要注意。

#### 数罪特别自首：把特别自首的概念列上去就行

数罪特别自首超级简单，各位就特别自首的概念列上去就可以了：被司法机关依法采取强制措施的三类人——犯罪嫌疑人、被告人和正在服刑的罪犯，如实供述司法机关还未掌握的本人**非同种罪行**（也就是"其他罪行"），以自首论。

那老师，这不就是特别自首的概念吗？为什么说是数罪的特别自首？因为特别自首往往是涉及**数个罪**的。比如甲因为盗窃被抓或者正在服刑，期间甲又交代了司法机关尚未掌握的抢夺事实——我们知道就抢夺罪他是成立特别自首的，第一这是司法机关没掌握的，第二这是本人其他罪行，所以就抢夺而言能构成特别自首没问题吧。但是一旦甲的抢夺罪成立了，这就几个罪了：前有盗窃，后有抢夺，这不就是数罪了吗？所以当他交代抢夺的时候，这其实也是数罪中的自首的情形。大家这一点一定要注意。

### 单位犯罪自首：谁能代表单位

第三，也是最后一个关联问题：单位犯罪自首。

单位能犯罪，单位犯罪之后也能成立自首。单位犯罪要体现单位的意志，要为了单位的利益；那单位犯罪以后自首，也要体现单位的意志。所以我们主要讨论的是：**谁有资格代表单位去自首**。

> **结论**：以下三种情形可以代表单位体现单位意志去自首，而且不光要自动投案，还要如实交代单位犯罪事实。
>
> 一、**单位集体决定**。我们是个公司，犯了罪，我们开个职工大会表决通过，决定自首，这么多员工手拉手、心连心一块找警察去自首，单位集体决定能够体现单位意志。
>
> 二、**单位负责人决定**。比如总经理决定，代表单位到公安去投案、如实供述，可以认定为单位自首。
>
> 三、**单位直接负责的主管人员**。因为他可以代表单位签合同，能代表单位意志；这类人自动投案、如实交代单位犯罪事实的，应当认定为单位自首。

那如果单位自首了，有什么效果？

| 情形 | 结论 |
| --- | --- |
| 单位已自首，直接负责的主管人员和直接责任人员没有自动投案，但如实交代自己实施的犯罪事实 | 可以**视为自首**——因为他们已经被代表了 |
| 同上人员拒不交代或者逃避法律追究 | 不成立自首 |
| 单位**没有**自首，只是直接责任人员自动投案并如实交代自己实施的犯罪事实 | 只能对**这一个人**认定自首，单位肯定不是自首 |

有人要问：主管人员和直接责任人员他都没自动投案，为什么可以视为自首呢？因为他被代表了。各位抬头看我，张三是某公司的总经理，然后他决定代表单位去投案——既然代表单位投案，那会体现单位的意志的，他是总经理，他过去了。此时主管人员李四、直接责任人员王五没有陪着总经理一块去投案，但不重要，因为他们已经被代表了。所以如果李四、王五如实交代自己实施的犯罪事实，对他们可以视为自首。

但反过来就不一样了：单位如果没有自首，直接责任人员自动投案，他有资格直接代表单位吗？经过授权吗？没有。所以直接责任人员自动投案并如实交代自己实施的犯罪事实的，只能对这一个人认定为自首，单位肯定不是自首。比如在逃税罪中，张三是总经理、李四是主管、小花是会计，张三和李四都能代表单位去自首，但小花如果自己一个人去自首，自首的效果只能适用于小花，不能波及到单位——单位是不能享有这样一个待遇的，因为小花不能代表单位、没有资格。

### 坦白：自首吃剩下的那一半

自首及其关联问题全部结束，下面看坦白。

首先看法条，《刑法》第 67 条第三款规定：犯罪嫌疑人虽不具有前两款规定的自首情节——就是不具有一般自首、特别自首的情节——但是如实供述自己罪行的，可以从轻处罚；因其如实供述自己罪行，避免特别严重后果发生的，可以减轻处罚。

从这个意义上来讲，坦白也分两种：**一般坦白是从轻处罚，重大坦白是可以减轻处罚**。但坦白没有像一般自首、特别自首，或者一般累犯、特别累犯那样的专业术语——如果你非要给它起个名字，也可以说一般坦白、重大坦白，但这是我们自己起的名字，出去不要这样讲，你知道把坦白分成这两种就可以了。

那坦白指的是什么？指的是犯罪分子**被动归案以后，如实供述自己罪行，并接受司法机关审查和裁判**的行为。"审查和裁判"简称"审判"。

提个醒：法条说的是"虽不具有前两款规定的自首情节"，这表明什么时候才能认定为坦白？它的**前提是不成立自首**。如果构成自首，直接认定为自首，不考虑坦白的问题。只有在不构成自首的前提下，才能考虑坦白。

因为自首本身就包含着坦白。各位你想，一般自首自动投案、如实供述——如实供述不就是坦白吗？而特别自首要如实供述司法机关尚未掌握的本人其他罪行，这也是坦白呀。所以自首本来就可以包含着坦白。正因如此：**有自首情节优先认定，没有自首情节才有可能认定为坦白。**

举个例子。张三因为盗窃罪被抓了，被抓过之后他就不可能成立一般自首了，然后他如实供述被指控的盗窃事实——各位，这不就是坦白吗？被动归案以后如实供述自己的罪行，成立坦白。

### 自首与坦白：四点相同，人身危险性不同

我们考试分析把坦白归纳为：被动归案后如实供述自己罪行，接受司法机关的审查和裁判。因此自首与坦白之间既有联系又有区别。

相同点包括四项，这四点其实主要是个背诵问题，很好理解——背诵逻辑中的相同点叫"**犯罪后交代，审判时从宽**"：

一、**都以实施犯罪行为为前提**。如果连犯罪都不成立，也就无所谓自首和坦白的问题；
二、**都是归案以后如实交代自己的犯罪事实**，自首要如实供述，坦白也是如此；
三、**都是审判时从宽**，都有接受国家司法机关审查和裁判的行为；
四、**都是法定的从宽处罚情节**，自首和坦白都有法律依据。

不同点则在于，概念不同咱们就不重复了，第二点有点重要：自首与坦白所反映的**犯罪人的人身危险性程度**不同。比如一般自首，人家是自动投案；而特别自首虽然没有自动投案，但他如实供述的是司法机关尚未掌握的本人其他罪行——所以自首的人其人身危险性相对较轻，坦白的人人身危险性相对较重。一般情况下，自首比坦白的从宽处罚幅度要更大：对自首的奖励是个大奖励，对坦白的奖励是个小奖励。

所以自首的法律后果是可以从轻或减轻处罚，其中犯罪较轻的甚至可以免除处罚；而坦白通常情况可以是从轻处罚，因坦白避免特别严重后果发生的可以减轻处罚。

到这一步，我们就讲完了自首、累犯、坦白、特别累犯——都能分成两种：自首分一般自首和特别自首，累犯分一般累犯和特别累犯，坦白也分两种，没有专业术语，我们自己给它起个名字，那就是一般坦白、重大坦白：一般坦白可从轻，重大坦白可减轻，重大坦白指的是因坦白避免特别严重后果发生的。量刑情节里现在就只剩立功这一种了。

### 本讲提到的题目

最后看一道真题：下列情形中哪些属于自首？

- **A.** 甲杀人后，其父主动报案并将甲送到派出所，甲如实供述。
- **B.** 甲与乙共同贪污后，主动到检察机关交代自己的贪污事实。
- **C.** 甲、乙共同盗窃，盗窃后主动到公安机关反映；乙曾诈骗数千，查证属实。
- **D.** 甲给派出所打电话主动交代了自己杀害妻子的事实，然后出走，不知所向。

**答案：A。**

**A 项，成立自首。** 甲父主动报案并将甲送到派出所，这就是**陪同投案**，不影响自动投案的成立。题干有没有说捆绑？没有；没有说捆绑，你就不能默认他是捆绑——如果捆绑，题目一定会交代清楚，所以不要加细。加上甲如实供述，构成一般自首。

**B 项，不成立。** 共同犯罪人的如实供述范围应与其在共同犯罪中的作用和具体分工相适应，大的方向是先交代自己、再交代同伙。题干只交代了自己的贪污事实，对乙只字未提，属于大包大揽、搞个人英雄主义，是撒谎，不能认定为如实供述，因而不成立自首。

**C 项，不成立。** 自首要求如实供述的是自己实施、并应由本人承担刑事责任的罪行。甲交代的是乙的诈骗事实，这属于揭发，最多可能成立立功，不能成立自首。

**D 项，不成立。** 自首以自动投案为前提。D 中甲打完电话即出走、不知所向，明显是在逃跑，既没有自动投案，也没有体现"我想坐牢的精神"。

## 立功：到案以后，揭发的还得与自己无关
> 对应块：BLK64 | 覆盖分集：P64 | 块标题（分集名）：《第14章 第05节：立功》

累犯、自首、坦白都讲完了，量刑情节这一块只剩下立功这一种。翻开书，我们把立功从头到尾捋一遍——这是刑法第 68 条的内容，也是本章法定情节的收尾。

第 68 条的表述是：犯罪分子有揭发他人犯罪行为，查证属实的，或者提供重要线索，从而得以侦破其他案件等立功表现的，可以从轻或者减轻处罚；有重大立功表现的，可以减轻或者免除处罚。

据此可以归纳出立功的概念：立功，是指犯罪分子揭发他人犯罪行为，查证属实，或者提供重要线索，从而得以侦破其他案件等行为。

从条文里一眼就能看出，立功分成两档：

> **结论**：一般立功可以从轻或者减轻处罚；重大立功可以减轻或者免除处罚。

下面先讨论一般立功的成立条件。

### 谁犯罪谁立功：主体与时间

立功的主体只能是犯罪分子。为什么？因为"谁犯罪谁立功"——自首、立功、坦白都属于量刑情节，而量刑只能对犯罪人进行。所以张三犯罪了，张三的父亲在外面替他去立功，不可以。没有犯罪的人谈不上刑法意义上的立功，犯罪分子也必须犯罪以后才谈得上立功。

> **易错点**：亲友不能代为立功。立功的主体只能是犯罪分子本人。

时间上要注意一个特别容易搞错的地方：立功的时间是**到案以后**，不是犯罪以后。司法解释对"到案"要做扩大解释，它包括司法机关在内的所有国家机关、党群组织、所在单位等一切能够接触、约束犯罪嫌疑人的主体。

大家还记得我们讲自动投案的时候讲过，行为人可以向有关负责人员投案、向有关单位投案。比如张三犯罪之后找到自己单位的领导，说"我投案"，各位，这就是和相关单位有所接触了；紧接着他说"我还要立功"——到案以后，那就可以立功。

所以请大家务必注意：立功的时间是到案后，不是犯罪后。它和自首不一样，自首是犯罪以后随时都能自首，而立功一定是到案以后才能立功。

**例一**：甲因挪用公款被单位领导约谈，甲主动联系监委，揭发他人受贿事实。各位，这不就已经到案了吗？那如果查证属实，是可以成立立功的。

**例二**（入库案例）我举一个实务中真实出现过的。甲乙共同伤害他人，警察误将甲当作目击证人，甲向警察指认了乙的逃跑方向，警察据此将乙抓获。甲根本没有到案，也没有表明自己犯罪人的身份——警察以为我是路过的目击证人，根本没把我当成嫌疑人。所以甲不构成立功。

想象一下那个场面：我和马峰一起抢劫，有人报警，警察过来抓我们两个，马峰拔腿就跑，跑得特别快，快马加鞭，我站在原地懵了，还没反应过来，马峰已经跑出了我的视线范围。警察过来看到我，指着我说"你干嘛的？"我说"我就在这旁边路过，刚刚有没有看到有人抢劫？""有，那个抢劫犯跑哪去了？""我就指着马峰跑的那个方向。"警察开车追过去了，把马峰给抓回来了。各位，我是立功吗？我是不是协助抓捕犯罪人构成立功了？不可能。理由很简单：立功的时间是到案以后。请问我的确是抢劫犯，但我到案了吗？没有。因为警察认错了人，他以为我是个目击证人，他根本没有将我当成嫌疑人，我也没有到案。

### 立功为什么值得从宽：两个指标

立功的本质是戴罪立功、将功折罪。为什么对立功的犯罪人可以从宽处罚？他跟前面的自首、坦白是一个道理，要求只有两个：有利于节约司法资源，或者体现犯罪人的人身危险性降低。

节约司法资源很好理解。比如张三犯罪之后，他带着警察把自己的同伙给抓回来了，这就是典型的节约司法资源；而紧接着通过立功将功折罪，可以体现犯罪人人身危险性相对降低。

教材上这段话我们看一下：立功的本质是将功折罪。从法律上看，行为人揭发或者阻止他人犯罪，表明行为人对犯罪行为的痛恨，其人身危险性、再犯可能性降低；从政策上看，行为人揭发或者阻止他人犯罪，有利于节约司法资源。这两句话不用背，理解了就行。

所以对立功从宽处罚的根据是什么？是行为人的人身危险性降低，或者节约司法资源。**如果和这两个指标没有关系，就不得认定为立功。**

**例一**：我们实务中确实出现过，有人犯罪之后为了获得从宽处罚，刚被抓就说"我要向地震灾区捐款 1000 万"。各位，这个捐款 1000 万是节约了司法资源吗？没有。能体现他的人身危险性降低吗？没有。和人身危险性没有关系，由此不能成立立功。如果这种情况都能成立立功，各位你感觉公平吗？这不是花钱买刑吗？花了钱之后让自己的刑罚变轻，明显不公平。

**例二**：甲到案以后，为减轻罪责，揭发其父贪污事实。各位，这也是揭发他人犯罪行为，查证属实，也节约了司法资源，所以成立立功。这个点要注意——揭发的是自己的父亲，照样成立立功。

### 一般立功的四种表现

根据刑法第 68 条和司法解释的规定，我把一般立功的表现分成了四个方向。先拿起笔勾一下，我们要先有框架意识，然后再去关注细节，这样记得才更清楚。请把书翻到 229 页，跟着 PPT 一起看：

- **揭发型**：检举揭发他人犯罪行为；
- **线索型**：提供侦破其他案件的重要线索；
- **协助型**：协助抓捕其他犯罪嫌疑人；
- **其他型**：兜底的其他有利于国家和社会的突出表现。

重大立功也是这四个方向。建议大家一定记一记：一般立功、重大立功都是揭发型、线索型、协助型、其他型这四项，满足的都可以认定为立功。但是每一项都有自己的细节，我们一项一项看。

先看第四项"其他型"（书 230 页），它只有两句话：阻止他人实施犯罪活动，以及具有其他有利于国家和社会的突出表现。比如张三在看守所的时候，发现自己的室友李四想自杀，张三就阻止了李四自杀，一般认为可以评价为具有其他有利于国家和社会的突出表现，认定为立功。

下面三节，我们重点讲前三类。

### 揭发型立功：揭发的必须与自己无关

按司法解释规定，揭发型立功是指：犯罪分子到案后，检举揭发他人犯罪行为，包括共同犯罪案件中的犯罪分子揭发同案犯共同犯罪以外的其他犯罪，经查证属实，应当认定为立功。

请注意我把"他人"圈起来了，旁边要记一句话：**与自己无关，不能与自己有关。**

#### 要点一：揭发的内容必须是犯罪行为

只要揭发的是他人的犯罪行为就可以。至于他人有没有被实际追究刑事责任，并不重要。

张三犯罪之后跟警察说"我要立功，我揭发李四杀人"，查证属实，李四果然杀了人——但李四两年前已经死了。张三是立功吗？同样构成立功。因为立法规定立功只要求是揭发他人的犯罪行为，从性质上看，只要是个犯罪行为就可以，至于他人有没有被实体追究刑事责任，不重要。

但反过来就不行。张三说"我要立功，我揭发李四杀人"，一查李四果真杀了人，但李四的行为属于正当防卫。请问张三现在揭发出来的是一个犯罪行为，还是一个正当防卫行为？正当防卫可不是犯罪行为，那张三就不能成立立功。

书上的例三是同一个道理：甲到案后揭发乙故意毁坏财物，经查证属实，但乙的毁坏财物行为属于紧急避险。紧急避险不是犯罪行为，而是合法行为，所以甲依然不成立立功。

这三个例子讲的是同一件事，我再说一遍：**只要求揭发的内容属于犯罪行为即可，不要求被揭发的人实际被追究刑事责任。**

#### 要点二：揭发同案犯的共同犯罪事实，属于如实供述

司法解释规定：共同犯罪案件的犯罪分子到案后，揭发同案犯共同犯罪事实，可以酌情从轻处罚，不构成立功。

为什么？因为共同犯罪是个整体行为。所谓揭发共同犯罪事实，其实也是在交代自己的犯罪事实。我和马峰构成抢劫罪的共犯，我到案之后跟警察说"警察，我要立功"。警察说你立什么功？我说"不是我一个人干的，我还有同伙，我同伙叫马峰"。各位，你感觉我这叫立功吗？疯了——我这就是在如实供述自己的犯罪事实。抢劫罪的共同犯罪事实本来就是我参与的，本来就是一个整体行为，所以这种情况不可能成立立功。

但是，如果我说"我要立功，我揭发马峰强奸"，而马峰的强奸是他自己单独实施的——各位，这还是共同犯罪事实吗？不是。这才有可能成立立功。

**例一**：甲乙共同盗窃后，甲被抓，揭发乙参与盗窃的事实。这不可能构成立功，只能评价为如实供述。根据刑法规定，揭发"他人"的犯罪行为、查证属实，构成立功。注意"他人"指的是和自己没有关系，也就是必须是共同犯罪以外的其他犯罪。甲揭发乙参与盗窃的事实，既是共同犯罪事实，其实也是自己供述的事实，由此不成立立功，充其量是坦白——被动归案以后如实供述。

**例二**（对象犯）：我向官员张三行贿之后自动投案，工作人员问我"你向谁行贿了？"各位，如果我把张三说出来，属于不属于揭发他人的受贿行为？对，我可以成立立功。各位你想想怎么可能啊——我过去之后，如果我自动投案而且交代自己的行贿行为，那必然要涉及到张三；如果不把张三说出来，我就不可能是如实供述。所以此时我交代出向张三行贿，这是如实供述的内容。我前有自动投案，后有如实供述自己的罪行，只能认定为自首，不能再认定为立功。你认为这是揭发他人的犯罪行为，这不是有点荒唐吗？

这里的法理是：行贿罪、受贿罪属于对象犯，属于共同犯罪中的对象犯。一方犯罪行为的实施，以相对方对应的行为为条件；没有行贿受贿，就没有办法完成具有对象关系的犯罪。一方在供述自己犯罪行为时，必然会涉及到相对方的犯罪行为，否则就不能完整地叙述犯罪事实。换句话说，揭发对象犯的犯罪行为，实际上也是在如实供述自己的犯罪行为，因此不构成立功。

所以请各位在这个位置重点补充一个笔记——**229 页，揭发型立功第一点**："他人"圈起来，旁边记"与自己无关"。如果构成了共同犯罪或者是对象犯这种情形，你可以想，如实供述必然会涉及到相对方的行为；这并不是在揭发他人的犯罪行为，而是在如实供述自己的犯罪行为，不能认定为立功。

而正是基于这个法理，司法解释讲得如此之详细、如此之清晰：**行贿人揭发受贿人与其行贿无关的其他犯罪行为，经查证属实的，才属于立功。** 言下之意，如果是揭发受贿人收受自己的贿赂，不可能成立立功。

#### 要点三：揭发同案犯共同犯罪以外、与自己无关的其他犯罪

这就是要补充进笔记的完整表述：所谓揭发型立功，指的是揭发他人的犯罪行为，与自己无关，查证属实才构成立功。

**例一**：甲乙共同盗窃后，甲被抓，甲揭发了乙单独实施的抢劫。请问乙的抢劫和甲有关系吗？没有。是共同犯罪吗？不是。这就是揭发他人的犯罪行为，因此甲可以构成立功。

**例二**：甲向官员行贿后自动投案，并如实供述自己受贿（原文：如实供述行贿）的经过，查证属实。就行贿罪而言，他是自动投案且如实供述自己罪行，成立一般自首没问题吧？到这一步还不能构成立功。但是注意，甲还揭发了乙收受其他人的贿赂——乙收其他人的贿赂，和甲是没有关系的。这个时候查证属实的情况下，可以成立立功。

所以张三向官员行贿、自动投案、如实交代行贿经过，行贿罪是一般自首；紧接着他又对工作人员说"据我所知，张三不光收了我的钱，还收了李四王五的钱，你们可以去查一查"——官员收李四王五的钱和我的行贿行为无关，所以前面构成自首，后面揭发官员收李四、王五的钱又可以构成立功。既自首又立功，能听懂吧？

#### 三个聪明反被聪明误的案例

**入库案例一：为了立功，把好朋友拉下水。** 张三因为诈骗被取保候审，他想立功，就找到好朋友李四说："哥们儿，你帮帮忙，能不能让我立功一下？"李四说怎么能让你立功呢。张三说简单："你先喝酒，你醉酒开开车，然后呢我举报你，这样的话我不就立功了吗？"李四说这不好吧，张三说你就帮帮忙嘛。反复教唆，李四醉酒驾驶机动车，张三举报李四，李四被抓了。

各位，在这个案例中你摸着良心想，张三是立功吗？必然不是立功。不光不是立功，他的前行为构成诈骗罪，后行为还构成危险驾驶罪的教唆犯，要数罪并罚。为何不能认定立功？因为立功要求揭发的是和自己没有关系的犯罪行为，而李四醉酒驾驶机动车，张三是教唆犯，就危险驾驶罪而言双方构成共犯关系，因此这不是揭发他人的犯罪行为。

**实务案例二：黑老大的辩护律师出的主意。** 甲是一个黑老大，乙是他的小弟。按照甲的罪行，大概率要被判处死缓或者死刑立即执行，甲也很害怕，就给律师说想想办法怎么样能让我减轻处罚。律师张三说："你可是黑老大对吧？难道你不掌握别人的犯罪线索吗？你不掌握一些能立功的机会吗？好好想一想。"甲乙一想要起来：我有个小弟叫乙，他三年前杀过人，到现在都没被发现，我如果把乙揭发出来能不能构成立功。律师一听说可以，甲就向办案人员检举揭发说他的小弟也杀人，我要立功。一查属实。

但是各位别忘了：犯罪集团的首要分子要对集团所犯的全部罪行承担责任，小弟实施的杀人行为仍然在整个犯罪集团罪行范围之内。他这一揭发，查证属实，结果甲被判处了死刑立即执行。各位你看看这个律师张三是什么业务水平，他竟然出这种主意。所以他不可能成立立功。

**连累犯：我故意连累他们，好给自己创造立功的机会。** 我杀了个人之后东躲西藏，但我也不想被判死刑，我只能跑。我先跑到马峰家，我说"马哥，我杀了个人，能不能在你家躲几天？"他可以啊，兄弟，你杀不杀人都是我的好兄弟，我家大门永远向你敞开。我在他家住了一个月，说了谢谢就走了。接下来到岳鹏家，"岳哥，我杀了个人，能不能躲几天？"没问题啊，随便住，我北京房子租的就是这套房子，送给你都可以。就在这藏着。我说好，谢谢岳哥，住了一个月我就走了。

又来到了宫城家——他是工程师。我说"我杀了个人，能不能躲一躲？"工程师说没问题，就住在我旁边，住在我主卧，咱俩住一起。我说哎呦你真好，住了一个月天天聊天很开心，谢谢谢谢。然后我走了。紧接着来到杜洪波家，我说"老杜，我杀了个人啊，能不能在家住一个月？"他说可以啊没问题，我虽然刚刚加入众合，但我们的关系也不错吧。我说那我们是好兄弟呀，住了一个月，天天陪我喝酒。我说谢谢老杜。

紧接着我就去投案了："警察，我杀了个人，我要自首。"警察说你小子还可以嘛，知道自首，自动投案、如实供述杀人的过程，就故意杀人罪我成立自首了。警察说不错不错，然后他就要离开。我说警察同志先别走，我不光要自首，我还要立功呢。"你立什么功？""司马峰、岳鹏、杜洪波他们明知道我杀人，仍然让我躲在他们家里面，而且每一家我都躲了一个月，而且我有生活过程中的录音，和他们聊天的录音，我手机上都有录音的具体时间。我要检举揭发，揭发他们构成窝藏罪，请你们把他们四个抓起来，然后和我安排在同一个监室，我们是好兄弟。"

各位，我能不能构成立功？疯了。这种情况在理论上称为**连累犯**——所谓连累犯，就是我是那个基本犯，我是先犯罪那个人，我是故意地去连累他们四个，然后借此创造立功的机会。各位你认为这种情况能成立立功吗？它跟我们倡导的价值取向一样吗？肯定不一样。如果这种情况都认定为立功，那就无异于鼓励犯罪人去连累更多人、去制造更多的犯罪人，为自己创造立功的机会。不可能。

#### 揭发型立功的判断结论

| 揭发的内容 | 是否构成立功 | 理由 |
| --- | --- | --- |
| 李四杀人，但李四两年前已死亡 | 成立 | 只要求揭发的是犯罪行为，不要求他人被追究刑责 |
| 乙故意毁坏财物，但属于紧急避险 | 不成立 | 紧急避险是合法行为，不是犯罪行为 |
| 甲揭发乙参与共同盗窃 | 不成立 | 共同犯罪事实即如实供述，充其量是坦白 |
| 甲揭发官员收受自己的贿赂 | 不成立 | 对象犯，属于如实供述，成立的是自首 |
| 甲揭发乙单独实施的抢劫 | 成立 | 与己无关的其他犯罪 |
| 甲揭发乙收受其他人的贿赂 | 成立 | 与己无关，成立立功（同时构成自首） |
| 教唆李四醉驾后举报 | 不成立 | 本身是危险驾驶罪的教唆犯，数罪并罚 |
| 揭发犯罪集团小弟的杀人 | 不成立 | 首要分子对集团全部罪行负责，无从"揭发" |
| 揭发故意窝藏自己的四个朋友 | 不成立 | 连累犯，不符合立功的价值取向 |

> **结论**：揭发他人犯罪行为，切记一定是和自己无关，自己不能参与。

### 线索型立功：线索来源必须合法

线索型立功指的是：犯罪分子提供侦破其他案件的重要线索，经查证属实。请把关键词圈起来——"提供侦破其他案件"。这里强调的是"其他案件"，指的是和自己无关，不是本案，而是其他案件。查证属实，此时可以成立线索型立功。

那么这个线索的来源，提出两个要求，一正一反：**正**——来源必须合法；**反**——不能来自负有侦查职责的国家工作人员处，否则也不会节约司法资源。

先看反面。第一种非法：通过贿买、暴力胁迫等非法手段，或者被羁押后与律师、亲友会见过程中违反监管规定，获取他人线索并检举揭发——这个线索来源本身就是非法的，所以不可能认定为立功。第二种：犯罪分子将本人在履历查办犯罪职务活动中掌握的，或者从负有查办犯罪监管职责的国家工作人员处获取的线索检举揭发，也不能认定为立功，因为没有节约司法资源。

举个例子。张三是公安局局长，涉嫌犯罪被抓了，张三说我要立功，工作人员给了他两页纸，都写满了，好多线索都是别人的犯罪线索。工作人员就问局长，你这个线索哪来的？张三说："老子做局长的时候刻意隐瞒下来的，就是为了我今天立功的。"各位，疯了，这不可能认定为立功，甚至有可能构成新的犯罪，比如徇私枉法。

同理，张三是局长，他的儿子张小三犯罪了，张小三说我要立功，也写了两页纸。工作人员说线索哪来的？他说"我和我爸聊天的时候听到的"——你爸是谁啊？我爸就是你们局长。各位，这能认定为立功吗？节约司法资源了吗？自然没有。

再看正面。偶然听到的线索是可以构成立功的。为什么看守所里经常出现立功的现象？一个监室可以关押很多犯罪嫌疑人，他们之间会聊天，聊天的时候有的犯人就吹牛："我现在虽然是进来了，但是我这辈子不亏了，老子前面弄死一个人，到现在公安都没发现。"说者无心，听者有意。张三吹牛，他的同监室的李四就听到了。管教找李四谈话的时候李四说："管教，我要立功。""立什么功？""我们监室的张三之前还杀过人呢。""你怎么知道的？""他在那吹牛的时候，我听到的，我感觉是真的，他描述得很像。"管教把线索记录下来，然后开始对张三进行侦查，一查发现线索属实。各位，那李四成立立功，线索来源就是合法的。

> **提示**：线索原本不是行为人通过履职活动掌握的，而是亲友等事先告知的，这种来源也不影响立功的认定，可以成立立功。比如甲被逮捕后，根据其在饭店偶然听到的线索揭发乙的犯罪行为，查证属实，可以成立线索型立功。

| 线索来源 | 能否构成立功 |
| --- | --- |
| 贿买、暴力胁迫等非法手段获取 | 不能，来源本身非法 |
| 被羁押后与律师、亲友会见时违反监管规定获取 | 不能，来源本身非法 |
| 本人在查办犯罪职务活动中掌握的 | 不能，没有节约司法资源 |
| 从负有查办犯罪监管职责的国家工作人员处获取 | 不能，没有节约司法资源 |
| 偶然听到（同监室吹牛、饭店听闻） | 能，来源合法 |
| 亲友等事先告知的 | 不影响立功认定，可以成立 |

### 协助型立功：帮助抓人，而且要多出"一点"

协助型指的是：犯罪分子协助司法机关抓捕其他犯罪嫌疑人。注意这个地方**包括同案犯**，应当认定为立功，因为协助抓捕同案犯同样会节约司法资源。

#### 协助抓捕的四种情形

按司法解释规定，以下四种情形可以认定为协助抓捕：

| 情形 | 场景 |
| --- | --- |
| 按司法机关的安排，以打电话、发信息等方式将其他嫌疑人（含同案犯）约到指定地点 | 张三因非法持有毒品被抓，警察问哪来的，他说从李四那买的，李四就是卖家。警察说，你能不能把李四约出来？可以，怎么约？我就假装继续买。约到什么地方？警察说就约到某某公园的门口。张三按警察的安排把李四约出来，李四刚露面就被抓了。成立立功 |
| 按司法机关的安排，当场指认、辨认其他犯罪嫌疑人（含同案犯） | 张三、李四一起盗窃，偷完东西混入人群，"哎呀好多人"。警察过来把张三抓了，问要不要立功，张三说"要，指出你的同伙是谁"。张三左瞅瞅右看看，说"就是他"，李四也被抓了 |
| 带领侦查人员抓获其他犯罪嫌疑人（含同案犯），简称"带捉" | 我和马峰共同犯抢劫罪后我被抓了，马峰跑得快，一出溜又跑了，公安抓不到他，定位也找不到。警察说，你想不想立功？我说想。你对马峰的一些习性了解吗？了解。他说，你能不能带着我们警察过去把马峰抓到？我说应该可以。他说你有什么思路？他说他家在某某方向，你们都不知道的是，他家附近有个古墓，古墓被盗墓贼盗过，有个盗洞，他如果不在家里，很可能藏到那个古墓里面去——他差点成为墓主人的地方。警察说来，带我们去。我带着一群警察过去包围古墓，向古墓里面喊话，马蜂不出来，开始朝里面喷烧辣椒、喷一些刺激性的东西，马蜂在里面好痛苦，就趴着出来了，然后被抓到了 |
| 提供司法机关尚未掌握的其他案件犯罪嫌疑人的联络方式、藏匿地址，司法机关据此将其抓捕 | 张三因诈骗被抓了，说"我要立功，我知道那个连环杀人案的凶手藏在什么地方，你们都不知道"。果真如此，司法机关根据张三提供的线索将连环杀人案的凶手抓到了 |

前三种为什么都能算立功？各位你想，如果不这样，成本都太高了。如果张三不指认不辨认，人群有那么多人，难道公安都要把他们带回去一个个去审查吗？如果不带着警察去古墓，警察连马峰长什么样都不知道。所以这些行为都是实打实节约了司法资源的。

第四点要注意：为什么要求是"其他案件"呢？难道不能是共同犯罪案件吗？请看下面的提示，这段略难，我讲慢一点，大家仔细听。

> **易错点**：犯罪分子提供同案犯的姓名、住址、体貌特征等基本情况，或者提供犯罪前、犯罪中掌握的同案犯的联络方式、藏匿地址，司法机关据此抓捕同案犯的，不能认定为立功。

它背后的法理是：因为以上内容是犯罪分子应当供述的内容。这样讲略抽象，抬头看我举个例子。

我和马峰构成抢劫共犯，我被抓了，马峰跑了。警察就问我："是你一个人干的吗？"我说不，我有同伙叫马峰。但警察对马峰不了解，就问马峰长什么样。我就描述一下：很壮，铁塔一样的男人，国字脸、短头发、大眼睛、戴个眼镜，有点近视眼。各位，我是在描述马峰的体貌特征。那如果警察根据我这个描述将马峰抓了，你认为我是立功吗？

我既不是揭发型——我不是揭发他人犯罪行为；也不是线索型——我提供的不是使其他案件得以侦破的重要线索，而且这也不是其他案件；我更不是协助型的哪一种？我只是描述了一下他的基本特征。**为什么不能认定为立功？很简单，因为这应该是我如实供述的内容。** 面对讯问的时候我应当如实供述，这是我如实供述的内容，充其量对我的行为评价为坦白——被动归案以后如实供述自己罪行。

那警察说马峰的电话号码是多少？我把电话给他了；他家庭地址在什么地方？我也给他了。据此抓捕，同样不是立功。这都是我如实供述的内容，因为它和犯罪紧密相关。

所以司法解释才规定：如果提供的是犯罪前、犯罪中掌握的同案犯的联系方式、藏匿地址，司法机关据此抓捕的，不能成立立功。为什么？因为犯罪前、犯罪中掌握的那是和犯罪紧密相关的内容，是犯罪人如实供述的义务、如实供述的内容。所以如果我被抓之后交代了马峰的姓名、年龄、体貌特征、家庭住址、联系方式，都是在犯罪前、犯罪中掌握的，这个时候对我不得认定为立功，这是坦白的内容。

言下之意是什么？换言之，**只有提供犯罪后新的联络方式、新的藏匿地址，才有可能成立立功**。因为新的联络方式、新的藏匿地址是犯罪以后的事情，它和犯罪没有关系，那不是我如实供述的义务，我完全可以不讲。所以此时我额外地交代出来，因此我属于协助抓捕——当然要求司法机关要凭借着这个新的联络方式、新的藏匿地址抓捕犯罪嫌疑人。

入库案例：甲归案后提供公安机关尚未掌握的同案犯杨某作案之后使用的手机号码和 QQ 号码，司法机关据此将其抓捕——这个时候可以成立立功。这个号码是犯罪以后才使用的。

#### 怎么快速分清立功和坦白

有人说老师这个好难啊，那啥时候是立功，啥时候是坦白？我给大家一个非常好的方法：**如果坦白是 A，那么立功一定要比坦白多一点，A+。**

```text
如实供述义务范围之内              →  坦白      A
        +
超出坦白范围的那一部分            →  立功      A +
（且对协助抓捕起到实质作用）
```

换句话说，你看行为人交代的内容，是不是他如实供述义务的范围？如果是应当如实供述的范围，那就是坦白；如果除此之外他还多交代了这一部分，多交代的这一部分对于协助抓捕犯罪嫌疑人起到了实质的作用，那才可能构成立功。少一点不行，如果在坦白范围内，那就只能认定为坦白；多一点，而且多的那一点对协助抓捕起到了实质作用，才成立立功。

**入库案例（不成立）**：和"李四"一起犯罪，其实他们两个也是临时起意，彼此之间没有那么熟。犯罪之后李四逃跑，张三被抓。警察就问张三"是你一个人吗？"不是，有同伙。"同伙叫什么名字？""我真的不知道，就是路上偶遇，然后临时起意决定去抢劫的。"你不知道同伙的名字？真不知道。那你描述一下他的特征。张三就开始描述："他是一个瘦高个，比较瘦，个子比较高。""还有什么特征明显一点？""脸呢是那种国字脸。""还有吗？""哦，对他右边的胳膊是有残疾，他右边的胳膊抬不起来，只能轻轻地摆动，但是不能抬起来，有明显的残疾。"警察一听："这个有价值呀。"问他："你们犯罪之后，他朝哪个方向走了？""就朝东边那个方向走了，他家应该住得离这不远，因为他是步行。"警察说行明白了，紧接着朝着那个方向开始去做调查，然后到这几个村子里面开口。警察问的第一句话就是："你们村子有没有人啊？有没有人右边胳膊有点问题、有点残疾、只能稍微动一动但抬不起来的？"第一个村子没问到，第二个村子说"有，就在他家那边住呢"，警察过去就把李四给抓了。

我想问各位，你认为张三能构成立功吗？不构成。张三被动归案以后如实供述自己罪行，成立坦白没问题。但能构成立功吗？不能。他描述的是什么？描述的是同案犯的体貌特征，这是在犯罪前、犯罪中掌握的，正因如此他和犯罪紧密相关，这是张三如实供述的义务、如实供述的内容。

**案例（成立）**：我和马峰一起犯了抢劫罪，犯罪之后我跑到了上海，他跑到了北京。到了北京之后，他担心被抓，换了一个手机号，而且是**用别人的身份证办的**手机号。接着他跟我联系："大海放心吧，我已经藏好了，我在北京躲躲风头，你到北京来找我玩。"我说好，马哥，你住在什么地方？他说"八大胡同"。我说好的好的。

紧接着我在上海被抓了。被抓之后说："你们抢劫的时候是你一个人吗？"不，有同伙。"叫什么名字？""马峰。""家什么地方？""山西。""长什么样子？""胖胖的，铁塔一样的男人，国字脸。"描述过之后，警察问他的手机号是多少。我说我把以前提供出去了——那是犯罪中我跟他打电话的号码。果然关机。警察说这个号怎么打不通？不知道，可能是换号码了。新号码有没有？再想想。我说我愿意提供：他是用别人的身份证办的，有个号。警察根据这个新的号码，通过定位手段找到了马峰，抓住了他。

各位，你可以想我能不能成立立功？可以。这个新号码是犯罪后马峰才使用的，和犯罪有关系吗？没有关系，那就不是在如实供述的范围之内。此时我不光是坦白了，而且比坦白还多一点，多供述了那个手机号，那个手机号对协助抓捕马峰起到了实质作用，所以认定为立功。抢劫罪我是坦白，同时我还具有立功情节。

> **结论**：协助型立功的关键，是要比坦白多出"一点"，而多的那一点必须对协助抓捕起到实质作用。

### 重大立功：比一般立功多加了几个字

重大立功和一般立功在主体、立功的时间、本质上完全相同，表现也一样分为揭发型、线索型、协助型、其他型。区别就是各加了"重大"两个字，具体是五种情形：

1. 揭发他人重大犯罪行为，查证属实；
2. 提供侦破其他重大案件的重要线索，查证属实；
3. 协助司法机关抓捕其他重大犯罪嫌疑人；
4. 阻止他人重大犯罪活动；
5. 对国家和社会有其他重大贡献。

重大立功的标准，按照司法解释规定，所谓重大犯罪、重大案件、重大犯罪嫌疑人的标准，一般指犯罪嫌疑人、被告人**可能被判处无期徒刑以上刑罚**，或者案件在本省、自治区、直辖市或者全国范围内有较大影响的情形。

注意只要是"可能"即可。比如张三犯罪之后揭发李四的犯罪，查证属实，而且李四是入户抢劫——各位，入户抢劫的法定刑是 10 年以上有期徒刑、无期徒刑、死刑，那张三就能成立重大立功。哪怕李四经过庭审只被判处 15 年，张三同样是重大立功。因为看的是被揭发的犯罪行为所对应的法定刑有没有无期徒刑这个选项就可以了。

把两种立功的法律后果摆在一起对比：

| 情形 | 法律后果 |
| --- | --- |
| 一般立功 | 可以从轻或者减轻处罚 |
| 重大立功 | 可以减轻或者免除处罚 |

### 四种法定情节摆在一张表里看

累犯、自首、立功、坦白这四种制度，只有一个的后果是"应当"——只有累犯是**应当从重处罚**。除此之外，自首、立功、坦白的后果都是"可以"，那个从重的是"应当"，从宽的这三种都是"可以"，这点要注意。

| 情节 | 法律后果的表述 |
| --- | --- |
| 累犯 | 应当从重处罚 |
| 自首 | 可以从宽 |
| 立功 | 可以从宽 |
| 坦白 | 可以从宽 |

再往下做一个提示：**自首和立功的效果对比，就一句话——自首基于本罪，立功基于全罪。** 自首的后果只能针对自首的那个罪名来使用，而立功不区分，它可以适用于行为人所有没有被判决的犯罪。

比如张三犯盗窃、诈骗、抢夺罪，然后自动投案以后交代了盗窃的事实，隐瞒了诈骗和抢夺。那盗窃罪可以对他适用自首的情节，诈骗、抢夺不能使用，所以自首基于本罪。但如果张三具有立功情节，立功的效果可以适用于盗窃、诈骗、抢夺这三个罪名，这就是立功及于全罪。

我们通常的表述是"就某某罪成立自首"，但一般不会说"就某某罪成立立功"。我们可以说：张三就盗窃罪成立自首，同时具有立功情节。这样表述是可以的。

### 四种情节的归位图

下面做个总结，请各位看这张图——从归案的方式看，无非两种，要么自动投案，要么被动归案，情节就顺着这两条线分下去。

```text
┌────────────┬──────────────────────────────────┬──────────────────┐
│  归案方式  │             供述内容             │     情节认定     │
├────────────┼──────────────────────────────────┼──────────────────┤
│            │  虚假陈述                        │ 三种情节都不成立 │
│  自动投案  │  自己或共同罪行（已掌握与否均可）│ 一般自首         │
│            │    他人罪行（司法机关已掌握）    │ 不构成立功       │
│            │    他人罪行（司法机关未掌握）    │ 立功             │
├────────────┼──────────────────────────────────┼──────────────────┤
│            │  虚假陈述                        │ 三种情节都不成立 │
│  被动归案  │本人或共同犯罪的罪行（司法已掌握）│ 坦白             │
│            │  本人或共同的本罪（司法尚未掌握）│ 坦白             │
│            │  本人或共同的他种罪行（未掌握）  │ 准自首           │
│            │    他人罪行（司法机关已掌握）    │ 不构成立功       │
│            │  他人罪行（司法未掌握）且与己无关│ 立功             │
└────────────┴──────────────────────────────────┴──────────────────┘
```

读图：纵向是归案方式，横向是供述的内容，两者一交叉就落到了具体的情节上。两条主线各有三条分支——虚假陈述一律不构成任何情节；如实供述了自己或共同的罪行，看归案方式和司法是否已掌握，分别落成自首、坦白或准自首；如实供述了他人的罪行，则看司法机关是否已经掌握，已掌握的不构成立功，未掌握且与己无关的才是立功。

为什么供述司法机关**已经掌握**的他人罪行不构成立功？因为它不会节约司法资源。大家都听过杭州杀妻案吧，把妻子杀死之后又分解，通过马桶又把她冲下去，这个特别惨。那张三犯罪之后跟警察说"我要立功"，警察说你立什么功啊？张三说"我揭发他人杀人，我知道犯罪人是谁"。警察说哪个案子？"杭州杀妻案。"犯罪人就是她的丈夫。警察说"你怎么知道的？""我看的新闻。"各位，怎么可能构成立功啊？这种情况不构成立功。

回到自动投案这一支，还要再强调一遍：自动投案加上如实供述，不管司法机关有没有掌握，都能成立一般自首。而且自己的罪行和共同的罪行可以放在一起评价，因为共同罪行其实也是自己的罪行。

四种法定情节到这里就全部结束了。大家看，从法官的角度、以时间推进为序列：进入刑法论，第一步讨论"量什么刑"，主刑、附加刑；知道了量什么种刑还不够，第二步要讨论量刑情节，所以我们先做铺垫引出量刑情节，分法定情节和酌定情节，酌定情节结束以后，集中讨论了四种法定情节——累犯、自首、立功、坦白。紧接着就进入第三步：你作为法官，既知道量何种刑，也知道量刑情节，下一步就开始量刑。一罪一罚，没什么好说的；那数罪并罚呢？比如他的刑期怎么算呢？下一节"数罪并罚"涉及到数学的问题。但有同学说老师我数学不好——没关系，能不能达到小学水平？达到小学水平你就能算得对。所以只要能听得懂、算得对就可以了。

### 本讲提到的题目

书 232 页真题。甲涉嫌受贿被逮捕，在受讯问时如实供述受贿罪行，并举报同监室的一名嫌疑人企图脱逃，查证属实。下列选项正确的是：

- A. 甲具有自首情节
- B. 甲具有立功情节，对其可以免除处罚
- C. 甲具有坦白情节，对其可以从轻处罚
- D. 甲具有重大立功情节，对其应当免除处罚

**解析**

先找重点：被逮捕——表明它不是自动投案，最起码题目没有说他自动投案，所以就受贿罪他不可能构成一般自首。在受讯问时如实供述受贿罪行，这就是被动归案以后如实供述自己罪行，成立坦白。到这一步，坦白成立。

并举报同监室的一名嫌疑人企图脱逃，查证属实——这是揭发他人犯罪行为，查证属实，成立立功。至于是一般立功还是重大立功：重大立功要求被检举揭发、协助抓捕的犯罪嫌疑人有可能被判处无期徒刑以上刑罚，这个简单的脱逃罪名没有那么重，达不到无期徒刑以上。当然有同学问老师那是不是要记法定刑？原则上不需要去翻分则，讲到一些常见常考的，我会提醒你们。

逐项看：

- **A 项错**：甲不具有自首情节。被逮捕是被动归案，没有自动投案的事实基础。
- **B 项错**：甲具有立功情节，但对其**可以免除处罚**是错的。这只是一般立功，一般立功可以从轻或者减轻处罚；可以减轻或者免除处罚是重大立功才有的待遇，这不可能是重大立功。
- **C 项对**：甲具有坦白情节，就其所犯受贿罪，因具有坦白情节可以对其从轻处罚。
- **D 项错**：两处错误。一是甲不具有重大立功情节（脱逃罪达不到无期徒刑以上）；二是即使是重大立功，也是"**可以**"免除，而不是"**应当**"免除。

**答案：C**
