# 主观责任阻却：责任年龄、责任能力、法律认识错误与期待可能性

## 主观责任阻却事由总览

   * **主观责任阻却事由**

       * > **定义**：客观构成要件与主观要件都具备之后，因某些事由把行为人的可谴责性排除掉，使其最终无从被刑法谴责的情形。

       * 阻却的是可谴责性，法律后果是排除责任、不负刑事责任。

       * 主观责任阶层由两个板块构成：主观要件与主观责任阻却事由。

       * 主观要件包括故意、过失以及事实认识错误，事实认识错误直接决定犯罪故意能否成立。

       * 主观责任阻却事由包括责任年龄、责任能力、违法性认识可能性、期待可能性。

       * 结果与因果关系不是每个罪都要求的成立条件，对故意犯罪而言主要属于既遂要件。

### 四项事由的考察重心

   * 责任年龄：主线是 12~14 周岁这一条线，附带 14~16 周岁的八种罪。

   * 责任能力：难点在行为与责任能力同时存在原则。

   * 法律认识错误：指刑法上的认识错误，理解上最抽象、最难。

   * 期待可能性：原理一理解即可，落点主要在妨害司法秩序类犯罪。

| 事由 | 关键点 | 落点 |
| :--- | :--- | :--- |
| 责任年龄 | 12~14 周岁与 14~16 周岁两段 | 总则记忆型考点，难度不大 |
| 责任能力 | 行为与责任能力同时存在原则 | 三种特殊人群与三段切割 |
| 法律认识错误 | 事实认识与法律认识的分野 | 法定犯里最容易翻车 |
| 期待可能性 | 法律不强人所难 | 妨害司法秩序犯罪 |

## 责任年龄

   * **责任年龄**

       * > **定义**：刑法规定的行为人承担刑事责任的年龄界限，分成无责任、相对、完全三段。

       * 三段划分解决的是"构不构成犯罪"。

       * 减轻责任年龄解决的是"怎么处罚"，不在构不构成这条线上。

       * 责任年龄整块考的基本上都是记性的东西，难度不大。

### 三段划分

   * 不满 12 周岁是完全无责任年龄，杀人放火也不构成犯罪，不负刑事责任。

   * 12~16 周岁是相对责任年龄，只对特定重罪负责，对轻罪不负责。

   * 已满 16 周岁是完全责任年龄，犯任何罪都要负刑事责任，往上一路管到成年。

   * 记住"不满十二、十二到十六、十六以上"这条线就够了。

| 年龄段 | 名称 | 法律后果 |
| :--- | :--- | :--- |
| 不满 12 周岁 | 完全无责任年龄 | 干再严重的坏事也不构成犯罪，不负刑事责任 |
| 12~16 周岁 | 相对责任年龄 | 只对特定重罪负责，对轻罪不负责 |
| 已满 16 周岁 | 完全责任年龄 | 犯任何罪都要负刑事责任 |

> **易错点**：不满 12 周岁的人犯罪是根本不构成犯罪，用词不是"罪轻"。

### 减轻责任年龄

   * 未满 18 周岁的人犯罪，要减轻处罚、从宽处罚。

   * 已满 75 周岁的老年人犯罪，也能享受从宽处罚的待遇。

   * 这两个年龄段不在三段划分的线里，只管处罚轻重，不管是否构成犯罪。

   * 一个护着小的、一个护着老的，恤老爱幼是我国传统美德。

### 十二到十四周岁的 2+2+1

   * 这一档写在刑法第十七条第三款，条文里就藏着"2+2+1"的结构，可以当填空题背。

   * 两个行为：故意杀人罪、故意伤害罪，行为性质被限定死了，不能拿别的行为往里套。

   * 两个结果之一是致人死亡，这一项没有附加要求。

   * 两个结果之二是以特别残忍手段致人重伤、造成严重残疾，"特别残忍手段""重伤""严重残疾"三个条件必须同时满足，少一个都不行。

   * 一个程序是经最高人民检察院核准追诉。

   * > **易错点**：⚠️ 核准追诉的是最高人民检察院，不是最高法院，因为核准追诉涉及追诉权，追诉权是检察院的权利，法院管审判、检察院管起诉。

### 十二到十四周岁的备考权重

   * 条文规定比较新。

   * 这个条文一直没有考过。

   * 实务中已经有该核准追诉程序被真正激活的例子，即邯郸未成年人杀人案。

### 十四到十六周岁的八个罪

   * 口诀是"烧杀淫掠伤贩爆头"。

   * 贩卖毒品罪在八种罪里只挑了"贩卖"这一个行为，走私、运输、制造毒品都不在内。

   * > **易错点**：口诀里"伤"这一格的限定语是致人重伤或者死亡，普通轻伤不在八种罪之列。

| 口诀 | 罪名 | 补充 |
| :--- | :--- | :--- |
| 烧 | 放火罪 | |
| 杀 | 故意杀人罪 | |
| 淫 | 强奸罪 | |
| 掠 | 抢劫罪 | |
| 伤 | 故意伤害罪 | 致人重伤或者死亡 |
| 贩 | 贩卖毒品罪 | 只此一项，不含走私、运输、制造 |

### 重罪的行为拆分

   * 绑架罪是重罪，但八种罪里没有它。

   * 15 岁的人绑架劫持 20 岁的人质后撕票杀人，对绑架罪这部分不负刑事责任，因为绑架罪不在八种罪里。

   * 撕票实质上构成杀人，故意杀人罪在八种罪之列，所以仍然负刑事责任。

   * 拐卖妇女儿童罪也是重罪，八种罪里同样没有它。

   * 15 岁的人在拐卖途中强奸被害人，负的是强奸罪的刑事责任，拐卖罪本身不承担。

   * 贩卖毒品是八种罪中唯一的非暴力型犯罪。

   * 15 岁的人从金三角走私毒品，只说走私就不负责，只有同时贩卖才负刑事责任。

   * 同样是"从金三角回来"，卖和运的结论完全不一样。

## 责任能力

   * **责任能力**

       * > **定义**：行为人对自己行为的法律性质和法律后果有没有辨认、控制的能力，通俗讲就是"知道自己不知道"自己在干什么。

       * 平常谈的责任能力主要就是谈精神状态正不正常。

       * 围绕精神状态分三档：完全责任能力、相对责任能力、完全无责任能力。

| 精神状态 | 名称 | 刑事责任 |
| :--- | :--- | :--- |
| 精神完全正常 | 完全责任能力 | 负完全刑事责任 |
| 尚未完全丧失辨认或者控制自己行为的能力 | 相对责任能力，又叫限定责任能力、限制责任能力 | 仍然负刑事责任，但可以从轻或者减轻处罚 |
| 完全丧失辨认或者控制自己行为的能力 | 完全无责任能力 | 不负刑事责任，责令监护人严加看管，必要时由政府强制医疗 |

### 三档刻度的处理结论

   * 精神完全正常即完全责任能力，负完全刑事责任，没有好讨论的。

   * 相对责任能力的关键词是"尚未完全丧失"，这种人处于"半精神病者"状态：说正常有点疯疯癫癫，说不正常有时又挺机灵。

   * 相对责任能力的人要负刑事责任，但可以从轻或者减轻处罚。

   * 完全无责任能力是彻底丧失辨认或控制能力，这时候真就是不负刑事责任。

   * 不负刑事责任不等于没事了，还要责令治疗，必要时由政府强制医疗。

   * 无责任能力对应"不负刑责 + 强制医疗"两个动作，一个都不能少。

### 相对责任能力与间歇性精神病不是一回事

   * 间歇性精神病指一会儿精神完全正常、一会儿精神完全不正常。

   * 相对责任能力的人是一直处在一个半精神病的状态，间歇性精神病是在正常与完全不正常之间来回切换。

   * 间歇性精神病在精神正常的时候犯罪，完全负刑事责任。

   * 间歇性精神病在完全疯了的情况下犯罪，完全不负刑事责任。

### 精神病、神经病与心理疾病

   * 精神病不是神经病，"神经病"往往就是骂人的话。

   * 心理疾病不等于精神病，有心理疾病不代表就没有责任能力、不负刑事责任。

   * 抑郁症是心理疾病而不是精神病，抑郁症患者还是要负刑事责任。

   * 强迫症、焦虑症、惊恐症同样属于心理疾病这一类。

### 特殊人群里的三组人

   * 聋哑人、盲人不是精神病人，属于残疾人，精神正常就负完全刑事责任。

   * 但可以给他们从宽处罚，毕竟是残疾人。

   * > **易错点**：⚠️ 是"又聋又哑"——聋和哑是且的关系，两个都要；而盲只要一个"盲"就够了，盲最严重。

   * 生理性醉酒是生活中的醉酒，一定要负刑事责任，而且不可能享受从宽处罚待遇。

   * 病理性醉酒是精神病的一种，按精神病对待。

   * 法条并没有规定"产生幻觉就不负刑事责任"，产生幻觉的人犯罪是负刑事责任的、是有罪的。

   * 第一次产生幻觉时犯罪，负刑事责任，但没法定故意杀人罪，因为他是在幻觉中干的，至少可以定一个过失致人死亡罪。

   * 第二次明知自己一喝酒就会产生幻觉而故意利用它犯罪，就可以定故意犯罪，其依据是原因自由行为。

### 行为与责任能力同时存在原则

   * **行为与责任能力同时存在原则**

       * > **定义**：实行行为实施之时行为人具有责任能力即为满足，不要求结果发生之时具有责任能力。

       * 原则的落点是"行为"，不是"结果"。

       * 它是三个具体原则的总称：行为与故意同时存在原则、行为与责任年龄同时存在原则、行为与责任能力同时存在原则。

       * 三个之中最难、最重要的是第三个。

       * 做这类题一定要先把精神正常阶段和精神失常阶段划开，划清楚了就很清晰。

### 三种情形中的因果关系切割

   * 毒药先寄出：精神正常时把毒药寄出，间歇性精神病发作后被害人才收到并毒死，寄出行为与死亡结果有因果关系，故意杀人罪既遂。

   * 先砍中再补刀：精神正常时砍中，精神失常时又砍两刀致死，精神正常时的砍杀算数，精神失常时的砍杀没有责任能力、直接排除，不参与评价。

   * 二因一果的情形下，两个有效行为共同导致死亡，但与前行为即精神正常时那一刀之间仍有因果关系，故意杀人罪既遂。

   * 先砍空后砍中：精神正常时砍空，精神失常时砍中致死，精神正常时的砍杀算数但与死亡没有因果关系，只能定故意杀人罪未遂。

   * 结果发生时精神失常不影响定罪，只要求行为时有责任能力。

   * > **易错点**：⚠️ 第二、三种情形只差一处——精神正常时那一刀砍中没砍中，砍中就是既遂，砍空了就只能是未遂。

```text
──────────────────────────────────────────────────────
情形二　先砍中了，被吓疯了以后又补两刀
──────────────────────────────────────────────────────
   精神正常    →   砍杀（砍中）  ─┐
   精神失常    →   砍杀 × 2     ─┴→  小芳死亡
                              ↓
        前行为与死亡之间有因果关系 → 故意杀人罪既遂
──────────────────────────────────────────────────────
```

```text
──────────────────────────────────────────────────────
情形三　先砍空了，崩溃之后才砍中
──────────────────────────────────────────────────────
   精神正常    →   砍杀（砍空，计入）      ✗ 与死亡无因果
   精神失常    →   砍杀（砍中，不计）  ─┐
                            小芳死亡    ─┘
                              ↓
        前行为与死亡之间没有因果关系 → 故意杀人罪未遂
──────────────────────────────────────────────────────
```

### 原因自由行为

   * **原因自由行为**

       * > **定义**：导致行为人精神失常的那个原因行为，该原因行为本身处在其自由可支配的范围内。

       * 它是行为与责任能力同时存在原则的一个例外。

       * 常见情形是明知自己一喝酒就陷入病理性醉酒，仍旧先去把被害人控制住再喝酒。

       * 喝酒这个原因行为能够自由决定，可以自由地决定要不要陷入病理性醉酒。

       * 能够自由支配却偏偏自由地支配，并把它当成犯罪工具加以利用，就是恶意利用原则的缺口。

       * 例外处理的结果是不但要定罪，而且按既遂认定。

```text
        精神正常                        病理性醉酒（精神病）
  ┌────────────────────┐          ┌──────────────────────┐
  │ 一手搂住小芳        │          │ 把小芳强奸了          │
  │ 一手喝二锅头        │ ───────→ │                      │
  │      ↓              │  喝酒致疯  │  此时无责任能力        │
  │  原行为：搂 + 喝     │          │  按原则本可不负责      │
  │  自由可支配，可以避免 │          └──────────────────────┘
  └────────────────────┘
                ↓
   自由地制造了精神失常 → 恶意利用例外 → 定强奸罪（既遂）
```

### 原因自由行为中的罪名与既遂

   * 精神正常时奔着强奸去、喝醉后改去抢劫的，精神失常时的抢劫行为因无责任能力定不了抢劫罪。

   * 此时只能退回去处理精神正常时的强奸预备行为，最多定一个强奸罪的犯罪预备。

   * 要给后罪定罪并且认定既遂，必须是精神正常时就想抢劫、喝醉后实施的也是抢劫。

   * 原因自由行为中要给后罪定罪并认定既遂，条件就一条——前罪与后罪同一，不忘初衷方能既遂。

## 法律认识错误

   * **事实认识错误与法律认识错误**

       * > **定义**：事实认识错误是对事实判断这一层的错误认识，刑法上主要考的是对行为对象的认错。

       * > **定义**：法律认识错误是对价值评价即法律评价这一层的错误认识，指行为人对刑法禁止性、也就是刑法违法性的态度产生了错误认识。

       * 法律认识错误有两个方向：以为刑法允许而实际禁止，以为不构成犯罪而实际构成犯罪。

       * 刑法上说的"法律"专指刑法，不包括行政法规，更不包括其他部门法。

       * 法律上的处理原则是"不知法者不免责"。

### 认识活动的两个层次

   * 第一层是事实判断，回答"我在干什么事"，错在这一层就是事实认识错误。

   * 第二层是价值评价，回答"刑法到底禁止不禁止我干这事"，错在这一层就是法律认识错误。

   * 文盲的狗蛋贩卖图书，以为是普通书刊、实为淫秽物品，错在行为对象，属事实认识错误，没有贩卖淫秽物品牟利罪的犯罪故意，不构成犯罪。

   * 小芳为给狗蛋戒毒而反锁房门、每天从门缝撒狗粮，事实判断一点没错，错在认为这是为他好、刑法不禁止，属法律认识错误。

```text
  第一层  事实判断：我在干什么事？     错在这一层 → 事实认识错误
  第二层  价值评价：刑法禁止不禁止？  错在这一层 → 法律认识错误
```

### 自然犯与法定犯

   * 自然犯如杀人放火，古今中外干这个事到哪都是犯罪，认定是一样的。

   * 法定犯是以违反某个行政法规为前提的那种犯罪，也叫行政犯。

   * 危害珍贵、濒危野生动物罪、非法经营罪都是法定犯。

   * 事实认识错误与法律认识错误最难区分的地方就在法定犯里。

   * 自然犯的行为对象本身就令人发指、谁都知道不对，对行为对象认错的空间很小。

   * 法定犯的行为对象要靠行政法规去解释、去限定，行为人完全可能先把行政法规搞错，再把这个错误传导到刑法上。

### 抓癞蛤蟆案的认识错误定性

   * 农民朋友在当地抓癞蛤蟆，认为那是普通动物不是保护动物，结果被认定构成危害珍贵、濒危野生动物罪。

   * 许多人会认为这是法律认识错误，但这种理解有误，理由有两个。

   * 第一，刑法上法律认识错误的"法律"指刑法，是对行为在刑法上的禁止性有认识错误；该农民是对行政法规有认识错误，属行政法上的法律认识错误，不在刑法这一层。

   * 第二，也是更关键的一点，危害珍贵、濒危野生动物罪是法定犯，前置法是《动物保护法》，该行政法规的作用就是解释、限定行为对象、界定这个东西到底算不算保护动物。

   * 农民朋友对《动物保护法》理解错了，就传导成对行为对象性质的认错，以为是普通动物、实为保护动物，在刑法上这就是事实认识错误。

   * 该案性质上更接近狗蛋贩书案：以为贩的是普通书刊、实为淫秽书刊，都是对行为对象的认错。

   * > **提示**：理论教材和实务中大多数说法都把抓癞蛤蟆、抓鹦鹉、掏鸟窝当作法律认识错误，其实它们主要是事实认识错误的案件。

### 派生法律认识错误的体系过滤

   * 主观责任阶层分为主观要件与主观责任阻却事由两个板块。

   * 事实认识错误一般埋伏在主观要件的犯罪故意之下，有事实认识错误就意味着没有犯罪故意。

   * 没有犯罪故意，主观要件直接打叉，案件审理到这里就画句号，不再往下走到主观责任阻却事由。

   * 责任阻却事由里要分析的法律认识错误必须不能由事实认识错误派生，得是独立产生的，即事实判断不打叉的情况下单独产生的法律认识错误。

   * 小芳非法拘禁狗蛋的案子没有事实认识错误，她独立地产生了一个法律认识错误，才轮到这一层登场。

```text
两阶层体系
    │
    └── 主观责任阶层
            ├── 主观要件 ────── 犯罪故意 ← 事实认识错误藏在这里
            │                      （错了 = 没有犯罪故意 = 不构成犯罪）
            │
            └── 主观责任阻却事由 ── 违法性认识可能性
                                           ← 只放独立产生的法律认识错误
```

### 抓癞蛤蟆案的三个阶段

   * 第一阶段对《动物保护法》有认识错误，属行政法上的法律认识错误。

   * 第二阶段传导到行为对象，以为是普通动物、实为保护动物，属刑法上的事实认识错误。

   * 第二阶段导致没有危害珍贵、濒危野生动物罪的犯罪故意，主观要件打叉，得出无罪结论，案件到此画句号。

   * 第三阶段以为刑法不禁止、实为刑法禁止，确有刑法上的法律认识错误，但它由第一阶段派生，案件已终结，这一层不再登场。

```text
  抓癞蛤蟆案：三个阶段的认识错误

  第一阶段    对《动物保护法》有认识错误
              → 行政法上的法律认识错误
                  │
                  ▼
  第二阶段    对行为对象有认识错误
              以为普通动物，实为保护动物
              → 刑法上的事实认识错误
                  │
                  ▼
              没有危害珍贵、濒危野生动物罪的犯罪故意
              主观要件打叉 → 无罪，案件到此画句号
                  │
                  ▼
  第三阶段    以为刑法不禁止，实为刑法禁止
              → 刑法上的法律认识错误（由第一阶段派生）
                 但案件已经终结，这一层不再登场
```

### 4 厘米的钥匙扣案

   * 狗蛋买的钥匙扣长约 4 厘米、长得像枪、还能发出一点点没有杀伤力的弹丸，被控非法持有枪支罪。

   * 《枪支管理法》这个行政法规把枪支认定标准定得很低，行政法规有效就先按有效办。

   * 狗蛋对《枪支管理法》的认识错误属行政法上的法律认识错误。

   * 该错误传导到行为对象，他以为自己拿的是普通钥匙扣、普通玩具，实为行政法上的真枪，这属于事实认识错误。

   * 由此没有非法持有枪支罪的犯罪故意，主观要件打叉，不构成非法持有枪支罪，后面派生的刑法上法律认识错误无需再分析。

   * 后来的司法解释对行政法上"枪"的范围作了限缩解释、缩小解释，要求刑法上的枪支要有较大杀伤力，这个解释是合理的。

   * 按今天的解释，这类钥匙扣不算刑法上的枪支，不构成非法持有枪支罪。

   * > **提示**：这就是"一词多义"，同一个"枪支"在行政法上和刑法上的范围其实不一样。

### 掏鸟窝案的两个阶段

   * 第一次掏鸟窝时他还不知道那是什么鸟，对行为对象认错，属事实认识错误，不构成犯罪。

   * 第二次他知道是燕隼、是国家二级保护动物，还上网查过保护层级，没有事实认识错误，也没有法律认识错误，构成危害珍贵、濒危野生动物罪。

   * 量刑标准是否合理是另外一回事，就定罪而言没有问题。

### 法律认识错误的法律后果

   * **违法性认识错误**

       * > **定义**：对刑法的违法性、刑法的禁止性产生了认识错误，也叫法律认识错误，德国那边叫禁止性认识错误。

       * 不特别强调时说"法律认识错误"，就是仅指刑法上的违法性认识错误。

       * 原则是"不知法者不免责"。

       * 小芳非法拘禁狗蛋是独立法律认识错误的标准案例，她认为这个行为是为他好、刑法不禁止、不是犯罪，但她仍要承担刑事责任、仍要定罪。

       * 量刑上可以判得很轻很轻，甚至判缓刑、免除处罚，但罪还是构成了。

### 没有违法性认识可能性的责任阻却

   * 不知法者不免责是原则，但如果行为人连知法的可能性都没有，就不谴责他、不让他承担刑事责任。

   * 这属于责任阻却事由，排除可谴责性，最终导致没有刑事责任、不定罪。

   * 违法性认识可能性看的就是认识条件、认识环境、认识机会是否客观存在。

   * 这种问题主要出现在自然犯和法定犯的场合。

### 自然犯的违法性认识可能性

   * 杀人罪、放火罪、强奸罪、抢劫罪这类自然犯，一般都有违法性认识的可能性。

   * 即使行为人声称没认识到这种行为的违法性，也至少有认识到的可能性，绝对可以谴责他、让他承担刑事责任。

### 听信有权机关正式答复案

   * 真题情形：小老板想做一项经营活动但不知刑法上是否禁止，咨询当地法院，法院以书面正式答复告知没有刑法上的禁止性、没有违法性，可以干。

   * 小老板干了一年被经侦局的人以非法经营罪抓捕，谁答复错了：是当地法院答复错了，经侦局认定构成非法经营罪没有问题。

   * 小老板对事实没有认识错误，对刑法评价禁止与否的认识错了，属违法性认识错误。

   * 但他听信的是法院的正式答复，信赖法院就导致他没有认识到的可能性。

   * 没有违法性认识可能性就排除了责任，最终不定罪。

   * > **注意**：渠道是硬条件——必须是**有权机关的正式书面答复**，而且这个答复还得是错的。问语文老师、体育老师、大律师、知名教授都不行。

### 违法性认识可能性的判断标准

   * 十几年前天津一个做外贸生意的老板常年往来韩国，与韩国一名有夫之妇通奸被以通奸罪抓捕，他惊讶于中国早已不处罚的通奸在韩国居然是犯罪。

   * 他对事实没有认识错误，通奸的违法性认识错误系独立产生，属刑法上的法律认识错误。

   * 但他的通奸对象本身就是韩国妇女，行为开始前完全可以向该妇女咨询确认韩国的刑事风险，对方一定会告诉他这么干就是通奸罪。

   * 他有认识条件、有认识环境、有认识机会，所以有违法性认识可能性，可以被谴责，最终要负刑事责任。

   * > **易错点**：⚠️ "客观上确实难以知道"与"主观上有没有认识机会"是两回事，判断认识可能性看的是认识条件、环境、机会是否客观存在，而不是当事人声称自己知不知道。

### 做题的判断顺序

   * 第一步看对构成要件事实、主要是行为对象，有没有事实认识错误。

   * 有事实认识错误的，排除犯罪故意，得出不构成犯罪，案件审理到此结束。

   * 没有事实认识错误的，第二步看对刑法禁止性、刑法违法性有没有法律认识错误。

   * 有法律认识错误的，第三步看他有没有违法性认识可能性。

   * 有违法性认识可能性的，有责任，定罪，量刑可从轻、缓刑或免除处罚。

   * 没有违法性认识可能性的，排除责任，不定罪。

   * 两个错误都没有的，不存在责任阻却事由，正常进入定罪。

```text
  遇到认识错误的案件
          │
          ▼
  第一步  对构成要件事实（行为对象）有没有认识错误？
          │
          ├── 有 ──► 排除犯罪故意 ──► 不构成犯罪 ──► 案件到此终结
          │
          └── 无 ──► 第二步：对刑法禁止性（违法性）有没有认识错误？
                     │
                     ├── 无 ──► 没有责任阻却事由 ──► 正常进入定罪
                     │
                     └── 有 ──► 第三步：有没有违法性认识可能性？
                                      │
                                      ├── 有 ──► 有责任 ──► 定罪
                                      │           量刑可从轻、缓刑或免除处罚
                                      │
                                      └── 无 ──► 排除责任 ──► 不定罪
```

| 对比项 | 事实认识错误 | 法律认识错误 |
| :--- | :--- | :--- |
| 认错了哪一层 | 事实判断 | 价值评价（法律评价） |
| 认识对象 | 构成要件事实，主要是行为对象 | 刑法的禁止性，即刑法的违法性 |
| 典型案例 | 以为是普通动物，实为国家保护动物 | 小芳以为反锁是为他好，刑法却禁止 |
| 所处体系 | 主观要件 → 犯罪故意 | 主观责任阻却事由 → 违法性认识可能性 |
| 法律后果 | 排除犯罪故意，不构成犯罪 | 原则：不知法者不免责；例外：没有违法性认识可能性才排除责任 |

## 期待可能性

   * **期待可能性理论**

       * > **定义**：刑法条文要生效，暗含一个条件——能够期待一般人都能够遵守它；在一些特殊情况下无法期待某个行为人遵守时，该行为人就不具有期待可能性，不得被谴责。

       * 它由德国引入，我国主流理论与教科书体系都已吸收。

       * 不具备期待可能性即可排除可谴责性、排除责任，构成主观责任阻却事由。

       * 法律不强人所难，要保留一丝人性的温情。

### 缰绳马车案与理论起源

   * 1897 年德国一家出租车公司雇用的马车夫，驾的马有怪癖，喜欢用马尾巴缠住缰绳，缰绳相当于方向盘，一缠就容易失控。

   * 马车夫请求换一匹正常的马，老板经营状况不好拒绝更换。

   * 马车夫想到全家都靠自己这份微薄工资养活，不干就会失业，于是硬着头皮继续干。

   * 终于有一天马又犯怪癖，车辆失控出了车祸，乘客死亡，马车夫被抓，一审定过失致人死亡罪。

   * 终审阶段律师提出了"法律不强人所难"的理由，这个理由后来被上升为期待可能性理论。

### 亲亲相隐的现代根据

   * 我国两千年前就有了亲亲相隐：儿子犯罪父亲把儿子藏起来不构成窝藏罪，反过来老父亲犯罪儿子把老父亲藏起来也不构成窝藏罪。

   * 古代的理论基础是儒家经典学说，孔子说过"父为子隐，子为父隐，直在其中"。

   * 放到今天的现代刑法理论里，它的根据就是期待可能性。

### 期待可能性的适用范围

   * 期待可能性不能随便滥用，它主要用在妨害司法秩序犯罪里。

   * 伪证罪：被告人本人站在那里胡说八道，构不成伪证罪，其犯罪主体不包括被告人本人。

   * 销赃：小偷偷了东西后去销赃，不需要另定掩饰、隐瞒犯罪所得罪，因为不具有期待可能性。

   * 期待可能性这个思想的实质就是期待一个人做他做得到的事。

   * > **易错点**：⚠️ 期待可能性主要是**排除责任**的，不是排除构成要件的，它处理的是"该不该谴责"，不是"有没有犯罪事实"。

### 主观责任阶层的整体位置

   * 责任年龄：主抓 12~14 周岁，另有 14~16 周岁的八种罪。

   * 责任能力：内含行为与责任能力同时存在原则，是这一块唯一有难度的内容。

   * 法律认识错误：指刑法上的认识错误，是全块最抽象最难的一处。

   * 期待可能性：没那么重要，原理一理解即可，分则讲妨害司法秩序类犯罪时还要大量运用。

```text
  主观责任阶层
  ├─ 主观要件
  │   ├─ 故意
  │   ├─ 过失
  │   └─ 事实认识错误
  └─ 主观责任阻却事由
      ├─ 责任年龄
      ├─ 责任能力
      ├─ 违法性认识可能性
      └─ 期待可能性
```
