# 侵犯人身权利的犯罪：生命身体、性权利、人身自由、名誉婚姻家庭

## 分则复习策略与罪名重要性

### 分则散乱的成因与破解

* **分则散乱的第一个原因**

    * > **定义**：分则是由四百多个罪名一个一个堆起来的，天然缺乏体系性。

    * 总论的体系性极强，是体系本身撑起来的；分则没有这根骨架。

* **分则散乱的第二个原因**

    * 一个罪名按客观构成要件、主观构成要件完整拆解，主体→行为→结果→因果关系→主观故意，也无法逐个讲。

    * 不是每个罪名的每个要件都重要，只能挑考试常考的那几个零部件专门讲；讲得挑、考得挑，读者就觉得凌乱。

* > **结论**：分则的散乱是罪名的考试方法决定的，不要指望它有总论那样的体系性。

* **能做的三件事**

    * 把部分罪名的底层原理讲透——抓住原理，考场上自己往外推。

    * 总结规律性以帮助记忆，用图表承载。

    * 接受散乱本身，克服方式是建立自己的切入点，而不是等教材给一个严丝合缝的框架。

* **钻牛角尖要两说**

    * 钻牛角尖体现的钻研精神值得鼓励，对研究生这类时间无限的人可以尽管钻。

    * 但这是一场考试，时间与精力有限，必须按比例原则投放精力：一线考点多投，二线考点少投，三线考点看时间——一线二线都掌握好且有余力才看三线，时间不够则一线二线优先。

* **讲解顺序**

    * 个人法益的犯罪 → 社会法益的犯罪 → 国家法益的犯罪。

    * 个人法益内部先人身犯罪、再财产犯罪。

### 罪名重要性排序

* > **定义**：分则八章按侵犯法益的种类划为个人法益、社会法益、国家法益三大板块，并按重要性排出"老一"到"老八"。

| 层次 | 章节 | 罪名数量与分值 |
| :--- | :--- | :--- |
| 老一 | 财产犯罪 | 三章合计罪名不到四十个，分值占至少 50%，是头部顶配区间 |
| 老二 | 人身犯罪 | 同上，重点罪名三十来个 |
| 老三 | 贪污贿赂犯罪 | 同上 |
| 老四至老八 | 经济犯罪、社会管理犯罪、危害公共安全犯罪、渎职犯罪、危害国家安全罪 | 罪名合计约占全部罪名的 90%，只分剩下约一半分值 |

* > **注意**：老一、老三、老二这三章罪名少而分值重，必须重中之重地复习；老四到老八贯彻抓大放小，只找其中的重点罪名，普通罪名提一两句。

* 危害国家安全罪不做常规复习，考前有时间瞄一眼即可。

* **人身犯罪内部也有排序**

    * 侵犯人身自由的犯罪是人身犯罪里最重要的一节，分值最高、难度最大，罪名共五个。

    * 一哥是绑架罪（难度最大、分值最高），二哥是非法拘禁罪（是轻罪但有难度，主观题考过、还考过观点展示），老三是拐卖妇女儿童罪。

    * 其次是杀人、强奸、猥亵等方面的罪名，零零碎碎，掌握要点即可。

    * 侵犯名誉权、人身权与婚姻家庭这一节的罪名属"二线罪名"，挑重点讲、总结规律。

## 安乐死与自杀自伤

### 安乐死与承诺的效力

* **安乐死**

    * > **定义**：绝症患者痛苦，请求医生给一针"送他上路"，医生照做的情形。

    * 在我国构成故意杀人罪，量刑上可以考虑从宽。

    * 理由是承诺放弃生命无效。

* **被害人承诺的效力阶梯**

    * 承诺放弃生命——无效。

    * 承诺接受重伤——无效。

    * 承诺接受轻伤——有效。

* > **提示**：承诺是后面判断行为人身份（实行犯还是帮助犯）的关键工具，不能一概而论。

### 自杀自伤四类型：按有无支配力分层

* > **结论**：前两类与后两类的分野在于有没有对被害人形成支配力。有支配力，你能支配他干什么、他干什么就是他自己的选择；没有支配力，被害人始终自己动手、自己负责。

| 行为类型 | 有无支配力 | 指向的罪名 |
| :--- | :--- | :--- |
| 欺骗、强迫他人自杀 | 有 | 故意杀人罪的间接正犯 |
| 欺骗、强迫他人自伤 | 有 | 故意伤害罪的间接正犯 |
| 教唆、帮助他人自杀 | 无 | 有观点展示：罪或无罪 |
| 教唆、帮助他人自伤自残 | 无 | 不构成故意伤害罪 |
| 变成承诺场合的"帮忙" | —— | 故意伤害罪的实行犯 |

* **欺骗、强迫他人自杀自伤**

    * 通过欺骗或强迫形成对被害人的支配力，成立故意杀人罪的间接正犯（骗人去死）；成立故意伤害罪的间接正犯（骗人自伤，如"欲练此功必先自宫"）。

    * 判断标准始终是结果指向死亡还是伤害，而不是"骗"这个手段本身。

* **教唆、帮助他人自杀**

    * 没有欺骗、没有胁迫、没有形成支配链，不可能构成故意杀人罪的间接正犯。

    * 两种观点都要说理由。

        * 无罪说：共犯从属性。实行者就是自杀者本人，自己自杀无罪，教唆者、帮助者因此无罪。

        * 有罪说：生命要绝对保护，共犯从属性在这一块要搞例外。

    * > **结论**：无罪说在德国还是多数说，有罪说在我国是多数说。

    * > **注意**：无罪说认为自杀是理性选择、他人应予尊重；有罪说认为自杀现象在我国很多，很多是痛苦想不开、要解脱，不能反倒去助长。

* **教唆、帮助他人自伤自残**

    * 只有一个结论：不构成故意伤害罪，严格遵守共犯从属性——自伤者自己无罪，教唆者、帮助者也无罪。

    * > **易错点**：同一个"共犯从属性"，在教唆帮助自杀那里被打破（保护生命法益），在教唆帮助自伤这里被严格遵守（保护身体健康）。区分点在于所侵害的法益层级，不在于"自杀"和"自伤"这两个词本身。

* **变成承诺场合的"帮忙"**

    * 教唆、帮助他人自杀自残有一个前提：自伤自残者是实行者。

    * 若被害人把刀交给行为人、要求其代砍，行为人已经实施了实行行为，不再是帮助他人自伤，而是故意伤害罪的实行犯。

    * 构成与否取决于承诺效力：砍掉一条胳膊是重伤，承诺接受重伤无效，故仍构成故意伤害罪的实行犯。

## 故意伤害罪

### 轻伤门槛与暴力行为的够格线

* **程度与定罪门槛**

    * 轻微伤不构成犯罪——扇耳光、口角打出血属轻微伤，是治安管理处罚与民事侵权的事。

    * 故意伤害罪在我国要求至少轻伤；轻伤之上是重伤，重伤之上是伤害致死。

    * > **注意**：我国轻伤标准其实挺高，打到颅脑出血还算轻伤。考试里把小手指砍了才算轻伤，大拇指没了是重伤。

* **暴力行为本身要够格**

    * 构成故意伤害罪要求该暴力行为本身具有造成轻伤的可能性、危险性，而不是只要有暴力行为就构罪。

    * 推一把、推搡本身没有造成轻伤的可能性，不构成故意伤害罪。

    * 是否构成过失致人死亡罪要再加条件：有过失则定过失致人死亡罪，没有过失就是意外事件。

### 杀人、伤害致死、过失致死三罪区分

* **共同点与区别**

    * 相同点：都导致人死亡。

    * 顺序问题：能构成故意杀人罪或故意伤害罪的，才谈得上"致人死亡"；过失致人死亡罪本身不要求构成故意伤害罪，只是一个单纯的过失致人死亡。

| | 故意杀人罪 | 故意伤害罪致人死亡 | 过失致人死亡罪 |
| :--- | :--- | :--- | :--- |
| 对伤害行为的故意 | 有 | 有 | 无 |
| 对死亡结果 | 有故意（直接或间接） | 无，故意内容是过失 | 无，故意内容是过失 |
| 行为本身的要求 | 具备剥夺生命的危险性 | 具备造成轻伤以上的可能性 | 具备造成轻伤以上的现实过失 |
| 定罪结论 | 故意杀人罪 | 故意伤害罪（致人死亡加重） | 过失致人死亡罪 |

* > **易错点**：主观心理的区分在考试里不好直接把握，只能根据客观题干给的信息推定，不能看当事人嘴上怎么说——嘴上怎么说，有时候口是心非。

* **杀人故意有两种**

    * 蓄谋杀人（谋杀）：事先计划已久。

    * 临时起意（激情杀人）：素不相识、无冤无仇，只说明没有谋杀故意，完全可能有临时起意杀人的故意。

* **以客观手段推定故意**

    * 双手死死掐住脖子不松手直至窒息身亡——掐脖子是致命要害部位，手段毫无节制，说明对死亡有放任心理，属间接故意，构成故意杀人罪。

    * 拿芭蕉叶打腰并口称"我要杀死你"——没有造成轻伤的可能性，连故意伤害罪都不构成。

    * 拿圆月弯刀一下一下刺心脏并口称"我真不想杀死你"——构成故意杀人罪。

* > **结论**：要看客观证据，不要看嘴。

### 竞合关系

* **法条竞合：杀人罪与伤害罪**

    * 两者不是 A 与非的对立排斥关系，是本科生与硕士生的关系——杀人罪蕴含伤害罪，可以被包容评价。

    * 特殊法优于一般法，杀人比伤害更重更特殊，定故意杀人罪。

* **想象竞合：伤害罪与其他暴力性犯罪**

    * 强制猥亵罪、非法拘禁罪、侮辱罪、暴力干涉婚姻自由罪、妨害公务罪中都可以有暴力；如果该暴力把人打成轻伤、重伤，还要与故意伤害罪想象竞合。

    * 想象竞合按一重处理，打成重伤时故意伤害罪重伤一般更重。

* > **注意**：对方罪里有结果加重犯规定的，不能按想象竞合定，要按结果加重犯定——结果加重犯是特殊规定，按特殊规定来定。如抢劫罪为取财把人打成重伤并取得财物，定抢劫罪（致人重伤）。

## 组织出卖人体器官罪

### 人体器官的判断标准

* > **定义**：本罪主要打击黑市上的器官买卖，而器官买卖主要服务于器官移植，所以判断标准是**能不能移植**。

* 属于人体器官的：肝脏、肾脏、眼角膜、皮肤（皮肤可移植）。

    * > **易错点**：不包括血液——另有非法组织卖血罪。

    * 不包括细胞、精子、卵子——有组织出卖卵子的，不构成本罪。

    * 脑袋能不能算，要看脑袋能不能移植。

* **出卖要看两件事**

    * 出卖者是未成年人，或者出卖行为受到欺骗、胁迫的，对组织者不定本罪，直接定故意伤害罪（摘取肾脏绝对重伤）、致死的定故意杀人罪。

* **罪名由来**

    * 2011 年前后安徽一名 17 岁高中生因攀比、贫困而卖肾，出卖者系被教唆者，正是本罪的设立缘起。

## 遗弃罪

### 真正的不作为犯罪

* > **定义**：真正的不作为犯罪，就是你不履行抚养义务。

* 不履行抚养义务的方式可以多种多样：不管不问、把瘫痪老人丢在那儿不管；也可以是把老人抛扔到马路边。

    * > **注意**：不能因为"扔在马路边"看起来像一个作为，就认为遗弃罪不是不作为——不履行抚养义务的表现既可以是静态的方式，也可以是动态的方式。

### 抚养义务即救助义务

* 抚养义务人这个行为主体不限于亲属之间，把抚养义务理解成**扶助义务、救助义务**即可。

* 救助义务是一个作为义务，其来源在总论已学：先行行为、职务业务、特定法律关系、亲属关系都可以产生。

    * 孤儿院院长对学生有抚养义务；用先行行为不小心把人打伤而产生扶助义务，不扶助也可能构成遗弃罪；交通肇事司机撞伤行人对行人有扶助义务。

* > **结论**：交通肇事中"因逃逸致人死亡"实质就是因遗弃致人死亡，作为交通肇事罪的加重处罚情节，而非单定遗弃罪。

* > **结论**：正因为遗弃罪的保护法益落在人身、身体这一侧，所以把它放在侵犯人身、身体的犯罪里，没有放在家庭犯罪里。

### 遗弃罪与杀人罪的界限

* > **定义**：杀人罪可以包容评价为遗弃罪，关键是看程度，即**对人的生命法益的紧迫程度**。

    * 把孩子扔到马路边——遗弃罪。

    * 把孩子扔到深山老林、扔到熊出没的地方——故意杀人罪。

    * 孩子没被熊咬死、反而被熊养起来，日后成了"熊孩子"——依然构成故意杀人罪，但是未遂。

## 强奸罪

### 保护法益与行为主体

* **保护法益**

    * > **定义**：强奸罪的保护法益是妇女的性自主权。

    * 卖淫女同样有性自主权；对方不同意而强行发生性行为，构成强奸罪。

    * 以"包夜协议""民法上的留置权"抗辩不成立——包夜协议违反公序良俗与强制性规定，本身无效、非法，刑法不介入该民事评价。

* **行为主体**

    * 只有男性才可能构成强奸罪的单独直接实行犯，妇女不能构成该罪的单独直接实行犯。

    * 但妇女完全可以构成该罪的教唆犯、帮助犯、共同实行犯、间接正犯。

### 实行行为：暴力、胁迫与其他方法

* 三类强制手段都是足以压制反抗、让人不敢反抗或者不知反抗的手段。

* **胁迫：四词一义的行为模型**

    * 胁迫、威胁、恐吓、敲诈四词含义一样，叫多词一义；强奸、抢劫、敲诈、妨害公务等罪里都有胁迫，模型要背下来。

    ```text
┌──────────────────────────────────────────┐
│① 行为人甲以「恶害」相通告                │
│    「你若不答应我的要求，我就施加恶害」  │
└─────────────────────┬────────────────────┘
                      ▼
┌──────────────────────────────────────────┐
│② 被害人乙对甲产生恐惧心理                │
│    （恶害须指向乙本人或乙的亲友）        │
└─────────────────────┬────────────────────┘
                      ▼
┌──────────────────────────────────────────┐
│③ 乙基于恐惧心理，答应甲不法要求          │
│    —— 至此才成立胁迫型强制               │
└──────────────────────────────────────────┘
    ```

    * > **提示**：整个模型的命门在"以恶害相通告"。恶害针对被害人一方；行为人拿自己去死、去自残来要挟被害人，不落在该模型里。

    * > **注意**：以好处相利诱不是胁迫——导师说"我也能让你考上"是权色交易，不算；若说"即使你初试第一我也照样把你刷下来""让你毕不了业"，被害人产生恐惧并答应，就算胁迫型强奸。

    * > **注意**："你不答应我就自杀"不算胁迫，因为恶害落在行为人自己身上；若改成"我给你丈夫看""我上网曝光"就落在被害人本人身上，算胁迫。

* **其他方法之一：昏醉型与趁机型**

    * 昏醉型：行为人带着奸淫目的把妇女灌醉、下迷药弄昏后发生性行为。

    * 趁机型：妇女自行醉酒或昏迷，行为人路过趁机发生性行为，仍是违背妇女意志的强奸。

* **其他方法之二：欺骗型要看受骗的性质**

    * 对事实有认识错误：冒充对方丈夫、男朋友，妇女认错人作出的承诺无效，构成欺骗型强奸。

    * 只是动机错误：承诺给女一号、宣称奔着结婚谈恋爱，妇女知道眼前是谁，因动机上当而发生性行为，不构成欺骗型强奸。

    * > **结论**：用"以恶害相通告"这一句可以把强奸与潜规则、权色交易区分开。

* **行为对象**

    * 没有"奸淫幼女罪"这个罪名，奸淫幼女构成强奸罪并从重处罚。

    * 幼女即使同意也构成强奸罪——她对这些事情没有正确理解能力，没有承诺能力，承诺无效。

### 法定升格条件

* **在公共场所当众强奸妇女、奸淫幼女**

    * 量刑起步价 10 年，到死刑。

    * "公共场所"指公共空间、非私密空间，即不特定人或多数人可以进出的空间。

        * 王府井大街、电影院、公交车都算；优衣库试衣间不算——"公共"指的是使用权限上人人可用，但某个顾客使用时那一刻起里面已是私密空间。

    * "当众"不要求当面、不要求视觉，听觉也行。

        * 街头大型公共厕所里强奸，墙外小弟摇旗呐喊，算；酒店房间里隔墙只有一只耳朵在听，不算。

        * 公安厕所案与宾馆房间案的区别在于：前者的被害人与行为人都知道外面有人为此事摇旗呐喊，后者行为人不知道隔墙有耳。

    * > **易错点**：当众不要求现实被看到，只要具有被众人看到的危险性、可能性就够了。小学教室里班主任在最后一排猥亵最后一排学生，前排同学都在认真读书、小女生不敢吱声，算"在公共场所当众实施"。

* **强奸致人重伤、死亡**

    * 典型的结果加重犯，原理与总论结果加重犯一章一致。

* **拐卖妇女儿童罪与强奸罪的结合犯**

    * 拐卖妇女儿童罪再加一个强奸罪，等于拐卖妇女儿童罪，然后加重处罚。

* **基本犯与加重犯的既未遂**

    * 共同正犯、部分实行全部负责：一人得逞、另一人因自身原因未得逞，二人的基本犯强奸罪都是既遂；后者的既遂是法律评价——要对同犯的既遂结果负责，不是事实判断。

    * 法定加重处罚条件（轮奸）成立，须加重处罚，10 年到死刑；加重形态是未遂，再按未遂犯的规定从宽一点。

## 负有照护职责人员性侵罪

### 四要件与判断表

* > **定义**：这是一个身份犯，要件特别窄，但也特别好记。

* **做题顺序**：先看行为对象的年龄 → 是 14 到 16 周岁的少女，再看行为主体是什么人 → 是有照护职责的人，再看行为方式。

| 构成要件 | 内容 |
| :--- | :--- |
| 行为主体 | 负有照护职责的人（如养父、班主任） |
| 行为对象 | 已满 14 周岁、不满 16 周岁的少女 |
| 行为方式 | 发生性交行为，不包括猥亵行为 |
| 被害人承诺 | 无效，即使少女同意也照样构罪 |

| 行为主体 | 少女是否同意 | 行为方式 | 处理 |
| :--- | :--- | :--- | :--- |
| 负有照护职责的人 | 同意 | 发生性交行为 | 负有照护职责人员性侵罪 |
| 负有照护职责的人 | 不同意 | 强制发生性交行为 | 同时构成强奸罪与本罪，想象竞合择一重，定强奸罪 |
| 负有照护职责的人 | 同意 | 猥亵（摸一摸、亲昵动作） | 无罪，不构成本罪，也不构成强制猥亵罪 |
| 负有照护职责的人 | 不同意 | 强制猥亵 | 强制猥亵罪（本罪只要求性交，不含猥亵） |
| 一般人 | 同意 | 性交或猥亵 | 无罪（已满 14 周岁，承诺有效） |
| 一般人 | 不同意 | 强制性交 | 强奸罪 |
| 一般人 | 不同意 | 强制猥亵 | 强制猥亵罪 |

* **"照护职责"怎么认定**

    * 不是所有老师、不是所有医生都算，关键是确实负有照护职责。

    * 15 岁高一女生在英语培训班与男老师谈恋爱并发生性交：不构成本罪（男老师无照护职责），也不构成强奸罪（已满 14 周岁，承诺有效）；如果不满 14 周岁，承诺同样无效，可以定强奸罪。

## 强制猥亵、侮辱罪

### 行为对象与"侮辱"的含义

* 行为对象是已满 14 周岁的人，包括男性也包括女性；未满 14 周岁的就是儿童，走猥亵儿童罪。

* 行为方式要同时具备强制与猥亵、侮辱两项。

* > **定义**：本罪中的"侮辱"要理解成"猥亵"，即侵犯对方的性羞耻心。

* > **易错点**：侮辱罪侵犯的是名誉，本罪里的"侮辱"是猥亵、侵犯性羞耻心，两个含义不一样——给妇女泼粪便按侮辱罪评价，扒人家衣服才是本罪。

### 不要求身体接触

* 拿刀逼女教师脱衣服后用手摸，是最典型的强制猥亵。

* 非典型也都算：

    * 强迫女教师自己摸、强迫她摸行为人；

    * 强迫她只当观众、看着他自摸，否则拿刀捅瞎双眼——这是视觉污染、视觉暴力；

    * 强迫妇女观看（"不看还不行"）有强制。

* 大街上突然脱裤子、妇女扭头就跑，不算——有猥亵但没有强制。

* > **结论**：强制猥亵罪不要求身体接触，确实存在"隔空猥亵"，如以曝光裸照相威胁、强迫妇女脱衣服表演。

* > **易错点**：有隔空强制猥亵，但有没有隔空强奸？强奸若要既遂仍要求身体接触，所谓"云强奸"不成立。

### 司法解释：强迫发裸照

* 强迫成年妇女把自己关起门拍的写真集寄发给自己，不构成强制猥亵罪——强迫他人寄发照片不属于强制猥亵行为。

    * 有人主张定敲诈勒索罪，看写真集数额是否达到入罪标准；我国没有兜底的强迫罪，至少可按治安管理处罚处理（德国、日本有独立的强迫罪）。

* 司法解释的特殊规定：被害人是 14 至 18 周岁的未成年人，强迫其发送裸照，构成强制猥亵罪，要特殊保护。

* 被害人不满 14 周岁的儿童，强迫其发裸照构成猥亵儿童罪，而且不要求强制手段——诱骗、指使，乃至其自愿发送，均构罪。

## 猥亵儿童罪

* 法定刑经过修改，最高提高到 15 年，原因是社会上对儿童的性侵突出，需要加大打击力度。

* > **结论**：强迫、引诱、指使儿童发裸照，儿童即使同意也构成猥亵儿童罪；这条防线保护的不是儿童的"性权利"，而是儿童的身心健康。

## 性权利犯罪的定罪三步

* **第①步 被害对象是谁**：先看性别，再看年龄——女性满 14 周岁为妇女、未满 14 周岁为幼女；男性满 14 周岁为成年、未满 14 周岁为男童。

* **第②步 行为方式**：发生性交行为还是猥亵行为。

* **第③步 对号入座**。

| 被害对象 | 发生性交行为 | 实施猥亵行为 |
| :--- | :--- | :--- |
| 女性·已满 14 周岁（妇女） | 强奸罪 | 强制猥亵罪 |
| 女性·未满 14 周岁（幼女） | 强奸罪（从重处罚） | 猥亵儿童罪 |
| 男性·已满 14 周岁 | 强制猥亵罪 | 强制猥亵罪 |
| 男性·未满 14 周岁（男童） | 猥亵儿童罪 | 猥亵儿童罪 |

* > **注意**：幼女、男童"自愿"也照样构罪——承诺无效。

* 对男性实施性交行为只能定强制猥亵罪，因为强奸罪只保护妇女的性自主权。

## 非法拘禁罪

### 非法剥夺人身自由的认定

* > **定义**：非法拘禁行为就是非法剥夺他人的人身自由。

* 广义打开思路的例子：

    * 追求者把对方关在塔吊上、关掉开关，让对方下不来——算非法拘禁。

    * 趁人洗澡抱走衣服让人上不了岸（牛郎织女、猪八戒抱走盘丝洞衣服）——算非法拘禁；同样手段下，牛郎被看作凄美、猪八戒被看作猥琐，关键看谁在做。

    * 同学上厕所没帮送纸而蹲了一节课——不算，因为这不是"没穿衣服出不来"，问题很容易解决。

* **欺骗的分水岭：客观上到底能不能出去**

    * 断电的电梯——构成。客观上确实让人出不去、对方也认为自己出不去；出不去的原因只是被欺骗。

    * "为爱画地为牢"——不构成。房门开着、可以自由进出，是受骗导致自己不想出去。

* > **提示**：非法拘禁一般要时间达到 24 小时才承担刑事责任；没达到 24 小时但有其他严重情节的，也能承担刑事责任。

### 致人重伤、死亡的结果加重犯

* 条文是《刑法》第 238 条第 2 款第 1 句：犯前款罪，致人重伤、死亡的，加重处罚；致重伤、死亡只能是过失。

* **因的辨认**

    * 致重伤、死亡的那个"因"必须是非法拘禁罪的实行行为本身。

    * 绳子勒得太紧致窒息死亡——因就是拘禁行为本身，构成非法拘禁罪过失致人死亡的结果加重犯。

* **因果关系与介入因素**

    * 咬舌自尽——介入因素是被害人自身的自杀行为，属异常，没有因果关系，不构成。

    * 追到悬崖边并以飞镖相威胁，被害人脚下一滑摔死——追赶的目的也是重新拘禁，故追赶行为属于拘禁行为的一部分；异常与否要具体化、情景化判断，此处不异常，有因果关系，构成。

* **主观必须是过失**

    * 强行把人往车上拉，一不小心把胳膊拉断——构成非法拘禁罪致人重伤。

* **故意掰断胳膊：为什么反而不是结果加重犯**

    * > **易错点**：故意掰断胳膊致重伤不构成"非法拘禁罪致人重伤"——结果加重犯要求对加重结果是过失，这次是故意。

    * 这是一个行为、两个目的：伤害目的构成故意伤害罪（致重伤加重处罚，故意伤害致重伤既包括本想打成重伤结果打成，也包括只想造成轻伤过失造成重伤）；拘禁目的构成非法拘禁罪。

    * 两罪两目的属于想象竞合，择一重罪论处。

    * > **注意**：分析非法拘禁罪的定性时暂不考虑定量要求（24 小时），只做定性分析。

    * > **易错点**：做题时选项常把中间"过失"两个字引掉，看到"非法拘禁罪致人重伤"要立刻想到里面有个"过失"，该选项不能选。

### 使用暴力致人伤残、死亡：故意说与过失说

* **两款两句的总钥匙：一个行为还是两个行为**

    * 第 1 句是结果加重犯，一个行为制造两个结果（基本犯结果与加重结果），所以是一个行为。

    * 第 2 句的"使用暴力"已经是拘禁行为之外的第二个行为，所以是两个行为。

* **故意说：注意规定**

    * "使用暴力致人伤残、死亡"指故意，因最终定的是故意伤害罪、故意杀人罪，主观当然是故意；该条是提醒不要搞错的正常办事。

    * 对应案例：拘禁两天后欲强吻，被连吐三口痰，恼羞成怒直接掐死——前面一个拘禁行为，后面一个暴力行为，定故意杀人罪。

* **过失说：法律拟制**

    * > **定义**：法律拟制就是立法者的任性、特事特办。

    * 法条表达对死亡结果的故意时会直接写"故意杀人"；写"致人伤残、致人重伤死亡"表达的都是过失（对照过失致人重伤罪、过失致人死亡罪）。

    * 说是过失却定故意伤害罪、故意杀人罪，正是把过失致人伤残、死亡拟制为故意伤害罪、故意杀人罪。

    * 对应案例：拘禁两天后想教训一下，轻轻扇一耳光不小心扇到太阳穴致死——暴力程度本不足以构成故意伤害罪，属过失致人死亡，拟制为故意杀人罪。

* > **结论**：多数说采法律拟制，理由有两条——条文一般说"致人伤残死亡"表达的都是过失；立法者没有必要设一个注意规定去提醒基层法官不要犯这种低级错误。

* **两句话怎么分：看暴力行为的目的**

    * 用**行为与目的同时存在原则**：看实施该暴力行为本身带着什么目的。

    * 目的是剥夺他人人身自由（拘禁目的）——就是拘禁罪实行行为本身，落第 1 句。

    * 目的是拘禁之外（如教训）——就是拘禁行为之外的暴力行为，落第 2 句。

### 四个标准模型

```text
[ 暴力致人伤残 / 死亡 ]
          |
          +-- 主观故意 ---> 正常处理：故意伤害罪 / 故意杀人罪
          |
          +-- 主观过失 ---> 法律拟制：拟制为故意伤害罪 / 故意杀人罪
                            |
                            +-- 两个行为 --> 罪数另算，须防"重复处罚"
                            |
                            +-- 一个行为 --> 问：这个暴力到底想干什么？
                                                |
                                                +-- 目的就是拘禁
                                                |      -> 拘禁行为本身
                                                |      -> 第2款第1句
                                                |
                                                +-- 目的是拘禁之外（如教训）
                                                       -> 拘禁之外的暴力行为
                                                       -> 法律拟制为故伤 / 故杀
```

* **模型一**

    * 拿绳子捆人，绳子勒太紧致窒息死亡。

    * 一个行为，就是拘禁罪实行行为；对死亡是过失，定非法拘禁罪过失致人死亡的结果加重犯。

* **模型二**

    * 为压制反抗把胳膊掰断致重伤。

    * 一个伤害行为既是非法拘禁罪的实行行为，也是伤害罪的行为；构成非法拘禁罪与故意伤害罪（重伤），想象竞合择一重罪论处。

    * > **注意**：对重伤是故意，绝不能定"非法拘禁罪致人重伤"。

* **模型三**

    * 已构成非法拘禁罪，被害者辱骂，行为人只为教训而扇耳光，不小心致人死亡。

    * 两个行为：拘禁行为 + 拘禁行为之外的暴力行为；后者过失致人死亡，按多数说拟制为故意杀人罪。

* **模型四**

    * 已构成非法拘禁罪，被害者辱骂，行为人故意直接把人杀死。

    * 两个行为，后一个暴力是正常处理的故意杀人，不走拟制。

### 罪数：模型四并罚、模型三不并罚

* **模型四：必须两罪并罚（多数说）**

    * 少数说：杀人罪吸收非法拘禁罪，只定故意杀人罪——两者同属人身犯罪、性质相同程度不同，重罪吸收轻罪。

    * 多数说：两罪并罚。章罪名角度上同属人身犯罪，但节罪名角度上，故意杀人罪保护生命法益、非法拘禁罪保护人身自由法益，法益性质不同，一个不能吸收另一个；只定杀人罪就一路评价、一路处罚了人身自由法益被剥夺的事实，违反禁止遗漏处罚原则。

* **模型三：只定一个故意杀人罪（多数说）**

    * 立法者再任性也不可能把单纯的过失致人死亡定成拟制故意杀人，否则过失致人死亡罪就被废掉了；他只能把某些背景条件下的过失致人死亡拟制为故意杀人——有非法拘禁罪这个背景条件才用得上这个拟制。

    * 即"非法拘禁罪 + 过失致人死亡罪 = 故意杀人罪"，已经评价了非法拘禁罪；再并罚就是处罚了两次，违反禁止重复处罚原则。

    * 少数说主张并罚，理由是两个行为、两个罪、性质又不同。

* **背后是总论罪数的两句话**

    * 模型三只定一个故意杀人罪——否则违反**禁止重复处罚、禁止重复评价**原则。

    * 模型四两罪并罚——否则违反**为了保护法益而禁止遗漏处罚、禁止遗漏评价**原则。

    * 客观题只需理解会用；主观题要求写理由，这两句要背到能默写。

## 绑架罪

### 行为结构：两步棋与两个目的

* > **定义**：完整的绑架案件结构是"非法拘禁 A + 敲诈勒索 B"。

    ```text
              行为一                         行为二
        实力控制人质  ───────────────→  向第三人提出不法要求
        （劫持 / 拘禁）                   （最常见：要钱）
              │                                │
             目的一                            目的二
        拘禁、控住人质              向第三人勒索财物 = 非法占有目的
    ```

* 行为一实力控制人质本身是非法拘禁；向第三人要钱本身是敲诈勒索——不给钱就撕票是典型敲诈。

### 既遂标准的三种观点

* **少数说**

    * 要求实施行为二；打到电话告知"不给钱就撕票"这一步就够了，不要求实施成功。

* **极少数说**

    * 不光要实施行为二，行为二还得实施成功（钱真到手）才算既遂——要求太晚。

* **多数说**

    * 只要行为一实施成功、把人质实力控制到手，绑架罪就既遂，不要求实施行为二。

    * > **结论**：理由是绑架罪的保护法益只有人质的人身安全与自由，没有第三人的财产法益；该罪规定在人身犯罪这一章。人身自由、安全一被剥夺、控制到手，法益侵害就完成了。

* **与非法拘禁罪的界限**

    * 行为二虽不要求实施，但要求有目的二——必须是"带着向第三人要钱的目的"去拘禁人质才成立绑架罪；没有这一目的，只是单纯想把人手拘禁到手，即使真绑到了也只构成非法拘禁罪。

* > **提示**：展示观点时，若只要求两种观点，摆多数说与少数说即可；要求三种时把极少数说也摆出来。

### 目的二是唯一的区分标准

* 绑架罪的客观行为与非法拘禁罪一模一样，都是拘禁、都是实力控制；区别只在于绑架罪多了一个目的二。

| 罪名 | 目的二 |
| :--- | :--- |
| 绑架罪 | 向第三人（被害人家属等）要钱 |
| 拐卖妇女罪 | 出卖被害人 |
| 强奸罪 | 强行性关系（劫色） |
| 抢劫罪 | 向被绑的本人要钱 |

* > **结论**：向第三人要钱 + 劫持他人 = 绑架；向被绑的这个人自己要钱 + 劫持他 = 抢劫。

### 合格人质

* > **定义**：合格的人质，是从**行为时一般人的角度**出发去评判、会让第三人产生担忧的那个人。

* 春秋战国时各国把王子送到他国做人质，当然会让对方担忧。

* 绑架非对方国家公民去要钱不成立绑架罪，因为对方不会担忧，只成立非法拘禁罪——目的二本身就落空了。

* > **易错点**：判断时点是行为时，不能从事后第三人个性化、个别化的角度看。被害人的丈夫巴不得妻子被绑、拒绝解救，仍成立绑架罪——从事时一般人角度看，把老婆绑了老公一般会担忧。

* > **提示**：检验自己在对方心中的地位有一个办法：看有没有资格成为一个合格的人质。

### 既遂条件与特定对象的特定性

* **必须实际控制到手**

    * 着手制服被害人而被打晕，绑架罪成立但未既遂——没有绑到手，只成立未遂。

* **必须控制住"合格"的人质**

    * 在小学门口抓错人、把邻居家的孩子绑到手再打电话要钱：绑架罪成立并着手，但对象是特定对象，对象认识错误影响既遂，故为绑架罪未遂；对抓错的孩子构成非法拘禁罪既遂（非法拘禁罪的对象是一般对象），两罪并罚。

    * > **注意**："对象认识错误不影响故意犯罪既遂"暗含一个条件——该罪名的行为对象是一般对象。绑架罪的对象是特定对象（人质），所以对象认识错误影响既遂。

* **合格人质根本不存在**

    * 小学门口根本没有目标孩子的孩子在场，连绑到合格人质的可能性、危险性都没有，不成立绑架罪，只构成非法拘禁罪既遂。

* **与故意杀人罪的对照**

| | 故意杀人案 | 绑架案（合格人质根本不存在） |
| :--- | :--- | :--- |
| 一般人视角的对象 | 是活人即可，为一般对象 | 必须让第三人担忧，为特定对象 |
| 是否成立 | 成立且已着手，即便指向的是其他嘉宾 | 不成立，连绑到合格人质的可能性都没有 |
| 特定性的作用 | 只影响中止与未遂的区分（被迫放弃 vs 自动放弃） | 影响罪是否成立 |

    * > **结论**：**特定对象的"特定性"，在绑架罪这里影响的是罪的成立，在故意杀人罪那里只影响中止与未遂的区分，不影响成立。**

* **行为二要不要并罚**

    * 不并罚，只定绑架罪。

    * 首位理由是牵连犯：行为一是手段行为、行为二是目的行为，按牵连犯从一重处断，择一重即绑架罪。

    * 次位理由是吸收犯观点：敲诈勒索是在绑架罪预设框架内实施的，但重罪吸收轻罪这一理由相对次要。

### 为索取债务非法扣押、拘禁他人

* 《刑法》第 238 条第 3 款：为索取债务非法扣押、拘禁他人的，依照前两款的规定处罚。

* > **结论**：这是一个**注意规定**，不是拟制——行为人本就因缺少"向第三人勒索财物的非法占有目的"而定不了绑架罪。

    * 讨债的目的是行使债权，不是非法占有目的，目的二打叉；但有目的一、行为一，所以定非法拘禁罪。

* **讨债对象一换人，结论就翻转**

    * 向配偶讨债——夫妻有共同财产，仍是行使债权，是讨债目的，定非法拘禁罪。

    * 向没有共同财产的第三人（如表弟）要钱——对该第三人财产完全具有非法占有目的，目的二具备，构成绑架罪。

* **自然债务与捏造债权**

    * 赌债、高利贷等"法律不保护的债务"，正确理解是有事实依据、没有法律依据（类似民法上的自然之债），不是"非法债务也算讨债"；以此讨债仍定非法拘禁罪。

    * 捏造欠条索要——连事实依据都没有，完全表明非法占有目的，构成绑架罪。

* **父债子还、子债父还**

    * 父亲欠钱不还，行为人把父亲拘禁起来向儿子要钱：儿子与父亲有共同财产关系的（如未分家），与夫妻关系同理，定非法拘禁罪；早已分家、完全独立甚至不同城居住的，对儿子有非法占有目的，构成绑架罪。

### 杀害被绑架人与故意伤害被绑架人

* **共同规则**

    * 犯绑架罪杀害被绑架人的，或者故意伤害被绑架人致人重伤、死亡的，仍定绑架罪，但加重处罚到无期徒刑、死刑。

    * 伤害必须发生在从绑架着手到释放人质之前的持续期间内。

* **结果：必须真把人质杀死**

    * 多数说认为"绑架 + 杀人 = 绑架罪加重处罚"这个结合犯要求人质真的被杀死；撕票时人质活了下来，不能定结合犯。

    * 正确处理：定绑架罪既遂 + 杀人罪未遂，两罪并罚。少数说则能定这个结合犯。

* **时间：必须在绑架持续期间**

    * 赎金到手、人质已释放后，行为人回头追上将人质撞死——杀人行为已出绑架罪框架，是独立杀人罪，要与绑架罪并罚。

* **杀害行为不能成为绑架罪的实行行为**

    * 绑架罪的实行行为是实力控制人质、拘禁人质、剥夺他人身自由，必须绑一个活的人质；绑架罪保护法益不包括生命法益。

    * 暴力控制人质不成而开枪将人质打死——绑架罪未遂 + 故意杀人罪既遂，两个行为，仍按"绑架 + 杀人 = 绑架罪加重处罚"的结合犯处理。

* **故意伤害被绑架人的构成要求**

    * 不包括轻伤，只有轻伤不适用本款。

    * 对重伤是故意（过失则行为太轻，加重到无期、死刑太重）；对死亡是过失（故意则直接是"绑架 + 故意杀人"）。

    * 要求有造成重伤的可能性，并且主观上有造成重伤的故意，间接故意也可以，比一般故意伤害罪要求高。

* **伤害行为的两种性质**

    ```text
        乙反抗 → 甲为压制反抗、制服乙，把乙打成重伤，终于控制住乙
                                │
              ┌─────────────────┴─────────────────┐
              │                                   │
   情形一：伤害即绑架的实行行为                    情形二：伤害在绑架之后
   伤害本身是"实力控制"的一部分                   绑架既遂后，未要到钱，泄愤
              │                                   │
        整体 1 个行为                             独立的第 2 个行为
        既触犯绑架罪又触犯故意伤害罪                 绑架 + 故意伤害
              │                                   │
        法条特别规定 → 结果加重犯                   → 结合犯
        「绑架罪（故意致人重伤）」                  「绑架 + 故意伤害
                                                 = 绑架罪加重处罚」
    ```

    * 情形一：为了控制人质而把反抗者打成重伤，伤害行为本身就是绑架罪的实行行为，整体是一个行为，按理应是想象竞合，但法条特别规定定为绑架罪（故意致人重伤）的结果加重犯。

    * 情形二：绑架既遂后未要到钱、泄愤把人打成重伤，是两个行为，成立结合犯，绑架罪加重处罚。

    * > **易错点**：**结合犯是两个行为、最后定一个罪加重处罚；情形二正好是结合犯，情形一只有一个行为，是结果加重犯。** 区分的钥匙是伤害行为是不是绑架罪的实行行为。

* **四个范例对照**

| 情形 | 定罪 | 犯的性质 |
| :--- | :--- | :--- |
| 绑架后没要到钱，杀了人质 | 绑架罪加重处罚 | 结合犯（2 个行为） |
| 绑架后没要到钱，怒而打成重伤 | 绑架罪加重处罚 | 结合犯（2 个行为） |
| 为控制而打伤反抗的人质，制服之 | 绑架罪加重处罚 | 结果加重犯（1 个行为） |
| 以绳捆人致其窒息死亡 | 想象竞合，择一重，定绑架罪 | 想象竞合 |

* **绳子勒死：从结果加重犯回归想象竞合**

    * 绳子本身是实力控制行为，一方面构成绑架罪，一方面构成过失致人死亡罪，想象竞合择一重定绑架罪。

    * > **易错点**：这个情形以前定结果加重犯，旧条文规定"绑架 + 致死 = 绑架罪"，过失致人死亡也按绑架罪加重处罚到死刑；《刑法修正案（九）》已删去该结果加重犯的特殊规定。

    * 删去理由是：行为人毕竟只是过失致人死亡，而且是一个行为，这样处理太狠。

    * 结果加重犯与想象竞合犯之间存在转化关系，本源结构完全一样——一个行为触犯两个罪名；弄特殊规定就是结果加重犯，特殊规定被删掉就回归原生态的想象竞合、择一重。

* > **结论**：说"绑架罪里从来就再也没有结果加重犯了"不严谨——为了控制人质而故意把人打成重伤的情形就是绑架罪的结果加重犯。**由伤害行为的性质决定：杀人不能成为绑架罪的实行行为，伤害可以。**

### 共犯的四个模型

* **模型一：帮忙做饭**

    * 乙不构成绑架罪既遂的共犯——做饭不是犯罪行为，没有侵犯人质法益。

* **模型二：帮忙看押**

    * 乙可以构成绑架罪既遂的共犯——看押已是危害行为，侵害了人质法益。

    * 甲绑架罪已既遂，乙后加入仍可构成共犯：绑架罪是**继续犯**，其实行行为是实力控制即拘禁行为（非法拘禁罪是继续犯，绑架罪也是继续犯）。

* **模型三：被欺骗的看押人**

    * 甲骗乙称被看押人之父欠钱、请其看押，实则无此债务。乙认为自己实施的是非法拘禁罪，而甲想实施绑架罪，绑架罪蕴含非法拘禁罪。

    * 两人只在非法拘禁罪范围内成立共同犯罪：甲定绑架罪，乙定非法拘禁罪。

* **模型四：撕票**

    * 甲叫乙来一起杀人，乙不可能构成绑架罪共犯——杀人行为不可能成为绑架罪的实行行为。

    * 甲、乙构成故意杀人罪的共同犯罪；对甲最终定绑架罪（绑架 + 杀人 = 绑架罪加重处罚），对乙只定杀人罪。

| 模型 | 乙的认知与行为 | 定性 |
| :--- | :--- | :--- |
| 一 | 做饭 | 不构成共犯 |
| 二 | 看押 | 构成绑架罪既遂的共犯（继续犯） |
| 三 | 被欺骗，以为在讨债 | 只在非法拘禁罪范围内共犯：甲定绑架罪，乙定非法拘禁罪 |
| 四 | 被叫来一起杀人 | 不构成绑架罪共犯，甲乙构成故意杀人罪共犯 |

* > **提示**：模型三与模型四特别爱考——模型三里蕴含"为索取债务非法扣押、拘禁他人定非法拘禁罪"，模型四里蕴含"绑架 + 杀人 = 绑架罪加重处罚"。

## 拐卖类犯罪

### 出卖目的这条主线

* 三个罪名：拐卖妇女儿童罪、收买被拐卖的妇女儿童罪、拐骗儿童罪；其中最重要的是第一个。

* **保护法益与定义**

    * > **定义**：拐卖妇女、儿童罪的保护法益是妇女儿童的人身自由；带着出卖目的实施绑架、贩卖、收买、拐骗等行为的，构成该罪。

    * 成年妇女同意被拐卖：多数说不构成（成年人放弃人身自由的承诺有效）；少数说构成（仍把妇女作为商品出卖）。

* > **易错点**：绑架、贩卖、收买、拐骗四种行为能统合进同一个罪名，靠的全是主观上的"出卖目的"。同样一个行为带着什么目的就定什么罪，这就是**行为与目的同时存在原则**。

* **行为与目的同时存在原则（贯穿多处）**

    * > **定义**：客观行为相同的时候，定什么罪、什么性质，关键看带着什么目的；主观心理一律以行为时判断。

    * 用在拐卖类定罪（收买/拐骗是否带出卖目的）、用在非法拘禁第 1 句与第 2 句的区分（暴力目的是拘禁还是教训）、用在绑架罪与非法拘禁罪的界限（有无向第三人要钱的目的）。

### 绑架型：以控制到手为既遂点

```text
  绑架型拐卖罪                    绑架罪
  ──────────────                ──────────────
  行为一：实力控制妇女儿童        行为一：实力控制被害人
            |                              |
  目的二：出卖目的                目的二：向被害人家属要钱
            |                              |
   出卖行为：虚线，不要求实施      （无后续行为要求）
            |                              |
   绑到手 → 罪即既遂              绑到手 → 罪即既遂
```

* 两个罪都搭在"行为一 + 目的二"上，缺任何一个都不成立；区别全在目的二填的是什么，以及"出卖行为"是虚线——可选、不要求实施。

* 带着出卖目的把孩子绑架到手后怎么都卖不出去，拐卖儿童罪仍然既遂。

* 区分绑架还是绑架型拐卖：看目的二——带着向其家人要钱的目的，绑到手即绑架罪既遂；带着出卖的目的，绑到手即拐卖儿童罪既遂。

### 贩卖型：以卖掉为既遂点

* 贩卖就是出卖；出卖要成为实行行为，前提是**不存在绑架行为**。

* 捡到弃婴后产生出卖目的——捡弃婴本身无罪，不是绑到手、不是拐到手，所以出卖行为就成为实行行为；卖掉才既遂，卖不出去就是未遂。

* > **易错点**：同一罪名的两种行为型，既遂点完全不同——绑架型看"控制到手"，贩卖型看"卖掉"，而前提是先确定实行行为落在哪一型。

* **贩卖与送养的界限**

    * 判断关键：这笔钱能不能评价成把孩子作为商品出卖的一个对价。

    * 司法解释没有给指导价，只能参照当地拐卖妇女儿童的非法行情价。

    * 生育困难家庭送出孩子并收受 2000 元"感谢费""营养费"，达不到当地非法行情价，按不合规送养处理，不定拐卖儿童罪；若一下收受十万、八万，就基本是交易，构成拐卖儿童罪。

### 收买型与拐骗型：自己养还是卖掉

* 收买时带着自己养的目的，买到手后定**收买被拐卖的妇女儿童罪**；收买时带着高价卖出赚差价的目的，成为中间商，定**收买型拐卖儿童罪**。

* 拐骗时想自己养，拐到手即既遂，定**拐骗儿童罪**；拐骗时带着出卖目的，定**拐骗型拐卖儿童罪**。

### 法定刑升格的两个入口

* **拐卖 + 强奸 = 拐卖罪加重处罚**

    * 把妇女拐到手后再实施强奸，本应两罪并罚，现在只定拐卖罪然后加重处罚——注意这是两个行为。

* **拐卖罪致人重伤、死亡**

    * 结果加重犯，原理与强奸罪致人重伤、死亡一致；为实力控制而制服被害人时致其重伤的，拐卖罪既遂的同时定拐卖罪（致人重伤）。

### 收买被拐卖的妇女儿童罪

* 与收买型拐卖罪的区别只在主观目的：没有出卖目的而是想着自己养，才定本罪；既遂是买到手。

* > **结论**：法条规定犯一个收买罪后再犯其他罪，原则上一律数罪并罚。收买妇女后强行与之性交，定收买被拐卖妇女罪 + 强奸罪，两罪并罚——不是牵连，也不是吸收。

* > **注意**：实务中常常强奸罪不判、只定收买罪，导致本罪量刑过轻；解决办法不是修改法条，而是把现有法条与数罪并罚的规定用到位。

### 一个行为、六种目的

* 同一个行为（如实力控制、绑架、劫持一名妇女）：

| 主观目的 | 定罪 |
| :--- | :--- |
| 只带着拘禁的目的 | 非法拘禁罪 |
| 带着奸淫目的 | 强奸罪 |
| 带着向本人要钱的目的 | 抢劫罪 |
| 带着向其家人的要钱的目的 | 绑架罪 |
| 带着出卖他的目的 | 拐卖妇女罪 |
| 没有出卖目的，且对方是儿童 | 拐骗儿童罪 |

* > **结论**：客观题的选项基本就是考罪名区分，而区分点在**主观目的**而不是客观要件；主观目的是一种心理活动，只能通过阅读题干信息加以推定、萃取。

### 继续犯里的承继共犯

* **继续犯范围**

    * 非法拘禁罪、绑架罪、绑架型拐卖罪、拐骗儿童罪都是继续犯。

* **明知是拐来的还接着养**

    * 拐骗者隐瞒真相说孩子是捡来的，妻子已经猜出是丈夫拐来的仍继续养——妻子是拐骗儿童罪承继的、继续的、片面的共同犯罪（片面即行为人单方明知而行为人对此并不知情）。

* **医生和警察入罪，校长出罪**

    * 三类人：开假出生证明的医院院长、上假户口的派出所警察、办入学手续的小学校长。

    * 医生和校长不构成承继共犯——医生出假出生证明、假户口，导致孩子进一步脱离父母的监护；校长让孩子上学，不管孩子是否被拐，孩子到哪都得上学，是保护孩子的利益，不算犯罪行为。

    * > **易错点**：承继共犯认不认，不看这行为"像不像"在帮孩子，而看它是不是在进一步巩固侵害——分水岭是保护了孩子，还是让拐骗更难被追溯。

* **立法论上的评价**

    * 拐卖儿童罪法定刑有死刑，拐骗儿童罪法定最高刑只有 5 年，这是不合理的。

    * 定法定刑不能只从犯罪人角度（想赚钱还是想自己养）考虑，还要从被害人受侵害的程度考虑——拐卖与拐骗的被害人所受伤害没有区别。

## 侵犯名誉、人身权与婚姻家庭

### 侮辱罪与诽谤罪

* > **定义**：名誉就是社会评价。

* **第一道分水岭：事实能不能是真的**

    * 诽谤罪的事实必须是**虚假事实**；侮辱罪的事实可以虚假，也可以真实。

    * 侮辱的高发场景是把真实隐私公之于众（把前任裸照打印出来从村头挂到村尾），侵犯了名誉，构成侮辱罪，同时构成传播淫秽物品罪，两罪想象竞合。

    * 诽谤的高发场景是网络谣言满天飞，网络诽谤是主要形式——虚假事实就是"谣言"。

    * > **易错点**：定诽谤罪之前先问一句，手里那个"事实"是真的还是假的；是真的，就往侮辱罪那边靠。

* **第二道分水岭：一定要"公然"**

    * 一对一通话不具备公然性——打电话给客服说"你这么说话，话费能能不费吗"，侮辱性极强但不公然。

    * 把 WiFi 名称设为"1601 全家都是傻叉"，全楼搜 WiFi 列表都会看到，具有公然性；情节一般不严重，情节严重的可以构成侮辱罪。

    * > **结论**：判断口径是一对一、私下不行；凡是能让不特定或多数人感知的展示方式，就有公然性。

* **入罪门槛与追诉方式**

    * 都要求情节严重；情节不严重就是民事侵权或治安管理处罚。

    * 都是**告诉才处理**的犯罪，但严重危害社会秩序、损害国家利益的可以公诉。

### 诬告陷害罪

* **与诽谤罪的区别**

    * 除虚假事实外，还要求这个虚假事实是**虚假的犯罪事实**——意图让人受刑事追究。

    * 谎称他人卖淫嫖娼不构罪（卖淫嫖娼只是违法行为）；谎称他人介绍卖淫则构成诬告陷害罪（介绍卖淫是犯罪）。

* **实行行为与既遂标准**

    * 实行行为是**告发**（向公安等司法机关告发），告发才是着手；编造虚假材料、捏造事实只是**预备行为**。

    * > **结论**：既遂标准是**司法机关收到诬告材料，并且足以引起司法机关的调查活动**。

    ```text
  捏造事实、编造虚假材料
         │  ← 预备行为，不是实行行为
         ▼
 向公安等司法机关告发        ← 着手实行行为
         ▼
 ┌────────────────────────────────────────┐
 │  司法机关收到诬告材料                  │
 │  且足以引起司法机关的调查活动          │  ← 既遂，到此为止
 └────────────────────────────────────────┘
         ▼
   以下都不是既遂标准
   · 司法机关实际启动了调查
   · 被诬告人被冤枉、被判刑入狱
    ```

    * > **注意**：若以"被诬告人真的被冤枉坐牢"为既遂标准就太晚了——诬告很少成功，那样打击太迟。

### 刑讯逼供罪：什么才算变相肉刑

* 刑讯指使用**肉刑或变相肉刑**，变相肉刑即酷刑。

* 在审讯室播放一晚上《爸爸的爸爸叫爷爷》这类歌曲，可能是一种精神折磨、可能算变相肉刑；放一晚上重金属、摇滚让人睡不着，也可能算酷刑。

    * > **结论**：变不变成肉刑，关键不看放什么内容，看的是有没有达到精神上的持续折磨、剥夺休息；放在刑法里还要叠加"情节严重"才构罪。

### 刑讯逼供、暴力取证、虐待被监管人：三罪两条线

* 第一个特征：都是**身份犯**。

* 第二个特征：都有**法律拟制**——实施这三个罪过失致人死亡的，都拟制为故意杀人罪。

| 罪名 | 定罪身份 | 过失致人死亡时 |
| :--- | :--- | :--- |
| 刑讯逼供罪 | 司法工作人员 | 法律拟制为故意杀人罪 |
| 暴力取证罪 | 司法工作人员 | 法律拟制为故意杀人罪 |
| 虐待被监管人罪 | 监管人员 | 法律拟制为故意杀人罪 |

### 重婚罪

* > **结论**：同时拥有两份婚姻，其中**一份必须是法律婚姻**，才构成重婚罪。

* 两种行为方式：法律婚姻 + 事实婚姻；法律婚姻 + 法律婚姻。

* > **注意**：民法不承认事实婚姻是不承认其**民事法律效力**；刑法承认的是这个**现象存在**——你这种不好的现象存在，而且破坏了他人合法婚姻。

### 破坏军婚罪

* 和军人配偶搞法律婚、搞事实婚、搞同居都构成破坏军婚罪；搞通奸不算。

* **一条逐级叠加条件的阶梯**

    ```text
  一夜情
    │  + 其中一方有配偶
    ▼
   通奸
    │  + 共同生活（已经是过日子了）
    ▼
   同居
    │  + 公开同居
    │  + 对外以夫妻名义相称，使周围群众以为是夫妻
    ▼
 事实婚姻
    │  + 办理结婚登记
    ▼
  法律婚姻
    ```

    * > **结论**：重婚罪里的"事实婚姻"停在倒数第二层，破坏军婚罪里的"同居"停在第三层。

| 罪名 | 覆盖的形态 | 不包括 |
| :--- | :--- | :--- |
| 重婚罪 | 法律婚姻 + 事实婚姻；法律婚姻 + 法律婚姻 | —— |
| 破坏军婚罪 | 与军人配偶的法律婚、事实婚姻、同居 | 通奸 |

* > **注意**：我国早已废除通奸罪，通奸目前只能算违反道德的行为，可以道德上谴责但尚未法定罪。

* 罪名存废的证据：通奸要求发生性行为，只拍到两人光着身子躺在床上、在学英语聊天，证不出关键那一步，认定太难，于是废除。

### 暴力干涉婚姻自由罪

* 以暴力方法干涉他人结婚、离婚自由，如法海暴力干涉白娘子和许仙的婚姻。

* > **注意**：暴力干涉婚姻自由罪致人死亡，**能包括被害人的自杀**。

### 虐待罪

* **家庭成员要扩大解释**

    * 虐待罪的行为主体法条明确规定是家庭成员，这跟遗弃罪不同（遗弃罪没说家庭成员，主体不限于家庭成员）。

    * "家庭成员"要扩大解释，不限于亲属关系：常年当保姆、当管家的丫鬟、老管家都算（已形成长期稳定的共同生活关系）。

    * 男女朋友长期同居、共同生活，即使没领证，也视为家庭成员。

* **结果加重犯：致人死亡包括被害人自杀**

    * > **结论**：虐待罪致人死亡**包括被害人自杀**；加深犯中致人死亡包括被害人自杀的只有两个——虐待罪致人死亡、暴力干涉婚姻自由罪致人死亡。

    * 男朋友长期辱骂、精神折磨女友致其抑郁自杀：主体扩大解释成立、致人死亡含自杀，成立虐待罪并属致人死亡的加重处罚。

* **立法论上的不满**

    * 拐卖儿童罪法定最高刑是死刑，拐骗儿童罪只有 5 年，从被害人受侵害的程度看两者没有区别，法定刑应当提高。

### 虐待被看护人罪

* 条文写的是"虐待被监护人罪"，课件和教材里也常写成"虐待被看护人罪"，一个罪名、两种叫法。

* 设立缘起：幼儿园阿姨把小朋友两个耳朵拎起来旋转、扔进垃圾桶一类案件，定不了虐待罪（非家庭成员、未共同生活），也定不了故意伤害罪（伤情未达轻伤），定寻衅滋事罪又不合适，故补设本罪——小朋友即被看护人。
