# 罪数判断：一个行为与两个行为

## 判断起点

    * **罪数**

        * > **定义**：犯罪成立之后要解决的第三个问题，即数量上的计算问题，与犯罪形态、两大正犯与两大共犯并列。

        * 罪数是做题的第一步，第一步只做一件事：判断犯罪的是一个行为还是两个行为，判断完再把相应概念一个一个处理下去。

        * 法考刑法不用传统的（法硕那套）罪数概念体系，只把其中具有可靠性的东西提炼出来讲；学过传统理论体系的人必须自己再把概念切换过来，否则反而是负资产。

        * 犯罪论的两个板块：一是"如何定罪"，核心是两阶层犯罪构成体系；二是犯罪成立之后解决三大问题——犯罪形态（时间上的发展）、两大正犯与两大共犯、罪数（数量上的计算）。

## 罪名关系的三种逻辑类型

    * **A 与非 A：对立排斥关系**

        * 比喻：男生与女生，二者只能取其一。

        * 罪名对应：盗窃罪 vs 诈骗罪。

        * 前提是一个行为针对一个对象，此时不可能同时构成两个罪，既不是法条竞合也不是想象竞合。

        * 典型：甲到商场柜台欺骗柜台员"回头看看那边有个帅哥"，柜台员一回头，甲趁机拿走柜台上的珠宝；甲这个欺骗行为要么构成诈骗罪，要么构成盗窃罪，案件最终定盗窃罪。

        * > **提示**：前提只限于一个行为针对一个对象；一个行为若针对两个被害人、两个对象，对甲对象可能构成盗窃罪、对乙对象构成诈骗罪，这两个罪仍可能想象竞合。

    * **A 与 A+B：包容评价关系**

        * 比喻：本科生与硕士生，本科生也可以读硕士。

        * 罪名对应：合同诈骗罪 vs 诈骗罪；故意杀人罪 vs 故意伤害罪；盗窃枪支罪 vs 盗窃罪；抢劫罪 vs 抢夺罪。

        * 结论：触犯 A+B 必然触犯 A，故为法条竞合，特殊法优于一般法，优先定 A+B。

        * A 是一般条文、一般罪名，B 是特殊因子、特殊因素，A+B 是特殊条文、特殊罪名。

        * 常见考法是对象错误：甲想偷普通财物实际偷到枪，盗窃枪支罪可以包容评价为盗窃罪，甲在盗窃罪范围内主观一致，定盗窃罪既遂。

    * **A 与 B：中立关系**

        * 比喻：一个男生同时也可以是硕士生，两种身份并不冲突。

        * 罪名对应：盗窃罪 vs 杀人罪；抢劫罪 vs 强迫交易罪。

        * 结论：没有必然触犯关系，不可能是法条竞合；但一个行为可以同时触犯，成立想象竞合，择一重罪论处。

    * **三类关系的分野**

        | 关系类型 | 比喻 | 罪名对应 | 结论 |
        | :--- | :--- | :--- | :--- |
        | A 与非 A | 男生与女生 | 盗窃罪 vs 诈骗罪 | 一个行为针对一个对象时二者只能取其一，既非法条竞合也非想象竞合 |
        | A 与 A+B | 本科生与硕士生 | 合同诈骗罪 vs 诈骗罪；故意杀人罪 vs 故意伤害罪；盗窃枪支罪 vs 盗窃罪；抢劫罪 vs 抢夺罪 | 触犯 A+B 必然触犯 A，即法条竞合，特殊法优于一般法，优先定 A+B |
        | A 与 B | 男生与硕士生 | 盗窃罪 vs 杀人罪；抢劫罪 vs 强迫交易罪 | 无必然触犯关系，不可能是法条竞合；一个行为可同时触犯，成立想象竞合，择一重罪论处 |

## 法条竞合与想象竞合

    * **区分标准：有无必然性**

        * > **定义**：触犯此罪如果必然触犯彼罪，两个罪就是法条竞合关系；如果没有这种必然性，就不是法条竞合，但有可能想象竞合。

        * 例：触犯合同诈骗罪必然触犯诈骗罪，两罪是法条竞合，处理上特殊法优于一般法，优先认定合同诈骗罪。

        * 触犯此罪不必然触犯彼罪时，两罪不是法条竞合；是否有想象竞合，要看能不能用一个行为把它们同时触犯。

        * 盗窃罪与杀人罪之间没有任何方向的必然触犯关系，不是法条竞合；但一个行为可以同时触犯，例如盗窃他人的救命药明知对方可能因此丧命仍窃走，一个盗窃行为同时构成盗窃罪与故意杀人罪（故意至少是间接故意），成立想象竞合。

    * **竞合关系判断与处理流程**

            ```text
            【竞合关系判断与处理流程】

                                        两罪同时触犯
                                              │
                                              ▼
                                 触犯此罪，必然触犯彼罪吗？
                                              │
                              ┌──────────────────────────────┴──────────┐
                              是                                    否
                              │                                     │
                              ▼                                     ▼
                        ┌───────────┐           一个行为能同时触犯吗？
                        │ 法条竞合  │                      │
                        │ A 与 A+B  │           ┌──────────┴──────────┐
                        └─────┬─────┘           是                    否
                              │                 │                     │
                              ▼                 ▼                     ▼
                                        ┌───────────┐         ┌───────────┐
                                        │  想象竞合  │         │  只能择一  │
                                        │   A 与 B  │         │  A 与非A  │
                                        └─────┬─────┘         └───────────┘
                                              │
                              └───────────────┘
                                              │
                                              ▼
                    特殊法优于一般法 → 定 A+B（特殊罪名）
                                              │
               若按 A+B 定罪量刑不能罪刑相适应、反而便宜了犯罪人
                                              ▼
                     临时调整为想象竞合 → 择一重罪 / 则以重刑论处
            ```

## 竞合关系的处理规则

    * **共同原理：哪个重定哪个**

        * 法条竞合的规则是特殊法优于一般法、特殊罪名优于一般罪名，即定 A+B 这个罪名；之所以定 A+B，是因为 A+B 比 A 多侵犯了一个 B 法益，法益侵害程度更重，法定刑通常更重，这样才能罪刑相适应。

        * 想象竞合的规则是择一重罪论处，同样是哪个重定哪个。

        * 两套规则的实质原理一致：既然两个罪都触犯，就要找一个更重的来定。

    * **法条竞合让位给想象竞合**

        * > **定义**：法条竞合的两个罪名按理应按特殊罪名优于一般罪名处理，但若按特殊罪名定罪量刑做不到罪刑相适应、反而便宜了犯罪人，就把法条竞合临时、动态地调整为想象竞合，择一重罪（或则以重刑）论处。

        * 触发条件主要是法条竞合的两个罪名犯罪形态不一致时，例如一个中止、一个既遂。

        * 甲要杀乙，乙已被打成重伤，甲自动放弃把人救活，构成故意杀人罪的犯罪中止，同时不可否认也构成故意伤害罪重伤的既遂；杀人罪中止可能判得更轻，伤害罪既遂可能判得更重，若仍按特殊罪名定杀人罪就罪刑相适应不上。

        * 这种情形下两个罪名符合想象竞合的构成（法条竞合同样是一个行为触犯两个罪名），所以按想象竞合处理。

## 逻辑关系误用

    * **考试最爱挖的坑**

        * 考试最喜欢考的是把某一种逻辑关系误认为另一种逻辑关系，即逻辑关系的误用。

        * 最常见的是把本属 A 与 B 的中立关系弄成 A 与非 A 的对立排斥关系。

        * 生活中的例子：营业员问顾客"你是打包还是带走"，被打愣的是顾客，因为打包和堂食才是 A 与非 A 的择一关系；考研与考法考，就时间角度讲两场考试不冲突可以并存，只有从个人能力角度讲才是对立排斥关系。

    * **沙滩夜市的乐队**

        * 案情：乐队强行到游客桌前唱，唱完要求付钱，不给便动手打人，游客是外地客不敢不给，事后报警。

        * 法官的推理：区分抢劫罪与强迫交易罪的标准是——抢劫罪是纯粹的、单纯的财产犯罪，强迫交易罪发生在市场交易背景下、扰乱市场秩序；关键看案件有没有发生在市场交易背景下；查明系发生在卖唱行业的市场交易背景下，于是定强迫交易罪。

        * > **易错点** ⚠️ 错在大前提：法官把抢劫罪与强迫交易罪理解成 A 与非 A 的对立排斥、择一关系，而两罪实际是 A 与 B 的中立关系。

        * 完整的案件事实要想象成一个多面体，既要照出"财产犯罪"这个面（对人实施暴力、取财目的，符合抢劫罪），也要照出"市场秩序"这个面（有扰乱市场秩序、强迫交易，符合强迫交易罪）。

            ```text
                         案件事实：把它想象成一个多面体
                                        │
                        ┌───────────────┴──────────────────┐
                        ▼                                  ▼
                财产犯罪这个面                      市场秩序这个面
                对人实施暴力                        有没有扰乱市场秩序
                取财目的                            有没有强迫交易
                        │                                  │
                        ▼                                  ▼
                符合罪名一：抢劫罪                  符合罪名二：强迫交易罪
                        └───────────────┬──────────────────┘
                       两个罪名是 A 与 B 的中立关系，不是择一关系
                                        │
                                        ▼
                        两罪可以同时构成 → 想象竞合，择一重罪论处
                                        │
                                        ▼
                        抢劫罪是重罪，强迫交易罪是轻罪 → 定抢劫罪
            ```

        * 正确结论是既构成抢劫罪又构成强迫交易罪，择一重罪论处，抢劫罪更重所以定抢劫罪；只按轻罪处理等于告诉所有抢劫犯先唱首歌就永远不构成抢劫罪。

        * 要少一点对立思维、多一点中立思维，否则定罪就会出现障碍。

## 继续犯

    * **继续犯（持续犯）**

        * 法考不考名词解释，只要配一个标准案例或罪名即可，典型的继续犯是非法拘禁罪。

        * 最大的卖点是既遂之后加入还能成为共犯，这是继续犯唯一能事后接盘的共犯情形。

        * 一般犯罪既遂之后再参与进来的，不可能构成前面那个罪的既遂共犯，最多构成妨害司法类的犯罪：狗蛋已抢走小芳的包构成抢劫罪既遂，铁牛此时参与"我帮你"，只能构成妨害司法类犯罪。

        * 继续犯破了例：狗蛋已把小芳非法拘禁三天三夜、非法拘禁罪早已既遂，铁牛此时加入说"我继续帮你看押、继续帮你拘禁"，仍能构成已经既遂的狗蛋非法拘禁罪的共犯。

        * 常考的继续犯罪名：非法拘禁罪（拘禁行为本身在持续）、绑架罪（核心行为也是拘禁、劫持行为）、重婚罪（事实上持续存在的婚姻状态）。

    * **重婚罪的继续犯**

        * 案情：狗蛋发现妻子小芳跟狗剩以事实夫妻身份生活，自己上门被轰出来，露宿街头盘缠用尽后请求"入伙"，狗剩与小芳都没有意见，三人开始共同生活；狗剩明知小芳已婚仍与之同居，三人已构成重婚罪。

        * 狗蛋不能构成重婚罪的承继共同犯罪，因为他是合法丈夫、正房先生，不可能与狗剩构成重婚。

        * 铁牛"带资进组"加入后情况不同：狗剩与小芳仍构成重婚罪，铁牛也构成重婚罪承继的共同犯罪。

## 加重犯

    * **三类加重犯**

        * 结果加重犯：故意伤害致人死亡，抢劫致人重伤、死亡等。

        * 情节加重犯：最典型的是入户抢劫，基本犯是抢劫罪，一旦入户即加重处罚到十年以上直至死刑。

        * 数额加重犯：在盗窃罪中大量遇到，如盗窃数额较大的财物为基本犯、盗窃数额特别巨大的财物为数额加重犯。

        * 结果加重犯与情节加重犯都是一个行为，所以加重犯被归入"一个行为"这一节。

    * **入户抢劫的重心**

        * "入户抢劫"这一表述的重心容易被误放在"抢劫"上；评价情节加重犯时加重部分是入户，与普通抢劫相比多出的正是非法入户这个 B 因子，抢劫只是基本犯。

        * 把表述换成"为抢劫而入户"就清晰了：入户抢劫加重处罚，是因为抢劫的方式升级为为抢劫而非法侵入住宅。

        * 狗蛋带着抢劫目的破门而入、打倒小芳、抢走财物，就抢劫罪而言是既遂，入户抢劫这个情节加重犯也既成立也既遂。

    * **形态一失衡即改按想象竞合**

        * 基本犯是 A、情节加重犯是 A+B，触犯入户抢劫必然触犯抢劫，两者是法条竞合关系，正常处理是特殊法优于一般法、优先定情节加重犯（入户抢劫，十年以上至死刑）。

        * 但基本犯与情节加重犯的犯罪形态可能不一致，此时若仍按情节加重犯定罪会罪刑相适应不上，就要调整为想象竞合择一重。

        * 例：狗蛋撞开小方家门冲进去，发现小芳架着加特林对着自己胸口，自己手里只有破菜刀，只好举手投降；基本犯抢劫罪是未遂（未进入实行阶段的既遂要素），而入户抢劫因已入户成立既遂，情节加重犯更重，定它即可。

        * 若出现情节加重犯是中止而基本犯是既遂，就必须想象竞合择一重。

        * 例：狗蛋想盗窃珠宝店价值 50 万的珠宝，伸手进柜台误拿了旁边 5000 元的那枚，拿回家才发现拿错；对眼前 5000 元珠宝偷到手，基本犯既遂；对 50 万珠宝虽未拿到手但有偷到手的可能性、已制造紧迫危险，属加重犯的未遂。

        * 这是对象错误而非打击错误，但因盗窃故意明显，形态分析优先；这一块存在观点分歧，按法考司法解释的正常原理处理。

        * 两罪罪名相同，所以只能"择一重刑论处"，不能叫"择一重罪论处"。

            ```text
            狗蛋伸手进柜台抓珠宝（一个行为）

              目标认定                行为结果         犯罪形态
              ───────────────────────────────────────────────────
              眼前这枚 5000 元  ───►  偷拿到了     ──►  基本犯（数额较大）既遂
              旁边那枚 50 万    ───►  没拿走       ──►  加重犯（数额特别巨大）未遂
                                    │
                                    ▼
                      两罪是 A 与 A+B → 法条竞合
                                    │
                                    ▼
                  特殊法优于一般法 → 必须定加重犯（未遂）
                                    │
                             ✗ 但未遂判得轻，基本犯既遂判得重
                             ✗ 罪刑相适应不上
                                    │
                                    ▼
                    临时调整为想象竞合 → 择一重刑论处
                    （罪名都是盗窃罪，所以只能"择一重刑"，
                      不能叫"择一重罪"）
            ```

        * 书上直接按入户抢劫升格并不矛盾：择一重时情节加重犯是既遂、重于基本犯未遂，就按入户抢劫既遂适用升格法定刑，再考虑基本犯那一部分是未遂，按未遂的规定从宽一点。

## 结合犯

    * **结合犯**

        * > **定义**：本来应当数罪并罚的，由法律特别规定只定一个罪并加重处罚的情况。

        * 例：狗蛋以暴力拐卖小芳，拐卖妇女罪已经既遂（以出卖为目的把妇女拐到手即终局，不要求卖出去），随后又强奸小芳；两个前后独立的行为、两个罪，按正常原理应当并罚，但法律特殊规定只定拐卖罪一个，把强奸作为拐卖罪的加重处罚情节、法定刑升格条件。

        * 名称来自日本，传统理论不太用这个概念，法考刑法用；叫"吞并犯"更贴切——A 罪把 B 罪吞并了，B 罪成了 A 罪的加重处罚情节。

        * 不用"吸收"二字是因为后面还有一个吸收犯概念。

        * > **提示**：结合犯是法律的特殊规定，不是正常办事；正常原理应当并罚。

        * 结合犯涉及的罪刑条款：拐卖罪 + 强奸罪（定拐卖罪加重处罚）、绑架罪 + 杀人罪（定绑架罪加重处罚）、绑架罪 + 故意伤害罪致人重伤、死亡（定绑架罪加重处罚）。

    * **结合犯与结果加重犯的分野**

        * 二者都是定拐卖罪、都加重处罚，处理结果一模一样，极易混淆。

        * 区别只有一句话：行为是一个还是两个。

        * 最好的切入点是回归"原生态"：结合犯是两个行为，回归原生态是两罪并罚；结果加重犯是一个行为，回归原生态是想象竞合、一重罪论处。

        * 结果加重犯的"一个行为"由来：狗蛋为拐卖小芳实施暴力，小芳反抗，他为压制反抗把小芳打成重伤后控制住并拐到手。暴力重伤行为与控制行为从自然事实角度确实是两个行为，但暴力重伤的目的就是拐卖妇女，暴力重伤行为本身就是拐卖罪的实行行为，整个控制也是，整个只实施了一个拐卖罪的实行行为。

        * 回归原生态：若无法条特殊规定，一个暴力行为一方面构成故意伤害罪（重伤）、一方面构成拐卖妇女罪，想象竞合一重罪论处。

        * 情节加重犯的"一个行为"回归原生态同样是想象竞合。

            | | 结合犯 | 结果加重犯（含情节加重犯） |
            | :--- | :--- | :--- |
            | 法条表述 | 犯拐卖罪又犯强奸罪，加重处罚 | 犯拐卖罪致人重伤、死亡，加重处罚 |
            | 行为个数 | 两个独立行为 | 一个行为 |
            | 罪数评价 | 两个行为、两个罪 | 拐卖妇女罪致人重伤死亡 |
            | 回归"原生态" | 两罪并罚 | 想象竞合犯，一重罪论处 |

## 行为数量的两个角度

    * **自然事实角度与法律评价角度**

        * 行为数量的判断不能停留在自然事实角度，一定要从法律评价角度数；自然事实角度看有许多是数不清的多算。

        * 法律评价角度看什么？看带着什么目的去实施这个行为。

        * 入户抢劫从法律评价上是一个行为：带着抢劫目的入户，入户本身即抢劫罪行为的一部分，所以入户加抢劫整体是一个抢劫行为；入侵户抢劫定一个罪、适用情节加重犯加重处罚。

        * 对照案例：狗蛋入户时只想非法侵入住宅、骚扰小芳，并没有带取财目的，进去发现小芳家有钱才临时产生取财目的并使用暴力抢钱；这时非法入户不能视为抢劫罪的行为，真正是两个行为——非法侵入住宅罪与抢劫罪，两罪并罚，不能按入户抢劫处理。

        * > **易错点**：⚠️ 入户抢劫定一个罪，非法入户之后再抢劫定两个罪，分野只在入户时有没有取财目的。

        * 补充：司法解释对入户抢劫的"入户目的"并没有限于必须带取财目的，带杀人目的、强奸目的也算；但按正常原理，只是带着非法入户目的入户而没带取财目的的，就是两个行为，不算入户抢劫。

        * 鲁智深拳打镇关西打了三拳，不能说是三个行为、三个故意伤害罪连续犯；从法律评价看，这三拳整体是一个伤害行为。

## 连续犯

    * **连续犯**

        * > **定义**：同样一种行为连续实施。处理规则按法考刑法讲，与传统理论、法硕刑法不一样。

        * 法考刑法的规则是两条原理加一个法律特殊规定。

    * **两条原理**

        * 第一条：罪名保护法益不具有人身专属性、具有可替代性时，定一个罪，不需要数罪并罚，如多次走私定一个走私罪并累加数额、多次受贿只定一个受贿罪并累加金额。

        * 第二条：罪名保护法益具有人身专属性时，原则上应当数罪并罚，这是法考刑法的多数说；如连续杀人，杀六个人就是六个故意杀人罪数罪并罚，因为生命法益不可替代，账要一笔一笔算。

        * 少数说认为连续杀人只定一个故意杀人罪加重处罚，但这在法考界只能算少数。

    * **法律特殊规定**

        * 把"多次"作为犯罪成立条件，多次实施就按一个罪处理：多次盗窃、多次抢夺、多次敲诈勒索。其中考得最多的是多次盗窃，且涉及数额问题。

        * 把"多次"作为法定刑升格条件，多次实施定一个罪但加重处罚：多次抢劫、多次强奸。

        * 多次强奸是特殊例子：若无此规定，按原理连续强奸六个女生因强奸罪保护人身法益具有专属性、不可替代性，应数罪并罚；但法条已规定定一个强奸罪加重处罚，就按特殊规定办。

        * 记忆要点是分清什么是原理、什么是特殊规定（例外），两条原理加上特殊规定就够了。

## 吸收犯

    * **吸收犯**

        * > **定义**：有两个独立的行为，最终一个把另一个吸收，只定一个罪。

        * 条件是能做到不遗漏评价、不遗漏处罚；做不到就不能吸收，只能老老实实两罪并罚。

        * 不作为也是一种行为方式，不要把不作为不当行为；所以盗掘古墓葬（积极作为）与不救人是两个行为。

    * **两个对照案例**

        * 盗掘古墓案不能吸收：狗蛋盗掘古墓葬把炕挖塌，小两口掉下去被土埋，他见人未死却不救，抱着文物跑路，构成盗掘古墓葬罪（保护文物法益）与不作为的故意杀人罪（保护活人生命法益）。两个法益性质完全不同，吸收不了，硬定一个杀人罪就遗漏了文物法益的侵害事实，故两罪并罚。

        * 猎人打伤人不救可以吸收：狗蛋打猎把野鸡挂在枪上扛着走过繁华街市，野鸡扑棱碰动扳机，子弹击中路人打成重伤（野鸡是他绑着的、子弹没退、还扛枪招摇过市，属疏忽大意的过失，构成过失致人重伤罪）；面对重伤者有救助义务而不救致其死亡，构成不作为的故意杀人罪。生命法益与身体健康法益不是性质不同的法益，而是性质相同、程度不同的未济关系，故重罪可以吸收轻罪，只定不作为的故意杀人罪。

        * > **结论**：只有性质相同、程度不同的重罪才能吸收轻罪；法益性质完全不同的两个独立行为、两个罪，老老实实并罚。

## 不可罚的事后行为

    * **不可罚的事后行为**

        * 属于吸收犯的一种情形，因重要而单列。

        * 销赃要不要另定掩饰、隐瞒犯罪所得罪（以前叫销赃罪），两种销赃必须分清。

        * 第一种拿到赃物市场上去卖：买的人就是来买赃物的，大家心照不宣，不具有期待可能性，也没有侵犯新的法益，只定盗窃罪。

        * 第二种拿到合法的二手市场上去卖：向不知情的普通买家伪装成"这是我的表，我现在不想戴了想换新的"，对方花正常价买到权利有瑕疵的财物而有财产损失，构成诈骗罪，且侵犯了新的法益，两罪并罚。

            ```text
              销赃方式 A：赃物市场低价卖
                → 对象是赃物流通的知情人，无期待可能性
                → 无独立法益侵害
                → 不可罚的事后行为：只定 盗窃罪

              销赃方式 B：合法二手市场伪装成自己的表卖
                → 欺骗不知情的普通买家，财产法益受新侵害
                → 定 盗窃罪 ＋ 诈骗罪，两罪并罚
            ```

        * > **易错点**：⚠️ 不可罚的事后行为特别喜欢考销赃，两种销赃一定要分开记。

## 牵连犯

    * **牵连犯**

        * > **定义**：有两个独立的行为、两个独立的罪，二者存在手段与目的的关系且这种关系在犯罪手法上具有通常性，因而择一重罪论处。

        * 例（《猫鼠游戏》）：先伪造支票，再用伪造的支票实施诈骗，伪造支票在我国定伪造、变造金融票证罪，用该支票诈骗定票据诈骗罪；按正常原理应并罚，但伪造是手段行为、诈骗是目的行为，且先伪造再诈骗是诈骗犯的常见手法，故择一重罪论处。

        * 第一个条件是有牵连关系，即手段与目的的关系，有时候也是原因与结果的关系。

        * 第二个条件是这个关系在犯罪手法上要具有通常性，即手段行为与目的行为是犯罪分子的常见手法、常发常伴随的关系；这个标准比较模糊。

        * 反例：狗蛋为杀小芳先到军营偷一把加特林机枪再开枪打死她，手段行为是盗窃枪支罪、目的行为是故意杀人罪，手段与目的的牵连关系是临时结成的，杀手杀人一般不会先去军营偷枪，不具有通常性，不能认定为牵连犯，按正常原理两罪并罚。

        * > **结论**：常见的择一重，不常见的并罚。

## 罪数的底层原理

    * **两句话的统摄**

        * 底层原理只有两句话：禁止重复评价、禁止遗漏评价，原理掌握好了概念自己就归位。

            ```text
              罪数判断的第一步：数行为
                          │
                 ┌────────┴────────┐
               一个行为           两个行为
                 │                  │
                 ├ 继续犯            ├ 结合犯
                 ├ 法条竞合          ├ 连续犯
                 ├ 想象竞合          ├ 吸收犯
                 └ 加重犯            ├ 不可罚的事后行为
                    ├ 情节加重犯     └ 牵连犯
                    ├ 结果加重犯
                    └ 数额加重犯
                          │
             这两类都各由两句话统摄 ↓
                 ┌────────┴────────┐
              禁止重复评价       禁止遗漏评价
              （一个行为、一个    （数个行为、数个法益
               结果只能罚一次）    侵害原则上都要评价）
            ```

    * **禁止重复处罚**

        * 禁止重复处罚行为：只有一个行为时，哪怕触犯两个罪、三个罪，也只能定一个罪，不能数罪并罚。想象竞合、法条竞合、结果加重犯都属此类。

        * 结果加重犯的"一个行为"不是自然事实上的一个行为，而是法律评价上的一个行为，由目的来决定定性，这是理解难点。

        * 禁止重复处罚结果：虽有两个行为但只制造了一个结果的，对这一个结果只能处罚一次。标准案例是事前故意、也叫推迟发生——甲要杀乙，把乙打成重伤昏迷，以为乙已死亡，为毁尸灭迹把乙扔进河里淹死；按多数说死亡结果是二因一果，前行为定故意杀人罪既遂，后行为把活人当死人扔进河里定过失致人死亡罪。

        * 两罪不能并罚，因为并罚等于把一个死亡结果评价、处罚了两次；只能启动吸收犯原理，重罪吸收轻罪，最终只定一个故意杀人罪既遂。

    * **禁止遗漏处罚**

        * 原则：数个行为侵犯数个法益、触犯数个罪名的，原则上应当数罪并罚，不并罚就遗漏评价、遗漏处罚。

        * 典型真题：甲暴力抢劫乙，乙跑时钱包掉地且不自知，甲追上捡走。抢劫罪不是既遂——既遂要求因无法反抗、被迫放弃财物而由行为人"截取"到财物，因果链条完整，本案是乙遗失、甲"捡取"，因果链条断裂；行为已到实行阶段，故定抢劫罪未遂。捡走钱包定侵占罪既遂，两罪并罚。

        * 这里虽看似一个"一直跑最后捡到手"的行为，其实要切成两个：暴力抢劫是一个行为，捡取是另一个行为，两个独立的罪。

        * > **易错点**：⚠️ 不能用吸收犯把侵占罪既遂和抢劫罪未罚合并——两者犯罪形态不同，形态一致时才可以重罪吸收轻罪。

        * 只定抢劫罪未遂不行：钱包被实际拿走造成实际财产损失，未遂无法评价这一法益侵害。

        * 只定侵占罪既遂也不行：侵占罪是平和手段，无法评价暴力手段导致的人身法益侵害。

        * 所以老老实实两罪并罚：抢劫罪未遂 + 侵占罪既遂。

    * **定一个罪的例外依据**

        * 两个行为、两个罪而例外地只定一个罪，必须有依据。

        * 法条依据：如结合犯，拐卖加强奸本应两罪并罚，法条作特殊处理，改为定拐卖罪加重处罚。

        * 充分的理论根据：吸收犯——必须做到不遗漏评价、不遗漏处罚才可以吸收，做不到就两罪并罚；牵连犯也是一种理论依据，它不是法律规定，而是因为有通常性的牵连关系才择一重。

## 两阶层犯罪构成体系回顾

    * **一张最完整的货品清单**

        * 犯罪论第一个板块是"如何定罪"，核心是两阶层犯罪构成体系；犯罪成立并不要求体系里每一个零部件都打勾。

        * 客观要件有行为主体、危害行为、危害结果、因果关系；就故意杀人罪的成立而言，客观要件不要求四项全具备，只要有害害行为、主观上有杀人故意就够了。

        * "危害结果 + 因果关系"是既遂要件的要求；过失犯罪则要求有实害结果、有因果关系。

        * > **结论**：到底哪些需要打勾，由当天的"出单任务"决定——出单任务是判断故意杀人罪是否成立，行为主体、危害行为打勾加杀人故意即可；出单任务是判断是否既遂，危害结果、因果关系都得打勾；出单任务是判断是否构成过失致人死亡罪，危害结果、因果关系都要打勾，而且主观上还得是过失。

    * **做题第一步**

        * 罪数是做题第一步，先判断是一个行为还是两个行为。

        * 自然事实角度只是参考，法律评价角度是关键，看带着什么目的去实施这个行为——入户抢劫与非法入户之后再抢劫的分野即由此而来。

            ```text
              出单任务：先定罪名个数
                    │
                    ├─ 第一步：一个行为还是两个行为？
                    │     · 自然事实角度（只是参考）
                    │     · 法律评价角度（关键：看你带着什么目的）
                    │
                    ├─ 一个行为 → 继续犯 / 法条竞合 / 想象竞合
                    │            加重犯（情节、结果、数额加重）
                    │
                    └─ 两个行为 → 结合犯 / 连续犯 / 吸收犯
                                  不可罚的事后行为 / 牵连犯
                          │
                    两句话统摄 ↓
                      禁止重复评价 · 禁止遗漏评价
            ```
