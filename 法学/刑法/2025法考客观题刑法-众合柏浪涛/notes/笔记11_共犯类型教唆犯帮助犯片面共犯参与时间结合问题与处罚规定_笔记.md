# 共犯类型：教唆犯、帮助犯、片面共犯、参与时间、结合问题与处罚规定

## 教唆犯的判断主线

* **教唆犯（instigator）**
    * > **定义**：狭义共犯，其成立条件与既遂条件都落在客观违法阶层，主观阶层只记一个结论。
    * 教唆犯的一切判断可以压缩成一句话——**引起正犯制造违法事实**，关键词就是"引起"。
    * 成立条件是引起正犯制造**违法行为**；既遂条件是引起正犯制造**违法结果**。
    * 既遂条件要求教唆行为与正犯的既遂结果之间有引起与被引起的因果关系。
    * 教唆犯等于 A（引起），间接正犯等于 A（引起）＋B（支配力），就高不就低论处。
    * 教唆犯的处罚规定没有难度。

* **雇凶杀人的定位**
    * 雇凶者是教唆犯，不是间接正犯。
    * 理由：雇主对杀手没有支配力，支配力要求的是强迫、欺骗；正常付费雇人，对方可以接也可以不接。

## 教唆成立的六种情形

* **早有此意**
    * 情形：教唆者称给一万元请对方杀人，被教唆者本来就想杀，不看上这一万元，还是去了。
    * 结论：被教唆者是故意杀人罪的实行犯，教唆者不构成教唆犯。
    * 原因：成立教唆犯必须是你引起了正犯实施一个违法行为；人家本来就有此意，不是你引起的。

* **轻罪变重罪**
    * 情形：本来打算实施诈骗，被对方讥讽"是男人就去抢劫"，遂改去抢劫并既遂。
    * 结论：对方构成抢劫罪的教唆犯。
    * 原因：你引起的正是他的重罪（抢劫）的犯意。

* **情节加重**
    * 情形：本只想赤手空拳实施普通抢劫，被对方怂恿带上加特林机枪实施抢劫。
    * 结论：对方构成抢劫罪法定加重处罚情节（持枪抢劫）的教唆犯。

* **数额加重**
    * 情形：本只想抢两千元，被对方怂恿改抢一个亿并抢到。
    * 结论：对方不构成数额加重犯的教唆犯，而构成**数额加重犯的心理性帮助犯**。

* **量变与质变的分水岭**

    | | 数额加重（抢 2000 → 抢 1 亿） | 情节加重（空手 → 加特林） |
    | --- | :--- | :--- |
    | 变的是什么 | 数额 | 行为方式 |
    | 基本行为类型 | 没有发生变化 | 已经发生变化 |
    | 性质 | 量变 | 质变 |
    | 对方的定性 | 数额加重犯的**心理性帮助犯** | 持枪抢劫的**教唆犯** |

    * 记忆点：量变不是教唆犯，只是一个心理性的帮助犯；质变可以算是教唆犯。

* **把重罪换成轻罪：降低危险**
    * 情形：对方本要去抢劫，被劝阻改去盗窃。
    * 结论：不构成教唆犯，连心理性帮助犯也不构成，任何犯罪都不构成。
    * 原因：抢劫罪蕴含着一个盗窃罪，去实施盗窃不是你引起的；而且你把他从一个重罪的危险拉到一个轻罪的危险，是**降低危险**，降低危险的行为不是危害行为，连危害行为都不是。

* **换到不同性质：替代危险**
    * 变形情形：对方本要去抢劫铁牛，被劝阻改去强制猥亵铁牛。
    * 结论：仍构成强制猥亵罪的教唆犯。
    * 原因：抢劫与盗窃性质相同、程度不同，往低的降才是降低危险；强制猥亵是人身犯罪、抢劫是财产犯罪，等于教唆他制造了一个**新的不同性质的危险**，这是替代危险。
    * 替代危险是否成立有罪，还要看后面有没有正当化事由；本案没有紧急避险，也没有推定的被害人承诺，不能自行加条件。

> **易错点**：把重罪换成轻罪这一块环节一变结论就完全变。换成同性质的轻罪是降低危险，不构成犯罪；换成不同性质的危险是替代危险，仍成立教唆犯。

## 教唆犯的既遂模型

* **门卫老大爷模型**
    * 先分析实行犯，再回头分析教唆犯；分析时要分预定目标与实害对象两条线。

```text
              教唆犯（狗蛋）                实行犯（杀手）
                    │                            │
   预定目标    小 芳 ◄───  教唆（引起）  ──►    犯罪预备
                    │                            │
   实害对象   门卫老大爷                       故意杀人 既遂
                    └──────  重大偏离  ─────────┘
                      狗蛋：意外事件，不构成犯罪
```

* **实行犯的结论**
    * 杀手预定的目标是小芳，着手了吗？没着手，因为已被围堵无法继续杀，构成**犯罪预备**。
    * 杀手对门卫老大爷成立故意杀人罪既遂。
    * 杀手整体其实是一个行为——杀老大爷也是为杀小芳制造条件的预备行为，想象竞合，择一重，最终定故意杀人罪既遂。

* **教唆犯的预定目标线**
    * 实行犯构成杀人罪的犯罪预备，教唆犯依犯罪形态的从属性，也只能是犯罪预备。

* **教唆犯的实害对象线**
    * 结论：对门卫老大爷的死亡不负责任，不构成犯罪。
    * 原因：教唆者只引起了正犯去杀小芳，正犯杀老大爷是节外生枝、实行过限、擅自加戏。
    * 更专业的说法：教唆者只是给小芳制造了一个危险流，杀手把危险流偏到门卫老大爷身上，这个偏离在理论上叫**重大偏离**——过于异常，对教唆者不具有预见可能性；一个人对自己无法预见的结果不用负责。

* **"无 A 则无 B"站不住**
    * 常见反驳论证是：不教唆杀手去小芳小区，杀手就不会遇到门卫老大爷，不会吵就不会杀人，所以结果要算到教唆者头上。
    * 这套论证用的是**必要条件**来论证因果关系，而必要条件只是因果关系的必要条件、不是充分条件。
    * 用必要条件论证，因果链条可以无限追溯：杀手在小区里干任何事都要算到教唆者头上，属于**滑坡论证**，不合理。

* **对传统结论的意义**
    * 传统理论主张"一人既遂，全部既遂"，实践中给本案教唆者定了故意杀人罪既遂，判得很重，而他其实只对预定目标成立犯罪预备。
    * 结论：**法官判案不是判案，是判人家的人生**。
    * 论证不能只满足于常情、常识、常理（三常），也不能只说符合三观三常；法律人的本领拼的是论证能力，给被告人施加一毫克的刑罚都要提供一毫克的论证理由。

## 打击错误的判断

* **判断标准两步走**

```text
第 1 步：看对实害对象的死亡结果是什么心态
   ├─ 过失 / 意外事件 ──► 打击错误（一步到位，不用再往下走）
   └─ 故意 ────────────► 进入第 2 步

第 2 步：判断行为人对实害对象有没有身份上的认错
   ├─ 有 ──────────────► 对象错误（对象认识错误）
   └─ 无 ──────────────► 什么错误都没有，是间接故意
```

* **预想与实害的分离**
    * 实行犯（杀手）杀错了人的是对象错误（对象认识错误），不是打击错误。
    * 教唆犯（狗蛋）则可能出现打击错误，要看狗蛋对实害对象的死亡结果是什么心态。

* **对实害对象是过失：杀二丫**
    * 情形：狗蛋把照片给了杀手提醒别认错人，杀手仍认错人把二丫打死。
    * 结论：对二丫的死亡狗蛋是**过于自信的过失**——预见了杀手可能认错人，又轻信能够避免。
    * 只要是过失，一步到位得出结论：狗蛋构成打击错误。
    * 具体符合说：对预定目标小芳是犯罪预备，对实害对象二丫尊重案件事实，定过失致人死亡罪，数罪并罚择一重。
    * 法定符合说：对预定目标小芳不变，对二丫的死亡把过失**拟制为故意**，定故意杀人罪既遂，数罪并罚择一重。

* **对实害对象是意外事件：杀门卫老大爷**
    * 情形：杀手为摆脱纠缠开枪打死了门卫老大爷。
    * 结论：狗蛋对老大爷的死亡是**意外事件**，无法预见、没有预见可能性，因此构成打击错误。
    * 法定符合说在这一场合**放弃了自己的阵地**：把过失拟制为故意尚可接受，把意外事件也拟制为故意则离大谱。
    * 所以这类案件只有具体符合说的正常分析：狗蛋对预定目标小芳是犯罪预备，对老大爷的死亡是意外事件、不构成犯罪。

* **两类打击错误的对照**

    | | 杀二丫（认错了人） | 杀门卫老大爷（节外生枝） |
    | --- | :--- | :--- |
    | 对实害对象结果的心态 | 过于自信的过失 | 意外事件，无预见可能性 |
    | 错误类型 | 打击错误 | 打击错误 |
    | 具体符合说·预定目标小芳 | 犯罪预备 | 犯罪预备 |
    | 具体符合说·实害对象 | 过失致人死亡 | 意外事件，不构成犯罪 |
    | 法定符合说·实害对象 | 把过失拟制为故意，定故意杀人罪既遂 | **放弃自己的阵地，不适用** |

## 教唆犯的故意要求

* **过失不构成教唆**
    * 情形：某人在宴席上随口说自己"在贩毒"，同村人听了之后千里奔赴边境，奋斗三年成为毒枭。
    * 结论：不构成贩卖毒品罪的教唆犯，客观上确实引起了、主观上却没有教唆故意，最多算**过失教唆**。
    * 这就是"说者无意，听者有心"。

* **故意教唆不能犯**
    * 空枪：给的枪没装子弹，扣扳机没有客观危险，属手段不能犯、无罪，教唆者不构成教唆犯。
    * 装了子弹但偶然卡壳：有危险但无结果，属故意杀人罪未遂犯，教唆者构成故意杀人罪的教唆犯未遂。
    * 理论上把前者称为"未遂的教唆"、后者称为"教唆的未遂"，这些是行业黑话，不必记。

> **提示**：法考刑法从来不考名词解释，考的是案例分析能力而不是记忆性考点；讨论问题应当从实际出发而不是从定义出发。

## 帮助犯的判断主线

* **帮助犯与教唆犯的差别只在关键词**
    * 教唆犯是"**引起**"正犯制造违法事实，帮助犯是"**促进**"正犯制造违法事实，就这一个字的差别。
    * 二者都是狭义共犯。

```text
                          帮  助  犯
                             │
        ┌────────────────────┴────────────────────┐
        │                                         │
   客观违法阶层                              主观责任阶层
   促进正犯制造违法事实                          故意帮
        │                                    （过失不成立）
        │
        ├── 成立条件：促进正犯【实施违法行为】
        │
        └── 既遂条件：促进正犯【制造违法结果】
```

* **两句话的分工**
    * 促进正犯**实施违法行为**是帮助犯的**成立条件**；促进正犯**制造违法结果**是帮助犯的**既遂条件**。
    * 结论：成立看行为，既遂看贡献；前一句问"有没有搭上"，后一句问"有没有出力"。

* **"一人既遂，全部既遂"不成立**
    * 传统理论的一刀切结论在实践中不成立：实行犯既遂，帮助犯并不当然既遂。
    * 只有帮助行为对正犯的既遂结果有实际贡献，帮助犯才既遂。

## 帮助成立的六个模型

* **总账**

```text
   成立条件一              成立条件二
   有可能的帮助作用         实际作用于正犯行为
   ───────────────         ───────────────
        ①  钥匙根本不能用 ──────────────►  不成立帮助犯
        ②  钥匙有用，但没交到正犯手里 ──►  不成立帮助犯
        ③  钥匙到手，途中被偷走 ────────►  成立，犯罪预备
        ④  钥匙到手，门被风吹开了 ──────►  成立，犯罪预备
        ⑤  钥匙到手，撬门时折断了 ──────►  成立，犯罪未遂
        ⑥  钥匙到手，顺利开门进屋 ──────►  成立，帮助犯既遂
```

* **成立的两个条件**
    * 条件一：帮助行为要具有**可能的帮助作用**，即物理上有没有可能用得上；根本不可能就出局。
    * 条件二：帮助行为要**实际作用于正犯行为**上，与正犯行为连接上；送钥匙的场景就要求钥匙交到正犯手里。
    * 两个模型要记的不是"钥匙有用没用"，而是"**钥匙在谁手里**"。

* **钥匙六种命运的汇总**

    | 钥匙的命运 | 有可能的帮助作用 | 实际作用于正犯行为 | 对既遂结果有实际贡献 | 结论 |
    | --- | :---: | :---: | :---: | --- |
    | 万般无能，根本打不开 | ✗ | — | — | 不成立帮助犯 |
    | 有用，但没交到正犯手里 | ✓ | ✗ | — | 不成立帮助犯 |
    | 交到正犯手里，途中被偷走 | ✓ | ✓ | ✗ | 成立，犯罪预备 |
    | 交到正犯手里，门被妖风吹开 | ✓ | ✓ | ✗ | 成立，犯罪预备 |
    | 交到正犯手里，撬门时折在锁里 | ✓ | ✓ | ✗ | 成立，犯罪未遂 |
    | 交到正犯手里，顺利开门进屋 | ✓ | ✓ | ✓ | 成立，帮助犯既遂 |

    * 从一到六，只有最后一个模型帮助犯才既遂。

* **犯罪形态的判定标准**
    * 成立但不既遂时，形态标准只有一条：**看帮助行为帮到正犯的哪个阶段**。
    * 只帮到正犯的**预备阶段**就帮不下去了，定犯罪**预备**。
    * 帮到正犯的**着手实行阶段**就帮不下去了，定犯罪**未遂**。
    * 判断不是中止：帮助犯没有主动终止自己的行为。
    * 坐标参照：入户盗窃的着手点是**撬门开门**，而且是撬正屋的门开门。

> **易错点**：钥匙在路上丢失与在门前丢失都定预备，但丢失时点不同，要始终回到"入户盗窃的着手点＝撬正屋的门开门"这个坐标上卡。题目选项原话就是"帮助行为的促进作用维持到正犯的预备阶段"。

## 帮助行为的形态与中立性

* **物理性帮助与心理性帮助**
    * 送钥匙这类是物理性帮助；出言鼓励、摇旗呐喊这类是心理性帮助。
    * 路人喊"加油"使杀人者更带劲，行为人构成故意杀人罪的**心理性帮助犯**。
    * 日本刑法为此另设**现场助威罪**，我国没有这一罪名，定成心理性帮助犯即可。

* **中立的帮助行为**
    * 民法与刑法是低位阶与高位阶的关系：民法上成立买卖行为合法，不能直接推出刑法上无罪，还要走到刑法这一层用刑法标准判断。

```text
   民法（低位阶）：买卖合同，合法
                    ↓  还要往上走一级
   刑法（高位阶）：是不是帮助犯？
                    │
                    ├─ 主观：是否明知对方在犯罪？
                    └─ 客观：对对方犯罪有没有起到
                              【实质并且紧迫】的促进作用？
                    │
                    └─ 两句都满足 → 是帮助犯（就高不就低）
```

    * 案例：行为人在五金店门口殴打他人并扬言买羊角锤锤死对方，店老板明知仍以两倍价钱卖锤，行为人当场用锤将对方锤死。
    * 结论：店老板构成故意杀人罪的帮助犯；"民法上的买卖行为所以没责任"这一抗辩不成立。

* **什么是实质的促进作用**
    * 实质的判断落点：**拿掉它，这个违法犯罪还成立吗**。
    * 通宵赌场里卖茶叶蛋的老奶奶不构成开设赌场罪的帮助犯——赌客没她也会继续赌，拿掉茶叶蛋赌场照样开。
    * 明知他人要开赌场仍出租场地的房东构成帮助犯——提供场地是开设赌场的实质促进作用。
    * 提升被害人的生活便利、提高某项活动的舒适度，不等于对犯罪有实质促进作用。

* **什么是紧迫的促进作用**
    * 紧迫的判断落点：**行为与犯罪之间有没有时间、空间上的间隔**。
    * 明知对方可能杀人仍卖老鼠药，事后对方用毒药毒死其妻，店老板不构成故意杀人罪的帮助犯：老鼠药虽是实质的，但对象必须带回家再等时机，存在时空间隔，不紧迫。
    * 紧迫性一出，商业经营自由就要保住；若连老鼠药都定帮助犯，农药店、药店就都不能开了。

## 四大角色的主观要件

* **只能故意的角色**
    * 帮助犯、教唆犯、间接正犯，主观上都必须是故意，**过失不构成**。
    * 过失帮不构成帮助犯，过失教唆不构成教唆犯；这两种角色头上安的罪名只能是故意犯罪。

```text
   教唆犯     =  A（引起）
   间接正犯   =  A（引起） + B（支配力）
```

    * 间接正犯之所以也只能故意，是因为它在教唆犯"引起"的基础上增加支配性而来；教唆犯这个 A 都只能由故意犯罪构成，A＋B 更只能由故意犯罪构成。

* **选项陷阱：过失罪名不能安在这些角色头上**
    * 谎称开车兜风、把车借给醉酒者的情形：把车借出的人构成交通肇事罪，但选项说"构成交通肇事罪的帮助犯"是错的——帮助犯只能由故意犯罪构成，交通肇事罪是过失犯罪，这句话本身就错。
    * 以"你不开车我就分手"逼人开车致人死亡的：说"构成交通肇事罪的教唆犯"同样错误，只能说构成交通肇事罪。
    * 医生欺骗护士给病人注射毒针致死的：选项说"护士构成医疗事故罪、医生构成医疗事故罪的间接正犯"是错的，正确答案是医生构成**故意杀人罪**的间接正犯。

* **共同正犯的主观要件：观点展示**
    * 标准案例是打野猪：二人有意思联络约定一起开枪，结果把人打死且无法查明谁打的致命一枪。
    * **行为共同说**：成立共同正犯只要求"一起制造违法事实"这一个条件，"一起"即有意思联络；启动部分实行全部责任原则，主观上查明对死亡是过失，两人成立过失致人死亡罪。
    * **部分共同说**：成立共同正犯要同时满足有意思联络和共同故意；二人是共同过失，不构成共同正犯，各自单独处理时启动存疑时有利于被告，对死亡结果都不用负责，两人无罪。
    * 行为共同说在法考刑法里是多数说，对法硕而言接近少数说；法考曾有一道题的官方答案采取行为共同说。
    * 行为共同说不违反法条的理由：法条说的"共同犯罪是指共同故意犯罪"指的是**狭义的共同犯罪**（教唆犯与帮助犯），这是作了**目的性限缩**、缩小解释，属于刑法允许的解释方法。

> **提示**：主观题考过共同正犯主观要件的观点展示，不必心悦诚服采纳行为共同说，但要能写出其论证逻辑。

## 正犯的责任年龄与责任能力

* **责任年龄不要求正犯具备**
    * 正犯（实行犯）要与教唆犯、帮助犯或其他正犯构成共同犯罪，不要求该正犯达到责任年龄。
    * 原因：成立共同犯罪只要求"一起制造违法事实"；责任年龄属于主观责任阶层，责任是独立的。
    * 案例：十岁的行为人强奸他人、让望风者望风，二者在客观上构成共同犯罪；十岁者因责任年龄不够最终无罪，但正犯的成立本来就不要求责任年龄。

* **教唆未成年人的三种情形**
    * 教唆已满十六周岁者去盗窃：正犯有责任年龄、有规范意识、独立作战能力，教唆者对其没有支配力，只构成**教唆犯**。
    * 教唆八周岁者去盗窃：两步走得出间接正犯。第一步故意引起，构成教唆犯；第二步因正犯无责任年龄、无规范意识、无独立作战能力，教唆者对其产生**支配力**，加上支配力即构成间接正犯，就高不就低按间接正犯论处。
    * 教唆十五周岁的惯偷去盗窃：该正犯已因盗窃被公安机关管教过，有规范意识、有独立作案能力，教唆者对其没有支配力，B 不成立，只构成**教唆犯**。

> **易错点**：传统理论按年龄一刀切，只要被教唆人未满十六周岁，教唆者一律定间接正犯。法考刑法采取**实质标准**：即便只差一天满十六周岁，只要对方有规范意识和独立作案能力，教唆者仍只定教唆犯。实质标准在法考界是多数说。

* **责任能力同样不要求**
    * 正犯与教唆犯、帮助犯或其他正犯构成共同犯罪，不要求该正犯具有责任能力。
    * 原因：责任年龄与责任能力都是主观责任阶层的阻却事由，只要求该正犯有**实施法益侵害的能力**。

* **精神病人的两种情形**
    * 妻子明知丈夫精神病发作在伤害他人而故意不阻止：妻子有阻止义务，不作为，属于不作为的帮助犯；丈夫是正犯，无责任能力最终无罪，妻子仍构成犯罪。
    * 教唆者不知道被教唆者是精神病患者，被教唆者精神病发作仍实施了伤害：教唆者不构成间接正犯（若明知对方是精神病患者还指使才构成间接正犯），至少构成**教唆犯**，二人构成故意伤害罪的共同犯罪。

> **易错点**：传统理论还有一刀切结论——精神正常、有责任能力的人与精神不正常的人共同犯罪时，有责任能力者一律构成间接正犯。教唆伤害案证明这个结论以偏概全、不完全归纳。法考在这里起到纠偏功能，把传统理论作为陷阱考出来。

## 片面的共同犯罪

* **片面的共同犯罪（einseitige Mittäterschaft）**
    * > **定义**：片面的"片面"要理解成**单方面**——单方面也能构成共同犯罪。
    * "共同犯罪"按理要求相互奔赴、一方使劲另一方也使劲、彼此心里都清楚；片面的共同犯罪是一方拼命帮忙、另一方从头到尾不知道有人帮。
    * 特点是意思联络不要求相互：你以为你在单干，我知道我在帮你。

* **小芳的那根小木棍**

```text
  T1  狗蛋：发现铁牛是自己的情敌 → 拔腿就追，两人相距约 100 米
  T2  小芳：在远处看见这一幕，心里想"狗蛋儿不喜欢的人我都想杀"
  T3  小芳：抢先绕到自家门口埋伏，等着铁牛跑到
  T4  小芳：往铁牛脚下扔了一根小木棍，铁牛"啪"一下摔倒
  T5  小芳：立刻闪进屋里，把门一关，做好事不留名
  T6  狗蛋：赶到跟前，认为铁牛是自己摔的
  T7  狗蛋：顺利把铁牛杀死 —— 故意杀人罪既遂
  ─────────────────────────────────────────────────────────
  狗蛋的认知：自始至终"我是一个人干的"
  小芳的认知："我在帮他"，而且打算永远不让他知道
```

* **片面帮助场合的两说**
    * 否定说：构成共同犯罪、构成帮助犯要求有相互的参与意识、相互的意思联络、相互奔赴；狗蛋浑然不觉，小芳只是单恋、暗恋，所以小芳不构成帮助犯，要单独处理。
    * 单独处理会撞墙：小芳只是扔了根木棍使对方摔倒，可能连轻微伤都没有，不构成故意伤害罪（该罪至少要求轻伤），只能无罪。
    * 无罪不合理——她是在帮着杀人，不能无罪；要定罪就必须把扔木棍这个行为放到狗蛋杀人的整体环境中评价，也就是必须挂靠到狗蛋的杀人罪上。
    * 肯定说：小芳构成狗蛋的单方面帮助犯、单方面的共同犯罪，**我帮你不需要你知道**。
    * 结论：否定说在片面帮助的场合接受了肯定说，给小芳定一个片面的帮助犯。

* **接受肯定说的两点注意**
    * 第一点：否定说只在片面帮助这个场合作出让步，到了片面实行的场合他仍然坚持自己原来的观点，同一套说辞在两个场合给出两个答案。
    * 第二点：考题如果让做观点展示，肯定说与否定说**都要展示**，毕竟否定说曾经有江湖地位。
    * 片面的教唆与片面的帮助原理几乎一模一样。

* **片面实行场合：狗蛋强奸二丫**

```text
  小芳：把二丫打成重伤、昏迷   ──→  暴力
  狗蛋：把二丫强奸             ──→  奸淫（发生性交行为）
                                      ↓
                      暴力 + 奸淫，都是强奸罪的实行行为
```

    * 肯定说：小芳构成狗蛋强奸罪的共同正犯、共同实行犯，只不过是片面的、单方面的实行犯。
    * 否定说：坚持必须是相互奔赴、必须有相互的意思联络，因此不承认片面的实行犯；但小芳实施的不是一个单纯的帮助行为而是实行行为，单拉出来就能定罪，故单独构成故意伤害罪既遂，不会出现处罚漏洞。
    * 否定说被追问到墙角后作出退让：承认构成狗蛋强奸罪的片面帮助犯，但就是不承认构成片面的实行犯。
    * 否定说最终的结论：小芳一方面构成单独的故意伤害罪既遂，另一方面构成狗蛋强奸罪的片面帮助犯；一个行为触犯两个罪，想象竞合，择一重罪论处。

> **易错点**：强奸罪的实行行为有两个——暴力行为与奸淫（性交）行为。把人打成重伤昏迷本身就是强奸罪的实行行为，所以按肯定说小芳是实行犯而不是帮助犯。

* **观点展示的考法**
    * 多选题、单选题同样可以考观点展示，形式是"如果……则……""若认为……则……""根据……则……"。
    * 考的是**前提和结论逻辑是否自洽**，不是唯一定论。

## 共同犯罪的参与时间

* **三个位置、三种身份**

```text
  参与时间：三个位置，三种身份
  ═══════════════════════════════════════

  [ 事前共谋 · 临时迟到 ]
      甲乙一开始就约好一起干
      乙迟到 → 仍是一开始的共同犯罪
      后果：乙对甲之前打出的重伤也要负责

  [ 中途参与 · 承继的共犯 ]
      介入时，实行行为还没做完
      铁牛接的是"取财行为"这一步
      后果：只对自己参与之后的事情负责

  [ 事后参与 · 事后帮 ]
      介入时，犯罪已经既遂
      铁牛只负责把人带走
      后果：转入妨害司法类犯罪

  中途退出：在上面任何一个位置上想下船
          → 最多退成犯罪中止，不可能退成无罪
```

* **中途参与即承继的共犯**
    * "承继"是日本汉字直译，汉语对应的是"继承"，直接把它列成"中途参与"即可。
    * > **定义**：抢劫罪的实行行为有**两步**——第一步是暴力行为，第二步是取财行为。
    * 基准案例：行为人先把被害人打趴下还没取财，中途加入者接下取财行为，构成承继的共犯。

* **无法查明死亡结果时**
    * 口诀：**死得越早，对兄弟们越有利**；无法查明死亡时间时，按死亡时间最早的那个时间点认定。

```text
  情形一：是前面那一脚          情形二：是加入者那一脚
  ──────────────────          ──────────────────────────
  死亡结果 → 行为人            该脚与死亡有因果关系

  加入者那时还没出现，          这一脚不是他一个人在踹，
  不用为自己参与之前          他代表前面的人一起踹，属于二
  发生的事情负责 → 不负责      人的共同犯罪 → 部分实行全部
                              责任 → 前面的人也要负责
```

    * 第一种可能：死亡结果算到先行者头上，加入者那一脚没踹死。
    * 第二种可能：是加入者那一脚踹到脾脏致死；此时该脚不是他一个人在踹，他代表先行者一起战斗、双方有意思联络，属于共同犯罪部分，基于部分实行全部责任，先行者也要负责。
    * 两种可能下先行者都要对死亡负责，对加入者则一可能不负责一可能负责，启动**存疑时有利于被告原则**，最终只让先行者负责。

* **事前共谋、临时迟到**
    * 情形：二人事前约定明晚八点抢劫，约定"不见不散"；先行者独自把被害人打成重伤、财物未取，迟到者赶到后接过取财。
    * 结论：迟到者不构成承继的共犯，因为二人一开始就有共谋、从一开始就构成共同犯罪，他只是临时迟到。
    * 区别落在"对重伤要不要负责"上：若认定为中途参与，迟到者只对参与之后的事情负责、对重伤不负责；因一开始即有共谋，他要对先行者打出的重伤负责。

* **事后参与即事后帮**
    * 情形：抢劫既遂、行为人已带着赃物离开现场，接应者载其逃离。
    * 结论：不构成抢劫罪的承继的共犯，只算事后参与、事后帮。
    * 事后帮的三种罪名取决于笑纳的对象是什么：

    | 事后帮的对象 | 它在刑法上的身份 | 罪名 |
    | --- | --- | --- |
    | 抢来的财物 | 赃物，即犯罪所得 | 掩饰、隐瞒犯罪所得罪 |
    | 用来犯罪的工具 | 犯罪工具，事后即变成犯罪证据 | 帮助毁灭证据罪 |
    | 犯罪人本人 | 犯罪人 | 窝藏罪 |

    * 明知是抢夺来的包还笑纳，构成掩饰、隐瞒犯罪所得罪。
    * 笑纳作案用的摩托车：该车不是赃物而是犯罪工具，事后变成犯罪证据，刑法没有"帮助隐藏证据罪"，只有"帮助毁灭证据罪"，把"隐藏"解释到"毁灭"里，定帮助毁灭证据罪。
    * 藏匿犯罪人本人构成窝藏罪；不能把犯罪人也当成犯罪所得。

> **易错点**：事后帮里赃物与犯罪工具的罪名不同：赃物对应掩饰、隐瞒犯罪所得罪，工具事后变成证据对应帮助毁灭证据罪。

## 中途退出与犯罪中止

* **基本原则**
    * 上了贼船退不成无罪，最多退成犯罪中止。
    * 成立中止的条件是**消除你的贡献、脱离与其他人的共犯关系**，物理性贡献与心理性贡献都要消除。
    * 消除贡献的标准按犯罪角色分别判断：

    | 犯罪角色 | 要消除什么 | 达到什么标准 | 达不到的后果 |
    | --- | --- | --- | --- |
    | 教唆犯 | 心理贡献 | 原则上打消对方犯意；例外：已尽最大努力仍未打消 | 跟着既遂 |
    | 帮助犯 | 物理贡献 + 心理贡献 | 收回工具等物理帮助，并让对方知道（切断心理依托） | 跟着既遂 |
    | 共同正犯·预备阶段 | 物理贡献 + 心理贡献 | 明确告知退出，并消除已实施的准备行为 | 跟着既遂 |
    | 共同正犯·实行阶段 | —— | 原则上要求**有效阻止**；例外：已尽力 | 跟着既遂 |

* **教唆犯的退出标准**
    * 教唆犯的贡献是心理贡献，原则上要求**打消对方的犯意**。
    * 口头通知取消行动不算实际打消；还要想办法阻止，如报警、请人拦截、亲自去拦、通知被害人躲避。
    * 例外：已经尽力、尽最大努力仍未打消的，仍可以定犯罪中止。这是"有原则就有例外"最典型的一处。

* **帮助犯的退出标准**
    * 望风有两类贡献：心理性贡献（让里面的人有安全感、从容不迫）与物理性贡献（主人回家时拦住主人）。
    * 悄悄溜掉：物理贡献消除了，心理贡献没消除，里面的人还以为有人在望风，因此不是犯罪中止，里面既遂你也既遂。
    * 正确做法是喊一声让里面的人知道你撤了，把对方那份心理依托抽掉；即便如此，里面的人仍然盗窃既遂，撤走的人照样成立犯罪中止。

```text
  望风者 → 里面的人
             心理依托：外头有人替我看着，我放心

  路线一：悄悄溜掉
    物理贡献：不再拦主人        → 已消除
    心理贡献：里面的人不知道    → 仍在
    结果：不是犯罪中止，里面既遂你也既遂

  路线二：喊一声"十楼的蛋哥，我撤了"
    物理贡献：不再拦主人        → 已消除
    心理贡献：兄弟知道你要走    → 已消除
    结果：成立犯罪中止
```

> **易错点**：悄悄溜掉不等于中途退出。区别就在心理性贡献还在不在——悄悄溜掉是让对方在不知情的情况下继续干；只有让对方知道你撤了、把对方那份心理依托抽掉，才算消除。

* **共同正犯在预备阶段的退出标准**
    * 心理性贡献要靠**明确告知**来消除。事后只打电话说"我拉肚子去不了"而隐瞒真相不行——对方会认为"兄弟还是想一起去，只是客观原因去不了，我要干出个样来"，心理依托仍在，跟着既遂。
    * 物理性贡献也要消除。把被害人骗到约定地点后说"你不杀拉倒"不够，因为事先实施的准备行为还在；事后打电话消除而没打通也不行——电话可以再打、没电了可以换手机，没消除就跟着既遂。
    * 真正做到明确告知并消除已实施的准备行为，才能成立**预备阶段的犯罪中止**。

* **共同正犯在实行阶段的退出标准**
    * 原则上要求**有效阻止**对方继续实行；已经着手杀人时说"我不杀了"而任由对方继续，不成立中止。
    * 例外：自己去阻止反而被打晕，已经尽最大努力，例外地享受终止的待遇，对既遂结果不负责。

* **四个悔意时刻的判断**
    * 共同正犯的既遂责任要看是**被迫放弃**还是**自动放弃**、发生在预备阶段还是实行阶段。
    * 去被害人家途中被父母强行拉回家、对方自己抢劫既遂：被迫放弃，乙还在实行，甲仍是共同正犯，启动部分实行全部责任，甲成立既遂并对乙的既遂负责。
    * 途中自行回家并告知对方，对方既遂：自动放弃且明确告知，心理贡献消除，成立中止，不对既遂负责。
    * 共同压制被害人反抗后自行离去，对方继续既遂：已进入着手实行阶段，自行离去不等于有效阻止，跟着既遂。
    * 共同压制被害人反抗后要阻止却被对方打晕，对方仍既遂：已尽力，例外成立中止，不对既遂负责。

## 共犯与身份犯的结合

* **保险案的标准分析**
    * 投保人与保险公司非国家工作人员经理内外勾结骗取本公司的保险金并分赃。

    | 分析视角 | 投保人 | 保险公司经理 |
    | --- | --- | --- |
    | 保险诈骗罪 | 实行犯（有投保人身份） | 帮助犯（无身份资格） |
    | 职务侵占罪 | 帮助犯（非本单位职员） | 实行犯（非国家工作人员、本单位职员） |
    | 想象竞合 | 一个行为，择一重罪论处 | 一个行为，择一重罪论处 |

    * 分析方法是各自分别分析，最后总结归纳。
    * 保险诈骗罪是身份犯，主体限于投保人、被保险人、受益人；经理没有身份资格，只能是帮助犯。
    * 经理是非国家工作人员的本公司职员，构成职务侵占罪的实行犯；投保人只能是职务侵占罪的帮助犯。
    * 结论：二人构成保险诈骗罪的共同犯罪，也构成职务侵占罪的共同犯罪；最终投保人定保险诈骗罪的实行犯，经理定职务侵占罪的实行犯。

* **为什么两人可以定不同罪名**
    * 构成共同犯罪并不要求最终定相同的罪名，罪名更不要求相同；行为共同说只要求"一起制造违法事实"。
    * 传统理论（含法硕考试）要求两人定同一个罪名，那就得看谁的身份更特殊、地位更高，按经理的身份定职务侵占罪。
    * 这样做的后果：给经理定职务侵占罪实行犯罪行还相适应，但给投保人也定职务侵占罪就只能定该罪的帮助犯，比原本的保险诈骗罪实行犯轻得多，**违反罪刑相适应原则**。

## 共犯与不作为犯的结合

* **两步判断路径**

```text
第一步：把作为义务人找出来
                │
                ▼
第二步：看他干了什么事
                │
        ┌───────┴─────────┐
        │                 │
     积极举动          能为而不为
        │                 │
  作为方式的实行犯    不作为方式的帮助犯
                     （前提：负有阻止义务）
```

* **遗弃案的身份倒置**
    * 情形：妻子想让别人用小推车把瘫痪的丈夫推到马路边扔掉，对方欣然照办。
    * 结论：推车的人是遗弃罪的**帮助犯**，妻子是遗弃罪的**实行犯**；"推车的人是实行犯、妻子是教唆犯"的说法是错的。
    * 理由：遗弃罪是真正的不作为犯，主体限于**负有抚养义务的人**，这种作为义务人就是一种定罪身份；没有抚养义务就没有资格做实行犯。
    * 妻子只要不履行抚养义务就构成该罪，其"不履行抚养义务"这一不作为本身就是实行行为，不要求积极举动。

> **易错点**：千万不要把"实行犯"理解成一定要求积极举动。不作为犯的实行行为就是不作为。

* **袖手旁观的不作为帮助犯**
    * 情形：他人闯入卧室对瘫痪在床者狂吻，配偶在门口看着、说笑、既不走也不阻止。
    * 结论：闯入者构成强制猥亵罪的实行犯（作为方式的实行犯），配偶构成强制猥亵罪的帮助犯（不作为方式的帮助犯）。
    * 理由：配偶对丈夫有阻止义务，能为而不为。

* **作为义务的来源：先行行为**
    * 判断标准是**看你的先行行为有没有让人家陷入危险状态**；有，就产生了保护义务、阻止义务。
    * 二人合谋殴打致人重伤昏迷，随后同伙欲强奸而不制止：先行行为让人陷入了危险状态，不阻止者构成强奸罪的不作为帮助犯。
    * 入户盗窃的分工中，一人欲强奸同伴而不制止：先行行为是盗窃，盗窃是平和手段的财产犯罪，只对财产法益产生危险、并没有让财产的主人陷入危险状态，因此没有保护义务、没有阻止义务，不构成强奸罪的不作为帮助犯。
    * 反驳"引狼入室所以有危险"：先行行为让人陷入危险状态指实施暴力、打昏迷、打重伤这类行为，不是"我把人带进来了"；而且事前预定的只是偷东西，对人身没有产生危险。

## 实行过限

* **判断标准**
    * 甲乙共同计划实施 A 罪，乙在实施 A 罪过程中又多实施了 B 罪，甲要不要为 B 罪负责。
    * 标准是看乙实施的 B 罪**有没有超出此前共同犯罪共同故意的范围**；超出则甲对故意不负刑事责任，但可能负过失责任。

* **共同正犯层面**
    * 入户盗窃的分工中，同伙欲强奸而另一人不制止：强奸超出了事先盗窃罪的共同故意范围，不负刑事责任；从作为义务角度看也没有阻止义务，最终对强奸罪一概不负责任。

* **教唆犯层面**
    * 情形：受雇去教训他人，被明确指示"可以打成遍体鳞伤，但不能要他的命"；打手遭遇激烈反抗后使用抱摔把人摔死。
    * 实行犯：由故意伤害罪升级为对死亡结果的间接故意，最终定故意杀人罪。
    * 教唆犯对故意杀人罪不负责，因为事先共同故意的范围只是故意伤害罪，属实行过限。
    * 但教唆犯对死亡结果有过失：指示中已预见可能出人命，只是轻信能够避免，属**过于自信过失**，应负过失致人死亡罪的责任。
    * 教唆者只有一个教唆行为，同时触犯故意伤害罪与过失致人死亡罪，本应想象竞合择一重，但法律对这一结构有特别规定，应转化为结果加重犯。
    * 结论：定**故意伤害罪致人死亡的结果加重犯**。

> **易错点**：雇凶类案件往往要么定得过重（故意杀人罪既遂，对教唆者不公平），要么定得过轻（只定故意伤害罪、对死亡结果完全不负责）。正确结论是故意伤害罪致人死亡的结果加重犯。

* **帮助犯层面**
    * 情形：一人望风、一人入室盗窃，盗窃者被发现后为抗拒抓捕对被害人施暴并转化为抢劫罪。
    * 实行犯：转化型抢劫罪。
    * 帮助犯不背这个锅：事前共谋的故意只是盗窃，盗窃只对物、手段平和，是纯粹的财产犯罪；对人施暴转化为抢劫已超出共同盗窃的范围，属实行过限。
    * 帮助犯依然只负盗窃罪的责任，仍是盗窃罪的帮助犯。

## 共犯与认识错误的结合

* **分析路线图**

```text
                        ┌───────────────────────┐
                        │  先分析实行犯（正犯）  │
                        └───────────┬───────────┘
                                    │
        ┌───────────────────────────┴───────────────────────────┐
        │                                                       │
┌───────▼────────┐                                    ┌─────────▼──────────┐
│  预定目标这条线   │                                    │  实害对象这条线      │
│（原打算下手的那个人）│                                    │（实际打中的那个人）  │
└───────┬────────┘                                    └─────────┬──────────┘
        │                                                       │
  狭义共犯跟实行犯走                                        实行犯自己负责
  （教唆犯跟实行犯，形态同形）                          （有没有故意，看对死亡
        │                                                      结果是什么心态）
        └───────────────────────────┬───────────────────────────┘
                                    │
                          两个对象、一个行为
                            想象竞合，择一重
```

    * 三句话：先解决有认识错误的那个人；每个行为人都要分预定目标与实害对象两条线；凡是"共犯＋正犯"的行为模型，都先定实行犯，再让狭义共犯跟着走。
    * 做题习惯：**先看谁有认识错误，就先解决谁**。

* **共同正犯之间的认识错误**
    * 情形：二人约定一起开枪杀馆长，一人打偏打碎了旁边的文物，另一人全未打中。
    * 有认识错误的是打偏者，先解决他：这是**不同犯罪构成间的打击错误**，因为预定目标是人、实害对象是文物，两者性质与种类不同。
    * 不同犯罪构成间的打击错误按正常分析即可，最多构成两个罪、想象竞合择一重。
    * 结论：对预定目标馆长是故意杀人罪未遂；对文物构成**过失毁损文物罪**（过失毁坏一般财物不构成犯罪，过失毁损文物才构成），二者想象竞合择一重。

* **狭义共犯加正犯**
    * 情形：教唆者指使杀手杀预定目标并交付照片提醒不要认错人，杀手把预定目标误认成自己的心上人打死。
    * 正犯：对实害对象是同一犯罪构成内的对象错误，不重要，成立故意杀人罪既遂；对预定目标未着手，成立犯罪预备；整体一个行为想象竞合择一重定故意杀人罪既遂。
    * 教唆者：对实害对象的死亡是过于自信的过失（提醒过别认错人＝有预见，轻信能避免＝过失），因此构成打击错误。
    * 具体符合说：对预定目标是犯罪预备，对实害对象尊重案件事实定过失致人死亡罪。
    * 法定符合说：对预定目标不变，对实害对象把过失**拟制为故意**，定故意杀人罪既遂，想象竞合择一重。

* **教唆犯与间接正犯之间**
    * 情形：教唆者以为对方精神正常而指使其杀人，对方早已精神失常但真的杀了人。
    * 主观上教唆者是教唆犯，客观上指使精神失常者杀人其实构成间接正犯。
    * 因为间接正犯是 A＋B，可以包容评价为教唆犯 A，所以在教唆犯范围内主客观相一致。

> **结论**：教唆犯与间接正犯之间发生认识错误时，定教唆犯。打个比方：教唆犯相当于 A 相当于故意伤害罪，间接正犯相当于 A＋B 相当于故意杀人罪，故意杀人罪可以包容评价为故意伤害罪。

* **共犯人成为被害人：渔网案**
    * 情形：帮助者给工具并支持，行为人按预定目标去偷某家的渔网，偷回来才发现偷的是帮助者家的。
    * 实行犯：对实害对象（帮助者的渔网）是同一犯罪构成内的对象错误，不重要，偷任何人的财物都构成盗窃罪，成立既遂；对预定目标未着手，成立犯罪预备；一个行为想象竞合择一重定盗窃罪既遂。
    * 帮助者：对实害对象这条线按理也属打击错误，但这里**没有观点展示**——她自己就是这条线的被害人，不能既是犯罪人又是被害人，两说都承认她不用负这条线的责任。
    * 帮助者只需对预定目标这条线负责，跟着实行犯走，成立**犯罪预备**。

* **共犯人成为被害人：雇人强奸自己**
    * 情形：教唆者指使他人去强奸第三人，结果对方把她打晕后把她当成了第三人。
    * 实行犯：对实害对象是对象错误，成立强奸罪既遂；对预定目标未着手，成立犯罪预备；一个行为想象竞合择一重定强奸罪既遂。
    * 教唆者：对实害对象这条线是被害人不用负责，对预定目标这条线要负责且成立犯罪预备。
    * 结论：教唆者构成犯罪预备，不是无罪；互联网上"雇人强奸自己所以雇主无罪"的说法过于简单。

* **正犯成为被害人：婚宴上撬错摩托车**
    * 情形：参加婚宴的人找不到自己的车，请新郎找工具来帮忙撬一辆；撬到一半他改指另一辆，被撬走的车其实是新郎自己的。
    * 预定目标是别人的车，实害对象是实行犯本人的车。

```text
   预定目标：他人车辆            实害对象：自己的车辆
        │                              │
   着手撬 → 中途放弃                对自己的财产不构成犯罪
   实行阶段的犯罪中止
```

    * 实行犯：对实害对象这条线不负刑事责任；但并非无罪——已对他人的车着手，撬到一半听从对方的话放弃，属**实行阶段的犯罪中止**。
    * 帮助犯：对预定目标跟着实行犯走，也是中止，他本人也有放弃的终止行为。
    * 帮助犯对实害对象这条线不承担责任，理由是**共犯从属性原则**：实行者都不构成犯罪，教唆者、帮助者也不构成犯罪。
    * 财产犯罪对象转移的规则在这里不适用：那个规则的前提是对新的对象也构成犯罪且既遂；这里换成的是自己的车，对自己的车不构成犯罪，所以对原预定目标的犯罪中止仍要认定。

* **正犯成为被害人：打中自己的队友**
    * 情形：共同正犯约定抢劫后若被害人追赶就开枪，事后甲发现追赶的是同伙乙，一枪把乙打伤（未打中要害）。
    * 甲对实害对象乙是对象错误，不重要，但未打中只能定故意杀人罪未遂（若打中则可能按伤情评价为故意伤害罪，想象竞合择一重）；对预定目标丙当时在现场但甲没看到，属未着手，成立犯罪预备。
    * 甲对两个对象触犯的罪想象竞合，择一重。
    * 乙对实害对象这条线不用负责（他是被害人）；对预定目标丙这条线要负责，因为二人约定过开枪杀人，即使乙没开枪，甲的行为乙也要负责，甲成立犯罪预备则乙也成立犯罪预备。

* **这一块的分量**
    * 共同犯罪这一章是刑法里许多知识点的**平台**，把大量知识点搬到共犯平台上做综合考察、交叉结合。
    * 单选题一般拦不住人，多选题与不定项选择题才拦得住，原因是多选专考知识点的结合与综合运用，而综合运用能力恰恰薄弱。

## 共同犯罪的处罚规定

* **处罚规定的分工**
    * 这一节没有理解性难度，主要是记忆性问题，课上不展开，要求下去自己看。
    * 两个理由：一是记性考点多；二是它不是共同犯罪部分的重点内容。
    * 分工标准如下：

    | 课上讲（需要来听） | 下去自己看书 |
    | --- | --- |
    | 看书看不懂、理不清楚 | 一看就懂 |
    | 自己不会总结 | 没什么理解难度 |
    | 不知道陷阱在哪里 | 死记硬背的记性考点 |

* **共同犯罪的成立条件**
    * > **定义**：共同犯罪即一起去犯罪，即"**一起制造违法事实**"。
    * 传统教材"客观上共同行为、主观上共同故意"那一套成立条件表述，在法考刑法里已过时。

* **第一本质原理：违法一起，责任独立**
    * 违法是一起的，就是一起制造违法事实。
    * 责任是独立的，就是主观责任阶层那些要求不作限制，可以具备也可以不具备。

* **四大角色**

```text
共同犯罪
│
├─ 正犯
│  ├─ 共同正犯
│  └─ 间接正犯
│
└─ 共犯
   ├─ 教唆犯
   └─ 帮助犯
```

    * 一定要树立正犯为王、为中心决策的观念，分析共犯之前先梳理正犯与共犯的关系。
    * 共同正犯的客观阶层是意思联络加实行行为；主观阶层不作要求，可以有也可以没有责任能力、可以是故意也可以是过失。
    * 间接正犯是引起加支配，支配力主要考的是通过欺骗手段取得。
    * 法考采**共犯从属性**，少数说是共犯独立性。

* **教唆犯与帮助犯的成立与既遂**

    | 类型 | 关键词 | 成立条件 | 既遂条件 |
    | --- | --- | --- | --- |
    | 教唆犯 | 引起 | 引起正犯实施违法行为 | 对正犯的既遂结果要有实际贡献，即有引起与被引起的关系 |
    | 帮助犯 | 促进 | 促进正犯实施违法行为 | 对正犯的既遂结果要有实际贡献，即有引起与被引起的关系 |

    * 成立只要"引起/促进正犯实施违法行为"就够；要求既遂时标准升级为"对正犯的既遂结果要有实际贡献"。

* **参与时间与结合问题的清单**
    * 中途参与即承继共犯；中途退出要消除自己的贡献，物理性贡献与心理性贡献都要消除，并按教唆犯、帮助犯、共同正犯分别分析，共同正犯还要再分预备阶段与实行阶段。
    * 片面的共同犯罪的特殊点在于意思联络不要求相互：你以为你在单干，我知道我在帮你。
    * 几组"结合"问题：共犯与身份的结合分别分析、可能想象竞合，最后定的罪名不要求是同一个；共犯与不作为犯的结合主要看作为义务怎么判断；实行过限看有没有超出共同故意的范围；认识错误的问题先分析正犯再分析共犯。
    * 还要注意犯罪人变成被害人、同伙变成被害人的情形该怎么处理。

* **分析路线图**
    * 分析路线图非常重要，要熟悉掌握；考场上不会做就在草稿纸上画出来，熟练时在脑子里画。
    * 共同犯罪这个板块难在"无他，唯熟耳"，多学几遍、多走两圈就熟悉了。
