# 抢劫、敲诈勒索、诈骗与职务侵占

## 事后转化抢劫罪

### 刑法第269条的三块法条

* **事后转化抢劫罪（刑法第269条）**

    * > **定义**：可以把这个条文切成三个板块来记——三个轻罪、三个目的、实行行为；漏掉其中任何一个词语，就可能漏掉一个考点。

    * 三个轻罪：盗窃罪 / 诈骗罪 / 抢夺罪。

    * 三个目的：窝藏赃物 / 抗拒抓捕 / 毁灭罪证。

    * 实行行为：当场使用暴力，或以暴力相威胁。

```text
第269条  事后转化抢劫罪
│
├─ 三个轻罪   ── 盗窃罪 / 诈骗罪 / 抢夺罪
├─ 三个目的   ── 窝藏赃物 / 抗拒抓捕 / 毁灭罪证
└─ 实行行为   ── 当场使用暴力，或以暴力相威胁
```

### 三个轻罪的认定标准

* **三个轻罪的范围**

    * > **结论**：法考标准不是"三种犯罪行为"，而是"具有财产犯罪属性"和"符合盗窃罪的构成要件"两个条件同时具备。

    * 第一条件：这个行为要具有财产犯罪的属性。

    * 第二条件：这个行为要符合盗窃罪的构成要件。

    * 要求财产犯罪属性的理由：要转化过去的是抢劫罪，抢劫罪是财产犯罪，属性相通才能转化。

    * 盗窃尸体不成立转化抢劫：盗窃尸体罪保护的是死者的名誉和生者家属的名誉，不是财产，既没有财产犯罪属性，也不符合盗窃罪构成要件。

    * 盗伐林木可以转化抢劫：林木就是财产，盗伐林木罪内蕴含一个盗窃罪，两个条件都满足。

    * > **易错点**：传统观点认为只要有"三种犯罪行为"之一即可转化。宁采臣在乱坟岗盗窃聂小倩尸体、被管理员狗蛋抓捕后为抗拒抓捕实施暴力，按"犯罪行为"标准会得出能转化抢劫的错误结论，一个反例即可否定该标准。

* **三大目的**

    * 目的必须是窝藏赃物、抗拒抓捕、毁灭罪证三者之一，缺一不可，之外的都不行。

    * 抢夺到假项链后扇耳光泄愤不构成转化抢劫：泄愤不是三大目的，也可能只是提醒对方着装（狄德罗效应——得到华丽睡袍后逐件更换鞋、地毯、书桌、书架，最后又整体换回原来的样子，因为不配套的整体更换下去会出问题）。

### 正常抢劫与事后转化抢劫的区分

* **区分标准是暴力的目的**

    * > **结论**：构成转化抢劫，暴力目的必须是三大目的之一；目的是继续取得财物、继续实现非法占有目的的，是正常抢劫。

    * 正常抢劫又称"临时起意、直接升级的抢劫"：我偷不成我就抢。

    * 行为与目的同时存在原则：同样一个暴力行为，看带着什么目的，由目的决定行为的定性。这个原则本科阶段不讲、一般教材也不讲，考试却经常考，主观题都考过。

    * 两个目的都有时，优先认定"继续取得财物"，因为非法占有目的是主要目的。

* **公交车上两种情形**

    * 扒手伸手进乘客口袋被当场抓住，一把尖刀顶到后腰说"放手"：目的既有抗拒抓捕又有继续取财，优先认定后者，按带着非法占有目的实施暴力威胁处理，定正常抢劫。

    * 乘客用太极推手扭住扒手胳膊将其抓住，扒手动弹不得，从口袋掏出刀刺来，乘客松手后其跑掉：使用暴力的目的只是抗拒抓捕，定事后转化抢劫。

### "当场"是时间概念

* **当场的时间性**

    * > **定义**："当场"是一个时间概念，不是一个空间概念；前面的盗窃行为与后面的使用暴力在时间上具有紧密联系性，即属当场使用暴力。

    * 传统理论把"当场"理解成时间和空间的结合，法考刑法不采。

* **时间紧密而空间错位**

    * 持续追捕案：歹徒抢夺男大学生手机后被追出 2 公里，跑不动时掏刀威胁。暴力威胁地点与抢夺地点相距 2 公里，不是同一空间，但持续追捕中间没有间断，存在时间纽带，仍属当场使用暴力，构成转化抢劫。

```text
t0 街边抢夺手机      t1 ← 持续追捕2公里，中间无间断 →      t2 跑不动了，掏刀威胁
└────────────── 时间纽带：前后两点紧密相连 ──────────────┘
   空间上相距2公里，不是同一现场；时间上紧密联系，仍然属于"当场"
```

* **空间同一而时间中断**

    * 珠宝盗窃既遂后隔夜被发现案：狗蛋带小弟入户偷走"海王之星"珠宝并已装进自带保险箱，次日小芳回家发现床上躺着小偷，狗蛋为抗拒抓捕打了小芳。前面盗窃确实既遂（把珠宝装进自己的箱子里就既遂，不要求拿出家门），但前后相隔整整一夜，没有当场性，不构成转化抢劫。

    * 该案两条路都走不通：只为抗拒抓捕、珠宝已盗窃既遂，不构成正常抢劫（正常抢劫要求为了继续取得财物）；因不具当场性也不构成转化抢劫。

    * 相应的处理：前面定入户盗窃罪，后面使用暴力把人打成轻伤的定故意伤害罪，两罪并罚。

* **一句话记"时空错位"**

    * "君住钱塘东，妾在临安北"：钱塘即杭州，秦朝叫钱塘，南宋叫临安，同一个空间却相隔千年，说明当场不能简单理解成"是同一现场"。

* **既遂标准的补充**

    * 同一结构下的判断只考虑时间：出单元门后在小区内打人属于时间上紧密联系，一般也就几分钟。

### 使用暴力与以暴力相威胁

* **使用暴力**

    * > **结论**："使用暴力"要求故意实施。

    * 跨栏踢倒栅栏砸伤追捕人案：狗蛋逃跑跨栏踢倒栅栏，栅栏倒后砸伤小芳，虽致人受伤但不是故意对小芳实施暴力，不构成转化抢劫。

    * 相应的处理：前面定盗窃罪；砸成重伤有过失的定过失致人重伤罪，没有过失的就是意外事件、不定罪，走民事赔偿。

* **以暴力相威胁**

    * > **结论**：必须是以暴力相威胁或相胁迫，以非暴力的都不算。

    * 反复脱裤子吓退追赶案：狗蛋反复脱裤子使小芳捂脸不敢追，被称作"视觉暴力"，不属于这里的暴力，不构成转化抢劫；这种行为有猥亵但没有"强制"，也不构成强制猥亵罪。

    * 对照：变态男当街脱裤子吓走妇女，只此一个行为不足以构成强制猥亵；追着对方一定要让人家看、自信豪放地脱，因有"强制"才构成强制猥亵罪。

* **恶害相恐吓的模型**

    * > **定义**：以恶害相恐吓是"你若不答应我的要求，我会对你施加恶害"，恶害必须加在对方身上。

    * "你再追我就抹我自己的脖子"：恶害加在自己身上，不属于以暴力相威胁，不构成转化抢劫。

    * "你再追我就捅死你"：恶害指向对方，属于以暴力相威胁，能够转化抢劫。

### 对象错误与打击错误

* **为抗拒抓捕而使用暴力的主客观要件**

    * > **结论**：核心要件就是一句话——为抗拒抓捕而使用暴力；这句话既有客观要件，也有主观要件。

    * 多数说（法考采用）：主观要件与客观要件都得打勾。除了主观上为抗拒抓捕使用暴力，客观上还要有现实的抓捕者在行动，打的就是一个抓捕者，主客观相一致，才能转化抢劫。

    * 少数说：这只是主观要求，客观上不作要求。

    * 误认贴小广告者为小芳丈夫：多数说下主观打勾、客观打叉（对方是贴广告的），不能转化抢劫；少数说下能转化抢劫。

    * > **提示**：这里讲的对象错误与总论里故意杀人罪的"认识错误"原理完全不一样，不要拿总论那一套来套，就按"为抗拒抓捕而使用暴力"这句话的满足条件处理。

* **打击错误下的实害对象**

    * 投掷飞刀偏了刺死二丫案：狗蛋为抗拒抓捕朝小芳扔飞刀，水平太差扔偏，把小芳旁边的二丫刺死。

    * 争议只在实害对象，预定目标根本没打中，两说对预定目标怎么处理没有争议。

    * 具体符合说：尊重案件事实、实事求是，案件是什么就是什么；狗蛋对二丫是过失，定抢劫罪过失致人死亡。

    * 法定符合说：为严惩凶手把过失拟制为故意，定抢劫罪故意致人死亡。

```text
                    狗蛋 扔飞刀（为抗拒抓捕而使用暴力）
                             │
              ┌──────────────┴──────────────┐
           预定目标                    实害对象
           小芳（未中）                 二丫（刺死）
              │                            │
      故意，属使用暴力            具体符合说：过失
      → 已成立转化抢劫              法定符合说：拟制为故意
              └──────────────┬──────────────┘
                两种观点都同意：定抢劫罪致人死亡
```

### 暴力的程度

* **足以压制对方反抗**

    * > **结论**：转化抢劫要求暴力程度足以压制对方反抗。

    * 理由：要转化的是抢劫罪，抢劫罪对暴力的要求就是这个高度，水涨船高。

    * 揉成团的报纸砸脸：不足以压制反抗，不构成转化抢劫；给定条件是报纸，不能擅自假设对方有内功、扔一片树叶也有威力。

    * 飞刀未中但已刺向被害人：即使没刺中，转化抢劫依然成立，因为这个飞刀已足以压制被害人反抗。

    * 飞刀刺中并把人钉死：成立转化抢劫，且属于抢劫罪致人死亡、抢劫罪故意致人死亡，因为这里没有打击错误。

### 转化抢劫的既遂标准

* **两种观点**

    * 多数说（法考采用）：看前面三个轻罪是否既遂，前面盗窃罪既遂了，转化抢劫就既遂。

    * 少数说：看最终转化成抢劫之后是否取得财物，案例中反击保安后被擒拿、财物被扣押，只能是未遂。

    * > **提示**：单选题问唯一正确答案时只能按多数说作答，开放式作答才可以各取一说。

### 共犯与身份

* **"犯盗窃者"是定罪身份**

    * 转化抢劫的实行行为是事后使用暴力，实施前罪（盗窃、诈骗、抢夺）只是前提事实。

    * "犯盗窃者"（犯诈骗者、犯抢夺者）是一种身份，只有拥有这种身份的人才能构成转化抢劫的实行犯，转化抢劫因此属于真正身份犯。

    * 调动身份犯的效果：没有该身份者既不能构成直接正犯，也不能构成间接正犯，只可能构成狭义共犯（教唆犯、帮助犯）。

    * 标准案例的前提事实：甲单独盗窃并且既遂，在逃离现场时乙参与进来。

* **四种参与形态**

    * 情形一 乙教唆甲打抓捕者：甲是转化抢劫的实行犯，乙是转化抢劫的教唆犯。

    * 情形二 甲教唆乙断后：乙不是"犯盗窃者"，不具备定罪身份，不能定实行犯；没有实行犯，甲就不能定教唆犯，只能定转化抢劫的间接正犯，因为间接正犯不要求搭配实行犯；乙可以定转化抢劫的帮助犯。

    * 情形二的补充：乙打人把主人打成轻伤的，另构成故意伤害罪实行犯，甲构成故意伤害罪教唆犯；抢劫更重，最终定抢劫。

    * 情形二同构：总论间接正犯中的虐囚案——狱警教唆囚犯甲虐待囚犯乙，囚犯甲不是监管人员，定不了实行犯；没有实行犯，狱警也定不了教唆犯，只能被扶上间接正犯的宝座。

    * 情形三 甲欺骗乙"防卫"：乙构成假想防卫，不构成转化抢劫；假想防卫不可能是故意，有过失定过失犯罪，没有过失就是意外事件；甲定转化抢劫的间接正犯，因为利用了不知情的乙作工具。

    * 情形四 乙暗中相助而甲不知情：甲不知道身后有人断后，不构成转化抢劫，只定盗窃罪且既遂；乙没有"犯盗窃者"身份，定不了实行犯；帮助犯不能单独存在，甲不构成实行犯，乙连帮助犯也不构成。

    * 情形四对片面帮助犯的追问：片面帮助犯必须说清是谁的什么罪的片面帮助犯；不可能是甲的转化抢劫的片面帮助犯，因为甲不构成转化抢劫。

    * 情形四的前置障碍：盗窃罪已经既遂，既构不成盗窃罪的事前帮助犯，也构不成承继共犯，因为承继共犯要求中途在既遂之前介入。

    * 情形四的结论：乙打伤主人的构成故意伤害罪；明知甲在犯罪而帮他逃匿的构成帮助犯罪人逃匿，定窝藏罪；两个罪整体是一个行为，想象竞合，从一重罪论处。

    * 窝藏罪要扩大理解：法条说的是帮助犯罪分子逃匿，不限于把犯罪分子藏在家里。

### 共犯与实行过限

* **知情加参与**

    * > **结论**：判断标准是知情加参与——又知情又参与，要对转化抢劫负责；只是知情而不参与，不用负责。

    * 情形一 甲入室盗窃在屋里打人，乙在外面望风不知情：甲转化抢劫，乙在盗窃罪范围内定帮助犯；若乙知道里面打起来了还继续望风，就构成甲转化抢劫的帮助犯。

    * 情形二 甲在屋里盗窃，乙在外面望风被保安发现而打保安，甲在屋里不知情：乙虽是帮助犯也能转化抢劫，因为"犯盗窃者"身份既包括实行犯也包括帮助犯；甲只定盗窃罪，两人在盗窃罪的范围内构成共同犯罪。

    * 情形三 甲盗窃既遂后逃跑，乙在望风处为主人实施暴力断后，甲不知情：乙有"犯盗窃者"身份，可以转化抢劫；虽然暴力目的是保护同伙甲而不是保护自己，但只要是对抓捕者使用暴力就行；甲只定盗窃罪。

    * 情形三的前提条件：给定条件是甲乙事先没有商量，只约定了共同盗窃；若事先约定"我进去偷，你望风，万一主人抓我你要帮我断后"，甲也要跟着转化抢劫。

## 抢劫罪的法定刑升格条件

### 入户抢劫

* **"户"的认定**

    * > **定义**：入户抢劫中的"户"，指与外界相对隔离的生活场所。

    * 户不要求固定不动，房车、渔船都算户；渔民常年以渔船为家，渔船同样是户。

    * 小卖部一类的经营性场所不能凭名称认定，要看闯入的那一刻它处在什么状态。

    * 24 小时接客的房间：能随时在营业状态与生活状态之间切换、实际上大部分时间处在接客状态，就按营业状态认定为工作场所，不算"户"，不构成入户抢劫。

* **入户抢劫的判断链**

    | 顺序 | 条件 | 不满足时 |
    | :--- | :--- | :--- |
    | ① | 场所是"户" | 营业中的小卖部、营业状态的房间不算户 |
    | ② | 入户是非法的，目的是实施人身犯罪、财产犯罪 | 合法入户后在户内抢劫，只定"在户内抢劫" |
    | ③ | 暴力（胁迫）行为发生在户内 | 骗出门、隔空扫射、轰塌后进入，都不构成 |
    | ④ | 行为人当时认识到这是"户" | 不一定构成入户抢劫 |

* **条件二：合法入户后抢劫**

    * 狗蛋儿送小芳回家，上楼后把人家家里东西全抢走：定在户内抢劫，学理上称"引狼入室"。

    * > **易错点**：合法入户之后再在户内抢，是入户抢劫里最容易丢分的一个坑。

* **条件三：暴力必须发生在户内**

    * 骗小芳说"张艺兴在你家门外等你"把她骗出门外再抢：不算入户抢劫。

    * 在门外架机枪扫射把人逼出来再抢：不算，入户抢劫要求行为人身体入进去，这是身体没入进去、子弹入进去。

    * 用炮把房子轰塌再跳进去抢：更不算，虽然身体入进去了，但户已经没了，跳进去的是废墟，入废墟不是入户。

    * > **提示**："暴力发生在户内"看的是暴力行为与户的空间关系，不是暴力强度、不是暴力对象、也不是暴力结果。

* **转化型入户抢劫**

    * > **结论**：转化抢劫与入户抢劫撞在一起时按顺序处理——先分析转化抢劫，再回来认定入户抢劫。

    * 入户盗窃被发现、逃跑被追赶，在户内为抗拒抓捕使用暴力：成立转化型抢劫，暴力发生在户内，认定为入户抢劫。

    * 逃出户外后被追赶，在户外为抗拒抓捕使用暴力：成立转化抢劫，但暴力不发生在户内，不构成入户抢劫。

    * > **易错点**：转化抢劫成立之后不要顺势就认定入户抢劫，一定要回头核一遍暴力行为发生的位置在户内还是户外。

### 在公共交通工具上抢劫

* **范围与空间**

    * > **结论**：公共交通工具不包括小型出租车、普通出租车和网约车，这里做缩小解释，一般指公交车、旅游大巴这一类。

    * > **定义**：在公共交通工具上抢劫，既包括上车后当场实施抢劫，也包括针对车上的人实施抢劫。

    * 拦路威胁司机把全部乘客赶下车、在车下逐个抢劫的，仍属于在公共交通工具上抢劫；为规避升格而"不上车"并不能跳出这个范围。

    * 转化型抢劫与升格条件结合的判断原理在这里同样适用。

### 抢劫罪致人重伤、死亡

* **致人重伤死亡的对象范围**

    * 抢劫罪致人重伤的人，不仅包括财产的主人，还包括前来阻挡的第三人。

    * 理由：抢劫罪是财产犯罪，保护财产法益，财产法益不具有人身专属性、具有可替代性，换一个人承担被害并不会让财产法益受到额外的、不可挽回的损害。

    * 强奸罪致人重伤的人，只能包括被害的那个妇女；理由是强奸罪保护人身法益，人身法益具有人身专属性、具有不可替代性。

    * 强奸案中打伤阻拦第三人的处理：对被害人构成强奸罪；对第三人的奸淫行为按强制猥亵罪处理，打伤的行为构成故意伤害罪，各算各的账，独立行为都要并罚。

    * > **提示**：结果加重犯中"致人重伤死亡"的对象范围跟着该罪保护法益的性质走——财产犯罪可替代、人身犯罪不可替代。这是通用钥匙，不是两个孤立的结论。

* **其他升格条件**

    * 抢劫银行、多次抢劫相对简单，靠记。

    * 冒充军警人员抢劫、持枪抢劫、抢劫军用物资、抢险物资，相比前面相对不重要。

## 抢劫罪与绑架罪

### 区分标准是主观目的

* **两罪的区分**

    * > **定义**：两罪的实行行为可以完全相同——都可以是劫持，都可以是实力控制。

    * > **结论**：区分标准是主观目的——带着向第三人要钱的目的是绑架罪，带着向被劫持人本人要钱的目的是抢劫罪。

    * 劫持乙在地下车库后直接向乙要钱：定抢劫罪。

    * 劫持乙在地下车库，以"撞人赔钱"骗乙妻把钱打到卡上，乙把钱给甲后释放：仍是抢劫罪，拿到钱即既遂。

    * 劫持乙到山谷，让乙通知其母亲送钱赎人：定绑架罪，把人绑到手就既遂。

    * 同一山谷案中乙骗母亲说自己开车撞了人需要赔钱：仍定绑架罪，骗取汇款只是索财手段的变形，不改变甲已经确定的主观目的。

    * > **易错点**：用"三角关系、两角关系"判断只是部分适用的常见情形，不是真正的标准。真正的标准是主观目的，行为与目的同时存在，以目的定罪。

* **陷阱设置的位置**

    * 陷阱藏在这两句话的先后顺序上：第一句只交代劫持，最多只能推出非法拘禁；第二句交代向谁要钱，才暴露出真实目的。

    * "劫持到山谷"那道真题错误率相当高，官方解析专门写了一大段说明真正的区分标准在于主观目的。

### 中立关系与想象竞合

* **两罪是中立关系**

    * > **结论**：绑架罪与抢劫罪是 A 与 B 的中立关系，可以想象竞合，不是有区分就对立排斥。

    * 关系的类型：男生/女生是 A 与非 A 的对立排斥关系，只能二选一；本科生/硕士生是 A 与 B 的中立关系，可以竞合。

    * 推导方法：案件事实一定要想象成一个多面体，不要想象成一个面、一条线，要从不同侧面去提炼、去评价。

* **夺孩子向母亲索财的模型**

    * 侧面一（被害人是孩子）：把孩子劫持做人质、向第三人（母亲）要钱，构成绑架罪。

    * 侧面二（被害人是母亲）："你不给钱我就捅死你孩子"属于以恶害相通告，足以压制母亲不敢反抗，当场向母亲取到钱，构成抢劫罪。

    * 侧面二的补充：所谓"以暴力相威胁"，指的是以恶害相通告——你若不答应我的要求，我会对你或你的亲人施加恶害，由此让你产生恐惧心理、让你不敢反抗。

    * > **结论**：同一行为从不同侧面评价，同时构成绑架罪与抢劫罪，整体是一个行为，想象竞合，择一重罪论处。

## 敲诈勒索罪

### 四部曲

* **四步行为结构**

    | 步骤 | 内容 | 意义 |
    | :--- | :--- | :--- |
    | 第一步 | 带着非法占有目的实施恐吓行为 | 这一步实施到位，敲诈勒索罪就成立 |
    | 第二步 | 使对方产生恐惧心理 | 恐吓行为起作用 |
    | 第三步 | 使对方基于恐惧心理而交付财物 | 最核心的一步 |
    | 第四步 | 行为人因此而取得财物 | 走到第四步，敲诈勒索罪才既遂 |

    * 四步按顺序走，一步都不能跳；刑法认定一个罪名不看"干了什么"，而看按什么顺序把被害人推到了哪一步上。

    * 按这个链条就能解释：为什么有人明明把钱要到了手还只构成未遂，为什么有人当场就把钱拿到了手反而还是敲诈而不是抢劫。

### 恐吓行为

* **以恶害相通告**

    * > **定义**：恐吓行为的模型是以恶害相通告——你若不答应我的要求，我就对你施加恶害，由此产生恐惧心理、基于恐惧交付财物。

    * 敲诈、恐吓、胁迫、威胁其实是一个意思。

    * 施加的恶害通常就是钱。

    * 以裸照威胁交付金钱的案例，属于典型的恐吓勒索。

    * > **结论**：恐吓行为不要求当场实施，也不要求使用暴力，只要"以恶害相通告"这个模型跑通。

* **谈条件不等于恐吓**

    * 捡到身份证索要"三天内不给钱就不还身份证"不构成敲诈勒索罪。

    * 理由：虽然有谈条件和不利后果，但没有达到让人恐惧的程度，丢个身份证补办一个就行。

    * 达不到恐惧程度的，按民事侵权或者行政违法行为处理。

    * > **易错点**："谈条件"只是表层现象，恐吓行为真正要检验的是对方是否产生了恐惧心理。

### 第三步是既遂的卡点

* **基于恐惧心理而交付财物**

    * > **结论**：核心是第三步。第三步不成立时，无论行为人是否实际拿到财物，都只构成未遂。

    * 陈浩南案：被"三天内不打钱小心卸你一条腿"敲诈后，因铜锣湾只有他一个陈浩南、从未被人敲诈，出于欣赏与爱才心理给对方打了一万元。钱到手，但第三步打叉，仍是未遂。

    * 裸照与指定地点案（真题）：小芳报警后按警方指示把钱放到指定地点离开，她是基于配合警方抓捕的心理交付财物，第三步打叉，未遂。

    * 同一案的引申：狗蛋装完钱后即使冲出重围、拿着钱跑路未被追上，结论一样，仍是未遂。

### 与抢劫罪的区分

* **唯一的区分标准**

    * > **定义**：真正的区分标准只有一个——被害人意志自由被剥夺的程度。

    * 抢劫是完全剥夺自由、压制反抗，没得选，只好给。

    * 敲诈勒索是部分剥夺自由，没有压制反抗，保留了一定选择，有的选但最好给。

    * "当场取财"标准是常见情形而非必要条件：黑社会收保护费本来约定下星期交，店老板要求当场交钱以免被算作抢劫，黑社会当场取钱仍然构成敲诈勒索罪。

    * 这与把"秘密性"当成盗窃罪必要条件是同一类逻辑陷阱——把常见情形当成了必要条件。

* **五种情形挨个过标准**

    | 情形 | 甲的威胁 | 被害人乙的处境 | 结论 |
    | :--- | :--- | :--- | :--- |
    | 一 | 不给钱，就先扇一耳光 | 达不到压制反抗的程度，仍有的选 | 敲诈勒索 |
    | 二 | 后天不给钱，后天就放你的血 | 后天才放血，还有选择余地 | 敲诈勒索 |
    | 三 | 现在不给钱，现在就放你的血 | 当场不给当场放血，没得选 | 抢劫 |
    | 四 | 现在不给钱，后天放你的血 | 还有两天思考时间，选择自由还在 | 敲诈勒索 |
    | 五 | 不答应就后天给钱，我现在就去放你的血 | 答应了还来得及，后天给钱 | 敲诈勒索 |

    * 情形一对应"敲诈不能有暴力"的误解：敲诈可以有暴力，只是这个暴力不能达到压制反抗的程度，仅是一记耳光只是警告，被害人还是有的选、最好给。

    * 情形三与情形四差别只在时间点：只有"现在不给钱、我当场就对你施加暴力"才没得选，才可能构成胁迫性的抢劫。

    * > **结论**：要构成抢劫，胁迫手段必须是"你现在不给钱，我当场就对你施加暴力"——只有当场取财，才能达到压制反抗的程度。

* **教材上三条标准的态度**

    * 主体不同（抢劫 14 岁、敲诈 16 岁）：标准本身没错，但法考不会靠它考区分。

    * 抢劫有暴力、敲诈不能有暴力：后半句错，敲诈也可以有暴力，只是不能达到足以压制反抗的程度。

    * 抢劫必须当场取材、敲诈只能日后取材：前半句对，后半句错。

    * 做题要找唯一的最核心的、通用的区分标准；标准太多反而起干扰与破坏作用。

* **民国赌场的割肉混混**

    * 衣衫褴褛的混混闯上赌桌，撩起裤腿用圆月弯刀割下一块大腿肉扔到桌上，赌客作鸟兽散，赌场老板拿银票赔笑打发，构成敲诈勒索罪。

    * 理由：割肉流血只是警告，赌场老板仍是有的选、最好给，识相的赶紧给钱还能保住这条腿；不是卖肉、不是强迫交易。

    * 若把刀架在赌场老板脖子上说"现在不给钱就要你的老命"，压制反抗、没得选，就已经是抢劫罪。

### 与行使权利的区分

* **两步判断**

    * > **结论**：敲诈勒索罪与行使权利的区分标准，就是看是否符合刑法上敲诈罪的成立条件。

    * 第一步看有没有非法占有目的，判断依据是有没有事实依据和法律依据；没有就不可能构成敲诈，有了也还不一定构成。

    * 第二步看有没有恐吓行为；没有恐吓行为也不够，有了才最终构成。

    * 有非法占有目的只是成立条件之一，是必要条件，不是充分条件。

* **请求权的有无是分水岭**

    * 哈根达斯小布条案：索赔 10 万元精神损害赔偿并威胁曝光。事实依据有（吃出小布条），法律依据有（民法有精神损害赔偿这一项），有权利基础就证明没有非法占有目的，不构成敲诈罪。

    * 漫天要价不重要，重要的是有没有请求权；民事纠纷本来就可以漫天要价、由法官居中裁判。

    * 500 万青春损失费案：民法上没有青春损失费这一项，没有请求权基础，说明有非法占有目的；又有"不给钱就曝光视频"的恐吓行为，最终构成敲诈勒索罪。

* **道德标准靠不住**

    * 有人因为同情第三者认为不构成，有人因为第三者知三当三认为构成，用道德标准就是莫衷一是。

    * > **结论**：我们是刑事法庭，不是道德法庭，判断标准就是刑法规定的敲诈勒索罪成立条件。

* **一哭二闹三上吊**

    * 声称有非法占有目的，但手段绝不使用恐吓，以"不给钱就上吊"相要挟，对方信以为真而给钱，得钱又完美规避犯罪——不构成恐吓行为，因而不构成敲诈勒索罪。

### 与诈骗罪的关系

* **可以竞合**

    * > **结论**：敲诈勒索罪与诈骗罪不是 A 与非 A 的对立排斥关系，可以竞合，结论是想象竞合、择一重罪论处。

    * 底层原理：人因"相信"而恐惧，不相信就不会恐惧；一旦所相信的事情是假的，就同时产生认识错误、同时被骗，恐惧心理与认识错误相伴相生。

    * P 出来的裸照案：先当面核实裸照再生出恐惧心理并打钱，同时构成敲诈勒索罪与诈骗罪，想象竞合，择一重罪。

    * 冒充会所小王逐个致电官员索钱案：既构成敲诈勒索罪又构成诈骗罪，想象竞合，择一重罪论处。

### 与编造恐吓信息型诈骗的区分

* **只定诈骗的情形**

    * > **结论**：被害人产生了恐惧心理，不等于行为人构成了敲诈勒索罪；恶害必须由行为人本人以恶害相通告。

    * 案例：狗蛋谎称铁牛得罪了黑社会老大、下个月要被卸一条腿，称自己与该老大关系不错、收 5000 元帮他摆平。

    * 只构成诈骗罪，不构成敲诈勒索罪：恐吓的来源是第三人黑社会老大，不是行为人自己；行为人给的是"我帮你摆平"，是把恶害挡在门外，不是"不给钱我就对你施加恶害"。

    * > **易错点**：借第三人编造的恶害去吓人，是编造恐吓信息型诈骗，只定诈骗罪。

## 诈骗罪

### 五部曲

* **五步行为结构**

    | 步骤 | 内容 | 对应的人 |
    | :--- | :--- | :--- |
    | ① | 带着非法占有目的实施欺骗行为 | 甲：行为人 |
    | ② | 使对方产生认识错误，或维持、强化已有的认识错误 | 乙：受骗人 |
    | ③ | 对方基于认识错误而处分财物 | 乙：处分人 |
    | ④ | 行为人因此取得财物 | 甲：行为人 |
    | ⑤ | 对方遭受财产损失 | 丙：受害人（可能就是乙） |

    * 第一步实施，诈骗罪就已成立；一路顺利走到第五步，诈骗罪既遂。

    * 骨架是"骗—错—处分—取得—损失"五个齿轮咬合；诈骗罪与盗窃罪的黄金考点全部压在第三步。

### 欺骗行为

* **骗什么**

    * > **结论**：欺骗的内容主要指向事实判断；原则上，对价值评价的内容去骗人，不好说是欺骗欺诈。

    * 婚介所案对比：广告承诺"美若天仙的单身女子"，介绍来的人根本不是单身或根本不是女子，构成欺骗；只是不够美属价值评价，每人心中标尺不同，不构成欺骗。

* **怎么骗**

    * 作为的欺骗是虚构事实，不作为的欺骗是隐瞒真相。

    * > **定义**：隐瞒真相就是不履行告知真相的义务——人家有权问，你就有义务答，缄口不言本身就是一种欺骗。

    * 办健康险、长寿险时隐瞒肺癌、肝癌、胃癌、肠癌、食道癌、直肠癌骗取保险金，属于不作为的欺骗。

* **骗的类型**

    * 一种是让对方从无到有产生认识错误。

    * 一种是让对方维持、强化已有的认识错误，后者同样属于欺骗的类型。

* **骗到什么程度**

    * "我是秦始皇，请打钱"不构成诈骗，因为欺骗程度不足以使一般人相信。

    * 刑法保护很傻很天真的人，但不保护太傻太天真的人，判断基准是一般人。

    * 骗子编造到足以使一般人相信的，仍然可以构成诈骗罪。

### 认识错误的对象

* **被骗的必须是人**

    * > **结论**：欺骗幼儿的钱、欺骗精神病患者的钱，即使具有公然性，也定盗窃罪而不定诈骗罪，这叫公开盗窃。

    * 理由：幼儿和精神病患者没有意识自治能力，他们产生的认识错误不算数，诈骗罪的链条接不上，剩下的只有盗窃罪。

* **机器不能成为诈骗的对象**

    * > **结论**：机器不能成为诈骗罪的对象，法考按多数说处理。

    * 铁片骗自动售货机出饮料、用假币喂售货机、伪造门票过闸机，都是盗窃：机器没有认识能力，骗不了它，只能把财物直接拿走。

    * 人工智能再聪明也解决不了：阿尔法狗不知道自己是谁、在干什么，没有自我意识；机器出错、程序出错不叫有自我意识基础上的错误认识。

    * 有自我意识也不够：幼儿有自我意识但没有意识自治能力，认识错误不算数，仍然不构成诈骗。

### 财产损失

* **成立与既遂的层次**

    * > **结论**：成立诈骗罪，要求有让对方遭受财产损失的危险性；成立诈骗罪既遂，要求对方实际有财产损失这个实害结果。

    * 这是故意犯罪的通例：犯罪成立的条件是对法益产生危险，犯罪既遂的条件是对法益制造实害。

* **整体财产说与个别财产说**

    * 案例：花 200 元买"柏浪涛刑法四件套"，到货却是母猪产后护理、如何防止老年痴呆、如何防止被骗，经鉴定也是正版、也值 200 元。

    * 整体财产说：不吃亏，没有财产损失。

    * 个别财产说（多数说、法考采用）：花的是冤枉钱，构成财产损失。

    * > **定义**：这就是目的落空理论（目的失败理论）——花这笔钱的目的没有实现，所以花的是冤枉钱。

    * 销赃场景：把赃车谎称自己的车按正常二手价卖给不知情的买家，整体财产说无损失，个别财产说认为买到权利有瑕疵的物品、花了冤枉钱，诈骗罪既遂。

    * 赃物渠道出手、买家心照不宣的，买家没有损失。

### 与盗窃罪的区分

* **第三步的两个要件**

    * > **结论**："基于认识错误而处分财物"是主客观相一致的概念，客观上要有处分行为，主观上要有处分意识，缺一不可。

    * 审查两步走：先看被害人有没有把占有转移给行为人（处分行为），没有直接定一号盗窃；有则看被害人是否意识到该财物的现实存在，没有定二号盗窃，有则定诈骗罪。

    * 最后定盗窃罪时，还要能判断出是一号还是二号。

* **处分行为就是转移占有**

    * > **定义**：处分行为就是处分占有，即被害人把自己占有的财物转移给对方占有——我失去占有，让你占有。

    * 骗柜台员回头看帅哥后顺走珠宝：骗了，但对方根本没有把珠宝交给你，没有处分占有，定盗窃罪。

    * 说"这珠宝我买"、对方包好交出，付的却是印着玉皇大帝的冥币：客观上对方亲自实施转移占有，构成诈骗罪。

* **处分意识要求意识到财物的现实存在**

    * > **定义**：处分意识是意识到该财物是现实存在的、自己正在占有它，并意识到现在要把它交给对方处分。

    * 调包案：把照相机装进饼干箱替换。客观上收银员把箱子交给甲、处分了照相机；主观上他连箱子里有照相机都不知道，未意识到其现实存在，没有处分意识，不构成诈骗，定盗窃罪。

    * 调换价签案：把 2000 元便宜相机的价签对调到 2 万元贵重相机上，且给定相机没有外包装盒、没有包装袋，收银员能直接看到相机机身和价签。客观有处分行为，主观也意识到相机存在并要交给甲，构成诈骗罪。

* **认识错误与处分意识是两个心理活动**

    * 处分意识只要求意识到该财物的现实存在，并不要求意识到它真正的价格和真正的数量。

    * 认识错误主要是对财物的数量、价格有错误认识，它是引发处分行为、处分意识的动因。

    * 反过来推也通：对价格数量都有正确认识，说明没有上当受骗，人家就不可能被骗成处分财物的样子。

    * > **提示**：既要求被害人有一个"认识错误"的心理活动（对数量、价格的错误认识），又要求一个"处分意识"的心理活动（意识到财物现实存在、我要交给对方），两个心理活动各管各的，千万别搅在一起。

* **五种现场训练情形**

    | 情形 | 客观处分行为 | 主观处分意识 | 定性 |
    | :--- | :--- | :--- | :--- |
    | 骗柜台员回头看帅哥后顺走 | 无 | — | 一号盗窃 |
    | 谎称"你家孩子被人打了"骗小芳下楼后拿走财物 | 无 | — | 一号盗窃 |
    | 谎称"老师可能都忘记这张邮票了"、请求送书连带拿走夹在书里的邮票 | 有 | 无 | 二号盗窃 |
    | 取出照相机包装盒里的泡沫材料、塞入超市要卖的手机，收银员按标价 2000 元收款并交付箱子 | 有 | 无 | 二号盗窃 |
    | 菜市场买西瓜被短斤少两多收 18 斤的钱 | 有 | 有 | 诈骗罪 |

    * 买西瓜案的三个要件都齐：客观上有处分钱的行为，主观上有处分这多余的钱的意识，而这个处分是基于对西瓜重量的错误认识。

    * 买菜买水果短斤少两的，一般都按欺诈、诈骗处理。

* **处分资金的三个案例**

    * 点"成为会员"链接导致 1 万元被划走：客观有处分资金的行为，主观没有处分资金的意识（以为只是点链接办会员），二号盗窃。

    * 点链接"支付一元钱成为 VIP"、实际划走 10001 元：客观有处分 10001 元的行为，但小芳只有处分 1 元的意识，对 10001 元缺处分意识，二号盗窃。

    * 饭店 POS 机多输一个零、3000 元变成 3 万元：客观有处分 2.7 万元的行为，主观只意识到要付 3000 元，对 2.7 万元无处分意识，二号盗窃。

    * 二号盗窃与诈骗罪极其相似：已经具备诈骗罪的所有要件，只缺一个主观处分意识。

### 三角诈骗

* **受骗人与受害人的关系**

    * > **结论**：受骗人和处分人必须是同一个人；受骗人和受害人不是同一个人也可以，不要求——后者就是三角诈骗。

    * "基于认识错误"说明你是受骗人，"处分财物"说明你是处分人，两者合一简称为受骗人；只上当受骗却没把财物处分给对方，或处分了却没上当受骗，都不是诈骗。

* **处分人资格是分水岭**

    * > **结论**：看受骗人有没有处分受害人财物的权利地位；有则构成三角诈骗的诈骗罪，没有则行为人构成盗窃罪的间接正犯。

    * 保姆案：甲谎称干洗店老板来取衣，保姆把主人乙的衣服给了甲。基于职业习惯，保姆有处分主人衣服的权利地位，是合格处分人，其处分就相当于代表主人处分，甲构成三角诈骗的诈骗罪。

    * 店员取衣案：甲真的到乙家院子取衣，店员不具有处分乙财物的权利地位，不构成诈骗，甲构成盗窃罪的间接正犯——利用不知情的店员作工具实施盗窃。

    * 做题方法：先找出受骗人，再看他有没有处分受害人财物的权利地位。

* **超市小票案**

    * 大妈付款后把小票扔进纸篓，男子捡起小票追上谎称东西是他的，保安核对小票后要求大妈归还，大妈在不明真相群众注视下把东西扔给了他。

    * 犯罪人是男子，受害人大妈，受骗人是超市保安；保安没有处分大妈财物的权利地位，不构成三角诈骗，也不构成诈骗罪。

    * 男子构成盗窃罪的间接正犯，且是完全公开的盗窃：当着保安和一群群众的面明目张胆取走财物。

    * > **易错点**：僵化地要求"盗窃必须秘密"，这个男子就既不构成盗窃也不构成诈骗，会出现处罚漏洞；盗窃并不以秘密窃取为必要条件。

### 盗窃、诈骗、侵占三罪的区分

* **三罪一起考的原因**

    * 侵占罪、盗窃罪、诈骗罪都是平和手段取得他人财物的犯罪，都是不通过暴力把人财物抢走就取得他人财物，经常一起考。

* **借打手机的四个模型**

    | 模型 | 有无非法占有目的 | 借出有无处分占有 | 定性 |
    | :--- | :--- | :--- | :--- |
    | 一 | 一开始就有 | 没有（当众打，紧密占有→松弛占有） | 盗窃罪（一号盗窃） |
    | 二 | 一开始就有 | 有（让对方拿回家，失去占有） | 诈骗罪，名为借实为骗 |
    | 三 | 一开始没有，打完才产生 | — | 盗窃罪 |
    | 四 | 一开始没有，借后才产生不法所有目的 | —（合法借到手） | 侵占罪，占有变所有 |

    * 模型一：出借只是把紧密占有变成松弛占有，乙最多是持有者、握有者、占有的辅助者，并没有失去占有；甲拿离饭馆是转移占有，盗窃罪。

    * 模型二：让对方拿回家借打三天，等于让人家拿离现场，对方失去占有、让对方占有，有处分占有，成立名为借实为骗的诈骗罪。

    * 模型四：合法借到手合法占有，之后不还，是把他人所有、自己合法占有的财物变成自己所有、据为己有，成立侵占罪。

    * 读表一句话：定性全看两个开关——出借时有没有处分占有、一开始有没有非法占有目的。

* **最爱考的两种组合**

    * 一 + 二：关键看出借行为到底有没有处分占有；没有是盗窃，有是诈骗。

    * 二 + 四：关键看一开始有没有非法占有目的；二是一开始就有，名为借实为骗的诈骗；四是合法借到手最后不想还的侵占。

    * "一开始有没有非法占有目的"是主观心理状态，必须根据题干仔细审题推定。

### 调包案

* **占有前调包定盗窃**

    * 趁店员招呼其他顾客，把事先准备好的假中华与柜台上的真中华对调，随后说"我不买了"离开。

    * 店员只是由紧密占有变成松弛占有，并没有失去占有；把真烟转移到自己包里，盗窃罪。

    * 总结：行为人在自己占有前调包，自己还没占有就把真货转移为自己占有，定盗窃罪。

* **占有后调包定诈骗**

    * 稻米案：乙把新稻谷运到甲的米业工厂约定三天后取货，甲用陈年大米加工的大米冒充新大米交付。

    * 第一件事：把乙所有、甲占有的新稻谷藏起来据为己有，构成侵占罪。

    * 第二件事：以陈米冒充新米交付，免除了返还新大米的义务，构成诈骗财产利益，成立诈骗罪。

    * 两罪不并罚：只造成一份财产损失、甲只获得一份好处，按吸收犯原理重罪吸收轻罪，诈骗罪重，定诈骗罪。

* **调换主板定诈骗**

    * 买手机后拆下新主板换上废旧主板，装配好以"七天无理由退货"要求全额退款。

    * 拆换新主板本身不构成犯罪，那是自己花钱买来的东西，砸了也不犯法。

    * 构成犯罪的是拿废旧主板冒充新主板要求退货退款，成立诈骗罪。

### 送快递的四个模型

* **四种情形**

    | 模型 | 情形 | 定性 |
    | :--- | :--- | :--- |
    | 一 | 快递员放在收件人乙家门口，邻居甲拿走（已进入乙的实际控制范围） | 盗窃罪 |
    | 二 | 快递员错放甲家门口，甲明知收件人是乙仍据为己有 | 侵占罪 |
    | 三 | 快递员上门核对身份，甲隐瞒真相冒领 | 诈骗罪，被骗的是快递员 |
    | 四 | 快递员在运送途中拆开包裹取走内容物 | 盗窃罪 |

    * 模型一的理由：放到乙家门口时按生活观念已进入乙的实际控制范围，乙在占有，甲拿走是转移占有。

    * 模型二的理由：快递放到甲家门口，按生活观念甲在占有，但权利人是乙；甲据为己有是占有变所有，侵占罪。

    * 模型四的理由：这种包裹一般包装严密、标识隐私，属于封缄物，快递员只占有外形物、不占有内容物，打开取走内容物是盗窃罪。

## 职务侵占罪

### A 加 B 的罪名结构

* **与贪污罪的对应**

    * > **定义**：职务侵占罪 = 单位职员 + 利用职务便利 + 侵占本单位的财产。

    * 贪污罪是国家工作人员贪国家的钱；职务侵占罪是私营单位、私营公司的职员贪本单位的钱。

    * 行为主体：必须是某个公司、企业单位的职员，而且不能是国家工作人员。

    * 行为对象：必须是这个单位自己的财产，既不能是国家的财产，也不能是某个个人的财产；单位财产包括其资产、股份等。

* **A 与 A 加 B**

    * 多数说（法考采用）：职务侵占罪的实行行为同样包括侵吞、窃取、骗取，即侵占、盗窃、诈骗。

    * 极少数说：只包括侵占。

    * A = 侵占罪 / 盗窃罪 / 诈骗罪；A + B = 职务侵占罪。

    * B1 行为主体：单位的职员；B2 行为对象：单位的财产；B3 行为方式：利用职务便利。

    * 判定路径：先定 A，再把 B1、B2、B3 逐项打勾或打叉；全勾升级为职务侵占罪，任意一项打叉就退回 A。

    * B1、B2、B3 中最容易考、也最容易翻车的是 B3 利用职务便利。

### 利用职务便利的两个考点

* **职务**

    * > **结论**：职务要求具有一定管理性，不包括纯粹的体力性劳务。

    * 物流公司的搬运工、装卸工、分拣工把手上的一批货物悄悄拿回家：没占有的定盗窃罪，占有的定侵占罪。

    * B1 打勾（单位正式职员）、B2 打勾（单位财产）、B3 的"职务"打叉（纯体力劳动），升级不成职务侵占罪，只能退回 A。

* **利用**

    * > **结论**：利用职务便利要求的是实质性的利用。

    * 正例：财务总监利用职权把单位一笔资金倒划到个人账户。倒划本质是盗窃；"职务"打勾（具有管理性），"利用"是实质性利用，B3 打勾，升级为职务侵占罪。

    * 反例：财务总监凭身份混个脸熟走进后勤仓库，顺走一个珍贵小零部件再大摇大摆走出——形式性的利用，B3 打叉，退回普通盗窃罪。

    * 区分口诀："能进得去、拿得着"只是形式利用；"凭这个职务本身的权限去支配、去处置"才是实质利用。前者的便利来自身份带来的人缘，后者来自职权。

    | 对照项 | 形式性的利用 | 实质性的利用 |
    | :--- | :--- | :--- |
    | 财务总监的两种动作 | 吹着口哨走进后勤仓库，顺走一个小零部件 | 把单位一笔资金倒划到自己的个人账户 |
    | 利用的是什么 | 身份带来的混个脸熟、方便进出 | 职权本身对单位财物的支配、处置 |
    | B3 判定 | 打叉 | 打勾 |
    | 结论 | 退回普通盗窃罪 | 升级为职务侵占罪 |

### 真实案例与三处检讨

* **博士生实习生的无罪辩护**

    * 博士生到科技公司做实习生，深得老板信任并被委托到外地采购原材料，把公款、采购款私吞，案发后被控职务侵占罪。

    * 年轻律师以"实习生不是私营公司的正式职员、三险一金没交、劳动合同没签"为由做无罪辩护，职务侵占罪真的被打掉了。

    * 结果：改判诈骗罪，而且当时诈骗罪比职务侵占罪要重；家属投诉，律师受到了一定处分。

    * > **结论**：正确的结论是既构成诈骗罪，又能升级为职务侵占罪，按特殊法优于一般法最终应定职务侵占罪。

* **律师栽跟头的三处**

    * 第一处 行为主体：把"单位职员"看成了编制问题。公司职员身份不看正式编制、不看劳动合同、不看三险一金这些形式，只看实质——有没有从事公司的职务、有没有从事具有管理性的职务；采购业务绝对具有管理性，所以实习生也是单位职员，行为主体打勾。

    * 第二处 法律关系：不知道诈骗罪是 A、职务侵占罪是 A + B。A 与 A + B 属于法条竞合关系，特殊法优于一般法，同时构成两罪时优先认定职务侵占罪；把职务侵占罪打掉，等于把当时较轻的罪给打掉了。

    * 第三处 辩护任务：把"不构成 A 罪"当成了"无罪"。三段论推导要循环往复推导大前提，要得出无罪就得把 438 个罪名全部作为大前提推导一遍、都不构成才可以；同一个案件事实要从不同侧面去评价、去萃取。

* **身份判断的通用标准**

    * > **易错点**：定罪身份看的是"在干什么活"，不是"拿什么身份"。编制、劳动合同、三险一金都是形式，实质标准只有一个——是否从事具有管理性的职务。这与贪污罪中国家工作人员身份的判断逻辑一模一样。

## 财产犯罪的罪名体系

### 普通罪名

* **普通罪名的范围**

    * 故意毁坏财物罪。

    * 挪用资金罪，后面与挪用公款罪对比来看。

    * 挪用特定款物罪。

    * 拒不支付劳动报酬罪。

### 财产犯罪七大罪名

* **三组加一**

    * 财产犯罪七大罪名 = 三组 + 一。

    | 组别 | 罪名 |
    | :--- | :--- |
    | 第一组 | 侵占罪、盗窃罪 |
    | 第二组 | 抢夺罪、抢劫罪 |
    | 第三组 | 敲诈勒索罪、诈骗罪 |
