# 违法阻却事由：正当防卫、紧急避险与被害人承诺

## 违法阻却事由的体系位置

* **所在体系位置**

    * > **定义**：违法阻却事由是客观违法阶层里排在客观要件之后的第二个板块。

    * 客观要件（行为主体、危害行为、危害结果、因果关系）全部打勾之后，才谈得上用违法阻却事由排除违法性。

    * 走到这一环节时，要做的是在承认行为确实具备法益侵害性、具备犯罪的形式特征与表面特征的前提下，把违法性阻却掉。

* **三大事由的分量**

    * 正当防卫是大哥，紧急避险是二哥，被害人承诺是三哥，重要性与分值依次递减。

* **客观阶层与主观阶层的分工**

    * 客观阶层负责查清"事实是什么"。

    * 主观责任阶层负责决定"该不该罚这个人"，判断标准是可谴责性。

    * 被害人承诺出现在哪一步都不要紧，作用都只有一个：替行为人把违法性这一栏划掉。

* **抵挡行为的定性**

    * > **结论**：抵挡行为本身不是危害行为。

    * 朝人扔飞镖，人拿铁锅一挡，飞镖被挡住却把铁锅刺穿，此人仍不构成防卫过当。

    * 抵挡没有还击、没有制造任何法益侵害危险，在"危害行为"这一关就打叉，直接无罪。

    * 无罪结论不需要用正当防卫来论证，正当防卫在这一步无从谈起。

    * > **易错点**：制止了不法侵害，不等于就成立正当防卫；不成立正当防卫，也不等于有罪——无罪往往是因为在危害行为那一关就打叉。

```text
客观要件全部打勾
      ↓
行为具有法益侵害性  ＋ 行为具有违法性
      ↓
是否存在违法阻却事由？
（大哥 正当防卫 ／ 二哥 紧急避险 ／ 三哥 被害人承诺）
      ↓
 ┌────────────┴────────────┐
是                          否
 ↓                           ↓
违法性走却掉          带着法益侵害性与违法性
 ↓                     进入主观责任阶层
                              ↓
                   看你能不能谴责你：可谴责性
                              ↓
                     可谴责 → 承担刑事责任
```

## 正当防卫

### 成立条件总览

* **条件清单**

    * > **定义**：正当防卫的成立条件包括起因条件、时间条件、意思条件、对象条件与限度条件。

    * 起因、时间、意思三项围绕法条核心词"制止不法侵害"展开。

    * 对象条件回答面对共同犯罪人时谁能反击，限度条件回答构不构成防卫过当。

* **判断路线**

    * 分析正当防卫时不是论证行为是不是危害行为，而是在承认它是危害行为的前提下，用正当防卫把违法性阻却掉。

    * 行为若在"危害行为"这一栏就打了叉，直接无罪，用不着正当防卫。

    * 行为即使客观上制止了不法侵害，也不必然成立正当防卫。

### 起因条件

* **防卫人**

    * > **结论**：防卫人既可以是被害人，也可以是第三人。

    * 小芳反击强奸她的狗蛋是被害人防卫；狗胜拿板砖砸狗蛋制止其强奸，是第三人防卫。

* **法益侵害性（不法性）**

    * 法益分个人法益、社会法益、国家法益三类，抢劫、强奸、伤害都针对个人法益，个人法益的防卫最常见。

    * 对个人法益、国家法益、社会法益的不法侵害都可以成为防卫对象。

    * 唯一的区别在于：对国家法益、社会法益的防卫必须具备紧迫性，等得到警察就落不到正当防卫里。

    * 外国间谍在我国境内刺探国家秘密被群众制止，因为再找警察就来不及，具备紧迫性，成立防卫。

    * 大妈拿菜刀砍站街招嫖的美女：侵害社会法益属实，但报警就足以解决，毫无紧迫性，不成立正当防卫。

* **客观性**

    * 记正当防卫就记法条原话六个字：制止不法侵害。

    * 考试会在"客观的不法侵害"前堆砌修饰语干扰，把作为/不作为、故意/过失、有无责任年龄与责任能力等修饰语统统撇掉，只剩"不法侵害"四个字即可。

    | 考试给你的修饰语 | 结论 |
    | --- | --- |
    | 作为的不法侵害 | 可以正当防卫 |
    | 不作为的不法侵害 | 可以正当防卫 |
    | 故意的不法侵害 | 可以正当防卫 |
    | 过失的不法侵害 | 可以正当防卫 |
    | 行为人没有责任年龄、没有责任能力 | 客观上仍是不法侵害，可以正当防卫 |

    * 群众强迫肇事者必须救人，是在制止其不作为的不法侵害，属于正当防卫；"你不救就打你"的强迫行为同样如此。

    * 反击持刀砍杀的小孩、反击没有责任能力的精神病患者的刀，都属于正当防卫。

    * > **易错点**：客观性问的是"有没有客观存在的侵害事实"，不是"这个人能不能被处罚"。

* **现实性与假想防卫**

    * > **定义**：假想防卫指主观上认为存在不法侵害并实施防卫，客观上根本没有不法侵害。

    * 狗蛋误以为情夫狗胜在强奸而砍成重伤，成立假想防卫，不可能构成正当防卫。

    * > **处理规则**：假想防卫不可能构成故意犯罪；有过失的按过失犯罪处理；没有过失的按意外事件处理。

    * 有无过失的标准是能否预见狗胜实际上没有不法侵害：幽会的场面不像强奸，存在预见可能性，构成过失致人重伤罪；确实无法预见的则属意外事件，无罪。

    * 谎称"他强奸我"挑唆丈夫动手的小芳，是故意伤害罪的间接正犯，把不知情的狗蛋当作工具利用。

    * > **易错点**：假想防卫永远不会构成故意犯罪，故意要求认识到自己在侵害一个法益，而假想防卫中根本没有真实的法益侵害事实。

* **过失不法侵害与动物反击**

    * "制止不法侵害"只要求客观上存在不法侵害，主观上既可以是故意，也可以是过失。

    * 森林里甲朝即将误击狗熊开枪的乙腿上开一枪救下狗蛋：甲作为第三人，制止的是乙过失的不法侵害，成立正当防卫。

    * 孙悟空打死哮天犬：杨戩故意唆使，犬咬人是杨戩故意的不法侵害，成立正当防卫。

    * 杨戩睡着、疏忽管理致犬跑出：疏忽管理本身就是过失的不法侵害，孙悟空打死它仍是正当防卫。

    * 野生野狗背后没有人，只是危险源，孙悟空打死它才是紧急避险；武松打虎同理属紧急避险。

    | | 正当防卫 | 紧急避险 |
    | --- | --- | --- |
    | 面对的东西 | 他人实施的不法侵害 | 危险源（背后没有不法侵害人） |
    | 孙悟空打哮天犬 | 杨戩故意唆使 → 正当防卫 | — |
    | 孙悟空打跑出来的哮天犬 | 杨戩疏忽管理 → 正当防卫 | — |
    | 孙悟空打野生野狗 | — | 背后无人，属于危险源 → 紧急避险 |
    | 武松打虎 | — | 老虎是野生动物 → 紧急避险 |

### 时间条件

* **不法侵害正在进行**

    * 时间条件要求不法侵害已经开始但尚未结束。

    * 侵害还没开始就动手是事前防卫，侵害已经结束才动手是事后防卫，两者都叫防卫不适时，不成立正当防卫。

* **防卫装置与事前准备**

    * 在院墙上插碎玻璃片不算事前防卫：装置虽是事前设立的，但真正起作用是在侵害开始以后。

    * 墙上走的是"梁上君子"，插碎玻璃片不危害公共安全。

    * 防卫人事前做准备是被允许的，比如事后前置地揣好凶器，这叫事前准备，不叫事前防卫。

* **不法侵害结束的两个要求**

    * > **结论**：不法侵害是否结束要同时满足"行为举动结束"和"危险性解除"；危险性能否解除要从事发当时一般人的角度判断，不能事后诸葛亮。

    * 昆山龙哥案分三个阶段：战略防御（龙哥先砍、于海明见招拆招）、战略相持（砍刀掉地、被反击一刀捅中）、战略反攻（龙哥逃跑仍被追砍）。

    * 前两个阶段在时间条件上都属防卫适时，争议集中在战略反攻阶段。

    * 龙哥往宝马车跑，有理由相信他可能从车里再取一把刀，也可能开车撞人（车本身是犯罪工具），故仍有反扑可能性与再次侵害的可能性。

    * 从事后诸葛亮角度看龙哥确实只是想逃命，但这种判断等于开天眼，不能采用。

    * > **注意**："宜将剩勇追穷寇，不可沽名学霸王"——战略反攻阶段的追砍仍属防卫适时。

* **财产犯罪的例外**

    * 财产犯罪中犯罪人已取得财物的，被害人当场追回财物的行为仍属防卫适时，不属于事后防卫。

### 意思条件

* **偶然防卫**

    * > **定义**：偶然防卫指客观上制止了不法侵害，主观上却没有认识到自己在防卫。

    * 案例：甲只为杀死仇人乙而开枪，乙正要扣扳机杀丙；甲并不知道丙在场，乙一死丙才免于被杀。

    * 形象说法是"坏心办好事"。

```text
         客观上              主观上
      制止不法侵害         有无防卫认识
  甲 ─────  ✔     ──────►     ✘
              └─ 偶然防卫 ─┘
                 客观打勾    主观打叉
```

* **两说之争**

    * 防卫认识不要说：只要求客观上制止不法侵害，主观不作要求，结论是偶然防卫一律成立正当防卫。

    * 其理论根据是结果本位主义，也叫结果无价值论，标志是结果好则制造好结果的行为就是好行为。

    * 防卫认识必要说：客观要件与主观要件都要打勾、主客观相统一，结论是偶然防卫一律不成立正当防卫。

    * 其理论根据是行为本位主义，也叫行为无价值论，标志是结果好坏与行为好坏独立算账，不能以成败论英雄。

    * 两说平分秋色、各有拥趸，价值观本身多元，考试按观点展示开放式地考，没有唯一正确答案。

    | | 防卫认识不要说 | 防卫认识必要说 |
    | --- | --- | --- |
    | 理论根据 | 结果本位主义（结果无价值论） | 行为本位主义（行为无价值论） |
    | 前提要求 | 只要求客观上制止不法侵害 | 客观、主观都要打勾 |
    | 对偶然防卫的结论 | 一律成立正当防卫 | 一律不成立正当防卫，转入定罪 |

* **故意杀人只到未遂**

    * 按防卫认识必要说，甲成立故意杀人罪，犯罪形态是未遂。

    * > **定义**：既遂结果要同时满足事实判断上的结果发生与价值评价上的结果是坏结果，两个条件缺一不可。

    * 事实判断是描述（今天下雨了），价值评价是评价（下雨天真糟糕）。

    * 死亡结果不必然是坏结果：法警执行死刑也制造了死亡结果，但那在价值评价上是好结果，不能成为加重处罚的既遂结果。

    * 甲在事实判断上制造了死亡结果，在价值评价上却是好结果（救了丙一命），故排除既遂。

    * 甲没有自动放弃，排除中止，只剩未遂。

### 对象条件与特殊情形

* **对共同犯罪人能反击谁**

    * > **结论**：原则上只能对实行犯进行防卫反击，判断标准只有"攻击性"三个字。

    * 对教唆犯、间接正犯不能反击：教唆、支配本身没有攻击性，真正砸过来的是实行犯那只手。

    * 对无攻击性的帮助犯（如望风）不能反击：帮助行为尚未指向防卫人。

    * 对有攻击性的帮助犯（如拔下钢管递过去）可以反击：帮助行为已具现实的侵害指向。

    | 对象 | 能不能对其防卫反击 | 判断理由 |
    | --- | --- | --- |
    | 实行犯 | 可以 | 亲手实施不法侵害，攻击性直接具备 |
    | 教唆犯、间接正犯 | 不能 | 教唆、支配本身没有攻击性 |
    | 帮助犯（无攻击性，如望风） | 不能 | 帮助行为尚未指向防卫人 |
    | 帮助犯（有攻击性，如递凶器） | 可以 | 帮助行为已具现实的侵害指向 |

* **花瓶三情形**

    * 情形一（乙主动把丙的花瓶砸向甲）：乙对甲成立正当防卫，乙对丙构成紧急避险，一个行为触犯两个违法阻却事由，属想象竞合，最终优先认定为正当防卫；成立紧急避险还须符合迫不得已等其他条件。

    * 情形二（甲拿丙的花瓶砸乙，乙徒手抵挡）：乙对甲不成立正当防卫，因为抵挡不是危害行为；乙对丙也不成立紧急避险，因为花瓶不是乙拿的，摔碎的结果算到甲头上。乙在这一关就打叉，直接无罪。

    * 情形三（乙只是拿花瓶抵挡、并未砸向甲）：乙对甲不成立正当防卫，乙对丙构成紧急避险。与情形一仅差"砸向甲"还是"只是抵挡"这一字之差。

    | | 花瓶砸向谁 | 乙对甲 | 乙对丙 | 乙的最终状态 |
    | --- | --- | --- | --- | --- |
    | 情形一 | 乙主动砸向甲 | 正当防卫 | 紧急避险 | 想象竞合，优先认定正当防卫 |
    | 情形三 | 乙只是拿它抵挡 | 不成立（非危害行为） | 紧急避险 | 成立紧急避险 |
    | 情形二 | 甲砸向乙，乙徒手抵挡 | 不成立（非危害行为） | 不成立（归甲） | 无罪 |

### 限度条件

* **过当结果的判断标准**

    * 法条表述是：防卫行为明显超过必要限度并造成重大损害。

    * 相当性标准表达的是比例原则：不法侵害越严重，防卫程度可以越严重，两边台阶一级一级往上走。

    * 枸杞茶案按相当性标准：恶棍刚破门而入、还没动手，侵害还不严重，直接弄死他不符合比例原则，属于防卫过当。

    * 必要性标准表达的是：只要是制止不法侵害的必要手段，就不过当。

    * 同一枸杞茶案按必要性标准：单身女子三更半夜没有反击机会，毒杀是必要手段，不属于防卫过当。

    * > **结论**：必要性标准今天已经成为多数说，枸杞茶案不过当；把相当性标准摆在首要地位不利于保护防卫人。

* **手段过当不等于结果过当**

    * 面对强制猥亵而端出加特林扫射却一枪未中，属于手段过当，少数说认为构成防卫过当。

    * 多数说认为不构成防卫过当，因为没有制造过当结果，一个死亡结果都没产生。

    * 如果加特林真把人打成筛子，则构成防卫过当，最终罪名是故意杀人罪，依法应当减轻或者免除处罚。

* **防卫过当的成立条件**

    * 法条只说"应当负刑事责任，但应当减轻或免除处罚"，并不存在"防卫过当罪"这个罪名。

    * 防卫过当可能落到的罪名按由重到轻是故意杀人罪、故意伤害罪（致重伤）、过失致人死亡罪、过失致人重伤罪。

    * 判断成立条件时，直接以其中最轻的罪名为衡量标准。

    * 客观要件：至少要有一个重伤结果或者一个死亡结果，达不到这个门槛就不是防卫过当。

    * 主观要件：至少过失；对过当结果连过失都没有、完全属于意外事件的，不构成防卫过当。

    | 排序 | 罪名 | 主观 |
    | --- | --- | --- |
    | 最重 | 故意杀人罪 | 故意 |
    | 稍轻 | 故意伤害罪（致重伤） | 故意 |
    | 再轻 | 过失致人死亡罪 | 过失 |
    | 最轻 | 过失致人重伤罪 | 过失 |

### 特殊防卫

* **第 20 条第 3 款的定位**

    * > **定义**：第 20 条第 3 款的核心特征是"严重危及人身安全的暴力犯罪"，理论上称特殊正当防卫或无限防卫权。

    * 条文表述：对正在进行的行凶、杀人、抢劫、强奸、绑架以及其他严重危及人身安全的暴力犯罪，采取防卫行为造成伤亡、死亡，不过当，不负刑事责任。

    * > **结论**：这一款不是特权而是正常办事；它之所以可以致人死亡而不过当，是因为落在了正当防卫正常的限度条件之内，同时满足了必要性标准与相当性标准。

* **无限防卫权的误读**

    * 面对投放迷药欲迷奸的侵害人，端出加特林把对方打成筛子，仍然构成防卫过当。

    * 昏醉型抢劫（把人灌醉后以取财为目的带走财物）同样不能据此主张无限防卫。

    * 不能把这一款理解成法律特批的特权——遇到这些罪就弄死对方也不过当。

* **行凶的认定**

    * "行凶"不要求携带凶器，只要求使用的是严重危及人身安全的暴力手段，司法解释已明确这一点。

    * > **易错点**："行凶"里的"凶"指的是气势汹汹，不是凶器；空手打人也可能是行凶。

### 防卫挑拨与相互斗殴

* **防卫挑拨**

    * > **定义**：防卫挑拨指行为人故意挑拨、激怒对方，使对方来打自己，然后反过来"防卫"。

    * 狗蛋扎破铁牛的轮胎并当面挑衅，铁牛跑来要打他时狗蛋用剪刀捅成轻伤，不成立正当防卫，成立故意伤害罪。

    * 对方先动手没有错，错在动手的原因是行为人自己挑拨，不认可其防卫意图，属于恶意利用正当防卫制度。

* **相互斗殴的两个结论**

    * "斗殴无防卫"：相互约架是不正对不正、狗咬狗一嘴毛，任何一方都不能主张正当防卫。

    * "斗殴有承诺，但承诺有限度"：承诺遭受轻伤有效，承诺遭受重伤或承诺放弃生命无效。

    * 因此互殴中一方把对方打成轻伤不构成故意伤害罪；打成重伤或打死的，成立故意伤害罪的加重结果或故意杀人罪。

* **区分互殴与防卫的考量点**

    * 先看谁先动手：一旦动手就构成不法侵害，先动手的一方是不法侵害，防守方带防卫性质。

    * 再看地点：上门打人的，进人家门的一方是不法侵害，被打的一方是在保卫家园。

    * 暴徒先调戏、先动手，女孩扇他一耳光属于防卫；不能因为常说"打架"就一律认定为相互斗殴。

## 紧急避险

### 五道关口与分工

* **条件清单**

    * > **定义**：紧急避险的成立条件共五个——起因条件、时间条件、意识条件、不得已条件、限度条件。

    * 起因、时间、意识三条件管"该不该管"，不得已、限度两条件管"管到什么份上"。

* **考点分布**

    * 意识条件里的偶然避险与限度条件里的法益衡量最容易被绕进去，也是考试最容易下手的地方。

* **与正当防卫的分工**

    * 记住正当防卫六个字"制止不法侵害"，记住紧急避险四个字"避免危险"。

    * 面对他人的不法侵害并予以反击，是正当防卫；面对无从反击的危险只能另寻出路时，才是紧急避险。

### 起因条件

* **危险的两种来源**

    * > **定义**：紧急避险的起因条件指避免一份危险，危险主要来自两个方面。

    * 大自然的危险（野生动物袭击、自然灾害）：老虎咬武松，武松逃不掉，迫不得已闯进潘金莲家躲藏，侵害了第三人的住宅法益。

    * 人的危险（他人的不法侵害）：西门庆追砍武松，武松逃不掉，迫不得已闯进潘金莲家。

    * 同是人的危险，武松若不逃而直接反击西门庆，干的就是正当防卫。

    | 危险来源 | 追着武松的是谁 | 武松的反应 | 法律性质 |
    | --- | --- | --- | --- |
    | 大自然的危险 | 老虎 | 逃不掉，闯进潘金莲家躲避 | 紧急避险 |
    | 人的危险 | 西门庆 | 逃不掉，闯进潘金莲家躲避 | 紧急避险 |
    | 人的危险 | 西门庆 | 不逃，直接反击 | 正当防卫 |
    | 大自然的危险 | 老虎（还在 2 公里外） | 提前跑去闯进潘金莲家 | 事前避险，不属实 |

* **假想避险**

    * > **定义**：假想避险指危险并不现实存在，是自己吓出来的。

    * 铁牛用木棒把正在甩狗屎的狗蛋打趴下，不构成紧急避险；狗蛋若真触电才成立紧急避险。

    * > **处理规则**：假想避险不可能是故意为之，所以不可能构成故意犯罪；有过失的定过失犯罪；没有过失的按无罪处理。

### 时间条件

* **危险正在发生**

    * 紧急避险要求危险正在发生，与正当防卫要求不法侵害正在进行相对应。

* **事前避险与事后避险**

    * 危险还没有发生、或者还不紧迫就去避险，可能构成事前避险。

    * 危险已经结束、已经消除后才去避险，属于事后避险。

    * 事前避险与事后避险都叫避险，但都不紧急，不属实。

    * 老虎还在 2 公里外武松就闯进潘金莲家，危险并不紧迫，成立事前避险，不属实。

### 意识条件

* **避险认识**

    * "避免危险"四个字既有客观要件（客观上避免了一份危险），也有主观要件（主观上认识到自己在避免危险，即避险认识）。

* **偶然避险**

    * > **定义**：偶然避险指客观上避免了一份危险，主观上没有认识到这一点，主客观相不一致，形象说法同样是"坏心办好事"。

    * 狗蛋为报复砸毁玛莎拉蒂车窗，石头恰好落进车内婴儿怀中并带来空气，救活了将被闷死的孩子；客观上救了孩子，主观上毫不知情。

    | | 避险认识不要说 | 避险认识必要说 |
    | --- | --- | --- |
    | 理论根据 | 结果本位主义（结果无价值论） | 行为本位主义（行为无价值论） |
    | 前提要求 | 只看客观上避免了一份危险 | 客观、主观都打勾 |
    | 对偶然避险的结论 | 一律成立紧急避险，无罪 | 一律不成立紧急避险，转入定罪 |

    * 避险认识不要说只看客观，认为偶然避险一律成立紧急避险、无罪，车主都说"砸得好"，好结果的行为应当被奖励。

    * 避险认识必要说要求客观、主观都打勾，认为偶然避险一律不成立紧急避险，行为的好坏与结果的好坏独立算账，带着毁坏财物目的砸车本身就是坏行为。

```text
                    客观上避免了一份危险      主观上认识到在避险
  紧急避险                  √                          √
  偶然避险                  √                          ×      ← 狗蛋这一石头
```

* **故意毁坏财物罪的未遂**

    * 按避险认识必要说转入定罪，涉嫌的罪名是故意毁坏财物罪，行为人带着毁坏财物的目的实施了毁坏行为。

    * 既遂与否仍要两步判断：事实判断上要有毁坏结果，价值评价上该结果还必须是个坏结果，因为既遂结果是要加重处罚的。

    * 车主自己都觉得"你砸那几片玻璃算啥呀，救了我孩子的命呢"，该毁坏结果是好结果，不能算既遂。

    * 排除中止（没有自动放弃），只剩未遂，最终定故意毁坏财物罪的未遂。

    * > **易错点**：车窗玻璃绝对值达到 5000 元，只盯着数额标准会误定既遂；数额标准不是判断既遂的唯一依据。

    * 两说平分秋色，没有哪一说自称多数说，考试只考观点展示与逻辑推导过程。

```text
狗蛋砸车窗玻璃
      │
      ├── 故意毁坏财物罪成立？── 成立（带着毁坏财物的目的实施了毁坏行为）
      │
      ├── 既遂？
      │     事实判断：有毁坏结果        ── √
      │     价值评价：结果是"坏结果"吗？── × （车主说"砸得好"）
      │     → 不是既遂结果
      │
      ├── 中止？── 要有自动放弃 ── 没有
      │
      └── 未遂 ✓    ← 排除法只剩这一条
```

### 不得已条件

* **迫不得已即补充性条件**

    * > **定义**：不得已条件即迫不得已，也称补充性条件，意味着这只能是你最后的手段。

    * 大多数紧急避险都要攻击无辜的第三人：闯进别人家、被迫毁掉别人财物，情形都很紧急。

    * 抢了面包店一个法棍面包后还能一路抱着面包跑到高架桥，说明还有力气打工挣钱，不属于迫不得已，不成立紧急避险。

* **受强制的紧急避险**

    * 歹徒以"不强奸就把你们两个都杀掉"相威胁，被害富翁被迫实施性交时，不定强奸罪，属于受强制的紧急避险。

    * 倘若真是被抬着按着实施、行为人完全不自主，连刑法上的行为都不构成，更谈不上犯罪。

    * 富翁是为保住两条性命而牺牲女孩的性自由，在法益衡量上仍是保护较大、损害较小（多数说，争议很大）。

### 限度条件

* **法益位阶**

    * > **定义**：紧急避险的限度条件要求为了保护较大的法益，迫不得已损害较小的法益。

```text
   生命法益        最高位阶
        │
   身体健康法益
        │
   自由方面法益    （性自由、人身自由）
        │
   财产法益        地位最低
```

* **画等号的尺度**

    * 财产对财产可以画等号：狗蛋为保住自己一吨货物把对方一吨货物推下海，成立紧急避险，不构成故意毁坏财物罪（民事上仍需赔偿）。

    * 财产对生命不能画等号：船继续下沉时把同行的小芳推下海，属于故意杀人罪，多数说如此，量刑可酌定从宽。

    * 生命对生命更不能画等号：海上木板案只能扶住一个人时把对方打下去，构成故意杀人罪，不成立紧急避险。

    * 多数人的命换少数人的命原则上不允许，因为人的生命不能作为手段；例外是 911 式绝境，空中击落可避免撞入大楼造成的更大伤亡。

    * > **提示**：财产对财产可以等，财产对生命不行，生命对生命也不行；唯独"多数命换少数命"属于例外中的例外，原则上不允许，911 式绝境才被认可。

## 被害人承诺

### 承诺的范围与权限

* **可放弃的法益谱系**

    * > **结论**：财产能放弃，名誉能放弃，人身自由能放弃；身体上轻伤能放弃，重伤不能；生命怎么也不能放弃。

    | 你想放弃的法益 | 承诺是否有效 | 依据 |
    | --- | --- | --- |
    | 财产 | 有效 | 车主自己点头，刑法不再保护这辆车 |
    | 名誉 | 有效 | 被害人自己请求，侮辱之类的罪名不成立 |
    | 人身自由 | 有效 | 被关者自己要求被关，非法拘禁不成立 |
    | 身体健康（轻伤） | 有效 | 伤情在轻伤以内，承诺有效 |
    | 身体健康（重伤） | 无效 | 超过国家保护底线，承诺无效 |
    | 生命 | 无效 | 生命法益不允许放弃 |

* **财产**

    * 车主请求他人砸掉自己不顺眼的玛莎拉蒂，不构成故意毁坏财物罪。

    * 原理只有一句：被害人自己放弃了法益保护，刑法就没有再介入的必要，刑法不保护就没有犯罪空间。

* **名誉**

    * 受虐狂之间互相提出并接受虐待，不构成侮辱罪。

* **人身自由**

    * 为闭关看书请求被关进山洞十天，不构成非法拘禁罪。

* **身体健康**

    * 承诺被砍一根小手指（轻伤）有效，不构成故意伤害罪。

    * 承诺被砍整条胳膊（重伤）无效，仍构成故意伤害罪。

    * > **易错点**：轻伤与重伤是这条线上最关键的分水岭，别看到"人家同意了"就直接放人，先把伤情等级问清楚。

* **生命**

    * 杨志应无赖牛二之请一刀砍下其头，构成故意杀人罪；生命法益不允许放弃，这条线到此为止。

### 承诺的时间

* **只能事前**

    * > **结论**：承诺必须在事前作出才有效，事后作出已经于事无补。

    * 但被害人在行为进行当中产生承诺的，从那一刻起，后面的部分就不再是犯罪。

* **两个阶段的区分**

    * 女乘客从一开始就愿意装睡，男乘客偷摸不构成强制猥亵罪。

    * 女乘客事前没有承诺、真的睡着，男乘客摸醒后她才改主意继续装睡：第一阶段构成强制猥亵，第二阶段因被害人有承诺而不构成犯罪。

    * > **易错点**：被害人有承诺不要求行为人意识到，被害人内心有承诺就行，不要求行为人认识到这个承诺的存在；如何证明是装睡属于证据法问题，实体法按给定条件分析。

### 承诺的能力

* **理解能力要求**

    * 承诺要有效，被害人对所承诺的事项要有理解能力。

    * 婴幼儿、精神病患者、严重智障的人作出的承诺无效。

* **被洗脑者的承诺**

    * 邪教头目把女弟子长期洗脑成巨婴后再引诱、诱奸，承诺无效，头目构成强奸罪。

    * > **注意**：必须确实已被洗脑成巨婴、变成严重智障、已经没有正确的理解能力，承诺才无效，不要脱离这个前提去套。

### 意思表示的真实性

* **受欺骗的两类判断**

    * 承诺必须是真实的意思表示；受欺骗、受欺诈作出的意思表示不真实，无效。

    * 判断时只看究竟是事实认识错误还是动机认识错误，不看其他。

    * > **易错点**：千万不要用道德标准来提炼判断标准。法律的归法律，道德的归道德；我们是刑事法庭，不是道德法庭。

* **事实认识错误**

    * 事实认识错误指对"对方是谁、发生了什么"有错误认识，承诺无效。

    * 尹志平冒充杨过欺骗小龙女，小龙女以为是自己的心上人，承诺无效，尹志平构成强奸罪。

    * 冒充丈夫爬上熟睡妻子床铺的歹徒，妻子误以为是丈夫，同属事实认识错误，承诺无效，构成强奸罪。

* **动机认识错误**

    * 动机认识错误指对事实没有错误认识、只是动机没实现，承诺有效。

    * 评委承诺一等奖换女模特上床，事后一个奖没给，只是不给奖而已；女模特知道对方是谁、知道会发生什么，属权色交易，不构成强奸罪。

```text
被害人作出承诺
│
├─ 事实认识错误（对"对方是谁、发生了什么"有错误认识）
│    └─ 行为人主动欺骗 → 被害人受骗作出承诺
│         → 承诺无效          典型：尹志平冒充杨过
│
├─ 动机认识错误（对事实无错误认识，只是动机没实现）
│    └─ 行为人主动欺骗 → 被害人受骗作出承诺
│         → 承诺有效          典型：评委拿一等奖换上床
│
└─ 被害人自行产生认识错误，行为人加以利用
     ├─ 行为人不知情
     │    → 承诺有效          典型：短信把"不行"写成了"行"
     │
     └─ 行为人知情，并以作为或不作为的欺骗
          促使或强化被害人的承诺
          → 承诺无效          典型：兽医隐瞒新药，打了安乐针
```

* **被害人自行产生认识错误、行为人不知情**

    * 求砍邻居院中珍树，邻居忙中漏字把"行不行"写成"行"，砍树者并不知对方有认识错误，承诺有效，不构成故意毁坏财物罪。

* **被害人自行产生认识错误、行为人知情**

    * 兽医发现马还有救、有新药却故意隐瞒，以不作为的欺骗强化主人"给我马注射死"的承诺，承诺无效，构成故意毁坏财物罪。

    * 不作为的欺骗以存在作为义务为前提；兽医基于职务、业务负有告知真相的作为义务，不告知本身就是欺骗，且属于强化而非促使承诺。

    * 主观上明知对方有认识错误而加以利用，与行为人主动欺骗同属"承诺无效"这一格。

### 推定的被害人承诺

* **定义**

    * > **定义**：推定的被害人承诺指被害人没有现实作出承诺，但刑法可以推定其会同意，理由是行为是为被害人好。

    * 这种处理类似民法上的无因管理。

* **砸门救火案**

    * 邻居老王见小芳忘关水龙头、打电话不接，强行破门入内关水并造成重大财产损失，不构成故意毁坏财物罪。

    * 小芳并不在场、也没有说过"你砸吧"，所以不能走现实的被害人承诺，只能走推定的被害人承诺。
