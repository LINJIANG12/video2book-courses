# 主观要件：犯罪故意、罪过形式与事实认识错误

## 犯罪故意的法定构成

* **犯罪故意**

    * > **定义**：明知自己的行为会发生危害结果，希望或者放任这个结果发生。

    * 拆成两截：前半截「明知」是认识因素，后半截「希望或者放任」是意志因素。

* **行政违法故意与犯罪故意的区分**

    * 闯红灯撞死人：闯红灯这一层确实是故意违反行政法，但撞死人的那一刻带的是侥幸心理（心里想「应当没事的吧」），对死亡结果只能是过失，成立交通肇事罪。

    * 结论：对行政违法是故意、对死亡结果是过失的，两截要分开认定；真希望或放任撞死人，就不再是交通肇事罪而是故意杀人罪。

    * > **易错点**：违反行政法规时的"故意"，不等于刑法上的犯罪故意。

## 主客观相一致原则

* **主客观相一致原则**

    * > **定义**：主观认识的内容和实际发生的内容必须相一致。

    * 机理：故意犯罪叫「明知故犯」，有认识因素，就存在「我主观认识的内容」与「实际发生的内容」对不对得上的问题。

    * 边界：只有故意犯罪有过主客观相一致问题；过失犯罪没有主观认识与实际结果要对应的问题。

    * 展开为两条线索：内容上的相一致、时间上的相一致。

### 内容上的相一致

* **行为对象上的相一致**

    * 考的是行为对象：贩卖淫秽物品牟利罪在「淫秽物品」这个对象上必须相一致。

    * 文盲在地铁口卖书被查是淫秽小说，他真的不知道（表哥说是功夫小说），客观打钩、主观打叉，缺少犯罪故意，不能定罪。

* **客观决定主观原则**

    * 客观行为对象决定主观认识的内容。

    * 客观行为对象是「人」，主观只要认识到「人」就够；姓名、身份这个下位概念认错了，只影响杀人动机的实现。

### 时间上的相一致

* **行为与故意或目的同时存在原则**

    * > **定义**：一个行为的定性只能由「当时」的故意或目的决定，不能由事前的计划或事后的心理决定。

* **撞死小芳案**

    * 开车去小芳家埋伏、途中不慎撞死一人，死者恰是小芳；开车前往途中仍处预备阶段，既遂只能发生在着手之后的实行阶段。

    * 行为时并没有认出前方行人就是小芳，对死亡结果是过失，成立交通肇事罪或者过失致人死亡罪；故意杀人罪只能停在犯罪预备。

    * > **易错点**：不能因为前面的计划里有杀小芳的故意，就把这个死亡结果也定成故意杀人罪既遂。

### 认定心理一律以行为时为准

* **毒苹果案**

    * 在小芳常坐但非专用的图书馆座位放毒苹果，小芳没来，小美坐下吃掉被毒死。

    * 行为时明知位置非小芳专用、明知可能毒死别人仍然放手，即对毒死他人有放任的故意，构成故意杀人罪既遂，属间接故意。

    * 狗蛋式的事后心理——「我以为毒死的是小芳、实际是毒死的小美」——发生在结果之后，对定罪不重要，也不能据此推出对象认识错误。

    * > **结论**：认定犯罪故意、犯罪目的、犯罪过失，一律以行为时为准，不以行为后、结果发生后为准。

## 概括故意与择一故意

* **概括故意**

    * > **定义**：知道会发生死亡结果，但不确定死谁、死几个，只有一个概括的认识。

    * 睡午觉被楼下吵醒，摸出手雷扔进人群炸死数人：对死亡结果是概括的故意，成立故意杀人罪，同时也构成爆炸罪。

* **择一故意**

    * > **定义**：知道这批对象里肯定会死一个，但不确定死哪个，是「要么……要么……」的关系。

    * 小芳给两杯一模一样的饮料，一杯投毒一杯投春药，让狗蛋和铁牛随便拿。

    * 对拿到毒药的狗蛋构成故意杀人罪既遂；对拿到春药的铁牛，其投毒方式已给铁牛的生命法益制造了紧迫危险，仍构成故意杀人罪未遂（铁牛属于与死神擦肩而过）。

    * 前后只投一次毒，整体是一个行为，两个罪名想象竞合，择一重罪论处。

    * > **易错点**：不能因为铁牛最后没死就认为对铁牛不构成犯罪。

## 罪过形式的体系

* **罪过形式的六个形式**

    * 罪过形式四个（故意、过失各两个），加两个无罪过事件，一共六个，分五组考区分。

    | 大类 | 具体形式 |
    | :--- | :--- |
    | 故意 | 直接故意、间接故意 |
    | 过失 | 疏忽大意过失、过于自信过失 |
    | 无罪过事件 | 意外事件、不可抗力 |

* **五组分水岭总表**

    | 对照的两组 | 相同点 | 关键分水岭 |
    | :--- | :--- | :--- |
    | 直接故意 / 间接故意 | 明知结果可能发生 | **希望** 还是 **放任** |
    | 间接故意 / 过于自信过失 | 都已预见结果可能发生 | **放任**（不采取避免措施）/ **不想**（会采取避免措施） |
    | 疏忽大意过失 / 过于自信过失 | 都是过失，都反对结果发生 | **应当预见**（应然）/ **已经预见**（实然） |
    | 疏忽大意过失 / 意外事件 | 都没有预见到 | 有没有**预见到的可能性** |
    | 过于自信过失 / 不可抗力 | 都已预见结果可能发生 | 有没有**结果避免发生的可能性** |

## 五组区分的展开

### 直接故意与间接故意

* **两者之别**

    * 直接故意是明知加希望，间接故意是明知加放任。

    * 小芳等铁牛松手后再开枪，铁牛狂吻一小时不撒手，小芳果断开枪打偏打死铁牛：对铁牛的死亡是间接故意；若这一枪真打死狗蛋，即为直接故意。

* **放任要求两种可能性**

    * 放任的心理是结果发生也可以、不发生也可以，无所谓，意味着可能发生、可能不发生两条轨道。

    * 叶文洁在山顶解绳索，政委与丈夫都在绳上：对政委是明知加希望，对丈夫表面上「不想」，但她认识到丈夫必死，事态只有一条轨道，内心深处也是希望。

    * > **易错点**：间接故意的明知只能是「明知可能」，不能是「明知必然」；明知必然还实施，其实就是希望，属于直接故意。

* **同一动作可以同时是两种故意**

    * 叶文洁对政委和对丈夫都是直接故意，因为是同样的一个动作。

### 间接故意与过于自信过失

* **过于自信过失的定义**

    * > **定义**：已经预见自己的行为可能发生危害结果，但轻信能够避免。

    * 轻信能够避免的实质是：不想让这个结果发生，结果却发生了。

* **分水岭是避免措施**

    * 相同点：都已预见危害结果可能发生。区别：对结果的态度，间接故意是放任（无所谓），过于自信过失是反对（不想发生）。

    * 过于自信过失一般会多少采取点避免措施，间接故意因为放任结果发生，不会采取避免措施。

    * > **结论**：区分间接故意与过于自信过失，最管用的一招是看有没有采取避免措施。

* **投毒饭案例**

    * 丈夫做有毒饭菜毒杀妻子，又怕孩子放学回家误吃，赶紧去学校接孩子；没接到，骑车赶回，老婆孩子全部吃死。

    * 对老婆是直接故意；对孩子是过于自信过失——已预见孩子可能吃死（不是必然），态度是不想，体现在他去接孩子这一避免措施上。

* **恶作剧充气案**

    * 工友甲把高压气泵塞进工友乙肛门充气，致乙肝肠寸断、重伤濒死。

    * 按案件事实，甲把气泵塞入人体并充气，对重伤结果是直接故意。

    * > **提示**：确实存在定「过于自信过失、走过失犯罪」的观点，答题时要认得出来。

### 疏忽大意过失与过于自信过失

* **两者之别**

    * 疏忽大意过失是应当预见可能发生危害结果，因疏忽大意没有预见，结果发生了；过于自信过失是已经预见。

    * 相同点：都是过失，对结果的发生都持反对态度。

    * > **易错点**：容易把「应当预见」当成「已经预见」——应当预见是应然，已经预见是实然，应然不等于实然。⚠️

* **手术纱布案**

    * 医生手术缝合时把纱布忘在体内导致感染重伤：没有预见到纱布在体内，但应当预见到，属于疏忽大意过失。

    * 不可能是过于自信过失——不存在「已经预见了还不拿出来」的情形，那会变成故意犯罪。

### 疏忽大意过失与意外事件

* **意外事件的定义**

    * > **定义**：无法预见危害结果会发生，既没有预见，也没有预见到可能性。

* **分水岭是预见到的可能性**

    * 相同点：都没有预见到。区别：疏忽大意过失是应当预见，意外事件是无法预见。

    * > **结论**：有预见到的可能性，就是应当预见，成立疏忽大意过失；没有预见到的可能性，就是无法预见，成立意外事件。

    * > **易错点**：误把「没有预见」当作「没有预见到的可能性」——我没有考上法考，不等于我没有考过法考的可能性。

* **旋转门倒车案**

    * 商场门口金杯车倒车，司机没看到刚出旋转门、边走边打电话的女士，撞倒后继续倒。

    * 身为司机、身处商场门口车来车往的环境，存在预见到的可能性，只是因为疏忽大意没有预见，成立疏忽大意过失。

    * 决定预见可能性的判断依据是主观认识水平与客观认识条件，主要是客观的认识环境。

### 过于自信过失与不可抗力

* **不可抗力的定义**

    * > **定义**：已经预见结果可能发生，但已经无法抗拒该结果发生。

* **分水岭是结果避免发生的可能性**

    * 相同点：都已预见结果可能发生。区别：有没有结果避免发生的可能性。

    * 不可抗力是没有避免可能，过于自信过失是有避免可能却因为过于自信而没避免。

    * 海啸袭来时船长无论怎么操纵也对抗不了，乘客海难死亡，不属于过于自信过失，属于不可抗力。

## 罪过判断的三步路线

* **先过认识，再过态度，最后过避免可能**

    * 考试把六种罪过形式打乱了考，等于四选一甚至六选一，要按统一路线走。

    ```text
    第一步：有没有认识到危害结果会发生？
     │
     ├─ 有 ──→ 走进上半区
     │        │
     │        └─ 第二步：对结果发生的态度是什么？
     │             ├─ 希望 ────────→ 直接故意
     │             ├─ 放任 ────────→ 间接故意
     │             └─ 反对（不想结果发生）
     │                    │
     │                    └─ 第三步：有没有结果避免的可能性？
     │                         ├─ 有 ────────→ 过于自信的过失
     │                         └─ 没有 ──────→ 不可抗力
     │
     └─ 没有 ─→ 走进下半区
                │
                └─ 有没有结果预见的可能性？
                     ├─ 有 ────────→ 疏忽大意过失
                     └─ 没有 ──────→ 意外事件
    ```

* **案例一：胡同里的大卡车**

    * 司机见胡同里有人躺着睡，判断卡车轮胎间距宽、底盘高，慢慢开过去即可相安无事；开到最后车尾汽油味熏人，睡着的人翻身被后轮轧死。

    * 第一步认识到可能致死；第二步态度是不想结果发生；第三步存在避免可能——结论是过于自信的过失。

* **案例二：德国军官的爆头**

    * 三个德国军官比赛打俘虏头上的西瓜、苹果、葡萄，第三个一枪把俘虏头打爆，还吹「I'm sorry」。

    * 认识到可能打死人，态度是放任（无所谓，反正是俘虏）——结论是间接故意杀人。

* **成立过失犯罪与有犯罪过失的题眼**

    * 成立过失犯要求客观要件打钩、主观要件打钩且为过失；「有没有犯罪过失」只在问主观要件一个层面，两者含义不同。

    * A 项：警察以为报警是恶作剧而未出警，有疏忽大意的犯罪过失，构成玩忽职守罪（过失犯罪）——成立。

    * B 项：法官知识储备不足未及时更新理论，只是学习上的过失，未达犯罪程度，不成立过失犯罪。

    * C 项：超市误卖过期食品致顾客轻伤，有过失，但只有过失致人重伤罪，过失致人轻伤不构成犯罪，故不成立过失犯罪。

    * D 项：黑暗中误将女儿当妻子开枪，是对象认识错误，有杀人故意，成立故意犯罪而非过失犯罪。

## 事实认识错误的层层辨认

* **辨认顺序是硬性的**

    * > **定义**：事实认识错误先看客观阶层，再看主观阶层。

    * 客观阶层的核心是客观要件，客观要件的核心是危害行为，所以第一个问题永远是有没有危害行为。

    * 具体错误（同一犯罪构成内）包含对象错误、打击错误、因果关系错误；抽象错误（不同犯罪构成间）单独成类。

    ```text
    事实认识错误
    │
    ├─ 客观阶层：有没有「危害行为」？
    │    ├─ 打叉 → 不能犯（对象不能犯）→ 一号案例
    │    └─ 打勾 → 主观阶层：有没有「犯罪故意」？
    │              ├─ 没有 → 缺乏犯罪故意型的事实认识错误
    │              │            → 二号案例
    │              │            → 要在「过失致人死亡」与「意外事件」之间选
    │              └─ 有   → 具有犯罪故意型的事实认识错误
    │                         ├─ 同一犯罪构成内 → 三号案例
    │                         │    └─ 具体错误
    │                         │         ├─ 对象错误
    │                         │         ├─ 打击错误
    │                         │         └─ 因果关系错误
    │                         └─ 不同犯罪构成间 → 四号案例
    │                              └─ 抽象错误
    │
    └─ 最后一站：对象错误 / 打击错误怎么分（两步走标准）
    ```

* **四个案例对照**

    | 案例 | 案情 | 危害行为 | 犯罪故意 | 定性 |
    | :--- | :--- | :--- | :--- | :--- |
    | 一号 | 沙漠里甲朝「仇人乙」开枪，实为稻草人，四下无人 | 打叉 | — | 不能犯（对象不能犯） |
    | 二号 | 树林里甲冲野兔开枪，打死了路人乙 | 打勾 | 打叉 | 缺乏犯罪故意型 |
    | 三号 | 甲朝「仇人乙」开枪，打死了路人丙 | 打勾 | 打勾 | 具体错误（同一构成内） |
    | 四号 | 动物园里甲朝「仇人乙」开枪，打死了狗熊 | 打勾 | 打勾 | 抽象错误（跨构成） |

* **客观阶层与主观阶层**

    * 一号：甲这一枪没对任何人的法益制造危险，不是危害行为，故意杀人罪无从成立，属不能犯（对象不能犯）。开枪另可能构成非法持有枪支罪，但就杀人罪无罪。

    * 二号：客观要件全部打勾，主观上只有打野兔的故意，与故意犯罪无关，要在过失致人死亡罪与意外事件之间选。

    * 三号与二号的主观表象相同（都认错了对象），区别只在主观上有没有犯罪故意。

    * 三号与四号的客观、主观都相同，区别在「预定目标」与「实害对象」的**法益种类**：都是人是同一犯罪构成内的错误（具体错误），一个是人是跨两个罪构成的抽象错误。

    * > **提示**：「具体的错误」「抽象的认识错误」这两个词考试经常直接甩进选项，必须记牢。

## 对象错误与打击错误的两步走

* **三情形骨架**

    * 情形一：狗蛋就在眼前，小芳开枪打偏把铁牛打死，事后才知铁牛是狗蛋的新欢；开枪时对铁牛的死亡是过失——这就是打击错误（对实害结果是意外事件时同样是打击错误）。

    * 情形二：铁牛来拥抱狗蛋，小芳等他一小时不松手，索性用力朝狗蛋开枪打偏打死铁牛；对铁牛的死亡是间接故意，明知且放任，主观认识与实际发生的内容一致，根本没有认识错误，属间接故意型案件，自然也不是打击错误。

    * 情形三：小芳见大树底下站着一个人，以为是狗蛋实际是铁牛，一枪打死；这个人的死亡是直接故意，且认错了实害对象的身份——这就是对象认识错误。

    * 情形二与情形三的相同点是对实害对象、对死亡结果都是故意；区别在于对实害对象的身份有没有搞错。

* **第一步：对实害对象、实害结果是什么心理**

    * 只看对**实害对象、实害结果**的心理，不看对预定目标是什么心理，焦点就是死亡结果。

    * 过失或意外事件，一步到位就是打击错误；故意（含间接故意）排除打击错误，进入第二步。

    * > **易错点**：不是「只要把枪打偏了就算打击错误」。枪确实打偏了，但对死亡结果是放任、是间接故意时，就不是打击错误。只有对实害对象的死亡结果是过失，才能是打击错误。

* **第二步：有没有认错实害对象的身份**

    * 行为时对实害对象的身份有认识错误，就是对象错误；没有认识错误，就是主客观一致、没有任何事实认识错误的间接故意型案件。

    ```text
    看行为人对【实害对象、实害结果】是什么心理
            │（不看对预定目标是什么心理）
            │
            ├── 过失 / 意外事件 ──▶ 打击错误（一步到位，就此出结论）
            │
            └── 故意（含间接故意）──▶ 行为时对实害对象的【身份】有没有认错？
                                        │
                                        ├── 有 ──▶ 对象错误
                                        └── 无 ──▶ 间接故意型案件
                                                     （主客观一致，无事实认识错误）
    ```

* **通用性体现在隔离犯**

    * 隔离犯是最简单的形态（如寄毒酒杀人），杀人行为与死亡结果之间有明显的时空间隔，难度高，考试爱考；两步走标准对普通同现场案件并无优越性，对任何题都能做对。

* **寄毒酒三模型**

    * 模型一：乙家确实是 211 室，甲也填对了单，快递员投递疏忽投到 217 毒死丙；甲对丙只能是过失或意外，一步到位属**打击错误**。快递员相当于甲射出的那颗子弹。

    * 模型二：甲知道乙与妻子丙都住 211，仍把酒寄到 211，包装写成红酒；丙喝死。对丙是间接故意，排除打击错误；甲没有「误将丙当作乙」的身份认识错误，故无对象错误，是**间接故意型案件，无任何事实错误**。

    * 模型三：甲以为 211 住户是乙、实际是丙。第一步问的是对「211 住户的死亡」而非「丙的死亡」——给 211 一家寄毒药，对这一家人死亡绝对是直接故意，排除打击错误；第二步身份认错了，故属**对象错误**。

    * > **结论**：认错身份，不等于没有杀人故意。

* **抹掉姓名、用位置代替的诀窍**

    * 做题时把案件里的姓名、身份抹掉，用位置代替。问「甲对 211 室住户有没有杀人故意」显然有；加个「丙」这个姓名很多人就晕了。

    * 他没有杀丙的动机，但他有杀「丙这个人」的故意。

* **情形三的同构案**

    * 小芳误把铁牛当狗蛋开枪杀人，一问「对铁牛的死亡是故意还是过失」就有人答过失；不要想到「铁牛」这个姓名，要想到「前方这个人」。

## 三种不通用标准的坑

* **只看部分情形，考试专门做成坑**

    * 考试恰恰喜欢揭示这些不具有通用性的标准，把它们的弊端做成坑，所以必须认得出来。

### 看预想对象在不在现场

* **标准说法与适用限度**

    * 说法是：预想对象出现在现场就是打击错误，预想对象不在现场就是对象错误。

    * 只对同一案发现场的案件管点用；遇到隔离犯不好办，甚至不是隔离犯时也可能失灵。

    * 情形三中狗蛋完全可以就在现场（只是小芳没看见），一旦狗蛋在，这个案件就变成打击错误，显然不对。

* **2019 年真题：假想盗窃丙的渔网**

    * 丙为捕鱼在河里设渔网，乙知情仍把渔船提供给甲；甲用乙的船偷走一张渔网，事后才知道偷走的是乙的渔网，实施盗窃时他想要的那张丙的渔网就在现场、只是没注意到。

    * 按「预定对象在不在现场」会推出打击错误；按两步走：对实害对象（乙的渔网）是故意，排除打击错误，行为时误将乙的渔网当作丙的渔网，故是**对象错误**。

    * 抹掉「乙」「丙」，甲盗窃的「这张河里的渔网」在他眼里就是丙的渔网，对它当然有盗窃故意。

### 看错误结果是主观原因还是客观原因

* **标准说法与失灵场景**

    * 说法是：客观原因导致的错误结果是打击错误，主观原因导致的是对象错误。

    * 隔离犯即失灵：甲知道乙住 211，填单时疏忽错写成 217 且自己没发现，快递按 217 投递毒死 217 的主人丙——疏忽是主观原因、错写是客观原因，两者共同制造错误结果，套不进去。

    * 正确做法是两步走：第一步对实害对象（丙的死亡）是过失（疏忽大意写错），一步到位就是打击错误，不必分析主观原因、客观原因。

### 看结果发生时的心理

* **标准说法**

    * 说法是以结果发生时行为人的心理来区分：甲在乙家车库装炸弹，知道乙的老婆孩子也可能开这辆车而不顾，第二天乙妻丙开车被炸死；甲事后打听得知死者是丙，以为死者是乙，故定对象错误。

* **错在哪里**

    * 「甲以为死者是乙、实际是丙」是**事后**的心理活动，对认定犯罪已经没有意义。

    * 违反的正是行为与故意同时存在原则——认定犯罪心理一定要以行为时为标准。

* **两步走的正确结论**

    * 第一步对丙的死亡是放任、间接故意，排除打击错误；第二步装炸弹时没有「误将丙当作乙」的心理，排除对象错误；既非打击错误也非对象错误，是间接故意型案件，无任何事实错误。

## 具体错误的定罪处理

* **处理分两大类**

    * 同一犯罪构成内的错误即具体错误，含对象错误、打击错误、因果关系错误三大类；不同犯罪构成间的错误即抽象错误。

    * 对象错误案件没有具体符合说、法定符合说的之争，有这两说之争的是打击错误。

### 对象错误

* **罪名的行为对象是人**

    * 故意杀人罪的行为对象是「人」这个上位概念，认识到前方有个人还朝这个人开枪并把人打死，就有杀人故意，构成故意杀人罪既遂。

    * 身份认错只影响杀人动机的实现：本来要杀狗蛋、结果杀了铁牛，动机没实现而已。

    * > **结论**：这种对象认识错误在德国法上叫**动机错误**。故意杀人罪是故意犯、不是动机犯，动机搞错不等于没有犯罪故意。

* **位置比身份更重要**

    * 故意杀人罪不叫「故意杀狗蛋罪」，也不叫「故意杀铁牛罪」；姓名、身份、性别、年龄在所不问，杀任何人都构成故意杀人罪。

    * 题目问「小芳对铁牛有没有杀人故意」时，要把这个姓名引去、忽略掉，只想「这个人有没有杀人的故意」。

    * > **易错点**：选项往往故意用姓名身份代替人（按位置讲解时是「马背上这个人」「马后面这个人」），心里一定要把姓名抹掉，否则容易混淆。

### 打击错误：具体符合说与法定符合说

* **打击错误的事实前提**

    * 对实害对象、实害结果的死亡必须是过失或者意外事件；若是间接故意、间接故意型案件，就不存在打击错误。

    * > **易错点**：很多人理解打击错误出错，就是没有先把案件事实澄清——案件事实是最重要的。

* **两说的完整推导链**

    * 具体符合说实事求是、尊重案件事实：对狗蛋是故意杀人罪未遂，对铁牛是过失致人死亡罪；一个行为、两个罪名，想象竞合，择一重得**故意杀人罪未遂**。缺点是罪刑不相适应、太便宜凶手。

    * 法定符合说要做到罪刑相适应、严惩凶手：把对铁牛的过失**拟制**为故意，对铁牛即故意杀人罪既遂，与未遂想象竞合，择一重得**故意杀人罪既遂**。理由是「有杀狗蛋的故意就是有杀人的故意，铁牛也是人」。缺点是被批评修改、篡改了案件事实。

    | 对比 | 具体符合说 | 法定符合说 |
    | :--- | :--- | :--- |
    | 对预定目标狗蛋 | 故意杀人罪未遂 | 故意杀人罪未遂 |
    | 对实害对象铁牛 | 过失致人死亡罪 | 故意杀人罪既遂（把过失「拟制」为故意） |
    | 罪名关系 | 一个行为、两个罪名，想象竞合 | 一个行为、两个罪名，想象竞合 |
    | 择一重之后 | 故意杀人罪未遂 | 故意杀人罪既遂 |
    | 优点 | 实事求是、尊重案件事实、正常分析、很丝滑 | 严惩凶手、罪刑相适应 |
    | 缺点 | 罪刑不相适应，便宜了凶手 | 被批评修改、篡改案件事实，把过失改成故意，理由不足 |

* **有没有多数说与怎么考**

    * 没有多数说，两说平分秋色。考试从不考唯一正确答案，问的都是「你的逻辑推导能否自圆其说」。

    * 客观题考法是：选项把两说的前提与结论对调，凡是「具体符合说下对铁牛成立故意杀人罪既遂」「法定符合说下对铁牛成立过失致人死亡罪」「具体符合说下最终定既遂」「法定符合说下最终定未遂」，一律错误。

    * 只要记住两说的完整推导链，任一选项的对错都能当场判断。

## 因果关系认识错误

### 作用范围

* **管既遂，不管成立**

    * > **定义**：因果关系错误研究的是故意犯罪是否既遂，而不是故意犯罪是否成立。

    * 以故意杀人罪为例，研究因果关系决定的是既遂与否，不是成立与否；作用范围搞错，后面全乱。

* **三类及其重要性排序**

    * 三类是狭义的因果关系错误、结果的推迟发生、结果的提前发生；按分值与重要性，依次是结果推迟发生、结果提前发生、狭义因果关系错误。

    * 任何一类因果关系错误的判断顺序都是：先问故意犯罪是否成立，成立之后再问是否既遂，既遂要过因果关系这一关。

    * 过失犯罪只有成立与否的问题，没有成立之后的既遂未遂问题；只有故意犯罪才有两个任务。

### 狭义的因果关系错误

* **定义与处理**

    * > **定义**：主观以为是 A 死法弄死你、实际上是 B 死法弄死你。

    * 主观上对因果关系流程（具体死法）的认识错误，不影响故意杀人罪既遂的成立。

    * 不重要的两个理由：故意杀人罪本身成立（客观有杀人危害行为、主观有杀人故意）；客观上杀人行为与死亡结果之间已存在因果关系。既遂两个要件都过了，中间死法的错位无关紧要。

* **三案对照**

    | 案例 | 主观以为的死法 | 现实死亡结果 | 行为与死亡有因果关系吗 | 结论 |
    | :--- | :--- | :--- | :--- | :--- |
    | 推下井 | 淹死 | 摔死（枯井） | 有，推的行为直接导致摔死 | 故意杀人罪既遂 |
    | 人参果 | 毒死 | 噎死（毒药未入胃） | 无，投毒未发挥作用 | 故意杀人罪未遂 |
    | 推下桥 | 淹死 | 摔死（撞桥墩） | 有，推的行为直接导致摔死 | 故意杀人罪既遂 |

* **两处易混点**

    * 推下井与推下桥本质相同，只差在死法从淹死变成摔死；人参果案则连因果关系都没有——投毒未发挥作用，噎死是猪八戒自己狼吞虎咽造成的。

    * > **易错点**：刑法讨论因果关系时，只讨论现实发生的死亡结果。现实结果是噎死，不是毒死。

### 结果的推迟发生

* **事前故意的标准案例**

    * 小方把狗蛋儿打成重伤昏迷，摸了脖子翻了眼，确认「应该死了」，把「尸体」扔进自家后院粪池，狗蛋儿被狗屎呛死、粪水淹死。

    * > **易错点**：后行为里的「尸体」要打引号，那不是真正的尸体，是个活人。

* **剥洋葱的三层结构**

    * 第一层：前行为无争议，成立故意杀人罪（客观有杀人行为、主观有杀人故意）。

    * 第二层：后行为也无争议，对活人当尸体扔进水里淹死，成立**过失致人死亡罪**（主观以为是尸体、对活人没有杀人故意，客观造成他人死亡）。

    * 第三层才是争议：前行为在故意杀人罪成立的基础上能不能既遂——要论证前行为与最终死亡结果之间有没有因果关系。

* **介入因素两步走**

    * 论证前行为的因果关系时，后行为自动变成**介入因素**，启动两步走标准。

    * 第一步判断介入因素是否异常：不异常则先前行为与最终死亡直接得出有因果关系；异常则认为先前行为与介入因素是独立关系，进入第二步。

    * 第二步看先前行为与介入因素谁对死亡的发生作用更大：作用一样大、没有显著差异，则**二因一果**，双方都有因果关系；某一作用明显更大，则只有作用大的一方有因果关系。

    ```text
    介入因素两步走
    │
    ├─ 第一步：介入因素异常吗？
    │    ├─ 不异常 ──→ 先前行为与最终死亡有因果关系
    │    └─ 异常     ──→ 进入第二步
    │
    └─ 第二步：先前行为与介入因素，谁对死亡作用更大？
         ├─ 一样大、无显著差异 ──▶ 二因一果
         └─ 某一作用明显更大     ──▶ 后因一果（后行为作用更大时）
    ```

* **粪池案的嵌套观点展示**

    * 观点一路径：介入因素**异常**——「杀人后处理尸体是规定动作所以不异常」的前提是真正杀死了人、处理的是真尸体；本案「尸体」是活人，主客观不一致，是小概率事件，故异常。进入第二步后认为前行为（打成重伤昏迷）与后行为（抛尸淹死）作用一样大，得出**二因一果**。

    * 观点二路径：介入因素**不异常**——杀手杀人后抛尸、碎尸本就是规定动作，不异常，直接得出前行为与死亡有因果关系，同样是**二因一果**。

    * 后因一果的理由：介入因素异常，且后行为（抛入粪池淹死）作用更大，只有后行为与死亡有因果关系。

    * 因果关系的最终结论只有二因一果与后因一果两种，二因一果有两条路径通向；这是观点展示里嵌套观点展示。

* **从因果关系落到罪数**

    * 二因一果：前行为与死亡有因果关系定故意杀人罪既遂，后行为永远定过失致人死亡罪；一个死亡结果只能用一次，不能并罚，按**吸收犯**重罪吸收轻罪，只定故意杀人罪既遂。

    * 后因一果：前行为与死亡无因果关系，只能定故意杀人罪未遂，后行为定过失致人死亡罪；未遂没有评价死亡结果，死亡结果没有用到前行为上，两罪可以并罚。

    ```text
    二因一果                                后因一果
      │                                      │
    前行为与死亡有因果关系                    前行为与死亡无因果关系
      │                                      │
    前行为：故意杀人罪既遂                    前行为：故意杀人罪未遂
    后行为：过失致人死亡罪                    后行为：过失致人死亡罪
      │                                      │
    一个死亡结果只能用一次                    未遂没有评价死亡结果
      │                                      │
    吸收犯：重罪吸收轻罪                      可以并罚
      │                                      │
    定故意杀人罪既遂                          故意杀人罪未遂 ＋ 过失致人死亡罪
    ```

    * 客观题问唯一答案时按多数说处理：二因一果是多数说，最终定故意杀人罪既遂；主观题才老老实实展示两种观点及各自结论。

### 结果的提前发生

* **两步走计划的识别**

    * > **定义**：结果提前发生的标准案件要求计划中存在两步——第一步是预备行为，第二步才是实行行为。

    * 潘金莲上午在家备好毒酒放餐桌上（预备行为），计划晚上拿到大郎摊点递给他喝（实行行为）；大郎提前收摊回来把酒喝了，毒死。

    * 如果案情改成只在家里放毒酒等他回来喝、喝死就完事，那就是一个行为、没有两步走计划，成立故意杀人罪既遂，不叫结果的提前发生。刑法只能根据给定条件分析。

* **既遂结果只能发生在实行阶段**

    * 故意杀人罪分预备阶段与实行阶段，分界点是**着手**；预备阶段的终局形态是犯罪中止和犯罪预备（犯罪预备是终局形态，不是指预备行为），实行阶段的终局形态是犯罪中止、犯罪未遂、既遂。

    * > **定义**：着手实行行为，是指该行为对法益造成现实、紧迫、直接的危险。

    * 潘金莲还没到摊点、没实施实行行为，死亡结果发生在预备阶段，不能称既遂结果；她没有自动放弃、无终止行为，因意志以外的原因（人已死了）无法着手，构成**故意杀人罪的犯罪预备**。

    * 对照：备好毒酒后转念觉得大郎对自己不错、把毒酒倒掉不杀，那才是预备阶段的犯罪中止。

* **死亡结果没人评价的处理**

    * 预备阶段就死亡的死亡结果没有大前提评价，对死亡结果只能定**过失致人死亡罪**——在家放毒酒也给同住者制造了危险。

    * 谭警察放毒酒后出门办事，小叔叔武松同住、回来不知情喝下毒死，放毒酒的行为对武松的死亡构成过失致人死亡罪；把武松换成提前回来的武大郎同理。

    * 男生宿舍甲把一包外形像零食的老鼠药临时放在公用桌上，接电话出去办事，室友乙当零食吃掉毒死，甲对乙的死亡定过失致人死亡罪。

    * 整体只有一个行为（外出买牛肉是生活行为不计入），一个行为、两个罪，想象竞合择一重罪论处。

* **已经着手的掐晕案**

    * 潘金莲第一步掐晕、第二步扔进湖里淹死，结果第一步就把人掐死了，第二步不用实施。计划中的前行为是预备、后行为是实行，但法官要看的是前行为有没有着手。

    * 人已被掐晕、最后被掐死，说明这个掐的行为对生命法益产生了现实、紧迫、直接的危险，显然已经着手。

    * 多数说：已进实行阶段，死亡结果发生在实行阶段且有因果关系，定**故意杀人罪既遂**；客观题问唯一答案就按此答。

    * 少数说：给定的计划只是「先掐晕」，掐死是没料到的，对死亡结果确属过失，故不能定既遂，只能定**故意杀人罪未遂**，死亡结果另定**过失致人死亡罪**，想象竞合择一重罪。

    * 生成第二种视角的方法是站到辩护人一侧：观点一刑罚更重是公诉人立场，辩护人必然主张更轻的未遂，再补上对死亡结果不能置之不理的评价。

* **两步走判断图**

    ```text
    结果提前发生：两步走判断
    │
    ├─ 第一步：前行为是否着手？
    │   │
    │   ├─ 尚未着手（如"上午家里放毒酒，晚上拿到摊点给大郎喝"）
    │   │     └─→ 故意杀人罪（犯罪预备）＋ 过失致人死亡罪
    │   │           └─→ 一个行为、两个罪 ──→ 想象竞合，择一重罪论处
    │   │
    │   └─ 已经着手（掐晕即掐死：对生命法益造成现实、紧迫、直接的危险）
    │         └─→ 进入第二步
    │
    └─ 第二步：观点展示
        │
        ├─ 多数说 ──→ 死亡结果发生在实行阶段 ＋ 有因果关系
        │            └─→ 故意杀人罪既遂
        │
        └─ 少数说 ──→ 计划只想掐晕，对死亡结果确属过失
                       └─→ 故意杀人罪未遂 ＋ 过失致人死亡罪
                             └─→ 想象竞合，择一重罪论处
    ```

* **先前行为与死亡有因果关系的判断**

    * 介入因素「异常不异常」没有标准答案，一定要具体化、情景化判断；「正常人不会吸沙子」这种脱离情景的判断是错的。

    * A 项：甲伤害乙打晕，乙昏迷在沙滩上吸入沙子窒息；介入因素是被害人自身，具体化到这一情景并不异常，先前行为与死亡有因果关系。

    * B 项：甲伤害乙打晕，乙醒来头昏脑胀走到马路上求救被车撞死；介入因素仍是被害人自身行为，具体化到「被打晕后醒来仍迷糊」的情景不异常，有因果关系。

    * C 项：甲杀害乙打晕，误以为乙已死亡抛入河中致溺亡，属**结果的推迟发生**；按多数说二因一果，先前行为与死亡有因果关系。

    * D 项：甲杀害乙打晕误以为已死，托路过的丙处理尸体，丙也以为是尸体抛入河中致溺亡；「处理尸体」既包括自己亲自处理也包括让他人代为处理，仍是前行为加后行为，按多数说二因一果，甲的先前行为与死亡有因果关系，定故意杀人罪既遂。

    * D 项中的丙：先构成**过失致人死亡罪**；该尸体此时属于甲故意杀人罪的犯罪证据，让丙掩埋、隐藏尸体构成**帮助毁灭证据罪**；丙一个行为触犯两罪，想象竞合择一重罪论处。

## 同一犯罪过程内错误的结合

* **五种错误与四组结合**

    * 同一犯罪过程内共五种错误：对象错误、打击错误、狭义因果关系错误、结果的提前发生、结果的推迟发生。

    * 近年趋势是考它们之间的结合，四组结合**基本都围绕打击错误**展开，所以打击错误是基本功。

    | 结合 | 标准案例 | 要点 |
    | :--- | :--- | :--- |
    | 对象错误 + 打击错误 | 二皇子刺杀太子案 | 先抹掉身份，用位置表示人 |
    | 狭义因果关系错误 + 打击错误 | 悬崖一枪案 | 先判客观因果关系，再谈两说 |
    | 结果提前发生 + 打击错误 | 潘金莲的毒酒 | 预备行为出打击错误，没有观点展示 |
    | 偶然防卫 + 打击错误 | 猪队友案 | 先立后破；第二步只按案件事实 |

### 对象错误撞上打击错误

* **二皇子刺杀太子案**

    * 二皇子射箭打偏射死了马后面的人，事后得知射死的正是太子——太子事先与太监调包换衣，自己穿太监衣服跟在后面。

    ```text
                            二皇子（射箭的人）
                                  │
                                  │  射箭（射偏了）
                  ┌───────────────┴───────────────┐
                  ▼                               ▼
            马背上这个人                     马后面这个人
            —— 二皇子以为：太子               —— 二皇子以为：太监
               实际上：太监                      实际上：太子
                  （没打中）                     （被射死了）
    ```

* **定位与做法**

    * 对预定目标（马背上这个人）的身份认错，是对象认识错误，一般不重要；箭射偏打死马后面这个人，对该人死亡是过失，这才是打击错误，由此才有具体符合说与法定符合说的观点展示。

    * 预定目标用「马背上这个人」、实害对象用「马后面这个人」表示，不致混淆。

* **两说的结论**

    * 具体符合说：对马背上的人未遂，对马后面的人过失致人死亡罪，想象竞合择一重得**故意杀人罪未遂**。

    * 法定符合说：对马背上的人未遂，把对马后面的人的过失拟制为故意得故意杀人罪既遂，想象竞合择一重得**故意杀人罪既遂**。

    * > **易错点**：命题老师会在选项里用「太子」「太监」代替位置。选项说「根据具体符合说，二皇子对太子构成过失致人死亡罪」看着别扭也不对——因为按案件事实太子当时在马后面、穿着太监服装，二皇子对他没有故意，对马后面这个人的死亡是过失。

    * 故意杀人罪的行为对象是「人」，不是「故意杀太子罪」；位置比身份更重要。

### 因果关系错误撞上打击错误

* **悬崖上的一枪**

    * 甲在悬崖上向仇人乙开枪打偏，子弹从悬崖边丙的耳边飞过，丙受惊吓失足坠崖摔死。

    ```text
       甲（悬崖上）
          │
          │  开枪（打偏了）
          ├───────────────▶ 乙（仇人，悬崖边）  ← 预定目标：没打中
          │
          └─ 子弹从耳边飞过 ──▶ 丙（悬崖边）    ← 实害对象
                                  │
                                  │ 受惊吓
                                  ▼
                              失足坠崖摔死
    ```

* **先判客观因果关系，再谈两说**

    * 有打击错误：预定目标是乙、实害对象是丙，对丙的死亡顶多是过失，甚至可能是意外事件。

    * 同时蕴含狭义的因果关系错误：以为打中弄死丙，实际根本没打中，是把丙吓掉下去摔死的。

    * 狭义因果关系错误一定要先判第一步——客观上因果关系有没有。丙正站悬崖边欣赏风景，子弹从耳边飞过受惊失足，不异常，故甲的开枪行为与丙的死亡有因果关系。

    | | 具体符合说 | 法定符合说 |
    | :--- | :--- | :--- |
    | 对乙（预定目标） | 故意杀人罪未遂 | 故意杀人罪未遂 |
    | 对丙（实害对象） | 过失致人死亡罪 | 过失致人死亡罪**拟制**为故意 → 故意杀人罪既遂 |
    | 想象竞合择一重 | 故意杀人罪未遂 | 故意杀人罪既遂 |

### 结果提前发生撞上打击错误

* **潘金莲毒酒案加武松**

    * 上午在武大郎摊点放好一瓶毒酒（只是预备行为）后出门买牛肉，同住的武松回来把这瓶毒酒喝了，武松死亡。

    ```text
       上午：潘金莲在武大郎摊上放好一瓶毒酒
                  （只是预备行为）     然后出门买牛肉
                         │
                         ▼
            武松（与武大郎同住）回来了
                         │
                         ▼
            武松自己把这瓶毒酒喝了 → 武松死亡

       预定目标：武大郎        实害对象：武松（对他是过失）
    ```

* **无观点展示的原因**

    * 武松同住且把这酒喝了，潘金莲对武松成立过失致人死亡罪；该案同时是结果的提前发生（死亡结果在预备阶段就发生），也可以说是打击错误（预定目标武大郎、实害对象武松、对实害对象是过失）。

    * 但这个打击错误**没有观点展示**：具体符合说、法定符合说都有一个前提——行为已经是**实行行为**；本案放毒酒只是预备行为，在预备行为中发生的打击错误没有观点展示。

    * 正常处理即可：对武大郎构成故意杀人罪的犯罪预备，对武松构成过失致人死亡罪，想象竞合择一重罪论处。

### 偶然防卫撞上打击错误

* **猪队友案的事实**

    * 甲与乙商量好一起朝丙开枪、都要开枪；甲枪法差打偏，把兄弟乙打死了，而若不打死乙，乙本会顺利开枪打死丙。

* **第一步：从打击错误切入的三角关系**

    * 预定目标是丙，实害对象是乙，对乙的死亡最多是过失——跟自己兄弟一起杀丙的人把兄弟打死了不可能是故意，故是打击错误。

    ```text
                      ┌── 丙 ── 预定目标：故意杀人罪未遂（两说无争议）
       甲  ────────────┤
                      └── 乙 ── 实害对象：对兄弟乙的死亡是过失
    ```

    | | 具体符合说 | 法定符合说 |
    | :--- | :--- | :--- |
    | 对丙（预定目标） | 故意杀人罪未遂 | 故意杀人罪未遂 |
    | 对乙（实害对象） | 过失致人死亡罪 | 过失**拟制**为故意 → 故意杀人罪既遂 |
    | 想象竞合择一重 | 故意杀人罪未遂 | 故意杀人罪既遂 |

* **第二步：从偶然防卫切入的两角关系**

    * 偶然防卫只涉及甲与乙，跟丙没关系，此时不是三角关系而是两角关系。

    ```text
       打击错误：三角关系              偶然防卫：两角关系

       丙 ──┐                             甲
            ├── 甲                      │
       乙 ──┘                            └──▶ 乙（制止了乙对丙的不法侵害）
                                            丙  不在这个结构里
    ```

    * > **定义**：偶然防卫，就是在「制止不法侵害」上没做到主客观相一致——客观上制止了不法侵害，主观上没有认识到、没有防卫认识。

    * 甲打死乙客观上制止了乙对丙的不法侵害（否则丙会被乙打死），主观上并不知情，是典型的偶然防卫、坏心办好事。

* **先立后破的顺序**

    * 两个理由：选项里的排列顺序就是先打击错误后偶然防卫；背后原理是分析打击错误是在给人**定罪入罪**，分析偶然防卫是在看能不能**出罪脱罪**。

    * > **结论**：分析案件的顺序都是先立后破——先立（能不能定罪），后破（能不能排除犯罪）。

* **第二步只按案件事实走**

    * 分析偶然防卫时**不能按法定符合说的事实去走**：法定符合说把对乙的过失拟制成故意，是在修改案件事实，甲对兄弟乙显然不可能是故意杀人，所以按正常案件事实（即具体符合说）分析即可。

* **偶然防卫出罪的两说**

    * 防卫认识必要说：成立正当防卫除客观上制止不法侵害外，还要求主观上有防卫认识。甲没有防卫认识，不成立正当防卫；此时甲涉嫌的罪名只有**过失致人死亡罪**，因为按案件事实对乙是过失。

    * 过失致人死亡罪要求一个过失行为、一个死亡结果、二者有因果关系；而死亡结果要件有两个层次——事实判断上制造了死亡结果，价值评价（法律评价）上这个结果还必须是**坏结果**。甲是坏心办好事，救下无辜的丙，造成的是好结果，结果要件不成立，不构成过失致人死亡罪，最终无罪。

    * 防卫认识不要说：成立正当防卫只要求客观上制止不法侵害，不要求主观上有防卫认识，故偶然防卫一律成立正当防卫，甲无罪。

    * > **结论**：两说在「甲把乙打死是否无罪」上意见一致，区别只在无罪理由——一个说因成立正当防卫而无罪，一个说因不成立正当防卫但不符合过失致人死亡罪的结果要件而无罪。

* **全案大汇总**

    * 偶然防卫只涉及甲对乙这条线，不涉及甲对丙那条线，所以甲对丙的故意杀人罪未遂是最终结论，两说一致无争议。

    * 甲对乙这条线：打击错误角度的具体符合说（过失致人死亡罪）与法定符合说（故意杀人罪既遂）分歧，但后者因不符合案件事实而弃用；偶然防卫角度两说都得出无罪。

    * 因为先立后破，以「破」的结论作最终结论：甲对丙构成故意杀人罪未遂，甲对实害对象乙最终无罪。

    ```text
       ┌──▶ 丙：预定目标 ──▶ 故意杀人罪未遂（两说一致，无争议）
       甲 ──┤
       └┬─▶ 乙：实害对象 ──▶ 打击错误角度（具体符合说：过失致人死亡罪
          │                     法定符合说：故意杀人罪既遂）→ 该线弃用
          └─▶ 偶然防卫角度（只按案件事实：过失）
                 ├── 防卫认识不要说 ──▶ 正当防卫 ──▶ 无罪
                 └── 防卫认识必要说 ──▶ 非正当防卫，但结果是好结果
                                          → 过失致人死亡罪结果要件不成立
                                          → 无罪

       先立后破：破成立 → 甲对乙无罪；甲对丙仍为故意杀人罪未遂
    ```

* **这一块怎么考**

    * 具体符合说与法定符合说没有多数说，防卫认识必要说与防卫认识不要说也是平分秋色，都不会有唯一答案。

    * 考试不要求心悦诚服地赞成哪个观点，开放式考，只要懂各说的逻辑推导即可。

## 不同犯罪构成间的错误

* **抽象错误的标准案例**

    * 孙悟空要打死二郎神的哮天犬，预定目标是哮天犬，金箍棒扔过去扔偏了，一闷棍把二郎神打死了。

    * 同样叫打击错误，性质可以完全不同：预定目标与实害对象都是人，法定权益种类相同，是同一犯罪构成内的错误；预定目标是犬（财物）、实害对象是人（当人看待），法定权益种类不同，是不同犯罪构成间的错误，也就是抽象错误。

    * > **定义**：法定权益的种类相同就是同一犯罪构成内的错误；法定权益的种类不同就是不同犯罪构成间的错误。

* **处理方法**

    * 不同犯罪构成间错误有打击错误，也有对象错误，但**没有因果关系错误**；对象错误和打击错误不必细致划分，因为处理方法完全一样：正常分析，分别定罪。

    * 孙悟空对预定目标哮天犬构成故意毁坏财物罪未遂，对实害对象二郎神构成过失致人死亡罪，前后只有「扔金箍棒」一个行为，想象竞合择一重罪论处。

    ```text
        预定目标：哮天犬        故意毁坏财物罪（未遂）
                │  （想打死人家狗，没打中）
                │
                ├──  一个行为：扔金箍棒  ──→  想象竞合，择一重罪论处
                │
        实害对象：二郎神        过失致人死亡罪
                 （不小心打偏了，一闷棍把人打死）
    ```

    * > **结论**：不同犯罪构成间错误 = 分别定罪 + 都成立则想象竞合择一重罪。

* **包容评价思维**

    * 考试找的两个罪名往往有关系，这个关系就是包容评价关系。

    * > **定义**：重罪可以包容评价为轻罪——重罪的行为里本身蕴含了一个轻罪的行为。

    * 用 $A$、$B$ 表示：轻罪故意伤害罪是伤害行为 $A$（侵害人的身体健康），重罪故意杀人罪是 $A+B$，$B$ 是要你的命。拿刀把人捅死这个杀人行为里包含了一个伤害行为，所以可以把 $A$ 从杀人行为里提炼出来。

    * 一句话收：包容评价思维，就是对一个重罪、重行为进行提炼，提炼出一个性质相同的轻行为；用定罪方法里的「从不同角度提炼、萃取」就能反向操作，把 $B$ 存而不论。

    ```text
       A = 伤害行为（侵害人的身体健康）
       ┌──────────────────────────────────────────┐
       │                                          │
       │   A 单独                    →  故意伤害罪（轻罪）
       │                                          │
       │   A + B                    →  故意杀人罪（重罪）
       │                               B = 要你的命
       └──────────────────────────────────────────┘
    ```

* **包容评价的适用结论**

    * > **口诀**：在性质相同、程度不同的轻罪和重罪之间产生认识错误，由于重罪可以包容评价为轻罪（或者说重罪里面蕴含了轻罪、可以评价为这个轻罪），那么**至少在轻罪的范围内，主客观肯定是相一致的，至少可以定轻罪的既遂**。

    * 偷人参果开出加特林：涉嫌盗窃枪支罪（重罪）与普通盗窃罪（轻罪）。盗窃枪支罪客观打钩（确实偷了一把枪）、主观打叉（不知道里面是枪），不构成；普通盗窃罪主观打勾（有偷人参果的故意，把人参果视为普通财物），而枪支是 $A+B$（$A$ 普通财物，$B$ 是杀伤力／火药或压缩气体的杀伤力），盗窃枪支的行为可包容评价为盗窃普通财物的行为，故定**普通盗窃罪既遂**。

    * 公交车上的 LV 包：想侵占遗忘物、事实上偷了司机的包，涉嫌盗窃罪（重罪）与侵占罪（轻罪）。盗窃罪客观上是盗窃行为但主观只有侵占故意，主观打叉不构成；侵占罪主观打勾，而盗窃行为可包容评价为侵占行为（同属财产犯罪），故定**侵占罪既遂**。

* **人身犯罪的包容评价关系**

    | 重罪 | 可包容评价为 | 考情 |
    | :--- | :--- | :--- |
    | 故意杀人罪 | 故意伤害罪 | 考过 |
    | 强奸罪 | 强制猥亵罪 | 没考过 |
    | 绑架罪 | 非法拘禁罪 | 考过，而且还多次考过，分则里还经常讲 |
    | 拐卖儿童罪 | 拐骗儿童罪 | 没考过 |

    * > **提示**：这里的「考过／没考过」是截至本主题的统计；没考过不代表不常考，命题是活的，遇到就往上套 $A+B$ 的提炼公式。

* **财产犯罪的包容评价金字塔**

    ```text
                            抢劫罪
                           /      \
              （暴力这条线）        （胁迫那条线）
                     /                        \
                 抢夺罪                   敲诈勒索罪
                     \
                     盗窃罪
                        \
                      侵占罪
    ```

    * 抢劫罪有两个手段：暴力与胁迫。沿暴力这条线往下走，抢劫罪包容评价为抢夺罪，抢夺罪包容评价为盗窃罪，盗窃罪包容评价为侵占罪。

    * 沿胁迫这条线下一个台阶，抢劫罪包容评价为敲诈勒索罪。

    * 传递性顺理成章：既然抢夺罪能包容评价为盗窃罪，抢劫罪当然也能直接包容评价为盗窃罪。
