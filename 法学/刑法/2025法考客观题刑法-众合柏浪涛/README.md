众合柏浪涛老师的法考刑法精讲卷。课程按刑法分则罪名逐章展开，配合客观题与主观题的答题方法训练，系统构建刑法体系的知识框架。

## 怎么学

- **先建框架** → 模块 01~09 打通总论与分则的体系，形成罪名之间的逻辑地图
- **分则攻坚** → 后半程逐罪名精讲，每讲配典型案例
- **答题方法** → 客观题抓构成要件，主观题按答题模板输出
- **考前冲刺** → `notes/` 下的笔记按罪名归类，便于快速回顾
