### 这套课的三个特点，和一个分工

各位学弟学妹好，我是柏浪涛。这套课是 2025 年法考刑法的精讲课程。开始讲刑法之前，先花几分钟把这套课的定位和用法交代一下。

这套课有三个特点。

第一个特点，主课一体化复习。同一套课既应对客观题，也应对主观题。

第二个特点，深刻讲解底层原理。为什么把这条单拎出来说？因为主观题考的是观点展示、说理论证，你不能光记一个结论，底层原理一定要理解好。所以我讲一个案件的分析过程时，你要跟住的是那个分析过程、那个说明理由，而不是最后蹦出来的那句结论。

第三个特点，理论立场。这一点最容易被忽略。我们刑法现在有两大学派：一派学习借鉴前苏联的旧理论、传统理论，一派学习借鉴德日的新理论。那我们法考采取的是什么理论立场呢？采取的是学习借鉴德日的新理论。所以这套课程的讲解立场，也是德日的。

> **易错点**：法考是一场考试，考试就是指挥棒。谁是指挥棒，我就跟谁走。我做学问，那我是有观点自由的；但在法考这个考场上，我个人是没有观点自由的。偏离了指挥棒，反倒是对广大考生的不负责任了。网上有人开玩笑说我是“古希腊研究张明楷的那尊神”，这也是没办法的事。

配套的书是众合教育出品的《刑法专题讲座·精讲卷》。除了这个精讲卷，我自己还搞了一个“过关四件套”：精讲卷、真题卷、背诵卷、模拟题卷，共四本，官网和各大购物网站都能买到。

很多同学问我：通过法考的经验有没有啊，给我传授一点什么捷径。我觉得没什么捷径。真要说经验就是一句话：尊重自己的选择。要么你就不选择这场考试，要么选择了咱就放手去干，不要想那么多，干就完了。

如果你做好了选择，而且还选了我，那真的是我的荣幸，那也是我们之间的缘分。我们之间做个分工吧：我负责从第一讲认认真真给大家讲到最后一讲，你负责从第一讲也认认真真听到最后一讲。那我们就从第一讲开始，相见。

### 先看一眼地图：总论三大块，四百多个罪名

把书翻到第一页，先看知识体系。我们刑法分为总论和分论：

```text
刑法
├─ 总论
│  ├─ 刑法论（＝刑法绪论、刑法概论）
│  ├─ 犯罪论 —— 解决定罪问题；主体部分，考得最多
│  └─ 刑罚论 —— 解决量刑问题；考得相对少很多
└─ 分论
   └─ 400 多个具体罪名，分类之后一个一个讲
```

总论分三大块：第一块是刑法论，其实就是刑法的绪论、刑法概论；第二块是犯罪论；第三块是刑罚论。犯罪论解决的是定罪问题，刑罚论解决的是量刑问题。但大家要注意，在刑法总论里面，犯罪论是主体部分、考得最多，它是老大；刑罚论、量刑这一块考得相对要少很多。

分论就是讲具体的罪名，一共有 400 多个，到时候我们分类，一个一个来讲解。

所以现在我们知道了，总论里主体部分是要学犯罪论。但前面还是得先把刑法论、刑法概论好好学习一下。把书翻到第三页，我们看第一讲刑法论。

### 两条研究路线：法考考的是解释论

第一讲是刑法论，第一节就是刑法的解释。为什么第一节是刑法的解释？刑法的解释为什么这么重要？因为刑法学研究分为两大研究路线。

```text
┌────────────────────────┐   ┌──────────────────────────┐
│      立法论研究        │   │     解释论研究           │
│                        │   │                          │
│  批判法条              │   │  解释法条的含义          │
│  修改法条              │   │        ↓                 │
│  完善法条              │   │  适用法条                │
│                        │   │        ↓                 │
│                        │   │  处理疑难案件            │
│                        │   │        ↓                 │
│  服务对象：            │   │  得出一个妥当的结论      │
│  立法者                │   │  服务对象：实务人士      │
│                        │   │  法官·检察官·律师        │
└────────────────────────┘   └──────────────────────────┘
```

立法论研究服务对象是立法者——批判法条、修改法条、完善法条。解释论研究是解释法条的含义，进而适用法条来处理疑难案件，得出一个妥当的结论，服务对象就是实务人士，就是法官、检察官、律师。

那大家给我猜一猜：法考考的是立法论研究，还是解释论研究。显然考的是解释论研究。考的就是你如何通过解释法条、适用法条来处理疑难案件。也就是说，解释法条、适用法条，才是刑法学人真正要打磨的本领。

### 一个没有生僻字的罪名：螃蟹案与饭盆案

有些同学会问：老师啊，解释法条有必要吗？我读过你们刑法典，里面没有生僻字，那含义很清楚的，需要什么解释？为什么这个解释法条、适用法条，还是考试的重点呢？

那你就不知道了。你如果孤立地看刑法条文，没有生僻字，好像都理解了；但你一旦遇到一个疑难案件，那就麻烦了。

最简单的例子，故意毁坏财物罪。法条摆在那儿，说“故意毁坏财物就是故意毁坏财物罪”。有的同学说，这几个词有什么难理解的，没有任何生僻字啊，我理解了，不用解释了。但是我说两个案例，那就不一样了。

第一个是螃蟹案。狗蛋养螃蟹，看到竞争对手狗剩也养螃蟹，他就要使唤人家。狗剩往池塘里投放的是珍贵的小蟹苗，然后慢慢饲养。结果狗蛋趁着狗剩不知道，晚上给人家池塘里又投放了大量的廉价蟹苗。池塘里的蟹苗数量就严重超量了。狗剩家那些珍贵的小螃蟹受不了了——你这是把人类内卷的机制引入到我们水产界了，让螃蟹都卷起来了，挤得要死。那些螃蟹大喊：受不了啦，卷死啦。最后狗剩家那些珍贵的许多蟹苗生长发育不行，大量死去了。

现在问你：狗蛋这么干，构不构成故意毁坏财物罪？这就是个问题，大家想一想。

说到螃蟹内卷，我不知道大家有没有看过《爱情公寓》。里面有人问律师张伟：你怎么通过法考的呀？张伟说我失败了好多次，直到有一天我逛超市，看到有一只被五花大绑的螃蟹，艰难地、努力地要从 18 块六的冰柜爬到 28 块六的冰柜里面去。我看到这一幕，泪流满面——螃蟹都比我有上进心，所以我要发愤图强，所以最后我做到了。

所以大家可以看到，螃蟹也卷，螃蟹也得卷，没办法。

第二个案例更简单。以前大学宿舍没有卫生间，有个室友狗蛋半夜要上厕所，嫌麻烦，嫌冷得要死，非要去楼道尽头的厕所，太麻烦了，那怎么办呢？直接朝室友狗剩的饭盆里撒了一泡尿。第二天呢，狗剩给气疯了。

那我们现在想一想：他这个算不算故意毁坏人家的饭盆？咱们先不考虑数额大小，先考虑定性问题。有人说这不算故意毁坏财物吧，因为还能用啊。而且狗蛋也给狗剩说了：我可以给你洗干净，你如果嫌脏，我用洗洁精给你泡一天，保证没有细菌，保证完璧归赵，还能用啊。诶，那我这算毁坏财物吗？这就是问题。

所以大家就可以看到：如果你没有联系这些疑难案件，从字面上去孤立地理解“故意毁坏财物”，那好像没什么歧义，也没什么要解释的必要；但一遇到我们具体的案件，我们就会发现需要解释法条的含义、去适用法条来处理这些案件。所以我们刑法的解释，就成为每年考试的重点。

### 解释的对象：刑法典与单行刑法

翻到第四页，第一个问题：解释的对象是什么？我们解释的法律文本有哪些？就两个。

第一个是刑法典。我们刑法典是 1997 年 10 月 1 日生效的。对刑法典还要做一些小修小补，那就是什么叫刑法修正案。刑法修正案至今一共有 12 个——这个大家一定要记住。

> **提示**：最近一个是第十二个刑法修正案，2024 年生效。它也是我们今年 2025 年法考的重点内容，在后面还会给大家讲。

第二个要解释的法律文本叫单行刑法。你知道有个单行刑法就行了，具体的内容你都不用去记。

### 解释的效力：立法解释压过司法解释

第二个问题，关于解释的效力。

| 解释主体 | 解释的名称 | 法律效力 |
| --- | --- | --- |
| 全国人大常委会 | 立法解释 | 有，效力最高 |
| 最高人民法院、最高人民检察院 | 司法解释 | 有，低于立法解释 |
| 学者 | 学理解释 | 没有法律效力，只能作为参考依据 |

可以作出对刑法条文的解释，这叫立法解释；最高人民法院、最高人民检察院对刑法典的条文也可以做解释，那就叫司法解释。

那谁的解释效力更高呢？显然是立法解释，立法解释的效力要大于司法解释。如果二者有冲突，以立法解释为准。

我们学者们也可以做一些解释，那就只能叫学理解释。学理解释有没有法律效力？显然是没有法律效力的，只能作为一些参考的依据。

### 解释技巧与解释理由：一个生产部门，一个质检部门

第三个问题，关于解释的方法。我们把它分为解释技巧和解释理由。

这两个有什么区别？解释技巧是生产结论的，它相当于一个生产部门；解释理由是论证这个结论的合理性，它相当于一个质检部门。所以一个是生产部门，一个是质检部门。

```text
      法律文本（刑法典、单行刑法）
                    │
                    ▼
   ┌────────────────────────────────┐
   │  解释技巧（五个）              │   生产部门：生产结论
   │  平义 · 缩小 · 扩大            │
   │  类推 · 反义                   │
   └────────────────────────────────┘
                    │
              ▼  产出的结论
   ┌────────────────────────────────┐
   │  解释理由（四个）              │   质检部门：论证结论
   │  文理 · 体系 · 当然 · 目的     │   的合理性
   └────────────────────────────────┘
                    │
                    ▼
              结论站得住脚
```

解释技巧一共五个：平义解释、缩小解释、扩大解释、类推解释、反义解释。解释理由一共四个：文理解释、体系解释、当然解释、目的解释。

这一节我们先看解释技巧。

### 五种解释技巧

#### 四个圈：平义、缩小、扩大、类推

前四个技巧要放在一起对比着学，因为它们是有关联性的。书上画了个圈，二环、三环、四环、五环，蓝色那部分是平义解释。

所谓平义解释，就是按照字面含义正常去解释，词义的含义范围既没扩大也没缩小——看山是山，看水是水。在这个基础上往两头推：比平义解释含义范围更窄的，叫缩小解释；比平义解释正常含义更宽的，叫扩大解释；把含义扩得更远的，叫类推解释。

这么一路排下来，重点难点就出来了：是扩大解释和类推解释的区分。因为扩大解释和缩小解释还是比较好区分的，但扩大解释和类推解释，都是把一个词义往大的扩，都是把词语往大的扩，那它们怎么去区分呢？

#### 扩大解释和类推解释：两把尺子

```text
┌────────────────────────────────────────────┐
│  类推解释：类推出去的行为与责任            │
│  尺一：已在词义射程之外        禁止        │
│  尺二：明显超出国民预测可能性  禁止        │
├────────────────────────────────────────────┤
│  扩大解释：结论仍在词义射程之内            │
│  尺一：未超出射程              允许        │
│  尺二：未超出国民预测可能性    允许        │
├────────────────────────────────────────────┤
│  缩小解释：比平义范围更窄                  │
├────────────────────────────────────────────┤
│  平义解释：字面含义                        │
│  看山是山，看水是水                        │
└────────────────────────────────────────────┘
```

首先要明白第一点：

> **结论**：我们刑法允许扩大解释，但禁止类推解释。二者性质都不一样。

所以这两者到底该怎么具体区分，就非常重要了。书上一共给了两个区分标准。

第一个区分标准：扩大解释得出的结论，还在词义的射程范围之内；类推解释的结论，已经在词义的射程范围之外了。

第二个区分标准：扩大解释的结论，没有超出国民的预测可能性；类推解释的结论，那就明显超出了国民的预测可能性。什么叫“超出国民预测可能性”？就是让人无法预料，让人感觉很意外——你竟然能这样解释是吧。

所以最后我们汇聚成一点就是：扩大解释就是你扯得还行，类推解释就是你扯得太远了。

> **易错点**：很多同学说，老师啊，你这个区分标准怎么感觉还是不够像理工科、像自然科学那样具体？你说到这的确是我们文科。我们法学提供的标准的确无法像人家数理化那样“一是一、二是二”，我们这个标准都没有那么精确。但是呢，这已经是我从命题老师那儿提炼出来的最精确的标准了。更重要的是什么？我们通过案例去练习，然后慢慢感受这个标准该怎么去运用，所以我们重点是要看这些案例。

#### 反义解释：从反面推

第五个技巧是反义解释，也叫反对解释，就是从反面推导。比如法条说“已满 16 周岁的人要对盗窃罪负刑事责任”，那么我们反面推理就是：未满 16 周岁的人，对盗窃罪就不用负刑事责任了。

好，解释技巧五个讲完了。简单回顾一下，最核心最难的是什么？最重要的是扩大解释和类推解释的区分。

### 三个案例：怎么判断是扩大还是类推

书上给大家还总结了一类常考情形，我们拿尺子量一量。

#### 遗弃罪：从家庭成员扩到扶助义务

第一个是遗弃罪。遗弃罪的犯罪主体和犯罪对象是什么？负有抚养义务的人。也就是说你负有抚养义务的人，你不履行这个抚养义务，把人家遗弃了，那就构成遗弃罪。

但是我们一般理解的“负有抚养义务的人”，往往把他理解成家庭成员，所以许多人就认为，这个遗弃罪必须是家庭成员之间的犯罪——比如父母遗弃子女、子女遗弃老人，就这样理解。但是呢，有时候它会出现这样的案例，你看怎么办。

比如有一家精神病院，医院领导就觉得有几个精神病患者，那种狂躁症，很麻烦，花了好多经费，太浪费了。所以领导们就集体决策想了个办法：开一个面包车把这几个精神病患者骗上车，还拉到一个郊外，然后骗人家下车，说“放水放水，撒泡尿，我们等你”。结果呢，这几个精神病患者一下车，领导开车门啪一关跑了，把人就遗弃在那、扔在那。

你说这种行为怎么办？能不能定罪？有些人说定不了罪。我们问为什么？他说定不了遗弃罪，因为遗弃罪的犯罪对象必须是家庭成员之间呀，现在精神病院的领导和精神病患者之间的关系不是家庭成员之间的关系，所以不构成遗弃罪。

那不构成遗弃罪，我们就问他：那你说这种行为算什么？就算放生吧？回归大自然吧？放虎归山，是这个意思吗？这肯定不行啊。我们觉得得定罪，那定什么罪呢？定遗弃罪。

说遗弃罪不是家庭成员之间的犯罪吗？你翻法条，遗弃罪的法条里面有没有写四个字叫“家庭成员”？没写。人家写的是什么？写的是“负有抚养义务的人”。

那“负有抚养义务”，我们就想一想：这个抚养义务是不是仅来自、仅限于家庭成员之间呀？那不是的。这个抚养义务，你可以把它扩大解释为扶助义务，也就是救助义务。它不仅仅来自于家庭成员之间，也可以来自于职务业务。那你说这个精神病院的院领导，对那些精神病患者有没有扶助义务呀？显然是有的。那你不履行这些扶助义务、这些抚养义务，情节严重的话，就要构成遗弃罪，所以他们应当是构成遗弃罪的。

所以我们现在就知道了：把遗弃罪的犯罪主体“负有抚养义务的人”，我们扩大到那些具有职务业务的那些人，我们认为这是一个扩大解释，不是类推解释。因为我们这扯得并不远，我们一般人也能接受，也没有明显超出国民的预测可能性——“哇，我太意外了，我接受不了这个结论”，不是的，是吧？我们认为这个解释还在词义的射程范围之内。

这就是扩大解释和类推解释的这么一个区分，大家要把它理解好。

#### 螃蟹和饭盆：财物、毁坏与功能

把扩大解释和类推解释理解了以后，我们回到前面那个案件。

比如螃蟹案，你把他家螃蟹给卷死了，那构不构成故意毁坏财物罪？狗剩养的螃蟹是不是狗剩的财物？是的。大家注意，财物可不一定要求只能是无生命的物品，人家养的狗、养的牛羊都是人家的财物，是吧？可以包括有生命的动物。

那现在就是，狗蛋这种卷法，算不算毁坏财物？我们认为肯定算。因为你投放一些蟹苗，把人家那些很珍贵的蟹苗给卷死了、饿死了，这也是毁坏的方式啊。你都是把人家那些蟹苗给毒死、杀死，你说有区别吗？没区别。所以他这个应当定的是故意毁坏财物罪。

那有同学问我：那个给人家饭盆里面撒尿的，算不算故意毁坏财物？那我们就要注意了。毁坏的平义解释是什么？就是物理性的毁坏。比如说你把人车给砸了，把人饭碗给砸了，这就叫毁坏。但是呢，我们毁坏还可以扩大解释为包括了功能性毁坏，也叫用途性毁坏——把人车砸了，最终的效果就是让人没法用了，所以呢我们要从效果、用途、功能上来说。

那现在问题来了：你说这个饭盆的功能，不就是打饭、盛饭吗？但是狗蛋说，从这个角度来说，这物理性功能没丧失啊，还是能打饭的，狗剩你打个汤都没问题。但大家想一想，我们这个功能、用途，我们既包括客观角度的功能用途，我们也要考虑主观角度的功能用途。也就是说你给人家饭碗里面撒泡尿，你觉得一般人还能用吗？从一般人的观念，这玩意儿还能用来打饭吗？那就不能用来打饭了。所以呢，从主观的角度来说，你也让人家这个打饭的功能丧失了，那这就算毁坏。

所以这就是一个对“毁坏”的扩大解释：也就是说从物理性的毁坏，扩大到功能性的毁坏；而功能又既包括客观角度的功能，也包括主观价值角度的功能。那这就是一步一步的扩大解释。

那为什么不是类推解释呢？我们觉得这扯的不算是远了，因为我们一般人都能接受，没有超出国民的预测可能性是吧。大家不会觉得特别意外——“这你这就是毁坏人家的饭盆了嘛”，是吧？这和把人饭碗给砸毁了，在效果上是没什么区别的。

#### 运钞车：算不算金融机构

我们看考试有时候还可以怎么考。我们做一道考试题，考试考了个什么呢？就是那个运钞车算不算银行？算不算银行机构？算不算金融机构？

因为实务中发生过这样的案件：在一个银行门口，人家五点下班了，银行人员把现金装到运钞车上。这个运钞车开走大概有一公里，结果被人家两个面包车给拦了。那面包车下来几个歹徒，很猛啊：先扔个烟雾弹，然后再来一个机枪扫射，最后把人家的现金全部给抢走了。

那这种案件，我们知道肯定很快就会被抓。那抓了以后，法官就判他构成抢劫罪，而且符合了抢劫罪法定的加重处罚情节，叫抢劫金融机构。而且一旦是普通的抢劫罪，判的是 10 年以下有期徒刑；一旦是抢劫金融机构，那就是 10 年到死刑——因为起步价就 10 年了。

所以呢，法官要判抢劫金融机构，结果人家这几个被告人、这几个歹徒说：法官你判的不对，我是学过刑法的，我专门为了规避抢劫金融机构、为了规避死刑，我就没有去那个银行里面去抢，因为我知道如果冲到银行里面去抢，那就属于抢劫金融机构了。我特意抢他的运钞车，运钞车怎么能是金融机构呢？所以我特意抢运钞车啊。你如果抢运钞车都算抢劫金融机构，那我还费劲干嘛，我直接就冲进去、冲到银行大楼里面去抢了。

那你是法官，你怎么去回答他呀？你可以这样回答：你们这几位兄台呀，是只知其一不知其二。你们那个呀，是一个什么平义解释。我们还有一个扩大解释。也就是说，“银行机构”“金融机构”啊，它不局限于大楼、不局限于大厅，它还包括他的一些附属的设施设备，那运钞车就是人家的附属的设施设备。我们把运钞车解释为金融机构，我们认为没有超出“金融机构”这个词义的射程范围，也没有明显超出国民的预测可能性，所以我们是扩大解释，我们不是类推解释。所以这个扩大解释的结论是被允许的，我们可以给你判抢劫金融机构，而且你我起步价就可以判 10 年了。现在呢，你们俩太猛了，机关枪扫射，那我当然可以判顶格，判死刑了。

### 解释理由：结论凭什么站得住

好，解释技巧五个讲完了。结论生产好了以后，那这个结论到底能不能站住脚，还需要理由来支撑。书上一共有四个：文理解释、体系解释、当然解释、目的解释。这都是比较重要的。

#### 文理解释

文理解释是什么意思？就是你解释出来的这个结论，在文法上、文理上要能够说得通。你不能连文法语法都不符合，这是不行的。

我们考试就考过一道真题，2015 年的题：把丈夫强奸妻子解释为构成强奸罪，这在文理上能不能说得通？他就问这个问题。我们的结论是，在文理上是能说得通的，也就是说，丈夫是有可能构成强奸罪的。

但有的人说，咦，这文理上怎么能说得通啊？我怎么听说婚内强奸不构成强奸罪？哎，那你那是一种误解。法条在文理上并没有把强奸罪的犯罪主体规定为“不包括丈夫”，没有这样规定。既然文法上没有这样规定，所以我们经常说“婚内强奸有可能不构成强奸罪”，那指的是证据证明问题——也就是说，有时候证据不太好证明。但是一旦证据能够证明这个丈夫符合我们法条的规定，那是有可能构成强奸罪的，实务中也有这样的判例。

十几年前上海就发生一个案例：有一个甲女，在父母的逼迫下被迫嫁给了乙男，但这个乙男有时候对甲女态度也不好啊——因为这有时候也是相互的。后来这个甲女搬出去住了，等于说就分居了，而且还起诉离婚。后来法院一审没有判离婚。这个甲女就想，那再过半年我再继续起诉离婚，反正她是在外面住。

有一天这个乙男就火大了，他就守在这个甲女的单位门口，等她下班。甲女刚一出来，他直接就把人劫持到车上，强行带回家，强行就强奸了。最后这个甲女呢，人家就报案了。大家想一想：你是法官，这个判犯强奸罪？法院最后判的就是强奸罪。因为也就是说，这个完全符合了法条的规定，从文理上这是能解释得通的，理由是能解释得通的。

所以大家就知道，所谓的“婚内强奸不构成强奸罪”，主要是证据法上的问题。我们刑法方面，从文理上是构成的。当然有的同学说，那即使给这个丈夫定了强奸罪，但量刑是不是还是得考虑轻一点啊，跟一般的普通的那种歹徒强奸是不是不一样呀？你可以这样去考虑，是吧，那都是量刑的事情了。

#### 体系解释的入口：同一用语的含义相对性

体系解释是我们这里面的重点内容。体系解释的意思是：你这个解释的结论，你在体系上要协调，你不能有矛盾，你不能冲突，是吧。

那体系解释的第一个考点是什么呢？叫同一用语的含义的相对性。啥意思呢？简单讲就是一词多义。我们经常考一词多义，其实实务中、生活中一词多义的现象也很多，原理其实都是一样的。

比如考研面试，人家考官就问一个法科生：你法考考过没？这个考生张口就来一句“考过了？没考过？”——同一句话里就并着两个相反的意思。这正是同一用语的含义相对性：问句还是那句问句，含义却随着语境来回摆动。

> **提示**：体系解释是这一节的重点，第一个考点只是入口——先把“一词多义”四个字记住。

### 本讲提到的题目

#### 运钞车抢劫案：运钞车算不算金融机构

**题干**：某银行五点下班，银行人员把现金装上运钞车，运钞车开出约一公里即被两个面包车拦截。歹徒先扔烟雾弹，再以机枪扫射，将现金全部抢走。法院以抢劫罪定罪，并认定为抢劫金融机构的法定加重处罚情节（普通抢劫罪为 10 年以下有期徒刑，抢劫金融机构为 10 年至死刑）。被告人抗辩称：我学过刑法，我专门为了规避“抢劫金融机构”、规避死刑，就没有去银行里面抢，我特意抢运钞车，运钞车怎么能是金融机构呢？

**答案**：构成抢劫罪，且属于抢劫金融机构的法定加重处罚情形，被告人的抗辩不成立。

**解析**：被告人只知其一不知其二，其采用的是平义解释。“金融机构”不局限于银行大楼、大厅，还包括银行的一些附属设施设备，运钞车就是银行的附属设施设备。把运钞车解释为金融机构，没有超出“金融机构”这个词义的射程范围，也没有明显超出国民的预测可能性，属于刑法允许的扩大解释，而不是被禁止的类推解释，所以这个结论可以被采纳。另外，本案歹徒用机枪扫射，情节严重，可以顶格判处死刑。详见正文「运钞车：算不算金融机构」。

#### 丈夫强奸妻子是否构成强奸罪（2015 年真题）

**题干**：有真题问：把丈夫强奸妻子解释为构成强奸罪，这一解释在文理上能不能说得通？

**答案**：能说得通，丈夫是有可能构成强奸罪的。

**解析**：法条在文法、文理上并没有把强奸罪的犯罪主体规定为“不包括丈夫”，没有这样的规定，所以这个解释在文理上是通顺的。所谓“婚内强奸不构成强奸罪”，指的是证据证明问题——这类案件证据往往不太好证明；一旦证据能够证明丈夫符合法条规定，即有可能构成强奸罪，实务中已有此类判例。定罪成立之后是否从轻，那是量刑阶段的事情，不影响定罪。详见正文「文理解释」。

#### 遗弃罪案例：精神病院领导遗弃精神病患者

**题干**：某精神病院的几个精神病患者患有狂躁症，医院领导觉得他们很麻烦、花费经费太多，遂集体决策，用面包车把几人骗上车拉到郊外，骗其下车后驾车离去，把人遗弃在那里。该行为构成何罪？

**答案**：构成遗弃罪。

**解析**：遗弃罪法条写的是“负有抚养义务的人”，并没有写“家庭成员”四个字。抚养义务并不仅仅来自家庭成员之间，也可以来自职务业务——把它扩大解释为扶助义务、救助义务，精神病院的院领导对精神病患者负有扶助义务，不履行且情节严重的，构成遗弃罪。这个扩大没有超出“负有抚养义务的人”的词义射程，也没有明显超出国民的预测可能性，是扩大解释而非类推解释。详见正文「遗弃罪：从家庭成员扩到扶助义务」。

#### 螃蟹案与饭盆案

**题干一**：狗蛋趁竞争对手狗剩不注意，往狗剩的养蟹池塘里大量投放廉价蟹苗，导致蟹苗严重超量、狗剩那些珍贵蟹苗大量死亡。狗蛋是否构成故意毁坏财物罪？

**题干二**：某大学宿舍没有卫生间，狗蛋半夜嫌麻烦、嫌冷，直接朝室友狗剩的饭盆里撒了一泡尿。狗蛋是否构成故意毁坏财物罪？（先不考虑数额大小，只考虑定性）

**答案**：两案均构成故意毁坏财物罪。

**解析**：财物不限于无生命的物品，人家养的狗、养的牛羊都是财物，可以包括有生命的动物，蟹苗当然也在内。投放蟹苗把人家珍贵蟹苗毒死、杀死，和直接把别人的财产砸了，在毁坏的效果上并无区别。而“毁坏”的平义只是物理性毁坏（砸车、砸饭碗），可以扩大解释为功能性毁坏、用途性毁坏：功能既包括客观角度的功能，也包括主观价值角度的功能——饭碗在客观上也许还能盛饭，但从一般人的观念，沾了尿的饭碗已经不能用来打饭了，打饭的功能已经丧失。两处扩大都仍在词义射程之内，没有超出国民的预测可能性，故为扩大解释。详见正文「螃蟹和饭盆：财物、毁坏与功能」。

## 刑法的解释：法条只给一句话，答案从哪里来
> 对应块：BLK02 | 覆盖分集：P01下 | 块标题（分集名）：《第01讲 第01节：刑法的解释》

先从一句让人哭笑不得的话说起。

考官问一个考生："你到底考过没有？"考生说："我考过，但没考过。"

你一听，这话不是自相矛盾吗？但你再想想，字面上说不通，意思上却完全说得通——考试考了，只是没考及格呗。这就是一个词在同一天里跑出了两种意思。

法条里大量玩的就是这个把戏。中文的词太省了，一个"传播"能包办新闻业和医学的两份工作，一个"收买"能包办买卖人口和策反公安的两份事业，一个"周"字能包办七天和一整圈。所以刑法解释的第一件事不是解释句子，是先把词钉在它该待的那个位置上。

下面这一段，我们就把刑法的解释里最讲得透、也最容易在考场上拉开差距的几块过一遍：体系解释里的三种手法、当然解释的前提、目的解释引出的观点争议，最后用一道 2019 年的真题把这堆东西串起来检验一遍。

### 一词多义：同一个词，在不同罪名里各说各话

一词多义是体系解释里最基础的一种。"传播"两个字，写在《刑法》不同条文里，法律地位完全不同。

2019 年考过一道题，问的是：传播性病罪中的"传播"，和传播淫秽物品罪中的"传播"，含义一不一样？答案是**不一样**。

为什么不一样？说清楚这两个"传播"分别在干什么就清楚了：

- 传播淫秽物品罪里的"传播"，指的是**新闻媒体传播**。我们很多大学设有新闻传播学院，新闻传播是什么意思？就是使不特定人或者多数人知晓其内容。
- 传播性病罪里的"传播"，指的是**传染**。跟新闻媒体一点关系都没有。

> **易错点**：有同学一看到"传播性病罪"就往"让多数人知道"上想，觉得不就是拿个大喇叭到处喊"我给大家宣布个事儿，我得了性病"，让多数人都知道吗？这能叫传播性病罪？不能。喊得再大声，那也只是"传播"了消息，既没有把病菌传出去，也没有"传染"这个行为。有人得病，和有人被传染是两件事。

那"收买"呢？巩固一个：**收买被拐卖的妇女儿童罪**里的"收买"，是花钱买人、买一个妇女、买一个儿童，是**收买肉体**；而**武装叛乱罪**的法条说"策动收买警察进行武装叛乱"，这里的"收买"是**收买人心**。你总不能理解成花钱买个警察，玩一玩吧？一个收的是人，一个收的是人心，写的都是"收买"，讲的不是同一件事。

> **定义**：一词多义。同一法律中的同一个词，在不同条文、不同罪名中具有不完全相同的含义，必须根据它所处的规范位置来确定它到底指什么。判断的第一步，永远是先把这个词所在的罪名圈出来。

至于开头那个"我考过但没考过"，同类的生活例子还有。前几年疫情期间，一位医生把一个抗原检测试剂（俗称"钢柿子"）交给一个男的，叮嘱他拿回去检测，拿着"钢柿子"旋转一周。结果这兄台果真把这个检测试剂在肛门旋转了**七天**——人家说旋转一周，他旋转了七天。我估计这家伙可能上瘾了。你看，"一周"这个词至少能读出两种意思：一星期是七天，一周是一个圆周。中文只要给你一个省略了量词的数，它就同时开着两个后门。

### 多词一义：恐吓、威胁、胁迫，本来就是一家人

一词多义的反面是多词一义，学名叫"**不同用语的含义同一化**"。这个词在生活里太常见了：以前叫竞争，现在叫内卷；以前叫生闷气，现在叫情绪内耗、精神内耗；以前叫缺心眼，现在叫钝感力；以前叫穷游，现在叫特种兵。词换了三个，意思就那一个。

刑法里的典型是**恐吓、威胁、胁迫**。它们是一个意思：**以恶害相通告，使对方产生恐惧心理**。

举个最直观的例子：拿人家的裸照，说"不给我 10 万元，我就把你的裸照曝光"。你管这叫恐吓？叫。叫威胁？也叫。叫胁迫？还是叫。三种叫法都成立，成立的是同一个罪——敲诈勒索罪。

> **结论**：多词一义。不同法律用语指向同一个含义，做题时不要因为法条换了个词就觉得范围变了。恐吓、威胁、胁迫的共同内核是"以恶害相通告"这五个字。

### 同类解释规则：兜底条款的边界，靠"找公因式"划出来

这一条是这一节里最实用的技术活。

先看法条。抢劫罪的条文写的是：**以暴力、胁迫或者其他方法抢劫他人财物的，构成抢劫罪。**请注意一个细节——"胁迫"后面没有顿号，它直接接了"其他方法"。

这种"其他方法""其他情形"的表述，刑法里到处都是，我们管它叫**兜底条款**、**兜底规定**。问题也就随之而来：考试问，抢劫罪里的"其他方法"，是不是指暴力、胁迫之外的其他一切方法？显然不是。要真是"其他一切方法"，这个条款就等于把整个刑法都装进去了。

那怎么给它划边界？靠**同类解释规则**：先看条文已经列举出来的那几项，找出它们的同类项、提取公因式，找到共同特征，再用这个共同特征去约束"其他方法"。

已列举的是暴力和胁迫。一刀把人砍晕了，是暴力型抢劫；把刀架在人家脖子上，不给钱就要砍他的脑袋，这是胁迫型抢劫。取公因式，暴力和胁迫的共同特征是什么？

```text
[条文] 以暴力、胁迫或者其他方法抢劫他人财物
                              |
        暴力、胁迫 = 已列举项      "其他方法" = 兜底项
                              |
                   兜底项不能单独看，范围无边无际
                   总不能是暴力、胁迫之外的"一切方法"
                              |
                  同类解释规则：先找已列举项的公因式
                              |
        暴力：一刀把人砍晕            胁迫：把刀架在脖子上
                              |
                    提取共同特征（公因式）
                              |
                    共同特征：足以压制人反抗
                              |
                              v
       "其他方法" = 其他足以压制人反抗的方法
                              |
              昏醉抢劫 / 智取生辰纲 都从这里进来
```

公因式一落地，边界就出来了：**其他方法 = 其他足以压制人反抗的方法**。关键词是"足以压制人反抗"——让被害人没得选。

最常见的例子是**昏醉抢劫**。你想拿人家东西，先下个迷药把人弄晕、弄醉，弄到不省人事，然后趁机把东西拿走，这就是昏醉抢劫。它既没有暴力，也没有胁迫，凭什么还能构成抢劫罪？因为下药使人昏迷、醉酒，本身就是一种足以压制人反抗的方法。

这里有个地方特别容易搞错，必须掰开看：

| | 昏醉抢劫 | 盗窃 |
| --- | --- | --- |
| 被害人为何失去反抗能力 | 行为人带着取财目的主动下药弄晕、弄醉 | 被害人自己醉了、自己晕了 |
| 行为形态 | 带走财物之前先制造压制状态 | 路过发现，趁其不能察觉取走财物 |
| 定性 | 抢劫罪 | 盗窃罪 |

同样是"人已经不省人事了，财物被拿走了"，差别只在**这个不省人事是谁造成的、是不是为了取财**。行为人自己动手制造的压制状态，是抢劫；被害人自己倒在路边、你顺手牵羊，是盗窃。

> **易错点**：昏醉抢劫不是盗窃。判准只有一条——行为人是不是带着取财目的把人弄晕、弄醉的。

你把这个理解了以后，会发现《水浒》里一个著名的桥段立刻变了味。**智取生辰纲**，小时候我一听"智取"两个字，觉得厉害，还以为就是诈骗嘛、骗嘛、骗取嘛。学刑法以后才知道吴用他们是怎么"智取"的：吴用带着阮小二、阮小五，给杨志押运的那个队伍下了蒙汗药，人家喝了蒙汗药不省人事了，然后把生辰纲运走了。

这叫诈骗吗？显然不是。这是截取，是抢劫。他们是抢劫犯，不是诈骗犯。原来是个昏醉抢劫。

> **定义**：同类解释规则。法律用语中冠有"其他""其他情形"等兜底表述时，应当从其前列列举的事项中提取共同特征，据以限定兜底部分的范围。

### 当然解释：两条比较规则，和一个不能忘的前提

第三个理由叫**当然解释**。先破除一个误解：当然解释不是"想当然地去解释"，它里面是有逻辑推理的，具体说是一种**比较推理**，一共就两句话。

第一句：**入罪时举轻以明重**。要给人定罪，得遵守举轻明重的逻辑。举例：如果强制猥亵都构成犯罪，那么强奸更应当构成犯罪。因为强制猥亵是个轻行为，轻行为都入罪了，重行为当然更入罪。

第二句：**出罪时举重以明轻**。假如抢劫都不构成犯罪，那么盗窃更不构成犯罪。这个推导对不对？对的。因为抢劫是重行为，重行为都不构成犯罪，轻行为更不构成犯罪。

> **易错点**：考试就是在这两句上设陷阱的。我们一看到"举重以明轻、举轻以明重"，马上反应过来这是重行为和轻行为之间的比较推导，但**当然解释有一个前提**——这个轻行为和重行为必须**性质相同**。它们得是"性质相同、程度不同"的关系，只有这样才能推。

哪些能比？强制猥亵和强奸，性质相同、程度不同，能比。抢劫和盗窃，都是取财的手段，都属于财产犯罪，性质相同、程度不同，能比。

哪些不能比？来两个练手：

- "如果抢劫都不构成犯罪，那么更轻的强制猥亵也不构成犯罪。"——不行。强制猥亵跟抢劫性质不同。
- "如果强制猥亵都构成犯罪，那么抢劫更构成犯罪。"——也不行。强制猥亵跟抢劫性质不同。

> **结论**：举轻以明重、举重以明轻，只能在"性质相同、程度不同"的行为之间进行。跨性质比较一律不成立。

这个道理在生活里也一样。我们每个人都喜欢跟人家比一比，心里比一比，但比的都是身边人——你不会跑去跟马云比谁有钱，也不会去跟张艺兴比谁更帅。乞丐不一定会嫉妒百万富翁，他只会嫉妒比自己乞讨得更透的那个乞丐。这不是一句玩笑，"既怕兄弟生活苦，又怕兄弟开路虎"，讲的正是这个：只有同一序列里的东西才有可比性，一比较才有意义。当然解释的推导，靠的也是这个前提。

2024 年的真题就是照着这个逻辑出的：问"抢夺国有档案都构成犯罪，那么抢劫国有档案呢？更构成犯罪"，这个推导对不对？对的，因为抢夺与抢劫性质相同、程度不同，推导成立。看起来不难，但前提得先想明白。

顺便插一段。这一块我要放慢语速，有同学嫌我讲得太慢，我早年讲课语速特别快，后来发现语速一快许多人听不懂。为什么？因为刑法理解性太强了，它不是诉讼法那种程序性规定，那"哒哒哒"快一点没问题；但刑法的逻辑推导，语速一快你就跟不上了。所以我还是有意放慢一点。当然了，真觉得自己理解能力够、就是想快点的同学也没问题，现在技术做得到，1.25 倍、1.5 倍你随便调，这都不影响你。

### 目的解释：一条"升迁计"，逼出诬告陷害罪的两种解读

目的解释怎么用？看一个实务里真实发生过的案子就明白了。

有一个**甲**，是个官员，很廉洁，但他觉得一直升不上去，也很苦恼。有一天他跟朋友**乙**说："你看我这人这么廉洁，还没升上去，很苦恼，有什么办法？"

乙说我有一计，保证你行。你找个人去诬告你，说你是个贪官，说你贪污了 100 万。这样司法机关肯定会查，但你又不怕查——一查发现你清廉，不就查出来了吗？那你就有升迁的机会了。

甲一听，好主意。甲说："那我不找别人告我了，主意就是你出的，你就来告我吧。"乙说不行，你这不构成诬告陷害罪吗？最后实在没办法，告吧。于是乙诬告甲贪污 100 万，司法机关赶紧查，一查发现这个甲真的很廉洁，大家才知道这甲确实很廉洁。甲很高兴，觉得这下自己有升迁机会了。

结果是事情被别人知道了，人家一举报，**两个人都被抓了**。

乙涉嫌**诬告陷害罪的实行犯**，甲涉嫌**诬告陷害罪的教唆犯**。这两个人构不构成诬告陷害罪？到这里，目的解释就该出场了——问的不是行为像不像诬告，而是**这个罪名到底保护什么**。答案分两派：

| 观点 | 结论 | 论证理由 |
| --- | --- | --- |
| 少数说 | 构成诬告陷害罪 | 诬告陷害罪的保护目的是**司法机关的正常活动**。你诬告陷害不是纯粹在折腾司法机关吗？白白浪费司法资源，所以要构成这个罪。 |
| 多数说 | 甲、乙都不构成 | 刑法设置这个罪名的保护目的是**公民个人的权利**，即自由权、名誉权。既然是公民个人的权利，个人就可以放弃——我不要你刑法保护了。个人的权利可以承诺放弃，但国家的一些权利法律，你没有权利承诺放弃。甲自愿被诬告，说明他已经放弃对自己名誉权、自由权的保护，刑法就不必再保护，诬告的人自然不构成诬告陷害罪。 |

那为什么我们说第二种是**多数说**？关键不在哪派讲得更好听，而在于翻法条：这个诬告陷害罪规定在哪一章？一翻法条，诬告陷害罪只规定在**人身犯罪**（侵犯人身权利）那一章。既然它被放在人身犯罪章里，它保护的目的就只能是公民个人的自由权、名誉权。条文自己已经把答案写在章的位置上了，所以它是多数说。

### 观点展示怎么考：逻辑自洽，以及刑法界的"四个圈"

这个案子顺手就把主观题的一个大关交代了，主观题经常考**观点展示、观点论证**。

刑法学里有一个观点：一个案件一般来说很难有唯一正确答案，基本上都是观点展示、观点论证。比的其实不是"谁是唯一正确"，而是**谁的论证理由更充分**。所以我在讲有些观点展示的时候，会特意把观点摆出来，同时标上哪个是多数说、哪个是少数说。

为什么要标？因为客观题也常考。客观题是选择题，考的是唯一定论、唯一正确答案，那你就得按多数说答。反过来说，如果我讲某个观点展示时**没有**标明多数说、少数说，就意味着这个知识点还没有形成多数说和少数说，各家平分秋色、平起平坐，那客观题就不会考它的唯一正确答案。

那没有唯一定论的时候怎么考？不管客观题还是主观题，考的都是**观点论证、说明理由**——考你的结论和你的前提在逻辑推导上上不上得去，也就是**逻辑是否自洽**。刑法特别特别喜欢考逻辑论证、逻辑自洽的问题，看你能不能说理充分、能不能自圆其说。

举个小例子。疫情期间我们要线上上课，有一次有个学生没上线，我怕他逃课，还是给他打了个电话。电话那头他说："老师，我这边信号不好。""什么？我听不见。""你是真听不见还是假听不见？""我真听不见。"

这里面逻辑论证就不自洽了——说谎都不知道，都没有做到自圆其说。我们练主观题的时候，最起码的标准就是自圆其说、逻辑论证要成立，这个要求不低。

> **提示**：由此还会带出一个让人困惑的现象：学到后面你会发现，法考刑法里的大量观点，和法硕考试里的观点不一致，甚至和实务中的观点也不一致。为什么会这样？因为刑法有**四个圈**，也叫四个界：**理论界、实务界、法考界、法硕界**。这四界相对独立，同一个问题可能各有各的答案。这很正常，真正的疑难案件本来就没有唯一定论，人家考观点展示，讲的就是这个道理。

很多同学还会问：法考和法硕都是考试，为什么观点还不一样？道理很简单——**两个考试的组织者不同，命题老师不同**，观点不一样很正常。不过这就苦了双考的同学：既考法考又考法硕，等于要建两套系统、装两个观点。当然这也是锻炼你，能参加双考，说明你还是勇于挑战的。

在这里我要重点提醒一个态度问题。我们很多同学不同意法考的某些观点，就骂人家，甚至人身攻击人家，我觉得这不对。你要明白，**法考是一场考试，考试是过桥**——不是站在桥上欣赏风景，更不是在桥上跟命题老师干起来。我们是赶紧匆匆过了这个桥，拿到执业证以后，那时候你爱坚持什么观点，那都是你的自由。

所以法考这套东西并不是让你心悦诚服地接受某个观点，只是让你知道有这么一个观点，然后看它的逻辑是否自洽，就 OK 了。观点是观点。千万不要因为某个观点跟你内心不一样，就排斥它、讨厌它，甚至人身攻击它，没必要。

最后送一条减少精神内耗的建议：**一派到底**。你既然选了某位老师，而这位老师采取的是学习德、日理论这套立场，那你就跟着他走到底。因为刑法的观点冲突本来就多，中途换来换去，对你是不利的，还白白浪费你好多时间。

### 解释技巧与解释理由：一条生产线，四套论证理由

解释技巧讲完了，解释理由也讲完了，现在说这两者之间的关系。这个关系是必考的。

打个比方就清楚了：**解释技巧是生产线，负责生产结论；解释理由是负责论证这个结论的合理性。**

第一条关系，是**解释技巧之间的关系是排斥关系**。生产线只有一条，一个结论只能由一条生产线生产出来，你不能说"我这个解释既是扩大解释，又是缩小解释"——那就自相矛盾了。

第二条关系，是**解释理由之间的关系是并存关系**。理由越多越好，论证越充分。文理解释、体系解释、目的解释、当然解释，它们之间不是对立排斥关系，而是并存关系。

第三条关系，是**解释技巧与解释理由之间的关系是相辅相成关系**。一个生产结论，一个论证结论的合理性，谁也离不开谁。

```text
                      结论：法条到底怎么用
                              ^
              +---------------+----------------+
              |                                |
     解释技巧：生产结论              解释理由：论证合理性
              |                                |
        排斥关系                            并存关系
   一条生产线只能产出一个结论        理由越多越好，论证越充分
   既是扩大又是缩小 = 矛盾           文理解释/体系解释/
              |                    当然解释/目的解释
              |                                |
              +---------------+----------------+
                              |
                          相辅相成
```

顺带再把体系解释内部的三个数一下：多词一义、一词多义、再加一个同类解释，一共三个。

### 2019 年那道真题：四个选项各在考什么

下面做一道 2019 年的真题。题干是：关于刑法的解释，下列说法正确的是——

**A 项**：按照体系解释，传播淫秽物品罪与传播性病罪的"传播"含义一致。

错的。这里考的就是一词多义：传播淫秽物品罪的"传播"指新闻媒体传播，传播性病罪的"传播"指传染，两者含义根本不一致。

**B 项**：依据目的解释，倒卖文物罪的"倒卖"是指以牟利为目的出售，或者为出售而购买国家禁止经营的文物。

这一项说法是对的，而且它背后藏着一个很有意思的司法解释故事。

从字面含义理解，"倒卖"应该是"买进再加卖出"，也就是必须是个二手贩子——便宜的进货，再卖出——才能构成倒卖文物罪。可是有一天出现了这样一个案子：**狗蛋偷了一个文物，然后把它卖掉。**偷文物构成盗窃罪，这没问题；但现在要卖掉的部分，要不要给他定一个倒卖文物罪？

当时真要给他定的时候，狗蛋说不能定。为什么不能定？他说："我以前也学过刑法啊，倒卖文物罪的'倒卖'，指的是二道贩子倒来倒去，便宜的货进货然后再卖出。我现在不是啊，我不是买进加卖出，我是偷来以后卖，所以我不是倒卖。"

法官一听，觉得人家说的好像还真有点道理。那怎么办？我们觉得还是得定。于是找最高法院，最高法院最后出了司法解释：说"倒卖"的核心含义是"卖"，"买进"这个修饰语可以去掉。所以，"倒卖"就被解释为**以牟利为目的的出售**——只要有卖的行为就行；或者说**为出售而购买**，进货再卖也行。但只要有"出售"，"卖"和"出售"就是一个意思——这里又是多词一义。

所以你看，这个司法解释背后是有目的的：把"卖"这个词从"买进加卖出"里单独拎出来保护住。B 项的说法是对的。

**C 项**：把招摇撞骗罪中的"招摇撞骗"解释为"冒充国家机关工作人员招摇撞骗"，说不符合文理解释。

这个说法是错的。我们想一想"冒充国家机关工作人员"能有哪些情形。一般理解的情形是什么？就是一个平头老百姓冒充官员，这当然算冒充。这是对"冒充"的一个**扩大解释**，而这种扩大解释一般人完全能接受，扩大解释也不等于类推解释，所以这样解释是可以的。语法上符合，文理方面也符合——"冒充"这个词有时候就是包含各种情形，只要是假的就算冒充，冒充就是说"你是假的、不是真的"。

所以 C 项说它不符合文理解释，这个说法是错的。

**D 项**：虐待被监管人罪是指殴打或体罚虐待被监管人，说将其中"体罚虐待"解释为"体罚或者虐待"，符合文理解释。

这一项说法是对的。但这里有个细节特别值得注意。有些同学会说，这解释很正常，没什么问题，为什么要考？是因为实务中有人这样解释：他说"体罚虐待"指的是**体罚式的虐待**——这里面的意思是只有虐待，不存在虐待的一种手段是用体罚的方式去虐待他。

这样解释的问题在哪里？在于你把这个词的词义给**限缩**掉了，是我们从文理上来讲，"体罚虐待"可以解释为"体罚或虐待"，二者可以拆开，是一个并存关系，这样解释才更合理。

所以答案是 **B、D** 两项。

### 回头扫一眼：这一节的骨架

最后我们一起回顾一下。

刑法的解释，一共有两个方法：**解释技巧**和**解释理由**。

解释技巧有五个：平义解释、缩小解释、扩大解释、类推解释、反义解释。这里考得最多的是**扩大解释和类推解释的区分**——扩大解释，刑法是允许的；类推解释，刑法是禁止的。怎么区分，我们前面举了好多例子。

解释理由有四个：**文理解释、体系解释、当然解释、目的解释**，这四个都是常考的。

最后还讲了它们之间的关系：技巧与技巧之间是排斥关系，理由与理由之间是并存关系，技巧与理由之间是相辅相成的关系。

### 本讲提到的题目

#### 第一题：2019 年真题（多选）

**关于刑法的解释，下列说法正确的是：**

A. 按照体系解释，传播淫秽物品罪与传播性病罪的"传播"含义一致

B. 依据目的解释，倒卖文物罪的"倒卖"是指以牟利为目的，出售或者为出售而购买国家禁止经营的文物

C. 招摇撞骗罪中的"招摇撞骗"解释为"冒充国家机关工作人员招摇撞骗"，不符合文理解释

D. 虐待被监管人罪中的"体罚虐待"解释为"体罚或者虐待"，符合文理解释

**答案：B、D**

**解析：**

- A 错。这里考的是**一词多义**。传播淫秽物品罪的"传播"指新闻媒体传播，即使不特定人或多数人知晓其内容；传播性病罪的"传播"指传染。两者含义不一致。依据见"一词多义"一节。
- B 对。这是一条最高法院司法解释：把"倒卖"中的"买进"这一修饰语去掉，"倒卖"的核心含义是"卖"，即以牟利为目的的出售，或为出售而购买。依据见"2019 年那道真题"一节中 B 项的狗蛋故事。
- C 错。平头百姓冒充官员属于"冒充"的扩大解释，扩大解释并不违反文理解释，也不是类推解释；只要是假的即属冒充。C 项的判断结论错了。依据见"2019 年那道真题"一节中 C 项的讲解。
- D 对。"体罚虐待"应拆解为"体罚或虐待"二选一，二者是并存关系；把它解释成"体罚式的虐待"属于不当限缩了词义。依据见"2019 年那道真题"一节中 D 项的讲解。

#### 第二题：2024 年真题（逻辑推导）

**已知抢夺国有档案构成犯罪，那么抢劫国有档案是否更构成犯罪？这一逻辑推导是否成立？**

**答案：推导成立。**

**解析：** 当然解释的推导有前提——只能比较"性质相同、程度不同"的行为。抢夺与抢劫同属财产犯罪，性质相同、程度不同，所以"轻的抢夺都入罪，重的抢劫更应入罪"的推导成立。依据见"当然解释：两条比较规则，和一个不能忘的前提"一节。

## 刑法的功能与原则：拿什么保护，凭什么约束
> 对应块：BLK03 | 覆盖分集：P02 | 块标题（分集名）：《第01讲 第02-03节：刑法的功能、刑法的原则》

刑法的功能，一共两个：保护法益、打击犯罪。

你要是把这十二个字记住了，方向就不会错；但真正决定一部刑法怎么写、法官怎么判的，是后面那三个原则。这一节我们把功能讲透，再把原则讲透。

### 刑法的两个功能

#### 法益：刑法到底保护什么

先说第一个功能——保护法益。这个概念特别重要，是咱们刑法里最基础的一个概念。

那么问题来了：我们刑法保护的客体到底是啥？

传统理论给的答案叫**社会关系**。可"社会关系"这四个字实在太笼统了，笼统到你拿着它什么也干不了。后来我们刑法把这个客体重新表述了一遍：刑法保护的是**一种利益**，是刑法保护的一种利益。这种利益，理论上把它浓缩成一个简称，就叫**法益**。

所以以后再问"刑法的保护客体是啥"，你就答：法益。

这不难，配两个例子就记住了：

- 刑法设立一个故意杀人罪，它的保护法益就是**人的生命**；
- 刑法设置一个盗窃罪，它的保护客体就是**财产权**。

顺着这条线，犯罪的定义也就出来了：

> **定义**：所谓犯罪，就是侵害法益的行为。

以后不管谁问你"什么是犯罪"，六个字：侵害法益的行为。

那考试是怎么考法益的？最常见的就是把它藏在具体罪名的解释方向里。前面我们讲目的解释的时候说过，**保护目的其实就是保护客体，就是保护法益**。再比如讲诬告陷害罪的时候，我们其实已经碰过一次了——它的保护法益到底是谁？多数说认为是公民个人的权利，比如自由权、名誉权；少数说认为是司法机关的司法活动。

记住：法益不是拿来背的，是拿来当指南针用的。你学一个罪，如果这个罪的保护法益你不太了解，那这个罪的解释方向你就没抓牢——解释的方向可以有好几个，但哪个方向是对的，指南针告诉你。

#### 一张住宅，两种保护法益

2022 年的主观题考过一个案子，很典型，我给你们完整讲一遍，因为它是"法益决定结论"最漂亮的一个样本。

狗蛋知道邻居常年在国外，房子一直空着，他就进了人家家里，在里面住了一个月。问：狗蛋构成不构成非法侵入住宅罪？还要你做观点展示。

观点展示的焦点问题只有一个——**非法侵入住宅罪的保护法益到底是什么**。

| | 第一种观点 | 第二种观点（多数说） |
| --- | --- | --- |
| 保护法益 | 住宅权，具体说是住宅的**进入许可权** | 住宅的**居住、生活的安宁状态** |
| 判断标准 | 未经共有人同意，擅自进入 | 是否破坏了安宁状态 |
| 狗蛋案结论 | 构成非法侵入住宅罪 | 不构成，交给民法处理 |
| 情夫案结论 | 构成（丈夫不同意） | 不构成（妻子同意） |

**第一种观点**说：这个罪保护的是住宅权，细一点说，是房屋主人的"进入许可权"。按这个观点，你只要未经同意擅闯民宅，就构成非法侵入住宅罪。狗蛋当然构成。

但这个观点有问题，而且问题出在哪儿，日本早就替我们踩过了。

日本早年有个案子：有个妻子趁丈夫不在家，把情夫带到家里，行云雨之欢。丈夫事后知道，气得要死，就把情夫告了，说你构成非法侵入住宅罪——你没我同意就进了我家。

法官这时候就犯难了。妻子请来的，情夫确实侵犯了**丈夫**的进入许可权，可**妻子**的进入许可权他一点没碰。房子是夫妻共有的，那这许可权怎么办？表决吧。一比一，还是定不了。

你们想想，如果共有人再多几个，这案子就变成董事会表决了，那肯定不合理。

> **易错点**：日本这个案子提醒我们，"进入许可权"这个定义是有硬伤的——它会逼着法官去做"共有人之间谁能代表这栋房子"的表决，而这恰恰不是刑法该干的事。

后来日本学界就想明白了：这样定义保护法益是有问题的。**我们刑法更侧重于保护一些实质的东西，是一种实质思维。**

你想，这个房子还是那间房子，我之所以不允许你进来，主要是因为啥？是因为我不允许你打扰我的**住宅的安宁状态**。住宅对一个人来说就是个家，是一种安宁状态。风能进，雨能进，王不能进。

住宅它有一种生活的安宁状态，这才是它真正的、实质的东西。

**第二种观点**由此而来：这个罪的保护法益是住宅的一种居住、生活的安宁状态。

按这个观点，邻居常年在外，房子空着，狗蛋住了一个月——邻居的居住、生活的安宁状态被破坏了吗？没有。因为是空房子，里面根本没有一个人在那儿住。没有人在里面住，这个房子就不存在一个值得我们刑法保护的生活安宁状态。所以不构成非法侵入住宅罪。

那是不是就啥事都没有了？也不一定。**在民法上，你至少侵犯了人家的住宅权，是一个妥妥的侵权行为**，那就按民法来处理。

第二种观点后来成了**多数说**。

回头再看刚才日本那个妻子、丈夫、情夫的案子：按第二种观点，情夫有没有把丈夫这个家的居住、生活的安宁状态搞破坏？没有。妻子是邀请他进来的，里面那个画面搞不好还很温馨、很浪漫、很祥和，没有一片狼藉、混乱不堪。

有同学说：你咋知道搞不好在里面昏天黑地、房倒屋塌、地动山摇？你别太离谱好吧。

所以这时候情夫**不构成非法侵入住宅罪**，最多是按民事上的规则去处理。民事上这一块到底怎么处理，得去请教孟宪贵老师了；至少在刑法上，按多数说是不构成的。

这就是保护法益的力量。同一批事实，换一个保护法益，结论直接反过来。所以大家一定要把这个概念掌握好。

#### 保护法益与打击犯罪：两个功能会撞车

那第二个功能是打击犯罪。为什么一定要有"保护法益"这个功能？如果刑法的功能只界定为"打击犯罪、保护法益"，你想一想——

我们制定一部刑法典，主要是为了打击犯罪、保护法益？**其实并不是。** 如果目的只是为了打击犯罪、保护法益，那反倒不需要刑法典了。为什么？因为没有刑法典的限制，我想打击犯罪、我想保护法益，我就无拘无束了，想怎么办就怎么办，那多爽。

所以，一个国家设置一部刑法典，实际上是想**给司法机关戴上一副镣铐**，让它戴着镣铐去跳舞——也就是要限制司法权。

> **结论**：刑法不仅仅是善良人的大宪章，也是**犯罪人的大宪章**。

不这么设定的话，无拘无束，想怎么打击犯罪就怎么打击犯罪，那还得了。

但麻烦在这儿：这两个功能有时候**是冲突的**。集中体现在什么案件里呢？

我们来看《基督山伯爵》。男主角埃德蒙·唐泰斯，被人诬告陷害，说他什么通敌叛变之类的，关进了监狱。他最后实在没办法，就越狱，越狱成功了。

那我的问题是：**假如他真被抓了回来，你是法官，要不要给他定一个脱逃罪？**（越狱在刑法上不叫"越狱罪"，罪名就叫脱逃罪。）

这里可以观点展示。**学会说理由**，理由从哪找？从保护法益里找。

**第一种观点：构成脱逃罪。** 理由是：脱逃罪的保护法益是**监狱的管理秩序**。你现在虽然是被冤枉的，但只要你在我的监狱里面坐牢，对监狱长来说你就是罪犯，你就不能破坏监狱的管理秩序；你一破坏，就构成脱逃罪。这种观点侧重的是保护法益、打击犯罪。

**第二种观点：不构成脱逃罪。** 理由是：刑法不仅仅要保护法益。你是被冤枉的，本来是司法机关搞错了，人逃跑是人之本能，结果一逃跑又逃出另一个罪来，还要给你再定罪——这是**错上加错**。

第二种观点是**多数说**。

到这里，第二个功能"怎么去实现它"的问题就冒出来了——这就要靠刑法的原则。

顺便把刑法的三个原则在这里交代一下：罪刑法定原则、罪刑相适应原则、刑法面前人人平等原则。第三个几乎不考，因为它内容太简单，所以重点看前两个，而**罪刑法定最重要**，我们先讲它。

### 罪刑法定原则

#### 一座沉没的火山

复习罪刑法定的时候，你一定要掌握它的思想原理。

我讲个我自己的感受。学刑法之前，你可能就都知道"罪刑法定原则"这个名字——刑法的帝王原则，地位特别高。但当你正式去学它的内容时，一看也就两句话：**法无明文规定不为罪，法无明文规定不处罚**。

我当时的感觉是：这**不是一句正确的废话吗**？法律都没有明文规定，你敢给人定罪？这还得了。

所以我就想，为什么这么一句"正确的废话"，能被抬到"第一铁则"的位置上？后来我才明白：**罪刑法定原则就像一座沉没的火山，平时不显山露水，但到了重要时刻，它才彰显自己的价值。**

举个好玩儿的例子。有这么个案子：狗蛋追求人家小芳，小芳不甩他，他就半夜三更经常给小芳打电话。小芳正睡着呢，拿起电话"喂，哪位？"那边说："我是周润发。"把人家气得啪一下把电话挂了。过两天又打。总这么骚扰，狗蛋的电话都成了午夜凶铃了。小芳气得吱吱乱叫，控告了，报案了。警察抓了他，**涉嫌非法侵入住宅罪**。

构不构成？

我们会发现，狗蛋确实干坏事了，他确实把小芳住宅的安宁状态破坏了。那是不是一定要定非法侵入住宅罪呢？不一定。但确实**有**人说得定——因为这行为太讨厌了，把人家住宅安全全破坏了，这不定说不过去啊。

可是大家想一想：我们要构成一个罪，要侵犯法益，但**是不是只要侵害了法益，就一定构成这个罪**？那不是。还得符合这个罪的**构成要件**。

那非法侵入住宅罪里的"侵入"指的是什么侵入？指的是**身体侵入**，身体得进去。那狗蛋的身体进到人家小芳家了吗？没有。他进去的是电磁信号。身体根本没进去，所以这时候就不能定非法侵入住宅罪。

你说他做坏事了吗？他侵犯法益了。我管他呢，必须定罪——这就属于**一味地为了保护法益**，就不考虑、不管这个罪的构成要件了，这是不行的。

所以你看清楚罪刑法定原则起什么作用了：

```text
  社会上发生一件事
        │
        ▼
  大家都觉得：好像有社会危害性，有法益侵害性，
  大家都觉得得定个罪来惩罚他
        │
        ▼
  法官一翻法条：行为不符合法条规定的构成要件
        │
        ▼
  ┌────────────────────────────────────┐
  │  定不了罪                          │
  │  此时考验的是法官的定力 / 抗压能力 │
  │  顶得住舆论压力，顶得住被害人及    │
  │  家属的压力                        │
  └────────────────────────────────────┘
```

这其实是很难的。做到这一点很难，所以这时候罪刑法定原则的作用就尤为突出。

#### 思想基础：自由主义与预测可能性

罪刑法定原则有两个内容：**思想基础**和**基本内容**。

思想基础有两个。第一个是"规定什么是犯罪、设置怎样的刑罚"这件事本身；第二个，也是最重要的，是**自由主义**。

自由主义是什么？大家想一想，一个人在社会上干任何事，其实至少要有一个**预测可能性**，要有一个稳定的预期，或者说一个预期利益。

比如你今天听我的课，你敢听，你其实是有个预测可能性在的——**听柏浪涛的课不构成犯罪**。假如说国家有个什么规定，说听柏浪涛的课构成犯罪，你还敢听吗？肯定不敢了。

再比如参加法考。如果你都不知道参加法考构不构成犯罪，你敢参加吗？搞不好参加法考是构成犯罪的，你还敢去吗？不敢。

我们把这个原理叫**国民的预测可能性原理**：说白了就是，**我们的行为自由，是由预测可能性来决定的**。

古人早就懂这个。《左传》里有一句话叫**"刑不可知，则威不可测"**。你看，多可怕。

所以你看，罪刑法定原则是 **1997 年新刑法**才把它写进去的——因为要做到这一点，是比较难的。

举个 1979 年之前的案子给你感受一下：有一辆公共汽车行驶在乡间公路上，轧过一个麦草堆，把老大爷的麦草麦秆压得不好看了。老大爷脾气很火爆，直接开骂；人家公交车继续往前开，也不搭理他。老大爷一急，喊他的狗去追这公交车。公交车为了躲避这条狗，一栽就栽到路边沟里去了，还有乘客受了轻微伤。没有人受很严重的伤害，都是轻微伤。

但是这不行啊，这个老大爷太可气了，得定罪。可是那时候还没有刑法典，压根儿没有这么个罪。到今天，按照我们刑法典、按照罪刑法定原则（**法定原则、法定主义**），这种情况是不构成犯罪的。

下面这张图是罪刑法定原则的整体骨架，先把位置摆好，我们一段一段填：

```text
                    罪 刑 法 定 原 则
                            │
        ┌───────────────────┴───────────────────┐
        │                                       │
   【思想基础】                             【基本内容】
   两个要点                                四个形容词
        │                                       │
   ┌────┴─────────────┐            ┌────────────┴────────────┐
   │                  │            │                         │
规定什么是犯罪    自由主义        成文的   事前的   严格的   确定的
设置怎样的刑罚                   │        │       │        │
                                 │        │       │        │
                    法律主义 / 禁止   禁止溯及  禁止类推  四个小内容
                    习惯法          既往      解释      （内容最多）
                                 （刑法的
                                  溯及力）
```

#### 成文：法律主义与禁止习惯法

**第一个是"成文的"罪刑法定原则**。它包含两点。

第一点叫**法律主义**。什么叫法律主义？就是：**能够规定犯罪和刑罚的法律**。

在我们国家，有权规定犯罪和刑罚的只有人大及其常委会制定的**法律**和**法规**。还要注意：地方人大没有权力制定犯罪和刑罚；部门规章没有权力；两个的**司法解释**更没有权力；那**立法解释**呢？立法解释也没有权力。

> **易错点**：立法解释名义上是"解释"，但它实质上是**立法**行为，所以它同样没有权力制定犯罪和刑罚。判断标准不是看它叫什么名字，而是看它在实质上是解释还是立法。

第二点叫**禁止习惯法**。我们有一年论述题考过：**为什么刑法要禁止习惯法，而民法不禁止习惯法**？

民法是怎么规定的？"有法律规定的，依照法律规定；没有法律规定的，依照习惯、依照惯例。"但我们刑法能依照习惯、依照惯例给人定罪量刑吗？肯定不行。

背后的原理：民法那边对应的是**意思自治原则**——虽然没有法律规定，但原告、被告双方都同意就这么办，那法官有什么好说的，尊重他们的意思，这叫自治。

刑法的逻辑不一样。

#### 事前与严格：禁止溯及既往，禁止类推解释

**第二个是"事前的"罪刑法定原则**。它的意思就是**禁止溯及既往**。这里面涉及到刑法的溯及力问题、时间效力问题，我们后面在时间效力那一块专门讲。

**第三个是"严格的"罪刑法定原则**。它指的是**禁止类推解释**。

前面给大家专门讲过为什么要禁止类推解释、但允许扩大解释。这里给你把原理补上：**类推解释违反了罪刑法定原则，因为类推解释的结论明显地超出了国民的预测可能性**。结论超出预测可能性，就不符合国民的预测可能性原理。

#### 确定：罪状要明确，刑罚不能绝对不定

**第四个是"确定的"罪刑法定原则**，也是内容最多的一个。它有四个小内容：明确性要求、禁止绝对不定期刑、禁止处罚不当罚的行为、禁止残虐的刑罚。先看前两个。

**明确性要求。** 罪刑法定原则要给国民提供预测可能性，那很显然就要求你对罪状的规定要明确。

你看，我们旧刑法为什么有"流氓罪"，到了 1997 年新刑法就把它废掉了？因为流氓罪太不明确了。

再举一个外国的例子：土耳其刑法典第 301 条有个罪名，叫**侮辱土耳其国魂罪**——国魂，灵魂的魂。你光听这个罪名，就知道这肯定不明确。

不明确的罪名就容易变成一个口袋，啥都往里装。所以你看，土耳其一直想加入欧盟，欧盟就一直不同意，说光你那个刑法第 301 条的罪名就不具有明确性。我都怀疑你能不能坚持罪刑法定原则。

**禁止绝对不定期刑。** 什么叫绝对不定期刑？指的是你的**刑罚的种类绝对不确定**。

比如你立一个法，说"某某行为构成犯罪，应判处刑罚"，句号完了。那应当判的是拘役，还是有期徒刑、无期徒刑、死刑？不说的话，你犯的时候把刑罚的种类完全交给法官随便选，这行吗？肯定不行。你搞得这个刑罚的种类跟**拆盲盒**一样，那也太不确定了。

那**禁止绝对不定期刑**呢？它是说：这样规定行为构成犯罪、判处有期徒刑，句号完了，请问这个有期徒刑从最低半年到最高 15 年，到底是多少？你给我弄一个档次、一个幅度吧。不弄的话，我可以判你半年，也可以判你 15 年，随便。那这个刑期简直也跟拆盲盒一样。

这都不确定，其实也是不明确，都应当被禁止。

#### 确定：处罚不当罚的行为——刑法的谦抑性

**第三个小内容是"禁止处罚不当罚的行为"**，这句话其实也叫**刑法的谦抑性**——谦是谦虚的谦，抑是抑制的抑；它也叫**刑法的补充性**。

什么意思？刑罚是我们所有制裁措施里面最严厉的制裁措施，**不能轻易使用**。它相当于原子弹：你不能刚一打仗，好家伙直接扔原子弹吧？你得先来一场常规战争。你不能动不动就扔原子弹，那肯定不行。

也就是说：先让民法、行政法去处理这个问题；如果他们搞不定，刑法再姗姗来迟登场。我们是**补充队员、板凳队员**，不能让刑法来解决社会矛盾、不能让刑法去打主力，不能一上战场就上。这是不行的。刑法要保持一个谦虚的姿态，这就叫刑法的谦抑性、刑法的补充性。

**关于谦抑性，我特别要强调一点：很多同学把这一块给误解了。**

他们理解成：刑法的谦抑性就是"只要民法能调整的事项，刑法就靠边站，刑法不要管"。我用图表给你画一下，如果按这种理解，民法和刑法就成了中间隔着一堵墙的对立排斥关系：

```text
   错误理解：隔一堵墙，互不干涉

     ┌──────────────┐        ▓▓▓        ┌──────────────┐
     │    民    法   │      ▓▓▓▓▓▓      │    刑    法   │
     └──────────────┘      ▓▓▓▓▓▓      └──────────────┘
            一   堵   墙，两   家   互   不   干   涉

        「民法能管的，刑法一律靠边站」——错
```

我问你几个问题。我啪扇你一耳光，扇得你嘴角流血了，我们刑法能不能管？

"刑法不要管，因为民法能管，民法能调整。"我说民法咋调整？民法不是有侵权责任法吗，侵权行为，侵犯人身权。那怎么处理呢？赔礼道歉、恢复原状。我说好。

那如果我一耳光把你耳朵都扇聋了呢？

"我们民法也能管，刑法靠边站。"我说民法怎么管？侵权，侵犯人身权。怎么处理？赔礼道歉、恢复原状。完了。

那如果我**一刀把你捅死了**呢？民法能不能管？

"民法也能管呀，侵犯生命权，侵权行为。"那赔礼道歉、恢复原状——**这咋恢复原状**？你想一想是不是？

所以把民法和刑法理解成对立排斥关系，是不对的。真正的关系，我称为**位阶关系**：民法是第一个位阶，刑法是第二个位阶。

```text
   真正的关系：位阶关系（先低位阶，后高位阶）

   ┌──────────────────────────────────────────────────┐
   │  第 一 位 阶 ：民 法                              │
   │  扇一耳光，嘴角流血 —— 轻微伤                     │
   │  侵权行为 → 赔礼道歉、恢复原状                   │
   │  够不够刑法？不够 → 这时候刑法不管               │
   └───────────────────────┬──────────────────────────┘
                           │  伤情加重
                           ▼
   ┌──────────────────────────────────────────────────┐
   │  第 二 位 阶 ：刑 法                              │
   │  一耳光把耳朵扇聋 —— 重伤                         │
   │  已完全符合故意伤害罪的构成要件 → 刑法也能管     │
   │  就高不就低：按刑法来处理                         │
   │  附带民事赔偿 → 刑事附带民事诉讼                 │
   └──────────────────────────────────────────────────┘
```

再说清楚一点：一耳光嘴角流血是轻微伤，先在民法上处理——因为这确实是侵权行为，按侵权法来处理。但这时候**够不够刑法？不够**。为什么不够？因为我们刑法规定构成故意伤害罪，要求打成**轻伤**；你现在只是嘴角流血，只是个轻微伤，所以这时候民法管，刑法的确不管。

但如果一耳光把你耳朵扇聋了，已经是**重伤**了，这个案件怎么处理？还是先民法——当然能管，在民法上还是个侵权行为。可是这时候刑法能不能管？也能管了，因为完全符合故意伤害罪的构成要件。

那这时候怎么办？**就高不就低，按刑法来处理。** 那民法那一块的赔偿怎么办？那就做**刑事附带民事诉讼**——我们还是进行刑事诉讼，然后附带进行民事诉讼。

你看，"刑事附带民事诉讼"这一句话就告诉我们：民法是第一位阶，刑法是第二位阶。当然你也可以说民法是低位阶、刑法是高位阶。但一定要注意，**这只是就适用顺序而言的**；如果要说两个法律的**效力等级**，大家是平起平坐的。从适用顺序上，是先看民法，民法符合了再看高阶位的刑法，刑法符合了那现在就高不就低，按刑法来处理。

所以你千万不能把民法和刑法理解成对立排斥关系，说只要民法能管的、能调整的，刑法就靠边站——这样理解反倒就错了。

#### 确定：禁止残虐的刑罚

**第四个小内容是禁止残虐的刑罚。**

这背后是人道主义。另外，残虐的刑罚其实也是不符合罪刑法定原则的。

大家知道古代最残虐的刑罚是什么吗？有人说是满清十大酷刑，其实最残忍的是**凌迟**。

这个"凌"字，壮志凌云的"凌"，但它其实通的是丘陵的"陵"；"迟"是迟缓的"迟"。**凌迟**的意思就是说，让你的痛苦像爬一个小丘陵一样，慢慢地、一点一点地增加你的痛苦，而且要迟缓一点、要延长一点，这就叫凌迟。俗称"千刀万剐"，可不是说第一刀就弄死你、后面成了碎尸万段，那是要一点点折磨、一点点增加痛苦，像爬一个小山坡一样，只有最后一刀才弄死你。

历史上有名的凌迟是谁的？明末的**袁崇焕将军**。他不是被冤枉了吗，崇祯皇帝给他来了个凌迟。

顺便纠正一个常识：明朝的刑场不在菜市口——菜市口那是清朝的刑场。明朝的刑场在**西四**，就是北京西单再往北那一站。

当年给袁崇焕凌迟的时候，底下台子下面挤着许多老百姓看。大家以为这是卖国贼，就看着一刀一刀地刮。史书记载：**"身具白骨而眼珠游动，四体分落而呻吟不息。"** 白骨都出来了，眼珠子还在那动，还没死；四肢像树叶一样纷纷飘落，而人还在呻吟。你一听他还在那呻吟，多可怕。

当时刽子手割一块肉往台下一扔，老百姓抢着肉吃，因为他们觉得这是卖国贼的肉、民族败类的肉。他们不知道啊。

所以你说这多可怕、多残忍。今天你像这种刑罚，肯定违反罪刑法定原则，我们肯定要把它废除。

到这里，罪刑法定原则的基本内容就讲完了。简单总结一下：**思想基础里最最重要的是自由主义**，就是要有国民的预测可能性——只有这样才能保障我们国民的自由；**基本内容四个里面，内容最多的是最后一个"确定的"**，其中最要紧的是刑法的谦抑性、补充性该怎么理解，也就是民法和刑法的关系：在**适用顺序**上是第一位阶和第二位阶的关系，而不是对立排斥关系。

### 罪刑相适应原则

#### 重罪重判，轻罪轻判

罪刑相适应原则讲的是什么？**重罪重判，轻罪轻判。**

你不能搞反了，不能来个轻罪重判、重罪可轻判。那其实是以罪行不均衡，也给人一种"没有什么稳定的预期、没有预测可能性"，就把人给整蒙了，那肯定不行。

大家知道卡夫卡吧，很伟大。他其实以前是**学法律的**，写过《审判》这个小说——你看，都跟法律有关系。他还写过一篇散文，就叫**《致父亲的一封信》**。他在信里回忆什么呢？他幼年时期调皮捣蛋，犯了一个小错误，结果招来父亲严厉的惩罚。他当时心里就想：老爸，至于吗？你至于吗？我就犯这个小错，你至于这么严厉地惩罚我吗？

你看，他成年以后还在回忆这一点——一个幼小的心灵被造成这么大的伤害。这就告诉我们，重罪重判、轻罪轻判这么一个朴素的道理，一个小孩他都懂。

所以罪刑要相适应、要相均衡，这个原则简直是不言自明。

#### 量刑依据的两根柱子：报应与预防

但接下来的问题是：**怎样才能做到罪刑相适应**？这就涉及量刑标准的问题了。

这一块我给大家板书一下。我们量刑所依据的事实有两个：

```text
                 量 刑 所 依 据 的 事 实
                          │
            ┌─────────────┴─────────────┐
            │                           │
       ┌────▼─────┐                ┌────▼─────┐
       │  已然事实  │                │  未然事实  │
       │ 已经发生的│                │ 未来可能  │
       └────┬─────┘                └────┬─────┘
            │                           │
       ┌────▼─────┐                ┌────▼─────┐
       │ 法益侵害性│                │人身危险性│
       │           │                │ 再犯可能性│
       └────┬─────┘                └────┬─────┘
            │                           │
       ┌────▼─────┐                ┌────▼─────┐
       │  报 应 刑 │                │  预 防 刑 │
       └──────────┘                └──────────┘
       已然事实：已经发生的事实       未然事实：未来可能发生的事实
```

**已然事实是什么？** 是法益侵害。根据法益侵害性给你施加的刑罚，我们叫**报应刑**。

**未然事实是什么？** 主要体现在**人身危险性**，也叫**再犯可能性**，就是你未来再犯的可能性大不大。根据这个指标给你施加的刑罚，叫**预防刑**。

所以量刑的标准依据就两个：一个是**报应型**，一个是**预防型**。这个原理一定要掌握，不然许多同学死记硬背是不行的。

拿三个例子把这个原理套上去，你就明白为什么这么从重、那么从宽了。

**入户抢劫为什么判得比普通抢劫重？** 因为入户抢劫是抢劫罪的一个法定加重处罚情节。为什么加重？因为你入户抢劫的**法益侵害性**比普通抢劫多了一个法益侵害——多了一个非法入户，也就是相当于一个非法侵入住宅罪。入户抢劫就相当于"非法侵入住宅罪 + 普通抢劫"，你的法益侵害性比普通抢劫要飙升一个档次，所以要给你加重处罚。**指标是法益侵害性，落在报应刑这一块。**

**累犯为什么从重处罚？** 它的依据是法益侵害性吗？不是，是**人身危险性**。为什么？狗蛋儿先犯一个前罪，判刑了，坐牢了，最后刑满释放；刑满释放以后的五年内，他又犯了第二个罪，这个第二个罪就叫累犯。给这个第二个罪判刑罚的时候要给你从重处置。

那依据是什么？很显然不是法益侵害性——因为**第一个罪他已经坐完牢了**。为什么给人第二个罪从重？因为你屡教不改，你总是"二进宫"，这时候你的人身危险性、再犯可能性是很大的。所以要给你从重处罚，处罚的根据就是**预防刑**。

**自首为什么能给你从宽处罚？** 因为你能够自动投案、如实供述，这时候体现的是你的人身危险性、再犯可能性比较低了，所以从预防刑这一块可以给你降低点程度。

#### 只能个别化判断的人身危险性

理解到这儿，我再问大家一个问题：**每个人的再犯可能性一样不一样？** 那肯定不一样。

那这时候我们就得**个别化**地去判断它。什么叫个别化判断？就是人身危险性、再犯可能性，你**只能针对每一个犯罪人个别化地判断**。

法益侵害性有时候两个人是一样的，但是人身危险性不一样。你比如说杀人——你杀了一个人，他杀了个人，从法益侵害的角度来说，你们都剥夺了一个人的生命法益，法益侵害性是一样的。但是你们这两个杀手的人身危险性、再犯可能性是不同的。

比方说《沉默的羔羊》里面那个男主角**汉尼拔**。那老兄他也杀人，可那老兄是个杀人狂魔呀。他杀一个人，他的人身危险性、再犯可能性大不大？太大了。

那我再说一个杀人案，大家给我判断一下。比如**北京昌平**有一个老太太，把她 80 多岁的老伴儿用枕头给捂死了。

她为什么捂死？因为她老伴儿是个植物人，已经昏迷了 20 年了，一直没醒。老太太觉得：我照顾你 20 年，我现在也老了，浑身是病，我实在没有照顾你的能力了，那干脆送你上路吧。然后用枕头把老伴儿给捂死了。

大家知道，**植物人也是活人**，也是人，你可不能随便杀，杀植物人也构成故意杀人罪的。

那大家想一想：这个老太太的被害人也杀了一个人，汉尼拔也杀了一个人，都只杀一个人的话，**法益侵害性是一样的**。但你觉得他们两个的人身危险性、再犯可能性能一样吗？肯定不一样。

杀一个植物人，而且也是因为实在无法照顾了，那他未来再杀人的可能性大吗？肯定是**几乎是零**了。但是《沉默的羔羊》里汉尼拔这个恶魔，他未来再杀人的可能性就很大。

所以从这个角度来说，人身危险性、再犯可能性，它所指向的**预防刑**，在这两个杀人案里面就是不一样的。这种需要个别化判断的人身危险性，我们给它起了个名字，就叫**刑罚的个别化理念**。

注意：这个"个别化"指的是**人身危险性、再犯可能性**需要个别化去判断。也就是这里面要实现**一般正义和个别正义的平衡**。

## 刑法的效力：空间效力与时间效力
> 对应块：BLK04 | 覆盖分集：P03 | 块标题（分集名）：《第01讲 第04节：刑法的效力》

第一讲讲到第四节了。刑法的效力一共就两块——空间效力和时间效力。空间效力回答"这个案子归不归我们管"，时间效力回答"归我们管的话，按哪部法办"。这一节我们还是老规矩，从做题的角度往下走，书上第 15 页那张图表，大家跟着我一起看。

### 境内犯罪：属地管辖与"中国领域"

#### 领域有多大：领陆、领空、领海

凡是在中国境内犯罪的，我们管，这叫属地管辖原则——你只要是在我们中国境内犯的罪，中国刑法都可以管辖。

那"境内"到底指什么？就是中国的领域内。领域包括什么？领陆、领空、领海，都算中国的领域。

> **结论**：属地管辖的判断起点，是行为地是否落在中国领域之内。

#### 四种交通工具，只认两种

领域这件事还有一个坑，就是交通工具该怎么办。地面上跑的、空中飞的、水里游的，都归到哪去？

大家给我想想都有些什么交通工具——飞机、船只、火车、汽车。我们总结一下，这四样里面只有两样有特殊待遇。

**飞机（航空器）和船只（船舶）实行旗国主义**。什么叫旗国主义？就是只要悬挂中国的国旗或者张贴中国的国旗，这样的飞机、这样的船只，它仍然属于我们中国的领域。

比如国航的飞机，你贴着中国的国旗，从北京飞到德国法兰克福，那这个机舱里面，按旗国主义仍然属于我们中国的领域。在这里面发生的刑事案件，中国刑法按照属地管辖是能管的。船只也是同样的道理。

**但是火车（列车）和汽车不行**，没有实行旗国主义。

你看《囧妈》那个电影，一辆列车从北京出发要开往莫斯科，这火车一旦到了人家俄罗斯境内，开在西伯利亚那趟火车上，火车内部那个领域已经不属于我们中国的领域了，那属于人家俄罗斯的领域。国际大巴也是一样，从北京一辆大巴车一直开到俄罗斯，你进入人家俄罗斯境内，这个大巴车上的领域已经不属于中国领域了。

这就是《东方快车谋杀案》的逻辑。那部电影很精彩，是逻辑推理、侦破案件。火车从土耳其伊斯坦布尔出发，目的地是法国。这火车如果开出土耳其，比如到了意大利境内，火车上发生了谋杀案，这个领域就不能按土耳其来管了——虽然火车是你土耳其的火车，但按我们国家刑法的原理，列车不属于旗国主义，那这时候火车到了哪个国家的境内，此时发生的谋杀案件就归那个国家来管。

> **易错点**：四种交通工具，只有飞机和船只适用旗国主义，火车和汽车不适用。考场上千万不要一律套用"挂我国国旗即属我国领域"。

#### 属地管辖盯的是所有的"地"

中国领域搞清楚了，接下来看属地管辖里的"地"都包括哪些。这个地方特别容易考。

属地管辖的"地"，包括犯罪行为地和犯罪结果地。

**犯罪行为地**从两个角度看：

- 按共同犯罪的角度：有实行行为地、教唆行为地、帮助行为地；
- 按犯罪形态的角度：有实行行为地，还有预备行为地。

**犯罪结果地**也是从两个角度：

- 按共同犯罪的角度：有整体结果地，也有部分犯罪人的结果地；
- 按危害形态来说：有实害结果地，还有危险发生地。

我为什么要说这么多"地"？因为接下来要记住一个原则：属地管辖有时候特别喜欢考"这个犯罪有好几个地"，**只要有一个地在我们中国境内、中国领域内，中国刑法就可以管辖**。

也就是说——沾边我们就能管。

#### 只要沾一个边，就能管

我举几个例子你就明白了。

**第一个：狗蛋的教唆行为在国内。** 狗蛋在我们中国境内，打电话给身在美国的小芳，让小芳在美国杀死美国的狗，小芳照办。这个案件我们中国刑法可不可以管辖？可以。因为这个案件教唆行为发生在中国境内。实行行为是发生在美国，但只要有一个地在中国境内，中国刑法按属地管辖就能管。

**第二个更狠：张子强案。** 当年香港有个老大叫张子强，很嚣张的，他把李嘉诚的大公子给绑架了，开口就要 10 亿港币。李嘉诚不含糊，直接就给了。这一战张子强成名，处理了。那像这种黑社会老大，肯定要收拾他。后来他又干了一件事——要炸香港监狱。为什么呢？因为他们那个组织的二当家被关到那个监狱里了，他想劫狱，要炸监狱，够猛吧。

那这个炸药在哪买的？炸药是在我们云南买的。后来我们就因为这个行为把他抓了。结果他说：诶，香港的刑法和内地的刑法是独立的啊，我在你们内地没犯事、没干坏事，所以你得把我引渡到香港去，因为我要炸的是香港监狱，我在内地也没犯事。

我们内地警方就问他：你要炸香港监狱，你那个炸药在哪买的？炸药是在云南买的呀。云南属于哪？云南属于内地啊。那不就结了吗——为了实施爆炸罪购买炸药的行为，属于什么行为？属于预备行为。那得了，你预备行为地在我们内地，那我们能不能管呀？能。全案我们都能管。属地管辖的地，只要有一个地在我们内地，我们就能管，沾边就能管。

### 境外犯罪：属人、保护、普遍三个管辖

中国境内犯罪靠属地管辖，那中国境外犯罪呢？有三种情形，对应三个管辖原则。

#### 属人管辖：中国人在境外犯罪

属人管辖指的是中国人在境外犯罪，中国刑法就能管。

这里有一个例外：犯的是轻罪，可以不追究刑事责任。

但如果是中国国家工作人员和军人在中国境外犯罪，我们一律追究——轻罪重罪，一律追究。

#### 保护管辖：犯我中华者，虽远必诛

保护管辖针对的是外国人：外国人在境外犯罪。而且有三个附加要求，缺一不可。

一是**在境外针对我们中国或者中国公民犯罪**；

二是**犯的还得是重罪**；

三是**要符合双重犯罪原则**——双重犯罪原则就是说，我们中国刑法规定这个行为是犯罪，人家这个外国人所在的国家当地，这个行为也被规定成犯罪，这时候中国刑法才能管。

保护管辖秉持的就是这么一句话：犯我中华者、犯我中华的公民者，虽远必诛。

#### 普遍管辖：国际犯罪那几类

普遍管辖针对的都是国际犯罪，比如贩卖奴隶、性剥削等等。普遍管辖考的比较少，我们现在需要重点掌握的是属人管辖和保护管辖。

| 管辖原则 | 针对谁 | 在哪犯罪 | 附加条件 |
| --- | --- | --- | --- |
| 属人管辖 | 中国人 | 中国境外 | 轻罪可以不追究刑事责任；国家工作人员、军人一律追究 |
| 保护管辖 | 外国人 | 中国境外 | 针对中国或中国公民犯罪、须为重罪、符合双重犯罪原则 |
| 普遍管辖 | 外国人 | 中国境外 | 属于国际犯罪 |

#### 双方都能管：方便调查原则

我们一起来训练几个，你看看能不能答对。

**中国留学生在美国杀了自己的导师。** 有个不幸的案件，我们中国一个留学生在美国，把他美国的一个导师给杀了，而且是拿一个铁锥刺他导师的头部，边刺边喊"我要找芯片，我要找芯片"——他认为自己导师脑袋里面装了个芯片，是被 FBI 装的，他要解救他导师，要把那个芯片掏出来，结果把导师一下子给刺死了。

这样的案件适用哪个管辖？首先肯定不是属地管辖，因为案件发生在中国境外，发生在美国。根据属人管辖，我们能管，因为这是中国人在境外犯罪。

那有的同学问：美国人家能不能管？美国刑法当然能管，因为按美国刑法它就属于属地管辖了。

问题来了：有的同学说，那美国也能管，我们中国也能管，双方争起来打起来怎么办？

这时候就出现了**管辖权冲突**。如果大家都能管，怎么办呢？我们有一个原则叫**方便调查原则**——哪一方收集证据更方便，那就谁来管。一般来说就是属地管辖那一方来管，因为按属地管辖，比如人家美国他收集证据比较方便，所以一般是属地管辖来管。

#### 江歌案与张莹莹案：一个属人，一个保护

我们再来一个大家都很熟的案件——江歌案。讲师提到，案件里有一个姓陈的中国人，被害的中国女孩叫江歌。

这个案件怎么管？首先人家日本肯定能管，人家日本是按属地管辖。我们国家刑法能不能管？也能管，根据什么原则？属人管辖。因为这也是中国人在境外犯罪。

这里有一个点要讲清楚：**属人管辖下，犯罪的对象既可以是中国人，也可以是人家当地人。** 行为人是中国人，就够了，不要求被害人是中国人。

有同学说，那这个案件是不是按保护管辖也能管呀？

错。**保护管辖针对的是外国人在中国境外犯罪**，而江歌案那个凶手是中国人，他不是外国人，所以不适用保护管辖。

那什么案子才适用保护管辖？我给你们举一个正例。大家知道有个北大的女生张莹莹，在美国做访问学者的时候，被当地的一个男的给劫持了、杀害了。这个案件我们中国刑法能不能管？能。这个案件根据什么管辖？

既不是属地——发生在美国；也不是属人——因为那个凶手他不是中国人。这时候根据保护管辖。这就属于外国人在境外针对我们中国人犯罪。

所以这一对案子对照着记：**江歌案看属人，张莹莹案看保护**，分野就在于凶手是不是中国人。

#### 两个"竞合"案：优先按属地管辖处理

接下来增加点难度，我们引申一个。

**案例一：缅北电诈。** 电影《孤注一掷》演的是缅甸北部那个电诈，王传君演的那个角色是个犯罪人，他在缅甸的时候还是个中国人，就是说一个中国人在缅甸对我们国内的人实施电信诈骗。那这个案件谁都能管。缅甸能管，那是按属地。我们中国刑法能不能管？能，按什么管辖？

有的同学可能想不到属地管辖——你明明说的是在缅甸呀，犯罪行为地在缅甸呀，怎么能属地管辖呢？大家再看一下那张图表，属地管辖的"地"还包括什么地？**犯罪结果地**。

那现在这个人诈骗谁的钱？诈骗我们国内老百姓的钱，我们国内老百姓在国内把钱给他打了。这个被害人的财产损失发生在哪？发生在国内。这就是犯罪结果地发生在国内，所以按照犯罪结果地，我们中国刑法可以根据属地管辖来管。

那我们中国刑法可不可以根据属人管辖来管？也可以。因为这属于中国人在境外犯罪，那个角色也是中国人，他在境外犯罪。

有的同学问，那这时候既按属地管辖、也按属人管辖，这矛盾吗？好像很矛盾。不矛盾，这叫**管辖权的竞合**——两个管辖原则都能管。都能管的话，我们优先按属地管辖来管。

这就告诉我们：**如果一个中国人在境外对我们中国境内的一个中国人实施犯罪，这时候属地管辖能管，属人管辖也能管**。注意这一点。

**案例二：缅甸人打诈骗电话。** 如果一个缅甸人在缅甸打电话，诈骗我们中国境内的一个中国人，导致这个中国人在境内把钱给他打了、遭受财产损失，这个案件我们中国刑法能不能管？

先按属地管辖，肯定能管，因为犯罪结果地发生在中国境内。

再按属人——肯定不行，因为犯罪人是个缅甸人。

那还能按什么？保护管辖。因为这是外国人在中国境外犯罪，但犯罪结果落在中国境内、被害人是中国人，符合保护管辖的实质要求。

所以在这个案件里面，属地管辖和**保护管辖**两个原则也竞合了。竞合了以后怎么认定？优先按属地管辖来管。

> **结论**：两个管辖原则竞合的时候，一律优先按属地管辖处理。

到这里，刑法的空间效力这几个管辖我们就整理完了。那张图表希望大家理解的基础上把它记住。

### 时间效力：行为时与审判时之间隔着一部新法

接下来是刑法的时间效力。我们还是看书上这张图表——这类题它的特点是容易混淆。做题你先找出**行为时**，再找出**审判时**，而且行为时和审判时中间夹着一个新法、一个新的规定生效了。

我们以最新的刑法修正案（十二）为例，它是 2024 年 3 月 1 日生效的。

现在就有这么一个问题：有一个人在 2024 年 3 月 1 日之前有行为，但这个案件到了审判的时候已经到了 2024 年 3 月 1 日之后了。中间夹着一个旧法、一个新法，这个案件到底怎么处理？

举个例子。我们刑法有一个罪名叫**为亲友非法牟利罪**，这个罪的主体以前只包括国有企业的人。但是刑法修正案（十二）新规定说，民企的工作人员也能构成这个罪了。这是一个法律的变化。

现在我问：有一个甲，他是民企的经理，他在 2023 年利用职务便利为亲友非法牟利，导致他所在的这个民企吃亏了、有财产损失了。后来老板知道了，老板就报案了。但这个案件发生的时候是 2023 年，报案的时候、审判的时候已经到了 2024 年 4 月以后了，也就是 2024 年 3 月 1 日之后了。那现在司法机关要审判了，这个案件怎么办？这就涉及刑法修正案（十二）的时间效力问题。

按新法（修正案十二）审判，这个民企经理就构成**为亲友非法牟利罪**；按行为时的旧法审判，当时的旧规定里民企的人不构成这个罪，那他就不构成这个罪。到底按哪个来审判？

#### 从旧兼从轻：一句话拆成两半

原则这就出来了，叫**从旧兼从轻原则**。

**"从旧"是什么意思？** 原则上要适用旧法。旧法指的就是行为时的法律。按从旧，给这个民企经理适用行为时的法律——行为时是 2023 年，按 2023 年的刑法规定，他就不构成**为亲友非法牟利罪**。这叫从旧原则。

**"兼从轻"是什么意思？** 也就是说，如果适用新法有利于被告人的，那就适用新法。

合起来就叫从旧兼从轻原则。

放到我们这个案子里：从旧肯定是对这个民企经理有利的（旧法下不构成犯罪），所以这时候适用旧法，结论就是不构成**为亲友非法牟利罪**。

> **定义**：从旧兼从轻原则 = 原则上适用行为时的法律（从旧）+ 新法有利于被告人时例外适用新法（兼从轻）。

#### 再审案件：只有从旧，没有从轻

但接下来的问题要注意。我们说的从旧兼从轻，只是**仅就未决案件**而言的——就是没有判决的案件。如果案件已经判决生效了，那这时候就不存在从旧兼从轻这些时间效力的问题了。

这里面要特别强调的是**再审的案件**，也叫按照审判监督程序的案件。有的同学可能法条还没学到，简单说一下什么是再审：狗蛋涉嫌犯罪，一审判有罪，他上诉了，到二审维持原判，二审就已经生效了，这属于终审。终审已经生效了，那狗蛋就坐牢了，坐了 5 年牢，刑满释放了。释放以后他又觉得自己不服，觉得当时给我判有罪，我不服，那这时候他就申请再审。这时候其实都已经是终审了，这会儿申请再审要推翻原来的判决，这就叫再审程序。

结论一句话：**对于再审案件，我们的时间效力原则是从旧原则。** 按行为时的法律来适用，这时候没有从轻，不是从旧兼从轻，只有从旧，按行为时的法律规定审理就完了。

为什么这么回事？我们讲一个例子你就明白了。

我们现行刑法是 1997 年生效的，但 1979 年的旧刑法里有**流氓罪**。狗蛋 1996 年对小芳耍流氓，被抓了，判了流氓罪，判了 3 年，他也坐了 3 年牢。坐完释放以后呢，他就一直苦学刑法，一直学到 1997 年 10 月 1 日，一看，哇，新刑法生效了。再仔细一看，哎哟，这个**流氓罪**被删掉了，没有流氓罪了。那按照现在的法律，我就不构成流氓罪了，我要申请再审。他就申请再审。

那我们现在给他再审这个案件，问题来了：如果按照 96 年当时的旧刑法，审查一下——事实认定没问题，当时的法律适用也没问题，那这时候我们按流氓罪还是要维持原判决。但如果按照现行法去审理，由于现在没有流氓罪了，按照现在审判时的法律，那就给他无罪可定了，只能无罪了。

但是大家想一想，我们能不能说，那从旧兼从轻原则，由于适用审判时的新规定，按新刑法他无罪，所以要给他适用新刑法、给他做无罪处理？**能这么干吗？肯定不能。**

因为这是再审案件。再审案件我们只看两件事：第一，当时法官给你事实认定有没有问题，如果没有新证据把原来的事实认定推翻掉，那我们事实认定没问题；第二，法律适用——看我当时适用当时的旧刑法，我法官法律适用有没有问题？也没问题。当时的事实认定、法律适用都没问题，那我当然要维持原判决。我不能因为后来法律改了，就给你来个无罪。

那这么干的话，那么多的流氓罪，随着 97 年**流氓罪**被废掉，那当然大量流氓罪的案件全部要推翻啊、重来啊，那怎么可能。

所以再审案件我们用的就是从旧原则，也就是行为时原则。

> **易错点**：从旧兼从轻只针对未判决生效的未决案件。已判决生效的案件（包括再审案件），一律只用从旧原则，没有"从轻"这一说。

#### 司法解释的时间效力：两个结论要记牢

最后是司法解释的时间效力。大家知道我们两高针对刑法出了好多司法解释，这个司法解释怎么去适用，也是有好多问题的，这块专门有个司法解释规定了它的时间效力问题。

为了方便记忆，我给大家画了一个图表。大家记住两个结论就完了。

**第一个结论：从无到有，按司法解释来办。** 也就是行为时没有司法解释，而到了审判时有了司法解释，那就按审判时的这个司法解释来办。

```text
司法解释的时间效力 —— 只有两种情形

  情形一：从无到有
  行为时无司法解释 ──► 审判时有司法解释
  结论：按审判时的司法解释办（从新）

  情形二：从旧到新
  行为时有旧司法解释 ──► 审判时有新的司法解释
  结论：从旧兼从轻（原则上用旧解释，新解释更有利时用新解释）
```

这一条一讲出来，人的感觉就不对劲了：审判时的这个司法解释竟然具有溯及力，对之前的行为还能够适用，这是不是违反了禁止溯及既往的原则？这完全就是从新啊。我们怎么回答？

**针对刑法条文的修订，我们一定要适用从旧兼从轻原则，原则上禁止溯及既往，除非有利于被告人的。但是，司法解释不是刑法条文的修订，司法解释只是对刑法条文含义的一个澄清。** 也就是说，我这个司法解释不是在立法，我只是对法条的含义做了解释。现在这个法条的含义有了新的理解，那就要按照新的理解来办。

就此而言，人家没有违反禁止溯及既往，也没有违反罪刑法定原则，因为司法解释只是对条文的解释，它不是条文的修订。我们说的"从旧兼从轻原则到底适用行为时的法律还是审判时的法律"，那个"法律"指的都是法律条文，指的不是对条文的一种解释。

**第二个结论：从旧到新，从旧兼从轻。** 也就是行为时有司法解释，然后审判时有了新的司法解释，这时候司法解释规定说从旧兼从轻，类比适用那个从旧兼从轻。原则上还是要适用行为时的那个旧司法解释，但如果适用新司法解释更轻、更有利于被告人的话，那就是适用新的司法解释。

> **易错点**：有些同学把这个记成"从旧兼从新"，那是记错了。从旧兼从轻这种情况，是司法解释的明文规定，一定要记牢，不要记混。

所以最后这张图表我们就这么记：**一种是司法解释从无到有，处理办法是从新；另一种是从旧到新，处理结论是从旧兼从轻。** 就这样去处理就可以了。

### 一道典型真题：2021 年 2 月 28 日的高空抛物

我们来做一道典型真题，书上第 16 页。

先说明一下，这道真题其实有许多知识点是我们后面刑法分则才讲解的，所以放在这儿对有些同学来说其实是不适合做的。你如果是一战的同学，后面没学这块，理解起来是有点难度的，所以姑且先听一听、混个耳熟就行了。

这道题是这样说的：**2021 年 2 月 28 日晚上八点，甲从三楼向下扔厨余垃圾，地面是停车场，正好砸在自家车上，司法机关在 2021 年 3 月 1 日后处理本案，问说法正确的。**

先要知道一个背景：2021 年 3 月 1 日，我们有个刑法修正案（十一）生效了。生效以后它规定了一个新罪，叫**高空抛物罪**。这个背景先了解一下。

我们来看选项。

**A 项**说三楼不属于高空，所以这个甲的行为即使发生在修正案（十一）实施之后，甲也不可能构成**高空抛物罪**。

这里考的其实不是时间效力问题，而是**高空抛物罪**的构成要件——这个"高空"到底多高。我们学到分则就知道，三楼已经属于高空了。所以 A 项说法错误。

**B 项**说甲的垃圾砸在自家车上，没有危害公共安全，即使甲的行为发生在修正案（十一）之后，甲也不构成**以危险方法危害公共安全罪**。

这里也有一个考点是分则要讲的，就是什么叫危害公共安全。我们现在先理解：把垃圾扔到自家车上，这个的确是没有危害公共安全。这样的行为即使发生在修正案（十一）之后，确也不构成**以危险方法危害公共安全罪**。所以 B 项说法正确。

**C 项和 D 项是对立的。** C 项说甲的行为是发生在修正案（十一）之前，那么甲是成立**以危险方法危害公共安全罪**；D 项说发生在修正案（十一）实施之前，甲不成立这个罪。它们的焦点就在于到底成立不成立这个罪。

我们学的分则就知道，从高空扔酒瓶子、从高空扔个垃圾，这种行为的确是没有危害公共安全。这一点许多同学现在不理解，没关系，不用急，我们的分则专门讲这一点。这时候不成立**以危险方法危害公共安全罪**，所以 C 项说法错误，D 项说法正确。

再回到时间效力：根据从旧兼从轻原则，按照行为时的法律（2021 年 2 月 28 日，修正案十一还没生效），甲不成立**以危险方法危害公共安全罪**，那别的罪也成立不了，这时候甲只能是无罪。所以 D 项说法正确。

| 选项 | 说法要点 | 判断 |
| --- | --- | --- |
| A | 三楼不属于高空，即使发生在修正案（十一）之后也不构成**高空抛物罪** | 错误——三楼已属于高空 |
| B | 砸在自家车上未危害公共安全，即使发生在修正案（十一）之后也不构成**以危险方法危害公共安全罪** | 正确 |
| C | 行为发生在修正案（十一）之前，成立**以危险方法危害公共安全罪** | 错误 |
| D | 行为发生在修正案（十一）之前，不成立**以危险方法危害公共安全罪** | 正确 |

答案是 B、D 两项。

这道题说是考时间效力，但它考了好多我们分则的知识点。所以这道题真正要做的话，是到分则学完以后回过头来再做，那时基本上就知道这里面的真正考点了。不过呢，这道题算是最近考时间效力的题，所以我们还是先在时间效力这一块把它讲一遍，以后再好好回顾。

### 第一讲收尾：四节内容回顾

讲完这一节，我们刑法的空间效力、时间效力就都讲完了。趁这个时机，我们把第一讲整个做一个小的总结。

第一讲一共讲了四节内容。

第一节是**刑法的解释**。这里面最重要的考点就是**扩大解释**和**类推解释**的区分，还有体系解释、目的解释、当然解释。

第二节讲的是**刑法的功能**。两大功能，其一是保护法益。

第三节讲的是**刑法的原则**。主要考的是**罪刑法定原则**和**罪刑相适应原则**。罪刑法定原则里面的思想基础主要指的是自由主义，要保障国民的预测可能性。这里面有时候还讲了一个民法和刑法的适用关系问题——不要把它理解成对立排斥关系，它们其实是第一位阶和第二位阶的关系。还有罪刑相适应原则：针对已然发生的事实施加的刑罚叫**报应刑**，针对未然发生的事实施加的刑罚叫**预防刑**，把这个原理要掌握好。

第四节就是我们今天讲的**刑法的效力**。有空间效力，有时间效力。空间效力主打四个管辖：第一个属地管辖，第二属人管辖，第三个是保护管辖，第四个普遍管辖，重要的是属地、属人、保护。最后是刑法的时间效力，你要知道**从旧兼从轻**这个原则的含义，还有它适用的案件是哪些案件。

把这些掌握好就可以了。第一讲刑法论，也叫刑法的概论，我们就讲完了。
