## 定罪的两道关：事实判断在前，价值评价在后
> 对应块：BLK05 | 覆盖分集：P04 | 块标题（分集名）：《第02讲 第01节：定罪标准：两阶层的犯罪构成体》

### 犯罪论其实只干一件事

先把地图摊开。

刑法分论管的是"这个行为该套哪一条罪名"，而整个刑法总论——具体说是犯罪论——只解决一个问题：**如何定罪**。

定罪问题又分成两大块。第一块是**犯罪是否成立**，这要靠"犯罪构成体系"来判断，我们这一讲专讲它。第二块是**犯罪成立之后的三大问题**，每一个都另有一套理论：

- **时间上的发展问题**，也就是犯罪形态：犯罪预备、犯罪中止、犯罪未遂、犯罪既遂；
- **空间上的分布问题**，也就是共同犯罪：教唆犯、帮助犯、实行犯；
- **数量上的计算问题**，也就是你犯了好几个罪，最后怎么算。

第三块怎么理解？我给大家举个人，狗蛋儿——

大清早起床，看见室友还在睡懒觉，一气之下把室友给杀了；然后一上午打了一上午的诈骗电话；打完到了中午该吃午饭了，出去吃个午饭路过银行，顺便来了个抢劫银行；到了晚上，开始忙活着组织卖淫；到后半夜自己也累了，找了一帮狐朋狗友。

这一天下来，这是时间管理大师呀，够忙，这一天过得是非常充实。但是他已经犯了好多罪。我们得一个一个罪给他数一数，把数量计算一下，最后到底是数罪并罚，还是择一重罪论处——这就是"数量计算"要回答的问题。

```text
                      犯罪论：如何定罪
                              │
              ┌───────────────┴───────────────┐
              │               │               │
              ▼               │               ▼
        犯罪是否成立                    犯罪成立之后
        犯罪构成体系                      三大问题
        （本讲内容）                          │
                                              ├── 时间发展：犯罪形态
                                              ├── 空间分布：共同犯罪
                                              └── 数量计算：数罪并罚 / 择一重罪
```

那么，犯罪是否成立，靠什么判断？有一个专门的判断标准，就叫**犯罪构成体系**。

### 犯罪构成体系，是整套刑法的底盘

关于这个体系，有两点必须提醒大家。

**第一点，它太重要了。** 它是我们的一辆汽车的底盘，也相当于一台电脑的操作系统。前面是分论的罪名，后面是责任年龄、责任能力、犯罪形态这些，底下全靠这个操作系统撑着。

**第二点，我们刑法界的"操作系统"主要是两个**——虽然实际上还有好多。一个是借鉴前苏联的**四要件体系**，这是一个系统；另一个是借鉴德日的**两阶层体系**。很多同学就是被这两套体系搞晕的。

那考试用哪一套？法硕考试大致上是借鉴前苏联，采用四要件体系；我们法考刑法采取的是借鉴德日的两阶层体系。N 多的真题已经证明，法考刑法采取的就是两阶层体系。

> **结论**：任何一个体系都没有完美的，都有优点也有缺点。但我们现在不是做研究，是考试——**考试是指挥棒，你别跟指挥棒过不去**。按两阶层体系去复习就 OK 了。

这里头有一个特别要紧的注意点：**你的体系和你的知识点一定要兼容。** 这就像你用的是苹果手机，你硬要给上面装一个安卓的 app，那肯定不兼容。我们有些同学复习到 8 月份，复习到后期，总觉得某一处打不通；我跟他详细一谈，他才知道原来是体系不兼容——他装的是一个四要件体系，却硬要在上面承载一个具体的知识点。你知道把体系打通了，有些知识点其实是很顺的。

所以这一块，书上写的内容大家务必要读两遍。不光听我讲，还要亲自读两遍，才能深刻理解。这是基本功，是基础体系。我苦苦婆心地跟大家这样讲，一定要听我这个忠告。

### 两阶层的地基：事实判断与价值评价

接下来如何认识两阶层体系？这是我们最大的问题，底层原理必须掌握好。这一块我详详细细地讲。

为了让大家把两阶层体系的底层原理掌握好，我必须引入我们哲学上的一个概念：**事实判断和价值评价**。这个概念在刑法里面好多地方都要用到，非常非常重要，希望大家认真体会。

#### 事实判断的结论能分真假，价值评价的结论不能

比如说，今天下雨了。我说这个话，就是一个事实判断。然后如果说"这真是个鬼天气"，那这就是一个价值评价。

那事实判断和价值评价有啥区别呢？

事实判断的结论，我们对它可以做真假、真伪的判断。比如你说今天下雨了，那今天到底有没有下雨？它有一个客观标准能判断。今天如果没下雨，你还说这个话，那就是说假话了。

价值评价的结论能不能做真假判断？不能。因为价值评价里装着每个人的价值观，每个人的好恶都不一样。有些人就喜欢淫雨霏霏——"好雨知时节，当春乃发生"；有的人他就讨厌下雨。每个人心境不一样，他面对同一个下雨天，评价出来的结论也是不一样的。这里头就没法做真假判断了，甚至也没有对错之分了。

| 维度 | 事实判断 | 价值评价 |
| --- | --- | --- |
| 结论能否做真假判断 | 能，有客观标准 | 不能 |
| 有无对错之分 | 有 | 没有 |
| 根源 | 客观事实本身 | 每个人的价值观与好恶 |
| 在定罪中对应什么 | 有无法益侵害事实（违法事实） | 能否谴责、责难 |

> **提示**：这里的分野不在于"哪个更重要"，而在于**结论能不能被验证**。能验证的是事实判断，验证不了的是价值评价。

不是有句话说得好吗——人生的一切痛苦，除了生病都是价值观导致的。啥意思呢？生病给你带来的痛苦，那可是实实在在的痛苦，那是个事实判断；但其他的痛苦，基本上都是价值观导致的。

#### 顺序不能颠倒：先事实判断，后价值评价

我们肯定得先说：今天有没有下雨？下雨了。然后我们再说：真是个鬼天气。事实判断在前，价值评价在后，一定要先做事实判断。

有一次我在街边看到两个人吵架，其中有一个人说了句什么？"**抛开事实不谈，你难道就没错吗？**"我当时听到这句话都懵了——我一个学法律的，听到这句都懵了。什么叫抛开事实不谈？你难道就没错吗？你不谈事实谈啥？你不谈事实谈啥？我当时就觉得，这个逻辑真的是神逻辑。

再举一个更贴近刑法的例子。我问大家：对面走来一个男人。这是个什么判断？这是个事实判断。我再说：这是一个渣男。这是什么？这是价值评价。有的人觉得人家是渣男，有的人觉得人家是暖男；那为什么又有人觉得是渣男？说你这是中央空调，你给谁都暖啊——那这不就是渣男嘛。可有的人是情人眼里出西诗。

那"这是一个恶人""这是一个罪人""这是一个罪犯"——这些都是价值评价。

所以现在大家就知道了：**给一个人的行为定性，说它是犯罪行为、说他是个罪犯，其实就是价值评价。** 当我们说某个行为构成犯罪，这本身就是一个价值评价。

不过呢，在这个价值评价之前，先要给人家做个事实判断，判断什么？判断他有没有制造法益侵害事实。如果制造了法益侵害事实，这个事实判断成立了；接下来，就着他制造的法益侵害事实，看我们能不能在价值上谴责他、批评他、责难他——这就是价值评价。

> **结论**：给人定罪，其实就是两步走。**第一步做一个事实判断，第二步做一个价值评价。**

我们拿狗蛋儿和小芳的花瓶试一下。狗蛋儿到女友小芳家，小芳在厨房做饭菜，狗蛋儿在客厅打游戏。这时候小芳家那个小泰迪"砰"一下，把小芳一个非常珍贵的花瓶给打碎了。小芳以为是狗蛋儿打碎的，拿着菜刀就出来质问："你怎么搞的啊？"狗蛋这时候只能说一句："亲爱的，这事不是我干的。"

言外之意是什么？花瓶打碎的确是一个法益侵害事实，是财产损失事实；但狗蛋儿没有制造法益侵害事实，那就不可能构成犯罪，不可能构成故意毁坏财物罪。这是第一种情况。

第二种情况：狗蛋儿真的不小心把那个珍贵的花瓶打碎了。小芳又拎着菜刀出来质问，这时候狗蛋儿只能说："亲爱的，我不是故意的。"言外之意是：我承认这个事是我干的，我制造了法益侵害事实，但你谴责不要太狠、责骂不要太狠，你对我的价值评价、对我否定评价不要太狠。

到这儿我们就大致知道了：给一个人定罪就分为两步。

### 走一遍两阶层：客观在前，主观在后

那我们现在就把书上这个图表好好看一下。

```text
┌──────────────────────────────────────────────────────┐
│  客观违法阶层（第一阶层）                            │
│  1. 客观要件                                         │
│     行为主体、危害行为、危害结果、因果关系           │
│     四项齐备 => 制造法益侵害事实（违法事实）         │
│  2. 客观违法阻却事由                                 │
│     正当防卫、紧急避险                               │
│     存在 => 违法性被走却（行为正当化）               │
└──────────────────────────────────────────────────────┘
                          ↓
┌──────────────────────────────────────────────────────┐
│  主观责任阶层（第二阶层）                            │
│  3. 主观要件                                         │
│     犯罪故意、犯罪过失                               │
│     存在 => 具备可谴责性（能责难、能谴责）           │
│  4. 主观责任阻却事由                                 │
│     责任年龄、责任能力、违法性认识可能性             │
│     期待可能性                                       │
│     存在 => 可谴责性被走却（不负刑事责任）           │
└──────────────────────────────────────────────────────┘
                          ↓
     事实判断、价值评价双双通过 => 承担刑事责任
                          ↓
                        最终有罪
```

上面这张图读下来就一句话：**先把"他干了什么"查清楚（第一步），再判断"该不该罚他"（第二步）；任何一步没过，后面一概不用看。**

#### 客观违法阶层：先看你有没有制造违法事实

第一个阶层的任务，是在客观上判断你有没有制造法益侵害事实，简称**违法事实**，所以这个阶层叫**客观违法阶层**。

它有两个板块。

**第一个板块是客观要件**：行为主体、危害行为、危害结果、因果关系。如果这些全部都具备了，那初步就可以认为你的行为制造了法益侵害事实、制造了违法事实——简称为你的行为具有**法益侵害性**、具有**违法性**。

**第二个板块是客观违法阻却事由**：看有没有一些事由，把你这违法性给你走却掉（走却就是排除）。有没有这样的事由？有，比如正当防卫、紧急避险。如果没有这样的走却事由，那么在客观违法阶层就要得出最终结论：你制造了违法事实，你的行为具有法益侵害性、具有违法性。

#### 主观责任阶层：看你能不能被谴责

接下来进入第二阶层，主观责任阶层。就你制造的法律事实而言，看能不能做价值评价、能不能谴责你、能不能否定评价你。

它同样有两个板块。

**第一个板块是主观要件**：犯罪故意、犯罪过失。你如果是故意干的或者过失干的，我都要谴责你，只不过谴责的程度不一样而已。比如狗蛋儿是过失把人家花瓶打碎了，那就是用过失来谴责——当然过失毁坏财物最终是无罪的，但是过失致人死亡是有罪的。所以过失有时候有些事实是无罪的，有的有罪。

**第二个板块是主观责任阻却事由**：看有没有一些事由，把你这个可谴责性走却掉。

> **易错点**：这里所说的"责任"，指的是**可谴责性**（有的教材也叫"有责性"），回答的是"刑法能不能谴责你、能不能责难你"。而且这个谴责**不是道德谴责**——道德上该不该骂他是一回事，刑法上能不能谴责你是另一回事。一旦刑法能谴责你，你最终就要承担刑事责任，那可就厉害了。

把可谴责性能走却掉的事由有哪些呢？责任年龄、责任能力、违法性认识可能性，还有期待可能性，大概是这些。

### 两个案子，把体系走一遍

体系讲完了，我们拿两个案子一起应用一下。

#### 昆山龙哥案：客观全打勾，被正当防卫走却

第一个要登场的是著名的昆山龙哥案。身上纹着几条龙，左青龙右白虎，一看就是"这个社会我龙哥"。但到最后就成了人狠肠子多了：龙哥嫌骑自行车的于海明不给他让道，从宝马车里拿把砍刀就砍杀于海明，结果未曾想被于海明反杀，还捅了两刀，肠子都露出来了。人家于海明扬长而去，可怜的龙哥。

龙哥自己当然是一个故意杀人行为，杀人未遂了，但他已经死了，也没法追究刑事责任了。我们要判断的，是于海明的行为怎么认定。用两阶层走一遍。

**第一阶层，客观违法阶层。** 第一个板块客观要件：

- 行为主体打勾——你是个自然人；
- 危害行为打勾——你拿刀捅龙哥，你至少是捅人；
- 危害结果打勾——你把人给捅死了；
- 因果关系也打勾——人就是你捅死的。

全部打够，初步就证明于海明剥夺了一个人的生命，制造了法益侵害事实、制造了违法事实，他的行为具有违法性。

**是不是于海明就要坐牢、要判死刑、判故意杀人罪？不是！** 还得走到第二个板块，看有没有什么事由把前面的违法性走却掉。一查警察一查就明白了：原来是龙哥先杀人家于海明啊，那人家捅你是正当防卫。就能把前面那个违法性给走却掉，说明人家行为是正当的，不构成犯罪。这个案件就这样走下来了。

#### 五岁小狗蛋：客观成立，责任年龄把可谴责性走却

五岁的小狗蛋儿——五岁那可能都得叫小小狗蛋了——来到邻居小芳家，小芳已经 18 岁了。小狗蛋儿暗恋小芳，整天到人家家去玩。结果有一天去玩，把人家小芳心爱的一个挺贵的毛绒玩具给偷走了。

这个行为该怎么处理？用两阶层走一遍。

**客观违法阶层。** 先看客观要件。行为主体打勾——注意，这跟四要件就不一样了：只要是个自然人，你就是一个合格的行为主体。你有危害行为，有危害结果，有因果关系。初步认定小狗蛋儿制造了法益侵害事实，把人家一个财产给偷走了，让小芳遭受了财产损失。他有正当防卫、紧急避险这些吗？没有。那客观阶层的结论就出来了：小狗蛋儿制造了违法事实，行为具有违法性，客观阶层打过。

**主观责任阶层。** 第一个板块主观要件，主要就是看你有没有犯罪故意：你是不是故意这么干的？他又不是不小心拿走的，他是故意拿的，他知道这是人家小芳心爱的毛绒玩具，你给偷走了，那你是故意这么干。初步来说能谴责他——这小年纪不学好，竟然偷东西。

可再往下看第二个板块：有没有什么事由把这个可谴责性走却掉？一查，小狗蛋儿年龄只有五岁，或者六岁。五六岁的孩子你能谴责他吗？刑法没法谴责他，你对他的价值评价达不到谴责的程度。

为什么？因为五岁的孩子他都没有法规范意识，他都不知道自己这个行为的法律性质和法律后果。

我们中国有句古话叫什么？**不教而诛谓之虐。** 你如果不教育他，而直接就因为他干了什么错事你又诛杀他，你其实都属于虐杀。所以这肯定是不对的。

于是这里就存在一个**责任年龄不具备**，可谴责性被走却，最终不具有可谴责性，没办法让他承担刑事责任。

### 适用顺序：先客观，后主观

两阶层的第一个应用，就是适用顺序问题。刚才详细讲过之后大家就大致知道了：**要先看客观违法阶层，再看主观责任阶层**。先看客观、后看主观，这就叫**客观主义**。

这个顺序太重要了，为此我要给大家讲一个案例。

#### 沙漠里的稻草人

古龙的小说《小李飞刀》里面，李寻欢来到沙漠，忽然看到前方站着自己的仇人。机会来了，"啪"一个飞刀就扔出去了。然后走近一看，原来是一个稻草人，而且四下无人，一片大沙漠。

现在问：对李寻欢该如何处理？有两个选择，一、构成故意杀人罪未遂；二、不构成故意杀人罪。

按两阶层怎么判断呢？先看你有没有制造违法事实，先看客观要件。行为主体打勾了。那接下来看：你是不是一个危害行为？

**危害行为就是给法益制造危险的行为**，对法益至少要制造个危险，才算危害行为。那现在大家想一想，李寻欢这一个飞刀飞过去，给谁的法益制造危险了？给谁的都没有——因为前方是个稻草人，而且是四下无人，一片大沙漠，他对任何人的生命法益都没有制造危险。

那么这样的扔飞刀行为是个危害行为吗？不是危害行为。危害行为在这里打叉，在这里就已经不构成故意杀人罪了，别的罪也不构成，无罪了。这就叫客观主义的历程。

> **提示**：客观主义是"先看客观后看主观"，绝不是"只看客观，不看主观"。它是说先看客观这一关；先看客观，危害行为就打叉、无罪了。

有的人说"你只要扔了飞刀就是个危害行为"，你不能这样说。我在我家后院朝我的墙上扔飞刀，这能叫危害行为吗？不能。我在沙漠里面扔飞刀，四下又无人，这也不是危害行为。

#### 客观判断与主观判断，差着一个罪名

我们再看一下第二种观点，第二种观点据说是法硕的观点。李寻欢这个案件构成故意杀人罪未遂。理由是：第一，李寻欢主观上有没有杀人的犯罪故意？有。第二，他客观上有没有实施一个危害行为？有啊，扔飞刀啊，那就挺危险的。所以故意杀人罪成立了。那人杀死了吗？没杀死。那你就构成故意杀人罪未遂。

我们会发现，它这里面最大的区别就在于：李寻欢扔飞刀这个行为到底是不是危害行为——到底是**客观判断**还是**主观判断**。按客观判断，他不是危害行为，因为客观上没危险；但如果按主观判断，李寻欢能扔飞刀，他主观上认为有危险，那这就认为是个危害行为，就要构成故意杀人罪，不过是未遂而已。

> **提示**：我们两阶层体系判案有一句话，叫**君子论迹不论心**。你别管人家李寻欢内心有没有犯罪故意、内心有多坏，关键是看他表面表现出来这个行为到底是不是个危害行为，而且这还要客观判断。

按"论迹不论心"，人家这个扔飞刀的行为就不是危害行为，就不构成故意杀人罪。但如果按照传统观点，那是"论心不论迹"——那李寻欢的心是坏的，有犯罪故意，我这时候就要给你定罪，不过是未遂而已。差异就是这么大。

说法硕考试遇到这个案件，定的就是故意杀人罪未遂。所以法硕考试跟我们法考考试，差异真的还挺大。

> **结论**：两类考试要用两套"操作系统"，脑子里要同时装着两个系统，是很难的事（要考法硕，最好去听车润海老师的讲课，他讲得相当好；法考这边我浪涛也讲得很好）。一个浪涛，一个大海，共同特征是啥？提取公因式——都是水货。名字都很水，但我们两个保证，讲课给大家讲的是干货。

### 体系审查思维：做题真正要练的东西

把顺序搞懂以后，我再给大家好好讲一个我们刑法考刑法的一个做题思维，这个思维叫**体系审查思维**。大家就会发现，到底怎么定罪，体系审查太重要了。

德国现在人家流行一种分析案例的方法，叫**鉴定式案例分析法**——这个"鉴定式"其实就是体系审查的意思。我们国家民法学界现在也在推广这个鉴定式案例分析法。王泽鉴的《民法思维》那本书里就专门讲体系审查，比如请求权基础的体系审查，各个请求权基础它都是有顺序、有讲究的。我们国家刑法学界现在也在推广，陈兴良的《刑法思维与案例讲习》这本书就是讲体系审查思维非常好。

如果你还不太理解，我给大家讲一个案例，它对我们做题来说有多么重要，这个一定要吃透。

#### 一道冰糖案：两个罪名，两个不同的无罪理由

有一个甲，他给乙说：想不想发财致富？乙说：我想呀，怎么发财致富？甲说：发财致富的方法都写在刑法里呀。乙说：那具体是什么方法吗？甲说：很简单。于是甲给了乙一包东西，说：你把这一包贩卖给那个丙，他给的钱，咱们两个对半分，好不好？乙一听："那好呀，对半分就行。"于是乙就把这个卖给了丙，丙付了钱，乙又把一半的钱给了甲。

事后证明，这根本不是什么毒品——甲给乙的其实是**冰糖**。也就是说，甲拿了一包冰糖冒充，让乙真以为是，乙又卖给了丙，丙这家伙也以为是，他就买了，把钱给了乙，乙又给了一部分钱给甲。

现在问：这个案件怎么处理？我们先分析乙，因为乙是实行者，甲只是一个教唆者、帮助者。

分析乙，可能的罪名只有两个：一个是**贩卖毒品罪**，一个是**诈骗罪**。

**贩卖毒品罪：主观打勾，客观打叉。**

主观要件一看就打勾了，乙主观上确实有贩卖毒品罪的犯罪故意。但问题是——**一定要先看，客观上有没有实施贩卖毒品罪的危害行为**。危害行为就要对法益制造危险，贩卖罪的保护法益就是国家对毒品的监管制度。那乙的行为有没有侵犯监管制度的可能性、危险性？我们认为没有。因为甲骗了乙，甲给乙的就是冰糖，所以他根本没有贩卖到真东西的可能性、对监管制度没有制造危险。既然没有制造危险，这就不是危害行为。危害行为这一块一打叉，直接得出结论：**不构成贩卖毒品罪**。

如果按照传统的、侧重主观主义的理论，他就会认为：乙主观上有贩卖毒品罪的犯罪故意，客观上似乎也有个贩卖行为嘛，那就成立贩卖毒品罪；如果贩卖没成功，那就是未遂。我们认为这是有问题的。

**诈骗罪：客观打勾，主观打叉。**

诈骗罪的客观要件满足不满足？打勾。换句话说，客观上乙有没有骗了丙的钱？有没有让丙遭受财产损失？有的，因为客观上真的是把丙给骗了，因为丙以为那真是毒品，还把钱给了乙。

但是乙主观上有没有实施诈骗的犯罪故意？没有。因为乙主观上并不说"我要冒充，我要骗丙的钱"，不是的。因为乙主观上认为这就是毒品，我现在就是明白明白地做等价交换，我并没有想骗别人的钱，我只是想贩卖毒品给丙。诈骗罪又是个故意犯罪，他没有这个诈骗罪的犯罪故意，所以从主观这一块就得出不构成诈骗罪的结论。

| 罪名 | 客观要件 | 主观要件 | 结论 |
| --- | --- | --- | --- |
| 贩卖毒品罪 | 打叉：无真毒品可卖，未对监管制度制造危险 | 打勾：以为卖的是毒品，有贩卖故意 | 不构成 |
| 诈骗罪 | 打勾：丙误以为真而付钱，财产损失真实存在 | 打叉：以为在做等价交换，无诈骗故意 | 不构成 |

> **易错点**：很多同学的思维是："乙客观上有危害行为，主观上有犯罪故意，所以我一定要定罪。"问题在于，他客观上的危害行为是**诈骗罪**的危害行为，主观上的犯罪故意是**贩卖毒品罪**的犯罪故意，这两个不匹配，主客观不一致。你不能泛泛地说"客观有危害行为、主观有犯罪故意，所以必须给他定罪"。有一种思维叫"客观不够主观补、主观不够客观补"——不行；那如果主观客观都不够，情节严重来补，行不行？也不行。这都违反了体系审查思维。

于是乙这两个罪都不构成，涉嫌什么罪？没有了。那我们最后就大胆地得出一个结论：**乙最终无罪。**

#### 无罪的理由，各有各的不同

按体系审查思维一步一步审，贩卖毒品罪的无罪理由和诈骗罪不构成的无罪理由是不一样的：一个是因为虽然主观打勾但客观打叉，一个是因为虽然客观打勾但主观打叉。到底哪一块打勾、哪一块打叉，我们是要详详细细把它分析清楚的。

托尔斯泰在《安娜·卡列尼娜》这本小说的第一页第一句话就说什么？"幸福的家庭都是相同的，但不幸的家庭各有各的不幸。"那我们由此也可以引出一句话：

> **结论**：**有罪的要求都是相同的，但是无罪的理由各有各的不同。**

我在德国学习的时候，看德国教授人家有一个教学优点：不管大案件小案件，人家在 PPT 上就是一个要件一个要件地审查——打勾、打勾，到这打叉，到这无罪。那无罪的理由就非常非常清晰。

但很遗憾，我们国内有一种观点。有些同学给我说什么呢：老师啊，我算看明白了，什么四要件体系、两阶层体系、三阶层体系，哎呀那都是几个要件，在那倒来倒去，都是排列组合，随意排列组合都差不多一个样。

大家给我想一想，你如果这样认为——那些要件都是随意的排列组合，没有本质区别，没有固定顺序——那就说明你**没有坚持体系审查思维**。我们认为是有固定位置的：我们两阶层体系先看客观、后看主观，这些固定位置是很重要的。

#### 价值观与方法论，是鸟的两个翅膀

德国的法哲学家恩吉施就说过，我们分析案件基本上就是两句话：**心中充满正义，目光不断往返于规范与事实之间。**

我觉得"心中充满正义"表达的是一个价值观，也就是说我们三观要正。我们法律人，我们的法官检察官律师，如果三观不正，你给这个社会的祸害越大。"目光不断往返于规范与事实之间"是什么？这是一个方法论，是定罪的方法论。那我们要有什么啊？正确的价值观，我们也要有精湛的方法论。

这就是我们法律人的两个翅膀，像鸟的翅膀，缺一不可。

但是有同学跟我说什么呢：老师啊，我发现我靠三观、靠朴素的正义感、靠常识、常情常理，我做客观题我也能做对啊，所以我不需要你那体系审查思维，那个太费劲了、太麻烦了、搞得太复杂了。

我的回答是：朴素的价值观、朴素的正义感、常情常理，的确能把客观题做对。但是——

第一，你这种正确率具有稳定性和可靠性吗？不具有吧。

第二，如果你只是靠朴素的正义感把客观题做对了，我试问主观题怎么办？主观题让你要说明理由、让你写理由的，你总不能写"理由是因为我有朴素的正义感啊，我靠了三观，我有常识常情常理"吧？肯定不行。而我们又知道，主观题才是我们的决胜局呀——许多人客观题刷刷刷很轻易就过了，结果就在主观题栽跟头了。

第三，如果我们就止步于满足自己的朴素正义感、满足自己的常情常理，用它来断案，那试问那还要我们法科生干什么？还要我们法学知识干什么？国家还组织法考干什么？大家都去用三观、用常情常理去断案就可以了。怎么当法官？就看你有没有朴素正义感；怎么当律师？看你有没有常识常情。能这样吗？肯定不行。

大家注意，我们不是说朴素的正义感、常情常理不重要——它很重要，它是我们说的价值观，一定要具有正确的价值观，它是鸟的一个翅膀。但你光有这个翅膀是不够的，你还要有精湛的方法论，就是体系审查思维。两个翅膀相辅相成，缺一不可。

但是我看有些同学，他就抹杀了精湛方法论的这个功能，光靠朴素的正义感，这肯定是不行的。

所以这一块我详详细细给大家强调了。先慢后快：刚开始你都是很慢的，这跟我们打台球、打篮球、踢足球一样，刚开始一个动作一个动作慢慢地校正，那这个过程肯定是慢的。但是时间长了以后，你慢慢就形成一种肌肉记忆，形成一种球感。也就是说，我们一定要在精湛方法论的长期训练上，最后形成一种感觉、形成一种肌肉记忆、形成一种思维，那这时候就越来越快了。

### 四要件体系卡在哪里

第三个问题，两阶层体系和四要件体系的比较。有同学就问我说：哎老师你且慢，我又不考法硕，我不用学四要件体系，你别给我比较，你比较把我脑子就搞混了。

没办法。因为我们法考的一个考察理念是什么呢？就是揭示四要件体系的一个 bug，也就是说那就是一个命题的陷阱。那我们要躲坑训练，我们肯定要认识那个坑，我们才能躲掉那个坑呀。所以从这个角度来说，我们还是要讲四要件体系的一个 bug。

我们不多讲。我不是说四要件体系一无是处，用着大致来说也没太大问题，整体上也没啥问题，就是有一个小小的 bug，把这个 bug 修复一下就好了。

这个 bug 是什么呢？就是一句话：**四要件体系认为犯罪主体是指具有责任年龄、责任能力的人。** 就这句话出问题。

#### 十岁的狗蛋和一帮望风的老爷爷

有一年我们华东师范大学法学院考研，到了复试，一位考官同事就问一个考生：请你举例说明两阶层体系和四要件体系的优点和缺点。

这个学生还是个女生，她张口就来说：十岁的狗蛋强奸小芳，让老爷爷为他望风。这一句我一听，哎呀，这肯定是听过我的课，但我也不好说什么。同事就请她继续分析：这个案件到底怎么样？

这个女生说：这个案件充分体现了四要件体系的一个 bug、一个弊端。

具体在哪呢？四要件体系认为，合格的犯罪主体是要具有责任年龄、责任能力的。那十岁的狗蛋，他责任年龄不够——因为强奸罪要求满 14 岁——所以他不是一个合格的犯罪主体。那犯罪主体都不合格，直接出局了，无罪了，踢出去了。

那现在就只剩下一个孤零零的老爷爷。

#### 四要件给出的结论：老爷爷无罪

给老爷爷定什么罪？第一，你不可能给他定强奸罪的帮助犯，因为帮助犯不能孤立存在，帮助犯必须依附于实行犯。

那这时候评委老师就说：定不了帮助犯，给老大爷可以定强奸罪的间接正犯呀，间接正犯可以独立存在、可以单独存在。

这个女生回答得挺好，还能沉着应对。她说：老师，如果要给老大爷定强奸罪的间接正犯，那么这个案件事实就要修改了。就要修改成什么呢？就是这个十岁的狗蛋儿，其实是一个童心未泯的好孩子，很纯洁善良，人家正在玩泥巴玩铁环；结果这个邪恶的老大爷指使这个狗蛋孙子："去给我强奸小芳！去强奸小芳！不强奸小心我揍你！"狗蛋儿为淫威所迫，然后去强奸小芳了。那这时候老大爷是可以定强奸罪的间接正犯，因为间接正犯是指把别人当作犯罪工具加以支配利用，对他人要有支配力，那老大爷现在对狗蛋是有支配力的。

但是我给的这个案件事实不是这样的。我给的版本是什么？是狗蛋自己要策划实施强奸小芳，他只是让老大爷给他望个风，"老大爷你去给我望个风"。是**他是指使老大爷**，老大爷还成了狗蛋的马仔了。这时候老大爷对狗蛋并没有支配力。那这时候老大爷就没法定强奸罪的间接正犯。

所以老大爷既不构成强奸罪的间接正犯，也不构成强奸罪的帮助犯，**老大爷在我这个案件事实版本里面只能无罪**。

但是按照四要件体系，这个结论合理吗？**不合理。这就是四要件体系的 bug。**

思路很清楚：先甩掉责任年龄不够的狗蛋，把实行犯从体系里直接踢出去，孤零零只剩个老爷爷；而老大爷既不依附任何实行犯（不能定帮助犯），对狗蛋又没有支配力（不能定间接正犯）——反倒让他占了便宜，让他无罪了，这就叫在风中凌乱，很不合适。

#### 两阶层的解法：客观阶层的实行犯

这位同学把两阶层和四要件体系最重要的这个区分就讲出来了。我们来看看两阶层怎么解这个案子。

**第一步，客观违法阶层。** 先看狗蛋儿的客观要件：行为主体打勾——按两阶层体系，行为主体只要是个自然人就行了，并不要求具有责任年龄、责任能力；那十岁的狗蛋儿是个自然人，行为主体打勾了。他也有危害行为，有危害结果，也有因果关系。所以初步来说他制造了违法事实。他有正当防卫、紧急避险这些吗？都没有。那最终就可以认定他制造了法益侵害事实，制造了违法事实，他干坏事了。

那么在狗蛋制造违法事实的时候，老大爷有没有提供帮助？有提供帮助。那么他和老大爷就**一起制造了违法事实**，二者的行为都是违法行为。

这个违法行为也可以称为**客观阶层的犯罪行为**。

**第二步，主观责任阶层。** 看能不能谴责他们。先看能不能谴责狗蛋儿：一查，狗蛋的年龄只有十岁，哎哟只有十岁，还真没法谴责他，最终他就不负刑事责任，无罪。

但老大爷能不能谴责你？能。因为你责任年龄、责任能力啥都具备，那当然能谴责你。那谴责你最终定的罪名是强奸罪，角色就是**强奸罪的帮助犯**。

那强奸罪的实行犯在哪里呢？全村的实行犯就是狗蛋。狗蛋不是最终无罪吗？对，狗蛋最终无罪，但那只是因为他责任年龄不具备、没法谴责他而无罪；但他在客观阶层是全部打勾的，**他在客观阶层是一个带双引号的犯罪行为，是带双引号的实行犯**。因为在客观阶层，他就实施了违法行为。犯罪概念可以阶段化地去理解。

所以狗蛋是一个客观阶层的实行犯，老大爷也走到了主观阶层，这个案件就能够合理地把它解决了——给老大爷就可以定强奸罪的帮助犯。而不像四要件体系，一上来说狗蛋不是犯罪主体，然后直接撇掉，那老大爷孤零零地反倒还无罪了，让他占便宜了，这是不合适的。

| 审查环节 | 四要件体系 | 两阶层体系 |
| --- | --- | --- |
| 狗蛋的行为主体 | 须有责任年龄、责任能力，十岁不合格，直接出局 | 只要是自然人即合格，客观要件全部打勾 |
| 狗蛋的角色 | 连实行犯都算不上 | 客观阶层的实行犯（带双引号） |
| 狗蛋的结局 | 主体不合格，无罪 | 客观违法成立，主观因责任年龄不可谴责而无罪 |
| 老大爷的结局 | 既无实行犯可依附、也无支配力，无罪 | 可谴责，定强奸罪帮助犯 |
| 评价 | 结论不合理，老大爷反而占了便宜 | 结论合理 |

> **提示**：这个"十岁狗蛋"的案子不是我自己想出来的，它有一个真题原型，就是 **2012 年法考第九题**：15 岁的甲要去抢夺，然后让 16 岁的乙给他望风。你想一想，他的特点是什么？就是那个实行者他只有 15 岁，而抢夺罪要求满 16 岁；那个帮助者乙呢，他满 16 岁了。换句话说，这里面就是**实行犯责任年龄不够，而帮助犯责任年龄够**。而十岁的狗蛋强奸小芳这个案子也是：狗蛋是实行犯，但是他年龄不够；老大爷是帮助犯，但是他年龄够。这就是我们说的做题的模型。我只是想让大家把这个好记一点，所以我就用了这个十岁狗蛋强奸小芳让老大爷去望风的版本。而这个模型 2012 年就考过第九题，也就 2012 年的这道题，就足以证明我们法考刑法采取的是两阶层体系。

### 犯罪概念可以阶段化去理解

那把这个讲完以后，咱们有些同学也注意到了：老师，你这块讲了一个"犯罪概念还可以阶段化去理解"，这是啥意思呢？

这就是我们接下来要讲的第四个问题。

传统理论把犯罪概念作为一个**点概念**。其实按照两阶层体系，犯罪概念可以阶段化地去理解：比如你客观阶层全部打勾，那你就是一个犯罪行为；你既然主观阶层也打勾，那你更是一个犯罪行为。正常来说这时候你要负刑事责任了，是吧？正常来说要负刑事责任了。

但是我们知道有的时候不是。比如**逃税罪**，我们逃税罪第四款它说什么呢？说你前面即使构成了逃税罪，但是你只要补交税款、接受行政处罚，那么不予追究刑事责任；而且这个不予追究是**应当**不追究刑事责任。那你不追究刑事责任，最终又会说无罪了。我们有些明星就享受了这个待遇。

那有些同学就疑惑了：老师，那你说这个明星他到底构不构成逃税罪啊？怎么前面说他构成逃税罪，最后说他补交税款以后就不追究刑事责任、又不构成逃税罪了？这好像很矛盾啊。

不矛盾。你如果把有罪、无罪理解成一个点概念，那当然矛盾，一会儿有罪一会儿无罪，那就冲突了。但你如果把它理解成一个前后阶段化的概念，那就一点都不矛盾：前面他已经构成逃税罪了，但是后面他补交税款了，那最终他不构成逃税罪了，因为他不追究刑事责任了。

这"补交税款"在我们书上给它起的名字叫什么？就属于**处罚阻却事由**。所以他不同阶段都有不同的犯罪概念啊，犯罪概念只要阶段化地去理解就没有问题了。

> **结论**：这一节的切入点有这么几条：用**事实判断与价值评价**这个哲学原理，把两阶层体系的底层逻辑打通；应用上记住**先客观后主观**的客观主义顺序；做题真正的肌肉记忆是**体系审查思维**（鉴定式案例分析法）；**四要件体系的 bug** 暴露在"实行犯责任年龄不够、帮助犯够"这个模型上；最后，**犯罪概念可以阶段化地去理解**，逃税罪就是最好的例子。这一块其实是个理念问题，不是个具体的考点，但理念不立，后面全乱。

### 本讲提到的题目

#### 沙漠里的稻草人

古龙《小李飞刀》里，李寻欢来到沙漠，看见前方站着仇人，一个飞刀扔过去，走近一看是个稻草人，四下无人。问：应如何处理？

选项一，构成故意杀人罪未遂；选项二，不构成故意杀人罪。

**答案：选项二，不构成故意杀人罪。** 危害行为要求对法益制造危险，李寻欢一飞刀扔向稻草人，四下无人，对任何人的生命法益都没有制造危险，危害行为打叉，客观违法阶层就已经不成立，无罪。这正是客观主义（先客观后看主观）的直接体现。若按法硕的传统观点，才会定故意杀人罪未遂。

#### 冰糖案

甲与乙商定，由甲出资、乙出力去贩卖毒品，所得利润由二人对半分。后查明甲交给乙的其实是冰糖而非毒品。乙在不知情的情况下将这包东西贩卖给丙，丙亦误以为是毒品，付钱给乙，乙又分给甲一部分。问：甲、乙二人应如何处理？

**答案：乙无罪，甲构成诈骗罪的间接正犯。**

- 乙不构成贩卖毒品罪：主观上确实有贩卖毒品罪的犯罪故意（打勾），但客观上没有真毒品可卖，根本没有对毒品监管制度制造危险，危害行为不成立（打叉）。
- 乙不构成诈骗罪：客观上确实骗得丙的财产（打勾），但主观上没有诈骗的犯罪故意，他以为自己在做等价交换（打叉）。
- 甲不构成贩卖毒品罪的教唆犯或帮助犯：既然乙都不构成贩卖毒品罪，甲自然也不构成。
- 但甲构成诈骗罪：他诈欺骗了丙的财产，虽然没有亲自骗丙，但他是利用了乙的不知情，把乙作为诈骗工具加以利用，因而是诈骗罪的间接正犯。

这道题是二十年前的法考的一道选择题，当年很多人把这个题选错了。深刻检讨选错的原因，主要就是没有建立体系审查思维、没有掌握鉴定式案例分析法。

#### 二〇一二年法考第九题

15 岁的甲要去抢夺，然后让 16 岁的乙给他望风。问：应如何处理？

**解析依据就是上面那个模型**——实行者甲只有 15 岁，未达抢夺罪要求的 16 岁；帮助者乙已满 16 岁。

在四要件体系下，甲因为不是"合格的犯罪主体"被直接排除，孤零零只剩乙；乙既没有实行犯可依附（不能定帮助犯），对甲又没有支配力（不能定间接正犯），于是得出乙无罪的结论——这正是四要件体系的 bug。

在两阶层体系下，甲在客观违法阶层是全部打勾的实行犯（行为主体只需为自然人），只是到了主观责任阶层才因责任年龄不具备而不被谴责；乙则顺利走完两个阶层，被定为抢夺罪的帮助犯。这道题本身，就足以证明我们法考刑法采取的是两阶层体系。

## 定罪的方法论：三段论推理怎么用
> 对应块：BLK06 | 覆盖分集：P05 | 块标题（分集名）：《第02讲 第02节：定罪方法：三段论推理》

### 从"柏拉图会死"说起

我们前面说过，客观题考的就是逻辑推理、逻辑论证——所以三段论推导这一块太重要了，它就是主观题的骨架。

有些同学可能上过逻辑学，有些没有，那我们从最简单的例子开始：

> 大前提：凡是人都会死。
> 小前提：柏拉图是人。
> 结论：柏拉图会死。

就这么一个推导。回头看这个例子，你能摸到一个规律：大前提是一个恒定的、一般的命题；小前提是一个变量，是一个具体化的概念——"柏拉图是人"，也可以换成"亚里士多德是人"，也可以换成"柏浪涛是人"，随时可以换、可以替换。

现在把这个规律搬到法律上来。你不管是律师还是法官，案头无非就放着两样东西：一沓卷宗，一本法条。卷宗就是案件事实，法条就是法律规定。

那么请问，哪个是大前提，哪个是小前提？

对照刚才的例子你就知道了。法律规定是一般化的概念，是恒定的命题，所以它是**大前提**；案件事实是具体的概念，可以随时换，这个案件是张三杀了人，那个案件是李四杀了人，还有王五杀了人，所以它是**小前提**。

举个完整的例子：大前提是故意杀人罪的构成要件——第232条说，故意杀人的，构成故意杀人罪，这是一个一般化、恒定的命题；小前提是案件事实，比如张三杀了人、李四杀了人、王五杀了人，这是一个具体化、可以变化、可以替换的概念。结论从哪儿来？从逻辑推导来，看**小前提是否符合大前提**。符合，就认为有罪；不符合，那就不构成这个罪。

```text
大前提 T   ← 法律规定（一般化、恒定）
              例：第232条——故意杀人的，构成故意杀人罪
                        │
                        │  法律适用＝逻辑推导
                        │  看小前提是否符合大前提
                        ▼
小前提 T₁  ← 案件事实（具体化、可替换的变量）
              例：张三杀了人 ／ 李四杀了人 ／ 王五杀了人
                        │
                        ▼
        符合大前提   → 构成犯罪
        不符合大前提 → 不构成该罪
```

所以你在逻辑推导里的任务，其实是三个：第一，**如何解释大前提**，也就是要对法律规定、对构成要件进行解释——这块我们第一节讲"刑法的解释方法"就是专门讲这个的；第二，**如何认定小前提**，因为案件事实是一个认定问题、是一个证明问题；第三，**如何逻辑推导**，也就是看小前提是否符合大前提。我们平时老说"法律解释、法律适用"，**法律适用说的就是这第三件事**。

三件事里头，第一件是解释，第二件是认定，第三件是适用。今天这一节，重点落在第三件上。

---

### 大前提只能是犯罪构成体系

先把这个大前提的范围管死。

我们认定一个案件被告人是否构成犯罪，小前提是否符合大前提——这个大前提，大家一定要记住：**只能是我们刑法规定的这个罪的犯罪构成体系，也就是犯罪构成要件。** 有罪无罪，就是看他符合不符合这个大前提；符合就有罪，不符合就无罪。

千万不要在这个犯罪构成体系之外去整出别的标准。你整出别的标准，你就不符合罪刑法定原则了。所谓罪刑法定原则里的"法定"两个字，意思就是：有罪无罪的标准的大前提，只能是刑法规定的这个罪的犯罪构成体系、犯罪构成要件。很多人是在有罪无罪的法定标准之外另外整一套标准，那其实都不符合罪刑法定原则。

我们上节课详详细细讲过的两阶层犯罪构成体系，就是这个大前提。我建议大家一定要把它记清楚，后面做题会经常用到它。我们不妨来过个电影，看你能不能记住——不要看书，就问：现在遇到一个案件，大前提是两阶层犯罪构成体系，我们怎么审查？

```text
两阶层犯罪构成体系
│
├─ 第一阶层 客观违法阶层：有没有制造一个违法事实
│   ├─ 客观要件
│   │    行为主体 · 危害行为 · 危害结果 · 因果关系
│   └─ 客观违法阻却事由
│        正当防卫 · 紧急避险 · 被害人承诺
│
└─ 第二阶层 主观责任阶层：就这个违法事实，能不能谴责被告人
│   │    即看有没有可谴责性
│   ├─ 主观要件
│   │    犯罪故意 · 犯罪过失
│   └─ 主观责任阻却事由
│        责任年龄 · 责任能力 · 违法性认识可能性 · 期待可能性
```

第一个阶层是客观违法阶层，先看客观要件：第一个是行为主体，第二个是危害行为，第三个是危害结果，第四个是因果关系。这几个都打勾了，初步来说你的行为就制造了一个违法事实、你的行为具有违法性。接下来走到后面第二个板块，看有没有一些事由把这个违法性阻却掉，这就叫客观违法阻却事由——我们图表里一共讲了三个：正当防卫、紧急避险、被害人承诺。这是第一个阶层。

第二个阶层是主观责任阶层。如果违法事实造出来了，主观责任阶层的任务就是：就你制造的违法事实而言，看能不能谴责这个被告人，也就是有没有可谴责性。这里面也有两个板块：一个是主观要件，一个是主观责任阻却事由。主观要件里有什么？就是犯罪故意，还有犯罪过失。如果有犯罪故意、有犯罪过失，初步来说就能谴责你了——明知故犯，或者你也太不小心了，能谴责你了。但还要走到后面那个板块，看有没有什么事由把这个可谴责性给它阻却掉，这就叫责任阻却事由。

责任阻却事由一共有四个：责任年龄、责任能力、违法性认识可能性、期待可能性。后两个我们后面都要学。

> **易错点**：这里说的"责任"不是刑事责任、不是刑事追责的意思，它就是"可谴责性""谴责"的意思。很多人把"主观责任阶层"理解成"要不要负刑事责任"，就讲拧了。

这个体系有点难为双考的同学了。要考法硕的同学还要再记一个四要件体系，你得装两套系统。我在这儿要提醒大家：如果你学法硕，比如听申润海老师的讲课；你考法考，比如听我的讲课，你会发现我们两个人讲课的侧重点其实是不一样的，有时候是没法比较的——侧重点不一样。法硕那边侧重于记忆性的知识点，它里面还有简答题、论述题，所以有些死记硬背的东西你得整理好；法考这边侧重于考理解性的知识点，侧重于应用，侧重于你的实战能力——也就是说你分析案件的能力怎样。

你可以比较一下法考的试卷和法硕试卷的案例分析，那个难度大不大？法考的难度特别大。法硕考试记忆性的要求、范围反而更广。所以这两套课的特点是不一样的。

有些同学就说了："你怎么把一些记忆性的东西讲得比较少呀？名词解释、定义概念讲得少，整天讲体系、审查思维、案例分析方法。"没办法，我们法考考的是一种实务能力，就是分析案件的能力，而分析案件的标准就是我们说的两阶层体系。对于双考的同学来说，两方面的能力都得具备：记忆性的知识点你还得大量去死记硬背，案例分析的方法、很深的那些你也得掌握，是有点难。但大家想一想，技不压身嘛，多学一点对自己也是收获。只参加法考的同学，相对来说就不需要死记硬背许多东西了，你只需要掌握案件分析能力就 OK 啦。

### 构成要件要素的四种分类

大前提说完，我们接下来要对大前提——也就是法律规定——在种类上做一个分类。分类的对象是**构成要件要素**。

什么叫构成要件要素？就是法律规定的最小单位，最小单位其实就是一个词语。比如"贩卖毒品罪"，构成要件要素就有两个：一个是"贩卖"，一个是"毒品"，一个是动词，一个是名词。大家会发现我们刑法的罪名相对好记，几乎全是动宾结构，动词加名词：贩卖毒品罪、故意杀人罪都是。

那我们对这些构成要件要素怎么分类？一共四种分类：

> 记述的要素与规范的要素；成文的要素与不成文的要素；积极的要素与消极的要素；客观的要素与主观的要素。

这四种里最难、最终考得最多的，是第一种。我们重点讲第一种。

#### 记述的要素与规范的要素

这一种难在哪？难在**这两个词起得不太好**。

"记述"，这是日本汉字直接译过来的。如果按照我们中国汉语的理解，你把它理解成"描述"就可以了。但是我为什么还要写"记述"？因为人家真题选项里用的就是"记述"，我不能自己把它改成"描述"。但你自己记的时候，理解成"描述"就行。

"规范"这个词含义特别多，我们会说法律规范、交通规范。但这儿的"规范"不是说法律规范、交通规范那个"规范"。一句话概括：**规范的要素，就是需要根据价值评价才能确定的要素**；而记述的要素，也就是描述的要素，描述的是事实，**是根据事实判断就能确定的要素**，一般来说是有客观标准的。

所以两边对照着记：记述要素靠事实判断，规范要素靠价值评价；事实判断一般有个客观标准，价值评价就受判断者价值观的影响。

举个例子你就明白了。还是刚才说的贩卖毒品罪，你问"贩卖"和"毒品"是记述要素还是规范要素？这应当是记述的要素、描述的要素。因为通过事实判断就能确定出来——你到底是不是在贩卖，你的成分里有没有这个东西，这是有客观标准的。

但我再问大家：我们考试考过"贩卖淫秽物品牟利罪"，这里面也有个要素叫"淫秽物品"。那"淫秽物品"在认定上，跟刚才那个有没有区别？有区别。区别就体现在：淫秽物品的认定有客观标准吗？很难弄出一个客观标准来，它要根据认定者，会受认定者价值观的影响。

有些人看到这个东西就觉得"哇，太淫秽了，不堪入目，恶心呕吐"；但有些人人家是见过世面的，说"这算啥呀，这哪叫淫秽物品，这是艺术作品"。你看，这就比较麻烦了。

所以美国最高法院那位大法官斯图尔特说了一句名言：你要问我淫秽物品的定义，我给不出来；但你如果让我看一眼，哎，我就知道它是不是淫秽物品。就是这样。

所以这种规范要素，是会受价值观影响的。不同的人看《红楼梦》、看《金瓶梅》，感受不同，仁者见仁、淫者见淫——有多少个哈姆雷特就有多少个读者。英国以前有个作家叫劳伦斯，写了一本小说《查泰莱夫人的情人》，这本书当时一问世就被当局盯上了。包括贾平凹写的《废都》，当年刚一问世——我当时第一时间没读到，许多同学读到了，说"哎呀很带劲"；等我去读的时候，读到那个紧要处就出现方框，然后写"此处省略多少个字"，让人浮想联翩、让人扼腕叹息。当年就认为这带有淫秽性，但今天就不觉得算个啥了，今天大家都见过世界了，觉得这有什么大惊小怪的。包括今天大家看余华的那个小说《兄弟》，里面有些句子很"炸裂"，读过的同学是知道的；还有电视剧《繁花》，那是同名小说，里面有些句子也是相当"炸裂"的，我看了我都有点脸红。所以这是不一样的。

回过头来我们就知道：

> **定义**：记述的要素 = 通过事实判断就能确定的要素，基本上有一个客观标准。规范的要素 = 需要价值评价、受价值观影响的要素，很难找出一个大家都公认的唯一客观标准。

我们再练一个：有一个罪名叫强制猥亵、侮辱罪，这里面有个要素叫"猥亵、侮辱"。你觉得它是记述的要素还是规范的要素？我们认为这应当是个规范的要素。因为是不是猥亵、是不是在侮辱，这同样受价值观的影响。

那这时候最终怎么办？最终就是看人家法官的价值观了——这就是人家法官自由裁量权的一部分。法官觉得这就是猥亵、这就是侮辱，那就得定；法官觉得这不算，那就不定。当然，这个法官自己也要兼听则明。所以这个法官当一个法官是不容易的，他一定要去感受我们一般人的一些标准。

#### 这条界线是相对的，不是绝对的

> **提示**：事实判断和价值评价的区分本身是相对化的，不好说得很绝对。"今天下雨了"是事实判断，"这天气真糟糕"是价值评价。但有些命题就没那么好归类了：你的室友买了条裙子，问你好不好看，你可以说不好看——好看不好看，这确实是价值评价；但你不能说人家腿很长。你说人家腿很短——这到底算事实判断还是价值评价？有的人说是事实判断，有的人说是价值评价。因为"腿很短"这里面好像有客观标准，但又确实受一些人的审美、价值观影响：人家腿明明很长的人，你让姚明去评价，他还是说腿很短。所以这里都要相对化地理解，没有绝对化。

推论也在这里：记述的要素与规范的要素，二者的区分是相对化的，不是绝对化的。这一点我们后面讲到真题的时候会再遇到。

### 小前提：案件事实存疑时怎么办

小前提就是案件事实，任务就是认定案件事实。

但大家知道，认定案件事实、查明案件事实、证明案件事实，是不是我们刑法这个实体法的任务？其实不是。认定案件事实主要是谁的任务？是刑事诉讼法、证据法的任务，是左宁老师、温媛媛老师他们的领域。

那我们刑法在"认定案件事实"这里考什么呢？我们考一个**案件事实如果存疑，你该怎么办**的问题。就是说侦查了一整，案件事实存疑了，那该怎么办？

于是我们刑法里诞生了一个原则，这个原则就叫**存疑时有利于被告人原则**。

> **易错点**：这个"存疑"，指的是**认定案件事实存疑**，不是法律适用存疑。大家一定注意。我们知道有"认定案件事实"，还有"法律适用"——认定案件事实在程序法上叫**事实审**，法律适用叫**法律审**。存疑时有利于被告人，这个"存疑"指的是在认定案件事实、事实审这个环节上存疑了、存在疑问了，**不是法律适用存疑**。法律适用你如果有疑问，你就请教人家法律专家呗，自己再多学学理论知识、把它搞清楚就完了。

考试喜欢考哪种存疑情形呢？我们看一个例子。

小芳心爱的毛绒玩具不见了，这个毛绒玩具还挺珍贵的，她报警了。警察去查，在狗蛋家给找到了，就是小芳的那个毛绒玩具。警察查呀查，最后查出的结论是这样的：它能证明这个毛绒玩具**要么是狗蛋偷来的，要么是狗蛋捡来的**。只能查到这一步了，再往下就查不出来了——到底是偷来的还是捡来的，查不出来。

现在我问你：证据法已经到了这一步了，只能查到这一步，把这个案件甩给我们实体法，我们实体法要根据一个规则、一个原则来处理。那这就是案件事实存疑了。案件事实一存疑，这时候该怎么办？就得启动存疑时有利于被告人原则，案件事实得**按有利于被告的那种情形来认定**。

那大家想想，有利于被告的情形显然是哪种情形？显然是"捡来的"这种情形。所以这个案件事实只能按捡来的这个情形来认定。

按捡来这个情形来认定的话，狗蛋捡来以后如果不给人家还，那是构成侵占罪；如果捡了以后还给人家了，那就不构成侵占罪。但**至少不能按盗窃罪来认定**，因为盗窃罪比侵占罪要重多了。所以大家注意这个问题：存疑时有利于被告人，就是这么去认定的。这是小前提的主要内容。

### 千万别把大小前提颠倒了

如何法律适用这一块就比较难、比较重要了，大家要仔细听。第一个问题就是：**要避免颠倒大小前提**。

大前提是一般化的概念，是法律规定；小前提是具体化的概念，是案件事实。但有些同学把它颠倒了——他把大前提弄成案件事实，把小前提弄成法律规定，这样去推导。考试考过这么一个错误的思维，考试就把它当陷阱考过。

我们来看那道真题。真题是这样说的：有一个孤儿院，领导们集体决策，把几个孤儿给卖掉了，现在问这个案件怎么处理。有同学是这样推导的：说这个大前提是案件事实，案件事实是什么？是一个孤儿院在拐卖儿童，这个孤儿院是个单位，是个单位在拐卖儿童——这是案件事实，我们查清楚了。那现在看小前提，查一下法律规定。法律规定是啥呢？法律规定说：单位不构成拐卖儿童罪，因为法律规定拐卖儿童罪只能由自然人构成。那最后推导出的结论是什么呢？这个案件就可以做无罪处理了，因为小前提不符合大前提。

当时就有一个 A 项说：由于单位不构成拐卖儿童罪，所以本案做无罪处理。问这个选项对不对。这个说法肯定是错的，错的原因是什么？**你颠倒了大小前提**。

那我们现在正确地推导一遍。大前提应当是法律规定。法律规定是什么？单位不构成拐卖儿童罪，但自然人构成拐卖儿童罪。那现在案件事实是什么？有个单位在实施拐卖儿童，这是案件事实。

但是大家注意，**案件事实我们可以对它进行提炼萃取，我们可以从不同角度去提炼它**。那我现在问大家：这个"单位实施拐卖儿童"里面，有没有蕴含一个"某些自然人在拐卖儿童"？你仔细给我想——这个问题肯定蕴含了。比如说领导，具体的领导在策划；那些手下在实施。因为你说单位在拐卖儿童，单位是个啥？单位是个空概念，是空架子呀，你最终还是要由自然人来策划、来实施嘛。所以这个"单位拐卖儿童"的事实里面，它就能蕴含出"某些自然人在拐卖儿童"这样一个案件事实。

我们把案件事实这样提炼出来以后，这就是小前提 T₁；大前提是法律规定。那我们来推导一下：大前提是法律规定"自然人可以构成拐卖儿童罪"；小前提是"现在领导，还有具体实施的这几个自然人，他们在实施拐卖儿童"。最后推导出的结论是什么？结论就是这些自然人构成拐卖儿童罪。这个结论就出来了，自然是构成拐卖儿童罪。所以我们就是这样去推导，就没问题了。

> **方法**：这里面的方法太重要了——**对案件事实，你完全可以从不同角度去提炼它**。一个案件事实里面，往往蕴含着另一个案件事实。你要学会提炼、萃取，这个思维特别重要，我怎么强调都不为过。

我们再拿一个案例练一遍。比如有一个公司、一个单位，它在实施贷款诈骗，有个单位在实施贷款诈骗，现在问怎么办？我们来正确地推导一下。先把案件事实作为小前提摆在这儿：单位在实施贷款诈骗。案件事实我们找到了，那现在找大前提，大前提一翻：只有自然人才构成贷款诈骗罪，单位不构成贷款诈骗罪。这个知识点我们分则还要学，还挺重要的。

那现在案件事实是一个单位在实施贷款诈骗，怎么办？对这个案件事实我们提炼萃取，提炼出"某些自然人在实施贷款诈骗"——就是人家那几个领导在策划，还有某些会计在落实，那这些都是自然人，他们在实施贷款诈骗。我们把这个案件事实提炼出来，最后来一个三段论推导：大前提是"自然人才能构成贷款诈骗罪"，小前提是"某些自然人在实施贷款诈骗"，那最后的结论就是——这些自然人构成贷款诈骗罪。

但是大家知道吗？实务中有一种观点是这样推导的，这是一道真题，这个推导我还得讲一下。

这种观点说：大前提是案件事实，案件事实是单位在实施贷款诈骗；小前提是法律规定，一查法律规定：单位不构成贷款诈骗罪。一推导，结论是本案做无罪处理。**但是呢，又觉得这个案件做无罪处理好像也不合适吧。**那实务中怎么办呢？说这个法律规定说单位不构成贷款诈骗罪——这个小前提可以换嘛，我再换一个法律规定，我再找一个法规规定，看有没有单位构成某个诈骗罪的。好，这个法律规定一找，还真找出来了。这条新的法律规定说：单位构成合同诈骗罪。

好，这个法律规定找到了，那就好办了。因为我们现在可以这样推导：说大前提是"单位在实施贷款诈骗"——那单位实施贷款诈骗的时候，肯定要用贷款合同呀，所以单位肯定是用贷款合同实施贷款诈骗了；那单位使用了贷款合同实施诈骗了。小前提是"法律规定：单位能构成合同诈骗罪"。最后结论就是：单位构成合同诈骗罪。

这个结论一出来，觉得"你看，我们这个逻辑推导也是完美无瑕啊，也把事儿办了，我们没有搞出无罪这种不妥当的结论，我们最终给单位定的是合同诈骗罪，你看，完美"。但是我们认为不完美。事儿好像是解决了，好像给这个单位定了个罪，但是呢，由于你这种逻辑推导本身就是颠倒了大小前提——你是把案件事实作为大前提，把法律规定作为小前提——你还是有 bug。

这个 bug 的后遗症，考试考了。当年这一套逻辑推导，实务中觉得行，最后还竟然把它上升为司法解释了。

那但是我们法考命题人认为：你虽然是司法解释，虽然有法律效力，但是我认为你这还是有问题。但是呢，我命题我又不能直接挑战你的司法解释——因为你的司法解释有法律效力，我怎么办呢？**我拐着弯来揭示你的 bug。**我曲径通幽，我拐着弯来解释。那怎么拐着弯来揭示呢？有一年考题是这样考的：

有一个甲公司实施贷款诈骗，骗到 100 万，然后交给一个银行职员乙，并且也告诉他：这是我们贷款诈骗来的 100 万犯罪所得，你帮我洗钱，用金融手段洗钱。这个乙说好，就照办了。现在就问：这个乙是否构成洗钱罪？

我们先来想想，洗钱罪是个什么东西。洗钱罪就是你帮人家用金融手段掩饰、隐瞒犯罪所得——人家有一个犯罪，那个犯罪有犯罪所得，然后你这个银行人员用金融手段帮人家把这个犯罪所得掩饰、隐瞒了，把它表面上合法化了，这就叫洗钱。

那洗钱罪要有一个洗钱罪的对象，是某**别的犯罪**的犯罪所得。在别的犯罪里，我们称之为**上游犯罪**。洗钱罪的上游犯罪的犯罪所得只有七种，我们后面会学，只有七种。那这七种里面有没有合同诈骗罪？**没有**。

那问题来了。如果按照那个司法解释的推导，甲公司实施贷款诈骗就定甲公司的合同诈骗罪，那这 100 万就是合同诈骗罪的犯罪所得。甲公司贷款诈骗，骗的肯定是一个银行；但他现在找的这个乙，肯定是另外一个银行的职员。那现在给这个乙能不能定洗钱罪呢？洗钱罪的上游犯罪的犯罪所得有七种，里面有没有合同诈骗罪？没有。也就是说，如果上游犯罪是合同诈骗罪，银行职员乙把这笔钱给他洗钱，那就不构成洗钱罪。所以你如果按照这个司法解释，给这个银行职员乙还定不了洗钱罪。

这就是问题呀，这就是 bug。我们觉得，给这个银行职员肯定得定个洗钱罪啊。

那按照我们刚才正确的推导，甲公司实施贷款诈骗，我们怎么推导？案件事实是甲公司在实施贷款诈骗，但这个案件事实里面能不能提炼出"某些自然人在实施贷款诈骗"？是能提炼出来的。那我们最后的结论就是：某些自然人构成贷款诈骗罪，比如领导、具体的实施人，他们构成贷款诈骗罪。而这 100 万就是**贷款诈骗罪的犯罪所得**。而洗钱罪的上游犯罪里面有没有贷款诈骗罪？刚好就有。也就是说，如果你为贷款诈骗罪的犯罪所得进行洗钱，是要构成洗钱罪的。所以最后的结论就是：这个银行职员乙构成洗钱罪。

那道题的答案就是这个——这个银行职员乙构成洗钱罪。

那"乙构成洗钱罪"这个结论，其实暗含了一个前提。前提是啥呢？就是甲公司实施贷款诈骗这个案件，是**按自然人的贷款诈骗罪来处理的**，而并没有按甲公司这个单位的合同诈骗罪来处理。也就是说，我不考你那个司法解释的内容，但我考个洗钱罪——我用下游的这个洗钱罪来考，曲径通幽，我就能够揭示你的 bug。如果我直接考那个司法解释的话，我要揭示你的错误，那是不行的。

后来这个立法解释就认可了我们说的这套逻辑推导：甲公司如果实施贷款诈骗的话，应当定的是里面那些自然人的贷款诈骗罪。由于立法解释的效力是高于司法解释的，所以这个立法解释一出，那个司法解释也就被废掉了，那个司法解释今天是已经没有效力了。

所以我们今天就要知道：**如果单位实施贷款诈骗，定的是单位里面那些自然人的贷款诈骗罪**，而不是说这个单位构成合同诈骗罪。当然你要说这个单位构成合同诈骗罪，那当然也是成立的；但是呢，你不能因此否认人家那些自然人构成贷款诈骗罪。明白吧？这里面是有这个问题的。

### 循环往复推导：多面体思维与想象竞合

第二个问题，就是书上说的循环往复推导和想象竞合。这一块也非常重要，里面也有一些需要我们特别特别注意的问题。我举一个案例，大家看那个视频都知道——他们随意地殴打那几个女孩，打得特别残忍。

说到这个案件，网上这两年有一个梗，叫"柏浪涛不懂法"。这个梗是从哪来的呢？就是因为当时出了这个案件，我一看这个视频，真的是气的不行，我就在微博上说了一句话——我说"还有王法吗"。结果被人讽刺："你懂法吗？"我当然也知道我许多法的确是不懂，那我还得继续学习。

好，我们来看这个案件。这几个暴徒本来想占人家便宜，人家不答应，就殴打，用皮鞋踹人家的头，那暴打太残忍了。我们现在来逻辑推导一下。

我板述一下大前提法律规定、小前提案件事实。案件事实就是这么一个案件事实。那我们现在找法律规定。许多同学首先找的是什么？寻衅滋事罪——因为你耍流氓嘛。寻衅滋事罪推导一下，这个案件事实符不符合寻衅滋事罪？符合的。这个案件事实是符合寻衅滋事罪的，最后得出的结论就是构成寻衅滋事罪。这是没问题的，结论就出来了。

那我的问题是：这个法律适用、这个逻辑推导，这个事儿就万事大吉了吗？这个工作是不是就画上句号了？是不是就完了？**不是的。**

这个案件事实我说过，一定要学会萃取，一定要学会提炼——**不要把它想象成一个点、一条线，你要把它想象成一个多面体。** 比如我们找出来一个面，找了一下大前提，是寻衅滋事罪，推导的结论是构成寻衅滋事罪。但你不能认为就万事大吉了，你要从不同侧面去学会分析它、评价它。这个思维很重要，分则许多同学有些地方拐弯拐不过来，就是因为这个思维没有立起来。

那我们再换一个面儿来提炼这个案件事实。我换一个面再提炼，问大家：这个案件事实里面，有没有蕴含一个"故意伤害他人身体"的案件事实？肯定蕴含了。所以我们再找一个大前提：法律规定。就可以找到故意伤害罪。找到以后，案件事实里面蕴含了一个故意伤害行为，而且把人都打成轻伤了——其实我当时就觉得那打可能都打成重伤吧，结果最后鉴定出来还是个轻伤。但不管怎样，轻伤就已经构成故意伤害罪了。所以按照这个案件事实，我们最后得出的结论是：构成故意伤害罪。

我们再换一个侧面，把这个案件事实再提炼一下，还有没有什么罪可能构成？找一找，好像没有了。整个论证就结束了。那我们的结论就是：一方面构成故意伤害罪。

许多同学说，你这个结论好像很矛盾啊——怎么一会儿说构成寻衅滋事罪，一会儿说构成故意伤害罪，这是不是很矛盾呀？

不矛盾。这时候我们就说，这两个罪现在就产生了**想象竞合**。想象竞合就这两个罪，现在想象竞合了。想象竞合是什么意思呢？**同一个事实、同一个行为，既构成了 A 罪，又构成了 B 罪**，那这两个罪此时就竞合在一起了。

但注意，这是一个行为构成的这两个罪。想象竞合了以后，我们能不能给这两个罪来个并罚呀？大家想一想，**肯定不能并罚**，只能**择一重罪论处**。

为什么不能两罪并罚？因为人家整体上只有一个行为，构成了两个罪——一个行为构成两个罪。这时候你如果给人家并罚，等于把那同一个行为，你给人家评价了两次、处罚了两次，那也是不合理的。所以这时候我们只能择一重罪论处，也就是找一个更重的罪来处罚他。

这个案件当时鉴定出来是轻伤，轻伤定故意伤害罪，量刑是比较轻的，故意伤害罪轻伤一般是 3 年；而寻衅滋事罪的量刑是可以到 5 年的。所以择一重罪论处，这个案件最终定的是寻衅滋事罪，判 5 年。他就是这么处理的。

这就是想象竞合的原理。想象竞合犯我们后面还会再讲，这里我们先提一下。

那想象竞合是怎么诞生的？其实就是我们对这个案件事实，从不同侧面来分析它、提炼它，最后认为它满足了两个罪的构成要件，构成了两个罪。所以这就是循环往复：三段论推导就有可能出现想象竞合。**想象竞合其实就是循环往复进行逻辑推导产生的。**

> **结论**：在这里面，不光是要理解有想象竞合，更重要的是——**对同一个案件事实，你要学会从不同侧面去提炼它、去萃取它**。有时候你要舍弃一些不相关的案件事实，剩下一些核心的案件事实，这样去提炼它。案件事实的提炼萃取、或者说从不同侧面去分析它，这个逻辑思维非常非常重要，我怎么强调都不为过。

那怎么去萃取呢？就是舍弃一些不重要的细节，抓住一些核心的细节。

我们打个比方。我们有时候搬家，有些人这也不愿意扔、那也不愿意扔，那整个搬家就负担很重了。其实我们知道，人活一世，需要的东西也不多，只需要什么呢？就三样东西：手机、电脑、充电宝，足矣。我们对我们人生的生活事实，我们提炼萃取也就这三样东西就够了，是吧。

这就是我们说的正确的逻辑推导，以及案件事实要该怎么去萃取。三段论推导到这里就讲完了。

### 本讲提到的题目

#### 孤儿院把几个孤儿卖掉，问无罪处理的选项对不对

**题干**：某孤儿院的领导们集体决策，把几个孤儿给卖掉了，问这个案件应当怎么处理。有一个选项说：由于单位不构成拐卖儿童罪，所以本案做无罪处理。问这个选项的说法对不对。

**答案**：错。

**解析**：错在颠倒大小前提。如果把案件事实（孤儿院这个单位在拐卖儿童）当成大前提，把法律规定（单位不构成拐卖儿童罪）当成小前提，推出来的"无罪处理"是站不住的。正确做法是回到正轨：把法律规定当大前提——拐卖儿童罪可以由自然人构成；再把案件事实从不同角度提炼萃取，提炼出"某些自然人在拐卖儿童"这个事实作为小前提。结论是：这些具体的自然人（策划的领导、具体实施的手下）构成拐卖儿童罪。参见上文"千万别把大小前提颠倒了"一节。

#### 甲公司贷款诈骗 100 万交给银行职员乙洗钱，乙是否构成洗钱罪

**题干**：甲公司实施贷款诈骗，骗到 100 万，然后交给一个银行职员乙，并告诉乙：这是我们贷款诈骗来的 100 万犯罪所得，你帮我洗钱，用金融手段洗钱。乙说好，照办了。问：乙是否构成洗钱罪？

**答案**：构成洗钱罪。

**解析**：按那种颠倒大小前提的推导（进而被写进司法解释的那一套），甲公司会被定合同诈骗罪，于是这 100 万是合同诈骗罪的犯罪所得；而洗钱罪的上游犯罪的犯罪所得只有七种，其中没有合同诈骗罪，乙就定不了洗钱罪——这就是那套推导留下的 bug。正确推导是：某些自然人构成贷款诈骗罪，这 100 万就是贷款诈骗罪的犯罪所得，而洗钱罪的上游犯罪里刚好有贷款诈骗罪，所以乙构成洗钱罪。后来立法解释采纳了这套推导，原来那个司法解释已被废止。参见上文"千万别把大小前提颠倒了"一节。

#### 构成要件要素，哪一个选项的说法是错误的

**题干**：关于构成要件要素，问哪一个选项的说法是错误的。（书上 24 页真题）

- A．传播淫秽物品中的"淫秽物品"是规范的要素、客观的要素
- B．签订、履行合同失职被骗罪中的"签订""履行"是记述的要素、积极的要素
- C．被害人基于认识错误处分财物，是诈骗罪中的一个客观的要素、不成文的要素
- D．国家工作人员是受贿罪的主体要素、主观的要素

**答案**：D。

**解析**：

- **A 项正确**。"淫秽物品"是规范的要素，要靠价值评价才能确定（斯图尔特大法官那句名言就是这个意思）；同时它是个行为对象，是客观的要素，不是主观因素。
- **B 项正确**。"签订""履行"通过事实判断就能确定有没有签订、有没有履行合同，所以是记述的要素；它又是积极要素——积极要素的意思是，从正面要证明犯罪成立就必须具备这个要素，成立这个罪肯定要有签订、履行这些行为。
- **C 项正确**。"处分"就是交付、处分，是客观的东西，所以是客观的要素；同时它又是不成文的要素——不成文的要素指法律条文里没有明确写出来、但暗含着的要素，诈骗罪的条文里确实没有这句话，但它是暗含的。
- **D 项错在后半句**。前半句"国家工作人员是受贿罪的主体要素"是对的，受贿罪的主体只能是国家工作人员；把它视为规范的要素，多数说也认为可以——因为"国家工作人员"要看有没有从事公务，而从事公务受价值评价的影响。但**"主观的要素"这个说法错了**：国家工作人员是犯罪主体，犯罪主体肯定是客观的要素；主观的要素指的是犯罪故意、犯罪过失、犯罪目的这些主观心理。

> **提示**：D 项这里还牵出前面讲过的那条线——记述的要素与规范的要素的区分是**相对化**的，不是绝对化。像"国家工作人员"这样的要素，主流观点认为其中含有价值评价的影响，所以可以视为规范的要素；但它同时也蕴含着事实判断的成分。所以事实判断与价值评价的区分，都要相对化地理解。
