## 正当防卫：体系地位、成立条件与两处硬骨头
> 对应块：BLK15 | 覆盖分集：P17 | 块标题（分集名）：《第07讲 第01节：正当防卫（01）》

"谁？柏神的家你敢偷！"

先讲个我自己的段子。有一天晚上我正睡得香呢，忽然听到阳台上有声音，一睁眼——一个小偷正在翻阳台，想偷我家。我懒得起床，就躺在屋里大喊了这一句。结果这一喊，把小偷吓得赶紧跑了。

我知道大家管我叫柏神，这是大家的厚爱，我心领了。

现在问题来了：这一喊也制止了不法侵害，那我这一喊算不算正当防卫？

我的答案是：不算。

这一喊虽然制止了不法侵害，但它不是正当防卫。为什么？光靠直觉说不清，我得带大家切到我们书上的两阶层犯罪构成体系里去看一眼——正当防卫在那个体系里站在什么位置，直接决定了这个问题的答案。

### 防卫在两阶层体系里的位置

```text
两阶层犯罪构成体系
│
├─ 客观违法阶层 ──────────────────────────────────
│   │
│   ├─ 客观要件
│   │   ├─ 行为主体    ✔ 已讲
│   │   ├─ 危害行为    ✔ 已讲
│   │   ├─ 危害结果    ✔ 已讲
│   │   └─ 因果关系    ✔ 已讲
│   │
│   └─ 客观违法阻却事由
│       └─ 正当防卫    ★ 我们现在站在这里
│
└─ 主观违法阶层 ──────────────────────────────────
    │
    ├─ 主观要件
    ├─ 责任能力 / 责任年龄
    └─ 主观违法阻却事由
```

读图：正当防卫处在"客观违法阻却事由"这个位置上，前面的行为主体、危害行为、危害结果、因果关系都已经打勾了。

把正当防卫放在这个位置上意味着什么？意味着我们分析正当防卫的时候，客观要件其实已经全部打勾了：这个行为在初步判断上已经具备法益侵害性、具备违法性，已经具备了犯罪的表面特征、形式特征了。这时候要做的不是论证"它是不是个危害行为"，而是在承认"它确实是个危害行为"的前提下，把它的违法性用正当防卫阻却掉。

那回过头看"谁？柏神的家你敢偷！"这一喊：我的行为在"危害行为"这一栏打的是叉。它连危害行为、犯罪行为的表面特征都没有——我就是喊了这么一句。所以在这一栏它就直接无罪了。既然连危害行为都不是，我还需要走到后面、靠正当防卫去排除一个根本不存在的违法性吗？排除啥？

> **结论**：制止了不法侵害，不等于就成立正当防卫。

于是就有一道判断题顺出来了。我问第一句：凡是成立正当防卫，都要求制止不法侵害——这句话对不对？对。反过来再问一句：凡是制止不法侵害的行为，都必然构成正当防卫——对不对？不对。还是我这一喊：它制止了小偷的不法侵害，但它不构成正当防卫。

> **注意**：不构成正当防卫，不等于有罪。我这一喊之所以无罪，正是因为它在"危害行为"那一栏就打叉、直接无罪了，不是因为它靠正当防卫出了罪。这个区别一定要拎清楚。

有的同学这时候会抬杠："你这一吼要是《倚天屠龙记》里的狮吼功呢？"——你不要擅自加戏好不好。我要是真使的是狮吼功，一下把它震得掉下来、摔成重伤，那我这个行为首先确实就是个危害行为，那才轮到用正当防卫来论证我的无罪。江湖里的事，咱们这一讲先不谈。

体系地位讲清楚了，接下来就正式进成立条件。正当防卫的成立条件有三个：起因条件、时间条件、意思条件。

### 起因条件：什么样的不法侵害才配得上你动手

正当防卫要求制止不法侵害，所以第一个条件就是"客观上存在一个不法侵害"。这个条件里又藏着三个要求：不法性、客观性、现实性。咱们一个一个来。

#### 防卫人是谁：被害人，或者第三人

先纠正一个特别常见的误解：很多人以为正当防卫的防卫人仅限于是那个被侵害的人、仅限于被害人。不对。防卫人可以包括第三人。

狗蛋在强奸小芳，狗胜看到了，英雄救美，拿块板砖就砸狗蛋，把狗蛋砸跑了。你说狗胜这算啥？民法上可能就算见义勇为，刑法上这就是正当防卫——因为狗胜也是在制止狗蛋的不法侵害。当然小芳自己反击狗蛋，作为被害人，那也是正当防卫。

> **结论**：正当防卫的防卫人，既可以是受害人，也可以是第三人。

#### 不法性：法益侵害性——社会法益、国家法益也能防，但必须紧迫

"不法性"讲的是法益侵害性。我们知道法益主要就三类：对个人法益的侵害、对社会法益的侵害、对国家法益的侵害。抢劫、强奸、伤害，都是针对个人法益的不法侵害；针对个人法益的防卫，是最常见的正当防卫。

那针对国家法益、社会法益的不法侵害，能不能正当防卫？2024 年考过一道题，结论是能——但是要加一个条件：必须满足**紧迫性**。

举个国家的例子：一个外国间谍正在我国境内刺探我国的国家秘密，被群众看到了，这时候我们能不能正当防卫制止他？当然能。因为这时候具有紧迫性——你再找警察就来不及了。

再举个社会的例子。小区附近的广场上，一个大妈在跳广场舞，忽然发现广场边上有个美女在站街招嫖。大妈气得不行，上去就呵斥："就是你们这种人，把社会环境都给污染了，搞得我老伴儿心旌荡漾的！你赶紧滚，不要在这儿污染我们环境了。"人家美女说："你让我去哪儿？上面老大给我分派的地盘就是这个地方，我得坚守岗位，我就不走。"大妈气得说："好，你不走是吧？你等着。"

大妈回家直接冲进厨房拿把菜刀。老伴儿问："拿菜刀干嘛？""杀鸡。""鸡在哪儿？""鸡就在大街上。"

过去以后，大妈拿刀就砍人家美女，其实也就是吓唬，把人给赶跑了。

那大妈这个吓唬的行为算不算正当防卫？不算。站街招嫖卖淫确实侵害了社会法益，这一点没问题。但这个侵害社会法益的行为，它具有紧迫性吗？不具有。大妈完全可以报警就完事了，犯得着亲自拿刀去砍吗？肯定不合适。

> **结论**：针对个人法益、国家法益、社会法益的不法侵害，都可以成为防卫的对象，唯一的区别在于——对国家法益、社会法益的防卫必须具备紧迫性。等得到警察，就不属于这里讨论的正当防卫。

#### 客观性：把修饰语统统撇掉，只留下"不法侵害"四个字

先说记忆方法。记正当防卫和紧急避险，很多人会记成"正当防卫是正对不正，紧急避险是正对正"。这话本身没错，但"正对不正"太简略，对做题帮助不大。记正当防卫，你干脆就记法条里现成的六个字：**制止不法侵害**。最核心的焦点就是这六个字。

那所谓"客观性"是什么？只要客观上有个不法侵害，我制止了，原则上就可能构成正当防卫。

问题在于，考试在这个"客观的不法侵害"前面会给你堆一堆修饰语来干扰你。修饰语有哪些？有作为还是不作为的不法侵害，有故意还是过失的，有有没有责任年龄的，有有没有责任能力的。你不要管那么多，把这些修饰语给它撇掉，只要最后剩下"不法侵害"四个字，那我制止它就可能构成正当防卫。

| 考试给你的修饰语 | 结论 |
| --- | --- |
| 作为的不法侵害 | 可以正当防卫 |
| 不作为的不法侵害 | 可以正当防卫 |
| 故意的不法侵害 | 可以正当防卫 |
| 过失的不法侵害 | 可以正当防卫 |
| 行为人没有责任年龄、没有责任能力 | 客观上仍是不法侵害，可以正当防卫 |

不作为这个考点最经典。2019 年考过一道题：狗蛋开车不慎把小芳撞伤了，他不但不救小芳，反而想逃逸。周围群众看不惯了，强迫狗蛋必须救小芳，实施了一些强迫行为。问：群众的这个强迫行为算不算正当防卫？

有的同学说："咦，这怎么能算正当防卫？"答案是，这**就是**正当防卫。正当防卫要求制止不法侵害，那这里制止的是狗蛋的什么不法侵害？制止的是狗蛋**不作为的不法侵害**。狗蛋因为先行开车撞伤小芳，已经产生了一个作为义务；现在你跑、你不救，你的不作为就是一个不法侵害。群众强迫你救人，正是在制止这个不作为的不法侵害。

所以大家可以看到，那种"你不救就打你"的强行、强迫行为，打着"你必须救"的旗号，属于制止不作为的不法侵害的正当防卫。

没有责任年龄、没有责任能力那一栏，例子也很直接：一个小孩拿刀砍杀你，你无处可躲，你反击，是不是正当防卫？是。一个精神病患者——一个没有责任能力的精神病患者——拿刀砍杀你，你反击，是不是正当防卫？也是。当然这里其实是有观点展示的，但多数说认为就是正当防卫。

> **易错点**：这里特别容易被"他没有责任能力"这几个字带偏。客观性问的是"有没有一个客观存在的侵害事实"，不是问"这个人能不能被处罚"。客观上存在的侵害，就是不法侵害。

#### 过失的不法侵害：把"正对不正"的定势拆掉

过失这一块有难点，考试考过一次但没考完，咱们要把它讲透。

案例是这样的：甲和乙两个人一起去森林里打猎，乙走在前面，甲走在后面。乙忽然发现前方有一头狗熊——实际那不是狗熊，那是狗蛋，只不过狗蛋长得熊样，让人当狗熊了。眼看乙要开枪射击了，后面的甲看到了这一幕，知道"哎哟，前面这是狗蛋，不是狗熊"，赶紧喊乙："别开枪！那是狗蛋！你别嫌他长得熊样，那是个活人，别开枪！"结果乙还是个聋子，还听不见。眼看乙要扣动扳机了，情况万分紧急、千钧一发，甲被迫朝乙的腿上给了一枪，乙的枪因此打偏了，没打中狗蛋，狗蛋获救了。

问题来了：甲情急之下朝乙腿上给了这一枪，救了前方的狗蛋，他属于正当防卫还是紧急避险？

有些同学说："紧急避险啊。"我问："为什么？""他情况很紧急，那就是紧急避险。"你们不能这样说——正当防卫也很紧急啊，德国干脆就把正当防卫叫"紧急防卫"，正当防卫当然也很紧急。

而且选紧急避险的同学，心里往往还藏着一个更深的定势，这个坑你必须把它挖出来。他之所以定紧急避险，是因为他脑子里储存的正当防卫全是这样的画面：人家要杀我、我反击，我是正当防卫；人家要抢劫我、我反击，我是正当防卫。但现在不是这样。

那么你注意，你脑子里储存的那一套"正当防卫"，所制止的不法侵害都是**故意**的不法侵害。于是你就可能得出一个结论：正当防卫制止的不法侵害只能包括故意的不法侵害。错。实际上，正当防卫制止的不法侵害只要求是个不法侵害就行，只要是客观上存在的不法侵害就行。至于主观，可以是故意，也可以是过失。

回到甲这一枪。乙如果真开枪把狗蛋打中了，乙就构成过失致人死亡罪。过失致人死亡罪属于什么？属于过失犯罪。过失犯罪属于什么？属于过失的不法侵害。而过失的不法侵害同样属于不法侵害。甲作为第三人，制止的是乙的客观上存在的不法侵害，只不过这个不法侵害是过失的——所以依然是正当防卫。

> **结论**：甲属于作为第三人制止乙的过失不法侵害，成立正当防卫。

把这个掌握好，考试考的那些"对动物反击"的情形你就完全能理解了。我一般是这么举例的，记起来特别牢。

二郎神杨戩唆使他的哮天犬去咬孙悟空，孙悟空怒了一棒把这条狗打死了。孙悟空打这条狗，属于正当防卫还是紧急避险？有同学说是紧急避险——"我记着打狗是紧急避险，我就这么死记硬背了。"错！这**是**正当防卫。因为虽然孙悟空打的是狗，但这条狗的背后有一个人在指使它。所以狗咬人，其实是二郎神的故意的不法侵害。孙悟空打这个狗，是在制止二郎神的故意的不法侵害，那就是正当防卫。

再增加点难度。假如二郎神有一天睡着了，疏忽管理，没牵住这个狗，狗自己跑出来了，跑到花果山去咬孙悟空。孙悟空问："是不是杨戩派你来的？"狗说："不是，我的主人还在灌江口老家睡觉呢。我现在对你很感兴趣，我现在就要咬你。"孙悟空一怒之下把这条狗打死了。

这下孙悟空是正当防卫还是紧急避险？有同学说："二郎神没有故意指使啊，那这下就不是正当防卫了，那就是紧急避险。"还是错！前面讲过，正当防卫制止的不法侵害既包括故意的，也包括过失的。二郎神睡着了、疏忽管理导致狗跑出来，这算不算过失的不法侵害？有没有过失？有，管理上的过失。那这就是过失的不法侵害，孙悟空打这个狗还是在制止不法侵害，那就是正当防卫。

那么孙悟空打狗难道就一定没有紧急避险的情形吗？有。前面两条哮天犬，背后都有二郎神这个"老板"。可要是来了一条野生的野狗，也凑热闹，学人家哮天犬要来咬孙悟空，孙悟空一棒把它打死了——这时候才是紧急避险。

所以我出一道题给大家：请你用"违法阻却事由"这个词，说一说"武松打虎"这个成语。武松打虎，老虎咬武松，武松把虎打死了——武松是什么？是紧急避险。因为这时候面对的是个野生动物，它背后没有一个人，它只能落在紧急避险里，不能落在正当防卫里。打一条野狗、打一只野生动物，前提是它要咬我，我把它打死，这时候就是紧急避险。

大家学会这一套你会发现，一部《西游记》基本就是这个套路：天上的神仙要么故意把自己的坐骑弄下去，要么睡着了、过失让自己的坐骑跑下去，跑到人间变成妖怪去吃唐僧。太上老君不就是睡着了、不小心让他的青牛精跑下去了吗？孙悟空作为第三人打这些妖怪，基本上都是正当防卫——要么是制止天上神仙故意的侵害，要么是制止天上神仙过失的侵害。孙悟空挺累的，都是在正当防卫。那孙悟空有没有打妖怪构成紧急避险的呢？有。那就是这种妖怪是野生的，背后没有一个人、没有天上的神仙做后台老板。打这种野生妖怪，那就是紧急避险。

顺便做一张对比表，把两种情形彻底分开：

| | 正当防卫 | 紧急避险 |
| --- | --- | --- |
| 面对的东西 | 他人实施的不法侵害 | 危险源（背后没有不法侵害人） |
| 孙悟空打哮天犬 | 杨戩故意唆使 → 正当防卫 | — |
| 孙悟空打跑出来的哮天犬 | 杨戩疏忽管理 → 正当防卫 | — |
| 孙悟空打野生野狗 | — | 背后无人，属于危险源 → 紧急避险 |
| 武松打虎 | — | 老虎是野生动物 → 紧急避险 |

#### 现实性：假想防卫

不法侵害的第三个要求是现实性。这块有一个考点挺重要，叫假想防卫。

假想防卫你别去背概念定义——我们法考不考概念定义，不考简答论述，只考案例分析。你想到假想防卫，就记一个案例就行。

狗蛋出差，他老婆小芳趁丈夫出差，立马把情夫狗胜叫到家里来幽会。狗蛋出门没走多远，忽然想起笔记本电脑忘带了，又返回家。推门一看，他就愣住了，盯着这个画面愣住。就在他发愣这一刻，人家小芳急中生智，反应很快："老公赶紧救我！他强奸我，你赶紧救我！"

狗蛋一听立马火冒三丈，拿把菜刀直接砍狗胜，把狗胜砍成重伤。

问题：狗蛋把狗胜砍成重伤，他属不属于正当防卫？不属于。为什么？正当防卫要求制止的是个**现实的**不法侵害。狗胜现在有现实的不法侵害吗？没有啊，人家根本没在强奸，双方是在幽会。但是狗蛋主观上认为有不法侵害，他就实施了。那狗蛋这就是**假想防卫**。

假想防卫的特点就一句话：你主观上认为有不法侵害、要去防卫，其实客观上根本没有不法侵害。显然它不可能构成正当防卫。那假想防卫怎么办？处理分三步：

> **处理规则**：
> 假想防卫不可能构成故意犯罪；有过失的，按过失犯罪处理；没有过失的，按意外事件处理。

那狗蛋把狗胜砍成重伤，他有没有过失？如果有过失，那就是过失致人重伤罪；如果没有过失，那就是意外事件。过失和意外事件我们后面会系统学，这里先做一个初步判断，标准就一个：看狗蛋虽然没预见到狗胜实际上没有不法侵害，但他有没有预见到的可能性。

有人会说："无法预见，他根本不可能预见得到。"我们认为还是有预见到的可能性的。为什么？你看一看那个场面——那能像强奸的场面吗？那么和谐、那么文明、两个人在那儿安安静静地幽会，这能像强奸的场面吗？所以你是存在预见到的条件的，说到底你太听信你老婆的话了。既然有过失，狗蛋构成过失致人重伤罪。当然你要是换条件、换成他确实无法预见，那狗蛋就是无罪，属于意外事件。

> **易错点**：假想防卫永远不会构成故意犯罪，因为故意要求你认识到自己在侵害一个法益，而假想防卫的故意里根本没有真实的法益侵害事实。

最后说一句大家可能没想到的。刚才小芳那句"老公赶紧救我，他强奸我"，把狗胜给出卖了。小芳有罪吗？有罪。给小芳定什么罪？这个知识点我们在共同犯罪里学——小芳定的是**故意伤害罪的间接正犯**。她把狗蛋的不知情利用起来，把狗蛋当作工具加以利用，属于间接正犯。

起因条件讲完了。

### 时间条件：侵害什么时候算"正在进行"

时间条件要求不法侵害正在进行，也就是不法侵害**已经开始但尚未结束**。侵害还没开始你就去防卫，叫事前防卫；侵害已经结束了你才去防卫，叫事后防卫。事前防卫、事后防卫都叫防卫不适时，都不构成正当防卫。

#### 防卫装置：这周插的碎玻璃片，不算事前防卫

先看不法侵害的开始，这里面一个重点问题是设立防卫装置。最简单的设立防卫装置是什么？给院墙上插些碎玻璃片。

这种行为算不算正当防卫？有人说："这属于事前防卫吧？人家下星期可能小偷来我家偷，你这星期你就开始插碎玻璃片了，你这不是事前防卫吗？"错。

我们应当这么理解：我这星期插碎玻璃片的时候，我这个防卫装置起作用了吗？并没有起作用。什么时候才起作用？下星期小偷来翻墙偷的时候，那才起作用。我是在侵害开始以后才起作用的，所以我这种设立防卫装置不算事前防卫。我是事前设立了防卫装置，但防卫真正起作用是在侵害开始以后，所以时间条件是没问题的。

那插碎玻璃片会不会危害公共安全？墙上有人走怎么办？好家伙，在墙上走的那都是什么人？都是梁上君子。正常人会在墙上走吗？所以也不会危害公共安全，这个设立防卫装置是完全正当的。

#### 昆山龙哥案：龙哥跑了吗，危险解除了吗

接下来是不法侵害的结束，这涉及事后防卫。关于这个问题，我们必须把我们的昆山龙哥请出来。这个案件我在其他章节会详细讲，今天必须把它吃透。

龙哥虽然离开我们已经好几年了，但龙哥永远活在我们刑法课堂上。龙哥是用他平凡的生命推动了我们中国法治的进步的，所以我们一定要把龙哥这个知识点吃透，把这个案件吃透。

这个案件大致分为三个阶段。

第一个阶段是**战略防御阶段**。龙哥开了一辆宝马，他嫌骑自行车的于海明不让道，一怒之下在车里拿出一把砍刀砍于海明，一会儿砍中路，一会儿神龙摆尾。于海明这时候也是沉着应战，兵来将挡、水来土掩，人家是见招拆招。这是于海明的战略防御阶段。

接下来进入双方**战略相持阶段**。相持阶段怎么发生的？是龙哥砍人的时候，手里那把刀掉地上了。这说明什么？说明龙哥底盘不稳、基本功不扎实，走位也没受过专业训练，有点野路子，他应该向人家拳击手张志磊好好学习学习。就在这个时候，于海明快速上前，他首先捡到了这把刀，只用一刀就捅到了龙哥的七寸。龙哥"哎哟"一声就被捅中了。你看，龙哥自己捅来捅去、砍来砍去没砍中，说明他都是花拳绣腿；但人家于海明一刀就成，刀法不拖泥带水，效率特别高。

龙哥发现自己被捅了一刀，就赶紧跑。这时候于海明去追，于是于海明进入了**战略反攻阶段**。龙哥往他宝马车那儿跑，刚跑到车那儿刚要开车门，于海明的刀砍过来了。龙哥赶忙一躲，砍到车框上了。龙哥看进不了车，就往路边的草丛里跑，但跑到那儿已经体力不支、失血过多，原来肠子都流出来了——我龙哥，人狠肠子多。于海明见此情景，扬长而去。龙哥最后失血过多死了。

三个阶段，前两个阶段在时间条件上于海明都算防卫适时，没问题。现在的焦点问题是：**于海明在战略反攻阶段，算不算事后防卫？** 因为此时龙哥是在跑、在逃跑，你于海明还追砍，这时候算不算事后防卫？

按以前的说法，这就是妥妥的事后防卫——龙哥都逃跑了，人家的不法侵害都已经结束了，你还去追、去砍，那妥妥是事后防卫，就不是正当防卫了。

但是这个案件当时虽然也是这样认定的，老百姓不答应，专家学者也不答应。我们一直主张什么？**不法侵害的结束，有两个要求**：一个是不法侵害的行为举动要结束；第二个是不法侵害的危险性也要解除。这个"危险性解除"，就是指反扑的可能性也要解除、再次侵害的可能性也要解除。

现在龙哥逃跑，他的**不法侵害的行为举动**的确已经结束了。但是，他逃跑，我们还要看他**不法侵害的危险性**有没有结束，也就是说他还有没有反扑可能性、还有没有再次侵害的可能性。

那这个应当怎么判断？我们的司法解释根据这个案件已经明确了：不能从事后诸葛亮的角度去判断，而应当从**行为时一般人的角度**去判断，看他还有没有反扑可能性。

从行为时一般人的角度去判断，龙哥往哪儿跑？他是往他的宝马车里面跑。那我们就有理由相信两件事：一是他有可能在车里再拿一把刀，因为你那把砍刀本来就是从车里拿出来的；二是他可以开车撞——车本身就是个犯罪工具，可以开车撞人。所以我们认为他有反扑可能性。既然有反扑可能性，就说明有再次侵害的可能性，说明龙哥的不法侵害还没有彻底消除。那么于海明的追砍行为在时间条件上依然属于防卫适时，而不属于事后防卫。

> **结论**：不法侵害是否结束，要同时满足"行为举动结束"和"危险性解除"两个要求；危险性能不能解除，要从事发当时一般人的角度判断，不能事后诸葛亮。

也就是说，毛主席教导我们，渡江作战我们并没有完，战略反攻的时候是什么来着？"宜将剩勇追穷寇，不可沽名学霸王。"所以这就告诉我们，此时防卫是适时的。

当然了，你如果从事后诸葛亮的角度去判断，有可能龙哥的确是想逃命、并不想反扑了——毕竟他肚子上都被捅了一刀，那一刀还挺重。但是我们不能从事后诸葛亮的角度去判断。

为什么这么强调？因为你从事后诸葛亮角度去判断，你其实是开了天眼。开天眼那不行。看看有些抗日神剧，它总是喜欢开天眼，说："同志们，加油！八年抗战剩最后一年了，我们要再接再厉！"你看你都知道"八年抗战剩最后一年"了——其实现在都成了十四年抗战了。

这就是龙哥案件最重要的时间标准。

#### 财产犯罪的例外：当场追回财物

关于时间条件还有一个财产犯罪的特殊情形，需要注意。

狗蛋抢劫到了小芳的钱财，拿到钱财以后撒腿就跑。小芳当场为了挽回财物就追，终于追上了，把狗蛋打趴下，把钱财夺回来。现在问：小芳夺回财物的这个行为，算事后防卫还是防卫适时？

我们认为是**防卫适时**，不属于事后防卫。

> **结论**：财产犯罪，犯罪人即使已经取得财物，但只要被害人当场能够挽回财物，这个当场挽回财物的行为仍然属于防卫适时，不属于事后防卫。

### 意思条件：主观上要"知道自己在防卫"

意思条件里藏着一个最难也最重要的考点，就是偶然防卫。

#### 偶然防卫：坏心办好事

先把案例辨认好，标准案例是这样的，我要给大家板书了。

有一个乙，他要开枪杀死丙，正要扣动扳机的时候，自己被爆头了，被打死了。被谁给杀了？被甲给杀了。甲开枪把乙打死了。

假如甲当时看到乙要杀丙，甲为了制止乙的不法侵害把乙打死了，那么甲显然属于正当防卫，是吧？这就简单了，没什么疑问。

但**偶然防卫**恰恰是另一种情形：甲当时**没有**看到乙正在杀人，甲只有一个想法——"我要杀死我的仇人乙。"甲就把乙给杀了。而甲如果没把乙打死，乙就会顺利地扣动扳机，把丙打死。这个甲，就叫偶然防卫。

偶然防卫的特点是什么？我们回到"制止不法侵害"这六个字上来。它也分客观要件和主观要件。偶然防卫就是：**客观上制止了不法侵害，主观上没有认识到这一点**。

```text
         客观上              主观上
      制止不法侵害         有无防卫认识
  甲 ─────  ✔     ──────►     ✘
              └─ 偶然防卫 ─┘
                 客观打勾    主观打叉
```

读图：甲在"制止不法侵害"这个条件上，客观那一栏打勾，主观那一栏打叉。这个组合就是偶然防卫。

形象地说，偶然防卫就是**坏心办好事**。

#### 两说之争：偶然防卫到底成不成立正当防卫

坏心办好事，怎么处理？能不能成立正当防卫？这里有两说，是典型的观点展示，而且是平分秋色的观点展示——没有哪个是唯一定论，也没有说是哪个是多数说。但这个观点展示的内部逻辑结构，我们一定要把它理解好。

**防卫认识不要说。** 在"制止不法侵害"这个条件上，不要求防卫认识。也就是认为，我只要客观上打勾就可以了，客观上制止了不法侵害，就能成立正当防卫，不要求主观上有防卫认识。标志性的结论是：**偶然防卫一律成立正当防卫**。

它背后的底层原理叫**结果本位主义**，理论上也叫结果无价值论。这个术语不好理解，你就理解成结果本位主义。它的标志性结论是：**结果好，那么推导出来行为就是好行为**。就看你这个行为制造的结果是好结果还是坏结果；制造的是好结果，制造好结果的行为就是好行为。

顺着这个思路往下推：甲把乙杀了，客观上制造的是好结果还是坏结果？坏心办好事，客观上办的是好事——他制止了乙杀人的不法侵害，救了无辜的丙一命。好结果。制造好结果的行为就是好行为。好行为我得奖励你，奖励的形式就是：成立正当防卫。

**防卫认识必要说。** 在"制止不法侵害"这六个字上，客观要件、主观要件都必须打勾，主客观要相统一。也就是成立正当防卫，既要求客观上制止不法侵害，而且要求主观上认识到这一点。结论是：**偶然防卫一律不成立正当防卫**。

它的底层原理叫**行为本位主义**，理论上也叫行为无价值论。行为本位主义的标志性结论是：**你不能用结果的好坏来推断行为的好坏**。结果的好坏和行为的好坏独立判断，各算各的账。

他为什么这么认为？因为他认为，坏心办好事这种情况是偶然的。正常情况下坏心会办坏事，偶然的坏心才办好事。同样的道理，好心正常情况下会办好事，但好心有时候也会办坏事。这里头没有必然联系。所以你不能以结果的好坏来推断行为的好坏——你这么做就是以成败论英雄，而这种历史观是不正确的。

那独立判断的话，行为本身要好的，才能成立正当防卫。而甲的行为本身就是坏的——他就是想杀死他的仇人乙，那就是一个坏行为。不能因为碰巧办了好事，就把这个行为说成好行为。那既然是坏行为，就要给他定罪。

#### 故意杀人为什么只到未遂

要定罪，这里有一个非常难的难点。我们直接上结论：甲成立故意杀人罪，但犯罪形态是**未遂**。

先说为什么是未遂、不是既遂。

**既遂结果是有要求的**，它分两个层次的要求：一个叫**事实判断**，一个叫**价值评价**，也叫法律评价。

这两个哲学概念我们刑法里多处要用，作用很大，先回顾一下什么叫事实判断、什么叫价值评价：事实判断是"今天下雨了"；价值评价是"下雨天真糟糕"。一个是描述，一个是评价。

所以一个结果要成为故意杀人罪的既遂结果，需要两个条件：第一，在**事实判断**上，你要制造一个死亡结果；第二，在**价值评价**上、法律评价上，这个死亡结果还必须是一个**坏结果**、是实害结果。

为什么必须是个坏结果？因为既遂结果是要严惩的，是要加重处罚的。只有坏结果我才可能给你严重处罚；你要是制造了个好结果，我能给你加重处罚吗？

有人会问：死亡结果……那不肯定是坏结果吗？肯定是危害结果吧？可我问你：法警执行枪决、执行死刑，他也制造了一个死亡结果，那在价值评价上你能说那个结果是坏结果、是实害结果吗？肯定不能——那个结果是个好结果。

> **结论**：死亡结果不一定就是坏结果，有些死亡结果可以是好结果。既遂结果 = 事实判断上的死亡结果 + 价值评价上的坏结果，两个条件缺一不可。

好，现在来衡量甲。甲偶然防卫把乙打死了，首先在事实判断上，他制造了一个死亡结果，这个条件满足了。接下来评价这个死亡结果是好结果还是坏结果？显然是好结果——他坏心办好事，制止了乙杀人的不法侵害，救了无辜的丙一命。既然是好结果，那就不能认定为既遂结果，因为既遂结果必须是坏结果、必须是加重处罚的结果。现在是好结果，你不能给人加重处罚。

不能认定为既遂，那还剩什么？实行阶段一共三大犯罪形态——未遂、中止、既遂。既遂已经排除掉了，只剩下未遂和中止。甲有中止行为吗？有自动放弃吗？没有。那按照排除法，给甲只能选未遂。所以甲成立故意杀人罪未遂。

你看防卫认识必要说给甲定未遂，这里面其实已经体现了两层意思：行为本位主义认为行为的好坏和结果的好坏要独立判断、各算各的账，因为这样更公平——行为上甲确实成立故意杀人罪，这是坏行为；结果上他确实办了坏事之外的好事，在结果这一栏上给他奖励一下，所以不予定既遂，定个未遂，可以从宽处罚。

而结果本位主义就不这样。防卫认识不要说、结果本位主义会认为："结果好，制造好结果的行为就是好行为，整个行为都是好的，不构成犯罪，是正当防卫。"防卫认识必要说、行为本位主义说："我不走那样的极端，我各算各的账，行为的好坏、结果的好坏独立分开，我觉得这样更公平。"

#### 观点为什么会打架：结果本位与行为本位

这两个观点背后，其实体现的是每个人不同的价值观。

结果本位主义就是看重结果，结果好那行为就好，它本质上就是**以成败论英雄**。什么场合最容易接受结果本位主义？站在老板的立场上，一般接受、喜欢、赞成的就是结果本位主义——"你不要跟我说那么多，我只要结果，我只要结果。"

但如果我们作为员工，更愿意站在行为本位主义立场上。我们会说："虽然我没有制造出好结果，但是我还是付出了很多劳动，没有功劳也有苦劳嘛。你不能说没有好结果，我整个行为都得不到认可，那不行吧。"

好多年前我有个师弟，他考上研究生，我就问他："你这个大学四年过得咋样？"他说："不堪回首，糟糕透了！"我说为什么？他说因为他谈了个女朋友，谈了三年，到了大四毕业季、分手季，人家把他甩了，所以他大学四年是不堪回首。我说："那你这就是结果本位主义。"

他最后果然是赞成结果本位主义、赞成结果无价值论的。他的恋爱观就是：没有一个好结果、最终没走到一起，那么整个恋爱过程那都不堪回首了，都要否定掉。但如果按照行为本位主义，这两个事情就得分开看——虽然没有走到一起、虽然没终成眷属，但谈恋爱的过程还是美好的，还是值得回忆的。

考法考也一样。有些同学就是结果本位主义：如果没考过，那这一年的付出就算白费了，完全浪费了。但有些同学看得开：即使没有考过，我这一年也学了好多知识，还跟着柏浪涛听了几个段子，还是有点收获的。

有些同学问我："老师，那你的价值观是啥？"我的价值观是这样的：我是行为本位主义。为什么？因为我觉得，追求结果、结果本位主义的人，结果导向，这一生成就感会高一点；而行为本位主义的人，因为不要求那么好的结果，重在过程，成就感可能会低一点，但是幸福感可能会强一点。我愿意幸福感强一点，不追求成就感高一点。因为功名利禄那些，有时候到头来也都是一场空。辛弃疾不是说过吗——"人生不过二两酒，一两无奈一两愁。都是黄泉预约客，何必计较忧与愁。"我们禅宗里面不是也讲"一朝风月，万古长空"。泰戈尔也说过："空中没有一丝痕迹，鸟儿已经飞过。"

当然，这是我的价值观，不能影响你。每个人有每个人的价值观，而且每个人遇到不同的场合、不同的事情，价值观还可能发生变化。正因如此，所以我们认为价值观是多元的，要尊重大家。所以这个知识点它就是观点展示、开放式地考，从来没有考过唯一正确答案。你只要能够把它逻辑推导好、逻辑自洽就行了。

偶然防卫这个知识点就讲到这儿。

### 防卫挑拨与相互斗殴

接下来重点讲另外两个特殊情形：防卫挑拨和相互斗殴。这两个也挺喜欢考的。

#### 防卫挑拨：恶意利用正当防卫制度

苏州有个狗蛋，跟铁牛有矛盾。有一天他拿个剪刀把铁牛电瓶车的轮胎给扎破了，而且把剪刀藏在身后，对着远处的铁牛喊："我把你的车轮胎给扎破了，你觉得爽不爽？你有种过来呀！"他还学沈腾，用食指勾人家："你过来呀！你过来呀！"把铁牛气得火冒三丈，跑过来就要殴打狗蛋。结果狗蛋临危不惧，从身后拿出剪刀，直接捅铁牛，把铁牛捅成轻伤了。

后来狗蛋被抓了。狗蛋说："是铁牛先动手打我的，他先扑过来要打我，我这是防卫反击，我是正当防卫，你不能给我定罪。"

你想想法官怎么定？还是要定故意伤害罪。为什么？因为这叫防卫挑拨。

铁牛为什么扑过来打你？他是先动手、是要先打你的，这没错。问题在于，他为什么要打你？是你挑拨人家、挑衅人家，是你引起人家来打你的——你这样去挑衅，是个男人都要冲过来打你。所以这时候这就叫防卫挑拨：认定你其实是没有防卫意图的，不认可你的这种行为。你是在恶意利用正当防卫制度。既然不能让你恶意利用正当防卫制度，那肯定要给你定一个故意伤害罪——你把人家捅成轻伤，故意伤害罪。

> **结论**：防卫挑拨不成立正当防卫。行为人故意挑拨、激怒对方，使对方来打自己，然后反过来"防卫"，这是在恶意利用正当防卫制度，按故意伤害罪等实犯处理。

#### 相互斗殴：斗殴无防卫，承诺有但有限度

相互斗殴其实就是相互约架。狗蛋带着女朋友小芳逛街，铁牛看了小芳一眼，狗蛋就不爽了，质问："看什么看？你哪儿来的？"铁牛也不服气，对小芳说："只因为我在人群中多看了你一眼，你男朋友就忘不了我的容颜，就要跟我干仗？干就干，说个地点！"狗蛋说："择日不如撞日，现在就开干！"两个人就为此打起来了。

这属于相互斗殴。互相打起来都把对方打伤了，这时候一方能不能说"我是正当防卫，他是故意伤害罪"？不能。

关于相互斗殴，我们有两个结论。

第一个结论叫**"斗殴无防卫"**。相互斗殴的任何一方都不能主张"我是正当防卫"。为什么？因为正当防卫要求"正对不正"，要求制止不法侵害，而相互斗殴是什么？"不正对不正"，是狗咬狗一嘴毛。任何一个人都不要说你是正当防卫，你们两个都是大大地坏了，就是这个意思。

第二个结论叫**"斗殴有承诺，但承诺有限度"**。既然是相互约架，其实就有一个心理预期、有个承诺：人家可能会把我打伤，但我还是要应战。这里其实就涉及一个被害人承诺的问题——被害人承诺我们后面专门会讲。在这里先把结论记住：**承诺遭受轻伤，这个承诺是有效的**；**如果承诺遭受重伤、承诺放弃生命，这个承诺是无效的**。

所以在相互斗殴里面，狗蛋把铁牛打成了轻伤，由于我们认为铁牛对轻伤是有承诺的、这个承诺也有效，所以狗蛋不构成故意伤害罪；但如果狗蛋把铁牛打成了重伤或者打死了，那狗蛋还是要构成故意伤害罪的加重结果，或者构成故意杀人罪。

#### 混战里怎么分：先看谁先动手，再看地点

相互斗殴的结论掌握以后，会带来一个实际问题：怎么区分双方是在相互斗殴，还是一方在不法侵害、另一方在正当防卫？因为有时候打起来一片混战，分不清。主要的考量点有两个。

**第一个，看谁先动手。** 有一个北方同学跟我说："我看南方人吵架太累了，吵半天都不动手，即使动手也是且战且退。要是我，废什么话，直接开干就完了。"南方人主张"君子动口不动手"。这里面有没有蕴含生活智慧？蕴含了。为什么？因为一旦动手，那就是不法侵害，谁先动手谁就是不法侵害，防守的那一方就带有防卫性质了。所以"君子动口不动手"这句话，是对的。

但有的时候我们把它把握得不太好。比如前两年唐山烧烤店那个案件，案件发生了以后，有人竟然说什么"双方是在打架，我们要劝架"。可大家知道，我们一般说"打架"，意思是说双方在打架斗殴了，打架斗殴往往就被理解成相互斗殴了。但那个暴徒和那几个可怜的女孩儿是在相互斗殴、相互打架吗？不是的。这时候关键看谁先动手。有人说是女孩先动手，她拿瓶子去砸人家——你不对，你仔细看那个视频：是那个暴徒、那个歹徒他先摸人家、先调戏人家。他先调戏人家，这就是个不法侵害；你调戏人家，人家啪地扇你一耳光，那咋了？没问题啊。所以是这个暴徒他们先动的手，所以人家这个女孩儿属于防卫。不能说双方在打架，不能说是打架斗殴，应当是暴徒在进行不法侵害、这些女孩儿在进行防卫。

**第二个，看地点，地点也很重要。** 实务中有这样一个案件：甲老板跟乙老板发生了矛盾，甲老板给乙老板打电话说："你信不信我把你的公司给砸了？"乙老板说："你有种就放马过来！"甲老板就带了一帮人冲到乙公司，见人就打、见东西就砸。乙老板也做好了应战，带着人马严阵以待，两边就打起来了。最后警察来了，把双方都带走了，认定双方是在相互斗殴，说是聚众相互斗殴。

这个认定有没有问题？肯定有问题，乙老板怎么能是在相互斗殴呢？当时警方说"你就是相互斗殴"，理由是：甲老板说"你信不信我带人把你公司给砸了"，乙老板竟然回答"有种放马过来"，那你这不就是接受挑战吗？你不是应邀吗？那这不就形成了约架吗？

好像是形成了约架，但问题是——**地点在哪里？** 地点在乙老板的公司。你只要上门打人家主人，那你就是不法侵害，主人是在保卫家园，那当然是防卫反击。所以这个时候主人就是防卫行为、正当防卫行为。你不看地点的话那是不公平的。你要是不看地点，那好家伙，你这么说的话，日本鬼子侵略到我们中国来，我们中国军人奋起反抗，你能说双方是在聚众相互斗殴吗？肯定不是。我们是什么？是卫国战争，是保卫家园。

> **结论**：相互斗殴的成立与否，主要考量两个点——先看谁先动手（先动手的一方是不法侵害），再看地点（上门打人的，进人家门的一方是不法侵害，被打的一方是在保卫家园）。

把这两个点掌握好，相互斗殴的重要考点就整理完了。整个意思条件的主要内容，也就讲完了。

## 正当防卫：防卫对象、花瓶三情形与防卫过当的判断
> 对应块：BLK16 | 覆盖分集：P18 | 块标题（分集名）：《第07讲 第01节：正当防卫（02）》

正当防卫我们前面一条一条过了条件，这一块还剩两个硬骨头：一个是**防卫反击的对象到底能指向谁**，一个是**限度条件里的防卫过当怎么判断**。这两个恰恰是考试里最容易被绕进去的地方。

先说对象条件。我先问一个很具体的问题：如果站在我面前的不法侵害人**不是一个，而是一群人**——这一群人里有实行犯，有教唆犯，有帮助犯——那我是防卫人，我对着他们**谁能反击、谁不能反击**？这就是这一块最焦点的那个问题。

### 对着共同犯罪人，防卫反击打向谁

这个问题的主导思想，其实杜甫一首诗里说得特别透。大家都念过——

> 挽弓当挽强，用箭当用长。
> 射人先射马，擒贼先擒王。
> 杀人亦有限，列国自有疆。
> 苟能制侵陵，岂在多杀伤。

你看"**射人先射马，擒贼先擒王**"，意思就摆在这儿了：原则上，只能对那个**实行犯**进行防卫反击。教唆的、帮忙的，本身不是那支射出去的箭，不是那个动手的人，所以原则上不是我的反击目标。

举个我们一直用的例子，狗蛋儿故意伤害铁牛，小芳在旁边望风。铁牛且战且退，正准备防卫反击，这时候问题就来了：

对狗蛋这个实行犯，铁牛反击他，当然可以，这就是正当防卫，没有问题。

那对在旁边望风的小芳，能不能反击？**不能**。因为小芳这个行为没有攻击性。她就站在那儿看着，既没动手也没递家伙，她对铁牛不构成现实的、紧迫的不法侵害。

那如果小芳不是望风，而是**教唆犯**或者**间接正犯**呢？也不能对小芳反击——理由还是一样：她没有攻击性。教唆只是把狗蛋的念头挑起来，真正砸过来的是狗蛋那只手。

但是，**一旦小芳的行为有了攻击性，结论立刻翻转**。

我们还是狗蛋打铁牛这个场景，只不过小芳不光望风了。她看男朋友狗蛋打得有点费劲，就跟狗蛋说："哎呀你这么费劲，你也知道我是跳钢管舞的，我把钢管拔了给你，拿这打他。"然后真给狗蛋递了一根钢管过去。

这一刻性质就变了。这已经不是"望风"了，这是**递凶器**——帮助行为本身带上了攻击性。那铁牛对这样的帮助犯实施防卫反击，**是可以的**。

所以这块我们总结一下：

| 对象 | 能不能对其防卫反击 | 判断理由 |
| --- | --- | --- |
| 实行犯 | 可以 | 亲手实施不法侵害，攻击性直接具备 |
| 教唆犯、间接正犯 | 不能 | 教唆、支配本身没有攻击性 |
| 帮助犯（无攻击性，如望风） | 不能 | 帮助行为尚未指向防卫人 |
| 帮助犯（有攻击性，如递凶器） | 可以 | 帮助行为已具现实的侵害指向 |

记住这个"**攻击性**"三个字就够了。

### 花瓶三情形：牺牲第三人利益时怎么定性

对象条件过完，接下来是**三种特殊情形**。这三种情形长得极像，就是角色对调一下，全靠一个字之差定生死，所以特别容易搞混。

但在进这三种情形之前，我要把一个**体系地位**的问题先钉死，否则后面会绕不过来。

正当防卫的上位概念叫**违法阻却事由**，它在犯罪论体系里属于**客观阶层的第二个板块**。前面还有一个板块，叫**客观要件**。也就是说，要判断正当防卫，客观要件必须先全部打勾——**你这个行为首先得是一个危害行为**，初步看具有法益侵害性、貌似犯罪行为，警察才可能先把你带走，回头一查发现原来是正当防卫，再放你走。

顺着这个体系往下看，就出现了一个特别重要、也特别好用的结论：

> **结论**：抵挡行为本身不是危害行为。

什么意思？大家设想我朝你扔一个飞镖，你拿个铁锅一挡——这个飞镖被铁锅挡住了，我没刺中你，**但我把你的铁锅给刺穿了**。你的抵挡行为客观上也制止了我的不法侵害。请问：你构成防卫过当吗？**不构成。**

为什么？因为你**拿铁锅抵挡**这个行为本身就是无害的，你没有还击，你没有制造任何法益侵害危险。你的行为在"危害行为"这一关就打叉了，直接无罪了——**我的无罪根本不需要用正当防卫来论证**。

这个道理你一旦接受，下面三种情形就是水到渠成了。

#### 情形一：把花瓶砸向侵害人

甲故意伤害乙，情急之下乙把丙的珍贵花瓶拿来砸向甲，砸中了甲，花瓶也毁损了。

先说乙对甲。乙砸的是正在侵害自己的甲，这是标准的正当防卫，成立。

再说乙对丙。瓶子是丙的，砸碎了，损的是丙的财产法益。乙以防卫的手段牺牲了无辜第三人的财产利益——这在**紧急避险**的范畴里。当然要以符合紧急避险的其他条件为前提，比如"迫不得已"之类。

所以这个情形里，乙一个行为，对甲是正当防卫，对丙是紧急避险——这属于**正当防卫和紧急避险的想象竞合**。违法阻因事由之间也可以想象竞合。想象竞合怎么处理？**最终优先认定为正当防卫**。

> **提示**：正当防卫和紧急避险发生想象竞合，优先认定正当防卫。

这个情形，**16 年考过**。

#### 情形三：只是拿花瓶抵挡

同样甲故意伤害乙，情急之下乙把丙的珍贵花瓶拿起来——但**只是抵挡，没有反击**。花瓶毁损了，他没有砸向甲。

对甲构成正当防卫吗？**不构成。**这就是我们前面刚钉死的那个体系问题：乙拿花瓶抵挡这个行为本身不是危害行为，在客观要件的"危害行为"这一关就打叉了，直接无罪，用不着拿正当防卫来说事。

> **易错点**：这里最容易错在"他确实制止了不法侵害啊"。制止了不等于就是正当防卫。**没有还击的抵挡行为，不是危害行为，正当防卫无从谈起。**

但是——你毕竟损了人家无辜第三人的花瓶。所以乙对丙还是要构成**紧急避险**。

所以情形三的结论是：既不是正当防卫（对甲），又是紧急避险（对丙）。跟情形一比，就差在"**砸向甲**"还是"**只是抵挡**"这四个字上。

这个情形，**2024 年考了**，去年刚考完。

#### 情形二：花瓶本来就是侵害人自己砸的

这是唯一一个两种定性都不成立的，也是最狠的一个。

甲拿起丙的花瓶砸向乙，想伤害乙。乙用手臂抵挡，结果花瓶掉在地上摔碎了。问乙怎么办？

首先，乙对甲**不成立正当防卫**。跟情形三一样的道理——单纯的抵挡行为没有危害性、没有违法性，在"危害行为"这一关就打叉。既然乙连危害行为都不是，那这个案件的定性根本走不到后面"违法阻因事由"那个板块，压根不需要用正当防卫或紧急避险去排除违法性。

其次，乙对丙**也不成立紧急避险**。因为这个花瓶**不是乙拿的**——是甲拿人家丙的花瓶砸向乙，乙只是伸手挡了一下。花瓶摔碎这个结果，算不到乙的头上，应当算到甲的头上。乙自己都没有违法性，还需要用正当防卫、紧急避险去排除自己的违法性吗？不需要。

> **结论**：情形二里，乙既不构成正当防卫，也不构成紧急避险。

但请注意，这**不是说乙有罪**。乙一开始就不是危害行为，在危害行为这一关就打叉，直接就无罪了。

三种情形，一考过、三考过，就剩**二没考过**。所以第二个情形是重中之重。它的全部解题价值就在于那一句归责逻辑：**花瓶是甲砸的，碎的结果算甲头上，跟乙没关系。**

| | 花瓶砸向谁 | 乙对甲 | 乙对丙 | 乙的最终状态 |
| --- | --- | --- | --- | --- |
| 情形一 | 乙主动砸向甲 | 正当防卫 | 紧急避险 | 想象竞合，优先认定正当防卫 |
| 情形三 | 乙只是拿它抵挡 | 不成立（非危害行为） | 紧急避险 | 成立紧急避险 |
| 情形二 | 甲砸向乙，乙徒手抵挡 | 不成立（非危害行为） | 不成立（归甲） | 无罪 |

### 防卫过当：过当结果怎么判断

接下来是第五个条件，**限度条件**。限度条件主要解决的是：到底构不构成**防卫过当**。

防卫过当有客观要件，也有主观要件。我们先说客观要件——客观要件要回答的就是一句话：**你有没有制造一个"过当的结果"。**

法条给的规定是：**防卫行为如果明显超过必要限度，造成重大损害**，就属于制造了一个过当的结果。

这句话怎么落地？理论上有两种看法，一种把**相当性标准**作为首要标准，一种把**必要性标准**作为首要标准。我们用一个案例就能把争议点全部揭示出来。

村里有那么一个恶棍。他强奸了村里一个寡妇，后来又去了一次。半夜三更破门而入，这回寡妇做好了准备。人家心生一计，跟他说："你先别动手，你看你其实长得也不错，能靠颜值嘛，为什么要靠暴力呢？我给你准备了一杯枸杞茶，你喝了你会龙马精神、一展雄风的。"这恶棍一听那不错啊，一饮而尽，立马七窍流血暴毙身亡。

现在问题来了：寡妇的行为是防卫行为，那么它是构成正当防卫，还是属于防卫过当？**你弄死人家，算不算一个过当的结果？**

**相当性标准**说的是什么意思？它表达的是一个**比例原则**：不法侵害的程度越严重，防卫的程度也可以越严重。侵害轻我就轻，侵害重我就重，两边台阶是一级一级往上走的。

这个原则听着好像没问题，挺合理的。但**它落到实务里就出问题了**：你能不能要求一个防卫人，在千钧一发之际时刻遵守这个比例原则？

按相当性标准看我们这个案例：恶棍刚破门而入，刚进屋，**还没有开始动手**，还没有对人实施暴力，那这一刻不法侵害"还没那么严重"。你这时候直接上一个大杀器把人弄死了——你这不符合比例原则。你的防卫级别和不法侵害级别没有沿着台阶一级一级往上走，人家还没到很严重的程度，你直接原子弹扔出来了。**所以防卫过当。**

**但是我们认为，把相当性标准作为首要标准去考虑，是不利于保护防卫人的。**

于是第二种观点登场，叫**必要性标准**。它表达的是什么？**只要是制止不法侵害的必要手段，我就不过当。**

放回这个案例：歹徒又来强奸，已经破门而入。虽然此刻你还没有对我实施暴力、还没有动手，**但我如果等到你已经对我动手、打我、压制我反抗的时候，我还有什么反击的可能？我还有什么机会？**我是一个单身女子，三更半夜，我哪有机会？天天不灵，叫地地不应。

从制止不法侵害的必要手段这个角度看，我可以智取、可以制取他，毒杀在这种情况下就是我的**必要手段**。所以此时弄死你，**不是防卫过当**。

> **结论**：必要性标准今天已经成为**多数说**。只要是制止不法侵害的必要手段，就不构成防卫过当。按今天多数说，枸杞茶案不过当。

这就是防卫过当在**客观要件**上的过当结果判断标准。

### 手段过当，不等于结果过当

客观要件里还有一个观点展示的问题，讲的是**手段过当和结果过当**的关系。给一个标准案例，大家就明白了。

狗蛋想**强制猥亵**小芳。刚拉小芳的手，小芳猛地一转身，端出加特林机枪，哒哒哒开始扫射——**一盘子弹都打完了，一颗都没打中**，人体描边大师。

问：小芳构成防卫过当吗？这里有两种观点。

**少数说**认为，这时候是防卫过当，因为**手段过当**了。人家只是要强制猥亵，现在刚抓你的手，你好家伙加特林机枪伺候，这手段也太猛了，所以构成防卫过当。

**多数说**认为，小芳**不构成**防卫过当。为什么？因为虽然手段过当了，但**她没有制造过当结果**。防卫过当要求制造过当结果。她虽然哒哒哒扫射，但是一个死亡结果都没有产生——没打中就什么都没有，所以不构成防卫过当。

> **结论**：防卫过当要求"制造过当结果"。手段过当而结果未过当的，不构成防卫过当。这是多数说。

大家常问我，老师你怎么整出这么多少数说、多数说，烦不烦。太烦了。但这不都是为了**主观题**服务嘛——主观题现在都考观点展示。而且你们会发现，学了这个你会发现，**真正我们刑法的案件很少有唯一正确答案**。我们又不像理工科，理工科才有唯一答案；刑法这边只能看谁的理论论证更有说服力。所以这块大家要适应。

那反过来问一句：**如果当时小芳真打中了**，人家也不是人体描边大师了，人家也不是浪得虚名，那加特林机枪真把狗蛋打成筛子了，这时候打死了——小芳确实构成防卫过当，**而且最终罪名是故意杀人罪**。虽然是故意杀人罪，但这个罪判得不会很重，因为**应当减轻或者免除处罚**。

### 防卫过当的成立条件：罪名范围与主观底线

法条对防卫过当的规定是：**应当负刑事责任，但应当减轻或免除处罚。**

那问题就来了——"负刑事责任"负的是什么责？有的同学说，那就定一个叫**防卫过当罪**。有这么一个罪名吗？**没有。**

所以防卫过当要负刑事责任，它的具体罪名无非是这么几个，从最重到最轻：

| 排序 | 罪名 | 主观 |
| --- | --- | --- |
| 最重 | 故意杀人罪 | 故意 |
| 稍轻 | 故意伤害罪（致重伤） | 故意 |
| 再轻 | 过失致人死亡罪 | 过失 |
| 最轻 | 过失致人重伤罪 | 过失 |

既然防卫过当只可能落在这四个罪名里，那我们在判断它的成立条件时，**就可以直接以这四个里最轻的那一个作为衡量标准**。也就是以**过失致人重伤罪、过失致人死亡罪的成立条件**来衡量防卫过当的成立条件。

#### 客观要件：要发生一个过当结果

防卫过当的客观条件是**发生过当结果**。按最轻的罪名衡量，那就是**至少要有一个重伤结果，或者一个死亡结果**。达不到重伤、死亡这个门槛，就不是防卫过当。

#### 主观要件：至少过失

主观上，防卫过当要看最轻的那个罪——过失致人死亡罪。所以**主观要件要求至少有过失**。

如果主观上对这个死亡结果、对这个过当结果**连过失都没有**，完全是一个**意外事件**——那就**不构成防卫过当**。因为意外事件是不负刑事责任的，它既然连刑事责任都不负，那当然就不算防卫过当。

> **结论**：防卫过当，客观上要有过当结果，主观上至少过失。偶然事件不构成防卫过当。

所以我们用**过失致人重伤罪的成立条件**来衡量防卫过当，成立条件就是这两条：客观有过当结果 + 主观至少过失。

### 特殊防卫：第 20 条第 3 款给的到底是什么

接下来是**最厉害的一个正当防卫**，就是第 20 条第 3 款。

条文的表述是：对**正在进行的行凶、杀人、抢劫、强奸、绑架，以及其他严重危及人身安全的暴力犯罪**，采取防卫行为造成伤亡、死亡，**不过当，不负刑事责任**。

这个条文，理论上一般被叫作**特殊正当防卫**，也有人叫**无限防卫权**。

很多人一理解就理解歪了：既然叫无限防卫权，那**只要遇到行凶、杀人、强奸、抢劫，我就可以弄死你，我弄死你也不过当**。举的例子是这样的——狗蛋想迷奸小芳，给小芳端了一杯饮料。小芳嗅觉很灵敏，一闻就闻出来里面有迷药，连化学成分、分子式都闻出来了。小芳立马说：你想迷奸我，迷奸也是强奸，我学过第 20 条第 3 款，面对强奸我可以行使无限防卫权，我弄死你都不过当。于是小芳又端出加特林机枪，把狗蛋扫射成筛子，打死了。

那小芳算不算防卫过当？**我们认为还是要算防卫过当的。**

这就告诉我们：**并不是说遇到强奸、抢劫、杀人，我就可以无限防卫、弄死你也不过当。不是这个意思。**

你要是这么理解，就把这个条文理解成**特事特办**了，等于法律给了我一个特权：遇到这些罪，弄死你我都不过当。不是的。这个条文是**正常办事儿**。

为什么说是正常办事？因为"造成伤亡、死亡也不过当"这件事，是因为**它满足了前面讲的正当防卫正常的限度条件**。而正常的限度条件要求什么？要求"**严重危及人身安全的暴力犯罪**"。

所以这个条文的核心特征就是这一句话：

> **定义**：严重危及人身安全的暴力犯罪。

正因为对方是**严重危及人身安全**的暴力犯罪，所以在防卫限度上我就可以高到弄死你。就此而言，我遵守了**必要性标准**，也遵守了**相当性标准**，所以不过当。

> **结论**：第 20 条第 3 款不是特权，是正常办事。它之所以可以致人死亡而不过当，是因为它落在了正当防卫正常的限度条件之内。

顺着这个意思，还有一种情形也要注意：比如**昏醉型抢劫**，把人灌醉带着取财目的、把财物拿走——这也叫抢劫。这时候他刚把你灌醉，你能不能说"你这是抢劫，我学过第 20 条第 3 款，我弄死你也不过当"？**不是这样的。**

还有一个特别需要大家注意的字眼，就是"**行凶**"。

以前的观点里，有一种说法认为"行凶"必须带着凶器才算。**其实我们行凶不要求带凶器。**"行凶"只要求满足一句话：**你使用的是严重危及人身安全的暴力手段**，这就是行凶。司法解释已经把它明确了：行凶不要求携带凶器，只要求严重危及人身安全的暴力手段，就算行凶。

我估计是武侠小说看多了才发现——**真正的武林高手，人家不会带凶器的**。不会带个什么 low 的凶器，什么狼牙棒、什么大铁锤，那跟人家的形象不符呀。人家往往都是空手打、空手道，降龙十八掌、九阴白骨爪、如来神掌，还有现代的什么闪电五连鞭——那闪电五连鞭那也很厉害的是吧。**真正的高手不需要带凶器，他照样可以满足行凶。**

把这个掌握好就可以了。因为你面对的是**最严重**的不法侵害，所以你的防卫限度也可以**最厉害**，但它仍然是正当防卫，仍然在正常的限度体系之内。

### 唐雪案综合演练：把五个条件串起来走一遍

条件是一条一条讲的，但考试仍然是**综合性**地考，所以我们最后综合训练一个案例——著名的**唐雪案**。

先把案情的时间线捋一遍：

```text
白天
  与村中男青年李某发生口角，随后各自散去
  │
  │  当晚约 22:00
  ▼
李某左想右想，觉得白天被唐雪骂得丢脸，气不过
  → 拿一把菜刀到唐雪家，一拍门，喊："唐雪，你给我出来"
  │
  ▼
唐雪其实已经睡下，听见叫骂声，不慌不忙
  → 穿好衣服
  → 到厨房拿一把菜刀，装进一边裤兜
  → 到客厅拿一把比较长的水果刀，装进另一边裤兜
  （左兜一把刀，右兜一把刀，准备就绪）
  │
  ▼
唐雪开门。门刚一开，李某："你来啦，你终于来啦" → 持刀上前要砍
  │
  ▼
李某的同伴怕出人命，赶紧把他的刀夺下来
  │
  ▼
李某赤手空拳冲上前，拳打脚踢殴打唐雪
  │
  ▼
唐雪拔出菜刀抵挡 → 被李某一脚踢飞
  │
  ▼
唐雪心想"多准备一把刀还是有用" → 改拔水果刀
  李某要踢，唐雪躲过；混战中唐雪已被打到地上，
  李某仍在拳打脚踢
  │
  ▼
唐雪以水果刀乱捅乱刺，双方混战
  │
  ▼
李某忽然发现腹部有血，一闻是自己的血
  → 知道自己被唐雪刺了一下
  → 转身且战且退，向同伴连喊三声"给我拿刀来"
  → 扑通栽倒在地
  │
  ▼
同伴把他抬起来，发现腹部中了一刀
  → 送医抢救，因失血过多，经抢救无效死亡
```

一审的结论是：出了人命，唐雪是**防卫过当**。

但这个案件一共有**三个争议点**，我们一个一个过。

#### 争议一：唐雪是事前防卫吗

第一个争议点说：你唐雪属于**事前防卫**，不符合时间条件。理由很清楚——人家只是在拍你的门、在那儿叫骂呢，你倒好，一听见就开始准备两把刀，一个裤兜一把刀，你这不就是事前防卫吗？

这个说法**不对**。这叫**事前做好准备**，不叫事前防卫。

我作为防卫人，可不可以事先做点准备？**可以。**人家拿个菜刀拍我的门，在那儿骂，我事先准备一下凶器，做个防卫准备，这都算事前防卫？不是这样的。

正因为这个案件，司法解释后来专门总结过：**防卫人事前是可以做准备的**，比如事前准备凶器。记住这一条就够了。

#### 争议二：这是相互斗殴吗

第二个争议点是意识条件上的：你们俩是**相互斗殴**啊——毕竟是一片混战。

这个说法**也不对**。我们认为：**李某是不法侵害，唐雪是防卫行为。**

那怎么判断到底是相互斗殴，还是一方不法侵害、一方正当防卫？**关键看两个点：第一，谁先动手；第二，地点在哪里。**

这个案情里说得非常清楚：其一，是**李某先动的手**，他先去殴打；其二，**地点是对方家里**，他上门来打你，这是侵入人家，是侵略别人的家园，唐雪是在保卫家园。

所以不能说是相互斗殴。唐雪就是在防卫，李某是不法侵害。

#### 争议三：限度条件是否过当

第三个也是最关键的争议点：限度条件。一审觉得你防卫过大了，弄死人了，出了人命。理由是：**人家当时没有拿凶器打你**——凶器当时被同伴夺下来了，他是赤手空拳打的。**赤手空拳可不算行凶，行凶要带凶器。**

这个理由，恰好就是我们刚才前面讲过的那个误解。

**行凶不要求携带凶器。**虽然"行凶"里有个"凶"字，但那个"凶"指的不是**凶器**，那个"凶"应当指的是**气势汹汹**。

气势汹汹是什么意思？就是我们前面说的——**你的手段已经是严重危及人身安全的暴力手段**，这就叫行凶。

那我问大家：李某上门就把唐雪打倒在地，还拳打脚踢往上打——**你这算不算严重危及人身安全的暴力行为？**算。你这其实就是行凶，这不是行凶还是什么是行凶。

> **易错点**："行凶"里的"凶"是气势汹汹，不是凶器。空手打人也可能是行凶。

那面临这种**正在进行的行凶**，第 20 条第 3 款说了，我的防卫级别就可以高到弄死你，弄死你也不过当。而且**这也是我的必要手段**——我那时候如果不拿刀捅你，怎么保不齐？说不定你就要拿刀了，你看你后面不是也喊"给我拿刀来"了吗？

所以这时候已经是**你死我活的斗争**了，弄死你也不过当。从限度条件上，也不过当。

#### 综合结论

把五个条件一一分析过来，我们认为：**唐雪构成正当防卫。**后来这个案件的结果，也确实给唐雪定了正当防卫，并且由此还提炼出了一些司法解释的要点——其实就是把我们刚才分析的这些要点都吸纳进去了。

到这里，正当防卫的成立条件就全部讲完了。回头看这一讲：先是共同犯罪人里对谁能反击、帮助犯看攻击性；再是花瓶三情形里"砸向"和"抵挡"的一字之差；然后是限度条件里必要性与相当性的取舍、手段过当与结果过当的分离、防卫过当的罪名范围与至少过失的主观底线；最后是第 20 条第 3 款的正确读法，以及唐雪案这条把全部条件串起来的综合线。

### 本讲提到的题目

#### 题目一：狗蛋强制猥亵小芳，加特林扫射未击中

**题干**：狗蛋想强制猥亵小芳（按给定条件即为强制猥亵）。刚拉小芳的手，小芳猛地转身，端出加特林机枪扫射，一盘子弹打完，一颗都没打中。问：小芳是否构成防卫过当？

**答案**：**不构成**（多数说）。

**解析**：少数学说认为手段过当即构成防卫过当；多数说认为防卫过当要求"制造过当结果"，本案未造成死亡等过当结果，故不构成。若加特林真打中把人打成筛子，则构成防卫过当，**故意杀人罪**，依法应当减轻或免除处罚。详见正文"手段过当，不等于结果过当"一节。

#### 题目二：唐雪案

**题干**：李某因白天口角吃亏，当晚持菜刀到唐雪家拍门叫骂，唐雪已睡下，听声后穿好衣服、到厨房取菜刀与客厅取水果刀各揣一边裤兜后开门。李某持刀上前砍人时，被同伴夺刀，遂赤手空拳拳打脚踢唐雪；唐雪拔菜刀抵挡被踢飞，改拔水果刀，在被打倒在地、对方仍在殴打的情况下乱捅乱刺。李某发现腹部出血，且战且退并连喊三声"给我拿刀来"后倒地，送医因失血过多经抢救无效死亡。问：唐雪的行为性质如何？

**答案**：**构成正当防卫**，不属于事前防卫，不是相互斗殴，限度条件也不过当。

**解析**：
- 唐雪事前备刀属**事前准备**而非事前防卫，正当防卫的时间条件并不排斥防卫人事前准备凶器（详见"争议一"）；
- 判断相互斗殴抑或防卫与不法侵害，看**谁先动手**与**地点**，本案李某先动手且上门侵入，应认定李某为不法侵害人（详见"争议二"）；
- 李某虽空手，但手段已达严重危及人身安全的程度，即构成"行凶"；"行凶"不要求携带凶器。面对正在进行的行凶，唐雪致人死亡既是必要手段，也落在第 20 条第 3 款与限度条件之内，故不过当（详见"争议三"）。

> **承前启后**：上一节讲完「正当防卫：防卫对象、花瓶三情形与防卫过当的判断」，下一节接着讲「紧急避险：五道关口，最难的是主观与限度」。

## 紧急避险：五道关口，最难的是主观与限度
> 对应块：BLK17 | 覆盖分集：P19 | 块标题（分集名）：《第07讲 第02节：紧急避险》

刚讲完正当防卫，我们接着看紧急避险。它跟正当防卫长得挺像，但没正当防卫那么难，也没那么重要。即便这样，成立条件我们还是得老老实实总结一遍。

紧急避险的成立条件一共五个：起因条件、时间条件、意识条件、不得已条件、限度条件。前面三个管"该不该管"，后面两个管"管到什么份上"。真要挑刺，意识条件里的**偶然避险**和限度条件里的**法益衡量**，是最容易被绕进去的两块，也是考试最容易下手的地方。

### 起因条件：危险从哪儿来，以及它必须是真的

#### 危险的两个来源

起因条件指的是：**避免一份危险**。这份危险主要来自两个地方。

第一个是大自然的危险——野生动物袭击、自然灾害这一类。前面讲过的例子全在这一格里：老虎咬武松，武松打虎；野狗咬狗蛋；野狗咬孙悟空，孙悟空打野狗。我们说这都是紧急避险。

具体一点：老虎咬武松，武松打不过老虎，武松就跑、就逃；老虎追着咬，武松无处可逃，迫不得已闯到人家潘金莲家。潘金莲当时单身，还没嫁人。闯进人家家里躲起来，为了救自己的命而不得已侵害了第三人的住宅法益——这就是来自于大自然的危险。

第二个是人的危险，也就是人的不法侵害。把老虎换成西门庆：西门庆追着砍武松，武松还是打不过人家，武松就逃；无处可逃，迫不得已闯进潘金莲家。这还是紧急避险。

但如果武松不逃，直接去反击西门庆，那武松干的就是正当防卫了。

| 危险来源 | 追着武松的是谁 | 武松的反应 | 法律性质 |
| --- | --- | --- | --- |
| 大自然的危险 | 老虎 | 逃不掉，闯进潘金莲家躲避 | 紧急避险 |
| 人的危险 | 西门庆 | 逃不掉，闯进潘金莲家躲避 | 紧急避险 |
| 人的危险 | 西门庆 | 不逃，直接反击 | 正当防卫 |
| 大自然的危险 | 老虎（还在 2 公里外） | 提前跑去闯进潘金莲家 | 事前避险，不属实 |

#### 假想避险：危险不能是你自己吓出来的

危险必须具有**现实性**，不能是你假想的。如果是假想的，那就可能构成**假想避险**。

标准案例是这样的：狗蛋儿有一天走在马路上，不小心踩到了一堆狗屎，很无奈。一手扶着电线杆，一手甩狗屎——不是，一手甩狗屎、一脚甩狗屎。结果正在甩的时候，人家铁牛拿一个木棒，直接把狗蛋儿就打趴在地上了。

狗蛋儿就懵了，来了一个黑人的问号：你为什么打我呀？

铁牛说：我打你，我救你呀，你触电了呀。所以你看，我特意找了个木棒打你，我都没敢找金箍棒打你，我怕导电。

狗蛋儿很无奈：我我我哪触电啦？我是在扶着电线杆甩狗屎呢。

铁牛说：哇，那你甩狗屎那个抖腿的样子也太魔性了吧，太像触电了。

那铁牛把人打趴下了，他这个行为算不算紧急避险？**不算**。如果狗蛋儿当时真触电了，铁牛把他打趴下，那是紧急避险；但现在人家没触电，现实中人家根本没有危险，你这时候打人家，这就属于**假想避险**。

假想避险的原理跟我们前面讲的假想防卫一模一样，怎么处理呢：

- 假想避险不可能是故意为之，所以**不可能构成故意犯罪**；
- 如果有过失，**定过失犯罪**；
- 如果没有过失，就按无罪处理。

这就是起因条件。

### 时间条件：危险正在发生

时间条件跟正当防卫的时间条件也很相似。正当防卫要求不法侵害**正在进行**，紧急避险要求危险**正在发生**。

- 危险还没有发生，或者说还没那么紧迫，你这时候去避险——有可能构成**事前避险**；
- 危险已经结束、已经消除了，你这时候再去避险——属于**事后避险**。

不管是事前避险还是事后避险，都叫避险，但不紧急，不属实。

来看武松的升级版：还是老虎咬武松追咬武松，这次隔了多远呢，相距 2 公里。武松说：哇，这时候拼命跑、拼命跑。武松为了躲老虎，直接闯到人家潘金莲家。潘金莲说：你怎么又闯到我家了？

武松说：我要躲这个老虎，老虎在咬我。

潘金莲问：老虎在哪儿？

——还在 2 公里外呢。

潘金莲：哇，老虎在 2 公里外，你这哪是迫不得已啊？这危险紧迫吗？你这就不叫紧急避险了，你这叫搭讪。你喜欢我就直说嘛，你这搭讪的方式也太 low 了。

严格来说，这就叫**事前避险**，不属实。这就是第二个条件。

### 意识条件：避险认识，以及偶然避险的两派之争

意识条件讲的是认识：防卫认识、避险的认识、避险的意图——当然最重要的是**避险认识**。

怎么记？大家记住两组字数。想到正当防卫的时候，想**六个字**：制止不法侵害。想到紧急避险的时候，想**四个字**：避免危险。

而"避免危险"这四个字，既有客观要件，也有主观要件。客观要件是客观上避免了一份危险；主观要件是主观上认识到自己在避免危险，也就是避险认识。

#### 什么是偶然避险：坏心办好事

意识条件里最最重要的一个问题，就是偶然避险。前面学过偶然防卫，这里对应一个偶然避险。偶然防卫考过好几次了，偶然避险还一次没考过，相对来说还是比较重要的。

案例：狗蛋儿要追求富婆小芳，没成功，人家看不起他，狗蛋儿就生气了，要报复人家。看到人家小芳的玛莎拉蒂停在门口，狗蛋儿拿起一个石头，咣就砸人家车窗玻璃，给砸毁了，很开心地走了。

结果没曾想，第二天小芳来到狗蛋儿家登门拜访，又送鲜花，又送锦旗："砸的好，感谢你。"

原来怎么回事呢？原来小芳当时下车的时候，把她的孩子——那个婴儿——忘在车里面了。婴儿在里面都快被闷死了。大家知道，每年夏天就有时候发生这种事情，就把孩子给闷在车里面给闷死了。孩子快被闷死的时候，一个石头飞进来了，落到婴儿的怀里了，还带来了清新的空气，孩子竟然活过来了。

有的同学问：那石头有没有砸中婴儿啊？在给定条件是没砸中婴儿，砸到孩子怀里了，孩子还抱着这个石头当面包啃呢。这些你就不用管了，孩子肯定没死嘛；如果死的话，那是另外一回事了，有可能是意外事件，因为他无法预见。现在孩子不但没死，而且还被救活了。

那狗蛋这一石头算不算紧急避险？

我们先给它起个名字，叫**偶然避险**。偶然避险这个问题我们怎么学？分两个方面：第一，如何辨认偶然避险；第二，辨认好了以后如何分析判断。

怎么辨认？偶然避险的一个特点跟偶然防卫一样，就是**坏心办好事**。狗蛋这个案子里：

- 客观上有没有避免一份危险？**有**。他客观上救了小孩一命。
- 主观上有没有认识到自己在避免危险、在救人？**没有**，压根儿没认识到。

```text
                    客观上避免了一份危险      主观上认识到在避险
  紧急避险                  √                          √
  偶然避险                  √                          ×      ← 狗蛋这一石头
```

> **定义**：偶然避险，就是客观上你避免了一份危险，但主观上你没有认识到这一点，主客观相不一致。

#### 两种观点，以及一场未遂的推导

辨认完了，接下来看怎么处理。这里面有观点展示，我们逐一辨认。

**第一种观点：避险认识不要说。**

它认为成立紧急避险只看客观，只要求客观上避免了一份危险就行了，主观上不作要求——我只看客观，只看结果。

那现在偶然避险恰恰就是：客观上避免了一份危险，主观上刚好没避险认识。而这个观点认为并不要求有避险认识，所以结论是：**所有偶然避险一律成立紧急避险**，也就无罪了。狗蛋砸玛莎拉蒂的玻璃，玻璃很贵，但不构成故意毁坏财物罪，不构成犯罪。

它背后的理论根据是**结果本位主义**，也叫**结果无价值论**。大家给我回顾一下结果本位主义的核心观点：结果好，那么制造好结果的行为就是好行为。放到狗蛋这个案子里，他坏心办好事，他办了好事，救了人一命；既然是好结果，制造好结果的行为肯定就是好行为。你看人家车主都说"砸的好"，那这还能有罪吗？不能有罪啊，得奖励人家这个好行为。怎么奖励？说你是紧急避险，你不构成犯罪。

**第二种观点：避险认识必要说。**

从名字我们就知道了：成立紧急避险，客观要件、主观要件都得打勾才行。既要求客观上避免这份危险，也要求主观上你认识到你在避免危险，有避险认识。而偶然避险恰恰是客观打勾、主观打叉，这时候能给你成立紧急避险吗？不能。所以它的结论是：**偶然避险一律不成立紧急避险**。

它背后的理论根据是**行为本位主义**，也叫**行为无价值论**，就是行为导向。行为导向的核心观点是：行为的好坏和结果的好坏要**独立评价**，双方独立算账。你不能因为结果好，就说制造好结果的行为就是好行为——这太功利了。狗蛋这个行为本身就是坏行为，你想毁坏人家财物，也确实实施了毁坏财物的行为，真的是坏心办好事，坏行为办好事，它仍然是坏行为。我不能因为你办了好事，我就说你的行为是好行为，我不能说你的心就是好心。所以你不能成立紧急避险。

| | 避险认识不要说 | 避险认识必要说 |
| --- | --- | --- |
| 理论根据 | 结果本位主义（结果无价值论） | 行为本位主义（行为无价值论） |
| 前提要求 | 只看客观上避免了一份危险 | 客观、主观都打勾 |
| 对偶然避险的结论 | 一律成立紧急避险，无罪 | 一律不成立紧急避险，转入定罪 |

两派说完了，结论是不能成立紧急避险，那就得给狗蛋定罪了。他涉嫌的罪名是什么？就是**故意毁坏财物罪**。

按避险认识必要说、行为本位主义，行为的好坏和结果的好坏独立评价：狗蛋的行为是大大的坏，他带着毁坏财物的目的砸人家的车，那这行为是坏行为。所以故意毁坏财物罪成立。

那是否构成**既遂**呢？这里有个难点，要把前面的知识点调动起来。我们先说结论：定的是故意毁坏财物罪的**未遂**，不是既遂。

> **易错点**：玛莎拉蒂的玻璃绝对值 5000 元，达到 5000 元按司法解释就构成故意毁坏财物罪了——那为什么还定未遂？光看数额标准会掉进这个坑。

关键在于，故意杀人罪、故意毁坏财物罪的既遂结果，其实有**两个层次的评价**：一个是**事实判断**，还有一个是**价值评价**。

- 事实判断上，你的确要有一个毁坏的结果，要有毁坏的结果；
- 价值评价上，这个结果还必须是个**坏结果**，才能算是个既遂结果——因为既遂结果是要加重处罚的嘛。

很多人认为，只要是毁坏结果，那肯定是坏结果。不一定。有些紧急避险制造的毁坏结果，的确是好结果。既遂结果它必须是个坏结果。

看狗蛋这个案子：事实判断上，狗蛋的确制造了一个毁坏结果，他确实把人车窗玻璃砸坏了；但价值评价上一衡量，车主自己都觉得"你砸那几片玻璃算啥呀，救了我孩子的命呢"，一比较，绝对是好结果。既然是好结果、不是坏结果，那这时候能定既遂结果吗？不能。

排除法就走通了：

```text
狗蛋砸车窗玻璃
      │
      ├── 故意毁坏财物罪成立？── 成立（带着毁坏财物的目的实施了毁坏行为）
      │
      ├── 既遂？
      │     事实判断：有毁坏结果        ── √
      │     价值评价：结果是"坏结果"吗？── × （车主说"砸得好"）
      │     → 不是既遂结果
      │
      ├── 中止？── 要有自动放弃 ── 没有
      │
      └── 未遂 ✓    ← 排除法只剩这一条
```

所以最后定的就是**故意毁坏财物罪的未遂**。

> **结论**：这两种观点在这里是平分秋色，没有哪个观点说自己是多数说。所以考试也不考唯一定论，不考唯一正确答案，只考**观点展示**，只考**逻辑推导过程**。你只需要掌握它的前提、结论，以及逻辑推导的原理过程，就够了。别在这儿较真，赞成哪一种无所谓。真考出"你的观点是什么"，你就大大方方亮明自己的底牌，再说一下你的理由。

这就是意识条件最重要的内容——偶然避险。跟前面讲过的假想防卫、偶然防卫里的"房屋认识不要说"，原理是一模一样的，我们在这里只是再回顾应用一下。

### 不得已条件：迫不得已，也叫补充性条件

不得已条件指的是什么呢？大多数的紧急避险，你都是要攻击无辜的第三人的。比如狗蛋儿要闯到人家小芳家；野狗咬你，你被迫闯进小芳家；歹徒砍你，你被迫闯进小芳家。都是必须满足一个条件：迫不得已，情况很紧急，迫不得已——也就意味着，这只能是你**最后的手段**。

所以不得已条件也称为**补充性条件**。

#### 什么才真叫迫不得已

《疯狂的石头》，也是黄渤的成名作，结尾那一段：黄渤在下水道里饿了三天，终于爬出来，这时候太饿了，就抢了人家面包店的一个法棍面包，抱着就跑；人家店主骑一个电瓶车就追黄渤，拼命追，就为这一个面包，一直追到高架桥上，电影在那儿就结束了。

那黄渤这个算不算紧急避险？有的说算——为了救命啊，都快饿死了，啃你一块面包。但我们认为不应当算。**为什么**？你还特能跑呀，你都从那个店面跑到高架桥上去了，你有那个力气，那你打个工挣个钱不行吗？在这种情况下，你不属于迫不得已，所以不满足紧急避险的条件。

#### 受强制的紧急避险

不得已条件里面，容易给你考的一个概念叫**受强制的紧急避险**。

有这么一个案件：某地有一帮歹徒，好几个人，想敲诈勒索当地的一个富翁，这个富翁名字就叫铁牛。他们把铁牛劫持到一个黑屋子里面，然后又在马路上劫持了一个女孩，塞到黑屋子里面，摄像头架起来，要求铁牛把这个女孩给强奸了，然后拍下这个视频，以后就成为把柄，就可以问你要钱了。

然后他就说：如果你不强奸这个女孩，你们两个人都得死。

新闻报道里说，人家这个富翁说"我不干"；新闻报道里面描述说，这群歹徒把铁牛抬着、按着实施了强奸。

但我就觉得这个描述有点怪怪的。**如果真的是抬着、按着实施强奸的话，那铁牛的行为都不是刑法上的行为**——那完全是不自主的，自己完全无法控制。连刑法上的行为都不算的话，那肯定不构成强奸罪。

那假如当时没有抬着按着，就是被迫："你不实施，我就把你们两个都杀了。"那铁牛被迫实施了强奸，这时候给铁牛要不要定强奸罪？我们的结论是：**不定强奸罪**。辩护理由叫**紧急避险**，属于受强制的紧急避险——因为受到强迫、被迫，迫不得已。

不过这里面引出了另外一个问题，就是紧急避险的**限度条件**，这就是接下来要讲的。

### 限度条件：法益之间能不能画等号

紧急避险必须是：**为了保护较大的法益，迫不得已损害较小的法益**。

#### 法益位阶：一路排下来的高低

我们一般会认为，生命法益是最高位阶的；生命法益应当大于身体健康法益；身体健康法益应当大于自由方面的法益，比如性自由、人身自由；自由方面的法益应当大于财产法益。财产法益的地位是比较低的。

```text
   生命法益        最高位阶
        │
   身体健康法益
        │
   自由方面法益    （性自由、人身自由）
        │
   财产法益        地位最低
```

回到铁牛那个案子：他是**为了保护两条人命**，迫不得已侵犯了这个女孩的性自由。在法益衡量上，这还是保护较大的法益、损害较小的法益，可以成立紧急避险。

但这里面只能说是多数说，争议其实都很大。少数说认为不成立紧急避险，你就构成强奸罪，不过最多在量刑上可以从宽一下。有这种少数说的。这里面绝对不可能有唯一正确答案。

> **提示**：法益衡量这一块考出来也喜欢考。凡是多数说、少数说并存、争议很大而没有唯一答案的题，你只要把两说的前提和结论都写清楚，就是满分。

#### 一条船往下沉：等号能划到哪一步

狗蛋和小芳两个人一起做生意，共同租用了一条商船，各自放各自的一吨货物，而且货物的价值都一样。在海上漂，结果遇到了海难，船快要沉了。

这时候狗蛋为了保护自己那一吨货物，强行把小芳那一吨货全部给推到海里去了。狗蛋这时候构不构成故意毁坏财物罪呢？我们认为**不构成**，构成什么？**紧急避险**。为什么呢？在财产法益这一块，我们是大于或等于，**画等号也可以**。就是为了保护自己一吨的货物，迫不得已把人家一吨货物扔下去，这也算紧急避险。

但这里的意思只是说，这时候你可以不构成故意毁坏财物罪；但在民事上你肯定是要给他赔偿的，这个大家都知道。

**那问题来了。** 如果这个船还继续往下沉。狗蛋说：小芳啊，你看这船还是要往下沉呀，我为了救我一吨货物，看来我得把你也扔下去，因为你也挺重的，这个船都载不动了，这得把你也扔下去。

这时候如果真把人小芳强行扔下去了，你说这能成立紧急避险吗？**肯定不能成立**。因为你一吨货物再值钱，小芳的生命法益是大于你这个财产法益的。小芳肯定说：你难道都没听过柏浪涛的刑法吗？生命法益是最高的，你怎么能把我扔下去？

狗蛋说：行吧行吧，那我就把我的货物扔下去吧。狗蛋把自己的一吨货物又扔下去了。扔下去以后，船上就剩下他们两个人了，现在船还是要往下沉。这时候比如说两个人合抱一个木板，只能扶住一个人了。狗蛋果断说：小芳，你看到这个时候，我终于可以把你扔下去了吧？

如果是这种情况，这就是我们著名的**海上木板案**。

小芳肯定会问：你凭什么我下去？

狗蛋说：那凭什么我下去？

小芳说：那你应当学习人家泰坦尼克号啊。

狗蛋说：你又不是 Rose，我学他干嘛。

狗蛋把人家小芳给打下去了。狗蛋这时候是构成故意杀人罪呢，还是成立紧急避险呢？我们的结论是：**不构成紧急避险，还是要构成故意杀人罪**。因为你为了救自己的一条命，牺牲人家的一条命，生命法益**划等号是不行的，不能划等号**。按照多数说认为是构成故意杀人罪的；这里面也有少数人认为能构成紧急避险，但多数说认为构成故意杀人罪；不过在量刑上可以考虑酌定给你从宽一下。

#### 多数人的命换少数人的命：原则上不行，例外在 911

接下来还有一个问题：在生命法益这一块，可不可以画**大于号**？也就是说我为了保护多数人的命，牺牲一个人的命或者少数人的命，这样可不可以呢？我们认为**原则上是不可以的**，因为人的生命不能作为手段。

但是呢，有例外的。有的例外的观点认为可以。典型的例子就是 911 那种事件：以后如果再发生 911 这种事件，空军被迫用导弹在空中把它击落。因为你如果不击落的话，这时候它撞向地面大楼，又死几千个人。也就是说，这时候你飞机上乘客那 200 人的生命注定是被牺牲了，横竖都是个死：要么就是我们在空中把你们击落，你们死了，那这时候还能避免地面大楼里面 2000 人的死亡；要么就是干看着让你撞向地面大楼，那这时候你们飞机上两百人也死了，地面 2000 人也死了，那何必呢。

所以这时候可以击落。但这种观点其实也是有争议的：我们法考认为这时候可以紧急避险，但是还是有少数说认为是不可以的——任何时候人的生命都不能作为你的手段，人的生命本身就是目的。

> **提示**：画等号的尺度把握住一句话——**财产对财产可以等，财产对生命不行，生命对生命也不行；唯独"多数命换少数命"属于例外中的例外，原则上不允许，911 式绝境才被认可。**

---

这就是限度条件。限度条件讲完，紧急避险这一块我们就讲完了。

我们可以发现，紧急避险的成立条件和正当防卫还是挺像的，有相同的地方，但是也有一些不同的地方。这个大家下去可以好好自己再总结总结。我们就讲到这。

> **承前启后**：上一节讲完「紧急避险：五道关口，最难的是主观与限度」，下一节接着讲「被害人承诺：哪些事你点了头，刑法就不管了」。

## 被害人承诺：哪些事你点了头，刑法就不管了
> 对应块：BLK18 | 覆盖分集：P20 | 块标题（分集名）：《第07讲 第03节：被害人承诺》

被害人承诺这块，分成两半：一半叫**现实的被害人承诺**，一半叫**推定的被害人承诺**。现实的那一半是内容最多的，也是这一节真正要啃的；推定的那一半特别好理解，留到最后再讲。

我们先从最核心的问题开始：被害人承诺的**权限和范围**——究竟哪些法益，你可以自己点头说一声“我不要了”。

### 你能放弃的法益，从财产一直排到生命

先看整个谱系。一句话的骨架是：**财产能放弃，名誉能放弃，人身自由能放弃；身体上轻伤能放弃，重伤不能；生命怎么也不能放弃。**

| 你想放弃的法益 | 承诺是否有效 | 依据 |
| --- | --- | --- |
| 财产 | 有效 | 车主自己点头，刑法不再保护这辆车 |
| 名誉 | 有效 | 被害人自己请求，侮辱之类的罪名不成立 |
| 人身自由 | 有效 | 被关者自己要求被关，非法拘禁不成立 |
| 身体健康（轻伤） | 有效 | 伤情在轻伤以内，承诺有效 |
| 身体健康（重伤） | 无效 | 超过国家保护底线，承诺无效 |
| 生命 | 无效 | 生命法益不允许放弃 |

下面一个一个说。

#### 财产：砸我的玛莎拉蒂，砸吧

最简单的例子，考试也考过。

小芳跟狗蛋儿说：狗蛋儿啊，我那个玛莎拉蒂我看着不顺眼，求你办个事儿，把它给我砸了。狗蛋儿一听：哎呦，太好了，我手痒痒了，我正想砸呢。那就给砸了。

那你说，有车主的承诺，狗蛋儿还构成故意毁坏财物罪吗？不构成。因为车主自己都承诺了、都放弃这个法益了，那我们刑法还保护吗？不保护了。刑法都不保护了，就没有犯罪的空间。

> **结论**：财产是可以承诺放弃的。原理就一句——被害人自己放弃了法益保护，刑法就没有再介入的必要。

#### 名誉：来，我们互相虐待

那名誉能不能承诺放弃？也能。

狗蛋儿跟小芳说：小芳，我是个受虐狂，你来虐待我吧。小芳说：太好了，我刚好也是个虐待狂啊，我就想虐待。两个人简直是天生一对，然后互相虐待，相爱相杀。

那你说这时候虐待的一方能构成犯罪吗？什么侮辱罪啊，不构成。

> **结论**：名誉也可以承诺放弃。

#### 人身自由：闭关十天，谁也别来烦我

这个例子是我自己的。

我考了法考，考了三年都没考过，后来遇到了柏浪涛，我才找到真正的原因——我整天光听课不看书。这是不行的，本来都说一定要看书，一定要看书，都说“公主请看书”嘛。我自认为是公主，我要看书。

那为了看得专心一点呢，我要闭关修炼。你把我关到一个山洞里面，你把我关起来，我专心看书。狗蛋儿问：那关多长时间呢？我说：估计看这个书啊得花十天，那你就把我关十天吧。狗蛋儿说好，那就关起来了，关十天。

那现在问题来了：你承诺放弃了人身自由，人家狗蛋儿还构不构成非法拘禁罪？不构成。我们认为不构成，考试也考过。

> **结论**：人身自由可以承诺放弃。

#### 身体健康：轻伤算数，重伤不算

身体健康这块，结论很干脆：

> **结论**：轻伤，承诺放弃是有效的；重伤，承诺放弃是无效的。

大家看《上海滩》里那个情节。许文强跟丁力说：人家老大要杀我，你来杀我。这样吧，你砍我一个手指头，小手指，给人家一个交代吧。丁力说行，咔就砍了，砍了个小手指。

这是轻伤。因为有承诺，这时候丁力就不构成故意伤害罪。

但大家要注意，如果是重伤，承诺放弃就是无效的。还是许文强跟丁力说：你把我胳膊都砍了，给他一个交代，让他高兴一点，让他烤个肉吃。丁力说好，一刀把人家胳膊都砍了，扛着胳膊走了。

那你说这个丁力构不构成故意伤害罪？重伤啊，那是要构成的。

> **易错点**：轻伤和重伤是这条线上最关键的分水岭。别看到“人家同意了”就直接放人，先把伤情等级问清楚。

#### 生命：杨志的宝刀，刀口不沾血也救不了他

到了生命这里，答案就只剩一个字了：无效。

《水浒传》里那个杨志卖刀，广告上打的是什么？他说我这个刀的特点是“杀人不沾血”。结果来了个无赖牛二，牛二认为你吹牛皮，说我就不相信：你要不把我杀了，你要不然就从我这个裤裆里面钻过去。你要不然做这两件事，你我就不相信。

杨志说：你滚蛋，别影响我卖刀。你要说不行，你必须在我这儿，要么把我杀了，要么从我裤裆钻过去。

杨志心想：我可不是韩信呀，我不能受胯下之辱。你说好的让我杀你是吧？好，咔，手起刀落，把牛二的头就给砍了。众人上前一看，刀口还真的不沾一滴血。杨志说：你看啊，这个活广告，我继续卖刀啊，这一下我价格要卖得高一点。

结果旁边一个人就悄悄跟杨志说：好家伙，你是不是没听过柏浪涛的课呀？人家放弃生命是无效的，你赶紧跑，你已经构成故意杀人罪了，再不跑官府就来抓人啦。杨志就赶紧跑了。

放到今天，杨志这个肯定是要构成故意杀人罪的。人家让你杀，你就杀，是这个意思。

顺便提醒大家注意安全。前不久好像有个视频，两个男的在街头不知因为什么吵起来了，一方手里拎着水果刀，还说“有本事你就杀了我”。我滴妈呀，你把他激到那个程度，他搞不好真就把你给砍了——那他当然是有罪了，你也没命了。最好能不要有这种冲突。

> **结论**：生命法益不允许承诺放弃。这条线到此为止。

---

以上讲的就是**承诺的范围和权限**。范围讲完了，接下来还有几个条件要看：时间、能力、意思表示是否真实。

### 承诺的时间：只能是事前，事后补不回来

关于时间，我们只有一个要求：**承诺必须在事前作出才有效，事后作出已经于事无补。**

这个要求本身不难，难的是一个航班上的案件。

我问大家一个案子：发生在美国的一个航班上。后排有个乘客甲，看到前排有个男乘客，趁人家旁边的女乘客睡着了偷摸。后排这个乘客甲就敲这个女乘客的椅背，意思是提醒你赶紧醒啦，你被人占便宜了。结果怎么敲都敲不醒。

有同学跟我说：老师啊，后排这个乘客他就不懂得一句话——装睡的人是永远也叫不醒的。

那又有同学问我：老师，假如这个女乘客她是装睡呢，那这个偷摸者怎么处理怎么处理呀？

这个问题回答起来稍微有点难，但还不能不回答，因为里面蕴含的知识点还挺重要的。我们分两种情况。

#### 第一种：她从一开始就愿意装睡

在男乘客偷摸之前，女乘客内心就愿意假装入睡。

那这时候男乘客偷摸，构不构成强制猥亵罪？不构成。答案就是不构成。

> **易错点**：这里有个考点——**被害人有承诺，不要求行为人意识到**。被害人内心有承诺就行，不要求行为人认识到这个承诺的存在。

至于“你怎么证明她是装睡的”——那是证据法的问题。咱们给定条件就是这样，不用分析。

#### 第二种：她是真睡着，摸醒之后才改主意

第二种情况是：女乘客事前没有承诺，人家是真的睡着了。男乘客偷摸，摸啊摸，把人给摸醒了。女乘客瞄了一眼：嗯，还颜值不错。然后继续装睡。那男乘客不知道她还在那儿摸。

这种情况要注意了，要把它分为两个阶段。

**第一阶段**：女乘客事前没承诺，真睡着了，你去摸她——这绝对是强制猥亵了。

**第二个阶段**：她醒了以后愿意装睡，这时候男乘客接着摸——这时候不构成强制猥亵罪了，因为这时候被害人有承诺。前面又说过了，被害人有承诺，不要求行为人意识到。

把这个掌握好就可以了。

> **结论**：承诺的时间条件只有一条——事前。事后再补，救不回来；但一旦被害人在行为进行当中产生了承诺，从那一刻起，后面的部分就不再是犯罪。

### 承诺的能力：洗成巨婴，就点不了这个头

承诺要有效，被害人对**他承诺的事项要有理解能力**。

所以我们知道：婴幼儿做出的承诺是无效的；精神病患者做出的承诺是无效的；严重智障的人做出的承诺也是无效的。

说到这儿我给大家举一个现实的例子。包括美国那些邪教组织，包括大家看过的电影《周处除三害》——那里面就有一些邪教组织。

那邪教组织里那些头目，他长期给那些女弟子洗脑，洗成什么呢？把女弟子洗成一个巨婴。变成巨婴之后，这个头目有时候引诱人家、诱奸人家，让人家做承诺。

那这些承诺有效无效呢？别说我看到那个邪教头目还给人家说什么呢，材料里面写他看了小说《十日谈》，他受到这个启发以后，就对那些已经被洗成巨婴的女弟子说：你的下面有个地狱，我的下面有个魔鬼，让我们一起把魔鬼赶到地狱去。就这样骗人家。

那这种情况下我们认为：这些女弟子已经不是正常人了，已经被洗脑了，像个巨婴，像个严重的智障，这时候已经没有承诺能力了。她们做出的承诺是无效的。那这个邪教头目是要构成强奸罪的，明白吗？要构成强奸罪的。

> **注意**：这里面有个条件必须说清楚——是这些女弟子都已经被洗脑了、变成巨婴、变成智障了，已经没有正确的理解能力了，承诺才无效。不要脱离这个前提去套。

### 意思表示必须真实：尹志平和那位女模特

接下来是第四个条件：承诺必须是**真实的意思表示**。这个我们民法上也讲，意思表示要真实。也就是说，如果是受欺骗、受胁迫——民法上叫受欺诈——那这时候做出的意思表示就是不真实的，不真实的意思表示就是无效的。

考试考得最多的是受欺骗，也叫受欺诈。这一块的判断怎么判断呢？我们先掌握两个标准案例，以后去套用就可以了。

#### 事实认识错误：尹志平冒充杨过

《神雕侠侣》里那个尹志平，后来叫甄志丙。他欺骗人家小龙女，冒充杨过。然后小龙女以为是杨过，是她心爱的欧阳锋——她以为是自己的心上人，然后就同意了，发生了性行为。

你们先把这个情况放在这儿。

#### 动机认识错误：评委拿一等奖换上床

第二个情况：有一个选美比赛，在颁奖典礼上，有一个女模特，她以为他能获奖。结果什么奖都没获到，他气得在主席台上当场就把高跟鞋一脱，砸向前排的一个评委，边砸还边说：昨天晚上咱们不是说好的吗，你这老家伙骗我。

我们知道这肯定之前有什么交易了。那时候的交易就是骗人家说：只要陪我上床，明天你就是一等奖。

那我们现在想一想，这个案件和尹志平这个案件都有欺骗人家妇女，这里面有没有区别？大家给我想一想。

**有区别。** 区别在哪呢？

在尹志平这个案件里面，他欺骗了小龙女，小龙女产生了**事实认识错误**。这个事实是什么？就是对方的身份，就是对方是谁。她对事实产生了错误：我以为对方是心爱的欧阳锋，实际上对方是个禽兽。

最后结论：我这种受骗而作出的承诺是无效的。无效的话，这个尹志平就要构成强奸罪。

再看女模特这个案件。评委骗了女模特，女模特也受骗了。但是女模特对事实有没有认错啊？她知不知道眼前这个男人是谁啊？她知道。她知不知道跟人家发生什么事儿啊？她也知道。所以她对事实是没有认错的。她做出的承诺是有效的。这个评委就没法给她定强奸罪。

这就叫权色交易。权色交易为什么定不了强奸罪？就是因为这个交易的一方，她对事实没有这种错误。

有同学说：那我总觉得他还是上当受骗的啊。他的确上当受骗了。他上当受骗是什么呢？是他知道在干什么事，但他干这个事儿背后是有个动机的，这个动机就是什么？想上位呀，想获奖呀。他其实动机没有实现，动机被骗了——这叫**动机错误**。只要不是事实错误，只是动机错误，就不影响承诺的有效性。所以这时候评委不构成强奸罪。

> **易错点**：在这里千万不要用道德标准。有的同学做题的时候，是用一种道德标准提炼出了判断标准：根据道德去评价。他认为评委不构成强奸罪，理由是那个女模特儿想靠这种手段获奖，她动机很卑劣、道德上品行很差，所以活该。但你这样一说，反方意见就来了：那这评委道德也很低劣呀，品行也很差呀，所以得给他定罪吧？所以我们就会发现，在里面千万不要用道德标准。
>
> 我们一定要记住一句话：**法律的归法律，道德的归道德；我们是刑事法庭，不是道德法庭。** 我们就用刚才那个标准——到底是事实认识错误，还是没有认识错误的动机错误。

#### 套一次模型：有人冒充丈夫爬上了床

我们抓紧训练一个。

有一天清晨，一个丈夫回家，他想去亲热他熟睡的妻子。结果妻子揉着没睡醒的眼睛，就骂了一句：你给我滚犊子吧，你昨天晚上折腾了我一宿，现在又来折腾我。

丈夫一听：我昨天晚上在外面上夜班呀，我刚回来啊，那人是谁啊？

妻子一听，一下子就给吓醒过来了，说：那是谁啊？

哦，原来有个歹徒竟然冒充人家丈夫，爬到人家床上。结果妻子假如给定条件是——妻子真把他错当成丈夫了，冒充丈夫真错当成丈夫了——那这时候发生性行为。

我问大家：你给我套公式套模型吧。那你说这个案件他属于尹志平那个案件，还是属于女模特这个案件啊？

那你就应当属于什么？应当属于尹志平这个案件。也就是说，妻子对事实是有认识错误的。那这时候那个歹徒要构成什么？构成强奸罪。因为人家对事实有认识错误的话，人家的承诺就是无效的——人家都以为对方是自己的丈夫呢，是不是。

好，上面这几个案例我们整理完了。但你会发现，它们都有一个共同特点：**行为人主动欺骗了被害人**。接下来是第二种情况，考试也考。

### 被害人自己想错了，行为人还顺手推了一把

第二种情况是：行为人没有主动欺骗被害人，是被害人自己产生了一个认识错误，然后行为人加以利用。

这一块有点复杂，所以我得给大家切换到书上 74 页的那个图表。我们一起来看一下。

```text
被害人作出承诺
│
├─ 事实认识错误（对"对方是谁、发生了什么"有错误认识）
│    └─ 行为人主动欺骗 → 被害人受骗作出承诺
│         → 承诺无效          典型：尹志平冒充杨过
│
├─ 动机认识错误（对事实无错误认识，只是动机没实现）
│    └─ 行为人主动欺骗 → 被害人受骗作出承诺
│         → 承诺有效          典型：评委拿一等奖换上床
│
└─ 被害人自行产生认识错误，行为人加以利用
     ├─ 行为人不知情
     │    → 承诺有效          典型：短信把"不行"写成了"行"
     │
     └─ 行为人知情，并以作为或不作为的欺骗
          促使或强化被害人的承诺
          → 承诺无效          典型：兽医隐瞒新药，打了安乐针
```

整张图的前两格我们上面已经走过了，剩下这两格是今天要啃的。

#### 行为人不知情：短信里那个“行”

第一种情况：行为人甲不知道被害人有这种认识错误。结论是——被害人的承诺有效。

标准案例：甲给邻居乙发短信说：你现在也不在家啊，你在外地打工，是这样的，我家的房子要装修一下，你家院子后院那棵树挡住了，你看能不能同意我把你家那个树给砍了啊。你按个数我也知道那树是挺珍贵的，所以我不能随便砍，所以我要征求一下你的意见。

这个乙呢，发过来一个“行”。

其实乙是想写“行不行”，但是他忙吧，少写了个“步”字，就写成了“行”。甲收到这个短信一看：行哦。那他就认为邻居乙同意了。他就直接把人家珍贵的树给砍了。

现在问怎么办？我们知道，乙写的是“行”不假，但甲并不知道乙此时有个认识错误，乙其实想说“不行”。由于甲不知道你有认识错误，那这时候的结论就是：乙的承诺是有效的，甲不构成故意毁坏财物罪。

当然我们这是作定性式分析——那棵树如果真要论故意毁坏财物，它得价值 5000 块钱呢，是吧。

#### 行为人知情：兽医隐瞒新药，打了安乐针

第二种情况：甲知道乙有认识错误。

考试也考过这么一个题。有一个乙，他自己养了一匹马，这匹马是很珍贵的，他也是爱马人士——爱马仕的人。但这匹马有一天生病了，他感觉它快要死掉了，好像得了一种绝症，觉得已经不行了。他干脆就找一个兽医甲，说：我这匹爱马快要死掉了，我不想让它痛苦了，你能不能给它打一个安乐针，让它安乐死？你给我检查一下。

结果兽医甲一检查发现，这匹马得的这个病还有救啊，不是得了绝症，有一种新药是能救这个马的。但是呢，这个医生甲他故意不说，故意隐瞒这个真相。他说：哦，你这马你认为没救了是吧？那就没救了，你让我打这个安乐死针是吧？行吧，那我就打吧。那他就给打了。那这匹马真的就被打死了。

那现在问：这个兽医甲构不构成故意毁坏财物罪？因为人家那个马还是很珍贵的。

有同学可能会问：哎，你这个兽医甲怎么知道这个马得的不是绝症啊？你这些怎么去证明？不要分析这些，这都是证据法的问题，我们实体法就根据给定条件来分析。

我们看这个图表，这个题的特点是什么呢？就是马的主人乙他是**有认识错误的**——他以为这个马没救了，实际上是有救的。他基于这个认识错误，做出了这个承诺：说你把我马给我注射死吧。

但兽医甲，他是知道这个马的主人是有认识错误的。那这时候怎么办？我们看结论：如果甲实施了欺骗行为——这个欺骗行为既包括作为，也包括不作为——让被害人已经做出承诺，或者强化了承诺，那人家的承诺是无效的。

那我们现在来看这个兽医甲，他有没有一个不作为的欺骗呀？我们认为有的。

当然我们说不作为的欺骗其实要有个前提，就是要有作为义务。这个作为义务是什么？就是告知真相的义务。那你说，你身为一名兽医，你有没有告知真相的义务？当然有，这是基于你的职务、业务而产生的作为义务。那你有告知的义务，你不告知，这个不作为本身就是一种欺骗，就是欺骗的行为，不作为的欺骗。

那你是基于这种欺骗行为，实际上是**强化了**马的主人乙的承诺，强化了那个基于认识错误的承诺。那这时候由于有欺骗行为在里面了，人家这个承诺就是无效的。承诺无效的话，你这个兽医甲就要构成故意毁坏财物罪了。马很珍贵，那是可以构成故意毁坏财物罪的。

所以大家按照这个图表把这一块要掌握好，因为这一块稍微有点复杂，一定要看我们手上这个图表。

### 推定的被害人承诺：老王砸门救火

刚才讲的都是现实的被害人承诺。接下来讲推定的被害人承诺。

什么叫推定的被害人承诺呢？看最简单的案件。

小芳不在家，她出门的时候忘了关水龙头，水在那儿哗哗哗地流啊，再流下去那就成了水漫金山了。

小芳有个邻居老王。老王一直爱慕人家小芳，整天就关心小芳的一举一动。他发现小芳家那水在那哗哗哗流呢。他这时候给小芳打电话——小芳一看是老王的电话，人家就不接啊。这一下把老王整得没办法了，热锅上的蚂蚁，这咋办？只能强行破门而入，把门砸了，破门而入，然后进去把那个水给关了。

那这砸门破门之后，也造成了人家重大财产损失。那这是不构成故意毁坏财物罪呢？我们认为是不构成。

> **结论**：老王不构成故意毁坏财物罪。

那不构成的理由是啥呢？用什么理由把他这个行为的违法性给走却掉、排除掉呢？

有人说：那你这个有被害人承诺啊。但问题是人家小芳没有现实的被害人承诺呀——人家不在家，也没打电话说过“你砸吧”。

所以我们在这里面引入一个概念，叫**推定的被害人承诺**，这是比较特殊的。也就是说，刑法能够推定你这个主人是有承诺的，因为这是为你好嘛，是吧。这在民法上其实都类似于无因管理。

所以呢，这时候你不能给人家隔壁老王定罪啊，你这定罪真的是寒人家的心呐。所以这时候他就不构成故意毁坏财物罪。

好，推定的被害人承诺讲完，整个被害人承诺我们就讲完了。

### 违法阻却事由的三分天下

最后我们小结一下。被害人承诺这一块，大家会发现，最难的是现实的被害人承诺里面那个**受欺骗做出的承诺是否有效**。那块儿又重要又难。记住那个图表：如果对事实有认识错误，承诺无效；如果仅仅是动机错误，承诺有效。

我们把这个讲完以后，整个这一讲违法阻却事由就讲完了。最后给大家总结一下：违法阻却事由主要是三个，这三个的重要性、分值是不一样的——

> **结论**：大哥是正当防卫，二哥是紧急避险，三哥是被害人承诺。基本上是这么一个分布。

> **提示**：这一节里点到的考法（财产、人身自由、强制猥亵、强奸、故意毁坏财物）讲师都提到“考试考过”，但课上并没有展开具体题干，题目部分不做补充，回顾时按上面的标准去套即可。

### 客观阶层到底怎么走完的

我们把这个讲完以后，整个客观阶层也就讲完了。再回顾一下，客观阶层前后是两个板块。

前面这个板块叫**客观要件**，如果全部打勾，初步来说你的行为就具有违法性；那进入后面这个板块，如果有一些违法阻却事由，违法性就走却掉；如果没有违法阻却事由，那最终就得出一个结论——在客观阶层，你制造了法益侵害性，你的行为具有违法性。

```text
客观要件全部打勾
      ↓
行为具有法益侵害性 ＋ 行为具有违法性
      ↓
是否存在违法阻却事由？
（大哥 正当防卫 ／ 二哥 紧急避险 ／ 三哥 被害人承诺）
      ↓
 ┌────────────┴────────────┐
是                          否
 ↓                           ↓
违法性走却掉          带着法益侵害性与违法性
 ↓                     进入主观责任阶层
                              ↓
                   看你能不能谴责你：可谴责性
                              ↓
                     可谴责 → 承担刑事责任
```

一句话：客观阶层负责把“事实是什么”查清楚，主观责任阶层负责把“该不该罚这个人”定下来。被害人承诺不管出现在哪一步，它的作用都只有一个——在你已经把事实查清楚之后，替你把违法性这一栏划掉。
