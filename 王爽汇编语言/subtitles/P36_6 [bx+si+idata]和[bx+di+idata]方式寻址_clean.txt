# 汇编语言：[bx+si+idata] 寻址方式与内存访问详解

---

### [00:00] 寻址方式介绍与地址计算原理

在这节课中，我们介绍一种寻址方式。这种寻址方式需要用到基址和变址两个寄存器，另外还要再加上一个立即数。我们可以看一下通过这种方式指定地址的具体含义。

对这种寻址方式而言，它同样表示一个内存单元。从示意图中可以看到：这是整个段的一个起始地址，在加上 $\text{BX}$ 之后，通过 $\text{BX}$ 发生了一定的偏移；而在当前这种方式中，还要加上 $\text{SI}$ 和 $\text{idata}$。在加上 $\text{SI}$ 之后，代表的偏移空间为：

$$\text{EA} = (\text{BX}) + (\text{SI})$$

若再加上一个常数/立即数 $\text{idata}$，此时对应的就是目标内存单元。

因此，这种方式表示几个寄存器包含一个立即数在偏移地址方面的叠加。用这种方式表示内存单元时，它表示的就是：$\text{BX}$ 中的数值加上 $\text{SI}$ 当中的数值，再加上 $\text{idata}$，共同代表整个有效偏移量（$\text{EA}$）。

---

### [01:07] 字单元读取与数学描述

当我们把这样一个单元的值传输到 $\text{AX}$ 时，其含义就非常明确了：

```assembly
mov ax, [bx+si+idata]
```

这条指令将一个内存单元的值送入 $\text{AX}$。由于目的操作数是 16 位寄存器 $\text{AX}$，因此此处读取的是一个字（Word），而不是一个字节（Byte）。其偏移地址是 $\text{BX}$、$\text{SI}$ 以及 $\text{idata}$ 三者叠加的结果，而段地址则默认在段寄存器 $\text{DS}$ 中。这种寻址方式更加灵活，虽然比前面所讲的方式稍显复杂，但具有其独特的用途。

把该内存单元的访问用数学形式描述如下：

$$(\text{AX}) = ((\text{DS}) \times 16 + (\text{BX}) + (\text{SI}) + \text{idata})$$

括号内部为物理地址的计算公式，外层括号表示取出该物理地址处存放的内容，并送入 $\text{AX}$ 寄存器中。

### [01:56] 多种灵活的指令书写格式

在汇编语言中，地址组合的书写语法具有很高的灵活性，支持多种等效写法：

```assembly
mov ax, [bx+200+si]
mov ax, [bx+si+200]
mov ax, 200[bx][si]
mov ax, [bx].200[si]
mov ax, [bx][si].200
```

1. 可以将常数与变址寄存器 $\text{SI}$ 交换位置（加法满足交换律）。
2. 可以把常数提到括号外面，写成 `200[bx][si]` 的形式。
3. 可以把常数写在寄存器之间或后面并使用点号分隔，例如 `[bx].200[si]` 或 `[bx][si].200`。
4. 另外，也可以写作 `[bx][si]`，这在之前也使用过，相当于偏移量常数 $\text{idata} = 0$ 的特殊情况。

### [02:41] 示例代码分析与内存寻址推导

接下来通过一个具体的示例来分析这种寻址方式的执行过程。

假设当前内存中已存在如下数据：段地址为 `2000H`，偏移基地址为 `1000H`。执行以下程序段：

```assembly
mov ax, 2000H
mov ds, ax
mov bx, 1000H
mov si, 0
mov ax, [bx+2+si]
inc si
mov cx, [bx+2+si]
inc si
mov di, si
mov ax, [bx+2+di]
```

执行过程逐步分析如下：

1. **段地址与基地址初始化**：
   * `mov ax, 2000H` 使得 $(\text{AX}) = 2000\text{H}$；
   * `mov ds, ax` 设置数据段地址 $(\text{DS}) = 2000\text{H}$；
   * `mov bx, 1000H` 设置偏移基地址 $(\text{BX}) = 1000\text{H}$；
   * `mov si, 0` 设置变址初值 $(\text{SI}) = 0$。

2. **第一次读取内存到 AX**：
   * 指令：`mov ax, [bx+2+si]`
   * 偏移地址计算：$1000\text{H} + 2 + 0 = 1002\text{H}$；
   * 对应内存物理地址为 `2000:1002`，该字单元内容为 `0006H`（低位字节 `1002H` 为 `06H`，高位字节 `1003H` 为 `00H`）；
   * 执行后，$(\text{AX}) = 0006\text{H}$。

3. **读取内存到 CX**：
   * `inc si` 执行加 1 操作，$(\text{SI}) = 1$；
   * 指令：`mov cx, [bx+2+si]`
   * 偏移地址计算：$1000\text{H} + 2 + 1 = 1003\text{H}$；
   * 对应内存物理地址为 `2000:1003`，该字单元内容为 `6A00H`（低位字节 `1003H` 为 `00H`，高位字节 `1004H` 为 `6AH`）；
   * 执行后，$(\text{CX}) = 6\text{A}00\text{H}$。

4. **第二次读取内存到 AX**：
   * `inc si` 执行加 1 操作，$(\text{SI}) = 2$；
   * `mov di, si` 将值赋给 $\text{DI}$，$(\text{DI}) = 2$；
   * 指令：`mov ax, [bx+2+di]`
   * 偏移地址计算：$1000\text{H} + 2 + 2 = 1004\text{H}$；
   * 对应内存物理地址为 `2000:1004`，该字单元内容为 `226AH`（低位字节 `1004H` 为 `6AH`，高位字节 `1005H` 为 `22H`）；
   * 执行后，$(\text{AX}) = 226\text{A}H$。
