# 汇编语言：磁盘读写与中断调用

---

### [00:00] 磁盘基本结构与访问方式

本节介绍读写磁盘的方法。磁盘主要包括软盘和硬盘，目前软盘已基本退出历史舞台。

无论是软盘还是硬盘，其物理结构基本一致：
* **磁头**：软盘一般有两个面，对应两个磁头；硬盘则包含若干盘面与磁头。
* **磁道**：磁盘上的同心圆被划分为若干磁道。
* **扇区**：每个磁道被均分为若干段，每一段称为一个扇区。扇区构成了磁盘操作的基本单位。

在汇编语言中操作磁盘，与处理键盘类似，主要有三种方式：
1. **直接硬件访问**：直接操作底层控制器端口（极少使用）。
2. **调用 BIOS 中断**：提供基础的磁盘物理扇区读写服务。
3. **调用 DOS 中断**：提供高级的目录管理与文件系统级操作。

---

### [00:51] BIOS 磁盘中断服务（`INT 13H`）

在实际开发中，BIOS 中断通过 `INT 13H` 提供磁盘底层服务。通过在寄存器 `AH` 中赋予不同的功能号，可以调用不同的磁盘子功能：
* `02H`：读扇区
* `03H`：写扇区
* 其他功能还包括格式化扇区、校验扇区等。

开发者只需按照规范设置入口参数并调用 `INT 13H` 即可完成操作。

---

### [01:37] BIOS 读扇区操作（功能号 `02H`）

当 `AH = 02H` 时，表示执行读扇区操作。

#### 1. 入口参数
* **`AH`**：`02H`（功能号）
* **`AL`**：要读取的扇区数
* **`CH`**：磁道号（柱面号）
* **`CL`**：扇区号
* **`DH`**：磁头号
* **`DL`**：驱动器号
  * 软盘：`00H` 对应软驱 A，`01H` 对应软驱 B
  * 硬盘：`80H` 对应硬盘 C，`81H` 对应硬盘 D
* **`ES:BX`**：指向接收读出数据的内存缓冲区地址段与偏移（数据指针）

#### 2. 出口参数
* **操作成功**：$AH = 0$，$AL$ 返回实际读取的扇区数。
* **操作失败**：$AH$ 返回对应的出错代码，具体错误信息可通过查阅开发手册获取。

---

### [03:06] 读扇区操作示例

**需求**：读取 C 盘 0 面 0 道 1 扇区的内容到内存单元 `0:0200H`。

```assembly
; 1. 设置接收数据的内存缓冲区地址 ES:BX = 0000:0200H
MOV AX, 0
MOV ES, AX
MOV BX, 0200H

; 2. 设置读取参数
MOV AL, 1        ; 读取扇区数：1
MOV CH, 0        ; 磁道号：0
MOV CL, 1        ; 起始扇区号：1
MOV DL, 80H      ; 驱动器号：80H（C 盘）
MOV DH, 0        ; 磁头号：0

; 3. 指定功能号并调用中断
MOV AH, 02H      ; 功能号 02H：读扇区
INT 13H
```

---

### [04:03] BIOS 写扇区操作（功能号 `03H`）

写操作的入口参数与返回参数与读操作基本一致。区别在于 `ES:BX` 指向的是**包含待写入数据的内存缓冲区**。

**需求**：将内存 `0:0200H` 处的扇区数据写入 C 盘 0 面 0 道 1 扇区。

```assembly
; 1. 指定待写入数据的内存地址 ES:BX = 0000:0200H
MOV AX, 0
MOV ES, AX
MOV BX, 0200H

; 2. 设置写入参数
MOV AL, 1        ; 写入扇区数：1
MOV CH, 0        ; 磁道号：0
MOV CL, 1        ; 目标扇区号：1
MOV DL, 80H      ; 驱动器号：80H（C 盘）
MOV DH, 0        ; 磁头号：0

; 3. 指定功能号并调用中断
MOV AH, 03H      ; 功能号 03H：写扇区
INT 13H
```

BIOS 中断屏蔽了复杂的硬件细节，只需查阅手册设置入口参数和返回参数规范即可使用。

---

### [05:15] DOS 磁盘中断服务（`INT 21H`）

相比于 BIOS 针对底层扇区的操作，DOS 中断（`INT 21H`）提供了更为高级和强大的文件与目录控制功能：

* **目录控制**：创建目录、删除目录、设置当前目录、获取当前目录。
* **磁盘管理**：磁盘复位、磁盘校验、选择驱动器、获取驱动器分配信息等。
* **文件操作**：直接对文件进行创建、打开、读写、关闭，以及基于分块记录（FCB / 句柄）级别的文件管理。

---

### [06:33] DOS 中断示例：创建目录（功能号 `39H`）

以 `INT 21H` 的 `39H` 功能号为例，演示如何创建新目录。

#### 1. 入口参数
* **`AH`**：`39H`（创建目录功能号）
* **`DS:DX`**：指向以 `0` 结尾（ASCIIZ 格式）的路径名字符串首地址。

#### 2. 出口参数
* **成功**：进位标志位 $CF = 0$。
* **失败**：进位标志位 $CF = 1$，$AX$ 中返回错误代码（可查阅 DOS 错误代码表排查具体原因）。

---

### [08:04] 总结

无论是 `INT 13H` 还是 `INT 21H`，汇编语言处理外设的核心流程均为：
1. 明确操作任务。
2. 查阅中断手册，获取指定功能号所需的入口参数配置（各通用寄存器与段寄存器赋值）。
3. 触发软中断指令。
4. 检查出口参数（如标志位 $CF$ 或 $AH$ 状态）验证执行结果并进行错误处理。
