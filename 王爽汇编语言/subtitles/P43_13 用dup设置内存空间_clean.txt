### DUP 伪指令概述与基本用法

**[00:00]**
在这节课中，我们介绍一个 `DUP` 指令，用于设置重复的内存空间。

对于 `DUP` 而言，它的功能是与 `DB`、`DW`、`DD` 等数据定义的伪指令配合使用，用来进行数据的重复。实际上，`DUP` 就是英文单词 **duplication** 的缩写。

在使用的时候，我们先举几个例子。比如我们用 `DB`（我们知道这是一个伪指令，用于定义单字节的数据），后边没有直接给出具体数据，而是写了这样一个串：
```assembly
db 3 dup(0)
```
它代表什么呢？代表我们定义 3 个字节，这 3 个字节都是 0。前面的 3 就是重复的次数，而 `DUP` 也是一个给编译器看的伪指令。整句话串起来就是由 3 个 0 构成的串，它等价于：
```assembly
db 0, 0, 0
```

**[00:56]**
同理，我们再看：
```assembly
db 3 dup(0, 1, 2)
```
后边 `DUP` 重复的是 `0, 1, 2`，因此它定义了 9 个字节，也就是把 `0, 1, 2` 重复了 3 次：
```assembly
db 0, 1, 2, 0, 1, 2, 0, 1, 2
```

同样，后边还可以给字符串：
```assembly
db 3 dup('abcABC')
```
如果是这样的话，它重复了 18 个字节。因为 `'abcABC'` 是 6 个字节，重复 3 次，$3 \times 6 = 18$ 个字节，构成的就是这个样子。

有了 `DUP` 这样一个伪指令之后，我们在定义重复数据时，程序编写就会显得比较简洁。

### DUP 语法格式与典型应用

**[01:34]**
我们在定义数据时，除了 `DB` 之外，还有 `DW`（字）和 `DD`（双字）。整体用法格式如下：
```assembly
重复次数 DUP (重复的数据列表)
```
`DUP` 写在中间，前面写重复的次数，后边把要定义的、要重复的字节型、字型或双字型数据依次写上即可。

**[01:54]**
接下来看一个具体用途。比如程序当中要去定义一个 200 个字节的栈段（Stack Segment）。关于栈段的定义，我们在前面的程序中曾经使用过。当时在初始化时，为了指定多长的一个栈段，花费的功夫是比较多的。比如 200 个字节的栈段，如果不使用 `DUP`，可能需要手动写出 200 个 0：
```assembly
db 0, 0, 0, ... ; 一边写一边数个数，一旦数错就麻烦了
```
而采用 `DUP` 指令的话则非常简洁：
```assembly
db 200 dup(0)
```
这样就能准确指定 200 个字节，一定是正确的。

### 实例演示与内存验证

**[02:39]**
接下来我们再通过一个实例进行观察。在这个例子中，我们给出一个 `data` 数据段，需要在其中预留一些空间，并在某些位置设置初值，很多默认值使用 0 来填充。代码段部分在当前例子中不是重点，我们主要观察将来数据段的构成。

我们可以在 EditPlus 中把程序编写好并保存，然后进入 DOSBox 进行编译。程序的源代码文件名为 `p8-1.asm`：

1. **编译**：
   ```shell
   masm p8-1.asm;
   ```
   编译没有问题。

2. **链接**：
   ```shell
   link p8-1.obj;
   ```
   链接完成后，提示一个无堆栈段的警告（no stack segment）。

3. **调入调试**：
   使用 Debug 将生成的可执行文件调入内存观察：
   ```shell
   debug p8-1.exe
   ```

**[03:49]**
此时观察寄存器状态，它的 `DS` 是 `075A`。我们知道这是整个程序加载入内存后的起始地址（PSP 程序段前缀的段地址）。

数据段在程序中排在 PSP 后面，需要跨过程序段前缀占用的 256 个字节（即 $100\text{H}$ 字节，对应段地址增加 $10\text{H}$）。因此数据段的起始物理位置应该位于段地址 `076A` 处。我们直接查看 `076A:0` 开始的内存内容：
```shell
d 076a:0
```

**[04:24]**
在查看的内存数据中可以观察到：
1. 最开始定义了 3 个重复的 0：
   ```text
   00 00 00
   ```
2. 接下来是 3 次重复的 `0, 1, 2`：
   ```text
   00 01 02 00 01 02 00 01 02
   ```
   这是完全按照我们的设定生成的。
3. 再往后是连续的 80 个 0（从此处开始连续 80 字节全为 `00`）。
4. 连续 80 个 0 之后，是小写的 `abc` 与大写的 `ABC` 重复 3 次。查看对应的十六进制 ASCII 码：
   ```text
   61 62 63 41 42 43 61 62 63 41 42 43 61 62 63 41 42 43
   ```
   （其中 `61H`~`63H` 为 `'a'`~`'c'`，`41H`~`43H` 为 `'A'`~`'C'`）。

**[05:11]**
由此可以看到，我们在数据段中的确完成了这些内存空间的初始化与设置。

`DUP` 作为用于重复定义字节、字等空间的伪指令，在今后遇到相应的情形时，大家应当灵活应用。本节课就讲到这里。
