# 条件转移指令的应用

### [00:00] 条件转移指令概述与基本原理

在这一节，我们介绍条件转移指令的应用。

条件转移指令是这样一些形式的指令：以 `J` 开头，代表能够跳转（Jump）。在 `J` 的后边跟上这样一些符号，比如：
- `E` 代表相等（Equal）
- `N` 代表否定（NOT）
- `A` 代表高于/大于（Above）

所以 `JE` 就是说如果相等就跳转；而 `JNA` 就是如果不大于的时候就跳转，等等这样一些指令。

这些指令非常丰富，它们可以根据某种条件（也就是后边跟的这些字母）决定是否转移程序执行的流程。在程序设计当中，这样的转移是经常见的。而我们知道，这种转移在实质上就是在修改 `IP`（Instruction Pointer）寄存器的值。通过对 `IP` 值的修改，程序转到执行保存在别处偏移地址处的指令序列。

### [00:51] 条件检测与标志寄存器

我们如何去检测条件呢？

检测条件从它的内部实现上来讲，是由标志位去体现的。也就是说，在标志寄存器里面，我们看特有的某一个标志位。

但是我们在用的时候，一般都是把这样的条件转移指令和 `CMP` 比较指令相配合使用。`CMP` 改变了标志位，然后通过条件转移指令检测到这种改变，进而去采取相应的动作。我们用不着去把某一个比较、某一个条件到底动用哪一个标志位等去记清楚，这个用不着，完全可以忽略它。

### [01:28] 双分支结构的汇编实现

接下来看用这样的一些条件转移指令和 `CMP` 指令相配合，去实现高级语言里面双分支结构的一个实现。

我们先看这段汇编代码：

```assembly
    cmp ah, bh
    je s
    add ah, bh
    jmp ok
s:  add ah, ah
ok: ...
```

在这段代码当中，先去比较 `AH` 和 `BH`。通过这句我们马上读出：如果两个相等的话，转而执行标号 `s` 处的指令。标号 `s` 处在这儿，然后它会把 `AH` 和 `AH` 相加起来，放到 `AH` 当中。其实就是把它自己自加了一下。

这是在相等的时候做的事情。而如果两个不相等的时候，执行的是这条指令：把 `AH` 和 `BH` 加起来，最后结果放到 `AH` 里面。执行完这条以后，马上执行一个无条件转移指令，要转移到 `ok`，转移到这个地方。

[02:15]  
所以我们看到它的逻辑是什么呢？如果是相等的话，执行标号 `s` 处的这一句，然后它也就返回了；如果不相等的话，执行这一句以后，它转到 `ok` 也返回了。

所以它所起到的作用其实是这样的：
- 如果两个是相等的：$A = A + A$；
- 否则的话：$A = A + B$。

从这里边就看出来了。所以这样一段用汇编语言写的结构，和我们在 C 语言里面写的双分支结构是完全等价的写法：

```c
if (a == b) {
    a = a + a;
} else {
    a = a + b;
}
```

尽管在这里边我们只能用到这样的寄存器。这就是条件转移指令在使用时的一个用法。

### [02:55] 条件转移与标志位的关系

在这里边我们必须要注意这样的事情：在大多数情况下，条件转移指令之前一定有一个用于比较的 `CMP` 指令，但是这个并不是必须的。

我们在去做这样一个条件转移指令的时候，只关心标志位是否发生改变，而不关心改变是由哪条指令发生的。前面可以有 `CMP` 去产生改变；而实际上，如果在调用其他指令时，只要能够使得标志位发生改变，那么 `JE` 或者说条件转移指令 `Jxx` 这样的指令都是可以继续做下去的。

### [03:33] 综合案例分析：内存数据统计

接下来，我们对这样的一些套路做一些应用的探讨。

现在有一组数据，这一组数据一共 8 个字节。现在我们要编程去做一些统计，统计的结果放在 `AX` 里面。我们要统计：
1. 数值为 8 的字节个数（有多少个字节正好等于 8）
2. 大于 8 的字节个数
3. 小于 8 的字节个数

这几个任务是非常相似的。

### [04:02] 任务一（解法一）：统计等于 8 的字节个数（JNE 实现）

现在要统计数值为 8 的字节个数。在当前给出的例子中：一个 8、两个 8，一共有三个 8。

我们如何去做这样的事情呢？其实在这里边我们做一个循环。在循环开始的时候，我们要保存结果的 `AX`，初值置 0。循环 8 次，每次循环的时候能够读到其中的一个数，然后和 8 进行相比。如果相等的话，我们就把 `AX` 的值加 1。这个思路其实非常简单，就是一个简单的循环就可以去做的。

[04:38]  
于是我们写出这样的程序：

```assembly
    mov ax, data
    mov ds, ax
    mov bx, 0
    mov ax, 0
    mov cx, 8
s:  cmp byte ptr [bx], 8
    jne next
    inc ax
next:
    inc bx
    loop s
```

在这个程序当中：
- 首先给 `DS` 数据段寄存器赋值，能够获得正确的段地址。
- 然后 `BX` 在这里边表示它的偏移地址。将来我们在取数据的时候，它的段地址在 `DS` 里面，它的偏移地址在哪呢？对第一个数据来讲，它的偏移地址就是 0，所以在这里边它的初值是 0。
- `AX` 作为要保存结果的寄存器，所以一开始给它赋值为 0。
- 要循环 8 次，所以循环计数器 `CX` 设置为 8。

[05:11]  
现在进入到比较当中。我们要把以 `BX` 作为地址的内存处取出的一个值和 8 进行比较。

比较以后，用 `JNE` 指令。`NE` 是 Not Equal，在不等于的时候，如果两个相比较不相等，它就转到 `next`。转到 `next` 以后，继续执行 `BX` 加 1（`inc bx`），然后 `loop s` 再循环回来。这是不相等的时候。

[05:43]  
如果在比较的时候相等，也就不会发生跳转。相等的时候它会执行 `inc ax`。实际上在这里边我们就找到了一个等于 8 的数值，把 `AX` 的值加 1。

加 1 以后干什么呢？我们还要去找下一个数，所以继续把偏移地址加 1，然后也循环上去了。

所以我们可以看到这个循环能够做 8 次。每次循环的时候，如果是相等，我们就把 `AX` 加 1；如果不相等的话，`AX` 加 1 的工作是不做的。因此自然就能够统计出它的值为 8 的字节个数。这是我们给出的解法一。

---

### [06:28] 任务一（解法二）：统计等于 8 的字节个数（JE 与 JMP 实现）

给出解法二，实际上是对分支跳转的处理过程有所不同。前面的设置循环条件以及比较是完全一样的。

```assembly
    mov ax, data
    mov ds, ax
    mov bx, 0
    mov ax, 0
    mov cx, 8
s:  cmp byte ptr [bx], 8
    je ok
    jmp next
ok: inc ax
next:
    inc bx
    loop s
```

在这块它用 `JE`，而不是用 `JNE` 了。

`JE` 是说如果相等的时候转到 `ok`。如果内存的值等于 8，转到 `ok`。`ok` 干什么呢？可以看到这里边是 `inc ax`，能够去让 `AX` 加 1，多了一个值为 8 的字节。在做完这个以后，接下来 `BX` 加 1，然后再去做循环。这是相等的时候做的事情。

[07:13]  
而如果不相等的时候，它不会跳转到 `ok`，而是执行下一条指令。如果不相等，它会通过无条件转移 `jmp next` 转到 `next`。转到 `next` 也就意味着执行到这，直接把 `BX` 加 1，而 `inc ax` 是不执行的。也就是说不相等的时候，`AX` 就不会去加 1。

因此仔细琢磨这段，它依然实现的还是：如果它等于 8，就把 `AX` 加 1；如果不等于 8，`AX` 是不加 1 的。这两个程序是完全等价的程序。我们将来编写程序在表达的时候，这两种思路都是可以用的。这是第一个任务。

---

### [07:57] 任务二：统计大于 8 的字节个数（JNA 实现）

看第二个任务，其实在解决起来就非常类似了。一开始 `AX` 仍然也是 0，然后在循环的过程当中依次去比较每一个字节。找到一个大于 8 的数，就把 `AX` 的值加 1。

现在给出一个解决方案：

```assembly
    mov ax, data
    mov ds, ax
    mov bx, 0
    mov ax, 0
    mov cx, 8
s:  cmp byte ptr [bx], 8
    jna next
    inc ax
next:
    inc bx
    loop s
```

前面这些都一样，对当前内存当中的字节和 8 进行比较。

用的指令是 `JNA`，`NA` 代表 Not Above。如果不是大于的，就转到 `next`。这样的话，`inc ax` 这个指令是不执行的。

言外之意就是说，如果是大于的，它不会转到 `next`，就会到这去增加 `AX` 的值。所以在这一块，它统计出的是大于 8 的字节个数。

---

### [08:54] 任务三：统计小于 8 的字节个数（JNB 实现）与总结

相应地，第三个要求统计小于 8 的字节个数，跟刚才也是非常类似的，区别仅仅在于这儿使用 `JNB`：

```assembly
    mov ax, data
    mov ds, ax
    mov bx, 0
    mov ax, 0
    mov cx, 8
s:  cmp byte ptr [bx], 8
    jnb next
    inc ax
next:
    inc bx
    loop s
```

我们现在求统计的是要统计小于 8 的字节个数。如果它不是小于的（Not Below），就直接 `BX` 加 1，循环回来以后就找下一个字节了。

言外之意就是说，如果是小于的，它就不会转到 `next`，它会继续执行 `inc ax`。在这种情况下面，通过 8 次的循环，把里边小于 8 的字节个数找出来了。
