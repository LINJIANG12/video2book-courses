## [00:32] 直接寻址 (Direct Addressing)

我们首先演示直接寻址的执行过程。

在直接寻址中，我们要执行的第一条指令就是直接寻址方式。因为在给出的地址位置上，直接给出了一个有效地址数值。

```assembly
MOV AX, [0001H] ; 演示示例中取直接地址数据至 AX
```

我们来看一下整个执行过程：

1. **取指令阶段**：
   当前 $\text{CS} = 2000\text{H}$，$\text{IP} = 0001\text{H}$。开始执行时，从 $\text{CS}$ 中读取段地址，从 $\text{IP}$ 中读取偏移地址，物理地址为：
   $$\text{物理地址} = \text{CS} \times 16 + \text{IP} = 20000\text{H} + 0001\text{H} = 20001\text{H}$$
   从当前 $20001\text{H}$ 位置取出一个 3 字节的指令。取出的 3 字节指令通过数据总线传送到指令缓冲器中。

2. **译码与执行阶段**：
   指令缓冲器读取指令并译码执行，识别出该指令为直接寻址。
   指令中取出的偏移地址为 $0001\text{H}$（演示中提及 $0006\text{H}$ 对应数据区偏移），取出段地址为 $2000\text{H}$。在合成数据物理地址时，要读取的数据位于 $20001\text{H}$ 位置。

> **思考与扩展：代码段与数据段重合的现象**  
> 这段程序有一个与众不同的地方：它的代码段寄存器（$\text{CS}$）和数据段寄存器（$\text{DS}$）中的值是相同的，都是 $2000\text{H}$。这意味着从代码段所在内存中去读取数据，初学者可能会觉得容易混淆。  
> 请大家体会：刚才通过 $\text{CS:IP}$ 确实在这一区域读取了指令，机器能够识别出这是一个 3 字节的指令；而在第二个环节执行指令需要数据时，同样基于该地址区间，CPU 则按照数据的方式去读取。  
> 内存中保存的数据究竟是作为代码执行还是作为普通数据使用，本质上是由人来决定的。汇编语言能够非常自由地访问内存，这也体现了底层操作的灵活性（乃至为黑客技术提供了便利）。

回到指令执行过程：找到要读取数据的物理地址 $20001\text{H}$。当前执行的是传送至 $\text{AX}$，因此需要读取一个字（2 个字节）。读取出的一个字为 `01 A1`（即 $\text{A101H}$），通过数据总线传送至 CPU 并存入寄存器 $\text{AX}$。同时，$\text{IP}$ 的值由 $0001\text{H}$ 更新为 $0011\text{H}$。这就是直接寻址的全过程。

## [03:20] 寄存器间接寻址 (Register Indirect Addressing)

接下来看第二条指令：寄存器间接寻址过程。

```assembly
MOV AX, [BX]
```

1. **取指令阶段**：
   当前代码段寄存器 $\text{CS} = 2000\text{H}$，$\text{IP} = 0011\text{H}$。将两个地址合成，得到指令的物理地址：
   $$\text{物理地址} = 2000\text{H} \times 16 + 0011\text{H} = 20011\text{H}$$
   该指令是一个 2 字节指令。将指令读取出来，通过数据总线送入 CPU 的指令缓冲队列。

2. **执行阶段**：
   进入指令缓冲队列后进行译码执行。指令中给出的操作数寻址寄存器为 $\text{BX}$（基址寄存器）。
   - 当前 $\text{BX} = 000\text{F}\text{H}$；
   - 使用 $\text{BX}$ 寻址时，默认的段寄存器为 $\text{DS}$，取 $\text{DS} = 2000\text{H}$。
   
   地址加法器合成物理地址：
   $$\text{物理地址} = \text{DS} \times 16 + \text{BX} = 20000\text{H} + 000\text{F}\text{H} = 2000\text{F}\text{H}$$
   随后到内存 $2000\text{F}\text{H}$ 位置读取一个字的数据，读取出的值为 `00 01`（即 $0001\text{H}$），通过数据总线传输并放入寄存器 $\text{AX}$ 中。执行结束。

## [04:54] 寄存器相对寻址 (Register Relative Addressing)

接下来看第三条指令：寄存器相对寻址。

```assembly
MOV AX, [BX + 1]
```

在该指令中，基址寄存器 $\text{BX}$ 加上了一个立即数（偏移位移量），构成了寄存器相对寻址。

1. **取指令阶段**：
   当前 $\text{CS} = 2000\text{H}$，$\text{IP} = 0013\text{H}$。取指令物理地址为 $20013\text{H}$。
   这是一条 3 字节指令。通过 16 位数据总线按时序读取这 3 个字节送入指令缓冲区。

2. **执行阶段**：
   指令译码得到寻址方式为 $\text{BX} + 1$。
   - 立即数位移量 $01\text{H}$ 来自于指令自身代码；
   - 寄存器 $\text{BX} = 000\text{F}\text{H}$；
   - 偏移地址由两者共同决定：
     $$\text{EA} = \text{BX} + 01\text{H} = 000\text{F}\text{H} + 0001\text{H} = 0010\text{H}$$
   - 对应的段寄存器依然为 $\text{DS} = 2000\text{H}$。
   
   三者在地址加法器中合成最终物理地址：
   $$\text{物理地址} = \text{DS} \times 16 + \text{BX} + 01\text{H} = 20000\text{H} + 0010\text{H} = 20010\text{H}$$
   CPU 访问内存 $20010\text{H}$ 单元，读取一个字的数据，取出的内容为 `8B 00`（$008\text{B}\text{H}$），经数据总线传送并写入 $\text{AX}$ 中。

## [06:40] 基址变址寻址 (Base-Index Addressing)

接下来看基址变址寻址指令：

```assembly
MOV AX, [BX + SI]
```

此指令中，基址使用 $\text{BX}$，变址使用 $\text{SI}$。

1. **取指令阶段**：
   当前 $\text{CS} = 2000\text{H}$，$\text{IP} = 0016\text{H}$。合成物理地址为 $20016\text{H}$。
   从 $20016\text{H}$ 处取出 2 字节指令，传送至 CPU 指令缓冲器，开始译码执行。

2. **执行阶段**：
   译码分析出数据地址来源由 $\text{BX}$ 和 $\text{SI}$ 共同构成：
   - 基址寄存器 $\text{BX} = 000\text{F}\text{H}$；
   - 变址寄存器 $\text{SI} = 0002\text{H}$；
   - 段地址由 $\text{DS} = 2000\text{H}$ 提供。
   
   三者汇总至地址加法器，段地址加上偏移地址完成合成：
   $$\text{EA} = \text{BX} + \text{SI} = 000\text{F}\text{H} + 0002\text{H} = 0011\text{H}$$
   $$\text{物理地址} = 20000\text{H} + 0011\text{H} = 20011\text{H}$$
   CPU 到 $20011\text{H}$ 位置读取一个字的数据，读取结果为 `07 8B`（$8\text{B}07\text{H}$），通过数据总线传送到 $\text{AX}$ 寄存器中。

## [08:00] 相对基址变址寻址 (Relative Base-Index Addressing)

最后看相对基址变址寻址指令：

```assembly
MOV AX, [BX + SI + 1]
```

“相对”体现在指令中包含了一个立即数位移量 $01\text{H}$。内存地址由 $\text{BX}$、$\text{SI}$ 以及立即数 $1$ 三方共同决定。

1. **取指令阶段**：
   确定指令地址，前往 $20018\text{H}$ 处读取指令。这是一条 3 字节指令，送入 CPU 指令缓冲队列中等待执行。

2. **执行阶段**：
   地址来源于三个组成部分：$\text{BX}$、$\text{SI}$ 与立即数位移量。
   - $\text{BX} = 000\text{F}\text{H}$；
   - $\text{SI} = 0002\text{H}$；
   - 指令代码中携带的立即数位移量为 $01\text{H}$（*注：课件动画此处有一处微小的标识缺失，指令中的 $01\text{H}$ 应当加下划线标识，它参与构成有效地址*）。
   - 段地址为 $\text{DS} = 2000\text{H}$。

   地址合成计算：
   $$\text{F}\text{H} + 2\text{H} = 11\text{H}$$
   $$11\text{H} + 01\text{H} = 12\text{H}$$
   合成出的物理地址为 $20012\text{H}$（*注：课件动画最终合成显示的 $20012\text{H}$ 数值是正确的*）。

   前往内存 $20012\text{H}$ 单元读取一个字，取出的内容为 `8B 07`，经数据总线传送至 CPU 后，$\text{AX}$ 的值更新为 $8\text{B}07\text{H}$。
