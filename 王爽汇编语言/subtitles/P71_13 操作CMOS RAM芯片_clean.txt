# CMOS RAM 芯片操作与端口读写

### [00:00] CMOS RAM 芯片概述

这一节我们通过操作 CMOS RAM 芯片，来看一下关于端口读写的方法。

在操作计算机时，电脑刚开机可以通过按键进入 BIOS 设置。在 BIOS 设置中包含系统时间以及整个系统的配置信息；如果缺失这些信息，计算机是无法正常启动的。能够完成这些工作，得益于主板上的一块 CMOS RAM 芯片。

该芯片包含一个实时时钟（RTC）和一个容量为 128 个存储单元（128 个字节）的 RAM 存储器。在这 128 个字节的存储器中，存储着：
1. 内部的实时时钟（相当于一块持续运行的电子表）。
2. 系统配置信息（包括硬盘配置、光驱配置、键盘配置等）。
3. 相关的系统程序，这些程序在开机引导机器启动时发挥关键作用。

CMOS RAM 芯片在系统刚刚启动时就会被使用，并且在整个系统运行过程中，基本配置信息的读取都依赖于它，因此非常关键。

这块 RAM 与普通内存不同：普通 RAM 在关机断电后内部数据会全部丢失；而 CMOS RAM 在关机后，其实时时钟仍能正常走动，存储的信息也不会丢失。这得益于主板上配备的一块纽扣电池，专门为这 128 个存储单元持续供电。因此在关机断电后，它依旧可以保存数据并维持时钟运行。

### [01:50] 端口 70H 与 71H 的读写机制

若要访问这块芯片以查找关键系统信息，需通过两个专门的端口，端口号分别为 `70H` 和 `71H`。CPU 正是通过这两个端口来对 CMOS RAM 进行读写操作的。在 64KB 的端口地址空间中，`70H` 和 `71H` 专门分配给了 CMOS RAM 芯片。

读写 CMOS RAM 的具体流程如下：

* **地址端口（`70H`）**：用于存放要访问的 CMOS RAM 存储单元的地址。CMOS RAM 共有 128 个存储单元（地址范围 $0 \sim 127$），欲访问哪个单元，就必须先将其单元地址写入 `70H` 端口中。
* **数据端口（`71H`）**：用于存放从选定单元读取的数据，或准备写入选定单元的数据。

`70H` 端口负责提供单元地址，`71H` 端口负责提供或接收数据。二者相互配合，便可完成对这 128 个存储单元中任意单元的读写操作。

因此，读取 CMOS RAM 中指定单元的数据需分为两步：
1. 将目标存储单元的地址写入地址端口 `70H`；
2. 从数据端口 `71H` 中读出（或向其写入）该单元的内容。

### [03:36] 实验任务与 CMOS 时间存储格式

本次任务的目标是在屏幕中间显示当前的月份。该月份信息可直接从 CMOS RAM 的时间数据中提取。

在 CMOS RAM 中，当前时间是非常重要的存储内容，共占用 6 个字节。其存放地址分配如下：

| 单元地址 | 对应时间信息 |
| :--- | :--- |
| `00H` | 秒 |
| `02H` | 分 |
| `04H` | 时 |
| `07H` | 日 |
| `08H` | 月 |
| `09H` | 年 |

这 6 个时间信息的长度均为 1 个字节。

例如在 5 月 15 日这天：
* 日期“15”保存在 `07H` 单元；
* 月份“05”保存在 `08H` 单元。

CMOS RAM 中的时间数据采用 **BCD 码**（Binary-Coded Decimal）格式存储。每个字节的高 4 位和低 4 位分别代表十进制的十位和个位：
* “15 日”表示为：前 4 位为 `0001`（1），后 4 位为 `0101`（5）；
* “05 月”表示为：前 4 位为 `0000`（0），后 4 位为 `0101`（5）。

在 0 到 9 的范围内，BCD 码的编码形式与对应的二进制数值完全一致。

### [06:04] 任务分解与核心指令实现

要在屏幕中间显示当前月份，整体逻辑可拆解为两个核心步骤：
1. 从 CMOS RAM 的 8 号单元中读取当前月份的 BCD 码；
2. 将该 BCD 码表示的月份转换为字符形式，并以十进制格式显示在屏幕上（即显示 `'0'` 和 `'5'` 两个字符）。

#### 步骤一：读取 8 号单元的月份数据

1. 将欲访问的单元地址 `8` 写入 `AL` 寄存器；
2. 通过 `OUT` 指令将 `AL` 中的地址输出至端口 `70H`；
3. 通过 `IN` 指令从数据端口 `71H` 读取该单元的数据到 `AL` 寄存器。

对应汇编代码实现：
```assembly
mov al, 8
out 70h, al
in al, 71h
```
此时，`AL` 中即保存了当前月份的 BCD 码数据。在操作端口时，由于是以单字节数据进行传输，使用的寄存器为 `AL`。

---

### [08:08] 数据转换（BCD 转 ASCII）与显存写入

#### 步骤二：分离高低位并转换为 ASCII 码

以 5 月份为例，其 BCD 码为：
$$0000\ 0101\text{b}$$

需要将其高 4 位（十位数）与低 4 位（个位数）分离开来：
* 将高 4 位（十位数值 `0`）放入 `AH` 寄存器；
* 将低 4 位（个位数值 `5`）放入 `AL` 寄存器。

分离出月份的十位数和个位数后，分别给它们加上 `30H`（即加 `48`），转换为对应的 ASCII 码字符：
$$0 + 30\text{H} = 30\text{H}\;(\text{'0'})$$
$$5 + 30\text{H} = 35\text{H}\;(\text{'5'})$$

#### 步骤三：写入显存显示

完成字符转换后，程序直接将 ASCII 码及属性字节写入显示缓冲区（显存），从而在屏幕中间完成字符呈现。
