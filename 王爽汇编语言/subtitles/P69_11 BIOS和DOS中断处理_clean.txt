# BIOS 与 DOS 中断处理

---

### [00:00] 一、BIOS 概述与内存分布

在这节课中，我们介绍一下 BIOS 中断处理和 DOS 中断处理。

首先认识一下 BIOS。它被称为**基本输入输出系统**（Basic Input Output System），在硬件层面上实际对应主板上的 ROM 芯片。

在这些芯片当中存放着一套程序，这套程序的容量只有 8KB，在统一编址当中的物理地址是从 `FE000H` 开始的。这套程序对整个计算机系统的意义非同小可。

从体系结构来看，它存放在系统 BIOS ROM 的地址空间中（即刚才所说的地址空间）。其中的程序起着至关重要的作用，其主要内容包括：

1. **硬件系统的检测和初始化程序**：这对整个计算机系统非常重要。开机时总要检查硬件系统是否工作正常、是否存在故障。
2. **外部中断和内部中断的中断例程**：计算机的基本操作都要依赖于它。
3. **硬件设备输入输出操作的中断例程**。
4. **与其他硬件系统相关的中断例程**。

可以说，整个计算机系统中最基本的功能都是由 BIOS 提供的，因此它是计算机系统运行中不可或缺的重要组成部分。

程序员在有了 BIOS 提供的功能调用后，不需要了解硬件底层的具体操作细节，可以直接通过指令设置参数，并通过中断调用 BIOS 例程来完成相关工作。这极大地解放了程序员，使其免于处理硬件电气层面的细节，直接使用指令调用中断即可完成任务。

使用 BIOS 功能调用的优势在于：
- **方便编程**：降低了编程的难度。
- **程序质量高**：能够写出简洁、可读性好且易于移植的代码。

在实际的汇编语言程序中，大量功能的底层实现都是通过调用 BIOS 中断例程来完成的。

### [02:40] 二、BIOS 中断调用示例：屏幕显示字符

通过一个具体例子来看如何调用 BIOS 中断例程：

> **需求**：在屏幕的第 5 行第 12 列显示 3 个“红底、高亮、闪烁、绿色”的字符 `'A'`。

如果采用直接写显存的方式，需要深入了解显示缓冲区的结构（如 $25 \times 80$ 字符模式、每个字符占 2 个字节），计算出偏移地址并直接写入数据。这种方式细节过于繁琐，如果不清楚显存内部结构就无法编写。

而调用 BIOS 中断则简便得多。BIOS 中的 `INT 10H` 中断专门提供与显示器相关的操作：
- 当设置功能号 $AH = 02H$ 时，调用 2 号子程序，用于设置光标位置。
- 当设置功能号 $AH = 09H$ 时，调用 9 号子程序，在当前光标处显示字符。

因此，只需分两步：**先定位光标位置，再显示字符**。

```assembly
; 1. 设置光标位置 (第 5 行，第 12 列)
mov ah, 02h      ; 功能号 02H：设置光标位置
mov bh, 0        ; 0 页
mov dh, 5        ; 行号：5
mov dl, 12       ; 列号：12
int 10h          ; 调用 BIOS 10H 中断

; 2. 在当前光标处按属性显示字符
mov ah, 09h      ; 功能号 09H：显示字符
mov al, 'A'      ; 要显示的字符
mov bl, 11001010b; 颜色属性：红底、高亮、闪烁、绿色 (0CAH)
mov bh, 0        ; 0 页
mov cx, 3        ; 重复显示 3 次
int 10h          ; 调用 BIOS 10H 中断
```

*属性字节 `BL` 解析（`11001010B` / `0CAH`）：*
- **Bit 7**：`1`（闪烁）
- **Bit 6~4**：`100B`（背景色：红）
- **Bit 3**：`1`（前景高亮）
- **Bit 2~0**：`010B`（前景色：绿）

相比于直接向显存写入数据，调用两个中断例程即可完成操作，大幅简化了编程流程。

### [06:36] 三、BIOS 中断服务分类与手册查阅

BIOS 中断功能丰富，可通过查阅《BIOS 中断手册》了解其具体功能。主要分类如下：

| 中断号 | 服务类型 | 功能描述 |
| :--- | :--- | :--- |
| **INT 10H** | 屏幕服务 | 屏幕控制、显示模式、光标设置、字符输出 |
| **INT 13H** | 直接磁盘服务 | 针对软盘、硬盘等外存的读写控制 |
| **INT 14H** | 串行口服务 | 串行通信端口数据传输 |
| **INT 15H** | 杂项系统服务 | 系统环境扩展与配置 |
| **INT 16H** | 键盘服务 | 键盘输入缓冲读取、状态检测 |
| **INT 17H** | 并行口服务 | 打印机等并行接口控制 |
| **INT 1AH** | 时钟服务 | 系统时钟读取与设置 |
| ... | 其他直接系统服务 | 系统内部调用的其他中断 |

#### 以 `INT 10H` 的 `09H` 号功能为例说明参数规范：
- **功能描述**：在当前光标处按指定属性显示字符。
- **前置操作**：需先用 `AH = 02H` 功能设置光标位置。
- **入口参数**：
  - `AH = 09H`（功能号）
  - `AL` = 字符 ASCII 码
  - `BH` = 显示页码
  - `BL` = 字符属性/颜色
  - `CX` = 重复输出字符的个数
- **调用方式**：`INT 10H`

掌握了手册的使用方法，查明所需功能的入口参数与出口参数，便可规范调用各中断例程。

### [09:51] 四、DOS 中断功能与层次结构

除了 BIOS 中断，操作系统还提供了更高层次的中断——**DOS 中断**。常见的 DOS 中断有 `INT 20H`、`INT 21H`、`INT 22H` 等，其中最核心、最常用的是 `INT 21H`。

`INT 21H` 涵盖了操作系统底层的丰富功能：
- 字符功能
- 目录控制
- 磁盘管理
- 文件操作
- 记录操作
- 内存分配
- 系统功能
- 时间与日期管理

#### 示例：获取系统日期（功能号 `2AH`）
- **入口参数**：`AH = 2AH`
- **调用**：`INT 21H`
- **出口参数**：
  - `CX` = 年
  - `DH` = 月
  - `DL` = 日
  - `AL` = 星期几

```assembly
mov ah, 2ah      ; 功能号 2AH：取系统日期
int 21h          ; 调用 DOS 21H 中断
; 执行后：
; 年保存在 CX
; 月保存在 DH
; 日保存在 DL
; 星期保存在 AL
```

### [12:02] 五、外设、BIOS 与 DOS 的调用层次关系

整个计算机系统自底向上的调用关系如下：

$$\text{硬件外设} \longleftarrow \text{BIOS 中断例程} \longleftarrow \text{DOS 中断例程} \longleftarrow \text{应用程序}$$

1. **硬件外设层**：包含复杂的芯片和电气操作细节。
2. **BIOS 层**：固化在 ROM 中，封装了底层硬件的直接 I/O 操作。
3. **DOS 层**：操作系统级的中断例程，在底层实现上大多调用 BIOS 中断例程，向上为程序员提供更抽象的高级功能。
4. **应用程序层**：
   - 优先推荐调用 **DOS 中断**（更高级、便捷）；
   - 亦可直接调用 **BIOS 中断**；
   - 若系统未提供相应中断服务，可在程序中直接通过**端口操作**直接访问外设。

### [14:29] 六、DOS 中断应用示例

#### 1. 程序安全返回功能（功能号 `4CH`）
- **入口参数**：`AH = 4CH`，`AL` = 返回码（通常为 0）
- **调用**：`INT 21H`

```assembly
mov ah, 4ch      ; 功能号 4CH
mov al, 0        ; 返回值 0
int 21h          ; 返回操作系统
```
这等价于常用的合并写法：
```assembly
mov ax, 4c00h
int 21h
```

#### 2. 在光标位置显示字符串（功能号 `09H`）
- **入口参数**：
  - `AH = 09H`
  - `DS:DX` 指向要显示的字符串首地址
  - 字符串必须以 `$` 作为结束符
- **调用**：`INT 21H`

> **需求**：在屏幕第 5 行第 12 列显示字符串 `"welcome to masm"`。

```assembly
data segment
    db 'welcome to masm$'
data ends

code segment
    assume cs:code, ds:data
start:
    ; 1. 调用 BIOS 10H 中断设置光标位置 (5行12列)
    mov ah, 2
    mov bh, 0
    mov dh, 5
    mov dl, 12
    int 10h

    ; 2. 设置数据段地址与偏移地址
    mov ax, data
    mov ds, ax
    mov dx, 0        ; DS:DX 指向字符串起始地址

    ; 3. 调用 DOS 21H 中断输出字符串
    mov ah, 9        ; 功能号 09H
    int 21h

    ; 4. 退出程序
    mov ax, 4c00h
    int 21h
code ends
end start
```

### [17:11] 七、BIOS 与 DOS 中断例程的装载流程

系统启动和中断例程的安装过程如下：

```
开机加电 
  ↓
CPU 初始化 (CS=FFFFH, IP=0000H)
  ↓
跳转至 BIOS 硬件检测与初始化程序 (从 FFFF0H 开始跳转)
  ↓
BIOS 建立中断向量表 (0000:0000H ~ 0000:03FFH 写入 BIOS 例程入口)
  ↓
调用 INT 19H 引导操作系统 (DOS/Windows)
  ↓
操作系统接管硬件，将 DOS 中断例程装入内存并将其入口登记在中断向量表
  ↓
系统启动完成，等待运行用户程序并响应中断调用
```

1. **加电与初始化**：CPU 上电初始化，寄存器赋值为 $CS = FFFFH,\ IP = 0000H$，执行物理地址 `FFFF0H` 处的指令。
2. **跳转执行 BIOS**：`FFFF0H` 处为一条跳转指令（`JMP`），跳转到 BIOS 的硬件系统检测和初始化程序。
3. **建立中断向量表**：检测完毕后，初始化程序在内存起始处（`0000:0000H` 开始的 1KB 空间）建立**中断向量表**，登记 BIOS 中断例程的入口地址。
4. **引导操作系统**：调用 `INT 19H` 引导操作系统。
5. **加载 DOS 中断例程**：DOS 启动后接管计算机控制权，将其提供的中断例程加载至内存，并将对应的入口地址写入中断向量表。
6. **就绪**：整个操作系统完成初始化，应用程序运行时即可直接通过中断向量表检索地址并执行相应的中断例程。
