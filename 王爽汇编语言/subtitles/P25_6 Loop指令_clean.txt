# 汇编语言：`loop` 指令与循环程序设计

---

### [00:00] `loop` 指令的基本格式与功能

在这一节，我们介绍 `loop` 指令。

`loop` 指令实现的是计数型循环，也就是说，我们可以设定循环的具体次数。该指令的基本格式如下：

```assembly
loop 标号
```

`loop` 是指令名称，后面紧跟一个标号。

以具体程序为例：
```assembly
s:  add ax, ax
    loop s
```
在这里使用的是 `loop` 指令，后面的 `s` 是一个标号。对于循环流程而言，当 CPU 执行到 `loop s` 时，会循环跳转到标号 `s` 所标识的语句位置上。这就是它的基本格式。

---

### [00:31] `loop` 指令的执行机制

CPU 在执行 `loop` 指令时，具体会进行以下操作：

1. 将寄存器 $cx$ 的值进行递减运算：
   $$(cx) = (cx) - 1$$
2. 判断寄存器 $cx$ 中的值：
   * 如果 $(cx) \neq 0$，则转向标号处执行程序；
   * 如果 $(cx) = 0$，则向下继续执行下一条指令，退出循环。

---

### [01:01] 循环执行过程解析：以计算 $2^{12}$ 为例

我们可以通过下面这段程序来分析其执行过程：

```assembly
    mov ax, 2
    mov cx, 11
s:  add ax, ax
    loop s
```

在进入循环之前，程序先将 $cx$ 赋值为 11。第一次执行完 `add ax, ax` 以后遇到 `loop s`：
1. CPU 首先执行 $(cx) = (cx) - 1$；
2. 减 1 之后发现 $cx$ 不为 0，于是跳转到标号 `s` 的位置继续执行 `add ax, ax`；
3. 再次执行到 `loop s` 时，继续将 $cx$ 减 1 并判断。

这两条指令构成的循环体总共会执行 11 次，其循环次数由预先存入 $cx$ 中的初值决定。

整体计算过程如下：
* 初始时：$ax = 2$；
* 第 1 次循环执行后：$ax = 2 + 2 = 4$，$cx$ 减为 10；
* 第 2 次循环执行后：$ax = 4 + 4 = 8$；
* 第 3 次循环执行后：$ax = 8 + 8 = 16$；
* 依次类推，$ax$ 中保存的数值序列为 $2, 4, 8, 16, 32, \dots$。

当循环执行完毕（共执行 11 次加法）后，最终计算出的结果就是 $2^{12}$。

### [02:39] 循环机制要点与隐含寄存器

在 `loop` 的运行机制中，重点在于：**$cx$ 寄存器必须存放循环次数**。因为 $cx$ 的值直接影响 `loop` 指令的跳转与终止，所以在进入循环之前，必须为 $cx$ 赋好初始值。

在 8086 汇编指令系统中，有些指令在书写时并未显式写出寄存器操作数，但执行时默认会使用特定的寄存器：
* `loop` 指令默认使用计数寄存器 $cx$；
* `push` 和 `pop` 指令默认使用栈顶指针寄存器 $sp$。

另外，使用 `loop` 指令必须配合一个标号来指示跳转的目标位置（例如本例中的标号 `s`）。

### [04:51] 反汇编分析：机器码中的转移地址

在 Debug 中使用 `u` 命令反汇编查看代码：

```text
mov ax, 0002
mov cx, 000B
add ax, ax
loop 0006
mov ax, 4C00
int 21
```

观察反汇编结果：
* 原程序中的十进制数 `11` 在机器中被表示为十六进制数 `000B`（汇编源程序中若未加后缀，默认采用十进制）。
* 原程序中的 `loop s` 在反汇编中体现为 `loop 0006`。
* 这里的 `0006` 对应的是指令 `add ax, ax` 的偏移地址。

这表明：在源程序中书写的标号，本质上代表的就是一个内存地址。当汇编程序将源程序翻译为机器指令后，`loop` 指令中直接体现出要跳转的指令偏移地址。

### [06:15] Debug 单步跟踪与执行流程分析

使用 `r` 查看初始寄存器状态，$ax$ 当前为 `FFFF`。使用 `t` 命令单步跟踪执行：

1. 执行 `mov ax, 0002`：
   $ax$ 变为 `0002`。
2. 执行 `mov cx, 000B`：
   $cx$ 变为 `000B`。
3. 此时偏移地址处于 `0006`，执行 `add ax, ax`：
   $ax$ 变为 `0004`。
4. 接下来将要执行位于 `0008` 的 `loop 0006`。执行 `t` 命令：
   $IP$ 寄存器由 `0008` 跳变回 `0006`，同时 $cx$ 递减为 `000A`。`loop` 指令正是通过修改 $IP$ 寄存器的值实现程序流程的跳转。
5. 再次单步执行：
   * 在 `0006` 处执行 `add ax, ax`：$ax$ 变为 `0008`；
   * 在 `0008` 处执行 `loop 0006`：$cx$ 由 `000A` 减为 `0009`，$IP$ 再次跳回 `0006`。
6. 继续连续跟踪：
   $ax$ 的值依次变为十六进制的 `0010`（十进制 16）、`0020`（十进制 32）、`0040`（十进制 64）……随着 $cx$ 逐步减小，循环持续进行。
7. 当 $cx$ 减为 `0001` 时，单步执行完成最后一次累加，此时 $ax$ 的值已计算至 $2^{12}$。
8. 再次执行 `loop 0006`：
   $cx$ 减 1 后变为 `0000`。由于满足 $(cx) = 0$ 的条件，CPU 不再跳转至 `0006`，而是顺序执行下一条指令（即位于 `000A` 的 `mov ax, 4C00h`），循环正常退出。

### [10:06] `loop` 编程实践与循环三要素

掌握 `loop` 指令后，即可进行循环程序设计。

#### 实例 1：计算 $2$ 的乘方

* **计算 $2^2$**：
  可通过一次加法 $2 + 2 = 4$ 实现：
  ```assembly
  mov ax, 2
  add ax, ax
  ```

* **计算 $2^3$**：
  在 $2^2$ 的基础上再加一次：$4 + 4 = 8$。

* **计算 $2^{12}$**：
  初始置 $ax = 2$，连续执行 11 次 `add ax, ax`：
  ```assembly
  mov ax, 2
  mov cx, 11
  s:  add ax, ax
      loop s
  ```

#### 循环结构的三要素

使用 $cx$ 寄存器配合 `loop` 指令实现循环程序时，有三个核心要点：
1. **设置循环计数**：在进入循环前，向 $cx$ 寄存器存入预期的循环次数；
2. **定义循环起点**：使用标号标识循环体的起始语句；
3. **编写循环体**：在标号与 `loop` 指令之间编写需要重复执行的程序段。

### [12:19] 实例 2：通过累加计算 $123 \times 236$

虽然汇编语言提供了专门的乘法指令，但我们也可以利用循环加法来模拟乘法运算。

**计算思路**：
计算 $123 \times 236$，即把 123 累加 236 次。

**程序实现逻辑**：
1. 结果保存在 $ax$ 中，累加前必须清零初始化：$ax = 0$；
2. 循环次数为 236 次，将 $cx$ 置为 236；
3. 循环体内部每次将 123 加到 $ax$ 中；
4. 利用 `loop` 递减 $cx$ 并实现跳转，循环执行 236 次。

```assembly
    mov ax, 0
    mov cx, 236
s:  add ax, 123
    loop s
```

每执行一次循环体，将 123 累加到 $ax$；执行 `loop s` 时 $cx$ 自减 1 并判断，确保精确循环 236 次，最终 $ax$ 中的结果即为 $123 \times 236$。
