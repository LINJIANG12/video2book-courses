### [00:00] DS 与数据段的概念与物理地址确定

在前面我们介绍过 CS 和代码段的问题，在这一节课，我们介绍 DS 和数据段。

这里面牵涉到的是对内存单元里面数据的访问。我们已经知道，在 PC 机里面，物理地址的确定是根据段地址和偏移地址去决定的。因此，我们在使用一段空间的时候，就应该把段地址和偏移地址定下来。比如说，我们现在要用的是这样一段空间。在使用这一段空间的时候，我们可以看到，在它的高 16 位是具有某种特征的，这个特征有助于帮助我们把段地址确定下来。

我们确定段地址的一个方法是：把 `123B`，也就是直接把它的高 16 位取出来，作为段地址。而如果把它作为段地址的话，我们会知道它的起始偏移地址就是 `0` 了，这个我们很好理解。对于这段空间来讲，由 `123B0` 到 `123B9`，它一共是 10 个字节。

其实我们在选取段地址的时候，还可以怎么做呢？我们把 `1230` 取作为段地址，于是在这个时候，这一段内存空间的起始地址是什么呢？偏移地址就是 `00B0`。因为在物理地址计算中，段地址和偏移地址一合并，仍然还是这一段空间的起始地址：

$$\text{物理地址} = 1230\text{H} \times 16 + 00\text{B}0\text{H} = 123\text{B}0\text{H}$$

其实对于段地址的取法来讲，可以有好多种。究竟把哪一段内存当做数据段、段地址是如何定下来的，这种定的方法很多，在编程的时候由程序设计人员自己安排就可以了。这是我们首先看到的这样一个问题。

### [01:45] 数据段的访问方式与通用惯例

在程序当中，我们经常用的一种惯用手法是：用 DS 去代表段地址，而把偏移地址直接通过地址值来给定，这是一种非常简单、非常初始的方法。

这样的话，由 DS 存放段地址，而相关的指令去访问数据段里面具体单元的时候，偏移地址由它给出。这里面相关的指令，我们现在学过的包括 `mov`、`add`、`sub` 等等。

### [02:14] 编程示例 1：累加数据段前三个字节型数据

接下来我们看这样一个例子。其实在这个例子当中，大家已经要体会到：我们学会编语言，学的指令并不多，现在还集中在对一些机制的了解上，但是现在我们的确可以去解决问题了。

我们现在解决的第一个问题是：累加（要做加法了）数据段里面前三个单元里的数据。我们要编这个程序的时候该如何去做呢？

在数据段，现在我们给出它的段地址——这是可以由程序设计人员自己确定的，我们确定在哪段空间里面放数据就可以了。接下来我们要去累加的时候，希望在 AL 里面放累加之后和的结果。所以，我们首先要把这个和清零；在还没有开始加之前，它的和是 0。然后，把偏移地址为 0 的单元里面的数据加到 AL 里面，偏移地址 1、偏移地址 2 里面的数据分别加到 AL 里面。

大家可以看到，这就是在这段空间里面，把前三个单元里面的数据逐个取出来和 AL 相加的过程。于是，这就是我们的一个程序，它能够解决特定的问题：累加数据段里面前三个单元的数据。

```assembly
; 累加数据段前三个字节型数据
mov ax, 123Bh
mov ds, ax      ; 设置数据段段地址 DS = 123BH

mov al, 0       ; 累加器 AL 清零
add al, [0]     ; 加上偏移地址为 0 的字节单元
add al, [1]     ; 加上偏移地址为 1 的字节单元
add al, [2]     ; 加上偏移地址为 2 的字节单元
```

### [03:41] 编程示例 2：累加数据段前三个字型数据

同样的道理，如果说现在我们累加的是数据段里面前三个字型（Word）数据的话，一个字型数据是 16 位的。于是我们编的程序是这样的：

首先要置 DS，我们确定它的数据段，要的是这段空间里面的数据，所以首先段地址给它设好；设好以后，AX 里面存放累加的和。在把 AX 置零之后，把 0 单元、2 单元、4 单元（分别是三个字当中的数据）取出来加到 AX 里面。这就是累加数据段里面前三个字型数据。

```assembly
; 累加数据段前三个字型数据
mov ax, 123Bh
mov ds, ax      ; 设置数据段段地址 DS = 123BH

mov ax, 0       ; 累加器 AX 清零
add ax, [0]     ; 加上偏移地址为 0 的字单元（占用 0 和 1 字节）
add ax, [2]     ; 加上偏移地址为 2 的字单元（占用 2 和 3 字节）
add ax, [4]     ; 加上偏移地址为 4 的字单元（占用 4 和 5 字节）
```

### [07:32] mov 指令格式总结与归纳

用 `mov` 指令操作数据，其实我们操作的数据可以是寄存器当中的数据，也可以是内存单元当中的数据；操作的可以是段寄存器的数据，也可以操作一般的通用寄存器的数据。

我们现在列出的 `mov` 指令形式包括：
- `mov 寄存器, 数据`
- `mov 寄存器, 寄存器`
- `mov 寄存器, 内存单元`
- `mov 内存单元, 寄存器`
- `mov 段寄存器, 寄存器`
- `mov 寄存器, 段寄存器`
- `mov 内存单元, 段寄存器`
- `mov 段寄存器, 内存单元`

> **禁忌**：不能用立即数直接给段寄存器赋值（如 `mov ds, 1000h` 报错）。

### [11:26] add 与 sub 指令的用法与限制

对于 `add` 与 `sub` 指令：
- `add 寄存器, 数据`
- `add 寄存器, 寄存器`
- `add 寄存器, 内存单元`
- `add 内存单元, 寄存器`

> **禁忌**：
> 1. 不能在两个内存单元之间直接执行加减法（如 `add [0], [2]` 非法）。
> 2. 段寄存器（DS、CS、SS、ES）不能参与算术加减法运算（如 `add ds, ax` 非法）。
