# 王爽：汇编语言（72 讲）

这门课程围绕王爽《汇编语言》教材展开，用 72 集逐章讲解 8086 寄存器、分段寻址、汇编程序结构、流程控制、中断与外设。它比速成课更重视程序如何编译、链接、运行，也保留了较多完整程序和调试过程。

- **原视频**：[通俗易懂的汇编语言（王爽老师的书）](https://www.bilibili.com/video/BV1Wu411B72F) — Bilibili，BV1Wu411B72F
- **全 72 集**，已产出 6 册模块全书、3 篇复习笔记、64 份逐字稿

## 怎么学

这门课的主线是“从 CPU 寄存器到完整程序”，很多概念只有真正跟踪一次程序执行才会稳定，因此要读代码、画内存图、做实验一起推进。

- **建立硬件心智模型** → 模块 01 先吃透寄存器、分段寻址和栈，后面的指令与程序结构才有落脚点
- **跟着程序走** → 模块 02~04 覆盖源程序结构、编译链接、寻址方式、循环、子程序与标志寄存器，建议逐段跟踪执行
- **实验不要跳** → 模块 05~06 涉及移位、直接定址表、中断和端口操作，这些内容是本书从语法走向硬件控制的关键
- **用逐字稿检索原话** → `subtitles/` 有 64 份 `_clean.txt`，适合核对具体命令、寄存器名和实验步骤
