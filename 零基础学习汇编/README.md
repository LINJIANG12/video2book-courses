# 零基础学习汇编（21 讲）

这门课按王爽《汇编语言》的章节顺序，从零讲 8086 汇编：机器指令与存储器、寄存器与物理地址、数据段与栈、汇编程序结构，再一路讲到 `[bx]` 寻址、循环、段前缀与代码段的多段用法。它讲得慢、动手多，几乎每个概念都会在 Debug 和实际程序里跑一遍，适合完全没有汇编基础的人跟练。

- **原视频**：[【汇编语言】零基础学习汇编 (从入门到入坟)](https://www.bilibili.com/video/BV1164y1v7yD) — Bilibili，BV1164y1v7yD
- **全 21 集**，已产出 4 册模块全书、4 篇复习笔记、21 份逐字稿

原合集共 22 个分P，其中「2.3 段寄存器」另有一个音轨不清的废弃版，本整理只取重制版，故实际收录 21 集。

## 怎么学

这门课的主线是“从硬件模型到完整程序”，概念不难，难在把寄存器、内存和指令的对应关系真正跑通。

- **先把硬件模型立起来** → 模块 01 讲透机器指令、寄存器、物理地址与段地址，后面的寻址和程序才有落脚点
- **跟着程序走，别只看概念** → 模块 02~03 从环境搭建一路写到第一个完整程序，建议在 Debug 里逐条跟踪执行
- **实验不要跳** → 查看 CPU 与内存、汇编编程训练、自己写一个汇编程序这三个实验，是这门课从语法走向动手的分水岭
- **用逐字稿核对细节** → `subtitles/` 有 21 份 `_clean.txt`，适合核对寄存器名、指令写法与实验步骤
