考研数学的完整系统课，按「高等数学考研大纲」逐章推进：先建立函数与极限的底层语言，再展开一元微分学、一元积分学、微分方程，最后进入多元微积分与无穷级数。特点是推导不跳步——每个定理都讲清「为什么这样想」，例题按考研真题难度分层训练，配套黑板课专攻易错点与计算技巧。

## 怎么学

- **先读第 1 册**（映射、函数与基本初等函数）。后面所有章节都建立在「函数是分析对象」这个观念上，这册没吃透，后面极限和导数都会变成公式记忆。
- **极限是全课的枢纽**（第 2 册）。把数列极限与函数极限的定义、等价无穷小、两个重要极限、洛必达法则串成一条线，导数的定义才有意义。
- **中值定理是微分学的枢纽**（第 5 册）。罗尔、拉格朗日、柯西、泰勒四个定理串成一条链，后面的单调性、极值、凹凸性、曲线作图全是它们的推论，不要分开记。
- **每章按「概念 → 定理 → 例题 → 黑板课易错点」的顺序过**，配套的【黑板】系列分集专攻计算技巧与易错题型，是这套课区别于普通教材的关键。
- **多元微积分部分（第 10–16 册）体量大**，建议按线代预理（向量代数）→ 偏导数全微分 → 重积分 → 曲线曲面积分这个顺序推进，曲线曲面积分的三大公式是这一大块的收口。
- **考前只看 `notes/`**：14 篇笔记按考点重组，跨章节把公式、适用条件、易错点并排放，适合冲刺期快速过。
