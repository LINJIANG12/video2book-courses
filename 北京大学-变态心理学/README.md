# 北京大学：变态心理学（22 讲）

北京大学心理学专业旗舰核心课程。系统剖析人类心理与行为异常现象的本质机制，从变态心理学的判定基准、生物-心理-社会多维理论模型，一路讲到精神分裂症谱系、心境障碍（抑郁症与双相）、焦虑障碍、强迫症、创伤后应激、躯体形式与解离障碍、进食障碍、物质成瘾、人格障碍与儿童发育病理。课程紧密结合大量真实临床病例讨论，穿透病理现象直击人性复杂性与深层共情。

## 怎么学

课程主线遵循现代精神病理学的诊断分层与多维审视框架：**学科界定与理论模型 → 精神分裂症谱系与心境障碍 → 焦虑强迫与应激解离 → 行为生理相关障碍（进食/成瘾/人格） → 性心理与发育障碍 → 真实临床病例机制推演**。建议：

- **确立多维理论整合视角** → 重点研读模块 01，建立生物学神经机制、精神分析动力学、认知行为与社会文化视角的综合审视框架，杜绝单一因果偏见
- **攻克重性与情感障碍核心主线** → 重点研读模块 02，系统掌握精神分裂症的阳性/阴性症状识别与多巴胺/谷氨酸假说，以及抑郁症、双相情感障碍与自杀危机评估干预
- **吃透神经症性与身心相关障碍** → 重点研读模块 03~05，深入理解恐怖惊恐、广泛性焦虑、强迫行为闭环、癔症解离转化、进食障碍及成瘾奖赏回路
- **把握人格病理与临床综合研讨** → 重点研读模块 06 与模块 04~05 的人格章节，通过复杂临床案例推演共病鉴别与深层心理机制
- **考前/考研速查与脑图导图复盘** → 直接查阅 `notes/` 目录下的 8 篇深度速查笔记，开篇知识拓扑树支持直接导入 Markmap 生成可视化脑图
