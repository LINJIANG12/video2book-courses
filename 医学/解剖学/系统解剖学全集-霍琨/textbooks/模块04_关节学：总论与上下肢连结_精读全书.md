## 椎骨的连结、胸廓与颞下颌关节
> 对应块：BLK07 | 覆盖分集：P10-P11 | 块标题（分集名）：《10.关节学-躯干骨连结》

脊椎看上去是一整根柱子，可它其实是一摞骨块摞起来的。单靠骨头自己，它是站不住的。椎骨之间**借助于韧带、关节、间盘相互连接在一起**——这一讲就顺着这条线往下走：先把椎骨的三种连接方式交代清楚，再退远一步看脊柱整体是个什么形状，然后把范围放大到胸廓，最后跨到颅骨那边，重点啃一个关节：颞下颌关节。

三种连接里，关节连接最省事：它指的是椎骨的**上下关节突**所构成的关节，也叫**椎间关节**，都是一些微动的关节，活动幅度很小，所以这块我不展开，简略说一下就够了。真正要花力气的是韧带和椎间盘这两个——一个关系到脊柱稳不稳，一个直接关系到疼不疼。

不过在往下看之前，得先把手里的挂图判读清楚，不然前后左右一乱，韧带的名字就全记串了。

> **提示**：读这张挂图，第一步永远是判方位——**这是前，这是后**。注意一个细节：图上**上两个椎体被切成矢状切面，下两个椎体是完整的**。我们主要看切面，因为只有断面才能把"贴在表面上的韧带"和"夹在两块骨头之间的结构"同时显示出来。

在矢状切面上，从前向后依次能认出来：最前面这一大块是**椎体**；椎体往后那一层断面，相当于**椎板**；再往后是**棘突**的断面。画这张图的时候有个小手法——凡是被切开的断面，都画成骨松质的网眼，一眼就能看出"这块是切开的"。椎体和椎体之间连着的那块东西，就是**椎间盘**，这个待会儿专门讲。

如果把前面那块拿掉，再往前看一层，能看到**椎弓根**的断面。相邻两个椎弓根之间的骨板，就是**椎板**。再往外，两侧伸出的是**横突**；椎板交界处往上翘的是**上关节突**。

至于椎骨的**上面观**，结构更简单：前方是椎体，后方是椎孔，椎弓根连在椎体和椎板之间，两侧是横突，后正中收成一个尖——棘突。

```text
                        棘 突（后正中，最细最长）
                            ▲
        椎 板 ════╮   ╭───┴───╮   ╭════ 椎 板
                 │   │       │   │
        横 突 ◀───┤   │ 椎  孔 │   ├───▶ 横 突
                 │   │       │   │
        椎弓根 ───┴───┴───────┴───┴─── 椎弓根
                             │
                          ┌──┴───┐
                          │ 椎 体 │  ← 前方
                          └──────┘
```

图里最上面是后方，最下面是前方：椎体在最前面，椎弓根从椎体两侧向后撑开椎板，椎板在后面围出一个椎孔，横突向左右伸出，棘突孤零零地伸在最后面。这张图看熟了，后面几乎所有韧带的位置都能自己推出来。

### 椎骨的韧带连接

先说韧带。椎骨的韧带按位置从前往后捋一遍，一共这么几处：**椎体前方、椎体后方、椎板之间、棘突之间、棘突尖以上**，另外还有**横突之间**的一小群。

#### 椎体前后的两条长韧带

**前纵韧带**在椎体的前方。从图上一眼能看出来，它在椎体前方下降，**范围包得很大**，而且它是**很长的一根韧带，从颅底一直延伸到尾骨**。

它的特点有三个：位置上在椎体前方；形态上**比较宽厚**；还有一个关键的特点——**与骨结合得紧密**。什么叫紧密？就是问一句：它和骨面容不容易分离？**不容易分离**。

**后纵韧带**在椎体后方下降，同样是长韧带。但它的特点跟前面那根恰好是反着来的。

> **易错点**：这一对是最容易记混的，因为它们的关键词正好摆对着。**前纵：宽厚、紧密结合**；**后纵：窄薄、结合疏松**。后一条先记住——它不是在这儿用的，后面讲椎间盘突出的时候，会直接拿它当推导的钥匙。

后纵韧带为什么窄？为什么薄？大家看，是不是**受到椎管的限制**？椎管就那么宽，韧带想宽也宽不了，所以又窄又薄。而它和骨面结合得比较**疏松**，翻译过来就是：这个韧带和椎体的骨面**容易分离**。

| 对比项 | 前纵韧带 | 后纵韧带 |
| --- | --- | --- |
| 位置 | 椎体前方 | 椎体后方 |
| 长度 | 长韧带，颅底直到尾骨 | 长韧带 |
| 形态特点 | 宽厚，包绕椎体的范围比较大 | 窄而薄——受椎管限制，宽不了 |
| 与骨面结合 | 紧密，不容易分离 | 疏松，容易分离 |

#### 椎板与棘突之间的短韧带

**黄韧带**在**椎板与椎板之间**。看图：它从椎弓根这块开始，往上、往下都有。椎弓根是椎板的上端，所以黄韧带就长在相邻两个椎板之间——这是一个**短韧带**。

它的意义在于：椎管的后壁，并不只是椎板自己。把图上那一片数一数就明白了——**椎管的后壁，除了若干个椎板以外，还有若干个黄韧带**，两者共同构成。

> **定义**：椎管后壁 = 若干个椎板 + 若干个黄韧带。

**棘间韧带**在棘突和棘突之间，位置跟黄韧带有点像，但对象换了：它跨的是棘突而不是椎板。同属**短韧带**。

**棘上韧带**在棘突尖的上方，从下往上连着棘突尖。它是**长韧带**。

接下来是**项韧带**。棘上韧带走到颈部，也就是项部，这一段**增宽**了，增宽以后我们给它改了个名字，叫**项韧带**。

看颈椎棘突这一串就明白它为什么要加宽了。上端连着颅骨，往下一节一节地数：最上面那个寰椎（第一颈椎）只有后弓，是没有棘突的；接下来颈椎的棘突很短，第二、三、四、五、六颈椎的棘突**越来越长**，到**第七颈椎最长**；再往下就是第一胸椎、第二胸椎，不画了。而棘上韧带就是**在棘突尖上由下往上去的一根韧带**，走到项部变宽，就改名成了项韧带。

> **提示**：项韧带和棘上韧带是什么关系？两个方向都能说：**项韧带是棘上韧带在项部增厚了**；或者说，**项韧带向下就移行为棘上韧带**。它们本来就是一根。

最后还有**横突间韧带**，在横突与横突之间，也是一些**短韧带**。

```text
                        后方
                         │
                    ┌────┴────┐
                    │ 棘上韧带 │   长　棘突尖之间
                    │    │ │   │
                    │  ┌─┴─┴─┐ │
                    │  │棘间  │ │   短　棘突之间
                    │  │韧带  │ │
       椎弓根 ─────┤  ├─────┤ ├───── 椎弓根
                    │▒▒│椎板 │▒▒│      黄韧带　短
                    │▒▒│     │▒▒│      ▒ 与椎板共同构成椎管后壁
                    │   ├─────┤ │
              前纵 │   │椎体 │ │ 后纵   ← 椎间盘（纤维环＋髓核）
```

这张图把前面五条韧带一次串起来：从前向后是前纵韧带（贴椎体前面）、椎体、后纵韧带、椎管，再往后是椎板与黄韧带、棘间韧带、棘上韧带。剩下的横突间韧带长在左右两侧，矢状面上看不到，图里没画。

### 椎间盘：两个椎体之间的软骨垫

#### 构造：纤维环加髓核

先说间盘的构成。椎体的**上方中间**有些**胶冻状的结构**，周围则形成了一个个**同心圆排列的软骨环**。因为这个排列是人为地划出来的，所以把间盘分成两部分：位于周围的那一圈软骨环，叫**纤维环**；位于中心的那个胶冻状的结构，叫**髓核**。

> **定义**：椎间盘 = 纤维环 + 髓核。它卡在两个椎体之间，形成一个软骨垫，作用是减少椎骨之间的震动。

```text
                上位椎体
          ╭─────────────────╮
          │    ╭─────────╮   │
          │    │ · · · · │   │   外层：纤维环
          │    │╭───────╮│   │   （同心圆排列的软骨环）
          │    ││· · · ·││   │
          │    ││  髓核 ││   │   中心：髓核（胶冻状）
          │    ││· · · ·││   │
          │    │╰───────╯│   │
          │    ╰─────────╯   │
          ╰─────────────────╯
                下位椎体
```

从断面上看，纤维环是一圈套一圈的软骨环，髓核被严严实实地围在正中间，性质像一块冻着的果冻。

#### 突出：一次搬缸的用力

间盘的第二个内容是**突出**。原理其实很直白：如果**纤维环破裂**了，上面和下面两个椎骨相互作用、互相一挤，就容易把里面胶冻状的结构挤出去，这就叫**突出**。

这种情况最常见的诱因是——**突然的腰部用力**。

我过去见到过这样一个患者。他在自家的小厂房里挪一口缸，那厂房门比较矮，缸往外挪的时候不得劲儿，只能先用腿把缸搬一下，然后非常吃力地一点一点把它挪过门去。就是在这么个"慢慢使劲"的状态下，**他突然一用力，人当时就跪倒在地下了**。这说明肯定有结构受压了。

什么结构受压了？顺着这个思路一步步推：

```text
      上下椎体相互挤压（突然的腰部用力）
                    ↓
         ┌──────────────────┐   上位椎体
         │     纤维环       │
         └────────┬─────────┘
                  │  纤维环破裂，髓核被挤向后下方
                  ▼
         ┌──────────────────┐   下位椎体
         │▓▓ 髓核 ▓▓ ──────┼──▶  挤出
         └──────────────────┘      │
                    ── 椎体后缘 ─┼────│
                                    │
                 后纵韧带 ─────────┼───▶│  与骨面结合疏松，
                        （疏松！）    │     所以跟着髓核一起向后突出
                                    ▼
         ┌──────────────────────────────────┐
         │ 椎管：马尾神经密集排列成束 → 受压 │
         └──────────────────────────────────┘
```

这里有同学要问了：**那还有韧带挡着呢，髓核怎么可能挤得出来？**

这个疑问正好把前面埋下的伏笔用上了。请你回头再看一眼**后纵韧带**的特点——**与骨面结合得疏松**。既然它是疏松的，那这时候它就不会死死钉在椎体后缘上，而是**跟着髓核一起向后突出了**。挡不住。

那**椎管里边的结构受不受压**？受压。而且这件事**一般多半发生在腰椎**。

为什么偏偏是腰椎？因为腰椎的椎管里**密集排列成束的是马尾神经**。马尾神经一旦受压，**下肢就产生了一系列临床改变**——这就是间盘突出在临床上表现出来的样子。

> **结论**：一条链子串起来——突然的腰部用力 → 纤维环破裂 → 髓核向后突出 → 因为后纵韧带与骨面结合疏松，所以它挡不住、跟着一起突出 → 椎管内马尾神经受压 → 下肢出现一系列临床改变。四个环节，缺一环这条推导就走不通，所以每一环都得记住。

### 脊柱的整体观：四个生理弯曲

椎骨怎么连的讲完了，接下来换个方向：不看单块骨头，看整根脊柱。我们从三个方向去看它。

**从后方看**脊柱，应该是什么样子？就是在一条直线上。两侧是肩胛骨，**脊柱所有的棘突应该在一条直线上**。这就是后边观。

**从前面看**，主要看的是椎体。椎体**从上到下由小变大**，一直到**骶骨的上缘最宽**；可当力作用到下肢以后，骶骨的下边是不是**越来越窄**了？所以它前面的规律是：**由小变大，由大又变小**。

**侧面观是重点，一定要记住。** 脊柱侧面有几个弯曲呢？颈部一个，胸部一个，腰部一个，骶尾部一个——加起来四个。我们分别管它们叫**颈曲、胸曲、腰曲、骶尾曲**。

```text
        前方 ←                              → 后方

                ╭────╮                       颈曲（凸向前）
           ╭────╯    ╰─╮
                       ╰────╮                  胸曲（凸向后）
           ╭───────────────╯
                 ╭─────────╮                    腰曲（凸向前）
           ╭─────╯         ╰───╮
                               ╰──╮             骶尾曲（凸向后）
   ─────────────────────────────────────────
        颈椎段        胸椎段    腰椎段    骶尾椎段
```

> **结论**：脊柱侧面观有**四个生理弯曲**——颈曲、胸曲、腰曲、骶尾曲。

那这四个弯曲里，**哪些是先天具备的，哪些是后天形成的**？看一个胎儿就知道了。

这是一个胎儿，带脐带、胎盘。你看它的脊柱，**先天就具备了两个弯曲**：一个是**胸曲**，还有一个是**骶尾曲**。

然后再看出生以后：孩子**会爬了、能抬头了**，**颈曲**就出现了；**会坐了、会站了**，**腰曲**就出现了。

所以答案很清楚：**先天有胸曲和骶尾曲，后天有颈曲和腰曲**。

> **易错点**：这里最容易记反的是后天的两个。**抬头出颈曲，坐站出腰曲**——记住这两句就行。

### 胸廓

把视野从脊柱挪开，我们来看围着它的另一个结构：胸廓。这一部分我从五个角度讲：组成、连接、特点、上下口、体表标志。

#### 组成与连接

**组成**很简单，就三部分。从前方看这张胸廓图：前方这一块是**胸骨**，两侧的是**肋**，后方的叫**胸椎**。所以胸廓由**胸骨、肋、胸椎**三大部分构成。

**连接**分前方和后方两路。

前方的连接是**关节连接**，叫**胸肋关节**，由胸骨和肋软骨构成。这里有个范围要记牢：**胸肋关节局限在 2 到 7**。为什么？因为**第一肋骨是软骨结合，没有形成关节**——它只是用软骨直接连到胸骨上。所以真正形成关节的，是**第 2 到第 7 肋和胸骨之间**的这些。

后方的连接看板图。先复习一下椎体的结构：椎体、椎孔、椎弓根、横突、棘突。肋骨怎么接上去的？肋骨上有两个东西——**肋骨小头**和**肋结节**，正好对应椎体的两个地方，形成**两个关节**：一个是**肋头关节**，一个是**肋横突关节**。这两个合起来，构成后方的**肋椎关节**。

> **结论**：胸廓前方靠**胸肋关节**（胸骨 ↔ 肋软骨，2～7 肋）连接，后方靠**肋椎关节**（肋头关节 + 肋横突关节）连接，两条路一起把肋骨固定在胸骨和脊柱上。

#### 三个特点

接下来是胸廓的**特点**，一共三个，一个一个看。

**第一个：上窄下宽。** 从前方观察胸廓，上面和下面的横径是不一样的，上面窄、下面宽。

**第二个：前后径小于左右径。** 为了看清这个，我给胸廓做一个**水平断面**。断面上后边是脊柱（这是后，这是前），两侧是肋，前方是胸骨。断面上量两个方向——**这是前后径，这是左右径**，比一比谁长谁短。结论是**前后径小于左右径**。

> **提示**：这个关系记住了，就等于同时记住了一个临床征象。**如果前后径和左右径相等了，那就不是正常了**。临床上有一种**桶状胸**，见于**肺气肿**，桶状胸的特征就是**前后径和左右径相等**。所以别把"前后径小于左右径"当成一句干巴巴的描述——它是用来跟桶状胸做对照的。

**第三个：脊柱凸入胸廓内。** 断面上一眼能看见：脊柱的断面**凸入到了胸廓的腔内**，这样就在脊柱两侧各留下一条凹陷，形成**两侧的肺沟**。

> **结论**：胸廓的三个特点——**上窄下宽**、**前后径小于左右径**、**脊柱凸入胸廓内**。

#### 上下口

特点讲完了，接着说胸廓的**上下口**是怎么围成的。

**胸廓上口**。看挂图：上方是**胸骨柄**，柄上缘有一个切迹叫**颈静脉切迹**；两侧是**第一肋**；后方就是**第一胸椎**。这三条围成的口，就叫**胸廓上口**。

**胸廓下口**。前方是**剑突**，两侧是**肋弓**，再往后能看到 11 肋、12 肋的**下缘**，最后到**第 12 胸椎**。

```text
                前方
   ┌────────────────────────────────────┐
   │  颈静脉切迹（胸骨柄上缘）            │   ← 胸廓上口
   └────┬──────────────────────────┬─────┘
      第一肋                    第一胸椎
                 ╲                ╱
                  ╲    胸  廓    ╱
                   ╲            ╱
   ┌────────────────┴──────────┴─────┐
   │  剑突                          │      ← 胸廓下口
   └────┬──────────────────────┬────┘
       肋弓          11、12 肋下缘    第 12 胸椎
```

这两个口结构对称着记，一句话各带走一套：

> **结论**：上口 = **颈静脉切迹 + 第 1 肋 + 第 1 胸椎**；下口 = **剑突 + 肋弓 + 第 11、12 肋下缘 + 第 12 胸椎**。

#### 体表标志

最后是**体表标志**。这一项是给临床用的：身上有几个地方一摸就能摸到，摸到了就能定位里面的东西。

第一个是**胸骨角**——就是**胸骨柄与胸体交界处向前凸的这个骨性隆起**。它两侧对应的正好是**第二肋**，所以**利用它可以计数肋骨**：摸到胸骨角，往下数第一根肋就是第二肋。

第二个是**剑突**，下方这个尖，体表能摸到。

第三个是**肋弓**，两侧的，体表也能摸到。

第四个是**胸骨下角**。这个要多说两句：整个的这个角叫**胸骨下角**，但它自己还会**分成两个角**——这侧的是**左侧剑肋角**，右侧的是**右侧剑肋角**。合起来才是整个的胸骨下角。

> **结论**：胸廓的体表标志有四个——**胸骨角、剑突、肋弓、胸骨下角**（其中胸骨下角又分为左、右剑肋角）。这几个知道一下就行。

到这里，躯干骨的连接就算讲完了：脊柱是怎么连的，胸廓是怎么连的。**请把椎骨的连接形式和胸廓的特点作为重点掌握**，尤其是胸廓的三个特点。

### 颞下颌关节

下面把范围换到颅骨。颅骨的连接里，我们重点只讲一个关节：**颞下颌关节**。这一个关节讲透了，整个颅骨连接就抓住了。

#### 关节的构成

先看构成。回忆一下颅骨的侧面观：鼻骨、上颌、眶、颧骨，然后注意这一块——**关节结节、下颌窝、外耳门、乳突**；再往下是下颌骨，有**下颌头（髁突）**、**喙突**，最前面是门齿。

要看的就是关节窝附近这一小块。颞下颌关节由下面这些结构组成：

**关节凸**，在下方，来自下颌骨，叫**髁突**，也叫**下颌头**——这两个名字指的是同一个东西。

**关节凹**，在上方。这个要把图放大看。放大之后能看到颧弓的剖面（同样画成骨松质的网眼），前方隆起的是**关节结节**，后方凹陷的是**下颌窝**，它们俩构成了关节凹。**这两个都是颅底的结构。**

**关节囊**，从前方到后方整个把关节包住。看图的时候要留意：你看到的关节囊那一片**一定是个剖面**。

**关节盘**，在关节囊里面，是一块**软骨板**。

> **定义**：颞下颌关节的构成——关节凸为下颌骨的**髁突（下颌头）**；关节凹为**关节结节 + 下颌窝**；外面包着**关节囊**，囊内有一块**关节盘**。

#### 三个结构特点

**第一个特点：关节囊薄而松。** 囊薄而松，**有利于这个关节的灵活性**——道理很直白，包得越松，活动度肯定越大。

**第二个特点：囊内有关节盘，把关节腔分成上下两个腔。** 因为关节盘的存在，**关节腔被分为上下两部分**，上面有一个腔隙，下面有一个腔隙。

这一点可以打一个很妙的比方。请看黑板上的示意：

- 关节盘的**凸面**和颅底的**骨性凹面**，是不是也构成一个关节？
- 关节盘的**凹面**和**髁突的凸面**，是不是又构成一个关节？

```text
        前方（颧弓侧）                          后方
  ┌──────────────────────────────────────────────────┐
  │        关节结节                                    │
  │          ╱╲                 外耳门 │                │
  │     下颌窝 ╲                       │                │
  │        ╱╲  ╲   ▒▒▒▒ 上腔 ▒▒▒      │                │
  │       ╱  ╲══╲══════════════════│ ← 关节盘         │
  │      ╱      ╲   ░░░ 下腔 ░░░                        │
  │     ╱   髁突（下颌头）                               │
  │        喙突                                          │
  │                                                      │
  │ ▒▒▒▒▒▒▒▒▒▒ 关节囊：薄而松，把整个关节包住 ▒▒▒▒▒▒▒▒ │
  └──────────────────────────────────────────────────┘
        囊外：外侧韧带
```

读图：关节盘是一块斜着的隔板，上方那个腔是**上腔**（盘凸面与颅底骨性凹面围成），下方那个腔是**下腔**（盘凹面与髁突凸面围成）；整个关节被薄而松的关节囊包住，囊外还挂着外侧韧带。

一个关节盘，把原来的一个关节劈成了两个关节，等于**形成了一个复合关节**——两个关节叠在一起协同运动，这个关节自然就更灵活。

**第三个特点：囊外有韧带。** 把图恢复到原来的样子看：颧弓、关节结节、下颌窝、外耳门、乳突、喙突、下颌角，整个都被关节囊包裹。而在**关节囊外侧**，还有一条韧带，叫**外侧韧带**。

> **结论**：颞下颌关节的三个结构特点——**囊薄而松**（灵活）、**囊内有关节盘把关节腔分成上下两腔**（复合关节，更灵活）、**囊外有外侧韧带**。

#### 运动与脱位

第三，看这个关节的**运动**。下颌关节可以**上下**、可以**前后**、也可以**左右**。所以它的运动**很灵活**，三个方向都能走。

第四，稍微讲一下它的**脱位**。记住一句话：**灵活的关节都容易脱位**。

那下颌关节容易往哪个方向脱位？回到下颌的解剖上看。**髁突正好坐在关节凹里面，而它脱位方向的后边紧挨着粗大的乳突**——后面被乳突顶住了，所以**它只能往前脱**。

> **结论**：下颌关节的脱位**只有前脱位**，没有后脱位。

这一段再补一个常识，大家记一下。看这张图：颧弓、颧骨、关节结节、下颌窝、外耳门、乳突都在。

**正常情况下，下颌头在哪儿？在下颌窝里。** 那当我们的嘴**张到 15 度**的时候，髁突到哪儿去了？它跑过来了——跑到**关节结节最高点的下方**。这个 15 度角，**就是最不稳定的位置**。

如果再继续张嘴呢？再看图，**整个都是向前滑动**，髁突跑到了**关节结节的前方**。到了这个位置就是**不可逆**了——**不能自行回位**。

```text
        闭口              张口约 15°            张口 > 15°
     ┌──────────┐      ┌──────────┐        ┌──────────┐
     │ 关节结节 │      │ 关节结节 │        │ 关节结节 │
     │  ▒▒▒▒▒   │      │  ▒▒▒▒▒  │        │ ▒▒▒▒▒   │
     │ ▒ ⊙ ▒    │  →   │▒   ⊙  ▒ │   →    │▒ ⊙  前方│
     │  ▒▒▒▒▒   │      │  最不稳定│        │  不可逆  │
     │  ⊙髁突   │      │  ⊙髁突   │        │  ⊙髁突   │
     │  下颌窝  │      │  最稳定  │        │          │
     └──────────┘      └──────────┘        └──────────┘
```

现在回答：下颌关节**什么原因容易造成脱位**？

第一个原因刚才其实已经出现了——像刚才大家做的**微笑**，如果再**大笑**，就容易脱位。第二个原因是**打哈欠**，也容易脱位。

这里边我特别想提醒大家的是第三个原因：**暴力拔牙**。

有同学可能会问，拔牙怎么能脱位呢？你想想拔牙时的情形——医生是不是**总是让你张大嘴**，他操作起来才方便？

我见过这样一个患者。拔牙的时候疼了个够呛，医生说嘴张大点儿，他就开始张，后面系了个小围裙。最后牙确实是拔下来了；没打麻药，所以也疼得不得了。拔完他特别生气，说这医生拔牙怎么这么不打麻药就给拔下来了。

然后，**拔完之后患者就出现变化了**。看图上这几点：**大汗淋漓**，注意，**口水都出来了**。什么原因？**脱位了。**

那么脱位的**临床表现**是什么？一条一条数：

- **第一个，下颌前移**，所说的**兜齿**；
- **第二个，不能说话**，也不能**吞咽**。大家想，张着嘴你怎么吞咽？吞不了，口水是不是就流出来了；
- **第三个，耳廓的前下方有一个明显的皮肤凹陷**。

这个凹陷值得多说两句，因为它在正常人身上也摸得到。**现在张嘴的时候，你都能摸到这个凹陷；闭嘴它又回去了。** 可是脱位的时候呢？髁突本该在这个位置，现在脱到前面去了，**这块就空出来了，形成一个凹陷**——位置变了，反过来就成了标志。

> **结论**：下颌关节脱位的临床表现——**下颌前移（兜齿）、不能说话、不能吞咽、流口水、耳廓前下方皮肤凹陷**。

最后，**怎么复位**？医生的**两个拇指**伸进患者的口腔去推。推之前有一件事必须做——**绷带一定要保护好，缠厚点儿**，因为拇指是要压在下颌骨前缘上的，牙齿可能直接伤到医生自己。

推的方向记两个动作：脱位了**先向下压**，然后**再向后上推**，就复位了。

到这里，颅骨连接里我们需要重点记住的东西就一个：**颞下颌关节**。

> **承前启后**：上一节讲完「椎骨的连结、胸廓与颞下颌关节」，下一节接着讲「上肢骨的连结：肩、肘、腕怎么接在一起」。

## 上肢骨的连结：肩、肘、腕怎么接在一起
> 对应块：BLK08 | 覆盖分集：P12 | 块标题（分集名）：《12.关节学-上肢骨连结》

上肢骨不是一个整块，拆开看是两截。靠内侧那一截是肢带骨——锁骨和肩胛骨，任务只有一个：把上肢挂到躯干上；外侧那一截是自由骨——上臂的肱骨、前臂的桡骨和尺骨、再往下的手骨，全靠关节一个接一个串起来。

连结也按这两截来记。肢带骨那一截简单得有点不讲道理：大家记住两个关节、知道它们在哪儿，就够了。真正要花时间的是自由骨，从肩一路数到腕，这一讲的内容基本都在这儿。

### 肢带骨的连结：两个关节，记住位置就行

从上方看人体，胸部这一侧是躯干，肩部这一侧就是肩带，中间横着的就是锁骨。锁骨呈 S 形，内侧端这一头粗，外侧端那一头扁——它外侧端搭着的不是骨头，是一个突起，叫肩峰。

```text
            胸骨
             │   ← 胸锁关节
        ┌────┴────┐
        │  锁  骨 │   （S 形，内侧端粗、外侧端扁）
        └────┬────┘
             │   ← 肩锁关节
           肩峰 ──── 肩胛冈
             │
        关节盂   喙突

        肩胛切迹 · 上角
```

读图说明：整个肩带只靠两处铰接在躯干上——内侧端与胸骨相接，外侧端与肩峰相接；肩胛骨上能一起认出来的还有肩胛冈、关节盂、喙突，以及肩胛切迹和上角。

所以要记的就是这两个：

- **胸锁关节**：前方这一个，锁骨内侧端和胸骨相连；
- **肩锁关节**：外侧这一个，锁骨外侧端连着肩峰。

> **结论**：肢带骨的连结 = 胸锁关节 + 肩锁关节。这一节只管位置，不用记更多。

### 肩关节：全身最灵活的关节，也因此最容易脱位

下面全是自由骨。第一个上场的是肩关节。

我们先看挂图，一共三张，一张一张换角度，把同一个关节拆开给你看。

第一张是从前方看右侧肩关节。这一眼看到的这一大片就是关节囊，囊的前方顶着两个突起，上面这个宽的是肩峰，前面这个尖的是喙突。关键在囊的下方：有一个肌腱从囊里面穿出来，叫**肱二头肌长头腱**。

第二张是肩关节的冠状切面。断面上，壁是关节囊，中间那个空腔是关节腔。构成这个关节的两块骨一望就知道：这个凹形的关节面在肩胛骨上，叫**关节盂**；这个球状的关节面在肱骨上，叫**肱骨头**。腔里又露出一个细条状结构从囊里钻出去——还是刚才那个肱二头肌长头腱。注意它这一段是走在**关节腔里面**的，这是肩关节很不一样的地方。

第三张换了个更狠的角度：从外向内看，把肱骨整个拿掉。拿掉以后，剩下那个浅盘状的关节面暴露出来，就是关节盂。这时候盯住关节面的周缘——有一圈环状的软骨结构，叫**关节盂缘**。它是周围厚、中心薄，正好用来把这个本来就浅的关节凹加深。刚才那根被切断的长头腱因为断了，就悬在那里，从上往下能看清楚它起自关节腔、也就是关节盂的上方，然后穿过关节腔出来。

三张图看完，胸有成竹了。肩关节我们按四件事来捋：构成、特点、运动、脱位。

#### 一个头，一个盂

> **定义**：肩关节由**肱骨头**（球状关节面）与**肩胛骨关节盂**（浅盘状关节凹）构成。

肱骨头的关节面我们在骨学那一讲已经学过，就是个球；关节盂是肩胛骨外侧的浅盘状凹陷，旁边挂着喙突，上方是肩峰。一个盂，一个头，这就构成了肩关节。

#### 四个特点

先看关节面。从断面图上比一比：关节盂的关节面比较小，肱骨头的关节面面积比较大。

> **结论**：肩关节第一个特点——**头大、盂小（盂浅）**。

盂浅这件事不是缺陷，它有专门的补救办法：就是刚才在第三张图上看到的关节盂缘，围在关节盂周缘一圈，把关节凹加深。记住这句就行：**关节盂周围有关节盂缘，用来加深这个关节**。

第二个特点在关节囊上。

> **结论**：肩关节第二个特点——**关节囊薄而松弛**。

大家设想一下：囊又薄又松，那关节腔是不是就大？腔大意味着什么？意味着这个关节肯定灵活，运动幅度肯定大。前后壁尤其薄弱，所以肩关节能做出那么大的动作。

囊薄而松，稳定性就得靠别的东西来补，于是有第三个特点。

> **结论**：肩关节第三个特点——**囊外有韧带加固**，其中有一条**喙肱韧带**，知道这个名字就行。

第四个特点，就是我们反复在三张图上看到的那根腱。

> **结论**：肩关节第四个特点——**关节腔内有肱二头肌长头腱通过**：起自关节盂上方，在关节腔内穿过，再穿出关节囊。

四个特点合起来：头大盂浅、囊薄而松、囊外有韧带、腔内走肌腱。

#### 运动：全身最灵活

- 往前去，**屈**；往后去，**伸**——前屈后伸；
- 向外，**外展**；向内，**内收**——外展内收；
- 肱骨自己的**旋内、旋外**；
- 另外还可以做**环转**。

讲到屈曲的时候他特意顿了一下：注意屈曲 90 度。

> **结论**：肩关节是**全身最灵活的关节**。灵活到这个程度，就埋下了下一个问题的伏笔。

#### 脱位：往前下方跑，肩就变"方"了

灵活的关节通常都带一个缺点：容易脱位。肩关节最容易往**前下方**脱。

X 线片子最好认：肱骨头从关节盂里跑出来了，滑到了关节盂的前下方；肩峰相对地明显向外突出——这个就叫前脱位。

前脱位在体表上有两个很典型的表现：

**第一，方肩。** 为什么？肱骨滑到前面去了，肩胛骨没动，那么肩峰相对就"翘"出来了，肩膀的正常圆隆外形被抹平，肩峰和锁骨那一段变成一个方棱角，摸着像"方肩"。

**第二，搭背实验阳性。** 正常人自己的手能搭到后背。肩关节一脱位，患者就够不着了——把手往后背方向搭，搭不过去，这就是搭背实验阳性。

```text
   正常                            肩关节前脱位
   ┌────────┐                    ┌────────┐
   │  肩峰  │ ← 圆隆            │  肩峰  │← 向外突出 → 方肩
   └───┬────┘                    └────┬───┘
       │ 锁骨                        │
                                    │ 锁骨
   手可搭到后背 ✓                   手够不到后背 ✗ → 搭背实验（+）
```

读图说明：脱位后肩峰相对肩胛骨向外突出，圆隆外形变成方角；同时手的内旋后伸动作受限，搭背实验转为阳性。

### 肘关节：三根骨凑成一个关节

看完肩，接着往下走，到肘。

看挂图：这张是从前方看肘关节的，能看到的这一些都是关节囊——上面是肱骨，下面是尺骨和桡骨。这张是矢状切面：上面那根圆形的关节面是**肱骨滑车**；尺骨这边，**冠突**在前、**鹰嘴**在后，它们中间那道凹面就是**滑车切迹**，正好是尺骨上端的关节面。而且看得很清楚，**正是在肱骨和尺骨相接的部位被切断的**——断开之后，肘关节的特色一下子就露出来了：前方的关节囊薄，后方的关节囊又薄而又松弛。前后都薄而松，两侧就靠韧带顶住。

顺着切面再往里找，还有一个结构：**桡骨小头环状韧带**，它和关节囊几乎融成了一体，它的起止关系我们待会儿单独说。

肘关节也按构成、特点、运动、脱位这四件事来捋。

#### 构成：三骨、六面、三关节

什么叫三骨六面三关节？先数骨。

**肱骨下端**有两个关节面：一个是**肱骨小头**，另一个是滑轮状的**肱骨滑车**。

**桡骨上端**也是两个面：小头上方朝上的那个凹面，以及桡骨小头周围那个环状关节面。

**尺骨上端**同样贡献两个面。

三个骨、六个关节面，接下来把它们两两配对成关节：

| 关节面 | 配对 | 组成的关节 |
| --- | --- | --- |
| 肱骨小头 | 桡骨小头上方的凹面（头凹） | **肱桡关节** |
| 肱骨滑车 | 尺骨的滑车切迹 | **肱尺关节** |
| 桡骨小头的环状面 | 尺骨上端的桡切迹 | **尺桡近侧关节** |

> **结论**：肘关节 = **三骨（肱骨、桡骨、尺骨）、六面、三个关节（肱桡关节、肱尺关节、尺桡近侧关节）**。

这个"三骨六面三关节"是肘关节最好记也最好用的一句话，看到肘就该条件反射地念出来。

#### 三个特点

**第一，囊薄而松。** 矢状剖面上看得很清楚。这一点还有个直接后果：肘关节在结构上就被"锁"在屈伸这个方向上了。

**第二，囊外有韧带加固，两侧各一条。** 沿着上下走行的方向看，挂图两侧各有一条韧带：因为角度的关系有一侧不太明显，但两条都是上下走的。尺骨这一侧叫**尺侧副韧带**，桡骨这一侧叫**桡侧副韧带**。两侧副韧带一加强，肘关节的横向稳定性就出来了。

**第三，桡骨小头周围有环状韧带。** 这个必须解释清楚它到底怎么连的。

把桡骨和尺骨画出来看：桡骨头在上，尺骨的冠突在前、鹰嘴在上后方，冠突和鹰嘴之间就是滑车切迹。这条韧带**起于尺骨上端的后方，绕到尺骨上端的前方，呈漏斗状**，正好**环抱桡骨颈**。

```text
  尺骨上端                                      尺骨上端
   后方：鹰嘴                                     前方：冠突
      ●━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━●
      ┃           环 状 韧 带（漏斗状）           ┃
 ┌────╂━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━╂────┐
 │    ┗━━━━━━━━━━━━━━━━┳━━━━━━━━━━━━━━━━━━━━━┛    │
 │                     桡   骨   颈                 │
 │                （桡骨小头在它的上方）              │
 └────────────────────────────────────────────────────┘
```

读图说明：环状韧带是一圈漏斗形的纤维束，后端起自尺骨鹰嘴一侧，前端止于尺骨冠突一侧，中间围成一个环把桡骨颈套在里面——这也是为什么桡骨小头在环状韧带里还能转。

> **易错点**：环状韧带环绕、环抱的是**桡骨颈**（桡骨小头下方那一段），不是桡骨小头本身。

#### 运动：屈伸为主，另有旋前旋后

前面说过，囊前后薄而松，肘关节在结构上被锁在屈伸这个方向上，所以它的运动**主要是屈伸**。

不过别记死，讲到运动这一条时他补了一句：除了屈伸，**还可以做旋前、旋后**。

#### 两种脱位：后脱位和桡骨小头半脱位

**后脱位。** 屈到 90 度的时候看这个咬合关系：肱骨滑车后边是**鹰嘴窝**，窝深；前边是**冠突窝**，窝浅。90 度屈曲状态下，鹰嘴和冠突正好把滑车夹在滑车切迹里，咬得很死。

那为什么会脱？摔倒了，手杵地，外力是从前面来的。前面本来就是浅的——冠突窝浅，滑车切迹的后缘挡不住往前的推力，**冠突就容易滑到滑车切迹的后方去，造成后脱位**。

```text
  屈肘 90°：滑车嵌在切迹里
      ┌────────────┐
      │  肱骨滑车  │
      └──┬──────┬──┘
      后 │      │ 前
   鹰嘴窝(深)  冠突窝(浅)
         │      │
     鹰嘴 ┄┄┄┄┄┄┄┄ 冠突    ┄＝滑车切迹

  摔倒手杵地：外力顶在浅的一侧
  ┌────────────┐
  │  肱骨滑车  │ ← 尺骨整体后移
  └────────────┘   ┌──────┐
                   │ 冠突 │ ← 越过切迹后缘，跑到滑车后方
                鹰嘴┤      │
                   └──────┘
```

读图说明：手杵地时力量自前向后，而关节前方只有浅的冠突窝承接，冠突一旦越过滑车切迹的后缘，尺骨（连同桡骨）就整体滑到肱骨后面去了。

后脱位在体表上看得见吗？看得见。冠突跑到后边去了，那后边自然就**鼓起来一个包**，隔着皮肤就能摸到。

**桡骨小头半脱位。** 前面刚说过，桡骨小头是被环状韧带环抱着的。什么情况下算半脱位？**小头从环状韧带里衬出去，和肱骨小头分离了**，这就叫半脱位。但注意——**和尺骨的那一关节还是咬合在一起的**，所以它是不完全的脱位，只是"它跟肱骨脱了位"而已。这种情况**多发生在 4 岁以下的小孩**。

怎么发生的？他讲了两例患者，都是小孩被大人拽手臂拽出来的：

**第一例**，一个年轻的妈妈领着孩子上医院打针。孩子肯定不愿意去，小孩就往回挣，妈妈在前面拽，拽了一会儿孩子哭了。妈说怕打针嘛，哭吧；到医院打完针，还哭；妈妈又给买点小食品，拿着小食品接着还哭。一看，桡骨小头半脱位。给拽下来了。

**第二例**更有意思：一个海员的爸爸，一出海就是半年，回来以后见着儿子喜欢得不得了，陪儿子玩。怎么玩呢？抡圈——把孩子抡起来转圈。孩子乐得呱呱叫，不一会儿哭了。孩子爸爸很不高兴："你看逗你玩你还哭。"能不哭吗。俩都拽下来了。

那半脱位了怎么复位？

- 先做一个动作：把小孩的上肢**直接外旋**，基本上就可以复位了；
- 如果还不能复位，那就给他做个**屈曲**——**一定要摁压桡骨小头**，然后屈曲，**听到一声响就复位了**。

> **结论**：肘关节常见的脱位就两种——**后脱位**（摔伤手杵地，冠突滑过切迹后缘，体表后方鼓包）和**桡骨小头半脱位**（4 岁以下小孩被牵拉所致，与肱骨小头分离但与尺骨仍咬合，牵拉肘）。

### 前臂骨的连结：上下两个关节，中间一张骨间膜

接下来看前臂骨，也就是桡骨和尺骨之间怎么连。这一块大家只需要记住**三个名词**。

先把两骨画全：桡骨那边有小头、体、粗隆、茎突；尺骨那边有冠突、鹰嘴、干、头、茎突，还有尺骨粗隆。

桡尺骨之间的连结就是三个东西：

```text
        ═══════════════════════════════
              尺桡近侧关节（靠肘那端）
        ┌────────────────────────────┐
        │  尺 ┃║║  骨间膜  ║║┃ 桡     │
        │  骨 ┃║║（桡尺骨间膜）║║┃ 骨   │
        └────────────────────────────┘
              尺桡远侧关节（靠腕那端）
        ═══════════════════════════════

        旋转时：尺骨是轴心，桡骨绕着尺骨转
```

读图说明：桡尺骨上、下各由一个关节相连（近侧、远侧），中间那段相对的骨缘由骨间膜连在一起；骨间膜是旋转的"折叠轴"，顺它折叠时是桡骨绕尺骨转。

也就是说：**上下是关节，中间是骨间膜**，把两个骨牢牢地连在一起。

这里有个必须搞清的问题：前臂旋转的时候，到底是**桡骨围着尺骨转**，还是尺骨围着桡骨转？

答案是**桡骨绕尺骨转，尺骨是轴**。这一点从结构上就能推出来：环状韧带环绕的是桡骨颈，桡骨小头在这个环里可以自由转动，说明上面那一端本来就是桡骨在动。

> **结论**：旋转时**桡骨围绕尺骨旋转，尺骨是轴心骨**。

这个结论有一个非常实际的用处：**桡尺骨骨折的时候，轴心骨最重要**。哪根骨是轴心，哪根骨就一定要对好。尺骨是轴心骨，**尺骨一定要对好**；桡骨稍微差一点还可以，因为它只是个绕着转的柱子。

### 手骨的连结：只要把桡腕关节讲透

手骨的连结里，我们主要给大家介绍一个——**桡腕关节**，也就是平常说的腕关节。这个关节只要知道两件事：**构成**和**运动**。

#### 构成：凸三、凹二

先回忆腕骨：一共八块，排成两排，每排四块。

```text
        远侧排：大多角骨 · 小多角骨 · 头状骨 · 钩骨
        ────────────────────────────────────────────
        近侧排：  舟  骨 ·  月  骨 · 三角骨
                                      ● 豌豆骨（落在上方）
        ────────────────────────────────────────────
        手指 ← 手掌 ← 腕 ← 前臂
```

腕骨下方接的就是前臂骨：这一块是**桡骨下端**，那一条是**尺骨下端**。这个由腕骨和前臂骨共同构成的关节，就是桡腕关节。

它的构成分凸和凹两头来记。

**关节凸（腕侧）**：**舟骨、月骨、三角骨**三块。

**关节凹（前臂侧）**只有两个成分：

- **桡骨下关节面**——直接和腕骨挨得最近的就是桡骨，它和腕骨组成关节；
- **尺骨下端的关节盘**——尺骨下端比较短，**它和腕骨并不直接相连**，中间隔着一个结构，这是一块软骨，就叫**关节盘**（尺骨下方的关节盘），它和舟、月、三角骨相对。

于是就有了这一句必须记住的话：

> **结论**：尺骨下端**不参与**构成桡腕关节，参与的只是它下面那块**关节盘**。

#### 运动：四个方向加环转

和肩关节一套路数，很好记：

- 向前，**屈**；向后，**伸**；
- **内收、外展**；
- 还可以做**环转**。

所以桡腕关节的活动也是比较灵活的。

#### 剩下的几个：记个名词就行

最后在整手的那张图上再点几个名字，知道叫什么、有个位置概念就够了，不展开。

- 腕骨之间的那些腔隙——**腕骨间关节**；
- 远侧排腕骨和五个掌骨之间构成的腔隙——**腕掌关节**；
- 再往下顺着手指的顺序：掌骨和掌骨之间是**腕掌关节**，掌骨和近节指骨之间是**掌指关节**，指骨和指骨之间是**指间关节**。

到这儿，上肢骨的连结就走完了一整圈：肢带骨两个关节打头，肩、肘、前臂、腕一路接过来，最末端的手指留几个名词收尾。

> **承前启后**：上一节讲完「上肢骨的连结：肩、肘、腕怎么接在一起」，下一节接着讲「下肢骨的连接：从骨盆环走到踝关节」。

## 下肢骨的连接：从骨盆环走到踝关节
> 对应块：BLK09 | 覆盖分集：P13-P14 | 块标题（分集名）：《13.关节学-下肢骨连结Ⅰ》

接下来我们讲第二部分，下肢骨的连接。

下肢骨的连接怎么分？和上肢一个套路，还是分成肢带骨和自由骨两大部分。肢带骨这边要过三个内容：骶髂关节、耻骨联合，还有骨盆；自由骨那边的重点，则落在髋、膝、踝这几个关节上。

### 肢带骨的连接

#### 骶髂关节：全身最牢固的关节

先看挂图。图上是左右两块髋骨，夹着中间的骶骨，骶骨下面还接着尾骨。骶骨的外侧我们前面讲过，有一块粗糙的关节面，叫耳状面；髋骨的内侧同样有一块粗糙的耳状面。两个相邻的耳状面怼在一起，中间夹出的那条缝所形成的关节，就叫骶髂关节。

```text
           骶骨外侧面              髂骨内侧面
         ┌────────────┐        ┌────────────┐
         │   骨松质   │        │   骨松质   │
         └─────██─────┘        └─────██─────┘
            耳状面  ╲          ╱  耳状面
           （粗糙）   ╲ 缝隙 ╱   （粗糙）
                       ╲    ╱
                        └──┘
                     骶髂关节
```

> **定义**：骶髂关节由相邻的骶骨与髂骨的两个耳状面构成。

构成说完了，接着看特点。挂图上我们从前方看、从后方看各画了一张，中间断开了，一张前面一张后面，这两张要连起来看。第一个印象是：骶髂关节的**前方**，关节囊的前面有很发达的韧带加固；**后方**同样有发达的韧带加固。

还有一张图是从骨盆正中切开的：右侧的髋骨、两个腰椎的断面、骶骨的断面都在上面。中间那个骨性凹窝叫骶管，下方开放的那个部位叫骶管裂。这两个我们前面学过，先混个脸熟。

现在把特点收一收，一共四条。

在收之前，顺手把髋骨上的标志复习一遍——这些待会儿还要用：**髂嵴、髂前上棘、髂前下棘、髂耻隆起、耻骨梳、耻骨结节、耻骨联合**；再往后是**耻骨弓、坐骨结节、坐骨棘、大坐骨切迹、耳状面**，还有**弓状线**和**闭孔**。

**第一个特点：关节面凹凸不平。** 我们看到的耳状面近似一个平面，而且很粗糙。大家设想一下，两个既接近平面、又凹凸不平的面组合在一起，这个关节能灵活吗？肯定不能——它天生就是个稳固的关节。

**第二个特点：关节囊紧贴关节面的周缘。** 整个囊从上到下都贴着骨面走，这又提示我们什么？说明关节里面的间隙太小了。间隙越小越稳固，还是同一个道理。

**第三个特点：无论关节囊前方还是后方看，都有发达的韧带加固。** 这个刚才挂图上看到了，囊外加固，关节就更稳固。

**第四个特点：这两个耳状面对接以后，一部分关节面相互骨化融合了。** 就跟焊接焊到一起一样，融合了就再也不会分开，更稳固。

> **结论**：四个结构特点一叠加，结果就出来了——这个关节几乎不运动，是全身最牢固的一个关节。

#### 耻骨联合：直接连接与间接连接之间

第二个是耻骨联合。

看挂图，这张图是从上往下看骨盆的，这边是前、那边是后。左右髋骨的前方各有一个耻骨联合面，两个联合面中间借着软骨连起来。这个软骨叫**耻骨间盘**。

> **定义**：耻骨联合由相邻的两个耻骨联合面，借助于纤维软骨（耻骨间盘）连接而成。

特点我们画个模式图看。

```text
         耻骨结节  耻骨联合面   耻骨联合面  耻骨结节
            ●         ▓            ▓         ●
   ┌────────┴─────────┴────────────┴─────────┴────────┐
   │  闭孔   ┃                          ┃   闭孔      │
   │         ┃        耻 骨 间 盘       ┃             │
   │  耻骨弓 ┃  ┄┄┄ 矢状位裂隙 ┄┄┄   ┃   耻骨弓    │
   │         ┃  （纤维软骨，形成腔）   ┃             │
   └─────────┴──────────────────────────┴─────────────┘
```

读图：左右两段是髋骨的耻骨部，中间夹的整块就是耻骨间盘，盘中央那道矢状位的缝就是它最要紧的地方。

间盘的特点大家已经看出来了：**中间有一个呈矢状位的裂隙**。

看到这个裂隙，我们就可以把骨连接的两种形式搬出来对一遍了。骨连接分直接连接和间接连接两种：直接连接的特点是两骨之间没有腔；间接连接有腔，所以又叫关节连接。

那么耻骨联合属于哪一种？它借纤维软骨相连，按定义应该算直接连接；可是它内部偏偏又有一个矢状位的裂隙，形成了腔。

> **结论**：耻骨联合是直接连接和间接连接的一个**过渡形式**。

既然兼了腔，活动度就略微有那么一点点——所以耻骨弓略微能够开大，而且女性大于男性。另外上下端还有些韧带加固：上面是耻骨上韧带，下面是耻骨弓状韧带。

> **易错点**：耻骨联合的结构特点，记住最要紧的一条就够了——**有矢状位的裂隙**。有裂隙，所以能微动。

#### 骨盆：髋、骶、尾围成的大小骨盆

第三个是骨盆。挂图上是上男下女两块骨盆。

骨盆怎么组成的？左右髋骨，加上后方的骶骨和尾骨——髋、骶、尾，三部分。

接下来说分界。看挂图：先摸到耻骨结节，从这个位置起，这一条骨缘比较锐利，叫**耻骨梳**；再往后，这一段骨缘比较钝圆了，叫**弓状线**；再往后就是**骶骨岬**；另一边重复一遍。借用这一条线，我们把骨盆分成大骨盆和小骨盆。

```text
                        ┌── 骶骨岬 ──┐
                     ╱                 ╲
                  弓状线               弓状线
               ╱                           ╲
           耻骨梳                         耻骨梳
        ╱                                     ╲
    耻骨结节                               耻骨结节
   ╱                                           ╲
═════ 耻骨联合上缘 ═════   ← 骨盆分界线 ＝ 小骨盆上口
    ║         大 骨 盆（＝腹腔）          ║
    ╠═════════════════════════════════════╣
    ║         小 骨 盆（固有盆腔）        ║
    ╚═════════════════════════════════════╝
      耻骨联合下缘 → 耻骨弓 → 坐骨结节
        → 骶结节韧带 → 尾骨尖   ← 小骨盆下口
```

读图：上面那条横贯左右的实线就是骨盆分界线；线以上、偏前的部分直接就是腹腔，我们叫**大骨盆**；斜线以下、后下方的这部分，才是临床所说的骨盆，也叫**固有盆腔**，也就是**小骨盆**。

顺便在板图上认几个点：这块是髂前上棘，**髂前上棘后上方三到四厘米**这一段，髂嵴增厚了，有个名词叫**髂结节**——这是临床骨穿的部位。往下依次是髂耻隆起、耻骨梳、耻骨结节、耻骨联合面，和前面说的一样。再往下是大小坐骨切迹；画的是骶骨那一块，正中有隆起，下面是**骶管裂孔**。

然后我们把板图上的两条口线收一下。

**小骨盆上口**：从前方来说就是**耻骨联合的上缘**，从这里开始，依次是耻骨结节、耻骨梳、弓状线、骶骨岬，另一侧重复。这一条线实际上身兼两职——它既是大小骨盆的分界线，也是小骨盆的上口线。

**小骨盆下口**：看挂图，这儿有个韧带叫**骶棘韧带**，还有一个韧带到坐骨结节，叫**骶结节韧带**。下口线从耻骨联合下缘开始，耻骨弓、坐骨结节，然后借骶结节韧带到尾骨尖，另一侧重复。这是一条不规则的线。

> **结论**：骨盆这一节，记住两件事就够了——由**髋、骶、尾**组成，被那条线分成**大骨盆（腹腔）**和**小骨盆（固有盆腔）**；再把上下口线的构成认熟。

### 髋关节：头大、臼深、囊厚的稳定关节

#### 构成与结构特点

下面进入自由骨。下肢自由骨怎么连接的？第一个是髋关节。这个关节要搞清四件事：**构成、特点、运动、容易往哪个方向脱位**。

先看黑板。髋骨的外侧面我们画一下，重点看这个：外侧有一个骨性的深窝，我们叫**髋臼**，它是构成髋关节的关节窝。关节头是哪个骨？股骨——股骨头、大转子、股骨干、小转子。一个头，一个臼，髋关节就构成了。

再看挂图。这张是从前方看右侧髋关节，关节囊外面的韧带叫**髂股韧带**；这张是从后边看右侧髋关节，看到的是关节囊，囊上有一块韧带叫**坐股韧带**。所以关节囊给人的印象是很宽厚、很坚韧的——那这个关节是以稳固为主，还是以灵活为主？当然是稳固。

还有一张图是把关节囊切开、把股骨头往外拉了一下。头和臼之间居然还有结构连着，这叫**股骨头韧带**，它里面有营养股骨头的血管在这儿走。

大家看那个深窝就是髋臼。它周围是不是还有一圈环状的软骨环？这和刚讲过的肩关节盂周围的**盂唇**是不是很相像？这个叫**髋臼唇**，也是纤维软骨构成的。由于这一圈纤维软骨，这个髋臼就更深了，有利于关节稳固。

再看这张冠状切面图：窝就是髋臼，里面那块是软骨板，颜色深的是关节腔，那一截连着的结构是股骨头韧带的断面。最要紧的是看两侧的关节囊——很厚、很厚，而且包裹的范围很广。

```text
        冠 状 切 面
   ┌──────────────────────────────┐
   │        髋臼（关节窝）         │
   │   ┌──────┐   ═══ 关节腔      │
   │   │ 股骨头│  ╱  股骨头韧带断面│
   │   └──┬───┘                    │
   └──────┼────────────────────────┘
          │
    ┌─────┴─────┐
    │  关节囊   │  厚而坚韧，包裹范围广
    └───────────┘
      前方全包
      后方约 2/3 被包（外 1/3 未包）
```

> **易错点**：囊外包裹看着很广，但只看前面会漏掉关键信息——**前方全包，后方只包了大部分，外侧 1/3 没包进去**。正因为有这个缺口，临床上才有"囊内骨折"和"囊外骨折"之分。股骨颈折在这块就是囊外骨折，折在里面那段就是囊内骨折。

现在把髋关节的结构特点收成四条。

第一条，**头大、髋臼深**，周围还附着髋臼唇，把窝又加深一层——所以它是个稳固的关节。

第二条，**关节囊厚而坚韧，包裹范围很广**：前方全包，后方约 2/3 被包进去。

第三条，**关节囊外有韧带加固**，挂图上看到的髂股韧带、耻股韧带都长在囊外，起加固作用。

第四条，**腔内有一根很短的小韧带，叫股骨头韧带**。这里可以和肩关节对记一下：讲肩关节的时候，关节腔里面是不是也有一个结构？肱二头肌长头腱。一个是肌腱，一个是韧带，都是腔内的东西。

#### 运动：和肩关节像，幅度小得多

髋关节的运动，腿向上抬叫屈，向后叫伸；也有外展、内收。能不能旋内旋外？能——屈曲到 90 度的时候就可以做旋内旋外。

能不能环转？这个怀疑大家的能力是吧？杂技演员蹬伞，躺在凳子上用一条腿把伞绕起来，那就叫环转。只是幅度比肩关节怎么样？小。

所以一句话：活动和肩关节类似，只是幅度小。

#### 后脱位：屈曲加内收再加内旋

髋关节最容易向哪个方向脱位？最常见的是**后脱位**。怎么造成的？我举几个动作，你们大家在实验课上照着标本做一遍，印象会特别深。

先看最稳固的状态。人体直立站着，股骨头完全在髋臼里面——从后方看，能看到股骨颈、大转子、小转子，头整个都在臼里面。这时候最稳固。

接着屈曲 90 度。注意关节面的变化：转子和窝都露出来一些了。

再在屈曲 90 度的基础上内收大腿——往里来。关节面又露出一些。

最后再来一个内旋，注意这时候**足跟是向外的**。这会儿关节面是不是几乎都露到髋臼外面去了？这个时刻就是关节最不稳固的状态。它一旦离开髋臼窝，就是后脱位。

| 体位 | 股骨头与髋臼的关系 | 稳固程度 |
| --- | --- | --- |
| 站立 | 头完全在臼内 | 最稳固 |
| 屈曲 90° | 关节面露出一些 | 变松 |
| 屈曲 90° + 内收 | 关节面又露出一些 | 更松 |
| 再加内旋（足跟向外） | 关节面几乎全部露在臼外 | 最不稳固 |

有同学会问：谁能在马路十字路口摆那么个姿势站着等车撞，来一个后脱位啊？

我见过一个 14 岁的小孩。做什么游戏呢——男孩子都玩过的跳驴。这游戏怎么玩呢：拿一个凳子当驴头，或者说小树，骑驴的在前头，扮马的、扮驴的跟在后面，队伍里排第三的人要撅着屁股去"骑"驴尾巴，队伍里有个小孩还要负责**敬老头**。结果那个敬老头的小孩一屁股坐下去，驴屁股塌了，人也哭了。路过一个老工人，问他"怎么了"，一看哭得挺厉害，直接送医院——**后脱位**。

至于老人为什么容易后脱位，我把动作拆开你就明白了：弯腰，等不等于大腿屈曲？弯腰时间长了，膝关节是向内借劲还是向外撇借劲？是向内——向内就等于内收。可老人要站着驼着一个人，还得靠稳，脚后跟就得往外撇——脚后跟往外撇就是内旋。屈曲、内收、内旋，三样凑齐了。

> **易错点**：后脱位送到医院，腿是长还是短？短。脱位是在屈曲、内收、内旋这个状态下发生的，脱位以后肢体就固定在这个体位上——看图上两侧都"包"出来了分辨不出哪条腿，但**大转子都支出来了，短的 那条就是脱位腿**。

### 膝关节：全身最复杂的关节

#### 构成：股骨、髌骨、胫骨三骨登场

膝关节是全身最复杂的关节。还记得讲关节总论时我说的那三个字吗——**囊、面、腔**。辅助结构呢？很多结构。在膝关节里，这些全有，所以它是全身最复杂的关节；至于全身最灵活的关节，那是肩关节。

构成先看挂图。这是从前方看右侧膝关节，这是从后边看，还有是把关节囊打开、从前方看的。

前方能看到什么？有个骨叫**髌骨**，髌骨上面是股四头肌，肌腹很发达；髌骨下端有一块短而扁的肌腱，叫**髌韧带**，止于胫骨粗隆。后边就是关节囊了。两侧能看到胫侧有一条副韧带、腓侧还有一条副韧带。关节囊后方有一条**腘斜韧带**。所以膝关节的前后两侧都有韧带加强。

把关节囊打开、把髌骨向下翻过来，就看得到关节腔里的一些结构了。从前向后到髁间窝里有一个韧带，叫**前交叉韧带**；从后向前来的那个，叫**后交叉韧带**。所以关节腔里面有韧带，这是第二个印象。

第三个印象是关节囊。和髋关节相比，膝关节的关节囊是不是薄而松弛？因为膝关节要比髋关节灵活。

回过来把构成正式说一遍：膝关节的上方是**股骨**（收肌结节，前方有一个髌面），下方是**胫骨**（髁间隆起、胫骨粗隆），前方还要加上**髌骨**。那么腓骨在哪呢？腓骨的上端在这儿——**腓骨不参与膝关节**。

> **结论**：膝关节 = 股骨 + 髌骨 + 胫骨，三块骨。

#### 结构特点：囊薄而松，稳固全靠囊里囊外

**第一条，囊薄而松。** 这是一条特点，而且它决定了方向：这个关节首先要灵活。那稳固靠什么？往下看。

**第二条，囊外有韧带。** 关节囊前方是髌韧带，两侧是胫侧副韧带和腓侧副韧带，后方是腘斜韧带——四周都有。

**第三条，囊内也有韧带。** 就是前面看到的前交叉韧带和后交叉韧带。前交叉韧带起自髁间隆起的前方向后去；后交叉韧带起自后方向前去。为什么板书上是虚线？因为这两个韧带都藏在髁间窝里面，从侧面看它们是不是呈十字形？所以大名叫**十字交叉韧带**，小名才叫前交叉韧带、后交叉韧带。

**第四条，囊内还有半月板。** 这是一块软骨垫，外周厚、里边薄。它起什么作用？大家想：股骨下端不是平面，胫骨上端也不是平面，两个凸面一接触，接触面积当然小。加上这块软骨垫，接触面积就增大了，有利于关节稳固；同时还能减少震动、吸收一部分外力。

**第五条，髌上囊。** 关节的辅助结构里讲过滑膜囊，在膝关节里就长成这样。我把它放大说一下位置：这是股骨的断面，能看到骨松质的网眼；下边是胫骨上端和胫骨粗隆的骨松质，这是髌骨；髌骨上方是发达的股四头肌，下方借一根韧带止于胫骨粗隆。

看关节的滑膜发生了什么改变：滑膜层在髌骨上方鼓出一个小的囊腔，又在别处鼓出一个突起，两个里面都是脂肪组织。先说这个囊腔——它就叫**髌上囊**，位于髌骨上方。囊的两侧，内侧是骨，外侧是肌肉，膝关节运动时这个肌肉也在动，囊里有少量滑液；这个囊卡在两个结构之间，作用就是**减少它们之间的摩擦**。

再说那个三角形的突起，里面有大量脂肪：滑膜包裹着脂肪形成的一个突起，突到关节腔里面，这个叫**翼状襞**，位置在髌骨下方。它填什么忙呢？膝关节的关节腔本来就大、空隙也多，这个结构正好填补这些空隙，也有利于关节稳固。

```text
          胫侧副韧带              腓侧副韧带          ← 囊外韧带
              │                      │
         ┌────┴──────────────────────┴────┐
         │  囊内：翼状襞 · 半月板 ·       │   ← 囊薄而松
         │        前后交叉韧带            │
         └────┬──────────────────────┬────┘
           半月板                  半月板
              │                      │
         ┌────┴──────────────────────┴────┐
         │          胫 骨 上 端            │
         └─────────────────────────────────┘
```

读图：外面一圈是囊外的副韧带，囊本身很薄很松；往里走才是干活的——翼状襞、半月板、交叉韧带，全都长在腔里面。半月板上下各贴着胫骨上端这块骨面，一头一尾正好被"夹"在中间。

#### 膝关节最常受的两个伤

膝关节最常见的损伤是什么？**半月板损伤**。

我以前有一个同学，是辽宁青年队下来的。怎么下来的呢？有一次踢球，身体旋转、腾空，把球狠狠踢出去。大家看这个动作：身体所有的重量是不是都作用到膝关节上了？膝关节是不是保持着一个屈曲状态？有没有直腿踢的？

屈曲的时候，从解剖上看是什么现象？你看股骨下端的后方是个尖的，屈曲的时候就是这个尖滑过来，和下面的关节面结合。而它们之间本来就摆着一块半月板。

那么什么时候不容易损伤？直立的时候接触面最大，不容易损伤。可这个尖滑过来的时候就容易了。再加上全身重量都作用到关节面上，最主要的动作还是旋转——尖一碾压，半月板就损坏、损伤了。所以半月板损伤是最常见的。

**第二种损伤是交叉韧带损伤。** 前、后两根交叉韧带如果是完好的，两块骨之间前后就被固定住了。有一根撕裂了、断了，会怎么样？大家设想一下，小腿应该是向前移位还是向后移位？

我们限制一个体位来看：让患者坐在凳子上。坐着的时候，大家想想，大腿是不是就不动了？把骨画出来——这是股骨，这是胫骨。假设前交叉韧带已经断了，后交叉韧带还是好的，这时候用手搬动患者的小腿：

- 前交叉韧带断的，小腿应当**向前**移位——因为后交叉韧带还好着，大腿不动，小腿就容易悠到前面去；
- 向后移位，就是**后交叉韧带**撕裂；
- 前后都能移位，说明**两根都断了**。

临床管这个检查叫**抽屉试验**——像拉抽屉一样，靠手感判断小腿能往前还是往后挪、挪多少。这就是膝关节最常见的损伤。

### 小腿骨与足骨的连接

#### 胫腓骨的连接

小腿骨的连接和前臂骨的连接很类似。看挂图：这是从前方看小腿骨，**上方是关节连接，下方是韧带连接**。前臂骨是不是上下都关节连接？所以它是一个关节、一个韧带带，中间还夹一层**骨间膜**，把胫骨和腓骨连在一起。

#### 距小腿关节：为什么偏偏向内扭

接下来说踝关节。踝关节的学名叫**距小腿关节**，注意它的用词。

"距"指的是足的距骨，距骨上方有一个关节面叫**距骨滑车**，所以叫距。胫骨和腓骨加在一起叫小腿骨，所以叫小腿。三块骨参与——**胫骨下端、腓骨下端、距骨**，这个关节的名字就出来了。

运动有三组：向上叫**背屈**，向下叫**跖屈**，另外还参与**内翻**和**外翻**。

这个关节我主要想解释一件事：为什么人踝关节扭伤，**容易足心向内扭，而不是向外**？

先看两端。胫骨下端是内踝，下面有关节面；腓骨下端是外踝；前方有韧带把它们连着。所以内踝和外踝这两点的距离是恒定的，不会变化。

再看中间的距骨。距骨是个什么样的骨？上面是个关节面，下面接着跟骨、跟结节，更往旁边是舟骨、骰骨、第一、第二、第三楔骨。那块关节面正好卡在胫腓两骨之间。

```text
        胫骨下端（内踝，高）        腓骨下端（外踝，低）
        ━━━━━━━━━━━━━┓                 ┃
        ┃            ┃                 ┃
        ┃  距 骨     ┃═════════════════╋ ← 前方韧带连接
        ┃  滑 车 面  ┃  内、外踝间距离恒定  ┃
        ┃ ██████████ ┃                 ┃
        ┃ ████████   ┃                 ┃
        ┃ ██████     ┃                 ┃
        ┗━━━━━━━━━━━━┛                 ┃
         前（宽）    后（窄）
```

读图：距骨上面这块滑车面**前边略宽、后边比较窄**，而两侧的胫骨和腓骨之间的距离是死的。于是：

- **足跟着地（背屈）**——宽面进入两骨之间，关节间隙最小，最稳固；
- **足尖着地（跖屈）**——窄面进来，骨与骨之间的空隙增大，就不稳固了。而这时候全身的重量都压在上面。

所以踝关节扭伤，是不是**在下楼的时候最容易**？正是——下楼时足尖着地，宽面还没进来，窄面先塞进去了。

那为什么只能向内、不能向外？大家看内踝和外踝的位置高低一样不一样？**内踝高，外踝低**。向外翻的时候，外踝先撞上，关节活动的余地被它限死了；往里倒，内踝这边没有东西挡着。所以结果只能是向内。

> **结论**：踝关节外侧是薄弱环节——外踝比内踝低，挡不住外翻；距骨滑车前宽后窄，足尖着地时处于松动状态。两条合起来，就是"下楼崴脚必向内"的解剖学原因。

#### 跗骨间、跖跖与跖趾关节

踝关节以外的关节，记住名称就行。看挂图：这些跗骨之间形成的关节叫**跗骨间关节**；再往下那条缝是**跖跖关节**；再往下是**跖趾关节**。跟手骨的命名是不是很相像？

> **结论**：附肢骨的连接到这里就讲完了。这个部分里，**肩、肘、髋、膝**这四大关节是要重点掌握的——它们的构成、结构特点、运动以及损伤，都要能讲清楚。
