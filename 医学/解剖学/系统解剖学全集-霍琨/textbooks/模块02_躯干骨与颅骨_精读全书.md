## 躯干骨：胸骨、椎骨与肋骨
> 对应块：BLK02 | 覆盖分集：P03 | 块标题（分集名）：《03.骨学-躯干骨》

这一讲里藏着三个特别实用的"数数"口诀：数肋骨靠胸骨角，数棘突靠第 7 颈椎，数腰椎靠两侧髂嵴最高点的连线。三个口诀用的是同一件事——**在体表能摸到的骨性标志**。所以这篇我会反复从体表定位的角度讲：标志摸得着，标志后面的东西自然就记住了。

框架先摆出来，躯干骨由三部分组成：**椎骨、胸骨、肋骨**。胸骨最简单，椎骨是重头，肋骨收尾。

---

### 胸骨：先认组成，再认切迹

胸骨我们只过三个方面：组成、结构（结构里全是切迹）、以及一个重要结构——胸骨角。

组成上没有难点。上方短的叫**胸骨柄**，中间这块叫**胸骨体**，下方叫**剑突**，三部分骨化为一体，合起来就是胸骨。

#### 切迹：全都是"接东西"的凹

胸骨的结构不用死记硬背，因为它们有个统称——凡是骨面上这种带名字的凹，都叫**切迹**。按"凹在哪里 + 接什么"来记就行。

```text
                 颈静脉切迹（后方即气管）
                        ▼
                 ┌────────────┐
                 │  胸 骨 柄   │──◄ 锁骨切迹：接锁骨内侧端
                 └─────┬──────┘
                       │ ← 胸骨角（柄体交界，向前微突）
                 ┌─────┴──────┐
                 │  胸 骨 体   │──◄ 肋切迹 ×7：接第1~7肋软骨
                 └─────┬──────┘
                       │
                 ┌─────┴──────┐
                 │   剑  突    │  ← 最下端，最窄
                 └────────────┘
```

- **颈静脉切迹**：胸骨上方正中、朝上的那个凹。它后方就是气管儿，所以它给你一个参照——两个手往这儿一卡，正好卡到气管儿，就能判断气管是不是居中。
- **锁骨切迹**：两侧的，和锁骨的内侧端相接。
- **肋切迹**：再往下那一串，全是肋切迹，和肋骨相接。

> **易错点**：肋切迹是 **7 个**，不是 12 个。因为胸骨只和上 7 个肋骨相接——第 1、2、3、4、5、6、7，一共七个。这里最容易顺手数成十二对。

#### 胸骨角：为了往下数肋骨

在组成上，胸骨柄和胸骨体的交界处形成一个向前不太明显的角，这个角就叫**胸骨角**。

记它的目的只有一个：让你掌握一个**计数肋骨的方法**。胸骨角两侧对应的正是第 2 肋，或者说第 2 肋**软骨**。这样你就找到了起点，从它两侧往外数第一根是第 2 肋，往下就可以一路数下去了。

> **提示**：为什么一定要说"软骨"两个字？因为肋软骨都在内侧——真正贴着胸骨的是肋软骨的内侧端，肋骨的骨性部分在外侧。所以"胸骨角两侧对应第 2 肋软骨"是准确的；如果只说"对应第 2 肋骨"，就不够妥了。

所以胸骨就这么简单，重点全在这个角上。

### 椎骨：全身 26 块，重头在这一块

椎骨全身一共 26 块：

$$
\text{颈椎 } 7 + \text{胸椎 } 12 + \text{腰椎 } 5 + \text{骶骨 } 1 + \text{尾骨 } 1 = 26
$$

骶部的 5 块骶椎骨化为一体，构成骶骨；尾骨同样骨化为一体。椎骨这一块分两个方面讲：先讲**一般形态**，也就是所有椎骨共同具备的形态；再讲**各部椎骨的形态**，不同部位各自的特性。

#### 一般形态：体、弓、孔

看挂图的时候先提醒一句：注意方位不一样。颈椎基本都是从上往下看的，胸椎有上面观和左侧面观，腰椎又是另一种摆法。别被图的摆法牵着走，抓住结构本身。

**前方**有一个短圆柱状的骨性结构，叫**椎体**。

**后方**有一个弓形的结构，叫**椎弓**。椎弓分成两部分：直接和椎体相连的这一部分叫**椎弓根**；后方的板状部分叫**椎弓板**。根和板合起来，围成一个完整的环形部分，这个环就是椎弓。

体在前、弓在后，中间自然围出一个孔，叫**椎孔**。

```text
                        前
             ┌────────────────────┐
             │       椎  体        │  短圆柱状
             └──┬─────────────┬───┘
              椎弓根         椎弓根
                │               │
             ┌──┴───────────────┴──┐
             │       椎   孔       │ ← 体 + 弓 围成
             └──┬─────────────┬───┘
              椎弓板         椎弓板
                 │    棘突     │
                 └──────┬──────┘
                        ↓
                        后
```

每一块椎骨都有一个椎孔，26 个叠罗汉似的摞在一起，这些孔就串成了一根骨性的管子，叫**椎管**。

> **结论**：椎骨的一般形态就三样——**前方的体、后方的弓、围成的孔**。

#### 椎板上的突起

把方位换成从后往前看，椎弓板上还长着一堆骨性突起。向上形成的突起叫**上关节突**，向两侧形成的凸起叫**横突**，向后形成的凸起叫**棘突**，另外还有向下的**下关节突**。

| 突起 | 方位 | 是否成对 |
| --- | --- | --- |
| 上关节突 | 向上 | 成对 |
| 下关节突 | 向下 | 成对 |
| 横突 | 向两侧 | 成对 |
| 棘突 | 向后 | **不成对**，只有一个 |

一句话记住那个例外：三个成对的（上下关节突、横突），加一个孤独的——棘突。

#### 椎管与椎间孔：一个上下走，一个左右走

椎管刚才说了，就是椎孔的立体化。这里要补的是它里面装什么：**从第 1 腰椎往上，管里容纳的是脊髓**。

椎间孔在哪儿？它既不在椎体上，也不在棘突上，它在**相邻两个椎弓根之间**。椎间孔左右成对——左侧一个，右侧一个。

```text
           第 n 椎                              第 n+1 椎
     ┌──────────────────┐                  ┌──────────────────┐
     │       椎体        │  ==  椎间盘  ==  │       椎体        │
     └──┬────────────┬──┘                  └──┬────────────┬──┘
      椎弓根        椎弓根                    椎弓根        椎弓根
        └──────┬──────┘                        └──────┬──────┘
               └────────► 椎间孔 ◄───────────────────┘
                            │
                          脊神经  ────►  椎管（上下走，容纳脊髓）
```

椎间孔里通过的是**脊神经**。临床上如果颈椎、腰椎或者胸椎下缘骨质增生，挤到椎间孔，受压的也正是脊神经。

所以特别好记：**管是上下走的，容纳脊髓；孔是左右走的，通过脊神经。**

### 颈椎：横突有孔，棘突分叉

#### 三个共同特点

颈椎的共性很多，我们只挑最主的三条说：

- **横突有孔**。孔里走的是动脉，叫**椎动脉**。这是颈椎最突出的一个特点——横突孔一变窄，椎动脉受压，脑供血就不足。
- **椎体沟**。从上面看颈椎，椎体的两个侧缘略微向上翘起，这两个翘起来的结构叫椎体沟。上一块椎体的下缘跟它一叠，就形成了一个关节，叫**钩椎关节**。
- **棘突分叉**。

```text
                          前
           ┌────────────────────────┐
           │         椎  体          │
           └──┬─────────────────┬───┘
          椎体沟                椎体沟
            ↖                   ↗
             ╲  与上一椎体的下缘  ╱
              ╲   叠合形成关节   ╱  → 钩椎关节
     ┌─────────┴─────────────────┴─────────┐
     │              椎  孔                  │
     └──┬───────────────────────────────┬───┘
        │          棘突（分叉）           │
   ┌────┴────┐                       ┌────┴────┐
   │ 横突  ○  │═══ 椎动脉 ══════════▶│  ○  横突│
   └─────────┘                       └─────────┘
                          后
```

> **提示**：这三条不是可有可无的加分项。临床上颈椎病的症状，一大半都能从这三条上倒推——椎动脉供血不足、钩椎关节的增生组织顶进椎间孔、棘突形态决定你能不能摸到它。

#### 寰椎与枢椎

前两块颈椎不守常规，得单独说。

第一颈椎叫**寰椎**。为什么叫寰椎？它只由一个前弓、一个后弓和两个侧块构成，所以在它身上找不到椎体——没有前方那个短圆柱状结构；也找不到棘突。它跟谁都不一样，像个环，所以叫寰（环）椎。

第二颈椎叫**枢椎**，它的特殊是有个**齿突**：椎体上方长出一根骨刺样的结构，就叫齿突。齿突和寰椎的相应部位构成**寰椎关节**——整个头颅是围着它转的，"枢"就是这个意思。

> **易错点**：齿突和寰椎是套在一起形成关节的。头部突然受到一个外力，这两处很容易造成**齿突骨折**；齿突一骨折，寰椎的椎孔和枢椎的椎孔就前后错位，脊髓受压，后果是**高位截瘫**。所以寰椎、枢椎这一段受伤从来不是小事。

#### 第 7 颈椎：唯一摸得到的棘突

颈椎还有一个特殊叫**隆椎**。看颈椎的棘突，本来是分叉的，到这儿忽然不分了——因为它下面紧接着就是胸椎了，两者形态很像，很容易搞混。

第 7 颈椎的棘突特别长，体表能够摸到，所以我们用它来**计数棘突**。方法是这样的：

让患者低头，用两侧的**肩峰**画一条线。在线的下方你能找到并摸到一个棘突，摸起来像一个包。然后让患者**左右转头**，你用手压住这个包，感受它微动不微动——如果微动，就再往下摸一个，**下边这个是不动的**。

上方微动的那个，就是第 7 颈椎的棘突。

### 胸椎：为肋骨而生的一节

#### 肋凹：胸椎的身份证

胸椎最突出的特点是有**肋凹**。位置有三个：椎体两侧，椎体**上缘的后方**和**下缘的后方**各有一个小关节面；**横突的前方**还有一个。这些关节面统称肋凹，是用来和肋骨构成关节的。

再看肋骨的后端，那是它和胸椎对话的一端：肋小头（小头上面有两个关节面）、肋颈、肋结节（结节后方还有一个关节面）、肋角，下方是**肋沟**。

两边的关节面一对上，就成了两个关节：

- **肋小头关节**——肋小头正好伸到两个椎体之间，上缘后方的小关节面和下缘后方的小关节面各接它的一个斜面。
- **肋横突关节**——横突前方的肋凹，接的是肋结节后方的关节面。

```text
                        前
              ┌────────────────────┐
              │        椎体         │
              └──┬─────────────┬───┘
       上缘后方肋凹        下缘后方肋凹  ┐
              └────┬────────┘           │ 肋小头带两个关节面
                ┌──┴──────────┐         │ 分别接上、下两个肋凹
                │    椎  孔    │◄───────┤
                └──┬────────┬──┘         │  → 肋小头关节
                 椎弓根    椎弓根        │
                    │         │         │ 肋 颈
                    │  棘 突  │         │
        ┌───────────┴───┐     │         │
        │  肋  凹        │     │         │
        │（横突前方）    │     │         │
        └───────┬───────┘     │         │
             肋  结  节 ──────┴─────────┘
                 │  后面还有一个关节面
                 └──► 与横突前方的肋凹相对
                        → 肋横突关节
```

#### 棘突斜向后下，穿刺要斜向前上

胸椎还有一个特点必须记住：它的棘突**斜向后下**。

因为棘突斜着往后下走，棘间隙就**窄**。这有什么实际意义？如果在胸椎做穿刺，进针方向应该按**斜向前上**——棘突挡在后面斜着往下走，你就得对着它的斜面往上顶才对得上。

同时还要注意**穿刺的体位**：让患者躺在床上，抱膝。这时候再斜向前上进针。

> **易错点**：胸椎穿刺"斜向前上"、腰椎穿刺"水平进针"，这两个方向千万别记混。记它的依据只有一条：棘突往哪儿倒，针就得往反方向去顶。

回过头来再说第 7 颈椎那个"摸得到、下边不动"的现象。为什么只有它能摸到？为什么上面的会微动？因为**所有的胸椎都和肋骨固定在一起，胸椎根本不能动**，只有颈椎能活动；而颈椎里只有第 7 颈椎离皮肤最浅（这一点跟后面讲韧带的内容有关），其他棘突都藏在深面，不容易摸到。

### 腰椎：腰穿就从这里进针

#### 椎体肥厚，棘突板状水平后伸

腰椎的体型是三段椎骨里最壮的，第一个特点：**椎体肥厚**。

第二个要记的是：**棘突呈板状水平后伸**。

水平后伸直接带来一个好处——棘间隙**大**。所以腰椎穿刺的时候，穿刺针可以**水平进针**，不需要像胸椎那样斜着往上顶。

那临床上常见的腰穿部位在哪儿？记住两个就够：**三、四腰椎之间**，或者**四、五腰椎之间**。

#### 髂嵴最高点连线

怎么精确定位？再教一个计数棘突的方法：摸两侧的**髂嵴**，取两侧髂嵴的**最高点**，连成一条线，这条连线对应的就是**第 4 腰椎的棘突**。

有了这个标志，腰穿点就非常好找了：三、四腰椎之间的那个凹窝在这条连线的上方，四、五之间的那个在它的下方。

> **提示**：这一讲的三个计数方法其实是一套思路：胸骨角是"向上数"，隆椎是"向下数"，髂嵴连线是"用一个固定平面把第 4 腰椎钉死"。只要在病人身上找得到骨性标志，后面的结构就是确定的。

### 骶骨：五块骶椎揉成的一块

#### 外形与前面

从外形上看，骶骨是**三角形，上宽下尖**。它的前面**光滑而凹陷**，后面**粗糙而隆起**。

前面要认的结构不多：

- **骶骨岬**：骶骨上缘前方有一个向前突的结构。临床上计量骨盆上口前后径，就以它作为标志。
- **骶前孔**：骶骨岬前方有 4 对。
- **横线**：那是 5 个骶椎骨化以后留下的痕迹，原来的位置是椎间盘。
- 另外还能看到上关节突。

#### 后面：三条嵴、四个孔、一个裂口

后面的结构比前面复杂。看正中隆起的部分：

**骶正中嵴**是怎么来的？它是 5 个骶椎的棘突骨化融合的结果——第 1、2、3、4 个棘突融合成中间这条嵴；**第 5 骶椎的棘突缺如**，于是在下方留下一个三角形的裂口，就叫**骶管裂**。后面还有 4 个**骶后孔**。

骶骨后面不止一条嵴：骶正中嵴、中间嵴、外侧嵴，都是隆起的骨性突起。

外侧面要单独看：骶骨的外侧面大约占上 $2/3$，有一块粗糙的骨面叫**耳状面**，它和髋骨的耳状面构成**骶髂关节**。

#### 骶管的交通关系

从骶骨正中往下，整个骨性的结构叫**骶管**。这一块**要重点掌握**，骶骨别的形态细节可以简略，**骶管的交通关系必须记下来**。

```text
                    椎管（内含脊髓）
                          │  相通
                    ┌─────┴─────┐
                    │   骶  管   │
                    └─┬───────┬─┘
          前方：4 对骶前孔   │   后方：4 个骶后孔
                    │       │
                    ▼       ▼
                        会 阴 部
                          ▲
                          │  第5骶神经由此穿出
                    ┌─────┴─────┐
                    │   骶管裂   │  ← 向下三角形的开放口
                    └─────┬─────┘
              骶骨角     │     骶骨角   （两侧骨性角，体表可摸）
                        │
                两角之间进针 → 骶管麻醉
```

把它的"交通"理一遍：向上和**椎管**相通；向前和**骶前孔**相通；向后和**骶后孔**相通；向下是那个三角形的开放口，也就是**骶管裂**。

骶管裂里通过的是什么？**从第 1 腰椎再往下、整个脊髓发出的那些脊神经**，统称**马尾神经**。其中**第 5 骶神经**从骶管裂出来，分布到会阴部。

所以会阴部的手术可以在这里做**阻滞麻醉**。怎么做？记住两侧的**两个骶骨角**，它们在体表是可以摸到的；在**两角之间进针**，麻醉就做到了。

### 肋：骨加软骨

#### 概念别搞混

先弄清楚概念。**肋**由两部分构成：肋骨，加上它前端接的那块软骨——就是我们吃的那种脆骨——**肋软骨**。所以"肋"是**骨加软骨**，单独那一段硬的才叫肋骨。这个概念一定要搞清楚。

#### 真肋、假肋与浮肋

肋按前端的连接方式分成两类：**真肋**和**假肋**。

**真肋**是第 1~7 对。区分标准就一条：它们的肋软骨**直接和胸骨相接**，所以叫真肋。

**假肋**是第 8~12 对。它们的肋软骨是间接接的：第 8 和第 7 相接，第 9 和第 8 相接，第 10 和第 9 相接，上方一根都不挨胸骨，所以叫假肋。

在假肋里还有一个名字：**第 11、12 肋**由于和谁都不相接，就叫**浮肋**。

| 类别 | 编号 | 前端连到哪里 |
| --- | --- | --- |
| 真肋 | 第 1~7 对 | 肋软骨直接连胸骨 |
| 假肋 | 第 8~12 对 | 肋软骨连上位的肋软骨 |
| 浮肋 | 第 11、12 对 | 上端与谁都不相接（假肋中的一类） |

#### 三种连接和肋弓

肋的连接一共有 **3 种形式**。

```text
  第 1 肋    肋软骨 ──► 胸骨                     软骨结合
  第 2~7 肋  肋软骨 ──► 胸骨                     关节连接（胸肋关节）
  第 8 肋    肋软骨 ──► 连第 7 肋的肋软骨   ┐
  第 9 肋    肋软骨 ──► 连第 8 肋的肋软骨   ├ 软骨连接
  第 10 肋   肋软骨 ──► 连第 9 肋的肋软骨   ┘ → 肋弓
  第 11 肋   肋软骨 ──► 上方谁也不挨         ┐ 浮肋
  第 12 肋   肋软骨 ──► 上方谁也不挨         ┘
```

- **软骨结合**：第 1 肋和胸骨相接，属于软骨结合。
- **关节连接**：直接和胸骨相接的那些肋软骨，与胸骨之间构成**胸肋关节**。
- **软骨连接**：第 8、9、10 肋的肋软骨不碰胸骨，而是和**上位**的肋软骨相连，这就叫软骨连接。由这些软骨拼出来的弓状结构，就叫**肋弓**。

**肋弓**是重要的**体表标志**，身体两侧都有。

## 从脑颅到面颅：颅的分区、下颌骨与颅底孔裂
> 对应块：BLK03 | 覆盖分集：P04 | 块标题（分集名）：《04.骨学-颅骨Ⅰ》

先说清楚一件事：颅的结构比较复杂，孔裂也比较繁多，当堂记忆很困难。所以这一讲我们先把骨头和孔裂过一遍，把位置和走行的东西对上号，但请务必记住——**真正把颅骨摸熟，得去实验课对着标本反复看**。今天能记住个大概位置和主要孔裂，就已经是赚到了。

---

### 一根线，把颅分成两半

第一个问题：颅可以分为几部分呢？

先看颅的侧面。上面有眶腔、颧、外耳门，下面还有下颌骨。**找两点**：一个是眶的上缘，一个是外耳门，把这两点连成一条线，这一条线就把颅分成了两部分。

- 后上方这一部分，叫**脑颅**；
- 前下方这一部分，叫**面颅**。

```text
            眶上缘 ●━━━━━━━━━━━━━━━━━━━● 外耳门
                       这条线就是分界
        ┌────────────────────┬────────────────────┐
        │      脑 颅         │      面 颅         │
        │      后上方         │      前下方         │
        │        8 块         │       15 块         │
        │                    │                    │
        │    容纳脑髓        │  眶腔鼻腔口腔      │
        └────────────────────┴────────────────────┘
                        8 + 15 = 23 块
```

数字非常好记：**脑颅 8 块，面颅 15 块，加起来颅由 23 块骨构成**。

而这两个部分各管一摊事：

> **定义**：脑颅围成**颅腔**，容纳的是**脑髓**；面颅围成我们所看到的**骨性眶腔、鼻腔和口腔**。

> **结论**：所以"眶腔、鼻腔、口腔"这三个腔在解剖学上属于面颅的功能区，不要跟脑颅的颅腔混在一起。

不过刚才那个侧面图上还能看到体表标志：上唇、下唇。**注意喉结**——请大家在喉结这个部位用手自己摸一下，**喉结的上方**，可能触到一个结构。

什么结构呢？是一个骨，一个 **U 型的骨**，叫**舌骨**。你触到的那个具体部位叫**舌骨体**。

> **结论**：舌骨是**唯一一个和颅骨不直接相连的颅骨**。它虽不与颅骨直接相连，却属于面颅 15 块中的一块。

这一条特别好考，就记这一句：**唯一不与颅骨直接相连的颅骨，是舌骨。**

---

### 下颌骨：一体两支

第二个问题：下颌骨。

下颌骨是个**马蹄铁型**的、**U 字形**的骨。我们简单看一下它上面的标志：

```text
                 冠突        下颌头
                   │            │
              ┌────┘            └────┐
              │        下颌颈          │
              └──────────┬────────────┘
                         │
              ┌──────────┴────────────┐
              │         下颌角         │
              │        （体表标志）     │
              │                        │
              │       下 颌 支         │  ← 两侧扁薄的骨板
              └──────────┬───────────┘
                         │
              ┌──────────┴────────────┐
              │      下 颌 骨 体       │  ← 马蹄铁形（U 形）
              │    上缘：齿槽（镶牙）   │
              └────────────────────────┘
```

- **骨体**：前方马蹄铁型的那一大块；
- **下颌支**：后方翘起的两个扁薄骨板，两侧对称。

所以下颌骨是**一体两支**。

再看几处骨性标志：

- 下颌骨的**上缘**有很多齿槽，镶嵌着下颌的牙齿；
- 骨体和下颌支交界的那个部位叫**下颌角**，是一个重要的**体表标志**；
- 下颌支上面有两个突起，一个叫**下颌头**，一个叫**冠突**（冠突在前，下颌头在后）；
- 下颌体前方正中线的两侧，有 **2 个孔**，叫**颏孔**。

那就把下颌骨骨体前正中线这一块锯开，看看它的断面。

断面上主要是**骨松质**，标出的结构依次是：上方的**下颌头**、下颌头下方变细的**颈**、前方的**冠突**、**下颌的齿槽**，以及前下方的**下颌角**。

在下颌支的**内侧面**，有一个孔，叫**下颌孔**。下颌角的内侧骨面比较粗糙，这块叫**翼肌粗隆**，是**肌肉抵止**的一个部位。

再往下看就明白了——**下颌孔进入下颌体后，是一个骨性的管儿，最后在颏孔这块出来**，我们在断面上看到的那条痕迹就是这个管走过的路径。

下颌体下边还有**两个骨性凹窝**：一个是**下颌下腺凹**，一个是**舌下腺凹**。这两个骨性凹窝里边各容纳一个腺体——**舌下腺凹容纳舌下腺，下颌下腺凹容纳下颌下腺**，这两块腺体我们在后面还会专门介绍。

> **易错点**：这一面（下颌体的内面）上，"孔—管—孔"的走向和"两凹窝容纳两腺体"，几乎是必考点。记住路线：**下颌孔进 → 骨性管 → 颏孔出**；记住落位：**舌下腺凹藏舌下腺，下颌下腺凹藏下颌下腺。**

---

### 颅顶外面：成人是缝，小儿是囟

第三个问题我们先看**颅的整体观**，第一部分先提**颅顶**。

颅顶的外面，也就是从上往下看颅顶，能看到哪些结构呢？

#### 成人颅顶看骨缝

成人的颅顶，从上往下看，能看到一些**骨缝**：

- 左右方向的缝，叫**冠状缝**；
- 前后方向的缝，叫**矢状缝**；
- 后方还有一条**人字缝**。

这就是成人颅骨从上面能看到的缝，缝里还有导血管的通道。

#### 小儿颅顶看囟

那么小儿呢？小儿的颅骨上，除了缝以外，**还能看到一些膜**。

大家看小儿的**额骨是分开的**。注意看这两个区：一个**菱形区**，一个**三角区**——就是我们说的**膜性的区**，小孩这里叫**囟**。

- 前方的囟叫**前囟**；
- 后边三角形的那个叫**后囟**。

前囟在哪些骨之间呢？前方对称的两个是**额骨**，这两个是**顶骨**，后面还有一个是**枕骨**。所以前囟位于**额顶之间**，形状**呈菱形**。

后囟的位置在**顶枕之间**，形状**呈三角形**。

那这个膜什么时候变成骨呢？

- **前囟 1～2 岁闭合**；
- **后囟生后不久就闭合**。

所谓闭合，就是变成骨了。

#### 囟的两个临床意义

**第一，判断颅内压。** 大家想，它是一个膜，当颅内压升高的时候，这个膜是不是就膨起呀？所以**根据囟我们可以判断颅内压的变化**。

**第二，采静脉血。** 新生儿如果采集静脉血，在其他部位很困难的时候，我们可以**在囟门这块儿采集静脉血**。

为什么这个部位能采血呢？注意看——在**颅顶正中线的下方**，在颅腔内有一个**很大的静脉管道**，叫**上矢状窦**。我们通过膜刺入上矢状窦，就可以采集静脉血。

| | 前囟 | 后囟 |
| --- | --- | --- |
| 位置 | 额骨与顶骨之间 | 顶骨与枕骨之间 |
| 形状 | 菱形 | 三角形 |
| 闭合时间 | 1～2 岁 | 生后不久 |

> **提示**：把位置、形状、闭合时间这三行和"额顶间菱形、前囟迟闭／顶枕间三角、后囟早闭"这一串口诀一起记，前后两栏正好互为反证，闭不上和早闭合的病历在临床上一眼就能看出来。

---

### 颅底内面：三个颅窝

第二部分，我们看**颅底的内面**。

前后从上往下来看颅底的内面，**大致可以看成由前向后排列的 3 个颅窝**：

- 前面这个凹陷进去的窝叫**颅前窝**，它**最浅**；
- 中间这个类似"横八字"形的窝叫**颅中窝**；
- 最深的、靠后方的一个窝叫**颅后窝**。

```text
                    颅 底 内 面（示意）

        ┌──────────────────────────────┐
        │       颅 前 窝（最浅）        │   鸡冠 · 筛板 · 筛孔
        ├───────┬──────────────────────┤
        │  蝶骨小翼后缘 · 前床突        │
        ├───────┴──────────────────────┤
        │        颅 中 窝               │   蝶鞍 · 视神经管
        │      中间高、两侧低           │   眶上裂 · 圆孔 · 卵圆孔
        │                              │   棘孔 · 破裂孔
        ├──────────────┬───────────────┤
        │            鞍 背              │
        ├──────────────┴───────────────┤
        │       颅 后 窝（最深）        │   枕大孔 · 舌下神经管
        │                              │   斜坡 · 颈静脉孔
        │                              │   内耳门 · 乙状窦沟 · 横窦沟
        └──────────────────────────────┘
```

看挂图的时候记住**方位**：这是前面，这是后面。然后我们把挂图变成板图——**先把外形画出来，三个颅窝的界限一定要搞清楚**：中窝和前窝的分界在**蝶骨小翼后缘**（注意这里的突起叫**前床突**），中窝和后窝的分界在**鞍背**。

> **结论**：**分界线只有两条**——前面一条是蝶骨小翼后缘（前端为前床突），后面一条是鞍背。记住了这两条，三个窝的位置就再也丢不了。

#### 颅前窝：结构最简，认准筛孔

前窝结构比较简单，只有三样：

- 正中线上向上翘起的一个薄骨板，叫**鸡冠**；
- 鸡冠两侧深凹进去的骨板，叫**筛板**；
- 筛板上有很多很多小孔，叫**筛孔**。

所以颅前窝大家只要记住**一个结构：筛孔**。

那筛孔里边通过的是什么结构呢？是**嗅神经**。

所以——**筛板一骨折，损伤了嗅神经，会出现嗅觉障碍**。

> **易错点**：颅前窝的考点不在结构多，而在"一个结构 + 一条神经 + 一个后果"：认筛孔 → 通嗅神经 → 筛板骨折致嗅觉障碍。三句话连着背。

#### 颅中窝：孔裂最多，绕着蝶骨体转一圈

中窝的特点是**中间高、两侧低**。中间高的这块骨叫**蝶鞍**：

- 蝶鞍上方有一个**垂体窝**，里面容纳**脑垂体**；
- 前方有**交叉沟**；
- 前方还有**视神经管**；
- 这个骨突叫**前床突**，左右对称；
- 后方这个骨突叫**后床突**，也对称；
- 这一整片区域就是**鞍背**。

然后是中窝的孔裂，**这是中窝真正的重头戏**。中窝的孔比前窝多得多，一共这么几个：

| 孔裂 | 通过的结构 |
| --- | --- |
| 视神经管 | 视神经、眼动脉 |
| 眶上裂 | 动眼神经、滑车神经、展神经、眼神经 |
| 圆孔 | 上颌神经 |
| 卵圆孔 | 下颌神经 |
| 棘孔 | 脑膜中动脉 |
| 破裂孔 | 颈内动脉 |

一个一个过：

- **视神经管**在**前床突的内侧**，左右各一个，里面走**视神经**，还有**眼动脉**。
- **眶上裂**里走的结构最多：**动眼神经、滑车神经、展神经，还有眼神经**——4 对脑神经都从这个裂隙**进入眶腔**。
- **圆孔**里走的是**上颌神经**。
- **卵圆孔**里走的是**下颌神经**；**卵圆孔的后外侧有一个小孔叫棘孔**，棘孔里走的是动脉，叫**脑膜中动脉**。
- 还有**颞骨岩部的尖端**这块的孔，叫**破裂孔**，破裂孔里走的是**颈内动脉**。

> **提示**：记中窝的孔，用"**视、裂、圆、卵、棘、破**"这一串就够。但更重要的是记住它们的**空间关系**——**视神经管、眶上裂、圆孔、卵圆孔、棘孔，这五个是在一条弧形区里，围绕着蝶骨体转的**；破裂孔则单独挂在颞骨岩部的尖端上，不在这条弧线上。弧线记住了，孔的先后顺序自然就有了。

#### 颅后窝：一个枕大孔定乾坤

后窝有个最突出的特点：**窝底有一个大孔，叫枕大孔**。

后窝里要记的东西：

- 枕大孔**前外侧**有两个管儿，叫**舌下神经管**，走的是**舌下神经**；
- 从**鞍背到枕大孔**之间倾斜的那块骨面叫**斜坡**，**脑干就在斜坡的上方**；
- 还有**颈静脉孔**：位于颞骨岩部的后方外侧，**舌下神经管、颈静脉孔、内耳门**这一带还有相连的一些骨性沟。这些骨性沟相当于颅内的静脉管道，从颈静脉孔上来的这个骨性凹窝叫**乙状窦沟、横窦沟**；而**颞骨岩部后坡**上的这个孔叫**内耳门**。

> **结论**：**斜坡很重要，因为斜坡的后上方是人最重要的脑干——如果斜坡骨折损伤脑干，会危及生命。**

现在回头把三个窝串一遍：颅前窝简单，翘起的骨板叫鸡冠、两侧的骨板叫筛板、筛板上的窟窿叫筛孔，走的是嗅神经；颅中窝孔裂多，视神经管、眶上裂、圆、卵、棘整个是**一个在弧形区围绕蝶骨体**的排列，蝶鞍上方还有个浅窝叫**垂体窝**、里头容纳脑垂体，岩部尖端是破裂孔、走颈内动脉；颅后窝有颈静脉孔、走三对脑神经，还有一系列的窦沟，以及那个**枕骨大孔**。

---

### 三个颅窝的毗邻与交通

刚才讲的是"有什么"，接下来讲"挨着什么"——**各颅窝的毗邻关系**。

这个关系光看挂图看不出来，我们**做两个断面**来看：一个是在颅前窝处做一个**冠状切面**，另一个从前向后做一个**正中的矢状切面**，然后在两个切面上比较它们的毗邻关系。

#### 冠状切面上看到什么

在第一个断面上，从上到下：上面是**上颌的牙齿**和颅骨；**颅前窝的颅底**正中线上翘起的这个薄骨板是**鸡冠**；往下是**鼻中隔**；两侧是**眶腔**，鼻腔里有**上鼻甲、中鼻甲**；再往下是一个比较大的窦腔叫**上颌窦**；上方有个大腔叫**额窦**；还有几个小腔叫**筛窦**。

现在说毗邻关系：

- 有**鸡冠**的那个颅窝，一定是**颅前窝**；
- 这里边应该装眼球的地方，这个腔肯定是**眶腔**；
- 这个窦腔叫**上颌窦**，左右对称的这两个是**骨性鼻腔**，再下方就是**口腔**。

#### 矢状切面上看到什么

第二个断面是矢状切面。上面是**上唇、下唇**；在这儿断开的骨是**额骨**，有**额窦**；下面是**鼻骨**；向后倾斜的这个骨板就是我们说的**筛板**，筛板上方翘起一个骨叫**鸡冠**；再向后，断到了**垂体窝**、**斜坡**；这个就是**蝶骨体**，蝶骨体里边有个大的窦腔叫**蝶窦**。

再看**鼻腔和口腔的分界**：在中间我们能断到的就叫**腭**——**前方是硬腭，后边是软腭**。再往下是**下颌骨的断面**，断到以后能断到**舌**；舌的后方这个腔隙是**喉**，它前方应该有**喉结**；再往下是**寰椎、枢椎**的椎体断面；最下面是**枕骨、枕大孔**的断面。

再从矢状面直接读腔隙：上面那个细长的腔隙叫**咽**，前方这个腔隙叫**鼻**，这个是**口**，这个小的腔隙叫**喉**；**枕大孔向下**的腔隙叫**椎管**。

#### 三个窝的毗邻，一次记牢

这时候就能下结论了：

- 有**鸡冠**的颅窝一定是**颅前窝**；
- 有**垂体窝**的应该是**颅中窝**；
- **枕大孔**的那个窝是**颅后窝**。

```text
        颅前窝 ── 中下：骨性鼻腔
                 └─ 两侧下方：眶腔
                          ↓
        颅中窝 ── 中部下方：咽
                 └─ 两侧：鼓室（鼓室盖下方）
                          ↓
        颅后窝 ── 经枕大孔：与椎管相通
```

| 颅窝 | 毗邻 / 交通 | 骨折后血液与脑脊液的去向 |
| --- | --- | --- |
| 颅前窝 | 中下邻骨性鼻腔，两侧下方邻眶腔 | 可从**口鼻**流出 |
| 颅中窝 | 中部下方邻咽，两侧邻中耳鼓室 | 可从口鼻或**外耳道**流出 |
| 颅后窝 | 经枕大孔与**椎管**相通 | 枕大孔上方是脑髓，下方容纳脊髓 |

推导也就顺下来了。大家设想：如果**颅前窝的中部骨折**了，血液和脑脊液会不会漏到鼻腔？**会的**。既然漏到鼻腔了，血液和脑脊液可不可以从鼻流出、从口流出？**可以**。所以**颅前窝骨折，口鼻可以流出粘稠鲜红的脑脊液**。

再看颅中窝，中部下方应该是**咽**。如果这个部位骨折，血液会不会漏到咽？漏到咽的血液能不能从鼻腔、口腔流出？可以。所以问题来了——

> **易错点**：从口鼻流出的血液和脑脊液，**能不能严格区分是颅前窝还是颅中窝？不能**。所以这种情况**统称为颅底骨折**，不要硬去细分。

中窝的**两侧**怎么记？记住一个结构就行：**鼓室盖**。挂图上这个部位有一处浅凹，叫**鼓室盖**；把这个薄骨板凿开，里面就是一个骨性腔，这个骨性腔叫**中耳鼓室**。所以中窝两侧就是记**鼓室盖**，它下方应该邻**鼓室**。这个部位如果骨折，血液和脑脊液会**通过外耳道流出来**。

最后是颅后窝。枕大孔这个窝和椎管是相邻还是**相通**？**相通**。以**枕骨大孔为界**：上方是**脑髓**，下方容纳的是**脊髓**（椎管内容纳脊髓）。所以后窝大家就记**中部**这一个关键——**经枕大孔，通向椎管**。

这就是三个颅窝的**毗邻和交通**。

### 颅底外面：从骨性腭一路看到枕大孔

最后一个部分，我们看**颅底的外面**，从下往上看。我把主要的结构点一下。

**骨性腭。** 上颌的牙齿所围成的这个叫**骨性腭**。骨腭上有些孔：

- **门齿的后方有切牙孔**，有**腭神经**通过这儿出来；
- 后方这一个孔、下面还有一个孔，分别叫**腭大孔和腭小孔**，有**腭大神经**在这儿传出、**腭小神经**在这儿传出。

所以这是**口腔的顶部，叫腭**。

**鼻后孔。** 腭的后上方，这两个叫**鼻后孔**。

**下颌窝与关节结节。** 再看这个部位，有一个明显的**骨性凹窝**，它和**下颌骨的下颌头**构成关节。这个凹窝是由两个结构构成的：**略微隆起的这个骨缘叫关节结节**，**后方凹进去的这个叫下颌窝**。

大家注意：下颌窝本来很浅，前方又隆起了一个骨性的**关节结节**，**使下颌窝变深了**——所以下颌关节才能稳固。这两个要记住：**关节结节、下颌窝**。

**乳突、茎突、茎乳孔。** 再向后，有一个粗大的骨性隆起，就是**耳廓后下方的乳突**。乳突的前内侧有两个骨刺，叫**茎突**。注意**乳突、茎突根部这块有个孔，叫茎乳孔**，**面神经在这儿出来**。

**枕大孔与寰枕关节。** 然后我们看到这个就是**枕大孔**，枕大孔两侧有两个关节面儿，这两个关节面和**寰椎上关节面**构成**寰枕关节**。

**颅底外面的孔。** 另外在下边，我们还能看到**卵圆孔和棘孔**；同时还能看到**颈动脉管的外口**，**破裂孔就是相当于内口**——**颈内动脉**从这儿进去，然后在里边骨管儿里走，最后**在破裂孔的上缘进到颅腔**。

> **结论**：颅底的外面，大家记住这些主要的结构就可以了——**骨性腭（切牙孔、腭大孔、腭小孔）→ 鼻后孔 → 关节结节与下颌窝 → 乳突、茎突、茎乳孔 → 枕大孔与寰枕关节 → 卵圆孔、棘孔 → 颈动脉管外口与破裂孔内口**。这一串走完，颅底外面就算过了一遍。

回头再看一眼颅底：孔裂比较复杂，名词也比较多，而且孔内通过的结构又是很多。所以真正要记牢的，是那句最实在的话——**参照挂图把它变成板图，抓住三条线的边界（中窝与前窝的蝶骨小翼后缘、中窝与后窝的鞍背），再抓住中窝"视、裂、圆、卵、棘、破"绕蝶骨体的那条弧线，剩下的就是往里填内容**。

> **承前启后**：上一节讲完「从脑颅到面颅：颅的分区、下颌骨与颅底孔裂」，下一节接着讲「颅骨的侧面观与前面观：翼点、三个窝、眶腔与鼻腔」。

## 颅骨的侧面观与前面观：翼点、三个窝、眶腔与鼻腔
> 对应块：BLK04 | 覆盖分集：P05-P06 | 块标题（分集名）：《05.骨学-颅骨Ⅱ》

接下来我们把整块颅骨翻到外面来看，先看侧面。

侧面的内容说白了就两大块：一个是翼点，再就是三个骨性凹窝。这两个说完，我们转到前面观——也就是我们说的面颅，眶腔、鼻腔、口腔，一个一个过。

### 翼点不是一个点，是一个区

先花半分钟把颅侧面的标志认全，免得后面找不着北。前边是额骨、鼻骨、上颌骨和眶腔，往外是颧弓；颧弓往后是关节结节、下颌窝；再后面是外耳门，外耳门后下方是乳突。下面挂着下颌骨，冠突、门齿。

骨缝先认四条：前面冠状缝，中间蝶缝，再往后颞缝，最后人字缝。翼点就藏在这几条缝交汇的地方。

#### 位置：额、顶、颞、蝶四骨交界

大家注意看，这四条骨缝围出来一块地方，中间夹着一个小三角形的骨头——蝶骨。所以它是**额骨、顶骨、颞骨、蝶骨四骨交界**的部位，骨缝在这里呈 **H 形**。

> **定义**：翼点是额、顶、颞、蝶四骨交界处、骨缝呈 H 形的那一块**区域**，不是一个点。

「不是一个点而是一个区」这句话一定要记住，后面说投影、说骨折，都是拿这一块**区**来说的。

#### 两个特点：骨板薄，里面还贴着一条动脉

第一个特点：**这个部位的骨板很薄**，又是四个骨交界的地方，所以对颅骨整体来说它就是个薄弱区。薄弱区容不容易骨折？大家自己就想明白了——所以它容易骨折。

第二个特点：翼点的**内面有一条重要的动脉**，叫**脑膜中动脉**，紧贴着这块骨板向后行。

一边是薄，一边是动脉，两个特点凑在一块儿，这就出事了。

#### 折起来的后果：硬膜外血肿

我们把链条一环一环串一下。

先说颅骨本身。颅骨是一个**弓状的扁骨**，受外力的时候，内板和外板的张力是不一样的——**弓状扁骨，内板张力大于外板张力**。所以受到同样的力，**内板比外板容易骨折**。

内板先断，而脑膜中动脉就贴着骨板走，骨折的碎片会直接刺破动脉，造成大出血。

再看它出血往哪儿跑。颅腔里有一层比较硬的膜叫**硬脑膜**，紧贴着颅板，并且附着在颅底。硬脑膜的特点要记牢：

> **结论**：硬脑膜与**颅底**的骨面结合得**比较紧**，而与**颅的侧面和颅顶**结合得比较**疏**。

而脑膜中动脉这条血管，恰恰就在颅板和硬脑膜之间。受了外力一旦骨折，血管就在这两者之间出血，越出越多；颅腔是个封闭的腔，血出不去，只能在里面聚积。血越积越多，就把那层本来就容易和颅骨分离的硬脑膜**推向内**，中间撑出来一个空腔——这就是**硬膜外腔**，这种出血临床上叫**硬膜外血肿**。

```text
              外力压下来
                 ↓
   ┌──────────────────────────────┐
   │  外板（张力小，不易断）      │
   ├──────────────────────────────┤
   │  内板（张力大，先断）        │
   │  折口向下，刺破动脉          │
   │  脑膜中动脉（贴骨板后行）    │
   │  出血，越积越多              │
   ├──────────────────────────────┤
   │  硬脑膜                      │
   │  颅底：结合紧                │
   │  颅顶、颅侧：结合疏          │
   │  被血液推向内侧              │
   ├──────────────────────────────┤
   │  【硬膜外血肿】              │
   ├──────────────────────────────┤
   │  脑（脑髓）受压              │
   │  血量到一定量，发生脑疝      │
   └──────────────────────────────┘
```

硬脑膜的里边就是我们说的脑髓。这层膜往里一挪，脑髓就跟着被推移、往内受压；出血到了一定的血量，到了一定程度，就会形成**脑疝**；不及时抢救，患者就会死亡。

所以临床上有这么一条特别要紧：

> **易错点**：翼点骨折，**外板尽管光滑、内板看不到明显的骨折痕**，也要把患者留院观察几个小时，不要轻易放走。因为这个出血是**渐渐的**，大约**六个小时以后**才能显现出症状。

#### 体表投影：颧弓终点上方四厘米

翼点既然这么重要，怎么在体表上判断它？靠**投影**。

我们从表面自上往下捋一遍定位标志：上唇、下唇、颏、喉结、下颌角、耳廓。这块我们能摸到一个骨性的隆起，叫**颧弓**，颧弓的终点是可以确定的。

> **结论**：翼点的体表投影在**颧弓终点上方约四厘米处**。

### 颞窝与颞下窝：颧弓上下的那一对

侧面的三个窝，先看容易看的两个。

大家先在挂图上找几个标志性的结构：**下颌角**体表能摸到，**乳突**在外耳门后下方能摸到，**颧弓**也能摸到。摸到颧弓了，往上一看——颧弓的上方是不是有一块骨性的凹窝？这个最明显，它叫**颞窝**。

再看下面。下颌骨的下颌支，**下颌支的深面**那个空间，叫**颞下窝**。

一句话把两者分开：

> **结论**：**颧弓上方的凹窝叫颞窝**；**颞窝向下一直延续到下颌支的深面，那一段空间叫颞下窝**。

那这两个窝里各装了什么？我们把下颌骨的下颌支切开来看。

**颞窝**上边有一个比较大的肌肉附着，这个肌肉叫**颞肌**，以后我们专门介绍它——记住，颞肌附着在颞窝。

**颞下窝**里有两小块肌肉：一个小肌肉走到**下颌颈**，叫**翼外肌**；它深面还有一个斜行的肌肉，走到**下颌角的内侧**，叫**翼内肌**。

除了肌肉，这两个窝里还有重要的**血管和神经**。

### 翼腭窝：位置深，交通最复杂

第三个窝位置比较深，而且交通关系很复杂——**这是我们这一块的重点**。

我们做一个断面看。从眶腔这个部位向下做一个矢状切面，然后从外侧看里边这部分：眶腔被剖开了，上颌窦也有一部分被剖开，能看到眶上壁、眶下壁。

#### 位置：一个狭长的间隙

先把这个窝本身的位置搞清。往下往后看，后方有一个**狭长的间隙**：那块骨板叫**翼突**，这一缘是**上颌骨的后缘**。所以

> **结论**：**翼腭窝**的前界是**上颌骨后缘**，后界是**翼突**，内侧界是**腭骨的垂直板**——它是一个很狭长的间隙，外侧就是**颞下窝**，两者相通。

#### 五个交通关系

这个窝窄归窄，交通却极多。我们一个一个对：

```text
                    翼腭窝
                      |
      +---------------+---------------+
      |               |               |
    圆孔           腭大孔          蝶腭孔
   颅中窝           口腔            鼻腔
      |               |
    翼管           眶下裂
  颅底外侧           眶腔
```

一条一条落到文字上：

| 通道 | 通向 |
| --- | --- |
| 圆孔 | 颅中窝 |
| 翼管 | 颅底外侧 |
| 腭大孔 | 口腔 |
| 蝶腭孔 | 鼻腔 |
| 眶下裂 | 眶腔 |

一个狭窄的间隙，却和周围这么多腔隙是沟通关系的。**这五个交通关系是翼腭窝的重点，三个窝里大家重点就记它。**

### 眶腔：一个装着眼球的四棱锥

我们最后再看一下颅的前面观，也就是我们说的**面颅**。它主要围成了**眶腔、鼻腔和口腔**。我们先说第一个腔——眶。

#### 外形与开口

大家在图上能看到什么呢？这个腔隙是一个**锥体型腔，后边尖、前边接近于四方形**，是个**四棱锥体型**。

拿头顶做参照：两侧是耳廓，前方是鼻。这样一看就清楚了——**眶腔底朝向前外，尖朝向后内**。

```text
    前外：上、前、外                          后内
          底  ──────────── 眶腔 ────────────  尖
      接近四边形         容纳眼球             视神经管
```

这里边容纳的是**眼球**，后边相连的是**视神经**，所以眶腔的尖儿一定是朝向后内。

眶腔里我们能看到三个开口：

- **视神经管**——尖部（眶尖）那个最圆的窟窿；
- **眶上裂**——斜长的裂隙，一个朝向外上；
- **眶下裂**——另一个朝向外下。

#### 四壁上能看到什么

**上壁**：前外侧有一个浅凹，叫**泪腺窝**。

**外侧壁**：后上方有一个狭长的裂隙，叫**眶上裂**。

**下壁**：后外侧还有一个裂隙，叫**眶下裂**。

**内侧壁**：前份有一个**泪囊窝**；壁上有许多小孔，是**筛窦**。

**眶尖**：结构就是视神经管。

#### 四壁各邻谁、通到哪

这是眶腔的重点内容，**毗邻和交通都很重要**。

| 壁 | 壁内的结构 | 毗邻 / 交通 |
| --- | --- | --- |
| 上壁 | 前外侧浅凹——泪腺窝 | 与**颅前窝**相邻 |
| 外侧壁 | 后上方狭长裂隙——眶上裂 | 眶上裂、视神经管**通颅中窝** |
| 下壁 | 后外侧裂隙——眶下裂 | 经眶下裂**通翼腭窝**；同时与**上颌窦**相邻 |
| 内侧壁 | 前部泪囊窝；小孔通向筛窦 | 与**筛窦、鼻腔**相邻；泪囊窝向下**经鼻泪管通鼻腔** |

眶尖的视神经管和眶上裂，**都和颅中窝相通**。

这里有一个特别容易搞混的地方，我给你掰开说。下壁的眶下裂，它**既相通又相邻**：经眶下裂**通**翼腭窝，同时下壁又**邻**上颌窦。相通是一条道，相邻是贴着一层骨板，这两回事不能混。

内侧壁也一样，**和筛窦是相邻而不是相通的**。壁上那些小孔是筛窦所在的位置，但它们并不构成一条能把眶腔和筛窦打通的通道。这里把两组的区别再捋一遍：下壁是「既通又邻」，内侧壁只是「邻」，不「通」。

泪囊窝向下的那条道，倒是真真正正的**相通**：

> **结论**：**泪囊窝向下，经鼻泪管与鼻腔相通**。

为什么鼻泪管相通这么重要？我们都熟悉一句话——**痛哭流涕**。为什么人痛哭的时候眼泪和鼻涕一起下来？眼泪是**泪腺**分泌的，从泪腺窝出来，经泪囊窝往下走；为什么鼻涕也下来了？就因为这儿经鼻泪管向下**通到鼻腔**去了。有这么一条相通的结构在，泪和涕就必然连在一起。

#### 眼球外凸：不一定是眶腔自己的肿瘤

我过去看过一个患者，那个现象大家猜是什么——**眼球明显外凸**。

碰到眼球外凸，第一个念头往往是眶腔肿瘤。但这里要问一句：眶腔肿瘤是**原发**还是**继发**？把眶的毗邻关系摊开，答案自己就出来了。

- 眶上裂和视神经管跟**颅中窝**相通，所以颅内的肿瘤——比如**蛛网膜纤维母细胞瘤**——就可以通过这条途径进入眶腔；瘤子越长越大，最后把眼球挤向外，形成凸眼。
- **上颌窦**长肿瘤，突破这层薄薄的骨壁，可以进入眶腔，同样造成眼球外凸。
- **筛窦**长肿瘤，突破骨壁进入眶腔，也会造成眼球外凸。

> **结论**：不要单一地只考虑「眶腔长肿瘤了」。**周围其他部位长肿瘤，一样会造成眼球外凸。**

这就是毗邻关系学以致用的地方。

### 骨性鼻腔：上窄下宽，左右两个腔

第二个腔，**骨性的鼻腔**。

#### 形态：上窄下宽，一条鼻中隔

先看形态。这儿画的是一半的鼻腔，注意两个特点：

第一个特点，**上窄下宽**。

第二个特点，**中间有隔**，这个隔叫**鼻中隔**，它把鼻腔分成左右两个腔。

- 前方经**梨状孔**和外界相通；
- 后方经**鼻后孔**和咽相通。

#### 四壁

**上壁**叫**筛板**。怎么认？图上那个翘起的骨板叫**鸡冠**，鸡冠两侧凹进去、横着的那块骨板，就是**筛板**——鼻腔的上壁实际上就是筛板。

**下壁**叫**骨腭**，从断面图上看，口腔的上壁就是方才点到的腭骨。骨腭的下方是口腔。

**内侧壁**就叫**鼻中隔**，分隔左右鼻腔。

这里补一句容易含混的地方：沿着正中线做一个**矢状切面**，会多出两个骨板结构，这两个骨板合起来叫**骨性鼻中隔**；而它**前边那个三角区是软骨性的**鼻中隔，两者加在一起才是完整的鼻中隔。

#### 外侧壁：三鼻甲、三鼻道

外侧壁是鼻腔结构最丰富的一面。从结构上看，注意两个数：**三个鼻甲、三个鼻道**。

```text
              上壁：筛板（中线隆起处为鸡冠）
         ┌───────────┬────────────┐
         │  外侧壁   │   内侧壁   │   上窄
         │           │            │
         │（三鼻甲） │  （鼻中隔） │
         │           │            │   下宽
         └───────────┴────────────┘
              下壁：骨腭（口腔的顶）
```

外侧壁上明显能看到三个**瓦片状的骨板**——鼻甲是凸出的，鼻甲和鼻甲之间凹进去的地方就是**鼻道**。从上往下：上鼻甲、中鼻甲、下鼻甲；上鼻道、中鼻道、下鼻道。

> **结论**：鼻腔外侧壁的结构，记住**三鼻甲、三鼻道**。

有一处特别：**上鼻甲的后上方**叫**蝶筛隐窝**，**蝶窦**就开口于蝶筛隐窝。

#### 毗邻与交通

外侧壁分上下两份来看。

**上份**：与**筛窦**相通，与**眶腔**相邻。

**下份**：与**上颌窦**相通，与**筛窦**相通（筛窦分了很多群，我在这儿就简单写成通筛窦），与**额窦**相通。

除了上下份，鼻腔的**前端**还有一个孔，就是**鼻泪管的开口**，通向**眶腔**——这就是前面说的相通关系的另一头。

这个道理是活的。我们**滴眼药**的时候，为什么滴完要用手轻摁一下**内眦**？就是为了防止眼药顺着鼻泪管流到鼻腔里去。鼻腔和眶腔这一条交通关系，就藏在这么一个小动作里。

### 鼻旁窦：四组，开口位置和方向

鼻腔里还有一组结构要介绍——**鼻旁窦**，也叫**副鼻窦**。

#### 组成与位置

鼻旁窦一共有**4 组**：**额窦、筛窦、上颌窦、蝶窦**。

位置一个个对：从图上看，这是中线，我们把这一侧剖开——中间是鸡冠，眶的上壁、外侧壁，上颌骨和上颌的牙齿，这个是眶腔，注意上鼻甲、中鼻甲，这是上颌窦。

- **额窦**在**眉弓的深面**；
- **筛窦**在**眶的内侧壁**；
- **上颌窦**在**上颌骨的深面**；
- **蝶窦**在**蝶骨体**里——刚才那个断面图上，颅中窝的中部有一个大的腔，蝶骨体里边就叫蝶窦。

四组齐了。

#### 开口位置

鼻旁窦的开口**仅限**于**上鼻道和中鼻道**。

- **额窦、上颌窦、筛窦的前群**，都开口于**中鼻道**；
- **筛窦的后群**，开口于**上鼻道**；
- **蝶窦**，开口于**蝶筛隐窝**。

#### 开口方向，以及它换来的临床体位

| 鼻旁窦 | 开口鼻道 | 开口方向 |
| --- | --- | --- |
| 额窦 | 中鼻道 | 向下（底在上、口在下） |
| 筛窦前群 | 中鼻道 | 向内侧 |
| 筛窦后群 | 上鼻道 | 向内侧 |
| 上颌窦 | 中鼻道 | 向内侧 |
| 蝶窦 | 蝶筛隐窝 | 向前 |

开口方向为什么重要？临床上给副鼻窦**滴药**的时候要采取什么体位，一看就清楚了：

| 目的 | 体位 | 道理 |
| --- | --- | --- |
| 额窦、蝶窦滴药 | **仰卧、头低位** | 额窦开口朝下、蝶窦开口朝前，药容易流进去 |
| 筛窦滴药 | **侧卧、头低位** | 开口朝内侧，侧过来就顺了 |
| 上颌窦滴药 | **侧卧位**即可 | 开口朝内侧，容易滴入 |
| 上颌窦内脓汁满罐、需要引流 | **病侧朝上**、侧卧、**足高头低**，并且**不断地晃头** | 上颌窦朝上，开口就转到下面，脓汁才容易引流 |

最后这一条要讲透。上颌窦里脓汁满罐的时候胀痛感特别明显，这时候不是滴药，是要把脓汁**引出来**。办法是：病变的这一侧上颌窦**朝上**，人侧卧、足高头低，还不断地晃头。你设想一下，上颌窦朝上了，它的开口自然就转到下面，脓汁顺着开口哗哗地流出来。**这就是上颌窦引流术的体位。**

### 这一讲要记住的几件事

这一讲的内容不少，我给你们把要记的点拎一下，课后结合标本加深：

- **前囟**：位置在哪儿、多长时间闭合，重点记；
- **颅底**：有哪些重要的孔裂，这些孔裂都通过什么结构，为后续课打基础；
- **颅窝的毗邻和交通**：颅前窝下方中间是鼻、两侧是眶；颅中窝下方是咽；颅后窝通椎管。这种交通关系一定要搞清；
- **翼点**：位置在哪儿、体表投影在什么部位、骨折会出现什么现象——位置、投影、后果，三样都要拿得出来；
- **翼腭窝**：五个交通关系搞清楚；
- **眶腔的毗邻和交通**，很重要；
- **鼻腔的毗邻和交通**，同样很重要。
