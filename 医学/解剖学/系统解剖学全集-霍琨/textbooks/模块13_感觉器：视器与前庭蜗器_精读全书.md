## 眼球：三层球壁与三样内容物
> 对应块：BLK33 | 覆盖分集：P42 | 块标题（分集名）：《43.感觉器-视器 眼球》

视器包括眼球和眼副器两大部分，这节课我们先把眼球讲完。眼球从组成上同样分两部分：一个是球壁，第二部分是内容物。

先把挂图打开，看这个眼球的剖面。球壁由三层构成，从外向内清清楚楚：最外边这层叫外膜，也叫纤维膜；里边这一层，前面是薄薄的、后面有增厚的、下面也是比较薄的，叫血管膜，也叫中膜；最里边很薄很薄的那层叫内膜，也叫视网膜。

球壁之外，腔里填着的三样东西，就是房水、晶状体和玻璃体。整个眼球的骨架长这样：

```text
                     外界光线
                        ↓
   ┌──────────────────────────────────────────┐
   │ 外膜 / 纤维膜                            │
   │   致密结缔组织 → 支持、保护               │
   │   ┌───────────┬──────────────────────┐   │
   │   │  角膜     │       巩膜           │   │
   │   │  前 1/6   │      后 5/6          │   │
   │   │ 微向外凸  │   白、不透明、很坚硬  │   │
   │   └─────┬─────┴──────────────────────┘   │
   │         ↕ 角巩膜交界处（内面）             │
   │         · 巩膜静脉窦（许氏管）             │
   ├──────────────────────────────────────────┤
   │ 中膜 / 血管膜                            │
   │   丰富血管 + 丰富黑色素                   │
   │   ┌──────┬──────────┬──────────────┐    │
   │   │ 虹膜 │  睫状体  │   脉络膜     │    │
   │   │      │ 环形增厚 │  （膜最厚处）│    │
   │   └──────┴──────────┴──────────────┘    │
   ├──────────────────────────────────────────┤
   │ 内膜 / 视网膜                            │
   │   ┌──────────────┬──────────────────┐   │
   │   │ 色素上皮层   │   神经细胞层     │   │
   │   │   在外       │     在内         │   │
   │   └──────────────┴──────────────────┘   │
   └──────────────────────────────────────────┘
                    眼  内  腔
              ┌─────────┼─────────┐
            房水      晶状体     玻璃体
        （无色透明） （双凸透镜）（胶冻状）
```

下面按由外向里的顺序，一层一层拆开。

### 外膜：角膜与巩膜

第一层叫纤维膜，也叫外膜。这层膜由致密的结缔组织构成，对眼球起到支持和保护的作用。它分成两部分：前方的叫角膜，后方白色不透明的部分叫巩膜。角膜大约占前 $1/6$，巩膜占后 $5/6$。

#### 角膜的三个特点

角膜有三个特点，请大家记住。

第一个特点，我们从图上已经看出来了——微向外突，有一定的弯曲度。第二个特点，无血管、无色透明。第三个特点，有丰富的神经末梢，所以感觉敏锐。

这三个特点不是三句孤立的性质，每一条后面都跟着一大堆临床表现：

| 特点 | 由此推出的后果 |
| --- | --- |
| 微向外凸，有一定弯曲度 | 暴露在外，容易受外伤；受伤后光滑的弯曲面被破坏，形成不了原有曲度 → 外伤性散光 |
| 无血管、无色透明 | 营养只能靠间接来源 → 一旦发病，病程肯定长、而且容易复发；损伤后结瘢形成角膜白斑，正好落在瞳孔前方时只有光感没有视力 |
| 神经末梢丰富、感觉敏锐 | 角膜的疾病有没有剧痛？肯定是剧痛 |

这三条串起来，其实就是一条完整的临床思路。你看"迷眼"这件事：沙粒迷进去以后敢眨眼、但只有异物感不疼，说明它落在白眼球上；如果连眨眼都不敢眨、特别疼，那就是落在角膜上了——眼睑一眨，砂粒等于在搓角膜，神经末梢那么丰富，能不疼吗？

> **易错点**：砂粒迷眼**不能揉**，一揉就损伤角膜。正确做法是把上睑提起来，让眼球向内转，靠泪液把沙粒冲下来；如果要拨，也借助于上睑轻轻往下拨、眼球往上翻，轻轻把它拨下来。

> **提示**：角膜白斑和后面要讲的晶状体浑浊，临床上都可以表现为"只有光感没有视力"。区别在位置——白斑看它落在不在瞳孔前方，晶状体浑浊则是光根本过不去。

#### 巩膜与巩膜静脉窦

巩膜有两个特点：白而不透明，这就是我们俗称的"白眼球"；非常坚硬，由纤维组织构成，对眼球起保护作用。

巩膜这里边，我们要求掌握的结构只有一个：巩膜静脉窦，它还有一个名字叫许氏管。

它在哪儿呢？就在角膜、巩膜的交界处——断面切开看，是一个环形的小管，正好落在角巩膜交界处的内面。

它和周围血管的联系也要捋清楚：这个部位有眼球的眼外肌附着，眼外肌里边有一条睫前静脉，和这个窦相通；而这个窦又和眼内腔相通。所以眼内的液体——我们待会儿要讲的房水——就能通过这个窦，再通过静脉回流出去。

> **定义**：巩膜静脉窦（许氏管）——位于角巩膜交界处内面的环形小管，与睫前静脉相通，内通眼房，作用是回收房水。

> **注意**：房水是不断地分泌、不断地回收的，靠的就是许氏管来回收。整条回流链路的终点，一直通到颈内静脉。

### 中膜：虹膜、睫状体、脉络膜

第二层膜也叫中膜，名字叫脉络膜、也叫血管膜。这层膜的特点是有丰富的血管，还有很多很多的黑色素。丰富的血管负责营养眼内组织，黑色素负责遮光。

这层膜由前向后分成三部分：最前方一个薄薄的膜叫虹膜，再向后有一个增厚的部分叫睫状体，睫状体再往后就是脉络膜。三部分正好对应它在图上"前薄、中厚、后薄"的形态。

#### 虹膜的瞳孔与两种平滑肌

先看虹膜。虹膜在哪儿？肯定在角膜的后方。严格描述的话，虹膜可以说位于角膜与晶状体之间。旁边那个双凸透镜状的结构就是晶状体，它靠一些睫状小带和睫状体相连。

从形态上看，虹膜是一个棕黑色的、圆盘状的、很薄很薄的膜。从前方看这层膜，中间有一个孔，叫瞳孔——光线就是通过瞳孔进入眼内腔的。

虹膜表面有很多很多放射状的纹理。注意，这些放射状的东西看到的是什么？是血管，所以叫血管纹——虹膜表面的血管很多的。

虹膜里边有两种平滑肌。一种是围绕瞳孔周围、呈环状排列的，叫瞳孔括约肌；另一种在它的外侧、呈放射状排列的，叫瞳孔开大肌。

> **易错点**：别把虹膜表面看到的放射状结构当成平滑肌。平滑肌在虹膜里边，从前面根本看不到；你在表面看到的放射状纹理是血管纹。

这两种肌肉的神经支配和作用，务必记牢：

| | 瞳孔括约肌 | 瞳孔开大肌 |
| --- | --- | --- |
| 排列 | 围绕瞳孔，环状 | 虹膜外侧，放射状 |
| 神经支配 | 副交感神经 | 交感神经 |
| 作用 | 缩小瞳孔（缩瞳） | 扩大瞳孔（散瞳） |

#### 睫状体：睫状突、睫状环与睫状肌

睫状体的位置和巩膜静脉窦一样——角巩膜交界处的内面。它的特点是这一段是整层膜环形增厚的部分。

要看清它的结构，我们把眼球做一个冠状切面，从后向前观察这个局部。最中心那个凸透镜状的是晶状体；晶状体的外周有很多很多向腔内凸起的皱襞，皱襞和晶状体之间还有一些纤细的睫状小带相连。

睫状体上要求记两个结构：

第一个是**睫状突**。它在睫状体最肥厚的那个部位，向腔内呈放射状排列突起——就是刚才说的那一圈向腔内凸起的皱襞。它的功能是**产生房水**。刚才说许氏管是回收房水，那水是从哪儿产生的？就在睫状突。

第二个是**睫状环**。再向外，睫状体外周那个平坦的部位，边缘呈锯齿状，这就是睫状环。

第三个要说的是睫状体里的平滑肌，也有两种：靠外的呈扇形，靠内的是环形。这两种肌肉的作用怎么理解？把睫状体的上方看成定点，上面长出来的那两种肌肉是动点。睫状肌收缩时，扇形肌肉要变短，就向上提；环形肌肉要收缩，向内移。也就是说，睫状肌收缩，整个这个凸起向内移。

凸起向内移，它和晶状体之间的小带是变松还是变紧？变松。晶状体本身是富有弹性的、弹性极高，周围一带一松，晶状体就变厚了。这时候就是看近处。

反过来，睫状肌舒张，肌肉变长，凸起外移，小带就变紧了；小带一紧，周围一拉，晶状体靠弹性被拉薄，这时候是往远看。

| | 睫状肌收缩 | 睫状肌舒张 |
| --- | --- | --- |
| 扇形肌（靠外） | 变短，向上提 | 变长，外移 |
| 环形肌（靠内） | 收缩，向内移 | 舒张 |
| 睫状小带 | 变松 | 变紧 |
| 晶状体 | 靠自身弹性变厚（变凸） | 被拉薄 |
| 视觉 | 视近，焦点变小 | 视远 |

> **结论**：睫状肌收缩 → 睫状小带变松 → 晶状体变厚 → 视近；睫状肌舒张 → 小带变紧 → 晶状体变薄 → 视远。

这两行必须能倒着背出来。倒推的用处在这儿：看书时间一长觉得眼睛累，主要是睫状肌疲劳了，那时候要主动往远看，睫状肌才能得到休息。

#### 脉络膜：靠黑色素遮光

脉络膜上有丰富的黑色素。它的功能是：外边的光线不能进到眼腔，起遮光作用；而射入眼球的光线如果出现杂色，也会被它吸收掉。挡住外面的光、消掉里面的杂色，这样成像才干净。

脉络膜这一层还有两个特点要记，都是"结合"上的讲究：

一是脉络膜和巩膜结合得比较疏松，疏松的意思就是容易分离。二是它和内膜的外层结合紧密、不易分离——这"内膜的外层"是谁？就是我们等一下要讲的视网膜，薄薄的一层，就贴在脉络膜表面。

### 内膜：视网膜

最里边的第三层叫视网膜，也叫内膜。

它从虹膜的后方开始出现，薄薄的一层，附着在睫状体的表面、脉络膜的表面，一直向后去了，整个一大圈儿。

#### 两层结构与视网膜脱离

别看它薄，这一层膜实际上还分成两层：外层是色素上皮层，内层是神经细胞层。色素上皮层同样含有丰富的黑色素。

它俩各自的"结合"特点，正好构成一组对照：

- 色素上皮层与脉络膜紧密相贴，不易分离——这也就是脉络膜的第二个特点；
- 神经细胞层与色素上皮层之间，**有潜在的间隙**。

这层潜在间隙，临床上对应一个病：视网膜脱离，也叫网脱。

```text
    脉络膜
       │
       │  紧密相贴，不易分离
       ▼
   色素上皮层 ─────────────┐
                            │  ← 潜在间隙
                            │     （视网膜脱离就发生在这里）
   神经细胞层 ─────────────┘
```

网脱是怎么来的？眼底检查的时候，如果发现这一块有个裂隙，形成一个线性的裂隙，这时候就危险了。裂隙出现以后，玻璃体的液体就很容易进入裂隙里边；进入裂隙以后，就跑到这个潜在间隙里，于是两层膜就分开了。

所以你设想这个过程：一周前检查只有一个线性的裂隙，一周后患者来复查，发现裂隙增加了、变大了，有一个薄薄的半透明膜卷下来——这就是视网膜，它这就叫网脱。

那么这个病最终的结局是什么？失明。因为脱得越来越多，脱下来的膜里就是感光细胞所在的地方，膜都脱下来了、露黑了，还能感光吗？最终结局就是失明。

> **易错点**：容易得这个病的情况主要是高度近视、视网膜变性，还有外伤。这就和视网膜"层间有潜在间隙"这个解剖特点分不开。

我过去认识一个小伙子，爱好是散打——那不是天天叫人揍吗，最后就网脱了，一只眼睛失明。

顺带把眼底检查的所见也对上号。查视野的时候先看鼻侧，视神经乳头就在那儿，视神经从这里穿出来，伴行的动脉也从这里出来，共两支；往鼻侧上、颞侧上是上方的两条动脉，鼻侧下、颞侧下是下方的两条动脉。再往旁边看，能看到一个最亮的反光点，叫中心凹，它周围有色素沉着区，这一整块就是我们说的黄斑。

#### 神经细胞层的三种细胞

神经细胞层就是最内的这一层，它含有三种神经细胞。从视网膜最外侧往里数，正好是这三种细胞，顺次把光线信号往内传，最后汇成视神经：

```text
            光线（由瞳孔进入）
                    ↓
   ┌────────────────────────────────┐
   │ ①  视锥细胞 / 视杆细胞         │ ← 最外侧
   │       感受光刺激，产生兴奋     │    靠脉络膜
   │              ↓                 │
   │ ②  双极细胞                    │ ← 中间
   │       把兴奋向内层传递         │    有两个极
   │              ↓                 │
   │ ③  节细胞                      │ ← 最内侧
   │       接受双极细胞的冲动       │
   │       每个细胞发出长长的轴突   │
   └────────────────────────────────┘
                    ↓ 轴突越汇越多
                    ↓
                 视神经（眼球后极汇聚而成）
```

最靠外侧的视锥细胞和视杆细胞，负责感受光线刺激、产生兴奋；它们之间的双极细胞有两个极，负责把视锥、视杆细胞的兴奋向内层传递；最内层的节细胞接受双极细胞的冲动，然后每个细胞发出长长的轴突，这些轴突都在眼球的后极逐渐汇聚，越汇聚越多，最后构成一条神经——视神经。

方向一定要记准：光线从瞳孔进来以后，先照到最外侧的细胞，传给中间细胞，再传给最内的节细胞，才产生视觉。

最后是这两种感光细胞的功能分工：

| | 视锥细胞 | 视杆细胞 |
| --- | --- | --- |
| 感光 | 感受强光觉 | 感受暗光觉 |
| 辨色能力 | 有 | 没有 |

球壁的三层到这里就讲完了。

### 内容物：房水、晶状体、玻璃体

第二个问题，我们来看眼球的内容物。眼球里边的结构有三种：房水、晶状体、玻璃体。

- **晶状体**：双凸透镜状，位置在虹膜和玻璃体之间，也就是虹膜的后方；
- **玻璃体**：晶状体后方很大一片范围里的胶冻状结构；
- **房水**：晶状体前方、眼球内空腔里那些无色透明的液体。

#### 眼房与房水的去向

先把"眼房"这个概念搞清。什么叫眼房？角膜与晶状体之间的眼内腔，就叫眼房。它分为两部分：虹膜后面那个较小的叫后房，前方那个较大的叫前房。前房和后房，是借瞳孔相通的——虹膜在中间，瞳孔一孔，两房就通了。

房水是无色透明的一种液体，充填在眼房内。它有三个作用。

一是营养。房水营养角膜和晶状体。角膜没有血管、晶状体也没有血管，靠谁营养？靠房水。

二是维持眼内压和眼球的外形。房水的产生和回收要保持一个动态平衡，这时候眼压就是平衡的；如果房水产生得多、回收得少，眼压就逐渐增高。外形也一样——眼球一旦受到外伤，房水流出来了，眼球是不是就塌陷了。

三是它的循环路线，这一条要完整背下来：

```text
   睫状突           后房          瞳孔          前房
   （产生）                                          │
     │                                             │
     └────────→ ──── ──── → ──── ──── → ──── ──── ──┘
                                    │
                              前房角（又称虹膜角膜角）
                                    │
                                    ↓
                            巩膜静脉窦（许氏管，回收）
                                    │
                                    ↓
                              睫前静脉 → 眼静脉
                                    │
                                    ↓
                              颈内静脉 → 心脏
```

一句话串起来：产生于睫状突，进入后房，经瞳孔到前房，移动到前房角，进入巩膜静脉窦，然后经眼静脉、颈内静脉回收，由颈内静脉带到心脏去。

你看这个循环的走向，和身体里淋巴液的回流通路很像，性质也像——都是无色透明的。

#### 晶状体与白内障

晶状体在哪儿？它在虹膜和玻璃体之间，或者说在虹膜的后方。前面讲虹膜的时候已经交代过它的样子了——剖面上就是个双凸透镜，而且富有弹性。

从形态上请记住这么几条：位置在虹膜后方；形态是双凸透镜状；特点是无色透明；外边包着一个高弹力的被膜，叫晶状体囊。

晶状体的功能我们已经知道了——它是靠睫状肌的收缩和舒张来调节薄厚的。

它要是有了疾病会怎么样？比如虹膜炎，比如外伤，再比如老年性的自然老化，晶状体里边的核逐渐要浑浊，随着年龄的增长，这叫老年性白内障。当然其他原因引起的白内障，也都是晶状体浑浊。

晶状体一浑浊，光线还能不能透过它到达视网膜？不能。那就是只有光感、没有视力。

> **提示**：讲到这儿可以把前面学的结构连成一条线——角膜、巩膜、虹膜、睫状体、小带、晶状体，这一条路上的东西我们解剖已经学过了。

白内障的手术现在可以做，植入人工晶体。这里头有几个环节值得留意：晶状体外面有一个高弹力的膜，所以手术时第一步一定是先把前膜切掉；然后把里边浑浊的晶状体核完全吸出去；再放入人工晶体。

人工晶体实际就像一个凸透镜，两边有 2 个弹力金属丝。手术前一定要先测度数——比如人家是 300 度，你就用 300 度的人工晶体，然后把两个金属丝压下来，放到晶状体囊里，金属丝再一崩开，就固定到囊里了。

```text
   ① 装入：把两侧弹力金属丝压拢
        ╱───╲
       │ 人工 │   ← 形似凸透镜
        ╲───╱
        ↓ 放入晶状体囊内
   ② 到位：弹力金属丝崩开，抵住囊壁
        ╱───────╲
       │ ┌─────┐ │
        ╲ └─────┘ ╱
           固定在晶状体囊里
```

所以晶状体的病，我们记住一句话：晶状体浑浊，就是白内障。

#### 玻璃体

最后是玻璃体。它是充填在大部分眼内腔里的一个胶冻状物质。

这个胶冻状的东西，像什么？很像我们放了很长时间的那种胶水——你说它没形吧，它很粘稠，还有一定形状；但是如果眼球有外伤，它会流出来。

它的另一个特性是：如果眼底有炎症，也会引起玻璃体混浊；如果眼底出血，血液可以渗入到玻璃体内，出现红视现象。患者来看病就会说，大夫，最近我们看什么都红颜色的；医生一看眼底，有出血。

这一块我们就不展开了。

眼球就介绍到这里。球壁三层、加上内容物三样，位置、结构、特点，出考点的地方基本都在上面这些对比关系里。休息一下，下节课继续。

## 眼副器：眼皮、结膜、泪器与眼外肌
> 对应块：BLK34 | 覆盖分集：P43 | 块标题（分集名）：《44.感觉器-眼副器、血管》

这一讲我们过眼副器。第一个问题，先从眼睑说起——俗称眼皮。眼副器这块东西不多，但每一个都是临床上天天要打交道的：病人来看病，主诉"眼皮垂下来了""眼里长了包""点眼药水点不对"，你要能听懂、要能写进病历、要能给出处理办法。所以我们把眼睑、结膜、泪器、眼外肌、眼底和眼的动脉一样一样过一遍。

### 眼睑的外部术语

先记术语。眼睑就是俗称眼皮，上方的叫**上睑**，下方的叫**下睑**；靠鼻梁那一侧是**内眦**，靠外侧、靠颞部那一侧是**外眦**。上睑最下缘和下睑最上缘这两条游离的边，都叫**睑缘**；上下睑缘之间裂开的那道缝，叫**睑裂**。

| 部位 | 术语 |
| --- | --- |
| 眼睛上方那一片 | 上睑 |
| 眼睛下方那一片 | 下睑 |
| 靠鼻侧（内侧）的角 | 内眦 |
| 靠颞侧（外侧）的角 | 外眦 |
| 上下睑各自最游离的边 | 睑缘 |
| 上下睑缘之间的裂隙 | 睑裂 |

> **结论**：记住这六个词，是因为病历必须这么写。来一个患者，这侧眼皮垂下来了，病历你就得记"**上睑下垂**"；同时睑裂是变大了还是变小了，你也得跟着写一句"睑裂变大"或者"睑裂变小"。用词不规范，临床信息就丢了。

### 眼睑断面的两个新东西：提上睑肌和睑板

翻开一个眼睑的断面看看。这一张图上有眉弓、眉、上睑、睑缘、睫毛、下睑，往里是眼球，眼球后面连着视神经，眼球表面那层是球结膜。

断面里记结构。肌肉这块，眼裂周围的**眼轮匝肌**前面学过了；上睑里今天新加一个——**提上睑肌**，它的作用就是使上睑上提。这一块要记牢，后面讲眼外肌的时候还会回来找它。

另一个结构是在眼睑的内侧，一块圆骨板状的东西，叫**睑板**。睑板里有腺体，叫**睑板腺**，睑板腺的下边就是它的排泄管，分泌物最终排到睑缘。

> **易错点**：睑板在眼睑的**内侧**——也就是贴着睑结膜的那一面，不在外侧。这一条定位你要是记反了，后面的手术刀就下错地方了。

### 睑板腺堵了会怎样：霰粒肿

睑板腺这块我重点说一下，因为它是临床天天见的东西。

临床上有个病叫**霰粒肿**，怎么回事呢？眼部卫生不注意，排泄管堵塞，睑板腺的分泌物出不来，就在里面越堆越多。堆得外面就能看出来——比如上睑这儿鼓起一个包，这就叫霰粒肿。

那怎么处理？既然睑板在**内侧**，你不能在外边儿直接下切口。得先把眼睑**翻开**，翻开以后就能看到那个肿物了，然后做**放射状切口**，把里边的分泌物排出来，**不用缝合**就可以了。

另外临床还多见的一个是**睑腺炎**，它是单个毛囊感染形成的。这两个要能分清：霰粒肿是睑板腺的排泄管堵了、分泌物淤积；睑腺炎是毛囊感染。这算是眼睑最常见的一批疾病了。

### 结膜：三部分和一个囊

第二个结构，结膜。分几部分大家知道就可以了。

睑板的内侧有薄薄的一层膜，叫**睑结膜**；白眼球表面还有薄薄的一层膜，这层是富有血管的，叫**球结膜**；它们两个相移行的那一段，叫**穹窿结膜**。

所以结膜就三块：

> **定义**：**结膜**是一层富有血管的薄膜。盖在眼睑内面的叫睑结膜，盖在白眼球表面的叫球结膜，两者移行处叫穹窿结膜。

顺带提一下**结膜囊**——就是我点点的那块区域，它是这几层结膜共同围成的一个腔，**开口与睑裂**。知道一下就行。

不过既然说到结膜囊，滴眼药水正确怎么做，我们顺手讲清楚，因为这个错的人太多了。

我在门诊碰到过一个老汉，农村来的，得了眼疾。医生说给你开个药水儿，这个药水儿必须经常点，最好是 10 分钟点一次。药水也挺贵。老汉说：开吧。开完以后再准时出来。

结果这老头一仰头，滴了一滴，然后使劲一挤眼，接着就走。走没多远儿，又一仰头，又来一滴，再一挤眼。

你们说这种滴眼药有用吗？眼药都给你挤出去了。

正确做法是：**把下睑向下牵拉，让下睑形成一个兜状**，眼药滴进去以后，**轻轻地合上眼睑，别挤**，然后**用手压住内眦**。压住内眦是干什么？一会儿讲泪道的时候大家就知道——是为了**防止眼药经鼻泪管流入鼻腔**。

### 泪器：腺体加管道

第三个结构，泪器。泪器包括两部分：一个是**泪腺**，第二部分是**泪道**。

#### 泪腺在哪儿

回忆一下运动系统讲过的眶腔：眶腔是一个**四棱锥体形**的腔，眼球在眶腔里，眶腔内侧壁上有**泪囊窝**。而泪腺的位置在**眶上壁的前外侧**，这儿有一个**泪腺窝**，泪腺就在泪腺窝内。

它的产物是泪液。

#### 泪道：点、管、囊

泪道是重点，分四部分：**点、管、囊，还有鼻泪管**。

**泪点**。把手把眼的内眦部翻开，会发现内眦部形成**两个乳头状的隆起**，叫泪乳头。这两个泪乳头的上边各有一个小孔，也就是小孔，这个小孔就是**泪点**——一个叫**上泪点**，一个叫**下泪点**。位置描述就一句话：位于**泪乳头顶端的小孔**。

**泪小管**。由泪点向下相连的管道叫**泪管**，也叫**泪小管**，分**上泪小管**和**下泪小管**。位置怎么描述呢：**泪点和泪囊之间的管道**，我们叫泪小管。上下泪小管往下走，最后汇入到一个囊腔。

**泪囊**。泪囊在哪儿？眶的内侧壁前部有一个骨性凹窝，叫**泪囊窝**，所以泪囊位于**泪囊窝内**，是一个**膜性的盲囊**。什么叫盲囊？看它的**上壁是盲端**，下端和鼻泪管相通——一头堵死（盲），一头通下去，这才叫盲囊。

**鼻泪管**。再往下就是鼻泪管。我们讲颅骨的时候提到过有个骨性的鼻泪管，这个是个**膜性**的，是套在骨性鼻泪管管腔里边的膜性管，穿行于骨性鼻泪管之内，最后**开口于鼻腔**。

把泪腺也画进来，整条路就通了：

```text
   泪腺（眶上壁前外侧的泪腺窝内）
        │  分泌泪液
        ▼
   结膜囊 ──── 湿润角膜 ────► 眼球表面
        │
        ▼
   上泪点 / 下泪点（内眦部泪乳头顶端的小孔）
        │  经上泪小管、下泪小管（泪管）
        ▼
   泪囊（泪囊窝内的膜性盲囊，上壁为盲端）
        │
        ▼
   鼻泪管（套在骨性鼻泪管内的膜性管）
        │
        ▼
   鼻腔 ──► 湿润鼻黏膜
```

正常情况下，泪腺分泌的泪液进入结膜囊，湿润角膜，然后通过上下泪点、上下泪小管到泪囊，再由鼻泪管下来，湿润鼻黏膜。这是正常的。

那什么时候会出问题？**情绪激动的时候量多了**，那就往外流吧——所以叫**痛哭流涕**。这时候你看到的就是连鼻涕带眼泪一块儿出来了。那么问题来了：它搁哪个道儿流的？鼻涕是搁鼻孔出来的；眼泪呢，是从**睑裂**出来的。所以眼泪和鼻涕虽然是一块儿下来的，走的却是两套道。

现在回头看前面滴眼药那句"压住内眦"——压住就是为了不让药水顺着鼻泪管跑到鼻腔里去，把药效白白地漏掉。

### 眼外肌：七块肌肉与总腱环

第四个结构，眼外肌。这块我们讲几个解剖关系。

#### 七块肌肉的名字

先看挂图。有一点要提醒大家：图上的眼外肌是**被人为地向外牵拉**的，**不是完全的解剖位置**，你别被它骗了。

看图辨认：眼球前方、向上方向后去的那个眼肌叫**上直肌**；下方向后去的是**下直肌**；内侧向后去的是**内直肌**；外侧向后去的是**外直肌**。再往旁边看，还有**上斜肌**和**下斜肌**。这样就 6 个了。

第 7 个在哪儿？还记得讲眼睑的时候提到的那块肌肉吗——**那块肌肉到眼睑去了，而不到眼球**，它叫**提上睑肌**。所以眼外肌一共记 **7 块**：

> **结论**：**上直肌、下直肌、内直肌、外直肌、上斜肌、下斜肌，加上提上睑肌，一共 7 块。**

#### 总腱环与各肌的附着

从侧面看，7 块肌肉是怎么走的就很清楚了。上直肌、下直肌、外直肌、内直肌、上斜肌，都向后走，**抵止在总腱环**上；只有**下斜肌例外**，它直接到**眶的内壁**。从上方看，**总腱环上还上来一块肌肉，到眼睑去，那就是提上睑肌**。

把眼球切开、眼球摘出去，看眶腔里这一圈，就更清楚了：眶腔里有**眶上裂**（记住这个位置），内侧有**泪囊窝**，**视神经从总腱环的内侧穿过**。从总腱环发出去的，往上的是上直肌（已断），内侧是内直肌，下方是下直肌，外侧是外直肌，这 4 个叫**4 个直肌**；上方还有一块**提上睑肌，它不到眼球**；再旁边有一块**上斜肌**（已断），还有一块**下斜肌，直接到眶的内侧壁**。

```text
   总腱环（眶尖处，环的内侧 = 视神经孔，视神经由此穿过）
       │
       ├── 上直肌 ────┐
       ├── 下直肌 ────┤  4 个直肌：由总腱环发出
       ├── 内直肌 ────┤  绕眼球止于眼球前面
       ├── 外直肌 ────┘
       │
       ├── 上斜肌 ──────  同样抵止于总腱环
       │
       ├── 下斜肌 ──────  唯一的例外：直接到眶的内壁
       │
       └── 提上睑肌 ────  往上出眶，到上睑去，止于上睑，不上眼球
```

所以**眼外肌把位置搞清楚，我们才能理解它的功能**。

#### 六条轴线：每块肌肉把眼球往哪儿带

从前方看眼球，记住**6 条轴线**：

- **内直肌**收缩，黑眼球**向内**；
- **外直肌**收缩，黑眼球**向外**；
- **上直肌**收缩，黑眼球**向上内**；
- **下直肌**收缩，黑眼球**向下内**；
- **上斜肌**收缩，黑眼球**向下外**；
- **下斜肌**收缩，黑眼球**向上外**。

| 眼肌 | 收缩时黑眼球的运动方向 |
| --- | --- |
| 内直肌 | 向内 |
| 外直肌 | 向外 |
| 上直肌 | 向上内 |
| 下直肌 | 向下内 |
| 上斜肌 | 向下外 |
| 下斜肌 | 向上外 |

上直肌为什么不是正上方？**因为眶腔的眶尖朝向后内，眶底朝向前外**，肌肉从后内往前外绕过来，收缩的方向就不是"正上"；下直肌同理，是**向下内**。

> **易错点**：斜肌的方向和直肌是反着来的。名字里的"上""下"说的是**这块肌肉所在的位置**，不是它把眼球带去的方向——往下转的是**上斜肌**，往上转的是**下斜肌**。这一条最容易记反，考试也最爱在这儿挖坑。

#### 临床上怎么查：瘫痪和斜视

记住这 6 条轴线，我们就可以检查哪一个眼肌瘫痪。检查的时候，只要患者能顺着你的手指按 6 个轴线走，眼肌就是正常的。

临床上也经常要判断**斜视**。

**成人**好判断。你站在他前边，手指头一伸："看我的手指。"让他往各个方向看，一下子就看出来是哪一眼、往哪个方向斜。

**小儿**麻烦，因为小孩的斜视**有很多是假性的**。小孩比较胖，皮下组织比较丰富，眼裂之间的距离显得很宽，再加上**内眦还没有完全发育**，所以看上去两个眼角内侧的距离显得特别宽。家长就说："我孩子眼睛好像斜了。"

那医生怎么判断真假？要**用一个小的手电筒，在前边 1 米多的地方一打**，叫孩子瞅你这个亮光。瞅亮光以后看哪儿？看**角膜**——看两个瞳孔里的反光点。

怎么判？

- 这一侧瞳孔**正中**是一个光点，那这只眼不斜，它正好瞅着光线了；
- 光点出现在瞳孔的**外侧**，说明这只眼**往内斜**；
- 光点出现在瞳孔的**内侧**，说明这只眼**往外斜**。

为什么小孩要这么查？因为皮下组织丰富、内眦没发育完全，看着宽。等孩子逐渐大了，皮下组织变薄了，眼裂展开了，他其实就不斜了——是假斜视。

### 眼底：视神经盘、中心凹和黄斑

第五个，**眼底**。用眼底镜看，能看出这么几个概念，这几个一定要记住。

在**鼻侧**有一个**圆盘状的结构**，叫**视神经盘**，也叫**视神经乳头**。这块记住一个特点：**没有感光细胞**。所以这个位置能不能感光？不能。我们把它叫做**生理盲点**——注意，这是**正常的**，正常人到那儿是看不到东西的。

不过这块地方我们**能看到血管**：**视网膜中央动脉**就在这儿穿过，形成**四个分支**——鼻侧上、鼻侧下、颞侧上、颞侧下动脉。它们都是视网膜中央动脉的分支。

在视神经盘**颞侧大约 3~4 毫米**的部位，能看到一个**最亮的光点**，就是**中心凹**；中心凹的**色素沉着区**，整个这一块区域叫**黄斑**。

```text
        鼻侧上动脉              颞侧上动脉
              │                  │
   鼻侧  ┌────┴──────────────────┴────┐  颞侧
         │       视神经盘             │
         │ （无感光细胞 → 生理盲点） │
         └───────────┬────────────────┘
        鼻侧下动脉    │              颞侧下动脉
                      │  颞侧约 3~4 mm
                      ▼
                     ●  中心凹（最亮的光点）
                     │  周围的色素沉着区
                     ▼
                黄斑：视觉细胞分布最密集 → 感光最敏锐
                      视网膜动脉的分支都不入此区 → 无血管营养，
                      病变恢复期很长
```

黄斑的特点要记牢：**视觉细胞分布最密集的部位就在黄斑**，所以**感光最敏锐**。这一条直接连着临床：病人来口述"我过去视力 1.5，现在突然变成 0.3"——医生首先应该想到的就是**眼底黄斑区有没有事儿**，因为只有它会出现明显的视力减退。

反过来也记一条：这几条血管有个规律，**都没有深入到黄斑区**，所以**黄斑区是没有血管的**。这个地方一旦有病变，**恢复期也是很长**的——没有血管直接营养，只能靠周边渗透，慢。

### 眼的动脉：来自颈内动脉的一支

第六个，眼的动脉。

先回到眶腔解剖：眶腔是锥体形的腔，眼球在眶腔里，后边连着视神经。眶的**内侧壁**特点是里面有**蜂窝状的腔**，那就是**筛窦**；外侧壁这边我们能看到前床突、骨松质这些结构。

眼的动脉从哪儿来？在前床突的**内侧**有一条动脉主干——**颈内动脉**。我们讲颈内动脉的时候提过：它在颈部是**没有分支**的，直接通过颅底的颈动脉管进到颅腔，营养脑髓和视器。眼动脉就是从它发出来的一支。

走法是：眼动脉进入眶腔以后，先在**视神经的外下方**，然后**绕过视神经的上方**，进入眶腔，再发出各条分支。

分支我写一下，重点记这几个：

- **视网膜中央动脉**——主干发出以后就钻到**视神经**里边去，然后分布到**眼底**，营养眼底；
- **滑车上动脉**；
- **鼻背动脉、眶上动脉**；
- **筛前动脉、筛后动脉**；
- **泪腺动脉**——到眶外侧壁那个泪腺去，还从泪腺再发出**睑外侧动脉**；另一侧发出**睑内侧动脉**；
- **睫状长动脉、睫状短动脉**（他还顺口提了一支**睫状前动脉**，说"两个一样"，记名字就行）；
- **睫状前动脉**。

```text
   颈内动脉（前床突内侧 · 颈部无分支，经颅底直接入颅）
        │
        │  发出眼动脉
        ▼
   眼动脉 ─► 视神经外下方 → 绕过视神经上方 → 入眶腔
        │
        ├── 滑车上动脉
        ├── 鼻背动脉、眶上动脉
        ├── 筛前动脉、筛后动脉 ──────► 筛窦
        ├── 泪腺动脉 ──► 泪腺 ──► 睑外侧动脉、睑内侧动脉
        ├── 睫状长动脉 ────────────► 虹膜、睫状体
        ├── 睫状短动脉 ────────────► 脉络膜
        ├── 睫状前动脉（与睫状长、短动脉同源）
        └── 视网膜中央动脉 ──► 钻入视神经内 ──► 眼底
```

分布区要能对上：到眼底的知道了；**筛前、筛后动脉到筛窦**；**泪腺动脉到泪腺**；**睫状长动脉营养虹膜和睫状体**；**睫状短动脉营养脉络膜**。

眼的动脉就是这些，**来源于颈内动脉**。

至于**眼的静脉**，这块我们就不展开了。

## 前庭蜗器：外耳、中耳与内耳的分工
> 对应块：BLK35 | 覆盖分集：P44 | 块标题（分集名）：《45.感觉器-前庭蜗器》

前庭蜗器这个名字有点怪——它不是按功能命名的，是按神经命名的。

我们过去学解剖，管它叫**位听器**，位是位置觉，听是听觉，说的是它管理头部位置觉和听觉这两件事。改叫前庭蜗器，是因为它由**前庭神经**和**蜗神经**两种神经共同组成。这两个名字说的是同一个东西：按功能叫位听器，按神经叫前庭蜗器。

组成上分三大块：外耳、中耳、内耳。这一讲的重点是**中耳**，外耳把名称和特点认下来，内耳把位置记住就行。

---

### 外耳

外耳讲三件事：耳廓各个部位的名称、外耳道的特点，还有一张膜叫鼓膜。

#### 耳廓：把各个部位的名称记下来

耳廓本身不讲原理，就记名字。最外周这个卷曲的边叫**耳轮**，里边这个隆起叫**对耳轮**；再往里有**三角窝**、**耳舟**、**耳甲艇**；到前面是**外耳门**。外耳门旁边这个叫**耳屏**，和它相对的那个叫**对耳屏**；最下面这一块叫**耳垂**。

外耳大家就记住各个部位的名称就可以了。

> **易错点**：这里的名字大多是成对的——耳轮 / 对耳轮、耳屏 / 对耳屏。看到"对"字的那个，位置比不带"对"的那个更靠内、靠后，别把两组弄混。

#### 外耳道：一个可以拉直的弯曲管道

挂图上把外耳道做一个剖面：外耳门里边这个弯曲的管道，一直到那层膜为止，这层膜就是鼓膜。

> **定义**：外耳道——外耳门与鼓膜之间的弯曲管道，长约 2.5 cm。

结构上分两部分。外侧 $1/3$ 是软骨做支架，叫**软骨部**；内侧 $2/3$ 是骨质做支架，叫**骨性部**。

> **结论**：这个管道要想变直，我们只能调软骨部，**骨性部是不变的**。

怎么调？成人向后上牵拉耳廓，整个管道就会变直；小儿不同，小儿外耳道的特点是**向后下牵拉**，外耳道才变直。

> **易错点**：成人"向后上"，小儿"向后下"，方向别记反了。

正因为要观察鼓膜的变化，必须先把外耳道调整到直的状态，这样才能往里看。

第二个特点在皮肤上：外耳道的皮肤与软骨以及骨（骨膜）结合得非常紧密，不容易分离。皮肤上还有毛囊、皮脂腺，以及别的皮肤上所不具备的一种结构——**耵聍腺**。最后一个特点：有**丰富的神经末梢**。

这就顺带解释了一个很常见的问题：外耳道一旦长了疖肿，为什么非常疼？就是因为神经末梢丰富。

#### 鼓膜：锤纹、鼓膜脐与两部

看挂图，这是右侧鼓膜。

先看一条斜行的隆起，叫**锤纹**；锤纹的末端，也就是鼓膜相当于中点这个位置，叫**鼓膜脐**。鼓膜脐的前下方有一个三角形的反光区，叫**光锥**。

膜本身分两部：上面隔着锤骨后皱襞和锤骨前皱襞，面积很小、鼓膜很松的那块叫**松弛部**；下方占绝大部分、鼓膜非常紧张的那块叫**紧张部**。

```text
                锤 骨
                  │
      ┌───────────┴───────────────────┐
      │  锤骨后皱襞 · 锤骨前皱襞  │
      │      松  弛  部               │
      │           │                   │
      │      鼓 膜 脐                │
      │           │                   │
      │        光  锥                 │
      │                             │
      │      紧  张  部               │
      └───────────────────────────────┘
```

读图：两条皱襞以上是松弛部，面积很小；中间是锤纹末端形成的鼓膜脐；从鼓膜脐往前下方展开的三角形反光区就是光锥；光锥以下直到下缘都是紧张部，占鼓膜绝大部分。

这里大家可以考虑一个问题：鼓膜穿孔最容易出现在紧张部还是松弛部？就好像给一个窗户糊一张纸，这张纸糊得松一点容易震破，还是糊得紧一点容易震破？一定是在紧张部。所以**鼓膜穿孔在紧张部**。

---

### 中耳

中耳分三部分：鼓室、咽鼓管、乳突小房。重点是**鼓室的解剖**，另外两个知道名称和位置就行——咽鼓管就是中耳通到鼻咽部的管道；乳突小房就是乳突内这些彼此相互通连的含气小腔。

#### 鼓室：藏在颞骨岩部里的含气小腔

位置一句话就能说完：**鼓室位于颞骨岩部内含气的小腔**。

这里要提一个名词——颞骨岩部。带着这个名字回忆一下以前讲颅骨时的结构：

```text
                     颅  前  窝
              鸡冠 · 筛板与筛孔 · 两侧骨板
   ──────────────────────────────────────────
                     颅  中  窝
  蝶骨小翼 · 视神经管 · 交叉沟 · 鞍背 · 垂体窝
  眶上裂 · 圆孔 · 卵圆孔 · 棘孔
                  ┌──────────────┐
                  │   颞 骨 岩   │   最高处：中窝与后窝的分界
                  │              │
                  │  鼓室盖(上壁)│ ──▶ 上方为颅中窝
                  │   鼓 室      │ ──▶ 前：咽鼓管  后：乳突小房  内：内耳道
                  └──────────────┘
   ──────────────────────────────────────────
                     颅  后  窝
  乙状窦沟 · 横窦沟 · 内耳门 · 枕大孔 · 舌下神经管
```

读图：整个三棱锥状的骨叫颞骨岩，最高处是它，上面是颅中窝、下面是颅后窝；鼓室就包在这块锥状骨的内部。

讲颞骨结构的时候我给大家提过一个**鼓室盖**，不知道大家还有没有印象。鼓室盖的骨板很薄，把这个骨板捅开，骨板里边的这个腔隙就是鼓室。所以"鼓室"才说是颞骨岩部内含气的小腔。

挂图上那张剖面大家可以这样看：这是乳突，上边是颅中窝的骨板，下壁这儿有一个弯曲的管道，这个就是咽鼓管；点点儿的都是**骨松质的网眼**，后方这些彼此相通的小腔叫**乳突小房**，都位于乳突里边。腔隙都在骨质里，那么鼓室指的是哪个腔隙呢？就是正对鼓室盖下方的那一个。

再换一个断面，从头部上面往下看：外耳道在这儿，外耳道里能看到一层膜状结构，就是鼓膜；由鼓膜再向后，这个小腔是**鼓室**；鼓室再往后的一个小腔叫**鼓窦**；鼓窦再向后就是相通的这些小房，乳突小房。向前通的那个管是咽鼓管。鼓室内侧还有一个重要结构——**内耳**，非常小，得放大才看得清；内耳再往内侧还有一个骨性管道叫**内耳道**，就是讲颅骨时提到的内耳门通出来的那一条。

另外这块里还有一块肌肉，叫**鼓膜张肌**，在挂图上这些结构是看不到的。

#### 鼓室的六壁：名字都是从邻居来的

鼓室一共六个壁。讲的时候你会发现一件很省力的事——**每个壁的名字，都是按它旁边那个"邻居"取的**。把邻居认全，六个壁的名字自然就记住了。

| 壁 | 名称 | 毗邻或交通 |
| --- | --- | --- |
| 上壁 | 鼓室盖 | 与颅中窝相邻；骨板很薄 |
| 下壁 | 颈静脉壁 | 与颈内静脉相邻 |
| 前壁 | 颈动脉壁 | 与颈内动脉相邻；上方有鼓膜张肌，下方经咽鼓管与鼻咽部相通 |
| 后壁 | 乳突壁 | 经鼓窦与乳突小房相通 |
| 外侧壁 | —— | 就是鼓膜 |
| 内侧壁 | 迷路壁 | 与内耳（迷路）相邻 |

逐个落实一下。上壁叫鼓室盖，因为它正上方就是颅中窝。下壁下方正好有颈内静脉，所以叫颈静脉壁。前壁的前方是颈内动脉，所以叫颈动脉壁——记住这两个大血管的位置，手术的时候要注意，如果这块儿操作过于粗糙，就会把动脉、把静脉搞破出血，而且不容易止住。

前壁值得多说两句：它的上方有一块肌肉，就是刚才说的鼓膜张肌；下方是一个管道，叫咽鼓管，**相通**。相通到哪儿去呢？回忆一下我们讲咽的时候，是不是提到过一个咽鼓管？它的咽口是在咽部（鼻咽部）开始的，一直通到中耳鼓室。所以记住这句：咽鼓管就是中耳到鼻咽部的这个管道。

后壁看图上这个开口，它整个通向乳突的内腔，所以叫**乳突壁**，是相通的关系——通过鼓窦与小房相通。

外侧壁好说，隔着鼓膜这一层膜看到的鼓室，这个膜就是鼓膜，所以外侧壁就是一个鼓膜。

内侧壁是一个结构，**内耳**；内耳还有一个名字叫**迷路**，所以内侧壁也叫**迷路壁**，与内耳相连。内侧壁上的细节我们下一段单独说。

#### 鼓室内侧壁与中耳炎的四个并发症

鼓室内侧壁上要认这几个结构。从断面图上看：这里下行一个面神经，它是从一个骨性管里钻出来的，这个骨性管叫**面神经管**，从面神经管下来就是以后要介绍的面神经；图上标出的那个凸起叫**面神经管凸**，里面走的就是面神经。在它旁边还能看到两个孔，一个椭圆形的、一个圆形的，叫**前庭窗和蜗窗**；还有一个隆起叫**骨岬**。

这里顺便把内侧壁的临床含义点一下：前庭窗是被三个听小骨中的**镫骨**封闭的，蜗窗被一层膜封闭，我们管它叫**第二鼓膜**。这些结构大家知道名称就行了，最主要要记住内侧壁有个**面神经管凸**，里面是面神经。

> **结论**：六壁都认识了，中耳炎的蔓延路径就很好推了。炎症从上呼吸道感染来，通过咽鼓管到鼓室，然后往四个方向走——**这四个并发症和我们的解剖密切相关**。

| 蔓延方向 | 后果 | 解剖依据 |
| --- | --- | --- |
| 向上 | 颅内感染 | 破坏鼓室盖进入颅腔（骨板很薄，上方就是颅中窝） |
| 向后 | 乳突炎 | 后壁经鼓窦与乳突小房相通 |
| 向外 | 鼓膜穿孔 | 外侧壁就是鼓膜 |
| 向内 | 面瘫 | 腐蚀内侧壁的面神经管凸，伤及面神经 |

> **注意**：鼓膜一旦穿孔，疼痛会立即减轻，但病**并没有好**。有时候家属看到不疼了，以为病已经好了，实际上鼓膜已经穿孔了。

### 内耳

内耳简单说，包括骨性部分和膜性部分两大块。

#### 骨迷路与膜迷路：一副骨架子套一层膜袋子

看挂图，外周的这个就是骨性部分，它由三部分构成：一个是**耳蜗**，像个蜗牛壳一样；中间这一部分膨大的叫**前庭**；然后还有三个管道——外半规管、前半规管、后半规管，合称**骨性半规管**。

从透视的角度看，管里边是不是还套了一层？那一层就是膜性的结构：耳蜗里边套的是膜性的**蜗管**；前庭里边套了两个囊，**球囊**和**椭圆囊**；在半规管的每个基底部膨大的部位里边，还套一个膜性的**壶腹嵴**。

打个不恰当的例子：这两部分的关系，好像是**自行车的外带和内带**，外带是骨性部，内带是膜性部。

```text
外带 ＝ 骨迷路                        内带 ＝ 膜迷路
┌──────────────────┐                ┌──────────────────────┐
│ 耳蜗（蜗牛壳状） │ ── 套 ──▶     │ 蜗管（盘曲 2 圈半）  │
├──────────────────┤                ├──────────────────────┤
│ 前庭（中间膨大） │ ── 套 ──▶     │ 球囊 ＋ 椭圆囊       │
├──────────────────┤                ├──────────────────────┤
│ 骨性半规管 ×3    │ ── 套 ──▶     │ 膜半规管 ×3          │
│ 外 · 前 · 后     │                │ 壶腹嵴在基底部膨大处 │
└──────────────────┘                └──────────────────────┘
```

读图：左边是骨迷路（耳蜗、前庭、骨性半规管），右边是套在它们里面的膜迷路（蜗管、球囊与椭圆囊、膜半规管），一对一对套起来，就是内耳的两大部分。

膜迷路内部自己还是连通的，这一点在简图上看得最清楚：蜗管盘曲 2 圈半，它通过一个细管和一个球囊相连，球囊又通过细管和一个椭圆囊相连，椭圆囊又和每个膜半规管根部那个膨大的腔相连，然后再延续到管道里面去。

```text
蜗管 ──细管──▶ 球囊 ──细管──▶ 椭圆囊 ──▶ 膜半规管根部的膨大腔 ──▶ 管内
```

#### 感受器分别在哪儿

听觉感受器在蜗管里，名字叫**螺旋器**，它感受听觉。

位置觉的感受器分两处：**静止的头部位置**和**匀速的直线运动**，感受器都在**球囊、椭圆囊**；如果是**旋转运动**，感受器在**壶腹嵴**。

| 头部的情况 | 位置觉感受器所在 |
| --- | --- |
| 静止时的头部位置觉 | 球囊、椭圆囊 |
| 匀速的直线运动 | 球囊、椭圆囊 |
| 旋转运动 | 壶腹嵴（位于半规管基底部膨大处） |

所以球囊、椭圆囊和壶腹嵴都是位置觉感受器的位置，把这张表记住就够了。

最后再重复一遍这一讲的分工：前庭蜗器里，重点给大家介绍的是**中耳**，外耳认名称和特点、内耳认位置，其他的我们就不展开了。
