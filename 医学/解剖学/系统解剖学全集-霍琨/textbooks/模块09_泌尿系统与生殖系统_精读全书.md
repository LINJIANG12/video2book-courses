## 输尿管、膀胱与女性尿道：一根细管和一个储尿仓库
> 对应块：BLK22 | 覆盖分集：P30 | 块标题（分集名）：《30.泌尿系统-输尿管、膀胱及女性尿道》

这一讲我们把泌尿系统里剩下的三块讲完：输尿管、膀胱，还有女性尿道。这三样东西其实是连着的一条线——肾盂里接出来的尿，顺着一根细管往下流，先进一个能存起来的仓库（膀胱），最后从一条短短的通道排出去。整节课的内容围绕三块展开，我们一块一块来看。

### 输尿管：顺着腹后壁一路下行到膀胱

#### 位置：肾盂到膀胱的 20 到 30 厘米

先说位置。请大家看一下挂图：我们看到的这是肾脏，这根管道叫输尿管，到膀胱去。所以它的位置是——**起于肾盂，相当于第二腰椎水平；止于膀胱**。肾盂与膀胱之间这 20 到 30 厘米的肌性管道，就叫输尿管。

这句话我们再捋一遍：起点是肾盂（在第二腰椎这个水平），终点是膀胱，中间的距离是 20 到 30 厘米。这三个数一起记。

#### 板图上的定位：先把地标摆出来

要讲输尿管怎么走，得先把这张腹后壁的板图看熟。我给大家描述一下这张图上都有什么。

板图正中腹后壁上一根动脉，叫**腹主动脉**，大约在**第四腰椎水平**开始分支，主干分成两大支，就是**左右髂总动脉**；这两支到了**骶髂关节前方**又分成**髂内动脉和髂外动脉**。我们把两侧的**腹股沟韧带**画出来，韧带的后方就是膀胱，膀胱的后方有一根肠管是直肠——显见这是个男性。

腹主动脉上还有一堆分支，以后的课我们讲腹腔动脉时会专门讲：左右走行的**肾动脉**、**睾丸动脉**，还有**肠系膜上动脉、肠系膜下动脉、骶正中动脉**等等。肾动脉相连的就是肾，所以肾在这里；肾的下方有一块肌肉，是我们以前学过的**腰大肌**。

这些东西看着啰嗦，其实每一根动脉、每一块肌肉都是给输尿管当路标的。

#### 走行与分部：腰大肌前方下降，跨髂血管入盆

有了地标，输尿管的走法就清楚了：**从肾盂出来，沿着腰大肌的前方下降，跨过髂血管，进到盆腔，最后止于膀胱**——准确说是到达膀胱底，然后斜穿膀胱壁，开口于膀胱。

```text
        肾盂（第 2 腰椎水平）
             │
             │  沿腰大肌前方下降
             │  （腰大肌在输尿管的后面）
             ▼
        跨过髂血管  ← 第 2 狭窄
        （骶髂关节前方，髂总动脉
          已分为髂内、髂外动脉）
             │  入盆
             ▼
        膀胱底 → 斜穿膀胱壁 → 膀胱内开口
                   ↑ 第 3 狭窄、壁内部

        输精管由睾丸、附睾上来，在输尿管的上方，
        它的末端从输尿管下方进入膀胱
```

按这个走行，输尿管正好分成三部分：

| 分部 | 范围 |
| --- | --- |
| 腹部 | 从腰大肌前方下降到跨髂血管这一段 |
| 盆部 | 跨过髂血管以后入盆，直到膀胱底这一段 |
| 壁内部 | 斜穿膀胱壁的那一段 |

这里容易搞错的是"分界点在哪里"。别去背百分比记比例，就记住两句话：**腰大肌前方到髂血管，是腹部；跨过髂血管进盆腔，是盆部**。而"壁内部"不是它在盆腔里的一小段，它是**斜着扎进膀胱壁里**的那一段。

> **易错点**：壁内部是"斜穿膀胱壁"形成的，不是"贴着膀胱壁走"的一段。

#### 斜穿膀胱壁：一个天生的阀门

什么叫斜穿膀胱壁？大家看图，这是膀胱壁，膀胱内壁的内侧有非常非常多的皱襞。输尿管从上方下来，穿进膀胱壁里边时是**斜着穿**的，就在壁上斜着形成了一个开口。尿液通过这个开口进入膀胱。

那它斜着穿有什么好处呢？实际是一个**阀门**。大家设想：膀胱是一个储尿器官，尿储得越多，膀胱壁的张力就越大；张力越大，对壁内这一段管道的压迫是不是就越厉害？一压迫，这管道就关闭了。

也就是说：膀胱充满的时候，这个开口暂时关闭，尿液不会从膀胱里倒流回输尿管；等我们把膀胱排空，张力下降了，这个管又开放，继续储存尿液。

```text
   膀胱充盈、壁张力增大             膀胱排空、壁张力下降

   ┌──────────────┐                 ┌──────────────┐
   │    膀胱腔    │                 │    膀胱腔    │
   │  尿液增多    │                 │              │
   └──────────────┘                 └──────────────┘
       ╲      ╱                         ╲      ╱
        ╲════╱                           ╲════╱
      输尿管壁内段                     输尿管壁内段
  （被压闭，不返流）                （重新开放，继续储尿）
```

图后一句话：膀胱张力一变，壁内段的"闸门"就一开一合——排尿方向是单向的，尿冲不回去。

#### 三个狭窄：结石最爱卡住的地方

输尿管全长有三个狭窄，这三个地方是泌尿系结石**最容易嵌顿**的部位：

- **起端**，也就是和肾盂相接的那个部位；
- **跨过髂血管**的那个部位；
- **斜穿膀胱壁**的那个部位，相对比较窄。

> **结论**：三个狭窄 = 肾盂输尿管连接处 + 髂血管交叉处 + 膀胱壁内斜穿处。

为什么临床要反复强调这三个点？因为泌尿系结石顺着输尿管向下冲刷的时候，就会产生**剧痛**。石头本来在肾里，待着的时候可能没什么感觉；一旦往下掉，挤过这三个窄地方，每挤一下都是一次剧痛。所以这三个狭窄，实质上就是结石卡住和肾绞痛发作的位置。

#### 四个交叉：谁在前，谁在后

第四个问题：输尿管全长有**四个交叉**，也就是和周围结构交叉的地方。我们在图上找一找。

第一个交叉在肾的下段，和动脉交叉，是**睾丸动脉**；第二个在盆骨上口，和**髂血管**交叉；第三个在盆壁，和**闭孔动脉**交叉；第四个在膀胱底下方，这个我们放大来看。

第四个交叉要仔细：这是膀胱的后方，膀胱后面有**输精管**和**精囊腺**，再往下是**前列腺**，这是膀胱底。输尿管从上面下来，是**从输精管的下方**进到膀胱里去的。

四个交叉的位置关系不一样，别搞混：

| 交叉的血管／管道 | 位置关系 |
| --- | --- |
| 睾丸动脉 | 动脉在前，输尿管在后（前后） |
| 髂血管 | 输尿管在前，髂血管在后（前后） |
| 闭孔动脉 | 输尿管在内侧，动脉在外侧（内外） |
| 输精管（精索内） | 输精管在上，输尿管在下（上下） |

前两个是"前后"关系，第三个是"内外"关系，第四个是"上下"关系——四种关系各来一遍，这也是我们为什么要一个一个定位，而不是笼统记一句"有四个交叉"。

### 膀胱：能装 350 到 500 毫升的储尿仓库

第二个大问题：膀胱。

膀胱是一个**储尿器官**，能够储存的尿液大约是 **350 到 500 毫升**。它是这一讲里唯一一个"有容量指标"的器官，所以我们先从它的量、形态、位置、毗邻一层层往下看。

#### 形态：空虚是锥体，充盈是卵圆

因为膀胱是储尿器官，储存尿液的多少决定了它形态的变化，所以我们分**空虚时**和**充盈时**两种状态来讨论。空虚的膀胱和充盈的膀胱肯定不一样。

**空虚时膀胱呈锥体形**。看这张空虚膀胱的矢状切面，我们把它分成四部分：朝向后下方的这部分叫**膀胱底**，中间的大部分叫**膀胱体**，前上方的这个叫**膀胱尖**，下方这个叫**膀胱颈**。

> **定义**：膀胱四部分 = 底（后下方）、体（中间大部分）、尖（前上方）、颈（下方）。

这里有个关键限定条件：**只有空虚的时候，膀胱才能清楚地区分出这四部分**。为什么？因为收缩状态下它有自己固定的形状；一旦充盈，壁被撑开、彼此拉平，这四个部分就没有清楚的界线了。

**充盈时膀胱呈卵圆形**，四部之间的界限也就分不出来了。

#### 位置与腹膜：充盈时把腹膜腔顶上去

膀胱的位置我们还是分两种状态讨论，而且要用到腹膜这个关系。

看这张男性盆腔的矢状断面：阴茎、阴囊、耻骨联合、腹前壁；这里边是膀胱，膀胱下边有前列腺，尿道穿过它。腹膜覆盖在膀胱的表面，然后再反折到直肠。

**空虚时的膀胱，它不超过小骨盆上口**。看图上耻骨联合的上缘，膀胱并没有超过它——就老老实实待在骨盆里。

换一个状态，**充盈时的膀胱**：还是耻骨联合、腹前壁，但膀胱已经变成了卵圆形，往上膨大了，**这时候它已经超出了小骨盆上口**。同时，因为膀胱往上顶，**腹膜被向上推移，腹膜腔也跟着上移**。

```text
   【空虚时】                         【充盈时】
   ┌────────────┐                   ┌────────────┐
   │  腹前壁    │                   │  腹前壁    │
   ├────────────┤                   ├────────────┤
   │  耻骨联合  │                   │  耻骨联合  │
   │            │                   │            │
   │  ┌──────┐  │                   │  ┌──────┐  │
   │  │膀胱  │  │ 不超过上口        │  │膀胱  │  │ 已超过上口
   │  └─┬────┘  │                   │  │卵圆  │  │
   │  ┌─┴────┐  │                   │  └─┬────┘  │
   │  │前列腺│  │                   │  ┌─┴────┐  │
   │  │尿道  │  │                   │  │前列腺│  │
   │  └──────┘  │                   │  │尿道  │  │
   └────────────┘                   │  └──────┘  │
   腹膜覆于膀胱表面，再             └────────────┘
   反折到直肠                       腹膜被向上推移，
                                    腹膜腔升高
```

图后一句话：膀胱一充盈就往上升，而腹膜是"被顶上去"的——这一上一下的关系，就是后面所有临床操作的解剖学基础。

所以把位置整理一下：**空虚时不超过小骨盆上口（在耻骨联合上方的骨盆腔内）；充盈时则超过小骨盆上口。**

#### 临床用法：穿刺、造瘘与取石

我们利用的正是这个"膀胱上移、腹膜被顶上去"的解剖关系。

**膀胱穿刺**：在膀胱充盈的状态下可以做穿刺，因为这时膀胱顶到腹壁下面、腹膜被推到更高处，从下往上进针就不会伤到腹膜。

**膀胱造瘘**：什么叫膀胱造瘘？手术做一个小切口，然后下一个管道下来，接到一个尿袋里；尿液滴入尿袋，满了以后再倒掉。这就叫膀胱造瘘。**当这个尿道不能排尿的时候，就可以用这个办法**。

**取石**：如果膀胱底部有一个比较大的结石，需要手术取出来，也可以利用这个解剖关系从这儿取。有同学会问：从上面取不行吗？上面当然也可以。但是大家想——如果在这个部位（从腹腔那一侧）进行手术取这个石，尿液渗入什么腔？渗入**腹膜腔**，污染了腹膜腔。

所以这个不是好选择。为什么从下面取是"最好的关系"？正因为充盈时**腹膜腔已经上移**，从下方进入不会污染腹膜腔。

> **结论**：腹膜与膀胱的关系，决定了临床上从下方（耻骨联合上）进入膀胱是安全的，从上方经腹腔取石会污染腹膜腔。

#### 毗邻：男性后方是直肠，女性后方是阴道和子宫

第三个问题，膀胱的毗邻。这里我们**只注意前后的关系**。

先看男性这张图：这是耻骨联合，这是盆底肌肉，这是膀胱、前列腺、尿道；膀胱后方有一根肠管——**直肠和肛管**。腹膜覆盖在膀胱表面，然后反折到直肠。

前面这一堆：男性在**耻骨联合到前列腺之间**有一条韧带，叫**耻骨前列腺韧带**。除此之外，这个间隙里还有**大量的静脉丛**，除此还有一些**脂肪组织**，都在这儿。

后面这一堆：矢状切面上能看到**输精管的末端和精囊腺**，它们组成**射精管**。

所以男性的毗邻关系，大家记住：后方应该是直肠，前方的这些韧带、静脉丛不用细记。

再看女性。女性膀胱的后边是不是也是直肠呢？女性的膀胱、女性的尿道比较短，旁边是阴蒂、小阴唇；这个部位有一个肌性管道，前后扁窄的肌性管道叫**阴道**，上边是**子宫**，再向后才是**直肠**。腹膜是反折到子宫前壁、后壁，再到直肠的。

女性这边的前方也有一个韧带，叫**耻骨膀胱韧带**，同样也有很多很多的静脉丛。

关键看后方：女性膀胱后方邻的就是**阴道和子宫**。

| 性别 | 膀胱后方紧邻 | 腹膜反折到 | 前方韧带 |
| --- | --- | --- | --- |
| 男性 | 直肠、肛管 | 直肠 | 耻骨前列腺韧带 |
| 女性 | 阴道、子宫 | 子宫前壁、后壁，再到直肠 | 耻骨膀胱韧带 |

> **提示**：两性前方那条韧带所在的间隙里，都还塞着丰富的静脉丛和脂肪组织。

#### 膀胱三角：唯一光滑的那块黏膜

最后一个结构特别重要，叫**膀胱三角**。我们分三步：位置、组成、特点。

**先看位置**。我们把膀胱做一个冠状切面，从前看后面一半，看到的膀胱是这样：这是切开的断面，下边（男性）有前列腺，膀胱内壁有皱襞，这是**尿道内口**。在这我们看到一个**三角区**。

三角区以外，膀胱内壁都有很多很多的皱襞；**唯独这个三角区里面没有皱襞**。我们把这个三角区叫做膀胱三角。这么切下来正好是在膀胱底的内面，所以：

> **定义**：膀胱三角位于**膀胱底的内面**。

**再看组成**。这个三角区是怎么来的？图上这是两个管道的开口，也就是**左、右输尿管的膀胱口**；这个口再往下续就是尿道，叫**尿道内口**。所以：

> **定义**：膀胱三角由**左输尿管膀胱口、右输尿管膀胱口、尿道内口**这三个开口围成。

**最后看特点**。这个三角区和其他部位不一样：其他部位有非常非常多的皱襞，而三角区没有——**黏膜光滑，无皱襞**。

它还有一个临床上的身份：**它是结核和肿瘤的好发部位**，膀胱结核、膀胱的肿瘤一般都发生在这个部位。临床上做**膀胱镜检查**，主要就是检查这个三角区。

一句话记住这块特殊的黏膜：**位置在膀胱底内面，三个口围成，光滑无皱襞，结核肿瘤好发，膀胱镜重点看。**

### 女性尿道：短、直、宽，所以容易感染

最后一块，女性尿道。

看这张女性盆腔的矢状断面：膀胱，这部分是**女性尿道**，后方依次是子宫、阴道、直肠。

女性尿道有什么特点？它**长 3 到 5 个厘米**，特点是**短，而且直，还宽**。

为什么医生喜欢强调"短、直、宽"这三个字？因为这样一个又短、又直、又宽的管道，**细菌最容易进入女性尿道**。所以在临床上，**泌尿系统的逆行感染，女性多于男性**——道理就在这里。

> **结论**：女性尿道 3～5 cm，短、直、宽，屏障作用弱，所以泌尿系逆行感染女性多于男性。

到这里，这一讲的三块内容——输尿管、膀胱、女性尿道——就介绍完了。

## 男性生殖系统：从睾丸一路走到尿道外口
> 对应块：BLK23 | 覆盖分集：P31-P32 | 块标题（分集名）：《31.男性生殖系统生殖腺与输送管道》

### 生殖系统只有两大部分

这节课讲男性生殖系统，但先得把框架搭起来——不然后面一堆管道和腺体全糊在一块儿。

不管男性还是女性，生殖系统都由两大部分构成：**内生殖器**和**外生殖器**。

内生殖器又包括三块：生殖腺、输送管道，还有一些附属腺体。

男性这边：生殖腺是睾丸；附属腺体是精囊腺、前列腺、尿道球腺；外生殖器是阴茎和阴囊。

```text
                        生 殖 系 统
                ┌───────────┴───────────┐
             内生殖器                 外生殖器
        ┌────────┼────────┐              │
      生殖腺   输送管道   附属腺体      阴茎 · 阴囊
       睾丸   输精管      精囊腺
             精索        前列腺
             射精管      尿道球腺
             尿道
```

这个三分类先立住，后面讲到的东西全往上头这三块上装。

### 睾丸：一个器官，两个功能

第一个正式介绍睾丸，我们按老规矩来：**形态、位置、功能**，三件事分开讲。

#### 形态：扁卵圆形，方向和肾正好相反

看挂图，这是一张模式图。上方是膀胱和前列腺，再往下是盆底的肌肉，阴茎里的尿道两侧、阴囊里两侧那两枚卵圆形的结构就是睾丸；后上方那个粗细不等的长形结构叫附睾。

从形态上讲，睾丸是**扁卵圆形**。它的各部位怎么叫？

- 上下两端：上端、下端；
- 前后两边：前缘、后缘；
- 内外两面：外面、内面。

> **易错点**：记住这个方向和肾脏**正好相反**。肾脏是前后为面——因为它扁贴在腹后壁上；内外为缘。睾丸是前后为缘，内外为面。这两个别记混了。

#### 位置：阴囊内，左右各一

从盆腔矢状切面看，阴茎后方的皮肤囊袋叫阴囊，阴囊里那枚扁卵圆形的结构就是睾丸。所以睾丸位于阴囊内。

再换一个角度，从前方观察：把阴茎提起来，再把阴囊前壁打开，会发现阴囊正中间有一个隔，把阴囊分成左右两个腔，每个腔里各容纳一个睾丸。

所以睾丸的位置就是三句话：**位于阴囊内，左右各一，是一对。**

#### 剖开：白膜、小隔、小叶，里面全是小管

在讲功能之前，先把睾丸剖开看结构——不然功能挂不上去。

把睾丸做一个断面，椭圆形的外壳很坚韧，叫**睾丸白膜**。白膜向睾丸实质内发出很多**睾丸小隔**，小隔把睾丸划分成若干个**睾丸小叶**。

小叶里面有什么？有管道——**曲细精管**和**直细精管**，每个小叶里都有。

直细精管在睾丸后缘这个位置进入睾丸的另一个结构，叫**睾丸纵隔**。小管从睾丸后缘发出，发出以后就叫**睾丸输出管**，输出管进到附睾里去，在附睾内形成了盘曲的**附睾管**。

整条路是这个走向：

```text
        睾丸白膜
              │  发出
              ▼
        睾丸小隔 ──→ 睾丸小叶（若干个）
                          │  内含
                          ▼
                   曲细精管 + 直细精管
                          │  直细精管在睾丸后缘进入
                          ▼
                     睾丸纵隔
                          │  在后缘发出
                          ▼
                     睾丸输出管 ──→ 进入附睾
                                       │
                                       ▼
                                 附睾管（盘曲）
```

#### 功能：精子在曲细精管，激素出自间质细胞

第一个功能，记住它——**产生精子**。

精子在哪里产生？就在曲细精管内。产生以后的路线是固定的：曲细精管 → 直细精管 → 睾丸纵隔 → 睾丸输出管 → 附睾管，再往下由输精管、射精管一路输送。

第二个功能，**分泌男性激素**。激素不是在那些小管里分泌的——注意看，这些管道**之间**有**间质细胞**，是间质细胞分泌男性激素，**直接入血**。

男性激素维持男性的第二性征：声音、喉结、胡须，全靠它。

### 附睾：贴在睾丸后上方的头体尾

附睾也按三件套来：形态、位置、功能。这一节形态和位置讲得干脆。

形态：是一个**长而粗细不等的扁圆器官**。从形态上把它分成三部分——前方膨大的叫**头**，中间的叫**体**，末端的叫**尾**。

位置：在**睾丸的后上方**。

后面讲输精管的时候还会用到它：输精管正是从附睾尾部起始的。

### 输精管：从附睾尾一路走到膀胱底

#### 走行全程

输精管的起始部在**附睾尾部**。从板图上看，路线是这么走的：

在睾丸的后内侧上升 → 经过阴囊根部 → 再经过腹股沟管 → 进入盆腔 → 到达膀胱底。

到了膀胱底，它和一个腺体的排泄管共同组成一个管道，叫**射精管**——这是个非常短的管道。输精管走行全程到此为止。

#### 分布四部

从附睾尾部往上数，输精管分四部分：

| 名称 | 范围 |
| :--- | :--- |
| 睾丸部 | 从附睾尾部上升的这一段 |
| 精索部 | 从睾丸上端到腹股沟管的皮下环 |
| 腹股沟管部 | 在腹股沟管内的那一段（简称管部） |
| 盆部 | 进入盆腔之后的部分，四段里最长的就是它 |

#### 手感硬如麻绳，结扎点由此定

输精管这个管道的特点很好记：**腔小壁厚**——管腔非常小，管壁非常厚。而且手感是**硬如麻绳**，非常硬。

这个手感直接决定了临床上怎么做。做输精管结扎的时候，很容易辨认它：手往里一摸，最硬的那个就是。

所以男性结扎术应该选择在**阴囊根部**结扎。为什么选这儿？阴囊根部这块最表浅，皮肤切个小口就行；里边是一根柔软的索状结构，在那里一摸，把最硬的输精管勾出来，一结扎就完成了。

### 精索：从腹环到睾丸上端的一束结构

精索是一个柔软的索状结构。

范围是：**从睾丸上端一直到腹股沟管的腹环**，这一段就精索。

为什么这一段要叫"索"？因为动脉、静脉、淋巴、神经，都是通过腹环进入腹股沟管的，和输精管相伴而行，然后继续伴行，一直到睾丸的上端。这么一束东西同行，就打成一个索。

精索的组成有五样：

- **睾丸动脉**
- **蔓状静脉丛**（静脉）
- **神经**
- **淋巴**
- **硬如麻绳的输精管**

```text
      腹股沟管腹环
            ║
            ║   ← 这一整段就是"精索"
            ║      动脉 · 静脉 · 淋巴 · 神经 · 输精管
            ║
      睾丸上端
            │
         睾丸
```

### 射精管：最短的一段

关于射精管，就了解这么三件事：**怎么合成的、在哪里、开口于什么部位**。

合成：输精管的末端膨大，叫**输精管壶腹**；壶腹和**精囊腺的排泄管**汇合，就构成射精管。汇合以后，这一小段钻到前列腺里边去了。

位置：**前列腺实质内**。对着前列腺的水平切面看得很清楚——前列腺后方有前列腺沟，中间有尿道贯穿，尿道后壁形成了一个纵行隆起叫**尿道嵴**；前列腺前方是前叶，后方是中叶，再向后是后叶，两侧是侧叶。精囊腺的排泄管和输精管壶腹从后方汇合，构成的这个管道就是射精管。

**射精管是一对**，左右各一条，穿过前列腺。

开口部位：开口于**尿道的前列腺部后壁**。具体说是尿道嵴中间膨大部位下方的两个小孔。

### 精囊：长椭圆形的囊

下面进入附属腺体。先看精囊，也叫**精囊腺**，还是形态、位置、功能三件套。

从后方观察膀胱、前列腺以及精囊：中间是膀胱，朝向后方的这一部分叫**膀胱底**；膀胱底的后方是一条管道，这是输精管的末端；管道外侧那个长椭圆形的腺体就是精囊。

形态：**长椭圆形的囊状器官**——把它剖开以后，里面都是腔。

位置：**膀胱底的后方**。

功能：分泌**淡黄色的、粘稠的液体**，这个液体参与精液的组成。

### 前列腺：栗子形，重点是前列腺沟

前列腺我们作为重点。掌握它的形态、位置和毗邻；知道前列腺实质内有哪些管道穿过；知道它可以分为多少个叶；最后知道功能。

#### 形态与位置

形态：**栗子形，底朝上，尖朝下**。尖端下方正好是盆底的肌肉。

形态上重点要记住**后方**：这里有个**前列腺沟**。

> **易错点**：**前列腺肿大的时候，这个沟就消失了。**记住这个特点——它是后面讲肛门指诊的钥匙。

位置：可以说在**膀胱与尿生殖隔之间**，或者说**膀胱底的下方**。

顺便说个细节：看膀胱内壁这张图的时候，你会发现膀胱底那一块我没画黏膜的曲线——因为这是**膀胱底的内面**。膀胱内壁别处都有隆起，只有膀胱底是光滑的：**膀胱三角最大的特点就是黏膜平滑、无皱襞**。这个点前面讲膀胱三角时讲过，这里再落实一遍。

#### 后方贴着直肠

毗邻关系大家记住：**前列腺的后方是直肠，与直肠的前壁紧贴**。

这一条在临床上直接换来一个操作——**肛门指诊**。

怎么做？比如患者排尿困难，怀疑是前列腺肥大，我们就可以做肛门指诊。经直肠的前壁能摸到前列腺，摸着什么呢？摸前列腺沟。**如果前列腺沟消失了，说明前列腺肥大**，而这正好符合患者排尿困难这个临床表现。

> **结论**：前列腺肿大时前列腺沟消失——这一条一定要记住，位置和毗邻讲完就能直接推出来。

#### 实质内穿过三种管道

前列腺实质内有哪些管道穿过？记三部分：

- **尿道**，贯穿前列腺；
- **射精管**，一对；
- **前列腺本身的排泄管**。

从正面观这张图看下来：先是膀胱内壁，尿道内口往下贯穿前列腺，再往下是盆底肌肉。盆底肌这一块里还藏着一个腺体叫**尿道球腺**，它通过导管开口于**尿道海绵体部**。

再看尿道前列腺部剖开的样子：后壁有一个纵行隆起叫**尿道嵴**；在嵴的中间膨大部位的下方，有**两个小孔**——这就是射精管的开口。另外在后壁上还有很多很多小的开口，那是前列腺本身排泄管的开口。

把前列腺水平断一下同样能对上：中部有尿道贯穿；后方和精囊腺汇合的那一小段管道，就是前面说的射精管，一对，左右都有。

#### 五个叶

前列腺可以分成几个叶？从前列腺的水平面上看：后方是前列腺沟，中间有尿道。分叶是这样的——

前方这块有一个叶，叫**前列腺前叶**；后方是**前列腺中叶**；再向后是**前列腺后叶**；两侧是**前列腺侧叶**。

标一下就清楚了：前叶、中叶、后叶，加上两个侧叶，**一共五个叶**。

#### 功能

前列腺也分泌液体：分泌的是**浓白色的、碱性液体**，同样参与精液的组成。

到这里两个附属腺体讲完了，放一起对一眼：

| | 精囊（精囊腺） | 前列腺 |
| :--- | :--- | :--- |
| 形态 | 长椭圆形的囊状器官 | 栗子形，底朝上、尖朝下 |
| 位置 | 膀胱底的后方 | 膀胱底的下方，位于膀胱与尿生殖隔之间 |
| 分泌物 | 淡黄色的、粘稠的液体 | 浓白色的、碱性液体 |

两者的分泌物都参与精液的组成。

### 外生殖器

#### 阴茎

阴茎我们要了解几个方面：位置、分几部分、功能、有哪些海绵体。

位置：把盆腔做一个矢状切面，阴茎正好是在**耻骨联合的下方，悬吊在耻骨联合的下方**。

分部：把阴茎游离下来看——前方叫**阴茎头**，中间是**阴茎体**，末端的这两个叫**阴茎脚**，左右各一。这两个脚附着在哪儿呢？换一个方向从腹侧面看，脚过去落在**耻骨弓**上，也就是骨盆闭孔下方的耻骨支和坐骨支。

海绵体有两种：中间这一条是**尿道海绵体**；后面成对并排的两条是**阴茎海绵体**，左右都有——阴茎海绵体的脚就是刚才说的阴茎脚。

功能：这里说的功能主要指海绵体里边的**尿道**——除了排尿，还能排精。

#### 阴囊

位置：在**阴茎后下方悬吊**的皮肤囊袋。

重点看形态。把阴茎向上提起来，裸露出来的就是阴囊。阴囊前正中有一个**纵行的皮纹**，叫**阴囊缝**。

把阴囊前壁打开，里面正中间有一个隔，把阴囊分成**左右两个腔**，腔里每侧都有一个睾丸和一个附睾。

> **结论**：阴囊分为左右两腔，容纳睾丸和附睾。这一节比较简单，把这一条记住就够了。

### 男性尿道：排尿也排精

男性尿道大约 16-22 厘米。这一节的重点是分部，另外三个问题是：功能、分几个部分、有几个弯曲、有几处狭窄。功能前面已经重复说过了——排尿和排精两条。

#### 分三部分

把前列腺、盆底肌肉以及尿道做一个冠状切面，尿道的三部分就全展现出来了：贯穿前列腺的是**前列腺部**，穿过盆底肌肉的是**膜部**，游离端这一段很长、实际最长的是**海绵体部**。

再看另一张图理解这三个部分：尿道从膀胱出发，穿前列腺、穿盆底肌肉，然后进入阴茎，最后开口于尿道外口。

各段长度：

| 部分 | 长度 | 归属 |
| :--- | :--- | :--- |
| 前列腺部 | 约 3 厘米 | 后尿道 |
| 膜部 | 约 1.5 厘米 | 后尿道 |
| 海绵体部 | 约 12～17 厘米 | 前尿道 |

> **结论**：**前列腺部和膜部合在一起叫后尿道**；海绵体部单独叫**前尿道**。这两个名字记住，临床上讲"后尿道梗阻"时指的就是前两段。

#### 两个弯曲

穿膜部这一块形成一个弯曲，在阴茎这个部位又形成一个弯曲——**耻骨下弯**和**耻骨前弯**，一共两个弯曲。

临床上导尿的时候，弯曲越少，尿管越容易进入。怎么让弯曲变少？看这张图：

```text
① 正常站立位
        膀胱
         │╲
         │ ╲___   耻骨下弯（不变）
        前列腺  ╲___
                     ╲___   耻骨前弯（可变）
                          ╲
                           尿道外口

② 将阴茎提起
        膀胱
         │╲___   耻骨下弯（不变）
        前列腺  ╲
                    ╲________  阴茎被提起，耻骨前弯消失、变直

③ 再用力向后下牵拉阴茎
        膀胱
         │╲_______________╱‾‾‾‾‾  阴茎
         耻骨下弯也被拉开 → 整条尿道近似一条直线
```

所以两个弯曲，一个是**可变的**（耻骨前弯），一个是**不变的**（耻骨下弯）。

#### 三处狭窄

尿道有**三处狭窄**：

- 起端的**尿道内口**；
- **穿膜部**处；
- **尿道外口**。

从整条男性泌尿系的图上看更直观：起端这块最窄；然后前列腺部形成膨大，到膜部又最窄；再往下又扩大了，扩大到相当于**尿道海绵体**的那一段；最后到尿道外口，这里是最窄的。

### 把整条路串一遍

最后从头过一遍，把整条路和所有的分支放在一张图上：

```text

      │
      ├── 睾丸 ── 白膜 / 小隔 / 小叶
      │              └── 曲细精管：产生精子
      │              └── 间质细胞：分泌男性激素（直接入血）
      │
      └── 附睾：头 · 体 · 尾
              │  从尾起始
              ▼
        输精管四部：
          睾丸部 → 精索部 → 腹股沟管部 → 盆部（最长）
              │                       ↑
        精索：睾丸上端 ↔ 腹环       │
        （睾丸动脉·蔓状静脉丛·淋巴·神经·输精管）
              │                       │
              └────── 经腹股沟管 ─────┘
              │  进入盆腔 → 绕到膀胱底
              ▼
        与精囊腺的排泄管汇合
              ▼
        射精管（一对，藏在前列腺实质内）
              ▼
   开口于尿道前列腺部后壁 · 尿道嵴上的两个小孔

        前列腺（栗子形，底朝上尖朝下）
          五叶：前叶 · 中叶 · 后叶 · 两个侧叶
          后方贴直肠 → 肛门指诊摸前列腺沟
              │

          前列腺部 约3cm ┐
          膜部      约1.5cm ┘ = 后尿道

          狭窄：尿道内口 · 穿膜部 · 尿道外口
              │
        旁支：尿道球腺（位于盆底肌内）→ 导管开口于尿道海绵体部
              │
        阴茎：阴茎头 · 阴茎体 · 阴茎脚（脚附着于耻骨弓）
              │
          尿道外口
```

到此为止，整个男性生殖系的全貌就讲完了——生殖腺、输送管道、附属腺体、外生殖器，四块拼齐。下一轮我们转去女性生殖系。

## 卵巢、输卵管与子宫——盆腔里的三件套
> 对应块：BLK24 | 覆盖分集：P33 | 块标题（分集名）：《33.女性生殖系统卵巢、输卵管和子宫》

先别急着背名词。我们从一张挂图的最上头往下看一遍，把这三个器官在盆腔里的位置关系一次性捋顺——这一讲绝大部分内容，都挂在这张图上。

挂图是从上往下看的：最上面那一横是**小骨盆上口**。进了盆腔，前边是膀胱，中间是子宫，后边是直肠。

```text
                 腹  前  壁
   ═════════════ 小骨盆上口 ═════════════
        膀胱         子宫         直肠      前 / 中 / 后
                       ╱  ╲
                 输 ╱ 卵  巢 ╲ 输
                    (    )                 ← 输卵管环抱卵巢
   ══════════════════ 盆底 ══════════════
```

读图：膀胱、子宫、直肠在盆腔里是前、中、后的一条线；子宫两侧向上后方弯曲的那根管道，就是**输卵管**；而输卵管所环抱着的那个卵圆形结构，就是**卵巢**。所以一开始先记住一句话：卵巢被输卵管抱着。

再看细节。卵巢在小骨盆的**侧壁**上，每侧一个。往腹膜的深面看，能隐约见到血管：一个往下肢去的，叫**髂外动脉**；一个奔盆腔去的，叫**髂内动脉**。这两条动脉交叉的部位形成一个深窝，这个窝有名字，叫**卵巢窝**——卵巢正好就在卵巢窝这个范围里。

位置先交代到这儿。下面正式讲卵巢。

---

### 卵巢的四个问题

面对卵巢，我们只需要问四个问题：形态、位置、功能、固定的装置。下面一个一个来。

#### 形态：扁卵圆形，表面凹凸不平

形态上，卵巢是一个扁卵圆形的器官。它表面有一个很显眼的特征——**凹凸不平**。

为什么？小孩子卵巢表面是光滑的，成人才凹凸不平。原因就在排卵这件事上。我们知道 28 天排卵一次，排卵本身就是卵巢表面**破溃**，把卵细胞释放到腹腔里边去；破溃的部分需要修补，修补以后是不是就形成一个凹窝？每个月都排卵，每个月都在破溃、修补，于是每个月都留下一批凹窝，表面就成了一片凹凸不平。

> **结论**：卵巢＝扁卵圆形 ＋ 表面凹凸不平。这四个字一起记，形态题就过了。

#### 位置：卵巢窝里的那个卵圆

位置刚才在挂图上已经说了，这里把来龙龙脉再说一遍。腹后壁的血管主干在**第 4 腰椎**水平开始发分支，每侧一个，这个主干叫**腹主动脉**；它发出的分支叫**髂总动脉**；髂总动脉在**骶髂关节前方**又分成两个去处——一个继续奔盆腔去，叫**髂内动脉**；另一个直接通过**腹股沟韧带**到大腿去，叫**髂外动脉**。

动脉没问题了。现在看分叉：髂内、髂外这两条动脉交叉的部位，在腹膜上形成一个凹陷，两侧各一个，这个凹陷就叫**卵巢窝**。我们所说的卵巢，就在这个窝里面。

> **定义**：髂内动脉与髂外动脉分叉交叉处所形成的腹膜凹陷，称为卵巢窝，卵巢位于其中。

#### 功能：卵子和雌性激素

卵巢的功能就两条：产生卵细胞；分泌雌性激素。而雌性激素的作用是维持女性的第二性征。

#### 固定的装置：两条韧带、一个系膜

那么卵巢靠什么结构来固定它呢？我们把一侧的输卵管向外一牵拉，卵巢就露出来了。上面看，它有**两个韧带**：内侧端一个，向骨盆侧方（外侧端）一个。另外，卵巢和输卵管前边还有一个**系膜**。合起来是三个装置。

| 固定装置 | 相连的两端 | 性质 |
| --- | --- | --- |
| 卵巢悬韧带 | 卵巢**上端** ↔ 骨盆侧壁 | 韧带 |
| 卵巢固有韧带 | 卵巢**下端（或内侧端）** ↔ 子宫角 | 韧带 |
| 卵巢系膜 | 卵巢 ↔ 子宫阔韧带后壁 | 双层腹膜反折 |

> **易错点**：固有韧带是连到**子宫角**的，不是连到宫底的；悬韧带是连到**骨盆侧壁**的，走向向上方。两条一上一下，别搞混。

---

### 一层腹膜兜住三样东西：子宫阔韧带

上面提到的卵巢系膜，得把腹膜这层关系摊开才讲得清。我们做一个**矢状切面**，从外向里看这半侧结构：能看到子宫的侧面轮廓，像一个倒置的梨形；还能看到输卵管的断端、卵巢的断端。

现在看这个韧带是怎么形成的。子宫**阔韧带**就是包绕着输卵管、向下垂吊到盆底的一个腹膜皱襞——它有两层。前层包绕着输卵管向下走，一直到盆底；后层向下，又包绕了卵巢，然后到盆底。这两层合起来，就叫子宫的**阔韧带**。

然后是那两个系膜：

```text
             输 卵 管
        ┌────────────────┐
        └───┬────────┬───┘   ← 输卵管系膜（双层反折）
    ════════╪════════╪════   阔韧带前层：包绕输卵管下行至盆底
            │        │
        ┌───╨────────╨───┐
        │      卵  巢    │   ← 卵巢系膜（双层反折）
    ════╧════════════════   阔韧带后层：包绕卵巢下行至盆底
              盆  底
```

读图：整张图就是一层腹膜从盆侧壁垂下来之后自己折出来的结构。最外侧那两个小反折是**输卵管系膜**，包着输卵管；下面包着卵巢的那一圈是**卵巢系膜**。要特别记住的一点是——**这两个系膜其实都包在阔韧带里面**，它们不是独立的第三、第四层腹膜，而是阔韧带这个整体在不同部位形成的双层反折。

所以整块结构自上而下：前层是输卵管系膜，中间夹着输卵管的腔和卵巢系膜，后层往下到盆底——整个这一大片腹膜形成的结构，就叫**子宫阔韧带**。输卵管正好走在阔韧带的上缘里；对卵巢来说，那一层双层反折就叫卵巢系膜，它是固定卵巢的结构，和阔韧带后壁相连接。

> **易错点**：看图时阔韧带边缘像是"断头"的，其实不是断端——它和盆侧壁的腹膜是相延续的，腹膜本来就是连续的。

### 输卵管：长而弯曲的喇叭状管道

#### 形态与位置

输卵管的形态很好记：内侧细、外侧粗，而且又长又弯曲——所以它是一个**长而弯曲的喇叭状管道**。

位置呢？把输卵管展开以后你会看到，它被一层膜状结构包着、向下垂吊到盆底，这个结构还是刚才那个**子宫阔韧带**。所以输卵管的常规位置是：**子宫阔韧带的上缘内**。

> **易错点**：有一块要除外——**子宫部**。输卵管有一部分位于**子宫壁内**，根本不在阔韧带里。等下讲四部分的时候会再碰它一次。

#### 四部分

把子宫放大、剖开看内腔，子宫向两侧水平外伸的就是输卵管，它逐渐膨大，末端形成漏斗状，边缘还有一些指状突起。

所以从子宫角往外，输卵管一共分**四部分**，从内到外：

| 部分 | 别称 | 位置与特点 |
| --- | --- | --- |
| 间质部 | 子宫部 | 位于**子宫壁内**，所以不在阔韧带内 |
| 峡部 | — | 由子宫水平向外伸；特点**短而直、腔小壁厚** |
| 壶腹部 | — | 长而弯；特点**腔大壁薄** |
| 漏斗部 | 伞部 | 呈漏斗状，口的周缘有许多**指状突起**，即**输卵管伞** |

四个名字要连着顺序背：间质部（子宫部）→ 峡部 → 壶腹部 → 漏斗部（伞部）。

峡部和壶腹部正好是反着的：峡部短而直、腔小壁厚，壶腹部长而弯、腔大壁薄。这两个特点很值钱，因为它们各接一个"用处"。

峡部的用处是：**女性输卵管结扎就在这一部位**。记住了，结扎＝峡部。

漏斗部要重点记它的特点：口的周缘有很多指状突起，这个指状凸起叫**输卵管伞**。

> **易错点**：挂图上那根输卵管是**展开**的，不是自然状态。自然状态它是盘曲的，看到那个直愣愣伸出去的样子，不要以为输卵管本来就这么直。

### 子宫：本讲的重点

子宫是这一讲的重点。我们按形态、位置、分部、固定装置的顺序过。

#### 位置与毗邻

先看女性盆腔的矢状面：最前面是腹前壁、耻骨联合，往后是膀胱（女性尿道短、直、阔，阴蒂、小阴唇都在这一带），再往后是阴道，阴道上方这个结构就是子宫，最后方是那个长管——**直肠**。

在图上先定一条线，这条线就是**小骨盆上口线**。于是子宫的位置就被框住了：

- 在**膀胱和直肠之间**（前膀胱，后直肠）；
- **上端不超过小骨盆上口**；
- **下端不低于坐骨肌**；
- 保持**轻度的前倾前屈位**；
- **两侧**有输卵管和卵巢，**下端**接阴道。

关于"下端不低于坐骨肌"这一条，我们多说一句：要是子宫掉到坐骨肌以下、垂到阴道里来了，就叫**子宫脱垂**，分三度，严重的 III 度脱垂时子宫颈直接从阴道口露出来。之所以会脱垂，就是因为**固定装置松弛了**。

正常子宫虽然是个倒置的梨形，但它不是直的，是弯的，保持**轻度的前倾前屈位**。这两个"度"要分清楚：

```text
                 子宫体长轴
                    ╱
                   ╱ 前屈角 ← 子宫体长轴与子宫颈长轴的夹角
        子宫颈长轴 ╱
                 │
                 │      阴道长轴
                 │     ╱
                 │  ╱ 前倾角 ← 子宫体长轴与阴道长轴的夹角
                 │ ╱
```

- **前屈**：子宫体长轴与子宫颈长轴之间的夹角。子宫体约占上 2/3，子宫颈约占下 1/3，两者的长轴在这个界线上折出一个角，这个角叫**前屈角**。
- **前倾**：把阴道的长轴也画上，子宫体长轴与阴道长轴之间的夹角，叫**前倾角**。

一句话记法：前屈是"腰弯了"，前倾是"整体往前倒"。正常的子宫只是**轻度**前倾前屈。

> **易错点**：别把这两个角记反，也别忘了"轻度"两个字。**极度**的前倾前屈、或者极度的前倾前屈的反面（后倾后屈），都会造成不孕症。

这套毗邻关系还顺便解释了两个常见现象。为什么孕妇会有**尿频**和**便秘**？因为子宫在这中间，怀孕时体积增大，往前压膀胱、往后压直肠。膀胱受压就不能过度充盈，存点儿尿就得排——这是尿频；直肠受压，食物残渣排不出去，在直肠里停留时间就长，而直肠本身有吸收残渣水分的功能，水分被吸收得越多，粪便越干越硬——这就是便秘的来源。

#### 外形与分部

把子宫放大、剖开，看到内腔，下边接阴道（阴道是一个扁平的管道，阴道下端有处女膜，小阴唇、大阴唇这些属于外生殖器），阴道内壁还有很多很多的皱襞。

子宫外形上分**四部分**：从下往上——

```text
        上端较圆凸 —— 子宫底
            ┌────────┐
            │ 子 宫 体│     上 2/3
            ├────────┤
            │ 子 宫 峡│     不足 1 cm，妊娠时可抻长到 7~11 cm
            ├────────┤
            │ 子 宫 颈│     下 1/3，底端比较圆钝
            └────┬───┘
    ═════════════╧══════   阴道：只环绕宫颈的下段
           阴道上段 │ 阴道部
               阴道口
```

- **子宫底**：向上比较圆凸的部分。
- **子宫体**：底和颈之间的部分，约占上 2/3。
- **子宫颈**：下 1/3，比较圆钝的部分。
- **子宫峡**：体和颈之间移行的那一小段，**不足 1 厘米**。

宫颈还有一个细分：阴道环绕了宫颈的下段，上段并没有被阴道环绕。画一条虚线一分，被环绕的那部分叫**阴道部**，上面的叫**阴道上段**。

> **结论**：外形上就记"**底、体、峡、颈**"四部分，**峡**夹在体和颈之间，**不足 1 cm**，但妊娠时可以抻长到 **7~11 个厘米**。这个"1 cm → 7~11 cm"的伸缩性，是后面子宫破裂那一段的关键伏笔。

#### 固定装置：一个铁桶和四根绳子

这部分我希望你们在脑子里能把那个立体状态建立起来。我举一个不恰当但很好用的例子。

想象有这么一个大铁桶：**后壁高，前壁比较矮**；铁桶的前边钻两个窟窿；然后在铁桶的底部，我们固定一块**很宽的板子**。

现在让一个人坐进这个铁桶里。大家想，这个人怎么坐，位置最稳固？我们让他**低头坐下**，然后两条腿——注意，是**膝关节**——**头埋到膝关节里边**，像这一侧有一条腿支出来了，那一侧又有一条腿支出来了，头靠到膝。**裤腰带后边拴两根绳儿**，拴到铁桶的后壁上。然后两只手呢，这只手扶着铁桶的这个壁，另一只手扶着另一个壁。

大家说，这时候姿势是不是最稳固？下边儿还不容易滑，就因为有那块板子啊。

现在关键的一步来了：我们用**一张最大的单子，从上往下自然地落下来**。大家看它形成了多少个皱襞——**这就是固定子宫的装置**。我们顺着这张"单子"往下读。

| 单子落在哪儿 | 比喻里对应什么 | 对应韧带 | 作用 |
| --- | --- | --- | --- |
| 上肢下方悬吊着的那双层腹膜皱襞 | 两只手扶着桶壁 | 子宫阔韧带 | 防止子宫**左右移位** |
| 阔韧带的基底部 | 桶底固定的那块宽板子 | 子宫主韧带 | 防止子宫**向下沉** |
| 两条小腿形成的两个皱襞 | 两条小腿、头夹着膝 | 子宫圆韧带 | 保持子宫**前倾** |
| 阔韧带后方的两个皱襞 | 裤腰带后拴的两根绳 | 子宫骶骨韧带 | 保持**前屈角**，即前屈 |

一一对上来就清楚了：

**上肢下方悬吊的那双层腹膜皱襞**，就是**子宫阔韧带**（注意它的边缘不是断端，是和盆侧壁的腹膜相延续的），功能是**防止子宫左右移位**——两片膜把子宫横向夹住固定。

那块"板子"就是**子宫主韧带**，它是阔韧带的基底部，**防止子宫下沉**。所以主韧带一旦松弛，就容易造成子宫脱垂。

**两条小腿形成的两个皱襞**叫**子宫圆韧带**，一直通到大阴唇。为什么在这个比喻里要让人头夹着膝、保持身体前倾？因为**子宫圆韧带的作用就是保持子宫的前倾状态**。

阔韧带后边的**两根绳**形成的两个皱襞，叫**子宫骶骨韧带**，它保持躯干的前屈角，也就是**保持子宫前屈**。

把四个方向串一遍，就是：前倾靠子宫圆韧带，前屈靠子宫骶骨韧带，左右的移位靠子宫阔韧带，向下沉靠子宫主韧带。四个韧带的名字记住了就行——子宫阔韧带、子宫主韧带、子宫圆韧带、子宫骶骨韧带。

### 把解剖用起来：宫外孕与子宫破裂

最后我们介绍两件事，把前面这些解剖串起来。

#### 宫外孕：为什么大出血

先看受孕的过程：大量精子进入阴道，游动到子宫内，然后奔输卵管去。卵巢释放的卵细胞，通过漏斗部被接收进输卵管。在这里跟精子相遇，变成**受精卵**。正常情况下，受精卵是逐渐往里移，到子宫内膜着床发育的。

那么不正常的时候呢？如果这个人**峡部比较狭窄**，或者说过去得过**输卵管结核**，造成峡部输卵管粘连、狭窄，受精卵还能不能进入子宫？进不去了。它就**停留在宽大的壶腹部**，开始发育——这就是**宫外孕**。

那接下来就是重头戏：**宫外孕为什么会大出血**？我们把血管加进来看。血管由**子宫动脉**供应，子宫动脉很粗，它沿着这个边缘来营养输卵管，另有分支营养子宫，再往下营养阴道。

当输卵管（壶腹部）肥大、越来越大的时候，迂曲的血管会怎么样？迂曲的血管本来是打折的，管腔一大，褶皱被撑开，血管先被**拉直**；可接着管腔还在扩大，血管就被**由直变紧**。由直又变紧，最后的结局是什么？**断了**。

所以宫外孕之所以会大出血，就是因为受精卵在壶腹部不断发育，把周围迂曲的子宫动脉分支**拉断了**。

> **结论**：宫外孕＝受精卵在峡部受阻 → 滞留壶腹部 → 壶腹膨大撑开迂曲血管 → 血管被拉直、拉紧、断裂 → 大出血。四个环节，一环扣一环，全是形态学的必然结果。

#### 子宫破裂：气球越吹，壁越薄

再说**子宫破裂**是怎么来的。我们回头看刚才那个分部：子宫峡本来就只有 1 个厘米，妊娠的时候可以变长到 7~11 个厘米。那妊娠的子宫到底发生了哪些变化？

我们看：宫口开大了，下面阴道也扩张了，**但产妇的骨盆下口特别狭窄，孩子出不来**。而出不来的时候，子宫在干什么？子宫是**体内最发达的一个平滑肌构成的器官**，宫底还在强烈收缩。

大家设想一下：给你一个气球，把气球底部捂住，然后吹这个气球，会怎么样？是不是两个侧壁越来越薄。对，就这个意思。那"俩侧壁"在解剖上是谁？是**子宫峡**。它越抻越薄，从 1 厘米抻到 7~11 厘米，孩子还是出不来，宫底还在强烈收缩，是不是就继续往外拉？

这时候再看子宫动脉的走法：它迂曲向内，形成升支、降支。**由于峡部不断拉长，子宫动脉也被迫变直，然后变紧**——和宫外孕那一步一模一样的机制。最后有没有断？断了可了不得，因为子宫动脉很粗，**造成大出血**。

所以临床上，孕妇的**腹部观察很重要**。如果发现腹部出现这样的改变：肚子呈**葫芦状**，中间形成一道**深沟**，胎儿的**头部和躯干轮廓显现出来了**——这就叫**病理收缩环**。

> **提示**：出现病理收缩环，立即剖腹产。否则接下来就是子宫破裂。

到这里，这一讲的解剖就串起来了：形态决定了薄弱点，薄弱点被拉长撑薄，牵动了旁边的迂曲血管，血管断了就是大出血。你把形态记牢了，宫外孕和子宫破裂这两个临床上最凶险的情况，机制自然就记住了。
