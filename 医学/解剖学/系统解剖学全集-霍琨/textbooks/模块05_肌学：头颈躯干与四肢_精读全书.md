## 头肌：长在皮上的表情，咬在骨上的力量
> 对应块：BLK10 | 覆盖分集：P15 | 块标题（分集名）：《15.肌学-头肌》

头肌这一块，落到实处就两大类：一类管"脸"，一类管"嘴"。管脸的叫面肌，管嘴的叫咀嚼肌。名字听着平常，但真正要把这块学扎实，靠的不是背名字，而是能把每块肌肉的位置、起止、功能对应起来——因为临床上判断一个人哪块肌肉坏了，靠的就是这些功能。

先说面肌。

### 起于骨、止于皮的面肌

面肌还有两个别名叫表情肌，还有的叫皮肌。为什么叫皮肌？

因为面肌的特点跟别的肌肉完全不一样：它位置比较表浅，就在皮下；更关键的是它的起止点不一样——别的肌肉都是起于骨、止于骨，它不是，**它起于骨、止于皮**。

这么一挂，逻辑就通了：肌肉一收缩，牵拉的是皮肤，皮纹就发生变化，皮纹一变，喜怒哀乐就出来了。

> **定义**：面肌（表情肌、皮肌）——位于皮下的浅层肌肉，起于骨、止于皮，收缩时直接牵拉皮肤产生表情。

这一类的肌肉，我们按位置一块一块过。

### 眼轮匝肌：绕眼裂的三圈

先看位置。眼轮匝肌长在哪儿？从头的侧面观察，颧弓、下颌角这些骨性标志都在，眼轮匝肌就在**眼裂的周围**，而且它不是一坨，是分成几部分的。

看图就清楚了：

```text
                       眶部
           （位于眼眶表面，最大的一圈）
        ┌─────────────────────────┐
        │     ┌─────────────┐     │
        │     │    睑部     │     │
        │     │   ┌─────┐   │     │
        │     │   │眼裂 │   │     │
        │     │   └─────┘   │     │
        │     └─────────────┘     │
        └─────────────────────────┘
                   ●
                   │
                   └─→ 泪囊部：内眦处到泪囊的一小束肌
```

三部分都是环绕眼裂、呈环状排列的，只是圈的大小和位置不同：

- **睑部**：最靠内，在上睑、下睑的前面围一圈；
- **眶部**：再向外，在眼眶的表面又围一圈；
- **泪囊部**：在内眦到泪囊那里，有一些小束肌。

三部分的功能大体记住就行：眶部主要是**闭眼**，睑部是**眨眼**，泪囊部是**扩张泪囊**。

> **结论**：眼轮匝肌眶部—闭眼；睑部—眨眼；泪囊部—扩张泪囊。

### 围绕口裂的两组肌肉

#### 口轮匝肌

口轮匝肌的位置特别好找：围绕**口裂**周围，呈环状排列——跟眼轮匝肌包眼裂是同一个套路，只是把眼裂换成了口裂。

它的功能能做两个动作。正常情况下闭口，就是口轮匝肌收缩造成的；再一个动作是**吹口哨**，口轮匝肌纤维强力收缩时产生。

所以口轮匝肌，位置在口裂周围，功能是闭口和吹口哨。

#### 口周放射肌

接下来看口轮匝肌周围还有些什么。

```text
                    鼻肌（鼻翼处）
                        │
        提上唇肌 ────────┼──────── 笑肌
             │          │              │
        颧大肌 ───────  │  〔口〕   颊肌（深面）
             │          │              │
        颧小肌 ────────┤        降口角肌
                        │              │
        降下唇肌 ───────┘         颏肌

        外围一圈细肌 = 口周放射肌
        口轮匝肌居中，管闭口和吹口哨
```

顺着口周摸一圈，这些细小的肌肉都在：鼻翼这块有鼻肌，提上唇肌，颧小肌、颧大肌（笑肌旁边就是颧弓），笑肌，深面是颊肌，还有降口角肌、降下唇肌、颏肌。

顺便说一个容易混的：颧弓下方还有一块挺大的肌肉，那是**咬肌**，属于咀嚼肌，不属于面肌。它长在口周放射肌的外侧，位置挨着，但体系不同。

这些肌肉的名字大家不用死记，真正要记住的是**排列规律**：它们全都排列在口轮匝肌的周围，呈**辐射状**排列。

所以口周放射肌的位置就是——口轮匝肌的周围，呈辐射状排列。功能呢？**牵拉口角向各个方向运动**。

辐射状排列这个规律很好用：只要认出"往中间收"的那一圈是口轮匝肌，往外散开成放射状的那一片，就全是口周放射肌。

### 颅顶肌：额肌和枕肌

第三类在头顶部，叫颅顶肌，由两块肌肉组成：**额肌**和**枕肌**。

看位置：额肌在额部，它的**抵止在额部的皮肤**，即止于皮；枕肌在后方的枕部，起自枕部颅骨的**上项线**，即止于骨。

这两块肌肉之间，夹着一层腱膜，连着它们，叫**帽状腱膜**。

```text
         前方                              后方
      ┌─────────┐                      ┌─────────┐
      │  额肌   │                      │  枕肌   │
      └────┬────┘                      └────┬────┘
           │                                  │
   止于皮（额部皮肤）              止于骨（枕骨上项线）
           │                                  │
      ┌────▼──────────────────────────────────▼────┐
      │               帽 状 腱 膜                   │
      └─────────────────────────────────────────────┘
                        │
                        ↓
              两肌收缩 → 头皮前后移动
```

为什么非要记住这个腱膜？先看它怎么动。

额肌收缩的时候，眉上提，额部出现**抬头纹**——所以抬头纹是额肌出来的。枕肌收缩的时候，是牵拉帽状腱膜。两块肌肉一起收缩，头皮就能前后动。

### 帽状腱膜：头皮层次里最要紧的一层

帽状腱膜是连接两个肌肉之间的一个**膜性结构**。它的关系有两层，大家记住：

- **和皮肤结合得紧密**；
- **与颅骨中间隔着疏松的结缔组织**。

因为中间是疏松的，所以它和颅骨之间**可以动**。

```text
          头皮层次，由浅到深
      ┌──────────────────────────┐
      │  皮肤                    │ ← 与帽状腱膜结合紧密
      ├──────────────────────────┤
      │  帽状腱膜                │ ← 连于额肌与枕肌之间
      ├──────────────────────────┤
      │  疏松结缔组织            │ ← 松 → 帽状腱膜可以滑动
      ├──────────────────────────┤
      │  颅骨                    │
      └──────────────────────────┘
```

这层关系直接决定了临床上的一个判断。

将来遇到头部外伤，比如一个人的头受伤了，发现伤口是**分开的**——刀口为什么张开？因为这块肌肉是有张力的，前后的肌肉两侧都有张力，刀把帽状腱膜砍开了，帽状腱膜就被向两侧拉开，所以刀口是分开的。**刀口分开，说明砍得比较深**，下面就是颅骨了。这时候要**彻底清创**，否则一感染就会引起颅内的感染。

反过来，如果看到的伤口是**闭合的**，说明帽状腱膜没被砍开，损伤比较浅，一般清创以后缝合就行。

> **结论**：帽状腱膜是头皮层次里一个很主要的层次，它紧贴颅骨（中间只隔疏松结缔组织）。头部外伤时，伤口张开与否，就是判断帽状腱膜有没有被切开、伤得深不深的直接依据。

面肌这块就讲完了。第二个问题，咀嚼肌。

### 咀嚼肌

先复习一下位置。过去讲颅骨的时候，上面有很多窝和骨性标志：鼻骨、上颌、眶、颧弓、颧骨、关节结节、下颌窝、外耳门、乳突，再到下颌骨的髁突、冠突。

这些标志今天全用得上。咀嚼肌一共四块，前面两块、后面深面两块。

#### 浅层：颞肌与咬肌

**颞肌**在颞窝里，颞窝是颅骨侧面一个比较大的窝，窝里附着着这块肌肉。它的起止很清楚：起于**颅骨侧面的颞窝**，止于**下颌骨的冠突**——从颧弓的深面过去，止在冠突上。

功能要分成两部分看。把它的肌纤维分成前部和后部：前部肌纤维一收缩，上提下颌；后部肌纤维一收缩，后拉下颌。所以颞肌的功能是**上提、后拉**。

**咬肌**也是一块很发达的肌肉。位置在颧弓到下颌角外侧之间，起于**颧弓的下面和内侧面**，止于**咬肌粗隆**。收缩的功能是**上提下颌**——它也有上提作用。

这两块是最前面的两块，一个上提兼后拉，一个专职上提。

#### 深层：翼外肌与翼内肌

要看深层，得动点手段：把颧弓锯开，把下颌支也破开——目的就是看里面那个窝。

这个窝里有两块肌肉：

- 上面一块，止于**翼肌凹**（位于下颌颈的前方）；
- 下面一块，在上一块的**深面**，止于**下颌角的内侧**。

上面这块叫**翼外肌**，下面那块叫**翼内肌**。

翼外肌还得再放大看一次。它在这块区域里其实有两个止点：

```text
        关节结节 / 下颌窝
               │
               ●────→ 小肌束，止于关节盘
               │        收缩时把关节盘向前拉
        ▓▓▓▓▓▓│▓▓▓
        ▓▓▓▓▓▓│▓▓▓   大片肌腹
        ▓▓▓▓▓▓│▓▓▓
               │
               ▼
        抵止于翼肌凹（下颌颈前方）

        小肌束 + 大片肌腹 = 翼外肌
```

这个小肌束停在哪儿？它止在**关节盘**上。要理解这一步，得先回头看下颌关节的结构：下颌关节的关节囊里面，中间夹着一个软骨板，这个软骨板就是**关节盘**，关节盘把下颌关节分成了**上、下两个腔**。

翼外肌这个小肌束收缩的时候，就把关节盘**向前拉**。一拉会怎样？髁突（也就是下颌头）正好被拉到关节结节的下方。

髁头一到关节结节下方，是什么动作？**张口**，张大嘴。

所以翼外肌的功能：一是**张口**；二是能**使下颌骨前移**；另外，**如果一侧收缩，能使下颌骨侧移**。

```text
    闭口                              张口（翼外肌收缩）
  ┌─────────┐                      ┌─────────┐
  │ 关节结节 │                      │ 关节结节 │
  │    ▽    │                      │    ▽    │
  └─────────┘                      └─────────┘
  ┌─────────┐                      ┌─────────┐
  │  上腔   │                      │  上腔   │
  ├═════════┤ ← 关节盘            ├═════════┤ ← 关节盘被前拉
  │  下腔   │                      │  下腔   │
  └─────────┘                      └─────────┘
      ██                                ██
   髁突（居中）                    髁突（移到结节下方）
```

**翼内肌**的功能：使下颌骨**上提**，也能使它**前移**。

四块肌肉合起来，就是咀嚼肌：前面浅面两块（颞肌、咬肌），深面两块（翼外肌、翼内肌）。

| 肌肉 | 起始 | 抵止 | 功能 |
|------|------|------|------|
| 颞肌 | 颅骨侧面的颞窝 | 下颌骨的冠突 | 上提下颌、后拉下颌 |
| 咬肌 | 颧弓的下面和内侧面 | 咬肌粗隆（下颌角外侧） | 上提下颌 |
| 翼外肌 | — | 翼肌凹（下颌颈前方） | 张口；下颌骨前移；一侧收缩使下颌骨侧移 |
| 翼内肌 | — | 下颌角的内侧 | 上提下颌；下颌骨前移 |

> **注意**：翼外肌和翼内肌的**起始部位**这一讲没有展开，只讲了它们的抵止，表格里空着不是漏了，是本讲没讲，用的时候回教材补上。

### 临床上怎么用：从表情读出哪块肌坏了

这节课介绍的是头肌，但头肌里**重点要把握的是表情肌这部分**——表情肌的功能一定要知道，临床上了才能判断。

看两个患者。

**第一个患者**：

- 这一侧有抬头纹，对侧没有；
- 这一侧眼睛闭不上，对侧能闭上；
- 这一侧鼻唇沟比较浅，对侧比较深；
- 嘴向一侧歪，略微流口水。

**第二个患者**：

- 两侧都有抬头纹；
- 让她闭眼，两侧眼都能闭上；
- 这侧鼻唇沟浅，那侧深；
- 嘴也向一侧歪，略微流口水。

第二个问题留给大家：分别都是哪些表情肌瘫痪造成的？

我们一个一个拆。

先看第一个。这侧有抬头纹、那侧没有——**说明这侧额肌是好的**（好的额肌才提得起眉、才出得了抬头纹），而**没有抬头纹的那侧额肌损伤了**。

这侧闭不上眼、对侧能闭上——**眼轮匝肌出问题了**，不能闭眼。

再看鼻唇沟的深浅。为什么这侧浅、对侧深？看口周放射肌：如果这侧的口周放射肌张力比较大、能够收缩，这侧鼻唇沟就深了；现在这侧**不能收缩**，而对侧是好的、对侧把口角**拉向对侧**，所以这侧的口周放射肌也**有问题**。

最后，为什么这侧口角流口水？因为肌肉闭不上了——闭不上口，是**口轮匝肌**不好使了。

四条合起来：这侧**额肌、眼轮匝肌、口周放射肌、口轮匝肌**，从上到下全瘫了，典型的**单侧面瘫**。这在临床上叫**面神经的周围瘫**，也叫**核下瘫**。

再看第二个。双侧都有抬头纹，说明**双侧额肌都好**；两侧眼都能闭，说明**两侧的眼轮匝肌都好**。表现全在嘴这儿：这侧鼻唇沟浅、嘴歪向一侧——还是**口周放射肌**这侧没力量，被对侧拉过去了；流口水，还是这侧的**口轮匝肌**不行了。

这个患者**仅仅是下半面瘫痪**，额肌和眼轮匝肌都好好的。这个临床上叫**中枢瘫**，也叫**核上瘫**。

> **结论**：能靠表情把病变部位认出来，靠的就是知道每块表情肌干什么。额头、眼、口角、闭口，四组体征一分，问题肌就锁定了。

### 本讲提到的题目

> **题目**：现有两位面部表情异常的患者，体征如下。分别判断是哪些表情肌瘫痪造成的，并给出瘫痪的类型。
>
> **患者甲**：一侧有抬头纹而对侧没有；一侧眼睛闭不上、对侧能闭；一侧鼻唇沟浅而对侧深；嘴向一侧歪，略微流口水。
>
> **患者乙**：两侧都有抬头纹；两侧眼都能闭；一侧鼻唇沟浅、另一侧深；嘴向一侧歪，略微流口水。

**答案**

| 体征 | 受累肌肉 |
|------|----------|
| 抬头纹消失的一侧 | 额肌 |
| 闭不上眼的一侧 | 眼轮匝肌 |
| 鼻唇沟浅、嘴角被拉向对侧的一侧 | 口周放射肌 |
| 流口水、闭不上口的一侧 | 口轮匝肌 |

**解析**

- **患者甲**：四组体征全部阳性，病变累及同侧自上而下的全部表情肌（额肌、眼轮匝肌、口周放射肌、口轮匝肌），是典型的**单侧面神经周围瘫（核下瘫）**。
- **患者乙**：抬头纹双侧存在、双眼均可闭合，说明额肌与眼轮匝肌完好；病变只出现在下半面，仅口周放射肌与口轮匝肌受累，表现**下半面瘫**，临床称**中枢瘫（核上瘫）**。

推理依据即上文"临床上怎么用"一节中的逐条分析：从体征回推肌肉，再从受累范围判定瘫痪类型。

## 颈肌与躯干肌：从皮肌到膈
> 对应块：BLK11 | 覆盖分集：P16-P17 | 块标题（分集名）：《16.肌学-颈肌》

颈部的肌肉不少，但真正要反复回想的就那么几块。我们从最外面的浅部和颈外侧开始，先认熟一片薄皮肌和一根斜着走的大肌；然后往里走到颈前部、颈深部；最后把躯干这一大片——背肌、胸肌、膈——顺着一条线串起来。

颈部这块的入手顺序是这样的：

```text
颈部肌肉分层（由浅入深）
  ── 浅部 / 颈外侧
       颈阔肌
       胸锁乳突肌
  ── 颈前部：以舌骨为界
       ├─ 舌骨上肌群   4 块
       └─ 舌骨下肌群   4 块
  ── 颈深部
       ├─ 外侧群  斜角肌 3 块
       └─ 内侧群  颈椎前方的细小肌肉（不记）
```

### 颈部肌肉：浅部、颈前与深部

#### 颈阔肌：一层盖在颈胸上的皮肌

先看这块薄薄的皮肌。板图上标出来的东西先过一遍：下颏、喉结、锁骨、胸骨、甲状软骨、舌骨、下颌角、耳廓。

我们回忆一下过去讲过的表情肌——在口角周围有哪些肌肉？降口角肌、降下唇肌、颏肌，还有笑肌。颈阔肌在哪儿呢？它就在这些细小肌肉上，然后向下，肌纤维很松散，分布到胸大肌的筋膜和三角肌的筋膜。

```text
颈阔肌：薄薄一层，向下斜行
  口周细小表情肌（下颏一带）
     ╲   ╲   ╲
      ╲   ╲   ╲   ← 纤维疏松、细薄
       ╲   ╲   ╲
        ▼   ▼   ▼
   胸大肌筋膜 · 三角肌筋膜
```

功能好推：它既然和口周这些小肌肉有联系，那么一收缩就能下拉口角。板图上也能看出来，肌纤维是向下拉的，这侧也是向下拉，所以口角向下。

> **定义**：颈阔肌是颈部的一块皮肌，纤维薄而疏松，起自下颏（口周）一带的小肌，向下分布到胸大肌筋膜与三角肌筋膜，作用是下拉口角。

它是"皮肌"两个字最标准的例子——记住这一层薄薄的皮就够它的全部内容了。下面把重点放到胸锁乳突肌。

#### 胸锁乳突肌：怎么记功能，怎么判断它瘫了

胸锁乳突肌在颈部的外侧，是一块粗大的、斜行的肌肉。板图上：喉结、乳突、胸骨（胸骨柄）、锁骨内侧端。它起于胸骨、锁骨内侧端，止于乳突——名字就是这么来的，"胸锁"加"乳突"。它的位置在颈阔肌的深面，斜位于颈部的外侧。

```text
胸锁乳突肌（颈外侧，斜行）
  乳突 ●                 ← 止点
        ╲
         ╲  胸锁乳突肌
          ╲
  胸骨柄  ●── 锁骨内侧端  ← 起点
```

功能分三种情况，这一块特别容易搞混，我们一条一条对：

- **双侧同时收缩**：头往后仰。两侧一起上抬，头就后仰。
- **两侧力量都没了**：头就低下来，出现屈颈的体位。
- **单侧收缩**：头向**同侧**倾斜，同时面转向**对侧**上扬。比如左侧胸锁乳突肌一收缩，头是向左侧倾斜，而面转向右上方。

> **易错点**：单侧收缩是"头向同侧倾斜、面转向对侧"，两个方向一定要分开记，不要颠倒。

它还是一个重要的体表标志。今后学心血管、神经外科都会用到：胸锁乳突肌前缘中点能摸到动脉的搏动，胸锁乳突肌后缘中点可以做神经组织麻醉。所以这块肌肉特别重要。

举个瘫痪的例子来判断：来了一位患者，你不容易直接看到他的颈部——那就让医生和他说："你坐好，往前看。"结果患者还是表现成这个样子：头直不过来，脸也转不过来。

现在问：哪侧胸锁乳突肌瘫了？

思路很简单：头向哪侧倾斜，说明哪侧收缩功能是好的。头往哪边歪，就是哪边的肌肉把头拉过去了。这位患者是**左侧是好的**——左侧拉着、变短；右侧变长、拉不住，所以显然是**右侧瘫痪**。

把这一节的重点收一下，就三件事：胸锁乳突肌的功能与损伤判断、舌骨上肌群和舌骨下肌群各包括什么、斜角肌间隙通过什么结构。

#### 舌骨上肌群：舌骨之上四块小肌

颈前肌分两个肌群，以舌骨为界，上面一组、下面一组。舌骨上肌群一共 4 块，这一块大家了解一下名称、看清位置就行，不用背更多的东西。

板图上先认地标：颏部、下颌角、耳廓，还有那块舌骨。耳廓的后方、后内侧有个茎突。从茎突拉到舌骨的肌肉，叫**茎突舌骨肌**。

第二个是**二腹肌**：起自下颌骨，到舌骨，然后牵向乳突——所以它的两个肌腹看起来一路跨过去。

第三个是**下颌舌骨肌**：在二腹肌前腹的深面，中缝两侧对等，也到舌骨去。

第四个是**颏舌骨肌**：这块藏得深。把下颌骨换一个角度，从后向前看下颌骨的内面，是一个马蹄铁形；在这匹"马"的里面有一对小小的肌肉，从前向后走，起点在这块骨上有个名词叫**颏棘**，止于舌骨。

| 舌骨上肌群 | 起点 | 止点 | 位置深浅 |
| --- | --- | --- | --- |
| 茎突舌骨肌 | 茎突（耳廓后内侧） | 舌骨 | 浅 |
| 二腹肌 | 下颌骨（中间腱另连乳突） | 舌骨 | 中等 |
| 下颌舌骨肌 | 下颌骨 | 舌骨 | 较深，位于二腹肌前腹深面 |
| 颏舌骨肌 | 颏棘 | 舌骨 | 最深面 |

把这四块的名字和它们的深浅关系记住就可以了：最深面的一块是颏舌骨肌，两侧是下颌舌骨肌，然后是二腹肌、茎突舌骨肌。

#### 舌骨下肌群：从骨到甲状软骨

舌骨下肌群也是 4 块。板图上的地标：下颏、喉结、甲状软骨、舌骨、胸骨柄、锁骨内侧端。

浅层有两块：最前面的一块叫**胸骨舌骨肌**；还有一块也在浅层，叫**肩胛舌骨肌**，起于肩胛骨的上缘，向上到舌骨——所以名字里带个"肩胛"。

深面还有两块：一条短的，从舌骨到甲状软骨，叫**甲状舌骨肌**；另一条长一些，从胸骨、锁骨向下到甲状软骨，叫**胸骨甲状肌**。

| 舌骨下肌群 | 起点 | 止点 | 位置深浅 |
| --- | --- | --- | --- |
| 胸骨舌骨肌 | 胸骨柄 | 舌骨 | 浅层、最前 |
| 肩胛舌骨肌 | 肩胛骨上缘 | 舌骨 | 浅层 |
| 甲状舌骨肌 | 舌骨 | 甲状软骨斜线 | 深层、短 |
| 胸骨甲状肌 | 胸骨、锁骨 | 甲状软骨斜线 | 深层 |

它们抵止在甲状软骨的什么位置？把甲状软骨这块软骨板放大看一下：前方有上角、下角，板的外侧面有一个斜行的隆起，叫**斜线**。深面那条短的抵止在斜线上，长一点的那条也抵止在斜线上。讲甲状软骨那一章时，大家就知道斜线具体在哪儿了。

这里的重点同样只是把名词记住：胸骨舌骨肌、肩胛舌骨肌、胸骨甲状肌、甲状舌骨肌，也是 4 块。

#### 斜角肌与斜角肌间隙

颈深部的外侧群，一共三块小肌肉，由前向后排列：前斜角肌、中斜角肌、后斜角肌。止点分两档：前、中两块抵止在第一肋，后斜角肌抵止在第二肋。

这一节真正的重点是**斜角肌间隙**。

```text
斜角肌间隙（颈根部）
   前斜角肌
      │
      │ 后缘
      ├──┐
      │  │   间隙内通过：
      │  │     · 锁骨下动脉
      │  │     · 臂丛神经
      ├──┘
      │ 前缘
   中斜角肌
      └─── 第 1 肋上缘（底）
```

它是怎么组成的？前斜角肌的**后缘**、中斜角肌的**前缘**，再加上第一肋的**上缘**，三边围成一个三角形的间隙。这个间隙里通过什么结构？第一个是一个动脉，**锁骨下动脉**，从这里面穿出来；除此之外还有神经，这一堆神经我们统称为**臂丛神经**。

记忆很简单：一个动脉（锁骨下动脉），加一个臂丛神经。

颈深部还有内侧群，是一些细小的肌肉，位于颈椎的前方，这一块大家就不用去记了。

### 躯干肌的四大块

接下来转到躯干。躯干肌分为四大部分：**背肌、胸肌、膈、腹肌**。这一讲我们把背肌、胸肌、膈过一遍。

背肌又分浅层和深层。浅层包括斜方肌、背阔肌、肩胛提肌、菱形肌；深层包括竖脊肌、夹肌。

讲背肌有一个贯穿始终的办法：**通过起止关系来理解它的作用**。所以每一块我们都先看板图上的起、止，再推功能。

#### 背肌浅层：斜方肌到菱形肌

**斜方肌**。看它的形状：单侧看是一个三角形的肌肉；两侧对称起来，就是一个斜方形。起点在颅底和脊柱上——起自颅底（上项线、枕外隆凸），往下有项韧带，再往后是全部胸椎的棘突。止点在肩胛冈，另外前方还有锁骨，肌纤维抵止在锁骨外侧 1/3 段。

功能按纤维分三路：

- 上部纤维收缩 → 肩胛骨上提
- 下部纤维收缩 → 肩胛骨下移
- 中部纤维收缩 → 两侧肩胛骨向脊柱靠拢

所以它本质上是一个**运动肩胛骨**的肌肉。

**背阔肌**，第二块，也是比较大的一个扁肌，和斜方肌有重叠。起点从下往上数：下部胸椎的棘突、全部腰椎的棘突、骶正中嵴（骶骨背面正中的一条嵴）、髂嵴，这些部位起始；止点在肱骨上端的前方，止点是肱骨的**小结节嵴**（大结节的下方）。

看纤维走向推功能——**躯干不动**的时候：

1. 纤维向躯干这一侧收缩，能使上臂的肱骨向内收；
2. 因为它抵止在肱骨上端的前方，所以除了内收，还能够**内旋**；
3. 再收缩，能使上肢骨**后伸**。

后伸、内收、内旋，三个功能。

**肩胛提肌**。起于上部颈椎的横突，纤维斜向下走，止于肩胛骨的内侧角——这个角也可以管它叫肩胛骨的上角。它收缩就是上提肩胛骨。

**菱形肌**，在这两块肌肉的下方。起自下部颈椎和上部胸椎的棘突，止在肩胛骨的内侧缘，也叫脊柱缘。它收缩除了能上提肩胛骨，主要是**内收**，也就是向内拉、牵拉肩胛骨。

这四块就是所谓的浅层背肌。

#### 背肌深层：竖脊肌与夹肌

**竖脊肌**。这名字一看就知道来路：所谓竖脊肌，一定是竖立脊柱的一个肌肉。它从下往上：起点是骶骨的背侧（骶骨的背面），从那里向上走，由三大块组成。

| 竖脊肌的组成 | 由内向外的位置 | 止点 |
| --- | --- | --- |
| 棘肌 | 最靠内侧，是一条 | 棘突 |
| 胸最长肌 | 在棘肌的外侧 | 各个椎骨的横突 |
| 髂肋肌 | 再向外 | 肋骨的后面 |

三个肌肉加在一起，有个大名叫**竖脊肌**。把这三个名字熟悉一下就行。

**夹肌**在头部这一侧。头夹肌：起自项韧带的下部，还有第 7 颈椎的棘突，向上止于**乳突**（耳廓后下方那块骨性隆起）。在它的深面还有一个肌束，起自上部胸椎的棘突，止于第 1、3 颈椎的横突，这个叫**颈夹肌**。

作用：这两个肌肉两侧同时收缩，能使头后仰，也就是**后伸脊柱**；如果只有一侧（比如左侧）收缩，头就转向同侧，脊柱也会侧屈。

再重复一遍：浅层我们介绍了四块，深层介绍了两块——竖脊肌和夹肌。

#### 胸腰筋膜：包住两块肌的三层膜

第三个内容是**胸腰筋膜**。什么叫胸腰筋膜？就是包裹竖脊肌、还有一个以后要介绍的腰方肌，这两块肌肉的那个筋膜，叫做胸腰筋膜（也常叫腰背筋膜）。

腰部做一个横断，我们能看到什么？

中间是腰椎：椎体、后方的椎板、棘突，断面还能看到骨松质的网眼。骨的两侧看肌肉：有一块比较大、比较发达的，就是**竖脊肌**；在竖脊肌的前外侧，还有一块比较大的，叫**腰方肌**；在腰方肌的前方，还有一块比较大的，叫**腰大肌**。最外面是皮肤和皮下脂肪。

筋膜的层次就是这么来的：

```text
腰背部横断面（自外向内）
  皮肤 → 皮下脂肪
  ┌─────────────────────┐   浅层：盖在竖脊肌、腰方肌的后面
  │  竖脊肌  │  腰方肌  │
  ├─────────────────────┤   中层：两肌之间
  ├─────────────────────┤   深层：腰方肌的前方
  │        腰大肌       │
  └─────────────────────┘
```

表面一层是浅层，两块肌肉之间那层是中层，腰方肌前方那层是深层——**腰背筋膜可以分为三层**，把竖脊肌和腰方肌整个包裹在一起。

它向前还有延续：这层膜向前延续到腹内斜肌、腹横肌的筋膜（腹外斜肌和它没有关系）；而背阔肌、下后锯肌，也是通过膜连到腰背筋膜上的。

#### 胸上肢肌：胸大肌、胸小肌、前锯肌

胸肌包括两部分：一个是**胸上肢肌**，第二部分叫**胸固有肌**。

什么叫胸上肢肌？所谓胸上肢肌，它一定和上肢的骨有附着关系。先看挂图：右侧是锁骨，中间是胸骨，整个这一大片叫**胸大肌**，也是一个比较大的扁肌。起点上有没有锁骨？有锁骨的内侧半，还有胸骨，另外有肋软骨（第一肋一直到第六肋的肋软骨）。止点在肱骨的上端，肱骨的**大结节嵴**。

挂图上把胸大肌切开，里边还有一个小的肌肉，这张图不太明显，换一张图就清楚了：它从肩胛骨的**喙突**到三、四、五肋，是一个三角形的小肌肉，位于胸大肌的深面，叫**胸小肌**。

前锯肌在胸部的侧面：上九个肋骨的外侧都有肌肉向后走，起点形成了**锯齿状**的改变，所以我们叫它前锯肌——9 个锯齿。

这三块的功能，都从起止推：

- **胸大肌**：这些纤维收缩，能把肱骨牵拉向内，所以有**内收**功能；又因为肌纤维是在肱骨的**前方**抵止，所以还能让肱骨**内旋**。
- **胸小肌**：起点在第三、第四、第五肋。向上收缩的话，起止关系决定了它只能**提肋**，所以吸气的时候帮我们提肋；向下收缩，则使肩胛骨紧紧地靠近躯干。
- **前锯肌**：起于上九个肋骨的外侧面，向后止于肩胛骨的**脊柱缘**。它收缩，就是把肩胛骨的脊柱缘紧紧地靠近胸廓。

前锯肌一旦损伤，会出现什么表现？

```text
  正常：肩胛骨脊柱缘 ←── 紧贴 ──→ 胸廓
  损伤：肩胛骨脊柱缘 ←── 翘起 ──→ 离开胸廓
```

患者从俯视方向看胸部和肩部，一侧肩胛骨翘起来，就是那一侧损伤了。这种翘起临床上叫**翼状肩胛**。为什么叫翼状？那个鸟刚要飞的时候是不是这个样子——内侧上翘，形成两个膀。所以形容它叫翼状肩胛。

#### 胸固有肌：肋间外肌与肋间内肌

胸固有肌主要包括两块：肋间内肌和肋间外肌。

怎么表示？看这个断面：画两个肋骨，肋骨的断面能看到骨松质，下面还有一个肋。肋骨和肋骨之间有两层肌肉，外边一层我们用**红色**表示，里边还有一层。断面上看，外层的肌纤维走向是**从后上斜向前下**；把它切开一部分、翻起来一看，深层那层肌肉的肌纤维和它**正好相反**。

```text
两肋之间（断面）
   后上 ╲  ╱ 前下
         ╲╱   ← 肋间外肌（外层，红色，纤维后上 → 前下）
         ╱╲   ← 肋间内肌（内层，纤维方向正好相反）
   后下 ╱  ╲ 前上
```

哪个是哪个？红颜色的是**肋间外肌**，里边的是**肋间内肌**。

| 肋间肌 | 位置 | 纤维方向 | 作用 |
| --- | --- | --- | --- |
| 肋间外肌 | 外层 | 后上 → 前下 | 提肋（吸气） |
| 肋间内肌 | 内层 | 与外层相反 | 降肋（呼气） |

怎么理解？肋间外肌的纤维是斜的，它向这个方向收缩，就使肋骨上提——而只有吸气的时候肋骨才上提。肋间内肌方向相反，它是降肋，使肋骨下降。所以它们两个也总称为**呼吸肌**：只要我们呼吸，这两个肌肉都在起作用。

在肋间内肌的里边，还有薄薄的一层肋间最内肌，这个我们就不讲了。胸固有肌，记住两个：肋间内肌和肋间外肌。

#### 膈：位置、形态与结构特点

第三个大块是**膈**。要弄懂膈，先明确五件事：知道膈的位置；知道膈肌的形态；知道膈肌的结构特点；知道膈上面有哪些裂孔、裂孔在哪儿、孔里通过什么结构；最后了解膈的功能。

先说位置。从一个图上看——这个是胸、腹、背、腰、臀，后方是脊柱，在这样一个矢状面上，膈肌在哪儿呢？就在这里。由于它的分隔，上方叫**胸腔**，下方为**腹腔**。所以描述膈肌的位置是：**位于胸、腹之间，封闭了胸廓下口**。

从形态上看，它是一个**扁肌**。

重点是结构特点。把膈肌画出来看：整个肌纤维都位于**外周**，而中心那一块是肌肉的**腱膜**部分，也就是不能收缩的膜状部分，位于**中间**。

```text
膈的结构（示意）
        ┌──────────┐
        │  中心腱  │   中央的膜状部分，不能收缩
   ╭────┴──────────┴────╮
  ╱                      ╲   ← 肌质部：肌纤维都在外周
 ╱                        ╲
```

所以整理一下：膈肌的结构特点是**肌质部**（含有肌纤维的部分）在外周，**腱膜部**在中心——这个中心的腱膜也给它个名字，叫**中心腱**。

#### 膈的裂孔与膈疝

第三个特点：膈肌上有**三个裂孔**。除了裂孔，还有**两个薄弱区**……

等一下，薄弱区不是两个，是**四个**。板图上：前方有两个，后方有两个，这四个区**没有肌纤维**，所以相对膈肌整体来说是最薄的部位。如果腹压增高，腹腔内容物就会通过这 4 个比较薄的区域突向胸腔，这就叫**膈疝**。

至于那三个裂孔，分别叫什么、在哪儿、里面过什么，板图上一目了然：

| 裂孔 | 位置 | 通过的结构 |
| --- | --- | --- |
| 腔静脉裂孔 | 第 8 胸椎的右侧 | 下腔静脉 |
| 食管裂孔 | 第 10 胸椎的左侧 | 食管、迷走神经 |
| 主动脉裂孔 | 第 12 胸椎的前方 | 主动脉、胸导管 |

记忆方式：孔的名字就是过它的结构——腔静脉裂孔过下腔静脉，食管裂孔过食管加迷走神经，主动脉裂孔过主动脉加胸导管。

#### 膈的功能

最后看膈肌的功能。假设我们看的是胸廓的侧壁，下边画的就是膈肌。

处于**收缩**状态的膈肌，膈顶向下来了，中心腱下移——胸腔的上下径是不是增大了？胸腔容积增大，这时候气体应该是**吸入**，是吸气状态。

膈肌**舒张**的时候正好相反：中心腱上移，膈顶向上，胸腔容积减小，肺受压，气体**呼出**。

```text
膈的运动与呼吸
  收缩：膈顶 ↓  中心腱 ↓  胸腔上下径 ↑  容积 ↑  →  气体吸入（吸气）
  舒张：膈顶 ↑  中心腱 ↑  胸腔上下径 ↓  容积 ↓  →  气体呼出（呼气）
```

> **结论**：膈肌收缩向下，是吸气；膈肌舒张向上，是呼气。记住这一条，整个膈的运动就都通了。

## 从"插兜"的手到直疝斜疝：腹壁肌与腹股沟管
> 对应块：BLK12 | 覆盖分集：P18 | 块标题（分集名）：《18.肌学-躯干肌Ⅱ》

上一讲收尾的时候提到了胸腰筋膜，说它包被着一块叫腰方肌的肌肉——那块其实就是腹肌的后群。今天顺着这个尾巴把腹肌讲完：正前方这堵墙由四块肌肉一层层叠出来，往下会撞见腹股沟管，再往里是海氏三角，最后要回答一个很实在的问题：同样是腹压升高，为什么有人得直疝、有人得斜疝。

### 腹肌分两拨，先把坐标认熟

腹肌分成两大部分。**前外侧群**一共四块：最浅的腹外斜肌，它深面一层腹内斜肌，再深面腹横肌，最后还有一块单独的腹直肌。**后群**就是腰方肌——就是刚才随胸腰筋膜一起提到的那一块。

后面每张图都要靠体表标志定位，这几个必须先记住：**髂前上棘、腹股沟、肋弓、剑突**，以及腹正中的**脐**和**正中线**。脐尤其重要，因为腹直肌鞘的分界线就是拿脐往下量出来的。

除腹直肌外，前外侧群另外三块在腹壁外侧排成整齐的三层。它们的故事大同小异：肌质都在后外侧，纤维斜着或者水平地走向腹中线，靠近腹直肌外缘时陆续变成腱膜，最后一起止于白线。

```text
 浅 --------------------------------------------------------------
      腹外斜肌    由后上斜向前下    插兜状
      腹内斜肌    由前下斜向前上    倒插兜状，与外斜肌相反
      腹横肌      水平向内
 深 --------------------------------------------------------------
      三层的腱膜最终都止于腹白线
```

把三层的差别一次摆齐，后面讲腹股沟管时不用再回头翻：

| | 腹外斜肌 | 腹内斜肌 | 腹横肌 |
| --- | --- | --- | --- |
| 肌纤维走向 | 后上→前下，"插兜状" | 斜向前上，与腹外斜肌正好相反 | 水平 |
| 腱膜止于白线的位置 | 经腹直肌前方 | 腹直肌外缘处分前后两层，一前一后夹住 | 从腹直肌后方包裹上来 |
| 起点 | 下8肋外面 | 髂嵴、腹股沟韧带、胸腰筋膜 | 腹股沟韧带、整个髂嵴、胸腰筋膜、下6肋内面 |
| 与腹股沟韧带之间 | 腱膜向下增厚，形成腹股沟韧带 | 内侧半上方有弓状分离区 | 也有一个弓状分离区 |

### 腹外斜肌：一只插兜的手

先看最浅的腹外斜肌。肌纤维从**后上走向前下**，走到内侧逐渐变成腱膜。记住这个方向有个特别省事的办法——把手插进裤兜，看手指指的方向，就是腹外斜肌纤维的方向。插兜状。

这块腱膜的面积特别大，它从外侧兜过来，包绕在腹直肌的前方，最后抵止在腹部正中线。正中线有个正式名字叫**白线**，所以这块腱膜的止点就写作"止于白线"。

起止关系理一遍：起于**下8肋的外面**，斜向前下方；止于**髂嵴**、**腹股沟韧带**，以及**白线**。

这块肌肉要抓住四个要点：

第一个要点，肌纤维的走向——后上向前下，插兜状。这一条决定方向，方向一错整块肌肉的立体关系就全乱。

第二个要点，它的腱膜面积大，因此形成许多结构。髂前上棘与耻骨结节之间连的那条线，就是腹外斜肌腱膜形成的一个结构，叫**腹股沟韧带**。

第三个要点，腹外斜肌腱膜在前下内侧形成**一个三角形的缺口**，叫**皮下环**，它是腹股沟管的外口。

第四个要点，它的腱膜是在腹直肌的**前方**抵止在白线的——是在前方，不是在后方。

> **提示**：这四条连起来是一条线：纤维走向 → 腱膜撑开了多少结构 → 撑出来的缺口在哪 → 最后落在哪儿。第二、三条给腹股沟韧带和皮下环搭好了台子，等讲到腹股沟管时直接就能用；第四条在腹直肌鞘那一节还要再用一次。

### 腹内斜肌：反过来的那一层

做假设解剖，把腹外斜肌切断，露出它的深面——就是腹内斜肌。旁边那个"从中间露出来"的长条仍然是腹直肌。

这块肌肉的纤维走向**和腹外斜肌正好相反**，还是从后下往前上，也就是"倒插兜状"。到了腹直肌外缘，它的腱膜也分成两层：一层包在腹直肌后面，一层包在腹直肌前面，两层最后都止于白线。

起止关系：起于**髂嵴**，**腹股沟韧带**上也有起点，后边的**胸腰筋膜**也有起点；然后纤维向前上，止于**白线**。

三个要点：

- 第一个，纤维方向与腹外斜肌正好相反。一深一浅两层肌交叉成网格，就是腹壁能承住腹压的力学基础。
- 第二个，在**腹股沟韧带内侧半上方有一个弓状分离区**——腹内斜肌的腱膜在这里和腹股沟韧带并不连，中间隔出一个空间。
- 第三个，止于白线时它是分两层的：腹直肌外缘处一前一后各一层，所以它是"经直肌前或后止于白线"。

### 腹横肌：水平的一层，还有那条5厘米的界线

再切一刀，把腹内斜肌也切掉，最深面露出来的是腹横肌。这时腹直肌已经基本整个露在外面了。

腹横肌的肌纤维是**水平走向**，内侧同样是腱膜，从腹直肌的后面包裹上来，止于白线。

起止关系：**腹股沟韧带**、整个**髂嵴**、**胸腰筋膜**，还有**下6个肋的内面**；纤维水平向内，止于白线。

三个要点：

- 第一个，肌纤维水平走向。
- 第二个，腹股沟韧带内侧半的上方，腹横肌**也有一个弓状分离区**。刚才腹内斜肌那里有一个，这里又有一个。
- 第三个，也是最要紧的一个：它到白线时，这个膜状结构在**脐下5厘米**处分界——**脐下5厘米以上，腱膜在腹直肌后方止于白线；脐下5厘米以下，腱膜跑到腹直肌前方止于白线**。这一点很重要，后面讲腹直肌鞘马上就要用它。

> **结论**：腹内斜肌和腹横肌这两层，在腹股沟韧带内侧上方**都有弓状分离区**，所以整个腹壁最薄弱的地方就在这一块。临床上腹股沟疝为什么高发在这里，原因就在这儿——这块腹壁薄，腹压一增高，内容物就能从这儿出来。

### 腹直肌：六个包块是怎么来的

腹直肌是两条长带状的肌肉。起点在**第5到7肋的肋软骨**，向下一直到**耻骨联合**。

它的特别之处在于：这条"长带"其实是由**很多很多短的肌纤维**，借助于**腱划**连接起来形成的。正因为有腱划，健美运动员一用力，腹部就鼓出六个或者八个包块——那不是什么神秘现象，就是肌腹收缩时被腱划分隔出来的鼓包。

接下来借这个肌肉引出三个概念：腹直肌鞘、白线，以及它们共同围出的那条白线。

### 腹直肌鞘：两个断面与半环线

第一个概念，**腹直肌鞘**。它不复杂——包裹腹直肌的那个鞘管，就叫腹直肌鞘。但这个鞘管并不是从头到尾一样厚，所以要设计两个断面来看。

选两个位置：**脐上**做一个断面，记作 **A**；**脐下5厘米以下**再做一个断面，记作 **B**。

看断面 A。腹外斜肌用红色，它的腱膜在腹直肌**前方**止在中线（中线就是白线）；腹内斜肌的腱膜在腹直肌的**外缘分成两层**，一层包在后面、一层包在前面，两层都止于白线；腹横肌的腱膜从**后方**包裹，止在白线。三层这么一夹，腹直肌果然被围成了一个完整的鞘管——前方的叫**前鞘**，后方的叫**后鞘**。

再看断面 B。同样是腹直肌，三层腱膜的位置全变了：腹外斜肌没变，还在前方包裹、止于白线；**腹内斜肌也跑到前方来了**；**腹横肌的下部同样在前面走**。也就是说到了脐下5厘米以下，三层腱膜全部跑到腹直肌前方去了。

那么问题就来了——B 断面上，腹直肌还有后鞘吗？没有了。

```text
  断面 A：脐上                    断面 B：脐下 5cm 以下
  +--------------------------+      +--------------------------+
  |  腹外斜肌腱膜 -> 前鞘    |      |  腹外斜肌腱膜 -> 前鞘    |
  |    +----------------+    |      |    +----------------+    |
  |    |   腹  直  肌   |    |      |    |   腹  直  肌   |    |
  |    +----------------+    |      |    +----------------+    |
  |  后鞘 = 腹内斜肌腱膜     |      |  腹内斜肌腱膜(转至前方)  |
  |       + 腹横肌腱膜       |      |  腹横肌腱膜(也转至前方)  |
  +--------------------------+      +--------------------------+
         <--- 白线 --->              <--- 白线 --->
```

读图要点：左边"前鞘"那一行下面还压着一层"后鞘"，右边前鞘之下就是腹直肌本身，夹在后面的东西全跑到前面去了。

于是腹直肌鞘的**特点**可以定下来了：

> **结论**：**前鞘是完整的**，从上面一直到下面都在。**后鞘只在脐下5厘米以上有**，脐下5厘米以下就没有了。

打个不太恰当但很好用的比方：把两条并拢的腿当成腹直肌，把裤子当成鞘。裤子的前片从上到下都在——那就是完整的前鞘；而后片只盖到某个刻度就"露腿肚子"了。往下那一段，后鞘没了，可这个包不住的地方总得有个边界吧？这个游离缘有个名字，**要记住，它叫半环线**——后鞘消失那个部位的游离缘，就叫半环线。

### 白线：上腹正中切口为什么偏爱它

第二个概念，**白线**。它的位置在腹部正中线上，上端一定是**剑突**，下端是**耻骨联合**。

它的特点有三个：一是**上宽下窄**，宽的地方也就1厘米左右，其实并不宽，窄的地方就呈线状了；二是**坚韧**；三是**无血管**。

这条线的临床意义非常大。设想一个患者：腹部外伤送来，人已经昏迷、休克，自己没法主诉。你在剑突、脐、腹股沟这几个位置做腹部穿刺，抽出来全是血性液体，初步怀疑内脏出血。内脏出血最容易出问题的是**肝和脾**破裂，可到底是肝还是脾？这时候需要做剖腹探查，切口必须**既能够到肝，又能够到脾**——正好就是**上腹正中切口**，也就是顺着腹白线切开。

它凭什么被选中？切开皮肤、皮下组织以后，**直接一刀就进到腹腔了，中间没有那些层次**。好处自然就跟着来了：

- **入腹快**——适合抢救病人，要的就是立刻找到出血点、立刻止血；
- **出血少**；
- **特别坚韧**——所以缝合的时候线不会脱，利于缝合。

优点很多，**唯一的缺点**就是术后这个部位的**瘢痕明显**，会形成很粗、很粗糙的瘢痕组织。

### 腹股沟管：一条四壁俱全的走廊

#### 它在哪里：韧带上方4到5厘米的肌间隙

腹股沟管的位置要清楚。前面讲过，三层腹肌下部的腱膜有两个弓状游离区——腹内斜肌形成一处，腹横肌形成一处——**这个部位就是腹壁最薄弱的部位**。

在这个最薄弱处把管子分成两半看：腹股沟韧带的**内侧半**，其**上方大约4到5厘米**有一条肌间隙，这条间隙就叫**腹股沟管**。间隙能形成，就是因为腹内斜肌和腹横肌在这里跟韧带分离了。

> **定义**：腹股沟管 = 腹股沟韧带内侧半上方约4～5厘米、由腹内斜肌与腹横肌弓状游离缘围成的肌间隙。

#### 两个口：一个在皮下，一个在腹内

作为一个管，一定有两个口。这两个口要反复强调，因为它们是后面判读疝的坐标。

**外口叫皮下环**。讲腹外斜肌腱膜时就说过，它在前下内侧形成一个三角形缺口，那就是皮下环。皮下环的位置在**耻骨结节的外上方**。

**内口叫腹环**。腹环的位置好记：拿腹股沟韧带**中点**就能确定，**中线上方1.5厘米**。

口诀可以这么串：外口在耻骨结节外上方，内口在韧带中点上方1.5厘米。

#### 四个壁：把管切开看

在管上做一个断面把它切开，四个壁就一目了然了。

```text
        上壁：腹内斜肌、腹横肌的弓状游离缘
  - - - - - - - - - - - - - - - - - - - - - -
  |                                        |
  |   o 外口(皮下环)                       |  前壁：腹外斜肌腱膜
  |                                        |  （腹内斜肌也参与）
  |                管  腔                  |
  |                                        |  后壁：腹横筋膜
  |           o 内口(腹环)                 |        + 腹膜
  |                                        |
  - - - - - - - - - - - - - - - - - - - - -
  ==========================================  下壁：腹股沟韧带
                                              （向内反折增厚）
```

读图要点：管子是一根"上盖下托"的斜通道——上面盖着两块肌肉的游离缘，下面托着增厚的腹股沟韧带；前壁那块黄色的膜是腹外斜肌腱膜，后壁那层几乎贴在一起的是腹横筋膜和腹膜。

四壁逐一落定：

- **前壁**：腹外斜肌腱膜。另外腹内斜肌有一部分也在内口的前方，所以**腹内斜肌也参与构成前壁**。
- **后壁**：腹横筋膜，加上薄薄的一层腹膜。
- **下壁**：腹股沟韧带，相当于管的地板。
- **上壁**：腹内斜肌和腹横肌两个肌肉的**弓状游离缘**。

再补一个立体关系。腹内斜肌起自腹股沟韧带的**外侧前缘**，止于韧带的**内侧缘**；腹横肌起自腹股沟韧带的**内侧**，同样止于内侧缘。**这两个止腱合在一起，有个名字叫联合腱。**

再往里就是腹横筋膜和腹膜，它们几乎贴在一起，画图时当成一个层次看。再往里，腹腔通过内口进入管，从外口出去——**内口进，外口出**，这是一根管。

#### 管里通过什么：男女不一样

第四样要看的是管内通过的结构，男女不一样：**男性是精索通过；女性通过的是子宫圆韧带**。

把整条管再通盘回顾一遍：位置在腹股沟韧带内侧半上方约4到5厘米的肌间隙；四壁是前壁腹外斜肌腱膜（加一部分腹内斜肌）、上壁腹内斜肌与腹横肌的弓状游离缘、后壁腹横筋膜与腹膜、下壁腹股沟韧带；两个开口，一个腹环（韧带中点上方1.5厘米），一个皮下环（耻骨结节外上方）。东西从内口进、外口出。

### 海氏三角：薄弱区里的薄弱

#### 换个角度，从腹腔里往外看

要讲海氏三角，先得看清这块地方的立体关系。前面是站在腹壁外面看，这回从**腹腔里向外看**。

这时候能看见：腹白线、腹直肌，往上腹直肌有后鞘，后鞘的游离缘就是刚才说的**半环线**；用另一种颜色标出腹股沟韧带，还有一整面**髂骨的骨面**。

这块地方有几个结构得交代清楚：

- 腹股沟韧带内侧有**一部分纤维向内后反折**，这部分反折的纤维叫**腔隙韧带**，也叫**陷窝韧带**。它反折到耻骨梳，并且和耻骨梳愈合到一起，**这一段就叫耻骨梳韧带**。
- 在中部有**一部分纤维向下立**，叫**髂耻弓**。它把腹股沟韧带和骨面之间分成了**两个间隙**：**外侧那个叫肌间隙，内侧那个叫血管间隙**。
- **血管间隙**里当然有血管：有个**股动脉**从这个间隙进入大腿，还有和它伴行的静脉往下走。动脉会发出分支，**斜向前内**，一头钻进了后鞘里——这就叫**腹壁下动脉**；和它伴行的**腹壁下静脉**同样进入后鞘、向上走。
- 腹股沟管在这一块也能看到：里面有些静脉、有些动脉，还有**硬如麻绳的输精管**，都在往管道里走。

```text
                  腹壁下动静脉
                    - - - - - - - - - - -   腹股沟管（自本区后方穿过，
                          /             \    位于动脉的前面）
                         /               \
                        /  海 氏 三 角    \
                       /                   \
                      o--------------------o
                腹直肌外侧缘          腹股沟韧带（下壁）
```

读图要点：三角的三条边分别是向内上走的**腹壁下动静脉**、内侧的**腹直肌外侧缘**和下方的**腹股沟韧带**；虚线是腹股沟管，它从三角区的后方斜穿而过。

#### 三角由什么围成，位置又在哪

现在这个三角就看得非常清楚了：**腹直肌的外侧缘 + 腹壁下动静脉 + 腹股沟韧带**，三者围成一个三角区，这个三角区就叫**海氏三角**。

位置上可以这样定位：**海氏三角在腹股沟管内侧半的后方**，而**腹股沟管在腹壁下动脉的前方**。

#### 直疝与斜疝：两条不同的路

讲腹股沟韧带的时候已经交代过，腹股沟管的位置是腹壁的**最薄弱区**；海氏三角是薄弱区里更靠内的**薄弱区**。这两块共同的特点就一个字：**薄**。

既然薄，腹压升高的时候容不容易形成疝？会。而且是**两种**。

**直疝**是这样来的：腹压升高，肠管很容易突入到这个间隙里；一突入，腹壁本身很薄，就跟着一起向外突。注意这块有个间隙，这个间隙就是腹股沟管——**海氏三角在管的后方**，所以是**管连着腹壁一起往外鼓**。这种在管的后方、绕开管腔膨出来的疝，叫直疝。

**斜疝**是这样来的：腹壁上有孔，比如**腹环**。腹环本来就是个缺口，腹压升高时肠管顺着这个管突进去，突进去以后把管撑开。这就是**沿着管子走**的疝，叫斜疝。

两种疝的位置其实差不多——都在腹股沟区、腹股沟、腹正中线一带鼓出一个包。外观上分不太清，所以必须靠鉴别方法。

#### 躺下来、还纳、用手按住内口

鉴别直疝和斜疝，办法很朴素：**先让患者躺在床上**，躺下以后腹壁放松；然后把疝内容物**还纳回去**；这时候你用手**压住管的内口**——这就相当于把这根走廊的门关上了。

然后让患者**慢慢起来**，起来以后腹压增加、咳嗽，再看这块鼓不鼓包。如果压着它，患者一起来这个包又出现了——这是哪种疝？它**经过管没有**？

### 本讲提到的题目

**题目**：一位腹股沟区肿物的患者，取仰卧位并放松腹壁，将肿物还纳后，术者用手压住腹股沟管的内口嘱患者起身咳嗽，肿物随即突出。请问这是直疝还是斜疝？该疝是否经过腹股沟管？

**解析**：

第一步，把"手压内口"这个动作翻译成解剖语言——**手压住的是管的内口，也就是这根走廊的门**。门一关，走廊这条路就被封死了。

第二步，回头看两条路各自是怎么走的。**斜疝**是肠管从腹环这个缺口钻进去、顺着管子一直走到皮下环出来的，它必须经过管腔；那么管的内口一按，斜疝这条路就断了，包绝不该再鼓起来。**直疝**则是在管的后方，把海氏三角这块薄壁连着管一起向前提出去，它根本不经过管腔；所以手按在管的内口上，压根挡不住它，包照样鼓。

第三步，对照现象：压着还鼓，就是**直疝**，而且它**不经过腹股沟管**；压着不鼓、放手才鼓的才是斜疝。

**答案**：**直疝**，该疝**不经过腹股沟管**，而是由腹壁下动静脉、腹直肌外侧缘和腹股沟韧带围成的海氏三角区连同腹壁一起向外膨出。

> **承前启后**：上一节讲完「从"插兜"的手到直疝斜疝：腹壁肌与腹股沟管」，下一节接着讲「上肢肌：肩到手的四层肌肉」。

## 上肢肌：肩到手的四层肌肉
> 对应块：BLK13 | 覆盖分集：P19 | 块标题（分集名）：《19.肌学-上肢肌》

今天我们学习上肢肌。上肢肌包括四大部分：肩肌、臂肌、前臂肌和手肌。

先说清分工。肩肌数量比较多，重点掌握三角肌的起止和作用；除了三角肌，还要知道一些比较小的肌肉，比如冈上肌、冈下肌、小圆肌、大圆肌和肩胛下肌——这些小的，理解它们的名称和位置就够了。臂肌和前臂肌则以大块肌肉为主，起止、作用必须记牢。到了手肌，重点落在中间群，外侧群和内侧群知道名字即可。

一个一个来看。

### 肩肌：包绕肩关节的这一圈肌肉

#### 三角肌：三角形的起点，三条纤维

先看三角肌在哪儿。这是锁骨，这是胸大肌，三角肌的位置就在肩关节的周围。抵止在什么部位呢？肱骨有一个三角肌粗隆，止就在这儿。

从上边观察三角肌，可以看到它的肌纤维从肩关节的三个方向包绕肩关节。起点是三角形的：锁骨的外侧段有肌纤维起，肩峰有，肩胛冈有，三处汇成一个三角形；抵止在肱骨的三角肌粗隆。

```text
                        锁骨外侧段
                            ●
                           ╱ ╲
                肩峰 ●────┘   └────● 肩胛冈
                       ╲           ╱
                        ╲         ╱
                         ╲       ╱
                          ╲     ╱
                           ╲   ╱
                            ▼
                    肱骨三角肌粗隆

        肌纤维从肩关节的三个方向包绕肩关节：

            前部纤维 ──收缩──▶ 肩关节前屈
            后部纤维 ──收缩──▶ 肩关节后伸
            外侧纤维 ──收缩──▶ 肩关节外展   ← 主要作用
```

功能就跟着这三条纤维的走向来：前方的纤维收缩，能使肩关节前屈；后方的纤维收缩，能使肩关节后伸；外侧的纤维收缩，能使肩关节外展。

> **结论**：三角肌最主要的作用是肩外展，来自外侧的（外部）那束纤维。

#### 冈上肌、冈下肌、小圆肌、大圆肌：记名字和位置就够了

先回忆肩胛骨：上角、喙突、肩峰、外侧角、下角。另一侧看到的是肱骨的上端。

看这几个窝。冈上窝里有一个小肌肉，向外止于大结节，这叫冈上肌。冈下窝也有一个肌肉，向外止于大结节，叫冈下肌。再向下排列，这一块叫小圆肌，也是止在大结节。

功能从跨过的位置推：冈上肌从肩关节上方过来，止在大结节，收缩时能协助臂外展；冈下肌和小圆肌在肩关节后方、又止于大结节，所以收缩时能使肱骨外旋。

再往下看，还有一个肌肉叫大圆肌。注意大圆肌的止点跟前面几个不一样——它是**通过肱骨上端的前方**，止于小结节嵴。所以它收缩时能使臂内收；因为止点在前方，还能使肱骨内旋。

| 肌肉 | 位置 | 止点 | 作用 |
| :--- | :--- | :--- | :--- |
| 冈上肌 | 肩胛骨冈上窝 | 肱骨大结节 | 协助臂外展 |
| 冈下肌 | 肩胛骨冈下窝 | 肱骨大结节 | 使肱骨外旋 |
| 小圆肌 | 冈下肌的下方 | 肱骨大结节 | 使肱骨外旋 |
| 大圆肌 | 肩胛骨下角处 | 小结节嵴（经肱骨上端前方） | 使臂内收，并使肱骨内旋 |

这些名词大家记住：冈上肌、冈下肌、小圆肌、大圆肌，再加上前面点到名的肩胛下肌。**以上这些肌肉我们管它叫做肩肌**——在肩关节周围，也可以说就是运动肩关节的肌肉。

### 臂肌：前群三块，后群一块

臂肌分为前群和后群。前群我给大家介绍三个：肱二头肌、喙肱肌，还有一个叫肱肌。后群只有一块，肱三头肌。

#### 前群：三块肌肉，三条不同的路径

**肱二头肌。** 前面观上非常醒目：一个头、一个头，两个头汇合一个肌腹，然后抵止在桡骨粗隆。因为上边有两个头，所以叫二头肌。

看板图更清楚。肱骨上端除了大结节以外，还有个小结节；小结节向下延续的骨性隆起叫小结节嵴；这两个隆起之间叫结节间沟。肱二头肌的长头起于盂上结节，也叫盂上粗隆，通过结节间沟下来；另一个头也往下走，止于桡骨粗隆。起始端是两个头，所以这个肌肉叫肱二头肌。

它跨过了肩关节前方，又跨过了肘关节前方，功能自然就有了：对肩关节是屈肩关节，对肘关节是屈肘关节。

**喙肱肌。** 把肱二头肌切掉，这块就看得比较清楚了：它从喙突下来，一直到肱骨干中段的内侧面。它同样在肩关节前方，所以也协助屈肩；另外还能使臂内收。

**肱肌。** 起自肱骨前方下半部，止于尺骨粗隆。它只跨过了肘关节前方，所以作用最单纯：屈肘。

板上定位要用的骨性标志，顺手复习一遍：

- 肩胛骨前面：上角、喙突、肩峰，上方翘起的是肩峰，下面那个面是肩胛下窝；
- 肱骨上端：肱骨头、大结节、小结节、小结节嵴、结节间沟；
- 肱骨下端：外侧有一个球状的关节面，是肱骨小头；内侧是滑车状的肱骨滑车，还有内上髁；
- 小头下方衔接的就是桡骨，桡骨粗隆在那边，桡骨头在最上；尺骨的前方有尺骨粗隆，后方有尺骨鹰嘴。

```text
| 肌肉     | 起点                                        | 止点       | 作用                          |
| -------- | ------------------------------------------- | ---------- | ----------------------------- |
| 肱二头肌 | 长头起于盂上结节（盂上粗隆），经结节间沟下行 | 桡骨粗隆   | 屈肩关节 + 屈肘关节          |
| 喙肱肌   | 肩胛骨喙突                                  | 肱骨干中段内侧 | 协助屈肩，并使臂内收      |
| 肱肌     | 肱骨下半部前方                              | 尺骨粗隆   | 屈肘关节                      |
```

前群这三块的起、止、点、功能，把它记住。

#### 后群：肱三头肌三个头汇于鹰嘴

后群要看肩关节的后面。还是那些标志：肩胛骨的上角、切迹、喙突、肩峰、外侧角、下角，旁边是肱骨、肱骨下端的内外上髁、尺骨的鹰嘴，再下面是桡骨的桡骨头。

起止关系一看就清楚：上面三个头——长头是从肩关节后方来的；肱骨后方中段有个桡神经沟，桡神经沟**下方**起内侧头，神经沟**上方**起外侧头。三个头汇合，下边止于尺骨的鹰嘴，这一个肌肉就叫肱三头肌。

```text
   肩胛骨 ──长头───┐
                   │
  桡神经沟上方 ─外侧头┼──▶ 汇合 ──▶ 尺骨鹰嘴
                   │
  桡神经沟下方 ─内侧头┘

  只有长头跨过肩关节后方 → 协助肩关节后伸；斜着走，还能使臂内收
  三个头绝大多数都过肘关节后方 → 伸肘关节（最主要的作用）
```

从起止点推功能：只有长头跨过了肩关节后方，所以它能协助肩关节后伸（往后叫后伸）；因为是斜着走的，还能内收。而三个头大多数都通过肘关节后方，所以它最主要的作用是伸肘关节。

从挂图的后方再看一遍，三角肌是比较发达的一个，上边是冈上肌，冈下肌就不说了；三头汇合止于鹰嘴的这就是肱三头肌，属于后群里比较大的一块肌肉。

### 前臂肌：九个对十个，只记功能

前臂肌可以分为前群和后群两部分。前臂的前群肌肉，也可以叫屈肌群；后群呢，可以叫伸肌群。从功能上已经给它定格了——一个是管屈，一个是管伸。

前群九块，后群十块，数量很多，那就不单一地给大家介绍每一个了，大家熟悉功能就行。

| 肌群 | 块数 | 另一个名字 | 四个共同功能 |
| :--- | :---: | :--- | :--- |
| 前臂前群 | 9 | 屈肌群 | 屈肘、屈腕、屈指、前臂旋前 |
| 前臂后群 | 10 | 伸肌群 | 伸肘、伸腕、伸指、旋后 |

从跨过的关节就能理解这四个功能：前群肌跨过肘关节当然能屈肘，跨过腕关节能屈腕，还能屈指，再就是旋前。后群的功能和它相对应：伸肘、伸腕、伸指、旋后。

> **提示**：旋前、旋后是按解剖方位命名的，不是按你看到的动作画面命名的——把手掌旋向前、掌心朝下，叫旋前；旋向后、掌心朝上，叫旋后。记住：前群是旋前，后群是旋后。

#### 腕部表浅肌腱：自己就能摸的解剖学

肌肉我们不详细说了，但腕部的表浅肌腱有些是标志性的，最好熟悉一下。大家可以做两个实验。

**实验一：握拳。** 握拳的时候，在腕部能发现三个最表浅的、隆起的肌腱。其中隆起最高的、在中间的那个，叫掌长肌腱；位于桡侧的，是桡侧腕屈肌腱；位于尺侧的，是尺侧腕屈肌腱。这三个起码要知道。

```text
   握拳时腕前三条最表浅的肌腱（自桡侧到尺侧）

       桡侧腕屈肌腱      掌长肌腱      尺侧腕屈肌腱
           │                 │                │
           │◄── 桡动脉 ─────►│                │
           │                 │◄── 尺动脉 ───►│
           │                 │                │

    （掌长肌腱在中间，隆起最高）

   桡动脉就在桡侧腕屈肌腱的桡侧，紧挨着肌腱；
   尺动脉在尺侧腕屈肌腱的桡侧，也就是靠中间的那一侧。
```

摸到肌腱，别忘了动脉：桡动脉就在桡侧腕屈肌腱的桡侧，紧挨着肌腱；尺动脉在尺侧腕屈肌腱的桡侧。这两处都是能把脉的地方。

**实验二：手背隆起，拇指也向后伸。** 这样手背能看到四个隆起的肌腱，就是指伸肌腱。拇指那边的两个要单独注意：上面这个是拇长伸肌腱，下面这个是拇短伸肌腱。拇指的指根这个部位，能看到一个三角形的凹窝，我们叫它三角窝。

摸一下，桡动脉有一个小的分支，从这里绕到手背侧，通过这个三角窝，再经过第一掌骨间隙，穿到掌侧面去了。所以在三角窝里边也能摸到这个分支的搏动。

所以这些表浅的肌腱，有个印象就可以了。

### 手肌：三群，重点在中间群

手肌包括三群：外侧群，管它叫大鱼际；内侧群，叫小鱼际；中间群是我们重点掌握的部分。外侧群、内侧群，大家知道名称就可以了。

#### 大鱼际与小鱼际

**大鱼际**，就是手拇指这个比较发达的肌肉群。里面有四块。外缘有一个很小的肌肉，我们把它切断——为了看深面的肌肉——这个叫**拇短展肌**；在拇短展肌的深面，这块叫**拇对掌肌**；再靠尺侧的，叫**拇短屈肌**；再向尺侧向下、有一部分纤维横向尺侧呈扇形的，叫**拇收肌**。这四块加在一起，有个大名，叫大鱼际。

**小鱼际**在尺侧。先看一个小的肌肉，同样把它切断，注意它的下端正好附着在一个骨上。腕部有没有这样一个小小的圆形的骨？有——豌豆骨。所以这块止于豌豆骨，叫**小指展肌**；再往里有一个短的，叫**小指短屈肌**；再向桡侧，肌纤维是斜行的，叫**小指对掌肌**。

| 肌群 | 所含肌肉 |
| :--- | :--- |
| 大鱼际（外侧群） | 拇短展肌、拇对掌肌、拇短屈肌、拇收肌 |
| 小鱼际（内侧群） | 小指展肌（止于豌豆骨）、小指短屈肌、小指对掌肌 |

这样外侧群、内侧群就有了基本了解，知道这些肌肉的名称就行了。重点我们看中间群。

#### 骨间肌：掌三收，背四散

中间群包括两部分内容：一个是骨间肌，还有蚓状肌。骨间肌一共有 7 块，蚓状肌是 4 块。骨间肌就是位于掌骨之间的，它还分为掌侧骨间肌和背侧骨间肌。

我画个图，大家判断一下哪个是掌侧面、哪个是背侧面。腕骨一共 8 块：舟、月、三角、豆、大、小、头状、钩，上面 4 个、下面 4 个。哪一面是掌侧？豌豆骨是不是在掌面——所以这一面就是掌侧面。

```text
【掌侧面】只在 3 个掌骨间隙里有肌肉

    ①—②     ②—③     ④—⑤        ①②③④⑤ = 五根掌骨
     ↑        ↑        ↑
    食→中    四→中    小→中

    起自掌骨 → 抵止在指骨的指背腱膜
    三块一起收缩：食指向中指靠拢、四指向中指靠拢、小指向中指靠拢
    四指并拢时实际移动的是三个指，中指没有动 → 这叫内收
    → 掌三收（既肯定了块数 3，又肯定了功能"收"）
```

```text
【背侧面】4 个掌骨间隙里都有肌肉

    ①—②     ②—③     ③—④     ④—⑤
     ↑        ↑        ↑        ↑
   食指     中指     中指    环指+小指
   远离中指  可桡移   可尺移   远离中指

    起点在相邻两个掌骨的相对缘 → 形成一个肌腹 → 到指骨去

    中指两侧各有一块：如果只收缩它俩，中指可以内外移；
    两块一起收缩，力量相互抵消，中指不动，实际散开的还是四指
    → 背四散（使四指散开）
```

> **结论**：骨间肌一共 7 块，掌 3 背 4；掌三收，背四散。

**临床上怎么查？** 检查骨间肌是否瘫痪，就让患者夹纸。正常人能不能夹住纸片？能夹住，医生往外拉的时候有一定阻力。可是骨间肌瘫痪的患者夹不住，一点阻力都没有。

#### 蚓状肌与爪型手

蚓状肌的起止关系，先看肌腱。前群肌有两个腱：一个是指浅屈肌腱，一个是指深屈肌腱。指浅屈肌腱发出四个腱，到达这四个指去；指深屈肌腱则一直下行，到末节指骨的底部。

蚓状肌怎么走？蚓状肌都起在这四个肌腱的**桡侧**，然后向前、到指背去，止于手指背侧的指背腱膜。所以蚓状肌一共 4 块。

这一组肌肉要收缩，能做什么动作？大家看这个动作：小指伸开，四指也伸开，这根也伸开了。这个动作跨了几个关节？掌骨和第一节指骨之间有一个关节，叫**掌指关节**；第一节和第二节之间、第二节和第三节之间还有两个关节，这两个叫**指间关节**。每个指都是这样。那么这个动作里，掌指关节是屈的，指间关节是伸的。

> **结论**：蚓状肌的作用是屈掌指关节、伸指间关节。

四块蚓状肌的神经支配是不一样的。第三、第四蚓状肌是由尺神经支配。那么，当尺神经损伤的时候，为什么描述患者的手是"爪型手"？因为这两个蚓状肌是坏的——屈掌指、伸指间这个动作做不出来，它们不往前走了；后边的肌肉张力相对增加，就把它落到后边去了。爪型手就是这样形成的，说明损伤的是后两个蚓状肌。

---

> **提示**：整块上肢肌，学习的时候要分清主次。大块的肌肉——三角肌、肱二头肌、喙肱肌、肱肌、肱三头肌——把起止、作用、位置记牢；小的肌肉主要熟悉名称就可以了。

> **承前启后**：上一节讲完「上肢肌：肩到手的四层肌肉」，下一节接着讲「下肢肌：先把骨头摆好，肌肉就认得了」。

## 下肢肌：先把骨头摆好，肌肉就认得了
> 对应块：BLK14 | 覆盖分集：P20 | 块标题（分集名）：《20.肌学-下肢肌》

这一讲我们过下肢肌。下肢肌一共四摊——髋肌、大腿肌、小腿肌、足肌。听着挺多，其实一块一块拆开来一点都不难，难的是刚开始容易懵：明明背了一堆名字，脑子里的骨盆和股骨却是一片空白，肌肉从哪儿起、到哪儿止，全对不上号。

所以咱们还是老规矩：讲肌肉，先把骨头摆出来。这些骨性标志我们在骨学那几讲里都学过，今天不是重学，是把它们重新摆到板图上，加固一下印象。因为下肢肌的每一条起止点，最后都要挂到这些点上去。

### 讲肌肉，先把骨头摆好

先看骨盆这一侧。髂前上棘、髂结节、髂前下棘在这儿；往中间是骶骨，画了 4 条横线，骶前孔就在横线之间；再往下是闭孔。髋臼在这儿，髋臼里坐着的那个球就是股骨头——骨盆这一块和股骨上端，界限就是这么划的。

股骨往下走，下端向两侧膨大的那两个，叫侧髁；前方是髌骨；髌骨下面接胫骨，胫骨的外侧是腓骨。记住这几块，等下肌肉一过来你就知道它挂哪儿了。

有一个点今天要特别拎出来：股骨上端朝内后方，有个小小的凸起，叫**小转子**。这地方今天要被好几块肌肉点名，务必认准。

再往上看，这块是腰椎，五节：5、4、3、2、1；上面还应该有一块，第 12 肋。看肌肉怎么走——从 5 个腰椎的外侧面和腰椎的横突起，向下来，止于小转子。

我们把今天要反复用到的骨性标志捋一遍：

```text
   腰椎 5 4 3 2 1 ── 上面还顶着第 12 肋
   骶骨（4 条横线、骶前孔）── 臀大肌、梨状肌的起点
   髂嵴 / 髂前上棘 / 髂前下棘 / 髂结节 / 髂后上棘 / 髂后下棘 / 大切迹
   髂窝 ── 髂肌的起点
   髋臼 → 股骨头
   大转子 / 小转子 / 转子间嵴
   股骨干 / 股骨粗线 / 收肌结节
   髌骨 ── 被股四头肌包住
   胫骨粗隆 / 腓骨小头 / 闭孔
   坐骨棘 / 坐骨结节 / 耻骨支 / 坐骨支
```

这一串背下来，后面每一块肌肉你都有地方"挂"。

### 髋肌前群：两块屈髋的肌肉

髋肌分两群，前群和后群。前群就两块：髂腰肌和阔筋膜张肌。

#### 髂腰肌：名字是两块肌肉凑出来的

挂图上这个展示得不全，我们看不清楚，得上板图。

从 5 个腰椎的外侧面和横突起，往下走，止于小转子——这块叫**腰大肌**。髂骨髂窝里还住着一块，起自髂窝，向下也止于小转子——这块叫**髂肌**。

重点来了：这两块肌肉，止点在一点上，都是小转子。既然止点归到一块儿，我们干脆就把它们看成一块肌肉。一个有个"腰"字，一个有个"髂"字，那大名合起来是什么？

> **定义**：髂腰肌——由腰大肌和髂肌合并构成，统称髂腰肌。

走行关系上，它是通过髋关节的前方的。它一收缩，大腿怎么样？屈曲。这个动作就叫屈髋。

一块肌肉，名字是两个肌肉名字拼出来的，记住它的办法不是硬背，而是记住"两块都止于小转子"这件事。

#### 阔筋膜张肌：肌腹很小，腱膜很长

这块肌肉小得很。从髂前上棘下来一个很小的肌腹，主要是**以腱膜的形式**止于胫骨上端的外侧——注意，跟髂腰肌的"小转子"不是一回事。

这里有个问题，我估计你们看挂图的时候也卡过：从这个角度看过去，根本看不出阔筋膜张肌到底是在髋关节的前方，还是在髋关节的外侧。

换个角度，从侧面看。先把髂嵴定出来，髂前上棘在这儿；股骨干在前，髌骨、胫骨，外侧是腓骨。这个肌腹很小，从髂前上棘下来，以腱膜的形式到胫骨上端的外侧——现在能看出来了：它在髋关节的**前方**。

所以它的作用也是屈髋。

> **易错点**：阔筋膜张肌在髋关节前方，不在外侧。挂图上看着像外侧，是视角骗人，换到侧面看就清楚了。

### 髋肌后群：三块臀肌和一个临床考点

后群肌肉比较多，有的浅、有的深。

浅层先看名称：臀大肌、臀中肌、臀小肌——一共三块臀肌。深层都是一些细小的肌肉。

#### 三块臀肌：叠着的，不是重叠的

看骨盆后侧这块：髂后上棘、髂后下棘、大切迹、坐骨棘、坐骨结节、髂嵴、髋臼；髂骨这一块是股骨颈，往下是大转子、小转子、转子间嵴；再往内侧，是骶骨。

第一块臀肌，臀大肌。回忆一下讲股骨的时候——股骨上端后方有一块，叫**臀肌粗隆**。有一块肌肉从髂嵴的外侧面往下来，止于臀肌粗隆；起点还有一部分在骶骨背面、髂骨的外侧面。这个比较大的肌肉就是臀大肌。

第二块叫臀中肌，在臀大肌的**深面**，也起自髂骨外侧，止于大转子。

中肌的深面还有一个，在它的深面——这叫**臀小肌**。

现在看这三块的关系：臀大肌、臀中肌，臀小肌在臀中肌的深面。说明什么？三块臀肌不是完全重叠的，只有部分重叠。这一点很要紧——因为下一条就要用到。

#### 臀部注射扎哪儿：这个必须记住

从体表上看：臀大肌在这儿，臀中肌在它的深面，臀小肌再深。

那么临床上打臀部针，扎在哪儿？在这个位置。要从四个象限上看一看——

```text
      臀 部 四 象 限
  ┌──────────────┬──────────────┐
  │  外上象限    │  内上象限    │
  │  （相对安全）  │ （血管神经）  │
  ├──────────────┼──────────────┤
  │  外下象限    │  内下象限    │
  │              │              │
  └──────────────┴──────────────┘
```

为什么外上相对安全？因为内上那一块有东西：臀上血管、臀上神经、坐骨神经、股后皮神经、阴部神经、血管神经，都在内侧这两个范围里。相对安全的意思是——相对，还没到最安全。

> **结论**：臀部注射真正最安全的部位，是外上象限里靠近髂前上棘的那块三角区。

怎么找？摸到这个髂前上棘——食指摸到髂前上棘，然后中指向下，把手指分开，顺手把皮肤绷紧，在这个三角区、在你这两指之间直接进针。这就是最安全的一个进针部位。

> **提示**：这一段是硬考点，操作前必须记住——先摸髂前上棘定外上缘，两指之间进针，不要凭"外上象限"四个字随便扎。

#### 深层的小肌群：记住名字和位置就够了

深层这几块，我们不用记起止点。板图上画下来，认出位置、叫出名字就行。

第一个要记住的是**梨状肌**——从骶骨到大转子，就一条，记住它。起自骶骨，止于大转子，作用是能够略微协助髋关节外展。

它下面这几个，就更简单了：上孖肌；起自闭孔、止于转子间窝的，叫**闭孔内肌**；下边还有下孖肌；再下面有一块比较大的，叫**股方肌**。

这几个肌肉的作用，我们一起看。它们都能使股骨**外旋**——为什么？因为它们抵止在后边。就这么简单一句话，原因就在止点的位置上。

髋肌到这里就讲完了。

### 大腿肌前群：缝匠肌与股四头肌

大腿肌分三群：前群、后群、内侧群。先看前群，就两个肌肉。

#### 缝匠肌：想想街边那个鞋匠

这个扁带状的肌肉，起自髂前上棘，然后斜向下内，最后止于**胫骨上端的后方偏内**。

这块叫缝匠肌。

它跨了几个关节？一个髋关节，一个膝关节。那么收缩的时候：对髋关节来说是屈髋；对膝关节来说，是屈还是伸？屈。所以它能屈髋、屈膝。

屈髋又屈膝——这不就是我们盘腿那个动作吗？大家想，街边上那个缝鞋匠，他的体位，是不是就是盘腿坐着那么个姿势？这就是这个肌肉的功能。

#### 股四头肌：查一查，到底几个头

缝匠肌的深面，是大腿上最发达的一块肌肉——股四头肌。

来了，我们查一查它到底几个头。板图上一看，一个、两个、三个……只看到三个头？

别急。**当你把这个头切掉的时候**——你看，断面出来了，断面里还埋着一个，叫**股中间肌**。一二三，再加上它，四个头。

```text
   髂前上棘 + 髂前下棘
            │
        ┌───┴───┐
        │ 长 头 │
        └───┬───┘
   股骨外侧 →  外 侧 头        股骨内侧 →  内 侧 头
        └───┬───┘
            │   ┌────────┐
            └───┤股中间肌│
                └────┬───┘
                     │
              ┌──────┴──────┐
              │    髌 骨     │
              └──────┬──────┘
                     │  髌韧带（短腱）
                     │
                 胫骨粗隆
```

四个头合在一起，包裹髌骨，止于胫骨粗隆。中间跨过髌骨的那一小段短腱，叫**髌韧带**——我们在讲膝关节解剖的时候提到过它，这里再遇上它了。

它也跨两个关节，髋关节和膝关节，而且都在前方下降。所以作用是：对髋关节来说，也能屈髋；对膝关节来说，是伸膝。

> **结论**：股四头肌——屈大腿，伸小腿。

前群就这两块。

### 大腿肌后群：伸髋、屈膝

从后方观察。先把骨性标志摆好：髂后上棘、髂嵴、髂后下棘、大切迹、坐骨棘、坐骨结节；内侧是骶骨，往下大转子、小转子、两个侧髁、髁间窝，股骨粗线，胫骨、比目鱼肌线，外侧腓骨小头。

后群我们提三块。

**股二头肌**，两个头。长头止于腓骨小头；还有一个头起自股骨粗线，也到腓骨小头。两个头合成一个肌腹，叫股二头肌——长头、短头。

**半膜肌**，从坐骨结节到胫骨上端后方。

**半腱肌**，走行其实和半膜肌是一样的。

把名字写上：股二头肌、半腱肌、半膜肌。

共同点很清楚：它们都在髋关节后方下来，都能协助**伸髋**——髋关节向后伸；还能**屈膝**。

> **结论**：大腿后群——伸髋、屈膝。

### 大腿肌内侧群：从上到下排开的四块

内侧群还有一个名字，叫**内收肌群**。先摆骨性标志：髂前上棘、髂嵴、下棘、髋臼、骶骨（横线、骶前孔）、闭孔；股骨颈、大转子、两个侧髁——注意这个叫**收肌结节**；髌骨、胫骨、胫骨粗隆、腓骨头。

从挂图上从上往下看，一块一块认：

- **耻骨肌**。上面有个耻骨线，也就是在股骨的后方，然后往上到耻骨上去。这是最上面的一块，是个小的肌肉。
- **短收肌**。耻骨肌再向下，止于股骨粗线。
- **长收肌**。再往下，也止于股骨粗线。
- **大收肌**。最下面这块最大，起自坐骨结节、坐骨支、耻骨支，往下到粗线。

名字写上：耻骨肌、短收肌、长收肌、大收肌。这四块从上到下排成一列，止点越往下越往股骨中线收，最后一块最大。

大收肌我要重点说，因为它身上背着一个以后讲血管一定要用到的结构。

大收肌上端，从坐骨结节、坐骨支、耻骨支开始往下。注意，它有**两个止点**：一个止于股骨粗线，一个止于收肌结节。两个止点之间，肌肉是不分开的——就在这儿形成一个孔，叫**腱裂孔**。

```text
   大收肌：起自坐骨结节、坐骨支、耻骨支
                        │
        ┌───────────────┴───────────────┐
        │                               │
        │  止于股骨粗线                 │
        │  止于收肌结节                 │
        │                               │
        └──────────── 腱裂孔 ───────────┘
                        ↑
                 股动脉自前方穿孔
                        │
                        ↓
                 到达腘窝后方
                 改名：腘动脉
```

这个孔有什么用处？以后讲血管的时候会提到：从上边下来的血管，开始是在大腿**前方**下降；下降到收肌裂孔的时候，直接从这儿就到达**腘窝后方**去了，到了腘窝就变成**腘动脉**。

> **提示**：把腱裂孔和大收肌的第二个止点（收肌结节）绑在一起记——正因为大收肌要同时抓粗线和收肌结节，两止点之间才撑出一个洞给血管走。这叫结构与功能的相互解释。

整个内收肌群的功能：一是**内收大腿**。

二是外旋。道理和髋肌后群那几块深层肌一样——大家看，这些肌肉都止于股骨后方的正中线上，止点在后面，肌肉一收缩，骨就往外转。

> **结论**：内收肌群——内收大腿 + 外旋股骨。

### 小腿肌：分三群，重点记功能

小腿肌也分三群：前群、后群、外侧群。

这一部分的要求跟前面不一样：**不要求大家记住每块肌肉的起止点**，重点了解功能就行——便于临床上做个鉴别。

#### 前群：从足背爬到各个趾

挂图上先看个印象。前群肌是通过**足背**到各个趾去的。

它的作用是什么？大家看这个动作——脚背往上翘，这叫**足背屈**；各趾是伸还是屈？**伸趾**；脚心向内，叫**内翻**。

这就是前群肌的作用。

#### 后群：小腿三头肌与跟腱

从侧面看后方，最发达的这块就是后群，后群也叫**小腿三头肌**。它通过**跟腱**到跟骨结节。跟腱就是这根。

后群是从后方走，在内踝的后方到足底去的。所以作用是：使足**跖屈**、**内翻**、**屈趾**。

> **易错点**：后群肌还有一个容易漏掉的作用——**屈膝**。为什么？因为后群肌上方的起点，一般都在股骨上，跨过了膝关节的后方。

这一条考试爱问，记住起点位置就不会丢分。

#### 外侧群：外翻的脚

外侧群的作用看这个动作：它是**跖屈**——你看足背，能做跖屈；而且是**外翻**，脚心向外。

三群讲完了。下面这些深层肌的名字大家有个印象就可以了，不用背。

### 这部分怎么记才不乱

整块内容最后收个口：下肢肌是重点记**比较大的肌肉的起止和功能**；小的肌肉，记住位置和名称就可以。

这个标准不是随便定的，它就是考试和临床上用得上的程度。大的肌肉——髂腰肌、阔筋膜张肌、三块臀肌、缝匠肌、股四头肌、股二头肌、半腱肌、半膜肌、四块内收肌、小腿三头肌——它们的起止点和功能，哪一条都可能直接出题。而梨状肌、上下孖肌、闭孔内肌、股方肌这类深层小肌，考试只需要你在图上指得出位置、说得出名字。

真要记不住的时候，还有一个特别省力的办法：**从止点反推作用**。抵止在后面的让它外旋，止于小转子的让它屈髋，跨过膝关节后方的还捎带屈膝——把止点和所跨关节盯死，功能就自己长出来了。
