## 肝、胰、胆道与鼻喉：位置、形态与毗邻
> 对应块：BLK19 | 覆盖分集：P25-P26 | 块标题（分集名）：《25.肝脏和胰腺》

上节课我们把腹部的分区和十二指肠过了一遍，这节课把它们接上——肝和胰。

### 肝脏：一个很复杂的化工厂

一说到肝，脑子里容易先跳出"消化腺"这三个字：它分泌胆汁，胆汁进肠腔乳化脂肪。可肝脏不单单是分泌消化液，它有很复杂的功能，所以我们说肝脏是一个**很复杂的化工厂**。这一段解剖学，我们抓三件事：**位置、形态、投影**。形态讲得最多，投影是临床上真正每天都要用的，另外别忘了胰的**前后毗邻关系**。

从形态上说，肝脏是个楔形——右侧比较厚，左侧比较薄。它有上面、下面、前缘、后缘。上面和下面是两张完全不同的脸，对比极其鲜明：

| | 膈面（上面） | 脏面（下面） |
| --- | --- | --- |
| 相对的东西 | 膈肌 | 腹腔里的脏器 |
| 形态特点 | 圆凸 | 凹凸不平，有许多压迹 |
| 腹膜 | 大部分有，中部一小块裸露 | — |

这张表先摆在这儿，我们分开讲。

#### 位置：大部分在右上腹

腹部九分法上节课已经学过了——剑突、肋弓、腹股沟、髂前上棘这些骨性标志，把腹部分成左右对称的九个区。肝脏的位置从图上一眼就能看出来：

> **结论**：肝脏**大部分位于右季肋区和腹上区**，只有**一小部分在左季肋区**。

记住"大部分"和"小部分"这两个词就够了，问肝脏在哪儿，就答这个。

#### 膈面：靠两条韧带吊在膈肌下面

上面为什么叫膈面？因为它正对着膈肌。从腹部做一个矢状切面看得很清楚：前面是腹前壁，后面是腹后壁和椎骨，膈肌在中间，肝脏正好在膈肌的下方。

肝脏就是借着冠状韧带和镰状韧带，悬吊在膈肌下方的。这两条韧带的方向一定要分清：

- **冠状韧带**：左右走向；
- **镰状韧带**：前后走向。

```text
           冠状韧带（左右走向）
  ┌──────────────────────────────────────────┐
  │                   │                      │
  │                   │                      │
  │                   │      裸  区            │
  │                   │   （无腹膜覆盖）        │
  │                   │                      │
  │                   │     镰状韧带           │
  │                   │    （前后走向）         │
  │                   │                      │
  └───────────────────┴──────────────────────┘
```

看图：冠状韧带并不是前后一直汇合在一起的。它的前后两层走到某处汇合，走着走着又分开——所以从前方看不太出来，从上方看就一目了然。两层分开夹出来的那一片，腹膜覆盖不上，我们叫**裸区**，裸露的裸。前后层再往前走、往前汇合的那一条，就是镰状韧带。

> **提示**：所以冠状韧带和镰状韧带，不是一条韧带的两段，而是前后层在不同位置分开与汇合的结果。

还有一件事必须记住：**膈肌随着呼吸上下移位，肝脏吊在它下方，也就跟着上下移动，幅度大约两到三个厘米。**所以临床上医生触诊肝脏的时候，要让你吸气——一吸气膈顶往下，肝脏跟着下来，就可能在肋弓下方摸到它，从而触摸它的大小和软硬度。

#### 脏面：H 形沟和两个肝门

下面和腹腔脏器相对，所以叫脏面，特点是凹凸不平，有许多压迹——都是脏器压出来的。最醒目的标志是那条明显的**H 形沟**（近似于 H 型）。把肝脏向上提起来看它的下面，三条沟一目了然：

```text
                   前缘（锐薄，肝脏下界）
        胆囊窝                        肝圆韧带
          │                             │
 ══════════╪══════════════════════════════╪═════════
          │  右纵沟        左纵沟          │
          │                             │
        腔静脉沟                      静脉韧带
      （下腔静脉）                （静脉导管闭锁）
       第二肝门
     （三条肝静脉出肝）
                   后缘（钝圆）
```

左右两条纵沟都是前后两段，横沟把它们连起来，于是成了"日"字里的那道横杠：

| 沟 | 分段 | 内含结构 |
| --- | --- | --- |
| 右纵沟 | 前方 | **胆囊窝**，容纳胆囊 |
| 右纵沟 | 后方 | **腔静脉沟**，下腔静脉正好贴在里面；三条肝静脉在此注入下腔静脉 |
| 左纵沟 | 前方 | **肝圆韧带**，胚胎脐静脉闭锁的遗迹 |
| 左纵沟 | 后方 | **静脉韧带**，胚胎静脉导管闭锁的遗迹 |
| 横沟 | — | 又名**肝门**，即第一肝门，肝门三件由此出入 |

**右纵沟的两个凹窝，一看名字就知道装什么。**前面那个窝既然叫胆囊窝，里面当然是胆囊；后面那个腔静脉沟，我们把它破开一看，下腔静脉就贴在沟里。既然有三个孔，就是三条肝静脉在这个部位出来，然后直接注入下腔静脉。

**左纵沟里的两条韧带有来历，值得多记一句。**肝圆韧带是胚胎时期的**脐静脉**闭锁以后形成的，静脉韧带是胚胎时期的**静脉导管**闭锁形成的。当时的循环是这样的：母体的血液通过脐静脉进来，一部分先进肝，然后通过静脉导管直接汇入下腔静脉，由下腔静脉向上奔心脏去参加循环。这两条管道，孩子生下来以后就逐渐闭锁了，一个留下肝圆韧带，一个留下静脉韧带。

**横沟就是肝门**，叫门，就有东西出入。这里最重要的有三件，我们统称**肝门三件**：

1. 胆管，也就是肝总管——运送胆汁；
2. 肝固有动脉——营养肝脏的动脉；
3. 肝门静脉——重要的静脉系，后面还会专门介绍。

这三条管道走到横沟这一块，每一条都分出**左右两支**，分别进入肝右叶和肝左叶，所以"肝门三件"里每一件都有自己的左右支。除此之外，还有神经和淋巴在这个部位出入——这才叫"门"。

> **易错点**：还有**第二肝门**。别和第一肝门搞混。腔静脉沟那一块也有三个孔，是三条肝静脉出肝的部位，习惯上管它叫**第二肝门**。三条肝静脉出肝，记住这一条就够了。

至于前缘和后缘：前缘是上面和下面在前方交界处的那一条，因为位置很低，所以我们管它叫**下界**，它比较锐薄；后缘比较钝圆，这个没有什么太大的意义了。

#### 投影：摸到肝不等于肝大

第三个问题，肝脏的投影——也就是怎么在体表判断这个肝是大是小。我们定三条线：右锁骨中线、正中线、左锁骨中线，然后看上下界。

| 线的位置 | 上界 | 下界 |
| --- | --- | --- |
| 右锁骨中线 | 第 5 肋 | 全部在右肋弓内——正常人肋弓下摸不到肝 |
| 正中线 | 胸骨体与剑突结合部 | —— |
| 左锁骨中线 | 第 5 肋间 | —— |

剑突下方呢，能摸到肝脏大约**三个厘米**。左侧没有什么意义。所以投影这一块，你要记的就是"上界 + 下界"两个含义、三条线。

**接下来是个容易翻车的地方，我们来看一道题。**一个患者，你发现肋弓下摸到肝脏一个厘米，剑突下摸到肝脏四个厘米——这个人肝大还是小？

不一定。光给你下界了，没给你上界啊。假如这个人是个**肺气肿**呢？长期处于吸气状态，膈肌就往下来，肝脏跟着下来是正常的，肝脏本身一点毛病没有。所以**必须上下界同时考虑**。

那上界怎么考虑？看脏器之间有没有重叠关系。胸腔里的肺，我们知道膈肌是向上鼓起的；肝脏的顶部同样是向上鼓起的。肺是个凹面，肝顶是个凸面，那它们之间肯定有重叠。肺里边都是空气，叩诊是**清音**；那么相重叠的这个区域，叩诊时就变成**浊音**、再往里是**实音**了。靠音的变化，我们就能通过叩诊找出肝脏的上界。

> **结论**：只有上界在正常位置，同时下边肋弓下可以触到，这时候才能说肝脏大。

### 胰：一副面孔管血糖，一副管消化

胰也是一个比较大的消化腺，但从组成上它不单单属于消化腺，它包括**内分泌部**和**外分泌部**两部分。

- **内分泌部**主要是胰岛细胞，分泌胰岛素，调节血糖浓度；
- **外分泌部**是腺细胞，分泌胰液，来参与消化。

我们讲的外分泌部。

#### 位置、分部与体表投影

从图上看，胰位于**腹上区和左季肋区**。从椎体上说，它横跨第 1、2 腰椎的前方，主要的部位在**第 1 腰椎水平**；胰头在第 2 腰椎水平，向左延伸到第 3 腰椎水平。

外形上分三部分：**头、体、尾**。回忆一下上节课的十二指肠——球部、降部、水平部、升部——胰正好被它环绕，被十二指肠环绕的正是**胰头**，后面是胰体，末端叫胰尾。

投影指的是**胰体部**的投影：胰体的上缘距离脐大约 10 个厘米，下缘距离脐 5 个厘米。所以记住两句话就行：胰体的上界是脐上 10 厘米处，下界是脐上 5 厘米处。

#### 前后毗邻：这一节要重点记

我们从椎体往腹后壁看：正中有腹主动脉，它的外侧有个比较大的静脉叫下腔静脉，而腹主动脉的前方还有一个比较大的静脉，叫肝门静脉。记住这三个，它们是判断胰前后关系的坐标。

然后我们做一个腹部的水平断面：

```text
                          前  方
     ┌──────────────────────────────────────────┐
     │                   胃                      │
     └──────────────────────────────────────────┘
  十二指肠降部    胰头 ── 胰体 ── 胰尾        脾
     ┌──────────────────────────────────────────┐
     │              肝门静脉                    │
     └──────────────────────────────────────────┘
              胆总管（走在胰腺实质里）
     ┌──────────────────────────────────────────┐
     │  腹主动脉     下腔静脉    左肾、左肾上腺  │
     └──────────────────────────────────────────┘
                          后  方
```

读图，从前往后一件一件数：

- **前方是胃**，具体说是**胃的后壁**，胰和胃后壁相邻；
- **右側是十二指肠**，准确说是**降部**——从水平面一刀断下去，胰头右侧当然是十二指肠的降部；
- **左侧是脾**；
- **后方结构就多了**，这是重点：肝门静脉（在胰腺实质里断到的那个管道）、胆总管、腹主动脉、下腔静脉，左侧还有**左肾和左肾上腺**。

顺便解释两个"为什么"：为什么两个肾画得一个大一个小？因为两个肾不在同一个水平面上，这一刀切下去，肾也不是在它最粗的地方。再向一侧，我们看到的那个管道是十二指肠，为什么这儿有？因为从胰头的右侧断开，正好是十二指肠的降部。

> **结论**：胰的毗邻关系要背下来——**前方胃后壁；后方左肾、肾上腺、腹主动脉、下腔静脉、肝门静脉、胆总管；右侧十二指肠降部；左侧脾。**

### 肝外输胆管道

肝和胰讲完，这节课再给大家继续讲一下肝外输胆管道。胆囊和输胆管道，一块儿说了。

#### 胆囊：梨形的袋子，底朝前

胆囊的位置我们刚才已经埋好伏笔了——肝下面的 H 形沟里，**右纵沟前方的胆囊窝**，胆囊就在里头。注意方向：胆囊窝是**前后走向**的，所以胆囊也是前后走向的一个器官。

形态上把胆囊看成是个**梨形**，放大以后分为四部分：**胆囊底、中间的胆囊体、胆囊颈、胆囊管**。

第三，胆囊底的体表投影。体表能摸到的，只能摸到胆囊的**底部**。把肝脏放下来，正好对着腹前壁，我们复习一下腹部的骨性标志：腹部正中线，这是脐；正中线两侧排列的肌肉是**腹直肌**。

> **结论**：胆囊底的体表投影在**右侧腹直肌外缘和右肋弓的交角处**。

临床怎么检查患者有没有胆囊压痛？医生把手放在这个位置上，拇指压在这一点上，然后**让患者吸气**。你想想，一吸气膈肌就往下走，胆囊是不是随着也降下来？正好触到医生的拇指。触到拇指以后，如果胆囊有炎症，患者就不敢吸气了，这口气马上憋住——这时候就是胆囊有压痛。

#### 从肝门到十二指肠大乳头

输胆管道包括哪些？看图，从肝门出来的**左右肝管**汇合，形成一个管道叫**肝总管**；肝总管和**胆囊管**汇合，形成**胆总管**。胆总管继续往下走，就钻到胰腺实质里边去了，和另一个管道汇合，这个叫**胰管**。汇合以后形成了一个膨大的腔，叫**肝胰壶腹**，然后开口于**十二指肠的大乳头**。

```text
        肝右叶                 肝左叶
          │                   │
         右肝管             左肝管
          └──────────┬──────────┘
                   肝总管
                     │
       胆囊 ─── 胆囊管
                     │
                   胆总管
                     │
                     ↓  （穿过胰头实质）
                   胰管
                     │
                 肝胰壶腹
                     │
               十二指肠大乳头
                     ↓
       胆汁 + 胰液进入十二指肠腔
```

所以，胆汁和胰液是通过大乳头进入肠腔的。**输胆管道的组成，从左右肝管、肝总管、胆总管，一直到胰管，汇合以后形成肝胰壶腹，开口于大乳头。**

这里请务必留意一条：**胆总管是穿过胰腺实质的**，然后才与胰管汇合。汇合以后形成肝胰壶腹，开口于十二指肠大乳头。

另外补一句：讲十二指肠降部的时候，我们讲过两个乳头。上边还有一个**小乳头**，它是**副胰管**的开口，里面出来的只有胰液，**没有胆汁**。

#### 胰头癌为什么把人憋黄

现在我们可以把前面的知识串起来了。各位请看——这些管道都在**胰头的实质里面**。那么如果这个患者得的是胰头癌，这些管道受不受压？受压。一受压以后，胆汁的排泄就受阻了，胆汁进不到肠管，这个患者的粪便就是**灰白便**；如果胆汁逆流回肝，最后入血，就会引起全身的黄染，也就叫**黄疸**。

所以这些管道走在实质内这件事，大家知道一下就行。

### 呼吸系统的组成与上下呼吸道

接下来我们把呼吸系统的开个头讲了。呼吸系统由两部分构成：

| 组成 | 干什么 |
| --- | --- |
| 呼吸管道 | 气体通过 |
| 肺 | 气体交换 |

第二个概念要搞清**上下呼吸道**。所谓**上呼吸道**，就是**喉以上**的呼吸管道；**下呼吸道**呢，就是**气管以下**的呼吸管道。就这么区分。

这一段我们介绍两个：一个是**鼻**，另一个是**喉**。

### 鼻：从鼻根一路看到鼻中隔

#### 外鼻与鼻腔

鼻大家了解两块：一个是**外鼻**，第二个是**鼻腔**。

外鼻主要是了解各个部位都叫什么。我们挑一个比较大的鼻子看：最上面那个部位叫**鼻根**，往下的隆起叫**鼻背**，最前面那个尖叫**鼻尖**，鼻尖两侧张开的两块叫**鼻翼**。这就是外鼻各部位的名称。

鼻腔要看什么？第一是鼻腔的分部。我们把鼻腔做一个矢状切面，图上能看到额骨、额窦、鼻骨、筛板、鸡冠、垂体窝、斜坡、蝶骨体、蝶窦，还有上唇；口腔和鼻腔的分界叫**腭**。鼻腔前方有一部分软骨。

那么鼻腔分为几部分？分两部分，以**鼻阈**为界：

- **鼻前庭**：就在鼻阈的前下方，里面有鼻毛。这是一部分很小的空间，"也就是指尖能插入的那个空间"；
- **固有鼻腔**：占绝大多数。骨性部分上节课讲过了，侧壁有三个鼻甲；向后以**鼻后口**和咽相通——这个就是鼻腔和咽的分界。

记住了：**以鼻阈为界，鼻腔分为鼻前庭和固有鼻腔两大部分。**

#### 鼻中隔与易出血区

鼻中隔我们再做一个断面。组成很好记：**上方是筛骨的垂直板，下方（骨性的这一块）是犁骨，前下方这一部分是软骨**。筛骨的垂直板、犁骨，加上前下方的软骨，组成了完整的鼻中隔。它把左右两个鼻腔分割开来。

接下来是鼻腔粘膜的一个特点。大家只记住**软骨区**就行：**软骨区有丰富的血管**，所以遇到外伤或者气候干燥，最容易出血——我们也把它叫做**易出血区**。

> **易错点**：不是整个鼻中隔都容易出血，是**前下方的软骨区**那一块。

#### 嗅区与呼吸区

整个鼻腔的粘膜，我们把它分成两个区。

看图：鼻腔的外侧壁有三个鼻甲，注意**上鼻甲的粘膜**，以及它相对的那一部分**鼻中隔的粘膜**——这一块叫**嗅区**。为什么叫嗅区？因为这块粘膜的深面有大量的**嗅细胞**，传导嗅觉。

其他的大部分区域，都叫**呼吸区**。

> **结论**：鼻粘膜就分这么两个区——**嗅区**和**呼吸区**。

#### 鼻旁窦的体表投影

鼻甲和鼻道、鼻旁窦这两块，在颅骨那会儿我们都做过了介绍，这儿就不展开了。但它的**体表投影**还有印象吧？从投影上看：额窦在**眉弓内侧**，筛窦在**眶内侧壁**，上颌窦在**上颌骨的深面**。

### 喉：既是发音器官，也是呼吸管道

#### 位置和毗邻

喉有**双重功能**：既是一个发音器官，又是呼吸管道。所以我们先讨论它的位置和毗邻。

咽我们已经学过了，把口腔下部放大：下唇、颏、颈、喉结；断到的是下颌骨前方的断面，上方有牙齿，后方是舌，舌盲孔、会厌软骨，这个才是喉，喉的后方是咽。

看椎骨：喉的**上端**是会厌软骨的上缘，相当于**第 3 颈椎**；它的下端在第 3、4、5、6 颈椎之间。所以：

> **结论**：喉的位置在**第 3～第 6 颈椎之间**。

毗邻关系，咽已经学过了，我们把话捋一遍：

```text
                    上方：咽（喉咽部）
                            │
            ┌────────────────┴────────────────┐
            │      舌骨下肌群（前方）           │
            ├─────────────────────────────────┤
            │                喉               │  两侧：舌骨（体、大角、小角）
            │                                 │   → 甲状舌骨膜 → 甲状软骨
            │                                 │   → 环甲膜 → 环状软骨
            │                                 │   → 甲状腺（峡部、侧叶）
            │                                 │   → 其后方：大血管、神经
            ├─────────────────────────────────┤
            │              气管                │
            └─────────────────────────────────┘
                    后方：咽（喉咽部）
```

读图：**上方通咽**，也就是喉咽部；**向下通气管**；**前方**是舌骨下肌群，它们正好在喉的前面；**后方**也是咽的喉咽部。两侧看图：舌骨有大角、小角、舌骨体，往下是一层膜状结构叫**甲状舌骨膜**，然后是**甲状软骨**；甲状软骨下方是**环甲膜**，再往下是**环状软骨**，再往下就是气管。气管上有一个重要的腺体叫**甲状腺**，它有峡部，向上两侧是甲状腺的侧叶；甲状腺的后方还有颈部的大血管和神经。

#### 四块软骨，和那一个唯一的环

喉由四大部分组成：**软骨、韧带、肌肉、关节**。我们先讲软骨。

挂图上一共四块：

1. 上方像树叶状的，叫**会厌软骨**；
2. 第二个叫**甲状软骨**。它从前方看是愈合的，叫**前角**，然后有**两个侧块**，构成侧板；但是它的**后壁是敞开的**。你从后边看，前方愈合、后方敞开，像两个铠甲一样，所以叫甲状软骨；
3. 甲状软骨下方有一对**杓状软骨**；
4. 最下面这个叫**环状软骨**。

> **结论**：这四块软骨里，**环状软骨是喉软骨里唯一呈环状的，也是唯一的一个完整软骨环**，对呼吸道的支撑起到重要的作用。你怎么摁它，它都不塌陷。

大家看过口对口人工呼吸吧？医生抢救患者时做了这么两个动作，我们看着很奇怪：一个是**掐住患者的鼻子**，另一个手呢，**摁住了环状软骨**。这医生在干什么呢？掐鼻子好理解——你吹的气别从鼻子跑了。**为什么压环状软骨**？因为环状软骨是唯一的完整软骨环，向后一压，就把喉咽部给闭锁了，这样你吹进去的气体不能到食管，只能进入气管，**防止胃胀气**。

#### 环甲中韧带：这个位置能扎针

韧带很多，我给大家说两个。

一个是**甲状舌骨膜**；另一个是**环甲膜**，也叫**环甲中韧带**。这两个里面，最主要是记住环甲中韧带，因为**它有临床意义**。

什么临床意义？**急性喉阻塞**的患者马上要窒息，那么我们要采取一个临时措施：**用最粗的针头，在这里毫不留情地扎进去**，建立一个暂时的呼吸通道。

所以这个位置在活体上应该能熟练地摸到：**摸到喉结向下滑动的那个凹窝，就是环甲中韧带。**

> **提示**：环甲中韧带这块可以做穿刺。等一会儿讲到喉腔的声门下腔，我们再把这条线索接起来。

至于喉肌——名字我们就不要求了，都是一些很小的肌肉，**只记住它的总功能就够了：开闭声门，调节声带的紧张度。**

#### 喉口、声门裂与喉腔的三段

喉口怎么组成的？我们从上往下看这张挂图：这是舌，这是腭扁桃体，这是会厌软骨；这个叫**杓会厌襞**，这个叫**杓间切迹**，它们所围成的这个口，就叫**喉口**。

那么从上往下看，喉口里边有什么结构？**内侧这两个皱襞叫声襞，外侧这两个钝圆的襞叫前庭襞。**所以能看到这么几个襞。由此得出一个印象：**两侧声襞之间的裂隙是最窄的，这叫声门裂**；两个钝圆的前庭襞之间比较宽，叫**前庭裂**。既然能看到四个襞，那就说明最内侧的那一对是最窄的。

**喉口什么时候才能封闭？**换一个图，从后方向前看，会厌软骨形成的这个口就是喉口。各位看，这里块儿是一个**关节轴**。当我们吞咽的时候，喉是不是上提？喉一上提，舌头没地方动啊，舌头还在原位。那么它要一上提，我们就想一想：喉上提，就顶压了这个会厌软骨；舌在这儿不动，喉一上提，会厌软骨就往下来，正好把喉口封闭。所以你说笑的时候，吞咽就容易误入到呼吸道。

**把喉剖开看内部。**我们冠状着把它切开，每一侧壁果然有两个皱襞：上面那个方才说过的、钝圆的是**前庭襞**；下面比较锐薄的那个是**声襞**，发音主要靠它。从这个断面上看左右距离，这两条最近（声门裂），这两条最远（前庭裂），所以从上方四个襞都能看到。

**既然这两个裂搞清楚了，把整个喉腔分为几部分？**

1. **喉前庭**；
2. **喉中间腔**，它两侧的洼兜叫**喉室**，属于喉中间腔里的一个结构；
3. **声门下腔**。

```text
                会  厌
            ╭─────────────╮
            │     喉口      │  ← 杓会厌襞 + 杓间切迹围成
            ╰──────┬──────╯
                喉前庭
    ────────────────┼──────────────  前庭襞（外侧，钝圆）
    ════════════════╪══════════════  声襞（内侧，锐薄）
                  │  ← 两侧的凹陷：喉室
                喉中间腔
    ────────────────┼──────────────  环状软骨下缘
                  │
                声门下腔
                  │
                气  管
```

读图：从上往下，会厌软骨下面是喉口；喉口到前庭襞之间是喉前庭；两条声襞之间那条最窄的缝是声门裂，裂的两侧就是喉室，夹着它的是喉中间腔；过了环状软骨下缘，就是声门下腔，再往下是气管。

**最后把这条线索接起来，这一段是全场的落点。**声门下腔的粘膜特点是**比较疏松**，在炎症刺激下**最容易水肿**。一水肿以后，粘膜是不是变厚了？变厚以后，声门裂是不是更窄了？那么最终总有闭合的时候——一闭合，气体不能通过了，这就叫**急性喉阻塞**。

这时候我们就需要穿刺。**穿刺能刺到哪个间隙里去呢？**大家记住，从环甲中韧带这儿刺进来，正好是**声门下腔**，也就是整个呼吸道最狭窄部位的下方，在那里建立一个暂时的呼吸通道，这样才能挽救患者的生命；到了医院以后，再行气管切开。

到这里，这一块就讲完了。

## 腹膜：一层浆膜，管住整个腹腔盆腔
> 对应块：BLK25 | 覆盖分集：P34 | 块标题（分集名）：《35.腹膜》

内脏学到这儿，就剩最后一块——腹膜。前面胃、肝、肠、膀胱、子宫这些器官都讲过了，可它们在腔里到底怎么待着、靠什么挂住，今天这一层膜全给交代了。

这一讲的顺序是这样的：先把两个概念立清楚，然后看腹膜有哪些功能，再看它自己长出了哪些特殊结构，最后把腹膜腔的分区和间隙过一遍。走完这一遍，内脏学就算收口了。

### 先立两个概念：腹膜和腹膜腔

要搞清概念，今天搞两个：第一个，什么叫腹膜；第二个，什么是腹膜腔。

大家看一下挂图。我们看这个模式图——这是整个腹盆腔的**正中矢状面**。

从这个图上我们看一下，腹膜是什么呢？是覆盖在**腹腔脏器表面**以及**盆腔脏器表面**的这层膜，还有呢，覆盖在**腹壁内面**、**盆壁内面**的这样一个浆膜。

> **定义**：腹膜是覆盖在腹腔和盆腔脏器表面，以及腹腔与盆腔内面的一层浆膜。

这个概念很像胸膜，很好记，跟我们讲胸膜的时候几乎是一个模子。

注意它的两头：一边贴脏器，一边贴腔壁。那么既然有的在脏器表面、有的在盆壁的内面，所以它也分为**脏层**和**壁层**两部分。

第二个概念，腹膜腔。

> **定义**：腹膜腔指的是脏层、壁层两层腹膜所围成的、不规则的腔隙。

所以"腹膜"是那层膜本身，"腹膜腔"是两层膜之间夹出来的那道缝。这一层关系一旦搞清，后面就顺了。

```text
   ┌─────────────────────────────────────┐
   │        腹  壁  /  盆  壁  肌  层    │
   ├─────────────────────────────────────┤
   │  壁层腹膜（parietal layer）         │  ← 衬在腹壁、盆壁的内面
   │                                     │
   │       ┌─────────────────────┐       │
   │       │                     │       │
   │       │     腹  膜  腔      │       │  ← 脏层与壁层之间的不规则腔隙
   │       │ (peritoneal cavity) │       │
   │       │                     │       │
   │       └─────────────────────┘       │
   │                                     │
   │  脏层腹膜（visceral layer）         │  ← 覆盖在脏器表面
   ├─────────────────────────────────────┤
   │        腹 腔 / 盆  腔  脏  器       │
   └─────────────────────────────────────┘
```

读图：壁层衬在腔壁的内面，脏层贴在被覆盖的脏器表面，两者之间夹出来的那道不规则的腔，就是腹膜腔。

### 腹膜的五大功能

概念搞清了，第二个问题：腹膜有哪些功能呢？一共五个——吸收、分泌、支持和固定、防御、修复。我们一个一个解释。

#### 吸收：上腹部强，盆部很弱

吸收功能指的是什么呢？腹膜这层浆膜，它能够吸收腹盆腔里边的液体，或者是积液和积脓，都能吸收。

但不同位置差别极大：**上腹部吸收能力特别强，而下腹部吸收能力很弱很弱。**

我们把整个腹壁位置最低的部位找出来就明白了。膈肌下方有肝脏；再往下是盆腔。整个腹腔和盆腔里，膈肌下方和盆部这两个位置最低。吸收能力强的部位在上腹部，弱的部位就在盆部——位置最低的这头一端。

这在临床上立刻变成一条医嘱。如果积液、积脓在吸收能力强的那个部位积存，患者术后采取一个平卧位，很快就吸收入血了；或者就在肝周围形成脓肿。

所以——

> **结论**：腹部手术后的患者一定要采取**半卧位**。半卧位让积液和积脓积存在盆腔，而盆腔吸收能力弱，就可以减少中毒。

记住这三句话连着走：上腹部吸收能力强，盆部吸收能力弱，术后一定要用半卧位。

#### 分泌：一点点浆液，换一分润滑

什么叫分泌功能？这层浆膜能分泌**少量的浆液**。所以腹腔内这么多脏器相互运动的时候，它可以减少摩擦。

分泌的是什么？浆液。不是水，也不是黏液，就是浆液。

#### 支持和固定：靠的是系膜和韧带

支持和固定的功能指的是什么呢？腹膜形成了很多很多的**系膜**，还有**韧带**，这些结构对脏器都有支持和固定的作用。

#### 防御：大网膜里养着一支吞噬细胞大军

防御的功能指的是谁呢？指的是**大网膜**。大网膜里边含有大量的**吞噬细胞**，能够吞噬细菌，所以对机体有防御能力。

一看到大网膜就记住这一条——它既是腹膜的防御功能所在，又是后面要讲的腹膜囊的邻居，还是外科最常用的"填塞止血"材料。

#### 修复：纤维素能把口子自己粘上

修复的功能指的是什么？腹膜这个光滑的腹膜一旦被破坏，它能够渗出一种**纤维素**。这种纤维素有很强的粘连能力。

我们看腹部手术。做一个小的肠断端吻合，肠壁的各层都要缝好，**最后还要把肠壁表面的这层浆膜缝好**。那么这层浆膜很快就粘连到一起，防止肠内容外漏——所以对机体是有利的。

但如果你手术缝合得不细，大家看，漏掉了两针，这一部分的浆膜没有缝合好，那么这个断端释放的纤维素，就会让临近的健康肠管怎么样？粘连。所以容易形成**肠梗阻**。

所以修复功能就是：它能够很快就粘连到一起。这是把双刃剑——缝得好，它帮你把口封死；缝得不好，它就替你制造一个肠梗阻。

### 网膜：胃大垂下来的那件围裙

第三个问题，腹膜形成哪些特殊的结构。第一个要给大家介绍的是**网膜**，包括**大网膜**和**小网膜**两部分。

我们把腹壁打开以后看腹腔的脏器。注意，挂图上肝脏的位置**不是解剖位置**，是被拉上去了。

看肝脏的下面和胆囊，这跟胃之间的膜绷紧了，这个叫**小网膜**，也就是肝脏与十二指肠、和胃小弯之间的膜。再看胃大弯向下垂掉的、像个围裙状的这个结构，这个叫**大网膜**。

所以网膜就分两个：一个是大网膜，一个是小网膜。

#### 小网膜：肝胃韧带加肝十二指肠韧带

小网膜在哪儿？我们看，从肝到胃小弯这一段是**双层**腹膜皱襞；从肝还到十二指肠上部，还有一部分。所以我们把它分为两部分，这部分叫**肝胃韧带**，这一部分叫**肝十二指肠韧带**，两个韧带加在一起叫小网膜。

> **定义**：小网膜是肝与胃小弯、以及十二指肠上部之间的双层腹膜皱襞，由肝胃韧带和肝十二指肠韧带构成。

它俩的厚度完全不一样，这个特点一定要记：**肝胃韧带很薄**，这两层很薄很薄，呈半透明状；**而肝十二指肠韧带很厚**。

为什么厚呢？我们讲肝脏的时候，不是给大家提了**肝门三件**吗？肝门三件就在这个韧带里边——也就是肝十二指肠韧带所包裹的这三件。所以摸起来，这块厚、那块薄。

> **提示**：所以下次摸标本，薄的那一片一定是肝胃韧带，厚的那一片一定是肝十二指肠韧带。薄厚不是韧带自己长的，是里面有没有东西。

#### 大网膜：位置、层次，还有那两层的另一个名字

大网膜的位置在**胃大弯与横结肠之间**，它是一个**多层的腹膜皱襞**。

我们从一个断面图上看：这是肝脏，从侧边看的，也就是腹腔的矢状切面。肝脏下方是胃，胃的下方是横结肠；腹后壁这儿有十二指肠水平部，还有胰。

看腹膜是怎么覆盖的：它在膈肌下边形成了**冠状韧带**，包绕肝脏；再往下到胃，又包绕了胃。注意，这是**胃大弯**，从胃大弯向下悬吊的这个多层腹膜皱襞，叫大网膜；然后包绕了横结肠；腹膜继续向后去，这是**横结肠系膜**；到腹后壁，又到了膈肌，围成的这个区域叫**肝脏的裸区**——**没有腹膜覆盖**。

所以我们说，胃大弯与横结肠之间的多层腹膜皱襞叫大网膜。

但这里边有一个要单独记：胃大弯和横结肠上缘之间的这个腹膜皱襞是**两层**，而它下方的这个部位是**四层**。所以这两层还有个名词，叫**胃结肠韧带**。

> **定义**：胃结肠韧带，指的是胃大弯和横结肠上缘之间那部分大网膜，也叫胃横结肠韧带。

**这个要记住。** 一张腹膜上就出了两个韧带名——肝胃、肝十二指肠归小网膜；胃结肠是大网膜顶上的那两层。

### 网膜囊与网膜孔：一间小屋，一个门

接着看网膜囊与网膜孔。这一对是今天最"有手术味"的结构。

#### 网膜囊在小网膜和胃的后方、胰的前方

先看位置。大家看，我点点的这个**潜在的间隙**叫网膜囊。它上方有一个孔，借这个孔和**大腹膜腔**是相通的。

所以它的位置应该是在**小网膜、胃的后方，胰的前方**——也就是在小网膜和胃与胰之间的这个腹膜间间隙、腹膜的间隙。

我们从另一个图上再看一下：把腹部做一个**水平断**。这是腹后方侧壁，中间突入进来的这是脊柱。脊柱的前方有一些血管，腹主动脉、下腔静脉；在它这个凹窝里边应该是左侧的肾脏。左侧肾脏这一侧，在左季肋区应该有个脾；这儿应该有一个膨大的腔，就是胃。我们是在这儿断开的，这侧和它相邻的就是脾脏。

这一断能断到哪些结构呢？脾断到了，胃断到了，小网膜在这儿也能断到。注意，**一个薄的、一个厚的**，厚的里边有肝门三件。然后它包绕胃——大家看，又反折到脾，这儿又反折到肾，脾也被包绕。那么到肾了以后，到腹后壁，我们看到的这个点点的腔隙，就是**网膜囊**。

#### 网膜孔在肝十二指肠韧带游离缘的后方

那么这个部位就是**网膜孔**。孔的位置在这儿，也就是在这个韧带的后方——这个韧带叫肝十二指肠韧带。所以：

> **定义**：网膜孔位于肝十二指肠韧带**右侧游离缘的后方**。

```text
          肝（下缘）
          │
   ═══════╪═════════════════════════════════   ← 网膜孔（肝十二指肠韧带右侧游离缘的后方）
          ║                                ║
          ║        网  膜  囊               ║   ← 潜在腹膜间隙
          ║（小网膜与胃的后方，胰的前方）  ║
          ║                                ║
   ───────╨════════════════════════════════╨
          胃                               胰
          │                                │
          └──────────── 大 腹 膜 腔 ────┘  ← 经网膜孔与大腹膜腔相通
```

读图：网膜囊是这层膜"兜"出来的一间小屋，上方只留了一个小孔（网膜孔）通向外面的大腹膜腔。门小、屋子大，是它最重要的解剖性格。

#### 这两个位置怎么用在临床上

先说网膜囊。这个腔隙比较大，而**口在上**。比如胃后壁穿孔了，手术术后一定要认真地清洗网膜囊——如果这里边有积液和积脓，大家看容不容易出来？**不容易**。所以很容易在里面陷聚，形成局限性的积液、积脓。

再说网膜孔。这里边就有肝门三件，大家知道肝门三件里边就有**肝固有动脉**。所以肝脏如果破裂了，这个患者造成大出血，我们把腹腔打开以后，是不是得先止血啊？应急的止血方法就是——**把食指伸到网膜孔里边，然后用拇指压迫肝固有动脉**，达到暂时止血的目的。

> **结论**：网膜孔这个位置本身是"手术入口"。你把它记牢，它就不只是一个名词，而是一手应急止血的功夫——手指从孔里进去，正好顶住肝十二指肠韧带里那条肝固有动脉。

### 系膜与韧带：两张熟悉的老面孔

这两个结构我们以前都讲过，我带大家复习一下。

**系膜**——小肠有没有系膜啊？小肠系膜、阑尾系膜、横结肠系膜、乙状结肠系膜，这些都是腹膜形成的结构。

**韧带**——也讲过很多很多。肝脏有冠状韧带、镰状韧带；刚讲过的肝胃韧带、肝十二指肠韧带；还有脾胃韧带、膈脾韧带、脾结肠韧带、脾肾韧带。

看图：这是脾脏。脾脏和肾脏之间有没有韧带啊？这叫**脾肾韧带**；这叫**脾胃韧带**。另外它和膈肌、结肠也都有韧带。很多很多。

一个小提醒：韧带的命名基本是"两个附着点 + 韧带"五个字。看不懂的时候，就把名字拆开念一遍——脾和肾之间是脾肾韧带，胃和脾之间是脾胃韧带，位置立刻就清楚了。

### 陷凹：腹膜转身时留下的凹窝

第四个结构，陷凹。这个我过去没有讲过。

陷凹是怎么形成的呢？**腹膜由一个脏器移行到另一个脏器，所形成的凹陷，我们叫陷凹**。

所以它不是长出来的一个囊，而是腹膜在换宿主时"折一下"留下的窝。男性和女性不一样。

#### 男性只有一个陷凹

男性有一个膀胱。回忆一下男性盆腔：前方有膀胱，下边有前列腺，然后尿道，后方是直肠和肛管。

腹膜怎么覆盖呢？腹前壁的腹膜覆盖在膀胱表面，然后**反折到直肠**，所以形成的这个凹陷叫**膀胱直肠陷凹**。

#### 女性有两个陷凹

女性前方是膀胱，然后是短而直的尿道，尿道后方是阴道，阴道再向后是直肠和肛管。中间多了个子宫。

腹膜怎么覆盖？还是从膀胱的一部分，反折到**子宫的前壁**，再到**子宫的后壁**，再反折到直肠。所以女性形成了两个陷凹：一个是**膀胱子宫陷凹**，还有一个是**子宫直肠陷凹**。

```text
   男 性                             女 性
  ┌──────────────┐                   ┌────────────────────┐
  │              │                   │                    │
  │      膀胱    │                   │       膀胱         │
  │       ↓      │                   │        ↓           │
  │  膀胱直肠陷凹│                   │   膀胱子宫陷凹     │
  │       ↓      │                   │        ↓           │
  │    直肠肛管  │                   │       子宫         │
  │       ↓      │                   │        ↓           │
  │              │                   │                    │
  └──────────────┘                   │   子宫直肠陷凹     │
                                     │   = Douglas 腔     │
                                     │        ↓           │
                                     │     直肠肛管       │
                                     └────────────────────┘
```

读图：腹膜在女性盆腔要连着翻两个身——膀胱翻到子宫前壁是一折，子宫后壁翻到直肠又是一折，所以两个陷凹；男性只有膀胱翻到直肠这一折，所以只有一个。折得越多，窝越深。

#### 位置最低的那个最有临床价值

大家看哪个陷凹位置最低呀？**子宫直肠陷凹**。它和**阴道的后穹窿**仅隔一个阴道壁和腹膜，所以它有临床意义。

> **结论**：临床所说的 **Douglas 腔**，指的就是子宫直肠陷凹。

有什么临床意义呢？如果这个患者术后盆腔聚集了很多积液和积脓，我们可以在这儿抽出去。

怎么抽啊？大家看，先把阴道给它扩张——这是膀胱，这是尿道，把阴道给它扩开，用**阴道扩张器**扩开；后方是直肠和肛管，这儿是子宫。我们把这两个陷凹画起来：这儿还有一个位置比较低的陷凹，这里面完全是积液和积脓，我们可以通过**穿刺**的方法，把积液和积脓抽出来。

所以陷凹大家重点记住一条：女性的 Douglas 腔也叫子宫直肠陷凹，位置最低，能穿刺。

### 腹膜腔的分区：横结肠为界

最后一块，腹膜腔的**分区**及**间隙**。我们从一张图上看过去。

图上：肝脏，下边是胃、脾，上方应该是膈肌；下边由横结肠、降结肠，这侧是升结肠、阑尾、盲肠；这个代表小肠，到这儿是空肠曲，这是十二指肠；那么继续向下，是乙状结肠、直肠和肛管。这一部分相当于盆腔。

图上的韧带也标出来了：肝的上表面有一个**镰状韧带**，两侧和膈肌之间相连的是**冠状韧带**，然后还有一个**肝圆韧带**到脐。**以到脐的这条斜线，作为左右的分区。**

再看其余的：肝与胃之间这是小网膜；胃大弯与横结肠之间还有胃结肠韧带；脾胃之间有脾胃韧带；膈和脾之间有膈脾韧带；脾和横结肠之间有脾结肠韧带；横结肠和膈肌之间有膈结肠韧带。很多啊，很多。

那腹部到底是怎么分区呢？**我们把横结肠作为分界**：横结肠以上叫**结肠上区**，横结肠以下叫**结肠下区**。两个区。

> **结论**：腹膜腔只分两区，分界线是横结肠。

分区简单，难的是分区里的间隙。跟着我往下看。

### 腹膜腔里的间隙和窦

区已经知道了，两个区。接下来看**间隙**。这部分是考试爱出判断题的地方，我按挂图带大家过一遍。

#### 肝上间隙：镰状韧带分左右

肝脏与膈肌之间存在间隙是吧？这个我们习惯叫**肝上间隙**。

大家注意，肝上间隙**以镰状韧带分为左右**，这侧叫**右肝上间隙**，这个叫**左肝上间隙**。

#### 肝下间隙：小网膜分前后

然后往下，肝脏与腹腔之间的间隙叫**肝下间隙**，也分为左右：右侧叫右肝下间隙；左侧因为有**小网膜**的分隔，也分为前、后两个——**左肝下前间隙**和**左肝下后间隙**。

> **易错点**：这两组"分前后"千万别记反，也别以为四个都分。**以冠状韧带为界**分出前、后两部的是**右肝上间隙**（肝上前间隙、肝上后间隙）；**以小网膜为界**分出前、后两部的是**左肝下间隙**。**右肝下间隙**和**左肝上间隙**都是单腔，不再分前后。

#### 结肠旁沟：左右各一条

间隙大家知道有两个。另外呢，还有两个**结肠旁沟**。

**结肠旁沟是下区的结构**——这点也要记，因为这决定了液体往哪儿跑。这侧叫**右结肠旁沟**，左边叫**左结肠旁沟**，两个。

#### 肠系膜窦：右死左通

还有两个**肠系膜窦**。

注意，这**是一个窦**：小肠围成的一个三角形腔隙，这个叫**右肠系膜窦**；这一个直接和盆腔相通，叫**左肠系膜窦**。

一句话对比就是：右肠系膜窦是死腔，左肠系膜窦是通腔。

#### 最后串一遍：液体到底往哪儿流

讲这些间隙、一些窦腔，主要是为了便于大家理解——**哪些部位的引流最畅通**。我们用一条线画一下。

```text
┌─ 右侧：通畅 ───────────────────────────────────────┐
│                                                    │
│    右肝上间隙（前 · 后）                           │
│             │                                      │
│                                                    │
│    右肝下间隙                                      │
│             ↓                                      │
│       右结肠旁沟                                   │
│             │                                      │
│             ↓                                      │
│                                                    │
│          盆　腔  ← 上下畅通，积液最易下到盆腔      │
│                                                    │
└────────────────────────────────────────────────────┘

┌─ 左侧：不通 ───────────────────────────────────────┐
│  左肝上间隙        左肝下间隙（前 · 后）           │
│       ×                  ×                         │
│                                                    │
│  被系膜和韧带分隔，与左结肠旁沟不通                │
│                                                    │
│  左结肠旁沟（膈结肠韧带以下） ──► 盆　腔           │
│  左肠系膜窦（直接与盆腔相通） ──► 盆　腔           │
│                                                    │
│  右肠系膜窦  ✗  死腔（四周全是回肠）               │
└────────────────────────────────────────────────────┘
```

读图：右侧的肝上、肝下间隙都能顺着右结肠旁沟一路下到盆腔，上下畅通，所以右侧腹腔的积液最容易被"送"到盆腔；左侧被小网膜、系膜和各条韧带切成了互不相通的几块，清不干净就会原地积住；而两个肠系膜窦里，右肠系膜窦四面被回肠围死，是个死腔。

把线头一段段说完：

- 右肝上前间隙和后方的右肝上间隙，**通过结肠旁沟直接就可以流到盆腔**，这是上下畅通的；
- 而右侧的肝下间隙呢，**也可以通过这条路直接到盆腔**。所以这个部位手术，积液、积脓最容易流到盆腔里边；
- 可是左侧注意，**由于有这些系膜和韧带的分隔，左侧和左结肠旁沟是不通的**，所以这一部分手术一定要彻底地清洗；
- 两个肠系膜窦，右肠系膜窦**是一个死腔**，因为它的表面全是回肠的肠管，所以这里边要认真清洗；左肠系膜窦这部分就不用担心了，直接会流到盆腔；
- 左结肠旁沟，从这个韧带以下的部分，也会顺利地到达盆腔。

好，腹膜腔的分区和一些间隙，简单地给大家介绍到这儿。以后大家看书，能够便于大家理解。

这节课到这儿。
