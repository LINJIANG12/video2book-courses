## 静脉：血液怎么流回心脏
> 对应块：BLK31 | 覆盖分集：P40 | 块标题（分集名）：《41.脉管系统Ⅵ》

动脉把血从心室推出去，静脉再把血收回来。这一讲我们把这条回流的路完整走一遍——先从心脏底下的那几根大血管数起。

### 肺循环的静脉：两条肺静脉回收肺里的血

我们一起回忆一下心脏的解剖，看心脏底部的大血管：有一对血管叫肺静脉，即左、右肺静脉；上方是肺动脉，然后是主动脉；这一侧是上腔静脉、右心房、下腔静脉；心脏的膈面还有一根小小的静脉，叫奇静脉。

```text
                肺动脉干            主动脉
                   │                  │
           ┌───────┴──────┐           │
         右肺静脉       左肺静脉       │
           └───────┬──────┘           │
                   │                  │
                   └────→ 左心房 ←────┘
                         （动脉血）

      上腔静脉 ──→ 右心房        下腔静脉 ──→ 右心房
      奇静脉  ：位于心脏膈面，向上注入上腔静脉的后壁
```

从这个图上我们不难看出：肺动脉的血液经肺门进入肺，在肺里由动脉血换成静脉血，再由这两对肺静脉回收。哪一侧的静脉血从哪儿出来？右肺的静脉血由右肺上、下静脉汇出，左肺的由左肺上、下静脉汇出。它们把动脉血带回哪一个心腔？左房。

> **易错点**：肺循环里"动脉""静脉"是按血流方向命名的，不是按血液含氧量命名的。肺动脉从心室流向肺，里面装的是静脉血；肺静脉从肺流回心房，里面装的是动脉血。名字跟着方向走，血液成分跟着肺毛细血管走，这两件事不能混。

这个我们简单了解一下就行了。重点，讲体循环的静脉。

### 体循环的静脉分三套系统

从组成上来看，体循环的静脉有三部分：上腔静脉系、下腔静脉系、心静脉系。

心静脉系我们已经讲过了，就是心脏的静脉最后经冠状窦注入右房。所以在这里展开的就是这两个系。

### 上腔静脉系

#### 收纳范围、合成与属支

上腔静脉系要了解这么几个问题。

**第一，收纳范围。**上腔静脉系负责收集头颈、胸部和上肢的静脉血。

**第二，合成。**上腔静脉系由左、右头臂静脉汇合而成。头臂静脉又是颈内静脉和锁骨下静脉汇合以后形成的。

**第三，属支。**这里要先说清一个概念：动脉是由主干到分支，静脉由于血流方向相反，是先分支、再汇成主干，所以汇入主干的那些支都叫**属支**。上腔静脉的属支记住一个名字就行——奇静脉，它注入上腔静脉的后壁。

```text
      颈内静脉 ┐
               ├→ 头臂静脉 → 上腔静脉 → 右心房
   锁骨下静脉 ┘                    ↑
                              奇静脉注入后壁
```

大体了解了以后，我们具体讲头颈部的静脉。

#### 头颈部：颈内静脉与颈外静脉

先看解剖标志：颏、喉结、下颌角、耳廓。喉结是哪一个软骨形成的？甲状软骨。甲状软骨下方是环状软骨，环状软骨下边是气管。这块儿有一个膜叫环甲膜，急性喉阻塞的患者可以在这儿做穿刺。这块还有一个腺体——甲状腺。

头颈部的静脉有两个主干需要大家知道：一个是颈内静脉，还有一个叫颈外静脉。

**颈内静脉**在哪儿合成？在颅底的颈静脉孔。这个部位颅底有个岩下窦，还有一个乙状窦，这两个窦汇聚形成颈内静脉。它回收哪些组织？我们从下往上数：

```text
  乙状窦 ┐
         ├→ 颈内静脉（在颈血管鞘内，与颈内动脉伴行）
  岩下窦 ┘
         ↑
   下颌后静脉前支 ←─ 颞浅静脉 + 上颌静脉 = 下颌后静脉
   面静脉        ←─ 口角、鼻翼一侧
   舌静脉、咽静脉  ←─ 汇成短干
   甲状腺上静脉
   甲状腺中静脉
```

注意下颌后静脉：颞浅静脉和上颌静脉汇合形成下颌后静脉，下颌后静脉再分成前支和后支——**前支汇入颈内静脉，后支汇入颈外静脉**。这个分叉是这一节最该记牢的一处。

所以颈内静脉的属支是：下颌后静脉前支、面静脉、舌静脉、咽静脉、甲状腺上静脉，还有甲状腺中静脉。颈内静脉在颈血管鞘内，和动脉是伴行的。

**颈外静脉**跟它不一样。颈内静脉在颈血管鞘内和动脉伴行，可是颈外静脉属于浅静脉，走在胸锁乳突肌的前面。它由谁汇成？上方有一个耳后静脉，向后有个枕静脉，这两个会合形成颈外静脉，然后注入锁骨下静脉。它的属支也是三个：耳后静脉、枕静脉、下颌后静脉的后支。

**静脉角**。这里还要提一个名词：静脉角。颈内静脉和锁骨下静脉形成的这个交角，就叫静脉角。全身的淋巴液，最后都通过两个淋巴导管汇入左、右静脉角，进入静脉血。知道概念就行了。

#### 上肢：深静脉与三条浅静脉

上肢静脉分为两种：一种叫深静脉，一种叫浅静脉。

深静脉跟动脉一样，都和同名动脉伴行——有什么动脉就有什么静脉，这个我们就不展开了。重点放在浅静脉。

浅静脉大家记住这么几个：**头静脉**、**贵要静脉**、**肘正中静脉**，三支。

```text
  手背静脉网
      │
      ├── 桡侧起 → 头静脉
      │     前臂桡侧 → 臂外侧 → 三角肌与胸大肌之间穿深筋膜
      │     → 腋静脉 / 锁骨下静脉
      │
      └── 尺侧起 → 贵要静脉
            前臂尺侧 → 臂内侧 → 臂中点穿深筋膜 → 肱静脉
            （动脉叫肱动脉，静脉就该叫肱静脉）

       头静脉 ←── 肘正中静脉（吻合支） ──→ 贵要静脉
       另有一条前臂正中静脉，不用管它
```

三条都起自于手背静脉网。头静脉在桡侧起，沿前臂的桡侧上升，再沿臂的外侧上升，在三角肌和胸大肌之间穿入深筋膜，汇入里边的腋静脉或者锁骨下静脉。贵要静脉在手背静脉网的尺侧起，沿前臂的尺侧、臂的内侧上行，在臂的中点穿深筋膜汇入里边的深静脉——大家想一想，这个部位的深静脉应该叫什么呢？动脉是不是叫肱动脉？那静脉就应该叫肱静脉。肘正中静脉是头静脉和贵要静脉之间的吻合支。

所以大家记住这么三个。

#### 胸部：奇静脉这一套

看胸的后壁：中间是脊柱，脊柱两侧都有静脉。

方才我们已经说了，在脊柱的**右侧**上升、注入到上腔静脉后壁的那根静脉，属于上腔静脉的属支，叫奇静脉——它回收的只是右侧胸部的静脉血。

再看另一侧：这一根是通过吻合支汇入奇静脉的，所以叫**半奇静脉**；沿脊柱的左侧上行、汇入这根吻合支的还有一个小支，叫**副半奇静脉**。

所以胸部静脉血的回收，主要靠奇静脉、半奇静脉、副半奇静脉这三个。胸部的静脉靠谁回收呢？靠奇静脉、半奇静脉、副半奇静脉。名称大家知道就可以了。

### 下腔静脉系

#### 合成与位置

下腔静脉系首先是合成：由左、右髂总静脉在第4腰椎和第5腰椎之间汇集而成。髂总静脉再往下分成髂内静脉和髂外静脉——髂外静脉往盆腔去。

它的位置：上端在腔静脉裂孔，下端是第4、5腰椎之间，整个主干在脊柱的左前方。

#### 动脉与静脉的配部关系

把腹主动脉和下腔静脉放在一起看，动脉比静脉短——到第4腰椎动脉才开始分，分出左、右髂总动脉。动脉都有哪些分支，我们回忆一下；静脉在同一个高度发什么，对照着记：

| 高度（由上而下） | 动脉 | 静脉 |
| --- | --- | --- |
| 膈肌下 | 膈下动脉（向上的一支） | 膈下静脉（成对） |
| 稍下 | 腹腔干（1 cm 短干） | — |
| 肾上腺水平 | 肾上腺中动脉（左右发出） | 肝静脉（3 支，不成对） |
| 再下 | 肠系膜上动脉 | 肾上腺静脉 |
| 肾水平 | 肾动脉（左右成对） | 肾静脉、肠系膜下动脉对应段 |
| 睾丸水平 | 睾丸动脉（左右成对） | 睾丸静脉 |
| 最下 | 骶正中动脉 | 骶正中静脉、左右髂总静脉 |

这一对表里有一处不一样的地方要特别记住：**肾上腺**。动脉这边是肾上腺中动脉，左右各发一支；静脉这边就明显不对称了——肾上腺静脉是在肾静脉那个高度汇入的，所以左右不一样。这个"不一样"，等下讲脏支的时候正好接上。

这个大家知道一下。

#### 壁支

下腔静脉的属支也分壁支和脏支。壁支先提：

- **膈下静脉**，与膈下动脉上下对应；
- **腰升静脉**（又叫髂腰静脉），沿脊柱两侧上行，回收四个腰静脉；
- **骶正中静脉**，骶正中也是壁支。

#### 成对的脏支

到脏器去的，成对的有三个。

**肾上腺静脉**——左右不一样。右侧起自主干，直接汇入下腔静脉；左侧呢，汇入到肾静脉。

**肾静脉**——这也是成对的，这个我就不说什么了。

**睾丸静脉**（女性的叫卵巢静脉）——左右又不一样了。先看右侧：右侧的睾丸静脉和动脉是伴行的，直接汇入到下腔静脉的主干。再看左侧：左侧的睾丸静脉汇入到肾静脉，而且是呈直角汇入，然后再汇入下腔静脉。

> **结论**：所以为什么左侧的这个静脉曲张多于右侧？因为左侧的回流阻力比较大。这是个现成的推论——一边的路短、直达主干，另一边要多绕一道、还是直角入肾静脉，阻力当然不一样。

#### 不成对的脏支：肝静脉

不成对的脏支最高处这个，大家看看叫什么——肝静脉。3 支，汇入下腔静脉。

还记得我们讲肝脏腔静脉窝的时候提到过的**第二肝门**吗？第二肝门就是这三条肝静脉在腔静脉窝汇入下腔静脉。

除它以外，不成对的脏支还应该有一个，叫肝门静脉——挂图上没有，因为它本身重要，我们单独把它提出来，叫肝门静脉系。它可属于下腔静脉系。

### 肝门静脉系

#### 两个特点：无静脉瓣，两头都是毛细血管

肝门静脉系有什么特点？就两条。

**第一，起端和止端——终止的那一端——都是毛细血管。**大家设想一下，两侧都是毛细血管，这个静脉系的血流应该慢还是快？慢。

**第二，这个静脉内没有静脉瓣。**所以血液可不可以逆流？可以。

就这两条：一个"慢"，一个"没有阀门"。第二点马上就能用上，一会儿我们举血液逆流的例子，看临床上会出现哪些表现。

#### 合成与属支

肝门静脉系主要由肝门静脉组成。它的合成很好记：肠系膜上静脉和脾静脉汇聚，形成一个短干叫肝门静脉，然后分成右支、左支进入肝脏。

属支我们画个模式图：

```text
                    肝门静脉 → 右支 / 左支 → 肝
                   ╱          │
        肠系膜上静脉          │   胃左静脉 ─┐
              │               │   胃右静脉 ─┴─ 胃小弯侧吻合
              │               │   胃网膜左静脉┐
        肠系膜下静脉 ─── 脾静脉 ┴─ 胃网膜右静脉┴─ 吻合
                                   │
                                   └─ 附脐静脉 → 脐部
```

名字要记牢：肠系膜上静脉、肠系膜下静脉、脾静脉、胃左静脉、胃右静脉（这两个在胃小弯侧吻合）、胃网膜左静脉、胃网膜右静脉（从脾静脉发出，与胃网膜右静脉相吻合），以及汇到脐部的附脐静脉。

这些支都属于肝门静脉的属支，这个我们做一个了解就行了。

#### 门腔静脉的三条吻合途径

关键是第四个问题：**门腔静脉的吻合途径**。这个很重要，我们看有几条。

```text
  门静脉系（无静脉瓣，血液可以逆流）
        │
        ├─ 路1 胃左静脉 → 食管静脉丛 → 奇静脉 → 上腔静脉
        │      （最简单的一条）
        │
        ├─ 路2 脾静脉 / 肠系膜上静脉 → 肠系膜下静脉 → 直肠上静脉
        │      → 直肠静脉丛 → 直肠下静脉 → 髂内 → 髂总 → 下腔静脉
        │
        └─ 路3 附脐静脉 → 脐周静脉网
                 ├─ 上行：胸腹壁浅/深静脉、胸腹臂浅静脉
                 │        → 腋静脉 / 锁骨下静脉 → 头臂静脉 → 上腔静脉
                 └─ 下行：腹壁深静脉 → 髂外静脉
                          腹壁浅静脉 → 大隐静脉 → 股静脉
                          → 髂外 → 髂总 → 下腔静脉
```

**第一条路。**门脉的血液，由于它没有静脉瓣，可以进入胃左静脉；再进入食管静脉丛；然后通过奇静脉，是不是就进入上腔了？——门静脉血可以进入胃左静脉，就可以进入食管静脉丛，就可以通过奇静脉汇入到上腔静脉。这条道儿比较简单。

**第二条路。**门脉血液通过脾静脉，会不会进入肠系膜下静脉？然后通过直肠上静脉是不是到直肠了？在直肠周围也形成了一些静脉丛。盆腔里边还应该有直肠下静脉（再往下穿过腹股沟韧带还有肛门静脉，这个我就不表示了）。直肠下静脉是不是和髂内静脉相连？所以血液通过这个方向到直肠静脉丛，又通过这个方向到髂内、髂总、下腔。整理一下：门静脉血 → 肠系膜下静脉 → 直肠上静脉 → 直肠静脉丛 → 直肠下静脉 → 髂内静脉 → 髂总静脉 → 下腔静脉。

**第三条路**比较复杂。门脉的血液可以通过附脐静脉到脐周静脉网，脐周静脉网有一个上行路到上腔，还有个下行路到下腔。

上行路：通过胸腹壁的浅深静脉、胸腹臂的浅静脉或深静脉，汇入到腋静脉或者锁骨下静脉，然后经头臂静脉汇入到上腔。

下行路：腹壁的深静脉直接汇入到髂外静脉；浅静脉汇入到大隐静脉，再通过股静脉、髂外静脉、髂总静脉到下腔。

到这里我们重新捋一遍：门腔静脉通过三条路相吻合。第一条走胃左静脉、食管静脉丛、奇静脉到上腔；第二条走脾静脉、肠系膜上静脉、直肠上静脉到直肠静脉丛，再通过直肠下静脉回到髂内、髂总、下腔；第三条走附脐静脉到脐周静脉网，上行一路到上腔，下行一路到下腔。

#### 门脉高压把血推向哪里

那么，为什么要费劲了解门腔静脉的吻合途径？因为我们说了门静脉的特点——血液可以逆流。

以肝硬化为例：肝硬化以后，肝脏本身变硬变小，门脉血进肝阻力是不是增大？这时门脉血进肝就很困难，它就要通过它的吻合支去分流。血被挤到哪儿去，临床就出现什么表现。

**一、逆流到脾静脉，进到脾。**大家知道脾有丰富的血窦，所以脾的体积是不是就变大了？门脉高压的第一个症状——脾大。正常人脾脏在肋弓下是摸不到的，脾大了以后就可以摸到。另外注意三个脾切迹，那是判断脾的标志，这一定要记住。

**二、进入肠系膜上静脉，就进入了小肠静脉。**大量的血液涌入小肠，就会出现第二个表现：患者消瘦，而且也躺不下，肚子变大了。这就是我们说的**腹水**。

**三、大量涌入胃左静脉。**那就是食管静脉丛的血液也过多，从而使食管静脉丛曲张。曲张以后，如果我们吃东西的时候受到机械刺激，比如吃一些粗糙的食物，就划破了这个静脉丛，就会产生第三个症状：呕血和便血。

便血怎么来的？门脉血进入肠系膜下静脉，汇聚到直肠静脉丛；如果患者便秘、使劲排便，是不是直肠静脉丛也破裂了？于是产生便血。

**四、通过附脐静脉到脐周静脉网**，就会产生腹壁静脉曲张。你看这腹壁的静脉，像个海蛇头一样，所以临床叫**海蛇头**。

所以肝硬化晚期有可能出现这些症状。

> **注意**：不是说在一个患者身上，这几个症状都会出现。知道"血往哪儿挤、哪儿就出问题"这条因果链，比背症状列表有用得多。

最后再强调一遍：肝门静脉系，它属于下腔静脉系，只不过它比较重要，所以我们才把它单独拎出来讲。

> **承前启后**：上一节讲完「静脉：血液怎么流回心脏」，下一节接着讲「淋巴系：给静脉回流加一条辅助路」。

## 淋巴系：给静脉回流加一条辅助路
> 对应块：BLK32 | 覆盖分集：P41 | 块标题（分集名）：《42.脉管系统Ⅶ》

这一讲我们转到一个新系统——淋巴系。

先弄清楚它由什么构成：淋巴管道、淋巴组织、淋巴器官，三大部分。这三部分里，我们要重点搞懂的是淋巴液——它是怎么生成的，又是怎么回流的。这两件事其实是同一件事的两头，看明白一张模式图就都懂了。搞清楚之后，再往里走：淋巴管道分几级、淋巴导管长什么样、最后落在哪个器官上。

### 淋巴液的生成与回流

我们画一个模式图。把毛细血管的结构摆出来，一头是毛细血管的动脉端，一头是静脉端，中间这一段就是毛细血管。

```text
   心脏 ──各级动脉──► 毛细血管动脉端 ══ 毛细血管静脉端 ══ 各级静脉 ══► 心脏
                         │  渗出
                         ▼
                      组织液（组织间隙内）
                         │  组织细胞吸收营养，排出代谢产物
                         ▼
              ┌──────────┴───────────┐
              ▼                      ▼
        小分子代谢产物           大分子代谢产物
              │                      │  难以透过毛细血管壁
              │ 直接透过管壁          ▼
              │                 毛细淋巴管（末端盲端）
              │                      │  淋巴管 → 淋巴干 → 淋巴导管
              ▼                      ▼
      毛细血管静脉端 ◄─────────  静脉角 ──► 静脉 ──► 心脏
```

> 读图：心脏经各级动脉把血液送到毛细血管动脉端，血浆成分从毛细血管壁渗出到组织间隙里，变成组织液；组织细胞把营养成分吸进去，把代谢产物排进组织液。这条主线是静脉回流的常规通路。组织液里的代谢产物又分成两拨——小分子那一拨原路透过毛细血管壁回到静脉端，跟着各级静脉回到心脏；大分子那一拨过不去管壁，于是走进毛细淋巴管。

这里要留个印象：**毛细淋巴管是末端呈盲端的管道，深深嵌在毛细血管之间**。正因为它是盲端、位置又正好在毛细血管丛里，那些挤不过毛细血管壁的大分子物质，一挪就能挪进来。进了毛细淋巴管，这液体就叫淋巴液了。所以淋巴液的生成说白了就是一句话：大分子的代谢产物进入毛细淋巴管，就成了淋巴液。

回流呢？淋巴液顺着淋巴管道一路往上走，最后一定要汇入静脉，再回到心脏。注意最后那一步——不是直接回心脏，是先进静脉。这是理解淋巴系全部功能的钥匙。

> **结论**：淋巴液的生成 = 大分子物质进入毛细淋巴管；淋巴液的回流 = 淋巴管道 → 静脉 → 心脏。终归是汇入静脉。

### 淋巴系的功能

从上面这张图就不难看出：静脉血的回流不是单单靠静脉自己完成的，还要靠毛细淋巴管组成的淋巴系统把一部分东西带回来。所以淋巴系是**静脉血回流的一个辅助路**，它协助静脉血的回流。这是它第一个功能。

第二个是**免疫功能**——从功能上来看，就这两个。

### 淋巴管道的四级

接下来看淋巴管道。它分四级，我们一级一级往上追。

| 级别 | 名称 | 数量与特点 |
| --- | --- | --- |
| 一级 | 毛细淋巴管 | 末端呈盲端，嵌在毛细血管之间 |
| 二级 | 淋巴管 | 数量相当庞大 |
| 三级 | 淋巴干 | 全身 9 条 |
| 四级 | 淋巴导管 | 全身 2 条 |

```text
   毛细淋巴管  ──►  淋巴管  ──►  淋巴干  ──►  淋巴导管
     一级          二级         9 条         2 条
   末端盲端      数量庞大        汇聚         汇入静脉
    ①──②──③──④──⑤──⑥──⑦──⑧──⑨──╳
```

你看这个数量变化：一级毛细淋巴管到处都有，二级淋巴管数量已经相当庞大了（他在这里连说了两遍"相当庞大"），汇聚成三级淋巴干就只剩 9 条，四级淋巴导管全身就 2 条。**越聚越粗，数量由多变少**——道理跟静脉一样。这条数量递减的线索是这一段最该记住的东西。

所以下面重点讲第四级，淋巴导管。

### 胸导管

淋巴导管全身只有 2 条，先讲第一个——**左淋巴导管**。它还有个名字，叫**胸导管**。

要看懂胸导管在胸腔里的走法，先得把图上这几个老朋友认一遍——它们都是前面讲过的。

先看上腔静脉：颈内静脉和锁骨下静脉合成一头臂静脉，两侧的头臂静脉再汇集成一个主干，这个主干就是上腔静脉。跟着上腔静脉伴行的是主动脉。主动脉下方发出的是左主支气管，右边是右主支气管，再往上两个主支气管汇聚就是气管；气管后方还有一个管道，略微偏左，叫食管。主动脉本身画全了的话，是逐渐向正中线靠拢的。

上腔静脉在肺根后方有一个重要的属支，叫**奇静脉**；奇静脉在第 8 胸椎这个高度接了**半奇静脉**，旁边还有一条**副半奇静脉**。

再看膈肌。膈肌下方的两个角围成**食管裂孔**，另外还有**主动脉裂孔**和**腔静脉裂孔**。主动脉就是从主动脉裂孔穿出来的。

这几个结构的位置关系搞清楚了，胸导管的行径就好找了。

#### 起点：第 1 腰椎前方的乳糜池

胸导管的起始部位在哪儿？在第 1 腰椎水平有一块梭形的膨大，这东西有个名字，叫**乳糜池**。从乳糜池发出的这个管道，就是胸导管了。

#### 行径：三个要点

第一，穿孔。胸导管要**穿过主动脉裂孔**，穿过去就进入胸腔了。

第二，找路标。它在**胸主动脉与奇静脉之间**上行。你在图上找它，就到这两个结构中间去找。

第三，转弯。大约到**第 5 胸椎水平**，它在**食管与脊柱之间**斜行向左。

最后，**注入到左侧的静脉角**。

```text
        第 1 腰椎水平
      ┌────────────┐
      │   乳糜池    │ ◄── 胸导管起于此
      └─────┬──────┘
            │  穿过主动脉裂孔 → 入胸
      ══════╪══════  膈肌
            │
     胸主动脉│奇静脉      ◄── 在两者之间上行
            │
     第 5 胸椎水平：在食管与脊柱之间斜行向左
            │
            └──────────►  左静脉角
```

> 读图：三个动作记行径——穿一个孔（主动脉裂孔）、在两个结构之间走（胸主动脉与奇静脉之间）、在一个高度上向左斜（食管与脊柱之间），终点是左静脉角。

#### 收进来的六条淋巴干

了解了行程，第三个问题：它接收哪些淋巴干？

淋巴管道一共四级，第三级是淋巴干，全身 9 条。胸导管接收其中的 6 条——**起始部 3 条，终止部 3 条**。

起始部那 3 条：左右各一条，对称的，叫**腰干**，来自下肢的淋巴液；中间一条叫**肠干**，来自腹腔的淋巴液。

终止部那 3 条是汇进末端来的：来自头颈部的叫**颈干**，来自上肢的叫**锁骨下干**，来自胸腔的叫**支气管纵隔干**。

| 部位 | 淋巴干 | 汇集来源 |
| --- | --- | --- |
| 起始部 | 左腰干、右腰干 | 下肢 |
| 起始部 | 肠干 | 腹腔 |
| 终止部 | 颈干 | 头颈部 |
| 终止部 | 锁骨下干 | 上肢 |
| 终止部 | 支气管纵隔干 | 胸腔 |

9 条里收 6 条，所以**全身大部分淋巴液都是由胸导管汇入静脉的**。

### 右淋巴导管

跟胸导管相对的是**右淋巴导管**。它跟胸导管完全不是一个量级：就是一个厘米的短干，很短很短，就在**右侧的静脉角**。

它也接收 3 个干——**右侧的颈干、右侧的锁骨下干、右侧的支气管纵隔干**，也就是 9 条里剩下的那 3 条。

> **易错点**：这两个导管收的干正好互补，但方向不能写混。胸导管那三条（颈干、锁骨下干、支气管纵隔干）在图上要注明是**左侧**的；右淋巴导管那三条，名称前面统统要加**右侧**。名字一样，靠的是前缀区分左右，这条极容易搞错。

到这儿淋巴导管就讲完了——全身一共 2 个。

### 淋巴器官

接下来是淋巴器官，包括**淋巴结、胸腺、扁桃体，还有脾**。这几样结构里，我们重点讲**脾**——它是最大的一个淋巴器官。

要了解这么几件事：位置、形态、功能，还有靠什么固定在这个位置。

#### 位置

从前方看，腹部已经分成 9 个区了，脾在哪一块？在**左季肋区**。

从侧面看更清楚一点：脾在**第 9～11 肋之间**。怎么定位呢——第 9 肋和第 10 肋相交，第 11 肋是浮肋，第 12 肋也是浮肋，数到这儿就知道脾应该落在哪几根肋之间了。脾是一个长形的器官，它的**长轴和第 10 肋平行**。

还有一点特别重要，是脾的一个特点：脾在肋弓的里面。所以**正常人的脾脏，在肋弓下是触不到的**。这句话你一定要记住，后面讲形态的时候马上就用得上。

#### 形态

先看挂图。脾的外侧面能看到前缘和后缘；翻过来看内侧面，位置和外面是对应的。

颜色上是暗红色。但这里要带出一个共性：**肝脏、脾脏都有一个共同特点——质软而脆，遇到暴力以后容易破裂**。所以腹部脏器的破裂，多见于肝和脾。记住这一条就够了。

脾的表面结构很好记：上下叫端（前有上端、后有下端），前后叫缘（前缘、后缘），内外叫面（外侧面、内侧面）。

形态上重点盯两处。

**一处是前缘。** 前缘上有一两段——准确说是 2 到 3 个**脾切迹**。这个要记住，它是临床上触摸脾脏、判断是不是脾脏的标志。为什么它能当标志？你想想：刚才说了正常人肋弓下根本摸不到脾，那怎么触到脾呢？只有在病态情况下——脾肿大了，从肋弓下面露出来了。这时候你摸到一坨肿物，凭什么断定它就是脾？**你要是摸到脾切迹了，那肯定就是脾脏**。

**另一处是内侧面。** 内侧面中部凹陷，有许多结构出入，所以这个地方叫**脾门**。脾门有血管、神经、淋巴出入。

形态上就这么两条重点：**脾切迹**和**脾门**。

#### 功能

从功能上，脾有 4 个。

**储血。** 怎么理解？把脾切开，里面有很多很多血窦。临床上很常见的一个例子：肝硬化导致门脉高压，门脉的血液逆流进入脾脏，把脾窦充盈大了，整个脾的体积也就跟着变大——这就是为什么肝硬化病人会有脾大。血窦能存这么多血，所以它有储血功能。

**造血。**

**清除衰老细胞。** 衰老的红细胞在脾脏被"处决"了。

**免疫。**

#### 靠四条韧带固定

最后说说，脾靠什么装置固定在这个位置上？靠韧带，一共 4 条。

先从前方的整体关系看一遍：右边是肝，这是胃，这一侧是脾，下边还有结肠。肝与胃之间是小网膜，脾和胃之间有韧带。

再做一个水平切面看：从脊柱、腹壁，到脏器——左肾在这儿，脾在这儿，再向内侧是胃的断面，再向内是小网膜的断面。注意看**腹膜**：它包被着肾脏，到达脾脏以后又包绕了脾，然后在这儿**返折回到胃、又包绕胃**，这样就形成了两条韧带——一条是**脾肾韧带**（脾和肾之间那条），一条是**脾胃韧带**（脾和胃之间那条）。

再换一个角度：上方是膈肌，这边是胸的侧壁、腹的侧壁，下边应该有一个横结肠的脾曲在这儿拐弯。膈肌和脾的上端之间有**膈脾韧带**，脾和结肠脾曲之间有**脾结肠韧带**。

这么一圈数下来：膈脾、脾结肠、脾胃，再加后边那个脾肾——**脾靠 4 个韧带来固定**。

| 韧带 | 连接 |
| --- | --- |
| 脾肾韧带 | 脾与左肾 |
| 脾胃韧带 | 脾与胃 |
| 脾结肠韧带 | 脾与结肠脾曲 |
| 膈脾韧带 | 脾上端与膈肌 |

> **结论**：脾的位置是左季肋区、第 9～11 肋之间、长轴与第 10 肋平行，肋弓下触不到；形态记脾切迹与脾门；功能四条（储血、造血、清除衰老细胞、免疫）；固定靠四条韧带。

到这里淋巴系就算简单给大家讲完了——它在整个脉管系统里相对是个配角，构造上不需要展开太细，做到一个了解的程度就够了。但有两件事是必须留下的：一个是淋巴液最终要汇入静脉这件事，一个是脾因为肝硬化门脉高压而肿大这件事。这两条都直接连着临床。
