## 解剖学绪论与骨学总论
> 对应块：BLK01 | 覆盖分集：P01-P02 | 块标题（分集名）：《01.解剖学绪论》

今天大家第一次上解剖课。

第一次上课，我先把几件事交代清楚：解剖学研究的到底是什么、它凭什么在医学里占这么重要的位置、它分成哪些科、人体是怎么从细胞一层层搭到系统的。最后还有一块是这节课的重点——解剖学的方位术语，这一块今后天天都要用，务必吃透。

那我们就从定义开始。

### 系统解剖学研究什么

一句话：系统解剖学研究的是**正常**人体或器官的**形态、结构**、**生理功能**，以及**发生发展的规律**。

> **定义**：系统解剖学——研究**正常**人体或器官的**形态结构**、**生理功能**与**发生发展规律**的学科。

这里有两个词要特别留意。

**第一是"正常"。** 定义里说的是"正常人体或器官"，不是病变、不是畸形。整个解剖学研究的都是正常的形态结构；等到学病理学、病理解剖学的时候，才是拿这个"正常"当参照，看它哪儿跑偏了。

**第二是"形态结构"和"生理功能"要放在一起看。** 光记住骨头在哪儿、肌肉怎么走是不够的，还要知道它为什么长成这样、在这个位置上能完成什么功能。后面会看到，很多结构特点都是被功能和位置逼出来的。

### 没有解剖学就没有医学

解剖学在医学上是什么地位？恩格斯说过一句话：**没有解剖学就没有医学。**

我们看看这句话能不能成立，举几个例子。

- **体表定位**：在人体体表，如何去判断肝、脾的大小？肝脏在体表怎么确定它的大小，脾脏又如何确定？在体表如何能准确地找出胆囊的投影位置，如何能找出阑尾的投影位置，或者说阑尾的压痛点、胆囊的压痛点？那说明你要对脏器的解剖熟悉——熟悉了，体表你才能准确地找到。
- **硬膜外麻醉**：一个患者要做麻醉，患者已经躺好了，做什么麻醉呢？**硬膜外麻醉**。我们在什么部位进针？沿着哪个方向进针？怎么才能知道针已经扎到硬膜外腔？也需要解剖知识。
- **球后注射**：眼部有病，局部要注射一些抗菌素，临床上叫**球后注射**。在什么部位进针？哪个方向才能不伤及眼球？也需要知道眼部的解剖。
- **环甲膜穿刺**：一个急诊患者来了，急性喉阻塞，马上就要窒息死亡了。这时候立即要做一个**环甲膜穿刺**，建立一个暂时的呼吸通道，然后赢得时间做气管切开。那么在哪儿穿呢？什么部位是环甲膜？这个针穿进去以后能扎到喉的哪一个腔隙？也需要解剖知识。
- **心内注射**：临床常做的心内注射。大家看，看起来很恐怖——这是一个胸腔，在胸骨左侧第四肋间扎进去一个针，这叫心内注射。那我们要知道胸腔的解剖啊。在这块你扎进去的话，能扎到心脏的哪个腔隙呢？周围又有哪些结构呢？会不会形成气胸？所以胸腔的解剖你也得知道。
- **胃切除术**：那更不用说外科手术了。比如我们要做一个**胃切除术**，切了以后，胃和空肠要吻合在一起。那么空肠的起端我们怎么走？如何去确定它？切胃的时候在哪儿结扎胃的血管？怎么样才能保证它的生理功能？等等——这些都需要解剖知识。

所以我们得出一个结论：**医学是建立在解剖学基础上面的**。

可见解剖学的重要。对我们广大医学生来说，它是一门重要的**医学基础课**。现在临床所用的名词，大约有**三分之二来自于解剖学**。

> **结论**：医学建立在解剖学的基础之上；解剖学是一门重要的医学基础课，临床所用名词约有三分之二来自解剖学。

### 解剖学怎么分科

方法很多，常见的是按方法和按内容来分。

```text
解剖学的分科
│
├─ 按方法分
│  ├─ 巨视解剖学：用人的肉眼去研究
│  │    ├─ 系统解剖学
│  │    └─ 局部解剖学
│  └─ 微视解剖学：借助于显微镜研究人体的形态和结构
│       ├─ 组织学
│       ├─ 细胞学
│       └─ 胚胎学
│
└─ 按内容分
   ├─ 外科解剖学、显微外科解剖学
   ├─ 表面解剖学、神经解剖学
   ├─ X 线解剖学（就是影像解剖学）、断层解剖学
   └─ 运动解剖学（体育学院）、美术解剖学（美术学院）
```

读图：左边是按研究方法分的入口——巨视和微视是两条主线；右边是按研究内容分的横向门类，医学之外，体育学院用运动解剖学，美术学院用美术解剖学。

**巨视解剖学**为什么叫这个名字？它是用人的肉眼去研究。**微视解剖学**则是借助于显微镜来研究人体的形态和结构——组织学、细胞学、胚胎学，今后大家都要学，属于微视解剖学这一支。

巨视解剖学再分，就是我们这门**系统解剖学**，还有一门**局部解剖学**。

**局部解剖学怎么解释呢？** 比如说一个患者，外伤，机器把胳膊压断，到医院以后是不是得断肢再植啊？断肢再植，我们如果不了解这个断面的解剖，你敢不敢植啊？你植完功能也没了，对不对？

所以局部解剖学研究的是：局部层次的器官，它的结构、层次以及它的毗邻。

> **提示**：两者视角完全不同。**系统解剖学**是按系统铺开全身，一个器官一个器官地认；**局部解剖学**是守住一个部位，把那一块的结构层次和毗邻关系抠清楚。断肢再植这类手术，靠的就是局部解剖。

### 细胞、组织、器官与系统

接下来讲器官与系统。

人体的基本结构是由细胞构成的。**细胞加上细胞的间质**，就构成了什么呢？组织。

```text
        细胞  ＋  细胞间质
                │
                ▼
             组织 ──┬── 上皮组织
                     ├── 结缔组织
                     ├── 肌组织
                     └── 神经组织
                │
                ▼
             器官 ──  不同的组织组成器官
                │
                ▼
             系统 ──  具有相同功能的器官构成系统
```

读图：细胞加间质构成组织，四种组织再搭成器官，功能相近的器官聚成系统——这是一条自下而上的四层链条。

人体可以分为四大组织：**上皮组织、结缔组织、肌组织、神经组织**。不同的组织又组成了器官。器官——具有相同功能的器官，它又构成了人体的系统。具有相同功能的不同器官，构成人体的系统。

那么人体一共有几大系统呢？

| 系统 | 系统 | 系统 |
| :--- | :--- | :--- |
| 运动系统 | 消化系统 | 泌尿系统 |
| 生殖系统 | 呼吸系统 | 循环系统 |
| 感觉器官系统 | 内分泌系统 | 神经系统 |

> **结论**：人体可以分为**九大系统**。

### 标准的解剖姿势

这节课的重点，是解剖学的方位术语。

要先弄清一件事：什么叫做标准的解剖知识？什么姿势是标准的姿势呢？

**头正，双下肢并拢，足尖朝前，两上肢自然下垂——注意，就在这儿，掌心一定要朝前。**

它和正常的人体立正，唯一的差别就是**掌心朝前**。

这个姿势作为标准的解剖姿势，我们的方位术语是根据这个姿势来定的。

> **易错点**：所有的方位术语（上下、前后、内外、左右）都是相对这个姿势而言的。姿势一变，术语的含义就全变了——所以课本上不写"掌心朝前"这句话的时候，描述的就是解剖姿势，而不是立正姿势。

### 剖面与轴

第二个，我们要知道解剖的**剖面与轴**。

什么叫剖面和轴呢？我们将人体切成不同的剖面，或者是人的器官也可以切成不同的剖面。

大家看有几个面呢？

- 这个面是**沿着前后方向**将人体和器官所切的切面，这个我们叫做**矢状面**；
- **沿着左右方向**将人体或者器官所切成的这个面呢，叫**冠状面**；
- **沿水平方向**所切开的，就叫**水平面**。

所以人体可以分为三个剖面。

有几个轴呢？

- 由**上向下**与地面垂直的这个轴，它就叫**垂直轴**；
- 从**左到右**、与水平面相平行的轴，这叫**冠状轴**；
- 由**前向后**、与水平面相平行的轴，叫**矢状轴**。

所以有三个轴、三个面。

| 剖面 | 切割方向 | 对应的轴 | 轴的方向 |
| :--- | :--- | :--- | :--- |
| 矢状面 | 沿前后方向切 | 矢状轴 | 由前向后，与水平面相平行 |
| 冠状面 | 沿左右方向切 | 冠状轴 | 从左到右，与水平面相平行 |
| 水平面 | 沿水平方向切 | 垂直轴 | 由上向下，与地面垂直 |

> **提示**：面的名字和轴的名字是**成对**的，从各自的方向定义直接就能对上——矢状面是沿前后切的，矢状轴就是前后走向的；冠状面是沿左右切的，冠状轴就是左右走向的。三个面、三个轴，别记混。

### 解剖方位术语

第三个就是方位术语。所谓方位术语，就是上、下、前、后等等这些术语。

| 术语 | 判断标准 |
| :--- | :--- |
| 上 | 近头顶 |
| 下 | 近足底 |
| 前（腹侧） | 近腹侧 |
| 后（背侧） | 近背侧 |
| 内 | 靠近中轴线 |
| 外 | 远离中轴线 |
| 近端 | 四肢：靠近肢根；消化管：靠近口腔 |
| 远端 | 四肢：远离肢根；消化管：靠近肛门 |
| 浅 | 体表结构：接近皮肤；管状结构：远离管腔 |
| 深 | 体表结构：远离皮肤；管状结构：接近管腔 |

这十条怎么理解，我们一条一条过。

**上、下、前、后。** 按解剖姿势来说，近头顶为上，越靠近头顶那一点就叫上；近足底为下。如果这是一个人的侧面，腹侧、背侧——近腹侧为前，近背侧为后。

**内、外。** 比如这是一个躯干：肋弓、剑突、脐。我们假设人体有一个中轴（中轴线），那我们看，靠近中轴线的为内，远离中轴线的为外。

**近端、远端。** 对四肢来说，靠近肢根的这一点叫近端，远离肢根的叫远端。对消化管来说，靠近口腔的为近端，靠近肛门的为远端。

**浅、深。** 越接近皮肤的是不是叫浅呢？远离皮肤的就叫深。那么对消化管来说呢？比如这是一个消化管，那就是**以管腔为准**——接近管腔的叫深，远离管腔叫浅。

> **易错点**：判断"内/外"和"浅/深"之前，先问一句——**参照物是谁**。体表结构以中轴线为准、以皮肤为准；管状结构（比如消化管）以管腔为准。参照物一换，"内"和"深"就反过来了。

**还有一些特殊部位的叫法。**

对于**臂**来说，按标准姿势还是叫内外。但**前臂**有个特殊的叫法：因为前臂由两个骨构成，内侧是**尺骨**，就叫**尺侧**；外侧是**桡骨**，就叫**桡侧**。

**大腿**还是叫内外。但**小腿**也一样：内侧是**胫骨**，所以内侧叫什么侧？**胫侧**；外侧是**腓骨**，所以外侧叫**腓侧**。

这就是经常遇到的解剖的方位术语。绪论这一部分大家注意，重点要掌握最后一个问题——解剖学的方位，因为在今后学习和工作中要经常遇到。

### 骨的形态分类

接下来我们进入骨学总论。首先，给大家介绍一下骨的形态。

人体骨按部位可以分为**颅、躯干和附肢**（也就是上肢和下肢）三大部分。而我们讲的骨的形态，是全身的骨按形态大体可以分为四组。

| 类型 | 代表 | 特点 |
| :--- | :--- | :--- |
| 长骨 | 位于四肢的骨 | 四肢的骨都比较长，以关节为轴，可以做幅度较大的**杠杆运动** |
| 短骨 | 手骨的**腕骨**、足骨的**跗骨** | 长、宽、高近似相等 |
| 扁骨 | 围成颅腔的骨、胸廓的骨以及骨盆的骨 | 都是扁薄呈弓形的骨，围成骨性腔，对腔内脏器起到保护作用 |
| 不规则骨 | 脊柱上的椎骨、颅骨里的下颌骨 | 形状不规则 |

所以骨的形态可以分为四类：长、短、扁，和不规则。

> **易错点**：别把"按部位分"和"按形态分"混成一锅。**按部位**是颅、躯干、附肢；**按形态**才是长骨、短骨、扁骨、不规则骨。这两套分法名字都不带"部位"或"形态"，考试和做题时特别容易串。

### 长骨由哪些部分组成

我们以长骨为例。作为一个长骨，它必须具备的几个特点是这样的：

- 中间较细的这部分叫**长骨体**，也叫**骨干**；
- 两端比较膨大的部位呢，叫**骺**；
- 骺的游离端，都有关节面，关节面的上方附着一层软骨，叫**关节软骨**；
- 在长骨的骨干还能看到一些小孔，叫**滋养孔**，血管经此孔进入骨质内。

```text
                 ┌────────────────┐
                 │ ══════════════ │  ← 关节软骨，覆盖在关节面上
                 └─┐            ┌─┘
                 ┌┘            └┐
   骨骺 ─────────►│                │  ← 骺：两端比较膨大的部位
                 │                │
                 │████  骨干  ████│  ← 骨干（长骨体）：中间较细的部分
                 │████  ○  ○  ████│  ← 滋养孔：血管经此孔进入骨质内
                 │                │
                 │                │
                 └┐            ┌┘
                 └─┐            ┌─┘
                 │ ══════════════ │
                 └────────────────┘
```

读图：长骨两端膨大是骨骺，骺的游离端有关节面、上面盖着关节软骨；中间细的一段是骨干（长骨体），骨干的骨面上开着滋养孔，血管从这里进骨质。

### 骨的构造

骨的构造包括四部分内容：第一是**骨质**，第二是**骨髓**，第三叫**骨膜**，第四，**骨的血管和神经**。

#### 骨质

我们把一个骨给它断开，断开以后，看这个剖面上能看到哪些结构。

首先看骨的外周——骨的外周有致密、坚硬的部分，我们叫**密质**。它位于骨的外周。

它有什么特点呢？在**骨干处密质比较厚**，骨骺处周围的密质比较薄，所以**骨干厚、骨骺薄**。另外，它致密而且坚硬。

我们再看它的内部，还有一些骨质呈疏松网眼状，这叫**骨松质**，位置在内部。

骨干处大家看有没有松质呢？松质在**干骺端逐渐向骨干处逐渐减少**，减少到骨干处松质消失，所以**干内就没有松质了**。正因为骨干里面没有松质，才形成了一个结构，叫**骨髓腔**。骨髓腔里面容纳骨髓。

| | 密质 | 松质 |
| :--- | :--- | :--- |
| 位置 | 骨的外周 | 骨的内部 |
| 形态 | 致密、坚硬 | 疏松、网眼状 |
| 分布 | 全骨都有；骨干厚，骨骺薄 | 干骺端向骨干逐渐减少，至骨干处消失 |

> **结论**：骨质 = 密质 + 松质。密质在外周、骨干厚骨骺薄；松质在内部、疏松网眼状，到骨干处完全消失，空出来的就是骨髓腔。

#### 骺板与骺线

在这里边大家要搞清两个概念：一个是**骺板**的概念，第二个是**骺线**的概念。

什么叫骺板呢？**在骨骺内部的这个软骨板就叫骺板。**

骨是怎么向长生长的呢？骺板增长的速度特别快，使骨长径被拉长；增长的同时，骺板周围又被骨化。再增长，再骨化，所以使骨由短变长。

当它的增长速度**小于**骨化速度的时候，逐渐逐渐骺板变薄，最后消失。

那我们在 X 光下观察，这个骺板是个什么现象呢？我们看到的是一个**骨分离的现象**。为什么出现呢？因为**软骨在 X 光下不显影**，所以形成一个带状的透明区。

当骺板生长速度变慢的时候，最终就被完全骨化。这个骺板骨化形成的一个痕迹——浓白致密的线状阴影。

所以我们把骨骺内那个软骨板叫**骺板**，把骺板被骨化形成的线状阴影叫**骺线**。

```text
  儿童                                  成人
  ┌──────────┐                          ┌──────────┐
  │  骺 板   │  软骨                    │  骺 线   │  浓白致密的线状阴影
  └──────────┘                          └──────────┘
       X 线下不显影，
    呈带状透明区，看起来像骨端「分离」
```

读图：左边是儿童时期，骨骺里的软骨板还在生长，X 光看不穿它，于是显得骨端"分离"；等这块软骨被完全骨化，位置不再移动，就留下右边那条终生不变的骺线。

| | 骺板 | 骺线 |
| :--- | :--- | :--- |
| 是什么 | 骨骺内部的软骨板 | 骺板骨化后形成的线状阴影 |
| X 线下什么样 | 软骨不显影，呈带状透明区，表现为骨端的"分离" | 浓白致密的线状阴影 |
| 结局 | 增长速度小于骨化速度时变薄，最后完全骨化消失 | 骺板骨化完成后就固定下来 |

> **易错点**：骺板是**软骨**，在 X 光下根本看不见，只留下一条透明带；骺线是骺板**骨化之后**留下的线状阴影。骺板最终必然完全骨化而消失，届时骨上就只剩骺线——两者不是同一种东西，也不会长期并存。

#### 骨髓

成人的骨髓包括两种：一种**红骨髓**，一种是**黄骨髓**。

- **红骨髓**在哪呢？红骨髓都存在于**骨松质的网眼内**，这里边都是红骨髓；
- **黄骨髓**仅存在于**长骨的骨髓腔内**。

> **结论**：**红骨髓有造血能力，而黄骨髓没有造血能力。**

#### 骨膜

大家看一下挂图——这是一个新鲜骨。新鲜骨大家看，骨的外周确实包了一个结缔组织膜，我们把这个膜叫做**骨膜**。

骨膜要从位置描述：确实覆盖在骨的外周。但是大家看一下，这是骨游离端的关节面，这个被切开的这一部分里边是骨性的关节面，而没有被切掉的这一部分是关节软骨。我们知道关节软骨终身保留，它不骨化。可是骨膜包没包在关节软骨的表面呢？没有。到关节面的周缘，骨膜就消失了。

所以骨膜从位置上我们描述它，是覆盖骨的外周，但是**关节软骨表面无骨膜覆盖**。

我们再看第二个特点：骨膜上有丰富的血管，很多很多的血管。

第三个特点：大家看骨膜是不是很容易和骨面分离啊？这个就掀开了，掀开了。掀开之后你会看到，**骨膜的内层细胞可以分化为两种细胞**：一个叫**成骨细胞**，一个叫**破骨细胞**。

那么归纳一下骨膜的特点：骨膜覆盖在骨的外周，是一个**结缔组织膜**；关节软骨表面没有骨膜。

它有什么特点呢？第一个特点：**骨膜富有血管和神经**。为什么骨折的时候疼痛难忍？就因为骨膜里面有很多**躯体传入神经**，疼痛是由它传递的。另一个特点就是，骨膜的内层细胞能够分化为两种细胞，一个叫成骨细胞，还有一个叫破骨细胞，这两种细胞参与骨的生长和修复。

> **注意**：骨膜的三个要点——① 位置：覆盖骨的外周，**但关节软骨表面无骨膜**；② 富含血管和**神经**（所以骨折剧痛，靠躯体传入神经传递）；③ 内层细胞可分化为成骨细胞和破骨细胞，参与骨的生长和修复。

#### 骨的血管与神经

重点我们说一下骨的血管。**骨的血管有丰富的来源。**

- **骺动脉**，进入骨；
- **干骺端动脉**，进入骨；
- 随**滋养孔**进入骨内的**滋养动脉**，分为**升支、降支**；
- 此外还有骨膜上的丰富血管，这些血管叫**骨膜动脉**。

来源很多，所以供给很充分——这也是为什么骨膜那么敏感、骨折那么疼。

### 骨的生长

#### 膜化骨与软骨化骨

骨的生长方式有两种：一种是**膜化骨**，一个是**软骨化骨**。

**什么叫膜化骨呢？** 我们说新生儿颅骨上有多少个**囟**？前囟、后囟、蝶囟、乳突囟——这些结缔组织最终要被骨化，形成颅骨。这种生长方式叫**膜化骨**：由结缔组织膜最后成为骨。

**什么叫软骨化骨呢？** 我们看到的**骺软骨**逐渐增长使骨变长，但是它最终被骨化成一个痕迹——这个叫**软骨化骨**。

| | 膜化骨 | 软骨化骨 |
| :--- | :--- | :--- |
| 由什么变成骨 | 结缔组织膜 | 软骨（骺软骨） |
| 例子 | 新生儿颅囟闭合成颅骨 | 骺软骨使骨变长，最终骨化成骺线 |

#### 茜草喂猪的实验：骨怎么长粗，髓腔为什么跟着变大

骨怎么向长生长、向粗生长，将来在组织学里边我们还要详细介绍。那么这里我重点给大家讲一个小故事，你们把这个故事听明白了，骨生长的道理也就懂了。

过去，英国有一个**花布印染商**，他家里养了很多猪。有一天他的朋友到家里做客，当然他是用猪肉来款待。朋友在吃猪的时候发现，这个猪肉吃完以后，骨头是红颜色。

医生就问他：为什么你的猪骨是红色的？他说我也不知道。医生说，你平时喂的什么食物呢？

花布印染商说：我印染花布，有一种植物叫**茜草**，我把它用来印染，然后把它的残渣拌上糖麸来喂猪。

医生就明白了。茜草里面含有大量的紫色素，可以染布——那么当猪吃了这个食物以后，色素是不是随着血液沉淀到骨质里边，使骨变红？然后他就写了一篇文章，登到**皇家学会的会报**上。

法国一个地主很好学，看了文章以后很好奇，回家就开始养猪，也用这种办法养猪。但是他不是花布印染商——他有时候茜草就会中断。那猪不能饿，就喂糖麸；有茜草了，就加上茜草再喂猪。

最后他做了一系列的实验。

**第一个实验**：他把猪养大了以后，把这个骨做一个断面。这是骨髓腔。他发现了什么现象呢？发现他的这个猪骨**红白相间**的，形成了很多**骨性环**。所谓红的，就说明饲料里边有什么茜草；白的，就是没有茜草。

最后他得出第一个结论：**骨向粗生长，跟大树一样**——树有树轮，所以跟大树一样，一圈一圈由外逐渐形成了骨性环。

那我们用现代的理论来解释：骨向粗生长，靠的是谁呢？我们已经讲了骨膜内层细胞可以分化为成骨细胞和破骨细胞。**成骨细胞不断地在骨的外周贴附，然后被骨化，再贴附，再骨化，形成了很多很多骨性的环，使骨逐渐逐渐变粗。**

**第二个实验**：在小猪的骨上**绑了一个银丝**，然后继续喂养这个猪。当猪长大了以后，发现银丝还在不在？这是里面的骨髓腔——发现银丝**掉到骨髓腔里**了。

这个现象说明什么呢？他得出了第二个结论：骨向粗生长的同时，**髓腔也随之变大**。

那用现在的理论，为什么髓腔能变大呢？因为骨膜内层细胞还能分化出一个细胞，叫**破骨细胞**。

那我们举一个不恰当的例子大家看。如果这是一个房子，房子外边这儿有一个工人在**漫墙**，这一侧也有一个工人在漫墙。这个漫墙的工人，我们把它看成是什么细胞？**成骨细胞**。这个墙是不是逐渐在加厚？那么墙里边有一个人，他开始**刨墙**，使墙总是保持一定的厚度。但是墙体是不是往外移了？往外移了——相对比喻，就等于骨变粗，变粗以后内腔变大。

```text
        ┌────────────────────────┐
        │                        │
        │    ┌────────────┐      │
        │    │            │      │
        │    │   房间（腔） │      │
        │    │            │      │
        │    └────────────┘      │
        │                        │
        └────────────────────────┘
          外侧工人「漫墙」          内侧工人「刨墙」
           ＝成骨细胞                ＝破骨细胞
```

读图：房子就是骨，房间就是髓腔；外侧那个只加砖的工人是成骨细胞，内侧那个一边刨一边等的是破骨细胞。墙两边同时动，结果是墙整体外移——骨变粗、内腔变大，而墙的厚度始终不变。

这样有什么好处呢？使**骨壁始终保持一个厚度，减少骨的重量**。这就是破骨细胞的作用。

#### 向长生长靠骨的两端

**第三个实验**：在小猪的骨头上**插上三个银针**——在骨干处插了三根银针，继续喂养。当猪长大了以后，发现银针的距离改变没有？**没有改变**。

他就得出了第三个结论：骨向长生长，是靠中部还是靠两端呢？**两端**。我们讲了什么结构？**骺板**。

于是得出第三个结论：骨向长生长，靠骨的两端，也就是**骺板**。

| 实验 | 做法 | 现象 | 结论 |
| :--- | :--- | :--- | :--- |
| 第一个 | 茜草时断时续地喂猪 | 骨断面红白相间，形成骨性环 | 骨向粗生长，像树轮一样一圈圈往外加 |
| 第二个 | 在小猪骨上绑一根银丝 | 银丝掉进了骨髓腔 | 骨变粗的同时，髓腔也随之变大 |
| 第三个 | 在骨干处插三根银针 | 三针之间的距离没有改变 | 骨向长生长靠骨的两端，也就是骺板 |

> **结论**：骨向长生长靠骨的两端（骺板）；骨向粗生长靠骨膜内层的成骨细胞；而破骨细胞从内侧刨，使髓腔随骨一起变大，骨壁厚度恒定、重量减轻。
