## 气管、支气管与肺：位置、构造与形态
> 对应块：BLK20 | 覆盖分集：P27 | 块标题（分集名）：《27.呼吸系统Ⅱ》

这一讲我们把气管、支气管和肺连起来讲。这三样东西其实是一条线上的：气管从颈部一路往下走，到底下分成左右两支；左右两支再经肺门进肺；进了肺还不能停，要继续分成肺叶支气管、一直分到肺段支气管。肺本身则要交代它长什么样、长在哪、怎么分叶。

先从气管开始。

### 从环状软骨往下：气管的位置

先把位置搞清楚，这比什么都重要。回忆一下喉的下界——喉的下界是环状软骨的下缘。喉到这里就结束了，从这往下开始就是气管，一直走到气管杈分叉的部位为止。

气管的上下界交代成这样：

- 上界在第六颈椎的下缘，也就是环状软骨的下缘；
- 下界在胸骨角平面，或者说第四胸椎水平；
- 说到下端的标志，就不得不说气管隆嵴。

把气管从中间断开看：左右主支气管交汇的部位向上隆起，形成一个半月状的隆起，这个结构就叫气管隆嵴。

> **定义**：气管隆嵴——左右主支气管开口在气管下端交汇处所形成的半月状隆起。

```text
        环状软骨下缘 ＝ 第 6 颈椎下缘
        ─────────────────────────────  ← 上界
                    │
                    │   气  管
                    │  （颈段 → 胸段）
        胸骨角平面 ＝ 第 4 胸椎水平
        ─────────────────────────────  ← 下界
                ┌─────┴─────┐
                │    ▲      │  ← 隆嵴：半月状隆起
                └─────┼──────┘
               右主     左主
              支气管   支气管
```

它是一个标志性的结构。临床上做气管镜检查的时候，一旦看到隆嵴了，就说明马上就要进入左右主支气管了。所以这一节不用死记，但要记住它是个标志。

### 气管的构造：软骨架加一道膜壁

气管的构成是两部分内容：气管软骨和膜壁。

软骨是 C 字形的，一节一节排列，大约 14～17 个。软骨和软骨之间借助于韧带连接起来，围成的是一个**后壁敞开**的管道。敞开的那个后壁，靠膜壁给它封闭住——就是一层含平滑肌的结缔组织膜。

```text
        前面（隆起方向）
     ╭───────────────╮
     │   气管软骨    │  C 字形，共 14~17 个
     │               │  相邻软骨之间借韧带相连
     ╰───────────────╯
       ╱           ╲   ← 后壁敞开
     ╰───────────────╯
        膜壁：含平滑肌的结缔组织膜
        封住后壁 → 后壁扁平的完整圆筒状管道
```

> **结论**：软骨加膜壁，两部分合起来才构成一个完整、后壁扁平的圆筒状管道——这就是气管。

### 切开为什么选在第 2～4 环

第三个问题稍微提一下：气管切开的部位。

气管切开一般在第 2～4 气管软骨环之间，临床上也常选到第 3～5 环。为什么是这个区间？先看前提——气管分颈段和胸段，气管切开主要在颈段做，而且在颈段里选择的位置**越低越好**。

至于为什么必须选在这个部位、又为什么必须在医院做，这就绕不开气管前方的东西。上一讲已经提到过：气管前方有甲状腺峡，甲状腺峡的前面还有舌骨下肌群。所以标准的手术层次是：先切皮，然后分离舌骨下肌群，再游离甲状腺峡，把甲状腺峡向上推移——这才能暴露出底下的气管环，这时候才能切。

> **提示**：正因为现场急救来不及做完这一整套分离，急救时只能退一步，用粗针头做一个环甲膜穿刺。

### 主支气管：一粗一细，一直一斜

主支气管分左右两个，特点记住就可以了。

| | 形态 | 走向 |
| --- | --- | --- |
| 右主支气管 | 比较短、比较粗 | 近似于垂直位 |
| 左主支气管 | 比较细、比较长 | 略微倾斜 |

这两个特点不是背下来就算完的，它有直接后果：如果小孩不慎把东西吞进气道、误入气管，最容易到哪一侧？

到右侧。因为它粗，而且接近垂直。

> **易错点**：左右千万别记反——左细长、略倾斜；右短粗、略垂直。异物最容易落入的是右侧主支气管。

### 支气管树：一路数下去

气管往下分成左右主支气管，左右主支气管经肺门进入肺。进入肺以后继续分：先分到各个肺叶，这一层叫肺叶支气管；再往下分，就叫肺段支气管，对应到肺段。

数字要捋清楚：右侧进入肺后形成三个分支，分别到右侧的三个肺叶；左侧是两个分支，到左侧的两个肺叶。再往下分，两侧各有十个肺段——右侧共十个，左侧也是十个。

```text
                       气管
                        │
            ┌───────────┴───────────┐
         右主支气管               左主支气管
         短粗 · 垂直位            细长 · 略倾斜
               │                      │
        ┌──────┼──────┐        ┌──────┴──────┐
       上叶   中叶    下叶      上叶        下叶   ← 肺叶支气管
               │                      │
            10 个肺段               10 个肺段        ← 肺段支气管
```

### 肺为什么能浮起来

这一部分重点在肺。先说它是什么质地的器官：肺是一个柔软而富有弹性的器官，里边充满着大量的空气。

所以肺如果取出来放在盆里，应该漂还是沉？应该飘起来。

过去有这样一个例子。某妇产科医院接生一位产妇，难产，孩子生下来以后，这医生拍打了很多次，孩子也没有哭。最后医生就告诉那个工人：放到箱里吧，这孩子已经是死婴了。工人往箱里放的时候，因为知道是死孩子，也就没轻轻放——他就隐约听到叫了一声。他回来就告诉这个大夫，说王大夫，那孩子是活的。王大夫听了以后大为不快，说我工作了 25 年，死孩子活孩子我分不清吗？你该干啥干啥去。

工人听了以后很不愉快，想了一阵，说你不管，我管。下午越想越觉得不对劲，就找领导汇报去。领导那儿呢，又挨了一顿批：领导说你上午干啥呢？你怎么不早来呢？结果领导跟他到那儿一看，孩子确实死了。

那么，究竟接生下来是活的还是死的？把法医找来了。法医把这个小孩的肺取出来，往盆里一放——漂起来了。活孩子，死孩子，活的。最后这个医生被判刑。

这就是"肺能浮"这件事的分量所在。

### 肺的位置：纵隔两侧的胸腔

肺在哪儿呢？先回忆一下胸廓。把胸廓做一个冠状切面：两侧是胸廓侧壁，中间有一个结构把胸廓分割成左右两个腔——这个中间的结构叫纵隔。

再从水平切面上看：这是脊柱，两侧是肋骨，同样能看到这个结构，从前到后把胸腔分割成左右两个腔隙——这个结构还是纵隔。

```text
        冠状切面                   水平切面
    ┌─────┬─────┐              ┌─────┬─────┐
    │ 肺  │ 肺  │              │ 肺  │ 肺  │
    │     │     │              │     │     │
    └─────┴─────┘              └─────┴─────┘
        纵隔                        纵隔
   （把胸廓分成左右             （把胸腔分成左右
      两个腔）                    两个腔隙）
```

肺就在这两个腔隙里，这侧一个肺，那侧一个肺。

> **定义**：纵隔——位于胸腔内、前后纵行，把胸腔分为左右两部分的间隙。

> **结论**：肺位于纵隔两侧的胸腔内。

### 肺的形态：一尖一底，三面三缘

肺的形态大家记住这八个字就够了：**一尖一底，三面三缘**。

#### 一尖一底

肺尖，也叫尖。从前方看完整的肺，上方钝圆的那个就是肺尖。

这里有一个解剖关系一定要记住。锁骨在哪儿？肺尖是**高出锁骨**的——具体地说，高出锁骨中内 1/3 交界处上方约 2～3 个厘米。

肺底就是下面那个面。如果把肺旋转一下，肺底、肺门这些结构就看得清楚了。肺底这个面是一个**凹面**，原因很简单：它坐落在膈肌的上方。

#### 三个面

第一个面，圆凸，和肋骨、肋间肌相对，所以叫肋面。记住它比较圆凸。

第二个面是内侧面，也就是纵隔面，它略微凹陷，所以是凹面。这个面上要重点记一个结构：中心部位有很多结构出入肺，所以这里叫肺门。

肺门里出入的是哪些结构？刚才讲过的主支气管在；肺动脉在；肺还有静脉；此外神经、淋巴也在这里出入肺。

第三个面叫膈面，也叫下面，就是坐落在膈肌上方的这个面，同样是一个凹面，位于膈肌之上。

#### 三条缘

**前缘**指的就是纵隔面和肋面在前方交汇处，比较锐薄。重点记左肺前缘有一个凹进去的弧形，叫心切迹。

把心脏和胸骨的位置一起画出来看：心切迹和胸骨左缘之间的这一部分，心脏是裸露的，也叫裸区；裸区的前方对应的是第四、第五肋。我们就利用这个解剖关系——如果在胸骨左缘第 4 肋间隙做心内注射，会不会造成气胸？不会。因为左肺前缘正好有心切迹，使心脏裸露、与胸前壁相贴。

**后缘**没有什么太大意义，它指的是那个钝圆的缘，在脊柱两侧，认个位置就行。

**下缘**是哪个面构成的缘？是膈面、肋面、纵隔面三者所形成的交界。

### 肺的分叶：右三左二

肺的分叶是根据什么分的？看裂。

右肺注意有两条：一条斜裂，还有一条水平裂。把右肺分成上叶、中叶、下叶，共三个叶。

左肺只有一个斜裂，所以左肺只有上叶和下叶。

> **结论**：肺的分叶简单记——右三左二。

这里还有一个很实用的联系。从矢状切面看（前面是胸，后面是背腰，下面是膈肌），肺是圆锥形的，有一条斜裂向下走。以左肺为例，斜裂上边是上叶、下边是下叶。这个方向关系直接影响听诊：

- 从前方用听诊器听，主要了解的是肺**上叶**呼吸音的改变；
- 从后方听，了解的是肺**下叶**呼吸音的改变。

所以千万不要光听前方而漏掉了后方。这句话务必记住。

## 胸膜、胸膜腔与纵隔，以及肾的形态与结构
> 对应块：BLK21 | 覆盖分集：P28-P29 | 块标题（分集名）：《28.呼吸系统Ⅲ》

这节课我们一口气解决三件事：胸膜、胸膜腔、纵隔。

把它们放在一起讲，是因为在胸腔里它们本来就是同一件事的三个侧面。从冠状面把胸腔切开，中间那一块把左右分成两半的结构就是纵隔；纵隔两侧的胸腔里各装一个肺；而把肺裹起来、又在肺根处折回去贴到胸廓内面上的那层浆膜，就是胸膜；脏层和壁层之间兜出来的那道缝，就是胸膜腔。把这三个概念咬死，整个胸腔的叙述就都通了。

我们分三问来：第一，胸膜是什么，它的壁层怎么分；第二，胸膜腔是什么，有什么特点，有哪些隐窝；第三，纵隔是什么，有什么特点，分几部分。收尾再补一个临床上最趁手的东西——肺与胸膜下界的体表投影。

胸腔里的事说完，我们把视线整体转个向：后面这一段讲泌尿系统，重点是肾。

---

### 胸膜：一层浆膜，两副面孔

先把概念立住。胸腔里覆盖在肺表面以及胸廓内面的这样一层浆膜，叫做胸膜。

这一层膜有个特点：它是**连续**的。贴肺表面的那一段叫脏层，走到肺根这个部位，它反折向上，反过来贴到胸廓的内面上，这一段就叫壁层。所以脏层和壁层不是两张互不相干的膜，而是同一张膜在肺根处折了个弯，弯的两条腿分别叫脏层和壁层。

```text
          胸骨
           │
  ┌────────┴─────────────────┐
  │ 壁层胸膜：衬在胸廓内面上 │
  │   ┌────────┐ ┌────────┐  │
  │   │  右肺  │ │  左肺  │  │
  │   │ 脏层   │ │  脏层  │  │
  │   └────┬───┘ └───┬────┘  │
  │  ─────┴─────────┴─────   │
  │    纵隔：两侧为纵隔胸膜  │
  └────────────┬─────────────┘
               │
          膈肌（膈胸膜）
```

读图：外面一圈贴着胸廓内面的是壁层胸膜；两个肺的轮廓外面那层是脏层胸膜；两个肺之间夹着的纵隔，左右两面各衬一层纵隔胸膜；最底下骑在膈肌上的是膈胸膜。

> **定义**：胸膜是覆盖肺表面和胸廓内面的浆膜。覆盖肺表面的叫脏层，位于胸廓内面的叫壁层；脏层在肺根处反折，连续地转为壁层。

### 壁层胸膜：四副面孔

壁层胸膜不是哪儿都一样的，按它贴附的位置正好分成四部分，一部分都不多，一部分都不少。

| 贴附位置 | 名称 |
| --- | --- |
| 纵隔的两侧 | 纵隔胸膜 |
| 膈肌的上面 | 膈胸膜 |
| 肋骨的内面 | 肋胸膜 |
| 肺尖的上方 | 胸膜顶 |

肺尖上方那一块要单独拎出来说一说，因为它是壁层胸膜能达到的**最高点**。做题碰到"壁层胸膜的最高处"这类问法，答案就是胸膜顶。

脏层只有一层，贴着肺表面走，不分区域。真正分区域的是壁层，就上面这四块。

### 胸膜腔：脏层和壁层之间兜出的那道缝

概念：脏层和壁层在肺根处反折移行，两者之间所形成的这个密闭腔隙，叫胸膜腔。

这里要特别小心一个字眼。前面说过，脏层和壁层这两层是紧紧贴在一起的，实际状态下中间根本撑不开多大空间。之所以还能算一个"腔"，是因为它在解剖学上确实存在、确实是个封闭的潜在腔隙——就像两块玻璃，中间用一些水把两片玻璃粘到一起，滑动可以，但能不能把它分开？分不开。

这个腔隙有三个特点，记住这三条就够用了：**左右不通**、**略呈负压**、**内有少量浆液**。

#### 左右不通

先看这一条。左右两侧的胸膜腔，由于中间被纵隔隔开，是互不相通的。

这一点决定了什么？看临床上最典型的一种情况：开放性气胸。比如这个人胸部受了外伤，胸壁破了一个口，外界气体直接灌进来，于是这一侧的胸膜腔和外界大气压**相等了**。原先靠负压吸附在胸廓上的肺，负压一没，肺就萎缩了，患者立刻出现呼吸困难。

但真正凶险的不是这一侧肺萎缩，而是纵隔。气体大量涌进这一侧胸腔，因为对侧和它并不连通，这一侧压力就大了，便把纵隔整个推向对侧——这是吸气时的情形；呼气时气体又从这个口子跑出去，胸腔内压力掉下来，纵隔又荡回来。这种一来一回的位移，就叫**纵隔摆动**。

> **易错点**：纵隔摆动严重时刺激迷走神经，可以引起心脏骤停。所以开放性气胸的现场处理，第一步就是赶紧把它变成闭合性气胸，目的正是防止纵隔摆动去刺激迷走神经。

反过来验证一下"左右不通"：正因为两侧不通，这一侧进的气体只折腾这一侧的肺，对侧的肺该通气还通气。要是不通，那就不是这个故事了。

#### 略呈负压

胸膜腔里略呈负压，这个负压是肺能够呼吸的根本原因。

肺本身**没有肌肉**。它自己不收缩也不舒张，那它是怎么扩张的？靠胸廓。胸廓在呼吸肌的带动下一起扩张、一起回缩，把外面的"墙"推开和收回；而肺呢，因为腔内的负压把它牢牢吸附在胸壁上，只能被动地跟着走。胸廓扩，它就被撑开；胸廓缩，它就回缩。这一整套呼吸运动就是这么来的。

所以负压不是结果，是前提。哪天一破坏，比如气胸进去了大气压，负压归零，肺就萎缩。

#### 内有少量浆液

胸膜是浆膜，浆膜的特点就是能分泌浆液，所以胸膜腔内本来就有少量的浆液。

浆液干什么用的？减少肺和胸廓之间的摩擦。它是夹在脏层和壁层之间那层薄薄的润滑液。

量一旦多起来就麻烦了。举例：结核性胸膜炎，产生大量胸水。水多了要占地方，肺被压缩，肺就萎缩了，同样表现为呼吸困难，而且液面越高，呼吸越困难。所以这个胸水一定要把它抽出去，肺才能重新扩张。

那抽胸水在哪儿下针？先考虑液面的高度，再决定穿刺位置，一般情况下是在**肩胛线第 7、8 肋之间**。

肩胛线怎么量？让患者坐在凳子上，双手向后靠到椅背上，这时候肩胛骨就容易摸到了——肩胛冈、肩胛下角都在手上。肩胛下角对应第几肋？第 7 肋，往下就是第 8 肋。所以在第 7、8 肋之间、肩胛线上穿刺，把水抽出来，肺就重新扩张了。

### 胸膜的三处隐窝

壁层胸膜在不同部位之间相交接的地方，会留下一些陷入的盲腔，这就是隐窝。

一共三处，看两张图就够了。

```text
  矢状面：肋膈隐窝       矢状面：膈纵隔隐窝     水平面：肋纵隔隐窝
  ┌──────────────────┐     ┌──────────────────┐     ┌──────────────────┐
  │      肋胸膜      │     │     膈           │     │    肋胸膜        │
  │   │              │     │                  │     │      │           │
  │   │      肺      │     │  纵隔│    肺     │     │  ┌───┴───┐       │
  │   │              │     │       │          │     │  │  肺   │       │
  │      膈胸膜      │     │  膈胸膜│         │     │  └───┬───┘       │
  │     肋膈隐窝     │     │  膈纵隔隐窝      │     │   纵隔胸膜       │
  │                  │     │                  │     │  肋纵隔隐窝      │
  └──────────────────┘     └──────────────────┘     └──────────────────┘
                           右侧为直角，无隐窝
```

读图三处：肋胸膜与膈胸膜相交形成**肋膈隐窝**；左侧膈胸膜与纵隔胸膜之间形成**膈纵隔隐窝**（右侧这两层是直角相交，没有隐窝）；水平面上肋胸膜与纵隔胸膜之间形成**肋纵隔隐窝**，左右两侧都有。

> **结论**：三处隐窝里，最要记住的是**肋膈隐窝**（也叫膈肋窦）。它有两个不可替代的特点：第一，它是胸膜腔最低的位置，腔内只要有一点积液或积脓，最先积存的就是它；第二，吸气的时候肺的下缘也伸不进这个隐窝里去。所以它是全身最容易存积液的部位。

胸膜腔积液的过程，在片子上一眼就能看出来：液体先积在肋膈隐窝，然后逐渐向上移动；液面越高，患者呼吸越困难。

### 肺与胸膜下界的体表投影

这一节临床上用得最多——抽胸水定位要靠它，体检听诊定位也要靠它。

三条线，各量各的：

- **锁骨中线**：从前方看，锁骨、胸大肌、胸廓、肋弓都在视野里，以锁骨中线为准；
- **腋中线**：从侧面看，腋窝前后皱襞之间作一条垂线，就是腋中线；
- **肩胛线**：从后方看，以后正中线、肩胛骨、肩胛冈为参照，这条线叫肩胛线。

在三条线上分别看肺下界和胸膜下界与第几肋相交：

| 体表线 | 肺的下界 | 胸膜（壁层）的下界 |
| --- | --- | --- |
| 锁骨中线 | 第 6 肋 | 第 8 肋 |
| 腋中线 | 第 8 肋 | 第 10 肋 |
| 肩胛线 | 第 10 肋 | 第 11 肋 |

> **易错点**：三条线上都是胸膜下界比肺下界低。记的时候可以偷个懒——"6、8、10"是肺，"8、10、11"是胸膜，数字是错开的。

### 泌尿系统：四个器官，一条通路

换一套系统。泌尿系统由四大部分组成，从上到下正好是一条通路：

| 器官 | 功能 |
| --- | --- |
| 肾 | 泌尿器官，尿液在这里生成 |
| 输尿管 | 输送尿液 |
| 膀胱 | 储尿器官，暂存尿液 |
| 尿道 | 排尿器官，尿液排出体外 |

尿液在肾里生成，经输尿管向下输送，暂存在膀胱，最后通过尿道排出体外。四个环节，缺一不可。

这一节我们只讲第一个——肾。

### 肾的形态：蚕豆型与三个关键词

看腹部标本，腹后壁上紧贴着两个器官，那就是肾；肾的上端还顶着一个腺体，叫肾上腺。

从外形上看，肾脏很像蚕豆，所以我们说它是**蚕豆型**。它的方位术语特别好记，三句就够：上下叫**端**（上端、下端），前后叫**面**（前面、后面），内外叫**缘**（内缘、外缘）。

在形态这一部分，有三个概念必须重点掌握：**肾门**、**肾蒂**、**肾窦**。一个一个来。

#### 肾门

肾的内缘中部有一个凹陷，这个部位叫肾门。

为什么叫"门"？因为有结构在那里进出。内缘中部的排列有一条规律：

| 排列方向 | 由前向后 / 由上向下依次为 |
| --- | --- |
| 从前向后 | 静脉 → 动脉 → 输尿管 |
| 从上向下 | 动脉 → 静脉 → 输尿管 |

也就是说，在**前方**出入的是肾静脉，静脉**后方**是肾动脉，动脉**再往后**才是输尿管。

> **易错点**：这两个顺序一定要分开记。别把"前静脉后动脉"和"上动脉下静脉"混成一团——讲的就是同三根管子，只是换了个观察方向。

#### 肾蒂

出入肾门的这些结构，被结缔组织包裹、包到一起，就形成了肾蒂。

#### 肾窦

把肾剖开，会发现里面有很多空腔。这个腔隙是**肾实质围成的**，所以叫肾窦，开口正好对着肾门。

那为什么你拿一个肾来却看不到这个腔？因为它被出入肾脏的这些结构和大量脂肪组织填满了。只有把这些结构和脂肪组织都剥开，肾窦才露得出来。

> **结论**：肾门是出入口，肾蒂是把出入口打包，肾窦是被肾实质围出来的那个内腔。三者说的是同一片区域的不同侧面——**没有肾窦这个腔，这些结构根本不可能在这里出入**。

### 肾的位置：左高右低

肾紧贴腹后壁，左右各一，高度不一样。

- **左肾**：上端约平第 11 胸椎下缘，下端约平第 2、3 腰椎之间；
- **右肾**：上端约平第 12 胸椎上缘，下端约平第 3 腰椎上缘。

一句口诀：**左高右低**。

为什么右肾低？因为右边有肝脏，肝右叶肥大而厚，把右肾往下顶了；左边没有肝脏挡着，位置就偏上。

第 12 肋与两肾的关系也不同：第 12 肋斜跨**左肾的中部**，斜跨**右肾的上部**。原因还是两肾位置不一样。

前面的毗邻关系，左肾一侧的脏器比较多：

- 两肾的**上端**都邻接肾上腺；
- **左肾**外侧缘邻脾脏，内侧上部邻胃，中段邻胰，下方一部分邻空肠和结肠；
- **右肾**前方内侧缘有一"C"字形区，与十二指肠相贴；大部分外侧缘与肝脏相贴；下方一小部分与结肠相贴。

### 肾门的体表投影

肾门在体表的投影怎么找？先在体表定出两个标志。

第一个标志：脊柱两侧有两条长带状的肌肉，叫**竖脊肌**。第二个标志：横在竖脊肌上方的第 12 肋。

把竖脊肌的外缘和第 12 肋画出来，两者相交的那个**交角**，就是肾门的体表投影位置。

> **结论**：从这张图上就能看出，两个肾和第 12 肋都有斜跨关系。所以临床上检查肾区有没有叩击痛，实际敲的就是**第 12 肋**——通过敲击震动肾脏，如果肾脏有炎症，病人就会疼。敲击点就在竖脊肌外缘与第 12 肋交角处。

### 肾的三层被膜

肾的外周包着三层被膜，由内到外一层一层来。

**第一层，肾纤维膜。** 直接贴在肾实质表面。取一个新鲜的肾，用刀划开一个口，就能把一层膜掀起来——这就说明肾实质外面确实有膜。这层膜**坚硬致密**，而且很容易剥离：一划开就能剥下来。临床上做**肾段切除**的时候，最后一定要把这层外边的膜缝好。

它的成分是致密的结缔组织加上弹性纤维，共同构成。

**第二层，肾脂肪囊。** 纤维膜的外侧有大量脂肪组织围着肾脏，这层叫肾脂肪囊，也叫**肾床**。

**第三层，肾筋膜。** 脂肪囊再往外，又有一层膜，从前方包绕、从后方也包绕，这叫肾筋膜。它分为两层：前面一层叫**肾前筋膜**，后面一层叫**肾后筋膜**。肾筋膜上还发出很多结缔组织的小梁，穿过脂肪囊一直连到纤维膜上，这些小梁对肾脏起固定作用。

```text
                脊柱、腹主动脉、下腔静脉
                          │
             ┌────────────┴────────────┐   ← 肾前筋膜 / 肾后筋膜
             │      肾脂肪囊           │
             │   ┌─────────┐           │
             │   │ 肾纤维膜 │          │
             │   │  肾实质  │          │
             │   └─────────┘           │
             └────────────┬────────────┘
                  内侧开口  外侧缘两层愈合
```

读图：由外向内是肾筋膜（肾前筋膜、肾后两层）、肾脂肪囊、肾纤维膜、肾实质。筋膜的上端**附着在膈肌的下方**，然后贴着腹壁往下走。

肾筋膜还有两个特点，得记住：

- 在肾的**外侧缘**处，肾前筋膜和肾后筋膜**愈合在一起**；在肾的**上端**，前后两层也愈合；
- 在肾的**下端和内侧**，两层是**开放的**。

这两条一对照，很多事就通了：肾动脉由腹主动脉发出分支要变成肾动脉进入肾，肾静脉也要通过这两层之间进出——内侧和下端是开放的，所以它们进得来；输尿管要从肾盂下来，经这两层之间一路下行到盆腔的膀胱，同样进得来。**假如这两层在下端和内侧也封闭了，输尿管就下不来了。**

至于为什么开放与不开放要分清楚，有一个特别生动的例子：膈肌是随呼吸运动上下移位的，肾筋膜附着在膈肌下方，那它自然也随呼吸上下动。临床上做**肾脂肪囊封闭**（往脂肪囊里打药），或者过去检查肾损伤做的**脂肪囊充气造影**（往里打气），都会碰到这层会动的膜——

怎么知道针扎到脂肪囊里了？先穿透腹壁，有落空感，就把针停住，然后让患者**深呼吸**。此时针柄会跟着上下摆动：腹壁是支点，膜在上下动，针尖已经穿透这层膜，针柄当然跟着动——这就证明针已经在脂肪囊里了。

反过来，如果进针时觉得"好像扎在一块硬橡皮上"，那实际扎到哪儿了呢？是**肾脏**。这时候只能退针，然后让他呼吸，看针柄是否摆动来判断。

### 肾的剖面：管腔部与实质部

把肾剖开，里面的东西分成两大块：一块是**管腔部**，一块是**实质部**。

先看管腔部。从下往上：最下面是输尿管，往上膨大的一段是**肾盂**，再往上分成许多小的腔隙，叫**肾小盏**；两个肾小盏汇合，形成一个大的腔，叫**肾大盏**。几个肾大盏再汇合到最大的那个腔，就是肾盂，然后接输尿管。

这套管腔有个用途：如果做**肾脏逆行造影**，造影剂就能充盈到这些腔隙里，在 X 光下看到的影像就是这样一个"小盏—大盏—肾盂"的形状，其他结构都看不到。所以**肾盂造影能看到的，就是这一套管腔**。

再看实质部。注意每一个肾小盏都环绕着一个**锥体状**的结构，这个叫**肾锥体**。锥体的底呈三角形，锥体的尖端叫**乳头**；肾小盏的空腔正好环绕乳头，呈一个环状的腔隙。再往外看，这部分肾实质就叫**肾皮质**。

```text
  ┌──────────────────────────────────┐
  │       肾皮质（最外一圈）         │
  │    ^   ^          ^   ^          │
  │    ^   ^          ^   ^          │
  │   /|\ /|\        /|\ /|\         │
  │   / | \ |        / | \ |         │ ← 肾锥体（底面三角形）
  │   \_|_/ \_|     \_|_/ \_|        │ ← 锥体尖 = 乳头（被小盏环抱）
  │    ( )  ( )      ( )  ( )        │ ← 肾小盏
  └──────────────────────────────────┘
        皮质最外一圈 = 肾皮质
        锥体之间填充的皮质柱 = 肾柱
        肾锥体 + 肾柱 = 肾髓质

管腔部：肾小盏 → 肾大盏 → 肾盂 → 输尿管
```

归纳一下：肾的剖面最外侧那一圈是**肾皮质**；锥体状的结构是**肾锥体**，锥体之间夹着的皮质叫**肾柱**；肾锥体加肾柱，构成**肾髓质**——皮质加髓质，就是肾的**实质**。管腔部则是肾小盏、肾大盏、肾盂。

最后顺一遍尿液的走向：尿液在皮质内产生，经过肾锥体流入肾小盏，再经肾大盏汇入肾盂，然后进入输尿管。

肾的解剖就讲到这里，输尿管、膀胱、尿道留到后面再接着讲。
