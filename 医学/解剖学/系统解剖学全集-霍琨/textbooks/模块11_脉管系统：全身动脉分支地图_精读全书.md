## 动脉的路：从主动脉弓捋到指尖的按压点
> 对应块：BLK28 | 覆盖分集：P37 | 块标题（分集名）：《38.脉管系统Ⅲ》

动脉这一讲我们分两股走。前面是短的那条——肺循环的动脉，就那么点东西，加一根容易被漏掉的动脉韧带；后面是长的那条，从主动脉一路往下捋：颈总动脉、锁骨下动脉、腋动脉、肱动脉，一直到前臂的桡、尺动脉和手掌里的两个血管弓。

这条路捋完，咱们把两个问题交回来：摸脉点在哪儿，止血点在哪儿。

### 先走短的那条：肺循环的动脉

肺循环的动脉，抓住三点就够了——肺动脉干的位置在哪、它起自哪里又分成几支、以及一个叫动脉韧带的结构。

位置上，肺动脉干在心包内，在升主动脉的**左前方**。这两个挨得极近，在心脏解剖图上并排摆着，一眼就能认。

```text
   右心室
      │
      └──→ 肺动脉干（心包内，位于升主动脉的左前方）
                 │
                 ├──→ 左肺动脉
                 └──→ 右肺动脉

   动脉韧带：主动脉弓下缘 ←── 结缔组织索 ──→ 左肺动脉根部
              胚胎时期为动脉导管，闭锁后成为此索
```

走行上，肺动脉起自**右心室**。左右肺动脉的分叉位置是要考的——它是在主动脉弓的**下方**分成左右两支的。

至于动脉韧带：主动脉弓下缘和左肺动脉根部之间连着一条结缔组织索，这就是动脉韧带。它在胚胎时期是动脉导管，出生后动脉导管闭锁，就留下了这么一条索。

> **提示**：韧带的位置一旦记牢，"胚胎期是动脉导管、闭锁后成为韧带"这句话就自动跟上了，不用单独背。

### 主动脉：起于左心室，分升、弓、降三段

体循环的动脉从主动脉讲起。主动脉要抓的也是三件事：起始、分布、分支。

先看位置。脊柱前方这一根大血管就是主动脉，它的起始端起自**左心室**。从左心室出来以后先向上升，再向左后弯曲，最后向下降——这一升、一弯、一降，就把它切成了三段：升主动脉、主动脉弓、降主动脉。

```text
                    左心室
                      │
                      ▼
                  升主动脉   ← 根部三窦：左窦→左冠状动脉
                      │        右窦→右冠状动脉（后窦无开口）
                  主动脉弓   ← 头臂干 · 左颈总动脉 · 左锁骨下动脉
                      │
                  降主动脉
                      │
              ┌───────┴───────┐
              胸主动脉 腹主动脉   ← T12 主动脉裂孔处被膈分开
                           │
                     左右髂总动脉
```

> **易错点**：升主动脉的根部形成三个窦——左窦、右窦、后窦；**只有前两个窦有动脉开口**，后窦没有。记住这一点，下一节冠状动脉就顺下来了。

降主动脉在**第12胸椎水平**穿过膈的主动脉裂孔，被膈分成胸、腹两段：上面这段叫胸主动脉，下面这段叫腹主动脉。往下到末端，分成左右两个髂总动脉。

### 主动脉的分支

三段都有分支，但轻重不同：升主动脉和主动脉弓的分支点不多，重点在降主动脉。

#### 升主动脉与主动脉弓：两支冠状动脉，三支弓上分支

升主动脉的分支就两个——**左冠状动脉**和**右冠状动脉**，分别起自左窦和右窦。根部三个窦里，后窦没有开口，所以也只有两支。

主动脉弓上有三个较大的分支，从右向左依次是：**头臂干、左侧颈总动脉、左侧锁骨下动脉**。

#### 胸主动脉

胸段分支就三类，按发出的位置记：

| 分支 | 发出部位 | 去向 |
|---|---|---|
| 支气管动脉 | 两侧 | 伴随左右主支气管进入肺，营养肺的主要动脉 |
| 食管动脉 | 前壁的许多小支 | 到食管 |
| 肋间动脉 | 后壁 | 下十对 |

> **提示**：最容易混的是前壁那一堆小支——它们不是肋间动脉，是**食管动脉**。肋间动脉是成对的，从后壁出来，一共下十对。

#### 腹主动脉

腹段的分支明显多起来，而且**自上而下有个固定顺序**，顺着念就不容易乱。先说不成对的，再穿插在其中的成对支：

| 自上而下 | 分支 | 成对情况 |
|---|---|---|
| 1 | 膈下动脉（到膈肌） | 成对 |
| 2 | 腹腔干，又叫腹腔动脉 | 不成对短干 |
| 3 | 肾上腺中动脉 | 成对 |
| 4 | 肠系膜上动脉 | 不成对 |
| 5 | 肾动脉 | 成对 |
| 6 | 睾丸动脉（女性叫卵巢动脉） | 成对 |
| 7 | 肠系膜下动脉 | 不成对 |
| 8 | 骶正中动脉 | 不成对 |
| 后壁 | 腰动脉 | 四对 |

> **结论**：不成对的是腹腔干、肠系膜上动脉、肠系膜下动脉、骶正中动脉这四支，其余全成对。这一条对上了，腹段的分支基本就有个底了。

> **提示**：膈下动脉是从主动脉裂孔下方**向上**发出的，走的方向和主流相反，别以为它也是往下顺次排下去的。

### 颈总动脉：左右起点不一样

颈总动脉要抓四点：起始、位置、分支，外加摸脉点和止血点。

先说最容易被人说反的那一条——**左右两侧的起点不一样**：

- **左侧**颈总动脉直接起自**主动脉弓**；
- **右侧**颈总动脉起自**头臂干**。

```text
   主动脉弓
      ├─ 头臂干 ──→ 右颈总动脉
      ├─ 左颈总动脉
      └─ 左锁骨下动脉
```

> **易错点**：为什么左右不一样，看一眼弓上的三个分支就明白了——主动脉弓只给了头臂干、左颈总动脉、左锁骨下动脉三支，右颈总动脉没有单独的弓上分支可挂，只能从头臂干下面分出来。

位置上，颈总动脉起始在**胸锁乳突肌的深面**，又在**甲状腺的深面**，沿着喉、气管、食管的外侧往上走。走到**甲状软骨上缘**水平就分叉了，分出一个颈外、一个颈内——所以它的主干就是这一段。

```text
   颈总动脉干
   （胸锁乳突肌深面 · 甲状腺深面）
        │  沿喉、气管、食管的外侧上行
        ▼
   甲状软骨上缘 —— 此处分叉
        ├──→ 颈外动脉
        └──→ 颈内动脉
```

摸脉点、止血点，就在**胸锁乳突肌前缘的中点**这个部位，正好能摸到动脉的跳动。

### 颈外动脉：分支繁多，重点记这几条

颈外动脉的重点全在分支上。走行倒简单：从颈总动脉分出后上行，在**下颌支的深面**走，到颞部成为终支——**颞浅动脉**。

分支里也有"这个大家不用记"的，比如颧眶动脉；颞中动脉、颞深前后动脉、颊动脉、面横动脉这些是细支，知道有就行。但下面这几条必须记住：

| 动脉 | 分布范围 | 备注 |
|---|---|---|
| 颞浅动脉 | 额部、顶部、颞部的软组织 | 颈外动脉的终支 |
| 上颌动脉 | 外耳道、硬脑膜、颊肌、牙齿、牙龈、咀嚼肌、腭、腭扁桃体 | 营养范围很广 |
| 脑膜中动脉 | 硬脑膜 | 上颌动脉发出的最重要的一支，在翼点内侧 |
| 面动脉 | 面部软组织 | 绕过下颌骨下缘、过口角与鼻翼，到眼内眦 |
| 舌动脉 | 舌、舌下腺、腭扁桃体 | |
| 甲状腺上动脉 | 甲状腺、喉 | 后面还会和另一条对上 |

面动脉自己还发出扁桃体支和腭升动脉。另外还有耳后动脉、枕动脉、咽升动脉、颏下动脉，以及上颌动脉发出的下牙槽动脉（从颏孔出来）。

> **提示**：脑膜中动脉是这一块最爱考的点——它不是颈外动脉直接发出的，而是**上颌动脉**在翼点内侧发出的那一支。

颈外动脉的摸脉点、止血点有两个，都要记：**颞浅动脉**在耳屏的前上方；**面动脉**在咬肌前缘与下颌骨下缘的交界处。

### 颈内动脉：颈部这一段没有分支

颈内动脉这里只提一个特点：**颈部无分支**。

它从颈总动脉分出后一直垂直上升，通过颅底的**颈动脉管**进入颅腔，分布到脑和视器。至于更细的分支和分布，神经系统那一讲再展开，这里不占时间。

> **提示**：颈部无分支——这是它最好认的一个特点，也是和颈外动脉最直接的对照。

### 锁骨下动脉：第一肋外缘是分水岭

锁骨下动脉从哪到哪：起点在**胸锁关节**，从这里呈弓状向外弯曲，止于**第一肋外缘**。

> **定义**：第1肋外缘以下就续接腋动脉了；只有第1肋外缘到胸锁关节之间这一段弓形，才叫锁骨下动脉。这个分界线记住了，腋动脉的长短就不会记错。

分支里，重点要记三条。

#### 椎动脉：从横突孔一路钻上去

椎动脉向上**穿过六个颈椎的横突孔**，再穿**枕大孔**进入颅腔，分布到脑和脊髓。

#### 胸廓内动脉：贴着肋软骨内面往下走

胸廓内动脉在第1到第6肋软骨的后方往下走。分布区记住四处：**胸前壁、心包、膈肌、乳房**。

#### 甲状颈干与肋颈干：甲状腺的另一路来血

甲状颈干是个短干，发出**甲状腺下动脉**、颈升动脉、颈横动脉、肩胛上动脉。其中**甲状腺下动脉**要记住。

肋颈干发出颈深动脉和**最上肋间动脉**（也就是第1肋间动脉）；它的升支再分成两支，分别走在第1肋间和第2肋间，形成肋间后动脉。

到这里可以问一问了——**甲状腺的血液供应，应该有几路？**

| 来源动脉 | 从哪来 |
|---|---|
| 甲状腺上动脉 | 颈外动脉 |
| 甲状腺下动脉 | 甲状颈干 |

> **结论**：答案是**两路**，一上一下。上路是颈外动脉发出的甲状腺上动脉，下路是锁骨下动脉的甲状颈干发出的甲状腺下动脉。名字叫"上""下"，来源却挂在两棵完全不同的动脉树上。

### 腋动脉：胸小肌把它分成三段

腋动脉的位置好记：从**第1肋外缘**往下走，在**胸小肌的深面**下行，到**大圆肌下缘**为止——这一段就是腋动脉。

```text
   第1肋外缘 ← 锁骨下动脉的终点
        │
        │  （在胸小肌的深面下行）
        │
   ┌────┴──────────┐
   │     腋动脉    │  胸小肌（三角形）把它分成三段
   │ (1) 胸小肌上    │  胸上动脉 · 胸肩峰动脉
   │ (2) 胸小肌后    │  胸外侧动脉
   │ (3) 胸小肌下    │  肩胛下动脉 · 旋肱前、后动脉
   └────┬──────────┘
        │
   大圆肌下缘 ← 肱动脉的起点
```

> **易错点**：起点是锁骨下动脉的终点（第1肋外缘），终点是肱动脉的起点（大圆肌下缘）——两头都卡在别人的节点上，别把大圆肌下缘记成胸大肌下缘。

分支一条条看：

- **胸上动脉**——在第1肋间和第2肋间各发一支，形成肋间后动脉。
- **胸肩峰动脉**——到胸小肌、胸大肌、肩峰、三角肌，分布区清一色是肌肉和关节。
- **胸外侧动脉**——在三角肌外侧缘的深面发出，到胸小肌、胸大肌和前锯肌。
- **肩胛下动脉**——这段较粗，它再发出**胸背动脉**和**旋肩胛动脉**。
- **旋肱前动脉与旋肱后动脉**——两者相互吻合。

这一段的分支了解一下就行，重点在下一段。

### 肱动脉：臂部肌肉和肘关节全靠它

肱动脉从**大圆肌下缘**开始，起初走在肱骨的**内侧**，转到**肱骨下三分之一的前方**下降，到**桡骨颈的水平**分成两支：桡动脉和尺动脉。

> **结论**：肱动脉的营养范围就两样——**臂部的肌肉和肘关节**。

它的分支里有几组互相搭上的关系：

| 动脉 | 走行与吻合 |
|---|---|
| 肱深动脉 | 绕过肱骨后方转向前下，与桡侧返动脉吻合 |
| 尺侧上副动脉 | 与尺侧返动脉吻合 |
| 尺侧下副动脉 | 与尺侧返动脉吻合 |
| 尺侧返动脉 | 起自尺动脉，向上与上面两支吻合 |

从尺动脉再往下还出一支**骨间总动脉**，到骨间膜附近分成三路：

```text
   尺动脉 ──→ 骨间总动脉 ─┬─→ 骨间前动脉（骨间膜前方下降）
                          ├─→ 骨间后动脉（骨间膜后方下降）
                          └─→ 骨间返动脉（向上，与骨间前动脉的吻合支相交通）
```

肱动脉的摸脉点、止血点在**肘窝前方**，既摸得到跳动，也压得住血。

### 桡、尺动脉与手掌里的两个血管弓

肱动脉一下去，桡、尺两条动脉各走一边：

- **桡动脉**在前臂桡侧、桡侧腕屈肌的桡侧向下降，经腕部进入手；
- **尺动脉**在尺侧屈肌的深面下降，经腕部进入手。

到腕部，两条动脉各自分成两支：桡动脉分为**终支**和**浅支**，尺动脉也分为**终支**和**深支**。这四支两两一拼，就在手掌里组成了两个血管弓：

```text
   桡动脉浅支 ─┐
                ├──→ 掌 浅 弓
   尺动脉终支 ─┘

   桡动脉终支 ─┐
                ├──→ 掌 深 弓
   尺动脉深支 ─┘
```

其中桡动脉的终支要先绕过桡骨茎突，从第一掌骨的背面绕过去，再经第一掌骨间隙进入手掌，所以它在腕背那一段是贴着骨面走的。

两个弓上各自的分支：

| 血管弓 | 构成 | 主要分支 |
|---|---|---|
| 掌浅弓 | 尺动脉终支 + 桡动脉浅支 | 3 条指掌侧总动脉（各自再分为指掌侧固有动脉）、小指尺掌侧动脉 |
| 掌深弓 | 桡动脉终支 + 尺动脉深支 | 拇主要动脉（再分为拇指桡侧、拇指尺侧动脉）、掌心动脉 |

深、浅两弓之间不是各走各的，**掌心动脉**把两头接上了：

```text
        掌深弓 ──── 掌心动脉 ──── 掌浅弓
           │                           │
       拇主要动脉                 指掌侧总动脉
           │                           │  ↓ 各自分为
     拇指桡、尺侧动脉             指掌侧固有动脉
                                      → 走向每个手指的两侧
```

> **结论**：掌心动脉是深浅两弓之间的交通支，好处很实在——浅弓要是受压了，血液可以绕道深弓到达各指；深弓受压了，也可以绕道浅弓。这就是"手掌不怕压"的解剖基础。

### 指端的止血：一定要压两侧

到这儿把动脉这一段的硬性要求收一收：一是**衔接关系**，谁接谁、谁从哪儿分出来；二是**摸脉点和止血点**都在哪。

其中最要紧的一条，是手指上动脉的走向——**手指的动脉是在指的两端向上走的**。

给大家讲个真事。有一次我到急诊室，一进去就看到机电室的地下全是血。我很好奇，顺着血迹一路找过去，到了机电室——几个工人围在那儿，其中有一个的手指被机器压伤了。另一个工人正在给他压迫止血。

旁边一位老工人说了一句话，挺有意思的。他说："**小张啊，今儿要不照小王这么给你压迫止血，你的血可都得淌光啊。**"

我好奇地凑过去一看，他到底是怎么压的呢？**前后压**。

可血管是走在两侧的呀——应该压两侧才对。前后压压的是哪儿？等于没压，该淌多少就淌多少，一点作用不起。

> **结论**：手指的压迫止血点**一定在两侧**。

那要在腕部压呢？压两处——**桡动脉和尺动脉，两个部位同时压迫**，一个都不能少。

最后把散在各处的按压点归拢成一张表：

| 动脉 | 摸脉 / 止血部位 |
|---|---|
| 颈总动脉 | 胸锁乳突肌前缘中点 |
| 颞浅动脉 | 耳屏前上方 |
| 面动脉 | 咬肌前缘与下颌骨下缘交界处 |
| 肱动脉 | 肘窝前方 |
| 桡动脉、尺动脉 | 腕部，桡、尺两侧同时压迫 |
| 手指 | 手指两侧 |

> **承前启后**：上一节讲完「动脉的路：从主动脉弓捋到指尖的按压点」，下一节接着讲「腹主动脉的分支地图与肝、胰的多源血供」。

## 腹主动脉的分支地图与肝、胰的多源血供
> 对应块：BLK29 | 覆盖分集：P38 | 块标题（分集名）：《39.脉管系统Ⅳ》

动脉这部分我们讲完上半身，这一讲往下走，落在腹部。腹部的动脉不好背，原因是分支太多，而且它不像上肢那样左右对称、好数着背——它的脏支是"成对"和"不成对"混着走的。所以这一讲我们换一种办法：先把整张挂图的后壁摊开，把腹主动脉的分支从上到下一根一根点清楚，再分类；然后把重点压在三个不成对的脏支上，因为这三个才是考试和临床上真正会遇到的；最后倒回来，专门解决两个问题——**肝脏和胰腺的血到底从哪来**。这两个器官一个"扎了主干还能活"，一个"上下两头都有人供血"，搞明白它们，前面那一堆分支名字才算真正长在了身上。

### 腹主动脉在哪：上起主动脉裂孔，下到第四腰椎

先看挂图。这张图把胸壁、腹壁的前壁都打开了，脏器也拿掉了，整张图就为了让你看一件事——**后壁**。

上一讲讲过的胸主动脉，从主动脉裂孔往下这一段，就叫腹主动脉。它的位置记三句话就够：

> **定义**：腹主动脉走行于脊柱前方，上界为主动脉裂孔（相当于第十二胸椎水平），下界为第四腰椎水平——也就是在这一处分叉成左、右髂总动脉。

髂总动脉再往下又分成髂内动脉和髂外动脉，这两个我们先放着，等讲骨盆和下肢的时候再看。

### 分支就两路：壁支和脏支

在挂图上我们把腹主动脉的分支从上往下点一遍。主动脉裂孔稍下方发出一对膈下动脉；再往下有个短干叫腹腔干；接着是肠系膜上动脉；成对发出的是肾动脉；再一对是睾丸动脉；再向下是肠系膜下动脉；后壁还成对发出四对腰动脉，到腹后壁去；最后在分叉处向下发出一个骶正中动脉。

点完这一圈，我们把它们归成两类——**壁支**和**脏支**。

壁支就是到腹壁去的：膈下动脉这一对、四对腰动脉，再加上分叉处向下那一支骶正中动脉。

脏支是到腹腔脏器去的，它又能分成成对和不成对两种。

- **成对的脏支**有三个：肾上腺中动脉、肾动脉、睾丸动脉（女性叫卵巢动脉）。
- **不成对的脏支**有三个：腹腔干、肠系膜上动脉、肠系膜下动脉。

| 类别 | 具体分支 | 数目 |
| --- | --- | --- |
| 壁支 | 膈下动脉 | 1 对 |
| 壁支 | 腰动脉 | 4 对 |
| 壁支 | 骶正中动脉 | 1 条 |
| 成对脏支 | 肾上腺中动脉、肾动脉、睾丸动脉（女性称卵巢动脉） | 各 1 对 |
| 不成对脏支 | 腹腔干、肠系膜上动脉、肠系膜下动脉 | 各 1 条 |

把它按从上到下的顺序画一遍，这张图基本就是腹主动脉的全貌了：

```text
        胸主动脉
           │
           ├── 主动脉裂孔（T12）＝ 腹主动脉上界
           │
           ├── 膈下动脉 ────── 壁支（1 对）→ 膈肌
           │
           ├── 腹腔干 ──────── 脏支（不成对）★ 重点
           │
           ├── 肾上腺中动脉 ── 脏支（成对）→ 肾上腺
           │
           ├── 肠系膜上动脉 ── 脏支（不成对）★ 重点
           │
           ├── 肾动脉 ──────── 脏支（成对）→ 肾
           │
           ├── 睾丸动脉 ────── 脏支（成对）→ 睾丸 / 卵巢
           │
           ├── 腰动脉 × 4 ──── 壁支 → 腹后壁
           │
           ├── 肠系膜下动脉 ── 脏支（不成对）★ 重点
           │
           ├── 骶正中动脉 ──── 壁支，自分叉处向下
           │
           └── 第四腰椎水平：分叉为左、右髂总动脉
                 （再分为髂内、髂外，此处不展开）
```

> **提示**：读这张图的时候，横着看是"名称"，竖着看是"发出的高低顺序"。考试里最爱考的就是顺序——比如问你腹腔干和肾动脉谁高，答案就是腹腔干在肾动脉的近侧。

成对的脏支三个，一分钟就能过。这一讲的重头戏全压在后面三个不成对的脏支上，我们一个一个展开。

### 腹腔干：一厘米的短干，三条分支

腹腔干大约是一个厘米的短干，很短，位置在**十二胸椎稍下方**发出。它为什么这么短？因为它一出来就要分成三大支，腹部的上半个脏器几乎全挂在它身上。

看分支之前，先在挂图上把腹腔的脏器认一遍：这里有一个很大很大的肝，肝上有胆囊切迹；我们把肝略微向上掀开一点。这边应该是胃，胃的下边是十二指肠；这一侧有一个脏器叫脾；在胃的后方，我们还能看到一个长形的脏器，叫胰——这是个腺体。

认完脏器再看血管，三条分支。

#### 脾动脉：最粗大的一支，经脾门入脾

腹腔干第一个分支，发出一个粗大的动脉，沿着胰的上方横行向左，经脾门入脾，所以叫脾动脉。

它自己的分支记三条就够了：

- 向上发出**胃后动脉**和**胃短动脉**，它们都营养胃底部；
- 在胃大弯侧发出**胃网膜左动脉**；
- 其他分支我们先不管。

#### 胃左动脉：沿胃小弯，还捎一根食管升支

第二个分支，向左上方发出一个胃左动脉，沿着胃小弯走；同时还发出一个**食管升支**，到食管的腹段。

#### 肝总动脉：向右上，是这里最绕的一支

第三支向右，叫肝总动脉。它的走法是"一头朝上、一头朝下"，两头都还有分支，所以最绕，我们分着说。

朝上的那一头：

- 肝总动脉向上是**肝固有动脉**；
- 肝固有动脉形成两支，经肝门入肝，分别叫左支、右支；
- 右支发出一个动脉到胆囊，叫**胆囊动脉**。

朝下的那一头：

- 在左右两支的**分界部位**向下发出一个**胃十二指肠动脉**；
- 它在胃和十二指肠的**后方**下降，然后在**十二指肠和胰头之间**分成两支：胰十二指肠上前动脉、胰十二指肠上后动脉；
- 在十二指肠的下部又发出一个**胃网膜右动脉**，和胃网膜左动脉吻合。

另外别忘了**肝固有动脉的根部**还会发出一支，沿着胃小弯走，和胃左动脉吻合——它叫**胃右动脉**。

把整棵树摆开是这样：

```text
腹腔干（T12 稍下方，短干约 1 cm）
├─ 胃左动脉 ──── 向左上方，沿胃小弯走
│                └─ 食管升支 ── 到食管的腹段
│
├─ 脾动脉 ────── 粗大，胰的上方横行向左，经脾门入脾
│                ├─ 胃后动脉 ┐
│                ├─ 胃短动脉 ┴─ 都营养胃底部
│                └─ 胃网膜左动脉 ── 胃大弯侧
│
└─ 肝总动脉 ──── 向右
     ├─ 向上 ─→ 肝固有动脉
     │           ├─ 根部发出：胃右动脉 ── 沿胃小弯，与胃左动脉吻合
     │           ├─ 左支 ┐
     │           └─ 右支 ┴─ 经肝门入肝
     │                    └─ 胆囊动脉
     │
     └─ 向下 ─→ 胃十二指肠动脉（胃与十二指肠后方下降）
                 ├─ 在十二指肠与胰头之间分成两支：
                 │    胰十二指肠上前动脉
                 │    胰十二指肠上后动脉
                 └─ 十二指肠下部 ─→ 胃网膜右动脉
                                    （与胃网膜左动脉吻合）
```

> **易错点**：胃网膜左动脉和胃右动脉，一个来自脾动脉，一个来自肝固有动脉根部——分属两大分支，千万别在画图时挂到同一根上；而胃网膜**右**动脉来自胃十二指肠动脉，不是来自肝固有动脉。

### 如果肝总动脉被误扎，肝脏会不会坏死

分支讲完，我们做一个假设，这个假设不是好玩，是临床天天要面对的。

营养肝脏的动脉，是不是有腹腔动脉 → 肝总动脉 → 肝固有动脉 → 左、右支进入肝？如果肝总动脉在手术中**误扎**了，你们说肝脏能不能坏死？也就是肝脏还有没有血过去？

所以这块大家要注意**吻合支**的情况。

你看这个血管扎住了以后，血确实过不来了——可是可不可以绕过去？走**胃左**和**胃右**进入肝固有动脉？答案是可以。

> **结论**：肝总动脉被结扎后，肝脏一般不会坏死，因为血有两条绕行路线：
> - **小弯侧**有吻合——胃左动脉 ↔ 胃右动脉 ↔ 肝固有动脉；
> - **大弯侧**也有吻合——胃网膜右动脉 ↔ 胃网膜左动脉。

> **提示**：这就是吻合支的临床意义——记住一句话：**血管扎住了，血并不是真的过不来，它绕得过去**。以后讲四肢、盆腔的动脉，凡是碰到"某干被结扎会不会怎样"的问题，先去找吻合支。

### 肠系膜上动脉：第一腰椎，管到横结肠

第二个不成对的脏支，肠系膜上动脉。它发起的位置在**第一腰椎水平**，由腹主动脉的主干发出来。重点还是看分支。

看分支之前，我们先把腹腔里边的肠管点一遍，脑子里得有这个"地图"，才知道哪根血管管哪一段肠子：升结肠；这个是盲肠，盲肠下方有阑尾；这里是回肠的末段，切断了；然后我们看横行、向左的这一段肠管，叫**横结肠**；再继续向下是**降结肠**、**乙状结肠**，最后是**直肠**和下方的**肛管**。

好，现在问一句：这些肠管分别有哪些动脉营养？

从肠系膜上动脉本身数下来，一共四组主要分支：

- **小肠动脉**：发出很多很多分支，沿小肠系膜两层之间走，分布到小肠——就是空肠和回肠；
- **回结肠动脉**：与它相并行的还有一支，它发出一支分布到阑尾，这个就叫**阑尾动脉**；
- **右结肠动脉**：在这个主干上发出，向右，分成一个降支、一个升支；
- **中结肠动脉**：靠近根部的地方发出，分成一个右支、一个左支。

此外，从动脉弓上还会再发出**直支**分布到肠管。

那么它影响哪一部分肠管？我们用虚线画一下——这一整段都是肠系膜上动脉的营养范围：阑尾、盲肠、升结肠，一直到横结肠。

### 肠系膜下动脉：第三腰椎，管到直肠上三分之二

第三个不成对的脏支，肠系膜下动脉，大约在**第三腰椎水平**发出来。

它的分支是三根：

- **左结肠动脉**：升支和降支各自去和乙状结肠动脉吻合，然后发出直支分布到肠管；
- **乙状结肠动脉**：发 2~3 支；
- **直肠上动脉**。

它营养哪些范围？我们还是点一下：直肠上 2/3、乙状结肠、降结肠，以及脾曲（横结肠的脾曲）这一片区域，都是肠系膜下动脉来营养。

> **注意**：直肠下 1/3 它不管，最底下的肛管它也不管。所以它的营养范围就卡在这两条线之间。肠系膜上、下动脉在"横结肠"这里交接——上动脉管到横结肠，下动脉从脾曲接手。

### 把三个不成对脏支摆在一起看

这一讲最重要的东西，最后可以压成下面这张表。发出的水平、分支、营养范围，三列记住，考场上随便哪一列都能反查另外两列：

| 动脉 | 发出水平 | 主要分支 | 营养范围 |
| --- | --- | --- | --- |
| 腹腔干 | T12 稍下方 | 胃左动脉、脾动脉、肝总动脉 | 胃、肝、脾、胰头、十二指肠上部 |
| 肠系膜上动脉 | L1 | 小肠动脉、回结肠动脉、右结肠动脉、中结肠动脉 | 空肠、回肠、阑尾、盲肠、升结肠、横结肠 |
| 肠系膜下动脉 | L3 | 左结肠动脉、乙状结肠动脉、直肠上动脉 | 脾曲、降结肠、乙状结肠、直肠上 2/3 |

画成势力范围就是这样：

```text
肠系膜上动脉（L1）                 肠系膜下动脉（L3）
   │                                    │
   ├─ 空肠、回肠                        ├─ 脾曲
   ├─ 阑尾                              ├─ 降结肠
   ├─ 盲肠                              ├─ 乙状结肠
   ├─ 升结肠                            └─ 直肠上 2/3
   └─ 横结肠
                                     ————————————
                                     直肠下 1/3、肛管：不在其列
```

分支的名字点完了，接下来我们反过来问两个问题：**肾上腺的血从哪来？胰的血从哪来？** 这两个器官的血供特别有意思，答好了，前面那一堆分支才算落地。

### 肾上腺：三根动脉，三个来源

我们换一张图，把动脉主干重新画一下：这发出一个肾动脉，这一侧也发出一个肾动脉。然后我们把肾脏画上——肾脏的上方突起的这一部分，就叫肾上腺。

现在从头捋一遍。主动脉裂孔稍下方成对发出的那一支壁支，是**膈下动脉**；膈下动脉记住它还会发出一个小的分支，叫**肾上腺上动脉**。讲腹主动脉主干的时候我们提过一支成对的**肾上腺中动脉**，它就直接从主干发出来。还有一支是**肾动脉**，肾动脉还会发出一支也到肾上腺，这叫**肾上腺下动脉**。

所以营养肾上腺的是几个动脉？三个。

> **结论**：肾上腺的血液供应有三个来源——**上来自膈下动脉，中来自腹主动脉，下来自肾动脉**。

| 动脉 | 来源 |
| --- | --- |
| 肾上腺上动脉 | 膈下动脉 |
| 肾上腺中动脉 | 腹主动脉（主干直接发出） |
| 肾上腺下动脉 | 肾动脉 |

### 胰腺：胰头两个来源，胰体胰尾一个来源

最后一个器官，胰。先把胰腺回忆一下，分几部分：胰头，这是钩突，胰体，胰尾。

然后我们看动脉，先从脾动脉这条线说起。腹腔干发出了一支沿胰上缘向左走的脾动脉，进入脾门。脾动脉向上我们已知有两个小分支——胃后动脉和胃短动脉；向下发出一个胃网膜左动脉——那三条不算胰的血供，别混进来。

脾动脉还有哪些分支是给胰的？从脾动脉上有一支分支进入胰体，叫**胰背动脉**；这儿还发出一个叫**胰大动脉**，它和胰背动脉相互吻合，形成**胰下动脉**；同时还发出很多很多小支，叫**胰支**，都到了胰体和胰尾。

所以胰体和胰尾这一段，是脾动脉的分支在营养。

那胰头呢？胰头是**两个来源**。一个是**胃十二指肠动脉**下来的：肝总动脉 → 肝固有动脉 → 胃十二指肠动脉，胃十二指肠动脉发出两支，一支沿着胰头前方下降，另一支沿着胰头后方下降，这两支互相吻合，它们合起来就是**胰十二指肠上动脉**的前、后两支。

另一个是**肠系膜上动脉**来的：肠系膜上动脉有两个分支是从**钩突那块穿出来的**，一支沿着胰头的前方向右上方去，一支在它的后方向上去，都营养胰头，这就是**胰十二指肠下动脉**的前、后两支。

同时呢，脾动脉的分支和它们也吻合。

```text
胰腺
├─ 胰头（+ 钩突）── 两个来源
│    ├─ 胃十二指肠动脉 → 胰十二指肠上前动脉
│    │                  胰十二指肠上后动脉
│    └─ 肠系膜上动脉  → 胰十二指肠下前动脉
│                       胰十二指肠下后动脉
│        （两组相互吻合，脾动脉的分支也参与吻合）
│
└─ 胰体、胰尾 ── 一个来源：脾动脉
     ├─ 胰背动脉
     ├─ 胰大动脉
     ├─ 胰下动脉（由胰背、胰大相互吻合形成）
     └─ 胰支（很多很多小支）
```

> **结论**：胰头来自**两个来源**——胃十二指肠动脉（上）和肠系膜上动脉（下）；胰体、胰尾来自**一个来源**——脾动脉，其中胰下动脉是由吻合支形成的。

腹部的动脉，我们就记住这么几个不成对脏支的重要分支，同时把最后这几个重要脏器的血液供应来源搞清楚。这一讲就到这里，下节课见。

> **承前启后**：上一节讲完「腹主动脉的分支地图与肝、胰的多源血供」，下一节接着讲「从腹主动脉到脚趾：盆部与下肢的动脉」。

## 从腹主动脉到脚趾：盆部与下肢的动脉
> 对应块：BLK30 | 覆盖分集：P39 | 块标题（分集名）：《40.脉管系统Ⅴ》

这一讲接着讲动脉的第三部分——盆部和下肢的动脉。挂图一摊开，腹主动脉就在腹部正中贴着椎体往上走，这条主干我们已经很熟了。今天就从它身上分出来的第一对分支开始，一路走到脚趾。

### 先从第四腰椎分家说起

腹主动脉我们在前面已经讲过了，它走到第四腰椎水平的时候，向左右分出一对**髂总动脉**。这两条走到**骶髂关节的前方**就要分家：一根向内拐进盆腔，盆腔里的东西全归它管，这叫**髂内动脉**；另一根越过盆缘，继续一路向下，成了下肢的主干，这叫**髂外动脉**。

```text
              腹主动脉
                 │
        ┌────────┴────────┐
        │                 │
     髂总动脉          髂总动脉
        │                 │
   ┌────┴────┐       ┌────┴────┐
   ↓         ↓       ↓         ↓
髂内动脉  髂外动脉  髂内动脉  髂外动脉
 入盆腔   过盆缘   入盆腔   过盆缘
```

读图：腹主动脉在第四腰椎高度一分为二，两条髂总动脉只走很短的一段，就在骶髂关节前方再次分叉，方向决定了分工——向内是髂内，向外下行是髂外。

> **定义**：髂总动脉——自第四腰椎水平（腹主动脉分叉处）至骶髂关节前方的一段，末端分为髂内动脉和髂外动脉。

所以髂总动脉的位置特别好记：**上起第四腰椎，下到骶髂关节前方**。这一段本身不长，名字却最长，后面要学的两条主干都是从它身上分出来的。

### 髂内动脉：一份给盆壁，一份给脏器

髂内动脉的分支不用全背，但要分清它送的是**两拨人**：一拨送到盆壁（肌肉、骨盆壁面），一拨送到盆腔里的脏器。

对照挂图上的男性盆腔正中矢状断面，髂内动脉发出的东西一眼就能看到：臀上动脉、臀下动脉、骶外侧动脉属于壁支，前方的闭孔动脉也是壁支；除此之外还有往脏器去的，比如到膀胱去的、到直肠去的。换成女性盆腔正中矢状断面，壁支照样在，另外还多出一根专门到子宫去的动脉，以及到会阴部去的。

整理成一张表：

| 类别 | 分支 | 说明 |
|---|---|---|
| 壁支 | 臀上动脉、臀下动脉 | 到臀肌去 |
| 壁支 | 髂腰动脉、骶外侧动脉、闭孔动脉 | 到盆壁去 |
| 脏支 | 膀胱上动脉、膀胱下动脉 | 到膀胱去 |
| 脏支 | 子宫动脉 | 到子宫去 |
| 脏支 | 直肠下动脉 | 到直肠去 |
| 脏支 | 阴部内动脉 | 到会阴部去，并发出肛门动脉 |

这张表的用途是**认名字**，不是背细节——名字在挂图上先混个脸熟就够了，这一块我们不展开。

#### 子宫动脉：三根支，还有不到两厘米的一道坎

这里我们把子宫的血供单独拎出来讲。看挂图：中间是子宫体，下方环绕它的是阴道；两侧向外一牵拉，输卵管连着输卵管伞展开成菊花瓣状的结构；再外面是扁卵圆形的卵巢，卵巢有固有韧带，另一头还有从盆侧壁下来的悬韧带。

子宫动脉的走法是：沿着盆壁下来，然后**横行向内迂曲**，到**子宫颈的两侧**，在这里分成升支和降支。升支又发出三根支：

```text
髂内动脉
   │  沿盆壁下行 → 横行向内迂曲
   ▼
 子宫颈两侧
   ├── 升支 ──┬── 输卵管支（沿输卵管走）
   │          ├── 卵巢支（经悬韧带下行，与输卵管动脉吻合，再发分支营养卵巢）
   │          └── 阴道支（营养阴道）
   └── 降支
```

三根支各管一摊：**输卵管支**（也叫输卵管动脉）沿着输卵管走；**卵巢支**在悬韧带里下来，和输卵管动脉有吻合，同时还发出分支营养卵巢，相当于给它开了个双保险；**阴道支**向下营养阴道。

> **易错点**：子宫动脉的下方有一条重要的管道通过，就是输尿管。做子宫动脉结扎的时候，止血钳一定要**靠近子宫颈**夹，千万不能远离子宫颈——因为它俩中间只隔了不到两厘米，往外偏一点，就把输尿管误扎了。

#### 直肠与肛管：血供在盆膈处换手

先看挂图：上面是直肠的断端，往下能看到盆膈，盆膈以上叫直肠，以下那一段就是肛管。这两段的动脉来源是不一样的。

**直肠的上三分之二**由**直肠上动脉**供应，而直肠上动脉来自**肠系膜下动脉**——肠系膜下动脉我们已经学过，它发出的这一支一路向下走，专管直肠上段。

**肛管**以及直肠的下段，靠的是**阴部内动脉**。阴部内动脉在盆腔里走行，然后穿盆膈到会阴部去，顺手发出**直肠下动脉**。这段血供有个细节：直肠下动脉**大多数**来源于阴部内动脉，但**也有直接在髂内动脉上分出来**的。此外阴部内动脉还发出一个更小的分支叫**肛门动脉**，专门营养肛管。

> **结论**：直肠上段来自肠系膜下动脉的直肠上动脉，直肠下段和肛管来自阴部内动脉的直肠下动脉与肛门动脉。记住"上段肠系膜下、下段阴部内"这一条，两段就都通了。

### 髂外动脉：真正的过桥段

髂外动脉的位置很干脆：上界就在**骶髂关节前方**（也就是髂总动脉分家的地方），下界是**腹股沟韧带中点的深面**。

它的分支很少，只有两条，而且都不做重点展开：**旋髂深动脉**主要到髂肌和附近的肌肉去；**腹壁下动脉**主要营养腹直肌。

> **定义**：髂外动脉——骶髂关节前方至腹股沟韧带中点深面的一段，穿过盆缘下行，至腹股沟韧带处续接为股动脉。

过了腹股沟韧带，它就不叫髂外了，换了个名字叫**股动脉**。这一段才是我们今天的重点。

### 股动脉：下肢的主干

先定位。股骨的结构先在脑子里过一遍：股骨头、股骨颈、大转子、股骨体、收肌结节、两个侧髁，前面是髌面，后面还有个小转子——这些骨性标志是我们给血管找位置的坐标。

股动脉的起点在**腹股沟韧带中点的下方**，由髂外动脉延续而来；到**腘窝上缘**这一段叫股动脉。所以它的位置范围是：**腹股沟韧带中点 → 腘窝上缘**。

#### 走行：三个必经点

股动脉往下走要过三道关口：

- **先在股三角内下降**（大腿前部那个局部解剖的三角区域）；
- **再穿收肌管**；
- 最后**穿腱裂孔**跑到股骨下端的后方，到这里它就**改名叫腘动脉**了。

#### 分支：一条主干带出五支

分支不算多，名字却容易混。从图上看，股动脉发出的分支如下：

```text
股动脉（腹股沟韧带中点下方接髂外动脉）
  │  走行：股三角 → 收肌管 → 腱裂孔 → 腘窝上缘
  │
  ├─ 旋髂浅动脉
  ├─ 腹壁浅动脉
  └─ 股深动脉（腹股沟韧带下方约 2.5 cm 发出）
       ├─ 穿支 ×3 ──▶ 大腿后群肌、内侧群肌
       ├─ 旋股外侧动脉 ──▶ 大腿前群肌
       └─ 旋股内侧动脉 ──▶ 绕过股骨颈内侧，再发分支到大腿内收肌群
```

读图：股动脉自己发出旋髂浅动脉、腹壁浅动脉，以及一条在**腹股沟韧带下方 2.5 厘米**就分出去的粗支——**股深动脉**。股深动脉才是真正"扎进肌肉里"的一支：它发出**三个穿支**到达股骨后方，供应大腿后群肌和内侧群肌；向上发出**旋股外侧动脉**，营养大腿前群肌；还发出**旋股内侧动脉**，绕过股骨颈的内侧，并另发一小支到大腿的内收肌群。

#### 摸脉与止血

股动脉是这一段最实用的血管——它位置表浅、搏动明显。

> **易错点**：摸脉点是**腹股沟韧带中点的下方**；止血时把手指压向**骨盆的方向**，就能压住这段动脉。

### 腘动脉：膝后正中线上的短段

这一段我简单说一下就行，**大家不用特意去记它**。

腘动脉的主干就在**腘窝的后正中线**上下降。腘窝里能摸到的骨性标志不少：上面是股骨下端的外侧髁、收肌结节、内侧髁和髁间窝，下面是胫骨的髁间隆起、比目鱼肌线，旁边还有腓骨小头——动脉的主干就在这堆骨性标志的后正中线上一路向下。

它发出**五个分支**：膝上外动脉、膝上内动脉、膝下外动脉、膝下内动脉，还有一个膝中动脉。知道有这五个就行。

### 胫前动脉与胫后动脉：小腿的分水岭

腘动脉继续向下走过膝关节后方，就分成小腿的两条主干，分水的标志非常干脆：

```text
髂外动脉
   │
   ▼  腹股沟韧带中点下方
股动脉 ──股三角──▶ 收肌管 ──▶ 腱裂孔
   │
   ▼  腘窝上缘
腘动脉（在腘窝后正中线上下降）
   │
   ├────────── 穿过小腿骨间膜，在小腿前群肌深面下降
   │                        │
   │                        ▼
   │                    胫前动脉
   │                        │
   │            内、外踝前方连线中点
   │                        │
   │                        ▼
   │                    足背动脉
   │                   （弓状动脉→跖背动脉→趾背动脉）
   │                        │
   │                   足底深支 ──► 穿到足底，与足底动脉弓吻合
   │
   └────────── 在小腿后群肌深面下降，绕内踝后方
                            │
                            ▼
                        胫后动脉
                            │
                            ▼
                足底内侧动脉 ＋ 足底外侧动脉
                            │
                            ▼
                       足底动脉弓
                            │
              趾底总动脉 ──▶ 趾底固有动脉
```

读图：这是一张"改名链"全景图。**髂外 → 股 → 腘 → 胫前/胫后 → 足背/足底**，名字一路改，路一直是往下走；胫前与胫后之间还有一条**足底深支**跨过，连着足背和足底。

- **胫后动脉**：在小腿后群肌的深面下行，**经内踝后方转向足底**。
- **胫前动脉**：**穿过小腿骨间膜**，到小腿前群肌的深面下行，一直走到**足背**。

两者之间有吻合，不是各走各的死路。

### 足的动脉：足背一支，足底一弓

#### 足背动脉

胫前动脉往下走到**内踝、外踝前方连线的中点**，就改名叫**足背动脉**了。这个点很浅、位置好认，**摸脉和止血都在这里**——记住这个规律：**两个结构连线的中点**。

它发出的分支有：钻到足底去的**足底深支**；向外走一横的**弓状动脉**；上方还有**跗外侧动脉**、内侧的**跗内侧动脉**，以及**外踝前动脉**、**内踝前动脉**。

弓状动脉上又发出很多分支到各个脚趾去，这一整片合称**跖背动脉**，再往下分成更小的**趾背动脉**。这些小支的名字就不用记了，知道它们是从弓状动脉上分出来的就行。

#### 足底动脉弓

胫后动脉绕过**内踝的后方**转向足底，在这里分成**足底内侧动脉**（还有浅支、深支之分）和**足底外侧动脉**，外侧动脉再往前续接成**足底动脉弓**。

足底动脉弓向下发出**趾底总动脉**，趾底总动脉再分到每个脚趾，就叫**趾底固有动脉**。

另一条路是从上面接过来的：足背动脉发出的**足底深支**穿到足底，与足底动脉弓**吻合**——所以足背和足底本来就是一张网。

> **提示**：内踝的**后方**转到足底的那支动脉，在那里也能摸到搏动，判断位置同样以内踝为准。

### 全身摸脉点与止血点：一次收口

最后我们把全身能摸到动脉搏动的点串一遍。这些点既是**摸脉**的位置，也是**压迫止血**的位置。

#### 头颈部

| 摸脉部位 | 动脉 |
|---|---|
| 耳屏的前上方 | 颞浅动脉 |
| 咬肌前缘与下颌骨下缘的交界处 | 面动脉 |
| 胸锁乳突肌前缘中点 | 颈总动脉 |

三个点从高到低排：耳朵前面是颞浅动脉，下颌角那一块（咬肌前缘和下颌骨下缘交角）是面动脉，脖子侧面那条斜行的胸锁乳突肌，前缘中点摸到的是颈总动脉。

#### 上肢

| 摸脉部位 | 动脉 |
|---|---|
| 肘窝前方 | 肱动脉 |
| 腕部桡侧、尺侧 | 桡动脉、尺动脉 |
| 三角窝窝中点 | 桡动脉终支 |

腕部两侧是最常用的两个点。**别忘了还有一个小地方**：把拳握起来、拇指伸开，腕背会露出一块**三角窝**，窝的中点同样能摸到搏动——那是**桡动脉的终支**。它的走法有点绕：**必须绕过桡骨颈**，转到后侧，再在**第一掌骨间隙**穿到掌侧，最后才到这个窝的中点。

#### 下肢

| 摸脉部位 | 动脉 |
|---|---|
| 腹股沟韧带中点下方 | 股动脉 |
| 腘窝 | 腘动脉 |
| 内、外踝前方连线中点 | 足背动脉 |
| 内踝后方 | 足底动脉（分足底内侧、足底外侧） |

下肢必须记住的第一个点就是**腹股沟韧带**这块。这里还得记一个比邻关系：股动脉的**内侧**是一条重要的静脉叫**股静脉**，**外侧**是一个神经叫**股神经**。由内向外排就是静脉、动脉、神经，而且静脉和神经的名字都跟动脉同名。

> **易错点**：腹股沟韧带下方由内向外是**静脉 → 动脉 → 神经**（股静脉、股动脉、股神经）。记动脉的名字，等于把旁边三家的名字一起记住了；反过来，要做动脉穿刺或结扎时，往哪边偏都可能出事。

最后把衔接关系再串一遍：下肢动脉的主干由髂外动脉接续而来，到腹股沟韧带中点下方改名**股动脉**；在大腿下降到腘窝上缘，改名**腘动脉**；腘动脉过膝关节后方，继续向下分成**胫后动脉**和**胫前动脉**；胫前转向**足背**，胫后转向**足底**，两者之间有吻合互相支援。头颈部和上肢的动脉，我们前面也讲过了。

这一讲就讲到这里，盆腔和下肢的动脉到此结束。
