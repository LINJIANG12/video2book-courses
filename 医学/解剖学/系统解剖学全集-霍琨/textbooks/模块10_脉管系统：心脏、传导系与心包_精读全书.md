## 心血管系与心脏：位置、形态与四个腔
> 对应块：BLK26 | 覆盖分集：P35 | 块标题（分集名）：《36.脉管系统Ⅰ》

脉管系分成两大块：一块是心血管系，一块是淋巴系。这一讲先把心血管系的地图铺开——它由哪几部分搭起来，血液在几个环路里打转；然后把心脏本身从位置、到外形、到四个腔，一层层拆开来看。这几层是环环相扣的：先认清血液在哪儿流，才知道心脏为什么长成这样、四个腔又为什么这么排布。

### 心血管系由什么搭起来，血液在两个环路里打转

> **定义**：心血管系由心脏、动脉、静脉和毛细血管四大部分构成。

这四部分不是并列的四个零件，而是一条接力链上的四棒。心脏把血泵出去，各级动脉把血从心室送到全身的毛细血管，毛细血管是营养交换真正发生的地方，各级静脉再把血一级一级收回来送回心房。血液一去一回，就构成了一个完整的环路。

心脏本身分成左右半心，每一侧又被房室瓣分成上下两半，合起来就是四个腔。我们按着血实际走的路线走一遍，就明白两个循环是怎么回事了。

从左心室出发，血经过各级动脉到达全身的毛细血管，在那里完成营养交换；毛细血管再汇成各级静脉，最后回到右心房。这个从左心室出发、又回到右心房结束的大环路，叫**体循环**，也叫**大循环**。

```text
【体循环（大循环）】  左心室 ──▶ 各级动脉 ──▶ 全身毛细血管 ──▶ 各级静脉 ──▶ 右心房
                        ▲                                                 │
                        └─────────────────────────────────────────────────┘

【肺循环（小循环）】  右心室 ──▶ 肺动脉 ──▶ 肺毛细血管 ──▶ 肺静脉 ──▶ 左心房
                        ▲                                             │
                        └─────────────────────────────────────────────┘

两条环路首尾相接：右心房 ▶ 右心室 ▶ 肺循环 ▶ 左心房 ▶ 左心室 ▶ 体循环 ▶ 右心房
```

读图要点：上面那条环走遍全身，起点是左心室、终点是右心房；下面那条环只走一趟肺，起点是右心室、终点是左心房。两个环的**起点都是心室、终点都是心房**，这一条记住了，两个循环就不会再混。

另一个环路是这样走的：右心房里的静脉血在心房收缩时被送进右心室，右心室的静脉血经肺动脉到达肺毛细血管，在那里完成气体交换，血液由静脉血变成动脉血，再经肺静脉回到左心房。这个环叫**肺循环**，也叫**小循环**。

> **结论**：人体两个循环——体循环（大循环）走全身，肺循环（小循环）只走肺；记住"大环全身、小环肺"这句话，考场上就不会张冠李戴。

两个循环搞清楚之后，接下来进入心脏。今天先讲心脏的外形和心腔结构。

### 心脏的位置与比邻

要搞清心脏在哪儿，最好的办法不是背书，而是看两个断面：一个胸部水平断面，一个纵行的断面。图看下来，位置和比邻自然就清楚了。

先看胸部水平断面。这张图上能看到胸廓，后方有脊柱突入，两侧是肋骨。纵隔胸膜从左到右把胸腔一分为二，分出来的两半里装的就是肺——右边三个叶，左边两个叶。两半之间的部分就是纵隔。

再往里看，下纵隔借助于心包又分成前、中、后三部分：胸骨与心包之间是前纵隔，心包里面是中纵隔，心包之后、脊柱之前是后纵隔。

> **定义**：纵隔借心包分为前纵隔、中纵隔、后纵隔三部分。

这一断面上能断出来的心腔，是左右心室的断面。心脏就落在中纵隔里，略微偏左。后纵隔里举两个代表结构：食管和胸主动脉，其余的神经、血管就不画了。

> **结论**：心脏位于中纵隔内，略偏左。

再看另一个断面。前方是胸骨柄、胸骨体、剑突，下方是膈肌，后方是脊柱。以心包为界，这条线以上叫上纵隔，从这里往下到膈肌中心腱，叫下纵隔；心包里面就是心脏，心包上方是出入心脏的大血管。后纵隔里拿主动脉做例子，它在后纵隔内往下走；除了动脉，还有一条纵行的管道叫食管，也是从上往下走的。

顺手记住两个地标：胸骨上这个部位叫**胸骨角**，对应第 2 肋；后方脊柱上这个位置是第 5～8 胸椎。

```text
        胸骨中线         左锁骨中线
            │                 │
   第2肋 ───┼─────────────────┤   ← 胸骨角，平对第 2 肋
   第3肋 ───┼─────────────────┤
   第4肋 ───┼─────────────────┤
            │                 ●   ← 第 5 肋间：心尖搏动点
   第6肋 ───┼─────────────────┤
```

读图要点：心尖搏动点落在左侧第 5 肋间隙，位置在左锁骨中线内侧，距前正中线 1～2 cm——也就是那个实心圆点的位置。

把两个断面合起来做个小结，比邻关系就是下面这张表。

| 方位 | 毗邻的结构 |
| --- | --- |
| 前方 | 胸骨与第 1～6 肋软骨（重点记住肋软骨） |
| 后方 | 第 5～8 胸椎体 |
| 两侧 | 肺与胸膜腔 |
| 上方 | 出入心脏的大血管（主动脉、肺动脉、腔静脉等） |
| 下方 | 膈肌 |

上方这一条是从前面观察、牵拉开两侧肺、暴露心脏看出来的：心脏外周这层膜就是心包（已经被切开了），心脏上方密密麻麻全是血管，有静脉有动脉，有肺动脉等等。

心脏的位置说完，顺带把心尖搏动的道理也说了。心脏是靠大血管吊在半空里的，所以心脏一搏动，心尖就向前去顶压肋间肌，于是产生了心尖搏动。正常人的搏动点就在前面那个位置：左侧第 5 肋间隙、锁骨中线内侧 1～2 cm。

> **易错点**：心尖搏动点在第 5 肋间隙，不要和心尖的朝向搞混——心尖朝左前下，搏动点却在第 5 肋间隙、锁骨中线内侧。

### 心脏的外形：一尖一底、两面、三缘、四沟

站在前面看，你看到的心脏是一个倒置的锥形体——上面宽、下面收成一个尖；而且它是个中空的肌性器官。记住这个大形，接下来就好拆了。

> **结论**：心脏的外形可以概括成一句话——一尖、一底、两个面、三个缘、四条沟。

#### 一尖与心底

**心尖**：朝向左前下。记住是"左前下"，不是正前下。特点是圆钝、游离，不和任何结构连接。

**心底**：朝向右后上。你把心脏翻过来从后方看，看到的基本就是心底和心底上那一堆大血管的名字了——上方的主动脉、左右肺动脉、左右肺静脉（每侧一对，共四支）、上腔静脉、下腔静脉。

再从前方看一遍，认认脸：看到的是上腔静脉；有一个主动脉向上去了；主动脉的左前方还有一个管道叫肺动脉；这侧有个心耳叫右心耳，左侧也有一个心耳叫左心耳；心脏的下缘是心尖；下方是下腔静脉。

> **提示**：心尖朝左前下、心底朝右后上，两端不在一条竖直线上，所以心脏的长轴是**斜行**的——这句话是后面理解"为什么心脏各个面都带着方向"的总钥匙。

#### 两个面：胸肋面与膈面

把心脏向右移，从左侧面观察。上方是主动脉，左边是左心耳，往上走的是上腔静脉，下面是下腔静脉。

从侧面看，心脏有两个面：对着胸骨和肋软骨的那一面叫**胸肋面**，因为它的邻居是胸骨和肋软骨；朝下、和膈肌相对的那一面叫**膈面**。名字就是这么来的——面前为什么叫胸肋面，对着胸骨和肋软骨；下面为什么叫膈面，因为和膈肌相对。

#### 三个缘

心脏有三个缘：右缘近似于垂直，下缘近似于水平，左缘是斜行的。

#### 四个沟与房室交点

心脏表面有四条沟，是分界面的所在。

**冠状沟**围绕心底呈环形，但被肺动脉拦腰分断了。严格说它并不算一条完整的沟，实际是浅沟，位置多被脂肪组织充填。这条沟以上是心房、以下是心室，所以它是**心房与心室的表面分界**。

**前室间沟**在前面，从前面能看到一条浅沟，经心脏下缘反折到膈面去；**后室间沟**就是从后面看到的那条。一前一后两条，把左右两个心室分开。

**房间沟**是往上走的那条，把左右心房分开。

这四条沟一对一对地交在一点上，那个点叫**房室交点**。

```text
                 冠状沟：心房与心室之间的表面分界
        ┌──────────────┬──────────────┐
        │     左房      ║     右房      │
        │              ║              │
        ├──────────────╫──────────────┤   ║ 房间沟，分开左右心房
        │     左室      ║     右室      │   ║ 后室间沟，分开左右心室
        │              ║              │
        └──────────────┴──────────────┘
                       ↑
                     房室交点：三条沟在这里相交
```

读图要点：冠状沟是横的那一条，房间沟和后室间沟是竖的那两条，三条沟在中心交成一个十字形——正是这个十字形，把心脏的四个腔在表面上分了出来。

> **结论**：冠状沟是心房与心室的表面分界，房间沟和室间沟是左右心腔的表面分界；它们相交处就是房室交点。

### 右心房

我们分腔逐个看，先看右心房。挂图上有两幅：一幅是打开的右心房，一幅是右心室打开以后的内部。先看外部结构，再把右心房切开看里面。

右心房里要提的东西不少：一个腔，一个沟，一个嵴，一堆肌隆起，几个孔。

#### 心耳与界沟

右心房外侧壁上有一条浅沟，叫**界沟**，把上腔静脉和下腔静脉前缘连起来的那一片区域圈在里面。我们就从界沟这块把右心房切开，连心耳一起切开，把房壁翻转开来。

心耳是心脏右前方一个**锥体形**的凸起结构，尖端朝向左侧。它的内腔与心房相通——这是心耳的一个特点，所以心耳不是一个封死的口袋。翻开之后能看到心耳内壁同样粗糙，有很多肌肉隆起。

这里要特别记住右心房内壁的**两个特点**：心耳的内壁和翻开的这部分房壁都很粗糙，布满梳状肌；而腔静脉那一片的内壁是光滑的。后面要讲的"右心房分两部分"，依据就是这两点。

#### 固有心房与腔静脉窦

把刚才那两面对起来看：由于内壁有光滑和粗糙之别，右心房被分成两部分。由梳状肌这些结构围成的空间叫**固有心房**（也叫固有心腔），而内壁光滑的那部分围成的空间叫**腔静脉窦**。

> **易错点**：界沟在外、界嵴在内，是同一个位置的一外一内。外边看是条沟叫界沟，里边隆起叫界嵴。把它合上看，两者严丝合缝对在一条线上。

分界就是界嵴——或者说界沟。固有心房和腔静脉窦之间是相通的。

#### 房内的隆起

翻开房壁、对着光看，有几样东西要认出来。

**梳状肌**是心房壁内面上那些平行排列的肌隆起，像木梳的齿一样。**卵圆窝**在房中隔上，是一个卵圆形的压迹，是胚胎时期卵圆孔闭锁以后形成的遗迹。**主动脉隆突**是另一块卵圆形突起：主动脉根部膨大形成三个动脉窦，朝右房这一侧的是后窦，后窦向腔内一凸，就形成了这个主动脉隆突。

#### 三个入口，一个出口

数孔最不容易出错。右心房有 **3 个入口**：上腔静脉口、下腔静脉口、冠状窦口。冠状窦是心脏自身静脉血回心的那个口，所以它也在右心房开口。

出口只有一个，就是**右房室口**——从心房通到心室去的那道口，这里装着三尖瓣。

### 右心室

#### 最靠前的心腔

我们回到胸部水平断面上：这一断面里最靠前的那腔就是右心室。这件事有直接用处——**心内注射**选在胸骨左缘第 4 肋间隙，药物推进去的正是右心室。

> **提示**：右心室是最靠前的心腔，这一点一定要记住。它既是解剖位置的事实，也是临床穿刺的落点。

#### 漏斗部与肉柱部

把心脏恢复到解剖位置，切开前室间沟（它右侧肯定是右心室），打开右心室，掀开前壁。

右心室内壁也有光滑和粗糙之分。上方这一部分内壁很光滑，形状像个倒置的漏斗，叫**漏斗部**；下面粗糙的部分叫**肉柱部**。这两部分的分界是一条弓形的肌隆起，叫**室上嵴**。

```text
              肺动脉口（肺动脉瓣）
                     │
            ┌────────┴────────┐
            │     漏斗部       │   内壁光滑，相当于动脉干的起始段
            ├─────────────────┤ ← 室上嵴：一条弓形肌隆起，作分界
            │     肉柱部       │   内壁粗糙，容纳肉柱、乳头肌、腱索
            └────────┬────────┘
                     │
              右房室口（三尖瓣）
```

读图要点：右心室以**室上嵴**为界分成上下两段，上段是光滑的漏斗部，通向肺动脉口；下段是粗糙的肉柱部，接右房室口。

#### 内壁的结构

掀开前壁往下看，粗糙的内壁上有好几样东西。

**肉柱**是纵横交错排列的肌隆起，纵横成网。**乳头肌**是肉柱里那些更粗、明显向腔内突起的那一类。**腱索**连在乳头肌上，是一束束纤细的索状结构（模型上为了看清内部被切断了），另一端连到瓣膜的游离缘。

腱索是干什么的？它牵拉瓣膜。心室舒张的时候，腱索放松，血液冲开瓣膜进入心室；心室收缩的时候，乳头肌收缩、腱索被拉紧，瓣膜被牢牢拉住，不至于被血液顶向心房翻卷。所以有瓣膜的地方，就一定要有腱索和乳头肌来把关。

> **结论**：腱索有 3 组瓣膜，乳头肌也得有 3 组。它们一一对应：膈侧乳头肌连膈侧瓣，后乳头肌连后瓣，前面的连前瓣。

这些结构里，有一个要单独记住，它有大名——**隔缘肉柱**（膈缘肉柱）。它包括两部分：一部分是在室间隔上的肌隆起；另一部分是一条横跨室腔、一直到前乳头肌根部的索状结构。两个合起来叫隔缘肉柱。

> **提示**：隔缘肉柱里面有什么？里面通过着心脏传导系的右束支。这个"隔缘肉柱里跑着传导束"是必记的一条。

#### 入口、出口与半月瓣

入口就是**右房室口**，装着**三尖瓣**——前瓣、后瓣、隔侧瓣，三个瓣。

出口是**肺动脉口**，装着**肺动脉瓣**。把肺动脉切一段、拿开向外展开，能看到动脉壁里有 3 个半月状的瓣膜；瓣膜只要张开，和动脉壁之间就形成三个间隙，这三个间隙叫**肺动脉窦**，一共三个。三个半月瓣的名字是前瓣、左瓣、右瓣。

半月瓣为什么能把血挡住？我们画个模式图看：

```text
   收缩期                                    舒张期
   血液冲向肺动脉口                            肺动脉弹性回缩，血液倒流
           │                                           │
           ▼                                           ▼
   半月瓣被压向动脉壁                          血液灌进半月瓣的“兜”里
   瓣口敞开                                      兜被充满，两侧瓣缘对合
           │                                           │
           ▼                                           ▼
   血液进入肺动脉                            肺动脉口关闭，血液不能倒灌回心室
```

读图要点：心室收缩时血液往上冲，把瓣膜压向动脉壁，瓣口敞开，血就出去了；心室舒张时肺动脉本身有弹性回缩，血液本来要往回流，一回冲就把瓣膜的"兜"灌满，兜一满，瓣缘两侧一对就合上了，肺动脉口封死。

> **结论**：肺动脉瓣保证血液永远只能由心脏流向动脉，不能由动脉倒回心脏。

### 左房与左心室

把正常的心脏向右旋转，看它的左侧。最靠后的心腔是谁？是**左房**。这个位置关系和右心室正好相反，一前一后，各居一头。

#### 左房

左房每侧都有一对血管进来——左侧的肺静脉看得清清楚楚，这里应该还有右侧的一对肺静脉同样通向左房内腔。所以左房有 **4 个肺静脉口**（左右肺静脉各两条），这是它和右房最大的差别：右房 3 个入口，左房也是 3 个入口、1 个出口。

左房的心耳叫左心耳，内壁和右侧一样，也有肌隆起，同样是梳状肌，断面上和腔内都能看到平行排列的梳状肌。左心耳也是锥体形，内腔与心房相通。

心房壁这一段是光滑的。往旁边一看，室壁变厚了——这一侧是左心室的壁，很厚，这是它必须承受的功。

左房唯一的出口叫**左房室口**，这里装着二尖瓣。

#### 左心室

打开之后，界限很明显：以上是房，以下是室。二尖瓣里有一个比较长的瓣膜，叫**前瓣**（前尖瓣）；另一个是**后瓣**（后尖瓣）。两个瓣，所以叫"二尖"。

左心室内腔里的隆起跟右心室很相像：也有肉柱，也有乳头肌和腱索。这里有一个比较大的乳头肌，叫**前乳头肌**，和前瓣相连。

左心室也分成两部分，依据血液的去路来分：

- 心房收缩时，血液从左房这个方向进入左心室，这部分内腔叫**流入道**；
- 左心室收缩时，二尖瓣关闭，血液只能从另一个途径进入主动脉，这部分内腔叫**流出道**。

两者的分界就是**二尖瓣的前瓣**。

| 部分 | 分界标志 | 内壁特点 |
| --- | --- | --- |
| 流入道 | 二尖瓣前瓣 | 粗糙，有肉柱、乳头肌、腱索 |
| 流出道 | 二尖瓣前瓣（另一侧） | 通向主动脉口 |

入口是左房室口，装着**二尖瓣**（前瓣、后瓣）。出口叫**主动脉口**，装着 3 个**主动脉瓣**，名字是左瓣、右瓣、后瓣。

> **提示**：这里有两套"分界"很容易混——左心室以**二尖瓣前瓣**分流入道和流出道；右心室以**室上嵴**分肉柱部和漏斗部。一套按瓣膜分，一套按肌隆起分，别记反。

### 四道瓣膜与血液的定向流动

心脏像一个血泵，不断地运动来推动血液循环，使血液总是沿着一个方向周而复始地运动。哪些结构在起主要作用？是心脏的瓣膜。

我们把所有瓣膜都画到一张模式图上：

```text
        上腔静脉                  肺静脉（左右各一对）
            │                          │
            ▼                          ▼
        ┌────────┐                ┌────────┐
        │ 右心房 │                │ 左心房 │
        └────┬───┘                └────┬───┘
             │                          │  ← 二尖瓣
             │ 三尖瓣                   │
             ▼                          ▼
        ┌────────┐                ┌────────┐
        │ 右心室 │                │ 左心室 │
        └────┬───┘                └────┬───┘
             │                          │
             │ 肺动脉瓣                  │ 主动脉瓣
             ▼                          ▲
           肺动脉                     主动脉
```

读图要点：整张图上只有四道关卡——右房室口的三尖瓣、肺动脉口的肺动脉瓣、左房室口的二尖瓣、主动脉口的主动脉瓣。心房收缩，血液进入心室；心室收缩，房室瓣关闭，血液冲开动脉瓣往前走；心室舒张，动脉瓣关闭，血回到心房，下一次心房收缩又灌进心室。就这样周而复始。

顺着图把四个腔的出入口捋一遍，这张表就是整讲的骨架：

| 心腔 | 入口 | 出口 |
| --- | --- | --- |
| 右心房 | 上腔静脉口、下腔静脉口、冠状窦口（3 个） | 右房室口（三尖瓣） |
| 右心室 | 右房室口（三尖瓣） | 肺动脉口（肺动脉瓣） |
| 左心房 | 4 个肺静脉口（左右肺静脉各一对） | 左房室口（二尖瓣） |
| 左心室 | 左房室口（二尖瓣） | 主动脉口（主动脉瓣） |

> **结论**：一个腔一条规矩——入口只进不出，出口只出不进；血液在四个腔里被四道瓣膜一路"单向闸"卡着，永远回不了头，所以它才能周而复始地转下去。

## 心脏的隔壁、传导系、血管与心包
> 对应块：BLK27 | 覆盖分集：P36 | 块标题（分集名）：《37.脉管系统Ⅱ》

这一节接着讲心脏的第二部分。顺序我先交代一下：先看房间隔与室间隔——这两个大家简单了解一下就行；然后是心脏的传导系，把概念和组成捋清楚；第三个问题是本节的重点，心脏自己的血管；最后再把包在心脏外面的心包说一下。

### 房间隔与室间隔：把四个腔隔开的两道墙

看心脏的模式图，心尖朝下，四个腔。这个结构把左右心房分割开，所以叫房间隔；下面这个结构分割左右心室，就叫室间隔。图上用白颜色表示瓣膜，右半心有房室瓣、左侧有房室瓣，这部分我们前面都过过了。

这两个隔的名字好记，**构成上却不能凭直觉猜**，得记下来。

**房间隔的构成**是三样：心房肌、结缔组织、两侧的心内膜——有肌层，有结缔组织，内外两面各贴一层心内膜。

第二个要记住的是，房间隔上有一个**最薄的区**。看图上这部分，从右房侧能看到一个卵圆形的压迹，它叫**卵圆窝**。这是房间隔最薄的地方。

**室间隔的构成**和房间隔一个套路，只是把心房肌换成心室肌：心室肌、结缔组织和心内膜。这个我们就不写了，你照着上一句改一个字就行。

室间隔真正的考点在**分部**。换了个颜色标出来看：薄的这部分叫**膜性部**，比较厚的叫**肌性部**。所以室间隔分膜性部和肌性部两部分。

膜性部还能再往下分。判断标准只有一个——看这一段的两边各是什么腔：

```text
                膜 性 部
   ┌                                   ┐
   │              房室部               │
   │  ┌────────┐   ┌────────┐          │
   │  │  心房  │   │  心室  │          │
   │  └────────┘   └────────┘          │
   ├                                   ┤
   │              室间部               │
   │  ┌────────┐   ┌────────┐          │
   │  │  心室  │   │  心室  │          │
   │  └────────┘   └────────┘          │
   └                                   ┘
```

上面这一段有房有室，叫**房室部**；下面这一段两侧都是心室，所以叫**室间部**。

> **易错点**：房室部、室间部的判据不是"在上还是在下"，而是"两侧是心房还是心室"。记住这一条就够了。

### 心脏的传导系：一群特殊分化的心肌细胞

#### 概念：四个字

传导系是什么结构？大家注意，是**特殊分化的心肌细胞**。四个字，记住：不是普通的心肌细胞。

那它和普通心肌细胞差在哪儿？差在功能上——它能够**产生或传导兴奋**。而这种兴奋可以调节心脏节律性地舒张或者收缩。这就是心脏传导系的概念。

#### 组成：从窦房结到心室肌的一条路

先看心脏的挂图。上面是心房、下面是心室，都是右半心。这根血管是上腔静脉，这个锥体型的腔是右心耳。那么这个结——它是正常心脏的**起搏点**，叫**窦房结**。

窦房结的位置要搞清楚：**上腔静脉根部与右心耳交界处的心外膜深面**。刚才我们讲的那个界沟，这个角度看不到，它就是**界沟的上端**。

它发出的冲动通过一些支传到心房，这些叫**结间支**（也叫结间束）。其中有一支传给另一个结，叫**房室结**。房室结得到冲动以后继续向下传，通过**房室束**；再往下分成**右束支**和**左束支**，分别到达左右心室。

把通路连起来是这样一条路：

```text
窦房结  上腔静脉根与右心耳交界处的心外膜深面（界沟上端）
  │
  ├─ 结间支（右）→ 右心房肌 → 右心房收缩
  ├─ 结间支（左）→ 左心房肌 → 左心房收缩
  └─ 结间支      → 房室结
                     │
                     房室束  走在室间隔的膜性部内
                     │
                     右束支  心内膜深面 → 经节制索 → 右心室
                     │
                     左束支  分三组束支 → 左心室
                     │
                     浦肯野纤维 → 心室肌收缩
```

这里有两个位置细节要抓：

第一，**房室束走在室间隔的膜性部里**，不是走在肌性部；一直走到肌性部上缘，才开始分支。

第二，**右束支的走法有地方特色**。它先在心内膜深面，然后通过**节制索**到达右心室，再和浦肯野纤维相联系，引起右心室收缩。刚才我们提到的那个**前乳头肌**，是不是有个到它根部的节制索？那是右室的一个特点。左侧则是**三组束支**向下走到左心室，再通过浦肯野纤维传给心室。

最后把时序串一遍，你就明白为什么心房心室能"一先一后"地配合了：冲动在窦房结发出，通过两侧的结间支使**心房先收缩**；它还有一支到房室结，房室结得到冲动后通过房室束、左右束支、浦肯野纤维，引起**心室收缩**。所以心室收缩的时候心房已经先动完了。整个心脏的运动，全靠这个系统来调节。

> **易错点**：房室束的"底"在膜性部，界在肌性部上缘。别把房室束记成从房室结一路直下。

### 心脏的血管：本节的重点

心脏的动脉一共有两条：**右冠状动脉**和**左冠状动脉**。别的先不管，就这两条主干。

看挂图的时候要有个心理准备：上面那幅是从前方看心脏的动静脉，下面那幅是从后方看。因为动静脉缠绕在一起，所以有很多动脉支被静脉遮盖了。**参考这两幅图的时候，重点看板图。**

先把大血管认一遍：前面观从上腔静脉、主动脉、肺动脉干、主动脉弓、左心耳开始，这侧看到的是右心耳，一直连到心脏的右缘、下缘，直到心尖。后面观看到左侧肺静脉、左心房、右侧肺静脉、左侧肺动脉、主动脉弓、右侧肺动脉、上腔静脉、右房、下腔静脉，以及心脏的膈面。

#### 右冠状动脉：绕右缘反折到膈面

右冠状动脉**在主动脉的右窦发出来**，进入冠状沟后绕心脏的右缘，反折到膈面，最后分为两个比较大的终支。

分支在前方看得见的有这么几支：根部向上发出一个小的**窦房结支**（往上到窦房结），再向上发出一个**右房前支**（到右心房）；往下有**圆锥支**（到肺动脉圆锥）、**右室前支**、**右缘支**。

转到后面还有几支：主干发出**右房后支**、**房室结支**（钻进去到房室结），以及**后室间支**（沿后室间沟下行）和**右旋支**。右冠状动脉的分支比较多。

#### 左冠状动脉：前降支与旋支

左冠状动脉同样发在主动脉根部，**由主动脉的左窦发出**。注意这里有个遮盖关系：主动脉根被肺动脉所遮盖，所以左冠状动脉是在**肺动脉后方**出来的，出来以后进入冠状沟。

进入冠状沟以后，它**立即发出一个很长很大的分支——前降支**，也叫**前室间支**；另一支叫**旋支**，绕过左缘到心脏后方去。

前室间支自己也发出一堆分支：**室间隔前支**（往室间隔里发很多很多小支）、**对角支**、**左室前支**、**右室前支**、**圆锥支**。

旋支在左侧边缘发出**左缘支**，转向后就是**左室后支**和**后外侧支**；另外还有一条**左房旋支**，旋转到后方到左心房去，沿途还发出一个**房支**到左房前方。

两套分支摆在一起是这样一张谱系图：

```text
主动脉根部
├─ 主动脉左窦 → 左冠状动脉（经肺动脉后方，进入冠状沟）
│   ├─ 前降支（前室间支）
│   │   ├─ 室间隔前支
│   │   ├─ 对角支
│   │   ├─ 左室前支
│   │   ├─ 右室前支
│   │   └─ 圆锥支
│   └─ 旋支（绕过左缘到心脏后方）
│       ├─ 左缘支
│       ├─ 左房旋支
│       ├─ 房支
│       ├─ 左室后支
│       └─ 后外侧支
└─ 主动脉右窦 → 右冠状动脉（冠状沟内绕右缘，反折到膈面）
    ├─ 窦房结支
    ├─ 右房前支
    ├─ 圆锥支
    ├─ 右室前支
    ├─ 右缘支
    ├─ 右房后支
    ├─ 房室结支
    ├─ 后室间支
    └─ 右旋支
```

#### 动脉之间很少有吻合：心绞痛、心肌梗死与搭桥

营养心脏的动脉有一个特点要记住：**它发出了很多很多的支，但动脉和动脉之间很少有吻合。**

这一个特点，直接决定了临床上的整套处理逻辑。既然动脉之间几乎不吻合，那么**每一个分支就只营养一个区域的心肌**——没有旁路可走，某一条断了，那个区域的供血就真的断了。

顺着这个思路往下推：

- **狭窄**。这条血管越来越窄，最常见的原因是动脉粥样硬化，末端供血不足。供血不足会出现**心前区的不适感**，这就叫**心绞痛**。心绞痛不是病，它是个症状，是心脏供血不足造成的。休息或者用硝酸甘油就能缓解。
- **持续性的堵塞**。不是狭窄了，是堵死了，血过来不了，营养区长时间没有血液供应，出现大面积的坏死——这就叫**心梗，心肌梗死**。

治疗手段也是顺着这个来的：

狭窄的时候，内壁粥样硬化、越来越粗糙变厚，把管腔挤窄了。我们可以**用引导管、用气囊把它扩开**；如果扩的效果不好，再**下一个金属支架**撑起来。注意看，血管壁本身变厚了，外壁也跟着外凸，支架是下在里面的，把管腔从里面撑开，血就可以通过了。

如果心脏的血管**很多地方**都出现狭窄或者堵塞，光靠支架就不够了，要做**搭桥术**。怎么搭？看图：这儿堵了——前降支这儿堵了，旋支根部也堵了——出现这样大面积的堵塞，怎么办？我们可以用**自身的大隐静脉**，在堵塞的**远端**建立通路再缝合。血液是不是就可以进入这个动脉了？另一处堵塞也一样，都在远端搭桥。这就是搭桥术，解决了动脉的供血问题。

> **结论**：搭桥的桥墩一定落在堵塞的**远端**。记住这一条就够了。

#### 心脏的静脉：冠状窦与三条心静脉

心脏的静脉从挂图的下图看——这是心底。注意看，**血管压出来的沟**叫冠状沟，另一条血管压的沟叫后室间沟。

冠状沟里边有一个很大很膨大的管腔，这个叫**冠状窦**；它有一个开口，叫**冠状窦口**。我们讲心脏的时候提过右房的几个入口——上腔静脉口、下腔静脉口，还有一个冠状窦口。心脏本身的静脉血就是通过这个口进到右房的。

窦的两端都有小静脉汇进来。心脏主要有三条：

```text
心大静脉 → 冠状窦左端 ┐
心中静脉 → 冠状窦右端 ├→ 冠状窦 → 冠状窦口 → 右房
心小静脉 → 冠状窦右端 ┘
```

对照关系记牢：**心大静脉**最粗大，它和**前降支**伴行，绕心脏的左缘过来，注入冠状窦的**左端**；**心中静脉**和**后室间支**伴行，注入冠状窦的**右端**；**心小静脉**绕过心脏的右缘过来，也注入冠状窦的**右端**。

所以：心大、心中、心小静脉，加上一些小分支，全都汇入冠状窦，再经冠状窦口注入右房。

> **易错点**：心大静脉在**左**端汇入，心中、心小在**右**端汇入。位置别记反。

### 心包：硬壳、浆膜与心包腔

#### 构成

心脏的外面有一个很坚硬的膜状结构，叫**纤维性心包**，它的**底在膈肌中心腱**。纤维性心包的内侧有一个薄薄的浆膜，附着在纤维性心包的内面，同时又附着在心脏的表面——这一层黄颜色的，就叫**浆膜性心包**。

这和我们以前讲的胸膜腔、腹膜腔是同一套逻辑。浆膜性心包包绕心脏表面的那层叫**脏层**，在纤维性心包内面的那层叫**壁层**。所以心包的构成是两层：纤维性心包 + 浆膜性心包（脏、壁两层）。

```text
  ┌────────────────────────────────┐
  │  纤维性心包（底：膈肌中心腱）  │
  │  ┌──────────────────────────┐  │
  │  │ 壁层（浆膜性心包）       │  │
  │  │ │ ┌────────────────────┐ │  │
  │  │ │ │       心包腔       │ │  │
  │  │ │ │  ┌──────────────┐  │ │  │
  │  │ │ │  │     心脏     │  │ │  │
  │  │ │ │  └──────────────┘  │ │  │
  │  │ │ └────────────────────┘ │  │
  │  │  壁层（浆膜性心包）       │  │
  │  └──────────────────────────┘  │
  └────────────────────────────────┘
```

**心包腔**的概念就是图中那一块——浆膜性心包脏层、壁层两层围成的密闭间隙。

#### 心包积液与心包穿刺

心脏有疾病的时候，比如心肌炎，会使心包腔里面的液体增多，这就叫**心包积液**。

心包积液会有什么后果？想一下就明白：心包腔里液体多了，**心脏的舒张肯定要受阻**；舒张受影响了，**心排血量就减少了**。所以这液体**应该抽出去**。

在哪儿抽？看前面观：如果前方的这个部位是胸骨，下边是剑突，两侧是肋弓，那么这两个角就叫**剑肋角**。我们在**左侧剑肋角**进针，做**心包穿刺**——也就是**穿透膈肌进入心包腔**，把液体抽出来。

```text
        胸骨
       ╱    ╲
     肋弓    肋弓
       ╲    ╱
        剑突
      ╱      ╲
 左侧剑肋角  右侧剑肋角
     │  ← 进针处
     ↓  穿透膈肌 → 心包腔
```

从侧面看也是同一件事：前方是胸骨（柄、体、剑突），下方是膈肌，后方是脊柱；心包在这个位置，心包腔夹在中间，进针角度就是从这个角度进去。

这一节的重点，我希望你们记住的是**心脏的血管**：左右冠状动脉起自于什么部位、形成哪些重要的分支、这些分支都分布在什么部位。课后大家结合实验课重点复习——光看挂图不够，标本上一手摸到前降支、旋支、右缘支，这些名字才真的长在你手上。
