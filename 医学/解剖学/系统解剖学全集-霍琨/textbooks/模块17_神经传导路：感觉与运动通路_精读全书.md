## 两条路各管一头：运动传导通路怎么走
> 对应块：BLK47 | 覆盖分集：P59 | 块标题（分集名）：《60.传导路-运动传导通路》

先问你一个特别无聊的问题：体育课上齐步走，老师喊“一——二一”，第一步迈哪只脚，你心里门儿清；可一旦走起来了，你还知道现在是左脚在前还是右脚在后吗？

说实话，没感觉了。

这就是这一讲要解决的事。运动传导通路不是一个整体，它是由**两个路**构成的：一个叫锥体路，一个叫锥体外路。你刚才那个“迈第一步清楚、走起来就不清楚”的落差，正是这两条路在分工。

### 一条管“起和止”，一条管“稳得住”

先看两条路各干什么。

**锥体路**主要支配随意运动，支配肢端一些精巧的活动。

**锥体外路**的作用是调节肌张力、协调随意运动，维持体态和人体的姿势，并且能完成习惯性的、节律性的活动。

两个路都是好的，我们的随意运动才既精准又随意。

怎么理解这个分工？再举一个例子就彻底明白了。假设一个女同学在打毛衣——现在会打毛衣的人不多了。打毛衣的时候，织平针儿，她可以一边织一边唠嗑、看电视，一点都不耽误。这说明什么？说明织平针儿已经变成一个习惯性动作了，锥体外路在接管。可是当她要**并针或者加针**的时候，她肯定要停下来，不跟你唠嗑了，得先数一数“我要并几针”，数完并完了，再重新唠嗑。

看见没有？动作的**两端**——启动、终止、修正——都是锥体路的事；一旦进入稳定节奏，就是锥体外路的事。

那锥体外路要是损伤了呢？随意运动的协调性当然受影响。你们经常看到有些老人**晃头、肢体震颤**；再比如上菜市场买菜，一毛钱可能要掏二十分钟才掏得出来。这不是什么舍不得一毛钱，是锥体外路坏了，动作的节律和协调全乱了。

| | 锥体路 | 锥体外路 |
|---|---|---|
| 主要功能 | 随意运动、肢端精巧活动 | 调节肌张力、协调随意运动 |
| | 动作的启动与终止 | 维持体态和人体姿势 |
| | | 习惯性、节律性活动 |
| 生活中的例子 | 正步走的起步与立定；打毛衣的并针、加针 | 走起来之后的左右脚交替；织平针时还能唠嗑 |
| 损伤之后 | 瘫痪 | 震颤、动作缓慢、协同失调 |

> **结论**：这两条路必须同时好，才能精准地完成随意运动。锥体路一出毛病，因为“协助它的那个路就没有用了”，直接瘫痪。

### 皮质脊髓束：从中央前回一路下行到前角细胞

既然是两条路组成，我们重点要讲的是第一个路——锥体路。锥体路里有两个束，先说第一个：**皮质脊髓束**。

这五个字其实已经把它的两头写清楚了。“皮质”是起点，“脊髓”是终点：起于大脑皮质，终于脊髓。所以它是一个下行路，也就是运动路。

#### 上下两级神经元，胞体分别在哪儿

这里有个地方跟感觉传导不一样，务必分清：运动传导路是由**两级神经元**完成的，而感觉传导是三级神经元。

两级神经元怎么叫？一个叫**上运动神经元**，另一个叫**下运动神经元**，两者不一样。

- **上运动神经元**的胞体在皮层。皮质脊髓束是到整个躯干和四肢去的，所以它起于皮层的运动区——**中央前回上 2/3，再加上旁中央小叶的前份**。
- **下运动神经元**的胞体在**脊髓前角细胞**。

> **易错点**：“上”和“下”讲的是胞体位置的高下，不是在通路上的先后顺序。大脑皮层在上，脊髓前角在下，所以皮层那个叫上运动神经元。

#### 传导全程：看图，记住三个要点

我们看挂图。这是一个皮质脊髓束的完整传导过程：

```text
  大脑皮质  中央前回上 2/3 + 旁中央小叶前份  ← 上运动神经元胞体
      │
      │  内囊后肢（内囊枕部）内下降
      │
      │  脑干内下行
      │
      │  延髓下部：锥体交叉 —— 纤维在此左右交换
      │
      │  对侧脊髓外侧索：皮质脊髓束下行，沿途发出侧支
      │
      │  同侧脊髓前角细胞                     ← 下运动神经元胞体
      │
      │  效应器
```

读图：纤维自中央前回上 2/3 与旁中央小叶前份出发，穿内囊后肢下行到脑干，在延髓的锥体交叉处换到对侧，沿脊髓外侧索继续下行，途中不断发出侧支，最终终止于同侧的脊髓前角细胞，再到达效应器。

回忆一下我们讲延髓时提到过的那个结构：锥体下方有个发辫式的交叉痕，就叫**锥体交叉**——这正是这束纤维左右交换的部位。而从图上还能看出，束在脊髓里是沿**外侧索**下降的，途中不断发出侧支去够前角细胞。

所以三个要点记住就够了：

| 要点 | 位置 |
|---|---|
| 一、经过内囊 | 内囊后肢（内囊枕部）内下降 |
| 二、左右交换 | 延髓的锥体交叉处 |
| 三、脊髓内下行 | 外侧索 |

内囊我们已经讲过，分前肢、膝部、后肢三大部，皮质脊髓束主要是在**后肢**内下降。

#### 交叉点决定瘫痪在哪一侧

有了这三个要点，病变定位就变成了一道很简单的算术题。

- 脊髓的外侧索发生病变：纤维在锥体交叉处已经换到对侧了，所以损伤平面以下表现为**同侧**肢体瘫痪。
- 交叉点以上的任何一个部位（内囊、脑干）发生病变：还没来得及交叉，所以表现为**对侧**半身瘫痪。

> **易错点**：“内囊病变对侧半身”和“脊髓外侧索病变损伤平面以下同侧”这两句最容易打架。判断的钥匙只有一个——病变在不在锥体交叉的**上游**。交叉点以上＝还没换边＝对侧；交叉点以下＝已经换边＝同侧。

### 皮质核束：下行到脑干就散开了

锥体路第二个束提一下，叫**皮质核束**。它过去还有一个名字，叫皮质脑干束。

起点还是大脑皮质，终点变成了**脑干**。它具体和谁发生联系？和脑干里面的**运动核**发生联系。

#### 从中央前回下 1/3 出发

皮层上的分布区是一个“倒影”：从外上到内下，依次是下肢、上肢、头面部。所以皮质核束起于**中央前回下 1/3**，管的是头面部。

它的走向：中央前回下 1/3 → 内囊 → 往下到脑干 → 散开，分别去接脑干里的运动核。脑干里的运动核非常多，比如动眼神经核、滑车神经核、展神经核、面神经核等等，我们画几个代表性的就够了。

脑干里的运动核，到底受双侧支配还是单侧支配？大多数情况下，一个核团左右两侧的皮质核束都管它。由此得出第一个结论：

> **大多数脑干运动核受双侧皮质核束支配。**

#### 一个半核：真正吃临床的那一条

上面这条在临床上有意义吗？打个比方：每天中午两个人给你送饭，有一个人病了没来，你饿得着不？

所以“大多数脑干运动核受双侧支配”这件事，**没有临床意义**。临床意义最大的在这儿：

- **面神经核**：只接受**对侧**皮质核束支配的，是它的**下半**部分；上半部分实际上还是双侧支配。
- **舌下神经核**：只接受**对侧**皮质核束支配。

所以要特别记住的就是这“**一个半核**”：一个舌下神经核，加上半个——面神经核的下半。

另外还有第三个要点：这个束的纤维同样是**经过内囊**下降的。

| 要点 | 内容 |
|---|---|
| 一 | 大多数脑干运动核受双侧皮质核束支配 |
| 二 | 面神经核下半和舌下神经核只接受对侧皮质核束支配 |
| 三 | 纤维经过内囊下降 |

#### 核上瘫和核下瘫：一张脸的两种瘫法

面神经核到底管哪一块，我们再明确一下。面神经核分为上半、下半；它管的面部，我们把整张脸分成四份来看：

```text
                            皮质核束（中央前回下 1/3 → 内囊 → 脑干）
                                │
    ┌───────────────────────────┴───────────────────────────┐
    │                                                       │
    │       面神经核上半                面神经核下半        │
    │             │                           │             │
    │     双侧皮质核束支配             只接受对侧支配       │
    │             │                           │             │
    │    面上四分之一表情肌          面下四分之一表情肌     │
    │                                                       │
```

读图：皮质核束到脑干后分开走向两个核团——面神经核上半接受双侧支配，管面上四分之一的表情肌；面神经核下半只接受对侧支配，管面下四分之一的表情肌。

那么这个束要是损伤了会什么样？举内囊病变为例：内囊一坏，离它最近的面神经核**下半**首先得不到冲动，而上半因为有双侧支配照样正常。下半管的是面下四分之一表情肌，于是这一块就瘫了。

临床上这就是**下四分之一瘫痪**：这一侧**抬头纹还在**（因为上半没坏），医生让闭眼，两只眼都能闭上；这一侧**鼻唇沟变浅**，嘴歪，流口水。

这种面瘫叫**面神经核上瘫**，也叫**中枢瘫**。

我们再对照一下之前讲过的另一种面瘫：那一侧**没有抬头纹**，这一侧有抬头纹；这一侧**眼睛闭不上**；嘴歪、流口水。整个半拉脸都瘫了，这叫**面神经核下瘫**，也叫**周围瘫**。

为什么一个叫中枢、一个叫周围？你想想，如果是半拉脸瘫痪，病变肯定不在中枢，而是在**面神经**——是面神经核或者面神经核以下任何一个部位受损。半侧脸，说明这一整套支配装置整个失灵了。而内囊损伤只影响面神经核的下半，只表现下四分之一。两者一眼就能分开。

> **提示**：核上瘫（中枢瘫）＝皮层或内囊出了问题，只有**面下四分之一**瘫，额纹保留、闭眼能闭；核下瘫（周围瘫）＝面神经核或面神经本身出了问题，**半张脸**全瘫，额纹消失、眼睛闭不上。

### 上下运动神经元损伤：五组表现帮你分家

第二个问题简单提一下：上下运动神经元损伤怎么鉴别？

我们从几个方面去判断：第一，看瘫痪的特点；第二，比较肌张力；第三，比较腱反射；第四，比较病理反射；最后再比较肌肉是否萎缩。

先看**瘫痪特点**。上运动神经元损伤，表现的是**硬瘫**，也叫痉挛性瘫痪；下运动神经元损伤表现的叫**软瘫**，也就是弛缓性瘫痪。这两种大家都有体会——我们见过小儿麻痹的患者，拄着一个拐杖，病侧那条腿像个面条一样，走起来来回悠；而且萎缩了没有？萎缩了。这是什么瘫？软瘫，是下运动神经元损伤。这个病叫**脊髓前角灰质炎**，正好是下运动神经元损伤，表现的就是弛缓性瘫痪。

| 比较方面 | 上运动神经元损伤 | 下运动神经元损伤 |
|---|---|---|
| 瘫痪特点 | 硬瘫（痉挛性瘫痪） | 软瘫（弛缓性瘫痪） |
| 肌张力 | 增高 | 降低 |
| 腱反射 | 亢进 | 减弱或消失 |
| 病理反射 | 出现 | 无 |
| 肌萎缩 | 早期无萎缩 | 早期即出现萎缩 |

肌萎缩这一项特别好记：拿小儿麻痹来一对——萎缩了吗？萎缩了，说明是下运动神经元损伤，而且早期就萎缩；而上运动神经元损伤的早期是**没有萎缩**的。

**病理反射**是上运动神经元损伤的经典标志。临床上最常见的就是两个：一个是**弹中指试验（Hoffmann 反射）**，还有一个是 **Babinski 征（划脚心试验）**，用它们来看有没有病理反射。下运动神经元损伤则没有病理反射。

肌张力、腱反射这两条更有意思，值得单独记一句：上运动神经元损伤是**张力增高、腱反射亢进**；下运动神经元损伤是**张力降低、腱反射减弱或消失**。

有了这五组临床表现，我们初步就能判断出是哪一个神经元损伤，然后再具体去找病变部位。运动传导通路我们就给大家介绍这么多，下次课再见。
