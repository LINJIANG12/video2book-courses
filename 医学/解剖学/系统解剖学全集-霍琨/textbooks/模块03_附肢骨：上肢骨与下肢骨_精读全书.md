## 上肢骨：从锁骨到指尖的骨性地图
> 对应块：BLK05 | 覆盖分集：P07 | 块标题（分集名）：《7.骨学-附肢骨-上肢骨》

这节课我们接着往下走，讲附肢骨，先从上肢开始。

上肢骨一共分两半：一半叫**肢带骨**，一半叫**自由上肢骨**。肢带骨是什么？就是直接和躯干骨相连带、把上肢挂在躯干上的那几块骨；另一半是可以自由活动的上肢骨。肢带骨我们讲两块——第一个是锁骨，第二个介绍肩胛骨。自由上肢骨我们讲三块——肱骨、前臂骨、手骨。

> **定义**：上肢骨 = 肢带骨（锁骨、肩胛骨）+ 自由上肢骨（肱骨、前臂骨〔桡骨、尺骨〕、手骨〔腕骨、掌骨、指骨〕）。

### 锁骨：一根悬在半空的骨头

先看锁骨。在挂图上从上方看，锁骨是一个 S 形：外侧段凹进去，内侧段向前凸。锁骨外侧端对应的，正是肩胛骨的肩胛冈。

```text
                前方（内侧段向前凸）
                      ↑
          ╭───────────╮
         ╱             ╲
        │               ╰╮
        ●                ╰──╮
      内侧端                 ╰──● 外侧端
    （胸骨端）                    （肩峰端）
                      ↓
                后方（外侧段凹进去）
```

读图：整根锁骨是"S"字，内侧段凸向前、外侧段凹向前；内侧端和胸骨相接，外侧端对应肩胛冈。

从前方看，锁骨外侧端扁平，内侧端比较圆钝。两端的名称记住就行：

> **定义**：锁骨内侧端叫**胸骨端**（与胸骨相接），外侧端叫**肩峰端**（与肩峰相接）。

知道两端的名称，就有用了——因为相接的结构一下子全清楚：内侧端正好和胸骨相接，外侧端和肩峰相接。锁骨的两端是一个关节，中间悬着。

#### 中外 1/3 交界处：最容易断的地方

麻烦就麻烦在这根骨头"悬"着：中间悬起，上方仅仅有一层皮肤。所以遇到外力，锁骨是最容易骨折的。

那最容易骨折的部位在哪儿呢？**中外 1/3 交界处**。就这一处。

这个部位一旦骨折，会损伤什么结构？我们看锁骨的下方——有一个很重要的动脉，叫**锁骨下动脉**。锁骨一断，骨折的折端很容易就把它刺破，造成动脉大出血。

```text
        中外 1/3 交界处骨折
                 │
                 ├──→ 锁骨对肩胛骨的支撑失去
                 │        │
                 │        └──→ 肩胛骨向前移位
                 │                  │
                 │                  └──→ 肩峰段与内侧段形成交叉，
                 │                       折端正好向下刺出
                 │
                 └──→ 折端直接下刺 → 刺破【锁骨下动脉】→ 大出血
```

读图：骨折有两条独立的危险路径——一条伤血管（折端向下刺破锁骨下动脉），一条因为肩胛骨前移而让内侧段与肩峰段交叉，交叉处同样把下面的动脉扎破。

#### 八字形绷带固定法

所以锁骨骨折的患者，现场一定要先做一个处理。怎么处理？**八字形绷带固定法**。

绷带怎么绑？记住四步：

```text
   ① 从患侧肩起，斜向下绕到【对侧】腋窝下方
                        │
                        ▼
   ② 转到身体前面，横着回来
                        │
                        ▼
   ③ 再绕到【患侧】腋窝下方
                        │
                        ▼
   ④ 再转到身体前面，与①交叉

   交叉后 = 一个"横"字，这就是"横八字"
```

固定的目的是什么？把两肩**向后拉**，向后拉之后，锁骨的两个断端就分开了，防止它折端刺破动脉。这时候再转送医院，这样比较安全。

到医院以后，固定方法可以用这个绷带固定法，也可以用钢针，也可以用钢板。因为它表面就是皮肤，这个手术比较简单。

### 肩胛骨：先把这几个名词记住

肩胛骨是一个**三角形的扁骨**。从后面看和从前面看是两块不同的面，我们先大致把结构过一遍，参考挂图和板图，把形状先混个印象，然后重点记下面这几个名词。

后方最明显的一个骨性隆起叫**肩胛冈**，体表能够摸到；冈的外侧端突出的这个骨性凸起叫**肩峰**，体表也能摸到。肩胛冈把肩胛骨后方分成上下两个窝，上面这个叫**冈上窝**，下面这个叫**冈下窝**。

既然是三角形的扁骨，那它当然有三个角：上面这个叫**上角**，下面这个叫**下角**，外侧这个叫**外侧角**。

> **易错点**：外侧角不是一个标准的"角"，它其实是一个浅盘状的关节窝，所以我们把它叫做**关节盂**——相对于三角形的另外两个角，它相当于外侧角。

再看前方：肩胛骨前方这个窝叫**肩胛下窝**；旁边有一个骨性突起，像个鸟嘴一样，叫**喙突**；还有这个叫**肩胛切迹**。

把名词整理成一张表，主要结构就是这些：

| 位置 | 结构 | 要点 |
| --- | --- | --- |
| 后面（横行隆起） | 肩胛冈 | 体表可摸 |
| 肩胛冈外侧端 | 肩峰 | 体表可摸 |
| 肩胛冈之上 / 之下 | 冈上窝 / 冈下窝 | 肩胛冈把后面分成上下两窝 |
| 上角 / 下角 | — | 下角体表可摸，对应第 7 肋 |
| 外侧角 | 关节盂 | 浅盘状关节窝，不是真正的"角" |
| 前面 | 肩胛下窝 | 肩胛骨前面的凹陷 |
| 前面骨性突起 | 喙突 | 像鸟嘴，体表可摸 |
| 外侧角附近 | 肩胛切迹 | |

#### 体表摸得到哪几个

除了记结构，第二件事是记哪些结构体表能摸到。我们把能摸到的用颜色标出来，一共四个：

- **肩峰**
- **肩胛冈**
- **肩胛下角**
- **喙突**

#### 数肋骨和数棘突

骨性结构里我再给大家介绍两个特别有用的：一个计数肋，一个计数棘突。

先数肋。看挂图，**肩胛下角对应的肋应该是第七肋**；肩胛上角对应的肋是第二肋。所以下角一看到，它所对应的肋骨就是第七肋——这就是计数肋的标志。

再数棘突。看患者后背，肩胛骨上这个隆起就是肩胛冈。那么：

- 两侧**肩胛冈内侧端的连线**，对应**第 3 胸椎的棘突**；
- 两侧**肩胛下角的连线**，对应**第 8 胸椎的棘突**。

所以这一节我们又学了两种计数方法：一个第三，一个是第八。

> **结论**：肩胛骨这块，理解上面这四个层次——形状、主要结构、体表标志、计数线——就够了。

### 肱骨：一根骨头上的四条神经

接下来是自由上肢骨。第一个介绍**肱骨**，它是一个典型的长骨。

先看结构。肱骨的前面和后面分别看：上端有一个半球状的关节面，叫**肱骨头**；上端的外侧有一个骨性突起，偏前内侧还有一个骨性突起，分别叫**大结节**和**小结节**；两个隆起中间当然是凹陷，这个叫**结节间沟**。

下端的关节面先看前面：有一个球状关节面叫**肱骨小头**，还有一个滑轮状的关节面叫**肱骨滑车**。从后方看，肱骨干后面有一个骨性的沟，这个叫**桡神经沟**；两侧的突起，内侧的叫**内上髁**，外侧的叫**外上髁**；内上髁的后外侧大家看这儿也有一个骨性沟，这个叫**尺神经沟**。再转到后方看肱骨滑车，滑车上方有一个深窝；从前方看，滑车上还有一个浅窝。

```text
                        前方                      后方
   ┌──────────────────────────────────┬──────────────────────────┐
上 │  肱骨头（半球状关节面）          │  肱骨头
端 │  大结节（外侧） / 小结节（前内侧）  │  大结节 / 小结节
   │  └ 两者之间：结节间沟              │  └ 结节间沟
   ├──────────────────────────────────┼──────────────────────────┤
下 │  肱骨小头（球状面）上：桡窝       │  肱骨滑车上：鹰嘴窝（深窝）
端 │  肱骨滑车（滑轮面）上：冠突窝（浅） │  滑车 ← 同一关节面的后面
   │  内外两侧：内上髁 / 外上髁        │  内上髁后外侧：尺神经沟
   │                                  │  骨干后面：桡神经沟
   └──────────────────────────────────┴──────────────────────────┘
```

读图：同一根骨头的前后两面看的是同一批结构，只是下端两个窝分前后来：前方是浅的（桡窝、冠突窝），后方是深的（鹰嘴窝）。

> **提示**：肱骨小头上方的窝叫**桡窝**，肱骨滑车前上方的窝叫**冠突窝**，滑车后上方的窝叫**鹰嘴窝**。前浅后深，这是这一段最容易混的地方。

#### 外科颈与解剖颈

结构看过以后，我们要说几个特别重要的名称。

**骨骺和骨干相接的这个部位**，有个名称叫**外科颈**；**关节面周缘**这个叫**解剖颈**。这两个"颈"是肱骨上最常考的定位点。

#### 骨折断在哪里，可能伤到哪根神经

现在我们看肱骨周围有哪些重要的毗邻，这部分一定要记住。

外科颈的**后方**有一个很重要的神经，从内向外走，叫**腋神经**；在**桡神经沟**里下来的一个神经，肯定就是**桡神经**；在**尺神经沟**下降的还有一个**尺神经**；肱骨的**内侧**有一个很粗大的动脉叫**肱动脉**，它在肱骨内侧下降，逐渐、逐渐转到下 1/3 的前方，然后进入前臂。

```text
   桡神经沟 ──────────► 桡神经    （沿骨干后面下行）
   尺神经沟 ──────────► 尺神经    （内上髁后外侧）
   外科颈后方 ───────► 腋神经    （自内向外走）
   肱骨内侧 ─────────► 肱动脉    （下 1/3 转到前方）
```

现在大家设想一下，把上面这些位置和骨折对上：

| 骨折部位 | 可能损伤 | 因为 |
| --- | --- | --- |
| 外科颈骨折 | 腋神经 | 外科颈后方，神经自内向外走 |
| 骨干中段骨折 | 桡神经 | 桡神经在桡神经沟里下行 |
| 内上髁骨折 | 尺神经 | 尺神经沟在内上髁后外侧 |
| 下 1/3 骨折 | 肱动脉 | 肱动脉在肱骨内侧下降，逐渐转到下 1/3 前方 |

> **结论**：肱骨这块记住三件事——一，结构（肱骨头、大小结节、结节间沟、内外上髁、桡窝、冠突窝、鹰嘴窝、桡神经沟、尺神经沟）；二，外科颈与解剖颈两个名称；三，上表这一串"骨折部位—受损神经"对应关系。

#### 体表摸得着的

体表能摸到的就两个：**内上髁**和**外上髁**。其他的结构，体表都摸不到了。

### 前臂骨：认出谁是谁

前臂骨就两块：一个是**桡骨**，一个是**尺骨**。

先认人。在挂图上从前方看和从后方看，哪一个是桡骨？注意四个字：**上小下大**。上端细、下端粗的是**桡骨**；上大下小的是**尺骨**。

#### 桡骨

桡骨上端膨大的这个部位叫**头**，头下方变细的叫**颈**；这块儿有一个肌肉的附着点，叫**桡骨粗隆**。下方要记住有一个骨刺，叫**桡骨茎突**，再往下是个关节面，和腕骨构成关节。

头这个位置上还有关节面值得记：朝向上的这个浅盘状关节面叫**头凹**，周围一圈叫**环状面**——所以桡骨头是由两个关节面构成的。下方桡骨的茎突旁边，朝下的关节面叫**下关节面**，这里还有一个切迹叫**尺切迹**。

#### 尺骨

尺骨前方有一个骨性突起叫**冠突**，后方比较大的突起叫**鹰嘴**，两个突起之间的关节面叫**滑车切迹**。这块还有一个**桡切迹**。下边是**尺骨头**和**尺骨茎突**。

对照起来记：

| | 桡骨 | 尺骨 |
| --- | --- | --- |
| 上端 | 头（头凹 + 环状面）、颈 | 冠突、鹰嘴，其间为滑车切迹 |
| 骨干部 | 桡骨粗隆（肌肉附着点） | 尺骨粗隆（肌肉附着点） |
| 下端 | 桡骨茎突、下关节面、尺切迹 | 尺骨头、尺骨茎突 |
| 体表特征 | 上小下大 | 上大下小 |

#### 切迹：和谁成关节，就叫谁

前臂骨里我们特别注意这两个**切迹**，它们的命名规律是统一的：

```text
   尺骨上的「桡切迹」  ←── 关节面是环状面，抱在【桡骨头】外面
            ▲
            │  名字来自对面那块骨
   桡骨上的「尺切迹」  ←── 关节面是头凹，套在【尺骨头】外面
```

> **结论**：和谁构成关节，就叫什么切迹。尺骨上那个和桡骨头成关节的叫**桡切迹**，桡骨上和尺骨头成关节的叫**尺切迹**。记这一条就够了。

#### 体表摸得着的

从体表标志上看，**桡骨头**能摸到，**尺骨茎突**和**桡骨茎突**能摸到，**尺骨头**也能摸到。其他结构体表都摸不到了。

另外还有一个很容易被忽略的细节：图上这两个茎突，**高度是不一样**的。体表能摸到的两个茎尖不在同一条水平线上——桡骨茎突位置比较低，尺骨茎突比较高，相差 1 到 1.5 cm。

### 手骨：腕、掌、指三段

手骨由三部分构成：**腕骨、掌骨、指骨**。

我们先看这些长、宽、高近似相等的骨，也就是**短骨**构成的，叫**腕骨**；这五个是**掌骨**；其余 14 个是**指骨**。

> **定义**：腕骨 8 块、掌骨 5 块、指骨 14 块。

#### 腕骨：两排八块与腕管

先看靠近前臂骨的这块——这是**桡骨的下端**和**尺骨的下端**。注意，它们并不在一个高度上：桡骨茎突位置比较低，尺骨茎突比较高，相差 1 到 1.5 cm，这是正常的。

再往上就是我们看到的腕骨。腕骨有**近侧排**和**远侧排**，每排 4 块。

怎么排列、怎么命名？从**近侧排**开始数，由**拇指向小指**：**舟、月、三角、豆**；然后**远侧排**，还是由拇指向小指：**大多角骨、小多角骨、头状骨、钩骨**。

```text
              拇 ──────────────────→ 小指

  近侧排    ｜  舟   ｜  月   ｜ 三角 ｜ 豆 ｜
  远侧排    ｜大多角骨｜小多角骨｜头状骨｜钩 ｜
  ───────────────────────────────────────
  掌  骨    ｜  ①   ｜   ②   ｜   ③  ｜④⑤│

  口诀：舟月三角豆，大小头状钩
  对应：①—大多角骨   ②—小多角骨   ③—头状骨   ④⑤—钩状骨
```

读图：8 块腕骨按"舟月三角豆、大小头状钩"两排排列；下方 5 块掌骨一一对应远侧排，只有第四、五掌骨共用钩状骨。

第二个要给大家提的概念是**腕管**和**腕沟**。

我们把手做一个切面，从这个断面上看，腕骨有什么特点？腕骨的特点是**背侧面的面积大于掌侧面的面积**。以近侧排为例，舟骨背侧大于掌侧，月骨背侧大于掌侧，三角骨也是背侧大于掌侧。

这样骨排列在一起，就不在一个平面上了，于是形成一个**骨性的凹窝**，我们把这个凹窝叫做**腕沟**。

三角骨上方还有一个小圆形的骨，叫**豌豆骨**。所以近侧排的四块是舟、月、三角，加上这块豌豆骨。

```text
   背侧 →   舟      月      三角
            （每个骨的背侧都更宽）
   ╭───────────────────────────────╮
   │          腕  沟                │  骨不在一个平面上，凹下去
   │   ╭───── 腕横韧带 ─────╮       │
   │   │       腕  管        │       │  韧带一封，沟就变成管
   │   ╰─────────────────────╯       │
   ╰───────────────────────────────╯
```

读图：腕骨背宽掌窄，排列成骨性凹窝即腕沟；腕横韧带在沟口一封，腕沟就变成了腕管。

那么管里边有什么结构？这里先点个名，以后会继续介绍：**拇长屈肌**的肌腱 1 个、**指深屈肌**的腱 4 个、**指浅屈肌**的腱 4 个，再加上一个重要的神经——**正中神经**。

> **结论**：腕骨这块，我们记住有"腕沟"和"腕管"两个概念就够了。腕管里通过的结构记住两个数字：**9 个肌腱，1 个神经（正中神经）**。

#### 掌骨：底、体、头

再往下就是掌骨，从拇指向小指依次是第一到第五掌骨，排列和命名就是 1、2、3、4、5，没有别的花样。

重点是结构上的命名。如果把掌骨放大：**底**在最下方，中间是**体**，末端是**头**。由于掌骨末端是个球状面，所以我们这个掌指关节既能屈伸，又能内收外展，还可以做环转——运动形式比较多，和这个结构有关系。

#### 指骨：近中末与滑车

指骨大家看，拇指是几节？两节。其余的都应该三节。

排列命名就是拇指、食指、中指、四指、小指。那三节怎么叫？**近节、中节、末节**，近中末。

关键还是结构命名。把指骨放大，注意指骨末端的关节面：两侧高、中间凹，它是滑车状的，所以叫**滑车**；近端叫**底**，中间叫**体**。

> **结论**：指骨末端是滑车，所以**指间关节只能做屈伸**——这个关节运动形式的限制，是由关节面的形状直接决定的。和前面掌指关节的球状面一比，就更清楚了。

再说指骨的**末节**。末节没有关节面了，末端叫**甲粗隆**，指甲就附着在这个骨面上。结构上还是**底、体**加甲粗隆。

那么小指的指骨，它到底算长骨还是短骨？看特点就行：**具不具有"一体两端"**。具有一体两端的就是长骨。答案是长骨。

#### 籽骨：X 光片上的那两个白点

最后提一个**籽骨**。籽骨在什么位置？**第一掌骨头的掌侧面**，有一对小骨，就叫籽骨。

所以今后在 X 光片上看到这个地方有两个浓白的阴影，**不要当成异物**——这是正常的。但它**不属于 206 块骨**里面。

以上就是我们提到的上肢骨。

## 从髂、坐、耻三块骨到关节的“三件套”
> 对应块：BLK06 | 覆盖分集：P08-P09 | 块标题（分集名）：《8.骨学-附肢骨-下肢骨》

上肢骨过完了，我们接着往下走。下肢骨的分法跟前面一模一样，也是分两拨：一拨叫**肢带骨**，一拨叫**自由骨**。唯一的区别是，下肢的肢带骨只剩一块，名字叫**髋骨**。

你现在摸自己的髋骨，它是一整块；可在发育过程中，它可是三块骨拼起来的。这块骨怎么拼、拼完长什么样、哪些位置隔着皮就能摸到，我们一段一段看。

### 髋骨：髂、坐、耻拼成的一块骨

先看挂图上这块小孩子的髋骨——它把发育过程直接摆在你眼前了。髋臼窝里有一横一竖两块软骨板，组成一个“T”字型，把髋骨劈成三块：上面一块叫**髂骨**，后下面一块叫**坐骨**，前面那一块叫**耻骨**。髂、坐、耻三块骨就是靠这副“T”字型软骨板连在一起的，等到 16 岁以后骨化了，才变成一整块髋骨。

```text
                  髂骨
        ┌───────────┴───────────┐
        │      横的软骨板       │
        └───────────┬───────────┘
                    │
    耻骨 ───────────┴─────────── 坐骨
               竖的软骨板
           16 岁以后骨化为一体
```

> **易错点**：这副软骨板不仅是解剖上的事实，还是一把“认名”的钥匙。三块骨各有各的势力范围——髂骨上的结构全带“髂”字，坐骨上的结构全带“坐”字，耻骨上的结构全带“耻”字。你拿到一个不认识的名字，先判断它长在哪块骨上，名字基本就猜对了一半。

#### 内侧面：那条弓状线，把骨盆分成了大小两半

内侧面是识别髋骨的主战场。先分清方向，这里是前、那是后。

上缘有一条弓形的骨缘，体表从头到尾都能摸到，这叫**髂嵴**。髂嵴前端的突起叫**髂前上棘**；从髂前上棘向上走大约 3 到 4 厘米，髂嵴在这里明显增厚，这块隆起叫**髂结节**——挂图上画得不够明显，一会儿板图上再强调，而它恰恰是临床上骨穿的部位。

再往里看，有一块粗糙的骨面，叫**耳状面**，因为形状像耳朵得名。

最关键的是那条骨线。从前往后看，骨线先是锐利的，从耻骨上缘一路斜着往外，这一段叫**耻骨梳**；再向后内侧转，骨线变得钝圆，这一段叫**弓状线**。

> **结论**：弓状线是**大骨盆和小骨盆的分界线**。线以上是容纳腹腔内容物的大骨盆，线以下是通向体外的骨盆腔。

后下方的突起是**坐骨结节**，它上方有一个尖尖的**坐骨棘**；坐骨棘上方的缺口是**大切迹**，下方的缺口是**小切迹**。前方那个大窟窿叫**闭孔**，闭孔上缘那张窄窄的骨面叫**耻骨联合面**。

#### 板图上再走一遍：这些名字要求你背下来

板图把髋骨摊平了给我们看。走一遍：前方是**髂前上棘**，往下是**髂前下棘**（这个不要求大家记，知道有这么个东西就行），再往内是**髂耻隆起**；然后是**耻骨梳**、**耻骨结节**、**耻骨联合面**，联合面往后外侧出去的一段叫**耻骨弓**；后下方是**坐骨结节**、**坐骨棘**，棘上是大切迹，棘下是小切迹；后面是**髂后上棘**和**髂后下棘**；再往前，那块粗糙的**耳状关节面**、钝圆的**弓状线**、以及**闭孔**，又都回到我们的视线里。

正式点名要记住的，是这么一批：

> **结论**：髂前上棘、髂结节、髂嵴、耳状面、耻骨梳、弓状线、髂耻隆起、耻骨结节、耻骨联合面、坐骨结节、坐骨棘、大切迹、小切迹。内外侧都出现的那一串（耻骨弓、耻骨结节、坐骨结节、坐骨棘、大切迹、小切迹、闭孔）也分清归属。

#### 外侧面：只要牢牢记住那个很深的窝

外侧面的结构跟内侧面的基本是一套（大切迹、坐骨棘、小切迹、坐骨结节、耻骨弓、耻骨结节、闭孔都在），只有一样东西是外侧面独有的，而且极其醒目：这块骨上有一个**很深很深的窝**，它叫**髋臼**。

髋臼是干什么的？它是下肢骨往躯干骨上“装”过去的地方——躯干骨那个向上的凹窝接住股骨头，接的就是这里。所以外侧面你只要认准一个词：**髋臼**。

#### 摸得到的那些，就是有临床价值的那些

- **髂嵴**：体表全程能摸到，是最方便、也最常被引用的骨性标志。
- **髂结节**：临床做骨穿（骨髓穿刺）选这里。为什么？因为表面就是皮，一按到底，不用穿过太多软组织。
- **髂前上棘**：重要的体表标志。经典的阑尾压痛点就在**脐与髂前上棘连线的中外三分之一交界处**。
- **耻骨结节、坐骨结节**：体表都能摸到。

还有一个必须记住的对应关系：两侧**髂嵴的最高点，对应的是第四腰椎的棘突**。

### 股骨：全身最长的一根骨头

下肢的自由骨里，第一根是股骨。它是我们身体里面最长的骨——没有之一，所以它身上的结构名也最多。

从挂图上看，股骨最大的特点在**上端**：上面是个球状的**头**，往下是一段细的**颈**，但这个颈不是直上直下的，它是个“歪脖子”。外侧这个骨性突起叫**大转子**，内侧的叫**小转子**。

> **易错点**：这里特别容易跟肱骨搞混。肱骨是外侧一个大结节、前内侧一个小结节；而股骨的小转子甩到了**后内侧**，大转子在外侧——方向不一样。记住：大转子在外，小转子在后内。

两个隆起之间那条粗糙的骨线，叫**转子间线**。

下端呢？两侧各有突出的**侧髁**，分别叫**内侧髁**和**外侧髁**；在前方正中，有一块和髌骨构成关节的关节面，叫**髌面**。

翻到后面看，除了同样的头、颈、大转子、小转子和两个侧髁，还多出两样东西：一个是后方骨干上一条粗糙的骨线，叫**股骨粗线**，内收肌群全都附着在这条线上；另一个是两个侧髁关节面之间凹进去的那个骨性凹窝，叫**髁间窝**。

板图上再强调一次：后方的股骨粗线越往下越锐利，到下端变成一条骨棱，两条棱之间夹着的凹陷就是髁间窝。旁边还有一块骨面比较粗糙的，叫**臀肌粗隆**——臀大肌就止在这个地方。

要求记住的名词：大转子、小转子、内侧髁、外侧髁、髌面、转子间线、股骨粗线、髁间窝、臀肌粗隆。

体表标志方面，**大转子**和**两个侧髁**都是隔着皮肤能摸到的。至于髌骨，这里先不展开。

### 小腿骨：胫骨在里面，腓骨在外面

小腿骨是两块：里面是**胫骨**，外面是**腓骨**。

#### 胫骨：上方粗大，前缘最锐利

胫骨上粗下细，是小腿的承重主力。往上走，两侧的突起也叫**侧髁**，分别是**内侧髁**和**外侧髁**；上端关节面的中部向上鼓起一个骨性突起，叫**髁间隆起**；上端的前方有一个骨性隆起，叫**胫骨粗隆**，它是肌肉的抵止点。

胫骨最好认的是它的**前缘**——从粗隆往下一路向下，这条骨缘非常锐利，所以叫**胫骨前嵴**（也叫胫骨前缘）。把手掌放在自己小腿前面从上往下压，能明显感到一条“刀背”，那就是它。

下端有两个结构：内侧的骨性隆起叫**内踝**；朝下的那个关节面叫**下关节面**。

#### 腓骨：只需要记两个名词

腓骨细长，不承重，功能上更像配角，所以它的骨性标志也最简单：**上面一个膨大叫腓骨头，下面一个膨大叫外踝**。就这两个，记住就够用。

从后面看，小腿下端两侧的突起就是内踝和外踝，外侧能摸到的最高点是腓骨头。

> **结论**：小腿骨上要背的名词——胫骨侧髁（内、外）、胫骨粗隆、髁间隆起、胫骨前嵴、内踝、下关节面；腓骨的腓骨头、外踝。体表能摸到的：两个侧髁、胫骨粗隆、胫骨前嵴、内踝、外踝、腓骨头，全都能摸到。

### 足骨：7、5、14

足骨分三部分，数目记牢——**跗骨 7 块、跖骨 5 块、趾骨 14 块**。

| 部分 | 数目 | 构成与命名 |
| --- | --- | --- |
| 跗骨 | 7 | 距骨、跟骨、足舟骨、骰骨、第一至第三楔骨 |
| 跖骨 | 5 | 第 1～5 跖骨，结构命名同手骨：底、体、头 |
| 趾骨 | 14 | 第 1～5 趾，每趾节数不等，结构命名：底、体、滑车，末端有甲粗隆 |

#### 跗骨：靠位置命名，最好记

看板图：靠内侧有一个小骨，叫**距骨**；它的下方有一个又长又大的，叫**跟骨**。再往外，**骰骨**的内侧紧贴着**舟骨**（正式名称叫足舟骨），最外面三块依次是**第一、第二、第三楔骨**。

命名全靠位置：前三块都叫楔骨，第四块叫骰骨，骰骨里面那一块叫舟骨；上面小的那个叫距骨，下面长大块的那个叫跟骨。

> **提示**：给你一句顺口溜，把七块跗骨一串到底——**一二三楔骰内舟，上距下跟后出头**。后方突出的那个叫**跟结节**。

#### 跖骨和趾骨：跟手骨几乎一个模子

跖骨的排列还是按 1、2、3、4、5 来，结构命名跟手骨非常相像：**底、体、头**。

再往前是趾骨，结构命名是**底、体、滑车**，最末端那一块粗糙的隆起叫**甲粗隆**——跟手骨的构造基本一致，所以这块我们就不详细展开了。

### 把上下肢的体表标志捋一遍

下肢骨讲完了，趁热把上下肢能在体表摸到的骨性标志统一捋一遍。这些是体表标志的清单，也是临床定位的底子，一定要记牢。

#### 上肢：从锁骨一路摸到指尖

**锁骨**：全长注意，都能摸到。锁骨外侧端上方还能摸到一个结构，叫**肩峰**。

**肘部**：肱骨下端向两侧突起，分别叫**外上髁**和**内上髁**；屈肘的时候，下方那个尖叫**鹰嘴**（尺骨的）。内上髁、外上髁、鹰嘴，这三点就是肘部最经典的体表标志。

**手部**：前臂桡骨下端、尺骨下端各有一个尖，叫**桡骨茎突**和**尺骨茎突**，两者相差 1 到 1.5 厘米。再往前一点，还能摸到一块绿豆大小的骨，**豌豆骨**。

**握拳的时候**，手背上冒出的一串骨性隆起就全暴露了：每个突起都是一根**掌骨头**；再往前是**指骨**——拇指有第一节、第二节，示指有第一节。指骨的结构是**底、体、滑车**，末端是**甲粗隆**。所以握拳时手上摸到的这些包，全是掌骨头和指骨滑车。

#### 下肢：从髂嵴一路摸到外踝

**髋部**：整圈能摸到的是**髂嵴**；它前方是**髂前上棘**，重要的体表标志；髋关节外侧是**大转子**；后面是**坐骨结节**。

> **结论**：把**坐骨结节**和**大转子**连一条线，这条线的中点下面走着一根重要的神经——**坐骨神经**。记住这个点位，将来定位坐骨神经痛一类的病变就有着落了。

**膝部**：上面是股骨，下面是胫骨，前面是髌骨（旁边的腓骨比胫骨短，缩在下面）。这一圈能摸到的是：股骨的**内侧髁、外侧髁**，胫骨的**内侧髁、外侧髁**，再加前方的**髌骨**。

**小腿**：**髌骨**、**胫骨粗隆**、**胫骨前嵴**，再往下就是**足背**和**内踝**；外侧还有腓骨的**腓骨头**（上）和**外踝**（下）。

> **提示**：体表标志要记牢，同时别忘了另一件事——**记住每块骨上到底有几个关节面**。因为下一步讲关节，这些知识马上要用。比如**尺骨上端有几个面**？桡切迹、滑车切迹，两个；**桡骨上端有几个面**？桡骨头凹、环状关节面，也是两个。带着这种“数面”的意识去学关节，学起来会顺很多。

### 骨与骨怎么连：直接连接和间接连接

讲完骨，接下来进入关节。第一个问题是：全身的骨与骨之间，一共有两种连接方式——**直接连接**和**间接连接**。

什么叫直接连接？举两个例子你立刻就明白了。第一种：颅骨是弓形的，一块挨一块，靠**骨缝**连接，而骨缝里面藏着一条韧带，叫**缝韧带**——它是长在骨缝里面的。第二种：两块骨之间靠**软骨**连接在一起。除此之外，还有靠骨性结合的。这几种形式的共同点是：都是借助韧带、软骨或者骨这样的结构，把两个骨直接连在一起。

它最突出的特点是什么？**两骨之间没有间隙**。骨缝里没有间隙，靠软骨连接的两块骨之间也没有间隙。试想一下：两块骨连得这么死，活动度能大吗？所以直接连接的活动度很小，甚至完全没有活动度。

间接连接就不一样了：骨与骨之间是借助**结缔组织囊**相连接的。既然中间隔了一个囊，两骨之间自然**有间隙**，活动度就大。这种连接方式就叫**关节连接**，也正是我们接下来要重点讲的东西。

| | 直接连接 | 间接连接（关节连接） |
| --- | --- | --- |
| 靠什么连 | 韧带、软骨、骨性结合 | 结缔组织囊（关节囊） |
| 两骨之间 | 没有间隙 | 有间隙 |
| 活动度 | 很小或没有 | 大 |
| 例子 | 颅骨的骨缝（缝韧带） | 膝关节、肩关节等 |

所以骨连接就这两种，重点全压在间接连接这一边。

### 关节的基本结构：囊、面、腔

> **定义**：相邻两骨的相对面必须具有**关节面**；两骨之间靠**结缔组织囊**相连；两骨之间又存在腔隙，叫**关节腔**。

把这三个字连起来记，就是**囊、面、腔**。三个条件齐备，这才叫一个关节，缺哪一个都不成立。

```text
       ┌──────────────┐
       │   关节囊     │
       │ （两层结构） │
       └───────┬──────┘
   ┌───────────┴───────────┐
   │       关节腔          │
   │    （内有滑液）       │
   └───────────┬───────────┘
   ▓▓▓▓▓▓▓▓▓▓▓▓      关节面         ▓▓▓▓▓▓▓▓▓▓▓▓
        骨                             骨
```

> **结论**：关节的三件套——**囊、面、腔**。囊是外层的包被，面是两块骨相对的骨面，腔是囊里那个让骨面互不直接接触的空间。

### 关节的辅助结构：把关节装得更稳

光有囊面腔，关节只做到“能连上”。真正让它经得起拉扯的，是关节的辅助结构，一共三类。

#### 囊内韧带：膝关节里的那对十字

先说为什么叫“囊内”韧带：大多数关节在关节囊**外面**就有韧带，所以长在囊里面的韧带其实很少。典型的例子就是膝关节。

看膝关节：上面是股骨下端，下面是胫骨上端，前面是髌骨。这个关节里有一对韧带，形状从侧面看是个十字，所以叫**十字交叉韧带**——一条叫**前交叉韧带**，一条叫**后交叉韧带**。它们起自胫骨的髁间隆起（一个从前方进去，一个从后方进去），止于股骨的**髁间窝**，所以正好交叉。

它们就长在关节腔里面，属于关节辅助结构中的**囊内韧带**。

#### 关节盘与关节唇：想办法让接触面积变大

**关节盘**就是个软骨结构。还是拿膝关节举例：股骨的内侧髁、外侧髁对着下面胫骨的关节面，接触面本来就只是两个平面。为了让它们贴合得更牢、更稳，关节面中间垫进一块块软骨垫，把接触面积扩大——这种软骨结构就叫做**关节盘**。

> **结论**：关节盘的作用就一句话：**增大两个关节面的接触面积，从而提高关节的稳固性**。

**关节唇**是另一个思路。肩关节由肩胛骨的**关节盂**和**肱骨头**构成，从形状上就能看出问题：关节窝是个很浅的浅盘，面积小；而肱骨头是半球状，面积大得多。小锅配大锅，当然不稳。

解决办法是：在关节盂的边缘绕一圈软骨环，贴在骨板上，相当于给窝“加了一圈边”，把关节凹的面积撑大。肱骨头装进去以后，稳定性明显加强。这圈软骨结构，就叫**关节唇**。

#### 滑膜襞和滑膜囊：膝关节里的髌上囊和翼状皱襞

第三类是滑膜结构的两个小玩意：**滑膜襞**和**滑膜囊**，它们在膝关节里能一次看全。

把膝关节放大看：上面是股骨下端，断面露出松质的网眼；下面胫骨也被断开，露着同样的网眼；前面是髌骨。先交代髌骨的位置关系：上面有块大的肌肉叫**股四头肌**，它的肌腱把髌骨包起来，一直抵止在**胫骨粗隆**上。

问题随之而来：关节活动的时候，髌骨和股骨下方的**髌面**相互摩擦。怎么减少这种摩擦？看看关节囊内层的滑膜是怎么变的：从关节面的周缘往上，滑膜层鼓起来形成一个小囊，形成一个**皱襞**，而皱襞里面装的**全是脂肪组织**。

这个三角形的结构，在膝关节里叫**翼状皱襞**，它就是**滑膜襞**。它存在是有道理的：关节囊的滑膜层包着大量脂肪，凸进膝关节这个本来就很大的腔隙里，把腔隙面积缩小，反而**有利于关节的稳固**。

```text
             股四头肌
                 │
         （肌腱包住髌骨）
                 │
               髌骨
                 │  ← 与股骨的髌面相互摩擦
   ┌─────────────┴──────────────┐
   │  翼状皱襞（滑膜襞）        │ ← 滑膜层包着脂肪，凸入关节腔
   │                            │
   │  关节腔（滑液）            │
   │                            │
   └──────┬──────────────┬──────┘
          │   髌上囊     │ ← 滑膜囊
          └──────────────┘
```

而关节囊上方鼓起来的那一个囊腔，从髌骨上缘往上顶出来的，叫**髌上囊**，它就是一个**滑膜囊**。它为什么必须在？因为髌骨和股骨之间要来回运动，如果囊腔里只有少量滑液，肌腱和骨面就能直接对上、直接磨；有了这个囊、有了这点滑液，骨面和肌腱就被隔开了，**摩擦就小得多**。

> **结论**：总论这一讲就三句话——骨连接分**直接**和**间接**两种，重点在间接连接，所以也叫关节连接；关节的基本结构是**囊、面、腔**三要素；辅助结构有三类——**囊内韧带**、**关节盘与关节唇**、**滑膜襞与滑膜囊**，它们共同的作用都是把关节弄得更稳、摩擦更小。
