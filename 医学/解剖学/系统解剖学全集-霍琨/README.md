# 系统解剖学全集（霍琨）

霍琨老师的系统解剖学全集，按人体系统逐章讲解运动、消化、呼吸、循环、泌尿与神经等系统的解剖结构，配合影像资料与示意图，是医学入门者的解剖学主干课。

- **原视频**：https://www.bilibili.com/video/BV1S1QAY8Eqk — Bilibili，BV1S1QAY8Eqk
- **59 集**，已产出 17 册模块全书、31 篇复习笔记、47 份逐字稿

## 怎么学

- **按系统推进** → 课程按运动、消化、呼吸、循环、泌尿、神经等系统依次展开
- **图文对照** → 建议配合教材插图与解剖图谱记忆结构位置
- **反复回看** → 解剖学重空间关系，第一遍建立框架、第二遍巩固细节
- **速查** → `notes/` 下的笔记按系统归类，便于考前回顾
