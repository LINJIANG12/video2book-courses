# 脉管系·心脏：外形、四个腔、瓣膜、传导系与心包

## 心血管系的构成与两个循环

* **心血管系**

    * > **定义**：由心脏、动脉、静脉和毛细血管四大部分构成。
    * 四者不是并列的零件，而是同一条接力链上的四棒：心脏泵血 → 各级动脉把血从心室送到毛细血管 → 毛细血管完成营养交换 → 各级静脉把血收回心房。
    * 血液一去一回，构成一个完整的环路。
    * 心脏本身分左右半心，每一侧又被房室瓣分成上下两半，合起来就是四个腔。

* **体循环（大循环）**

    * > **定义**：从左心室出发、回到右心房结束的血液循环大环路。
    * 路线：左心室 → 各级动脉 → 全身毛细血管 → 各级静脉 → 右心房。
    * 走遍全身，在全身毛细血管完成营养交换。
    * 起点是心室、终点是心房。

* **肺循环（小循环）**

    * > **定义**：从右心室出发、回到左心房结束的血液循环环路。
    * 路线：右心室 → 肺动脉 → 肺毛细血管 → 肺静脉 → 左心房。
    * 右心房内的静脉血在心房收缩时被送入右心室。
    * 在肺毛细血管完成气体交换，血液由静脉血变为动脉血。
    * 只走一趟肺，起点是心室、终点是心房。

* **两个循环的判别与相接**

    * 记忆口诀：大环全身、小环肺，两个循环不会张冠李戴。
    * 两个环的起点都是心室、终点都是心房。
    * 首尾相接顺序：右心房 → 右心室 → 肺循环 → 左心房 → 左心室 → 体循环 → 右心房。

    ```text
    【体循环（大循环）】  左心室 ──▶ 各级动脉 ──▶ 全身毛细血管 ──▶ 各级静脉 ──▶ 右心房
                            ▲                                                 │
                            └─────────────────────────────────────────────────┘

    【肺循环（小循环）】  右心室 ──▶ 肺动脉 ──▶ 肺毛细血管 ──▶ 肺静脉 ──▶ 左心房
                            ▲                                             │
                            └─────────────────────────────────────────────┘
    ```

## 纵隔的分部与心脏的位置

### 纵隔的三分部与上下纵隔

* **纵隔（mediastinum）**

    * > **定义**：纵隔胸膜从左到右把胸腔一分为二后，两肺之间的那部分区域。
    * 分出的两半里装的就是肺：右肺三个叶，左肺两个叶。
    * 借助于心包分为前纵隔、中纵隔、后纵隔三部分。

* **前、中、后纵隔**

    * 前纵隔：胸骨与心包之间。
    * 中纵隔：心包里面。
    * 后纵隔：心包之后、脊柱之前。
    * 后纵隔的代表结构是食管和胸主动脉，两者都从上往下走行。

* **上纵隔与下纵隔**

    * > **定义**：以心包为界，心包以上叫上纵隔，心包上缘往下到膈肌中心腱叫下纵隔。
    * 心包里面就是心脏。
    * 心包上方是出入心脏的大血管。
    * 胸主动脉位于后纵隔内，向下走行。

### 心脏的位置与体表地标

* **心脏的位置**

    * > **结论**：心脏位于中纵隔内，略微偏左。
    * 在胸部水平断面上，心脏所在的断面能断出左右心室的断面。
    * 心脏是依靠大血管吊在半空里的，搏动时心尖向前顶压肋间肌，因而产生心尖搏动。

* **两个地标**

    * 胸骨上叫胸骨角，对应第 2 肋。
    * 后方脊柱上的对应位置是第 5～8 胸椎。

* **心尖搏动点**

    * 落在左侧第 5 肋间隙，位置在左锁骨中线内侧，距前正中线 1～2 cm。
    * ⚠️ **易错点**：心尖搏动点在第 5 肋间隙，不要和心尖的朝向搞混——心尖朝左前下，搏动点却在第 5 肋间隙、锁骨中线内侧。

    ```text
            胸骨中线         左锁骨中线
                │                 │
       第2肋 ───┼─────────────────┤   ← 胸骨角，平对第 2 肋
       第3肋 ───┼─────────────────┤
       第4肋 ───┼─────────────────┤
                │                 ●   ← 第 5 肋间：心尖搏动点
       第6肋 ───┼─────────────────┤
    ```

### 心脏的毗邻关系

    * 前面观、牵开两侧肺并剖开心包即可暴露上方的出入心脏大血管（静脉与动脉混杂，含肺动脉）。
    * 前方紧邻的骨性结构中，重点记住肋软骨；后方对应的骨性结构是胸椎体。
    * 心脏与膈肌、两侧肺及胸膜腔之间构成下、上和两侧的毗邻。

| 方位 | 毗邻的结构 |
| :--- | :--- |
| 前方 | 胸骨与第 1～6 肋软骨（重点记住肋软骨） |
| 后方 | 第 5～8 胸椎体 |
| 两侧 | 肺与胸膜腔 |
| 上方 | 出入心脏的大血管（主动脉、肺动脉、腔静脉等） |
| 下方 | 膈肌 |

## 心脏的外形

* **外形总纲**

    * > **结论**：从前面看是倒置的锥形体——上面宽、下面收成一个尖的中空洞性肌性器官。
    * 可概括为一句话：一尖、一底、两个面、三个缘、四条沟。

### 一尖一底与心脏长轴

* **心尖**

    * 朝向左前下，不是正前下。
    * 特点是圆钝、游离，不和任何结构连接。

* **心底**

    * 朝向右后上。
    * 从后方看基本就是心底及心底上大血管的名称：上方的主动脉、左右肺动脉、左右肺静脉（每侧一对，共四支）、上腔静脉、下腔静脉。
    * 从前方看的辨识顺序：上腔静脉 → 向上走的主动脉 → 主动脉左前方的肺动脉 → 右心耳 → 左侧的左心耳 → 下缘心尖 → 下方下腔静脉。

* **心脏长轴**

    * 心尖朝左前下、心底朝右后上，两端不在一条竖直线上。
    * 因此心脏的长轴是斜行的。
    * 这是理解心脏各个面都带方向的总钥匙。

### 两个面与三个缘

* **胸肋面与膈面**

    * 胸肋面：对着胸骨和肋软骨的那一面。
    * 膈面：朝下、与膈肌相对的那一面。
    * 侧位观察时：上方为主动脉，左边为左心耳，往上走的是上腔静脉，下面是下腔静脉。

* **三个缘**

    * 右缘近似于垂直。
    * 下缘近似于水平。
    * 左缘是斜行的。

## 心脏表面的四条沟与房室交点

* **冠状沟**

    * > **结论**：冠状沟是心房与心室的表面分界。
    * 围绕心底呈环形，但被肺动脉拦腰分断。
    * 严格说并不算一条完整的沟，实际是浅沟，位置多被脂肪组织充填。
    * 沟以上是心房、以下是心室。

* **前室间沟与后室间沟**

    * 前室间沟在前面，呈一条浅沟，经心脏下缘反折到膈面。
    * 后室间沟是从后面看到的那条。
    * 一前一后两条把左右两个心室分开，是左右心室的表面分界。

* **房间沟**

    * 是往上走的那条，把左右心房分开，是左右心房的表面分界。

* **房室交点**

    * 四条沟一对一对地交在一点上，该点叫房室交点。
    * 冠状沟是横的一条，房间沟和室间沟是竖的两条，三条沟在中心交成十字形。

    ```text
                     冠状沟：心房与心室之间的表面分界
            ┌──────────────┬──────────────┐
            │     左房      ║     右房      │
            │              ║              │
            ├──────────────╫──────────────┤   ║ 房间沟，分开左右心房
            │     左室      ║     右室      │   ║ 后室间沟，分开左右心室
            │              ║              │
            └──────────────┴──────────────┘
                           ↑
                         房室交点：三条沟在这里相交
    ```

## 右心房

### 心耳、界沟与界嵴

* **右心耳**

    * 心脏右前方一个锥体形凸起，尖端朝向左侧。
    * 内腔与心房相通，不是封死的口袋。
    * 内壁同样粗糙，有许多肌肉隆起。
    * 右心房的打开方式：从界沟处把房壁连心耳一起切开，将房壁翻转展开。

* **界沟与界嵴**

    * 界沟是右心房外侧壁上的浅沟，圈出上腔静脉与下腔静脉前缘连起来的那一片区域。
    * 固有心房与腔静脉窦的内部分界是界嵴。
    * ⚠️ **易错点**：界沟在外、界嵴在内，是同一个位置的一外一内。外面看是条沟叫界沟，里面隆起叫界嵴，合起来看两者严丝合缝对在一条线上。

* **右心房内壁的两个特点**

    * 心耳内壁与翻开的这部分房壁都粗糙，布满梳状肌。
    * 腔静脉那一片的内壁是光滑的。
    * 右心房分两部分的依据就是粗糙与光滑之别。

### 固有心房与腔静脉窦

* **固有心房（固有心腔）**

    * > **定义**：由梳状肌等结构围成的腔室部分。
    * 与腔静脉窦相通。

* **腔静脉窦**

    * > **定义**：由内壁光滑的那部分围成的腔室部分，对应界沟所圈的外部区域。

### 房内隆起与孔道

* **梳状肌**

    * 心房壁内面上平行排列的肌隆起，像木梳的齿。

* **卵圆窝**

    * 位于房中隔上，是一个卵圆形的压迹。
    * 是胚胎时期卵圆孔闭锁以后形成的遗迹。

* **主动脉隆突**

    * 另一块卵圆形突起。
    * 主动脉根部膨大形成三个动脉窦，朝右房这一侧的是后窦，后窦向腔内一凸即形成该隆突。

* **三个入口**

    * 上腔静脉口。
    * 下腔静脉口。
    * 冠状窦口——冠状窦是心脏自身静脉血回心的口，所以在右心房开口。

* **一个出口**

    * 右房室口，从心房通到心室，此处装着三尖瓣。

## 右心室

### 漏斗部与肉柱部

* **右心室的位置**

    * 胸部水平断面上最靠前的那腔就是右心室。
    * 心内注射选在胸骨左缘第 4 肋间隙，药物推进去的正是右心室。

* **漏斗部**

    * 右心室上部内壁光滑的部分，形状像倒置的漏斗。
    * 相当于动脉干的起始段，上方通向肺动脉口。

* **肉柱部**

    * 右心室下部内壁粗糙的部分，容纳肉柱、乳头肌、腱索。
    * 下方接右房室口。

* **室上嵴**

    * > **定义**：漏斗部与肉柱部之间的一条弓形肌隆起，构成两者的分界。

    ```text
              肺动脉口（肺动脉瓣）
                     │
            ┌────────┴────────┐
            │     漏斗部       │   内壁光滑，相当于动脉干的起始段
            ├─────────────────┤ ← 室上嵴：一条弓形肌隆起，作分界
            │     肉柱部       │   内壁粗糙，容纳肉柱、乳头肌、腱索
            └────────┬────────┘
                     │
              右房室口（三尖瓣）
    ```

### 内壁结构：肉柱、乳头肌、腱索、隔缘肉柱

* **肉柱**

    * 纵横交错排列的肌隆起，纵横成网。

* **乳头肌**

    * 肉柱里更粗、明显向腔内突起的那一类。

* **腱索**

    * 连在乳头肌上的一束束纤细索状结构，另一端连到瓣膜的游离缘。
    * 功能是牵拉瓣膜。
    * 心室舒张时腱索放松，血液冲开瓣膜进入心室；心室收缩时乳头肌收缩、腱索被拉紧，瓣膜被拉住，不至于被血液顶向心房翻卷。

* **乳头肌与腱索的对应**

    * 腱索有 3 组瓣膜，乳头肌也得有 3 组，一一对应。
    * 膈侧乳头肌连膈侧瓣，后乳头肌连后瓣，前面的连前瓣。

* **隔缘肉柱（膈缘肉柱）**

    * 包括两部分：一部分是室间隔上的肌隆起；另一部分是横跨室腔、一直到前乳头肌根部的索状结构。
    * 内部通过心脏传导系的右束支。
    * 「隔缘肉柱里跑着传导束」是必记的一条。

### 入口、出口与半月瓣机制

* **入口**

    * 右房室口，装着三尖瓣——前瓣、后瓣、隔侧瓣三个瓣。

* **出口**

    * 肺动脉口，装着肺动脉瓣。
    * 三个半月瓣的名字是前瓣、左瓣、右瓣。

* **肺动脉窦**

    * 把肺动脉切一段向外展开，可见动脉壁里有 3 个半月状瓣膜。
    * 瓣膜张开时，瓣膜与动脉壁之间形成三个间隙，这三个间隙叫肺动脉窦。

* **半月瓣的挡血机制**

    * 心室收缩时血液上冲，把瓣膜压向动脉壁，瓣口敞开，血进入肺动脉。
    * 心室舒张时肺动脉弹性回缩、血液倒流，血液灌进半月瓣的"兜"里，兜被充满后两侧瓣缘对合，肺动脉口关闭，血液不能倒灌回心室。
    * 结论：半月瓣保证血液永远只能由心脏流向动脉，不能由动脉倒回心脏。

    ```text
       收缩期                                    舒张期
       血液冲向肺动脉口                            肺动脉弹性回缩，血液倒流
               │                                           │
               ▼                                           ▼
       半月瓣被压向动脉壁                          血液灌进半月瓣的“兜”里
       瓣口敞开                                      兜被充满，两侧瓣缘对合
               │                                           │
               ▼                                           ▼
       血液进入肺动脉                            肺动脉口关闭，血液不能倒灌回心室
    ```

## 左心房

* **左房的位置**

    * 把正常心脏向右旋转看其左侧，最靠后的心腔是左房。
    * 与右心室正好相反，一前一后各居一头。

* **四个肺静脉口**

    * 左房每侧都有一对血管进来，左右肺静脉各两条，共 4 个肺静脉口。
    * 这是左房与右房最大的差别——左房靠 4 个肺静脉口接纳回流的动脉血。

* **左心耳**

    * 呈锥体形，内腔与心房相通。
    * 内壁同样有平行排列的梳状肌，断面和腔内都能看到。

* **房壁与心室壁**

    * 心房壁这一段是光滑的。
    * 旁边的室壁变厚，是左心室的壁，因为它必须承受更大的功。

* **唯一出口**

    * 左房室口，装着二尖瓣。

## 左心室

* **入口与瓣膜**

    * 入口是左房室口，装着二尖瓣——前瓣、后瓣两个瓣，所以叫"二尖"。
    * 二尖瓣中比较长的瓣膜叫前瓣（前尖瓣），另一个叫后瓣（后尖瓣）。

* **内腔隆起**

    * 与右心室很相像：也有肉柱，也有乳头肌和腱索。
    * 其中有一个比较大的乳头肌叫前乳头肌，与前瓣相连。

* **流入道与流出道**

    * 左心室以血液的去路分成两部分。
    * 流入道：心房收缩时血液从左房方向进入左心室的那部分内腔，内壁粗糙，有肉柱、乳头肌、腱索。
    * 流出道：心室收缩时二尖瓣关闭，血液只能经此进入主动脉的那部分内腔。
    * 两者的分界是二尖瓣的前瓣。

* **出口**

    * 主动脉口，装着 3 个主动脉瓣，名字是左瓣、右瓣、后瓣。

* **两套分界的区别**

    * ⚠️ **易错点**：左心室以二尖瓣前瓣分流入道与流出道（一套按瓣膜分），右心室以室上嵴分肉柱部与漏斗部（一套按肌隆起分），别记反。

## 心脏的瓣膜与血液定向流动

* **瓣膜的作用**

    * 心脏作为血泵不断运动推动血液循环，血液总是沿一个方向周而复始地运动。
    * 起主要作用的是心脏的瓣膜。

* **四道关卡**

    * 右房室口——三尖瓣。
    * 肺动脉口——肺动脉瓣。
    * 左房室口——二尖瓣。
    * 主动脉口——主动脉瓣。

* **一次心动周期里的开合**

    * 心房收缩，血液进入心室。
    * 心室收缩，房室瓣关闭，血液冲开动脉瓣往前走。
    * 心室舒张，动脉瓣关闭，血液回到心房；下一次心房收缩又灌进心室。
    * 一个腔一条规矩：入口只进不出，出口只出不进；血液被四道瓣膜一路"单向闸"卡着，永远回不了头。

    ```text
            上腔静脉                  肺静脉（左右各一对）
                │                          │
                ▼                          ▼
            ┌────────┐                ┌────────┐
            │ 右心房 │                │ 左心房 │
            └────┬───┘                └────┬───┘
                 │                          │  ← 二尖瓣
                 │ 三尖瓣                   │
                 ▼                          ▼
            ┌────────┐                ┌────────┐
            │ 右心室 │                │ 左心室 │
            └────┬───┘                └────┬───┘
                 │                          │
                 │ 肺动脉瓣                  │ 主动脉瓣
                 ▼                          ▲
               肺动脉                     主动脉
    ```

| 心腔 | 入口 | 出口 |
| :--- | :--- | :--- |
| 右心房 | 上腔静脉口、下腔静脉口、冠状窦口（3 个） | 右房室口（三尖瓣） |
| 右心室 | 右房室口（三尖瓣） | 肺动脉口（肺动脉瓣） |
| 左心房 | 4 个肺静脉口（左右肺静脉各一对） | 左房室口（二尖瓣） |
| 左心室 | 左房室口（二尖瓣） | 主动脉口（主动脉瓣） |

## 房间隔与室间隔

### 房间隔与卵圆窝

   * **房间隔（interatrial septum）**

       * > **定义**：分隔左、右心房的那道隔。

       * 名称好记，构成却不能凭直觉猜，必须背下来。

       * 构成三样：心房肌、结缔组织、两侧的心内膜——有肌层，有结缔组织，内外两面各贴一层心内膜。

   * **卵圆窝（fossa ovalis）**

       * > **定义**：房间隔上最薄的区域，从右房侧可见一个卵圆形压迹。

       * 它就是房间隔最薄的地方。

### 室间隔与膜性部的再分

   * **室间隔（interventricular septum）**

       * > **定义**：分隔左、右心室的那道隔。

       * 构成与房间隔同一套路，只把心房肌换成心室肌：心室肌、结缔组织和心内膜。

       * 分两部：薄的部分称膜性部，比较厚的部分称肌性部。

   * **膜性部（membranous part）的房室部与室间部**

       * > **定义**：膜性部可再分，判定标准只有一个——看这一段的两边各是什么腔。

       * 上面一段有房有室，称房室部（atrioventricular part）。

       * 下面一段两侧都是心室，称室间部（interventricular part）。

       * 两侧腔的判定关系：

           ```text
                       膜 性 部
              ┌                                   ┐
              │              房室部               │
              │  ┌────────┐   ┌────────┐          │
              │  │  心房  │   │  心室  │          │
              │  └────────┘   └────────┘          │
              ├                                   ┤
              │              室间部               │
              │  ┌────────┐   ┌────────┐          │
              │  │  心室  │   │  心室  │          │
              │  └────────┘   └────────┘          │
              └                                   ┘
           ```

       * > **易错点**：⚠️ 房室部、室间部的判据不是"在上还是在下"，而是"两侧是心房还是心室"。

## 心脏的传导系

### 概念与起搏点

   * **心脏传导系（cardiac conduction system）**

       * > **定义**：由特殊分化的心肌细胞构成的结构，四个字记住——不是普通的心肌细胞。

       * 与普通心肌细胞的差别在功能上：能够产生或传导兴奋。

       * 这种兴奋可以调节心脏节律性地舒张或者收缩。

   * **窦房结（sinoatrial node，SA node）**

       * > **定义**：正常心脏的起搏点。

       * 位置：上腔静脉根部与右心耳交界处的心外膜深面。

       * 这个位置正是界沟的上端。

### 冲动传导通路

   * **结间支（结间束，internodal tract）**

       * 窦房结发出的冲动通过结间支传到心房，也有一支传给另一个结——房室结。

       * 分左右两路：结间支（右）到右心房肌，引起右心房收缩；结间支（左）到左心房肌，引起左心房收缩。

   * **房室结（atrioventricular node，AV node）与房室束（bundle of His）**

       * 房室结得到冲动后继续向下传，通过房室束继续下传。

       * 房室束走在室间隔的膜性部内，不走在肌性部；一直走到肌性部上缘，才开始分支。

       * > **易错点**：⚠️ 房室束的"底"在膜性部，界在肌性部上缘，别把它记成从房室结一路直下。

   * **右束支（right bundle branch）与左束支（left bundle branch）**

       * 右束支的走法有地方特色：先在心内膜深面，再通过节制索（moderator band）到达右心室，然后和浦肯野纤维相联系，引起右心室收缩。

       * 通向心室前乳头肌根部的节制索是右室的一个特点。

       * 左束支向下分成三组束支走到左心室，再通过浦肯野纤维传给心室。

   * **浦肯野纤维（Purkinje fibers）与收缩时序**

       * 浦肯野纤维位于束支末端，把兴奋传给心室肌，引起心室收缩。

       * 冲动在窦房结发出后，通过两侧的结间支使心房先收缩。

       * 房室结得到冲动后，经房室束、左右束支、浦肯野纤维引起心室收缩；此时心房已经先收缩完了。

       * 整个心脏的运动全靠这个系统来调节，这就是心房心室能"一先一后"配合的原因。

   * **完整通路**

       * 通路连起来是这样一条路：

           ```text
           窦房结  上腔静脉根与右心耳交界处的心外膜深面（界沟上端）
             │
             ├─ 结间支（右）→ 右心房肌 → 右心房收缩
             ├─ 结间支（左）→ 左心房肌 → 左心房收缩
             └─ 结间支      → 房室结
                                │
                                房室束  走在室间隔的膜性部内
                                │
                                右束支  心内膜深面 → 经节制索 → 右心室
                                │
                                左束支  分三组束支 → 左心室
                                │
                                浦肯野纤维 → 心室肌收缩
           ```

## 心脏的血管

### 挂图的读法

   * 心脏的动脉一共有两条：右冠状动脉和左冠状动脉，其余先不管，就这两条主干。

   * 心脏动静脉的挂图有两幅：上面一幅是从前方看，下面一幅是从后方看。

   * 因为动静脉缠绕在一起，有很多动脉支被静脉遮盖了；参考这两幅图的时候，重点看板图。

   * 前面观看到的结构依次是上腔静脉、主动脉、肺动脉干、主动脉弓、左心耳；这侧看到的是右心耳，它一直连到心脏的右缘、下缘，直到心尖。

   * 后面观看到的结构是左侧肺静脉、左心房、右侧肺静脉、左侧肺动脉、主动脉弓、右侧肺动脉、上腔静脉、右房、下腔静脉，以及心脏的膈面。

### 右冠状动脉

   * **右冠状动脉（right coronary artery，RCA）的起点与走行**

       * > **定义**：起自主动脉右窦的冠状动脉主干，走行方向是绕右缘反折到膈面。

       * 起点在主动脉的右窦，发出后进入冠状沟。

       * 进入冠状沟后绕心脏的右缘，反折到膈面，最后分为两个比较大的终支。

   * **右冠状动脉的分支**

       * 前方可看见的分支：根部向上发出一个小的窦房结支（往上到窦房结），再向上发出右房前支（到右心房）。

       * 前方靠下的分支：圆锥支（到肺动脉圆锥）、右室前支、右缘支。

       * 转到后面的分支：主干发出右房后支、房室结支（钻进去到房室结）、后室间支（沿后室间沟下行）和右旋支。

       * 右冠状动脉的分支比较多。

### 左冠状动脉

   * **左冠状动脉（left coronary artery，LCA）的起点与走行**

       * > **定义**：起自主动脉左窦的冠状动脉主干，进入冠状沟后分为前降支与旋支。

       * 主动脉根部被肺动脉所遮盖，所以左冠状动脉是在肺动脉后方出来的，出来以后进入冠状沟。

       * 进入冠状沟后立即发出一个很长很大的分支——前降支，也叫前室间支；另一支叫旋支，绕过左缘到心脏后方去。

   * **前室间支与旋支的分支**

       * 前室间支发出的分支：室间隔前支（往室间隔里发很多很多小支）、对角支、左室前支、右室前支、圆锥支。

       * 旋支在左侧边缘发出左缘支，转向后就是左室后支和后外侧支。

       * 旋支另有一条左房旋支，旋转到后方到左心房去，沿途还发出一个房支到左房前方。

### 分支谱系

   * **左冠状动脉的分支树**

       * 前降支与旋支两套分支的关系：

           ```text
           主动脉左窦 → 左冠状动脉（经肺动脉后方，进入冠状沟）
             │
             ├─ 前降支（前室间支）
             │   ├─ 室间隔前支
             │   ├─ 对角支
             │   ├─ 左室前支
             │   ├─ 右室前支
             │   └─ 圆锥支
             │
             └─ 旋支（绕过左缘到心脏后方）
                 ├─ 左缘支
                 ├─ 左房旋支
                 ├─ 房支
                 ├─ 左室后支
                 └─ 后外侧支
           ```

   * **右冠状动脉的分支树**

       * 右冠状动脉的分支从主动脉右窦发出，绕右缘反折到膈面：

           ```text
           主动脉右窦 → 右冠状动脉（冠状沟内绕右缘，反折到膈面）
             ├─ 窦房结支
             ├─ 右房前支
             ├─ 圆锥支
             ├─ 右室前支
             ├─ 右缘支
             ├─ 右房后支
             ├─ 房室结支
             ├─ 后室间支
             └─ 右旋支
           ```

### 吻合稀少与临床后果

   * **营养心脏的动脉的吻合特点**

       * > **定义**：心脏的动脉支发得很多很多，但动脉和动脉之间很少有吻合。

       * 这一特点直接决定了临床上的整套处理逻辑。

       * 推论：正因为动脉之间几乎不吻合，每一个分支就只营养一个区域的心肌——没有旁路可走，某一条断了，那个区域的供血就真的断了。

   * **心绞痛（angina pectoris）**

       * > **定义**：供血不足时出现的心前区不适感，是一种症状而不是一种病。

       * 成因：血管越来越狭窄，最常见的原因是动脉粥样硬化，末端供血不足。

       * 处理：休息或者用硝酸甘油就能缓解。

   * **心肌梗死（myocardial infarction）**

       * > **定义**：血管持续性堵塞、血过不来，营养区长时间没有血液供应而出现的大面积坏死。

       * 与狭窄的区别在于：狭窄是管腔变窄，心梗是持续性的堵塞。

   * **支架**

       * 狭窄时内壁粥样硬化、越来越粗糙变厚，把管腔挤窄了。

       * 可用引导管、用气囊把它扩开；扩的效果不好时，再下一个金属支架撑起来。

       * 支架下在血管壁里面，是从里面把管腔撑开；血管壁变厚的同时外壁也跟着外凸。

   * **搭桥术（coronary artery bypass grafting）**

       * 适用情形：心脏的血管很多地方都出现狭窄或者堵塞，光靠支架不够。

       * 做法：用自身的大静脉，在堵塞的远端建立通路再缝合，让血液进入这个动脉。

       * 有几处堵就在几处的远端搭桥，这就解决了动脉的供血问题。

       * > **易错点**：⚠️ 搭桥的桥墩一定落在堵塞的远端。

## 心脏的静脉

### 冠状窦与冠状窦口

   * **冠状沟与后室间沟**

       * 心脏后面观（心底）可见两条血管压出来的沟：一条叫冠状沟，另一条叫后室间沟。

   * **冠状窦（coronary sinus）与冠状窦口（opening of coronary sinus）**

       * > **定义**：冠状沟里那个很大很膨大的管腔是冠状窦，它的开口叫冠状窦口。

       * 冠状窦口是右房的三个入口之一（另两个是上腔静脉口与下腔静脉口）。

       * 心脏本身的静脉血就是通过冠状窦口进到右房的。

### 心静脉与冠状窦的对应

   * **心大静脉（great cardiac vein）**

       * > **定义**：三条主要心静脉中最粗大的一条，注入冠状窦的左端。

       * 走行：与前降支伴行，绕心脏的左缘过来。

   * **心中静脉（middle cardiac vein）与心小静脉（small cardiac vein）**

       * > **定义**：这两条都注入冠状窦的右端。

       * 心中静脉与后室间支伴行。

       * 心小静脉绕过心脏的右缘过来。

   * **汇入总路**

       * 心大静脉、心中静脉、心小静脉加上一些小分支，全都汇入冠状窦，再经冠状窦口注入右房：

           ```text
           心大静脉 → 冠状窦左端 ┐
           心中静脉 → 冠状窦右端 ├→ 冠状窦 → 冠状窦口 → 右房
           心小静脉 → 冠状窦右端 ┘
           ```

       * > **易错点**：⚠️ 心大静脉在左端汇入，心中、心小在右端汇入，位置别记反。

## 心包

### 构成

   * **纤维性心包（fibrous pericardium）**

       * > **定义**：心脏外面一个很坚硬的膜状结构。

       * 底在膈肌中心腱。

   * **浆膜性心包（serous pericardium）**

       * > **定义**：纤维性心包内侧一个薄薄的浆膜，同时附着在纤维性心包的内面和心脏的表面（图中黄颜色的一层）。

       * 包绕心脏表面的那层叫脏层，在纤维性心包内面的那层叫壁层。

   * **心包腔（pericardial cavity）**

       * > **定义**：浆膜性心包的脏层与壁层两层围成的密闭间隙。

       * 层次关系与胸膜腔、腹膜腔是同一套逻辑：

           ```text
             ┌────────────────────────────────┐
             │  纤维性心包（底：膈肌中心腱）  │
             │  ┌──────────────────────────┐  │
             │  │ 壁层（浆膜性心包）       │  │
             │  │ │ ┌────────────────────┐ │  │
             │  │ │ │       心包腔       │ │  │
             │  │ │ │  ┌──────────────┐  │ │  │
             │  │ │ │  │     心脏     │  │ │  │
             │  │ │ │  └──────────────┘  │ │  │
             │  │ │ └────────────────────┘ │  │
             │  │  壁层（浆膜性心包）       │  │
             │  └──────────────────────────┘  │
             └────────────────────────────────┘
           ```

### 心包积液与心包穿刺

   * **心包积液（pericardial effusion）**

       * > **定义**：心脏有疾病时（如心肌炎）使心包腔内液体增多。

       * 后果：心包腔里液体多了，心脏的舒张肯定要受阻；舒张受影响了，心排血量就减少了。

       * 所以这液体应该抽出去。

   * **心包穿刺（pericardiocentesis）**

       * > **定义**：从左侧剑肋角进针，穿透膈肌进入心包腔，把液体抽出来。

       * 定位标志：前面观中前方为胸骨、下为剑突、两侧为肋弓，胸骨与两侧肋弓构成的这两个角叫剑肋角（costoxiphoid angle）。

       * 侧面关系相同：前方是胸骨（柄、体、剑突），下方是膈肌，后方是脊柱，心包居其中，心包腔夹在中间，进针角度即由此确定。

           ```text
                   胸骨
                  ╱    ╲
                肋弓    肋弓
                  ╲    ╱
                   剑突
                 ╱      ╲
             左侧剑肋角  右侧剑肋角
                │  ← 进针处
                ↓  穿透膈肌 → 心包腔
           ```
