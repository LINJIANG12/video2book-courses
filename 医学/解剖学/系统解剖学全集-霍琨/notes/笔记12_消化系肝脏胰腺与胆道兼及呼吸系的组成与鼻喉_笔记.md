# 消化系·肝脏、胰腺与胆道；兼及呼吸系的组成与鼻、喉

## 肝脏

肝脏不只分泌胆汁乳化脂肪，还是一个很复杂的化工厂。这一段解剖学抓三件事：位置、形态、投影；形态讲得最多，投影是临床上真正每天都要用的。

### 位置与外形

* **肝脏**

    * > **定义**：楔形的消化腺，右侧较厚、左侧较薄，兼有分泌胆汁之外的多项复杂功能。

    * 有上面、下面、前缘、后缘四个面缘；上面与下面是两张形态完全不同的面。
    * 上面称**膈面**，正对膈肌，形态圆凸，大部分有腹膜覆盖，只有中部一小块裸露。
    * 下面称**脏面**，与腹腔脏器相对，凹凸不平并有许多脏器压出来的压迹。
    * 前缘是膈面与脏面在前方交界处的一条，因位置很低故称肝的下界，比较锐薄。
    * 后缘比较钝圆。

* **肝的位置**

    * 腹部九分法以剑突、肋弓、腹股沟、髂前上棘等骨性标志把腹部分成左右对称的九区。
    * 肝脏**大部分位于右季肋区和腹上区**，只有一小部分在左季肋区。

### 膈面与腹膜

* **冠状韧带与镰状韧带**

    * 肝脏借着冠状韧带和镰状韧带悬吊在膈肌下方。
    * 冠状韧带为**左右走向**，镰状韧带为**前后走向**。

```text
           冠状韧带（左右走向）
  ┌──────────────────────────────────────────┐
  │                   │                      │
  │                   │                      │
  │                   │      裸  区            │
  │                   │   （无腹膜覆盖）        │
  │                   │                      │
  │                   │     镰状韧带           │
  │                   │    （前后走向）         │
  │                   │                      │
  └───────────────────┴──────────────────────┘
```

    * 冠状韧带不是前后一直汇合在一起的：前后两层走到某处汇合，走着走着又分开，从前方看不太出来，从上方看一目了然。
    * 两层分开夹出来的那一片腹膜覆盖不上，即**裸区**。
    * 前后层再往前、往前汇合的那一条就是镰状韧带。
    * > **提示**：冠状韧带和镰状韧带不是一条韧带的两段，而是前后层在不同位置分开与汇合的结果。

* **肝的呼吸性移动**

    * 膈肌随呼吸上下移位，肝脏吊在膈肌下方也随之上下移动，幅度约两到三个厘米。
    * 临床触诊肝脏要让患者吸气：一吸气膈顶往下，肝脏跟着下降，就可能在肋弓下方摸到，从而触摸其大小和软硬度。

### 脏面与H形沟

* **脏面的标志**

    * 脏面最醒目的标志是一条明显的 **H 形沟**，三条沟的划分来自把肝脏向上提起看其下面。
    * 左右两条纵沟都是前后两段，横沟把它们连起来，于是成了"日"字里的那道横杠。

```text
                   前缘（锐薄，肝脏下界）
        胆囊窝                        肝圆韧带
          │                             │
 ══════════╪══════════════════════════════╪═════════
          │  右纵沟        左纵沟          │
          │                             │
        腔静脉沟                      静脉韧带
      （下腔静脉）                （静脉导管闭锁）
       第二肝门
     （三条肝静脉出肝）
                   后缘（钝圆）
```

* **右纵沟**

    * 前方为**胆囊窝**，容纳胆囊。
    * 后方为**腔静脉沟**，下腔静脉正好贴在里面。

* **左纵沟**

    * 前方为**肝圆韧带**，是胚胎**脐静脉**闭锁的遗迹。
    * 后方为**静脉韧带**，是胚胎**静脉导管**闭锁的遗迹。
    * 胚胎期循环为：母体血液经脐静脉进来，一部分先进肝，然后经静脉导管直接汇入下腔静脉，再向上奔心脏参加循环；孩子出生后这两条管道逐渐闭锁。

* **横沟与肝门**

    * 横沟又名**肝门**，即第一肝门。

| 沟 | 分段 | 内含结构 |
| :--- | :--- | :--- |
| 右纵沟 | 前方 | 胆囊窝，容纳胆囊 |
| 右纵沟 | 后方 | 腔静脉沟，下腔静脉贴在沟里，三条肝静脉在此注入下腔静脉 |
| 左纵沟 | 前方 | 肝圆韧带，胚胎脐静脉闭锁的遗迹 |
| 左纵沟 | 后方 | 静脉韧带，胚胎静脉导管闭锁的遗迹 |
| 横沟 | — | 又名肝门即第一肝门，肝门三件由此出入 |

### 肝门与肝门三件

* **肝门三件**

    * **胆总管（肝总管）**：运送胆汁。
    * **肝固有动脉**：营养肝脏的动脉。
    * **肝门静脉**：重要的静脉系。
    * 这三条管道在横沟处**各自分出左右两支**，分别进入肝右叶和肝左叶。
    * 除此之外还有神经和淋巴在这个部位出入，这才是"门"的由来。

* **第二肝门**

> ⚠️ **易错点**：腔静脉沟那一块也有三个孔，是三条肝静脉出肝的部位，习惯上管它叫**第二肝门**，别和第一肝门搞混。

### 肝的体表投影

* **上界与下界**

    * 投影用来在体表判断肝的大小，定三条线——右锁骨中线、正中线、左锁骨中线，再看上下界。
    * 剑突下方可摸到肝脏约三厘米，左侧没有什么意义。

| 线的位置 | 上界 | 下界 |
| :--- | :--- | :--- |
| 右锁骨中线 | 第 5 肋 | 全部在右肋弓内，正常人肋弓下摸不到肝 |
| 正中线 | 胸骨体与剑突结合部 | — |
| 左锁骨中线 | 第 5 肋间 | — |

* **叩诊找上界**

    * 胸腔里的肺向上鼓，肝脏顶部也向上鼓；肺是个凹面，肝顶是个凸面，两者之间存在重叠。
    * 肺内都是空气，叩诊为**清音**；相重叠区域叩诊变为**浊音**，再往里是**实音**。
    * 靠叩诊音的变化即可找出肝脏的上界。

* **肝大的判断**

    * 只给下界不能判断肝大：肺气肿者长期处于吸气状态，膈肌往下、肝脏跟着下来，本身可以一点毛病没有。
    * 必须**上下界同时考虑**：只有上界在正常位置，同时肋弓下可以触到，才能说肝脏大。

## 胰腺

### 内分泌部与外分泌部

* **胰**

    * > **定义**：较大的消化腺，但按组成上不单单属于消化腺，包括内分泌部和外分泌部两部分。

    * 内分泌部主要是**胰岛细胞**，分泌胰岛素，调节血糖浓度。
    * 外分泌部是**腺细胞**，分泌胰液，参与消化。
    * 这一部分解剖学重点讲外分泌部。

* **胰头、胰体与胰尾**

    * 外形分三部分：头、体、尾。
    * 胰正好被十二指肠的球部、降部、水平部、升部环绕，被十二指肠环绕的正是**胰头**。
    * 胰头后面是胰体，末端叫胰尾。

### 位置与投影

* **胰的位置**

    * 位于**腹上区和左季肋区**。
    * 从椎体上说横跨第 1、2 腰椎的前方，主要部位在**第 1 腰椎水平**；胰头在第 2 腰椎水平，向左延伸到第 3 腰椎水平。

* **胰的体表投影**

    * 投影指的是**胰体部**的投影。
    * 胰体上界在脐上约 10 厘米处，下界在脐上 5 厘米处。

### 前后毗邻

* **判断坐标**

    * 腹后壁正中是**腹主动脉**，其外侧有较大的**下腔静脉**，腹主动脉前方还有较大的**肝门静脉**。
    * 记住这三个，它们是判断胰前后关系的坐标。

* **各方向毗邻**

    * 前方是**胃**，准确说是胃的后壁。
    * 右侧是**十二指肠**，准确说是**降部**——水平面一刀断下去，胰头右侧就是十二指肠降部。
    * 左侧是**脾**。
    * 后方结构最多：肝门静脉（在胰腺实质里断到的那个管道）、胆总管、腹主动脉、下腔静脉，左侧还有**左肾和左肾上腺**。

```text
                          前  方
     ┌──────────────────────────────────────────┐
     │                   胃                      │
     └──────────────────────────────────────────┘
  十二指肠降部    胰头 ── 胰体 ── 胰尾        脾
     ┌──────────────────────────────────────────┐
     │              肝门静脉                    │
     └──────────────────────────────────────────┘
              胆总管（走在胰腺实质里）
     ┌──────────────────────────────────────────┐
     │  腹主动脉     下腔静脉    左肾、左肾上腺  │
     └──────────────────────────────────────────┘
                          后  方
```

    * 两个肾画得一大一小，是因为两个肾不在同一个水平面上，这一刀切下去肾也不是处在它最粗的地方。
    * 胰腺右侧出现的管道是十二指肠降部，因为断口正好在胰头的右侧。

    * > **注意**：胰的毗邻关系要背下来——前方胃后壁；后方左肾、肾上腺、腹主动脉、下腔静脉、肝门静脉、胆总管；右侧十二指肠降部；左侧脾。

## 肝外输胆管道

### 胆囊

* **胆囊的位置**

    * 胆囊位于肝下面 H 形沟的**右纵沟前方胆囊窝**内。
    * 胆囊窝是**前后走向**的，所以胆囊也是前后走向的器官。

* **胆囊的分部**

    * 形态上呈**梨形**，放大后分为胆囊底、中间的胆囊体、胆囊颈、胆囊管四部分。

* **胆囊底的体表投影**

    * 体表能摸到的只能是胆囊的**底部**，投影在**右侧腹直肌外缘和右肋弓的交角处**。
    * 检查胆囊压痛时，手放在该位置，拇指压住这一点，让患者吸气。
    * 一吸气膈肌往下走，胆囊随之降下来正好触到拇指；若胆囊有炎症，患者不敢继续吸气、这口气马上憋住，这就是胆囊有压痛。

### 输胆管道的组成

* **肝外输胆管道**

    * 从肝门出来的**左右肝管**汇合，形成**肝总管**。
    * 肝总管和**胆囊管**汇合，形成**胆总管**。
    * 胆总管继续向下钻入胰腺实质，与**胰管**汇合，汇合后形成膨大的腔——**肝胰壶腹**。
    * 肝胰壶腹开口于**十二指肠大乳头**，胆汁和胰液由大乳头进入肠腔。
    * 组成顺序：左右肝管、肝总管、胆总管，一直到胰管，汇合后形成肝胰壶腹，开口于大乳头。

```text
        肝右叶                 肝左叶
          │                   │
         右肝管             左肝管
          └──────────┬──────────┘
                   肝总管
                     │
       胆囊 ─── 胆囊管
                     │
                   胆总管
                     │
                     ↓  （穿过胰头实质）
                   胰管
                     │
                 肝胰壶腹
                     │
               十二指肠大乳头
                     ↓
       胆汁 + 胰液进入十二指肠腔
```

* **胆总管与胰实质的关系**

    * > **注意**：胆总管是**穿过胰腺实质**之后才与胰管汇合的，汇合后形成肝胰壶腹，再开口于十二指肠大乳头。

* **副胰管**

    * 十二指肠降部有两个乳头，上面还有一个**小乳头**。
    * 小乳头是**副胰管**的开口，里面出来的只有胰液，**没有胆汁**。

* **胰头癌的临床联系**

    * 上述管道都走在**胰头实质里面**，胰头癌时这些管道受压。
    * 受压后胆汁排泄受阻，胆汁进不到肠管，粪便呈**灰白便**。
    * 胆汁若逆流回肝、最后入血，引起全身黄染，即**黄疸**。

## 呼吸系统的组成

### 组成与上下呼吸道

* **呼吸系统**

    * > **定义**：由气体通过的管道和进行气体交换的肺两部分构成。

| 组成 | 干什么 |
| :--- | :--- |
| 呼吸管道 | 气体通过 |
| 肺 | 气体交换 |

* **上呼吸道与下呼吸道**

    * 上呼吸道是**喉以上**的呼吸管道。
    * 下呼吸道是**气管以下**的呼吸管道。

## 鼻

### 外鼻与鼻腔

* **外鼻**

    * 最上方的部位叫**鼻根**，往下的隆起叫**鼻背**，最前面的尖叫**鼻尖**。
    * 鼻尖两侧张开的两块叫**鼻翼**。

* **鼻腔的分部**

    * 鼻腔做矢状切面可见额骨、额窦、鼻骨、筛板、鸡冠、垂体窝、斜坡、蝶骨体、蝶窦和上唇。
    * 口腔和鼻腔的分界叫**腭**，鼻腔前方有一部分软骨。
    * 鼻腔以**鼻阈**为界分为两部分。

| 鼻腔分部 | 位置 | 特点 |
| :--- | :--- | :--- |
| 鼻前庭 | 鼻阈的前下方 | 里面有鼻毛，很小的空间，即指尖能插入的那个空间 |
| 固有鼻腔 | 鼻阈后方 | 占绝大多数，骨性侧壁有三个鼻甲 |

* **鼻后口**

    * 固有鼻腔向后以**鼻后口**和咽相通，这是鼻腔和咽的分界。

### 鼻中隔与易出血区

* **鼻中隔**

    * > **定义**：分隔左右两个鼻腔的隔板，由三部分组成。

    * 上方是**筛骨的垂直板**。
    * 下方骨性部分（下方这一块）是**犁骨**。
    * 前下方这一部分是**软骨**。

* **易出血区**

    * > **定义**：鼻腔粘膜中血管特别丰富、外伤或气候干燥时最容易出血的那一块区域。

    * 位于**软骨区**，也就是鼻中隔前下方的那一块。

> ⚠️ **易错点**：不是整个鼻中隔都容易出血，是**前下方的软骨区**那一块。

### 嗅区、呼吸区与鼻旁窦投影

* **嗅区**

    * > **定义**：鼻腔粘膜中能传导嗅觉的区域。

    * 范围是**上鼻甲的粘膜**以及它相对的那一部分**鼻中隔的粘膜**。
    * 深面有大量的**嗅细胞**。

* **呼吸区**

    * 鼻腔粘膜中除嗅区以外的其他大部分区域。

* **鼻旁窦的体表投影**

    * 额窦在**眉弓内侧**。
    * 筛窦在**眶内侧壁**。
    * 上颌窦在**上颌骨的深面**。

## 喉

### 位置和毗邻

* **喉的功能**

    * > **定义**：兼具双重功能的器官，既是发音器官，又是呼吸管道。

* **喉的位置**

    * 上端是会厌软骨的上缘，相当于**第 3 颈椎**。
    * 下端在第 3、4、5、6 颈椎之间。
    * 所以喉的位置在**第 3～第 6 颈椎之间**。

* **喉的毗邻**

    * 上方通**咽**（喉咽部），向下通**气管**。
    * 前方是**舌骨下肌群**。
    * 后方也是咽的喉咽部。
    * 两侧由上到下依次为：舌骨（体、大角、小角）→ 甲状舌骨膜 → 甲状软骨 → 环甲膜 → 环状软骨 → 气管。
    * 气管上有重要的腺体**甲状腺**，有峡部，向上两侧是甲状腺的侧叶；甲状腺的后方还有颈部的大血管和神经。

### 软骨与唯一的环

* **喉的组成**

    * 喉由软骨、韧带、肌肉、关节四大部分组成。

* **会厌软骨**

    * 位于上方，形状像树叶状。

* **甲状软骨**

    * 从前方看是愈合的，叫**前角**。
    * 有**两个侧块**构成侧板。
    * 后壁是敞开的：从后边看前方愈合、后方敞开，像两个铠甲一样，所以叫甲状软骨。

* **杓状软骨**

    * 一对，位于甲状软骨下方。

* **环状软骨**

    * 位置最靠下。
    * > **注意**：四块软骨中，环状软骨是喉软骨里**唯一呈环状、也是唯一的一个完整软骨环**，对呼吸道的支撑起重要作用，怎么摁都不塌陷。
    * 口对口人工呼吸时医生要**掐住患者鼻子**并**按住环状软骨**：捏鼻是防止吹的气从鼻子跑掉；压环状软骨是因向后一压就把喉咽部闭锁，使气体只能进入气管而不能到食管，**防止胃胀气**。

### 环甲中韧带

* **甲状舌骨膜与环甲膜**

    * 环甲膜也叫**环甲中韧带**，它是两者中需要重点记住的一个，因为它有临床意义。

* **环甲中韧带的临床意义**

    * 急性喉阻塞的患者马上要窒息，需采取临时措施：用**最粗的针头**在环甲中韧带处毫不留情地扎进去，建立一个暂时的呼吸通道。
    * 体表标志：喉结向下滑动的那个凹窝就是环甲中韧带，活体上应能熟练摸到。
    * 从这里刺入正好到达**声门下腔**，也就是整个呼吸道最狭窄部位的下方。

* **喉肌**

    * 名字不要求，只记住总功能：开闭声门，调节声带的紧张度。

### 喉口、声门裂与喉腔

* **喉口**

    * 由**杓会厌襞**和**杓间切迹**围成。
    * 吞咽时喉上提，舌头仍在原位，喉一上提就顶压会厌软骨，会厌软骨往下来正好把喉口封闭。
    * 说话时吞咽容易误入呼吸道，正是因为喉口在这个动作中会封闭。

* **声襞与前庭襞**

    * 喉腔内每侧壁有两个皱襞：内侧这两个皱襞叫**声襞**，外侧两个钝圆的襞叫**前庭襞**。
    * 上面钝圆的是前庭襞，下面比较锐薄的是声襞，发音主要靠声襞。

* **声门裂与前庭裂**

    * 两侧**声襞**之间的裂隙最窄，叫**声门裂**。
    * 两个钝圆的**前庭襞**之间比较宽，叫**前庭裂**。

* **喉腔的三段**

    * 喉腔分为喉前庭、喉中间腔、声门下腔三部分。
    * 喉中间腔两侧的洼兜叫**喉室**，属于喉中间腔里的一个结构。

```text
                会  厌
            ╭─────────────╮
            │     喉口      │  ← 杓会厌襞 + 杓间切迹围成
            ╰──────┬──────╯
                喉前庭
    ────────────────┼──────────────  前庭襞（外侧，钝圆）
    ════════════════╪══════════════  声襞（内侧，锐薄）
                  │  ← 两侧的凹陷：喉室
                喉中间腔
    ────────────────┼──────────────  环状软骨下缘
                  │
                声门下腔
                  │
                气  管
```

* **各段的分界**

    * 会厌软骨以下是喉口，喉口到前庭襞之间是喉前庭。
    * 两条声襞之间最窄的缝是声门裂，裂的两侧就是喉室，夹着它的是喉中间腔。
    * 过了环状软骨下缘就是声门下腔，再往下是气管。

### 急性喉阻塞

* **声门下腔水肿**

    * 声门下腔的粘膜特点是**比较疏松**，在炎症刺激下**最容易水肿**。
    * 水肿使粘膜变厚、声门裂更窄，最终总有闭合的时候。
    * 一旦闭合，气体不能通过，这就叫**急性喉阻塞**。

* **环甲穿刺**

    * 这时候需要穿刺，从环甲中韧带刺入正好是声门下腔，即整个呼吸道最狭窄部位的下方。
    * 在那里建立暂时的呼吸通道以挽救患者生命，到医院以后再行气管切开。
