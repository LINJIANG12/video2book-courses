# 呼吸系·气管、支气管树与肺

## 气管的位置与标志

* **上下界与范围**

    * 上界在第六颈椎的下缘，即环状软骨的下缘，这也是喉的下界。

    * 下界在胸骨角平面，即第四胸椎水平。

    * 气管的范围自喉的下界（环状软骨下缘）向下，直到气管杈分叉的部位为止。

    * 气管在结构上分为颈段和胸段。

* **气管隆嵴（tracheal carina）**

    * > **定义**：左右主支气管开口在气管下端交汇处所形成的半月状隆起。

    * 位置关系：把气管从中间断开看，左右主支气管交汇的部位向上隆起，形成半个月状隆起。

    * 临床意义：做气管镜检查时一旦看到隆嵴，说明马上就要进入左右主支气管。

    ```text
            环状软骨下缘 ＝ 第 6 颈椎下缘
            ─────────────────────────────  ← 上界
                        │
                        │   气  管
                        │  （颈段 → 胸段）
            胸骨角平面 ＝ 第 4 胸椎水平
            ─────────────────────────────  ← 下界
                    ┌─────┴─────┐
                    │    ▲      │  ← 隆嵴：半月状隆起
                    └─────┼──────┘
                   右主     左主
                  支气管   支气管
    ```

## 气管的构造

* **气管软骨（tracheal cartilage）**

    * 形态为 C 字形，一节一节排列，约 14～17 个。

    * 相邻软骨之间借韧带连接，围成的管道后壁敞开。

* **膜壁（membranous wall）**

    * 是含平滑肌的结缔组织膜。

    * 功能是封住敞开的后壁。

    * 软骨加膜壁两部分合起来，才构成一个完整、后壁扁平的圆筒状管道——这就是气管。

    ```text
            前面（隆起方向）
         ╭───────────────╮
         │   气管软骨    │  C 字形，共 14~17 个
         │               │  相邻软骨之间借韧带相连
         ╰───────────────╯
           ╱           ╲   ← 后壁敞开
         ╰───────────────╯
            膜壁：含平滑肌的结缔组织膜
            封住后壁 → 后壁扁平的完整圆筒状管道
    ```

## 气管切开

* **切开部位**

    * 一般在第 2～4 气管软骨环之间切开，临床上也常选到第 3～5 环。

    * 位置选择的前提：气管切开主要在颈段做，而且在颈段内选择的位置越低越好。

* **手术层次**

    * 气管前方有甲状腺峡，甲状腺峡的前面还有舌骨下肌群，所以切开必须先把这一层结构处理掉。

    * 标准层次依次为：切皮 → 分离舌骨下肌群 → 游离甲状腺峡 → 把甲状腺峡向上推移 → 暴露出底下的气管环 → 切开。

    * > **提示**：正因为现场急救来不及做完这一整套分离，急救时只能退一步，改用粗针头做一个环甲膜穿刺。

## 主支气管

| | 形态 | 走向 |
| :--- | :--- | :--- |
| 右主支气管 | 比较短、比较粗 | 近似于垂直位 |
| 左主支气管 | 比较细、比较长 | 略微倾斜 |

* **形态差异的直接后果**

    * 主支气管分左右两个。

    * 儿童把异物误入气管时，异物最容易落到右侧主支气管。

    * 原因在于右主支气管粗，而且接近垂直。

    * > **易错点**：左右千万别记反——左细长、略微倾斜；右短粗、略垂直。异物最容易落入的是右侧主支气管。

## 支气管树

* **分支顺序**

    * 气管往下分成左右主支气管，左右主支气管经肺门进入肺。

    * 进入肺以后先分到各个肺叶，这一层叫肺叶支气管。

    * 再往下分成肺段支气管，对应到肺段。

* **分支数目**

    * 右侧主支气管进入肺后形成三个分支，分别到右侧的三个肺叶。

    * 左侧主支气管进入肺后形成两个分支，到左侧的两个肺叶。

    * 两侧各有十个肺段，右侧共十个，左侧也是十个。

    ```text
                           气管
                            │
                ┌───────────┴───────────┐
             右主支气管               左主支气管
             短粗 · 垂直位            细长 · 略倾斜
                   │                      │
            ┌──────┼──────┐        ┌──────┴──────┐
           上叶   中叶    下叶      上叶        下叶   ← 肺叶支气管
                   │                      │
                10 个肺段               10 个肺段        ← 肺段支气管
    ```

## 肺的位置

* **肺（lung）**

    * 肺位于纵隔两侧的胸腔内，左侧一个肺，右侧一个肺。

    * 肺是一个柔软而富有弹性的器官，里边充满着大量的空气。

    * 由此肺从体内取出放在盆里会漂起来；法医正是据此鉴定死婴——把新生儿的肺取出来放进盆中，肺漂起来即判定为活婴。

* **纵隔（mediastinum）**

    * > **定义**：纵隔是位于胸腔内、前后纵行，把胸腔分为左右两部分的间隙。

    * 在胸廓的冠状切面上看，纵隔把胸廓分割成左右两个腔。

    * 在水平切面上看，纵隔从前后方向把胸腔分割成左右两个腔隙。

    ```text
            冠状切面                   水平切面
        ┌─────┬─────┐              ┌─────┬─────┐
        │ 肺  │ 肺  │              │ 肺  │ 肺  │
        │     │     │              │     │     │
        └─────┴─────┘              └─────┴─────┘
            纵隔                        纵隔
       （把胸廓分成左右             （把胸腔分成左右
          两个腔）                    两个腔隙）
    ```

## 肺的形态

* **一尖一底，三面三缘**

    * 肺的形态用八个字概括：一尖一底，三面三缘。

* **肺尖与肺底**

    * 肺尖也叫尖，从前方看完整的肺，上方钝圆的那个就是肺尖。

    * 肺尖高出锁骨，具体是高出锁骨中内 1/3 交界处上方约 2～3 个厘米。

    * 肺底是肺的下面那个面，呈凹面，原因是它坐落在膈肌的上方。

* **三个面**

    * 肋面：第一个面，比较圆凸，与肋骨、肋间肌相对。

    * 纵隔面：即内侧面，略微凹陷；这个面中心部位有很多结构出入肺，所以此处称肺门。

    * 膈面：也叫下面，是坐落在膈肌上方的这个面，同样是凹面，位于膈肌之上。

    * 肺门出入的结构：主支气管、肺动脉、肺静脉，此外神经、淋巴也在此出入肺。

* **三条缘**

    * 前缘：纵隔面和肋面在前方交汇处，比较锐薄。

    * 后缘：没有什么太大意义，指的是那个钝圆的缘，位于脊柱两侧，认个位置就行。

    * 下缘：由膈面、肋面、纵隔面三者所形成的交界。

* **心切迹与裸区**

    * 左肺前缘有一处凹进去的弧形，称心切迹。

    * 心脏与胸骨的位置关系是：心切迹和胸骨左缘之间的这一部分，心脏是裸露的，也叫裸区。

    * 裸区的前方对应的是第四、第五肋。

    * > **易错点**：在胸骨左缘第 4 肋间隙做心内注射不会造成气胸——因为左肺前缘正好有心切迹，使心脏裸露、与胸前壁相贴。

## 肺的分叶与听诊定位

* **分叶依据**

    * 肺的分叶是根据裂来分的。

    * 右肺有两条裂：一条斜裂，还有一条水平裂，把右肺分成上叶、中叶、下叶三个叶。

    * 左肺只有一个斜裂，所以左肺只有上叶和下叶。

    * 结论：肺的分叶简单记——右三左二。

* **斜裂方向与听诊**

    * 从矢状切面看，前面是胸，后面是背腰，下面是膈肌，肺是圆锥形的，有一条斜裂向下走。

    * 以左肺为例，斜裂上边是上叶、下边是下叶。

    * 从前方用听诊器听，主要了解的是肺上叶呼吸音的改变。

    * 从后方听，主要了解的是肺下叶呼吸音的改变。

    * > **易错点**：千万不要光听前方而漏掉了后方，务必把后方也听一遍。
