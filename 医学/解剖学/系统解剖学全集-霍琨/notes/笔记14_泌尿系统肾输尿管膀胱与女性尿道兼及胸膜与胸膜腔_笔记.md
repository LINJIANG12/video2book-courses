# 泌尿系统：肾、输尿管、膀胱与女性尿道；兼及胸膜与胸膜腔

## 胸膜与壁层胸膜

* **胸膜（pleura）**

    * > **定义**：覆盖肺表面和胸廓内面的浆膜；贴肺表面的部分叫脏层胸膜（visceral pleura），位于胸廓内面的部分叫壁层胸膜（parietal pleura）。

    * 这层膜是连续的：脏层走到肺根部位向上反折，反过来贴到胸廓内面转为壁层。脏层和壁层不是两张互不相干的膜，而是同一张膜在肺根处折了个弯，折出的两条腿分别叫脏层和壁层。

    * 脏层只有一层，贴着肺表面走，不分区域；分区域的只有壁层。

    * 纵隔两侧的胸腔里各装一个肺，脏层与壁层之间兜出的那道缝就是胸膜腔，三个概念是同一件事的三个侧面。

* **壁层胸膜（parietal pleura）**

    * 按贴附位置正好分成四部分，一部分都不多，一部分都不少。

    * 衬在肺尖上方的那一块是壁层胸膜能达到的最高点，遇到"壁层胸膜的最高处"这类问法，答案就是胸膜顶。

    * 分部对照如下：

| 贴附位置 | 名称 |
| :--- | :--- |
| 纵隔的两侧 | 纵隔胸膜 |
| 膈肌的上面 | 膈胸膜 |
| 肋骨的内面 | 肋胸膜 |
| 肺尖的上方 | 胸膜顶 |

```text
+--------------------------------------+
| 壁层胸膜：贴胸廓内面                 |
|  +----------+    +----------+        |
|  |   右肺   |    |   左肺   |        |
|  |  (脏层)  |    |  (脏层)  |        |
|  +----┬-----+    +----┬-----+        |
|  ─────┴───────────────┴───────       |
|       纵隔：两侧衬纵隔胸膜           |
+---------------┬----------------------+
                |
         膈肌（膈胸膜）
```

## 胸膜腔

* **胸膜腔（pleural cavity）**

    * > **定义**：脏层与壁层在肺根处反折移行，两者之间形成的密闭腔隙。

    * 脏层和壁层实际状态下紧紧贴在一起，中间根本撑不开多大空间；之所以还算一个"腔"，是因为它在解剖学上确实存在、确实封闭，属于潜在的腔隙——就像两片玻璃被水粘到一起，可以滑动但分不开。

    * 三个特点：左右不通、略呈负压、内有少量浆液。

* **左右不通**

    * 左右两侧的胸膜腔由于中间被纵隔隔开，互不相通。

    * 后果：这一侧进的气体只折腾这一侧的肺，对侧的肺该通气还通气。

    * 开放性气胸时，胸部外伤使胸壁破口，外界气体直接灌进这一侧胸膜腔，使该侧腔压与外界大气压相等；原先靠负压吸附在胸廓上的肺因负压消失而萎缩，患者立刻出现呼吸困难。

    * 气体大量涌入使这一侧压力升高，把纵隔整个推向对侧，这是吸气时的情形；呼气时气体从口子逸出、腔内压力掉下来，纵隔又荡回来。这种一来一回的位移叫纵隔摆动。

    * > **易错点**：真正凶险的不是这一侧肺萎缩，而是纵隔摆动；纵隔摆动严重时刺激迷走神经，可以引起心脏骤停。所以开放性气胸现场处理的第一步就是赶紧把它变成闭合性气胸，目的正是防止纵隔摆动去刺激迷走神经。

* **略呈负压**

    * 胸膜腔略呈负压，这个负压是肺能够呼吸的根本原因。

    * 肺本身没有肌肉，不自己收缩也不舒张；靠的是胸廓——胸廓在呼吸肌带动下一起扩张、一起回缩，而肺因腔内负压被牢牢吸附在胸壁上，只能被动跟随：胸廓扩就被撑开，胸廓缩就回缩。

    * 负压不是结果而是前提；一旦被破坏，比如气胸进去大气压，负压归零，肺就萎缩。

* **少量浆液**

    * 胸膜是浆膜，浆膜能分泌浆液，所以胸膜腔内本来就有少量浆液，功能是减少肺和胸廓之间的摩擦。

    * 量一多就成胸水：结核性胸膜炎产生大量胸水，水多了要占地方，肺被压缩而萎缩，同样表现为呼吸困难，而且液面越高、呼吸越困难。胸水必须抽出去，肺才能重新扩张。

    * 下针位置先考虑液面高度再决定，一般情况下在肩胛线第 7、8 肋之间。

    * 肩胛线的量法：让患者坐在凳子上、双手向后靠到椅背，肩胛骨（肩胛冈、肩胛下角）就容易摸到；肩胛下角对应第 7 肋，往下即第 8 肋。

## 胸膜的隐窝

* **隐窝**

    * 壁层胸膜在不同部位之间相交接的地方会留下陷入的盲腔，这就是隐窝。

    * 全身共三处，由两层胸膜相交接形成：

| 隐窝 | 相交接的两层 | 所在切面与范围 |
| :--- | :--- | :--- |
| 肋膈隐窝（膈肋窦） | 肋胸膜与膈胸膜相交 | 矢状面 |
| 膈纵隔隐窝 | 膈胸膜与纵隔胸膜之间 | 矢状面，仅左侧；右侧这两层是直角相交，没有隐窝 |
| 肋纵隔隐窝 | 肋胸膜与纵隔胸膜之间 | 水平面，左右两侧都有 |

* **肋膈隐窝（膈肋窦）**

    * 第一，它是胸膜腔最低的位置，腔内只要有一点积液或积脓，最先积存的就是它。

    * 第二，吸气的时候肺的下缘也伸不进这个隐窝里去。

    * 正因这两条，它是全身最容易存积液的部位，也是三处隐窝中最要记住的一处。

    * 胸膜腔积液的过程在片子上一眼就能看出：液体先积在肋膈隐窝，然后逐渐向上移动；液面越高，患者呼吸越困难。

## 肺与胸膜下界的体表投影

* **三条体表线**

    * 锁骨中线：从前方看，锁骨、胸大肌、胸廓、肋弓都在视野里，以锁骨中线为准。

    * 腋中线：从侧面看，腋窝前后皱襞之间作一条垂线，就是腋中线。

    * 肩胛线：从后方看，以后正中线、肩胛骨、肩胛冈为参照，这条线叫肩胛线。

    * 这三条线是抽胸水定位和体检听诊定位的依据，各线分别量肺下界与胸膜下界。

    * > **易错点**：三条线上都是胸膜下界比肺下界低。记的时候可以偷个懒——"6、8、10"是肺，"8、10、11"是胸膜，两组数字是错开的。

| 体表线 | 肺的下界 | 胸膜（壁层）的下界 |
| :--- | :--- | :--- |
| 锁骨中线 | 第 6 肋 | 第 8 肋 |
| 腋中线 | 第 8 肋 | 第 10 肋 |
| 肩胛线 | 第 10 肋 | 第 11 肋 |

## 泌尿系统的组成

* **四大部分与一条通路**

    * 泌尿系统由四大部分组成，从上到下正好是一条通路，四个环节缺一不可。

    * 尿液在肾里生成，经输尿管向下输送，暂存在膀胱，最后通过尿道排出体外；本节只讲第一个——肾。

| 器官 | 功能 |
| :--- | :--- |
| 肾 | 泌尿器官，尿液在这里生成 |
| 输尿管 | 输送尿液 |
| 膀胱 | 储尿器官，暂存尿液 |
| 尿道 | 排尿器官，尿液排出体外 |

## 肾的形态

* **肾的外形与方位术语**

    * 腹后壁上紧贴着左右各一个肾，肾的上端顶着一个腺体，叫肾上腺。

    * 从外形上看肾脏很像蚕豆，所以说是蚕豆型。

    * 方位术语特别好记：上下叫端（上端、下端），前后叫面（前面、后面），内外叫缘（内缘、外缘）。

* **肾门（hilum）**

    * 肾的内缘中部有一个凹陷，这个部位叫肾门；叫"门"是因为有结构在那里进出。

    * 内缘中部的排列有一条规律：同一根管子换一个观察方向，顺序就变。

    * 也就是说，在前方出入的是肾静脉，静脉后方是肾动脉，动脉再往后才是输尿管。

    * > **易错点**：这两个顺序一定要分开记，别把"前静脉后动脉"和"上动脉下静脉"混成一团——讲的就是同三根管子，只是换了个观察方向。

| 观察方向 | 依次为 |
| :--- | :--- |
| 从前向后 | 静脉 → 动脉 → 输尿管 |
| 从上向下 | 动脉 → 静脉 → 输尿管 |

* **肾蒂（renal pedicle）**

    * 出入肾门的这些结构，被结缔组织包裹、包到一起，就形成了肾蒂。

* **肾窦（renal sinus）**

    * 把肾剖开，里面有很多空腔；这个腔隙是肾实质围成的，所以叫肾窦，开口正好对着肾门。

    * 拿一个完整肾之所以看不到这个腔，是因为它被出入肾脏的这些结构和大量脂肪组织填满了；只有把这些结构和脂肪组织都剥开，肾窦才露得出来。

    * 肾门是出入口，肾蒂是把出入口打包，肾窦是被肾实质围出来的那个内腔，三者说的是同一片区域的不同侧面——没有肾窦这个腔，这些结构根本不可能在这里出入。

## 肾的位置与毗邻

* **位置：左高右低**

    * 左肾：上端约平第 11 胸椎下缘，下端约平第 2、3 腰椎之间。

    * 右肾：上端约平第 12 胸椎上缘，下端约平第 3 腰椎上缘。

    * 右肾低是因为右边有肝脏，肝右叶肥大而厚，把右肾往下顶了；左边没有肝脏挡着，位置就偏上。

    * 第 12 肋斜跨左肾的中部，斜跨右肾的上部，原因还是两肾位置不一样。

* **毗邻关系**

    * 两肾的上端都邻接肾上腺。

    * 左肾：外侧缘邻脾脏，内侧上部邻胃，中段邻胰，下方一部分邻空肠和结肠。

    * 右肾：前方内侧缘有一"C"字形区与十二指肠相贴，大部分外侧缘与肝脏相贴，下方一小部分与结肠相贴。

## 肾门的体表投影

* **两个体表标志定出投影**

    * 第一个标志：脊柱两侧有两条长带状的肌肉，叫竖脊肌。

    * 第二个标志：横在竖脊肌上方的第 12 肋。

    * 把竖脊肌的外缘和第 12 肋画出来，两者相交的那个交角，就是肾门的体表投影位置。

    * 两个肾和第 12 肋都有斜跨关系，所以临床上检查肾区有没有叩击痛，实际敲的就是第 12 肋——通过敲击震动肾脏，肾脏有炎症病人就会疼；敲击点就在竖脊肌外缘与第 12 肋交角处。

## 肾的三层被膜

* **肾纤维膜**

    * 位于最内，直接贴在肾实质表面；取新鲜肾用刀划开一个口就能把一层膜掀起来，说明肾实质外面确实有膜。

    * 质地坚硬致密，而且很容易剥离，一划开就能剥下来。

    * 成分是致密的结缔组织加上弹性纤维，共同构成。

    * 临床上做肾段切除的时候，最后一定要把这层外边的膜缝好。

* **肾脂肪囊（肾床）**

    * 肾纤维膜的外侧有大量脂肪组织围着肾脏，这层叫肾脂肪囊，也叫肾床。

* **肾筋膜**

    * 肾脂肪囊再往外的膜，从前方包绕、从后方也包绕，分两层：前面一层叫肾前筋膜，后面一层叫肾后筋膜。

    * 肾筋膜上发出很多结缔组织的小梁，穿过脂肪囊一直连到纤维膜上，这些小梁对肾脏起固定作用。

    * 筋膜的上端附着在膈肌的下方，然后贴着腹壁往下走；由外向内依次是肾筋膜、肾脂肪囊、肾纤维膜、肾实质。

```text
+--------------------------------+
|  肾筋膜：肾前筋膜 + 肾后筋膜   |
|  +--------------------------+  |
|  |     肾脂肪囊（肾床）     |  |
|  |  +--------------------+  |  |
|  |  |    肾纤维膜        |  |  |
|  |  |  +------------+    |  |  |
|  |  |  |  肾实质    |    |  |  |
|  |  |  +------------+    |  |  |
|  |  +--------------------+  |  |
|  +--------------------------+  |
+--------------------------------+
   内侧、下端：两层开放
   外侧缘、上端：前后两层愈合
   上端附着在膈肌的下方
```

* **筋膜的愈合与开放**

    * 在肾的外侧缘处，肾前筋膜和肾后筋膜愈合在一起；在肾的上端，前后两层也愈合。

    * 在肾的下端和内侧，两层是开放的。

    * 这两条一对照，很多事就通了：肾动脉由腹主动脉发出分支进入肾、肾静脉也要通过这两层之间进出；输尿管要从肾盂下来，经这两层之间一路下行到盆腔的膀胱。内外侧和下端开放，所以它们进得来。

    * > **易错点**：假如这两层在下端和内侧也封闭了，输尿管就下不来了。

* **肾脂肪囊穿刺的判断**

    * 膈肌随呼吸上下移位，肾筋膜附着在膈肌下方，自然也随呼吸上下动；做肾脂肪囊封闭（往脂肪囊里打药）或过去检查肾损伤做的脂肪囊充气造影（往里打气），都会碰到这层会动的膜。

    * 怎么知道针扎到脂肪囊里了：先穿透腹壁，有落空感就把针停住，然后让患者深呼吸；此时腹壁是支点、膜在上下动，针尖已穿透这层膜，针柄就跟着上下摆动，证明针已经在脂肪囊里了。

    * > **易错点**：如果进针时觉得"好像扎在一块硬橡皮上"，那实际扎到的是肾脏；这时候只能退针，然后让他呼吸，看针柄是否摆动来判断。

## 肾的剖面结构

* **管腔部**

    * 从下往上：最下面是输尿管，往上膨大的一段是肾盂，再往上分成许多小的腔隙叫肾小盏；两个肾小盏汇合形成一个大的腔叫肾大盏，几个肾大盏再汇合到最大的那个腔，就是肾盂，然后接输尿管。

    * 用途：做肾脏逆行造影时，造影剂能充盈到这些腔隙里，X 光下看到的影像就是"小盏—大盏—肾盂"的形状，其他结构都看不到——所以肾盂造影能看到的，就是这一套管腔。

* **实质部**

    * 每一个肾小盏都环绕着一个锥体状的结构，这个叫肾锥体；锥体的底呈三角形，锥体的尖端叫乳头，肾小盏的空腔正好环绕乳头，呈一个环状的腔隙。

    * 再往外看，这部分肾实质就叫肾皮质。

    * 归纳：肾的剖面最外侧那一圈是肾皮质；锥体状的结构是肾锥体；锥体之间夹着的皮质叫肾柱；肾锥体加肾柱构成肾髓质——皮质加髓质，就是肾的实质。

```text
+--------------------------------+
|                                |  <- 肾皮质：剖面最外一圈
|   /\      /\      /\           |
|  /  \    /  \    /  \          |  <- 肾锥体：底面呈三角形
|  |  |    |  |    |  |          |  <- 锥体尖 = 乳头
|  (  )    (  )    (  )          |  <- 肾小盏环抱乳头
|                                |
+--------------------------------+
  锥体之间填充的皮质 = 肾柱
  肾锥体 + 肾柱 = 肾髓质
  管腔部：肾小盏 → 肾大盏 → 肾盂 → 输尿管
```

* **尿液的走向**

    * 尿液在皮质内产生，经过肾锥体流入肾小盏，再经肾大盏汇入肾盂，然后进入输尿管。

## 输尿管

### 位置与长度

* **输尿管**

    * > **定义**：肾盂与膀胱之间一条长 20～30 cm 的肌性管道

    * 起于肾盂，起点相当于第二腰椎水平

    * 止于膀胱：先到达膀胱底，再斜穿膀胱壁，开口于膀胱内

    * 肾盂接出的尿液沿此管自上而下流入膀胱

* **定位三要素**

    * 起点是肾盂

    * 起点的高度是第二腰椎水平

    * 终点是膀胱，肾盂与膀胱之间的距离为 20～30 cm

### 腹后壁上的定位地标

* **腹主动脉及其分支**

    * 位于腹后壁正中

    * 约在第四腰椎水平开始分支

    * 主干分为左、右髂总动脉

    * 左、右髂总动脉在骶髂关节前方分成髂内动脉和髂外动脉

    * 腹主动脉上还有肾动脉、睾丸动脉、肠系膜上动脉、肠系膜下动脉、骶正中动脉等分支

* **骨盆与腹膜的参照物**

    * 两侧腹股沟韧带的后方是膀胱

    * 膀胱的后方有一根肠管即直肠，此骨盆为男性

    * 腹膜覆盖在膀胱表面，然后反折到直肠

    * 肾动脉相连的就是肾，肾的下方是腰大肌

* **地标的作用**

    * 每一根动脉、每一块肌肉都充当输尿管走行判断的参照物

### 走行与分部

* **输尿管的走行**

    * 从肾盂出发，沿腰大肌的前方下降

    * 跨过髂血管，进入盆腔

    * 到达膀胱底后斜穿膀胱壁，开口于膀胱

    ```text
            肾盂（第 2 腰椎水平）
                 │
                 │  沿腰大肌前方下降
                 │  （腰大肌在输尿管的后面）
                 ▼
            跨过髂血管  ← 第 2 狭窄
            （骶髂关节前方，髂总动脉
              已分为髂内、髂外动脉）
                 │  入盆
                 ▼
            膀胱底 → 斜穿膀胱壁 → 膀胱内开口
                      ↑ 第 3 狭窄、壁内部

            输精管由睾丸、附睾上来，在输尿管的上方，
            它的末端从输尿管下方进入膀胱
    ```

* **输尿管的三部分**

    * 腹部：从腰大肌前方下降到跨髂血管这一段

    * 盆部：跨过髂血管以后入盆，直到膀胱底这一段

    * 壁内部：斜穿膀胱壁的那一段

    * > **易错点**：壁内部是斜穿膀胱壁形成的，不是贴着膀胱壁走的一段

* **分部的判定规则**

    * 腰大肌前方到髂血管，是腹部

    * 跨过髂血管进盆腔，是盆部

    * 分界按解剖标志判定，不按长度比例记忆

### 斜穿膀胱壁形成的阀门

* **斜行开口的形成**

    * 输尿管自上方下来，斜着穿入膀胱壁，在壁上形成斜行开口

    * 尿液通过这个开口进入膀胱

    * 除该开口所在处外，膀胱内壁有大量皱襞

* **斜行开口的阀门作用**

    * 膀胱储尿越多，膀胱壁的张力越大

    * 张力越大，对壁内这一段管道的压迫越厉害，管腔随之关闭

    * 膀胱充满时开口暂时关闭，尿液不会从膀胱倒流回输尿管

    * 膀胱排空后张力下降，管道重新开放，继续储存尿液

    * 排尿方向是单向的，尿液冲不回输尿管

    ```text
       膀胱充盈、壁张力增大             膀胱排空、壁张力下降

       ┌──────────────┐                 ┌──────────────┐
       │    膀胱腔    │                 │    膀胱腔    │
       │  尿液增多    │                 │              │
       └──────────────┘                 └──────────────┘
           ╲      ╱                         ╲      ╱
            ╲════╱                           ╲════╱
          输尿管壁内段                     输尿管壁内段
      （被压闭，不返流）                （重新开放，继续储尿）
    ```

### 三个狭窄

* **输尿管全长三处狭窄**

    * > **定义**：起端（肾盂输尿管连接处）、跨过髂血管处、斜穿膀胱壁处（相对比较窄）

    * 这三处是泌尿系结石最容易嵌顿的部位

    * 结石本来在肾里时可能没什么感觉，一旦往下掉、挤过这三个窄地方，每挤一下都是一次剧痛

    * 三个狭窄实质上就是结石卡住和肾绞痛发作的位置

### 四个交叉

* **四个交叉的定位**

    * 第一个在肾的下段，与睾丸动脉交叉

    * 第二个在盆骨上口，与髂血管交叉

    * 第三个在盆壁，与闭孔动脉交叉

    * 第四个在膀胱底下方

* **第四交叉处的局部结构**

    * 膀胱的后方有输精管和精囊腺，再往下是前列腺，此处即膀胱底

    * 输精管由睾丸、附睾上行而来，走在输尿管的上方

    * 输精管的末端从输尿管的下方进入膀胱

    * 矢状切面上可见输精管的末端和精囊腺，二者组成射精管

| 交叉的血管或管道 | 交叉部位 | 位置关系 |
| --- | :--- | :--- |
| 睾丸动脉 | 肾的下段 | 动脉在前，输尿管在后（前后） |
| 髂血管 | 盆骨上口 | 输尿管在前，髂血管在后（前后） |
| 闭孔动脉 | 盆壁 | 输尿管在内侧，动脉在外侧（内外） |
| 输精管（精索内） | 膀胱底下方 | 输精管在上，输尿管在下（上下） |

## 膀胱

### 容量与形态

* **膀胱**

    * > **定义**：储存尿液的器官

    * 储存尿液的量大约是 350～500 mL

    * 形态随储存尿液的多少改变：空虚时呈锥体形，充盈时呈卵圆形

* **空虚时膀胱的四部分**

    * > **定义**：膀胱底（后下方）、膀胱体（中间的大部分）、膀胱尖（前上方）、膀胱颈（下方）

    * 只有空虚的时候才能清楚地区分这四部分，因为收缩状态下它有固定的形状

    * 一旦充盈，壁被撑开、彼此拉平，四部之间的界限就分不出来了

### 位置与腹膜的关系

* **空虚时的位置**

    * 不超过小骨盆上口

    * 位于耻骨联合上方的骨盆腔内

* **充盈时的位置与腹膜变化**

    * 向上膨大，变为卵圆形

    * 超过小骨盆上口

    * 膀胱向上顶，腹膜被向上推移

    * 腹膜腔也跟着上移升高

    * 这一上一下的关系就是后面所有临床操作的解剖学基础

* **腹膜的覆盖与反折**

    * 腹膜覆盖在膀胱的表面，再由膀胱反折到直肠

    * 女性的腹膜反折到子宫前壁、后壁，再到直肠

    ```text
       【空虚时】                       【充盈时】
       ┌────────────┐                   ┌────────────┐
       │  腹前壁    │                   │  腹前壁    │
       ├────────────┤                   ├────────────┤
       │  耻骨联合  │                   │  耻骨联合  │
       │            │                   │            │
       │  ┌──────┐  │                   │  ┌──────┐  │
       │  │膀胱  │  │ 不超过上口        │  │膀胱  │  │ 已超过上口
       │  └─┬────┘  │                   │  │卵圆  │  │
       │  ┌─┴────┐  │                   │  └─┬────┘  │
       │  │前列腺│  │                   │  ┌─┴────┐  │
       │  │尿道  │  │                   │  │前列腺│  │
       │  └──────┘  │                   │  │尿道  │  │
       └────────────┘                   │  └──────┘  │
       腹膜覆于膀胱表面，再             └────────────┘
       反折到直肠                       腹膜被向上推移，
                                        腹膜腔升高
    ```

### 临床应用

* **膀胱穿刺**

    * 在膀胱充盈的状态下可以做穿刺

    * 这时膀胱顶到腹壁下面、腹膜被推到更高处

    * 从下往上进针就不会伤到腹膜

* **膀胱造瘘**

    * 手术做一个小切口，然后下一个管道下来，接到一个尿袋里

    * 尿液滴入尿袋，满了以后再倒掉

    * 当这个尿道不能排尿的时候，就可以用这个办法

* **膀胱底部结石取石**

    * 膀胱底部有较大的结石时，可手术取出

    * 从上方即腹腔那一侧进入，尿液渗入腹膜腔，会污染腹膜腔

    * 从下方即耻骨联合上进入不污染腹膜腔

    * 之所以从下面取是最佳关系，是因为充盈时腹膜腔已经上移

    * > **注意**：临床上从下方进入膀胱是安全的，从上方经腹腔取石会污染腹膜腔

### 毗邻

* **男性膀胱的毗邻**

    * 后方是直肠和肛管

    * 腹膜覆盖在膀胱表面，然后反折到直肠

    * 前方在耻骨联合到前列腺之间有一条韧带，叫耻骨前列腺韧带

    * 该间隙里还有大量静脉丛，此外还有一些脂肪组织

    * 矢状切面上可见输精管的末端和精囊腺，二者组成射精管

* **女性膀胱的毗邻**

    * 后方邻的是阴道和子宫，再向后才是直肠

    * 阴道是前后扁窄的肌性管道，位于女性膀胱和尿道的旁侧

    * 前方有耻骨膀胱韧带

    * 该间隙里同样有大量静脉丛

| 性别 | 膀胱后方紧邻 | 腹膜反折到 | 前方韧带 |
| --- | :--- | :--- | :--- |
| 男性 | 直肠、肛管 | 直肠 | 耻骨前列腺韧带 |
| 女性 | 阴道、子宫 | 子宫前壁、后壁，再到直肠 | 耻骨膀胱韧带 |

> **提示**：两性前方那条韧带所在的间隙里，都塞着丰富的静脉丛和脂肪组织。

### 膀胱三角

* **膀胱三角**

    * > **定义**：膀胱底内面上由三个开口围成的三角区

    * 位置在膀胱底的内面

    * 由左输尿管膀胱口、右输尿管膀胱口、尿道内口这三个开口围成

    * 黏膜光滑、无皱襞，三角区以外膀胱内壁有大量皱襞

    * 是膀胱结核和膀胱肿瘤的好发部位

    * 临床上做膀胱镜检查，主要就是检查这个三角区

## 女性尿道

* **女性尿道**

    * 长 3～5 cm

    * 特点是短，而且直，还宽

    * 后方依次是子宫、阴道、直肠

    * 旁为阴蒂、小阴唇

    * > **注意**：又短、又直、又宽的管道最容易被细菌进入，屏障作用弱，所以泌尿系统的逆行感染女性多于男性
