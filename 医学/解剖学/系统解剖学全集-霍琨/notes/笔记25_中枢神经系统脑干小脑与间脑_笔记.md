# 中枢神经系统·脑干、小脑与间脑

## 脑的四块与脑干的座位

* **脑的组成**
    * > **定义**：脑由大脑、间脑、脑干、小脑四块拼成，脑干是其中最下面的一块。
    * 冠状切面上左右对称，中线叫半球间裂；把两个半球连在一起的板状结构是胼胝体。
    * 胼胝体下方的许多腔隙即侧脑室和第三脑室，再往下两个灰色核团是间脑。
    * 更下方的脑干被切断，露出中脑、脑桥、延髓三段；脑干再往后下方是小脑。
    * 正中矢状切面自前向后的标记顺序：胼胝体 → 背侧丘脑、丘脑间粘合、丘脑下沟、视交叉、脑垂体 → 中脑、脑桥、延髓 → 松果体、后连合、上丘、下丘、前髓帆、中脑水管 → 小脑中间被切开的部分及其后方的小脑半球。

* **脑干的位置**
    * > **定义**：脑干坐在颅后窝里，具体位置是斜坡的后上方。
    * 斜坡是颅骨上往后下方向下倾斜的那一片骨面。
    * 枕外隆凸位于斜坡之后；枕骨大孔是颅骨上最大的孔，由它围成的窝就是颅后窝。
    * 颅骨前面是垂体窝，垂体窝往上为鞍背，垂体窝下方是蝶窦的骨松质网眼。

* **脑干的毗邻关系**
    * > **定义**：脑干上连间脑，下续脊髓，后接小脑。
    * 从枕骨大孔往下顺延即脊髓，脑干与脊髓在枕骨大孔这个关口首尾相接。
    * 也可以把脑干理解成中枢的头端那一段：上面顶着一个间脑，下面插进枕骨大孔变成脊髓，后面靠着小脑。

## 脑干外形分两个视角

* **腹侧面与背侧面**
    * 脑干外形分腹侧面（前面）和背侧面（后面）两方面看。
    * 挂图上脑干是倾斜摆着的，从这个角度看到的是腹侧面，从后面看过去才是背侧面。
    * > **易错点**：⚠️ 刚上手时很容易把腹侧面与背侧面看反，看两遍就习惯了。

* **腹侧面三段的形态与界限**
    * 从腹侧面一眼能分出三段：上面缩细的是中脑，中间膨大的是脑桥，下面呈圆锥形的是延髓。
    * 每段都按界限、结构、神经根三样来认。

| 分段 | 上界 | 下界 |
| :--- | :--- | :--- |
| 中脑 | 视束 | 脑桥上沟 |
| 脑桥 | 脑桥上沟 | 脑桥下沟（桥延沟） |
| 延髓 | 桥延沟 | 枕骨大孔 |

    * > **易错点**：⚠️ 脑桥下沟也叫桥延沟——名字里挂的是「下沟」，干的却是脑桥和延髓的界，两个名字指同一条缝。

* **腹侧面上方的成对挂件**
    * 两侧被切断的圆柱是视神经，视神经后方是视交叉，再往后是视束。
    * 视交叉下方有灰结节和漏斗，再往下那个膨大的、被切断的是脑垂体。
    * 脑垂体后方有一对乳头体。
---

## 中脑

* **中脑的界限**
    * 上界是视束，下界是脑桥上沟。
    * 从侧面看，脑桥上面那个凹陷就是脑桥上沟。

* **大脑脚、脚间窝与后穿质**
    * > **定义**：中脑腹侧面那两个圆柱状隆起叫大脑脚，两脚斜行。
    * 两脚之间夹着的凹窝叫脚间窝。
    * 脚间窝的窝底有些小孔，叫后穿质。
    * > **易错点**：⚠️ 后穿质不是神经节，它实际是小动脉进入脑干时留下的孔，脑子里那些穿通动脉就是从这儿钻进去的。

```text
      视神经 ── 视交叉 ── 视束                  ← 上界
        灰结节 · 漏斗 ── 脑垂体（切断）  乳头体
                      ╲  ╱
        大脑脚    ╲    ╱    大脑脚              ← 两脚斜行
                  ╲  ╱
                    ╳  脚间窝 → 窝底小孔：后穿质
                    ║  动眼神经
      ─────────── 脑桥上沟 ───────────          ← 下界
```

* **中脑腹侧面的神经根**
    * 动眼神经在脚间窝里发出，是中脑腹侧面唯一的一对神经根。
    * > **提示**：中脑腹侧面记住「两脚一窝一孔一根神经」就够了：大脑脚、脚间窝、后穿质、动眼神经。
---

## 脑桥

* **脑桥的界限**
    * 脑桥就是腹侧面中间那截膨大的部分。
    * 上界是脑桥上沟，下界是脑桥下沟（桥延沟），后者是脑桥和延髓的交界。

* **脑桥的结构**
    * 腹侧膨大的部分叫基底部，两侧比较细的叫桥臂。
    * 基底部正中有一条浅沟，沟里有一条动脉通过，叫基底动脉沟。

* **脑桥的神经根（四对）**
    * 桥延沟上由内向外依次是展神经根、面神经根、前庭蜗神经根。
    * 基底部与桥臂结合处还有一根粗大的三叉神经根，左右对称一共四对。
    * > **提示**：脑桥口诀是「桥延沟上展、面、前庭蜗，基底部与桥臂交界三叉走」；考神经根时按位置反推比硬背顺序更稳。
---

## 桥小脑角

* **桥小脑角**
    * > **定义**：脑桥、延髓和小脑三者交界的那块三角区叫桥小脑角。
    * 从下往上看脑的底部时：前方是前，后方是后；脑桥是中间庞大的一块，它后面是延髓，延髓两侧是小脑。
    * 脑神经的根几乎都在这里集中。
    * 临床上最典型的例子是听神经长了听神经纤维瘤，也就是前庭神经鞘瘤：瘤子从小处开始，一点一点向外扩大，迟早会波及邻近的神经根，于是冒出相应的临床症状。
    * > **结论**：桥小脑角＝脑神经最集中的部位；这就是病人来的时候往往已经不只一个神经受累的原因。

```text
              脑    桥
        ╱              ╲
         延  髓        小  脑
        ╲              ╱
              └─┬─┘
             桥 小 脑 角
```
---

## 延髓

* **延髓的界限**
    * 上界是桥延沟，下界是枕骨大孔。

* **延髓的结构**
    * 正中的裂隙叫前正中裂，和脊髓是一致的。
    * 前正中裂两侧那两个纵行隆起叫锥体。
    * 锥体的下三分之一处有些发辫式的交叉痕，叫锥体交叉。
    * 再往上，两侧各有一个卵圆形的突起，叫橄榄体。

* **延髓的神经根（四对）**
    * 延髓侧面由上向下依次是舌咽神经、迷走神经、副神经。
    * 橄榄体和锥体之间出来的是舌下神经。
    * 合计四对：舌咽、迷走、副神经走侧面，舌下神经走前外侧。
    * > **提示**：延髓口诀是「侧面咽、迷、副，锥体橄榄之间舌下」。
---

## 腹侧面的账：一共九对

* **脑干腹侧面发出的脑神经根**
    * 中脑 1 对、脑桥 4 对、延髓 4 对，腹侧面合计九对。

| 段落 | 神经根 | 对数 |
| :--- | :--- | :--- |
| 中脑 | 动眼神经 | 1 |
| 脑桥 | 展神经、面神经、前庭蜗神经、三叉神经 | 4 |
| 延髓 | 舌咽神经、迷走神经、副神经、舌下神经 | 4 |

* **滑车神经是唯一的背侧出口**
    * 十二对脑神经里，唯一从脑干背侧出去的一对是滑车神经。
    * 滑车神经从下丘的下方出来，然后绕到腹侧去。
    * 其余绝大多数脑神经都从腹侧面出。
---

## 中脑背侧：四叠体

* **中脑背侧的全景标志**
    * 上端两个卵圆形的团块是背侧丘脑，它们后边各有一个内侧膝状体和外侧膝状体。
    * 中间夹着第三脑室，往下有髓纹、松果体，再往下是上丘和下丘。

* **四叠体**
    * > **定义**：中脑背侧四个隆起合起来叫四叠体，实际包括上面两个上丘和下面两个下丘。
    * > **结论**：上丘是视反射中枢，下丘是听反射中枢，一上一下，一眼一耳。

```text
             丘脑间粘合
                  │
   外侧膝状体 ─┐ │ ┌─ 内侧膝状体
                  │ ▼ │
             上  丘   ← 视反射中枢
                  │   │
             下  丘   ← 听反射中枢
                  │   │
             脑 水 管
```

* **上丘臂与下丘臂**
    * 下丘到内侧膝状体之间的隆起叫下丘臂，上丘到外侧膝状体之间的隆起叫上丘臂。
    * 它们把丘脑的这两个膝状体和中脑四叠体连了起来。

## 菱形窝

* **菱形窝**
    * > **定义**：菱形窝是脑干背侧的菱形凹陷，由脑桥和延髓共同构成，也是第四脑室的底。
    * 第四脑室是脑桥、延髓、小脑之间夹出的三角形腔隙，菱形窝正是它的底。
    * 髓纹是脑桥与延髓的分界线：髓纹以上那半个三角窝由脑桥形成，髓纹以下由延髓形成。
    * 横在窝里的纤维状结构就是髓纹；窝上下方被它切开的两个小窝，是切开的桥臂断面。

```text
                      上 端 · 脑 桥 部
    ┌───────────────────────────────────────────────────────────────┐
    │菱 形 窝 ＝ 第 四 脑 室 底                                     │
    └───────────────────────────────────────────────────────────────┘
  ══════════════════════ 髓 纹 ══════════════════════════════════
    ┌────────────┬────────────┬────────────────────┬────────────────┐
    │正 中 沟    │内 侧 隆 起 │  面  丘            │                │
    │            │            │(深面：展神经核)    │                │
    ├            ┼────────────┼────────────────────┼────────────────┤
    │            │            │舌 下 神 经 三 角   │                │
    │            │            │（舌下神经核）      │前 庭 区        │
    │            │            │                    │（前庭神经核）  │
    ├            ┼────────────┼────────────────────┼────────────────┤
    │            │            │迷 走 神 经 三 角   │                │
    │            │            │（迷走神经背核）    │听 结 节        │
    │            │            │                    │（蜗神经核）    │
    ├────────────┼────────────┼                    ┼────────────────┤
    │薄 束 结 节 │楔 束 结 节 │                    │                │
    │（薄束核）  │（楔束核）  │                    │                │
    └────────────┴────────────┴────────────────────┴────────────────┘
                      下 端 · 延 髓 部
```

* **菱形窝内的隆起与三角**
    * 内侧隆起是正中沟两侧那两个纵行的柱状隆起。
    * 面丘是中部隆起形成的一个丘状凸起，它鼓起是因为深面是一个神经核——展神经核，所以这块隆起才被叫做「面」丘。
    * 舌下神经三角在面丘下方，里面是舌下神经核。
    * 迷走神经三角在舌下神经三角下方，里面是迷走神经背核。
    * 外侧那个三角区是前庭区，也就是前庭神经三角，里面是前庭神经核；它的最外侧角叫听结节，里面是蜗神经核。
    * 窝底还有分隔索和最后区两个小结构，这两处不用记，知道有这么个位置就行。
    * 最下面的四个包：上面一对是楔束结节，里面是楔束核；下面一对是薄束结节，里面是薄束核。
    * > **易错点**：⚠️ 听结节里装蜗神经核（听觉），前庭区里装前庭神经核（平衡觉），这两个位置紧挨着，最容易被互串。
    * > **易错点**：⚠️ 楔束结节对应楔束核、薄束结节对应薄束核，结节是表面隆起、核团在深处，顺序别写反。

## 脑干内部的灰质

* **脑干内部的三块**
    * 脑干内部就是三块：灰质、白质、网状结构。

* **脑神经核的分布**
    * 灰质里头最要紧的是脑神经核，从中脑到延髓的核团分布见下图。

```text
   ┌────────────┬──────────────┬──────────────┐
   │  中  脑    │  脑  桥      │  延  髓      │
   ├────────────┼──────────────┼──────────────┤
   │  动眼神经核│  展神经核    │  舌下神经核  │
   │  滑车神经核│  三叉神经运动核│  疑  核      │
   │  动眼旁核  │  面神经核    │  副神经核    │
   │  上丘核    │  上泌涎核    │  迷走神经背核│
   │  下丘核    │  下泌涎核    │  孤束核      │
   │  红  核    │  脑桥核      │  上橄榄核    │
   │  黑  质    │  蓝斑核      │  下橄榄核    │
   └────────────┴──────────────┴──────────────┘
```

* **脑神经核按纤维性质分七类**
    * > **定义**：脑神经核按纤维性质分成七类，一类一类数过去。
    * 每类核团各自管辖固定的运动或感觉。

| 类别 | 核团 | 管辖的运动或感觉 |
| :--- | :--- | :--- |
| 一般躯体运动核 | 动眼神经核、滑车神经核、展神经核、舌下神经核 | 前三个管眼外肌，舌下神经核管舌肌 |
| 特殊躯体运动核 | 三叉神经运动核、面神经核、疑核、副神经核 | 咀嚼肌 / 表情肌 / 咽喉肌 / 胸锁乳突肌与斜方肌 |
| 一般内脏运动核 | 动眼旁核、上泌涎核、下泌涎核、迷走神经背核 | 内脏运动 |
| 一般躯体感觉核 | 三叉神经感觉核（中脑核、脑桥核、脊髓核） | 头面部的浅部感觉 |
| 特殊躯体感觉核 | 前庭神经核、蜗神经核 | 平衡觉 / 听觉 |
| 一般内脏感觉核 | 孤束核下半 | 一般内脏感觉 |
| 特殊内脏感觉核 | 孤束核上半 | 味觉 |

* **特殊躯体运动核「特殊」在哪里**
    * 它们支配的肌肉是与特殊感觉器官的活动直接关联的肌肉——咀嚼、表情、发声、呼吸都离不开三叉神经支配的咀嚼肌和面神经支配的表情肌。
    * 四对里，面神经核的纤维要绕过展神经核才从脑桥出去，这也是为什么面丘会在菱形窝底上鼓出一个包。
    * 疑核管咽喉肌，副神经核管胸锁乳突肌和斜方肌。

* **三叉神经感觉核**
    * 唯一一个贯穿整个脑干的长感觉核，纵向分三段：中脑那一段叫中脑核，脑桥那一段叫脑桥核，往下到延髓那一段叫脊髓核。
    * 它管头面部的浅部感觉。

* **孤束核**
    * 上下两半功能完全不同：上半是特殊内脏感觉（味觉），下半是一般内脏感觉。
    * > **提示**：核团这一段是重点。把「哪一核管哪块肌肉」横着背一遍比顺着核团名单硬啃牢得多，例如咽喉肌→疑核、胸锁乳突肌和斜方肌→副神经核、舌肌→舌下神经核。

* **非脑神经核**
    * 和脑神经没关系、因此不连着脑神经的核团叫非脑神经核，这一部分只记名称、不做展开。
    * 中脑：上丘核、下丘核、红核、黑质。
    * 脑桥：脑桥核、蓝斑核。
    * 延髓：上橄榄核、下橄榄核、薄束核、楔束核。
    * 区分标准：连着脑神经的叫脑神经核，不连的叫非脑神经核。

## 脑干内部的白质

* **上行束（感觉）**
    * 上行束一提起就要想到「感觉」，记住几个「丘系」：丘系即上行感觉束。
    * 这四条都是向上传导感觉的。

| 上行（感觉）束 | 传导什么 |
| :--- | :--- |
| 内侧丘系 | 躯干和四肢的深部感觉与精细触觉 |
| 脊丘系 | 浅部感觉 |
| 三叉丘系 | 头面部的浅部感觉 |
| 外侧丘系 | 听觉 |

* **下行束（运动）**
    * 下行束重点就两个，都是运动束。
    * 皮质核束是大脑皮层与脑干所有运动核相互联系的传导束。
    * 皮质脊髓束是由皮层下行到脊髓前角细胞的传导束。
    * > **结论**：上行是感觉，下行是运动；上行记四个丘系，下行记皮质核束与皮质脊髓束。

## 网状结构

* **网状结构**
    * 位置在脑干的中央部，是一个比较广泛、比较弥漫的区域。
    * 特点是灰质与白质相间：白质纵横交错编织成一张网，网眼当中又含有许多许多灰质核团。
    * 这些结构既不能叫白质（不是传导束），也不能叫灰质（不是单纯核团堆积），于是有了网状结构这个专门的名字。
    * 功能一：保持皮层的觉醒状态。皮层一觉醒，上行的各种信号它都能接收、都能判断、然后做出相应反应；清醒的时候就是网状结构兴奋的时候。
    * 功能二：调节内脏活动，因为网状结构里含有呼吸中枢和心血管运动中枢。
    * 功能三：调节躯体运动、调节肌张力。
    * 功能四：参与睡眠。
    * 功能五：抑制疼痛。
    * > **提示**：睡眠、觉醒、止痛是同一件事的三个侧面。安眠药的药理作用是阻断网状结构的兴奋性——网状结构一兴奋皮层就觉醒，觉都睡不着了；吃止痛片疼痛减轻，实际也是抑制了网状结构。安眠药和止痛药看着是两类药，靶子却指向同一处。

## 小脑的位置与毗邻

* **小脑（cerebellum）**

    * > **定义**：缩在颅后窝里、位置在大脑枕叶下方的一个脑，它与卡在两半球正当中的间脑并列为藏在颅腔底部、夹在两个大脑半球之间的结构。

    * 前方毗邻：脑桥与延髓，二者紧贴在它的正前方。

    * 描述位置从两头说——所在的是颅后窝且在大脑枕叶下方；紧挨着的前方是脑桥与延髓。

    * 颅底定位线索：颅中窝有垂体窝，窝的后缘是鞍背，鞍背往后是斜坡，斜坡下面就是蝶窦，骨松质呈网眼样；再往后是枕外隆突，那里也是一片骨松质的网眼；中间那块白颜色骨板围起来的孔是枕骨大孔，枕骨大孔往后这一块凹陷就是颅后窝。

    * 正中矢状面上由前向后的排列：最外面是大脑半球与连接左右两半球的胼胝体，垂体挂在那里；往下依次是中脑、脑桥、延髓，中间这一串即脑干；再往后是穹窿、丘脑间粘合、丘脑下沟、松果体、后联合、上丘和下丘，中脑水管往下通成第四脑室；再往后是大脑半球，而最里面这一块就是小脑。

```text
                  大脑半球（枕叶）
            ─────────────────────────
            颅中窝：垂体窝、鞍背、斜坡
                     （下方是蝶窦）
                            │
                         枕骨大孔
                            │
            ╭─────────────────────────╮
            │        颅  后  窝         │
            │           小脑            │
            │    前方毗邻：脑桥、延髓    │
            ╰─────────────────────────╯
```

    * 读图：上面是大脑的枕叶压着，下面才是颅后窝，小脑就蹲在这个窝里；它的正前方紧贴着脑桥和延髓。

## 小脑的外形

* **小脑半球（cerebellar hemisphere）**

    * 从上往下看，小脑中间这一部分是翘起的、两侧向下倾斜；两侧膨大的部分叫小脑半球。

* **小脑蚓部（vermis）**

    * 同一视角下中间缩细的部分叫小脑蚓部。

    * 小脑就两大块：两个半球夹着一条蚓。

* **小脑扁桃（tonsil）**

    * 从下方看重点能看到小脑的后半部，这里有两个橄榄状的突起，叫小脑扁桃。

    * 两个扁桃中间夹着一条凹沟，沟里容纳的正是延髓，两个凸起正好卡在延髓的后外侧。

    * > **易错点**：颅内压力增高时，小脑扁桃会被挤进枕骨大孔；一挤进去，两个扁桃之间的延髓就受压，而延髓里有生命中枢，这就是小脑扁桃疝，临床上的危象。

* **第四脑室在下面观的位置**

    * 两个小脑扁桃之间的断面被切开，中间的腔就是第四脑室，即讲脑干时提过的那个三角形腔。

* **前下方观看到的表面结构序列**

    * 从前下方看过去，小脑表面的裂隙从这个方向最明显，裂隙的上缘平行排列着一道道脑回。

    * 按前后顺序核过名字：绒球，往下是绒球角（两侧都有），绒球深面那个凸起叫小结，再往后是蚓垂、蚓锥体、蚓结节，最后那两个凸起就是小脑扁桃，中间那个腔隙是第四脑室。

```text
         从上面看                      从下面看
    ╭──────┬──────╮              ╭────────────╮
    │ 半球 │ 蚓部 │              │  ◯      ◯  │ ← 小脑扁桃
    │      │      │              │   延  髓   │
    ╰──────┴──────╯              ╰────────────╯
       前        后                 前       后
```

    * 读图：上面观是两胖一瘦，半球鼓、蚓细；下面观只见得到后半部，一对小脑扁桃分居两侧，正好卡住延髓。

## 小脑的分叶

* **原裂（primary fissure）**

    * 分叶只要抓住一道深裂——原裂。

    * 从上面看，小脑后面有一道深裂就叫原裂；借着这道原裂，小脑的上面被分成前方的一小部分和后方的一大块，所以从上面看只能数出两个叶。

    * 再从前下方看，整个那一长条叫绒球小结叶，三个叶这就凑齐了。

```text
          ┌───── 前叶 ─────┐ 原裂 ┌────── 后叶 ──────┐
      从上面看：小脑背面只有一道深裂 = 原裂
      从前下方看：绒球小结叶 ┊ 前叶 ┊ 后叶（三叶凑齐）
```

* **绒球小结叶（flocculonodular lobe）**

    * 又叫原小脑，也有人管它叫前庭小脑。

    * 与前庭神经的纤维相联系。

* **前叶（anterior lobe）**

    * 原裂前方小的部分；叫旧小脑，也叫脊髓小脑。

    * 与脊髓的纤维有联系。

* **后叶（posterior lobe）**

    * 原裂后方大的部分；叫新小脑，也叫大脑小脑。

* **原、旧、新这套名字的依据**

    * 按演化上出现的先后划分：原小脑最古老，新小脑最新。

## 小脑内部的核团

* **水平切面上的定位标志**

    * 水平切面上前方是脑桥，脑桥正中有一道浅沟，叫基底动脉沟。

    * 后方是小脑，中间是第四脑室，腔隙周围还有一些灰质，属于蚓部。

* **小脑深部四组核团**

    * 靠正中、挨着蚓部一侧是最内侧的顶核，往外依次是球状核、栓状核，最外且偏后的是体积最大的齿状核。

    * 左右完全对称。

```text
               脑桥（基底动脉沟）      前
           ┌──────────────────────┐
           │   蚓部     │ 第四脑室 │
           │  （灰质）  │          │
           │   ● 顶核   │ ○ 球状核 │
           │           │ ○ 栓状核 │
           │           │  ○ 齿状核 │
           └──────────────────────┘
```

    * 读图：由内向外依次是顶核、球状核、栓状核、齿状核，齿状核最外、偏后且最大。

## 小脑的三叶分工

| 叶 | 又名 | 主要功能 |
| --- | --- | --- |
| 绒球小结叶 | 原小脑、前庭小脑 | 管理平衡觉 |
| 前叶 | 旧小脑、脊髓小脑 | 管理肌张力 |
| 后叶 | 新小脑、大脑小脑 | 调节骨骼肌的随意运动与精细运动 |

* **分工的本质**

    * 三个叶的分工本质上取决于它们和什么连着。

    * 绒球小结叶与前庭神经的纤维相联系，所以管平衡觉；前叶与脊髓的纤维有联系，所以管肌肉的张力。

## 小脑损伤的临床检查

### 平衡觉相关的检查

* **蹒跚步态**

    * 蹒跚，像喝醉酒一样，还总愿意扶着墙——这是平衡觉出了问题。

* **后仰试验**

    * 让患者闭上眼睛，医生说"你向后仰"。

    * 正常人身体后倾靠整个脊柱和下肢一起调节重心，重心还在足面里。

    * 小脑损伤的患者，你要让他仰，他就实实在在往后面倒。

    * > **注意**：作为医生，一定要想到他是个病人，后边随时会倒，一定要扶住他，别让人摔了。

### 随意运动与协调的检查

* **指鼻试验**

    * 让他闭着眼睛指一下鼻尖，正常人能指到。

    * 病人心里想得好好的，手守在这儿，心里想着"一定能指上"，可是一指就发现偏离了，怎么指都对不上鼻尖。

    * 机理：肌张力一旦受影响，关节的随意运动就受影响——屈肌往这个方向使劲，伸肌往那个方向拽，两边张力的平衡被打破，他就控制不了方向了。

* **写字**

    * 让他写字，写出来大小不均，有大有小，还是肌张力的缘故。

* **轮替试验**

    * 两个手同时做动作，正常人两个基本上是对等的。

    * 小脑损伤的时候，一个快一个慢，两者不协调。

* **精细运动**

    * 给他一根大头针，他会用那样的手势去接——他当然知道大头针有多大，可这就是肌张力失调造成的。

### 屈肌与伸肌张力牵制的检查

* **握拳松手试验**

    * 让他臂屈曲、握拳，医生握住他这只手，让他往里使劲，然后医生的手突然一松，他的拳头一下就打到自己。

    * 正常人为什么打不到自己：屈肌用力的时候，伸肌还保持着一定的张力在那儿拽着他。

    * 小脑损伤的患者肌张力失调、张力下降，屈肌一用劲就过劲，一下就打到自己。

### 检查的共同底座

* 这几种检查的底座其实是同一件事——肌张力与协调。

* 查平衡觉：蹒跚步态、后仰试验。

* 查随意运动的方向与协调：指鼻试验、写字、轮替试验。

* 查屈肌与伸肌张力之间的相互牵制：握拳松手那一项。

* 查精细运动：捏大头针。

## 间脑的位置

* **间脑（diencephalon）**

    * > **定义**：卡在左右两个大脑半球正当中、被中间那道狭窄的第三脑室分成左右两部分的脑部。

    * 冠状切面（沿脑干纵轴切）所见：胼胝体跨过半球间裂连接左右半球；间脑是左右对称的两个团块；外侧面贴着大脑半球的内囊（白质）；下端与中脑相连；脑干后方的完整结构就是小脑。

    * 正中矢状切面所见：胼胝体、前联合、视交叉、脑垂体、中脑、脑桥、延髓（后面这一串是脑干）、穹窿、丘脑下沟、丘脑间粘合；再往后是髓纹、缰三角、缰联合，突出的那个是松果体，再向下形成后联合，然后是上丘、下丘、前髓帆；第四脑室；再往后是大脑枕叶和颞叶，小脑在小脑断面和它的脑回上。

    * 两个面一对照，间脑的范围就很清楚：在左右半球之间，连接半球与中脑，中间夹一道狭窄的第三脑室。

```text
                  胼胝体（跨过半球间裂，连接左右半球）
       ┌──────────┐┌──────────┐┌──────────┐┌──────────┐
       │ 大脑半球 ││   间脑   ││   间脑   ││ 大脑半球 │  冠状切面
       │   内囊   ││    │     ││    │     ││   内囊   │
       └──────────┘└────┬─────┘└────┬────┘└──────────┘
                        │第三脑室│
                        └────┬────┘
                             ↓ 中脑
```

* **丘脑间粘合（massa intermedia）**

    * > **定义**：左右两个丘脑在正中相连的那个结构，把它切开就形成一个断端。

## 间脑的分部

* **分部的两种数法**

    * 在图上数一遍得到四部分：上丘脑、背侧丘脑、下丘脑，还有背侧丘脑与中脑移行的那一块底丘脑。

    * 换一个角度又多出一个：背侧丘脑后方有两个小包，叫内侧膝状体和外侧膝状体，这两个膝状体合起来叫后丘脑。

    * 合计五个部分：上丘脑、背侧丘脑、后丘脑、下丘脑、底丘脑。

| 部分 | 位置 | 主要结构 |
| --- | --- | --- |
| 上丘脑 | 背侧丘脑上方、第三脑室上方 | 髓纹、缰三角、缰联合、松果体、后联合 |
| 背侧丘脑 | 间脑的主体，卵圆形灰质团块 | 丘脑间粘合；核团众多 |
| 后丘脑 | 背侧丘脑后方的两个小包 | 内侧膝状体、外侧膝状体 |
| 下丘脑 | 背侧丘脑前下方，以丘脑下沟为界 | 视交叉、视束、灰结节、漏斗、乳头体 |
| 底丘脑 | 背侧丘脑与中脑移行部 | 位于丘脑下沟与中脑之间 |

## 背侧丘脑

### 地位

* **背侧丘脑（dorsal thalamus）**

    * > **定义**：一个卵圆形的、左右对称的灰质团块，中间靠丘脑间粘合连在一起。

    * 在整个神经系统里占的位置很特别：特定感觉传导的最后一站。

* **中继站（relay station）**

    * > **定义**：中继站就是中转站。

    * 感觉传导由三级神经元完成：第一级、第二级神经元都在丘脑以下，第三级神经元的胞体就在丘脑里边。

    * 第三级神经元在丘脑里交换完神经元以后再到皮层去，所以最后一站落在丘脑。

### 毗邻

* **内侧面**

    * 除了丘脑间粘合那一点，左右两个是分开的，其他都是游离面。

    * 正因为都是游离面，中间才留得出那道狭窄的第三脑室。

* **上面**

    * 也是游离面，也对应一个腔隙——对应的是侧脑室中央部。

* **外侧面**

    * 不游离，和大脑半球的白质相连，这块白质叫内囊。

* **下面**

    * 也不游离，和底丘脑、中脑相连。

* **前下方**

    * 是下丘脑。

* **五个面的小结**

    * 内侧面、上面是游离面，分别对应第三脑室和侧脑室中央部；外侧面接内囊，下面接底丘脑和中脑，前下方是下丘脑。

### 核团

* **水平切面的注意事项**

    * 两个切面并不在同一个高度：着色深的那块说明切面切得比较高，另一个略低一点，所以两个结构并不对称。

* **丘脑核团的分层**

    * 切面上隐约能看到背侧丘脑中间有一个 Y 字形的白质板，把它分成前核、内侧核、外侧核三部分，这三支是往下分下去的。

    * 外侧核向下分为腹侧核与背侧核；腹侧核再分前核、外侧核、后核；后核再分为腹后内侧核和腹后外侧核。

```text
        背侧丘脑
          ├── 前核
          ├── 内侧核
          └── 外侧核
              ├── 腹侧核
              │   ├── 前核
              │   ├── 外侧核
              │   └── 后核
              │       ├── 腹后内侧核
              │       └── 腹后外侧核
              └── 背侧核
```

* **只需重点记住的两个核**

    * 腹后内侧核和腹后外侧核是在丘脑众多核团里逐渐分出来的，讲传导路的时候主要提的就是这两个；其他核团不用记。

## 下丘脑

### 位置与组成

* **下丘脑（hypothalamus）**

    * > **定义**：背侧丘脑前下方、丘脑下沟前方的那一个三角区。

    * 正中矢状切面上看，背侧丘脑是那个卵圆形的小块，往前下方有一个三角区，这就是下丘脑。

    * 它和背侧丘脑中间隔着一道浅沟，叫丘脑下沟；丘脑下沟就是下丘脑和背侧丘脑的分界线，沟的前下方那个三角区才叫下丘脑。

* **组成下丘脑的结构**

    * 从中脑腹侧从下往上看：视神经往后是视交叉，这个位置正好被脑垂体遮住；从视交叉向两侧延续的叫视束。

    * 视交叉的后方这部分叫灰结节，从灰结节向下变细的叫漏斗，两侧那个乳头状的突起叫乳头体。

    * 视交叉、视束、灰结节、漏斗、乳头体加在一起的这个三角形，就叫下丘脑。

* **中脑上界与视束**

    * 中脑的上界是视束，而视束属于下丘脑的结构。

### 与垂体的血管联系

* **垂体分部**

    * 垂体自己先分成两半：前叶也叫腺垂体，后叶也叫神经垂体。

* **需要记住的下丘脑核团**

    * 视上核、室旁核，还有漏斗核。

* **垂体门脉（hypophyseal portal system）**

    * > **定义**：垂体上动脉钻进来以后形成毛细血管，下方又形成毛细血管，这些血管和颅腔里的静脉窦相连，中间那一整套叫垂体门脉。

    * 特点与肝门静脉相同：起端和终止端都是毛细血管——动脉过来先成毛细血管，然后收成一个干，到那一边又散成毛细血管，两头都是毛细血管。

    * 垂体下动脉进入神经垂体，也形成毛细血管。

```text
      垂体上动脉 ──► 毛细血管 ──► 干 ──► 毛细血管 ──► 颅内静脉窦
                            └─────── 垂 体 门 脉 ────┘
      垂体下动脉 ──► 毛细血管（神经垂体）
```

    * 读图：垂体门脉的两头都是毛细血管，下端汇入颅内静脉窦；神经垂体另有垂体下动脉供血。

### 与垂体的纤维联系

* **三个束的总貌**

    * 下丘脑的核团一共发出三个束：视上核经视上垂体束、室旁核经室旁垂体束通向神经垂体（后叶）的毛细血管，漏斗核经结节垂体束通向腺垂体（前叶）并调控分泌。

```text
      视上核 ── 视上垂体束 ──┐
      室旁核 ── 室旁垂体束 ──┼─→ 神经垂体（后叶）的毛细血管
      漏斗核 ── 结节垂体束 ──┼─→ 腺垂体（前叶）：调控分泌
```

* **视上垂体束（supraopticohypophyseal tract）**

    * 来自视上核，视上核分泌加压素。

    * 作用是运输：物质沿视上垂体束到达神经垂体，也就到了垂体后叶的毛细血管。

* **室旁垂体束（paraventriculohypophyseal tract）**

    * 来自室旁核，室旁核分泌催产素。

    * 同样属于干运输的活，物质沿室旁垂体束到达神经垂体（后叶）的毛细血管。

* **结节垂体束（tuberoinfundibular tract）**

    * 来自漏斗核，送到腺垂体，不是运送物质，而是控制腺垂体的分泌。

    * 腺垂体自己分泌生长激素、促肾上腺皮质激素、促甲状腺激素、促性腺激素；调节它们的物质由下丘脑核团分泌，经结节垂体束送到腺垂体。

* **后叶物质如何进入全身**

    * 后叶的毛细血管和颅腔里的静脉窦相通，先回到心脏，心脏一搏动，就把这些物质带到了全身。

* **三个束的分工一句话**

    * 前两条束管"运"，结节垂体束管"控"。
