# 骨学·附肢骨：上肢骨、下肢骨与关节的基本结构

## 上肢骨的构成

* **上肢骨**

    * > **定义**：分为肢带骨与自由上肢骨两半。

* **肢带骨（pectoral girdle）**

    * > **定义**：直接与躯干骨相连、把上肢悬挂在躯干上的骨。

    * 肢带骨共 2 块：锁骨、肩胛骨。

* **自由上肢骨**

    * > **定义**：可以自由活动的上肢骨。

    * 包含三组：肱骨、前臂骨（桡骨、尺骨）、手骨（腕骨、掌骨、指骨）。

## 锁骨

### 形态与两端

* **锁骨（clavicle）**

    * > **定义**：S 形的长骨，内侧段凸向前、外侧段凹向前。

    * 从上方看呈 S 形：内侧段凸向前，外侧段凹向前。

    * 两端各构成一个关节，中间悬空；中段上方仅有一层皮肤覆盖。

    * 从前方看，外侧端扁平，内侧端圆钝。

* **胸骨端**

    * 内侧端的名称，与胸骨相接。

* **肩峰端**

    * 外侧端的名称，与肩峰相接，位置正对肩胛骨的肩胛冈。

```text
             前方（内侧段凸向前）
                        ↑
          ╭─────────────────────╮
         ╱                       ╲
   内侧端 ●                         ╰──● 外侧端
 （胸骨端）    ╭── S 形 ──╮            （肩峰端）
                        ╲
                        ↓
             后方（外侧段凹向前）
```

### 骨折好发部位

* **锁骨**

    * > **定义**：中间悬起、上方只有皮肤，是最易发生骨折的骨。

    * 骨折好发部位只有一处：中外 1/3 交界处。

    * 锁骨下方有锁骨下动脉（subclavian artery）走行。

    * 该处骨折有两条独立的危险路径。

    * 路径一：折端直接向下刺出，刺破锁骨下动脉，造成大出血。

    * 路径二：锁骨对肩胛骨的支撑失去，肩胛骨向前移位，肩峰段与内侧段形成交叉，交叉处折端同样向下刺破动脉。

```text
        中外 1/3 交界处骨折
                 │
      ┌──────────┴───────────┐
      ▼                      ▼
   折端向下刺出          对肩胛骨的支撑失去
   → 刺破锁骨下动脉        → 肩胛骨向前移位
   → 动脉大出血           → 肩峰段与内侧段交叉
                         → 交叉处折端向下刺破动脉
```

### 八字形绷带固定法

* **八字形绷带固定法**

    * > **定义**：锁骨骨折的现场处理方法，靠横"八"字把两肩向后拉。

    * ① 从患侧肩起，斜向下绕到**对侧**腋窝下方。

    * ② 转到身体前面，横着回来。

    * ③ 再绕到**患侧**腋窝下方。

    * ④ 再转到身体前面，与①交叉；交叉后形成一个"横"字，即"横八字"。

    * 目的：把两肩**向后拉**，使锁骨两个断端分开，防止折端刺破动脉，再转送医院。

    * 到医院后的固定方式可以是绷带固定法、钢针或钢板；因锁骨表面就是皮肤，手术比较简单。

## 肩胛骨

### 主要结构

* **肩胛骨（scapula）**

    * > **定义**：三角形的扁骨，后面与前面是两块不同的面。

    * 后面最明显的骨性隆起是肩胛冈（spine of scapula），体表能摸到。

    * 肩胛冈外侧端突出的骨性凸起是肩峰（acromion），体表能摸到。

    * 肩胛冈把肩胛骨后方分成上下两个窝：上方为冈上窝（supraspinous fossa），下方为冈下窝（infraspinous fossa）。

    * 三角形的三角：上角（superior angle）、下角（inferior angle）、外侧角。

    * 前面有肩胛下窝（subscapular fossa），是肩胛骨前面的凹陷。

    * 前面有一形似鸟嘴的骨性突起，称喙突（coracoid process）。

    * 外侧角附近有肩胛切迹（scapular notch）。

| 位置 | 结构 | 要点 |
| :--- | :--- | :--- |
| 后面横行隆起 | 肩胛冈 | 体表可摸 |
| 肩胛冈外侧端 | 肩峰 | 体表可摸 |
| 肩胛冈之上 / 之下 | 冈上窝 / 冈下窝 | 肩胛冈把后面分成上下两窝 |
| 上角 / 下角 | 上角 / 下角 | 下角体表可摸，对应第 7 肋 |
| 外侧角 | 关节盂（glenoid cavity） | 浅盘状关节窝，不是真正的"角" |
| 前面 | 肩胛下窝 | 肩胛骨前面的凹陷 |
| 前面骨性突起 | 喙突 | 形似鸟嘴，体表可摸 |
| 外侧角附近 | 肩胛切迹 | — |

* **关节盂（glenoid cavity）**

    * > **定义**：肩胛骨外侧角处的浅盘状关节窝。

    * > **易错点**：⚠️ 外侧角不是一个标准的"角"，它是浅盘状的关节窝，所以称为关节盂；相对三角形的另外两个角，它才相当于外侧角。

### 体表标志

* **肩胛骨体表可摸到的结构**

    * 一共 4 个：肩峰、肩胛冈、锁骨下角、喙突。

    * 锁骨下角体表可摸，同时对应第 7 肋，是计数肋的标志。

### 计数肋与计数棘突

* **计数肋**

    * 肩胛下角对应的肋是**第 7 肋**，看到下角就知道所对应的肋骨。

    * 肩胛上角对应的肋是**第 2 肋**。

* **计数棘突**

    * 两侧**肩胛冈内侧端的连线**对应**第 3 胸椎的棘突**。

    * 两侧**肩胛下角的连线**对应**第 8 胸椎的棘突**。

* **记忆要点**

    * 肩胛骨只需掌握四个层次：形状、主要结构、体表标志、计数线。

## 肱骨

### 骨性结构

* **肱骨（humerus）**

    * > **定义**：典型的长骨，是自由上肢骨的第一块骨。

    * 上端为半球状的关节面，称肱骨头（head of humerus）。

    * 上端外侧的骨性突起为大结节（greater tubercle），偏前内侧的骨性突起为小结节（lesser tubercle）。

    * 大、小结节之间的凹陷称结节间沟（intertubercular groove）。

    * 下端关节面：球状关节面为肱骨小头（capitulum），滑轮状关节面为肱骨滑车（trochlea）。

    * 下端两侧的突起：内侧为内上髁（medial epicondyle），外侧为外上髁（lateral epicondyle）。

    * 骨干后面有桡神经沟（radial groove）。

    * 内上髁的后外侧有尺神经沟（ulnar groove）。

    * 肱骨滑车上方、后面观为深窝即鹰嘴窝（olecranon fossa），滑车上方、前面观为浅窝即冠突窝（coronoid fossa），肱骨小头上方为桡窝（radial fossa）。

| 部位 | 前方 | 后方 |
| :--- | :--- | :--- |
| 上端 | 肱骨头、大结节（外侧）、小结节（前内侧），两者之间为结节间沟 | 肱骨头、大结节、小结节、结节间沟 |
| 下端关节面 | 肱骨小头（球状面）、肱骨滑车（滑轮面） | 肱骨滑车，与前方是同一关节面的后面 |
| 下端窝 | 桡窝（肱骨小头上方）、冠突窝（滑车前上方） | 鹰嘴窝（滑车上方） |
| 下端两侧 | 内上髁 / 外上髁 | 内上髁 / 外上髁 |
| 沟 | — | 桡神经沟（骨干后面）、尺神经沟（内上髁后外侧） |

* **下端两个窝的规律**

    * 桡窝在肱骨小头上方，冠突窝在肱骨滑车前上方，鹰嘴窝在肱骨滑车上方（后面）。

    * 前面观的两窝（桡窝、冠突窝）是浅的，后面观的一窝（鹰嘴窝）是深的。

    * > **易错点**：⚠️ 下端两个窝最容易混——前浅后深，这是这一段最易出错的地方。

* **外科颈（surgical neck）**

    * > **定义**：骨骺与骨干相接的部位。

* **解剖颈（anatomical neck）**

    * > **定义**：关节面的周缘。

* 两个"颈"是肱骨上最常考的定位点。

### 骨折部位与受损结构

* **肱骨周围的毗邻**

    * 外科颈**后方**有腋神经（axillary nerve）自内向外走。

    * 桡神经沟内下行的是桡神经（radial nerve）。

    * 尺神经沟内下降的是尺神经（ulnar nerve）。

    * 肱骨**内侧**有粗大的肱动脉（brachial artery）沿内侧下降，逐渐转到下 1/3 的前方，然后进入前臂。

* **骨折与损伤的对应**

| 骨折部位 | 可能损伤 | 定位依据 |
| :--- | :--- | :--- |
| 外科颈骨折 | 腋神经 | 位于外科颈后方，自内向外走 |
| 骨干中段骨折 | 桡神经 | 桡神经在桡神经沟内下行 |
| 内上髁骨折 | 尺神经 | 尺神经沟位于内上髁后外侧 |
| 下 1/3 骨折 | 肱动脉 | 肱动脉沿肱骨内侧下降，逐渐转到下 1/3 前方 |

### 体表标志

* **肱骨体表可摸到的结构**

    * 只有 2 个：内上髁、外上髁。

    * 肱骨头、大小结节、结节间沟、桡窝、冠突窝、鹰嘴窝、桡神经沟、尺神经沟体表都摸不到。

## 前臂骨

### 桡骨与尺骨的区分

* **前臂骨**

    * > **定义**：只有两块，即桡骨（radius）与尺骨（ulna）。

* **外形区分**

    * 四个字概括：**上小下大**。

    * 上端细、下端粗的是桡骨；上大下小的是尺骨。

    * 判读时从前方和后方两个方向看，用这条规律认出哪一块是桡骨。

### 桡骨

* **桡骨（radius）**

    * 上端膨大部分为头（head），头下方变细处为颈（neck）。

    * 桡骨粗隆（radial tuberosity）是一处肌肉附着点。

    * 下方骨刺为桡骨茎突（radial styloid process）。

    * 桡骨茎突之下为下关节面，与腕骨构成关节。

    * 桡骨头由两个关节面构成：朝上的浅盘状关节面为头凹（fovea），周围一圈为环状面（articular circumference）。

    * 桡骨茎突旁朝下的关节面称下关节面。

    * 此处有尺切迹（ulnar notch），与尺骨头相关节。

### 尺骨

* **尺骨（ulna）**

    * 前方的骨性突起为冠突（coronoid process）。

    * 后方较大的突起为鹰嘴（olecranon）。

    * 冠突与鹰嘴之间的关节面为滑车切迹（trochlear notch）。

    * 尺骨上另有桡切迹（radial notch）。

    * 下端为尺骨头（head of ulna）和尺骨茎突（ulnar styloid process）。

* **桡骨与尺骨对照**

| 部位 | 桡骨 | 尺骨 |
| :--- | :--- | :--- |
| 形态特征 | 上小下大 | 上大下小 |
| 上端 | 头（头凹 + 环状面）、颈 | 冠突、鹰嘴，其间为滑车切迹 |
| 骨干部 | 桡骨粗隆（肌肉附着点） | 尺骨粗隆（肌肉附着点） |
| 下端 | 桡骨茎突、下关节面、尺切迹 | 尺骨头、尺骨茎突 |

### 切迹的命名规律

* **切迹命名规则**

    * > **定义**：和谁构成关节，就叫什么切迹——名字来自对面的那块骨。

* **桡切迹（radial notch）**

    * 位于尺骨上，其关节面是环状面，抱在桡骨头外面。

* **尺切迹（ulnar notch）**

    * 位于桡骨上，其关节面是头凹，套在尺骨头外面。

### 体表标志与茎突高度差

* **前臂骨体表可摸到的结构**

    * 共 4 个：桡骨头、尺骨茎突、桡骨茎突、尺骨头。

    * 前臂骨的其他结构体表都摸不到。

* **两茎突的高度差**

    * 桡骨茎突与尺骨茎突不在同一条水平线上。

    * 桡骨茎突位置较低，尺骨茎突位置较高，两者相差 1～1.5 cm。

    * 这一高度差是正常状态，不是变异。

## 手骨

### 手骨的数量与分部

* **手骨**

    * > **定义**：由腕骨、掌骨、指骨三部分构成。

* **腕骨（carpals）**

    * 共 8 块。

    * 腕骨的长、宽、高近似相等，属短骨。

* **掌骨（metacarpals）**

    * 共 5 块。

* **指骨（phalanges）**

    * 共 14 块。

### 腕骨的排列

* **腕骨的两排结构**

    * 分近侧排与远侧排，每排 4 块。

    * 近侧排由拇指向小指依次为：舟骨（scaphoid）、月骨（lunate）、三角骨（triquetral）、豆骨。

    * 远侧排由拇指向小指依次为：大多角骨（trapezium）、小多角骨（trapezoid）、头状骨（capitate）、钩骨（hamate）。

    * 口诀：舟月三角豆，大小头状钩。

    * 5 块掌骨与远侧排一一对应：第 1 掌骨对应大多角骨，第 2 掌骨对应小多角骨，第 3 掌骨对应头状骨，第 4、5 掌骨共用钩骨。

```text
          拇 ───────────────────────→ 小指

  近侧排   ｜  舟  ｜  月  ｜ 三角 ｜  豆  ｜
  远侧排   ｜大多角｜小多角｜头状骨｜  钩  ｜
  ───────────────────────────────────────
  掌  骨   ｜  ①  ｜  ②  ｜  ③  ｜ ④⑤ │

  口诀：舟月三角豆，大小头状钩
  对应：①—大多角骨  ②—小多角骨  ③—头状骨  ④⑤—钩状骨
```

* **豌豆骨（pisiform）**

    * 位于三角骨上方，是一块小圆形的骨。

    * 它计入近侧排，近侧排因此是舟骨、月骨、三角骨加上豌豆骨。

### 腕沟与腕管

* **腕骨排列特点**

    * 腕骨背侧面的面积大于掌侧面的面积。

    * 以近侧排为例，舟骨背侧大于掌侧，月骨背侧大于掌侧，三角骨背侧大于掌侧。

* **腕沟（carpal groove）**

    * > **定义**：腕骨排列不在同一平面上，由此形成的骨性凹窝。

* **腕管（carpal tunnel）**

    * > **定义**：腕横韧带（flexor retinaculum）在腕沟沟口封闭后，腕沟变成的管道。

* **腕管内的结构**

    * 9 个肌腱：拇长屈肌（flexor pollicis longus）的肌腱 1 个、指深屈肌（flexor digitorum profundus）的腱 4 个、指浅屈肌（flexor digitorum superficialis）的腱 4 个。

    * 1 个神经：正中神经（median nerve）。

### 掌骨

* **掌骨（metacarpals）**

    * 排列命名从拇指向小指依次为第一至第五掌骨，即 1、2、3、4、5。

    * 结构命名：底在最下方（近端），中间为体，末端为头。

    * 掌骨末端为球状面，所以掌指关节既能屈伸，又能内收外展，还可以做环转。

    * 掌指关节运动形式多，与掌骨头球状面的结构直接有关。

### 指骨

* **指骨（phalanges）**

    * 拇指为 2 节，其余各指均为 3 节。

    * 排列命名按拇指、食指、中指、四指、小指。

    * 三节依次称近节、中节、末节。

* **指骨的滑车状关节面**

    * 指骨近端为底，中间为体，末端关节面两侧高、中间凹，呈滑车状，称滑车。

    * > **结论**：指间关节只能做屈伸，这个运动形式的限制由滑车状关节面的形状直接决定；与掌指关节的球状面一比，差别最明显。

* **指骨的末节**

    * 末节不再有关节面，末端称甲粗隆（tuberosity of distal phalanx），指甲附着在这个骨面上。

    * 末节的结构是底、体加甲粗隆。

* **小指指骨的骨型判定**

    * 判定长骨与短骨看是否具有"一体两端"。

    * 小指指骨具有一体两端，属长骨。

### 籽骨

* **籽骨（sesamoid bone）**

    * 位置在第一掌骨头的掌侧面，为一对小骨。

    * X 光片上该处出现的两个浓白阴影是正常结构。

    * 籽骨不属于 206 块骨之内。

## 下肢骨的划分

* 下肢骨的分法与上肢骨完全一致，也分两拨：**肢带骨**和**自由骨**。
* 唯一的区别是下肢的肢带骨只剩一块，名字叫**髋骨**。
* 髋骨摸上去是一整块，可在发育过程中它由三块骨拼成。
* 下肢的自由骨依次是**股骨**、**胫骨**、**腓骨**、**足骨**。

## 髋骨

### 髋骨的形成与三块骨

* **髋骨**
    * > **定义**：由髂骨、坐骨、耻骨在发育过程中愈合而成的一整块成年骨。
    * 髋臼窝内有一横一竖两块软骨板，组成一个"T"字型，把髋骨劈成三块。
    * "T"字型上面一块是**髂骨**，后下面一块是**坐骨**，前面那一块是**耻骨**。
    * 髂、坐、耻三块骨靠这副"T"字型软骨板连在一起，等到 16 岁以后骨化了，才变成一整块髋骨。

```text
                  髂骨
        ┌───────────┴───────────┐
        │      横的软骨板       │
        └───────────┬───────────┘
                    │
    耻骨 ───────────┴─────────── 坐骨
               竖的软骨板
           16 岁以后骨化为一体
```

* > **易错点**：这副软骨板还是一把"认名"的钥匙。髂骨上的结构全带"髂"字，坐骨上的结构全带"坐"字，耻骨上的结构全带"耻"字；拿到一个不认识的名字，先判断它长在哪块骨上，名字基本就猜对了一半。

### 髋骨的内侧面

* 内侧面是识别髋骨的主战场，分辨清"这里是前、那是后"之后再认结构。
* **髂嵴**
    * 上缘一条弓形的骨缘。
    * 体表从头到尾都能摸到。
* **髂前上棘**：髂嵴前端的突起。
* **髂结节**
    * 从髂前上棘向上走约 3～4 厘米，髂嵴在此明显增厚形成的隆起。
    * 挂图上画得不够明显，而它恰恰是临床上骨穿的部位。
* **耳状面**：一块粗糙的骨面，因形状像耳朵得名。
* **耻骨梳**
    * 内侧面那条骨线的前段，从耻骨上缘一路斜着往外。
    * 这一段骨线是锐利的。
* **弓状线**
    * 骨线向后内侧转的那一段，变得钝圆。
    * 弓状线是**大骨盆和小骨盆的分界线**。
    * 线以上是容纳腹腔内容物的大骨盆，线以下是通向体外的骨盆腔。
* **坐骨结节**：后下方的突起。
* **坐骨棘**：坐骨结节上方那个尖尖的突起。
* **大切迹**：坐骨棘上方的缺口。
* **小切迹**：坐骨棘下方的缺口。
* **闭孔**：前方那个大窟窿。
* **耻骨联合面**：闭孔上缘那张窄窄的骨面。

### 髋骨的外侧面

* 外侧面的结构跟内侧面基本是一套：大切迹、坐骨棘、小切迹、坐骨结节、耻骨弓、耻骨结节、闭孔都在。
* **髋臼**
    * 外侧面独有而且极其醒目的结构，一个很深很深的窝。
    * 髋臼是下肢骨往躯干骨上"装"过去的地方：躯干骨那个向上的凹窝接住股骨头，接的就是这里。
    * 认外侧面只要认准一个词：髋臼。

### 髋骨结构的分布与归属

* 板图把髋骨摊平后的走行顺序：
    * 前方是**髂前上棘**。
    * 往下是**髂前下棘**（不要求记，知道有这么个东西就行）。
    * 再往内是**髂耻隆起**。
    * 然后是**耻骨梳**、**耻骨结节**、**耻骨联合面**，联合面往后外侧出去的一段叫**耻骨弓**。
    * 后下方是**坐骨结节**、**坐骨棘**，棘上是大切迹，棘下是小切迹。
    * 后面是**髂后上棘**和**髂后下棘**。
    * 再往前回到粗糙的**耳状面**、钝圆的**弓状线**以及**闭孔**。
* 内外侧都出现的那一串（耻骨弓、耻骨结节、坐骨结节、坐骨棘、大切迹、小切迹、闭孔）必须分清归属。
* > **注意**：正式点名要背的是髂前上棘、髂结节、髂嵴、耳状面、耻骨梳、弓状线、髂耻隆起、耻骨结节、耻骨联合面、坐骨结节、坐骨棘、大切迹、小切迹。

### 髋骨的体表标志

* **髂嵴**
    * 体表全程能摸到。
    * 是最方便、也最常被引用的骨性标志。
* **髂结节**
    * 临床做骨穿（骨髓穿刺）选这里。
    * 原因是表面就是皮，一按到底，不用穿过太多软组织。
* **髂前上棘**
    * 重要的体表标志。
    * 经典的阑尾压痛点在**脐与髂前上棘连线的中外三分之一交界处**。
* **耻骨结节、坐骨结节**：体表都能摸到。
* 两侧**髂嵴的最高点对应第四腰椎的棘突**。

## 股骨

* **股骨**
    * > **定义**：下肢自由骨里的第一根骨，也是全身最长的骨。
    * 全身最长，因此它身上的结构名也最多。
    * 最大的特点在上端：上面是球状的**头**，往下是一段细的**颈**，而这个颈不是直上直下的，是个"歪脖子"。

### 股骨的上端

* **大转子**：上端外侧的骨性突起。
* **小转子**：上端内侧的骨性突起。
* **转子间线**：大转子与小转子之间那条粗糙的骨线。
* > **易错点**：这里特别容易跟肱骨搞混。肱骨是外侧一个大结节、前内侧一个小结节；股骨的大转子甩到了**后内侧**。记住：大转子在外，小转子在后内。

### 股骨的下端

* **内侧髁**：下端两侧突出的侧髁之一。
* **外侧髁**：下端两侧突出的侧髁之一。
* **髌面**
    * 下端前方正中一块关节面。
    * 与髌骨构成关节。

### 股骨后面的结构

* **股骨粗线**
    * 后方骨干上一条粗糙的骨线。
    * 内收肌群全都附着在这条线上。
    * 越往下越锐利，到下端变成一条骨棱。
* **髁间窝**
    * 两个侧髁关节面之间凹进去的那个骨性凹窝。
    * 两条骨棱之间夹着的凹陷就是髁间窝。
* **臀肌粗隆**
    * 旁边一块比较粗糙的骨面。
    * 臀大肌就止在这个地方。

### 股骨的必记名词与体表标志

* 要求记住的名词：大转子、小转子、内侧髁、外侧髁、髌面、转子间线、股骨粗线、髁间窝、臀肌粗隆。
* 隔着皮肤能摸到的：**大转子**和**两个侧髁**。

## 小腿骨

* 小腿骨是两块：里面是**胫骨**，外面是**腓骨**。

### 胫骨

* **胫骨**
    * > **定义**：小腿里面那块骨，上粗下细，是小腿的承重主力。
* **内侧髁、外侧髁**：上端两侧的突起，同样叫侧髁。
* **髁间隆起**：上端关节面的中部向上鼓起的一个骨性突起。
* **胫骨粗隆**
    * 上端前方的骨性隆起。
    * 它是肌肉的抵止点。
* **胫骨前嵴**（也叫胫骨前缘）
    * 从粗隆往下一路向下的骨缘，非常锐利，是胫骨最好认的标志。
    * 手掌放在自己小腿前面从上往下压，能明显感到一条"刀背"，那就是它。
* **内踝**：下端内侧的骨性隆起。
* **下关节面**：下端朝下的那个关节面。

### 腓骨

* **腓骨**
    * 细长，不承重，功能上更像配角。
    * 因此它的骨性标志也最简单：上面一个膨大叫**腓骨头**，下面一个膨大叫**外踝**，记住这两个就够用。
    * 从后面看，小腿下端两侧的突起就是内踝和外踝，外侧能摸到的最高点是腓骨头。

### 小腿骨的必记名词与体表标志

* > **注意**：要背的名词是胫骨侧髁（内、外）、胫骨粗隆、髁间隆起、胫骨前嵴、内踝、下关节面，以及腓骨的腓骨头、外踝。
* 体表能摸到的全都能摸到：两个侧髁、胫骨粗隆、胫骨前嵴、内踝、外踝、腓骨头。

## 足骨

### 足骨的数目与构成

* 足骨分三部分，数目记牢：跗骨 7 块、跖骨 5 块、趾骨 14 块。

| 部分 | 数目 | 构成与命名 |
| :--- | :--- | :--- |
| 跗骨 | 7 | 距骨、跟骨、足舟骨、骰骨、第一至第三楔骨 |
| 跖骨 | 5 | 第 1～5 跖骨，结构命名同手骨：底、体、头 |
| 趾骨 | 14 | 第 1～5 趾，每趾节数不等，结构命名：底、体、滑车，末端有甲粗隆 |

### 跗骨的定位与命名

* 跗骨靠位置命名，最好记。
    * 靠内侧有一个小骨，叫**距骨**。
    * 距骨的下方有一个又长又大的，叫**跟骨**。
    * **骰骨**的内侧紧贴着**舟骨**（正式名称叫足舟骨）。
    * 最外面三块依次是**第一、第二、第三楔骨**。
* 命名规则：前三块都叫楔骨，第四块叫骰骨，骰骨里面那一块叫舟骨；上面小的那个叫距骨，下面长大块的那个叫跟骨。
* **跟结节**：跗骨后方突出的那个。
* > **提示**：七块跗骨可以一串到底——**一二三楔骰内舟，上距下跟后出头**。

### 跖骨与趾骨的构造命名

* **跖骨**
    * 排列还是按 1、2、3、4、5 来。
    * 结构命名跟手骨非常相像：**底、体、头**。
* **趾骨**
    * 结构命名是**底、体、滑车**。
    * 最末端那一块粗糙的隆起叫**甲粗隆**。
    * 跟手骨的构造基本一致。

## 上下肢骨性标志

* 体表标志就是临床定位的底子，一定要记牢。

### 上肢的骨性标志

* **锁骨**：全长注意，都能摸到；锁骨外侧端上方还能摸到**肩峰**。
* **肘部**
    * 肱骨下端向两侧突起，分别叫**外上髁**和**内上髁**。
    * 屈肘的时候，下方那个尖叫**鹰嘴**（尺骨的）。
    * 内上髁、外上髁、鹰嘴这三点就是肘部最经典的体表标志。
* **手部**
    * 前臂桡骨下端、尺骨下端各有一个尖，叫**桡骨茎突**和**尺骨茎突**，两者相差 1～1.5 厘米。
    * 再往前一点还能摸到一块绿豆大小的骨，**豌豆骨**。
* **握拳时暴露的结构**
    * 手背上冒出的一串骨性隆起，每个突起都是一根**掌骨头**。
    * 再往前是**指骨**：拇指有第一节、第二节，示指有第一节。
    * 指骨的结构是**底、体、滑车**，末端是**甲粗隆**。
    * 所以握拳时手上摸到的这些包，全是掌骨头和指骨滑车。

### 下肢的骨性标志

* **髋部**
    * 整圈能摸到的是**髂嵴**。
    * 它前方是**髂前上棘**。
    * 髋关节外侧是**大转子**。
    * 后面是**坐骨结节**。
* **坐骨神经的体表定位**
    * 把**坐骨结节**和**大转子**连一条线。
    * 这条线的中点下面走着一根重要的神经——**坐骨神经**。
* **膝部**
    * 上面是股骨，下面是胫骨，前面是髌骨（旁边的腓骨比胫骨短，缩在下面）。
    * 这一圈能摸到的是：股骨的**内侧髁、外侧髁**，胫骨的**内侧髁、外侧髁**，再加前方的**髌骨**。
* **小腿**
    * **髌骨**、**胫骨粗隆**、**胫骨前嵴**，再往下就是**足背**和**内踝**。
    * 外侧还有腓骨的**腓骨头**（上）和**外踝**（下）。
* > **提示**：别忘了记住每块骨上到底有几个关节面，因为下一步讲关节，这些知识马上要用。比如**尺骨上端有几个面**？桡切迹、滑车切迹，两个；**桡骨上端有几个面**？桡骨头凹、环状关节面，也是两个。带着这种"数面"的意识去学关节会顺很多。

## 骨与骨的连接方式

* 全身的骨与骨之间一共有两种连接方式：**直接连接**和**间接连接**。
* 重点全压在间接连接这一边。

### 直接连接

* **直接连接**
    * > **定义**：借助韧带、软骨或者骨这样的结构，把两个骨直接连在一起。
    * 第一种形式：颅骨是弓形的，一块挨一块，靠**骨缝**连接，骨缝里面藏着一条韧带叫**缝韧带**，它是长在骨缝里面的。
    * 第二种形式：两块骨之间靠**软骨**连接在一起。
    * 第三种形式：靠**骨性结合**。
    * 最突出的特点是**两骨之间没有间隙**：骨缝里没有间隙，靠软骨连接的两块骨之间也没有间隙。
    * 因为连得这么死，活动度很小，甚至完全没有活动度。

### 间接连接（关节连接）

* **间接连接**
    * > **定义**：骨与骨之间借助**结缔组织囊**相连接，因中间隔了一个囊，两骨之间自然**有间隙**，活动度大。
    * 这种连接方式就叫**关节连接**。

### 两种连接的对比

| 比较项 | 直接连接 | 间接连接（关节连接） |
| :--- | :--- | :--- |
| 靠什么连 | 韧带、软骨、骨性结合 | 结缔组织囊（关节囊） |
| 两骨之间 | 没有间隙 | 有间隙 |
| 活动度 | 很小或没有 | 大 |
| 例子 | 颅骨的骨缝（缝韧带） | 膝关节、肩关节等 |

## 关节的基本结构

* **关节面**
    * > **定义**：相邻两骨的相对面必须具有关节面。
* **关节囊**
    * > **定义**：两骨之间靠结缔组织囊相连，这个囊是两层结构。
* **关节腔**
    * > **定义**：两骨之间存在的腔隙，内有滑液。
* 把这三个字连起来记，就是**囊、面、腔**。
* 三个条件齐备这才叫一个关节，缺哪一个都不成立。
    * 囊是外层的包被。
    * 面是两块骨相对的骨面。
    * 腔是囊里那个让骨面互不直接接触的空间。

```text
       ┌──────────────┐
       │   关节囊     │
       │ （两层结构） │
       └───────┬──────┘
   ┌───────────┴───────────┐
   │       关节腔          │
   │    （内有滑液）       │
   └───────────┬───────────┘
   ▓▓▓▓▓▓▓▓▓▓▓▓      关节面         ▓▓▓▓▓▓▓▓▓▓▓▓
        骨                             骨
```

## 关节的辅助结构

* 光有囊面腔，关节只做到"能连上"；真正让它经得起拉扯的是关节的辅助结构，一共三类。

### 囊内韧带

* **囊内韧带**
    * 为什么叫"囊内"：大多数关节在关节囊**外面**就有韧带，所以长在囊里面的韧带其实很少。
    * 典型的例子就是膝关节：上面是股骨下端，下面是胫骨上端，前面是髌骨。
* **十字交叉韧带**
    * 膝关节里的一对韧带，形状从侧面看是个十字。
    * 一条叫**前交叉韧带**，一条叫**后交叉韧带**。
    * 它们起自胫骨的**髁间隆起**（一个从前方进去，一个从后方进去），止于股骨的**髁间窝**，所以正好交叉。
    * 它们长在关节腔里面，属于关节辅助结构中的囊内韧带。

### 关节盘与关节唇

* **关节盘**
    * > **定义**：一块软骨结构，垫进两个关节面中间，用来增大接触面积。
    * 以膝关节为例：股骨的内侧髁、外侧髁对着下面胫骨的关节面，接触面本来只是两个平面。
    * 为了让它们贴合得更牢、更稳，关节面中间垫进一块块软骨垫，把接触面积扩大。
    * 作用一句话：**增大两个关节面的接触面积，从而提高关节的稳固性**。
* **关节唇**
    * 肩关节由肩胛骨的**关节盂**和**肱骨头**构成。
    * 问题的根源在形状上：关节窝是个很浅的浅盘，面积小；而肱骨头是半球状，面积大得多，小锅配大锅当然不稳。
    * 解决办法是在关节盂的边缘绕一圈软骨环，贴在骨板上，相当于给窝"加了一圈边"，把关节凹的面积撑大。
    * 肱骨头装进去以后稳定性明显加强，这圈软骨结构就叫关节唇。

### 滑膜襞与滑膜囊

* 两者在膝关节里能一次看全，先交代髌骨的位置关系。
    * 上面有块大的肌肉叫**股四头肌**，它的肌腱把髌骨包起来，一直抵止在**胫骨粗隆**上。
* **滑膜襞**
    * 关节活动时髌骨和股骨下方的**髌面**相互摩擦，问题是怎样减少这种摩擦。
    * 从关节面的周缘往上，滑膜层鼓起来形成一个小囊，形成一个**皱襞**，皱襞里面装的**全是脂肪组织**。
    * 这个三角形结构在膝关节里叫**翼状皱襞**。
    * 存在是有道理的：关节囊的滑膜层包着大量脂肪，凸进膝关节这个本来就很大的腔隙里，把腔隙面积缩小，反而**有利于关节的稳固**。
* **滑膜囊**
    * 关节囊上方鼓起来的那一个囊腔，从髌骨上缘往上顶出来，叫**髌上囊**。
    * 它为什么必须在：髌骨和股骨之间要来回运动，如果囊腔里只有少量滑液，肌腱和骨面就能直接对上、直接磨。
    * 有了这个囊、有了这点滑液，骨面和肌腱就被隔开了，**摩擦就小得多**。

```text
             股四头肌
                 │
         （肌腱包住髌骨）
                 │
               髌骨
                 │  ← 与股骨的髌面相互摩擦
   ┌─────────────┴──────────────┐
   │  翼状皱襞（滑膜襞）        │ ← 滑膜层包着脂肪，凸入关节腔
   │                            │
   │  关节腔（滑液）            │
   │                            │
   └──────┬──────────────┬──────┘
          │   髌上囊     │ ← 滑膜囊
          └──────────────┘
```

* > **注意**：关节的三句总纲——骨连接分**直接**和**间接**两种，重点在间接连接，所以也叫关节连接；关节的基本结构是**囊、面、腔**三要素；辅助结构三类——**囊内韧带**、**关节盘与关节唇**、**滑膜襞与滑膜囊**，共同作用都是把关节弄得更稳、摩擦更小。
