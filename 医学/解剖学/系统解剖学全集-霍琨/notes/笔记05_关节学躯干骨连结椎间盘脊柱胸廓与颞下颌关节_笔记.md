# 关节学·躯干骨连结：椎间盘、脊柱、胸廓与颞下颌关节

## 椎骨的连结形式

* **椎骨之间的三种连接**

    * 关节连接——上下关节突之间构成的关节，又称椎间关节。

    * 韧带连接——关系到脊柱稳不稳。

    * 椎间盘连接——直接关系到疼不疼。

* **椎间关节**

    * > **定义**：椎骨的上下关节突所构成的关节，也叫椎间关节。

    * 活动幅度很小，属微动关节。

* **三条连接线索的分工**

    * 关节连接最省事，幅度最小。

    * 韧带决定脊柱稳定性。

    * 椎间盘一旦破裂即产生疼痛与神经压迫。

## 椎骨结构的判读

### 矢状切面上的辨识

* **判方位是第一步**

    * > **提示**：拿到挂图先分清前与后。

    * 图上上两个椎体被切成矢状切面，下两个椎体是完整的。

    * 主要看切面——只有断面才能把"贴在骨表面的韧带"和"夹在两块骨之间的结构"同时显示出来。

* **矢状切面从前向后的顺序**

    * 最前面一大块是椎体。

    * 椎体往后一层断面相当于椎板。

    * 再往后是棘突的断面。

    * 把椎体拿掉再往前看一层，是椎弓根的断面；相邻两个椎弓根之间的骨板就是椎板。

    * 椎板交界处向上翘的是上关节突，椎板两侧伸出的是横突。

* **断面画法**

    * 凡是被切开的断面都画成骨松质的网眼，一眼可辨"这块是切开的"。

### 上面观的结构

* **椎体上面观**

    * 前方为椎体，后方为椎孔。

    * 椎弓根连接椎体与椎板，椎弓根两侧是横突。

    * 后正中收成一个尖——棘突，是最细最长的结构。

* **上面观示意**

    ```text
                            棘 突（后正中，最细最长）
                                ▲
            椎 板 ════╮   ╭───┴───╮   ╭════ 椎 板
                     │   │       │   │
            横 突 ◀───┤   │ 椎  孔 │   ├───▶ 横 突
                     │   │       │   │
            椎弓根 ───┴───┴───────┴───┴─── 椎弓根
                                 │
                              ┌──┴───┐
                              │ 椎 体 │  ← 前方
                              └──────┘
    ```

## 椎骨的韧带连接

### 位置总览

* **韧带的分布**

    * > **定义**：椎骨韧带按位置分为椎体前方、椎体后方、椎板之间、棘突之间、棘突尖以上，另有一小群在横突之间。

* **五条韧带的矢状面排列**

    ```text
                            后方
                             │
                        ┌────┴────┐
                        │ 棘上韧带 │   长　棘突尖之间
                        │    │ │   │
                        │  ┌─┴─┴─┐ │
                        │  │棘间  │ │   短　棘突之间
                        │  │韧带  │ │
           椎弓根 ─────┤  ├─────┤ ├───── 椎弓根
                        │▒▒│椎板 │▒▒│      黄韧带　短
                        │▒▒│     │▒▒│      ▒ 与椎板共同构成椎管后壁
                        │   ├─────┤ │
                  前纵 │   │椎体 │ │ 后纵   ← 椎间盘（纤维环＋髓核）
                  韧带 │   ╰─────╯ │ 韧带
                        │  ▒▒▒▒▒▒  │
                        ╰───────────╯
                            前方
    ```

    * 从前向后依次是前纵韧带（贴椎体前面）、椎体、后纵韧带、椎管，再往后是椎板与黄韧带、棘间韧带、棘上韧带。

    * 横突间韧带长在左右两侧，矢状面上看不到。

### 椎体前后的两条长韧带

* **前纵韧带**

    * > **定义**：在椎体前方下降的长韧带。

    * 范围包得很大，从颅底一直延伸到尾骨。

    * 形态宽厚。

    * 与骨面结合紧密——问一句它和骨面容不容易分离：不容易分离。

* **后纵韧带**

    * > **定义**：在椎体后方下降的长韧带。

    * 窄而薄，原因是受到椎管宽度限制，想宽也宽不了。

    * 与骨面结合疏松，翻译过来就是与椎体骨面容易分离。

* **两条长韧带对照**

    | 对比项 | 前纵韧带 | 后纵韧带 |
    | :--- | :--- | :--- |
    | 位置 | 椎体前方 | 椎体后方 |
    | 长度 | 长韧带，颅底直到尾骨 | 长韧带 |
    | 形态特点 | 宽厚，包绕椎体的范围比较大 | 窄而薄，受椎管限制宽不了 |
    | 与骨面结合 | 紧密，不容易分离 | 疏松，容易分离 |

* **易混点**

    * > **易错点**：这一对最容易记混，因为关键词正好摆对着——前纵是宽厚、紧密结合，后纵是窄薄、结合疏松。

    * > **提示**：后纵韧带"结合疏松"这一条先记住，它不是在这儿用的，后面讲椎间盘突出时直接拿它当推导的钥匙。

### 椎板、棘突与横突之间的韧带

* **黄韧带**

    * > **定义**：椎板与椎板之间的短韧带。

    * 从椎弓根处起，向上、向下都有；椎弓根是椎板的上端，所以黄韧带长在相邻两个椎板之间。

    * > **定义**：椎管后壁 = 若干个椎板 + 若干个黄韧带。

    * 椎管后壁不只是椎板自己。

* **棘间韧带**

    * 跨在棘突与棘突之间，与黄韧带位置相近但对象不同。

    * 同属短韧带。

* **棘上韧带**

    * 位于棘突尖的上方，从下往上连着棘突尖。

    * 是长韧带。

* **项韧带**

    * > **定义**：项韧带是棘上韧带在项部增宽的一段。

    * 棘上韧带走到颈部即项部增宽，改名为项韧带；反过来说，项韧带向下就移行为棘上韧带。

    * 增宽与颈椎棘突的形态有关：最上的寰椎只有后弓、没有棘突；第二至第六颈椎棘突越来越长，第七颈椎最长。

* **横突间韧带**

    * 位于横突与横突之间，是一些短韧带。

## 椎间盘

### 构造

* **椎间盘**

    * > **定义**：椎间盘 = 纤维环 + 髓核，卡在两个椎体之间形成软骨垫。

    * 作用是减少椎骨之间的震动。

    * 纤维环与髓核的界限是人为划出来的。

* **纤维环**

    * 位于周围，是一圈套一圈的软骨环，同心圆排列。

* **髓核**

    * 位于中心，是胶冻状结构，性质像一块冻着的果冻。

* **椎间盘断面示意**

    ```text
                    上位椎体
              ╭─────────────────╮
              │    ╭─────────╮   │
              │    │ · · · · │   │   外层：纤维环
              │    │╭───────╮│   │   （同心圆排列的软骨环）
              │    ││· · · ·││   │
              │    ││  髓核 ││   │   中心：髓核（胶冻状）
              │    ││· · · ·││   │
              │    │╰───────╯│   │
              │    ╰─────────╯   │
              ╰─────────────────╯
                    下位椎体
    ```

### 突出

* **椎间盘突出**

    * > **定义**：纤维环破裂后，上面和下面两个椎体相互作用、互相一挤，把胶冻状结构挤出去，就叫突出。

    * 最常见的诱因是突然的腰部用力。

    * 一般多半发生在腰椎。

* **推导链的四个环节**

    * 突然的腰部用力 → 纤维环破裂 → 髓核向后突出。

    * 因为后纵韧带与骨面结合疏松，它不会死死钉在椎体后缘上，而是跟着髓核一起向后突出，挡不住。

    * 椎管内密集排列成束的马尾神经受压。

    * 下肢产生一系列临床改变。

    * 四个环节缺一环这条推导就走不通，所以每一环都得记住。

* **腰椎好发的根据**

    * 腰椎的椎管里密集排列成束的是马尾神经。

    * 马尾神经一旦受压，下肢就产生一系列临床改变，这正是间盘突出的临床表现。

* **突出过程示意**

    ```text
          上下椎体相互挤压（突然的腰部用力）
                        ↓
               ┌──────────────────┐   上位椎体
               │     纤维环       │
               └────────┬─────────┘
                        │  纤维环破裂，髓核被挤向后下方
                        ▼
               ┌──────────────────┐   下位椎体
               │▓▓ 髓核 ▓▓ ──────┼──▶  挤出
               └──────────────────┘      │
                      ── 椎体后缘 ─┼────│
                                      │
                   后纵韧带 ─────────┼───▶│  与骨面结合疏松，
                          （疏松！）    │     所以跟着髓核一起向后突出
                                      ▼
           ┌──────────────────────────────────┐
           │ 椎管：马尾神经密集排列成束 → 受压 │
           └──────────────────────────────────┘
    ```

## 脊柱的整体观

### 三个方向的观察

* **后方观**

    * 脊柱应该成一条直线，两侧是肩胛骨。

    * 脊柱所有的棘突应该在一条直线上。

* **前方观**

    * 主要看椎体，椎体从上到下由小变大。

    * 到骶骨的上缘最宽；力作用到下肢以后，骶骨下边越来越窄。

    * 规律是由小变大，再由大变小。

* **侧面观**

    * 颈部一个弯曲，胸部一个，腰部一个，骶尾部一个。

    * 名称依次是颈曲、胸曲、腰曲、骶尾曲。

### 四个生理弯曲

* **侧面观示意**

    ```text
            前方 ←                            → 后方

                    ╭────╮              颈曲（凸向前）
                ╭────╯    ╰────╮
                               ╰────╮    胸曲（凸向后）
                ╭───────────────────╯
                     ╭───────╮          腰曲（凸向前）
                ╭─────╯       ╰────╮
                                  ╰──╮  骶尾曲（凸向后）
      ──────────────────────────────────────
           颈椎段        胸椎段      腰椎段     骶尾椎段
    ```

* **四个生理弯曲的凸向**

    * 颈曲凸向前。

    * 胸曲凸向后。

    * 腰曲凸向前。

    * 骶尾曲凸向后。

* **先天与后天**

    * 胎儿先天具备两个弯曲：胸曲、骶尾曲。

    * 会爬、能抬头以后，颈曲出现。

    * 会坐、会站以后，腰曲出现。

    * > **易错点**：后天这两个最容易记反——抬头出颈曲，坐站出腰曲。

## 胸廓

### 组成与连接

* **胸廓的组成**

    * 前方是胸骨，两侧是肋，后方是胸椎，三大部分构成胸廓。

* **胸肋关节**

    * > **定义**：胸廓前方的关节连接，由胸骨和肋软骨构成。

    * 局限在第 2 到第 7 肋。

    * 第一肋骨是软骨结合，没有形成关节，只是用软骨直接连到胸骨上。

* **肋椎关节**

    * > **定义**：胸廓后方的连接，由肋头关节和肋横突关节合称。

    * 肋骨上的肋骨小头对应椎体，形成肋头关节。

    * 肋骨上的肋结节对应横突，形成肋横突关节。

* **两条连接通路**

    * 前方靠胸肋关节（胸骨 ↔ 肋软骨，2～7 肋）连接。

    * 后方靠肋椎关节（肋头关节 + 肋横突关节）连接。

    * 两条路一起把肋骨固定在胸骨和脊柱上。

### 三个特点

* **上窄下宽**

    * 从前方观察胸廓，上面和下面的横径不一样，上面窄、下面宽。

* **前后径小于左右径**

    * 在胸廓做水平断面，量前后径与左右径并比较，前者短于后者。

    * > **提示**：前后径与左右径相等就不是正常。临床上的桶状胸见于肺气肿，特征就是前后径和左右径相等——这条描述是用来跟桶状胸做对照的。

* **脊柱凸入胸廓内**

    * 断面可见脊柱的断面凸入到胸廓的腔内。

    * 脊柱两侧因此各留下一条凹陷，形成两侧的肺沟。

* **三个特点汇总**

    * 上窄下宽。

    * 前后径小于左右径。

    * 脊柱凸入胸廓内。

### 上下口

* **胸廓上口**

    * 前方是胸骨柄，柄上缘有颈静脉切迹。

    * 两侧是第一肋，后方是第一胸椎。

* **胸廓下口**

    * 前方是剑突，两侧是肋弓。

    * 再往后可见 11 肋、12 肋的下缘，最后到第 12 胸椎。

* **上下口对照**

    | 开口 | 前方 | 两侧 | 后方 |
    | :--- | :--- | :--- | :--- |
    | 胸廓上口 | 颈静脉切迹（胸骨柄上缘） | 第一肋 | 第一胸椎 |
    | 胸廓下口 | 剑突 | 肋弓、11、12 肋下缘 | 第 12 胸椎 |

* **上下口示意**

    ```text
                    前方
       ┌────────────────────────────────────┐
       │  颈静脉切迹（胸骨柄上缘）            │   ← 胸廓上口
       └────┬──────────────────────────┬─────┘
          第一肋                    第一胸椎
                       ╲                ╱
                        ╲    胸  廓    ╱
                         ╲            ╱
       ┌────────────────┴──────────┴─────┐
       │  剑突                          │      ← 胸廓下口
       └────┬──────────────────────┬────┘
           肋弓          11、12 肋下缘    第 12 胸椎
    ```

### 体表标志

* **胸骨角**

    * 胸骨柄与胸体交界处向前凸的骨性隆起。

    * 两侧对应的正好是第二肋；摸到胸骨角往下数第一根肋就是第二肋，可用来计数肋骨。

* **剑突**

    * 胸骨下方的尖，体表能摸到。

* **肋弓**

    * 位于两侧，体表能摸到。

* **胸骨下角**

    * > **定义**：整个的角称胸骨下角，它自己还分成两个角——左侧剑肋角、右侧剑肋角，合起来才是整个胸骨下角。

## 颞下颌关节

### 关节的构成

* **关节凸**

    * > **定义**：来自下颌骨的髁突，又名下颌头，这两个名字指的是同一个东西。

    * 位于关节的下方。

* **关节凹**

    * > **定义**：由颅底的关节结节与下颌窝构成，位于关节上方。

    * 放大后可见颧弓的剖面同样画成骨松质网眼，前方隆起的是关节结节，后方凹陷的是下颌窝。

    * 关节结节和下颌窝都是颅底的结构。

* **关节囊与关节盘**

    * 关节囊从前到后整个把关节包住，图上看到的那一片一定是剖面。

    * 关节盘在关节囊里面，是一块软骨板。

* **构成一览**

    | 组成 | 结构 | 位置 | 归属 |
    | :--- | :--- | :--- | :--- |
    | 关节凸 | 髁突（下颌头） | 下方 | 下颌骨 |
    | 关节凹 | 关节结节 + 下颌窝 | 上方 | 颅底 |
    | 关节囊 | 薄而松，前到后包住全关节 | 外层 | — |
    | 关节盘 | 软骨板 | 囊内 | — |

### 三个结构特点

* **关节囊薄而松**

    * 囊薄而松有利于这个关节的灵活性——包得越松，活动度越大。

* **囊内有关节盘，关节腔被分成上下两腔**

    * 关节盘的凸面与颅底的骨性凹面围成上腔。

    * 关节盘的凹面与髁突的凸面围成下腔。

    * 一个关节盘把原来的一个关节劈成了两个关节，等于形成了一个复合关节，两个关节叠在一起协同运动，这个关节自然更灵活。

* **囊外有外侧韧带**

    * 关节囊外侧还有一条韧带，叫外侧韧带。

    * 关节囊包住颧弓、关节结节、下颌窝、外耳门、乳突、喙突、下颌角这一整片。

* **关节结构示意**

    ```text
            前方（颧弓侧）                          后方
      ┌──────────────────────────────────────────────────┐
      │        关节结节                                    │
      │          ╱╲                 外耳门 │                │
      │     下颌窝 ╲                       │                │
      │        ╱╲  ╲   ▒▒▒▒ 上腔 ▒▒▒      │                │
      │       ╱  ╲══╲══════════════════│ ← 关节盘         │
      │      ╱      ╲   ░░░ 下腔 ░░░                        │
      │     ╱   髁突（下颌头）                               │
      │        喙突                                          │
      │                                                      │
      │ ▒▒▒▒▒▒▒▒▒▒ 关节囊：薄而松，把整个关节包住 ▒▒▒▒▒▒▒▒ │
      └──────────────────────────────────────────────────┘
            囊外：外侧韧带
    ```

### 运动与脱位

* **运动方向**

    * 下颌关节可以上下、可以前后、也可以左右，三个方向都能走，运动很灵活。

* **脱位方向**

    * > **结论**：下颌关节只有前脱位，没有后脱位。

    * 髁突正好坐在关节凹里，脱位方向的后边紧挨着粗大的乳突，后面被乳突顶住。

    * 灵活的关节都容易脱位。

* **髁突位置与张口角度**

    * 正常情况下下颌头在下颌窝里。

    * 张口到 15 度时，髁突到达关节结节最高点的下方，15 度角就是最不稳定的位置。

    * 继续张大，整个关节都向前滑动，髁突跑到关节结节的前方。

    * 到了关节结节前方就是不可逆的，不能自行回位。

* **常见诱因**

    * 大笑（微笑本身不至于，笑到大笑程度才容易脱位）。

    * 打哈欠。

    * 暴力拔牙——拔牙时医生总要患者张大嘴，操作起来才方便。

* **脱位的临床表现**

    * 下颌前移，即所说的兜齿。

    * 不能说话。

    * 不能吞咽，张着嘴吞不了，口水因此流出来。

    * 耳廓前下方有一个明显的皮肤凹陷。

    * 这个凹陷正常人张嘴时也摸得到、闭嘴即回；脱位时髁突前移，该处空出来才形成凹陷，位置一变反倒成了标志。

* **复位手法**

    * 医生的两个拇指伸进患者口腔去推，拇指压在下颌骨前缘上。

    * 推之前必须用绷带保护好、缠厚点儿，因为牙齿可能直接伤到医生自己。

    * 方向记两个动作：脱位了先向下压，然后再向后上推。
