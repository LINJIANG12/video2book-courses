# 解剖学绪论：人体结构层次、方位术语与骨的总论

## 系统解剖学的研究对象

* **系统解剖学**

    * > **定义**：研究**正常**人体或器官的**形态结构**、**生理功能**与**发生发展规律**的学科。

    * 研究对象限定为**正常**人体或器官，不含病变、不含畸形；病理学、病理解剖学才以这个「正常」为参照，考察它在哪里发生了偏离。

    * **形态结构**与**生理功能**必须合看：既要记住骨在何处、肌肉走向如何，也要知道它为什么长成这样、在所处的位置上能完成什么功能；很多结构特点是被功能和位置逼出来的。

## 解剖学在医学中的地位

* **恩格斯的论断**

    * > **结论**：没有解剖学就没有医学，医学是建立在解剖学基础之上的。

    * 解剖学是一门重要的**医学基础课**。

    * 临床上使用的名词约有**三分之二**来自解剖学。

* **需要解剖学直接支撑的临床操作**

    * **体表定位**：靠解剖熟悉脏器，才能在体表准确判断肝、脾的大小，找出胆囊与阑尾的投影位置以及胆囊、阑尾的压痛点。

    * **硬膜外麻醉**：患者已就位后，须确定进针部位、针的走行方向，并判断针尖何时进入硬膜外腔。

    * **球后注射**：眼部局部注射抗菌素，须选定进针部位与进针方向，才能不伤及眼球。

    * **环甲膜穿刺**：急性喉阻塞患者濒临窒息，先行环甲膜穿刺建立暂时呼吸通道以争取气管切开时间；须明确环甲膜所在部位及针尖穿入的是喉的哪个腔隙。

    * **心内注射**：在胸骨左侧第四肋间进针，须了解胸腔解剖，明确针尖进入心脏的哪个腔隙、周围有哪些结构，以及会不会造成气胸。

    * **胃切除术**：切断后需将胃与空肠吻合，须确定空肠起端的走行与辨认方法、切胃时结扎胃血管的位置，并保证术后生理功能。

## 解剖学的分科

```text
解剖学的分科
│
├─ 按方法分
│  ├─ 巨视解剖学：用人的肉眼去研究
│  │    ├─ 系统解剖学
│  │    └─ 局部解剖学
│  └─ 微视解剖学：借助于显微镜研究人体的形态和结构
│       ├─ 组织学
│       ├─ 细胞学
│       └─ 胚胎学
│
└─ 按内容分
   ├─ 外科解剖学、显微外科解剖学
   ├─ 表面解剖学、神经解剖学
   ├─ X 线解剖学（就是影像解剖学）、断层解剖学
   └─ 运动解剖学（体育学院）、美术解剖学（美术学院）
```

* **巨视解剖学与微视解剖学**（按方法分的主线）

    * **巨视解剖学**：用人的肉眼去研究人体的形态和结构，下分**系统解剖学**与**局部解剖学**。

    * **微视解剖学**：借助于显微镜研究人体的形态和结构，包括**组织学、细胞学、胚胎学**。

* **按内容分出的横向门类**

    * 医学类：外科解剖学、显微外科解剖学、表面解剖学、神经解剖学、X 线解剖学（即影像解剖学）、断层解剖学。

    * 医学之外：运动解剖学供体育学院使用，美术解剖学供美术学院使用。

* **系统解剖学与局部解剖学的视角差别**

    * **系统解剖学**：按系统铺开全身，一个器官一个器官地认。

    * **局部解剖学**：守住一个部位，把该部位的结构、层次以及毗邻关系抠清楚。

    * 断肢再植这类手术，依赖的正是断面的局部解剖知识；不了解断面解剖，肢体接回去了功能也保不住。

## 人体的结构层次与系统

```text
        细胞  ＋  细胞间质
                │
                ▼
             组织 ──┬── 上皮组织
                     ├── 结缔组织
                     ├── 肌组织
                     └── 神经组织
                │
                ▼
             器官 ──  不同的组织组成器官
                │
                ▼
             系统 ──  具有相同功能的器官构成系统
```

* **结构层次的四级链条**

    * **细胞**是人体最基本的结构单位。

    * **细胞 ＋ 细胞间质 = 组织**；人体只有四大组织：**上皮组织、结缔组织、肌组织、神经组织**。

    * 不同的组织构成**器官**；具有相同功能的器官构成**系统**。

* **九大系统**

    | 系统 | 系统 | 系统 |
    | :--- | :--- | :--- |
    | 运动系统 | 消化系统 | 泌尿系统 |
    | 生殖系统 | 呼吸系统 | 循环系统 |
    | 感觉器官系统 | 内分泌系统 | 神经系统 |

## 标准的解剖姿势

* **解剖姿势（anatomical position）**

    * 头正，双下肢并拢，足尖朝前，两上肢自然下垂，**掌心朝前**。

    * 与普通人立正姿势的唯一差别就是掌心朝前。

    * 全部方位术语（上下、前后、内外、左右）都以这个姿势为基准来定义。

    * > **易错点**：姿势一变，术语的含义就全变。课本上没写「掌心朝前」时，描述指的是解剖姿势，而不是立正姿势。

## 剖面与轴

* **三个剖面**

    * **矢状面**：沿**前后方向**将人体或器官切成的切面。

    * **冠状面**：沿**左右方向**将人体或器官切成的切面。

    * **水平面**：沿**水平方向**切开的切面。

* **三个轴**

    * **垂直轴**：由上向下，与地面垂直。

    * **冠状轴**：从左到右，与水平面相平行。

    * **矢状轴**：由前向后，与水平面相平行。

* **面与轴的对应关系**

    | 剖面 | 切割方向 | 对应的轴 | 轴的方向 |
    | :--- | :--- | :--- | :--- |
    | 矢状面 | 沿前后方向切 | 矢状轴 | 由前向后，与水平面相平行 |
    | 冠状面 | 沿左右方向切 | 冠状轴 | 从左到右，与水平面相平行 |
    | 水平面 | 沿水平方向切 | 垂直轴 | 由上向下，与地面垂直 |

    * > **提示**：面与轴的名字是成对的，各自从方向定义即可对上——沿前后切出来的是矢状面，前后走向的轴就是矢状轴；沿左右切的是冠状面，左右走向的轴就是冠状轴。三个面、三个轴不要记混。

## 解剖方位术语

* **十条约定的判断标准**

    | 术语 | 判断标准 |
    | :--- | :--- |
    | 上 | 近头顶 |
    | 下 | 近足底 |
    | 前（腹侧） | 近腹侧 |
    | 后（背侧） | 近背侧 |
    | 内 | 靠近中轴线 |
    | 外 | 远离中轴线 |
    | 近端 | 四肢：靠近肢根；消化管：靠近口腔 |
    | 远端 | 四肢：远离肢根；消化管：靠近肛门 |
    | 浅 | 体表结构：接近皮肤；管状结构：远离管腔 |
    | 深 | 体表结构：远离皮肤；管状结构：接近管腔 |

* **上下前后与内外**

    * **上**：按解剖姿势，靠近头顶的一侧为上。

    * **下**：靠近足底的一侧为下。

    * **前（腹侧）**与**后（背侧）**：从人体侧面看，靠近腹侧为前，靠近背侧为后。

    * **内**与**外**：以假设存在的人体中轴（中轴线）为界，靠近中轴线为内，远离中轴线为外；以躯干为例，肋弓、剑突、脐均属中轴附近的结构。

* **近端远端与浅深**

    * **近端**与**远端**：四肢以肢根为界，靠近肢根为近端，远离肢根为远端；消化管改以两端为界，靠近口腔为近端，靠近肛门为远端。

    * **浅**与**深**：体表结构以皮肤为界，接近皮肤为浅，远离皮肤为深；管状结构（如消化管）改以管腔为界，接近管腔为深，远离管腔为浅。

    * > **易错点**：判断「内/外」和「浅/深」之前，先问参照物是谁。体表结构以中轴线、以皮肤为准；管状结构以管腔为准。参照物一换，「内」和「深」就反过来了。

* **上下肢的侧别称谓**

    * **臂**按标准姿势仍称内外；**前臂**有特殊叫法：内侧是尺骨，内侧称**尺侧**；外侧是桡骨，外侧称**桡侧**。

    * **大腿**仍称内外；**小腿**同理：内侧是胫骨，内侧称**胫侧**；外侧是腓骨，外侧称**腓侧**。

## 骨的形态分类

* **两套互不相同的分类口径**

    * **按部位分**：人体骨分为**颅、躯干、附肢**（附肢即上肢和下肢）三大部分。

    * **按形态分**：全身的骨分为长骨、短骨、扁骨、不规则骨四组。

    * > **易错点**：这两套分法的名字都不带「部位」或「形态」，做题时极易串在一起。按部位是颅、躯干、附肢；按形态才是长、短、扁、不规则。

* **按形态分类的四型骨**

    | 类型 | 代表 | 特点 |
    | :--- | :--- | :--- |
    | 长骨 | 位于四肢的骨 | 四肢的骨都比较长，以关节为轴，可以做幅度较大的**杠杆运动** |
    | 短骨 | 手骨的**腕骨**、足骨的**跗骨** | 长、宽、高近似相等 |
    | 扁骨 | 围成颅腔的骨、胸廓的骨以及骨盆的骨 | 都是扁薄呈弓形的骨，围成骨性腔，对腔内脏器起保护作用 |
    | 不规则骨 | 脊柱上的椎骨、颅骨里的下颌骨 | 形状不规则 |

## 长骨的结构

* **长骨的组成**

    * **骨干（长骨体）**：长骨中间较细的部分。

    * **骨骺**：长骨两端比较膨大的部位。

    * **关节软骨**：位于骨骺的游离端所具有的关节面之上。

    * **滋养孔**：长骨干上可见的小孔，血管经此孔进入骨质内。

## 骨的构造

* **骨质**

    * 骨质由**密质**与**松质**两部分构成。

    * **密质**：位于骨的外周，致密、坚硬；全骨都有，**骨干处厚，骨骺处薄**。

    * **骨松质**：位于骨的内部，呈疏松网眼状；在**干骺端向骨干逐渐减少，至骨干处完全消失**，骨干内空出的腔就是**骨髓腔**，腔内容纳骨髓。

    | | 密质 | 松质 |
    | :--- | :--- | :--- |
    | 位置 | 骨的外周 | 骨的内部 |
    | 形态 | 致密、坚硬 | 疏松、网眼状 |
    | 分布 | 全骨都有；骨干厚，骨骺薄 | 干骺端向骨干逐渐减少，至骨干处消失 |

* **骺板与骺线**

    * **骺板**：位于**骨骺内部的软骨板**。

    * **骺线**：骺板被完全骨化后形成的**浓白致密的线状阴影**。

    * 骨的长径由骺板的增长拉长：骺板增长的同时，其周围又被骨化；再增长、再骨化，骨由短变长。当**增长速度小于骨化速度**时，骺板逐渐变薄，最后完全骨化消失。

    * 软骨在 X 光下不显影，所以儿童的骺板在片子上呈**带状透明区**，表现为骨端的「分离」；等这块软骨被完全骨化，位置不再移动，就留下终生不变的骺线。

    ```text
      儿童                                  成人
      ┌──────────┐                          ┌──────────┐
      │  骺 板   │  软骨                    │  骺 线   │  浓白致密的线状阴影
      └──────────┘                          └──────────┘
           X 线下不显影，
        呈带状透明区，看起来像骨端「分离」
    ```

    | | 骺板 | 骺线 |
    | :--- | :--- | :--- |
    | 是什么 | 骨骺内部的软骨板 | 骺板骨化后形成的线状阴影 |
    | X 线下什么样 | 软骨不显影，呈带状透明区，表现为骨端的「分离」 | 浓白致密的线状阴影 |
    | 结局 | 增长速度小于骨化速度时变薄，最后完全骨化消失 | 骺板骨化完成后就固定下来 |

    * > **易错点**：骺板是软骨，X 光下根本看不见，只留下一条透明带；骺线是骺板骨化之后留下的线状阴影。骺板最终必然完全骨化而消失，此后骨上只剩骺线——两者不是同一种东西，也不会长期并存。

* **骨髓**

    * 成人的骨髓分**红骨髓**与**黄骨髓**两种。

    * **红骨髓**存在于**骨松质的网眼内**。

    * **黄骨髓**仅存在于**长骨的骨髓腔内**。

    * > **结论**：红骨髓有造血能力，黄骨髓没有造血能力。

* **骨膜**

    * 骨膜是覆盖在**新鲜骨外周**的**结缔组织膜**；到关节面的周缘骨膜即消失，**关节软骨表面无骨膜覆盖**。

    * 骨膜**富有血管和神经**，其中含大量躯体传入神经，骨折疼痛即由它传递。

    * 骨膜容易与骨面分离；**骨膜内层细胞可分化为成骨细胞和破骨细胞**，二者参与骨的生长和修复。

    * > **注意**：关节软骨终身保留、并不骨化，但它表面没有骨膜，骨膜只包到关节面周缘为止。

* **骨的血管与神经**

    * 骨的血管来源丰富：进入骨的**骺动脉**、**干骺端动脉**；随滋养孔进入骨内的**滋养动脉**，分为**升支和降支**；以及骨膜上的**骨膜动脉**。

    * 来源多、供给充分，这也是骨膜敏感、骨折疼痛剧烈的原因。

## 骨的生长

* **两种生长方式**

    | | 膜化骨 | 软骨化骨 |
    | :--- | :--- | :--- |
    | 由什么变成骨 | 结缔组织膜 | 软骨（骺软骨） |
    | 例子 | 新生儿颅囟（前囟、后囟、蝶囟、乳突囟）闭合成颅骨 | 骺软骨使骨变长，最终骨化成骺线 |

* **骨向长生长靠骨的两端**

    * 在小猪骨干处插上**三根银针**继续喂养，长大后三针之间的距离**没有改变**。

    * 结论：骨向长生长靠骨的两端，靠的就是**骺板**。

* **骨向粗生长与髓腔扩大**

    * **茜草喂猪实验**：英国花布印染商用印染花布的茜草残渣拌糖麸喂猪，肉骨呈红色，文章登于皇家学会会报；法国地主照做但茜草时断时续，猪骨断面**红白相间**，形成很多**骨性环**——红即有茜草，白即无茜草。

    * **第一个结论**：骨向粗生长像大树长树轮一样，由内向外一圈一圈形成骨性环；机制是**成骨细胞**不断在骨的外周贴附、被骨化，再贴附、再骨化，骨因此逐渐变粗。

    * **第二个实验**：在小猪骨上**绑一根银丝**继续喂养，长大后银丝**掉进了骨髓腔**里。

    * **第二个结论**：骨向粗生长的同时，**髓腔也随之变大**；机制是骨膜内层细胞分化出的**破骨细胞**从内侧把骨质刨除。

    * **第三个实验**：在骨干处插上**三根银针**继续喂养，长大后三针之间的距离没有改变。

    * **第三个结论**：骨向长生长靠骨的两端，也就是**骺板**。

    | 实验 | 做法 | 现象 | 结论 |
    | :--- | :--- | :--- | :--- |
    | 第一个 | 茜草时断时续地喂猪 | 骨断面红白相间，形成骨性环 | 骨向粗生长，像树轮一样一圈圈往外加 |
    | 第二个 | 在小猪骨上绑一根银丝 | 银丝掉进了骨髓腔 | 骨变粗的同时，髓腔也随之变大 |
    | 第三个 | 在骨干处插三根银针 | 三针之间的距离没有改变 | 骨向长生长靠骨的两端，也就是骺板 |

    * **成骨与破骨的相对比喻**

        ```text
                ┌────────────────────────┐
                │                        │
                │    ┌────────────┐      │
                │    │            │      │
                │    │   房间（腔） │      │
                │    │            │      │
                │    └────────────┘      │
                │                        │
                └────────────────────────┘
                  外侧工人「漫墙」          内侧工人「刨墙」
                   ＝成骨细胞                ＝破骨细胞
        ```

        * 房子是骨，房间是髓腔；外侧只加砖的工人是成骨细胞，内侧一边刨一边等的工人是破骨细胞。

        * 墙两边同时动作，墙整体外移：骨变粗、内腔变大，而墙的厚度始终不变。

        * 好处是**骨壁始终保持一个厚度，减少骨的重量**——这正是破骨细胞的作用。

    * > **结论**：骨向长生长靠骨的两端（骺板）；骨向粗生长靠骨膜内层的成骨细胞；破骨细胞从内侧刨除骨质，使髓腔随骨一起变大，骨壁厚度恒定、重量减轻。
