# 肌学·头肌：面肌、颅顶肌与咀嚼肌

## 头肌的两大类

   * **面肌（表情肌、皮肌）**

       * > **定义**：位于皮下的浅层肌肉，起于骨、止于皮，收缩时直接牵拉皮肤产生表情。

       * 位置表浅，就在皮下。

       * 起止点与一般肌肉相反：一般肌肉起于骨、止于骨，面肌起于骨、止于皮。

       * 肌肉一收缩就牵拉皮肤，皮纹发生变化，皮纹一变，喜怒哀乐就出来了。

   * **咀嚼肌**

       * 共四块，前面浅面两块、后面深面两块。

       * 附着所用的骨性标志：鼻骨、上颌、眶、颧弓、颧骨、关节结节、下颌窝、外耳门、乳突，以及下颌骨的髁突、冠突。

---

## 面肌

   * **面肌（表情肌、皮肌）**

       * > **定义**：起于骨、止于皮、位于皮下的浅层肌肉。

       * 别名有表情肌与皮肌两种；叫皮肌是因为它位置表浅且止于皮。

       * 临床判断某块肌肉是否受损，靠的就是把位置、起止、功能三者对应起来。

---

## 眼轮匝肌

   * **眼轮匝肌**

       * > **定义**：位于眼裂周围、分部呈环状排列的面肌。

       * 位置在眼裂周围，不是完整的一坨，而是分成几部分。

       * 三部分都环绕眼裂、呈环状排列，区别只在圈的大小和位置。

```text
                   眶部
       （位于眼眶表面，最大的一圈）
    ┌─────────────────────────┐
    │     ┌─────────────┐     │
    │     │    睑部     │     │
    │     │   ┌─────┐   │     │
    │     │   │眼裂 │   │     │
    │     │   └─────┘   │     │
    │     └─────────────┘     │
    └─────────────────────────┘
               ●
               │
               └─→ 泪囊部：内眦处到泪囊的一小束肌
```

| 部分 | 位置 | 功能 |
| :--- | :--- | :--- |
| 眶部 | 眼眶表面，最大的一圈 | 闭眼 |
| 睑部 | 最靠内，在上睑、下睑前面围一圈 | 眨眼 |
| 泪囊部 | 内眦处到泪囊的一小束肌 | 扩张泪囊 |

> **结论**：眼轮匝肌眶部—闭眼；睑部—眨眼；泪囊部—扩张泪囊。

---

## 口裂周围的肌肉

### 口轮匝肌

   * **口轮匝肌**

       * > **定义**：环绕口裂、呈环状排列的面肌。

       * 位置在口裂周围呈环状排列，与眼轮匝肌包绕眼裂是同一套路，只是把眼裂换成口裂。

       * 正常情况下闭口由口轮匝肌收缩造成。

       * 肌纤维强力收缩时产生吹口哨的动作。

### 口周放射肌

   * **口周放射肌**

       * > **定义**：排列在口轮匝肌周围、呈辐射状排列的一组面肌。

       * 功能是牵拉口角向各个方向运动。

       * 排列规律：全部排列在口轮匝肌的周围，呈辐射状。

       * 辨认方法：认出「往中间收」的那一圈是口轮匝肌，向外散开成放射状的一片就全是口周放射肌。

       * 组成：鼻肌（鼻翼处）、提上唇肌、颧大肌、颧小肌、笑肌、颊肌（深面）、降口角肌、降下唇肌、颏肌。

```text
                     鼻肌（鼻翼处）
                            │
    提上唇肌 ────────────────┼────────────── 笑肌
         │                 │                 │
    颧大肌 ────────────────┤            颊肌（深面）
         │                 │                 │
    颧小肌 ────────────────┤            降口角肌
         │                 │                 │
    降下唇肌 ──────────────┘              颏肌
                            │
                         〔口〕

  〔口〕= 口轮匝肌，管闭口与吹口哨
  外围一圈细肌 = 口周放射肌，呈辐射状排列
```

> ⚠️ **易错点**：颧弓下方那块较大的肌肉是咬肌，属于咀嚼肌，不属于面肌；它位置挨着口周放射肌的外侧，但体系不同。

## 颅顶肌

### 额肌与枕肌

   * **颅顶肌**

       * 位于头顶部，由额肌和枕肌两块肌肉组成。

   * **额肌**

       * 位于额部，抵止在额部的皮肤，即止于皮。

       * 收缩时眉上提，额部出现抬头纹；抬头纹是额肌出来的。

   * **枕肌**

       * 位于后方的枕部，起自枕部颅骨的上项线，即止于骨。

       * 收缩时牵拉帽状腱膜。

   * 额肌与枕肌之间夹着一层腱膜相连，叫帽状腱膜。

       * 两块肌肉一起收缩，头皮就能前后动。

```text
            前方                           后方
        ┌───────────┐                  ┌───────────┐
        │  额肌     │                  │  枕肌     │
        └─────┬─────┘                  └─────┬─────┘
              │                                │
      止于皮（额部皮肤）            止于骨（枕骨上项线）
              │                                │
        ┌─────▼────────────────────────────────▼─────┐
        │            帽状腱膜            │
        └──────────────────────────────────────────────┘
                        │
                        ▼
              两肌收缩 → 头皮前后移动
```

### 帽状腱膜

   * **帽状腱膜**

       * > **定义**：连接额肌与枕肌的膜性结构。

       * 与皮肤结合得紧密。

       * 与颅骨中间隔着疏松的结缔组织；因为中间是疏松的，所以它和颅骨之间可以动。

```text
      头皮层次，由浅到深
  ┌──────────────────────┐
  │  皮肤                │ ← 与帽状腱膜结合紧密
  ├──────────────────────┤
  │  帽状腱膜            │ ← 连于额肌与枕肌之间
  ├──────────────────────┤
  │  疏松结缔组织        │ ← 松 → 帽状腱膜可以滑动
  ├──────────────────────┤
  │  颅骨                │
  └──────────────────────┘
```

       * 头部外伤时，伤口张开说明帽状腱膜已被砍开：这块肌肉本身有张力，前后的两侧都有张力，刀把帽状腱膜砍开后它被向两侧拉开。

       * 伤口张开说明伤得比较深，下面就是颅骨，这时要彻底清创，否则一感染就会引起颅内的感染。

       * 伤口闭合说明帽状腱膜没被砍开，损伤比较浅，一般清创以后缝合就行。

> **结论**：帽状腱膜是头皮层次里一个很主要的层次，紧贴颅骨（中间只隔疏松结缔组织）。头部外伤时伤口张开与否，就是判断帽状腱膜有没有被切开、伤得深不深的直接依据。

## 咀嚼肌

   * **咀嚼肌**

       * 共四块：浅层的颞肌与咬肌，深层的翼外肌与翼内肌。

       * 看深层要动手段：把颧弓锯开、把下颌支破开，露出里面那个窝，窝里有上下两块肌肉。

---

### 浅层肌肉

   * **颞肌**

       * > **定义**：位于颞窝、起于颅骨侧面颞窝而止于下颌骨冠突的咀嚼肌。

       * 位置在颞窝里，颞窝是颅骨侧面一个比较大的窝，窝里附着着这块肌肉。

       * 起于颅骨侧面的颞窝，止于下颌骨的冠突，从颧弓的深面过去止在冠突上。

       * 肌纤维分前部与后部：前部肌纤维收缩上提下颌，后部肌纤维收缩后拉下颌。

       * 功能是上提下颌、后拉下颌。

   * **咬肌**

       * > **定义**：位于颧弓到下颌角外侧之间、起于颧弓而止于咬肌粗隆的咀嚼肌。

       * 位置在颧弓到下颌角外侧之间，是一块很发达的肌肉。

       * 起于颧弓的下面和内侧面，止于咬肌粗隆。

       * 功能是上提下颌。

---

### 深层肌肉

   * **翼外肌**

       * > **定义**：位于深层上方、止于翼肌凹，并另有一小肌束止于关节盘的咀嚼肌。

       * 位置在深层两块肌肉的上面一块。

       * 抵止于翼肌凹，翼肌凹位于下颌颈的前方。

       * 另有一个止点是止于关节盘的小肌束，该小肌束收缩时把关节盘向前拉。

       * 关节盘被前拉后，髁突（也就是下颌头）被拉到关节结节的下方，这就是张口动作。

       * 功能一是张口；二是使下颌骨前移；三是一侧收缩时能使下颌骨侧移。

   * **翼内肌**

       * > **定义**：位于翼外肌深面、止于下颌角内侧的咀嚼肌。

       * 位置在深层两块肌肉的下面一块，即上一块（翼外肌）的深面。

       * 抵止于下颌角的内侧。

       * 功能是使下颌骨上提，也能使下颌骨前移。

   * **关节盘**

       * 位于下颌关节的关节囊里面，是夹在囊内的中间软骨板。

       * 把下颌关节分成上、下两个腔。

```text
          关节结节 / 下颌窝
                 │
                 ●────→ 小肌束，止于关节盘
                 │      收缩时把关节盘向前拉
         ▓▓▓▓▓▓▓▓│▓▓▓▓▓▓
         ▓▓▓▓▓▓▓▓│▓▓▓▓▓▓   大片肌腹
         ▓▓▓▓▓▓▓▓│▓▓▓▓▓▓
                 │
                 ▼
    抵止于翼肌凹（下颌颈前方）
```

---

## 四块咀嚼肌的起止与功能

| 肌肉 | 起始 | 抵止 | 功能 |
| :--- | :--- | :--- | :--- |
| 颞肌 | 颅骨侧面的颞窝 | 下颌骨的冠突 | 上提下颌、后拉下颌 |
| 咬肌 | 颧弓的下面和内侧面 | 咬肌粗隆（下颌角外侧） | 上提下颌 |
| 翼外肌 | 长文未说明 | 翼肌凹（下颌颈前方） | 张口；下颌骨前移；一侧收缩使下颌骨侧移 |
| 翼内肌 | 长文未说明 | 下颌角的内侧 | 上提下颌；下颌骨前移 |

> ⚠️ **注意**：翼外肌和翼内肌的起始部位未展开说明，只讲了它们的抵止，表里空着不是漏写，用的时候回教材补上。

## 从表情体征定位受累肌

   * **体征与受累肌的对应**

       * 抬头纹消失的一侧：额肌。

       * 闭不上眼的一侧：眼轮匝肌。

       * 鼻唇沟浅、嘴角被拉向对侧的一侧：口周放射肌。

       * 流口水、闭不上口的一侧：口轮匝肌。

       * 推理依据：好的额肌才提得起眉、才出得了抬头纹；眼轮匝肌不能收缩就闭不上眼；口周放射肌张力大、能收缩的一侧鼻唇沟深，不能收缩的一侧就被对侧拉走；闭不上口即口轮匝肌不好使。

| 患者 | 抬头纹 | 闭眼 | 鼻唇沟与口角 | 流口水 | 受累肌 | 瘫痪范围与类型 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 患者甲 | 一侧有、对侧没有 | 一侧闭不上 | 一侧浅，口角被拉向对侧 | 有 | 额肌、眼轮匝肌、口周放射肌、口轮匝肌 | 同侧自上而下全部表情肌受累，单侧面神经周围瘫（核下瘫） |
| 患者乙 | 两侧都有 | 两侧都能闭 | 一侧浅，口角被拉向对侧 | 有 | 口周放射肌、口轮匝肌 | 仅下半面瘫，中枢瘫（核上瘫） |

   * **单侧面神经周围瘫（核下瘫）**

       * 抬头纹消失的一侧额肌损伤，有抬头纹的一侧额肌是好的。

       * 眼轮匝肌出问题，闭不上眼。

       * 口周放射肌不能收缩，鼻唇沟变浅，口角被对侧拉向对侧。

       * 口轮匝肌不好使，闭不上口而流口水。

       * 四组合起来是同侧自上而下的全部表情肌瘫痪。

   * **中枢瘫（核上瘫）**

       * 两侧都有抬头纹，说明双侧额肌都好。

       * 两侧眼都能闭，说明两侧眼轮匝肌都好。

       * 表现全部集中在嘴部：一侧口周放射肌没力量，被对侧拉过去，鼻唇沟变浅、口角歪向一侧。

       * 该侧口轮匝肌也不行，闭不上口而流口水。

       * 额肌和眼轮匝肌完好，仅下半面瘫痪。

> **结论**：额头、眼、口角、闭口四组体征一分，受累的问题肌就锁定；再由受累范围判定瘫痪类型。
