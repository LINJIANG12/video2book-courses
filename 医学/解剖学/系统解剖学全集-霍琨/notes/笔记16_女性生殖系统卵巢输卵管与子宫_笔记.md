# 女性生殖系统：卵巢、输卵管与子宫

## 盆腔内的位置关系

* **小骨盆上口**
    * 盆腔的入口平面，是辨认盆腔内器官上下位置的基准线
    * 进入盆腔后，膀胱居前、子宫居中、直肠居后，三者排成一条前中后的线
    * 子宫两侧向上后方弯曲的那根管道是输卵管
    * 被输卵管环抱的卵圆形结构是卵巢

* **位置关系口诀**
    * 卵巢被输卵管抱着

    ```text
                     腹  前  壁
       ═════════════ 小骨盆上口 ═════════════
            膀胱         子宫         直肠      前 / 中 / 后
                           ╱  ╲
                     输 ╱ 卵  巢 ╲ 输
                        (    )                 ← 输卵管环抱卵巢
       ══════════════════ 盆底 ══════════════
    ```

## 卵巢

### 形态

* **卵巢（ovary）**
    * 外形为扁卵圆形
    * 成人表面凹凸不平，小儿卵巢表面光滑
    * 凹凸不平的成因是排卵：约 28 天排卵一次，排卵使卵巢表面破溃将卵细胞释放入腹腔，破溃处修补后留下一批凹窝
    * 反复破溃与修补累积，使表面终呈一片凹凸不平

* **形态速记**
    * 扁卵圆形 + 表面凹凸不平，两者一起记

### 位置

* **卵巢窝（ovarian fossa）**
    * > **定义**：髂内动脉与髂外动脉分叉交叉处所形成的腹膜凹陷，称为卵巢窝，卵巢位于其中
    * 凹陷位于腹膜上，左右两侧各一个
    * 卵巢位于小骨盆侧壁，每侧一个

* **髂内动脉与髂外动脉的由来**
    * 腹主动脉在第 4 腰椎水平开始分支，每侧发出一支髂总动脉
    * 髂总动脉在骶髂关节前方分成两支
    * 奔向盆腔者为髂内动脉
    * 经腹股沟韧带到大腿者为髂外动脉
    * 在腹膜深面可见这两条动脉，交叉处即形成卵巢窝

### 功能

* **卵巢的两项功能**
    * 产生卵细胞
    * 分泌雌性激素

* **雌性激素的作用**
    * 维持女性的第二性征

### 固定的装置

* **固定装置的组成**
    * 共三个：两条韧带加一个系膜
    * 将一侧输卵管向外牵拉即可暴露卵巢

| 固定装置 | 相连的两端 | 性质 |
| :--- | :--- | :--- |
| 卵巢悬韧带 | 卵巢上端 ↔ 骨盆侧壁 | 韧带 |
| 卵巢固有韧带 | 卵巢下端（或内侧端）↔ 子宫角 | 韧带 |
| 卵巢系膜 | 卵巢 ↔ 子宫阔韧带后壁 | 双层腹膜反折 |

* ⚠️ **易错点**：卵巢固有韧带连到子宫角，不是连到宫底；卵巢悬韧带连到骨盆侧壁，走向向上方。两条一上一下，不要互换。

## 子宫阔韧带

* **矢状切面所见**
    * 由外向内看半侧结构，可见子宫侧面轮廓，呈倒置的梨形
    * 同一层面上还可见输卵管断端与卵巢断端

* **阔韧带的形成**
    * 子宫阔韧带是包绕输卵管、向下垂吊到盆底的一个腹膜皱襞，共两层
    * 前层包绕输卵管向下走行直到盆底
    * 后层向下走行，又包绕卵巢，然后到盆底
    * 两层合起来即子宫阔韧带
    * 输卵管走在阔韧带的上缘内
    * 阔韧带自上而下的次序是：前层的输卵管系膜，中间隔着输卵管的腔与卵巢系膜，后层下行至盆底

    ```text
                 输 卵 管
            ┌────────────────┐
            └───┬────────┬───┘   ← 输卵管系膜（双层反折）
        ════════╪════════╪════   阔韧带前层：包绕输卵管下行至盆底
                │        │
            ┌───╨────────╨───┐
            │      卵  巢    │   ← 卵巢系膜（双层反折）
        ════╧════════════════   阔韧带后层：包绕卵巢下行至盆底
                  盆  底
    ```

* **两个系膜的归属**
    * 最外侧的小反折是输卵管系膜，包着输卵管
    * 包着卵巢的那一圈是卵巢系膜
    * 卵巢系膜是固定卵巢的结构，与阔韧带后壁相连接

* ⚠️ **易错点**：输卵管系膜与卵巢系膜都包含在阔韧带之内，它们不是独立的第三、第四层腹膜，而是阔韧带整体在不同部位形成的双层反折。

* ⚠️ **易错点**：图中阔韧带边缘看似断头其实不是断端，它与盆侧壁的腹膜相延续，腹膜本来就是连续的。

## 输卵管

### 形态与位置

* **输卵管的形态**
    * 长而弯曲的喇叭状管道
    * 内侧细、外侧粗

* **输卵管的常规位置**
    * 位于子宫阔韧带的上缘内
    * 被一层膜状结构包着并向下垂吊到盆底，这层结构即子宫阔韧带

* ⚠️ **易错点**：常规位置有一条例外，即子宫部，它位于子宫壁内，根本不在阔韧带内。

* ⚠️ **易错点**：挂图上那根输卵管是展开画的，并非自然状态；自然状态下输卵管是盘曲的，看到直愣愣伸出的样子不要当作本来形态。

### 四部分

* **分部顺序**
    * 子宫向两侧水平外伸处即输卵管起端，逐渐膨大，末端形成漏斗状，边缘有指状突起
    * 从子宫角向外共分四部分

| 部分 | 别称 | 位置与特点 |
| :--- | :--- | :--- |
| 间质部 | 子宫部 | 位于子宫壁内，所以不在阔韧带内 |
| 峡部 | — | 由子宫水平向外伸；短而直、腔小壁厚 |
| 壶腹部 | — | 长而弯；腔大壁薄 |
| 漏斗部 | 伞部 | 呈漏斗状，口的周缘有许多指状突起，即输卵管伞 |

* **四部分名称的背法**
    * 间质部（子宫部）→ 峡部 → 壶腹部 → 漏斗部（伞部）

* **峡部与壶腹部特点相反**
    * 峡部短而直、腔小壁厚；壶腹部长而弯、腔大壁薄
    * 女性输卵管结扎就选在峡部
    * 漏斗部口的周缘为许多指状突起，这个指状凸起称输卵管伞

## 子宫

### 位置与毗邻

* **位置的范围**
    * 位于膀胱与直肠之间，前邻膀胱、后邻直肠
    * 上端不超过小骨盆上口
    * 下端不低于坐骨肌
    * 两侧有输卵管和卵巢，下端接阴道
    * 保持轻度的前倾前屈位

* **前后毗邻**
    * 由前向后依次为腹前壁、耻骨联合、膀胱、阴道、子宫、直肠
    * 女性尿道短、直、宽，阴蒂与小阴唇位于膀胱一带

* **下端不低于坐骨肌这条边界的意义**
    * 子宫掉到坐骨肌以下、垂入阴道称为子宫脱垂
    * 子宫脱垂分三度，严重的 III 度脱垂时子宫颈直接从阴道口露出
    * 脱垂的成因是固定装置松弛

* **怀孕时的尿频与便秘**
    * 怀孕后子宫体积增大，向前压膀胱、向后压直肠
    * 膀胱受压不能过度充盈，存少许尿就要排，产生尿频
    * 直肠受压使食物残渣排出变慢、停留时间延长，直肠吸收残渣水分，水分被吸收越多粪便越干越硬，形成便秘

### 前倾与前屈

* **前屈角**
    * > **定义**：子宫体长轴与子宫颈长轴之间的夹角称前屈角
    * 子宫体约占上 2/3，子宫颈约占下 1/3，两条长轴在体颈交界处折出此角

* **前倾角**
    * > **定义**：子宫体长轴与阴道长轴之间的夹角称前倾角

    ```text
                     子宫体长轴
                        ╱
                       ╱ 前屈角 ← 子宫体长轴与子宫颈长轴的夹角
            子宫颈长轴 ╱
                     │
                     │      阴道长轴
                     │     ╱
                     │  ╱ 前倾角 ← 子宫体长轴与阴道长轴的夹角
                     │ ╱
    ```

* **两个角的区分**
    * 前屈是体与颈之间"腰弯了"，前倾是整体往前倒
    * 正常子宫只是轻度前倾前屈
    * ⚠️ **易错点**：不要把两个角记反，也别丢掉"轻度"二字；极度前倾前屈以及它的反面后倾后屈都会造成不孕症

### 外形与分部

* **子宫的四部分**
    * 底、体、峡、颈四部分，峡夹在体与颈之间
    * 子宫底：向上比较圆凸的部分
    * 子宫体：底与颈之间的部分，约占上 2/3
    * 子宫颈：下 1/3，比较圆钝的部分
    * 子宫峡：体与颈之间移行的一小段，不足 1 厘米

    ```text
            上端较圆凸 —— 子宫底
                ┌────────┐
                │ 子 宫 体│     上 2/3
                ├────────┤
                │ 子 宫 峡│     不足 1 cm，妊娠时可抻长到 7~11 cm
                ├────────┤
                │ 子 宫 颈│     下 1/3，底端比较圆钝
                └────┬───┘
        ═════════════╧══════   阴道：只环绕宫颈的下段
               阴道上段 │ 阴道部
                   阴道口
    ```

* **宫颈的细分**
    * 阴道只环绕宫颈的下段，上段未被阴道环绕
    * 被环绕的部分称阴道部，上部称阴道上段
    * 阴道本身是扁平管道，下端有处女膜，内壁有大量皱襞

* **子宫峡的伸缩性**
    * 非妊娠时不足 1 厘米
    * 妊娠时可抻长到 7~11 厘米
    * 这一伸缩性是子宫破裂机制的形态伏笔

### 固定的装置

* **四个方向与四个韧带**
    * 前倾靠子宫圆韧带
    * 前屈靠子宫骶骨韧带
    * 左右移位靠子宫阔韧带
    * 向下沉靠子宫主韧带

| 固定装置 | 比喻中落下的位置 | 作用 |
| :--- | :--- | :--- |
| 子宫阔韧带 | 上肢下方悬吊的那双层腹膜皱襞 | 防止子宫左右移位 |
| 子宫主韧带 | 桶底固定的那块宽板子，即阔韧带的基底部 | 防止子宫向下沉 |
| 子宫圆韧带 | 两条小腿形成的两个皱襞 | 保持子宫前倾 |
| 子宫骶骨韧带 | 阔韧带后方的两个皱襞 | 保持前屈角，即保持前屈 |

* **子宫阔韧带**
    * 上肢下方悬吊的双层腹膜皱襞即子宫阔韧带
    * 边缘不是断端，与盆侧壁的腹膜相延续
    * 两片膜把子宫横向夹住，防止左右移位

* **子宫主韧带**
    * 即阔韧带的基底部，防止子宫下沉
    * 主韧带一旦松弛就容易造成子宫脱垂

* **子宫圆韧带**
    * 由两条小腿形成的皱襞构成，一直通到大阴唇
    * 作用是保持子宫的前倾状态

* **子宫骶骨韧带**
    * 由阔韧带后方的两根绳形成的皱襞构成
    * 作用是保持前屈角，即保持子宫前屈

## 宫外孕

* **受孕的过程**
    * 大量精子进入阴道，游动到子宫内，再奔向输卵管
    * 卵巢释放的卵细胞经漏斗部被接收进输卵管
    * 在输卵管内与精子相遇变成受精卵
    * 正常情况下受精卵逐渐向里移动，到子宫内膜着床发育

* **宫外孕的发生**
    * 峡部狭窄，或既往输卵管结核造成峡部粘连狭窄，使受精卵进不了子宫
    * 受精卵滞留在宽大的壶腹部开始发育，即宫外孕

* **宫外孕大出血的机制**
    * 血管由子宫动脉供应，子宫动脉很粗，沿边缘营养输卵管，另有分支营养子宫，再往下营养阴道
    * 壶腹部不断发育肥大，管腔扩大
    * 迂曲血管先被拉直，继而由直变紧，最后断裂
    * 受精卵在壶腹部发育把周围迂曲的子宫动脉分支拉断，造成大出血

* **结论**
    * 宫外孕＝受精卵在峡部受阻 → 滞留壶腹部 → 壶腹膨大撑开迂曲血管 → 血管被拉直、拉紧、断裂 → 大出血

## 子宫破裂

* **薄弱点的来源**
    * 子宫峡本来只有 1 个厘米，妊娠时可变长到 7~11 个厘米
    * 比喻如底部捂住的气球，吹气时两个侧壁越来越薄，这两个侧壁在解剖上就是子宫峡

* **破裂的进程**
    * 宫口开大、阴道扩张，但产妇骨盆下口特别狭窄，孩子出不来
    * 子宫是体内最发达的一个平滑肌构成的器官，宫底仍在强烈收缩
    * 峡部越抻越薄，从 1 厘米抻到 7~11 厘米，孩子仍出不来，宫底继续收缩就继续向外拉

* **大出血的机制**
    * 子宫动脉迂曲向内形成升支、降支
    * 峡部不断拉长，子宫动脉被迫变直再变紧，机制与宫外孕一步相同
    * 子宫动脉很粗，一旦断裂即造成大出血

* **腹部体征与处理**
    * 腹部呈葫芦状，中间形成一道深沟，胎儿的头部和躯干轮廓显现，称为病理收缩环
    * > **提示**：出现病理收缩环立即剖腹产，否则接下来就是子宫破裂
