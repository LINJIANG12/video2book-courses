# 前庭蜗器：外耳、中耳与内耳

## 前庭蜗器的命名与分部

* **前庭蜗器（位听器）**

    * > **定义**：管理头部位置觉与听觉的感官器，按组成神经命名——由前庭神经与蜗神经两种神经共同组成。

    * 按功能命名的旧称是**位听器**，位指位置觉、听指听觉；按神经命名的现称是**前庭蜗器**。

    * 两个名字指的是同一个结构，不是两套器官。

    * 组成上分三大块：**外耳**、**中耳**、**内耳**。

    * 三块中以**中耳**的解剖为重；外耳只需认名称和特点，内耳只需记位置。

---

## 外耳

### 耳廓的部位名称

* **耳廓**

    * > **定义**：外耳最外周的软骨性结构，只记各部位名称，不讲原理。

    * 最外周卷曲的边叫**耳轮**，它内侧的隆起叫**对耳轮**。

    * 更靠内的凹陷与隆起依次是**三角窝**、**耳舟**、**耳甲艇**。

    * 前方的开口叫**外耳门**，是外耳道的内端。

    * 外耳门旁那块隆起叫**耳屏**，与它相对的那个叫**对耳屏**。

    * 最下面的一块叫**耳垂**。

    * > **易错点**：名称多是成对的——耳轮与对耳轮、耳屏与对耳屏。带"对"字的那个位置比不带"对"的更靠内、靠后，两组不可混记。

### 外耳道

* **外耳道**

    * > **定义**：外耳门与鼓膜之间的弯曲管道，长约 2.5 cm。

    * 外侧 $1/3$ 由软骨作支架，称**软骨部**。

    * 内侧 $2/3$ 由骨质作支架，称**骨性部**。

    * > **结论**：管道要变直，只能调软骨部，**骨性部是不变的**。

    * 成人向后上牵拉耳廓，整个管道即可变直。

    * 小儿方向相反，**向后下**牵拉耳廓，外耳道才变直。

    * > **易错点**：成人"向后上"、小儿"向后下"，方向不能记反。

    * 皮肤特点一：外耳道皮肤与软骨以及骨（骨膜）结合得非常紧密，不容易分离。

    * 皮肤特点二：皮肤内有毛囊、皮脂腺，以及别的皮肤上不具备的**耵聍腺**。

    * 皮肤特点三：有**丰富的神经末梢**。

    * 正因为神经末梢丰富，外耳道一旦长疖肿就非常疼。

    * 必须先把外耳道调整到直的状态，才能往里观察鼓膜的变化。

### 鼓膜

* **鼓膜**

    * > **定义**：外耳道尽端的那层膜，膜本身分为面积很小、很松的松弛部和占绝大部分、非常紧张的紧张部。

    * **锤纹**：鼓膜上一条斜行的隆起。

    * **鼓膜脐**：锤纹的末端，即鼓膜相当于中点的位置。

    * **光锥**：鼓膜脐前下方的三角形反光区。

    * **松弛部**：锤骨后皱襞和锤骨前皱襞以上的那块鼓膜，面积很小、鼓膜很松。

    * **紧张部**：松弛部以下、直到下缘的那块鼓膜，占鼓膜绝大部分、鼓膜非常紧张。

    * 鼓膜穿孔发生在**紧张部**。

    * > **易错点**：松弛的纸一碰就破，绷紧的纸更耐震，所以破洞出在最绷的紧张部，而不是松弛部。

    * 读图顺序：两条皱襞以上是松弛部；中间是锤纹末端形成的鼓膜脐；从鼓膜脐往前下方展开的三角形反光区是光锥；光锥以下直到下缘是紧张部。

    ```text
                    锤 骨
                      │
      ┌───────────────┴────────────────┐
      │ 锤骨后皱襞 · 锤骨前皱襞       │
      │           松  弛  部           │
      │                │              │
      │           鼓  膜  脐           │
      │                │              │
      │             光  锥              │
      │                               │
      │           紧  张  部           │
      └───────────────────────────────┘
    ```

## 中耳

### 中耳的三部分

* **中耳**

    * 分三部分：**鼓室**、**咽鼓管**、**乳突小房**。

    * 重点是鼓室的解剖，另外两部分知道名称和位置即可。

* **咽鼓管**

    * > **定义**：中耳通到鼻咽部的管道，咽口起自鼻咽部。

    * 鼓室前壁下方经咽鼓管与鼻咽部**相通**。

* **乳突小房**

    * > **定义**：乳突内彼此相互通连的含气小腔，位于鼓室后方。

    * 鼓室后壁经鼓窦与乳突小房相通。

### 鼓室的位置与毗邻

* **鼓室**

    * > **定义**：位于颞骨岩部内含气的小腔，具体指正对鼓室盖下方的那一个腔隙。

    * **颞骨岩部**是三棱锥状的骨，最上部正是颅中窝与颅后窝的分界，上方为颅中窝、下面为颅后窝，鼓室包在这块锥状骨内部。

    * **鼓室盖**是颞骨岩部上一块很薄的骨板，把骨板捅开，骨板里的腔隙就是鼓室。

    * 从上往下看的剖面次序：外耳道 → 鼓膜 → 鼓室 → 鼓窦 → 乳突小房；向前是咽鼓管。

    * 鼓室腔隙四周骨质内点状分布的是**骨松质的网眼**。

    * **鼓窦**是鼓室再往后的小腔，是鼓室与乳突小房之间的中间腔隙。

    * 鼓室内侧有一个非常小的结构**内耳**，要放大才看得清；内耳再往内侧是骨性管道**内耳道**，即内耳门通出来的那一条。

    * 鼓室内另有一块肌肉叫**鼓膜张肌**，在鼓室剖面挂图上通常看不到。

    ```text
                         颅  前  窝
                  鸡冠 · 筛板与筛孔 · 两侧骨板
       ──────────────────────────────────────
                         颅  中  窝
      蝶骨小翼 · 视神经管 · 交叉沟 · 鞍背 · 垂体窝
      眶上裂 · 圆孔 · 卵圆孔 · 棘孔
                      ┌──────────────┐
                      │   颞 骨 岩   │  最高处：中窝与后窝的分界
                      │              │
                      │ 鼓室盖(上壁)│ ──▶ 上方为颅中窝
                      │   鼓  室     │ ──▶ 前：咽鼓管  后：乳突小房  内：内耳道
                      └──────────────┘
       ──────────────────────────────────────
                         颅  后  窝
      乙状窦沟 · 横窦沟 · 内耳门 · 枕大孔 · 舌下神经管
    ```

### 鼓室的六壁

* **鼓室六壁**

    * > **定义**：鼓室共六个壁，每个壁的名称都按它旁边那个"邻居"结构取名——把邻居认全，六壁的名字自然就记住了。

    * **上壁**叫鼓室盖，正上方就是颅中窝，骨板很薄。

    * **下壁**叫颈静脉壁，下方正好是颈内静脉。

    * **前壁**叫颈动脉壁，前方是颈内动脉；上方有鼓膜张肌，下方经咽鼓管与鼻咽部相通。

    * **后壁**叫乳突壁，整个开口通向乳突内腔，经鼓窦与乳突小房相通。

    * **外侧壁**就是鼓膜，隔着这层膜看到鼓室。

    * **内侧壁**叫迷路壁，因为内耳又叫**迷路**，它与内耳相邻。

    * 颈内动脉与颈内静脉就在前壁、下壁外侧，手术时操作过于粗糙会把动脉、静脉搞破出血，而且不容易止住。

### 鼓室内侧壁的结构

* **面神经管凸**

    * 鼓室内侧壁上的一个凸起，里面走的就是面神经。

    * > **定义**：面神经从一个骨性管里钻出来，这根骨性管叫**面神经管**，下行的面神经即出自此处。

    * > **结论**：鼓室六壁中，内侧壁最需记住的就是这个面神经管凸。

* **前庭窗与蜗窗**

    * 内侧壁上并排的两个孔，一个椭圆形、一个圆形。

    * **前庭窗**被三个听小骨中的**镫骨**封闭。

    * **蜗窗**被一层膜封闭，这层膜叫**第二鼓膜**。

* **骨岬**

    * 鼓室内侧壁上的一个隆起。

### 中耳炎蔓延的四个方向

* > **结论**：炎症从上呼吸道感染来，通过咽鼓管到鼓室，然后往四个方向走，这四个并发症与鼓室的解剖毗邻关系直接相关。

    | 蔓延方向 | 后果 | 解剖依据 |
    | :--- | :--- | :--- |
    | 向上 | 颅内感染 | 破坏鼓室盖进入颅腔，骨板很薄，上方就是颅中窝 |
    | 向后 | 乳突炎 | 后壁经鼓窦与乳突小房相通 |
    | 向外 | 鼓膜穿孔 | 外侧壁就是鼓膜 |
    | 向内 | 面瘫 | 腐蚀内侧壁的面神经管凸，伤及面神经 |

* > **注意**：鼓膜一旦穿孔，疼痛会立即减轻，但病并没有好。家属看到不疼了以为病已痊愈，实际上鼓膜已经穿孔了。

## 内耳

### 骨迷路

* **内耳**

    * > **定义**：包括骨性部分和膜性部分两大块。

    * 骨性部分即骨迷路，膜性部分即膜迷路。

    * 两部分的关系如同自行车的外带与内带：外带是骨性部，内带是膜性部。

* **骨迷路**

    * > **定义**：内耳的骨性部分，由三部分构成。

    * **耳蜗**：像蜗牛壳一样的结构。

    * **前庭**：位于中间、膨大的部分。

    * **骨性半规管**：外半规管、前半规管、后半规管三个管道，合称骨性半规管。

### 膜迷路

* **膜迷路**

    * > **定义**：套在骨迷路内部的那一层膜性结构。

    * 耳蜗里边套的是膜性的**蜗管**。

    * 前庭里边套了两个囊：**球囊**和**椭圆囊**。

    * 每条半规管基底部膨大的部位里边套一个膜性的**壶腹嵴**。

    * 膜迷路内部自己还是连通的：蜗管盘曲 2 圈半，通过一个细管和球囊相连，球囊又通过细管和椭圆囊相连，椭圆囊再和每个膜半规管根部那个膨大的腔相连，然后延续到管道里面去。

    ```text
    蜗管 ──细管──▶ 球囊 ──细管──▶ 椭圆囊 ──▶ 膜半规管根部膨大腔 ──▶ 管内
    ```

* **骨迷路与膜迷路的套合**

    | 骨迷路 | 膜迷路（套在其内） |
    | :--- | :--- |
    | 耳蜗（蜗牛壳状） | 蜗管（盘曲 2 圈半） |
    | 前庭（中间膨大） | 球囊 ＋ 椭圆囊 |
    | 骨性半规管 ×3（外 · 前 · 后） | 膜半规管 ×3，壶腹嵴在基底部膨大处 |

### 感受器的分布

* **螺旋器**

    * > **定义**：位于蜗管里的听觉感受器，感受听觉。

* **球囊与椭圆囊**

    * 位置觉的感受器所在处。

    * 感受静止状态下的头部位置觉。

    * 感受匀速的直线运动。

* **壶腹嵴**

    * 位于半规管基底部膨大处的位置觉感受器。

    * 感受旋转运动。

* **位置觉感受器对照**

    | 头部的情况 | 位置觉感受器所在 |
    | :--- | :--- |
    | 静止时的头部位置觉 | 球囊、椭圆囊 |
    | 匀速的直线运动 | 球囊、椭圆囊 |
    | 旋转运动 | 壶腹嵴（位于半规管基底部膨大处） |
