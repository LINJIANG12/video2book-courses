# 周围神经系统·脊神经：构成、纤维成分与各神经丛

## 脊神经的三个考察面

* 组成：根丝汇成前根、后根，前根与后根再合成脊神经。

    * 分支：脊神经出椎管以后分成四路。

    * 纤维成分：前根纯运动，后根纯感觉。

* 同一条神经拆开来是两半——一半管运动，一半管感觉，混在一根管子里往前走。

    * 损伤诊断的时候，恰恰要把这两半分开来算。

## 脊神经的组成

* **脊髓（spinal cord）的表面标志**

    * 形态是前后略扁的圆柱状，表面有 6 条纵行的沟。

    * 中间隔着中央管的是一片蝴蝶状的灰质，中央管居中。

    * 按左右对称去数：前正中裂 1 条、前外侧沟 2 条、后外侧沟 2 条、后正中沟 1 条，正好 6 条。

* **根丝与神经根（nerve root）**

    * > **定义**：沟里出来的那一束一束叫根丝，好多根丝捋成一股叫神经根。

    * 前根、后根是神经根这一级，不是根丝那一级。

    * 前外侧沟发出的根丝构成前根（运动），后外侧沟发出的根丝构成后根（感觉）。

* **脊神经（spinal nerve）**

    * > **定义**：前根与后根在椎间孔处汇合而成的混合性神经。

    * 汇合地点就在椎间孔，左右对称，两侧各成一条。

* **脊神经节（spinal ganglion）**

    * 后根上鼓起来的膨大，称脊神经节。

    * 它位于后根上，在前后两根汇合成脊神经之前。

## 脊神经的分支

### 分支方位与总览

* **椎管水平切面的方位**

    * 椎体在后，横突和椎板再往后，棘突是向后最突出来的骨性标志。

    * 棘突围出来的就是椎管，椎管里是被三层脊膜包着的脊髓。

* **四路分支**

    * 脊神经在椎间孔这个水平面上分成四路：脊膜支、交通支、后支、前支。

    * 四支的粗细与走向各不相同。

    ```text
                              脊神经
                                │
       ┌──────────┬─────────────┼─────────────┬──────────┐
       │          │             │             │          │
      脊膜支     交通支          后支           前支
      细小       白＋灰          细小           粗大
      折返椎管内 灰↔交感干      直接向后、      向前走
      骨膜·脊膜   往返联络       节段性         只有胸神经
    ·间盘·血管壁               项背腰底       节段性，
                               一条窄条、     其余全部
                               左右对称       交织成神经丛
                                                 │
                                      ┌──────────┴──────────┐
                                    颈丛                臂丛 ……
    ```

### 脊膜支

* **走向**

    * 这是最细的那一支，从脊神经发出以后又折返回椎管内。

    * 它从椎间孔折返入椎管。

* **分布**

    * 它回去找的对象是椎管内壁的骨膜、椎间盘、脊膜，还有椎管里的血管壁。

    * > **易错点**：这是唯一"发出去又回来"的分支，名字里的"脊膜"就是它回去要去的地方。

### 交通支

* **白交通支**

    * 方向是脊神经 → 交感干，属于往外送的一支。

    * 纤维性质是有髓纤维，因颜色发白而得名。

* **灰交通支**

    * 方向是交感干 → 脊神经，属于往回收的一支。

    * 纤维性质以无髓纤维为主，因颜色发灰而得名。

* **成对与双向**

    * 交通支是成对的两个，一个白的一个灰的，看名字就知道方向不一样。

    * 一对合起来是双向的：白的是"往外送"的，灰的是"往回收"的。

### 后支

* **形态与节段性**

    * 后支的特点是细小、节段：它比较细，直接向后走。

    * 出椎间孔以后不参加任何交织，一根管一段，这叫节段性配布。

* **皮肤分布**

    * 后支在皮肤上的分布正好是一条纵行的窄条，从上到下为项、背、腰、底，左右对称。

    * 节段性是理解全身神经分布的钥匙：躯干表面的感觉是分节的，一个节段一根管，互不搅和。

    * 头颈和四肢不一样——头颈自己抱团成丛，四肢是上下乱绞的，所以四肢的神经丛才那么复杂。

### 前支

* **形态与方向**

    * 前支跟后支正好是一对反义词：它粗大，方向是向前走的。

* **配布规律**

    * > **结论**：前支除了胸神经成节段性配布以外，都交织成神经丛。

    * 胸神经是一根管一个节段、老老实实往下走；除此之外的所有前支全都绞到一块儿去了。

    * 绞出来的丛就是颈丛、臂丛。

## 脊神经的纤维成分

* **混合性神经**

    * 脊神经是混合性神经，成分既有运动又有感觉。

    * 感觉和运动这两类各自还要再分躯体和内脏两路。

    | 根 | 性质 | 含有的纤维成分 |
    | :--- | :--- | :--- |
    | **前根** | 完全是运动性 | 躯体运动 ＋ 内脏运动 |
    | **后根** | 完全是感觉性 | 躯体感觉 ＋ 内脏感觉 |

* **根的纯度与临床推断**

    * 脊神经虽是混合的，但往前根、后根里各切一刀，前根干净得一点感觉纤维都没有，后根干净得一点运动纤维都没有。

    * 前根损伤 → 只出现运动障碍，感觉照常往里传。

    * 后根损伤 → 只出现感觉障碍，运动正常。

    * > **易错点**：问"某某部位损伤会出现什么表现"，先判断伤的是根还是干、是前根还是后根。伤前根只瘫不麻，伤后根只麻不瘫——感觉和运动永远是分开的两笔账。

## 颈丛

### 组成与位置

* **组成**

    * 颈丛由颈 1～颈 4 节段的前支交织而成。

* **位置**

    * 颈丛的位置特别好记：在胸锁乳突肌的深面。

    ```text
       胸锁乳突肌
       ┌──────────────┐
       │              │──→ 后缘中点：枕小、耳大、颈横、锁骨上
       │              │    4 支皮支全部在此浅出
       │              │──→ 深面：颈丛
       └──────┬───────┘
              │  前缘中点：颈总动脉（摸得到搏动，可压迫止血）
           颈总动脉
    ```

### 皮支

* **四支皮支的出口**

    * 颈丛的分支主要是皮支，还有一支混合支。

    * 4 个名字：枕小神经、耳大神经、颈横神经、锁骨上神经。

    * 统一特点：全部在胸锁乳突肌后缘中点浅出。

* **与颈总动脉的位置对照**

    * 胸锁乳突肌前缘中点能摸到颈总动脉的搏动，那里还能压迫止血。

    * 这么一对比就出来了：后缘全是神经出来的地方，前缘是动脉的。

* **临床用途**

    * 这几支皮支集中在后缘中点一个点上，所以做颈部的阻滞麻醉时非常方便。

    * 比如做甲状腺手术，在这个部位把组织的传导阻断掉（阻断颈横神经的传导），手术就可以进行。

### 膈神经

* **地位**

    * 膈神经是颈丛唯一的混合性分支，不是纯感觉也不是纯运动。

* **纤维成分**

    * 运动纤维：管理膈肌的运动。

    * 感觉纤维：管理胸膜、心包的感觉，还管膈肌下方的腹膜。

* **左右差异**

    * 膈神经左右对称，分左支和右支。

    * 右支还额外发出一些纤维，去管理肝脏、胆囊以及肝外的输胆管道这些部位的浆膜。

## 臂丛

### 组成与范围

* **组成**

    * 臂丛由颈 5～胸 1 节段的前支交织而成。

* **范围与形态**

    * 臂丛的范围特别大：从斜角肌间隙一直到腋窝区，整段都叫臂丛。

    * 各节前支从椎间孔出来以后反复地交叉，而且缠绕着这些动静脉，一路绞到腋窝。

    * 所以臂丛不是一根整齐的束，而是一大团反复交织、缠着血管走的网，丛内再发出单根的神经。

    ```text
       颈5 ～ 胸1  各节前支
            │  反复交叉，并缠绕伴行的动静脉
            ▼
       斜角肌间隙 ═════════════════════► 腋窝
            └────── 整段范围都叫臂丛 ──────┘
            │
            ▼  丛内再发出单根的神经
       腋神经 · 肌皮神经 · 正中神经 · 尺神经 · 桡神经
    ```

### 腋神经

* **出口：四边孔**

    * > **定义**：肩胛骨、肱三头肌长头、大圆肌三者凑在一起，在肩胛冈下方围出两个孔，一个三边孔，一个四边孔。

    * 腋神经就从四边孔里出来。

* **分支**

    * 肌支：管理三角肌和小圆肌。

    * 皮支：名叫臂外侧上皮神经，管理臂上方偏外这一片区域（肩部）的皮肤感觉。

### 肌皮神经

* **走行**

    * 肌皮神经从臂丛下来，先穿透喙肱肌。

    * 然后走在肱二头肌和肱肌之间，再奔前臂的外侧去。

* **分支**

    * 肌支：到喙肱肌、肱二头肌、肱肌，营养这几个肌肉。

    * 皮支：只有一个，叫前臂外侧皮神经，是纯感觉支，到前臂的皮肤去。

    * 臂的肌肉由肌皮神经管，这解释了正中神经为什么在臂部一个分支都不发。

### 正中神经

* **来源与走行**

    * > **定义**：正中神经是臂丛内、外两束合成的。

    * 走行是一条非常清楚的路线：臂部、肘窝、前臂、腕部、手部。

    ```text
      臂部：走在肱二头肌的内侧（整个臂部主干不发分支）
            │
      肘窝：经肘窝前方，在肌肉的深面
            │
      前臂：正中下行
            ├─ 关节支 → 肘关节、腕骨间关节
            ├─ 肌支   → 前臂大部分屈肌
            └─ 皮支   → 掌皮支
            │
      腕部：穿过腕管
            │
      手部：到各指发分支
            ├─ 返支（鱼际肌支）→ 大鱼际
            └─ 皮支 → 掌桡侧 3 个半指
    ```

* **分支清单**

    * 关节支：到肘关节，还有到腕骨间关节的。

    * 肌支：管前臂的大部分屈肌。

    * 肌支的排除项：尺侧腕屈肌和指深屈肌的尺侧半这"一个半"它不管，归尺神经。

    * 手部肌支：大鱼际一共 4 块肌肉，它管 3 块，除外拇收肌；另外还管第 1、2 蚓状肌。

    * 返支：也叫鱼际肌支，单独发一条回到大鱼际。

    * 掌皮支：发到手掌皮肤。

* **皮支范围与敏感区**

    * 一句话记住：手掌桡侧半、掌桡侧三个半指，归正中神经管。

    * > **结论**：正中神经最敏感的区域在大鱼际表面的皮肤，临床上要检查它的感觉区就查大鱼际表面。

    * > **提示**：正中神经的肌支在臂部一个分支都不发，因为臂部肌肉已经被肌皮神经管了；到前臂才开始发分支——这个"到前臂才分叉"是它跟尺神经、桡神经最大的不同。

    ```text
                   手掌（掌侧面）
       ┌────────────────────────────────┐
       │  桡侧                中立  尺侧 │
       │  正中神经            线   尺神经 │
       │  手掌桡侧半               手掌尺侧│
       │  掌桡侧三个半指            掌尺侧│
       │                                │  一个半指
       └────────────────────────────────┘
        最敏感：大鱼际表面的皮肤   最敏感：小鱼际的外缘
    ```

### 尺神经

* **定位标志**

    * 肱骨下端两侧的凸起分别是内上髁和外上髁。

    * 内上髁的后方有一个骨性的凹沟，叫尺神经沟。

* **走行**

    ```text
      臂部：下行，此段无分支
            │
            ▼  穿过内上髁后方的尺神经沟
            │
      前臂：沿前臂尺侧缘下降
            │
      腕部：走在腕管的前面（不进腕管）
            │
      手掌：发分支到各指
            ├─ 浅支 → 各指（浅）
            ├─ 深支 → 骨间肌等
            ├─ 掌皮支
            ├─ 手背支 → 转向手背，管指背尺侧两个半指
            └─ 关节支 → 肘关节、腕关节
    ```

* **分支清单**

    * 关节支：到肘关节、腕关节。

    * 肌支：尺侧腕屈肌和指深屈肌的尺侧半这"一个半"，然后到小鱼际。

    * 肌支的手部部分：拇收肌（正中神经排除的那块）、第 3、4 蚓状肌、骨间肌、第一骨间背侧肌。

    * 皮支：手掌尺侧、手背尺侧，即掌尺侧一个半指、背尺侧两个半指，手掌手背都管。

* **敏感区与手部分工**

    * > **结论**：尺神经最敏感的部位在小鱼际的外缘。

    * > **易错点**：尺神经和正中神经在手部是"一个半"对"三个半"的关系——记住尺神经手掌一个半、手背两个半，因为手背侧的皮肤一半的面积归它。

    * 手部的肌肉里，尺神经管的块数比正中神经还多。

### 桡神经

* **走行与分叉**

    * 桡神经从丛里出来以后，先通过桡神经沟（肱骨后面）。

    * 然后到外上髁的外侧，在这里分成浅支和深支。

* **三条线**

    | 分支 | 内容 |
    | :--- | :--- |
    | **关节支** | 肘关节、腕关节、桡尺近侧关节、掌指关节、指间关节——关节特别多 |
    | **肌支** | 整个上肢的伸肌群，无论臂部还是前臂，全归桡神经管 |
    | **皮支** | 手背桡侧半、指背桡侧两个半指 |

* **浅支与深支**

    * 浅支往下走，到手背。

    * 浅支发出的关节支特别多，一路管下去。

    * 深支发出很多很多肌支。

* **皮支名称与分工结论**

    * 皮支是前臂外侧皮神经、臂后皮神经、臂外侧下皮神经。

    * > **结论**：桡神经的肌支是上肢伸肌群的总管，前臂能伸、能旋后靠的就是它，正好和正中神经管前臂大部分屈肌对上。

    * 手背桡侧两个半指归桡神经，尺侧两个半指归尺神经。

    * 手背上不存在中立线，从中间往尺侧直接交给尺神经。

## 正中、尺、桡三神经并排对比

* **对照表**

    | | **正中神经** | **尺神经** | **桡神经** |
    | :--- | :--- | :--- | :--- |
    | **定位标志** | 肘窝前方、穿腕管入掌 | 内上髁后方的尺神经沟，腕管**前**面入掌 | 桡神经沟 → 外上髁外侧，分浅、深两支 |
    | **关节支** | 肘关节、腕骨间关节 | 肘关节、腕关节 | 肘、腕、桡尺近侧、掌指、指间关节 |
    | **肌支** | 前臂大部分屈肌（**尺侧腕屈肌、指深屈肌尺侧半除外**）；大鱼际 4 块管 3 块（除拇收肌）、第 1、2 蚓状肌 | **尺侧腕屈肌、指深屈肌尺侧半**；小鱼际、**拇收肌**、第 3、4 蚓状肌、骨间肌、第一骨间背侧肌 | **整个上肢的伸肌群**（臂部＋前臂） |
    | **皮支** | 手掌桡侧半、掌桡侧三个半指 | 手掌尺侧、手背尺侧；掌尺侧一个半指、背尺侧两个半指 | 手背桡侧半、指背桡侧两个半指 |
    | **最敏感区** | **大鱼际表面皮肤** | **小鱼际外缘** | 长文未说明 |

* **分工格局**

    * 一个"一分为二"的画面：前臂的屈肌归正中，伸肌归桡；手和前臂尺侧那"一个半"的肌肉归尺。

    * 三套神经分工明确，几乎不重叠。

    * 一旦有一条出了问题，临床表现就非常干净，这正是临床上做定位诊断最方便的地方。

## 胸神经前支的节段性配布

* **胸神经前支**

    * 分布特点很干脆：**呈节段性**。

    * > **定义**：节段性配布——某一个节段管某一个带状区，一个节段管一个区。

    * 记忆线索是几个体表标志：锁骨、胸肌、剑突、脐、腹股沟韧带。

* **体表平面与胸神经节段的对应**

| 体表平面 | 相当于 |
| :--- | :--- |
| 胸骨角平面 | 胸 2 |
| 乳头平面 | 胸 4 |
| 剑突平面 | 胸 6 |
| 肋弓最低点 | 胸 8 |
| 脐平面 | 胸 10 |
| 脐与耻骨联合中点 | 胸 12 |

```text
        锁骨 ─────────────────────── 以上已经是颈神经的地盘
          │
    胸 2  │  胸骨角平面
    胸 4  │  乳头平面
    胸 6  │  剑突平面
    胸 8  │  肋弓最低点
    胸 10 │  脐平面
    胸 12 │  脐 — 耻骨联合中点
          ▼
    再往下就是腰丛的地盘了
```

* **下界与临床用途**

    * 胸神经的下界到**胸 12** 截止。
    * 脐水平是胸 10，肋弓最低点是胸 8，剑突水平是胸 6，乳头是胸 4，胸骨角是胸 2。
    * 临床用途：出现**一个带状区的感觉障碍**，据此确定是哪个节段损伤。

## 腰丛

* **腰丛（lumbar plexus）**

    * 由**胸 12 到腰 4 节段的前支**汇集而成。
    * 位置在**腰大肌的深面**——只有把腰大肌拿掉才看得见。
    * 椎间孔出来的这些神经相互交叉后再分支，交织出来的结构即腰丛。

* **髂腰肌**

    * 腰大肌与髂肌合称**髂腰肌**。
    * 腰大肌：最大的一块，从上往下、通过**腹股沟韧带深面**、止于**小转子**。
    * 髂肌：位于髂窝内。
    * 腰丛在这块肌肉的**深面**。

* **必须先认出来的结构**

    * 骨性标志：髂前上棘、髂结节、髂嵴、骶前孔、髂前下棘、骨盆的**闭孔**，以及股骨上端的**大转子、小转子**。
    * 图中白色条带是**腹股沟韧带**，其上开着一条**腹股沟管**。

* **外侧缘三支的上下次序**

    * **髂腹下神经**：外侧缘出来的**最高位**一支，一直穿出到皮下，管下腹壁皮肤感觉，沿途发肌支，最后到皮肤。
    * **髂腹股沟神经**：略低一点，在髂嵴上方走，转向前**进入腹股沟管**，管腹股沟区皮肤感觉，沿途也有肌支。
    * 脐—耻骨联合中点以上是胸神经的地盘，往下髂腹下神经从皮下钻出来接管**下腹壁**皮肤感觉，正好与胸 12 接上。
    * 三根都从腰大肌外侧缘出来，出去以后落脚点一个比一个低，节段管一区的规律在这里同样成立。

* **越过腹股沟韧带中点的两条神经**

| 神经 | 位置与走行 | 管到哪儿 |
| :--- | :--- | :--- |
| **股外侧皮神经** | 外侧缘发出，经**髂前上棘内侧**，**越过腹股沟韧带中点** | 只管大腿外侧皮肤感觉 |
| **股神经** | 外侧缘发出的、**最粗大**的一根，越过腹股沟韧带中点到大腿 | 皮支、肌支都重，肌支管大腿前面整块肌肉 |

    * > **易错点**：⚠️ 股外侧皮神经和股神经都越过腹股沟韧带中点，但一根只管皮肤、一根把大腿前面整块肌肉连同皮肤一起管住；只记「都过中点」必然混淆，要连落脚点一起记。

* **生殖股神经（genitofemoral nerve）**

    * 从**腰大肌前方**发出，一支进腹股沟管、一支到大腿。
    * 管**股三角**皮肤感觉；入管的一支支配**提睾肌**。

* **闭孔神经（obturator nerve）**

    * **唯一**从腰大肌**内侧缘**出来的一根神经。
    * 经**闭孔**穿出。
    * 支配**大腿内收肌群**，并管大腿内侧皮肤感觉。

## 骶尾丛

* **骶尾丛（sacral and coccygeal plexus）**

    * 由**腰 4 一直到尾 1 节段的前支**交织而成。
    * 骨性标志：髂后上棘、髂骨、髂前上棘、髂前下棘、髋臼、坐骨结节、坐骨**大切迹、小切迹**。
    * **骶结节韧带**：从骶骨到坐骨结节。
    * **骶棘韧带**：从骶骨到坐骨棘，位于骶结节韧带的深面。

### 梨状肌把坐骨大孔一分为二

* **梨状肌（piriformis）**

    * 三角形的肌肉，自坐骨大孔上部穿出。
    * 把坐骨大孔分成**上孔**与**下孔**：**上孔出来一根，下孔出来四根**。

```text
        骶骨
         ├──── 骶棘韧带 ────→ 坐骨棘
         ├──── 骶结节韧带 ──→ 坐骨结节
         │
    ┌────┴──────── 坐骨大孔 ────────┐
    │         ▓ 梨 状 肌 ▓          │  梨状肌自大孔穿出，把大孔一分为二
    └────────┬───────────────┬──────┘
          上孔 │               │ 下孔
              ▼               ▼
          臀上神经        臀下神经 · 阴部神经
                          股后皮神经 · 坐骨神经
```

* **上孔的一根：臀上神经**

    * 到**臀中肌、臀小肌**，另有一支到**阔筋膜张肌**。

* **下孔出来的四根**

    * **臀下神经**：由下孔出来，主要到**臀大肌**。
    * **阴部神经**：由下孔出来，**绕过坐骨棘**，再从小孔进去，向前到**外生殖器**，再经会阴部到**肛门**。
    * **股后皮神经**：由下孔出来后向后进入大腿后部，主干一直延续到**腘窝**，途中分出去会阴部的分支；总的营养范围是**臀部、会阴部和大腿后部**这一片皮肤感觉，故名股后皮神经。
    * **坐骨神经**：同样从下孔出来，是**全身最粗大的神经**。

---

## 坐骨神经

* **沿途辨认的肌肉**

    * 臀部这块发达的**臀大肌**。
    * 臀大肌下方的**股二头肌长头和短头**。
    * 小腿处切开的**比目鱼肌**。
    * 足底的肌肉。

* **走行三环节**

```text
   梨状肌下孔出盆
        │
        │   ← 臀大肌深面下行
        ▼
   坐骨结节 ┿ 大转子        ← 压痛点
        │
        │   ← 大腿后群肌深面（股二头肌长头深面）
        ▼
   腘窝上缘 ┬─→ 胫神经
            └─→ 腓总神经
```

    * 第一环节：在**梨状肌下孔出盆**。
    * 第二环节：在**坐骨结节与大转子之间**入股部。
    * 这两个骨性标志之间是**压痛点**：在此压迫能引出下肢放射状疼痛，就是坐骨神经痛。
    * 第三环节：在**大腿后群肌的深面**（股二头肌长头深面）下降到**腘窝**，一直到**腘窝上缘**才开始分支。

* **主干上的分支**

    * 先发一个**关节支**到**髋关节**。
    * 沿途发出很多很多**肌支**到附近肌肉，所以主干一路走过去并不是光秃秃的一条。

* **分支共四类**

    * 坐骨神经的分支是 **4 类**：关节支、肌支，加上两个终支（**胫神经**、**腓总神经**）。
    * 关节支只有一个，去髋关节。
    * 肌支主要管**大腿后群肌**。

---

## 胫神经

* **胫神经（tibial nerve）**

    * 特点是**直**：在腘窝这一段沿**腘窝正中线**继续往下，走在**小腿后群肌的深面**一路向下，笔直无弯。

* **走行**

    * 从肌肉深面下降后，第二个环节是**绕过内踝后方到达足底**。
    * 到足底分成两支：**足底内侧神经**、**足底外侧神经**。

* **分支**

    * 关节支：起端发出到**膝关节**，沿途再发到**踝关节**。
    * 肌支：沿途很多，营养**小腿后群肌**；绕到内踝后方进入足底以后，还有肌支到**足底肌**。
    * 皮支：发出一个**腓肠神经**，管**小腿下后 1/3** 的皮肤感觉和**足底**的皮肤感觉，此外**小趾外缘**这一块也归它。

---

## 腓总神经

* **腓总神经（common fibular nerve）**

    * 是一个很短的**短干**。
    * 从坐骨神经主干**斜向前下**，正好经过**腓骨颈的外侧**，和骨面**紧密相贴**。
    * 位置**浅**，是下肢最容易受损伤的部位之一。

* > **易错点**：⚠️ 给下肢骨折病人打石膏时，腓总神经这一部位一定要加**厚厚的纱布垫**再把石膏糊上；石膏干了以后非常硬，如果三个月不拆又不加垫，就会把腓总神经压伤，等石膏打开人也已经残疾了。

### 腓总神经的两大支

```text
        坐骨神经主干
              │
              │  ↘ 斜向前下
              │     腓总神经（短干）—— 紧贴腓骨颈外侧骨面
              │        │
              │        ├──→ 腓深神经 → 小腿前群肌深面 → 足背
              │        └──→ 腓浅神经 → 小腿外侧群深面 → 小腿下 1/3 穿出皮下
              │                                                    → 足背、趾背
              ▼
           胫神经
```

* **腓深神经（deep fibular nerve）**

    * 在小腿**前群肌的深面**下降，下行到**足背**。
    * 肌支管**小腿前群肌**。
    * 皮支**没有临床意义**：只管**第一趾间隙**的皮肤，面积太小，临床上看不出什么。

* **腓浅神经（superficial fibular nerve）**

    * 走在小腿**外侧群肌的深面**，然后转向**足背、趾背**。
    * 分支主要是肌支，管**小腿外侧群**。
    * 皮支的意义大：管**足背**皮肤，以及**第 2 到第 5 趾**的趾背皮肤。
    * 另发出一个**腓肠外侧皮神经**。

    * > **提示**：两条神经对比着记很快——**腓深**在前群深面往下，管**肌肉**为主、皮肤只有第一趾间隙；**腓浅**在外侧群深面往外再往下，管**足背大片皮肤**为主。一个是肌肉神经，一个是感觉神经。

---

## 足部神经的配布

* **足底——胫神经的两大支**

| 神经 | 管辖范围 |
| :--- | :--- |
| 足底内侧神经 | 第 1、2、3 趾间隙，三个半 |
| 足底外侧神经 | 第 4、5 趾外侧，一个半 |

```text
足底 —— 胫神经的两大支
  ┌────────────────────────────────────────┐
  │ 足底内侧神经：第 1、2、3 趾间隙 → 三个半 │
  │ 足底外侧神经：第 4、5 趾外侧   → 一个半 │
  └────────────────────────────────────────┘

足背与足缘
  ┌────────────────────────────────────────┐
  │ 隐神经（股神经的末支）→ 足内侧缘        │
  │ 腓肠神经 → 跟内支、跟外支（足内支/足外侧支）│
  │ 腓浅神经 → 足背皮肤 + 第 2–5 趾背       │
  │ 腓深神经 → 第 1 趾间隙                  │
  └────────────────────────────────────────┘
```

* **足底为什么这样分**

    * 足底内侧神经管第一、第二、第三趾间隙，**三个半**；足底外侧神经只管**一个半**。
    * 两者的名称就是按各自管辖的趾数与范围来的。

* **足背与足缘的归属**

    * 最内侧是**隐神经的末支**，管**足内侧缘**。
    * 外侧还有**跟内支、跟外支**（足内支、足外侧支），这一块是**腓肠神经**发出分支管的范围。

* **隐神经在踝前的临床位置**

    * 隐神经是**股神经的分支**，一直伴着**大隐静脉**走到足内侧缘。
    * 做大隐静脉低位切开术抢救患者时，在**内踝前方作纵行切口**，切开以后就能看到大隐静脉和伴行的隐神经。
