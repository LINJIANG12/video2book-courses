# 中枢神经系统的被膜、脑脊液循环与脑血管

## 脑与脊髓三层被膜的对应

* **被膜**

    * > **定义**：脑和脊髓外面共同包裹的三层膜，由外向内排列。

    * 脊髓侧自外向内为硬脊膜、蛛网膜、软脊膜。

    * 脑侧自外向内为硬脑膜、蛛网膜、软脑膜；结构与脊髓一一对应，名称差别只在"脊"换"脑"。

    * 硬膜与蛛网膜几乎紧贴在一起，夹不出宽的腔隙。

    * 蛛网膜与软膜之间是蛛网膜下隙，腔内充满脑脊液。

---

## 硬脊膜

* **硬脊膜**

    * > **定义**：包裹脊髓最外层的膜，厚而坚硬，由致密结缔组织构成。

    * 上端附着于枕骨大孔周缘，与颅内的硬膜相延续。

    * 下端在第二骶椎水平开始包裹终丝，止于尾骨的骨膜。

    * > **易错点**：务必抓住"附着在枕骨大孔这个骨面的周缘"这一句——这一个"附着"直接决定了硬膜外隙与颅腔不通。

---

## 硬膜外隙

### 位置与内容物

* **硬膜外隙（硬膜外腔）**

    * > **定义**：硬脊膜与椎管内骨膜两者之间夹出来的间隙。

    * 内含三样结构：神经根、静脉丛、脂肪。

    * 脊髓发出的神经根都通过此间隙出椎间孔，所以其中积有大量脊神经根。

    * 第二个特点：略呈负压，穿刺时可据此判断针尖是否已到达硬膜外隙。

* **椎管层次与穿刺路径**

    * 自外向内：皮肤 → 棘上韧带 → 棘间韧带 → 黄韧带 → 椎管内骨膜 → 硬膜外隙 → 硬脊膜 → 蛛网膜 → 蛛网膜下隙。

    * 韧带位置：棘上韧带在棘突尖上方，棘间韧带在两棘突之间，黄韧带在两椎板之间、构成椎管后壁的最后一道。

    * 层次示意：

      ```text
      皮肤
        │
        ▼
      棘上韧带   ← 棘突尖上方
        │
      棘间韧带   ← 两棘突之间
        │
      黄韧带     ← 两椎板之间，椎管后壁最后一道
        │
        │       ← 穿过韧带，首次落空感＝已进入椎管
        ▼
      椎管内骨膜
        │
      硬膜外隙   ← 留 1 mL 空气：空气被吸入，针柄自动前移
        │
      硬脊膜
        │
      蛛网膜
        │
      蛛网膜下隙 ← 扎深了：回抽出无色透明液体（脑脊液）
      ```

### 与颅腔的关系

* **硬膜外隙与颅腔**

    * > **结论**：硬膜外隙与颅腔**不通**。

    * 不通的原因：硬膜附着在枕骨大孔骨面周缘，膜外侧的腔隙在骨面那一圈就被封死。

    * > **易错点**：与颅腔不通，但正因为上端靠近延髓，麻醉平面不宜过高——这两句是一对，必须连着记。

### 硬膜外麻醉的平面控制

* **硬膜外麻**

    * 原理：麻药注入硬膜外隙，阻断神经根的传导而达到麻醉。

    * 危险所在：上平面没看住、患者又是头低脚高位时仍不断追加，麻药会沿硬膜外隙上行到靠近枕大孔的那一段，那里离延髓最近，威胁其中的生命中枢。

    * 处理一：术中随时用大头针扎一扎测感觉，一旦发现切口上界的麻醉已经够用，就不再往上麻醉。

    * 处理二：调整体位，头调高、脚调低，麻药便流向椎管下界。

* **穿刺层次的判断规则**

    * 注射器里预留 1 毫升空气：空气被腔吸走、针柄自动往前，说明扎到的是硬膜外隙。

    * 扎得过深时同样有落空感，但空气不往里去；回抽见液体，说明进入深面的蛛网膜下隙。

    * > **结论**：空气能进去，是硬膜外腔；水能流出来，是深面的蛛网膜下腔。

## 蛛网膜与蛛网膜下隙

* **蛛网膜**

    * > **定义**：位于硬膜深面的一层膜；颅内的蛛网膜通过枕大孔延续到椎管内。

    * 位于硬脊膜与软脊膜之间，与硬膜几乎紧贴。

    * 重点掌握两个结构：蛛网膜下隙与终池。

* **蛛网膜下隙（下腔）**

    * 位置：蛛网膜与软脊膜之间。

    * 内容物：脑脊液——穿刺抽出的无色透明液体即是证据。

---

## 终池

* **终池**

    * > **定义**：第一腰椎到第二骶椎之间，蛛网膜下腔膨大形成的腔，位于终点的位置。

    * 形成基础：成人脊髓圆锥下端在第一腰椎水平，而包绕终丝的蛛网膜要到第二骶椎水平才继续下行，一头一尾之间膨出很大一截。

    * 位置：第一腰椎到第二骶椎之间。

    * 内容物三样：马尾神经、脑脊液、终丝。

* **马尾（马尾神经）**

    * > **定义**：脊髓圆锥以下围绕终丝排列成束的神经根。

    * 是终池的内容物之一，与终丝一起被膜层包绕下行。

---

## 腰穿定位

* **腰穿（蛛网膜下腔穿刺）**

    * > **定义**：在终池处穿刺抽取脑脊液的操作，终池是它的最佳位置。

    * 常用穿刺间隙：第三、四腰椎之间或第四、五腰椎之间。

    * 选此处的原因一：脊髓下端在第一腰椎以上，扎这里不会损伤脊髓。

    * 选此处的原因二：终池腔隙很大，穿进去以后可以把脑脊液抽出来。

* **体表定位标志**

    * > **结论**：两侧髂嵴最高点连线对应第四腰椎棘突。

    * 该棘突的上一个间隙是腰三/腰四，下一个间隙是腰四/腰五，两个都可以作为腰穿部位。

* **腰穿体位**

    * 患者取坐位使脊柱弯曲；侧面观骶骨骶曲一段弯曲最厉害，该处腔隙就张开。

    * 定位示意：

      ```text
      骶骨骶曲：脊柱弯曲最厉害处，腔隙张开
      ══════╪══════   棘突
      ┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄   ← 针沿棘突间隙进入
            │
      腰3 ──┼── 腰4    脊髓下端在 L1 以上，扎此处不伤脊髓
      腰4 ──┼── 腰5    位于终池 L1—S2 范围内，腔隙大
      腰5 ──┼── 骶1
            │
      两侧髂嵴最高点连线 → 第4腰椎棘突
            │
      其上间隙＝腰3/腰4    其下间隙＝腰4/腰5
      ```

## 软脊膜

* **软脊膜**

    * > **定义**：脊髓最内层的膜，很薄，上面布满神经和血管。

    * 分布特点：会突入脊髓的沟和裂里头去，紧密贴在脊髓表面。

    * 画脊髓断面时，表面的沟里有、裂里有的一层膜就是软脊膜。

---

## 硬脑膜

* **硬脑膜**

    * > **定义**：脑最外层的膜，厚而坚硬，由致密结缔组织构成，特点与硬脊膜相同。

    * 第一个要点：分两层。外层很薄，实际上它就是颅内的骨膜；内层厚而坚硬。

    * 第二个要点：与颅骨的结合有规律——与颅顶骨结合疏松，与颅底骨结合紧密。

    * 第三个要点：在某些部位能反折，形成较硬的板状结构，深入脑的间隙里去。

### 疏松与紧密的临床后果

* **颅顶骨与硬脑膜结合疏松**

    * 颅顶骨骨折的碎片容易损伤脑膜中动脉。

    * 颅内血量增多会把硬脑膜向内移，脑髓受压，产生脑疝。

    * 正因结合疏松，硬脑膜能与骨面分离，所以颅顶可以出现硬膜外腔。

* **颅底骨与硬脑膜结合紧密**

    * 颅底骨一骨折，硬膜与蛛网膜就同时被撕裂。

    * 临床表现是口鼻流出血液和黏稠的脑脊液，即脑脊液外漏。

    * > **结论**：颅顶疏松 → 硬膜外腔 + 脑膜中动脉出血致硬膜内移、脑疝；颅底紧密 → 骨折时硬膜蛛网膜同时撕裂、脑脊液漏。

---

## 大脑镰与小脑幕

* **硬脑膜反折结构**

    * 要记住的三个：大脑镰、小脑幕、硬脑膜静脉窦。

* **大脑镰**

    * > **定义**：硬脑膜到达颅顶正中线时两层分开，向下深入左右大脑半球之间形成的镰刀状板状结构。

    * 位置：深入左右大脑半球中间的半球间裂内，对大脑起固定作用。

    * 形态：前窄后宽，像镰刀，名称由此而来。

    * 邻近窦腔：根部有三角形腔，根部下方另有圆形腔。

* **小脑幕**

    * > **定义**：硬脑膜反折形成的板状结构，左右两片像小帐篷一样搭在一起。

    * 位置：伸入枕叶与小脑之间的裂隙里，作用同样是固定脑髓。

    * 承托关系：左右两片幕搭成帐篷，罩在小脑与脑干上方。

## 硬脑膜静脉窦

| 静脉窦 | 位置 | 通连关系 |
| :--- | :--- | :--- |
| 上矢状窦 | 颅顶正中线、大脑镰根部，断面三角形 | 蛛网膜粒伸入其两侧壁回收脑脊液；向后经直窦接窦汇 |
| 下矢状窦 | 大脑镰下缘，断面圆形 | 向后经直窦接窦汇 |
| 窦汇 | 枕内隆突内侧 | 所有窦汇集于此，再向两侧发出横窦 |
| 横窦 | 颅底横窦沟 | 由窦汇向两侧发出；收纳岩上窦 |
| 乙状窦 | 小脑幕深面下行而成，颅底乙状窦沟 | 从颈静脉孔出颅，接颈内静脉 |
| 海绵窦 | 蝶鞍两侧 | 前通眼上静脉与眼下静脉（进而通内眦静脉），另连大脑中浅静脉；后有岩上窦通横窦、岩下窦通乙状窦 |
| 岩上窦 | 颞骨岩上部 | 汇入横窦 |
| 岩下窦 | 颞骨岩部 | 与乙状窦相通 |

* **颅底静脉窦的相互关系**

    * 颈静脉孔往上是乙状窦沟，再往外是横窦沟，窦汇居两者之间。

    * 海绵窦向前与眼上静脉、眼下静脉相通，眶内静脉由此与内眦静脉相通。

    * 海绵窦还与大脑中浅静脉相连。

    * 整体印象：颅底静脉窦很多，彼此相互通连；颅顶则是上矢状窦与下矢状窦。

## 脑的蛛网膜与蛛网膜粒

### 蛛网膜下腔与下池

* **蛛网膜下腔（蛛网膜下隙）**

    * > **定义**：脑的蛛网膜与软脑膜之间的腔隙，内含脑脊液。

    * 颅内与椎管内的这两个蛛网膜下腔隙是相通的。

* **蛛网膜下池**

    * > **定义**：蛛网膜下腔扩大的部位。

    * 五个下池及其所在部位：

      | 池 | 所在部位 |
      | :--- | :--- |
      | 交叉池 | 视交叉所在部位，周围空隙较大 |
      | 脚间池 | 中脑的脚间窝 |
      | 桥池 | 脑桥与斜坡之间 |
      | 小脑延髓池 | 延髓与小脑之间 |
      | 四叠体池 | 大脑、小脑之间，即四叠体所在处 |

### 蛛网膜粒

* **蛛网膜粒**

    * > **定义**：蛛网膜突入上矢状窦形成的绒毛状粟粒状小体，很像小米粒大小。

    * 位置：上矢状窦的两个侧壁上，整个上矢状窦两侧壁有很多很多。

    * 功能：回收脑脊液，将脑脊液回收到上矢状窦内。

    * > **结论**：回收脑脊液在蛛网膜粒，产生脑脊液在脉络丛，一进一出，两个位置别搞混。

---

## 软脑膜与脉络丛

* **软脑膜**

    * > **定义**：脑最内层的膜；关于它只需记住一个结构——脉络丛。

* **脉络丛**

    * > **定义**：由软膜、毛细血管丛和室管膜上皮共同构成的绒毛状结构。

    * 功能：产生脑脊液。

    * 分布：整个脑室里边都有，脑室内以侧脑室居多、在侧脑室中最多。

---

## 脑脊液的产生、环流与回收

* **脑脊液的环流路径**

    * > **定义**：侧脑室 → 室间孔 → 第三脑室 → 中脑水管 → 第四脑室 → 正中孔与侧孔 → 蛛网膜下腔 → 蛛网膜粒 → 上矢状窦 → 窦汇 → 横窦/乙状窦 → 颈内静脉 → 回心。

    * 产生于左右侧脑室，因为侧脑室的脉络丛最多。

    * 由室间孔进入第三脑室。

    * 由中脑水管进入第四脑室。

    * 第四脑室有三个孔，一个正中孔、两个侧孔，脑脊液由此进入蛛网膜下腔。

    * 进入蛛网膜下腔后，颅内与椎管内的腔隙相通，脑脊液一路循环并上行。

    * 到达蛛网膜粒后被回收到上矢状窦。

    * 再由上矢状窦到窦汇，被横窦、乙状窦回收到颈内静脉，最后回心。

    * 环流示意：

      ```text
      脉络丛（侧脑室最多）产生脑脊液
           │
           │  室间孔
           ▼
      第三脑室
           │  中脑水管
           ▼
      第四脑室
           │  正中孔 ×1、侧孔 ×2
           ▼
      蛛网膜下腔 ←─→ 椎管内蛛网膜下腔（相通，含终池 L1—S2）
           │
           │  上行至蛛网膜粒
           ▼
      蛛网膜粒（伸入上矢状窦侧壁，回收脑脊液）
           │
           ▼
      上矢状窦 → 窦汇 → 横窦 / 乙状窦 → 颈内静脉 → 回心
      ```

* **脑室系统的门**

    * > **结论**：环流路线上可数清四个"门"——进入侧脑室之间的室间孔、离开第三脑室的中脑水管、离开第四脑室的正中孔与侧孔，以及终池的穿刺点。

* **环流受阻的后果**

    * 环流途中任何一个部位堵塞，都会造成脑脊液环流不畅。

    * 脑脊液一阻塞，脑室就增大。

## 脑动脉的来源与分支体系

* **皮质支（cortical branch）**

    * > **定义**：脑动脉的两大分支之一，供养大脑皮质及皮质下浅层结构。
    * 必记三支：大脑前动脉、大脑中动脉、大脑后动脉。
    * 三大皮质支的分支名称高度格式化，按"部位 + 内侧/外侧"或"所在脑沟"命名。

* **中央支（central branch）**

    * > **定义**：脑动脉的两大分支之一，主要营养脑髓质、基底神经核以及间脑等结构。
    * 大脑前动脉、大脑中动脉、大脑后动脉三者**都有中央支**。

* **颈内动脉（internal carotid artery）**

    * > **定义**：脑的动脉的两个来源之一，经过颅底的**颈动脉管**入颅腔，再分布到脑。
    * 在脑底面被切断的断面即颈内动脉，由它发出大脑中动脉、眼动脉与大脑前动脉。

* **椎动脉（vertebral artery）**

    * > **定义**：脑的动脉的另一个来源，穿**上 6 个颈椎的横突孔**，然后经**枕骨大孔**进入颅腔。
    * 颅内走行是"穿孔 → 汇合 → 改名"三步。
    * 左右椎动脉在**桥延沟**部位左右两支**汇合**，汇合后构成一个**短干**。
    * 该短干行至**基底动脉沟**部位**改名为基底动脉**，再由基底动脉发出分支到达其分布区。

```text
   颈内动脉                              椎动脉
      │                                    │
  颈动脉管（颅底）                      上 6 个颈椎横突孔
      │                                    │
      │                                  枕骨大孔
      │                                    │
      └────────────►  脑  ◄──────────────┘
                        │
            ┌───────────┴───────────┐
            │                       │
         皮质支                   中央支
   （前 / 中 / 后三支主供）    （脑髓质、基底神经核、间脑）
```

> **结论**：脑的动脉虽然分支极多，但根子上只有两棵树——颈内动脉一棵树，椎动脉一棵树。

## 皮质支

### 大脑前动脉

* **大脑前动脉（anterior cerebral artery, ACA）**

    * > **定义**：皮质支三支之一，根部发出以后沿着**胼胝体的上缘向后行，到顶枕沟支之前结束**。
    * 颈内动脉发出的小支钻入**半球间裂**，左右两侧各一条，两条一起进半球间裂。

* **大脑前动脉的分支序列**

    * 分支按顺序为：额底内侧动脉、额前内侧动脉、胼胝体缘动脉、额中内侧动脉、额后内侧动脉、膝前动脉。
    * **额底内侧动脉**与**额前内侧动脉**这两支都**绕过了胼胝体的上缘**。
    * **胼胝体缘动脉**的末端到旁中央小叶，在那儿改叫**旁中央动脉**。
    * > **提示**：命名规律是一串"额 × × 内侧动脉"——前、中、后排着队，再加一支胼胝体缘动脉收尾。

* **内侧面上的标志结构**

    * 连接左右大脑半球的横行结构是**胼胝体**。
    * 胼胝体前方依次是**前联合、视交叉、灰结节、漏斗、丘隆、丘脑间联合、丘脑下沟**，再往后是脑干。
    * 更往后是**顶枕沟**，顶枕沟那边是**颞叶、枕叶**，另有一条**距状沟**。
    * 这几条沟围出来的那块标志性结构叫**旁中央小叶**。

### 大脑中动脉

* **大脑中动脉（middle cerebral artery, MCA）**

    * > **定义**：皮质支三支之一，主干**藏在外侧沟的深面**，走在外侧沟里面不出来。
    * 挂图上这段主干以虚线表示，位于**外侧沟深面**。
    * 外侧面图上直接可见的标志：**大脑外侧沟、顶枕沟**，以及**颞叶、枕叶**。

* **出沟向上的分支**

    * 分支为：顶叶后动脉、角回动脉、额底外侧动脉、额前沟动脉、中央前沟动脉、中央沟动脉、中央后沟动脉。
    * **角回动脉**因为跟着角回走，所以得名。

* **沟内发出的颞支**

    * 由沟里边出来的分支是三支颞支：颞叶前动脉、颞叶中动脉、颞叶后动脉。

* **出沟终支**

    * 出沟的终支是**顶叶后动脉**和**角回动脉**，加上前面提到的三支颞支。

* ⚠️ **易错点**：这一堆分支名字里的"额前沟、中央前沟、中央沟、中央后沟"，是按它们各自所在的**脑沟**命名的，不是按动脉干的顺序命名的——名字里的沟就是位置。

### 大脑后动脉

* **大脑后动脉（posterior cerebral artery, PCA）**

    * > **定义**：皮质支三支之一，在**颞叶的下方**（即**半球底面**）开始分出，然后沿着**顶枕沟**向后去。
    * 挂图上在**下缘走**的是大脑后动脉。

* **主干级分支**

    * 两支主干级分支：**顶枕沟支**、**距状沟支**。

* **颞支**

    * 往下发三支排着队的颞支：**颞前支、颞中支、颞后支**。

## 皮质支的分布与分工

* **大脑前动脉与大脑后动脉的分布范围**

    * > **结论**：大脑前动脉和大脑后动脉主要分布范围是**大脑半球内侧面、颞叶的下面和枕叶**。
    * 它们的分支都**绕过了大脑的上缘和下缘，跑到外侧面去了**。

* **三大皮质支的分工规律**

    * > **结论**：**外侧面归中动脉，上缘归前动脉，下缘归后动脉**。
    * **大脑中动脉**的营养区是**半球外侧面的大部分**。
    * 外侧面上缘一带来的分支来自**大脑前动脉**的分支。
    * 外侧面下缘一带来的分支来自**大脑后动脉**的分支。
    * 挂图上的三处对位：外侧沟深面走的是**大脑中动脉**，胼胝体上缘走的是**大脑前动脉**，下缘走的是**大脑后动脉**。

* **动脉来源与分布的关系**

    * 延髓处椎动脉通过整个**枕骨大孔**上来，左右两支到**脑桥基底部合成基底动脉**，然后再发分支。
    * 旁边被切断的断面是**颈内动脉**，由它发出**大脑前动脉**直接**进入半球间裂**。
    * 断面旁一堆细小的连接血管都是**交通支**。

| 动脉 | 主干标志 | 主要分布区 |
| :--- | :--- | :--- |
| 大脑前动脉 | 胼胝体上缘 | 内侧面大部；越上缘到外侧面上缘 |
| 大脑中动脉 | 外侧沟深面 | 半球外侧面的大部分 |
| 大脑后动脉 | 半球底面，沿顶枕沟 | 颞叶下面、枕叶 |

```text
        大脑上缘 ───── 越过上缘来的：大脑前动脉的分支
             ▲
             │
   额底外侧 / 额前沟 / 中央前沟 / 中央沟 /
   中央后沟 / 顶叶后 / 角回   ← 全部是大脑中动脉（外侧面）
             │
             ▼
        大脑下缘 ───── 越过下缘来的：大脑后动脉的分支
```

## 中央支与内囊出血

* **中央支（central branch）**

    * > **定义**：主要营养**脑髓质、基底神经核以及间脑**等结构的动脉分支。
    * 三个中央支里最要紧的一支是**中中央动脉**。

* **中中央动脉（豆纹动脉）**

    * > **定义**：**大脑中动脉**所发出来的中央支，又名**豆纹动脉**。
    * 分布范围是三个地方加一个：**尾状核、豆状核**，以及**内囊的膝部和后肢**。

```text
        尾状核  ●
                 ╲
        豆状核  ●   ╲
                   ● 内囊（膝部 + 后肢）
```

* **内囊内的传导束**

    * 内囊**膝部**里有重要的传导束——**皮质核束**。
    * 内囊**后肢**里有重要的感觉束——**丘脑皮质辐射**，还有一个运动传导束——**皮质脊髓束**。
    * 这些全都是大脑中动脉的中央支来营养的。

* **内囊出血的三偏**

    * 感觉、运动、视野三条通路在后肢和膝部挨着挤，被一支豆纹动脉同时供养，所以一处出血三条一起倒。
    * > **结论**：内囊出血的三偏 = 对侧**偏身感觉障碍** + 对侧**偏身运动障碍** + 两眼**同向偏盲**。

## 大脑动脉环

### 脑底面的标志结构

* 底面正中从前往后：两个**视神经**（其中一个切断了，另一个没断），往里相当于**视交叉**的位置，再往后形成**视束**。
* **垂体的上方**是视交叉，**垂体下方**是**漏斗、灰结节**；再往后两个是**乳头体**。
* 乳头体后方相当于**脚间窝**，那里有**后穿质**。

### 组成

* **大脑动脉环（circulus arteriosus cerebri）**

    * > **定义**：又称**基底动脉环**，由多条动脉**不成环形地排列**、但**合起来构成一个环状**结构，位置正好在**大脑基底部**，围绕**下丘脑**。
    * ⚠️ **易错点**：动脉**不是**绕着脑底面这些结构一圈一圈走的，它们是**不成环形地排列**的，只是**合起来构成一个环状**。

* **颈内动脉发出的分支**

    * 向外发出**大脑中动脉**。
    * 向前外发出**眼动脉**，到眶腔去。
    * 一个小支钻到**半球间裂**里，即**大脑前动脉**（左右两侧各一条，一起进半球间裂）。

* **连接动脉与结缔干**

    * 两条大脑前动脉之间是**前交通动脉**（前交通支）。
    * 向后一个细支是**后交通动脉**（后交通支），它连到**大脑后动脉**那一侧。
    * 左右**大脑后动脉**往后汇合的那个主干，就是**基底动脉**。

> **结论**：大脑动脉环 = **大脑前动脉 + 前交通动脉 + 颈内动脉主干 + 后交通动脉 + 大脑后动脉**。前部由前交通动脉把两侧的大脑前动脉连起来，两侧由颈内动脉主干撑住，后部由后交通动脉把颈内动脉连到大脑后动脉，而左右大脑后动脉又借基底动脉连成一体。

```text
                    前交通动脉
                 ┌──────┴──────┐
            大脑前动脉    大脑前动脉
                 │                │
        颈内动脉 ├───── 环 ────┤ 颈内动脉
        （主干） │   围绕下丘脑   │ （主干）
                 │                │
            后交通动脉    大脑后动脉
                 │                │
            大脑后动脉    大脑后动脉
                 └──────┬──────┘
                     基底动脉
                        │
                      脚间窝
```

### 作用

* **分配血量**

    * > **结论**：当某一支供血动脉**狭窄或闭塞**时，血流可以经环上的**吻合支**改道，**重新分配血量**。
    * 例如大脑前动脉这一侧由于**动脉硬化形成斑块**越来越狭窄乃至堵住，其供血仍可通过**吻合支**绕过去。

* **缓冲血压**

    * > **结论**：动脉环把**颈内动脉主干上的高压在环内均摊开**，减轻了细小的中央支（尤其是**豆纹动脉**）承受的压力，从而降低脑出血的发生可能。
    * 颈内动脉是很粗的动脉干，血压很高；中央支（如中中央动脉）是它发出的细小分支。
    * 致病链条：长期**高血压**、**动脉硬化**使血管变脆 → 突然**情绪激动**使血压再升高 → 小血管鼓破 → **内囊出血**。
    * 血压高的人众多却不是人人都内囊出血，就是因为有这样一个**动脉环**把颈内动脉的高压很快疏通掉、使血压下降。

## 大脑静脉

### 静脉的三条特点

* **不与动脉伴行**

    * 大脑静脉**既不跟着动脉走，名字也不跟着动脉起**，与身体其他部位多与同名动脉伴行的静脉不同。

* **没有静脉瓣**

    * 大脑静脉**没有静脉瓣**，所以**血液可以逆流**。

* **分浅深两组并有丰富的吻合**

    * 大脑静脉分为**浅、深两组**，并有**丰富的吻合**。
    * > **提示**：这三条特点里第三条是理解后面所有内容的钥匙——正因为吻合丰富，所以才有动脉环；正因为吻合丰富，浅组和深组之间才能互相代偿。

| 对比项 | 其他部位的静脉 | 大脑的静脉 |
| :--- | :--- | :--- |
| 与动脉的关系 | 多与同名动脉伴行 | 不伴行、也不同名 |
| 静脉瓣 | 有静脉瓣，血液单向 | 无静脉瓣，血液可逆流 |
| 分组 | 分组简单 | 浅、深两组 + 丰富的吻合 |

```text
   与其他部位的静脉                大脑的静脉
   ─────────────────         ───────────────────
   多与同名动脉伴行      ✗     不伴行、也不同名
   有静脉瓣，血液单向    ✗     无静脉瓣 → 血液可逆流
   分组简单              ✗     浅、深两组 + 丰富的吻合
```

### 浅组静脉

* **浅组静脉的汇流目标**

    * 浅组静脉最后都要汇到**脑膜的静脉窦**身上去，所以先回顾静脉窦的盘子。
    * **上矢状窦**在颅顶，向后到**窦汇**为止；另有**下矢状窦**；下矢状窦和窦汇之间还有一个**直窦**。
    * 再向两侧是**横窦**，然后是**乙状窦**，最后变成**颈内静脉**。
    * **眼上静脉**和**眼下静脉**分出来以后和**海绵窦**相连。
    * **海绵窦**通过**岩上窦**通到**直窦**，通过**岩下窦**通到**乙状窦**。

* **大脑上静脉（superior cerebral vein）**

    * > **定义**：浅组静脉之一，收集**脑实质（大脑半球）上半部**的静脉血，**汇入上矢状窦**。
    * 数目约 **8~12 条**。
    * 挂图上与上矢状窦相连的那些血管就是大脑上静脉。
    * > **提示**：脑的顶面中间是**半球间裂**，上边那些**小米粒状的凸起**是**蛛网膜粒**；见到蛛网膜粒就说明这块相当于**上矢状窦侧壁**的位置。
    * 走行上，上矢状窦在半球间裂里边由前向后走，后面是**窦汇**，再变成**横窦**。

* **大脑中静脉（middle cerebral vein）**

    * > **定义**：浅组静脉之一，收集**半球外侧沟附近**的静脉血，**汇入海绵窦**。
    * **主干在外侧沟深面**——这一点和大脑中动脉正好一样，一个在沟深面走动脉，一个也在沟深面走静脉，只不过动脉不伴行静脉。
    * 发的分支就在**外侧沟附近的皮质**，并且**还发出一个分支到岛叶**。

* **大脑下静脉（inferior cerebral vein）**

    * > **定义**：浅组静脉之一，在**大脑底面**回收**下半部（半球底面）**的静脉血，**直接奔横窦**去，**汇集到横窦**。
    * 主干在底面。

```text
浅组静脉
  大脑上静脉（8~12条）──► 上矢状窦 ──┐
  大脑中静脉 ────────────► 海绵窦 ──┤
  大脑下静脉 ────────────► 横窦  ─┐ │
                                   │ │
        下矢状窦 ──► 窦汇 ──────────┘ │
                        │             │
                        ▼             │
                      直窦 ◄─── 岩上窦（海绵窦 → 直窦）
                        │             │
                        │        岩下窦
                        │             │
                        ▼             ▼
                      横窦 ───────► 乙状窦
                        │             │
                        └──────┬──────┘
                               ▼
                          颈内静脉 ──► 回心
```

### 深组静脉

* **大脑内静脉（internal cerebral vein）**

    * > **定义**：脑深部的静脉最后都汇集成的一个主干，左右各一。
    * 左右的大脑内静脉再向上**汇集成一个大脑大静脉**。

* **大脑大静脉（great cerebral vein）**

    * > **定义**：由左右大脑内静脉汇合而成，**直接注入到直窦**。
    * 静脉血交给直窦后，由**直窦 → 横窦 → 乙状窦 → 颈内静脉 → 回心**。

```text
  脑深部静脉
        │
        ▼
  大脑内静脉（左右各一）
        │      │
        └──────┘
             ▼
       大脑大静脉
             │
             ▼  （直接注入）
           直窦 ──► 横窦 ──► 乙状窦 ──► 颈内静脉 ──► 回心
```
