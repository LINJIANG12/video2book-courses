# 关节学·四肢骨的连结：上肢与下肢

## 上肢骨的两截结构

* **肢带骨与自由骨**
    * > **定义**：上肢骨不是一个整块，拆开看是两截——靠内侧的肢带骨、外侧的自由骨，连结也按这两截分别记。
    * 肢带骨 = 锁骨 + 肩胛骨，任务只有一个：把上肢挂到躯干上。
    * 自由骨 = 上臂的肱骨、前臂的桡骨和尺骨，再往下的手骨，全靠关节一个接一个串起来。
    * 肢带骨那一截的连结只管位置、不用记更多；真正要花时间的是自由骨，从肩一路数到腕。

* **锁骨的形态**
    * 呈 S 形：内侧端这一头粗，外侧端那一头扁。
    * 锁骨外侧端搭着的不是骨头，是一个突起，叫**肩峰**。
    * 从上方看人体，胸部这一侧是躯干，肩部这一侧就是肩带，中间横着的就是锁骨。

## 肢带骨的连结

* **胸锁关节**
    * > **定义**：肩带在躯干一侧的铰接，位于前方，锁骨内侧端与胸骨相连。

* **肩锁关节**
    * > **定义**：肩带在肱骨一侧的铰接，位于外侧，锁骨外侧端连着肩峰。

* **肩带结构的整体关系**
    * 整个肩带只靠两处铰接在躯干上：内侧端与胸骨相接，外侧端与肩峰相接。
    * 肩胛骨上能一起认出来的还有肩胛冈、关节盂、喙突，以及肩胛切迹和上角。

    ```text
                胸骨
                 │   ← 胸锁关节
            ┌────┴────┐
            │  锁  骨 │   （S 形，内侧端粗、外侧端扁）
            └────┬────┘
                 │   ← 肩锁关节
               肩峰 ──── 肩胛冈
                 │
            关节盂   喙突

            肩胛切迹 · 上角
    ```

    * > **结论**：肢带骨的连结 = 胸锁关节 + 肩锁关节。

## 肩关节

### 构成

* **肩关节**
    * > **定义**：由肱骨头的球状关节面与肩胛骨的浅盘状关节盂构成。
    * 关节盂是肩胛骨外侧的浅盘状凹陷，旁边挂着喙突，上方是肩峰。
    * 从外向内看、把肱骨整个拿掉后，暴露出来的浅盘状关节面就是关节盂。
    * 从前方看，关节囊的前方顶着两个突起：上面宽的是肩峰，前面尖的是喙突。

* **关节盂缘**
    * > **定义**：围在关节盂周缘一圈的环状软骨结构，形态是周围厚、中心薄。
    * 作用是把本来就浅的关节凹加深，弥补关节盂浅的不足。
    * 盯住关节面的周缘就能认出它。

* **肱二头肌长头腱**
    * 起自关节腔、也就是关节盂的上方。
    * 在关节腔内穿过，再穿出关节囊。
    * 从前方看肩关节时，囊的下方有一个肌腱从囊里面穿出来，就是它。
    * 肩关节冠状断面上，腔里露出一个细条状结构从囊里钻出去——这一段是走在**关节腔里面**的，这是肩关节很不一样的地方。

### 四个特点

* **关节面：头大盂小**
    * > **结论**：肩关节第一个特点——头大、盂小（盂浅）。
    * 关节盂的关节面比较小，肱骨头的关节面面积比较大。
    * 盂浅不是缺陷，有专门的补救办法，就是关节盂缘。

* **关节囊薄而松弛**
    * > **结论**：肩关节第二个特点——关节囊薄而松弛。
    * 囊又薄又松，关节腔就大，关节因此灵活、运动幅度大。
    * 前后壁尤其薄弱，所以肩关节能做出那么大的动作。

* **囊外韧带加固**
    * > **结论**：肩关节第三个特点——囊外有韧带加固。
    * 囊薄而松，稳定性要靠囊外的东西来补。
    * 其中有一条**喙肱韧带**，知道这个名字就行。

* **关节腔内有肌腱通过**
    * > **结论**：肩关节第四个特点——关节腔内有肱二头肌长头腱通过。
    * 四条合起来：头大盂浅、囊薄而松、囊外有韧带、腔内走肌腱。

### 运动

* **运动方向**
    * 往前去是屈，往后去是伸——前屈后伸。
    * 向外是外展，向内是内收——外展内收。
    * 肱骨自己的旋内、旋外。
    * 另外还可以做环转。
    * 注意屈曲 90 度。

* **灵活性定位**
    * > **结论**：肩关节是全身最灵活的关节。
    * 灵活到这个程度，就埋下了容易脱位的伏笔。

### 脱位

* **肩关节前脱位**
    * > **定义**：肱骨头从关节盂里跑到关节盂的前下方的脱位。
    * 肩关节最容易往前下方脱——灵活的关节通常都带容易脱位这个缺点。
    * X 线表现：肩峰相对地明显向外突出。

* **方肩**
    * > **定义**：前脱位时肩膀摸起来像“方肩”的体表表现。
    * 肱骨滑到前面去了，肩胛骨没动，肩峰相对就翘出来了。
    * 肩膀的正常圆隆外形被抹平，肩峰和锁骨那一段变成一个方棱角。

* **搭背实验阳性**
    * 正常人自己的手能搭到后背。
    * 肩关节一脱位，患者就够不着了——把手往后背方向搭，搭不过去，这就是搭背实验阳性。
    * 机制是手的内旋后伸动作受限。

* **正常与前脱位对比**

    ```text
       正常                            肩关节前脱位
       ┌────────┐                    ┌────────┐
       │  肩峰  │ ← 圆隆            │  肩峰  │← 向外突出 → 方肩
       └───┬────┘                    └────┬───┘
           │ 锁骨                        │
                                        │ 锁骨
       手可搭到后背 ✓                   手够不到后背 ✗ → 搭背实验（+）
    ```

## 肘关节

### 构成：三骨六面三关节

* **三骨**
    * 肱骨、桡骨、尺骨三块骨共同构成肘关节。
    * 肱骨下端有两个关节面：肱骨小头、滑轮状的肱骨滑车。
    * 桡骨上端也是两个面：小头上方朝上的凹面（头凹）、桡骨小头周围的环状关节面。
    * 尺骨上端同样贡献两个面。

* **六面三关节配对**

    | 关节面 | 配对 | 组成的关节 |
    | :--- | :--- | :--- |
    | 肱骨小头 | 桡骨小头上方的凹面（头凹） | **肱桡关节** |
    | 肱骨滑车 | 尺骨的滑车切迹 | **肱尺关节** |
    | 桡骨小头的环状面 | 尺骨上端的桡切迹 | **尺桡近侧关节** |

* **尺骨上端的结构**
    * 冠突在前、鹰嘴在后，它们中间那道凹面就是滑车切迹，正好是尺骨上端的关节面。
    * 矢状切面上，肱骨和尺骨相接的部位是被切断的——正是在这个部位切开，肘关节的特色才暴露出来。
    * 断面上壁是关节囊，中间是关节腔；上面那根圆形的关节面是肱骨滑车。

* **全关节总括**
    * > **结论**：肘关节 = 三骨（肱骨、桡骨、尺骨）、六面、三个关节（肱桡关节、肱尺关节、尺桡近侧关节）。
    * 看到肘就该条件反射地念出“三骨六面三关节”。

### 三个特点

* **囊薄而松**
    * 矢状剖面上：前方的关节囊薄，后方的关节囊又薄而又松弛。
    * 前后都薄而松，两侧就靠韧带顶住。
    * 直接后果是肘关节在结构上被“锁”在屈伸这个方向上。

* **囊外韧带，两侧各一条**
    * 挂图两侧各有一条韧带，沿上下方向走；因为角度关系有一侧不太明显，但两条都是上下走的。
    * 尺骨这一侧叫**尺侧副韧带**，桡骨这一侧叫**桡侧副韧带**。
    * 两侧副韧带一加强，肘关节的横向稳定性就出来了。

* **桡骨小头环状韧带**
    * 起于尺骨上端的后方，绕到尺骨上端的前方，呈漏斗状，正好环抱桡骨颈。
    * 它和关节囊几乎融成了一体。
    * > **易错点**：环状韧带环绕、环抱的是**桡骨颈**（桡骨小头下方那一段），不是桡骨小头本身。

    ```text
      尺骨上端                                      尺骨上端
       后方：鹰嘴                                     前方：冠突
          ●━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━●
          ┃           环 状 韧 带（漏斗状）           ┃
     ┌────╂━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━╂────┐
     │    ┗━━━━━━━━━━━━━━━━┳━━━━━━━━━━━━━━━━━━━━━┛    │
     │                     桡   骨   颈                 │
     │                （桡骨小头在它的上方）              │
     └────────────────────────────────────────────────────┘
    ```

* **环状韧带与桡骨小头的转动**
    * 环状韧带是一圈漏斗形的纤维束，中间围成一个环把桡骨颈套在里面。
    * 桡骨小头在这个环里还能转，正因为环是围住颈的、小头在环内可自由转动。

### 运动

* **以屈伸为主**
    * 囊前后薄而松，肘关节在结构上被锁在屈伸方向上，所以运动主要是屈伸。

* **另有旋前、旋后**
    * 不要记死：除了屈伸，还可以做旋前、旋后。

### 脱位

* **肱骨滑车与窝的深浅**
    * 肱骨滑车后边是**鹰嘴窝**，窝深；前边是**冠突窝**，窝浅。
    * 屈肘 90 度时，鹰嘴和冠突正好把滑车夹在滑车切迹里，咬得很死。

* **后脱位**
    * > **定义**：摔到手杵地、外力自前向后，冠突滑到滑车切迹的后方，尺骨连同桡骨整体滑到肱骨后面去的脱位。
    * 前面本来就是浅的——冠突窝浅，滑车切迹的后缘挡不住往前来的推力，冠突就容易往后滑。
    * 体表表现：冠突跑到后边去了，后边自然鼓起来一个包，隔着皮肤就能摸到。

    ```text
      屈肘 90°：滑车嵌在切迹里
          ┌────────────┐
          │  肱骨滑车  │
          └──┬──────┬──┘
          后 │      │ 前
       鹰嘴窝(深)  冠突窝(浅)
             │      │
         鹰嘴 ┄┄┄┄┄┄┄┄ 冠突    ┄＝滑车切迹

      摔倒手杵地：外力顶在浅的一侧
      ┌────────────┐
      │  肱骨滑车  │ ← 尺骨整体后移
      └────────────┘   ┌──────┐
                       │ 冠突 │ ← 越过切迹后缘，跑到滑车后方
                    鹰嘴┤      │
                       └──────┘
    ```

* **桡骨小头半脱位**
    * > **定义**：桡骨小头从环状韧带里衬出去、和肱骨小头分离，但和尺骨的那一关节仍咬合在一起的不完全脱位。
    * 多发生在 **4 岁以下**的小孩，成因是小儿的手臂被大人牵拉拽出来。
    * > **易错点**：它与尺骨的关节还是咬合的，所以只是“它跟肱骨脱了位”，属于不完全脱位。

* **桡骨小头半脱位的复位**
    * 先把小孩的上肢直接外旋，基本上就可以复位。
    * 不能复位时做屈曲：一定要摁压桡骨小头，然后屈曲，听到一声响就复位了。

* **脱位类型总括**
    * > **结论**：肘关节常见的脱位就两种——后脱位与桡骨小头半脱位。
    * 后脱位：摔伤手杵地，冠突滑过切迹后缘，体表后方鼓包。
    * 桡骨小头半脱位：4 岁以下小孩被牵拉所致，与肱骨小头分离但与尺骨仍咬合，即牵拉肘。

## 前臂骨的连结

* **桡尺骨的连结格局**
    * > **结论**：上下是关节，中间是骨间膜。
    * 靠肘那端是**尺桡近侧关节**，靠腕那端是**尺桡远侧关节**。
    * 中间相对的骨缘由**骨间膜**（桡尺骨间膜）连在一起，把两根骨牢牢连住。
    * 桡骨那侧的结构有小头、体、粗隆、茎突；尺骨那侧有冠突、鹰嘴、干、头、茎突，还有尺骨粗隆。

    ```text
            ═══════════════════════════════
                  尺桡近侧关节（靠肘那端）
            ┌────────────────────────────┐
            │  尺 ┃║║  骨间膜  ║║┃ 桡     │
            │  骨 ┃║║（桡尺骨间膜）║║┃ 骨   │
            └────────────────────────────┘
                  尺桡远侧关节（靠腕那端）
            ═══════════════════════════════

            旋转时：尺骨是轴心，桡骨绕着尺骨转
    ```

* **前臂旋转的轴心**
    * > **结论**：旋转时桡骨围绕尺骨旋转，尺骨是轴心骨。
    * 结构依据：环状韧带环绕的是桡骨颈，桡骨小头在这个环里可以自由转动，说明上面那一端本来就是桡骨在动。
    * 骨间膜是旋转的“折叠轴”，顺它折叠时就是桡骨绕尺骨转。

* **轴心骨在骨折时的意义**
    * 桡尺骨骨折的时候，轴心骨最重要，哪根骨是轴心就一定要对好。
    * 尺骨是轴心骨，尺骨一定要对好。
    * 桡骨稍微差一点还可以，因为它只是个绕着转的柱子。

## 桡腕关节

### 构成：凸三、凹二

* **腕骨的排列**
    * 腕骨一共八块，排成两排，每排四块。
    * 远侧排：大多角骨、小多角骨、头状骨、钩骨。
    * 近侧排：舟骨、月骨、三角骨，豌豆骨落在其上方。
    * 腕骨下方接的是前臂骨：这一块是桡骨下端，那一条是尺骨下端。

    ```text
            远侧排：大多角骨 · 小多角骨 · 头状骨 · 钩骨
            ────────────────────────────────────────────
            近侧排：  舟  骨 ·  月  骨 ·三角骨
                                          ● 豌豆骨（落在上方）
            ────────────────────────────────────────────
            手指 ← 手掌 ← 腕 ← 前臂
    ```

* **桡腕关节**
    * > **定义**：由腕骨与前臂骨下端共同构成的关节，也就是平常说的腕关节。
    * 关节凸在腕侧：舟骨、月骨、三角骨三块。
    * 关节凹在前臂侧，只有两个成分：桡骨下关节面、尺骨下端的关节盘。
    * 桡骨下关节面直接和腕骨挨得最近，它和腕骨组成关节。
    * 尺骨下端比较短，它和腕骨并不直接相连，中间隔着一块软骨，就叫关节盘；它和舟骨、月骨、三角骨相对。
    * > **结论**：尺骨下端**不参与**构成桡腕关节，参与的只是它下面那块关节盘。

* **凸三凹二的算法**
    * 凸 = 三块腕骨：舟骨、月骨、三角骨。
    * 凹 = 两个成分：桡骨下关节面 + 尺骨下端关节盘。

### 运动

* **运动方向**
    * 向前是屈，向后是伸。
    * 内收、外展。
    * 还可以做环转。

* **灵活性**
    * 桡腕关节的活动也是比较灵活的，运动方式与肩关节一套路数。

## 手部其余的关节名称

* **腕部与掌部的关节**
    * 腕骨之间的那些腔隙是**腕骨间关节**。
    * 远侧排腕骨和五个掌骨之间构成的腔隙是**腕掌关节**。

* **掌部与指部的关节**
    * 顺着手指的顺序往下：掌骨和掌骨之间是腕掌关节。
    * 掌骨和近节指骨之间是**掌指关节**。
    * 指骨和指骨之间是**指间关节**。

## 下肢骨连接的总划分

   * **肢带骨连接**

       * 含三块内容：骶髂关节、耻骨联合、骨盆。

   * **自由骨连接**

       * 重点落在髋、膝、踝这几个关节上。

## 骶髂关节

   * **骶髂关节（sacroiliac joint）**

       * > **定义**：由相邻的骶骨与髂骨的两个耳状面构成的关节。

       * 骶骨外侧面有一块粗糙的耳状面，髂骨内侧同样有一块，两面相贴夹出的缝即该关节。

       * 骨性特点一：关节面凹凸不平，近似平面而又粗糙，天生是稳固型关节。

       * 骨性特点二：关节囊紧贴关节面周缘，从上到下贴着骨面走，关节腔间隙极小。

       * 骨性特点三：无论从前方还是从后方看，关节囊外都有发达的韧带加固。

       * 骨性特点四：两个耳状面对接以后，一部分关节面相互骨化融合。

       * > **结论**：四条结构特点叠加，使该关节几乎不运动，是全身最牢固的一个关节。

       * > **易错点**：前方与后方各有一张挂图，必须连起来看，只看一张会漏掉另一侧的韧带加固。

   * **骶管与骶管裂孔**

       * 骨盆正中切开的断面图上，骶骨中央的骨性凹窝称骶管。

       * 骶管下方开放的部位称骶管裂孔。

## 耻骨联合

   * **耻骨联合（pubic symphysis）**

       * > **定义**：相邻两个耻骨的耻骨联合面，借助于纤维软骨（耻骨间盘）连接而成的结构。

       * 位置在骨盆前方，左右髋骨各有一个耻骨联合面，中间借软骨相连。

       * 耻骨间盘最要紧的结构特点是中央有一道呈矢状位的裂隙。

       * 骨连接分两类：直接连接的两骨之间没有腔，间接连接有腔，又称关节连接。

       * > **结论**：耻骨联合按纤维软骨相连本属直接连接，却因矢状位裂隙形成了腔，是直接连接与间接连接的过渡形式。

       * 兼有腔，故活动度略微存在：耻骨弓略微能够开大，女性大于男性。

       * 上下端另有韧带加固，上方为耻骨上韧带，下方为耻骨弓状韧带。

       * > **易错点**：结构特点只需记住最要紧的一条——有矢状位的裂隙；有裂隙，所以能微动。

## 骨盆

### 骨盆的组成与分界

   * **骨盆（pelvis）**

       * > **定义**：由左右髋骨加上后方的骶骨和尾骨三部分构成的骨性结构。

       * 分界线的走行：自耻骨结节起为耻骨梳（骨缘锐利）→ 弓状线（骨缘钝圆）→ 骶骨岬，另一侧重复。

   * **大骨盆与小骨盆**

       * 分界线以上、偏前的部分为大骨盆，即腹腔。

       * 分界线以下、后下方的部分为小骨盆，即固有盆腔，也是临床所称的骨盆。

    骨盆分界线由耻骨结节、耻骨梳、弓状线、骶骨岬连成，左右对称：

    ```text
                          ┌── 骶骨岬 ──┐
                       ╱                 ╲
                    弓状线               弓状线
                 ╱                           ╲
             耻骨梳                         耻骨梳
          ╱                                     ╲
      耻骨结节                               耻骨结节
     ╱                                           ╲
    ═════ 耻骨联合上缘 ═════   ← 骨盆分界线 ＝ 小骨盆上口
      ║         大 骨 盆（＝腹腔）          ║
      ╠═════════════════════════════════════╣
      ║         小 骨 盆（固有盆腔）        ║
      ╚═════════════════════════════════════╝
    ```

### 骨盆的上下口

   * **小骨盆上口**

       * 前方起于耻骨联合上缘，依次经耻骨结节、耻骨梳、弓状线、骶骨岬，另一侧重复。

       * > **提示**：这条线身兼两职，既是大小骨盆的分界线，也是小骨盆的上口线。

   * **小骨盆下口**

       * 自耻骨联合下缘起，经耻骨弓、坐骨结节，再借骶结节韧带到达尾骨尖，另一侧重复。

       * 是一条不规则的线。

### 骨盆的骨性标志

   * **髂结节**

       * 位于髂前上棘后上方三到四厘米处，髂嵴在此增厚。

       * > **提示**：这是临床骨穿的部位。

   * **髋骨前面的标志**

       * 自上而下依次为髂嵴、髂前上棘、髂前下棘、髂耻隆起、耻骨梳、耻骨结节、耻骨联合面，再往下为耻骨弓。

   * **髋骨后面的标志**

       * 坐骨结节、坐骨棘、大坐骨切迹、耳状面；另有弓状线与闭孔。

   * **骶骨上的标志**

       * 断面正中有隆起，其下为骶管裂孔。

## 髋关节

### 构成

   * **髋关节（hip joint）**

       * > **定义**：由股骨头与髋骨髋臼构成的关节。

       * 关节窝是髋骨外侧面的骨性深窝，称髋臼。

       * 关节头是股骨，关系密切的骨性标志为股骨头、大转子、股骨干、小转子。

   * **股骨头韧带（ligament of head of femur）**

       * 位于关节腔内，连接股骨头与髋臼，很短小。

       * 内部有营养股骨头的血管通过。

   * **髋臼唇（acetabular labrum）**

       * 环绕髋臼周缘的环状软骨环，由纤维软骨构成，形态类似肩关节盂周的盂唇。

       * 作用是把髋臼再加深一层，有利于关节稳固。

### 结构特点

   * 特点一：头大、髋臼深，周围附着髋臼唇又把窝加深一层，故为稳固关节。

   * 特点二：关节囊厚而坚韧，包裹范围很广，前方全包，后方约 2/3 被包进去。

   * 特点三：关节囊外有韧带加固，囊外可见髂股韧带、耻股韧带、坐股韧带。

   * 特点四：关节腔内有一根很短的小韧带，称股骨头韧带。

   * > **易错点**：囊外包裹看着很广，但只看前面会漏掉关键信息——前方全包，后方只包了大部分，外侧 1/3 没有包进去。

   * > **提示**：正因为后方外侧 1/3 未被包入，临床才有囊内骨折与囊外骨折之分；股骨颈折在这一段是囊外骨折，折在里面那段是囊内骨折。

   * > **提示**：与肩关节对记——肩关节腔内是肱二头肌长头腱，髋关节腔内是股骨头韧带，一个肌腱一个韧带，都是腔内结构。

### 运动

   * 屈为腿向上抬，伸为腿向后。

   * 有外展与内收。

   * 屈曲到 90 度时可以做旋内、旋外。

   * 可以做环转，杂技演员蹬伞时用一条腿把伞绕起来即为环转。

   * > **结论**：运动和肩关节类似，只是幅度小得多。

### 脱位方向

   * **后脱位（posterior dislocation）**

       * 是髋关节最常见的脱位方向。

       * 诱发体位为屈曲加内收再加内旋，此状态下足跟向外。

       * 体位叠加与稳固程度的关系：站立时头完全在臼内最稳固；屈曲 90 度后关节面露出一些；再加内收又露出一些；再加内旋时关节面几乎全部露在臼外，处于最不稳固状态。

       * 老人易后脱位的动作拆解：弯腰相当于大腿屈曲；站着驼人时膝关节向内借劲相当于内收；为站稳脚后跟向外撇相当于内旋，三者凑齐即造成后脱位。

   * 稳固程度对照：

   | 体位 | 股骨头与髋臼的关系 | 稳固程度 |
   | :--- | :--- | :--- |
   | 站立 | 头完全在臼内 | 最稳固 |
   | 屈曲 90 度 | 关节面露出一些 | 变松 |
   | 屈曲 90 度加内收 | 关节面又露出一些 | 更松 |
   | 再加内旋（足跟向外） | 关节面几乎全部露在臼外 | 最不稳固 |

   * > **易错点**：后脱位后患肢是短的，因为肢体固定在屈曲、内收、内旋这个体位上；两侧看都「包」出来分辨不出哪条腿，但大转子都支出来了，短的那条就是脱位腿。

## 膝关节

### 构成与辅助结构

   * **膝关节（knee joint）**

       * > **定义**：由股骨、胫骨与髌骨三块骨构成的关节，是全身最复杂的关节。

       * 上方为股骨，相关标志有收肌结节，前方有髌面。

       * 下方为胫骨，相关标志有髁间隆起、胫骨粗隆。

       * 前方另加髌骨；腓骨不参与膝关节。

       * 全身最灵活的关节是肩关节，膝关节则因囊、面、腔与辅助结构俱全而最复杂。

   * **髌骨与髌韧带**

       * 髌骨位于膝关节前方，其上方为肌腹很发达的股四头肌。

       * 髌骨下端有一块短而扁的肌腱，称髌韧带，止于胫骨粗隆。

   * **囊外韧带**

       * 前方为髌韧带，两侧为胫侧副韧带与腓侧副韧带，后方为腘斜韧带。

       * > **结论**：膝关节的前后两侧都有韧带加强，四周俱全。

   * **交叉韧带（囊内）**

       * 前交叉韧带起自髁间隆起的前方向后走行，后交叉韧带起自后方向前走行。

       * 两者都藏在髁间窝内，从侧面看呈十字形，故大名为十字交叉韧带，前交叉韧带、后交叉韧带只是小名。

   * **半月板（meniscus）**

       * 是位于关节腔内的软骨垫，外周厚、里边薄。

       * 股骨下端与胫骨上端都不是平面，两个凸面相接触面积小；加上半月板可增大接触面积，有利于关节稳固。

       * 还能减少震动、吸收一部分外力。

   * **髌上囊（suprapatellar bursa）**

       * 滑膜层在髌骨上方鼓出的一个小囊腔，内有少量滑液。

       * 囊的两侧内侧为骨、外侧为肌肉，膝关节运动时该肌肉也在运动。

       * > **结论**：该囊卡在骨与肌肉两个结构之间，作用是减少它们之间的摩擦。

   * **翼状襞**

       * 滑膜包裹着大量脂肪形成的三角形突起，突入关节腔内，位置在髌骨下方。

       * 填补膝关节关节腔内多余的空隙，也有利于关节稳固。

### 结构特点

   * 第一条：囊薄而松——这一条决定了膝关节首先要灵活，稳固要靠囊内外结构另行承担。

   * 第二条：囊外有韧带，髌韧带、胫侧副韧带、腓侧副韧带、腘斜韧带四周都有。

   * 第三条：囊内也有韧带，即前交叉韧带与后交叉韧带。

   * 第四条：囊内还有半月板。

   * 第五条：另有滑膜囊结构髌上囊。

   * > **结论**：囊薄而松换来灵活，稳固则全靠囊内囊外结构共同承担。

### 常受的两个损伤

   * **半月板损伤**

       * 是膝关节最常见的损伤。

       * 损伤机制：屈曲时股骨下端后方的尖滑过来，与之结合的关节面之间本就摆着一块半月板，此时全身重量压在关节面上且以旋转为主要动作，尖一碾压半月板即损坏。

       * 直立时接触面最大，不容易损伤。

   * **交叉韧带损伤**

       * 前、后两根交叉韧带完好时，两块骨之间前后方向即被固定住。

       * 前交叉韧带断、后交叉韧带还好时，搬动小腿，小腿可向前移位。

       * 小腿向后移位，说明后交叉韧带撕裂。

       * 小腿前后都能移位，说明两根都断了。

   * **抽屉试验（drawer test）**

       * 让患者坐在凳上，大腿不动，用手搬动小腿。

       * 像拉抽屉一样，靠手感判断小腿能往前还是往后挪、挪多少，这是膝关节最常见的检查手段。

## 小腿骨与足骨的连接

### 胫腓骨的连接

   * **小腿骨连接**

       * 走行与前臂骨的连接类似：上方是关节连接，下方是韧带连接。

       * 前臂骨是上下都是关节连接，小腿骨则是一个关节、一个韧带带。

       * 两者之间还夹一层骨间膜，把胫骨与腓骨连在一起。

### 距小腿关节

   * **距小腿关节（talocrural joint，即踝关节）**

       * > **定义**：由胫骨下端、腓骨下端与距骨三块骨构成的关节，即通常所说的踝关节。

       * 命名依据：「距」指足的距骨，距骨上方有一个关节面称距骨滑车；胫骨与腓骨合称小腿骨，故称小腿。

       * 运动三组：向上为背屈，向下为跖屈，另参与内翻与外翻。

   * **内踝与外踝**

       * 胫骨下端为内踝，其下方有关节面；腓骨下端为外踝；前方有韧带把两者连着。

       * > **结论**：内踝与外踝两点之间的距离恒定，不随运动变化。

       * > **提示**：内踝高，外踝低。

   * **距骨**

       * 上面是距骨滑车面，下面接跟骨与跟结节，更往旁是舟骨、骰骨和第一、第二、第三楔骨。

       * 滑车面正好卡在胫腓两骨之间。

### 易内翻扭伤的结构原因

   * **距骨滑车面（trochlea of talus）**

       * 这块关节面前边略宽、后边比较窄。

       * 足跟着地即背屈时宽面进入两骨之间，关节间隙最小，最稳固。

       * 足尖着地即跖屈时窄面进来，骨与骨之间的空隙增大，不稳固，而此时全身重量都压在上面。

       * > **提示**：踝关节扭伤以下楼时最容易，因为下楼时足尖着地，宽面还没进来，窄面先塞进去了。

    距骨滑车面前宽后窄，两侧胫腓骨的间距恒定：

    ```text
            胫骨下端（内踝，高）      腓骨下端（外踝，低）
            ━━━━━━━━━━━━┓              ┃
            ┃           ┃              ┃
            ┃  距 骨    ┃══════════════╋ ← 前方韧带连接
            ┃ 滑 车 面  ┃  内、外踝间距恒定 ┃
            ┃ ██████████┃              ┃
            ┃ ██████    ┃              ┃
            ┗━━━━━━━━━━━┛              ┃
             前（宽）    后（窄）
    ```

   * **内翻受限机制**

       * 向外翻时外踝先撞上，关节活动的余地被它限死。

       * 往里倒时内踝这边没有东西挡着。

       * > **结论**：外踝比内踝低挡不住外翻，距骨滑车前宽后窄使足尖着地时处于松动状态，两条合起来就是「下楼崴脚必向内」的解剖学原因。

### 跗骨间、跖跖与跖趾关节

   * **跗骨间关节**

       * 由各跗骨之间形成的关节。

   * **跖跖关节**

       * 位于跗骨与跖骨之间，是跗骨间关节下方的那条缝。

   * **跖趾关节**

       * 位于跖骨与趾骨之间，是跖跖关节下方的那条缝。

   * > **结论**：踝关节以外的这些关节记住名称即可，其命名与手骨的命名相类似。

   * > **结论**：附肢骨的连接中，肩、肘、髋、膝这四大关节的构成、结构特点、运动以及损伤方向都要能讲清楚。
