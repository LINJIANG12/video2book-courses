# 周围神经系统·脑神经：纤维成分与分型、三叉神经、面神经、舌咽神经与迷走神经

## 脑神经的七种纤维成分

脊神经只有前根的两种运动成分加后根的两种感觉成分，共四种；脑神经一开口就是七种，多出的三种全由"特殊"二字带来。

* **一般躯体感觉纤维（general somatic afferent）**
    * > **定义**：传递头面部皮肤以及口腔、鼻腔黏膜的一般感觉。

* **特殊躯体感觉纤维（special somatic afferent）**
    * > **定义**：视觉、位置觉、听觉全归这一类，感官中的视、听与躯感因此混在一起。
    * 位置觉最容易被漏掉，记忆时须与听觉、视觉并列点出。

* **一般内脏感觉纤维（general visceral afferent）**
    * > **定义**：传递头、颈、胸、腹绝大多数脏器的感觉。

* **特殊内脏感觉纤维（special visceral afferent）**
    * > **定义**：只有舌的味觉和鼻黏膜的嗅觉两样东西。

* **一般躯体运动纤维（general somatic efferent）**
    * > **定义**：支配眼外肌和舌肌。

* **一般内脏运动纤维（general visceral efferent）**
    * > **定义**：支配头、颈、胸、腹部脏器的运动，本质就是副交感纤维，属于植物神经中的一种。

* **特殊内脏运动纤维（special visceral efferent）**
    * > **定义**：支配表情肌、咀嚼肌、咽喉肌，还包括胸锁乳突肌和斜方肌。

* > **易错点**：特殊内脏感觉是味觉加嗅觉，特殊内脏运动是表情肌、咀嚼肌、咽喉肌外加胸锁乳突肌和斜方肌，一个管感觉一个管运动，两组最容易互相串。

## 脑神经按成分性质分三型

十二对脑神经不是每对都把七种成分凑齐，有的只有单一成分，有的凑好几种。

* **单纯运动性脑神经**
    * 共三对：动眼神经、滑车神经、展神经。

* **单纯感觉性脑神经**
    * 纤维成分只有一种感觉成分。

* **混合性脑神经（mixed nerve）**
    * > **定义**：指一条神经里既有感觉成分又有运动成分的那种。
    * 混合性是本主题的重点，涵盖三叉神经与面神经。

* **逐条学习的三件事**
    * 知道它的纤维成分。
    * 重点记得它的分支名称和分布区。
    * 知道它从哪个孔出颅。
    * 神经具体走行路径留到实验课结合标本再讲，先把这三条框架记牢才有东西可对。

## 眼外肌的七块肌肉与总腱环

* **七块眼外肌**
    * 侧视视角：上方一个上直肌，下方一个下直肌，下方还有一个斜肌，上方也有一个斜肌叫上斜肌；外侧是外直肌，内侧是内直肌；还有一个到上睑去的肌肉叫提上睑肌。
    * 眶内后视视角：最中间是总腱环，上翘被切断的是上直肌，内侧被切断的是内直肌，下方是下直肌，外侧是外直肌——四个直肌；另有上斜肌和下斜肌，加提上睑肌共七个。

```text
                     上 直 肌
                        ↑
   上 斜 肌  ↖     ┌─────────┐     ↗  下 斜 肌
                   │ 总 腱 环 │
   内 直 肌  ←──────┤         ├──────→  外 直 肌
   （被切断）       └────┬────┘       （被切断）
                        ↓
                     下 直 肌
```

## 动眼神经、滑车神经、展神经

### 神经核位置与出入眶上裂

* **动眼神经（oculomotor nerve）**
    * 神经核：上丘水平的动眼神经核。
    * 出路：从脚间窝发出，经眶上裂进入眶腔。
    * 含两种运动成分：一般躯体运动纤维与一般内脏运动纤维（副交感，管瞳孔括约肌和睫状肌）。

* **滑车神经（trochlear nerve）**
    * 神经核：下丘水平的滑车神经核。
    * 出路：唯一在背侧出脑的脑神经，绕到腹侧后经眶上裂进入眶腔。

* **展神经（abducens nerve）**
    * 神经核：展神经核位于面丘的背深面。
    * 出路：从桥延沟发出，经眶上裂进入眶腔。

* **共同点**
    * 三者都属运动性脑神经，都经眶上裂入眶，眼球后面的走行一眼可从眶上裂这个点判断。

### 眼外肌的归属与上下支分工

| 脑神经 | 神经核位置 | 出颅部位 | 支配的眼外肌 |
| --- | :--- | :--- | :--- |
| 动眼神经 | 上丘水平的动眼神经核 | 脚间窝发出，经眶上裂入眶 | 上直肌、提上睑肌（下支管下斜肌、下直肌、内直肌） |
| 滑车神经 | 下丘水平的滑车神经核 | 背侧出脑，绕到腹侧，经眶上裂入眶 | 上斜肌 |
| 展神经 | 展神经核位于面丘背深面 | 桥延沟发出，经眶上裂入眶 | 外直肌 |

* **动眼神经的两支**
    * 上支管上直肌和提上睑肌，下支管下斜肌、下直肌、内直肌，合计五块。
    * 滑车神经只管上斜肌一块，展神经只管外直肌一块。
    * 七块眼外肌的账：动眼 5、滑车 1、展 1。

### 对光反射弧的通路

```text
视网膜 ──▶ 视神经 ──▶ 视交叉（鼻侧纤维交叉，颞侧不交叉）──▶ 视束
                                                                │
                                          ┌─────────────────────┴──────────┐
                                          ▼                                ▼
                                    外侧膝状体                     顶盖前区（换元）
                                                                           │
                                                                           ▼
                                                                     两侧动眼旁核
                                                                           │
                                副交感纤维随动眼神经一同出眶上裂，入眶后换元
                                                                           │
                                                                           ▼
                                                                  瞳孔括约肌、睫状肌
```

* **视网膜一侧**
    * 眼底内侧（鼻侧）的纤维交叉，外侧（颞侧）的不交叉。
    * 无论交叉还是不交叉，这两束都会各分出一个侧支到顶盖前区。

* **中继与传出**
    * 顶盖前区换元后走到两侧的动眼旁核。
    * 动眼旁核的纤维随动眼神经出来，入眶后交换神经元，再到瞳孔括约肌。

* **直接与间接的区分**
    * 把光打到左眼，双侧瞳孔都缩小。
    * 照到的那只眼瞳孔缩小叫直接对光反射，跟着缩小的另一只叫间接对光反射。

### 动眼神经损伤的临床表现

* **眼睑下垂**
    * 动眼神经管提上睑肌，提不上去，患侧眼睑垂下。

* **眼球斜向外下**
    * 所支配的五块眼外肌全瘫，剩下未瘫的只有外直肌和上斜肌。
    * 外直肌把黑眼球拉向外，上斜肌拉向外下，两者张力把黑眼球固定在斜向外下。

* **对光反射消失**
    * 直接打光刺激患侧，直接对光反射消失，间接的也出不来。
    * 把光挪到好眼上，好眼出现直接反射，患侧本该出现的间接反射照样出不来，因为回来的路还是那一条断掉的路。
    * 直接对光反射与间接对光反射全部消失。

## 三叉神经

### 两种成分与出脑膨大

* **一般躯体感觉纤维**
    * 管头面部的浅部感觉：痛觉、温觉、触觉、压觉。
    * 胞体在三叉神经半月节内，汇入三叉神经后上行，终止于三叉神经感觉核。

* **特殊内脏运动纤维**
    * 管咀嚼肌的运动。
    * 由三叉神经运动核发出，不经半月节换元，直接加入第三支下颌神经。

* **出脑与膨大**
    * 三叉神经在脑桥出脑，随即膨大成三叉神经半月节，眼神经、上颌神经、下颌神经三大支由此分出。
    * 三个叉为第一支眼神经、第二支上颌神经、第三支下颌神经。

* **出颅孔裂**
    * 眼神经出眶上裂，上颌神经出圆孔，下颌神经出卵圆孔，三个孔裂都在颅中窝。

* > **提示**：三叉神经整体是混合神经，但真正混合的只有第三支，眼神经和上颌神经都是纯感觉性的脑神经。

### 三支的出颅孔裂与感觉分布区

| 分支 | 出颅孔裂 | 感觉分布区 |
| --- | :--- | :--- |
| 第一支 眼神经 | 眶上裂 | 眼球、结膜、泪腺，一部分鼻黏膜；额部、顶部、上睑、鼻背的皮肤 |
| 第二支 上颌神经 | 圆孔 | 上颌的牙齿牙龈，口腔与鼻腔黏膜，硬脑膜；睑裂与口裂之间的皮肤 |
| 第三支 下颌神经 | 卵圆孔 | 下颌的牙齿牙龈，口腔黏膜，硬脑膜，舌前2/3黏膜；耳颞部与口裂以下的皮肤 |

* **感觉传导通路**
    * 三叉神经半月节是感觉纤维胞体所在，纤维汇入后上行终止于三叉神经感觉核。

* **运动纤维的归属**
    * 运动纤维由三叉神经运动核发出后直接加入第三支，奔咀嚼肌去，第二、三支之外的分支不带走运动成分。

### 头面皮肤的三分区与九条皮支

三个叉意味着头面部皮肤分成三个区，每区由三条皮支管理，合计九条。

* **第一区：鼻背，加上睑裂以上的额部和顶部皮肤**
    * 眶上神经从眶上缘往上走，管理额部皮肤。
    * 滑车上神经管理额部皮肤。
    * 滑车下神经到鼻背去。

* **第二区：睑裂与口裂之间的皮肤**
    * 眶下神经从眶腔下方的眶下孔出来。
    * 颧面支。
    * 颧颢支。

* **第三区：耳颞部、下颌以及口裂以下的皮肤**
    * 颏神经从颏孔出来。
    * 颊神经。
    * 耳颢神经。

```text
┌─────────────────────────────┐
│   鼻背 + 额部 + 顶部         │  第一支：眶上神经、滑车上神经、滑车下神经
├─────────────────────────────┤
│   睑裂 ↔ 口裂 之间           │  第二支：眶下神经、颧面支、颧颢支
├─────────────────────────────┤
│   耳颞部 + 下颌 + 口裂以下   │  第三支：颏神经、颊神经、耳颢神经
└─────────────────────────────┘
```

* **实验课用途**
    * 记牢这九条，实验课上对着标本辨认面部的皮支就有切入点。

## 面神经

### 四种纤维成分

面神经成分比三叉神经还多，共四种。

| 纤维成分 | 管什么 |
| --- | :--- |
| 特殊内脏运动 | 表情肌的运动 |
| 一般内脏运动 | 泪腺、舌下腺、下颌下腺的分泌（副交感） |
| 特殊内脏感觉 | 舌前 2/3 的味觉 |
| 一般躯体感觉 | 面部与耳部的本体感觉，也叫深感觉 |

* **管内与管外的成分分布**
    * 茎乳孔以上的管内段，四种纤维成分都有。
    * 茎乳孔以下的管外段只剩两种，多出来的两种恰恰是味觉和腺体分泌。

### 茎乳孔与颅内段、颅外段

* **出入颅部位**
    * 茎乳孔，位置在颅底，面神经管下方的管段从此钻出。

* **颅内段与颅外段的分界**
    * 茎乳孔以上的一段走在面神经管内，叫颅内段。
    * 茎乳孔以下的一段叫颅外段。
    * 面神经损伤按这条分界线分成管内损伤和管外损伤，两种症状完全不同。

* **副交感纤维的起点**
    * 管理腺体的这一路副交感纤维由上泌涎核发出，出面神经后分成两路走。

### 副交感纤维的两条路

```text
                            上泌涎核
                               │
                            面神经
                               │
        ┌──────────────────────┴───────────────────────┐
        │                                              │
   岩大神经                                     鼓  索
        │                                              │
   翼管神经                                          舌神经
        │                                              │
   翼腭神经节（换元）                            下颌下神经节（换元）
        │                                              │
   联络支 → 上颌神经                            下颌下腺、舌下腺
        │
   吻合支 → 泪腺神经 → 泪腺
```

* **第一条路管泪腺**
    * 上泌涎核纤维出面神经后先走岩大神经，再经翼管神经，到翼腭神经节换元。
    * 换元后通过联络支进入上颌神经，再由上颌神经的吻合支进入泪腺神经，最后到泪腺管理分泌。
    * 这一路中途借道三叉神经的上颌神经。

* **第二条路管唾液腺**
    * 另一部分纤维向下发出鼓索，鼓索进入舌神经，再在舌神经上走到下颌下神经节换元。
    * 换元后到达下颌下腺和舌下腺。
    * 这一路中途借道舌神经。

* > **易错点**：泪腺这一路要借道上颌神经，唾液腺这一路要借道舌神经，两条借道的路线不要记混。

### 运动纤维与所支配的肌肉

* **走行路线**
    * 运动纤维由面神经核发出，进入面神经后先到中耳鼓室。
    * 在鼓室内发出镫骨肌支，然后继续往下行，进入各分支。

* **所支配的肌肉清单**
    * 表情肌。
    * 茎突舌骨肌。
    * 二腹肌后腹。
    * 耳肌和枕肌。
    * 这一整套肌肉都由面神经核发出的纤维支配。

### 味觉与本体觉的两个终点

* **味觉通路**
    * 舌前 2/3 → 舌神经 → 鼓索 → 由鼓索进入面神经。
    * 胞体在神经节内，纤维进入孤束核的上半部，管味觉。

* **本体觉通路**
    * 携带面部和耳部肌肉的本体感觉，沿同一支上行。
    * 胞体同样在神经节内，纤维进入三叉神经脊束核。

* > **注意**：味觉终点是孤束核上半部，本体觉终点是三叉神经脊束核，两个终点不要串；孤束核在脑干图上分为上下两半，味觉占上半部。

### 管内损伤与管外损伤

| 表现 | 管内损伤 | 管外损伤 |
| --- | :--- | :--- |
| 面上运动 | 周围性面瘫 | 周围性面瘫 |
| 腺体分泌 | 障碍 | 正常 |
| 舌前 2/3 味觉 | 障碍 | 正常 |
| 角膜反射 | 消失 | 消失 |

* **管内损伤的四种表现**
    * 面上运动障碍：患侧没有抬头纹，闭眼时健侧能闭而患侧闭不上，患侧鼻唇沟浅，口角歪向健侧，还流口水，整个半张脸瘫，称面神经周围瘫即周围性面瘫。
    * 腺体分泌障碍：患侧泪腺、舌下腺、下颌下腺分泌出问题。
    * 味觉障碍：舌前 2/3 的味觉传不进来，患侧出现味觉障碍。
    * 角膜反射消失：用棉絮划角膜正常人立即闭眼，靠的是眼轮匝肌收缩；面神经损伤后眼轮匝肌不能收缩，角膜反射消失。

* **管外损伤的表现**
    * 只有面瘫和角膜反射消失两项。
    * 腺体分泌障碍和味觉障碍都不出现。

* > **易错点**：角膜反射在管内和管外损伤中都消失，不要因为它列在管内那栏就以为管外没事。角膜反射的传出靠眼轮匝肌，而眼轮匝肌无论管内管外都归面神经管，传出这一路断了反射就出不来。真正决定味觉和腺体分泌的是鼓索，鼓索在管内就分出去，管外损伤碰不到它，所以这两项安然无恙。

## 舌咽神经的纤维成分

* **舌咽神经**

    * > **定义**：混合性脑神经，而且不是普通的混合——运动、副交感、一般感觉、特殊感觉（味觉）、一般躯体感觉五种纤维成分凑齐，一个不少。

* **五种纤维成分的分工与核团**

| 纤维成分 | 管什么 / 管哪儿 | 相连核团 |
| --- | --- | --- |
| 特殊内脏运动纤维 | 茎突咽肌 | 疑核 |
| 一般内脏运动纤维（副交感） | 腮腺的分泌 | 下泌涎核 |
| 一般内脏感觉纤维 | 舌后 1/3、咽鼓管、鼓室的黏膜 | 孤束核**下半** |
| 特殊内脏感觉纤维 | 舌后 1/3 的味觉 | 孤束核**上半** |
| 一般躯体感觉纤维 | 耳后皮肤 | 三叉神经脊束核 |

* **孤束核的「一人两线」**

    * 舌后 1/3 的黏膜感觉与舌后 1/3 的味觉，功能完全不同、纤维成分也完全不同（前者 GVA，后者 SVA），但两条都送进孤束核。

    * 区别只在核团内部：感觉上去下半，味觉去上半。

    * > **易错点**：⚠️ 只记一句话就够——**孤束核上半味觉，下半一般内脏感觉**，别把两条线记反了。

## 舌咽神经的出入部位与神经节

* **颈静脉孔**

    * > **定义**：颅底的一个孔，舌咽神经、迷走神经、副神经都在这一块儿出入颅腔。

    * > **提示**：这一孔要连着记三根神经：舌咽、迷走、副神经。

* **与延髓的关系**

    * 舌咽神经与延髓相连，中脑水管后方是第四脑室，中脑后面有上丘、下丘。

* **下神经节与上神经节**

    * 舌咽神经出颅后形成两个神经节，感觉神经元的胞体在下神经节。

    * 一般躯体感觉这一条（耳后皮肤）的胞体在上神经节。

## 舌咽神经的分支分布

* **耳支**

    * 与迷走神经的耳支**合并**着走，分布到耳廓部。

* **鼓室支**

    * 钻进中耳鼓室，咽鼓管就在旁边连着。

    * 鼓室支续为岩小神经，再经耳神经节、耳颞神经到达腮腺。

    * 耳神经节还与下颌神经相联系。

* **咽支**

    * 分布到咽部黏膜与咽肌（茎突咽肌）。

* **舌支**

    * 只管舌后 1/3。

* **窦支**

    * 分布到颈动脉窦（压力感受器）与颈动脉体（化学感受器）。

    * > **定义**：颈动脉窦是颈内动脉根部膨大处的感受器，颈动脉体是米粒状的小体；一大一小两个加起来就是化学感受器与压力感受器。

    * > **提示**：这两个感受器位于颈外动脉与颈内动脉交叉的部位，它们的传入走的就是窦支。

---

## 舌咽神经五种成分的核团归属

* **疑核**

    * 发出特殊内脏运动纤维，经咽支到达茎突咽肌，管咽与茎突咽肌的运动。

* **下泌涎核（副交感至腮腺，路径特别绕）**

    ```text
      下泌涎核
          │  副交感纤维
          ▼
        舌咽神经 ──→ 加入迷走神经
                        │
                        ▼
                    鼓室支 ──→ 鼓室
                                  │
                                  ▼
                            岩小神经
                                  │
                                  ▼
                            耳神经节  ← 在这里交换神经元（成为节后）
                                  │
                                  ▼
                              耳颞神经
                                  │
                                  ▼
                                腮腺
    ```

* **孤束核下半（一般内脏感觉）**

    * 接收的传入分几股：舌后 1/3 的黏膜感觉、咽部黏膜的感觉，以及窦支带回来的压力感受器与化学感受器。

    * 咽鼓管的感觉、鼓室的感觉也都归孤束核下半。

    * 传入纤维胞体在下神经节，中央突进脑干后到孤束核下半。

* **孤束核上半（特殊内脏感觉）**

    * 舌后 1/3 的味觉，胞体同样在下神经节，进脑干后直奔孤束核上半。

    * 板书上用虚线把它与舌后 1/3 黏膜的一般感觉区分开。

* **三叉神经脊束核（一般躯体感觉）**

    * 耳后皮肤的传入直接入核，不绕弯。

    * > **提示**：舌咽、迷走这些脑神经带来的一般躯体感觉，一律投到**三叉神经脊束核**，记的时候只抓「脊束核」这三个字。

* **三叉神经感觉核的三部分**

    * 中脑里的叫中脑核，脑桥里的叫脑桥核，延髓里的这一段叫脊束核。

    * 脑神经带来的一般躯体感觉投到的是最下面那一段（脊束核），不是中脑核，不是脑桥核。

---

## 迷走神经的纤维成分与出入部位

* **迷走神经**

    * > **定义**：混合型脑神经，含四种纤维成分；是十二对脑神经中形成最远、分布最广的一个。

* **四种纤维成分的分工与核团**

| 纤维成分 | 管什么 / 管哪儿 | 相连核团 |
| --- | --- | --- |
| 一般内脏运动纤维 | 平滑肌、心肌以及一些腺体的分泌 | 迷走神经背核 |
| 特殊内脏运动纤维 | 咽喉肌的运动 | 疑核 |
| 一般内脏感觉纤维 | 头、颈、胸、腹脏器的感觉 | 孤束核下半 |
| 一般躯体感觉纤维 | 耳廓皮肤、外耳道、硬脑膜 | 三叉神经脊束核 |

* **迷走神经背核**

    * 位于延髓里，是最大的一个副交感核团。

* **疑核的共用**

    * 迷走神经的特殊内脏运动纤维挂的仍然是疑核，与舌咽神经是同一个核。

    * 舌咽和迷走这两根神经在「管咽喉肌」这件事上，是从同一个核团出发的。

* **出入部位**

    * 同样经颈静脉孔出入脑，与舌咽神经是同一个门。

---

## 迷走神经的分支分布

* **按颈、胸、腹三段展开**

    ```text
      延髓
       │
       ├── 颈 部 ──┬── 脑膜支    → 颅后窝的硬脑膜
       │           ├── 耳 支     → 耳廓皮肤、外耳道
       │           ├── 喉上神经  → 感觉：声门裂以上的黏膜 → 孤束核下半
       │           │              运动：环甲肌        ← 疑核
       │           ├── 咽  支    → 感觉：咽部黏膜      → 孤束核下半
       │           │              运动：咽缩肌、软腭肌 ← 疑核
       │           └── 颈心支    → 心丛
       │
       ├── 胸 部 ──┬── 喉返神经  → 感觉：声门裂以下的黏膜 → 孤束核下半
       │           │              运动：除环甲肌以外大部分喉肌 ← 疑核
       │           ├── 食管支    → 食管丛
       │           └── 支气管支  → 肺丛
       │
       └── 腹 部 ──┬── 胃前支（前干）、胃后支（后干） → 胃
                   └── 肝丛、腹腔丛 → 肝、胆、胰、脾、肾、脾曲以上的消化管
                            ↑ 相连核团：迷走神经背核
    ```

### 颈部

* **脑膜支**

    * 到颅后窝这一部分的硬脑膜。

    * 属感觉支，终止于三叉神经脊束核。

* **耳支**

    * 主要分布到耳廓皮肤、外耳道这两部分皮肤。

    * 属感觉支，同样终止于三叉神经脊束核。

* **喉上神经**

    * 含两种纤维：感觉纤维管理声门裂以上的黏膜，到孤束核下半；运动纤维管理环甲肌，来自疑核。

* **咽支**

    * 感觉：咽部黏膜的感觉到孤束核。

    * 运动：咽缩肌、软腭肌这一部分肌肉，由疑核来的纤维管运动。

* **颈心支**

    * 这几支总称叫颈心支，由它们形成心丛，管心脏的运动与活动。

    * 纤维来自迷走神经背核。

### 胸部

* **喉返神经（胸部的重点）**

    * 感觉纤维管理声门裂以下的黏膜，到孤束核下半。

    * 运动纤维管除环甲肌以外的大部分喉肌，来自疑核。

* **食管支**

    * 形成食管丛到食管。

* **支气管支**

    * 形成肺丛到肺。

* > **易错点**：⚠️ 这组对比一定要成对记——**环甲肌、声门裂以上归喉上神经；环甲肌以外的喉肌、声门裂以下归喉返神经**。两句话的运动纤维都从疑核出发，但神经不同，理由是支配的肌肉不同。凡是看到「喉返神经管喉肌」，第一反应就该加一句「除了环甲肌」。

### 腹部

* **腹部分布的总特点**

    * 腹部神经都是以神经丛的形式分布到脏器，唯独胃是以神经干来分布。

* **胃前支与胃后支**

    * 左右迷走神经所发出的前支和后支，到胃去了。

* **肝丛与腹腔丛**

    * 从胃再向下就看不到神经干了，看到的是神经丛，肉眼已经很难看出它的主干。

    * 肝丛、腹腔丛分布到肝、胆、胰、脾、肾，以及脾曲以上的消化管（升结肠、横结肠在此截止）。

* **纤维来源**

    * > **结论**：腹部这几条支的纤维来源是同一个——**迷走神经背核**。

## 舌咽神经与迷走神经的对照

| 对照项 | 舌咽神经 | 迷走神经 |
| --- | --- | --- |
| 性质 | 混合神经 | 混合型脑神经 |
| 纤维成分 | 五种，含特殊内脏感觉（味觉） | 四种 |
| 出入部位 | 颈静脉孔 | 颈静脉孔（同一个门） |
| 特殊内脏运动核团 | 疑核 | 疑核（与舌咽同一个核） |
| 分布范围 | 活动范围基本不出头颈 | 十二对中形成最远、分布最广，从颅底一直走到肝、胆、胰、脾、肾 |
| 腹部形态 | 长文未说明 | 唯独胃以神经干（前支、后支）分布，其余为神经丛 |
| 耳部分支 | 耳支与迷走神经耳支合并到耳廓 | 耳支单独分布到耳廓皮肤、外耳道 |

## 十二对脑神经的学习分工

* **单纯运动性脑神经**

    * 动眼神经、滑车神经、展神经，这三个是单纯运动的。

* **混合性脑神经**

    * 三叉神经、面神经、舌咽神经、迷走神经属于混合性。

* **理论课与实验课的分工**

    * 理论课重点讲主要分支和纤维的分布情况，要求记熟「有哪些支、到哪儿去」。

    * 实验课重点讲神经干的走行与关系，看「这根神经在标本上从哪儿经过」。

    * 两件事正好接得上。
