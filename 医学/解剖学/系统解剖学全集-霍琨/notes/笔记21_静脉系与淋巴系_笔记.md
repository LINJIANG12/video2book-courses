# 静脉系与淋巴系

## 肺循环的静脉

* **肺静脉（pulmonary veins）**

    * > **定义**：位于心脏底部的一对大血管，把肺内经气体交换后变成动脉血的血液引回心房。

    * 左、右肺静脉分别由同侧的肺上静脉与肺下静脉汇出。

    * 肺动脉的血液经肺门进入肺，在肺内由动脉血换成静脉血，再由这两对肺静脉回收。

    * 肺静脉把动脉血带回的心腔是左心房。

    * > **易错点**：⚠️ 肺循环中「动脉」「静脉」按血流方向命名，不按血液含氧量命名。肺动脉从心室流向肺，装的是静脉血；肺静脉从肺流回心房，装的是动脉血。名字跟着方向走，血液成分跟着肺毛细血管走。

* **心脏底部大血管的方位**

    * 心脏底部上方为肺动脉干，其后为主动脉。

    * 右侧自上而下为上腔静脉、右心房、下腔静脉。

    * 心脏膈面另有一根细小的奇静脉，向上注入上腔静脉的后壁。

```text
                肺动脉干            主动脉
                   │                  │
           ┌───────┴──────┐           │
         右肺静脉       左肺静脉       │
           └───────┬──────┘           │
                   │                  │
                   └────→ 左心房 ←────┘
                         （动脉血）

      上腔静脉 ──→ 右心房        下腔静脉 ──→ 右心房
      奇静脉  ：位于心脏膈面，向上注入上腔静脉的后壁
```

## 体循环静脉的系统划分

* **体循环静脉的三套系统**

    * 上腔静脉系。

    * 下腔静脉系。

    * 心静脉系：心脏的静脉最后经冠状窦注入右心房，此处不再展开。

* **属支（tributary）**

    * > **定义**：静脉血流方向与动脉相反，先分支、再汇成主干，凡汇入主干的支统称属支；动脉则相反，是由主干到分支的分支关系。

---

## 上腔静脉系的收纳范围与合成

* **上腔静脉系（system of superior vena cava）**

    * > **定义**：收集头颈、胸部和上肢静脉血的静脉系统。

    * 由左、右头臂静脉汇合而成。

    * 头臂静脉由颈内静脉与锁骨下静脉汇合以后形成。

    * 属支只须记住奇静脉一个名字，它注入上腔静脉的后壁。

```text
      颈内静脉 ┐
               ├→ 头臂静脉 → 上腔静脉 → 右心房
   锁骨下静脉 ┘                    ↑
                              奇静脉注入后壁
```

## 头颈部的解剖标志

* **颈部骨性标志**

    * 主要标志为颏、喉结、下颌角、耳廓。

    * 喉结由甲状软骨形成。

    * 甲状软骨下方是环状软骨，环状软骨下边是气管。

    * > **注意**：甲状软骨与环状软骨之间有一层环甲膜，急性喉阻塞的患者可以在这里做穿刺。

* **甲状腺**

    * 在上述区域还有一个腺体，即甲状腺。

    * 它的甲状腺上静脉、甲状腺中静脉均汇入颈内静脉。

## 颈内静脉与颈外静脉

* **颈内静脉（internal jugular vein）**

    * > **定义**：在颅底颈静脉孔处由颅内硬脑膜窦汇合形成、承担头颈静脉血回收的主干静脉。

    * 由乙状窦与颅底岩下窦汇聚形成。

    * 位于颈血管鞘内，与颈内动脉伴行。

    * 属支共六条：下颌后静脉前支、面静脉、舌静脉、咽静脉、甲状腺上静脉、甲状腺中静脉。

    * 面静脉来自口角与鼻翼一侧；舌静脉与咽静脉汇成短干。

    * 回收范围自下而上依次为下颌后静脉前支、面静脉、舌静脉与咽静脉、甲状腺上静脉、甲状腺中静脉。

```text
  乙状窦 ┐
         ├→ 颈内静脉（在颈血管鞘内，与颈内动脉伴行）
  岩下窦 ┘
         ↑
   下颌后静脉前支 ←─ 颞浅静脉 + 上颌静脉 = 下颌后静脉
   面静脉        ←─ 口角、鼻翼一侧
   舌静脉、咽静脉  ←─ 汇成短干
   甲状腺上静脉
   甲状腺中静脉
```

* **下颌后静脉（posterior mandibular vein）**

    * > **定义**：颞浅静脉与上颌静脉汇合后形成的静脉，出下颌角处再分为前支与后支。

    * 前支汇入颈内静脉。

    * 后支汇入颈外静脉。

    * > **易错点**：⚠️ 下颌后静脉前支归颈内静脉、后支归颈外静脉，这一处分叉最容易记混。

* **颈外静脉（external jugular vein）**

    * > **定义**：走行于胸锁乳突肌前面的浅静脉，由耳后静脉与枕静脉会合形成，注入锁骨下静脉。

    * 属于浅静脉，不在颈血管鞘内，也不与动脉伴行——这与颈内静脉正好相反。

    * 属支三个：耳后静脉、枕静脉、下颌后静脉后支。

* **静脉角（venous angle）**

    * > **定义**：颈内静脉与锁骨下静脉汇合处形成的交角。

    * 全身淋巴液最后通过左、右两条淋巴导管汇入左、右静脉角，进入静脉血。

## 上肢的静脉

* **上肢深静脉**

    * 与同名动脉伴行，有什么动脉就有相应的静脉。

    * 例：上臂的动脉称肱动脉，其伴行静脉即肱静脉。

* **手背静脉网（dorsal venous network of hand）**

    * > **定义**：位于手背部的静脉网，是上肢三条浅静脉的共同起点。

    * 桡侧的一支续为头静脉。

    * 尺侧的一支续为贵要静脉。

* **头静脉（cephalic vein）**

    * 由手背静脉网桡侧起始。

    * 走行于前臂桡侧，再沿臂的外侧上升。

    * 在三角肌与胸大肌之间穿深筋膜，汇入深层的腋静脉或锁骨下静脉。

* **贵要静脉（basilic vein）**

    * 由手背静脉网尺侧起始。

    * 走行于前臂尺侧，再沿臂的内侧上升。

    * 在臂中点穿深筋膜，汇入同部位的深静脉，即肱静脉。

* **肘正中静脉（median cubital vein）**

    * > **定义**：头静脉与贵要静脉之间的吻合支。

    * 前臂另有一条正中静脉，不在掌握范围内。

```text
  手背静脉网
      │
      ├── 桡侧起 → 头静脉
      │     前臂桡侧 → 臂外侧 → 三角肌与胸大肌之间穿深筋膜
      │     → 腋静脉 / 锁骨下静脉
      │
      └── 尺侧起 → 贵要静脉
            前臂尺侧 → 臂内侧 → 臂中点穿深筋膜 → 肱静脉
            （动脉叫肱动脉，静脉就该叫肱静脉）

       头静脉 ←── 肘正中静脉（吻合支） ──→ 贵要静脉
       另有一条前臂正中静脉，不用管它
```

## 胸壁的静脉

* **奇静脉（azygos vein）**

    * > **定义**：在脊柱右侧上升、注入上腔静脉后壁的静脉。

    * 回收右侧胸部的静脉血。

    * 身份是上腔静脉的属支。

* **半奇静脉（hemiazygos vein）**

    * 沿脊柱左侧上行。

    * 通过吻合支汇入奇静脉。

* **副半奇静脉（accessory hemiazygos vein）**

    * 沿脊柱左侧上行，作为小支汇入半奇静脉。

* **胸部静脉血回收的构成**

    * 奇静脉、半奇静脉、副半奇静脉三者共同承担胸部静脉血的回收。

    * 三者最终都经奇静脉注入上腔静脉。

## 下腔静脉系的合成与位置

* **下腔静脉（inferior vena cava）**

    * > **定义**：由左、右髂总静脉在第4腰椎与第5腰椎之间汇集而成的粗大静脉干，回收下半身静脉血。

    * 上端位于腔静脉裂孔，下端在第4、5腰椎之间，整个主干走在脊柱的左前方。

    * 起始处由左、右髂总静脉汇合而成；髂总静脉再向下分为髂内静脉与髂外静脉，髂外静脉通往盆腔。

    * 属支按走行分为壁支与脏支两类。

---

## 腹部的动静脉配部关系

* **同一高度动静脉分支的对照**

    * 腹主动脉比下腔静脉短，到第4腰椎动脉才开始分叉，分出左、右髂总动脉。

    * 静脉在同一高度发出的属支与动脉分支的对应关系如下。

| 高度（由上而下） | 动脉 | 静脉 |
| :--- | :--- | :--- |
| 膈肌下 | 膈下动脉（向上的一支） | 膈下静脉（成对） |
| 稍下 | 腹腔干（1 cm 短干） | — |
| 肾上腺水平 | 肾上腺中动脉（左右发出） | 肝静脉（3 支，不成对） |
| 再下 | 肠系膜上动脉 | 肾上腺静脉 |
| 肾水平 | 肾动脉（左右成对） | 肾静脉、肠系膜下动脉对应段 |
| 睾丸水平 | 睾丸动脉（左右成对） | 睾丸静脉 |
| 最下 | 骶正中动脉 | 骶正中静脉、左右髂总静脉 |

* **配部关系中唯一的不对称处**

    * > **易错点**：⚠️ 肾上腺是表里唯一对不上的地方：动脉侧为肾上腺中动脉，左右各发一支；静脉侧明显不对称，肾上腺静脉是在肾静脉那个高度才汇入的，因此左右不一致。

    * 这一不对称正好与下腔静脉成对脏支的左右差异接上。

---

## 下腔静脉的壁支

* **膈下静脉（inferior phrenic vein）**

    * 与膈下动脉上下对应。

* **腰升静脉（ascending lumbar vein，又称髂腰静脉）**

    * 沿脊柱两侧上行。

    * 回收四个腰静脉。

* **骶正中静脉（median sacral vein）**

    * 骶正中静脉同属壁支。

    * 与骶正中动脉对应，同在配部表的最下一行。

---

## 下腔静脉的成对脏支

* **肾上腺静脉（adrenal vein）**

    * 左右回流方式不一致。

    * 右侧起自主干，直接汇入下腔静脉。

    * 左侧汇入肾静脉。

* **肾静脉（renal vein）**

    * 成对发出，汇入下腔静脉。

    * 左侧肾上腺静脉汇入左侧肾静脉。

* **睾丸静脉（testicular vein）**

    * > **定义**：左右回流路径显著不同的成对脏支，女性相应血管称卵巢静脉。

    * 右侧与同名动脉伴行，直接汇入下腔静脉主干。

    * 左侧汇入肾静脉，且呈直角汇入，然后再汇入下腔静脉。

    * > **结论**：左侧回流阻力大于右侧——一侧路径短而直达主干，另一侧要多绕一道、还以直角汇入肾静脉——因此左侧精索静脉曲张多于右侧。

---

## 下腔静脉的不成对脏支

* **肝静脉（hepatic veins）**

    * 3 支，是位置最高的不成对脏支，汇入下腔静脉。

    * > **定义**：第二肝门指肝的三条肝静脉在腔静脉窝汇入下腔静脉的部位。

* **肝门静脉（portal vein）**

    * 属不成对的脏支，因本身重要而单独提出，称之为肝门静脉系。

    * 归属上仍属于下腔静脉系。

---

## 肝门静脉系的特点

* **肝门静脉系（portal venous system）**

    * > **定义**：由肝门静脉及其属支组成的静脉系统，起端和终止端都是毛细血管。

    * 特点一：两端都是毛细血管，因而血流缓慢。

    * 特点二：静脉内没有静脉瓣，血液可以逆流。

    * 归属上属于下腔静脉系，只因重要才单列。

    * > **注意**：血液可逆流这一条，是理解门腔静脉吻合途径与门脉高压全部临床表现的前提。

---

## 肝门静脉的合成与属支

* **肝门静脉（portal vein）**

    * 合成：肠系膜上静脉与脾静脉汇聚，形成一个短干，即肝门静脉。

    * 行程：由该短干分为右支与左支进入肝脏。

    * 属支包括肠系膜上静脉、肠系膜下静脉、脾静脉、胃左静脉、胃右静脉、胃网膜左静脉、胃网膜右静脉、附脐静脉。

    * 胃左静脉与胃右静脉在胃小弯侧相吻合。

    * 胃网膜左静脉从脾静脉发出，与胃网膜右静脉相吻合。

    * 附脐静脉汇到脐部。

```text
                    肝门静脉 → 右支 / 左支 → 肝
                   ╱          │
        肠系膜上静脉          │   胃左静脉 ─┐
              │               │   胃右静脉 ─┴─ 胃小弯侧吻合
              │               │   胃网膜左静脉┐
        肠系膜下静脉 ─── 脾静脉 ┴─ 胃网膜右静脉┴─ 吻合
                                   │
                                   └─ 附脐静脉 → 脐部
```

## 门腔静脉的吻合途径

* **三条吻合途径**

    * > **定义**：门静脉系与腔静脉系之间存在的三条血流通道；因门静脉无静脉瓣，门静脉血可经吻合支逆向进入腔静脉系。

    * 第一条：门静脉 → 胃左静脉 → 食管静脉丛 → 奇静脉 → 上腔静脉，是最简单的一条。

    * 第二条：门静脉 → 脾静脉或肠系膜上静脉 → 肠系膜下静脉 → 直肠上静脉 → 直肠静脉丛 → 直肠下静脉 → 髂内静脉 → 髂总静脉 → 下腔静脉。

    * 第三条：门静脉 → 附脐静脉 → 脐周静脉网，再分为上行与下行两支。

    * 第三条的上行支：脐周静脉网 → 胸腹壁浅静脉或深静脉、胸腹臂浅静脉 → 腋静脉或锁骨下静脉 → 头臂静脉 → 上腔静脉。

    * 第三条的下行支：脐周静脉网 → 腹壁深静脉 → 髂外静脉；或腹壁浅静脉 → 大隐静脉 → 股静脉 → 髂外静脉 → 髂总静脉 → 下腔静脉。

```text
  门静脉系（无静脉瓣，血液可以逆流）
        │
        ├─ 路1 胃左静脉 → 食管静脉丛 → 奇静脉 → 上腔静脉
        │      （最简单的一条）
        │
        ├─ 路2 脾静脉 / 肠系膜上静脉 → 肠系膜下静脉 → 直肠上静脉
        │      → 直肠静脉丛 → 直肠下静脉 → 髂内 → 髂总 → 下腔静脉
        │
        └─ 路3 附脐静脉 → 脐周静脉网
                 ├─ 上行：胸腹壁浅/深静脉、胸腹臂浅静脉
                 │        → 腋静脉 / 锁骨下静脉 → 头臂静脉 → 上腔静脉
                 └─ 下行：腹壁深静脉 → 髂外静脉
                          腹壁浅静脉 → 大隐静脉 → 股静脉
                          → 髂外 → 髂总 → 下腔静脉
```

## 门脉高压的血液去向与临床后果

* **门脉高压的形成**

    * > **定义**：肝硬化后肝脏变硬变小，门静脉血进入肝脏的阻力增大，血流被迫经吻合支分流。

    * 记住「血往哪儿挤、哪儿就出问题」这条因果链，比死背症状列表更可靠。

* **血液逆流入脾静脉——脾大**

    * 血液逆流进入脾静脉，随即进入脾脏。

    * 脾有丰富的血窦，血流淤积使脾体积增大。

    * 正常人脾脏在肋弓下摸不到，脾大后可以摸到。

    * 脾有三个切迹，是判断脾的标志，必须记住。

* **血液进入肠系膜上静脉——腹水**

    * 血液进入肠系膜上静脉后，就进入了小肠静脉系统。

    * 大量血液涌入小肠，患者出现消瘦、不能平卧、肚子变大，即腹水。

* **血液涌入胃左静脉——呕血**

    * 血液大量涌入胃左静脉，使食管静脉丛内血量过多而曲张。

    * 进食粗糙食物等机械刺激可划破曲张的食管静脉丛，产生呕血。

* **血液经肠系膜下静脉——便血**

    * 门脉血进入肠系膜下静脉，汇聚于直肠静脉丛。

    * 便秘时用力排便，可使直肠静脉丛破裂而产生便血。

* **血液经附脐静脉——腹壁静脉曲张**

    * 血液经附脐静脉进入脐周静脉网，导致腹壁静脉曲张。

    * 曲张的腹壁静脉形如海蛇头，临床称海蛇头。

> **注意**：这些表现是肝硬化晚期可能出现的，并不是同一个患者身上都会出现。

## 淋巴系

* **淋巴系（lymphatic system）**
    * > **定义**：由淋巴管道、淋巴组织、淋巴器官三大部分组成。
    * 重点在于淋巴液：它的生成与回流其实是同一件事的两头。
    * 功能只有两个——协助静脉血回流、免疫。
    * 静脉血的回流不是静脉自己单独完成的，淋巴系把一部分物质带回来，是静脉血回流的辅助路。

## 淋巴液的生成与回流

* **组织液（tissue fluid）**
    * 心脏经各级动脉把血液送到毛细血管动脉端，血浆成分从毛细血管壁渗出到组织间隙中，成为组织液。
    * 组织细胞从组织液中吸收营养成分、排出代谢产物。
    * 组织液中的代谢产物按能否透过毛细血管壁分成两拨。

* **代谢产物的两条出路**
    * 小分子代谢产物：直接透过毛细血管壁回到毛细血管静脉端，随各级静脉回到心脏，是静脉回流的常规通路。
    * 大分子代谢产物：难以透过毛细血管壁，只能走进毛细淋巴管。

* **毛细淋巴管（capillary lymphatic vessel）**
    * > **定义**：末端呈盲端的管道，深深嵌在毛细血管之间。
    * 盲端 + 位于毛细血管丛中的位置，使挤不过毛细血管壁的大分子物质一挪就能进入。
    * 进入毛细淋巴管的液体即为淋巴液。

* **淋巴液（lymph）**
    * > **定义**：大分子的代谢产物进入毛细淋巴管，即成为淋巴液。
    * 回流路径：淋巴管道 → 静脉 → 心脏。
    * > **注意**：回流终点不是直接回心脏，而是先汇入静脉——这是理解淋巴系全部功能的钥匙。
    * > **易错点**：⚠️ 淋巴液最终汇入静脉这一条与临床直接相关，不能写成"回流心脏"。

```text
   心脏 ──各级动脉──► 毛细血管动脉端 ══ 毛细血管静脉端 ══ 各级静脉 ══► 心脏
                         │  渗出
                         ▼
                      组织液（组织间隙内）
                         │  组织细胞吸收营养，排出代谢产物
                         ▼
              ┌──────────┴───────────┐
              ▼                      ▼
        小分子代谢产物           大分子代谢产物
              │                      │  难以透过毛细血管壁
              │ 直接透过管壁          ▼
              │                 毛细淋巴管（末端盲端）
              │                      │  淋巴管 → 淋巴干 → 淋巴导管
              ▼                      ▼
      毛细血管静脉端 ◄─────────  静脉角 ──► 静脉 ──► 心脏
```

* **静脉角（venous angle）**
    * 淋巴导管的最终汇入部位，左右各一。
    * 名称用于区分左右：胸导管注入左侧静脉角，右淋巴导管位于右侧静脉角。
    * 静脉角的具体构成，长文未说明。

## 淋巴管道的四级

* **淋巴管道（lymphatic vessels）**
    * > **定义**：由毛细淋巴管、淋巴管、淋巴干、淋巴导管四级构成，数量由多变少、越聚越粗，道理与静脉相同。
    * 数量递减的线索是本主题最该记住的内容。

| 级别 | 名称 | 数量与特点 |
| :--- | :--- | :--- |
| 一级 | 毛细淋巴管 | 末端呈盲端，嵌在毛细血管之间 |
| 二级 | 淋巴管 | 数量相当庞大 |
| 三级 | 淋巴干 | 全身 9 条 |
| 四级 | 淋巴导管 | 全身 2 条 |

* **各级过渡关系**
    * 毛细淋巴管到处都有，数量最多。
    * 汇聚成淋巴干时只剩 9 条，淋巴干起汇聚作用。
    * 9 条淋巴干再汇入淋巴导管，淋巴导管全身只有 2 条。

```text
   毛细淋巴管  ──►  淋巴管  ──►  淋巴干  ──►  淋巴导管
     一级          二级         9 条         2 条
   末端盲端      数量庞大        汇聚         汇入静脉
    ①──②──③──④──⑤──⑥──⑦──⑧──⑨──╳
```

## 胸导管

* **胸导管（thoracic duct）**
    * > **定义**：淋巴导管全身 2 条中的一条，另一个名字叫左淋巴导管。
    * 起始于第 1 腰椎水平，穿越膈肌入胸，终点为左侧静脉角。
    * 全身 9 条淋巴干中接收 6 条，**全身大部分淋巴液由胸导管汇入静脉**。

### 胸导管的定位参照结构

* **上腔静脉（superior vena cava）**
    * 颈内静脉与锁骨下静脉合成一头臂静脉。
    * 两侧头臂静脉再汇集成一个主干，该主干即上腔静脉。
    * 上腔静脉在肺根后方有一个重要属支——奇静脉。

* **奇静脉系**
    * 奇静脉是上腔静脉在肺根后方的属支。
    * 奇静脉在第 8 胸椎高度接受半奇静脉，旁边还有一条副半奇静脉。

* **气管与食管**
    * 主动脉下方发出左主支气管，右边是右主支气管，两个主支气管向上汇聚成气管。
    * 气管后方还有一个管道，略微偏左，叫食管。

* **主动脉（aorta）**
    * 与上腔静脉伴行。
    * 主动脉画全了是逐渐向正中线靠拢的。

* **膈肌的裂孔**
    * 膈肌下方的两个角围成食管裂孔。
    * 另有主动脉裂孔与腔静脉裂孔，主动脉从主动脉裂孔穿出。

### 胸导管的行径

* **起点**
    * 第 1 腰椎水平有一块梭形膨大，称乳糜池。
    * 胸导管从乳糜池发出。

* **行径三要点**
    * 穿孔：穿过主动脉裂孔，进入胸腔。
    * 找路标：在胸主动脉与奇静脉之间上行，图上定位就到这两个结构中间去找。
    * 转弯：约到第 5 胸椎水平，在食管与脊柱之间斜行向左。
    * 终点：注入左侧静脉角。

```text
        第 1 腰椎水平
      ┌────────────┐
      │   乳糜池    │ ◄── 胸导管起于此
      └─────┬──────┘
            │  穿过主动脉裂孔 → 入胸
      ══════╪══════  膈肌
            │
     胸主动脉│奇静脉      ◄── 在两者之间上行
            │
     第 5 胸椎水平：在食管与脊柱之间斜行向左
            │
            └──────────►  左静脉角
```

* **胸导管收进的六条淋巴干**
    * 分布规律：起始部 3 条，终止部 3 条。
    * 起始部为向上汇入的干，终止部为在末端汇入的干。

| 部位 | 淋巴干 | 汇集来源 |
| :--- | :--- | :--- |
| 起始部 | 左腰干、右腰干 | 下肢 |
| 起始部 | 肠干 | 腹腔 |
| 终止部 | 颈干 | 头颈部 |
| 终止部 | 锁骨下干 | 上肢 |
| 终止部 | 支气管纵隔干 | 胸腔 |

* **腰干与肠干**
    * 腰干左右各一条、彼此对称，来自下肢的淋巴液。
    * 肠干为居中的单条，来自腹腔的淋巴液。

## 右淋巴导管

* **右淋巴导管（right lymphatic duct）**
    * > **定义**：淋巴导管全身 2 条中的另一条，是一个厘米的短干，就在右侧静脉角。
    * 与胸导管完全不是一个量级，长度很短。
    * 只接收 3 条淋巴干，即 9 条中剩下的 3 条：右侧颈干、右侧锁骨下干、右侧支气管纵隔干。

* **两条导管的干互补**
    * 胸导管收 6 条（起始部 3 条 + 终止部 3 条），右淋巴导管收 3 条，合计 9 条。
    * 两管收的淋巴干名称完全相同，靠前缀区分左右。
    * > **易错点**：⚠️ 胸导管的颈干、锁骨下干、支气管纵隔干在图上要注明是**左侧**的；右淋巴导管那三条名称前统统要加**右侧**。名称一样，只靠前缀区分，极易写混。

## 淋巴器官

* **淋巴器官（lymphatic organs）**
    * 包括淋巴结、胸腺、扁桃体、脾。
    * 其中脾是最大的一个淋巴器官，需掌握位置、形态、功能及固定装置。
    * 在整个脉管系统中，淋巴系属配角，构造上不需展开太细，达到了解的程度即可。
    * 两条必须留下的要点：淋巴液最终汇入静脉；脾因肝硬化门脉高压而肿大——均直接连着临床。

## 脾

* **脾（spleen）**
    * > **定义**：最大的淋巴器官，位于左季肋区，靠 4 条韧带固定于该位置。

### 脾的位置

* **定位标志**
    * 腹部分成 9 个区，脾位于左季肋区。
    * 侧面看位于第 9～11 肋之间。
    * 脾是长形器官，长轴与第 10 肋平行。

* **肋弓关系**
    * 脾在肋弓的里面。
    * 正常人的脾脏在肋弓下是触不到的。
    * 触诊定位的逻辑：正常人肋弓下摸不到，只有病态脾肿大、从肋弓下露出时才能触及。

### 脾的形态

* **外形与命名规律**
    * 颜色为暗红色。
    * 外侧面可见前缘和后缘，内侧面位置与外面相对应。
    * 上下叫端（前有上端、后有下端），前后叫缘（前缘、后缘），内外叫面（外侧面、内侧面）。

* **脾切迹（notch）**
    * 位于脾的前缘，共 2～3 个。
    * 临床意义：触摸脾脏、判断是否为脾脏的标志——摸到脾切迹即可肯定为脾脏。

* **脾门（hilum）**
    * 位于内侧面中部凹陷处，该处有血管、神经、淋巴出入。

* **肝脾共性**
    * 肝脏与脾脏的共同特点是质软而脆，遇暴力后容易破裂。
    * 腹部脏器的破裂多见于肝和脾。

### 脾的功能

* **储血**
    * 脾内含大量血窦，血窦能存大量血。
    * 临床联系：肝硬化导致门脉高压，门脉血液逆流进入脾脏、充盈脾窦，脾体积随之变大，故肝硬化病人会出现脾大。
    * > **注意**：脾因肝硬化门脉高压而肿大这一条与临床直接相关。

* **造血**
    * 脾参与造血功能。

* **清除衰老细胞**
    * 衰老的红细胞在脾脏被清除。

* **免疫**
    * 脾参与免疫功能。

### 脾的固定装置

* **四条韧带**
    * 脾靠 4 条韧带固定在左季肋区。

| 韧带 | 连接 |
| :--- | :--- |
| 脾肾韧带 | 脾与左肾 |
| 脾胃韧带 | 脾与胃 |
| 脾结肠韧带 | 脾与结肠脾曲 |
| 膈脾韧带 | 脾上端与膈肌 |

* **韧带的形成与位置关系**
    * 水平切面上腹膜包被肾脏，到达脾脏后包绕脾，再返折回到胃并包绕胃，由此形成脾肾韧带与脾胃韧带。
    * 侧面观膈肌位于上方，胸的侧壁与腹的侧壁居侧，横结肠的脾曲在下方拐弯；膈肌与脾上端之间为膈脾韧带，脾与结肠脾曲之间为脾结肠韧带。
    * 整体关系：肝与胃之间是小网膜，脾与胃之间有韧带。
