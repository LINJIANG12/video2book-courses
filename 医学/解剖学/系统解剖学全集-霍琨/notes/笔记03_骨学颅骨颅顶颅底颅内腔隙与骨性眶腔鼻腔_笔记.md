# 骨学·颅骨：颅顶、颅底、颅内腔隙与骨性眶腔鼻腔

## 颅的分部与骨数

* **脑颅（cranium）**
    * > **定义**：以眶上缘与外耳门两点连线为界，颅分成的后上方部分。
    * 围成颅腔，容纳脑髓。
    * 由 8 块骨构成。
* **面颅（viscerocranium）**
    * > **定义**：以眶上缘与外耳门两点连线为界，颅分成的前下方部分。
    * 围成骨性眶腔、鼻腔和口腔。
    * 由 15 块骨构成。
* **颅骨总数**
    * 脑颅 8 块加面颅 15 块，颅由 23 块骨构成。
* **舌骨（hyoid bone）**
    * > **定义**：位于喉结上方的 U 型骨，可触到的那一部分称舌骨体。
    * 是唯一不与颅骨直接相连的颅骨。
    * 虽不与颅骨直接相连，仍计入面颅的 15 块骨。

```text
            眶上缘 ●━━━━━━━━━━━━━━━━━━━● 外耳门
                       这条线就是分界
        ┌────────────────────┬────────────────────┐
        │      脑 颅         │      面 颅         │
        │      后上方        │      前下方        │
        │        8 块        │       15 块        │
        │    容纳脑髓       │  眶腔鼻腔口腔     │
        └────────────────────┴────────────────────┘
                        8 + 15 = 23 块
```

> **结论**：骨性眶腔、鼻腔、口腔这三个腔在解剖学上属于面颅的功能区，不要与脑颅的颅腔混在一起。

## 下颌骨

* **下颌骨（mandible）**
    * > **定义**：马蹄铁形（U 字形）的骨，由骨体与左右两侧的下颌支组成，即一体两支。
    * 骨体是前方马蹄铁型的一大块。
    * 下颌支是后方翘起的两个扁薄骨板，左右对称。
* **下颌角（angle of mandible）**
    * > **定义**：下颌骨体与下颌支交界的部位。
    * 是重要的体表标志。
* **下颌头（head of mandible）**
    * 是下颌支上两个突起之一，位置偏后。
* **冠突（coronoid process）**
    * 是下颌支上两个突起之一，位置偏前。
* **齿槽（alveolar process）**
    * 位于下颌骨的上缘。
    * 齿槽内镶嵌下颌的牙齿。
* **颏孔（mental foramen）**
    * 位于下颌体前方正中线的两侧，左右共 2 个。
    * 是下颌支内侧面骨性管在下颌体上的出口。
* **下颌孔（mandibular foramen）**
    * > **定义**：位于下颌支内侧面的一处骨孔。
    * 进入下颌体后形成一条骨性管，最后从颏孔穿出。
* **翼肌粗隆（pterygoid tuberosity）**
    * > **定义**：下颌角内侧骨面上的粗糙隆起，是肌肉抵止的部位。
* **下颌下腺凹（submandibular fossa）**
    * 位于下颌体下边的两个骨性凹窝之一。
    * 容纳下颌下腺。
* **舌下腺凹（sublingual fossa）**
    * 位于下颌体下边的两个骨性凹窝之一。
    * 容纳舌下腺。

```text
              ┌────────────┐        ┌────────────┐
              │   冠突   │        │  下颌头  │
              └───┬─────┘        └───┬─────┘
                  │    下 颌 颈       │
                  └───────────────────┘
                            │
              ┌─────────────┴─────────────┐
              │         下颌角           │
              │      （体表标志）        │
              │                          │
              │        下 颌 支          │  ← 两侧扁薄的骨板
              └─────────────┬─────────────┘
                            │
              ┌─────────────┴─────────────┐
              │      下 颌 骨 体          │  ← 马蹄铁形（U 形）
              │    上缘：齿槽（镶牙）      │
              └───────────────────────────┘
```

> **易错点**：下颌体内面"孔—管—孔"的走向和"两凹窝容纳两腺体"是必考点。路线是下颌孔进、骨性管、颏孔出；落位是舌下腺凹藏舌下腺，下颌下腺凹藏下颌下腺。

## 颅顶外面

### 成人颅顶的骨缝

* **冠状缝（coronal suture）**
    * 成人颅顶左右走向的骨缝。
* **矢状缝（sagittal suture）**
    * 成人颅顶前后走向的骨缝。
* **人字缝（lambdoid suture）**
    * 成人颅顶后方的骨缝。
* **骨缝内的通道**
    * 骨缝里有导血管的通道。

### 小儿颅顶的囟

* **前囟（anterior fontanelle）**
    * 位于两块额骨与两块顶骨之间，即额骨与顶骨之间。
    * 形状呈菱形。
    * 1～2 岁闭合。
* **后囟（posterior fontanelle）**
    * 位于顶骨与枕骨之间。
    * 形状呈三角形。
    * 生后不久即闭合。
* **上矢状窦（superior sagittal sinus）**
    * 位于颅顶正中线的下方、颅腔之内。
    * > **定义**：颅腔内的一个很大的静脉管道。
* **囟的临床意义**
    * > **定义**：闭合是指膜性的区转变为骨。
    * 判断颅内压：颅内压升高时囟膜膨起，可据此判断颅内压的变化。
    * 采集静脉血：新生儿在其他部位采血困难时，可经囟刺入上矢状窦采集静脉血。

| | 前囟 | 后囟 |
| :--- | :--- | :--- |
| 位置 | 额骨与顶骨之间 | 顶骨与枕骨之间 |
| 形状 | 菱形 | 三角形 |
| 闭合时间 | 1～2 岁 | 生后不久 |

> **提示**：把位置、形状、闭合时间三行与"额顶间菱形、前囟迟闭；顶枕间三角、后囟早闭"这一串口诀一起记，前后两栏正好互为反证。

## 颅底内面

### 颅窝的方位与分界

* **颅底内面（internal surface of cranial base）**
    * > **定义**：由前向后大致排列成 3 个颅窝的颅骨内面。
* **颅窝的前后顺序**
    * 颅前窝在最前方，凹陷进去，在三个颅窝中最浅。
    * 颅中窝居中，形状类似"横八字"。
    * 颅后窝在最靠后方，在三个颅窝中最深。
* **颅窝的分界**
    * 颅前窝与颅中窝的分界在蝶骨小翼后缘，其前端突起称前床突。
    * 颅中窝与颅后窝的分界在鞍背。
    * 分界线只有这两条。

```text
                    颅 底 内 面（示意）

        ┌───────────────────────────────┐
        │       颅 前 窝（最浅）         │   鸡冠 · 筛板 · 筛孔
        ├───────────────┬───────────────┤
        │  蝶骨小翼后缘 · 前床突         │
        ├───────────────┴───────────────┤
        │        颅 中 窝                │   蝶鞍 · 视神经管
        │      中间高、两侧低            │   眶上裂 · 圆孔 · 卵圆孔
        │                               │   棘孔 · 破裂孔
        ├───────────────┬───────────────┤
        │            鞍 背              │
        ├───────────────┴───────────────┤
        │       颅 后 窝（最深）         │   枕大孔 · 舌下神经管
        │                               │   斜坡 · 颈静脉孔
        │                               │   内耳门 · 乙状窦沟 · 横窦沟
        └───────────────────────────────┘
```

### 颅前窝

* **颅前窝（anterior cranial fossa）**
    * > **定义**：三个颅窝中最靠前、最浅的一个，结构最简，只有三样。
* **鸡冠（crista galli）**
    * 位于正中线上，是一个向上翘起的薄骨板。
* **筛板（cribriform plate）**
    * 位于鸡冠两侧，是深凹进去的骨板。
* **筛孔（cribriform foramina）**
    * 是筛板上的众多小孔。
    * 嗅神经由此通过。
    * 筛板骨折损伤嗅神经，会出现嗅觉障碍。

> **易错点**：颅前窝的考点不在结构多，而在"一个结构 + 一条神经 + 一个后果"：认筛孔 → 通嗅神经 → 筛板骨折致嗅觉障碍。

### 颅中窝

* **颅中窝（middle cranial fossa）**
    * > **定义**：三个颅窝中间的一个，形状类似"横八字"，特点是中间高、两侧低。
    * 孔裂数量远多于颅前窝。
* **蝶鞍（sella turcica）**
    * 是颅中窝中间高起的骨。
* **垂体窝（hypophyseal fossa）**
    * 位于蝶鞍上方。
    * 容纳脑垂体。
* **交叉沟（chiasmatic sulcus）**
    * 位于蝶鞍前方。
* **前床突（anterior clinoid process）**
    * 是左右对称的骨突，构成颅前窝与颅中窝分界线蝶骨小翼后缘的前端。
* **后床突（posterior clinoid process）**
    * 是左右对称的骨突。
* **鞍背（dorsum sellae）**
    * 是蝶鞍后方这一整片骨性区域。
    * 构成颅中窝与颅后窝的分界。
* **视神经管（optic canal）**
    * 位于前床突的内侧，左右各一个。
    * 内有视神经和眼动脉通过。
* **眶上裂（superior orbital fissure）**
    * 是颅中窝孔裂中通过结构最多的一处。
    * 动眼神经、滑车神经、展神经、眼神经共 4 对脑神经经此进入眶腔。
* **圆孔（foramen rotundum）**
    * 内有上颌神经通过。
* **卵圆孔（foramen ovale）**
    * 内有下颌神经通过。
* **棘孔（foramen spinosum）**
    * 位于卵圆孔的后外侧。
    * 内有脑膜中动脉通过。
* **破裂孔（foramen lacerum）**
    * 位于颞骨岩部的尖端。
    * 内有颈内动脉通过。
* **中窝孔裂的空间关系**
    * 视神经管、眶上裂、圆孔、卵圆孔、棘孔这五个孔位于一条弧形区上，围绕蝶骨体排列。
    * 破裂孔单独挂在颞骨岩部的尖端上，不在这条弧线上。

| 孔裂 | 通过的结构 |
| :--- | :--- |
| 视神经管 | 视神经、眼动脉 |
| 眶上裂 | 动眼神经、滑车神经、展神经、眼神经 |
| 圆孔 | 上颌神经 |
| 卵圆孔 | 下颌神经 |
| 棘孔 | 脑膜中动脉 |
| 破裂孔 | 颈内动脉 |

> **提示**：记中窝的孔用"视、裂、圆、卵、棘、破"这一串就够，更重要的是记住空间关系：视神经管、眶上裂、圆孔、卵圆孔、棘孔围绕蝶骨体转成一条弧线，破裂孔不在弧线上。弧线记住了，孔的先后顺序自然就有了。

### 颅后窝

* **颅后窝（posterior cranial fossa）**
    * > **定义**：三个颅窝中最靠后、最深的一个，窝底有一个大孔称枕大孔。
* **枕大孔（foramen magnum）**
    * 位于颅后窝窝底，是颅后窝与椎管相通的通道。
    * 以枕大孔为界，上方是脑髓，下方容纳脊髓的椎管内容纳脊髓。
* **舌下神经管（hypoglossal canal）**
    * 位于枕大孔的前外侧，左右各一条。
    * 内有舌下神经通过。
* **斜坡（clivus）**
    * 位于鞍背到枕大孔之间，是一块倾斜的骨面。
    * 脑干位于斜坡的上方。
    * 斜坡骨折损伤脑干会危及生命。
* **颈静脉孔（jugular foramen）**
    * 位于颞骨岩部的后方外侧。
* **乙状窦沟（sulcus sigmoideus）与横窦沟（sulcus transversus）**
    * > **定义**：与舌下神经管、颈静脉孔、内耳门一带相连的骨性沟，相当于颅内的静脉管道。
    * 乙状窦沟是自颈静脉孔向上延伸的骨性凹窝。
* **内耳门（internal acoustic meatus）**
    * 位于颞骨岩部的后坡上。

### 颅窝的毗邻与交通

* **冠状切面（coronal section）**
    * > **定义**：在颅前窝处做的切面，用于观察颅窝与颅外腔隙的毗邻关系。
    * 从上到下依次可见上颌牙齿与颅骨、颅前窝正中线上翘起的鸡冠、鼻中隔、两侧眶腔、鼻腔内的上鼻甲与中鼻甲、上颌窦、额窦、筛窦。
* **矢状切面（median sagittal section）**
    * > **定义**：从前向后做的正中切面。
    * 依次可见上唇与下唇、额骨与额窦、鼻骨、向后倾斜的筛板及其上方翘起的鸡冠、垂体窝、斜坡、蝶骨体与蝶窦、腭、下颌骨断面与舌、喉、寰椎与枢椎椎体断面、枕骨与枕大孔断面。
    * 腔隙自上而下依次是咽、鼻、口、喉，枕大孔向下的腔隙即椎管。
* **腭（palate）**
    * 是鼻腔与口腔的分界。
    * 前方是硬腭，后方是软腭。
* **颅前窝的毗邻**
    * 中下方邻骨性鼻腔，两侧下方邻眶腔。
    * 颅前窝中部骨折时血液和脑脊液漏入鼻腔，可从口鼻流出粘稠鲜红的脑脊液。
* **颅中窝的毗邻**
    * 中部下方邻咽，两侧邻中耳鼓室。
    * 中部骨折时血液和脑脊液漏入咽，可从口鼻流出。
    * 两侧骨折时血液和脑脊液可经外耳道流出。
* **鼓室盖（tegmentum tympani）**
    * 位于颅中窝两侧，表现为一处浅凹。
    * > **定义**：覆盖中耳鼓室的薄骨板，凿开后里面是骨性腔即中耳鼓室。
* **颅后窝的交通**
    * 经枕大孔与椎管相通。
    * 枕大孔上方是脑髓，下方容纳脊髓。
* **颅底骨折的出血与脑脊液**
    * 颅前窝骨折可从口鼻流出粘稠鲜红的脑脊液。
    * 颅中窝骨折可从口鼻或外耳道流出。

```text
        颅前窝 ── 中下：骨性鼻腔
                 └─ 两侧下方：眶腔
                          ↓
        颅中窝 ── 中下：咽
                 └─ 两侧：鼓室（鼓室盖下方）
                          ↓
        颅后窝 ── 经枕大孔：与椎管相通
```

| 颅窝 | 毗邻 / 交通 | 骨折后血液与脑脊液的去向 |
| :--- | :--- | :--- |
| 颅前窝 | 中下邻骨性鼻腔，两侧下方邻眶腔 | 可从**口鼻**流出 |
| 颅中窝 | 中部下方邻咽，两侧邻中耳鼓室 | 可从口鼻或**外耳道**流出 |
| 颅后窝 | 经枕大孔与**椎管**相通 | 枕大孔上方是脑髓，下方容纳脊髓 |

> **易错点**：从口鼻流出的血液和脑脊液，不能严格区分来自颅前窝还是颅中窝，这种情况统称为颅底骨折，不要硬去细分。

> **结论**：有鸡冠的颅窝一定是颅前窝，有垂体窝的颅窝是颅中窝，枕大孔所在的窝是颅后窝。

## 颅底外面

### 骨性腭与鼻后孔

* **骨性腭（hard palate）**
    * > **定义**：由上颌牙齿围成的骨性结构，是口腔的顶部。
* **切牙孔（incisive foramen）**
    * 位于门齿的后方。
    * 腭神经由此穿出。
* **腭大孔（greater palatine foramen）**
    * 位于骨性腭后方的孔。
    * 腭大神经由此传出。
* **腭小孔（lesser palatine foramen）**
    * 位于腭大孔下方的孔。
    * 腭小神经由此传出。
* **鼻后孔（posterior nasal aperture）**
    * 位于腭的后上方，左右各一。

### 下颌窝与颞骨乳突区

* **关节结节（articular tubercle）**
    * 是下颌窝前方略微隆起的骨缘。
* **下颌窝（mandibular fossa）**
    * 是下颌骨后方凹入的骨性凹窝。
    * 与下颌骨的下颌头构成关节。
    * 本身很浅，因前方隆起的关节结节而变深，使下颌关节得以稳固。
* **乳突（mastoid process）**
    * 是耳廓后下方一个粗大的骨性隆起。
* **茎突（styloid process）**
    * 是乳突前内侧的骨刺，左右对称。
* **茎乳孔（stylomastoid foramen）**
    * 位于乳突与茎突的根部。
    * 面神经由此穿出。

### 枕大孔与颅底外面的孔

* **枕大孔（foramen magnum，颅外面观）**
    * 位于颅底外面，可见其轮廓。
    * 两侧各有一个关节面。
* **寰枕关节（atlanto-occipital joint）**
    * 由枕大孔两侧的关节面与寰椎上关节面构成。
* **颅底外面的卵圆孔与棘孔**
    * 颅底外面可以见到卵圆孔和棘孔。
* **颈动脉管（carotid canal）**
    * 颅底外面可见颈动脉管的外口，破裂孔相当于它的内口。
    * 颈内动脉经外口进入，在骨管内行走，最后在破裂孔的上缘进入颅腔。

> **结论**：颅底外面自前向后可依次记为骨性腭（切牙孔、腭大孔、腭小孔）、鼻后孔、关节结节与下颌窝、乳突与茎突与茎乳孔、枕大孔与寰枕关节、卵圆孔与棘孔、颈动脉管外口与破裂孔内口。

> **提示**：记忆颅底的切入点是两条分界线加一条弧线——先抓住颅中窝与颅前窝的蝶骨小翼后缘、颅中窝与颅后窝的鞍背，再抓住中窝"视、裂、圆、卵、棘、破"中围绕蝶骨体的那条弧线，剩下的内容往里填即可。

## 颅侧面观的地标与骨缝

* **颅侧面可触知的骨性标志**

    * 颧弓：体表能摸到的骨性隆起，其终点可以确定。
    * 下颌角：体表能摸到。
    * 乳突：位于外耳门的后下方，体表能摸到。

* **颅盖的骨缝**

    * 冠状缝：居前。
    * 蝶缝：居中。
    * 颞缝：在蝶缝之后。
    * 人字缝：最靠后。
    * 这四条骨缝围出一块区域，中间夹着蝶骨。

## 翼点

### 位置与体表投影

* **翼点**

    * > **定义**：额骨、顶骨、颞骨、蝶骨四骨交界处、骨缝呈 H 形的那一块**区域**，不是一个点。

    * 骨缝在该区呈 H 形，区域中夹着蝶骨。
    * 说投影、说骨折时，说的都是这一块**区**。

* **体表投影**

    * 投影位置：在**颧弓终点上方约四厘米处**。
    * 自上而下捋定位标志：上唇、下唇、颏、喉结、下颌角、耳廓。

### 骨折的力学条件

* **薄骨板与脑膜中动脉**

    * 第一个特点：该处骨板很薄。
    * 第二个特点：内面有一条**脑膜中动脉**紧贴骨板向后行。
    * 薄骨板加上四骨交界，使翼点成为颅骨整体的薄弱区，容易骨折。

* **颅骨内外板张力**

    * 颅骨是一个**弓状的扁骨**。
    * 弓状扁骨内板张力大于外板张力。
    * 受同样外力时内板比外板容易先骨折。
    * 内板骨折碎片向下，直接刺破紧贴骨板后行的脑膜中动脉，造成大出血。

### 硬膜外血肿

* **硬脑膜**

    * 与**颅底**的骨面结合得**比较紧**。
    * 与**颅的侧面和颅顶**结合得比较**疏**。
    * 脑膜中动脉这条血管就走行在颅板与硬脑膜之间。

* **硬膜外腔与硬膜外血肿**

    * 翼点骨折后，血管在颅板与硬脑膜之间出血，越出越多。
    * 颅腔是封闭腔，血出不去，只能在腔内积聚。
    * 血液把本来与颅骨结合较疏的硬脑膜**推向内**，中间撑出一个空腔，即**硬膜外腔**。
    * 这种出血临床上称为**硬膜外血肿**。

    ```text
                  外力压下来
                     ↓
       ┌──────────────────────────────┐
       │  外板（张力小，不易断）        │
       ├──────────────────────────────┤
       │  内板（张力大，先断）          │
       │  折口向下，刺破动脉            │
       │  脑膜中动脉（贴骨板后行）      │
       │  出血，越积越多                │
       ├──────────────────────────────┤
       │  硬脑膜                        │
       │  颅底：结合紧                  │
       │  颅顶、颅侧：结合疏            │
       │  被血液推向内侧                │
       ├──────────────────────────────┤
       │  【硬膜外血肿】                │
       ├──────────────────────────────┤
       │  脑（脑髓）受压                │
       │  血量到一定量，发生脑疝        │
       └──────────────────────────────┘
    ```

    * 硬脑膜向内一挪，脑髓跟着被推移、往内受压。
    * 出血到一定血量、一定程度就形成**脑疝**，不及时抢救患者即死亡。
    * > **易错点** ⚠️：翼点骨折时外板尽管光滑、内板看不到明显骨折痕，也要把患者留院观察几个小时，不要轻易放走——这个出血是渐渐的，大约**六个小时以后**才显现出症状。

## 颞窝与颞下窝

### 位置

* **颞窝**

    * 位置：颧弓上方的骨性凹窝，是侧面三个窝中最明显的一个。
    * 窝内有较大的肌肉附着，即**颞肌**。

* **颞下窝**

    * 位置：下颌骨下颌支的**深面**那部分空间。
    * 与颞窝的分界一句话：颞窝向下一直延续到下颌支的深面，那一段空间叫颞下窝。

### 窝内肌肉

* **翼外肌**

    * 位于颞下窝内。
    * 走行方向：向下到**下颌颈**。

* **翼内肌**

    * 位于颞下窝内，在翼外肌的**深面**，斜行。
    * 走行方向：到**下颌角的内侧**。

## 翼腭窝

### 位置与边界

* **翼腭窝**

    * 形态：位于眶腔向下、向后看的一个**狭长的间隙**。
    * 前界：上颌骨的后缘。
    * 后界：翼突。
    * 内侧界：腭骨的垂直板。
    * 外侧就是颞下窝，两者相通。

### 交通关系

* **五个通道**

    * 圆孔：通颅中窝。
    * 翼管：通颅底外侧。
    * 腭大孔：通口腔。
    * 蝶腭孔：通鼻腔。
    * 眶下裂：通眶腔。

    | 通道 | 通向 |
    | :--- | :--- |
    | 圆孔 | 颅中窝 |
    | 翼管 | 颅底外侧 |
    | 腭大孔 | 口腔 |
    | 蝶腭孔 | 鼻腔 |
    | 眶下裂 | 眶腔 |

* **记忆权重**

    * 位置深、交通关系复杂，是三个窝里的重点。
    * 一个狭窄的间隙却与周围这么多腔隙沟通，这五个交通关系必须拿得出来。

## 眶腔

### 外形与开口

* **眶腔**

    * 形态：锥体型腔，后边尖、前边接近于四方形，即**四棱锥体型**。
    * 方位：**底朝向前外，尖朝向后内**。
    * 参照定位：两侧为耳廓，前方为鼻。
    * 内容：容纳**眼球**；尖部与**视神经**相连，所以尖一定朝后内。

* **眶腔的三个开口**

    * 视神经管：尖部（眶尖）那个最圆的窟窿。
    * 眶上裂：斜长的裂隙，一个朝向外上。
    * 眶下裂：另一个裂隙，朝向外下。

### 四壁与眶尖

* **上壁**

    * 前外侧有一个浅凹，叫**泪腺窝**。

* **外侧壁**

    * 后上方有一个狭长的裂隙，叫**眶上裂**。

* **下壁**

    * 后外侧还有一个裂隙，叫**眶下裂**。

* **内侧壁**

    * 前份有一个**泪囊窝**。
    * 壁上有许多小孔，是**筛窦**所在。

* **眶尖**

    * 眶尖的结构就是视神经管。

### 毗邻与交通

| 壁 | 壁内的结构 | 毗邻与交通 |
| :--- | :--- | :--- |
| 上壁 | 前外侧浅凹——泪腺窝 | 与**颅前窝**相邻 |
| 外侧壁 | 后上方狭长裂隙——眶上裂 | 经眶上裂、视神经管**通颅中窝** |
| 下壁 | 后外侧裂隙——眶下裂 | 经眶下裂**通翼腭窝**；同时与**上颌窦**相邻 |
| 内侧壁 | 前部泪囊窝；小孔通向筛窦 | 与**筛窦、鼻腔**相邻；泪囊窝向下**经鼻泪管通鼻腔** |

* **通向颅中窝的两条道**

    * 眶上裂和视神经管都和颅中窝**相通**。

* **鼻泪管**

    * > **结论**：**泪囊窝向下，经鼻泪管与鼻腔相通**。
    * 泪由泪腺分泌，从泪腺窝出来，经泪囊窝往下走，再经鼻泪管通到鼻腔。
    * 这条相通关系就是「痛哭流涕」中眼泪与鼻涕一起下来的结构基础。

* > **易错点** ⚠️：下壁的眶下裂**既通又邻**——经眶下裂**通**翼腭窝，同时下壁又**邻**上颌窦。相通是一条道，相邻是隔着一层骨板贴在一起，两回事不能混。

* > **易错点**：内侧壁与筛窦只是**邻**而不是**通**——壁上那些小孔是筛窦所在的位置，但并不构成一条能把眶腔和筛窦打通的通道。

### 眼球外凸的来源

* **眼球外凸**

    * 碰到眼球外凸，第一个念头往往是眶腔肿瘤，但要先问一句：是**原发**还是**继发**。
    * 把眶的毗邻关系摊开，答案就出来了。
    * 颅内肿瘤（如**蛛网膜纤维母细胞瘤**）可经眶上裂、视神经管这条途径进入眶腔，瘤子长大把眼球挤向外，形成凸眼。
    * **上颌窦**肿瘤突破这层薄薄的骨壁，可进入眶腔，造成眼球外凸。
    * **筛窦**肿瘤突破骨壁进入眶腔，也会造成眼球外凸。
    * > **结论**：不要单一地只考虑「眶腔长肿瘤了」；周围其他部位长肿瘤，一样会造成眼球外凸。

## 骨性鼻腔

### 形态与开口

* **骨性鼻腔**

    * 形态特点一：**上窄下宽**。
    * 形态特点二：中间有隔，这个隔叫**鼻中隔**，把鼻腔分成左右两个腔。
    * 前方经**梨状孔**与外界相通。
    * 后方经**鼻后孔**与咽相通。

    ```text
                  上壁：筛板（中线隆起处为鸡冠）
             ┌───────────┬────────────┐
             │  外侧壁   │   内侧壁   │   上窄
             │           │            │
             │ （三鼻甲） │  （鼻中隔） │
             │           │            │   下宽
             └───────────┴────────────┘
                  下壁：骨腭（口腔的顶）
    ```

* **鼻中隔的两个部分**

    * 沿正中线作**矢状切面**会多出两个骨板结构，这两个骨板合起来叫**骨性鼻中隔**。
    * 骨性鼻中隔**前边的三角区是软骨性**的鼻中隔。
    * 两者加在一起才是完整的鼻中隔。

### 四壁

* **上壁——筛板**

    * 鼻腔的上壁实际上就是筛板。
    * 认法：图上那个翘起的骨板叫**鸡冠**，鸡冠两侧凹进去、横着的那块骨板就是筛板。

* **下壁——骨腭**

    * 下壁叫**骨腭**，即口腔的上壁。
    * 骨腭的下方就是口腔。

* **内侧壁——鼻中隔**

    * 内侧壁就叫鼻中隔，作用是分隔左右鼻腔。

### 外侧壁

* **三鼻甲、三鼻道**

    * 外侧壁上明显能看到三个**瓦片状的骨板**，即**上鼻甲、中鼻甲、下鼻甲**。
    * 鼻甲是凸出的，鼻甲与鼻甲之间凹进去的地方就是**鼻道**。
    * 鼻道从上往下为**上鼻道、中鼻道、下鼻道**。
    * > **结论**：鼻腔外侧壁的结构，记住**三鼻甲、三鼻道**。

* **蝶筛隐窝**

    * 位置：外侧壁的**上鼻甲后上方**。
    * 蝶窦开口于蝶筛隐窝。

### 毗邻与交通

* **外侧壁上份**

    * 与**筛窦**相通。
    * 与**眶腔**相邻。

* **外侧壁下份**

    * 与**上颌窦**相通。
    * 与**筛窦**相通。
    * 与**额窦**相通。

* **鼻腔前端的开口**

    * 前端有一个孔，是**鼻泪管的开口**，通向**眶腔**。
    * 这条道就是眶腔一侧「泪囊窝向下经鼻泪管通鼻腔」的另一头。

* **滴眼药后按压内眦**

    * 滴眼药后要用手轻摁一下**内眦**，目的是防止眼药顺着鼻泪管流到鼻腔里去。
    * 鼻腔与眶腔的这一条交通关系，就藏在这么一个小动作里。

## 鼻旁窦

### 组成与位置

* **鼻旁窦（副鼻窦）**

    * 数量：一共 **4 组**。
    * 额窦：位于**眉弓的深面**。
    * 筛窦：位于**眶的内侧壁**。
    * 上颌窦：位于**上颌骨的深面**。
    * 蝶窦：位于**蝶骨体**内——颅中窝中部那个大的腔就是蝶骨体，蝶骨体里边就叫蝶窦。

### 开口位置

* **开口的鼻道范围**

    * 鼻旁窦的开口**仅限**于**上鼻道和中鼻道**。

* **各窦开口**

    * 额窦：开口于**中鼻道**。
    * 上颌窦：开口于**中鼻道**。
    * 筛窦的前群：开口于**中鼻道**。
    * 筛窦的后群：开口于**上鼻道**。
    * 蝶窦：开口于**蝶筛隐窝**。

### 开口方向

| 鼻旁窦 | 开口鼻道 | 开口方向 |
| :--- | :--- | :--- |
| 额窦 | 中鼻道 | 向下（底在上、口在下） |
| 筛窦前群 | 中鼻道 | 向内侧 |
| 筛窦后群 | 上鼻道 | 向内侧 |
| 上颌窦 | 中鼻道 | 向内侧 |
| 蝶窦 | 蝶筛隐窝 | 向前 |

### 临床体位

* **滴药体位**

    * 额窦、蝶窦滴药：取**仰卧、头低位**，因为额窦开口朝下、蝶窦开口朝前，药容易流进去。
    * 筛窦滴药：取**侧卧、头低位**，因为开口朝内侧，侧过来就顺了。
    * 上颌窦滴药：**侧卧位**即可，开口朝内侧，容易滴入。

* **上颌窦引流术体位**

    * 适用情形：上颌窦内脓汁满罐、胀痛感特别明显，此时不是滴药，而是要把脓汁**引出来**。
    * 体位：病变这一侧上颌窦**朝上**，人**侧卧、足高头低**，并且**不断地晃头**。
    * 原理：上颌窦朝上后，它的开口自然就转到下面，脓汁顺着开口流出。

## 颅窝的下方交通

* **颅窝与下方腔隙的关系**

    * 颅前窝下方：中间是鼻，两侧是眶。
    * 颅中窝下方：是咽。
    * 颅后窝：通椎管。
    * 这组上下交通关系决定了颅底各处孔裂里通过什么结构，是后续内容的打基础。
