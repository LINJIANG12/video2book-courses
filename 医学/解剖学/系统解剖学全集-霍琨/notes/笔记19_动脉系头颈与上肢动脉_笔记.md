# 动脉系·头颈与上肢动脉

## 肺循环的动脉

* **肺动脉干**

    * > **定义**：肺循环的动脉主干，起自右心室，向左右肺供血

    * 位于**心包内**，处在**升主动脉的左前方**

    * 起自**右心室**

    * 在**主动脉弓的下方**分成左、右肺动脉两支

    ```text
       右心室
          │
          └──→ 肺动脉干（心包内 · 升主动脉左前方）
                   │
                   ├──→ 左肺动脉
                   └──→ 右肺动脉
    ```

* **动脉韧带**

    * > **定义**：主动脉弓下缘与左肺动脉根部之间相连的结缔组织索

    * 位置固定在**主动脉弓下缘**与**左肺动脉根部**之间

    * 胚胎时期是**动脉导管**，出生后动脉导管闭锁即留下这条索

    * > **提示**：只要记牢位置，「胚胎期是动脉导管、闭锁后成为韧带」就自动跟得上

## 主动脉的分段

* **主动脉**

    * > **定义**：位于脊柱前方的体循环动脉主干，起自左心室

    * 起始端起自**左心室**

    * 走行是「一升、一弯、一降」：先向上升，再向左后弯曲，最后向下降

    * 三段即由这一次转向切出：**升主动脉、主动脉弓、降主动脉**

    * 降主动脉在**第12胸椎水平**穿过膈的主动脉裂孔，被膈分成**胸主动脉**（上段）与**腹主动脉**（下段）

    * 末端分成**左右髂总动脉**

    ```text
        左心室
           │
           ▼
        升主动脉   ← 根部三窦：左窦→左冠状动脉、右窦→右冠状动脉（后窦无开口）
           │
        主动脉弓   ← 头臂干 · 左颈总动脉 · 左锁骨下动脉
           │
        降主动脉   ← 第12胸椎水平穿主动脉裂孔，被膈分成胸、腹两段
           │
           ├────────┬────────┐
        胸主动脉    腹主动脉
                    │
               左右髂总动脉
    ```

* **升主动脉根部的三个窦**

    * > **定义**：升主动脉根部膨大形成的三个窦状结构

    * 根部共三窦：**左窦、右窦、后窦**

    * ⚠️ **易错点**：三个窦中**只有左窦与右窦有动脉开口，后窦没有开口**——正因为后窦无开口，升主动脉的分支才只有两支

## 主动脉的分支

### 升主动脉与主动脉弓

* **冠状动脉的起始**

    * > **定义**：供应心肌的动脉，起自升主动脉根部的三个窦

    * 升主动脉的分支只有两支：**左冠状动脉**起自**左窦**，**右冠状动脉**起自**右窦**

    * 后窦无开口，所以没有第三支冠状动脉

* **主动脉弓上三支**

    * > **定义**：由主动脉弓上缘直接发出的三大分支

    * 从**右向左**依次为：**头臂干、左侧颈总动脉、左侧锁骨下动脉**

    * 右颈总动脉没有单独的弓上分支可挂，只能从**头臂干**下方分出

### 降主动脉

* **胸主动脉的分支**

    * > **定义**：胸段主动脉发出的分支，共三类，按发出位置区分

    | 分支 | 发出部位 | 去向 |
    | :--- | :--- | :--- |
    | 支气管动脉 | 两侧 | 伴随左右主支气管进入肺，营养肺的主要动脉 |
    | 食管动脉 | 前壁的许多小支 | 到食管 |
    | 肋间动脉 | 后壁 | 下十对 |

    * > **提示**：最容易混的是前壁那一堆小支——它们不是肋间动脉，是**食管动脉**；肋间动脉成对，从**后壁**出来，一共**下十对**

* **腹主动脉分支的固定顺序**

    * > **定义**：腹段主动脉的分支自上而下按固定次序发出，顺着念就不乱

    | 自上而下 | 分支 | 成对情况 |
    | :--- | :--- | :--- |
    | 1 | 膈下动脉（到膈肌） | 成对 |
    | 2 | 腹腔干，又叫腹腔动脉 | 不成对短干 |
    | 3 | 肾上腺中动脉 | 成对 |
    | 4 | 肠系膜上动脉 | 不成对 |
    | 5 | 肾动脉 | 成对 |
    | 6 | 睾丸动脉（女性叫卵巢动脉） | 成对 |
    | 7 | 肠系膜下动脉 | 不成对 |
    | 8 | 骶正中动脉 | 不成对 |
    | 后壁 | 腰动脉 | 四对 |

    * 不成对的只有四支：**腹腔干、肠系膜上动脉、肠系膜下动脉、骶正中动脉**，其余全成对

    * > **提示**：膈下动脉是从主动脉裂孔下方**向上**发出的，方向与主流相反，不要当成往下顺次排下去

## 颈总动脉

* **颈总动脉**

    * > **定义**：颈部的主干动脉，上端在甲状软骨上缘分叉为颈外、颈内两支

    * 左侧起自**主动脉弓**，右侧起自**头臂干**——左右起点不同

    * 起始部位在**胸锁乳突肌的深面**，又在**甲状腺的深面**

    * 沿**喉、气管、食管的外侧**向上走行

    * 到**甲状软骨上缘**水平分叉，分出**颈外动脉**与**颈内动脉**

    * 摸脉点与止血点在**胸锁乳突肌前缘的中点**

    ```text
       主动脉弓
          ├─ 头臂干 ──→ 右颈总动脉
          ├─ 左颈总动脉
          └─ 左锁骨下动脉

       颈总动脉干（胸锁乳突肌深面 · 甲状腺深面）
          │  沿喉、气管、食管外侧上行
          ▼
       甲状软骨上缘 —— 此处分叉
          ├──→ 颈外动脉
          └──→ 颈内动脉
    ```

    * > **易错点**：⚠️ 左右起点为何不同，看弓上三支即可明白——弓只给了头臂干、左颈总动脉、左锁骨下动脉，右颈总动脉只能挂在头臂干下

## 颈外动脉

* **颈外动脉**

    * > **定义**：供应头颈部以外与面部、颅外结构的动脉，分支繁多

    * 走行简单：从颈总动脉分出后上行，在**下颌支的深面**走

    * 到颞部成为**终支——颞浅动脉**

    * 细支知道有就行，不必强记：**颧眶动脉、颞中动脉、颞深前后动脉、颊动脉、面横动脉**

* **颈外动脉的重点分支**

    * > **定义**：颈外动脉上分布范围明确、必须记住的几条分支

    | 动脉 | 分布范围 | 备注 |
    | :--- | :--- | :--- |
    | 颞浅动脉 | 额部、顶部、颞部的软组织 | 颈外动脉的终支 |
    | 上颌动脉 | 外耳道、硬脑膜、颊肌、牙齿、牙龈、咀嚼肌、腭、腭扁桃体 | 营养范围很广 |
    | 脑膜中动脉 | 硬脑膜 | 上颌动脉发出的最重要的一支，在翼点内侧 |
    | 面动脉 | 面部软组织 | 绕过下颌骨下缘、过口角与鼻翼，到眼内眦 |
    | 舌动脉 | 舌、舌下腺、腭扁桃体 | |
    | 甲状腺上动脉 | 甲状腺、喉 | 另一路是甲状颈干发出的甲状腺下动脉 |

    * > **易错点**：⚠️ 脑膜中动脉**不是颈外动脉直接发出**，而是由**上颌动脉**在**翼点内侧**发出

* **颈外动脉的次要分支**

    * > **定义**：存在但不作重点要求的分支

    * 面动脉自己还发出**扁桃体支**与**腭升动脉**

    * 另有**耳后动脉、枕动脉、咽升动脉、颏下动脉**

    * 上颌动脉还发出**下牙槽动脉**，从**颏孔**出来

* **颈外动脉的摸脉点与止血点**

    * > **定义**：颈外动脉两处可触及搏动并可压迫止血的部位

    * **颞浅动脉**在**耳屏的前上方**

    * **面动脉**在**咬肌前缘与下颌骨下缘的交界处**

## 颈内动脉

* **颈内动脉**

    * > **定义**：与颈外动脉在甲状软骨上缘分出的另一支，供应颅内结构

    * 最容易认的特点是**颈部无分支**

    * 从颈总动脉分出后**垂直上升**，通过颅底的**颈动脉管**进入颅腔

    * 分布到**脑和视器**

    * 更细的分支与分布不在此处展开

    * > **提示**：颈部无分支正是它与颈外动脉最直接的对照

* **与颈外动脉的对照**

    * > **定义**：颈内、颈外动脉在颈部最直接的差别

    * 颈外动脉在颈部**分支繁多**，且有**颞浅动脉**、**面动脉**两处摸脉与止血点

    * 颈内动脉在颈部**一条分支也没有**

    * 更细的分支与分布不在这条脉络里展开

## 锁骨下动脉

* **锁骨下动脉**

    * > **定义**：起于胸锁关节、止于第1肋外缘的弓形段动脉

    * 起点在**胸锁关节**，由此呈弓状向外弯曲

    * 止于**第1肋外缘**

    * > **定义**：第1肋外缘以下即续接腋动脉，只有第1肋外缘到胸锁关节之间这一段弓形才叫锁骨下动脉

* **椎动脉**

    * > **定义**：由锁骨下动脉发出、穿颈椎横突孔入颅的动脉

    * 向上**穿过六个颈椎的横突孔**

    * 再穿**枕大孔**进入颅腔

    * 分布到**脑和脊髓**

* **胸廓内动脉**

    * > **定义**：贴肋软骨内面下降、供应胸前壁的动脉

    * 在**第1到第6肋软骨的后方**往下走

    * 分布区共四处：**胸前壁、心包、膈肌、乳房**

* **甲状颈干与肋颈干**

    * > **定义**：锁骨下动脉上两支为颈部与肋间供血的短干

    * **甲状颈干**发出**甲状腺下动脉、颈升动脉、颈横动脉、肩胛上动脉**

    * **肋颈干**发出**颈深动脉**与**最上肋间动脉**（即第1肋间动脉）

    * 肋颈干的升支再分成两支，分别走在**第1肋间**和**第2肋间**，形成**肋间后动脉**

* **甲状腺的血液供应**

    * > **定义**：甲状腺由上、下两路来源不同的动脉供血

    | 来源动脉 | 从哪来 |
    | :--- | :--- |
    | 甲状腺上动脉 | 颈外动脉 |
    | 甲状腺下动脉 | 甲状颈干 |

    * 供应共**两路**，一上一下

    * 名字叫「上」「下」，来源却挂在两棵完全不同的动脉树上

## 腋动脉

* **腋动脉**

    * > **定义**：第1肋外缘至大圆肌下缘之间、走在胸小肌深面的动脉段

    * 起点在**第1肋外缘**（即锁骨下动脉的终点）

    * 在**胸小肌的深面**下行

    * 终点在**大圆肌下缘**（即肱动脉的起点）

    * ⚠️ **易错点**：大圆肌下缘不是胸大肌下缘；两头都卡在别人的节点上

    ```text
       第1肋外缘 ← 锁骨下动脉的终点
            │
            │  （在胸小肌深面下行）
            │
       ┌────┴──────────┐
       │    腋动脉     │  胸小肌把它分成三段
       │ (1) 胸小肌上  │  胸上动脉 · 胸肩峰动脉
       │ (2) 胸小肌后  │  胸外侧动脉
       │ (3) 胸小肌下  │  肩胛下动脉 · 旋肱前、后动脉
       └────┬──────────┘
            │
       大圆肌下缘 ← 肱动脉的起点
    ```

* **腋动脉的三段分支**

    * > **定义**：按胸小肌位置把腋动脉分成三段，每段各有分支

    * 第(1)段位于胸小肌**上**，分支为**胸上动脉**与**胸肩峰动脉**

    * 第(2)段位于胸小肌**后**，分支为**胸外侧动脉**

    * 第(3)段位于胸小肌**下**，分支为**肩胛下动脉**与**旋肱前动脉、旋肱后动脉**

* **腋动脉各分支的去向**

    * > **定义**：三段分支各自供应的部位与二级分支

    * **胸上动脉**在第1肋间和第2肋间各发一支，形成**肋间后动脉**

    * **胸肩峰动脉**到胸小肌、胸大肌、肩峰、三角肌，分布区全是肌肉与关节

    * **胸外侧动脉**在**三角肌外侧缘的深面**发出，到胸小肌、胸大肌和前锯肌

    * **肩胛下动脉**是这段较粗的一支，再发出**胸背动脉**与**旋肩胛动脉**

    * **旋肱前动脉**与**旋肱后动脉**两者相互吻合

## 肱动脉

* **肱动脉**

    * > **定义**：臂部的主干动脉，供应臂部肌肉与肘关节

    * 从**大圆肌下缘**开始

    * 起初走在肱骨的**内侧**，转到**肱骨下三分之一的前方**下降

    * 到**桡骨颈的水平**分成两支：**桡动脉**与**尺动脉**

    * 营养范围就两样：**臂部的肌肉**和**肘关节**

    * 摸脉点与止血点在**肘窝前方**

* **肱动脉的吻合组**

    * > **定义**：肱动脉各分支与尺动脉侧支之间互相搭接的血管关系

    | 动脉 | 走行与吻合 |
    | :--- | :--- |
    | 肱深动脉 | 绕过肱骨后方转向前下，与桡侧返动脉吻合 |
    | 尺侧上副动脉 | 与尺侧返动脉吻合 |
    | 尺侧下副动脉 | 与尺侧返动脉吻合 |
    | 尺侧返动脉 | 起自尺动脉，向上与上面两支吻合 |

    * **尺侧返动脉**起自**尺动脉**，再向上与尺侧上、下副动脉吻合

* **骨间总动脉**

    * > **定义**：自尺动脉发出、在骨间膜附近分成三路的动脉

    ```text
       尺动脉 ──→ 骨间总动脉 ─┬─→ 骨间前动脉（骨间膜前方下降）
                              ├─→ 骨间后动脉（骨间膜后方下降）
                              └─→ 骨间返动脉（向上，与骨间前动脉的吻合支相交通）
    ```

    * 从**尺动脉**再往下发出，名叫**骨间总动脉**

    * 三路分别是：**骨间前动脉**（骨间膜前方下降）、**骨间后动脉**（骨间膜后方下降）、**骨间返动脉**（向上）

    * **骨间返动脉**向上与**骨间前动脉的吻合支**相交通

## 桡动脉与尺动脉

* **桡动脉**

    * > **定义**：肱动脉终支之一，走在前臂桡侧入掌

    * 在前臂**桡侧**、**桡侧腕屈肌的桡侧**向下降

    * 经腕部进入手

    * 到腕部分成**终支**与**浅支**两支

    * 终支要先**绕过桡骨茎突**，从**第一掌骨的背面**绕过去，再经**第一掌骨间隙**进入手掌，所以腕背那一段贴着骨面走

* **尺动脉**

    * > **定义**：肱动脉终支之一，走在前臂尺侧入掌

    * 在**尺侧屈肌的深面**下降

    * 经腕部进入手

    * 到腕部分成**终支**与**深支**两支

    * **尺侧返动脉**起自本干，向上与尺侧上、下副动脉吻合

## 手掌血管弓

* **两个血管弓的构成**

    * > **定义**：桡、尺动脉在腕部各分两支，两两拼合形成掌浅弓与掌深弓

    ```text
       桡动脉浅支 ─┐
                   ├──→ 掌浅弓
       尺动脉终支 ─┘

       桡动脉终支 ─┐
                   ├──→ 掌深弓
       尺动脉深支 ─┘
    ```

    * 桡、尺动脉到腕部各分两支，共四支

    * **掌浅弓**＝**尺动脉终支** ＋ **桡动脉浅支**

    * **掌深弓**＝**桡动脉终支** ＋ **尺动脉深支**

* **两个血管弓上的分支**

    * > **定义**：掌浅弓与掌深弓各自发出的指、手部动脉

    | 血管弓 | 构成 | 主要分支 |
    | :--- | :--- | :--- |
    | 掌浅弓 | 尺动脉终支 + 桡动脉浅支 | 3 条指掌侧总动脉（各自再分为指掌侧固有动脉）、小指尺掌侧动脉 |
    | 掌深弓 | 桡动脉终支 + 尺动脉深支 | 拇主要动脉（再分为拇指桡侧、拇指尺侧动脉）、掌心动脉 |

    * 掌浅弓发出**3条指掌侧总动脉**，各自再分为**指掌侧固有动脉**，另有**小指尺掌侧动脉**

    * 掌深弓发出**拇主要动脉**，再分为**拇指桡侧动脉**与**拇指尺侧动脉**，另有**掌心动脉**

* **掌心动脉**

    * > **定义**：连缀掌深弓与掌浅弓的交通支

    ```text
       掌深弓 ──── 掌心动脉 ──── 掌浅弓
        │                          │
       拇主要动脉           指掌侧总动脉
        │                          │
       拇指桡、尺侧动脉     指掌侧固有动脉
    ```

    * **掌心动脉**是深、浅两弓之间的交通支，把两头接上

    * **指掌侧固有动脉**走向每个手指的两侧

    * 浅弓受压时血液可绕道深弓到达各指；深弓受压时也可绕道浅弓——这是「手掌不怕压」的解剖基础

## 手指与腕部的压迫止血

* **手指的压迫止血**

    * > **定义**：手指外伤出血时的正确压迫部位

    * 手指的动脉走在手指的**两侧**

    * 压迫止血点**一定在两侧**

    * ⚠️ **易错点**：前后压压的正是手掌与手背，血从两侧的血管照样流出，等于没压

* **腕部的压迫止血**

    * > **定义**：腕部止血必须同时压住的两处

    * 腕部要压**两处**：**桡动脉**与**尺动脉**同时压迫

    * 一个都不能少

* **动脉摸脉与止血部位**
