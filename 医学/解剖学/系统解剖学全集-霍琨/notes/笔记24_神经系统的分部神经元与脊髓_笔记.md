# 神经系统的分部、神经元与脊髓

## 神经系统的组成与地位

   * **神经系统（nervous system）**

       * > **定义**：由脑和脊髓，以及与它们相连的这些周围神经所组成的一个庞大的系统。

       * 脑和脊髓不是孤岛，它们的外面接着一圈向外延伸的神经，这一整套加起来才叫神经系统。

       * 特点一：具有高度的整合能力，由数以亿万计的神经细胞构成。

       * 特点二：保证机体各种生理活动的进行。

       * 在人体九大系统中占主导地位——别的系统各管一摊，只有神经系统是把所有这些系统串起来的主干。

## 神经系统的两套分法

```text
                        神经系统
                           │
            ┌──────────────┴──────────────┐
       中枢神经系                    周围神经系
    ┌──────┴──────┐              ┌───────┴───────┐
  颅腔内的脑    椎管内的脊髓    与脑相连：脑神经 12 对
                             与脊髓相连：脊神经 31 对
```

   * **中枢神经系（central nervous system）**

       * 只含两样结构：颅腔内的脑、椎管内的脊髓。

       * 脑包括大脑、脑干和小脑；大脑位于最前，小脑在脑后下方，脑干在小脑前方。

       * 任何时候都等于脑加脊髓两样，只有这一种分法。

   * **周围神经系（peripheral nervous system）**

       * 与脑相连的称**脑神经**，共 12 对。

       * 与脊髓相连的称**脊神经**，共 31 对。

       * 周围神经系还能再分，见下。

```text
                        周围神经系
              ┌────────────┴────────────┐
          体躯神经                  内脏神经
       ┌──────┴──────┐         ┌──────┴──────┐
   体躯感觉神经   体躯运动神经  内脏感觉神经  内脏运动神经
                                          │
                                又叫植物神经、自主神经
```

   * **周围神经系的再分**

       * 先分**体躯神经**与**内脏神经**两大块。

       * 每块再按性质分为感觉与运动，于是得到体躯感觉神经、体躯运动神经、内脏感觉神经、内脏运动神经四种。

   * **内脏运动神经**

       * 又名**植物神经**，也叫**自主神经**。

       * 三个名称说的是同一件事。

> **注意**：两套分法不要混着用——第二套分法只针对周围神经系，中枢神经系不参与。

## 神经元与胶质细胞

   * **神经元（neuron）**

       * > **定义**：构成神经系统的最基本的一个单位。

       * 又叫**神经细胞**，显微镜下呈多角形。

   * **胶质细胞（glial cell）**

       * 本身没有传导功能。

       * 对神经细胞起四种作用：**支持、保护、营养、修复**。

## 神经元的构造

```text
            ┌──────── 树突（周围突）────────┐
            │  短小、树枝状，数目很多      │
            └─────────────┬────────────────┘
                          ▼
   ┌──────────────────────────────────────────────┐
   │  胞  体                                      │
   │  ├ 细胞核 · 细胞质 · 细胞器 · 细胞膜        │
   │  └ 独有：尼氏体、神经元纤维                  │
   └─────────────────────┬────────────────────────┘
                         ▼
              ┌──── 轴突（中央突）────┐
              │  长，一个神经元一条  │
              └───────────────────────┘
```

   * **胞体（soma）**

       * 具备细胞核、细胞质、细胞器与细胞膜。

       * 独有**尼氏体**和**神经元纤维**——这两样是神经元身上别的细胞没有的，看见了就知道是神经元。

   * **树突（dendrite）**

       * 又叫**周围突**；短小、树枝状，数目很多。

       * 接受外环境的各种刺激，并把刺激传给胞体。

   * **轴突（axon）**

       * 又叫**中央突**；比较长，一个神经元一条。

       * 把胞体产生的神经冲动向下传递。

   * **神经冲动的链式传导**

       * 胞体把刺激转化为**神经冲动**，通过中央突向下传递。

       * 冲动传给下一个神经元，下一个神经元的树突接受后再由其中央突继续向下传递，一个接一个、节节相传。

```text
  树突① ─▶ 胞体① ─▶ 轴突① ══▶ 树突② ─▶ 胞体② ─▶ 轴突② ══▶ 树突③ ─▶ 胞体③
   接受刺激   转化为神经冲动   向下传递     接受刺激   转化      向下传递
```

> **提示**：树突（周围突）与轴突（中央突）这两个别名不是另的东西，答题时两种写法都要认。

## 神经元的分类

### 按形态分

```text
【假单极神经元】胞体 → 一个突起 → 分成两支
      │
   ┌──┴──┐
   │ 胞体 │      两极先合在一起走一段，然后分开
   └──┬──┘       —— 所以叫“假”单极，实际是双极
      └─┬─┐
        │ └─┐
        │   └─┐

【双极神经元】胞体两侧各发一个突起
   ┌──┼──┐
   │ 胞体 │
   └┬───┬┘
  树突  轴突
   没有合在一起走，直接在胞体两侧发出

【多极神经元】多条树突 + 一条长轴突
   ┌──┼──┬──┐
   │  胞体  │   树突的突起很多，另有一条
   └┬───┬──┴─┐  很长很长的轴突（中央突）
  树突树突  轴突
```

   * **假单极神经元**

       * 胞体发出一个突起，这一个突起又分成两个，看上去是“一根”，所以叫单极。

       * 实际上发出的是两极——发出时两极合在一起走一段，然后分开，所以叫**假**单极，实际是双极。

   * **双极神经元**

       * 没有合在一起走，直接在胞体两侧各发一个突起，就叫双极神经元。

   * **多极神经元**

       * 树突突起很多，另外还有一个很长很长的轴突（中央突）。

### 按功能分

屈曲反射：桌上有一杯热水，手伸过去一摸，热水杯接触皮肤，手马上离开。完成这一反应所需的神经元如下。

```text
  热水杯 ──▶ 皮肤感受器（接受热的刺激）
                   │  传入
                   ▼
            传入神经元：假单极神经元
                   │
                   ▼
           脊髓后角：中间神经元（把冲动转给前角）
                   │  脊髓中央管
                   ▼
           脊髓前角：运动神经元
                   │  传出
                   ▼
         肱二头肌收缩 ──▶ 手离开热水杯
```

   * **感觉神经元**

       * 从感受器把信息往中枢送的那一个；按传导方向是向中枢传导，所以又叫**传入神经元**。

   * **中间神经元**

       * 在中间“通风报信”的那个；又叫**联络神经元**。

   * **运动神经元**

       * 执行运动指令、向外传递，所以又叫**传出神经元**；最终引起肌肉收缩。

| 分类依据 | 类别 | 形态／结构特点 | 别称与说明 |
| :--- | :--- | :--- | :--- |
| 形态 | 假单极神经元 | 一个突起发出后分成两支，两极先合行一段再分开 | 实际是双极 |
| 形态 | 双极神经元 | 胞体两侧各发一个突起，不合行 | |
| 形态 | 多极神经元 | 树突很多，另有一条很长的轴突 | 轴突即中央突 |
| 功能 | 感觉神经元 | 屈曲反射中承担传入的那一个 | 又叫**传入神经元** |
| 功能 | 中间神经元 | 脊髓后角到前角“通风报信”的那个 | 又叫**联络神经元** |
| 功能 | 运动神经元 | 指令向外，作用于效应器 | 又叫**传出神经元** |

> **提示**：形态三类记“假、多、双”或“假双多”都行，功能三类记“感、联、动”。两套分类的**类别名完全不同**，考试常把两行摆在一起让你对应。

## 灰质与白质

   * **灰质（gray matter）**

       * > **定义**：由神经细胞的**胞体**还有它的**树突**聚集形成的部位。

       * 出现位置被限定死：**只在中枢神经系统内**用这个词，周围神经系里没有灰质白质之说。

   * **白质（white matter）**

       * > **定义**：由**神经纤维**大量聚集形成的部位。

       * 大量髓鞘化的神经纤维聚集，颜色偏白，故名。

   * **皮质与髓质**

       * 大脑、小脑表面的那层灰质另有一个叫法，叫**皮质**。

       * 大脑、小脑的白质叫**髓质**。

       * 这是**大脑、小脑专属**的别称，脊髓没有皮质、髓质这一说。

## 神经核与神经节

| 术语 | 位置 | 构成 |
| :--- | :--- | :--- |
| **神经核** | 中枢神经系统内 | 形态和功能相似的神经元胞体聚集成团 |
| **神经节** | 周围神经系统内 | 形态和功能相似的神经元胞体聚集的部位 |

   * **判断依据**

       * 两者定义几乎一模一样，一个叫“核”，一个叫“节”。

       * 在中枢叫核，在周围叫节；判断题给出描述时看位置即可。

## 神经的三级结构

   * **神经纤维（nerve fiber）**

       * 单根神经纤维，可比作一根挂面。

   * **神经纤维束（nerve fasciculus）**

       * 许许多多根神经纤维聚集在一起、被一个膜包裹形成。

   * **神经（nerve）**

       * 许多神经纤维束再被神经外膜一包就叫神经。

       * 从单根纤维到神经，正好是三级结构，一层套一层。

## 反射与反射弧

   * **反射（reflex）**

       * > **定义**：机体对内外环境刺激所做出的一种**适宜**的反应。

       * “适宜”二字是要点：反应必须是对这个刺激来说合适、有意义的；否则是损伤或抽搐，不属反射。

   * **反射弧（reflex arc）**

       * > **定义**：完成反射的**形态基础**。

       * 由 5 大环节构成：感受器、传入神经、中枢、传出神经、效应器。

```text
   内外环境刺激（热水杯）
          │
          ▼
   ① 感受器    ── 皮肤里感受温热觉的那一个
          │  传入神经
          ▼
   ② 传入神经  ── 假单极神经元，把信息送进来
          │
          ▼
   ③ 中枢      ── 脊髓中央管周围灰质：后角 → 前角
          │  传出神经
          ▼
   ④ 传出神经  ── 运动神经元，把指令送出去
          │
          ▼
   ⑤ 效应器    ── 产生运动效应的部位，肱二头肌
          │
          ▼
        屈曲反射：手离开热水杯
```

> **注意**：这 5 个环节中**任何一个环节损伤，反射都不能完成**——不是减弱，是不能完成。

## 脊髓的位置

   * **脊髓（spinal cord）**

       * > **定义**：脑控制下的一个低级中枢；自己也能干活（如完成反射），但它的上面还压着一个脑。

       * 位于**椎管内**这个骨性管中，外面裹有 3 层被膜，最里边那一层叫**软膜**。

       * 长度大约 45 厘米。

       * **上端**相当于**枕骨大孔**的水平，与**脑干**相连。

       * **下端**终止于**第 1 腰椎水平**（成人）；小儿终止于**第 3 腰椎水平**。

       * 向下借助一条**终丝**来固定。

> **提示**：小儿椎管相对长，脊髓还没长到，末端位置比成人更高；成人 L1 与小儿 L3 两个数都是考点。

## 脊髓的外部形态

整体形状记五个字：**前后稍扁的扁圆柱状**。要记住的结构是**一个圆锥、两个膨大、六条纵沟**，再加**根丝、终丝、马尾神经**几个概念。

### 脊髓圆锥与终丝

   * **脊髓圆锥（conus medullaris）**

       * 脊髓**下端**逐渐变细，形成的圆锥状结构。

   * **终丝（filum terminale）**

       * 软膜包绕脊髓圆锥后继续向下延续形成的丝状结构，借它把脊髓固定到尾骨的骨膜上。

       * 里面**没有神经细胞**，因此**没有传导的功能**，只是固定脊髓的结构。

### 颈膨大与腰膨大

   * **两个膨大**

       * 脊髓全长有两个膨大部位：颈部的**颈膨大**、腰部的**腰膨大**。

       * 形成的直接原因是：支配上肢、下肢的神经元胞体大量聚集在脊髓内，胞体聚得越多该处越粗。

       * 节段范围：颈膨大在**颈 4 到胸 1 节段**，腰膨大在**腰 2 到骶 3 节段**。

       * 反过来记最快：正因为人有了四肢、支配四肢的胞体大量聚集在这两个部位，脊髓才鼓出两个膨大；**如果人没有四肢，脊髓上下均匀一致，根本没有膨大**。

### 六条纵沟与根丝

   * **六条纵沟**

       * 前正中裂 1 条，**最深**；后正中沟 1 条；前后外侧沟分左右两侧共 4 条。

       * 合计 1 + 1 + 4 = 6 条纵沟。

> **易错点**：⚠️ 前后外侧沟是**分左右的**，一侧 2 条（1 条前外侧、1 条后外侧），两侧一共 4 条；加上正中那两条才凑成 6。别把“前后外侧沟”当成一条算，那就成 4 了。

   * **根丝、前根与后根**

       * 从前后外侧沟发出来的**神经纤维束**叫**根丝**。

       * 根丝组成前方的叫**前根**，组成后方的叫**后根**。

       * 前根与后根在**椎间孔**部位汇聚在一起，构成**脊神经**。

```text
              后外侧沟 ──┬── 后根 ┐
                          │        ├─▶ 椎间孔 ─▶ 脊神经
          脊髓 ───────────┘        │
              前外侧沟 ────── 前根 ┘
```

### 马尾

   * **马尾（cauda equina）**

       * 下部节段的脊神经下行一段后在相应椎间孔发出，根丝也下降一段、在对应椎间孔发出；不断下降的结果是这些神经根**缠绕在终丝的周围，聚集成束**，这一束即马尾。

       * 马尾神经中**最中心的那个是终丝**，它不是神经根，没有传导能力；其余才是神经根。整束称**马尾神经**。

> **易错点**：⚠️ 马尾里最中间那根是**终丝**，不是神经根，也不参与传导——最容易在“马尾由什么组成”的题上栽跟头。

## 脊髓灰质

脊髓断面中央是 H 型（蝴蝶状）的灰质，灰质内是**脊髓中央管**，灰质在外、白质包在外边。

| 灰质分部 | 位置与范围 |
| :--- | :--- |
| **后角** | 向后突出；反射弧中在此把来自传入侧的冲动转给前角 |
| **前角** | 向前突出；存运动神经元，其冲动经前根传出 |
| **侧角** | 位于侧边；**不是所有节段都有**，只在**胸 1 到腰 3 节段**出现 |
| **中间带** | 前后角之间的灰质 |
| **中央灰质** | 中央管**后方**为**灰质后连合**，**前方**为**灰质前连合**，这两部分合称中央灰质 |

```text
                        后正中沟
                            │
                  ╭─────────┼─────────╮
                  │  ╭──────┴──────╮  │
           后角 ──┤  │  灰质后连合  │  ├── 后角  向后突出
                  │  │            │  │
                  │  │  中央管   │  │
                  │  │            │  │
                  │  │  灰质前连合  │  │
           侧角 ──┤  ╰──────┬──────╯  ├── 侧角  仅胸1～腰3
                  │         │         │
                  │  中间带 │         │  前后角之间的灰质
                  │         │         │
           前角 ──┤  ╭──────┴──────╮  ├── 前角  向前突出
                  │  ╰─────────────╯  │
                  ╰─────────┬─────────╯
                            │
                        前正中裂
```

## 脊髓白质

   * **三大索**

       * 按后角、前角画出两条虚线，白质分成前索、后索、外侧索三块。

       * 索内传导束分两个方向：**往上的叫上行束，往下的叫下行束**。

| 索 | 上行束（感觉传导束） | 下行束（运动传导束） |
| :--- | :--- | :--- |
| **后索** | 薄束、楔束——躯干四肢的深部感觉与精细触觉 | |
| **外侧索** | 脊髓丘脑侧束——痛、温觉 | 皮质脊髓侧束——四肢骨骼肌的随意运动 |
| **前索** | 脊髓丘脑前束——触压觉 | 皮质脊髓前束——躯干的随意运动 |

   * **上行束共 4 个**

       * 后索内的**薄束**和**楔束**，传导躯干、四肢的深部感觉（深度感觉与精细触觉）。

       * 外侧索内的**脊髓丘脑侧束**，传导痛、温觉，在侧索上升。

       * 前索内的**脊髓丘脑前束**，传导触压觉，在前索上升。

   * **下行束共 2 个**

       * **皮质脊髓侧束**管理四肢骨骼肌的随意运动。

       * **皮质脊髓前束**管理躯干的随意运动。

> **提示**：先记“三索、四个上行、两个下行”这个骨架，再往里填名字。
