# 男性生殖系统：生殖腺、输送管道与外生殖器

## 生殖系统的三分框架

* **内生殖器与外生殖器**

    * > **定义**：不分男性女性，生殖系统一律由内生殖器和外生殖器两大部分构成。

    * 内生殖器再分三块：生殖腺、输送管道、附属腺体。

    * 男性的生殖腺是睾丸；附属腺体是精囊腺、前列腺、尿道球腺；外生殖器是阴茎和阴囊。

* **男性生殖系统的归属**

    ```text
                            生 殖 系 统
                    ┌───────────┴───────────┐
                 内生殖器                 外生殖器
            ┌────────┼────────┐              │
          生殖腺   输送管道   附属腺体      阴茎 · 阴囊
           睾丸   输精管      精囊腺
                 精索        前列腺
                 射精管      尿道球腺
                 尿道
    ```

* **输送管道的四条**

    * 输精管、精索、射精管、尿道合起来构成男性的输送管道。

    * 精索不是一条独立的管道，而是动脉、静脉、淋巴、神经与输精管伴行成束所占据的部位。

## 睾丸

### 形态与位置

* **睾丸**

    * > **定义**：男性唯一的生殖腺，形态为扁卵圆形的成对器官。

    * 方位名称：上、下两端称上端与下端；前、后两边称前缘与后缘；内、外两面称内面与外面。

    * 位于阴囊内，左右各一，是一对。

* > **易错点**：睾丸的长轴方向与肾脏**正好相反**。肾脏是前后为面、内外为缘（因它扁贴在腹后壁上）；睾丸是前后为缘、内外为面。

### 白膜、小隔、小叶

* **睾丸白膜**

    * 睾丸断面外层坚韧的椭圆形外壳。

    * 由白膜向睾丸实质内发出许多**睾丸小隔**。

* **睾丸小隔与睾丸小叶**

    * 小隔把睾丸实质划分成若干个睾丸小叶。

    * 每个小叶内都含有管道：曲细精管和直细精管。

* **睾丸纵隔、睾丸输出管与附睾管**

    * 直细精管在睾丸后缘处进入睾丸纵隔。

    * 小管从睾丸后缘发出后改称睾丸输出管。

    * 睾丸输出管进入附睾，在附睾内盘曲形成附睾管。

    ```text
          睾丸白膜
                │  发出
                ▼
          睾丸小隔 ──→ 睾丸小叶（若干个）
                            │  内含
                            ▼
                     曲细精管 + 直细精管
                            │  直细精管在睾丸后缘进入
                            ▼
                       睾丸纵隔
                            │  在后缘发出
                            ▼
                       睾丸输出管 ──→ 进入附睾
                                             │
                                             ▼
                                   附睾管（盘曲）
    ```

### 功能

* **产生精子**

    * 精子在曲细精管内产生。

    * 产生后路线固定：曲细精管 → 直细精管 → 睾丸纵隔 → 睾丸输出管 → 附睾管，再往下经输精管、射精管一路输送。

* **分泌男性激素**

    * 分泌者不是小管，而是管道**之间**的间质细胞。

    * 间质细胞分泌的男性激素**直接入血**。

    * 男性激素维持男性第二性征：声音、喉结、胡须。

## 附睾

* **附睾**

    * > **定义**：紧贴睾丸后上方的一个长而粗细不等的扁圆器官，由睾丸输出管盘曲而成。

    * 形态上分三部：前方膨大部分为头，中间为体，末端为尾。

    * 位置在睾丸的后上方。

* **附睾与输精管的衔接**

    * 输精管正是从附睾尾部起始的。

    * 附睾管是附睾内盘曲的管道，来自睾丸输出管的一端即接入其中。

## 输精管

### 走行全程

* **输精管**

    * > **定义**：起自附睾尾部、止于膀胱底的长管道，分部走行全程。

    * 路线：在睾丸的后内侧上升 → 经过阴囊根部 → 再经过腹股沟管 → 进入盆腔 → 到达膀胱底。

    * 到膀胱底后，与一个腺体（精囊腺）的排泄管共同组成射精管，输精管走行全程到此为止。

### 分布四部

* **输精管四部**

    * 从附睾尾部往上数，输精管分四部分。

    | 名称 | 范围 |
    | :--- | :--- |
    | 睾丸部 | 从附睾尾部上升的这一段 |
    | 精索部 | 从睾丸上端到腹股沟管的皮下环 |
    | 腹股沟管部 | 在腹股沟管内的那一段，简称管部 |
    | 盆部 | 进入盆腔之后的部分，四段里最长的就是它 |

* **四部与精索范围的关系**

    * 精索部由输精管与伴行的血管、淋巴、神经共同占据，因此精索的起止界与输精管的精索部相邻接。

    * 腹股沟管部对应精索穿过腹股沟管的区段。

### 管道特点与结扎部位

* **管壁特征**

    * 输精管腔小壁厚：管腔非常小，管壁非常厚。

    * 手感硬如麻绳，非常硬。

* **结扎术的定位与选择**

    * 临床上做输精管结扎时很容易辨认它：手往里一摸，最硬的那个就是。

    * 男性结扎术应选择在阴囊根部结扎。

    * 选阴囊根部的理由：该处最表浅，皮肤切个小口即可；里边是一根柔软的索状结构，在此一摸即可把最硬的输精管勾出来，一结扎就完成。

## 精索

* **精索**

    * > **定义**：一个柔软的索状结构，范围从睾丸上端一直到腹股沟管的腹环。

    * 成"索"的原因：动脉、静脉、淋巴、神经都通过腹环进入腹股沟管，与输精管相伴而行并一直伴行到睾丸上端，这一束同行结构即打成索。

    * 组成有五样：睾丸动脉、蔓状静脉丛（静脉）、神经、淋巴、硬如麻绳的输精管。

    ```text
          腹股沟管腹环
                ║
                ║   ← 这一整段就是"精索"
                ║      动脉 · 静脉 · 淋巴 · 神经 · 输精管
                ║
          睾丸上端
                │
             睾丸
    ```

## 射精管

* **输精管壶腹**

    * 输精管的末端膨大部分称输精管壶腹。

* **射精管**

    * > **定义**：由输精管壶腹与精囊腺的排泄管汇合构成的极短管道，左右各一对。

    * 合成后在前列腺内穿过，位置在前列腺实质内。

    * 开口于尿道的前列腺部后壁，即尿道嵴中间膨大部位下方的两个小孔。

* **射精管在前列腺内的毗邻标志**

    * 前列腺的水平切面上，前方是前列腺前叶，后方是前列腺中叶，再向后是前列腺后叶，两侧是前列腺侧叶。

    * 前列腺后方有前列腺沟，中间有尿道贯穿，尿道后壁形成纵行隆起称尿道嵴。

    * 精囊腺的排泄管与输精管壶腹从后方汇合，构成的就是射精管。

## 附属腺体

### 精囊

* **精囊（精囊腺）**

    * > **定义**：位于膀胱底后方的长椭圆形囊状器官，剖开内含腔。

    * 形态为长椭圆形的囊状器官，剖开后里面都是腔。

    * 位置在膀胱底的后方。

    * 功能是分泌淡黄色的、粘稠的液体，该液体参与精液的组成。

    * 它的排泄管与输精管壶腹汇合，构成射精管。

### 前列腺

* **前列腺的形态与位置**

    * 形态为栗子形，底朝上、尖朝下，尖端下方正好是盆底的肌肉。

    * 位置在膀胱与尿生殖隔之间，即膀胱底的下方。

    * 形态上要重点记住后方的**前列腺沟**。

* **前列腺与直肠**

    * 前列腺的后方是直肠，与直肠的前壁紧贴。

    * 经直肠前壁可摸到前列腺，触摸时摸的是前列腺沟。

    * 前列腺肿大时前列腺沟消失，这一特点正是肛门指诊判断前列腺肥大的钥匙。

* **穿过前列腺实质的三种管道**

    * 尿道：贯穿前列腺。

    * 射精管：一对。

    * 前列腺本身的排泄管：后壁上有很多很多小的开口。

    * 尿道前列腺部剖开时，后壁有纵行隆起称尿道嵴，嵴的中间膨大部位下方有两个小孔，即射精管的开口。

* **前列腺的五个叶**

    * 前叶在前，中叶在后，后叶再向后，两侧为侧叶。

    * 前叶、中叶、后叶加两个侧叶，一共五个叶。

* **前列腺的功能**

    * 分泌浓白色的、碱性液体，同样参与精液的组成。

* **精囊与前列腺对照**

    | | 精囊（精囊腺） | 前列腺 |
    | :--- | :--- | :--- |
    | 形态 | 长椭圆形的囊状器官 | 栗子形，底朝上、尖朝下 |
    | 位置 | 膀胱底的后方 | 膀胱底的下方，位于膀胱与尿生殖隔之间 |
    | 分泌物 | 淡黄色的、粘稠的液体 | 浓白色的、碱性液体 |

    * 两者分泌物都参与精液的组成。

### 尿道球腺

* **尿道球腺**

    * 位置在盆底肌内。

    * 通过导管开口于尿道海绵体部。

* > **提示**：观察膀胱内壁时，膀胱内壁别处都有隆起，只有膀胱底是光滑的——膀胱三角最大的特点就是黏膜平滑、无皱襞。

## 外生殖器

### 阴茎

* **阴茎的位置与分部**

    * 位置在耻骨联合的下方，悬吊于耻骨联合下方。

    * 分部：前方为阴茎头，中间为阴茎体，末端左右各一为阴茎脚。

* **阴茎脚与海绵体**

    * 从腹侧面看，阴茎脚附着在耻骨弓上，即骨盆闭孔下方的耻骨支和坐骨支。

    * 海绵体有两种：中间一条为尿道海绵体；后面成对并排的两条为阴茎海绵体，阴茎海绵体的脚就是阴茎脚。

* **阴茎的功能**

    * 这里的尿道除排尿外还能排精。

### 阴囊

* **阴囊**

    * > **定义**：在阴茎后下方悬吊的皮肤囊袋，内有纵行的阴囊缝，正中有隔分为左右两腔。

    * 把阴茎向上提起来即可裸露阴囊，阴囊前正中有一个纵行皮纹称阴囊缝。

    * 打开阴囊前壁，正中间的隔把阴囊分成左右两个腔，腔里每侧各有一个睾丸和一个附睾。

## 男性尿道

### 长度与分部

* **男性尿道**

    * > **定义**：起自膀胱、止于尿道外口的管道，长度大约 16～22 厘米，功能为排尿和排精。

    * 分三部分：贯穿前列腺的是前列腺部，穿过盆底肌肉的是膜部，游离端这一段很长、实际最长的是海绵体部。

    | 部分 | 长度 | 归属 |
    | :--- | :--- | :--- |
    | 前列腺部 | 约 3 厘米 | 后尿道 |
    | 膜部 | 约 1.5 厘米 | 后尿道 |
    | 海绵体部 | 约 12～17 厘米 | 前尿道 |

    * 前列腺部和膜部合在一起叫后尿道，海绵体部单独叫前尿道。

    * 临床上讲的"后尿道梗阻"即指前列腺部与膜部这两段。

* **尿道走向**

    * 尿道从膀胱出发，穿前列腺、穿盆底肌肉，然后进入阴茎，最后开口于尿道外口。

### 两个弯曲

* **弯曲的部位与性质**

    * 穿膜部这一块形成一个弯曲，在阴茎部位又形成一个弯曲，共两个弯曲。

    * 一个是可变的（耻骨前弯），一个是不变的（耻骨下弯）。

    * 临床上导尿时弯曲越少尿管越容易进入，因此要设法让弯曲变少。

    ```text
    ① 正常站立位
            膀胱
             │╲
             │ ╲___   耻骨下弯（不变）
            前列腺  ╲___
                         ╲___   耻骨前弯（可变）
                              ╲
                               尿道外口

    ② 将阴茎提起
            膀胱
             │╲___   耻骨下弯（不变）
            前列腺  ╲
                          ╲________  阴茎被提起，耻骨前弯消失、变直

    ③ 再用力向后下牵拉阴茎
            膀胱
             │╲_______________╱‾‾‾‾‾  阴茎
             耻骨下弯也被拉开 → 整条尿道近似一条直线
    ```

### 三处狭窄

* **狭窄部位**

    * 起端的尿道内口。

    * 穿膜部处。

    * 尿道外口。

* **狭窄之间的膨大**

    * 前列腺部形成膨大。

    * 再往下扩大，相当于尿道海绵体的那一段。

* > **注意**：从整条男性泌尿系的图上看，起端最窄，然后前列腺部膨大，到膜部又最窄，再往下扩大，最后到尿道外口是最窄的。

## 全程通路串讲

* **从阴囊到尿道外口**

    ```text
      阴囊（左右两腔，中间有一隔）
          │
          ├── 睾丸 ── 白膜 / 小隔 / 小叶
          │              └── 曲细精管：产生精子
          │              └── 间质细胞：分泌男性激素（直接入血）
          │
          └── 附睾：头 · 体 · 尾
                  │  从尾起始
                  ▼
            输精管四部：
              睾丸部 → 精索部 → 腹股沟管部 → 盆部（最长）
                  │                       ↑
            精索：睾丸上端 ↔ 腹环       │
            （睾丸动脉·蔓状静脉丛·淋巴·神经·输精管）
                  │                       │
                  └────── 经腹股沟管 ─────┘
                  │  进入盆腔 → 绕到膀胱底
                  ▼
            与精囊腺的排泄管汇合
                  ▼
            射精管（一对，藏在前列腺实质内）
                  ▼
       开口于尿道前列腺部后壁 · 尿道嵴上的两个小孔

            前列腺（栗子形，底朝上尖朝下）
              五叶：前叶 · 中叶 · 后叶 · 两个侧叶
              后方贴直肠 → 肛门指诊摸前列腺沟
                  │
            尿道（16～22 厘米）
              前列腺部 约3cm ┐
              膜部      约1.5cm ┘ = 后尿道
              海绵体部 约12～17cm = 前尿道
              弯曲：耻骨下弯（不变）+ 耻骨前弯（可变）
              狭窄：尿道内口 · 穿膜部 · 尿道外口
                  │
            旁支：尿道球腺（位于盆底肌内）→ 导管开口于尿道海绵体部
                  │
            阴茎：阴茎头 · 阴茎体 · 阴茎脚（脚附着于耻骨弓）
                  │
              尿道外口
    ```

* **生殖腺、输送管道、附属腺体、外生殖器四块拼齐**，即构成男性生殖系的全貌。
