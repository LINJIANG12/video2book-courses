# 动脉系·腹主动脉、骨盆与下肢动脉

## 腹主动脉的起止

* **腹主动脉**

    * > **定义**：主动脉裂孔向下延续而成的一段动脉干，走行于脊柱前方。

    * 上界为主动脉裂孔，相当于第十二胸椎水平。

    * 下界为第四腰椎水平，就在这一高度分叉为左、右髂总动脉。

    * 髂总动脉再向下分为髂内动脉和髂外动脉。

## 腹主动脉分支的归类

* **壁支**

    * 膈下动脉，一对。

    * 腰动脉，四对，成对发出到腹后壁。

    * 骶正中动脉，一条，自分叉处向下发出。

* **成对的脏支**

    * 肾上腺中动脉、肾动脉、睾丸动脉各一对，睾丸动脉在女性称卵巢动脉。

* **不成对的脏支**

    * 腹腔干、肠系膜上动脉、肠系膜下动脉各一条。

* **成对与不成对混走的记忆难点**

    * 腹部的动脉分支太多，而且不像上肢那样左右对称、好数着背，脏支是成对与不成对混着走的。

    * 有效的记法是先把整张挂图的后壁摊开，把腹主动脉的分支从上到下一根一根点清楚，再分类。

| 类别 | 具体分支 | 数目 |
| :--- | :--- | :--- |
| 壁支 | 膈下动脉 | 1 对 |
| 壁支 | 腰动脉 | 4 对 |
| 壁支 | 骶正中动脉 | 1 条 |
| 成对脏支 | 肾上腺中动脉、肾动脉、睾丸动脉（女性称卵巢动脉） | 各 1 对 |
| 不成对脏支 | 腹腔干、肠系膜上动脉、肠系膜下动脉 | 各 1 条 |

## 腹主动脉分支的发出顺序

```text
        胸主动脉
           │
           ├── 主动脉裂孔（T12）＝ 腹主动脉上界
           │
           ├── 膈下动脉 ────── 壁支（1 对）→ 膈肌
           │
           ├── 腹腔干 ──────── 脏支（不成对）★ 重点
           │
           ├── 肾上腺中动脉 ── 脏支（成对）→ 肾上腺
           │
           ├── 肠系膜上动脉 ── 脏支（不成对）★ 重点
           │
           ├── 肾动脉 ──────── 脏支（成对）→ 肾
           │
           ├── 睾丸动脉 ────── 脏支（成对）→ 睾丸 / 卵巢
           │
           ├── 腰动脉 × 4 ──── 壁支 → 腹后壁
           │
           ├── 肠系膜下动脉 ── 脏支（不成对）★ 重点
           │
           ├── 骶正中动脉 ──── 壁支，自分叉处向下
           │
           └── 第四腰椎水平：分叉为左、右髂总动脉
                 （再分为髂内、髂外，此处不展开）
```

* **顺序判读**

    * 横着看是分支名称，竖着看是发出的高低顺序。

    * 主动脉裂孔稍下方先发一对膈下动脉，再往下是短干腹腔干，接着肠系膜上动脉，成对发出肾动脉，再一对睾丸动脉，再向下是肠系膜下动脉，后壁还成对发出四对腰动脉，最后在分叉处向下发出骶正中动脉。

    * 腹腔干位置高于肾动脉，在肾动脉的近侧。

    * 三个不成对脏支自上而下的高度依次是十二胸椎稍下方、第一腰椎、第三腰椎。

## 腹腔干

* **腹腔干**

    * > **定义**：腹主动脉在十二胸椎稍下方发出的短干，长约一个厘米。

    * 它之所以这么短，是因为一出来就要分成三大支，腹部的上半个脏器几乎全挂在它身上。

* **脾动脉**

    * 腹腔干分支中最粗大的一支，沿胰的上方横行向左，经脾门入脾。

    * 向上发出胃后动脉和胃短动脉，二者都营养胃底部。

    * 在胃大弯侧发出胃网膜左动脉。

* **胃左动脉**

    * 腹腔干的第二个分支，向左上方发出，沿胃小弯走。

    * 同时发出食管升支，到食管的腹段。

* **肝总动脉**

    * 腹腔干的第三个分支，向右发出，走法是一头朝上、一头朝下，两头都还有分支，是三条分支里最绕的一支。

    * 向上的一头是肝固有动脉。

    * 向下的一头是胃十二指肠动脉。

* **肝固有动脉**

    * 肝固有动脉在肝门处形成两支入肝，分别叫左支、右支。

    * 右支发出胆囊动脉到胆囊。

    * 肝固有动脉的根部还发出一支胃右动脉，沿胃小弯走，与胃左动脉吻合。

* **胃十二指肠动脉**

    * 在肝固有动脉左右两支的分界部位向下发出。

    * 在胃和十二指肠的后方下降，在十二指肠和胰头之间分成胰十二指肠上前动脉与胰十二指肠上后动脉。

    * 在十二指肠的下部发出胃网膜右动脉，与胃网膜左动脉吻合。

```text
腹腔干（T12 稍下方，短干约 1 cm）
├─ 胃左动脉 ──── 向左上方，沿胃小弯走
│                └─ 食管升支 ── 到食管的腹段
│
├─ 脾动脉 ────── 粗大，胰的上方横行向左，经脾门入脾
│                ├─ 胃后动脉 ┐
│                ├─ 胃短动脉 ┴─ 都营养胃底部
│                └─ 胃网膜左动脉 ── 胃大弯侧
│
└─ 肝总动脉 ──── 向右
     ├─ 向上 ─→ 肝固有动脉
     │           ├─ 根部发出：胃右动脉 ── 沿胃小弯，与胃左动脉吻合
     │           ├─ 左支 ┐
     │           └─ 右支 ┴─ 经肝门入肝
     │                    └─ 胆囊动脉
     │
     └─ 向下 ─→ 胃十二指肠动脉（胃与十二指肠后方下降）
                 ├─ 在十二指肠与胰头之间分成两支：
                 │    胰十二指肠上前动脉
                 │    胰十二指肠上后动脉
                 └─ 十二指肠下部 ─→ 胃网膜右动脉
                                    （与胃网膜左动脉吻合）
```

> **易错点**：胃网膜左动脉来自脾动脉，胃右动脉来自肝固有动脉的根部，二者分属腹腔干的两大分支，不要在画图时挂到同一根干上。

> **易错点**：胃网膜右动脉来自胃十二指肠动脉，不是来自肝固有动脉。

## 肝总动脉结扎后的血供绕行

* **吻合支**

    * > **定义**：彼此沟通的动脉分支，某干被结扎后血流可经吻合支绕过阻塞段。

    * 肝总动脉在手术中被误扎后，血确实过不来，但可以绕过去。

* **绕行路线**

    * 小弯侧的吻合是胃左动脉与胃右动脉相互吻合，再通到肝固有动脉。

    * 大弯侧的吻合是胃网膜右动脉与胃网膜左动脉相互吻合。

* **临床意义**

    * 肝总动脉被结扎后，肝脏一般不会坏死。

    * 遇到"某干被结扎会不会怎样"的问题，先去找吻合支。

> **提示**：血管扎住了，血并不是真的过不来，它绕得过去。

## 肠系膜上动脉

* **肠系膜上动脉**

    * > **定义**：腹主动脉在第一腰椎水平由主干发出的不成对脏支。

    * 营养范围从阑尾、盲肠、升结肠一直到横结肠。

* **主要分支**

    * 小肠动脉：发出很多很多分支，沿小肠系膜两层之间走，分布到小肠，即空肠和回肠。

    * 回结肠动脉：发出一支分布到阑尾，这支就叫阑尾动脉。

    * 右结肠动脉：在主干上发出，向右，分成一个降支、一个升支。

    * 中结肠动脉：在靠近根部的地方发出，分成一个右支、一个左支。

    * 直支：从动脉弓上发出，分布到肠管。

* **肠管地图**

    * 腹腔内肠管自上而下的次序是：升结肠、盲肠（盲肠下方有阑尾）、回肠末段、横结肠、降结肠、乙状结肠、直肠、肛管。

## 肠系膜下动脉

* **肠系膜下动脉**

    * > **定义**：腹主动脉在第三腰椎水平发出的不成对脏支。

    * 营养范围是脾曲、降结肠、乙状结肠和直肠上 2/3。

* **分支**

    * 左结肠动脉：升支和降支各自去与乙状结肠动脉吻合，然后发出直支分布到肠管。

    * 乙状结肠动脉：发 2~3 支。

    * 直肠上动脉。

> **注意**：直肠下 1/3 和肛管不在肠系膜下动脉的营养范围内，它的范围就卡在这两条线之间。

> **注意**：肠系膜上、下动脉在横结肠处交接，上动脉管到横结肠，下动脉从脾曲接手。

## 三个不成对脏支对照

| 动脉 | 发出水平 | 主要分支 | 营养范围 |
| :--- | :--- | :--- | :--- |
| 腹腔干 | T12 稍下方 | 胃左动脉、脾动脉、肝总动脉 | 胃、肝、脾、胰头、十二指肠上部 |
| 肠系膜上动脉 | L1 | 小肠动脉、回结肠动脉、右结肠动脉、中结肠动脉 | 空肠、回肠、阑尾、盲肠、升结肠、横结肠 |
| 肠系膜下动脉 | L3 | 左结肠动脉、乙状结肠动脉、直肠上动脉 | 脾曲、降结肠、乙状结肠、直肠上 2/3 |

```text
肠系膜上动脉（L1）                 肠系膜下动脉（L3）
   │                                    │
   ├─ 空肠、回肠                        ├─ 脾曲
   ├─ 阑尾                              ├─ 降结肠
   ├─ 盲肠                              ├─ 乙状结肠
   ├─ 升结肠                            └─ 直肠上 2/3
   └─ 横结肠
                                     ————————————
                                     直肠下 1/3、肛管：不在其列
```

* **反查用法**

    * 记住发出的水平、分支、营养范围中的任何一列，都能反查另外两列。

    * 腹腔干营养胃、肝、脾、胰头、十二指肠上部，胰头的血供正是靠这一支的分支接进来的。

## 肾上腺的血液供应

* **肾上腺的位置**

    * 肾上腺是肾脏上方突起的部分。

* **肾上腺的动脉**

    * 肾上腺上动脉：由膈下动脉发出，膈下动脉在主动脉裂孔稍下方成对发出。

    * 肾上腺中动脉：由腹主动脉主干直接发出，是腹主动脉的成对脏支。

    * 肾上腺下动脉：由肾动脉发出。

    * 肾上腺的血液供应有三个来源——上来自膈下动脉，中来自腹主动脉，下来自肾动脉。

| 动脉 | 来源 |
| :--- | :--- |
| 肾上腺上动脉 | 膈下动脉 |
| 肾上腺中动脉 | 腹主动脉（主干直接发出） |
| 肾上腺下动脉 | 肾动脉 |

## 胰腺的血液供应

* **胰腺的分部**

    * 胰腺分胰头、胰体、胰尾，胰头有钩突。

### 胰头与钩突

* **胰头的血供来源有两个**

    * > **定义**：胰头由上、下两组动脉同时供血，是两个来源的器官。

* **来自胃十二指肠动脉的一组**

    * 走行路线是肝总动脉 → 肝固有动脉 → 胃十二指肠动脉。

    * 胃十二指肠动脉发出两支，一支沿胰头前方下降，另一支沿胰头后方下降，两支互相吻合，合起来就是胰十二指肠上动脉的前、后两支。

* **来自肠系膜上动脉的一组**

    * 肠系膜上动脉有两个分支是从钩突那块穿出来的。

    * 穿出后一支沿胰头的前方向右上方去，一支在胰头的后方向上去，二者就是胰十二指肠下动脉的前、后两支。

    * 脾动脉的分支也参与这两组之间的吻合。

### 胰体与胰尾

* **胰体、胰尾只有一个血供来源**

    * > **定义**：胰体和胰尾由脾动脉的分支单独营养，不属于多源供血的器官。

* **脾动脉给胰的分支**

    * 胰背动脉：从脾动脉发出后进入胰体。

    * 胰大动脉：同样从脾动脉发出，与胰背动脉相互吻合，形成胰下动脉。

    * 胰支：很多很多小支，都到胰体和胰尾。

    * 胃后动脉、胃短动脉、胃网膜左动脉是脾动脉向胃的分支，不算胰的血供。

```text
胰腺
├─ 胰头（+ 钩突）── 两个来源
│    ├─ 胃十二指肠动脉 → 胰十二指肠上前动脉
│    │                  胰十二指肠上后动脉
│    └─ 肠系膜上动脉  → 胰十二指肠下前动脉
│                       胰十二指肠下后动脉
│        （两组相互吻合，脾动脉的分支也参与吻合）
│
└─ 胰体、胰尾 ── 一个来源：脾动脉
     ├─ 胰背动脉
     ├─ 胰大动脉
     ├─ 胰下动脉（由胰背、胰大相互吻合形成）
     └─ 胰支（很多很多小支）
```

## 髂总动脉

* **髂总动脉（common iliac artery）**

    * > **定义**：自第四腰椎水平（腹主动脉分叉处）至骶髂关节前方的一段动脉，末端分为髂内动脉和髂外动脉。

    * 起点是腹主动脉在**第四腰椎水平**左右分出的一对分支。

    * 走行区间为**上起第四腰椎、下到骶髂关节前方**，这一段本身不长，名字却最长。

    * 后面要学的髂内动脉与髂外动脉两条主干，都从它身上分出来。

* **分家位置与走向**

    * 再分叉点固定在**骶髂关节的前方**，分叉方向直接决定了两条分支的分工。

```text
                  腹主动脉
                     │
            ┌────────┴────────┐
            │                 │
         髂总动脉          髂总动脉
            │                 │
       ┌────┴────┐       ┌────┴────┐
       ↓         ↓       ↓         ↓
     髂内动脉  髂外动脉  髂内动脉  髂外动脉
      入盆腔   过盆缘   入盆腔   过盆缘
```

    * 向内拐进盆腔的一支是**髂内动脉**，盆腔里的东西全归它管。

    * 越过盆缘继续一路向下的一支是**髂外动脉**，它成为下肢的主干。

## 髂内动脉的壁支与脏支

* **髂内动脉（internal iliac artery）**

    * 入盆腔后，分支按送血对象分成两拨：一拨送到**盆壁**（肌肉、骨盆壁面），一拨送到**盆腔里的脏器**。

    * 在男性盆腔正中矢状断面上，壁支有臀上动脉、臀下动脉、骶外侧动脉，前方的闭孔动脉也是壁支；除此之外还有到膀胱去的、到直肠去的。

    * 换成女性盆腔正中矢状断面，壁支照样在，另外还多出一根专门到子宫去的动脉，以及到会阴部去的。

### 壁支

* **臀上动脉、臀下动脉**：到臀肌去。

* **髂腰动脉、骶外侧动脉、闭孔动脉**：到盆壁去。

### 脏支

* **膀胱上动脉、膀胱下动脉**：到膀胱去。

* **子宫动脉**：到子宫去。

* **直肠下动脉**：到直肠去。

* **阴部内动脉**：到会阴部去，并发出肛门动脉。

## 子宫动脉

* **子宫动脉（uterine artery）**

    * 走法是沿盆壁下来，然后**横行向内迂曲**，到**子宫颈的两侧**，在这里分成升支和降支。

    * 升支又发出三根支，三根支各管一摊。

```text
    髂内动脉
       │  沿盆壁下行 → 横行向内迂曲
       ▼
      子宫颈两侧
       ├── 升支 ──┬── 输卵管支（沿输卵管走）
       │          ├── 卵巢支（经悬韧带下行，与输卵管动脉吻合，再发分支营养卵巢）
       │          └── 阴道支（营养阴道）
       └── 降支
```

* **升支的三根分支**

    * **输卵管支（输卵管动脉）**：沿着输卵管走。

    * **卵巢支**：在悬韧带里下来，和输卵管动脉有吻合，同时还发出分支营养卵巢，相当于给它开了个双保险。

    * **阴道支**：向下营养阴道。

* ⚠️ **易错点**：子宫动脉的下方有一条重要的管道通过，就是输尿管。做子宫动脉结扎的时候，止血钳一定要**靠近子宫颈**夹，千万不能远离子宫颈——因为它俩中间只隔了**不到两厘米**，往外偏一点，就把输尿管误扎了。

## 直肠与肛管的血供

* **两段来源不同，换手点在盆膈**

    * 盆膈以上叫直肠，盆膈以下那一段就是肛管，这两段的动脉来源是不一样的。

    * **直肠的上三分之二**由**直肠上动脉**供应，而直肠上动脉来自**肠系膜下动脉**，由它发出的这一支一路向下走，专管直肠上段。

    * **肛管**以及直肠的下段，靠的是**阴部内动脉**：阴部内动脉在盆腔里走行，然后穿盆膈到会阴部去，顺手发出**直肠下动脉**。

    * 阴部内动脉还发出一个更小的分支叫**肛门动脉**，专门营养肛管。

    * 直肠下动脉**大多数**来源于阴部内动脉，但**也有直接在髂内动脉上分出来**的。

    * > **结论**：上段肠系膜下、下段阴部内。记住这一条，两段就都通了。

## 髂外动脉

* **髂外动脉（external iliac artery）**

    * > **定义**：骶髂关节前方至腹股沟韧带中点深面的一段，穿过盆缘下行，至腹股沟韧带处续接为股动脉。

    * 上界就在**骶髂关节前方**（也就是髂总动脉分家的地方），下界是**腹股沟韧带中点的深面**。

    * 过了腹股沟韧带，它就不叫髂外了，换了个名字叫**股动脉**。

### 两条分支

* **旋髂深动脉**：主要到髂肌和附近的肌肉去。

* **腹壁下动脉**：主要营养腹直肌。

## 股动脉

* **股动脉（femoral artery）**

    * 起点在**腹股沟韧带中点的下方**，由髂外动脉延续而来；到**腘窝上缘**这一段叫股动脉。

    * 位置范围记成一条线：**腹股沟韧带中点 → 腘窝上缘**。

    * 给血管找位置的骨性坐标：股骨头、股骨颈、大转子、股骨体、收肌结节、两个侧髁，前面是髌面，后面还有个小转子。

### 走行三关

* **先在股三角内下降**（大腿前部那个局部解剖的三角区域）。

* **再穿收肌管**。

* 最后**穿腱裂孔**跑到股骨下端的后方，到这里它就**改名叫腘动脉**了。

### 分支

* 股动脉自己发出**旋髂浅动脉**、**腹壁浅动脉**。

* **股深动脉**在**腹股沟韧带下方约 2.5 cm** 分出去，是真正"扎进肌肉里"的一支。

* 股深动脉发出**三个穿支**到达股骨后方，供应大腿后群肌和内侧群肌。

* 股深动脉向上发出**旋股外侧动脉**，营养大腿前群肌。

* 股深动脉发出**旋股内侧动脉**，绕过股骨颈的内侧，并另发一小支到大腿的内收肌群。

```text
    股动脉（腹股沟韧带中点下方接髂外动脉）
      │  走行：股三角 → 收肌管 → 腱裂孔 → 腘窝上缘
      │
      ├─ 旋髂浅动脉
      ├─ 腹壁浅动脉
      └─ 股深动脉（腹股沟韧带下方约 2.5 cm 发出）
           ├─ 穿支 ×3 ──▶ 大腿后群肌、内侧群肌
           ├─ 旋股外侧动脉 ──▶ 大腿前群肌
           └─ 旋股内侧动脉 ──▶ 绕过股骨颈内侧，再发分支到大腿内收肌群
```

### 摸脉与止血

* 股动脉是这一段最实用的血管——它位置表浅、搏动明显。

* ⚠️ **易错点**：摸脉点是**腹股沟韧带中点的下方**；止血时把手指压向**骨盆的方向**，就能压住这段动脉。

## 腘动脉

* **腘动脉（popliteal artery）**

    * 主干就在**腘窝的后正中线**上下降。

    * 腘窝的骨性坐标：上面是股骨下端的外侧髁、收肌结节、内侧髁和髁间窝，下面是胫骨的髁间隆起、比目鱼肌线，旁边还有腓骨小头。

    * 发出**五个分支**：膝上外动脉、膝上内动脉、膝下外动脉、膝下内动脉，还有一个膝中动脉。

    * > **注意**：这一段只要求知道主干位置与这五个分支的名字，不用特意去记。

## 胫前动脉与胫后动脉

* **小腿的两条主干**

    * 腘动脉继续向下走过**膝关节后方**，就分成小腿的两条主干，分水的标志非常干脆。

    * **胫后动脉**：在小腿后群肌的**深面**下行，**经内踝后方**转向足底。

    * **胫前动脉**：**穿过小腿骨间膜**，到小腿前群肌的**深面**下行，一直走到**足背**。

    * 两者之间有吻合，不是各走各的死路。

* **改名链**

    * 名字一路改，路一直是往下走：**髂外 → 股 → 腘 → 胫前/胫后 → 足背/足底**。

```text
    髂外动脉
       │
       ▼  腹股沟韧带中点下方
    股动脉 ──股三角──▶ 收肌管 ──▶ 腱裂孔
       │
       ▼  腘窝上缘
    腘动脉（在腘窝后正中线上下降）
       │
       ├────────── 穿过小腿骨间膜，在小腿前群肌深面下降
       │                        │
       │                        ▼
       │                    胫前动脉
       │                        │
       │            内、外踝前方连线中点
       │                        │
       │                        ▼
       │                    足背动脉
       │                   （弓状动脉→跖背动脉→趾背动脉）
       │                        │
       │                   足底深支 ──► 穿到足底，与足底动脉弓吻合
       │
       └────────── 在小腿后群肌深面下降，绕内踝后方
                                │
                                ▼
                            胫后动脉
                                │
                                ▼
                    足底内侧动脉 ＋ 足底外侧动脉
                                │
                                ▼
                           足底动脉弓
                                │
                  趾底总动脉 ──▶ 趾底固有动脉
```

## 足的动脉

### 足背动脉

* **足背动脉（dorsalis pedis artery）**

    * 胫前动脉往下走到**内踝、外踝前方连线的中点**，就改名叫足背动脉了。

    * 这个点很浅、位置好认，**摸脉和止血都在这里**；规律是**两个结构连线的中点**。

    * 分支有：钻到足底去的**足底深支**；向外走一横的**弓状动脉**；上方还有**跗外侧动脉**、内侧的**跗内侧动脉**，以及**外踝前动脉**、**内踝前动脉**。

    * 弓状动脉上又发出很多分支到各个脚趾去，这一整片合称**跖背动脉**，再往下分成更小的**趾背动脉**。

    * > **注意**：跖背动脉、趾背动脉这些小支的名字不用记，知道它们是从弓状动脉上分出来的就行。

### 足底动脉弓

* **足底动脉弓（plantar arch）**

    * 胫后动脉绕过**内踝的后方**转向足底，在这里分成**足底内侧动脉**（还有浅支、深支之分）和**足底外侧动脉**。

    * **足底外侧动脉**再往前续接成**足底动脉弓**。

    * 足底动脉弓向下发出**趾底总动脉**，趾底总动脉再分到每个脚趾，就叫**趾底固有动脉**。

    * 另一条路是从上面接过来的：足背动脉发出的**足底深支**穿到足底，与足底动脉弓**吻合**——所以足背和足底本来就是一张网。

    * > **提示**：内踝的**后方**转到足底的那支动脉，在足底也能摸到搏动，判断位置同样以内踝为准。

## 全身摸脉点与止血点

* 这些点既是**摸脉**的位置，也是**压迫止血**的位置。

### 头颈部

    | 摸脉部位 | 动脉 |
    | :--- | :--- |
    | 耳屏的前上方 | 颞浅动脉 |
    | 咬肌前缘与下颌骨下缘的交界处 | 面动脉 |
    | 胸锁乳突肌前缘中点 | 颈总动脉 |

* 三个点从高到低排：耳朵前面是颞浅动脉，下颌角那一块（咬肌前缘和下颌骨下缘交角）是面动脉。

* 脖子侧面那条斜行的胸锁乳突肌，其前缘中点摸到的是颈总动脉。

### 上肢

    | 摸脉部位 | 动脉 |
    | :--- | :--- |
    | 肘窝前方 | 肱动脉 |
    | 腕部桡侧、尺侧 | 桡动脉、尺动脉 |
    | 三角窝的中点 | 桡动脉终支 |

* 肘窝前方摸到肱动脉，腕部桡侧与尺侧是最常用的两个点，分别摸到桡动脉与尺动脉。

* 别忘了还有一个小地方：把拳握起来、拇指伸开，腕背会露出一块**三角窝**，窝的中点同样能摸到搏动——那是**桡动脉的终支**。

* 桡动脉终支的走法有点绕：**必须绕过桡骨颈**，转到后侧，再在**第一掌骨间隙**穿到掌侧，最后才到这个窝的中点。

### 下肢

    | 摸脉部位 | 动脉 |
    | :--- | :--- |
    | 腹股沟韧带中点下方 | 股动脉 |
    | 腘窝 | 腘动脉 |
    | 内、外踝前方连线中点 | 足背动脉 |
    | 内踝后方 | 足底动脉（分足底内侧、足底外侧） |

* 下肢必须记住的第一个点就是**腹股沟韧带**这块，摸到的是股动脉；再往下依次是腘窝的腘动脉、内踝前方连线中点的足背动脉、内踝后方的足底动脉。

* 股动脉的**内侧**是一条重要的静脉叫**股静脉**，**外侧**是一个神经叫**股神经**；静脉和神经的名字都跟动脉同名。

* ⚠️ **易错点**：腹股沟韧带下方由内向外是**静脉 → 动脉 → 神经**（股静脉、股动脉、股神经）。记动脉的名字，等于把旁边三家的名字一起记住了；反过来，要做动脉穿刺或结扎时，往哪边偏都可能出事。

* 衔接关系串一遍：下肢动脉主干由髂外动脉接续而来，到腹股沟韧带中点下方改名**股动脉**；在大腿下降到腘窝上缘，改名**腘动脉**；腘动脉过膝关节后方，继续向下分成**胫后动脉**和**胫前动脉**；胫前转向**足背**，胫后转向**足底**，两者之间有吻合互相支援。
