# 运动传导通路：皮质脊髓束、皮质核束与上下运动神经元损伤

## 运动传导通路的构成

运动传导通路不是一个整体，它由两条路构成，分工不同，必须同时完好，随意运动才能既精准又随意。

### 锥体路

* **锥体路（pyramidal tract）**
    * > **定义**：主要支配随意运动的通路，兼管肢端一些精巧的活动。
    * 负责动作的**两端**——启动、终止、修正。
    * 动作一旦需要数清楚才能做（如并针前先数"我要并几针"），就归它管；数完并完才重新唠嗑。
    * 生活中的例子：齐步走的起步与立定；打毛衣的并针、加针。
    * 损伤后表现为瘫痪。

### 锥体外路

* **锥体外路（extrapyramidal tract）**
    * > **定义**：调节肌张力、协调随意运动的通路。
    * 维持体态和人体的姿势；完成习惯性的、节律性的活动。
    * 动作进入稳定节奏后由它接管，此时可以分心做别的事。
    * 生活中的例子：齐步走起来之后的左右脚交替；织平针时还能一边织一边唠嗑看电视。
    * 损伤后：震颤、动作缓慢、协同失调——如老人晃头、肢体震颤，买菜时一毛钱要掏二十分钟才掏得出来，这不是舍不得钱，是动作的节律和协调全乱了。

### 两路协作与后果对比

* 两条路缺一不可：锥体路一出毛病，协助它的那个路就没有用了，表现为直接瘫痪。
* 锥体路与锥体外路各管一头——一头管"起和止"，一头管"稳得住"。

| 比较方面 | 锥体路 | 锥体外路 |
| :--- | :--- | :--- |
| 主要功能 | 随意运动、肢端精巧活动 | 调节肌张力、协调随意运动 |
| 附加功能 | 动作的启动与终止 | 维持体态和人体姿势；完成习惯性、节律性活动 |
| 生活中的例子 | 齐步走的起步与立定；打毛衣的并针、加针 | 走起来之后的左右脚交替；织平针时还能唠嗑 |
| 损伤之后 | 瘫痪 | 震颤、动作缓慢、协同失调 |

## 皮质脊髓束

### 两级神经元

* **上运动神经元（upper motor neuron）**
    * > **定义**：胞体位于皮层的运动传导神经元。
    * 皮质脊髓束是到整个躯干和四肢去的，所以起于中央前回上 2/3，再加上旁中央小叶的前份。
* **下运动神经元（lower motor neuron）**
    * > **定义**：胞体位于脊髓前角细胞的运动传导神经元。
* 运动传导路由**两级神经元**完成，感觉传导则是三级神经元——这里跟感觉传导不一样，务必分清。
* > **易错点**："上"和"下"讲的是胞体位置的高下，不是在通路上的先后顺序。大脑皮层在上、脊髓前角在下，所以皮层那个才叫上运动神经元。

### 起止与完整行程

* **皮质脊髓束（corticospinal tract）**
    * > **定义**：起于大脑皮质、终于脊髓的下行路（运动路）——"皮质"是起点，"脊髓"是终点。
    * 完整行程如下：

    ```text
      中央前回上 2/3 + 旁中央小叶前份   ← 上运动神经元胞体
          │
          │  内囊后肢（内囊枕部）内下降
          │
          │  延髓下部：锥体交叉，纤维在此左右交换
          │
          │  对侧脊髓外侧索：皮质脊髓束下行，沿途发出侧支
          │
          │  同侧脊髓前角细胞              ← 下运动神经元胞体
          │
          │  效应器
    ```

    * 三个要点记住就够了：经过内囊后肢下降、在延髓锥体交叉处左右交换、在脊髓外侧索内下行。
* **锥体交叉（pyramidal decussation）**
    * > **定义**：延髓下部、锥体下方发辫式的交叉痕，是皮质脊髓束纤维左右交换的部位。
    * 束在脊髓里是沿外侧索下降的，途中不断发出侧支去够前角细胞。

| 要点 | 位置 |
| :--- | :--- |
| 一、经过内囊 | 内囊后肢（内囊枕部）内下降 |
| 二、左右交换 | 延髓的锥体交叉处 |
| 三、脊髓内下行 | 外侧索 |

* 内囊分前肢、膝部、后肢三大部，皮质脊髓束主要是在**后肢**内下降。

### 交叉点决定瘫痪在哪一侧

* 脊髓的外侧索发生病变：纤维在锥体交叉处已经换到对侧了，所以损伤平面以下表现为**同侧**肢体瘫痪。
* 交叉点以上的任何一个部位（内囊、脑干）发生病变：还没来得及交叉，所以表现为**对侧**半身瘫痪。
* 有了这三个要点，病变定位就变成了一道很简单的算术题：先判断病变落在锥体交叉的上游还是下游。
* > **易错点**："内囊病变对侧半身"与"脊髓外侧索病变损伤平面以下同侧"这两句最容易打架。判断的钥匙只有一个——病变在不在锥体交叉的**上游**。交叉点以上＝还没换边＝对侧；交叉点以下＝已经换边＝同侧。

## 皮质核束

### 起点与走行

* **皮质核束（corticonuclear tract）**
    * > **定义**：起于大脑皮质、终于脑干，与脑干内的运动核发生联系的下行束；旧称皮质脑干束。
    * 皮层上的分布区是一个"倒影"：从外上到内下依次是下肢、上肢、头面部，所以皮质核束起于**中央前回下 1/3**，管的是头面部。
    * 走向：中央前回下 1/3 → 内囊 → 往下到脑干 → 散开，分别去接脑干里的运动核。
    * 脑干里的运动核非常多，动眼神经核、滑车神经核、展神经核、面神经核等都是它的落点。
    * 纤维同样是**经过内囊**下降的。

### 双侧支配与一个半核

* 大多数情况下，一个核团左右两侧的皮质核束都管它。
    * 这条结论没有临床意义：每天中午两个人送饭，一个人病了没来，另一个顶上，你饿不着。
* **一个半核**——真正吃临床的只有这一条：
    * **面神经核（facial nucleus）**：只接受**对侧**皮质核束支配的是它的**下半**部分；上半部分实际上还是双侧支配。
    * **舌下神经核（hypoglossal nucleus）**：只接受**对侧**皮质核束支配。
    * 即"一个"舌下神经核，加上"半个"——面神经核的下半。

| 要点 | 内容 |
| :--- | :--- |
| 一 | 大多数脑干运动核受双侧皮质核束支配 |
| 二 | 面神经核下半和舌下神经核只接受对侧皮质核束支配 |
| 三 | 纤维经过内囊下降 |

### 核上瘫与核下瘫

* **面神经核上瘫（中枢瘫）**
    * > **定义**：面神经核上半完好、只有下半失去冲动时出现的面瘫，仅表现为**下四分之一瘫痪**。
    * 以内囊病变为例：内囊一坏，离它最近的面神经核**下半**首先得不到冲动；上半因为有双侧支配照样正常。
    * 这一侧**抬头纹还在**（上半没坏），医生让闭眼，两只眼都能闭上。
    * 这一侧**鼻唇沟变浅**，嘴歪，流口水。
* **面神经核下瘫（周围瘫）**
    * > **定义**：面神经核或面神经核以下任何一个部位受损时出现的面瘫，整个半拉脸都瘫。
    * 这一侧**没有抬头纹**；这一侧**眼睛闭不上**。
    * 同样是嘴歪、流口水。
* 命名依据：半侧脸瘫痪说明这一整套支配装置整个失灵了，病变肯定不在中枢而在**面神经**一侧，属周围；内囊损伤只影响面神经核的下半，只表现下四分之一。
* 面神经核分上、下半，整张脸分四份，支配关系如下：

    ```text
            皮质核束（中央前回下 1/3 → 内囊 → 脑干）
                                │
            ┌────────────────────┴─────────────────────┐
            │                                          │
            │    面神经核上半         面神经核下半     │
            │          │                    │          │
            │  双侧皮质核束支配      只接受对侧支配    │
            │          │                    │          │
            │ 面上四分之一表情肌   面下四分之一表情肌  │
            │                                          │
    ```

| 鉴别点 | 面神经核上瘫（中枢瘫） | 面神经核下瘫（周围瘫） |
| :--- | :--- | :--- |
| 病变部位 | 皮层或内囊 | 面神经核或面神经本身 |
| 瘫痪范围 | 只有面下四分之一 | 半张脸整个半拉脸 |
| 抬头纹 | 保留 | 消失 |
| 闭眼 | 两只眼都能闭上 | 眼睛闭不上 |
| 口角 | 鼻唇沟变浅、嘴歪、流口水 | 嘴歪、流口水 |

* > **提示**：核上瘫（中枢瘫）＝皮层或内囊出了问题，只有**面下四分之一**瘫，额纹保留、闭眼能闭；核下瘫（周围瘫）＝面神经核或面神经本身出了问题，**半张脸**全瘫，额纹消失、眼睛闭不上。

## 上下运动神经元损伤的鉴别

### 五个比较方面

* 判断顺序：先看瘫痪的特点，再比较肌张力、腱反射、病理反射，最后比较肌肉是否萎缩。
* 上运动神经元损伤表现为**硬瘫**（痉挛性瘫痪），下运动神经元损伤表现为**软瘫**（弛缓性瘫痪）。
* 典型对照：脊髓前角灰质炎（小儿麻痹）患者拄着拐杖，病侧那条腿像个面条一样来回悠，而且萎缩了——这就是软瘫，属下运动神经元损伤。
* > **提示**：肌张力与腱反射这一对最好记：上运动神经元损伤是**张力增高、腱反射亢进**；下运动神经元损伤是**张力降低、腱反射减弱或消失**。
* 肌萎缩一项特别好记：下运动神经元损伤**早期即出现萎缩**，上运动神经元损伤的早期是**没有萎缩**的。

| 比较方面 | 上运动神经元损伤 | 下运动神经元损伤 |
| :--- | :--- | :--- |
| 瘫痪特点 | 硬瘫（痉挛性瘫痪） | 软瘫（弛缓性瘫痪） |
| 肌张力 | 增高 | 降低 |
| 腱反射 | 亢进 | 减弱或消失 |
| 病理反射 | 出现 | 无 |
| 肌萎缩 | 早期无萎缩 | 早期即出现萎缩 |

### 病理反射的常用检查

* 病理反射是上运动神经元损伤的经典标志，下运动神经元损伤则没有病理反射。
* 临床上最常见的两个：
    * **弹中指试验（Hoffmann 反射）**
    * **Babinski 征（划脚心试验）**
* > **提示**：有了这五组临床表现，就能初步判断出是哪一个神经元损伤，然后再具体去找病变部位。
