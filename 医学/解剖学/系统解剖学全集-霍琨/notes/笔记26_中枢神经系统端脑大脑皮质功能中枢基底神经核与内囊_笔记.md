# 中枢神经系统·端脑：大脑皮质、功能中枢、基底神经核与内囊

## 端脑的整体形态

   * **端脑（cerebrum）**

       * > **定义**：人类神经系统的最高级中枢，冠状切面上被切开的两大块，夹在中间的一小块是间脑。

   * **半球间裂**

       * > **定义**：把端脑劈成左右两个半球的深裂隙。

       * 裂隙深处并非分离，左右两半球仍是连成一体的整体。

   * **胼胝体（corpus callosum）**

       * > **定义**：位于半球间裂深处、横跨中线的白质，把两个半球牢牢连成一个整体。

       * 内侧面只有胼胝体处与对侧相连，其余都是游离面。

   * **端脑的三个面**

| 面 | 特点 |
| :--- | :--- |
| 背外侧面 | 向上向外圆凸 |
| 底面 | 与颅窝一致，凹凸不平 |
| 内侧面 | 平坦；只有胼胝体处与对侧相连，其余都是游离面 |

   * > **易错点**：⚠️ 内侧面虽称为平坦，却不是光秃秃的一面——扣带回、旁中央小叶、楔叶都在上面。

---

## 大脑皮质的分叶

   * **中央沟**

       * > **定义**：从侧面看端脑时，一道纵行的深沟。

       * 它的前方是中央前沟，后方是中央后沟。

   * **顶枕裂**

       * > **定义**：位于内侧面的裂隙。

   * **额叶、顶叶、颞叶、枕叶**

       * > **定义**：中央沟与顶枕裂这两道沟裂把端脑分成的四块，分别为前方的额叶、上方的顶叶、外侧的颞叶、后下方的枕叶。

   * **岛叶（insula）**

       * > **定义**：第五个叶，藏在外侧裂的深面，裂隙深面里嵌着的一层皮质。

       * 从完整半球的外侧部位把上面一块皮质"扣开"拿掉，裂隙深面才能看到它。

   * > **提示**：岛叶必须掰开外侧裂才能见到，这是它与其余四叶最大的区别；大脑皮质一共五个叶，即额、顶、颞、枕、岛。

---

## 外侧面的沟与回

   * **沟与回**

       * > **定义**：大脑皮质凹进去的部位叫沟，隆起的部分叫回。

       * > **结论**：沟的名字不用特意去记，关键是记住回——重要的中枢全都落在回上。

   * **中央前回与中央后回**

       * 中央前回夹在中央沟和中央前沟之间，中央后回夹在中央沟和中央后沟之间。

   * **其余的沟**

       * 额叶有额上沟、额下沟；顶叶有顶间沟；枕叶有枕沟；颞叶有颞上沟、颞下沟。

       * 额叶的两个沟把额叶分成上、中、下三个回；顶间沟把顶叶分成上方的顶上小叶和下方的顶下小叶；颞叶的两个沟把颞叶分成颞上回、颞中回、颞下回。

   * **外侧面各叶的主要脑回**

| 脑叶 | 主要脑回 |
| :--- | :--- |
| 额叶 | 额上回、额中回、额下回 |
| 顶叶 | 顶上小叶、顶下小叶（以顶间沟为界） |
| 颞叶 | 颞上回、颞中回、颞下回 |
| 枕叶 | 楔叶、舌回 |

---

## 内侧面的沟与回

   * **分离左右半球须切断的三个结构**

       * > **定义**：要把左右半球分开，胼胝体、丘脑和脑干这三个结构必须切断。

       * 切断之后，胼胝体上方的脑回全都是游离面。

   * **扣带沟与扣带回**

       * 扣带沟是胼胝体上方的这条沟，它和胼胝体之间的脑回叫扣带回。

       * 扣带回到后端收窄，这一窄段叫扣带回峡。

   * **海马旁回与海马回钩**

       * 内侧面靠下方那条狭窄的脑回叫海马旁回，它再往下钩过去的一段叫海马回钩。

       * 旁边还有齿状回和海马本身。

   * **枕颞内侧回与枕颞外侧回**

       * 位于更下方的两个纵行脑回。

   * **楔叶与楔前叶**

       * 顶枕沟和距状沟围出的部分叫楔叶，即距状沟上方的部分；楔叶前方那一片叫楔前叶。

   * **旁中央小叶**

       * > **定义**：位于胼胝体沟上方的后端，分为前、后两部。

## 皮质功能中枢

   * **躯体运动中枢与躯体感觉中枢**

       * 躯体运动中枢位于中央前回加旁中央小叶的前部。

       * 躯体感觉中枢位于中央后回加旁中央小叶的后部。

       * > **易错点**：⚠️ 旁中央小叶紧贴在胼胝体上方，前部管运动、后部管感觉，这两半千万别记反。

   * **视区**

       * > **定义**：视觉的最高级中枢，位于楔叶和舌回，下边是舌回，上边是楔叶。

   * **听区**

       * > **定义**：位于颞横回，在外侧裂的深面，即外侧沟里边。

   * **嗅区**

       * > **定义**：位于海马回钩。

   * **边缘叶**

       * > **定义**：内脏运动的最高级中枢，范围是绕着胼胝体转的一圈，由膈区、扣带回、扣带回峡、齿状回、海马、岛叶前部和颞极组成。

       * 边缘叶不是一个单独的回，而是一串结构围成的环。

---

## 语言中枢

   * 语言中枢不止一个，散布在额叶和颞叶的沟回上，共四处，各伤各的。

| 语言中枢 | 部位 | 损伤后的表现 |
| :--- | :--- | :--- |
| 书写中枢 | 额中回后部 | 长文未说明 |
| 运动性语言中枢（Broca 区） | 额下回后部 | 不能说话，但说话能被听懂 |
| 听感觉性语言中枢 | 缘上回 | 听不懂别人的话；写条子完全理解，还能回答，说话能力也在 |
| 视感觉性语言中枢 | 角回 | 写什么都看不明白，但问他什么都能对答如流 |

   * 三个中枢损伤后的表现互不相同：一个坏了是"不能说"，一个坏了是"听不懂"，一个坏了是"看不懂"，对外界刺激的反应能力各自保留着不同的部分。

## 基底神经核

   * **基底神经核（basal nuclei）**

       * > **定义**：位于脑基底部的核团总称，包括纹状体、屏状核和杏仁核三样。

   * **纹状体（corpus striatum）**

       * > **定义**：由尾状核和豆状核共同组成，单独说其中任何一个都不叫纹状体。

   * **尾状核（caudate nucleus）**

       * 位置特殊，核体弯曲着下降，前方大、后方小。

       * 水平切面上前后两个端都被切到，正好对应核头和核尾。

   * **豆状核（lentiform nucleus）**

       * 外侧那个像西瓜皮一样的结构。

       * 自己还能再分：外侧的部分叫壳，内侧的部分叫苍白球。

   * **新旧纹状体**

       * > **结论**：旧纹状体等于苍白球；新纹状体等于尾状核加壳；纹状体是锥体外系的重要组成部分。

   * **屏状核（claustrum）**

       * > **定义**：位于豆状核外侧的核团，把白质分成里、中、外三份。

       * 屏状核以内是内囊，屏状核外侧是外囊，再外侧是最外囊。

   * **杏仁核（amygdala）**

       * > **定义**：位于侧脑室下角的前上方，即海马旁回的深面，是一个圆形的核团。

## 侧脑室

   * **侧脑室（lateral ventricle）**

       * > **定义**：端脑内的腔隙，左右对称的柱形空腔，而且深入到各个脑叶里去。

       * 铅柱模型是把熔化的铅从打好的孔灌进脑内，铅很沉，瞬间充盈脑室内间隙后铸成的。

       * 名字里的"侧"，是因为左右两个没法排出一、二，先后次序说不清，干脆都叫侧脑室。

   * **脑室系统的四个脑室**

       * 端脑里的叫侧脑室，间脑里的叫第三脑室，第三脑室向后变细的一段叫中脑水管，最后方膨大的那部分叫第四脑室。

       * 第四脑室由脑桥、延髓和小脑围成。

   * **侧脑室的分部**

       * 从侧面看，侧脑室分成四部分，每一部分正好伸进一个脑叶。

| 部分 | 伸入的脑叶 |
| :--- | :--- |
| 前角 | 额叶 |
| 中央部 | 顶叶 |
| 后角 | 枕叶 |
| 下角 | 颞叶 |

   * **脑室的交通关系**

       ```text
       左 侧 脑 室  --室间孔-->  第 三 脑 室  --中脑水管-->  第 四 脑 室
       ```

       * 室间孔左右各有一个，两个孔离得很近，但确实是两个。

       * 侧脑室经室间孔通到第三脑室，第三脑室再经中脑水管通到第四脑室。

       * > **结论**：这一串交通里最需要记住的名字就是室间孔。

   * **脉络丛（choroid plexus）**

       * 侧脑室打开后里面有很多絮状结构，功能是产生脑脊髓液。

       * 侧脑室的中央部和下角，脉络丛最丰富。

## 内囊

   * **内囊（internal capsule）**

       * > **定义**：位于尾状核、背侧丘脑与豆状核之间的白质区。

       * 可以把尾状核和背侧丘脑看作马路的一侧，豆状核在另一侧，内囊就是夹在它们中间的那条白质马路。

   * **内囊的分部形态**

       * 内囊分成三部分，切面不同、样子也不同：冠状切面（额状切面）呈 Y 字形，水平切面呈 X 字形。

       ```text
       冠状切面（额状切面）—— 内囊呈 Y 字形

         尾状核头   丘脑     豆状核
             │        │         │
             │ 前肢   │   后肢  │
             │        │         │
             └───┬─────┘        │
                 └─────┬────────┘
                     膝部

       水平切面 —— 内囊呈 X 字形

       尾状核  \         /  豆状核
               \       /
                \     /
                 \   /
                  \ /
                   X          膝部
                  / \
                 /   \
                /     \
               /       \
       丘脑    /         \  壳
       ```

       * 三条分支的两端是它左右的核团，中间打弯的那一段就是膝部。

   * **内囊各部分及其传导束**

| 部分 | 别称 | 重要传导束 |
| :--- | :--- | :--- |
| 前肢 | 额部 | 长文未说明 |
| 膝部 | 长文未说明 | 皮质核束 |
| 后肢 | 枕部 | 皮质脊髓束；丘脑中央辐射、听辐射、视辐射 |

   * **皮质核束**

       * 从中央前回下行到脑干就截止了，只和脑干的运动核相联系，走在膝部。

   * **皮质脊髓束**

       * 从中央前回和旁中央小叶前部发出，经内囊后肢下行到延髓，在延髓锥体交叉，再与脊髓和前角细胞联系，最后到达骨骼肌。

   * **丘脑中央辐射**

       * > **定义**：丘脑是感觉传导的最后一站，在丘脑交换完神经元后，第三级神经元的轴突通过丘脑中央辐射投射到皮层去的那一束纤维。

       * 与之并列的还有听辐射与视辐射。

---

## 内囊损伤的三偏现象

   * **感觉：三条上行的路共用同一段**

       * 内囊后肢里的感觉传导来自三条不同的上行通路，它们的最后一段——从丘脑经丘脑中央辐射穿内囊后肢上到皮层——是共用的。

| 感觉 | 上行通路 | 交叉的位置 |
| :--- | :--- | :--- |
| 深感觉 | 后索的薄束、楔束 → 延髓薄束核、楔束核 → 内侧丘系 → 丘脑 | 延髓的薄束核、楔束核，交换神经元后交叉 |
| 浅感觉 | 一级神经元入脊髓，上升 1~2 个节段即交换神经元 → 脊髓丘系 → 丘脑 | 脊髓内，入脊髓后 1~2 个节段就交叉 |
| 三叉神经（头面部） | 三叉神经进入脑桥 → 三叉神经感觉核 → 三叉丘系 → 丘脑 | 脑桥的三叉神经感觉核，交换神经元后立即交叉 |

       * 三条路都已经交叉过，也都到过丘脑；内囊一损伤，这共用的一段断了，感觉就传不上去了。

       * > **结论**：第一偏是对侧偏身感觉障碍——已经交叉了，头面部是对侧的，躯干和四肢也是对侧的。

   * **运动：皮质脊髓束决定肢体一侧**

       * 皮质脊髓束在延髓交叉，因此内囊损伤表现为对侧偏身运动障碍。

       * > **结论**：第二偏是对侧偏身运动障碍。

   * **运动：皮质核束只管头面部下段**

       * 脑干的运动核里，有两个只接受对侧皮质核束支配：面神经核的下半、舌下神经核。

       * 面神经核的下半管的是头面部的下 1/4。

       * > **易错点**：⚠️ 这种面瘫的样子很特别——两侧抬头纹都有，两只眼睛都能闭，就是嘴歪、流口水，瘫痪的只有面部下 1/4；这叫中枢瘫，也叫核上瘫。

       * 因为只接受对侧支配，损伤时表现为面部下 1/4 对侧瘫痪、舌肌对侧瘫痪，合起来仍属第二偏。

   * **视觉：视辐射必过内囊**

       * 视网膜来的纤维经视神经、视束到外侧膝状体，再由外侧膝状体发出视辐射，经内囊后肢到枕叶的视区。

       * 外侧膝状体发出的纤维到视觉中枢叫视辐射；旁边还有一个内侧膝状体，它发出的纤维到听中枢，叫听辐射。

       * 视束里的纤维分配：管理眼球内侧的那一半交叉到对侧的外侧膝状体，管理眼球外侧的那一半不交叉、终止于同侧的外侧膝状体；到外侧膝状体交换神经元后，再统一经内囊上行到视中枢。

       * > **提示**：视野和它在视网膜上的位置是相反的——晶状体是凸透镜，视网膜上成的是倒像；视网膜上偏内侧（管眼球内侧视野）的那部分感知的其实是视野的外侧，反过来视网膜偏外侧的那部分管的是视野的内侧。

       * 视区在枕叶，收的是对侧的视野，内囊一旦损伤这条通路就断了。

       * > **结论**：第三偏是对侧视野偏盲；损伤在右侧，表现出来就是左侧同向偏盲。

   * 三条感觉通路和两条运动通路在到达内囊之前都已完成交叉，视辐射上行后接的又是枕叶的对侧视野，所以内囊损伤在同一侧，症状却出现在对侧，且三组一起出现：对侧偏身感觉障碍、对侧偏身运动障碍、对侧视野偏盲，这就是三偏现象。
