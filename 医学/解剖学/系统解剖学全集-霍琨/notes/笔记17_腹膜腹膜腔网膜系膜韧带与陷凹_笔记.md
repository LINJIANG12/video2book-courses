# 腹膜：腹膜腔、网膜、系膜韧带与陷凹

## 腹膜与腹膜腔

* **腹膜（peritoneum）**

    * > **定义**：覆盖在腹腔和盆腔脏器表面，以及腹腔与盆腔内面的一层浆膜。

    * 两端各贴一面：一端贴脏器表面（腹腔脏器表面、盆腔脏器表面），一端贴腔壁内面（腹壁内面、盆壁内面）。

    * 构成模式与胸膜几乎相同，可对照记忆。

    * 贴脏器表面的那层称脏层，贴腔壁内面的那层称壁层。

* **腹膜腔（peritoneal cavity）**

    * > **定义**：脏层、壁层两层腹膜所围成的、不规则的腔隙。

    * 它是两层膜之间夹出来的一道缝，形状不规则，不是独立器官。

    * 壁层衬在腹壁、盆壁内面，脏层覆盖脏器表面，两者之间留出的间隙即腹膜腔。

```text
   ┌─────────────────────────────────────┐
   │        腹  壁  /  盆  壁  肌  层    │
   ├─────────────────────────────────────┤
   │  壁层腹膜（parietal layer）         │  ← 衬在腹壁、盆壁的内面
   │                                     │
   │       ┌─────────────────────┐       │
   │       │                     │       │
   │       │     腹  膜  腔      │       │  ← 脏层与壁层之间的不规则腔隙
   │       │ (peritoneal cavity) │       │
   │       │                     │       │
   │       └─────────────────────┘       │
   │                                     │
   │  脏层腹膜（visceral layer）         │  ← 覆盖在脏器表面
   ├─────────────────────────────────────┤
   │        腹  腔 / 盆  腔  脏  器       │
   └─────────────────────────────────────┘
```

## 腹膜的功能

腹膜共有五项功能：吸收、分泌、支持和固定、防御、修复。

### 吸收

* **吸收功能**

    * 腹膜能吸收腹腔盆腔内的液体，也能吸收积液和积脓。

    * 不同部位差别极大：上腹部吸收能力特别强，下腹部很弱，盆部最弱。

    * 差别的原因：膈肌下方（被肝占据）和盆部是整个腹腔与盆腔中位置最低的两处，吸收能力弱的正是位置最低的那一端。

    * 临床后果：积液、积脓若积存在吸收能力强的部位，患者术后取平卧位便迅速被吸收入血，或在肝周围形成脓肿。

* > **结论**：腹部手术后的患者一定要取半卧位，使积液和积脓积存在吸收能力弱的盆腔，从而减少中毒。

* 三句连记：上腹部吸收能力强，盆部吸收能力弱，术后一定要用半卧位。

### 分泌

* **分泌功能**

    * 腹膜能分泌少量的浆液。

    * 分泌物是浆液，不是水，也不是黏液。

    * 作用是润滑，减少腹腔内各脏器相互运动时产生的摩擦。

### 支持和固定

* **支持和固定功能**

    * 腹膜形成大量系膜。

    * 腹膜同时形成大量韧带。

    * 这些由腹膜形成的结构对脏器起支持和固定作用。

### 防御

* **防御功能**

    * 防御功能由大网膜承担。

    * 大网膜内含大量吞噬细胞，能够吞噬细菌，因此对机体有防御能力。

    * 大网膜同时是腹膜囊的邻居，也是外科常用的填塞止血材料。

### 修复

* **修复功能**

    * 腹膜一旦被破坏，创面能渗出一种纤维素。

    * 纤维素有很强的粘连能力，腹膜创面会很快粘连到一起。

    * 有利的一面：肠断端吻合时各层缝好之后，最后还要把肠壁表面的这层浆膜缝好，浆膜粘连可封住断端，防止肠内容外漏。

    * 不利的一面：缝合不细、漏掉两针，该处浆膜未缝合好，断端释放的纤维素会使邻近健康肠管粘连，容易形成肠梗阻。

## 网膜

* 网膜分为两部分：大网膜和小网膜。

* **大网膜**：胃大弯向下垂落、呈围裙状的那个结构。

* **小网膜**：肝脏下面和胆囊与胃之间绷紧的那片膜，即肝脏与十二指肠、与胃小弯之间的膜。

### 小网膜

* **小网膜**

    * > **定义**：肝与胃小弯、以及十二指肠上部之间的双层腹膜皱襞，由肝胃韧带和肝十二指肠韧带构成。

    * 从肝到胃小弯这一段是双层腹膜皱襞，命名为肝胃韧带。

    * 从肝到十二指肠上部这一段是另一部分，命名为肝十二指肠韧带；两个韧带加在一起才是小网膜。

    * 两部分厚度完全不一样：肝胃韧带很薄，两层薄而呈半透明状；肝十二指肠韧带很厚。

    * 厚薄差异的原因是肝十二指肠韧带内包裹着肝门三件。

* > **提示**：摸标本时，薄的那一片一定是肝胃韧带，厚的那一片一定是肝十二指肠韧带；厚薄不是韧带自己长出来的，而是里面有没有东西。

### 大网膜

* **大网膜**

    * > **定义**：胃大弯与横结肠之间的多层腹膜皱襞。

    * 自胃大弯向下悬吊，形态像围裙，因此又称胃大垂下的围裙。

* **大网膜表面的腹膜覆盖次序**

    * 膈肌下方的腹膜形成冠状韧带，包绕肝脏。

    * 腹膜再往下到胃，包绕胃；从胃大弯向下悬吊的多层腹膜皱襞即大网膜。

    * 腹膜继续包绕横结肠，向腹后壁延伸形成横结肠系膜。

    * 腹膜绕到腹后壁与膈肌之间所围成的区域是肝脏的裸区，该处没有腹膜覆盖。

* **胃结肠韧带（胃横结肠韧带）**

    * > **定义**：胃大弯和横结肠上缘之间的那部分腹膜皱襞，即大网膜顶端的两层。

    * 大网膜的层次并不处处相同：胃大弯与横结肠上缘之间为两层，其下方部位为四层。

    * 这两层另有专名，叫胃结肠韧带，也叫胃横结肠韧带。

* 一张腹膜上共出两个韧带名：肝胃韧带、肝十二指肠韧带归小网膜；胃结肠韧带是大网膜顶上的那两层。

## 网膜囊与网膜孔

### 网膜囊

* **网膜囊**

    * > **定义**：位于小网膜和胃的后方、胰的前方的潜在腹膜间隙。

    * 它是腹膜在小网膜和胃与胰之间兜出的一个潜在间隙，位置上在腹后壁一侧。

    * 囊腔较大，而开口朝上。

    * 囊的上方有一个孔，借这个孔与腹膜腔主体（大腹膜腔）相通。

* > **注意**：网膜囊口在上，胃后壁穿孔手术后必须认真清洗；囊内如有积液和积脓，因位置深、不容易出来，极易在囊内陷聚，形成局限性的积液、积脓。

### 网膜孔

* **网膜孔**

    * > **定义**：位于肝十二指肠韧带右侧游离缘的后方。

    * 孔依附于肝十二指肠韧带，而该韧带内包裹着肝门三件。

    * 它是网膜囊与大腹膜腔之间的通道，构成网膜囊朝上的那个开口。

* > **结论**：网膜孔是腹部手术的应急止血入口——肝脏破裂大出血、开腹后，先把食指伸入网膜孔，用拇指压迫肝十二指肠韧带内的肝固有动脉，可达暂时止血的目的。

```text
          肝（下缘）
          │
   ═══════╪═════════════════════════════════   ← 网膜孔（肝十二指肠韧带右侧游离缘的后方）
          ║                                ║
          ║        网  膜  囊               ║   ← 潜在腹膜间隙
          ║（小网膜与胃的后方，胰的前方）  ║
          ║                                ║
   ───────╨════════════════════════════════╨
          胃                               胰
          │                                │
          └──────────── 大 腹 膜 腔 ────┘  ← 经网膜孔与大腹膜腔相通
```

## 系膜与韧带

### 系膜

* **系膜**

    * 系膜是腹膜形成的结构，对脏器起支持和固定作用。

    * 包括小肠系膜、阑尾系膜、横结肠系膜、乙状结肠系膜。

    * 横结肠系膜由包绕横结肠的腹膜向腹后壁延伸形成。

### 韧带

* **韧带**

    * 韧带同样是腹膜形成的结构，对脏器起支持和固定作用。

    * 肝的韧带有冠状韧带、镰状韧带、肝圆韧带；冠状韧带在膈肌下包绕肝脏，肝圆韧带由肝走到脐。

    * 网膜部分的韧带有肝胃韧带、肝十二指肠韧带、胃结肠韧带。

    * 脾周围的韧带有脾胃韧带、膈脾韧带、脾结肠韧带、脾肾韧带；脾肾韧带连脾与肾，脾胃韧带连胃与脾。

    * 还有膈结肠韧带，位于横结肠与膈肌之间。

* > **提示**：韧带的命名基本是「两个附着点 + 韧带」；看不懂时把名字拆开念一遍，位置立刻清楚，例如脾和肾之间是脾肾韧带，胃和脾之间是脾胃韧带。

## 陷凹

* **陷凹**

    * > **定义**：腹膜由一个脏器移行到另一个脏器所形成的凹陷。

    * 它不是长出来的一个囊，而是腹膜在换宿主时折一下留下的窝。

    * 腹膜反折的折数越多，窝越深，陷凹的数目也越多。

* **男性盆腔的陷凹**

    * 男性盆腔器官由前向后为膀胱、前列腺、尿道、直肠和肛管。

    * 腹前壁的腹膜覆盖膀胱表面，然后反折到直肠。

    * 这一折形成的凹陷称膀胱直肠陷凹，男性只有这一个陷凹。

* **女性盆腔的陷凹**

    * 女性盆腔器官由前向后为膀胱、短而直的尿道、阴道、子宫、直肠和肛管，比男性多一个子宫。

    * 腹膜从膀胱的一部分反折到子宫前壁，再从子宫后壁反折到直肠。

    * 这一折形成两个陷凹：膀胱子宫陷凹与子宫直肠陷凹。

* **位置最低的陷凹**

    * 子宫直肠陷凹位置最低，与阴道的后穹窿仅隔一个阴道壁和腹膜。

    * > **结论**：临床所说的 Douglas 腔，指的就是子宫直肠陷凹。

    * 盆腔内聚集的积液和积脓可在此抽出：先用阴道扩张器扩开阴道暴露后方，再以穿刺方法把积液、积脓抽出。

* **男女陷凹对比**

    | 对比项 | 男性 | 女性 |
    | :--- | :--- | :--- |
    | 腹膜反折路线 | 膀胱 → 直肠 | 膀胱 → 子宫前壁 → 子宫后壁 → 直肠 |
    | 反折次数 | 一次 | 两次 |
    | 陷凹数目 | 一个 | 两个 |
    | 陷凹名称 | 膀胱直肠陷凹 | 膀胱子宫陷凹、子宫直肠陷凹 |
    | 位置最低的陷凹 | 长文未说明 | 子宫直肠陷凹 |
    | 临床名称 | 长文未说明 | 子宫直肠陷凹即 Douglas 腔 |

```text
   男 性                             女 性
  ┌──────────────┐                   ┌────────────────────┐
  │              │                   │                    │
  │      膀胱    │                   │       膀胱         │
  │       ↓      │                   │        ↓           │
  │  膀胱直肠陷凹│                   │   膀胱子宫陷凹     │
  │       ↓      │                   │        ↓           │
  │    直肠肛管  │                   │       子宫         │
  │       ↓      │                   │        ↓           │
  │              │                   │                    │
  └──────────────┘                   │   子宫直肠陷凹     │
                                     │   = Douglas 腔     │
                                     │        ↓           │
                                     │     直肠肛管       │
                                     └────────────────────┘
```

## 腹膜腔的分区

* **腹膜腔的分区**

    * > **结论**：腹膜腔只分两区，分界线是横结肠。

    * 横结肠以上称结肠上区。

    * 横结肠以下称结肠下区。

* **左右分界**

    * 肝圆韧带由肝走到脐，以这条到脐的斜线作为左右两侧的分区线。

## 腹膜腔的间隙与窦

### 肝上间隙

* 肝脏与膈肌之间的间隙习惯上称肝上间隙。

* 肝上间隙以镰状韧带为界分为左右两部：右侧为右肝上间隙，左侧为左肝上间隙。

* 右肝上间隙以冠状韧带为界再分出前、后两部。

### 肝下间隙

* 肝脏与腹腔之间的间隙称肝下间隙，同样分为左右两部，右侧称右肝下间隙。

* 左侧因有小网膜的分隔，分为前、后两个：左肝下前间隙与左肝下后间隙。

* > **易错点**：以冠状韧带为界分出前、后两部的是右肝上间隙；以小网膜为界分出前、后两部的是左肝下间隙；右肝下间隙与左肝上间隙都是单腔，不再分前后，不要以为四个都分。

* **四个肝周围间隙的分腔对照**

    | 间隙 | 是否再分前、后 | 分界依据 |
    | :--- | :--- | :--- |
    | 右肝上间隙 | 分 | 冠状韧带 |
    | 左肝上间隙 | 不分，单腔 | — |
    | 右肝下间隙 | 不分，单腔 | — |
    | 左肝下间隙 | 分 | 小网膜 |

### 结肠旁沟

* 结肠旁沟有两条：右结肠旁沟与左结肠旁沟，左右各一条。

* 结肠旁沟是结肠下区的结构。

* 结肠旁沟的归属直接决定腹盆腔积液的引流方向。

### 肠系膜窦

* 肠系膜窦共两个。

* 右肠系膜窦是小肠围成的一个三角形腔隙。

* 左肠系膜窦直接与盆腔相通。

* > **结论**：右肠系膜窦是死腔，左肠系膜窦是通腔。

### 积液的引流方向

* 右肝上间隙的前部与后部，通过结肠旁沟可以直接流到盆腔。

* 右肝下间隙同样可以经结肠旁沟直接到盆腔，因此这个部位手术后积液、积脓最容易流到盆腔里。

* 左侧由于有系膜和韧带的分隔，左侧各间隙与左结肠旁沟并不相通，所以这一部分手术一定要彻底清洗。

* 右肠系膜窦表面全是回肠的肠管，是个死腔，术中要重点冲洗。

* 左肠系膜窦直接与盆腔相通，这部分不必担心积液滞留。

* 左结肠旁沟从膈结肠韧带以下的部分，也会顺利到达盆腔。
