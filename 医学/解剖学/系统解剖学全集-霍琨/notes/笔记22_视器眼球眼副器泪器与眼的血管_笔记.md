# 视器：眼球、眼副器、泪器与眼的血管

## 眼球组成

* **视器**

    * > **定义**：包括眼球和眼副器两大部分。
    * 眼球本身再分为球壁与内容物两部分。

* **球壁**

    * > **定义**：眼球的骨架，从外向内分三层，构成清晰可辨。
    * 外膜：又称纤维膜，由致密结缔组织构成，起支持和保护作用。
    * 中膜：又称血管膜，前面薄薄、后面有增厚、下面较薄。
    * 内膜：又称视网膜，是最里边的、很薄很薄的一层。

* **内容物**

    * > **定义**：填在球壁之内眼腔里的三样东西。
    * 三样是房水、晶状体、玻璃体。

---

## 外膜与角膜

* **角膜**

    * > **定义**：外膜前方约占 $1/6$ 的部分，微向外凸、有一定弯曲度。
    * 第二个特点：无血管、无色透明。
    * 第三个特点：神经末梢丰富，感觉敏锐。
    * 无血管的代价是营养靠间接来源，一旦发病病程长且容易复发。
    * 损伤后结瘢形成角膜白斑，白斑正好落在瞳孔前方时表现为只有光感没有视力。

| 特点 | 由此推出的后果 |
| :--- | :--- |
| 微向外凸，有一定弯曲度 | 暴露在外容易受外伤；受伤后光滑弯曲面被破坏、形成不了原有曲度，导致外伤性散光 |
| 无血管、无色透明 | 营养靠间接来源，病程长且易复发；损伤后结瘢形成角膜白斑，落在瞳孔前方时只有光感没有视力 |
| 神经末梢丰富、感觉敏锐 | 角膜的疾病表现为剧痛 |

### 砂粒迷眼的落点判断

* 砂粒落在白眼球上：敢眨眼，只有异物感而不疼。
* 砂粒落在角膜上：连眨眼都不敢眨，疼痛特别剧烈，因为眼睑一眨等于在搓角膜。
* > **易错点**：砂粒迷眼不能揉，一揉就损伤角膜。
* 正确做法：把上睑提起来、让眼球向内转，靠泪液把沙粒冲下来。
* 需要拨出时，借上睑轻轻往下拨、眼球往上翻，把它轻轻拨下来。

### 角膜白斑与晶状体浑浊的共同表现

* 二者临床上都可以表现为"只有光感没有视力"。
* 区别在位置：角膜白斑看它落在不在瞳孔前方，晶状体浑浊则是光根本过不去。

## 巩膜与巩膜静脉窦

* **巩膜**

    * > **定义**：外膜后方的白色不透明部分，约占后 $5/6$。
    * 特点一：白而不透明，即俗称的"白眼球"。
    * 特点二：非常坚硬，由纤维组织构成，对眼球起保护作用。

* **巩膜静脉窦（许氏管）**

    * > **定义**：位于角膜、巩膜交界处内面的环形小管，断面切开即可看到。
    * 该部位有眼球的眼外肌附着，眼外肌内有一条睫前静脉与它相通。
    * 它又与眼内腔相通，所以眼内的房水能经此窦回收、再通过静脉回流出去。
    * 房水是不断分泌又不断回收的，靠的就是许氏管来回收。
    * 整条回流链路的终点一直通到颈内静脉。

---

## 中膜与虹膜

* **中膜（血管膜、脉络膜）**

    * > **定义**：球壁中层，特点是丰富的血管加上很多很多的黑色素。
    * 丰富的血管负责营养眼内组织。
    * 黑色素负责遮光。
    * 由前向后分成三部分：最前方薄薄的虹膜、向后增厚的睫状体、再往后的脉络膜，对应图上"前薄、中厚、后薄"的形态。

* **虹膜**

    * > **定义**：位于角膜与晶状体之间、角膜后方的棕黑色圆盘状薄膜，很薄。
    * 从前方看，中央有一个孔叫瞳孔，光线由瞳孔进入眼内腔。
    * 表面可见很多放射状纹理，即血管纹，说明虹膜表面的血管很多。
    * 虹膜内含两种平滑肌：围绕瞳孔呈环状排列的瞳孔括约肌，位于其外侧呈放射状排列的瞳孔开大肌。
    * > **易错点**：不要把虹膜表面的放射状结构当成平滑肌，平滑肌长在虹膜里面、前面根本看不到；表面看到的放射状纹理是血管纹。

| | 瞳孔括约肌 | 瞳孔开大肌 |
| :--- | :--- |
| 排列 | 围绕瞳孔，环状 | 虹膜外侧，放射状 |
| 神经支配 | 副交感神经 | 交感神经 |
| 作用 | 缩小瞳孔（缩瞳） | 扩大瞳孔（散瞳） |

---

## 睫状体与调节

* **睫状体**

    * > **定义**：中膜中间环形增厚的部分，位置与巩膜静脉窦一样在角巩膜交界处的内面。
    * 做眼球冠状切面从后向前观察：最中心凸透镜状的是晶状体，晶状体外周有向腔内凸起的皱襞，皱襞与晶状体之间有纤细的睫状小带相连。
    * 睫状突：睫状体最肥厚部位向腔内呈放射状排列的突起，即那圈向腔内凸起的皱襞，功能是产生房水。
    * 睫状环：睫状体外周那个平坦部位，其边缘呈锯齿状。

* **睫状肌的调节机制**

    * > **定义**：睫状体内的平滑肌有两种，靠外呈扇形、靠内呈环形。
    * 力学模型：把睫状体上方看作定点，从上方长出的两种肌肉看作动点。
    * 睫状肌收缩时，扇形肌变短向上提，环形肌收缩向内移，整个凸起向内移。
    * 凸起内移使睫状小带变松，晶状体靠自身极高的弹性变厚，此时看近处。
    * 睫状肌舒张时，肌肉变长、凸起外移，小带变紧，晶状体被周围拉薄，此时往远看。
    * 长时间看书眼睛累主要是睫状肌疲劳，那时要主动往远看，睫状肌才能得到休息。

| | 睫状肌收缩 | 睫状肌舒张 |
| :--- | :--- |
| 扇形肌（靠外） | 变短，向上提 | 变长，外移 |
| 环形肌（靠内） | 收缩，向内移 | 舒张 |
| 睫状小带 | 变松 | 变紧 |
| 晶状体 | 靠自身弹性变厚变凸 | 被拉薄 |
| 视觉 | 视近，焦点变小 | 视远 |

> **结论**：睫状肌收缩 → 睫状小带变松 → 晶状体变厚 → 视近；睫状肌舒张 → 睫状小带变紧 → 晶状体变薄 → 视远。

## 脉络膜

* **脉络膜**

    * > **定义**：中膜最后面的一段，是整层膜最厚处，富含黑色素。
    * 遮光：外边的光线不能进到眼腔，射入后若出现杂色也会被它吸收，成像才干净。
    * 与巩膜结合较疏松，容易分离。
    * 与内膜的外层（视网膜）结合紧密、不易分离。

---

## 视网膜的分层与脱离

* **视网膜（内膜）**

    * > **定义**：球壁最里层，从虹膜的后方开始出现，薄薄一层，附着在睫状体表面和脉络膜表面，向后环绕一大圈。
    * 虽薄，实际分两层：外层是色素上皮层，内层是神经细胞层。
    * 色素上皮层同样含有丰富的黑色素。

* **两层之间的潜在间隙**

    * 色素上皮层与脉络膜紧密相贴、不易分离，这也就是脉络膜的第二个结合特点。
    * 神经细胞层与色素上皮层之间存在潜在的间隙。
    * 这层潜在间隙对应的临床疾病是视网膜脱离，也叫网脱。

```text
    脉络膜
       │
       │  紧密相贴，不易分离
       ▼
   色素上皮层 ─────────────┐
                            │  ← 潜在间隙
                            │     （视网膜脱离就发生在这里）
   神经细胞层 ─────────────┘
```

* **视网膜脱离的发生过程**

    * 初始阶段眼底检查只发现一条线性的裂隙。
    * 裂隙出现后，玻璃体的液体很容易进入裂隙并跑到潜在间隙里，两层膜就分开。
    * 一周后复查可见裂隙增大、变薄，有半透明的膜卷下来，这就是视网膜。
    * 结局是失明，因为脱下来的膜所在之处正是感光细胞所在的地方，膜脱下来露黑了就不能感光。
    * > **易错点**：易患此病的情况主要是高度近视、视网膜变性和外伤，这都和视网膜"层间有潜在间隙"这个解剖特点分不开。

### 眼底检查的所见

* 查视野时先看鼻侧，视神经乳头就在那里，视神经从这里穿出来，伴行的动脉也从这里出来，共两支。
* 以视神经乳头为中心，上方是鼻侧上、颞侧上两条动脉，下方是鼻侧下、颞侧下两条动脉。
* 再往旁边能看到一个最亮的反光点，叫中心凹；它周围有色素沉着区，这一整块就是黄斑。

## 神经细胞层与感光细胞

* **神经细胞层的三种细胞**

    * > **定义**：视网膜神经细胞层含有三种神经细胞，从视网膜最外侧往里数正好是它们，依次把光线信号往内传，最后汇成视神经。
    * 视锥细胞与视杆细胞在最外侧、靠脉络膜，负责感受光刺激、产生兴奋。
    * 双极细胞在中间，有两个极，负责把视锥、视杆细胞的兴奋向内层传递。
    * 节细胞在最内侧，接受双极细胞的冲动，每个细胞发出长长的轴突。
    * 这些轴突在眼球后极逐渐汇聚，越汇聚越多，最后构成一条神经，即视神经。
    * 方向要记准：光线从瞳孔进来后先照到最外侧的细胞，传给中间细胞，再传给最内的节细胞，才产生视觉。

```text
            光线（由瞳孔进入）
                    ↓
   ┌────────────────────────────────┐
   │ ①  视锥细胞 / 视杆细胞         │ ← 最外侧
   │       感受光刺激，产生兴奋     │    靠脉络膜
   │              ↓                 │
   │ ②  双极细胞                    │ ← 中间
   │       把兴奋向内层传递         │    有两个极
   │              ↓                 │
   │ ③  节细胞                      │ ← 最内侧
   │       接受双极细胞的冲动       │
   │       每个细胞发出长长的轴突   │
   └────────────────────────────────┘
                    ↓ 轴突越汇越多
                    ↓
                 视神经（眼球后极汇聚而成）
```

* **两种感光细胞的功能分工**

    * 视锥细胞感受强光觉，并且有辨色能力。
    * 视杆细胞感受暗光觉，没有辨色能力。

| | 视锥细胞 | 视杆细胞 |
| :--- | :--- | :--- |
| 感光 | 感受强光觉 | 感受暗光觉 |
| 辨色能力 | 有 | 没有 |

## 眼房与房水

* **眼房**

    * > **定义**：角膜与晶状体之间的眼内腔，分为前、后两部分。
    * 虹膜后面那个较小的叫后房，前方那个较大的叫前房。
    * 前房和后房借瞳孔相通，因为虹膜在中间、瞳孔是一孔，两房就通了。

* **房水**

    * > **定义**：充填在眼房内的无色透明液体，由睫状突产生。
    * 作用一是营养角膜和晶状体，二者都没有血管，靠房水供给。
    * 作用二是维持眼内压和眼球外形：产生与回收保持动态平衡时眼压平衡，产生多回收少则眼压逐渐增高；眼球受外伤房水流出，眼球就塌陷。
    * 作用三是它的循环路线，需完整背下来。

```text
   睫状突           后房          瞳孔          前房
   （产生）                                          │
     │                                             │
     └────────→ ──── ──── → ──── ──── → ──── ──── ──┘
                                    │
                              前房角（又称虹膜角膜角）
                                    │
                                    ↓
                            巩膜静脉窦（许氏管，回收）
                                    │
                                    ↓
                              睫前静脉 → 眼静脉
                                    │
                                    ↓
                              颈内静脉 → 心脏
```

* **房水循环一句话串讲**

    * 产生于睫状突，进入后房，经瞳孔到前房，移动到前房角，进入巩膜静脉窦，再经眼静脉、颈内静脉回收，由颈内静脉带到心脏去。
    * 循环走向与性质都和身体里淋巴液的回流通路很像，同样是无色透明。

## 晶状体与白内障

* **晶状体**

    * > **定义**：位于虹膜与玻璃体之间、虹膜后方的双凸透镜状结构，富有弹性。
    * 特点是无色透明，外面包着一层高弹力的被膜，叫晶状体囊。
    * 功能是薄厚可调，由睫状肌的收缩和舒张控制。
    * 角膜、巩膜、虹膜、睫状体、睫状小带、晶状体连成一条路，是同一条解剖通路上的结构。

* **白内障**

    * > **定义**：晶状体核逐渐浑浊即白内障，虹膜炎、外伤、老年性自然老化都可引起。
    * 晶状体一浑浊，光线不能透过它到达视网膜，表现为只有光感、没有视力。
    * 记住一句话：晶状体浑浊，就是白内障。

* **人工晶体植入术的环节**

    * 第一步先把外面的高弹性晶状体囊前膜切掉。
    * 然后把里边浑浊的晶状体核完全吸出去。
    * 再放入人工晶体，它形似一个凸透镜，两边有 2 个弹力金属丝。
    * 手术前必须先测度数，比如对方是 300 度就用 300 度的人工晶体。
    * 植入时把两个金属丝压拢放进晶状体囊内，金属丝再一崩开就抵住囊壁，固定在囊里。

---

## 玻璃体

* **玻璃体**

    * > **定义**：充填在晶状体后方很大一片范围里的胶冻状物质。
    * 性状很像放了很久的那种胶水：看着没形，却很粘稠并有一定形状，但眼球有外伤时会流出来。
    * 眼底有炎症会引起玻璃体混浊。
    * 眼底出血时血液可渗入玻璃体内，出现红视现象，患者会觉得看什么都偏红，检查眼底可见出血。

## 眼睑的外部术语

* **上睑与下睑**

    * > **定义**：眼睑即俗称的眼皮，位于眼球前方；上方的称上睑，下方的称下睑。

* **内眦与外眦**

    * > **定义**：眼睑靠鼻梁那一侧（内侧）相汇的角为内眦，靠颞部那一侧（外侧）相汇的角为外眦。

* **睑缘**

    * > **定义**：上睑最下缘与下睑最上缘这两条游离的边都叫睑缘。

    * 睑板腺的排泄管分泌物最终排到睑缘。

* **睑裂**

    * > **定义**：上下睑缘之间裂开的那道缝叫睑裂。

    * 睑裂是变大还是变小，需与睑的异常一同记录。

* 病历用词

    * > **提示**：这六个词是病历的强制用词。主诉「眼皮垂下来了」要写成「上睑下垂」，并跟写一句「睑裂变大」或「睑裂变小」；用词不规范，临床信息就丢了。

## 提上睑肌与睑板

* **眼轮匝肌（orbicularis oculi）**

    * 环绕眼裂周围的肌肉，运动系统部分已学。

* **提上睑肌（levator palpebrae superioris）**

    * > **定义**：位于上睑内的肌肉，作用是使上睑上提。

    * 它到眼睑去而不到眼球；讲眼外肌时仍要回提这块肌肉。

* **睑板（tarsal plate）**

    * > **定义**：位于眼睑内侧、贴睑结膜那一面的圆骨板状结构。

    * > **易错点**：睑板在眼睑的内侧，不在外侧。定位记反了，后面的手术刀就下错地方。

* **睑板腺（meibomian gland）**

    * 位于睑板内的腺体，其下为排泄管，分泌物最终排到睑缘。

## 睑板腺堵塞与睑腺炎

* **霰粒肿（chalazion）**

    * > **定义**：睑板腺排泄管堵塞、分泌物淤积后，在眼睑外表鼓出的包。

    * 诱因：眼部卫生不注意，排泄管堵塞，睑板腺分泌物出不来，越堆越多。

    * 手术处理：睑板在眼睑内侧，不能在外边直接下切口；先把眼睑翻开显露肿物，再做放射状切口排出分泌物，不用缝合。

* **睑腺炎（hordeolum）**

    * > **定义**：单个毛囊感染形成的炎症。

    * 与霰粒肿的区分：睑腺炎是毛囊感染，霰粒肿是睑板腺排泄管堵塞、分泌物淤积。

* 二者的临床地位

    * 这两个病是眼睑最常见的一批疾病。

## 结膜的三部分与结膜囊

* **结膜（conjunctiva）**

    * > **定义**：一层富有血管的薄膜。盖在眼睑内面的叫睑结膜，盖在白眼球表面的叫球结膜，两者相移行的那一段叫穹窿结膜。

* **睑结膜（palpebral conjunctiva）**

    * 睑板内侧薄薄的一层膜。

* **球结膜（bulbar conjunctiva）**

    * 白眼球表面薄薄的一层膜，富有血管。

* **穹窿结膜（fornix）**

    * 睑结膜与球结膜相移行的那一段。

* **结膜囊（conjunctival sac）**

    * > **定义**：三层结膜共同围成的一个腔。

    * 开口与睑裂相通；泪腺分泌的泪液进入此囊湿润角膜。

## 滴眼药水的正确操作

* 操作步骤

    * 把下睑向下牵拉，让下睑形成一个兜状。

    * 眼药滴进去以后轻轻合上眼睑，不要挤。

    * 用手压住内眦，阻止眼药经鼻泪管流入鼻腔，使药效白白漏掉。

* > **易错点**：仰头滴一滴、使劲一挤眼就走，药液已经被挤出，等于没点；需按医嘱频次滴用（如最好每 10 分钟点一次）才能起效。

## 泪器与泪腺

* **泪器（lacrimal apparatus）**

    * > **定义**：由泪腺和泪道两部分组成。

* **泪腺（lacrimal gland）**

    * 位置：眶上壁的前外侧的泪腺窝内。

    * 产物：泪液。

* **眶腔（orbit）**

    * > **定义**：容纳眼球的四棱锥体形腔。

    * 眶腔内侧壁上有泪囊窝；眶尖朝向后内，眶底朝向前外。

## 泪道

* **泪道**

    * > **定义**：泪器的管道部分，包括泪点、泪小管、泪囊和鼻泪管四部分。

* **泪点（lacrimal punctum）**

    * > **定义**：泪乳头顶端的小孔，分上泪点与下泪点。

    * 内眦部形成两个乳头状的隆起，称泪乳头；两个泪乳头的上边各有一个小孔。

* **泪小管（泪管，lacrimal canaliculus）**

    * > **定义**：泪点与泪囊之间的管道，分上泪小管与下泪小管。

    * 由各该侧泪点向下相连，上、下泪小管往下走，最后汇入一个囊腔（泪囊）。

* **泪囊（lacrimal sac）**

    * > **定义**：位于眶内侧壁前部骨性泪囊窝内的膜性盲囊。

    * 盲囊的含义：上壁是盲端，下端与鼻泪管相通，一头堵死、一头通下去。

* **鼻泪管（nasolacrimal duct）**

    * > **定义**：套行于骨性鼻泪管管腔之内的膜性管。

    * 开口于鼻腔。

## 泪液的通路与泪溢

* **泪液的正常流向**

    * 泪腺分泌的泪液进入结膜囊，湿润角膜并流到眼球表面，再通过上、下泪点和上、下泪小管到泪囊，最后由鼻泪管下来开口于鼻腔，湿润鼻黏膜。

* 泪液通路示意

    ```text
        泪腺（眶上壁前外侧的泪腺窝内）
             │  分泌泪液
             ▼
        结膜囊 ──── 湿润角膜 ────► 眼球表面
             │
             ▼
        上泪点 / 下泪点（内眦部泪乳头顶端的小孔）
             │  经上泪小管、下泪小管（泪管）
             ▼
        泪囊（泪囊窝内的膜性盲囊，上壁为盲端）
             │
             ▼
        鼻泪管（套在骨性鼻泪管内的膜性管）
             │
             ▼
        鼻腔 ──► 湿润鼻黏膜
    ```

* **泪溢**

    * 情绪激动时泪腺分泌量增多，泪液往外流，故称「痛哭流涕」。

    * 鼻涕从鼻孔出来，眼泪从睑裂出来；二者虽一块儿下来，走的却是两套道。

## 眼外肌的数目与总腱环

* **眼外肌**

    * > **定义**：共 7 块，即上直肌、下直肌、内直肌、外直肌、上斜肌、下斜肌，加上提上睑肌。

    * 辨认方位：眼球前方向上、向下、向内、向外去的是上直肌、下直肌、内直肌、外直肌，另两块为上斜肌和下斜肌。

    * 第 7 块是提上睑肌——它到眼睑去了，不到眼球。

* **总腱环（common tendinous ring）**

    * 位置：眶尖处，环的内侧相当于视神经孔，视神经从总腱环的内侧穿过。

    * 抵止于总腱环的肌肉：上直肌、下直肌、外直肌、内直肌、上斜肌，均向后走抵止于总腱环。

    * 例外：下斜肌不抵止总腱环，直接到眶的内壁。

    * 提上睑肌从总腱环上方发出，往上出眶止于上睑。

* 眼外肌的附着示意

    ```text
        总腱环（眶尖处，环的内侧 = 视神经孔，视神经由此穿过）
            │
            ├── 上直肌 ────┐
            ├── 下直肌 ────┤  4 个直肌：由总腱环发出
            ├── 内直肌 ────┤  绕眼球止于眼球前面
            ├── 外直肌 ────┘
            │
            ├── 上斜肌 ──────  同样抵止于总腱环
            │
            ├── 下斜肌 ──────  唯一的例外：直接到眶的内壁
            │
            └── 提上睑肌 ────  往上出眶，到上睑去，止于上睑，不上眼球
    ```

* 眶内的毗邻结构

    * 眶腔里有眶上裂，内侧有泪囊窝。

    * > **提示**：挂图上的眼外肌是被人为地向外牵拉过的，不是完全的解剖位置，不要据图判断走行。

## 六条眼肌运动轴线

* **眼肌运动方向**

    * 从前方看眼球，眼外肌的作用可归纳为 6 条轴线。

| 眼肌 | 收缩时黑眼球的运动方向 |
| :--- | :--- |
| 内直肌 | 向内 |
| 外直肌 | 向外 |
| 上直肌 | 向上内 |
| 下直肌 | 向下内 |
| 上斜肌 | 向下外 |
| 下斜肌 | 向上外 |

* **上下直肌方向偏移的原因**

    * 眶腔的眶尖朝向后内、眶底朝向前外，肌肉从后内往前外绕过来。

    * 上直肌收缩方向因此不是正上，下直肌同理，方向是向下内。

* **直肌与斜肌的运动方向**

    * > **易错点**：斜肌的方向和直肌是反着来的。名字里的「上」「下」说的是这块肌肉所在的位置，不是它把眼球带去的方向——往下转的是上斜肌，往上转的是下斜肌。

## 眼肌瘫痪与斜视的检查

* **眼肌瘫痪的判定**

    * 让患者顺着手指按 6 个轴线走；六个方向都能走，眼肌就是正常的。

* **成人斜视的判断**

    * 站在患者前边伸出一根手指说「看我的手指」，让他往各个方向看，即可看出是哪一眼、往哪个方向斜。

* **小儿假性斜视的成因**

    * 小孩比较胖，皮下组织丰富，眼裂之间距离显得很宽。

    * 内眦还没有完全发育，两个眼角内侧的距离显得特别宽。

    * 等孩子长大、皮下组织变薄、眼裂展开，他其实就不斜了——属假斜视。

* **角膜反光点检查法**

    * 用一个小的手电筒，在患者前边 1 米多的地方打亮光，让其注视该亮光。

    * 观察两个瞳孔内的角膜反光点位置：光点在这一侧瞳孔正中，说明该眼正好瞅着光线，不斜；光点在瞳孔外侧，说明这只眼往内斜；光点在瞳孔内侧，说明这只眼往外斜。

* **泪道通畅的临床联用**

    * 滴眼药水时用手压住内眦，目的就是防止药液顺着鼻泪管跑到鼻腔里去。

## 眼底：视神经盘、中心凹与黄斑

* **视神经盘（视神经乳头，optic disc）**

    * > **定义**：位于鼻侧的圆盘状结构。

    * 特点：没有感光细胞，因此不能感光，称生理盲点；这是正常的，正常人到那儿看不到东西。

    * 该处能看到血管：视网膜中央动脉在此穿过并形成四个分支——鼻侧上、鼻侧下、颞侧上、颞侧下动脉。

* **中心凹（fovea）**

    * 位置：在视神经盘颞侧大约 3~4 毫米处。

    * > **定义**：该处可见一个最亮的光点。

* **黄斑（macula）**

    * > **定义**：以中心凹的色素沉着区在内的整块区域。

    * 特点：视觉细胞分布最密集，故感光最敏锐。

    * 临床价值：患者自述「过去视力 1.5，现在突然变成 0.3」时，首先应想到眼底黄斑区有无病变，因为只有它会出现明显的视力减退。

* **黄斑区无血管**

    * 视网膜的各条动脉分支都不深入黄斑区，故该区没有血管营养。

    * 病变恢复期很长——没有血管直接营养，只能靠周边渗透。

* 眼底定位示意

    ```text
        鼻侧上动脉              颞侧上动脉
              │                  │
       鼻侧  ┌────┴──────────────────┴────┐  颞侧
            │       视神经盘             │
            │ （无感光细胞 → 生理盲点） │
            └───────────┬────────────────┘
        鼻侧下动脉    │              颞侧下动脉
                          │  颞侧约 3~4 mm
                          ▼
                         ●  中心凹（最亮的光点）
                         │  周围的色素沉着区
                         ▼
                    黄斑：视觉细胞分布最密集 → 感光最敏锐
                          视网膜动脉的分支都不入此区 → 无血管营养，
                          病变恢复期很长
    ```

## 眼动脉的来源与走行

* **眶腔与眶壁**

    * 眶腔是锥体形的腔，眼球在眶腔里，后边连着视神经。

    * 眶的内侧壁内有蜂窝状的腔，即筛窦；外侧壁可见前床突、骨松质。

* **颈内动脉（internal carotid artery）**

    * 位置：在前床突的内侧。

    * 特点：在颈部没有分支，直接通过颅底的颈动脉管进入颅腔，营养脑髓和视器。

* **眼动脉（ophthalmic artery）**

    * 来源：由颈内动脉发出的一支，是眼的动脉总干。

    * 走行：进入眶腔后先在视神经的外下方，再绕过视神经的上方进入眶腔，然后发出各条分支。

## 眼动脉的分支与分布

* **视网膜中央动脉（central artery of retina）**

    * 走行：主干发出后钻到视神经里边去，分布到眼底，营养眼底。

* **筛前动脉与筛后动脉**

    * 分布区：筛窦。

* **泪腺动脉（lacrimal artery）**

    * 分布区：眶外侧壁的泪腺；并从泪腺再发出睑外侧动脉，另一侧发出睑内侧动脉。

* **睫状长动脉**

    * 分布区：营养虹膜和睫状体。

* **睫状短动脉**

    * 分布区：营养脉络膜。

* **睫状前动脉**

    * 与睫状长、睫状短动脉同源。

* **其他分支**

    * 滑车上动脉。

    * 鼻背动脉、眶上动脉。

* 眼动脉分支示意

    ```text
        颈内动脉（前床突内侧 · 颈部无分支，经颅底直接入颅）
             │
             │  发出眼动脉
             ▼
        眼动脉 ─► 视神经外下方 → 绕过视神经上方 → 入眶腔
             │
             ├── 滑车上动脉
             ├── 鼻背动脉、眶上动脉
             ├── 筛前动脉、筛后动脉 ──────► 筛窦
             ├── 泪腺动脉 ──► 泪腺 ──► 睑外侧动脉、睑内侧动脉
             ├── 睫状长动脉 ────────────► 虹膜、睫状体
             ├── 睫状短动脉 ────────────► 脉络膜
             ├── 睫状前动脉（与睫状长、短动脉同源）
             └── 视网膜中央动脉 ──► 钻入视神经内 ──► 眼底
    ```
