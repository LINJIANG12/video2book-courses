# 生理学（罗自强·国家精品课程）（100 讲）

罗自强教授主讲的生理学国家精品课程，按人体各系统从细胞到整体讲清"生命活动如何维持稳态"：细胞膜与生物电、血液、血液循环、呼吸、消化吸收、泌尿、感觉器官、神经系统、内分泌与生殖。100 集课程整编为 4 册模块全书与 8 篇主题复习笔记，适合医学基础课学习与考研生理学复习。

- **全 100 集**，已产出 4 册模块全书、8 篇复习笔记、22 份逐字稿

## 怎么学

- **先立主线**：整门课围绕"内环境稳态"展开，每学一个系统都问一句"它把哪个指标拉回正常范围"。
- **电生理要提前啃透**：静息电位、动作电位、兴奋传导是循环、神经、肌肉三部分的共同底座，建议最先吃透。
- **循环与呼吸按"泵—管道—调节"串**：心脏泵血 → 血压与血流 → 神经体液调节，呼吸则按"通气—换气—运输—调节"。
- **泌尿抓住"滤过—重吸收—分泌"三步**，再叠加对水盐与酸碱平衡的调节。
- **神经与内分泌用反射弧串起来**：感受器—传入—中枢—传出—效应器，激素部分则记"来源—靶点—效应—调控轴"。
