# 尿的生成与调节

## 尿生成的三个环节

* **肾小球滤过（glomerular filtration）**

    * > **定义**：血液流经肾小球毛细血管时，在有效滤过压的作用下穿过滤过膜进入肾小囊腔的过程。

    * 滤过是尿生成的第一步，决定原尿"有多少、是什么"。

* **肾小管和集合管的重吸收（reabsorption）**

    * > **定义**：把小管液中的物质转运回血液的过程。

    * 决定回收什么物质、回收多少。

* **肾小管和集合管的分泌（secretion）**

    * > **定义**：把上皮细胞自身产生的或血液中的物质转运入小管液的过程。

    * 与重吸收一起调节机体的酸碱平衡和电解质平衡，维持内环境相对稳定。

* **原尿、小管液与终尿**

    * 原尿即超滤液：不含血细胞和大分子蛋白质，其余成分与血浆完全一致——与血液的差别只有这两样。

    * 原尿流入肾小管后成分不断变化，改称小管液；经重吸收与分泌加工后成为终尿。

    ```text
    血液
     │ ① 肾小球滤过：有效滤过压驱动，血浆成分穿过滤过膜
     ▼
    原尿（超滤液）──流入肾小管后改称小管液
     │
     ▼
    肾小管 + 集合管
     ├─ ② 重吸收：小管液中的物质转运回血液
     └─ ③ 分泌：上皮细胞产生或血液中的物质转运入小管液
     ▼
    终尿
    ```

## 肾小球滤过的功能指标

* **肾小球滤过率（GFR）**

    * > **定义**：单位时间内（如一分钟）两肾生成的原尿量，即超滤液量。

    * 正常成年人约为每分钟 125 ml（与体表面积有关）；换算下来，一天 24 小时生成的原尿约 180 L。

* **肾血浆流量**

    * > **定义**：单位时间内（如一分钟）流经两肾的血浆量。

* **滤过分数（FF）**

    * > **定义**：肾小球滤过率与肾血浆流量的比值。

    * 回答"血浆流经肾小球毛细血管时有多少被滤出"：正常人大约 19%，即约 1/5 的血浆经滤过膜进入肾小囊腔生成原尿。

## 滤过膜及其屏障作用

* **滤过膜（filtration membrane）**

    * > **定义**：血浆成分进入肾小囊腔所穿越的三层结构，作用类似筛子——直径小于孔径的物质能穿孔而出，大于孔径的被阻挡。

    * 机械屏障：随分子有效半径增大，物质的滤过能力减小。

    * 电学屏障：滤过膜各层都带负电荷，对带负电荷物质的阻挡最大。

* **三层结构层层设卡**

| 层次 | 结构与孔径 | 阻挡任务 |
| :--- | :--- | :--- |
| 毛细血管内皮细胞 | 内皮窗孔直径约 70~90 nm | 挡住血细胞 |
| 基膜 | 由水和凝胶构成，微纤维网上有直径约 2~8 nm 的多角形网孔 | 孔径最小，起主要阻挡作用 |
| 肾小囊脏层上皮细胞（足细胞） | 膜上有直径约 4~11 nm 的小孔 | 最后一层阻挡 |

* **电荷与滤过能力**

    * 有效分子半径相同的物质：带正电荷者滤过能力最大，电中性者次之，带负电荷者最小。

* **肾小球肾炎与滤过膜受损**

    * 通透性增加的路径：炎症导致内皮细胞、上皮细胞坏死脱落，或基膜被破坏 → 挡不住血细胞和大分子蛋白质 → 血尿、蛋白尿。

    * 面积减小的路径：毛细血管腔狭窄或阻塞 → 有滤过功能的肾小球数量减少 → 有效滤过面积减小 → 肾小球滤过率降低 → 少尿甚至无尿。

    * > **易错点**：同是肾小球肾炎，走两条不同的路——滤过膜通透性增加漏出血尿、蛋白尿；有效滤过面积减小造成少尿、无尿。

## 有效滤过压

* **有效滤过压（effective filtration pressure）**

    * > **定义**：滤过动力与阻力之间的差，是驱动血浆穿过滤过膜的净压差。

    * $$\text{有效滤过压} = \text{肾小球毛细血管血压} - (\text{血浆胶体渗透压} + \text{肾小囊内压})$$

    * 毛细血管血压是唯一动力；原尿一侧因不含蛋白质，其胶体渗透压可忽略不计，阻力只有血浆胶体渗透压与肾小囊内压两项。

    * 决定肾小球滤过的全部变量：滤过膜、有效滤过压的三项压力、肾血浆流量和滤过系数。

## 影响肾小球滤过的因素

* **肾小球毛细血管血压**

    * 动脉血压在 80~160 mmHg 之间变化时，肾脏自身调节使肾血流量稳定，毛细血管血压无明显变化，滤过变化不大。

    * 动脉血压低于 80 mmHg：自身调节力有不逮 → 肾血流量降低 → 毛细血管血压减小 → 有效滤过压降低 → 肾小球滤过率减少。

    * 血压进一步降到 40~50 mmHg 以下（如休克时）：可以因为没有滤过而无尿。

    * 高血压病晚期：入球小动脉硬化、口径变窄 → 毛细血管压降低 → 有效滤过压减小 → 滤过减少。

* **肾小囊内压**

    * 肾小管或其以下排尿管道腔内阻塞、腔外压迫 → 尿液排出受阻 → 梗阻上方腔内积水、压力升高 → 囊内压升高 → 有效滤过压降低 → 滤过减少、滤过率降低。

* **血浆胶体渗透压**

    * 由血浆蛋白撑起。大量输入生理盐水稀释血浆，或肝功能损伤使血浆蛋白合成减少 → 血浆蛋白浓度降低 → 胶体渗透压下降 → 有效滤过压增大 → 滤过增多。

* **肾血浆流量与滤过平衡点**

    * 沿毛细血管从入球端走向出球端：毛细血管血压因克服阻力略有下降；水不断滤出而蛋白质被挡在血内，血浆胶体渗透压不断上升 → 有效滤过压一路下滑。

    * > **定义**：滤过平衡点是有效滤过压恰好降为零的那一点，从此处开始滤过停止；只有平衡点之前的管段才有滤过。

    * 血浆流量大 → 有效滤过压下降速率放慢 → 平衡点靠近出球端，甚至达不到平衡、毛细血管全长都有滤过 → 滤过率增大。

    * 血浆流量小 → 有效滤过压很快降到零 → 平衡点前移 → 发生滤过的毛细血管段缩短 → 滤过减少。

    * 肾血浆流量是影响肾小球滤过率的关键因素之一。

* **滤过系数（Kf）**

    * > **定义**：在单位有效滤过压的驱动下，单位时间内经过滤过膜的液体量。

    * $K_f = k \times S$，其中 $k$ 为滤过膜的有效通透系数，$S$ 为滤过膜面积；面积减小则滤过减少（如肾炎致滤过面积减小，出现少尿甚至无尿）。

## 肾小管与集合管的重吸收概览

各段重吸收量的总账：

| 部位 | Na⁺ 与 Cl⁻ | 水 | 备注 |
| :--- | :---: | :---: | :--- |
| 近端小管 | 65% | 65% | 等渗性重吸收；碳酸氢根约 85%；葡萄糖、K⁺ 全部回收 |
| 髓袢 | 20% | 15% | 升支粗段对水不通透 |
| 远曲小管和集合管 | 10% | 14% | 水的重吸收量大于钠和氯，且受抗利尿激素调节 |

* 髓袢分降支粗段、降支细段、升支细段、升支粗段：降支粗段的重吸收机制与近端小管一致；降支细段和升支细段钠泵活性低，主要是被动重吸收。

* 远曲小管上皮细胞间连接致密、通透阻力大，物质不易经旁路通透而被重吸收——钠的重吸收取决于它怎么跨过管腔膜。

## 近端小管的重吸收

* **总体特征**

    * 对水和钠离子的通透性很高，非常有利于重吸收；65% 的 Na⁺、Cl⁻ 和水在此被回收。

    * 水随钠、氯、葡萄糖、氨基酸等溶质被等比例重吸收，小管液渗透压始终与原尿相同——等渗性重吸收。

* **前半段：Na⁺ 跨管腔膜的三条通路**

    * Na⁺ 走跨上皮细胞路径：先穿管腔膜入胞，再被基底膜钠泵泵入组织间隙；跨管腔膜是关键步骤，钠泵是整个重吸收的发动机。

    * 管腔膜三类转运体：Na⁺/H⁺ 逆向交换体、Na⁺-葡萄糖同向转运体、Na⁺-氨基酸同向转运体。

    * Na⁺ 顺浓度梯度入胞释放的势能，带动葡萄糖、氨基酸逆浓度差入胞，并把 H⁺ 换出、分泌入小管液；葡萄糖、氨基酸随后以易化扩散经基底膜进入组织间隙、回血液。

    * 电位：Na⁺ 与 H⁺ 各带一个正电荷，一比一交换、一进一出，小管腔电位不变；Na⁺-葡萄糖、Na⁺-氨基酸同向转运把正电荷带进细胞 → 小管腔失去正电荷而带负电。

    * 前半段 Cl⁻ 不被重吸收而水被重吸收 → Cl⁻ 被浓缩，浓度升至原来的 1.2~1.4 倍。

* **后半段：Cl⁻ 打头的细胞旁路重吸收**

    * Cl⁻ 浓度已升高，且上皮细胞间紧密连接较疏松 → Cl⁻ 顺浓度梯度经紧密连接（细胞旁路）进入细胞间隙被重吸收。

    * Cl⁻ 带负电荷离开小管液 → 小管腔正电荷相对增多、电位由负转正 → 正电位驱使 Na⁺ 顺电势梯度经紧密连接被动重吸收。

    * 近端小管重吸收的 Na⁺ 中，跨细胞途径主动重吸收约占 2/3，细胞旁路被动重吸收约占 1/3。

* **钾离子与葡萄糖的两个"全部回收"**

    * 原尿中的 K⁺ 基本上被肾小管全部主动重吸收；终尿中的 K⁺ 大部分由远曲小管和集合管分泌而来。

    * 原尿中的葡萄糖在近端小管被 100% 重吸收，正常终尿不含葡萄糖。

* **碳酸氢根：以二氧化碳的形式回血**

    * 约 85% 的 HCO₃⁻ 在近端小管被重吸收；HCO₃⁻ 自己过不了管腔膜，走"变形"路线：

    ```text
    小管液：HCO3- + H+ → H2CO3 → CO2 + H2O
                                │ CO2 是脂溶性气体，扩散进入上皮细胞
                                ▼
    细胞内：CO2 + H2O ──碳酸酐酶──→ H2CO3 → H+ + HCO3-
              H+  → 经 Na+/H+ 交换再分泌入小管液
              HCO3- → 经基底膜回血液，重吸收完成
    ```

    * 重吸收依赖于 H⁺ 的分泌：氢离子分泌减少，碳酸氢根的重吸收随之减少。

    * CO₂ 是脂溶性气体、扩散快 → 碳酸氢根的重吸收速度比氯离子快，优先于 Cl⁻ 被重吸收——呼应前半段 Cl⁻ 不被重吸收、反被浓缩的现象。

    * 乙酰唑胺抑制碳酸酐酶活性 → H⁺ 分泌减少 → Na⁺ 重吸收降低 → 水的重吸收减少、尿量增多。

    * 酸性的 H⁺ 被分泌入小管液、碱性的 HCO₃⁻ 被回收回血——排酸保碱，是肾脏调节机体酸碱平衡的体现。

## 葡萄糖的重吸收与肾糖阈

* **重吸收机制**

    * 原尿中葡萄糖浓度与血浆一致；肾小管对葡萄糖的重吸收仅限于近端小管——此处未回收，其他部位不再回收。

    * 管腔膜 Na⁺-葡萄糖同向转运体：Na⁺ 顺浓度梯度入胞，带动葡萄糖逆浓度差入胞；细胞内葡萄糖再顺浓度梯度经基底膜入组织间隙、入血。

    * 属于继发于钠泵原发性主动转运的继发性主动转运，与 Na⁺ 的重吸收共同进行。

* **转运体有限与饱和**

    * 转运体数量有限，出现饱和现象：滤过量随血糖浓度线性增加（原尿葡萄糖浓度与血浆一致）；血糖不超过约 200 mg/100ml 时，终尿中没有葡萄糖；超过约 200 mg/100ml 后，终尿排糖量随血糖增高而增加。

    * 重吸收量随血糖升高相应增加，达到最大极限后不再增加——葡萄糖的最大转运量（Tm），此时血糖约达 300~400 mg/100ml 以上。

* **肾糖阈**

    * > **定义**：尿中不出现葡萄糖的最高血糖浓度（即尿中开始出现葡萄糖的最低血糖浓度），正常人为 160~180 mg/100ml。

    * 各近端小管上转运体数量不同、重吸收能力不同：重吸收能力最小的那部分肾小管达到饱和时，尿中即开始出现糖——肾糖阈反映的是能力低的那部分肾小管的最大重吸收能力。

    * 葡萄糖最大转运量是所有肾小管都发挥最大作用、全部达到饱和时的转运量：正常男性约 375 mg/min，女性约 300 mg/min。

    * > **易错点**：肾糖阈（160~180 mg/100ml）与最大转运量（男 375、女 300 mg/min）不是一回事——前者是"能力最差的那部分肾小管"饱和时的血糖浓度，此时尿中已开始出现糖；后者是全部肾小管都饱和时的转运上限。

## 髓袢升支粗段的重吸收

* **Na⁺-2Cl⁻-K⁺ 同向转运**

    * 对水不通透，但可主动重吸收氯化钠；管腔膜同向转运体一次搭载 1 个 Na⁺、2 个 Cl⁻、1 个 K⁺，由 Na⁺ 顺浓度梯度入胞的势能驱动。

    * 进入细胞的 Na⁺ 由基底膜钠钾泵泵入组织间隙；Cl⁻ 在胞内浓度升高后经氯离子通道离开；K⁺ 因细胞内本为高钾，一部分入组织间隙、一部分返回小管腔。

    * K⁺ 返漏使小管腔呈正电位 → 驱使 Na⁺、K⁺、Ca²⁺ 等正离子经细胞间紧密连接（细胞旁路）顺电位梯度重吸收。

    * 溶质被大量抽走而水出不去 → 小管液离开升支粗段时渗透压降低，管内液体被稀释。

* **呋塞米**

    * 强效利尿剂（速尿）：强烈抑制 Na⁺-2Cl⁻-K⁺ 同向转运体 → Na⁺、Cl⁻ 重吸收减少 → 水的重吸收随之降低 → 尿量明显增加。

## 远曲小管和集合管的重吸收

* **两套钠离子走法**

    * 远曲小管前段：管腔膜 Na⁺-Cl⁻ 同向转运体，钠氯成对进出、电荷相抵，不发生电位改变。

    * 远曲小管后段和集合管主细胞：管腔膜 Na⁺ 通道，Na⁺ 顺浓度梯度入胞 → 小管腔带负电——既促进细胞内 K⁺ 经钾通道分泌入小管腔，也驱使 Cl⁻ 顺电势梯度被重吸收。

    * 噻嗪类利尿剂阻断前段 Na⁺-Cl⁻ 同向转运体；阿米洛利阻断主细胞 Na⁺ 通道——两者都减少 Na⁺ 重吸收，使水重吸收减少、尿量增加。

* **水的重吸收依赖抗利尿激素**

    * 此段重吸收约 14% 的水（多于钠氯的 10%）；对水的通透性取决于抗利尿激素——它调节管腔膜上水通道的多少，从而调节水重吸收量。

    * 远曲小管和集合管因此能依据机体是否缺水，调节对水的重吸收量。

## 肾小管与集合管的分泌

* **氢离子**

    * 各段肾小管和集合管上皮细胞均可分泌，近端小管分泌量最大。

    * 两种方式：近端小管经 Na⁺/H⁺ 交换排氢（继发性主动转运）；远曲小管经消耗 ATP 的质子泵（氢泵）主动分泌（原发性主动转运）。

    * 意义：使小管液变酸；既可与磷酸氢根结合，也可与 HCO₃⁻ 结合生成碳酸、再解离为 CO₂ 和水，CO₂ 弥散入胞使 HCO₃⁻ 被重吸收——排酸保碱、调节机体酸碱平衡；此外还促进氨的分泌。

* **氨（铵根）**

    * 来源：谷氨酰胺的脱氨基。

    * 两种分泌方式：近端小管谷氨酰胺脱氨生成两个铵根，铵根代替 H⁺ 进行交换——"钠-铵交换"（Na⁺ 入胞，NH₄⁺ 分泌入小管液）；远曲小管内氨顺浓度梯度以扩散方式分泌。

    * 持续分泌的条件：主细胞消耗 ATP 主动分泌 H⁺，H⁺ 与氨结合成铵根、不断消耗小管液中的氨 → 氨得以顺浓度梯度持续扩散——氢的分泌促进氨的分泌。

    * 反向促进：氨结合 H⁺ 后小管液 H⁺ 浓度降低 → 小管液与上皮细胞间的 H⁺ 浓度差增大 → 有利于质子泵主动、持续地转运 H⁺——氢与氨的分泌互相促进、持续不断。

    * > **定义**：保碱指把小管液中的碳酸氢根重吸收回来；获碱指获得新生的碱。

    * 排氢获碱的账目：近端小管每分解谷氨酰胺产生两个铵根和两个碳酸氢根，铵根经钠-铵交换分泌、碳酸氢根入血——每分泌 2 个铵根，机体获得 2 个新生的 HCO₃⁻；远曲小管每有 1 个分泌出的 H⁺ 被氨结合，也新生 1 个 HCO₃⁻ 送入血液。

* **钾离子与钠钾交换**

    * 终尿中的 K⁺ 由远曲小管主细胞分泌，动力有二：Na⁺ 经钠通道重吸收使小管腔带负电（电势梯度）；基底膜钠钾泵不断把 K⁺ 泵入细胞使胞内高钾（浓度梯度）。

    * > **定义**：钾的分泌伴随钠的主动重吸收进行，称为钠钾交换。

    * 钠钾交换与钠氢交换存在竞争性抑制：酸中毒时钠氢交换加强、钠钾交换受抑制 → 氢排得多、钾排得少 → 血钾浓度升高；低血钾时钠钾交换减弱、钠氢交换相对增强。

    * 促进 K⁺ 分泌的四个因素：

        * 细胞外液 K⁺ 浓度升高：钠钾泵活动增强、把细胞外液的钾转运入胞 → 胞内 K⁺ 升高；同时刺激醛固酮分泌、保钠排钾。

        * 醛固酮分泌增多：直接促进保钠排钾。

        * 小管液流量增加：稀释小管腔内的 K⁺ → 上皮细胞内外 K⁺ 浓度差增大 → 分泌增加（大部分利尿药都借此增加 K⁺ 分泌）。

        * 小管腔内负电位增高：促进分泌，降低则抑制——阿米洛利抑制主细胞钠通道使负电位减小，K⁺ 分泌随之减少。

    * 保钾利尿药：螺内酯（氨体舒通）拮抗醛固酮；阿米洛利阻断主细胞钠通道——两者都减少 Na⁺ 重吸收与 K⁺ 分泌。

## 利尿药的作用位点

| 药物 | 作用位点与机制 | 后果 |
| :--- | :--- | :--- |
| 乙酰唑胺 | 抑制碳酸酐酶 → H⁺ 分泌减少 → Na⁺ 重吸收减少 | 水重吸收减少，尿量增多 |
| 呋塞米（速尿） | 抑制髓袢升支粗段 Na⁺/2Cl⁻/K⁺ 同向转运体 | 钠氯水重吸收减少，强效利尿 |
| 噻嗪类 | 阻断远曲小管前段 Na⁺/Cl⁻ 同向转运体 | 减少 Na⁺ 重吸收，利尿 |
| 阿米洛利 | 阻断主细胞 Na⁺ 通道，管腔负电位减小 | 减少 Na⁺ 重吸收与 K⁺ 分泌（保钾） |
| 螺内酯（氨体舒通） | 拮抗醛固酮 | 减少 Na⁺ 重吸收与 K⁺ 分泌（保钾） |

## 肾髓质渗透梯度

* **梯度形态**

    * 各部位组织液渗透浓度与血浆之比：皮质部为 1、约 300 毫渗单位，与血浆等渗；从皮质与髓质交界处开始越往髓质底部越高，髓质底部达 1200 毫渗单位——血浆渗透压的 4 倍。

    * > **定义**：与血浆渗透压相等的溶液称为等渗溶液；肾脏皮质部组织液的渗透压与血浆相同，属于等渗。

* **逆流倍增模型**

    * U 型管：氯化钠溶液由甲管（左）自上而下流入、乙管（右）自下而上流出，两管流向相反构成"逆流"；间隔膜上的钠泵不断把 Na⁺ 从乙管转运进甲管。

    * 结果：甲管越往下浓度越高、U 型管底最高；乙管越往上越低——两管都是越靠近管底氯化钠浓度越高，形成浓度（渗透压）梯度。

    * 肾脏里的对应结构是 U 形髓袢：降支细段和升支细段位于内髓质部，升支粗段位于外髓质部——这就是逆流的结构基础。

* **通透性差异是梯度形成的前提**

各段肾小管对水、尿素、氯化钠的通透性（＋通透，0 不通透；星号表示对水的通透必须依赖抗利尿激素）：

| 肾小管节段 | 水 | 尿素 | 氯化钠 |
| :--- | :---: | :---: | :---: |
| 髓袢降支细段 | ＋ | 0 | 0 |
| 髓袢升支细段、升支粗段 | 0 | ＋ | ＋ |
| 远曲小管、集合管 | ＋* | — | — |

* 抗利尿激素提高管腔膜对水的通透性；没有抗利尿激素，远曲小管和集合管的管腔膜就失去对水的通透性。

## 髓质高渗的形成

* **外髓部：升支粗段主动重吸收氯化钠**

    * 升支粗段对水不通透，依靠 Na⁺-K⁺-2Cl⁻ 同向转运体主动重吸收 Na⁺ 和 Cl⁻ → 小管液渗透压逐渐降低，管周组织渗透浓度升高——外髓质部高渗由此建立。

    * 越往皮质方向，能被重吸收进入组织间隙的氯化钠越少 → 从髓质深部到皮质形成渗透压梯度。

    * 外髓质部高渗的形成，是髓袢升支粗段主动重吸收氯化钠的结果。

* **内髓部：尿素与氯化钠共同建立**

    * 尿素线索：远曲小管和外髓部集合管对尿素不通透、对水通透（抗利尿激素存在的条件下）→ 外髓高渗使水不断被重吸收 → 小管液中尿素被浓缩；进入内髓部集合管后对尿素有通透性 → 尿素顺浓度梯度进入内髓组织 → 组织渗透浓度增高。

    * 氯化钠线索：降支细段对水通透、对 NaCl 不通透 → 水在渗透压差作用下不断被重吸收 → 管内 NaCl 浓度越来越高、到髓袢底部最高；进入升支细段后对水不通透、对 NaCl 通透 → NaCl 顺浓度梯度进入内髓组织 → 组织渗透浓度增高、小管液渗透浓度越来越低。

    * 两条线索汇合：髓袢降支细段和升支细段的小管液连同周围组织，自上而下渗透浓度越来越高，髓袢底部达到最高。

    * 内髓质部的渗透浓度，由尿素和氯化钠的重吸收共同形成。

* **尿素循环**

    * 内髓组织间隙的尿素进入髓袢升支细段随小管液流动，流经内髓部集合管时又重新进入组织间隙——尿素在管间打转，促进髓质渗透梯度的建立。

* **原动力与连锁反应**

    * 髓袢升支粗段对 NaCl 的主动重吸收是髓质高渗梯度建立的原动力；各段肾小管对水、NaCl、尿素通透性的不同是前提条件；尿素循环促进梯度建立。

    * 破坏升支粗段 Na⁺-K⁺-2Cl⁻ 转运体的连锁反应：外髓渗透浓度降低 → 外髓部集合管内水重吸收减少、尿素浓缩程度减小 → 进入内髓集合管后尿素不易扩散入组织、内髓渗透浓度降低 → 降支细段水重吸收受影响、管内 NaCl 浓度升高不明显 → 升支细段 NaCl 顺浓度差扩散入组织的量减少 → 内髓渗透浓度进一步降低。

    * 结果：外髓和内髓的渗透梯度形成都受到明显影响——牵一发动全身，原动力只有这一个。

## 髓质渗透梯度的维持

* **逆流交换模型**

    * 单根 U 型管过热源：20 度冷水进、80 度热水出，带走大量热量；把两管合并贴在一起且管间可传热：下行冷水一路接受上行热水传来的热量，进热源后获得的热量明显减少，流出时只有 30 度——同样流过热源，带走的热量明显减少，称为逆流交换。

* **直小血管的逆流交换**

    * 肾小管不断重吸收水，水进入髓质组织间隙会稀释溶质、破坏梯度——必须运走水、尽可能少运走溶质；执行这一角色的是 U 型的直小血管，属毛细血管、通透性非常高。

    * 血液从皮质流来时渗透浓度约 300 毫渗单位；降支下行：周围组织渗透浓度高 → 水顺渗透压差渗出、溶质渗入 → 血液越走越浓，到髓质底端达 1200 毫渗单位、与周围组织持平。

    * 升支上行：血液渗透浓度高于周围组织 → 溶质渗出回到组织间隙 → 血液渗透浓度不断降低——离开髓质时带走的溶质很少。

    * 升支内静水压越来越低、血液渗透浓度又高于邻近组织 → 组织间隙有更多水进入血管——带走大量的水、较少的溶质。

    * 重吸收的水被运走而溶质留在髓质，肾髓质高渗得以维持。

## 影响髓质渗透梯度的因素

* **髓袢结构与机能的完整性**

    * 慢性肾盂肾炎长期炎症损伤肾小管结构和功能 → 破坏髓质高渗梯度的形成 → 影响尿液的浓缩和稀释。

* **尿素的供应**

    * 尿素是蛋白质的代谢产物，髓质高渗的形成需要它参与；严重营养不良、蛋白质摄入不足 → 尿素生成减少 → 髓质高渗受影响 → 尿液浓缩程度降低、尿量增加。

* **药物**

    * 速尿（呋塞米）阻断升支粗段 Na⁺-K⁺-2Cl⁻ 转运体 → 外髓质渗透浓度降低 → 进而影响内髓质渗透梯度的形成 → 水重吸收减少、尿量明显增加。

* **直小血管的血流**

    * 直小血管没有自身调节，血流速度易随血压变化：血流过快 → 来不及充分交换 → 带走大量溶质 → 梯度维持受影响——高血压病早期血压高、常表现为多尿，道理在此。

    * 血流过慢 → 多余的水分带不走 → 同样影响梯度的维持。

    * > **易错点**：直小血管血流既不能太快也不能太慢——快了带走溶质，慢了潴留水分，两头都会破坏髓质高渗的维持。

## 尿液的浓缩与稀释

* **基本概念**

    * 正常人血浆渗透压 300 毫渗单位；终尿渗透压可在 50~1200 毫渗单位之间变化。

    * 终尿渗透压低于、等于或高于血浆渗透压，分别称为低渗尿、等渗尿、高渗尿。

    * 尿渗透压的改变实际反映尿中溶质浓度的变化，并引起尿比重相应变化——临床上通过测定尿比重，间接反映肾脏对尿液的浓缩或稀释功能。

* **浓缩与稀释的条件**

    * 尿液的浓缩与稀释，需在肾髓质渗透梯度的环境下进行。

    * 浓缩的基础：肾小管外存在高渗环境，且管壁对水有通透性——水分不断进入高渗的管外，小管液一路浓缩，到管底达 1200 毫渗单位；管内外无渗透压差后，浓缩到此为止。

    * 稀释的基础：管壁对水没有通透性，而小管液内溶质的重吸收继续——水留下、溶质被吸走，小管液渗透压越来越低，降到 50 毫渗单位为止，这是肾小管稀释功能的极限。

    * 抓两个关键：必须有渗透压梯度存在；看肾小管对水是否有通透性——后者受抗利尿激素调节。

* **抗利尿激素对水通道的开与关**

    * 有抗利尿激素：含水通道蛋白的囊泡移位到管腔膜与之融合 → 管腔膜含水通道、对水有通透性 → 水进入高渗的管外，小管液被浓缩，终尿为高渗尿。

    * 无抗利尿激素：管腔膜上的水通道蛋白被内吞入胞浆 → 管腔膜失去对水的通透性 → 即使管外渗透压高于管内，水也不被重吸收；溶质继续被重吸收，小管液渗透浓度越来越低，最终以低渗尿排出。

    * 机体根据自身水平衡状况调节抗利尿激素释放量 → 决定远曲小管和集合管对水通透性的大小与水重吸收量 → 决定尿被浓缩还是被稀释。

* **尿崩症的两种情形**

    * 抗利尿激素缺乏 → 集合管对水通透性降低、水不能被重吸收 → 尿量大量增加，称真性尿崩症。

    * 抗利尿激素分泌正常，但集合管上皮细胞上的抗利尿激素受体减少或功能受损 → 同样尿量大量增加，称肾源性尿崩症。

* **尿浓缩试验**

    * 做法：受试者正常进食，日间尿白天每 2 小时收集一次、共六次；夜间尿 12 小时收集一次；分别测定尿量及尿比重。

| 指标 | 正常 | 浓缩功能减退时 |
| :--- | :---: | :---: |
| 24 小时尿量 | 1000~2000 ml | 超过 2500 ml |
| 最高尿比重 | 大于 1.020 | 小于 1.018 |
| 最高与最低尿比重之差 | 不小于 0.009 | 小于 0.009，严重者仅 0.001~0.002 |

    * 浓缩功能减退时，髓质渗透梯度不能很好建立和维持、水重吸收受严重影响——尿量增多、尿液不能被浓缩。

    * 尿比重常常固定在 1.010 左右 → 提示肾脏完全丧失了浓缩功能。

## 肾小球滤过率的调节

* **肾血流量的自身调节**

    * 动脉血压在 80~160 mmHg 范围内变化时，肾血流量维持稳定 → 肾小球滤过率维持稳定 → 尿量无明显变化。

* **管球反馈**

    * > **定义**：肾小管内液体流量的变化反馈调节肾血流量和肾小球滤过率，称为管球反馈——小管液流量增加时，该肾单位的肾小球滤过率降低，本质是一种负反馈。

    * 链条：GFR 增加 → 到达远端小管致密斑的流量增加 → 致密斑（化学感受器）感受小管液中 Na⁺ 量的增加 → 信息传递给入球小动脉 → 入球小动脉收缩 → 肾血流量降低 → GFR 降低。

    * 机制链：致密斑处流量升高 → Na⁺ 增多 → 致密斑主动重吸收 Na⁺ 增加 → ATP 消耗增多、腺苷产生增加 → 腺苷作用于球外系膜细胞 → 细胞内 Ca²⁺ 浓度升高 → Ca²⁺ 经细胞间通道进入球旁细胞 → 入球小动脉平滑肌收缩并抑制肾素释放 → 肾血流量降低 → GFR 减少。

* **神经与体液因素**

    * 交感神经兴奋：收缩入球小动脉 → 肾血流量降低 → GFR 降低、尿量减少。

    * 较高水平的血管紧张素 II：收缩入球小动脉和出球小动脉 → 肾血流量和 GFR 降低。

    * 心房钠尿肽：舒张入球小动脉、收缩出球小动脉 → 肾小球毛细血管血压升高、滤过分数增大；并使肾小球系膜细胞舒张、滤过面积增大 → GFR 增加。

    * 场景对照：安静状态靠自身调节维持 GFR 与尿量稳定；大出血等情况下靠交感神经兴奋减少肾血流量、降低 GFR、使尿量减少 → 减少体液丢失、有利于维持血量。

## 尿生成的肾内自身调节

* **渗透性利尿**

    * > **定义**：小管液中溶质浓度升高 → 小管液渗透浓度增加 → 小管液与管周组织间渗透压差减小 → 水重吸收减少 → 尿量增加，称为渗透性利尿。

    * 糖尿病人多尿的机制：血糖浓度高于肾糖阈 → 原尿中部分葡萄糖不能被重吸收 → 小管液溶质渗透浓度增加 → 水重吸收减少 → 多尿。

    * 甘露醇脱水治疗：可被肾小球滤过而不被重吸收 → 增加小管液溶质浓度 → 产生渗透性利尿，排出体内多余水分。

* **球管平衡**

    * > **定义**：无论肾小球滤过率增多还是减少，近球小管对滤过液的重吸收量始终占肾小球滤过量的 65%~70% 左右，称为定比重吸收。

    * 数据：GFR 每增加或减少 25 ml/min，近球小管重吸收绝对量相应增减 17.5 ml/min，流到远端小管的液量只增减 7.5 ml/min——远端小管内流量相对稳定，尿中排出的溶质和水不因 GFR 变化而大幅增减。

    * 机制（近球小管周围毛细血管的状态）：肾血流量相对稳定而 GFR 增加时 → 滤过分数增大 → 近球小管周围毛细血管内胶体渗透压升高、静水压降低 → 有利于组织液进入毛细血管 → 重吸收增加；GFR 降低时 → 胶渗压升高不明显、静水压降低不明显 → 部分吸收到组织间隙的液体不易进入毛细血管。

    * 近球小管是"渗漏上皮"：紧密连接不像远端小管那样致密 → GFR 降低时，组织间隙的液体可经上皮细胞顶端的紧密连接反漏回小管腔 → 重吸收量相应减少而比例保持不变。

    * 球管平衡与管球反馈都是肾小球和肾小管之间的相互作用，共同维持 GFR、重吸收和尿量的稳定。

* **交感神经的直接作用**

    * 除收缩肾动脉、刺激球旁细胞增加肾素释放以影响 GFR 外，交感神经还直接作用于肾小管：增加近球小管和髓袢对 Na⁺ 和水的重吸收 → 尿量减少。

## 抗利尿激素

* **合成、储存与释放**

    * 由下丘脑视上核和室旁核的神经元合成 → 沿下丘脑-垂体束运送到神经垂体储存 → 从神经垂体释放入血；下丘脑和神经垂体的病变都会减少其合成和分泌。

* **生物学作用**

    * 与血管平滑肌上的 V1 受体结合 → 血管收缩、血压升高——因此又称血管升压素。

    * 与远曲小管和集合管上皮细胞上的 V2 受体结合 → 激活腺苷酸环化酶 → 含水通道蛋白的囊泡移位至小管管腔膜并融合 → 顶端膜水通道蛋白数量增多、对水通透性提高 → 水重吸收增多、尿量减少。

    * 促进内髓部集合管对尿素的通透、促进髓袢升支粗段对 NaCl 的主动重吸收 → 加强髓质高渗的形成（髓质高渗正是促进水重吸收的动力）。

    * 两头夹击：一方面加强髓质高渗，另一方面增大远曲小管和集合管对水的通透性 → 水重吸收明显增多、尿量明显减少——很强的抗利尿效应。

* **分泌的调节**

    * 血浆渗透压（轻微变化即可引起明显反应）：健康成人饮 1.2 L 清水后约 1 小时尿量达峰值、2 小时左右基本回落；饮 1.2 L 生理盐水则 2 小时内尿量无明显变化——清水吸收使血浆渗透压降低 → 对下丘脑渗透压感受器的刺激减弱 → 抗利尿激素合成释放减少 → 水重吸收减少、尿量增加，称为水利尿；生理盐水是等渗液体，血浆渗透压不变 → 抗利尿激素不减少 → 尿量无明显波动。

    * 血容量（敏感度较低）：血容量减少 5%~10% 以上才能引起抗利尿激素量的明显增加——循环血量减少 → 对心肺感受器（容量感受器）的刺激减少 → 迷走神经传入冲动降低 → 对下丘脑的抑制作用减轻 → 抗利尿激素合成分泌增多。

    * 血压：血压升高刺激压力感受器 → 传入冲动增加、加强对下丘脑的抑制 → 抗利尿激素分泌减少；血压降低则分泌明显增加——由此调节水重吸收量，有助于血容量和血压恢复正常。

    * 其他因素：恶心、疼痛、某些药物使抗利尿激素分泌增高；酒精使其分泌减少——这是饮酒后尿量增多的重要原因。

## 肾素-血管紧张素-醛固酮系统

* **系统级联**

    * 球旁细胞合成分泌肾素 → 在肾素作用下血管紧张素原变为血管紧张素 I → 再经一系列酶作用生成血管紧张素 II、血管紧张素 III；血管紧张素 II 和 III 都能促进醛固酮的合成分泌。

    * 系统中影响肾小管和集合管重吸收、导致尿量改变的两个因素：血管紧张素 II 与醛固酮。

* **醛固酮**

    * 由肾上腺皮质球状带合成分泌的类固醇激素，作用是保钠、保水、排钾。

    * 机制：与胞浆受体结合进入细胞核 → 促进基因转录 → 生成多种醛固酮诱导蛋白——管腔膜上的钠通道蛋白、线粒体中合成 ATP 的酶、基侧膜上的钠泵等 → 钠通道数量增多利于 Na⁺ 重吸收；ATP 合成增多、能量供应增加，促进 Na⁺ 重吸收和 K⁺ 分泌。

    * 分泌调节：血管紧张素 II 和 III 促进其分泌；血 K⁺ 浓度升高或血 Na⁺ 浓度降低也可刺激其分泌增加——从而促进钾的分泌或钠的重吸收，维持血钾和血钠浓度相对稳定。

    * 醛固酮异常增高：保钠保水排钾过强 → 血量增多和低血钾。

* **血管紧张素 II 的三条作用途径**

    * 刺激肾上腺皮质球状带细胞合成、释放醛固酮 → 间接保钠保水排钾。

    * 直接作用于近球小管，促进对 NaCl 的重吸收。

    * 作用于下丘脑，使抗利尿激素分泌增加 → 促进对水的重吸收。

* **肾素分泌的调节（系统关键）**

    * 肾素分泌增加 → 血管紧张素 II 及醛固酮分泌增加；肾素受肾内与肾外因素双重调节。

    * 入球小动脉牵张感受器：入球小动脉血压降低 → 对牵张感受器的刺激减弱 → 肾素释放增加。

    * 致密斑化学感受器：流经致密斑处的 Na⁺ 减少 → 促进肾素释放。

    * 交感神经：兴奋时刺激球旁细胞的 β 受体 → 肾素释放增多；肾上腺素和去甲肾上腺素的作用与交感神经类似。

## 心房钠尿肽

* **来源与性质**

    * 由心房肌细胞合成并释放的肽类激素，有利钠利尿作用。

* **直接作用**

    * 升高 cGMP → 集合管上皮细胞管腔膜上的 Na⁺ 通道关闭 → 抑制对 NaCl 的重吸收。

    * 血管平滑肌细胞内 cGMP 升高 → 舒张入球小动脉 → 肾小球血流量增加 → 肾小球滤过率增大。

    * 增大肾小球滤过 + 抑制 NaCl 重吸收 → 直接利尿、利钠。

* **间接作用**

    * 抑制肾素、醛固酮、抗利尿激素的分泌 → 间接利尿利钠。
