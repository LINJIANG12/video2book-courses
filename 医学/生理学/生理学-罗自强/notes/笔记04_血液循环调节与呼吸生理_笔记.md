# 血液循环调节与呼吸生理

## 心脏与血管的神经支配

* **变时、变力、变传导**

    * > **定义**：变时指心率，变力指心肌收缩力，变传导指兴奋在心肌内的传导；"正性"即三者都增强，"负性"即三者都减弱。

* **心交感神经**

    * 兴奋时节后纤维释放去甲肾上腺素，使心肌自律性增加、心率加快、心肌收缩力增强，表现为正性变时、变力、变传导。

* **心迷走神经**

    * 兴奋时使所有心肌细胞对 K⁺ 的通透性增加、K⁺ 外流增加，心肌的兴奋性、传导性、自律性和收缩性全部下降，表现为负性变时、变力、变传导。

    * 安静状态下心迷走神经活动占优势，把心率从窦房结固有的自动兴奋频率 100 次/分压低到 75 次/分左右；劳动、运动、激动时心交感神经占优势，心率可超过 100 次/分（如 120 次/分）。

* **交感缩血管神经**

    * 体内几乎所有血管平滑肌都受其支配；节后纤维释放去甲肾上腺素，与血管平滑肌 α 受体结合使血管收缩——小动脉和微动脉收缩使外周阻力增加，静脉收缩使静脉回流增加，两者都升高血压。

    * 分布密度存在差异：皮肤血管中分布密度最大，骨骼肌和内脏血管居第二，冠脉和脑血管最低——交感缩血管神经兴奋时引起血液在全身的重新分配。

    * 安静状态下自发地以每秒 1~3 次的频率发放冲动，称为交感缩血管紧张；血管正是在这股持续张力维持下保持一定收缩状态，用 α 受体阻断剂阻断后血管舒张、血压下降。

* **舒血管神经纤维**

    * 血管也受舒血管神经纤维支配，如主要分布在骨骼肌血管的交感舒血管神经纤维；其释放的递质是乙酰胆碱，与血管平滑肌 M 受体结合使血管舒张。

## 压力感受性反射

### 反射弧组成

* **压力感受性反射（窦弓反射）**

    * > **定义**：颈动脉窦和主动脉弓压力感受性反射的简称，血压升高时把血压降下来、血压降低时把血压托回去，又称降压反射（减压反射），是最重要的心血管反射。

* **感受器**

    * 颈动脉窦和主动脉弓，真正敏感的刺激是牵张刺激（血压变化产生牵张），故习惯称压力感受器。

* **传入神经与中枢**

    * 传入神经为窦神经和主动脉神经。

    * 最基本的心血管中枢在延髓，包括心迷走中枢、心交感中枢和交感缩血管中枢。

* **传出神经与效应器**

    * 传出神经即心迷走神经、心交感神经和交感缩血管神经，效应器为心脏和血管——反射弧五个部分在此凑齐。

### 双向调节过程

* **血压升高时（降压方向）**

    * 感受器牵张刺激加强 → 窦神经、主动脉神经传入冲动增加 → 心迷走中枢活动加强，心交感中枢和交感缩血管中枢活动减弱 → 心迷走神经活动加强，心交感神经、交感缩血管神经活动减弱。

    * 效果分两路：心率减慢、收缩力减弱 → 心输出量减少；外周血管舒张 → 外周阻力下降——最终血压降低。

    ```text
    血压升高
       │
       ▼
    颈动脉窦、主动脉弓牵张刺激加强
       │  窦神经、主动脉神经传入冲动增加
       ▼
    延髓心血管中枢：心迷走中枢加强；心交感、交感缩血管中枢减弱
       │
       ├─→ 心率减慢、收缩力减弱 → 心输出量减少
       └─→ 外周血管舒张         → 外周阻力下降
       │
       ▼
    血压降低
    ```

* **血压降低时（升压方向）**

    * 感受器刺激减弱、传入冲动减少 → 心迷走中枢活动减弱，心交感中枢和交感缩血管中枢活动加强 → 心率加快、收缩力加强、心输出量增加，血管收缩、外周阻力增加——血压回升。

    * 即血压降低时通过该反射的减弱使血压回升，与降压方向互为镜像。

### 调节特点

* **工作范围**

    * 动脉血压 60~180 mmHg 之间才能起作用；低于 60 mmHg 或高于 180 mmHg 时压力感受性反射都不能起作用。

* **重调定（resetting）**

    * 只对血压的迅速变化敏感：对收缩压持续 ≥140 mmHg 的高血压患者，它不能把血压降到正常，只能在较高水平上维持血压的相对稳定。

* **双向调节**

    * 以窦神经放电频率为纵坐标、颈动脉窦内压为横坐标作曲线，正常平均血压正好落在曲线中部——高于正常可降下来，低于正常可升上去。

* **敏感性差异**

    * 两个感受器中，颈动脉窦的敏感性高于主动脉弓。

### 生理意义与临床应用

* **快速缓冲血压变化**

    * 动物实验去除压力感受性反射相应的结构后，动脉血压大起大落；维持动脉血压相对稳定最重要的因素就是压力感受性反射。

* **治疗阵发性室上性心动过速**

    * 按摩颈动脉窦 → 压力感受性反射加强、心迷走中枢活动加强、心迷走神经活动加强 → 减慢心率。

## 心血管活动的体液调节

* **体液调节**

    * 心血管活动受神经、体液和自身调节三种方式调节；体液调节指血液和组织液中某些化学物质对心肌和血管平滑肌活动的调节。

### 肾素-血管紧张素系统

* **肾素**

    * 肾脏近球细胞合成和分泌的酸性蛋白酶，经肾静脉进入血液循环。

* **血管紧张素的级联水解**

    ```text
    血管紧张素原（肝脏产生，无活性）
       │  肾素（肾脏近球细胞分泌的酸性蛋白酶）
       ▼
    血管紧张素Ⅰ（十肽，对体内大多数组织细胞不具活性）
       │  血管紧张素转化酶（血浆与组织中均有，尤以肺循环血管内皮表面为多）
       ▼
    血管紧张素Ⅱ（八肽，作用最重要）
       │  氨基肽酶（再水解掉一个氨基酸）
       ▼
    血管紧张素Ⅲ（七肽）
       │  相应的酶继续水解
       ▼
    血管紧张素1-9、血管紧张素1-7、血管紧张素Ⅳ……
    ```

    * 各产物功能不同，甚至相互拮抗——肾素-血管紧张素系统远比想象的复杂。

* **血管紧张素Ⅱ的强大升压效应**

    * 血管紧张素需与组织细胞表面特异性受体结合才能发挥作用；对体内大多数组织和细胞，血管紧张素Ⅰ不具活性，以血管紧张素Ⅱ的作用最为重要。

    * 外周机制：直接使全身微动脉收缩、外周阻力增加；使静脉收缩、回心血量增加。

    * 中枢与交感机制：使交感神经末梢释放的去甲肾上腺素增多；使交感缩血管中枢的紧张性活动加强——中枢与外周机制协同发挥强大升压效应。

    * 容量机制：非常强地刺激肾上腺皮质球状带细胞合成和释放醛固酮 → 肾小管对 Na⁺ 和水的重吸收增加、循环血量增加；同时兴奋渴觉、引起饮水行为，同样增加循环血量。

    * 临床应用：血管紧张素转化酶抑制剂减少血管紧张素Ⅱ的生成，产生明显降压效应。

* **血管紧张素Ⅲ**

    * 缩血管效应约为血管紧张素Ⅱ的 10%~20%；刺激肾上腺皮质球状带合成和分泌醛固酮的作用更强——既缩血管又增加循环血量，也有一定升压效应。

* **RAAS 命名**

    * 只要有肾素生成就有血管紧张素生成、进而使醛固酮分泌增加，故肾素-血管紧张素系统又称肾素-血管紧张素-醛固酮系统（RAAS）。

### 肾上腺素与去甲肾上腺素

* **来源**

    * 循环血液中的肾上腺素和去甲肾上腺素主要来自肾上腺髓质的分泌，其中肾上腺素约占 80%、去甲肾上腺素约占 20%；肾上腺髓质受交感神经节前纤维支配，交感兴奋时二者释放明显增加——常合称"交感-肾上腺髓质系统"。

    * 肾上腺素能神经末梢也能释放少量去甲肾上腺素入血，作为激素起作用。

* **肾上腺素：以强心为主**

    * 兴奋心脏 β1 受体 → 正性变时、变力、变传导 → 心输出量增加，血压升高。

    * 对血管的总效应取决于血管平滑肌上 α 与 β 受体的分布：皮肤、肾脏、胃肠道血管以 α1 受体为主 → 收缩；骨骼肌和肝脏血管 β2 受体占优势 → 小剂量肾上腺素以兴奋 β2 为主引起血管舒张，大剂量以兴奋 α 受体为主引起收缩。

    * 总效应：既升高收缩压，又能降低舒张压，以强心为主；能在不增加甚至降低外周阻力的情况下增加心输出量——临床常用作强心药。

* **去甲肾上腺素：血压升高而心率减慢**

    * 也能兴奋心脏、加强心脏活动；但静脉注射后强烈的升压效应激活压力感受性反射，迷走对心脏的抑制效应超过其直接兴奋效应——净效应是血压升高、心率反而减慢。

    * > **易错点**：⚠️ 静脉注射去甲肾上腺素后心率减慢，不是它直接抑制心脏，而是血压升高激活窦弓反射、迷走的抑制效应压过了直接兴奋作用——判断心血管药物的净效应，永远要把压力感受性反射算进去。

* **两者对比**

    | 对比项 | 肾上腺素 | 去甲肾上腺素 |
    | :--- | :--- | :--- |
    | 对心脏的直接作用 | 兴奋 β1 受体，正性变时变力变传导 | 也能兴奋心脏、加强活动 |
    | 对血管的作用 | 皮肤、肾、胃肠血管收缩；骨骼肌和肝血管小剂量舒张、大剂量收缩 | 强烈的升血压效应 |
    | 血压表现 | 收缩压升高、舒张压降低 | 明显升高 |
    | 心率的净变化 | 加快 | 反而减慢（反射性抑制占上风） |

### 血管升压素

* **血管升压素**

    * > **定义**：由下丘脑视上核和室旁核合成、经垂体后叶（神经垂体）释放入血的体液因素，兼有抗利尿与缩血管两种效应。

    * 与肾脏集合管上皮细胞上相应受体结合 → 水重吸收增加、尿量减少——因此又称抗利尿激素。

    * 与血管平滑肌上相应受体结合 → 强烈收缩血管、外周阻力增加、血压升高——血管升压素是已知的最强的缩血管物质。

    * 正常情况下血浆浓度升高时首先出现抗利尿效应；只有当浓度比产生抗利尿作用时升高十倍以上，才引起升压效应——因为它能提高压力感受性反射的敏感性，缓冲了自身的升压效应。

    * > **易错点**：⚠️ "最强缩血管物质"不等于"生理浓度下就升压"——正常浓度升高先看到的是抗利尿，升压要等浓度高出十倍以上，且还会被压力感受性反射缓冲掉一部分。

### 升压与舒张的体液因素

* **升压与舒张一览**

    | 体液因素 | 主要心血管效应 |
    | :--- | :--- |
    | 肾上腺素 | 以强心为主，兼有一定升压效应 |
    | 去甲肾上腺素、血管紧张素Ⅱ、血管升压素、内皮素 | 强烈缩血管、升压（内皮素在生理情况下增高并不明显） |
    | 肾上腺髓质素、心房钠尿肽、缓激肽、NO、前列环素 | 舒张血管 |

* **来源补充**

    * 肾上腺髓质除分泌肾上腺素和去甲肾上腺素外，还产生第三种激素肾上腺髓质素；心房肌细胞产生心房钠尿肽——两者与缓激肽、NO、前列环素同属舒张血管的体液因素。

## 呼吸的环节与肺通气动力

### 呼吸的环节

* **呼吸**

    * > **定义**：机体与环境之间气体交换的过程，是人体最基本的生命活动之一。

* **五个环节**

    * 肺通气：一吸一呼，气体进出肺泡，实现肺与外环境之间的气体交换。

    * 肺换气：肺泡与肺毛细血管之间的气体交换。

    * 气体在血液中的运输：把吸入的氧送到组织利用，把组织产生的二氧化碳运送到肺排出体外。

    * 组织换气：组织毛细血管与组织细胞之间的气体交换。

    * 细胞内的氧化代谢：氧在细胞内被氧化利用并产生二氧化碳。

    ```text
    外环境
       ⇅  肺通气
      肺泡
       ⇅  肺换气
      肺毛细血管
       ⇅  气体在血液中的运输
      组织毛细血管
       ⇅  组织换气
      组织细胞
       ⇅  细胞内氧化代谢
    ```

* **三环节口径**

    * 外呼吸＝肺通气＋肺换气；内呼吸＝组织换气＋细胞内氧化代谢；加上中间的气体在血液中的运输，呼吸也可分为三个环节。

* **肺通气的三个参与者**

    * 呼吸道：从鼻腔到终末细支气管的传导气道，既是气体进出肺的通道，又对吸入气有加温、湿润、过滤清洁和引起防御反射的保护作用。

    * 肺泡：肺换气的主要场所，肺通气使肺泡内的气体不断更新。

    * 胸廓：容纳和保护气道与肺，并通过呼吸肌的运动为肺通气提供动力。

### 肺通气的直接动力

* **肺内压与大气压之差**

    * > **定义**：肺泡内压力（肺内压）的变化是肺通气的直接动力；气体顺着压力梯度从压力高的一端流向压力低的一端。

    * 吸气：肺容积增大 → 肺内压降低、低于大气压 → 空气流入肺泡；随肺内气体增加肺内压回升，至吸气末与大气压相等、气流停止。呼气：肺容积减小 → 肺内压升高、超过大气压 → 气体流出；肺内气体减少、肺内压下降，至呼气末又与大气压相等。

    * > **提示**：无论吸气末还是呼气末，只要气流停止，肺内压一定与大气压相等——没有压力差就没有气流。

    * 肺内压变化幅度取决于呼吸运动的缓急深浅和呼吸道是否通畅：平静呼吸时吸气相低于大气压 1~2 mmHg、呼气相高于大气压 1~2 mmHg；用力呼吸时吸气相可低至 -100~-30 mmHg、呼气相可高达 60~140 mmHg——压差放大几十倍。

* **人工呼吸**

    * 自然呼吸停止时，用人为方法建立肺内压与大气压之间的压力差，维持肺通气。

    * 负压通气：降低胸廓外压力、使胸廓扩大实现吸气；正压通气：提高肺外压力、将气体压入肺内（如人工呼吸机、口对口人工呼吸）——正压通气吸气相的肺内压高于大气压，与生理性吸气相肺内压低于大气压不同。

### 呼吸运动与呼吸肌

* **呼吸运动**

    * 肺本身不具备主动扩张和缩小的能力，肺容积和肺内压的变化由胸廓的扩大缩小带动：中枢神经系统控制 → 呼吸肌节律性收缩与舒张 → 胸廓容积周期性变化 → 肺被动扩大缩小 → 肺内压周期性变化 → 吸气与呼气。

    * > **定义**：呼吸肌的收缩与舒张引起胸廓节律性的扩大和缩小，称为呼吸运动——肺通气的原动力。

    * 呼吸肌分吸气肌和呼气肌：吸气肌收缩引起胸廓容积增大和吸气；呼气肌收缩或吸气肌舒张引起胸廓容积缩小和呼气。

* **吸气肌**

    * 膈肌最重要：位于胸腔与腹腔之间、构成胸腔的底和腹腔的顶，静息呈穹窿状向上隆起，收缩时膈顶下移、胸腔上下径增大——膈肌的作用约占胸腔容积增大的 4/5，肋间外肌远不如它显著。

    * 肋间外肌：起自上一肋骨下缘、斜向前下方止于下一肋骨上缘，收缩时肋骨和胸骨上抬、肋骨下缘向外偏转，胸腔左右径和前后径增大。

    * 辅助吸气肌：斜角肌、胸锁乳突肌等。

* **呼气肌**

    * 腹肌：收缩使腹内压增高，压迫腹腔脏器将膈肌向上推移，并牵拉肋骨向下、向内移位，胸腔上下径减小。

    * 肋间内肌：走行和作用与肋间外肌相反，收缩使肋骨向下、向内移位并向内翻转，胸腔前后径和左右径缩小。

* **腹式呼吸与胸式呼吸**

    * 以膈肌活动为主、引起腹腔内器官位移和腹壁起伏的呼吸运动称腹式呼吸；以肋间外肌活动为主、引起胸壁起伏的称胸式呼吸。

    * 一般为腹式与胸式的混合式，只在胸部或腹部活动受限时出现单一形式：妊娠后期、腹腔炎症等使膈肌活动受限 → 明显胸式呼吸；胸膜炎、胸腔积液因疼痛影响 → 明显腹式呼吸。

* **平静呼吸与用力呼吸**

    * 平静呼吸：安静时平稳均匀；吸气是主动的（膈肌、肋间外肌收缩），呼气是被动的（由膈肌和肋间外肌舒张引起，呼气肌不收缩）。

    * 用力呼吸（深呼吸）：运动或气道阻力增大时呼吸加深加快；参与收缩的吸气肌数量更多、收缩更强，呼气时呼气肌也收缩——吸气和呼气都是主动过程。

    * > **易错点**：⚠️ 平静呼气是被动的（靠吸气肌舒张回位），用力呼气才是主动的（呼气肌收缩）——别把"呼气肌"和平静呼气绑在一起。

## 胸膜腔内压

### 胸膜腔的结构

* **胸膜腔**

    * > **定义**：肺与胸廓内壁之间由脏层胸膜和壁层胸膜密封形成的密闭、潜在性腔隙，左右两个、互不相通。

    * 腔内没有气体，仅有少量浆液：一是润滑，减少呼吸运动中两层胸膜之间的摩擦；二是浆液分子的内聚力使两层胸膜贴附在一起、不容易分开。

    * 密闭的胸膜腔把肺和胸廓两个弹性结构偶联在一起，使不能主动扩大缩小的肺能随胸廓容积变化而扩大缩小。

* **肺的两个容积参照**

    * 将肺取出或打开胸腔，肺会因自身弹性回缩力塌陷至自然容积（气体容积约 500 ml）；正常即使用力呼气末，肺内仍余 1000~1500 ml 气体（余气量），远大于自然容积——肺在胸廓内始终维持一定程度的扩张状态。

### 胸膜腔内压的形成

* **测定与数值**

    * 胸膜腔内压（胸内压）可用连接检压计的注射针头刺入胸膜腔直接测定，也可用测定食管内压间接反映。

    * 平静呼吸全程低于大气压（负压）并周期性波动：平静吸气末 -10~-5 mmHg，呼气末 -5~-3 mmHg——故称胸膜腔负压。

* **形成的力学基础**

    * 生长发育中胸廓的发育速度比肺快，胸廓的自然容积大于肺的自然容积；两层胸膜又将两者紧贴在一起，肺因此总处于被动扩张状态。

    * 被动扩张的肺产生指向内的弹性回缩力；肺回缩的内向牵引又使胸廓容积小于其自然容积，胸廓于是形成向外的弹性回位力——两个方向相反的力共同作用，使胸膜腔容积趋于扩大，形成负压。

    * 两力平衡时：胸膜腔内压 ＝ 肺内压 − 肺回缩压；吸气末或呼气末气流停止、肺内压等于大气压，把大气压计为零，胸膜腔内压就等于负的肺回缩压。

    * 生理情况下即使呼气末肺也处于扩张状态、总有回缩倾向，所以平静呼吸全程胸内压保持负值：吸气时肺扩张程度增大、肺回缩压增高、负压增大；呼气时肺扩张程度降低、回缩压降低、负压减小。

    * > **易错点**：⚠️ 胸内压负值的大小由肺回缩压决定——肺扩张程度越大、回缩压越高、负值越大，所以吸气末（-10~-5 mmHg）比呼气末（-5~-3 mmHg）更负，方向别搞反。

### 胸膜腔负压的意义与气胸

* **生理意义**

    * 维持肺的扩张状态；并作用于胸腔内管壁薄、可扩张性大的腔静脉和胸导管，促进静脉血和淋巴液的回流。

* **气胸**

    * 胸膜破裂、胸膜腔与大气相通 → 空气进入胸膜腔 → 脏壁两层分开、负压消失（等于大气压）→ 促进肺扩张的力量消失，肺因自身弹性回缩力塌陷，不能再随胸廓运动扩大缩小。

    * 患侧胸内压大于健侧 → 纵隔移向健侧；严重时吸气、呼气两侧胸膜腔压力不平衡 → 纵隔摆动（吸气时移向健侧、呼气时移向患侧）。

    * 气胸不仅影响肺通气，还因胸内负压消失使血液和淋巴液回流减少；不及时治疗可因呼吸功能障碍导致循环功能衰竭，甚至危及生命。

* **胸内压变正的情况**

    * 咳嗽或吹小号时声门紧闭、用力呼气：呼气肌收缩使胸廓容积缩小、压迫肺，肺内压急剧升高并大于肺回缩压 → 胸膜腔内压明显升高、变为正值，甚至可达 +110 mmHg。

## 肺通气的阻力

### 肺通气阻力的构成

* **弹性阻力**

    * 包括肺的弹性阻力和胸廓的弹性阻力，约占总通气阻力的 70%，是平静呼吸时的主要阻力。

* **非弹性阻力**

    * 包括气道阻力、惯性阻力和组织的粘滞阻力，约占 30%，其中以气道阻力为主。

    * 与弹性阻力不同，非弹性阻力在气体流动过程中产生，并随气流速度的变化而变化。

### 弹性阻力与顺应性

* **弹性阻力**

    * > **定义**：物体在外力作用下发生变形时所产生的对抗变形的力。

    * 肺扩张变形产生的弹性回缩力既对抗跨肺压所引起的肺扩张、是吸气的阻力，又促进肺回缩、是呼气的动力。

    * > **易错点**：弹性阻力并不天然是"坏事"——它是吸气的阻力、限制肺的扩张，但同时也是呼气的动力；太大吸不进（肺纤维化、肺不张），太小呼不出（肺气肿），两头都出问题。

* **顺应性**

    * > **定义**：弹性组织在外力作用下发生变形的难易程度，用单位跨壁压变化所引起的容积变化量表示：$C = \frac{\Delta V}{\Delta P}$。

    * 顺应性与弹性阻力成反比：顺应性越大越容易变形，弹性阻力越小。

* **比顺应性**

    * 单位肺容积下的肺顺应性。正常成年人和新生儿测得的肺顺应性不同只是因为肺容积不同；比顺应性排除了肺容积的影响，可用于比较不同个体之间的肺弹性阻力——成年人和新生儿的比顺应性相同。

### 肺弹性阻力的来源

* **充空气与充盐水的对比**

    * 向肺内充空气所需压力约为充生理盐水的三倍：充空气时肺泡内衬液与肺泡气之间存在液气交界面，产生指向肺泡中央、使肺泡倾向缩小的表面张力；充盐水消除液气交界面，只剩肺组织本身的弹性回缩力。

* **构成比例**

    * 肺的弹性阻力约 1/3 来源于肺组织本身的弹性回缩力，约 2/3 来源于肺泡表面液体层与肺泡气之间液气界面产生的表面张力。

* **顺应性曲线的两个细节**

    * 肺充气过程的顺应性呈 S 形曲线：肺容积较小或较大处曲线平坦、斜率小，顺应性低、不易被扩张；中等容积处斜率大，顺应性大、易被扩张——正常成年人平静呼吸恰处于曲线中段，呼吸比较省力。

    * 充气与放气过程的顺应性曲线彼此分离，称滞后现象；充、抽生理盐水时曲线相互重叠、无滞后——说明滞后现象与充气放气过程中肺泡表面张力的动态变化有关。

### 肺泡表面张力与 Laplace 定律

* **Laplace 定律**

    * $P = \frac{2T}{r}$（$T$ 为表面张力，$r$ 为肺泡半径）——半径越小，回缩压越大。

    * 大小两个肺泡表面张力相同时，小肺泡内压力大于大肺泡 → 气体从小肺泡流向大肺泡 → 小肺泡萎缩塌陷、大肺泡膨胀甚至破裂——肺泡失去稳定性，总面积大大减小，影响肺泡与血液之间的气体交换。

* **表面张力的三重麻烦**

    * 使大小肺泡的容积不能维持稳定，甚至呼气时塌陷造成肺不张。

    * 限制肺泡扩张，使吸气阻力增大、吸气做功增加。

    * 表面张力指向肺泡腔中央，对肺间质产生抽吸作用 → 肺泡间质静水压降低、组织液生成增多 → 可能导致肺水肿。

    * 这些表现合在一起就是呼吸窘迫综合征；正常人不会出现，因为肺泡里存在调节表面张力的关键因素——肺泡表面活性物质。

### 肺泡表面活性物质

* **本质与结构**

    * > **定义**：由肺泡Ⅱ型上皮细胞合成并释放、分布在肺泡液气界面上的复杂脂蛋白复合物。

    * 成分：脂质约占 90%，最主要的是二棕榈酰卵磷脂（DPPC）；蛋白质约占 10%。

    * DPPC 一端是非极性的疏水脂肪酸尾（不溶于水），另一端是极性亲水的头（易溶于水）→ 分子垂直排列于液气界面：极性端插入液体层、非极性端朝向肺泡腔，形成单分子层；其密度随肺泡的张缩而改变。

    * 原理：减弱肺泡液体分子之间的相互作用力，从而降低肺泡表面张力、减小肺泡回缩力。

* **三大生理意义**

    * 降低肺的弹性阻力、增加肺的顺应性、减少吸气做功。

    * 维持大小肺泡容积稳定：大肺泡或吸气时分子密度减小、降低表面张力的作用减弱、表面张力变大，防止肺泡过度膨胀；小肺泡或呼气时密度增大、降低作用很强、表面张力小，防止萎缩塌陷和肺不张——用密度变化实时解开 Laplace 定律"半径越小压力越大"的死结。

    * 保持肺内干燥：降低表面张力即减弱对肺泡间质的抽吸作用，防止肺水肿。

* **新生儿呼吸窘迫综合征**

    * 时间线：妊娠 22~24 周肺泡Ⅱ型上皮细胞开始合成表面活性物质，25~30 周肺泡腔内才开始出现，之后分泌量渐增、分娩时达高峰——早产儿容易缺乏。

    * 缺乏时不能降低肺泡表面张力：大小肺泡容积不能维持稳定、呼气时塌陷导致肺不张；吸气阻力增大、吸气做功增加，出现吸气性呼吸困难。

    * 胸内负压极度增大 → 胸骨上窝、锁骨上窝和肋间隙出现明显凹陷，即"三凹征"；同时肺组织液生成增多导致肺水肿，最终可致新生儿死亡。

### 吸气困难与呼气困难

* **弹性阻力异常的两种方向**

    | 情形 | 弹性阻力 | 顺应性 | 结果 |
    | :--- | :--- | :--- | :--- |
    | 肺充血、肺不张、肺纤维化、肺部感染、肺表面活性物质减少 | 增加 | 降低 | 吸气困难 |
    | 肺气肿（肺弹性纤维破坏、肺回缩力减小） | 减小 | 增大，但肺不易回缩 | 呼气困难 |

    * 两类情况都会降低肺的通气功能。

## 气道阻力

### 气道阻力的概念与分布

* **气道阻力**

    * > **定义**：气体流经呼吸道时，气体分子之间以及气体分子与气道壁之间的摩擦所形成的阻力；占非弹性阻力的 80%~90%，是其主要成分。

    * 不能直接测量，按流体力学用推动气体流动的压力差与单位时间内呼吸道内气体流量之比表示：$R = \Delta P / Q$。

* **阻力分布**

    | 部位 | 占气道阻力 | 说明 |
    | :--- | ---: | :--- |
    | 鼻腔 | 50% | 上呼吸道（鼻、口、咽等）结构迂回复杂，总横截面积小，阻力大 |
    | 声门 | 25% | 同属上呼吸道 |
    | 气管和支气管 | 15% |  |
    | 管径小于 2mm 的细支气管 | 仅 10% | 总横截面积大、气流速度慢，且为层流 |

    * 张口呼吸或气道插管可明显降低气道阻力——绕开了占一半阻力的鼻腔。

    * 小气道（直径小于 2mm）病变时，除非病变非常严重而广泛，测定气道总阻力通常难以及时发现异常——它们在总阻力里本来就只占 10%。

### 影响气道阻力的因素

* **流速**

    * 流速大阻力大，流速慢阻力小。

* **气流形式**

    * 层流阻力小、湍流阻力大；从气管到肺泡湍流与层流交替出现：气管和支气管分叉处，或气道某部位有粘液渗出物、肿瘤、异物时往往出现湍流，呼吸性支气管则主要是层流。

* **气道半径**

    * 流体阻力与管道半径的四次方成反比（$R \propto 1/r^4$）——气道半径是影响气道阻力最重要的因素，气道环境改变可使阻力明显增高或减小。

### 气道口径的调节

* **呼吸周期中的口径变化**

    * 吸气时：胸内压降低 → 呼吸道跨壁压增大 → 管径被动扩大；肺容积增大 → 肺实质对气道壁的外向放射状牵引增强 → 无软骨支撑的细支气管管径增大；吸气时交感神经紧张性增高 → 气道平滑肌舒张。合计气道半径增大、阻力减小。

    * 呼气时相反：气道半径变小、阻力增大。

* **神经调节**

    * 交感神经：末梢释放去甲肾上腺素，与气道平滑肌 β2 受体结合 → 舒张、管径变大、阻力降低。

    * 副交感（迷走）神经：末梢释放乙酰胆碱，作用于气道平滑肌 M 受体 → 收缩、管径变小、阻力增加。

    * 非肾上腺素能非胆碱能神经纤维：释放血管活性肠肽、速激肽等，分别引起气道平滑肌的舒张和收缩。

* **体液调节**

    * 儿茶酚胺类物质和前列腺素 E2 等引起气道平滑肌舒张，可用来解除气道痉挛。

    * 过敏反应时组胺、白三烯等大量释放 → 气道黏膜水肿＋气道平滑肌痉挛性收缩 → 气道狭窄、呼吸困难。

* **支气管哮喘：呼气型呼吸困难**

    * 哮喘患者气道平滑肌痉挛＋气道黏膜水肿使气道严重狭窄；而呼气时跨壁压减小、肺缩小、放射状牵引减弱，迷走紧张性增高还使支气管平滑肌收缩——呼气的气道阻力本来就大于吸气，哮喘时呼气阻力增加更显著，故表现为呼气性呼吸困难。

    * 治疗用 β2 受体激动剂舒张支气管平滑肌，可迅速缓解哮喘发作。

## 肺通气功能的评价

### 限制性与阻塞性通气不足

* **限制性通气不足**

    * 气胸等引起肺的扩张受限。

* **阻塞性通气不足**

    * 支气管平滑肌痉挛、气道内异物、气管和支气管黏膜腺体分泌过多、气道外肿瘤压迫等引起气道半径减小或呼吸道阻塞。

* **测定的价值**

    * 对肺通气功能的测定不仅能明确是否存在肺通气功能受损及其程度，还可以鉴别通气功能降低的类型。

### 肺容积

* **四项基本气量**

    | 指标 | 定义 | 正常值 | 意义 |
    | :--- | :--- | :--- | :--- |
    | 潮气量 | 每次呼吸时吸入或呼出的气量 | 400~600ml，平均 500ml | 运动时增大，最大可接近肺活量 |
    | 补吸气量 | 平静吸气末再尽力吸气所能吸入的气量 | 1500~2000ml | 反映吸气的储备量 |
    | 补呼气量 | 平静呼气末再尽力呼气所能呼出的气量 | 900~1200ml | 反映呼气的储备量 |
    | 余气量 | 最大呼气末仍存留于肺内不能呼出的气量 | 1000~1500ml | 避免肺泡在低容积条件下发生坍塌 |

* **余气量**

    * 远大于肺 500ml 的自然容积——最大呼气末肺仍处于一定程度的扩张状态；支气管哮喘和肺气肿患者的余气量增加。

### 肺容量

* **组合指标**

    * 肺容量是两项或两项以上基本肺容积之和。

    | 指标 | 组成 | 正常值 | 意义 |
    | :--- | :--- | :--- | :--- |
    | 深吸气量 | 潮气量＋补吸气量 | — | 平静呼气末用力吸气所能吸入的最大气量；衡量最大通气潜力的重要指标，胸廓、胸膜腔病变可使其减少、降低最大通气功能 |
    | 功能余气量 | 补呼气量＋余气量 | 约 2300ml，占肺总量的 40% 左右 | 缓冲呼吸过程中肺泡气氧和二氧化碳分压的变化幅度；肺气肿患者弹性回缩力减低，功能余气量增加 |
    | 肺活量 | 潮气量＋补吸气量＋补呼气量 | 男约 3500ml，女约 2500ml | 最大吸气后所能呼出的最大气量；可反映肺组织或呼吸器官病理变化、呼吸肌力量强弱 |
    | 肺总量 | 肺活量＋余气量 | 男约 5000ml，女约 3500ml | 肺所能容纳的最大气体量 |

### 用力肺活量与用力呼气量

* **肺活量的局限**

    * 测定肺活量时不限定呼气时间：肺组织弹性功能降低或呼吸道狭窄的患者可通过延长呼气时间使肺活量"正常"——肺活量难以充分反映肺组织的弹性状态和气道通畅程度。

* **用力肺活量（FVC）**

    * > **定义**：一次最大吸气后，尽力尽快呼气所能呼出的最大气体量。

    * 正常时略小于不限时间测得的肺活量；气道阻力增高时用力肺活量可明显低于肺活量。

* **用力呼气量（FEV，时间肺活量）**

    * > **定义**：一次最大吸气后再尽力尽快呼气，一定时间内所能呼出的气体量；第一、二、三秒末呼出的气量分别称一、二、三秒用力呼气量。

    * 通常以占用力肺活量的百分数表示，以排除肺容积差异的影响：正常人第一、二、三秒末分别呼出用力肺活量的 83%、96%、99%。

* **两类肺疾病的鉴别**

    | 疾病类型 | 一秒用力呼气量 | 用力肺活量 | 两者比值 |
    | :--- | :--- | :--- | :--- |
    | 阻塞性肺疾病（如气道狭窄） | 下降，且比用力肺活量降低得更明显 | 降低 | 降低 |
    | 限制性肺疾病（如肺纤维化） | 下降 | 下降 | 可正常，甚至超过 83% |

### 肺通气量

* **每分通气量**

    * > **定义**：每分钟吸入或呼出的气体总量，等于潮气量与呼吸频率的乘积。

    * 正常成年人每分钟 6~9L，体力劳动或运动时增加。

* **最大随意通气量（最大通气量）**

    * 尽力做深而快呼吸时每分钟所能吸入或呼出的最大气体量；通常只测 10 秒或 15 秒的最深最快呼出或吸入气量，再换算成每分钟值。

    * 一般可达每分钟 150L，约为平静肺通气量的 25 倍，反映单位时间内充分发挥全部通气能力所能达到的通气量。

    * 任何降低肺或胸廓顺应性、降低呼吸肌收缩力量和速度、增大气道阻力的因素，都可使其减小。

* **通气储量百分比**

    * 比较平静呼吸时的每分通气量与最大通气量，了解通气功能的储备能力；正常值等于或大于 93%。

### 无效腔与肺泡通气量

* **解剖无效腔**

    * > **定义**：每次吸入的气体中留在鼻与终末细支气管之间的呼吸道内、不参与肺泡与血液之间气体交换的那部分呼吸道的容积；正常成年人约 150ml。

    * 吸入 500ml 潮气量时：350ml 新鲜空气进入肺泡参与交换，150ml 留在解剖无效腔，并把上次呼气末残留在无效腔里的 150ml 高 CO₂、低 O₂ 的气体推入肺泡——解剖无效腔的存在影响肺泡内气体的更新率。

    ```text
    一次潮气量 500ml 的去向
     ├─ 350ml 新鲜空气 ──→ 进入肺泡，参与气体交换
     └─ 150ml 新鲜空气 ──→ 留在解剖无效腔，不参与交换
         （同时把上次呼气末残留在无效腔里的 150ml
           高 CO2、低 O2 的肺泡气推入肺泡）
    ```

* **肺泡无效腔与生理无效腔**

    * 进入肺泡的新鲜气体不一定都参与交换：肺泡有通气但血液灌注不足时，进入肺泡后未与血液进行气体交换的新鲜气体量为肺泡无效腔。

    * 解剖无效腔与肺泡无效腔合称生理无效腔；健康人平卧时肺泡无效腔很小，生理无效腔等于或接近解剖无效腔。

* **肺泡通气量**

    * > **定义**：每次吸气时减去无效腔气量后的有效通气量；肺泡通气量＝（潮气量−无效腔气量）×呼吸频率，约为肺通气量的 70%。

    * 因约 2500ml 功能余气量的存在，每次呼吸的有效通气量为 350ml，肺泡内气体的更新率约为 14%（350/2500）；潮气量减少、无效腔增大或功能余气量增加，都使更新率降低、不利于肺换气。

    * 潮气量与呼吸频率对两种通气量的影响不同：呼吸频率加倍而肺通气量不变（潮气量减半）时，肺泡通气量会发生明显变化——浅快呼吸对肺换气不利；深慢呼吸可增大肺泡通气量但同时增加呼吸做功；适当深度和频率的平静呼吸耗能少、肺泡通气量较大。

### 呼吸功

* **呼吸功**

    * > **定义**：呼吸过程中实现肺通气所做的功。

    * 正常人平静呼吸的呼吸功主要用于吸气动作：65% 用于克服弹性阻力，28% 用于克服气道阻力，7% 用于克服粘滞阻力。

    * 机体会"自选省功方案"：肺顺应性降低、弹性阻力增高时表现为浅而快的呼吸，减少克服弹性阻力所做的功；气道阻力增加时表现为深而慢的呼吸，减小克服气道阻力所做的功。

## 肺换气

### 气体分压与扩散动力

* **气体分压**

    * > **定义**：混合气体中每一种组成气体所产生的压力，等于混合气体总压力乘以该气体所占的容积百分比。

    * 大气中氧分压为 159 mmHg、二氧化碳分压为 0.3 mmHg；分压大小反映该气体在混合气体中的浓度。

* **分压差是扩散的动力**

    * 两个部位之间存在分压差时，气体从分压高的一侧向分压低的一侧扩散——即从浓度高处向浓度低处扩散。

* **体内各部位的气体分压**

    | 部位 | 氧分压（mmHg） | 二氧化碳分压（mmHg） |
    | :--- | ---: | ---: |
    | 大气 | 159 | 0.3 |
    | 肺泡气 | 102 | 40 |
    | 静脉血（入肺毛细血管） | 40 | 46 |
    | 动脉血（出肺毛细血管） | 100 | 40 |
    | 组织 | 30 | 50 |

### 肺换气与组织换气

* **肺换气**

    * > **定义**：肺泡与肺毛细血管之间的气体交换过程；肺毛细血管缠绕在肺泡壁表面，交换就发生在这个紧贴的界面上。

    * 肺泡氧分压 102 mmHg 高于静脉血的 40 mmHg → O₂ 从肺泡进入肺毛细血管；毛细血管内二氧化碳分压 46 mmHg 高于肺泡的 40 mmHg → CO₂ 从毛细血管进入肺泡——静脉血变成含氧多、含二氧化碳少的动脉血。

* **组织换气**

    * 组织毛细血管内氧分压 100 mmHg 高于组织的 30 mmHg → O₂ 从毛细血管进入组织；组织内二氧化碳分压 50 mmHg 高于毛细血管的 40 mmHg → CO₂ 从组织进入毛细血管——动脉血又变回静脉血。

    * 组织换气过程与肺换气正好相反。

### 影响肺换气的理化因素

* **四条物理规律**

    * 扩散速度与气体的分压差成正比——分压差越大扩散越快。

    * 扩散速率与气体分子量的平方根成反比——分子量越大扩散越慢。

    * 扩散速率与气体的溶解度成正比。

    * 温度高扩散快——但生理情况下体温恒定，温度不是影响肺换气的主要因素。

* **扩散系数**

    * > **定义**：气体的溶解度与其分子量平方根之比值；扩散系数越大，扩散速率越快。

    * 用它平衡"氧分子量小"与"二氧化碳溶解度大"两个方向：二氧化碳扩散系数为 7.76，氧只有 0.38——二氧化碳的扩散速度约为氧的 20 倍。

### 呼吸膜

* **六层结构**

    * > **定义**：肺换气时气体必须穿越的结构，从肺泡侧向肺毛细血管依次为：含肺表面活性物质的液体层、肺泡上皮细胞层、肺泡上皮下的基膜、肺泡上皮与肺毛细血管基膜之间的间隙（间质）、肺毛细血管基膜、肺毛细血管内皮细胞层。

    * 呼吸膜非常薄，最薄处仅 0.2μm，气体很容易通过。

    * 任何使呼吸膜变厚的因素都扩大扩散距离、减少扩散：肺纤维化（间质胶原含量增多）、肺水肿（间质水含量增多）→ 肺换气降低。

* **呼吸膜的面积**

    * 正常人约 3 亿个肺泡，呼吸膜总面积约 70m²；安静时只需约 40m² 即可完成正常生理所需的气体交换——机体有巨大的呼吸膜储备。

    * 运动时肺毛细血管开放数量增多、开放程度增大，参与气体交换的面积大大增加。

    * 肺不张、肺实变（肺泡被大量炎性渗出物充满）、肺气肿（肺泡隔大量破坏、肺泡数量减少——肺泡虽大、面积反而减少）、肺叶切除、大量肺毛细血管关闭闭塞 → 扩散面积降低、肺换气减少。

    * 呼吸膜总面积小于健康人的 1/3~1/4 时，气体交换速度甚至不能满足静息状态下机体的需求。

### 通气血流比值

* **通气血流比值**

    * > **定义**：每分钟肺泡通气量与每分钟肺血流量之比值；正常人安静时为 0.84。

    * 适宜的肺泡通气量与适宜的肺血流量相互匹配，是气体交换的重要因素。

* **比值增大**

    * 如肺血管栓塞时流经肺泡的血流减少：进入该肺泡的气体不能有效地与血液交换，该肺泡实际上成为无效腔——肺泡无效腔增大。

* **比值降低**

    * 如支气管痉挛时进入肺泡的气体减少：流经通气不良肺泡的血液不能充分气体交换，部分静脉血未变成动脉血就掺入动脉血——好像发生了功能性的动静脉短路（静脉血掺杂）。

* **偏离的后果与局部调节**

    * 比值增大或降低都导致肺内气体交换障碍 → 机体缺氧和二氧化碳排除障碍（二氧化碳潴留）。

    * 局部调节：支气管痉挛处肺泡得不到气体更新、局部氧分压下降 → 该处肺血管收缩、血流量降低 → 通气血流比值恢复匹配——有助于维持局部比值稳定，避免动静脉短路和静脉血掺杂。

    * > **提示**：肺泡局部缺氧引起的是肺血管收缩（"少给血"来恢复匹配）；若低氧是全肺性的（如全肺通气不足，或高原环境大气氧分压偏低），将导致整个肺动脉广泛收缩、肺动脉压力增高，称为低氧性肺动脉高压。

### 肺扩散容量

* **肺扩散容量**

    * > **定义**：单位分压差下每分钟通过呼吸膜扩散的气体量；扩散容量降低表示肺换气功能障碍。

    * 正常成年人安静时氧的肺扩散容量约 20 ml/(min·mmHg)，二氧化碳约 400 ml/(min·mmHg)——是氧的 20 倍，二氧化碳比氧更容易通过呼吸膜。

    * 因此肺换气功能受损时，机体首先表现为缺氧；只有当换气功能进一步明显受损时，才出现二氧化碳排除障碍、二氧化碳潴留。

## 氧的运输

### 氧在血液中的存在形式

* **两种存在方式**

    * 物理溶解的氧只占总氧量的 1.5%，化学结合的约占 98.5%——真正运氧的是氧与血红蛋白结合形成的氧合血红蛋白，血红蛋白是运氧的载体。

* **三个必须分清的量**

    | 术语 | 含义 | 正常值 |
    | :--- | :--- | :--- |
    | 血红蛋白氧容量 | 每 100ml 血液中血红蛋白所能结合的最大氧量 | 20.1 ml |
    | 血红蛋白氧含量 | 实际结合的氧量 | 约 19.4 ml |
    | 血红蛋白氧饱和度 | 氧含量占氧容量的百分比 | 约 96.5% |

    * 计算依据：一分子血红蛋白可结合四分子氧，一克血红蛋白可结合 1.34 ml 氧；按每 100ml 血液含血红蛋白 15g 计，氧容量＝15×1.34＝20.1 ml；氧含量约 19.4 ml，19.4÷20.1≈96.5% 即正常人血红蛋白氧饱和度。

* **发绀**

    * 氧合血红蛋白呈鲜红色、脱氧血红蛋白呈暗紫色——富含氧合血红蛋白的动脉血鲜红、含较多脱氧血红蛋白的静脉血暗紫。

    * 血液中脱氧血红蛋白含量达到 5g/100ml 以上时，皮肤黏膜呈暗紫色，称为发绀——机体缺氧的标志之一。

### 氧解离曲线

* **氧与血红蛋白结合的特点**

    * 快速、可逆，不需要酶催化；反应方向取决于氧分压高低：肺内氧分压高 → 结合形成氧合血红蛋白；组织内氧分压低 → 迅速解离释放氧、成为脱氧血红蛋白。

* **氧解离曲线的三段**

    * > **定义**：以血液氧分压为横坐标、血红蛋白氧饱和度为纵坐标绘出的曲线呈特殊 S 形，按变化特点和功能意义分上、中、下三段。

    | 分段 | 氧分压范围 | 曲线形态 | 功能意义 |
    | :--- | :--- | :--- | :--- |
    | 上段 | 60~100 mmHg | 平坦（饱和度 90%~97.4%） | 反映肺内结合；在高原或某些呼吸系统疾病时，只要动脉血氧分压不低于 60 mmHg，饱和度仍维持在 90% 以上，血液还能携带足够量的氧，不出现明显低氧血症 |
    | 中段 | 40~60 mmHg | 较陡 | 反映安静状态下的供氧：氧饱和度从动脉血约 97% 降至静脉血的 75%，氧含量从 19.4 降到 14.4 ml/100ml，每 100ml 血液释放 5ml 氧，氧的利用系数为 25% |
    | 下段 | 15~40 mmHg | 特别陡 | 供氧储备：氧分压从 40 降到 15 mmHg 时氧含量再从 14.4 降到 4.4 ml/100ml，每 100ml 血液多释放 10ml 氧；组织活动加强（如运动，组织氧分压可降到 15 mmHg）时氧利用系数从 25% 增至 75%（每 100ml 血供氧 15ml） |

### 氧解离曲线的偏移

* **P50**

    * > **定义**：血红蛋白氧饱和度为 50% 时血液的氧分压，正常约 26.5 mmHg——衡量血红蛋白与氧亲和力的标尺。

    * P50 增大 → 需更高氧分压才能达到 50% 饱和 → 亲和力下降、曲线右移；P50 降低 → 较低氧分压即可达到 50% 饱和 → 亲和力增加、曲线左移。

* **影响亲和力的因素**

    * 血液二氧化碳分压增加、氢离子增加（pH 下降）、红细胞内 2,3-DPG 增多、温度升高 → 血红蛋白对氧的亲和力下降、曲线右移——右移有利于血红蛋白在组织中释放更多的氧。

    * > **定义**：波尔效应——二氧化碳和氢离子浓度的改变对血红蛋白氧亲和力的影响。

    * 血液流经肺：二氧化碳不断排入肺泡 → 血中二氧化碳分压与氢离子浓度下降 → 亲和力增加 → 促进氧与血红蛋白结合、血氧含量增加。

    * 血液流经组织：代谢产生的二氧化碳入血 → 二氧化碳和氢离子浓度增加 → 亲和力降低 → 促进氧合血红蛋白解离、为组织提供更多的氧。

### 运动时的供氧途径

* **四条途径一起发力**

    * 运动肌肉局部耗氧增加、局部氧分压进一步降低 → 氧合血红蛋白进一步解离——动用氧解离曲线下段对组织供氧的储备能力。

    * 局部代谢产物增多、产热增加 → 局部二氧化碳分压、氢离子浓度、温度升高 → 血红蛋白对氧的亲和力下降、氧离曲线右移 → 释放更多的氧。

    * 局部代谢产物增多舒张局部血管 → 局部血流量增加，带来更多血流量和氧供应。

    * 肺这一侧：运动时肺通气增强、肺毛细血管大量开放 → 呼吸膜面积大大增加 → 促进血红蛋白在肺毛细血管内与氧的结合。

### 一氧化碳中毒

* **第一重打击：抢占结合位点**

    * 一氧化碳与血红蛋白的亲和力约为氧与血红蛋白亲和力的 250 倍——少量一氧化碳即可取代氧与血红蛋白结合，使血红蛋白氧容量降低、氧饱和度下降、氧含量明显减少。

    * 阈值极低：肺泡气中一氧化碳浓度仅 0.05%（一氧化碳分压约 0.4 mmHg）就足以使血红蛋白氧饱和度下降一半。

* **第二重打击：妨碍解离**

    * 一氧化碳与血红蛋白结合后使血红蛋白对氧的亲和力增大、氧离曲线左移、减少氧的解离——既妨碍氧与血红蛋白的结合，又妨碍氧合血红蛋白对氧的解离，进一步导致机体缺氧，严重时致死。

* **急救**

    * 现场首先通风，想办法兴奋呼吸、促进一氧化碳排出；到医院给病人吸纯氧甚至进高压氧舱——用高浓度氧把结合在血红蛋白上的一氧化碳置换出来，既提高血氧含量又促进一氧化碳排除。

### 血红蛋白的质和量

* **贫血**

    * 血红蛋白总量减少 → 氧容量降低、氧含量下降，但氧饱和度正常——饱和度是"含量÷容量"的百分比，剩下的血红蛋白该结合多少还是结合多少。

* **高铁血红蛋白血症**

    * 血红蛋白分子中的亚铁被氧化成三价铁、失去对氧的携带能力 → 氧容量、氧含量、氧饱和度都下降。

## 二氧化碳的运输

### 二氧化碳的存在形式

* **三种形式的分工**

    * 物理溶解占运输总量的 5%，化学结合约占 95%；化学结合分碳酸氢盐和氨基甲酰血红蛋白两种形式。

    | 存在形式 | 占运输总量 | 特点 |
    | :--- | :--- | :--- |
    | 物理溶解 | 5% | 直接溶解在血液中 |
    | 碳酸氢盐 | 88% | 绝对主力；装货与卸货都要靠红细胞内的碳酸酐酶 |
    | 氨基甲酰血红蛋白 | 7% | 不需要酶、速度快；从肺排出的二氧化碳中它贡献的份额远超 7% |

### 碳酸氢盐路线

* **组织端：生成碳酸氢盐**

    * 二氧化碳与水结合生成碳酸、碳酸再解离为碳酸氢根和氢离子；反应可逆、方向取决于二氧化碳分压（组织端分压高、向生成方向进行），而二氧化碳与水生成碳酸的过程比较缓慢，需碳酸酐酶催化才能迅速完成。

    * 单纯的血浆难以有效地完成二氧化碳运输；红细胞里含丰富的碳酸酐酶，扩散进入红细胞的二氧化碳可迅速生成碳酸并解离。

* **氯转移**

    * 红细胞内生成的碳酸氢根要流出进入血浆：一是避免细胞内碳酸氢根浓度过高、使反应可持续进行；二是碳酸氢根带负电、外流会引起跨膜电位变化，氯离子经氯-碳酸氢根转运体进入红细胞平衡电荷——此过程称氯转移。

* **肺端：反向释放**

    * 肺毛细血管中二氧化碳大量排向肺泡 → 血浆二氧化碳减少 → 所有反应向反方向进行：血浆中碳酸氢根回到红细胞内与氢离子结合生成碳酸、再分解为二氧化碳和水，二氧化碳源源不断排入肺泡、排出体外。

    ```text
    【组织端】代谢产生 CO2
       CO2 扩散入血浆、进入红细胞（含丰富碳酸酐酶）
          CO2 + H2O --碳酸酐酶--> H2CO3 --> HCO3- + H+
             |
             |-- HCO3- 流出红细胞（防止胞内浓度过高，使反应可持续）
             |     +-- Cl- 经氯-碳酸氢根转运体进入红细胞，平衡电荷【氯转移】
    【肺端】CO2 分压降低，反应反向进行
       血浆中 HCO3- 回到红细胞 + H+ --> H2CO3 --> CO2 + H2O
             +-- CO2 排入肺泡，排出体外
    ```

    * 路线要点：装货发生在红细胞内（只有那里有碳酸酐酶），押运在血浆里以碳酸氢盐形式完成，卸货又回到红细胞内收尾。

* **碳酸酐酶的关键性**

    * 用碳酸酐酶抑制剂（如乙酰唑胺）阻断该酶，二氧化碳的运输近乎停摆：组织中二氧化碳分压从正常的 46 mmHg 一直升到 80 mmHg。

### 氨基甲酰血红蛋白路线

* **氨基甲酰血红蛋白**

    * 在红细胞内二氧化碳直接与血红蛋白的氨基结合生成氨基甲酰血红蛋白；不需要酶催化、速度非常迅速、可逆，方向取决于二氧化碳分压（组织端分压高时结合、肺端分压低时分解释放二氧化碳）。

    * 以此形式运输的二氧化碳只占运输总量的 7%，但从肺排出的二氧化碳中由它释放的份额远不止 7%——卸货时的贡献比装货时的占比大得多；红细胞内的碳酸酐酶和血红蛋白在二氧化碳运输中都发挥重要作用。

### 二氧化碳解离曲线与荷尔登效应

* **二氧化碳解离曲线**

    * 以二氧化碳分压为横坐标、血液二氧化碳含量为纵坐标：随二氧化碳分压增加，血液二氧化碳含量呈线性增加——没有 S 形，与氧解离曲线很不一样。

    * 同样的二氧化碳分压下，静脉血的二氧化碳含量大于动脉血（静脉血曲线位于动脉血曲线之上）。

* **荷尔登效应**

    * > **定义**：氧与血红蛋白的结合促使二氧化碳释放，因为脱氧血红蛋白更容易与二氧化碳结合。

    * 解释静脉血"载货"更多：动脉血里氧与血红蛋白结合促使二氧化碳释放；静脉血里脱氧血红蛋白多，与二氧化碳结合更多。

    * 波尔效应与荷尔登效应首尾相接：组织中二氧化碳和氢离子多、促血红蛋白放氧；肺里氧合好、促血红蛋白放二氧化碳——把"肺装氧卸二氧化碳、组织卸氧装二氧化碳"两场方向相反的交换都变得更顺畅。

## 呼吸的化学调节

### 化学感受器

* **化学感受性反射**

    * > **定义**：氧、二氧化碳和氢离子等因素所引起的呼吸反射。

* **外周化学感受器**

    * 位于颈总动脉分叉处和主动脉弓，分别称颈动脉体和主动脉体。

    * 感受动脉血液中氧分压的下降、二氧化碳分压的升高和氢离子浓度的升高 → 反射性引起呼吸加深加快、肺通气量增加。

    * 比利时生理学家海曼斯于 1930 年首次证明颈动脉体和主动脉体在化学感受性呼吸调节中的作用，并因此获 1938 年诺贝尔生理学或医学奖。

* **中枢化学感受器**

    * 位于延髓腹外侧浅表部位，感受脑脊液中二氧化碳和氢离子浓度的增高。

    * 实质是氢离子感受器：人为用缓冲液控制脑脊液 pH 后再给二氧化碳，中枢化学感受器不再兴奋——二氧化碳对它的刺激是通过氢离子间接实现的。

* **两套感受器的比较**

    | 比较项 | 外周化学感受器 | 中枢化学感受器 |
    | :--- | :--- | :--- |
    | 位置 | 颈总动脉分叉处、主动脉弓 | 延髓腹外侧浅表部位 |
    | 感受的刺激 | 动脉血氧分压下降、二氧化碳分压升高、氢离子浓度升高 | 只感受氢离子的刺激，不直接感受二氧化碳或低氧 |
    | 对二氧化碳的敏感性 | 二氧化碳分压需升高 10 mmHg 才起反应 | 二氧化碳分压只需升高 2 mmHg 即起反应，敏感得多 |
    | 反应潜伏期 | 较短 | 较长 |

* **中枢潜伏期长的原因**

    * 二氧化碳须先与水结合生成碳酸、再解离出氢离子才能刺激中枢化学感受器，而脑脊液中缺乏碳酸酐酶、水合反应非常慢——对二氧化碳的反应有一定时间延迟。

### 二氧化碳对呼吸的调节

* **最重要的生理性化学因素**

    * 过度通气大量排除二氧化碳 → 动脉血二氧化碳分压过度降低 → 呼吸暂停；吸入气中二氧化碳增加 → 肺泡气二氧化碳分压增大、呼吸增强增快、每分通气量显著增加；吸入气二氧化碳超过 10% → 反而抑制呼吸，出现二氧化碳麻醉。

    * 二氧化碳对呼吸的影响因浓度不同而存在促进和抑制双重效应。

* **两条兴奋途径与主次**

    * 途径一：血液中二氧化碳经血脑屏障进入脑脊液，与水结合生成碳酸、解离出氢离子，刺激中枢化学感受器 → 呼吸加深加快。

    * 途径二：血液中二氧化碳直接刺激外周化学感受器 → 反射性引起呼吸加深加快、肺通气量增加。

    * 主次判定：切除外周化学感受器的传入神经后，吸入 5% 二氧化碳引起的肺通气增强反应仅降低 20%——中枢化学感受器在二氧化碳引起的通气增强中起主要作用。

### 氢离子对呼吸的调节

* **效应**

    * 血液中氢离子浓度增加（如给动物注射乳酸）→ 呼吸加深加快、肺通气量增加；氢离子浓度降低 → 呼吸运动受抑制、肺通气量下降。

* **通路**

    * 氢离子不易通过血脑屏障去刺激中枢化学感受器，主要通过外周化学感受器起作用。

### 低氧对呼吸的调节

* **阈值与地位**

    * 动脉血氧分压低于 80 mmHg 时肺通气量才会增加、低于 60 mmHg 以后才显著增加——动脉血氧分压的改变对呼吸运动的调节作用平时不大，只在机体严重缺氧时才参与调节、扮演重要角色。

* **通路唯一**

    * 人为切断外周化学感受器后，急性低氧对呼吸运动的刺激作用完全消失——低氧只通过刺激外周化学感受器来兴奋呼吸中枢。

    * > **注意**：严重缺氧时，外周化学感受器的兴奋作用不足以对抗低氧对呼吸中枢的直接抑制，反而导致呼吸运动减弱。

### 慢性二氧化碳潴留时的给氧

* **驱动呼吸的主导刺激发生了切换**

    * 严重肺气肿、肺心病患者因肺换气功能障碍导致慢性缺氧和长时间二氧化碳潴留：长时间二氧化碳潴留使中枢化学感受器对二氧化碳的刺激产生适应，而外周化学感受器对低氧刺激的适应比较慢——低氧对外周化学感受器的刺激成为驱动呼吸运动的最主要因素。

* **为什么不能吸纯氧**

    * 给这类病人吸纯氧 → 解除低氧刺激 → 呼吸抑制 → 肺通气量显著降低、血中二氧化碳浓度急剧增加，二氧化碳更排不出去。

    * > **提示**：临床上对这类病人只能持续低浓度给氧——既适当纠正缺氧，又避免取消低氧对呼吸的刺激作用。

### 三因素的整体比较

* **化学因素的通路全景**

    ```text
    CO2 ----+--> 中枢化学感受器（主通路：CO2 入脑脊液生成 H+ 起效）
            +--> 外周化学感受器（次要）
    H+  --------> 外周化学感受器（主通路：H+ 不易透过血脑屏障）
    低氧 -------> 外周化学感受器（唯一通路）
    ```

* **单因素实验与整体实验**

    * 单因素控制（只改一个因素、其余不变）：随二氧化碳分压增加、氧分压下降或 pH 降低，肺通气量都增加，且三者增加的程度差不多。

    * 整体情况下（其他因素不控制）：吸入二氧化碳引起的呼吸反应最强——二氧化碳分压增加的同时体内氢离子浓度相应增加，两因素叠加，兴奋作用比单一二氧化碳分压增加大得多；低氧的刺激最弱——呼吸增强排出较多二氧化碳，血中二氧化碳和氢离子浓度下降反而削弱了低氧的兴奋作用；氢离子的变化介于两者之间。

    * 单因素实验说明每个因素"单独能干什么"，整体实验说明它们"合起来实际干了什么"——整体情况下某一种因素改变时，其他因素常发生继发性改变。

### 肺对酸碱平衡的调节

* **亨德森-哈塞尔巴赫公式**

    * $pH = pK + \log\frac{[\mathrm{HCO_3^-}]}{[\mathrm{H_2CO_3}]}$——缓冲液的 pH 取决于缓冲对的 pK 值及缓冲对中弱酸与相应碱的浓度比。

    * 血浆中主要缓冲对为碳酸氢根/碳酸，血浆 pH 取决于两者的浓度比；碳酸浓度与二氧化碳溶解量成正比，而二氧化碳溶解量＝溶解度×动脉血二氧化碳分压（$P_{a\mathrm{CO_2}}$）→ 血浆 pH 取决于碳酸氢根与动脉血二氧化碳分压的比值。

* **两条结论**

    * 任何引起动脉血二氧化碳分压增高的因素 → pH 下降 → 酸中毒；任何引起动脉血二氧化碳分压降低的因素 → pH 增大 → 碱中毒。

    * 肺通过改变二氧化碳的排出量来改变动脉血二氧化碳分压，从而参与机体酸碱平衡的调节。
