# 心脏泵血与心肌电生理

## 心脏泵血功能的评价指标

   * **每搏输出量**

       * > **定义**：一侧心室一次收缩所射出的血量，又称搏出量。

       * 计算式：每搏输出量 = 收缩前的心室容积 − 收缩后的心室容积；收缩前的最后一瞬间（舒张刚开始那一瞬）的心室容积相当于心室舒张末期容积。

       * 数值：心室舒张末期容积 125 ml，收缩末期容积 55 ml，每搏输出量 = 125 − 55 = 70 ml。

   * **心输出量**

       * > **定义**：一侧心室每分钟收缩射出的血量，即每分输出量，简称心输出量。

       * 计算式：心输出量 = 每搏输出量 × 心率。

       * 数值：健康成年男性静息状态心率 75 次/分、每搏量约 70 ml，心输出量为 5250 ml，一般以 5000 ml（每分钟 5 L）计算。

       * 规律：心输出量一般男性高于女性、年轻人高于老年人，运动时增加。

       * 心输出量是衡量心脏泵血功能的基本指标。

   * **心指数**

       * > **定义**：每平方米体表面积的心输出量，即用心输出量除以体表面积。

       * 依据：心输出量与能量代谢率一样，与体重不成正比，却与体表面积成正比；心功能好坏的关键是能否满足自身代谢的需要。身材矮小的人心输出量可能只有 4 L/min，身材高大的人可达 7 L/min，用心输出量的绝对值比较不同个体之间的心功能并不全面。

       * 规则：劳动、运动、激动时心输出量增加而体表面积不变，心指数增大；孕妇心输出量增大而体表面积变化不大，心指数同样增大。

       * 应用：比较不同个体的心脏泵血功能时，应采用静息心指数。

   * **射血分数**

       * > **定义**：每搏输出量占心室舒张末期容积的百分比。

       * 计算式：$\text{射血分数} = \frac{\text{每搏输出量}}{\text{心室舒张末期容积}} \times 100\%$；正常值为 55%～65%，每搏量 70 ml、舒张末期容积 125 ml 时为 56%。

       * 边界：舒张末期容积从 125 ml 增大到 200 ml 而每搏量仍为 70 ml 时，射血分数降至 35%，心功能已经减退。

       * > **易错点**：⚠️ 每搏量、心输出量、心指数都“正常”不代表心脏没病——反映心功能不但要看输出量，还要看射血分数，心室舒张末期容积增大时尤其如此。

   * **心力储备**

       * > **定义**：心输出量随着代谢的需要而增加的能力。

       * 地位：心力储备是反映心脏健康程度的最好指标——静息心输出量同为 5 L/min，运动时能达 30 L/min 者增加 25 L，能达 35 L/min 者增加 30 L，后者心脏功能更好。

       * 心率储备：心率可从正常的每分钟 75 次增快到 180 次，储备 105 次/分。

       * 舒张期储备：通过增加心室舒张末期容积使心输出量增加；正常心肌有抵抗过度延伸的特性，心室不能过度扩大，舒张末期容积只能从 125 ml 增加到 140 ml，储备 15 ml。

       * 收缩期储备：收缩末期容积正常为 55 ml，运动时可以低于 20 ml，相当于多挤出 35 ml。

       * 三个方面之中，以心率储备和收缩期储备的贡献更大。

   * **心脏做功量**

       * > **定义**：心室收缩一次所做的外功称为每搏功，心脏每分钟所做的功称为每分功。

       * 用途：比较动脉血压值不等的个体之间的心脏泵血功能，以及同一个体动脉血压改变前后的心脏泵血功能——动脉血压从 100 mmHg 增至 150 mmHg 而每搏量仍要达到 70 ml 时，心脏做功必须增大。

| 指标 | 含义 | 用在哪 |
| :--- | :--- | :--- |
| 每搏输出量 | 一侧心室一次收缩射出的血量（125 − 55 = 70 ml） | 计算的基础 |
| 心输出量 | 每搏量与心率的乘积（静息约 5 L/min） | 衡量泵血功能的基本指标 |
| 心指数 | 心输出量除以体表面积 | 比较不同个体（用静息值） |
| 射血分数 | 每搏量占舒张末期容积的百分比（55%～65%） | 舒张末期容积改变时 |
| 心力储备 | 心输出量随代谢需要而增加的能力 | 反映心脏健康程度的最好指标 |
| 心脏做功量 | 每搏功、每分功 | 动脉血压改变时 |

## 心肌细胞的分类

   * **分类依据**

       * 根据生理特性，心肌细胞分为普通心肌细胞（心房肌细胞、心室肌细胞）和特殊心肌细胞两大类。

       * 正常情况下，心房和心室不停歇地进行有顺序的、协调的收缩和舒张交替活动，这是心脏实现泵血功能、推动血液循环的必要条件，而这种有序活动建立在心肌细胞生物电的基础上。

   * **工作细胞（working cell）**

       * > **定义**：具有兴奋性、传导性和收缩性、没有自律性的普通心肌细胞，包括心房肌细胞和心室肌细胞。

       * 兴奋性：具有产生动作电位的能力或特性。

       * 传导性：兴奋产生以后可以在心肌细胞之间进行传导。

       * 收缩性：细胞中存在收缩蛋白。

       * 无自律性：没有自动产生动作电位的能力。

   * **自律细胞**

       * > **定义**：构成心脏特殊传导系统的特殊心肌细胞，与工作细胞一样具有兴奋性和传导性，大多还具有自动产生动作电位的能力，即自律性。

       * 无收缩性：这些细胞没有收缩蛋白。

       * 组成：房室束（也称希氏束）、左右束支、浦肯野氏纤维（也称浦氏细胞），以及结区和结希区。

## 心室肌细胞的动作电位

   * **静息电位（resting potential）**

       * 数值：静息状态下心室肌细胞膜内电位为 −90 mV。

       * 机制：以钾离子外流为主，另外还有少量钠背景电流以及生电性钠泵的参与。

   * **动作电位的分期**

       * 特点：与神经细胞的动作电位相比，心室肌细胞动作电位波形复杂、持续时间很长、上升支与下降支不对称。

       * 划分：人为分为 0 期去极化以及复极 1、2、3、4 期。

       * > **易错点**：⚠️ 分期从 0 期开始，不存在“1 期去极化”；这是最初研究心室肌细胞动作电位时定下的命名，记住即可。

```text
膜内电位/mV
 +30 |            _
     |           / \
     |          /   \
   0 |         /     \______________________________
     |        /                                     \
 -90 |_______/                                      \____________
     |
     +--------------------------------------------------------------> 时间
        0期     1期          2期(平台期)               3期       4期
```

   * **0 期去极化**

       * 数值：膜内电位从 −90 mV 变化到 +30 mV，去极幅度高达 120 mV，历时仅 1～2 ms，去极速度高达 800～1000 V/s。

       * 机制：心室肌细胞受有效刺激时膜上钠离子通道被激活，钠离子内流使膜内正电荷增加；膜电位去极到 −70 mV（心室肌细胞的阈电位）时，大量钠离子通道被激活，钠离子大量内流，膜电位从 −90 mV 一直变到 +30 mV。

       * 通道性质：参与 0 期的钠通道开放快、内流快，称为快通道；可被河豚毒素（TTX）阻断，但心室肌细胞对河豚毒素的敏感性仅为神经细胞和骨骼肌细胞的 1/100～1/1000。

       * 相应地，心室肌细胞称为快反应细胞，其动作电位称为快反应动作电位。

   * **1 期复极（快速复极初期）**

       * 数值：膜电位从 +30 mV 拉回到 0 mV；相对于平台期，复极速度很快。

       * 机制：钾离子外流。

   * **2 期复极（平台期）**

       * 数值：膜电位回到 0 mV 后持续 100～150 ms 基本不变，构成平台。

       * 机制：钾离子通道开放、钾离子外流的同时，钙离子通道开放（以 L 型为主）、钙离子内流，两者所负载的电荷相等，膜电位稳定在 0 mV 左右。

       * 意义：平台期的存在是心室肌细胞动作电位持续时间长的主要原因；与骨骼肌细胞和神经细胞相比，有平台期是心室肌细胞动作电位的最大特点——若把 3 期复极直接接在 1 期后面，波形与骨骼肌、神经细胞的动作电位非常相像。

   * **L 型钙离子通道（long lasting channel）**

       * 阈电位为 −30～−40 mV。

       * 激活、失活和复活的速度都很慢，因此称为慢通道（slow channel）。

       * 通透性大约只有快钠通道的 1/10。

       * 可被锰离子和维拉帕米阻断。

   * **3 期复极（快速复极末期）**

       * 数值：膜电位从 0 mV 下降到 −90 mV，历时约 100～150 ms；所谓“迅速”是相对 2 期而言。

       * 机制：慢钙通道失活，钾离子通道开放，钾离子产生再生性外流，膜内正电荷迅速下降——3 期复极是钾离子外流引起的。

   * **4 期（静息期）与离子复位**

       * 3 期复极完毕后膜电位稳定在 −90 mV，故有人将 4 期称为静息期；但 4 期并非真正静息：0 期内流过钠离子，复极 1、2、3 期外流过钾离子，2 期还内流过钙离子。

       * 钠钾泵：把 0 期内流的钠离子泵出、把复极期外流的钾离子摄回，迅速恢复膜两侧离子浓度，保证下一次动作电位的正常产生。

       * 钠钙交换：平台期内流的钙离子经钠钙交换排到细胞外；排钙逆浓度差、需要消耗能量，能量来自钠离子顺浓度差内流，内流的钠离子再经钠钾泵泵出到细胞外——属典型的继发性主动转运（secondary active transport）。

   * **强心苷增强心肌收缩的机制**

       * 临床背景：治疗心力衰竭常采用抑制钠钾泵的强心苷类药物。

       * 因果链：强心苷抑制钠钾泵 → 钠离子泵出减少、细胞内 Na⁺ 增多 → 膜两侧 Na⁺ 浓度差减小 → 推动钙离子外排的能量减少、心肌细胞内 Ca²⁺ 浓度增高 → 活化的横桥数目增加 → 心肌收缩能力增强。

| 分期 | 膜电位走向 | 主要离子机制 |
| :--- | :--- | :--- |
| 0 期 | −90 → +30 mV，1～2 ms | 快钠通道开放，Na⁺ 大量内流 |
| 1 期 | +30 → 0 mV（快速复极初期） | K⁺ 外流 |
| 2 期 | 稳定在 0 mV 左右，100～150 ms（平台期） | K⁺ 外流与 Ca²⁺ 内流并存，两者电荷相等 |
| 3 期 | 0 → −90 mV，约 100～150 ms（快速复极末期） | 慢钙通道失活，K⁺ 再生性外流 |
| 4 期 | 稳定在 −90 mV（“静息期”） | 钠钾泵运转与钠钙交换，恢复离子分布 |

## 自律细胞的动作电位

### 浦肯野细胞

   * 与心室肌细胞的相同点：最大复极电位（或者说静息电位）同为 −90 mV；0 期去极与复极 1、2、3 期形态非常相似、离子机制也非常相似——0 期也是钠离子内流引起，复极 1、2、3 期都有钾离子外流，平台期既有钾离子外流也有钙离子内流且两者所负载的电荷几乎相等，同样有明显平台期。

   * 与心室肌细胞的不同点：复极到 −90 mV 之后，膜电位会在没有受到任何外来刺激的情况下自动从 −90 mV 变到 −80 mV，即 4 期自动去极化——这是浦肯野细胞动作电位的最大特点。

   * 4 期自动去极化的最主要因素：逐渐增强的钠离子内流（If 电流）——浦肯野细胞有丰富的 If 通道，复极到 −60 mV 开始激活，而最大复极电位可到 −90 mV，开放的 If 通道数目很多，钠离子不断内流。

   * 4 期自动去极化的次要因素：钾离子外流的衰减——复极到 −50 mV 时 Ik 通道开始去激活（激活后的电压门控钾通道进入的一种有别于失活的状态），到复极 −90 mV 时接近完成；开放的钾通道越来越少、钾离子外流越来越少，膜内正电荷逐渐增多。

### If 通道

   * 本质：浦肯野细胞上一种“奇异”（funny）的钠离子通道，完全不同于心室肌细胞 0 期去极的快钠通道。

   * 激活方式：去极时不激活，只有当复极到 −60 mV 时才被激活，复极程度越大激活的通道越多、内流的钠离子越多，复极到 −100 mV 时全部激活。

   * 阻断剂：不能被河豚毒素（TTX）阻断，但可以被金属元素铯阻断——铯是特异性的 If 通道阻断剂。

   * > **易错点**：⚠️ If 通道是复极（超极化）时才激活的钠通道，激活方向与快钠通道正好相反——快钠通道去极到 −70 mV 激活，If 通道复极到 −60 mV 才开始激活、复极到 −100 mV 时全部激活，别把两者的阈电位记混。

### 窦房结细胞

   * 0 期特点：去极化幅度低、速度慢、时间长。

| 对比项 | 浦肯野细胞 | 窦房结细胞 |
| :--- | :---: | :---: |
| 0 期去极化幅度 | 120 mV | 70 mV |
| 0 期去极化速度 | 800～1000 V/s | 仅 10 V/s |
| 0 期去极化时间 | 1～2 ms | 长达 7 ms |

   * 0 期机制：L 型钙通道（慢钙通道）开放、钙离子内流所引起。

   * 复极特点：找不到明显的平台期，分不清哪里是 1 期复极的结束、哪里是 3 期复极的开始，1、2、3 期融合在一起统称为复极的三期；离子机制是钾离子外流。

   * 最大复极电位：−70 mV。

   * 4 期自动去极化的三个因素：衰减的钾离子外流（复极到 −50 mV 时 Ik 通道逐渐去激活关闭，钾离子外流不断减少，留在细胞内的正电荷越来越多）；If 电流（窦房结细胞上也有 If 通道，4 期过程中被激活，形成逐渐增强的钠离子内流）；钙离子内流（4 期自动去极到 −50 mV 时钙通道被激活，钙离子内流、膜内正电荷进一步增多）。

   * 主要因素：钾离子外流的衰减与 If 电流的贡献是 6 比 1，造成窦房结细胞 4 期自动去极化的最主要原因是钾离子外流的衰减——窦房结细胞最大复极电位仅为 −70 mV，复极到 −60 mV 时 If 通道才开始激活，激活的 If 通道数目不够多、内流的钠离子不多，与浦肯野细胞正好相反。

### 快反应细胞与慢反应细胞

   * 分类规则：按 0 期去极化的速度快慢，分为快反应细胞和慢反应细胞；按 4 期有无自动去极化，分为自律细胞和非自律细胞。

   * 归属示例：心室肌细胞属于快反应非自律细胞，窦房结细胞属于慢反应自律细胞。

   * 判定要点：区分快反应还是慢反应，主要看 0 期去极化的速度；区分自律还是非自律，主要看 4 期有无自动去极化。

## 心肌的自律性

   * **自律性**

       * > **定义**：在没有任何外来刺激的条件下，细胞能自动产生节律性动作电位的能力或特性。

       * 发生方式：4 期自动去极化达到阈电位时，即可自动引发一次动作电位。

       * 分布：构成心脏特殊传导系统的窦房结、房室交界、房室束、左右束支以及浦肯野氏纤维都有自律性。

   * **自律性的衡量与数值**

       * 衡量标准：每分钟自发产生动作电位的次数。

       * 数值：窦房结每分钟能自动产生 100 个动作电位，房室交界为每分钟 50 次，浦肯野氏纤维为每分钟 25 次。

   * **正常起搏点与窦性心律**

       * 在所有自律细胞中自律性最高的是窦房结，心脏由窦房结起搏，窦房结被称为正常起搏点；由窦房结起搏而形成的心脏节律称为窦性心律。

   * **潜在起搏点**

       * 正常情况下，窦房结以外的其他自律细胞受窦房结的控制，并不表现出自身的自律性，只起着传导的作用，属于潜在起搏点。

       * 生理意义：在窦房结起搏障碍时，可充当备用起搏点，以较低的频率维持心脏的跳动。

   * **异位起搏点**

       * 潜在起搏点的自律性异常增高、超过窦房结，或因传导阻滞不再受窦房结控制而起搏心脏时，就成为异位起搏点；异位起搏点的出现是引发多种形式心律失常的主要原因。

### 窦房结控制潜在起搏点的方式

   * **抢先占领**

       * 窦房结的自律性明显高于其他潜在起搏点，在潜在起搏点 4 期自动去极化尚未达到阈电位水平之前，就已受到来自窦房结的冲动、被动地产生动作电位，其自身的自动兴奋根本无法实现。

   * **超速驱动抑制**

       * 潜在起搏点在自律性高达每分钟 100 次的窦房结兴奋驱动下被动兴奋——房室交界本来自律性 50 次/分、浦肯野细胞本来 25 次/分，都必须跟随每分钟 100 次的频率兴奋；长时间超速兴奋的结果，是潜在起搏点出现抑制效应。

       * > **注意**：由于超速驱动抑制的存在，在人工起搏的情况下，如有特别需要要暂时中断起搏器，中断之前一定要逐步减慢起搏频率，以避免发生心脏停搏。

### 影响自律性的因素

   * 最大复极电位水平：最大复极电位越负，离阈电位越远，自律性将降低。

   * 阈电位水平：阈电位上移，最大复极电位到阈电位的间距延长，自律性也会降低。

   * 4 期自动去极化速度：速度越快自律性越高，是三个因素中最重要的；窦房结细胞 4 期自动去极化速度为每秒 0.1 伏，约为浦肯野细胞（约每秒 0.02 伏）的 5 倍——窦房结有钾离子外流衰减、If 电流、钙离子内流三大因素协同，4 期自动去极化速度最快、自律性最高，从而成为正常起搏点。

## 心肌的传导性

   * **传导性**

       * > **定义**：心肌细胞具有传导兴奋的能力或特性。

   * **兴奋传导的路径**

       * 兴奋首先由窦房结自动产生：窦房结 → 心房肌 → 房室交界 → 房室束（希氏束） → 左右束支 → 浦肯野氏纤维网 → 心室肌。

   * **兴奋传导的特点**

       * 心肌细胞间直接电传递：无论自律细胞之间、心房肌细胞和心室肌细胞等工作细胞之间，还是自律细胞与工作细胞之间，都以局部电流的方式直接传导。

       * 通过特殊传导系统有序传播：兴奋由窦房结产生以后，经心房肌、房室交界、房室束、左右束支、浦肯野氏纤维网最后到心室肌，次序井然。

       * 传导速度不均匀。

| 部位 | 传导速度（m/s） |
| :--- | :--- |
| 窦房结 | 0.05 |
| 心房肌 | 0.4（心房内优势传导通路可达 1.0～1.2） |
| 房室交界（结区） | 0.02 |
| 房室束 | 2 |
| 左右束支 | 2 |
| 浦肯野氏纤维网 | 4 |
| 心室肌 | 1 |

   * **房室延搁**

       * 房室交界是心脏内兴奋传播速度最慢的部位（0.02 m/s），而它又是正常时兴奋由心房进入心室的唯一通道，缓慢传导使兴奋在此延搁一段时间，称为房室延搁。

       * 生理意义：保证心室是在心房收缩完毕后才开始收缩，使心房与心室不会同时收缩。

   * **浦肯野氏纤维网的意义**

       * 传导速度最快（可达每秒 4 米）且呈网状分布于心室肌，使由房室交界传入心室的兴奋能迅速而广泛地向左右两侧心室壁传播，保证左右心室几乎同时兴奋、同时收缩。

   * **决定和影响传导性的因素**

       * 解剖因素——心肌细胞的直径：细胞越大电阻越小、传导越快，传导速度与直径成正变；浦肯野细胞直径可达 70 μm，传播速度最快；心房肌细胞直径约 5～10 μm；房室交界结区细胞直径仅 3 μm，传导速度慢至每秒 0.02 米。

       * 生理因素之一——0 期去极化的速度和幅度：速度越快，与邻近未兴奋膜之间的电位差形成越快，局部电流形成加快、兴奋传导加快；幅度越大，兴奋部位与未兴奋部位之间的电位差越大，形成的局部电流越强、兴奋能传播的距离越大，传导速度越快。

       * 生理因素之二——邻近未兴奋部位膜的兴奋性：邻近未兴奋部位膜的兴奋性降低时，兴奋的传导速度将减慢。

       * 归因：房室交界结区传导最慢，一是细胞直径最小（仅 3 μm）、电阻最大，二是慢反应细胞 0 期去极化速度慢、幅度低；浦肯野细胞传导最快，一是直径最大（高达 70 μm），二是快反应细胞 0 期去极化速度快、幅度大（可达 120 mV）。

## 心肌的收缩性

   * **收缩性**

       * > **定义**：心肌的第四个生理特性，也是唯一的机械特性；心肌的收缩和舒张，才有了心脏的射血与充盈。

       * 心肌和骨骼肌都是横纹肌，与骨骼肌收缩相比，心肌收缩有三个特点。

   * **全或无式收缩**

       * > **定义**：一个心房肌细胞兴奋即可引起整个心房肌的同步兴奋与收缩，一个心室肌细胞兴奋能引起几乎所有心室肌细胞的同步兴奋与收缩；也称心肌的同步收缩、合胞体式收缩。

       * 心房同步的机制：心房肌细胞之间存在低电阻的闰盘，传播兴奋的速度非常快，使左右心房几乎同时兴奋、同时收缩。

       * 心室同步的机制：左心室壁比右心室壁厚很多，左右心室几乎同时兴奋、同时收缩主要依赖广泛分布于心室肌细胞且传播速度最快的浦肯野纤维；同时心室肌细胞之间也存在传播兴奋很快的闰盘。

       * 意义：正因为是全或无式收缩，心室收缩的强度不会随着参加活动的肌细胞数目的多少而改变。

   * **不发生完全强直收缩**

       * 原因：心肌细胞的有效不应期很长，相当于整个收缩期加上舒张早期；在有效不应期内即使给予高频率的外部刺激，心肌也不会再产生一次动作电位、引起一次收缩，下一次收缩不可能落在前一次收缩的收缩期内，不会出现收缩叠加、只收缩而没有舒张的完全强直收缩。

       * 意义：使心肌总是做收缩与舒张交替进行的活动，以利于心室的充盈和射血。

   * **对细胞外钙离子的依赖程度大（钙诱导钙释放）**

       * 两个先天不足：心肌细胞的肌浆网以及终末池没有骨骼肌那样发达，储存的钙离子比较少；心肌细胞肌浆网内钙离子的释放，依赖于细胞外钙离子内流的触发。

       * 数值：细胞外内流 10%～20% 的钙离子，就可以触发肌浆网释放 80%～90% 的钙离子，即钙诱导钙释放；流入细胞内的钙离子越多，触发肌浆网释放的钙离子越多，心肌收缩越强。

       * 低血钙的后果：低血钙时内流的钙离子减少 → 心肌细胞内钙离子浓度降低 → 活化的横桥数目减少 → 心肌收缩能力减弱 → 收缩无力。

       * > **提示**：记住“10%～20% 触发 80%～90%”这组数字——外面的钙先进来一点，肌浆网里面存的钙才大量放出来。

## 动脉血压

   * **血压（blood pressure）**

       * > **定义**：血液对血管壁的侧压强，即血液对单位面积血管壁的侧压力；压力除以面积才是压强，血压是侧压强而不是侧压力。

       * 动脉血压：血液在动脉里面流动时对动脉管壁的侧压强；通常所指的血压一般指动脉血压。

       * 单位：血压高低以大气压为零、用高于大气压的数值表示，常用毫米汞柱（mmHg），1 mmHg = 0.133 kPa；动脉血压 100 mmHg 意味着血液对动脉管壁的侧压强比大气压高 100 毫米汞柱。

   * **收缩压（systolic pressure，SP）**

       * > **定义**：一个心动周期中动脉血压的最高值，一般在心室收缩中期达到最高。

       * 数值：我国健康成年人的收缩压一般为 100～120 mmHg。

   * **舒张压（diastolic pressure，DP）**

       * > **定义**：一个心动周期中动脉血压的最低值，实际测量中动脉血压是在等容收缩期末达到最低的。

       * 数值：我国健康成年人的舒张压为 60～80 mmHg。

   * **脉搏压（pulse pressure，PP）**

       * > **定义**：收缩压与舒张压的差值。

       * 数值：正常值一般为 30～40 mmHg。

   * **平均动脉压**

       * > **定义**：一个心动周期中动脉血压的平均值。

       * 计算式：$\text{平均动脉压} = \text{舒张压} + \frac{1}{3}\text{脉压}$；因为一个心动周期中舒张期明显长于收缩期，其数值一般要稍微低于收缩压与舒张压的平均值。

   * **动脉血压的生理波动**

       * 昼夜节律：大部分人上午 8 点到 10 点、下午 4 点到 8 点达到高峰值，凌晨 2 点到 3 点最低；非 24 小时连续测定时应注意选择高峰段测量，对高血压的控制白天和夜间都应达到理想水平。

       * 运动的影响：运动时收缩压、舒张压以及平均动脉压都会升高，一般以收缩压的升高更为明显。

       * 年龄与性别：儿童期的动脉血压低于成年人；成年之后血压随年龄增长，收缩压与舒张压都升高，一般收缩压的升高大于舒张压；成年男性的动脉血压一般稍高于女性，更年期以后这种性别差异消失。

       * 双上肢差别：正常人两侧上肢的动脉血压存在一定差别，一般相差 5～10 mmHg，多数人右上肢略高于左上肢；测定动脉血压时最好每次都测同一侧上肢。

   * **动脉血压的生理意义**

       * 血流量的大小与血压呈正变关系、与血流阻力呈反变关系，动脉血压的意义是推动血液流动；动脉血压异常将会影响组织器官的血液供应。

       * 血压过低：休克时动脉血压低于 50 mmHg，组织器官的血流量明显减少，出现缺血缺氧状态，引起相应的临床症状与体征。

       * 血压过高：成年人在不是同一天的三次测量中收缩压都 ≥140 mmHg 或舒张压都 ≥90 mmHg，即可诊断为高血压病；血压过高可造成动脉病变、左室肥厚、肾脏萎缩等。

       * 降压收益：舒张压每降低 5 mmHg，脑卒中的发病风险降低 40%、缺血性心脏病的发病风险降低 14%；收缩压每降低 10 mmHg，脑卒中的发病风险降低 30%、缺血性心脏病的发病风险降低 23%。

## 动脉血压的形成与影响因素

   * **体循环平均充盈压**

       * > **定义**：心脏停止跳动、血流暂停时，血管系统里面充盈的血液对血管壁的侧压强，数值大概 7 mmHg。

       * 地位：要形成有一定高度的动脉血压，首先血管系统里必须充盈有一定的血液；但仅有这样的充盈还不够，它只有 7 mmHg。

   * **动脉血压形成的条件**

       * 血管系统必须有足够的血液充盈——前提条件（见体循环平均充盈压）。

       * 心脏射血：心室收缩所做的功一部分转变成动能，用来推动血液流动；另一部分转变成势能，势能又有两种——弹性势能（促成大动脉管壁弹性扩张的能量）和压强能（即心室收缩时动脉血压的最高值，收缩压）。

       * 外周阻力：射入动脉的血液如果没有遇到任何阻力，无法形成具有一定高度的动脉血压；心室射血与外周阻力是动脉血压形成的关键。

       * 大动脉的弹性回缩：心室射血停止后，主动脉和大动脉发生弹性回缩，储存在管壁中的弹性势能转变成压强能（即舒张压）以及推动血液流动的动能。

       * 大动脉弹性的缓冲作用：避免收缩压过高、舒张压过低，并把间断的心室射血变成连续的动脉血流——心室内压大起大落（最高时超过动脉血压以实现射血，最低时低于房内压以实现充盈），而动脉血压不能像心室内压这样大起大落，否则将引起严重的功能障碍。

### 影响动脉血压的因素

   * 每搏输出量：增加时射入动脉的血液增多，收缩压升高、舒张压也升高，但首先升高的是收缩压，以收缩压升高为主，脉压增大；减少时以收缩压降低为主，脉压减小。一般情况下，收缩压的高低主要反映每搏输出量的大小。

       * > **易错点**：⚠️ 这一条很容易与外周阻力记混——记住这组对应：收缩压对每搏输出量，舒张压对外周阻力。

   * 心率：加快时心室舒张期缩短、舒张期内流向外周的血液减少、舒张末期存留在大动脉里的血液增多，舒张压升高，收缩压也升高但不如舒张压明显，以舒张压升高为主，脉压减小；减慢时以舒张压降低为主，脉压增大。

   * 外周阻力：主要产生在小动脉和微动脉，其大小最主要取决于小动脉和微动脉的半径（也可以说直径或口径）；外周阻力增加时舒张期血液流向外周的速度明显减慢、舒张末期存留在主动脉里的血液增多，以舒张压升高为主、脉压减小，下降时以舒张压降低为主、脉压增大。一般情况下，舒张压的高低主要反映外周阻力的大小。

   * 大动脉管壁的弹性：弹性降低时收缩压明显增高、舒张压明显降低、脉压明显增大——大动脉管壁的弹性对脉压的影响非常明显。

   * 循环系统的充盈程度：充盈程度降低时收缩压降低、舒张压也降低，以收缩压降低得更为明显，脉压减小。

   * > **注意**：以上五大因素——每搏输出量、心率、外周阻力、大动脉管壁的弹性以及循环系统充盈程度——都是在假设其他因素不变的前提下分析的单因素效应；实际整体情况下这五大因素可以同时改变，分析动脉血压时一定要综合考虑各方面的效应。

## 静脉血压与静脉回心血量

   * **静脉的储存库作用**

       * 静脉不仅是血液回流心脏的通道：安静时体循环中大约 60%～70% 的血液量容纳在静脉系统中；静脉的收缩与舒张能有效地调节回心血量和心输出量，使机体适应各种生理状态下的需要。

   * **外周静脉压与中心静脉压**

       * 外周静脉压：各器官静脉的血压。

       * 中心静脉压：右心房和胸腔大静脉里面的血压，正常范围大约 4～12 cmH₂O。

       * > **易错点**：⚠️ 中心静脉压的大小用厘米水柱（cmH₂O）表示，而动脉血压用的是毫米汞柱（mmHg）——这是两种不同的单位，不能混。

       * 意义：中心静脉压的高低反映心脏射血能力与静脉回心血量之间的平衡，是反映心血管功能的重要指标——心脏射血力量够强时能及时把回流血液射入动脉，中心静脉压比较低；射血力量下降时心室存留血液增多、右心房里的血增多，中心静脉压升高；射血能力不变而静脉回流速度或回流力量增加时，中心静脉压也增高。

       * 临床应用：输液治疗休克患者时，中心静脉压偏低或出现下降趋势提示输液量不够；明显高于正常并出现进行性升高趋势，提示输液过多过快，或者已发生心功能不全。

### 影响静脉回心血量的因素

   * 前提：静脉回心血量取决于外周静脉压与中心静脉压的差值以及静脉的阻力；凡能影响外周静脉压、中心静脉压以及静脉阻力的因素，都影响静脉回心血量。

   * 体循环平均充盈压：血量增加或容量血管收缩（如输液）时升高，静脉回心血量增加；大失血时静脉回心血量减少。

   * 心脏收缩力量：心脏收缩力量更强时射血更充分、中心静脉压降低，静脉回心血量增加。

       * 右心衰竭：射出去的血液减少、右心室压力增高、右心房以及大静脉里面的血液增多、中心静脉压增高，可出现右心衰三联征——颈外静脉怒张、肝脏肿大以及下肢水肿。

       * 左心衰竭：出现左心房压力以及肺静脉压力升高，可造成肺淤血和肺水肿。

   * 体位改变：久蹲或平卧后突然站立 → 重力作用使身体低垂部分（如下肢）的静脉压升高 → 静脉扩张、静脉容量增大 → 回心血量减少 → 每搏输出量减少 → 动脉血压下降 → 脑部供血不足、缺氧 → 头晕。

   * 骨骼肌的挤压作用（肌肉泵）：肌肉收缩时对肌肉内以及肌肉间的静脉发生挤压，静脉里的瓣膜使血液只能向心脏方向单一流动而不能倒流，两者共同起“泵”的作用；站立不动时足部静脉压可达 90 mmHg，移动一步即可下降 50% 至 45 mmHg，继续步行或原地踏步可降至 25 mmHg。

   * 呼吸运动（呼吸泵）：吸气时胸内负压增大，胸腔内的大静脉以及右心房扩张，静脉回心血量增加；呼气时静脉回流到右心房的血量减少。

## 微循环

   * **微循环**

       * > **定义**：微动脉与微静脉之间的血液循环。

       * 地位：血液在流经动脉系统、回到静脉系统之前必须经过微循环；微循环最重要的生理意义是实现物质交换。

       * 组成：由微动脉、后微动脉、毛细血管前括约肌、真毛细血管、通血毛细血管、动静脉吻合支、微静脉七个部分组成，构成三条通路。

```text
微动脉
 ├→ 后微动脉
 │   ├→ 毛细血管前括约肌 → 真毛细血管 → 微静脉    （迂回通路）
 │   └→ 通血毛细血管 → 微静脉                     （直接通路）
 └→ 动静脉吻合支 → 微静脉                         （动静脉短路）
```

### 迂回通路（营养通路）

   * 路径：血液从微动脉到后微动脉，再经过毛细血管前括约肌到真毛细血管，然后回到微静脉。

   * 结构特点：真毛细血管的数量很多，只由一层内皮细胞构成，管壁非常薄、通透性非常大；管径在微循环七个组成部分中最小，阻力最大，血液流经时速度最慢。

   * 功能：非常有利于进行物质交换，是物质交换的主要场所，因此又称营养通路。

   * 交替开放：一般情况下（安静时）全身大约有 20% 的迂回通路开放；调控机制——毛细血管前括约肌关闭 → 该区域血流停止 → 乳酸、二氧化碳、腺苷、组胺等局部代谢产物浓度增高 → 前括约肌对这些代谢产物非常敏感而开放 → 局部血流增加、代谢产物被带走 → 在肾上腺素、去甲肾上腺素等全身性缩血管物质作用下再次关闭。

### 直接通路

   * 路径：血液从微动脉经过后微动脉，再经通血毛细血管回到微静脉。

   * 特点：通血毛细血管管径比较大而且很直，血流阻力比较小、血流速度比较快，经常性开放；在骨骼肌组织中比较多见。

   * 功能：保证一部分血液能够迅速经过微循环回心，以维持循环血量的相对稳定；通血毛细血管也能进行少量物质交换。

### 动静脉短路（非营养性通路）

   * 路径：血液从微动脉经过动静脉吻合支回到微静脉，吻合支把微动脉与微静脉直接连通，类似于动脉与静脉之间的短路。

   * 特点：在真毛细血管、通血毛细血管以及动静脉吻合支三个部分中，动静脉吻合支的管壁最厚、管径最粗、血流速度最快，没有物质交换功能，因此又称非营养性通路。

   * 分布与开闭：主要分布在手指、脚趾、耳廓这样一些地方的皮肤以及某些组织器官内；一般情况下不开放，环境温度增高时开放、皮肤血流量增高以利散发热量（高烧患者满脸通红即脸部、耳廓等处的动静脉短路大量开放），环境温度降低时关闭、皮肤血流量减少以保存体热——参与调节体温。

   * > **注意**：发生感染性休克或中毒性休克时可出现动静脉短路大量开放，皮肤血流量增多、四肢温暖，看似状态不错，实为假象——休克后循环血量已严重减少，少量血液经动静脉短路流经皮肤，流经其他重要组织器官的血流量减少，出现严重缺血缺氧，别被温暖的四肢骗了。

| 通路 | 路径 | 特点 | 主要功能 |
| :--- | :--- | :--- | :--- |
| 迂回通路 | 微动脉→后微动脉→毛细血管前括约肌→真毛细血管→微静脉 | 真毛细血管管壁薄、通透性大、管径最小、血流最慢；交替开放（安静时约 20% 开放） | 物质交换的主要场所（营养通路） |
| 直接通路 | 微动脉→后微动脉→通血毛细血管→微静脉 | 通血毛细血管管径较大且直、阻力小、流速快；经常开放 | 保证部分血液迅速回心、维持循环血量相对稳定；少量物质交换 |
| 动静脉短路 | 微动脉→动静脉吻合支→微静脉 | 吻合支管壁最厚、管径最粗、血流最快；平时不开放，随体温调节开闭 | 参与体温调节（非营养通路，无物质交换功能） |

## 组织液的生成与回流

   * **组织液**

       * > **定义**：存在于组织和细胞间隙里面的液体，是血浆经过毛细血管壁滤过所生成的液体。

       * 形态：绝大部分呈胶冻状、不能自由流动，只有很少一部分呈液态、能够自由流动，因此一般情况下组织液没有办法抽出来。

   * **滤过与重吸收**

       * 滤过：液体由毛细血管内向毛细血管外（组织液方向）流动。

       * 重吸收：液体由组织向毛细血管内流动。

   * **有效滤过压**

       * 滤过的力量：毛细血管血压（把毛细血管里面的液体压向毛细血管外）与组织液胶体渗透压（把毛细血管内的液体吸向组织液）。

       * 重吸收的力量：血浆胶体渗透压（把液体吸回到血管内）与组织液静水压（把组织里面的液体推向毛细血管内）。

       * 四种力量在毛细血管的任意一个部位同时起作用；滤过的力量减去重吸收的力量即有效滤过压，它决定液体是进毛细血管还是出毛细血管。

$$\text{有效滤过压} = (\text{毛细血管血压} + \text{组织液胶体渗透压}) - (\text{血浆胶体渗透压} + \text{组织液静水压})$$

   * **动脉端生成与静脉端回流**

       * 动脉端：毛细血管血压 30 mmHg、组织液胶体渗透压 15 mmHg，滤过的力量 45 mmHg；血浆胶体渗透压 25 mmHg、组织液静水压 10 mmHg，重吸收的力量 35 mmHg；有效滤过压 = 45 − 35 = +10 mmHg，滤过的力量大于重吸收的力量，组织液生成。

       * 静脉端：液体从动脉端流向静脉端的过程中大量流出，毛细血管血压降低到 12 mmHg，其他三个因素几乎不变；有效滤过压 = 12 + 15 − 35 = −8 mmHg，滤过的力量小于重吸收的力量，组织液从静脉端回流进毛细血管。

       * 回流去向：促使组织液生成的力量是 +10 mmHg，促使回流的力量是 −8 mmHg——从动脉端生成的组织液并没有从静脉端全部回流，大约 90% 从静脉端回流，另外约 10% 经淋巴回流最终回到血液循环。

       * 生理意义：组织液的生成与回流维持动态平衡，使血量与组织液量保持相对稳定；毛细血管动脉端通过生成组织液给组织细胞带来营养物质，静脉端回流组织液的同时带走代谢产物。

| 力量（mmHg） | 方向 | 动脉端 | 静脉端 |
| :--- | :--- | :---: | :---: |
| 毛细血管血压 | 滤过 | 30 | 12 |
| 组织液胶体渗透压 | 滤过 | 15 | 15 |
| 血浆胶体渗透压 | 重吸收 | 25 | 25 |
| 组织液静水压 | 重吸收 | 10 | 10 |
| 有效滤过压 | — | +10（生成） | −8（回流） |

## 水肿的发生机制

   * 毛细血管血压、组织液胶体渗透压、血浆胶体渗透压、组织液静水压中任何一个因素受到影响，都通过改变有效滤过压影响组织液的生成。

   * **毛细血管血压升高**

       * 有效滤过压增加，组织液生成增加；右心衰竭是典型——静脉回流受阻、静脉系统淤血、毛细血管血压升高、有效滤过压增高，出现组织液生成过多所导致的严重双下肢水肿。

   * **血浆胶体渗透压降低**

       * 有效滤过压增加、组织液生成过多；关键在血浆白蛋白，任何原因使体内白蛋白浓度下降都可能导致水肿。

       * 白蛋白浓度下降的三类原因：白蛋白合成需要氨基酸作为原料，严重营养不良使原料不足；白蛋白的合成场所是肝脏，肝脏疾患时合成能力下降；原料足够、肝脏正常时，肾脏疾患丢失白蛋白过多也会使体内白蛋白减少。

   * **毛细血管通透性增加**

       * 经毛细血管滤过到组织间隙的白蛋白增多，使组织液胶体渗透压增高、血浆胶体渗透压下降，两个变化都使有效滤过压增加而出现水肿。

       * 常见因素：烧伤、低氧、炎症等都可以使毛细血管通透性增加，其中以过敏时更为明显——过敏时毛细血管通透性增加，可出现严重水肿，还可以引起严重的哮喘。

   * **淋巴回流受阻**

       * 约 10% 的组织液经淋巴回流，任何原因造成淋巴回流受阻都可造成组织水肿；如丝虫病可引起淋巴管阻塞，临床上更多见的是肿瘤的压迫或肿瘤细胞侵入淋巴管；非常严重时可出现象皮腿。
