# 内分泌与生殖生理

## 激素与内分泌系统

### 激素的两种作用机制

* **内分泌系统（endocrine system）**

    * > **定义**：由内分泌腺和散在的内分泌细胞组成的信号系统，与神经系统并列，共同调节机体各项生理功能。

* **激素（hormone）**

    * > **定义**：内分泌细胞合成、分泌的、能够传递信息的生物活性物质，是内分泌系统调节机体功能的信息传递媒介。

    * 从广泛的角度调节机体的代谢、生长发育等多种生理功能。

* **激素的化学分类**

    * 含氮激素：化学结构含氮原子，包括蛋白质（肽类）激素与胺类激素。

    * 类固醇激素：化学结构含环状甾体骨架，又称甾体类激素，如糖皮质激素。

    * 按溶解性：水溶性激素为蛋白质、肽类激素及胺类激素中的儿茶酚胺；脂溶性激素为类固醇激素。

* **膜受体后作用**

    * > **定义**：水溶性激素与靶细胞膜上受体结合、在细胞内层层接力放大信号的作用方式，是水溶性激素机制中最常见的形式。

    * 通路：激素结合膜受体 → 腺苷酸环化酶（AC）活化 → ATP 水解产生大量 cAMP → 依赖 cAMP 的蛋白激酶活化 → 相应蛋白质磷酸化 → 生物学效应。

* **胞内受体后作用**

    * > **定义**：脂溶性激素进入细胞内与受体结合、通过调节基因转录起效的作用方式。

    * 通路：激素入胞 → 与胞内受体或核内受体结合形成激素-受体复合物 → 复合物结合 DNA 链上的激素反应元件 → 调节靶基因转录、合成新的效应蛋白 → 生物学效应。

```text
水溶性激素（蛋白质/肽类、儿茶酚胺）—— 膜受体后作用
激素 → 膜受体 → AC 活化 → ATP 水解产生大量 cAMP
      → cAMP 依赖蛋白激酶活化 → 蛋白质磷酸化 → 生物学效应

脂溶性激素（类固醇激素）—— 胞内受体后作用
激素 → 进入细胞 → 激素-受体复合物 → 结合 DNA 上的激素反应元件
      → 调节靶基因转录 → 合成新效应蛋白 → 生物学效应
```

### 激素作用的共同特征

* **相对特异性**

    * 多数激素随血液循环广泛接触全身器官、腺体、组织与细胞，但只选择性地作用于与它亲和力高的特定目标——靶器官、靶组织、靶细胞。

    * 判定方式：细胞能否被某激素作用，取决于该细胞上有无与之结合的特异性受体；只有 A 受体的细胞只对激素 A 起反应，同时有 A、B 两种受体的细胞可对两种激素都起反应。

* **高效能与酶促放大效应**

    * 激素是高效能生物活性物质，很低浓度即可产生很大的生物学效应。

    * 机理：细胞内每一次酶促反应都具有放大效应。例：一分子肾上腺素与肝细胞受体结合后，经一系列酶促放大可使 $10^{8}$ 个糖原分子分解，生物学效应被放大上千万倍。

* **协同作用**

    * > **定义**：多种激素联合作用产生倍增效应，总效应大于各激素单独作用之和。

    * 例：糖皮质激素、肾上腺素、胰高血糖素单独升血糖作用都不特别明显，协同起来产生很强的升血糖效应。

* **拮抗作用**

    * > **定义**：作用方向相反的激素彼此对抗。

    * 例：胰岛素通过多种途径降低血糖，与各升血糖激素方向相反。

* **允许作用**

    * > **定义**：某激素对特定器官、组织或细胞没有直接作用，但它的存在是另一种激素发挥生物效应的必备基础，是一种支持性作用。

    * 例：糖皮质激素本身无缩血管作用；单独在血管培养液中加去甲肾上腺素，血管收缩不明显；两者同时存在时血管才发生强烈收缩。

## 生长激素

### 促生长效应与 IGF-1 介导

* **生长激素（growth hormone，GH）**

    * 由腺垂体分泌，促进机体生长；人的长高主要取决于骨骼的生长，尤其是脊柱和双腿长骨的生长，长骨生长依赖骺板软骨组织的生长。

* **胰岛素样生长因子-1（insulin-like growth factor-1，IGF-1）**

    * > **定义**：生长激素作用于肝脏后由肝脏产生的促生长中间介导因子，再去作用于骨和肌肉发挥促生长作用。

    * 证据链第一步：切除幼年动物垂体 → 动物不再生长；把生长激素静脉注射回去 → 生长恢复——证明 GH 有促生长效应。

    * 证据链第二步：离体培养软骨、直接把 GH 加进培养液 → 软骨不生长——证明 GH 并不能直接刺激软骨细胞生长。

    * 证据链第三步：给去垂体动物注射 GH 后取其血清，加到离体软骨培养液中 → 软骨生长——证明 GH 促使动物体内产生了新的促生长物质。

    * > **易错点**：不要把「生长激素促进生长」理解成它直接作用于软骨——离体条件下它对软骨细胞没有直接作用，必须经肝脏产生的 IGF-1 介导；「整体有效、离体无效、血清有效」三步就是完整证据链 ⚠️

### 分泌异常

* **巨人症**

    * 幼年期（骨头未闭合）GH 分泌过多，机体不断生长，身高可超过 2 米甚至 2.5 米以上；通常活不长，有记载最高 2.72 米、仅活 22 岁；重要死因之一是 GH 过量导致的垂体性糖尿病。

* **侏儒症**

    * 幼年期 GH 分泌不足，生长缓慢、身材矮小，成年身高约 1 米；智力正常、寿命不受影响，有记载最矮 0.54 米、活到 75 岁。

* **肢端肥大症**

    * 成年之后（骨头已闭合）GH 分泌过多，骨不能再长长就横着长：手指明显变粗、颌面部骨骼变厚、面容改变。

* **垂体性糖尿病**

    * GH 抑制机体对糖的利用，使血浆中葡萄糖浓度升高，作用与胰岛素相反，称抗胰岛素作用；过量 GH 引起明显血糖升高，即垂体性糖尿病——病变在垂体而非胰岛。

| 疾病 | 发生时期 | 激素状态 | 表现 |
| :--- | :--- | :--- | :--- |
| 巨人症 | 幼年期（骨未闭合） | 分泌过多 | 不断生长，身高可超 2 米；通常活不长 |
| 侏儒症 | 幼年期 | 分泌不足 | 生长缓慢，成年身高约 1 米；智力正常、寿命不受影响 |
| 肢端肥大症 | 成年后（骨已闭合） | 分泌过多 | 手指变粗、颌面部骨骼变厚、面容改变 |

> **易错点**：侏儒症与呆小症都是幼年身材矮小，但侏儒症智力正常、寿命不受影响；呆小症则「又小又呆」，身高与智力双双受损，两者病因不同。

### 代谢作用与分泌调节

* 对三大物质代谢

    * 促进蛋白质合成（与促生长作用一致）、促进脂肪分解：使用 GH 的猪肌肉层明显厚实、脂肪层明显减少。

    * 抑制机体对糖的利用 → 血糖升高 → 抗胰岛素作用（见垂体性糖尿病）。

* 下丘脑的双重调节

    * 下丘脑神经核团合成、释放促生长激素释放激素（GHRH）与生长激素释放抑制激素（GHRIH），对 GH 分泌进行双重调节；一般认为 GHRH 起经常性的调节作用。

    * GH 对下丘脑和腺垂体存在负反馈调节。

* 脉冲式分泌与睡眠

    * 在双重调节下 GH 呈脉冲式分泌；夜间睡眠时的分泌明显高于白天觉醒——总量、峰值高度、峰值密度都更高；慢波睡眠状态下分泌达最高值。

    * 生活佐证：睡眠好的婴儿 GH 分泌总量一定比常不好好睡觉的孩子多，将来有可能长得更高更壮。

* 代谢物与肥胖的影响

    * 低血糖促进 GH 分泌，氨基酸促进分泌，脂肪酸减少分泌。

    * 肥胖减少分泌：体质指数（BMI）高达 46 的肥胖症患者，GH 分泌的总量、峰值、频率都远低于正常体重者——婴幼儿、青少年期过度肥胖会影响将来身高。

## 甲状腺激素

### 合成、储存与释放

* **甲状腺（thyroid gland）**

    * 人体内最大的内分泌腺，位于颈前；由滤泡组成——滤泡上皮是甲状腺激素合成与释放的部位，滤泡腔中的胶质是储存库。

    * 功能不活跃时上皮细胞呈扁平状、胶质多；受刺激功能活跃时细胞变高柱状、胶质减少。

* **T4 与 T3 的对比**

    * T4（四碘甲腺原氨酸）占甲状腺激素分泌总量的 93%；T3（三碘甲腺原氨酸）只占 7%，但生物活性是 T4 的 5 倍。

    * 激素要起作用必须变成游离型：T4 以结合型为主，T3 以游离型为主，游离型 T3 更有利于快速发挥生物学活性。

| 比较项 | T4（四碘甲腺原氨酸） | T3（三碘甲腺原氨酸） |
| :--- | :--- | :--- |
| 占分泌总量 | 93% | 7% |
| 生物活性 | 较低（T3 是它的 5 倍） | 高，约为 T4 的 5 倍 |
| 起效特点 | 缓慢而持久 | 快而迅速 |
| 半衰期 | 约 7 天 | 约 1.5 天 |
| 更新率 | 缓慢 | 快得多 |
| 血中主要存在形式 | 结合型为主 | 游离型为主 |
| 甲状腺外分布 | 多 | 少 |

* **反 T3（逆 T3）**

    * T3 的碘原子在 3、5、3′ 位，逆 T3 在 3、3′、5′ 位，仅这一点结构差别使其生物活性只有 T3 的 5%。

    * 正常情况下含量很少；饥饿、应激状态时升高，使机体能耗下降、节省能量。

* 合成原料与关键酶

    * 原料两种：碘与甲状腺球蛋白——甲状腺球蛋白在甲状腺上皮细胞中合成后送入滤泡腔，碘原子加到其上形成 T3 或 T4。

    * 关键酶：甲状腺过氧化物酶（TPO），参与氧化、碘化、偶联各个环节；治疗甲亢的常用药物就是通过抑制 TPO 阻断 T3、T4 的合成。

* 合成四步：聚碘 → 活化 → 碘化 → 偶联

    * 聚碘：甲状腺内碘离子浓度为血清的 30 倍，带负电荷的碘离子逆电化学梯度进入滤泡上皮细胞，是主动摄取（碘的捕获）、消耗大量能量；经钠碘同向转运体把碘和钠同向转入细胞，属继发性主动转运；哇巴因抑制钠泵则聚碘障碍；TSH 也能促进聚碘。

    * 临床应用：口服放射性核素碘-131 后用放射线追踪，看是否被甲状腺绝大部分摄取，据此判断甲状腺聚碘能力与功能状态。

    * 活化：无机碘离子没有活性，不能直接用于合成，必须先经 TPO 氧化成有活性的碘原子。

    * 碘化：活性碘原子在 TPO 参与下加到甲状腺球蛋白的酪氨酸上（酪氨酸碘化）。

    * 偶联：碘化产物再缩合，生成 T3 与 T4。

* 储存

    * 合成后大量储存在滤泡腔内，可供机体使用 50~120 天（约四个月）。

    * 抗甲状腺药物（如 TPO 抑制剂）虽抑制合成但不能立即见效——须等滤泡腔库存激素消耗完作用才逐渐体现，疗程至少三个月以上。

* 释放与运输

    * 释放：上皮细胞以吞饮方式把胶冻样胶质吞入胞内 → 溶酶体水解酶水解甲状腺球蛋白 → T3、T4 水解脱落 → T3、T4 为脂溶性激素，进入血液。

    * 运输：血中以结合型与游离型两种形式存在；T4 发挥作用时大部分先转变成游离型 T3；T3 既可以来自外周组织中 T4 的脱碘，也可以直接来自甲状腺的释放。

    * 结合型的意义：临时储存库——缓冲甲状腺分泌活动的急剧变化，并防止 T3、T4 在肾脏被滤过、过快丢失。

```text
血中 I⁻ ──钠碘同向转运体──→ 滤泡上皮细胞              【聚碘】
  （甲状腺内碘浓度约为血清 30 倍，逆电化学梯度、耗能）
无机碘离子 ──TPO 氧化──→ 活性碘原子                    【活化】
活性碘原子 ──TPO──→ 加到甲状腺球蛋白的酪氨酸上          【碘化】
碘化产物缩合生成 T3、T4（仍连在甲状腺球蛋白上）         【偶联】
滤泡腔胶质 = 储存库（可供机体 50~120 天）
机体需要时：上皮细胞吞饮 → 溶酶体水解酶水解 → T3、T4 释放入血
```

### 生物学作用

* 产热效应

    * 用甲状腺激素后，心脏、胃黏膜、肝脏等绝大多数脏器产热明显增加，基础代谢率升高：1 mg T4 可使机体产热增加 1000 千卡、基础代谢率增加 28%。

    * 甲亢患者基础代谢率可超过正常值 50%~100%，怕热、易出汗；甲减患者可低于正常 30%~45%，非常怕冷。

* 对蛋白质代谢（剂量决定方向）

    * 生理剂量促进蛋白质合成，呈正氮平衡，利于机体生长发育与各种功能活动；剂量过大促进蛋白质分解，呈负氮平衡。

    * 甲亢：以骨骼肌为主的外周组织蛋白分解加速 → 尿酸含量增加、尿氮排泄增加、肌肉收缩无力。

    * 甲减：蛋白质合成障碍 → 组织间黏蛋白沉积、水滞留皮下 → 黏液性水肿，面容呈「虚胖」感。

* 对脂肪与胆固醇代谢

    * 增强脂肪代谢所有环节——既促进脂肪合成也促进分解，加速脂肪代谢速率。

    * 胆固醇：既增加合成也促进分解，但促降解的作用大于促合成 → 甲亢血胆固醇低于正常；甲减血胆固醇升高，易发生动脉粥样硬化。

* 对糖代谢（双向）

    * 生理剂量促进机体对糖的利用，使血糖降低；大剂量促进糖的吸收、促进糖原分解，使血糖升高。

    * 甲亢：餐后血糖升高快（促吸收）甚至出现糖尿，又能很快下降（高水平激素促进外周组织利用）。

* 对生长发育：呆小症

    * 主要影响脑和长骨的发育——影响脑即影响智力，影响长骨即影响身高。

    * 幼年甲状腺激素缺乏 → 长不高、身材矮小，且大脑发育障碍导致智力障碍，称呆小症（又小又呆）。

    * 出生三个月后再补充甲状腺激素一般很难有效，重在预防：从妊娠期妇女抓起，普遍缺碘地区的妇女更应普查甲状腺功能。

* 对神经系统

    * 使交感活动亢进、增加神经系统兴奋性，并影响学习和记忆过程。

    * 甲亢：紧张、易激动、脾气暴躁、失眠多梦、注意力无法集中；甲减：表情淡漠、言语行动迟钝、嗜睡。

* 对心血管系统

    * 心率增快、心肌收缩增强 → 心输出量增多 → 收缩压升高；代谢增加使代谢产物增多 → 外周血管舒张 → 外周阻力下降 → 舒张压降低。

* 对消化与生殖系统

    * 增加消化道运动和消化腺分泌：甲亢常伴顽固性吸收不良腹泻（吃得多但不吸收，是消瘦原因之一）；甲减常有腹胀、便秘。

    * 维持正常月经和泌乳；甲状腺激素过高或过低都会对生育产生重要影响。

| 方面 | 甲亢（激素过多） | 甲减（激素不足） |
| :--- | :--- | :--- |
| 基础代谢率 | 超过正常值 50%~100% | 低于正常 30%~45% |
| 冷热感受 | 怕热、易出汗，冬天单衣还出汗 | 怕冷，夏天也穿棉袄 |
| 蛋白质代谢 | 分解加速：尿酸增加、尿氮增多、肌肉收缩无力 | 合成障碍：黏蛋白沉积、黏液性水肿 |
| 血胆固醇 | 低于正常 | 升高，易发生动脉粥样硬化 |
| 神经精神 | 紧张、易激动、失眠多梦、注意力难集中 | 表情淡漠、行动迟钝、嗜睡 |
| 消化道 | 顽固性吸收不良腹泻、消瘦 | 腹胀、便秘 |

### 分泌的调节

* 下丘脑-腺垂体-甲状腺轴

    * 下丘脑分泌促甲状腺激素释放激素（TRH）→ 促进腺垂体分泌促甲状腺激素（TSH）。

    * TSH 两大作用：促进甲状腺激素的合成和释放；刺激甲状腺腺泡细胞增生——TSH 增多时甲状腺激素分泌增加、腺泡增大、甲状腺外观肿大。

    * 血中游离 T3、T4 达到一定水平时，对 TRH 和 TSH 产生负反馈，构成 T3、T4 分泌的自动控制环路，维持血中甲状腺激素水平相对稳定与甲状腺正常生长。

* 地方性甲状腺肿（大脖子病）的机理

    * 食物长期缺碘 → 血碘不足、合成原料不够 → T3、T4 合成大大减少、血中处于低水平 → 对腺垂体的负反馈大大解除 → 腺垂体分泌大量 TSH → 长期刺激甲状腺滤泡不断增生 → 甲状腺明显肿大。

* **自身调节与 Wolff-Chaikoff 效应**

    * > **定义**：甲状腺对一定范围内血碘浓度的变化，自身调整摄取碘以及合成、释放甲状腺激素能力的适应性调节。

    * 血碘过高时 T3、T4 的合成和分泌都受到抑制，这种过量碘产生的抗甲状腺效应称 Wolff-Chaikoff 效应。

    * 应用：甲亢症状严重时服用高浓度碘剂，利用该效应暂时抑制 T3、T4 的分泌（让库存激素「不出来」），可快速控制症状——与起效慢的抗合成药物互补。

* 神经调节

    * 交感神经促进甲状腺的功能，副交感神经抑制其功能。

## 肾上腺皮质与糖皮质激素

### 皮质结构与生命必要性

* 肾上腺皮质三带

    * 肾上腺位于两侧肾脏顶端，分皮质与髓质两部分；皮质分三个细胞带：球状带合成盐皮质激素（代表为醛固酮）、束状带主要合成糖皮质激素、网状带主要合成性激素。

    * 糖皮质激素由束状带与网状带合成分泌。

* 肾上腺皮质是维持生命所必需

    * 摘除动物双侧肾上腺、不做适当处理，一两周内动物即死去；只切除髓质则可存活较长时间。

    * 摘除皮质后的两条死因：水盐丢失严重、血压降低、循环衰竭（缺乏盐皮质激素）；糖、蛋白质、脂肪三大物质代谢严重紊乱、对各种有害刺激的抵抗力降低（缺乏糖皮质激素）。

### 对物质代谢的作用

* 对糖代谢

    * 糖异生：将体内非糖物质转化成为糖的过程。

    * 促糖异生的两手：促进蛋白质分解、让较多氨基酸进入肝脏；增强肝内与糖异生有关的酶的活性。

    * 抗胰岛素：抑制胰岛素与受体结合，从而抑制外周组织对糖的利用。

    * 结果：分泌不足 → 低血糖；分泌过多或大量服用此类激素 → 血糖升高甚至出现尿糖，此类尿糖称类固醇性尿糖。

* 对蛋白质代谢

    * 促进肝外组织蛋白质分解（为糖异生提供更多原料），特别促进肌肉组织中蛋白质的分解。

    * 分泌过多：生长停滞、肌肉消瘦无力、皮肤菲薄、骨质疏松、淋巴组织萎缩、伤口愈合延缓。

* 对脂肪代谢与向心性肥胖

    * 主要促进脂肪分解；皮质功能亢进时出现脂肪重新分布——四肢脂肪组织分解增强，头面部、肩部、背部促进脂肪合成。

    * 结果形成头面部脂肪堆积（满月脸）、背部堆积（水牛背）、腹部隆起（将军肚）而四肢相对消瘦的特殊体型——向心性肥胖，临床上统称 Cushing 综合征。

    * 皮肤紫纹成因：皮肤的生长跟不上皮下脂肪堆积所需的空间，真皮下组织被撕裂（与妊娠纹形成原理一致）。

### 水盐、血细胞与心血管

* 对水盐代谢

    * 皮质醇有类似醛固酮的保钠排钾作用，但活性只有醛固酮的 1/400。

    * 增加肾小球滤过率、减少肾小管对水的重吸收，有利于水的排出；皮质功能不足患者排水能力明显受损，严重时出现水中毒——补充糖皮质激素可缓解，补充盐皮质激素无效。

* 对血细胞（增多机制两样、减少另有通路）

    * 增多方：红细胞和血小板——直接促进骨髓造血；中性粒细胞——促进附着在血管壁上的中性粒细胞释放到外周血；两者都增多但途径完全不同。

    * 减少方：淋巴细胞与嗜酸性粒细胞——抑制淋巴细胞有丝分裂、促进其凋亡，并增加两者在脾脏和肺脏的破坏。

    * 皮质功能亢进者因皮肤变薄、红细胞增多，出现「多血质外貌」——红光满面的病理面容。

* 对心血管

    * 允许作用：增强血管平滑肌对儿茶酚胺（以肾上腺素、去甲肾上腺素为主）的敏感性，使其对血管产生强烈收缩效应。

    * 降低毛细血管通透性，有利于维持血容量；皮质功能降低时血管平滑肌对儿茶酚胺的反应性降低、毛细血管扩张且通透性增加、循环血压下降。

    * 离体体外实验证明还能增强心肌收缩能力。

* 对胃黏膜与神经系统

    * 促进胃酸和胃蛋白酶分泌、抑制胃粘液分泌——破坏因素增强、保护因素减少，可诱发或加剧胃溃疡；用药前应询问胃病史，必要时同时给胃黏膜保护药物。

    * 提高中枢神经系统兴奋性：小剂量引起欣快感；剂量过大引起思维无法集中、烦躁不安、失眠。

### 应激反应与应急反应

* **应激反应（stress）**

    * > **定义**：机体受到各种有害刺激时，引起的以 ACTH 与糖皮质激素分泌增加为主的一系列非特异性反应；由加拿大科学家 Selye 提出。

    * 受伤害性刺激（如外伤）后，血浆糖皮质激素浓度约 5 分钟内升至峰值并维持较高水平。

    * 三方面作用：减少缓激肽、蛋白水解酶、前列腺素等有害物质的产生，减轻对机体的伤害；升高血糖，保证危机状态下心、脑等重要脏器的功能（大脑几乎完全依赖葡萄糖供能）；允许作用使去甲肾上腺素更好发挥作用，对血压维持至关重要。

* **应急反应（emergency reaction）**

    * > **定义**：机体在紧急状态下发生的、以交感-肾上腺髓质活动增强为主的反应；由 Cannon 提出。

    * 紧急状态下交感神经活动增强，肾上腺髓质释放的去甲肾上腺素和肾上腺素增加，提高机体在紧急状态下的耐受力和敏捷性。

    * > **易错点**：应激的「激」与应急的「急」是两个字、两个概念——应激以 ACTH 和糖皮质激素分泌增加为主，应急以肾上腺髓质分泌增加为主；机体遇到伤害性刺激时两个反应同时发生、协同抗打击，不是二选一 ⚠️

```text
              伤害性刺激（如外伤）
                      │
        ┌─────────────┴─────────────┐
        ↓                           ↓
  应激反应 stress              应急反应 emergency
 ACTH 与糖皮质激素分泌增加     交感-肾上腺髓质活动增强
 约 5 分钟内升至峰值并维持      儿茶酚胺急剧升高
        │                           │
        └─────────────┬─────────────┘
                      ↓
           两个反应同时发生，协同抗打击
```

### 分泌调节与临床用药

* 下丘脑-腺垂体-肾上腺皮质轴

    * 下丘脑某些神经核团合成促肾上腺皮质激素释放激素（CRH）→ 促使腺垂体分泌促肾上腺皮质激素（ACTH）→ ACTH 作用于肾上腺皮质，使糖皮质激素分泌。

    * ACTH 经常性调控糖皮质激素的基础分泌与应激状态下的分泌，还刺激束状带、网状带细胞的生长发育：切除垂体 → 两带萎缩、分泌显著减少；及时补充 ACTH → 已萎缩的两带基本恢复正常、分泌回升。

    * 负反馈：糖皮质激素对腺垂体和下丘脑都产生负反馈，ACTH 也对下丘脑产生负反馈——维持血中糖皮质激素水平相对稳定。

    * 应激例外：应激状态下血中出现高水平的 ACTH 与糖皮质激素，其升高完全不受轴负反馈的影响。

* 长期用糖皮质激素为什么不能突然停药

    * 机理链：长期外源性糖皮质激素 → 血中高水平对下丘脑、腺垂体产生负反馈抑制 → 内源性 ACTH 分泌减少 → 肾上腺皮质束状带、网状带萎缩 → 突然停药后萎缩的皮质不能立即合成内源性激素 → 肾上腺皮质功能低下（正常血压不能维持、各种代谢紊乱）。

    * 对策：逐渐减量停药，让负反馈作用逐渐减弱；或停药前适当补充外源性 ACTH，促进肾上腺皮质结构和功能恢复。

* 昼夜节律与早晨八点给药

    * 分泌的昼夜节律：早上八点达一天中最高峰，午夜 12 点降至最低值，每天如此循环。

    * 节律来源：血中 ACTH 和 CRH 也有昼夜节律；切除肾上腺皮质后 ACTH 分泌节律仍存在——说明 ACTH 调控糖皮质激素的节律，而 ACTH 自身节律不受糖皮质激素反馈影响，提示早晨 ACTH 对糖皮质激素的反馈抑制不敏感。

    * 应用：按体内分泌规律每天早晨八点给药，此时给药对内源性 ACTH 影响不大，可减少机体激素分泌昼夜节律被干扰的程度。

## 胰岛与血糖调节

### 胰岛细胞构成

* **胰岛**

    * 成小岛状散在分布于胰腺外分泌腺泡之间的内分泌细胞团，约占整个胰腺总体积的 1%，却是机体最重要的内分泌器官之一。

| 细胞类型 | 分泌激素 | 占胰岛细胞总数 |
| :--- | :--- | :--- |
| β细胞 | 胰岛素 | 70%（数量最多） |
| α细胞 | 胰高血糖素 | 25% |
| δ细胞 | 生长抑素 | 少量 |
| PP细胞（F细胞） | 胰多肽 | 少量 |

### 胰岛素

* **胰岛素（insulin）**

    * > **定义**：机体内唯一能降低血糖的激素，是促进物质合成代谢、维持血糖水平稳态的关键激素。

    * 降血糖的总策略：减少血糖的来源，增加血糖的去路。

* 增加去路（三条）

    * 促进全身组织细胞摄取和氧化葡萄糖。

    * 促进肝糖原、肌糖原的合成和储存。

    * 促进葡萄糖转变为脂肪酸，储存在脂肪组织中。

* 减少来源（两条）

    * 抑制肝内糖异生，减少糖的释放。

    * 减少脂肪动员。

* 促进葡萄糖入胞的实验与机理

    * 培养实验：无胰岛素时，无论细胞外葡萄糖浓度多高，细胞内葡萄糖浓度都没有很大变化；加入胰岛素后，细胞内糖随细胞外浓度增加而逐渐增长——证明胰岛素促进葡萄糖进入细胞。

    * 机理：葡萄糖进入细胞必须有相应的葡萄糖转运体；胰岛素与受体结合后，葡萄糖转运体才得以发挥把葡萄糖转运进细胞的作用。

* 典型的促合成激素

    * 脂肪代谢：促进脂肪合成、抑制脂肪分解；蛋白质代谢：促进蛋白质合成、抑制蛋白质分解——把氨基酸运进细胞，并促进 DNA 复制、RNA 转录和翻译。

    * 与生长激素协同促进生长：切除动物的胰腺和腺垂体 → 生长停止；单给生长激素或单给胰岛素 → 几乎都不再生长；同时给予两者 → 体重呈增长趋势。

* 分泌的调节

    * 血糖浓度首当其冲：高糖刺激下血浆胰岛素呈两阶段变化——早期快速而短暂的升高（β 细胞储存的胰岛素快速释放），经短暂下降后逐渐升高并稳定在较高水平（依赖 β 细胞继续合成和释放）；血糖升高既刺激胰岛素的分泌、也刺激其合成。

    * 氨基酸也促进胰岛素分泌。

    * 激素调节：抑胃肽、胰高血糖素可直接促进分泌，生长激素直接抑制；所有能升高血糖的激素（生长激素、皮质醇、甲状腺激素等）都通过升高血糖间接促进分泌。

    * 口服葡萄糖比静脉注射等量葡萄糖引起更明显的胰岛素释放——口服除升高血糖外，还刺激胃肠道释放抑胃肽，直接促进胰岛素分泌。

    * 神经调节：交感神经兴奋抑制分泌，迷走神经兴奋促进分泌。

    * 临床联系：正常人进食后 1 小时血糖达峰值、2 小时回到基础水平；糖尿病患者因胰岛功能障碍，血糖升幅更大且 2 小时内不能回基础；空腹血糖正常但餐后血糖 2 小时不能回基础者，胰岛功能也有问题——监测餐后血糖是了解胰岛功能的重要手段。

### 胰高血糖素

* **胰高血糖素（glucagon）**

    * 由胰岛 α 细胞合成；生物学作用是升高血糖，通过促进糖原分解和糖异生实现。

    * 对脂肪促进分解；对蛋白质抑制合成——把氨基酸转作糖异生原料用于升血糖。

    * 分泌调节：血糖、氨基酸、脂肪酸直接影响；胰岛分泌的生长抑素和胰岛素经旁分泌直接抑制；胃泌素、胆囊收缩素等胃肠激素促进；交感神经兴奋促进、迷走神经兴奋抑制——与胰岛素正相反。

| 比较点 | 胰岛素 | 胰高血糖素 |
| :--- | :--- | :--- |
| 来源细胞 | β细胞 | α细胞 |
| 对血糖 | 唯一降血糖 | 升血糖（糖原分解＋糖异生） |
| 脂肪代谢 | 促合成、抑分解 | 促分解 |
| 蛋白质代谢 | 促合成、抑分解 | 抑制合成，氨基酸转作糖异生原料 |
| 交感神经 | 抑制分泌 | 促进分泌 |
| 迷走神经 | 促进分泌 | 抑制分泌 |

## 卵巢与女性生殖

### 生卵作用与卵巢周期

* **卵巢的生卵作用**

    * 卵巢是女性生殖系统的主性器官，成熟后最基本的生殖功能是生卵；原始卵泡在胚胎形成早期就已存在，临近青春期才开始发育。

    * 每个月只有一批卵泡发育，其中通常只有一个发育成熟并以排卵的形式排出，其余在不同阶段闭锁；从卵泡发育到排卵、黄体形成到萎缩正好一个月。

* **卵巢周期**

    * > **定义**：卵巢生卵功能的规律性周期变化；以排卵为界分两期——排卵前为卵泡期、排卵后为黄体期，前后各 14 天。

```text
原始卵泡 → 初级卵泡 → 次级卵泡 → 成熟卵泡 → 破裂排卵 → 黄体 →（未受精）萎缩退化 → 白体
```

* **雌激素合成的双重细胞学说**

    * > **定义**：排卵前雌激素的合成和分泌，由成熟卵泡中内膜细胞和颗粒细胞共同参与完成。

    * 排卵前孕激素由内膜细胞和颗粒细胞均能合成分泌；排卵后两者分别转变为黄体中的膜黄体细胞与粒黄体细胞——膜黄体细胞分泌大量雌激素，粒黄体细胞分泌大量孕激素。

* 对代谢的作用

    * 骨骼：促进多种蛋白质合成、增强成骨细胞活动、促进钙盐沉积和骨骺愈合——青春期女孩身高增长比男孩来得早，但促进骨骺愈合又加速骨骼生长停止，女孩长得早、停得也早。

    * 血脂：降低体内胆固醇——生殖年龄段女性冠心病发病率显著低于同年龄段男性；更年期后雌激素下降，冠心病发病率不再有性别差异。

    * 水盐代谢：促进醛固酮分泌、促进肾小管对钠和水的重吸收 → 钠水潴留；有些女性在月经前 7~14 天（黄体期）雌、孕激素水平高，全身液体潴留，出现水肿、头痛、腹胀，称经前期综合征。

    * 老年性阴道炎：雌激素水平长时间大大下降（如老年妇女）时，阴道的酸性环境被大大削弱——这是老年性阴道炎常见的原因之一。

### 孕激素

* **孕激素（progestogen）**

    * 排卵后随黄体成熟大量分泌，与雌激素一收一放配合，核心是为受精卵着床保驾护航。

* 对生殖通道的作用

    * 子宫两面性：抑制子宫运动，保证受精卵的稳定着床及妊娠期间胎儿居住环境的安稳；在雌激素作用基础上使子宫内膜进一步增厚、内膜腺体分泌增加。

    * 抑制输卵管的收缩；减少宫颈粘液分泌、增大其稠度，使精子难以通过；此时宫颈涂片风干后镜下呈椭圆形结晶——与雌激素水平高时的羊齿植物叶状结晶截然不同，宫颈涂片因此成为快速判断雌、孕激素水平的简易手段。

* 乳腺与基础体温

    * 在雌激素基础上促进乳腺腺泡的发育和成熟，为分娩后泌乳做准备——雌激素管导管、孕激素管腺泡。

    * 升高基础体温：排卵后基础体温升高 0.5℃ 左右并在整个黄体期维持较高水平，称基础体温的双向性，可作为判定排卵的指标之一；曲线呈单向性则提示没有排卵——在家监测体温即可初步判断有无排卵。

| 作用对象 | 雌激素 | 孕激素 |
| :--- | :--- | :--- |
| 子宫平滑肌 | 促进增生增厚 | 抑制运动 |
| 子宫内膜 | 促进增生 | 在雌激素基础上进一步增厚、腺体分泌 |
| 输卵管 | 促进运动 | 抑制收缩 |
| 宫颈粘液 | 量多、稀薄清亮、拉丝度强，涂片呈羊齿植物叶状结晶 | 分泌减少、稠度增大，涂片呈椭圆结晶 |
| 乳腺 | 促进导管增生发育 | 在雌激素基础上促进腺泡发育成熟 |
| 基础体温 | — | 排卵后升高约 0.5℃，维持整个黄体期 |

### 月经与子宫内膜周期

* **月经（menstruation）**

    * > **定义**：生育年龄妇女子宫内膜周期性脱落以及出血的现象，即周期性的子宫出血。

    * 有规律的月经周期的存在，是女性生殖功能成熟的外在指标之一。

* **月经周期（menstrual cycle）**

    * > **定义**：两次月经第一天之间所间隔的时间（以 28 天周期为例分三期）。

| 时期 | 时间跨度 | 主要特点 |
| :--- | :--- | :--- |
| 月经期 | 第 1~5 天（月经开始到停止） | 子宫内膜的坏死、脱落和出血 |
| 增殖期 | 第 6~14 天（月经停止到卵巢排卵） | 子宫内膜的修复和增生 |
| 分泌期 | 第 15~28 天（排卵到下次月经来潮） | 内膜进一步增厚，腺体开始呈现分泌现象 |

* 内膜脱落的机理与痛经

    * 月经期子宫内膜中的螺旋小动脉发生痉挛性收缩 → 内膜缺血 → 坏死、脱落、出血。

    * 起因是月经期子宫合成前列腺素增多——经血中含有前列腺素，此时子宫内膜中前列腺素含量最高；它还作用于子宫肌层使肌纤维收缩，加重子宫缺血。

    * 痛经即月经期伴有痉挛性腹痛的症状；可采用前列腺素合成的抑制剂（消炎痛一类药物）缓解。

### 卵巢周期对子宫内膜的调控

* 核心证据与通路

    * 因疾病切除卵巢的病人不再有月经、内膜不再周期性变化——卵巢就是子宫内膜发生周期性出血的原因。

    * 激素通路：卵泡生长发育过程以分泌雌激素为主，排卵后黄体同时分泌大量雌激素和孕激素；雌激素引起子宫内膜增生，孕激素在雌激素基础上引起内膜进一步增生和分泌。

    * 结论：月经周期中子宫内膜的周期性变化完全受卵巢周期调控——卵巢周期性变化导致血浆中雌、孕激素水平周期性改变，从而调控子宫内膜发生周期性变化与出血。

* 一个月经周期的推演

    * 月经期：卵泡还处于初级卵泡状态、不具备分泌性激素的能力，血中雌、孕激素浓度很低。

    * 增殖期：卵泡发育并分泌渐增的雌激素，排卵前卵泡完全成熟、雌激素最多——形成第一个雌激素高峰；内膜修复增生、血管增生、腺体数目增加；增殖期末排卵发生。

    * 排卵后：卵泡破裂使雌激素浓度下降；黄体形成并发育成熟，孕激素升到全周期的峰值、雌激素出现第二个峰值；内膜转为分泌期——进一步增厚、血管增长扩张、腺体扩大并开始分泌粘液，为受精卵着床和发育准备条件。

    * 分泌期末：卵子未受精 → 黄体萎缩 → 性激素水平骤降 → 高度增生的内膜失去支持，再次坏死、脱落、出血进入下一个月经期；激素下降同时解除对上级中枢的负反馈，新一批卵泡又开始发育——周而复始。

```text
天数        1             5    6                     14 15                      28
            |───月经期────|────|───────增殖期──────────|───|─────────分泌期─────────|
子宫内膜    坏死、脱落、出血     修复、增生               进一步增厚、腺体分泌
卵巢        初级卵泡            卵泡发育成熟→排卵        黄体形成→成熟→萎缩
血中激素    雌孕激素低水平      雌激素渐增→第一峰        孕激素峰＋雌激素第二峰→骤降
```

* **人工周期（人工月经周期）**

    * > **定义**：人为地按照卵巢生理活动的规律补充外源性雌激素和孕激素，形成子宫内膜的周期性变化、促使月经产生的方法。

    * 操作：给闭经患者连续口服雌激素 20 天，最后 5~7 天加用孕激素，然后突然停药——模仿机体内性激素周期性变化的规律。

    * 判读：给予人工周期后仍无月经 → 子宫本身发生病变；能诱发月经来潮 → 子宫内膜健康，病变在子宫以上（卵巢，或腺垂体、下丘脑），需沿轴逐级排查。

### 下丘脑-腺垂体-卵巢轴

* **FSH 与 LH**

    * 腺垂体分泌两种促性腺激素：卵泡刺激素（FSH）主要刺激卵泡的生长发育；黄体生成素（LH）主要促进排卵以及黄体的形成。

    * 周期中的分配：卵泡期 FSH 水平相对较高，与 LH 共同促使初级卵泡生长发育；排卵后 LH 处于相对较高水平，维持黄体的发育和功能；LH 高峰一般只维持 24 小时左右。

    * 临床证据：垂体瘤病人常出现卵巢失去生卵功能、无月经——卵巢活动的周期性变化受腺垂体调控；摘除腺垂体的动物注射外源性 LH 就能诱发排卵，排卵预测的原理就是检测 LH 峰值的出现。

* 雌激素的浓度依赖性反馈

    * 低浓度时对上级中枢产生负反馈——腺垂体分泌的 FSH 减少。

    * 排卵前雌激素达到周期第一个峰值时，高浓度产生特殊的正反馈——促进腺垂体分泌促性腺激素，血中出现 LH 峰和 FSH 峰。

    * 孕激素只有负反馈作用；雌、孕激素浓度都升高时两者协同，负反馈更强烈，FSH、LH 的分泌降到最低值。

    * > **易错点**：同样是雌激素，低浓度是「刹车」（负反馈），排卵前的高峰却是「油门」（正反馈）——作用方向取决于浓度，这是性腺轴调节里最特殊的一笔 ⚠️

* 激素接力全程

    * 月经期：上一个月经周期末黄体萎缩，雌、孕激素骤降，解除对下丘脑和腺垂体的负反馈 → FSH 率先回升，1~2 天后 LH 跟着上升，两者促使初级卵泡生长发育。

    * 卵泡期：卵泡分泌雌激素渐增，负反馈使 FSH 出现一个下降的过程。

    * 排卵前：雌激素第一峰触发正反馈 → 腺垂体分泌大量促性腺激素，LH 显著增加形成高峰、FSH 形成相对较低的峰；两种激素以适当比例作用，排卵发生。

    * 黄体期：LH 高峰维持约 24 小时后下降；此后 FSH、LH 浓度都相对较低，正是低水平的 LH 维持黄体的发育与功能。

    * 分泌期末：黄体成熟使雌、孕激素同时达高峰 → 负反馈使 FSH、LH 分泌进一步减少 → 黄体萎缩，回到月经期，循环闭合。

* **下丘脑与性腺轴**

    * 下丘脑分泌促性腺激素释放激素（GnRH）调控腺垂体；下丘脑是将外界信息传递到性腺轴的关键部位。

    * 环境改变、高强度排练、精神极度焦虑等都通过神经系统作用于下丘脑的 GnRH 而影响月经规律（月经失调）；雌、孕激素的正反馈与负反馈对下丘脑同样有效。

    * 下丘脑-腺垂体-卵巢轴又称性腺轴：卵巢周期性生卵 → 性激素周期性分泌 → 月经与月经周期；卵巢活动又受腺垂体与下丘脑调控，三者相互作用、相互制约。

```text
大脑皮层／外界环境（环境改变、精神压力、情绪波动）
        │
        ↓
下丘脑 ──GnRH──→ 腺垂体 ──FSH、LH──→ 卵巢（生卵＋分泌雌、孕激素）
   ↑                                     │
   │            雌激素、孕激素            │
   └────────── 反馈调节（＋或－）←────────┘
```

* 青春期前无月经与更年期绝经

    * 青春期前：下丘脑 GnRH 神经元对雌、孕激素负反馈的敏感性太高 → GnRH 分泌很少 → 腺垂体 FSH、LH 水平非常低 → 卵巢的生卵作用无法启动；青春期后机体发育成熟，经性腺轴调节产生月经周期。

    * 更年期：卵巢功能逐渐衰退，剩余的卵泡不再对促性腺激素发生反应 → 卵泡不再发育、不再分泌雌激素 → 月经停止（绝经）。

## 睾丸与男性生殖

### 生精作用

* **生精作用**

    * 睾丸是男性的主性器官，产生精子在睾丸的曲细精管内完成；曲细精管上皮由生精细胞（精子形成各阶段细胞的总称）和支持细胞共同构成。

    * 青春期开始后，原始的生精细胞——精原细胞——开始分裂；流程为：精原细胞 ─多次有丝分裂→ 初级精母细胞 ─减数分裂→ 次级精母细胞 → 精子细胞 → 精子。

* **生精周期**

    * > **定义**：从精原细胞发育成为精子的整个过程；人类平均需要两个半月左右。

* 温度与生精条件

    * 精子生成和存活的适宜温度比体温低 1~2℃；阴囊内温度比腹腔内低 2℃ 左右，具备良好降温效应。

    * 隐睾：胎儿在子宫发育后期睾丸未正常降入阴囊、停留在腹腔 → 长期处于温度过高的环境，严重影响精子生成和发育，可导致男性不育。

    * 长期吸烟、过量饮酒、放射线、某些药物等因素也可影响男性精子的生成。

### 睾丸的内分泌

* **睾酮（testosterone）**

    * 由睾丸间质细胞分泌的雄激素中最主要的化学形式（间质细胞还分泌少量雌激素）。

    * 三项本职：促进精子生成、维持睾丸的生精作用；刺激男性生殖器官的生长发育、促进并维持男性第二性征；维持男性正常性欲——睾丸功能低下者血中雄激素水平低，常出现阳痿和性欲降低，给予雄激素治疗往往疗效较好。

    * 代谢「副业」：促进蛋白质合成、促进骨骼生长和钙磷沉积（男性肌肉比女性发达、平均身高高于女性）；促进红细胞生成；增加肌肉收缩的力量和速度——运动员兴奋剂中雄激素衍生物是目前使用范围最广、频率最高的一类，也是赛前药检的重点排查对象。

* **抑制素**

    * 由曲细精管上皮的支持细胞分泌；主要抑制腺垂体 FSH 的分泌，对 LH 的分泌没有影响。

* **雄激素结合蛋白**

    * 支持细胞分泌；与睾酮结合，维持曲细精管局部睾酮的高浓度，从而促进生精作用。

### 下丘脑-腺垂体-睾丸轴

* 轴的构成

    * 下丘脑分泌 GnRH → 促使腺垂体细胞合成、分泌 FSH 和 LH。

    * 在男性：LH 主要促进睾酮的合成和分泌；FSH 可增强 LH 的作用；FSH 还作用于支持细胞，促进抑制素和雄激素结合蛋白的分泌。

* 反馈调节（四个实验各钉死一条通路）

    * 切除睾丸的动物体内 GnRH 水平明显升高 → 睾酮对下丘脑产生负反馈抑制。

    * 体外培养的垂体细胞中加入外源性睾酮 → LH 分泌减少 → 睾酮可抑制腺垂体的功能。

    * 培养的支持细胞中加入 FSH → 抑制素分泌增加 → 腺垂体 FSH 促进睾丸中抑制素的分泌。

    * 给动物注射抑制素 → FSH 分泌减少 → 抑制素通过负反馈调节抑制腺垂体、减少 FSH 的合成。

    * > **易错点**：反馈各有选择性——睾酮只对 LH 产生负反馈抑制、对 FSH 没有抑制；雌激素正好相反，只对 FSH 产生负反馈作用、对 LH 没有抑制效应，两条通路不要张冠李戴 ⚠️

```text
下丘脑 ──GnRH──→ 腺垂体 ──┬── LH ──→ 间质细胞：合成、分泌睾酮
                          │            （FSH 还能增强 LH 的作用）
                          └── FSH ─→ 支持细胞：分泌抑制素、雄激素结合蛋白

负反馈：睾酮  ──选择性──→ 抑制 LH（对 FSH 没有抑制）
        抑制素 ──选择性──→ 抑制 FSH（对 LH 没有影响）
```

* 生精的激素调节

    * 给动物注射 FSH → 生精细胞数目增加 → FSH 有促进生精的作用。

    * 成年动物切除垂体后给予外源性睾酮，仍能看到精子生成（精原细胞已启动分裂）→ 睾酮可维持生精；幼年动物切除垂体后即使给予外源性睾酮，也看不到精子生成（精原细胞尚未启动）。

    * 结论：FSH 可以启动生精作用，睾酮只能维持生精作用；LH 没有直接刺激精子生成的功能，通过促进睾酮分泌间接起到生精作用。

| 激素 | 在男性生殖中的主要角色 |
| :--- | :--- |
| LH | 刺激睾丸中睾酮的生成 |
| FSH | 启动和维持生精作用 |
| 睾酮 | 维持生精作用；选择性负反馈抑制 LH |
| 抑制素 | 选择性抑制 FSH |
