## 高分笔记与通关880的使用方法——兼讲蛋白质三维结构
> 对应块：BLK09 | 覆盖分集：P29-P31 | 块标题（分集名）：《【经验分享】高分笔记如何使用》

这一期给大家介绍和测评求臻高分笔记，讲的是生物化学分册。先把这本笔记是什么、该怎么用讲清楚，再说配套习题册通关880怎么刷；资料讲透之后，进入知识正课——蛋白质的三维结构专题。

### 先选对版本：参考书写什么，你就用什么

生物化学的高分笔记不止一个版本。大家最常见的是朱圣庚、王镜岩版，也就是我手里这本，也是使用度最广的一版，可以叫它"通用版"；除此之外，还有杨荣武《生物化学原理》对应的版本、生化解密教程的高分笔记、人卫版生化的高分笔记。求臻这边做了好几个生化版本，那选哪本？就看你的目标院校参考书目是什么——参考书用哪个版本，你就用哪个版本。其他版本大家自己去了解，我们这一篇讲的就是用得最多的朱圣庚、王镜岩版。

### 一本300页的复习全书

什么叫高分笔记？它其实就是一本复习全书。这本资料一共289页，300页的量；教材呢，1200页。也就是说，它的体量大约是教材的四分之一。而且它行间距非常小、页边距也很小，A4纸打印，所以按字词量、段落量算，你大约可以认为是教科书的三分之一。

它的本质，就是教科书的重点知识总结：把教材中考研究竟考什么摘下来，做了总结。

翻开看它是怎么整理的。章节目录和教科书一一对应：教材36章，它也36章。每一章开头有一个本章的知识框架，然后是考情分析——如果你现在学得还不透彻，考情分析可能看不懂，没有关系，先跟着看正文。每一章正文都分成很多个考点，考点和教材的每一小节是对应的；每个考点下面又分级，一级底下再分更细的小级。

它和教材最大的不同在呈现方式。教材是大段大段的内容，艰深晦涩；高分笔记把这些大段内容拆分了：红色字体和特殊字体标注的，就是划分出来的重点，以及这个考点具体怎么考，都标在旁边；大段论述还被拆成表格、分段、小标题的形式，明显更易读。该配的图也有：比如讲氨基酸结构这一块，教材是结构图和性质文字混在一起、长篇累牍地讲，高分笔记把结构图和文字一一对应上，这一点做得比较好。

> **结论**：考研只用这本资料，够。别看只有300来页，它的复习量其实很大，考任何学校都够用。但"知识给你总结到了"不等于"每位同学都能理解"，所以备考还要结合习题和学校的真题来学。

### 贯穿全程的用法：基础用、强化背、冲刺重复背

好多同学买了这本笔记，学习时不知道怎么用，或者觉得内容太多背不下来。这里先给大家明确定位：它是一本复习全书。你想想高中备考时是不是也有本厚厚的复习全书？跟那个一样——那本复习全书可不是靠一两个月就能学会背完的。同样，这本高分笔记要贯穿你的全程备考：基础阶段要用，强化阶段要背，冲刺阶段还要重复背。最终目标就一个：上考场之前，把它背得比较熟练。

具体怎么贯穿？先看整套资料的全程安排：

| 阶段 | 用的资料 |
| :--- | :--- |
| 零基础（跨考打底） | 零基础高分笔记 |
| 基础 | 高分笔记（主） + 通关880（习题巩固） |
| 强化 | 真题狂背（按章节整理的真题） + 历年真题 |
| 冲刺 | 冲刺背诵册（名词问答合集） + 生化模拟卷 |

**基础阶段**要过一到两轮，时间比较多的同学可以过三轮。怎么过？建议一轮先听课——跟着求臻的全程课把知识框架搭起来——然后再过一遍高分笔记，加深印象，能记忆的尽量记忆。但大部分东西你是记不下来的，这很正常。基础阶段能做到"看到这个知识点能理解"就行，写不出来没有关系，因为你还记忆不下来；能大致知道每一章、每一节学了哪些东西，这一阶段的目标就达成了。在这个过程中，搭配通关880做题巩固。注意，做题不是为了"检测"，主要是拿到每一道题时，知道高分笔记里这个知识点到底是怎么考的——通过题目来巩固记忆。

**强化阶段**轮到真题登场。为什么这时候要做真题？因为高分笔记虽然已经给你画了重点，但真正的、最核心的重点在哪里？在真题里。做真题不是为了把真题背下来，而是通过真题去了解高分笔记的每一章每一节，你的目标院校究竟是怎么考的。了解了这些之后，再拿出高分笔记来背，这时候你的背诵就有目标、有方向了。举个例子：你一张一张做真题，发现"氨基酸的酸碱性"这个考点很难，但你的学校从来没考过——这意味着什么？意味着之后的学习背诵里，这个地方可以划掉了，至少前中期先不用背它：它不考嘛。你先把考的东西学习掌握，学有余力，再把历年没涉及到的内容补背一下。所以强化阶段说到底还是背高分笔记，只不过是通过真题来背，更加有针对性、更加有目标。

**冲刺阶段**的冲刺背诵册，用一句话讲叫"可遇而不可求"：一定要在背完高分笔记和真题的基础上，再去背它。如果高分笔记还没背好，冲刺阶段的这两样先别碰。所以整个考研备考，最重要的是基础阶段。

总结一下：全程备考最核心、最重要的就是这本资料。基础阶段学习记忆，尽量记个一两轮；强化阶段从八九月份起大概三个月，通过真题再去背它——前后加起来，这本笔记至少要背四五个月。一轮二轮主要记什么？记红色字体这种特殊标记的内容，这些是最重要的。高分笔记内容很多，你只要能掌握其中的70%，考上任何学校都没有问题。至于细胞生物学的笔记，以后再给大家介绍。

### 通关880的结构：每章四组题

说完主资料，再说习题册。命名先说清楚：生化与分子生物学这套叫880，其他学科都叫660，下面主要以生化880为例。它的章节结构和教材一样，也是36章；内容比较多的章节，下面又划分成几个部分。绪论肯定没什么内容，大家不用看。

每一章（专题）的习题分为四个部分：A组题、B组题、C组题、D组题。这四组题，完全够考研基础阶段刷题使用。

#### A组题：最基础，必刷

最简单、最基础的一组，知识内容都是高分笔记里有的，题型以选择题、填空题为主——一轮复习你也做不了名词解释、问答题那些东西。这一组是所有同学必须刷的。

#### B组题：经典好题，题量最大

从市面上使用比较多的各个版本习题册里，把难题、怪题、偏题——反正不好的题——删掉，保留核心的好题，组成了B组题。它的题量是最大的，你看第二章，内容非常多。题型也最全：选择、填空、判断、大题都有，混在一块。

#### C组题：最新真题

比如你现在备考2027级考研，C组题里就给你放了去年最新的真题以及前年的，也就是25、26年的题；到28考研，就换成26、27的真题。为什么放最新的？看得到真题，你就一定知道现在在考什么。

#### D组题：专项难题，有的章节才有

如果某一章考研会特殊地考某个题型、比较难的题型，就专门为它总结一个D组。比如第二章有D组，因为第二章考试会出一个分析难题——肽段推导题。这种题你一看就觉得很难，但把D组这些题刷一遍，考试再遇到这种"看似很难"的题，你就有经验了，能解决。再比如专题五"氨基酸的分析分离"，涉及实验题，它的D组就是等电点计算和蛋白质纯化——这种题基本上每个学校都要考。反过来说，像第三章，考研没有一个很特殊的难题型，就没有D组。细胞生物学660也类似：同样按考点划分A、B组，C组放最新真题，答案解析放在社群公告里；它没有独立的D组，实验题这类专项放到了B组题里面。

### 通关880怎么刷

先把权重排清楚：所有人必须要做的是A组和D组。A组最基础，帮你巩固知识；D组是考试里那种难点分析题，这种题靠背是解决不了的，所以才专门给你搞了个专项。C组是真题，主要用来看，不必要做——看一看真题到底怎么考，用它指导你接下来的复习备考。B组呢，有余力就尽量多做一点，因为它题量最大。

三个轮次这样安排：

| 复习轮次 | 任务 |
| :--- | :--- |
| 一轮 | 只做A组题，开卷做 |
| 二轮 | A组题再做一遍（尽量闭卷），有余力带做一点B组 |
| 三轮 | A组题迅速过一遍，重点做D组，C组扫一扫 |
| 时间充裕 | 把A、B、C组都做掉 |

大部分同学的时间不会那么充分，所以按上面的来：一轮主要做A组；二轮还是A组——你要重复一遍才记得住——再加部分B组；三轮是A加D，再看一看C。你会发现A组哪一轮都没离开：这些题得重复，你才能记得住。

再强调一遍开卷这件事。一轮开卷做就可以了。你别看A组题简单，做对与否没有关系，重要的是通过这些题去了解：这些知识点究竟怎么考，哪些点会出题。比如第一题，"组成蛋白质的常见氨基酸有多少种"。你如果死记硬背一个"20种"，有什么意义？没有意义。正确的用法是：拿着这道题回到高分笔记，翻到讲"20种"的那一处——哦，原来这个地方它会这么考。这一下，你既把知识点又巩固了一遍，也知道了它会怎么考。这就是习题的使用方法。

D组题比较难，我的建议是不必闭卷做，把它们当例题就好了——把它搞懂。考试它不会出得很灵活，都是这些题，搞懂就可以。

最后说说这套习题的质量和定位。质量非常高：不管是最新的真题还是其他部分，答案不仅准，题目新，而且设计层层递进，比你网上能看到的任何习题册质量都高。所以其他乱七八糟的习题册不要做了。但也要说句实话：在整个求臻资料系列里，习题册的"戏份"是最弱的。回顾一下备考规划你就明白：基础阶段是高分笔记加习题；到了强化阶段，大概暑假开始就刷真题了——真题也算习题，但它比通关880重要得多。所以880主要在基础阶段、前两三轮学习的时候刷；暑假及以后，刷题的主战场换成真题。等你把真题刷得比较透、没东西可刷了，再回过头把880打开回顾：还有很多题你没做；而且做过真题之后，你就知道你这个学校究竟喜欢考哪些题、自己的薄弱点在哪，再有针对性地找题做。比如D组那些专项题，基础阶段让你去做，你其实是没有感受的，只是把它当成一个题在学；等你真正做了真题，才会发现这种题型的重要性，回头再做一遍，就有了自己的认知。这才叫学习：不断反馈，然后不断去补。

### 进入正课：蛋白质的三维结构

资料和方法讲完，进入知识正课。我是小万老师，今天开始一个新的专题——蛋白质的三维结构。先明确一个说法：三维结构，指的就是空间结构。考点一讲三维结构的概述，我们从三个方面展开：三维结构的特点、稳定三维结构的化学键，以及肽平面。

#### 三维结构是什么：拿摩托车打个比方

三维结构指的是：一个蛋白质整体、或者这个蛋白质整体当中的任意部分当中的原子的空间排列，称为它的三维结构，也叫空间结构，或者叫空间构象。它包括二级、三级、四级三个层次——也就是说，三维结构等于二、三、四级结构的总和。

我们还是以金属丝拧成的摩托车当例子。如果整个摩托车是一个蛋白质：它的整体有一个空间结构，这就是四级结构；它的每一个部件——比如前轮胎、后轮胎——你可以看出是由一条金属丝拧成的，一条金属丝就是一条肽链，所以每个部件的空间结构是它的三级结构；再往局部看，比如发动机这个地方，由一条链拧出好多螺旋，这些局部的螺旋就是它的二级结构——螺旋本身也是空间结构，也是三维的。

所以三维结构这个说法，要么指蛋白质的整体，要么指它的一个部分——大部分可以，小部分也可以。二级、三级、四级，三个层次都在里头。

#### 三维结构的几条特点

第一条：蛋白质的三维结构取决于氨基酸序列。前面专题讲过，蛋白质（多肽链）的氨基酸序列就是它的一级结构，所以说空间结构取决于一级结构——一级结构是空间结构的基础。

第二条：蛋白质大多数以一种、或者说少数几种稳定的结构存在。为什么必须是稳定构象？蛋白质在生物体里要发挥作用，构象必须稳定。但对一个特定的蛋白质来说，构象又不止一种。想一个酶：大多数酶是蛋白质，它有的时候需要被激活，有的时候需要被抑制，那它至少就需要两种构象——一种失活的构象，一种激活的构象。有的酶活性还分强弱等级，比如从强到弱有五个等级，那它就可能对应五种构象。这些都是存在的。

第三条：蛋白质的功能取决于它的三维结构。注意把前两条串起来看：一级结构是三维结构的基础，三维结构又是功能的基础。

第四条：稳定特定蛋白质结构的，是一些非共价的相互作用，也就是非共价键。蛋白质里维持结构的化学键有共价键和非共价键两大类，下面单独展开讲。

第五条：不同的蛋白质之间，常有一些相似的序列和结构。比如这个蛋白质中间有几段螺旋，另一个蛋白质里面也可能有螺旋——这是它们结构上的共同点。

第六条：蛋白质的结构不是静态的。这一条要和第二条对应起来理解：既然它以少数几种稳定结构存在，这少数几种结构之间就会发生转换；既然可以转换，结果就不是静态的——它会随着外界环境的变化，根据细胞对它功能的需要，做出一些调整。

> **提示**：第二条和第六条连起来记：稳定构象只有少数几种，构象之间可以转换——"稳定"和"动态"并不矛盾。

### 稳定三维结构的化学键

先看全局。蛋白质从一级结构到二级、三级、四级结构（二三四级就是三维结构），维持它们的化学键总共两大类：

| 大类 | 具体的键 | 主要维持 |
| :--- | :--- | :--- |
| 共价键 | 肽键、二硫键 | 一级结构 |
| 非共价键 | 氢键、盐键（离子键）、疏水作用力（疏水键）、范德华力 | 二、三、四级结构（三维结构） |

两点补充：二硫键在很多教材上也被归到维持三维结构的化学键里；非共价键虽然单个很弱，但架不住多——多了就能撑起整个三维结构。四种非共价键里，疏水作用力占主导地位。

> **定义**：盐键又叫离子键；疏水作用力又叫疏水键。

#### 氢键：从一杯水的表面张力说起

氢原子和氧、氮、氟这三种原子形成共价键——比如氢和氧形成水，一个氧原子可以和两个氢原子形成两对共价键。形成共价键时要共用一对电子，但这对共用电子会更靠近氧、氮、氟这一方。拿水来说：电子对偏向氧，氧原子就有了一定的电负性；电子对远离氢，氢就有了一定的正电性。于是这个氢原子可以和附近另一个分子中的氧原子——那边正好带负电性——异性相吸，产生一个相互作用力。这就是氢键。

正是因为有氢键，倒水的时候才会出现表面张力：水面已经高出杯口了，还没有流出去，就是氢键在拉着。看示意图：图里画的都是水分子，红色的是氧原子，两个灰色的是氢原子，一个水分子里的氢拉着旁边水分子里的氧，它的氧又被另一家水分子里的氢拉着——一个拉着一个，一个拉着好几个，附近的水分子之间都形成这样的作用力。

氢键在肽链之间怎么发挥作用？回忆氨基酸串成肽链的方式：第一个α碳上连的羰基（碳氧双键）和第二个α碳上的氨基脱水生成肽键。如果底下再有一条肽链，它羰基上的氧和上面肽链氨基上的氢靠得足够近，这两条肽链之间就形成一个氢键——这就是氢键发挥作用的典型方式。

#### 盐键（离子键）：以氯化钠为例

盐键是两个或多个原子、化学基团失去或获得电子成为离子以后，靠静电吸引形成的作用力。用食盐氯化钠来看：钠原子11个电子，最外层1个电子，特别容易失去；氯原子17个电子，最外层7个，特别容易再得一个——得到一个电子，最外层就变成八电子稳定结构。于是钠失去一个电子变成钠离子，氯得到一个电子变成氯离子，一个带正电、一个带负电，互相吸引，这就是氯化钠，在溶液当中就以离子形式存在。

但注意：这两个离子又不能无限接近。为什么？因为它们两个的原子核里带的都是正电，靠得足够近时，原子核之间正电的斥力就开始发挥作用。所以最后两个离子所处的位置是一个平衡：静电吸引和静电排斥达到平衡，这就形成了离子键。

放到蛋白质里：正负电荷的侧链基团互相靠近，也可以通过静电吸引形成离子键（盐键），比如羧基和氨基、羟基、咪唑基等等基团之间的这种作用力。为什么蛋白质里有这个条件？蛋白质由氨基酸组成，氨基酸在不同pH环境下会带不同的电——只要带了电，就可能出现盐键。盐键大家了解就可以了。

#### 疏水作用力：占优势的那一个

先想一个生活场景：一杯水里滴上几滴油，哪怕滴的时候没滴在同一个地方，过一段时间这些油也会聚在一起。为什么？油是疏水的。疏水分子被放进水环境里，它们特别不想跟水待在一起，于是彼此聚集——疏水的物质或基团在水环境当中，互相之间有吸引力，这就叫疏水作用力。

落到氨基酸上：丙氨酸是非极性的脂肪族氨基酸，侧链是一个甲基。脂肪族的基团都是碳链，或者碳形成的环；芳香族其实也是烃链，只不过是芳香烃——烃就是碳和氢组成的，写烃链的时候，碳上连的氢一般省略不写。两个丙氨酸放在水溶液里，它们的两个疏水侧链（甲基）就会聚集，之间有一个互相吸引的力。另一张图更明显：上面是异亮氨酸，侧链四个碳；下面是缬氨酸，侧链三个碳。碳链更长，疏水作用力就更大，更容易发生聚集。

往后讲到核酸结构时还会遇到它。把DNA双螺旋拉平成一个平面：蓝色小圆圈是磷酸，五边形是戊糖，中间一串A、T、C、G这样的字母都是碱基。注意，碱基都是疏水的。于是对中间这一对碱基来说：上面那一对碱基对它有疏水吸引力，往上拉；下面那一对也吸引它，往下拉——上下两边像把它扯住一样，达到平衡以后，整个结构就稳定了。

还有一个前提要记住：疏水作用力一定是疏水的物质或基团在水环境当中才会出现的作用力。而我们的细胞里面就是一个水环境，所以蛋白质处在细胞里，疏水作用力发挥着非常重要的作用，对蛋白质形成一定的结构贡献很大。

> **结论**：在整个蛋白质三维结构的维持过程中，占优势地位的是疏水作用力。这一条要记住。

#### 范德华力：很弱，但架不住多

范德华力简单说一下：它是一种普遍存在于固体、液体和气体当中的分子间作用力。它很弱，但是它多呀——多了之后就能发挥作用了。这也正是整个非共价键家族的共性：单个和共价键比很弱，但数量多，所以足以起到维持蛋白质三维结构的作用。

### 肽平面：六个原子锁在一个平面上

肽平面是这一讲要重点掌握的内容。

先说肽键怎么形成：肽键是氨基酸之间通过α-氨基和α-羧基脱水缩合生成的化学键。以最简单的两个甘氨酸为例：第一个甘氨酸的羧基和第二个甘氨酸的氨基之间脱水——羧基脱下羟基，氨基脱下一个氢——生成一分子水，中间就形成了这样一个化学键，这就是肽键。

把肽键单独拿出来看。它要看作由六个原子共同组成：第一个氨基酸的α-碳，羧基碳、羰基氧，第二个氨基酸的氨基氮、氨基氢，以及第二个氨基酸的α-碳。为什么是六个原子？因为研究表明，这六个原子处于同一个平面上。

凭什么共平面？研究发现，肽键的键长介于单键和双键之间，具有部分双键的性质——也就是说，形成肽键的这两个原子不能自由旋转，被锁在一个平面上。于是涉及肽键的六个原子就共处于一个平面，这个平面叫做肽平面，又称肽单元，也叫做酰胺平面。

一条肽链，就是若干个肽平面一个接一个连起来的。画一条由五个氨基酸组成的肽链：每一处肽键周围数出六个原子（α-碳、羧基碳、羰基氧、氨基氮、氨基氢、下一个α-碳），这就是一个平面；相邻两个肽平面之间，由α-碳连接起来。

```text
               O            O
               ||           ||
               H            H
...---N---Ca---C---N---Ca---C---N---Ca---...
          |<------------|
                       |<------------|

一个肽平面：竖线框住的六个原子——Ca、羧基碳 C、羰基氧 O、
氨基氮 N、氨基氢 H、下一个 Ca——共处一个平面。
相邻两个肽平面共用中间那个 Ca。
```

读图：每一对 `|<------------|` 框出的就是一个肽平面，O 连在羧基碳上，H 连在氨基氮上；两个平面在中间的 Ca 处衔接。α-碳和羧基碳之间的夹角记作 ψ，它和氨基氮之间的夹角记作 φ。正是通过这两个角，相邻的两个肽平面之间形成一定的夹角，最终折叠出空间结构。所以说，肽平面是整个蛋白质形成三维结构的基础。

### 肽链的骨架与方向

肽链的骨架，指的是除了侧链之外的原子形成的结构。数一数上面那条五氨基酸肽链：每个氨基酸的侧链是R1到R5，把R1到R5去掉，再把氢原子去掉，剩下的原子就组成骨架——氨基氮—α碳—羧基碳—氨基氮—α碳—羧基碳，这样重复排下去。

有同学可能会问：为什么不管氢原子？因为氢是所有原子当中最小的原子，它对整个结构的贡献太小，说骨架的时候就把它忽略掉了。

肽链还有方向：从氮端（N端）往碳端（C端）走。为什么是这个方向？因为生物体当中合成肽链的时候，就是从N端往C端走的。但要注意区分：实验室里用固相合成法合成多肽的时候，方向刚好相反，是从C端到N端。

### 测定方法：把资料上的六种背下来

第二个考点是蛋白质三维结构的测定方法。这个考点没有什么可展开的——真要展开，方法学特别特别复杂。大家直接把资料上列的这六种测定方法重点记忆一下就可以了。

最后把这一讲小结一下，一共三件事：第一，蛋白质的三维结构就是它的高级结构，也叫空间结构、空间构象，包括二级、三级、四级三个层次；第二，稳定三维结构的化学键主要是氢键、盐键、疏水作用力、范德华力这几种非共价键，此外还有二硫键，其中占优势的是疏水作用力；第三，形成肽键的六个原子共处一个平面，这就是肽平面，相邻的肽平面由α-碳连接——蛋白质的空间结构，就是从这一个一个平面折叠出来的。

## 蛋白质的二级结构：主链骨架上的 α-螺旋与 β-折叠
> 对应块：BLK10 | 覆盖分集：P32-P35 | 块标题（分集名）：《[专题03习题]考点1∶蛋白质三维结构概述》

接着蛋白质的三维结构往下走，该说二级结构了。这个考点的分量不用多说：α-螺旋是蛋白质里最常见、最典型、含量最丰富的二级结构，也肯定是最爱考的。先把话放在前面——定义里的每一个字都要抠，尤其是“主链”这两个字，抠不清楚，后面的题全是坑。

二级结构名目不少，真正要抓的只有两件事：什么算二级结构、靠什么键维持；剩下的就是四种典型结构——α-螺旋、β-折叠、β-转角、Ω 环。前两个是重点，必须掌握；后两个知道特征、记住几个常考的小题就够了。

### 二级结构只认主链

什么是蛋白质的二级结构？一句话：蛋白质分子中某一肽链局部的空间结构，也就是多肽链中主链原子的相对空间排布。

> **定义**：蛋白质二级结构，指的是多肽链中主链原子的局部空间排布。

这句话里有两个关键词：一个是“局部”，一个是“主链原子”。

先说“主链原子”。把一条多肽链摊开：R1、R2、R3、R4、R5……这些都是侧链，先划掉；氢原子是最小的原子，讨论骨架走向时也先忽略。剩下的才是主链——氨基氮、α-碳、羰基碳（其实就是羧基碳脱水之后留下的那个碳），再往后又是氨基氮、α-碳、羧基碳。N—Cα—C—N—Cα—C 这样重复下去，连成整条肽链的骨架。

所以二级结构说的是：这条骨架在某一段上盘出来的空间结构。注意“局部”两个字——只看某一段，不是整条链一起看。

侧链不参与二级结构的形成，这一点要反复强调：不是侧链，也不是氨基酸残基侧链的空间排布。二级结构只谈主链。

维持二级结构的化学键只有一种：氢键。氢键的两头，一头是羰基氧——羧基脱水之后留下的 C=O；另一头是氨基上剩下的 N—H。两者靠得足够近，氢键就形成了。

> **提示**：讲骨架走向时把侧链和氢原子略去，是为了看清 N—Cα—C 这条主线；讲到氢键时，酰胺氢又必须数回来。两处并不矛盾：一处看骨架，一处看成键。

二级结构的类型很多。只要是多肽链中局部的一段空间结构，都可以算作二级结构的一种；研究得比较清楚、考试反复出现的典型结构有四种：α-螺旋、β-折叠，以及非典型的 β-转角和 Ω 环（欧米伽环）。其中 α-螺旋是已知蛋白质二级结构里含量最多的一种，也是这一讲的重点。

### α-螺旋：3.6 个残基一圈的右手弹簧

α-螺旋是蛋白质空间结构里最基础的一层，也是二级结构里的一种主要类型。它长什么样？把一条肽链想成一圈一圈往上盘的楼梯。每一个肽平面是一块平板，α-碳恰好落在相邻两块平板的交界处：1 号 α-碳和 2 号 α-碳之间是第一个肽平面（第一个肽键），2 号和 3 号之间是第二个，3 号和 4 号之间是第三个，依此类推。这些平板沿着螺旋轴一级一级盘旋上去，就是 α-螺旋。

为什么 α-碳正好在交界处？一个肽平面由肽键本身、它两端的两个 α-碳，以及羰基氧和酰胺氢共同构成，这些原子共面。相邻两个肽平面共用中间那个 α-碳，所以 α-碳就是两块平板的铰接点。整条链于是变成一串由 α-碳串起来的平板。

这一条是整讲的主角：它是蛋白质里含量最丰富的二级结构元件，后面的参数、氢键和弹性都围绕它展开。

#### 一圈 3.6 个残基，螺距 0.54 nm

一个螺旋，也就是转一圈，包含 3.6 个氨基酸残基，约等于 4 个。沿螺旋轴上升 0.54 nm，这个高度就是螺距。

3.6 不是整数。意思是：转满一圈、回到几乎相同的方位时，已经跨过了 3 个完整残基，还多走了 0.6 个。所以“约等于 4 个”只在粗略估算时成立，写参数必须写 3.6。

还有一条必须记死：α-螺旋是右手螺旋。别记反。

含量上，蛋白质中大约 1/4 的氨基酸残基以 α-螺旋的形式存在——这就是它“最常见、最典型、含量最丰富”的底气。

| 参数 | 数值 | 说明 |
| :--- | :--- | :--- |
| 每圈残基数 | 3.6（约 4） | 一个螺旋重复单位跨过的残基数 |
| 螺距 | 0.54 nm | 每转一圈沿螺旋轴上升的高度 |
| 手性 | 右手 | 方向不能记反 |
| 氢键配对 | 第 n 个残基的 C=O 与第 n+4 个残基的 N—H | 换肽键口径是第 n 个与第 n+3 个 |
| 闭环大小 | 13 元环 | 整个螺旋记作 3.6₁₃ |
| 占残基比例 | 约 1/4 | 已测蛋白质中的统计 |

把这几项参数放在一起，α-螺旋的骨架就清楚了。

#### 氢键从 N 端出发：残基 n 拉 n+4

氢键怎么形成？先在螺旋上认方向。取任意一个氨基酸：它朝 C 端一侧的肽键是它的羧基，朝 N 端一侧的肽键是它的氨基。氨基在前、羧基在后，所以整条肽链的 N 端在上、C 端在下。

然后数残基。最上面的 α-碳算第 n 个，往下依次是 n+1、n+2、n+3，再往下一个就是第 n+4 个。第 n 个残基羧基上的氧，与第 n+4 个残基氨基上的氢，形成氢键。

3.6 个残基一圈，第 n+4 个残基差不多就是转一圈之后的那一个，它的 N—H 正好落在第 n 个残基 C=O 的对面。

换成肽键的口径再数一遍：最上面的肽平面算第 n 个肽键，往下是 n+1、n+2、n+3。第 n 个肽键羰基上的氧，与第 n+3 个肽键上的氨基氢形成氢键。

两套数法说的是同一根氢键，只是一个按残基编号、一个按肽键编号。肽键在有些材料里也叫肽基，名字不同，指的是同一个东西。

| 数法 | 羰基氧来自 | 酰胺氢来自 | 数字关系 |
| :--- | :--- | :--- | :--- |
| 按氨基酸残基 | 第 n 个残基 | 第 n+4 个残基 | n 与 n+4 |
| 按肽键（肽平面） | 第 n 个肽键 | 第 n+3 个肽键 | n 与 n+3 |

> **易错点**：N 与 N+4 说的是氨基酸残基，N 与 N+3 说的是肽键。题目里只要出现这两个数字，先看清它数的是残基还是肽键，别混。

方向也要记住：氢键的形成是从 N 端出发的，每个肽平面的羰基氧，去和它后面第 4 个残基的酰胺氢配对。由于 α-螺旋最大程度地利用了氢键，它在蛋白质结构里广泛存在。所谓“最大程度”，就是螺旋内部每个残基的 C=O 和 N—H 几乎都找到了配对，没有空着的。

```text
N 端
  Cα(n)     ── C=O ⋯⋯⋯⋯┐
  Cα(n+1)              ⋮
  Cα(n+2)              ⋮   氢键
  Cα(n+3)              ⋮
  Cα(n+4)   ── N—H ⋯⋯⋯┘
C 端
```

把螺旋沿轴拉直后的氢键配对示意（省略中间的肽平面）：第 n 个残基的羰基氧跨过 4 个残基，与第 n+4 个残基的酰胺氢相连。真实结构里，这些氢键几乎平行于螺旋轴，从侧面看是一道道竖直的“横撑”，把一圈一圈的主链撑住。

氢键一闭合，主链上就围出一个环。数一数环上的原子：13 个。所以这个环叫 13 元环，整个螺旋记作 3.6₁₃。

名字拆开看就明白了：3.6 是螺旋每转一圈的残基数，13 是氢键闭环里的原子数。这 13 个原子，是 11 个主链原子（C、N、Cα 交替）加上羰基氧和酰胺氢。

#### 侧链不参与成键，却决定倾向性

侧链去哪了？氨基酸的 R 基团不参与 α-螺旋的形成。其实不光是 α-螺旋：β-折叠、β-转角、Ω 环也都不涉及侧链基团——因为二级结构只讲主链原子的空间排布。

但“不参与”不等于“没影响”。侧链基团的大小、形态、带电状态，都会影响螺旋能不能形成、形成以后稳不稳定。所以某一段肽链形成 α-螺旋的倾向性——是容易形成，还是不容易形成——取决于这段肽链里氨基酸残基的本性和序列。

序列是什么？就是一级结构。绕了一圈又回到那句话：一级结构决定二级、三级、四级结构。

#### 弹簧一样的弹性

α-螺旋的结构特点，决定了它像一个弹簧，弹性比较好。弹簧的特点是拉得开、也回得去；α-螺旋一圈一圈地盘着，受力时能发生可恢复的形变，这就是它弹性好的原因。

人体里 α-螺旋含量特别丰富、弹性也特别好的几类蛋白质，正好是例子：毛发当中的角蛋白、肌肉组织当中的肌球蛋白、血凝块当中的纤维蛋白。它们都需要经受拉伸和形变，α-螺旋给了它们这种能力。

### β-折叠：从蚕丝被看折纸状的链间氢键

讲 β-折叠之前，先看一样东西：蚕丝被。

#### 蚕丝为什么这么能拉

蚕丝被的做法很能说明问题，李子柒拍过整个过程：蚕茧煮过，反复清理、洗净，用手一扯就能拉开，扯开也不断；拉开成薄薄的一层，晾干，一沓一沓地叠着；做被子的时候，四个人从不同方向同时往开扯，能扯成很大的一张，一层一层铺上去，最后就是一床被子。

整个过程靠的就是蚕丝极好的延展性。蚕丝凭什么这么能拉？因为蚕丝蛋白里的二级结构主要就是 β-折叠。把 β-折叠的形状看明白，这个延展性就解释通了。

#### 折纸状的骨架与链间氢键

把 β-折叠打开看，它的形状是折纸状，或者说锯齿状。每一个小平面仍然是一个肽平面；一条肽链就是由这样一串平板连成的锯齿带，平板之间由 α-碳连接。相邻的 α-碳一上一下地交替，主链就被折成一列锯齿。

两条肽链靠得足够近的时候，一条链肽平面上的羰基氧，与另一条链上的酰胺氢靠近，形成氢键。β-折叠就是靠这种链间氢键，把几条锯齿带并成一片。

把骨架摊开看更清楚：每一个平行四边形是一个肽平面，相邻肽平面的交界处是 α-碳；一个肽平面羧基碳上连的氧，与下面那条链某个 α-碳所连氨基上的氢，靠近就成氢键。

这里要抓住一个对比：α-螺旋的氢键是同一条肽链内部、第 n 个残基拉第 n+4 个残基；β-折叠的氢键主要发生在两条链之间，一条链的羰基氧去拉另一条链的酰胺氢。

#### 平行与反平行

β-折叠分两种形式：平行的和反平行的。判断之前，先记住一条：肽链是有方向的，方向就是从 N 端到 C 端。

怎么认出一条链的方向？看 α-碳挨着的是谁：α-碳的一侧连着氨基氮，另一侧连着羧基碳；从氨基走向羧基，就是 N 端到 C 端。

一条链的 α-碳左边连着氨基，它就从左往右走；与它配对的那条链反过来，从右往左走。两条链方向相反，这就是反平行。

相反，如果几条链都朝同一个方向走，就是平行。

平行和反平行，跟“几条链”没有必然关系：平行的 β-折叠，大多数由不同的肽链并成；反平行的 β-折叠，既可以在不同肽链之间形成，也可以在同一条肽链里折回来形成。

```text
反平行：两条链方向相反

  N ─────────────────────────→ C
        ┆   ┆   ┆   ┆   ┆
  C ←───────────────────────── N


平行：两条链方向相同

  N ─────────────────────────→ C
        ╲   ╲   ╲   ╲   ╲
  N ─────────────────────────→ C
```

箭头表示肽链从 N 端到 C 端的方向。反平行时两条链首尾相对，平行时两条链同向并排；中间的竖线和斜线表示把相邻链缝在一起的氢键。

#### 纤维状蛋白与球状蛋白里的分布

再看两类蛋白质里的分布，这里是容易混的地方。

纤维状蛋白质里，主要是反平行的 β-折叠，而且氢键存在于不同的肽链之间。你可以想象一根蚕丝：一条链折过去、另一条链折回来，一条挨一条并成一片，链与链之间全靠氢键缝住。

球状蛋白质里，反平行和平行都有；氢键可以存在于不同的肽链之间、不同的蛋白质分子之间，也可以存在于同一条肽链的不同肽段之间。

重点记纤维状蛋白，因为蚕丝就是它：一根蚕丝里有许多反平行 β-折叠并成的片层，所以延展性特别好。

这就像一张 A4 纸折成折纸：折起来体积很小，但一打开，能展开的面积很大。β-折叠就是蛋白质里的折纸——折起来紧凑，拉开有余量。

### β-转角：180 度回折的那一拐

β-转角顾名思义，就是肽链拐弯的地方：肽链进行 180 度回折时，那个转折部位就是 β-转角。

它由 4 个氨基酸残基组成。第 1 个残基的羰基氧，与第 4 个残基的酰胺氢形成氢键，把这个回折固定住。β-转角有两种类型，类型本身不用记——只要知道它们都属于 β-转角、都是 180 度回折的部位就够了。

> **易错点**：甘氨酸和脯氨酸经常出现在 β-转角当中，这是选择题、填空题常考的一句；但反过来不成立——β-转角并不一定含有甘氨酸和脯氨酸。前半句对，后半句倒过来就错。

β-转角经常出现在球状蛋白的表面。想想一个球：表面总得有拐弯、有 180 度回折，链才能折回来，把球面铺出来。

### Ω 环：球状蛋白表面的亲水大环

Ω 环和 β-转角是一路的，只是更大：形状就像希腊字母 Ω，是一个更大的环。它更多出现在球状蛋白的表面，长度一般是 6～8 个氨基酸残基，最多不超过 16 个。

Ω 环以亲水基团为主。为什么？蛋白质在细胞里是泡在水相环境中的，球状蛋白要把亲水的基团摆到外表面；Ω 环正好长在外表面，自然以亲水基团为主。

也正因为露在外面，不同蛋白质分子之间发生相互作用时，Ω 环常常参与分子识别，发挥重要作用。

### 两条主线

整讲的主线只有两条。

概念这条：一句话——主链原子、局部空间结构；维持它的化学键只有一种——氢键，本质是羰基氧与酰胺氢的配对。

分类这条：四种典型结构——α-螺旋、β-折叠、β-转角、Ω 环。其中 α-螺旋和 β-折叠是必须掌握的；α-螺旋又是含量最丰富、最典型、最爱考的那一个。

## 纤维状蛋白与蛋白质三维结构的层次
> 对应块：BLK11 | 覆盖分集：P36-P43 | 块标题（分集名）：《[专题03] 考点04：纤维状蛋白》

这一讲要讲的纤维状蛋白，我说四种，其实是五种——五种四类。

名单先摆出来：α角蛋白，丝心蛋白和β角蛋白，胶原蛋白，弹性蛋白，血纤蛋白原。它们散落在身体各个角落：头上的毛发、菜市场的腱子肉、伤口上那层血痂、肺和血管的弹性，背后站着的都是这几类蛋白。

这五种的分量并不一样。α角蛋白要熟悉，一般出小题；丝心蛋白和β角蛋白了解就行；胶原蛋白是重点，三种不常见的氨基酸、Gly-X-Y 的重复序列、三股螺旋的旋向，都得弄清楚；弹性蛋白最好的记法是拿去和胶原蛋白对照着背；血纤蛋白原只要把凝血那条主线捋顺。

| 蛋白 | 主要存在 | 结构要点 | 掌握程度 |
| :--- | :--- | :--- | :--- |
| α角蛋白 | 皮肤及其衍生物：毛发、鱼类鳞片、鸟类羽毛、龟甲 | 右手α螺旋，两股拧成左手卷曲螺旋，二硫键交联 | 熟悉，常出小题 |
| 丝心蛋白 / β角蛋白 | 蚕茧、蜘蛛丝；鸟类与爬行动物的皮肤、羽毛、鳞片 | 反平行β折叠片，靠氢键与范德华力稳定 | 了解 |
| 胶原蛋白 | 腱、骨、软骨、牙齿、皮肤、血管等结缔组织 | 三股左手螺旋拧成右手原胶原，富含 Gly-X-Y | 重点 |
| 弹性蛋白 | 结缔组织，肺、血管、韧带 | 不被糖基化，只有一个基因 | 与胶原对比记 |
| 血纤蛋白原 | 血浆 | 凝血级联的底物，被凝血酶切成血纤蛋白 | 记住凝血主线 |

### 五种纤维状蛋白：撑起皮肤、蚕丝与肌腱

#### α角蛋白：右手螺旋拧成的左手绳

α角蛋白是皮肤及其衍生物的组分。皮肤衍生物有哪些？往身上数，是毛发；往水里数，是鱼类的鳞片；往天上数，是鸟类的羽毛；再算上乌龟的龟甲。这些东西硬、韧、不易烂，靠的结构蛋白就是α角蛋白。

它还有个名字，叫α螺旋蛋白质。原因很直白：它的二级结构几乎全是α螺旋，就是我们讲二级结构时反复提的那个右手螺旋。判断右手螺旋的办法，把右手伸出来，大拇指指向N端，四指弯曲的方向就是螺旋盘绕的方向；两者一致，就是右手螺旋。

这种螺旋偏爱几种氨基酸：丙氨酸、缬氨酸、亮氨酸、异亮氨酸、甲硫氨酸和苯丙氨酸。

单股只是起点。两条右手的α螺旋会以相反的方向互相缠绕，拧成一根左手的卷曲螺旋。

> **提示**：这里有两层旋向，千万别混。单股α螺旋是右手；两股拧成的卷曲螺旋是左手。看任何一张螺旋图，先问自己数的是哪一层，再判旋向。

再往上，就是一根毛发的各级组装。

```text
α 螺旋（单股，右手）
   │  两股反方向缠绕
   ▼
卷曲螺旋（左手）
   │  两根并排
   ▼
原纤维
   │  多根成束
   ▼
微原纤维
   │  大量平行排列
   ▼
毛发
```

从下往上读就是拆解：一根头发拆到最细，最里面是单股的右手α螺旋；从上往下读就是组装：一根螺旋不成绳，两股反着拧才成绳，绳再并绳，最后成束。图上从上一级到下一级只做一件事——把上一级的东西并起来。

两条螺旋靠什么粘住？半胱氨酸。相邻两个分子的α螺旋上各有一个半胱氨酸残基，两个巯基各脱掉一个氢，合成一个二硫键。二硫键是共价键，比氢键结实得多。所以有一个很直接的比例关系：二硫键越多，纤维的刚性越强。

毛发还有个怪脾气：湿热的时候能拉长到原来的两倍。为什么？热和水把维持α螺旋的氢键拆了，螺旋撑开、拉直，转成β构象，也就是一种比较伸展的构象。可这个伸展状态它待不住——α角蛋白的侧链R基一般比较大，挤在伸展的构象里互相打架，本来就不适合处在这种状态。所以湿热一撤，回到寒冷干燥，它自己又缩回α螺旋，再交联成左手卷曲螺旋，两根卷曲螺旋并成原纤维，原纤维聚成束，又恢复成头发的样子。

这一段就是烫发的全部物理化学基础。

#### 烫发：先拆后建的一次化学手术

永久性卷发的原理，考试真会问，值得单独拎出来。

理发店的做法是先按想要的形状把头发卷起来——卷成什么样，最后就是什么样。接下来的四步化学操作，才是这件事的关键。

1. 加热加湿。氢键被拆开，α螺旋打开，转成伸展的β构象。
2. 涂还原剂。还原剂是含巯基的化合物，它把二硫键还原回两个巯基，两条螺旋之间的束缚松开，彼此的联系变松，能够随发卷滑开、变形。
3. 去还原剂，再涂氧化剂。氧化剂把巯基上的氢夺走，巯基重新氧化成二硫键——但这一次是在已经卷好的形状下，和邻近的螺旋成键。
4. 洗涤、冷却。氢键恢复，β构象重新变回α螺旋，只不过这一回是在被二硫键固定住的卷曲形状里长回去的。

```text
按形状卷好头发
      │
      ▼
[湿热] 拆氢键：α 螺旋 → β 构象（伸展）
      │
      ▼
[还原剂·含巯基] 拆二硫键：—S—S—  →  两个 —SH
      │        螺旋之间的束缚松开，随发卷变形
      ▼
[去还原剂 + 氧化剂] 重建二硫键：在新的相对位置上成键
      │        形状被共价键锁死
      ▼
[洗涤冷却] 氢键恢复：β 构象 → α 螺旋
      │        但此时是在卷曲形状里长回去的
      ▼
永久卷发
```

读这张图抓两点：竖着看是四步操作的先后，横着看是每一步只动一种键。

为什么顺序不能换？先断氢键，螺旋才伸得开、两股才滑得动；这时候再断二硫键，才有意义。重建时反过来，先把二硫键在新的位置上接好，形状就锁住了；再冷却让氢键在锁住的构象里恢复，形状才留得下来。顺序一乱，头发会弹回原样。

> **提示**：还原剂不是把二硫键“删掉”，是把 —S—S— 还原成两个 —SH；氧化剂也不是凭空造键，是把两个 —SH 再氧化成 —S—S—。整个过程是一对可逆的氧化还原，加上一对可逆的氢键破坏与重建。

把四步压成一句话：先拆氢键、再拆二硫键；先建二硫键、再建氢键。拆，靠加热和还原剂；建，靠氧化剂和冷却。

#### 丝心蛋白与β角蛋白：反平行β折叠

丝心蛋白存在于昆虫的茧——就是蚕丝被里那个茧——以及蜘蛛丝的纤维成分里。它是β折叠蛋白，结构靠氢键和范德华力稳定。

范德华力是什么？就是原子、分子之间普遍存在的一种很微弱的相互作用力。它单个很小，但几乎无处不在，一根纤维里成千上万个接触点累加起来，就是可观的凝聚力。

它的二级结构以反平行的β折叠片为主，另外还含有一定量的无规卷曲和α螺旋。β角蛋白是同一路数的蛋白，出现在大多数鸟类和爬行动物的皮肤、羽毛、鳞片中，也是β片层结构。这两样了解就可以。

#### 胶原蛋白：三股左手拧成的右手绳

胶原蛋白我们太熟了。皮肤表面就是它；年纪大了，广告里天天说“胶原蛋白流失”，皱纹就是这么出来的。它到底是什么东西，值得弄清楚。

它是很多脊椎动物和无脊椎动物体内最丰富的蛋白质，属于结构蛋白。腱、骨、软骨、牙齿、皮肤、血管这些结缔组织，主要成分都有它，是它让这些组织具有机械强度。想想皮肤、牙齿、软骨的手感就明白了，那都是硬邦邦的力学性能。

胶原蛋白属于糖蛋白。翻译生成多肽链的时候，链上还没有糖；在它最终折叠成有活性的胶原蛋白之前，糖才以糖基的形式加进去。所以糖基化是翻译之后、折叠定型之前的一步修饰。

它的氨基酸组成有三个特点。

第一，含三种不常见的氨基酸：4-羟脯氨酸、3-羟脯氨酸和5-羟赖氨酸。前两个是在脯氨酸的四位碳、三位碳上各加羟基，第三个是在赖氨酸的五位碳上加羟基。催化它们的酶分别是脯氨酸羟化酶和赖氨酸羟化酶，而这两个酶催化的羟化反应需要维生素C参与。

> **结论**：胶原合成离不开维生素C。护肤品爱强调维C，原因就在这儿——它是羟化这一步的必需配角，没有它，羟化做不成，正常的胶原就合成不出来。

第二，胶原蛋白有多个亚基，每个亚基都有自己的基因。这一点要记牢，它意味着每一条多肽链的一级结构都不一样。由不同多肽链组成的聚合物，叫异聚体。

第三，它富含甘氨酸、脯氨酸和羟脯氨酸。这三种氨基酸凑在一起，会形成三股α肽链，缠绕成特有的三股螺旋，这个三股螺旋就是原胶原。

旋向是这里最容易翻车的地方，必须说清楚：原胶原整体是右手螺旋，而每一股链自身是左手螺旋。看图的时候，先看那股细的——把左手拿出来比一比，走向和左手四指一致，它是左手螺旋；再看三股拧成的那根粗绳——和右手四指一致，整体是右手螺旋。

> **易错点**：问“三股螺旋整体”，答右手；问“单股链自身”，答左手。这两句话必须同时记住，考试最爱在这里设套。

多肽链里还有一段特征性的重复序列：Gly-X-Y。X 和 Y 可以是甘氨酸以外的任何氨基酸，但 X 常常是脯氨酸，Y 常常是羟脯氨酸。这和前面“富含甘氨酸、脯氨酸、羟脯氨酸”正好对上——所谓富含，富就富在这条重复序列里。

胶原在体内以胶原原纤维的形式存在，而胶原原纤维的基本结构单位就是原胶原。

```text
三条肽链（每股自身：左手螺旋）
        │  三股相互缠绕
        ▼
原胶原（整体：右手螺旋）
        │  多条聚合
        ▼
胶原原纤维
        │
        ▼
胶原
```

读图还是那套问法：最细的一级是什么旋向，上一级靠什么方式并起来。这里最细的是三条左手螺旋，往上一级是三股拧成的右手绳，再往上是许多根右手绳并成的原纤维。

胶原蛋白一般不容易被蛋白酶水解。想想骨、肌腱、牙齿、皮肤有多稳定就理解了。但它能被梭菌或者动物的胶原酶切断；一旦断了，碎片会自动变性，变性后的碎片就能被普通蛋白酶水解了。

这也解释了厨房里的两件事。一是腱子肉：里面富含胶原，生的时候嚼不动，煮熟的过程就是把结构破坏掉，进了消化道，普通蛋白酶才水解得动。二是明胶：胶原在水中煮沸，就变成明胶，也叫动物胶，是一种可溶性的多肽混合物。皮冻就是这么来的——猪皮一煮，胶原被煮出来变成明胶，另外还有些不溶于水的成分一起凝在里头。

#### 弹性蛋白与血纤蛋白原

弹性蛋白主要存在于结缔组织中，它让肺、血管和韧带具有伸展性。

它和胶原蛋白最容易混，三个差别记住就够。

| 项目 | 胶原蛋白 | 弹性蛋白 |
| :--- | :--- | :--- |
| 糖基化 | 是糖蛋白，多肽链合成后、折叠前加糖基 | 不被糖基化，不是糖蛋白 |
| 基因与亚基 | 多个亚基，每个亚基有各自的基因，属异聚体 | 只有一个基因 |
| 羟化氨基酸 | 含 4-羟脯氨酸、3-羟脯氨酸、5-羟赖氨酸 | 不含羟赖氨酸，羟脯氨酸含量也很少 |

血纤蛋白原是第五种。血液凝固至少需要13种凝血因子参与，这些凝血因子都是各种各样的蛋白质，整个凝血过程是一个级联放大反应。

最基本、最直接的那条线是这样的：伤口出现，凝血酶原被激活，激活后叫凝血酶；凝血酶催化血纤蛋白原转变成血纤蛋白；血纤蛋白再在凝血因子XIIIa——它还有个名字叫血纤蛋白稳定因子——的作用下交联，形成不溶性的血纤蛋白凝块，也就是血凝块，把伤口封住，防止继续出血。

```text
伤口
  │ 激活
  ▼
凝血酶原 ──► 凝血酶
                │ 催化
                ▼
          血纤蛋白原 ──► 血纤蛋白
                              │ 凝血因子 XIIIa
                              │ （血纤蛋白稳定因子）交联
                              ▼
                    不溶性血纤蛋白凝块
                              │
                              ▼
                        封堵伤口、止住出血
```

读图注意两个“变”：凝血酶原是“被激活”成凝血酶的，血纤蛋白原是“被催化”成血纤蛋白的；最后一步不是简单的聚合，而是由 XIIIa 催化交联，产物才不溶。

级联放大反应常拿来考名词解释。它指的是：在体内的不同位置，通过一系列酶的酶促反应传递一个信息，初始信息传到系列反应的最后一步时，信号被放大，这样的一连串反应就叫级联放大反应，也叫级联系统。

```text
1 个初始信号
   │
   ├──► 3 个 ──► 许多个
   ├──► 3 个 ──► 许多个
   └──► 3 个 ──► 许多个

每经过一层酶促反应，响应的数量都成倍扩大
到最后一步，信号已经被放大
```

一个信号传给三个，三个各自又传给许多个，层层分下去，到最后一步已经是一大片响应。凝血就是这样：一个很小的伤口刺激，最后能调动起足以封住伤口的大量血纤蛋白。

### 二级结构与三级结构之间的两个台阶

纤维状蛋白讲完，话题要往回收一收：蛋白质的结构究竟是怎么一层一层搭起来的。

还是那张图。一级结构是从N端到C端的氨基酸排列顺序；二级结构是主链原子的局部空间构象；三级结构是一条肽链当中所有原子的空间位置；如果蛋白质由多条肽链组成，每条肽链叫一个亚基，不同亚基之间相对的空间位置就叫四级结构。

可二级到三级不是一步跨过去的。一条肽链上有好多个局部，就有好多个二级结构，它们中间还需要过渡性的组织方式。这中间正好有两个台阶：一个是二级结构的组合，叫超二级结构；一个是三级结构内部相对独立的一块，叫结构域。这两个都是结构单位，概念都重要，都是名词解释的常客。

#### 超二级结构：二级结构的组合

先把定义完整说一遍：在蛋白质分子中，尤其是在球状蛋白质分子中，两个或更多个相邻的二级结构单元——主要是α螺旋和β折叠——连同它们的连接部件放在一起，彼此相互作用，形成种类不多、内能降低的、有规则的二级结构组合，这就叫超二级结构，也叫模体。

定义里要咬住三个词：组合、相邻、有规则。

组合，是说它本身不是一种新的二级结构，只是既有二级结构的搭配。前面讲过的二级结构一共四种——α螺旋、β折叠、β转角和Ω环，超二级结构主要挑前两种来搭。

相邻，是说参与组合的单元在序列上挨着，中间由连接部件串起来，不是隔着老远靠空间凑到一起。

“内能降低”这四个字最容易看过去，其实它是这个组合能稳定存在的原因。一条肽链里，每一个原子都受周围一堆原子的吸引和排斥；蛋白质最终折叠成的那个状态，是对每一个原子来说受力最平衡、最“舒服”的状态，这就叫内能降低。反过来，如果内部本身就拉扯着，引力或者斥力都很大，内能就高，这个构象立不住。

“种类不多”也是要点：花样有限，才能在成千上万种蛋白质里反复出现。正因为种类有限，我们才敢把它们当成可命名的“模体”。

#### 常见的几种模体

常见的超二级结构有这么几类。

- 两个α螺旋缠绕在一起，就是卷曲螺旋。
- β折叠接α螺旋。这种组合在结合锌离子的蛋白里最典型：蛋白质本身含锌，或者发挥功能时需要结合锌离子，往往就有这么一个β折叠加α螺旋的疙瘩，也就是通常说的锌指。
- β折叠、α螺旋、β折叠、α螺旋、β折叠这样串下来。
- 两个β折叠并排。
- 五个β折叠围成一个筒，中间用无规卷曲或者Ω环连起来。这类连接用的都是不太典型的二级结构。

> **提示**：这里又要分两层旋向。单股α螺旋是右手；两股α螺旋拧成的卷曲螺旋是左手。看图时先确认自己数的是哪一层，再判断旋向。

#### 亮氨酸拉链

亮氨酸拉链值得单独拿出来说，因为后面讲分子生物学、讲转录因子的时候还会撞见它。

DNA 的功能无非两条路：复制，或者转录成RNA。这两件事都要跟大量蛋白质打交道。蛋白质上与DNA相互作用的区域，经常出现亮氨酸拉链。

它长什么样？两个α螺旋并排，一个圆柱就是一股螺旋。两个螺旋上，亮氨酸交错地、有规律地排列着。亮氨酸是疏水的，而细胞里是水相环境，疏水侧链泡在水里不舒服，于是两个螺旋上的亮氨酸彼此靠拢、聚到一起，像拉链一样咬合，把两个螺旋锁成一个二聚体。

```text
螺旋 A  ═══════════════════
           Leu    Leu    Leu      ← 疏水侧链交错咬合
螺旋 B  ═══════════════════
                │
                ▼
          拉链状二聚体
                │  两个 N 端各有一段区域
                ▼
        插入 DNA 的结构之中，与 DNA 相互作用
```

读图看两处：一排排 Leu 是“齿”，两股螺旋靠这些齿咬在一起；咬合发生在 C 端一侧，而游离出来干活的，是两个 N 端各带的一段区域。

锁好之后，两个螺旋N端各有一段区域正好能插进DNA的结构里，与DNA发生相互作用。这就是它作为转录因子结构基础的道理：拉链负责把两个蛋白亚基拴成一对，N端负责去抓DNA。

#### 结构域：蛋白质里的“手”

换个比方。假设你这个人就是一个蛋白质，而且已经告诉你：它只由一条肽链组成。那么它的最高级结构只有三级——因为没有第二条链，谈不上四级。这个三级结构里有若干独立的区域，各自管一摊事。比如你的手：手能抓、能拿，这就是它的独立功能。手，就是这个蛋白质的一个结构域。

定义是这样的：结构域是多肽链在二级结构或者超二级结构的基础上，进一步折叠形成的三级结构的局部折叠区；它在空间上相对独立，是一个紧密的球状实体；它是生物大分子当中具有特异结构和独立功能的区域。

> **定义**：结构域 = 三级结构内部的局部折叠区，空间上相对独立、紧密成球，具有特异结构和独立功能，一般由100到200个氨基酸残基组成。

它一般承担一定的生物学功能，这一点从“独立功能”四个字里已经能看出来。

结构域之间经常出现裂缝。裂缝不是缺陷，是功能位：酶的活性部位常常就在这道缝里，底物从这里进去，产物从这里出来，所谓“活性部位和反应物的出入口”。己糖激酶就是典型——整个蛋白分成两个结构域，中间夹着一道裂缝。

> **提示**：这两个概念背的时候各抓一个词。超二级结构抓“组合”——它是二级结构的组合，本身还不是三级；结构域抓“独立功能”——它已经是三级结构内部的一块，能独立干活。

### 球状蛋白与三级结构

#### 三级结构到底指什么

三级结构的完整定义很绕：多肽链在二级结构、超二级结构或者结构域的基础上，因序列上相隔较远的氨基酸残基侧链的相互作用，进一步进行范围更广的盘曲折叠，形成的包括多肽链主链、侧链所有原子或基团在内的整体空间排布。

绕就绕在它把前面几级全点了一遍。记的时候只抓两个词：整条肽链、所有原子。

**整条肽链**——划清了它和四级的界。一条链的蛋白，三级结构就是它的最高级结构；多条链的蛋白，每条链各自所有原子的空间结构是它的三级结构，链与链之间相对的空间位置才是四级结构。

**所有原子**——划清了它和二级的界。二级只管主链原子的局部构象，三级连侧链一起管，而且是整条链的范围。

> **结论**：三级结构就是整条肽链所有原子的三维空间排布。答题时把“整条肽链”和“所有原子”两个限定词写全，比背那句长定义管用。

#### 稳定三级结构的键

撑住三级结构的有两类力。

一类是二硫键。它是共价键，比较强。

另一类是各种弱相互作用，也就是弱键：疏水键、盐键、氢键和范德华力。

二硫键的归属有个坑，得说清楚。有的课本把它写进“维持一级结构的键”里。这话不算错，但要看场合。胰岛素就是那种场合：A、B两条链之间由二硫键连着，A链自身还有一处链内二硫键，一共三对，把两条链锁成一个分子；它们规定的是“哪条链和哪条链是一伙的”，属于一级结构层面的连接。

三级结构里的二硫键不一样：它是同一条链上相隔很远的两处半胱氨酸之间搭的桥，作用是把已经盘好的构象钉死。同一个键，位置不同，算的层次就不同。

三级结构的稳定和一级结构密切相关。一级结构是线性结构，二、三、四级结构是空间结构，一级结构是所有空间结构的基础，三级自然也在其中。

三级结构还有一个身份：它是单条肽链蛋白质的最高级结构。肌红蛋白就是最好的例子——只有一条多肽链，最高级结构就是三级；而且只要有了完整的三级结构，它全部的生物学功能就已经具备了。

#### 球状蛋白的内外分工

球状蛋白这部分了解就行。

大多数球状蛋白用α螺旋和β折叠片搭出球状分子的核心；三维结构具有明显的折叠层次；整个分子是一个紧密的球状或者椭球状实体。

内外分工非常明确：外表面是亲水基团，内部是疏水基团。疏水侧链埋在分子内部，亲水侧链暴露在分子表面。为什么必须这样？因为它泡在细胞的水相环境里，表面亲水才待得住，疏水侧链埋进去才不用碰水。要是内部的疏水基团不小心暴露出来，它们就会互相聚集，形成斑块，功能也跟着出问题。

分子的中心，基本上就是由α螺旋和β折叠组成的——这和“核心是螺旋与折叠片”是同一句话的两种说法。

分子表面一般还会有一个空穴。这个空穴，就是它和其他物质相互作用的位点。

### 膜蛋白的三种存在方式

膜蛋白，顾名思义，就是在膜上、或者与膜有关的蛋白质。这一块内容简单，快速过一遍，重点只有一个——概念。

先记住膜长什么样：磷脂双分子层，每个磷脂有一个亲水的极性头部加两条疏水的尾巴，头朝外、尾朝里。于是膜的内外两个表面是亲水的，中间夹着一层脂溶性的疏水区。核膜、细胞膜、线粒体膜，都是这个构造。

膜蛋白分三种：膜周边蛋白、膜内在蛋白、脂锚定蛋白。区别就在“怎么挂在膜上”。

#### 膜周边蛋白

膜周边蛋白分布在脂双层的内外表面，是可溶性的球状蛋白。

它到不了膜内部——里面是脂溶性环境，可溶性的球状蛋白进不去。它靠什么待着？靠静电相互作用和氢键，一只手抓着膜内在蛋白露在外面的亲水结构域，另一只手抓着膜脂的极性头部。

结合得弱，拆得也就容易：改变pH、改变离子浓度、加尿素，这类温和的、只破坏离子键和氢键的手段就够把它从膜上分下来。

它占膜蛋白总数的20%到30%。

#### 膜内在蛋白

膜内在蛋白是嵌进去的那一类：部分或者全部嵌在脂双层当中，有的还横跨全膜。它主要靠与脂双层的疏水相互作用和膜牢固结合，所以嵌在膜里的那些区段，必然是疏水基团组成的——整个膜内部本来就是疏水区，亲水的片段在这里待不住。

要把它弄出来，得用能破坏疏水作用的介质：去污剂、变性剂，或者有特异性作用的酶。

它是膜蛋白里的绝对多数，占70%到80%。

功能一大串：作为转运蛋白和离子通道，把外面的物质转到里面，让内外离子交换；作为激素、神经递质和生长因子的受体；参与免疫过程；参与细胞间识别——A细胞和B细胞表面各有一个跨膜蛋白，两个蛋白一搭手，两个细胞就认识了；还参与氧化磷酸化和光合磷酸化。

#### 脂锚定蛋白

脂锚定蛋白走的是第三条路：它本身不含跨膜的肽段，但身上共价连着一个脂质，靠这个脂质插进膜里，与膜牢牢结合。脂质是疏水的，膜内部也是疏水的，两者自然合得来。

因为它既可能出现在细胞溶胶里，也可能挂在膜上，所以也叫兼在膜蛋白。

```text
细胞外
──────────────────────────────  磷脂极性头部（亲水）
══════════════════════════════  疏水尾部
        ████                    膜内在蛋白：跨膜区嵌在疏水层
══════════════════════════════  疏水尾部
──────────────────────────────  磷脂极性头部（亲水）
细胞内

○ 膜周边蛋白：贴在内外表面，靠静电作用与氢键结合
◆ 脂锚定蛋白：蛋白质与脂质共价相连，脂质尾巴插进膜里
```

看这张图，三种蛋白的位置差别一目了然：贴着的在表面，嵌着的进了疏水层，拴着的不进膜、靠一根脂质尾巴锚住。

| 类型 | 与膜的结合方式 | 提取条件 | 占膜蛋白比例 |
| :--- | :--- | :--- | :--- |
| 膜周边蛋白 | 静电相互作用与氢键，结合在脂双层内外表面或膜内在蛋白的亲水结构域上 | 温和手段：改变 pH、改变离子浓度、加尿素 | 20%~30% |
| 膜内在蛋白 | 与脂双层疏水相互作用，部分或全部嵌入，部分横跨全膜 | 去污剂、变性剂、有特异性作用的酶 | 70%~80% |
| 脂锚定蛋白 | 共价连接的脂质插入膜中，自身不含跨膜肽段 | — | — |

三类膜蛋白的分工，到这里就齐了：贴着的、嵌着的、拴着的。

## 从亚基缔合到贮氧：蛋白质结构的收尾与功能的展开
> 对应块：BLK12 | 覆盖分集：P44-P50 | 块标题（分集名）：《[专题03] 考点08：四级结构和亚基缔合》

前面几讲，我们一直盯着的是一条多肽链：它怎么盘出 α 螺旋、β 折叠，又怎么折叠成一个完整的三级结构。可你去看血红蛋白——两条 α 亚基、两条 β 亚基，四条链凑成一个四聚体。这四条链，每一条自己都已经折到了三级结构，那它们拼在一起，算第几级结构？

这就是今天要讲的四级结构。它是蛋白质三维结构里结构层次的最后一层；讲完这一层，我们还要顺着往下走三步：结构被破坏会怎样（变性），破坏了还能不能装回去（复性、折叠），以及装好之后这些蛋白质在体内到底干什么（功能的多样性，以及肌红蛋白怎么贮存氧）。

先立一个总的印象：一条链有一条链的结构，多条链有多条链的规矩。四级结构讲的不是链内怎么折，而是链与链之间怎么摆、怎么接触、怎么互相影响。

### 四级结构：亚基怎样拼成一个整体

先把亚基说清楚。一个蛋白质如果由两条或两条以上的多肽链构成，那么每一条具有完整三级结构的多肽链，就称为一个亚基。

这里的落脚点有两个。第一，亚基是一条多肽链；第二，这条链得自己先折到三级结构——三级结构是一条肽链内所有原子的空间排布，是一条链能达到的最高级结构。几个亚基各自折好之后，再通过非共价键相互连接，形成一个立体的、一般呈球状的结构，这个结构才是四级结构。

反过来也成立：具有四级结构、也就是由多条多肽链组成的蛋白质，一般都是球状蛋白。

四级结构具体管哪些事？四件事：亚基的组成，也就是有哪些类型的亚基；亚基的数目，有几条；各亚基在整个分子当中的空间排布；以及亚基之间的相互作用。这四件事合起来，才是完整的四级结构。

维持四级结构的化学键，是疏水作用力、范德华力、氢键和离子键——清一色的非共价键。

> **提示**：名词解释考「什么是四级结构」，要把这几条全写上去：先讲清什么是亚基，再讲亚基之间相对的空间位置；亚基的组成、数量、排列组合；最后补一句维持它的化学键——疏水作用、范德华力、氢键、离子键。少写一条，就少一个得分点。

#### 亚基、寡聚与单体

血红蛋白就是一个现成的例子：两条 α 亚基加两条 β 亚基，组成一个球状的四聚体。

像这样由为数不多的亚基组成的蛋白质，叫寡聚蛋白质。血红蛋白就是寡聚蛋白；说得再具体一点，它是一个四聚体，由四个亚基组成。

大多数寡聚蛋白质的亚基数目是偶数，血红蛋白就是四。这个规律和我们前面讲肽的时候是一个道理：少数氨基酸连起来叫寡肽，多了叫多肽；亚基少叫寡聚，亚基多就叫多聚。由多个亚基组成的蛋白质，称为多聚蛋白质。

再往后退一步：只由一个亚基组成、也就是只有一条多肽链的蛋白质，叫单体蛋白。单体蛋白没有四级结构，它的最高级结构就是三级结构。前面讲过的肌红蛋白就是典型——一条链，一个亚基，三级结构封顶。

| 类型 | 亚基数目 | 最高级结构 | 例子 |
| :--- | :--- | :--- | :--- |
| 单体蛋白 | 一条多肽链，一个亚基 | 三级结构 | 肌红蛋白 |
| 寡聚蛋白 | 少数亚基，多为偶数 | 四级结构 | 血红蛋白（2α + 2β 四聚体） |
| 多聚蛋白 | 多个亚基 | 四级结构 | — |

这张表把三种情况摆在一起，记的时候抓住一条线：亚基数目决定最高级结构。一条链，三级结构封顶；两条以上，才有四级结构。

#### 对称性与别构效应

大多数寡聚蛋白质分子里，亚基的排列组合是对称的，至少有一个对称轴。对称性是蛋白质四级结构最重要的性质之一。

为什么强调这一点？一条链的时候，谈不上「怎么摆」；多条链凑在一起，才有排布问题，而自然界给出的答案多半是对称的。你去看血红蛋白那四条链，不是随便堆在一起的。

四级结构的优越性，很大程度上就体现在亚基之间的相互影响上。这里要引出一个名词：别构效应。这一块了解即可，但「别构效应」这四个字要会解释。

> **定义**：多亚基蛋白质一般具有多个配体结合部位。配体结合在蛋白质分子上的特定部位，会对分子的其他部位产生影响，这样的蛋白质称为别构蛋白质；这种由一个部位的结合改变另一个部位功能的调节方式，就叫别构效应。

拿血红蛋白来说，它的配体是氧气。第一个亚基结合上氧气以后，会影响到第二、第三个亚基的结构，使它们更容易结合自己的配体；第二、第三个都结合上之后，又诱导第四个亚基的结构改变，进一步促进第四个亚基结合氧气。一个接一个，越往后越容易——这叫别构激活。

有别构激活，就有别构抑制：某个配体结合上去，把其他部位对配体的亲和力压下去。

> **注意**：别构效应有时候会出名词解释。答题时两层都要有：配体结合在「特定部位」，影响的是「分子的其他部位」。只写「一个亚基影响另一个亚基」，漏掉「部位」这一层，答案是不完整的。

### 变性：散掉的是空间结构

结构讲完了，反过来问一句：这么辛苦折出来的空间结构，如果被破坏，会怎样？这就是蛋白质的变性。

> **定义**：天然蛋白质分子受到某些物理、化学因素——有机溶剂、酸、碱、高温等等——的影响，发生生物活性丧失、溶解度降低、不对称性增高，以及其他物理化学性质改变，这个过程就叫蛋白质的变性。

定义里的因果要看清：先有外界因素，然后是一组性质的变化，而这一组变化里最核心的是生物活性丧失。

生活里最典型的例子是鸡蛋。蛋清的主要成分是蛋白质。你把蛋清单独拿出来，放进一杯清水里，一开始还能看见蛋清是蛋清、水是水；放一会儿，蛋清会均匀分布到水相里，形成一个胶体溶液。这个时候，蛋白质还是天然的、有活性的。怎么把它从水里弄出来？加热。一加热，就成蛋花汤了——蛋白质变性，生物活性丧失，溶解度降低，沉淀下来，过滤也好、离心也好，都能把它去掉。

那变性的实质是什么？

> **结论**：蛋白质变性的实质是次级键被破坏，不涉及共价键的断裂。次级键是相对共价键说的：疏水作用、离子键（盐键）、范德华力、氢键这些维持立体结构的作用力被打断，空间构象散掉，生物活性随之丧失；肽键、二硫键这类共价键则不动。

尤其是肽键。肽键维持的是一级结构，所以变性的实质可以压成一句话：二、三、四级结构被破坏，一级结构保持完好。

这句话经常考，一定要记牢。变性不是把肽链剪断，而是把已经折好的形状拆散——氨基酸的排列顺序原封不动，只是空间上的那副架子塌了。

#### 变性之后能看到什么

变性的结果，前面已经露了几条，这里系统过一遍。

最显著的一条是生物活性丧失。蛋白质变性以后就失活了，这是变性最主要的特征。

第二条是侧链基团暴露。原本包在蛋白质内部的疏水基团，变性时被翻到外面来；这些疏水基团一暴露，分子之间就容易相互聚集。还有一些原本包藏在内部、不容易与化学试剂反应的侧链基团，也被放了出来，放出来以后就能和化学试剂起反应了。

第三条是物理化学性质的改变。疏水基团外露，分子又发生聚集，溶解度自然降低，也更容易沉淀下来；同时分子的不对称性增高。

第四条是生物化学性质的改变：变性的蛋白质比天然蛋白更容易受到蛋白水解酶的作用。

这条在生活里天天遇到。我们吃东西，家长总强调要做熟了吃——做熟的过程，就是让食物里的蛋白质变性。变性蛋白在体内更容易被蛋白水解酶水解，也就更容易消化。反过来，生吃、吃下去没有变性的蛋白，它可能还带着一定的活性，吃进去就可能闹肚子，甚至产生毒性。

> **易错点**：变性不等于水解。变性只拆空间结构，肽键完好，所以变性蛋白的肽链仍然是完整的，只是折法乱了；水解才是把肽键切开、把链剪短。两者常被混为一谈，答题时千万分清。

#### 变性剂怎样把蛋白质拆散

变性剂重点看两种：尿素和盐酸胍。

它们使蛋白质变性，靠两条机制。

第一条，与多肽链的主链竞争氢键，破坏蛋白质的二级结构。二级结构是三级结构的基础，二级结构被破坏，三级结构也就保不住了。

第二条，也是更重要的原因：它们增加疏水侧链在水中的溶解度，从而降低维持蛋白质三级结构的疏水相互作用。

这句话要展开一下。三级结构为什么能在水环境里形成？因为在水里，疏水基团会自发聚集，形成疏水核心；亲水基团自然而然地朝向外面，于是有了那个特定的空间构象。尿素、盐酸胍一加进去，把疏水侧链在水里的溶解度抬高了，疏水基团自发聚集的动力就弱了——原来紧紧抱成一团的疏水核心散开，肽链也就散架了。

还有 SDS。SDS 是一种去污剂，属于阴离子表面活性剂。它同样破坏蛋白质分子当中的疏水作用：疏水基团被暴露到水介质里；同时它降低了疏水侧链从疏水内部转移到水介质的转移自由能，也就是让疏水侧链更容易跑到水相里去。疏水核心本来是靠疏水作用力紧紧结合在一起的，现在每个侧链都愿意往水里跑，核心自然就散了。

把这条路径画出来：

```text
天然构象（疏水核心在内、亲水基团在外）
        │
        │  加热 / 强酸 / 强碱 / 有机溶剂
        │  尿素、盐酸胍：竞争氢键 + 抬高疏水侧链溶解度
        │  SDS：破坏疏水作用 + 降低转移自由能
        ▼
次级键断裂 → 疏水侧链暴露 → 肽链松散
        │
        ├──▶ 分子间疏水聚集 → 溶解度降低 → 沉淀
        └──▶ 更易被蛋白水解酶水解

（一级结构：肽键、二硫键保持完好）
```

图里最后那行括号是关键：不管走哪条变性路线，被拆掉的都是次级键，肽键和二硫键不动。

### 复性与折叠：散了的还能不能装回去

变性讲完，自然要问：把变性因素去掉，蛋白质能不能回到原来的样子？能，但有条件。这个返回的过程叫复性。

> **定义**：变性蛋白质分子除去引起它变性的因素，恢复到原来的天然构象和生物活性，这个现象就叫蛋白质的复性。

#### 复性的前提

不是所有变性的蛋白质都能复性。煮熟的鸡蛋、煎好的荷包蛋，里面的蛋白质还回得去吗？回不去了。只有变性程度较轻的蛋白质，才有可能复性。

操作上，多采用透析或者超滤这些方法，把变性剂去掉，让蛋白质重新折叠。前提仍然是变性程度要低——变性程度太高，就回不去了。

> **注意**：复性的关键词是「除去变性因素」和「恢复天然构象与生物活性」，两个都要写。只写「恢复活性」，漏掉「除去变性因素」这个前提，概念就不完整。

#### 分子伴侣：Hsp70 与 GroEL/GroES

多肽链在生物体内合成出来以后，一定要折叠成一个特定的空间构象，才具有功能；折不成那个构象，它就没有功能。

而折叠这件事，不是肽链自己就能顺利完成的，需要一系列蛋白质协助：肽基脯氨酰异构酶、分子伴侣家族、蛋白质二硫键异构酶等等。这里重点讲分子伴侣家族。

分子伴侣家族里有一类叫热激蛋白，缩写 HSP。H 是热（heat），S 是应激（stress），P 是蛋白质（protein）。HSP70 就是分子量 70 kD 左右的一种热激蛋白。

一条新生的多肽链，还没折叠好，处于第一种状态，不具有功能；第二种状态是已经折叠好、具有功能的构象。HSP70 这类分子伴侣的作用，就是帮助没有完全折叠的蛋白质折叠成最终有功能的空间构象。

另一组是 GroES 和 GroEL。GroEL 像一个桶，GroES 像一个盖子。

为什么需要一个桶？新生肽链在折叠过程中，有时候不得不把疏水基团暴露在外面。可细胞里同一种蛋白质有千千万万个拷贝——一号的疏水侧链暴露出来，二号、三号、五号、六号、七号、八号也可能暴露出来，彼此的疏水基团一碰头就聚集，聚成一团，就再也折不成有活性的状态了。

GroEL 的桶里是疏水的、没有水，相当于给肽链提供了一个相对疏水的微环境：肽链进去，可以把疏水侧链暴露着折叠，不怕被别人的疏水侧链粘住；折叠好了，再放出去。GroES 就是盖在桶口的那层盖子。

```text
                GroES（盖子）
              ┌────────────┐
              │            │
           ┌──┴────────────┴──┐
           │                  │
           │   GroEL 桶腔      │  ← 内部疏水、无水
           │  肽链在此折叠      │
           │                  │
           └──────────────────┘
```

读图：GroEL 围出一个与外界水相隔绝的桶腔，GroES 把桶口盖上；新生肽链在腔内折叠，疏水侧链可以暂时外露，而不至于和别的肽链聚成一团，折叠完成后再从腔内释放。

### 蛋白质的功能：远不止催化

结构讲完，接下来回答一个更朴素的问题：这些蛋白质在体内到底干什么？

生物体里几乎所有的生命活动过程都有蛋白质参与，所以蛋白质的功能注定是多种多样的。这一节内容不难，但例子多，混个脸熟很重要。

| 功能 | 例子 | 一句话说明 |
| :--- | :--- | :--- |
| 催化与转化 | 唾液淀粉酶、转氨酶 | 生物体内几乎所有化学变化都是酶促反应 |
| 信号分子与信号转导 | 胰岛素及其受体 | 受体接收信号后把信号传进细胞 |
| 转运 | 血红蛋白、转铁蛋白 | 专一地运输分子或离子 |
| 结构与支撑 | α-角蛋白、胶原蛋白 | 为细胞和机体提供结构支持 |
| 运动与动力 | 肌球蛋白、肌动蛋白 | 两者相互滑动导致肌肉收缩或松弛 |
| 防卫保护与免疫 | 免疫球蛋白、淋巴细胞受体 | 识别与清除外来物 |
| 养分储存 | 卵清蛋白、酪蛋白 | 为胚胎发育或幼体提供营养 |
| 支架与衔接 | 支架蛋白 | 把多个信号蛋白聚到一起 |
| 调节 | 周期蛋白 cyclin | 调节 CDK 活性，进而调节基因表达 |
| 奇异功能 | 甜蛋白 | 极高的甜度，天然甜味剂 |

表里每一行都值得停一下，挑几个有意思的说。

先说催化。生物体内所有的化学变化，本质上都是酶促反应。唾液淀粉酶催化淀粉在唾液里变成麦芽糖——这就是为什么我们嚼馒头会嚼出甜味。你要是配一口咸菜，馒头会更甜：咸菜里有氯化钠，氯离子是唾液淀粉酶的一种非必需激活剂，有了氯离子，淀粉酶活性更高，转化出来的麦芽糖更多。

转氨酶是肝脏里的一种酶，代表是谷丙转氨酶。它催化谷氨酸和丙氨酸之间氨基的转移：谷氨酸脱掉氨基，变成 α-酮戊二酸；脱下来的氨基转给丙酮酸，丙酮酸得到氨基就变成丙氨酸。

再说信号。胰岛素和它的受体结合，最终导致血糖下降。饭后血糖升高，胰岛素分泌，通过血液循环到达靶细胞——机体绝大多数细胞都有胰岛素受体——胰岛素把信号交给受体，受体再把信号传到细胞内部、甚至细胞核，让细胞启动降血糖的程序。对普通细胞来说，就是加速摄取葡萄糖，把血里的葡萄糖降下来。

转运这一栏，血红蛋白运氧气，转铁蛋白运三价铁离子。转运氧气的蛋白不止血红蛋白，还有肌红蛋白——那是后面两节的主角。

结构支撑这一栏，毛发里的 α-角蛋白、结缔组织里的胶原蛋白都是。人的皮肤衰老、长皱纹，一个原因就是结缔组织里的胶原蛋白减少，支撑力下来了。

运动靠肌球蛋白和肌动蛋白相互滑动，肌肉细胞因此收缩或者松弛。防卫保护和免疫靠免疫球蛋白、淋巴细胞受体。养分储存靠卵清蛋白和酪蛋白——卵清蛋白为鸟类胚胎发育提供能量，乳汁里富含酪蛋白。

支架蛋白这一栏值得多看一眼。支架蛋白像一张桌子，ABCDE 五种蛋白质都坐在同一张桌子上。这五种蛋白在细胞内传递信号时需要互相接触，可它们自己找不到对方；支架蛋白把它们全都放到同一个支架上，彼此挨着了，信号就能传下去。用大白话说，支架蛋白就是「传了一个局」，把该见面的人凑到一张桌子上。

调节这一栏，周期蛋白 cyclin 调节 CDK 的活性。CDK 是 cyclin-dependent kinase，周期蛋白依赖的激酶。CDK 再往下游走，可以调节基因表达。

最后还有一类不好归类的奇异功能：有的水果里含有甜蛋白，甜度极高，是一种天然甜味剂。

### 氧与血红素：为什么非得是亚铁离子

下面进入这一讲的最后一个考点：氧结合蛋白——肌红蛋白，它的看家本领是贮存氧。要讲肌红蛋白，得先讲氧凭什么能挂在蛋白质上。

氧气难溶于水。多细胞生物要转运氧气，得靠亚铁离子或者亚铜离子来结合它。绝大多数我们生活里能见到的动物——包括人——选的是亚铁离子；亚铁离子结合氧气以后显红色，这就是血液的颜色。

另一些节肢动物选了亚铜离子，血液显蓝色，它们体内运输氧的蛋白叫血蓝蛋白。

在人这样的生物体里，肺里携带着氧的亚铁离子要运到全身各个组织器官，最远到手指、脚趾，转运距离是以米来计的。这么远的距离，亚铁离子不能自己漂过去，得有一个载体：先把它装进辅基——血红素，血红素再把自己放进一个蛋白质里。这个蛋白质就是珠蛋白，包括肌红蛋白和血红蛋白。

所以这条链是：亚铁离子先装进血红素，血红素再嵌进珠蛋白。一层套一层，为的就是把难溶于水的氧安全地运到几米之外。

含有血红素的蛋白质，主要是肌红蛋白、血红蛋白，还有许多称为血红素蛋白的其他蛋白。这门课里重点就两个：肌红蛋白和血红蛋白。

#### 血红素的六配位

血红素的结构有一个卟啉环母核，最中间是一个铁原子。铁可以有六个配位键：其中四个和卟啉环上的四个氮原子相连；剩下两个，一个用来结合氧气，另一个连到蛋白质上——连的就是那个能贮存或运输氧的蛋白质，比如肌红蛋白、血红蛋白。

```text
        平面内：4 个 N（来自卟啉环）与 Fe²⁺ 配位

                  N
                  │
             N ─ Fe²⁺ ─ N
                  │
                  N

        轴向：2 个配位位置
                  │
                  ├── O2
                  └── 蛋白质
```

读图：中心的 Fe²⁺ 一共伸出六根「手」——四根抓住卟啉环的四个氮原子，一根抓住氧气，一根抓住蛋白质。氧和蛋白质各占一个配位位置，这就是血红素既能「挂」在蛋白上、又能「抓」住氧的结构基础。

人体里除了血红素，还有一些细胞色素类的物质也是这样的结构。

关键的一条：只有亚铁离子，也就是二价铁，才能结合氧气。二价铁一旦失去一个电子变成三价铁，就不能运输氧气了。

> **易错点**：不是「铁」能结合氧，而是「亚铁离子」能结合氧。三价铁已经失去了这个能力，写答案时别把价态漏掉。

#### 一氧化碳为什么能杀人

一氧化氮和一氧化碳与血红素铁配位的亲和力都比氧气高。三者同时存在时，血红素优先选择一氧化氮和一氧化碳。

一氧化碳一旦结合上去，因为它亲和力更高，氧气就被挤出去了。这就是一氧化碳对生物剧毒的原因，也是一氧化碳中毒的机制：氧气被从血红蛋白的血红素里挤走，机体缺氧窒息。

> **提示**：这里说的「血红素铁」，指的就是那个二价铁。一氧化碳抢占的是氧气的配位位置，不是把铁氧化成三价铁——它是「占座」，不是「换人」。

#### 动脉血与静脉血的颜色

两管血放在一起，动脉血是鲜红色，静脉血是紫红色，肉眼看上去甚至有点发黑。

差别来自含氧量：动脉血富氧，亚铁离子携带的氧气多；静脉血相对缺氧。

为什么含氧量不同，颜色就不同？因为亚铁离子与氧结合以后，电子的性质发生了变化；电子性质一变，颜色就跟着变。

所以血液的颜色不是一个孤立的表象，它背后是血红素里那个铁原子的电子状态。

### 珠蛋白家族与肌红蛋白

珠蛋白是一个大家族，里面有很多不同类型的蛋白质，但它们有相似的一级结构和三级结构，都能结合氧气。

家族里最重要的两个是肌红蛋白和血红蛋白。肌红蛋白只有一条多肽链，是一个单体，最高级结构就是三级结构；血红蛋白由四条多肽链组成，是四个亚基的四聚体。血红蛋白的每一个亚基，结构都和肌红蛋白相似。

每个肌红蛋白里有一个血红素，血红蛋白的每个亚基里也有一个血红素，所以血红蛋白里有四个血红素。一个血红素携带一个氧气，于是肌红蛋白一次携带一分子氧，血红蛋白一次携带四分子氧。

功能上两者相似，都能转运和贮存氧，但侧重不同：血红蛋白主要转运氧，肌红蛋白主要贮存氧。当然，肌红蛋白存下来的氧最终也要运出去，所以它既贮存也转运。

| 比较项 | 肌红蛋白 | 血红蛋白 |
| :--- | :--- | :--- |
| 多肽链数 | 1 条 | 4 条（2α + 2β） |
| 亚基与最高级结构 | 单体，三级结构 | 四聚体，四级结构 |
| 血红素数 | 1 个 | 4 个 |
| 一次携带氧 | 1 分子 | 4 分子 |
| 主要功能 | 贮存氧（也转运） | 转运氧 |
| 分布 | 肌肉组织 | 血液 |

#### 肌红蛋白的三级结构

肌红蛋白由一条珠蛋白链和一个血红素组成，与血红蛋白同源。

这一条多肽链里有八段 α 螺旋，依次命名为 A、B、C、D、E、F、G、H。整条链里 78% 的氨基酸残基都在 α 螺旋中，差不多五分之四——大部分氨基酸都用来搭这几段螺旋了。

它的功能是促进肌肉组织中氧的扩散。注意，肌红蛋白只在肌肉组织里有。

还有一个常考的点：肌红蛋白是第一个被完整解析出三级结构的蛋白质。选择题、填空题都可能考。

> **提示**：肌红蛋白是单体，最高级结构就是三级结构；但它并不是「结构简单、没什么可考」——第一个三级结构、八段螺旋、一个血红素、一条氧合曲线，考点都在这儿。

#### 从细胞膜到线粒体

肌肉组织里，毛细血管中血红蛋白释放的氧气穿过细胞膜进入肌肉细胞，在细胞膜内侧与去氧肌红蛋白结合，变成氧合肌红蛋白。

氧合肌红蛋白在细胞溶胶中向线粒体扩散。为什么往线粒体跑？因为细胞里真正利用氧气的地方就是线粒体。

当线粒体中的氧浓度下降时，氧合肌红蛋白把贮存的氧释放给线粒体，自己变回氧肌红蛋白，回到细胞膜内侧，等待血红蛋白释放进来的下一批氧气。

整个过程是一个可逆结合、定点装卸的循环：在细胞膜内侧装氧，在线粒体旁边卸氧。装和卸不在同一个位置，氧就被从膜内侧传递到了线粒体。

```text
毛细血管中的血红蛋白
        │ 释放 O2
        ▼
肌细胞膜 ──▶ 去氧肌红蛋白（空载）
                    │ 结合 O2
                    ▼
              氧合肌红蛋白
                    │ 在细胞溶胶中扩散
                    ▼
                 线粒体（耗氧场所）
                    │ O2 被释放
                    ▼
              去氧肌红蛋白
                    │
                    └──▶ 回到细胞膜内侧，等待下一批 O2
```

读图：氧的路线是一条单向循环——膜内侧装载、线粒体卸载、空载返回。肌红蛋白本身不消耗氧，它只是把氧从膜内侧「摆渡」到线粒体旁边。

#### 氧合曲线与 P50

肌红蛋白与氧的结合有一条曲线。横轴是氧分压，也就是氧的浓度；单位是 Torr（托），1 Torr 就等于 1 mmHg。纵轴是饱和度：1 表示 100%，即所有肌红蛋白都结合了氧；0.5 表示 100 个肌红蛋白里有 50 个结合了氧。

P50 指的是肌红蛋白被氧半饱和时的氧分压。肌红蛋白的 P50 大约是 1 Torr。

曲线一开始就是陡直上升：氧分压从 0 到 1 mmHg 这么一点点，肌红蛋白就立刻结合氧气。这说明它对氧的亲和力很高——只要有一点点氧，它就抓得住。

```text
饱和度
100% ┤              ●───●───
     │          ●
 50% ┤      ●   ← P50 ≈ 1 Torr
     │    ●
  0% ┼──●────────────────────▶
     0   1   2   3   4   PO2 / Torr
```

读图：曲线在低氧分压区几乎垂直上升，很快就接近饱和；半饱和点落在 1 Torr 附近。这样的走势对应的就是高亲和力——低氧分压下也能迅速把氧抓住。

#### 结构如何改变配体的命运

蛋白质的结构会影响它和配体的结合。肌红蛋白的配体是氧气。拿一氧化碳来比：一氧化碳结合游离血红素的能力，比氧气高 25000 倍。这就是前面说的一氧化碳中毒——它把血红素里的氧挤走，自己占住位置。

可把血红素放进肌红蛋白里以后，情况变了。肌红蛋白有空间结构，中间塞了一个血红素，此时血红素结合一氧化碳的能力只比氧气高 200 倍。

$25000 \div 200 = 125$。同一个血红素，游离时和装在蛋白质里，对一氧化碳的偏好差了 125 倍。

> **结论**：蛋白质不是被动地驮着一个配体。它自身的空间结构会改变配体的结合性质——肌红蛋白把血红素包进自己的结构里，一氧化碳的相对优势就从 25000 倍被压到了 200 倍。

把这一讲串起来看：四级结构回答的是「多条链怎么拼」；变性和复性回答的是「拼好的结构散了以后会怎样、还能不能装回去」；折叠回答的是「装回去这件事在细胞里由谁帮忙」；功能多样性回答的是「装好之后能干什么」；肌红蛋白则给了一个具体样本——一个单体、一个血红素、一条可逆的氧结合曲线，把结构和功能扣在了一起。

从三级结构到四级结构，再到变性、复性与折叠，最后落到肌红蛋白这个具体的功能样本——蛋白质结构这条线，到这里就完整地走了一遍。

## 氧结合蛋白质：血红蛋白的运氧与分子病
> 对应块：BLK13 | 覆盖分集：P51-P54 | 块标题（分集名）：《[专题04习题]考点2：氧结合蛋白质——肌红蛋白》

血液从肺里出来的时候，血红蛋白的氧饱和度是 96%；等它在外周组织转一圈、回到心脏，只剩 60%。这 36 个百分点，就是血红蛋白这一趟真正交出去的货。前面讲过的肌红蛋白 Mb 负责把氧存起来，今天讲的血红蛋白 Hb 负责把氧运出去——同样结合氧，一个管囤，一个管跑。

这一讲先看血红蛋白靠什么结构完成运输，再看这套结构里写错一个氨基酸会出多大的事。

### 四个亚基，四个氧

血红蛋白，简写 Hb；前面讲过的肌红蛋白，简写 Mb。名字只差一个字，分工不同：肌红蛋白把氧存着，血红蛋白把氧运走。

血红蛋白在血液里转运氧气，这是它的主要功能。肺里氧多，血红蛋白在肺里把氧装上；血液流到外周组织，再把氧交出去。数字很直观：动脉血里，血红蛋白的氧饱和度是 96%；等血液回到心脏、变成静脉血，饱和度只剩 60%。从 96% 掉到 60%，掉的这部分就是组织用掉的氧。

血红蛋白不是一个亚基干完所有活，它是四个亚基组成的四聚体。每个亚基上都有一个氧结合部位，所以一个血红蛋白一次可以结合四分子氧。

血红蛋白在红细胞里的质量占比高达 34%。红细胞为什么是红的？因为二价铁离子结合氧气以后会显红色——上节课讲血红素时说过这件事，血红蛋白的颜色就来自这里。

脊椎动物的血红蛋白有四个多肽亚基，但亚基的种类很多。现在已经发现的至少有七种：α、β、Aγ、Gγ、δ、ε、ζ。四个位置从这七种亚基里挑，挑法不同，就有了不同的血红蛋白类型：

| 血红蛋白 | 亚基组成 | 在哪里为主 |
| :--- | :--- | :--- |
| HbA | α2β2 | 成人红细胞中的主要形式 |
| HbF | α2γ2 | 胎儿时期的主要形式 |
| HbA2 | α2δ2 | 成人体内约占 2% |

成人主要掌握 α2β2，胎儿主要掌握 α2γ2。为什么这两个要单独记？因为后面讲胎儿怎么从母体获取氧气，靠的就是这两种血红蛋白对氧的亲和力有差异。HbA2 只占成人血红蛋白的 2%，了解即可。

每个亚基都有一个血红素。血红素就是结合氧气的部位，中间有一个二价铁离子。这个铁离子有六个配位键：四个与血红素的卟啉环相连，一个连蛋白质，一个连氧气。

```text
                    O2
                     │  第 6 个配位键
                     │
                  ┌──Fe2+──┐
                  │        │
        卟啉环 4 个氮原子   蛋白质
        （第 1～4 个键）    （第 5 个键）
```

读图：亚铁离子的六个配位键里，四个交给血红素本身，一个交给蛋白质，最后一个留给氧气。所以一个亚基一个血红素、一个氧结合部位；一个血红蛋白四个亚基，正好带四个氧。账要这么算，别把“四聚体”和“四个氧”当成两件互不相干的事。

### 红细胞里的四聚体怎样维系

血红蛋白主要存在于红细胞中。成熟的红细胞是一个小的双凹圆盘状细胞，没有细胞核、没有内质网、没有线粒体，这些细胞器都没有，所以它不能增殖，是一次性的，寿命只有 120 天。

按形状给蛋白质分类，可以分成纤维状蛋白和球状蛋白；血红蛋白是球状蛋白。

四个亚基之间的结合力不一样。两条不同链之间的亚基相互作用最大，相同链之间的亚基相互作用最小。以 HbA 的 α2β2 为例：α 和 β 之间的作用力强，α 与 α 之间、β 与 β 之间的作用力都比较弱。

这个差别可以用尿素试出来。尿素处理以后，四聚体解离成两个二聚体——α1β1 和 α2β2。注意，是两个保持完整的 αβ 二聚体，不是四条散开的单链。不同链之间的界面强，同种链之间的接触面弱，尿素先拆开的是后者。

换句话说，血红蛋白可以看成两个 αβ 二聚体拼起来的。每一条链单独看，三级结构都和肌红蛋白相似；功能也相似，都能结合一个氧。肌红蛋白只有一条多肽链，血红蛋白的每个亚基就像是它的一个翻版，四个这样的亚基拼在一起，才组成完整的血红蛋白。

### T 态与 R 态：一块被捏紧的海绵

血红蛋白主要有两种构象：T 态（tense，紧张态）和 R 态（relaxed，松弛态）。这两种状态对氧气的结合能力不一样。

T 态结构比较紧密，与氧的亲和力小；R 态结构比较松弛，与氧的亲和力大。

怎么理解？把血红蛋白想成一块吸水的海绵：海绵是血红蛋白，水是氧气。T 态就是海绵被捏紧了，捏得越紧，吸水能力越弱；R 态就是海绵放松了，放得越松，吸水能力越强。

氧气与 T 态血红蛋白不太容易结合。但只要有一个氧气结合到 T 态血红蛋白的一个亚基上，就会促使整个四聚体的构象朝 R 态转变；R 态与氧的亲和力大，剩下的亚基再结合氧就容易了。

反过来，氧释放以后，血红蛋白也会回到 T 态；T 态对氧的亲和力低，剩下的氧就更容易继续放掉。T 态和 R 态这样来回切换，血红蛋白才能在肺里抓氧、在组织里放氧。

> **易错点**：T 态是绷紧的低亲和力状态，R 态是松开的高亲和力状态。别把 tense（紧张）理解成“活跃”，也别把 relaxed（松弛）理解成“不工作”。

### 协同效应：一个氧带来的连锁反应

一个氧结合以后会改变其他亚基对氧的结合能力，这就是协同效应。这里经常出名词解释，三个概念要分清楚。

> **定义**：协同效应 —— 一个配体与蛋白质上的一个亚基结合，会影响同一蛋白质中其他亚基与配体的结合能力（亲和力）。

> **定义**：正协同效应 —— 一个配体与蛋白质上的一个亚基结合后，促进同一蛋白质上其他亚基与配体的结合。

> **定义**：负协同效应 —— 一个配体与蛋白质上的一个亚基结合后，抑制同一蛋白质上其他亚基与配体的结合。

注意定义里的动词是“影响”，不是“促进”。一个配体结合，可能促进也可能抑制；促进的叫正协同，抑制的叫负协同。

对血红蛋白来说，配体就是氧气，它受正协同调节：第一个亚基结合氧以后，促进第二个和第三个亚基结合氧；第二个和第三个亚基也结合上氧以后，促进第四个亚基结合氧。

回到前面那句话：没有结合氧的时候，血红蛋白是 T 态；只要结合上去一个氧，就促使它由 T 态朝 R 态转变，从而更容易结合氧。正协同效应在血红蛋白上，就是这么一个“一个带动三个”的过程。

### 氧合曲线为什么是 S 形

把血红蛋白的氧饱和度对氧分压作图，得到氧合曲线。横轴是氧分压，也就是氧气的多少；纵轴是氧饱和度，100% 表示每一个血红蛋白的四个位点都被氧占满。

这条曲线是 S 形的：先缓、再陡、后平。

```text
氧饱和度
100% ┤                          ┌────────────
     │                      ╱
 75% ┤                  ╱
     │              ╱
 50% ┤          ╱
     │       ╱
 25% ┤    ╱
     │ ╱
  0% └────────────────────────────────────→ 氧分压
       缓慢        陡升         平台
```

读图：横轴从左到右是氧分压升高，纵轴从下到上是氧饱和度升高；曲线先缓、再陡、最后走平。

为什么会是这三段？原因就在协同效应。

- 起始段缓：第一个亚基与氧结合比较难，血红蛋白还在 T 态；氧分压升高一点，饱和度上不去多少。
- 中段陡：第一个氧结合以后，立刻促进第二、第三、第四个亚基结合氧，T 态转 R 态，饱和度直线上升。
- 末段平：所有血红蛋白都被氧饱和，四个位点都占满，再增加氧分压也装不下了。

> **结论**：S 形曲线是“第一个氧难、后面三个氧容易”这件事在坐标图上的投影。

这条 S 形曲线对血红蛋白的功能很重要。在静脉血、在外周组织里，氧分压比较低，血红蛋白不容易结合氧，更倾向于释放氧、把氧卸载给组织；到了肺里，氧含量很高，血红蛋白结合氧的能力增强，就把氧装上。

以骨骼肌为例：肌肉细胞里氧分压低，血红蛋白在这里卸氧；肺里氧分压高，血红蛋白在这里装氧。一装一卸，氧就从肺运到了远端组织。

把开头的两个数字放回这条曲线：肺里接近饱和，落在平台段；血液流到组织，氧分压降下来，曲线正处在陡升段，饱和度随之大幅下降——96% 到 60% 的落差，就是在这段陡坡上完成的。

### 波尔效应：氢离子把氧挤走

血红蛋白不只运氧。它还运氢离子和二氧化碳：转运的氢离子占体内总氢离子的 40%，转运的二氧化碳占总二氧化碳的 15% 到 20%。二氧化碳从组织运到肺和肾脏，到肺里通过呼吸呼出去，到肾脏里通过尿液排出去。

血红蛋白与氧的结合还受环境里其他分子的调节，主要有两类：一类是氢离子和二氧化碳，另一类是 2,3-二磷酸甘油酸（2,3-BPG，简称 BPG）。

先看氢离子和二氧化碳。它们会促进氧的释放，这个作用叫波尔效应（Bohr effect）。

具体怎么发生的？氧气与血红蛋白的结合受 pH 和二氧化碳浓度的影响。去氧血红蛋白——没有结合氧的血红蛋白——对氢离子的亲和力比氧合血红蛋白大。换句话说：血红蛋白结合了氧以后，更不容易结合氢离子；释放了氧、变成去氧血红蛋白以后，更容易结合氢离子。

反过来也成立：降低 pH，也就是增加氢离子浓度，会促进氧合血红蛋白释放氧，变成去氧血红蛋白。

这其实是双向的、互斥的：氢离子进来，把氧挤走；氧回来，把氢离子挤走。血红蛋白与氧的结合、与氢离子和二氧化碳的结合，是互斥的——要么结合氢离子和二氧化碳，要么结合氧。

> **定义**：波尔效应 —— 氢离子和二氧化碳影响血红蛋白与氧气亲和力的效应。氢离子和二氧化碳浓度增加，会降低血红蛋白与氧气的亲和力，使氧合曲线右移，促进血红蛋白释放氧气。

为什么曲线会右移？因为氢离子存在时，血红蛋白与氧的亲和力变弱；要达到同样高度的饱和度，就需要更多的氧气。同样的饱和度需要更大的氧分压，曲线自然往右挪。

这里有一组 pH 要记住：

| 场景 | pH | 氢离子与二氧化碳 |
| :--- | :--- | :--- |
| 氧结合实验的测定条件 | 7.4 | 标准对照 |
| 肺 | 7.6 | 较低 |
| 组织（如骨骼肌） | 7.2 | 较高 |

组织比肺酸，氢离子更多。氢离子和二氧化碳一般是同时存在的：二氧化碳在水里会生成碳酸，碳酸是酸性物质，也会解离出氢离子。所以二氧化碳多的地方，氢离子通常也多。

波尔效应的生理意义，要从肺和组织两个场景看。

血液流经肌肉等组织时，pH 较低，氢离子和二氧化碳浓度较高。这时血红蛋白释放氧，同时结合氢离子和二氧化碳。氧被放到了肌肉里，肌肉代谢生成的二氧化碳和氢离子又被带走了。不仅如此，它还能把肌肉细胞呼吸作用生成的二氧化碳一并带走，并把呼吸作用产二氧化碳引起的 pH 下降缓冲掉——血红蛋白把氢离子也带走了，所以能起到缓冲血液 pH 的作用。

血液流经肺部时，氢离子和二氧化碳浓度较低。这时血红蛋白结合氧，同时释放氢离子和二氧化碳。二氧化碳通过呼吸呼出去以后，血液里二氧化碳减少，碳酸也减少，pH 上升；pH 上升又进一步促进血红蛋白与氧结合。

```text
肺（氧分压高，pH 7.6，二氧化碳低）
        │
        │  血红蛋白结合氧，释放氢离子和二氧化碳
        ▼
动脉血（氧饱和度 96%）
        │
        │  血液流向外周组织
        ▼
组织（氧分压低，pH 7.2，二氧化碳高）
        │
        │  血红蛋白释放氧，结合氢离子和二氧化碳
        ▼
静脉血（氧饱和度 60%）
        │
        │  回到肺，呼出二氧化碳
        └──────────────→ 二氧化碳减少，pH 回升，重新结合氧
```

读图：同一个血红蛋白在肺和组织两种环境里来回切换；pH 和二氧化碳就是那个开关，决定它是抓氧还是放氧。

波尔效应记起来不难：血红蛋白运氧的时候，对氢离子和二氧化碳的亲和力低；运氢离子和二氧化碳的时候，对氧的亲和力低。两种货不能同时满载。

> **提示**：这一条是重点，考试常考。把“氢离子进来、氧出去；氧进来、氢离子出去”记住，曲线右移和生理意义都能顺着推出来。

### BPG：把血红蛋白按在 T 态

2,3-二磷酸甘油酸（2,3-BPG）是血红蛋白的别构抑制剂。它降低血红蛋白对氧气的亲和力：BPG 来了，血红蛋白更不容易结合氧，或者说更容易释放氧。

哪些组织需要血红蛋白释放氧？肌肉细胞就是。肌肉细胞里含有 BPG，可以促进血红蛋白释放氧。所以 BPG 的作用是增加血红蛋白在组织中的泄氧量——把氧卸载下来。

BPG 浓度越大，血红蛋白的氧饱和曲线越往右移。原因和波尔效应一样：它抑制血红蛋白与氧的结合，要达到同样的氧饱和度，就需要更多的氧气。

BPG 靠什么起作用？它稳定血红蛋白的 T 态。T 态是紧张态，与氧的亲和力小；血红蛋白被按在 T 态，氧就更容易被卸载下来。

还有一个现实限制：缺少 BPG 不能靠体外补充，因为 BPG 不能透过红细胞膜。

人从低海拔到高海拔以后，红细胞里的 BPG 浓度会很快上升。上升以后干什么？帮助血红蛋白在组织当中释放氧。

> **提示**：BPG 不是帮血红蛋白“装氧”的，而是让血红蛋白“别把氧抓太紧”。高海拔时身体上调 BPG，是为了在组织里把氧放下来。

### 胎儿怎样从母亲手里拿氧

前面埋的伏笔在这里收。胎儿的血红蛋白主要是 HbF，α2γ2；成人的血红蛋白主要是 HbA，α2β2。两者只差一条链：胎儿是 γ 链，成人是 β 链。

差异落在 γ 链的 H 螺旋第 21 位。γ 链在这里是丝氨酸，β 链在这里是组氨酸。

这个丝氨酸带来一个优势：它减少了 BPG 结合部位的正电荷，降低了胎儿血红蛋白对 BPG 的亲和力。前面讲过，BPG 是抑制血红蛋白与氧结合的物质。胎儿血红蛋白结合更少的 BPG，受到的抑制更小，对氧的亲和力就更高。

母亲的血红蛋白用的是 β 链，第 21 位是组氨酸，更容易结合 BPG，对氧的亲和力相对更低。于是胎儿的血红蛋白比母亲的血红蛋白对氧的亲和力更高，就可以从母亲体内把氧拿过来。

| 血红蛋白 | 亚基组成 | H 螺旋第 21 位 | 结合 BPG | 对氧的亲和力 |
| :--- | :--- | :--- | :--- | :--- |
| 成人 HbA | α2β2 | β 链为组氨酸 | 较多 | 较低 |
| 胎儿 HbF | α2γ2 | γ 链为丝氨酸 | 较少 | 较高 |

这张表的推理链是单向的：γ 链丝氨酸 → BPG 结合部位正电荷减少 → 结合 BPG 少 → 对氧的抑制小 → 对氧亲和力高 → 胎儿能从母体取氧。顺着链条推一遍，比死记“胎儿亲和力高”更稳。

### 分子病与镰状细胞贫血

接下来换一个角度：血红蛋白的分子病。这一块主要讲一个疾病——镰状细胞贫血，也叫镰刀状红细胞性贫血。

正常的红细胞是一个比较小的双凹圆盘状细胞，里面装着血红蛋白。血红蛋白在肺里结合氧，再把氧运输到其他组织器官。

镰状细胞贫血病人的红细胞变了：从双凹圆盘状变成了镰刀状。镰刀状的红细胞丧失了运输氧气的功能。血液里大量出现这种镰刀状红细胞，患者就会缺氧窒息——因为它们不能像正常红细胞那样给组织细胞运氧。

这个病的原因是遗传基因突变，导致血红蛋白分子结构改变，最终引起细胞形态改变，产生病理效应。镰状细胞贫血死亡率很高，它也是最早被认识的一种分子病。

> **定义**：分子病 —— 基因突变导致蛋白质分子发生变异，进而引起的疾病。

基因在 DNA 上。DNA 把信息转录给 mRNA，mRNA 再翻译成蛋白质。DNA 的信息一变，最终就会影响蛋白质的结构和功能。分子病走的就是这条链路。

这里要明确一点：并不是所有的基因突变都会导致蛋白质分子变异。只有那些导致蛋白质分子发生变异、并由此引起疾病的基因突变，才属于分子病讨论的范围。

再看一眼 HbA 的结构：四聚体，两个 α、两个 β，是成人体内主要的血红蛋白形式。镰状细胞贫血动的就是其中的 β 亚基。

### 一个氨基酸怎样把红细胞掰弯

镰状细胞贫血的突变点很具体：β 亚基 N 端第 6 位氨基酸，正常是谷氨酸，突变后变成缬氨酸。就一个氨基酸的改变。

谷氨酸是酸性氨基酸，亲水；缬氨酸是疏水氨基酸。疏水基团如果暴露在细胞内的水相环境里，就会去寻找其他疏水结构，发生聚集。

这个突变显著降低了去氧血红蛋白的溶解度。去氧血红蛋白就是没有结合氧的血红蛋白；溶解度一降，它就很容易沉淀出来。

但要注意：突变后的血红蛋白在氧合形式下不受影响。也就是说，只要它结合了氧，就和正常血红蛋白一样。

为什么只有去氧形式受影响？看突变后的 HbS 表面：β 亚基第 6 位的缬氨酸侧链暴露在分子表面，而缬氨酸侧链是疏水的。去氧血红蛋白分子上有一个互补的疏水口袋——氧去掉以后，这个口袋就空出来了。缬氨酸的疏水侧链正好插进这个疏水口袋，通过疏水作用结合。

疏水基团和疏水口袋在细胞内的水相环境里互相靠近、聚集，越聚越多，形成纤维状沉淀。

```text
去氧 HbS：β6 缬氨酸的疏水侧链暴露
        │
        │  插入另一分子去氧 HbS 的疏水口袋
        ▼
    分子间疏水作用，不断聚集
        │
        ▼
    纤维状沉淀（像一根杆子撑在红细胞里）
        │
        ▼
    红细胞由双凹圆盘变成镰刀形
        │
        ▼
    红细胞破裂、血液呈冻胶状，血流变慢、血管堵塞
        │
        ▼
    组织氧分压进一步下降
        │
        └──→ 去氧 HbS 更多，镰刀化加重
```

读图：单个 HbS 分子的疏水侧链是“钩子”，另一分子去氧血红蛋白的疏水口袋是“扣眼”；钩子扣进扣眼，分子就连成长链，最后聚成纤维状沉淀。沉淀越积越多，红细胞就被撑成了镰刀形；细胞破裂、血流受阻，又把缺氧推得更深，形成一个越转越快的闭环。

氧合血红蛋白的表面没有疏水性口袋，所以只有缺氧的时候红细胞才会变成镰刀状；不缺氧的时候，红细胞还是正常形态。红细胞的形态因此和氧气的供应密切相关。

氧分压低、氧气供应不足的时候，镰刀状化的程度会增加。某些细胞会在血管中破裂，大多数破裂的就是红细胞；破裂后形成冻胶状，限制血液流速、堵塞血管。血流一慢，正常血红蛋白带过来的氧就更少，组织氧分压进一步下降，生成更多去氧 HbS，镰刀状化进一步加重，组织细胞缺血受伤，器官功能受影响。

这就是镰状细胞贫血患者早亡的主要原因：不是单个分子出错就立刻要命，而是这个“缺氧—镰刀化—更缺氧”的循环一旦转起来，就会不断放大。

### 治疗尝试与地中海贫血

镰状细胞贫血是遗传性疾病，目前为止没有很好的治疗方法。

体外的研究表明，有一种化学物质叫氰酸钾，用它处理镰状细胞贫血患者的红细胞，可以防止突变的 HbS 在缺氧状态下形成镰刀状。

氰酸钾的修饰是不可逆的，修饰的是 N 末端区域的缬氨酸残基。这个缬氨酸正是突变产生的那一个；被氰酸钾修饰以后，可以矫正血红蛋白的构象，使血红蛋白分子重新获得运输氧气的能力。

但这个方案目前还在实验室阶段、临床前阶段，还没有用到临床上。

最后了解一下地中海贫血。它影响的也是 HbA，因为成年人血液里的主要血红蛋白就是 HbA。HbA 有 α 亚基和 β 亚基各两个，地中海贫血也是一种遗传性疾病，遗传因素改变会导致 α 亚基或 β 亚基的结构和功能改变。影响 β 亚基的，叫 β 地中海贫血；影响 α 亚基的，叫 α 地中海贫血。

把这一讲串起来：血红蛋白靠四个亚基的协同，把氧从肺运到组织；T 态与 R 态的切换、S 形氧合曲线、波尔效应和 BPG 调节，都是在调节“抓氧—放氧”这个开关。而镰状细胞贫血告诉我们，这个精密结构里只要错一个氨基酸，红细胞就会被撑成镰刀，整套运输系统随之崩溃。

## 背诵方法、免疫系统与蛋白质的溶液行为
> 对应块：BLK14 | 覆盖分集：P55-P59 | 块标题（分集名）：《[专题04习题]考点4∶血红蛋白的分子病》

生物考研的背诵内容多且杂，基础阶段最常见的景象是：书翻了好几遍，合上书还是写不出来；明明很努力，效率却低得让人怀疑自己。问题多半不在勤快程度，而在方法——理解、框架、筛选、重复这几件事排对了，背诵才不白费。把这件事讲清楚之后，再进入蛋白质专题：免疫系统和免疫球蛋白、肌肉里的两类蛋白，以及蛋白质在水溶液中的行为。

### 基础阶段的背诵怎么排

上来就拿着书死记硬背，是最费劲也最没用的做法。基础阶段的背诵要解决四件事：怎么学、背什么、用什么策略、踩了坑怎么调整。

#### 先理解，再搭框架，做题可以开卷

**理解优先**。理解是记忆的前提，先通过听课或者看教材把原理搞懂，再动手背。一上来就硬背不理解的东西，就像盖房子没有根基，很容易倒塌。

**搭建框架**。学完一章，要能说清这一章讲了哪几块内容。框架清晰了，零散的知识点才有挂靠点，相当于给每个知识点安了个家。

**基础阶段做题可以开卷**。目的不是检验，而是把刚理解的知识再强化一遍。这个阶段不必纠结不会的题多——考研题目其实很固定，随着复习深入，会越来越顺手。

#### 背什么：只背骨架

很多同学一背诵就什么都想背，结果反而什么都记不住。基础阶段的背诵关键在于精准筛选：抓住核心资料里的标记内容——红色字、加粗部分、划线的段落，还有表格里的核心信息。这些内容是提炼过的高频考点和核心概念，本身就是章节的骨架；记住它们，就抓住了这一章的主要脉络。

那没有标记的非重点怎么办？基础阶段不用强迫自己记住所有细节，暂时记不住没关系，到强化阶段结合真题再针对性补充。现在的任务是把骨架搭起来。

打个比方，基础阶段的背诵像给房子打地基：先把主要的梁柱立起来，细节装修后面再说。如果一开始就陷进细节，反而会忽略整体框架，导致记忆混乱。

#### 三个核心策略

**小标题记忆与拓展**。不是只背标题，而是先记住小标题，再用自己的话去拓展内容。以双缩脲反应为例，只需要记住“定义、特点、应用”这三个小标题，合上书之后能大致把每个小标题下的内容写出来就行。一开始用自己的话写，会不会显得不专业？不会——刚开始先说人话，等熟练之后再换成专业术语，记忆起来会轻松很多。

**重复背诵**。它包含滚动复习和多轮背诵两层。滚动复习是学第二章之前先复习第一章，学第三章时复习前两章，每天花 20% 的时间翻看旧内容；这是对抗遗忘最有效的方式。多轮背诵则是：基础阶段背常规重点，强化阶段结合真题背针对性重点，冲刺阶段利用冲刺背诵手册查漏补缺。每一轮本质上都是重复。

**基础与强化阶段分工**。基础阶段背常规重点，能记下小标题、理解框架就算成功；强化阶段结合真题，在高分笔记或书上标记本校常考点加强背诵，同时把基础阶段被忽略的细节捡起来。分工明确，效率才高。

#### 六个常见误区，逐个拆

**背了又忘**。这几乎是所有人都会遇到的，背完第二天就跟没背过一样，特别打击信心。核心解法还是滚动复习：每天花 20% 的时间翻看旧内容，学第二章前先复习第一章，学第三章时复习前两章，像滚雪球一样把之前的知识不断重新巩固一遍，记忆自然就加深了。

**什么都想背**。要学会取舍：基础阶段只背高分笔记里的重点内容——红色字、加粗部分、划线段落和表格核心信息，这些本身就是一章的骨架。其他细节不用急，强化阶段结合真题再补也来得及。

**合上书就写不出东西**。明明感觉自己背下来了，一合书就空白，问题出在背诵顺序上。应该先背小标题，再用自己的话拓展：比如双缩脲反应，先记住定义、特点、应用这三个小标题，合上书能把这些框架说出来，再慢慢填充内容。先说人话，熟练后换成专业术语，就容易多了。

**不理解还硬背**。效果一定不好。理解是记忆的前提，遇到不理解的内容就应该先停下来，通过听课或者看教材把原理搞懂，不要一上来就硬背。这和盖房子是一个道理，没有根基的房子很容易倒塌。

**做题喜欢闭卷，错一大堆**。基础阶段做题建议开卷，目的不是检验，而是把刚理解的知识再强化一遍。不必纠结不会的多，考研题目其实很固定，复习深入之后会越来越顺手。

**觉得教材太难啃**。如果教材确实难，可以直接用高分笔记——笔记已经把重点梳理出来了，能省下很多时间和精力，复习效率也更高。

### 免疫系统：在分子水平上分清自我与非我

免疫系统和免疫球蛋白这个知识点，考研的时候一般不太涉及，学有余力的同学跟着了解一下就够了。

免疫是人类和脊椎动物最重要的防御机制。平时说谁免疫力高、免疫力低，说的就是这个。它能在分子水平上识别自我和非我：一方面认得出自身的细胞和分子，另一方面也认得出不是自己的细胞和分子，并且把非我的部分破坏掉。所谓非我，通常就是侵入身体的细菌、病毒之类。

免疫系统主要靠两种细胞发挥作用：淋巴细胞和吞噬细胞。这两种细胞其实都来自骨髓干细胞。

#### 淋巴细胞：B细胞与T细胞

B 细胞在骨髓当中完成发育。骨髓的英文首字母是 B，所以叫 B 细胞。B 细胞的受体本身就是一种抗体分子，是能够单独识别抗原的膜结合糖蛋白；一个 B 细胞表面长着许多这样的抗体。当 B 细胞遇上与它的膜结合受体特异性匹配的抗原，就开始迅速分裂，子代细胞分化成记忆细胞和效应细胞。效应细胞就是浆细胞，当即去杀死抗原；记忆细胞则把抗原的样子记下来，等这个抗原下次入侵时迅速增殖、分裂，再把它清除。

T 细胞迁移到胸腺，在胸腺内完成后期发育并成熟，胸腺的英文首字母是 T。成熟期间，T 细胞表达抗原特异的膜受体，称为 T 细胞受体（T cell receptor，TCR），它是一种异二聚体。T 细胞分两类：辅助性 T 细胞（TH，helper T cell）和细胞毒性 T 细胞（TC，cytotoxic T cell）。

T 细胞受体和 B 细胞受体有一处根本不同：它不认游离的抗原。只有当抗原与主要组织相容性复合体（major histocompatibility complex，MHC）结合，由 MHC 把这个抗原从细胞里面“拿”出来、站到细胞膜表面举在前面暴露出来，T 细胞受体才能识别它。

> **提示**：B 细胞受体直接结合抗原；T 细胞受体只认“抗原肽—MHC”复合物。这是两类淋巴细胞在识别方式上最本质的差别。

#### 巨噬细胞与抗原

巨噬细胞也由骨髓干细胞分化而来：在骨髓中发育成幼单核细胞，进入血液后分化为单核细胞，再迁移到组织中，分化成组织特异的巨噬细胞。

它的功能有三条：吞噬大颗粒、吞噬其他细胞，以及作为抗原呈递细胞。

由此引出抗原的定义：能够引起免疫反应的任何分子或者病原体，都是抗原。它可以是一种病毒，可以是细菌的细胞壁，也可以是一些蛋白质或者其他生物大分子。

#### 体液免疫与细胞免疫

免疫系统整体上分两大系统。

**体液免疫系统**主要针对细菌的感染、胞外病毒，以及进入细胞内的病原生物、体内的外来蛋白质，通过体液免疫对它们进行对抗或清除。

**细胞免疫系统**主要破坏被病毒感染的宿主细胞（这有可能是我们自身的细胞），以及某些寄生物和外来的移植组织。

#### MHC：把抗原举到细胞表面

免疫系统能识别自我和非我，靠的是前面提过的那种蛋白质——MHC。它是一种内在的膜蛋白，是一种异二聚体分子，宿主中蛋白质抗原的检测就是由它介导的。

它是怎么介导的？MHC 与细胞内被消化的蛋白质肽片段结合——这个片段有可能来自入侵细胞的细菌或病毒蛋白——然后把它们展示在细胞的外表面。换句话说，MHC 把细胞内消化出来的蛋白质碎片拿出来，站到细胞膜上，举到外面给免疫系统看。展示出来的外来肽段，就是免疫系统识别为“非我”的抗原；这个动作等于在告诉免疫系统：这是外来的，是敌人的标志。T 细胞受体与这些片段结合之后，T 细胞就像战士认出了目标，随后引发一系列免疫反应。

MHC 分一型和二型：

| 类型 | 分布 | 展示的肽来自哪里 |
| :--- | :--- | :--- |
| MHC I | 几乎所有脊椎动物细胞的表面 | 细胞内随机发生的蛋白质降解和更新所衍生的肽 |
| MHC II | 少数几种特化细胞（巨噬细胞、B 淋巴细胞） | 通过吞噬作用或胞吞作用内化的外来抗原，经消化后的小肽段 |

MHC II 所在的这些特化细胞就是抗原呈递细胞：它们把外来抗原内化、消化成小肽段，再展示出来。

#### 免疫记忆与疫苗

抗原耗尽以后，被激活的免疫细胞会在几天内死去。但少数被激活的 B 细胞和 T 细胞会成熟为记忆细胞，长期存在于身体当中，参与再次免疫。已经被清除的抗原如果再次进入体内，记忆细胞就会迅速分裂增殖，再次免疫的速度更快、更强。

疫苗就是建立在这个机制上的：一开始给机体一部分抗原——灭活的抗原，或者病原体本身（一种病毒、一种细菌），或者它特征性的一些蛋白片段——让机体产生相应的记忆细胞。等再次被同一种病原体感染时，直接发生的就是更快更强的再次免疫。

### 抗体：四条链与三个常用概念

抗体也称为免疫球蛋白（immunoglobulin，Ig），是一类可溶性的血清糖蛋白，是血清当中最丰富的蛋白质之一。抗体有五种类型：IgG、IgA、IgM、IgD 和 IgE。其中 IgG 是抗体当中的一大类。

#### IgG 的四条链

IgG 具有四条多肽链组成的对称结构：两条较长、分子量较大的重链，两条较短的轻链；链与链之间由二硫键和非共价键连接，组成一个单体分子。这是 IgG 的结构，其他几类抗体的结构也与它类似。

#### 单克隆抗体

单克隆抗体（单抗）是由单一的 B 细胞克隆产生的、高度均一的、仅仅针对某一个特定抗原的抗体。克隆就是 copy：把一个 B 细胞复制成很多个，再从这些 B 细胞上得到抗体。制备上一般采用杂交瘤技术，这样得到的抗体全部识别同一个表位——也就是抗原上被识别的那个位点。

#### ELISA

酶联免疫吸附测定（enzyme-linked immunosorbent assay，ELISA）是一种可以快速筛查和定量样品中抗原的方法。它以待测抗原和酶标抗体的特异性反应为基础，通过测定酶活力来确定抗原或抗体的含量。

整个实验的骨架可以拆成几步：

```text
抗体与待测抗原特异结合
        ↓
抗体上连着酶（酶标抗体）
        ↓
洗去非特异结合（特异结合的抗体洗不掉）
        ↓
测定酶活：酶越多，样本里原本的抗原越多
```

道理很直白：非特异结合的都被洗掉了，留下来的酶量就对应着被抗体抓住的抗原量，测酶活就等于测抗原。

#### Western blot

Western blot（也写作 western blotting，实验室里通常简称 WB）是利用抗原—抗体的特异性反应检测目标蛋白的方法，读研以后多少都会接触这类实验。

它检测的是抗原，但用到的试剂是抗体：只要能把抗体检测到，就说明样本当中有这个抗原；抗体给出的信号越强，说明样本里的抗原越多。

### 肌肉里的两类蛋白与分子马达

这部分内容非常简单，简单了解就可以，考试的时候一般不会涉及。

分子马达依靠核苷三磷酸作为能量，进行循环式的构象变化，推动细胞的运动。核苷三磷酸包括 ATP、CTP、UTP 和 GTP，其中主要是 ATP。它的结构不断变化，就像一条腿不断往前走，细胞因此被推动。

肌肉当中最主要的蛋白质有两大类：肌球蛋白和肌动蛋白。肌球蛋白由两条重链和四条轻链组成。

肌肉的结构是一层套一层、越来越小的：

```text
肌肉
└─ 肌束
   └─ 肌纤维
      └─ 肌原纤维
         └─ 明带（I 带）与暗带（A 带）交替分布
```

肌原纤维呈现明带和暗带交替分布的结构：明带称 I 带，暗带称 A 带，由粗丝和细丝交替重叠排列产生。I 带被 Z 盘分成两半，Z 盘起锚钩的作用，用来固定细丝；A 带的中央有较明亮的 H 区，这里只有粗丝、没有细丝；A 带的正中间还有一条 M 线。

> **提示**：I 带、A 带、H 区、M 线、Z 盘这一串名词，知道各自指哪一块就够了，不必展开。

### 蛋白质在水溶液中的行为

蛋白质的性质、分离纯化和鉴定这个专题，第一个知识点是蛋白质在水溶液当中的行为，分三部分：两性解离性质、胶体性质，以及蛋白质的沉淀。

#### 从氨基酸的两性解离说起

氨基酸的结构通式是：α 碳上连着一个羧基、一个氨基、一个氢和一个侧链基团。α-羧基在碱性条件下失去一个质子，变成羧酸根离子；α-氨基在酸性条件下得到一个质子，变成铵离子。这样一个氨基酸既有带负电的基团，也有带正电的基团，或者说既有可以失去质子的基团，也有可以得到质子的基团——这种性质就叫氨基酸的两性电离，也叫两性解离。

蛋白质是一条多肽链。一条多肽链至少有一个完整的 N 端 α-氨基和一个完整的 C 端 α-羧基，这两个基团的行为和氨基酸里的完全一样：羧基在碱性条件下失去质子，氨基在酸性条件下得到质子。所以蛋白质和氨基酸一样，具有两性解离的性质。

不止两端。蛋白质分子除了 N 端和 C 端，侧链基团也参与解离：酸性氨基酸的侧链含有羧基，碱性氨基酸含有可以得到质子的碱性基团。这些基团在一定的溶液 pH 下都可以解离成带电荷的基团——要么带负电，要么带正电。

#### 等电点

那么到底带正电还是带负电？这要先回到等电点的概念。

当蛋白质溶液处于某一个 pH 时，蛋白质解离成正、负离子的趋势相等，成为两性离子，净电荷为零；此时溶液的 pH 就称为该蛋白质的等电点（pI）。注意，虽然有的基团失去质子、有的基团得到质子，但得到和失去的质子数量相等，所以整体不带电。

这个概念经常作为名词解释来考，而且它和氨基酸的等电点一模一样——只要把概念里的“蛋白质”换成“氨基酸”。

pH 与 pI 的关系可以这样推：

**pH = pI**：净电荷为零，蛋白质不带电。

**pH < pI**：相当于在 pH = pI 的基础上往溶液里加氢离子。羧基上原本失去的质子被补回来，氨基依然是带正电的状态，所以整个蛋白质带正电。

**pH > pI**：相当于加氢氧根离子。氢氧根与氨基上的一个质子反应生成水，氨基不再带电，而羧基依然是带负电的状态，所以整个蛋白质带负电。

反过来调也一样：带负电的体系加氢离子把 pH 调回 pI，就恢复不带电；带正电的体系加氢氧根把 pH 调到 pI，也不带电。

| 环境 pH | 净电荷 | 电泳时的去向 |
| :--- | :--- | :--- |
| pH < pI | 正电 | 负极 |
| pH = pI | 零 | 不移动 |
| pH > pI | 负电 | 正极 |

电泳就是把这个性质用起来：把蛋白质混合物放进电场，让颗粒泳动。颗粒要在电场中移动必须带电，所以 pH 小于等电点时蛋白质带正电、往负极跑；pH 大于等电点时带负电、往正极跑。

#### 等离子点：把等电点固定下来

蛋白质的等电点并不是一个死数。在有中性盐存在的溶液当中，它会发生明显的变化——溶液里的钠离子、钾离子、铵根离子等等，都会影响蛋白质的等电点。同一份蛋白质，在没有任何盐离子的清水里测是一个值，水里含一定盐离子又是另一个值。

于是就有了等离子点：在没有其他盐类干扰时，蛋白质质子供体基团解离出来的质子数与质子受体基团结合的质子数相等，此时溶液的 pH 就称为该蛋白质的等离子点。它其实就是等电点的一个特例——没有其他盐类干扰时的等电点，此时蛋白质依然不带电、净电荷为零。区别在于，等离子点是蛋白质的特征性常数，不会随外界环境的变化而变化。

> **易错点**：等电点会随盐离子改变，等离子点不会。题目里出现“特征性常数”，对应的应该是等离子点。

#### 胶体性质

把蛋黄和蛋清分开，把蛋清倒进一杯清水：一开始还能看出蛋清是蛋清、水是水，过一段时间，蛋清就均匀分散在水相当中了——这就是胶体。

蛋白质能形成胶体，靠的是两个尺寸条件：分子量在 1 万到 100 万之间，分子直径在 1 到 100 nm 之间。落在这个范围里，它在水中会形成比较稳定的亲水胶体。

因为蛋白质水溶液是胶体，所以它不能透过半透膜；也因为它是胶体，它可以发生丁达尔效应和布朗运动。丁达尔效应在中学化学里见过：一束光打过去，硫酸铜溶液的光完全透过，而氢氧化铁胶体会形成一条光路——胶体才有这条光路。

#### 胶体为什么稳定

蛋白质分子在水相中均匀分散、不沉淀，靠两个因素。

**水化膜**。大多数蛋白质是球状蛋白，亲水基团排在外表面，会吸引水分子，在颗粒表面形成一层水化膜。

**同种电荷互斥**。同一种蛋白质在同一杯液体、同一 pH 环境下带的电荷相同（除非这个 pH 正好是它的等电点）。相同的电荷互相排斥，一颗一颗蛋白质就均匀悬浮在水相中，没有聚集，也就没有沉淀。

反过来说：把水化膜去掉，或者把表面电荷去掉，或者两个都去掉，蛋白质就会从水中析出、沉淀。这就是所有沉淀方法的共同出发点。

#### 六种沉淀方法

**盐析**。加盐，最常用的是硫酸铵。高浓度的盐离子会与蛋白质表面的亲水基团争夺水分子，水化层被破坏，蛋白质随之析出。

**有机溶剂沉淀**。常用甲醇、乙醇和丙酮。它们同样能去除水化层，并且降低介电常数，使蛋白质容易聚集；水化层去掉之后，蛋白质带的电荷暴露出来。有机溶剂还会导致蛋白质变性——变性后内部结构改变，原本折叠在内部的基团暴露出来，有的带正电、有的带负电，彼此结合，于是聚集。

**重金属盐沉淀**。前提是溶液的 pH 大于等电点。这时蛋白质带负电，而重金属离子带正电，两者结合，形成不溶性的盐沉淀。

这也解释了重金属中毒时为什么要吃富含蛋白质的东西，比如喝牛奶：从外面补进去的蛋白质去和金属离子结合，减少金属离子与体内正常功能蛋白的反应。

**生物碱试剂和某些酸类沉淀**。这个时候条件是 pH 小于等电点：蛋白质带正电，与带负电的酸根离子结合，形成不溶性的盐沉淀。

**加热**。加热使蛋白质变性凝固，最典型的就是煮鸡蛋、煎鸡蛋——蛋清受热凝固成块，自然就从溶液里沉淀出来了。

**等电点沉淀**。在等电点时蛋白质不带电，前面说的两个稳定因素里，“表面带同种电荷互相排斥”这一条就失去了，胶体因此不稳定，容易发生沉淀。

| 方法 | 关键条件 | 动的是哪根支柱 |
| :--- | :--- | :--- |
| 盐析 | 高浓度中性盐（常用硫酸铵） | 水化膜 |
| 有机溶剂沉淀 | 甲醇／乙醇／丙酮 | 水化膜，兼降介电常数、变性 |
| 重金属盐沉淀 | pH > pI | 电荷（与金属正离子成不溶性盐） |
| 生物碱试剂与某些酸 | pH < pI | 电荷（与酸根负离子成不溶性盐） |
| 加热 | 加热 | 变性凝固 |
| 等电点沉淀 | pH = pI | 电荷（同种电荷斥力消失） |

> **结论**：蛋白质的沉淀方法看着有六种，底层只有一句话——把胶体稳定的水化膜和表面电荷拆掉。盐析和有机溶剂动的是水化膜，重金属盐、生物碱试剂与酸、等电点动的是电荷，加热则是让蛋白质直接变性凝固。
