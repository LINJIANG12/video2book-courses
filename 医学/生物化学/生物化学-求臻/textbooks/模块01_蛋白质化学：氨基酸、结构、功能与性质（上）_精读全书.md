## 走进生物化学：这门课研究什么，需要哪些化学底子
> 对应块：BLK01 | 覆盖分集：P01 | 块标题（分集名）：《生化学前必备基础知识》

这是整门课的开场白。在正式进入糖、脂、蛋白质这些大头之前，先把两件事说清楚：生物化学这门课到底在研究什么；以及开始学习之前，要把哪些基础知识备好。这些底子大多是中学化学里的东西，看起来简单，但后面每一章都要反复用到。

### 生物化学是什么：发生在生物体里的化学反应

为什么这门课叫"生物化学"？把这个词拆开理解就通了：它说的就是发生在生物体当中的化学反应。那生物体里有哪些化学反应？太多了——大到一个人这样的个体，小到肝脏、皮肤这样的器官，再小到一个细胞，无时无刻不在进行化学变化。生物体就是靠这些化学变化来传递信息，同时适应整个环境的变化。

> **定义**：生物化学就是生命的化学。它的任务是了解生物的化学组成与结构，以及生命全过程中的各种化学变化。

要研究这些化学变化，有一条层层递进的线索。想了解生物体里发生的化学变化，首先得知道发生这些变化的物质是什么——也就是先了解生物的化学组成；知道了是哪些物质，接着要看它们的结构是什么样子；然后才轮到研究它的各种化学变化。最后，了解这些是为了用它来解释、阐明生物体从受精卵开始的发育、生长、衰老、死亡的全生命过程。

注意，从受精卵开始到死亡，好像一个个体就全部结束了——其实中间还缺一环：还要繁衍后代。所以整个生命过程当中的生殖、遗传的本质和规律，也要一并阐明。

### 研究内容的三条主线

生物化学的主要研究内容，和刚才概念里的三个部分统一起来了，是一脉相承的。

#### 生物分子的结构与功能

要了解化学变化，先要知道有哪些物质在参加这些变化。生物体当中的这些物质，大多数是一些大分子——生物大分子。所以第一件事，就是把它们的结构和功能认识清楚。

#### 物质代谢及其调节

认识了结构功能，紧接着就要了解它们的变化。后面讲代谢的时候，会讲糖代谢、脂代谢、氨基酸代谢，分别对应三大营养物质：糖类、脂类和蛋白质类。拿人体来说：我们从外界摄入这些物质，先要消化——摄入的大分子一般是一些多聚物，要通过消化把多聚物变成一个一个的单体，然后再吸收进人体；人体最终还要利用这些单体。怎么利用？比如糖类物质，首先要拿它进行有氧氧化来提供能量。这就涉及代谢了，这就是物质代谢及其调节。

#### 基因信息的传递及其调控

我们都知道，基因的信息储存在 DNA 上。基因信息的传递包括 DNA 的复制；而且基因信息不只是 DNA 传给 DNA，还要从 DNA 传给 RNA，这就是转录；传给 RNA 以后，最终通过 mRNA 翻译成蛋白质，这就是翻译。所以基因信息的传递，主要就是复制、转录、翻译。

复制、转录、翻译讲完之后，还要讲基因表达的调控：一个细胞在一个特定的时间点，需要表达哪些基因、不需要表达哪些基因，是由它所处的环境决定的。当一个细胞遇到特殊的环境，它要表达哪些、不表达哪些，是要经过一个严格的调控的。这也是生物化学研究的内容之一。

### 碳与碳骨架：为什么把碳看得这么重

接下来进入基础知识。这部分对本科就学过生物学的同学可能没有什么问题，但跨专业考研的同学要重点过一遍。

生物化学当中为什么反反复复提到碳、把碳看得这么重？因为组成生物体的最基本元素就是碳元素。

碳骨架指的是：碳原子之间通过碳碳单键相结合，也可以通过碳碳双键相结合——碳碳双键也把它叫做烯键；碳原子与碳原子之间还可以形成碳碳三键。这些连接构成不同长度的链状、分支状或者环状的结构，这些结构就称为有机物的碳骨架。

> **结论**：生物体最基本的元素组成是碳元素；生物体整个的骨架，就是有机物的碳骨架。

生物体很多时候也被称作"有机体"，就是这个原因。

### 认识几个常见的化学基团

还有一些经常会提到的化学基团，后面每一章都会反复出现，先把它们认全。

#### 羟基：极性决定亲水还是疏水

第一个是羟基，由一个氧和一个氢组成。羟基的极性比较大，含有羟基的部位就是一个极性比较大的部位。

极性大是什么意思？可以简单地这样记：极性越大的基团或分子，水溶性越强，我们就说它的亲水性越强；而极性越小的分子，水溶性越差——水溶性越差，脂溶性就越强，它就是疏水的。

结合生活当中的例子来想：物质溶解的时候，要么溶在水里，要么溶在油里，而水和油是不互溶的。水的极性可以认为是最大的，油的极性可以认为是最小的——油就是非极性物质。相似相溶：油里面一般溶进去的是非极性物质，水里面溶解的一般是极性很强的物质。

为什么要在这里花这么多功夫？因为我们人体——或者说动物体、整个生物体——体内的环境是一个水相的环境。在水相环境当中，极性越大的分子越容易溶解；而溶解状态，往往正是它有活性的状态。

对人体而言，还有很多非营养物质——比如不可避免摄入到体内的一些色素，还有空气当中的污染物，很多都是对我们没用的非营养物质。这些物质往往极性很小：水溶性很差，脂溶性很强。要把它排出体外，就需要增加它的极性。其中有一种方式，就是给它加一个羟基——这就叫羟化反应，是在我们的肝脏当中进行的。

#### 烃链：只写碳，氢默认不写

第二个是烃链：仅仅由碳和氢组成的链状结构。

看烃链的图时要注意一个问题：概念上说它由碳和氢组成，为什么图里只写了碳？因为我们默认氢原子可以不写。真要写上是什么样？碳能形成四个共价键：处在两头的碳，除了和隔壁碳相邻的那根键以外还剩三根，各连三个氢；中间的碳都连两个氢。

```text
只写碳：C-C-C-C
补全氢：CH3-CH2-CH2-CH3
```

读图：只写碳的骨架补上氢之后，两头碳各带 3 个氢、中间碳各带 2 个氢，正好凑满碳的四根共价键。

#### 侧链：从肽链的主链说起

第三个是侧链。说侧链之前要先说主链——这个在基础课里面其实讲过。

看一条由五个氨基酸连起来的链：氮—碳—碳、氮—碳—碳这样反复出现的这条线，就是它的主链。中间那些连有 R 基团的碳，都是它们的 α-碳；α-碳上连着一个氨基和一个羧基。前一个氨基酸的羧基和后一个氨基酸的氨基脱水缩合，形成一个肽键——第一个氨基酸的羧基和第二个氨基酸的氨基形成一个肽键，第二个的羧基和第三个的氨基又形成一个肽键，就这样以肽键的形式不断连起来。整条这样连起来的链，就是肽链的主链结构。

```text
H2N-CH-C-NH-CH-C-NH-CH-C-NH-CH-C-NH-CH-COOH
    |  |    |  |    |  |    |  |    |  |    |
    R  O    R  O    R  O    R  O    R  O    R
```

读图：—NH—CH—C(=O)— 反复出现的这条线就是主链；竖线连下去的 R 是各个 α-碳上的侧链；—C(=O)—NH— 那一段就是肽键。

而这几个 R 基团，就是它的侧链结构。侧链一般都是在哪里说到的？都是在肽链当中说到的——而肽链又是由氨基酸组成的，所以其实这个侧链说的就是氨基酸的侧链。

氨基酸的通式：α-碳上连一个羧基、连一个氢、连一个氨基，第四根共价键上连一个 R 基团——这个 R 基团就是它的侧链。

```text
    H
    |
H2N-C-COOH
    |
    R
```

读图：α-碳的四根键分别连氨基、氢、羧基和 R 基。

我们常说的 20 种编码氨基酸，其他三个部位都一样，只有侧链这个部位是不一样的。

#### 氨基、羧基与巯基

氨基刚才画过了：一个氮原子。注意，氮原子本来可以连三根共价键，三根都连氢的话，它就是氨气；去掉一个氢原子之后剩下 $-NH_2$，再连到碳上——如果连的是氨基酸的 α-碳，这就是氨基酸的 α-氨基。

羧基的结构式是：碳上连一个双键氧（碳氧双键），后面还连一个羟基，这一部分合起来就是 $-COOH$；连在 α-碳上，就是 α-羧基。

还有一个是巯基。巯基是半胱氨酸当中含有的一个基团。它的性质和羟基很像——羟基是极性基团，而巯基的极性比羟基更强，它其实是 20 种编码氨基酸当中极性最强的一个基团。所以含有巯基的半胱氨酸，极性是很强的。

### 化学键：牢固的共价键，不牢固的非共价键

化学键其实是我们中学化学的一个概念：纯净物分子内或晶体内，相邻的两个或多个原子（或离子）之间强烈的相互作用力，统称为化学键。

在生物化学里面讲的时候，主要把它分为两大类：一类是共价键，另一类是非共价键。这里一定要注意的是：共价键是牢固的，相对来说更牢固；而非共价键是不牢固的。

生物化学当中要区分两个基团（或者说两个化合物、两个分子）连接得紧密还是不紧密，就看它们是不是形成了共价键。形成了共价键之后，用物理的方法——比如超滤（超滤是一种过滤）、透析——是去不掉的，我们就认为它们连接得比较牢固；而如果两个分子是以非共价键连起来的，就可以通过超滤、透析这些物理方法把它去掉，它们的连接就比较疏松。

> **易错点**：判断连接紧密与否，标准只有一个——有没有形成共价键。共价键牢固，超滤、透析去不掉；非共价键疏松，超滤、透析去得掉。

非共价键又包括这几种：氢键、盐键、疏水作用力和范德华力。下面挨个来看，先看共价键本身。

#### 共价键：共用外层电子，凑到饱和为止

共价键当然是化学键的一种。两个或多个原子共同使用它们的外层电子，在理想状况下达到电子饱和的状态，由此组成一个比较稳定的化学结构——像这样有几个相邻原子通过共用电子、并且与共用电子之间形成一种强烈的作用，就叫做共价键。

什么叫外层电子？把元素周期表搬出来看。氢的最外层只有一个电子，氦是两个；从锂开始进入第二周期，因为它们的原子轨道——电子轨道——有两层了。电子轨道有这么一个特点：第一层轨道最饱和的状态就是两个电子，有两个电子它就稳定了；而第二层轨道需要有八个电子才稳定；第三层轨道也需要有八个电子才稳定。周期表最后那一列惰性气体，最外层轨道就是饱和、稳定的。

具体到一个原子，怎么凑饱和？如果它只有一层轨道，那有两个电子才稳定——其实只有氢涉及这个问题：它能得到一个电子，凑成两个就稳定；得不到的话，它可以把这一个电子失掉，失掉以后它就变成了氢离子。

再看第二周期的原子。比如氟，9 号：第一层轨道先满足两个电子，第二层轨道有七个电子，而第二层要八个才饱和，所以氟特别容易得到一个电子，凑成八电子就稳定了。反过来，最外层只有一个电子的原子（比如锂）：它要凑齐八个还差七个，得七个电子太难了，怎么办？往往就失掉这一个电子——失掉之后，里面那层两个电子的轨道变成了它的最外层，它就稳定了。

拿水分子来举个例子。水分子由两个氢和一个氧组成：氧是 8 号元素，最外层有六个电子，先画上六个；每个氢的最外层是一个电子，用叉叉表示。氧原子和右边的氢共用一对电子，又和下面的氢共用一对电子——这样，每个氢的最外层变成了两个电子，它稳定了；氧呢，和两个氢分别共用之后也凑够了八个，它也稳定了。写成结构就是 H—O—H：像这样相邻原子通过共用电子形成的强烈作用，就叫共价键。

#### 氢键：不共用电子对的静电吸引

再来看非共价键里面的氢键。

还是拿水说事。水分子当中的氢原子，其实更显正电性。为什么？它虽然和氧原子共用了一对电子对，但氧的原子核更大，吸电子能力更强，共用电子对是更偏向氧原子的。电子是显负电的，于是氧原子就更具有负电性，而氢原子就更具有正电性。

这样一来，一个水分子里显正电性的氢，就有可能和它附近另一个水分子里显负电性的氧互相吸引——一个倾向于带正电、一个倾向于带负电，两者之间就有一个互相吸引力；反过来，氧和它周围的氢之间也同样有吸引力。这样的吸引力就叫做氢键。

> **提示**：氢键并没有共用电子对——它只是一个显负电性的原子和另一个显正电性的原子之间的静电吸引。这一点要和共价键分开。

#### 盐键：静电吸引与静电排斥的平衡

盐键也叫离子键。它是两个或者多个原子（或化学基团）失去或者获得电子而成为离子以后，带相反电荷的离子相互吸引——异性相吸；而电子和电子、原子核与原子核之间又相互排斥；当静电吸引与静电排斥作用达到平衡的时候，便形成了离子键。

还是看最经典的氯化钠。钠原子是 11 号，轨道排布是 2、8、1：最外层一定要有八个电子才稳定，但它最外层只有一个，所以这一个电子很容易失掉——失掉以后，第二层轨道变成最外层，是八个，它就稳定了。氯原子是 17 号，外层轨道是 2、8、7：它再得到一个电子就稳定了。

一个特别容易失电子、一个特别容易得电子，那怎么就稳定了呢？钠索性把最外层那个电子转移给氯。转移之后：钠失掉了一个电子——电子是带负电的——所以它带了一个正电荷；氯得到一个电子之后，外面的电子变成 18 个，而它内部的质子只有 17 个，这样就变成了一个负离子、阴离子。钠离子带正电、氯离子带负电，异性相吸，相互靠近。

但吸引也不是无限接近的：吸引到接近一定程度的时候，钠外侧的 10 个电子和氯的 18 个电子之间，同性相斥；钠的原子核和氯的原子核带的也都是正电，也同性相斥。当静电吸引与静电排斥作用达到平衡的时候，就形成了离子键——钠离子和氯离子不可能无限接近，接近到一定程度就开始排斥了。

对应到蛋白质里：蛋白质分子当中带正、负电荷的侧链基团可以互相接近，通过静电吸引而形成离子键，或者说盐键。比如羧基和氨基、胍基、咪唑基这些基团之间的作用力：羧基是一个容易失去质子、带负电的基团；氨基、胍基、咪唑基都是容易得到质子、显正电的基团。带负电的基团和带正电的基团之间的这种作用力，就是蛋白质里面的盐键。

#### 疏水作用力：疏水分子自己聚在一起

前面讲过，生物体当中、我们的细胞当中都是一个水相的环境。在这个水相环境当中，举一个生活中的例子：家里吃完饭洗碗，如果没洗、泡了一晚上，第二天早上你就会发现那些油滴都聚集在一起了。为什么？因为水和油是完全不互溶的——油是脂溶性的，极性特别低，是非极性的。记住这一条：非极性就等于疏水性。

疏水性很强的分子特别"讨厌"水，怎么办？它们自己就会聚集在一起——这就叫疏水作用力。

对应到蛋白质当中：比如丙氨酸，它的侧链基团是一个甲基，甲基就是一个疏水基团，两个丙氨酸互相靠近时，甲基就会和甲基互相靠近。异亮氨酸的侧链基团疏水性就更强了——它是由四个碳组成的烃链。亮氨酸也一样：亮氨酸和异亮氨酸的侧链互相靠近以后，也会因为疏水作用力聚合在一起。

再往后讲 DNA 结构的时候还会遇到它。DNA 的结构像一个梯子：两边是磷酸和戊糖组成的骨架，中间梯子的"阶梯"由碱基互补配对组成。碱基的疏水性是很强的，当 DNA 形成双螺旋结构的时候，碱基与碱基互相靠近——它们本身都是疏水的基团，在细胞核这个水相的环境当中就会产生相互的吸引力，这个吸引力就是疏水作用力。

#### 范德华力：最弱、但普遍存在

最后看范德华力。它是一种普遍存在于固体、液体和气体当中的分子间作用力。两条规律：对于组成和结构相似的物质，相对分子质量越大，范德华力就越大；对于相对分子质量相等的物质，极性越大，范德华力越大。另外，范德华力一般没有方向性和饱和性。

和前面的几种作用力比起来，范德华力更弱。怎么理解？可以把它理解成一种分子与分子、或者原子与原子之间的"万有引力"——它是普遍存在的。

| 作用力 | 怎么形成 | 典型位置 |
| :--- | :--- | :--- |
| 氢键 | 显正电性的氢与显负电性的原子之间的静电吸引，不共用电子对 | 水分子之间 |
| 盐键（离子键） | 相反电荷的离子相互吸引，与静电排斥达到平衡 | 蛋白质的羧基与氨基、胍基、咪唑基之间 |
| 疏水作用力 | 非极性（疏水）分子在水相环境中自发聚集 | 蛋白质的疏水侧链之间；DNA 双螺旋的碱基之间 |
| 范德华力 | 分子间普遍存在的弱吸引，类似"万有引力" | 固体、液体、气体中无处不在 |

### 结构式、分子式与反应方程式

最后再看几个基本概念，还是拿乙醇（酒精）当例子。

**结构式**，就是用化学键表示分子里各直接相连原子的结合情况的式子。乙醇嘛，肯定有两个碳，后面有一个羟基，其他位置都是氢：

```text
    H   H
    |   |
H-C-C-O-H
    |   |
    H   H
```

读图：第一个碳连三个氢，第二个碳连两个氢和一个羟基——这就是乙醇的结构式。

结构式还可以简化：第一个碳是 $CH_3$，第二个碳是 $CH_2$ 连一个 $-OH$，合起来写成 $CH_3CH_2OH$，这就是结构简式；还能再进一步简写成 $C_2H_5OH$。

写结构式有一条讲究：一定要把官能团单独写出来。官能团是什么？就是决定这个化合物到底是个什么样物质的基团。你看这个物质为什么是乙醇、是醇类物质？因为它有一个羟基。

**分子式**，则是用元素符号表示这个物质的分子组成以及相对分子质量的化学式，只标清楚有哪些元素、各有多少个：乙醇有碳、氢、氧三种元素；几个碳呢？两个；几个氢呢？五个加一个是六个；再有一个氧——写成 $C_2H_6O$。这是三种写法里最简单的一个。

**反应方程式**，就是用化学式表示化学反应的式子，它展示了反应物和生成物之间的关系。还是乙醇：它燃烧的时候和氧气发生反应，条件是燃烧、或者说点燃，最后的产物是两分子的二氧化碳和三分子的水：

$$\mathrm{C_2H_5OH + 3\,O_2 \xrightarrow{\text{点燃}} 2\,CO_2 + 3\,H_2O}$$

这就是一个反应方程式。注意，一般情况下在化学当中，反应方程式是要把它配平的——你看这个式子整个就是配平了的。但是在我们生物化学当中，研究生物体里的化学变化时，这些变化真的太复杂了，很难配平。所以我们在生物化学当中研究的时候，只关注它的底物和产物：有哪些物质，最后反应生成了另外一些物质；对配平的关注，相对来说是比较少的。

> **提示**：化学里写反应方程式要配平；生物化学里主要盯住"底物 → 产物"这条线，配平不是重点。

## 氨基酸：蛋白质的单体亚基
> 对应块：BLK02 | 覆盖分集：P02-P05 | 块标题（分集名）：《[专题02] 考点01：氨基酸-蛋白质单体亚基.》
> **静音页说明**：本块含 P03（[专题02习题]考点01：氨基酸结构），该集音频无口播，为静音考点小测页，内容据画面整理。[原视频 P03](https://www.bilibili.com/video/BV1zjpLeoEDh?p=3)

把一个教室比作一个细胞，这个比方我在基础课里打过：教室里的桌椅板凳，是蛋白质搭起来的；坐在里面上课的师生，身上真正执行功能的分子，主要也是蛋白质。蛋白质既是生物功能的载体，又是功能的执行者——撑起结构的是它，干活最多的也是它。

它在人体里占固体成分的 45%。有同学听到这个数会追问：那剩下的 55% 是什么？是水。整个生命体里的分子其实都泡在水环境当中，细胞里最多的成分就是水。所以蛋白质在水里的溶解性，会直接影响它能不能正常行使功能。这条线索先埋在这里，讲极性分类时会接上。

从细菌到植物到动物，蛋白质都是最重要的一类分子，所以我把它放在整个课程的最前面。

可最早研究蛋白质的人，面对的是一个很朴素的问题：鸡蛋的蛋清是蛋白质，牛奶里也主要是蛋白质，可它到底是一种什么样的分子？拿到一个大分子，人的第一反应就是敲敲打打，把它敲碎，打开看看里面是什么。先切成大块，再切碎，最后看一个一个的最小单元——这条路就是蛋白质的水解。

### 把大分子敲开：蛋白质的水解

蛋白质是聚合物，由一个个小单元聚合成的生物大分子；那个小单元就是氨基酸。

水解这两个字，水先放一边，重点在“解”：分解、裂解。把大分子一路拆成单体。

```text
蛋白质大分子（聚合物）
        │ 切块
        ▼
多肽碎片（若干小段）
        │ 继续切割
        ▼
氨基酸单体（最小单元）
```

读图：水解是逐级拆小——先把长链断成小段，再把小段断成单体；酸、碱、酶提供的正是三种不同的“下刀”手段。

三条路：酸水解、碱水解、酶水解。条件不同，牺牲的东西也不同。

#### 酸水解：条件最狠，代价也最明确

酸水解用 6 mol/L 的盐酸，或者 4 mol/L 的硫酸。两个浓度都高得吓人，还要回流煮沸 20 个小时。

回流是怎么回事？蛋白质放进酸里加热煮沸，酸蒸汽往上跑，上面接一根冷凝管，蒸汽在管里凝成液体再流回瓶里，循环 20 小时，酸不跑掉，样品一直被高浓度酸煮着。这个条件相当苛刻。

换来的好处是不起消旋作用，产物全是 L 型氨基酸。

代价有三条：

第一，色氨酸被破坏。

第二，天冬酰胺和谷氨酰胺的侧链酰胺基被水解，分别变成天冬氨酸和谷氨酸。

第三，丝氨酸和苏氨酸会小部分分解。

这三条是选择题的常客，尤其色氨酸和两种酰胺。

> **易错点**：酸水解是把 Asn、Gln 的酰胺基水解掉，生成 Asp、Glu，不是把这两种氨基酸整个破坏掉。测组成时 Asp、Glu 会“变多”，原来的酰胺形式消失；真正被破坏的是色氨酸。

刚开课就牵扯到酰胺键、旋光性，很正常。生物化学的知识是环状结构，前后咬得特别紧，从哪儿开始讲都会碰到后面的东西。先把结论记下来，后面接着学几节，自然就熟了。

#### 碱水解：保住色氨酸，赔上构型

碱水解用 5 mol/L 的氢氧化钠，共煮 10 到 20 个小时。强碱加长时间煮沸，同样苛刻。

它的优点正好和酸水解对着来：色氨酸稳定。

缺点三条：

第一，多数氨基酸会遭到不同程度的破坏。

第二，消旋。天然蛋白质里的氨基酸绝大多数是 L 型，碱一煮，L 型保不住，转成 D 型，最后得到 D 型和 L 型的混合物。

第三，精氨酸脱氨，生成鸟氨酸和尿素。

> **提示**：酸水解和碱水解的优缺点是一对镜像——酸怕色氨酸、碱保色氨酸；酸不消旋、碱消旋。成对记，比一条一条背省力。

#### 酶水解：温和，为拆序列而生

酶水解加的是蛋白酶或肽酶。

优点：不消旋，也不破坏氨基酸。它可以把蛋白质一点一点水解下来，所以能用于蛋白质的部分水解，服务于一级结构分析。

肽可以理解成小一号的蛋白。蛋白质是一条链，组成它的氨基酸少一些，这条链就叫肽链。

一级结构分析怎么用酶？把蛋白质放进烧杯，加入只切某一端的蛋白酶；切下一段后，马上加酶抑制剂把酶终止；再检测烧杯里多了哪些氨基酸，就能确定这条肽链末端到底是什么。

```text
蛋白质 / 肽链
     │ 加入只切末端的蛋白酶
     ▼
末端残基被切下，释放游离氨基酸
     │ 加入酶抑制剂，终止反应
     ▼
检测释放出的氨基酸种类
     │
     ▼
确定末端残基，推断一级结构
```

读图：关键在“切一段—立刻停—再检测”，抑制剂把反应卡在一个可读的中间状态。

缺点：持续时间比较长；反应条件温和，没有酸和碱那么强烈。

#### 酸、碱、酶怎么选

把三种方式摆在一起，各自牺牲了什么就很清楚。

| 方式 | 条件 | 优点 | 主要代价 |
| :--- | :--- | :--- | :--- |
| 酸水解 | 6 mol/L 盐酸或 4 mol/L 硫酸，回流煮沸 20 h | 不消旋，产物全为 L 型 | 色氨酸破坏；Asn、Gln 变为 Asp、Glu；Ser、Thr 部分分解 |
| 碱水解 | 5 mol/L 氢氧化钠，共煮 10~20 h | 色氨酸稳定 | 多数氨基酸不同程度破坏；消旋成 D/L 混合物；Arg 脱氨生成鸟氨酸和尿素 |
| 酶水解 | 蛋白酶或肽酶 | 不消旋、不破坏氨基酸；可部分水解，用于一级结构分析 | 耗时长；反应不如酸碱强烈 |

要保住色氨酸，用碱；要保住构型，用酸或酶；要读序列，用酶。三种方法没有全能选手，考点就藏在各自牺牲了什么。

### α-氨基酸的一般结构

组成蛋白质的常见氨基酸有 20 种；除了甘氨酸，其余 19 种都是 L 型 α-氨基酸。

为什么叫 α-氨基酸？看羧基。羧基是这个分子的官能团——它决定整个分子显酸性，氨基酸名字里的“酸”就来自它。直接连接羧基的那个碳，叫 α 碳。

α 碳有四个配位键，连着四样东西：一个羧基、一个氨基、一个氢、一个 R 基。R 基就是侧链。

20 种氨基酸长得一样的地方，是 α 碳上的这套骨架；不同之处只有 R 基。

```text
         COOH              COO-
          |                 |
   H2N -- C -- H      H3N+ -- C -- H
          |                 |
          R                 R

      未电离形式          兼性离子形式
```

读图：两种写法只差一个质子的转移——羧基丢一个 $H^+$ 变成 $-\mathrm{COO^-}$，氨基得一个 $H^+$ 变成 $-\mathrm{NH_3^+}$；右边整体净电荷仍然为零。

> **定义**：同一个分子里同时带有可解离的酸性基团和碱性基团，在水溶液中以正、负离子并存的形式存在，这种离子叫兼性离子（zwitterion）。氨基酸在水环境里主要以这种形式存在。

写通式时两种写法都算对：要么羧基、氨基都不电离，要么都电离。后一种羧基少了一个质子、氨基多了一个质子，正负抵消，分子整体仍是电中性的。

考试不会直接让你默画这个结构，但后面很多内容都从这套骨架长出来，这个通式必须理解透。

### 手性碳、旋光与 L 型

α 碳的四个配位键如果连着四个不同的基团，这个碳就是手性碳，分子具有旋光性。

一束偏振光通过这样的分子，偏振方向会发生偏转：向左偏叫左旋，向右偏叫右旋。天然蛋白质里的 19 种手性氨基酸都是 L 型。

甘氨酸是唯一的例外。它的 R 基也是一个氢，α 碳上两个配位键连的都是氢，四个基团里有重复，不构成手性碳，所以甘氨酸没有旋光性。

> **易错点**：判断有没有旋光性，只看 α 碳上的四个基团是否两两不同。甘氨酸是 H 和 H 重复，因此无旋光性；其余 19 种都有。

> **提示**：L / D 是构型标记，左旋、右旋是旋光仪测出来的偏转方向，两者不是同一个概念。考试要记的结论只有一条：组成蛋白质的 20 种常见氨基酸中，除甘氨酸外全为 L 型。

### 氨基酸的分类

氨基酸先分成两大类：组成蛋白质的氨基酸，和非蛋白质氨基酸。组成蛋白质的又分常见与不常见，重点是常见的那 20 种。

```text
氨基酸
├─ 蛋白质氨基酸
│  ├─ 常见蛋白质氨基酸（20 种，重点）
│  └─ 不常见蛋白质氨基酸（硒代半胱氨酸，第 21 种）
└─ 非蛋白质氨基酸（代谢中间产物，一般不出现在蛋白质中）
```

读图：第一刀切在“是否出现在蛋白质里”，第二刀才切“常见与否”；考试重心压在常见的那一支。

#### 常见氨基酸与三字母符号

20 种常见氨基酸，每一种都有三字母符号和单字母符号。三字母符号要求记下来——后面的题目经常直接用三字母写肽链的排列顺序，符号不熟，题都读不下去。单字母先混个脸熟，重心放在三字母上。

这 20 种共用一套通式：α 碳上挂羧基、氨基、氢和侧链。侧链不同，带电情况、极性和溶解性就不同，分类也是按侧链来切的。

#### 按化学结构分类

按化学结构，分成脂肪族、芳香族、杂环族三组。

脂肪族里面再分四小类：

- 一氨基一羧基的；
- 一氨基一羧基的酰胺，只有谷氨酰胺和天冬酰胺两种；
- 一氨基二羧基的，是酸性氨基酸，通常带负电；
- 二氨基一羧基的，是碱性氨基酸，带正电。

芳香族氨基酸的侧链含苯环。杂环族里主要是组氨酸，侧链是咪唑基，它也显碱性。

所以碱性氨基酸其实是三种：脂肪族里的精氨酸、赖氨酸，加上杂环族里的组氨酸。这一点特别容易漏——按结构分类时它们被拆在两处，数的时候别只数脂肪族那两个。

> **注意**：酸性氨基酸和碱性氨基酸的带电结论，默认环境都是 pH 7.0。pH 一变，质子得失的情况就变，带电也跟着变。

#### 酸性氨基酸与碱性氨基酸的带电账本

先看酸性氨基酸，一共两种：天冬氨酸（Asp）和谷氨酸（Glu）。它们的侧链上带一个羧基，这个羧基能释放质子。

天冬氨酸在 pH 7.0 的账是：α-羧基失去一个质子，记 −1；侧链羧基再失去一个质子，再记 −1；α-氨基得到一个质子，记 +1。两失一得，净电荷 −1。

谷氨酸的侧链比天冬氨酸多一个碳，账一模一样，净电荷也是 −1。

碱性氨基酸一共三种：赖氨酸（Lys）、精氨酸（Arg）、组氨酸（His）。它们的侧链上有能结合质子的基团。

赖氨酸的侧链末端是氨基。α-羧基失质子 −1，α-氨基得质子 +1，侧链氨基再得质子 +1，两正一负，净 +1。

精氨酸的侧链上是胍基，胍基上的氮能结合质子。α 端一失一得互相抵消，侧链再得一个质子，净 +1。

组氨酸的侧链是咪唑基，同样能结合质子。α 端抵消，侧链得一个质子，净 +1。

> **结论**：pH 7.0 时，酸性氨基酸（Asp、Glu）净带负电，碱性氨基酸（Lys、Arg、His）净带正电。决定酸碱性的是侧链上多出来的那个可解离基团；α-羧基和 α-氨基这一对在任何氨基酸里都互相抵消，不决定类别。

碱性氨基酸有个口诀：进来坐。进是精氨酸，来是赖氨酸，坐是组氨酸。

| 类别 | 氨基酸 | 三字母符号 | 侧链可解离基团 | pH 7.0 净电荷 |
| :--- | :--- | :--- | :--- | :--- |
| 酸性 | 天冬氨酸 | Asp | 羧基 | −1 |
| 酸性 | 谷氨酸 | Glu | 羧基 | −1 |
| 碱性 | 赖氨酸 | Lys | 氨基 | +1 |
| 碱性 | 精氨酸 | Arg | 胍基 | +1 |
| 碱性 | 组氨酸 | His | 咪唑基 | +1 |

这五种连同三字母符号是硬要求：Asp、Glu、Lys、Arg、His。

#### 按极性分类

先讲极性是什么。把水和油倒进同一个杯子，摇得再匀，放一会儿还是分层——水和油完全不互溶，可以看成极性的两个极端：水的极性最大，油的极性最小。从油到水，就是极性从小到大的过程。

极性还有一个名字叫亲水性，也叫水溶性；非极性叫脂溶性，也叫疏水性。极性越大，越容易溶进水里；非极性越大，越容易溶进油里。

20 种氨基酸的极性，可以用纸层析看出来：先把它们溶在水里，点在一张滤纸的原点；滤纸下端浸入展开剂，展开剂是脂溶性的有机溶剂，可以把它当成“油”；展开剂沿着滤纸往上爬，路过点样点，脂溶性强的氨基酸被带着走，脂溶性弱的带不走。

```text
滤纸
┌──────────────────────────┐
│ 展开剂前沿 ↑              │
│ ── 条带 3（脂溶性最强）    │
│ ── 条带 2                 │
│ ── 条带 1                 │
│ ● 点样原点（水溶性最强）   │
└──────────────────────────┘
       展开剂自下而上渗透
```

读图：跑得越远，说明越容易溶在展开剂里，脂溶性越强、非极性越强；留在原点附近，说明越亲水、极性越强。

pH 7.0 下的结果可以归成这张表：

| 大类 | 小类 | 侧链特征 | pH 7.0 带电 |
| :--- | :--- | :--- | :--- |
| 非极性（疏水） | 非极性脂肪族 | 基本由碳、氢组成，甲硫氨酸多一个硫原子 | 不带电 |
| 非极性（疏水） | 芳香族 | 含苯环，环上也是碳、氢 | 不带电 |
| 极性（亲水） | 极性不带电 | 有极性基团但不带净电荷 | 不带电 |
| 极性（亲水） | 碱性氨基酸 | 侧链可结合质子 | 带正电 |
| 极性（亲水） | 酸性氨基酸 | 侧链可释放质子 | 带负电 |

不管按哪种方式分，氨基酸的溶解性都跟环境 pH 密切相关。pH 改变解离状态，带电情况变了，极性和溶解性也跟着变。

#### 不常见的蛋白质氨基酸：硒代半胱氨酸

半胱氨酸的侧链是 $-\mathrm{CH_2SH}$，末端是巯基。巯基特别容易失去上面的氢。

硒代半胱氨酸，就是把半胱氨酸里的硫原子换成硒原子。

为什么单独把它拎出来？过去大家说组成蛋白质的氨基酸只有 20 种；后来发现，硒代半胱氨酸也能出现在生物体自身合成的蛋白质里。所以它是第 21 种蛋白质氨基酸。这个“第 21 种”是选择题的常客。

> **注意**：第 21 种属于“不常见的蛋白质氨基酸”，不在常见 20 种里。题目问常见氨基酸有多少种，答案仍是 20。

#### 非蛋白质氨基酸

非蛋白质氨基酸特别多：β-丙氨酸、γ-氨基丁酸、环丝氨酸、鸟氨酸、胱氨酸、高丝氨酸，等等。

它们一般是生物体代谢产生的中间产物，一般不出现在蛋白质当中——“非蛋白质氨基酸”这个名字说的就是这个意思。这里了解即可，讲到具体代谢过程时还会再遇到。

### 本讲提到的题目

考点小测里有这么两道选择题。

**题目 1**：蛋白质酸水解，容易破坏哪个氨基酸？

A. 甘氨酸　B. 色氨酸　C. 谷氨酸　D. 天冬氨酸

**答案**：B。

**解析**：酸水解的缺点里，第一条就是色氨酸被破坏。谷氨酸和天冬氨酸不但不是主要破坏对象，酸水解还会把谷氨酰胺、天冬酰胺的酰胺基水解掉，分别生成谷氨酸和天冬氨酸，使这两种在组成分析里“变多”。甘氨酸的 R 基就是氢，没有可被酸水解破坏的侧链基团。

**题目 2**：组成蛋白质的常见氨基酸共有多少种？

A. 18 种　B. 20 种　C. 21 种　D. 300 余种

**答案**：B。

**解析**：常见的蛋白质氨基酸是 20 种，除甘氨酸外 19 种为 L 型 α-氨基酸。21 是加上硒代半胱氨酸之后的蛋白质氨基酸总数，属于不常见的那一类；18 不对；300 余种不是“常见蛋白质氨基酸”的口径。

## 氨基酸的酸碱性质与化学反应
> 对应块：BLK03 | 覆盖分集：P06-P10 | 块标题（分集名）：《[专题02] 考点03：氨基酸的酸碱性质【修】》
> **静音页说明**：本块含 P08（[专题02习题]考点03：氨基酸的酸碱性质2），该集音频无口播，为静音考点小测页，内容据画面整理。[原视频 P08](https://www.bilibili.com/video/BV1zjpLeoEDh?p=8)

一个氨基酸分子上，同时挂着一个羧基和一个氨基。羧基是酸性基团，在水里会把氢离子交出去；氨基是碱性基团，在水里专门接氢离子。一个往外放、一个往里收，同一个分子上就出现了两块电性相反的基团——氨基酸所有的酸碱性质，都是从这件"自相矛盾"的事上长出来的。

所以这一讲分两段走。前半段把这个分子在水里的带电情况拆开看清楚：它怎么一步一步丢掉质子，pK 到底是个什么东西，等电点为什么能用一个平均值算出来，酸性氨基酸和碱性氨基酸的算法又为什么不一样。看清楚带电，后半段换一副眼光看同一个分子——它的羧基、氨基、侧链分别能参加哪些化学反应，哪些只是了解，哪两个反应是必须拿下的测序手段。

### 一个分子上的两种电荷

氨基酸的通式前面已经反复用过：一个 α-碳，上面连着羧基和氨基，另外还挂着一个氢原子和一个侧链 R 基团。真正决定酸碱性质的是前两个：羧基是酸性基团，能解离出氢离子，解离之后自己变成一个带负电的基团；氨基是碱性基团，在溶液里能吸引氢离子、接受氢离子，接受之后自己带上正电。

一个丢、一个接，于是氨基酸在水里就有了两种写法：一种是非离子形式，羧基和氨基都不显电；另一种是兼性离子形式，一头带负电、一头带正电。

在中性水溶液里，氨基酸绝大多数以兼性离子形式存在。这句话里有个前提必须记住——**是"中性水溶液里"**。酸性基团要不要丢质子、碱性基团要不要接质子，取决于所处溶液的 pH；pH 一变，形态就跟着变。兼性离子只是 pH 中性时的主流形态，不是它永远的样子。

拿最简单的甘氨酸来看。它的兼性离子里，羧基已经丢掉了质子，带负电；氨基接上了质子，带正电。对整个分子来说，一个负、一个正，加起来净电荷是 0。

> **定义**：兼性离子是指分子内部同时带有正电荷中心和负电荷中心、但整个分子净电荷为零的离子形式。判断它是不是兼性离子，看的不是"有没有带电基团"，而是"正负电荷加起来是不是零"——甘氨酸的兼性离子里明明有两个带电基团，它仍然是兼性离子。

### 甘氨酸的三步解离

把甘氨酸的兼性离子放进一个极酸的环境里，它会完全质子化。所谓完全质子化，就是所有能携带质子的基团都带上质子：氨基本来就带着质子，仍然带着；羧基上那个已经跑掉的质子，在极酸环境里会回来，变回中性的羧基。这时候整个分子带一个正电荷，净电荷 +1。

往这个带正电的溶液里加氢氧化钠，就是往里加氢氧根。氢氧根对氢离子的亲和力很强，它会逐步把羧基上的质子夺走，分子就从完全质子化的状态变成兼性离子，净电荷从 +1 回到 0。这一步不是单向的：溶液里并不是加了氢氧根就一个氢离子都不剩了，所以 1 号状态会往 2 号状态走，2 号状态也会往 1 号状态走，是一个可逆平衡。

当 1 号状态和 2 号状态的浓度相等时，溶液的 pH 就定义为 $\text{pK}_1$。那个 $K$ 是解离常数，不用去管它，只要记住 $\text{pK}_1$ 就是"解离方程式两侧两种状态浓度相等时的 pH"。

继续加氢氧根，轮到氨基了。2 号状态里的氨基本来携带着一个质子，氢氧根越来越多，这个质子也会被夺走，氨基变成不带电的状态。此时羧酸根依然带着负电，于是整个分子净电荷变成 −1。2 号与 3 号浓度相等时的 pH，就是 $\text{pK}_2$。

```text
pH 低（极酸）
     |
     |   状态 1：净电荷 +1    α-COOH / α-NH3+
     |        ↕  pK1（状态 1 与状态 2 等浓）
     |   状态 2：净电荷  0    α-COO- / α-NH3+   ← 兼性离子
     |        ↕  pK2（状态 2 与状态 3 等浓）
     |   状态 3：净电荷 -1    α-COO- / α-NH2
     v
pH 高（极碱）
```

竖轴是 pH，自上而下 pH 升高：每跨过一个 pK，主流形态换一次，分子的净电荷就减 1。三个状态之间都是可逆平衡，加酸往上走、加碱往下走。

整个过程归纳成一句话：从左往右就是 pH 升高、逐步失质子。第一步失的是羧基上的质子，生成羧酸根；第二步失的是氨基上的质子，最后整个分子带负电。而最开始那个完全质子化的分子，带的是正电。

> **提示**：pK 值从左到右是越来越大的。这个顺序后面会直接用到——先解离的基团 pK 小，后解离的 pK 大，判断酸性、碱性氨基酸该取哪两个 pK 时，靠的就是这一条。

### 等电点：pI 是一个 pH 值

整个解离过程里最重要的一个名词，是等电点。

> **定义**：等电点指在某一个 pH 条件下，氨基酸解离成阳离子和阴离子的数量相等，此时分子呈电中性。这个溶液的 pH 就称为该氨基酸的等电点。

对照上面的三个状态，分子呈电中性的就是 2 号状态。所以等电点不是别的，它就是一个 pH 值——氨基酸处在电中性的兼性离子状态时，所处溶液的 pH 值。甘氨酸的 2 号状态对应哪个 pH，甘氨酸的等电点就是多少。

算的时候，等电点等于兼性离子两端那两个 pK 值的平均值。甘氨酸的兼性离子是 2 号状态，左边是 $\text{pK}_1$、右边是 $\text{pK}_2$，于是

$$\text{pI} = \frac{\text{pK}_1 + \text{pK}_2}{2}$$

绝大多数氨基酸都这么算。原因很简单：绝大多数氨基酸只有一个氨基、一个羧基，解离只有这两步，走完就结束了，兼性离子正好夹在 $\text{pK}_1$ 和 $\text{pK}_2$ 中间。

例外是五个 R 基团也能解离的氨基酸：其中两个是酸性氨基酸，三个是碱性氨基酸。它们的 pK 有三个，不能照搬这条公式。

> **提示**：等电点说的"两端"，指的是兼性离子在解离序列里的前后两个邻居，不是"分子的两端"。先找准哪个状态是兼性离子，再取它左右两个 pK，这题就不会错。

### 酸性氨基酸：多一个羧基，等电点往酸侧走

酸性氨基酸有两个：谷氨酸和天冬氨酸。它们的共同点是有一个氨基、两个羧基——一个是 α-羧基，另一个在 R 基团侧链上。

以谷氨酸为例。在极酸环境里完全质子化时，α-羧基和侧链羧基都以羧基的形式存在，质子都连得好好的，不带电；氨基上携带着它的质子，带正电。整个分子净电荷 +1。

pH 逐渐升高，它开始按顺序失质子，一共四个状态：

| 状态 | α-羧基 | 侧链羧基 | α-氨基 | 净电荷 |
| :--- | :--- | :--- | :--- | :--- |
| 1 | —COOH | —COOH | —NH₃⁺ | +1 |
| 2 | —COO⁻ | —COOH | —NH₃⁺ | 0 |
| 3 | —COO⁻ | —COO⁻ | —NH₃⁺ | −1 |
| 4 | —COO⁻ | —COO⁻ | —NH₂ | −2 |

第一步先失 α-羧基的质子。1 号状态本来带一个正电荷，失掉一个质子就等于失掉一个正电荷，可同时又多出来一个带负电的羧酸根，正负抵消，2 号状态净电荷为 0。第二步轮到侧链羧基，它再失一个质子，分子变成两个负电基团对一个正电基团，净电荷 −1。第三步氨基失质子，两个负电基团一个正电基团都不剩，净电荷 −2。

四个状态里，只有 2 号状态不带电，它就是兼性离子。而 2 号状态出现在**第一次解离之后**，所以它两侧的 pK 是 $\text{pK}_1$（α-羧基）和 $\text{pK}_\text{R}$（侧链羧基）：

$$\text{pI} = \frac{\text{pK}_1 + \text{pK}_\text{R}}{2}$$

换成一句考场上更好用的话：酸性氨基酸有三个 pK，算等电点时取**两个较小的 pK** 求平均。因为 pK 从左到右越来越大，前两个正好就是小的那两个。天冬氨酸完全同理。

这里有个原则值得单独记：不管这个 pK 属于哪个基团，只看兼性离子两端是哪两个 pK。基团的名字可以忘，位置不能找错。

> **易错点**：三个 pK 既不等于"取中间那个"，也不等于"三个一起平均"。酸性氨基酸的兼性离子在第一次解离之后就出现了，所以要取两个较小的；这一点和下面碱性氨基酸正好相反。

考试里常见这么问：某氨基酸解离时有三个 pK 值，问它是谷氨酸、天冬氨酸，还是后面的碱性氨基酸，等电点怎么算。看到酸性氨基酸，直接取两个小的求平均。

### 碱性氨基酸：多一个碱性基团，等电点往碱侧走

碱性氨基酸有三个：赖氨酸、精氨酸、组氨酸。以赖氨酸为例。

它的侧链上还多一个碱性基团（氨基），所以在极酸环境里完全质子化时，能带质子的地方有三处：α-羧基是羧基形式、不带电，α-氨基带着质子，侧链氨基也带着质子。整个分子净电荷 +2，这是 1 号状态。

pH 升高，解离照样从 α-羧基开始：

| 状态 | α-羧基 | α-氨基 | 侧链氨基 | 净电荷 |
| :--- | :--- | :--- | :--- | :--- |
| 1 | —COOH | —NH₃⁺ | —NH₃⁺ | +2 |
| 2 | —COO⁻ | —NH₃⁺ | —NH₃⁺ | +1 |
| 3 | —COO⁻ | —NH₂ | —NH₃⁺ | 0 |
| 4 | —COO⁻ | —NH₂ | —NH₂ | −1 |

第一步失 α-羧基的质子，2 号状态是一个负电荷对两个正电荷，净电荷 +1——注意，它**不是**兼性离子，因为兼性离子要找的是不带电的那个。第二步 α-氨基失质子，此时羧基带一个负电、侧链氨基带一个正电，净电荷才归零，3 号状态才是兼性离子。第三步侧链氨基再失质子，分子带一个负电。

兼性离子 3 号出现在**第二次解离之后**，它两侧的 pK 是后两个：

$$\text{pI} = \frac{\text{pK}_2 + \text{pK}_\text{R}}{2}$$

也就是 α-氨基和侧链碱性基团那两个。换成考场的说法：碱性氨基酸有三个 pK，取**两个较大的 pK** 求平均。

为什么必然是两个大的？把逻辑捋一遍就清楚了：碱性氨基酸在完全质子化时带两个正电；解离一次还剩一个正电，解离两次才到电中性，解离第三次才带一个负电。兼性离子既然出现在第二次解离之后，夹着它的自然就是序列里靠后的那两个 pK。精氨酸、组氨酸同理。

把三类氨基酸放在一起对照，规律一目了然：

| 类型 | 数目 | 完全质子化净电荷 | 兼性离子出现在 | pI 取哪两个 pK |
| :--- | :--- | :--- | :--- | :--- |
| 中性氨基酸 | 20 种中的 15 种 | +1 | 第 1 次解离后 | 两个 pK 平均 |
| 酸性氨基酸 | 2 种（谷氨酸、天冬氨酸） | +1 | 第 1 次解离后 | 两个较小的 |
| 碱性氨基酸 | 3 种（赖氨酸、精氨酸、组氨酸） | +2 | 第 2 次解离后 | 两个较大的 |

> **易错点**：酸性氨基酸完全质子化时净电荷是 +1，不是负的——两个羧基都还是中性的羧基，只有氨基带正电。别被"酸性"两个字带偏，判断带电只看基团当下的状态。

### 组氨酸：生理 pH 下的缓冲者

二十种氨基酸的 pK 值和等电点排在一张表里，绝大多数扫一眼就过去了，只有一个值得单独拎出来：组氨酸。

它的等电点是 7.59。整张表里，等电点落在 7 附近、也就是中性附近的，只有组氨酸这一个。

这件事的意义在于：生理状态下 pH 就在 7 左右，而组氨酸的等电点也在 7 左右，所以组氨酸在生理条件下正好以兼性离子形式存在。而兼性离子这个形态很特殊——它既能当质子的受体，也能当质子的供体。

```text
pH 低（溶液里进来酸）
     |
     |   状态 1：净电荷 +1   羧基把质子接回来，把外加的 H+ 吸住
     |        ↕
     |   状态 2：净电荷  0   兼性离子（生理 pH 下的主流形态）
     |        ↕
     |   状态 3：净电荷 -1   α-氨基交出质子，中和外加的 OH-
     v
pH 高（溶液里进来碱）
```

溶液里进来一些酸、也就是进来一些氢离子，它那个本来已经丢掉质子的羧基可以把质子接回来，等于把刚加进来的少量氢离子收掉了，不让它们游离在溶液里。溶液里进来一些氢氧根，氢氧根要夺质子，它就把氨基上的质子交出去。往左能接、往右能给，两头都兜得住。

所以组氨酸溶液在生理条件下，加入少量的酸或碱，pH 的改变其实很小——它可以作为一种缓冲溶液，缓冲的是溶液的酸碱度。实验室里常用的 Tris 就是同一个道理：水溶液的 pH 被强酸或强碱调定之后，再加少量弱酸弱碱、甚至少量强酸强碱，pH 都很难被改变。

> **提示**：缓冲不等于"不反应"。外来酸有基团把质子接住，外来碱有质子可以交出去，反应照做，只是溶液里的氢离子浓度被摁住了，pH 才显得稳。

### pH 与 pI 的三条判断

还有一个几乎每次都考的问题：一个氨基酸所处的溶液 pH 等于、大于、小于它的等电点时，它各自带什么电？

$\text{pH} = \text{pI}$ 时，它以兼性离子的形式存在：一个基团丢了质子，一个基团得到了质子，正负相抵，净电荷为 0。顺带说一句，兼性离子状态和非离子状态是可以互变的，只是在水溶液里绝大多数以兼性离子形式存在。

$\text{pH} > \text{pI}$ 时，相当于在等电点那个状态上加氢氧根。氢氧根和质子的亲和力很高，它会去夺本来携带着质子的氨基上的质子；氨基丢了质子，可羧酸根还在那儿放着，于是整个分子带负电。

$\text{pH} < \text{pI}$ 时，相当于在等电点状态上加氢离子。氢离子会加到本来已经丢了质子的羧基上，重新结合成羧基；氨基那边本来带着质子，氢离子更多了，它更没有理由丢掉。于是整个分子带正电。

| 条件 | 相当于 | 哪个基团发生了变化 | 净电荷 |
| :--- | :--- | :--- | :--- |
| $\text{pH} = \text{pI}$ | 兼性离子本身 | 不变 | 0 |
| $\text{pH} > \text{pI}$ | 加碱（OH⁻） | 氨基交出质子 | 负 |
| $\text{pH} < \text{pI}$ | 加酸（H⁺） | 羧基接回质子 | 正 |

记的时候有个小窍门：加酸就是加氢离子，氢离子带正电，所以 $\text{pH} < \text{pI}$ 时氨基酸带正电；加碱就是加氢氧根，氢氧根带负电，所以 $\text{pH} > \text{pI}$ 时氨基酸带负电。一句话——酸正碱负。

> **易错点**：别把它记成"pH 高就带正电"。判断的顺序永远是：先问溶液里多出来的是酸还是碱，再问哪个基团会被动。pH 高意味着碱多，碱去夺氨基的质子，氨基不带电了、羧酸根还在，所以带负电。

### 换一副眼光看氨基酸：哪些基团能反应

带电的事讲完，同一个分子还能再看一遍——这次看它能跟什么试剂起反应。

从这一讲开始，PPT 上每个知识点都会标出重要程度，分三个等级：三颗星是必须掌握的内容，两颗星是一般性的知识，一颗星是了解就可以。

还是先回到通式：一个 α-碳，上面连着羧基、氨基、一个氢原子，剩下一个是侧链 R 基团。把一个氨基酸拆成这三块来看，化学反应自然就分成三堆：

- α-羧基，二十种氨基酸全都有，所以它参与的反应就是大家共有的反应；
- α-氨基，二十种编码氨基酸也全都有，所以它参与的反应几乎也是所有氨基酸都能参与的；
- 侧链 R 基团，氨基酸之间的差别恰恰在这里，所以它参与的反应就比较特殊，往往只针对某一些氨基酸上的某些特殊基团。

最后这一条还有一层用处：正因为侧链反应是特异的，就可以反过来拿它做检测——某种试剂只跟某种侧链反应，就能在复杂体系里把那种氨基酸单独认出来。

整块内容分四个板块：

| 板块 | 具体反应 | 掌握要求 |
| :--- | :--- | :--- |
| α-羧基参与 | 酯化、酰氯化、酰胺化 | 了解即可 |
| α-氨基参与 | 酰化（保护氨基）、西佛碱 | 知道用途即可 |
| α-氨基参与 | 二硝基氟苯标记、苯异硫氰酸酯标记 | 三颗星，必须掌握 |
| 羧基与氨基共同参与 | 成肽、茚三酮 | 三颗星，必须掌握 |
| 侧链参与 | 米隆反应、Pauly 反应等 | 了解即可 |

### α-羧基的三类反应

先看羧基的结构。写出来是 —COOH，但这个碳氧氧氢不是四个原子随便排的：羧基碳前面连着 α-碳；后面一个氧是碳氧双键；再后面那个氧连着一个氢，是一个羟基。所以羧基能参加的反应，主要就发生在这个羟基上。

酯化反应就是中学化学里学过的那个酯化：酸脱羟基、醇脱氢，在干燥的氯化氢作用下回流，两边脱掉一分子水，剩下的部分接起来。拿乙醇做例子，乙醇上的 $\text{C}_2\text{H}_5\text{O}$— 接到羧基碳上，原来的碳氧双键保留，生成的就是酯。酯可以看成一个酰基连了一个烷氧基，属于特殊的酰基化合物。

酰氯化反应里，α-氨基是先被保护起来的——这一步只看羧基，氨基先不用管。羧基和五氯化磷反应，羟基被脱下来，羧基碳直接和氯原子连起来，生成的就是酰氯。

顺便把"酰基"这个说法定清楚：羧基去掉羟基之后剩下的那部分（—CO— 连着碳链）就叫酰基。羟基位置上换成什么基团，就叫什么酰化物——换成氯是酰氯，换成氨基就是酰胺。

酰胺化更直白：羧基碳后面连上一个氨基，产物就叫酰胺。

> **提示**：酯化、酰氯化、酰胺化听着名目多，做的其实是同一件事——把羧基上的羟基换掉。盯住那个羟基，这三类反应就串成一条线了。

### α-氨基的反应：保护与两条测序路线

#### 酰化：先把氨基藏起来

氨基和酰氯在弱碱的环境下就能反应，生成酰胺的衍生物。反应发生在氨基上，氨基和酰氯一接，原来的氨基就变成了酰胺的一部分。

这个酰胺衍生物有个很有用的性质：它特别稳定，不容易再跟别的化学试剂反应。于是它就成了一个保护基——先把氨基这样"封"起来，是很常见的操作的第一步。保护起来之后，再拿这个衍生物去跟其他试剂反应，氨基就不会跟着乱动了。

这套"先保护、再反应"的思路，本质上就是让分子上不想动的地方暂时失去活性，把反应赶到想要的位置上去。

#### 西佛碱：酶促反应里的常客

氨基还能和醛类化合物反应，生成西佛碱。

这个反应在生物体内很常见：很多酶促反应的过程中都会形成西佛碱类的中间产物。也就是说，这不是一条只在试管里成立的反应，酶催化时会反复借用这个结构。

#### 桑格法：给 N 端贴标签

接下来这个反应是三颗星，比较重要：氨基与二硝基氟苯反应。

二硝基氟苯有三种缩写写法——FDNB、DNFB、FNDB，指的都是同一个试剂。它经常和后面"多肽链一级结构测定"那个知识点联动考。

反应在弱碱中进行，对象是一条肽链。肽链就是一堆氨基酸首尾串起来的链，它只有一头是自由的氨基，也就是第一个氨基酸的 α-氨基。二硝基氟苯恰恰就和这个氨基反应，接上去以后生成 DNP-肽，译成中文就是二硝基苯多肽——相当于给整条链的 N 端挂了一个二硝基苯基的牌子。

```text
多肽链（N 端在左，其余残基首尾相连）
     |
     |  ① 弱碱条件下与二硝基氟苯反应
     v
DNP-多肽（只有 N 端那一个氨基酸挂上了二硝基苯基）
     |
     |  ② 酸水解：肽链上的肽键全部断开
     v
游离氨基酸的混合物  +  带标记的 DNP-氨基酸（只来自 N 端）
     |
     |  ③ 分离并鉴定这个 DNP-氨基酸是哪一种
     v
确定整条肽链的 N 端是哪个氨基酸
```

关键在于酸水解这一步：肽键全断了，链上每个氨基酸都变成游离的个体，唯独第一个氨基酸因为跟二硝基氟苯连在一起，变成了 DNP-氨基酸，和其余所有氨基酸区分开。把它挑出来检测，就知道 N 端是谁。

这个方法最早是桑格（Sanger）用来检测多肽链第一个氨基酸的，所以也叫桑格法。

#### Edman 法：一轮切一个

另一个三颗星的反应，用的是苯异硫氰酸酯，缩写 PITC。它的反应式和桑格法类似，也是从肽链的 N 端下手，但后续走向不同。

```text
多肽链（N 端在左）
     |
     |  ① PITC 与 N 端氨基酸的氨基反应，把 N 端标记上
     v
PITC-肽
     |
     |  ② 环化分裂：N 端这一个氨基酸从链上被切下来
     v
ATZ（第一个氨基酸与 PITC 环化后的产物）  +  少了一个残基的肽链
     |                                        （新的 N 端变成原来的第二个氨基酸）
     |  ③ ATZ 进一步转变
     v
PTH-氨基酸  →  鉴定它是哪一种氨基酸
     |
     |  ④ 对剩下的肽链重复 ①～③
     v
第二轮读出第二个氨基酸，如此一轮一个，直到整条序列读完
```

第一步，PITC 和第一个氨基酸的氨基反应，相当于在肽链头上做了一个标记。第二步环化分裂，第一个氨基酸直接从肽链上被切下来，剩下的就是以第二个氨基酸为首的多肽。第三步，切下来的产物（ATZ）进一步转变成 PTH-氨基酸，拿去做后续检测，确定这第一个氨基酸到底是哪一种。然后拿 PITC 去跟剩下的肽链再反应一轮，第二个氨基酸就测出来了；一轮一轮往下走，整条多肽链的序列就全读出来了。

这就是 Edman 法。考试里最常考的两种测序方法就是它和桑格法，两种方法的区别要分清楚：

| 方法 | 试剂 | 与 N 端反应后的产物 | N 端残基是否被切下 | 最终检测什么 |
| :--- | :--- | :--- | :--- | :--- |
| 桑格法 | 二硝基氟苯（FDNB、DNFB、FNDB） | DNP-肽 | 不切，靠酸水解把肽键全部打断 | DNP-氨基酸 |
| Edman 法 | 苯异硫氰酸酯（PITC） | PITC-肽，环化后得 ATZ | 切下，剩余肽链可继续测下一轮 | PTH-氨基酸 |

> **注意**：桑格法和 Edman 法都能回答"N 端是谁"，但只有 Edman 法能一轮一轮往下读序列——因为它把测过的残基切掉了，剩下的链还能接着用。试剂更不能记混：桑格法是二硝基氟苯，Edman 法是苯异硫氰酸酯。

### 羧基与氨基联手：成肽与茚三酮

#### 成肽反应：肽键就是酰胺键

这一组也是三颗星，而且第一个反应最要紧：成肽反应。

先把这个反应的位置摆正。氨基酸最终要组成蛋白质，路线是：一个个氨基酸先串成肽链，很多条肽链、或者很复杂的肽链，再进行空间折叠，最后才形成有空间构象的蛋白质。串起来这一步，靠的就是成肽反应。

它由前一个氨基酸的 α-羧基和后一个氨基酸的 α-氨基共同完成。具体到原子上：前一个氨基酸 α-羧基上的羟基，和后一个氨基酸 α-氨基上的一个氢，两者脱水缩合，脱掉一分子水。

```text
第一个氨基酸：α-羧基提供 —OH
第二个氨基酸：α-氨基提供一个 —H
        ↓  脱水缩合（脱去一分子水）
生成的连接：—CO—NH—     这个 C—N 键就是肽键
```

水脱掉之后，前一个氨基酸的羧基碳直接连到后一个氨基酸的氨基氮上。这个碳氮键就是肽键，它本质上是一个酰胺键——前面讲 α-氨基与酰氯反应生成的酰胺，用的是同一个结构。

肽键的形成过程必须掌握：谁提供羟基、谁提供氢、脱水之后哪两个原子连在一起，这三件事都要能自己写出来。

#### 茚三酮反应：蓝紫色化合物

氨基酸还能和茚三酮试剂反应，生成蓝紫色的化合物。

这个反应的完整过程相当复杂，机理不要求掌握。要求掌握的是两件事：氨基酸与茚三酮反应生成蓝紫色化合物；这个现象可以用来检测、鉴定氨基酸。

它的灵敏度高到什么程度？有个很典型的场景。一部美剧里有这样的情节：博物馆里的东西反复失窃，那些东西都罩在玻璃罩里，罩子每次都是完好的，东西却不见了，于是怀疑是内部工作人员干的。他们就在玻璃罩上喷了茚三酮试剂，当天晚上东西果然又丢了；第二天去看工作人员的手——谁的手上是蓝紫色的，谁头一天晚上就碰过这个罩子。手上本来就带着氨基酸，一沾试剂就显色，人就被认出来了。

> **注意**：茚三酮反应只要求"现象 + 用途"这两条：遇氨基酸显蓝紫色、可用于检测。机理不在要求范围内，不必在这里纠缠反应步骤。

### 侧链基团的反应与化学修饰

侧链基团的反应特别多、也特别杂，这一块了解就可以。但在看具体反应之前，有个概念要先立住：化学修饰。

> **定义**：化学修饰是指在较温和的条件下——注意不是极端条件——以可控制的方式，使蛋白质与某种试剂发生特异性的反应，从而引起蛋白质中个别氨基酸残基的官能团发生共价化学变化的过程。

这里的"特异性"是关键，说的是一对一：某一种试剂只认某一种氨基酸残基的官能团。反应之后往往伴随可观察的现象，最典型的就是颜色改变。于是这些试剂就成了探针——拿它去处理蛋白质，看有没有对应的现象，就知道蛋白质里有没有那种氨基酸。

两个常被提到的例子都与酪氨酸有关。酪氨酸的侧链是一个苯环，苯环上带一个酚羟基，这个酚羟基就是它参与反应的位点。

米隆反应：酪氨酸与亚硝酸汞及硝酸的混合液反应，生成红色的沉淀。

Pauly 反应：酪氨酸的酚基与重氮化合物结合，生成橘黄色的化合物。

两个反应针对的是同一个氨基酸，颜色却不一样，这在小题里正好拿来互相干扰。

复习材料上列出的侧链反应远不止这两个，因为那是把好多种生物化学教材里的相关反应都罗列在了一起。要不要全背？建议是这样：先去看报考学校给出的参考书目，书目上出现了哪几个反应，就把那几个重点看一遍。这部分内容通常考小题，按书目取舍最划算。

> **提示**：侧链反应多而杂，不要平均用力。先翻参考书目划范围，再在范围内记颜色和对应的氨基酸，比从头背到尾效率高得多。

### 本讲提到的题目

课上前后留了两次考点小测，都只说了"把答案打在公屏里，一起交流"，没有展开题目内容。

另外还出现过一道组氨酸的选择题：题干给的是一张组氨酸兼性离子的结构式，问若向氨基酸溶液中逐步加碱，这个兼性离子首先转变成下面哪一种状态？选项是三张结构式。

解析：加碱意味着溶液里的氢氧根变多、pH 升高，也就是从等电点往碱侧走。按前面的判断，$\text{pH} > \text{pI}$ 时氨基酸带负电。兼性离子要变成带负电的形态，只能交出它身上还留着的那个质子：羧基早已是羧酸根，没有质子可交；剩下的只有 α-氨基上的质子。交出之后，分子从净电荷 0 变成净电荷 −1。

答案：应选"α-氨基失去质子、羧基仍带负电"的那张结构式，即净电荷为 −1 的状态。

### 必须拿下的几条

亮蓝色标出的都是要求掌握的内容，每次小结都会集中到这几条上。

- 中性氨基酸占二十种里的十五种，等电点取 $\text{pI} = \frac{\text{pK}_1 + \text{pK}_2}{2}$，也就是两个 pK 的平均值。
- 酸性氨基酸（谷氨酸、天冬氨酸）有三个 pK，取两个较小的求平均。
- 碱性氨基酸（赖氨酸、精氨酸、组氨酸）有三个 pK，取两个较大的求平均。
- $\text{pH} = \text{pI}$ 时不带电；$\text{pH} > \text{pI}$ 时带负电；$\text{pH} < \text{pI}$ 时带正电。记成一句：酸正碱负。
- 桑格法用二硝基氟苯（FDNB、DNFB、FNDB 三种缩写），标记 N 端后酸水解，检出 DNP-氨基酸。
- Edman 法用苯异硫氰酸酯（PITC），环化切下 N 端残基，经 ATZ 转成 PTH-氨基酸检测，可逐轮读出序列。
- 成肽反应由前一个氨基酸的 α-羧基与后一个氨基酸的 α-氨基脱水缩合，生成肽键，肽键本质是酰胺键。
- 茚三酮与氨基酸反应生成蓝紫色化合物，可用于检测氨基酸。

一条线索收尾：酸碱性质回答的是"这个分子在某个 pH 下带什么电"，化学反应回答的是"我们能用什么手段把它认出来、连起来"。前者决定它在电场里往哪走、在什么 pH 下沉淀，后者决定它怎么被测定、怎么被串成肽链——两件事合起来，才是这个分子在生化里的完整面貌。

> **承前启后**：上一节讲完「氨基酸的酸碱性质与化学反应」，下一节接着讲「氨基酸的旋光性、紫外吸收与分离分析」。

## 氨基酸的旋光性、紫外吸收与分离分析
> 对应块：BLK04 | 覆盖分集：P11-P15 | 块标题（分集名）：《接接接接福气》

把手伸出来。

掌心贴着掌心，左手和右手严丝合缝，你会觉得这两只手是一回事。可要是换一种对法——一只手的掌心去对另一只手的手背——你会发现，不管怎么转、怎么摆，它们都重合不了。它们长得一模一样，却永远贴不到一起；一只就是另一只照镜子照出来的影子。

这一讲，我们就从这双手开始。前面已经把氨基酸的分类、等电点这些底子铺完了，今天接着往下走，讲两个考点：氨基酸的旋光性和光谱性质，以及氨基酸的分离分析。前一个考点里，有些内容只要了解，但有几句话是必须背下来的；后一个考点里的两个原理，是明确要求掌握的。

### 从左右手讲起：什么是旋光活性

先说旋光活性。

一束偏振光通过某物质的溶液，它原本的振动平面发生了旋转——这种物质就叫旋光活性物质，这种性质就叫旋光活性。

至于偏振光究竟是一种什么样的光、能量怎么分布，不用深究。你只要知道它是一束光，穿过溶液之后，振动平面被“拧”了一下，就足够了。我们不需要会画偏振，只需要会用这个结论。

旋转有方向。让振动平面朝顺时针方向转的，叫右旋；朝逆时针方向转的，叫左旋。所以旋光活性只有两类：左旋和右旋。

> **定义**：偏振光通过物质溶液后，振动平面发生旋转，该物质即为旋光活性物质；使振动平面顺时针旋转的为右旋物质，逆时针旋转的为左旋物质。

再说手性分子。手性分子，就是不能与自己的镜像完全重叠的分子。

“完全重叠”这四个字是关键。左右手能不能重合？手心对手心当然能贴住，但那不是镜像关系下的重合。真正的检验是这样：一只手摆好，另一只按镜像摆——一只掌心朝前，另一只就得掌心朝后。这时候你再去对，怎么都对不上。左手是右手的镜像，右手也是左手的镜像。

把右手对着镜子，镜子里那只“右手”的影子，正是你的左手。

> **结论**：凡是具有手性的分子，都具有旋光活性。手性和旋光性，在氨基酸这一章里是绑在一起出现的一对概念。

### 手性碳与 L 型氨基酸

分子为什么会有手性？落到有机分子上，最常见的来源是一个碳原子。

碳能连四个基团。如果一个碳原子所连的四个基团彼此都不相同——比如分别是 A、B、C、D——这个碳就叫手性碳原子，也叫不对称碳。它所在的分子就具有旋光活性，表现出来要么左旋，要么右旋。

这些概念写出来一大串，但真正要拿走的只有一条：**碳原子所连的四个基团全不相同，它就有手性，就有旋光活性。**

#### α-碳：四个基团定手性

现在把这条结论套到氨基酸上。

氨基酸的结构通式里，羧基、氨基、氢原子和 R 侧链都挂在同一个碳上，这个碳就是 α-碳。20 种蛋白质氨基酸彼此之间的差别只在 R 侧链，所以判断它们有没有手性，只需要看一件事：R 基团和羧基、氨基、氢这三个是不是都不一样。

只要不一样，α-碳所连的四个基团就全不相同，它就是手性碳，这个氨基酸就有旋光性。

二十种里只有一个例外：甘氨酸。它的 R 基团就是一个氢，和 α-碳上那个氢完全相同，四个位置占了两个氢，手性碳的前提就不成立了。

> **结论**：组成蛋白质的 20 种氨基酸中，甘氨酸没有手性碳，也没有旋光性；其余 19 种都是 L-型 α-氨基酸，都具有旋光性。

> **易错点**：L/D 是构型标记，左旋/右旋是旋光方向，这是两套不同的体系，不能划等号。构型讲的是 α-碳上四个基团的空间排布与参照物的对应关系，旋光方向只能靠旋光仪实测。所以“是 L-型”推不出“一定左旋”，反过来也一样。

#### 苏氨酸：侧链上还有一个手性碳

还有一类情况要单独说。

苏氨酸的 α-碳当然有手性——它连的羧基、氨基、氢和侧链四个基团各不相同。但它的侧链上还有一个碳：这个碳连着一个氢、一个羟基、一个甲基，以及 α-碳那一头。四个基团同样各不相同。

| 手性中心 | 所连的四个基团 |
| :--- | :--- |
| α-碳 | —COO⁻、—NH₃⁺、—H、—CH(OH)CH₃ |
| β-碳 | —OH、—CH₃、—H、—CH(NH₃⁺)COO⁻ |

所以对苏氨酸来说，它有两个手性碳原子。每一个手性碳都有 L 型和 D 型之分，两种构型一组合，整个分子就有四种立体异构体：L-苏氨酸、D-苏氨酸，以及 L-别苏氨酸、D-别苏氨酸。

这四种之间的差别落在哪里，值得分清：

- L 与 D 的差别在 α-碳上，氢和氨基的位置对调，两者互为镜像；
- 苏氨酸与别苏氨酸的差别在 β-碳上，羟基和氢的位置对调。

> **提示**：“别”（allo）这个字，说的就是第二个手性中心翻了面。看到“别苏氨酸”不要当成另一种氨基酸，它还是苏氨酸，只是 β-碳的构型换了一种。

这一条了解即可——知道苏氨酸有两个手性碳、因此有四种立体异构体，就够了。

### 光谱：从 X 射线到红外

构型说完，换个角度：氨基酸怎么和光打交道。

“光谱”听着抽象，其实就是把不同波长的光按长短排成一排。波长最短的一头是 X 射线，往上是紫外线，再往上是可见光，再往长波方向走是红外。

> **提示**：紫外大约在 100~400 nm（严格说可见光从 380 nm 起），可见光大约 380~780 nm，比 780 nm 更长的就是红外。这几个数字记个大概，不用抠边界。

| 波段 | 大致波长 | 特点 |
| :--- | :--- | :--- |
| X 射线 | 比紫外更短 | 能量更高，也能被物质吸收 |
| 紫外 | 100~400 nm | 肉眼看不见，共轭双键在这里有特征吸收 |
| 可见光 | 380~780 nm | 物质吸收可见光，我们才看得到颜色 |
| 红外 | 长于 780 nm | 肉眼看不见 |

所有物质都会吸收一定的光。吸收可见光的，我们看得见它的颜色；吸收紫外或红外的，肉眼就看不出来；还有的会吸收波长更短的 X 射线。

我之前请教过一位前辈：有没有哪种物质，对光一点吸收都没有？他想了想说，那大概就是宇宙里的暗物质了。

所以，我们身边能接触到的物质，在光谱里总能找到它吸收的那一段，差别只在于吸收的范围和波长不同。

### 共轭双键：紫外吸收从哪来

有机物里对紫外光有特征吸收的结构，是共轭双键——有的书上写“共轭 π 键”。

什么叫共轭双键？一个碳碳双键，隔着一个碳碳单键，再接一个碳碳双键。中间那个单键把两个双键串起来，这样一组结构就是共轭双键。

> **定义**：两个碳碳双键被一个碳碳单键隔开、彼此共轭的结构，称共轭双键；它对紫外光有特征性的吸收。

20 种蛋白质氨基酸里，带共轭双键的只有三个：苯丙氨酸、酪氨酸、色氨酸。它们的侧链里都有环，环上的双键两两之间被单键隔开，正好构成共轭体系，所以这三种氨基酸都能吸收紫外。

把它们的溶液放进仪器，在 200~320 nm 之间扫一遍：从 200 nm 起步，一点点加长波长，同时记录吸收值，就得到三条吸收曲线。

```text
吸收值
  ▲
  │                                  ●  Tyr / Trp
  │                                  │  280 nm，峰高
  │        ●  Phe                    │
  │        │  260 nm，峰矮            │
  └────────┴─────────────────────────┴──────────▶ 波长增大
```

横轴是波长，纵轴是吸收值。苯丙氨酸在 260 nm 附近出一个峰，峰比较矮；酪氨酸和色氨酸在 280 nm 附近出峰，峰高得多。

> **注意**：几座峰不是等高的。酪氨酸和色氨酸的吸收值明显高于苯丙氨酸，正因为高得多，蛋白质在 280 nm 处的吸收才主要由这两个氨基酸贡献。

### 280 nm：一个必须记住的数字

大多数蛋白质都含有酪氨酸和色氨酸，所以蛋白质溶液在 280 nm 处有最大吸收；而且这两种氨基酸的浓度越高，吸光值越大。

> **结论**：蛋白质在 280 nm 处的吸光度与其浓度成正比，可以用来做蛋白质的定量分析。

举个最直观的用法。手边有两杯溶液，已经知道它们是同一种蛋白质的溶液，但不知道哪杯更浓。分别测一下 280 nm 的吸光值，吸光值大的那杯，浓度就更高。

> **易错点**：280 是蛋白质的，260 是核酸的。这两个数字考试里经常放在一起让你区分，记串了整道题就废了。

还有一句了解性的：核磁共振（NMR）在氨基酸和蛋白质的化学表征里起重要作用。医院里那台核磁共振，用的是同一套原理，只是照的对象不同。这个点一颗星，知道有这回事就行。

### 层析：让混合物在两相之间赛跑

第二个考点是分离分析。手段有两个：层析和电泳。

层析的定义有点绕口：根据混合物中各组分在互不相溶的两相之间分配行为的差别，引起移动速度的不同，从而把各组分分开的方法。这两相，一个叫固定相，一个叫流动相。

拆开看就三件事：有两相、各组分在两相里的分配不一样、分配不一样导致跑得快慢不一样。抓住这三件事，定义不用死背也能自己推出来。

名字有来历。1903 年，俄国的植物学家用这个方法分离植物色素，色素被分成一条一条不同颜色的带，所以又叫色谱。

> **提示**：层析、色谱、层析法，在教材和题目里混着用，指的都是同一类方法，不要被不同的叫法绕进去。

按固定相和流动相的性质不同，层析可以分成很多种。这里只抓两类：分配层析和离子交换层析。这两个的原理是要求掌握的。

### 分配层析：纸、柱、薄层，三种载体一套原理

分配层析按所用的实验设备或介质不同，又分成纸层析、柱层析和薄层层析。

名字其实已经把装置说清楚了：纸层析在纸上做，柱层析在柱子里做，薄层层析在一块薄板上做。三种做法原理完全一样——让各组分在固定相和流动相之间反复分配，谁更愿意跟着流动相走，谁就跑得远。

```text
样品点在起点
      │
      ▼
流动相流过（上行或下行），经过样品
      │
      ▼
各组分在固定相与流动相之间反复分配
      │
      ├── 更“亲”流动相 ──▶ 随流动相走得远
      └── 更“亲”固定相 ──▶ 留在起点附近
      │
      ▼
显色后得到一条条分开的色带
```

三件事：上样、让流动相走、按分配结果分开。纸、柱、薄层，换的只是载体和流动相走的方向。

#### 纸层析：一条滤纸上的赛跑

纸层析的装置，可以想成一支大试管：底部盛着展开剂，展开剂就是流动相；中间竖一条滤纸条，滤纸是惰性支持物，一般不跟样品发生反应；顶上用橡胶塞塞住；样品溶液点在滤纸条的下端。

橡胶塞不是摆设。展开剂通常是有机物配的溶液，很容易挥发，不塞住，液面会跑、比例也会变。

```text
    +--------------------------+
    |         橡 胶 塞          |      密封，防止展开剂挥发
    +--------------------------+
               |
          [ 滤 纸 条 ]              惰性支持物
               |
            ( ● )                  样品点，必须高出液面
               |
    ~~~~~~~ 展 开 剂 ~~~~~~~        流动相
               |
           虹吸上行
```

点样有一条硬规矩：样品点不能浸到展开剂里，必须离液面有一段距离。浸进去，样品就直接溶进展开剂，后面什么都没得看。

展开剂沿着滤纸往上爬（虹吸），爬的路上会经过样品点。样品里假设有 A、B、C、D、E 五种氨基酸：展开剂对谁的溶解性更强，谁就更愿意跟着它走、被带得更远；对谁溶解性弱，谁就几乎留在原地。

```text
    展开剂前沿 ────────────────────────────

                      ● A        跑得最远（在展开剂中溶解度最大）
                ● B
          ● C
      ● D
   ● E                          几乎没动（在展开剂中溶解度最小）

    点样原点 ────────────────────────────
```

最后在纸上得到 A、B、C、D、E 五条分开的带，混合物就分开了。

> **结论**：纸层析能分开，靠的是各组分在固定相（滤纸上吸附的水相）与流动相（展开剂）之间分配行为的差别；在流动相中溶解度大的组分迁移得快、走得远。

#### 柱层析与薄层层析：换个载体，原理不变

柱层析换了个方向。一根玻璃柱，里面先填好固相；样品从柱顶加进去，只占最上面薄薄一层；然后洗脱剂从上面往下滴，穿过样品往下走。

跟纸层析完全是一个道理：样品里的组分在洗脱剂里溶解度大的，被带得远、走得快；溶解度小的跑得慢。走一段，先后就拉开了。

薄层层析则是把固相涂在一块板上——一般是玻璃板，现在也有塑料板——点样，然后用展开剂上行展开。点样的方法和纸层析一样。

| 类型 | 载体 | 流动相 | 与另外两种的差别 |
| :--- | :--- | :--- | :--- |
| 纸层析 | 滤纸条（惰性支持物） | 展开剂，靠虹吸上行 | 最经典，固定相是纸上吸附的水相 |
| 柱层析 | 玻璃柱内填充的固相 | 洗脱剂，从上往下流 | 上样在柱顶，洗脱方向向下 |
| 薄层层析 | 玻璃板或塑料板上涂的薄层 | 展开剂，上行展开 | 点样方式与纸层析相同，载体换成薄板 |

### 离子交换层析：先把电荷算清楚

离子交换层析长得跟柱层析很像，区别在填充物：填的是离子交换树脂。

树脂分两类，阳离子交换树脂和阴离子交换树脂。这两个名字最容易记反，记住一条就不会错：叫“阳离子交换”，指的是它交换的对象是阳离子——树脂自己解离出阳离子，骨架就带上了负电。

#### 阳离子交换树脂：酸性氨基酸先下来

阳离子交换树脂本身能解离出 H⁺ 或 Na⁺。解离出去的既然是阳离子，树脂骨架就带上负电，于是它吸引的是带正电的离子或分子。

用它分离氨基酸，上样在 pH 2~3。为什么非要这个酸度？因为在这个 pH 下，三类氨基酸的带电状态正好被拉开：

- 中性氨基酸：环境 pH 低于它的等电点，羧基不带电、α-氨基带上质子，净带 1 个正电；
- 酸性氨基酸：等电点就在 3 左右，pH 2~3 差不多正好落在它的等电点上，净电荷接近 0；
- 碱性氨基酸：等电点大于 7，pH 2~3 远低于等电点，α-氨基和侧链上的碱性基团全都带上质子，净带 2 个正电，羧基不带电。

| 氨基酸类型 | 等电点 | pH 2~3 时的净电荷 | 与阳离子交换树脂的亲和力 |
| :--- | :--- | :--- | :--- |
| 酸性 | 约 3 | 0 | 最弱，几乎不结合 |
| 中性 | 中性附近 | +1 | 中等 |
| 碱性 | 大于 7 | +2 | 最强 |

三种氨基酸就这样按亲和力挂在柱子上：碱性最牢，中性次之，酸性几乎挂不住。

接着洗脱。先用 pH 3 左右的液体洗，同时往洗脱剂里加氢氧根，把 pH 一点点往上抬。

- pH 3：酸性氨基酸结合最弱，先被洗下来；
- pH 升到 6~7 左右：中性氨基酸到达自己的等电点，净电荷变成 0，不再被树脂吸住，跟着下来；
- pH 继续升到 8~10、再往上：碱性氨基酸也到了不带电的状态，最后被洗下来。

```text
阳离子交换树脂（骨架带负电）

上样 pH 2~3
   │
   ├── 酸性氨基酸  0    ──▶ 结合最弱
   ├── 中性氨基酸 +1    ──▶ 结合中等
   └── 碱性氨基酸 +2    ──▶ 结合最强
   │
   ▼
洗脱：pH 3  ──▶  pH 6~7  ──▶  pH 8~10 以上
   │
   ▼
出柱顺序：酸性  ──▶  中性  ──▶  碱性
```

> **结论**：阳离子交换层析分离氨基酸，上样在酸性条件（pH 2~3），靠不断加碱抬高 pH 洗脱，出柱顺序是酸性 → 中性 → 碱性。

> **易错点**：上样时 pH 低，是为了让氨基酸带正电、挂得上带负电的树脂；洗脱时 pH 升高，是为了让它们逐步失去正电、脱附下来。上样和洗脱是两个相反的方向，别记成同一个。

#### 阴离子交换树脂：顺序刚好倒过来

阴离子交换树脂解离出的是阴离子，比如 OH⁻ 或 Cl⁻。解离掉阴离子，骨架就带上正电，于是它吸的是带负电的分子。

这一次上样放在碱性条件下。三类氨基酸的电荷翻了个面：

- 碱性氨基酸：环境 pH 接近它的等电点，净电荷 0，不被吸；
- 中性氨基酸：环境 pH 高于它的等电点，净带 1 个负电，被吸住；
- 酸性氨基酸：环境 pH 远高于它的等电点，羧基全部解离，至少带 2 个负电，吸得最牢。

洗脱从碱开始，然后逐渐降低 pH。于是不带电的碱性氨基酸先出来，中性氨基酸第二，酸性氨基酸最后。

> **结论**：阴离子交换层析的出柱顺序与阳离子交换层析刚好相反：碱性 → 中性 → 酸性。

| 比较项 | 阳离子交换树脂 | 阴离子交换树脂 |
| :--- | :--- | :--- |
| 树脂解离出的离子 | H⁺、Na⁺ | OH⁻、Cl⁻ |
| 树脂骨架所带电荷 | 负 | 正 |
| 吸附的对象 | 带正电的组分 | 带负电的组分 |
| 上样条件 | pH 2~3（酸性） | 碱性 |
| 洗脱时 pH 的变化 | 由 3 逐渐升高 | 由碱性逐渐降低 |
| 出柱顺序 | 酸性 → 中性 → 碱性 | 碱性 → 中性 → 酸性 |

### 电泳：带电粒子在电场里游泳

电泳这个词很形象：带电的粒子在电场里“游动”，像游泳一样移动。带电粒子在电场中向与其电性相反的电极移动，这个现象就叫电泳。用它来分离、纯化、鉴定物质。

电泳在生物化学与分子生物学里用得极多，往后读研做科研，跑电泳基本是家常便饭。生化里用电泳，更多是用来分离蛋白质样品。不同的蛋白质在电场里跑得快慢不同，快慢由三个因素决定。

#### 带电量：正比

带的电越多，受到的电场力越大，跑得越快。这是正比关系。

举个具体的例子。四种蛋白质 A、B、C、D，等电点依次升高，$pI_A < pI_B < pI_C < pI_D$。把环境 pH 调到低于这四个等电点，四种蛋白质就都带上正电。

谁带的正电最多？看环境 pH 离各自的等电点有多远——离得越远，净电荷越多。现在环境 pH 卡在 pI_A 左边最近的地方，离 pI_D 最远，所以 D 带的正电最多，A 最少。于是 D 跑得最快。

```text
环境 pH 低于全部四个 pI，四种蛋白质都带正电

pH 升高 ──────────────────────────────────▶
          ▲         ▲         ▲         ▲
        pI_A      pI_B      pI_C      pI_D
          │                             │
      离环境 pH 最近               离环境 pH 最远
      正电荷最少                   正电荷最多
      跑得最慢                     跑得最快
```

#### 分子量与形状：越小越快、越圆越快

分子量：带电量相同时，分子越大，在介质里受到的阻力越大，跑得越慢。电泳速率与分子量成反比。

形状：蛋白质从形状上大致分两类，球状的和纤维状的。带电量相同、分子量也相同时，越接近球形的跑得越快——球形在介质里运动阻力最小；纤维状的长条拖着走，阻力大得多。

> **结论**：影响电泳速率的三个因素——带电量（正比）、分子量（反比）、分子形状（越接近球形越快）。

#### 图上的条带是怎么来的

最常见的例子是醋酸纤维素薄膜电泳分离血清蛋白。薄膜就是一块膜，样品点在起始位置，让蛋白质都带上负电，它们就从负极往正极跑；跑完之后在膜上分成几条带，血清蛋白就被分开了。

```text
(－) 负极 ────────────────────────────────────▶ (＋) 正极
      点样处      ①       ②        ③       ④
                跑得慢 ─────────────────▶ 跑得快
```

另一类常见的是 DNA 电泳图。最左边那一条是 Marker，相当于买回来的一把尺子，用已知大小的条带做参照；后面那些亮条带是样品跑出来的结果，比对位置就知道大小。

## 肽与蛋白质：从肽键、肽平面到四级结构
> 对应块：BLK05 | 覆盖分集：P16-P19 | 块标题（分集名）：《[专题02] 考点07：肽》

氨基酸讲完了，接下来要把它们串起来。串的方式说起来只有一句话：一个氨基酸的 α-羧基交出羟基，下一个氨基酸的 α-氨基交出一个氢，两者之间留下一个键。这个键叫肽键，连成的链叫肽。

这一讲就把这根链从第一个键开始拆开讲：键长为什么特殊、六个原子为什么必须共面、链为什么有方向，以及一条链怎么一路折叠出四级结构。肽和肽键这部分要重点掌握；后面的蛋白质组成、分类和结构层次，是把视野从一根链放大到整个蛋白质分子。

### 肽键：一次脱水，留下一个酰胺键

> **定义**：肽是氨基酸之间通过 α-氨基和 α-羧基以肽键相连形成的聚合物。

先看肽键本身。肽键是一个酰胺键。羧基去掉羟基，剩下的酰基再连上氨基，形成的 $\mathrm{-CO-NH-}$ 就是酰胺键；肽键正是酰胺键的一种。反过来说，酰胺键不一定是肽键——只有氨基酸的 α-羧基和 α-氨基之间形成的那个酰胺键，才叫肽键。

> **易错点**：肽键一定是酰胺键，酰胺键不一定是肽键。

肽键是怎么形成的？拿最简单的甘氨酸来看。每个氨基酸都有一个 α-氨基和一个 α-羧基。两个甘氨酸靠近时，第一个甘氨酸的 α-羧基和第二个甘氨酸的 α-氨基发生缩合：第一个交出羧基上的羟基，第二个交出氨基上的一个氢，合起来正好是一分子水。

```text
  H2N-CH2-COOH   +   H2N-CH2-COOH
        |                  |
        |                  +--- 脱 H
        +---------------------- 脱 OH
                   |
                   v   -H2O
  H2N-CH2-CO-NH-CH2-COOH
             |
          肽键
```

上面这条式子里，左边是第一个甘氨酸，右边是第二个甘氨酸；中间新形成的 C-N 键就是肽键。两个甘氨酸连起来以后，产物叫甘氨酰甘氨酸——名字里的“甘氨酰”来自第一个氨基酸，“甘氨酸”来自第二个氨基酸。

这里的关键位置要看清楚：第一个氨基酸的羧基碳和第二个氨基酸的氨基氮之间连起来了，肽键就长在这两个原子之间。肽键两侧各挂着一个 α-碳，分别属于第一个和第二个氨基酸。

> **提示**：写肽链时，习惯把第一个氨基酸的 α-碳画在左边、第二个的 α-碳画在右边，这样一眼就能看出肽键连接的是“前一个的羧基碳”和“后一个的氨基氮”。

### 肽平面：六个原子锁在一个面上

肽键不只是“一根普通的单键”。研究发现，肽键的键长介于 C-N 单键和 C=N 双键之间，具有部分双键的性质。

为什么会这样？羰基的 π 电子与氨基氮上的孤对电子发生共轭，电子不再只属于某一个键，C-N 键就带上了一部分双键的性格。双键的特点是不能自由旋转。

单键可以自由旋转。你们可以想象左手和右手各是一个碳原子，中间拿一根铅笔连着——你可以随便转，铅笔不会限制你。双键就不一样了：两只手各拿一支笔，把两支笔平行放好，再想让它们转起来就转不动了，无论怎么使劲，两支笔始终待在一个平面上。这就是单键和双键最直观的区别。

肽键既然有部分双键性质，C-N 键就不能自由旋转。这一不能转，牵出了一连串后果：羰基碳上还连着一个氧，氮上还连着一个氢，羰基碳前面是第一个氨基酸的 α-碳，氮后面是第二个氨基酸的 α-碳——这六个原子被肽键及其两端的连接固定住，只能共处一个平面。

```text
            O
            ||
   Ca1 ---- C ---- N ---- Ca2
             \      /
              \    /
                H
```

图里的 Ca1、Ca2 就是两个 α-碳。这六个原子是：第一个氨基酸的 α-碳、肽键的羰基碳、羰基氧、氨基氮、氨基氮上的氢、第二个氨基酸的 α-碳。它们组成的平面叫肽平面，也叫肽单元，或者酰胺平面——因为肽键本来就是一个酰胺键。

> **定义**：肽平面（肽单元、酰胺平面）是由参与肽键形成的六个原子共同构成的平面，这六个原子是 Ca1、C、O、N、H、Ca2。

一条肽链上有很多个肽键，也就有很多个肽平面。相邻两个肽平面并不是各转各的，它们通过一个共用的原子连在一起——这个共用点就是 α-碳。

```text
  Ca1 ---- C ---- N ---- Ca2 ---- C ---- N ---- Ca3
  |<------ 肽平面 1 ------>|<------ 肽平面 2 ------>|
                          共用 Ca2
```

两个肽平面以共用的 α-碳为轴，可以形成不同的夹角，也就是二面角。肽链的空间构象丰富不丰富，很大程度上就取决于这些二面角怎么转。这里是后面整个蛋白质空间结构的地基：肽键本身是刚性的，能动的只有 α-碳两侧的键，所以一条肽链的柔性来自“平面之间的夹角”，而不是“肽键自己扭来扭去”。

> **结论**：肽键不能自由旋转，六个原子共处一个肽平面；相邻肽平面通过共用的 α-碳相连，靠二面角改变相对取向，为肽链折叠成蛋白质空间结构提供了基础。

### 肽链的方向：N 端与 C 端

两个氨基酸缩合叫二肽，三个叫三肽，四个叫四肽，一路可以叫到十肽。由 2 到 20 个氨基酸连成的肽，通常叫寡肽；大于 20 个的，叫多肽。

这个界线不是死的。我做阿尔茨海默病方向的时候，常遇到一个由 42 个氨基酸组成的有毒多肽，很多人就直接叫它 42 肽——按“大于 20 就是多肽”的规矩，它当然算多肽，但叫“42 肽”更省事，也更常见。

肽链里的氨基酸，已经不是原来那个完整的氨基酸了。第一个氨基酸交出羧基上的羟基，第二个氨基酸交出氨基上的氢，缩合以后，每个氨基酸都少了一点东西。所以肽链中的氨基酸单位叫氨基酸残基。

具体看两端：

- 第一个氨基酸保留了完整的 α-氨基，它的 α-羧基已经参与成键；
- 最后一个氨基酸保留了完整的 α-羧基，它的 α-氨基已经参与成键；
- 中间所有氨基酸的 α-氨基和 α-羧基都参与了成键，两个基团都不完整。

因此，整条肽链上只有一个完整的 α-氨基、一个完整的 α-羧基。带完整 α-氨基的那一头叫氨基端，也就是 N 端；带完整 α-羧基的那一头叫羧基端，也就是 C 端。

```text
  H2N-残基-残基-...-残基-COOH
   ^                    ^
   N 端                 C 端
```

肽链是有方向的，默认方向是 N 端到 C 端。为什么默认这个方向？因为生物体合成多肽链时，就是从 N 端往 C 端合成的。合成方向和书写方向一致，读序列、比序列、写序列才不会乱。

> **注意**：说“肽链的方向”时，默认就是 N→C。写序列时如果从 C 端往 N 端写，一定要标清楚，否则同一段序列会被读反。

### 双缩脲反应：用颜色数肽键

肽的化学性质里，最常考的是双缩脲反应。

> **定义**：双缩脲反应是蛋白质或多肽中的肽键在稀碱溶液中与硫酸铜共热，产生颜色反应的现象。

这个反应有两个前提：第一，检测的是肽键；第二，肽键数目必须大于等于两个。满足这两个条件，才会出现颜色。

颜色不是单一的一种，而是随着肽键数目变化：肽键最少时呈粉红色，肽键增多依次变成紫红色、紫色，肽键最多时呈蓝色。从感官上看，就是颜色越来越深。

这个颜色梯度正好可以用来检测蛋白质的水解程度。拿一杯蛋白质溶液，加入能水解蛋白质的酶，在不同时间点各取一点出来做双缩脲反应：刚开始蛋白质完整、肽键多，颜色是蓝色或紫色，比较深；随着水解进行，肽键被一个个破坏，肽链越来越短，颜色越来越浅；水解到最后，蛋白质变成氨基酸，肽键没了，颜色也就没了，最多只剩一点粉红。

那它能不能检测氨基酸？不能。原因很简单：它认的是肽键，氨基酸没有肽键。

> **易错点**：双缩脲反应不能检测氨基酸，也不能检测二肽。氨基酸没有肽键；二肽只有一个肽键，达不到“大于等于两个”的门槛。

所以这个反应的本质不是“认蛋白质”这三个字，而是“认肽键”。多肽可以把它看成一个小蛋白，蛋白质可以看成一条复杂的大多肽，只要肽键够数，都能反应。

### 谷胱甘肽：一个三肽怎么抗氧化

天然活性肽里，最重要的是谷胱甘肽，书上打了三颗星。

> **定义**：谷胱甘肽是由谷氨酸、半胱氨酸和甘氨酸三种氨基酸组成的三肽。

生物体里的蛋白质大多是大分子，由很多氨基酸组成，结构复杂、功能多样。但也有例外：谷胱甘肽只有三个氨基酸，结构简单得不能再简单，却有人体内非常重要的抗氧化活性。

它的抗氧化本领来自中间那个半胱氨酸上的巯基（-SH）。在 20 种蛋白质氨基酸的侧链基团里，半胱氨酸的巯基是最容易失去氢的一个。谷胱甘肽常简写成 G-SH，后面的 SH 就是巯基；还原型也常写作 GSH。

两个还原型谷胱甘肽碰到一起，可以各自脱掉巯基上的一个氢，把两个硫原子连起来，形成二硫键。连起来以后，两个谷胱甘肽就“缩合”成了一个整体，这就是氧化型谷胱甘肽。

```text
  2 G-SH  --(-2H)-->  G-S-S-G
   还原型              氧化型
   带氢、有活性        脱氢、失去活性
```

带氢的、也就是加氢还原的状态，叫还原型谷胱甘肽；脱掉氢的、也就是氧化后的状态，叫氧化型谷胱甘肽，常写作 GSSG。整个生物体里真正具有抗氧化活性的是还原型。

为什么还原型才有活性？拿双氧水举例。双氧水是细胞代谢过程中不可避免会产生的东西，氧化性太强，留在细胞里会造成氧化损伤——我们在实验中做简单的氧化损伤模型，有时就是直接加双氧水。细胞必须把它处理掉，最好处理成无毒的水。

谷胱甘肽过氧化物酶正好干这件事：

$$ \mathrm{H_2O_2 + 2\,GSH \rightarrow 2\,H_2O + GSSG} $$

一分子双氧水变成两分子水，多了两个氢。这两个氢从哪来？两个还原型谷胱甘肽各提供一个巯基上的氢，自己变成氧化型谷胱甘肽。氧化型谷胱甘肽没有抗氧化活性了，但细胞还有办法把它救回来：谷胱甘肽还原酶用 NADPH 供氢，把氧化型还原成还原型。

$$ \mathrm{GSSG + NADPH + H^+ \rightarrow 2\,GSH + NADP^+} $$

NADPH 给出两个氢，自己变成 NADP⁺；谷胱甘肽恢复还原型，重新具备抗氧化能力。这一对反应构成了一个循环：还原型谷胱甘肽消耗自己，把过氧化物还原成水；谷胱甘肽还原酶再把它拉回还原型。

谷胱甘肽在细胞里有三个重要作用。

第一，保护含巯基的蛋白质或酶。过氧化物要损伤巯基时，谷胱甘肽会把自己的巯基供出去，替那些蛋白质和酶挡一刀。可以把它想象成冲在最前面的那个：你们不是要损伤巯基吗？来损伤我的。

第二，保护红细胞膜结构的完整性。红细胞膜很容易受到氧化物质的损伤，比如蚕豆里就有能对红细胞造成氧化损伤的物质。谷胱甘肽能对抗这种损伤。如果一个人体内的谷胱甘肽活性偏低，吃了蚕豆以后红细胞就容易破裂，造成溶血性黄疸——这就是蚕豆病。

第三，保持血红蛋白里的铁离子处于二价状态。只有二价铁才能携带氧气、运输氧气；铁一旦被氧化成三价，血红蛋白的运氧功能就出问题。

把这三件事串起来看，还能理解蚕豆病的最终机制：谷胱甘肽要恢复活性，需要 NADPH 供氢；如果代谢过程中缺乏 NADPH，谷胱甘肽就供不上，红细胞膜失去保护，最终破损。所以蚕豆病不只是“吃了蚕豆”这么简单，背后是 NADPH 供氢、谷胱甘肽抗氧化这条链断了。

> **提示**：谷胱甘肽的还原型和氧化型是一对氧化还原搭档，记反应时抓住“谁供氢、谁失氢”：谷胱甘肽过氧化物酶让 GSH 失氢，谷胱甘肽还原酶让 GSSG 得氢，NADPH 是后一步的供氢者。

### 天然活性肽：小肽里的大活性

#### 鹅膏蕈碱：一针扎在 RNA 聚合酶 II 上

除了谷胱甘肽，还有一类天然活性肽是毒素。最典型的是 α-鹅膏蕈碱，它是一个环八肽，主要存在于毒蘑菇里——就是“红伞伞白杆杆”那些不能随便吃的蘑菇。

它的致死机制非常精准：α-鹅膏蕈碱能与真核细胞核内的 RNA 聚合酶 II 特异性结合。RNA 聚合酶 II 主要负责合成 mRNA。mRNA 合成被抑制，蛋白质翻译就没有模板，整个细胞的蛋白质合成就被卡住，细胞很快丧失功能。

```text
  DNA --转录--> mRNA --翻译--> 蛋白质
                  ^
                  |
            RNA 聚合酶 II
                  ^
                  |
          α-鹅膏蕈碱（结合并抑制）
```

这条链子一断，细胞不是“少合成一点蛋白”，而是整个表达程序停摆。所以毒蘑菇的毒性不是闹着玩的。

#### 多肽激素与神经肽：短链，大功能

多肽类激素也是天然活性肽的一大类：

| 名称 | 长度 |
| :--- | :--- |
| 缩宫素 | 九肽 |
| 加压素 | 九肽 |
| 促肾上腺皮质激素 | 39 肽 |
| 促甲状腺素释放激素 | 三肽 |

这些名字听起来都很“重”，但结构其实很简单：短的只有三个氨基酸，长的也不过 39 个。结构简单，功能却很强——这正说明肽的生物活性不取决于链有多长，而取决于序列和构象。

神经肽也是一样：脑啡肽、内啡肽、强啡肽、孤啡肽，都是体内起调节作用的小肽。内啡肽这两年网上比较火，很多人把它和“跑步后的愉悦感”联系在一起；从生化角度看，它就是一个典型的神经肽。

#### 不标准的肽键：天然活性肽的护身符

天然活性肽里经常出现一些蛋白质中没有的结构：γ-肽键、β-氨基酸、D 型氨基酸。

这些结构在正常的蛋白质里不存在。体内的蛋白酶长期“认”的是蛋白质中常见的化学键和化学结构，遇到这些不标准的部件就不太认得，天然活性肽因此能躲过蛋白酶的降解，在体内保持较长的寿命。

> **结论**：天然活性肽的“非标准结构”不是装饰，而是一种保护机制——结构越不像常规蛋白质，越不容易被常规蛋白酶拆掉。

### 蛋白质的化学组成：氮含量 16% 的妙用

说完肽，视野放大到蛋白质。

蛋白质是由氨基酸以肽键形式串联聚合形成的多聚物，是一个生物大分子。它的元素组成，本质上就是氨基酸的元素组成：主要是碳、氢、氧、氮四种，另外含有少量的硫——半胱氨酸和甲硫氨酸里都有硫。再往后，还会出现磷、铁、铜、锌等元素，这些多半是在氨基酸连成蛋白质以后，通过化学修饰加进去的。

这些元素里，氮被单独拎出来讲，因为所有蛋白质样品的平均含氮量是一个定值：16%。这是一个经验值，但确实好用——不管拿到什么蛋白质样品，平均含氮量都落在这附近。

于是就有了凯氏定氮法：

$$ \text{蛋白质含量} = \frac{\text{氮含量}}{16\%} = \text{氮含量} \times 6.25 $$

因为 $100/16 = 6.25$，所以“除以 16%”和“乘以 6.25”是一回事。测出样品中的氮含量，乘上 6.25，就得到蛋白质含量。

> **提示**：16% 是平均经验值，不是每个蛋白质都精确等于 16%；凯氏定氮法给出的是由总氮折算的蛋白质含量。

### 蛋白质的分类：四种分法

蛋白质的分类有好几种方式，这部分不要求死记硬背，理解每种分法的依据和典型例子就够了。

#### 按化学组成：简单蛋白与缀合蛋白

按化学组成，蛋白质分两类：简单蛋白质和缀合蛋白质。

简单蛋白质只由蛋白质组分构成，不需要别的物质参与，本身就已经具有全部功能。比如胶原蛋白有支撑功能，有些酶只靠蛋白质部分就能催化——只要有蛋白质部分，它们就能干活。

缀合蛋白质不一样：除了蛋白质组分，还需要结合一些非蛋白质组分，才能具有全部功能。那个非蛋白质组分叫辅基，蛋白质部分叫脱辅基蛋白质。脱辅基蛋白质加上辅基，整体打包成有功能的完整分子，叫全蛋白。

| 分类 | 组成 | 功能前提 | 对应概念 |
| :--- | :--- | :--- | :--- |
| 简单蛋白质 | 只有蛋白质组分 | 自身即具备全部功能 | 胶原蛋白、部分酶 |
| 缀合蛋白质 | 脱辅基蛋白质 + 辅基 | 两者结合才有全部功能 | 全蛋白 |

这和后面讲酶时的“全酶”是同一个思路：酶蛋白单独存在不够，还要有辅助因子，两者结合成全酶才有活性。

#### 按生物学功能：酶、转运、结构……

按生物学功能分，蛋白质的种类就多了：

| 功能类别 | 例子 |
| :--- | :--- |
| 催化 | 酶 |
| 调节 | 转录因子 |
| 转运 | 血红蛋白（运氧） |
| 储存 | 肌红蛋白（储氧） |
| 收缩与游动 | 肌纤维蛋白 |
| 结构 | 细胞骨架蛋白 |
| 支架 | 支架蛋白 |
| 防卫与保护 | 免疫球蛋白 |

支架蛋白其实也可以看成结构蛋白的一种，只是它更强调“把其他东西组织在一起”的作用。

#### 按形状与溶解度：纤维状、球状、膜蛋白

按形状和溶解度，分纤维状蛋白、球状蛋白和膜蛋白。

纤维状蛋白包括胶原蛋白、弹性蛋白、角蛋白、丝蛋白等。它们大多不溶于水。角蛋白在头发里，如果角蛋白溶于水，洗个头头发就没了——这个例子虽然直白，但很能说明“纤维状蛋白多数不溶于水”。

球状蛋白是可溶性蛋白的主要类型，大多数可溶性蛋白都属于这一类，细胞里的很多酶也在其中。一条多肽链折叠成球状，疏水基团藏在球内部，亲水基团露在球表面。细胞环境是水环境，亲水基团在外才能和水相处，疏水基团在内才能避开水的干扰——这就是球状蛋白能溶于水的原因。

膜蛋白是与各种膜系统结合的蛋白，比如细胞膜、核膜、内质网膜上的蛋白。跨膜蛋白的跨膜区段一定是疏水的，因为磷脂双分子层内部是疏水区；跨膜段要和膜内部相处，就不能是亲水的。

| 类型 | 特点 | 例子 |
| :--- | :--- | :--- |
| 纤维状蛋白 | 多数不溶于水，起支撑、保护作用 | 胶原蛋白、弹性蛋白、角蛋白、丝蛋白 |
| 球状蛋白 | 多数可溶性蛋白，疏水基团在内、亲水基团在外 | 细胞内多数酶 |
| 膜蛋白 | 与膜系统结合，跨膜段疏水 | 跨膜受体 |

#### 按多肽链数目：单体与寡聚

按蛋白质分子包含的多肽链数目，还可以分单体蛋白和寡聚蛋白。

单体蛋白只有一条多肽链，比如肌红蛋白——肌肉里储存氧气的那个蛋白，就是一条链。

寡聚蛋白由两条或两条以上的多肽链组成，比如血红蛋白由四条肽链聚合而成，己糖激酶也是寡聚蛋白。寡聚蛋白里，每一条多肽链叫一个亚基。

> **提示**：亚基是“一条多肽链”，不是“一个氨基酸”。血红蛋白四个亚基，指的是四条链，不是四个氨基酸。

### 用 110 估算蛋白质的大小

20 种氨基酸的平均分子量大约是 110。对于不含辅基的简单蛋白质，相对分子质量可以用氨基酸数目估算：

$$ M_r \approx N \times 110 $$

反过来，知道一个蛋白质的相对分子质量，除以 110，就能大致算出它由多少个氨基酸组成：

$$ N \approx \frac{M_r}{110} $$

这是估算，不是精确计算；但它足够快，考试里用来判断数量级很好用。

### 蛋白质的结构层次：一根金属丝摩托车的比喻

这部分别跳过。考试不一定直接出一道“请论述蛋白质四级结构”的大题，但它和下一节、下一个专题的蛋白质分子结构密切相关。先把层次感建立起来，后面学具体结构才不会乱。

想象一个用金属丝拧成的摩托车工艺品。整辆摩托车由很多根铁丝拧成：前轮胎一根，后轮胎一根，油箱一根，发动机一根。每一根铁丝自己拧成一个相对独立的立体形状，几根铁丝再拼成整辆车。

把整辆摩托车比作一个蛋白质：

- 整辆车所有金属丝共同组成的空间结构，是四级结构；
- 每一根铁丝自己拧成的相对独立的空间结构，是三级结构；
- 每一根铁丝上局部的螺旋状结构，是二级结构；
- 铁丝本身是一节一节接起来的，对应氨基酸串联成的线性序列，是一级结构。

换成蛋白质的语言：

| 层次 | 定义 | 摩托车类比 |
| :--- | :--- | :--- |
| 一级结构 | 氨基酸的线性排列顺序 | 拧成铁丝的那串氨基酸本身 |
| 二级结构 | 一条肽链内部局部的规则空间结构，如螺旋 | 铁丝上局部拧出的螺旋 |
| 三级结构 | 一条肽链全部原子形成的完整空间结构 | 一根铁丝拧成的完整零件 |
| 四级结构 | 多条肽链（亚基）组装成的整体 | 所有零件拼成的整辆摩托车 |

一条多肽链就像一根很长的铁丝，上面串着一个一个氨基酸。这根铁丝开始折叠，折出一段一段的局部结构，那些局部结构就是二级结构；所有二级结构在同一条链上组成一个相对完整的空间结构，就是三级结构；不同的肽链各有各的三级结构，再按一定方式组合起来，就是四级结构。

一级结构是基础结构，二、三、四级结构是高级结构，也就是空间结构。下一节先讲一级结构——氨基酸序列；二、三、四级结构留到下一个专题展开。

> **提示**：四级结构讨论的是多条肽链之间的组装，所以只有寡聚蛋白才谈得上四级结构；一条链的单体蛋白，最高到三级结构。

## 蛋白质的一级结构：从氨基酸序列到人工合成
> 对应块：BLK06 | 覆盖分集：P20-P26 | 块标题（分集名）：《[专题02习题]考点08∶蛋白质组成、结构、分子》

### 一辆金属丝摩托车

上一讲我用一根金属丝折成的摩托车打过比方。这一讲还得把它拎出来——蛋白质的结构层次，用这辆车一看就清楚。

整辆摩托车是一个完整的蛋白质，它对应四级结构。注意，四级结构说的是"整辆车"，不是车上某个零件。车上的前轮胎、后轮胎、发动机、油箱，还有车头，每个区域都由一条多肽链折叠而成；一条多肽链上所有原子的位置，就是它的三级结构。再往细里看，发动机那一块里头有好几个螺旋区域，每一个螺旋区域只是整条肽链上的一段局部空间结构，这是二级结构。而所有这些螺旋、折叠，说到底都是一根金属丝弯出来的——这根金属丝就是氨基酸靠肽键一个一个串起来的链状结构，也就是蛋白质的一级结构。

```text
四级结构：整辆摩托车（多条肽链组装）
└─ 三级结构：前轮 / 后轮 / 发动机 / 油箱 / 车头（每条肽链的整体空间结构）
   └─ 二级结构：发动机里的一个个螺旋区域（肽链的局部空间结构）
      └─ 一级结构：一根根金属丝（氨基酸序列，靠肽键串联）
```

读图说明：从上往下是拆车，从下往上是装车。这一讲只盯最底下那根金属丝。

> **定义**：蛋白质的一级结构，指多肽链中氨基酸的排列顺序。氨基酸之间靠肽键串联，所以肽键是维持一级结构最重要、也是最主要的化学键。

### 一级结构到底包含什么

先把最没有争议的一条钉死：一级结构就是氨基酸序列，一句话说完，没有别的花样。

那这条序列是靠什么键维持的？你们想，一条多肽链是氨基酸一个接一个串起来的，串它们的键只能是肽键——前一个氨基酸的羧基和后一个氨基酸的氨基脱水缩合出来的那个酰胺键。所以肽键是维持一级结构最重要的化学键。不少教材说得更绝，干脆写成"唯一"的化学键；也有的书写得松一点，说"主要"。考试写"肽键"两个字，方向不会错。

但一级结构的内容不止序列。它还包括二硫键的数量和位置。这里各家教材有出入：人卫版教材把二硫键的数量和位置放进了一级结构所涉及的化学键里，别的教材我翻下来，没怎么见到这种写法。所以我的建议是分两层记——

> **易错点**：问"一级结构包括什么"，答氨基酸序列、二硫键的数量与位置；问"维持一级结构的化学键是什么"，答肽键（最主要，很多教材写作唯一）。不要把"二硫键是一级结构的组成内容"错说成"二硫键是维持一级结构的主要化学键"。

还有一类蛋白质要单独说：缀合蛋白质。有的蛋白质要发挥功能，光有蛋白部分不够，还得挂上一些辅助成分，这些辅助成分叫辅基。对缀合蛋白质来说，它的一级结构还应该包括共价连接上去的辅基部分。这个上一讲讲过，这里只是把它归回一级结构的定义里。

把这些合起来，一级结构的地位就出来了：它在很大程度上决定了二、三、四级结构，也决定了蛋白质的功能。换句话说，一级结构是高级结构的基础。注意"在很大程度上"这几个字，别写成"完全决定"——序列是蓝图，但折叠还受别的东西影响，这话留有余地。

### 桑格试剂与牛胰岛素

一级结构这个概念不是凭空来的，它是被一个实验砸实的：1953 年，桑格（Sanger）用化学方法测定了胰岛素多肽链的氨基酸序列。这是世界上第一个被测出序列的蛋白质。

他用的试剂是 2,4-二硝基氟苯，也叫桑格试剂，缩写常见 DNFB、FDNB 这几种写法，字母顺序调了个个儿，指的是同一个东西。在生化这门课里，看到这组字母组合，基本跑不了就是它。

反应本身不复杂，分三步：

1. 二硝基氟苯在碱性条件下和多肽链 N 端的 α-氨基反应，生成 DNP-肽，也就是二硝基苯肽；
2. 在酸性条件下水解，肽键全部断掉，得到一堆游离氨基酸，外加一个带着 DNP 的氨基酸；
3. 把这个 DNP-氨基酸鉴定出来，就知道 N 端第一个残基是谁。

关键在于：DNP 只连在 N 端那一个氨基酸上，酸水解把别的肽键都打断了，它却还稳稳挂在那儿。所以这法子给出的信息是"N 端第一个是谁"，仅此一个。

```text
多肽链：NH2-AA1-AA2-AA3-…-C端
           │
        DNFB（碱性）
           ↓
        DNP-肽
           │  酸水解
           ↓
DNP-AA1  +  AA2 + AA3 + …（游离氨基酸）
```

读图说明：DNP 这面"旗子"只插在 N 端第一个残基上，水解之后靠找旗子认人。

顺便把 DNP 这个缩写拆开：DNP 就是二硝基苯（基）。桑格法又叫 DNP 法，原因就在这儿——试剂反应之后连上去的那一坨，名字叫 DNP。

牛胰岛素的一级结构，就是桑格交出来的那份答卷。胰岛素由两条多肽链组成，A 链 21 个氨基酸，B 链 30 个氨基酸，一共 51 个；两条链靠二硫键连在一起，所以它是个寡聚蛋白。三个二硫键的位置要记：

- A 链第 6 位半胱氨酸与第 11 位半胱氨酸，形成 A 链内部的二硫键；
- A 链第 7 位半胱氨酸与 B 链第 7 位半胱氨酸，形成第一条链间二硫键；
- A 链第 20 位半胱氨酸与 B 链第 19 位半胱氨酸，形成第二条链间二硫键。

```text
        A 链（21 个残基）
   Cys6 ─────────── Cys11        （链内）
      │
   Cys7 ─────────── Cys7   B 链（30 个残基）
                    │
  Cys20 ─────────── Cys19
```

读图说明：三条连线就是三个二硫键，两条在 A、B 链之间，一条在 A 链内部。

就因为把第一个蛋白质的序列读了出来，桑格拿到了 1958 年的诺贝尔化学奖。这个人后面还会出现——人工合成那一段，绕不开他。

### 两条测序路线

测定一级结构是个庞大又复杂的工程，但总体策略只有两条：一条是化学测序，也叫直接法；另一条是测核酸序列，再按密码子反推氨基酸序列，叫间接法。

```text
直接法：蛋白质 ──化学测序──→ 氨基酸序列

间接法：DNA ──转录──→ mRNA ──翻译──→ 蛋白质
           ↑
      先测 DNA / mRNA 序列，再按密码子反推
```

读图说明：直接法从蛋白质这头下手，间接法从基因那头绕过去，终点都是同一条氨基酸序列。

#### 化学测序的九个步骤

直接法的流程，我按九步走一遍。先提醒一句：这是总体策略，具体到每一步都极其复杂，别以为背下九步就等于会测序。

1. 确定蛋白质分子中不同多肽链的数目。先得知道这个蛋白质由几条链组成，一条、两条还是四条。
2. 把这几条多肽链拆开。像胰岛素那样靠二硫键把 A、B 链拴在一起的，得先把链间的二硫键断开。
3. 断裂多肽链内部的二硫键。链内二硫键会让肽链自己打个环，后面的酶切和测序都会受干扰；断完之后，一条链就只剩肽键串联的线状结构。
4. 分析每条多肽链的氨基酸组成。也就是这条链里各种氨基酸各有多少个，先把"料"点清楚。
5. 鉴定多肽链的 N 端和 C 端残基。两端各是谁，是后面拼接顺序时的锚点。
6. 把多肽链断裂成较小的片段。原因很实际：一步能读的残基数有限，长链必须先切短。
7. 测定各个肽段的氨基酸序列。一段一段读。
8. 重建完整多肽链的一级结构。把各段序列按重叠关系接回整条链。
9. 确定二硫键的位置。最后回到完整分子，把前面拆掉的二硫键信息补回去，定出哪两个半胱氨酸成键。

```text
① 确定多肽链数目
        ↓
② 拆开各条多肽链
        ↓
③ 断开链内二硫键，只留肽键
        ↓
④ 分析氨基酸组成
        ↓
⑤ 鉴定 N 端与 C 端残基
        ↓
⑥ 切成较小片段
        ↓
⑦ 测定各肽段序列
        ↓
⑧ 重建完整一级结构
        ↓
⑨ 确定二硫键位置
```

读图说明：前三步是"拆"，中间三步是"读"，最后三步是"拼回去、补回二硫键"。

> **提示**：第 6 步切片段不是随便切一刀。切出来的片段之间必须有重叠区，第 8 步才有办法把顺序接回去；这也是后面要准备两套不同切割方式的原因——一套切出来的片段，靠另一套的重叠片段来定位。

#### 从核酸序列反推氨基酸序列

第二条路是间接法。蛋白质由 mRNA 翻译而来，mRNA 又由 DNA 转录而来；所以只要手上有这个蛋白质的基因序列（DNA 或 mRNA 都行），按密码子表一推，氨基酸序列就出来了。

这条路的逻辑很顺：测核酸比测蛋白质容易得多，能测基因就不去硬啃蛋白。当然，前提是你得先拿到对应的基因或 mRNA 序列——手上没有核酸序列，这条路走不通。

### 定 N 端：桑格法与埃德曼法

接下来两件事是测序里的重点：一是鉴定多肽链的 N 端和 C 端残基，二是把多肽链断裂成较小片段。先说末端鉴定。

N 端的方法有两个：桑格法和埃德曼法。这部分内容到这儿已经是第三次讲了，我给它标三颗星——不是因为它难，是因为它反复出现，必须一次记牢。

#### 桑格法（DNFB法）

桑格法就是 DNFB 法，反应前面已经完整走过一遍：DNFB 和 N 端第一个氨基酸的氨基反应，生成 DNP-肽；酸性水解后，DNP 仍然挂在 N 端那个残基上，其余氨基酸全部游离；把 DNP-氨基酸鉴定出来，N 端就定了。

所以桑格法测的是 N 端。它叫 DNFB 法，是因为试剂是二硝基氟苯；它叫 DNP 法，是因为反应后连上去的那部分叫二硝基苯（DNP）。

它的局限也要看清：酸水解把整条链都打断了，你只能知道"第一个是谁"，没法一轮一轮往下读。要把整条序列读出来，得换一种每轮只削掉一个残基的方法。

#### 埃德曼法（PITC法）

埃德曼法（Edman 法）又叫 PITC 法，试剂是苯异硫氰酸酯（PITC），也叫埃德曼试剂。叫 PITC 法，和桑格法叫 DNFB 法是一个道理——名字直接取自试剂。

它的过程比桑格法多几步，但关键差别只有一个——每轮只切掉 N 端一个残基，剩下的肽链完好无损：

1. PITC 与多肽链 N 端的 α-氨基反应，生成 PTC-肽；
2. 在酸性条件下，N 端这个残基环化并断裂下来，形成 ATZ-氨基酸，肽链剩下的部分原样保留；
3. ATZ 转化为 PTH-氨基酸，也就是便于层析鉴定的形式；
4. 用层析鉴定这个 PTH-氨基酸，就知道本轮切下来的是谁；
5. 剩下那条短了一截的肽链，重复上述步骤，读第二个、第三个……

```text
PITC + NH2-AA1-AA2-AA3-…
        ↓
     PTC-肽
        ↓  酸性条件，环化断裂
ATZ-AA1  +  NH2-AA2-AA3-…（肽链其余部分完好）
        ↓  转化
PTH-AA1  → 层析鉴定
```

读图说明：每转一圈只削掉 N 端一个残基，肽链像被从头上啃掉一粒，所以能一轮一轮读下去。

正因为能连续读，埃德曼法成了测序的主力。但它有上限：一次能准确读 50～60 个氨基酸残基，肽链再长就不适用了。原因不难想——每一轮反应都不可能百分之百完全，轮数一多，没反应完的残余、副反应产物一轮轮累积，信号就糊了。所以长链必须先切成 50～60 个残基以内的小段，这也是九步里第 6 步存在的理由。

| 比较项 | 桑格法（DNFB 法） | 埃德曼法（PITC 法） |
| :--- | :--- | :--- |
| 试剂 | 2,4-二硝基氟苯 | 苯异硫氰酸酯 |
| 反应对象 | N 端 α-氨基 | N 端 α-氨基 |
| 中间产物 | DNP-肽 | PTC-肽 |
| 鉴定物 | DNP-氨基酸 | PTH-氨基酸 |
| 能否连续测 | 不能，酸水解打断整条链 | 能，每轮只切一个残基 |
| 适用长度 | 只定 N 端第一个残基 | 约 50～60 个残基 |

这两栏的差别要记死：同样是测 N 端，桑格法是一锤子买卖，埃德曼法是可以反复削的削皮刀。

### 定 C 端：四种羧基肽酶

N 端有两个法子，C 端靠酶。用的是羧肽酶——从 C 端开始，把肽键一个一个水解掉，第一个被切下来的残基就是 C 端残基。羧肽酶有 A、B、C、Y 四种，分工各不相同。

| 羧肽酶 | 能从 C 端切下的残基 | 切不动的残基 |
| :--- | :--- | :--- |
| A | 除脯氨酸、精氨酸、赖氨酸外的多数残基 | 脯氨酸、精氨酸、赖氨酸 |
| B | 只切精氨酸、赖氨酸 | 其余全部 |
| C | 除羟脯氨酸外的所有残基（脯氨酸也能切） | 羟脯氨酸 |
| Y | 所有氨基酸残基 | 无 |

把这张表读成一句话：A 管大多数，B 专管碱性氨基酸中的精氨酸和赖氨酸，A 加 B 一合，几乎什么都能切，只剩一个脯氨酸；C 正好补上脯氨酸这个缺口，但它怕羟脯氨酸；Y 是万能刀，什么都能切。四把刀凑齐，任何多肽链的 C 端都能测。

这里有个点必须单独拎出来：

> **易错点**：如果倒数第二个氨基酸是脯氨酸，羧肽酶 A 和 B 都不起作用，只有羧肽酶 C 能切。原因是这一刀切的是脯氨酸羧基侧的那个肽键，A、B 都动不了脯氨酸参与的这个键。另外，C 端本身就是脯氨酸时，A、B 也放不出它来，还是得靠 C 或 Y。两件事位置不同，卡住的道理都是"脯氨酸这一关"。

### 把长链切成小段

测序的另一个重点，是把长链切成小片段。两类方法：酶解法和化学法。

先说方向。整条多肽链是有方向的，从 N 端到 C 端。每个氨基酸的头是氨基，和前一个氨基酸的羧基成肽键；它的羧基又和后一个氨基酸的氨基成肽键。所以"某个氨基酸的羧基所形成的肽键"，就是它后面那个键；"氨基侧的肽键"，就是它前面那个键。这个前后之别千万别搞反，后面所有切割位点都靠它。

```text
N端                                                     C端
NH2-Leu-CO-NH-Leu-CO-NH-Arg-CO-NH-Val-CO-NH-Phe-CO-NH-Asp-COOH
                     ^              ^                ^
                     a              b                c
```

读图说明：a 是 Leu—Arg 之间的肽键，由 Leu 的羧基形成；b 是 Arg—Val 之间的肽键，由 Arg 的羧基形成；c 是 Phe—Asp 之间的肽键，由 Phe 的羧基形成。说"切 Arg 的羧基侧"，落刀点就是 b。

酶解法主要用三种蛋白酶，都是人体消化蛋白质的主力：

| 试剂 | 识别残基 | 切在哪一侧 |
| :--- | :--- | :--- |
| 胰蛋白酶 | 赖氨酸、精氨酸 | 羧基侧（残基之后） |
| 糜蛋白酶（胰凝乳蛋白酶） | 苯丙氨酸、色氨酸、酪氨酸 | 羧基侧（残基之后） |
| 胃蛋白酶 | 苯丙氨酸、色氨酸、酪氨酸、亮氨酸 | 氨基侧（残基之前） |
| 溴化氢 | 甲硫氨酸 | 羧基侧（残基之后） |

胰蛋白酶认赖氨酸和精氨酸，从它们的羧基侧下刀，也就是切在 Lys 或 Arg 的后面。糜蛋白酶又叫胰凝乳蛋白酶，认苯丙氨酸、色氨酸、酪氨酸这三种芳香族、疏水氨基酸，也是切在它们后面。胃蛋白酶认苯丙氨酸、色氨酸、酪氨酸、亮氨酸这几种疏水氨基酸，但切在它们前面——氨基侧。

> **易错点**：糜蛋白酶和胃蛋白酶认的残基高度重叠，刀口却不在同一侧。糜蛋白酶切在 Phe、Trp、Tyr 之后，胃蛋白酶切在 Phe、Trp、Tyr、Leu 之前。做题时先看酶名，再定刀口在残基的哪一边，别一看"苯丙氨酸"就条件反射往后面切。

化学法用的是溴化氢，选择性切割甲硫氨酸羧基侧形成的肽键，也就是切在 Met 后面。这一条了解即可，考得不如酶解法多。

> **提示**：为什么非要两套切法？因为一条长链切一次得到的片段，顺序还是乱的；换一种切法再切一次，两套片段之间会形成重叠区，靠重叠区才能把片段排回原来的次序。只切一套，第 8 步的"重建"就无从下手。

### 同源蛋白质与生物进化

这一讲还剩两个考点，我把它们并在一起讲：氨基酸序列与生物进化、肽和蛋白质的化学合成。放在一起，是因为这两块都属"了解"级别，内容也不多。

先看同源蛋白质。定义很直白：不同物种中功能相同或相似的蛋白质，它们具有相似或明显同源性的氨基酸序列，就叫同源蛋白质。

不是随便两种蛋白序列像就算。得同时满足两条：功能相同或相似，序列也相似。人和其他哺乳动物，甚至昆虫这类低等动物身上，都有这样的蛋白——序列很像，功能一样或者差不多。

最典型的例子还是胰岛素。牛胰岛素 51 个氨基酸，A、B 两条链。人、猪、狗、兔、牛、羊、马这七种哺乳动物的胰岛素，51 个残基里不一样的只有少数几个位置，集中在 A 链第 8、9、10 位和 B 链第 30 位。人和猪比，只差 B 链第 30 位这一个氨基酸。

```text
物种：    人    猪    狗    兔    牛    羊    马
差异位点：A8、A9、A10、B30（只在少数位置）
人和猪：  仅 B30 不同
```

读图说明：七个物种的胰岛素摆在一起，差异只落在四个位置上，其余四十多个残基完全一致。

这件事临床上是有痕迹的。1 型糖尿病患者每次吃饭前要打一针胰岛素；最早用的不是人胰岛素，是猪源、牛源的胰岛素，照样能把血糖降下来。为什么？因为猪、牛胰岛素和人胰岛素序列几乎一样，功能也一模一样。

> **结论**：同源蛋白质的序列保守性和功能一致性是互为表里的——序列差得越少，功能越接近，物种之间的亲缘也越近。看同源蛋白的序列差异，本质上是在看进化留下的脚印。

### 从催产素到牛胰岛素：肽的人工合成

1958 年，北京大学生物系在国内首先合成了一个具有生物活性的八肽——催产素。这个点如果考北大，很可能会碰到，记一下不吃亏。

同一年，桑格因为测出胰岛素序列拿了诺贝尔化学奖。当时《Nature》发过评论，大意是：桑格把胰岛素的序列读出来了，但人工合成胰岛素还是遥远的事。

结果这句话很快被打脸。1958 年中国组建团队，开始啃人工合成胰岛素这块硬骨头；几年艰苦奋斗之后，1965 年 9 月，我国在世界上首次人工合成了牛胰岛素结晶。

肽的化学合成现在有两条路：固相合成和液相合成，固相用得更多。固相合成的主角是一个叫 DCC 的试剂，全名二环己基碳二亚胺，是最有效的接肽缩合剂。

它的基本过程是这样：

1. 先把目标多肽 C 端的羧基，以共价键连到一个不溶性高分子树脂上；
2. 以这个氨基酸的 α-氨基为起点，加入下一个氨基酸，让它的羧基和这个氨基成肽键，缩合剂用 DCC；
3. 重复"加氨基酸—DCC 缩合"，链就一步一步往上长；
4. 长到目标长度，把肽从树脂上切下来，得到产物。

```text
树脂-OH + HOOC-AA1-NH2  →  树脂-O-CO-AA1-NH2
                                  │
                                  │ + HOOC-AA2-NH2，DCC
                                  ↓
                        树脂-O-CO-AA1-NH-CO-AA2-NH2
                                  │
                                  │ 重复加氨基酸 + DCC 缩合
                                  ↓
                        树脂-O-CO-(AA)n-NH2
                                  │
                                  │ 从树脂上切下
                                  ↓
                            NH2-(AA)n-COOH
```

读图说明：C 端氨基酸先"钉"在树脂上，新氨基酸一个个从它的氨基这头接上去，所以链是从 C 端往 N 端长的。

树脂这个东西不陌生。前面讲分离纯化时说过柱层析：玻璃柱里要装固体填料，那个就是固相。固相合成借的是同一个思路——把反应物挂在不溶的固体上，加试剂、洗杂质都方便，最后一切了之。

> **易错点**：固相合成的延伸方向是 C 到 N，和生物体内核糖体上的合成方向正好相反。生物合成是 N 到 C，一边翻译一边从 N 端往 C 端长；固相合成是把 C 端固定在树脂上，从 C 端往 N 端接。这一条年年有人记反。

### 本讲提到的题目

课程每讲开头都留了考点小测，题面没有在讲解里展开，这里不代拟；下面两道是讲解中完整给出、并当场推演过的题。

#### 六肽在三种处理下各得什么

**题目**：现有一个六肽，一级结构为亮氨酸—亮氨酸—精氨酸—缬氨酸—苯丙氨酸—天冬氨酸（Leu-Leu-Arg-Val-Phe-Asp）。分析它在以下三种反应条件下分别得到什么物质：

1. 用 2,4-二硝基氟苯（DNFB）反应；
2. 用胰蛋白酶反应，得到哪几个多肽？得到的这几个多肽再分别用 DNFB 反应，又得到什么？
3. 用胰凝乳蛋白酶反应，得到哪几个多肽？

**解析**：

第一问考 DNFB 的反应原理。DNFB 只和整条肽链 N 端第一个氨基酸的氨基反应，生成 DNP-肽；酸水解后，DNP 仍然连在 N 端残基上，其余残基全部变成游离氨基酸。这条六肽的 N 端是亮氨酸，所以产物是 DNP-亮氨酸，加上游离的亮氨酸、精氨酸、缬氨酸、苯丙氨酸、天冬氨酸。

注意后五个是"游离氨基酸"，不是一个一个肽段——酸水解把肽键全打断了。

第二问考胰蛋白酶的切割位点。胰蛋白酶切赖氨酸、精氨酸的羧基侧；这条链里只有第 3 位一个精氨酸，没有赖氨酸，所以只能在 Arg 后面下刀，一分为二，得到两个三肽：Leu-Leu-Arg 和 Val-Phe-Asp。

两个三肽再分别用 DNFB 处理，各自只标记自己 N 端的残基：

- Leu-Leu-Arg：N 端是 Leu，产物为 DNP-Leu，加上游离的 Leu、Arg；
- Val-Phe-Asp：N 端是 Val，产物为 DNP-Val，加上游离的 Phe、Asp。

第三问考胰凝乳蛋白酶的切割位点。它切苯丙氨酸、色氨酸、酪氨酸的羧基侧；六肽里只有第 5 位一个苯丙氨酸，所以切在 Phe 后面，得到一个五肽 Leu-Leu-Arg-Val-Phe 和一个游离的天冬氨酸。

> **提示**：考场上如果一时想不起某个三字母缩写对应哪种氨基酸，直接写三字母缩写也能得分，别因为译名卡住整道题。

**答案**：

1. DNP-Leu，加上游离的 Leu、Arg、Val、Phe、Asp；
2. 胰蛋白酶水解得到 Leu-Leu-Arg 与 Val-Phe-Asp；前者再用 DNFB 反应得 DNP-Leu + Leu + Arg，后者得 DNP-Val + Phe + Asp；
3. 胰凝乳蛋白酶水解得到五肽 Leu-Leu-Arg-Val-Phe + 游离 Asp。

#### 从三条线索反推六肽顺序

**题目**：现需测定某六肽的序列。已知该六肽含有一个天冬氨酸、一个缬氨酸、一个苯丙氨酸、两个亮氨酸和一个精氨酸。根据以下条件推断这个六肽的顺序：

1. 用 DNFB 反应，得到 DNP-亮氨酸；
2. 用胰蛋白酶裂解，生成两个三肽；其中一个肽段再与 DNFB 反应，得到 DNP-缬氨酸；
3. 用胰凝乳蛋白酶水解，得到一个五肽和一个游离的天冬氨酸。

**解析**：

先画六个空位，从左到右依次是 1 到 6，最左边是 N 端，最右边是 C 端。

```text
位次：  1     2     3     4     5     6
方向： N端 ──────────────────────→ C端
```

条件一：DNFB 标记的是 N 端第一个残基，得到 DNP-亮氨酸，所以第 1 位是 Leu。

条件二：胰蛋白酶把六肽切成两个三肽，说明刀口在第 3 位之后；胰蛋白酶切精氨酸、赖氨酸的羧基侧，而这条链里只有精氨酸、没有赖氨酸，所以第 3 位是 Arg。再看两个三肽的 N 端：第一个三肽的 N 端就是整条链的 N 端，即 Leu；那么能得到 DNP-缬氨酸的只能是第二个三肽，所以第 4 位是 Val。

条件三：胰凝乳蛋白酶水解得到一个五肽加一个游离的天冬氨酸。五肽意味着只切了一刀，游离出来的是末端那一个残基；如果切在第 1 位之后，游离出来的应该是 Leu，与"游离天冬氨酸"矛盾，所以刀口只能在第 5 位之后，第 6 位是 Asp。胰凝乳蛋白酶切 Phe、Trp、Tyr 的羧基侧，六肽里只有 Phe，所以第 5 位是 Phe。

六个位置里已经填了 1=Leu、3=Arg、4=Val、5=Phe、6=Asp，剩下第 2 位只能是另一个 Leu。

```text
位次：  1     2     3     4     5     6
残基： Leu   Leu   Arg   Val   Phe   Asp
方向： N端 ──────────────────────→ C端
```

**答案**：Leu-Leu-Arg-Val-Phe-Asp，即亮氨酸—亮氨酸—精氨酸—缬氨酸—苯丙氨酸—天冬氨酸。

这两道题是考试里反复出现的题型。第一道顺着"试剂—刀口—产物"往下推，第二道反过来从产物倒推位置，考的都是同一套东西：DNFB 认 N 端，胰蛋白酶认 Lys/Arg 的羧基侧，胰凝乳蛋白酶认 Phe/Trp/Tyr 的羧基侧。把这三条记牢，题目怎么换皮都不怕。

## 氨基酸补丁课：把第二章的冷门考点补齐
> 对应块：BLK07 | 覆盖分集：P27 | 块标题（分集名）：《第二章》

我是小七。这门"补丁课"是接在高分笔记正课后面的：张小万老师已经带大家过了一遍高分笔记的基础内容，我也讲过一遍，但一轮下来同学们反映，总有些基础内容他没提到、或者问的人特别多。于是我把这些问题集中总结出来，专门补那些冷门的考点和被忽略的角落。这门课的定位，是帮你在高分笔记一轮复习之后，对笔记的理解再深一层——这些问题你自己复习时多半也冒出来过，所以这一讲要集中注意力听，收获会很大。咱们从第二章氨基酸开始。

### 脯氨酸：亚氨基酸，也是 α-氨基酸吗

第一个考点很小：脯氨酸算不算 α-氨基酸？高分笔记的表述是：除脯氨酸之外，其他氨基酸都含有一个 α-碳原子上的氨基，所以称为 α-氨基酸——脯氨酸就是那个被单独拎出来的例外。

先把结论统一好：脯氨酸属于亚氨基酸。它为什么特别？它的侧链缠绕回来之后，和 α-位上那个含氮的基团形成了一个环状结构——氨基被圈进环里，所以叫亚氨基酸。

至于脯氨酸算不算 α-氨基酸，众说纷纭，大部分教材、大部分看法认为它其实也是 α-氨基酸。真题里一般不会直接问"组成蛋白质的 20 种氨基酸都是 α-氨基酸吗"；万一考了，从规范口径答"对"也行——脯氨酸虽是亚氨基酸，但多数口径下它也算 α-氨基酸。我自己倾向于答"错"，理由很简单：判断题没有白问的，问到你了肯定就有蹊跷。不同口径说法不一样，这个问题不用再深究，你记两条就够：脯氨酸是亚氨基酸；它特殊在侧链回折成环、把含氮基团圈了进去。

### 物理性质：冷门，但特例要记

氨基酸的物理性质，正课里没有仔细提及，是个非常冷门的考点，不用特地去背，但几个点要心里有数。

α-氨基酸是白色晶体，熔点高，有特殊的结晶形状——根据结晶形状的不同，可以鉴别不同的氨基酸，这是第一个要背的点。溶解度方面，除了半胱氨酸和酪氨酸较低之外，氨基酸都可以溶于水；注意这两个特例是"溶解度低"，不是"不溶于水"，要单独记一下。最后，亚氨基酸——羟脯氨酸和脯氨酸——可以溶于乙醇这类有机溶剂。

要背的就三条：白色晶体（可按结晶形状鉴别）、半胱氨酸与酪氨酸低溶解度、亚氨基酸能溶于有机溶剂。当冷门考点掌握就 OK。

### 必需氨基酸，以及"不常见氨基酸有没有密码子"

必需氨基酸有哪些？口诀"甲缬赖一本亮色书"——甲硫氨酸、缬氨酸、赖氨酸、异亮氨酸、苯丙氨酸、亮氨酸、色氨酸、苏氨酸。这个属于基础中的基础，一句带过，不再展开。

真正要紧的是：不常见的蛋白质氨基酸，有没有对应的密码子？高分笔记写清楚了——它们都是在已经合成的肽链上，由常见氨基酸经专一的酶催化修饰而来的。注意，这是一般规律：不常见的蛋白质氨基酸走的是"翻译后酶修饰"这条路，而不是直接翻译出来的。

但有两个例外：硒代半胱氨酸和吡咯赖氨酸是含有密码子的，直接由密码子翻译得到。这两个名字要背过，填空题考过：硒代半胱氨酸与吡咯赖氨酸是含有密码子的氨基酸；除此之外的不常见蛋白质氨基酸都不含密码子。

> **结论**：不常见蛋白质氨基酸 = 已合成肽链上经专一酶催化修饰而来（无密码子）；例外是硒代半胱氨酸与吡咯赖氨酸（有密码子，直接翻译）。

### 极性与非极性：谁在外、谁在内

高分笔记里有一张按极性给蛋白质氨基酸分类的表。常见疑问有三层：这张表要不要背？分类依据是什么？球状蛋白里两类氨基酸各在什么位置？要不要背这个问题，答案是：不需要完整记忆，下面教你方法。

极性代表亲水。生物体内是溶液环境、泡在水里，所以极性氨基酸往往多位于蛋白质的外部；非极性氨基酸疏水，往往躲在蛋白质的内部。

这条位置规律直接连着一个老考点：蛋白质变性的时候，侧链相互作用被瓦解打开，藏在内部的非极性氨基酸暴露出来，蛋白质随之沉淀。所以"变性导致沉淀"的分子图景，就是非极性氨基酸从里面翻到了外面。

顺带一句：疏水相互作用是稳定蛋白质结构的重要作用力——这句话本身没有问题，照着理解就行。

> **易错点**：天冬酰胺是判断题里容易出问题的考点。极性氨基酸按大规律该在外，但天冬酰胺的侧链参与氢键形成、起稳定球蛋白结构的作用，所以它在内部参与结构的构成、位于内部的较多。看到"极性氨基酸都在外部"这种绝对化说法，要留个心眼。

### 纸层析与 Rf 值：固定相居然是水

顺着极性这条线，有必要把纸层析补清楚——它是用来分离氨基酸的一种技术，考点里常拿 Rf 值做文章。纸层析有两个要点：流动相和固定相。这里有个反常识的点：纸层析的固定相是水，流动相才是有机溶剂。

把氨基酸放进这个体系：固定相的水牢牢待在原地不动，流动相跟着有机溶剂移动。越亲水的氨基酸，就越被水牢牢抓在原位，不能跟着有机溶剂流动，迁移距离就越近；越疏水的氨基酸，就越容易跟着有机溶剂走、摆脱固定相水的束缚，跑得就越远。

> **定义**：Rf 值 = 氨基酸移动的距离 ÷ 溶剂前沿移动的距离。

Rf 值说的是移动距离的事，所以它和疏水性直接挂钩：Rf 值越高的氨基酸，越不容易被固定相的水抓住，就越是非极性的疏水氨基酸；Rf 值越低，就越是极性、亲水的氨基酸。

### 极性的相对顺序：背强弱，不背名字

讲到这儿就收，不是我的风格——要讲就把极性的相对顺序给你讲清楚，因为考题里要用。同学们的困扰是：极性氨基酸、非极性氨基酸分了好多类，要不要背名字？不需要背名字，你只需要背强弱——极性的相对顺序。怎么背是关键。

强极性那一类里，精氨酸、赖氨酸是碱性氨基酸，天冬氨酸、谷氨酸是酸性氨基酸，再加上酰胺类——这几类都带着电荷（电负性），一定是亲水的。所以酸性、碱性氨基酸一定是最亲水的，这是常识，不用专门背；中间那一大段也不用背。

真正要背的是疏水端。谁最疏水？异亮氨酸最疏水——它侧链里的碳数最多，最像一个有机烷烃，所以最疏水；缬氨酸比异亮氨酸少一点，次疏水一些；再下来是亮氨酸。你发现没有，这几个含支链的氨基酸——亮氨酸、缬氨酸、异亮氨酸——全是疏水的，而且因为支链的缘故额外疏水。除了这三个，苯丙氨酸和半胱氨酸也是疏水的。

所以背法很简单：前面记住酸性、碱性氨基酸最亲水（带电，常识）；疏水端背五个——异亮氨酸、缬氨酸、亮氨酸、苯丙氨酸、半胱氨酸，其中前三个是支链氨基酸、额外疏水。中间的不用管。

### 例题：强酸性阳离子交换柱上的洗脱顺序

背这张强弱表有什么用？有些题会这样考：写出天冬氨酸、精氨酸、异亮氨酸、甘氨酸在强酸性阳离子交换柱上的洗脱顺序。离子交换的原理这里就不从头展开了，直接看这道题怎么想。

第一步，别把"阳离子交换柱"弄混：阳离子交换柱是用来结合阳离子的柱子，是"交换、吸收阳离子"的柱子，不是"含有阳离子去结合阴离子"的柱子。想通这一点：酸性氨基酸带负电，不能与阳离子交换柱很好地结合，所以最先被洗脱——四个氨基酸里明牌告诉你有一个酸性氨基酸，天冬氨酸，它第一个下来。碱性氨基酸带正电，能与阳离子交换树脂紧密结合，所以精氨酸往往是最后一个被洗脱的。

麻烦的是中间两个：异亮氨酸和甘氨酸怎么排？刚背过——异亮氨酸是支链很长的烷烃样结构，非常疏水；比起甘氨酸，它更疏水。它更疏水，洗脱就要更慢。为什么疏水反而洗脱慢？这里藏着一个信息：无论标的是阳离子还是阴离子交换柱，商品化的树脂在制造过程中都会引入疏水介质，所以疏水氨基酸与任何交换柱都结合得比较紧。你也可以换个更直观的想法：洗脱的时候拿水去洗，亲水的当然洗得快，疏水的就牢牢抓在上面不走。两条思路随便挑一条，殊途同归。

所以顺序是：天冬氨酸 → 甘氨酸 → 异亮氨酸 → 精氨酸。这张表怎么背、这道题里"电荷决定两头、疏水决定中间"的逻辑，自己再顺一遍，应该就没有问题了。

### 特殊氨基酸的官能团：看结构想性质

好多氨基酸带着各种各样的结构，官能团要掌握到什么程度？我的建议是：看到一个氨基酸，要能立刻想到它 R 基上最有辨识度的官能团，以及这个官能团的经典性质。高分笔记里有张氨基酸结构表，没事就翻一翻，把每张"脸"混熟。一个个说：

半胱氨酸——想到巯基，两个巯基可以形成二硫键。甲硫氨酸——想到硫醚结构，和半胱氨酸的巯基区分开。丝氨酸、苏氨酸——含羟基的氨基酸，可以参与磷酸化等修饰：动态生物化学里讲的磷酸化、去磷酸化，往往就是丝氨酸或苏氨酸位点的修饰。酪氨酸也含羟基，但那是酚羟基、长在芳香环上，性质和丝、苏完全不同。天冬氨酸、谷氨酸这类酸性氨基酸，酸性就来自侧链上的羧基。赖氨酸的侧链末端带一个氨基，所以是碱性氨基酸。精氨酸含胍基，碱性很强，而且胍基能发生坂口反应——这里给大家提个醒。组氨酸的咪唑基能够参与酶的酸碱催化——酸碱催化就是咪唑基负责的，这在科研界是常识；它还有缓冲功能，下面专门讲。色氨酸的侧链是一个吲哚环。

| 氨基酸 | 标志官能团 | 要记住的经典性质 |
| :--- | :--- | :--- |
| 半胱氨酸 | 巯基 | 两个巯基可形成二硫键 |
| 甲硫氨酸 | 硫醚 | 与半胱氨酸的巯基区分开 |
| 丝氨酸、苏氨酸 | 羟基 | 参与磷酸化等修饰 |
| 酪氨酸 | 酚羟基（芳香环上） | 性质与丝、苏完全不同 |
| 天冬氨酸、谷氨酸 | 侧链羧基 | 酸性氨基酸 |
| 赖氨酸 | 侧链末端氨基 | 碱性氨基酸 |
| 精氨酸 | 胍基 | 碱性很强；可发生坂口反应 |
| 组氨酸 | 咪唑基 | 参与酶的酸碱催化；有缓冲功能 |
| 色氨酸 | 吲哚环 | 含氮杂环 |

有同学问：色氨酸既有苯环又有杂环，到底算哪类？这个问题其实很简单：同一个氨基酸完全可以从不同角度看。按芳香族来分，它就是芳香族氨基酸；按环的结构来分，吲哚环是个含氮杂环。怎么分类不关键，知道它的本质是什么就可以了。

### 组氨酸的缓冲能力：答案在 R 基上

组氨酸有缓冲能力，这事都知道。但缓冲能力的来源，到底是因为 pI 接近 7，还是 pK_R 接近 7？答案很简单：真正关键的点在于组氨酸侧链上有个咪唑基，这个可解离基团的 pKa 接近中性范围——高分笔记里给的这个 pK 大概是 6.0 左右。

缓冲体系是什么意思？就是一个基团既可以比较容易地接受氢，也可以比较容易地把氢释放出去。组氨酸能在"接受一个质子"和"失去一个质子"之间来回切换，充当一个调节者的角色，把溶液的 pH 控制在一定范围内——这就是缓冲。

这个问题不用死记，动脑子想就能懂：除了组氨酸，还有好多氨基酸的 pI 也接近 7，那别的氨基酸怎么就没有缓冲能力，偏偏组氨酸有？那肯定是组氨酸的 R 基里面有作用。动脑子学，就这个思路。

> **结论**：组氨酸的缓冲能力来自侧链咪唑基（$pK_R \approx 6.0$，接近中性），而不是"pI 接近 7"。

### 氨基酸的解离与等电点：把 pI 公式从头推一遍

关于酸碱性氨基酸的解离问题，正课讲得并不特别全面，这里讲全面——接下来这一大段请不要跳过，把内容全部掌握：为什么酸性、碱性氨基酸按这个顺序解离，解离常数怎么来的，平衡方程又是怎么来的。

#### 三步走：从完全质子化到完全去质子化

高中讲过氨基酸的结构式。为了方便描述电性，我们把质子化、去质子化对应的正号、负号标上——接下来全部用这个写法。

假设现在环境特别特别酸，酸到倒牙：氢离子非常丰富。先别管等电点是什么意思，只记住"特别酸"意味着 pH 极小，必然小于某个数——那个数就是 pI。氢多，就会攻占氨基酸上两个可解离的位置，把负号全填成正的，得到完全质子化的氨基酸（记作 A⁺）。

然后随着碱性增强——溶液里有更多的 OH⁻，它们会吸引氢往前走、把 OH⁻ 结合掉——氢开始一个个脱落。第一个脱下来的是谁？是羧基上的氢。因为高中化学讲过：羧基的酸性比氨基强、pKa 比氨基小，酸性强、pKa 小的基团氢先掉，这是高中化学压轴题的常客。羧基的氢脱出去，就回到兼性离子 A⁰。注意，是人们把此时溶液的 pH 定义为 pI：氨基酸恰好全部以兼性离子状态存在时的那个 pH，就叫等电点，所以此刻 pI = pH。三句话就把等电点讲明白了。

> **定义**：兼性离子（A⁰）——同一个分子上带着一个正电荷和一个负电荷（氨基质子化、羧基去质子化）、净电荷为零的状态；此时溶液的 pH 被定义为等电点 pI。

碱性再增强，氨基上那个氢也遭不住了，脱掉，变成完全去质子化的氨基酸 A⁻。整个图景：从强酸里的完全质子化 A⁺，到兼性离子 A⁰，再到强碱里的完全去质子化 A⁻——这就是氨基酸随酸碱过渡的全过程，也是接下来所有推导的基础。

#### 解离常数与 pI 公式

高中化学（选修二）讲过化学平衡：A + B → C + D，平衡常数 K = [C][D] / [A][B]，有化学计量数就上次方。氨基酸的解离式也有同样的规律：完全质子化的氨基酸解离出一个氢，经 $K_1$ 得到 A⁰ 兼性离子；A⁰ 再解离出一个氢，得到 A⁻。两个方程对应的常数：

$$K_1 = \frac{[H^+][A^0]}{[A^+]}, \qquad K_2 = \frac{[H^+][A^-]}{[A^0]}$$

注意力集中的同学看好了：两式相乘，$K_1 K_2 = [H^+]^2 \cdot [A^-]/[A^+]$。而在等电点，兼性离子对外不呈现电性，意味着 $[A^-] = [A^+]$，这两项正好消掉，剩下 $K_1 K_2 = [H^+]^2$。

对这个式子取对数，用高中数学的两个性质：两个对数相加对应真数相乘，真数上的平方可以拿下来。$-\log[H^+]^2 = -\log(K_1 K_2)$，也就是 $2\,\mathrm{pH} = pK_1 + pK_2$（pH 的定义就是负 log 氢离子浓度，负 log 什么就等于 p 什么）。于是：

$$pI = \frac{pK_1 + pK_2}{2}$$

有人会说：这些我都知道，你讲半天不是废话？不是——有些同学真不知道，而且接下来这两个多数人就不知道了，虚心听。

例：已知甘氨酸 $pK_1 = 2.34$、$pK_2 = 9.60$，求 pI。直接套公式，$(2.34 + 9.60)/2 = 5.97$，完事。这是一般学校会考的题。

#### 谷氨酸：优先 α-碳原则

如果你要考中科院，题目就复杂了。谷氨酸是酸性氨基酸，α-碳上有一个羧基，R 基里还有一个羧基——三个可解离基团，问题就复杂化了。随着碱性增强，哪个氢离子先解离？

这里先立一条规则：**优先 α-碳原则**——在不违反化学里大小规律的前提下，优先 α-碳上的氢原子解离。这条原则有非常明确的文献支撑。于是谷氨酸的解离次序是：第一步，α-碳上的羧基先解离，R 基上的羧基先别动，解离后变成 COO⁻；第二步，比较剩下两个基团，化学的基本原则是羧基比氨基更容易先解离，所以第二步轮到 R 基羧基（其解离常数记作 $K_R$）；最后一步才轮到氨基。

特别注意：$K_1$、$K_2$ 不是按反应发生的时间顺序定义的，而是按基团的性质定义的——$K_1$ 就是 α-碳上羧基的解离常数，$K_2$ 就是 α-碳上氨基的解离常数，R 基羧基的是 $K_R$。这个定义不随解离次序改变。

那 pI 怎么算？兼性离子（净电荷为零）夹在第一步与第二步之间，所以公式里"$pK_2$ 的位置"被 $pK_R$ 取代，pI 由前两步决定。第三步（氨基解离）可以忽略不计——化学的基本原则是每多一步解离，浓度就低一个层级（指数式的关系），第三步的解离常数往往比前面的小上好几个数量级，不影响大局。所以：

$$pI(\text{谷氨酸}) = \frac{pK_1 + pK_R}{2} = \frac{2.19 + 4.25}{2} = 3.22 \approx 3.2$$

如果你还用 $(pK_1 + pK_2)/2$ 就错了。考试会给你谷氨酸的 $K_1$、$K_R$ 和 $K_2$，问 pI 是多少——你要用 $pK_1$（α-羧基）和 $pK_R$，不考虑 α-氨基的 $pK_2$。

#### 赖氨酸：碱性氨基酸反过来算

碱性的赖、精、组怎么办？以赖氨酸为例，依然从完全质子化的状态看起。第一步还是优先 α-碳上的羧基先解离——优先 α-碳原则照旧，同时羧基酸性本来也强。第二步比较的是两个氨基：一个是 α-碳上的氨基，一个是侧链末端的氨基，两个氨基的强弱差不出明显大小的时候，优先 α-碳原则让下一步解离 α-氨基，而不是侧链氨基。最后一步，侧链氨基当然也逃不过，照样解离。

碱性氨基酸相当于解离的反过程，要反过来着看：净电荷为零的兼性离子，夹在 α-氨基解离（$K_2$）与侧链氨基解离（$K_R$）之间，只看"框里"的这两步，所以：

$$pI(\text{碱性氨基酸}) = \frac{pK_2 + pK_R}{2}$$

笔记上为什么这么总结，讲到这原因已经说透了。给个复习策略：如果你报考的学校很少考这部分，不必像我这样一步步推导，把公式记住就好；如果往年真题考过酸碱平衡的推导或计算，就必须把这套推导方式学会。不同的学生，分而治之，方法不一样。

#### "净电荷为零"是个文字游戏

等电点时"静电荷为零"，是不是说分子上完全没有电荷？这是个文字游戏。pH = pI 时氨基酸净电荷为零，没问题——注意"净"字：净盈亏的净。你总不能说"我没亏过也没赢过"，就说这人从没经手过钱吧？只能说分子上所有正电、负电的电荷加起来等于零而已。兼性离子一端是氨基、一端是羧基，分子上明明囤着一个正电荷、一个负电荷，只是一加一减相互抵消了。

> **易错点**：判断题常考"等电点时氨基酸主要以兼性离子存在"——对，原因就是正、负电荷相互抵消，静电荷（净电荷）为零；但这绝不等于"分子基本不带电"。

### 甲醛滴定法：把终点从 pH 12~13 拉到 9

顺着解离这个知识点，把甲醛滴定法也讲了。问题是这样来的：用正常的化学试剂去滴定氨基酸，反应终点往往存在 pH 过高的问题——别管为什么，先接受这个事实——终点 pH 太高，就没法常规滴定。所以要想个化学办法，把反应终点降下来。

办法就出在甲醛上。甲醛能与氨基酸中的氨基生成羟甲基的结构。甲醛过量时，游离的氨基就会被消耗；氨基这边被消耗，整个解离平衡就要往右移；右移就释放出更多的氢；氢多了，反应终点的 pH 就变低了——正好解决了氨基酸反应终点 pH 过高的问题。终点从 pH 12~13 降到了 9。

这个方法还能用来判断蛋白质的水解（或合成）程度。关键在一句常识：蛋白质里不存在游离的氨基，只有长链被水解打开之后，游离的氨基、羧基才暴露出来。所以做甲醛滴定时，如果你发现甲醛滴定量过大，说明游离氨基多了、游离氨基酸多了，蛋白质分解程度就高；反过来，甲醛用得少，说明蛋白质基本没被分解成游离氨基酸，结构还相对完整。

### 茚三酮反应：19 种紫色、2 种亮黄

茚三酮反应说的是：茚三酮在弱酸性条件下与 α-氨基酸共热，引起 α-氨基酸氧化脱氨；脱下来的氨把茚三酮还原，还原型茚三酮再与另一分子茚三酮作用，生成一个紫色产物，它在 570 nm 处有最大吸收峰。这是 19 种"普通"氨基酸走的路径。

脯氨酸和羟脯氨酸不一样：它们发生茚三酮反应生成的是亮黄色产物，最大吸收峰在 440 nm。所以判断题"蛋白质氨基酸与茚三酮反应都呈紫色吗"——不是，脯氨酸和羟脯氨酸生成亮黄色产物。颜色名字、两个吸收峰数值，全部要背下来，填空题、判断题都考过。

为什么这两个特殊？原理不需要深究，出在结构上：脯氨酸和羟脯氨酸有含氮的环状结构，不像普通氨基酸那样带着 α-位游离的一级氨基；一级氨基结构不同，生成的产物就不同。这个反应的应用也很重要：可以检测和定量氨基酸——一定要背好。

### 旋光性、L/D 构型与顺反异构：三个概念别串

什么是 L/D 构型？什么是旋光方向？顺反异构又是什么？这三个名字听起来都在说"立体"的事，特别容易串。不要害怕，给你分开。

L/D 构型指的是分子的构型：对氨基酸来说，是在特定投影规则之下，描述它手性中心的相对构型——它是化学上的一种书写标记。构成蛋白质的常见氨基酸，除了甘氨酸没有手性中心之外，一般都是 L-氨基酸。旋光方向（左旋、右旋）则是实验测出来的一个参数，跟 L/D 没有必然的逻辑联系——别看 L、D 像是"左"和"右"，旋光性和 L/D 构型一点关系也没有：一个是测出来的，一个是化学写法。顺反异构又是另一个概念：它描述的是某个结构在不能自由旋转（类似双键）的时候，两边基团的空间相对位置——高中加成反应里的顺式加成、反式加成，玩的就是这个。

| 概念 | 说的是什么 | 怎么来的 |
| :--- | :--- | :--- |
| L/D 构型 | 手性中心的相对构型 | 特定投影规则下的化学标记 |
| 旋光方向 | 左旋 / 右旋 | 实验测出来的参数 |
| 顺反异构 | 不能自由旋转处两侧基团的空间相对位置 | 类似双键的几何关系 |

落到肽链上，考点来了：肽链里的肽键一般是反式构型；但如果出现"某个氨基酸连一个脯氨酸"这样的结构（X-Pro），它可以是反式、也可以是顺式——X-Pro 的出现大大提高了顺式构型出现的概率，不过整条肽链仍然以反式为主。再补一条常识：天然氨基酸多为 L 构型；甘氨酸没有手性中心，不用 L、D 来描述。

### 亲和层析：从 His 标签讲起

除了纸层析和柱层析，有同学想了解亲和层析的原理。考试作答用高分笔记里那份标准定义就行；这里我按实验室里的真实做法，把原理给你讲成人话。

分离目标蛋白时，我们会先给这个蛋白加一个 His 标签——组氨酸标签，六个组氨酸连成一串。这个标签不影响蛋白的表达、也不影响蛋白的功能，因为它是个很"中性"的标签。加了之后的好处马上就来：做亲和层析时，我们会用金属镍。镍是一种天然的、能与咪唑发生配位作用的金属——金属镍碰上咪唑，它们两个就会"贴贴"。而组氨酸里恰恰含着咪唑。

于是流程就顺了：把带上 His 标签的目标蛋白放到层析柱里流过，杂蛋白、别的蛋白都直接流走，而含组氨酸标签（含咪唑）的目的蛋白则与镍柱紧紧结合在一起。接着用水洗几遍，把杂蛋白洗掉；再用纯的咪唑溶液慢慢洗，最后就把目的蛋白洗脱下来了——蛋白就这么分离出来了。

复杂蛋白样品通过柱子之后，只保留与固定相特异性结合的蛋白、其余杂蛋白被洗脱，这就是亲和层析。它的原理就是用配位作用、抗原与抗体、酶与底物这类特异性结合来实现分离；最大的优点是选择性特别高，最后纯度也比较高，操作也比较简单。

### 双向电泳：先等电点，后分子量

有同学希望讲一下双向电泳。为什么叫"双向"？第一向，先通过等电聚焦电泳分离；第二向，把凝胶水平放置到第二块平板上，再通过 SDS-PAGE 分离。考点就两条：第一向是等电聚焦电泳，按 pI 的差异来分离；第二向是 SDS-PAGE，按分子量来分离。你要记的就是谁先谁后：先按等电点分，再按分子量分。

为什么必须是这个顺序？如果反过来先做 SDS-PAGE，蛋白质就被 SDS 给变性了，等电点的差异就显现不出来了，第二步等电聚焦就做不成。所以只能先根据等电点进行等电聚焦电泳，再根据分子量进行 SDS-PAGE。

### 肽键的结构特点：本质、双键性、肽平面与顺反构型

肽键具有一定的双键性质：不能自由旋转；键长比单键短，但略长于双键。参与肽键形成的六个原子不能自由转动、位于同一平面，这个平面叫肽平面，也叫酰胺平面。肽链里的肽键一般是反式构型，反式与顺式之比约为 1000:1；X-Pro（某个氨基酸连脯氨酸）可以增加顺式构型的占比。

这一块我强调一遍，你掌握四个考点就够了。第一，肽键的本质：一个氨基酸的 α-氨基与另一个氨基酸的 α-羧基缩合之后形成的键，本质上是一个酰胺键——酰胺键在蛋白质里就叫肽键。第二，为什么说它有双键性质？因为肽键里的电子可以发生一种叫"共振离域"的东西：C–N 酰胺键不是普通单键，有一定的共振离域效果，于是产生了双键特性。听不懂没关系，这是讲化学的，不用背。第三，一定要记住肽键不能自由旋转——不能自由旋转就会产生一个面，这个面就是肽平面。肽平面由肽键的六个原子构成：C、O、N、H，加上两头的 Cα₁、Cα₂。这是名词解释考点：参与肽键形成的六个原子不能自由转动、处于同一平面，这个平面就是肽平面。第四，一般肽键是反式构型——只要有双键就会有顺反；但 X-Pro 可以增加顺式构型的占比，这点常考。

### 对角线电泳：把"确定二硫键位置"画成一张图

接下来讲对角线电泳，请耐心看，这部分我讲得很长。对角线电泳是一种用来确定二硫键位置的实验方法。我说这个方法是天才般的创造力：它能把最基本的原理转化成一个实验——这种思想是将来前沿科学创造实验方法的最基本办法。当然，更多情况下是先有实验、后有原理。想出这个方法的人，多多少少是个天才。整个流程先看这张图：

```text
长肽链
  |  胃蛋白酶切成小肽段（专一性低、切点多、肽段小）
  v
第一向电泳：A、B、C……按各自迁移率排开成一条带
  |  沿第一向切下整条带，暴露在过甲酸蒸汽中
  v
左旋 90 度，贴回点样端，跑第二向电泳
  |
  +-- 无二硫键：无事发生，迁移率不变
  |             第二向走的距离 = 第一向走过的距离
  |             -> 落点构成正方形，全部连成对角线
  +-- 有二硫键：肽段变小 + 负电荷增加，迁移率改变
                -> 偏离对角线（茚三酮显色定位）
```

这张图就是对角线电泳的全过程：两次电泳夹一次过甲酸处理，最后看谁偏离对角线。下面一段段拆开讲。

#### 先把知识备齐

二硫键：肽链链内或链间，两个半胱氨酸残基的巯基之间氧化而成的键——一条链内部的叫链内二硫键，两条链之间的叫链间二硫键。

胃蛋白酶：一种专一性很低的酶。想想我们的胃，什么样的蛋白质都能消化，不可能只消化一部分、剩下的就没办法了，所以它的专一性非常低。专一性低带来一个后果：切点很多，一条链到处切，切出来的每一小段肽段就会比较小。

还有一点：胃蛋白酶在胃里酸性强，pH 等于 2.0。这个强酸环境能防止二硫键发生交换反应——不然二硫键断开之后跟别的巯基交换，就不是原来的构象构型了；酸性条件保证构象和构型跟原来一样。

过甲酸：能使二硫键断裂，断裂之后还会进一步氧化成磺酸基。磺酸基具体是什么，先不探究。

电泳：粒子在外加电场作用下，朝着与自身电性相反的方向移动的现象；单位时间内粒子移动的距离就是速度，这个速度叫迁移率，它与粒子的大小、带电量和形状都有关。

最后，茚三酮可以使蛋白质显色。

#### 第一次电泳：先把肽段分开

一条长的肽链，你大概不好确定哪里有二硫键，所以先用胃蛋白酶把它切成非常多的小肽段——之所以选胃蛋白酶，就是因为它专一性低、切点多、肽段尽可能小，实验就尽可能精确。

把多肽混合物点在加有电场的极板上跑第一向电泳：A 类肽段迁移率是 A，就走 A 那么多距离；B 走 B 的距离；C 走 C 的距离——A、B、C 三种肽段就这样被分开了。

但这不够：我们只是分开了它们，还没鉴定出 A、B、C 里哪一个肽段含有二硫键。

#### 过甲酸蒸汽：有事发生与无事发生

把整条带切下来，暴露在过甲酸蒸汽里。如果这些肽段里含有二硫键，二硫键就会被过甲酸破坏掉：一条长肽段断成两小条，表现出来的就是肽段变小；而且二硫键被氧化成磺酸基之后，负电荷比原来多了——二硫键本身不怎么带电，氧化成两个磺酸基就都带电了。所以填空题考点就两句话：肽段变小、负电荷增加。

如果不含二硫键呢？过甲酸处理之后无事发生，是什么还是什么。

#### 左旋 90 度再跑一次：正方形与对角线

处理过的胶条左旋 90 度，再进行第二次电泳。先看一种极端情况：所有肽段都没有二硫键，无事发生。旋转之后，每个肽段在第二向上走的距离，仍然等于它第一向走过的距离——橙色（A）仍走 A，绿色（B）仍走 B，紫色（C）仍走 C。

回忆第一向上相邻色带的间距：橙到绿是 B−A，绿到紫是 C−B。旋转之后，竖直方向的间距还是 B−A，跟水平方向的 B−A 相等——横竖一样，这就是个正方形，A 和 B 恰好是一对对角顶点。同理，橙到紫竖直方向差 C−A，水平方向 (B−A) + (C−B) 也等于 C−A，外面还是个正方形，C 也在顶点上。三个点都落在正方形的顶点上，A 和 C 连起来就是一条对角线，B 也在这条对角线上。把握住"正方形"这个要点，这一段就通了。

所以：没有二硫键，无事发生，所有肽段都分布在该正方形的对角线上。若有二硫键呢？那些肽段被过甲酸破坏，肽段变小、电荷更负，加速度变了，第二向就不再走原来的距离——它们就会偏离对角线的位置。最后用茚三酮染色使蛋白质显色，确定每个点的位置：哪个点偏离对角线，哪个肽段就含有二硫键。

#### 课本图的极性问题与应试答法

再做一个深度思考。加速度是不是 $a = QE/m$？负电荷增加，就是 Q 变了；质量也变了——变小了。那如果电场力也变小了呢？加速度就可能不变，迁移距离仍然不变，肽段就有可能还分布在对角线上，导致实验出问题。

把这个事看清楚。初速度为零、加速度恒定时 $s = \tfrac{1}{2}at^2$（v = at，v–t 图的面积就是路程）；而加速度等于电场力除以 m，电场力等于电荷量乘电场强度，电场强度是我们自己加的、不变。若按课本图那样摆——左边正极、右边负极——负电荷增加之后，右边给它的排斥力增加，它在前进方向上受到的电场力反而减少；F 电减少、m 也减少，a 就有可能不变，肽段仍落在对角线上，含二硫键的肽段被处理后分不出来了，那就麻烦了。所以电场应该改成左边负极、右边正极：这样负电荷增加，往右的力增加，F 电上升、m 减小，加速度一定上升，必然偏离对角线。天津大学董晓燕老师那版课本上的图，在极性方向上是不严谨的，原因就在这。

应试的时候这个题不用想太多。它不考你画图，也不考数学、物理原理。填空题就考过甲酸处理之后肽段怎么变——把"变小""负电荷增加"两个空填上，满分。问答题若考"简述对角线电泳的原理"，把上面整个流程整理成文字写下来，就是满分答案。这套推导听起来啰嗦，但我敢保证：走完这一遍，你对对角线电泳的了解已经非常清楚了。

### 构象与构型：象是长相，形是风骨

构型和构象容易混淆，如何区分？高分笔记第一章绪论里其实提到过。很简单，你想想"形"和"象"各是什么意思：象指的是一个人长啥样，形往往说的是一个人的风骨。你说一个人长什么样容易改变，还是他的风骨容易改变？肯定是长相——相由心生嘛，心一变，相就变了。所以构象容易改变：它的改变不要求共价键的断裂和重新形成，往往扭一个位置，构象就变了。

构型则是一个人的骨头：骨头不容易改变，想要改变就得粉身碎骨——把共价键打碎，再重新接上，那才叫构型的改变。所以构型不能靠"扭一下"：扭一个位置那不叫构型的改变，叫构象的改变；构型必须把共价键拆开、连到别的地方去。

> **结论**：构象改变不要求共价键断裂（扭一下就变）；构型改变必须断裂并重建共价键（粉身碎骨）。用汉语字面记：象是长相，形是风骨，就不会混淆。

### 一级结构测定：从目标反推

蛋白质一级结构的测定方法里提到好多酶、好多化学试剂，篇幅太长我不一一列，你也不用全背——里面的关键酶挑几个掌握、有个大概印象（哪个酶干什么、哪个试剂能干什么）就可以。这里我想讲的是：宏观上、理解上，蛋白质一级结构测定到底是怎么个事。学蛋白生化很容易犯的毛病，是背了一堆试剂，却不知道每一步都在干嘛，一团混乱。咱们从目标反推，你就清楚了。

最终目标是什么？测出整条蛋白质从 N 端到 C 端的完整氨基酸序列，以及必要的共价连接关系。可蛋白动辄几百个氨基酸，从第一个直接测到第 500 个肯定很困难。所以第一步，先看看这个蛋白质由多少条肽链组成——先拆链。多条链一般是亚基通过非共价作用结合的，用尿素、盐酸胍这类破坏非共价作用的化学试剂把不同的链拆开。注意：拆链和拆二硫键不是一个事儿。如果两条链还用二硫键连着，那你必须用还原剂把二硫键拆开——前面刚讲过。

拆完链才进入序列分析。为什么还要切成小片段？因为短肽往往比一条超长的多肽容易测。所以用特异性蛋白酶切割，测短肽。关键来了：如果你只用一种办法切，你只会得到 A、B、C 这些片段，但你不知道它们怎么排列。于是换第二种切割方法，得到 D、E、F 这些片段——两套片段之间有重叠区域。比如第一套切出 ABCDE，第二套切出 DEFGH，看到 D 和 E 重叠了，就能拼成 ABCDEFGH。说白了，就是用不同切割方法产生的信息交叉验证，把完整序列恢复出来。

最后才确定二硫键的位置。注意这个细节：二硫键是先切断的——切断它是为了把长链变短链；但"确定位置"要放在最后，序列测出来了才能定。为什么？序列都没测出来，你怎么知道半胱氨酸在什么地方？万一这蛋白压根没有半胱氨酸，你不白测了吗？所以切二硫键是第一步，测二硫键是最后一步——对角线电泳就用在最后这一步。

```text
拆链：先看蛋白质由几条肽链组成
      亚基间靠非共价作用结合 —— 用尿素、盐酸胍等拆开
      链间还有二硫键 —— 用还原剂拆开（拆链和拆二硫键是两件事）
  |
  |  用特异性蛋白酶把长链切成小片段
  |  只用一种切法只能得到片段、不知道怎么排 —— 换第二种切法
  v
测与拼：测每条小片段的序列，两套片段靠重叠区交叉拼接
      第一套 ABCDE，第二套 DEFGH，重叠 DE —— 拼出 ABCDEFGH
  |
  v
最后确定二硫键的位置（对角线电泳）
```

从上往下读就是全部流程：拆链、切片段、测与拼、最后定二硫键——每一步为什么这么做，正文里都有交代。

### 固相合成：保护、活化与合成方向

保护基与活化剂要掌握到什么程度？蛋白质是可以固相合成的；合成里要用好多种试剂，但高分笔记没列，所以不需要掌握那么多，先把"为什么要这么做"理解了。

假设你想让氨基酸 A 和氨基酸 B 形成一个肽键。问题出在哪？每个氨基酸都必须既有氨基又有羧基，那到底是 A 的氨基连 B 的羧基，还是 A 的羧基连 B 的氨基？这就闹不清楚了。所以你需要保护基：保护住一个氨基酸的氨基或者羧基，让它只剩一端去反应。光这样还不够，反应本身还需要活化——一个被保护、一个被活化，接肽的顺序也就定下来了。

为什么需要活化？提示一下：氨基和羧基在普通化学条件下不是一个很快、很容易自发发生的反应，必须先活化，氨基和羧基才能在溶液中完成连接。一句话总结：保护，是不让不该反应的地方反应；活化，是让真正需要反应的地方反应。至于具体的活化剂叫什么名字，能有余力就背，没有余力就别背——你一定要知道的是"为什么要保护、为什么要活化"。哪些保护基保护氨基、哪些保护羧基，我不建议背，不太考。

最后是最重要的考点：如果你什么都不背，也要背这一条——肽链的固相合成，人工合成时方向是从 C 端到 N 端；而生物体翻译（分子生物学里讲的）是从 N 端到 C 端。人工合成恰好是反的。

> **易错点**：合成方向——生物体翻译 N → C，人工固相合成 C → N，方向相反。这个考点必背。

### 本讲提到的题目

这一讲课上点到的题和例题，集中放在这里；每道题的解析依据都在正文里。

**判断题：组成蛋白质的 20 种氨基酸都是 α-氨基酸。**
答：规范口径可判"对"——脯氨酸虽是亚氨基酸，但多数教材仍把它算作 α-氨基酸；我个人的倾向是判"错"，判断题没有白问的，问到你了肯定有蹊跷。（依据见"脯氨酸"一节）

**思考题：组氨酸的缓冲能力，究竟是因为 pI 接近 7，还是 pK_R 接近 7？**
答：源于侧链咪唑基，$pK_R \approx 6.0$、接近中性，可在得质子与失质子之间来回切换。反证：pI 接近 7 的氨基酸不止组氨酸一个，别的没有缓冲能力，说明关键在 R 基。（依据见"组氨酸的缓冲能力"一节）

**计算题：已知甘氨酸 $pK_1 = 2.34$、$pK_2 = 9.60$，求 pI。**
答：$pI = (2.34 + 9.60)/2 = 5.97$。（依据见"解离常数与 pI 公式"一节）

**计算题：谷氨酸是酸性氨基酸，α-碳上有羧基、R 基里还有一个羧基；题目会同时给出 K1、K_R 与 K2，求 pI。**
答：$pI = (pK_1 + pK_R)/2$；以 $pK_1 = 2.19$、$pK_R = 4.25$ 计，$(2.19 + 4.25)/2 \approx 3.2$。α-氨基的 $pK_2$ 不进公式。（依据见"谷氨酸：优先 α-碳原则"一节）

**简答题：写出天冬氨酸、精氨酸、异亮氨酸、甘氨酸在强酸性阳离子交换柱上的洗脱顺序。**
答：天冬氨酸 → 甘氨酸 → 异亮氨酸 → 精氨酸。电荷决定两头：酸性氨基酸带负电、不与阳离子交换树脂结合，最先洗脱；碱性氨基酸带正电、结合最紧，最后洗脱。疏水决定中间：商品化树脂都引入疏水介质，异亮氨酸比甘氨酸疏水、洗脱更慢。（依据见"例题"一节）

**填空题：对角线电泳中，含二硫键的肽段经过甲酸蒸汽处理后发生什么变化？**
答：肽段变小；负电荷增加。（依据见"过甲酸蒸汽"一节）

**问答题：简述对角线电泳的原理。**
答：胃蛋白酶把长链切成小肽段 → 第一向电泳按迁移率分开 → 切下整条带用过甲酸蒸汽处理（含二硫键者变小且负电荷增加）→ 左旋 90 度跑第二向 → 无二硫键的肽段迁移率不变、全部落在对角线上，偏离对角线者即含二硫键的肽段，用茚三酮显色定位。（依据见"对角线电泳"一节）
