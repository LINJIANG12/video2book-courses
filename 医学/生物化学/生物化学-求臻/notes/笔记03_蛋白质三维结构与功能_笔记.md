# 蛋白质三维结构与功能

## 二级结构

### 只由主链原子定义的局部构象

* **二级结构（secondary structure）**

    * > **定义**：蛋白质分子中某一肽链局部的空间结构，即多肽链中主链原子的相对空间排布。

    * 定义的两个限定是「局部」与「主链原子」：只看某一段肽链，且只看 N—Cα—C 重复而成的主链骨架，不看整条链。

    * 讨论骨架走向时略去侧链与氢原子，讲到成键时酰胺氢必须数回来——看骨架与看成键是两件事，并不矛盾。

    * 侧链不参与二级结构的形成，α-螺旋、β-折叠、β-转角、Ω 环都不涉及侧链基团。

    * 维持二级结构的化学键只有一种：氢键，成键两端是羰基氧（C=O）与酰胺氢（N—H）。

    * 只要是多肽链中局部的一段空间结构都算二级结构；研究清楚、反复出现的典型结构有四种：α-螺旋、β-折叠，以及属非典型的 β-转角和 Ω 环。

    * α-螺旋是已知蛋白质二级结构中含量最多的一种。

### α-螺旋的参数

* **α-螺旋（α-helix）**

    * 结构由一串肽平面沿螺旋轴盘旋而成，每个肽平面是一块平板，相邻两个肽平面共用中间的 α-碳，α-碳就是两块平板的铰接点。

    * 一个肽平面由肽键本身、两端的两个 α-碳、羰基氧和酰胺氢共同构成，这些原子共面。

    * 每圈 3.6 个氨基酸残基，约等于 4 个；转满一圈跨过 3 个完整残基还多走 0.6 个，写参数必须写 3.6。

    * 螺距 0.54 nm，即每转一圈沿螺旋轴上升的高度。

    * α-螺旋是右手螺旋。

    * 蛋白质中约 1/4 的氨基酸残基以 α-螺旋形式存在。

    * 整个螺旋记作 3.6₁₃：3.6 是每圈残基数，13 是氢键闭环内的原子数。

    * 13 元环由 11 个主链原子（C、N、Cα 交替）加羰基氧和酰胺氢构成。

| 参数 | 数值 | 说明 |
| :--- | :--- | :--- |
| 每圈残基数 | 3.6（约 4） | 一个螺旋重复单位跨过的残基数 |
| 螺距 | 0.54 nm | 每转一圈沿螺旋轴上升的高度 |
| 手性 | 右手 | 方向不能记反 |
| 氢键配对（残基口径） | 第 n 个残基 C=O 与第 n+4 个残基 N—H | — |
| 氢键配对（肽键口径） | 第 n 个肽键 C=O 与第 n+3 个肽键 N—H | 同一根氢键 |
| 闭环大小 | 13 元环 | 整个螺旋记作 3.6₁₃ |
| 占残基比例 | 约 1/4 | 已测蛋白质中的统计 |

### α-螺旋的氢键配对

* 认方向：任一氨基酸朝 C 端一侧的肽键是它的羧基，朝 N 端一侧的肽键是它的氨基，因此整条肽链 N 端在上、C 端在下。

* 按氨基酸残基编号：第 n 个残基羧基上的氧与第 n+4 个残基氨基上的氢形成氢键。

* 按肽键（肽平面）编号：第 n 个肽键羰基上的氧与第 n+3 个肽键上的酰胺氢形成氢键。

* 两套数法说的是同一根氢键，只是一个按残基编号、一个按肽键（肽基）编号。

* 3.6 个残基一圈，第 n+4 个残基差不多是转一圈之后的那一个，它的 N—H 正好落在第 n 个残基 C=O 的对面。

* α-螺旋最大程度地利用了氢键：螺旋内部每个残基的 C=O 与 N—H 几乎都找到了配对，没有空着的，所以它在蛋白质结构中广泛存在。

* 真实结构中这些氢键几乎平行于螺旋轴，从侧面看是一道道竖直的横撑，把一圈一圈的主链撑住。

```text
N 端
  Cα(n)     ── C=O ⋯⋯⋯⋯┐
  Cα(n+1)              ⋮
  Cα(n+2)              ⋮   氢键
  Cα(n+3)              ⋮
  Cα(n+4)   ── N—H ⋯⋯⋯┘
C 端
```

> **易错点**：N 与 N+4 说的是氨基酸残基，N 与 N+3 说的是肽键；题目里出现这两个数字，先看清它数的是残基还是肽键。

### 侧链与螺旋倾向性

* 侧链 R 基团不参与 α-螺旋的形成，但「不参与」不等于「没影响」。

* 侧链基团的大小、形态、带电状态都会影响螺旋能不能形成、形成以后稳不稳定。

* 某一段肽链形成 α-螺旋的倾向性，取决于这段肽链里氨基酸残基的本性和序列。

* 序列就是一级结构，一级结构决定二级、三级、四级结构。

* α-螺旋一圈一圈地盘着，受力时能发生可恢复的形变，所以像弹簧一样弹性好。

* 弹性好且 α-螺旋含量丰富的典型：毛发中的角蛋白、肌肉中的肌球蛋白、血凝块中的纤维蛋白。

### β-折叠的骨架与链间氢键

* **β-折叠（β-sheet）**

    * 形状是折纸状或锯齿状：每个小平面仍是一个肽平面，肽平面之间由 α-碳连接，相邻 α-碳一上一下地交替，主链被折成一列锯齿。

    * 两条肽链靠得足够近时，一条链肽平面上的羰基氧与另一条链上的酰胺氢形成氢键，靠这种链间氢键把几条锯齿带并成一片。

    * 与 α-螺旋的关键区别：α-螺旋的氢键是同一条肽链内部第 n 个残基拉第 n+4 个残基；β-折叠的氢键主要发生在两条链之间。

    * 折叠起来紧凑、拉开有余量，像折纸一样，所以 β-折叠含量高的蚕丝延展性特别好。

### 平行与反平行

* 肽链有方向，方向就是从 N 端到 C 端；判断链方向看 α-碳两侧，一侧连氨基氮、另一侧连羧基碳，从氨基走向羧基即 N 端到 C 端。

* 两条链方向相反为反平行，几条链同向并排为平行。

* 平行与反平行跟「几条链」没有必然关系。

* 平行的 β-折叠大多数由不同的肽链并成。

* 反平行的 β-折叠既可以在不同肽链之间形成，也可以在同一条肽链里折回来形成。

```text
反平行：两条链方向相反

  N ─────────────────────────→ C
        ┆   ┆   ┆   ┆   ┆
  C ←───────────────────────── N


平行：两条链方向相同

  N ─────────────────────────→ C
        ╲   ╲   ╲   ╲   ╲
  N ─────────────────────────→ C
```

### 两类蛋白质中的 β-折叠分布

* 纤维状蛋白质中主要是反平行的 β-折叠，而且氢键存在于不同的肽链之间。

* 球状蛋白质中反平行和平行都有。

* 球状蛋白质的 β-折叠氢键可以存在于不同的肽链之间、不同的蛋白质分子之间，也可以存在于同一条肽链的不同肽段之间。

* 蚕丝就是纤维状蛋白：一根蚕丝里有许多反平行 β-折叠并成的片层，所以延展性特别好。

### β-转角与 Ω 环

* **β-转角（β-turn）**

    * 肽链进行 180 度回折时，那个转折部位就是 β-转角。

    * 由 4 个氨基酸残基组成，第 1 个残基的羰基氧与第 4 个残基的酰胺氢形成氢键，把这个回折固定住。

    * 分两种类型，类型本身不用记，都属于 β-转角、都是 180 度回折的部位。

    * 经常出现在球状蛋白的表面——球面要有拐弯和 180 度回折，链才能折回来把球面铺出来。

    * 甘氨酸和脯氨酸经常出现在 β-转角当中，但 β-转角并不一定含有甘氨酸和脯氨酸。

* **Ω 环（Ω loop）**

    * 与 β-转角同一路数而更大，形状像希腊字母 Ω。

    * 长度一般是 6～8 个氨基酸残基，最多不超过 16 个。

    * 更多出现在球状蛋白的表面，以亲水基团为主：蛋白质泡在水相环境中，球状蛋白要把亲水基团摆到外表面。

    * 正因为露在外面，不同蛋白质分子之间发生相互作用时，Ω 环常常参与分子识别。

> **易错点**：甘氨酸和脯氨酸常出现在 β-转角中，这句话成立；反过来推「β-转角一定含甘氨酸和脯氨酸」就错了。

## 纤维状蛋白

### α角蛋白与卷曲螺旋

* **α角蛋白（α-keratin）**

    * 又称 α 螺旋蛋白质，是皮肤及其衍生物的组分：毛发、鱼类鳞片、鸟类羽毛，再算上龟甲。

    * 二级结构几乎全是 α-螺旋，即右手螺旋。

    * 判断右手螺旋：把右手伸出来，大拇指指向 N 端，四指弯曲的方向就是螺旋盘绕的方向，两者一致即右手螺旋。

    * 偏爱的氨基酸是丙氨酸、缬氨酸、亮氨酸、异亮氨酸、甲硫氨酸和苯丙氨酸。

    * 单股只是起点：两条右手的 α-螺旋以相反方向互相缠绕，拧成一根左手的卷曲螺旋。

    * 组装层次为单股右手 α-螺旋 → 两股反方向缠绕成左手卷曲螺旋 → 原纤维 → 微原纤维 → 毛发，每一级只做一件事，把上一级的东西并起来。

    * 相邻两个分子的 α-螺旋上各有一个半胱氨酸残基，两个巯基各脱掉一个氢合成一个二硫键；二硫键是共价键，比氢键结实得多。

    * 二硫键越多，纤维的刚性越强。

    * 湿热时毛发能拉长到原来的两倍：热和水拆了维持 α-螺旋的氢键，螺旋撑开拉直，转成比较伸展的 β 构象。

    * 伸展状态待不住，因为 α角蛋白的侧链 R 基一般比较大，挤在伸展构象里互相打架；湿热一撤、回到寒冷干燥，它自己又缩回 α 螺旋并重新交联。

```text
α 螺旋（单股，右手）
   │  两股反方向缠绕
   ▼
卷曲螺旋（左手）
   │  两根并排
   ▼
原纤维
   │  多根成束
   ▼
微原纤维
   │  大量平行排列
   ▼
毛发
```

> **提示**：这里有两层旋向。单股 α 螺旋是右手，两股拧成的卷曲螺旋是左手；看螺旋图先问自己数的是哪一层，再判旋向。

### 烫发的化学步骤

* 先按想要的形状把头发卷起来，卷成什么样，最后就是什么样。

* 加热加湿：氢键被拆开，α 螺旋打开，转成伸展的 β 构象。

* 涂还原剂：还原剂是含巯基的化合物，把二硫键还原回两个巯基，两条螺旋之间的束缚松开，能够随发卷滑开、变形。

* 去还原剂再涂氧化剂：氧化剂把巯基上的氢夺走，巯基重新氧化成二硫键，但这一次是在已经卷好的形状下与邻近的螺旋成键。

* 洗涤冷却：氢键恢复，β 构象重新变回 α 螺旋，只不过这一回是在被二硫键固定住的卷曲形状里长回去的。

* 顺序不能换：先断氢键，螺旋才伸得开、两股才滑得动，此时再断二硫键才有意义；重建时反过来，先把二硫键在新位置接好把形状锁住，再冷却让氢键在锁住的构象里恢复。

```text
按形状卷好头发
      │
      ▼
[湿热] 拆氢键：α 螺旋 → β 构象（伸展）
      │
      ▼
[还原剂·含巯基] 拆二硫键：—S—S—  →  两个 —SH
      │        螺旋之间的束缚松开，随发卷变形
      ▼
[去还原剂 + 氧化剂] 重建二硫键：在新的相对位置上成键
      │        形状被共价键锁死
      ▼
[洗涤冷却] 氢键恢复：β 构象 → α 螺旋
      │        但此时是在卷曲形状里长回去的
      ▼
永久卷发
```

* 压成一句：先拆氢键、再拆二硫键；先建二硫键、再建氢键。拆靠加热和还原剂，建靠氧化剂和冷却。

> **提示**：还原剂不是把二硫键删掉，是把 —S—S— 还原成两个 —SH；氧化剂也不是凭空造键，是把两个 —SH 再氧化成 —S—S—。整个过程是一对可逆的氧化还原加一对可逆的氢键破坏与重建。

### 丝心蛋白与 β角蛋白

* 丝心蛋白存在于昆虫的茧以及蜘蛛丝的纤维成分里，是 β 折叠蛋白，结构靠氢键和范德华力稳定。

* 范德华力是原子、分子之间普遍存在的一种很微弱的相互作用力，单个很小但几乎无处不在，一根纤维里成千上万个接触点累加起来就是可观的凝聚力。

* 丝心蛋白的二级结构以反平行的 β 折叠片为主，另外还含有一定量的无规卷曲和 α 螺旋。

* β角蛋白出现在大多数鸟类和爬行动物的皮肤、羽毛、鳞片中，也是 β 片层结构。

### 胶原蛋白的组成

* **胶原蛋白（collagen）**

    * 是很多脊椎动物和无脊椎动物体内最丰富的蛋白质，属于结构蛋白。

    * 腱、骨、软骨、牙齿、皮肤、血管这些结缔组织的主要成分都有它，是它让这些组织具有机械强度。

    * 属于糖蛋白：翻译生成多肽链时链上还没有糖，在最终折叠成有活性的胶原蛋白之前，糖才以糖基的形式加进去，所以糖基化是翻译之后、折叠定型之前的一步修饰。

    * 含三种不常见的氨基酸：4-羟脯氨酸、3-羟脯氨酸和 5-羟赖氨酸。

    * 前两个是在脯氨酸的四位碳、三位碳上各加羟基，第三个是在赖氨酸的五位碳上加羟基。

    * 催化羟化的酶是脯氨酸羟化酶和赖氨酸羟化酶，这两个酶催化的羟化反应需要维生素 C 参与，缺了它正常的胶原就合成不出来。

    * 有多个亚基，每个亚基都有自己的基因，这意味着每一条多肽链的一级结构都不一样；由不同多肽链组成的聚合物叫异聚体。

    * 富含甘氨酸、脯氨酸和羟脯氨酸。

### 胶原蛋白的螺旋与水解

* 三种氨基酸凑在一起，会形成三股 α 肽链，缠绕成特有的三股螺旋，这个三股螺旋就是原胶原。

* 旋向：原胶原整体是右手螺旋，每一股链自身是左手螺旋。

* 特征性的重复序列是 Gly-X-Y，X 和 Y 可以是甘氨酸以外的任何氨基酸，X 常常是脯氨酸，Y 常常是羟脯氨酸。

* 所谓富含甘氨酸、脯氨酸和羟脯氨酸，富就富在这条重复序列里。

* 胶原在体内以胶原原纤维的形式存在，胶原原纤维的基本结构单位就是原胶原。

* 组装层次为三条肽链（每股自身左手螺旋）→ 三股相互缠绕成原胶原（整体右手螺旋）→ 多条聚合成胶原原纤维 → 胶原。

* 胶原一般不容易被蛋白酶水解，但能被梭菌或者动物的胶原酶切断；一旦断了，碎片会自动变性，变性后的碎片就能被普通蛋白酶水解。

* 胶原在水中煮沸就变成明胶，也叫动物胶，是一种可溶性的多肽混合物。

```text
三条肽链（每股自身：左手螺旋）
        │  三股相互缠绕
        ▼
原胶原（整体：右手螺旋）
        │  多条聚合
        ▼
胶原原纤维
        │
        ▼
胶原
```

> **易错点**：问「三股螺旋整体」答右手，问「单股链自身」答左手；这两句话必须同时记住。

### 弹性蛋白

* 主要存在于结缔组织中，让肺、血管和韧带具有伸展性。

* 不被糖基化，不是糖蛋白。

* 只有一个基因。

* 不含羟赖氨酸，羟脯氨酸含量也很少。

| 项目 | 胶原蛋白 | 弹性蛋白 |
| :--- | :--- | :--- |
| 糖基化 | 是糖蛋白，多肽链合成后、折叠前加糖基 | 不被糖基化，不是糖蛋白 |
| 基因与亚基 | 多个亚基，每个亚基有各自的基因，属异聚体 | 只有一个基因 |
| 羟化氨基酸 | 含 4-羟脯氨酸、3-羟脯氨酸、5-羟赖氨酸 | 不含羟赖氨酸，羟脯氨酸含量也很少 |

### 血纤蛋白原与级联放大

* 血纤蛋白原存在于血浆，是凝血级联的底物，被凝血酶切成血纤蛋白。

* 血液凝固至少需要 13 种凝血因子参与，这些凝血因子都是蛋白质，整个凝血过程是一个级联放大反应。

* 主线：伤口出现 → 凝血酶原被激活成凝血酶 → 凝血酶催化血纤蛋白原转变成血纤蛋白 → 血纤蛋白在凝血因子 XIIIa（血纤蛋白稳定因子）作用下交联 → 形成不溶性的血纤蛋白凝块即血凝块，封住伤口。

* 两个「变」要分清：凝血酶原是「被激活」成凝血酶的，血纤蛋白原是「被催化」成血纤蛋白的。

* 最后一步不是简单的聚合，而是由 XIIIa 催化交联，产物才不溶。

* **级联放大反应（cascade）**

    * > **定义**：在体内的不同位置，通过一系列酶的酶促反应传递一个信息，初始信息传到系列反应的最后一步时信号被放大，这样的一连串反应就叫级联放大反应，也叫级联系统。

    * 一个信号传给三个，三个各自又传给许多个，层层分下去，到最后一步已经是一大片响应。

| 蛋白 | 主要存在 | 结构要点 |
| :--- | :--- | :--- |
| α角蛋白 | 皮肤及其衍生物：毛发、鱼类鳞片、鸟类羽毛、龟甲 | 右手 α 螺旋，两股拧成左手卷曲螺旋，二硫键交联 |
| 丝心蛋白／β角蛋白 | 蚕茧、蜘蛛丝；鸟类与爬行动物的皮肤、羽毛、鳞片 | 反平行 β 折叠片，靠氢键与范德华力稳定 |
| 胶原蛋白 | 腱、骨、软骨、牙齿、皮肤、血管等结缔组织 | 三股左手螺旋拧成右手原胶原，富含 Gly-X-Y |
| 弹性蛋白 | 结缔组织，肺、血管、韧带 | 不被糖基化，只有一个基因 |
| 血纤蛋白原 | 血浆 | 凝血级联的底物，被凝血酶切成血纤蛋白 |

## 超二级结构、结构域与三级结构

### 超二级结构（模体）

* **超二级结构（super-secondary structure，模体 motif）**

    * > **定义**：在蛋白质分子中，尤其是在球状蛋白质分子中，两个或更多个相邻的二级结构单元（主要是 α 螺旋和 β 折叠）连同它们的连接部件放在一起，彼此相互作用，形成种类不多、内能降低的、有规则的二级结构组合，叫超二级结构，也叫模体。

    * 定义里要咬住三个词：组合、相邻、有规则。

    * 组合：它本身不是一种新的二级结构，只是既有二级结构的搭配，主要挑 α 螺旋和 β 折叠来搭。

    * 相邻：参与组合的单元在序列上挨着，中间由连接部件串起来，不是隔着老远靠空间凑到一起。

    * 内能降低：一条肽链里每个原子都受周围一堆原子的吸引和排斥，最终折叠成的状态是对每个原子受力最平衡的状态，内能就低；内部本身拉扯着、引力或斥力很大则内能高，构象立不住。

    * 内能降低正是这个组合能稳定存在的原因。

    * 种类不多：花样有限，才能在成千上万种蛋白质里反复出现，也才敢把它们当成可命名的模体。

### 常见模体

* 两个 α 螺旋缠绕在一起，就是卷曲螺旋。

* β 折叠接 α 螺旋，这种组合在结合锌离子的蛋白里最典型：蛋白质本身含锌，或发挥功能时需要结合锌离子，往往就有这么一个 β 折叠加 α 螺旋的疙瘩，即锌指。

* β 折叠、α 螺旋、β 折叠、α 螺旋、β 折叠依次串下来。

* 两个 β 折叠并排。

* 五个 β 折叠围成一个筒，中间用无规卷曲或者 Ω 环连起来，这类连接用的都是不太典型的二级结构。

### 亮氨酸拉链

* DNA 的功能只有复制与转录成 RNA 两条路，两者都要跟大量蛋白质打交道，蛋白质上与 DNA 相互作用的区域经常出现亮氨酸拉链（leucine zipper）。

* 结构是两个 α 螺旋并排，一个圆柱就是一股螺旋，两个螺旋上亮氨酸交错地、有规律地排列着。

* 亮氨酸是疏水的，细胞里是水相环境，疏水侧链泡在水里不舒服，于是两个螺旋上的亮氨酸彼此靠拢聚到一起，像拉链一样咬合，把两个螺旋锁成一个二聚体。

* 咬合发生在 C 端一侧，而游离出来干活的是两个 N 端各带的一段区域。

* 锁好之后两个 N 端区域正好插进 DNA 的结构里与 DNA 相互作用，这就是它作为转录因子结构基础的道理：拉链负责把两个蛋白亚基拴成一对，N 端负责去抓 DNA。

### 结构域

* **结构域（domain）**

    * > **定义**：结构域是多肽链在二级结构或者超二级结构的基础上进一步折叠形成的三级结构的局部折叠区；它在空间上相对独立，是一个紧密的球状实体；是生物大分子当中具有特异结构和独立功能的区域。

    * 一般由 100 到 200 个氨基酸残基组成。

    * 结构域之间经常出现裂缝，裂缝不是缺陷而是功能位：酶的活性部位常常就在这道缝里，底物从这里进去、产物从这里出来。

    * 己糖激酶是典型例子：整个蛋白分成两个结构域，中间夹着一道裂缝。

* 两个概念各抓一个词：超二级结构抓「组合」，它本身还不是三级结构；结构域抓「独立功能」，它已经是三级结构内部能独立干活的一块。

### 三级结构的定义与稳定力

* **三级结构（tertiary structure）**

    * > **定义**：多肽链在二级结构、超二级结构或者结构域的基础上，因序列上相隔较远的氨基酸残基侧链的相互作用，进一步进行范围更广的盘曲折叠，形成的包括多肽链主链、侧链所有原子或基团在内的整体空间排布。

    * 记的时候只抓两个词：整条肽链、所有原子。

    * 「整条肽链」划清了它与四级的界：一条链的蛋白三级结构就是最高级；多条链的蛋白，每条链各自所有原子的空间结构是三级，链与链之间相对的空间位置才是四级。

    * 「所有原子」划清了它与二级的界：二级只管主链原子的局部构象，三级连侧链一起管，而且是整条链的范围。

* 稳定三级结构的两类力：二硫键（共价键，比较强）与各种弱相互作用，即疏水键、盐键、氢键和范德华力。

* 二硫键的归属要看位置：胰岛素 A、B 两条链之间由二硫键连着，A 链自身还有一处链内二硫键，一共三对，规定的是哪条链和哪条链是一伙的，属一级结构层面的连接。

* 三级结构里的二硫键不一样：它是同一条链上相隔很远的两处半胱氨酸之间搭的桥，作用是把已经盘好的构象钉死。

* 一级结构是线性结构，二、三、四级结构是空间结构，一级结构是所有空间结构的基础。

* 三级结构是单条肽链蛋白质的最高级结构；肌红蛋白只有一条多肽链，只要有了完整的三级结构，全部生物学功能就已经具备。

### 球状蛋白的内外分工

* 大多数球状蛋白用 α 螺旋和 β 折叠片搭出球状分子的核心，三维结构具有明显的折叠层次，整个分子是一个紧密的球状或椭球状实体。

* 内外分工非常明确：疏水侧链埋在分子内部，亲水侧链暴露在分子表面。

* 必须如此的原因：蛋白质泡在细胞的水相环境里，表面亲水才待得住，疏水侧链埋进去才不用碰水。

* 内部的疏水基团若不小心暴露出来，会互相聚集形成斑块，功能也跟着出问题。

* 分子的中心基本上就是由 α 螺旋和 β 折叠组成的。

* 分子表面一般还会有一个空穴，这个空穴就是它与其他物质相互作用的位点。

## 膜蛋白

### 膜周边蛋白

* 分布在磷脂双分子层的内外表面，是可溶性的球状蛋白。

* 到不了膜内部：膜里面是脂溶性环境，可溶性的球状蛋白进不去。

* 靠静电相互作用和氢键结合：一只手抓着膜内在蛋白露在外面的亲水结构域，另一只手抓着膜脂的极性头部。

* 结合得弱、拆得也就容易：改变 pH、改变离子浓度、加尿素这类只破坏离子键和氢键的温和手段就够把它分下来。

* 占膜蛋白总数的 20% 到 30%。

### 膜内在蛋白

* 部分或者全部嵌在脂双层当中，有的还横跨全膜。

* 主要靠与脂双层的疏水相互作用和膜牢固结合，所以嵌在膜里的区段必然是疏水基团组成的。

* 要把它弄出来，得用能破坏疏水作用的介质：去污剂、变性剂，或者有特异性作用的酶。

* 是膜蛋白里的绝对多数，占 70% 到 80%。

* 功能包括：作为转运蛋白和离子通道；作为激素、神经递质和生长因子的受体；参与免疫过程；参与细胞间识别（两个细胞表面的跨膜蛋白一搭手，两个细胞就认识了）；参与氧化磷酸化和光合磷酸化。

### 脂锚定蛋白

* 本身不含跨膜的肽段，但身上共价连着一个脂质，靠这个脂质插进膜里与膜牢牢结合。

* 脂质是疏水的，膜内部也是疏水的，两者自然合得来。

* 因为它既可能出现在细胞溶胶里，也可能挂在膜上，所以也叫兼在膜蛋白。

* 三类膜蛋白的分工一句话：贴着的、嵌着的、拴着的。

| 类型 | 与膜的结合方式 | 提取条件 | 占膜蛋白比例 |
| :--- | :--- | :--- | :--- |
| 膜周边蛋白 | 静电相互作用与氢键，结合在脂双层内外表面或膜内在蛋白的亲水结构域上 | 温和手段：改变 pH、改变离子浓度、加尿素 | 20%~30% |
| 膜内在蛋白 | 与脂双层疏水相互作用，部分或全部嵌入，部分横跨全膜 | 去污剂、变性剂、有特异性作用的酶 | 70%~80% |
| 脂锚定蛋白 | 共价连接的脂质插入膜中，自身不含跨膜肽段 | 长文未说明 | 长文未说明 |

## 四级结构与亚基缔合

### 亚基与蛋白质的聚合形态

* **亚基（subunit）**

    * > **定义**：一个蛋白质如果由两条或两条以上的多肽链构成，那么每一条具有完整三级结构的多肽链就称为一个亚基。

    * 两个落脚点：亚基是一条多肽链；这条链得自己先折到三级结构。

* 几个亚基各自折好之后，再通过非共价键相互连接，形成一个立体的、一般呈球状的结构，这个结构才是四级结构。

* 反过来也成立：具有四级结构、即由多条多肽链组成的蛋白质，一般都是球状蛋白。

* 单体蛋白只由一个亚基组成、只有一条多肽链，没有四级结构，最高级结构就是三级结构，如肌红蛋白。

* 寡聚蛋白由为数不多的亚基组成，大多数寡聚蛋白的亚基数目是偶数，如血红蛋白是四聚体。

* 多聚蛋白由多个亚基组成；亚基少叫寡聚、亚基多叫多聚，与寡肽、多肽的命名同理。

| 类型 | 亚基数目 | 最高级结构 | 例子 |
| :--- | :--- | :--- | :--- |
| 单体蛋白 | 一条多肽链，一个亚基 | 三级结构 | 肌红蛋白 |
| 寡聚蛋白 | 少数亚基，多为偶数 | 四级结构 | 血红蛋白（2α + 2β 四聚体） |
| 多聚蛋白 | 多个亚基 | 四级结构 | 长文未说明 |

### 四级结构的内容与维持力

* > **定义**：蛋白质由两条或两条以上的多肽链组成时，每条具有完整三级结构的多肽链为一个亚基，各亚基通过非共价键相互连接，形成立体的、一般呈球状的结构；不同亚基之间相对的空间位置关系即四级结构。

* 四级结构管四件事：亚基的组成，即有哪些类型的亚基；亚基的数目，有几条；各亚基在整个分子当中的空间排布；亚基之间的相互作用。

* 维持四级结构的化学键是疏水作用力、范德华力、氢键和离子键，清一色的非共价键。

* 名词解释的写法：先讲清什么是亚基，再讲亚基之间相对的空间位置，补上亚基的组成、数量、排列组合，最后写维持它的化学键——少写一条就少一个得分点。

### 对称性与别构效应

* 大多数寡聚蛋白质分子里亚基的排列组合是对称的，至少有一个对称轴。

* 对称性是蛋白质四级结构最重要的性质之一：一条链谈不上怎么摆，多条链凑在一起才有排布问题，而自然界给出的答案多半是对称的。

* **别构效应（allosteric effect）**

    * > **定义**：多亚基蛋白质一般具有多个配体结合部位；配体结合在蛋白质分子上的特定部位，会对分子的其他部位产生影响，这样的蛋白质称为别构蛋白质，这种由一个部位的结合改变另一个部位功能的调节方式就叫别构效应。

    * 别构激活：血红蛋白第一个亚基结合氧后，影响第二、第三个亚基的结构，使它们更容易结合自己的配体；第二、三个都结合上之后，又诱导第四个亚基结构改变，进一步促进其结合氧，一个接一个、越往后越容易。

    * 别构抑制：某个配体结合上去，把其他部位对配体的亲和力压下去。

> **注意**：写别构效应两层都要有——配体结合在「特定部位」，影响的是「分子的其他部位」；只写「一个亚基影响另一个亚基」，漏掉部位这一层，答案不完整。

## 变性、复性与折叠

### 变性的实质

* **蛋白质变性（denaturation）**

    * > **定义**：天然蛋白质分子受到某些物理、化学因素——有机溶剂、酸、碱、高温等等——的影响，发生生物活性丧失、溶解度降低、不对称性增高，以及其他物理化学性质改变，这个过程就叫蛋白质的变性。

    * 定义里的因果要看清：先有外界因素，然后是一组性质的变化，其中最核心的是生物活性丧失。

    * > **定义**：蛋白质变性的实质是次级键被破坏，不涉及共价键的断裂。

    * 次级键是相对共价键说的：疏水作用、离子键（盐键）、范德华力、氢键这些维持立体结构的作用力被打断，空间构象散掉，生物活性随之丧失；肽键、二硫键这类共价键则不动。

    * 压成一句话：二、三、四级结构被破坏，一级结构保持完好。

    * 变性不是把肽链剪断，而是把已经折好的形状拆散，氨基酸的排列顺序原封不动。

* 蛋清的例子：蛋清放进清水会均匀分布成胶体溶液，此时蛋白质还是天然的、有活性的；一加热就成蛋花汤，蛋白质变性、生物活性丧失、溶解度降低、沉淀下来。

### 变性的结果

* 生物活性丧失，这是变性最主要的特征。

* 侧链基团暴露：原本包在内部的疏水基团被翻到外面，分子之间就容易相互聚集。

* 原本包藏在内部、不容易与化学试剂反应的侧链基团也被放了出来，放出来以后就能和化学试剂起反应。

* 物理化学性质改变：疏水基团外露、分子又发生聚集，溶解度自然降低、更容易沉淀，同时分子的不对称性增高。

* 生物化学性质改变：变性的蛋白质比天然蛋白更容易受到蛋白水解酶的作用，所以食物做熟后更容易消化。

> **易错点**：变性不等于水解。变性只拆空间结构，肽键完好，肽链仍然是完整的，只是折法乱了；水解才是把肽键切开、把链剪短。

### 变性剂的作用机制

* 尿素和盐酸胍使蛋白质变性靠两条机制。

* 第一条：与多肽链的主链竞争氢键，破坏蛋白质的二级结构；二级结构是三级结构的基础，二级结构被破坏，三级结构也就保不住了。

* 第二条也是更重要的原因：增加疏水侧链在水中的溶解度，从而降低维持蛋白质三级结构的疏水相互作用。

* 三级结构能在水环境里形成，是因为水里疏水基团会自发聚集形成疏水核心、亲水基团自然朝外；尿素、盐酸胍把疏水侧链在水里的溶解度抬高以后，疏水基团自发聚集的动力就弱了，疏水核心散开，肽链也就散架了。

* SDS 是一种去污剂，属于阴离子表面活性剂，同样破坏蛋白质分子当中的疏水作用。

* SDS 使疏水基团暴露到水介质里，同时降低疏水侧链从疏水内部转移到水介质的转移自由能，也就是让疏水侧链更容易跑到水相里去，疏水核心自然就散了。

* 不管走哪条变性路线，被拆掉的都是次级键，肽键和二硫键不动。

```text
天然构象（疏水核心在内、亲水基团在外）
        │
        │  加热 / 强酸 / 强碱 / 有机溶剂
        │  尿素、盐酸胍：竞争氢键 + 抬高疏水侧链溶解度
        │  SDS：破坏疏水作用 + 降低转移自由能
        ▼
次级键断裂 → 疏水侧链暴露 → 肽链松散
        │
        ├──▶ 分子间疏水聚集 → 溶解度降低 → 沉淀
        └──▶ 更易被蛋白水解酶水解

（一级结构：肽键、二硫键保持完好）
```

### 复性的条件

* **蛋白质复性（renaturation）**

    * > **定义**：变性蛋白质分子除去引起它变性的因素，恢复到原来的天然构象和生物活性，这个现象就叫蛋白质的复性。

    * 不是所有变性的蛋白质都能复性，只有变性程度较轻的蛋白质才有可能；煮熟的鸡蛋、煎好的荷包蛋回不去了。

    * 操作上多采用透析或者超滤把变性剂去掉，让蛋白质重新折叠，前提仍然是变性程度要低。

> **注意**：复性的关键词是「除去变性因素」和「恢复天然构象与生物活性」，两个都要写；只写恢复活性、漏掉前提，概念就不完整。

### 分子伴侣

* 多肽链在生物体内合成出来以后，一定要折叠成特定的空间构象才具有功能，折不成那个构象就没有功能。

* 折叠需要一系列蛋白质协助：肽基脯氨酰异构酶、分子伴侣家族、蛋白质二硫键异构酶。

* **热激蛋白（heat shock protein，HSP）**：H 是热（heat），S 是应激（stress），P 是蛋白质（protein）；HSP70 就是分子量 70 kD 左右的一种热激蛋白。

* HSP70 这类分子伴侣的作用，是帮助没有完全折叠的蛋白质折叠成最终有功能的空间构象。

* GroEL 像一个桶，GroES 像一个盖子。

* 需要桶的理由：新生肽链折叠时有时不得不把疏水基团暴露在外面，而细胞里同一种蛋白质有千千万万个拷贝，彼此的疏水基团一碰头就聚集，聚成一团就再也折不成有活性的状态。

* GroEL 桶里是疏水的、没有水，相当于给肽链提供了一个相对疏水的微环境：肽链进去可以把疏水侧链暴露着折叠，不怕被别人粘住，折叠好了再放出去；GroES 就是盖在桶口的那层盖子。

```text
                GroES（盖子）
              ┌────────────┐
              │            │
           ┌──┴────────────┴──┐
           │                  │
           │   GroEL 桶腔      │  ← 内部疏水、无水
           │  肽链在此折叠      │
           │                  │
           └──────────────────┘
```

## 蛋白质功能的多样性

* 催化与转化：生物体内几乎所有化学变化都是酶促反应，如唾液淀粉酶催化淀粉变成麦芽糖，这就是嚼馒头会嚼出甜味的原因。

* 唾液淀粉酶可被氯离子提高活性，氯离子是它的一种非必需激活剂。

* 转氨酶代表是谷丙转氨酶，催化谷氨酸脱掉氨基变成 α-酮戊二酸，脱下的氨基转给丙酮酸生成丙氨酸。

* 信号分子与信号转导：胰岛素与受体结合，受体把信号传到细胞内部甚至细胞核，对普通细胞就是加速摄取葡萄糖，最终使血糖下降；机体绝大多数细胞都有胰岛素受体。

* 转运：血红蛋白运氧气，转铁蛋白运三价铁离子。

* 结构与支撑：毛发里的 α-角蛋白、结缔组织里的胶原蛋白；皮肤衰老长皱纹的一个原因是结缔组织中的胶原蛋白减少、支撑力下来了。

* 运动与动力：肌球蛋白和肌动蛋白相互滑动，肌肉细胞因此收缩或者松弛。

* 防卫保护与免疫：免疫球蛋白、淋巴细胞受体，负责识别与清除外来物。

* 养分储存：卵清蛋白为鸟类胚胎发育提供能量，乳汁里富含酪蛋白。

* 支架与衔接：支架蛋白像一张桌子，把多个信号蛋白聚到一起，使原本自己找不到对方的蛋白彼此挨着，信号就能传下去。

* 调节：周期蛋白 cyclin 调节 CDK（周期蛋白依赖的激酶）的活性，CDK 再往下游走可以调节基因表达。

* 奇异功能：有的水果里含有甜蛋白，甜度极高，是一种天然甜味剂。

## 血红素与氧的结合

### 血红素的六配位

* 氧气难溶于水，多细胞生物要转运氧气得靠亚铁离子或者亚铜离子来结合它。

* 绝大多数常见动物包括人选择亚铁离子，亚铁离子结合氧气以后显红色，这就是血液的颜色。

* 另一些节肢动物选择亚铜离子，血液显蓝色，它们体内运输氧的蛋白叫血蓝蛋白。

* 转运链是一层套一层：亚铁离子先装进辅基血红素，血红素再嵌进珠蛋白，珠蛋白包括肌红蛋白和血红蛋白。

* 血红素的结构有一个卟啉环母核，最中间是一个铁原子。

* 铁可以有六个配位键：四个和卟啉环上的四个氮原子相连，剩下两个一个用来结合氧气，另一个连到蛋白质上。

* 只有亚铁离子、也就是二价铁才能结合氧气；二价铁一旦失去一个电子变成三价铁，就不能运输氧气了。

* 人体里除了血红素，还有一些细胞色素类的物质也是这样的结构。

### 一氧化碳的竞争

* 一氧化氮和一氧化碳与血红素铁配位的亲和力都比氧气高，三者同时存在时，血红素优先选择一氧化氮和一氧化碳。

* 一氧化碳一旦结合上去，因为它亲和力更高，氧气就被挤出去了。

* 这就是一氧化碳对生物剧毒的原因，也是一氧化碳中毒的机制：氧气被从血红蛋白的血红素里挤走，机体缺氧窒息。

* 一氧化碳抢占的是氧气的配位位置，不是把铁氧化成三价铁——它是占座，不是换人。

### 血液颜色

* 动脉血是鲜红色，静脉血是紫红色，肉眼看上去甚至有点发黑。

* 差别来自含氧量：动脉血富氧，亚铁离子携带的氧气多；静脉血相对缺氧。

* 含氧量不同颜色就不同，是因为亚铁离子与氧结合以后电子的性质发生了变化，电子性质一变颜色就跟着变。

* 血液的颜色不是孤立表象，背后是血红素里那个铁原子的电子状态。

## 肌红蛋白

### 结构与定位

* 珠蛋白是一个大家族，成员有相似的一级结构和三级结构，都能结合氧气，其中最重要的是肌红蛋白和血红蛋白。

* 肌红蛋白（Mb）只有一条多肽链，是一个单体，最高级结构就是三级结构，分布在肌肉组织，功能是促进肌肉组织中氧的扩散。

* 肌红蛋白由一条珠蛋白链和一个血红素组成，与血红蛋白同源。

* 这条多肽链里有八段 α 螺旋，依次命名为 A、B、C、D、E、F、G、H。

* 整条链里 78% 的氨基酸残基都在 α 螺旋中，差不多五分之四。

* 肌红蛋白是第一个被完整解析出三级结构的蛋白质。

* 每个肌红蛋白有一个血红素，一个血红素携带一个氧气，所以肌红蛋白一次携带一分子氧。

* 功能上肌红蛋白主要贮存氧，当然存下来的氧最终也要运出去，所以它既贮存也转运。

### 肌细胞内的运氧循环

* 毛细血管中血红蛋白释放的氧气穿过细胞膜进入肌肉细胞，在细胞膜内侧与去氧肌红蛋白结合，变成氧合肌红蛋白。

* 氧合肌红蛋白在细胞溶胶中向线粒体扩散，因为细胞里真正利用氧气的地方就是线粒体。

* 线粒体中的氧浓度下降时，氧合肌红蛋白把贮存的氧释放给线粒体，自己变回去氧肌红蛋白，回到细胞膜内侧等待下一批氧气。

* 整个过程是一个可逆结合、定点装卸的循环：在细胞膜内侧装氧，在线粒体旁边卸氧，肌红蛋白本身不消耗氧，只把氧从膜内侧摆渡到线粒体旁边。

```text
毛细血管中的血红蛋白
        │ 释放 O2
        ▼
肌细胞膜 ──▶ 去氧肌红蛋白（空载）
                    │ 结合 O2
                    ▼
              氧合肌红蛋白
                    │ 在细胞溶胶中扩散
                    ▼
                 线粒体（耗氧场所）
                    │ O2 被释放
                    ▼
              去氧肌红蛋白
                    │
                    └──▶ 回到细胞膜内侧，等待下一批 O2
```

### 氧合曲线与 P50

* 横轴是氧分压，也就是氧的浓度，单位 Torr（托），1 Torr 等于 1 mmHg；纵轴是饱和度，1 表示 100%。

* **P50** 指蛋白质被氧半饱和时的氧分压；肌红蛋白的 P50 大约是 1 Torr。

* 曲线一开始就陡直上升：氧分压从 0 到 1 mmHg 这么一点点，肌红蛋白就立刻结合氧气。

* 这说明它对氧的亲和力很高——只要有一点点氧，它就抓得住。

```text
饱和度
100% ┤              ●───●───
     │          ●
 50% ┤      ●   ← P50 ≈ 1 Torr
     │    ●
  0% ┼──●────────────────────▶
     0   1   2   3   4   PO2 / Torr
```

### 蛋白质结构对配体结合的影响

* 一氧化碳结合游离血红素的能力比氧气高 25000 倍。

* 把血红素放进肌红蛋白里以后，此时血红素结合一氧化碳的能力只比氧气高 200 倍。

* $25000 \div 200 = 125$，同一个血红素游离时与装在蛋白质里，对一氧化碳的偏好差了 125 倍。

* 蛋白质不是被动地驮着一个配体，它自身的空间结构会改变配体的结合性质。

## 血红蛋白

### 亚基组成与类型

* 血红蛋白（Hb）在血液里转运氧气：肺里氧多就把氧装上，血液流到外周组织再把氧交出去。

* 动脉血里血红蛋白的氧饱和度是 96%，回到心脏的静脉血只剩 60%，这 36 个百分点就是它一趟真正交出去的货。

* 血红蛋白是四个亚基组成的四聚体，每个亚基上都有一个氧结合部位，所以一个血红蛋白一次可以结合四分子氧。

* 血红蛋白在红细胞里的质量占比高达 34%，红细胞显红是因为二价铁离子结合氧气以后会显红色。

* 脊椎动物的血红蛋白有四个多肽亚基，已发现的亚基种类至少有七种：α、β、Aγ、Gγ、δ、ε、ζ。

* 四个位置从这七种亚基里挑，挑法不同就有了不同的血红蛋白类型。

| 血红蛋白 | 亚基组成 | 在哪里为主 |
| :--- | :--- | :--- |
| HbA | α2β2 | 成人红细胞中的主要形式 |
| HbF | α2γ2 | 胎儿时期的主要形式 |
| HbA2 | α2δ2 | 成人体内约占 2% |

* 每个亚基都有一个血红素，血红素就是结合氧的部位，中间有一个二价铁离子。

* 成熟的红细胞是一个小的双凹圆盘状细胞，没有细胞核、没有内质网、没有线粒体，所以它不能增殖，是一次性的，寿命只有 120 天。

* 按形状给蛋白质分类可以分成纤维状蛋白和球状蛋白，血红蛋白是球状蛋白。

### 四聚体的维系

* 四个亚基之间的结合力不一样：两条不同链之间的亚基相互作用最大，相同链之间的亚基相互作用最小。

* 以 HbA 的 α2β2 为例：α 和 β 之间的作用力强，α 与 α 之间、β 与 β 之间的作用力都比较弱。

* 这个差别可以用尿素试出来：尿素处理以后四聚体解离成两个二聚体 α1β1 和 α2β2，是两个保持完整的 αβ 二聚体，不是四条散开的单链。

* 换句话说，血红蛋白可以看成两个 αβ 二聚体拼起来的。

* 每一条链单独看，三级结构都和肌红蛋白相似，功能也相似，都能结合一个氧；每个亚基就像是肌红蛋白的一个翻版。

### T 态与 R 态

* **T 态（tense，紧张态）**：结构比较紧密，与氧的亲和力小。

* **R 态（relaxed，松弛态）**：结构比较松弛，与氧的亲和力大。

* 比喻：血红蛋白是吸水的海绵，水是氧气；T 态是海绵被捏紧了，捏得越紧吸水能力越弱；R 态是海绵放松了，放得越松吸水能力越强。

* 氧气与 T 态血红蛋白不太容易结合，但只要有一个氧气结合到 T 态的一个亚基上，就会促使整个四聚体的构象朝 R 态转变；R 态与氧的亲和力大，剩下的亚基再结合氧就容易了。

* 反过来，氧释放以后血红蛋白也会回到 T 态；T 态对氧的亲和力低，剩下的氧就更容易继续放掉。

* T 态和 R 态这样来回切换，血红蛋白才能在肺里抓氧、在组织里放氧。

> **易错点**：T 态是绷紧的低亲和力状态，R 态是松开的高亲和力状态；不要把 tense（紧张）理解成「活跃」，也不要把 relaxed（松弛）理解成「不工作」。

### 协同效应

* > **定义**：协同效应是一个配体与蛋白质上的一个亚基结合，会影响同一蛋白质中其他亚基与配体的结合能力（亲和力）。

* > **定义**：正协同效应是一个配体与蛋白质上的一个亚基结合后，促进同一蛋白质上其他亚基与配体的结合。

* > **定义**：负协同效应是一个配体与蛋白质上的一个亚基结合后，抑制同一蛋白质上其他亚基与配体的结合。

* 注意定义里的动词是「影响」而不是「促进」：一个配体结合可能促进也可能抑制，促进的叫正协同，抑制的叫负协同。

* 血红蛋白的配体是氧气，它受正协同调节：第一个亚基结合氧以后促进第二、第三个亚基结合氧；第二、三个也结合上以后，促进第四个亚基结合氧。

* 未结合氧时血红蛋白是 T 态，只要结合上去一个氧就促使它由 T 态朝 R 态转变，从而更容易结合氧；正协同在血红蛋白上就是「一个带动三个」。

### S 形氧合曲线

* 把血红蛋白的氧饱和度对氧分压作图得到氧合曲线，形状是先缓、再陡、后平。

* 起始段缓：第一个亚基与氧结合比较难，血红蛋白还在 T 态，氧分压升高一点，饱和度上不去多少。

* 中段陡：第一个氧结合以后立刻促进第二、第三、第四个亚基结合氧，T 态转 R 态，饱和度直线上升。

* 末段平：所有血红蛋白都被氧饱和，四个位点都占满，再增加氧分压也装不下了。

* S 形曲线就是「第一个氧难、后面三个氧容易」这件事在坐标图上的投影。

```text
氧饱和度
100% ┤                          ┌────────────
     │                      ╱
 75% ┤                  ╱
     │              ╱
 50% ┤          ╱
     │       ╱
 25% ┤    ╱
     │ ╱
  0% └────────────────────────────────────→ 氧分压
       缓慢        陡升         平台
```

* 在静脉血、外周组织里氧分压比较低，血红蛋白不容易结合氧，更倾向于释放氧、把氧卸载给组织；到了肺里氧含量很高，结合氧的能力增强，就把氧装上。

* 肺里接近饱和落在平台段，血液流到组织氧分压降下来，曲线正处在陡升段，96% 到 60% 的落差就是在这段陡坡上完成的。

### 波尔效应

* 血红蛋白不只运氧，还运氢离子和二氧化碳：转运的氢离子占体内总氢离子的 40%，转运的二氧化碳占总二氧化碳的 15% 到 20%。

* 二氧化碳从组织运到肺和肾脏，到肺里通过呼吸呼出去，到肾脏里通过尿液排出去。

* > **定义**：波尔效应（Bohr effect）是氢离子和二氧化碳影响血红蛋白与氧气亲和力的效应；氢离子和二氧化碳浓度增加，会降低血红蛋白与氧气的亲和力，使氧合曲线右移，促进血红蛋白释放氧气。

* 去氧血红蛋白对氢离子的亲和力比氧合血红蛋白大：血红蛋白结合了氧以后更不容易结合氢离子，释放了氧变成去氧血红蛋白以后更容易结合氢离子。

* 反过来也成立：降低 pH、也就是增加氢离子浓度，会促进氧合血红蛋白释放氧，变成去氧血红蛋白。

* 这两种结合是双向的、互斥的：氢离子进来把氧挤走，氧回来把氢离子挤走——要么结合氢离子和二氧化碳，要么结合氧。

* 曲线右移的原因：氢离子存在时血红蛋白与氧的亲和力变弱，要达到同样高度的饱和度就需要更多的氧气，曲线自然往右挪。

| 场景 | pH | 氢离子与二氧化碳 |
| :--- | :--- | :--- |
| 氧结合实验的测定条件 | 7.4 | 标准对照 |
| 肺 | 7.6 | 较低 |
| 组织（如骨骼肌） | 7.2 | 较高 |

* 组织比肺酸，氢离子更多；氢离子和二氧化碳一般同时存在，因为二氧化碳在水里会生成碳酸，碳酸是酸性物质，也会解离出氢离子。

* 血液流经组织时 pH 较低、氢离子和二氧化碳浓度较高，血红蛋白释放氧、同时结合氢离子和二氧化碳：氧被放到肌肉里，代谢生成的二氧化碳和氢离子又被带走。

* 血红蛋白把呼吸作用产二氧化碳引起的 pH 下降一并缓冲掉，因为它把氢离子也带走了，所以能起到缓冲血液 pH 的作用。

* 血液流经肺部时氢离子和二氧化碳浓度较低，血红蛋白结合氧、同时释放氢离子和二氧化碳；二氧化碳呼出后血液里二氧化碳减少、碳酸减少、pH 上升，pH 上升又进一步促进血红蛋白与氧结合。

* 记忆法：运氧的时候对氢离子和二氧化碳的亲和力低，运氢离子和二氧化碳的时候对氧的亲和力低，两种货不能同时满载。

### BPG 调节

* 2,3-二磷酸甘油酸（2,3-BPG，简称 BPG）是血红蛋白的别构抑制剂，降低血红蛋白对氧气的亲和力，使血红蛋白更不容易结合氧、或者说更容易释放氧。

* 肌肉细胞里含有 BPG，可以促进血红蛋白释放氧，所以 BPG 的作用是增加血红蛋白在组织中的泄氧量。

* BPG 浓度越大，血红蛋白的氧饱和曲线越往右移，原因和波尔效应一样：抑制血红蛋白与氧的结合，要达到同样的氧饱和度就需要更多的氧气。

* BPG 靠稳定血红蛋白的 T 态起作用：T 态与氧的亲和力小，血红蛋白被按在 T 态，氧就更容易被卸载下来。

* 缺少 BPG 不能靠体外补充，因为 BPG 不能透过红细胞膜。

* 人从低海拔到高海拔以后，红细胞里的 BPG 浓度会很快上升，帮助血红蛋白在组织当中释放氧。

### 胎儿血红蛋白的取氧优势

* 胎儿的血红蛋白主要是 HbF（α2γ2），成人的主要是 HbA（α2β2），两者只差一条链：胎儿是 γ 链，成人是 β 链。

* 差异落在 γ 链的 H 螺旋第 21 位：γ 链在这里是丝氨酸，β 链在这里是组氨酸。

* 丝氨酸减少了 BPG 结合部位的正电荷，降低了胎儿血红蛋白对 BPG 的亲和力。

* BPG 是抑制血红蛋白与氧结合的物质，结合得更少、受到的抑制更小，对氧的亲和力就更高。

* 母亲的血红蛋白用 β 链、第 21 位是组氨酸，更容易结合 BPG，对氧的亲和力相对更低，于是胎儿的血红蛋白能从母亲体内把氧拿过来。

| 血红蛋白 | 亚基组成 | H 螺旋第 21 位 | 结合 BPG | 对氧的亲和力 |
| :--- | :--- | :--- | :--- | :--- |
| 成人 HbA | α2β2 | β 链为组氨酸 | 较多 | 较低 |
| 胎儿 HbF | α2γ2 | γ 链为丝氨酸 | 较少 | 较高 |

* 推理链是单向的：γ 链丝氨酸 → BPG 结合部位正电荷减少 → 结合 BPG 少 → 对氧的抑制小 → 对氧亲和力高 → 胎儿能从母体取氧。

## 血红蛋白分子病

### 分子病与镰状细胞贫血

* > **定义**：分子病是基因突变导致蛋白质分子发生变异，进而引起的疾病。

* 信息链是 DNA 把信息转录给 mRNA、mRNA 再翻译成蛋白质，DNA 的信息一变，最终就会影响蛋白质的结构和功能。

* 并不是所有的基因突变都会导致蛋白质分子变异，只有那些导致蛋白质分子发生变异、并由此引起疾病的基因突变才属于分子病讨论的范围。

* 镰状细胞贫血病人的红细胞从双凹圆盘状变成了镰刀状，镰刀状的红细胞丧失了运输氧气的功能。

* 血液里大量出现这种镰刀状红细胞，患者就会缺氧窒息，因为它们不能像正常红细胞那样给组织细胞运氧。

* 病因是遗传基因突变导致血红蛋白分子结构改变，最终引起细胞形态改变、产生病理效应；该病死亡率很高，也是最早被认识的一种分子病。

### 镰状化的分子机制

* 突变点很具体：β 亚基 N 端第 6 位氨基酸，正常是谷氨酸，突变后变成缬氨酸，就一个氨基酸的改变。

* 谷氨酸是酸性氨基酸、亲水；缬氨酸是疏水氨基酸。

* 这个突变显著降低了去氧血红蛋白的溶解度，溶解度一降就容易沉淀出来。

* 但突变后的血红蛋白在氧合形式下不受影响：只要它结合了氧，就和正常血红蛋白一样。

* 机制：突变后的 HbS 表面，β 亚基第 6 位的缬氨酸疏水侧链暴露在分子表面；去氧血红蛋白分子上有一个互补的疏水口袋，氧去掉以后口袋就空出来了。

* 缬氨酸的疏水侧链正好插进这个疏水口袋，通过疏水作用结合，在水相环境里互相靠近、越聚越多，形成纤维状沉淀。

* 氧合血红蛋白的表面没有疏水性口袋，所以只有缺氧的时候红细胞才会变成镰刀状，不缺氧时红细胞还是正常形态。

```text
去氧 HbS：β6 缬氨酸的疏水侧链暴露
        │
        │  插入另一分子去氧 HbS 的疏水口袋
        ▼
    分子间疏水作用，不断聚集
        │
        ▼
    纤维状沉淀（像一根杆子撑在红细胞里）
        │
        ▼
    红细胞由双凹圆盘变成镰刀形
        │
        ▼
    红细胞破裂、血液呈冻胶状，血流变慢、血管堵塞
        │
        ▼
    组织氧分压进一步下降
        │
        └──→ 去氧 HbS 更多，镰刀化加重
```

* 单个 HbS 分子的疏水侧链是钩子，另一分子去氧血红蛋白的疏水口袋是扣眼，钩子扣进扣眼，分子就连成长链，最后聚成纤维状沉淀。

* 沉淀越积越多，红细胞就被撑成镰刀形；细胞破裂、血流受阻，又把缺氧推得更深，形成一个越转越快的闭环。

* 患者早亡的主要原因不是单个分子出错就立刻要命，而是「缺氧—镰刀化—更缺氧」的循环一旦转起来，就会不断放大。

### 治疗尝试与地中海贫血

* 镰状细胞贫血是遗传性疾病，目前为止没有很好的治疗方法。

* 体外研究表明，用氰酸钾处理镰状细胞贫血患者的红细胞，可以防止突变的 HbS 在缺氧状态下形成镰刀状。

* 氰酸钾的修饰是不可逆的，修饰的是 N 末端区域的缬氨酸残基，正是突变产生的那一个。

* 被氰酸钾修饰以后可以矫正血红蛋白的构象，使血红蛋白分子重新获得运输氧气的能力；但该方案目前还在实验室阶段、临床前阶段，还没有用到临床上。

* 地中海贫血影响的也是 HbA，因为成年人血液里的主要血红蛋白就是 HbA。

* 地中海贫血也是遗传性疾病，遗传因素改变会导致 α 亚基或 β 亚基的结构和功能改变；影响 β 亚基的叫 β 地中海贫血，影响 α 亚基的叫 α 地中海贫血。

## 免疫系统与免疫球蛋白

### 淋巴细胞

* 免疫是人类和脊椎动物最重要的防御机制，能在分子水平上识别自我和非我，并把非我的部分破坏掉。

* 免疫系统主要靠两种细胞发挥作用：淋巴细胞和吞噬细胞，两种细胞都来自骨髓干细胞。

* B 细胞在骨髓当中完成发育（骨髓英文首字母是 B）。

* B 细胞的受体本身就是一种抗体分子，是能够单独识别抗原的膜结合糖蛋白，一个 B 细胞表面长着许多这样的抗体。

* B 细胞遇上与它的膜结合受体特异性匹配的抗原，就开始迅速分裂，子代细胞分化成记忆细胞和效应细胞。

* 效应细胞就是浆细胞，当即去杀伤抗原；记忆细胞把抗原的样子记下来，等这个抗原下次入侵时迅速增殖、分裂再把它清除。

* T 细胞迁移到胸腺，在胸腺内完成后期发育并成熟（胸腺英文首字母是 T），成熟期间表达抗原特异的膜受体 T 细胞受体（T cell receptor，TCR），TCR 是一种异二聚体。

* T 细胞分两类：辅助性 T 细胞（TH，helper T cell）和细胞毒性 T 细胞（TC，cytotoxic T cell）。

* 两类受体的根本差别：B 细胞受体直接结合抗原；T 细胞受体不认游离的抗原，只有当抗原与主要组织相容性复合体（MHC）结合、由 MHC 把抗原举到细胞膜表面暴露出来，它才能识别。

### 巨噬细胞与抗原

* 巨噬细胞也由骨髓干细胞分化而来：在骨髓中发育成幼单核细胞，进入血液后分化为单核细胞，再迁移到组织中分化成组织特异的巨噬细胞。

* 功能有三条：吞噬大颗粒、吞噬其他细胞，以及作为抗原呈递细胞。

* > **定义**：能够引起免疫反应的任何分子或者病原体都是抗原，它可以是一种病毒，可以是细菌的细胞壁，也可以是一些蛋白质或者其他生物大分子。

* 体液免疫系统主要针对细菌的感染、胞外病毒，以及进入细胞内的病原生物、体内的外来蛋白质。

* 细胞免疫系统主要破坏被病毒感染的宿主细胞（这有可能是我们自身的细胞），以及某些寄生物和外来的移植组织。

### MHC 与抗原呈递

* MHC 是一种内在的膜蛋白，是一种异二聚体分子，宿主中蛋白质抗原的检测就是由它介导的。

* MHC 与细胞内被消化的蛋白质肽片段结合，把这些片段展示在细胞的外表面——等于把细胞内消化出来的碎片举到外面给免疫系统看。

* 展示出来的外来肽段就是免疫系统识别为「非我」的抗原；T 细胞受体与这些片段结合之后，T 细胞就像战士认出了目标，随后引发一系列免疫反应。

* MHC I 分布在几乎所有脊椎动物细胞的表面，展示的是细胞内随机发生的蛋白质降解和更新所衍生的肽。

* MHC II 分布在少数几种特化细胞（巨噬细胞、B 淋巴细胞），展示的是通过吞噬作用或胞吞作用内化的外来抗原经消化后的小肽段。

* MHC II 所在的这些特化细胞就是抗原呈递细胞：把外来抗原内化、消化成小肽段，再展示出来。

### 免疫记忆与疫苗

* 抗原耗尽以后，被激活的免疫细胞会在几天内死去，但少数被激活的 B 细胞和 T 细胞会成熟为记忆细胞，长期存在于身体当中，参与再次免疫。

* 已经被清除的抗原如果再次进入体内，记忆细胞就会迅速分裂增殖，再次免疫的速度更快、更强。

* 疫苗建立在这个机制上：一开始给机体一部分抗原——灭活的抗原、病原体本身，或者它特征性的一些蛋白片段——让机体产生相应的记忆细胞。

* 等再次被同一种病原体感染时，直接发生的就是更快更强的再次免疫。

### 抗体的类型与 IgG 结构

* 抗体也称为免疫球蛋白（immunoglobulin，Ig），是一类可溶性的血清糖蛋白，是血清当中最丰富的蛋白质之一。

* 抗体有五种类型：IgG、IgA、IgM、IgD 和 IgE，其中 IgG 是抗体当中的一大类。

* IgG 具有四条多肽链组成的对称结构：两条较长、分子量较大的重链，两条较短的轻链。

* 链与链之间由二硫键和非共价键连接，组成一个单体分子；其他几类抗体的结构也与 IgG 类似。

### 单克隆抗体

* 单克隆抗体是由单一的 B 细胞克隆产生的、高度均一的、仅仅针对某一个特定抗原的抗体。

* 克隆就是 copy：把一个 B 细胞复制成很多个，再从这些 B 细胞上得到抗体。

* 制备上一般采用杂交瘤技术，这样得到的抗体全部识别同一个表位，也就是抗原上被识别的那个位点。

### 免疫检测方法

* **酶联免疫吸附测定（enzyme-linked immunosorbent assay，ELISA）**

    * 是一种可以快速筛查和定量样品中抗原的方法。

    * 以待测抗原和酶标抗体的特异性反应为基础，通过测定酶活力来确定抗原或抗体的含量。

    * 流程是抗体与待测抗原特异结合 → 抗体上连着酶（酶标抗体）→ 洗去非特异结合（特异结合的抗体洗不掉）→ 测定酶活。

    * 道理很直白：非特异结合的都被洗掉了，留下来的酶量就对应被抗体抓住的抗原量，测酶活就等于测抗原。

* **Western blot（WB）**

    * 利用抗原—抗体的特异性反应检测目标蛋白的方法。

    * 检测的是抗原，但用到的试剂是抗体：只要能把抗体检测到，就说明样本当中有这个抗原。

    * 抗体给出的信号越强，说明样本里的抗原越多。

## 肌肉蛋白与分子马达

### 肌球蛋白与肌动蛋白

* 分子马达依靠核苷三磷酸作为能量，进行循环式的构象变化，推动细胞的运动。

* 核苷三磷酸包括 ATP、CTP、UTP 和 GTP，其中主要是 ATP。

* 分子马达的结构不断变化，就像一条腿不断往前走，细胞因此被推动。

* 肌肉当中最主要的蛋白质有两大类：肌球蛋白和肌动蛋白。

* 肌球蛋白由两条重链和四条轻链组成。

### 肌原纤维的带区

* 肌肉的结构是一层套一层、越来越小的：肌肉 → 肌束 → 肌纤维 → 肌原纤维。

* 肌原纤维呈现明带和暗带交替分布的结构：明带称 I 带，暗带称 A 带，由粗丝和细丝交替重叠排列产生。

* I 带被 Z 盘分成两半，Z 盘起锚钩的作用，用来固定细丝。

* A 带的中央有较明亮的 H 区，这里只有粗丝、没有细丝。

* A 带的正中间还有一条 M 线。

```text
肌肉
└─ 肌束
   └─ 肌纤维
      └─ 肌原纤维
         └─ 明带（I 带）与暗带（A 带）交替分布
```

## 蛋白质的溶液行为

### 两性解离

* **两性解离（amphoteric dissociation）**

    * 氨基酸的结构通式是 α 碳上连着一个羧基、一个氨基、一个氢和一个侧链基团。

    * α-羧基在碱性条件下失去一个质子变成羧酸根离子，α-氨基在酸性条件下得到一个质子变成铵离子。

    * 一个氨基酸既有可以失去质子的基团，也有可以得到质子的基团，这种性质就叫氨基酸的两性电离，也叫两性解离。

* 一条多肽链至少有一个完整的 N 端 α-氨基和一个完整的 C 端 α-羧基，这两个基团的行为和氨基酸里的完全一样，所以蛋白质和氨基酸一样具有两性解离的性质。

* 不止两端：酸性氨基酸的侧链含有羧基，碱性氨基酸含有可以得到质子的碱性基团，这些基团在一定 pH 下都可以解离成带正电或带负电的基团。

### 等电点

* > **定义**：当蛋白质溶液处于某一个 pH 时，蛋白质解离成正、负离子的趋势相等，成为两性离子，净电荷为零，此时溶液的 pH 就称为该蛋白质的等电点（pI）。

* 虽然有的基团失去质子、有的基团得到质子，但得到和失去的质子数量相等，所以整体不带电。

* pH = pI：净电荷为零，蛋白质不带电。

* pH < pI：相当于往溶液里加氢离子，羧基上原本失去的质子被补回来，氨基依然是带正电的状态，所以整个蛋白质带正电。

* pH > pI：相当于加氢氧根离子，氢氧根与氨基上的一个质子反应生成水，氨基不再带电，而羧基依然是带负电的状态，所以整个蛋白质带负电。

* 电泳就是把这个性质用起来：颗粒要在电场中移动必须带电。

| 环境 pH | 净电荷 | 电泳时的去向 |
| :--- | :--- | :--- |
| pH < pI | 正电 | 负极 |
| pH = pI | 零 | 不移动 |
| pH > pI | 负电 | 正极 |

* 蛋白质的等电点和氨基酸的等电点一模一样，只要把概念里的「蛋白质」换成「氨基酸」。

### 等离子点

* 蛋白质的等电点并不是一个死数：在有中性盐存在的溶液当中它会发生明显变化，钠离子、钾离子、铵根离子等都会影响蛋白质的等电点。

* 同一份蛋白质，在没有任何盐离子的清水里测是一个值，水里含一定盐离子又是另一个值。

* > **定义**：在没有其他盐类干扰时，蛋白质质子供体基团解离出来的质子数与质子受体基团结合的质子数相等，此时溶液的 pH 就称为该蛋白质的等离子点。

* 等离子点其实就是等电点的一个特例——没有其他盐类干扰时的等电点，此时蛋白质依然不带电、净电荷为零。

* 区别在于等离子点是蛋白质的特征性常数，不会随外界环境的变化而变化。

> **易错点**：等电点会随盐离子改变，等离子点不会；题目里出现「特征性常数」，对应的应该是等离子点。

### 胶体性质与稳定因素

* 蛋白质能形成胶体靠两个尺寸条件：分子量在 1 万到 100 万之间，分子直径在 1 到 100 nm 之间。

* 落在这个范围里，它在水中会形成比较稳定的亲水胶体。

* 因为蛋白质水溶液是胶体，所以它不能透过半透膜，也可以发生丁达尔效应和布朗运动。

* 稳定的第一个因素是水化膜：大多数蛋白质是球状蛋白，亲水基团排在外表面，会吸引水分子在颗粒表面形成一层水化膜。

* 稳定的第二个因素是表面同种电荷互斥：同一种蛋白质在同一杯液体、同一 pH 环境下带的电荷相同（除非这个 pH 正好是它的等电点），相同电荷互相排斥，颗粒均匀悬浮、不聚集也不沉淀。

* 反过来说，把水化膜去掉，或者把表面电荷去掉，或者两个都去掉，蛋白质就会从水中析出、沉淀——这就是所有沉淀方法的共同出发点。

### 沉淀方法

* 盐析：加盐，最常用硫酸铵；高浓度的盐离子与蛋白质表面的亲水基团争夺水分子，水化层被破坏，蛋白质随之析出。

* 有机溶剂沉淀：常用甲醇、乙醇和丙酮；它们同样能去除水化层，并且降低介电常数使蛋白质容易聚集。

* 有机溶剂还会导致蛋白质变性，变性后内部结构改变、原本折叠在内部的基团暴露出来，带正电与带负电的基团彼此结合而聚集。

* 重金属盐沉淀：前提是溶液的 pH 大于等电点，此时蛋白质带负电，与带正电的重金属离子结合形成不溶性的盐沉淀。

* 重金属中毒时喝牛奶的道理就在这里：从外面补进去的蛋白质去和金属离子结合，减少金属离子与体内正常功能蛋白的反应。

* 生物碱试剂和某些酸类沉淀：条件是 pH 小于等电点，蛋白质带正电，与带负电的酸根离子结合形成不溶性的盐沉淀。

* 加热：加热使蛋白质变性凝固，蛋清受热凝固成块，自然就从溶液里沉淀出来。

* 等电点沉淀：在等电点时蛋白质不带电，「表面带同种电荷互相排斥」这一条失去，胶体因此不稳定，容易发生沉淀。

| 方法 | 关键条件 | 动的是哪根支柱 |
| :--- | :--- | :--- |
| 盐析 | 高浓度中性盐（常用硫酸铵） | 水化膜 |
| 有机溶剂沉淀 | 甲醇／乙醇／丙酮 | 水化膜，兼降介电常数、变性 |
| 重金属盐沉淀 | pH > pI | 电荷（与金属正离子成不溶性盐） |
| 生物碱试剂与某些酸 | pH < pI | 电荷（与酸根负离子成不溶性盐） |
| 加热 | 加热 | 变性凝固 |
| 等电点沉淀 | pH = pI | 电荷（同种电荷斥力消失） |

* 底层只有一句话：把胶体稳定的水化膜和表面电荷拆掉——盐析和有机溶剂动水化膜，重金属盐、生物碱试剂与酸、等电点动电荷，加热则是让蛋白质直接变性凝固。
