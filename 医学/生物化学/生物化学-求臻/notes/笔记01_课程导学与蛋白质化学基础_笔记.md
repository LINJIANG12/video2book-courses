# 课程导学与蛋白质化学基础

## 生物化学的研究对象

* **生物化学（Biochemistry）**
    * > **定义**：生物化学是生命的化学，任务是了解生物的化学组成与结构，以及生命全过程中的各种化学变化。
    * 研究对象是发生在生物体当中的化学反应：小到细胞、大到器官与个体，都靠这些化学变化传递信息，并适应整个环境的变化。
    * 研究线索层层递进：先弄清参加变化的物质是什么（化学组成）→ 再认识其结构 → 再研究其化学变化 → 最终用以阐明从受精卵开始的发育、生长、衰老、死亡的全过程。
    * 从受精卵到死亡并不完整，还缺繁衍后代这一环，因此生殖、遗传的本质和规律也要一并阐明。

* **生物分子的结构与功能**
    * 参加化学变化的物质大多是大分子，即生物大分子；第一件事是把它们的结构与功能认识清楚。

* **物质代谢及其调节**
    * 对应三大营养物质：糖类、脂类、蛋白质类，分别落实为糖代谢、脂代谢、氨基酸代谢。
    * 摄入的大分子多为多聚物，须先消化成单体才能吸收，吸收后再被机体利用，例如糖类首先进行有氧氧化提供能量。

* **基因信息的传递及其调控**
    * 基因信息储存于 DNA：复制是 DNA 传给 DNA，转录是 DNA 传给 RNA，翻译是 mRNA 生成蛋白质，三者构成基因信息传递的主干。
    * 基因表达调控：一个细胞在特定时间点表达哪些基因、不表达哪些基因，由其所处环境决定，并受严格调控。

## 碳骨架与常见化学基团

* **碳骨架**
    * > **定义**：碳原子之间以碳碳单键、碳碳双键（烯键）或碳碳三键相连，构成不同长度的链状、分支状或环状结构，这些结构即有机物的碳骨架。
    * 生物体最基本的元素组成是碳元素，生物体整个的骨架就是有机物的碳骨架，生物体也因此被称为有机体。

* **羟基（-OH）**
    * 由一个氧和一个氢组成，极性较大，含羟基的部位就是分子中极性较大的部位。
    * 极性与溶解性的对应：极性越大 → 水溶性越强 → 亲水性越强；极性越小 → 水溶性越差 → 脂溶性越强 → 疏水。
    * 水可视为极性最大，油可视为极性最小（非极性物质）；相似相溶，非极性物质溶于油，强极性物质溶于水。
    * 生物体内是水相环境，极性大的分子容易溶解，而溶解状态往往正是它有活性的状态。
    * 肝脏中的羟化反应给色素、空气污染物这类极性小、脂溶性强的非营养物质加上羟基，提高极性以便排出体外。

* **烃链**
    * > **定义**：仅由碳和氢组成的链状结构。
    * 书写时氢原子默认省略；碳形成四根共价键，补全后两端碳各连三个氢、中间碳各连两个氢，如 `C-C-C-C` 补全为 `CH3-CH2-CH2-CH3`。

* **主链与侧链**
    * 肽链中 —NH—CH—C(=O)— 反复出现的这条线是主链；各 α-碳上连的 R 基团是侧链。
    * 肽键由前一个氨基酸的羧基与后一个氨基酸的氨基脱水缩合形成，肽链即由肽键反复连接而成。
    * 20 种编码氨基酸的其余三个部位相同，只有侧链（R 基）不同。

* **氨基、羧基与巯基**
    * 氨基：氮原子本可连三根键，三根都连氢即氨气；去掉一个氢剩下 $-NH_2$，连到氨基酸的 α-碳上即为 α-氨基。
    * 羧基：碳上连一个碳氧双键、再连一个羟基，合起来为 $-COOH$；连在 α-碳上即为 α-羧基。
    * 巯基：半胱氨酸所含的基团，性质与羟基相似，但极性比羟基更强，是 20 种编码氨基酸中极性最强的基团；因此半胱氨酸的极性很强。

## 化学键与分子间作用力

### 共价键与非共价键

* **化学键**
    * > **定义**：纯净物分子内或晶体内，相邻的两个或多个原子（或离子）之间强烈的相互作用力，统称化学键。
    * 在生物化学中分两大类：共价键与牢固性相对较弱的非共价键。

* **连接紧密程度的判据**
    * 只看是否形成共价键：形成共价键的，用超滤、透析这类物理方法去不掉，视为连接牢固；以非共价键相连的，超滤、透析可以去得掉，连接疏松。
    * > **易错点**：判据只有一个——有没有共价键；不要凭"看起来结合得紧不紧"下判断。

* **共价键（covalent bond）**
    * > **定义**：两个或多个原子共同使用外层电子，在理想状况下达到电子饱和，由此组成比较稳定的化学结构。
    * 轨道饱和：第一层 2 个电子即稳定，第二层与第三层各需 8 个电子；惰性气体最外层即饱和稳定。
    * 只有一层轨道的氢：得到一个电子凑成 2 个即稳定，得不到就失掉这个电子，成为氢离子。
    * 第二周期：氟（9 号，2,7）极易再得一个电子凑成八电子；锂这类最外层只有 1 个电子的原子则倾向失掉该电子，使内层 2 电子层成为最外层。
    * 水分子：氧（8 号，2,6）分别与两个氢共用一对电子，两个氢各达 2 电子、氧达 8 电子，写作 H—O—H。

* **非共价键的四种类型**

| 作用力 | 形成方式 | 典型位置 |
| :--- | :--- | :--- |
| 氢键 | 显正电性的氢与附近显负电性的原子之间的静电吸引，不共用电子对 | 水分子之间 |
| 盐键（离子键） | 带相反电荷的离子相互吸引，与静电排斥达到平衡 | 蛋白质的羧基与氨基、胍基、咪唑基之间 |
| 疏水作用力 | 非极性（疏水）基团在水相环境中自发聚集 | 蛋白质的疏水侧链之间；DNA 双螺旋的碱基之间 |
| 范德华力 | 分子间普遍存在的弱吸引，类似"万有引力" | 固体、液体、气体中无处不在 |

### 氢键

* **形成机理**
    * 水分子中共用电子对更偏向氧：氧的原子核更大、吸电子能力更强，电子带负电，于是氧显负电性、氢显正电性。
    * 一个水分子中显正电性的氢，与附近另一水分子中显负电性的氧相互吸引，这种静电吸引即氢键；反向的氧—氢之间同样如此。
    * > **提示**：氢键不共用电子对，只是显负电性的原子与显正电性的原子之间的静电吸引，这一点要与共价键分开。

* **宏观表现**
    * 水的表面张力由氢键造成：水面已高出杯口仍未流出，就是氢键在拉着。
    * 一个水分子里的氢拉着旁边水分子里的氧，它的氧又被另一水分子的氢拉着，一个拉一个、一个拉好几个。

* **肽链之间**
    * 一条肽链的羰基（碳氧双键）与另一条肽链氨基上的氢靠得足够近，两条肽链之间就形成一个氢键。
    * 这是氢键在蛋白质结构中发挥作用的典型方式。

### 盐键

* **形成机理**
    * 两个或多个原子（或化学基团）失去或获得电子成为离子后，带相反电荷的离子相互吸引；与此同时电子与电子、原子核与原子核相互排斥。
    * 静电吸引与静电排斥达到平衡时形成离子键；离子不能无限接近，接近到一定程度即开始排斥。
    * 氯化钠：钠（11 号，2,8,1）易失最外层一个电子成为带正电的 Na⁺，氯（17 号，2,8,7）易得一个电子、电子数 18 而质子数 17，成为带负电的 Cl⁻。

* **蛋白质中的盐键**
    * 带正、负电荷的侧链基团相互接近，通过静电吸引形成盐键。
    * 羧基容易失去质子而带负电；氨基、胍基、咪唑基容易得到质子而显正电，两类基团之间的作用力即蛋白质中的盐键。

### 疏水作用力

* **形成机理**
    * 非极性即等于疏水性；疏水性很强的分子"讨厌"水，在水相环境中彼此聚集，这种相互吸引即疏水作用力。
    * 生活例证：未洗的油碗泡一夜，油滴会聚在一起，因为水与油完全不互溶。

* **蛋白质与核酸中的疏水作用力**
    * 丙氨酸侧链是一个甲基，属疏水基团，两个丙氨酸靠近时甲基与甲基相互靠近。
    * 异亮氨酸侧链是由四个碳组成的烃链，疏水性比丙氨酸更强；亮氨酸亦然，两者侧链靠近后会因疏水作用力聚合。
    * DNA 双螺旋：两侧是磷酸与戊糖组成的骨架，中间阶梯由互补配对的碱基组成；碱基疏水性强，在细胞核的水相环境中相互吸引。

### 范德华力

* **普遍存在**
    * 固体、液体和气体中都存在，一般没有方向性和饱和性。
    * 比前述几种作用力更弱，可理解为分子与分子、原子与原子之间的"万有引力"，胜在普遍存在。

* **两条规律**
    * 组成和结构相似的物质，相对分子质量越大，范德华力越大。
    * 相对分子质量相等的物质，极性越大，范德华力越大。

## 化学式与反应方程式的写法

* **结构式**
    * > **定义**：用化学键表示分子里各直接相连原子的结合情况的式子。
    * 书写要求：一定要把官能团单独写出来；官能团是决定该化合物到底是什么物质的基团，乙醇因含羟基而属醇类。
    * 乙醇结构式可简化为结构简式 $CH_3CH_2OH$，再进一步简写为 $C_2H_5OH$。

* **分子式**
    * > **定义**：用元素符号表示物质的分子组成以及相对分子质量的化学式，只标元素种类与各自个数。
    * 乙醇写作 $C_2H_6O$：2 个碳、6 个氢、1 个氧；三种写法中分子式最简单。

* **反应方程式**
    * > **定义**：用化学式表示化学反应的式子，展示反应物与生成物之间的关系。
    * 乙醇燃烧需点燃，产物为两分子二氧化碳与三分子水：

$$\mathrm{C_2H_5OH + 3\,O_2 \xrightarrow{\text{点燃}} 2\,CO_2 + 3\,H_2O}$$

* **生物化学中的差别**
    * 化学中反应方程式一般要配平；生物体内的化学变化极其复杂、很难配平，故只关注"底物 → 产物"这条线，对配平关注较少。

## 氨基酸的基本属性

* **编码氨基酸的共性**
    * 常见编码氨基酸共 20 种，α-碳上分别连一个氨基、一个氢、一个羧基与一个 R 基（侧链）；20 种之间只有侧链不同。
    * 构成蛋白质的常见氨基酸，除甘氨酸没有手性中心外，一般为 L-氨基酸。

* **脯氨酸（Proline，Pro）**
    * 属于亚氨基酸：侧链回折后与 α-位上含氮的基团形成环状结构，氨基被圈进环里，故称亚氨基酸。
    * 是否算 α-氨基酸口径不一：多数教材与多数看法认为它也算 α-氨基酸；规范口径可答"对"，判断题考到时倾向判"错"——判断题不会白问。
    * 只需记两条：脯氨酸是亚氨基酸；其特殊之处是侧链回折成环、把含氮基团圈了进去。

* **物理性质**
    * α-氨基酸为白色晶体，熔点高，结晶形状特殊，可据结晶形状鉴别不同的氨基酸。
    * 除半胱氨酸与酪氨酸溶解度较低外，其余氨基酸都可溶于水；这两个是"溶解度低"，不是"不溶于水"。
    * 亚氨基酸——羟脯氨酸与脯氨酸——可溶于乙醇这类有机溶剂。

* **必需氨基酸**
    * 共 8 种：甲硫氨酸、缬氨酸、赖氨酸、异亮氨酸、苯丙氨酸、亮氨酸、色氨酸、苏氨酸。
    * 口诀：甲缬赖一本亮色书。

* **不常见蛋白质氨基酸**
    * 一般规律：在已经合成的肽链上，由常见氨基酸经专一的酶催化修饰而来，属翻译后修饰，没有密码子。
    * 例外：硒代半胱氨酸与吡咯赖氨酸含有密码子，直接由密码子翻译得到。

* **极性与非极性的空间分布**
    * 极性代表亲水；生物体内是溶液环境，极性氨基酸多位于蛋白质外部，非极性（疏水）氨基酸多躲在内部。
    * 变性的分子图景：侧链相互作用被瓦解打开，藏在内部的非极性氨基酸暴露出来，蛋白质随之沉淀。
    * 疏水相互作用是稳定蛋白质结构的重要作用力。
    * > **易错点**：天冬酰胺的侧链参与氢键形成、起稳定球蛋白结构的作用，位于内部的较多；"极性氨基酸都在外部"这类绝对化说法不成立。

## 氨基酸侧链官能团与特征反应

* **侧链官能团速查**

| 氨基酸 | 标志官能团 | 要记住的经典性质 |
| :--- | :--- | :--- |
| 半胱氨酸 | 巯基 | 两个巯基可形成二硫键 |
| 甲硫氨酸 | 硫醚 | 与半胱氨酸的巯基区分开 |
| 丝氨酸、苏氨酸 | 羟基 | 参与磷酸化等修饰 |
| 酪氨酸 | 酚羟基（芳香环上） | 性质与丝氨酸、苏氨酸完全不同 |
| 天冬氨酸、谷氨酸 | 侧链羧基 | 酸性氨基酸 |
| 赖氨酸 | 侧链末端氨基 | 碱性氨基酸 |
| 精氨酸 | 胍基 | 碱性很强；可发生坂口反应 |
| 组氨酸 | 咪唑基 | 参与酶的酸碱催化；有缓冲功能 |
| 色氨酸 | 吲哚环 | 含氮杂环 |

* **分类角度的相对性**
    * 色氨酸按芳香族划分属芳香族氨基酸，按环结构划分属含氮杂环；同一氨基酸可从不同角度归类，知道其本质即可。

### 组氨酸的缓冲能力

* **来源在 R 基**
    * 真正起作用的是侧链上的咪唑基，该可解离基团的 pKa 接近中性，$pK_R \approx 6.0$。
    * 咪唑基能在"接受一个质子"与"失去一个质子"之间来回切换，充当调节者，把溶液 pH 控制在一定范围内。

* **排除 pI 的论证**
    * pI 接近 7 的氨基酸不止组氨酸一种，别的并没有缓冲能力，可见关键在 R 基而不在 pI。

* **缓冲体系的含义**
    * > **定义**：缓冲体系是一个基团既能较容易地接受氢，也能较容易地释放氢，从而把 pH 稳定在一定范围。

### 甲醛滴定法

* **要解决的问题**
    * 用常规化学试剂滴定氨基酸，反应终点 pH 过高（12~13），无法按常规方式滴定，需要用化学办法把终点降下来。

* **原理**
    * 甲醛与氨基生成羟甲基结构；甲醛过量时游离氨基被消耗，解离平衡右移，释放出更多氢离子。
    * 氢离子增多使反应终点 pH 降低，从 12~13 降到 9。

* **判断水解程度**
    * 蛋白质中不存在游离的氨基，只有长链被水解打开后，游离氨基与羧基才暴露出来。
    * 甲醛滴定量大，说明游离氨基多、游离氨基酸多，蛋白质分解程度高；用量少则说明结构相对完整。

### 茚三酮反应

* **反应过程**
    * 弱酸性条件下茚三酮与 α-氨基酸共热，引起 α-氨基酸氧化脱氨。
    * 脱下来的氨把茚三酮还原，还原型茚三酮再与另一分子茚三酮作用，生成紫色产物，最大吸收峰在 570 nm。
    * 20 种标准氨基酸中有 19 种走这条紫色产物路径。

* **两种例外**
    * 脯氨酸生成亮黄色产物，最大吸收峰在 440 nm；羟脯氨酸同样呈亮黄色。
    * 原因在结构：两者有含氮的环状结构，没有 α-位上游离的一级氨基，一级氨基结构不同，产物就不同。
    * > **易错点**：判断题"蛋白质氨基酸与茚三酮反应都呈紫色"不成立，脯氨酸（及羟脯氨酸）生成亮黄色产物；颜色与 570 nm、440 nm 两个数值都要记。

* **应用**
    * 检测和定量氨基酸。

## 极性、层析与氨基酸分离

### 纸层析与 Rf 值

* **纸层析（paper chromatography）**
    * 固定相是水，流动相是有机溶剂——与直觉相反的一点。
    * 越亲水的氨基酸越被固定相的水牢牢抓住、不能随有机溶剂移动，迁移距离越近；越疏水的氨基酸越容易随有机溶剂走、摆脱水的束缚，跑得越远。

* **Rf 值（retention factor）**
    * > **定义**：Rf 值 = 氨基酸移动的距离 ÷ 溶剂前沿移动的距离。
    * Rf 值越高，越不容易被固定相的水抓住，越是非极性的疏水氨基酸；Rf 值越低，越是极性、亲水的氨基酸。

### 极性强弱的记忆顺序

* **最亲水的一端**
    * 酸性氨基酸（天冬氨酸、谷氨酸）与碱性氨基酸（精氨酸、赖氨酸）带电荷，一定最亲水，属常识，不必专门背。
    * 酰胺类同样带电荷，也归在亲水一侧。

* **最疏水的一端**
    * 异亮氨酸最疏水：侧链碳数最多，最像一个有机烷烃；缬氨酸次之，亮氨酸再次。
    * 亮氨酸、缬氨酸、异亮氨酸都是支链氨基酸，因支链而额外疏水；此外苯丙氨酸与半胱氨酸也疏水。
    * 背法：亲水端记住酸性、碱性氨基酸，疏水端背五个——异亮氨酸、缬氨酸、亮氨酸、苯丙氨酸、半胱氨酸，中间一大段不必背。

### 离子交换柱上的洗脱顺序

* **柱子的辨析**
    * 阳离子交换柱是"交换、吸收阳离子"的柱子，不是"含有阳离子去结合阴离子"的柱子。

* **判据**
    * 电荷决定两头：酸性氨基酸带负电，不能与阳离子交换柱良好结合，最先洗脱；碱性氨基酸带正电，与树脂结合最紧，最后洗脱。
    * 疏水决定中间：商品化树脂在制造过程中都会引入疏水介质，疏水氨基酸与任何交换柱都结合得比较紧、洗脱更慢。
    * 等价理解：洗脱用水去洗，亲水的洗得快，疏水的被牢牢抓住。

* **例题结论**
    * 天冬氨酸、精氨酸、异亮氨酸、甘氨酸在强酸性阳离子交换柱上的洗脱顺序：天冬氨酸 → 甘氨酸 → 异亮氨酸 → 精氨酸。

### 亲和层析

* **His 标签与镍柱**
    * 给目标蛋白加 His 标签，即六个组氨酸连成一串；标签不影响蛋白表达，也不影响其功能。
    * 镍是天然能与咪唑发生配位作用的金属，而组氨酸含咪唑，故带 His 标签的目的蛋白与镍柱紧密结合。

* **操作流程**
    * 样品过柱：杂蛋白直接流走，目的蛋白结合在镍柱上。
    * 用水洗数遍洗掉杂蛋白，再用纯咪唑溶液慢慢洗脱目的蛋白。

* **原理与优点**
    * > **定义**：复杂蛋白样品通过柱子后只保留与固定相特异性结合的蛋白、其余杂蛋白被洗脱，即亲和层析。
    * 原理是用配位作用、抗原与抗体、酶与底物这类特异性结合实现分离。
    * 优点：选择性特别高，纯度较高，操作较简单。

### 双向电泳

* **两向的分工**
    * 第一向为等电聚焦电泳（isoelectric focusing，IEF），按 pI 的差异分离。
    * 第二向为 SDS-PAGE（sodium dodecyl sulfate polyacrylamide gel electrophoresis），按分子量分离。
    * 记忆点：先按等电点分，再按分子量分。

* **顺序不可颠倒**
    * 若先做 SDS-PAGE，蛋白质已被 SDS 变性，等电点差异显现不出来，第二步等电聚焦就做不成。

## 氨基酸的解离与等电点

### 三步解离与兼性离子

* **完全质子化状态（A⁺）**
    * 环境极酸时 pH 极小、必然小于 pI，氢离子非常丰富，会攻占氨基酸上两个可解离的位置，把负号全部填成正号，得到完全质子化的氨基酸。

* **兼性离子（zwitterion，A⁰）**
    * > **定义**：同一分子上带一个正电荷和一个负电荷（氨基质子化、羧基去质子化）、净电荷为零的状态。
    * 碱性增强后第一个脱落的是羧基上的氢：羧基的酸性比氨基强、pKa 比氨基小，酸性强、pKa 小的基团氢先掉。
    * 氨基酸恰好全部以兼性离子状态存在时，溶液的 pH 被定义为等电点（isoelectric point，pI），此刻 pI = pH。

* **完全去质子化状态（A⁻）**
    * 碱性继续增强，氨基上的氢也脱掉，得到完全去质子化的氨基酸。
    * 全图景：强酸中的 A⁺ → 兼性离子 A⁰ → 强碱中的 A⁻，这是后续所有推导的基础。

### 解离常数与 pI 公式

* **两个解离常数**
    * $K_1 = \dfrac{[H^+][A^0]}{[A^+]}$，$K_2 = \dfrac{[H^+][A^-]}{[A^0]}$

* **推导**
    * 两式相乘：$K_1K_2 = [H^+]^2 \cdot \dfrac{[A^-]}{[A^+]}$。
    * 等电点时兼性离子对外不呈现电性，$[A^-] = [A^+]$，两项约去，得 $K_1K_2 = [H^+]^2$。
    * 两边取负对数：$2\,\mathrm{pH} = pK_1 + pK_2$，即 $pI = \dfrac{pK_1 + pK_2}{2}$。

* **甘氨酸算例**
    * 已知 $pK_1 = 2.34$、$pK_2 = 9.60$，$pI = (2.34 + 9.60)/2 = 5.97$。

### 酸性氨基酸的 pI

* **优先 α-碳原则**
    * 在不违反化学中大小规律的前提下，优先让 α-碳上的氢原子解离。

* **谷氨酸的解离次序**
    * 三个可解离基团：α-羧基、R 基羧基、α-氨基。
    * 第一步 α-羧基解离，R 基羧基先不动；第二步轮到 R 基羧基（羧基比氨基更容易先解离）；最后才轮到氨基。

* **解离常数的定义方式**
    * $K_1$ 是 α-碳上羧基的解离常数，$K_2$ 是 α-碳上氨基的解离常数，$K_R$ 是 R 基羧基的解离常数。
    * 三个常数按基团性质定义，不随解离次序改变。

* **pI 计算**
    * 兼性离子夹在第一步与第二步之间，公式中 $pK_2$ 的位置由 $pK_R$ 取代：$pI = \dfrac{pK_1 + pK_R}{2}$。
    * 谷氨酸：$(2.19 + 4.25)/2 = 3.22 \approx 3.2$。
    * 第三步氨基解离可忽略：每多一步解离浓度就低一个层级（指数关系），其解离常数往往比前面小好几个数量级。
    * > **易错点**：仍套 $(pK_1+pK_2)/2$ 会算错；题目同时给出 $K_1$、$K_R$、$K_2$ 时，只取 $pK_1$ 与 $pK_R$。

### 碱性氨基酸的 pI

* **赖氨酸的解离次序**
    * 第一步仍是 α-羧基先解离：优先 α-碳原则照旧，羧基酸性本来也更强。
    * 第二步比较 α-氨基与侧链末端氨基，两者强弱差不出明显大小时，优先 α-碳原则让 α-氨基先解离。
    * 最后侧链氨基解离。

* **pI 计算**
    * 净电荷为零的兼性离子夹在 α-氨基解离（$K_2$）与侧链氨基解离（$K_R$）之间，故 $pI = \dfrac{pK_2 + pK_R}{2}$。
    * 复习取舍：目标院校很少考这部分时记住公式即可；真题考过酸碱平衡的推导或计算，则必须掌握整套推导。

### 净电荷为零的含义

* **净电荷的含义**
    * pH = pI 时氨基酸净电荷为零，但兼性离子一端是质子化的氨基（正电）、一端是去质子化的羧基（负电），一正一负相互抵消。
    * "净"是净盈亏的净：只能说正负电荷加起来等于零，不能说分子上没有电荷。

* **判断题口径**
    * "等电点时氨基酸主要以兼性离子存在"应判对，理由正是正负电荷相互抵消、净电荷为零。
    * > **易错点**：净电荷为零不等于分子基本不带电——兼性离子上明明囤着一个正电荷、一个负电荷，只是一加一减抵消了。

## 立体化学概念辨析

### 构型、旋光与顺反异构

* **L/D 构型（configuration）**
    * 指分子的构型，对氨基酸而言是在特定投影规则下描述手性中心的相对构型，属化学上的书写标记。
    * 构成蛋白质的常见氨基酸，除甘氨酸没有手性中心外，一般为 L-氨基酸；甘氨酸不用 L、D 描述。

* **旋光方向（optical activity）**
    * 左旋、右旋是实验测出来的参数，与 L/D 构型没有必然的逻辑联系。
    * 两者不能互推：一个是测出来的性质，一个是化学写法。

* **顺反异构**
    * > **定义**：描述某个结构在不能自由旋转（类似双键）时，两侧基团的空间相对位置；高中加成反应中的顺式加成、反式加成即属此类。
    * X-Pro（某氨基酸连脯氨酸）可以反式也可以顺式，X-Pro 的出现大大提高了顺式构型出现的概率，不过整条肽链仍以反式为主。

### 构型与构象

* **构象（conformation）**
    * 构象改变不要求共价键的断裂与重新形成，往往扭一个位置，构象就变了。

* **构型（configuration）**
    * 构型改变必须把共价键打碎、再重新接上；扭一个位置不叫构型改变，叫构象改变。

* **记法**
    * "象"是长相、"形"是风骨：长相易变，风骨难改；据此记构象易变、构型难变。

## 肽键与肽平面

### 肽键的本质与双键性

* **肽键（peptide bond）**
    * > **定义**：一个氨基酸的 α-氨基与另一个氨基酸的 α-羧基脱水缩合形成的键，本质是一个酰胺键；酰胺键在蛋白质里就叫肽键。
    * 形成方式：羧基脱下羟基、氨基脱下一个氢，生成一分子水，中间形成该化学键。

* **双键性质的来源**
    * C–N 酰胺键不是普通单键，有一定的共振离域效果，由此产生部分双键性质。
    * 键长介于单键与双键之间：比单键短，但略长于双键；因具双键性质而不能自由旋转。

* **构型**
    * 一般肽键为反式构型，反式与顺式之比约为 1000:1。

### 肽平面与二面角

* **肽平面（peptide plane）**
    * > **定义**：参与肽键形成的六个原子不能自由转动、处于同一平面，这个平面叫肽平面，又称肽单元，也叫酰胺平面。
    * 六个原子：第一个氨基酸的 α-碳、羧基碳、羰基氧，第二个氨基酸的氨基氮、氨基氢、α-碳。
    * 一条肽链由若干肽平面一个接一个连成，相邻两个肽平面由 α-碳连接。

```text
                  O                 O
                  ||                ||
...---N-----Ca----C-----N-----Ca----C-----N---...
            |<---------------->|
```

* **图示说明**
    * 括号圈住的为一个肽平面：Ca、羧基碳 C、羰基氧 O、氨基氮 N、氨基氢 H、下一个 Ca 共六个原子。
    * O 连在羧基碳上、H 连在氨基氮上；两个肽平面在中间的 Ca 处衔接。

* **二面角**
    * α-碳与羧基碳之间的夹角记作 ψ，α-碳与氨基氮之间的夹角记作 φ。
    * 相邻肽平面通过这两个角形成一定夹角，最终折叠出空间结构；肽平面是蛋白质形成三维结构的基础。

## 蛋白质三维结构

### 定义与层次

* **三维结构（空间结构、空间构象）**
    * > **定义**：一个蛋白质整体、或者整体当中任意部分中原子的空间排列，称为它的三维结构，也叫空间结构或空间构象。
    * 包括二级、三级、四级三个层次，即三维结构等于二、三、四级结构的总和。

* **层次比喻**
    * 把金属丝拧成的摩托车当作整个蛋白质：整车的空间结构对应四级结构。
    * 每个部件由一条金属丝拧成，一条金属丝即一条肽链，部件的空间结构对应三级结构。
    * 发动机处由一条链拧出好多螺旋，这些局部螺旋对应二级结构；螺旋本身也是空间结构，也是三维的。

### 六条性质

* **取决于一级结构**：三维结构取决于氨基酸序列，而序列就是一级结构，一级结构是空间结构的基础。
* **以少数稳定结构存在**：蛋白质大多数以一种或少数几种稳定结构存在；同一蛋白质的构象不止一种，酶需要激活与抑制至少两种构象，活性分级越多，对应构象越多。
* **决定功能**：蛋白质的功能取决于三维结构；一级结构是三维结构的基础，三维结构又是功能的基础。
* **靠非共价相互作用稳定**：稳定特定蛋白质结构的是一些非共价的相互作用。
* **存在相似性**：不同蛋白质之间常有一些相似的序列和结构，例如都含若干段螺旋。
* **不是静态的**：少数几种稳定结构之间可以相互转换，随外界环境变化与细胞功能需要作出调整。
* > **提示**："少数几种稳定构象"与"结构动态"并不矛盾：稳定指构象种类有限，动态指这些构象之间可以转换。

### 稳定结构的化学键

* **两大类键的归属**

| 大类 | 具体的键 | 主要维持 |
| :--- | :--- | :--- |
| 共价键 | 肽键、二硫键 | 一级结构 |
| 非共价键 | 氢键、盐键（离子键）、疏水作用力（疏水键）、范德华力 | 二、三、四级结构（三维结构） |

* **两点补充**
    * 二硫键在很多教材上也被归入维持三维结构的化学键。
    * 非共价键单个与共价键相比很弱，但数量多，多了就能撑起整个三维结构；四种非共价键中疏水作用力占主导地位。
    * > **定义**：盐键又叫离子键；疏水作用力又叫疏水键。

### 肽链的骨架与方向

* **骨架**
    * 除去侧链、再除去氢原子后剩下的原子组成骨架：氨基氮—α-碳—羧基碳—氨基氮—α-碳—羧基碳，重复排列。
    * 忽略氢的原因：氢是所有原子中最小的原子，对整个结构的贡献太小。

* **方向**
    * 肽链从 N 端（氮端）走向 C 端（碳端），因为生物体合成肽链就是从 N 端向 C 端进行。
    * 实验室用固相合成法合成多肽时方向相反，从 C 端到 N 端。

## 蛋白质一级结构的测定

### 从目标反推的流程

* **目标**
    * 测出整条蛋白质从 N 端到 C 端的完整氨基酸序列，以及必要的共价连接关系。

* **拆链**
    * 先看蛋白质由几条肽链组成；多条链一般是亚基通过非共价作用结合，用尿素、盐酸胍这类破坏非共价作用的试剂拆开。
    * 拆链与拆二硫键是两件事：两条链之间还有二硫键时，必须再用还原剂把二硫键拆开。

* **切片段与交叉拼接**
    * 短肽往往比一条超长的多肽容易测，故用特异性蛋白酶把长链切成小片段。
    * 只用一种切法只能得到 A、B、C 这些片段，却不知它们如何排列；换第二种切割方法得到 D、E、F，两套片段之间存在重叠区，据此交叉拼接。
    * 例：第一套切出 ABCDE，第二套切出 DEFGH，D 与 E 重叠，即可拼成 ABCDEFGH。

* **二硫键的位置**
    * 切断二硫键放在第一步，目的是把长链变短链；确定位置放在最后，因为序列测出来才知道半胱氨酸在何处。
    * 若该蛋白根本没有半胱氨酸，最后一步就不必做；定位方法为对角线电泳。

```text
拆链：先看蛋白质由几条肽链组成
      亚基间靠非共价作用结合 —— 用尿素、盐酸胍拆开
      链间还有二硫键 —— 用还原剂拆开（拆链与拆二硫键是两件事）
  |
切片段：用特异性蛋白酶把长链切成小片段
      只用一种切法只能得到片段、不知排列 —— 换第二种切法
  |
测与拼：测每条短片段的序列，两套片段靠重叠区交叉拼接
      第一套 ABCDE，第二套 DEFGH，重叠 DE —— 拼出 ABCDEFGH
  |
定位置：最后确定二硫键的位置（对角线电泳）
```

### 对角线电泳的原理

* **二硫键（disulfide bond）**
    * 肽链链内或链间两个半胱氨酸残基的巯基之间氧化而成的键。
    * 一条链内部的叫链内二硫键，两条链之间的叫链间二硫键。

* **电泳与迁移率**
    * 电泳：粒子在外加电场作用下，朝着与自身电性相反的方向移动。
    * 迁移率：单位时间内粒子移动的距离，与粒子的大小、带电量、形状都有关。

* **试剂与条件**
    * 胃蛋白酶专一性很低——胃里什么蛋白质都要消化，不可能只消化一部分；专一性低带来切点很多，切出的每一小段肽段都比较小。
    * 胃蛋白酶在 pH 2.0 的强酸环境工作，强酸可防止二硫键发生交换反应，保证构象与构型跟原来一样。
    * 过甲酸使二硫键断裂，断裂后还会进一步氧化成磺酸基。
    * 茚三酮可使蛋白质显色，用于确定斑点位置。

* **流程**
    * 胃蛋白酶把长肽链切成很多小肽段 → 第一向电泳按各自迁移率分开成一条带 → 切下整条带暴露在过甲酸蒸汽中 → 左旋 90 度贴回点样端跑第二向电泳 → 茚三酮显色定位。

* **含二硫键者的变化**
    * 肽段变小：一条长肽段断成两小条。
    * 负电荷增加：二硫键本身不怎么带电，氧化成两个磺酸基后都带电。
    * 迁移率随之改变，落点偏离对角线。

* **无二硫键者的落点**
    * 过甲酸处理无事发生，第二向走的距离仍等于第一向走过的距离，落点构成正方形并连成对角线。
    * 正方形之所以成立：第一向相邻色带间距为 B−A、C−B，第二向竖直方向间距相同，横竖相等，A 与 B 恰为对角顶点；A 与 C 的连线即对角线，B 也落在其上。

### 对角线电泳的电场极性

* **加速度关系**
    * $a = QE/m$：负电荷增加即 Q 变大，肽段变小即 m 变小，而电场强度 E 由外加电场决定、保持不变。

* **极性摆错会失效**
    * 若按左正极、右负极摆放，负电荷增加后前进方向上受到的电场力反而减小；F 减小、m 也减小，加速度可能不变，含二硫键的肽段仍落在对角线上，分不出来。
    * 应改为左负极、右正极：负电荷增加后向右的力增加，F 上升而 m 减小，加速度必然上升，肽段必然偏离对角线。

* **应试口径**
    * 填空只考过甲酸处理之后肽段怎么变：肽段变小、负电荷增加。
    * 问答若考原理，把上述流程整理成文字写下来即可。

## 肽链的固相合成

### 保护与活化的必要性

* **保护基**
    * 每个氨基酸都必须既有氨基又有羧基，两个氨基酸相接时无法确定是 A 的氨基连 B 的羧基，还是 A 的羧基连 B 的氨基。
    * 保护住一个氨基酸的氨基或羧基，让它只剩一端去反应，接肽的顺序才定得下来。

* **活化剂**
    * 氨基与羧基在普通化学条件下不是快速、自发发生的反应，必须先活化，两者才能在溶液中完成连接。

* **分工**
    * 保护是不让不该反应的地方反应；活化是让真正需要反应的地方反应。
    * 具体保护基与活化剂的名称长文未说明，能有余力再背，不必强求。

### 合成方向

* 人工固相合成肽链的方向是从 C 端到 N 端。
* 生物体翻译的方向是从 N 端到 C 端，人工合成恰好是反的。
* > **易错点**：两个方向不要记反——生物体翻译 N → C，人工固相合成 C → N。
