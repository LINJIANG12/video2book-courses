# 核酸化学

## 核酸的种类与分布

### 化学本质与细胞定位

* **脱氧核糖核酸（DNA）**

    * > **定义**：由四种脱氧核苷酸经 3′,5′-磷酸二酯键连接成的多聚物，是遗传信息的载体。

    * 主要存在于真核生物的细胞核，线粒体与植物叶绿体也各有自己的 DNA，但最主要的仍是细胞核。

    * 功能是携带遗传信息，并把它从亲代传给子代。

* **核糖核酸（RNA）**

    * > **定义**：由四种核苷酸经 3′,5′-磷酸二酯键连接成的多聚物，通常是 DNA 转录的产物。

    * 主要分布于细胞核、细胞质和线粒体，参与遗传信息的复制与表达。

* **原核与真核的 DNA 组织**

    * 原核细胞没有明显的细胞核，DNA 集中在细胞质中的核区；每个原核细胞只有一条染色体，真核细胞有多条，人有 23 对。

    * 病毒的遗传物质可以是 DNA 也可以是 RNA，两者都能以单链或双链形式存在——RNA 可形成双链，DNA 病毒也能以单链发挥功能。

* **环状双链 DNA 与线性染色体**

    * 原核生物核区的 DNA、质粒 DNA、真核生物的细胞器 DNA（线粒体 DNA、叶绿体 DNA）都是环状双链分子。

    * 真核生物染色体是线性双链 DNA，末端为高度重复序列，重复形成的结构叫端粒。

* **质粒**

    * > **定义**：原核生物染色体以外的环状双链 DNA 分子，比原核生物自身的 DNA 小得多，能自我复制，并可使宿主细胞获得附加性状。

    * 附加性状的来路：质粒进入原核细胞后被表达为蛋白质，宿主由此获得新的性状。

### 三类 RNA 的分工

* **核糖体 RNA（rRNA）**

    * 核糖体的组成成分，参与核糖体功能的发挥；核糖体的工作是翻译，把 mRNA 上的信息翻译成氨基酸序列。

* **信使 RNA（mRNA）**

    * 蛋白质生物合成的模板，携带遗传信息。

* **转运 RNA（tRNA）**

    * 转运氨基酸：把氨基酸从细胞质转运到核糖体，以 mRNA 为模板逐个串联成多肽链，多肽链再盘曲折叠成成熟蛋白质。

* 三类 RNA 发挥作用的位置都在细胞质。

* **核内不均一 RNA（hnRNA）**

    * 又称 pre-mRNA，是真核 mRNA 的前体。

    * 经加帽、加尾、剪接后成为成熟 mRNA，出核进入细胞质才作为模板发挥功能。

### 多顺反子与单顺反子

* **多顺反子**

    * > **定义**：原核生物的一条 mRNA 编码多个多肽链，各结构基因位于同一转录单位，共用一个转录起点与一个转录终点。

    * 每个结构基因各有自己的翻译起始位点与翻译终止位点。

    * 同一条 mRNA 编码出的不同多肽链，成熟后功能上相互协调。

* **单顺反子**

    * > **定义**：真核生物基因的转录产物，一条 mRNA 只含一个翻译起始点和一个终止点，只编码一条肽链。

* 判别只看最终编码多肽链的多少：一条为单顺反子，多条为多顺反子。

### siRNA 与 RNA 干扰

* **小分子干扰 RNA（small interfering RNA，siRNA）**

    * > **定义**：由内源或外源较长双链 RNA 诱导产生的双链小 RNA，功能是降解靶 mRNA、下调对应基因的表达。

    * 靶 mRNA 必须与 siRNA 完全互补才会被降解。

    * 直接向细胞注射 siRNA 同样有效；据此可制成药物——针对表达量过高致病蛋白的 mRNA 设计 siRNA，抑制该蛋白表达。

* **RNA 干扰**

    * 链路：长双链 RNA（dsRNA）→ Dicer 酶切割成 siRNA → 双链解开、一条链与靶 mRNA 完全互补结合 → 诱导蛋白质结合形成 RISC → 靶 mRNA 沉默并被水解降解。

    * > **定义**：RNA 诱导的沉默复合体（RISC，RNA induced silencing complex）——siRNA 结合靶 mRNA 后招募蛋白质形成的复合体，负责让靶 mRNA 沉默并降解。

    * 前体 dsRNA 可以是内源的，也可以外源注射 siRNA 直接启动。

### DNA 与 RNA 的差异

| 比较项 | DNA | RNA |
| :--- | :--- | :--- |
| 戊糖 | 脱氧核糖（2′位脱氧） | 核糖 |
| 碱基组成 | A、G、C、T | A、G、C、U |
| 多聚核苷酸链数目 | 双链 | 大多数是单链 |
| 细胞内双螺旋结构 | B 型和 Z 型 | A 型 |
| 种类 | 只有一种 | 多种（tRNA、rRNA、mRNA 及小 RNA） |
| 功能 | 充当遗传物质，储存并传递遗传信息 | 种类多，功能也多 |
| 碱溶液中的稳定性 | 比较稳定 | 不稳定，很容易水解 |

* 戊糖差异是最根本的化学差别：DNA 的脱氧核糖在 2′位脱氧，RNA 的核糖 2′位带羟基。

* 碱基差异只有一个字母：DNA 用 T，RNA 用 U。

* 构型差异：DNA 在细胞内主要是 B 型与 Z 型，RNA 是 A 型。

* 稳定性差异：RNA 在碱溶液中不稳定、很易水解，DNA 比较稳定。

## 化学组成与碱基结构

### 组成层次与戊糖

* **核苷酸**

    * > **定义**：核酸的基本组成单位，由磷酸、戊糖、碱基三部分组成；去掉磷酸剩下核苷，核苷再分成戊糖与碱基。

    * 拆解次序：核酸 → 核苷酸 → 核苷 → 戊糖 + 碱基。

* **戊糖**

    * 五个碳的五碳糖；五元环只含 1～4 号碳，1 号与 4 号碳共用一个氧成环，5 号碳在环外。

    * 核糖的 2′位碳带完整羟基，是 RNA 的戊糖；2′位羟基脱氧即成脱氧核糖，是 DNA 的戊糖。

    * > **易错点**：DNA 的“脱氧”脱在戊糖 2′位碳的羟基上，不在其他位置。

* **碱基的归属**

    * 腺嘌呤、鸟嘌呤、胞嘧啶在 DNA 与 RNA 中都存在。

    * 核糖与尿嘧啶主要存在于 RNA；脱氧核糖与胸腺嘧啶主要存在于 DNA。

### 碱基的种类与母环

* **碱基**

    * > **定义**：含氮的杂环类化合物，分嘌呤与嘧啶两类，母环都近似平面。

    * 嘌呤有腺嘌呤（A）、鸟嘌呤（G）；嘧啶有胞嘧啶（C）、尿嘧啶（U）、胸腺嘧啶（T）。

* **嘧啶母环**

    * 六元环、含两个氮原子的含氮杂环，三个嘧啶都由它衍生。

    * 尿嘧啶：2 位与 4 位碳各带一个碳氧双键。

    * 胸腺嘧啶：在尿嘧啶的 5 位碳上再加一个甲基——从尿嘧啶合成胸腺嘧啶只需提供一个甲基。

    * 胞嘧啶：2 位碳一个碳氧双键，4 位碳一个氨基。

* **嘌呤母环**

    * 六元环并五元环，共 9 个原子，1、3、7、9 位是氮。

    * 腺嘌呤：6 位碳加一个氨基。

    * 鸟嘌呤：6 位碳加碳氧双键，2 位碳加氨基。

    * 腺嘌呤与鸟嘌呤都带氨基，脱氨基作用会破坏 DNA 中的这两种碱基。

### 碱基母环的合成原料

* **嘧啶母环**

    * 原料三种：天冬氨酸、谷氨酰胺、二氧化碳。

    * 谷氨酰胺与二氧化碳先缩合成氨基甲酰磷酸，由它提供 N3 与 C2。

    * 天冬氨酸提供 1、6、5、4 四个原子。

* **嘌呤母环**：原料五种，各原子的来源如下表。

| 原料 | 提供的原子 |
| :--- | :--- |
| 甘氨酸 | C4、C5、N7 |
| 谷氨酰胺（酰氨基） | N3、N9 |
| 一碳单位（甲酰基） | C8、C2 |
| 天冬氨酸 | N1 |
| 二氧化碳 | C6 |

* 记忆口诀：甘氨当中站中间，谷氨坐两边，一碳单位在两旁，左上添冬氨，头上二氧碳。

### 稀有碱基与表观遗传

* **稀有碱基**

    * > **定义**：RNA 中除 A、G、C、U 四种主要碱基以外的其他碱基，大多是在原有碱基上加甲基修饰而成。

    * tRNA 是含稀有碱基最多的核酸分子，含量可达 10%，不同材料记 10%～15%，有的写 20%。

    * 嘌呤类：7-甲基鸟嘌呤、N6-甲基腺嘌呤、N6,N6-二甲基腺嘌呤。

    * 嘧啶类：5-甲基胞嘧啶、5-羟甲基胞嘧啶、二氢尿嘧啶、胸腺嘧啶。

    * 胸腺嘧啶出现在 RNA 中时也归为稀有碱基——它由尿嘧啶加一个甲基而来。

    * 来历：全部由转录后修饰生成；转录时只有 A、G、C、U，转录完成后再修饰加工。

* **5-甲基胞嘧啶**

    * 出现在真核生物基因组 DNA 上，属表观遗传：5 位碳甲基化可抑制特定基因表达，序列不变而表型改变。

    * 被称为 DNA 分子上的第五个碱基，前四个是 A、G、C、T。

### 核苷与糖苷键

* **核苷**

    * > **定义**：核苷酸去掉磷酸后的部分，由戊糖与碱基以糖苷键相连；戊糖为脱氧核糖时称脱氧核苷。

    * 连接位点：嘌呤的 9 位氮或嘧啶的 1 位氮，与戊糖 1′位碳脱水缩合。

    * 空间关系：碱基平面与糖环平面互相垂直。

    * 构型：全部是 β 糖苷键——1′位与 5′位羟基同在环平面一侧，且 1′碳连碱基氮，故为 β-N-糖苷键。

* **假尿嘧啶核苷（Ψ）**

    * 与真尿嘧啶结构相同，区别只在成键原子：真尿嘧啶用 1 位氮连核糖，假尿嘧啶用 5 位碳连核糖。

    * 存在于 tRNA 与 rRNA 中；核糖本身的修饰也以甲基化为主。

### 核苷酸的命名

* **命名规则**

    * 碱基决定名称前半，磷酸数目决定 MP、DP、TP，脱氧在名称前加小写 d。

    * 腺苷酸 AMP（腺苷一磷酸）、鸟苷酸 GMP、胞苷酸 CMP、尿苷酸 UMP。

    * 脱氧腺苷酸 dAMP、脱氧鸟苷酸 dGMP、脱氧胞苷酸 dCMP、脱氧胸苷酸 dTMP。

* **磷酸位置异构体**

    * 戊糖 2′、3′、5′位都有羟基，磷酸可接在任一位置，形成 2′-核苷酸、3′-核苷酸、5′-核苷酸，如 2′-AMP、3′-AMP、5′-AMP。

    * 核苷酸与脱氧核苷酸的区别只在 2′位是否脱氧，这也是 RNA 与 DNA 组成单位的主要区别。

### 核苷酸衍生物

* **二磷酸与三磷酸核苷**

    * AMP 上再加一个磷酸成 ADP，再加一个成 ATP；ATP 是生物界的能量货币。

    * 四种核苷酸都能形成 MP、DP、TP 三档形式。

* **环核苷酸**

    * ATP、GTP 在相应环化酶作用下环化，生成环腺苷酸（cAMP）与环鸟苷酸（cGMP）。

    * cAMP 与 cGMP 在细胞中作为第二信使传递信号。

* **辅酶组分**

    * AMP 是 NAD、NADP、FAD 和辅酶 A 的组成成分，B 族维生素多以辅酶形式存在。

    * 辅酶 B12 含有脱氧腺苷。

### 磷酸二酯键与链方向

* **磷酸二酯键**

    * > **定义**：前一个核苷酸 3′位羟基与后一个核苷酸 5′位磷酸脱水缩合形成的键；磷酸两侧各有一个酯键，故称 3′,5′-磷酸二酯键。

    * 链中间每个核苷酸的 3′羟基与 5′磷酸都不完整，整条链只有一个完整的 5′磷酸和一个完整的 3′羟基。

    * 带完整 5′磷酸的一端是 5′末端，带完整 3′羟基的一端是 3′末端。

* **方向规定**

    * 核酸链方向规定为 5′→3′，因为生物体自身合成 DNA、RNA 都是从 5′向 3′进行。

    * 题目未标两端时，默认序列按 5′→3′、从左往右书写。

    * 一级结构即 5′端到 3′端的核苷酸排列顺序；因核苷酸间唯一差异是碱基，也可表述为碱基排列顺序。

## DNA 的结构与功能

### 一级结构与基因组组织

* **DNA 一级结构**

    * > **定义**：DNA 链中从 5′端到 3′端的核苷酸排列顺序。

    * 四种脱氧核苷酸经 3′,5′-磷酸二酯键连成直链或环状多聚物：真核 DNA 为直链，原核（如大肠杆菌）与质粒为环形。

    * 双链摊开像一架梯子：两侧扶手是磷酸与戊糖交替的骨架，中间阶梯是成对碱基。

* **病毒基因组**

    * 基因组较小但紧凑，有些基因彼此重叠。

    * 基因是 DNA 上的一段序列，可看作整个 DNA 结构的一部分。

* **细菌基因组**

    * 基因连续，没有内含子。

    * 功能相关的基因组成操纵子，共用调节与控制序列，协调地同时高表达或同时低表达。

    * 调控序列所占比例较小，很少有重复序列。

* **真核基因组**

    * 基因是断裂基因：编码 RNA 与蛋白质的外显子被不编码的内含子隔开。

    * 功能相关的基因不组成操纵子，各自一个一个表达。

| 比较项 | 细菌（原核生物） | 真核生物 |
| :--- | :--- | :--- |
| 基因结构 | 连续，没有内含子 | 断裂基因：外显子被内含子隔开 |
| 操纵子 | 功能相关基因组成操纵子，共用调节控制序列，协调表达 | 不组成操纵子，功能相关基因也各自表达 |
| 调控序列比例 | 较小 | 较大 |
| 重复序列 | 很少 | 大量，分低拷贝、中度拷贝、高拷贝重复 |

### 二级结构与查加夫规则

* **DNA 二级结构**

    * > **定义**：在一级结构基础上通过次级键（非共价键）形成的双螺旋或多股螺旋结构；一般以双螺旋形式存在，不同构象在一定条件下可相互转变。

* **查加夫规则**

    * 腺嘌呤与胸腺嘧啶的摩尔数相等：$A = T$。

    * 鸟嘌呤与胞嘧啶的摩尔数相等：$G = C$。

    * 嘌呤总摩尔数等于嘧啶总摩尔数：$A + G = C + T$；前两条相加即得，左右互换还可得 $A + C = G + T$。

    * 本质是 A-T、G-C 配对在碱基组成上的体现。

### 双螺旋模型的特点

* **反向平行的右手双螺旋**

    * 两条反向平行的右手螺旋多核苷酸链，围绕同一中心轴相互缠绕。

    * 一条链自上而下为 5′→3′，另一条自下而上为 5′→3′。

* **碱基在内、磷酸与核糖在外**

    * 碱基位于双螺旋内侧，磷酸与核糖位于外侧，经 3′,5′-磷酸二酯键相连构成分子骨架。

    * 碱基平面与中心轴垂直，糖环平面与中心轴平行。

* **大沟与小沟**

    * 双螺旋表面形成大沟、小沟相间的沟状结构。

    * 碱基对配对时带一个夹角，使梯子的阶梯逐个内凹，再拧成双螺旋即出现大小沟。

    * 沟为蛋白质识别 DNA 碱基序列并提供相互作用的结构基础；复制与转录都需要蛋白质与 DNA 结合。

* **几何参数**

    * 平均直径 2 nm。

    * 相邻核苷酸夹角 36°，每圈 10 个核苷酸（实际 10.4 个）。

    * 螺距 3.4 nm，相邻碱基对高度 0.34 nm；$0.34 \times 10 = 3.4$，正好是一个螺距。

* **碱基配对**

    * A 与 T 之间两个氢键，G 与 C 之间三个氢键，G-C 结合更稳定。

    * 一条链序列确定后，按配对原则即可推出互补链序列；遗传信息由碱基序列携带。

### 维持双螺旋的作用力

* **横向氢键**

    * 碱基与碱基之间的氢键把两条链横向拉住，使其不散架。

* **纵向碱基堆积力**

    * 碱基堆积力的本质是疏水作用力。

    * 碱基疏水而细胞内是水相，疏水基团倾向互相靠近；每个碱基对受上下相邻碱基对吸引被固定在原地，整列碱基像互相挽着手的队列一样牢固。

### A 型、B 型与 Z 型

* **B 型**

    * 把 DNA 做成钠盐，在湿度达 92% 的较高湿度下制备的纤维状结构。

    * 最接近大部分 DNA 在细胞中的构象，细胞里的 DNA 大多为 B 型；Watson 与 Crick 发现的双螺旋就是 B 型。

* **A 型**

    * 相对湿度降低、盐浓度升高后出现的构象。

    * RNA 与 DNA 的杂交双螺旋、RNA 形成的局部双螺旋也是 A 型。

* **Z 型**

    * 左手双螺旋；A 型与 B 型都是右手螺旋。

    * 与基因表达调控和基因重组有关。

| 比较项 | A 型 | B 型 | Z 型 |
| :--- | :--- | :--- | :--- |
| 螺旋方式 | 右手 | 右手 | 左手 |
| 外形 | 粗短 | 中等 | 细长 |
| 每圈碱基对数 | 11 | 10（实际 10.4） | 12 |
| 螺距 | 2.53 nm | 3.4 nm | 4.56 nm |
| 糖苷键构型 | 反式 | 反式 | 嘧啶反式、嘌呤顺式 |

* **填空要点**

    * A 型与 B 型是 DNA 的两种基本构象，多为反式构象；Z 型存在顺式构象。

    * 自然界中双螺旋大多数为右手螺旋，指的就是 A 型与 B 型。

### 三级结构：超螺旋与拓扑学

* **DNA 三级结构**

    * > **定义**：双螺旋 DNA 分子通过扭曲、折叠形成的特定构象，包括二级结构单元间的相互作用、单链与二级结构单元间的相互作用以及 DNA 的拓扑特征。

    * 最常见的三级结构是超螺旋。

* **质粒的三种构象**

    * 提取时若一条链断裂变成开环，两条链都断变成直链，双链完整则呈超螺旋。

| 形态 | 断链情况 | 分子状态 | 电泳迁移速率 |
| :--- | :--- | :--- | :--- |
| 共价闭环 DNA（cccDNA） | 两条链完整 | 呈超螺旋 | 最快 |
| 线性 DNA | 两条链都断裂 | 直链 | 居中 |
| 开环 DNA（OC） | 一条链断裂 | 分子比较松弛 | 最慢 |

* **拓扑学参数**

    * 关系式：$L = T + W$。

    * 连环数 L：一条链按右手方向绕另一条链的次数，即双螺旋的圈数；正超螺旋时 L 变大，负超螺旋时 L 变小。

    * 扭转数 T：两条链相互缠绕的次数。

    * 缠绕数 W：双螺旋轴绕超螺旋轴旋转的次数，即超螺旋的圈数；正超螺旋取正，负超螺旋取负。

| 状态 | L | T | W |
| :--- | :--- | :--- | :--- |
| 松弛环状 | 20 | 20 | 0 |
| 负超螺旋 | 18 | 20 | -2 |
| 正超螺旋 | 22 | 20 | +2 |

* 换算时写成 $T = L - W$ 更顺：负超螺旋时 W 为负，一减反而变大。

### 四级结构：核小体与染色质

* **DNA 四级结构**

    * > **定义**：DNA 与蛋白质形成的复合物结构，主要指真核生物 DNA。

    * 真核 DNA 以核小体为单位，形成高度有序、致密的结构。

* **染色质与染色体**

    * 细胞周期大部分时间以核小体为单位、以松散染色质形式存在；电镜下是串珠样结构，每个珠子是一个核小体。

    * 细胞分裂期串珠高度浓缩，形成致密的染色体。

    * 染色质由 DNA、蛋白质和少量 RNA 组成，DNA 与紧密结合的蛋白质约各占一半。

    * 染色质蛋白分组蛋白与非组蛋白，关注更多是组蛋白。

## RNA 的结构与功能

### 一级结构与三类 RNA 的分工

* **RNA 一级结构**

    * 以 AMP、GMP、CMP、UMP 为基本单位，经磷酸二酯键连成单链多聚物。

    * 一级结构是 5′端到 3′端的核苷酸排列顺序，因核苷酸间唯一差异是碱基，也可表述为碱基排列顺序。

* **三类 RNA 的分工**

| RNA | 角色定位 | 具体功能 |
| :--- | :--- | :--- |
| tRNA | 转接器（翻译者） | 携带活化的氨基酸送到核糖体，用反密码子识别 mRNA 的密码子，把核酸的序列语言转成氨基酸的序列语言 |
| rRNA | 装配厂的组成成分 | 与数十种蛋白质组成核糖体，使 mRNA 与 tRNA 正确定位，并催化肽键的合成 |
| mRNA | 指导者 | 从 DNA 获得一串信息，作为蛋白质生物合成的模板，决定蛋白质的氨基酸序列 |

* **丰度**

    * rRNA 占总 RNA 的 80%，含量最多。

    * tRNA 约占细胞总 RNA 的 15%，排第二。

    * mRNA 丰度最小、种类最多，但合成与分解的工作量最大——环境一变就要转录新的 mRNA，用完后很快降解。

### tRNA 的稀有碱基与三叶草结构

* **稀有碱基**

    * tRNA 是含稀有碱基最多的 RNA，稀有碱基占 10%～15%，有的材料写 20%。

    * 双氢尿嘧啶（DHU）：尿嘧啶的 5 位、6 位碳各加一个氢。

    * 假尿嘧啶（ψ）：5 位碳与戊糖相连，区别于正常尿嘧啶的 1 位氮。

    * 甲基化鸟嘌呤，最常见的是七甲基鸟嘌呤。

* **三叶草形二级结构**

    * 单链中可互补的片段配对形成发夹（茎环）结构，一系列茎环排布成三叶草形。

    * 氨基酸臂：位于 3′末端，氨基酸连在末端腺苷酸的戊糖上。

    * TψC 环：含胸腺嘧啶、假尿嘧啶、胞嘧啶，功能是识别并结合核糖体。

    * 反密码环：含反密码子，识别 mRNA 的密码子并与之反向互补配对。

    * DHU 环：含双氢尿嘧啶，功能是辨认并结合氨酰-tRNA 合成酶。

    * 附加叉：位于 TψC 环与反密码环之间，无主要功能，是 tRNA 分类的指标。

* **两端通例**

    * 3′末端一律是 C-C-A 序列（共有序列，不是密码子），氨基酸连在最后一个 A 上。

    * 5′末端多为 G，带一个磷酸基团；少数 tRNA 的 5′末端是胞嘧啶核苷酸。

* **氨基酸的连接**

    * 氨基酸羧基脱羟基、腺苷酸 3′位羟基脱氢，脱水成酯键；氨基酸脱去羧基羟基后的基团称氨基酰基团。

    * 氨基酸偶尔也连到戊糖 2′位羟基上。

### tRNA 的三级结构与反密码子

* **倒 L 型**

    * tRNA 三级结构为倒 L 型；3′末端接纳氨基酸的位置与反密码子位置相距较远。

* **反密码子的读向**

    * 密码子与反密码子都是核酸片段，书写一律按 5′→3′。

    * 例：mRNA 上密码子按 5′→3′读作 UAC，反密码子要先找 5′端再读得 GUA，与密码子反向互补。

    * > **易错点**：环上同样三个碱基，从不同端读起得到完全不同的序列；先定 5′端再读，不要按视觉从左到右硬读。

* **功能**

    * 活化并搬运氨基酸到核糖体，参与蛋白质的翻译。

### rRNA 与核糖体

* **组成与场所**

    * rRNA 与核糖体蛋白共同组成核糖体，为蛋白质生物合成提供场所（装配厂）。

    * 原核与真核的核糖体都由一个小亚基和一个大亚基组成。

| 比较项 | 原核生物 | 真核生物 |
| :--- | :--- | :--- |
| 小亚基蛋白质 | 21 种 | 33 种 |
| 小亚基 rRNA | 1 条：16S | 1 条：18S |
| 大亚基蛋白质 | 31 种 | 49 种 |
| 大亚基 rRNA | 2 条：23S、5S | 3 条：28S、5.8S、5S |

* **沉降系数**

    * 大肠杆菌核糖体为大亚基 50S 加小亚基 30S，组成 70S；沉降系数不是简单加和，50S + 30S ≠ 80S。

* **真核 rRNA 的转录**

    * 18S、28S、5.8S 由同一条 DNA 同时转录，先得到 45S 前体，再切割成三段。

    * 5S 单独转录。

* **核糖体的三个位点**

    * A 位（氨酰位）：结合氨酰-tRNA。

    * P 位（肽位）：结合肽酰-tRNA。

    * E 位（exit，排出位）：卸载了氨基酸的 tRNA 由此离开。

    * 每个位点对应 mRNA 上三个核苷酸，即一个密码子。

### mRNA 的帽子与尾巴

* **mRNA**

    * 蛋白质合成的直接模板：在细胞核内转录基因序列，携带到细胞质指导蛋白质合成——这是真核的情形。

    * 原核没有细胞核，mRNA 从核区 DNA 转录后直接作模板，转录与翻译可以同时进行。

    * 真核 mRNA 先在核内转录并加工，加工完成后才释放到细胞质。

* **5′帽子**

    * 帽子是 7-甲基鸟苷三磷酸（$m^{7}\mathrm{GTP}$），三个磷酸与整条链第一个核苷酸共用。

    * 作用一：对抗 5′外切核酸酶的降解，保护 mRNA。

    * 作用二：帮助核糖体识别并结合 mRNA，使翻译正确进行。

* **3′尾巴**

    * 尾巴是 polyA，一长串腺苷酸；转录过程中从中间位点切开后，由加尾酶加上 80～250 个腺苷酸。

    * 作用一：可能与 mRNA 从细胞核到细胞质的运输有关。

    * 作用二：与 mRNA 的半衰期（稳定性）有关；新生 mRNA 的 polyA 长，衰老的短。

    * 缓冲机制：3′外切酶先切尾巴，切掉二三十个不影响主体功能，直到尾巴切完 mRNA 才被降解。

### RNA 的加工修饰

* **一般性加工**

    * 包括切割修剪、添加修饰、异构化。

    * 不改变 RNA 的编码序列。

* **选择性加工**

    * 包括剪接、编辑、再编码。

    * 可以改变编码序列，即改变 RNA 携带的遗传信息。

* 加工修饰一般在转录完成后进行。

* > **易错点**：一般性加工不改变编码序列，选择性加工才改变编码序列，两类加工的分界就在这里。

## 核酸的水解

### 水解位点

* **3′,5′-磷酸二酯键**

    * 核苷酸之间的连接键，可朝两个方向断：一头连前一个核苷酸的 3′端，一头连后一个核苷酸的 5′端。

    * 断 3′侧，磷酸跟着后一个核苷酸的 5′走；断 5′侧，磷酸跟着前一个核苷酸的 3′走。

* **糖苷键**

    * 碱基与戊糖之间的键；核苷酸中的糖苷键无一例外是 β 型，因为 1′位羟基与 5′位羟基在环平面同侧。

    * 1′碳连的是碱基氮，准确称 β-N-糖苷键。

* **三种水解方式**

    * 酸水解、碱水解、酶水解；生物体内主要走酶水解。

### 酸水解

* **先掉碱基**

    * 酸性条件下糖苷键与磷酸酯键都能水解，但糖苷键比磷酸酯键更易被酸水解。

    * 结果是最先切下碱基，磷酸二酯键尚未明显断裂，链先“秃”。

* **糖苷键稳定性规律**

    * 嘧啶糖苷键比嘌呤糖苷键稳定。

    * 核糖糖苷键比脱氧核糖糖苷键稳定。

    * 两条叠加：脱氧核糖与嘌呤形成的糖苷键对酸最不稳定。

    * 推论：DNA 上的碱基比 RNA 上的更易被酸切掉；嘧啶糖苷键最稳，水解它需更高温度、更多能量。

* > **提示**：遇到“最不稳定”“最容易水解”这类填空，限定条件要记全——哪种碱基、哪种糖、哪条键。

### 碱水解

* **RNA 易被碱水解**

    * 核糖 2′位有游离羟基，与同一核苷酸上的磷酸离得很近。

    * 碱性条件下 2′-OH 亲核攻击相邻磷酸，再形成一个酯键，得到 2′,3′-环状磷酸（环状磷酸三酯）中间体。

    * 中间体在碱中继续水解开环，磷酸可能留在 2′位，也可能留在 3′位。

    * 产物是 2′-单核苷酸与 3′-单核苷酸两种，名称由磷酸位置决定。

* **DNA 耐碱**

    * 脱氧核糖 2′位只有氢，没有 2′-OH，形不成环状中间体，磷酸二酯键没有这条自拆通道。

    * 一个 2′位上的氧，决定整条链对碱的态度。

### 酶水解与内外切

* **按底物分**

    * 核糖核酸酶（RNase）专门水解 RNA，脱氧核糖核酸酶（DNase）专门水解 DNA。

    * RNA 被切成单核苷酸或寡核苷酸，DNA 被切成单脱氧核苷酸或寡脱氧核苷酸。

* **按作用方式分**

    * 外切酶从链的一端逐个切：从 5′端起切的是 5′核酸外切酶，从 3′端起切的是 3′核酸外切酶。

    * 内切酶不挑端头，直接从链内部下刀。

* **外切酶的方向与产物**

    * 牛脾磷酸二酯酶从 5′末端开始切，产物是 3′-核苷酸——被切下核苷酸的 5′位磷酸交给了上一个核苷酸，3′位磷酸留下来。

    * 蛇毒磷酸二酯酶从 3′末端开始切，产物是 5′-核苷酸——磷酸留在被切下核苷酸的 5′位。

    * > **易错点**：从 5′端切（牛脾）得 3′-核苷酸，从 3′端切（蛇毒）得 5′-核苷酸，两个产物不要记反。

* **按底物链数分**

    * 有的酶只作用于双链，有的只作用于单链，按底物要求区分。

### 3′-与 5′-磷酸二酯酶

* **3′-磷酸二酯酶**

    * 作用位点在 3′-羟基与磷酸之间，把磷酸从 3′-羟基上切下，磷酸留给 5′端。

* **5′-磷酸二酯酶**

    * 切 5′-羟基与磷酸之间的键，切完磷酸留在 3′位点。

* > **易错点**：酶名说的是“切哪一侧的酯键”，不是“磷酸最后留在哪一侧”；3′-磷酸二酯酶切 3′侧、磷酸反留 5′端，5′-磷酸二酯酶切 5′侧、磷酸留 3′端。判断时先画一段 5′→3′链、把磷酸标在中间，再按“断哪侧、磷酸归另一侧”推。

## 核酸的酸碱性质

### 碱基的解离

* **可解离基团与 pKa**

| 碱基 | 类别 | 可解离基团数 | pKa |
| :--- | :--- | :--- | :--- |
| 胞嘧啶 | 嘧啶 | 2 | 4.6、12.5 |
| 尿嘧啶 | 嘧啶 | 1 | 9.5 |
| 胸腺嘧啶 | 嘧啶 | 1 | 9.9 |
| 腺嘌呤 | 嘌呤 | 2 | 4.15、9.8 |
| 鸟嘌呤 | 嘌呤 | 3 | 3.2、9.6、12.4 |

* **等电点算法**

    * 等电点取不带电状态左右两侧 pKa 的平均值，与氨基酸、蛋白质同一套算法。

    * 胞嘧啶：$\mathrm{pI} = (4.6 + 12.5)/2 = 8.55$。

    * 尿嘧啶在 pH 9.5 时脱氢与不脱氢各占一半；胸腺嘧啶同理，平衡点在 pH 9.9。

    * 鸟嘌呤第三个基团解离时失去质子带负电，平衡点在 pH 12.4。

### 核苷与核苷酸的解离

* **核苷**

    * 糖从两方面影响解离：改变碱基所处的化学环境使 pKa 变化；糖环自身的羟基也能解离（5′位羟基，RNA 还有 2′位羟基）。

    * 判断结构先看 2′位：画羟基是核糖（RNA 的单位），只有氢是脱氧核苷，少一个可解离羟基。

* **核苷酸**

    * 三个解离来源：碱基、糖环羟基、磷酸基团，其中磷酸是主力。

    * 磷酸两个羟基都能失质子：第一个 pKa 0.7～1.6，生理 pH 下早已带负电；第二个 pKa 5.9～6.5，处在弱酸区间，pH 稍变就影响带电。

    * “核苷酸”的“酸”指的就是这个磷酸。

### 两性电解质与等电点

* **两性电解质**

    * 磷酸基团能释放质子，碱基上的氨基能接受质子，同一分子兼具酸性与碱性基团，故为两性电解质，可处于兼性离子状态。

    * 兼性离子净电荷为零，此时溶液的 pH 就是等电点。

    * pH 等于等电点时净电荷为零，pH 小于等电点带正电，pH 大于等电点带负电。

    * 反向推：pH 低时质子充足，氨基结合质子带正电；pH 高时质子被夺走，磷酸也交出质子，带负电。

* **UMP 例外**

    * 尿嘧啶碱性极弱，接受不了质子，形不成带正电的基团。

    * 形不成兼性离子，也就谈不上等电点；腺苷酸、胞苷酸、鸟苷酸三种都能成为兼性离子。

    * > **易错点**：不能形成兼性离子的核苷酸是 UMP（尿苷酸），这是单选题与填空题的常客。

## 紫外吸收与定量测定

### 共轭双键与 260 nm

* **共轭双键**

    * > **定义**：两个双键之间隔一个单键相连，这样的两个双键称共轭双键。

    * 共轭双键吸收紫外光，是核酸中真正负责吸光的基团。

    * 嘌呤与嘧啶的共轭双键成片存在：环内双键与相邻双键共轭，环内双键又与环外羰基共轭；五种碱基都有多组共轭双键，故 DNA 与 RNA 都吸收紫外。

* **260 nm 定量**

    * 核酸在 260 nm 处有特异吸收峰，浓度越高吸光值越大。

    * 吸光能力排序：寡核苷酸 > 单链 DNA 或 RNA > 双链 DNA——达到同样 A260 所需浓度越低，单位质量吸光能力越强。

    * 与结构状态对应：双链碱基堆叠在螺旋内部，单链摊开，寡核苷酸最短、碱基暴露最彻底。

    * A260 = 1.0 对应的经验浓度如下表。

| 样品 | A260 = 1.0 对应的浓度 |
| :--- | :--- |
| 双链 DNA | 50 μg/mL |
| 单链 DNA 或 RNA | 40 μg/mL |
| 寡核苷酸 | 20 μg/mL |

### 增色效应与减色效应

* **增色效应**

    * > **定义**：单链核酸吸光值高于双链，核酸变性时双链解开为单链，使 260 nm 处吸光值升高的现象。

    * 原因是双链中碱基堆叠在螺旋内部、共轭双键被包裹；解开后碱基暴露，更多共轭双键参与吸光。

    * > **提示**：名词解释要把三件事写全——前提是变性（双链变单链）、表现是 $A_{260}$ 升高、原因是单链吸光能力高于双链。

* **减色效应**

    * 复性后碱基重新配对、被包回双螺旋内部，吸光能力减弱，紫外吸收降低。

    * 增色与减色是一对：变性时碱基暴露、$A_{260}$ 升高；复性时碱基归位、$A_{260}$ 降低。

### 纯度判断

* **A260/A280 经验值**

    * 纯 DNA 溶液约为 1.8，纯 RNA 溶液约为 2.0。

    * RNA 比值更高，因为 RNA 大多是单链，单链在 260 nm 的吸光值高于双链。

* **比值偏低的原因**

    * 分母变大，即 280 nm 处吸光升高。

    * 蛋白质在 280 nm 吸收最强，杂蛋白未去干净会使比值明显下降。

    * 提取时常用苯酚，残留量多也会抬高 280 nm 吸光、拉低比值。

    * 判断口径：A260/A280 偏低先怀疑蛋白质污染与苯酚残留。

### 定磷法

* **三种定量方法**

    * 紫外分光光度法、定磷法、定糖法；实验室更常用紫外法。

* **钼蓝比色流程**

    * 核酸中的有机磷加浓硫酸或过氯酸水解，变成无机磷（正磷酸）。

    * 酸性条件下与钼酸作用生成磷钼酸。

    * 在还原剂抗坏血酸（维生素 C）作用下被还原成钼蓝，最大吸收峰 660 nm。

    * 一定范围内吸光值与磷含量成正比，由此算出核酸含量。

    * 本质：通过测磷酸的数量反映核酸浓度。

## 变性、复性与分子杂交

### 变性

* **DNA 变性**

    * > **定义**：在加热、极端 pH、离子强度降低或变性剂作用下，双螺旋区的氢键断裂、双链解开成单链，天然构象与性质随之改变的过程。

    * 变性剂常见的有尿素、盐酸胍、甲醛。

    * 引起变性的因素分三类：热变性、酸碱变性、变性剂变性。

    * 本质是配对双链之间的氢键断裂——氢键就在 A-T、G-C 碱基对之间。

    * 具有双链或局部双链结构的 RNA 在同样条件下也可变性；平时说的变性主要指 DNA。

* **变性后的改变**

    * $A_{260}$ 升高，即增色效应。

    * 生物学功能改变，但一级结构不变——碱基排列顺序没有变，与蛋白质变性只涉及高级结构同理。

    * RNA 只有具备高级结构才会变性失功能；没有高级结构的 RNA 变性不破坏其功能。

### Tm 值

* **解链温度（Tm）**

    * > **定义**：DNA 热变性过程中物理化学性质改变达到一半时的温度，即解链一半时的温度。

    * 在解链曲线上，起始吸光值到最大吸光值的变化量为 $\Delta A_{260}$，变化达到一半时对应的温度就是 Tm。

    * Tm 与 GC 含量成正比：GC 含量越高，Tm 越大。

    * 原因：G-C 之间三个氢键、A-T 之间两个氢键，GC 越多双链结合越牢，打开所需能量越多、温度越高。

    * 计算 GC 含量：A-T 与 G-C 之和为 100%，给出 A-T 比例就用 100% 减去它。

* **判据**

    * 比较几段 DNA 的 Tm，只比 GC 含量：GC 含量最高的一段 Tm 最高。

### 复性与退火

* **复性**

    * > **定义**：变性因素消失后，解开的互补单链全部或部分恢复到天然双螺旋结构的现象。

    * 分全部复性与部分复性，只有全部复性的 DNA 才具备原来的功能。

* **退火**

    * 热变性的 DNA 经缓慢冷却即可复性，这个过程称退火。

    * 复性时紫外吸收减少，即减色效应。

### 分子杂交

* **核酸分子杂交**

    * > **定义**：利用核酸变性与复性的性质，使来源不同的核酸片段按碱基互补配对规则形成异源双链，从而对特定目标核酸作定性或定量分析的技术。

    * 原料是变性给出的单链，动力是复性时的碱基互补配对。

    * 异源双链可在 DNA 与 DNA 之间形成，也可在 DNA 单链与 RNA 单链之间形成。

* **衍生技术**

    * Southern blotting 检测 DNA，Northern blotting 检测 RNA，Western blotting 检测蛋白质，同属 blotting 家族。

### 印迹技术

* **印迹（blotting）**

    * > **定义**：将待测核酸或蛋白质分子结合到一定固相支持物上的方法，类似用吸墨纸吸收纸张上的墨迹。

    * DNA 印迹因由 Southern 发明而命名为 Southern blotting。

* **探针**

    * > **定义**：带有可检测标志物的 DNA 或 RNA 片段，序列提前设计，能按碱基互补配对规则与待测核酸特异性结合。

    * 标志物可以是放射性核素、生物素或荧光物质。

    * 探针有 DNA 也有 RNA，实验室绝大多数用 DNA，因为 DNA 比 RNA 稳定。

* **Southern blotting**

    * > **定义**：将电泳分离的待测 DNA 片段转印并结合到固相支持物（一般为硝酸纤维素薄膜，NC 膜）上，再用标记的 DNA 或 RNA 探针检测待测 DNA 的方法。

    * 流程六步：限制性核酸内切酶消化（DNA 太大，先切成不同大小的片段）→ 琼脂糖凝胶电泳（负极向正极，大片段慢、小片段快）→ 转印（自下而上为缓冲液、海绵、凝胶、NC 膜、滤纸，靠毛细作用上吸，DNA 穿不过膜孔被截留）→ 杂交（装杂交袋加放射性探针）→ 洗膜（未配对的探针洗掉）→ 检测（覆胶片曝光，条带处即目的 DNA）。

    * Marker 泳道单独加样，按说明书读出各条带对应的分子量，用于判断目的条带大小。

* **Northern blotting**

    * 与 Southern 唯一区别是最初的样品：Northern 检测 RNA，又称 RNA blotting。

    * RNA 本身是小分子，不需要酶切，可直接上样。

## 核酸的分离纯化

### 目的与防降解

* **目的**

    * 得到纯度较高的 DNA 或 RNA，并尽可能保持其在生物体内的天然状态（活性状态）。

* **三条防破坏要求**

    * 防止核酸变性。

    * 防止核酸酶降解：核酸酶需要二价金属离子作辅助因子，常通过抑制镁离子等二价金属离子来抑制酶活。

    * 防止化学因素与物理因素的降解。

### 三步流程

* **分离核蛋白**

    * 体内 DNA 以脱氧核糖核蛋白（DNP）形式存在，RNA 以核糖核蛋白形式存在，核酸与蛋白质胶连缠绕。

    * DNP 在 1.0 mol/L NaCl 中溶解度很高，提取 DNA 用 1.0 mol/L NaCl。

    * 核糖核蛋白在 0.14 mol/L NaCl 中溶解度较高，提取 RNA 用 0.14 mol/L NaCl。

* **去除蛋白质**

    * 蛋白酶 K 消化，把蛋白质降解掉。

    * 酚/氯仿多次抽提：苯酚与氯仿使蛋白质变性沉淀，离心去掉。

* **沉淀核酸**

    * 在一定盐浓度下加 2.5～3 倍体积的冷无水乙醇，核酸沉淀析出。

    * 乙醇要预冷（4℃ 或插冰盒），低温使核酸更容易沉淀；可观察到白色絮状沉淀。

* **RNA 提取的特殊要求**

    * RNA 酶无处不在，必须先去掉或破坏。

    * 器材与材料用 DEPC 水处理（DEPC 抑制 RNA 酶活性）或高温处理。

    * 加入强变性剂与 RNA 酶抑制剂，确保 RNA 酶失活。

### 苯酚法

* **流程**

    * 组织研磨，加含 NaCl 的裂解液，把 DNA 以 DNP 形式提取出来。

    * 加苯酚——强蛋白变性剂，使蛋白质变性沉淀。

    * 冷冻离心后取上层水相，反复多次抽提，直至蛋白除净。

    * 合并水相，在有盐条件下加 2～3 倍体积冷乙醇沉淀 DNA，再用乙醇清洗沉淀。

* **分层的道理**

    * 苯酚比水重，故酚相在下、水相在上，DNA 在水相。

    * 变性后的蛋白质漂在中间界面或粘在管壁内壁，取水相即可把它甩开。

### 氯化铯密度梯度离心

* **原理**

    * 铯原子相对原子质量大，铯离子在超速离心力场中沉降形成浓度梯度。

    * DNA 密度大，只有在浓铯离子溶液中才产生浮力，悬浮在中间。

    * 氯化铯水溶性极大，浓度可达 8.0 mol/L。

    * 可分离不同碱基组成、不同构象、单链与双链的 DNA。

* **离心后分层**

    * 自上而下密度递增：石蜡油、蛋白质、开环及线性 DNA、闭环质粒 DNA、超螺旋 DNA。

    * 超螺旋 DNA 密度最大沉在最底，石蜡油密度最小飘在最上。

### 寡聚胸腺嘧啶核苷酸亲和层析

* **原理**

    * 把一连串 T 固定在树脂上做成柱子，可抓取含一连串 A 的核酸。

    * mRNA 的 3′端有 polyA 尾巴，正好被一连串 T 吸附，其他 RNA 流出。

* **洗脱**

    * 加低离子强度缓冲液，破坏 A-T 之间的相互作用力，mRNA 被洗出。

    * 洗脱液即去除其他 RNA 后的 mRNA。

### 琼脂糖凝胶电泳

* **介质**

    * 琼脂糖是天然聚合的长链分子，沸水中溶解。

    * 45℃ 开始形成多孔性刚性结构，孔径大小由琼脂糖浓度决定；浓度越高，长链越多，孔径越小越密。

    * 制胶：溶解的胶液倒入方盒，插入梳子（梳齿没入胶液但不插到底），凝固后拔出梳子留下一排加样孔。

* **分离原理**

    * 以琼脂糖凝胶为支持物，利用电荷效应与分子筛效应分离混合物。

    * DNA 带负电，通电后向正极迁移。

* **影响迁移速率的因素**

    * 琼脂糖浓度：负相关，浓度越高越慢。

    * 分子大小：负相关，越小越快。

    * 分子形状：超螺旋最快，线性第二，开环最慢；三者长度相同。

* **染色**

    * 溴化乙锭（EB）插入 DNA 相邻碱基对之间形成荧光络合物；紫外光激发发橙色荧光，波长 590 nm。

    * EB 是强致癌物，操作需小心。

    * GoldView 是 EB 的替代品，用法用量相同，发绿色荧光。

## DNA 的酶法测序

### 反应体系

* **测序目标**

    * 确定未知 DNA 序列中 A、G、C、T 的排列顺序。

* **模板与引物**

    * 模板是待测的单链 DNA。

    * 引物是一段短链 RNA，为 DNA 聚合酶提供 3′-OH 末端——聚合酶不能直接催化两个游离 dNTP 聚合。

* **底物与酶**

    * 四种 dNTP：d 代表脱氧，N 为 A、G、C、T 中任一种。

    * DNA 聚合酶用 Klenow 片段，即大肠杆菌 DNA 聚合酶Ⅰ的大片段，具 5′→3′ 聚合酶活性。

    * 四种 dNTP 中一种用放射性同位素标记（如 dATP），否则找不到新合成的片段。

    * > **易错点**：原料写作 dNTP，小写 d 不能丢，它代表脱氧。

### 双脱氧链终止法

* **方法沿革**

    * 桑格先后两次设计：先有加减法，后改进为双脱氧链终止法。

* **ddNTP**

    * 2′,3′-双脱氧核苷三磷酸：2′位与 3′位都脱氧；dNTP 只有 2′位脱氧。

    * 3′-OH 是与下一个核苷酸形成 3′,5′-磷酸二酯键的关键，3′位一脱氧，链延伸即在此终止。

* **四管设计**

    * 每管都加全四种 dNTP，另按一定比例分别多加一种 ddNTP：ddATP、ddCTP、ddGTP、ddTTP。

    * 不能把某一种 dNTP 全换成 ddNTP，否则新链很可能在第一个核苷酸处就终止。

    * 按比例掺入后，轮到该碱基处有两种结局：掺入单脱氧的继续延伸，掺入双脱氧的当场停止。

    * 结果：A 管得到一整套长短不一、全部终止在 A 上的片段，其余三管分别终止在 C、G、T 上。

### 读序

* **电泳分离**

    * 四管产物并排做凝胶电泳，片段越短跑得越快、越靠下，越长越靠上。

* **读带规则**

    * 由短到长（自下而上）读，依次记下每条带所在泳道，就是从引物向外延伸的新链序列。

    * 例：由短到长读得 G、C、A、T、T、G、C、A、A、C。

    * 新链与模板互补，读出这条新链即可推出未知模板序列。

## 维生素与辅酶

### 定义与分类

* **维生素**

    * > **定义**：参与生物生长发育和代谢所必需的一类微量有机物质；在体内不能合成或合成量不足，需求量很少但必须由食物供给。

    * 两个关键词是微量与必需；微量不等于不重要，两条缺一进不了名单。

| 类别 | 成员 |
| :--- | :--- |
| 脂溶性维生素 | 维生素 A、D、E、K |
| 水溶性维生素 | B 族维生素（B1、B2、烟酸与烟酰胺、B6、泛酸、生物素、叶酸、B12）以及维生素 C |

* 分类依据是溶解性。

### 脂溶性维生素

* **维生素 A**

    * 又名视黄醇；有 A1 与 A2 两种形式，A2 的生理活性只有 A1 的一半，活性更强的是 A1。

    * 体内活性形式有三种：视黄醇、视黄醛、视黄酸。

    * 视黄醛中最重要的是 9-顺视黄醛与 11-顺视黄醛；11-顺视黄醛是视紫红质的组成成分，视紫红质是视网膜细胞感受弱光的物质。

    * 缺乏链：维生素 A 缺乏 → 11-顺视黄醛缺乏 → 视紫红质合成受阻 → 暗适应能力降低 → 夜盲症。

* **维生素 D**

    * 类固醇衍生物，体内可由胆固醇转变而来；抗佝偻病维生素。

    * D2 麦角钙化醇存在于植物，D3 胆钙化醇存在于动物；人体 D3 由皮肤中的 7-脱氢胆固醇经紫外线照射产生。

    * 活性形式是 1,25-二羟基 D3：在 D3 的 1 号与 25 号碳上各加一个羟基。

    * 与降钙素、甲状旁腺激素共同调节体内钙磷平衡；防治佝偻病、软骨病、手足抽搐症。

    * > **易错点**：维生素 D 与钙是“促进吸收”和“被吸收”的关系，不能互相替代——吃 D 要同补钙，补钙也要配 D。

* **维生素 E**

    * 生育酚，主要存在于植物油，豆类与蔬菜中含量也较多。

    * α-生育酚生理活性最高；但就抗氧化作用而言 δ-生育酚最强、α-生育酚最弱。

    * 极易被氧化，是动物和人体中最有效的抗氧化剂与自由基清除剂：自身被氧化，换取其他分子不被氧化。

    * 对抗生物膜磷脂中不饱和脂肪酸的过氧化反应，避免脂质过氧化物产生，保护生物膜结构与功能。

* **维生素 K**

    * 凝血维生素，促进肝脏合成凝血因子Ⅱ，并调节凝血因子Ⅶ、Ⅸ、Ⅹ 的合成。

    * 四个凝血因子编号连起来记：2、7、9、10。

### B 族维生素

* **维生素 B1**

    * 抗神经炎维生素、抗脚气病维生素；化学名硫胺素。

    * 活性形式是硫胺素焦磷酸（TPP），也叫焦磷酸硫胺素。

    * TPP 是 α-酮酸氧化脱羧酶（丙酮酸脱羧酶、α-酮戊二酸脱氢酶）与转酮酶的辅酶，都属糖代谢。

    * 缺乏时糖代谢受阻、丙酮酸累积，血、尿与脑组织中丙酮酸增多，出现脚气病。

    * B1 主要存在于种子外皮且极易溶于水，大米不宜多淘洗。

    * > **易错点**：脚气病不是脚气——脚气是真菌感染，脚气病是神经炎症。

* **维生素 PP**

    * 又称维生素 B3、抗糙皮病维生素；包括烟酸与烟酰胺，尼克酰胺是烟酰胺的音译，同一物质。

    * 活性形式是辅酶Ⅰ（NAD，烟酰胺腺嘌呤二核苷酸）与辅酶Ⅱ（NADP，比 NAD 多一个磷酸）。

    * 作为脱氢酶辅酶起递氢作用：底物脱下的氢交给 NAD 生成 NADH，交给 NADP 生成 NADPH，再供其他加氢反应。

    * 烟酸在人体内可由色氨酸代谢产生。

    * 氧化型与还原型在 260 nm 都有最大吸收峰；还原型（NADH、NADPH）在 340 nm 另有吸收峰，氧化型没有——测 340 nm 吸光变化即可反映以 NAD 或 NADP 为氢受体或供体的酶促反应快慢。

* **维生素 B2**

    * 氧化型呈黄色，故名核黄素。

    * 磷酸化后转变为黄素单核苷酸（FMN）与黄素腺嘌呤二核苷酸（FAD），二者是活性形式。

    * 构成黄素酶（黄素蛋白）的辅基，参与氧化还原反应、参与递氢。

    * 缺乏引起口角炎、舌炎；溶于水易随尿排出，服后尿黄。

* **泛酸**

    * 又称维生素 B5、遍多酸（广泛存在于自然界）。

    * 活性形式有两种：辅酶 A 与酰基载体蛋白（ACP）。

    * 辅酶 A 是主要活性形式，传递酰基、活化酰基，是各种酰化反应的辅酶；ACP 主要在脂肪酸合成、甘油三酯合成中发挥作用。

* **维生素 B6**

    * 包括吡哆醇、吡哆醛、吡哆胺；活性形式是磷酸吡哆醛与磷酸吡哆胺。

    * 两种活性形式差一个氨基，相互转化可逆，因而能转移氨基——是氨基转移酶的辅酶。

    * 还参与氨基酸的转氨、消旋、某些氨基酸脱羧、半胱氨酸脱硫基、糖原磷酸化；参与血清素、去甲肾上腺素、鞘磷脂、血红素合成。

    * 广泛存在于谷类外皮，肠道微生物也能合成；长期服抗生素可能致肠道菌群缺乏而缺乏 B6。

* **维生素 B12**

    * 氰钴胺素、钴胺素、抗恶性贫血因子；深红色含钴晶体，是唯一含金属元素的维生素。

    * 体内转变为两种辅酶：5′-脱氧腺苷钴胺素（辅酶 B12，甲基丙二酰 CoA 变位酶的辅酶）；甲基钴胺素（参与转甲基反应与叶酸代谢，是 N5-甲基四氢叶酸甲基转移酶的辅酶）。

    * 参与 DNA 合成，对红细胞成熟重要；缺乏时幼红细胞 DNA 合成受阻、不能分裂成熟，胞体变大，形成巨幼红细胞，导致巨幼红细胞性贫血。

    * 肠道细菌可合成，一般不缺乏；巨幼红细胞性贫血时需补充。

* **生物素**

    * 维生素 H；辅酶形式是生物胞素。

    * 在羧化反应中作活性羧基载体；是丙酮酸羧化酶、乙酰辅酶 A 羧化酶的辅基。

    * 与酶蛋白赖氨酸残基的 ε-氨基共价结合，形成“生物素-赖氨酸”官能团即生物胞素。

    * 缺乏场景：长期吃生鸡蛋（蛋清中抗生物素蛋白与生物素强亲和，结合后不能吸收）；长期服抗生素抑制肠道菌群。

* **叶酸**

    * 绿叶中含量丰富；是除二氧化碳外各种氧化水平一碳单位的重要受体和供体。

    * 活性形式是四氢叶酸（辅酶 F），由二氢叶酸还原酶对叶酸连续还原生成：叶酸 → 二氢叶酸 → 四氢叶酸。

    * 脱氧尿苷酸（dUMP）转变为脱氧胸苷酸（dTMP）需 N5,N10-亚甲基四氢叶酸提供甲基，这是体内合成胸腺嘧啶核苷酸的主要过程。

    * 另两个反应：N5,N10-亚甲基四氢叶酸使甘氨酸甲基化成丝氨酸；N5-甲基四氢叶酸使高半胱氨酸（同型半胱氨酸）转变为甲硫氨酸。

    * 抗癌药氨甲蝶呤、氨基蝶呤是四氢叶酸类似物，抑制二氢叶酸还原酶，进而抑制 dTMP 与 DNA 合成、抑制细胞分裂。

    * 缺乏时 DNA 合成受抑，骨髓幼红细胞分裂减慢、胞体变大，形成巨幼红细胞性贫血；B12 缺乏也走到同一结果——B12 是四氢叶酸给出甲基时的辅酶，缺 B12 则四氢叶酸的甲基给不出去，四氢叶酸相对不足。

* **硫辛酸**

    * 自然界很少以游离状态存在，与酶蛋白赖氨酸残基的 ε-氨基以酰胺键共价结合，形成硫辛酰胺残基——即其活性形式。

    * 是酰基载体，存在于丙酮酸脱氢酶复合物与 α-酮戊二酸脱氢酶复合物中。

    * 在 α-酮酸的氧化和脱羧中偶联酰基转移与电子转移。

    * 食物中的硫辛酸常与 B1 同时存在。

### 维生素 C

* **抗坏血酸**

    * 防治坏血病，故称抗坏血酸；广泛分布于动植物界。

    * 人及其他灵长类、少数脊椎动物与一些鸟类肝脏缺少 L-古洛糖酸-γ-内酯氧化酶，不能自行合成，必须从食物获取。

    * 是强还原剂，生化功能与生理功能都源于还原性，在体内起电子载体作用；氧化型仍有维生素 C 活力，但很快被降解。

* **生理功能**

    * 保持巯基酶的活性与谷胱甘肽的还原状态，起解毒作用；谷胱甘肽是谷氨酸、半胱氨酸、甘氨酸组成的三肽，被氧化后由维生素 C 还原。

    * 促进肠道吸收铁：把三价铁还原为二价铁；也把红细胞中高铁血红蛋白还原为血红蛋白，血红蛋白只有二价铁才能运氧。

    * 促进胶原蛋白合成：多肽链中脯氨酸与赖氨酸的羟化需要羟化酶，维生素 C 是维持羟化酶活性的必需辅因子。

    * 参与胆固醇转化为胆汁酸——这是胆固醇在体内最主要的去路。

    * 还参与芳香族氨基酸代谢，防止贫血与若干转运金属离子毒性，改善变态反应、调节组胺代谢、刺激免疫系统、防治感染。
