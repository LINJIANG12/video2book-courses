## 怎么学

- **按"专题 → 考点"两层走**：先看每册导读把专题主线立住，再用笔记按考点速查，二者不要混着读。
- **蛋白质部分先抓结构层次**：一级结构决定高级结构，高级结构决定功能；把这条因果链背熟，后面血红蛋白、抗体、酶活调节都能挂上去。
- **酶学抓住"活力—动力学—调节"三段**：活力怎么测、底物浓度怎么影响、抑制与别构/共价调节怎么区分，是选择题和简答题的高频区。
- **代谢部分画通路线图**：糖酵解 → 柠檬酸循环 → 氧化磷酸化 → 糖异生/糖原，脂代谢与含氮代谢分别挂在乙酰辅酶 A、丙酮酸、α-酮戊二酸等枢纽上。
- **考前只看 `notes/`**：10 篇笔记按考点重组，把定义、数值、限速酶、易错点并排放，适合冲刺期快速过。
