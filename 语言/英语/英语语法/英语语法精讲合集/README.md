# 英语语法精讲合集（29 讲）

从零开始、用中文讲透英语语法的一门系统课。主线是「先建体系、再逐块攻坚」：先讲清句子的基本骨架和十大词类职能，再依次攻克动词时态与语气、非谓语结构、从句、冠词介词、名词代词、数词形容词副词，最后落到被动、倒装、强调、省略与标点这些把句子写对的实战技巧。特点是例子密集、推导细致，不背规则而讲规则背后的道理。

## 怎么学

- **零基础先读第 1 册**，把「句子成分 + 十大词类 + 动词分类」这张地图铺开，后面每一册都在这张地图上填细节，跳过它后面会一直缺坐标系。
- **时态与虚拟语气（第 1 册后半）是全课最高频考点**，建议逐条对照笔记里的时态表与选用依据，把「时间轴 + 状态」两个维度真正分开算，而不是背十六个形态。
- **非谓语动词与从句（第 2 册）是第二大难点**，判断路径固定为「谓语位置是否被占用 → 剩下的动作降级成什么形式」，先把这条主线走顺，再看细分搭配。
- **冠词、介词、名词、代词（第 3 册）靠语感也靠规则**，中英差异最大的就是这一块：中文没有形态变化，所以要重点练冠词的泛指/特指切换和介词的固定搭配。
- **想快速查某个语法点**，直接用 `notes/` 的七篇笔记，每篇按主题组织、条目化速查，比翻视频快得多。
- **写句子总出错时翻第 5 册**，被动、倒装、强调、省略、主谓一致、标点这六件事，正是「语法没错但表达不对」的高发区。
