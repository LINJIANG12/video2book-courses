# 拯救者：汇编语言速成（19 讲）

这是一门面向期末、复试和专升本复习的 8086 汇编速成课，用 19 集压缩讲完微机基础、处理器结构、寻址方式、流程控制与子程序调用。课程强调“先把考试要用的主干抓出来”，适合已经上课但需要快速梳理的人。

- **原视频**：[【拯救者】汇编语言速成(期末 复试 专升本) 均可用 基础+题+文档](https://www.bilibili.com/video/BV1Wt4y1R7TU) — Bilibili，BV1Wt4y1R7TU
- **全 19 集**，已产出 6 册模块全书、3 篇复习笔记

## 怎么学

这门课的价值在“压缩主干”，适合带着考试范围或课程笔记来对照复习，不建议完全零基础时只靠它建立底层概念。

- **先补底板** → 模块 01 用较短的篇幅梳理微机基础、进位计数制与总线体系，是后面理解 8086 的前提
- **抓住两条主线** → 模块 02~04 处理寄存器、内存分段和八大寻址方式；模块 05~06 处理流程控制、循环与子程序
- **结合例题复习** → 速成课会把知识点直接落到典型题目上，建议按模块把例题重新手算一遍
- **用笔记收口** → `notes/` 的 3 篇把寄存器/存储、寻址/伪指令、控制流/堆栈三块内容聚合起来，适合考前快速回忆
