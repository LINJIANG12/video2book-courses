# 汇编语言工程结构、伪指令与八大寻址方式精解

## 汇编源程序工程构建与生命周期

### 工具链与文件生成机制

* **源程序文件（Source File，ASM）**

    * > **定义**：程序员使用文本编辑器编写的原始汇编代码纯文本文件。

    * 语法构成：内部包含由 CPU 执行的汇编指令与指导汇编器工作的伪指令。

    * 文件扩展名：固定为 `.ASM`。

    * 编译输入：作为汇编编译器（MASM）的直接输入文件。

* **目标文件（Object File，OBJ）**

    * > **定义**：源程序文件经汇编编译器语法分析与翻译后生成的中间二进制文件。

    * 内容结构：包含机器语言二进制机器码以及符号重定位信息。

    * 文件扩展名：固定为 `.OBJ`。

    * 硬件约束：目标文件尚未绑定运行库与段基址，无法由操作系统直接装载运行。

* **可执行文件（Executable File，EXE）**

    * > **定义**：链接器将一个或多个目标文件与系统库文件合并重定位后生成的最终二进制文件。

    * 生成工具：由链接器（LINK）处理 `.OBJ` 生成。

    * 文件扩展名：固定为 `.EXE`。

    * 加载机制：操作系统读取 `.EXE` 文件头信息，在内存中划分程序段前缀、代码段、数据段和堆栈段，并将 `CS:IP` 寄存器指向程序首条指令启动执行。

    * 工程构建生命周期流动模型：

        ```text
        +-------------------------------------------------------------+
        | 文本源文件 (.ASM)                                           |
        |        |                                                    |
        |        v   [ MASM 汇编器编译 ]                              |
        | 目标模块 (.OBJ)                                             |
        |        |                                                    |
        |        v   [ LINK 链接器链接 ]                              |
        | 可执行文件 (.EXE)                                           |
        |        |                                                    |
        |        v   [ DOS / OS 内存加载 ]                            |
        | 内存运行空间 (分配 PSP、CS:IP、DS、SS:SP)                   |
        +-------------------------------------------------------------+
        ```

### 汇编指令与伪指令本质分工

* **汇编指令（Instruction）**

    * > **定义**：具有直接对应二进制机器码、最终在 CPU 硬件电路上执行的底层操作语句。

    * 职能边界：用于控制硬件实现具体的算术逻辑运算、寄存器与内存数据传送以及程序分支跳转。

    * 典型代表：`MOV`、`ADD`、`SUB`、`JMP`、`INT`。

* **伪指令（Directive）**

    * > **定义**：没有对应机器指令码、不由 CPU 执行，仅在汇编阶段指示编译器如何组织程序结构的控制语句。

    * 职能边界：用于在编译期声明段结构、分配内存空间、关联段寄存器与定义符号常量。

    * 典型代表：`SEGMENT`、`ENDS`、`ASSUME`、`END`、`DB`、`DW`、`DD`、`ORG`、`EQU`。

* **汇编语句核心属性对比**

    | 特性维度 | 汇编指令 | 伪指令 |
    | :--- | :--- | :--- |
    | **机器码对应** | 严格对应 1 至多个字节二进制机器码 | 完全没有对应的机器码 |
    | **执行主体** | CPU 硬件微架构 | 汇编编译器（如 MASM）在编译期识别处理 |
    | **生命周期** | 程序运行时生效 | 编译阶段生效，运行期已不存在 |
    | **核心职能** | 控制数据计算、状态转移与外设交互 | 内存布局规划、符号表绑定与常量展开 |

## 汇编程序分段架构与加载运行机制

### 逻辑段界定与段关联伪指令

* **段界定伪指令（Segment Definition Directives）**

    * > **定义**：用于在汇编源程序中成对界定一个逻辑段起点与终点的控制伪指令。

    * 语法格式：段起始声明为 `段名 SEGMENT`，段结束声明为 `段名 ENDS`。

    * 配对规则：`SEGMENT` 与 `ENDS` 必须严格成对出现且段名一致，段内包裹该逻辑段的具体数据或代码。

* **段关联伪指令（Assume Directive，ASSUME）**

    * > **定义**：通知汇编编译器将定义的逻辑段与 CPU 内部段寄存器建立默认对应关系的指示语句。

    * 语法格式：`ASSUME 段寄存器名:段名 [, 段寄存器名:段名 ...]`。

    * 作用机理：仅在编译期建立符号表的基准关联，辅助编译器检查指令合法性与计算偏移地址，不产生任何机器码。

    * > ⚠️ **易错点**：`ASSUME DS:DATA` 绝不会在程序运行时将数据段地址写入段寄存器 `DS`，数据段基址必须在代码段入口由 CPU 显式执行传送指令加载。

* **源程序结束伪指令（End Directive，END）**

    * > **定义**：标志汇编源程序文件编译扫描终止并指定程序执行初始入口的伪指令。

    * 语法格式：`END [入口标号]`。

    * 截断机理：编译器扫描到 `END` 后立即停止语法分析，其后书写的任何代码均被忽略。

    * 入口定位：若书写 `END START`，操作系统加载程序时将把代码标号 `START` 的逻辑地址赋给 `CS:IP`，确保指令从指定标号启动。若未带入口标号，加载器无法准确定位首条执行指令。

* **程序安全返回机制（Program Termination Scheme）**

    * > **定义**：程序执行结束时，主动将 CPU 控制权交还给操作系统的软中断调用规范。

    * 指令组合：由 `MOV AX, 4C00H`（或 `MOV AH, 4CH` 配合 `MOV AL, 00H`）与 `INT 21H` 构成。

    * 运作机理：调用 DOS 系统的 4CH 号服务例程释放内存占用并返回系统命令行，缺失该调用将导致 CPU 连续执行后续随机内存内容引发崩溃。

### 程序段前缀与段寄存器初始化

* **程序段前缀（Program Segment Prefix，PSP）**

    * > **定义**：操作系统加载 `.EXE` 文件到内存时，在程序各逻辑段之前开辟的用于存储进程控制信息的连续内存块。

    * 空间大小：固定占用 256 字节（十六进制 100H）。

    * 内存相对布局：

        ```text
        +-----------------------------------------------+
        | 程序段前缀 PSP (大小 256 字节 / 100H)          | <--- DS, ES 默认指向基址
        +-----------------------------------------------+
        | 代码段 CODE (存放机器指令序列)                 | <--- CS:IP 指向 START
        +-----------------------------------------------+
        | 数据段 DATA (存放静态全局变量)                 |
        +-----------------------------------------------+
        | 堆栈段 STACK (存放运行时调用栈)               | <--- SS:SP 指向栈顶
        +-----------------------------------------------+
        ```

* **初始寄存器状态与段地址加载规范**

    * 入口初始态：程序刚启动时，`CS:IP` 自动指向 `END` 伪指令指定的标号，`DS` 和 `ES` 默认指向 `PSP` 的段首地址，`SS:SP` 自动指向显式声明 `STACK` 属性的堆栈段。

    * 数据段基址赋值铁律：必须先将段名赋给通用寄存器，再由通用寄存器送入段寄存器。

        ```x86asm
        MOV AX, DATA
        MOV DS, AX
        ```

    * > ⚠️ **易错点**：8086 硬件指令集严禁立即数直接写入段寄存器，写出 `MOV DS, DATA` 属于严重语法错误，汇编阶段直接报错。

## 数据定义伪指令与内存存储模型

### 变量定义与数据宽度伪指令

* **数据定义伪指令（Data Definition Directives）**

    * > **定义**：为变量在内存中分配特定字节宽度的连续存储单元并初始化数据的伪指令。

    * 语法格式：`变量名 伪指令助记符 初始值1, 初始值2, ...`。

    * 核心宽度类型：

        * `DB`（Define Byte）：字节类型，每个单元分配 1 个字节（8 位）。

        * `DW`（Define Word）：字类型，每个单元分配 2 个字节（16 位）。

        * `DD`（Define Doubleword）：双字类型，每个单元分配 4 个字节（32 位）。

* **标识符命名规范（Identifier Naming Rules）**

    * 字符集限制：只能由英文字母、数字和下划线 `_` 组成。

    * 首字符约束：严禁以数字作为首字符（如 `2DATA`、`2DA` 均为非法标识符）。

    * 关键字排他：严禁使用系统保留关键字充当变量名（如寄存器名 `AX`、指令助记符 `MOV` 均不可用）。

* **标号分类及冒号规则**

    * 代码标号：定义在指令语句前端，末尾必须带有英文冒号（如 `START:`），指示指令段内偏移地址，供跳转调用。

    * 数据标号：定义在数据伪指令前端，末尾严禁带有英文冒号（如 `VAR1 DW 1234H`），指示变量存储首字节偏移地址。

### 批量重复操作符与空间计算

* **批量重复操作符（Duplicated Operator，DUP）**

    * > **定义**：指示汇编编译器将指定初始值或数据模式连续重复分配多次的内存定义操作符。

    * 语法格式：`重复次数 DUP ( 重复内容 )`。

    * 空间计算准则：某语句分配的总内存字节数等于外层重复次数、括号内元素个数与单元素类型宽度字节数三者的连乘积：

        $$\text{总字节数} = \text{外层重复次数} \times \text{括号内元素个数} \times \text{类型字节宽度}$$

* **嵌套 DUP 展开逻辑**

    * 展开规则：由最内层括号向外层逐级拆解，内层序列展开后再参与外层乘算。

    * 示例推导：针对 `BUF DB 3 DUP(1, 2 DUP(3), 4)`：

        1. 内层展开：`2 DUP(3)` 展开为 `3, 3`，元素个数为 2；

        2. 组合中层：`(1, 2 DUP(3), 4)` 合并为序列 `1, 3, 3, 4`，单组元素共 4 个；

        3. 外层相乘：最外层重复 3 次，总元素个数为 $3 \times 4 = 12$ 个；

        4. 宽度校核：类型为 `DB`（1 字节），总空间为 $12 \times 1 = 12$ 字节；前 6 个字节十六进制依次为 `01H, 03H, 03H, 04H, 01H, 03H`。

    * > ⚠️ **易错点**：若将定义语句前缀换为 `DW`，计算出的元素总个数必须再乘以 2 才是最终分配的内存字节数。

### 地址计数器与定位伪指令

* **地址计数器（Location Counter，\$）**

    * > **定义**：汇编器在对源程序进行编译扫描时，内部维护的保存当前语句段内偏移地址的保留变量符号。

    * 动态特性：每翻译一条指令或定义一个变量，地址计数器 `$` 会自动递增当前语句所占用的字节数。

* **起始地址设定伪指令（Origin Directive，ORG）**

    * > **定义**：强制改变编译器内部当前地址计数器数值的定位伪指令。

    * 语法格式：`ORG 数值表达式`。

    * 运作机理：将当前地址计数器 `$` 强制重置为指定值，后续数据或指令紧随该偏移地址开始存放。

* **等值伪指令与数组动态计数（Equate Directive，EQU）**

    * > **定义**：为数据表达式、常数或地址差值定义符号常量的文本替换伪指令。

    * 存储特性：不占用任何生成文件的目标代码内存空间。

    * 数组容量统计范式：对于数组 `TABLE DW 10, 20, 30, 40, 50`：

        * 字节长度统计：`COUNT1 EQU $ - TABLE` 计算结果为 10，代表占用总字节数。

        * 元素个数统计：`COUNT2 EQU ($ - TABLE) / 2` 计算结果为 5，代表字数组包含的有效元素个数。

### 内存小端存储与字符编码排布

* **小端存储格式（Little-Endian）**

    * > **定义**：多字节数据写入连续内存时，低位数据字节存放于低内存物理地址、高位数据字节存放于高内存物理地址的存储模式。

    * 存储准则：

        ```text
        +-------------------------------------------------------------+
        | 多字节小端存放逐字节展开排布规则                            |
        |                                                             |
        |   DATA1 DB 10         ; 十进制 10 -> 0AH (占 1 字节)        |
        |   DATA2 DW 0100H      ; 字数据 -> 低位 00H，高位 01H        |
        |   DATA3 DD 12345678H  ; 双字 -> 78H, 56H, 34H, 12H          |
        |                                                             |
        |   偏移地址      存放十六进制内容      逻辑数据归属           |
        |   +---------+   +--------------+     +--------------------+ |
        |   |  0006H  |   |     12H      | <-- DATA3 最高位字节       | |
        |   |  0005H  |   |     34H      | <-- DATA3 次高位字节       | |
        |   |  0004H  |   |     56H      | <-- DATA3 次低位字节       | |
        |   |  0003H  |   |     78H      | <-- DATA3 最低位字节       | |
        |   +---------+   +--------------+     +--------------------+ |
        |   |  0002H  |   |     01H      | <-- DATA2 高位字节         | |
        |   |  0001H  |   |     00H      | <-- DATA2 低位字节         | |
        |   +---------+   +--------------+     +--------------------+ |
        |   |  0000H  |   |     0AH      | <-- DATA1 字节数据         | |
        |   +---------+   +--------------+     +--------------------+ |
        +-------------------------------------------------------------+
        ```

    * 负数补码排布：16 位负数在字变量中以补码存放，如 `-1` 补码为 `0FFFFH`，低字节存入 `0FFH`，高字节存入 `0FFH`。

* **字符与字符串常量的 ASCII 映射**

    * 书写语法：汇编语言中字符或字符串必须使用英文单引号包裹。

    * 编码规则：汇编器将字符逐一转化为对应 ASCII 码值存入单字节单元中。

    * 关键编码基准：字符 `'A'` 对应十六进制 `41H`（十进制 65），`'B'` 对应 `42H`；字符 `'a'` 对应十六进制 `61H`（十进制 97）。

    * 大小写转换算术关系：大写字母与小写字母 ASCII 码相差固定值 $20\text{H}$：

        $$\text{大写字母 ASCII} = \text{小写字母 ASCII} - 20\text{H}$$

## 系统功能调用与调试跟踪技术

### 中断功能调用通信协议

* **DOS 系统功能调用（DOS System Call，INT 21H）**

    * > **定义**：汇编语言通过 CPU 软中断指令向 DOS 操作系统请求内核级基础 I/O 与进程控制服务的统一接口。

    * 标准调用四步协议：

        1. 功能号装载：在寄存器 `AH` 中装入预设的系统子功能号；

        2. 入口参数配置：根据所调功能要求，在 `DL`、`DX` 或 `AL` 等寄存器中填入待处理数据或缓冲区首地址；

        3. 触发软中断：执行 `INT 21H` 转移执行权至 DOS 中断处理程序；

        4. 出口结果获取：中断返回后从指定寄存器（如 `AL`）读取返回值。

* **核心系统功能号全景规范**

    | 功能号（AH） | 服务功能 | 入口参数要求 | 出口返回值 | 运行约束与典型场景 |
    | :--- | :--- | :--- | :--- | :--- |
    | `01H` | 键盘单字符输入并回显 | 无 | `AL = 键入字符 ASCII 码` | 读取单键输入并实时显示在屏幕上 |
    | `02H` | 屏幕显示单个字符 | `DL = 待显字符 ASCII 码` | 无 | 屏幕输出单字符或输出控制符 |
    | `09H` | 屏幕显示字符串 | `DS:DX = 字符串起始逻辑地址` | 无 | 输出文本串，必须以 `$` 作为终止符 |
    | `0AH` | 键盘带缓冲输入字符串 | `DS:DX = 预设缓冲区起始地址` | 实际内容写入缓冲区 | 读取长串输入，支持退格编辑 |
    | `4CH` | 进程安全终止并退出 | `AL = 返回代码（通常设 00H）` | 无 | 释放内存控制权并安全返回操作系统 |

### 常用屏幕输入输出功能

* **单字符输出与换行控制（02H号功能）**

    * 单字符输出逻辑：将待显 ASCII 码存入 `DL`，执行 `MOV AH, 02H; INT 21H`。

    * 规范光标换行序列：DOS 屏幕换行必须由回车符（CR）与换行符（LF）两步顺序调用组成：

        ```x86asm
        MOV AH, 02H
        MOV DL, 0DH    ; 回车符 CR，将光标移动至当前行首
        INT 21H
        MOV DL, 0AH    ; 换行符 LF，将光标垂直下移一行
        INT 21H
        ```

* **带终止符字符串输出（09H号功能）**

    * 地址装载：必须将字符串所在段基址置入 `DS`，偏移地址送入 `DX`（采用 `LEA DX, 变量名` 或 `MOV DX, OFFSET 变量名`）。

    * 终止标志约束：待输出字符串的末尾必须显式包含美元符号 `$`（ASCII 码 24H）。

    * 扫描截断机理：

        ```text
        09H 字符串内存扫描流程:
        [ 'H' ][ 'E' ][ 'L' ][ 'L' ][ 'O' ][ 0DH ][ 0AH ][ '$' ][ 内存无序数据... ]
          ▲                                                ▲
          │                                                │
        DS:DX 指向字符串首地址                             遇 '$' 立即终止扫描输出
        ```

    * > ⚠️ **易错点**：若字符串尾部遗漏 `$`，09H 功能在打印完有效文本后将持续向后越界读取相邻内存字节并在屏幕上打印乱码，直到偶然匹配到十六进制 `24H` 为止。

* **带缓冲区键盘输入结构（0AH号功能）**

    * 缓冲区内存定义模板：

        ```x86asm
        BUF DB 50        ; 第 1 字节：预设允许输入的最大字符容量（含回车符）
            DB ?         ; 第 2 字节：系统在输入完成后回填的实际字符数（不含回车符）
            DB 50 DUP(0) ; 第 3 字节开始：实际存放键入字符的物理存储区
        ```

    * 数据对齐关系：调用 `MOV AH, 0AH; LEA DX, BUF; INT 21H` 触发输入，用户按下回车键（0DH）结束输入。此时 `BUF+1` 记录实际长度 $N$，键入的第一个字符固定保存在 `BUF+2` 单元中。

### 调试工具核心命令与步过策略

* **Debug 基础调试命令族**

    * `R` 命令：单独输入 `-R` 打印全部寄存器值、状态标志位与下一条待执行指令；输入 `-R 寄存器名` 提供后续输入以修改指定寄存器。

    * `D` 命令（Dump）：按段基址与偏移地址查看内存原始内容，如 `-D DS:0000 20` 连续显示 20H 个字节。

    * `E` 命令（Enter）：直接修改内存指定单元的数值，如 `-E DS:0 12 34 56`。

    * `U` 命令（Unassemble）：将内存中存放的二进制机器码反编译显示为汇编指令。

    * `A` 命令（Assemble）：在指定内存起始偏移地址处直接以交互方式敲入汇编指令并就地汇编。

    * `Q` 命令（Quit）：退出 Debug 工具安全返回操作系统命令行。

* **单步跟踪与单步步过执行策略**

    * `T` 命令（Trace）：真正的单步跟踪指令，遇到子程序调用 `CALL` 或系统软中断 `INT 21H` 时，会直接深入跳转进系统内核服务程序内部逐条指令运行。

    * `P` 命令（Proceed）：过程步过指令，遇到 `INT 21H`、`CALL` 或循环结构 `LOOP` 时，会在后台自动将整个子过程、中断例程或循环执行完毕，直接中断在紧随其后的下一条语句上。

    * > **提示**：在跟踪包含 `INT 21H` 功能调用、`CALL` 过程或 `LOOP` 循环的代码段时，必须使用 `P` 命令步过以防止陷入底层海量无关指令中；仅在核验自身算术逻辑指令时使用 `T` 命令单步跟踪。

## 操作数来源与非内存寻址方式

### 操作数存储位置分类

* **操作数四大来源维度**

    * 指令代码内部：操作数直接作为机器码的一部分编码在指令中，称为立即数。

    * CPU 内部寄存器：操作数存放于通用寄存器或段寄存器内，访问完全在芯片内部完成。

    * 内存存储单元：操作数保存在数据段、附加段、堆栈段或代码段的物理存储单元中，需通过总线寻址访存。

    * 外设 I/O 端口：操作数位于独立编址的硬件外设接口寄存器中，通过专有 `IN` 和 `OUT` 指令存取。

### 立即寻址与寄存器寻址

* **立即寻址（Immediate Addressing）**

    * > **定义**：操作数数值直接包含在机器指令代码中紧随操作码之后的寻址方式。

    * 数据特征：该操作数被称为立即数，可以是 8 位（如 `MOV AL, 50H`）或 16 位（如 `MOV AX, 1234H`）。

    * 位置限制：立即数只能充当源操作数，绝对严禁作为目的操作数（如 `MOV 100H, AX` 非法）。

    * 硬件限制：8086 硬件禁止将立即数直接传送至段寄存器（如 `MOV DS, 1000H` 非法）。

* **寄存器寻址（Register Addressing）**

    * > **定义**：操作数直接保存在 CPU 内部指定的寄存器中的寻址方式。

    * 性能表现：指令执行期数据传输纯粹在芯片寄存器堆内部进行，无需占用外部总线周期，执行速度最快。

    * 字长匹配规则：源操作数与目的操作数的寄存器位宽必须严格一致，8 位对 8 位、16 位对 16 位（写出 `MOV AL, BX` 属于非法指令）。

## 内存寻址铁律与存储器寻址形态

### 内存寻址寄存器约束与段默认法则

* **有效地址（Effective Address，EA）**

    * > **定义**：CPU 访问内存操作数时，该单元相对于所属逻辑段起始位置的 16 位段内偏移地址。

    * 物理地址计算公式：

        $$\text{物理地址 (PA)} = (\text{段基址} \times 16) + EA = (\text{段基址} \times 10\text{H}) + EA$$

* **16 位存储器寻址四大铁律**

    * 铁律一（寻址寄存器白名单）：在中括号 `[...]` 内充当内存寻址指针的寄存器**仅允许使用 `BX`、`BP`、`SI`、`DI` 四个**。其余寄存器（`AX`、`CX`、`DX`、`SP`、`IP` 及所有段寄存器）严禁放入括号内寻址。

    * 铁律二（段寄存器默认配对法则）：

        * 寻址指针中凡包含基址指针寄存器 **`BP`** 的，其默认段基址必定为 **`SS`（堆栈段）**。

        * 寻址指针中凡只包含 **`BX`、`SI`、`DI`** 或**纯常数位移量**的，其默认段基址必定为 **`DS`（数据段）**。

    * 铁律三（双寄存器合法组合准则）：在复合寻址中同时使用两个寄存器求和时，**必须是一个基址寄存器（`BX` 或 `BP`）搭配一个变址寄存器（`SI` 或 `DI`）**。

        * 合法双寄存器组合仅 4 种：`[BX+SI]`、`[BX+DI]`、`[BP+SI]`、`[BP+DI]`。

        * 严禁双基址合用：`[BX+BP]` 非法。

        * 严禁双变址合用：`[SI+DI]` 非法。

    * 铁律四（双内存操作数禁止原则）：8086 指令系统严禁源操作数与目的操作数同时为内存存储器操作数（如 `MOV [BX], [SI]` 语法非法，必须借助通用寄存器拆分为两步传输）。

### 简单与间接内存寻址

* **直接寻址（Direct Addressing）**

    * > **定义**：指令直接给出操作数 16 位有效地址偏移量数值的内存寻址方式。

    * 表达形式：可直接书写括号常数（如 `MOV AX, [2000H]`）或直接引用数据标号变量名（如 `MOV BX, TOTAL`）。

    * 段超越前缀：若需越界访问其他逻辑段，需显式附加段超越前缀（如 `MOV AX, ES:[2000H]`，此时有效地址由 `ES` 乘 16 合成）。

* **寄存器间接寻址（Register Indirect Addressing）**

    * > **定义**：操作数的有效地址保存在基址或变址寄存器中，指令通过单个寄存器内容间接寻址内存的机制。

    * 表达形式：括号内仅包含单个合法指针寄存器，写作 `[BX]`、`[BP]`、`[SI]`、`[DI]`。

    * 地址映射逻辑：

        ```text
        寄存器间接寻址数据流拓扑:
        [ 指令: MOV AX, [BX] ]
                   |
                   v 提取内容
             [ 寄存器 BX: 0100H ] --------------+
                                                +--> [ 20位加法器 ] --> 物理地址 20100H --> 读取字送入 AX
             [ 段寄存器 DS: 2000H ] --- x 16 ---+
        ```

### 基址变址与相对复合寻址

* **寄存器相对寻址（Register Relative Addressing）**

    * > **定义**：有效地址由指定寻址寄存器的内容与指令中给出的位移量（Displacement）相加合成的寻址方式。

    * 有效地址计算：$EA = (BX/BP/SI/DI) + \text{位移量}$。

    * 等价语法形态：`MOV AX, [BX+10H]` 与 `MOV AX, 10H[BX]` 机器语义完全等价。

    * 高级语言映射：映射高级语言中一维数组访问 `array[i]`，位移量作为数组基地址，寄存器充当下标。

* **基址变址寻址（Base Indexed Addressing）**

    * > **定义**：有效地址由一个基址寄存器（`BX` 或 `BP`）的内容与一个变址寄存器（`SI` 或 `DI`）的内容相加合成的寻址方式。

    * 有效地址计算：$EA = (\text{基址寄存器}) + (\text{变址寄存器})$。

    * 段寄存器绑定：若基址部分为 `BX` 则默认段为 `DS`；若基址部分为 `BP` 则默认段为 `SS`。

* **相对基址变址寻址（Relative Base Indexed Addressing）**

    * > **定义**：有效地址由一个基址寄存器、一个变址寄存器以及一个常量位移量三者共同求和合成的寻址方式。

    * 物理地址合成拓扑：

        ```text
        相对基址变址寻址硬件合成拓扑:
        段基址 (DS / SS) x 16 -----+
        基址寄存器 (BX / BP) ------+
        变址寄存器 (SI / DI) ------+---> [ 20位内部加法器 ] ---> 目标物理地址 (PA)
        位移量 (Displacement) -----+
        ```

    * 等价书写形式：`MOV AX, [BX+SI+100H]`、`MOV AX, 100H[BX][SI]`、`MOV AX, [BX][SI+100H]` 等价。

    * 高级语言映射：映射二维数组或表格检索 `matrix[row][col]`，位移量指定表格起始地址，基址寄存器定位行号，变址寄存器步进列号。

### 操作数类型限定符与隐含寻址

* **类型限定操作符（Pointer Operator，PTR）**

    * > **定义**：在指令中用于显式声明内存操作数数据宽度类型（字节或字）的操作符。

    * 强制使用条件：当源操作数为立即数且目的操作数为内存单元时（如 `MOV [BX], 25H`），因两端均无法隐式推导操作数宽度，必须显式指明 `BYTE PTR` 或 `WORD PTR`。

    * 内存改写边界：

        * 执行 `MOV BYTE PTR [BX], 78H`：仅且只改写 `[BX]` 所指向的 1 个字节，相邻高地址单元内容保持不变。

        * 执行 `MOV WORD PTR [BX], 0ABH`：立即数扩展为 16 位字 `00ABH`，小端序将低位 `ABH` 写入低地址单元，同时**高位 `00H` 强制覆盖并清零紧邻的高地址字节单元**。

* **隐含寻址（Implied Addressing）**

    * > **定义**：操作数的存储位置不由指令显式给出，而是由指令操作码本身硬性隐含约定的寻址方式。

    * 典型范例：无符号乘法指令 `MUL BL`，源操作数显式给出 `BL`，而目的累加器 `AX` 则由 `MUL` 助记符底层硬件架构隐含固定绑定。

## 寻址方式综合对比与合法性判定

### 八大寻址方式综合特性对比

| 寻址方式名称 | 指令书写典型范式 | 有效地址 $EA$ 解析公式 | 默认段寄存器 | 高级语言及底层数据结构映射 |
| :--- | :--- | :--- | :--- | :--- |
| **立即寻址** | `MOV AX, 1000H` | 无（操作数嵌于机器码中） | 代码段（CS） | 常量赋值、掩码初始化 |
| **寄存器寻址** | `MOV AX, BX` | 无（操作数在 CPU 内部） | 无（寄存器堆） | 高速局部变量暂存与核心计算 |
| **直接寻址** | `MOV AX, [1000H]` | $EA = 1000\text{H}$ | `DS`（可通过前缀超越） | 全局静态变量存取 |
| **寄存器间接寻址** | `MOV AX, [BX]` | $EA = (BX)$ | `DS`（若为 BP 则默认 `SS`） | 一级指针直接解引用 `*ptr` |
| **寄存器相对寻址** | `MOV AX, [BX+10H]` | $EA = (BX) + 10\text{H}$ | `DS`（若为 BP 则默认 `SS`） | 一维数组检索 `array[i]` |
| **基址变址寻址** | `MOV AX, [BX+SI]` | $EA = (BX) + (SI)$ | `DS`（若为 BP 则默认 `SS`） | 动态数组、栈上动态偏移定位 |
| **相对基址变址寻址** | `MOV AX, [BX+SI+4]` | $EA = (BX) + (SI) + 4$ | `DS`（若为 BP 则默认 `SS`） | 二维数组、结构体数组元素 `s[i].field` |
| **隐含寻址** | `MUL BL` | 无（由操作码底层内嵌绑定） | 无（硬件内嵌 AX 等） | 定向乘除算术运算及特定串操作 |

### 指令合法性排查规则与典型误区

* **指令合法性五步核验法**

    ```text
    指令合法性五步排验流程:
    1. 查两端宽度 ──> 是否一边 8 位一边 16 位？(例如 MOV AL, BX 非法)
    2. 查双内存   ──> 是否两端均为存储器操作数？(例如 MOV [BX], [SI] 非法)
    3. 查段寄存器 ──> 是否给 CS 写入？是否段寄存器互拷？是否直赋立即数？
    4. 查指针合规 ──> 括号内是否仅限 BX/BP/SI/DI？是否出现双基址或双变址？
    5. 查类型指向 ──> 立即数送内存时，是否缺失 BYTE PTR 或 WORD PTR？
    ```

* **常见非法指令错误原因速查清单**

    * `MOV [BX], [SI]`：非法。违反双内存禁止原则，8086 不支持内存到内存直接传送。

    * `MOV AL, BX`：非法。两端操作数字长不匹配，`AL` 为 8 位，`BX` 为 16 位。

    * `MOV DS, 1000H`：非法。立即数严禁直接赋给段寄存器，必须经通用寄存器中转。

    * `MOV CS, AX`：非法。代码段寄存器 `CS` 严禁充当传送指令的目的操作数，破坏执行指令流。

    * `MOV DS, ES`：非法。8086 不支持段寄存器之间直接数据传送，必须借助通用寄存器。

    * `MOV AX, [DX]`：非法。`DX` 严禁出现在中括号内充当寻址指针寄存器。

    * `MOV AX, [BX+BP]`：非法。双基址合用错误，不能同时使用两个基址寄存器寻址。

    * `MOV AX, [SI+DI]`：非法。双变址合用错误，不能同时使用两个变址寄存器寻址。

    * `MOV [BX], 25H`：非法。操作数属性不明确，缺少 `BYTE PTR` 或 `WORD PTR` 类型说明符。

    * `MOV ES:[BX+SI], AX`：合法。基址配变址，显式段超越前缀，16 位字长对齐。

### 物理地址合成与内存改写推导

* **多模式物理地址合成综合实例**

    * 初始寄存器环境：设 $(DS) = 2000H$，$(SS) = 3000H$，$(ES) = 4000H$，$(BX) = 0100H$，$(BP) = 0200H$，$(SI) = 0010H$，$(DI) = 0020H$。

    * 综合推导核验表：

        | 待测指令 | 寻址方式判定 | 有效地址 $EA$ 推导 | 最终绑定段寄存器 | 20 位物理地址（PA）计算链条 |
        | :--- | :--- | :--- | :--- | :--- |
        | `MOV AX, [1200H]` | 直接寻址 | $EA = 1200\text{H}$ | `DS (2000H)` | $2000\text{H} \times 10\text{H} + 1200\text{H} = 21200\text{H}$ |
        | `MOV AX, [BX+SI]` | 基址变址寻址 | $0100\text{H} + 0010\text{H} = 0110\text{H}$ | `DS (2000H)` | $2000\text{H} \times 10\text{H} + 0110\text{H} = 20110\text{H}$ |
        | `MOV AX, [BP+DI+6]` | 相对基址变址寻址 | $0200\text{H} + 0020\text{H} + 6\text{H} = 0226\text{H}$ | `SS (3000H)` | $3000\text{H} \times 10\text{H} + 0226\text{H} = 30226\text{H}$ |
        | `MOV AX, ES:[BX+10H]` | 寄存器相对寻址 | $0100\text{H} + 0010\text{H} = 0110\text{H}$ | `ES (4000H)` | $4000\text{H} \times 10\text{H} + 0110\text{H} = 40110\text{H}$ |

    * > **提示**：做物理地址合成题时，首要检查中括号内是否包含 `BP` 寄存器。若包含 `BP` 且指令无显式段超越前缀，段基址必须强行绑定堆栈段寄存器 `SS`。
