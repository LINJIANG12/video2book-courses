# 微型计算机底层基础与 8086 寄存器存储体系

## 进位计数制与机器数表示体系

### 常用数制与进位标识

* **进位计数制（Positional Numeral System）**

    * > **定义**：按位权展开并遵循固定基数进位规则的数值表示体系。

    * 二进制（Binary，B）：基数为 2，数码范围为 $0 \sim 1$，运算规则为逢二进一，书写后缀为 `B`（例如 `10001B`）。

    * 八进制（Octal，O/Q）：基数为 8，数码范围为 $0 \sim 7$，运算规则为逢八进一，书写后缀为 `O` 或 `Q`（例如 `1750O`）。

    * 十进制（Decimal，D）：基数为 10，数码范围为 $0 \sim 9$，运算规则为逢十进一，书写后缀为 `D`，在汇编源程序中通常可省略后缀（例如 `178D` 或 `178`）。

    * 十六进制（Hexadecimal，H）：基数为 16，数码范围为 $0 \sim 9, \text{A} \sim \text{F}$（其中 $\text{A}=10, \text{B}=11, \text{C}=12, \text{D}=13, \text{E}=14, \text{F}=15$），运算规则为逢十六进一，书写后缀为 `H`（例如 `1F4H`, `2BH`）。

    * > **易错点**：⚠️ 汇编源程序中书写十六进制常数时，若最高位数值为字母（$\text{A} \sim \text{F}$），必须在最前端补写数字 `0`（例如必须书写为 `0A000H` 而非 `A000H`），否则汇编编译器会将其误识别为变量名或标号。

### 进位计数制转换机理

* **数制转换算法（Number System Conversion）**

    * > **定义**：在不同进位基数之间实现数值等价映射的算法集合。

    * 整数转换机理：十进制整数转换为任意 $R$ 进制数采用除基取余法，连续除以基数 $R$ 并记录余数，直至商为 0 终止；所有余数自底向上逆序排列，最后一次产生的余数为主高位（MSB），首次产生的余数为最低有效位（LSB）。

    * 小数转换机理：十进制纯小数转换为任意 $R$ 进制数采用乘基取整法，连续乘以基数 $R$ 并移出乘积的整数部分，剩余纯小数继续乘基，直至小数部分归零或达到规定精度截断；移出的整数位自顶向下顺序排列。

    * 按权展开求和机理：任意 $R$ 进制数转十进制采用多项式按权求和法，计算公式为 $\sum d_i \times R^i$；小数点左侧位权指数依次为 $0, 1, 2, \dots$，小数点右侧位权指数依次为 $-1, -2, -3, \dots$。

    * 特殊位权特征机理：形如 $(100)_R$ 的多进制数，其对应十进制真值直接等于基数的平方 $1 \times R^2$；八进制数 $(100)_8 = 8^2 = 64\text{D}$，十六进制数 $(100)_{16} = 16^2 = 256\text{D}$。

    * 定长分组映射机理：二进制与八进制、十六进制之间基于 $2^3=8$ 与 $2^4=16$ 存在定长映射；八进制 1 位精确对应二进制 3 位，十六进制 1 位精确对应二进制 4 位。

    * 分组补零规则：以小数点为基准，整数部分向左划分分组且高位不足补零，小数部分向右划分分组且末尾不足向右补零。

    * > **易错点**：⚠️ 转换方向必须遵循“整数倒，小数顺”，即整数除基取余自底向上逆序记录，小数乘基取整自顶向下顺序记录；小数向右划组不足 4 位时必须在最右侧尾部补零，严禁向左补零。

### 原码与补码表示机理

* **机器数（Machine Number）**

    * > **定义**：在计算机物理硬件内部用特定位宽的二进制高低电平编码表示的有符号数值。

    * 符号位（Sign Bit）：机器数的最高有效位固定充当符号位；符号位为 `0` 表示正数，符号位为 `1` 表示负数。

    * 原码（Sign-Magnitude Representation）：最高位为符号位，其余低位为数值本身的绝对值二进制表示；在 8 位字长下，Bit 7 为符号位，Bit 6 ~ Bit 0 为 7 位数值位，表示范围为 $-127 \sim +127$。

    * 原码双零歧义：原码存在正零（`00000000B`）与负零（`10000000B`）两种编码形式，且加减运算电路无法统一。

    * 2 的幂次方基准数值：$2^7 = 128$，$2^8 = 256$，$2^9 = 512$，$2^{10} = 1024$。

* **补码（Two's Complement）**

    * > **定义**：计算机内部统一用于存储、处理与执行有符号整数加减运算的机器编码。

    * 正数补码规则：正数的补码与原码完全相同，符号位为 `0`。

    * 负数补码生成规则：负数的补码由其原码变换生成，符号位保持 `1` 不变，其余数值位逐位按位取反，最后在最低有效位（LSB）加 1。

    * 补码求相反数规则：已知某数的补码 $[Y]_{\text{补}}$，将其连同符号位在内的全部二进制位按位取反，再在最低位加 1，即可直接获得其相反数的补码 $[-Y]_{\text{补}}$。

### 补码加减法运算与逻辑操作

* **补码加减运算（Two's Complement Arithmetic）**

    * > **定义**：利用补码代数性质将减法运算统一转化为加法操作的硬件运算机理。

    * 运算代数公式：$[X + Y]_{\text{补}} = [X]_{\text{补}} + [Y]_{\text{补}}$，$[X - Y]_{\text{补}} = [X]_{\text{补}} + [-Y]_{\text{补}}$。

    * 溢出与进位舍弃规则：在固定字长（如 8 位）的补码加法运算中，最高位进位产生的溢出位自动丢弃，微处理器寄存器仅保留低位结果。

* **基本逻辑运算（Bitwise Logic Operations）**

    * > **定义**：在微处理器内部直接由底层逻辑门电路执行的按位布尔代数运算。

    * 逻辑与（Logical AND，`&`）：双目运算符，运算规则为全 1 为 1，有 0 则 0；常用于屏蔽指定位或提取特定位。

    * 逻辑或（Logical OR，`|`）：双目运算符，运算规则为有 1 为 1，全 0 则 0；常用于将指定二进制位置 1。

    * 逻辑非（Logical NOT，`~`）：单目运算符，运算规则为按位逐位求反，0 变 1，1 变 0。

    * 逻辑异或（Logical XOR，`^`）：双目运算符，运算规则为相异为 1，相同为 0。

    * 寄存器清零机制：汇编语言中执行 `XOR AX, AX` 指令，由于任意数值与自身异或结果必然为全 0，可实现寄存器快速清零；其执行周期与机器码字节开销均优于 `MOV AX, 0`。

### 字符编码体系

* **ASCII 码（American Standard Code for Information Interchange）**

    * > **定义**：用于在计算机系统中表示文本字符与控制符的标准二进制编码规范。

    * 大写字母基准编码：大写字母 `'A'` 的十进制 ASCII 码为 65，十六进制表示为 `41H`，二进制表示为 `01000001B`。

    * 小写字母基准编码：小写字母 `'a'` 的十进制 ASCII 码为 97，十六进制表示为 `61H`，二进制表示为 `01000001B` 与 $32$ 相加得到的 `01100001B`。

    * 大小写转换机理：大小写英文字母 ASCII 码差值恒定为 $32$（即二进制第 5 位的权重 $2^5$）；大写字母转小写只需在其 ASCII 码上加 32 或将第 5 位置 1，小写转大写只需减 32 或将第 5 位置 0。

## 微型计算机硬件架构与系统总线机理

### 计算机语言层级划分

* **计算机程序设计语言层级（Computer Language Hierarchy）**

    * > **定义**：按照对物理硬件抽象程度从低到高划分的计算机指令表达体系。

    * 机器语言（Machine Language）：直接由 `0` 和 `1` 二进制代码构成的指令序列，是计算机硬件唯一能直接识别并执行的原生语言，执行效率最高，但极难编写与调试。

    * 汇编语言（Assembly Language）：使用英文助记符（Mnemonic，如 `MOV`、`ADD`）与符号地址替代二进制机器指令的符号化程序设计语言；指令与机器码保持严格的一一映射关系，直接面向处理器内部寄存器与物理存储结构。

    * 编译器（Assembler）：将汇编语言源程序中的助记符翻译为物理芯片可识别执行的二进制机器码的系统软件。

    * 高级语言（High-Level Language）：面向算法与问题求解、屏蔽处理器底层硬件细节、具备高度可移植性的程序设计语言（如 C、C++、Java、Python 等）。

    * > **易错点**：⚠️ 汇编语言属于面向机器底层的**低级语言（Low-Level Language）**，绝不是高级语言。

### 汇编程序组成要素

* **汇编源程序构成成分（Assembly Program Components）**

    * > **定义**：构成汇编语言源文本并由汇编编译器与处理器分工协作的三类基本语法要素。

    * 汇编指令：具有严格对应的机器码，是程序的核心组成部分，经编译后生成目标机器代码并由 CPU 硬件翻译执行（如 `MOV`、`ADD`、`SUB`、`JMP`）。

    * 伪指令：没有对应的物理机器码，CPU 硬件在运行期根本不执行伪指令；伪指令面向编译器，用于在编译阶段指导内存段分配、符号定义与数据类型组织。

    * 宏与辅助符号：包括标号、变量名以及加减乘除运算符等，没有机器码，由编译器在编译期解析并完成相对地址或常数偏移计算。

### 存储系统与容量单位

* **存储器架构与数据表示（Memory Architecture）**

    * > **定义**：用于存放计算机运行所需的指令与操作数的硬件存储阵列。

    * 内存储器与外存储器分工：中央处理器（CPU）只能直接访问内存储器（RAM/ROM）；外存储器（磁盘、SSD）中的程序与数据必须预先加载调入内存后，CPU 方能对其寻址执行。

    * 指令与数据的物理同一性：在物理存储器中，指令与数据在存储介质中完全相同，均表现为无差别的二进制电平序列；CPU 根据处理机运行周期加以区分：在取指周期（Fetch）从内存取出的内容一律解释为指令，在执行周期（Execute）按地址访问读写的内容一律解释为数据。

    * 存储单元与编址规则：内存按字节（Byte）统一划分物理存储单元，每个单元拥有从 0 开始递增的唯一物理地址编号；每个存储单元固定存放 1 个字节（8 个二进制位 bit）。

    * 容量单位进位梯次：计算机存储容量遵循严格的 1024（$2^{10}$）阶梯倍率换算：
      $$1\text{ TB} = 1024\text{ GB}$$
      $$1\text{ GB} = 1024\text{ MB}$$
      $$1\text{ MB} = 1024\text{ KB}$$
      $$1\text{ KB} = 1024\text{ Byte}$$
      $$1\text{ Byte} = 8\text{ bit}$$

### 系统总线分类与协同机制

* **系统总线（System Bus）**

    * > **定义**：微型计算机系统中连接 CPU、存储器与各类外围接口芯片并用于传递信息的一组公用导线通道集合。

    * 地址总线（Address Bus，AB）：单向传输总线，信号方向始终由 CPU 发出指向存储器或 I/O 接口；用于传递存储单元或端口的二进制物理地址编码。

    * 寻址空间极限公式：地址总线的物理线数（宽度）$N$ 直接决定 CPU 的物理寻址范围，系统最大可寻址空间为 $2^N$ 个字节存储单元。

    * 控制总线（Control Bus，CB）：由一组专用的时序控制与状态反馈信号线构成的总线集合；CPU 借助控制总线向存储器或 I/O 发出内存读（MEMR）、内存写（MEMW）、中断响应等脉冲命令，整体表现为双向协同。

    * 数据总线（Data Bus，DB）：双向传输总线，用于在 CPU 与存储单元或外设端口之间双向高速吞吐实际数据与指令代码。

    * 访存三步协同机理：CPU 完成一次完整的内存读写操作严格经历“AB 选址定位 $\rightarrow$ CB 发出读写命令 $\rightarrow$ DB 传输数据”三步时序联动。

    ```text
    +-------------------------------------------------------------+
    | 8086 微机系统访存三总线拓扑协同时序                         |
    |                                                             |
    |   +---------------+                       +---------------+ |
    |   |               |====== 地址总线 (AB) ==>| 存储单元定位  | |
    |   |               |   (单向: 传输物理地址) | (选定唯一单元)| |
    |   |  8086 CPU     |                       | 内存存储矩阵  | |
    |   |               |------ 控制总线 (CB) ->| 读写控制命令  | |
    |   | 控制与执行逻辑|   (发出 MEMR / MEMW)  | (使能读写引脚)| |
    |   |               |                       |               | |
    |   |               |<==== 数据总线 (DB) ===>| 数据双向传输  | |
    |   |               |   (双向: 读出或写入)  | (8位/16位吞吐)| |
    |   +---------------+                       +---------------+ |
    +-------------------------------------------------------------+
    ```

### 处理器外部数据总线规格

* **8086 与 8088 硬件总线规格对比（Bus Width Comparison）**

    * 内部运算与寄存器规格：8086 与 8088 处理器的内部算术逻辑单元（ALU）、通用寄存器与内部数据通路物理位宽完全一致，均为 16 位。

    * 外部地址总线规格：8086 与 8088 处理器的外部地址总线均为 20 根，物理寻址能力均为 $2^{20}\text{ Byte} = 1\text{ MB}$。

    * 外部数据总线规格差异：8086 拥有 16 根外部数据总线（真 16 位微处理器），单次总线周期可直接并行吞吐 16 位（1 个字/2 字节）数据；8088 仅拥有 8 根外部数据总线（准 16 位微处理器），单次总线周期只能吞吐 8 位（1 个字节）数据。

    * 字数据传输时序对比：向内存写入 16 位数据（如 `89D8H`）时，8086 仅需 1 个总线读写周期即可整字送出；8088 必须分两个周期执行，首个周期传输低 8 位字节（`D8H`），次个周期传输高 8 位字节（`89H`）。

| 处理器型号 | 内部寄存器位宽 | 内部 ALU 位宽 | 外部地址总线位宽 | 外部数据总线位宽 | 物理寻址空间 | 架构属性 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **Intel 8086** | 16 位 | 16 位 | 20 位 | **16 位** | 1 MB | 真 16 位微处理器 |
| **Intel 8088** | 16 位 | 16 位 | 20 位 | **8 位** | 1 MB | 准 16 位微处理器 |

### 存储器芯片类型与统一逻辑地址空间

* **存储器件分类（Memory Device Classification）**

    * > **定义**：微机系统中依据半导体工作特性与物理读写权限划分的存储芯片阵列。

    * 随机存取存储器（Random Access Memory，RAM）：支持随机读出与写入操作；具有易失性（Volatile），断电后内部存储的信息立刻全部丢失；在微机中用于充当系统主内存条与显示适配器显存（VRAM）。

    * 只读存储器（Read-Only Memory，ROM）：在正常系统工作状态下只能读出不可写入；具有非易失性（Non-Volatile），系统断电后内部固化数据永久保存；用于固化主板系统引导程序（BIOS）及扩展接口卡固件。

    * 接口卡（Interface Card）：微机主板通过显卡、声卡、网卡等接口部件实现 CPU 与各类物理外设之间的电气隔离、驱动增强与协议中继。

* **8086 统一逻辑地址空间（Logical Address Space）**

    * > **定义**：CPU 将分布于主板、接口卡上的不同物理存储介质统一抽象并编址形成的单一线性连续空间。

    * 编址范围：8086 的 20 根地址线对应 `00000H ~ FFFFFH` 连续的 1MB 逻辑空间。

    * 主存 RAM 空间：`00000H ~ 9FFFFH`（共 640 KB），分配给系统常规物理内存，用于加载操作系统核心模块与用户汇编应用程序。

    * 显存 VRAM 空间：`A0000H ~ BFFFFH`（共 128 KB），映射给显示适配器的视频存储器，直接向该空间地址写入字符或像素数据即可驱动显示屏显示。

    * 固件 ROM 空间：`C0000H ~ FFFFFH`（共 256 KB），分配给各类外设接口扩展卡 ROM 以及主板 BIOS ROM，供微机冷启动自检与系统初始化引导。

## 8086 寄存器阵列与指令指针协同

### 8086 处理器内部规格

* **16 位微处理器结构（16-Bit Microprocessor）**

    * > **定义**：内部数据处理通路、运算部件及主要寄存器均以 16 位二进制字长为基本规格的微处理器架构。

    * 处理能力：内部算术逻辑单元（ALU）单次能够直接完成 16 位二进制数的加、减、逻辑及移位操作。

    * 寄存器位宽：处理器内部的核心寄存器最大物理宽度均为 16 位。

    * 内部通路：寄存器组之间、寄存器与内部运算器之间的内部总线宽度均为 16 位。

    * 寄存器功能本质：寄存器是 CPU 芯片内部存取延迟最低的高速存储单元，用于暂存参与当前运算的操作数、中间结果或内存地址指针。

### 内部寄存器体系分类

* **8086 寄存器阵列（8086 Register Set）**

    * > **定义**：8086 处理器内部集成的 14 个专用及通用 16 位寄存器集合。

    * 通用数据寄存器（4 个）：`AX`、`BX`、`CX`、`DX`，用于暂存常规数据及运算结果。

    * 指针寄存器（2 个）：均以字母 `P`（Pointer）结尾，包含堆栈指针寄存器 `SP`（Stack Pointer）和基址指针寄存器 `BP`（Base Pointer）。

    * 变址寄存器（2 个）：均以字母 `I`（Index）结尾，包含源变址寄存器 `SI`（Source Index）和目的变址寄存器 `DI`（Destination Index）。

    * 控制与状态寄存器（2 个）：指令指针寄存器 `IP`（Instruction Pointer，存放下一条待执行指令的偏移地址）以及标志寄存器 `FLAG`（又称程序状态字 PSW，记录算术逻辑运算的状态与控制标志位）。

    * 段寄存器（4 个）：均以字母 `S`（Segment）结尾，包含代码段寄存器 `CS`（Code Segment）、数据段寄存器 `DS`（Data Segment）、堆栈段寄存器 `SS`（Stack Segment）和附加段寄存器 `ES`（Extra Segment）。

| 寄存器分类 | 寄存器名称 | 物理位宽 | 独立拆分能力 | 助记渊源与核心职能 |
| :--- | :--- | :--- | :--- | :--- |
| **通用数据寄存器** | `AX`, `BX`, `CX`, `DX` | 16 位 | 各可独立拆分为 `H`（高8位）与 `L`（低8位） | 累加器(Accumulator)、基址(Base)、计数(Count)、数据(Data) |
| **指针寄存器** | `SP`, `BP` | 16 位 | 不可拆分 | 栈指针(Stack Pointer)、基址指针(Base Pointer) |
| **变址寄存器** | `SI`, `DI` | 16 位 | 不可拆分 | 源变址(Source Index)、目的变址(Destination Index) |
| **控制与状态寄存器**| `IP`, `FLAG` | 16 位 | 不可拆分 | 指令指针(Instruction Pointer)、状态标志字(PSW) |
| **段寄存器** | `CS`, `DS`, `SS`, `ES` | 16 位 | 不可拆分 | 代码段(Code)、数据段(Data)、堆栈段(Stack)、附加段(Extra) |

### 寄存器拆分与数据单位映射

* **寄存器拆分与字字节映射（Register Splitting & Word Mapping）**

    * > **定义**：16 位通用寄存器物理位映射为两个独立 8 位寄存器的硬件解耦机制。

    * 独立拆分特性：4 个通用数据寄存器 `AX`、`BX`、`CX`、`DX` 各自可以拆解为两个完全互不干扰的 8 位寄存器使用；对高 8 位寄存器的读写不会影响低 8 位，反之亦然。

    * 高低位字节分布：高 8 位由 `AH`、`BH`、`CH`、`DH` 映射，占用 Bit 15 ~ Bit 8；低 8 位由 `AL`、`BL`、`CL`、`DL` 映射，占用 Bit 7 ~ Bit 0。

    * 度量基准：1 个字节（Byte）由 8 位二进制构成；1 个字（Word）由 2 个字节（16 位二进制）构成。

    * 十六进制数据映射实例：十六进制数每 2 个字符精确对应 1 个字节；当将十六进制常数 `4E20H` 送入 `AX` 时，高字节 `4EH` 存入 `AH`（对应二进制 `01001110B`），低字节 `20H` 存入 `AL`（对应二进制 `00100000B`）。

### 基础数据传送与算术指令

* **基础微指令语法（Basic Machine Instructions）**

    * `MOV`（数据传送指令）：语法格式为 `MOV 目的操作数, 源操作数`，用于将源操作数复制传送至目的操作数中，原内容被覆盖（如 `MOV AX, 8`）。

    * `ADD`（加法指令）：语法格式为 `ADD 目的操作数, 源操作数`，将目的操作数与源操作数相加，运算和写回目的操作数中（如 `ADD AX, 8` 使 `AX` 累加 8）。

    * `SUB`（减法指令）：语法格式为 `SUB 目的操作数, 源操作数`，将目的操作数减去源操作数，运算差写回目的操作数中（如 `SUB AX, 8` 使 `AX` 递减 8）。

    * 符号大小写不敏感性：汇编源程序中指令助记符与寄存器标识符严格不区分大小写，`MOV AX, 8` 与 `mov ax, 8` 在编译后生成完全一致的机器码。

### 物理地址合成机理与段管理

* **地址加法器与物理地址生成（Address Adder & Physical Address）**

    * > **定义**：8086 总线接口部件（BIU）内用于将 16 位段地址与 16 位偏移地址合成为 20 位物理地址的专用硬件电路。

    * 硬件矛盾本质：8086 内部寄存器、运算器与内部总线均为 16 位规格，而外部地址总线为 20 位（需输出 20 位地址以覆盖 1MB 空间）。

    * 物理地址合成公式：
      $$\text{物理地址} = \text{段地址} \times 16 + \text{偏移地址}$$

    * 段地址乘 16 的数制本质：在十六进制表示下，乘以 16 等价于数值整体向左移动 1 位，并在最低位补一个十六进制的 `0`（在二进制下等价于左移 4 位）。

    ```text
    +-------------------------------------------------------------+
    | 8086 地址加法器 20 位物理地址合成硬件拓扑                   |
    |                                                             |
    |   16 位段寄存器 (如 CS)           16 位偏移指针 (如 IP)     |
    |         |                                 |                 |
    |         v                                 |                 |
    |   [左移 4 位 (×16)]                       |                 |
    |         |                                 |                 |
    |         v (20 位段基址)                   |                 |
    |         +------------->[ 地址加法器 ]<-----+                 |
    |                              |                              |
    |                              v                              |
    |                    [ 20 位物理地址输出 ]                    |
    |                              |                              |
    |                              v                              |
    |                     20 根外部地址总线引脚                   |
    +-------------------------------------------------------------+
    ```

### 内存分段机制与段边界规律

* **逻辑分段（Memory Segmentation）**

    * > **定义**：CPU 内部通过“段基址 + 偏移量”寻址模式对平坦物理内存进行的逻辑划分管理机制。

    * 物理内存平坦性：物理内存本身是一整片连续线性的字节存储空间，硬件上不存在物理隔板；分段完全源于 CPU 内部地址加法器的分段计算逻辑。

    * 单个逻辑段最大容量上限：段内单元寻址由 16 位偏移地址提供，16 位二进制的地址状态总数为 $2^{16} = 65536$；以字节为寻址单元，单个逻辑段的最大物理容量恒定为 $2^{16}\text{ B} = 64\text{ KB}$。

    * 段空间大小计算公式：已知段起始与终止物理地址，其物理长度计算公式为：
      $$\text{段长度} = \text{终止物理地址} - \text{起始物理地址} + 1$$

    * 物理地址反推段基址公式：当逻辑段起始偏移地址为 `0000H` 时，起始物理地址直接除以 16（在十六进制下向右移 1 位抹去末尾 `0`）即可反推得到段基地址：
      $$\text{段地址} = \frac{\text{起始物理地址}}{16}$$

### 代码段寄存器 CS 与指令指针 IP 运行机理

* **CS:IP 协同执行机制（CS:IP Instruction Fetching）**

    * > **定义**：代码段寄存器 `CS` 与指令指针寄存器 `IP` 联合界定当前待抓取执行机器指令物理位置的协同运行机制。

    * 核心铁律：任何时刻，8086 CPU 均将 `CS:IP` 合成物理地址所指向的内存单元内容无条件解释为机器指令代码读取并执行。

    * 指令自动推进时序逻辑：
      1. 地址加法器将 `CS` 与 `IP` 合成 20 位物理地址并送上外部地址总线；
      2. 控制逻辑从目标内存单元读取指令字节送入指令预取队列缓冲；
      3. 一旦指令拾取完毕，微处理器硬件自动更新 `IP` 的数值，其自增步长严格等于当前刚被读取指令所占用的字节长度：
         $$\text{IP}_{\text{新}} = \text{IP}_{\text{旧}} + \text{当前读取指令的字节长度}$$
      4. 执行部件执行队列中的指令机器码，若引起运算结果更新则写入目标寄存器。

### 转移指令 JMP 对执行流的控制

* **控制转移指令（Control Transfer Instruction, JMP）**

    * > **定义**：通过修改代码段寄存器 `CS` 与指令指针 `IP` 从而强制改变指令拾取与执行流程的汇编指令。

    * 段寄存器语法禁忌：8086 严禁使用普通数据传送指令 `MOV` 对 `CS` 或 `IP` 进行直接写入（`MOV CS, 2000H` 或 `MOV IP, 0000H` 均为非法机器语法）。

    * 段间远转移机理：语法格式为 `JMP 段地址:偏移地址`（例如 `JMP 2AE3H:0003H`）；执行后微处理器同时修改 `CS` 与 `IP`，段地址写入 `CS`，偏移地址写入 `IP`。

    * 段内近转移机理：语法格式为 `JMP 通用寄存器`（例如 `JMP AX`）；执行后仅将通用寄存器中的 16 位数值写入 `IP`，而代码段寄存器 `CS` 保持原值绝对不变。

## 数据段寻址、小端存储与堆栈运行机理

### 数据段寄存器 DS 与段寄存器传送规则

* **数据段寄存器（Data Segment Register, DS）**

    * > **定义**：指示数据存储段基准地址并为内存操作数寻址提供段基值的段寄存器。

    * 数据访问默认基地址：汇编指令中使用 `[...]` 寻址内存操作数时，若无段超越前缀，硬件默认使用 `DS` 提供段基准地址。

    * 立即数写入段寄存器禁忌：8086 硬件内部未铺设将立即数直接写入段寄存器的机器译码与数据通路，指令 `MOV DS, 1000H` 在语法与硬件级别均属非法。

    * 段寄存器初始化中转规范：对 `DS`（以及 `SS`、`ES`）赋值时，必须先将段基址传送至通用寄存器（通常使用 `AX` 或 `BX`），再由通用寄存器中转传送至段寄存器：
      ```assembly
      MOV BX, 1000H   ; 通用寄存器暂存段基址
      MOV DS, BX      ; 中转送入数据段寄存器
      ```

    * > **易错点**：⚠️ 严禁使用立即数对任何段寄存器直接执行 `MOV` 操作；必须且只能通过通用寄存器进行二级中转。

### 小端存储模式与内存字节分布

* **小端存储模式（Little-Endian）**

    * > **定义**：多字节数据在连续内存物理存储单元中低位字节占据低地址、高位字节占据高地址的硬件存放规则。

    * 排布口诀：高高低低，低对低高对高。

    * 字单元连续分配机制：一个 16 位字数据在内存中跨越占用 2 个连续的字节单元；数据的低 8 位字节存放在较低的物理地址中，数据的高 8 位字节存放在紧随其后的较高物理地址中。

    * 字单元地址定义：任意一个字单元的物理地址，严格以该字数据所占据的两个连续内存单元中**较低的那个物理地址**作为该字单元的标识地址。

    ```text
    +-------------------------------------------------------------+
    | 8086 小端存储内存字节物理排布示意 (DS=1000H)                 |
    |                                                             |
    |   偏移地址     物理地址      存放内容       所属逻辑字      |
    |   +-------+   +---------+   +-------+                       |
    |   | 0003H |   | 10003H  |   |  11H  | <--- 1122H 之高字节   |
    |   +-------+   +---------+   +-------+                       |
    |   | 0002H |   | 10002H  |   |  22H  | <--- 1122H 之低字节   |
    |   +-------+   +---------+   +-------+                       |
    |   | 0001H |   | 10001H  |   |  11H  | <--- 1123H 之高字节   |
    |   +-------+   +---------+   +-------+                       |
    |   | 0000H |   | 10000H  |   |  23H  | <--- 1123H 之低字节   |
    |   +-------+   +---------+   +-------+                       |
    |                                                             |
    |   物理地址增长方向: 自底向上连续递增 (10000H -> 10003H)     |
    +-------------------------------------------------------------+
    ```

### MOV 指令合法操作数规范

* **MOV 指令操作数匹配规则（MOV Instruction Constraints）**

    * > **定义**：微处理器硬件指令集所支持的合法的源操作数与目的操作数寻址组合规范。

    * 四类合法传送模式：
      1. `MOV 寄存器, 立即数`：将常数送入通用寄存器；
      2. `MOV 寄存器, 寄存器`：在两个内部寄存器之间高速复制数据；
      3. `MOV 寄存器, 内存单元`：从内存指定有效地址读入寄存器；
      4. `MOV 内存单元, 寄存器`：将寄存器数值写入内存指定存储单元。

    * 硬件绝对禁忌：严禁在源操作数与目的操作数之间同时使用内存单元（微机系统不存在内存单元到内存单元的直接传送机器指令）；严禁将立即数直接传送给段寄存器。

### 堆栈结构特性与出入栈机理

* **堆栈（Stack）**

    * > **定义**：由处理器硬件直接支持、在逻辑上遵循先进后出（FILO / LIFO）规则的连续内存数据缓冲区域。

    * 栈顶操作集中性：堆栈的所有压入与弹出操作，必须且只能在当前的**栈顶**位置进行；最先存入的数据必定最后被读出，最后存入的数据必定最先被弹出。

    * 段基址与指针分工：堆栈段基地址由堆栈段寄存器 `SS`（Stack Segment）锁定，当前栈顶单元的偏移地址由堆栈指针寄存器 `SP`（Stack Pointer）动态跟踪；在任何时刻，`SS:SP` 合成的 20 位物理地址始终精准指向当前栈顶单元的最高有效字节。

    * > **易错点**：⚠️ 堆栈操作指令 `PUSH` 与 `POP` 在执行全过程中，**仅仅动态修改堆栈指针 SP 的数值，绝对不会改变堆栈段寄存器 SS**。

    * 硬件操作字长硬约束：8086 硬件架构规定堆栈指令 `PUSH` 与 `POP` **必须且只能以字（Word，16 位，2 字节）为基本单位进行**；处理器不存在针对 8 位单字节寄存器的直接压栈指令（`PUSH AL` 属于非法指令）。

### 栈顶指针 SP 动态演变与边界判定

* **SP 增减时序与生长特性（Stack Pointer Operations）**

    * > **定义**：8086 采用高地址向低地址向下生长的倒水桶式堆栈指针递变时序机理。

    * 向下生长规律：8086 堆栈的栈底固定位于高物理地址端，随着数据的压入，栈顶向低物理地址方向不断延展推进。

    * 压栈指令（`PUSH`）执行时序：
      1. 指针预减移位：硬件首先使栈指针递减 2 个字节，即 $\text{SP} \leftarrow \text{SP} - 2$；
      2. 写入字数据：将源操作数中的 16 位字按小端规则写入新的 `SS:SP` 指向的内存字单元。

    * 出栈指令（`POP`）执行时序：
      1. 读出字数据：首先从当前 `SS:SP` 指向的栈顶内存字单元中读出 16 位数据，送入目的操作数；
      2. 指针后回退：硬件使栈指针递增 2 个字节，即 $\text{SP} \leftarrow \text{SP} + 2$，栈顶向高物理地址回退收缩。

    ```text
    +-------------------------------------------------------------+
    | 8086 PUSH 与 POP 对 SP 栈指针的动态修改时序                 |
    |                                                             |
    |   高物理地址 (栈底)                                         |
    |       +---------------+                                     |
    |       |   [ 空闲区 ]  | <--- 栈空时的初始 SS:SP (栈底最高处) |
    |       +---------------+                                     |
    |       |   数据元素 1  |                                     |
    |       +---------------+                                     |
    |       |   数据元素 2  | <--- PUSH 前的旧栈顶                |
    |       +---------------+                                     |
    |       |   新入栈元素  | <--- PUSH AX 后: SP 先减 2, 指向此处 |
    |       +---------------+                                     |
    |   低物理地址 (向下生长)                                     |
    |                                                             |
    |   - 执行 PUSH AX: SP = SP - 2 (指针向低地址先推 2 字节)     |
    |   - 执行 POP AX:  SP = SP + 2 (指针向高地址后退 2 字节)     |
    +-------------------------------------------------------------+
    ```

    * 栈空初始指针设定：若分配的堆栈段空间偏移地址区间为 `0000H ~ 001FH`（总容量 32 字节），最高有效字单元起始偏移为 `001EH`；依据入栈“先减 2 后写”的机理，栈空初始化时 `SP` 必须被设定为最高单元的下一位置，即初始 $\text{SP} = 0020\text{H}$。

    * 堆栈平衡原则（Stack Balancing）：程序在执行过程中，压入堆栈的字数与弹出堆栈的字数必须严格保持相等；每次 `PUSH` 使 $\text{SP} - 2$，每次 `POP` 使 $\text{SP} + 2$，只有出入栈完全对称平衡，`SP` 才能无偏差复原至初始基准位置。

## 存储器分段寻址边界推算与极限分析模型

### 给定段地址推导物理寻址区间

* **正向分段寻址边界模型（Segment Range Deduction）**

    * > **定义**：已知固定段地址，依据 16 位偏移地址极值区间推导物理内存覆盖范围的计算方法。

    * 偏移地址取值界限：在 8086 系统中，偏移地址由 16 位寄存器提供，其十六进制取值区间严格限定为：
      $$0000\text{H} \le \text{偏移地址} \le \text{FFFFH}$$

    * 最小物理地址公式：偏移地址取下限极值 `0000H`：
      $$\text{物理地址}_{\min} = \text{段地址} \times 16 + 0000\text{H}$$

    * 最大物理地址公式：偏移地址取上限极值 `FFFFH`：
      $$\text{物理地址}_{\max} = \text{段地址} \times 16 + \text{FFFFH}$$

    * 推导演练实例（以段地址 `0001H` 为例）：
      1. 计算 20 位段基址：$0001\text{H} \times 16 = 00010\text{H}$；
      2. 寻址下限：$00010\text{H} + 0000\text{H} = 00010\text{H}$；
      3. 寻址上限计算（列十六进制竖式，遵循逢 16 进 1）：
         ```text
             0 0 0 1 0 H
           +   F F F F H
           -------------
             1 0 0 0 F H
         ```
         最低位 $0 + \text{F} = \text{F}$；第 1 位 $1 + 15 = 16$，本位写 `0` 向高位进 `1`；后续高位连续进位，最终获得最大物理地址为 `1000FH`。
      4. 结论：段地址 `0001H` 所能覆盖的连续物理地址区间为 `00010H ~ 1000FH`。

### 给定物理地址反推有效段地址极限

* **逆向段基址极值求解模型（Inverse Segment Limit Analysis）**

    * > **定义**：已知目标物理存储单元地址，推导能够通过 16 位偏移寻址触达该单元的合法段地址闭区间的数学模型。

    * 反推方程建立：根据物理地址合成公式 $\text{物理地址} = \text{段地址} \times 16 + \text{偏移地址}$，反解出段基址：
      $$\text{段地址} = \frac{\text{物理地址} - \text{偏移地址}}{16}$$

    * 最大段地址求解（$\text{段地址}_{\max}$）：减去的偏移量必须取理论极小值 `0000H`：
      $$\text{段地址}_{\max} = \frac{\text{物理地址} - 0000\text{H}}{16} = \frac{\text{物理地址}}{16}$$
      在十六进制表示下，相当于直接抹去物理地址末尾的一个十六进制 `0`。

    * 超出上限不可达性：若段地址大于 $\text{段地址}_{\max}$，其起始基地址本身就已经超过了目标物理地址；由于偏移地址不能为负数，CPU 绝对无法向低地址回退寻址。

    * 最小段地址求解（$\text{段地址}_{\min}$）：减去的偏移量必须达到物理极限最大值 `FFFFH`：
      $$\text{段地址}_{\min} = \left\lceil \frac{\text{物理地址} - \text{FFFFH}}{16} \right\rceil$$

    * 向上进位截断机理：当 $(\text{物理地址} - \text{FFFFH})$ 除以 16 产生非零余数时，商值必须无条件向上进位加 1；若直接截断余数取商值，该段基址加上最大偏移量 `FFFFH` 后依然会落后于目标单元（至少差 1 个字节），导致目标单元脱出寻址范围。

    * 经典实例极限推导（以目标物理地址 `20000H` 为例）：
      1. 求解最大段地址：$\text{段地址}_{\max} = 20000\text{H} \div 16 = 2000\text{H}$；若取 `2001H`，基地址达 `20010H > 20000H`，不可达。
      2. 求解最小段地址分子：$20000\text{H} - \text{FFFFH} = 10001\text{H}$；
      3. 除基取商与余数：$10001\text{H} \div 16 = 1000\text{H} \dots\dots \text{余数 } 1\text{H}$；
      4. 进位验证：若取段地址为 `1000H`，其所能触达的最大物理地址为 $10000\text{H} + \text{FFFFH} = 1\text{FFFFH} < 20000\text{H}$，无法覆盖目标地址；因此段地址必须向上进 1 取 `1001H`；
      5. 结论：能够寻址到物理地址 `20000H` 的段地址合法闭区间为 $[1001\text{H}, 2000\text{H}]$；段地址低于 `1001H` 或高于 `2000H` 时均不可寻址。

### 堆栈程序执行追踪与寄存器数据置换

* **堆栈数据流动与置换模型（Stack Flow & Data Swapping）**

    * > **定义**：利用堆栈后进先出特性实现寄存器状态保存、数据逆序与变量无辅助空间置换的运行模型。

    * 颠倒效应与值互换机理：连续压入一组数据后按原入栈顺序反向执行出栈，出栈数据序列将呈现完全逆序；利用该机理可直接实现寄存器内容互换而无需开辟中间临时变量。

    * 执行过程全景追踪示例：
      设初始堆栈段已建立，初始 $\text{SP} = 0064\text{H}$；执行下列程序片段：
      ```assembly
      MOV AX, 0001H   ; AX 写入初始值 0001H
      MOV BX, 0002H   ; BX 写入初始值 0002H
      PUSH AX         ; AX 压栈: SP 先减 2 (SP=0062H), 写入 0001H
      PUSH BX         ; BX 压栈: SP 先减 2 (SP=0060H), 写入 0002H
      POP AX          ; 弹出栈顶 0002H 写入 AX, SP 后增 2 (SP=0062H)
      POP BX          ; 弹出栈顶 0001H 写入 BX, SP 后增 2 (SP=0064H)
      ```

    * 终态结果分析：
      1. 寄存器状态：执行完毕后，$\text{AX} = 0002\text{H}$，$\text{BX} = 0001\text{H}$，两个通用寄存器中的数据成功完成互换；
      2. 栈指针状态：程序经历了 2 次入栈（累计 $\text{SP} - 4$）与 2 次出栈（累计 $\text{SP} + 4$），最终 $\text{SP}$ 恢复为初始基准值 `0064H`，满足堆栈平衡原则。
