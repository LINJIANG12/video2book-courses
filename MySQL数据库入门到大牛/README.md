# MySQL：数据库入门到大牛（199 讲）

一门覆盖面极宽的关系型数据库长课：从「为什么要有数据库」和 MySQL 的双版本安装讲起，一路走到 SQL 全语法体系、数据类型与约束、视图与存储程序、Linux 部署与字符集，再进入高级特性——存储引擎、B+ 树索引、InnoDB 页结构、索引与查询优化、范式与库表设计，最后收在事务与 Redo/Undo 日志、锁与 MVCC、日志体系与主从复制、备份恢复与数据迁移。全 199 集，是目前收录课程里唯一把「会用」到「懂原理」再到「能运维」串成一条线的课。

- **原视频**：[MySQL数据库入门到大牛，mysql安装到优化](https://www.bilibili.com/video/BV1iq4y1u7vj) — Bilibili，BV1iq4y1u7vj
- **全 199 集**，已产出 22 册模块全书、13 篇复习笔记、199 份逐字稿

## 怎么学

这门课**前半段靠敲、后半段靠悟**：SQL 语法与函数部分只有动手写才会有手感，索引与事务部分则要顺着「为什么需要它」的推演走一遍，否则记住的只是结论。

- **跟着课程顺序读** → `textbooks/` 的 22 册就是讲课顺序。模块 01~11 属于基础篇，模块 12 起进入高级特性篇，两段之间的节奏差别很大
- **语法要动手** → 模块 03~07 是 SQL 主体（单表查询、七表连接、单行函数、聚合分组与子查询、DDL 与 DML），建议对着本地库把每条语句跑一遍
- **原理要顺着推** → 模块 14~17 从「单页检索为什么慢」推到 B+ 树分层，再落到索引失效的各类场景，这一串不建议跳读
- **运维与架构** → 模块 12、13、21、22 涉及 Linux 部署、权限、日志体系、主从复制与备份恢复，偏运维视角
- **考前速查** → `notes/` 的 13 篇按「基础 / SQL / 对象与编程 / 部署 / 存储引擎 / 索引 / 设计 / 事务 / 锁 / 日志」聚合，粒度比模块全书小
- **核对原话** → `subtitles/` 有全部 199 份逐字稿，适合检索课程里提过的具体参数名或报错信息
