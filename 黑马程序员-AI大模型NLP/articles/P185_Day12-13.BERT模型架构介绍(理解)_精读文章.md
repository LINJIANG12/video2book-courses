# BERT 架构剖析：输入表示、双向编码器与四类下游任务

上一讲看图的时候说到 BERT 最下方那一层，还记得是什么吗？是词嵌入。这一讲就把这张图从上到下、从下到上彻底过一遍：输入是拼出来的，编码器是借来的，输出是靠微调层接活的。

要把这张图看明白，记住一个方向：**从上往下读输入，从下往上读结构**。input 那一行是要处理的文本，中间是三层 embedding 相加，再往上是双向 Transformer，最上面是模型微调。

## 1 输入层的特殊符号与三段嵌入

输入那一行大家都在看，`CLS`、`my dog is ...`、`he likes playing ...`。这跟我们之前做的中文案例是同一套做法。

先认两个符号：

- `CLS` 代表开头，这个位置是给整句话留的；
- `SEP` 代表结束，用来切分句子边界。

> **提示**：`CLS` 和 `SEP` 不是普通词，它们是占位的特殊标记（special token）。`CLS` 挂在整句开头，`SEP` 标出句子的结束，这两个位置在后边的下游任务里会经常被用到。

再来看中间标出来的三个嵌入。这三个才是这一节真正要记的东西：

| 嵌入名称 | 英文 | 作用 |
| --- | --- | --- |
| 词嵌入向量 | Token Embedding | 把词本身变成向量 |
| 句子分段嵌入向量 | Segment Embedding | 标记这个词属于哪一句 |
| 位置编码向量 | Position Embedding | 告诉模型谁先谁后 |

`Token Embedding` 这个东西，说白了就是我们讲 Transformer 时候的词嵌入向量，负责处理开头的输入文本内容。

`Segment Embedding` 叫句子分段。它是干什么的？大家记不记得我们有个 `token_type_id` 那一堆 0、1？就是干这个用的：一句标 0，另一句标 1，用来区分句子划分。你看，一串 `111111` 好，这是一个句子；换一串 `bbbbb`，好，这是第二个句子。两句话进来的时候，模型得知道哪个词属于哪一句，靠的就是它。

`Position Embedding` 就是位置编码向量，这个不用多解释。还是那句话：我们现在用的是正弦余弦。但后边你学大模型的时候，有些模型已经不用这套了，可能会用一个叫**旋转位置编码**的东西——旋转就是转圈那个意思。

> **提示**：旋转位置编码是个值得提前留意的话题，阿里系列、DeepSeek 系列的底层可能就会用它来替代正弦余弦那一套。这也是一个面试题，会让你说说对旋转位置编码的理解；你也可以直接问大模型：正弦余弦位置编码表示法和旋转位置编码表示法之间的区别是什么。大概率暂时看不懂，下下个阶段会细讲。

## 2 三段嵌入之和

现在记一句话：**输入嵌入（Input Embedding）是 Token Embedding、Segment Embedding 和 Position Embedding 之和。**

念一下最后两个字——**之和**。之和是什么意思？就是把这仨加起来。

以前讲位置编码的时候没讲过这么细，只是告诉你位置编码是算出来的；现在看就更具体了：词嵌入向量、句子分段向量、位置编码向量三个加起来，就是最终送进编码器的输入表示。

```text
        CLS   my   dog   is   hairy   SEP   he   likes  playing  SEP
         |     |     |     |     |     |     |     |      |       |
         v     v     v     v     v     v     v     v      v       v
      +---------------------------------------------------------------+
      | Token Embedding      （词本身的向量）                          |
      +---------------------------------------------------------------+
      | Segment Embedding    （标记属于第几句：A 句 / B 句）             |
      +---------------------------------------------------------------+
      | Position Embedding   （标记位置先后，正弦余弦算出）              |
      +---------------------------------------------------------------+
                  |            |            |
                  +------------+------------+
                               v
                  三者逐元素相加，得到输入嵌入
                               v
                        送入双向 Transformer
```

读图说明：三段嵌入的维度一致，所以可以逐元素相加；相加之后得到的那一个向量，才是真正喂给 Transformer 的输入。

这一层其实没什么特别多好聊的，但你必须会。感兴趣的话花点时间瞅瞅就行，没什么难度。

## 3 双向 Transformer 与只借编码器

再往上是三个主要模块里的第二个：双向 Transformer。

拿 BERT 来讲，"双向"刚才说过了，它可以往左走，也可以往右走。

看那个大框：BERT 使用的是哪一侧？编码器那一侧。也就是说 BERT 这个模型使用编码器，解码器那块儿它连动都没动。

> **结论**：BERT 只用了 Transformer 的编码器，解码器整块没有参与。这一点是 BERT 与 GPT 分道扬镳的地方。

## 4 四类下游任务

正因为结构是"双向编码器 + 微调层"，BERT 接下来可以接四类任务。这四项任务的英文先过一遍，考验英语的时候到了：

| 任务 | 中文 | 我们做过的对应案例 |
| --- | --- | --- |
| Sentence pair classification task | 句子对分类任务 | 判断两个句子的关系 |
| Single sentence classification task | 单句分类任务 | 情感分类 |
| Question answering task | 问答任务 | 阅读理解 |
| Single sentence tagging task | 单句标注任务 | 命名实体识别（NER） |

第一个 `sentence pair classification task`：sentence 是句子，pair 是对儿，classification 是分类，task 是任务——句子对分类任务。它做什么？输入两个句子，判断两个句子的关系。关系有哪些？比如是否认识、蕴含、中性；再具体一点，第一是矛不矛盾，第二是两个句子像不像。这些事都可以做。

第二个 `single sentence classification`：单句分类任务。比如我们之前做的情感分类——句子是好评还是差评，就归到这一类。

第三个 `Question Answering task`：问答任务。顾名思义做问答，也就是我们之前讲的阅读理解那一堆。

第四个 `single sentence tagging`：单句标注任务。这个单词不认识就去搜。它能干什么？比如我们之前做的 NER，命名实体识别，去识别里面到底谁是谁。

现在看图 A 到图 D 分别对应什么：图 A 输入两个句子判断两个句子的关系，就是分类；图 B 做的是情感分类；图 C 做的是阅读理解，也就是问答；图 D 做的是分词/标注。这张图把"底层谁干活、上层谁干活"的关系标得很清楚。

那从这里能发现什么？面对特定任务，只需要对哪一层进行微调？

> **结论**：只需对最上面的预微调层做微调。因为这几个任务下边那一层动作基本上都差不多，只有上边那一层不太一样。Transformer 强大的注意力机制可以模拟很多下游任务，所以我们换任务的时候真正改动的只是顶上那一小块。

## 5 三个主要模块回顾

到这儿，BERT 的三个主要模块就都过完了，再说一遍是谁：

1. 词嵌入（Embedding）——输入表示，三段嵌入相加；
2. 双向 Transformer——中间那堆编码器；
3. 模型微调——顶上那层绿色的，完成指定任务。

这三个动作是这一讲的主干。接下来就该聊预训练了，那是下一个话题。
