# 全球人名分类案例：RNN 模型的测试流程与维度推导

RNN 模型刚搭完，先别急着写训练代码。我们得给它做一次简单的测试，看看相关的东西对不对。整件事实操起来非常简单，就两个动作：第一个，把模型实例化；第二个，准备一份数据喂进去。中间还有输出形状的来回推导，那才是最值得看的地方。

先说数据。这次我准备的是 `(6, 57)`，而之前举例一直用的是 `(4, 57)`——我一直拿"丁"给大家举例，丁这个字长度是 4。那 6 是哪个姓？张是五个字，不太对。6 的话，欧阳，诶对，复姓。"欧阳"正好六个字符。

> **提示**：`(6, 57)` 这个 6 是**人名长度**，57 是**词向量维度**（52 个字母加 5 个符号）。

## 1. 实例化模型并打印结构

来到 7.1 这个位置，先定义测试函数。

第一步必然是实例化。你想测谁？测上面那个 `MyRNN`，所以先创建对象：

```python
def dm_test_my_rnn():
    # 1. 实例化 rnn 对象
    my_rnn = MyRNN(input_size=57, hidden_size=128, output_size=18, n_layers=1)
```

参数怎么传？一个个来。

- `input_size`：词向量维度。你们说填几？56？不对。是 **57**——52 个字母加 5 个符号，一直是 57；
- `hidden_size`：隐藏层维度，**128**。这个可以随便写，值越大意味着记的东西越多。课件上写的是 128，那我们写 128；你想改 256，记得后面都跟着改一下；
- `output_size`：**18**，对应 18 个国家；
- `n_layers`：**1**，跟前面默认值一致。

有人会说，实在不会就把那张图拉出来对着填。但我想说一句：不想每次写代码都把图拉一遍，好像搞得我看不清你似的。这几张图里的参数，你现在在脑子里该记住了。你该记还是要记的。

```python
    # 2. 打印模型结构，确认各层维度
    print(my_rnn)
```

把它打出来看一眼。你会看到三块：

```text
MyRNN(
  (rnn): RNN(57, 128)            输入 57 维词向量 → 128 维隐藏状态
  (linear): Linear(128, 18)      隐藏状态 128 维 → 18 个国家
  (softmax): LogSoftmax(dim=-1)  把 18 个分数变换成对数概率分布
)
```

这三行就是模型的骨架：RNN 层负责把 57 维的词向量滚成 128 维的隐藏状态，全连接层（输出层）把 128 维压成 18 个国家，最后是激活函数负责概率化。（"国家名"、"国家种类"那几行打印是之前数据准备阶段留下的信息，留着也行，不要就注释掉。）

## 2. 准备测试数据

第二个动作：准备测试数据，创建一个随机张量模拟输入。

```python
    # 3. 准备测试数据：创建随机张量模拟输入，形状为 (人名长度, 词向量维度)
    input = torch.randn(6, 57)
    print('输入的张量：', input)
    print('输入张量的形状：', input.shape)
```

为什么是 `(6, 57)`？因为这个 6 是**人名长度**，57 是**词向量维度**。丁的长度是 4，欧阳的长度是 6，这里拿欧阳举例就写 6。

有人要问：这个形状是你自己写死的吧？对，是我写死的——**测试阶段就随便扔一组数据进去，训练的时候才不写死**。打印 `input.shape`，你会看到它确实是 `(6, 57)`，内容长什么样不重要，爱谁谁。

> **易错点**：打印内容本身没有意义，随机数每次都不一样；这里真正要看的是 `shape`，因为形状决定了后面能不能喂进模型。

## 3. 初始化隐藏状态

第三个动作：初始化隐藏状态。

```python
    # 4. 初始化隐藏状态
    h0 = my_rnn.init_hidden()
```

正常来讲，这一行应该写成 `h0 = torch.zeros(1, 1, 128)`：一层、一个批次、128 维隐藏状态。但我们在 `MyRNN` 里面已经把这个操作封装过了，所以直接调 `my_rnn.init_hidden()`，**效果同上**。

你要是不想封装，就自己写 `torch.zeros(1, 1, 128)`，随你。封装的意义只是省得每次重复写这一段。

## 4. 一次性输入一个完整样本

第四个动作：把整个序列数据一次性喂进去。

```python
    # 5. 测试一次性输入一个完整的样本（序列数据）
    output, hn = my_rnn(input, h0)
```

到这一步，"是骡子是马拉出来遛遛"。接下来打印结果的时候，你得先猜一猜形状对应是多少——不是瞎蒙，这都有依据，就看你在脑子里有没有把这个弯转过来。

### 4.1 输出形状为什么不是 `(6, 1, 18)`

```python
    # 6. 打印结果
    print('输出的形状：', output.shape)
    print('输出的内容：', output)
```

`output` 是不是 `(6, 1, 18)`？是，`output` 记录的确实是 `(6, 1, 18)`。但**我们这里打印出来的不是它**，而是 `(1, 18)`。

为什么？因为人名的句子长度（那个 6）我们其实不需要——**只要最后一个就够**，最后一个记录的是前面所有的信息。

拿"欧阳"来说：它会有 6 个字符，O、U、Y、A、N、G。第一次把 O 送进去，得到一个隐藏状态；下一次循环把 U 怼进去，得到一个 Y；下次把 Y 扔进去，再往后……一步一步滚下去。最后一步把 G 送进来之后得到的那个隐藏状态，**记录的就是前面所有字符的信息**。

所以：

```text
output 的形状           (6, 1, 18)
                        └┬┘ └┬┘ └┬┘
                         │   │   └── 18 个国家上的分数
                         │   └────── batch 维（批次为 1）
                         └────────── 句子长度 6，对应 O U Y A N G 六个时间步

取 output[-1] 之后      (1, 18)
```

这张图说的是：`(6, 1, 18)` 里的 6 是六个时间步，一层层往后攒信息；取最后一个时间步之后，句子长度这一维消失，只剩下 `(1, 18)`——也就是"这份输入在这 18 个国家上的分数"。

> **结论**：模型内部已经把 `output[-1]` 取出来了，所以你在外面看到的 `output` 是 `(1, 18)`，不是 `(6, 1, 18)`。

### 4.2 隐藏状态形状为什么是 `(1, 1, 128)`

接着打印隐藏状态：

```python
    print('隐藏状态的形状：', hn.shape)
```

隐藏状态是 `(1, 1, 18)` 还是 `(1, 1, 128)`？看模型定义里写的是什么——答案是 **`(1, 1, 128)`**。一层、一个批次、128 维隐藏状态，跟 `init_hidden` 里 `torch.zeros(1, 1, 128)` 完全一致，跟前面那张图也一致。

### 4.3 `128` 变 `18` 的分界点

到这儿肯定有人要纠结：上面到处都是 `hidden_size`，凭啥到你这儿就变成 18 了？大家不都应该是 128 吗？

你说得对，就应该都是 128，你没说错。但你得记住一件事——**中间隔着一个全连接层**。

RNN 这一层处理完，输出的隐藏状态是 `(1, 128)`；`self.linear` 接收的是 `hidden_size`（128），吐出来的是 `output_size`（18）。所以底层流过来的是 128，经过全连接层的转换之后，结果就是 18。

```text
隐藏状态（RNN 层输出）      (1, 128)     128 维隐藏状态，本身不是类别
        |
        | self.linear   128 进、18 出
        v
输出（全连接层输出）        (1, 18)      18 个国家上的分数

而 hn 走的是另一条线，不经过全连接层：
hn                          (1, 1, 128)
```

这张图解释了那个"对不上号"的疑问：`hn` 不经过全连接层，所以保持 128；而 `output` 经过全连接层，所以被压成了 18。两者不冲突。

> **易错点**：`hidden_size` 是隐藏状态的宽度，`output_size` 是类别数。它们相等只是巧合，不相等才是常态；能不能对上号，看的是中间有没有那一层线性变换。

## 5. 从分数到国家：还差两步

现在 `output` 是 `(1, 18)`，它表示什么？表示当前这个输入（比如"欧阳"这个姓）在 18 个国家上的**概率分数**。

注意，这里还只是分数，因为**全连接层后面还有一层**——就是那个 `LogSoftmax`。我们以前写 RNN 从来没写过它，因为以前直接用 `CrossEntropyLoss`，Softmax 那一截是底层替你做的。

所以如果你要往下继续做，该干什么就能想到了：

1. 把这个张量再过一次 Softmax，得到的就不再是分数，而是**概率**；
2. 有了概率之后，怎么知道它属于哪个国家？用 `argmax` 找出最大概率对应的下标，那就是分类结果。

这两步在下面做训练的时候会写。就先聊到这儿。

## 6. 测试代码与实测结果

完整的测试代码：

```python
import torch

def dm_test_my_rnn():
    # 1. 实例化 rnn 对象
    my_rnn = MyRNN(input_size=57, hidden_size=128, output_size=18, n_layers=1)

    # 2. 打印模型结构，确认各层维度
    print(my_rnn)

    # 3. 准备测试数据：随机张量模拟输入，形状 (人名长度, 词向量维度)
    input = torch.randn(6, 57)
    print('输入的张量：', input)
    print('输入张量的形状：', input.shape)

    # 4. 初始化隐藏状态（等价于 torch.zeros(1, 1, 128)）
    h0 = my_rnn.init_hidden()

    # 5. 一次性输入一个完整的样本（序列数据）
    output, hn = my_rnn(input, h0)

    # 6. 打印结果
    print('输出的形状：', output.shape)
    print('输出的内容：', output)
    print('隐藏状态的形状：', hn.shape)
```

跑出来的结果是这样的：

```text
输入的张量形状：      torch.Size([6, 57])
输出的形状：          torch.Size([1, 18])
隐藏状态的形状：      torch.Size([1, 1, 128])
```

输入是一份 `(6, 57)` 的姓名数据；输出的形状是 `(1, 18)`——因为原来应该是 `(1, 128)`，经过全连接层处理之后被转成了 18；隐藏状态是 `(1, 1, 128)`，跟模型定义里那行 `torch.zeros` 写的完全一样，返不返回都是这个样子。

## 7. 那张反复出现的参数图

从我们开始学深度学习到现在，那张图一直在用。我的建议是：**在脑子里把它刻下来**，看清楚哪个参数是谁、谁是谁。这样你往下做案例就不会晕；要是记不住，做题的时候就各种懵——"谁是谁呀，谁是谁呀"，然后就说听不懂了。

所以传参的时候注意，这四个参数我是一个一个给你标过的：

| 参数 | 含义 | 本案例取值 | 在测试里的大小 |
| --- | --- | --- | --- |
| `input_size` | 词向量维度 | 57 | 对应 `input` 的最后一维 |
| `hidden_size` | 隐藏层维度 | 128 | 对应 `hn` 的最后一维 |
| `output_size` | 输出维度（国家数） | 18 | 对应 `output` 的最后一维 |
| `n_layers` | RNN 层数 | 1 | 对应 `hn` 的第一维 |
| `batch_size` | 批次大小 | 1 | 测试时固定为 1 |

到这里，RNN 搭建完毕、测试也走完一遍。这些维度之间的转换看清了，后面写训练就有底了。
