## RNN 内部结构：两个输入、两个输出

先看 RNN 的内部结构长什么样。

这张图上花花绿绿的一堆——黄色的、粉色的、各种箭头和圆点——第一次看确实容易懵。但先别管颜色，我们把图上最下面那段文字介绍读一遍：**每个时间步有两个输入，这两个输入会融合到一起，经过一系列运算，再得到输出**。这不就是我们之前一直在说的那个动作吗？

具体到符号：

- $x_t$ 代表**本次的输入**；
- $h_{t-1}$ 代表**上一时刻的隐藏状态**；

这两个输入进去，得到两样东西：

- $h_t$，**本次的隐藏状态**；
- 以及本次的输出。

> **定义**：RNN 的一个时间步，本质就是一个"二进二出"的运算单元——拿本时刻的输入 $x_t$ 和上一时刻的隐藏状态 $h_{t-1}$，算出本时刻的隐藏状态 $h_t$ 和本时刻的输出。

这里肯定有人要举手：本次的隐藏状态有了，那本次的输出呢？图上怎么没画出来？

别急，你回想一下我们前面讲过的分类：RNN 按照输入输出划分，是有 **N vs 1** 这一种的——输入 N 个，只输出一个。那我只要最后那一个 $y$ 是不是就够了？所以图上没有把每个时间步的输出都画出来，这不用纠结。

## 图例解读：五种符号各代表什么

把图放大之后，上面的符号得逐个认。一共五类，我一个个说。

### Neural Network Layer：神经网络层

`Neural Network Layer`。`Neural Network` 就是神经网络，`Layer` 就是层，所以这哥们儿叫**神经网络层**。图上它用黄色的圆角块表示。

### Pointwise Operation：逐点运算

`Pointwise Operation`。`Point` 是点，`wise` 是逐个的"逐"，合起来就是**逐点运算**。

那什么叫逐点运算？简单来讲，你就把它理解成点乘或者矩阵乘法，就是这种运算。

### Vector Transfer：向量传输

`Vector Transfer`。`Vector` 是向量，`Transfer` 是传输，所以它是**向量传输**，管的是数据从一个位置流到另一个位置。

### 连接与复制：合并和分裂

剩下两个动作符号是一对：

- 那个把两路数据并到一起的符号，叫**连接**，你可以理解为合并，把两个合成一个，二合一；
- `Copy` 就是**复制**，复制相当于一变二，一份数据分给两个地方用。

先把这张图的骨架画出来，你就知道这些符号各自待在什么位置了：

```text
                       输出序列 y_1        y_2              y_3
                          ^                ^                ^
                          |                |                |
         +--------+   +--------+       +--------+       +--------+
   x_1 ->| 连接   |-->| tanh   |--+--->| tanh   |--+--->| tanh   |--> ...
         +--------+   +--------+  |    +--------+  |    +--------+
              ^           ^       |        ^       |        ^
              |           |       |        |       |        |
             x_1        h_0 ------+       h_1 -----+       h_2
                     (Copy 分给下一时间步)

  图例：
    连接        两路输入合成一路（合并）
    tanh        激活函数所在的神经网络层
    箭头         向量传输（Vector Transfer）
    圆点/星号    逐点运算（Pointwise Operation）
    Copy         一路复制成两路
```

读图说明：每一个时间步里，本时刻输入 $x_t$ 与上一时刻隐藏状态 $h_{t-1}$ 先在"连接"处合并成一路向量，送进 tanh 神经网络层做一次运算，出来的就是本时刻的隐藏状态 $h_t$；$h_t$ 一方面向上成为本时刻的输出，另一方面被 Copy 复制一份，传给下一个时间步。

## 图上各变量的角色

把符号认全了，再回头认变量，一个一个对号入座。

$x_t$ 不用说，充当的是**本次的输入**。

$h_{t-1}$ 也不用说，它充当的是**上一时间步的隐藏状态**，你也可以叫上一时刻的隐藏状态，随你怎么叫，自己能看明白就行。

$h_t$ 呢？$h_t$ 就是**本次的隐藏状态**。

画面上中间那个 tanh，颜色是黄色的，黄色在我们的图例里代表神经网络层——所以它就是一个**激活函数神经网络层**。它的计算公式前面已经看过了，我们下面单独说它。

## 激活函数 tanh 与两个公式的差别

先讲流程。RNN 内部结构的运算顺序是这样的：上一时刻的隐藏状态 $h_{t-1}$ 和本次的输入 $x_t$，先经过一次**加权求和**，把结果送进 **tanh 激活函数**处理一下，然后继续往下传递就可以了。

> **结论**：RNN 内部结构 = 先加权求和，再做激活函数，增加非线性元素。

那 tanh 在这里的作用是什么？往上翻一页看激活函数的作用——**把一个值映射成一个非线性的结果**。所以激活函数的作用就是用来给模型增加非线性部分的。这一点记牢，后面讲 LSTM、GRU 的时候，门控里面用的还是这套东西。

好，接下来是个更容易被问到的点：工业界到底是怎么做的？

### 学术界论文里的写法

如果是学术界的论文，RNN 的论文里是这么写的：$x_t$ 和 $h_{t-1}$ **共用一个权重矩阵** $W$。

$$h_t = \tanh\left(W \cdot [h_{t-1},\ x_t]\right)$$

也就是先把 $h_{t-1}$ 和 $x_t$ 拼成一个长向量，再拿同一个 $W$ 去乘这一个拼接后的向量，最后过 tanh。一次乘法把两路输入一起算完，所以权重矩阵只有一个。

### 工业界框架底层的写法

但是在工业界，比如说 PyTorch 这种框架，它底层实现的时候是**各算各的**：你的输入 $x_t$ 有它自己的权重 $W_{xh}$，你的历史状态 $h_{t-1}$ 也有历史状态的权重 $W_{hh}$。

$$h_t = \tanh\left(W_{xh} x_t + W_{hh} h_{t-1} + b\right)$$

先把两路分开做加权求和，两个结果相加，外边再套一个激活函数。

这两种方式本质上是一样的，都是"先加权求和，外面加一个激活函数"，一模一样。你要非说区别，那还真有一个——**运算量的不同**。哪一个运算量更大？是 PyTorch 这种写法更大一些。

有人不服："你说是什么就是什么，我不信。"行，我让你心服口服。

打开 PyCharm，随便写一行：

```python
import torch.nn as nn
```

这什么意思？这不就是导入神经网络嘛。你的 RNN 是哪个 API，还记得吗？是 `nn.RNN`。

不用传参，按住 `Ctrl` 别松手，鼠标左键点进去看源码，往上扒拉到最上面。看着，屏幕上是不是 `class RNN`？是不是 RNN 这个类？然后你把它的 `maths` 念一遍——它底层的数学公式就在那儿。你会发现源码里的公式和讲义下面那个公式是一样的：先算的是 $x_t$，也就是本次输入；再来的那项是 $h_{t-1}$，也就是上一时刻的隐藏状态。

> **结论**：工业界用的是"两个权重矩阵各自乘、再加起来"的写法，论文里写的是"拼起来共用一个权重矩阵"的写法。两者严格来讲没什么区别，非要说区别，就是 PyTorch 那套写法的运算量要多一些，仅此而已。

所以讲义上的公式和底层实现的公式，不能说谁对谁错，只不过**参数量的多与少是核心**——这种底层运算的参数量，比论文里那套要稍微多一些。

### 参数形状怎么对得上

既然讲到了两套公式，顺手把矩阵的形状核对一遍，你才能真正看出"运算量多在哪"。

设输入维度（词向量维度）为 $d$、隐藏层维度为 $h$：

| 写法 | 权重参数 | 形状 | 参与乘法次数 |
| --- | --- | --- | --- |
| 论文写法 | $W$ | $(h,\ h+d)$ | 一次（向量长度 $h+d$） |
| PyTorch 写法 | $W_{xh}$ | $(h,\ d)$ | 一次（向量长度 $d$） |
| PyTorch 写法 | $W_{hh}$ | $(h,\ h)$ | 一次（向量长度 $h$） |

> **提示**：论文写法里那个 $(h,\ h+d)$ 的乘法，等价于把 $W_{hh}$ 与 $W_{xh}$ 并排成一个矩阵再乘一个拼接向量。分成两个矩阵之后，乘法的总元素数没有变少，但多了一路相加、多了一份偏置，框架还为此区分了两组参数，所以实际运算量与参数量都会略多一点。这就是"运算量更多"的来源。

## RNN 作为"层"该怎么调用

图上还有一个东西没写。把刚才的源码截图拉过来，把中间看不懂的那一堆删掉，只留一行：`class RNN`，`maths = ...`。这一行的意思就是——它是 **PyTorch 框架底层源码的计算公式**。

既然它是底层的计算公式，那就说明 `nn.RNN` 天生就替我们把刚说的那套加权求和 + 激活实现好了。所以我们不需要自己写那个 $\tanh$，直接拿它当**层**来用就行。

这一点从调用方式上能直接看出来。你要用 RNN，第一步是创建层对象：

```python
rnn = nn.RNN(输入维度, 隐藏层维度, 隐藏层层数)
```

这个 `rnn` 就是你创建出来的**层对象**；你后面调用的时候，用的就是这个对象，`rnn` 小括号里传参数。

那传什么参数？两个输入。把小写的 `rnn` 摆在这儿，把刚才图上的符号对号入座摆进去：

```text
   output ,  h_n  =  rnn (  x  ,  h_{t-1}  )
     |         |            |        |
     |         |            |        +-- 第二路输入：上一时间步的隐藏状态 h_{t-1}
     |         |            +----------- 第一路输入：本次的输入 x
     |         +------------------------ 第二路输出：本次的隐藏状态 h_t
     +---------------------------------- 第一路输出：本次的输出
```

读图说明：图上画的是数据流，落到代码里就是这一行调用；图上的两路输入（$x_t$ 与 $h_{t-1}$）对应括号里的两个实参，图上的两路输出（本次输出与本次隐藏状态）对应等号左边的两个返回值。
