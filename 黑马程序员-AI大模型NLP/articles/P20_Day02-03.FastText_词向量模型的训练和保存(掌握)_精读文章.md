# FastText 词向量模型的训练、日志解读与保存

环境搭好了，数据也拷进来了，现在就一件事：**让模型跑起来，并把训练结果存到硬盘上**。

这一讲干的就是四步流程里的第二步——训练和保存。写完之后你会发现，训练代码短得有点意外：一行就训完了。真正需要花心思的地方不在代码，而在训练过程中屏幕上刷出来的那一大堆日志。那些数字我看一眼就知道模型有没有学歪，你也得看得懂。

## 1 训练与保存的整体流程

先在脑子里排好顺序，这一讲的代码就是按这个顺序往下写的：

```text
  导入工具包      import fastText
        |
        v
  定义训练函数    demo01_train_save()
        |
        +--- fastText.train_unsupervised(数据路径)   无监督训练，参数全默认
        |            |
        |            v
        |        得到 my_model（内存中的模型对象）
        |
        +--- my_model.save_model(模型路径.bin)       保存为二进制文件
        |
        v
  主函数调用       if __name__ == '__main__': 里调用 demo01
```

读图说明：上半段是"训练"，下半段是"保存"，两步是分开的——`train_unsupervised` 返回的模型先存在于内存里，必须再显式调一次 `save_model` 才会在硬盘上留下 `.bin` 文件。

## 2 导包与第一个函数

切到 PyCharm，先导包：

```python
import fastText
```

就这一句，包名就是 `fastText`（注意首字母小写的 `f`、中间大写的 `T`，跟 `pip` 安装时写的 `fasttext` 大小写不一样，但都能装能导）。

接着按骨架填第一个函数。这个函数要干的事写在注释里很清楚：**定义函数实现训练词向量模型，并保存模型**。

## 3 无监督训练与最简调用

函数签名起名叫 `demo01_train_save`——训练和保存一体，名字就把职责说完了。

第一个动作：**以无监督的方式运行**。写法非常简单：

```python
import fastText


def demo01_train_save():
    # 直接开始训练，以无监督的方式运行
    my_model = fastText.train_unsupervised('./data/0502_ad')
    # 训练完直接保存模型
    my_model.save_model('./model/0502_fil9.bin')
    print('训练完毕，模型保存成功')


if __name__ == '__main__':
    demo01_train_save()
```

数据集用哪个？`data` 下面 `fil9` 是 680 兆那个最大的，其余是 100 兆的，还有一个 80 兆的。**先用 100 兆这个**，跑起来压力不大。

路径写 `./data/0502_ad` 就行。

> **易错点**：后面那一堆 `model=`、`lr=`、`dim=` 之类的参数**全删掉**，一个都不写。为什么不写？因为我们现在就是要用**最原始的默认参数**把流程跑通。参数怎么设是第四步的事，现在先别动。

## 4 默认参数从哪来

那"默认"到底是哪些值？得去源码里看。

按住 `Ctrl`，鼠标点一下 `train_unsupervised` 这个函数名，就跳进 `fastText` 包里的实现了。往下翻，会看到一个变量：

```text
unsupervised_default
```

按住 `Ctrl` 不要松开，再点一下它，编辑器会跳到定义这个默认值的那一行上。这里有个细节值得体会一下：**它定义的位置在 551 行附近，但 `Ctrl` 点过去之后会跳到 439 行**——因为跳转跟的是符号定义处，而不是引用处。

命名上叫 `unsupervised_default`，也就是**无监督模式下的默认参数**——训练时你若什么都不写，用的就是它。

先把其中最关键的四个拎出来：

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| `model` | `skipgram` | 底层用的是 Skip-gram 方式 |
| `lr` | `0.05` | 学习率（learning rate），控制每步更新的幅度 |
| `dim` | `100` | 维度：用多少个数字表示一个词 |
| `epoch` | `5` | 训练的轮数 |

其余参数先放着不动，到超参设定那一讲再逐个调。

> **定义**：`dim=100` 的意思是"**用 100 个数字来表示一个词**"。前面我们演示 one-hot 时是用三个数字表示一个词，这里换成了 100 维的稠密向量——维度越高，能塞进去的语义信息越多，但训练和存储的开销也越大。

## 5 保存模型与加载接口

代码里第二个动作就是保存。`train_unsupervised` 一执行完，模型就**已经可以保存了**，不需要等别的东西。

保存用 `save_model`，存成**二进制文件**，扩展名 `.bin`：

```python
my_model.save_model('./model/0502_fil9.bin')
```

为什么不存到 `data` 目录？因为这是**模型**，不是数据，得单独放一个地方。文件名里带上数据集名 `fil9`，一眼就知道这份模型是哪份数据训出来的。

顺手打个提示，确认这步执行成功：

```python
print('训练完毕，模型保存成功')
```

> **提示**：跟保存配对的还有加载。`fastText` 里有个 `load_model` 函数专门用来把 `.bin` 文件读回内存。现在先记住有这么一个接口，下一个函数就要用它。

## 6 目录准备与运行

在运行之前先检查一件事：工程里**有没有 `model` 这个文件夹**？

右键看一眼——没有。那就右键先新建一个 `model` 目录出来，不然 `save_model` 找不到落盘位置。

然后写 `main` 入口，调用第一个 demo：

```python
if __name__ == '__main__':
    # 测试：训练词向量模型并保存模型
    demo01_train_save()
```

右键运行。100 兆这份数据，训练时间大概**两分钟左右**。

> **结论**：如果你用的是 680 兆的 `fil9`，耗时要围绕 100 兆的时长**乘 4 到乘 6**，时间会明显拉长。想快速看效果，就用分片。

## 7 训练日志逐项解读

让它在后台跑着，我们来看它刷出来的日志——这一堆数字是这一讲最值得弄明白的部分。

先把日志按组切开：

```text
Read 19M words
Number of words: 43589
Number of labels: 0
Progress:   4.5%  words/sec/thread:  50234  lr: 0.047965  avg.loss: 2.1417  ETA: 0:01:23
```

读图说明：第一行读到的词数，第二行去重后的词表规模，第三行标签数量，第四行是随训练不断刷新的进度行，包含进度、吞吐、学习率、平均损失和预计剩余时间五项。

一条条来。

**`Read 19M words`**：读取了多少个单词。这份数据里一共读了 **19M**（约 1900 万）个词。

**`Number of words: 43589`**：**去重之后**的单词数量——也就是语料库的**词表大小**。一共 4 万多个不同的单词。注意这是词表规模，不是总词数，别和上一行混起来。

**`Number of labels: 0`**：标签数量为 0，说明这次是**无监督训练**。

为什么标签是 0 就代表无监督？因为无监督任务里根本没有标签可预测。属于无监督的典型就是 Word2vec 的两种模式——**CBOW** 和 **Skip-gram**，它们只从语料本身学词与词的共现关系，不需要人工标注。反过来，一旦标签数不为 0，那就是在做分类，属于有监督。

**第四行是最有用的一行**，把它拆成五段：

| 字段 | 取值示例 | 含义 |
| --- | --- | --- |
| `Progress` | `4.5%` | 训练进度 |
| `words/sec/thread` | `50234` | 每个线程每秒处理的单词数 |
| `lr` | `0.047965` | 当前学习率 |
| `avg.loss` | `2.1417` | 平均损失 |
| `ETA` | `0:01:23` | 预计完成时间 |

`words/sec/thread` 拆开读就是：`words` 是单词，`sec` 是秒，`thread` 是线程，连起来就是**每个线程每秒处理的单词数**。这个数**仅供参考**——上面说词表有 4 万多个不同单词，这里每秒能处理 5 万左右，而总量是 19M，所以它并不能精确反映"还剩多久"。

`lr` 是学习率，注意它**不是恒定的**：一开始是 `0.05`，随着训练推进会慢慢衰减，日志里看到的就是衰减后的当前值。

`avg.loss` 是平均损失，判断模型学得好不好主要看它——正常训练时它应该随进度稳步下降。

`ETA` 是预计完成时间（estimated time of arrival），告诉你还要等多久。

> **提示**：`avg.loss` 下降得快不快，跟学习率、词表规模、语料质量都有关。它长时间不降或者上下乱跳，通常意味着学习率偏大或者数据有问题，那时候就该回头调参了。

## 8 换全量语料再训一次

代码跑通之后，值得再做一个动作：**把 `fil9` 整份丢进去试一次**。

```python
my_model = fastText.train_unsupervised('./data/fil9')
```

效果会不会比用分片更好？会——**因为它的单词更多**，词表更大，词与词的共现统计更充分，学出来的向量自然更准。

代价就是时间。这也是把两个数据集都留在工程里的意义：**先用分片把代码调顺，再用全量拿最终结果**。

> **结论**：这一讲的产出物是两样东西——一个跑通的无监督训练函数，和一份存到 `model/` 下的 `.bin` 模型文件。下一讲就用 `load_model` 把这份模型读回来，看它到底学到了什么。
