# RNN 模型的两套分类：输入输出角度与内部结构角度

## 这一讲要背下来的两个角度

RNN 模型的分类主要有两个角度：**按输入和输出的角度划分**，以及**按内部结构划分**。这一讲的内容是要记到本子上的，被问到「说一下 RNN 的分类」时，必须把这两个方向都说清楚。

先说清楚为什么强调这一点。如果你上来只答「N vs N、N vs 1、1 vs N、N vs M」，那这个回答是没有意义的——那只是第一个角度底下的一种分法，漏掉了整个内部结构那一半。

## 输入输出角度：四种形态

输入输出角度要回答的问题很朴素：**输入几个，输出几个？**

### N vs N：输入 N 个，输出 N 个

你给我五个，我给你五个；你给我六个，我给你六个。输入和输出个数对齐。这种形态适用于**写诗、写对联这类固定场景的表达**。

为什么是这两件事？因为诗本身就是对仗工整的。四言、七言绝句，字数格律都定死了：「孤山寺北贾亭西，水面初平云脚低」，上下句字数一致；「床前明月光，疑是地上霜。举头望明月，低头思故乡」，也是整齐的句式。输入多长、输出就多长，正好对上 N vs N。

幻灯片上对它的描述是：RNN 的基础形态，生成的输入和输出等长，例如生成等长度的诗句。

### N vs 1：输入 N 个，输出 1 个

我给你一堆的句子，你最后告诉我它是好评还是差评——这就是**情感分类**。换成意图识别的说法：我用了一堆字去描述我的问题，你最后识别出「原来你要做理财」，输入是一整句话、输出是一个标签，同样是 N vs 1。

幻灯片上的描述是：输入的是一个序列、也就是一句话，输出是一个单独的值，适用于文本分类——给你一堆文本，最后告诉我它属于什么类，是经济类、体育类还是新闻类文章，意图识别也可以用它来做。

### 1 vs N：输入 1 个，输出 N 个

这就是**看图说话**：我给你一张图片，你解析解析这张图里有哪些内容，基于这张图帮我提取出更多文字信息。给你一个，你生成一堆。

### N vs M：输入 N 个，输出 M 个

翻译、语音转换、文本生成、摘要都属于这一类。**N 个进、M 个出，而且 M 和 N 不相等**——这是它和 N vs N 最本质的区别。

课上举的例子很能说明问题。有个英语老师在讲课时翻了一句很文艺的话：「君之所向，吾意所往。」对应到英文，她给出的翻译是：

```text
You go, I go.
```

中文这边是八个字，英文那边只有四个单词，个数完全不对齐。这正是 N vs M 的典型形态。

那么四种形态里，**哪一种玩得最多？**答案是 N vs M。之前说过我们会接触至少三个 800 行以上的代码案例，其中就包括后面要做的 sequence-to-sequence 英译法案例，那个案例就是 N vs M。英译法案例是必须掌握的，所以 N vs M 很重要。

### 编码器与解码器：N vs M 的结构与那个 C

N vs M 的展开图，现在先建立一个整体印象就行，细节等英译法案例再细讲。

```text
   编码器（左半程）                解码器（右半程）

   h0     h1     h2 ...           s0     s1     s2 ...
   ^      ^      ^                ^      ^      ^
   |      |      |                |      |      |
  x1     x2     x3              中间语义 C 传过来
```

上图是经典编码器—解码器（encoder-decoder）结构：左边一串隐藏状态负责把输入序列读成一份语义表示，右边一串负责把它展开成目标序列，中间那份表示就是 $C$。

- 左边这一堆动作，可以理解为我们所说的**编码器**；
- 右边这一堆，可以理解为**解码器**；
- 中间那个 $C$ 叫**中间语义编码张量 $C$**，也叫中间语义张量。

再往这个结构上延伸、延伸，它就成了 Transformer。现在看不懂 $C$ 是什么意思完全正常，英译法案例里会详细讲。

顺便把学习节奏说明白：我们先把 RNN、LSTM、GRU 的原理和代码都学了，然后做全球人名分类案例，之后讲注意力机制，讲完再做英译法案例——这一章就全部结束，接着开 Transformer。这个顺序是安排好的，英译法案例会放慢节奏讲，因为那个案例确实不好掌握。

## 内部结构角度：五种模型

第二个大类不按输入输出分了，按**内部结构**分。这是本讲要着重聊的部分。

### 传统 RNN

传统 RNN 就是我们前面说的那一套：由输入层、隐藏层、输出层组成，其中隐藏层里一个是**词嵌入层**，一个是**循环网络层**。

### LSTM：从层变成门

LSTM 直接告诉你，它就不是上面那个意思了。它是**门**：遗忘门、输入门、细胞状态、输出门。

> **提示**：这一串名词第一次听全是新词，一个都不认识，这很正常。你现在只需要知道「LSTM 内部由这些门和细胞状态组成」，每个门具体干什么，等原理部分再展开。

### Bi-LSTM 与 Bi-GRU：双向的意思

`Bi-` 这个前缀就是 binary、那个「二」的意思。之前讲 N-gram 时，2-gram 就叫 Bi-gram，所以 `Bi-` 在这里表示**双向**：`Bi-LSTM` 就是双向 LSTM，`Bi-GRU` 就是双向 GRU。

双向怎么做的？一句话从前向后做一遍，再从后往前做一遍，然后把两次结果合并。

拿「我爱你」来想：先拿「我爱你」做一遍 LSTM，再拿「你爱我」做一遍 LSTM，把两个结果合并，就是最终结果。

为什么要双向？因为不管是从前往后还是从后往前，都能更好地理解语义——两个方向的信息互为补充。但它带来的弊端是**运算量会增加**，这一点是必然的。也正因为这样，实际开发中除非必要，一般不会选双向的那两个。

### GRU：用更少的门做更多的事

GRU 的思路是：LSTM 门太多了。所以在保证效率的前提下，尽量减少门的操作，只留两个——**重置门**和**更新门**，就完事了。

把这句话说得更准确一点：GRU 是基于 LSTM 做的一个优化，核心意思是**用最少的资源做更多的事情**。

于是内部结构角度的五个模型可以并列摆开：

| 模型 | 内部结构要点 |
| --- | --- |
| 传统 RNN | 输入层、隐藏层（词嵌入层 + 循环网络层）、输出层 |
| LSTM | 遗忘门、输入门、细胞状态、输出门 |
| GRU | 重置门、更新门 |
| Bi-LSTM | 双向 LSTM：正向一遍、反向一遍，结果合并 |
| Bi-GRU | 双向 GRU：正向一遍、反向一遍，结果合并 |

> **结论**：未来实际开发中用得最多的是 LSTM。虽然摆出来是五个模型，但双向的除非必要一般不选，剩下三个里，LSTM 相对用得更多。

为什么是 LSTM，原理部分会解释。

## 从输入输出角度延伸出去的三个场景

把输入输出这条线再走一遍，顺手把每个场景落到具体业务上。

**N vs N**：输入 N 个、输出 N 个，用在写诗这种对仗工整的场合，生成等长度的诗句。

**N vs 1**：输入 N 个，最后只要一个结果，用来做情感分析、意图识别。输入是序列，输出是单独的值，适用于文本分类——判断这段文本属于经济类、体育类还是新闻类文章，意图识别也走这条路。

**1 vs N**：看图说话，把图片生成文字，给你一张图，你基于它提取出更多文字信息。

**N vs M**：输入 N 个、输出 M 个。中文八个字对英文四个词，「君之所向，吾意所往」对 `You go, I go`，个数不必相等。翻译就是它的主战场，后面那个 800 行以上的英译法案例讲的就是这个操作。

## 本讲提到的题目

这一讲在讲完分类后留了一道单项选择题：**循环神经网络为什么要叫循环？**

- A. 因为 RNN 循环网络也属于深度网络
- B. 因为它有输入、输出以及隐藏
- C. 因为它可以支持文本序列
- D. 上一个的输出作为下一个的输入

**答案：D。**

**解析**：循环的含义落在数据流上——网络里上一次的输出会作为下一次的输入，同一个单元反复执行，所以叫循环。A 项说的「属于深度网络」是所有深层网络的共性，不构成循环的理由；B 项的三层结构描述的是组成，ANN 也有这三层；C 项说它支持文本序列，那是它适合处理序列数据的能力表现，而不是「循环」这个名字的由来。只有 D 项直接对应循环网络层的运行方式。
