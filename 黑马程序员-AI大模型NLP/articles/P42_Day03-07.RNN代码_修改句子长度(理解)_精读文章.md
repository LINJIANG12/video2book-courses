# 改句子长度：output 与 h_n 的形状如何联动变化

刚才我们已经完成了 RNN 的基础搭建，代码跑通了，形状也打印出来验证过了。那接下来做一件事：**修改它输入数据的长度**。

比如讲义上这个位置，把那个 `1` 改成了 `11`。`11` 是谁？`11` 就是把 `input` 那个位置——`input` 是谁？是 `x`——相当于把 `x` 里第一个位置上的 `1` 改成了 `11`。你把这改成 `11` 了，上面那个句子长度的位置也改成 `11`，其他的都不变。能跟上我的思路吗？

**无论改谁，你看这里边的参数就行了。**

## 复制基础版代码与新增第二个函数

我们来做修改。把上面那段代码 `Ctrl+C` 全选，直接 `Ctrl+V` 贴下来——我贴我自己的代码，没意见吧。

贴到下面之后，这个函数叫第二个函数，名字就叫"演示修改 RNN 模型的句子长度"。

名字也不用跟原来一样。原来那个叫 `base`，我们就换个名字：s-e-q-u-e-n-c-e，`sequence`，后面再写上 `len` 就可以了。所以函数名就是 `demo_rnn_sequence_len`。

新函数里改哪一处？就改 `x` 的第一个位置。

这里我改的是 `20`。有同学说课件上是 `11`——你管我呢，爱改多少改多少。我把 `input` 那个位置，也就是 `x` 这个位置，从这里的 `1` 改成了 `20`。

## 一处改、一处跟：哪些参数必须同步修改

改完 `x` 之后我先问你个问题：我把 `1` 改成 `20` 了，那还有哪个地方要改？

**上面那个句子长度的位置是不是也要改？** 对，就这两处。

那除了它俩以外，其他地方动吗？**不动。** 批次还是 3，词向量维度还是 5，隐藏状态 `h_0` 也还是 `1 3 6`，一个数都不用碰。

```python
# TODO 2 定义函数：演示修改 RNN 模型的句子长度
def demo_rnn_sequence_len():
    # 1. 创建 RNN 模型：参数完全不变
    rnn = nn.RNN(input_size=5, hidden_size=6, num_layers=1)

    # 2. 准备输入数据：句子长度由 1 改为 20
    x = torch.randn(20, 3, 5)         # (sequence_len=20, batch_size=3, input_size=5)

    # 3. 初始化隐藏状态：与句子长度无关，保持 1 3 6
    h_0 = torch.randn(1, 3, 6)        # (num_layers, batch_size, hidden_size)

    # 4. 调用 RNN 模型
    output, h_n = rnn(x, h_0)

    # 5. 打印结果
    print("output:", output.shape)
    print("h_n:", h_n.shape)
    print("RNN模型:", rnn)
```

> **易错点**：`h_0` 的第一个维度是隐藏层层数，不是句子长度。句子长度改到 20，`h_0` 依然是 `1 3 6`——这一点最容易顺手改错。

## 形状推导：output 与 h_n 各自变成什么

改完之后，两个返回值的形状马上就能推出来。

`output` 打印出来是多少？它是不是就变成 `20 3 6` 了——因为 `output` 的第一维跟的就是句子长度。

那 `h_n` 呢？`h_n` 输出的还是 `1 3 6`。而且这个 `1 3 6` 肯定是 `20 3 6` 里面的什么？**最后一个。**

一句话总结这次的改动：

> **结论**：句子长度只影响 `output` 的第一个维度；`h_n` 的形状由"层数 × 批次 × 隐藏维度"决定，与句子长度无关。所以 `seq_len` 从 1 改成 20 之后，`output` 是 `20 3 6`，`h_n` 仍是 `1 3 6`，且 `h_n` 就是 `output` 里的最后一行。

## 运行验证与科学计数法下的数值对比

接下来我们试试。把下面原来那个基础版的测试调用注释掉，换成新的测试：

```python

    print("=" * 30, "修改句子长度", "=" * 30)
    demo_rnn_sequence_len()
```

右键执行。先看打印结果——打印内容太多了，不看，直接看它的维度。

请问是不是我们刚才所说的？来，瞅着看：第一个叫 `20 3 6`，是左边这个；右边这个是个多少呢？念一下，是不是个 `1 3 6`？

看到了吧。而且这个 `1 3 6`，你会发现里面整个内容都是 `3.67...e-...` 这样、`0.84...` 这样——其实你会发现它和后面那个值是一样的，**只不过它用的是科学计数法**。

> **提示**：张量里数字很多的时候，PyTorch 打印会自动改用科学计数法（形如 `3.67e-01`）来压缩显示宽度。数值本身没有变，`h_n` 和 `output` 最后一行仍然是同一组数，别被显示格式骗了。

所以到这里，还是那句话：你的隐藏状态记录的其实就是你上述输出状态的**最后一级**。这里 `1 3 6` 记录的就是 `20 3 6` 里面的**最后一组数据**。

```text
   x : (20, 3, 5)                                    seq_len 1 -> 20
        |
        v
   nn.RNN(input_size=5, hidden_size=6, num_layers=1)
        |
        +--> output : (20, 3, 6)   <-- 第 0..19 时间步的隐藏状态全存着
        |
        +--> h_n    : ( 1, 3, 6)   ==  output[-1]  <-- 只留最后一个时间步

   形状对照（改动前 -> 改动后）：
       x       ( 1, 3, 5) -> (20, 3, 5)
       output  ( 1, 3, 6) -> (20, 3, 6)
       h_0     ( 1, 3, 6) -> ( 1, 3, 6)   不变
       h_n     ( 1, 3, 6) -> ( 1, 3, 6)   不变，等于 output 最后一行
```

读图说明：句子长度只让 `x` 与 `output` 的第一个维度一起变长，`h_0` 与 `h_n` 完全不受影响；`h_n` 始终等于 `output` 最后一个时间步的那一组数。

## 模板化改参：改哪个参数就换哪个元素

这个位置修改的是它输入的一个**长度**。那我想说的其实是另一句话：

无论是现在在这里边我去修改了哪一个参数，你看上面有变量名，还有变量的值——**无论我修改谁呢，你是不是把那对应的元素做一个变换，是不是就可以了？**

> **结论**：这一节的代码是一份"模板"。模型参数在一处（`nn.RNN` 的三个实参），输入形状在一处（`x`），隐藏状态形状在一处（`h_0`），输出形状由它们推出来。以后你要调批次、调词向量维度、调隐藏层维度，都是同样的动作——找到那个数所在的位置，改它，然后顺着依赖关系把该跟着改的改掉，其他都一样。

这就是修改 RNN 句子长度的全部内容，这份代码我们就先聊到这。
