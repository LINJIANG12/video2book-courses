# 句子长度分布分析：训练集与测试集的长度统计与可视化

拿到一份情感分类语料，第一件事不是清洗，也不是切分，而是先看清楚它。我先问你们一个问题：在真正做文本处理之前，我们第一个动作应该是什么？答案是做句子长度分布的可视化统计。这一步只统计、只画图，不做截断、也不做补齐——我们要先知道句子的长度大致分布在哪里。

为什么这么在意这个？我举个例子。我来带咱班之前，会先找班主任勇哥要一下班级名单，看看大家的"吸水情况"：前半段学得怎么样、学历、年龄、之前几次考试的成绩。如果前几次考试平均分 99 分，那我讲课就往深里挖，说明基础都不错；如果平均分只有 60 多分，那我就只能先保证基础的那些逻辑代码。数据到手先摸一遍底，后面所有决策才有依据——语料也是同一个道理。

## 1 长度分布的两组统计指标

### 1.1 统计对象：训练集与测试集各自的句子长度

句子长度分布不是一个数，而是两组统计量：训练集的长度分布、测试集的长度分布。两者都要做，而且用的是同一套代码逻辑。不要只画训练集就收工——测试集的长度分布是判断划分是否一致的直接依据。

> **定义**：句子长度，指一条样本在**按字符切分**意义下的长度，即把整条句子当成字符串，用 `len()` 求出的字符个数。

这里一定要区分清楚：这一步没有任何"处理"动作。不截断（truncate），也不补齐（pad）。我们只是在看。

### 1.2 统计结果的表示：计数柱状图与密度曲线图

长度分布用两种图表达，一组图对应一个数据集，所以四个图为一轮：

| 图 | 名称 | 表达什么 | 用在哪个数据集 |
| --- | --- | --- | --- |
| 图一 | 计数柱状图（count plot） | 每个长度值/区间上有多少条句子 | 训练集、测试集各一张 |
| 图二 | 密度曲线图（使用直方图 + KDE 实现） | 长度取值的整体分布形状，峰值落在哪 | 训练集、测试集各一张 |

计数柱状图回答"哪个长度上句子多"，密度曲线图回答"长度整体集中在哪一段"。两者配合，一眼就能定出后面截断的上下界。

## 2 数据读取与句子长度列的计算

### 2.1 读取训练集与测试集

函数名叫 `len_sns_countplot_displot`——长度、计数柱状图、密度图三件事写在名字里。第一步永远不用想：

```python
def dm02():
    # 1. 读取训练集和测试集
    train_data = pd.read_csv('./data/train.csv')
    test_data = pd.read_csv('./data/test.csv')
```

### 2.2 计算句子长度的思路一：map 函数

原始数据只有两列：句子一列、标签（好评/差评）一列。现在要给它加第三列——句子长度。

"咋算呀？"别急着看代码，先想：句子就是 `train_data` 里的 `sentence` 这一列，把它当字符串，前面加个 `len` 不就拿到长度了？问题是，我不可能一条一条去 `len`。所以要请出前面刚讲过的组合——`list` + `map`。

`map` 的作用是把一个函数作用到每一个元素上，它的前面给函数对象，后面给要处理的句子，最外层再用 `list` 把结果收敛成一个列表：

```python
    # 2. 计算训练集每个句子的长度
    train_data['sentence_len'] = list(map(lambda x: len(x), train_data['sentence']))
```

我们把这段写成过伪代码，对照着念一遍就通了：

```text
list(  map(  获取句子长度的函数对象,  每一条句子  )  )
        └── lambda x: len(x) ──┘    └── train_data['sentence'] ──┘
```

从内往外读：`lambda x: len(x)` 是函数对象，功能就是"获取句子长度"；`train_data['sentence']` 给出的是句子；外面套一层 `list`，把 map 产出的结果收成列表，再赋值给新列 `sentence_len`。

`train_data.head()` 扫一眼就能看到结果：48、80、70、65……这就是那句话"先讲了 `list`+`map` 这种组合，再看这段代码就 so easy，没讲的话看下来肯定非常重"。

### 2.3 计算句子长度的思路二：apply 函数

同样是加一列长度，还有第二条路：`apply`。

前面学 pandas 的时候接触过一个函数，它也能让函数作用到每个元素上，叫 `apply`。写法一模一样：

```python
    # 思路二：apply 实现
    train_data['sentence_len'] = train_data['sentence'].apply(lambda x: len(x))
```

两个思路跑出来的内容是**完全一致**的——48、80、70、65、39，一条不差。

> **结论**：`map` 与 `apply` 在这里等价，选哪个都行，不用纠结。

如果让我来给你们写，讲义上没给 `map` 那版，我可能直接就写 `apply`，因为它更省事——挂在 `Series` 上，不用再套 `list`。但 `map` 那版必须会，它是理解"函数作用到每个元素"这件事最干净的入口。

### 2.4 同理计算测试集的长度列

测试集完全照搬，只是数据源从 `train_data` 换成 `test_data`：

```python
    # 3. 计算测试集每个句子的长度
    test_data['sentence_len'] = list(map(lambda x: len(x), test_data['sentence']))
```

到这里数据就是三列了：句子、标签、长度。下面开始画图。

## 3 训练集的长度分布可视化

### 3.1 计数柱状图

```python
    # 4. 绘制训练集句子长度分布：计数柱状图
    sns.countplot(x='sentence_len', data=train_data)
    plt.title('训练集句子长度分布-计数柱状图')
    plt.xticks([])          # 隐藏 x 轴刻度值
    plt.show()
```

三个动作逐条过一遍：

- `sns.countplot`：`x` 给要统计的列，也就是刚算出来的 `sentence_len`，`data` 给数据来源，图就出来了；
- `plt.title`：写清这是训练集的计数柱状图；
- `plt.xticks([])`：括号里给一个**空列表**，意思就是隐藏 x 轴的刻度值，让它什么都不显示。

跑出来是什么样？x 轴标签 `sentence_len` 还在，但 x 轴上那些密密麻麻的数字全没了，只剩一根根高低不同的柱子。

> **提示**：`plt.xticks([])` 是"刻度一个都不显示"，不是清空标题、也不是清空柱子。给空列表才是不显示；不给值它就按默认刻度画。

### 3.2 密度曲线图的旧版写法与它的毛病

密度图讲义上给的是 `displot`，但我得先说清楚，我为什么要把这段单独讲一下——**`displot` 这个函数已经过时了**。所以与其照抄，不如把它当反面例子看一眼。

```python
    # 旧版写法（已过时）：displot
    sns.displot(x='sentence_len', data=train_data)
    plt.yticks([])
    plt.show()
```

这节课的代码我一个字没动，直接照讲义跑，跑出来它只会给你一条很淡的线，分布的样子看得不是特别明显。那它到底想干什么？其实就是给你加一条线，告诉你长度大概怎么分布。

想让这条线明显一点，可以打开核密度估计（Kernel Density Estimation，KDE），把 `kde` 置为 `True`：

```python
    # 打开核密度估计
    sns.displot(x='sentence_len', data=train_data, kde=True)
    plt.show()
```

这次能看到一条细线了，那就是核密度预估区间。但它还是不太明显。

> **注意**：部分电脑照上面这段写会报一个警告，这是 matplotlib 版本的问题。之前我让你们装的时候建议装的是 3.2.9——如果你装成 3.10 或者别的版本，同样的代码就可能出问题。这不是你写错了。

### 3.3 密度曲线图的新版写法：histplot + kde

新版一般这样画——用直方图 `histplot` 打底，再挂上 `kde`：

```python
    # 新版写法：直方图 + 核密度估计
    sns.histplot(x='sentence_len', data=train_data, kde=True)
    plt.title('训练集句子长度分布-密度曲线图')
    plt.show()
```

差别就在这儿：`hist` 负责画直方图，`kde=True` 负责在旁边把那条核密度曲线画出来。把前面那些图全清掉重新跑一次，这条线就清楚多了。

从这条线上读出来的结论是：绝大多数句子的长度落在 **20 到 250** 这个区间里。

```text
句子条数
  │            ╭──╮
  │           ╱    ╲
  │         ╱        ╲___
  │       ╱              ╲______
  │  ___╱                        ╲________
  └──┴────┴────┴────┴────┴────┴────┴──────►  句子长度
     0   20   50   ...        250       3500
     └────── 绝大多数句子落在这里 ──────┘        └ 离群：极少数
```

读图说明：横轴是句子长度，纵轴是该长度的句子条数，曲线的主峰（约 20~250 那段）装下了绝大部分语料，右端拖着一条又长又薄的长尾。

## 4 测试集的长度分布可视化

第 4 步的写法和第 3 步一样，所以不用废话。先把测试集的长度序列算出来，再画两张图：

```python
    # 5. 绘制测试集句子长度分布
    sns.countplot(x='sentence_len', data=test_data)
    plt.title('测试集句子长度分布-计数柱状图')
    plt.xticks([])
    plt.show()

    sns.histplot(x='sentence_len', data=test_data, kde=True)
    plt.title('测试集句子长度分布-密度曲线图')
    plt.show()
```

就是把上面那套动作**复制、粘贴**，只把数据来源换掉。

四个图连起来看，测试集的分布比训练集更清晰一些——这是数据量造成的差别。训练集样本多，每个长度上的句子数被摊薄，柱子显得参差；测试集样本少，形状反而更容易看清。

### 4.1 柱状图与直方图的读数方式

拿测试集这张计数图看，x 轴是句子的长度，y 轴是落在该长度上的句子条数。数字是这样的：某一个区间大概有 50 条，再往左那个区间（差不多 20 到 25 这个长度段）大概有 200 多条句子。也就是说，长度集中在 20 到 25 附近的句子有两百多条。

> **提示**：柱状图（bar chart）与直方图（histogram）读法不同。柱状图的一根柱子对应一个**离散的取值**，比如"长度为 0 的有多少条、长度为 1 的有多少条"；直方图的一根柱子对应一个**连续区间**，比如"长度落在 20~25 这个区间的有多少条"。看长度这种连续量，按区间读才不容易看花眼。

### 4.2 区间结论与后续截断的关系

四张图给出同一个答案：**绝大多数句子的长度集中在 20 到 250 这个区间**。

这个结论不是拿来看的，是拿来用的。后面真要做截断、做补齐的时候，20 和 250 就是那两个可以直接拿来用的区间边界——短于 20 的补，长于 250 的截。

为什么敢这么定？回到语料本身看尾部就明白了：

```text
长度 0 附近   ：写一个字、两个字的评论，有，但很少
20 ~ 250      ：评论的主体，绝大多数都在这里
400 字以上    ：有，但非常非常少
3500 附近     ：极个别，属于需要单独审查的离群点
```

一条四百字以上的评论是有的，但那种评论非常非常少。反过来，"嗯""不错""还行"这种一两个字的短评也不多。两头都薄、中间厚，这就是定截断区间的依据。
