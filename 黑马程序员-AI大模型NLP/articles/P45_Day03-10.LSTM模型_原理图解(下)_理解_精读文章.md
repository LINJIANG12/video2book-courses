# LSTM 四个门的公式与计算流程

前面我们从核心和整体流程上把 LSTM 过了一遍：三门一状态、管家整理记忆、旧的删一些留一些、新的也删一些留一些。但流程归流程，真正落到公式上还没写。这一节就把遗忘门、输入门、记忆细胞、输出门这四步的公式逐条对上去，看每一步到底在算什么。

## 1. 遗忘门的作用、公式与门值含义

一上来第一个区域就是遗忘门。

它的作用是：通过**当前的输入**和**上一时刻的隐藏状态**，决定记忆细胞里的哪些信息可以丢掉。

看图上箭头：`x`（当前输入）有一路进到遗忘门；上边还有一路箭头过来，那是上一时刻的隐藏状态一路往后走传下来的。两个信息合在一起做判断，判断的对象就是记忆细胞里的内容——哪些可以丢。

举个例子：你记日记的时候，发现昨天记的是天气预报。对今天的事来说，这玩意儿没用，那就把它从长期记忆本（也就是你的细胞状态）里划掉，不要了。

### 1.1 门值公式的逐项拆解

遗忘门的公式是：

$$f_t = \sigma(W_f \cdot [h_{t-1}, x_t] + b_f)$$

跟着思路把它念一遍：门值等于激活函数，括号里是 $W_f$ 乘以中括号里的一项，中括号里是 $h_{t-1}$（上一时刻隐藏状态）和 $x_t$（本次输入），最后加上 $b_f$，也就是偏置。

> **提示**：偏置这一项有时候其实可以不考虑，不影响理解主流程。

公式下面还有一组 $f_t \times C_{t-1}$。这一组**不是门值**：$f_t$ 才是门值，门值再乘上一次的细胞状态，是"拿到门值之后怎么用"的动作。这里先记下来，等到讲记忆细胞更新的时候会正式用上。

> **结论**：门值是一个数值，落在 0 到 1 之间。
>
> - 门值**接近 1** → 这一挑**旧记忆**有用，**保留**。
> - 门值**接近 0** → 这一挑旧记忆**忘掉**。

### 1.2 门值大小的直观含义

公式看着抽象，换个实物就清楚了：把它当成一扇真实的门。

```text
门开得足（门值 -> 1）：        虚掩着（门值约 0.5）：         堵死（门值 = 0）：

   |‾‾‾‾‾‾‾‾|                    |‾‾\                          |‾‾‾‾‾‾‾‾|
   |        |                    |   \                         |        |
   |        |  <- 进去的最多       |    \  <- 效率大幅下降         |        |  <- 谁也进不来
   |________|                    |_____\                        |________|
```

门值决定的是门开多大——门开得越大，能过滤进来的信息越多；门越小，能进来的越少；门堵死变成 0，谁也进不来。遗忘门就是靠这个数值来调整"过滤掉多少旧信息"。

## 2. 输入门的作用、门值与候选记忆

遗忘门讲完，接着讲输入门。它主要是两个动作。

输入门的作用是：同样是通过当前的输入和上一时刻的隐藏状态，决定**哪些新信息需要放进记忆细胞**。

换句话说，上面那个门管的是"丢掉哪些旧的"，这个门管的是"记住哪些新的"。

类比一下：你今天遇到一件大事。什么算大事？比如过生日，女朋友送你一辆法拉利——判断这事重要，就把它记到长期记忆本里。于是你会永远记得，在自己多少多少岁生日的时候，女朋友送了你什么。

### 2.1 门值公式与遗忘门同形

输入门的第一个公式是：

$$i_t = \sigma(W_i \cdot [h_{t-1}, x_t] + b_i)$$

你会发现它的内容和上面一模一样——门值等于激活函数，权重乘以等等等等，加偏置。

所以这里有个很实用的结论：写笔记的时候根本不用把字母写全，只写"门值"两个字就够了。为什么不说这是遗忘门的门值、那是输入门的门值？因为下一个门的门值公式可以直接复制粘贴拿过来用，一个字都不用改。

> **易错点**：门值公式的四件套——激活函数、权重矩阵、$h_{t-1}$ 与 $x_t$ 的拼接、偏置——对三个门完全同构，区别只在权重矩阵的下标（$W_f$ / $W_i$ / $W_o$）与偏置的下标。三个门用的激活函数都是 sigmoid，因为门值要被压到 0 到 1 之间才能当"开合程度"用。

### 2.2 候选记忆的生成与激活函数选择

第二个公式是候选记忆：

$$\tilde{C}_t = \tanh(W_C \cdot [h_{t-1}, x_t] + b_C)$$

念一遍：激活函数处理之后，得到的是候选记忆——**生成可能要存的新信息**。

注意"可能"两个字，它还没有真正去更新，只是临时记一下。为什么要绕这么一道？可以理解为**容错**。

> **提示**：这个道理跟过年晚会很像。过年那天是直播，但你觉得这帮演员前期有没有去那个舞台上做过任何排练？不可能的，前期肯定排练了很多很多回。所以候选记忆就是排练这个动作，最终才会推进去。要是瞄了一眼觉得重要就直接推进去，那后面就没有余地了。

最后一步动作是**门值乘以候选记忆**：

$$i_t \cdot \tilde{C}_t$$

门值越大，真正存进去的越多；门值越小，落地的新信息越少——这一项的物理含义就是"候选记忆里哪些是要真正存进去的"。

> **易错点**：候选记忆用的是 `tanh`，门值用的是 `sigmoid`。这不是随手选的：门值必须落在 0 到 1 之间才能表示"放多少进来"，而候选记忆是一个内容值，用 `tanh` 可以取正也可以取负，表示"往记忆里加什么、减什么"。两个激活函数的取值区间不同，作用也不同。

## 3. 记忆细胞的存储作用与更新公式

第三个是记忆细胞，也叫细胞状态。写代码的时候用 `C` 来表示这个细胞，用 `H` 来表示隐藏状态，这两个变量名要知道来路。

它其实就是那个**长期记忆本**，作用是**存储关键信息**。

你长这么大，人生中总有些转折点：高中选文科还是理科、大学选学校选专业、最后怎么来到这里。这些都可以理解为人生中的转折点，其中有些对你更重要，可以作为记忆留下来。它的关键特点是**能跨很多时间步传递**。

这也正是它能解决长序列记忆问题的原因：**我只记录那些核心的信息，这样在传递的时候就不用传那么多**。

> **提示**：对比一下前面 RNN 为什么处理不了长文本——它记以前的信息记得太多了，不管是重要的还是不重要的它都记。如果你脑子里把从出生第一天到现在事无巨细全记下来，这会儿脑子得炸。你还能记清楚一年前的今天吃的什么饭吗？大多记不住。为什么腊八有人能记住？因为腊八有喝粥的传统，这个日子有特殊意义；换成六月初六、6 月 13 号这种普通日子，前两年那天做了什么，基本是记不住的。**它对你有特殊意义，你才记得住。**

那么这些关键信息是怎么筛出来的？靠的就是下面这行更新公式。

$$C_t = f_t \cdot C_{t-1} + i_t \cdot \tilde{C}_t$$

这个公式为什么叫"更新方式"？因为公式左边是新的细胞状态，右边两项分别是旧的和新的：

- $f_t \cdot C_{t-1}$：**遗忘门门值 × 旧记忆细胞状态**。也就是旧的信息往后传的时候，再忘掉一些。
- $i_t \cdot \tilde{C}_t$：**输入门门值 × 候选记忆**。也就是新的信息挑重点再加一些进来。

前面那两组"看起来没用上"的运算（$f_t \times C_{t-1}$、$i_t \times \tilde{C}_t$）到这里正好全部对上——之前没展开，是因为它们真正展开的位置就在这一行。

> **结论**：细胞状态靠"旧记忆筛一遍、新记忆挑一挑"来解决长序列记忆问题。不能全存，全存就是扯淡，哪能存那么多。

旧记忆为什么会变得不重要？想想自己：上初中或高中时谈的那个对象，当时记录你们之间的事记得还是比较清晰的，甚至刻骨铭心；等到年纪再大一点，结完婚有了小孩，再回忆以前的事，可能都不一定想得起来了，甚至初恋是谁都记不起来。当时觉得很重要的事，随着时间推移也就无所谓了——所以每次往后传的时候，都要用遗忘门门值再筛一遍。

## 4. 输出门与本次隐藏状态的计算

最后一步是输出门。事总得往前走：过了今天还有明天，过了后天还有大后天。

输出门的作用多了**第三个输入源**：除了本次的输入和上一时刻的隐藏状态，还要看**更新后的记忆细胞**。因为要往外送的内容，正是从更新后的细胞状态里挑的。

它决定的事情是：**输出哪些信息**。

类比很直接：你给朋友讲今天发生的事，你会从长期记忆本里挑重要的讲。"昨天有人送了我一辆法拉利"这种事要讲；"早上吃了面包"这种相对来讲没那么重要，暂时不说。

### 4.1 门值公式

$$o_t = \sigma(W_o \cdot [h_{t-1}, x_t] + b_o)$$

还是那套门值公式，只不过下标换成输出门的权重与偏置。$o$ 就是 output 那个单词的首字母。

本次隐藏状态则用它去调制更新后的细胞状态：

$$h_t = o_t \cdot \tanh(C_t)$$

念一遍：本次隐藏状态等于**输出门门值乘以 `tanh` 激活函数处理后的新的记忆细胞状态**——括号里处理的就是 $C_t$，也就是刚才更新完的那个新记忆细胞状态。

### 4.2 为什么每次都一定有本次隐藏状态

这里要接上前面 RNN 讲过的模型分类：按输入输出的对应关系分为 N vs N、N vs 1、1 vs N、N vs M。

拿 N vs 1 来讲：给你 N 个输入、只输出一个结果，那就只需要最后一次输出。也就是说，**不一定每次都有 Y，但 100% 每次都有本次的隐藏状态**。

```text
                 +-----------------------------+
   x_t  -------> |           遗忘门            | <------- h_{t-1}
   h_{t-1} ----> |  f_t = sigmoid(Wf·[h,x]+bf) |
                 +-----------------------------+
                                 |
                                 v
                 +-----------------------------+
   x_t  -------> |           输入门            | <------- h_{t-1}
   h_{t-1} ----> |  i_t = sigmoid(Wi·[h,x]+bi) |
                 +-----------------------------+
                                 |
                                 v
                 +-----------------------------+
                 |          细胞状态           |
                 |  C_t = f_t·C_{t-1} + i_t·C~t|
                 +-----------------------------+
                                 |
                                 v
                 +-----------------------------+
   x_t  -------> |           输出门            | <------- h_{t-1}
   h_{t-1} ----> |  o_t = sigmoid(Wo·[h,x]+bo) |
                 |  h_t = o_t · tanh(C_t)      |
                 +-----------------------------+
                                 |
                                 v
                          h_t（本次隐藏状态）
```

读图方式：三个门的门值都由同一组输入（本次输入 `x_t` 与上一时刻隐藏状态 `h_{t-1}`）算出；两个门值在细胞状态那一行汇合完成"旧减新增"的更新；输出门再拿更新后的 $C_t$ 去生成本次隐藏状态 $h_t$。

这就是各个公式到底是什么意思。
