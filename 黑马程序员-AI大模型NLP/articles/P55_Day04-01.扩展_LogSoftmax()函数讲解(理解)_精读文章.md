## 1. 用一段三分类的假数据做实验

我们建个新脚本，就叫今天的 `demo02`，注释写上：演示 `log_softmax` 函数的用法。

第一件事永远是导包：

```python
import torch
import torch.nn as nn
```

然后创建数据，模拟模型输出的原始分数。这个"原始分数"有个专门的英文名，叫 Logits（未归一化的预测分数）。

假设我们现在用 Softmax 做的是三分类：先得到分数一、分数二、分数三，经过 Softmax 处理之后拿到三个概率，这三个概率加起来等于 1。这就是"前身"做的事情。那 Logits 就表示三个分类的预测值，也就是全连接层处理之后的结果。

有人要问：为什么非得三分类？五个不行吗，六个不行吗？当然可以，无非运算量大一点而已。

```python
# 1. 创建数据：模拟模型输出的原始分数（Logits）
# 表示三个分类的预测值，即全连接层处理后的结果
output = torch.tensor([3.2, 5.1, -1.7])
```

这三个数是我随手编的，不作任何数理上的讲究，只用来演示算法。

## 2. `LogSoftmax` 一步到位的用法

第一步，用 `nn.LogSoftmax` 直接算。

```python
# 2. 思路一：使用 log_softmax 函数计算
# 2.1 创建 log_softmax 函数对象
log_softmax = nn.LogSoftmax(dim=0)

# 2.2 具体的计算
log_probs = log_softmax(output)

# 2.3 打印结果：结果就是对数概率
print('对数概率计算结果：', log_probs)
```

`dim=0` 表示按列来操作——我们这个张量只有一维，所以就是沿着这一维把三个分数一起归一化。

看到 `nn.LogSoftmax` 你有没有觉得眼熟？它跟 `nn.CrossEntropyLoss` 是一家的，还有二分类那边用的 `nn.BCELoss`，都是同一堆里的东西。

> **易错点**：`nn.LogSoftmax` 是一个**层**，它只负责把分数变成对数概率；`nn.CrossEntropyLoss` 是一个**损失**，它才负责跟你对比真实标签、算出那个 loss 值。两者名字像、长相像，干的事不一样。

在讲这个函数之前，我想先让你们把 `CrossEntropyLoss` 的底层公式再背一遍。这个公式我之前专门强调过一句"后面要用"，现在就是它要用的时候了。

从里往外数，它是这么几层：

1. 最里面是加权求和；
2. 外面套一层 Softmax，得到各类的概率；
3. Softmax 外面套一层对数 `log`；
4. 再往外，乘以真实概率（分类问题里就是 0 或 1）；
5. 把乘出来的结果累加求和；
6. 最前面再加一个负号。

> **定义**：多分类交叉熵的底层计算顺序是「加权求和 → Softmax → log → 乘以真实概率 → 累加 → 取负数」。

现在，对照这个公式看看我们要写的东西。以前的具体计算是这样两步：先 Softmax，再 log。所以现在我们手里的"概率、log 概率"就是：

```python
log_probs = log_softmax(output)
```

它就是对上面那个 `output` 先做 Softmax、再做 log 的结果。

跑一下，你会看到结果变成了 `-2.0439`、`-0.1439`、`-6.9439` 这一串负数。有人又要问了：那不对啊，公式里还有乘以 $y$、还有累加、还有负号呢？——那是**新版**的 `CrossEntropyLoss` 干的活，一会儿除了它之外你还得写别的代码，这就是我们后面要捋的点。

## 3. 手动验算：先 Softmax 再取对数

`log_softmax` 的底层到底做了什么？它就是对你的分数**先 Softmax，再取对数**，算到这儿就停。既然只有两步，那我就手动走一遍，看能不能和它一模一样对上。

```python
# 3. 思路二：手动验算（先 softmax，再 log）
# 3.1 创建 softmax 函数对象（这里是函数式写法）
softmax_probs = torch.softmax(output, dim=0)
print('softmax 计算结果：', softmax_probs)

# 3.2 手动算 log，得到对数概率
log_softmax_probs = torch.log(softmax_probs)
print('手动计算对数概率：', log_softmax_probs)
```

先打 Softmax 的结果，你看这三个哥们的概率加起来是不是正好是 1——Softmax 该做的处理它已经做完了。但公式里 Softmax 后面还有个对数，所以我还要手动算一次 log。所谓"手动算 log"，就是对你刚拿到的 Softmax 结果取自然对数。

两个结果都打出来一比：上面那个是一步到位算出来的，下面那个是我们分两步自己验算的，**最终结果一模一样**。

> **结论**：`nn.LogSoftmax(dim=-1)` 的底层就是对输入先做 Softmax、再做 log，两步合一。

把这条结论抄下来，它马上就有用。那"乘以真实概率 $y$、累加、负号"呢？那是新版 `CrossEntropyLoss` 替你办的——你一会儿除了它以外，是不是还得写点别的代码？这就是接下来要思考的点。

## 4. 为什么 Softmax 层会出现在模型里

到这里就能解释一个细节了：为什么我这个模型里居然出现了 Softmax 层。

如果你用 RNN 接多分类交叉熵，直接写 `CrossEntropyLoss` 就完事了，那个 Softmax 我们从来都是直接忽略、根本不写。为什么可以忽略？因为 `CrossEntropyLoss` 的底层自己就带着 Softmax 和 log，你把它们再写一遍，等于算了两遍。

而现在课件里给的是**旧版写法**：

$$
\text{log\_softmax} = \log\big(\text{Softmax}(x)\big)
$$

旧版要你自己把 Softmax 和 log 这一截手工写出来，所以模型定义里就得显式放一个 `nn.LogSoftmax`。等换成 `CrossEntropyLoss`，这一层立刻变成多余，删掉不影响任何结果——这就是我一会儿标注的「优化二」。

> **提示**：实际开发里我们写新版；但前人留下的代码里旧版写法很多。所以这个函数我的要求不高——**你能看懂别人写的代码即可**。
