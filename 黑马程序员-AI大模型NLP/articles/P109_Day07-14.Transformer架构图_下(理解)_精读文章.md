# Transformer 架构图右半边逐项拆解：从目标词嵌入到 Softmax 输出

上一次把架构图左边那坨画到了 `Nx`，这一次接着往右画。右边这一坨的信息量比左边大，铺垫也多——尤其有一个组件是左边完全没有的，名字里那个「掩」字，就是后面反复要拿出来做文章的地方。

先把右边这条链路摆在眼前，然后从下往上一项一项写。

```text
                          ┌──────────────────────────┐
                          │    Softmax（概率归一化）   │
                          ├──────────────────────────┤
                          │   Linear（映射到词表维度） │
                          ├──────────────────────────┤
                          │   Add & Norm             │
                          │        ▲                 │
                          │   Feed Forward（前馈）    │
                          ├──────────────────────────┤
       编码器输出 ───────► │   Multi-Head Attention   │
       （语义向量 C）      │   （多头注意力）          │
                          ├──────────────────────────┤
                          │   Add & Norm             │
                          │        ▲                 │
                          │   Masked Multi-Head      │
                          │   Attention（掩码多头）   │
                          ├──────────────────────────┤
                          │   Positional Encoding    │
                          ├──────────────────────────┤
                          │   Output Embedding       │
                          ├──────────────────────────┤
                          │   Outputs（目标文本）     │
                          └──────────────────────────┘
```

读图说明：目标文本从最底下进来，先换成词向量、再加位置信息，然后进掩码多头注意力；紧接着这一层做多头注意力，它的两条输入一条来自下面、一条来自左边编码器的输出；再往上走残差归一化加前馈，最后经线性层压到词表维度、Softmax 转成概率。上下的 `Nx` 表示这一整套要重复堆叠。

## 目标文本嵌入层

右边第一个组件不叫 Input Embedding 了，它叫 **Output Embedding**，中文叫**目标文本嵌入层**。

> **定义**：目标文本嵌入层的英文写作 Output Embedding，作用是**把输出的目标语言文本转成词向量**，和源文本嵌入层的作用是一样的。

放到英译法案例里说，就是把**法语单词**转成词向量，方便解码器处理。

这里有一个地方极容易把人绕晕，必须一次说清：**这个法语句子，模型是知道的**。整条链路上有两类法语——一类是已经作为标签句子喂进来的已知法语，另一类是被要求一步步预测出来的法语。目标文本嵌入层处理的是**已知的法语**，也就是用来当训练标签的那个句子。别晕。

## 位置编码：给输出词向量换颜色

再往上，还是位置编码，英文写作 Positional Encoding，和左边那个是同一个东西，作用一个字都不用改。

> **定义**：输出侧位置编码的作用，是**给输出词向量加上位置信息**，让模型懂得输出的顺序。

用我的话讲，这一步其实就是**给输出词向量换颜色**。换颜色不是真去染个色，而是让每个位置带上一层自己的标记，模型看见标记就知道谁在前、谁在后。左边已经用大白话讲过一遍了，这边就不再重复讲一遍白话，记住一个作用即可。

## 掩码多头注意力层

接下来该哪一层了？`Masked Multi-Head Attention`，**掩码多头注意力机制**。这是右边这一坨里真正的新东西。

先说它的作用：**防止偷看未来的词。**

「掩码」这个词的全部秘密就在那个「掩」字上。什么叫防止偷看未来的词？举个例子。假设一个法语句子有八个单词，你正在生成第三个法语单词。这时候只允许你看第一个和第二个法语单词，这叫已知；第三个往后的，一律不给你看。

那如果不掩码会怎么样？这事情其实很严重：我在训练的时候，是把整个法语的八个单词全都告诉你了。既然正确答案就摆在旁边，模型完全可能绕开学习过程，直接把这个正确答案学会、往对应位置一丢——那就等于抄答案，什么也没学会。

> **易错点**：掩码不是为了省算力，而是为了**堵住抄答案的路径**。把未来词遮住，模型在预测第三个词时只能靠前两个词和编码器给的语义信息去推，这才练出了真正的生成能力。

换成白话说这条机制：**解码器是一步步、一步步生成输出的，所以它只能用已经生成的词，不能用未生成的词。**

具体到刚才那个例子上，你要预测第三个法语词，那么前两个你可以看，后边的这些你看不着——不让用，就是不让用。

## 多头注意力层：让解码器盯住编码器的输出

掩码注意力讲完，再往上是三个字：Add & Norm？不是——先上来的是**多头注意力机制**，Multi-Head Attention。

它的作用一句话：**让解码器关注编码器输出的内容。**

这句话怎么解读？你看这一层的输入就明白了。它接收的数据除了下面这一坨传上来的东西，还有两条线从左边一直连过来，连到编码器那边去。所以这一层的注意力，干的就是让解码器去关注编码器已经处理好的那一份输出。

把它理解成**中间语义向量 $C$** 就顺了：编码器处理完，把语义向量 $C$ 传到这一层，让解码器接着对它做一次加工。

再举个例子。翻译时，解码器每生成一个法语词，都得**盯着处理后的英文词意**，这样做的目的有两个：

- **确保翻译准确**；
- **找出对应关系**。

第二个目的听着抽象，其实前面早就见过了。还记得英译法案例最后画的那张**注意力权重分布图**吗？英语词和法语词的关联越强，颜色就越浅。那一张图做的就是这件事——找对应关系。所以注意力层不只是收下 $C$，它还在英文词意和正在生成的法语词之间建立一份权重分布。

## 残差连接、规范化与前馈全连接

再往上那一层，跟左边一模一样：`Add & Norm` 加上 `Feed Forward`，然后外面套 `Nx`。翻成一句话就是：**和编码器里的逻辑一样。**

既然是同一套逻辑，这里就不再啰嗦第二遍，只把每一段的职责复述清楚：

- **残差连接**——把输入和输出加在一起，防止信息被削掉太多；
- **归一化**——把数值规范到可控范围，确保训练稳定；
- **前馈网络**——强化特征；
- **`Nx` 重复堆叠**——重复堆叠、加深模型。

讲到这里，右边这一坨里和左边重复的部分就结束了，剩下的两个操作是这一讲最后的新内容。

## 线性层：把向量压到词表维度

第一个是 **Linear**，也就是**线性层**。

> **定义**：线性层的作用是**把解码器输出的向量调整成词表大小（`vocab_size`）的维度**。

为什么非要调成词表大小？这不就是我们做英译法时那个 `114345` 干的事吗。举个例子：词表里有一万个词，那么就把解码器送来的向量转成**一万维**，让**每一个维度对应一个词的概率分数**。

> **易错点**：线性层输出的叫**概率分数**，不叫概率。分数可以是任意实数，可以大于 1，也可以为负，它还不是一个能拿来选词的分布。

想要真正的概率，就得再往下走一层。

## Softmax 层：概率归一化与选词

这一层终于轮到了 **Softmax**。它在这里的角色是**归一化层**，也叫**激活层**（它本身是激活函数）。作用就一句话：**把线性层输出的数值转成概率，并且概率总和为 1。**

有了每个词的概率，模型就知道**该选哪个词作为输出**。到这里，整张架构图的最终效果就有了。

```text
   解码器输出向量 ──► Linear ──► 10000 维概率分数 ──► Softmax ──► 10000 个概率，总和 = 1
                                                                        │
                                                                        ▼
                                                              取概率最高的词输出
```

读图说明：线性层负责把维度对齐到词表，Softmax 负责把分数变成总和为 1 的概率分布，最后由概率决定这一轮输出哪个词。

## 整个架构的核心与面试讲法

架构图上下两侧的每一个组件，到这里作用就全标完了。最后收一句总纲，这一句是要背下来的。

> **结论**：Transformer 整个架构的核心是——**通过注意力机制去抓关联，通过多层堆叠去挖数据的深度，通过残差归一化去稳训练。**

记成一句顺口溜：**注意力抓关联，多层堆叠挖深度，残差归一化稳训练。** 残差归一化为什么能稳训练？因为多头之后出来的是多个维度的结果，既要把这些结果做一次汇总，又要让它们统一到同一套规范标准上，训练才不会跑偏。

别人问「Transformer 架构图能画出来吗」，你就按这个思路跟他说：先说核心是三件事，然后说总体流程——**输入文字 → 词嵌入 → 位置编码 → 编码器（多层）→ 解码器 → 线性层 → Softmax → 输出概率**。把这条流程再背一遍，讲的时候就不会散。

再往下问，重点一定落在注意力的细节上。这里我先给你画一个大大的对号，然后把对号撤掉，问你一个问题：**解码器的多头注意力跟编码器的多头注意力，作用一样吗？**

**完全不一样。** 名字都叫 Multi-Head Attention，意思完全不同：编码器里那一层做的是句子内部的关联，解码器里这一层是去关注编码器输出的内容，条件是从编码器那边传过来的。别人就喜欢在这儿做文章——先问编码器有多头注意力、解码器也有多头注意力层，然后问这两个作用一样吗。这个问题必须能自己讲清楚。

> **提示**：整张图至少值 500 块钱，图里面的东西要背。面试的时候别只是嘴上说，能手绘出来写成这个样子，你就太厉害了。
