## RNN 的三层结构与循环的含义

RNN 全称 Recurrent Neural Network，中文叫循环神经网络（recurrent neural network，RNN）。它在深度学习部分已经简单介绍过，当时梳理的三层是：**词嵌入层（embedding layer）、循环网络层（recurrent layer）、输出层**。

三层各干什么，先复习一遍。

第一个问题：词嵌入层的作用是什么？把文本转成词向量。说白了就是把文本转成数值——大模型底层只认识数字，它不认识你的语言。

第二个问题：循环网络层干什么？就是 RNN 里面那一层，它是**基于上一时刻的隐藏状态和本次的输入，得到本次的隐藏状态以及本次的输出**。还记得当时让大家背的那 12 个参数吗？一共 12 个：传出两个、返回两个，而每一次传参都带三个参数，$3 \times 4 = 12$。

> **提示**：想翻旧账的话，这些内容都在深度学习随堂资料 day07 的图片里。当时那张图和我们这一讲画的 RNN 图解是同一件事，12 个参数的图就在里面。

那么，既然词嵌入层已经把文本变成了数值，为什么下一层叫**循环**网络层？循环体现在哪儿？

> **定义**：循环网络层的「循环」，指的是这一层实质上只有一个神经元，而它**上一次的输出会作为下一次的输入**，如此反复执行。

就一个神经元，反复地做同一件事，所以叫循环。这也是整个 RNN 的立身之本。

## 时间步展开：h 与 y 的传递链

下面把 RNN 沿时间步展开，看成一个平铺的网络结构。

```text
   h0 --> [ 循环单元 ] --> h1 --> [ 循环单元 ] --> h2 --> [ 循环单元 ] --> h3
          ^        |               ^        |               ^        |
          |        v               |        v               |        v
         x1       y1              x2       y2              x3       y3
```

上图是同一套参数在时间上反复复用：每个时间步都吃一份新的输入和一个上一时刻的隐藏状态，吐出新的隐藏状态和该步的输出。

> **易错点**：图上横着画了三个、五个方块，但这里**不是三个、五个神经元，而是一个神经元在重复执行**。

对着这张图把数据流走一遍。第一次输入记作 $x_1$；在它之前还有一个 $h_0$，$h_0$ 是**上一时刻的隐藏状态**，用来记录历史信息。基于 $h_0$ 和 $x_1$ 得到 $h_1$；如果需要输出，再基于 $h_1$ 得到 $y_1$。下一步拿 $y_1$ 作为输入，结合 $h_1$ 得到 $h_2$；基于 $h_2$ 得到 $y_2$。再往下，$y_2$ 和 $h_2$ 得到 $h_3$，$h_3$ 再得到 $y_3$，依次往后走。

把中间的算式摊开就是：

$$
h_t = \sigma(W_{hh}h_{t-1} + W_{xh}x_t + b_h)
$$

$$
y_t = \text{softmax}(W_{hy}h_t + b_y)
$$

也就是说，$h_1$ 由「$x_1$ 加权求和、$h_0$ 加权求和，再过激活函数」得到；$h_2$ 同样由 $y_1$ 与 $h_1$ 加权求和后过激活函数得到，$y_2$ 再从 $h_2$ 来。**循环就是这么解读的**。

于是 RNN 网络结构的特点可以收成这么几条：由输入层、隐藏层、输出层组成——说得更确切些，输入层之后是隐藏层，隐藏层往下再分成两部分，一部分是词嵌入层，另一部分是循环网络层，最后给出输出层；并且**上一时间步的输出作为下一时间步的输入**，也就是上一步的 $y_1$ 成为这一步的输入。

## 每个时间步的两个输入与两个输出

把 RNN 的参数账算清楚，只要数每个时间步有几个输入、几个输出。

每个时间步的输入有两个：

| 输入 | 说明 |
| --- | --- |
| 数据端的输入 | 当前这一步的输入数据，如 $x_1$ |
| 隐藏层的输入 | 上一时刻的隐藏状态，如 $h_0$ |

每个时间步的输出也有两个：

| 输出 | 说明 |
| --- | --- |
| 数据端的输出 | 当前这一步的数据输出，如 $y_1$ |
| 隐藏层的输出 | 当前这一步的隐藏状态，如 $h_1$ |

每个时间步的两进两出各自都带三个参数，四个 $3$ 加起来正好是 $3 \times 4 = 12$ 个参数——这就是前面反复提到的 12 个参数的来历，一会儿真正调用模型时传的就是它们。

## RNN 的作用与序列数据

RNN 的作用，第一条是**能够连续性地输入序列数据**：因为它是循环的，一个一个往里扔就行了。

第二条是**提取特征**：人类的语言、语音特别适合用 RNN 处理。原因在于语言和语音都是**序列数据**——下一个字对上一个字有依赖，你必须从前往后一个一个传、一个一个解析，所以它天然适合用 RNN 来做。

> **定义**：序列数据指后面的数据对前面的数据有依赖，这样的数据才叫序列。

RNN 模型广泛用于 NLP 的各种领域和任务：文本分类（判断这篇文章属于体育类、财经类还是新闻类）、情感分析（好评还是差评）、意图识别等等。

### 意图识别：判断用户到底想干什么

意图识别后面会专门讲案例，因为面试会问。它要解决的问题是：用户进来了，他要做什么。

拿招商银行的 App 举例。打开之后里面有个「小招」助手，你点开小招助手，还没做任何输入，它就会问「小主您是要干嘛呀」——存钱、理财、买基金，上面摆着一排选项。它要在你开口之前判断你可能要做什么，然后基于这个判断给出相应决断，这就是意图识别。

我们后面做案例也要做这件事：未来用户来输问题查数据时，我们要判断用户输的是专业领域的问题还是通用知识的问题，从而决定走不同的模型。

### 一个例子走完整条链路

以「what time is it」这句话为例。第一步先分词；然后注意，**RNN 是一个时间步输入一个词，每次只收一个单词**——这正是它被称为循环神经网络的原因。

```text
what   time   is   it
  |      |     |    |
  v      v     v    v
 h0 ->  h1 -> h2 -> h3 -> h4 -> h5
  |      |     |    |     |     |
  v      v     v    v     v     v
 O1     O2    O3   O4    O5
(time)  (is)  (it)  ...
```

上图是这句话的处理时序：每个词依次喂进去，隐藏状态一路往右传，右上角写出该步应有的输出。

对着图看一遍：第二步是把 `what` 输给 RNN 产生 $O_1$，下一次 $O_1$ 就作为本次的输入；同时最开始还有一个 $h_0$，$h_1$ 是基于 `what` 和 $h_0$ 算出来的，基于 $h_1$ 又能算出 $O_1$。按这个节奏，`time` 扔进去，结合 $h_1$ 算出 $h_2$，这一步的 $O_2$ 位置应该是 `is`；再往下 `is` 进去算出 $h_3$，对应位置是 `it`，依此类推。

这条链的关键在于**隐藏状态的记忆**：

> **结论**：神经元循环的次数越靠后，它记住的状态就越多——之前发生过的事情会被一路记下来。

课上的类比是看电视剧。假设一共 40 集，你看到第二集，脑子里只有第一集的剧情，因为第二集还没看完；等你看到第三集，脑子里就有了第一集和第二集的剧情，再结合第三集继续往下；看到第四集时，前三集的剧情你都已经知道了。RNN 的隐藏状态就是这个「越往后知道的越多」的过程。

重复到所有词处理完，最后拿到的是最终隐藏层输出的 $O_5$，它用来解析用户意图。如果意图识别是 18 个分类，18 分类属于二分类还是多分类？多分类。那该用哪个损失函数？**Softmax**：它把输出映射成 18 个分类各自的概率，取概率最高的那一个作为最终结果。$O_5$ 经过 Softmax 转成概率，就能判断用户到底属于 18 个分类中的哪一个。这些任务用 RNN 都能做，也正是循环网络存在的意义。

## 两条必须记住的结论

关于 RNN 的简单介绍，收成两句话：

> **结论**：第一，RNN 主要处理序列数据；第二，RNN 由输入层、隐藏层、输出层组成，其中隐藏层主要分为词嵌入层和循环网络层。

第二句特别值得停一下。单看输入、隐藏、输出这三层，你会发现它像极了人工神经网络（artificial neural network，ANN）。而隐藏层里放什么，决定了它变成谁：如果里面是一个卷积、一个池化，那就是 CNN；如果里面是一个词嵌入层、一个循环网络层，那就是 RNN。所以不管是 C 还是 R，**它们的底层都是依赖 ANN 的**——这一层关系理清了，前面深度学习的内容就和这里接上了。
