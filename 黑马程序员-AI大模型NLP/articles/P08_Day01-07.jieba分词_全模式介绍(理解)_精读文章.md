先给 `demo01` 那一整段加上 `TODO` 注释，Ctrl+C、Ctrl+V 挪到下面，然后把编号往下推一位：`TODO 1` 换成 `TODO 2`。

`TODO 2` 的措辞要改两处：

- 不再是"演示 jieba 精确分词模式"，而是"演示 jieba 全模式分词"；
- 适用场景不再是文本分析，而是**关键词提取**——也就是那些**不需要严格分词准确性的场景**。我对你的准确性要求没那么高，只要能把词分出来就行，这种场合就该用全模式。

函数名也从 `demo01` 换成 `demo02`。改的时候一行一行检查，别一口气改完回头发现漏了；或者干脆选中 `demo01` 按 Ctrl+R 做一次替换，也能保证不漏。

## 全模式只改一个参数

关键改动只有一处：`cut_all` 不再是 `False`，而是 `True`。

```python
result2 = jieba.cut(content, cut_all=True)
```

我把这句话说得再直白一点：**所谓全模式，就是把 `cut_all` 换成 `True`，仅此而已。** 打印出来的地址值跟你机器上看到的不一定一样，不用纠结，但它肯定还是一个生成器对象——`cut` 这个函数没换，返回类型就不会变。

后面的代码基本不用动：从生成器中取数据的 `next` 不用动，`for` 遍历不用动，生成器转列表的那一段也不用动。真正要动的是最后那一行语法糖——`lcut` 里的 `False` 换成 `True`。

```python
    # 4.2 思路二: 切词时直接返回 list(语法糖)
    list2 = jieba.lcut(content, cut_all=True)
    print(f"list2: {list2}")
```

> **提示**：第一次学这套代码的时候，我们用了很长时间一行一行写；第二次只需要改一个地方。学编程只有第一次是难的，把内容学会了，后面再学就轻松了。

## 全模式与精确模式的结果对比

把结果放在一起看，全模式明显比精确模式**多**。还是那句"传智教育是一家上市公司"：

- 精确模式给的是完整的词：`传智`、`教育`、`是`、`一家`、`上市公司`、……；
- 全模式把"能拆的全给你拆出来"：`传智` 拆出一个 `传`、一个 `智`；`上市公司` 拆出一个 `上市`，后面还跟着一个 `公司`；此外还有 `教育`、`是`、`一家` 等等一大堆。

| 原文片段 | 精确模式 | 全模式 |
| --- | --- | --- |
| 传智 | `传智` | `传`、`智` |
| 上市公司 | `上市公司` | `上市`、`公司`（`上市公司` 本身也在） |
| 教育 / 是 / 一家 | `教育`、`是`、`一家` | 同样切出，且与更多碎片共存 |

```text
两种模式的切分层次对比

  原文:  传智教育是一家上市公司

  精确模式: |传智|教育|是|一家|上市公司|
                —— 只给完整的词, 粒度较粗

  全模式:   |传智|传|智|教育|是|一家|上市公司|上市|公司| ...
                —— 长词连同它的所有子词一起给, 粒度最细
```

读图说明：精确模式每个字只归属一个词；全模式允许同一个字同时出现在多个候选词里，`上市公司` 与 `上市`、`公司` 会同时出现在输出中。

一句话总结这个差别：**精确模式还要筛选一下哪些切法更符合人的习惯，全模式不筛，能成词的都扫描出来。**

## 全模式的歧义问题

全模式速度快，但代价是它**不能消除歧义**。

看第一个词"传"，它切出来是 `传`——`传` 是啥？可能是 `传智`，但同样可能是 `传球`，也可能是 `传奇`。你光看到一个 `传`，机器没法替你判断这里到底是哪一个；`智` 也一样，`智慧`、`智能`、`智力`，组合多得是。

```text
全模式的歧义来源示意

  原文: 传智教育是一家上市公司
  全模式输出中包含的短碎片:
      传   → 传智 / 传球 / 传奇 / ...
      智   → 智慧 / 智能 / 智力 / ...
      上市 → 上市 / (与"公司"拼回"上市公司")
  每个碎片都可能归属多个不同的词, 单看碎片无法确定原意
```

读图说明：全模式保留了大量单字与短词碎片，而这些碎片本身可以归属到多个候选词，歧义信息因此被带进了分词结果里。

所以全模式在实际项目里用得相对少些：它适合"关键词提取"这类对准确性要求不高的场景，哪怕切出来的词不一定符合我们的应用习惯，也不影响使用；但要做严谨的文本分析，还得回到精确模式。

拿这个例子反过来看会很直观：面对"传智教育是一家上市公司"，精确模式给你的是完整的词，你拿去统计词频、做特征，每个词都是有意义的；全模式给你的是 `传`、`智`、`上市`、`公司` 加上完整的词混在一起，`传` 和 `智` 这类单字碎片一旦进了特征集，统计出来的就不再是"哪个词重要"，而是"哪个字出现过"。何况 `传` 还可以是传球、传奇，`智` 还可以是智慧、智能——同一个字在不同语境下的含义被混在一起，这就是"不能消除歧义"的后果。

## 完整脚本

```python
import jieba


# TODO 1 定义函数, 演示 jieba 精确分词模式, 适用于文本分析
def demo01():
    content = "传智教育是一家上市公司"
    result1 = jieba.cut(content, cut_all=False)
    print(f"result1: {result1}")
    list1 = jieba.lcut(content, cut_all=False)
    print(f"list1: {list1}")


# TODO 2 定义函数, 演示 jieba 全模式分词, 适用于关键词提取(不要求严格的分词准确性)
def demo02():
    # 1 定义待分词的文本内容
    content = "传智教育是一家上市公司"

    # 2 使用 jieba 进行全模式分词, cut_all=True 即全模式
    result2 = jieba.cut(content, cut_all=True)
    print(f"result2: {result2}")          # 生成器对象

    # 3 从生成器对象中获取所有的分词结果(遍历方式)
    for item in result2:
        print(item)

    # 4 切词时直接返回 list(语法糖)
    list2 = jieba.lcut(content, cut_all=True)
    print(f"list2: {list2}")


# TODO 6 测试代码
if __name__ == '__main__':
    # 测试 jieba 精确模式分词
    # demo01()
    # 测试 jieba 全模式分词
    demo02()
```
