# Transformer 位置编码层的原理：公式、参数与手算全过程

先看几个句子，你就能明白这一讲到底要解决什么问题：

- 「在教室中间唱《我爱中国》」——「中」放在不同的位置，整句话的意思就变了；
- 「你欠我 100 元」和「我欠你 100 元」——同样的词，语序一换，债权人和债务人调了个个儿；
- 「小龙女来到了杨过生活过的地方，她说：我也想过过过过过过的生活」；
- 「下雨天路滑，一把把把把住了」；
- 「明天校庆，校长说：明天开会休假，除了校徽，别别别的」。

这些句子读起来好玩，但它们指向同一件事：**同词不同义在语言里是常态，而区分它的关键往往是顺序**。既然顺序这么重要，我们就得问一句：Transformer 知道顺序吗？

## 1 位置编码要解决的问题

### 1.1 为什么一定要给文本加位置信息

我们自己在图上画过 Transformer 的整体结构，从那儿往下看就能发现问题出在哪。

**编码部分**里做的是多头注意力（Multi-Head Attention）。注意，这里没有任何掩码（mask）动作：每个词都能看见序列里的每一个词。掩码只出现在生成侧——生成第三个词的时候，我看不到第三个词以及它后面的内容，后面的信息是被挡住的。但编码部分不一样，它是全可见的。

全可见会带来一个后果。假设现在处理的是「爱」这个字，而我手上同时有两句话：

```text
我爱你   →  处理「爱」时，它看到 我 和 你
你爱我   →  处理「爱」时，它看到 你 和 我
```

两种情况下，「爱」这个位置拿到的可见词集合完全一样，都是「我」和「你」。那 Transformer 就懵了：到底「我」在「爱」的前面，还是「你」在「爱」的前面？它全都看得见，可谁先谁后，它不知道。

> **结论**：Transformer 的结构本身不自带词顺序的感知能力。它必须有额外的输入告诉它「谁在前、谁在后」，这个额外输入就是位置编码。

### 1.2 位置编码器的作用

军训排队这件事最能说明问题。你刚上初一或者高一，第一天军训，教官第一件事就是让大家按身高排队站位。第一天你能把男生整个队形记住吗？记不住。但教官心里是有数的，谁在谁前面、怎么根据身高去调，他都清楚。

对你来说，要做的事情其实非常简单：**你只需要记住你站在谁的后边**，那个人站哪，你就跟着站哪。整支队伍瞬间就排好了；否则就是一锅乱枪。

位置编码干的就是这件事：给每个词贴一个顺序标签，让模型看到语序。

去火锅店吃饭是同一个道理。生意火爆的店先给你一个号，它根本不知道你是谁，它只认号——几号在前、几号在后。而学校门口那些小摊就不一样了，谁先来谁后到，全靠自己说，插个队也没人计较，最后谁先吃上还真不一定。

> **定义**：位置编码（Position Encoding，PE）就是把「谁在前、谁在后」的信息，硬塞进词向量里去的一个机制。

注意「硬塞」这两个字——它不是另外挂一份顺序表在旁边，而是直接把位置信息加进词向量本身，让词向量自己带上顺序这件事。

论文里的表述是：给数据添加位置信息是通过位置编码来实现的。位置编码函数以当前元素在序列中的位置作为输入，然后乘以一组预定义的常数（位置常数），生成对应的向量。

```text
词向量（语义）   ──┐
                   ├──► 相加 ──► 带位置信息的词向量 ──► 送入编码器
位置编码（顺序） ──┘
```

读图：左边两路输入形状相同，一路是词本身的语义向量，一路是它所在位置的编码向量，二者逐元素相加后成为编码器真正的输入。

## 2 位置编码公式与参数含义

### 2.1 正弦余弦公式与奇偶维度

论文给出的公式长这样：

$$PE_{(pos,\,2i)} = \sin\!\left(\frac{pos}{10000^{\,2i/d_{model}}}\right)$$

$$PE_{(pos,\,2i+1)} = \cos\!\left(\frac{pos}{10000^{\,2i/d_{model}}}\right)$$

第一次单看这个公式，你肯定是看不明白的，只会觉得晕。所以下面我们把它拆开，一个参数一个参数地过。

先看关于 `2i` 和 `2i+1` 的结构。Transformer 用的是两种三角函数：一个是正弦函数 sin，一个是余弦函数 cos。公式把词向量的维度分成了两类：

- `2i` 这一路是**偶数维度**。为什么它一定叫偶数维度？因为不管 i 取几，`2i` 一定能被 2 整除；
- `2i+1` 这一路就是**奇数维度**，不用多说。

> **提示**：偶数维度用 sin、奇数维度用 cos，这是这条公式最容易被记反的一处。记住维度的奇偶是由 `2i` / `2i+1` 决定的，而不是由 pos 决定的。

### 2.2 四个参数：pos、i、d_model、10000

`PE` 不用解释，它指的就是位置编码（position encoding）这个函数。它本质上是一个关于「单词位置」和「奇偶特征」的函数。剩下要弄清的是四个东西。

**pos**：词在句子里的位置。从 0 或从 1 开始数，两种写法都有，一般从 0 开始数。

举例：「我爱吃西瓜」，标一下位置——从 0 数的话，「我」是 0，「爱」是 1。所以「爱」的 `pos` 就是 1。

**i**：维度的索引。举个例子，512 维的词向量，i 的取值是多少？0 到 255，不是 0 到 512。

为什么是 0 到 255？因为 `2i` 要覆盖 0 到 511 这 512 个位置。i 每加 1，`2i` 和 `2i+1` 就同时往前走两格：i 取 0，得到维度 0 和 1；i 取 1，得到维度 2 和 3；i 取 2，得到维度 4 和 5。**一个 i 刚好锁住两个维度位置**，所以 i 的范围就是维度数除以 2。

用 i 的上界验证一下：512 维时 i 最大到 255。255 是奇数，走奇数维度这一路，`2 × 255 + 1 = 511`；同一个 i 在偶数维度这一路是 `2 × 255 = 510`。510 和 511 一起出现，正好把最后两个维度补齐。

> **易错点**：i 不是「第几个维度」，而是「第几组维度」。写成 `2i` 的时候，这个下标指的是词向量的第 `2i` 维；i 自己只走到维度数的一半。

**d_model**：词向量的维度，比如 512。这个命名不是随手起的，公式里写的就叫 `d_model`，词向量维度就叫这个名字，写代码时变量名也照它写。

`d_model` 和 i 的关系很直接：i 的范围就是 `d_model / 2` 得来的。

**10000**：它出现在指数的底数位置上，整个指数是 `2i / d_model`，也就是 $10000^{\,2i/d_{model}}$。

> **注意**：这里的 `2i/d_model` 是**多少次幂**，不是异或运算。`d_model` 是一个整体符号，不要拆开理解。

### 2.3 周期缩放因子：i 越大周期越长

`10000^{2i/d_model}` 这个量叫**周期缩放因子**。它的作用是让不同的 i 对应不同的周期。

先固定住分母：`d_model` 是写死的，我们还是取 512。那 `2i` 越大，`2i/512` 这个比值就越大。

- 假设 `2i = 100`，那么比值是 $\frac{100}{512}$，大约是 $\frac{1}{5}$；
- 假设 `2i = 500`（i 取 250 就能到），那么比值是 $\frac{500}{512}$，已经非常接近 1 了。

比值的差别，直接决定底数被开方还是被原样保留：

- 比值接近 1 时，$10000^1 = 10000$，这个数还是它自己，**数值很大**；
- 比值是 $\frac{1}{5}$ 时，$10000^{1/5}$ 相当于对 10000 开五次方，**这个数会变得很小很小**。

所以结论是：

> **结论**：i 越大，周期缩放因子的指数越大，整个因子数值越大，对应维度的周期就越长。

## 3 手算位置编码：pos = 2、d_model = 4

理论摆完了，得动手算一遍才知道自己是不是真懂了。为了好算，我们把词向量维度从 512 换成 4——实际开发里当然还是 512。

设定：句子位置 `pos = 2`（也就是第二个词），词向量维度 `d_model = 4`。

先定 i 的取值范围。约束是 `2i < 4`，所以 `i < 2`，i 只能取 **0 和 1**。

### 3.1 i = 0：偶数维度与奇数维度的两个值

i 取 0 时，奇偶两路都要算。

先看指数部分：`2i = 0`，`d_model = 4`，所以 `2i / d_model = 0/4 = 0`，于是 $10000^{0} = 1$。指数化成 1，整个分式就退化成 `pos / 1 = pos = 2`。

- 偶数维度：$PE_{(2,0)} = \sin(2) \approx 0.909$
- 奇数维度：$PE_{(2,1)} = \cos(2) \approx -0.416$

其中 $\cos(2)$ 是一个约等值，取 $-0.416$。

### 3.2 i = 1：sin 与 cos 的取值

i 取 1 时，`pos` 依然是 2，但指数变了：`2i / d_model = 2/4 = 1/2`。

于是分母变成 $10000^{1/2}$，也就是对 10000 开平方，结果是 100。所以这一路算的是 $\sin(2/100) = \sin(0.02)$：

- 偶数维度：$PE_{(2,2)} = \sin(0.02) \approx 0.020$
- 奇数维度：$PE_{(2,3)} = \cos(0.02) \approx 0.998$

### 3.3 四个数字拼成位置编码向量

现在 i 从 0 走到 1，维度下标正好凑齐 0、1、2、3 四个，得到位置编码向量：

| 维度下标 | 公式 | 计算结果 |
| --- | --- | --- |
| 0 | $PE_{(2,0)}=\sin(2)$ | $0.909$ |
| 1 | $PE_{(2,1)}=\cos(2)$ | $-0.416$ |
| 2 | $PE_{(2,2)}=\sin(0.02)$ | $0.020$ |
| 3 | $PE_{(2,3)}=\cos(0.02)$ | $0.998$ |

这一步之后，位置编码就真正算出东西了：词向量的维度是几，就要算出几个数——词向量 4 维，就算 4 个数；词向量 5 维，就算 5 个数。然后拿着词向量那几个数，和位置编码这几个数**逐个相加**，得到的就是加了位置信息之后的新词向量，再交给编码器。

## 4 为什么用三角函数：位置平移的线性组合

用三角函数最重要的一个优点，是**任意平移都可以表示为线性函数**，计算大大方便，而且不受序列长度影响。

这句话有点抽象，我们换成具体数字看。假设现在要算 $\sin 5$，我要不要把 $\sin 5$ 从头到尾按公式重新推一遍？不需要。因为 5 可以拆开：

$$5 = 2 + 3$$

套两角和公式：

$$\sin(2+3) = \sin 2 \cdot \cos 3 + \cos 2 \cdot \sin 3$$

而 $\sin 2$、$\cos 2$、$\sin 3$、$\cos 3$ 这些值，前面算 0、1、2、3 这些位置的时候都已经算过了。5 也等于 $1+4$，同样能用已知值乘出来。所以算第 5 个位置时，我根本不用把公式再走一遍，直接把前面算出来的值乘一乘就行，**计算量被大幅节省**。

这就是三角函数用在这里的原因，也是位置编码「看似复杂、其实简单」的地方——后面我们总结它的好处时会专门回到这一点。
