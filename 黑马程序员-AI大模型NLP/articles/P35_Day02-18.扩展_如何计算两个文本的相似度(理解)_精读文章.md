# 文本相似度计算：切词、词频向量与距离度量

n-gram 特征写到这儿，理论上接下来该轮到文本长度规范了——长度过长的截断、长度过短的补齐。但在那之前，我们先插一段扩展知识，因为将来你很可能被问到这么一道面试题：**如何计算两段文本的相似性？**

先看两句现成的话。第一句是"今天天气很好，适合旅游"，第二句是"今天天气不是特别好，下雨了，适合睡觉"。你一眼就能看出这两句有一定相似度，可轮到"到底相似多少"，就没法下手了——"一定程度"是多大？怎么把它变成一个数？

这道题不写好，将来面试官一追问就卡住了。所以我把整套思路拆开给你走一遍，你照着走就能自己算出来。

## 1. 切词：相似度计算的前置步骤

要算两段文本的相似性，第一个动作一定是切词。不切，你算不了。

为了算得清楚，我把两段文本换短一点（句子长了只是数频次麻烦，道理一样）。切词之后：

```text
文本 1 切词后：我  是  黑马  人  我
文本 2 切词后：你  是  黑马
```

有人会问：文本 1 里为什么多了一个"我"？这是我故意多加的。加它的用意是让两句话不只是措辞不同，连同一个词出现的次数也不一样——只有这样，"统计频次"这一步才看得出意义。步骤本身和你手里真实的句子完全一致，只是切完词的结果不同而已。

## 2. 思路一：1-gram 下的词汇表与词频向量

先看不加 n-gram 的做法。不加 n-gram，就意味着默认使用 1-gram，每个词都是独立的个体。

第二步是统计词汇，把两句话切出来的词合到一起做**去重统计**：

```text
文本 1 的词：我  是  黑马  人  我
文本 2 的词：你  是  黑马
              ↓ 合并去重
词汇表：     我  你  是  黑马  人
```

去重之后一共 5 个词：把两句话里出现过的词都收进来，"我"已经有了就不再收第二个。这里有个必须记住的细节：

> **易错点**：这份词汇表的顺序是**一旦生成就不能再变**的。这 5 个词的先后顺序本来可以任意排列，"我 是 你 黑马 人"可以，"我 黑马 你 是 人"也可以，但只要你把某一种顺序定为标准，后面两段文本就都必须照这个顺序去排。原因很简单——它是后面那个向量的维度顺序，两句话的维度必须一一对应，否则算差值就是在拿"我"减"你"。

顺序定好之后，第三步是把每段文本按这个顺序套进去，统计每个词出现了几次。文本 1：有几个"我"？两个，所以第一位是 2；有几个"你"？没有，所以是 0；"是"有一个、"黑马"有一个、"人"有一个。文本 2 同理，只是它没有"我"、没有"人"：

```text
维度：      我   你   是   黑马   人
文本 1：     2    0    1    1     1
文本 2：     0    1    1    1     0
```

这两行数字就是两段文本的**词频向量**——一句话被压缩成了一串能参与数学计算的数。到这里，"比较两句话"就变成了"比较两个向量"。

## 3. 欧氏距离：对应维度差值平方和开平方根

有了两个向量，剩下的就是算它们之间的距离。我们之前讲过欧氏距离，这次要把它叫准：

$$d(A,B)=\sqrt{\sum_{i=1}^{n}(a_i-b_i)^2}$$

用大白话说就是：**对应维度差值平方和开平方根**。

> **提示**：刚接触的时候你把它理解成"勾股定理"没问题，它形式上确实是勾股定理在高维的推广。但到了这一步就不要再叫勾股定理了——勾股定理说的是两条直角边，而这里说的是两个 $n$ 维向量在每一个维度上的差，通用叫法是"对应维度差值平方和开平方根"。

把前面那两行数代进去，逐个维度做差：

```text
维度：      我    你    是    黑马    人
文本 1：     2     0     1     1      1
文本 2：     0     1     1     1      0
差值：       2    -1     0     0      1
平方：       4     1     0     0      1
```

$2^2+(-1)^2+0^2+0^2+1^2=4+1+0+0+1=6$，所以两段文本的欧氏距离是 $\sqrt{6}\approx 2.449$。

> **结论**：思路一完整走下来，两段文本的相似度就用一个数 $\sqrt{6}$ 表达了：切词、合并去重定词汇表、按词汇表统计频次得到词频向量、再算两个向量之间的欧氏距离。

顺便说一句，欧氏距离只是其中一种规则。曼哈顿距离、城市街区距离也都有各自的计算方式，你感兴趣可以自己去查。

## 4. 思路二：加入 bi-gram 后的向量与距离

同一个问题，我们把 n-gram 加进去再算一遍，看看有什么变化。

bi-gram 就是 2-gram，所以两段文本要按"连续两个词"重新切开：文本 1 切出"我是""是黑马""黑马人""人我"；文本 2 切出"你是""是黑马"。

```text
文本 1 的 2-gram：我是  是黑马  黑马人  人我
文本 2 的 2-gram：你是  是黑马
```

接下来还是老套路：合并去重，然后套频次。这次词汇表比刚才长一倍——原来的 5 个 1-gram，加上 5 个 2-gram：

```text
维度：    我  你  是  黑马  人  我是  你是  是黑马  黑马人  人我
文本 1：   2   0   1   1    1    1     0     1      1      1
文本 2：   0   1   1   1    0    0     1     1      0      0
差值：     2  -1   0   0    1    1    -1     0      1      1
平方：     4   1   0   0    1    1     1     0      1      1
```

挑几个位置核对一下：文本 1 里"我是"出现 1 次、文本 2 里没有，所以这一维是 $1-0=1$；"你是"只在文本 2 里出现，这一维是 $0-1=-1$；"是黑马"两句话都有，这一维差值是 0，说明这个组合是两段文本共享的特征。

同样按"对应维度差值平方和开平方根"算：$4+1+1+1+1+1=10$，结果是 $\sqrt{10}\approx 3.162$。

> **提示**：1-gram 下的 $\sqrt{6}$ 和 2-gram 下的 $\sqrt{10}$ 不能直接横向比大小，因为这两个距离是在两套不同的特征空间里算出来的——一套 5 维，一套 10 维。要比较相似度，两段文本必须用同一份词汇表、同一套度量。

算完你会发现，加了 n-gram 之后多出来的那几个维度，正是"词与相邻词的搭配"。1-gram 只统计单个词出现了几次，搭配信息被丢掉了；2-gram 把"是黑马"这样的相邻组合单独变成一维，两段文本在搭配层面重合与不重合的地方，就都体现在向量差值里了。所以这套做法"特别好使"——它不需要额外训练什么模型，全靠统计。

## 5. 通用解题步骤与常用距离度量

将来在真实开发里，别人问你"如何计算两个文本的相似性"，你不必从头举例，直接用大白话答就行：

> **结论**：针对两段文本，先切词；切词之后去重合并，得到一份统一的词汇表；再按词汇表统计每个词（以及每类 n-gram）在这段文本里出现的频次；这份频次就是它的词向量；最后计算两个词向量之间的距离，欧氏距离、闵氏距离这一类都可以。

这就是完整答案。除此之外还有几个距离度量，玩得比较多的是下面这几个：

| 度量 | 说明 |
| --- | --- |
| 欧氏距离 | 对应维度差值平方和开平方根，刚才已经算过两遍 |
| 曼哈顿距离（城市街区距离） | 有自己的计算规则，可以自行了解 |
| 闵氏距离 | 与欧氏距离同属一类，换参数即可覆盖不同距离形式 |
| 杰卡德距离（Jaccard） | 注意是"杰卡德"，不是"杰拉德"；本质是共同特征占总特征的占比 |
| 余弦相似度（Cosine Similarity） | 后面讲大模型时还会专门讲 |

> **提示**：这几个里，欧氏距离是必须会的；余弦相似度后面讲大模型还会用到，先留个印象；杰卡德距离简单了解一下它的含义就够了——共同特征占总特征的占比，就这么一句话。

想看就找时间自己搜一搜杰卡德怎么算、余弦怎么算，不看也没有关系，后面讲大模型的时候我们还会再碰到。

## 6. 本讲提到的题目

**题干**（面试题）：给定两段文本，例如"今天天气很好，适合旅游"和"今天天气不是特别好，下雨了，适合睡觉"，如何计算两段文本的相似性？

**解析**：两段文本没法直接比较，必须先转成可以计算的数值形式，再衡量两个数值形式的距离。转换靠切词加频次统计，衡量靠向量距离，具体走四步：

1. 两段文本各自切词；
2. 把切词结果合并去重，得到一份顺序固定、两段文本共用的词汇表；
3. 按词汇表统计每段文本的词频，得到各自的词频向量（也可以把 n-gram 片段一并放进来，扩大词汇表维度）；
4. 计算两个向量的距离，例如欧氏距离——对应维度差值平方和开平方根。

**答案**：以本讲的短样例为例，切词后文本 1 为"我 是 黑马 人 我"、文本 2 为"你 是 黑马"，词汇表去重后是"我 你 是 黑马 人"共 5 维，两段的词频向量分别是 $(2,0,1,1,1)$ 与 $(0,1,1,1,0)$，欧氏距离为 $\sqrt{2^2+1^2+0^2+0^2+1^2}=\sqrt{6}$。若再加上 bi-gram 特征，词汇表扩到 10 维，同样方式算出的欧氏距离为 $\sqrt{10}$。答题时把"切词 → 去重合并 → 统计频次得到词向量 → 算向量距离"这条链路说清楚即可，其中词汇表顺序必须统一，是所有步骤的前提。
