# Word2Vec 的 Skip-Gram 模式：由中心词预测上下文

CBOW 讲完，接着看 Word2Vec 的另一种训练模式：**Skip-Gram**，也叫跳字模式、跳词模式。CBOW 是基于两端去预测中间，Skip-Gram 反过来——**基于中间去预测两端**。

套路还是那一套：输入层、隐藏层的参数矩阵、矩阵乘法、算损失、反向传播、更新权重。整个流程不变，变的只是"谁当输入、谁当目标"。正因为主干完全一致，昨天讲 CBOW 花了半个多小时甚至四十分钟，今天这套东西几分钟就能讲完。编程这件事，只有第一次玩是难的，后面再学都很简单。

## 网络的层与两个输出权重矩阵

先看网络骨架：输入层、隐藏层的参数矩阵，还是那个 $3 \times 5$。

不同之处出在隐藏层之后。CBOW 里，隐藏层的结果只跟一个 $5 \times 3$ 的输出权重矩阵做运算，得到一个预测值；Skip-Gram 里，隐藏层的结果要和**两个 $5 \times 3$ 的矩阵**分别做运算，于是得到**两个预测值**。

这两个预测值各管一边：

- 上面那个，是这个单词**前一个词**的预测；
- 下面那个，是这个单词**后一个词**的预测。

两个权重矩阵的差别只在参数值不同，形状、语义、计算方式完全一样。

## 两个预测值与两种损失合并方式

有预测就得有真实值。这两个词的**真实值我们也是知道的**——它们就是语料里紧挨着中心词的那两个词。所以接下来做的事很直接：算损失。

一个中心词对应两个上下文词，就有两个预测、两个真实，于是产生**两个损失值**。这两个损失怎么合成一个总损失？两种思路都行：

- 第一种，把两个损失**加起来求和**，当作最终损失；
- 第二种，对两个损失**求平均值**。

底层具体用哪种，无所谓，选一个即可。

拿到总损失以后，训练闭环照旧：**先往前更新输出层的参数矩阵，再反向传播更新前面隐藏层的参数矩阵**。两个输出矩阵各自的那份梯度都要回传，隐藏层那个 $3 \times 5$ 的矩阵也一样被更新。

> **结论**：最终的结果仍然是前面那个隐藏层矩阵。第一列是第一个单词的词向量，第二列是第二个、第三列是第三个、第四列是第四个、第五列是第五个。

## 中心词与上下文的配对

现在换个具体例子看 CBOW 与 Skip-Gram 的输入输出差别。取语料里三个词：

```text
hope   set   free
```

CBOW 是这么用的：`hope` 和 `set` 当输入，去预测 `free`——基于两端预测中间。

Skip-Gram 是这么用的：拿 `set` 当输入，去预测 `hope` 和 `set` 两侧的词。**注意方向翻过来了**：同一个词，在 CBOW 里它是输出，在 Skip-Gram 里它就是输入。

> **易错点**：不要凭词本身判断它是输入还是输出。判断依据只有一个——在 CBOW 里，中间那个词是目标；在 Skip-Gram 里，中间那个词是输入，两侧的词才是目标。

用更完整的一句话来看更清楚：语料是 `hope can set you free`，网络里把 `can` 挑出来当中心词，它的前后邻居是 `hope` 和 `set`，这两个就是输出。

## 一次前向计算的过程

以中心词做输入，走完整条链路。以下沿用上一节那个 $3 \times 5$ 的隐藏层权重矩阵和 $5$ 个词的位置编号，中心词在词表中的 One-Hot 是 `0 1 0 0 0`。

```text
              输入层(5)              隐藏层(3)                 输出层
            ┌───────────┐         ┌───────────┐        ┌───────────┐
            │           │         │           │        │ 5 x 3 (上)│──► 前一个词的预测
中心词      │           │  W(3x5) │           │        └───────────┘
0 1 0 0 0 ─►│  输入层   │────────►│  隐藏层   │────────┤
            │           │         │           │        ┌───────────┐
            │           │         │           │        │ 5 x 3 (下)│──► 后一个词的预测
            └───────────┘         └───────────┘        └───────────┘
                                        │
                                        └──► 每列一个词向量，最终取这一列组
```

读图说明：中心词的 One-Hot 与隐藏层权重矩阵相乘得到 $3 \times 1$；这一个 $3 \times 1$ 分别喂给上下两个 $5 \times 3$ 矩阵，各得到一个 $5 \times 1$ 的预测值，分别负责前一个词和后一个词。

### 输入层

输入层放的是中心词的 One-Hot。比如中心词是看，它的向量是：

```text
看  ->  0 1 0 0 0
```

这就是我们所说的"输入层"，它跟前面几个例子里输入层的地位一样，只是这次只放一个词，而不是两个词相加。

### 隐藏层

隐藏层需要 $3 \times 5$ 的权重矩阵，就是上一节那个矩阵原封不动搬过来。

$0\,1\,0\,0\,0$ 与它做矩阵乘法，只有第二个位置是 1，所以结果就是**取权重矩阵的第 2 列**：

$$W_{\text{隐藏}} \, x_{\text{中心词}} = (3 \times 5)(5 \times 1) = 3 \times 1 \;\longrightarrow\; \begin{bmatrix} w_{12} \\ w_{22} \\ w_{32} \end{bmatrix}$$

隐藏层出来的就是这三行的那一列数字，$3 \times 1$。

### 输出层

隐藏层给了一个 $3 \times 1$，后面要接两个 $5 \times 3$ 的输出矩阵：

- 上面那份 $5 \times 3$，负责算前一个词的预测；
- 下面那份 $5 \times 3$，负责算后一个词的预测。

两份矩阵各算一次，得到两个 $5 \times 1$ 的预测值。每份张量里的 5 个位置和整个词表对齐。

### 真实值与损失

输出层得到的两个预测值，各自与对应位置的真实值比较。上面那个预测对应前一个词的真实值，下面那个预测对应后一个词的真实值，各自算一份损失。

两份损失按前面说的方式合成总损失（求和或求平均），然后开始反向传播。反向传播的先更新后面这一层的两个权重矩阵，再往前更新隐藏层那个 $3 \times 5$ 的权重矩阵。

### 三层的划分

把三层在图上标清楚，整条链路就完全对得上：

```text
    输入层              隐藏层               输出层             真实值
  ┌─────────┐       ┌─────────────┐      ┌─────────────┐    ┌──────────┐
  │ 中心词  │       │  3 x 5      │      │  5 x 3 (上) │    │ 前一个词 │
  │ One-Hot │──────►│  权重矩阵   │─────►│  5 x 3 (下) │───►│ 后一个词 │
  └─────────┘       └─────────────┘      └─────────────┘    └──────────┘
                            │                   │
                            │                   └──► 算预测值
                            └──────────────────────► 反向传播时被更新，
                                                    但最终要取走的是它
```

读图说明：输入层是中心词的 One-Hot，隐藏层是 $3 \times 5$ 的权重矩阵，输出层是两份 $5 \times 3$ 的权重矩阵，输出层算出的两个结果就是预测值，与真实值一起进入损失计算。

> **结论**：有了真实值和预测值就能算损失，算完损失更新输出层的权重，再往前更新隐藏层的权重；最终目的是更新隐藏层那个矩阵。

## 最终取用的矩阵与维度扩展

训练收敛之后，还是要问一句：到底拿走哪一个矩阵？是 $3 \times 5$ 那个，还是 $5 \times 3$ 那个？

答案明确：**取 $3 \times 5$ 的那一个**，也就是隐藏层的权重矩阵。跟 CBOW 完全一样。

两份产出比一比：

| 对比项 | CBOW | Skip-Gram |
| --- | --- | --- |
| 输入 | 上下文（两端） | 中心词（中间） |
| 输出 | 中心词 | 上下文（两端） |
| 输出层权重矩阵份数 | 一份 | 两份 |
| 损失份数 | 一份 | 两份（求和或求平均） |
| 适用词频 | 高频词 | 低频词 |
| 最终取用 | 隐藏层权重矩阵 | 隐藏层权重矩阵 |

维度也仍然是可调的。这里 $3 \times 5$ 里的那个 3，意思是每个词向量用三维来表示。想换成十维，矩阵就变成 $10 \times 5$；换成六维，就是 $6 \times 5$。列数永远是词表里的词数，行数永远是你要的词向量维度。

最终拿到的词向量，就是隐藏层矩阵的每一列：第一列是第一个词的词向量，第二列是第二个词的——以此类推。

```text
               隐藏层权重矩阵（3 x 5）
        ┌───────────────────────────────────┐
        │  w11   w12   w13   w14   w15      │  <- 第 1 维
        │  w21   w22   w23   w24   w25      │  <- 第 2 维
        │  w31   w32   w33   w34   w35      │  <- 第 3 维
        └───────────────────────────────────┘
           │     │     │     │     │
           v     v     v     v     v
         词1   词2   词3   词4   词5
        的词  的词  的词  的词  的词
        向量  向量  向量  向量  向量
```

读图说明：行列方向要记牢——横着看是"维度"，竖着看是"词"。每一列是一个词的完整向量表示，这就是 Word2Vec 交付给下游模型的最终产物。
