# Pipeline 文本摘要：让摘要模型把长文压成一句话

第五个任务叫文本摘要。它要干的事一句话就能说清：给你一段文字 —— 一篇很长的文章、一篇论文、一段故事 —— 你帮我提炼出精华，用一段简短的话把里面的内容总结出来。

这次的语料我不自己编了，直接拿一段现成的英文长文（一段介绍 BERT 的文字）来做实验。

## 创建 pipeline 对象

思路和前面几个任务完全一样，四个动作：创建 pipeline 对象、定义数据送给模型、获取预测结果、打印输出。

先写 `TODO 5` 标记位置 —— 文本摘要，等价于「提炼精华」，函数名就叫 `demo05_text_summarization`。

```python
from transformers import pipeline

# TODO 5 文本摘要 = 提炼精华
my_model = pipeline(
    task="summarization",     # 参数一：任务类型
    model=r"C:\software\os4\pretrained_model\distilbart-cnn-6-6"   # 参数二：模型路径
)
```

第一个参数 `task` 写 `summarization`，这就是文本摘要的任务名。第二个参数 `model` 换成 `distilbart` 这个模型，把它从模型目录里 Ctrl+C 拉到路径尾部。

> **提示**：又换模型了，是不是？不知道某个任务该配哪个模型时，去模型库页面就行：左边按任务分类，点进你要做的任务，右边就会列出对应的候选模型，在里面挑一个即可。这里我给的是 `distilbart`，但你完全可以不用这个，自己去 Hugging Face 上再下别的模型来解决同一件事 —— **只要能出效果就都行，因为模型有很多**。魔搭社区和 Hugging Face 都是一个道理。

参数一永远是任务类型，参数二永远是模型路径。这两条记住，后面每个任务都照这个套路套。

## 定义数据与获取预测结果

数据这一步就是把刚才复制的那段长文贴进来，然后直接喂给 pipeline：

```python
text = """
BERT is a transformer model trained on a large English corpus in a self-supervised way...
（后面是一整段介绍 BERT 预训练目标的英文原文）
"""

output = my_model(text)

print(output)
```

第三步输出照旧 `print` 一下，下面再写一行注释标上「第五个，测试文本摘要」，右键运行。

## 模型返回什么：summary_text

运行起来控制台照样先刷日志（`model will be on cpu` 那一类），跳过就好。真正要看的返回值是这一项：

```python
[{'summary_text': 'BERT is a transformer trained on a large English corpus in a self-supervised way...'}]
```

> **定义**：`summary_text` 就是摘要文本，也就是模型提炼出来的那段简短内容。字段名直接告诉你它是「摘要」，不是原文。

回答我一句：这段内容和输入的那段长文比，有没有缩减？有，而且缩得相当明显 —— 原文是好几段，摘要压成了一句话。

那它支持中文吗？想确认一个模型支不支持某种语言，有个很直接的办法：双击进模型目录，看它下面的 `vocab.json`，里面标着这个模型认识哪些字符；同一目录里一般还有 `README`，写着你想用我该做哪些事、版本、用法（usage）等等，翻一翻就有数。如果不支持你手上的语言怎么办？很简单，换个模型就好了 —— **思路全都一样，换的只是模型这一行**。

## 对比验证：把原文和摘要都翻成中文

原文和摘要都是英文，光看长度不够直观，我们把两段都翻译成中文来对着看。我用的是有道。

先看**原始文本**的翻译，大意是：

> BERT 是一种在大量英语语料库上、以自监督方式训练的 Transformer 模型。这意味着它只在原始文本上做预训练，不需要任何人工标注……

再看**摘要文本**的翻译，大意是：

> BERT 是一种在大规模英语语料库上以自监督方式训练的 Transformer。它通过两个目标进行预训练，第一个是 MLM，第二个是 NSP……

不用细抠字眼，摆在一起你立刻能看出两件事：长度上摘要短得多；内容上摘要几乎把原文每一段的主干都留住了。

## 摘要到底抓走了哪些核心

现在对着原始文本逐句找核心。原文明明讲了一大堆，它留下了什么？

第一句：BERT 是一种在大量**英语语料库**上、以自监督方式训练的 Transformer。注意这里说的是「原生的 BERT」—— 后面我们还学过好几种 BERT 的变形，其中一个就是带中文的 `BERT-base-Chinese`，那是变体，别搞混。

第二句：这意味着它仅在原始文本上进行预训练，没有任何人工标注的数据。

第三句开始就是两个预训练目标了：更确切地说，它通过两个目标进行预训练。原文里这一大段写得很长，念一念你就知道后面有几个任务 —— 两个。分别是：

- **掩码语言模型（Masked Language Modeling，MLM）**：从一个句子里随机遮蔽 15% 的词，把整个句子输入进去做预测；
- **下一个句子预测（Next Sentence Prediction，NSP）**：判断两个句子是不是相邻、是不是相关。

原文里围绕着这两个任务各有一整段介绍：一段讲第一个任务，另一段讲第二个任务。把这两段和摘要对比着看，会发现原文的结构在摘要里被完整地保留了一层 —— 它没有简单砍掉后半段，而是把「两个目标」这个骨架拎出来了。

最后一句：这使得模型能够学习句子的**双向表示** —— 也就是既能从前往后看，也能从后往前看。

> **结论**：摘要文本的每一句都能在原文里找到出处，它是针对原文的**提取**，不是另起一段自由发挥。这就是这个模型让人觉得「绝顶」的地方：它保住了主干信息和结构，同时把篇幅压下去。

MLM 和 NSP 这两个目标具体是怎么回事，下次课会专门展开讲，那时候你会清楚得多 —— 这一讲先把它们在摘要里的位置认出来就够了。
