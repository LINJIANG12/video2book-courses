# GRU 的门控结构、原理图解与 LSTM 对比

接下来讲 GRU 模型。同样从四个点讲起：介绍、内部结构、API、优缺点。

在正式讲之前要先说一句话：**为什么会有 GRU？** 原因就是为了解决 LSTM 内部结构复杂的问题，于是才有了它。

我问你个问题：LSTM 里的神经网络，就是那些黄框，有几个？四个。那我再问：如果我能把它从四个压缩成三个，甚至压缩成两个，算不算成功？如果功能给你类似的，那当然算成功。

所以我们把它从四个压缩成了三个——不是两个，是三个。这就是 GRU。

> **结论**：GRU 的定位非常清楚，它就是奔着「简化 LSTM 的内部结构」去的：功能对标 LSTM，结构比 LSTM 简单，但比 RNN 复杂。

## 门控循环单元的概念与结构特点

GRU 被称为**门控循环单元结构**。把它拆开看：第一个词 `Gated`，门控；第二个词 `Recurrent`，循环；第三个词 `Unit`，单元。所以叫门控循环单元结构。

它是传统 RNN 的变体，同 LSTM 一样能够有效捕捉长序列之间的语义关联，缓解梯度消失和梯度爆炸。有人可能会嘀咕：等会儿，这功能不就是 LSTM 的功能吗？没错，功能是一样的，区别在于——它比 LSTM 简单，比 RNN 复杂。

RNN 里边的黄框有几个？就一个。顺着这个想下去，其实有个很自然的推演：如果哪天出现一种架构，也是「一个神经网络」就能把事全搞定，那以后还学 LSTM、GRU 吗？学还是要学，但可能就不会花这么长时间了，三四分钟带过，大概念叨一下是啥玩意，了解一下就完事，直接快速刷过，学最新的。一定是这样。

> **提示**：RNN → LSTM → GRU 这条线，本质是「在记忆能力和结构复杂度之间反复找平衡」。GRU 是往「更轻」的方向走了一步，这也是它在工业界仍然常见的原因。

## 三个层与两个门

从结构上看，GRU 里边的层有几个？三个：输入层、隐藏层、输出层。

你要这么说的话，它是不是又回到了 RNN 那个状态？确实是。所以同 RNN 一样，每个时间步有两个输入，每个时间步也有两个输出。

```text
GRU 整体结构（与 RNN 同构，内部换成两个门）

   输入层            隐藏层（门控）              输出层
  ┌───────┐        ┌───────────────┐        ┌───────┐
  │  x_t  │───────►│  重置门  R_t  │───────►│  h_t  │
  └───────┘        │  更新门  Z_t  │        └───────┘
                   └───────────────┘
                          ▲
                   ┌──────┴──────┐
                   │  h_{t-1}    │  上一时刻隐藏状态（这里同时承担记忆的角色）
                   └─────────────┘
```

读图说明：每个时间步吃进「上一时刻隐藏状态」和「本次输入」两样东西，产出「本次隐藏状态」一样东西——和 RNN 完全一样的输入输出形式，只是中间多了一道门控调节。

它内部只出两个门：一个叫**更新门**，一个叫**重置门**。

我们先把公式摆在纸面上，$R_t$ 是重置门，$Z_t$ 是更新门：

$$R_t = \sigma(W_r \cdot [h_{t-1}, x_t])$$

$$Z_t = \sigma(W_z \cdot [h_{t-1}, x_t])$$

看一下这两个式子的构造：最外边还是 $\sigma$，也就是 sigmoid 激活函数；括号里边是权重矩阵乘上「上一时刻隐藏状态」和「本次的输入」的拼接。$h_{t-1}$ 是上一时刻隐藏层的状态，$x_t$ 是本次的输入。

有没有发现思路是一样的？连符号习惯都没换。真正的差别落到候选状态和最终融合上：

$$\tilde{h}_t = \tanh(W \cdot [R_t \odot h_{t-1}, x_t])$$

$$h_t = (1 - Z_t) \odot h_{t-1} + Z_t \odot \tilde{h}_t$$

那个 $\tilde{h}_t$ 是**候选隐藏状态**，$h_t$ 是最终的隐藏状态。

> **为什么 GRU 没有细胞状态？** 玩 LSTM 的时候它多了一个细胞状态，也就是记忆细胞。写代码的时候你会发现，记忆细胞和隐藏状态的形状、维度长得一模一样。所以有人做了一个尝试：把这两者合并。于是 GRU 里就不再有「细胞状态」这个概念了——它已经被合进了隐藏状态。所以那个候选隐藏状态，其实等价于 LSTM 里的候选记忆细胞；而最终的 $h_t$，等价于 LSTM 里的 $C_t$，也就是最终的记忆细胞，只不过它同时承担了对外输出的职责。

## 隐藏状态承担记忆角色

先说这个隐藏状态。它是存**关键信息**的，相当于上面那张图里说的「记忆本」，也就是长期记忆本，跟 LSTM 的细胞状态是同一个角色，但比它更简单。

这「更简单」到底简单在哪？用记账打个比方。

LSTM 那套，相当于你们家每个月**手动记账**：拿个本子，在纸上写你的支出、收入各是多少。你想算某一项支出合计，本子可不会帮你自动算——你还得自己掏计算器再算一遍。

GRU 这个隐藏状态就好比现在的**记账 App**：你消费了什么，甚至可以跟你的某些软件关联，你花了多少钱、对方商铺属于什么类型，它自动帮你记账，帮你把这个月的交通出行花了多少、吃住花了多少、买衣服花了多少、交际花了多少、其他支出花了多少统计得清清楚楚。

这就是「更智能一些」的含义：手动记账和自动记账都能把账记下来，但后者在你需要的时候直接给你结果。所以它不是把记忆扔了，而是把记忆的载体和对外输出的载体合成了一件事。

## 重置门与更新门的公式与结论

### 重置门

**重置门决定要不要擦除旧记忆。** 它有点像 LSTM 里面的遗忘门。

数值结论上：重置门门值接近 1，表示旧记忆保留、接着用；接近 0，表示少保留旧记忆、多加新记忆，相当于把记忆清洗一遍。

公式就是前面的 $R_t$：

$$R_t = \sigma(W_r \cdot [h_{t-1}, x_t])$$

> **提示**：这里外边一律写 sigmoid，不用纠结「为什么不是 tanh」——门是拿来当「开关/比例」用的，取值落在 $(0, 1)$ 才好当权重用；tanh 的输出范围是 $[-1, 1]$，更适合拿去当候选内容。

### 更新门

**更新门决定新旧记忆怎么融合**——保留多少新的、保留多少旧的，也就是这个比例是多少。

这不就跟家庭财政支出一样吗？固定的资金存下来多少，拿多少钱去做理财。比如说拿家庭总收入的 30% 去做理财，剩下的当什么什么基金。结婚前你月光其实还可以，结婚以后就不能再月光了，万一小孩有个什么情况，你总不可能满世界借钱去。

数值结论上：更新门门值越接近 1，越少保留旧记忆、越多加入新记忆；越接近 0，越多保留旧记忆、越少添加新记忆。

公式是前面的 $Z_t$：

$$Z_t = \sigma(W_z \cdot [h_{t-1}, x_t])$$

> **易错点**：重置门和更新门的结论方向看一眼容易记反。抓一个锚点就不会错——**更新门 $Z_t$ 是「新的权重」**，它出现在 $Z_t \cdot \tilde{h}_t$ 这一项上，所以 $Z_t$ 越接近 1 就越偏新东西；重置门 $R_t$ 作用在旧记忆上，$R_t$ 越接近 1 就越把旧记忆原样留下。

### 候选隐藏状态

**候选隐藏状态是生成新记忆候选。** 它有点像 LSTM 里面的候选记忆，是同一个角色。

它的公式里有两处要看清：

$$\tilde{h}_t = \tanh(W \cdot [R_t \odot h_{t-1}, x_t])$$

用大白话说这个式子：先把旧记忆用重置门筛选一遍——$R_t$ 乘上 $h_{t-1}$，就相当于按比例保留旧记忆；然后把它和新的信息 $x_t$ 混合到一起；最后通过一个 tanh 激活函数，把数值压缩到 $\tanh$ 的范围 $(-1, 1)$ 之内，生成新记忆候选。

### 最终隐藏状态

**最终隐藏状态就是最终的记忆状态**，它完成两件事：新旧记忆融合，然后定稿存储——定稿了就不再动。

公式与大白话解释：

$$h_t = (1 - Z_t) \odot h_{t-1} + Z_t \odot \tilde{h}_t$$

最终融合后的新记忆，等于「$1$ 减去更新门门值」乘上一次的隐藏状态（也就是 LSTM 里那个记忆细胞的位置），再加上「更新门门值」乘上新记忆候选。

说白了，就是更新门决定了将来要更多之前的旧信息，还是更多现在的新信息；融合之后得到的 $h_t$，就是要往下传递的新记忆。

它其实可以理解为 LSTM 里的 $C_t$——因为记忆细胞和隐藏状态的动作、形状基本上都一样，所以在这里直接合二为一了。

接着看边界值：$Z_t$ 接近 1，少保留旧的、多加新的；$Z_t$ 接近 0，多保留旧的、少添加新的。极端一点，$Z_t = 0$ 就说明这次不更新，完全用以前的；$Z_t = 1$ 就是完全更新，之前的东西一概不要。

```text
GRU 单个时间步的数据流

  h_{t-1} ──┬──► R_t = sigmoid(W_r * [h_{t-1}, x_t])
            │            │
            │            ▼
            │      R_t (*) h_{t-1} ──┐
            │                        ├──► tanh ──► h_t 候选 ──┐
  x_t  ─────┴──► Z_t = sigmoid(W_z * [h_{t-1}, x_t])          │
                                                              ▼
  h_{t-1} ─────────────────────► (1 - Z_t) (*) h_{t-1} ──► 加权求和 ──► h_t
  h_t 候选 ─────────────────────►      Z_t  (*) h_t 候选 ──┘

  说明：重置门先把旧记忆筛一遍，拼上本次输入后过 tanh 得到新记忆候选；
        更新门同时充当两个互补权重，(1 - Z_t) 走旧记忆，Z_t 走新候选，相加得到 h_t。
```

读图说明：两条分支并行计算门值——重置门先去筛旧记忆、拼上新输入、过 tanh 得到候选；更新门则作为一对互补权重 $(1 - Z_t)$ 与 $Z_t$，把「旧记忆」和「新候选」按比例加起来，得到这一时刻的 $h_t$。

## GRU 与 LSTM 的对比

为什么要 GRU？一句话：简化。

LSTM 靠**三个门加记忆细胞**解决长序列的记忆问题，但结构复杂、计算慢。GRU 想的是：能不能简化结构，同时保留「智能记忆」的功能？所谓智能记忆，就是选择性的记忆。

它把 LSTM 的**部分门做了合并**，合并之后变成了更轻量的「记忆管家」。更轻量是什么意思？说白了就是消耗资源少，消耗资源少你自然就训练快。而且关键是——快了之后，那个核心问题的解决能力还在。要是光快、问题没解决，那其实也没太大用。

所以 GRU 的核心就是：**两个门加一个隐藏状态**。其实这个隐藏状态话都不用写——RNN 的时候它本来就一定有。所以真正要记的就是**两个门**。

| 对比项 | LSTM | GRU |
| --- | --- | --- |
| 门的数量 | 三门（遗忘门、输入门、输出门）+ 细胞状态 | 两门（重置门、更新门） |
| 记忆载体 | 隐藏状态 + 细胞状态，两份 | 只有隐藏状态，合二为一 |
| 结构复杂度 | 复杂，训练慢 | 更简单，参数更少，训练更快 |
| 长序列能力 | 能捕捉长序列语义关联，缓解梯度消失/爆炸 | 同样能捕捉、同样只缓解 |
| 资源消耗 | 大（四个神经网络结构） | 更轻量（三个） |

> **结论**：GRU 用「少一个门 + 去掉独立的细胞状态」换来更小的参数量和更快的训练速度，而长序列上的记忆能力基本保住。

## API 与前向写法

翻到 API 那一页，你会惊喜地发现一件事：GRU 的写法跟 RNN 的写法**一模一样**，区别只有一个——把你那个 `RNN` 换成 `GRU`，参数都不带变的。

```python
import torch
import torch.nn as nn

// 与 RNN 的唯一区别：类名从 nn.RNN 换成 nn.GRU
gru = nn.GRU(input_size=561, hidden_size=135, num_layers=236)
```

三个参数一一对应：输入维度、隐藏层维度、隐藏层层数——以前 RNN 是怎么写的，现在就怎么写。前向调用也一样，每个时间步两个输入（上一时刻隐状态 + 本次输入），两个输出（本次输出 + 本次隐状态）：

```python
output, hn = gru(input, h0)   # 注意：没有 c0 了
```

> **提示**：调用 GRU 千万别再顺手补一个 `c0`。GRU 没有细胞状态，它只要一个隐状态——这也是「记忆和输出合二为一」在 API 上的直接体现。

## 表述与面试要点

把话收回来。这玩意简单不简单？它是真的简单，编程越往后学越简单，一定是这样的——但前提是你的积累达到一定的量。

我见过太多弯道超车的学生。刚开始来学的时候，说实话我都担心这孩子将来怎么就业，心里会嘀咕一句：他适合学编程吗？学这么慢？一个 Hello World 那样的入门案例他可能得敲很多遍。但也不妨有很多是后期超车的。你要相信量变会引起质变：代码天天敲、天天敲，突然有一天就跟吃了什么灵丹妙药似的，脑子一下就开窍了——原来这个代码是这个意思，那个代码是那个意思，很多事一下子都想通了。所以一定要多抄多练。

再往后还有个话必须说：往后的面试里，RNN、LSTM、GRU 这三种结构你不能念错。以前有同学模拟面试，问他「说一下 RNN 那三种结构的区别」，那哥们居然能说成 `GUR`。就这一个念错，你就直接寄了——这相当于你跟人说你上过语文、数学、英语，然后说成「我学过文语、学数学过、学过英语」，属于常识性错误，这个地方一定要注意。

还有一点也值得一提：GRU 这套内容相对来讲还是比较简单的，公式你不用背。**你只要能用自己的话把「重置门决定要不要擦除旧记忆、更新门决定新旧记忆怎么融合、两者拼出最终隐藏状态」这一段讲出来，GRU 就搞定了**；同理，能把 LSTM 那一段讲出来，LSTM 就搞定了。

> **提示**：面试官要是追问细节，你就说这是我自己手绘的一张图，讲给他听。但要命的是——他问「你给我讲讲这是啥意思」，你回一句「等会儿，让我想想我当时咋画的来着」，那就尴尬了。所以图你得真看会，而不是记住页码。

最后一层背景：回到 18 年左右，那时候 BERT 刚火，你去面试，Transformer 不会被问那么深，问得多的就是 RNN、LSTM、GRU——市场上解决问题全靠这玩意。后来随着 BERT 火起来，大家才开始关注 Transformer，再往后大模型如雨后春笋一样起来。所以这段内容既是基本功，也是理解后面注意力机制的前置台阶。
