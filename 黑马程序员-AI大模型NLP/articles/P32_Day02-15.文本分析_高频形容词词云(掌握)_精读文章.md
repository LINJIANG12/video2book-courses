# 高频形容词词云的绘制：从词性过滤到分样本出图

接下来这件事更有意思：**获取词云**。

注意，我们要的是**高频**词云——比如训练集正样本里形容词的词云、训练集负样本里形容词的词云。那先回答一个反问：除了形容词，我能不能找名词或者动词的词云？当然也可以，都是 OK 的，做法完全一样。

那既然要挑形容词、动词，是不是肯定得先做词性标注（POS）？对。后面再交给 `wordcloud` 去统计、去作图就行。这一段本身没有特别难的，核心动作就一个：**画图**。

我先要提醒一句：这两个函数跟训练集、测试集有关系吗？**一毛钱关系都没有**。一个是我给你一句话、你替我把形容词挑出来；另一个是我给你一个词列表、你替我画张图。它们都是"铺垫动作"，真正干活的那个函数还没写。所以别急着一步到位——先做几步小铺垫，最后再把它们串起来。

## 获得文本中的形容词列表

先写 `get_a_list`。这名字里的 `a` 就是形容词——词性标注里 `a` 代表形容词，这个对照关系我们前面已经见过。

第一步，准备一个空列表来装形容词：

```python
a_list = []
```

第二步，用结巴的词性标注功能切分文本，并遍历取到每个词：

```python
for val in psg.lcut(text):
    print(val)
```

这里的 `text` 就是**一个句子**——注意，这个函数一次只处理一句话，不是一整个数据集。切完之后，`val` 里装的东西我们前面打印过，格式是"词/词性"成对出现的。想拿它的词性，用 `val.flag`；想拿词本身，用 `val.word`。

拿"早餐不好"这句话试一下，打印出来是这样：

```text
早餐/n
不好/d
```

`早餐` 是这个句子里唯一的词，词性是 `n`（名词）；`不好` 的词性是 `d`（副词）。看清楚这个输出，下一步的判断就好写了。

第三步，判断词性是否为形容词，是就加进列表：

```python
for val in psg.lcut(text):
    if val.flag == 'a':
        a_list.append(val.word)
```

第四步，返回结果——返回 `a_list`，这就是这句话里的全部形容词。

```python
def get_a_list(text):
    """获取一个句子中的形容词列表"""
    a_list = []
    for val in psg.lcut(text):
        if val.flag == 'a':
            a_list.append(val.word)
    return a_list
```

> **提示**：`val` 是一个 `pair` 对象，`.word` 拿词、`.flag` 拿词性，两个字段名别记混。要换别的词性，只改 `'a'` 这一个字符就行：名词是 `'n'`，动词是 `'v'`。

## 根据词列表产生词云图

铺垫动作之二：`get_word_cloud`。它接收一个词的列表，输出一张词云图。

```python
def get_word_cloud(keywords_list):
    """根据词列表生成词云图"""
    # 1. 实例化词云生成器
    word_cloud = WordCloud(font_path='./data/simhei.ttf',
                           max_words=100,
                           background_color='white')
    # 2. 把关键词列表转换成空格分隔的字符串
    keywords_str = ' '.join(keywords_list)
    # 3. 根据关键字字符串生成词云
    word_cloud.generate(keywords_str)
    # 4. 配置并显示词云图像
    plt.figure()
    plt.imshow(word_cloud, interpolation='bilinear')
    plt.axis('off')
    plt.show()
```

三个实例化参数，一个一个说清楚：

| 参数 | 取值 | 作用 |
| --- | --- | --- |
| `font_path` | `./data/simhei.ttf` | 字体路径，必须指定中文字体 |
| `max_words` | `100` | 词云里最多显示多少个词 |
| `background_color` | `white` | 背景色 |

**字体这一条是坑**。还记得我们 `data` 目录下贴过来的那个 `simhei` 字体吗？现在这哥们就要出场了。中文字体路径不指对，图上一排方块，什么都看不见。

**`max_words=100` 是什么意思**？就是这张词云里最多只显示 100 个词。如果我有 200 个不同的词怎么办？它会按出现次数排序，取前 100 个——所谓"高频"，就是这么来的。

**第二步为什么要把列表转成字符串**？因为词云要的输入格式是"空格分隔的字符串"，不是我们自己习惯的列表。我们要把数据整成 `词1 词2 词3` 这样。怎么写？`' '.join(keywords_list)`——用一个空格把列表里每个词连起来。这不是我们定的格式，是它要的格式。

第三步 `word_cloud.generate(keywords_str)`，按上面的字符串生成词云。**其实到这一步，词云已经画出来了，图已经生成了**，剩下的是把它显示出来。

第四步，四个小动作：

- `plt.figure()`：创建一块新画布；
- `plt.imshow(word_cloud, interpolation='bilinear')`：把刚才那块词云拿过来渲染显示。第一个参数是图像数据，第二个参数是插值方法，`bilinear` 就是双线性插值；
- `plt.axis('off')`：隐藏坐标轴；
- `plt.show()`：把图显示出来。

> **提示**：`interpolation='bilinear'` 管的是图像显示的平滑方式，词云里那些词横着摆还是斜着摆、怎么错落，是 `WordCloud` 自己在排版时决定的（由它内部的排布参数控制，比如是否优先横向排布）。所以你想要"横竖错落"的效果，要调的是词云生成器的排布参数，而不是这里的插值方式。

## 最终业务函数：分样本出图

现在写真正干活的那个：`dm05_word_cloud`。上面那两个函数到这里就派上用场了。

```python
def dm05_word_cloud():
    """实现训练集、测试集的高频形容词词云"""

    # 场景1：训练集正样本
    train_data = read_csv('./data/ChnSentiCorp_htl_all.csv')
    # 1. 读取训练集并筛选正样本，只取句子列
    p_train_data = train_data[train_data['label'] == 1]['sentence']
    # 2. 对每个正样本句子提取形容词，再合并成一个完整列表
    pa_train = chain(*map(lambda x: get_a_list(x), p_train_data))
    # 3. 根据形容词列表绘制词云
    get_word_cloud(pa_train)
    print('-.' * 10)
```

正样本就是 `label` 等于 `1` 的那些数据，负样本就是 `label` 等于 `0` 的那些数据。

第 1 步的筛选写法要留意：`train_data[train_data['label'] == 1]` 拿出来的是整张表，`sentence` 和 `label` 两列都在；后面再接一个 `['sentence']`，才是"只要正样本的句子"。

```text
train_data                     整张表：sentence + label
    |
    |  [train_data['label'] == 1]        布尔筛选：只留 label==1
    v
正样本子表                      sentence + label 两列都在
    |
    |  ['sentence']                      只取句子这一列
    v
p_train_data                   一串正样本句子
```

第 2 步是整节的骨架，和上一节词汇统计的套路一模一样：`map` 把每个句子送进 `get_a_list`，得到一堆**小的**形容词列表；星号解包，`chain` 把它们拉直合并成一个**大的**词列表。

> **易错点**：`chain(*map(...))` 得到的是一个**对象**，不是列表。直接 `print` 它，你会看到一个对象地址。想看里面具体的数据，得用 `list()` 或者 `set()` 转一下。

为了确认数据对不对，打印一下：

```python
print(pa_train)
```

运行 `dm05_word_cloud()`，正样本那张图出来了：有横着摆的、有斜着摆的，看着挺自然。词是这些——**少、舒服、干净、好、不错、方便**。

你告诉我这是什么样本？训练集的正样本。那敢不敢把那玩意儿换成负样本看看？也会有"差"这类词出现——评论数据不是绝对干净的，这很正常。

看下面这张负样本的图：**差、一般、不满意**，然后还有**最差、很小**。差评里"差"字最多，一点不奇怪。

## 词云结果的解读与数据审查

到目前为止，我们可以根据高频形容词词云对当前语料做一个简单评估，同时对语料里的词汇做一轮**人工审查**。

先看一个反直觉的现象：正样本的词云里居然出现了"遗憾""不足"，负样本里居然出现了"豪华""不错"。

为什么？看一句真实的正样本评论：

> 酒店还是存在着一些不足的，比如说下车的时候没有人帮忙开车门，但是前台的态度非常非常好，价格非常低。

前半句是差评口吻，后半句是好评，整条标注为 1。还有一种典型的写法：

> 去的时候在装修，感觉有点挤，本来该享受也没有享受。

前面明显是差评，但往后走，说到前台服务态度非常好，就变成 `1` 了。

> **易错点**：评论数据里出现模棱两可的词是**普遍现象**，不是标注错误。你在绘制的时候一定会遇到这种词，别把它当成 bug 去追。

那发现可疑词怎么办？去查带这些词的句子，看看是标记错了、还是识别错了，做人工核实。比如负样本里出现"豪华"就值得查一查。

**审查之后有两类处理**：如果语料里确实出现了大量明显不当的词，要么把带这些词的句子过滤掉，要么把词用星号 `**` 遮蔽掉。

> **注意**：词云这一步是**没有做敏感词过滤**的。数据里有什么，它就老老实实显示什么，别指望它替你遮。

## 场景复用：换词性、换样本、换数据集

处理完训练集正、负样本，再处理测试集的正、负样本——场景 3 和场景 4 跟前面**一模一样**，把数据换掉就行。

如果想要名词的词云、动词的词云，改哪里？改 `get_a_list` 里那个 `'a'`。名词换成 `'n'`，动词换成 `'v'`，其他一行都不用动。

```python
def dm05_word_cloud():
    """实现训练集、测试集的高频形容词词云"""
    train_data = read_csv('./data/ChnSentiCorp_htl_all.csv')
    dev_data = read_csv('./data/ChnSentiCorp_htl_all.csv')

    # 训练集正样本
    p_train_data = train_data[train_data['label'] == 1]['sentence']
    pa_train = chain(*map(lambda x: get_a_list(x), p_train_data))
    get_word_cloud(pa_train)
    print('-.' * 10)

    # 训练集负样本
    n_train_data = train_data[train_data['label'] == 0]['sentence']
    na_train = chain(*map(lambda x: get_a_list(x), n_train_data))
    get_word_cloud(na_train)
    print('-.' * 10)

    # 测试集正样本 / 负样本
    p_dev_data = dev_data[dev_data['label'] == 1]['sentence']
    pa_dev = chain(*map(lambda x: get_a_list(x), p_dev_data))
    get_word_cloud(pa_dev)
    print('-.' * 10)

    n_dev_data = dev_data[dev_data['label'] == 0]['sentence']
    na_dev = chain(*map(lambda x: get_a_list(x), n_dev_data))
    get_word_cloud(na_dev)
```

> **提示**：这一段里 `train_data` 和 `dev_data` 的读取是最简写法，实际代码按你前面的数据集划分方式来取，测试集从划分结果里拿就行，不要重复切分。

每次画完图打一行 `print('-.' * 10)` 做分隔——四张图连着弹出来，有个分隔符才不会看串。

**为什么代码要按分节板块命名？** `dm05_1`、`dm05_2`、`dm05_3`，每个函数只干一件事，这种命名的维护和管理成本就非常低。要名词词云，改一个字符；要负样本，改一个数字。代码写成一坨，找都找不着。

## 一套代码当模板用的价值

文本语料数据分析到这儿就告一段落了，一共四块内容：标签数量分布、句子长度分布、词频统计，还有关键字词云的绘制。

有人会问：这里边哪个动作是**必须掌握**的？要我说，这些内容全做到**理解**就可以了。

为什么？因为以后换一份数据要做同样的探查，我们刚才写的这一堆代码，可以直接当成**模板**用。你不会到公司里遇到同样的需求，还从头再敲一遍吧？把数据集一改，代码往里一套就完事了。

这件事在面试里也有用。面试官问"你对数据做了哪些预处理"，只说"我把缺失值做了个处理，用均值填了一下"，一句话就没了。换个说法：

> 上来先对数据做查看——看标签分布、看句子长度分布、看词频、看词云；然后决定怎么做处理，比如引入词性标注、命名实体识别、文本张量，用 n-gram 和文本长度规范，数据偏少的部分还用了回译数据增强。

同一个工作量，谈资完全不同。**先做查看，再做处理**，这个顺序就是这段话的骨架。

## 选择题回顾

四道选择题的考点都落在我们刚用过的函数上：

| 题目 | 选项要点 | 答案 | 依据 |
| --- | --- | --- | --- |
| 显示数据集中每个类别的数量/频率 | A. `sns.countplot()` B. `sns.histplot()` C. `sns.stripplot()` D. `sns.distplot()` | A | 我们画的第一个图就是它，直接按类别计数出柱 |
| 绘制句子长度的分布 | A. `sns.countplot()` B. `sns.histplot()` C. `sns.stripplot()` D. `sns.distplot()` | B | 新版绘制直方图用 `histplot`，旧写法 `distplot` 已经过时 |
| `stripplot` 的用途 | A. 比较不同类别的分布 B. / C. / D. | A | 它画的是散点，用来比较不同类别的分布 |
| `map` 的作用 | A. 对列表中每个元素应用同一个函数 B. / C. / D. | A | `map` 就是把函数作用到列表的每一个元素上，不是"地图" |

关于直方图与柱状图的区别，这是容易被混在一起的一对概念：

> **定义**：柱状图统计的是**离散取值的个数**，比如 A 出现了多少次、B 出现了多少次；直方图统计的是**区间（范围）里的个数**，比如 20 到 30 之间有多少个、30 到 40 之间有多少个。

句子长度是连续量，所以要用直方图；样本类别是离散量，所以要用计数柱状图。

## 本讲提到的题目

`chain` 那道题给的是三行代码：`c1` 是 `chain([1, 2, 3], ['x', 'y', 'z'])`，`c2` 是 `chain([[1, 2, 3], ['x', 'y', 'z']])`，`c3` 是 `chain(*[[1, 2, 3], ['x', 'y', 'z']])`，每个都转成 `list` 再比较。

问的是：下面关于 `c1`、`c2`、`c3` 的说法正确的是哪一个？

答案选 B：**`c1` 和 `c3` 的结果完全相同**，都是 `[1, 2, 3, 'x', 'y', 'z']`。

推断过程：`c1` 是把两个列表直接接起来；`c3` 里的星号先把外层列表解开，等于也是把这两个列表交给 `chain`，所以和 `c1` 一样。`c2` 没有星号，它把整个嵌套结构当成一个元素，结果是嵌套的 `[[1, 2, 3], ['x', 'y', 'z']]`，拿不到拉平的效果。

这题的答案可不好想。最简单的思路是把它贴到 PyCharm 里跑一遍，结果立刻就出来了——但考试的时候不能这么干，得自己把星号那一层在脑子里推出来。
