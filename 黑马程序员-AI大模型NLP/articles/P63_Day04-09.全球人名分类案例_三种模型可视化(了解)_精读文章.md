# 三个模型的损失、耗时与准确率对比图绘制

三个模型的训练代码都写完了，现在到了验收的时候。这一节要把它们的效果放到图上比一比，然后回答一个很实际的问题：这三个模型里，到底该用哪一个。

不过在动笔之前先确认一件事：**三个模型是不是都已经训练出来、都正常能跑**。模型都在这儿好好的，我们才开始画图。另外提醒一句，从这个环节开始就是"了解"级别的操作——图怎么画我会带你们走一遍，但重点在结果，不在你把每一行都默写出来。

## 1. 训练与绘图的职责划分

这里的操作属于模型训练加绘图，函数结构上分三组，每组负责一个模型：

```python
def model_train():
    train_rnn()
    train_lstm()
    train_gru()
```

先明确一件事：这三个动作**一个比一个耗时**，整个这一坨跑起来大概要三分钟左右。为什么？因为每调用一次就相当于把那个模型从头训练一遍。

再明确一件事：可视化那部分代码你可以不写，直接复制粘贴过来用就行；但**模型训练这块的代码必须自己写出来**——训练产物就是那三张图。

> **提示**：我在优化项里还留了一条，你们可以自己去做——把训练函数返回的那三个对象直接写到文件里存起来，下次直接从文件读，就不用每次都重训三分钟。这里我不做，留给你。

## 2. 训练函数的三个返回值

回想一下 `train_gru()` 那一坨代码，一路拉到最后你会发现：训练完之后它其实把三样东西都返回了。问题是这三个值当时既没写进文件，也没存到别的地方。所以现在重新调用的时候，得用三个变量把它们接住：

```python
total_loss_list_rnn, total_time_rnn, total_acc_list_rnn = train_rnn()
total_loss_list_lstm, total_time_lstm, total_acc_list_lstm = train_lstm()
total_loss_list_gru, total_time_gru, total_acc_list_gru = train_gru()
```

三个返回值的含义分别是：

| 返回值 | 含义 |
| --- | --- |
| `total_loss_list_*` | 损失列表（取值为负，绝对值越小越好） |
| `total_time_*` | 训练总耗时 |
| `total_acc_list_*` | 准确率列表 |

> **易错点**：损失列表的长度不是随便来的。**每 100 个样本统计一次**，所以这个列表里的元素个数就等于训练过程中的统计次数。搞清楚这一点，后面画曲线时 x 轴该怎么标就清楚了。

这三个值接住之后，就能直接拿来画图了。

## 3. 损失对比曲线的绘制

第一张图是损失对比曲线，评估的是**模型的收敛速度**——谁下降得最快，谁就收敛得快。

### 3.1 创建画布

`figure` 里第一个参数给 `0`，代表这是图一；`figsize` 给 `15`，宽一点放三条曲线比较舒服。

```python
plt.figure(0, figsize=(15, 6))
```

### 3.2 绘制各模型损失曲线

`plot` 输入损失列表，`label` 用来图例显示：

```python
plt.plot(total_loss_list_rnn, label='RNN')
plt.plot(total_loss_list_lstm, label='LSTM')
plt.plot(total_loss_list_gru, label='GRU')
```

### 3.3 图表属性

```python
plt.title('模型损失对比曲线')
plt.xlabel('训练步数')
plt.ylabel('平均损失')
plt.grid(True, linestyle='--', alpha=0.5)
plt.legend(loc='upper left')
plt.savefig('./images/rnn_lstm_gru_loss_time.png')
plt.show()
```

几个属性的含义：

- `xlabel` 写"训练步数"，因为我们是每 100 步统计一次；
- `ylabel` 写"平均损失"比单写"损失"更准确，它是 100 步的平均；
- `grid=True` 打开网格，`linestyle='--'` 让网格线变成虚线，`alpha` 是透明度；
- `legend(loc='upper left')` 表示图例放左上角，`loc` 是 `location` 的简写，默认是 `best`，会自动找合适的位置。

`alpha` 我一开始给了 0.5，发现太淡了，改成 0.7。

> **易错点**：参数最好一次写对。为什么？因为你为了改这一个参数，就得把上面整段重跑一遍——那就是三分钟。所以这些细节先在脑子里过一遍再运行，别一会儿少一个参数、一会儿又想加一个，那都是时间。要么就按前面说的，把训练结果写进文件直接读。

> **注意**：`savefig` 要存到 `./images`，那你在画之前得先有这个文件夹。**自己把 `images` 目录建出来**，不建的话保存这一步会失败。

## 4. 用时对比柱状图的绘制

第二张图是训练耗时对比的柱状图。注意它评估的是什么——不是"训练耗时有毛用"，而是**模型的计算效率**。

打个比方：老板交给你们部门三个人同一件事，有人花三天、有人花十天、有人花九天。老板真的是想看你们花几天吗？不是，他是想通过这个天数去评估你们的**工作效率**。谁快谁慢、差在哪儿，一眼就看出来了。这里也一样，耗时的数字只是外壳，我们要评估的是计算效率。

### 4.1 创建画布

这里的 `1` 代表图二：

```python
plt.figure(1, figsize=(15, 6))
```

> **提示**：`plt.figure` 的第一个参数决定的是渲染出来的窗口编号——`0` 是图一，`1` 是图二。两张图分开编号，才不会互相覆盖。

### 4.2 准备 x 轴与 y 轴数据

柱状图有三根柱子，所以先准备横轴上的三个标签，再准备纵轴上的三个耗时值：

```python
x_data = ['RNN', 'LSTM', 'GRU']
y_data = [total_time_rnn, total_time_lstm, total_time_gru]
```

### 4.3 绘制柱状图

```python
plt.bar(range(len(x_data)), y_data, tick_label=x_data)
```

`len(x_data)` 是 3，那 `range(3)` 就是 `0、1、2`，正好是三个位置；`y_data` 是三个值，个数对得上；`tick_label=x_data` 让横轴上依次显示 `RNN`、`LSTM`、`GRU`。

### 4.4 图表属性

```python
plt.title('模型耗时对比柱状图')
plt.savefig('./images/rnn_lstm_gru_time.png')
plt.show()
```

这张图不需要再设 `xlabel`，横轴的标签已经在 `tick_label` 里给过了。

plt.figure(2, figsize=(15, 6))

### 5.2 绘制各模型准确率曲线

## 6. 运行与三张图的结果

写完之后把这些动作跑起来：先调用三次训练拿到参数，再依次画出三张图。

```text
调用 train_rnn  ──┐
调用 train_lstm ──┼──▶ 拿到 3 组 (损失列表, 总耗时, 准确率列表)
调用 train_gru  ──┘              │
                                 ▼
                     fig 0：损失对比曲线   ── 看收敛速度
                     fig 1：耗时对比柱状图 ── 看计算效率
                     fig 2：准确率对比曲线 ── 看模型效果
                                 │
                                 ▼
                        ./images/ 下三张 png
```

这张图说明了整个流程的推进方向：训练只跑一次，产出的三组指标同时喂给三张图，三张图各自回答一个不同的问题。

跑完之后的日志是这样的：

| 顺序 | 模型 | 单轮耗时 |
| --- | --- | --- |
| 1 | RNN | 51 秒 |
| 2 | LSTM | 48 秒 |
| 3 | GRU | 47 秒 |

**损失对比曲线**：三条曲线都在逐步往下降。谁降得最快？是 GRU。它的曲线在三条里下降最快，说明收敛最快。损失越小说明拟合得越准，所以**从损失这一项看，GRU 会更好一点**。

**准确率对比曲线**：三条准确率曲线整体都是越来越高的趋势，其中 **GRU 的准确率比其他两个要好一些**。

**耗时对比柱状图**：这张图没达到我本来想要的效果。我期待的是 LSTM 那根柱子明显最高、RNN 明显最低，结果不是这样。

> **结论**：三个模型里，从损失和准确率两项看 GRU 表现最好。但耗时的结论不要急着下——原因下一节说。

## 7. 耗时结论存疑时的排查

时间这张图跟预期不符的时候，第一件要做的事不是怀疑模型，而是**排查自己有没有写反**。

排查方法很简单，顺着"横轴标签"和"实际实例化的模型"对一遍：

- 横轴第一个标签写的是 `LSTM`，那上面这一步里装的必须真的是 `MyLSTM`，不能是 `MyRNN`；
- 横轴写着 `GRU` 的位置，里面装的必须真的是 `MyGRU`。

有的同学会出现这种情况：上面标签写着 `LSTM`，里面装了一个 `GRU`；写着 `GRU` 的那一格，里面装的是 `LSTM`。这是最典型的写法错误——**模型和标签错位**，图一出来就全乱了。

另外还要接受一件事：每个人最后跑出来的这张时间图，内容都不一样。因为耗时受机器状态影响太大，这跟前面测单轮耗时是同一个道理。

## 8. 作业与提交要求

这一讲的作业就是把这三张图绘制出来，我看看你模型的效果。具体怎么交：

- 代码部分：**模型训练那块自己写出来**，可视化这块可以直接复制粘贴，只要最后能出三张图；
- 交付物：就是这三张图，损失对比、准确率对比、耗时对比，一个都不能少；
- 图上必须加你的名字：**写你自己的真名**，别写网名。

名字的位置有个硬要求——**必须压在线上**，压在曲线的线上。为什么这么要求？因为如果你的名字写在空白处，别人截个图就把你的名字裁掉了；但如果名字压在线上，别人截走之后想抹掉你的名字，就得自己手绘一条曲线接上去，那就很难不露痕迹。

具体操作：`Ctrl C` 复制图片，打开画图工具粘贴进去，直接用文字工具在线上写名字就行，原来那张不需要的图删掉。

> **注意**：名字不能写太大，压在线上就行。三张图每一张都要这么处理，一张都不能漏。

## 9. 训练结果缓存这一项优化

前面提过两次的那个优化，这里再说一次它到底是什么：**把训练函数返回的损失列表、总耗时、准确率列表这三个对象写进文件保存下来，下次直接从文件读**。

现在不这么做的代价很具体：只要你想调一个画图参数，就得把三个模型重新训练一遍，等三分钟。做了缓存之后，画图阶段就变成秒级的反复试验——颜色不满意换一个、图例位置不合适挪一下，都不需要重训。

这也解释了为什么这一讲的定位是"了解"：真正花时间的不是画图代码，而是你对 matplotlib 的那几行调用熟不熟。熟悉之后，绘图就是复制粘贴加改数据的事。
