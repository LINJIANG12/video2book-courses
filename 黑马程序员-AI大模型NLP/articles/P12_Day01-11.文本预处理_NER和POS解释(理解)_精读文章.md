# 命名实体识别与词性标注

命名实体识别，也就是 NER，其实讲完理论一分钟就够了。可这一分钟里藏着两个特别容易答混的东西：**NER** 和 **POS**。

面试官经常不跟你说中文，直接就问：你来跟我讲讲 NER 和 POS，这两个你咋理解？很多人一听 POS 就想到 POS 机，当场卡壳，分一扣，工资就跟着受影响。所以我把命名实体识别和词性标注放在一起讲，一个视频把这两个概念一次分清。

## 命名实体识别是什么

先看几个专有名词：**周杰伦**、**黑山县**、**孔子学院**，还有那个字念堃的 **阿尔斯堃**。人名、地名、机构名，这些专有的名词统称起来，就是**命名实体**。

> **定义**：命名实体识别（Named Entity Recognition，NER），就是把一段文本里的人名、地名、机构名这类专有名词识别出来的技术。

说白了一句话：**我给你一段话，你去里面帮我找出来哪些是人名、哪些是地名、哪些是专有名词**。找出来干什么？方便模型做分析。

这一层意义跟前面反复强调的那件事是同一件事：大模型之所以火，首先是因为它**能更好地理解我们的人话**，其次才是生成的内容符合人类的用语习惯。命名实体是人类理解文本的**基础单元**，也因此是 AI 解决 NLP 领域**高阶任务的重要技术环节**。

拿一句话来练：**鲁迅，浙江绍兴人，五四新文化运动的重要参与者，代表作《朝花夕拾》。**

里面能提取出来的信息是成串的：

- 鲁迅——**人名**；
- 浙江绍兴——**地名**；
- 五四新文化运动——**专有名词**；
- 《朝花夕拾》——**专有名词**。

提取出人名和地名之后，句子里的关系就能被读出来：**鲁迅**做了什么事？他**参加了五四新文化运动**。他还有什么？有一个**代表作**，叫**《朝花夕拾》**。

注意最后那一项：它没有把《朝花夕拾》当成成语，也没有把它拆成「朝花」「夕拾」这样的碎片，而是识别为一个**专有名词**。这一步做好，对整份内容的理解就顺得多。

## 命名实体识别的实现安排

那 NER 怎么实现？这个先不着急。后面 NLP 里要做的**第一个项目就是它**，所以代码会放到后面详讲，因为它写起来会稍微复杂那么一点点。

> **提示**：这里先把概念立住：一是命名实体识别的动作——从一段话里识别出命名实体（人名、地名、机构名）；二是它的英文缩写叫 **NER**。后面再做具体的实操。

## 词性标注是什么

词性标注，简单说就是**语言中对词的一种分类方法**：以词性特征为主要依据，兼顾词汇意义，对词进行划分，划出来的结果就是名词、动词、形容词、代词、介词、叠词这一堆。

> **定义**：词性标注（Part of Speech Tagging，POS），就是标注出一段文本中**每个词汇的词性**。

对比一下两个动词：NER 是**去找实体**，POS 是**去贴标签**。两个都属于文本处理的基本方法，但作用完全不一样，这就是它们老被放在一起问、又老被答混的原因。

### 为什么要看词性

词性标注的价值在于它给了你**理解文本语言的另一个角度**。

问一个问题：有些词在不同的语境里，能不能既当名词又当动词？能。那结合词性去理解一个词，就能更好地让大模型理解人所说的话。

看叠词。「**小龙女来到了杨过生活过的地方，动情地说，我也想过过过过过过的生活**」——这里有六个「过过」。有的「过过」是名词，因为它是人名；有的「过过」是动词；有的「过过」那可能就是形容词之类。

同一个字，意思不一样。如果你能把词性理解清楚，翻译就会准得多——早上看到的那台讯飞手持翻译机在翻「过过过过过过的生活」这种叠词的时候，翻出来的意思是相近的，但没那么精准。原因就在这里：**它没有把每个词的词性分析到位**。

再来一句：「**下雨天路滑，小明骑车一把把把把住了**。」还是同一个字，在不同的语境里词性也不一样。

> **结论**：分词是为了知道「词在哪」，词性标注是为了知道「这个词此刻是什么」。后者是从另一个角度切进文本语义的入口。

## 收束回文本预处理的目标

无论是分词、命名实体识别，还是词性标注，归根结底就一句话：**让大模型更好地理解人话**。大模型火的第一点是理解人话，第二点才是生成内容符合人类的用语习惯，而我们这一堆文本处理的基本方法，全部服务于第一点。

## 词性标注的代码实现

先看一句带标记的话：**我爱自然语言**。这里「我」是 `r`，「爱」是 `v`，「自然语言」是 `n`，「处理」是 `vn`。这些字母啥意思？看不懂就翻那张对照表——专门截下来过的那张**结巴词性对照表**，就是干这个用的。

代码从导包开始，跟以前不一样的地方只有一处：以前直接导 `jieba` 就能 `lcut`，现在多导一个子包，导的是**词性标注**的包。

```python
import jieba.posseg as pseg
```

写完就把 `demo01` 存下，另建一个脚本 `demo02`——我更想把它命名成 `demo02_pos`，因为它演示的就是词性标注。

```python
# 代码演示：文本预处理之词性标注
import jieba.posseg as pseg

# 名词解释
# NER = 命名实体识别（Named Entity Recognition）
#      识别出一段文本中可能存在的命名实体
# POS = 词性标注（Part of Speech Tagging）
#      标注出一段文本中每个词汇的词性

def demo02_pos():
    # 1. 定义变量，记录等待分词并标注词性的文本内容
    content = '我爱武汉黄鹤楼和东湖，还有传智教育科创园'

    # 2. 使用 jieba 的 posseg 做分词 + 词性标注
    result = pseg.lcut(content)
    print(f'result: {result}')

    # 3. 获取每组数据里的词与词性
    for word, flag in result:
        print(f'{word} : {flag}')

demo02_pos()
```

### 返回值是词与词性的配对

`result` 里面装的是 **pair**，也就是一对一对的：**左边是这个内容本身，也就是词；右边是它的词性**。

拿「我爱武汉黄鹤楼」这句看结果里的标记：

| 词 | 标记 | 含义 |
| --- | --- | --- |
| 我 | `r` | 代词 |
| 爱 | `v` | 动词 |
| 武汉 | `ns` | 地名 |
| 黄鹤楼 | `nr` | 人名 |

`r` 是代词，`v` 是动词，`ns` 是地名，这些对上对照表都说得通。但最后一行有问题：**黄鹤楼被识别成了人名**——按这个标记读下来，那就是「姓黄，名叫鹤楼」。

> **易错点**：结巴把 `黄鹤楼` 标成 `nr`（人名），这是它的通用词典对这个词的自然判断，跟我们常识里的地名不符。这类偏差正是用户自定义词典的用武之地。

要纠回来怎么做？**把我自己的词典用起来**：在词典里把「黄鹤楼」写进去，词频增一下，后面标一个 `ns`，就告诉它这是个地名。

> **提示**：结巴还没做到「屌到一统江湖」。如果真能做到，各机构、甚至一些学校就不会自己做分词器了。正因为通用工具需要容错手段，才有了用户自定义词典这一项。感兴趣的话可以自己写写看。

### 遍历结果与拆包

拿到 `result` 之后，第三个动作是把每组数据里的词和词性分别取出来：`for word, flag in result`，`word` 就是词，`flag` 就是标记，也就是词性。打印的时候中间可以加个笑脸隔开，也可以直接打。

为什么前面能写两个变量？因为我把里面那个 pair，也就是那一对儿，当成**元组**来处理就好了。这就是经典的**拆包**思想。代码确实简单。

## 文本预处理基本方法的总结

第一趴到这里就结束了。把整块内容快速收一遍。

### 分词的作用与中文分词的由来

分词就是**将连续的字符按照一定的规则重新排序的一个过程**。为什么要分词？因为要去**理解语义**，而**词是语义的最小单元**。

中文为什么要分词，英文为什么不需要？因为**英文有天然的空格，直接截取就好**；中文没有这种现成的分隔符，得自己去找那个**分界符**。

### jieba 的 API 一览

导包就是 `import jieba`，导完直接玩就行。主要讲了这几个：

| 能力 | 调用式 |
| --- | --- |
| 精确模式分词 | `jieba.lcut(content)`，即 `cut_all=False` |
| 全模式分词 | `jieba.lcut(content, cut_all=True)` |
| 搜索引擎模式分词 | `jieba.lcut_for_search(content)` |
| 用户自定义词典 | `jieba.load_userdict(path)` |
| 词性标注 | `jieba.posseg.lcut(content)` |

繁体字的处理也归在这里：不需要额外设置，直接 `lcut` 就能切。

### NER 与 POS 的口径

这一块必须把口径锁死，两个概念答混就是丢分：

- **命名实体**指的是人名、地名、机构名这些专有名词。**去句子中把这些名词识别出来，这个动作叫命名实体识别（NER）**。
- **词性标注（POS）**指的是**对一段话先切词，然后标记出每个词的词性**——到底是名词、动词还是形容词。

> **提示**：常用的几个标记值得顺手记一两个——名词用 `n`，动词用 `v`，其余去查对照表。**不要背，太多了背不完。**

## 本讲提到的题目

这一讲有三道单选题，都是围绕分词的定位和 NER、POS 的口径出的。

**题一**：在自然语言处理中，分词指的是？

- A. 将句子分解成单词或者字词的过程
- B. 将句子转换为另一种语言
- C. 将句子进行语法分析
- D. 将句子进行逻辑推理

> 答案：**A**。
> 解析：把句子转成另一种语言是机器翻译干的活；来回翻译几次，那是回译数据增强。语法分析和逻辑推理也都不是分词要做的事。分词的本质就是把连续字符按规则切分成词。

**题二**：以下哪个属于命名实体？

- A.
- B. 地名
- C. 动词
- D. 代词

> 答案：**B**（地名）。
> 解析：命名实体指的是人名、地名这一类专有名词。动词、形容词、代词这些不是实体，它们是**用来做词性标注**的类别。
> 这道题稍微改一改就变成送命题：「如下的动词、形容词、代词、叠词分别用哪个字母表示？你背一遍。」——所以标记体系可以不背，但要清楚它标的是词性，不是实体。

**题三**：词性标注指的是？

- A. 将句子分解成单词或者字词
- B. 给句子中的每个词汇标记相应的词性
- C.

> 答案：**B**。
> 解析：把句子分解成词是**分词**，不是词性标注；给每个词贴上词性标签才是词性标注。题一选 A、题二选 B、题三选 B，所以三题的答案连起来是 **A、B、B**。
