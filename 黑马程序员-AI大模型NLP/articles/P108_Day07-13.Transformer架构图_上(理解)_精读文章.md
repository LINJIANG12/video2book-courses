# Transformer 架构图逐项拆解：从词嵌入到 N× 堆叠

现在把整体的架构图细致地走一遍，告诉你每个组件到底是干什么用的。这一讲从下往上画：先画出总流程，再把编码器这一侧（也就是图左边这坨）的每一个组件逐个讲透。

## 总流程：一条从上到下的链路

先把总的流程写出来。

```text
        ┌───────────────────────┐
        │      输出概率选词       │
        ├───────────────────────┤
        │        softmax        │
        ├───────────────────────┤
        │        线性层          │
        ├───────────────────────┤
        │   解码器多层加工        │   掩码注意力 + 关联编码器的注意力 + 前馈
        ├───────────────────────┤
        │   编码器多层加工        │   注意力 + 前馈
        ├───────────────────────┤
        │       位置编码          │
        ├───────────────────────┤
        │       词嵌入层          │
        ├───────────────────────┤
        │       输入文字          │   Inputs
        └───────────────────────┘
```

读图说明：从下往上看这条链路，输入文字先进词嵌入层，再进位置编码，然后进编码器做多层加工，接着进解码器做多层加工，最后经线性层、softmax，得到输出概率并选词。

别人问你「Transformer 架构图能画出来吗」，能——大概就是从**输入文字 → 词嵌入 → 位置编码 → 编码 → 解码 → 线性 → softmax → 输出**这一堆。

> **定义**：编码器的多层加工分两块——**注意力 + 前馈**；解码器的多层加工分三块——**掩码注意力 + 关联编码器的注意力 + 前馈**。其中「关联编码器的注意力」，指的就是从编码器那边过来的那个注意力，它的条件是从编码器传过来的。

下面我从最底下这一层开始，一个一个往上画。

## 原文本嵌入层：把文字变成数值向量

最底下第一个是原文本嵌入层，英文写作 Input Embedding。

```text
   输入文字（Inputs）  ──►  原文本嵌入层（Input Embedding）  ──►  数值向量
```

> **定义**：原文本嵌入层的作用，一句话就是把输入的文字，比如一个单词，转成数值向量，算出三维的向量。

换成白话讲：**计算机看不懂文字，所以把文字转成计算机看得懂的数值。**

例如「你好」这两个字，转成 `0.1`、`-0.3`、`0.21` 这样一串数，等等等等。

## 位置编码：给词向量补上位置信息

往上第二层是位置编码，英文写作 Positional Encoding。

> **定义**：位置编码的作用是给词向量加上位置信息。

上一层能做的事，是把「我爱你」和「你爱我」转成词向量；但「我爱你」和「你爱我」里，这个「我」在前面还是后面，模型是不知道的。所以要在词向量的基础上再加上位置编码，把顺序补进去。

换白话讲：**Transformer 本身不明白词的顺序。** 所以要额外给每个位置一个坐标标签，告诉模型谁前谁后。

例如「我打你」和「你打我」，字一模一样，顺序一换，意思完全反过来。

## 多头注意力层：让模型从多个角度关注句子里的词

再往上是多头注意力层，英文写作 Multi-Head Attention。这一层是干什么的？注意力嘛——**让模型有侧重点**。

那「多头」是什么意思？你想想，哪吒有个技能叫三头六臂。三头是干什么用的？再想想那些探案片、或者特种兵打仗的站位——前面走一个人、后面再走一个人，就是防止背后放冷枪。有了多头以后，就可以从多个角度去观察战场的局势。

> **定义**：多头注意力就是让模型**同时从多个角度关注句子里的词**，从多个维度去分析，这样分析出来的结果就会更准一些，而不是只从一个点看。

举例：「猫追老鼠」这句话要去处理。

```text
        猫        追        老鼠
        │         │         │
        └────┬────┘         │
             │              │
        既要关注「猫」和「追」的关系
             │              │
             └──────┬───────┘
                    │
        也要关注「猫」和「老鼠」的关联
             │
        还有「追」和「老鼠」的关系
```

读图说明：把这一层的作用落到具体句子上，就是让模型从多个角度去观察句子里各个词的意思和它们之间的关联，而不是只盯住一个点。

这一层先大概理解，能听懂多少算多少，后面会给出代码。

## 残差连接与规范化层：让训练更稳、更高效

再往上是 Add 与 Norm，也就是**残差连接 + 规范化层**。

> **提示**：规范化层也叫层规范化、层归一化、归一化层，叫法都行，指的都是同一个东西。

这两个组件的作用合起来说就是：**让训练更稳，然后更高效。**

先说 Add。为什么这里要加一下？原因就在上一层——上一层的名字前两个字是什么？**多头**。多头不就是多个角度吗？多个角度看问题要不要合并结果？那肯定要。所以 Add 在这里出场了。

> **定义**：Add 是把注意力层的**输入和输出加在一起**，目的是防止信息丢太多。注意措辞是「丢太多」，不是「不丢失」——残差连接做的是把输入和输出加一起，让信息不至于在多层加工中被削掉太多。

再说 Norm。规范化是做归一化：把数值限制在某个范围内，避免训练时跑偏。

> **结论**：Norm 归一化的目的，是防止训练过程中出现**梯度消失或者梯度爆炸**——所谓跑偏，说的就是这类情况。

把这两个组件合起来理解：因为多头是从多个角度看，处理完了以后结果可能不太可控，所以通过残差连接和规范化，让多头看出来的这些角度在这里做一次信息的汇总。

## 前馈全连接层：给每个词单独强化特征

再往上最后一个组件是 Feed Forward，也就是**前馈全连接层**，也叫前馈网络层，叫法都有。

> **定义**：前馈全连接层的作用，是对**每个位置的词向量单独强化特征**。

「单独强化特征」这句话单听着会懵，举个例子就明白了：经过注意力层之后，再用全连接网络加工一下，给每个词注入更多细节。

例如：

- 「猫」——强化猫的**动物属性**，它是个动物；
- 「追」——强化追的**动作属性**，它是个动作。

也就是说，注意力层负责把词与词之间的关系拉出来，前馈全连接层负责给每个词本身补上更细的属性信息。

## N×：这一整套重复堆叠几次

再往上是 **N×**，表示重复堆叠。

> **定义**：N× 的作用是把上面的**多头注意力 + Add/Norm + 前馈网络**这一整套重复 N 次。

这里论文写的是 **6 次**。为什么需要重复？白话讲：**一层不够深，那就多堆几层。**

这么做的意义是让模型层层递进地理解文本：从**表面语义**走向**深层逻辑**。

打个比方就懂了：今天你的领导跟你谈了一段话，如果你只听他表面上的这段话，你可能不太知道他到底在向你传达什么信息；但如果你回去以后反反复复琢磨这件事、多思考几遍，你就能从中分析出更多信息。堆叠多层做的就是这件事——同一段文本，一层层往下琢磨，挖出更深的含义。

到这里，架构图左边这坨（编码器这一侧）就写完了。右边那坨（解码器）稍后继续。
