## 怎么学

课程主线很清楚：**文本预处理 → 词向量 → 循环网络 → 注意力 → Transformer → 预训练模型**。这条线不能跳，前面每个组件都是后面架构的零件。建议：

- **系统学** → `textbooks/` 从模块 01 顺序读到模块 16，模块 10~12 是 Transformer 的三连拆解，是全课核心
- **跑代码** → `textbooks/` 保留了课程中的代码与逐段解析。注意：只在幻灯片上出现、音频里没有口述的代码不会被补写，这类内容仍需回看视频
- **考前复习** → 直接看 `notes/`，11 篇笔记跨模块聚合，其中 Transformer 相关篇幅横跨多个模块
- **核对细节** → `subtitles/` 有全部 189 份逐字稿，适合检索课程里提过的具体 API 名或参数

模块 05~09 用两个完整案例（全球人名分类、英法机器翻译）把序列模型串起来，是理解注意力机制的最佳铺垫，不要跳过。
