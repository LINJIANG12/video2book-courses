## 1. 显示模式转换

> **一句话主旨**：讲清块级与行内及行内块三态特性，并用热区扩大与自适应标签及缝隙消除落地实战。

### 1.1 三态特性与转换规则

* **标准流（Normal Flow）**
    * > 定义：无特殊样式干预时浏览器默认解析渲染的流式排版方式。
    * 块级元素独占一行，不设宽度时默认填满父容器 100%。
    * 行内元素同行从左到右排列，排满自动折行。
    * > 来源: P56
* **块级元素（Block）**
    * > 定义：独占一行并可自由设置宽高与四向内外边距的元素形态。
    * 默认宽度为父容器 100%，典型原生标签为 `div`、`p`、`h1`~`h6`、`ul`、`li`。
    * `display: block` 使行内元素获得独占一行与尺寸控制能力。
    * > 来源: P56
* **行内元素（Inline）**
    * > 定义：不独占一行且尺寸由内容撑开的元素形态。
    * 直接设置 `width` 与 `height` 无效，垂直方向内外边距不占流空间。
    * 典型原生标签为 `span`、`a`、`strong`、`em`。
    * 转为 `display: inline` 的实战场景罕见，仅作理论了解。
    * > 来源: P56
* **行内块元素（Inline-block）**
    * > 定义：兼具同行并排与尺寸承载能力的复合显示形态。
    * 一行可并排多个，同时完全支持 `width` 与 `height` 及四向内外边距。
    * 原生典型标签为 `input`、`img`、`button`。
    * 2025 年工程中退守行内小图标与徽标标签等局部微调场景。
    * > 来源: P56

| 模式特征 | 块级元素（`block`） | 行内元素（`inline`） | 行内块元素（`inline-block`） |
| :--- | :--- | :--- | :--- |
| 同行排列 | 独占一行，从上往下 | 一行多个，从左往右 | 一行多个，从左往右 |
| 显式宽高 | 完全支持 | 不支持，设置无效 | 完全支持 |
| 默认宽度 | 撑满父级 100% | 由内容撑开 | 由内容撑开 |
| 内外边距 | 四向支持且正常推挤 | 水平有效，垂直不占流空间 | 四向支持且正常推挤 |

### 1.2 工业实战手法

* **热区扩大（display: block）**
    * > 定义：将行内链接转为块级以铺满整行点击区域的工程手法。
    * 小米侧边栏容器宽 `234px`，链接转块后宽度自动拉满 234px。
    * 链接定高 `height: 42px`，配 `line-height: 42px` 实现单行垂直居中。
    * `padding-left`推移文字，`:hover` 切换整行背景高亮色。
    * > 来源: P56
* **自适应胶囊标签（padding 撑开）**
    * > 定义：不定死宽而靠水平内边距随字数自适应伸展的排版法则。
    * 链接设 `display: inline-block`，定高 `32px` 配等值行高约束垂直方向。
    * 水平方向用 `padding: 0 16px` 自适应 2 字至 5 字文本，`border-radius: 16px` 成胶囊角。
    * 胶囊之间用 `margin: 0 6px` 隔离呼吸间距。
    * > 来源: P56

```css
.tag-group a {
    display: inline-block;
    height: 32px;
    line-height: 32px;
    padding: 0 16px;
    margin: 4px 6px;
    border-radius: 16px;
}
```

### 1.3 空白缝隙机理与消除

* **空白折叠（White-space Collapse）**
    * > 定义：行内块之间源码换行与空格被合并渲染为一个空格宽度的机制。
    * 600px 父盒放 3 个 200px 行内块仍掉行，盒间残留约 4px~8px 缝隙。
    * 缝隙宽度由当前 `font-size` 决定。
    * > 来源: P56
* **父级字号归零法（font-size: 0）**
    * > 定义：父容器字号清零使空白字符宽度归零的主流消除方案。
    * 父容器声明 `font-size: 0` 后，子元素必须显式重声明真实字号如 `14px`。
    * > 易错点：`font-size` 具继承性，遗漏子级重声明将致文字整体消失。
    * 源码紧贴法可消除空格但摧毁可读性，生产项目禁用。
    * > 来源: P56

## 2. 浮动与闭合浮动

> **一句话主旨**：讲清浮动图文环绕本源与脱标塌陷灾难，并收敛四种清除方案的选型结论。

### 2.1 浮动机制与多列推导

* **浮动（Float）**
    * > 定义：使元素向左右停靠并令文本环绕其四周的过渡性排版属性。
    * 取值仅 `none`（默认不浮动）、`left`（靠左）、`right`（靠右）三档。
    * 设计初衷为图文环绕，并非页面大骨架布局。
    * 新项目已全面停用，旧代码保留属历史债务妥协。
    * > 来源: P57
* **浮动排列特征（Float Layout）**
    * > 定义：同向浮动元素顶对齐紧贴且零缝隙排列的渲染行为。
    * 首个贴父容器内边，后续依次贴前一个浮动元素边缘。
    * 总宽超出父容器可用宽度时自动折行重排。
    * 浮动盒仍可自由设置 `width` 与 `height`。
    * > 来源: P57
* **多列间距推导（Margin Clearing）**
    * > 定义：按容器总宽反算盒宽与间隙并清零末项边距的像素规划法。
    * 600px 容器放 3 列：盒宽 190px，间隙 `(600 - 190 × 3) / 2 = 15px`。
    * 全员 `margin-right: 15px` 将致总宽 615px 挤掉末盒，必须清零末项。
    * 单行用 `:last-child`，多行矩阵用 `:nth-child(3n)` 清右外边距。
    * > 来源: P57
* **脱标（Out of Normal Flow）**
    * > 定义：浮动元素腾空悬浮且不再占据地基物理空间的本质特征。
    * 后续标准流兄弟视前方为空而前移钻底，发生层叠重叠。
    * > 来源: P57
* **父级高度塌陷（Height Collapse）**
    * > 定义：全员浮动子项无法撑开未定高父容器的结构性灾难。
    * 商业容器禁写死高度，应由子盒自然撑开以适配动态数据量。
    * 塌陷后后续板块上移穿透，页面版式错乱。
    * > 来源: P57

### 2.2 闭合浮动四方案

* **额外标签法（Clear Div）**
    * > 定义：末尾插入空块级标签并声明 `clear: both` 的早期土办法。
    * 机理为该标准流墙被推至浮动最底端从而撑开父容器。
    * 代价为污染 DOM 语义，现代工程弃用。
    * > 来源: P57
* **单伪元素清除法（Single Clearfix）**
    * > 定义：父级 `::after` 生成无形墙闭合浮动的工业标准写法。
    * 固定写法为 `content: ""`、`display: block`、`clear: both`，配 `height: 0` 与 `visibility: hidden` 防御。
    * 使用时直接给塌陷父盒挂 `.clearfix` 类名。
    * > 来源: P57
* **双伪元素清除法（Double Clearfix）**
    * > 定义：首尾双伪元素兼治浮动塌陷与父子外边距穿透的进阶写法。
    * `::before` 与 `::after` 共用 `content: ""` 加 `display: table`，尾部追加 `clear: both`。
    * 为小米等大厂标准写法。
    * > 来源: P57
* **溢出隐藏法（overflow: hidden）**
    * > 定义：父级单行声明触发块级格式化上下文以计入浮动高度的极简写法。
    * 底层规则为计算 BFC 高度时强制计入浮动子项高度。
    * > 易错点：溢出下拉菜单、气泡提示与角标将被一刀裁切，含溢出 UI 的组件禁用。
    * > 来源: P57

```css
.clearfix::after {
    content: "";
    display: block;
    clear: both;
    height: 0;
    visibility: hidden;
}
```

| 解决方案 | 核心代码原理 | 致命缺陷 | 工业采纳建议 |
| :--- | :--- | :--- | :--- |
| 额外标签法 | 尾部空 `div` 配 `clear: both` | 污染 DOM | 严禁使用 |
| 单伪元素清除 | 父级 `::after` 无形墙 | 需维护公共类名 | 强烈推荐 |
| 双伪元素清除 | `display: table` 双墙加尾部 `clear` | 代码多两行 | 强烈推荐 |
| BFC 清除法 | 父级 `overflow: hidden` | 裁切溢出菜单与角标 | 仅无溢出组件慎用 |

## 3. 弹性盒容器与双轴对齐

> **一句话主旨**：讲清父控子与主轴交叉轴几何，并收敛方向换行与两套对齐属性的取值结论。

### 3.1 容器激活与轴模型

* **父控子原则（Container Control）**
    * > 定义：排列对齐换行指令全部写在父容器上的弹性盒铁律。
    * 外层称容器（Flex Container），直属子盒称项目（Flex Item）。
    * 父子须为直接亲子关系，隔代须逐层嵌套声明。
    * `display: flex`、`justify-content` 等宏观属性禁写子项。
    * > 来源: P58
* **主轴与交叉轴（Main Axis and Cross Axis）**
    * > 定义：子项排队延伸的主方向与之正交的辅助方向。
    * 默认主轴水平向右，默认交叉轴垂直向下，子项默认沿主轴排队。
    * 交叉轴自动正交跟随，无须手动配置。
    * > 来源: P58, P60
* **弹性容器三优势（Flex Behavior）**
    * > 定义：子项天然同行且不脱标、父容器自适应撑高的渲染特性。
    * 子项无浮动式脱标与高度塌陷，外层兄弟排版不受干扰。
    * 注释掉父级定高后容器仍被子项稳稳撑开。
    * > 来源: P58
* **子项三态尺寸（Item Sizing）**
    * > 定义：显式尺寸照单渲染、缺省拉伸撑开、超宽等比压缩的三态机理。
    * 缺省高度时子项被 `align-items: stretch` 拉满父高，缺省宽度由内容撑开。
    * 默认 `flex-wrap: nowrap` 且收缩系数为 1，超宽时等比压缩，500px 父放 4 个 200px 盒各压至约 125px。
    * 商业卡片仍倡导显式尺寸或 `min-width` 保底防畸形压缩。
    * > 来源: P58, P61

### 3.2 主轴与单行交叉轴对齐

* **主轴对齐（justify-content）**
    * > 定义：分配子项尺寸之和小于容器时剩余空白空间的父容器属性。
    * `flex-start` 贴起点为默认，`flex-end` 贴终点，`center` 两侧等空居中。
    * `space-between` 两端贴边、中间平分，口诀为 A--B--C。
    * `space-around` 每项两侧等衬，中间为边缘 2 倍，口诀为 -A--B--C-。
    * `space-evenly` 全部缝隙绝对等宽，口诀为 -A-B-C-。
    * DevTools 中点选容器 `flex` 徽章可图形化预览各取值。
    * > 来源: P59
* **单行交叉轴对齐（align-items）**
    * > 定义：控制单行子项在交叉轴上对齐方式的父容器属性。
    * `flex-start` 顶对齐，`flex-end` 底对齐，`center` 为垂直居中王牌。
    * `stretch` 为默认值，无显式高度时拉满父高。
    * > 易错点：子项写死 `height` 后拉伸优先级低于显式尺寸，`stretch` 视觉无反应。
    * `line-height` 仅控单行文本基线，无法使块级盒垂直居中。
    * > 来源: P59
* **双轴复合（Dual Axis）**
    * > 定义：主轴管水平分布、交叉轴管垂直居中的协同作战范式。
    * 导航栏标准组合为 `justify-content: space-between` 加 `align-items: center`。
    * > 来源: P59

### 3.3 方向置换与换行体系

* **主轴方向（flex-direction）**
    * > 定义：设定主轴指向的父容器属性，共 `row`、`column`、`row-reverse`、`column-reverse` 四值。
    * `row` 默认从左到右，`column` 从上到下为本讲核心。
    * 反向两值仅用于聊天气泡镜像与底部向上时间线等特殊场景。
    * > 来源: P60
* **轴向置换法则（Axis Swap）**
    * > 定义：主轴转垂直后居中职责互换但属性认轴不认向的规律。
    * `column` 下垂直居中用 `justify-content: center`，水平居中用 `align-items: center`。
    * 判别只记主轴归 `justify-content`、侧轴归 `align-items`。
    * > 来源: P60
* **行内弹性块级化（Flex Blockification）**
    * > 定义：行内元素获 `display: flex` 后自动具备块级尺寸能力的隐藏特性。
    * `a` 与 `span` 无须再写 `display: block` 即可设宽高与内外边距。
    * 复杂界面采用外层管宏观分布、内层管微观对齐的双层嵌套架构。
    * > 来源: P60
* **换行控制（flex-wrap）**
    * > 定义：控制超宽子项折行与否的父容器属性，默认 `nowrap` 强行压缩。
    * `wrap` 放不下另起一行从上到下，为电商网格极高频取值。
    * `wrap-reverse` 多行自下而上堆叠，仅特殊图表使用。
    * 多行商品列表父容器禁写死高度，由换行子项自然撑开。
    * 行间距用子卡 `margin-bottom` 拉开。
    * > 来源: P61
* **多行交叉轴分配（align-content）**
    * > 定义：控制两行及以上整体在交叉轴上间距分配的父容器属性。
    * 与 `align-items` 的分野为单行管行内微观、多行管行间宏观。
    * 生效须同时满足已换行出多行与父容器在交叉轴有剩余空间。
    * 取值谱系与主轴一致，另有 `stretch` 默认拉伸平分父高。
    * 实战心法为 `flex` 加 `wrap` 加 `space-between` 配子卡下边距。
    * > 来源: P61

| 控制维度 | 核心属性 | 常用取值 | 使用场景 |
| :--- | :--- | :--- | :--- |
| 主轴方向 | `flex-direction` | `row`、`column` | 横向排或纵向上图下文 |
| 主轴对齐 | `justify-content` | `start`、`end`、`center`、`between`、`around`、`evenly` | 空白分配，两端对齐最高频 |
| 是否换行 | `flex-wrap` | `nowrap`、`wrap` | 电商网格必开 `wrap` |
| 单行交叉轴 | `align-items` | `start`、`end`、`center`、`stretch` | 单行垂直居中 |
| 多行交叉轴 | `align-content` | `start`、`end`、`center`、`between`、`around`、`evenly` | 多行间垂直空隙分配 |

## 4. 伸缩分配与多行网格工程

> **一句话主旨**：讲清份数伸缩与间隙扣除算法，并收敛淘宝京东多行方案与瀑布流底隙根治结论。

### 4.1 份数伸缩与间隙控制

* **伸缩份数（flex）**
    * > 定义：写在子项身上瓜分父容器剩余空间份数的属性。
    * `flex: 1` 占 1 份，`flex: 2` 占 2 份，数值越大份额越高。
    * 主轴方向计算优先级绝对高于子项 `width` 与 `height`。
    * 4 项全 `flex: 1` 时各占父宽 1/4，随视口毫秒级自适应。
    * 1、1、2、1 配比下总 5 份，1000px 容器中 3 号占 400px。
    * > 来源: P62
* **剩余空间扣除（Free Space）**
    * > 定义：先剔除外边距与间隙再切分份数的浏览器计算次序。
    * 1000px 父放 4 个 `flex: 1` 且各 `margin-right: 10px` 时，可分空间为 960px，每盒 240px。
    * 800px 父放 4 个 `flex: 1` 配 `gap: 10px` 时，间隙耗 30px，每盒 192.5px。
    * 加外边距绝不掉行。
    * > 来源: P62
* **三位一体解构（flex Shorthand）**
    * > 定义：`flex: 1` 等价于三子属性复合简写的底层结构。
    * 展开为 `flex-grow: 1`、`flex-shrink: 1`、`flex-basis: 0%`。
    * `grow` 管剩余拉伸，`shrink` 管不足压缩，`basis` 为分配前初始占位。
    * > 来源: P62
* **轨道间隙（gap）**
    * > 定义：只在子项之间生成空隙且两端零边距的父容器属性。
    * 单值如 `gap: 20px` 行列统一，双值如 `gap: 20px 10px` 前行后列。
    * 彻底淘汰 `margin-right` 加 `:last-child` 修复写法。
    * 传统尾项外边距会破坏 `space-between` 两端贴边。
    * > 来源: P62

```css
.box {
    display: flex;
    gap: 15px;
}
.box .item {
    flex: 1;
}
```

### 4.2 淘宝与京东多行方案

* **单值伸缩失效（flex-wrap Conflict）**
    * > 定义：全员 `flex: 1` 时基准归零致换行阈值永不触发的冲突机理。
    * `flex-basis: 0%` 使 14 盒同分一行 100% 空间，总和不溢出故不换行。
    * 破局关键为给定明确尺寸基准，使第 7 项挤爆首行。
    * > 来源: P63
* **淘宝百分比方案（Percentage Basis）**
    * > 定义：外层占位配内层内容并以负边距抵消端头白边的嵌套方案。
    * 子项声明 `flex: 0 0 16.666667%`，即不拉伸不收缩、基准为六等分之一。
    * 百分比项禁加水平 `margin`，否则 100% 加 96px 必爆框掉行。
    * 外层 `.item` 用 `padding: 0 8px` 造透明缝，内层 `.content` 承载业务。
    * 父 `.box` 用 `margin-left: -8px` 与 `margin-right: -8px` 抵消两端 8px。
    * 版心居中须拆 `.w` 外层承载，否则负边距覆盖 `auto` 致失居中。
    * 窄屏靠媒体查询切换 20% 与 25% 降列。
    * > 来源: P63
* **京东计算约束方案（calc Constraint）**
    * > 定义：单层盒子配最值锁定与动态扣减的扁平方案。
    * 子项保留 `flex: 1`，用 `min-width` 与 `max-width` 双锁 `16.666667%` 逼出换行。
    * 间隙直接写 `margin: 0 8px 16px`，纯宽改写 `calc(16.666667% - 16px)` 对冲。
    * 六项总占宽恒为 100%，分毫不差。
    * > 易错点：`calc` 内加减号两侧必须留空格，紧贴致整行失效。
    * > 来源: P63
* **一二维边界（1D and 2D）**
    * > 定义：多行多列非 Flex 强项而属 Grid 领地的设计哲学界限。
    * Flex 为一维擅单行分配对齐折行，Grid 为二维专行列交叉网格。
    * Grid 双行声明即可替代嵌套负边距与像素计算。
    * > 来源: P63

| 评估维度 | 淘宝实现方案 | 京东实现方案 |
| :--- | :--- | :--- |
| Flex 核心属性 | `flex: 0 0 16.666667%` | `flex: 1` |
| 换行约束手段 | 固定百分比基准 | `min-width` 与 `max-width` 双锁 |
| 间隙实现方式 | 父级透明 `padding` 加内层盒 | 子盒直接 `margin` |
| 尺寸计算机制 | 纯百分比 | `calc()` 动态扣像素 |
| DOM 复杂度 | 高，需内外嵌套 | 低，单层承载 |
| 低版本兼容性 | 极佳，IE8 起 | 良好，依赖 `calc`，IE9 起 |

### 4.3 瀑布流与图片底隙

* **分列瀑布流架构（Waterfall Columns）**
    * > 定义：外层水平 Flex 分列、内层普通流垂直堆叠的两层建模范式。
    * 单主轴纵向 Flex 难维护动态追加高度，故化整为零按列排布。
    * 1180px 版心放 5 列各 `flex: 1`，列间隙一行 `gap: 16px`。
    * 列内卡片用 `margin-bottom: 15px` 拉垂直间距。
    * > 来源: P64
* **热区圆角裁切（Hotspot Clipping）**
    * > 定义：圆角挂可交互父层并以溢出隐藏裁直角子图的层级设计。
    * `a` 转 `display: block` 配 `width: 100%` 撑满列宽以扩大点击热区。
    * `border-radius: 18px` 须挂 `a` 层，仅挂 `img` 将致热区残直角。
    * 子图直角覆盖父圆角时，父层追加 `overflow: hidden` 硬裁。
    * 图片只写 `width: 100%` 不写高度，靠固有宽高比等比联动。
    * > 来源: P64
* **基线幽灵缝隙（Baseline Gap）**
    * > 定义：行内图片贴基线而容器探底线致底侧残留 3px~5px 的排印落差。
    * `img` 默认行内块遵循基线对齐，容器须容纳降笔字母故底边下探。
    * 全局 `margin` 与 `padding` 清零无法消除。
    * > 来源: P64
* **底隙双解法（Gap Fixes）**
    * > 定义：转块脱离基线体系或改垂直对齐锚点的两套根治手段。
    * 常规业务首选 `display: block`，底边与父容器瞬间贴合。
    * 保行内特性时改 `vertical-align` 为 `top`、`middle`、`bottom` 任一，百度原版取 `top`。
    * 图文混排图标文字居中取 `vertical-align: middle`。
    * 老 IE 中 `a` 包 `img` 自动套蓝边，祖传库用 `img { border: 0; }` 防御。
    * > 来源: P64

| 属性值 | 垂直对齐基准 | 能否消除底隙 |
| :--- | :--- | :--- |
| `baseline` | 默认贴文本基线 | 否，产生幽灵缝隙 |
| `top` | 贴整行顶线 | 是，百度原版做法 |
| `middle` | 中线对齐 | 是 |
| `bottom` | 贴整行底线 | 是 |

| 文件夹名 | 存放内容与生命周期 | 典型素材示例 |
| :--- | :--- | :--- |
| `images` | 静态皮肤结构，永久存在 | Logo、精灵图、装饰底纹 |
| `uploads` | 动态商品数据，随时增删 | 生鲜实拍、瀑布流卡片图 |

* **三层样式架构（CSS Layers）**
    * > 定义：按重置、公共、页面专属拆分职责的外部样式表体系。
    * `base.css` 负责清内外边距、列表去点、链接去下划线与盒模型统一。

    * `index.css` 只存首页轮播、商品楼层等独有板块。
    * 引入顺序须为图标库、`base.css`、`common.css`、`index.css`，倒置致业务细节被重置冲刷。
    * > 来源: P65, P77
* **初始化与版心（Reset and Wrapper）**
    * > 定义：全局重置打底加 1240px 居中容器的公共底座。
    * `body` 基准为 `font-size: 16px`、`color: #333`，`em` 与 `i` 去倾斜备图标位。
    * `img` 统配 `vertical-align: middle` 根除底隙，`input` 清边框与聚焦轮廓，`h1`~`h6` 去加粗。
    * 版心类 `.w` 固定 `width: 1240px` 加 `margin: 0 auto`，业务标签多类名追加复用。
    * > 来源: P65
* **文本截断工具（ellipsis）**
    * > 定义：抽离公共类的单行溢出省略 DRY 封装。
    * 三件套为 `white-space: nowrap`、`overflow: hidden`、`text-overflow: ellipsis`，缺一不可。
    * 挂载示例为 `<h3 class="title ellipsis">`，防长标题撑爆固定卡高。
    * > 来源: P75, P77

    * 深层裸标签选择器随结构一改全崩，京东式全员类名降耦合。
    * 注释同时服务协同定位与三个月后排障。
    * 解法不唯一，贴合设计稿即成立，遇更优再吸收。
    * > 来源: P77
* **防御性留白（Defensive Gaps）**
    * > 定义：为动态数据与后续定位预埋结构与样式的工程前瞻。
    * 搜索图标位、角标容器、轮播注释占位皆先行预留。
    * 标准流与 Flex 负责骨架，未竟的压盖悬浮待定位接管。
    * > 来源: P68, P71, P76, P77

## 6. 定位系统与层叠次序

> **一句话主旨**：讲清四类定位的脱标与基准差异，并收敛居中算法与固定粘性及层叠选型结论。

### 6.1 相对定位与绝对定位及子绝父相

* **定位总纲（Positioning）**
    * > 定义：以边偏移将元素定至参考系特定位置并具层叠能力的布局技术。
    * 解决脱离文档流、层叠压盖、锁定特定坐标三件事。
    * 默认 `static` 无定位，遵循常规流且边偏移与层叠无效。
    * > 来源: P78, P83
* **相对定位（relative）**
    * > 定义：相对自身原位偏移且停职留薪保留占位的定位。
    * 基准为标准流原始左上原点，兄弟不顶替，骨架不扰动。
    * 上下冲突听 `top`，左右冲突听 `left`。
    * > 易错点：相对非相对父容器移动，主业为充当绝对定位之父。
    * > 来源: P78
* **绝对定位（absolute）**
    * > 定义：彻底脱标并以最近定位祖先为基准的自由层叠定位。
    * 无定位祖先时基准退为视口初始包含块，后方兄弟立刻顶补。
    * 冲突优先级同相对，上听顶左听左。
    * > 来源: P78
* **子绝父相（Child Absolute Parent Relative）**
    * > 定义：子绝对配父相对的最经典黄金搭档口诀。
    * 子须脱标悬浮故取绝对，父须限域故必须带定位。
    * 父取相对因其既供坐标系又不脱标，父取绝对将致下方模块冲顶盖压。
    * 搜框镜、角标、轮播箭头皆属此式。
    * > 来源: P78

| 定位模式 | 核心声明 | 是否脱标 | 移动参照基准 |
| :--- | :--- | :--- | :--- |
| 相对定位 | `position: relative` | 否，原位保留 | 自身原始位置 |
| 绝对定位 | `position: absolute` | 是，空间塌陷 | 最近定位祖先，无则视口 |
| 固定定位 | `position: fixed` | 是，空间塌陷 | 仅浏览器可视窗口 |
| 粘性定位 | `position: sticky` | 混合，阈值前后切换 | 滚动祖先或视口，受父界约束 |

### 6.2 定位实战与居中算法

* **搜索图标定位（Search Icon）**
    * > 定义：父相对锁域、子绝对压面、输入框内边距避让的三件套。
    * `.search` 取 `position: relative`，图标取 `absolute` 配 `top: 7px` 与 `left: 0`。
    * 输入框 `padding-left: 28px` 防文字被镜遮挡。
    * 删父定位将致图标飞至视口左上。
    * > 来源: P79
* **角标自适应法则（Badge Growth）**
    * > 定义：弃固定宽高改内边距撑开并锁定左边界向右生长的徽标规范。
    * 初版 `width: 16px` 加 `border-radius: 50%` 加 `right: 0` 在多位时溢出并左胀盖图标。
    * 定稿取 `left: 20px`、`padding: 2px 6px`、`border-radius: 8px`、`white-space: nowrap`。
    * 单字近圆、多字成胶囊，核心图标永不被侵占。
    * > 来源: P79
* **轮播指示器（Carousel Dots）**
    * > 定义：容器相对锚定、圆点绝对压右下、阴影扩散作光环的组件。
    * `.banner` 取 `position: relative` 配 `1240px × 500px`，圆点盒取 `bottom: 20px` 与 `right: 20px`。
    * 单点 `14px × 14px` 半透明白底纯圆，项间 `margin: 0 8px`，配 Flex 横排。
    * 悬停与激活态禁 `border`，改 `box-shadow: 0 0 0 4px rgba(255,255,255,0.5)`。
    * > 易错点：边框占盒模型几何，悬停加框必挤兄弟抖动，阴影零占位则丝滑。
    * 分类栏须 `z-index: 1` 方压住后写轮播图。
    * > 来源: P79
* **定位垂直居中（Centering Formula）**
    * > 定义：走父一半回己一半的两步像素校准公式。
    * 脱标后 `margin: 0 auto` 失效，单写 `top: 50%` 因上缘对线而整体偏下。
    * 定稿为 `top: 50%` 加 `margin-top: -30px`，60px 高盒回退一半。
    * 百分比 `top` 基准为父高，负边距基准为自身高。
    * 双向模板为 `left: 50%` 加 `margin-left: -宽一半` 叠加纵向同式。
    * 未知尺寸场景后置 `transform: translate(-50%,-50%)` 升级。
    * > 来源: P80, P83
* **翻页按钮工程（Prev and Next）**
    * > 定义：40px×60px 半透明箭头贴边并垂直居中的轮播操控件。
    * 公共样式并集抽取定位居中与底色对齐，左钮 `left: 250px` 避分类栏，右钮 `right: 0`。
    * 左钮写 `left: 0` 将被 250px 侧栏活埋。
    * 图标 `text-align: center` 加 `line-height: 60px` 双向居中。
    * > 来源: P80
* **滚动画廊综合（Cat Gallery）**
    * > 定义：子绝父相加伪元素椭圆障眼加弹性锁宽的横向相册系统。
    * 视口 `.box` 取 `1000px` 居中加 `position: relative` 加 `overflow: hidden`。
    * 默认 `nowrap` 加收缩 1 将致 12 个 200px 卡压扁至约 83px。
    * 子项须 `flex: 0 0 200px`，即不拉伸不压缩基准 200px，强制横向溢出。
    * 伪元素挂 `.box` 而非 `ul`，否则遮罩随卷走；绝对定位伪元素免 `display: block` 直设尺寸。
    * 椭圆 `100% × 100px` 配 `border-radius: 50%`，上下各偏 50px，底色须同页面。
    * 文案塞 `content`，上行高 125px 下行高 55px，配 `pointer-events: none`。
    * 轨道 `overflow-x: scroll` 加 `scroll-behavior: smooth`，隐藏条用 `scrollbar-width: none` 与 `::-webkit-scrollbar`。
    * 滚轮脚本取 `e.deltaY × 1.5` 累加 `scrollLeft` 并 `preventDefault` 截纵向。
    * > 来源: P81

### 6.3 固定定位与粘性定位及层叠

* **固定定位（fixed）**
    * > 定义：永远唯一以视口为基准且滚轮不跟随的定位。
    * 脱标致后方元素顶补上浮覆盖，行内设固定免转块直设尺寸。
    * 水平 `left` 与 `right` 冲突听左，垂直 `top` 与 `bottom` 冲突听顶。
    * 定宽水平居中取 `left: 50%` 加 `margin-left: -300px`，600px 盒回退一半。
    * 返回顶部取 `right: 0` 与 `bottom: 100px`，`html` 加 `scroll-behavior: smooth` 化生硬闪跳。
    * > 来源: P82
* **粘性定位（sticky）**
    * > 定义：阈值前相对占标、触线后吸附固定的混合定位。
    * 须至少显式声明 `top`、`bottom`、`left`、`right` 之一，常取 `top: 0`。
    * 祖先设 `hidden`、`auto`、`scroll` 易截断失效，父出界即被带走。
    * 吸顶条须显式背景色，否则下方图文穿透成乱码。
    * 表头吸顶与吸顶导航为两大工业场景。
    * > 来源: P82
* **层叠默认规则（Stacking Default）**
    * > 定义：定位天然高于标准流与浮动、同级后来者居上的裁决链。
    * 三维 Z 轴正对用户眼球，值大者逼近遮挡值小者。
    * 同值回归源码先后，负值沉至标准流之下可被父背景盖住。
    * > 来源: P83
* **层叠指数（z-index）**
    * > 定义：控制定位元素 Z 轴坐标的纯整数属性。
    * 取正整数、`0`、负整数，默认 `auto` 与父同层。
    * > 易错点：仅对 `relative`、`absolute`、`fixed`、`sticky` 有效，静态写万级亦废纸；禁带 `px` 等单位。
    * 悬停置顶取 `:hover` 配 `z-index: 1` 叠 `translateY` 放大。
    * 吸顶导航穿透取 `z-index: 999` 断层压全页。
    * > 来源: P83

| 核心维度 | 固定定位（`fixed`） | 粘性定位（`sticky`） |
| :--- | :--- | :--- |
| 文档流状态 | 完全脱标 | 阈值前占标，触线后吸附 |
| 参考基准 | 仅浏览器视口 | 滚动祖先或视口，受父界约束 |
| 方位依赖 | 边偏移可选 | 至少显式其一 |
| 受溢出影响 | 不受父 `overflow` 阻碍 | 祖先非 `visible` 易失效 |
| 经典场景 | 侧边栏、返回顶部、居中弹窗 | 吸顶导航、长表表头 |

## 7. 网格布局体系

> **一句话主旨**：讲清轨道划分与弹性响应及跨行跨列，并收敛项目对齐与全景速查结论。

### 7.1 容器轨道与弹性度量

* **二维网格（Grid）**
    * > 定义：以行列正交骨架同时约束双向空间的排版模型。
    * Flex 为一维内容驱动，单轴线性且换行各行独立难跨行对齐。
    * Grid 为二维骨架驱动，先规划轨道再注内容，原生跨行跨列。
    * 选型为单行单列找 Flex，多行多列找 Grid，二者混用不替代。
    * B 站顶部单行取 Flex，视频卡片墙取 Grid。
    * > 来源: P84
* **网格四术语（Grid Terms）**
    * > 定义：容器、项目、轨道、单元格与网格线的结构抽象。
    * 容器为 `display: grid` 或 `inline-grid` 父元，项目仅限直接子代。
    * 行轨道为水平空间，列轨道为垂直空间，单元格为行列交叉最小矩形。
    * N 列配 N+1 列线，M 行配 M+1 行线，编号自 1 起禁 0 起。
    * > 来源: P84, P87
* **轨道声明（Template Tracks）**
    * > 定义：以空格参数个数定轨数、数值定尺寸的显式划分语法。
    * `display: grid` 后默认单列轨道，子项仍竖排占满。
    * 九宫格取三 `100px` 列轨加三 `100px` 行轨，子项先行后列自动填入并撑满格。
    * 固定列数不写行轨可借隐式网格无限延展，淘宝 6 列即此式。
    * 轨道群分布用 `justify-content` 管水平、`align-content` 管垂直。
    * > 来源: P84
* **弹性份数（fr）**
    * > 定义：Grid 专用剩余空间等分单位，为 Fraction 缩写。
    * 300px 容器三 `1fr` 各 100px，`1fr 2fr 1fr` 总 4 份中轨占 150px。
    * 规则写父容器轨道参数，改一数即调列，子项零侵入。
    * 换行后各列仍共享列宽，跨行竖向严格对齐。
    * > 来源: P85
* **槽道间隙（gap）**
    * > 定义：控行列轨道间物理距离且不损盒模型的现代间距属性。
    * 单值双向统一，双值前行后列，分支为 `row-gap` 与 `column-gap`。
    * 旧前缀 `grid-gap` 系草案写法，新项目一律标准 `gap`。
    * 容器边缘无间隙，边缘留白走 `padding`。
    * 计算先扣固定轨与间隙再分份，300px 三列配 10px 间隙各约 93.33px。
    * > 来源: P85
* **重复函数（repeat）**
    * > 定义：以次数加轨道模式展开重复声明的原生函数。
    * `repeat(3, 1fr)` 等价三均分，`repeat(11, 1fr)` 等价十一均分。
    * 支持周期模式如 `repeat(3, 1fr 2fr)`，无规律三值禁套用。
    * B 站 11 列双行导航取 `repeat(11, 1fr)` 加 `repeat(2, 1fr)` 加 `gap: 10px`。
    * > 来源: P85

| 对比维度 | 弹性盒（`flex: 1`） | 网格（`1fr`） |
| :--- | :--- | :--- |
| 声明位置 | 子项各自书写 | 父容器轨道统管 |
| 局部改动成本 | 高，须拎出子盒重设 | 极低，改父级一参 |
| 多行约束 | 各行各自为政难对齐 | 全列共享列宽跨行对齐 |

### 7.2 响应式填充与网格线流向

* **自动填充（auto-fill and auto-fit）**
    * > 定义：按单轨最小尺寸自发计算列数的 `repeat` 自动化关键字。
    * 800px 容器配 100px 轨加 10px 间隙自建 7 列，子少仍保留空槽。
    * 子少时 `auto-fill` 留白等后文，`auto-fit` 折叠空轨拉伸已有子项铺满。
    * 子足填满一行以上时二者无差别。
    * > 来源: P86
* **极值约束（minmax）**
    * > 定义：限定轨道尺寸闭区间的下限保底上限撑满函数。
    * 下限常取像素如 210px 触发折行，上限常取 `1fr` 消灭右侧白边。
    * 纯 `1fr` 无下限致列数难算，纯像素致临界残留死白边。
    * 神级公式为 `repeat(auto-fill, minmax(210px, 1fr))`。
    * 父容器须 `max-width` 而非死宽，否则感知不到收缩。
    * 媒体子元须 `width: 100%` 加 `height: 100%`，210px 源自设计稿最小可读宽。
    * > 来源: P86

| 关键字 | 空轨道策略 | 典型场景 |
| :--- | :--- | :--- |
| `auto-fill` | 保留空轨，子项保尺寸 | 电商货架，防小量拉大 |
| `auto-fit` | 折叠空轨，已有项铺满 | 仪表盘监控卡，整宽平铺 |

* **跨行跨列（Grid Span）**
    * > 定义：以起止网格线合并多格的项目属性，须写子元禁写父容。
    * 显式式为 `grid-column: 1 / 3` 与 `grid-row: 1 / 3`，各跨 2 轨占 4 格。
    * 相对式为 `1 / span 2`，免心算结束线。
    * 判网格数看最密小单元，B 站区取 5 列 3 行，首卡跨双行双列。
    * 跨行项须 `height: auto`，否则死高截断留大片空白。
    * 分写为 `grid-column-start` 与 `grid-column-end` 及行向同对。
    * > 来源: P87
* **自动流向（grid-auto-flow）**
    * > 定义：控制未显式定位项先行或先列入格的父容器属性，默认 `row`。
    * `column` 下纵向填满再开新列，B 站分类扁平数据免拆列容器。
    * 跨列项在纵流下易被推上首行空缺，须并锁 `grid-row: 2 / 3` 钉死。
    * 画廊骨架取 2 行 3 列，首卡纵跨双行，第三卡横跨后两列并锁次行。
    * > 来源: P88
* **媒体适配（object-fit）**
    * > 定义：替换元素保比例充满容器的缩放属性。
    * `width: 100%` 加 `height: 100%` 直写将致窄屏压扁拉长。
    * `contain` 全图留白，`cover` 充满裁剪为商业卡片最常用，`fill` 默认拉伸弃用。
    * 对位背景 `background-size` 同名值，焦点用 `object-position` 调，默认中心。
    * 行内图片底侧 2px~3px 缝隙取 `display: block` 根除。
    * > 来源: P88

| 属性值 | 渲染行为 | 适用场景 |
| :--- | :--- | :--- |
| `fill` | 强制拉伸填满 | 破坏比例，基本弃用 |
| `contain` | 最长边贴界留白 | 详情大图全展示 |
| `cover` | 最短边填满裁剪 | 商业卡片充满不变形 |

### 7.3 项目对齐与体系总览

* **单元格项目对齐（Item Alignment）**
    * > 定义：控制子项在各自单元格内几何定位的父容器声明。
    * 缺省无尺寸时默认 `stretch` 拉满格，定死 50px 格内 100px 格默认停左上。
    * `justify` 永远管水平，`align` 永远管垂直。
    * 四值中 `start` 靠左或靠顶，`end` 靠右或靠底，`center` 双向正中。
    * `stretch` 有定尺寸退化为 `start`。
    * 复合 `place-items` 为先垂直后水平，企业实战倡导分开写防记混。
    * > 来源: P89
* **轨道与项目分野（Content and Items）**
    * > 定义：大骨架对不齐找 Content、格内小件对不齐找 Items 的判别口诀。
    * `justify-content` 与 `align-content` 挪整套轨道群，解容器大于网格。
    * `justify-items` 与 `align-items` 管格内子元，解格大盒小。
    * DevTools 点容器 `grid` 徽章可视化调试走位。
    * > 来源: P89

| 属性组合 | 作用靶标 | 物理矛盾 | 典型取值 |
| :--- | :--- | :--- | :--- |
| `justify-content` 与 `align-content` | 网格轨道整体 | 容器大而网格小 | `center`、`space-between` |
| `justify-items` 与 `align-items` | 格内子元素 | 格大而子盒小 | `start`、`end`、`center`、`stretch` |

| 维度分类 | 核心属性 | 核心取值要点 | 工业场景 |
| :--- | :--- | :--- | :--- |
| 容器启航 | `display` | `grid` 与 `inline-grid` | 初始化网格上下文 |
| 轨道规划 | `grid-template-columns` 与 `grid-template-rows` | `repeat(11, 1fr)` | 骨架与陈列墙导航 |
| 动态响应式 | `repeat` 加 `auto-fill` 加 `minmax` | `repeat(auto-fill, minmax(210px, 1fr))` | 无断点卡片流 |
| 槽道间隙 | `gap` 与 `row-gap`、`column-gap` | `10px` 与 `20px 10px` | 替代子项边距 |
| 流向次序 | `grid-auto-flow` | `row` 与 `column` | 竖排清单与媒体瀑布 |
| 宏观对齐 | `justify-content` 与 `align-content` | `center` 与 `space-between` | 网格群分布 |
| 微观对齐 | `justify-items` 与 `align-items` | `start`、`end`、`center`、`stretch` | 头像居中与靠底 |

## 8. 多列布局与书写规范

> **一句话主旨**：讲清流式分栏与防断裂三属性，并收敛鼠标语义与五梯队书写结论。

### 8.1 多列布局与防断裂机制

* **多列布局（Multi-column Layout）**
    * > 定义：将单容器内容自动分割灌入多垂直列的 CSS3 排版模块。
    * 两大场景为长文本报刊分栏与不等高卡片瀑布流。
    * 数据纵向先填满首列再流向次列，语雀与 Iconfont 生产采用。
    * Flex 与 Grid 模拟须手包列容器并用 JS 重算搬运，多列仅改列数自动重排。
    * > 来源: P90
* **三核心属性（Column Properties）**
    * > 定义：列数、列隙、栏间线的三行声明体系。
    * `column-count` 取纯整数，子盒免设宽度，单列宽按父宽扣隙均分。
    * 1200px 父配 4 列 20px 隙时单列 `(1200 - 60) / 4 = 285px`。
    * `column-gap` 只管列间水平缝，默认约 `1em`，上下间距须子元 `margin-bottom`。
    * `column-rule` 复合语法同 `border`，居中渲染于间隙且零占位。
    * > 来源: P90

| 对比维度 | Flex 与 Grid 模拟瀑布流 | 多列布局瀑布流 |
| :--- | :--- | :--- |
| DOM 嵌套 | 须手包列容器，结构冗余 | 单父容器扁平排列 |
| 数据灌入 | 模版或 JS 手算分列 | 线性灌入自动分流 |
| 响应式改列 | 须 JS 搬运节点 | 仅改 `column-count` |
| 排列顺序 | 人工交错分发 | 默认纵向流动 |

* **跨列断裂与防御（Column Break）**
    * > 定义：流式介质列末任意截断与卡片防折断机制。
    * 长文本折断属报刊本意，17 个 150px 盒配 4 列时第 5 盒被腰斩上下分列。
    * 子元追加 `break-inside: avoid` 加 `-webkit-column-break-inside: avoid` 双保险。
    * 语义为整盒放不下即完整挪次列顶，瀑布流必加。
    * > 来源: P90

```css
.box {
    column-count: 4;
    column-gap: 20px;
    column-rule: 1px dashed #ff4d4f;
}
.box .item {
    margin-bottom: 20px;
    break-inside: avoid;
    -webkit-column-break-inside: avoid;
}
```

### 8.2 鼠标样式与属性书写顺序

* **鼠标样式（cursor）**
    * > 定义：以光标形态传递可点禁用拖拽等状态暗示的属性。
    * `pointer` 为链接按钮最高频小手，`not-allowed` 为禁用禁行符。
    * `text` 为工字文本光标，`wait` 为加载沙漏圆环，`help` 为问号提示。
    * `move` 为十字拖拽，`grab` 张掌 `grabbing` 握拳，`zoom-in` 与 `zoom-out` 管预览缩放。
    * 购物车减号置灰须配 `not-allowed` 止用户狂点。
    * 自定义图写法为 `cursor: url('my-cursor.png'), auto`，商业系统首选原生语义。
    * > 来源: P91

| 属性值 | 光标形态 | 适用场景 |
| :--- | :--- | :--- |
| `default` | 标准箭头 | 普通非交互区 |
| `pointer` | 食指小手 | 链接按钮可点卡片 |
| `text` | 工字形 | 段落与可选词句 |
| `not-allowed` | 禁止符号 | 禁用按钮与无权限项 |
| `wait` | 沙漏圆环 | 提交与拉取等待遮罩 |
| `help` | 问号指针 | 释义与气泡帮助入口 |
| `move` | 十字四向 | 可拖浮窗与弹窗头 |
| `grab` 与 `grabbing` | 张掌与握拳 | 地图画布抓取平移 |
| `zoom-in` 与 `zoom-out` | 加减放大镜 | 缩略全屏与还原 |

* **五梯队书写顺序（Declaration Order）**
    * > 定义：按布局定位、盒模型、视觉文本、交互动效、高级杂项依次书写的团队规范。
    * 价值为降检索认知负荷并支撑 Stylelint 自动化校验。
    * 第一梯队含 `display`、`visibility`、`position` 系、`float`、`clear`、`overflow` 及 Flex 与 Grid 容器控制。
    * 第二梯队含 `box-sizing`、宽高三元、内外边距、边框轮廓。
    * 第三梯队含字体排印、`color`、背景系、圆角阴影。
    * 第四梯队含 `cursor`、`opacity`、`transition`、`transform`、`animation`。
    * 第五梯队含 `filter`、裁剪遮罩、`content`、`will-change`。
    * 小米导航、京东推荐链、淘宝按钮线上源码皆严守布局居首动效收尾。
    * > 来源: P91

```css
.card {
    display: flex;
    position: relative;
    z-index: 1;
    width: 200px;
    height: 300px;
    margin-top: 10px;
    padding: 15px;
    border: 1px solid #dddddd;
    background-color: #ffffff;
    font-size: 14px;
    color: #333333;
    cursor: pointer;
    transition: all 0.3s ease;
}
```

| 知识模块 | 核心准则 | 实战要点 |
| :--- | :--- | :--- |
| `cursor` 鼠标样式 | 状态与光标语义吻合 | 可点用 `pointer`，禁用用 `not-allowed`，拖拽用 `grab` 系 |
| 梯队 1 布局定位 | `display` 与 `position` 系 | 最先书写，定宏观落点 |
| 梯队 2 自身盒模型 | 宽高与边距边框 | 第二顺位，定几何外形 |
| 梯队 3 文本视觉 | 色彩字体背景阴影 | 第三顺位，定修饰装潢 |
| 梯队 4 交互动效 | `cursor` 与过渡动画 | 第四顺位，定反馈补间 |
| 梯队 5 高级杂项 | 滤镜裁剪等 | 尾部收束前沿特性 |
