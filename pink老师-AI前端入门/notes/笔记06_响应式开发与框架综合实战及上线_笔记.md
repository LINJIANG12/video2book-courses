# 响应式开发与框架综合实战及上线
## 媒体查询与断点体系


* **响应式布局（Responsive Layout）**
    * > **定义**：一套 `HTML` 通过不同 `CSS` 规则自适应多种屏幕宽度的布局方式
    * 同一套结构，窄屏单列加汉堡菜单，宽屏多列加完整导航，中间自动过渡
* **媒体查询（Media Query）**
    * > **定义**：写在 `CSS` 里按条件生效的分支语句，关键字为 `screen`、`max-width`、`min-width`、`and`
    * `max-width: 768px` 表示宽度小于等于 `768px` 时生效，`min-width` 反之，写反则逻辑颠倒
    * 基础样式写桌面端，媒体查询写文件最下方，后写覆盖先写
    * `max-width` 覆盖时按先大后小书写，小屏规则在后才能压住大屏规则
```css
.container { width: 1170px; margin: 0 auto; }
@media screen and (max-width: 992px) { .container { width: 970px; } }
@media screen and (max-width: 768px) { .container { width: 750px; } }
```
* **断点（Breakpoint）**
    * > **定义**：布局切换的视口宽度阈值，写在 `@media` 条件里
    * 取值照抄主流框架 `768px`、`992px`、`1200px`，不自创怪数
    * 定断点的方法是拖窗口，看何处挤爆挤叠即定何处
    * 京东仿站档位为容器 `1170px`、`970px`、`750px`，商品列数对应 `4` 列、`3` 列、`2` 列
    * 容器按档跳变，不连续伸缩，保证卡片整数列不变形
* **外链样式按需加载**
    * `media` 属性挂在 `link` 上，浏览器按宽度决定下载哪份样式
```html
<link rel="stylesheet" href="./css/pc.css" media="screen and (min-width: 993px)">
<link rel="stylesheet" href="./css/mobile.css" media="screen and (max-width: 768px)">
```
    * `media` 只控制用不用该文件，文件内选择器写法不变
* **响应式与自适应区分**
    * 自适应是给手机单独做一版，响应式是一套代码靠媒体查询内部切换
    * 响应式改结构只改一处，代价是 `CSS` 写三档、调试量更大
    * | 方案 | 结构 | 切换手段 |
      | :--- | :--- | :--- |
      | 自适应 | 两套页面 | 条件写死，容器 `100%` |
      | 响应式 | 同一套 | 同一选择器随宽度覆盖，容器 `1170px` 切 `750px` |
* **导航折叠与次要元素隐藏**
    * 两套导航 `HTML` 常驻，大屏 `.nav-full { display: flex; }`，小屏翻转为 `.nav-full { display: none; }`、`.nav-mini { display: block; }`
    * 顶部促销条、侧边广告栏在 `max-width: 768px` 下一律 `display: none`
    * > **易错点**：隐藏用 `display: none`，`visibility: hidden` 仍占位，会留空白
    * 商品区用 `display: flex; flex-wrap: wrap;`，卡片宽度按 `25%`、`33.33%`、`50%` 对应四三两列
    * | 档位 | 容器 | 商品 | 导航 |
      | :--- | :--- | :--- | :--- |
      | 大于 `992px` | `1170px` | 4 列 | 完整横排 |
      | `768px` 到 `992px` | `970px` | 3 列 | 精简 |
      | 小于 `768px` | `750px` | 2 列 | 汉堡，次要元素隐藏 |

## DesignCode 头部响应式


### 版心与顶部通告栏

* **版心（Container）**
    * > **定义**：页面内容居中的最大宽度区域，本项目取 `1200px`
```css
.wrap { width: var(--wrap-width); max-width: 100%; margin: 0 auto; padding: 0 24px; }
```
    * `width: 1200px` 写死会出现横向滚动条，`max-width: 100%` 加左右 `24px` 则自动收缩
    * 只有 `.topbar` 是通栏背景内套版心，`.header` 本身版心居中，背景不写到内层
    * | 写法 | 桌面 | 窄屏 |
      | :--- | :--- | :--- |
      | `width: 1200px` | 居中正常 | 横向滚动条 |
      | `width + max-width: 100%` | 居中正常 | 自动收缩 |
* **顶部通告栏（Topbar）**
    * 外层管背景高度，内层管版心与弹性对齐，不可混淆
```css
.topbar { background-color: var(--topbar-bg); font-size: 13px; }
.topbar-inner { display: flex; justify-content: center; align-items: center; gap: 12px; height: 36px; }
```
    * 高度取 `36px`，舒适区间为 `32px` 到 `40px`
    * 小屏先保证不换行不撑爆：`white-space: nowrap; overflow: hidden; text-overflow: ellipsis;`，字号降至 `12px`
    * 项目变量为 `--main-color: #5457f5`、`--text-dark: #111827`、`--text-gray: #6b7280`、`--topbar-bg: #111827`，首行写死 `box-sizing: border-box`

### 标志与导航栏

* **语义化（Semantics）**
    * > **定义**：用贴切标签表达内容含义，`h1` 表示页面主标题，权重大于 `div`
    * 一个页面只放一个 `h1`，标志放入 `h1` 拉满权重
    * 并列链接闭眼用 `ul > li > a`，导航区外包 `nav` 供读屏播报
    * | 写法 | 显示 | 语义 |
      | :--- | :--- | :--- |
      | `div.logo > a` | 正常 | 无权重 |
      | `h1.logo > a` | 正常 | 主标题权重 |
* **标志背景图写法**
```css
.logo { width: 180px; height: 36px; }
.logo a { display: block; width: 100%; height: 100%; background: url("../images/logo.png") no-repeat left center / contain; font-size: 0; }
.header { display: flex; align-items: center; height: 72px; }
```
    * `a` 不加 `display: block` 则宽高失效，背景只剩一行字高
    * `background-size: contain` 按比例缩进盒子不裁剪，`cover` 会裁掉左右
    * `font-size: 0` 与 `text-indent: -9999px` 均可藏字，前者不产生超宽滚动
    * 路径 `../images/logo.png` 因 `index.css` 在 `css/` 下，需先退一层
    * 标志在任何屏幕下固定 `180px`，不缩水不换行
* **导航间距与状态**
```css
.nav ul { display: flex; align-items: center; gap: 28px; }
.nav a { font-size: 15px; font-weight: 500; line-height: 72px; }
.header { display: flex; align-items: center; justify-content: space-between; height: 72px; }
.nav { flex: 1; margin-left: 40px; }
```
    * `flex` 加在 `ul` 上，`nav` 只占位，`gap` 写父级，不逐项写 `margin`
    * `line-height: 72px` 同步头高，垂直居中且整块可点击
    * 悬停变主色加 `transition: color 0.2s`，当前项 `.nav li.active a` 加粗加主色，裸写 `.active` 权重不够
    * | 属性 | 取值 | 作用 |
      | :--- | :--- | :--- |
      | `display` | `flex` | 横排 |
      | `gap` | `28px` | 等距 |
      | `line-height` | `72px` | 居中并扩大点击区 |

### 汉堡菜单切换

* **汉堡按钮（Burger）**
    * 结构用 `button` 加 `aria-label="menu"`，天生可聚焦可回车，`div` 模拟需自补键盘事件
```html
<button class="burger" aria-label="menu"><span></span><span></span><span></span></button>
```
```css
.burger { display: none; flex-direction: column; justify-content: center; gap: 5px; width: 40px; height: 40px; background: none; border: 0; cursor: pointer; }
.burger span { display: block; height: 2px; width: 22px; margin: 0 auto; border-radius: 2px; }
@media (max-width: 1024px) { .burger { display: flex; } }
```
    * `span` 不加 `display: block` 则宽高无效，三线挤成一团
    * 视觉线宽 `22px`，点击区 `40px`，可点击至少 `40px`，窄屏放大点击区
    * 父级用 `margin-left: auto` 贴右，`72px` 内垂直居中
    * | 元素 | 桌面大于 `1024px` | 移动小于等于 `1024px` |
      | :--- | :--- | :--- |
      | `.nav` | 显示 | `none` 隐藏 |
      | `.btn-login` | 显示 | `none` 隐藏 |
      | `.burger` | `none` 隐藏 | `flex` 显示 |
    * 隐藏必须用 `display: none`，`visibility: hidden` 与 `opacity: 0` 仍占位
    * 断点取 `1024px` 与 `768px`，依据为导航加按钮约 `700px` 加标志 `180px`，`1000px` 附近重叠，拖窗看坏点即定点

## 课程区骨架与入口


### 版心骨架与标题节奏

* **课程三段分层**
    * 外层 `section.courses` 管背景留白，`.w` 管宽度居中，`.courses-bd` 管排列，不可搅合
```html
<section class="courses"><div class="w"><div class="courses-hd"></div><div class="courses-bd"></div></div></section>
```
```css
.w { max-width: 1200px; margin: 0 auto; padding: 0 24px; }
.courses { padding: 96px 0; background-color: #f5f7fa; }
.courses-hd { text-align: center; margin-bottom: 56px; }
.courses-hd h2 { font-size: 40px; font-weight: 700; line-height: 1.2; }
.courses-hd p { margin-top: 16px; font-size: 17px; line-height: 1.6; color: #666; }
.courses-bd { display: grid; grid-template-columns: repeat(3, 1fr); gap: 32px; }
```
    * 模块标题用 `h2`，`h1` 留给站点名
    * 标题 `40px` 对副标题 `17px`，差一倍以上才分清主次，组内紧组间松
    * `repeat(3, 1fr)` 等价三遍 `1fr`，`fr` 自动吃掉剩余宽度
    * > **易错点**：`width: 1200px` 手机必出横向滚动，响应式一律 `max-width`
    * | 层 | 管的事 | 关键属性 |
      | :--- | :--- | :--- |
      | `section.courses` | 背景留白 | `padding: 96px 0` |
      | `.w` | 宽度居中 | `max-width: 1200px; margin: 0 auto` |
      | `.courses-hd` | 对齐组距 | `center; margin-bottom: 56px` |
      | `.courses-bd` | 排列 | `grid; gap: 32px` |
* **图标分类行**
    * 语义为并列导航，用 `ul`，图标用字体图标（Iconfont），一次请求且随 `font-size` 缩放不发虚
```css
.cate { display: flex; justify-content: center; gap: 48px; margin-bottom: 40px; }
.cate a { display: flex; flex-direction: column; align-items: center; gap: 12px; font-size: 14px; }
.cate .iconfont { width: 56px; height: 56px; line-height: 56px; text-align: center; font-size: 28px; border-radius: 50%; }
```
    * 纵向弹性加居中为图标导航固定搭配，宽高不等则切出椭圆
    * > **易错点**：`line-height` 等高仅对单行图标字体居中有效，多行文字失效

### 搜索框与响应式变阵

* **胶囊搜索框**
    * 输入框类型用 `search`，移动端键盘带搜索键
```css
.search { display: flex; align-items: center; max-width: 560px; margin: 0 auto; padding: 6px 6px 6px 20px; border: 1px solid #e5e5e5; border-radius: 999px; box-shadow: 0 8px 24px rgba(0, 0, 0, 0.06); }
.search input { flex: 1; border: 0; outline: 0; font-size: 15px; background-color: transparent; }
.search button { padding: 12px 28px; font-size: 15px; color: #fff; background-color: #5e5ce6; border: 0; border-radius: 999px; cursor: pointer; }
```
    * `border-radius: 999px` 半径给足即全圆，不用算一半高度
    * 输入框须清 `border` 与 `outline`，否则胶囊内套方框，`flex: 1` 吃掉剩余宽度
    * | 部件 | 手法 | 关键取值 |
      | :--- | :--- | :--- |
      | `.cate` | 横向居中散开 | `center; gap: 48px` |
      | 图标圆底 | 等宽高等行高全圆 | `56px; 50%` |
      | `.search` | 横向弹性 | `999px; flex: 1` |
* **课程变阵断点**
    * 断点取 `1024px` 与 `768px`，桌面三列，平板两列，手机单列
```css
@media (max-width: 1024px) { .courses-bd { grid-template-columns: repeat(2, 1fr); gap: 24px; } }
@media (max-width: 768px) {
  .courses-bd { grid-template-columns: 1fr; gap: 20px; }
  .courses { padding: 64px 0; }
  .courses-hd h2 { font-size: 28px; }
  .cate { gap: 24px; flex-wrap: wrap; }
  .search { max-width: 100%; }
}
```
    * 媒体查询只改列数、间隙、留白、字号，版心 `max-width` 不动
    * 平板间隙 `32px` 收至 `24px`，手机图标行必须 `flex-wrap: wrap`，搜索框放开至 `100%`
    * | 档位 | 条件 | 列数 | 附带 |
      | :--- | :--- | :--- | :--- |
      | 桌面 | 默认 | `repeat(3, 1fr)` | 基准 |
      | 平板 | `max-width: 1024px` | `repeat(2, 1fr)` | 间隙 `24px` |
      | 手机 | `max-width: 768px` | `1fr` | 留白 `64px`、标题 `28px`、图标换行 |
    * > **易错点**：漏写 `width=device-width, initial-scale=1.0` 时手机按 `980px` 假宽渲染，断点永不进入

## 卡片动效与故事波浪


### 课程卡片结构与内部小盒子

* **卡片外框与封面比例**
    * 语义用 `article`，封面正文上下两截，角标绝对定位压图
```css
.card { background-color: #fff; border-radius: 20px; overflow: hidden; box-shadow: 0 10px 30px rgba(0, 0, 0, 0.08); }
.card-cover { position: relative; aspect-ratio: 16 / 9; overflow: hidden; }
.card-cover img { width: 100%; height: 100%; object-fit: cover; }
.card-cover .tag { position: absolute; left: 16px; top: 16px; padding: 6px 12px; font-size: 12px; border-radius: 999px; }
```
    * 纵横比（Aspect Ratio）`aspect-ratio` 写容器，图片 `100%` 铺满，反写则变宽露白边
    * `overflow: hidden` 配圆角，否则图片直角戳出卡片
    * 平板只收圆角至 `16px`，手机翻为左右结构，封面 `flex: 0 0 128px; aspect-ratio: 1 / 1;`，标题 `16px`
    * > **易错点**：弹性容器只写 `width: 128px` 会被挤小，锁死用 `flex: 0 0 128px`
    * | 档位 | 形态 | 封面 |
      | :--- | :--- | :--- |
      | 桌面 | 上下堆叠 | `16 / 9` 横图 |
      | 平板 | 上下堆叠 | 不变，只收圆角 |
      | 手机 | 左图右文 | `1 / 1` 方图 `128px` |
* **正文小盒子弹性**
    * 标题独占一行，讲师行左中右散开，底部价格评分顶两端
```css
.card-body { padding: 20px; }
.card-body h3 { font-size: 18px; line-height: 1.4; white-space: nowrap; overflow: hidden; text-overflow: ellipsis; }
.meta { display: flex; align-items: center; gap: 8px; margin-top: 12px; font-size: 13px; }
.meta .avatar { width: 28px; height: 28px; border-radius: 50%; object-fit: cover; }
.meta .lessons { margin-left: auto; }
.foot { display: flex; align-items: center; justify-content: space-between; margin-top: 16px; padding-top: 16px; border-top: 1px solid #eee; }
.foot .price { font-size: 18px; font-weight: 700; }
```
    * 自动外边距（Auto Margin）在弹性布局吃掉剩余空间，`margin-left: auto` 即推到最右
    * 标题三件套 `nowrap + hidden + ellipsis` 防撑高，否则卡片忽高忽低
    * > **易错点**：头像只写 `50%` 不锁宽高，长方形切出椭圆，须配等宽高加 `cover`
    * | 小盒子 | 手法 | 关键属性 |
      | :--- | :--- | :--- |
      | 标题 | 单行省略 | `nowrap; ellipsis` |
      | 讲师行 | 左贴右弹 | `flex; margin-left: auto` |
      | 底部行 | 两端加线 | `space-between; border-top` |

### 悬停分层与故事模块

* **悬停分层过渡**
    * 分三层各配 `transition`，动画写常态，变化写 `:hover`
```css
.course-card { background-color: #fff; border-radius: 20px; box-shadow: 0 8px 24px rgba(0, 0, 0, 0.06); transition: transform 0.3s ease, box-shadow 0.3s ease; }
.course-card:hover { transform: translateY(-8px); box-shadow: 0 20px 48px rgba(0, 0, 0, 0.14); }
.course-card .pic { overflow: hidden; border-radius: 20px 20px 0 0; }
.course-card .pic img { width: 100%; height: 100%; object-fit: cover; transition: transform 0.5s ease; }
.course-card:hover .pic img { transform: scale(1.08); }
.course-card .more { opacity: 0.4; transform: translateX(-6px); transition: opacity 0.3s ease, transform 0.3s ease; }
.course-card:hover .more { opacity: 1; transform: translateX(0); }
```
    * `translateY(-8px)` 只视觉位移不占文档流，不挤旁卡，位移取 `6px` 到 `12px`，小元素 `6px`
    * 图片 `0.5s` 比卡片 `0.3s` 慢一拍，节奏错开才有层次，去掉 `overflow: hidden` 则图片漫出圆角
    * 只过渡变化项，不写 `transition: all`，优先用 `transform` 与 `opacity`
    * | 写法 | 效果 | 取舍 |
      | :--- | :--- | :--- |
      | `all 0.3s` | 全属性过渡 | 不用 |
      | `transform + shadow 0.3s` | 只过渡变化项 | 采用 |
      | 常态过渡悬停变化 | 进出均有动画 | 必须如此 |
* **故事区搭建与变阵**
    * 语义为 `section` 包 `h2` 加 `p`，卡片用 `article`，图片必写 `alt`
```css
.stories-body { display: grid; grid-template-columns: 1.2fr 1fr; gap: 28px; }
.story-main { background-color: #fff; border-radius: 24px; overflow: hidden; box-shadow: 0 16px 40px rgba(0, 0, 0, 0.08); }
.story-main .pic img { width: 100%; height: 320px; object-fit: cover; }
.story-main .info { padding: 28px; }
.story-main .quote { font-size: 20px; line-height: 1.6; }
.story-item { display: flex; gap: 16px; align-items: center; border-radius: 18px; padding: 16px; }
.story-item .pic img { width: 120px; height: 96px; border-radius: 12px; object-fit: cover; flex-shrink: 0; }
```
    * 大卡列给 `1.2fr`，主角比配角宽，`fr`（fraction）分剩余空间
    * `1024px` 以下主体变 `1fr`，大图降至 `260px`，小卡列表变两列网格，`768px` 以下小卡列表回单列，小卡内部改竖排图片全宽高 `180px`
    * 手机引言 `20px` 降至 `17px`，内边距 `28px` 降至 `20px`，大图降至 `220px`
    * > **易错点**：小图不加 `flex-shrink: 0` 会被弹性压缩压扁，只改列数不改字号图高属于半截工程
    * | 区间 | 大卡 | 小卡列表 | 小卡内部 |
      | :--- | :--- | :--- | :--- |
      | 大于 `1024px` | 左列 `1.2fr` | 右列纵排 | 横向图文 |
      | `768px` 到 `1024px` | 独占一行 | 两列网格 | 横向图文 |
      | 小于 `768px` | 独占一行 | 单列 | 竖向全宽图 |

### 裁剪页脚与装饰修错

* **裁剪路径（clip-path）**
    * > **定义**：用几何函数圈定元素可见区域的属性，裁掉部分不显示但盒子仍在
    * `polygon` 按顺时针百分比绕一圈，圈内留圈外剪，`ellipse` 画椭圆弧
```css
.wave { clip-path: polygon(0 0, 100% 0, 100% 85%, 0 100%); }
.stories { clip-path: ellipse(75% 100% at 50% 0%); }
.divider { height: 120px; background-color: #0b0d12; clip-path: polygon(0 60%, 10% 40%, 20% 55%, 30% 35%, 40% 55%, 50% 40%, 60% 60%, 70% 45%, 80% 60%, 90% 45%, 100% 60%, 100% 100%, 0 100%); }
@media (max-width: 768px) { .divider { height: 70px; } }
```
    * 波浪顶边 `y` 在 `35%` 到 `60%` 摆动，振幅 `25%` 以内，百分比天然响应式
    * | 方案 | 做法 | 问题 |
      | :--- | :--- | :--- |
      | 波浪图片背景 | 定位到底边 | 拉伸变形加请求 |
      | `clip-path` 百分比 | 纯 `CSS` | 自适应无资源 |
* **页脚四列与订阅胶囊**
    * 语义外层 `footer`，顶部四列加底部版权行，链接组用 `dl + dt + dd`
```css
.footer-top { display: grid; grid-template-columns: 1.4fr 1fr 1fr 1fr; gap: 32px; }
.subscribe { display: flex; align-items: center; background-color: #f3f4f6; border-radius: 999px; padding: 6px 6px 6px 18px; }
.subscribe input { flex: 1; border: 0; outline: none; background-color: transparent; }
.subscribe button { border: 0; border-radius: 999px; padding: 10px 22px; background-color: #111827; color: #fff; cursor: pointer; }
@media (max-width: 1024px) { .footer-top { grid-template-columns: 1fr 1fr; } .brand { grid-column: 1 / -1; } }
@media (max-width: 768px) { .footer-top { grid-template-columns: 1fr; } .footer-bottom { flex-direction: column; gap: 12px; text-align: center; } .subscribe { width: 100%; } }
```
    * `grid-column: 1 / -1` 横跨整行，不受列数变化影响，`span 2` 列变即错位
    * 手机订阅框须 `width: 100%`，按钮两字即可，四字会挤输入框
    * | 区间 | 顶部 | 底部 |
      | :--- | :--- | :--- |
      | 大于 `1024px` | 四列，品牌 `1.4fr` | 左右分布 |
      | `768px` 到 `1024px` | 两列，品牌通栏 | 左右分布 |
      | 小于 `768px` | 单列堆叠 | 上下居中 |
* **飘动装饰与两处修错**
    * 小圆绝对定位脱离文档流，父级 `.banner` 须 `relative` 加 `overflow: hidden`，小圆加 `pointer-events: none` 防挡点击
    * 位移动画（`transform` animation）只改变 `transform` 与 `opacity`，不触发重排，可走合成器线程
```css
@keyframes floatY { 0% { transform: translateY(0); } 50% { transform: translateY(-18px); } 100% { transform: translateY(0); } }
.dot1 { animation: floatY 3s ease-in-out infinite; }
.dot2 { animation: floatY 4.2s ease-in-out 0.6s infinite; }
.dot3 { animation: floatY 3.6s ease-in-out 1.1s infinite; }
@keyframes floatScale { 0%, 100% { transform: translateY(0) scale(1); } 50% { transform: translateY(-22px) scale(1.12); } }
```
    * 三圆时长延迟错开防齐上齐下，幅度 `18px` 到 `22px`，小屏藏大圆缩小靠边
    * 导航残留修法为大屏 `@media (min-width: 769px)` 强制横排无视 `open`，加 `resize` 超 `768px` 清 `open` 类，`JS` 只换类显隐交 `CSS`
    * 横向滚动修法先 `html, body { overflow-x: hidden; }` 加父级裁剪，再治本为小屏隐藏探出装饰、卡片改 `max-width: 100%`、图片限宽，`overflow-x` 只是保险丝
    * 验收取 `1200px`、`768px`、`375px` 各刷新加点汉堡开合加左右拖测
    * | 断点 | 策略 |
      | :--- | :--- |
      | 大于 `992px` | 三圆全显 |
      | 小于等于 `768px` | 藏大圆缩小靠边 |
      | 小于等于 `480px` | 减小动画幅度 |

## Bootstrap 栅格与图标


### 框架引用与容器组件

* **前端框架（Framework）**
    * > **定义**：封装好布局、组件与 `JS` 插件的半成品页面库，只写结构与类名即拼出统一兼容界面
    * `Bootstrap`（简称 `bs`）源自 `Twitter` 内部样式库，现学第 `5` 版
    * 第 `3` 版用 `float` 加依赖 `jQuery`，第 `5` 版栅格换 `flex`，不再强依赖 `jQuery`
    * 框架解决快而稳，不解决独一无二，高度定制仍须自写 `CSS` 覆盖
    * | 维度 | 手写 | 框架 |
      | :--- | :--- | :--- |
      | 栅格 | 百分比加媒体查询 | `row + col` 十二等分 |
      | 按钮表单 | 逐个调 | `btn btn-primary` 一行 |
      | 兼容文档 | 靠经验 | 官方文档即查即用 |
* **本地与在线引用**
    * 本地取 `css/bootstrap.min.css` 与 `js/bootstrap.bundle.min.js`，离线可跑，`CSS` 放头部，`JS` 放 `body` 尾
    * 学习期用内容分发网络（Content Delivery Network，CDN）复制两行，认准 `5.x`
```html
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
```
    * 自写 `style` 压在框架之后，谁后谁赢，写前则被覆盖
    * > **易错点**：`link` 缺 `rel="stylesheet"` 则静默失效，仍为裸 `HTML`
    * 验证写 `class="btn btn-primary"`，出蓝色圆角即成功，否则查 `Network` 路径版本
* **版心容器与常用组件**
    * 容器（Container）即居中版心，`container` 随断点定宽居中，`container-fluid` 永远 `100%`
    * 断点（Breakpoint）预设为 `576px`、`768px`、`992px`、`1200px`，容器栅格依附切换
```html
<button class="btn btn-primary">主要操作</button>
<button class="btn btn-success">提交成功</button>
<button class="btn btn-danger">删除</button>
<button class="btn btn-outline-primary">描边按钮</button>
<table class="table table-striped table-hover table-bordered"></table>
```
    * `btn` 管形状，`btn-*` 管颜色，缺 `btn` 则形状不出
    * 表单为 `form-control` 配文本框、`form-select` 配下拉、`form-check-input` 配复选，间距用 `mb-3`，规律为 `m/p + t/b/s/e/x/y + 0~5`
    * | 类名 | 作用 |
      | :--- | :--- | :--- |
      | `table-striped` | 隔行变色 |
      | `table-hover` | 悬停高亮 |
      | `table-bordered` | 全边框 |
      | `btn-lg / btn-sm` | 尺寸档 |

### 十二列与列控制

* **栅格列（Column）**
    * > **定义**：`row` 内按十二等分划分的纵向槽位，数字即占几份，如 `col-4` 占 `4/12`
    * 三件套为 `container` 版心、`row` 行、`col-*` 列，列包行内行包容器，跨级必出多余边距
    * 同行份数按 `12` 配，`4+8`、`3+6+3`、`6+6` 铺满，超 `12` 自动换行
    * `row` 自带负边距吃掉列内边距，列间槽（gutter）才整齐，`col` 直丢 `container` 则两侧对不齐
    * 移动优先，先写小屏份数再用断点类覆盖，只写 `col-md-4` 则手机三列硬挤叠字
    * | 前缀 | 宽度 | 记忆 |
      | :--- | :--- | :--- |
      | `col-` | 小于 `576px` | 手机竖屏默认 |
      | `col-sm-*` | 大于等于 `576px` | 横屏 |
      | `col-md-*` | 大于等于 `768px` | 平板 |
      | `col-lg-*` | 大于等于 `992px` | 小桌面 |
      | `col-xl-*` | 大于等于 `1200px` | 大桌面 |
      | `col-xxl-*` | 大于等于 `1400px` | 超宽屏 |
```html
<div class="container"><div class="row">
<div class="col-12 col-md-4">课程介绍</div>
<div class="col-12 col-md-4">课程目录</div>
<div class="col-12 col-md-4">学员评价</div>
</div></div>
```
* **偏移与整行等分排序**
    * 偏移（offset）写自身左边空几轨，`col-6 offset-3` 因 `12-6=6` 一边 `3` 即居中
```html
<div class="row"><div class="col-6 offset-3">居中</div></div>
<div class="row"><div class="col-3">图片</div><div class="col-7 offset-1">文字</div></div>
<div class="row"><div class="col-12 col-md-6 offset-md-3">手机满行电脑居中</div></div>
<div class="row row-cols-2 row-cols-md-4"><div class="col">卡片1</div><div class="col">卡片2</div><div class="col">卡片3</div><div class="col">卡片4</div></div>
```
    * 偏移加在被空者自身，`offset-md-3` 为手机不偏平板上偏
    * `row-cols-*` 写 `row` 上子项自动平分，商品宫格用此招
    * 排序（order）只改视觉不改 `DOM`，读屏搜索仍见源码顺序，`order-1` 到 `order-5` 数小靠前，另有 `order-first`、`order-last`、`order-md-2`
    * 对齐因 `row` 本质为弹性盒（flexbox），水平用 `justify-content-*`，垂直用 `align-items-*`
    * 槽宽（gutter）用 `g-*`、`gx-*`、`gy-*`，`g-0` 去缝，微调优先改 `--bs-gutter-x` 或 `g-*`，直写 `col` 的 `margin` 会撑破等分挤掉末列
    * | 类名 | 作用 | 场景 |
      | :--- | :--- | :--- |
      | `order-1` 到 `order-5` | 数小靠前 | 图文对调 |
      | `order-first` | 抢最前 | 重要提前 |
      | `order-last` | 沉最后 | 次要垫后 |
      | `order-md-2` | 断点排序 | 手机电脑顺序不同 |
* **字体图标（icon font）**
    * > **定义**：字形为图标的字体文件，官方套件为 Bootstrap Icons
```html
<link rel="stylesheet" href="./css/bootstrap-icons.min.css">
<i class="bi bi-search"></i><i class="bi bi-person"></i><i class="bi bi-cart3"></i><i class="bi bi-list"></i>
```
    * 大小用 `font-size`，颜色用 `color`，悬停可换色
    * > **易错点**：图标不显示多为 `CSS` 路径错或 `fonts` 文件夹未整 folder 搬运，相对路径缺字体即失效
    * 实战组合为 `row-cols-2 row-cols-md-4 g-3 text-center` 配四图标文案，手机两列电脑四列

## vivo 导航与轮播产品


### 官网骨架与导航栏

* **项目骨架与层叠（cascade）**
    * 目录为 `index.html`、`css/bootstrap.min.css`、`css/bootstrap-icons.min.css`、`css/index.css`、`js/bootstrap.bundle.min.js`、`images/`，自写与库文件分离
```html
<link rel="stylesheet" href="./css/bootstrap.min.css">
<link rel="stylesheet" href="./css/bootstrap-icons.min.css">
<link rel="stylesheet" href="./css/index.css">
```
    * 自写样式放框架后，谁后谁赢，`JS` 放 `body` 结束前
    * > **易错点**：只引 `CSS` 不引 `JS` 则汉堡轮播点不动
    * 头部须写 `charset="UTF-8"`、`lang="zh-CN"`、`width=device-width, initial-scale=1.0`，缺视口（viewport）则手机不按设备宽渲染，响应式全废
    * `body` 先留五段注释：导航、轮播、热门产品、未来科技、底部
* **标题描述关键词优化（Title Description Keywords，TDK）**
```html
<title>vivo官网-vivo X100系列新品|拍照旗舰手机官方正品</title>
<meta name="description" content="vivo官方网站提供X系列、S系列、Y系列智能手机，官方正品保障，顺丰包邮，七天无理由退换。">
<meta name="keywords" content="vivo,vivo官网,vivo手机,X100,拍照手机,智能手机">
<link rel="shortcut icon" href="./images/favicon.ico">
```
    * | 标签 | 对象 | 要求 |
      | :--- | :--- | :--- |
      | `title` | 用户与搜索结果 | 品牌加产品加卖点，`30` 字内 |
      | `description` | 搜索摘要 | 卖什么有何保障，`80` 字内，不写空话 |
      | `keywords` | 搜索引擎分类 | `6` 到 `8` 词逗号隔，不堆砌 |
    * 图标（favicon）取 `32x32` 的 `ico`，版心（container）取 `1200px` 左右，`Bootstrap` 用 `container` 类实现
* **导航折叠与覆盖**
    * 断点展开（expand）指大于某宽横铺、小于折叠，`navbar-expand-lg` 即 `992px` 为界，菜单多选 `lg` 最稳
```html
<nav class="navbar navbar-expand-lg navbar-dark"><div class="container">
<a class="navbar-brand" href="#"><img src="./images/logo.png" alt="vivo" height="30"></a>
<button class="navbar-toggler" type="button" data-bs-toggle="collapse" data-bs-target="#vivoNav"><span class="navbar-toggler-icon"></span></button>
<div class="collapse navbar-collapse" id="vivoNav"><ul class="navbar-nav mx-auto">
<li class="nav-item"><a class="nav-link active" href="#">产品</a></li>
</ul></div></div></nav>
```
    * `collapse` 管收起，`navbar-collapse` 管展开排版，`mx-auto` 左右自动即居中
    * `data-bs-toggle="collapse"` 配 `data-bs-target="#vivoNav"`，`#` 不可丢，`Bootstrap 5` 带 `bs` 前缀，老版 `data-toggle` 必错
    * > **易错点**：点击无反应先查 `JS` 是否引入，再查 `target` 与 `id` 是否一字不差
    * 覆盖用自写 `#000` 高 `60px`，摘掉 `bg-dark`，`navbar-dark` 只管浅色字，`line-height: 60px` 即垂直居中
    * 悬停（hover）与激活（active）同式，平时 `border-bottom: 2px solid transparent` 预留位，悬停只换色不抖
    * 右侧 `bi` 图标 `18px` 左距 `22px`，悬停 `opacity: 0.7`，图标组放折叠区外常驻顶栏

### 轮播热门与科技区

* **轮播（carousel）**
    * 三件套为图片轨道、指示点、左右箭头，全包同 `id`，`active` 只许一张
```html
<div id="vivoBanner" class="carousel slide" data-bs-ride="carousel" data-bs-interval="4000" data-bs-pause="hover">
<div class="carousel-indicators"><button data-bs-target="#vivoBanner" data-bs-slide-to="0" class="active"></button></div>
<div class="carousel-inner"><div class="carousel-item active"><img src="./images/banner1.jpg" class="d-block w-100" alt="X100"></div></div>
<button class="carousel-control-prev" data-bs-target="#vivoBanner" data-bs-slide="prev"><span class="carousel-control-prev-icon"></span></button>
```
    * `data-bs-ride` 为自动开关，`w-100` 顶满轨道，`d-block` 去图片底白缝
    * | 参数 | 作用 | 建议 |
      | :--- | :--- | :--- |
      | `data-bs-interval` | 每张毫秒 | `4000` 到 `5000` |
      | `data-bs-pause` | 悬停是否暂停 | `hover` |
      | `data-bs-wrap` | 末尾是否循环 | 默认循环不关 |
    * 对象贴合（object-fit）`cover` 即等比铺满裁多余，框多大图多大，人物不放边上
    * 轮播图高 `520px` 配 `cover`，手机压至 `320px`，遮罩（mask/overlay）为底部 `45%` 高 `linear-gradient(transparent, rgba(0, 0, 0, 0.65))`，文案 `bottom: 60px`
    * 层叠自下而上为图片、渐变蒙层、文案，同属一 `item` 且 `position: relative`
* **热门产品栅格与卡片**
    * 区块浅灰 `#f7f8fa` 托白卡，`padding: 60px 0`，标题行 `space-between` 左题右链
```html
<section class="hot"><div class="container"><div class="hot-head"><h2>热门产品</h2><a href="#">查看更多 &gt;</a></div>
<div class="row g-3 hot-list"><div class="col-6 col-lg-3"><div class="card hot-card h-100">
<img src="./images/hot1.jpg" class="card-img-top" alt="X100">
<div class="card-body"><h3 class="card-title">X100 系列</h3><p class="card-price">￥3999起</p><a href="#" class="buy">立即购买</a></div>
</div></div></div></div></section>
```
    * `col-6 col-lg-3` 即默认两列、`992px` 上四列，槽宽用 `g-3` 约 `16px`，不自加 `margin`
    * 结构用 `card` 套 `body`，`h-100` 顶满父列保底边一条线
    * 图片定高 `200px` 加 `cover`，`img` 加块级去底白缝，标题 `16px #333` 单行省略，价格 `14px #415fff` 以色补形
    * 悬停只做 `translateY(-6px)` 加柔阴影加购买显现，`transition` 写本体，按钮平时 `opacity: 0` 悬停 `1`
    * 小屏压为区块 `40px`、标题 `22px`、图高 `160px`，`overflow: hidden` 配 `12px` 圆角防方角顶穿
    * | 宽度 | 生效 | 列数 |
      | :--- | :--- | :--- |
      | 小于 `992px` | `col-6` | 2 列两行 |
      | 大于等于 `992px` | `col-lg-3` | 1 行 4 列 |
* **未来科技叠层**
    * 通栏黑底不套 `1200px` 容器，媒体盒 `relative` 高 `480px` 加 `overflow: hidden`

```css
.tech { background-color: #000; padding: 0 0 60px 0; }

.tech-media img { width: 100%; height: 100%; object-fit: cover; }
```

    * 居中背诵 `left/top 50%` 加 `translate(-50%, -50%)`，副文案 `15px rgba(255,255,255,0.8)` 让位标题
    * 深色按钮平时透明描边，悬停实心蓝，手机压为高 `320px`、标题 `24px`、副文案 `13px`
    * | 元素 | 常态 | 悬停 |
      | :--- | :--- | :--- |
      | `.more` | 透明底白描边 | 蓝底蓝边 |

## vivo 页脚适配与上线


### 服务条与链接版权

* **页脚服务条**
    * 外层 `footer` 底 `#222`，比科技区 `#000` 亮一档，相邻深色差一档才有层次
```css
.footer { background-color: #222; color: #999; }
.service { display: flex; justify-content: space-between; align-items: center; padding: 28px 0; border-bottom: 1px solid #333; }
.service a { flex: 1; text-align: center; font-size: 14px; color: #ccc; }
.service a + a { border-left: 1px solid #333; }
.service a:hover { color: #fff; }
.service .icon { display: inline-block; width: 28px; height: 28px; line-height: 28px; border: 1px solid #555; border-radius: 50%; margin-right: 8px; font-style: normal; }
@media (max-width: 768px) { .service { flex-wrap: wrap; } .service a { flex: none; width: 50%; margin-bottom: 16px; } }
```
    * 相邻兄弟选择器（sibling selector）`a + a` 从第二项起加左线，新增入口自动有分隔，不手敲 `|`
    * 图标 `28px` 圆配 `14px` 字，`i` 须 `font-style: normal` 掰直斜体
    * 小屏换行一行两个，`width: 50%`
    * | 属性 | 取值 | 作用 |
      | :--- | :--- | :--- |
      | `display` | `flex` | 四项横排 |
      | `justify-content` | `space-between` | 均分撑开 |
      | `border-bottom` | `1px solid #333` | 与链接区分段 |
* **链接区五列**
    * 上下两层为链接区加版权区，前者弹性盒（Flexible Box，Flex）多列，后者单行居中，分开写利媒体查询（Media Query）
    * 单列用描述列表（Description List，`dl`），`dt` 放标题，`dd` 放链接
```css
.footer-link { display: flex; justify-content: space-between; padding: 40px 0; }
.footer-col { flex: 1; }
.footer-col dt { color: #fff; font-size: 14px; margin-bottom: 16px; }
.footer-col dd { margin: 0 0 10px 0; }
.footer-col dd a { color: #999; font-size: 12px; text-decoration: none; }
.footer-col dd a:hover { color: #fff; }
.footer-service .tel { color: #fff; font-size: 20px; font-weight: 700; }
.footer-service .btn { display: inline-block; border: 1px solid #999; border-radius: 20px; padding: 6px 20px; color: #fff; font-size: 12px; }
```
    * 字号层级为标题 `14px`、链接 `12px`、电话 `20px`，`dd` 须 `margin: 0` 清左缩进
    * 右侧服务列三件为大字电话、白字标题、描边按钮
    * | 属性 | 取值 | 作用 |
      | :--- | :--- | :--- |

* **版权区分隔与图标**
    * 分区不用 `hr`，用 `border-top: 1px solid #333`，比 `#222` 亮一线即可

```css
.footer-bottom { border-top: 1px solid #333; }

```
    * 相邻兄弟选择器（Adjacent Sibling Selector）`a + a` 自动适配新增链接，手敲 `|` 间距对不齐
    * 社交占位 `24px` 方半圆，后续换字体图标（Iconfont）或图片结构不动

### 适配滚动条与托管发布

* **三档适配与滚动条**
    * 断点取 `1200px`、`992px`、`768px`，沿用框架老数
```css
.container { width: 1200px; margin: 0 auto; }
@media (max-width: 992px) { .container { width: 750px; } }
@media (max-width: 768px) { .container { width: 100%; padding: 0 15px; box-sizing: border-box; } }
@media (max-width: 768px) {
  .footer-link { flex-wrap: wrap; }
  .footer-col { flex: none; width: 50%; margin-bottom: 24px; }
  .footer-service { width: 100%; }
  .bottom-inner { flex-direction: column; text-align: center; gap: 12px; }
}
```
    * 小屏 `100%` 配 `15px` 内边距，须加 `box-sizing: border-box`，否则溢出左右晃，媒体查询从大往小写
    * 伪元素（Pseudo-element）三件为 `::-webkit-scrollbar` 管宽、`::-webkit-scrollbar-track` 管轨道、`::-webkit-scrollbar-thumb` 管滑块
```css
::-webkit-scrollbar { width: 8px; }
::-webkit-scrollbar-track { background: #f1f1f1; }
::-webkit-scrollbar-thumb { background: #888; border-radius: 4px; }
::-webkit-scrollbar-thumb:hover { background: #555; }
```
    * 滑块 `8px` 配圆角 `4px` 即两头全圆，`Chrome` 与 `Edge` 好使，火狐认 `scrollbar-width`
    * | 断点 | 链接列 | 版权行 |
      | :--- | :--- | :--- |
      | 大于 `768px` | `flex: 1` 横排 | 横排两端 |
      | 小于等于 `768px` | `50%` 换行 | 竖排居中 `12px` 间隙 |
* **发布（Deploy）与静态托管（Static Hosting）**
    * > **定义**：发布即把 `html`、`css`、`images` 搬到一直开机的服务器（Server），访问网址即回吐文件渲染
    * 上线目录只留四样，首页必须叫 `index.html`，无文件名请求默认找它
```text
vivo-site/
  index.html
  css/style.css
  images/logo.png
  js/index.js
```
    * 路径全改相对路径（Relative Path）如 `images/logo.png`，禁 `C:\`、`D:\` 绝对路径与中文文件夹，否则本地成发上裂图
    * 通用四步为新建静态站点、拖整个文件夹且首页在根、等构建成功、复制网址手机电脑各试，首白多为缓存，`Ctrl + F5` 强刷
    * | 步骤 | 动作 | 检查点 |
      | :--- | :--- | :--- |
      | 新建 | 选静态站点 | 不选动态应用 |
      | 上传 | 拖整个文件夹 | 首页在根 |
      | 等待 | 看构建日志 | 成功再走 |
      | 访问 | 复制网址打开 | 双端试 |
    * 更新为改本地重传覆盖等一分钟再刷，先换标题关键词、页脚电话改邮箱
    * 行李为超文本标记语言（HyperText Markup Language，HTML）语义感、层叠样式表（Cascading Style Sheets，CSS）盒子弹性媒体查询手感、一个可访问作品网址，练习未说明后端与动态接口
