# pink老师：AI + 前端入门（HTML5 / CSS3）

2025 版前端入门课，从 HTML5 语义化标签、CSS3 选择器与盒模型，一路讲到 Flex/Grid 布局、响应式、移动端适配与 Bootstrap5，并全程穿插 AI 辅助开发（Trae）。全 200 集，体量与本仓库的 NLP 课相当，但上手门槛低得多。

- **全 200 集**，已产出 12 册模块全书、6 篇复习笔记

## 怎么学

前端是**看得见结果**的方向，最适合边写边看。这门课的结构是「讲一个知识点 → 立刻做一个页面」，所以最好的学法就是跟着敲：

- **按模块顺序学** → `textbooks/` 从模块 01 读起，模块 01~02 打 HTML5 基础，模块 03~07 进入 CSS 视觉与布局，是整门课的分水岭
- **动手优先** → 模块全书保留了课程中每个实战案例的完整代码与拆解，建议每个案例都自己在本地复现一遍
- **写样式时查速查** → `notes/` 的 6 篇笔记按「选择器 / 布局 / 动效 / 移动端」聚类，比翻模块全书快
- **框架部分别偷懒** → 模块 12 的 Bootstrap5 与 vivo 官网实战是综合收尾，前面的 Grid/Flex 没吃透这里会很吃力

这门课不含 JavaScript，专注 HTML + CSS 的视觉与布局能力。
