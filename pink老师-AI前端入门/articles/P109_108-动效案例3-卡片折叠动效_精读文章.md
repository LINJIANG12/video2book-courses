# 108-CSS3 实战：手风琴卡片折叠动效与 :has() 父选择器

在现代电商、游戏官网和流媒体展示页中，“手风琴折叠展开卡片”是一种极其经典且优雅的交互组件：几个卡片并排排列，默认第一个展开占据主要视口，其余卡片折叠收拢；当用户鼠标掠过某张卡片时，该卡片如同折叠扇一样丝滑展开，其余卡片相应收缩，同时卡片内部的标题描述从底部向上浮现。

在过去很长一段时间内，前端开发者要实现这种“鼠标滑过子元素，却需要改变父级整体布局”的交互，必须强依赖 JavaScript（监听 `mouseenter` 事件、计算宽度或动态增删类名）。

但在现代 CSS 标准中，随着 **Grid 网格布局** 和革命性的 **`:has()` 父选择器** 的普及，我们完全可以用**纯 CSS**、零 JS 依赖实现极致平滑的手风琴折叠动效！

本节我们将手把手带大家解构这一高水准动效，并彻底搞懂 `:has()` 的逆向选择原理。

---

## 1. 动效解构与架构设计

### 1.1 网格份数分配模型
我们使用 Grid 布局来管理 4 张并排的卡片。Grid 布局天生具备自适应弹性单位 `fr`（Fractional unit），极度适合做比例伸缩：

```text
手风琴卡片网格份数分配示意
初始状态（默认第1项展开）：
+--------------------+----------+----------+----------+
|  Item 1 (展开: 2fr)| Item 2   | Item 3   | Item 4   |
|                    | (1fr)    | (1fr)    | (1fr)    |
+--------------------+----------+----------+----------+

鼠标悬停在 Item 2 上时：
+----------+--------------------+----------+----------+
|  Item 1  |  Item 2 (展开: 2fr)| Item 3   | Item 4   |
|  (1fr)   |                    | (1fr)    | (1fr)    |
+----------+--------------------+----------+----------+
```

- **初始状态**：`grid-template-columns: 2fr 1fr 1fr 1fr;`
- **悬停在第 2 项**：`grid-template-columns: 1fr 2fr 1fr 1fr;`
- **悬停在第 3 项**：`grid-template-columns: 1fr 1fr 2fr 1fr;`
- **悬停在第 4 项**：`grid-template-columns: 1fr 1fr 1fr 2fr;`

只要在父级网格容器上加入 `transition: all 0.5s;`，列宽比例切换时就会产生令人惊叹的丝滑弹性拉伸过渡！

## 2. 核心革命性新特性：`:has()` 父选择器

### 2.1 为什么必须选择父级？
细心的同学会立刻发现一个核心矛盾：
- 用户的**鼠标悬停行为（`:hover`）**是发生具体某一个子盒子（`li.item`）上的；
- 但是控制整套网格宽度的属性 **`grid-template-columns`** 却属于父级容器（`ul`）。

在 CSS4 之前，CSS 选择器遵循严格的“单向级联”规则：你只能“从父找子（`ul li`）”或“向后找兄弟（`li + li`）”，**绝无可能从子元素逆向选择父元素**！

### 2.2 `:has()` 彻底终结前端痛点
CSS 规范新增了 `:has()` 伪类，又被称为**父选择器**或**存在选择器**。

它的核心机制是：**根据其内部子元素是否满足某种状态，来决定是否命中该父元素**！

```css
/* 语法剖析 */
ul:has(.item:nth-child(2):hover) {
  grid-template-columns: 1fr 2fr 1fr 1fr;
}
```

这段代码的大白话翻译就是：
> **“请帮我选中那个内部包含了【正被鼠标悬停的第 2 个子项】的父级 `ul`，并把这个 `ul` 的列分配比例修改为 `1fr 2fr 1fr 1fr`！”**

有了 `:has()`，以往必须写十几行 JS 事件监听的逻辑，现在仅仅一行纯 CSS 选择器便迎刃而解！

### 3.2 CSS 核心样式编码

```css
* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}

body {
  height: 100vh;
  display: flex;
  justify-content: center;
  align-items: center;
  background-color: #1a1a24;
}

/* 1. 外层容器 */
.box {
  width: 100%;
  max-width: 1320px;
  height: 527px;
  padding: 20px;
}

/* 2. Grid 父级容器：默认 2:1:1:1 比例分栏 */
.accordion {
  list-style: none;
  width: 100%;
  height: 100%;
  display: grid;
  grid-template-columns: 2fr 1fr 1fr 1fr; /* 默认第1张展开 */
  gap: 18px; /* 卡片之间的间隙 */
  transition: grid-template-columns 0.5s ease-in-out; /* 丝滑列宽过渡 */
}

/* 3. 单个卡片样式 */
.item {
  position: relative;
  border-radius: 16px;
  overflow: hidden; /* 裁剪底部滑入标题与圆角 */
  background-repeat: no-repeat;
  background-position: center;
  background-size: cover;
  cursor: pointer;
}

/* 各卡片背景图 */
.item1 { background-image: url("images/card1.jpg"); }
.item2 { background-image: url("images/card2.jpg"); }
.item3 { background-image: url("images/card3.jpg"); }
.item4 { background-image: url("images/card4.jpg"); }

/* 4. 卡片内浮动标题：默认藏在底部以下，鼠标悬停时上浮 */
.item .title {
  position: absolute;
  left: 0;
  bottom: -100px; /* 初始藏在盒子下方不可见区域 */
  width: 100%;
  padding: 20px;
  background: linear-gradient(to top, rgba(0,0,0,0.85), transparent);
  color: #fff;
  font-size: 20px;
  font-weight: bold;
  letter-spacing: 1px;
  transition: bottom 0.4s cubic-bezier(0.25, 1, 0.5, 1);
}

/* 鼠标悬停卡片时，文字平滑升上来 */
.item:hover .title {
  bottom: 0;
}

/* =======================================================
   5. 核心魔法：使用 :has() 响应不同子项的 hover 状态
   ======================================================= */

/* 悬停第1项：第1项展开 */
.accordion:has(.item:nth-child(1):hover) {
  grid-template-columns: 2fr 1fr 1fr 1fr;
}

/* 悬停第2项：第2项展开 */
.accordion:has(.item:nth-child(2):hover) {
  grid-template-columns: 1fr 2fr 1fr 1fr;
}

/* 悬停第3项：第3项展开 */
.accordion:has(.item:nth-child(3):hover) {
  grid-template-columns: 1fr 1fr 2fr 1fr;
}

/* 悬停第4项：第4项展开 */
.accordion:has(.item:nth-child(4):hover) {
  grid-template-columns: 1fr 1fr 1fr 2fr;
}
```

## 4. 重点避坑与知识延伸

1. **`transition` 的过渡属性精确性**：
   - 我们可以写 `transition: all 0.5s;`，但更推荐显式指定 `transition: grid-template-columns 0.5s;`。这样能够最大程度减少浏览器不必要的重绘开销，让手风琴滑动如丝般顺滑。
2. **背景图居中等比缩放**：
   - 卡片在缩窄和展宽的过程中，卡片宽高比一直在动态巨幅变化。因此必须设置 `background-position: center; background-size: cover;`，确保图片始终稳居画面视觉中心，不会被粗暴拉伸变形。
3. **`:has()` 的兼容性与前瞻性**：
   - 现代主流浏览器（Chrome 105+、Safari 15.4+、Edge 105+、Firefox 121+）已全线原生支持 `:has()`；
   - 在前端开发中，`:has()` 被誉为近十年 CSS 最重磅的革新之一，面试中只要提及使用 `:has()` 替代传统 JS 监听，绝对是极大的加分项！
