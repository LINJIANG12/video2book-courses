# 盒子视觉工程：CSS 背景 `background` 核心属性群精解

我们在前面的章节中，已经把盒子模型的骨架结构（`border`、`padding`、`margin` 以及 `box-sizing`）彻底拆解明白了。骨架搭好之后，接下来的核心任务就是对盒子进行**高颜值的视觉装潢**。

在初学阶段，我们给盒子做视觉区分通常只是给它涂上一个素色背景，比如 `background-color: pink;`。但在真实的企业级 Web 界面中，随处可见极其丰富华丽的视觉表现：
- 登录面板里极具设计感的品牌背景图；
- 列表项前面精致小巧的自定义图标（而不是浏览器默认的粗糙圆点）；
- 类似《王者荣耀》《和平精英》官网中那种气势磅礴的大型 Hero 游戏全屏海报；
- 还有带有光影渐变质感的高级操作按钮。

要实现这些精美的页面效果，单靠背景颜色是远远不够的。

这一讲我们系统进入 CSS 极其核心的视觉系统——**背景属性群（`background`）**，逐一攻克背景图片、平铺控制、坐标定位、尺寸缩放与固定视差等 5 大核心属性！

## 1. 视觉进阶：为什么不能只用背景颜色？

### 1.1 背景图片与 `<img>` 标签的本质区别

很多零基础的同学在这里很容易产生困惑：
> “老师，我要在盒子里放一张图，我直接在 HTML 里面写个 `<img src="...">` 不就完了吗？为什么还要费劲用 CSS 背景图？”

这两者在前端语义和布局机制上有着本质的区别：

```text
HTML 插入图片 (img) 与 CSS 背景图片 (background-image) 渲染层级对比

【HTML 插入图片 <img>】：属于页面内容实体
┌───────────────────────────────────────┐
│ 盒子容器                              │
│  ┌─────────────────┐                  │
│  │ <img> 实体图片  │ 文本被挤到旁边   │ ──> 占有文档流真实空间，
│  └─────────────────┘ 或下方           │     文字无法直接盖在图片正上方
└───────────────────────────────────────┘

【CSS 背景图片 background-image】：属于盒子的装饰衬底
┌───────────────────────────────────────┐
│ 盒子容器 (底衬：background-image)     │
│                                       │
│   登 录 表 单 / 标 题 文 字           │ ──> 图片在底层，文字与表单控件
│   [ 输入框 ]  [ 提交按钮 ]            │     可以自由漂浮在其正上方
└───────────────────────────────────────┘
```
*图 1：HTML 实体图片与 CSS 衬底背景图渲染层级差异*

1. **`<img>` 是内容实体**：它是一个行内块元素，**会占据页面的真实文档流空间**。如果盒子里既有 `<img>` 又有文字，文字会被图片挤到一旁或下方，除非使用复杂的绝对定位，否则文字无法直接叠写在图片上面；
2. **`background-image` 是装饰衬底**：它只负责盒子的底层背景渲染，**完全不占据文档流空间**。文字、表单、按钮等任何子元素都可以稳稳当当地悬浮在背景图之上。

> **核心原则**：如果这张图是网页核心内容的一部分（比如商品详情图、新闻报道照片、用户头像），必须使用 `<img>` 标签，方便 SEO 抓取与屏幕阅读器无障碍识别；如果这张图只是起修饰、美化、衬托作用（比如品牌水印、小图标、卡片底图），坚决使用 CSS 背景图。

### 1.2 背景属性全景拓扑

CSS 为背景控制提供了一整套专门的子属性：

```text
CSS 背景属性体系拓扑
├── background-color       : 基础底色 (支持十六进制 / rgb / rgba 半透明)
├── background-image       : 背景图像源 (必须使用 url() 引入)
├── background-repeat      : 图像平铺规则 (repeat / no-repeat / repeat-x / repeat-y)
├── background-position    : 图像起始定位坐标 (像素 / 百分比 / 方位名词)
├── background-size        : 图像缩放尺寸 (像素 / cover / contain)
└── background-attachment  : 图像滚动依附性 (scroll 随动 / fixed 视口固定)
```
*图 2：CSS 背景常见核心子属性架构图*

## 2. 背景图片引入与平铺控制（`image` & `repeat`）

### 2.1 引入背景图片：`background-image`

在 CSS 中引入背景图片，语法必须配合 `url()` 函数使用：

```css
selector {
  background-image: url("图片路径");
}
```

> **易错点**：`url()` 里面的路径千万不要漏写括号；在现代 CSS 规范中，引号可加可不加，但**强烈建议规范加上英文双引号或单引号**。

```css
.card {
  width: 300px;
  height: 200px;
  background-color: #f5f5f5; /* 背景底色 */
  background-image: url("./images/logo.png"); /* 背景图片 */
}
```

**背景色与背景图的共存机制**：
背景图片和背景颜色是**完全可以和平共处**的。浏览器的图层渲染顺序是：**背景颜色在最底层，背景图片覆盖在背景颜色之上**。如果背景图是带有透明通道的 PNG 图片，透明区域会自然透出底层的背景颜色；如果背景图加载失败或没有覆盖满，底色就会露出来充当兜底保护。

### 2.2 背景平铺控制：`background-repeat`

当你给一个尺寸很大的盒子设置了一张小尺寸的背景图片时，浏览器默认会发生什么？

你会发现整张图片像铺瓷砖一样，横向、纵向密密麻麻铺满了整个盒子。这是因为 `background-repeat` 的默认值就是 `repeat`。

为了按需控制图像的重复行为，CSS 提供了 4 种常用取值：

| 取值 | 表现机理 | 经典应用场景 |
| :--- | :--- | :--- |
| **`repeat`**（默认） | 在水平方向（X 轴）和垂直方向（Y 轴）同时平铺 | 传统无缝拼接纹理底纹（如噪点、微小几何格子） |
| **`no-repeat`** | **坚决不平铺**，背景图只出现一次 | **开发中使用率高达 90%**（各类卡片配图、单个图标、全屏大图） |
| **`repeat-x`** | 仅沿着水平方向（X 轴）平铺 | 页面顶部横条渐变底色拉伸、横向波浪装饰线 |
| **`repeat-y`** | 仅沿着垂直方向（Y 轴）平铺 | 侧边栏垂直条纹装饰、时间轴虚线背景 |

```css
/* 现代开发最经典高频组合：设定背景图并不平铺 */
.banner {
  background-image: url("./images/bg.jpg");
  background-repeat: no-repeat;
}
```

## 3. 背景精确定位：`background-position`

当设置了 `background-repeat: no-repeat;` 后，图片默认会呆在盒子的什么位置？

默认情况下，它会死死贴在盒子的**左上角**。但在实际排版中，我们经常需要把背景图居中、靠右、或者定位到某个精确的像素偏移点上。这就必须用到 `background-position`。

### 3.1 盒模型的笛卡尔坐标系

要理解定位，首先必须清楚盒子内部的二维坐标系：

```text
盒子内部背景定位坐标系示意
(0,0) 原点 ───────────────────────────> X 轴正方向 (水平向右为正)
  │
  │   ┌───────────────────────────┐
  │   │ 左上角 (0, 0)             │
  │   │                           │
  │   │               中心点      │
  │   │              (50%, 50%)   │
  │   │                           │
  │   │                 右下角    │
  │   │              (100%, 100%) │
  │   └───────────────────────────┘
  ▼
Y 轴正方向 (垂直向下为正)
```
*图 3：盒子内部坐标系与特征点分布*

- 盒子的**左上角**是坐标原点 `(0, 0)`；
- 水平向右是 **X 轴正方向**；
- 垂直向下是 **Y 轴正方向**。

`background-position` 接收两个参数：**第一个代表 X 轴偏移，第二个代表 Y 轴偏移**，中间用空格隔开：
```css
background-position: x y;
```

### 3.2 三种定位取值体系

#### 方式一：精确像素值（精准到像素）
```css
/* 图片左上角距离盒子左边 50px，距离盒子顶边 20px */
background-position: 50px 20px;
```

#### 方式二：方位名词（语义化直观表达）
方位名词包含五个词：
- 水平方向：`left`（左）、`center`（中）、`right`（右）；
- 垂直方向：`top`（上）、`center`（中）、`bottom`（下）。

```css
background-position: left top;     /* 左上角（默认效果） */
background-position: right bottom;  /* 右下角 */
background-position: center center;/* 水平与垂直正居中 */
```

> **提示**：如果前后两个值都是方位名词，由于词义本身就带有方向性，因此前后顺序颠倒不影响渲染。例如 `background-position: top right;` 和 `background-position: right top;` 效果完全相同。但建议大家严格养成“先水平、后垂直”的书写习惯，保持代码统一。

#### 方式三：百分比定位
```css
background-position: 50% 50%; /* 正中心对齐，等价于 center center */
```

### 3.3 单值缺省解析规则（高频易错）

在阅读别人的代码或大厂源码时，你经常会看到只写了一个参数的情况：
```css
background-position: center;
/* 或者 */
background-position: left;
```

很多同学就会懵了：“不是说有两个轴吗？这写的一个到底是 X 轴还是 Y 轴？”

> **核心规则**：**如果 `background-position` 只指定了一个值，那么该值一定赋给水平 X 轴，而垂直 Y 轴默认自动取 `center`（居中）！**

- `background-position: center;` $\rightarrow$ 等价于 `center center`（水平居中，垂直居中）；
- `background-position: left;` $\rightarrow$ 等价于 `left center`（水平靠左，垂直居中）；
- `background-position: 50px;` $\rightarrow$ 等价于 `50px center`（距离左侧 50px，垂直居中）。

## 4. 背景缩放与自适应机制：`background-size`

在移动端响应式或各种大屏展示中，设计稿给出的背景图尺寸往往与用户的实际盒子尺寸不一致。我们必须对背景图进行拉伸或缩放，这就是 `background-size`。

`background-size` 默认值为 `auto`（保持图片原始分辨率尺寸）。

### 4.1 显式尺寸与等比缩放

我们可以直接给 `background-size` 传具体尺寸：

```css
/* 1. 双值模式：强制设置宽为 300px，高为 200px（可能导致图片变形失真） */
background-size: 300px 200px;

/* 2. 单值模式（推荐）：指定宽度为 300px，第二个值缺省或写 auto */
background-size: 300px; /* 高度会自动按原图纵横比自适应等比缩放，绝不变形！ */

/* 3. 百分比模式：宽度占盒子的 100%，高度等比适应 */
background-size: 100% auto;
```

### 4.2 工业级双子星：`cover` 与 `contain`

在真实开发中，我们最常用的并不是手动计算像素，而是使用两个高度智能的关键字：`cover` 和 `contain`。

```text
cover（覆盖）与 contain（包含）机理比对
【cover 模式：填满盒子，绝不留白】
┌──────────────────────────────────┐ ◄─── 盒子边框
│▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒│
│▒▒▒▒▒▒▒▒▒ 完整图片等比拉大 ▒▒▒▒▒▒▒▒▒│ ──> 只要盒子还有空隙就继续拉大，
│▒▒▒▒▒▒▒▒▒ 直到铺满整个盒子 ▒▒▒▒▒▒▒▒▒│     直到填满盒子为止。超出的边缘
│▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒│     会被裁剪看不见！
└──────────────────────────────────┘

【contain 模式：保全整图，允许留白】
┌──────────────────────────────────┐ ◄─── 盒子边框
│      ┌────────────────────┐      │
│ 留白 │  完整图片等比缩放  │ 留白 │ ──> 只要图片有一条边碰到了盒子边界，
│      │  确保 100% 完整展现│      │     立刻停止缩放。图片绝不被裁剪，
│      └────────────────────┘      │     但容器其余部分可能会露底留白！
└──────────────────────────────────┘
```
*图 4：cover（溢出裁剪铺满）与 contain（保全全貌留白）机制对比*

#### 1. `cover`（覆盖 / 铺满）
- **机理**：把背景图像等比缩放，直到**完全覆盖住整个盒子容器**为止；
- **代价**：如果图片的比例和盒子的比例不一致，图片超出盒子的那部分**会被直接裁剪切掉**；
- **适用**：全屏海报、轮播大图、卡片展示底图（宁可裁掉边缘，也绝不能露出白边）。

#### 2. `contain`（包含 / 容纳）
- **机理**：把背景图像等比缩放，直到**宽或高其中一边触碰到盒子边界**即停止；
- **代价**：图片能够保证 100% 完整显示，但盒子没有被覆盖到的其余区域**会出现空白**（露出背景色）；
- **适用**：展示完整商品图、公司 Logo、不可被裁切的专业图表。

| 关键字 | 中文含义 | 是否保全整张图 | 容器是否会有留白 | 核心用途 |
| :--- | :--- | :--- | :--- | :--- |
| **`cover`** | 覆盖 / 铺满 | 否（边缘可能被裁剪） | **绝不留白**，全域覆盖 | 全屏海报、卡片大图背景 |
| **`contain`** | 包含 / 容纳 | **是（100% 完整露出）** | 可能会留白 | 品牌 Logo、完整产品图示 |

## 5. 视差滚动基石：背景固定（`background-attachment`）

在浏览某些极具设计感的前端官网时，你经常会看到一种奇妙的视觉冲击：页面在不断往下拉，文字和卡片都在向上滚动，但背后的那张大图却**像被施了定身法一样纹丝不动**，产生了强烈的空间层次感。

这种效果的底层控制属性就是 `background-attachment`（背景依附方式）。

### 5.1 `scroll` 与 `fixed` 的机理对比

```css
selector {
  background-attachment: scroll | fixed;
}
```

1. **`scroll`（默认值：随动滚动）**：
   背景图片紧紧依附在它所在的盒子上。页面滚动时，盒子往上走，背景图跟着一起往上跑。
2. **`fixed`（固定模式）**：
   背景图片不再跟随普通的页面滚动流移动，而是**直接相对于浏览器的可视窗口（Viewport）被咬死固定**！不管你怎么拉动滚动条，背景图都坚守在屏幕固定视野内。

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>背景固定实验</title>
  <style>
    body {
      height: 2000px; /* 撑出长滚动条 */
    }
    .box {
      width: 600px;
      height: 400px;
      border: 5px solid #333;
      margin: 100px auto;
      background-image: url("./images/hero.jpg");
      background-repeat: no-repeat;
      background-position: center center;
      /* 核心：将背景锁定在可视窗口中 */
      background-attachment: fixed;
    }
  </style>
</head>
<body>
  <div class="box"></div>
</body>
</html>
```

当你把代码中的 `scroll` 改成 `fixed` 并滚动页面时，你会惊奇地发现：**盒子就像是一个在屏幕上滑动的“镂空小窗口”，窗口滑到哪里，就能透过它看到屏幕后面那一幅静止不动的画卷**！

这就是前端著名的**视差滚动（Parallax Scrolling）**的核心原理基石。

## 6. 小结与下节预告

本节我们深入拆解了盒模型背景系统的 5 大核心属性：

1. **`background-image`**：通过 `url()` 挂载衬底，与 `<img>` 内容元素分工明确，且能与 `background-color` 完美叠加；
2. **`background-repeat`**：日常开发优先锁定 `no-repeat`，横纵纹理巧用 `repeat-x` / `repeat-y`；
3. **`background-position`**：基于盒子左上角直角坐标系，支持像素、百分比与方位词，单值缺省默认 Y 轴为 `center`；
4. **`background-size`**：全面吃透 `cover`（填满不留白，允许裁剪）与 `contain`（保全图，允许留白）；
5. **`background-attachment`**：`fixed` 模式钉死视口，是搭建高大上视差滚动效果的幕后功臣。

虽然这 5 个属性各自功能强大，但在实际项目中如果每一个都单写一行，代码就会显得冗长繁琐。
