# 电商底部基石工程：小兔鲜 Footer 架构搭建与 Slogan 精灵图组件实战

完成了小兔鲜电商门户的头部（Header）之后，按照常规思维，很多同学可能会急着往下写轮播图（Banner）或者首页的推荐商品卡片。

但如果有过实际企业级项目开发经验，你就会明白：**绝对不能这么干**。

在任何现代 Web 项目中，页面都是由“公共模块（Common/Public Modules）”和“业务专有模块（Page-Specific Modules）”组合而成的。
- **公共模块**：像顶部的快捷导航（Shortcut）、头部导航（Header）、底部的服务与版权区（Footer），它们在首页、商品列表页、商品详情页、个人中心、购物车页等每一个页面中都**100% 保持一致**；
- **专有模块**：只有中间那一块内容区（如首页的轮播图和推荐榜单），才是各个页面独有的。

如果我们一上来就顺着页面往下平铺直叙地写，就会导致代码混乱、公共样式与页面私有样式杂糅在一起。最科学的工程化开发次序，一定是**先头尾合拢，把整站的“公共外壳”全部敲定，再向内填充具体的业务内容**。

今天我们就正式转入网站底部的开发，先搭建起 `.footer` 大容器的三段式骨架，并把顶部最具视觉冲击力的**服务口号（Slogan）模块**完整推导落地。

1. **外层通栏大盒子（`.footer`）**：
   - 宽度：`100%`（铺满整个视口宽度）；
   - 高度：约 `580px`；
   - 背景颜色：`#f5f5f5`。这种极浅的暖灰色是电商行业最青睐的背景主色，既能与上方纯白色的商品卡片产生清晰的空间层次，又保证了视觉的柔和不刺眼。

   - **顶段：服务口号区（`.slogan`）**：高度 `178px`，底部带一条细边框，承载 4 项核心服务承诺；

   - **底段：版权信息区（`.copyright`）**：居中展示免责声明、条款链接与版权所有字样。

## 2. 口号模块（.slogan）弹性均分排版

### 2.1 业务特征与电商标语对标

口号模块展示了小兔鲜的 4 大服务特色：**价格亲民、物流快捷、品质新鲜、售后无忧**。这与京东著名的“多、快、好、省”以及天猫超市的“品质保障、准时送达”在交互定位上完全一致。

这 4 个项在版心内部横向并列展开，呈现出极高的对称美感。

### 2.2 间隙均等与 Space-Evenly 属性推导

很多同学在实现 4 个元素横向排列时，第一反应是用浮动或 `justify-content: space-between`，然后再去计算两端内边距。

但大家仔细观察设计稿：**不仅第 1 项和第 2 项之间有间隙，最左侧第 1 项距离版心左边缘、最右侧第 4 项距离版心右边缘的距离，全部完全相等**！

```text
三种 Space 分布模式对比
┌────────────────────────────────────────────────────────────┐
│ space-between (两端顶死，中间留白)：                       │
│ [Item 1]               [Item 2]               [Item 3]     │
├────────────────────────────────────────────────────────────┤
│ space-around (每个项目左右边距相等，两端留白是中间的一半)： │
│   [Item 1]        [Item 2]        [Item 3]                 │
├────────────────────────────────────────────────────────────┤
│ space-evenly (所有空白槽完全均等，两端与中间完全一致)：    │
│     [Item 1]          [Item 2]          [Item 3]           │
└────────────────────────────────────────────────────────────┘
```
*图 2：space-evenly 能够精准实现首尾与项间距离的完全绝对等分*

> **结论**：既然 4 个项之间的留白以及到边界的留白完全相等，在现代弹性盒（Flexbox）中，唯一也是最优雅的解法就是：
> `justify-content: space-evenly;`！
> `evenly` 本身就是“均等地、平等地”之意，交给浏览器引擎自动计算，省去了一切繁琐的百分比和边距换算。

### 2.3 列表骨架与垂直居中

口号模块内部由无序列表包裹 4 个 `<li>`：

```html
<div class="slogan">
  <ul>
    <li><!-- 项 1 --></li>
    <li><!-- 项 2 --></li>
    <li><!-- 项 3 --></li>
    <li><!-- 项 4 --></li>
  </ul>
</div>
```

```css
.slogan ul {
  height: 178px;
  display: flex;
  /* 水平方向：所有空隙完全均等分配 */
  justify-content: space-evenly;
  /* 垂直方向：所有子项在 178px 轨道内垂直居中对齐 */
  align-items: center;
}
```

> **易错点**：为什么这里必须给 `ul` 显式声明 `height: 178px;`？
> 如果 `ul` 不设高度，它的高度默认会被内部内容紧紧包裹，此时给 `ul` 设置 `align-items: center;` 根本看不出垂直居中效果。只有父容器有明确的 178px 物理高度空间，子项目才能沿着交叉轴精准居中。

## 3. 口号子项（li）内部图文混排

### 3.1 京东同款标签语义化选型

每一个小 `<li>` 内部都包含两个元素：**左侧是一张 58px×58px 的特色大图标，右侧是 28px 的标语文案**。

在前端开发中，这组图文结构怎么选标签？
有些同学会图省事直接放一个 `<div>` 加一个 `<span>`。但在商业级大型电商中，为了极致的 SEO 和清晰的文档大纲树，我们参考一线大厂（京东）的同款语义方案：
- 左侧图标使用 `<h5>`（标题标签，象征该项服务的主题）；
- 右侧文字使用 `<p>`（段落标签，承载标语文案）。

```html
<li>
  <h5></h5>
  <p>价格亲民</p>
</li>
```

### 3.2 图文同行与水平垂直对齐

因为 `<h5>` 和 `<p>` 都是标准的块级元素，如果不加干预，它们会上下各占一行显示。

为了让它们水平左右排开，我们再次在子项 `<li>` 上开启 Flex 弹性布局：

```css
.slogan li {
  display: flex;
  /* 让图标与文字垂直居中对齐 */
  align-items: center;
}

/* 左侧图标容器尺寸 */
.slogan li h5 {
  width: 58px;
  height: 58px;
}

/* 右侧文案样式与间隙控制 */
.slogan li p {
  font-size: 28px;
  color: #333;
  /* 图文拉开 20px 的舒适间距 */
  margin-left: 20px;
}
```

这里我们不需要给每个 `<li>` 设定死板的宽度，因为图标宽度 58px + 外边距 20px + 四个汉字的宽度是自然的流动尺寸，配合外层 `ul` 的 `space-evenly`，四个模块会极其自然地呼吸分布在版心之中。

## 4. 精灵图（CSS Sprites）定位算法推导

### 4.1 精灵图素材特征分析

口号模块左侧的 4 个图标并不是 4 张独立的 PNG 碎图，而是整合在同一张名为 `sprites.png` 的雪碧图（精灵图）中。

我们用图像工具打开这张图，测量其排布特征：

```text
sprites.png 纵向单列精灵图结构示意
┌─────────────────────────┐ ── Y = 0
│  [ 图标 1: 价格亲民 ]   │ (高 58px)
├─────────────────────────┤ ── Y = -58px
│  [ 图标 2: 物流快捷 ]   │ (高 58px)
├─────────────────────────┤ ── Y = -116px (2 × 58)
│  [ 图标 3: 品质新鲜 ]   │ (高 58px)
├─────────────────────────┤ ── Y = -174px (3 × 58)
│  [ 图标 4: 售后无忧 ]   │ (高 58px)
└─────────────────────────┘
```
*图 3：纵向单列精灵图的等距步长位移规律*

1. 这是一张**单列纵向排布**的精灵图，所有图标横向 X 轴坐标都是 `0`；
2. 每个图标的物理宽高统一为 `58px × 58px`；
3. 图标之间没有额外的杂乱间隙，完全是按照 `58px` 的等差步长向下依次排列。

### 4.2 数学等差推导与代码实现

回顾精灵图的核心定位原理：**背景移动方向与数值正负相反（往左上移动取负值）**。
我们要把底下的图标挪到 58×58 的盒子窗口里显示，就必须把整张大背景图往上拉，因此 Y 轴坐标全部取负值：

- **第 1 项（价格亲民，默认类或 1 号）**：
  大图不需要移动，左上角对齐窗口：
  $$\text{position} = (0, 0)$$
- **第 2 项（物流快捷，.two）**：
  大图往上拉 1 个图标高度（$1 \times 58 = 58\text{px}$）：
  $$\text{position} = (0, -58\text{px})$$
- **第 3 项（品质新鲜，.three）**：
  大图往上拉 2 个图标高度（$2 \times 58 = 116\text{px}$）：
  $$\text{position} = (0, -116\text{px})$$
- **第 4 项（售后无忧，.four）**：
  大图往上拉 3 个图标高度（$3 \times 58 = 174\text{px}$）：
  $$\text{position} = (0, -174\text{px})$$

> **提示**：掌握了这一步长规律后，根本不需要拿标尺像素去一点点抠，只要确认好单个图标的高度，后面的坐标就是等差数列递减，代码一秒钟就能算出来。

我们给 4 个 `<h5>` 分别挂载对应的定位类名：

```html
<!-- 口号模块 HTML 完整结构 -->
<div class="slogan">
  <ul>
    <li>
      <h5></h5>
      <p>价格亲民</p>
    </li>
    <li>
      <h5 class="two"></h5>
      <p>物流快捷</p>
    </li>
    <li>
      <h5 class="three"></h5>
      <p>品质新鲜</p>
    </li>
    <li>
      <h5 class="four"></h5>
      <p>售后无忧</p>
    </li>
  </ul>
</div>
```

```css
/* 基础精灵图引入：所有 h5 共享同一张背景大图 */
.slogan li h5 {
  width: 58px;
  height: 58px;
  background: url(../images/sprites.png) no-repeat 0 0;
}

/* 第 2 项：往上提 58px */
.slogan li h5.two {
  background-position: 0 -58px;
}

/* 第 3 项：往上提 116px (2 × 58) */
.slogan li h5.three {
  background-position: 0 -116px;
}

/* 第 4 项：往上提 174px (3 × 58) */
.slogan li h5.four {
  background-position: 0 -174px;
}
```

保存并在浏览器中刷新，4 个精致清晰的品牌服务图标便稳稳地镶嵌在浅灰色底板之上，图文间距均匀，整个口号区的高级质感跃然纸上。

## 6. 核心知识要点小结

1. **公共模块优先开发战略**：商业项目中，Header 与 Footer 属于全站复用的核心公共资产，必须优先将其打造完毕，形成闭环外壳模板后，再向内部注入业务模块；
2. **三段式底部拓扑**：工业级电商底部通常分为“口号区、服务区、版权区”三大纵向分层，外层大容器负责通栏背景铺满，内层版心负责约束阅读安全边界；
3. **Space-Evenly 弹性对齐**：当多个项目在一行排布，且要求“项与项之间的距离”与“两端到父容器边界的距离”绝对相等时，`justify-content: space-evenly` 是唯一的标准解；
4. **京东同款图文语义化**：服务标语组件使用 `<h5>`（标题代表特征）配合 `<p>`（段落代表文案），再通过子级 Flex 弹性盒实现两者的同行垂直居中；
5. **单列等距精灵图推导**：掌握纵向精灵图的步长规律，背景向上移动取负值，依据步长高度递减公式 $-(n-1) \times \text{height}$ 即可实现精准高效的批量背景定位。
