# 电商交互抽屉与百分比定位：CSS3 平移 translate 商业级实战

同学们好！上一讲我们搞明白了 2D 变换的坐标系法则，知道了 `transform: translate()` 为什么具备“零重排、不破坏文档流”的天然性能优势。

但光懂语法规则还远远不够。在实际的企业级项目开发中，平移到底怎么用？怎么与盒模型、定位、过渡以及各种状态选择器严丝合缝地配合起来？

这一讲，我们就进入真实的商业项目战场，以大型电商项目《小兔鲜儿》的“服饰 / 新鲜好物”商品卡片为例，亲手实现一个极具代表性的电商高频交互：**鼠标悬停卡片时边框变色，同时底部抽屉（“找相似”遮罩层）丝滑升起**。在这个案例中，我们会遭遇初学者必踩的三个“大坑”，并顺势解锁 `translate` 百分比参数带来的前端神器——**无需计算尺寸的绝对定位垂直水平居中秘籍**。

### 1.2 标签语义与防嵌套违规

很多同学在写 HTML 结构时，一激动就把代码写成了这样：

```html
<!-- 典型错误结构：a 标签套 a 标签（HTML 规范严厉禁止！） -->
<li>
  <a href="#">
    <img src="goods.jpg" alt="">
    <h3>男士情侣跑步鞋</h3>
    <div class="mask">
      <a href="#">找相似</a> <!-- 严重错误！页面解析必崩！ -->
    </div>
  </a>
</li>
```

> **易错点**：**`<a>` 标签内严禁嵌套另一个 `<a>` 标签**。在 HTML 规范中，超链接属于交互型元素，浏览器遇到 `<a>` 内部又有 `<a>` 时会强行错乱闭合，导致整块 DOM 结构四分五裂。
> 卡片主体跳转到商品详情页，而“找相似”是跳转到搜索相似推荐列表，二者是并列的独立交互！

因此，正确的 DOM 骨架必须让卡片主链接与 `.mask` 保持兄弟关系，共同置于 `li` 内部：

```html
<ul class="goods-list">
  <li>
    <!-- 1. 商品主要图文信息超链接 -->
    <a href="#" class="goods-link">
      <img src="images/shoes.png" alt="跑鞋">
      <p class="title">轻便透气减震情侣款跑步鞋</p>
      <p class="price">¥199</p>
    </a>
    <!-- 2. 独立抽屉图层：找相似遮罩 -->
    <div class="mask">
      <a href="#">找相似</a>
    </div>
  </li>
</ul>
```

## 2. 商业实战三道坎与核心机制推导

要完美交付这个效果，我们需要在 CSS 中逐一化解三个技术卡点。

### 2.1 第一道坎：边框变色为何引发页面剧烈抖动？

我们要实现鼠标悬停卡片时边框变绿，最容易写出的直觉代码是：

```css
/* 错误示范：悬停时临时挂载边框 */
li {
  width: 240px;
  height: 300px;
  background-color: #fff;
}
li:hover {
  border: 2px solid #27ba9b; /* 导致内容抽搐！ */
}
```

#### 现象与原因剖析
当你把鼠标放上去时，卡片内部的内容会瞬间“往里缩一下”，挪开鼠标又“弹回来一下”，整个页面如同抽搐一般抖动。
为什么？因为 `li` 原本没有边框，在 `:hover` 的一瞬间凭空多出了上下左右各 `2px` 的物理边框。这新多出来的 `2px` 会向内挤压内容空间（或者向外撑大外轮廓），瞬间破坏了原本精准对齐的盒模型空间！

#### 终极解决方案：预埋透明边框
在静态初始化时，就为 `li` 赋予一个宽度为 `2px` 的**透明边框（transparent）**。

```css
/* 正确写法：预先占位，悬停只换颜色 */
li {
  width: 240px;
  height: 300px;
  background-color: #fff;
  /* 预先占好 2px 的坑位，颜色完全透明 */
  border: 2px solid transparent;
  transition: all 0.3s;
}

li:hover {
  /* 悬停时尺寸不变，仅切换色彩 */
  border-color: #27ba9b;
}
```
这样一来，盒子的几何尺寸在悬停前后没有发生丝毫改变，彻底杜绝了排版重排与内容抖动。

---

### 2.2 第二道坎：底部抽屉 mask 为什么初始值是 bottom: -83px？

抽屉 `.mask` 需要定位在卡片的正底部，其高度经测量为 `83px`。我们对它应用“子绝父相”定位：
- 父级 `li`：`position: relative;`
- 抽屉 `.mask`：`position: absolute; left: 0; width: 100%; height: 83px;`

现在关键来了：**在未悬停时，怎么把它藏到卡片下方去？**

很多同学在这里把正负号搞得晕头转向：
- 我们知道 `bottom: 0;` 是让 `.mask` 的底边贴齐父容器的底边；
- 那么如果写 `bottom: 10px;`，盒子是往上走还是往下走？
  - `bottom` 的含义是“**距离父容器底边的距离**”！
  - 距离底边越来越大（`10px`、`20px`），盒子只能**向上跑**！
- 因此，要想让它跑到父容器底边的外面去，距离必须是负数！
- 抽屉自身高度正好是 `83px`，所以设置 `bottom: -83px;`，抽屉便分毫不差地沉睡在父级底边的正下方。

```text
定位 bottom 极性几何分析
┌─────────────────────────┐
│ li 父容器                │
│                         │
│                         │
│                         │
├─────────────────────────┤ bottom: 0 (贴齐底边)
│ .mask 抽屉 (高 83px)    │ 
└─────────────────────────┘ bottom: -83px (完全移出父级底边之外)
```
*图 2：定位属性 bottom 正负值的几何空间映射*

最后，在父级 `li` 上加上一行：
```css
overflow: hidden;
```
这一行就像一把锋利的裁纸刀，把超出 `li` 底边范围的 `-83px` 抽屉干净利落地隐藏在视口之外。

---

### 2.3 第三道坎：悬停选择器层级与 translateY 的负值逻辑

抽屉就位后，我们必须让它在鼠标悬停时优雅升起。

#### 1. 选择器层级铁律：鼠标划过谁？谁产生动画？
鼠标指针滑入的是商品卡片 `li`，但真正执行位移动画的是里面的子元素 `.mask`。
所以选择器必须精准写出**后代关系（中间必须有空格）**：

```css
/* 鼠标滑过 li，让其内部的 .mask 发生形变 */
.goods-list li:hover .mask {
  /* 动效核心代码 */
}
```

#### 2. 为什么不用 bottom: 0，而必须用 transform: translateY(-83px)？
有同学会说：“老师，我直接写 `.goods-list li:hover .mask { bottom: 0; }` 不也能拉上来吗？”
能，视觉上确实能上来。但是！我们上一讲反复强调过底层性能：
- 修改 `bottom` 会触发浏览器的**布局回流（Reflow）**；
- 而使用 `transform: translateY()` 属于**独立图层矩阵运算**，由合成线程直接交付 GPU 渲染，性能平滑，无卡顿。

#### 3. 为什么是 translateY(-83px) 而不是正数？
初学者最容易产生的困惑：“盒子本来在下面，现在要升上来，不是往正方向移动吗？怎么还是负数？”

牢记这一条核心铁律：
> **结论**：**`translate` 位移的坐标原点，永远是元素自身的当前静态位置（即它原本呆着的地方）！**
> `.mask` 此时此刻的静态物理位置已经在 `bottom: -83px` 的地方趴着了。以这个位置作为 $(0,0)$ 原点，要让它**向上**位移 83 像素，在网页坐标系中，垂直向上**必须是负值**！因此代码必须是 `translateY(-83px)`。

## 4. 进阶核心：translate 百分比机制与绝对居中神器

在这个案例中，我们传入的参数都是像素值（如 `83px`）。但实际上，`translate()` 还隐藏着一个极其强大的特性：**支持百分比单位（`%`）**。

### 4.1 百分比的参照物基准

请所有同学在这里竖起耳朵认真听：**CSS 中绝大多数属性（如 `width: 50%`、`left: 50%`、`margin-left: 50%`）的百分比计算，都是以父容器为参照基准的**。

但是，**`transform: translate()` 是一个极其罕见的例外！**

> **定义**：`translate()` 中的百分比参数，**严格相对于元素自身的几何尺寸进行换算**，与父级容器的尺寸没有任何关系！
> - `translateX(50%)`：向右移动**自身宽度**的 50%；
> - `translateY(-50%)`：向上移动**自身高度**的 50%；
> - `translate(-50%, -50%)`：水平向左移动自身宽度的 50%，垂直向上移动自身高度的 50%。

```text
translate 百分比换算原理
┌──────────────────────────────────────────────┐
│ 盒子本身（宽度 W = 200px, 高度 H = 100px）    │
└──────────────────────────────────────────────┘
应用 transform: translate(-50%, -50%):
水平移动距离 = -(200px × 50%) = -100px (向左移 100px)
垂直移动距离 = -(100px × 50%) = -50px  (向上移 50px)
【与外部父容器有多宽、多高彻底解耦！】
```
*图 3：translate 百分比以自身几何尺寸为基准的计算机制*

### 4.2 终极解脱：告别尺寸心算的绝对居中法

我们在前面制作轮播图左右切换箭头、弹窗对话框时，经常需要让一个绝对定位的元素在垂直或水平方向上精确居中。

过去我们的传统做法是：
```css
.prev-btn {
  position: absolute;
  top: 50%;
  height: 60px;
  /* 痛苦的心算：必须知道按钮高 60px，然后往回拉一半高 (-30px) */
  margin-top: -30px;
}
```
这种写法有致命的维护缺陷：如果 UI 设计师突然把按钮高度改成了 `178.56px`，你还得掏出计算器除以 2，重新改写 `margin-top: -89.28px`。

现在有了 `translate` 百分比，我们彻底告别计算器：

```css
/* 现代企业级垂直居中标准写法 */
.prev-btn {
  position: absolute;
  top: 50%;
  /* 自动抓取自身当前高度并向上回拉 50% */
  transform: translateY(-50%);
}
```

```text
绝对定位 + translate 垂直居中二段式推导
【第一步：top: 50%（盒子顶边到达父级中线，偏下）】：
┌────────────────────────┐
│ 父级容器               │
│                        │
├────────────────────────┤ ← 父级垂直中线 (50%)
│ ┌────────────────────┐ │
│ │ 目标元素 (顶边对齐) │ │ (盒子整体沉在下半区，未居中)
│ └────────────────────┘ │
└────────────────────────┘

【第二步：transform: translateY(-50%)（向上回拉自身高度一半，正中！）】：
┌────────────────────────┐
│ 父级容器               │
│    ┌──────────────┐    │
├────┤  目标元素    ├────┤ ← 父级垂直中线精确贯穿元素几何中心！
│    └──────────────┘    │
└────────────────────────┘
```
*图 4：top: 50% 配合 translateY(-50%) 实现垂直居中的几何推导*

同理，想要让一个弹窗在屏幕正中央绝对居中，终极万能公式呼之欲出：

```css
/* 终极全居中神器：无需知道弹窗的任何具体宽高！ */
.modal-dialog {
  position: absolute;
  left: 50%;
  top: 50%;
  transform: translate(-50%, -50%);
}
```
无论弹窗内部的内容怎么动态撑大、缩小，它永远像一颗定海神针一样，纹丝不动地锁死在屏幕的正中心。

*图 5：平移案例核心知识与居中方案全景总结*

1. **悬停边框防抖**：通过 `border: 2px solid transparent` 预先锁定几何尺寸，悬停时仅修改 `border-color`，杜绝内容回流抖动；
2. **抽屉定位极性**：`bottom` 属性给正值向上走、给负值向下沉；利用 `bottom: -高度` 配合父级 `overflow: hidden` 实现无缝藏身；
3. **位移动画法则**：鼠标划过父级，动效赋给子级（选择器带空格）；`translate` 向上移动必须使用负值；
4. **百分比核心基准**：`translate` 中的百分比严格以**元素自身宽高**为分母，配合 `top: 50%; left: 50%` 能优雅实现与尺寸彻底解耦的绝对居中。
