# 110-CSS3 实战：饿了么企业级品牌墙无缝滚动与动画暂停

在各类商业官网、外卖平台（如饿了么、美团）以及 SaaS 产品的落地页中，合作商展示墙或客户口碑往往采用**多行多列无限无缝横向滚动（Seamless Marquee）**。

图片匀速向左缓缓流动，当第一批商户滑出视口后，第二批无缝接力，完全看不出任何断档与卡顿；当用户将鼠标悬停在品牌墙上时，滚动瞬间静止，移开后继续前行。

这种无缝滚动动效既不需要复杂的 Swiper 库，也无需 JS 定时器驱动，仅需原生 CSS3 动画与双份克隆原理即可极致高性能运行。

本节我们将以 **饿了么合作商品牌墙** 为实战蓝本，深度解析无缝循环数学原理、抖动消除技巧与悬停暂停机制。

---

## 1. 动效解构：无缝滚动的“双份克隆”哲学

为什么单组图片无法做到真正的“无缝”？

如果我们只放一组图片，当它向左平移出视口时，右侧就会变成一片空白；一旦动画执行完毕跳回起点，用户肉眼就会看到画面“啪”地闪现跳动一下，体验极差。

### 核心破局思路：AB 双组接力

```text
无缝滚动的轨道模型
视口容器 (width: 1180px, overflow: hidden)
+──────────────────────────────────────────────+
| [ A 组 (1180px) ] ── 间距 20px ── [ B 组 (1180px) ]  | 运动轨道 .scroll (flex 并排)
+──────────────────────────────────────────────+
  ◄──────── 动画匀速向左位移 1200px (1180px + 20px) ───┘
```

1. **结构设计**：
   - **外层视口（`.box`）**：固定宽 `1180px`，设置 `overflow: hidden` 裁剪溢出；
   - **运动轨道（`.scroll`）**：设置为 `display: flex`，包裹两组内容**完全一模一样**的品牌列表：A 组与 B 组。
2. **运动与跳跃点**：
   - 让轨道整体向左平移；
   - 当 A 组刚好完全移出视口，B 组正好完全顶替了 A 组原本的位置；
   - 在这一瞬间，动画一个周期结束，瞬间跳回 `0%` 起点！
   - **因为 A 组和 B 组长得丝毫不差，肉眼根本感知不到这一瞬间的“偷梁换柱”，从而形成绝对无缝的永动视觉！**

## 2. 关键数学避坑：为什么位移距离是 1200px 而不是 1180px？

这是绝大多数新手在做无缝滚动时最常踩的坑——**动画周期结束时画面轻微顿挫抖动**。

- 视口宽度：`1180px`；
- A 组与 B 组之间为了视觉美观，设置了 `margin-right: 20px` 的组间距；
- 如果你把关键帧位移写成 `-1180px`，当它跳回起点时，还有 `20px` 的距离差没有走完！这会导致画面在交接处瞬间向前“抽搐”20 像素！

### 精准位移公式：
$$\text{总位移距离} = \text{单组内容宽度} + \text{组间距} = 1180\text{px} + 20\text{px} = 1200\text{px}$$

```css
@keyframes move {
  to {
    /* 严格位移 1200px，严丝合缝无抖动 */
    transform: translateX(-1200px);
  }
}
```

## 3. 完整实战代码开发

### 3.1 HTML 结构
采用语义化的网格容器，A 组与 B 组并列排布在 `.scroll` 轨道内：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>仿饿了么品牌墙无缝滚动</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <!-- 视口大盒子 -->
  <div class="box">
    <!-- 移动轨道 -->
    <div class="scroll">
      <!-- A 组品牌卡片（6列 × 4行） -->
      <div class="ad ad1">
        <div class="item"><img src="images/logo1.png" alt="logo"></div>
        <div class="item"><img src="images/logo2.png" alt="logo"></div>
        <!-- 循环24张商户图片 -->
      </div>
      <!-- B 组品牌卡片（与 A 组内容 100% 相同克隆） -->
      <div class="ad ad2">
        <div class="item"><img src="images/logo1.png" alt="logo"></div>
        <div class="item"><img src="images/logo2.png" alt="logo"></div>
        <!-- 循环24张商户图片 -->
      </div>
    </div>
  </div>
</body>
</html>
```

### 3.2 CSS 核心样式编码

```css
* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}

body {
  height: 100vh;
  display: flex;
  justify-content: center;
  align-items: center;
  background-color: #f5f6fa;
}

/* 1. 视口容器：锁定标准宽度 1180px，开启裁剪 */
.box {
  width: 1180px;
  overflow: hidden;
  padding: 20px 0;
  border-radius: 12px;
  background-color: #fff;
  box-shadow: 0 10px 30px rgba(0, 0, 0, 0.05);
}

/* 2. 运动轨道：使用 Flex 让 A、B 两组强制横向并排 */
.scroll {
  display: flex;
  width: max-content; /* 轨道宽度由内容撑开 */
  /* 20秒匀速无限滚动 */
  animation: seamlessMove 20s linear infinite;
}

/* 3. A 组与 B 组单组布局：Grid 6列 4行 */
.ad {
  width: 1180px;
  display: grid;
  grid-template-columns: repeat(6, 180px); /* 6列，每列180px */
  grid-template-rows: repeat(4, 90px);     /* 4行，每行90px */
  gap: 16px 20px; /* 行间距16px，列间距20px */
  flex-shrink: 0; /* 核心避坑：禁止 Flex 子项被压缩 */
}

/* A 组右侧补充 20px 间距，与网格列间距保持一致 */
.ad1 {
  margin-right: 20px;
}

/* 单个商户卡片修饰 */
.ad .item {
  background: #f8f9fa;
  border-radius: 8px;
  display: flex;
  justify-content: center;
  align-items: center;
  border: 1px solid #edf0f5;
  transition: transform 0.2s;
}

.ad .item img {
  max-width: 140px;
  max-height: 60px;
  object-fit: contain;
}

/* 4. 关键帧动画：严格位移单组宽度+间距 (1180 + 20 = 1200) */
@keyframes seamlessMove {
  from {
    transform: translateX(0);
  }
  to {
    transform: translateX(-1200px);
  }
}

/* =======================================================
   5. 人性化交互：鼠标悬停品牌墙时，滚动暂停！
   ======================================================= */
.box:hover .scroll {
  animation-play-state: paused;
}
```

## 4. 重点细节与生产环境考量

1. **`animation-play-state: paused`**：
   - 这是一个非常提升用户体验的属性。品牌展示墙的目的是展示商业合作伙伴，如果用户对某个品牌感兴趣想看清楚甚至点击，鼠标悬停时动画必须立刻停顿；鼠标移开后自然恢复播放；
2. **`flex-shrink: 0` 防挤压法则**：
   - 在 `display: flex` 的容器中，如果子元素总宽度超过了父容器，子元素默认会被等比压缩。必须显式给 `.ad` 声明 `flex-shrink: 0;`，确保 1180px 宽度始终坚挺；
3. **GPU 硬件合成加速**：
   - 动画位移一定要用 `transform: translateX()`，坚决不能用传统的 `margin-left`。`transform` 位移在浏览器渲染管线中只触发 Composite（合成），不会引起重排与重绘，即使滚动几千张大图依然平滑如镜。
