## 2. 核心作业解构与破局思路

### 2.1 作业 1：3D 翻转立体卡片
- **设计目标**：鼠标悬停在卡片上，卡片沿 X 轴或 Y 轴翻转 180 度，露出背面的详情；移开后顺滑归位。
- **核心考点**：
  1. 父级容器开启 `transform-style: preserve-3d` 和 `perspective: 800px`；
  2. 背面卡片预先翻转 180 度（`rotateY(180deg)`），并声明 `backface-visibility: hidden` 隐藏背面；
  3. 悬停时仅需给总盒子旋转 180 度即可实现无缝交替。

---

### 2.2 作业 2：双线对冲流动边框特效
- **痛点分析**：前面我们学了 360 度旋转光盘，虽然酷炫，但有时候设计师需要极简风格——只有上下两条极细的光线反向穿梭。
- **极简破解方案**：
  - 完全不需要大光盘！利用容器的 `::before` 和 `::after`：
  - `::before` 是一条高 2px 的水平渐变线，放置在顶部，从左平移到右；
  - `::after` 是另一条高 2px 的水平渐变线，放置在底部，从右平移到左；
  - 配合 `overflow: hidden`，就能用极其轻巧的代码呈现出流光在边框两端对冲掠过的速度感。

---

### 2.3 作业 4 & 5：纵深与微动法则
- **微动交互（Micro-interaction）**：
  卡片悬停时切忌大幅晃动，通常采用 `transform: translateY(-6px);` 配合阴影扩张 `box-shadow: 0 12px 24px rgba(0, 0, 0, 0.15);`，即可营造出从桌面被“磁力吸起”的轻盈质感。
- **Z 轴纵深拉伸**：
  在开启 3D 空间的舞台中，对文字或核心徽标施加 `transform: translateZ(60px);`，卡片倾斜时文字会如同全息投影一样“浮出”卡片表面，极具层次感。

### 2.4 作业 6 核心攻坚：气泡浮现与 CSS 纯手工尖角

很多电商 App（如淘宝、京东）鼠标悬停在“手机扫码”时，旁边会缓缓浮现一个带箭头的小弹窗。这里包含两个核心考点：

#### 考点 A：如何做出自然的“淡入淡出”？
很多初学者直接写 `display: none` 到 `display: block`，结果发现没有任何过渡动画，生硬突兀。
- **底层原因**：`display` 属于离散属性，不支持任何 `transition` 补间！
- **标准解法**：初始设置 `opacity: 0; pointer-events: none;`，悬停时修改为 `opacity: 1; pointer-events: auto;`，配合 `transition: opacity 0.3s;`，实现呼吸般顺滑的浮现。

#### 考点 B：对话框小尖角是如何拼出来的？
```text
纯 CSS 旋转三角形气泡尖角拼装术
   +-----------------------------+
   |   扫描二维码下载客户端        |
   |                             | <- 矩形主气泡框 (.bubble)
   +--------------+--------------+
                  \ /
                   ▼  <- 纯 CSS 尖角 (正方形旋转 45° 露出一半)
```

1. 气泡框下方放置一个纯小正方形伪元素（如宽 12px、高 12px）；
2. 背景色与主气泡框完全一致；
3. 将其**旋转 45 度（`transform: rotate(45deg)`）**；
4. 绝对定位在气泡框底部边缘正中心，一半露在外面，一半被主体遮挡；露在外面的那一半就是一个极其规整的直角等腰三角形！

```css
/* 纯手工尖角标准代码 */
.bubble::after {
  content: "";
  position: absolute;
  bottom: -6px;
  left: 50%;
  width: 12px;
  height: 12px;
  background-color: #fff;
  /* 偏转 45 度形成小三角尖尖 */
  transform: translateX(-50%) rotate(45deg);
  box-shadow: 2px 2px 4px rgba(0, 0, 0, 0.05);
}
```

## 3. 作业实战标准模板代码

为了方便同学们对照自测，下面给出作业 6（带阴影与气泡尖角扫码框）的完整工业级标准实现：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>悬浮扫码与气泡尖角交互</title>
  <style>
    * {
      margin: 0;
      padding: 0;
      box-sizing: border-box;
    }

    body {
      height: 100vh;
      display: flex;
      justify-content: center;
      align-items: center;
      background-color: #f0f2f5;
    }

    /* 扫码按钮触发区 */
    .qr-trigger {
      position: relative;
      padding: 12px 24px;
      background-color: #1677ff;
      color: #fff;
      border-radius: 8px;
      font-size: 16px;
      cursor: pointer;
    }

    /* 悬浮气泡弹窗：默认隐藏，设置淡出过渡 */
    .qr-popup {
      position: absolute;
      bottom: calc(100% + 14px); /* 位于触发按钮正上方，保留14px缝隙 */
      left: 50%;
      transform: translateX(-50%) translateY(10px); /* 初始微下沉 */
      width: 150px;
      padding: 12px;
      background-color: #fff;
      border-radius: 8px;
      box-shadow: 0 10px 25px rgba(0, 0, 0, 0.15);
      
      /* 核心：用 opacity 和 visibility 替代 display */
      opacity: 0;
      visibility: hidden;
      transition: all 0.3s cubic-bezier(0.4, 0, 0.2, 1);
      text-align: center;
    }

    /* 气泡底部小三角（45° 旋转菱形） */
    .qr-popup::after {
      content: "";
      position: absolute;
      bottom: -5px;
      left: 50%;
      width: 10px;
      height: 10px;
      background-color: #fff;
      transform: translateX(-50%) rotate(45deg);
    }

    .qr-popup img {
      width: 100%;
      height: auto;
      display: block;
      border-radius: 4px;
    }

    .qr-popup p {
      margin-top: 8px;
      font-size: 12px;
      color: #666;
    }

    /* 鼠标悬停时平滑浮现并上升 */
    .qr-trigger:hover .qr-popup {
      opacity: 1;
      visibility: visible;
      transform: translateX(-50%) translateY(0); /* 归位平移 */
    }
  </style>
</head>
<body>
  <div class="qr-trigger">
    <span>手机扫码体验</span>
    <!-- 气泡弹出层 -->
    <div class="qr-popup">
      <img src="images/qrcode.png" alt="二维码">
      <p>微信扫一扫体验</p>
    </div>
  </div>
</body>
</html>
```

## 4. 阶段总结与学习建议

1. **先推导，再敲码**：
   在做 3D 旋转或无缝滚动时，先在草稿纸或脑海中建立物理几何坐标系，算清 `translate` 的尺寸参数，切忌盲目乱试数字；
2. **多用过渡驱动，少用强制重绘**：
   优先选用 `transform` 和 `opacity` 作为动效载体，这是现代浏览器合成层性能最高的两大黄金属性；
3. **完成作业并沉淀属于自己的动效组件库**：
   把本篇学到的 3D 翻转导航、渐变边框、手风琴折叠、无缝品牌墙整理为模块化代码片段。在未来的任何商业项目中，这些都将是你信手拈来的提效杀手锏！
