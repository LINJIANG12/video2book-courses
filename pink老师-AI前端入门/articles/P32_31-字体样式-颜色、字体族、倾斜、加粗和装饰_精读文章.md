# CSS 字体样式全解：颜色、字体族、大小、风格、粗细与文本装饰

书接上回。在上一讲中，我们完成了杜甫《登高·千古第一绝句》的图文综合案例。在那个案例里，骨架虽然搭建完整，大盒子与卡片也都各就各位，但细心的同学肯定早就发现了许多刺眼的视觉瑕疵：诗句的字号不够凸显、文字颜色层次单一、段落挤成一团、链接底下拖着难看的默认下划线。

要彻底解决这些视觉痛点，我们就必须系统掌握 CSS 中最基础、却也最核心的一大板块——**文本样式体系**。

在正式拆解具体属性之前，我必须先向大家强调一个绝不能触犯的核心铁律：

> **核心原则**：**CSS 无法直接修饰裸露的纯文本**！在网页中，任何文字要想被赋予样式，**必须先用 HTML 标签将其包裹包含**（例如 `<p>`、`<span>`、`<h1>`、`<em>` 等），然后通过选择器选中该标签，进而更改其文字外观。

整个文本样式在前端开发中主要被切分为两大体系：
1. **字体样式（Font Styles）**：专注控制文字本身的物理外观特征，包括颜色、字体类型、字号大小、是否倾斜、文字粗细以及装饰线；
2. **文本布局（Text Layout）**：专注控制文字在宿主盒子内部的空间排布与版式规则，包括水平对齐、首行缩进、字间距以及多行行高。

      ┌──────┴──────────────────────┐
      ▼                             ▼
┌──────────────────────────┐  ┌──────────────────────────┐
│ 1. 字体样式（Font Styles）│  │ 2. 文本布局（Text Layout）│

## 1. 文本颜色控制与色彩表示模型（color）

更改文字颜色使用的属性是 `color`。在 CSS 中，为 `color` 赋值主要有三种工业级写法。

### 1.1 颜色赋值的三种格式

1. **预定义颜色关键字（Color Keywords）**：
   例如 `red`、`green`、`blue`、`pink` 等。浏览器内置了上百种颜色英文单词。
   > **提示**：关键字在日常写 Demo、教学演示时极其顺手，但在实际生产环境和商业项目中**几乎不使用**，因为它的色彩表达过于单一、粗糙，无法精确匹配设计师精雕细琢的调色稿。

2. **十六进制表示法（Hexadecimal Notation）**：
   这是现代前端商业开发中使用频次最高的格式。它以井号 `#` 开头，后跟 6 位十六进制字符（`0-9`, `a-f`），分别代表红（R）、绿（G）、蓝（B）三种原色的强度比例，例如 `#ff0000`（纯红）、`#979797`（灰色）。当每两位颜色数值相同时，可以缩写为 3 位，例如 `#f00`、`#fff`。
   > **注意**：很多初学者一看到十六进制就犯怵：“老师，这么多数字和字母我怎么可能背得下来？”记住：**十六进制颜色绝对不需要任何人死记硬背，谁也背不住**！在真实开发中，我们打开设计师交付的蓝湖、Figma 或 MasterGo 设计稿，选中文字，在属性面板中单机一键复制十六进制色值（例如 `#333333`、`#979797`），直接粘贴到代码中即可。

3. **RGB 与 RGBA 颜色模型**：
   - **RGB**：采用函数表达式写法 `rgb(red, green, blue)`。三个参数分别取值 `0 ~ 255`。例如 `rgb(255, 0, 0)` 表示纯红，`rgb(0, 0, 0)` 表示纯黑。
   - **RGBA**：在 RGB 基础上引入了第四个参数——Alpha 透明通道：`rgba(red, green, blue, alpha)`。
     - `alpha` 的取值范围是 `0 ~ 1`。
     - `0` 代表完全透明（文字不可见）；
     - `1` 代表完全不透明（常规实体色）；
     - `0.5` 即为 50% 半透明。在实际代码书写中，小数点前面的 `0` 允许直接省略，简写为 `.5` 或 `.6`。

```css
/* 颜色赋值的三种典型写法 */
.keyword-demo {
    color: pink; /* 关键字：教学与快速验证使用 */
}

.hex-demo {
    color: #e02424; /* 十六进制：商业开发最常用，从设计稿直接复制 */
}

.rgba-demo {
    color: rgba(255, 0, 0, .5); /* RGBA：支持透明度控制，前导 0 可省略 */
}
```

### 1.2 商业实战：为什么需要 RGBA 半透明模式？

大家看主流商业网站时常常会发现：导航栏或者浮动悬浮卡片并不是纯黑或纯白，而是透着底下背景图的朦胧质感。比如《和平精英》官网顶部的横幅通栏导航条，当页面向下滚动时，背景的酷炫游戏画面会隐隐约约从导航条背后透出来。

我们打开浏览器开发者工具审查《和平精英》顶部的这块区域，会发现它的背景样式正是：
```css
/* 和平精英官网顶部半透明导航条工业级写法 */
.nav-header {
    background-color: rgba(43, 43, 52, .6);
}
```
十六进制和普通关键字根本无法表达“透光度”，而 `rgba()` 格式精准解决了这种现代沉浸式界面的视觉诉求。

## 2. 字体族匹配机制与字体类型辨析（font-family）

`font-family` 属性用于为文本指定具体采用哪种字体进行渲染呈现。

### 2.1 字体声明与多级回退匹配机制

我们给网页设置字体时，通常遵循这种语法结构：
```css
body {
    font-family: Arial, "PingFang SC", "Microsoft YaHei", sans-serif;
}
```

仔细观察这段代码，各个字体之间用英文逗号 `,` 分隔开来。浏览器的解析工作流如下：

```text
浏览器字体多级匹配瀑布流
┌─────────────────────────────────────────┐
│ 打开网页，浏览器读取 font-family 字体列表  │
└────────────────────┬────────────────────┘
                     │
                     ▼
         ┌───────────────────────┐   YES
         │ 系统是否安装了 Arial？  ├────────► [采用 Arial 渲染]
         └───────────┬───────────┘
                     │ NO
                     ▼
         ┌───────────────────────┐   YES
         │ 系统是否安装了苹方？    ├────────► [采用 PingFang SC 渲染]
         └───────────┬───────────┘
                     │ NO
                     ▼
         ┌───────────────────────┐   YES
         │ 系统是否安装了微软雅黑？├────────► [采用 Microsoft YaHei 渲染]
         └───────────┬───────────┘
                     │ NO
                     ▼
┌─────────────────────────────────────────┐
│ 调用操作系统底层的兜底字体族（sans-serif）│
└─────────────────────────────────────────┘
```
*图 2：font-family 从左到右的优先级检索流程*

1. **从左到右检索**：浏览器首先检查访问者计算机中是否安装了列表中排在第一位的字体。如果有，直接采用该字体完成渲染；
2. **多级平滑回退**：如果第一种字体缺失，依次往后寻找第二种、第三种；
3. **通用字体兜底**：如果前面列出的所有具体字体在用户的操作系统上全都没有安装，浏览器会启用列表最末端的通用字体族（如 `sans-serif`）作为保底方案，调用系统自带的对应默认字体呈现。

> **提示**：
> - 英文字体一定要写在中文字体前面！英文字体只包含英文字母和符号，当中英文混排时，英文优先走英文字体渲染，中文由于英文字体库缺失，会自动掉入后面的中文字体渲染，从而实现中西文搭配的最优排版效果；
> - 包含空格或特殊字符的字体名（如 `"Microsoft YaHei"`、`"PingFang SC"`），必须用英文引号包裹；
> - 商业项目中，字体规范一律遵循公司前端代码规范或设计稿复制，绝不需要死背。例如小米官网、天猫官网的 `body` 字体列表直接复制使用即可。

### 2.2 衬线体与无衬线体核心对比

在印刷设计与屏幕交互中，字体分为两大阵营：

| 字体类别 | 英文术语 | 核心物理特征 | 代表性字体 | 屏幕阅读适用性 |
| :--- | :--- | :--- | :--- | :--- |
| **衬线体** | Serif | 笔画起始与末端有明显装饰尖角、粗细过渡剧烈 | 宋体（SimSun）、仿宋、Times New Roman | 适合纸质传统出版物长篇印刷；在屏幕小字号下容易发虚模糊 |
| **无衬线体** | Sans-serif | 笔画端正平整，粗细均匀一致，转角无额外修饰 | 微软雅黑、苹方、黑体（SimHei）、Arial | **现代屏幕显示首选**，笔画利落清晰，高低分辨率下均具有极佳的辨识度 |

现代网页设计中，**99% 的场景都要求使用无衬线体**。这也是为什么我们通常会在 `body` 的 `font-family` 声明末尾加上 `sans-serif`。

## 3. 字体大小与像素单位规范（font-size）

`font-size` 用于精确设定字体的空间高宽尺寸。

```css
/* 字体大小的设置 */
.title {
    font-size: 18px;
}

.desc {
    font-size: 14px;
}
```

在编写 `font-size` 时，必须死死锁定以下两个细节：
1. **必须显式追加单位 `px`**：`px` 即像素（Pixel），是 CSS 中最常用的绝对长度单位。只写 `font-size: 16` 属于语法错误，浏览器会直接将其当作非法样式抛弃忽略；
2. **浏览器默认基准字号各异**：
   - 绝大多数现代浏览器（Chrome、Edge、Safari、Firefox）的默认基准正文字号均为 `16px`；
   - 极老版本的 IE 浏览器默认字号曾为 `21px`。
   - **正规军做法**：大型商业网站一定会在全局样式中给 `body` 明确指定一个基准字号（例如小米官网指定 `14px`，电商列表常用 `12px` 或 `14px`），避免各端浏览器默认字号差异破坏版面。

> **Emmet 提效**：在支持 Emmet 的编辑器中，输入 `fz14` 然后按下 `Tab` 键，即可秒级展开为 `font-size: 14px;`。

## 4. 字体风格与图标倾斜重置（font-style）

`font-style` 属性决定文字是否以斜体展示。

### 4.1 属性取值
- `normal`：正常外观，文字不发生倾斜；
- `italic`：斜体展示。

```css
/* 让正常文字变倾斜 */
.make-italic {
    font-style: italic;
}

/* 让默认倾斜的文字恢复正直端正 */
.reset-normal {
    font-style: normal;
}
```

### 4.2 真实业务场景：为什么我们总在用 font-style: normal？

很多同学可能会疑惑：“既然我们要让文字倾斜，用 `font-style: italic` 不就好了吗？为什么老师在讲解时反复强调开发中最常用的反而是 `normal`？”

真实商业项目里，**极少有产品经理或设计师会主动把正文大面积改成斜体**（用户看斜体文字非常费眼，降低阅读效率）。相反，我们大量依赖 `font-style: normal;` 的原因在于清除原生标签的倾斜行为：

1. **小图标载体标签清洗**：
   在 HTML 规范中，`<i>` 和 `<em>` 默认自带斜体样式。但在现代前端开发中，由于 `<i>` 代表 icon，开发团队极其喜欢用短小的 `<i>` 或 `<em>` 标签作为网页小图标的容器（例如小米官网右上角的购物车图标、搜索小放大镜）。如果不清除倾斜，图标挂载上去就会歪歪扭扭。
2. **强调标签语义化**：
   在百度搜索结果中，用户搜索的关键词会用 `<em>` 标签包裹高亮（呈现红色）。为了保证词语依然端正显示，百度前端在全局 CSS 里统一声明：
   ```css
   /* 清除语义标签原生斜体样式的行业标配 */
   em, i {
       font-style: normal;
   }
   ```

## 5. 字体粗细与权重数值模型（font-weight）

`font-weight` 用于设置字体的笔画粗细程度。

### 5.1 关键字与数值档位映射

`font-weight` 支持两套赋值方案：

| 赋值方式 | 常见取值 | 对应数值档位 | 技术内涵与应用场景 |
| :--- | :--- | :--- | :--- |
| **关键字** | `normal` | 400 | 正常粗细，默认不加粗 |
| **关键字** | `bold` | 700 | 加粗，相当于原生 `<strong>` 效果 |
| **数字档位** | `100 ~ 900` | 100 的整百倍 | 纯数字赋值，**后面绝不能加 `px` 单位**！更精准细腻 |

```css
/* 粗细控制的典型写法 */
.title-reset {
    font-weight: 400; /* 或 normal，去除粗体 */
}

.text-strong {
    font-weight: 700; /* 或 bold，显式加粗 */
}
```

### 5.2 为什么有了 strong/b 标签，还必须用 font-weight？

有的同学会问：“老师，HTML 里面不是已经有 `<strong>` 和 `<b>` 可以把字变粗了吗？为什么 CSS 还要专门弄一个 `font-weight` 呢？”

在商业开发中，存在两个无法绕开的业务刚需：

#### 场景一：标题标签默认加粗的“反向消除”
HTML 中的 `<h1>` 到 `<h6>` 标签在浏览器里默认是生硬的大粗体。但在现代 UI 设计风格中（如小米商城“手机”、“智能穿戴”等二级楼层标题），为了体现科技感与极简风，标题不仅不加粗，反而需要很细。
我们不可能去改写浏览器内置的标签定义，只能使用 CSS 的选择器选中标题标签，通过 `font-weight: normal;`（甚至设为 `font-weight: 200;`）将其生硬的加粗效果剥离掉。

#### 场景二：海量文本的高效批量加粗
在体育赛事积分榜（例如 NBA 赛程表），某一列包含雷霆、火箭、湖人、勇士等几十个球队名字需要全部加粗。如果你纯靠 HTML，就必须在每一个 `<td>` 内部机械地敲一遍 `<strong>...</strong>`，产生极其冗余的代码垃圾。
而有了 CSS，我们只需要给父级容器（如 `<tr>` 或整个表格类选择器）挂上一句：
```css
/* 批量为所有子项目加粗 */
.rank-table .team-name {
    font-weight: 700;
}
```
所有球队名称瞬间完成统一加粗，代码简洁，维护成本极低。

## 6. 文本装饰线的设置与清除（text-decoration）

`text-decoration` 属性用于在文本的上方、下方或中间施加装饰线。

### 6.1 四大核心取值

```css
/* 文本装饰线的常用取值 */
.no-line {
    text-decoration: none; /* 清除所有装饰线，商业开发最高频 */
}

.underline {
    text-decoration: underline; /* 开启下划线 */
}

.overline {
    text-decoration: overline; /* 开启上划线，极少见 */
}

.line-through {
    text-decoration: line-through; /* 开启贯穿线/删除线，电商核心应用 */
}
```

```text
文本装饰线四种形态物理示意图
┌──────────────────────────────────────────────┐
│  text-decoration: overline;    ── 上划线 ──   │
│  T E X T   C O N T E N T                     │
│  text-decoration: line-through; ── 中穿线 ──  │
│  T E X T   C O N T E N T                     │
│  text-decoration: underline;   ── 下划线 ──   │
└──────────────────────────────────────────────┘
```
*图 3：四种装饰线相对于文字字形基线的所处位置*

### 6.2 商业实战应用

1. **清除超链接默认下划线（前端必背金句）**：
   在 HTML 中，`<a>` 标签天生自带一条底边下划线，并且文字呈现蓝色。在 B站、小米、京东等任意现代网页上，导航与文字链平时绝不会挂着刺眼的下划线。
   因此，所有正规商业前端项目的第一行基础重置样板代码中，必定包含这句：
   ```css
   /* 清除全站所有 a 标签下划线 */
   a {
       text-decoration: none;
   }
   ```
2. **电商原价划线与二手平台划线**：
   在电商平台展示商品价格时，“现价 ￥1999，原价 ~~￥2268~~”，原价上面那条水平划掉的横线，除了可以使用 `<del>` 标签外，更主流、更轻量的方式是直接对包裹的 `<span>` 应用：
   ```css
   .origin-price {
       text-decoration: line-through;
       color: #999;
   }
   ```
   闲鱼、淘宝、京东的划线价几乎无一例外采用这种写法。

## 7. 字体样式核心属性快速检索全貌

为了让大家在后续开发中随时准确定位，我们把本讲学到的六大属性归纳对比如下：

| CSS 属性名 | 中文含义 | 常用核心取值 | 工业实战高频用法与防坑点 |
| :--- | :--- | :--- | :--- |
| `color` | 文本颜色 | `#333`、`#f00`、`rgba(0,0,0,.6)` | 开发严禁手敲关键字，优先从设计稿直接吸取十六进制；半透明质感采用 `rgba()` |
| `font-family` | 字体族 | `Arial, "PingFang SC", "Microsoft YaHei", sans-serif` | 英文字体置于中文字体前；带空格的字体名必须加英文引号；末尾加通用无衬线体兜底 |
| `font-size` | 字体大小 | `14px`、`16px`、`18px` | **必须加 `px` 单位**！现代浏览器正文基准通常为 `14px` 或 `16px` |
| `font-style` | 字体风格 | `normal`、`italic` | 绝大多数场景用于将默认倾斜的 `<i>`、`<em>` 标签强制重置为 `normal`（端正显示） |
| `font-weight` | 字体粗细 | `normal(400)`、`bold(700)`、`200` | 优先使用纯数字写法（不加 `px`）；常用于消除 `h` 系列标题自带的粗体 |
| `text-decoration` | 文本装饰 | `none`、`underline`、`line-through` | 全局给 `a` 标签设置 `none` 去除默认下划线；给原价添加 `line-through` 贯穿线 |
