# 109-CSS3 实战：仿苹果多元素 3D 倾斜层叠与毛玻璃卡片动效

在苹果（Apple）官方产品展示页或各大大厂年度设计中，我们经常能看到一组极具视觉冲击力的卡片动效：

页面居中层叠着 5 张精美的卡片，初始状态下它们以统一的 3D 角度优雅倾斜，彼此交叠错落，透出细腻的毛玻璃质感；当鼠标悬停进入容器时，所有卡片如同被赋予了生命一般，顺滑地抹平倾斜角，并按照精心设计的轨迹向四周错落展开，带来极其震撼的高级空间交互体验。

本节我们将以这个 **仿苹果 3D 倾斜层叠卡片案例** 为核心，深入演练多元素协同动画的编排、子代通配符选择技巧、以及质感利器 `backdrop-filter`（毛玻璃效果）。

---

## 1. 动效架构与空间解构

### 1.1 五卡片层叠与空间排布
整个动效由 1 个外层大盒子（`.box`）和 5 个绝对定位的子卡片（`.card1 ~ .card5`）构成：

```text
3D 倾斜层叠卡片初始与悬停状态对比
【初始状态：统一步调 3D 倾斜 + 叠合】
            [ Card 2 (顶部微偏) ]
       [ Card 1 ]  [ Card 3 (核心主图) ]  [ Card 5 ]
            [ Card 4 (毛玻璃半透) ]
      └── 全体以 rotateY(-20deg) rotateX(20deg) 侧偏 ──┘

【悬停状态 (.box:hover)：抹平倾斜 + 错落平移展开】
     [ Card 1 ] ◄── 飞向左上方 (-30px, -30px)
     [ Card 2 ] ◄── 飞向上方 (0, -30px)
     [ Card 3 ] ◄── 居中归位 (0, 0)，作为锚点
     [ Card 4 ] ◄── 飞向左下方 (-120px, +60px)
     [ Card 5 ] ◄── 飞向右下方 (+30px, +30px)
```

### 1.2 核心状态机设计：
1. **静止倾斜态**：利用 CSS 变换将所有子卡片统一绕 Y 轴与 X 轴偏转，营造统一的光影空间透视；
2. **悬停激活态**：在父级 `.box:hover` 时，子卡片同时执行两个动作：**清除倾斜角度**，并**向各自的预设方向平移指定像素**。

## 2. 核心技术点深入拆解

### 2.1 亲儿子通用选择器：`.box > *`
如何优雅地给 5 个子卡片同时施加初始倾斜效果？
传统写法是给每个 `.card1, .card2, .card3...` 都写一遍，代码极其臃肿。

pink 老师教给大家一个非常规范的工程写法：
```css
/* 选中 .box 下的所有直系子元素（亲儿子） */
.box > * {
  transform: rotateY(-20deg) rotateX(20deg);
}
```
- `>` 表示子代选择器，只约束直系子层级；
- `*` 通配符代表所有标签。配合起来即为“无论子元素是 `div`、`article` 还是 `section`，全部统一倾斜”！

> **顺序避坑要点**：
> `transform` 中多个变换函数的书写顺序会严重影响最终朝向。先旋转 Y 轴再旋转 X 轴（`rotateY(...) rotateX(...)`）与先 X 后 Y 呈现的空间姿态是完全不同的，必须严格按照视觉稿调试对齐。

---

### 2.2 现代高级感灵魂：`backdrop-filter`（毛玻璃效果）

很多同学会混淆 `filter: blur()` 与 `backdrop-filter: blur()` 的区别：

| 属性 | 作用对象 | 表现结果 |
| :--- | :--- | :--- |
| **`filter: blur(10px)`** | **元素自身及内部所有子内容** | 卡片上的文字、图标、边框全部变得模糊一片，用户根本看不清文字！ |
| **`backdrop-filter: blur(10px)`** | **仅作用于该元素背后的背景区域** | 元素自身的文字、图片依然**无比清晰锐利**，但透过半透明卡片背后的底层画面则呈现出真实的磨砂玻璃质感！ |

pink 老师生动比喻：
> “`blur` 就像近视眼镜的度数：度数越深，世界越模糊。5 米之外雌雄莫辨，10 米之外人畜不分。数值写得越大，后面的画面散焦就越彻底。”

配合半透明背景色（如 `background-color: rgba(255, 255, 255, 0.15)`），即可瞬间拉满苹果原生的拟态物理质感！

```css

  align-items: center;

  z-index: 1;
}

.card2 {
  width: 220px;
  height: 160px;
  left: 260px;
  top: 40px;
  background: linear-gradient(135deg, #43e97b, #38f9d7);
  z-index: 2;
}

/* Card 3: 核心主卡片（居中主视觉） */
.card3 {

   4. 鼠标悬停交互编排：抹平倾斜，错落展开

.box:hover .card1 {

.box:hover .card4 {
  transform: translate3d(-120px, 60px, 0);
}

/* Card 5：向右下大幅平移展开 */
.box:hover .card5 {
  transform: translate3d(30px, 30px, 0);
}
```

## 4. 关键技巧与实战小结

1. **`translate3d` 激活 GPU 硬件加速**：
   - 在写位移动效时，优先采用 `translate3d(x, y, 0)` 而非 `translate(x, y)`。这样可以强制浏览器开辟独立的 GPU 合成渲染层，5 个卡片同时位移依旧维持 60FPS 的极致流畅度；
2. **贝塞尔曲线的“回弹质感”**：
   - 代码中使用的 `cubic-bezier(0.34, 1.56, 0.64, 1)` 是经典的手感弹簧曲线，展开到终点时会发生极其微妙的轻微超调与回弹，完全消除普通 `linear` 或 `ease` 的机械呆板感；
3. **`-webkit-backdrop-filter` 兼容前缀**：
   - 生产环境中，在写 `backdrop-filter` 时务必补全 `-webkit-backdrop-filter`，确保在 iOS Safari 和老版本 macOS 上均能呈现剔透的毛玻璃效果。
