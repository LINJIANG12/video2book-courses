# 综合案例实战：杜甫《登高·千古第一绝句》图文网页搭建

“风急天高猿啸哀，渚清沙白鸟飞回。无边落木萧萧下，不尽长江滚滚来。”

杜甫这首《登高》，被明代胡应麟誉为“古今七言律诗第一”。今天我们暂且放下纯粹的语法背诵，进入第二篇章的重量级实操战场——**综合案例：登高赏析文章页面制作**！

做网页绝不能一上来就盲目敲代码。很多初学者写页面时习惯“摸着石头过河”，写一个标签看一眼，结果越写越乱、样式四处打架。在前面我就教过大家一套行业正规军的标准工作流：**先整体分析，再拆解细节，最后编码落地**。

通过这一讲的实战，我们要达成三个核心目标：
1. **语义化标签大练兵**：运用 `<div>`、`<p>`、`<h5>`、`<img>`、`<video>` 让页面骨架结构严谨、层次分明；
2. **选择器与基础盒模型综合运用**：实战类选择器、后代选择器、`margin: 0 auto` 水平居中以及初探内边距 `padding`；
3. **温故而知新，引出下阶段技术痛点**：在制作过程中大家会直观地看到——为什么段落没有首行缩进？为什么诗句无法水平居中？为什么文字挤在一起行高不够？带着这些真实的视觉痛点，我们将顺理成章地迈入接下来的文本与字体样式大门。

### 1.1 大外框与小内框的“双盒”嵌套设计
- **外层大盒子（`.box`）**：
  - 宽度固定为 `677px`；
  - 配备一个设计师调好的淡蓝色背景；
  - 负责统揽全局，并在浏览器窗口中实现水平居中。
- **内层内容盒子（`.content`）**：
  - 宽度收紧为 `610px`；
  - 背景色设置为纯白（`#fff`）；
  - 嵌套在大盒子下方并同样水平居中，左右两侧自然露出大盒子的浅蓝色底边，形成极具层次感的雅致卡片效果。

### 1.2 页面元素的纵向排列细节
1. **顶部横幅**：一张大头图直接塞进 `.box` 顶部，与大盒子等宽融合；
2. **正文区域**：背景文字介绍、古诗主体、赏析解析段落、两张 WebP 意境配图；
3. **底部媒体**：配置了封面图（`poster`）和原生控件（`controls`）的朗诵视频。

## 2. 搭建基础骨架与大盒子外框

打开编辑器，我们首先建立标准 HTML5 文档，并准备好素材资源。

### 2.1 清除默认内外边距与大盒子居中

写 CSS 的第一句核心代码是什么？大家还记不记得？——**清除浏览器的默认内外边距**！
默认情况下，浏览器的 `<body>`、`<p>` 等标签自带一些烦人的外边距，导致盒子与窗口四周总留着一条刺眼的白边。我们用通配符选择器一招搞定：

```css
/* 清除所有标签的默认内外边距 */
* {
    margin: 0;
    padding: 0;
}
```

紧接着，我们要定义外层大盒子 `.box`：
```html
<div class="box">
    <!-- 所有的网页内容都将被包在这个大盒子里 -->
</div>
```

```css
.box {
    /* 设计师指定的宽度 */
    width: 677px;
    /* 浅蓝色背景 */
    background-color: #f0f7fe;
    /* 让大盒子在网页视口中水平居中 */
    margin: 0 auto;
}
```

> **核心机制**：很多同学在初学时容易疑惑：“老师，为什么我写了 `.box` 的宽度和背景色，在页面上却什么都看不见？”
> 记住这个铁律：**块级元素如果不给高度，它的高度默认由内部的内容撑开**！由于此时我们的 `.box` 里面空空如也，高度为 0，自然肉眼看不见。只要把正文内容塞进去，大盒子就会像气球一样被饱满地撑起来。

## 3. 白色卡片盒子构建与内边距 Padding 揭秘

完成了大盒子的居中搭建，紧接着在横幅大图下方，我们需要开辟专门的白底内容区——`.content`。

### 3.1 宽度与背景色设定

```html
<div class="box">
    <!-- 顶部横幅题图 -->
    <img src="./images/img.jpg" alt="登高诗意图">

    <!-- 内容卡片容器 -->
    <div class="content">
        <!-- 文字、诗词、配图、视频 -->
    </div>
</div>
```

为 `.content` 设定样式：
```css
.content {
    /* 比大盒子稍窄，留出浅蓝边框感 */
    width: 610px;
    /* 纯白卡片底色 */
    background-color: #fff;
    /* 让卡片在 .box 内部同样水平居中 */
    margin: 0 auto;
}
```

### 3.2 为什么必须引入内边距 Padding？

当我们把杜甫生平文字放入 `.content` 之后，刷新页面会发现一个极不舒服的视觉缺陷：
文字死死地贴在白色卡片的左边缘和上边缘，视觉上极其紧迫逼仄。在真实的前端页面重构中，任何优质的排版都讲究“留白”与“呼吸感”。

```text
内边距 Padding 作用机理示意
未加 Padding 时（文字贴脸，极其压抑）：
┌────────────────────────────────────────┐
│杜甫（712年—770年），字子美，自号少陵野老...│
└────────────────────────────────────────┘

加入 padding: 20px 后（文字向内收缩，留出舒适边距）：
┌────────────────────────────────────────┐
│  ▲                                     │
│  │ 20px 缓冲间距                        │
│◄─┼─ 杜甫（712年—770年），字子美... ──┼─►│
│  │                                     │
│  ▼                                     │
└────────────────────────────────────────┘
```
*图 2：Padding 撑开内容与边框的安全距离*

> **定义与直观理解**：
> `padding` 就是**内边距**。简单来说，就是**盒子里的内容与盒子边缘之间的距离**。就像你对别人说：“你的字离我的边稍微远一点，别离我贴得那么近，咱们俩还不熟！”加上 `padding: 20px;`，文字就会乖乖地向盒子内部退缩 20 像素，瞬间呈现出呼吸感。

```css
.content {
    width: 610px;
    background-color: #fff;
    margin: 0 auto;
    /* 增加内边距，让内容与白框四周保持舒适间隙 */
    padding: 20px;
}
```

## 4. 媒体元素后代适配：100% 宽度的工程铁律

在 `.content` 内部，我们插入了数张诗文插图（`1.webp`、`2.webp`）以及一段朗诵视频（`video.mp4`）。此时立刻遭遇了第二个典型工程问题——**图片把盒子撑爆了**！

### 4.1 现象与后代选择器介入

设计稿中的内容盒子只有 `610px` 宽，但单反拍摄或素材库下载的配图原始宽度可能是 1200px 甚至更大。如果不加限制地直接插入 `<img>`，超大的图片会蛮横地顶破白色卡片，直接溢出到大盒子外面，造成页面排版彻底坍塌。

此时我们绝不能给每张图片手动写固定的像素值，而要祭出上一节学到的强大法宝——**后代选择器**配合百分比宽度：

```css
/* 选中 content 盒子内部所有的 img 标签 */
.content img {
    /* 100% 纯牛奶法则：父亲多宽，我就多宽！ */
    width: 100%;
}
```

### 4.2 为什么推荐写 100% 而不是具体的 610px？

有些同学会问：“老师，我知道内容盒子是 610px，我直接写 `width: 610px` 不也行吗？”
千万不要这么写！这里面藏着资深前端的工程智慧：
1. **联动解耦**：如果后续设计师要求把 `.content` 的宽度调整为 `650px`，如果你的图片写死了 `610px`，你就必须跑到 CSS 里把所有的图片宽度一个个翻出来改一遍；
2. **纯牛奶继承思维**：写成 `width: 100%`，就代表“紧跟父级脚步”。父容器多宽，子元素自动填满多宽。改了父盒子的尺寸，所有子图片自动缩放适配，省心省力！

同样地，底部的视频也必须遵循完全相同的自适应逻辑：

```css
/* 选中 content 内部的所有 video 视频标签 */
.content video {
    width: 100%;
}
```

## 6. 本讲小结与下阶段技术痛点透视

运行上述代码，一个层次分明、雅致大气的古典文学赏析单页已经初步展现在眼前！
我们不仅回顾了语义化排版、类选择器与后代选择器，而且切身体验了页面重构中极其重要的“双盒居中”和“100%父级响应”思想。

但是，看着当前渲染出来的网页，细心的同学一定会皱起眉头，提出一系列现实的排版疑问：
1. **首行为什么不能空两个字？**：文章段落一开头应当像语文课本那样“缩进两个汉字”，现在的文本全顶格排布；
2. **诗文标题与作者为何居左偏斜？**：诗歌应该居中排版才具对称美，《登高》和“唐·杜甫”为什么死死靠在左边？
3. **段落之间为什么如此局促？**：诗句之间文字贴得太紧，行与行之间缺乏呼吸间距，如何让文字更显疏朗？
4. **字体样式单调沉闷**：全篇都是系统默认的宋体或黑体，如何更换字体族（font-family）？如何让重点词汇优雅倾斜或加粗？

不要着急！解决这些疑问的钥匙，正是我们接下来要系统攻克的重头戏——**CSS 字体与文本修饰全套家族**。在下一讲（P32）中，我们将正式开启字体样式核心五件套（颜色、字体族、倾斜、加粗与装饰线）的精研之旅！
