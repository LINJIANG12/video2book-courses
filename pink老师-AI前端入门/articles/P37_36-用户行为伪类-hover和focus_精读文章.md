# 36-用户行为伪类-hover和focus

在上一节课中，我们学习了链接专属的四种状态伪类，尤其是通过“LV包包好（LVHA）”口诀记住了它们的书写顺序。很多同学学完之后就问我：“老师，`:hover` 这个鼠标悬停的效果太酷了，难道它只能给 `<a>` 标签使用吗？我们平时在网页里看到的那些普通的盒子、图片、搜索框，鼠标放上去也能变大变亮，它们到底是怎么实现的？”

答案是：**`:hover` 绝不仅仅属于超链接，页面上几乎所有的 HTML 元素都可以拥有悬停效果！**

不仅如此，平时大家在逛 B站（Bilibili）或者查阅 MDN 前端文档时，只要鼠标轻轻一点顶部的搜索框，光标闪烁的一瞬间，输入框要么突然变宽，要么周围亮起一圈精致的高亮边框——这种当表单控件“获得光标焦点”时产生的交互响应，就是由另一个极具战斗力的伪类——**`:focus`** 所掌管的。

今天我们就把这两个与用户交互行为息息相关的核心动态伪类——**`:hover`** 与 **`:focus`** 彻底讲深讲透！

---

## 1. 什么是用户行为伪类（动态伪类）？

在 CSS 规范中，**用户行为伪类（User Action Pseudo-classes）**，在日常开发中也常被称为**动态伪类**。

它与我们之前讲的静态类选择器有着本质区别：
- 静态类是我们在 HTML 结构中写死的（例如 `<div class="card">`）；
- 而用户行为伪类**只有在用户对网页执行了某种特定的动作（比如鼠标移入、按住、点击表单获取光标）时，才会动态被浏览器激活并附加样式**；一旦用户的动作结束（鼠标移走、光标失焦），这些样式又会立刻自动撤销，恢复原状。

```text
用户行为伪类触发机理
┌─────────────────────────┐
│     DOM 元素初始状态     │
└────────────┬────────────┘
             │  用户触发行为（鼠标悬停 / 光标聚焦）
             ▼
┌─────────────────────────┐
│    动态伪类规则激活生效    │  <── 注入 :hover / :focus 临时样式
└────────────┬────────────┘
             │  用户撤销行为（鼠标离开 / 光标失去）
             ▼
┌─────────────────────────┐
│  样式自动卸载，重回初始   │
└─────────────────────────┘
```

本讲核心聚焦两大最常用、最核心的动态伪类：
1. **`:hover`**：鼠标指针悬停/经过元素上方时生效；
2. **`:focus`**：表单控件等可聚焦元素获得键盘光标焦点时生效。

## 2. 鼠标悬停伪类——`:hover` 的通用化实战

### 2.1 任何元素都能 `:hover`

很多初学者容易陷入一个误区，以为 `:hover` 只能跟在 `a` 后面写成 `a:hover`。一定要记住：**在现代 CSS 中，`<div>`、`<p>`、`<li>`、`<img>`、`<button>` 等任何可见元素，都可以挂载 `:hover` 伪类！**

语法结构如下：

```css
选择器:hover {
    /* 鼠标经过该元素时，需要改变的任意 CSS 属性 */
}
```

> **易错点**：**选择器与 `:hover` 之间绝对不能有空格！**
> 必须紧紧连在一起写成 `.box:hover`。如果你不小心手滑打了一个空格写成 `.box :hover`，在 CSS 选择器语法中，空格代表**后代选择器**，这就变成了“选择 `.box` 内部所有处于悬停状态的子元素”，导致当前盒子本身的悬停效果彻底失效！

### 2.2 盒子悬停多重样式跃迁演练

我们来写一个最直观的基础案例：在页面上放置一个宽高均为 `100px` 的粉色盒子，当鼠标悬停上去时，不仅背景颜色要变，里面的文字颜色也要随之改变。

#### HTML 结构：

```html
<div class="box">文字</div>
```

#### CSS 样式：

```css
/* 1. 基础状态：100x100的粉色盒子，文字水平垂直居中 */
.box {
    width: 100px;
    height: 100px;
    background-color: pink;
    text-align: center;
    line-height: 100px; /* 单行文本垂直居中技巧：行高等于盒子高度 */
    color: #333;
}

/* 2. 鼠标经过状态：背景转红，文字转白 */
.box:hover {
    background-color: red;
    color: #fff;
}
```

代码解析：
1. 页面初始化加载时，盒子展示为柔和的粉红色，中间是深灰色的文字；
2. 只要用户的鼠标光标移动到这个正方形区域内，浏览器瞬间命中 `.box:hover` 规则，背景直接跳变为鲜艳的红色，文字同步变更为纯白色；
3. 一旦鼠标指针滑出盒子边缘，样式立刻无缝复原。

在 `:hover` 内部，我们可以修改的不仅仅是颜色和背景，还包括盒子阴影、边框、透明度乃至二维/三维位移。

### 2.3 小米官网产品卡片悬停分析

我们来看一线大厂小米官网的真实案例。

在小米商城首页浏览手机或家电列表时，每个白色的产品小卡片（通常用 `<li>` 搭建）在鼠标滑过时都会展现出极度精致的“浮起”质感：

```text
小米产品卡片悬停交互解剖
┌─────────────────────────┐
│     产品图片与标题       │
│                         │
│  [ 基础状态: 平贴页面 ]   │
└─────────────────────────┘
             │
             │ 鼠标滑入 (:hover)
             ▼
┌─────────────────────────┐ ──▲
│     产品图片与标题       │   │ 向上浮动 2px (transform: translateY(-2px))
│                         │   │
│   [ 悬停状态: 盒子悬浮 ] │ ──▼
└─────────────────────────┘
  ░░░░░░░░░░░░░░░░░░░░░░░   <── 底部投射弥散阴影 (box-shadow)
```

这种交互的核心思路就是利用 `:hover`：
1. **未悬停时**：普通的白色背景盒子，平铺在灰色底板上；
2. **悬停时（`li:hover`）**：
   - 给盒子添加微小的向上位移，让它在视觉上“浮起来”；
   - 同步注入一层由浅入深的盒子阴影（`box-shadow`），营造出真实世界的光影层次感；
   - 内部的文字链接或售后服务标题同步发生色值转变。

虽然盒子的阴影与位移属性我们会在后面的盒子模型与 2D 变换章节中详细展开，但大家必须深刻理解：**支撑这一切高级视觉反馈的底层入口，全部归功于 `:hover` 伪类**。

## 3. 焦点伪类——`:focus` 的表单实战

### 3.1 什么是焦点与 `:focus`？

平时我们在网页里填表单、登录账号或者在搜索栏找东西，总要把鼠标光标移动到输入框里面点一下，看到那一根细细的光标竖线在里面闪烁，这在前端专业术语里叫做**元素获得了焦点（Focus）**。

与此相对，当你在输入框外面随便点一下，光标消失了，就叫做**失去焦点（Blur）**。

> **定义**：**`:focus` 伪类选择器专门用于选取当前获取了键盘光标焦点的元素**。最典型的应用对象就是表单类元素（如 `<input>` 文本框、`<textarea>` 文本域等）。

```text
表单元素焦点状态流转示意
┌─────────────────────────┐
│  <input class="search"> │ ──> 默认失焦状态（无光标）
└────────────┬────────────┘
             │  用户点击输入框 / Tab 键切入
             ▼
┌─────────────────────────┐
│     .search:focus       │ ──> 获焦激活状态（光标闪烁，高亮边框/变宽）
└────────────┬────────────┘
             │  点击空白区域 / Tab 键切出
             ▼
┌─────────────────────────┐
│  <input class="search"> │ ──> 焦点释放，样式回归
└─────────────────────────┘
```

### 3.2 搜索框获焦样式交互演练

我们以大型网站常用的搜索栏为例，来看看 `:focus` 的代码实操：

#### HTML 结构：

```html
<input type="text" class="search" placeholder="请输入搜索关键词..." />
```

#### CSS 样式：

```css
/* 1. 基础状态：设置初始尺寸与边框 */
.search {
    width: 200px;
    height: 36px;
    background-color: #f5f5f5;
    border: 1px solid #ccc;
    padding-left: 10px;
    /* 清除输入框获焦时浏览器默认自带的轮廓外线 */
    outline: none;
}

/* 2. 焦点状态：当光标进入输入框时触发 */
.search:focus {
    background-color: #fff;
    border-color: #ff6700; /* 小米橙色高亮边框 */
    width: 300px;           /* 焦点获焦时宽度延展伸长 */
}
```

代码运行效果解析：
1. **初始静止时**：输入框宽度为 `200px`，背景为低调的淡灰色，带有浅灰边框；
2. **光标点击切入时**：输入框瞬间进入 `:focus` 状态，背景底色变为纯白，外边框立刻跳变成亮眼的小米橙色，同时输入框宽度直接从 `200px` 延伸扩展到 `300px`！

> **提示（小彩蛋）**：如果在 `.search` 的基础样式中加上一句过渡动画声明 `transition: all 0.3s;`，输入框在获取焦点时就不会是生硬地瞬间变宽，而是会像橡皮筋一样丝滑流畅地展开。这是后面动效篇的核心，大家先提前感受一下 CSS 的无限魅力。

### 3.3 MDN 与 B站搜索栏的工业级焦点表现

我们看看业界顶尖技术站点与产品是怎么用 `:focus` 的：

| 网站平台 | 基础状态表现 | 获焦（`:focus`）后的交互升级 | 用户体验心理学考量 |
| :--- | :--- | :--- | :--- |
| **MDN 官方文档** | 灰色极简搜索框，融入整体暗色/明色导航背景 | 整个输入框周围浮现出一圈醒目的高对比度纯白边框，宽度向外伸展 | 明确提醒开发者：当前键盘输入已就绪，防止误触其他按键 |
| **Bilibili (B站)** | 浅灰色药丸形搜索框，半透明底色 | 输入框底色变为纯白，边框出现高光，弹出热门搜索下拉推荐弹窗 | 强化当前主操作区层级，过滤背景杂乱视频信息的视觉干扰 |

在没有学习 `:focus` 之前，很多初学者以为这种输入框变色、变宽的效果必须写复杂的 JavaScript 脚本去监听 `onfocus` 事件。现在大家知道了，**仅仅凭借一行朴素的 CSS `:focus` 伪类，就能以零 JS 成本实现极致细腻的工业级表单反馈**！

## 4. 开发者工具（DevTools）高效调试动态伪类

在实际开发中，无论是 `:hover` 还是 `:focus`，它们都是“转瞬即逝”的动态状态。如果我们要用浏览器检查工具（F12）去查看获焦或者悬停时的具体样式属性，光标一离开输入框或者鼠标一挪开，样式就消失了。

如何用 Chrome 开发者工具死死“锁住”这些状态呢？

```text
Chrome 开发者工具锁定动态伪类状态指南：
┌────────────────────────────────────────────────────────────────────────┐
│ 步骤 1：按 F12 展开审查面板，用选择箭头选中对应的 HTML 节点（如 input） │
│ 步骤 2：在 Elements 节点上点击鼠标右键                                 │
│ 步骤 3：在上下文菜单中移入 "Force state"（强制状态）                    │
│ 步骤 4：根据需求勾选 ":focus" 或 ":hover"                               │
└────────────────────────────────────────────────────────────────────────┘
```

勾选之后：
- 对应的 DOM 节点前会出现一个橙色/黄色的小圆点，提示该节点已被开发者工具强制挂载了虚拟状态；
- 页面上的输入框会常驻停留在获得焦点（`:focus`）的外观下；
- 右侧 Styles 面板会清晰展示生效的 `:focus` 属性集合，你可以随意在这里勾选、取消或修改颜色，效率翻倍！

## 5. 核心要点归纳与下节预告

在本讲中，我们系统学习了与用户交互息息相关的两大动态行为伪类：

1. **`:hover` 用户悬停伪类**：
   - 适用于网页中**所有**可见的 HTML 元素，而绝非仅限于 `<a>` 标签；
   - 书写时选择器与冒号之间严禁出现空格（空格代表后代选择器）；
   - 广泛应用于电商卡片浮起、文字变色、阴影投射与微交互动效中。
2. **`:focus` 焦点伪类**：
   - 主要作用于 `<input>`、`<textarea>` 等表单控件；
   - 在光标点入、键盘聚焦时瞬间激活，常用于高亮外边框、延展宽度与切换底色；
   - 能够零成本替代 JS 的 focus 事件监听，属于现代表单美化必备神技。
3. **调试技巧**：
   - 熟练运用浏览器控制台的 `Force state` 功能，可以常驻锁定 `:hover` 与 `:focus` 状态，轻松排查复杂样式问题。

学完了基于“用户动作”的动态伪类，接下来我们要把目光投向更为强大的——**根据 DOM 树形结构的排列位置来选取元素的“结构伪类选择器”**！

如果一个父容器里面有 10 个一模一样的小盒子，我们怎么精准选中第一个？怎么单独挑出最后一个？如果我们要制作像商城后台那样**隔一行换一个背景色（隔行变色）**的经典数据表格，难道要手动给每一行加 class 吗？

下一节课，我们将深入拆解**结构伪类选择器及其在表格隔行变色中的终极应用**，咱们不见不散！
