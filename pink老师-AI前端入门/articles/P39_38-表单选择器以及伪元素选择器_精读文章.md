# 38-表单选择器以及伪元素选择器

大家平时在上网注册账号、填写问卷或者网购结算时，一定遇见过这样极其丝滑的交互体验：

比如在小米账号注册页面上，只要你还没输入合法的手机号和验证码，底部的【立即注册】大橙色按钮就是灰暗且不可点击的；一旦你输完了 11 位手机号，那颗按钮瞬间“被点亮”，变回饱满的品牌橙色；或者在登录界面勾选“我已阅读并同意《用户协议》”时，只要鼠标轻轻一点那个小小的复选框，旁边的协议文字就会立刻高亮变色；更有很多细心的同学在仿写大厂页面时，想把输入框里那句“请输入手机号/密码”的灰色占位提示文字调小一点或者改个颜色，结果发现无论在 `input` 上怎么写 `color`，改变的永远只是自己敲进去的文字，对原有的提示字毫无作用！

想要搞定这些高频、核心的工业级交互细节，今天我们要学习的两大利器就是你的必经之路：**专门掌管表单状态的“表单伪类选择器”**，以及在现代网页修饰与布局中堪称降维打击的**“伪元素选择器”**！

## 1. 概念厘清：点、冒号与双冒号的速记法则

在正式开讲前，粉哥先教大家一个绝不混淆的独家速记口诀，把这几个极易混淆的概念从符号上彻底锁死：

| 符号特征 | 语法全称 | 核心本质 | 代码范例 |
| :--- | :--- | :--- | :--- |
| **一个点（`.`）** | **类选择器** | 匹配在 HTML 标签上明确写死的 `class` 属性 | `.btn`、`.box` |
| **两个点（`:`，单冒号）** | **伪类选择器** | 匹配元素处于某种**特殊状态**（如悬停、聚焦、禁用、被选） | `:hover`、`:focus`、`:disabled` |
| **四个点（`::`，双冒号）** | **伪元素选择器** | 选取元素的**特定微观部分**，或凭空插入一个**虚拟 DOM 盒子** | `::placeholder`、`::before`、`::after` |

> **提示**：虽然在 CSS2 规范中伪元素也曾短暂使用过单冒号（如 `:after`），但 **CSS3 规范为了彻底区分“伪类”与“伪元素”，已经明确规定伪元素必须统一使用双冒号 `::`**。编写规范的现代 CSS 代码，一律使用标准的双冒号写法！

## 2. 表单伪类选择器实战

表单伪类专门用于根据表单控件的实时逻辑状态（是否可用、是否被勾选等）来动态挂载样式。

### 2.1 禁用状态伪类——`:disabled`

#### 机制解析与工业级写法对比

当一个表单元素（如 `<button>` 或 `<input>`）被添加了 HTML 原生布尔属性 `disabled` 时，用户就无法对其进行点击、聚焦或输入操作。

在 CSS 中，我们可以通过 **`:disabled`** 伪类直接选中所有处于禁用状态的表单，为其赋予“置灰”或“半透明”样式。

```text
表单禁用状态流转图
┌─────────────────────────────────┐
│     <button> 基础状态（可用）    │ ──> 正常背景色、指针正常交互
└────────────────┬────────────────┘
                 │ 注入 HTML 属性 disabled（如表单校验未通过）
                 ▼
┌─────────────────────────────────┐
│ <button:disabled> 禁用状态      │ ──> 样式被 :disabled 拦截覆盖
└─────────────────────────────────┘
```

很多初学者的写法是直接暴力修改背景色：

```css
/* 普通可用状态 */
button {
    width: 150px;
    height: 40px;
    background-color: #ff6700; /* 小米橙 */
    border: none;              /* 清除按钮默认黑边框 */
    color: #fff;
    font-size: 14px;
}

/* 初学者粗暴写法：直接换灰色背景 */
button:disabled {
    background-color: #ccc;
}
```

#### 小米官网真实高级技巧：透明度 `opacity`

然而，当你去审查小米官网或者苹果官网的注册登录按钮源码时，你会发现大厂设计师往往不会简单地给按钮糊上一层难看的灰色。**小米采用的高级做法是直接控制整体不透明度——`opacity`**：

```css
/* 小米官网同款高级写法：利用透明度弱化 */
button:disabled {
    opacity: 0.4; /* 将整个按钮的不透明度降至 40% */
}
```

> **深度剖析**：
> - `opacity` 的取值范围在 `0`（完全透明不可见）到 `1`（完全不透明）之间；
> - 与单纯修改背景色不同，**`opacity` 会让整个按钮容器连同其内部的文字、图标整体呈现出自然的虚化淡出感**，完美保留了原始按钮的色彩倾向，视觉质感远超生硬的纯灰色。

### 2.2 勾选状态伪类——`:checked`

#### 原生复选框的痛点

`:checked` 伪类专门用于匹配当前处于**已被选中/已打勾**状态的单选框（`radio`）或复选框（`checkbox`）。

很多同学学了 CSS 之后就想：“既然能选中，那我能不能直接给 `input:checked` 设置一个红色背景，让那个蓝色的打勾小方块变成红色的？”
——**答案是：原生复选框是由操作系统底层原生控件渲染的，无法直接通过 `background` 或 `color` 改变勾选框内部的对勾图标！**

#### 破局之道：相邻兄弟联动变色

大厂在不引入复杂组件库的前提下，最经典的一招是**利用 `:checked` 配合相邻兄弟选择器（`+`）实现协议文字联动**！

#### 完整演示代码：

```html
<!-- HTML 结构：注意 input 与 label 处于同一父级且紧紧相邻 -->
<input type="checkbox" id="agree">
<label for="agree">我已阅读并同意《小米商城服务协议》</label>
```

```css
/* 默认状态下协议文字呈现柔和的灰色 */
label {
    color: #666;
    font-size: 14px;
    cursor: pointer;
}

/* 核心联动规则：当 checkbox 被勾选时，紧随其后的相邻兄弟 label 变橙高亮！ */
input:checked + label {
    color: #ff6700;
    font-weight: bold;
}
```

> **代码解读**：
> 1. `input:checked`：精准捕捉“处于勾选状态的输入框”；
> 2. `+`：**相邻兄弟选择器**，指代在 DOM 树中紧挨在该 input 后面的第一个同级元素；
> 3. `label`：目标接收者。当用户点击打勾时，旁边的条款文字瞬间从暗淡的灰色跳变为鲜艳的小米橙色，视觉反馈一目了然！

## 3. 伪元素选择器：从微观排版到虚拟 DOM

### 3.1 什么是伪元素？

> **定义**：**伪元素选择器用于在页面上创建抽象的、在 HTML 文档中并未实际声明的虚拟节点（Virtual Elements），或者选取某个可见元素的特定微观文本片段。**

它让我们不需要为了修饰性目的在 HTML 结构中堆砌一堆无意义的 `<span>` 或 `<div>`，从而保持 DOM 结构的纯净与语义化。

### 3.2 文本片段微调：`::first-line` 与 `::first-letter`

1. **`::first-line`（选取首行文本）**：
   ```css
   p::first-line {
       color: red;
   }
   ```
   它选中的永远是当前段落在屏幕上渲染出来的**第一行**。无论用户如何缩放浏览器窗口导致段落文字重新折行，被标红的始终严格是首行。
2. **`::first-letter`（选取首字符/首字母）**：
   ```css
   p::first-letter {
       font-size: 28px;
       color: #ff6700;
   }
   ```
   经典报刊杂志排版中经常使用的“首字下沉”、“首字放大”排版艺术，在 CSS 中仅需一行即可实现。

### 3.3 破解占位符美化：`::placeholder`

回到我们在引言中提到的痛点：如何美化 `<input>` 或 `<textarea>` 内部的 `placeholder` 占位文字？

```css
/* 错误做法：直接改 input，只能影响用户敲进去的真内容，改不了提示词 */
textarea {
    color: pink; /* 此时占位符依然是浏览器默认的死板浅灰色 */
}

/* 正确做法：必须动用专职伪元素 ::placeholder */
textarea::placeholder {
    color: #999;       /* 柔和典雅的深灰色 */
    font-size: 12px;   /* 占位词字号调小，突出层次感 */
}
```

在审查 DeepSeek 或者小米注册页的源码时，我们可以看到大厂前端工程师都会针对 `::placeholder` 做专属的色值与行高调优，让输入框显得极具高级感。

## 4. 网页装饰的绝对王者：`::before` 与 `::after`

如果说前面的伪元素是锦上添花，那么 **`::before`** 与 **`::after`** 则是现代 CSS 页面制作中无处不在的“核武器”。无论是做图标、气泡箭头、悬停装饰线，还是高级动效，处处都是它们的身影。

### 4.1 核心运行机理与几何模型

`::before` 和 `::after` 并不是插在盒子的外部，而是**直接插入在宿主元素的内容最前端或最后端，充当该盒子的“第一个子元素”或“最后一个子元素”**：

```text
::before 与 ::after 几何结构示意图
┌─────────────────────────────────────────────────────────────┐
│ 宿主容器盒子 (例如 <div class="box">)                       │
│                                                             │
│  ┌──────────────┐     ┌──────────────┐     ┌─────────────┐  │
│  │  ::before    │  +  │ 宿主原有内容 │  +  │  ::after    │  │
│  │ (虚拟子元素) │     │ (如文本文本) │     │(虚拟子元素) │  │
│  └──────────────┘     └──────────────┘     └─────────────┘  │
│  (排在内容最前面)                           (排在内容最后面) │
└─────────────────────────────────────────────────────────────┘
```

### 4.2 必须焊死的三大金科玉律

在使用 `::before` 与 `::after` 时，有三条铁律必须刻进潜意识：

1. **必须声明 `content` 属性！**
   这是伪元素生成的前提条件。**哪怕你只是想用它画一个纯色的小红点或者一条分割线，不需要任何文字，也必须写 `content: "";`**。如果不写 `content` 属性，浏览器根本不会在页面上渲染这个伪元素盒子！
2. **默认特性为“行内元素（Inline）”**：
   它们默认像文字或 `<span>` 一样在同一行上并排排列，不独占一行。若想为它们设置固定的 `width` 和 `height`，后续必须将其转换为块级或配合定位使用；
3. **真实 DOM 树中不存在，但可被开发者工具审查**：
   在 HTML 源文件中看不到它们对应的标签，但打开浏览器控制台（F12）展开目标元素时，你能清晰看到紧随其后的 `::before` 和 `::after` 节点。

### 4.3 板书现场推导：盒子文字拼接实战

我们通过一个最直接的代码范例，看清它们的插入过程：

#### HTML 结构：

```html
<div class="box">pink</div>
```

#### CSS 样式：

```css
/* 1. 在 pink 前面插上一个盒子，注入文字 "我是" */
.box::before {
    content: "我是";
    color: red;
}

/* 2. 在 pink 后面插上一个盒子，注入文字 "老师" */
.box::after {
    content: "老师";
    color: blue;
}
```

#### 浏览器最终渲染效果：

```text
页面实际显示：我是pink老师
其中："我是"（红色，由 ::before 呈现）
      "pink"（默认颜色，由宿主自身文本呈现）
      "老师"（蓝色，由 ::after 呈现）
三者都在一行上无缝衔接！
```

### 4.4 商业级经典应用：北京大学官网导航栏装饰线

在一线名校（如北京大学官网）或大厂产品站的顶部导航栏中，当你把鼠标悬停在某个链接上方时，文字上方或下方会优雅地浮现出一段精致的短横线。

这种效果绝不是去写一堆多余的 `<div>`，而是直接通过 `a:hover::before` 或 `a:hover::after` 生成一条带有背景色和尺寸的伪元素装饰线。既不破坏语义，又实现了极其轻量且高档的视觉设计。

## 5. 本讲技术核心对照全景表

| 选择器类型 | 具体语法 | 匹配目标 / 插入位置 | 必须附带的关键属性 | 经典应用范例 |
| :--- | :--- | :--- | :--- | :--- |
| **表单伪类** | `:disabled` | 被禁用的表单元素 | 无 | 小米登录按钮不可用时 `opacity: 0.4` 虚化 |
| **表单伪类** | `:checked` | 被勾选的单选/多选框 | 无 | 复选框勾选时联动相邻 `label` 文字标橙 |
| **伪元素** | `::first-line` | 段落的第一行文本 | 无 | 报刊首行醒目排版 |
| **伪元素** | `::first-letter`| 段落的第一个文字 | 无 | 文章首字下沉变大 |
| **伪元素** | `::placeholder` | 输入框内部占位词 | 无 | 独立定制占位文字的颜色、字号与透明度 |
| **伪元素** | `::before` | 宿主内部内容的最前部 | **`content`（必须有）** | 导航悬停横线、图标前缀、装饰小红点 |
| **伪元素** | `::after` | 宿主内部内容的最后部 | **`content`（必须有）** | 气泡箭头、下拉小三角、清除浮动 |
