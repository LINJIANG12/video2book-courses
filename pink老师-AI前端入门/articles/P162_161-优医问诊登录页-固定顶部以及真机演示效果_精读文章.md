# 优医问诊登录页固定顶部与真机预览验证

页面四个模块都写完了，在电脑上拖着看挺像样，可你们有没有想过一个问题：真机上滑起来，顶部的“登录”标题栏会不会跟着滚走？我第一次把这个页面发到手机上看，标题一滚就不见了，体验一下就垮了。所以这一讲干两件事：先把顶部固定住，再把页面装进真手机里实打实验证一遍。

---

## 1. 登录页顶部标题栏的固定处理

### 1.1 固定定位的脱标补偿

顶部标题栏固定的手段只有一个：固定定位（固定定位，Fixed Positioning），`position: fixed` 加 `top: 0`。但你们一定要记住它带来的副作用——固定定位的元素会脱离标准流，原来它占的那一块高度就塌了，下面的 Logo 会“顶”上去，被标题栏压住半截。

```css
.header {
  position: fixed;
  top: 0;
  left: 0;
  width: 100%;
  height: 44px;
  background-color: #fff;
  z-index: 10;
}
```

补偿的办法同样固定：给紧跟在后面的页面主体加一个和标题栏等高的上内边距。标题栏 `44px` 高，主体就 `padding-top: 44px`，被压住的部分一下就让出来了。

```css
.main {
  padding-top: 44px;
}
```

> **易错点**：`position: fixed` 默认宽度会被内容撑开，一定要补 `width: 100%`，否则标题栏会缩成一小条，这是固定头部最高频的翻车现场。

### 1.2 固定头部的宽度与层级控制

还有两个参数是顺手必须写的。`left: 0` 保证它贴着屏幕左边缘，不写的话在某些机型上会莫名其妙错位几像素。`z-index: 10` 是让标题栏压在后面滚动内容的上层，不然图片和按钮滚上来会盖住标题字。背景色 `#fff` 也别漏，不写背景，滚动的内容会从半透明的标题底下透出来。

```text
层叠关系侧视图 (z 轴从下往上)
-------------------------------
[ z=10 ]  .header  标题栏 (不透明)
-------------------------------
[ z=0  ]  .main    页面内容 (滚动经过)
-------------------------------
```

读图说明：标题栏层级高于内容层，内容上滑时从标题栏背后经过，被不透明背景遮住。

## 2. 真机预览的环境准备

电脑浏览器里那个手机图标只是模拟，真机验证才是交作业的标准。准备工作就三条，你们对照着做。

```text
真机预览链路拓扑
+----------+    同一 WiFi    +----------+
|  电脑     | <------------> |  手机     |
| Live     |   192.168.x.x  |  浏览器   |
| Server   |   :5500        |  输入地址 |
+----------+                +----------+
```

读图说明：电脑起服务，手机和电脑连同一个局域网，手机浏览器输入电脑的局域网地址加端口即可访问。

第一，电脑和手机连同一个 WiFi，这是大前提，不在同一个局域网后面全白搭。第二，编辑器里的 Live Server 保持启动，端口一般是 `5500`。第三，在电脑上用命令行查出本机局域网地址，Windows 下是 `ipconfig` 看 IPv4 那一行，比如 `192.168.1.6`。

> **提示**：公司或校园网如果开了客户端隔离，手机会打不开电脑地址，这时自己开个手机热点给电脑连，最省事。

## 3. 真机地址拼接与效果检验

地址拼接格式固定：`http://` 加电脑 IP 加冒号加端口加项目路径。比如 `http://192.168.1.6:5500/login.html`，在手机浏览器里敲进去，登录页就出来了。

我在手机上重点验了三处，你们也照着验：

| 检验项 | 合格表现 | 对应代码 |
| :--- | :--- | :--- |
| 顶部标题栏 | 上下滑动始终悬停，不跟随滚动 | `position: fixed; top: 0` |
| 第三方图标行 | 三个图标居中，横线随宽度伸缩 | `flex` 加 `gap` |
| 登录按钮 | 宽度撑满，两侧留白与设计稿一致 | `margin` 加 `border-radius` |

滑动时标题纹丝不动，说明固定生效；把手机横过来看一眼，横线变长、图标依然居中，说明弹性布局在真机上同样自适应。到这一步，这个登录页才算真正闭环。
