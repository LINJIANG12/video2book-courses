# CSS3 3D 变换之三维坐标系、左手法则与空间旋转 rotateXYZ

在前面的章节中，我们系统学习了平移（`translate`）、旋转（`rotate`）、缩放（`scale`）以及倾斜（`skew`）等 2D 变换。然而，2D 变换始终被牢牢禁锢在一个扁平的二维画布中——元素只能在屏幕的水平 X 轴和垂直 Y 轴构成的“纸面”上滑动或打转。

真实世界是三维立体的。现代前沿的网页交互中，到处充斥着极具空间沉浸感的三维效果：带有厚度感与双面翻转的卡片、3D 环形相册画廊、根据鼠标位置产生纵深俯仰的透视橱窗。而且，CSS3 的 3D 变换原生支持 GPU 硬件加速，相比于用 JavaScript 强行计算坐标模拟立体感，CSS 3D 渲染极为高效丝滑，完全不阻塞主线程。

要想玩转 3D 变换，我们必须彻底跨越从二维平面到三维空间的认知门槛。这一讲，我们就来建立三维空间坐标系认知，掌握讲师招牌的“三维左手法则”旋转判定秘诀，剖析 `rotateX`、`rotateY`、`rotateZ` 的物理运动模型，并搞清楚为什么初学 3D 旋转时总感觉盒子“被压扁”的深层原因。

---

## 1. 网页三维空间坐标系与 Z 轴物理特性

### 1.1 从二维平面到三维空间的维度跨越

在 2D 坐标系中，我们只有水平向右的 X 轴和垂直向下的 Y 轴。而在 3D 空间中，浏览器引入了一个极其关键的全新维度——**Z 轴（深度轴 / 视线轴）**。

```text
网页 3D 三维直角坐标系空间指向示意

             -Y (垂直向上为负)
              ↑
              │
              │
-X ───────────┼───────────→ +X (水平向右为正)
(水平向左为负)│
              │
              │
              ↓
             +Y (垂直向下为正)
            /
           /  (垂直冲出屏幕，直奔眼球！)
          ↙
        +Z (屏幕外为正)
```
*图 1：浏览器视口环境下的三维空间右手/左手物理坐标轴分布*

### 1.2 三大坐标轴的正负极性法则

必须牢记屏幕坐标系与初高中立体几何坐标系的一个核心差异（尤其是 Y 轴）：

| 坐标轴 | 空间物理方向 | 正值（+）方向 | 负值（-）方向 | 屏幕环境物理映射 |
| :---: | :--- | :--- | :--- | :--- |
| **X 轴** | 水平横向 | **向右**（水平向右延伸） | 向左（水平向左收缩） | 屏幕左右水平边缘 |
| **Y 轴** | 垂直纵向 | **向下**（从上向下坠落） | 向上（从下向上升起） | 屏幕上下垂直边缘（注意：向下为正！） |
| **Z 轴** | 垂直屏幕表面 | **朝向屏幕外**（直奔用户眼睛） | 深入屏幕内（背离视线深处） | 用户眼睛与显示器屏幕之间的视距方向 |

> **定义**：Z 轴是垂直于屏幕平面的法线轴。在默认观察视角下，**正 Z 轴（+Z）是从显示器内部笔直穿透屏幕、指向坐在电脑前的你**；负 Z 轴（-Z）则是从屏幕表面不断向显示器内部深处无限延伸的虚拟空间。

## 2. 旋转正负方向判定：三维左手法则

在 2D 旋转中，我们只需记住“正值顺时针、负值逆时针”。但在 3D 空间中，元素可以绕着 X、Y、Z 三条不同的轴各自旋转，从不同角度看去顺逆时针极易混淆。

为了彻底解决这一空间感知痛点，Pink 老师结合 Web 标准给出了最实用、最不易出错的招牌记忆工具——**左手法则（Left-Hand Rule）**。

### 2.1 准备姿势：三指空间定向

```text
左手三指直角坐标系手势示意

           食指 (指向地面：+Y 轴正方向)
              ↓
              │
              │
              *───→ 大拇指 (指向身体右侧：+X 轴正方向)
             /
            /
           ↙
         中指 (指向自己的鼻梁：+Z 轴正方向)
```
*图 2：左手大拇指、食指与中指在空间中的标准三维定向*

伸出你的**左手**，将大拇指、食指与中指相互垂直张开（注意文明手势）：
- **大拇指**指向身体右侧：代表 **+X 轴**的正方向；
- **食指**笔直指向下方：代表 **+Y 轴**的正方向；
- **中指**垂直对准自己的面部：代表 **+Z 轴**的正方向。

---

### 2.2 核心实操：左手四指弯曲握拳法

当我们需要判断一个元素绕某个轴旋转正角度（如 `rotateX(45deg)` 或 `rotateY(60deg)`）究竟是往哪个方向翻转时，使用**左手四指握拳法**一步定乾坤：

> **结论（左手法则旋转判定法则）**：
> 1. **大拇指对准正方向**：将左手的大拇指精确对准你要旋转的那个坐标轴的**正方向**（绕 X 轴指向右，绕 Y 轴指向下，绕 Z 轴指向自己）；
> 2. **四指弯曲看流向**：此时其余四指自然向掌心弯曲握拢，**这四指弯曲的环绕方向，就是旋转正角度（正值）的方向**；
> 3. 反之，逆着四指弯曲的反方向，就是**负角度**。

```text
左手握拳判定各轴正向旋转轨迹

【绕 X 轴正向旋转 (大拇指指向右侧 +X)】：
    四指弯曲方向：从上方往屏幕里面翻，从下方往屏幕外面出！
    -> 视觉呈现：像掀开翻盖一样，上面向后倒，下面向前翻。

【绕 Y 轴正向旋转 (大拇指指向下方 +Y)】：
    四指弯曲方向：从右侧向屏幕外转，从左侧向屏幕内进！
    -> 视觉呈现：像转门一样，左边缘向后退，右边缘向前迎。

【绕 Z 轴正向旋转 (大拇指对准自己 +Z)】：
    四指弯曲方向：顺时针环绕转动！
    -> 视觉呈现：与 2D 平面旋转完全同构的顺时针自转。
```

## 3. 3D 旋转三大函数与生活物理模型

在 CSS3 中，3D 旋转通过调用特定的轴向函数来实现：

```css
/* 绕 X 轴旋转 */
transform: rotateX(角度);

/* 绕 Y 轴旋转 */
transform: rotateY(角度);

/* 绕 Z 轴旋转 */
transform: rotateZ(角度);
```

为了让大家建立极其直观的具象联想，我们通过三个经典的生活与运动场景来对应这三大函数：

### 3.1 `rotateX()` —— 单杠体操回环模型
- **物理意象**：想象 X 轴是一根水平架在半空中的**单杠**，我们的网页元素就像一名体操运动员双手紧抓单杠。
- **运动表现**：
  - 当给 `rotateX(180deg)` 正值时，元素绕着这根水平杠前后翻滚，上边缘朝屏幕深处后仰，下边缘翻出屏幕外；
  - 这种效果极其适合制作日历翻页、折叠门帘、以及翻牌器上下掀开的交互。

### 3.2 `rotateY()` —— 钢管舞 / 旋转大门模型
- **物理意象**：想象 Y 轴是一根垂直插在地面上的**钢管**，或者酒店大堂里三翼旋转门的中间立柱。
- **运动表现**：
  - 当给 `rotateY(180deg)` 正值时，元素绕着这根纵向立轴左右回转，左半边朝屏幕内部退去，右半边向视线近处转来；
  - 这种效果是制作**卡片正反面双面翻转（Card Flip）**、立体魔方左右换面的绝对基石。

### 3.3 `rotateZ()` —— 电风扇扇叶 / 飞镖自转模型
- **物理意象**：Z 轴就像一根从屏幕深处径直穿出、直抵我们鼻尖的长矛。
- **运动表现**：
  - 元素绕着 Z 轴旋转，实际上就是在与屏幕完全平行的二维平面内转圈；
  - **重要技术对等**：`transform: rotateZ(45deg);` 在几何效果上与我们之前学的 2D 变换 `transform: rotate(45deg);` **完全等价**。

## 4. 实操对比验证与“压扁感”底层痛点揭秘

### 4.1 三轴空间旋转代码验证骨架

我们编写一段简洁明了的实验骨架，为三个盒子分别赋予绕 X、Y、Z 轴旋转 180 度的悬停交互：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>CSS3 3D 旋转 rotateXYZ 实战体验</title>
  <style>
    * {
      box-sizing: border-box;
      margin: 0;
      padding: 0;
    }

    body {
      display: flex;
      justify-content: center;
      align-items: center;
      gap: 50px;
      min-height: 100vh;
      background-color: #2c3e50;
      font-family: sans-serif;
    }

    .card {
      width: 200px;
      height: 260px;
      line-height: 260px;
      text-align: center;
      font-size: 20px;
      font-weight: bold;
      color: #ffffff;
      border-radius: 12px;
      cursor: pointer;
      transition: all 0.6s ease;
      box-shadow: 0 10px 25px rgba(0, 0, 0, 0.3);
    }

    /* 1. 绕 X 轴旋转（单杠模型） */
    .rdx {
      background: linear-gradient(135deg, #ff7675, #d63031);
    }
    .rdx:hover {
      transform: rotateX(180deg);
    }

    /* 2. 绕 Y 轴旋转（钢管/旋转门模型） */
    .rdy {
      background: linear-gradient(135deg, #74b9ff, #0984e3);
    }
    .rdy:hover {
      transform: rotateY(180deg);
    }

    /* 3. 绕 Z 轴旋转（风扇自转模型） */
    .rdz {
      background: linear-gradient(135deg, #55efc4, #00b894);
    }
    .rdz:hover {
      transform: rotateZ(180deg);
    }
  </style>
</head>
<body>

  <div class="card rdx">rotateX 单杠</div>
  <div class="card rdy">rotateY 旋转门</div>
  <div class="card rdz">rotateZ 扇叶</div>

</body>
</html>
```

### 4.2 深度追问：为什么看起来像被“压扁”而不是真实 3D？

大家将上面的代码在浏览器中运行后，把鼠标放到第二个蓝色盒子 `.rdy` 上，你会发现一个非常奇怪的视觉现象：
- 盒子确实在旋转，最终也翻转成了文字倒立背向的镜像状态；
- **但是在旋转的过程中，它并没有呈现出“面向我们的一侧变大、远离我们的一侧变小”的立体空间纵深，反而视觉上像被一扇巨大的液压机在水平方向强行“挤扁、缩窄、压平”了一样！**

很多同学在这里会陷入自我怀疑：“老师，这真的是 3D 吗？怎么感觉就像做了一个简单的横向缩放 `scaleX` 呢？”

> **易错点与核心机理**：
> 这是因为当前浏览器处于**正交平行投影（Orthographic Projection）**模式下！
> 在现实物理世界中，人眼之所以能感知到三维物体的立体感，是因为人的眼球晶状体天然具备**透视规律——“近大远小”**。离眼睛近的边缘会显得粗大，离眼睛远的边缘会迅速缩小并汇聚于地平线灭点。
> 而在当前的 CSS 视图中，我们**尚未开启视距透视属性（`perspective`）**。在没有透视的环境下，所有光线平行映射在屏幕上，旋转到屏幕深处的边缘尺寸没有衰减，转到我们眼前的边缘也没有放大，大脑接收不到近大远小的深度线索，只能把它误判为一个二维图形在水平或垂直方向被粗暴挤压！

要打破这种尴尬的“扁平压缩假 3D”，必须为容器引入专门的灵魂属性——**透视 `perspective`（视距）**。关于如何给父元素添加透视、如何计算人眼与屏幕的最佳视距（如 800px ~ 1200px）以激发出震撼立体的物理翻转视效，我们将在下一讲全面展开！
