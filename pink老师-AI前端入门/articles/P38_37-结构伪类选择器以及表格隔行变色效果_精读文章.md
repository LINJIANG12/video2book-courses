# 37-结构伪类选择器以及表格隔行变色效果

在前面两节课中，我们学习了链接伪类选择器（`LVHA`）和用户行为动态伪类（`:hover` 与 `:focus`）。很多同学在写网页布局时，尤其是做导航栏或者商品列表，经常会遇到这样的尴尬场景：

比如在顶部导航栏里，五个并列的文字链接之间都需要一条细细的竖线分隔开，通常我们会给每个 `<li>` 加上一条左边框（`border-left`）。但只要代码一跑起来，你就会发现：**最左侧的第一个链接左边，也莫名其妙多出了一条光秃秃的竖线**，看着非常刺眼！再比如像小米商城、小米有品或者京东商城的商品列表，一行整整齐齐排列着 5 个商品卡片，中间的间距都是统一的，但偏偏最右边最后一个盒子的外边距（`margin-right`）必须为 0，否则这一行就会被硬生生挤爆，导致最后一个盒子被迫掉到下一行！

在过去，很多初学者只能在 HTML 结构里手动给第一个或者最后一个标签单独起一个类名，比如 `<li class="first">` 或 `<li class="last">`，然后写样式去覆盖它。但试想一下：如果这几百条数据都是通过后端程序从数据库动态循环遍历出来的，难道我们还要逼着后端程序员写一堆判断逻辑去给标签加 class 吗？

当然不用！CSS 为我们提供了一套无比优雅且智能的解决方案——**结构伪类选择器（Structural Pseudo-classes）**。今天我们就把这套能够根据“元素在 DOM 树中所处结构位置”进行精准点杀的利器彻底讲透，并带大家手把手打造一个一线门户网站级别的“表格隔行变色与高亮”综合案例！

## 1. 什么是结构伪类选择器？

### 1.1 核心定义与设计初衷

> **定义**：**结构伪类选择器是 CSS3 提供的一类专门根据元素在文档树（DOM）中的结构位置、排列次序或兄弟关系来匹配目标元素的选择器。**

简单来说，它的本质就是**按顺序抓人**：
- 挑选这一群兄弟里的“老大”（第一个孩子）；
- 挑选这群兄弟里的“老幺”（最后一个孩子）；
- 或者是指定挑选第 3 个、第 8 个孩子；
- 甚至可以按照“所有的奇数项”、“所有的偶数项”或者数学公式批量点选。

```text
结构伪类匹配机理示意图
父容器 (如 <ul>)
  ├── <li> 1 ──> :first-child  (精准命中老大)
  ├── <li> 2 ──> :nth-child(2)
  ├── <li> 3 ──> :nth-child(3)
  ├── <li> 4 ──> :nth-child(4)
  └── <li> 5 ──> :last-child   (精准命中老幺)
```

### 1.2 工业级典型应用场景

在企业级前端开发中，结构伪类的出场率极高：
1. **列表分割线消除**：多列菜单之间用 `border-left` 分割，通过 `:first-child` 将第一项的左边框清零（`border-left: 0`）；
2. **电商栅格布局边缘间距消除**：每行第 4 个或最后一个卡片，通过 `:last-child` 清除右外边距，防止盒子掉行；
3. **数据报表隔行变色（Zebra Striping）**：在密集的数据表格或排行榜中，奇数行与偶数行交替变色，大幅减轻用户的视觉疲劳。

## 2. 结构伪类三大核心语法

### 2.1 `:first-child`——选取第一个子元素

语法结构：

```css
E:first-child {
    /* 样式规则 */
}
```

- **含义**：匹配作为父元素的**第一个子元素**，且该元素的类型必须是 `E`。
- **比喻理解**：在这一群兄弟姐妹里，精准找到排在第一个位置的孩子。

实战示例：为无序列表中的第一项赋予粉色高亮：

```css
ul li:first-child {
    color: pink;
}
```

> **易错点严正警告**：
> **选择器名称与冒号之间严禁出现空格！**
> 必须紧贴着写成 `li:first-child`。如果你手滑写成 `li :first-child`（中间带空格），CSS 解析器就会把它当成**后代选择器**，含义瞬间变成了“选择 `li` 内部的所有第一个子元素”，导致你的样式完全无法命中目标 `li`！

### 2.2 `:last-child`——选取最后一个子元素

语法结构：

```css
E:last-child {
    /* 样式规则 */
}
```

- **含义**：匹配作为父元素的**最后一个子元素**，且类型为 `E`。
- **生动场景**：在学校里老师最关注哪两个学生？往往是考了第一名的学生（`:first-child`），以及考了倒数第一名的学生（`:last-child`）。这两个位置在页面布局中往往承担着边界处理的特殊任务。

### 2.3 `:nth-child(n)`——指定序号精确匹配

如果我们要选取的既不是第一个，也不是最后一个，而是中间指定的某一个（比如第 3 个或第 8 个），就必须使用更加强大的通用结构选择器——**`:nth-child(n)`**。

语法结构：

```css
E:nth-child(参数) {
    /* 样式规则 */
}
```

> **关键规则**：
> - `nth-child` 的小括号内传入正整数时，**索引计数从 1 开始**（与某些编程语言从 0 开始不同，在 CSS 选择器中第 1 个就是 1）；
> - 想要选取第 3 个元素，就写 `li:nth-child(3)`；想要选取第 8 个元素，就写 `li:nth-child(8)`。

## 3. `:nth-child` 进阶运算全解：关键字与公式匹配

如果 `:nth-child` 仅仅只能传固定数字，那它还算不上强大。它的真正威力在于**小括号内支持传入关键字和自增公式**，实现惊人的模式匹配能力！

### 3.1 关键字匹配：奇数 `odd` 与偶数 `even`

在渲染斑马条纹列表或隔行交替效果时，我们可以直接传入两个预设英文单词：

1. **`odd`（奇数）**：匹配第 1、3、5、7、9……项；
2. **`even`（偶数）**：匹配第 2、4、6、8、10……项。

实操代码演示：

```css
/* 选中第二组列表中所有的奇数项，文字标红 */
.ul2 li:nth-child(odd) {
    color: red;
}

/* 选中第二组列表中所有的偶数项，文字标蓝 */
.ul2 li:nth-child(even) {
    color: blue;
}
```

### 3.2 公式匹配：`n` 的自增代入机理

除了英文单词，小括号内还允许书写代数表达式，如 `3n`、`2n`、`n+3`、`-n+3`。

> **核心数学机理**：
> 在 `:nth-child(公式)` 中，字母 **`n` 永远是一个从 0 开始、以步长为 1 逐次递增的非负整数序列**：
> $$n = 0, 1, 2, 3, 4, 5, 6, \dots$$
> 浏览器会将 $n=0, 1, 2, \dots$ 依次代入公式计算结果，**只有计算结果为大于等于 1 的正整数时，对应的第几个 DOM 元素才会被命中**（计算结果为 0 或负数时直接被浏览器忽略）。

我们通过小学算术列表推导三种最常见的实战公式：

#### 公式一：倍数匹配——`3n`（3 的倍数）

- 当 $n = 0$ 时：$3 \times 0 = 0$（无第 0 个元素，忽略）；
- 当 $n = 1$ 时：$3 \times 1 = 3$（命中第 3 个元素）；
- 当 $n = 2$ 时：$3 \times 2 = 6$（命中第 6 个元素）；
- 当 $n = 3$ 时：$3 \times 3 = 9$（命中第 9 个元素）；
- 依此类推……

> **结论**：`li:nth-child(3n)` 能够精准选中第 3、6、9、12 项，即所有 3 的倍数！同理，`5n` 就是选中第 5、10、15 项；而 `2n` 的计算结果为 2、4、6、8，它与关键字 `even` 完全等价！

#### 公式二：范围向后选取——`n + 3`（从第 3 个开始往后全选）

- 当 $n = 0$ 时：$0 + 3 = 3$（命中第 3 个）；
- 当 $n = 1$ 时：$1 + 3 = 4$（命中第 4 个）；
- 当 $n = 2$ 时：$2 + 3 = 5$（命中第 5 个）；
- 依此类推……

> **结论**：`li:nth-child(n+3)` 的含义是**选取从第 3 个元素起（包含第 3 个）及其后面的所有元素**。如果写 `n+2`，那就是从第 2 个开始往后全包揽。

#### 公式三：范围向前截取——`-n + 3`（选取前 3 个元素）

这个公式非常巧妙，带有负号，很多初学者容易犯怵，我们同样代入推导：

- 当 $n = 0$ 时：$-0 + 3 = 3$（命中第 3 个）；
- 当 $n = 1$ 时：$-1 + 3 = 2$（命中第 2 个）；
- 当 $n = 2$ 时：$-2 + 3 = 1$（命中第 1 个）；
- 当 $n = 3$ 时：$-3 + 3 = 0$（计算结果为 0，停止匹配）；
- 当 $n = 4$ 时：$-4 + 3 = -1$（负数，忽略）。

> **结论**：计算结果正好是 3、2、1，**`-n + 3` 的本质就是选取“前 3 个元素”**！如果想选取列表前 2 个，直接写 `-n + 2` 即可。

### 3.3 公式速查对照表

| 表达式写法 | 计算序列（$n=0,1,2,3\dots$） | 命中元素位置 | 业务常见场景 |
| :--- | :--- | :--- | :--- |
| `2n` 或 `even` | $0, 2, 4, 6, 8\dots$ | 第 2, 4, 6, 8 项（偶数项） | 斑马条纹交替底色 |
| `2n+1` 或 `odd` | $1, 3, 5, 7, 9\dots$ | 第 1, 3, 5, 7 项（奇数项） | 奇数行着色 |
| `3n` | $0, 3, 6, 9\dots$ | 第 3, 6, 9 项（3 的倍数） | 三列网格末尾项清 margin |
| `n + 4` | $4, 5, 6, 7\dots$ | 第 4 个及之后的所有元素 | 排除前三名（前三名特殊发光，其余普通） |
| `-n + 3` | $3, 2, 1, 0, -1\dots$ | 前 3 个元素（第 1, 2, 3 项） | 奖牌榜前三甲（金银铜牌冠亚季军高亮） |

## 4. 综合实战：仿网易 NBA 榜单制作表格隔行变色

有了结构伪类和公式匹配的硬实力，我们来仿照真实门户网站（如网易体育 NBA 排行榜）手把手实现一个专业的数据表格。

### 4.1 核心技术铺垫：`border-collapse` 合并相邻边框

在制作漂亮表格之前，我们必须扫清一个关于表格边框的巨大认知障碍。

当我们给 `<table>` 标签和内部的 `<td>` 单元格同时设置边框时：
```css
table, td {
    border: 1px solid red;
}
```
运行后你会发现：**表格线不是细细的单线，而是每个单元格之间都留有空隙，边框重叠在一起变成了双粗线**，显得极度粗糙。

```text
表格边框合并原理示意
[未加 border-collapse: separate (默认)]
┌───┐ ┌───┐  <── 表格与单元格、单元格与单元格之间
└───┘ └───┘      边框独立，形成双重缝隙线（1px + 1px = 2px 且有间隙）

[添加 border-collapse: collapse]
┌───┬───┐  <── 边框相邻贴合，重叠合并为单条 1px 细线
└───┴───┘      实现 1 + 1 = 1 的纯净线条
```

> **定义**：**`border-collapse: collapse;` 专门用于合并表格中相邻的边框**。这句声明是现代网页中所有高颜值细线表格的标准标配，必须牢记！

### 4.2 完整实战代码落地

#### HTML 结构：

```html

            <td>排名</td>
            <td>球队</td>

        </tr>
        <tr>
            <td>1</td>
            <td>凯尔特人</td>
            <td>50</td>
        </tr>
        <tr>
            <td>2</td>
            <td>雷霆</td>
            <td>48</td>
        </tr>
        <tr>
            <td>3</td>
            <td>掘金</td>
            <td>47</td>
        </tr>
        <tr>
            <td>4</td>
            <td>快船</td>
            <td>45</td>
        </tr>

            <td>5</td>
```

#### CSS 样式：

```css
/* 1. 基础重置与表格整体框架构建 */
* {
    margin: 0;
    padding: 0;
    box-sizing: border-box;
}

.data {
    /* 核心属性：合并相邻单元格边框 */
    border-collapse: collapse;
    /* 整体外框 */
    border: 1px solid #e1e1e1;
    width: 400px;
    margin: 50px auto; /* 水平居中 */
    text-align: center; /* 单元格文字水平居中 */
    font-size: 14px;
}

/* 单元格统一加边框，行高拉开呼吸感 */
.data td {
    border: 1px solid #e1e1e1;
}

.data tr {
    height: 35px; /* 设置每行高度 */
}

/* 2. 隔行变色：奇数行赋予极浅灰条纹背景 */
.data tr:nth-child(odd) {
    background-color: #f9f9f9;
}

/* 3. 第一行表头特殊化定制（写在 nth-child 之后利用层叠覆盖） */
.data tr:first-child {
    background-color: #8fa4c5; /* 蓝灰主题色 */
    color: #fff;               /* 表头纯白文字 */
    font-weight: bold;
}

/* 4. 用户交互悬停反馈：鼠标划过某一行，该行背景微亮高亮 */
.data tr:hover {
    background-color: #f1f1f1;
}
```

### 4.3 核心细节与踩坑排查

1. **层叠顺序的玄机**：
   在上面的样式表中，我们先写了 `.data tr:nth-child(odd)`，随后才写了 `.data tr:first-child`。
   > **避坑思考**：第一行（表头）的索引是 1，1 也是奇数！如果把 `first-child` 写在上面，而把 `nth-child(odd)` 写在下面，根据 CSS **代码后发制人（后写的覆盖先写的）**的层叠原则，奇数行样式就会把表头的蓝灰色背景粗暴覆盖掉！因此在尚未学习 CSS 权重计算规则前，**务必将具体的 `first-child` 放在大范围的 `nth-child(odd)` 后面书写**。
2. **高效调试快捷键**：
   在浏览器中调试这类复杂样式时，不要每次都费劲右键再点检查，直接按下 **`Ctrl + Shift + C`**（Mac 为 `Cmd + Opt + C`），鼠标光标会立刻变成拾取吸管，滑到哪行就直接精准点选审查哪个 DOM 节点，效率倍增！

通过这套结构伪类的精准组合，我们无需修改任何一行 HTML 标签，仅凭 CSS 就打造出了兼具现代审美与丝滑交互的一流表格！
