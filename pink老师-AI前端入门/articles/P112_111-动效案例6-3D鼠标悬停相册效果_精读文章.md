# 111-CSS3 实战：3D 悬停风琴相册、倒影与 :not() 兄弟选择器

在很多一线科技大厂（如 vivo、Apple）的官网展示中，经常能看到一种充满空间纵深感的高级 3D 相册：

默认状态下，多张精美卡片横向整齐排列，下方伴随着逼真的镜面倒影；当鼠标滑入某一张卡片时，该卡片立刻放大并升至最顶层，而它左侧的所有卡片统一向右侧偏转倾斜，右侧的所有卡片则以镜像对称的姿态向左侧偏转倾斜！整个相册如同两面对称折叠的百叶风琴，紧紧簇拥着被选中的主角卡片。

本讲我们将手把手还原这套企业级 **3D 悬停风琴相册**，并系统掌握三大进阶利器：`-webkit-box-reflect` 镜面倒影、`:not()` 否定选择器、以及 `~` 通用兄弟选择器。

---

## 1. 动效解构：向心对称 3D 空间的数学逻辑

为什么这个相册能产生如此强烈的立体视觉？我们将其视觉形态进行空间拆解：

```text
3D 风琴相册悬停姿态剖析
鼠标悬停在 Item 3 (中间主角) 上：
+──────────+   +──────────+   +──────────────+   +──────────+   +──────────+
|  Item 1  |   |  Item 2  |   |    Item 3    |   |  Item 4  |   |  Item 5  |
| (缩小0.9)|   | (缩小0.9)|   |   (放大1.2)   |   | (缩小0.9)|   | (缩小0.9)|
| rotateY: |   | rotateY: |   |  z-index:999 |   | rotateY: |   | rotateY: |
|  +45deg  |   |  +45deg  |   | 保持正向无偏转 |   |  -45deg  |   |  -45deg  |
+──────────+   +──────────+   +──────────────+   +──────────+   +──────────+
      ▲              ▲                                 ▲              ▲
      └─ 主角左侧兄弟：顺时针偏转 ─┘               └─ 主角右侧兄弟：逆时针偏转 ─┘
```

### 核心三大状态：
1. **当前选中者（主角）**：尺寸放大（`scale(1.2)`），层级拔高（`z-index: 999`），压住周围卡片，面向用户正立；
2. **主角左侧卡片**：尺寸缩小（`scale(0.9)`），绕 Y 轴顺时针旋转（`rotateY(45deg)`）；
3. **主角右侧卡片**：尺寸缩小（`scale(0.9)`），绕 Y 轴逆时针旋转（`rotateY(-45deg)`），形成完美的镜像内收夹角！

## 2. 核心技术点与新选择器实战

### 2.1 镜面倒影利器：`-webkit-box-reflect`
在 CSS 中实现倒影无需复制 DOM 结构，WebKit 引擎提供了专门的原生属性：
```css
-webkit-box-reflect: below 1px linear-gradient(transparent, rgba(0, 0, 0, 0.8));
```
#### 参数拆解：
- **方向**：`below`（在元素下方生成倒影；可选 `above`, `left`, `right`）；
- **偏移距离**：`1px`（原图与倒影之间的垂直缝隙）；
- **遮罩渐变（Mask）**：利用线性渐变控制倒影的透明度衰减。从 `transparent` 过渡到半透明黑色，呈现出由实到虚、自然消融在底板里的倒影质感。

---

### 2.2 否定选择器：`:not()`
我们希望鼠标悬停在父容器上时，**排除当前被悬停的那张卡片**，让其余所有兄弟卡片统统缩小并偏转。

此时就要祭出 **`:not()` 否定选择器**：
```css
/* 语法剖析 */
.box:hover .item:not(:hover) {
  transform: scale(0.9) rotateY(45deg);
}
```
- `.box:hover`：鼠标进入了相册大舞台；
- `.item:not(:hover)`：选中所有**没有被鼠标直接悬停**的卡片！
- 一行代码，精准剥离出“非主角”的所有次要卡片。

---

### 2.3 通用兄弟选择器：`~` 打造左右镜像偏转
有了 `:not(:hover)`，所有非主角卡片默认都偏转了 `+45deg`（适合左侧卡片）。但主角右侧的卡片如果也偏转 `+45deg`，整体就会歪向同一边，失去对称美感。

如何只把**主角右侧的所有卡片**挑选出来并反向偏转为 `-45deg`？

使用 **通用兄弟选择器 `~`**：
```css
/* 选中正被 hover 的卡片之后的所有兄弟卡片 */
.box .item:hover ~ .item {
  transform: scale(0.9) rotateY(-45deg);
}
```
- 在 DOM 树中，排在当前元素后面的同级兄弟节点，全都会被 `~` 命中！
- 于是，右侧兄弟节点的旋转角度被顺理成章地覆盖改写为 `-45deg`，对称向心风琴效果瞬间达成！

### 3.2 CSS 核心样式编码

```css
* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}

body {
  height: 100vh;
  display: flex;
  justify-content: center;
  align-items: center;
  background-color: #15151e; /* 深色背景烘托倒影 */
}

/* 1. 舞台大盒子：开启 3D 透视 */
.box {
  display: flex;
  justify-content: center;
  align-items: center;
  /* 核心透视：视距500px，近大远小 */
  perspective: 500px;
  /* 开启 3D 空间保留 */
  transform-style: preserve-3d;
}

/* 2. 单张卡片基础样式与倒影配置 */
.item {
  position: relative;
  width: 120px;
  height: 180px;
  margin: 0 10px;
  border-radius: 8px;
  cursor: pointer;
  /* 核心：优雅的底面倒影 */
  -webkit-box-reflect: below 2px linear-gradient(transparent 60%, rgba(0, 0, 0, 0.7));
  /* 丝滑过渡属性 */
  transition: all 0.5s cubic-bezier(0.25, 1, 0.5, 1);
}

.item img {
  width: 100%;
  height: 100%;
  object-fit: cover;
  border-radius: 8px;
}

/* =======================================================
   3. 核心 3D 交互逻辑组合拳
   ======================================================= */

/* 步骤 A：鼠标进入相册容器时，适度聚拢间距营造拥趸感 */
.box:hover .item {
  margin: 0 -15px; /* 负外边距让卡片彼此叠交错落 */
}

/* 步骤 B：使用 :not(:hover) 排除主角，让其余卡片默认缩小并顺时针偏转（左侧卡片姿态） */
.box:hover .item:not(:hover) {
  transform: scale(0.9) rotateY(45deg);
}

/* 步骤 C：使用 ~ 兄弟选择器，精准命中主角右侧的所有卡片，将其改写为逆时针偏转（右侧对称姿态） */
.box .item:hover ~ .item {
  transform: scale(0.9) rotateY(-45deg);
}

/* 步骤 D：主角卡片（正被 hover 的卡片）放大并置顶 */
.box .item:hover {
  transform: scale(1.25) rotateY(0deg); /* 放大且正向面对用户 */
  z-index: 999; /* 保证居于所有卡片最上方 */
}
```

## 4. 关键技巧与学习总结

1. **`perspective` 必须加在父级**：
   - 很多同学把 `perspective: 500px` 误写在 `.item` 子盒子上，导致每个子盒子自成一个独立视口，旋转时无法产生同一空间下的透视交错感；透视必须统一施加在包含整个相册的父容器 `.box` 上。
2. **负外边距 `margin: 0 -15px` 的空间收拢感**：
   - 初始排列时卡片留有间距；当鼠标悬停进入时，通过负外边距让卡片适度重叠，配合 `z-index` 的层层压盖，使“众星拱月”的戏剧化效果更加强烈。
3. **`:not()` 与 `~` 的组合威力**：
   - 本案例是纯 CSS 选择器逻辑编排的巅峰范例。无需任何 JS 计算卡片索引，仅仅通过 `:not(:hover)` 与 `hover ~` 的自然状态覆盖，便实现了精准的“左/中/右”三态分区渲染。
