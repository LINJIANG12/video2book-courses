# 底部固定切换模块的结构与样式

吸顶解决的是往下翻找不到入口，吸底解决的是拇指够不着操作。你们看咱们优医问诊这个首页，最底下那一排首页、问诊、我的，拇指一抬就能够到，这一讲我就带你们把这个底部切换模块做出来，全程固定定位（Fixed Position），滑到哪它都在。

## 1. 底部导航的结构划分

底部导航本质是一个固定条包着三个等分选项，每个选项是图标加文字上下叠放：

```text
+----------------------------------+
| .tabbar (fixed, bottom:0)        |
|  .item    .item    .item         |
| [图标]    [图标]    [图标]        |
|  首页     问诊      我的          |
+----------------------------------+
```

读图说明：外层通栏固定，内层三个选项均分宽度，每个选项内部图标在上、文字在下居中。

```html
<div class="tabbar">
  <a class="item active" href="#">
    <i class="iconfont icon-home"></i>
    <span>首页</span>
  </a>
  <a class="item" href="#">
    <i class="iconfont icon-consult"></i>
    <span>问诊</span>
  </a>
  <a class="item" href="#">
    <i class="iconfont icon-mine"></i>
    <span>我的</span>
  </a>
</div>
```

图标我用字体图标（Iconfont），文字用 `span` 包起来，两个都是行内元素，正好上下排列。选中态给 `active` 类，后面换色就靠它，你们先把钩子留好。

## 2. 固定定位与均分布局

```css
.tabbar {
  position: fixed;
  left: 0;
  bottom: 0;
  width: 100%;
  display: flex;
  background-color: #fff;
  border-top: 1px solid #eee;
  z-index: 20;
}
.tabbar .item {
  flex: 1;
  display: flex;
  flex-direction: column;
  align-items: center;
  padding: 6px 0 8px;
  color: #999;
  font-size: 11px;
}
.tabbar .item i {
  font-size: 22px;
  line-height: 1;
}
.tabbar .item.active {
  color: #16c2a3;
}
```

几点你们跟着我捋。第一，`position: fixed` 加 `bottom: 0` 是吸底的标准写法，再配 `left: 0` 加 `width: 100%` 让它通栏，否则固定盒子宽度会塌成内容宽。第二，`display: flex` 配三个 `flex: 1`，三个选项自动等分，不管以后加到四个五个都不用改宽度。第三，每个 `.item` 自己又是一个纵向弹性盒，`flex-direction: column` 让图标压着文字，`align-items: center` 让它们居中。

> **提示**：固定定位会完全脱离文档流，下面的医生卡片最后一张会被导航条压住一部分。标准解法是给 `body` 或者内容区加 `padding-bottom`，数值跟导航条高度一致，比如导航条 56 像素，就加 `padding-bottom: 56px`。

## 3. 选中态与安全距离

选中态不要整花活，就改颜色。默认灰 `#999`，选中绿 `#16c2a3`，图标和文字一起变，用户一眼就知道自己在哪。你们要是给选中态又加粗又加背景，底部那点高度根本撑不住，反而显乱。

还有一个细节，碰到全面屏手机，底部有个小横条手势区，导航会被系统条顶到。我的习惯是多留一点下内边距，或者直接用环境变量兜底：

```css
.tabbar {
  padding-bottom: constant(safe-area-inset-bottom);
  padding-bottom: env(safe-area-inset-bottom);
}
```

`safe-area-inset-bottom` 是系统告诉你的安全距离（Safe Area），有刘海屏就有值，没刘海就是 0，写上不亏。你们现在先记住有这么个东西，真机调试看到被压住再回来加也来得及。

| 对比项 | 顶部粘性切换 | 底部固定切换 |
| :--- | :--- | :--- |
| 定位方式 | `sticky` 加 `top: 0` | `fixed` 加 `bottom: 0` |
| 是否占位 | 占位 | 脱标，需补 `padding-bottom` |
| 层级建议 | `z-index: 10` | `z-index: 20`，压住内容 |

> **结论**：到这里首页是上面吸一个、下面钉一个，中间内容随便滑，拇指操作一刻不停。你们把这个底栏封装好，后面登录页、我的页直接复用。
