# 01-Trae AI 编辑器介绍与安装配置指南

俗话说“工欲善其事，必先利其器”。在正式书写网页代码之前，我们必须先准备好最核心的两大开发工具：
1. **代码编辑器**：我们用来编写、敲打代码的生产力环境；
2. **浏览器**：用来解释和展示网页渲染效果的运行环境。

过去很多年，前端开发的主流编辑器经历了从 Dreamweaver、Sublime Text、HBuilder 到 VS Code 的变迁。而进入 2025 年，AI 编辑器已经彻底重构了开发体验。本讲我们将深入了解为什么选择字节跳动推出的国产 AI 编辑器 **Trae**，剖析其版本差异，并完成零基础的完整安装与初始化配置。

---

## 1. 传统编辑器与现代 AI 编辑器的演进

### 1.1 常用编辑器全景对比

在日常开发中，前端开发者接触到的编辑器主要可以分为两代：

| 类型 | 代表工具 | 核心特点与局限 | 适用场景 |
| :--- | :--- | :--- | :--- |
| **传统代码编辑器** | **VS Code**、WebStorm、Sublime Text、HBuilderX | 功能成熟，插件生态极其丰富；但原生不具备深度集成的 AI Agent 编码能力，多需额外配置第三方补全插件 | 传统工程维护、成熟项目开发 |
| **现代 AI 深度集成编辑器** | **Trae**、Cursor、Windsurf | 大模型深度融入 IDE 底层，具备上下文感知、语音输入、交互式代码修改与 Agent 级自动化排错 | 2025 现代敏捷开发、AI 辅助全栈编程 |

### 1.2 为什么本套课程选择 Trae？

很多同学听说过国外大火的 **Cursor**，但对于国内绝大多数零基础学习者来说，Cursor 存在两大现实门槛：
1. **网络门槛**：访问国外模型需要配置特殊的网络环境；
2. **费用门槛**：Cursor Pro 每月订阅费约为 20~30 美元（折合人民币 150~200 余元），长期使用成本较高。

正所谓“不是 Cursor 用不起，而是 Trae 更有性价比”：
- **国产免费且流畅**：由字节跳动推出，国内服务器直连，响应极速；
- **原生全中文界面**：不需要繁琐地安装汉化语言包，所有菜单和配置一目了然；
- **深度集成顶尖大模型**：不仅支持常规的代码自动补全，更支持语音输入、图片直接生成代码、智能纠错以及基于 Agent 的自动化文件创建。

## 2. Trae 国内版与国际版核心特性解析

Trae 针对不同网络环境和用户群体提供了两个版本，两者的核心功能架构一致，但在模型底座与账号体系上有所不同：

```text
Trae 编辑器双版本生态
├── Trae 国内版 (Trae CN)
│   ├── 模型底座：集成国产主流大模型（字节豆包 Doubao、DeepSeek、Kimi 等）
│   ├── 账号体系：国内手机号 + 验证码一键登录
│   └── 网络要求：国内网络直连，无需任何科学上网配置
└── Trae 国际版 (Trae Global)
    ├── 模型底座：集成国外顶尖大模型（Claude 3.5 Sonnet、GPT-4o 等）
    ├── 账号体系：需绑定 Google 账号或 GitHub 账号
    └── 高阶能力：支持深度 Agent 编排与 MCP (Model Context Protocol) 扩展协议
```

> **学习选型建议**：
> 初学阶段我们**强烈推荐使用国内版 Trae**。它完全满足 HTML5/CSS3 的全套代码辅助开发、语法纠错和实时预览需求，零门槛开箱即用；后续有进阶海外模型或 MCP 协议需求的同学，也可以在同一台电脑上并存安装国际版。

## 3. Trae 详细下载与安装实战

### 3.1 官网获取安装包
1. 打开浏览器访问 Trae 官方网站（`https://www.trae.cn`）；
2. 网站会根据当前操作系统自动识别并高亮适配版本（支持 Windows 与 macOS）；
3. 点击立即下载，安装包体积仅约 170MB 左右，下载极其快捷。

### 3.2 安装过程中的关键避坑点

下载完成后双击运行安装程序，安装向导非常直观，但有几点必须注意：

1. **许可协议**：勾选“我同意此协议”，点击“下一步”；
2. **安装路径选择（重点避坑）**：
   - **强烈建议不要直接安装在 C 盘（系统盘）**！随着开发深入、缓存累积和依赖增多，C 盘空间不足会导致整台电脑运行卡顿甚至系统崩溃；
   - 点击“浏览”，将路径修改为非系统盘，例如 `D:\Trae` 或 `E:\Trae`；
3. **快捷方式设置**：勾选“创建桌面快捷方式”，其余选项保持默认，连续点击“下一步”；
4. **执行安装**：点击“安装”，等待进度条跑完后，勾选“启动 Trae”，点击“完成”。

## 4. Trae 界面结构与 AI 辅助能力初探

启动 Trae 后，整体界面布局清晰，主要分为四大核心交互区域：

```text
+-------------------------------------------------------------------------+
|  [菜单栏] 文件  编辑  选择  查看  转到  运行  终端  帮助                |
+---+-----------------------------+-----------------------------+---------+
|   |                             |                             |         |
| 侧 |                             |                             |  AI     |
| 边 |      项目资源管理器         |        代码主编辑区         |  辅助   |
| 栏 |      (文件/文件夹目录树)    |      (书写 HTML/CSS 代码)    |  对话   |
| 图 |                             |                             |  侧栏   |
| 标 |                             |                             | (Chat)  |
|   |                             |                             |         |
+---+-----------------------------+-----------------------------+---------+
|  [底部状态栏] UTF-8  Spaces: 2  HTML  AI连通状态                       |
+-------------------------------------------------------------------------+
```

### 4.1 四大核心区域说明
- **左侧活动栏**：包含文件管理器（资源管理）、全局搜索、Git 源代码管理、运行调试以及插件市场；
- **中间主编辑区**：我们日常手写或查看 HTML、CSS、JS 代码的核心工作台；
- **右侧 AI 助手面板**：
  - **首次使用登录**：点击右侧面板的“登录”，输入手机号与短信验证码完成身份验证（一次登录长期有效）；
  - **多模态输入支持**：支持键盘打字提问、直接点击麦克风进行**语音输入**，以及拖拽设计稿截图进行图生代码；
- **底部状态栏**：显示编码格式（必须保证为 UTF-8）、缩进空格数及当前语言模式。

### 4.2 AI 智能辅助编码体验
登录成功后，我们可以直接在右侧对话框中输入自然语言指令。例如：
> “帮我新建一个 HTML 文件，里面写上一段内容：pink 老师带我们学习前端，并为文字设置加粗效果。”

Trae 会迅速在上下文中分析需求，自动生成标准的 HTML 结构，并给出单键“应用/接受（Accept）”按钮，一键将生成的代码落入本地工程中。
