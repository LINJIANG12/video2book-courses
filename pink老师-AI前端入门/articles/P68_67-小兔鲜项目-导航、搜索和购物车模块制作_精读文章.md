# 电商头部核心交互区：小兔鲜导航、搜索框与购物车模块精构

在上一讲中，我们完成了小兔鲜电商门户头部（Header）的宏观骨架搭建，并用大厂最高规范完成了 SEO 优化的 Logo 模块制作。

这一讲我们继续向右推进，攻克头部最核心的三个交互子系统——**主导航栏（Nav）、搜索框（Search）与购物车（Cart）**。

很多同学在写导航和搜索框时，经常遇到一堆头疼的小毛病：
- 为什么鼠标滑过导航文字时，自带的下划线死死贴着文字底边，显得又紧又丑？
- 为什么小列表项用 `margin-right` 隔开后，最后一个元素总会把右侧盒子顶偏？
- 为什么搜索框里的“搜一搜”用 `color` 怎么改都改不掉颜色？
- 为什么导航和搜索框放在一起，上下怎么看都不在一根水平基准线上？

今天我就带大家用一线商业项目的规范，把这三大模块逐一拆解、推导并优雅落盘。

## 2. 主导航栏（.nav）模块制作

### 2.1 HTML 结构骨架

导航栏属于网站主导航，语义化采用 `<div class="nav">` 包裹标准的无序列表 `<ul>` 与 `<li>`。每一个分类项都必须是一个独立的超链接 `<a>`：

```html
<!-- 主导航模块 -->
<div class="nav">
  <ul>
    <li><a href="#">首页</a></li>
    <li><a href="#">生鲜</a></li>
    <li><a href="#">美食</a></li>
    <li><a href="#">餐厨</a></li>
    <li><a href="#">电器</a></li>
    <li><a href="#">居家</a></li>
    <li><a href="#">洗护</a></li>
    <li><a href="#">孕婴</a></li>
    <li><a href="#">服装</a></li>
  </ul>
</div>
```

> **提示**：在开发初期，我们把 `href` 统一赋为占位符 `#`。等未来各个分类路由与专题页面建立后，再进行具体的路径挂载。

### 2.2 列表横向排开与 Flex Gap 属性选型

小 `<li>` 默认是块级元素，垂直堆叠排列。我们需要让它们在同一行水平铺开。

过去传统的做法是给 `<li>` 添加浮动 `float: left` 或者给每个 `<li>` 加上 `margin-right: 48px`。但这会带来一个非常恶心的边际副作用：**最后一个 `<li>` 也会带上 48px 的右外边距**，导致整个列表右侧无故多出一截空白，破坏整体的对称与居中。

在现代 CSS 中，我们直接给弹性容器赋予 `gap` 属性：

```css
/* 让导航列表横向排开，且项与项之间产生间距 */
.nav ul {
  display: flex;
  gap: 48px;
}
```

```text
传统的 margin-right 与现代 gap 对比
┌────────────────────────────────────────────────────────────┐
│ margin-right 方式：                                        │
│ [li 1]--48px--[li 2]--48px--[li 3]--48px-- (末尾产生脏边距)│
├────────────────────────────────────────────────────────────┤
│ flex gap 方式：                                            │
│ [li 1]--48px--[li 2]--48px--[li 3] (末尾干净利落，无溢出)  │
└────────────────────────────────────────────────────────────┘
```
*图 2：gap 属性避免了尾部外边距冗余问题*

> **结论**：`gap` 只在子元素之间注入间隙，绝对不会在首尾两侧产生多余的外边距，既优雅又不需要写 `:last-child { margin-right: 0; }` 去补刀修补。

### 2.3 扩大超链接点击热区与块级转换

默认情况下，超链接 `<a>` 是行内元素（`inline`），它的宽高完全被那几个汉字的字形包围盒卡死。用户如果想点击“生鲜”，鼠标必须极其精确地戳到那两个汉字上，稍微偏上一点或偏下一点都点不中。

在商业级前端体验设计中，我们必须**扩大点击热区（Hit Area）**：

```css
.nav li a {
  display: block;
  height: 40px;
  line-height: 40px;
  font-size: 16px;
  color: #333;
}
```

- 将 `<a>` 转换为块级元素（`display: block;`），使其拥有完整的尺寸盒；
- 赋予其与设计稿一致的 `40px` 高度，并配合 `line-height: 40px` 实现文字垂直居中；
- 此时，用户在 40px 的纵向整条轨道内滑动或点击，都能稳定激活链接，操作容错率大幅提升。

### 2.4 下边框伪装下划线的交互推导

在小兔鲜的设计原型中，当鼠标悬停在某个分类项上时，文字会变成小兔鲜的主题绿色（`#27ba9b`），并且文字下方会出现一条精致的绿色横线。

很多初学者第一反应是写这行代码：

```css
/* 错误尝试：原生文本装饰线下划线 */
.nav li a:hover {
  color: #27ba9b;
  text-decoration: underline;
}
```

如果你在浏览器中实测，就会发现效果非常糟糕：`text-decoration: underline` 是直接贴着字符基线（Baseline）绘制的，下划线死死咬在汉字的脚后跟上，汉字底下如果有“撇、捺、竖弯钩”，横线甚至会和笔画粘在一起，极其逼仄杂乱。

**大厂的标准解法：用 `border-bottom` 伪装悬停指示线**！

```css
/* 工业级交互：下边框下划线 */
.nav li a:hover {
  color: #27ba9b;
  border-bottom: 2px solid #27ba9b;
}
```

```text
text-decoration 与 border-bottom 悬停视觉对比
┌───────────────────────────┐     ┌───────────────────────────┐
│ text-decoration: underline│     │ border-bottom: 2px solid  │
│                           │     │                           │
│          首  页           │     │          首  页           │
│         ────────          │     │                           │
│   (横线死贴文字，极压抑)  │     │ ───────────────────────── │
│                           │     │  (落在 40px 底边，透气舒适)│
└───────────────────────────┘     └───────────────────────────┘
```
*图 3：利用盒模型底部边框实现高质感悬停指示条*

因为我们的 `<a>` 标签设置了 `height: 40px;`，而文字垂直居中在中间，因此 `border-bottom` 稳稳地落在了 40px 盒子的最底部边缘。这在文字与横线之间创造出了充足而舒适的呼吸感，高级感瞬间拉满。

## 3. 搜索模块（.search）制作

### 3.1 模块结构与基本尺寸

紧随导航栏右侧的是搜索区域。我们使用 `<div class="search">` 包裹一个文本输入框 `<input>`：

```html
<!-- 搜索模块 -->
<div class="search">
  <input type="text" placeholder="搜一搜">
</div>
```

根据测量，搜索输入框的宽度为 `170px`，高度同样为 `40px`。为了与整体极简轻快的界面风格契合，我们清空其默认的三维立体边框，仅保留底部一条浅灰色的标尺线：

```css
.search input {
  width: 170px;
  height: 40px;
  /* 清除原生全包围边框，只保留底部细线 */
  border: none;
  border-bottom: 2px solid #e4e4e4;
  font-size: 16px;
}
```

### 3.2 图标预留内边距与占位符样式定制

小兔鲜的搜索框内部，左侧应该有一个放大的搜索镜图标，右侧跟着提示文案“搜一搜”。

放大镜图标宽度约为 20px，图标与文字之间还有大约 8px 的间隙，加在一起就是 `28px`。如果在 input 里直接打字，文字会直接顶死在最左侧边缘。

因此，我们给输入框注入左内边距：

```css
.search input {
  padding-left: 28px;
}
```

> **易错点**：为什么这里放大镜图标先不放上去？
> 因为要在输入框内部靠左固定一个图标，最标准且唯一的解法是使用**绝对定位（`position: absolute`）**把它悬浮压在 input 容器之上。在当前的知识体系中，我们还没有系统学习定位技术，所以我们先用 `padding-left: 28px;` 把这个位置严格留出来。等学完绝对定位，我们立刻回来把图标精准空降进去。

另一个核心技术点是修改提示文字“搜一搜”的外观。

很多同学直接对 input 设置 `color: #ccc;`，结果发现不仅 placeholder 变了，用户输入真实内容时文字也变成了浅灰色，导致看不清。

**正确解法：使用专用的伪元素选择器 `::placeholder`**：

```css
/* 专门定制 input 占位符的颜色与大小 */
.search input::placeholder {
  font-size: 16px;
  color: #ccc;
}
```

`::placeholder` 属于双冒号伪元素，它精准匹配输入框内未输入内容时呈现的虚拟文本。当用户敲入文字时，真实文本将继续应用 input 自身设定的主文字颜色，互不干扰。

## 4. 购物车模块（.cart）制作与头部最终渲染

### 4.1 结构与字体图标引入

头部最右侧是购物车模块。它由一个购物车图标以及一个悬浮在右上角的商品数量气泡角标组成：

```html
<!-- 购物车模块 -->
<div class="cart">
  <i class="iconfont icon-cart-full"></i>
</div>
```

在前期准备中，我们已经引入了阿里巴巴矢量图标库 `iconfont`。这里直接通过类名 `icon-cart-full`（或小兔鲜资源包中的 `icon-cart4`）调出购物车图标。

### 4.2 尺寸调试与边距微调

字体图标在本质上就是矢量字体，因此直接通过 `font-size` 即可缩放其大小：

```css
.cart {
  /* 与最右侧边缘留出一定安全距离，并为将来的角标预留空间 */
  margin-right: 15px;
}

.cart .iconfont {
  /* 调整图标至与导航、搜索框视觉平衡的大尺寸 */
  font-size: 40px;
  color: #333;
}
```

在录课现场，我先试了 `24px`，发现放在 130px 高度的头部里太显单薄小气；随后逐步加大调试到 `40px`，此时与左侧 40px 高度的导航热区、40px 高度的搜索框形成了完美的视觉重量均衡。

> **提示**：购物车图标右上角的红色数量角标（如展示当前加购了“2”件商品），同样需要依赖绝对定位悬浮在图标肩膀上，我们同样暂时保留其容器，待定位篇章合流后再行补装。

### 4.3 清除阶段性调试背景

在上一讲搭建 `.header` 容器时，为了看清楚外层大盒子的轮廓与居中状态，我们曾临时给 `.header` 添加了一行粉色背景：

```css
.header {
  /* background-color: pink; 调试完毕，务必注释或彻底删除 */
}
```

现在，导航、搜索和购物车三大核心组件全部就位，我们将这行调试背景果断注释掉。此时保存刷新，小兔鲜网站纯白通透、层次分明、对齐精准的商业级头部组件便完美呈现在浏览器中。

## 6. 核心知识要点小结

1. **点击热区扩展原则**：行内元素超链接在做导航时，必须转为块级（`display: block`）并设置合适的高度与行高，避免用户因点击区域过窄而产生挫败感；
2. **文本下划线选型**：商业级网页中，带留白的悬停指示线一律优先采用 `border-bottom` 实现，坚决弃用死贴字符底部的原生 `text-decoration: underline`；
3. **弹性间距选型**：单行并列项目优先采用弹性盒容器的 `gap` 属性，彻底根除传统 `margin-right` 在末尾子项产生的布局脏边距；
4. **表单占位符伪元素**：区分 `input` 自身的文本颜色设置与 `input::placeholder` 伪元素样式定制，掌握精准修改占位符字体和色彩的规范写法；
5. **视觉水平基准对齐**：并列功能块（如导航项与搜索输入框）采用统一的垂直几何高度（40px），确保视线流动自然、工业质感严密。
