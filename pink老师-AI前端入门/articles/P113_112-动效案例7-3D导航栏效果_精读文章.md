# 112-CSS3 实战：3D 翻转立体导航栏与立方体空间建模

在网页交互设计中，导航栏（Navbar）是用户视线停留时间最长、交互最频繁的核心区域。传统的导航栏悬停动效大多是变颜色、下划线滑动等二维平面过渡。

而很多前沿潮流网站（如潮牌电商、游戏门户、科技硬件新品站）则常常使用**3D 翻转方块导航栏**：

当鼠标悬停在某一个导航按钮上时，整个长方体按钮如同机械翻板一样向上做 90 度立体翻滚，底部隐藏的彩色面瞬间翻转到正前方；鼠标移出后，方块又自然滚回原位，视觉空间感极其逼真震撼。

本节我们将以实物空间建模的视角，彻底推导 **3D 立方体翻转导航栏** 的坐标变换公式与工程落地。

---

## 1. 空间解构：实物长方体的空间建模

很多同学在初学 3D 变换时，觉得 `translateZ` 和 `rotateX` 抽象难懂，全靠死记硬背。pink 老师教大家一个最管用的诀窍：**拿出一个真实的药盒或首饰盒，摆在眼前亲自转一转！**

我们要做的导航项，本质上是一个只有“前表面（Front）”和“底表面（Bottom）”的长方体盒子：

```text
长方体导航项的侧面投影剖析 (高度 H = 40px, 半高 = 20px)
                Y 轴 (向上)
                ▲
                │
         [ 旋转中心 (0, 0, 0) ]
                │
◄───────────────┼───────────────► Z 轴 (向用户飞来)
                │  ▲
                │  │ 向前移 20px (+Z)
                │  ▼
        +-------+-------+
        | 前表面 (Front) |  <- 初始面向用户
        +-------+-------+
                │
                │ 向下移 20px (+Y) 并绕 X 轴折转 -90°
                ▼
        +---------------+
        | 底表面 (Bottom)|  <- 初始平躺在底部，文字朝下
        +---------------+
```

假设导航项的尺寸为：**宽 80px，高 40px**。长方体的旋转几何中心点默认在盒子的中心 `(40px, 20px, 0)`。

### 1.1 前表面（`.front`）定位推导：
- 前表面初始就立在正前方；
- 为了让它在翻滚时不偏离中心轴，它必须**向前（向着用户的眼睛方向）平移半个盒子的高度（20px）**：
  $$\text{前表面变换} = \text{translateZ}(20\text{px})$$

### 1.2 底表面（`.bottom`）定位推导：
- 底表面初始需要扣在长方体的正下方；
- **第一步**：向下平移半个盒子的高度（20px）：`translateY(20px)`；
- **第二步**：根据左手法则，大拇指指向 X 轴正右侧，四指卷向屏幕内部，绕 X 轴旋转 **`-90deg`**：
  $$\text{底表面变换} = \text{translateY}(20\text{px}) \text{ rotateX}(-90\text{deg})$$

### 1.3 悬停整体翻转（`:hover`）：
- 当鼠标悬停在父容器上时，父容器整体绕 X 轴向上翻滚 **`+90deg`**：
  $$\text{悬停翻转} = \text{rotateX}(90\text{deg})$$
底表面顺势翻转到正前方，前表面顺势翻转到正上方，一次完美的立体翻转即刻完成！

---

## 2. 核心避坑要点

1. **必须声明 `transform-style: preserve-3d`**：
   - 承载两个面的父级 `li` 必须开启 `transform-style: preserve-3d;`。如果不开启，即使子元素写了 `translateZ`，也会被强制压扁在父级的 2D 平面内，完全失去立体透视；
2. **先平移，后旋转（顺序不可颠倒）**：
   - 底表面的变换必须书写为 `transform: translateY(20px) rotateX(-90deg);`。
   - 在 CSS 矩阵运算中，先旋转会同时旋转该元素局部的三维坐标轴！如果先旋转 90 度，局部的 Y 轴就会变成 Z 轴，后续平移方向就会彻底错乱；
3. **父相子绝叠合**：
   - 前后两面必须通过 `position: absolute; top: 0; left: 0;` 先严丝合缝重叠在同一物理位置，然后再施加各自的 3D 变换。

## 3. 完整代码实战开发

### 3.1 HTML 结构
每个导航项由一个 `li` 包裹前表面与底表面：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>3D 翻转立体导航栏</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <!-- 导航栏容器 -->
  <ul class="nav">
    <li>
      <div class="front">首页</div>
      <div class="bottom">Home</div>
    </li>
    <li>
      <div class="front">课程</div>
      <div class="bottom">Course</div>
    </li>
    <li>
      <div class="front">实战</div>
      <div class="bottom">Project</div>
    </li>
    <li>
      <div class="front">关于</div>
      <div class="bottom">About</div>
    </li>
  </ul>
</body>
</html>
```

---

### 3.2 CSS 核心样式编码

```css
* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}

body {
  height: 100vh;
  display: flex;
  justify-content: center;
  align-items: center;
  background-color: #1e1e2f;
}

/* 1. 导航列表 */
.nav {
  list-style: none;
  display: flex;
  gap: 20px;
}

/* 2. 单个 3D 长方体容器 */
.nav li {
  position: relative;
  width: 90px;
  height: 44px; /* 高度 H = 44px，半高 = 22px */
  cursor: pointer;
  
  /* 核心 A：开启子元素 3D 空间保留 */
  transform-style: preserve-3d;
  /* 翻转平滑过渡 */
  transition: transform 0.4s cubic-bezier(0.4, 0, 0.2, 1);
}

/* 3. 前后两面公共样式 */
.nav li div {
  position: absolute;
  top: 0;
  left: 0;
  width: 100%;
  height: 100%;
  border-radius: 6px;
  display: flex;
  justify-content: center;
  align-items: center;
  font-size: 15px;
  font-weight: 600;
  letter-spacing: 1px;
}

/* 4. 前表面：白底黑字，向前平移半高 22px */
.nav li .front {
  background-color: #ffffff;
  color: #2c3e50;
  transform: translateZ(22px);
}

/* 5. 底表面：炫酷渐变底白字，先下移 22px 再绕 X 轴旋转 -90° */
.nav li .bottom {
  background: linear-gradient(135deg, #667eea, #764ba2);
  color: #ffffff;
  transform: translateY(22px) rotateX(-90deg);
}

/* =======================================================
   6. 悬停触发：父容器长方体整体绕 X 轴上翻 90°
   ======================================================= */
.nav li:hover {
  transform: rotateX(90deg);
}
```

## 4. 拓展与工程总结

1. **四面立体滚动立方体**：
   - 掌握了前表面与底表面的关系后，同理可以为长方体添加顶表面（`translateY(-22px) rotateX(90deg)`）和后表面（`translateZ(-22px) rotateX(180deg)`），从而实现无限滚动的立体骰子或四面魔方；
2. **多级导航的 3D 联动**：
   - 可以为每个 `li` 设置错峰延迟（如通过 `:nth-child(n)` 设置 `transition-delay: 0.1s * n`），在鼠标掠过导航栏时产生波浪状翻滚的震撼效果！
