# 优医问诊头部 home-header 区域结构搭建

准备工作做完，目录、视口标签、转 vw 插件三样齐了，这一讲我们正式敲下项目的第一行业务代码。先做哪个？永远是自上而下，第一个大盒子就是顶部的 `home-header`。

你们先别急着写，想一想：打开任何一个问诊类 App，第一眼看到的是什么？一片绿色。绿色在医疗场景里代表健康、安全，设计师把头部做成绿色渐变，不是为了好看，是为了让你们一进来就安心。所以头部的第一要务，是把这片渐变绿铺对；第二要务，才是往上面摆标题和搜索框。

---

## 1. 头部区域版式分析

### 1.1 header 的三层内容

对着设计稿把头部横着切，一共三层：第一层是问候标题行，左边是"优医问诊"几个字，右边是一个消息小图标；第二层是一个白色圆角搜索框，里面是灰色提示文字"搜医院、医生、疾病"；第三层是渐变背景本身，底部可能是微微的弧形，一直延伸到导航栏的背后。

```text
home-header 头部版式分解
+------------------------------------------+
| 优医问诊                          [消息] |  <- 标题行
|                                          |
| +--------------------------------------+ |
| | [放大镜] 搜医院、医生、疾病          | |  <- 搜索框
| +--------------------------------------+ |
|         (绿色渐变背景,底部延伸)          |
+------------------------------------------+
```

读图说明：标题行和搜索框是内容，渐变背景是容器。三层先分清，写代码时先搭容器再填内容，顺序不能反。

### 1.2 容器与标题行骨架

骨架先用语义化标签搭起来。头部整体用 `header` 标签，类名按业务起名叫 `home-header`，见名知意，后面维护的人一眼就知道这是首页的头：

```html
<header class="home-header">
  <div class="title">
    <h1>优医问诊</h1>
    <a href="#" class="msg"></a>
  </div>
  <div class="search">
    <i></i>
    <span>搜医院、医生、疾病</span>
  </div>
</header>
```

标题用 `h1` 不是讲究，是规矩：一个页面只允许一个 `h1`，它就是整站的门面，搜索引擎认它。消息图标和放大镜先用空标签占位，样式里再用背景图贴上去。

---

## 2. 渐变背景与标题行样式

### 2.1 绿色线性渐变铺底

渐变用线性渐变（linear-gradient），方向自上而下，从亮绿过渡到深绿。写的时候先写 px，插件会自动转 vw，这就是上一讲配环境的意义——我们只管按设计稿量，单位的事交给工具：

```css
.home-header {
  background: linear-gradient(180deg, #2edf9e 0%, #22c484 100%);
  padding: 15px 12px 30px;
}
```

> **结论**：移动端头部的渐变一定写在容器上，而不是每行内容各写一段。只有容器持有完整渐变，标题行和搜索框压在上面，色彩过渡才是连贯的一整片。

### 2.2 标题行弹性布局

标题行是典型的左右两端对齐：左边标题，右边图标。弹性布局（flexbox）一行搞定，主轴两端对齐、交叉轴居中：

```css
.home-header .title {
  display: flex;
  justify-content: space-between;
  align-items: center;
}
.home-header .title h1 {
  font-size: 20px;
  color: #fff;
  font-weight: 600;
}
.home-header .title .msg {
  width: 24px;
  height: 24px;
  background: url(../images/msg.png) no-repeat center / contain;
}
```

你们看，标题是白色压在绿底上，对比足够，字号 `20px` 在 375 的稿子里正好压得住场。消息图标固定 `24px` 见方，背景图用 `contain` 完整呈现，图标再小也不会被裁掉一半。

> **提示**：背景图简写 `center / contain` 里的斜杠不能丢，斜杠前面是位置，后面是尺寸。丢了斜杠，浏览器会把 `contain` 当成重复方式解析，图直接没了。

---

## 3. 搜索框结构与样式起步

搜索框是一个白色圆角长条，里面左边是放大镜图标，右边是灰色提示字。结构上图标和文字是左右关系，同样用 flex，交叉轴居中，文字颜色用浅灰，和白色底拉开一点距离就够了：

```css
.home-header .search {
  display: flex;
  align-items: center;
  height: 38px;
  margin-top: 12px;
  padding: 0 14px;
  background-color: #fff;
  border-radius: 19px;
}
.home-header .search i {
  width: 16px;
  height: 16px;
  background: url(../images/search.png) no-repeat center / contain;
}
.home-header .search span {
  margin-left: 8px;
  font-size: 13px;
  color: #999;
}
```

圆角取高度的一半（`38px` 高配 `19px` 圆角），长条两端就是标准的胶囊形。这个"高度一半即胶囊"的结论，移动端搜索框、按钮、标签页通用，记住一条，处处能用。

---

这一讲我们把头部的容器、标题行、搜索框骨架全部立起来了，但对照设计稿看，还有两处没收尾：搜索框里图标和文字的垂直位置要不要再微调，头部底部的留白要给导航栏让多少。下一讲我们把这两处收完，并且第一次亲眼看着插件把整片 px 批量转成 vw。
