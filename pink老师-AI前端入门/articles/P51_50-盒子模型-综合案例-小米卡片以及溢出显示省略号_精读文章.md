# 盒子模型实战：小米商城商品卡片重构与文本溢出省略号方案

我们在前面已经系统把盒子模型的尺寸计算、内边距、边框、外边距以及背景属性全部讲透了。但很多同学学完之后会有一种感觉：“老师，单独看每一个属性我都懂，为什么一面对真实网页里的卡片、侧边栏，我还是无从下手？”

从这一讲开始，我们进入真正的实战演练环节。通过真实一线电商的经典案例，把我们学过的盒子模型体系彻底串联打通。

我们要做的第一个案例是**小米商城商品卡片**。在真实的商业前端开发中，通常 UI 设计师会给我们提供高保真的设计稿（如 Figma、蓝湖或 PSD），我们可以直接在设计稿上测量出精准的尺寸、色值与间距。但在日常学习或者临摹优秀产品时，我们手里往往没有原始设计稿。这时，浏览器的开发者工具（F12）就是我们最强大的测量武器。

2. **看细节**：外层大盒子内部纵向排列着 4 个子元素：

3. **后编码**：在脑海中建立起清晰的盒子嵌套结构树后，再打开编辑器书写 HTML 骨架与 CSS 样式。

## 2. 卡片外层容器构建与图片布局

### 2.1 基础样式重置与卡片外框

在编写具体组件样式前，标准工程的第一步必然是做样式初始化重置。不同浏览器默认的 `margin` 和 `padding` 不一致，同时默认的盒模型会导致边框内边距撑大盒子，因此先做通配重置：

```css
* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}

body {
  background-color: #ccc; /* 灰色底衬，方便凸显出白色的卡片轮廓 */
}
```

紧接着我们创建卡片容器 `.card`。为了让卡片在屏幕中易于观察，我们给它一个距离顶部 `100px` 且水平居中的外边距：

```css
.card {
  width: 234px;
  height: 300px;
  background-color: #fff;
  margin: 100px auto;
  text-align: center; /* 关键：让内部所有行内/行内块元素继承水平居中 */
}
```

> **核心思路**：为什么要在 `.card` 外层大盒子上直接写 `text-align: center;`？因为卡片内部的图片、标题文字、描述段落、价格都是居中显示的。`text-align` 具有继承性，直接加给父级容器，内部的行内元素与行内块元素全部自动水平居中，不需要我们给每一个子元素单独去写居中代码。

### 2.2 商品图片配置与外边距塌陷深度辨析

在 HTML 中引入图片：

```html
<div class="card">
  <img src="./images/mi.webp" alt="小米耳机">
</div>
```

图片原始尺寸可能很大，必须严格限制其尺寸为 `160px × 160px`。同时，图片顶部距离卡片边缘有 `20px` 的安全留白：

```css
.card img {
  width: 160px;
  height: 160px;
  margin-top: 20px;
}
```

> **易错点辨析**：有的同学写到这里心里会犯嘀咕：“老师，前面讲外边距时不是说过吗？如果一个盒子里套着一个子盒子，直接给子盒子设置 `margin-top`，会导致父盒子跟着一起掉下来，发生外边距塌陷（外边距合并）吗？为什么这里直接给 `img` 设置 `margin-top: 20px;`，父级 `.card` 却完全没有塌陷？”
> 
> 请大家一定要把外边距塌陷的前提条件刻在脑子里：
> **外边距塌陷（Margin Collapse）只发生在垂直方向相邻的『块级盒子（Block Box）』之间！**
> 
> 我们这里的 `<img>` 标签根本不是块级元素，它是**行内块级元素（Inline-block）**。行内块元素既有盒子的宽高特征，又保留了行内元素的流式特性，**它绝对不会与父级块级元素触发外边距塌陷**。所以在这里放心大胆地使用 `margin-top: 20px;`，结构坚如磐石。

## 3. 卡片文本流与价格区域语义化排版

### 3.1 标题（`title`）与描述（`desc`）的排版设计

在图片下方紧接着加入标题和描述：

```html
<h3 class="title">Xiaomi Buds 5</h3>
<p class="desc">半入耳舒适佩戴 | 独立声学腔体 | 空间音频</p>
```

在 CSS 中，我们要重点处理字号、字重与颜色层次：

```css
.card .title {
  font-size: 14px;
  color: #333;
  font-weight: normal; /* 关键：重置 h3 浏览器默认的加粗效果 */
  margin-top: 18px;
}

.card .desc {
  font-size: 12px;
  color: #b0b0b0;
  margin-top: 6px;
  padding: 0 10px; /* 左右各给 10px 内边距，防止文本贴紧边缘 */
}
```

> **提示**：浏览器对 `<h1>` ~ `<h6>` 默认都会附加粗体样式（`font-weight: bold`）。在一线大厂的精致 UI 规范中，卡片标题一般要求与整体细腻风格统一，不需要过度粗重，因此必须显式声明 `font-weight: normal;`。给类名（如 `.title`、`.desc`）而不是裸标签名写样式，是大型工程中避免样式污染的必备好习惯。

### 3.2 价格区域的行内语义化结构

很多初学者排版价格时会犯难：“现价是橙色大字，原价是灰色带划线的字，它们还要并排显示在同一行，是不是得用浮动或者 flex 弹性盒？”

完全不需要杀鸡用牛刀！我们利用最朴素的 HTML 标签特性即可完美搞定：

```html
<p class="price">
  <span>659元</span>
  <del>699元</del>
</p>
```

价格区域各元素特性解析：
- `<p>` 作为一个独立的块级容器，承载整行价格数据；
- `<span>` 是纯行内元素，用来单独包裹现价文字以便单独给它赋予品牌橙色；
- `<del>` 是专门表达“已废弃/删除内容”的 HTML5 语义化标签，浏览器默认自带横向贯穿删除线。

```css
.card .price {
  font-size: 14px;
  margin-top: 10px;
}

/* 现价：高亮橙色 */
.card .price span {
  color: #ff6700;
}

/* 原价：划线灰色 */
.card .price del {
  color: #b0b0b0;
  font-size: 12px;
  margin-left: 5px; /* 原价与现价之间保留适度呼吸感 */
}
```

因为 `<span>` 和 `<del>` 本身都是行内元素，它们天然会在同一行内自左向右排列，既拥有极佳的语义化，又省去了复杂的布局推导。

## 4. 单行文本溢出显示省略号核心方案

### 4.1 核心属性推导三步法

在实际电商业务中，后端的商品卖点描述字数是不受控的。有的商品描述只有 5 个字，有的描述长达 30 多个字。如果文本过长，默认情况下文字会自动折行，这会直接把下方的价格区域挤出卡片，导致整个页面排版错位“车祸”。

因此，前端界面必须建立防御性布局：**单行文本溢出时，截断并显示省略号（`...`）**。

实现该效果有一组经典的万能搭配公式，缺一不可：

```css
.card .desc {
  /* 1. 强制文字在同一行内显示，禁止换行 */
  white-space: nowrap;

  /* 2. 溢出容器范围的内容直接裁剪隐藏 */
  overflow: hidden;

  /* 3. 溢出裁切的部分替换渲染为省略号 */
  text-overflow: ellipsis;
}
```

三步核心推导机制剖析：

```text
单行文本溢出省略号渲染三阶段推进示意
[阶段 1：普通换行状态]
┌──────────────────┐
│ 半入耳舒适佩戴 | │ ──> 默认换行，高度被撑大，破坏卡片垂直节律
│ 独立声学腔体...  │
└──────────────────┘

[阶段 2：强制单行 + 溢出裁剪]
white-space: nowrap; overflow: hidden;
┌──────────────────┐
│ 半入耳舒适佩戴 | │独  ──> "独" 字被生硬切成两半，用户体验极其粗糙
└──────────────────┘

[阶段 3：注入省略号]
text-overflow: ellipsis;
┌──────────────────┐
│ 半入耳舒适佩戴...│    ──> 优雅截断并告知用户后文还有未尽内容
└──────────────────┘
```
*图 3：单行文本从换行、裁切到优雅省略的渲染状态递进*

1. **第一步 `white-space: nowrap;`**：普通文本只要遇到容器右边界，就会自动寻找空格或汉字断点折到第二行。我们必须先下达死命令：无论文字多长，一律强行压在同一行内；
2. **第二步 `overflow: hidden;`**：强制单行之后，超出的文字会横向穿破卡片右边框露出外面。我们必须给容器加上裁切罩子，把冲出边界的内容砍掉；
3. **第三步 `text-overflow: ellipsis;`**：生硬地把字切掉一半对用户非常不友好，必须使用 `text-overflow` 属性将截断处的边缘字符自动转换为三点省略号 `...`。

> **易错点**：很多初学者经常漏掉 `overflow: hidden;` 或 `white-space: nowrap;`，然后纳闷为什么单写一个 `text-overflow: ellipsis;` 完全不起作用。请记住：**省略号必须建立在“文字不换行”且“内容被裁切隐藏”这两个先决条件之上**，三行代码必须形影不离！

## 5. 交互动效与进阶拓展

### 5.1 悬浮卡片阴影与平滑过渡

为了让卡片在用户鼠标滑过时更有品质感，小米商城在卡片悬浮状态下加入了精致的微上浮与外发光阴影效果。

我们在 CSS 中利用 `:hover` 伪类配合 `box-shadow` 实现：

```css
.card {
  /* 基础样式保留不变 */
  transition: all 0.2s linear; /* 注入 0.2 秒平滑缓动过渡，避免阴影突然闪现 */
}

.card:hover {
  /* x偏移 y偏移 模糊半径 扩散半径 颜色 */
  box-shadow: 0 15px 30px rgba(0, 0, 0, 0.1);
  transform: translateY(-2px); /* 悬浮时产生轻微上浮质感 */
}
```

### 5.2 进阶拓展：多行文本溢出显示省略号（两行截断）

在讲完单行省略号之后，大家一定会联想到另外一个极其高频的真实场景：
“老师，我们在刷 Bilibili 视频列表、京东或者淘宝商品详情时，商品的标题往往允许显示两行甚至三行，只有超过指定行数时才在末尾显示省略号，这该怎么做？”

多行文本省略在现代前端中有着一套基于 WebKit 弹性盒规范的工业级标准写法（万年不变的 5 句公式）：

```css
.multi-line-ellipsis {
  /* 1. 溢出隐藏 */
  overflow: hidden;

  /* 2. 溢出文本展示省略号 */
  text-overflow: ellipsis;

  /* 3. 必须转换为旧版伸缩盒模型展示 */
  display: -webkit-box;

  /* 4. 设置伸缩盒对象的子元素垂直排列 */
  -webkit-box-orient: vertical;

  /* 5. 核心限制行数：限制在第几行显示省略号（如 2 行） */
  -webkit-line-clamp: 2;
}
```

> **核心机制与定高防御**：
> 多行文本溢出截断中，最关键、最容易踩坑的细节是**容器的高度控制**！
> 
> 在部分老旧内核或特定排版环境下，仅仅写上述 5 句代码，如果容器没有设置高度，且后面跟着紧邻的元素，截断后第三行的文字碎片可能会在边缘漏出一截。
> 
> 在大厂成熟工程中（如京东、B站），我们通常会严格**将容器高度（`height`）设定为目标行数的总高度**。
> 例如：单行文字行高 `line-height: 24px`，如果要求显示两行，则容器的 `height` 必须显式设定为 `48px`（即 $24\text{px} \times 2 = 48\text{px}$）。这样即便有任何偶发的渲染溢出，多余内容也绝不可能破框而出。

## 6. 完整工程实现代码

我们将本讲所有的知识点装配为一份完整、可独立运行的工程化代码文件：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>小米商城商品卡片重构实战</title>
  <style>
    /* 1. 全局初始化重置 */
    * {
      margin: 0;
      padding: 0;
      box-sizing: border-box;
    }

    body {
      background-color: #f5f5f5;
      font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif;
    }

    /* 2. 卡片外层容器 */
    .card {
      width: 234px;
      height: 300px;
      background-color: #ffffff;
      margin: 100px auto;
      text-align: center;
      transition: all 0.2s linear;
      border-radius: 4px;
    }

    /* 悬浮交互微动效 */
    .card:hover {
      box-shadow: 0 15px 30px rgba(0, 0, 0, 0.1);
      transform: translateY(-2px);
    }

    /* 3. 商品大图：行内块防塌陷 */
    .card img {
      width: 160px;
      height: 160px;
      margin-top: 20px;
    }

    /* 4. 商品标题：重置字重 */
    .card .title {
      font-size: 14px;
      color: #333333;
      font-weight: normal;
      margin-top: 18px;
    }

    /* 5. 描述文本：单行溢出省略三步法 */
    .card .desc {
      font-size: 12px;
      color: #b0b0b0;
      margin-top: 6px;
      padding: 0 10px;

      /* 省略号三剑客 */
      white-space: nowrap;
      overflow: hidden;
      text-overflow: ellipsis;
    }

    /* 6. 价格区域：语义化行内并列 */
    .card .price {
      font-size: 14px;
      margin-top: 10px;
    }

    .card .price span {
      color: #ff6700;
    }

    .card .price del {
      color: #b0b0b0;
      font-size: 12px;
      margin-left: 5px;
    }
  </style>
</head>
<body>

  <!-- 小米卡片独立组件 -->
  <div class="card">
    <img src="./images/mi.webp" alt="Xiaomi Buds 5">
    <h3 class="title">Xiaomi Buds 5</h3>
    <p class="desc">半入耳舒适佩戴 | 独立声学腔体 | 空间音频计算</p>
    <p class="price">
      <span>659元</span>
      <del>699元</del>
    </p>
  </div>

</body>
</html>
```

### 关键架构总结表

| 组件模块 | HTML 标签 / 类名 | 核心属性配置 | 布局机理与设计意图 |
| :--- | :--- | :--- | :--- |
| **外层容器** | `div.card` | `width: 234px; height: 300px; text-align: center;` | 固定大厂规格；通过文本对齐继承性直接控制全子元素居中 |
| **主图区域** | `img` | `width: 160px; height: 160px; margin-top: 20px;` | 行内块元素，安全设置外边距且不会触发父子外边距塌陷 |
