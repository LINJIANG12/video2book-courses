# 106-CSS3 实战：流光渐变边框按钮动效实现

在学习完 2D/3D 变换与 `animation` 关键帧动画之后，我们正式进入高阶商业动效实战阶段。

很多前沿科技官网（如各大手机品牌旗舰新品发布页、AI 产品官网）经常会出现极其吸睛的按钮动效：**按钮的彩色边框如同流动着霓虹光彩一样，持续不断地匀速循环流动**。当鼠标悬停时，光晕还会加速流转。

这种动效不仅高级，而且在各类大厂面试中屡见不鲜。本讲我们将以 **流光渐变边框按钮** 为例，彻底拆解其背后的“障眼法”原理与完整工程实现。

---

## 1. 动效解构：边框渐变的“障眼法”真相

很多初学者看到这个效果，第一反应是去查 CSS 有没有类似 `border-image` 或可以直接给 `border` 做 `@keyframes` 线性渐变位移的属性。

然而，W3C 规范中并没有直接支持原生 `border-color` 线性渐变沿边框平滑位移的简易语法。

pink 老师告诉大家：**网页中所有看起来精巧绝伦的渐变边框流光动效，底层全都是“障眼法”！**

它并不是真正的边框在变色，而是**三个盒子的叠罗汉游戏**：

```text
流光渐变边框的三层结构拆解
+---------------------------------------------------------+
| 1. 最外层父级盒子 <a>                                   |
|    - 作用：总容器，设置 padding: 3px 作为边框宽度        |
|    - 设置 overflow: hidden 裁剪多余流光                |
|  +---------------------------------------------------+  |
|  | 2. 中间层伪元素 ::before (双倍宽度彩色盒子)         |  |
|  |    - 宽度 200%，铺设多段线性渐变流光               |  |
|  |    - 不停向左位移 transform: translateX(-50%)     |  |
|  |  +---------------------------------------------+  |  |
|  |  | 3. 最内层内容盒子 <span>                     |  |  |
|  |  |    - 纯黑色背景，遮住绝大部分彩色层         |  |  |
|  |  |    - 仅靠父级 padding 露出 3px 彩色流光边框   |  |  |
|  |  |    - 承载“开始按钮”文字内容                 |  |  |
|  |  +---------------------------------------------+  |  |
|  +---------------------------------------------------+  |
+---------------------------------------------------------+
```

### 核心机制总结：
1. **底层（容器）**：外层 `<a>` 设置固定宽高与 `overflow: hidden`，并通过 `padding: 3px` 为内层留出刚好 3px 的空隙；
2. **夹层（流光动效）**：利用 `::before` 伪元素绝对定位在最底层，铺满鲜艳的双倍渐变色，利用 `translate` 水平位移做循环动画；
3. **顶层（内容遮罩）**：内层 `<span>` 设置和页面底色完全一致的纯黑背景，将夹层的大部分渐变色死死遮住，只把父级 `padding` 挤出来的 3px 缝隙漏出来！

人眼透过这 3px 的缝隙，看到底下不停滑动的彩色渐变，便会产生“边框在流动”的奇妙视觉！

## 2. 核心避坑：为什么彩色盒子必须是 200% 宽度？

这是本案例中最容易踩坑的地方。

如果我们把 `::before` 的宽度设置为与父级相同的 `100%`，当动画将它向左位移 `100%` 时，右侧就会露出一大块空白，按钮右侧的流光边框会瞬间断档、熄灭，呈现出一段极其难看的残缺空隙。

### 优雅解决方案：走一半，留一半
1. **宽度放大一倍**：`width: 200%`；
2. **背景缩放为双份平铺**：`background-size: 50% 100%`，让水平方向正好无缝并排两个一模一样的渐变图案；
3. **关键帧位移设定为 -50%**：
   ```css
   @keyframes move {
     to {
       transform: translateX(-50%);
     }
   }
   ```
当彩色盒子刚好向左滑动自身的一半（50%，即一个完整周期的长度）时，动画立刻瞬间回到 `0%`。因为前后两半图案完全一致，视觉上没有任何跳跃与断裂，实现了完美的**无缝无限循环流光**！

## 3. 完整代码实战开发

### 3.1 HTML 语义结构
无需冗余标签，最外层为超链接按钮，内层包裹文字的 `span` 即可：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>流光渐变边框按钮</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <!-- 按钮容器 -->
  <a href="#" class="btn1">
    <span>开始体验</span>
  </a>
</body>
</html>
```

---

### 3.2 CSS 核心样式编码

```css
* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}

body {
  height: 100vh;
  display: flex;
  justify-content: center;
  align-items: center;
  background-color: #0f0f14;
}

/* 1. 外层总容器：通过 padding 挤出 3px 边框间距，裁剪溢出 */
.btn1 {
  position: relative;
  display: block;
  width: 140px;
  height: 60px;
  padding: 3px; /* 核心：内边距即为视觉边框厚度 */
  border-radius: 6px;
  overflow: hidden; /* 裁剪双倍彩色盒子的外部溢出 */
  text-decoration: none;
}

/* 2. 夹层伪元素：双倍宽度的彩色渐变流动层 */
.btn1::before {
  content: "";
  position: absolute;
  top: 0;
  left: 0;
  width: 200%; /* 200% 双倍宽度，保证无缝循环不留白 */
  height: 100%;
  /* 炫酷多色线性渐变 */
  background-image: linear-gradient(
    115deg,
    #4fcf70,
    #fad648,
    #a767e5,
    #12bcfe,
    #44ce7b
  );
  background-size: 50% 100%; /* 水平横向缩放50%，容纳两组完整渐变 */
  /* 绑定位移动画：0.75秒匀速无限滚动 */
  animation: streamMove 0.75s linear infinite;
}

/* 3. 关键帧：仅向左移动自身宽度的 50% */
@keyframes streamMove {
  to {
    transform: translateX(-50%);
  }
}

/* 4. 顶层遮罩盒子：纯黑遮挡，提升层级 */
.btn1 span {
  position: relative; /* 核心避坑：加相对定位提升层级，压住定位的 ::before */
  z-index: 1;
  display: block;
  width: 100%;
  height: 100%;
  background-color: #000; /* 与整体风格契合的遮蔽背景 */
  border-radius: 3px; /* 圆角比外层稍小，保持同心圆视觉协调 */
  color: #fff;
  font-size: 16px;
  text-align: center;
  line-height: 54px; /* 60px 减去上下各 3px padding，保持文字垂直居中 */
}

/* 鼠标悬停时加速流光效果 */
.btn1:hover::before {
  animation-duration: 0.4s;
}
```

## 4. 关键踩坑点与工程细节

1. **`span` 为什么会被 `::before` 盖住？**
   - 在 CSS 规范中，定位元素（`position: absolute` 的 `::before`）层级天然高于普通流元素（`span`）。
   - **解决办法**：必须显式给 `span` 加上 `position: relative;`（或 `z-index: 1`），让内容层重新覆盖在流动光效之上。
2. **同心圆角法则（Border Radius Matching）**：
   - 如果外层按钮圆角是 `6px`，内层 `span` 如果也写 `6px`，在转角处容易出现内外边缘厚度不均的畸变；
   - 经验公式：**内层圆角 = 外层圆角 - 边框厚度**，即 `6px - 3px = 3px`，视觉过渡最为自然。
3. **行高居中计算**：
   - 外层总高为 `60px`，因为设置了 `padding: 3px`，`span` 的实际高度为 `60 - 3*2 = 54px`，因此文字的 `line-height` 建议设置为 `54px` 避免偏下。
