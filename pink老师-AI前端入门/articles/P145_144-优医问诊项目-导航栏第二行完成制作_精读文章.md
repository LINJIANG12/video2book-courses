# 优医问诊图标导航栏第二行与整体收尾

第一行 5 个入口跑通了，这一讲把第二行 5 个补上，导航栏整体收工。先说结论：第二行没有新知识点，结构复制第一行，样式共用同一套。但千万不要觉得这一讲是水课——"复制"里面藏着三个真问题：两行之间的间距归谁管？上下两行的图标对齐靠什么保证？整张卡片的底部留白留多少？答不上来，复制出来的第二行就是歪的。

## 1. 第二行结构复制

### 1.1 复用同一套类名

第二行还是 `ul.nav-row`，类名和第一行完全一样，样式零新增。需要新写的只有 5 组 `li` 的内容：

    <li><a href="#"><img src="./images/nav2.png" alt="预约挂号"><p>预约挂号</p></a></li>
    <li><a href="#"><img src="./images/nav3.png" alt="名医会诊"><p>名医会诊</p></a></li>
    <li><a href="#"><img src="./images/nav4.png" alt="药品商城"><p>药品商城</p></a></li>
    <li><a href="#"><img src="./images/nav5.png" alt="健康测评"><p>健康测评</p></a></li>
  </ul>
  <ul class="nav-row">
    <li><a href="#"><img src="./images/nav6.png" alt="体检预约"><p>体检预约</p></a></li>
    <li><a href="#"><img src="./images/nav7.png" alt="疫苗接种"><p>疫苗接种</p></a></li>

你们看，同样的 `nav-row` 写两遍，CSS 一行不用加。这就是类名设计的好处：第一行定的是"一行的样子"，第二行只是"再来一行"。

> **结论**：能复用的结构坚决复用，不要为了区分第一行第二行去起 `nav-row1`、`nav-row2` 这种名字。多一个类名，将来改字号就要改两处，维护成本翻倍。

## 2. 行间距与卡片收尾

### 2.1 两行之间的间距归属

两行之间的空隙，正确做法是给第一行加 `margin-bottom`（或者给容器加统一的上下 padding 配合行间距），而不是给第二行加 `margin-top`。理由很实际：将来如果产品说"先上线一行，第二行下个版本再上"，删掉第二行时，第一行的底部间距依然完整，页面不会塌。

```css
.nav {
  margin: -20px 12px 0;
  padding: 14px 0 16px;
  background-color: #fff;
  border-radius: 10px;
  box-shadow: 0 2px 8px rgba(0, 0, 0, 0.06);
}
.nav-row {
  display: flex;
}
.nav-row + .nav-row {
  margin-top: 12px;
}
```

`.nav-row + .nav-row` 这个相邻兄弟选择器很有味道：它只命中"前面还有一行的行"，也就是天然选中第二行及以后。以后加第三行、第四行，间距自动跟上，不用补样式。

### 2.2 图标对齐的隐形保证

上下两行图标能对齐，不是因为我们算过，而是因为两行的 `li` 都是 `flex: 1` 五等分。格子宽度完全一致，图标又都在格子里居中，对齐是数学上的必然。反过来，如果某一行的图标尺寸写错了，比如第二行写成 `46px`，对齐立刻就破。所以检查方法很简单：两行图标尺寸必须同一个数，`48px` 就是 `48px`，一个都不能差。

```text

|  (绿)                                    |
| +--------------------------------------+ |
| | [图] [图] [图] [图] [图]  第一行    | |
| | 在线 预约 名医 药品 健康              | |
| |                                      | |
| | [图] [图] [图] [图] [图]  第二行    | |
| | 体检 疫苗 慢病 报告 资讯              | |
| +--------------------------------------+ |
+------------------------------------------+
```

读图说明：白色卡片内两行各 5 个入口，行间距一致，图标列上下对齐，卡片上浮压住绿底——导航栏至此完工。

## 3. 完工自查三项

收工前三件事，做完再往下走。第一，模拟器切到 `320px`，确认 10 个入口没有一个被挤到下一行；第二，`F12` 里看插件转换结果，`48px` 应为 `12.8vw`（`48 ÷ 3.75`），`12px` 字应为 `3.2vw`，对不上就回查插件基准是不是 375；第三，把第二行的 `ul` 整个注释掉，看第一行单行的底部留白是否依然好看——好看，说明间距归属做对了。
