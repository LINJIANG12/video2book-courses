# rem 适配的脚本实现与插件配置

原理听懂了还不够，手停在键盘上写不出来等于没学。这一讲我们就把 `rem` 适配真正跑起来：先用一小段脚本让根字号跟着视口走，再配好自动换算插件，以后你们量出多少像素，直接写，插件替你们换成 `rem`。

## 1. 动态根字号的脚本写法

上一讲的公式还记得吧，根字号等于视口宽除以份数。咱们设计稿 750，分 10 份，根字号就是视口宽除以 10。375 的手机就是 37.5，414 的手机就是 41.4。用媒体查询（Media Query）一个个断点写能累死，直接一段脚本搞定：

```js
function setRootFont() {
  const width = document.documentElement.clientWidth;
  const fontSize = width / 10;
  document.documentElement.style.fontSize = fontSize + 'px';
}
setRootFont();
window.addEventListener('resize', setRootFont);
```

三件事你们看清。第一，`document.documentElement` 就是 `html` 标签，`clientWidth` 拿到的是视口宽；第二，除以 10 得到根字号，直接写到 `html` 的行内样式；第三，监听窗口变化（Resize）事件，横竖屏一转、窗口一拖，重新算一遍。我习惯页面一进来先调一次，不然首屏会闪一下默认值。

> **提示**：除以几完全是约定，10 是为了好算，750 设计稿下 `1rem` 等于 75 像素，量出 150 除以 75 得 `2rem`，心算都行。你们团队定成 7.5 也行，只要全站统一，比例就不会错。

上限也要封一下。平板、桌面动不动 1200 宽，除以 10 根字号 120，全站大得吓人。我的习惯是封顶，比如超过 750 就按 750 算：

```js
function setRootFont() {
  let width = document.documentElement.clientWidth;
  if (width > 750) width = 750;
  document.documentElement.style.fontSize = width / 10 + 'px';
}
```

## 2. 自动换算插件的配置

```text
手写流程                      插件流程
量出 68px -> 心算             量出 68px -> 照写 px
68 / 75 = 0.9067rem           插件编译成 0.9067rem
手动写 rem                    源码仍是 px, 上线自动换
```

读图说明：插件把换算从人肉挪到编译时，源码可读性不变，产物自动带 `rem`。

我用的是 `postcss-pxtorem`，配合 `lib-flexible` 那套思路也行，原理一样。先装包：

```bash
npm install postcss-pxtorem --save-dev
```

再配 `postcss.config.js`，关键就两个参数：

```js
module.exports = {
  plugins: {
    'postcss-pxtorem': {
      rootValue: 75,
      propList: ['*']
    }
  }
};
```

`rootValue: 75` 必须和脚本里的 750 除以 10 对上，设计稿 750 就是 75，设计稿 375 就是 37.5，这两个数是一对，改一个另一个必须跟着改。`propList: ['*']` 表示所有属性都换，你们要是只想换字号和宽高，就写 `['font-size', 'width', 'height']`。

| 参数 | 含义 | 常用值 |
| :--- | :--- | :--- |
| `rootValue` | `1rem` 对应的像素数 | 750 稿填 75，375 稿填 37.5 |
| `propList` | 哪些属性参与换算 | `['*']` 全换 |
| `selectorBlackList` | 哪些选择器不换 | `['.no-rem']` 排除特定类 |

> **易错点**：行内样式和 `1px` 边框别进换算。`1px` 的细线换成 `rem`，大屏下会粗成 `2px`，丑得很。插件里把 `minPixelValue` 设成 2，或者边框手写 `1px` 并加黑名单，都能保住细线。

配完你们验证一下：源码写 `width: 150px`，编译出来变成 `width: 2rem`，手机 375 下根字号 37.5，算出来 75 像素，正好一半，比例严丝合缝，就可以上线了。

> **结论**：脚本管根字号跟着屏走，插件管像素自动变 `rem`，两件套一配，`rem` 适配就闭环了。下一阶段我们拿这套东西重做登录页，你们会发现量稿、写码、适配一气呵成。
