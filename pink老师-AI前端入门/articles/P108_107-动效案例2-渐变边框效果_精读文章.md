# 107-CSS3 实战：旋转流光渐变边框与 inset 现代语法

在上一节中，我们掌握了基于双倍宽度线性渐变位移实现的“水平流动边框按钮”。

而很多现代前沿科技网站、高端产品展示页中，还有另一种更为吸睛的边框形态：**边框的光芒如同探照灯扫掠、或荧光粒子围着卡片外沿做 360 度匀速旋转绕圈**。

很多人以为这必须依赖复杂的 Canvas 粒子或者 WebGL 着色器才能做出来，其实单纯依靠 CSS3 的旋转变换、伪元素以及一个现代定位新特性，就能以极小的开销完美呈现。

本节我们将彻底解密**旋转流光渐变边框**的实现原理，并学习高阶新语法 `inset` 与 `z-index: -1` 的巧妙运用。

---

## 1. 动效原理解构：四个盒子的“遮天蔽日”

旋转边框流光的底层逻辑依然是“障眼法”，但在层级与结构设计上比普通按钮更加精妙：

```text
旋转流光边框层级模型
+-------------------------------------------------------------+
| 1. 外层容器 .card (父级 relative, overflow: hidden)         |
|    - 规定卡片尺寸 (如 300px × 200px) 与圆角                  |
|                                                             |
|    [ 2. 伪元素 ::before 巨大旋转光盘 (500px × 500px) ]       |
|         - 超大尺寸，居中对齐                                |
|         - 锥形/扇形发散渐变背景                             |
|         - 360° 匀速旋转动画                                 |
|                                                             |
|    +-----------------------------------------------------+  |
|    | 3. 伪元素 ::after 黑色内衬遮挡层 (inset: 3px)       |  |
|    |    - 纯黑背景，上下左右各内缩 3px                   |  |
|    |    - 遮住巨大的旋转光盘，只在边缘露出 3px 光晕      |  |
|    +-----------------------------------------------------+  |
|                                                             |
|    [ 4. 真实内容层 (文字/图标/段落) ]                        |
|         - 居于最上层正常显示                                |
+-------------------------------------------------------------+
```

### 为什么需要四个盒子？
1. **容器盒子（`.card`）**：定义卡片整体大小，并开启 `overflow: hidden` 裁剪掉旋转光盘飞出卡片外面的巨大边角；
2. **旋转流光层（`::before`）**：必须**比父级盒子大得多**（例如卡片是 300×200，光盘做成 500×500 甚至更大）。如果尺寸与父级一样大，旋转到四个角落时就会因为对角线距离不足而露怯、截断；
3. **内衬遮罩层（`::after`）**：卡片内部往往承载着大量图文，内容层本身不适合做遮罩。因此专门拿 `::after` 作为遮挡层，只在四周镂空 3px；
4. **内容层（`div/h3/p`）**：在遮罩层之上承载真实业务信息。

## 2. 核心新知识点详解

### 2.1 现代定位简写：`inset` 属性
在以往我们要让一个绝对定位的子元素距离父级四周均为 `3px`，通常需要书写四行代码：
```css
/* 传统冗长写法 */
position: absolute;
top: 3px;
right: 3px;
bottom: 3px;
left: 3px;
```
现代 CSS 提供了全浏览器广泛支持的复合属性 **`inset`**：
```css
/* 现代极简写法 */
position: absolute;
inset: 3px; /* 等价于 top/right/bottom/left 全部为 3px */
```
如果要分别指定不同间距，语法规则与 `margin/padding` 四值法完全一致：
- `inset: 10px;`（四周全为 10px）；
- `inset: 5px 10px;`（上下 5px，左右 10px）；
- `inset: 0;`（彻底拉伸撑满父级）。

### 2.2 巧妙利用负层级：`z-index: -1`
在添加了 `::before` 和 `::after` 两个绝对定位的伪元素之后，默认情况下定位元素的层级高于标准流内容，导致卡片内部的文字和段落全部被黑色的 `::after` 遮挡住。

传统做法是给文字添加 `position: relative` 并手动拔高 `z-index`。但在复杂组件中，子节点非常繁多，逐一加定位极其繁琐。

**pink 老师的高阶技巧**：
直接给 `::before` 和 `::after` 加上：
```css
z-index: -1;
```
在 CSS 规范中，负的 `z-index` 会让定位元素沉降到**普通标准流内容（如行内文本、块级盒子）的下方**。这样一来，卡片里的文字内容天然无需加任何定位样式，直接就能稳稳浮现在最上方！

## 3. 完整代码实操与调试

### 3.1 HTML 结构
```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>旋转流光渐变边框卡片</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <div class="card">
    <h3>科技创变未来</h3>
    <p>CSS3 360° 旋转光晕动效</p>
  </div>
</body>
</html>
```

---

### 3.2 CSS 核心实现

```css
* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}

body {
  height: 100vh;
  display: flex;
  justify-content: center;
  align-items: center;
  background-color: #0b0c10;
  font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif;
}

/* 1. 外层卡片容器 */
.card {
  position: relative;
  width: 320px;
  height: 200px;
  background-color: transparent;
  border-radius: 12px;
  /* 核心防溢出：裁剪 500px 超大光盘的外部多余部分 */
  overflow: hidden;

  /* 使用 Flexbox 让超大旋转光盘自然垂直水平居中 */
  display: flex;
  flex-direction: column;
  justify-content: center;
  align-items: center;
  color: #fff;
}

/* 2. 伪元素 ::before：超大旋转发光盘 */
.card::before {
  content: "";
  position: absolute;
  /* 尺寸必须远大于父级，确保旋转时四个角落始终有光 */
  width: 500px;
  height: 500px;
  /* 炫彩锥形渐变（光斑扫掠效果） */
  background-image: conic-gradient(
    transparent 70%,
    #00ffff,
    #ff007f 100%
  );
  /* 负层级：下沉到底层，避免遮挡普通文字 */
  z-index: -1;
  /* 绑定旋转动画：3秒一圈匀速无限转动 */
  animation: rotateLight 3s linear infinite;
}

/* 3. 关键帧定义：360度整圈旋转 */
@keyframes rotateLight {
  from {
    transform: rotate(0deg);
  }
  to {
    transform: rotate(360deg);
  }
}

/* 4. 伪元素 ::after：纯黑内衬遮盖层 */
.card::after {
  content: "";
  position: absolute;
  /* 核心语法：四边向内缩进 3px，露出 3px 旋转光芒 */
  inset: 3px;
  background-color: #12131a; /* 稍有质感的深黑底色 */
  border-radius: 9px; /* 内圆角 = 外圆角 12px - 边框 3px */
  /* 同样沉降到底层，但在 ::before 之上遮挡光盘 */
  z-index: -1;
}

/* 5. 卡片文字排版（无需加定位即可自然显现） */
.card h3 {
  font-size: 22px;
  margin-bottom: 8px;
  letter-spacing: 1px;
}

.card p {
  font-size: 13px;
  color: #8892b0;
}
```

## 4. 效果演练与细节剖析

1. **光盘为什么要用 Flexbox 居中？**
   - 如果用传统的 `left: -90px; top: -150px;` 硬算定位偏移，一旦卡片宽度在响应式适配中发生改变，光盘的旋转中心就会偏移，转起来重心不稳；
   - 借助父级的 `display: flex; justify-content: center; align-items: center;`，绝对定位的 `::before` 会被自动吸附并锁死在父级几何中心，任由卡片宽高伸缩，旋转永不偏心！
2. **渐变样式的灵活替换**：
   - 本案例使用了 `conic-gradient` 锥形渐变制造出雷达扫盘的效果；
   - 也可以替换为多色平铺径向/线性渐变，实现类似霓虹彩虹绕圈跑马灯的高阶光效。
