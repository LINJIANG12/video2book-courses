# 102-CSS3 动画 Animation 核心原理与基本使用

在前面的学习中，我们系统掌握了 CSS 的 2D 与 3D 变换。但大家会发现，变换本身只是改变了元素在空间中的静态形态；如果要让它“动”起来，此前我们只能依靠 `transition`（过渡）。

然而过渡有一个致命的局限性：**它只能定义开始和结束两个状态**，中间过程完全无法精细干预，且大多需要用户通过鼠标悬停（`:hover`）等交互来被动触发。为了实现更加丰富多彩、自动循环、多节点精细控制的视觉动效，现代前端全面引入了 **CSS3 动画（Animation）**。

本讲我们将深入剖析动画相比 JavaScript 动效的绝对优势，吃透核心概念——**关键帧（Keyframes）**，并掌握定义动画与调用动画的标准工作流。

---

## 1. 为什么优先使用 CSS 动画？

在早期的网页开发中，很多复杂动效都是靠 JavaScript 定时器（`setInterval` 或 `requestAnimationFrame`）修改 DOM 属性实现的。但在现代前端开发中，CSS 动画已成为绝对的主流选择：

| 维度 | JavaScript 脚本动画 | CSS3 Animation 动画 |
| :--- | :--- | :--- |
| **执行性能** | 频繁触发 JS 引擎执行与重排重绘，容易引起卡顿与掉帧 | 浏览器原生支持，可走独立合成线程与 GPU 硬件加速，性能开销极低 |
| **代码复杂度** | 需要手写时间步长、状态记录与缓动算法，代码量庞大繁琐 | 仅需定义关键节点，中间过渡插值由浏览器内核算法自动补全平滑计算 |
| **状态跨度** | 代码逻辑稍有不慎容易内存泄漏 | 突破 `transition` 仅能设置“开始/结束”两态的局限，可定义任意多节点状态 |
| **触发机制** | 强依赖 JS 逻辑绑定 | 无需用户鼠标操作即可自动播放，亦可与鼠标事件、JS 交互无缝结合 |

---

## 2. 动画核心机制：到底什么是关键帧？

动画的本质是“时间的函数”。要想让一个静态的盒子动起来，核心就在于定义**关键帧（Keyframes）**。

```text
动画插值渲染全景拓扑
+------------------+         浏览器算法自动插值平滑运算         +------------------+
|  起始关键帧 (0%)  | ────────────────────────────────────────> | 过程关键帧 (50%) |
| 初始形状 / 坐标   |                                           | 路径折返 / 形变  |
+------------------+                                           +------------------+
                                                                        │
                                   浏览器算法自动补全                     │
                                                                        ▼
                                                               +------------------+
                                                               | 结束关键帧 (100%)|
                                                               | 终点坐标 / 变半透明|
                                                               +------------------+
```

大家可以将关键帧理解为**时间轴上的状态锚点**：
- 我们只需要向浏览器声明：“在 0% 这个起始时刻，盒子长什么样；在 50% 这个中间时刻，盒子跑到哪里、变什么颜色；在 100% 这个结束时刻，盒子停在何处”；
- 至于从 0% 渐变到 50%、从 50% 渐变到 100% 的全部中间连续画面，**完全交给浏览器底层算法自动计算生成**，从而呈现丝滑连贯的动态视觉。

## 3. 动画开发标准两步法

使用 CSS 动画必须遵循非常严格的两步工作流：**先定义动画，后使用动画**。这就像定义类选择器与在 HTML 标签上引用类名一样，次序不可颠倒。

### 3.1 第一步：使用 `@keyframes` 定义关键帧

语法格式如下：
```css
@keyframes 动画名称 {
  0% {
    /* 初始状态样式 */
  }
  50% {
    /* 中间过程样式 */
  }
  100% {
    /* 结束状态样式 */
  }
}
```

#### 形式 A：百分比多状态定义法（推荐通用写法）
关键帧的节点可以设置任意多个百分比（如 `0%`、`20%`、`50%`、`80%`、`100%`），定义的关键帧越多，动画控制越细腻：
```css
@keyframes movePath {
  0% {
    transform: translate(0, 0);
    background-color: pink;
    border-radius: 0;
  }
  25% {
    transform: translate(300px, 0);
    border-radius: 20%;
  }
  50% {
    transform: translate(300px, 300px);
    border-radius: 50%;
  }
  75% {
    transform: translate(0, 300px);
    border-radius: 20%;
  }
  100% {
    transform: translate(0, 0);
    border-radius: 0;
  }
}
```

#### 形式 B：`from` 和 `to` 简写形式（两状态专属）
如果动画比较简单，仅包含起点和终点两个状态，可以使用 `from` 代替 `0%`，用 `to` 代替 `100%`：
```css
@keyframes moveSimple {
  from {
    transform: translate(0, 0);
  }
  to {
    transform: translate(200px, 0);
  }
}
```

### 3.2 第二步：在目标元素上调用动画

动画定义完毕后本身不会起效，必须指定哪个 DOM 盒子来使用它：
```css
.box {
  width: 100px;
  height: 100px;
  background-color: royalblue;
  
  /* 必须填写的两大基本参数：动画名称 持续时间 */
  animation: movePath 3s;
}
```

- **参数 1（动画名称）**：对应 `@keyframes` 后面声明的自定义名称（大小写敏感，必须完全匹配）；
- **参数 2（持续时间）**：单位必须加（秒 `s` 或毫秒 `ms`，如 `3s`、`2000ms`），不写时间则默认为 0，动画将无法播放。

## 4. 动手实战：盒子巡回与形变动效开发

我们来写一个经典的方形盒子一边移动、一边变成圆形、最终原路巡回闭环的完整案例：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>CSS 动画基本使用实战</title>
  <style>
    /* 1. 先定义关键帧动画 */
    @keyframes squareToCircle {
      0% {
        transform: translate(0, 0);
        border-radius: 0;
        background-color: #ff6b6b;
      }
      50% {
        transform: translate(400px, 200px);
        border-radius: 50%;
        background-color: #4ecdc4;
        opacity: 0.8;
      }
      100% {
        transform: translate(0, 0);
        border-radius: 0;
        background-color: #ff6b6b;
      }
    }

    /* 2. 盒子元素调用动画 */
    .target-box {
      width: 120px;
      height: 120px;
      background-color: #ff6b6b;
      /* 调用动画：名称为 squareToCircle，单次跑完用时 4 秒 */
      animation: squareToCircle 4s;
    }
  </style>
</head>
<body>
  <div class="target-box"></div>
</body>
</html>
```

### 关键细节剖析：
1. **闭环返回**：如果想让盒子平滑归位，可以将 `100%` 的样式设置得与 `0%` 一致（如上例中的 `translate(0, 0)`），这样动画播放完毕后回到原点就不会发生突兀跳变；
2. **多属性复合**：关键帧内部不仅能放 `transform` 坐标位移，还可以同时修改 `border-radius`（边框圆角）、`background-color`（色彩过渡）甚至 `opacity`（透明度渐变），所有属性都会协同自动插值。

## 5. 本讲小结与下节预告

- **核心要点回顾**：
  - CSS3 动画比 JS 动效性能更好，比 `transition` 能支撑更多状态跨度；
  - 核心工作流：先通过 `@keyframes 动画名` 定义关键状态，再用 `animation: 动画名 时长` 调用生效；
  - 关键帧可写百分比（`0%~100%`），两状态时亦可用 `from / to`。
