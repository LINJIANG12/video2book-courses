# 优医问诊图标导航栏第一行制作

头部那片绿铺完，接下来是第二个大盒子：图标导航栏。你们回想一下自己用的 App，不管是美团、京东还是挂号软件，搜索框下面一定跟着一排图标，"扫一扫""付款码""外卖""打车"，点哪里进哪里。我们的问诊首页也一样：在线问诊、预约挂号、名医会诊一排摆开，用户进来第一眼就知道能干什么。

导航栏一共两行，每行 5 个。这一讲我们只做第一行。为什么拆开？因为第一行的结构、尺寸、间距定下来，第二行就是原样复制。把第一行做精，第二行就是体力活。

---

## 1. 导航栏整体定位

### 1.1 白色卡片上浮压住头部

导航栏不是老老实实排在头部下面的，它是一张白色圆角卡片，往上浮起来压住头部底部的绿色。实现手法是负边距：头部底部上一讲多留了 `40px` 的绿，导航栏用 `margin-top` 的负值提上去，两者一盖，层次感就出来了：

```text
导航栏上浮示意 (侧视图)
........ 绿色头部区域 ........
|                            |
|   home-header (绿底)       |
|............................|
|  +----------------------+  |  <- nav 卡片上浮,
|  |  nav (白色圆角卡片)  |  |     盖住头部底部
|  +----------------------+  |
   (灰色页面底色)
```

读图说明：卡片的上半截压在绿底上，下半截落在灰底上，"压界"出现的位置就是视觉的焦点线。

```css
.nav {
  margin: -20px 12px 0;
  background-color: #fff;
  border-radius: 10px;
  box-shadow: 0 2px 8px rgba(0, 0, 0, 0.06);
}
```

> **提示**：负边距只吃掉头部多留的那截绿，不会把搜索框盖住。万一发现搜索框被压住了，说明头部底部的留白和这里的负值没对上，回去对一下两个数，前者必须大于后者。

### 1.2 第一行骨架结构

导航用列表语义：`ul` 包 5 个 `li`，每个 `li` 里一个 `a`，`a` 里上面是图标、下面是文字。图标用 `img` 直接引用素材，文字用 `p` 或 `span` 都行，全站统一即可：

```html
<nav class="nav">
  <ul class="nav-row">
    <li><a href="#"><img src="./images/nav1.png" alt="在线问诊"><p>在线问诊</p></a></li>
    <li><a href="#"><img src="./images/nav2.png" alt="预约挂号"><p>预约挂号</p></a></li>
    <li><a href="#"><img src="./images/nav3.png" alt="名医会诊"><p>名医会诊</p></a></li>
    <li><a href="#"><img src="./images/nav4.png" alt="药品商城"><p>药品商城</p></a></li>
    <li><a href="#"><img src="./images/nav5.png" alt="健康测评"><p>健康测评</p></a></li>
  </ul>
</nav>
```

## 2. 第一行五等分布局

### 2.1 flex 均分与图标尺寸

一行 5 个入口，最干净的写法是 flex 容器，每个 `li` 占一份。`flex: 1` 让五个格子自动均分，屏幕从 375 缩到 320，每个格子跟着等比变窄，图标和文字永远居中：

```css
.nav-row {
  display: flex;
  padding: 14px 0 10px;
}
.nav-row li {
  flex: 1;
}
.nav-row li a {
  display: flex;
  flex-direction: column;
  align-items: center;
}
.nav-row li img {
  width: 48px;
  height: 48px;
}
.nav-row li p {
  margin-top: 6px;
  font-size: 12px;
  color: #333;
}
```

> **定义**：主轴（main axis）是 flex 容器默认的横向排列方向。这里 `li` 沿主轴一字排开 5 个；`a` 内部把主轴转成纵向（`flex-direction: column`），图标在上、文字在下。两个方向各管一层，互不干扰。

图标 `48px` 是设计稿量出来的，圆角图标自带彩色底，视觉上已经足够醒目。文字 `12px` 是移动端辅助文字的标准字号，再小就看不清了，再大一行五个就挤了。

### 2.2 间距取舍

你们注意，`li` 之间我没有加 `gap`，也没有加左右 margin。为什么？五个 `flex: 1` 的格子本身就是均分的，格子之间的空隙天然相等。图标在格子里居中，间距自动均匀。移动端这种"等分格子 + 内容居中"的模式，比手动算 margin 省心得多，也永远不会出现最后一个被挤掉下去的惨剧。
