# 12-创建超级链接以及锚点链接

平时大家上网冲浪，尤其是女孩子买东西的时候，看中哪件衣服或者口红，鼠标移上去变成一只小手，轻轻一点，网页立刻跳转到了对应的商品详情页和购买界面——这就是我们天天都在用的**超级链接（Hyperlink）**。

在 HTML 文档里，超级链接不仅能帮我们把当前页面链接到互联网上的任意网页和文件资源，而且能点的不只是文字，一张图片、一段视频、一个标题甚至整个排版盒子，都可以包裹进链接标签里变成可点击的入口。今天我们就把 HTML 中最核心的跳转武器——超链接以及长网页定位必备的锚点链接，彻底讲透讲明白。

---

## 1. 超级链接基础语法与核心属性

在 HTML 中，我们使用 `<a>` 标签来创建超链接。`<a>` 是英文 `anchor`（锚）的缩写，它是一个标准的**双标签**（`<a>...</a>`）。

### 1.1 链接标签基本语法

创建一个最基础的超链接，骨架如下：

```html
<a href="跳转目标地址" target="目标窗口打开方式" title="悬停提示文字">链接文本或元素</a>
```

在 `<a>` 标签中，最灵魂的核心属性是 `href`（Hypertext Reference，超文本引用）。它负责告诉浏览器：**当用户点击这个链接之后，到底要去往哪个地方**。

> **提示**：前面讲图片标签时我们用的是 `src`（Source），因为图片是从外部把资源“请到我这里来显示”；而超链接用的是 `href`，代表点击后“要去往哪里”，这两个属性千万不要混淆。

### 1.2 链接常用属性全景对比

日常开发中，`<a>` 标签最常用的三大属性如下表所示：

| 属性名 | 含义与作用 | 常见取值 | 默认值 |
| :--- | :--- | :--- | :--- |
| `href` | 指定链接跳转的目标地址或资源路径 | URL 地址、相对路径、`#`、`mailto:` 等 | 无（必填项） |
| `target` | 指定目标网页在哪个窗口中打开 | `_self`（当前窗口）、`_blank`（新窗口） | `_self` |
| `title` | 鼠标悬停在链接上方时显示的提示文字 | 自定义文本字符串 | 无 |

## 2. 内部链接与外部链接实操

根据跳转目标所在位置的不同，超链接最常规的分类是**内部链接**与**外部链接**。

### 2.1 内部链接与页面间跳转

如果链接指向的是我们自己网站内部的其他 HTML 文件，就称为**内部链接**。

例如，我们当前正在编写第 12 课的文件，想在页面中添加一个链接跳回第 11 课的音视频页面，直接在 `href` 中写入目标文件的相对路径即可：

```html
<!-- 内部链接：直接使用相对路径指向本地 HTML 文件 -->
<a href="./11-音视频标签.html">查看第11讲音视频标签</a>
```

保存后在浏览器中预览，鼠标放上去变成小手，点击就会瞬间打开上一节的页面；点击浏览器的“后退”按钮，又能完好无损地退回当前页。

### 2.2 外部链接与协议规范

如果点击之后要跳转到别人的、外部互联网上的网站，就属于**外部链接**。

在书写外部链接时，必须写上完整的网络传输协议（如 `http://` 或 `https://`），不能直接从 `www` 开始写，否则浏览器会误以为这是你本地工程里的某个相对路径：

```html
<!-- 外部链接：必须携带完整的 http:// 或 https:// 协议头 -->
<a href="https://www.deepseek.com">访问 DeepSeek 官方网站</a>
```

### 2.3 窗口打开方式：`target` 属性的权衡

默认情况下，我们点击外部链接跳转到 DeepSeek 官网，会发现**我们自己的页面被直接覆盖替掉了**。

这样好不好？肯定不好！人家别人的网站再好，那也是别人的，咱们辛辛苦苦做的网站怎么能随随便便被别人顶掉呢？合理的体验是：点击链接后，**保留我们当前自己的网页，在旁边重新启动开启一个新的浏览器标签页**。

这就需要借助 `target` 属性来控制：

```text
target 属性控制窗口打开机制
├── target="_self"  (默认值：在当前窗口直接替换打开，原页面被覆盖)
└── target="_blank" (推荐值：空白新窗口打开，保留原页面，新建 Tab 页)
```

实战代码演示：

```html
<!-- 保持自身页面不丢失，新开标签页打开外链 -->
<a href="https://www.deepseek.com" target="_blank" title="国内顶尖 AI 搜索工具">
  访问 DeepSeek 官网（新窗口打开）
</a>
```

> **提示**：`_blank` 前面是一条英文**下划线**，不是减号短横线，很多初学者容易手滑打错导致新窗口失效。

### 2.4 悬停提示文字：`title` 属性在实战中的应用

我们在浏览大型网站（例如小米官网）时，经常会看到鼠标停留在顶部的企业 Logo 图标上时，浮现出“小米官网”的小提示框。这种细节交互就是由 `title` 属性实现的：

```html
<!-- 给 Logo 或关键入口添加 title 提升用户体验与可访问性 -->
<a href="https://www.mi.com" target="_blank" title="小米官网 - 探索黑科技">
  <img src="./images/logo.png" alt="小米Logo" />
</a>
```

## 3. 三种特殊形态的超级链接

在真实工程开发中，除了普通的网页跳转，`<a>` 标签还承载着另外三种特殊应用场景：

### 3.1 空链接（占位链接）

在项目开发初期，某些页面（例如“产品介绍”、“加入我们”）的前端结构还没开发完，或者产品经理还没确定跳转地址，但界面上又必须先放置一个超链接样式。此时我们使用**空链接**进行占位：

```html
<!-- 空链接写法：href 赋值为单个井号 # -->
<a href="#">产品介绍（页面制作中，先占位）</a>
```

当点击空链接时，页面不会发生跨网页跳转，而是会直接跳转到当前页面的顶部，保证链接有点击效果但不会报错 404。

### 3.2 文件下载链接

如果 `href` 属性指向的不是一个网页（`.html`），而是一个**可执行程序或压缩包文件**（例如 `.zip`、`.rar`、`.exe`、`.7z` 等浏览器无法直接解析的内容），浏览器在用户点击时就会自动触发**文件下载**功能。

例如我们在官网上下载微信客户端：

```html
<!-- 指向本地或网络上的压缩包/安装包文件，浏览器将自动下载 -->
<a href="./downloads/WeChatSetup.exe">立即下载微信 Windows 客户端</a>
<a href="./files/course_materials.zip">下载课程全套课件压缩包</a>
```

### 3.3 电子邮箱链接

在个人博客、企业网站的“联系我们”区域，为了方便访客直接给站长发邮件，可以使用邮件协议链接：

```html
<!-- 邮件链接：固定格式 mailto: 后接目标邮箱地址 -->
<a href="mailto:service@company.com">点击给官方客服发送邮件</a>
```

> **易错点**：`mailto:` 是固定写法，冒号必须是英文字符且紧跟在后面不能省略；当用户在电脑上点击该链接时，系统会自动启动默认的邮件客户端（如 Outlook、Foxmail 等）并预填好收件人地址。

## 4. 长文档定位利器——锚点链接

### 4.1 什么是锚点链接？

在阅读篇幅极长的网页时（比如百科词条中刘德华的生平简介，或者 MDN 的超长技术文档），页面内容动辄几万字，用户如果全靠鼠标滚轮往下拖动寻找信息，体验会非常糟糕。

这时候我们通常会在页面顶部或侧边放一个目录：点击“早年经历”，页面瞬间就跳到早年经历区域；点击“主要作品”，页面立刻直达作品表格——这种**在同一个页面内部快速跳转到指定位置**的链接，就叫做**锚点链接（Anchor Link）**。

> **比喻**：锚点就像船在海上抛下的锚。你在目的地插上一枚标记苦无（正如《火影忍者》里四代目水门的黄色闪电飞雷神之术），不管人当前在页面的哪个角落，只要点击链接，瞬间就能定位瞬移过去。

```text
锚点跳转交互逻辑
[点击目录链接] <a href="#part3">跳转到第三部分</a>
       │
       │ (浏览器在当前页面内快速定位并滚向目标元素)
       ▼
[目标内容区域] <h2 id="part3">第三部分：核心原理详解</h2>
```
*图 1：页面内部锚点链接定位流向图*

### 4.2 锚点链接两步实现法

实现锚点链接严格分为标准的两个步骤，顺序不能颠倒：

#### 第一步：在目标位置插旗（定义目标标签的 `id`）
找到你想让页面跳过去的目标标签（例如某个 `<h2>` 或 `<div>`），为该标签添加全局唯一的 `id` 属性作为坐标标记：

```html
<!-- 1. 在目标位置添加 id 属性（id 命名必须全页面唯一，可使用英文、拼音或数字） -->
<h2 id="section3">3. 核心功能与主要作品展示</h2>
```

#### 第二步：创建定位链接（在 `<a>` 的 `href` 中写入 `#id`）
在跳转点击处书写 `<a>` 标签，将其 `href` 属性的值设置为**井号加上刚才定义的 id 名**（`#目标id`）：

```html
<!-- 2. 链接处以井号开头，后接目标标签的完整 id 名 -->
<a href="#section3">直达作品介绍</a>
```

> **结论**：**`id` 叫什么，`href` 里面就必须写 `#` 加什么**。`id` 取名为 `section3`，链接的 `href` 就必须严丝合缝地写成 `#section3`，两者必须完全对应。

### 4.3 锚点链接完整实战代码

我们来看一段完整的长网页多锚点跳转实战演练：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>锚点链接实战演示</title>
</head>
<body>
  <!-- 顶部快捷目录导航 -->
  <h1>课程知识点大纲</h1>
  <a href="#link_internal">1. 内部链接</a><br>
  <a href="#link_external">2. 外部链接</a><br>
  <a href="#link_empty">3. 空链接</a><br>
  <a href="#link_download">4. 下载链接</a><br>
  <a href="#link_mail">5. 邮件链接</a>
  
  <hr>

  <!-- 目标内容区域 1 -->
  <h2 id="link_internal">1. 内部链接</h2>
  <p>内部链接指向当前站点内部的 HTML 页面，使用相对路径书写，支持页面间的双向跳转切换...</p>
  <div style="height: 600px;">（模拟长文档内容填充区域）</div>

  <!-- 目标内容区域 2 -->
  <h2 id="link_external">2. 外部链接</h2>
  <p>外部链接跳转到公网其他站点，必须加上完整协议头，建议配置 target="_blank" 保留原页面...</p>
  <div style="height: 600px;">（模拟长文档内容填充区域）</div>

  <!-- 目标内容区域 3 -->
  <h2 id="link_empty">3. 空链接</h2>
  <p>使用 href="#" 进行占位，当目标路径尚未确定或需回滚到页面顶端时使用...</p>
  <div style="height: 600px;">（模拟长文档内容填充区域）</div>

  <!-- 返回顶部的极简锚点 -->
  <p><a href="#">回到页面顶部 ↑</a></p>
</body>
</html>
```

### 4.4 拓展进阶：开启页面平滑丝滑滚动（Smooth Scroll）

细心的同学在体验 MDN 官方文档的目录点击时会发现：人家点击目录后不是“咔”一下生硬地瞬移到底部，而是非常丝滑柔和地**平滑滑动**过去。

虽然我们还没正式学 CSS，但这里教大家一个仅需一行代码就能极大提升页面质感的高级技巧：在 HTML 页面的 `<head>` 内部写入一段样式，开启全局平滑滚动行为：

```html
<head>
  <meta charset="UTF-8">
  <title>丝滑滚动效果演示</title>
  <style>
    /* 让整个 HTML 页面的锚点跳转呈现平滑滚动动效 */
    html {
      scroll-behavior: smooth;
    }
  </style>
</head>
```

只要加上这行声明，浏览器遇到所有锚点跳转时，都会自动将生硬的瞬间跳帧转换为优雅的平滑移动，交互体验直接上升一个台阶！

## 5. 本讲小结与下节预告

本讲我们系统攻克了 HTML 中关于页面链接与位置跳转的全套核心机制：

1. **链接五种核心形态**：
   - 内部链接：使用相对路径（`href="./other.html"`）；
   - 外部链接：完整协议头 + 新窗口（`href="https://..." target="_blank"`）；
   - 空链接：占位与回顶（`href="#"`）；
   - 下载链接：指向压缩包或程序（`href="app.zip"`）；
   - 邮件链接：调用邮件客户端（`href="mailto:user@mail.com"`）。
2. **锚点链接定位两步法**：
   - 第一步：目标位置插红旗——在目的地标签上写 `id="标记名"`；
   - 第二步：链接处飞雷神——在 `<a>` 的 `href` 中写 `#标记名`。
3. **视觉体验加分项**：借助 CSS 原生属性 `html { scroll-behavior: smooth; }` 一键开启丝滑滚动。
