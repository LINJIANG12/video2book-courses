# 盒子模型视觉重塑：`border-radius` 圆角边框、几何切割原理与多值顺时针体系

我们在前面的课程中学会了给盒子加上各种各样的边框。但大家在日常浏览网页时一定会发现：现代网页里的盒子，几乎没有几个是直挺挺、冷冰冰的硬直角。

不信你们打开淘宝网看一看：商品展示卡片、搜索框两端、促销标签，全部都带着柔和细腻的小圆角；再看看 B 站（bilibili）或者各类主流社交平台，用户的个人头像、热门分类标签，干脆直接就是一个个完美的正圆形。

如果整个网页放眼望去全是一棱一角、如同方砖般的生硬直角，用户的视觉体验会非常生硬、紧张；而恰到好处的圆角弧度，不仅能瞬间抚平界面的锐利感，还能在视觉心理上赋予界面一种温润、亲和与精致的现代质感。

这节课我就带大家系统攻克 CSS3 中的核心视觉属性：`border-radius` 圆角边框。我们将从最基础的数值写法，一步步推导到正圆、胶囊按钮的成型法则，彻底搞懂多值顺时针映射体系，并从底层几何原理层面把“圆角到底是怎么切出来的”彻底讲透。

## 1. `border-radius` 基础语法与核心形变实践

要给一个普通的矩形盒子施加圆角魔法，在 CSS 中使用的是 `border-radius` 属性。

```css
selector {
  border-radius: length | percentage;
}
```

其属性值既可以接受具体的像素长度（`px`），也可以接受相对百分比（`%`）。

### 1.1 像素单位控制微圆角

我们先写一个最基础的正方形盒子，宽高各为 $100\text{px}$，给一个漂亮的粉色（`pink`）背景：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>圆角边框初体验</title>
  <style>
    .box1 {
      width: 100px;
      height: 100px;
      background-color: pink;
      border-radius: 10px;
    }
  </style>
</head>
<body>
  <div class="box1"></div>
</body>
</html>
```

在浏览器中运行这段代码，你会立刻发现盒子的四个尖角不再是 $90^\circ$ 的直角，而是变成了向内平滑过渡的小圆弧。

> **结论**：当你给 `border-radius` 赋予一个单一数值时，该数值将同时、对称地作用于盒子的**全部四个角**（左上、右上、右下、左下）。

### 1.2 动态调试推导：从微圆角到正圆形的临界跃迁

为了让大家亲眼看清圆角数值对盒子形态的影响，我们在浏览器中按 F12 打开开发者工具，选中该元素，将光标定位在 `border-radius: 10px;` 上，然后按下键盘的向上方向键，让数值逐像素递增：

```text
数值递增演变过程：
10px ──> 20px ──> 30px ──> 40px ──> 50px
[微圆角] ───────────────────────────> [正圆形]
```

随着数值从 10、11、12 不断调大，盒子的四个直角被削掉的面积越来越大，四条边迅速向内弯曲收缩。当数值一路增加到 **50px** 的瞬间，原本方方正正的盒子完全蜕变，变成了一个标准、完美的**正圆形**！

为什么偏偏是 50px？

请大家仔细观察这里的数学关系：
- 盒子的宽度：$W = 100\text{px}$；
- 盒子的高度：$H = 100\text{px}$；
- 临界圆角值：$R = 50\text{px}$；
- 核心等量关系：$50\text{px} = \frac{100\text{px}}{2} = \frac{W}{2} = \frac{H}{2}$。

原来，当圆角半径恰好等于正方形边长的一半时，相邻两角的弧线会在边长的中点处完美相切闭合，四个 $90^\circ$ 的扇形圆弧无缝拼接成一个完整的 $360^\circ$ 正圆！

如果换成 $120\text{px} \times 120\text{px}$ 的盒子，要切出正圆该设多少？数学好的同学脱口而出：“60px！”如果是 $138\text{px} \times 138\text{px}$ 呢？难道我们写代码还得随身带个计算器去算除法吗？

根本不需要！CSS 允许我们直接写**百分比**：

```css
.avatar {
  width: 100px;
  height: 100px;
  background-color: pink;
  /* 无论是 100px、120px 还是任意尺寸，直接写 50% 永远是正圆 */
  border-radius: 50%;
}
```

> **定义**：**正圆形制作法则**
> 1. 元素必须是一个严格的正方形（即 $\text{width} == \text{height}$）；
> 2. 将 `border-radius` 设置为边长的一半（如 `50px`）或直接设置为 `50%`。

不仅 `<div>` 容器可以这样用，页面中的 `<img>` 图片标签也完全通用。比如在做移动端或游戏出装推荐（如王者荣耀中“反伤刺甲”等装备圆形图标）、用户圆形头像时，直接给正方形图片设置 `border-radius: 50%;`，就能秒变圆形图标，无需借助外部作图软件切图。

```html
<img src="armour.webp" alt="反甲装备图标" class="armour-icon">

<style>
  .armour-icon {
    width: 80px;
    height: 80px;
    border-radius: 50%;
  }
</style>
```

### 1.3 胶囊按钮（跑道形）构建算法：短边折半原则

除了正圆形，我们在京东、淘宝、MDN 等各大网站的搜索栏、分类筛选条、登录/注册按钮上，最常见的是一种两头完全圆润呈半圆形、中间为水平延伸矩形的样式——俗称**胶囊按钮（Pill Button）**，也有人形象地称之为“跑道形”。

```text
胶囊按钮结构分解：
┌──────┬──────────────────────────┬──────┐
│ 半圆 │         矩形主体         │ 半圆 │
└──────┴──────────────────────────┴──────┘
  左端 (R)                        右端 (R)
```
*图 1：胶囊按钮两侧半圆与中间矩形衔接示意图*

胶囊按钮不再是正方形，而是一个矩形（例如宽 $200\text{px}$，高 $40\text{px}$）。如果直接给它写 `border-radius: 50%`，它不会变成标准圆弧胶囊，而是会被压成一个被压扁的“椭圆”。

要做出标准平直、两端为饱满半圆的胶囊按钮，应当如何设定？

我们再次进行逻辑推导：
- 胶囊两端的圆弧是由上下两条长边向内弯曲交汇形成的；
- 这两个半圆的最大直径，完全受限于盒子的**较短边**；
- 水平横向胶囊的短边是**高度（height）**。要让高度两侧完全收缩为半圆，圆角半径必须等于**高度的一半**：$R = \frac{\text{height}}{2} = \frac{40\text{px}}{2} = 20\text{px}$。

```css
/* 水平胶囊按钮标准写法 */
.capsule-horizontal {
  width: 200px;
  height: 40px;
  background-color: skyblue;
  border-radius: 20px; /* 取较小值高度 40px 的一半 */
}
```

同理，如果是垂直竖向的胶囊（宽 $40\text{px}$，高 $200\text{px}$），此时短边变成了宽度，那么圆角半径就应当取**宽度的一半**：

```css
/* 垂直胶囊条标准写法 */
.capsule-vertical {
  width: 40px;
  height: 200px;
  background-color: skyblue;
  border-radius: 20px; /* 取较小值宽度 40px 的一半 */
}
```

> **定义**：**胶囊形（跑道形）制作法则**
> 无论是横向还是纵向矩形，只要将 `border-radius` 设置为**较短边（较小值）的一半**，即可呈现标准胶囊按钮效果。

在真实商业开发中，我们在还原设计稿时可以直接利用设计稿测量工具，鼠标移到对应的圆角卡片上查看标注（例如标注为 $40\text{px}$ 或 $20\text{px}$），直接抄录量取的像素值即可。

## 2. 多值语法与顺时针映射体系

在很多高阶 UI 场景中，盒子的四个角并非千篇一律全部磨圆。

例如：
- 淘宝的促销商品卡片：为了形成折角视觉差，可能只将**左上角**和**右下角**削圆，而右上角和左下角保持硬直角；
- 社交软件的聊天气泡：说话人发出的气泡，右上角保留直角指明出处，其余三个角磨圆；
- 王者荣耀等游戏界面的角色面板：对角线两端呈现极具科幻感的圆角，其余对角保持锐利直角。

这就要求我们必须掌握 `border-radius` 的多参数赋值体系。

### 2.1 参数个数与方位映射规则

`border-radius` 复合属性后面可以跟 1 个、2 个、3 个或 4 个数值，各个数值之间用**半角空格**隔开：

```text
盒模型四个角的空间分布基准：
         [左上角 top-left]        [右上角 top-right]
                 ┌────────────────────────┐
                 │                        │
                 │                        │
                 └────────────────────────┘
        [左下角 bottom-left]     [右下角 bottom-right]
```
*图 2：盒子模型的四个物理角方位分布*

很多同学容易记串：什么时候是上下左右？什么时候是对角线？其实记忆诀窍非常直观：
1. **第一个值永远、无条件指向【左上角】**；
2. 整体流向遵循钟表运转的**顺时针规律**（左上 $\rightarrow$ 右上 $\rightarrow$ 右下 $\rightarrow$ 左下）；
3. 数值缺失时，遵循**对角镜像对齐**原则。

| 声明形式 | 参数解析与对应角 | 典型视觉形态与应用场景 |
| :--- | :--- | :--- |
| `border-radius: A;` | 四个角全部为 `A` | 统一圆角矩形、正圆（50%） |
| `border-radius: A B;` | **A**：左上 + 右下（主对角线）<br>**B**：右上 + 左下（副对角线） | 柠檬叶片形、对称斜切卡片、王者荣耀角标 |
| `border-radius: A B C;` | **A**：左上角<br>**B**：右上 + 左下（副对角线）<br>**C**：右下角 | 顶部单边圆角、非对称特殊气泡 |
| `border-radius: A B C D;` | **严格顺时针次序**：<br>A: 左上 $\rightarrow$ B: 右上 $\rightarrow$ C: 右下 $\rightarrow$ D: 左下 | 完全自由定制的异形四角卡片 |

### 2.2 典型多值代码推导验证

我们通过具体的 CSS 声明来一一对照渲染机制：

#### 单值情况：
```css
.radius-1 {
  width: 100px;
  height: 100px;
  background-color: pink;
  border-radius: 10px; /* 左上、右上、右下、左下皆为 10px */
}
```

#### 双值情况（主副对角线）：
```css
.radius-2 {
  width: 100px;
  height: 100px;
  background-color: orange;
  /* 两个值之间必须用空格隔开 */
  border-radius: 10px 30px;
}
```
- 第一个值 `10px` 赋给【左上角】与对角线的【右下角】；
- 第二个值 `30px` 赋给【右上角】与对角线的【左下角】；
- 盒子渲染出来像一片活泼的柠檬或者倾斜的树叶，具有强烈的视觉张力。

#### 三值情况：
```css
.radius-3 {
  width: 100px;
  height: 100px;
  background-color: pink;
  border-radius: 10px 30px 50px;
}
```
- 左上角独占第一个值：`10px`；
- 对角线上的两个角（右上角与左下角）共享中间的值：`30px`；
- 右下角独占最后一个值：`50px`。

#### 四值情况（顺时针闭环）：
```css
.radius-4 {
  width: 100px;
  height: 100px;
  background-color: pink;
  border-radius: 10px 30px 50px 70px;
}
```
- 严格按照顺时针方向依次赋值：
  1. 左上角：`10px`
  2. 右上角：`30px`
  3. 右下角：`50px`
  4. 左下角：`70px`

### 2.3 局部直角与 `0` 值占位原则

如果在业务开发中，我们只需要某些角是圆角，而某些角必须维持 $90^\circ$ 的标准尖锐直角，应该怎么写？

> **注意**：如果某个角不需要圆角，**绝对不能直接把该位置的数值省略不写**！在多值语法中，一旦省略数值，参数总数就会减少，导致剩余数值被浏览器按照两值或三值的规则错误重配。保持直角必须**显式书写 `0`（或 `0px`）**进行位置占位！

例如，我们要实现淘宝与电商中极具辨识度的“对角圆角卡片”（仅左上与右下磨圆 $12\text{px}$，右上与左下为直角）：

有两种标准书写方式：

**写法一（极简双值对角线法，推荐）：**
```css
.diagonal-box {
  /* 第一个值给主对角线（左上+右下），第二个值 0 给副对角线（右上+左下） */
  border-radius: 12px 0;
}
```

**写法二（严谨四值顺时针法）：**
```css
.diagonal-box-full {
  /* 顺时针依次为：左上(12px) -> 右上(0) -> 右下(12px) -> 左下(0) */
  border-radius: 12px 0 12px 0;
}
```

两种写法渲染出的结果完全等价，在实际项目中优先使用更简练的双值对角线写法。

## 3. `border-radius` 底层数学与几何切割原理

很多同学会好奇：计算机底层到底是怎么通过 `border-radius` 把一个方形的盒子弄出圆角的？为什么设置了 50% 刚好能切出圆？

要彻底理解这一过程，我们必须回归 `border-radius` 的英文原意：
- `border`：边框；
- `radius`：在数学几何中代表**半径**（尤其是圆或球的半径）。

### 3.1 四角内切辅助圆裁剪模型

当你写下 `border-radius: 50px;` 时，浏览器的排版渲染引擎在底层实际上执行了如下几何运算：

1. 以盒子的物理顶点作为坐标基准，在内侧以声明的尺寸（如 $50\text{px}$）为半径，分别绘制一个虚拟的**内切辅助圆**；
2. 内切圆的一条水平半径与盒子的水平边界重合相切，一条垂直半径与垂直边界重合相切；
3. 辅助圆圆弧与边界形成的公共相交区域被完整保留下来；
4. 而辅助圆弧线外侧、原本直角顶点包裹的多余三角形锐角区域，被渲染引擎全部**裁剪（clip）丢弃**！

```text
单个直角顶点内切圆裁剪几何机理图：
      切点 P1 ┌───────────────────────────> 盒子上边框
        │     │
        ▼     │
  ━━━━━━┳━━━━━┷━━━━━━━━━━━━━━━━━━━━━━━━━━━━
        ┃    / \ 
        ┃   /   \ 
        ┃  /     \  内切圆圆弧 (保留)
        ┃ /       \
        ┃/         \
  ──────╂───────────○ 圆心 (Center)
        ┃\         /│
        ┃ \       / │
        ┃  \     /  │ 半径 R
        ┃   \   /   │
        ┃    \ /    │
        ┃     ▼     ▼
  ──────┨─── 切点 P2 ─────────────────────> 盒子左边框
  ▲     ┃
  │     ┃
  └─────┴─ 原直角尖峰区域（弧线外侧被截断丢弃）
```
*图 3：单角内切圆圆弧保留与外侧直角尖角裁剪机理*

### 3.2 正方形与 50% 切圆的严密闭环

当元素为一个长宽均为 $2R$ 的正方形时：
- 四个角的内切辅助圆半径全部为 $R$（即边长的一半）；
- 四个圆的圆心在几何位置上全部重叠，汇聚在正方形的**正中心点**；
- 四段 $90^\circ$ 的象限圆弧在四条边长的中点处彼此精确相切、无缝咬合，最终在屏幕上留下一个以盒子中心为圆心、以边长一半为半径的标准圆形；
- 原本属于正方形四个角的多余直角三角形材质，被完全裁剪一空。

这就是为什么 `border-radius: 50%` 能精准把正方形切成圆形的底层数学本质。

## 4. 综合实战：王者荣耀英雄卡片与对角视觉构筑

结合前面所学的所有知识，我们来完整还原王者荣耀英雄展示界面的对角圆角卡片。

卡片特征要求：
1. 容器内嵌套英雄海报图片（如英雄夏侯惇 `w3.webp`）；
2. 呈现非对称的科技感切角：**左上角**与**右下角**呈现大圆弧（$15\text{px}$），**右上角**与**左下角**保持硬直角（$0$）；
3. 辅以精致的浅天蓝色高亮描边，强化边缘层次。

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>王者荣耀对角圆角卡片实战</title>
  <style>
    /* 英雄卡片图片容器样式 */
    .hero-card {
      display: inline-block;
      /* 给图片赋予边框 */
      border: 2px solid skyblue;
      /* 
        利用双值对角线映射规则：
        第一个值 15px：作用于左上角、右下角
        第二个值 0：作用于右上角、左下角，保持硬直角
      */
      border-radius: 15px 0;
    }
  </style>
</head>
<body>
  <!-- 直接给图片应用样式，展示王者荣耀本命英雄夏侯惇 -->
  <img src="images/w3.webp" alt="王者荣耀夏侯惇" class="hero-card">
</body>
</html>
```

#### 关键参数逻辑解析：
- `border: 2px solid skyblue;`：设置了 2 像素宽的实线天蓝色描边。当元素被施加圆角时，边框会沿着 `border-radius` 算出的几何圆弧平滑弯折，绝不会出现边框脱轨破损的情况；
- `border-radius: 15px 0;`：利用极简的双值映射，精准将两组对角线分离开来。左上与右下圆润，右上与左下锐利，极具动感与辨识度。

准备一张尺寸自定的图片或正方形盒子，要求：

2. 使盒子的**左上角**与**右下角**具备 $15\text{px}$ 的圆角；
3. 使盒子的**右上角**与**左下角**保持绝对的直角（$0\text{px}$）。

#### 【参考答案与解析】
```css
.test-hero {
  width: 120px;
  height: 120px;
  border: 2px solid skyblue;
  /* 方式一：双值对角线写法（推荐） */
  border-radius: 15px 0;

  /* 方式二：四值顺时针完整写法（等价） */
  /* border-radius: 15px 0 15px 0; */
}
```
**解析依据**：双值语法中，首值赋给主对角线（左上与右下），次值赋给副对角线（右上与左下）。直角处赋值 `0` 即可锁定为硬直角。

### 练习 2：右下角单角直角卡片（缺角卡片）

#### 【题目要求】
制作一个尺寸为 $200\text{px} \times 120\text{px}$ 的信息卡片，背景色自定：
要求该盒子的**右下角**保持纯直角（无圆角），而其余三个角（左上角、右上角、左下角）均具有 $20\text{px}$ 的圆角。

#### 【参考答案与解析】
```css
.card-missing-corner {
  width: 200px;
  height: 120px;
  background-color: #f5f5f5;
  border: 1px solid #ddd;
  /* 
    顺时针四值顺序：左上(20px) -> 右上(20px) -> 右下(0) -> 左下(20px)
  */
  border-radius: 20px 20px 0 20px;
}
```
**解析依据**：因为只有右下角为直角，无法用简单的两值对称表示。依据顺时针流向：左上（$20\text{px}$）、右上（$20\text{px}$）、右下（$0$）、左下（$20\text{px}$），右下角位置必须严格写入 `0` 进行占位，其余三个方位填入目标圆角值，即可实现精准的单角直角切面。
