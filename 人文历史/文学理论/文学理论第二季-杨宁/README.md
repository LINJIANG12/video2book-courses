# 文学理论课程全集 第二季（杨宁）（28 讲）

杨宁老师 2021 年秋季《文学理论》全集第二季（28 讲），延续第一季的「四要素」框架做纵深化：绪论讲清「理论是什么」，然后依次进入文学的本体视域（定义方式、文学事件论、审美文化与虚拟情境、文学语言、后情感、文学形象与真实、审美意识形态论争）、文学的作者视域（作者之死与权力话语、意图谬误、灵感与想象）、文学的读者视域（文学经典的建构与命运、阐释学、还原论与接受论）、文学的文本视域（抒情性作品）。28 讲整编为 4 册模块全书与 5 篇主题复习笔记。

- **原视频**：[文学理论课程全集 第二季（28讲）（ 2021年秋）](https://www.bilibili.com/video/BV1EG4y187wq) — Bilibili，BV1EG4y187wq
- **全 28 集**，已产出 4 册模块全书、5 篇复习笔记、28 份逐字稿

## 怎么学

- **先修第一季**：本季所有论题都挂在第一季立好的「四要素 + 本体论」框架上，术语（陌生化、期待视野等）不再重讲，直接深化。
- **本体视域是重头**：8 讲从「文学怎么定义」一路推到「审美意识形态论争」，笔记 02 是本季信息量最大的一篇，建议先读它的框架图再进各节。
- **作者视域抓两条线**：「作者之死」的理论脉络与「灵感—想象」的创作心理学是两条独立线索，笔记 03 分开整理。
- **经典与阐释连着读**：笔记 04 从「经典何以成立」过渡到「阐释何以合法」，还原论与接受论两派的对照是本段核心。
- **抒情性作品补叙事之外的另一半**：第一季重叙事学，本季文本视域专讲抒情，笔记 05 与第一季笔记 05 对照着看。
- **考前只看 `notes/`**：5 篇笔记按视域重组，概念谱系与论争焦点并排放置。
