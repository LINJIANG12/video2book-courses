# 绪论：理论与文学理论

## 理论的重要性

* **国家与个人都离不开理论**

    * 国家层面：自然科学、理科发展得比较弱，落后的是物质、是生活；文科比较落后，落后的就是思想，而社会的发展进步恰恰需要思想。

    * 个人层面：将来要成为一个什么样的人、要走什么样的道路，支撑你的是理论；阅读文学作品的时候，需要的还是理论。

    * 《觉醒年代》从 1915 年开始讲述：那个时刻是中国近代社会以来最薄弱的时刻、从封建社会走向现代社会最薄弱的环节，李大钊、陈独秀始终在寻找的就是"理论"两个字，最后选择了马克思主义理论。

* **"文科无用"的感觉从何而来**

    * 原话"文科生太多"讨论的是文科生的多少问题，到了网络舆论中变成文科有没有用的问题——关注点这样一漂移，恰恰说明大家真正关心的是文科到底有没有用。

    * 文科给人"没用"感觉的原因：人们习惯性地认为，文科对推动社会历史发展进步、对生产力的发展，好像没有什么直接的作用。

## 理论的词源与本义

* **理论（theory）**

    * > **定义**：理论的本意是一种冷静地站在旁边的观看，一种观察和沉思活动；它要求用审视的眼光，去看一切关于文学阅读的活动。

    * 词源：英语 theory 源自拉丁语 theoria，theoria 是对希腊语的音译，与 theater（剧院）同根，本义是"去观看"。

    * 观察意味着非沉浸式：有理论思考的阅读要冷峻、要跳出来，追问"在我刚才沉浸的过程当中发生了什么"——一个人沉浸在其中的时候，他身上发生了什么，他自己恰恰是看不见的。

    * 跳出来不是不让你沉醉、沉浸，而是你要有反思。

    * > **提示**：中文系的学生要拒绝文艺青年式的自我陶醉——看到一部作品就"哇，好感动"，那是进去了，不是观看。

## 理论与反思

### 反思的内涵

* **反思**

    * > **定义**：反思是一种事后思维——跳出刚刚的沉浸与行动，在事后反复追问"刚才发生了什么"。

    * 反思是理论的一个非常重要的品格。

    * 为什么要反复思考：我们的喜好、我们的热爱，可能并非我们以为的那样出自自己的内心，而很可能是被控制的结构。

* **选择发生在比较结构之中**

    * 旅行社实验：去罗马与去巴黎都包吃住、都是 1800 美金时，选择基本各占 50%，因为这两个选项在后边没有任何区别；追加一个无人会选的"巴黎只包吃不包住 1800 美金"之后，这个毫无意义的选项衬托出"巴黎包吃住"更有价值，让更多人倒向它。

    * 不需要别的，只需要多增加一个选项，就能控制你的选择；个别坚持选罗马是自由，但在大数据上，大量的选择一定会做出这样的统计结构。

    * 人做出选择、做出喜好、付出热爱的时候都是在比较当中选出来的，人的内心当中并没有一个明确的普遍标准。

    * 阅读同理：当喜好一部作品、热爱它、沉浸在其中的时候，要跳出来看一看——我是真的喜欢吗？这个过程当中到底发生了什么？

    * 中学语文课程当中学到的很多知识都非常值得反思；每一次反思都是一个非常重要的理论问题，都可以写成一篇毕业论文。

### 静夜思的二元对立分析

> 床前明月光，疑是地上霜。举头望明月，低头思故乡。

* 反思的起点：这首诗表达思乡没有问题，但要追问"这首诗到底好在哪里"——传颂广被归因于简单（阅读上几乎没难度），可没难度的诗多了去了，唯独这一首成了小学必学，肯定有独特的地方；"因为是李白写的"也有道理，但李白写的也很多。

* **二元对立结构**

    * 有人从文学理论的角度对这首诗进行了分析，发现它当中有一整套二元对立结构。

    * 形式基础：前两句严格意义上是陈述句——"疑是"两个字代表明月光与地上霜之间有相似关系，共同点在于都是白的；后两句是对偶句。

    * > **易错点**：⚠️ 远近这组最容易答反——"床前明月光，疑是地上霜"都是眼前之景，属近；"举头望明月，低头思故乡"才是远——望向天边，想向千里之外。

| 对立轴 | 前两句 | 后两句 |
| :--- | :--- | :--- |
| 虚实 | 月光实，霜虚（"疑是"想象出来的结果） | 明月实（实实在在望见），故乡虚（只存在于心里） |
| 远近 | 近：明月光就在床前 | 远：明月在天上，故乡在千里之外 |
| 有意无意 | 无意看到 | 有意为之：举头、低头是主动行为 |
| 有限无限（主观客观） | 月光客观有限，霜主观无限 | 明月客观有限，故乡主观无限 |

* 四个重要意象各占一个象限（横轴是远近，纵轴是有限与无限、客观与主观）：

    ```text
                     无限（主观）
                         │
             霜（近）    │    故乡（远）
                         │
      近 ────────────────┼──────────────── 远
                         │
             月光（近）  │    明月（远）
                         │
                     有限（客观）
    ```

* 这首诗虽然只有四句，却构成了两两相对的叙事关系；它的重点全放在后面的意象上，"床前""举头""低头""疑是"这些字几乎没有什么太大的直接意义。

* **结构主义**

    * 这种把意象放进对立结构的分析方法，就是文学理论当中经常说的结构主义；结构主义从某种程度上源自反思——表达什么思想大家都知道，要追问的是这首诗背后的结构到底是什么、它为什么具有某种美感。

    * 对这种结构主义的分析有很多人不太认同，但它确实是一种分析方法。

    * 据此得出的判断：《静夜思》之美在于**在有限当中把握到了无限，在瞬间当中把握到了永恒**——通过一个生活当中的短小片段，想到了一个人类共鸣的集体情感。

## 理论与常识

### 常识与理论的分界

* **常识**

    * > **定义**：源自经验、因被普遍接受而成立的观念系统——大家都这么说、大家都这么做，于是它就成了常识。

    * 常识与理论的共同点：二者背后都是一整套的观念系统，都是一种观念。

    * 边界：常识解决不了经验之外的事情；如果永远停留在常识当中，认知就永远没办法突破、没办法打开，只能停留在某种舒适圈之中。

* **理论与常识的关系**

    * 乔纳森·卡勒给理论下的四个定义当中，第二条就是理论与常识：理论是对常识的某种批评。

    * 理论反思的对象就是常识——常识是理论的对象。

    * 理论源自反思而非经验，是经过过滤之后的常识、被证明之后的某种观念体系。

    * 理论并不是非要跟常识作对，而是说常识必须经过理性的过滤，它最重要的特征是要源自证明。

    * 键盘侠、网络喷子分析问题的逻辑停留在某些常识层面上：必须坚守住常识作为认知的边界，不愿意接受跟自己观念、经验不相同的事物，于是产生网络上的一大堆争议——争议源自"我恪守住我这个边界，只要跟我不一样的，我就反击"。

    * 搞理论的人要学会具有包容性，所有观点兼容并包——不是上来就反击，而是思考对方为什么这么说、出于什么这么说、这么说的理由是什么。

| | 常识 | 理论 |
| :--- | :--- | :--- |
| 来源 | 经验：大家都这么说、这么做 | 反思：经过理性过滤 |
| 成立方式 | 因被普遍接受而成立 | 被证明之后的观念体系 |
| 能力边界 | 解决不了经验之外的事情 | 可以追问经验背后的结构 |

### 三观评判标准的追问

* 常识层面的高赞答案："作品可以写三观不正的事情，但是不能宣扬这种三观不正，作者不能宣扬它"——这话对，但它停留在常识的层面上、经验的层面上；从理论层面上说，假设它是对的，依旧有很多问题没有解决。

* 追问一：我怎么知道作者对这种三观不正，是宣扬还是贬低？去问作者吗？作者死了怎么办？就算作者还活着，他跟你说的是实话吗？

* 追问二：用"三观不正的坏人有没有好下场"来判断也不够——就算写坏人没有好下场，如果对坏人的作恶行为写了非常丰富的心理描写和细节描写，以至于读者认同了这个坏人，坏人死掉时读者产生的不是"你终于死了"，反而是心疼感甚至凄美感，即所谓的 BE 美学。

* 追问三：坏人有了好下场就是三观不正吗？文学作品中有一种手法叫反讽——虽然表面上在写他，事实上表达的是相反的意思，通俗的说法叫"高级黑"；闻一多《死水》"这是一沟绝望的死水"描写的全都是丑的东西，但恰恰是以另外一种方式呼唤美。

* 判断很难：它既涉及作者写作时是一种什么样的意识形态观念，也涉及读者接受时是一种什么样的心态——不能以结局的好坏来评判，也不能简单地以作者写作的目的来评判，不能一概而论。

* 专业分析方式：用大量的文学作品、举大量的例子去分析文学与道德之间的关系——这个关系绝对不是简单的一句正向、逆向就能说清的；上来一句"可以写，但是不能宣扬"，对，但是还不够，作为文学理论专业的同学差太多了。

## 理论与阐释

### 理论的三个基本描述

* **雷蒙德·威廉斯的三个描述**

    * 出处：《关键词：文化与社会的词汇》——通过对每一个关键词做历史性的、考古性的梳理，挖掘其原始内涵以及它跟社会之间的联系；"理论"是书中的重要关键词。

    * 第一，理论是一种观念体系、思想系统：任何人都离不开理论，只要在思考着、在行动着，理论就跟你发生密切关系——下课后去食堂吃饭还是回宿舍睡觉、到了食堂吃这个还是吃那个，抉择背后都是理论；不一定是文学理论，但一定是某种理论。

    * 第二，理论还包含着推测、思索的意味：理论是基于某种观念进行的某种推测——三个描述当中与阐释关系最密切的一层。

    * 第三，理论的生成源于人把握深层世界的欲望：人们总希望找到这个世界的某种本质规律，尽管事实上也很难。

### 传统理论与现代理论

* "理论"这个概念是一个历史概念，有传统的理论和现代理论的区别。

* 传统理论：本质上就是找规律——找一个事物背后的本质、规律；这没什么问题，但找本质、找规律容易使理论变成一种工具，就像做数学题抓住公式就能解决其他同类问题。

* 现代理论：有些事物太过复杂，很难找到统一的本质和规律，于是近现代理论更多走向了阐释。

* 学习理论需要两种能力：第一种是反思的能力，第二种是分析和阐释的能力——反思是发现问题，阐释是解决问题。

* 自然科学的理论确实是某种工具；人文科学的理论不是工具——如果仅仅把它理解为工具就大错特错，因为人文科学当中很难找到一个唯一确定的答案。

* > **注意**：传统的这种观念不是有什么错，而是它容易把理论沦为工具。

| | 传统理论 | 现代理论 |
| :--- | :--- | :--- |
| 追求 | 找本质、找规律 | 走向阐释 |
| 特点 | 抓住公式就能解决同类问题 | 承认事物复杂，难有统一答案 |

### 阐释的非唯一性

* **卡勒的分手例子**

    * 出处：乔纳森·卡勒《当代学术入门：文学理论》，用日常聊天的例子说明理论在聊天过程中的生成。

    * "麦克和劳拉分手了，因为麦克劈腿了"——这种解释一望而知，不叫理论。

    * "分手是因为劳拉喜欢一个像她父亲那样的男人，但是麦克做不到"——基于某种阐释的观念、基于某种理论给出的解释，这就叫理论；这种解释对不对并不重要。

    * 人文科学的理论不具有唯一性，没有绝对的可查实性，也不具有绝对的确定性——它仅仅在于它本身的自洽和逻辑上。

* **文科为什么"不靠谱"**

    * 原因之一是没有办法验证、不具有可验证性：理科可以做实验，只要实验可被验证大家就得服；文科没法证明——《静夜思》到底是什么意思，把李白叫出来都不叫证明。

    * 关键不在证明而在理由：你可以任意给说法（哪怕说《静夜思》是李白在练功、修仙），但你得给出基于什么；理由足够充分，你的说法就成立。

    * 《静夜思》表达思乡之所以被基本共同承认，靠的是文本依据（诗中说了"低头思故乡"）加上月亮与中国古代思乡之间的密切联系。

* **春晓的读法**

    * > 春眠不觉晓，处处闻啼鸟。夜来风雨声，花落知多少。

    * 读法一（惜春）：睡了个大懒觉、被鸟吵醒（估计快到中午）、夜里依稀刮风下雨、出门发现花儿都落了——春天快过去了，这么美好的春天就这么快过去；小学教的"喜爱春天、热爱春天"有道理，但要建立在惜春的基础上；再进一步，诗人想表达的可能是对时光逝去的无奈与淡淡的忧伤——春天过去了明年还会再来，美好青春过去了就再也不会再来了。

    * 读法二（偏重结构主义）：前两句是室内空间，后两句是室外空间，表达一种超然物外的心态——夜来风雨声，外边花落了多少跟我有什么关系，我独自在屋里睡觉，站在更高的角度看待世间万物。

    * 这种解读注意到了诗的两层空间结构，但要反驳也可以反驳（如有人说这与孟浩然的思想倾向不符合）；争议可以继续探讨、写成文章分析——这些本质上都是某种阐释、某种推测，而且绝非毫无意义的推测。

* > **提示**：不光精神分析理论"不靠谱"，所有理论严格意义上讲都不靠谱，因为它们都不具有科学性；搞文学的人不要在乎科学不科学，而在乎合理不合理——文学恰恰讲的不是确定唯一。

## 理论与实践

* **"一切理论都是灰色的"**

    * 歌德借魔鬼之口说："一切理论都是灰色的，而生命之树常青"——这句话被很多人拿去当厌恶理论、反抗理论的人的引用，言下之意是理论不重要。

    * 中学教的"理论源于实践，同时又指导实践"再被推一步就变成：理论既然源于实践，那我干嘛还要学理论，直接实践就行了，实践出真知——很多人就是用这套观念反对理论的。

* **质疑一：实践多样，理论也该多样**

    * 理论源于实践——这点承认；但实践的对象是丰富的、多样的，那么理论也应该是丰富的、多样的、具体问题具体分析的。

    * > **易错点**：⚠️ 某种理论有僵化教条的感觉，一定是这个理论出了问题——它错了，而不是"理论本身"有问题；僵化教条的东西根本不是正确的理论。

* **质疑二："实践"到底是什么**

    * 一般讲的实践就是"做"、干一件事（种花种草、打扫卫生）；但它背后是一个非常复杂的理论问题，今天学术界依旧争议极多。

    * 正在写一部小说，算实践；没动笔、只在脑子里思考这部小说应该是什么样子，按教材观点也是一种生产实践——只不过这种生产叫精神生产；生产分为两种：物质生产与精神生产（教材"文学创造"一章讲的就是文学创造作为一种精神生产）。

    * 争论焦点：到底存不存在"精神实践"这个东西——你认为实践只具有物质性，还是实践也具有精神性；当今美学界实践美学、后实践美学、新实践美学之争的焦点其实就在这里。

    * 现在大部分人认为实践是有精神性的；把"写"与"构思"完全割裂开是有问题的——不写、打电脑也是个实践过程；把小说说出来算实践，那不说出口、只在脑子里说，凭什么说它不是实践？

    * 追问到底，实践最要紧的东西在于两个字：生产——它是一个主观的生产过程。

    * > **提示**：如果实践具备精神性，那么理论就绝对不是空想——搞理论的人也在进行某种实践，也是某种实干家，只不过是一种精神生产；一个哲学家思考问题、写出一本书，依旧是一种实践。

## 文学理论的定位与目标

* **文学理论**

    * > **定义**：文学理论约等于哲学，是文学的哲学。

    * 它是一个评判作品的价值系统。

    * 它提供解读作品的角度和方法。

    * 课程边界：一门课完全讲不够，能做的只是搭一个框架、让你知道有这些东西，接下来慢慢学；理论素养需要一个长期磨练的过程，不能指望一个学期下来就立马有了很高的理论素养。

    * > **注意**：像中学背书似的把教材从头到尾吃透，不是学文学理论的方式——搞文学理论的人要有框架、有体系，看的书足够多，把各方面的知识联系起来，对一个问题有深入思考的能力。

* **准阅读者**

    * > **定义**：文学理论课的目的——把大家从中学语文的应试当中拉出来，成为一个文学专业的准阅读者。

    * "准"的含义：经过大一到大四的整个学习过程之后，你也仅仅是文学作品的准阅读者，还不能称之为读者。

    * 阅读这件事情是有门槛的：认字不等于能阅读；阅读是需要训练的、是需要一整套理论的——厨师成为饭店大厨、医生走上手术台之前都要经过长期的训练和积累，拿起文学作品进行阅读同样要储备大量的知识和理论，否则很难说是真正的阅读者。

    * 从大一到大四，汉语言文学专业的一个重要训练就是成为这个准阅读者，把自己跟一般的阅读者区别开来；区别开来的过程就是你要有理论。

    * 考研很多学校都会考文学评论：给你一个作品，看你能分析出什么——你能看出什么东西，前提是你具备什么样的理论基础。

## 文学理论的对象与任务

### 对文学现象的抽象反思

* > **定义**：文学理论是对文学现象的一种抽象反思。

#### 文学活动的两个系统

```text
系统一：文学创作 ────→ 文学文本（作品）────→ 文学接受

系统二：文学生产 ────→ 文学价值 ────→ 文学消费
```

* 系统一说的是"先得有人写，然后写成作品，然后得有人读"；系统二是同一部作品在社会层面的另一条命——被生产出来、承载价值、进入消费。

* 系统一内值得反思的文学现象：文学创作的心理动因是什么、文学创作的思维方式是什么、作家在什么情况下会进行创作、文学作品有什么样的内在结构、文学文本跟其他文本有什么区别、文学接受到底是公共的还是私人的、当我的解读跟别人解读出来的意义不一样时到底怎么评判谁对谁错。

* 系统二的运转：作品完成之后还不能简单地让它流传，还得"生产"——传统方式是找一个出版社，现在的方式是直接找个网站把稿子放上去；出版成了一本书就变成了商品，放到书店里供人们消费。

* 系统二内值得追问的问题：文学消费跟文学市场有什么关系；作家在创作过程当中是一定要适应市场的需求，还是坚守自己的艺术品格——每一个问题都值得写一篇论文。

#### 文学四要素框架

* **文学四要素**

    * 提出者与出处：艾布拉姆斯在《镜与灯》当中提出。

    * 目前的文学研究基本上没有突破四要素的，都是在这个框架之内对它进行进一步的充实。

    * 文学四要素是文学理论课关键的四个点：抓住这四个点，接下来就有了一个非常清晰的框架。

* **四要素框架的引申**

    * 叶维廉（1937 年生于广东，后到了美国）特别强调艾布拉姆斯的文学四要素，并给出了另外的一套解释——依旧强调这个框架，但把这个框架稍微复杂化，相关论述在《地域的融合：中西美学对话》里。

    * 刘若愚在《中国的文学理论》里也对四要素进行了一些阐发。

    * > **提示**：记东西要记全面——研究生面试常在你"知道"的地方追问书上就有的细节（例如《镜与灯》还有一个副标题叫什么），以此筛选学生。

#### 人工智能写诗之问

* **微软小冰**

    * 事件：2017 年，人工智能微软小冰写了一本诗集并出版，诗集名叫《阳光失了玻璃窗》，整本诗集全部是人工智能写出来的。

    * 生成机制：往小冰系统里输入 1920 年以后的五百多位中国诗人的诗歌，让它自己去找关系、找规律，然后再输出。

    * 拼贴痕迹：诗中"康桥"立马让人想到徐志摩，"三月之惠的风"立马让人想到汪静之的《蕙的风》——它肯定是把诗人的诗全部吸收进来之后各种拼贴组合，不过至少语法上还可以。

    * 小冰的诗没灵魂：不知道那几句话之间到底是什么关系，说明它写的时候根本没有想到这首诗要表达一个什么样的主题思想——它就是学了语法规则、学了一些意象表达，然后这些学得很溜。

    * 争议：《中国文化报》刊文《微软小冰写诗：诗歌创作的反面教材》，认为这恰恰反映出来诗歌创作就得是人干的事儿；开发者则说一点零版本现在还不行，以后慢慢升级迭代，一定能创作出伟大的诗歌。

```text
1920年以后五百多位诗人的诗歌 ──输入──→ 微软小冰（自己找规律）──输出──→ 《阳光失了玻璃窗》
```

* **本质问题：文学创作依靠什么**

    * 争论背后的本质核心：文学创作依靠的是什么——是技巧、方法，还是依靠别的东西（比如说灵魂）；是不是学了一些技巧方法之后就会写诗。

    * 课程观点：不否认人工智能能写出超过人的诗，有可能，或许有那么一天；但如果那天到来的话，那一定是人类即将淘汰的那天——一旦人工智能能写出跟人一样的诗或超过人的诗，说明它就有了灵魂。

    * 诗歌创作是人工智能能不能真正变成人的最后一道防线：AI 能干很多事情，现在写新闻报道、写法律文书都没问题，但诗歌目前写不出来；别的领域的方式、方法、技巧都相对固定、可以被替代，而文学创作要的是创作——写出来不一样的、具有灵魂性的东西。

    * 遗留问题：这种人工智能写出来的诗，署名权是谁；文学与非文学的界限到底是什么。

### 对文学文本的深入分析

* > **定义**：文学理论还是对文学文本的深入分析——不停留在文本的表层意义上（表层意义大家都看得出来），而要分析支撑这些意义的背后的逻辑。

* **爽文的心理机制**

    * 修炼文：主角刚开始是小白、水平不够，被周围人嘲笑打击却一味隐忍、憋一门绝世武功，之后反杀——这类爽文一定不是直接的宣泄，而是先压抑再宣泄，压抑的是读者，让你看得急死了，到最后宣泄出来这个爽点就一定成了；这一套心理机制用弗洛伊德的精神分析理论完全可以解释。

    * "老子天下第一"型：主人公一出来就直接获得了某种超能力，见谁秒谁、想干啥都能干啥——现实生活里满足不了的，在这里全部给你满足，即想象性满足（欲望满足）。

    * 霸道总裁文：先制造矛盾——平时"百花丛中过，片叶不沾身"的年轻霸道总裁，遇到唯一敢顶嘴、敢扇嘴巴子的单纯女孩；矛盾起来之后慢慢平息，互觉对方挺好而在一起；标配桥段是女孩被绑架，总裁面临"要江山还是要美人"的抉择，接下来一定要放弃一切跟女孩在一起。

    * 爽文从文学水平上讲没什么，仅仅是为人们提供一种满足和消遣；要关注的是为什么大家希望的点在这儿——"人生如此艰难，小说里爽一下难道不行吗"体现的是读爽文的一种心理需求及其背后的现实社会历史背景：现实生活当中太累了、压力太大了，所以在这个过程中寻求一种想象性的满足。

    * > **提示**：分析文学作品不要只是分析表面意思，而要透过它去问：它跟整个社会、整个历史、整个文化之间有什么样的关系——如果能进到这个层面，才叫一个专业的文学读者。

### 对文学观念的学理探讨

* > **定义**：文学理论还是对文学观念的学理探讨——如何看待文学这件事情。

* **文笔之争**

    * 电视剧《隐秘的角落》原著是紫金陈的小说《坏小孩》：故事很有悬念，但文笔不怎么样；若公开发表"紫金陈小说文笔不怎么样"，招来的反驳会是"小说的重点不就在悬念吗，跟我谈文笔？你老套了"。

    * 刘慈欣之争更有代表性：他的文笔也常被认为不怎么样，但这不否认他能成为科幻文学的领军人物；反驳会是"科幻文学讲的是想象力、讲的是营造的世界观，你跟我谈文笔"。

* **落脚点**

    * 这些讨论表面上是对具体现象的讨论，争到最后全都变成关于什么是文学、文学应该是什么样子的讨论——讨论哲学，上升到一个世界观。

    * 文学理论到最后探讨的就是：我们应该具有一个什么样的文学观念、什么样的小说才算好小说、小说应该具有什么样的伦理规范——这些问题都是值得去分析的。
