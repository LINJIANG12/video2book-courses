# 文学的本体视域

## 文学定义的障碍

* **文学本质问题**

    * > **定义**：文学本质论的追问起点是「文学是什么」——它是文学理论必须回答的第一个问题，也是最难、至今没有明确答案的问题。

    * 「视域」指目力所及、视线尽头的范围；文学的本体视域，即关于文学本质这个问题我们所能看到的尽头。

### 不可定义论的阵容

* **维特根斯坦（Wittgenstein）**

    * > **定义**：分析哲学的重要代表；早期《逻辑哲学论》从语言角度把整个世界一分为二——可说的与不可说的。

    * 判断「可说」的标准是语言能否找到清晰的对应物：苹果、桌子、手表可说；「人生」「爱情」这类词找不到明确对应物，属「不可说」，也就难以定义。

    * 后期《哲学研究》提出**家族相似**（family resemblance）：像「家族」一样难以画出清晰界限、不断延展的概念——你爸的哥哥算家人，他妻子算不算？他妻子的母亲算不算？照此推下去全中国人都算家人，可拆开任何一对又都不合理。

    * 例证概念是「游戏」：踢皮球、世界杯、电脑游戏、剧本杀都算游戏，却找不到共同特征；若拿「娱乐性」当标准，考试也能产生愉悦与成就感，整个人生都成了角色扮演游戏，概念无限扩大。

    * 文学、美、道德这类概念同属家族相似——不要指望用一句话概括它们的本质。

* **韦茨（Morris Weitz）**

    * 《理论在美学中的作用》（1956）：假设要给艺术下定义，这是徒劳无功的——等于在定义一个不可说、根本没办法定义的事物。

    * 论据：艺术是不断变化的，新形式、新案例、新观点思潮不断出现；一旦定义出现，就会有艺术家来挑战它——后现代主义艺术正是对已有艺术定义的不满和反叛，处在不断反叛之中，明确定义找不着。

* **卡勒（Jonathan Culler）**

    * 反本质主义代表；《当代学术入门：文学理论》第二章标题即「文学是什么？它有什么关系吗？」——在他看来「文学是什么」这个问题根本不重要。

    * 理由：当今的文化理论已经压倒了文学理论，以至于文学跟其他东西都融为一体。

    * 他给出的定义：文学就是特定时期、某个社会团体认为是文学的那个东西——等于宣布文学根本没有本质。

### 经验与理论的矛盾

* 经验中文学是可定义的：《哈姆雷特》肯定算文学，电脑说明书上的文字肯定不算——关于什么是文学、什么不是文学，经验里有比较清晰的边界。

* 理论中文学似乎具有某种「不可定义性」（要打引号）：一旦要划定太明确的界限，似乎很难。

* 处理原则：理论一定源于经验、是对经验的提炼和总结；当「不可定义」出现时，是理论出了问题，不是经验出了问题——应该去找更合适的定义方式，而不是宣布问题不重要。

> **提示**：日常生活里使用「文学」这个概念有相对确定的意思；要找的正是这种相对确定。

## 定义方式与属加种差

### 从实质定义到逻辑定义

* **实质性定义**

    * > **定义**：指着事物给出命名——「这是什么、那是什么」，寻求命名的确定性。

    * > **易错点**：实质性定义只是「贴标签」——只告诉你用什么符号称呼这个事物，对事物本身的独特性一点都没有揭示。

* **逻辑定义**

    * > **定义**：把被定义项放进一个关系体系——如「猫是一种动物」，把「猫」安置在某个概念集合之下。

    * 比实质性定义复杂：要把所要定义的东西放进一个关系体系当中。

### 属加种差法

* > **定义**：属加种差法——被定义项 = 种差 + 邻近的属；源自亚里士多德的逻辑学，是逻辑学给事物下定义的基本方法。

* 操作两步：先看被定义项处在什么集合之内（找它邻近的属——背后所处的大概念、大集合）；再看它跟这个集合中其他成员有什么区别（种差）。

* 每确定一条与同属成员的差别，定义就向本质逼近一步；生物分类「门纲目科属种」就是属加种差式的分类，许多教材的论述背后都是这种思维方式。

* 例：人首先属于动物，往里收是哺乳类、灵长类；再添种差「高智商」（区别于识破不了总量没变的猴、猩猩、狒狒）与「社会性」（区别于狼孩、荒岛上的鲁滨逊那种偏于动物的生活方式），得到「人是具有社会性的高智商的灵长类动物」——本来难下的定义被一步步逼近、清晰化。

## 文学的存在方式与经典定义

* 文学的存在方式是定义文学的起点：用属加种差法定义文学，先要找到文学之上那个最大的概念——文学以什么方式存在。

* 存在方式最简的分法是物质方式与精神方式两种：文学以精神方式存在。

* > **易错点**：探讨本质时，不要把承载内容的媒介当成事物本身——物质的书只是载体，如同研究「水是什么」时杯子只是媒介，不能把承载水的媒介当成水的本质。

* 物质载体确实会影响内容传递（口头文学、网络文学因媒介不同而对传递产生不同影响），但那是非本质性影响。

* 存在与否也以精神为标准：《红楼梦》的书全部烧掉，它仍在人们的意识中存在，它就存在；最后还记得《红楼梦》的那个人消失了，它才真的不存在。

* 经典定义的推导链（两次收拢）：

    * 第一步：排除物质形态（物质只是媒介与载体），文学属精神形态——这是它最根本的东西。

    * 第二步：精神形态有哲学、道德、宗教、科学观念、艺术等；艺术以审美性区别于其他精神形态，文学属艺术。

    * 第三步：在各艺术门类中按媒介区分——文学以语言为媒介，于是得出**文学是语言的艺术**：属是「艺术」，种差是「以语言为媒介」。

```text
物质形态 ── 排除：只是媒介与载体，不是本质
精神形态
  ├── 哲学 / 道德 / 宗教 / 科学观念
  └── 艺术（区别于其他精神形态的性质：审美性）
        ├── 绘画（视觉）
        ├── 音乐（听觉·旋律）
        ├── 舞蹈（肢体）
        ├── 建筑（物质性载体）
        └── 文学（语言）
              ⇒ 文学是语言的艺术
```

| 艺术门类 | 传达媒介 |
| :--- | :--- |
| 绘画 | 视觉 |
| 音乐 | 听觉、旋律 |
| 舞蹈 | 肢体 |
| 建筑 | 物质性载体 |
| 文学 | 语言 |

* 这个定义是目前中国很多文学理论课堂与教材采用的主流定义，因为它确实在众多方式中找到了文学的独特性；但定义没有结束——向小学生解释「文学是语言的艺术」，会立刻引出「什么是语言？什么是艺术？」，而解释语言与艺术比解释文学更复杂：问题出在定义方式本身，需要回头反思属加种差法。

## 下定义的困境

### 属加种差的软肋

* 软肋一：属加种差只能揭示关系，不能揭示本质——它把文学放进社会关系大网里层层定位，如同报出「某排某座」，给了位置，没给面孔；回答不了「它本身是什么」。

* 软肋二：它假定了属与种之间、种差之间的界限是清晰的——集合图把问题简化了；事实上界限复杂、交叉、模糊：相声是语言的艺术，辩论也是，文学与它们的关系却划不清。

### 定义总有例外

* 相声《挂钟》式的连环追问（挂起来的东西响→秤砣是实心的不响→炮仗有药才响→药铺全是药却不响→吃进嘴里的不响→跳跳糖有胶性又响→皮鞋接着地不响→轮胎又响）揭示了：给事物下一个完整的定义是困难的，要做到全部周延极难。

* 根源：下定义就是用一句话概括事物并区别于他物，而概括要求周延，经验世界永远能给你备好一个反例——每立一条规则，就总有一个例外。

### 字典式循环

* 下定义图什么：找本质——只要找到事物区别于其他事物的那个东西就够了。

* 字典里的定义是一个符号指向另一个符号，符号的链条落不到事物本身：《说文解字》释「玩」为「弄也」，再查「弄」是「玩也」——顺着词典链条追下去找不到那个事物，最后变成语言游戏。

* 出路的指向：应该直面事物本身，而不是再用一个词去对应它。

## 共相之争

### 唯名论与唯实论

* > **定义**：共相即事物本身的共性——「本质」就是共相，从柏拉图开始这么叫。

* **唯实论**：共相存在——爱情、人生、文学、美、艺术这些抽象概念背后有一个本质，这个本质不是虚构的，实实在在存在。

* **唯名论**：共相不存在、只是虚构——承认有这个词，但词不指向确定的对象，只是人们为了日常交流方便造出来的（如「爱情」：人人都在用，却没有人知道爱情「是」什么）。

| 立场 | 共相是否存在 | 这意味着什么 |
| :--- | :--- | :--- |
| 唯实论 | 存在 | 概念背后有真实的本质，不是虚构 |
| 唯名论 | 不存在，只是虚构 | 词不指向确定对象，只是为了说得方便 |

### 一把椅子的考验

* 指认容易：走进任何场所，哪怕从没见过这把椅子，也能轻易认出「它是椅子」——似乎心里有一个关于椅子的共相，唯实论好像占了上风。

* 定义困难：椅子用来坐？（在桌子上坐，桌子是不是椅子）都有四条腿？都有一个面？都有靠背？——都不一定，共相很难找，向唯名论倾斜。

* 临界点难题：把椅子砍掉一条腿、两条腿、四条腿都还能认出是椅子，剁成碎片就不是了——哪个瞬间它从「是椅子」变成「不是椅子」？唯实论认为这个瞬间找得到、界限存在；否定方认为根本找不到临界点。

### 本质主义与反本质主义

* **本质主义**：所有同类事物应该有一个共同的本质，而且这个本质是我们找得到的。

* **反本质主义**：在寻找本质的过程中发现，这个本质只不过是我们的虚构、幻觉，根本不存在。

* 立场分布：古典时期的哲学更倾向本质主义；当今哲学界越来越多的人倾向反本质主义。

## 结构论与同一性

### 同一性思想实验

* **忒修斯之船**：一艘能航行几百年的木船，零件坏一颗换一颗，一百年后所有零件都换过一遍——它还是一百年前那艘船吗？

* **金阁寺**：建于十四世纪末、历经二战完好，后被寺里和尚放火烧毁（理由是「因为我嫉妒金阁寺的美」）；三岛由纪夫取材于这一真实事件写成小说《金阁寺》（主人公沟口）；现存金阁寺是重建的——若所有内容、零件结构都跟原来一模一样，它还是原来那个金阁寺吗？

* 推到自身：人体有新陈代谢，据说每隔 7 年细胞就换一遍，肉体与精神都已与三岁时不同——三岁的你和现在的你还是同一个你吗？

* 这一问不能随便答「不是」：现代法律建立在一个基本前提上，叫**同一性**——今天的你应该是昨天的你、二十年前的那个你；二十年前的你杀了人，不能以「我全变了」免责。

* 结论：船、寺、人保持同一性，不在于构成它们的材料和内容，而在于组成它们的**结构和关系**——关系决定了你是你、决定了独一无二性，因为不可能有第二组一模一样的关系结构；细胞、肉体可以换，关系结构换不了。

### 文学本质即关系结构

* 把「关系决定同一性」落到文学上：文学的本质就是组成文学作品的那种关系结构；这种关系结构具体体现在文学上，就是**语言的运用**。

* 文学的语言——基础词汇甚至语法——都源自日常语言，但运用方式不一样：文学之所以有文学性，不在于它用了什么语言，而在于语言的运用。

* 这一思路突破了唯名论与唯实论的二元对立，开始从关系的角度探讨文学本质；但它同样有瑕疵，属于值得继续探究的开放问题。

> **提示**：结构论没有直接回答「本质是什么」，而是把问题换了个方向——不问「文学由什么构成」，而问「是什么关系让文学成为文学」。

## 本质主义与反本质主义的反思

### 本质主义的三重缺陷

* 缺陷一：预设了「现象／本质」的二元对立——先预设事物有本质，才去找本质；这个预设从柏拉图来（我们看到的世界都不是真实世界，表象背后才有本质和规律）。西方与之相类的说法是**逻各斯中心主义**：仿佛世界背后有一个造就万物、本身摸不着看不见的共通之物。

* 在人文学科的概念中本质很难划出、总有例外——像抓肥皂泡：觉得本质「不就在那儿嘛」，一抓就破，再抓再破，那个本质可能根本是虚幻的。

* 缺陷二：误以为本质是普适的既定事实——事实上本质处在不断变化之中。例：一位大学老师发文批判玄幻文学《诛仙》，称「中国文学已进入装神弄鬼的时代」，遭粉丝围攻——论战双方对「文学是什么」的认知不同（一方要求文学反映现实生活的本质规律，一方接受另一种文学观念）；不同时期的文学本质观念在不断变化，现实主义盛行只是其中一段。

* 缺陷三：误以为本质是唯一确定的——为此只能不断抽象到最高处，「文学是语言的艺术」就是典型的**过分概括**（over generalization）：它是概括，但什么都没说，独特性根本没有说出来。

* 思维提醒：一个人越意识到自己的无知，思想才会越深刻；越觉得自己把握住了本质，往往越浅薄——他可能恰恰陷入了某种思维方式出不来。

* 文学理论给人的不是评判作品的唯一标准、唯一定律，而是多套（甚至互相矛盾的）标准：没学过文学理论的人用自己的一套标准评判所有作品；学过的人用多套标准看待同一部作品——这是两者的根本区别。

### 反本质主义的陷阱

* 背景：本质主义确实有缺陷，2000 年以来中国许多文学理论教材开始反本质主义转向——陶东风主编的《文学理论基本问题》在序言中高举反本质主义大旗；南京大学也有学者以反本质主义为核心主张编写教材。

* 问题：反本质主义的思维方式容易陷入**虚无主义**——极端的反本质推到底，什么都没意义，整个历史全部无意义。

* 陶东风反复申明：「我说反本质，但不等于无本质」——极端反本质从理论上可以推到底，但不符合当下的生活经验（我们的经验是：文学有确定性的意义）；一切的理论要从经验出发。

* 反本质主义的两个最大失误：

    * 没有区分「绝对的本质」与「相对的本质」：超时空、超历史、绝对普遍性的本质确实没有；但在特定历史时期、特定阶段，人们谈文学时有特定所指——反掉绝对本质，不等于相对本质不存在。

    * 否认了文学本质的可把握性、可规定性：文学本质不是一团怎么抓都抓不住的雾。

### 文学性的四个维度

* 思路转换：不把文学当作普遍确定的本质去一锤定音，也不去找某一个独特性，而是**找维度**——像游戏人物能力的六边形图：几个能力点各自标上去连出图形，形状随历史时期与环境变化，但大概范围不出圈。

* 关键转化：把「文学」问题转化成「文学性」问题——谈「文学本质」是非问题（这个是不是文学）；变成「文学性」就成了强弱问题（文学性强不强）。

* 四个维度：**文化与审美、语言、形象、想象**。

* 强弱举例：跟《红楼梦》相比《史记》文学性弱，跟《史记》相比《论语》更弱——在这个框架下不必追问《史记》「到底是不是文学」，只看它与谁比、按什么规定来看。

* 维度之间的支配关系：前两个维度决定后两个维度——正因文学具有审美性、语言符号的属性，才决定了文学具有情感性和形象性，也决定了文学具有想象性和虚构性。

## 文学事件论

* **事件哲学**：西方理论背景是德勒兹、阿兰·巴迪欧等人的事件哲学；引入文学领域的是英国理论家特里·伊格尔顿的《文学事件》——这本书回归最传统、经典的文学基本问题，提出文学本质上就是一个**事件**。

* 创作作为事件：《兰亭集序》被称为「天下第一行书」，是王羲之醉酒所书，水平高到他本人再也写不出——对王羲之而言，每一次创作都是一次独特的事件。

* 阅读作为事件：「一千个读者有一千个哈姆雷特」之外更进一步——同一个读者在不同时候对同一部作品的解读也很不一样：每一次阅读，本质上都是一个事件。

* 伊格尔顿列出的文学认定特性：虚构性、道德性、语言性、非实用性、规范性——认定文学作品时会有符合的条目；看待文学作品时要把它当作为一个事件（与四个维度的思路比较相像）。

* 解答《便条》问题：「我吃了冰箱里的梅子……」这首到底是便条还是诗？事件视角主张不看它的内容，而看它背后跟怎样的背景联系在一起——放进当时的整个社会历史与「文本转向」的解读观念中，它的意义才会凸显；把《便条》的创作当成一次事件来考察，而不是把作品单拎出来问「是不是诗」。

## 文学的文化属性与审美属性

### 文化的本质

* 教材的论证路径分两步：第一步，文学是一种文化形态（文化具有历史性，所以界定文学本质不能采取普遍性、本质性的方式——文学的定义具有历史性）；第二步，文学不是一般的文化，而是一种审美文化——文学是具有审美属性的语言言语行为及其作品。两步连读仍是属加种差：先把文学放进「文化」大类，再用「审美」把它跟其他文化形态区分开。

* > **定义**：文化是人类的一种生活方式（雷蒙德·威廉斯）——你以什么样的生活方式生活在这个世界上，人类就形成了什么样的文化（如校园文化就是学生生活在校园中形成的独特生活方式）。

* 「文化」天天用、反复用，却没有一个人能说清楚——古今中外关于文化（culture）的定义极多，不同的材料里都有。

* 文化是一个有机整体：多方面、多层次、多角度构成的层次结构。

* 文化的背后是人与现实之间的关系：人活在世界 上要跟现实打交道、发生各种关系，文化从这里来。

* 文化一定是人创造的：不是人创造的东西不能称为文化——纯自然的东西、纯动物的东西不能叫文化，必须带有人的印痕。

### 文学作为文化形态

* 2016 年诺贝尔文学奖颁给音乐人鲍勃·迪伦，引发轩然大波；此前他 1990 年已获文学艺术杰出贡献奖、2006 年又一次获重要肯定——获奖不是草率之举。

* 颁奖词：鲍勃·迪伦的作品改变了我们关于诗歌可以是什么、以及诗歌可以如何作用的观点。

* 他能被纳入文学的理由一：诗歌与音乐在人类文化诞生之初本是一体——《诗经》可以唱出来，诗、音乐、舞蹈合一；荷马史诗靠游吟诗人传唱；当时没有「纯粹的音乐」「纯粹的诗歌」，是后来的学科分科把它们分化出来。文学自始至终是人类文化的一部分。

* 理由二：他的歌词、作品是对社会现实的一种回应——在美国乃至西方 20 世纪 60 年代的反文化运动、反战运动、嬉皮士运动中，表达了当时人们的困惑、向往和追求。

* 结论：文学是一种文化——以文学的方式去回应人与现实之间某种关系的东西。

### 文学作为审美文化

* 人与现实发生关系的方式有很多种，不同文化形态对应不同方式：

| 文化形态 | 与现实发生关系的方式 |
| :--- | :--- |
| 宗教 | 宗教价值信仰 |
| 科学 | 对真理的追求 |
| 道德 | 伦理 |
| 文学 | 审美 |

* > **定义**：审美文化，就是以审美的视角对人类生活方式的一种重塑（重新建构）——我跟现实发生关系时，是带着审美的视角的。

* 疫情题材影视的追问：疫情大家都经历过、新闻报道都看过，为什么还要拍成电影电视剧？——现实生活太过琐碎，艺术能以集中的方式呈现现实当中看不到的东西：人们的价值信仰、审美理想、期待、社会生活的某种本质规律。

* 课文删改之争（《鲁提辖拳打镇关西》被指宣扬暴力血腥、《武松打虎》打的又不是人、《谁是最可爱的人》有血腥描写、《背影》父亲爬月台违反交通规则）与民间说法「少不读水浒（小孩年轻气盛，再看水浒更压不住）、老不读三国（老人已世故，再看全是勾心斗角就更坏）」背后共享一个逻辑：认为文学能够建构现实——文学会反过来影响人、塑造人，进而参与建构现实。

* 文学到底能不能建构现实：能，又不能——背后是两个不同的理论脉络；审美文化属性对应「不能被现实标准约束」的一面，「能建构」的一面另有讨论。

* 读《背影》读的不是交通规则，是父与子之间极为深沉、极为克制、想说又不说、不说又似乎全说了的情感——文学作品中存在跟现实完全不一样的东西，这个东西就是审美。

> **结论**：对文艺作品不能用现实生活的标准去约束它，应该用审美的标准去约束它——看的是它哪一点感动了我。

### 审美的本质特征

* > **定义**：审美的本质特征是无功利性——它是「看似无功利的方式，满足人类的某种需求」。

* 人与现实的关系按功利性至少分两种：有功利（对象对我有用——出门选最优路线省时间、上课分辨哪些考点、食堂挑饭菜有无营养；日常生活当中的一切思考都是功利性思考）与无功利。

* 无功利的例子：吃完饭走在回宿舍的路上，看见花园里阳光映照下的一朵花、上面飞舞的蜻蜓蜜蜂，突然感受到大自然的美好——这种美好不能帮你吃、管你喝，没有任何好处，这就是无功利的、审美的。

* 审美是「无目的的合目的性」：说它纯粹无功利吧，它也有功利——一种高级的功利，满足精神上的享受；日常满足的是现实性需求，审美满足的是精神需求。

* 审美一定带来愉悦：美的东西一定能够带给人某种愉悦感、愉悦的享受。

* 不愉悦的对象也能产生审美愉悦：《鲁提辖拳打镇关西》三拳打死人，用现实生活的视角看当然不能愉悦；但课本选它呈现的不是杀人过程，而是惩恶扬善、嫉恶如仇的过程——通过审美性的方式符合了人们的某种审美理想，愉悦感源于这里。

* 若文学跟现实生活没区别，文学就根本不需要了——之所以要去塑造，是因为艺术能够呈现出现实当中呈现不出来的东西，其中很重要的一个就是审美。

## 虚拟情境

### 作家的虚构权利

* > **定义**：文学给人提供审美愉悦的独特方式是虚拟情境；作家有虚构的权利——这是文学作为文学的最独特性。

* 现实生活当中没办法虚构（现实是什么样就是什么样）；在文学世界当中，可以再造一个世界——作家写的东西不能当成是真的，完全可以进行想象加工。

* 玄幻文学论战的启示：玄幻文学好还是不好，一定要参照审美标准；若用现实生活的逻辑去印证它，所有文学作品都逃不掉——《西游记》又该怎么评价？文学最重要的一点：它提供的是一种虚拟情境。

### 情感的积蓄与释放

* **柯林伍德**《艺术原理》：人的情感分为两个阶段（两级）——积蓄阶段与释放阶段，说白了是一个量变和质变的过程。

* 「成年人的崩溃只在一瞬间」——那一瞬间的崩溃一定是之前长时间情感积累的结果；文艺的功能就是帮助人们把长时间积累的压力、情感释放出来。

* 虚拟情境因脱离了实用性，现实生活当中被压抑的情感可以在其中释放——艺术由此承担了「取代现实」的功能，成为现实生活的某种代偿。

* 演员的印证：独幕剧演员每年演上百场、长期在舞台上呈现疯癫挣扎的状态，被问「会不会现实与艺术不分、演到抑郁」，回答恰恰相反——在舞台上把不好的情绪、不好的想法释放掉，反而能在现实生活中以更健康的姿态面对生活。

* 恐怖小说、恐怖电影的吸引力同理：人有着释放某种情绪的需求。

### 悲剧的审美心理

* 「BE 美学」本质上就是悲剧——《红楼梦》按这个说法也算「BE 美学」；明知让人难受却喜欢看，是需要理论解释的审美心理问题。

* 解释一：文学提供虚拟情境，让现实里被压抑的情感得以释放（柯林伍德的积蓄—释放机制）。

* 解释二：在缺陷、不完美的过程中，更加激发了你追求美好的欲望——审美跟欲望相关，而欲望的关键点不在欲望的对象，而在欲望本身（特别想要的东西，获得的那一瞬间反而会失望；欲望的魅力在过程）；结局不是想要的完美结局，更加激发想得到完美的欲望——合上书之后依旧意难平。

* 解释三（尼采）：每个人的生命其实都不完美，悲剧给了你一个上帝视角——在看的过程中有一种操控感、操控的快感。

### 代偿与建构现实

* 艺术作品以一种提供虚拟情境、可以尽情想象的方式，让现实中的不满与不如意得到代偿——「你也可以体会一下，过一把瘾」。

* 阅读的功能：没有一个人可以经历世间一切事情，但在文学作品当中可以尽情体会不同人的人生、不同人生在纠结点上的难受、期待与选择——这一切反过来成为人生的印证和参照；学文学是离人性最近、离人生最近的专业（前提是读了足够多的作品；伟大的作品一定能得到全世界、历朝历代的人的共鸣，具有典型性）。

* 另一面——文学可以建构现实：确有小孩看了《水浒传》学里面的样子、游戏玩多了真把现实生活当游戏、看了「霸道总裁」剧就幻想找一个霸道总裁；但这个「度」没有标准，是一个非常主观的标准。

* 无论哪一面，都不能把审美文化跟现实生活画等号：作为审美文化，文学要按照审美的逻辑走——审美的逻辑最重要的就是提供愉悦与无功利性。

## 文学语言的独特性

* 语言维度（文学的语言属性与符号属性）的核心问题：文学语言与日常语言的区别——界定文学本质的延续：文学运用的媒介都是语言，那文学语言跟日常语言到底有什么区别。

* 学这组区别最重要的是记住「哪位理论家提出了哪一对区别」的对应关系；书名译名不同版本有差异，关系比译名重要。

### 九条区别

* **陌生化与自动化**

    * 文学语言是陌生化的语言——读起来觉得「怎么感觉那么独特」，不按日常生活的逻辑与惯性走；日常语言是自动化的语言。

    * 代表：俄国形式主义理论家什克洛夫斯基，《词语的复活》。

* **多义性与确定性**

    * 文学语言特别强调意义：用简单的语言文字符号，表达出尽可能多的含义；日常语言必须是确定的，不能有太多歧义、不能让人产生不一样的理解。

    * 相关说法：非指向性与指向性、深度语言与浅度语言。

    * 代表：伊格尔顿《二十世纪西方文学理论》；韦勒克《文学理论》——文学语言是内涵式的，日常语言、科学语言是指称式的。

* **虚拟性与现实性**

    * 文学语言是虚拟性语言，日常语言是现实性语言。

    * 代表：德国康斯坦茨学派的接受理论家伊瑟尔，《文本的召唤结构》；他的另一说法：文学是描述性语言，日常语言是解说性语言。

* **内置性与外置性**

    * 文学语言是内置性的语言，日常语言是外置性的语言。

    * 代表：德国接受美学家施蒂尔勒，《虚构文本的阅读》——另一说法：文学语言是自主性语言，日常语言是他指性的语言（依赖具体情境、指向实在对象的语言）。

    * 加拿大理论家弗莱《批评的解剖》：文学是内向的语言，日常语言是外向的语言。

* **情感表现与信息传递**

    * 文学语言是用来表达、抒发情感的语言；日常语言是信息传递的语言。另一说法：可感性语言与非可感性语言。

    * 代表：新批评的瑞恰兹。

* **生成性与惰性**

    * 文学语言是生成性语言——具有一定的生产力，意义可以不断地被生产（一千个读者有一千个哈姆雷特；一词多义性与奇异性使意义具有足够的生产性）；日常语言基本上是惰性的，是什么就是什么，没有可产生的余地。

    * 代表：法国理论家保罗·利科，《言语的力量：科学与诗歌》。

* **伪陈述与陈述**

    * 文学语言是伪陈述（也有叫「拟陈述」的）：它并不是在陈述什么、并不陈述某种真理；「伪」就在于事实的真伪并不重要。

    * 日常语言是陈述：要讲究真伪、讲求证伪、讲求逻辑。

    * 海德格尔：一首诗的真正伟大，在于它能掩盖这个人和诗的名字。

    * 应用：小说《社戏》以第一人称「我」写作，但这个「我」不等于鲁迅本人——小说就是小说，不指向现实生活；《再别康桥》的「我」其实对应徐志摩本人，但理论上不能说是——因为它是文学作品。

    * > **易错点**：查找文学作品中的人物影射谁（如《红楼梦》人物影射考证）是不专业的做法——文学不指向现实的真伪，不能把文学当成史料；「诗史互证」的研究原则中，文学仅仅只是参考资料。

    * 边界：散文中的「我」在中学语文教学中可以等同作者——散文文学性稍弱、与纪实性作品关系密切；文学性越高越不能把作者等同于作品中的人物，降到新闻报道就要等同。这是一个文学性高低的问题。

* **塑形语言与记述语言**

    * 背景：前八条不是铁律——文学作品中并非随便一句话都具有多义性、内置性、生成性：老舍小说的特点恰是以日常生活口语入文；杜拉斯《情人》的开头毫无修辞、语言跟日常语言几乎没有区别，却能把读者立马拉入某种虚拟情境。

    * 解答来自语用学派：语言的意义不在于他说了什么，而在于他在什么时候说、给谁说、向谁说——语言的运用方式决定了语言的意义。代表：美国哲学家约翰·塞尔（《言语行动》《表达和意义》）；英国语言哲学家奥斯汀（《如何以言行事》）。

    * 记述语言：对事物进行描述、叙述、陈述，且是一种特别一般性的语言——「太阳从东边升起」「中国的首都是北京」。

    * 塑形语言：不是描述、说明，而是表示着某种许诺、暗示——暗示说话人要执行和实践他所说的内容（卡勒《文学理论入门》例：说「我保证明天还你钱」不是客观描述，而是许诺，接下来还要执行和实现）。

    * 文学语言是塑形语言：背后体现出对读者的劝说与说服——让读者相信讲的故事是真的、情境确确实实有可能存在（其实是假的，但暗示事件真实发生过），以此干预读者的判断；旅游说明书运用的全是客观性描述、不向你许诺什么、不干预你的判断，所以不会被当作文学。

* **字面意与修辞意的矛盾**

    * 代表：解构主义者保罗·德曼，《阅读的寓言：卢梭、尼采、里尔克和普鲁斯特的比喻语言》。

    * 鞋带例：妻子边系鞋带边问丈夫「从鞋孔上面穿进去好看，还是从下面穿出来好看」，丈夫答「有什么区别吗」——这句话既可指「我不知道有什么区别」，也可指「我觉得没有区别」；妻子耐心的解释既可以是「你不知道我教你」，也可以是「你居然觉得没有区别？那我给你解释解释」——日常生活当中的很多语言本身就充满复杂性。

    * 判定：当同一个语法形式产生了两种相互矛盾的含义时，它就孕育了成为文学语言的可能性。

    * 叶芝《在学童中间》结尾「我们怎能区分舞蹈与跳舞人」：既可读成典型反问（区分不出来），也可读成疑问——既然有一种东西叫舞蹈、有一个东西叫跳舞的人，两者就应该有区别，那到底怎么区分（一种催促的口吻）；含蓄意跟字面意形成极大反差，就是典型的文学语言。

    * 维姆萨特（新批评）的比值表述：文学语言就是含蓄的意义同清晰的意义之比，明显超过一个普通的日常标准——分子是含蓄意（修辞意），分母是字面意；比值越大越接近文学语言。日常语言也有修辞意，但维持在一定的标准内。

    * 文学语言关键不在于它是否修辞，而在于它所表达的含蓄的意义与字面意形成的反差。

### 九条区别速览

| 区别 | 文学语言 | 日常语言 | 代表理论家与著作 |
| :--- | :--- | :--- | :--- |
| 陌生化与自动化 | 陌生化语言 | 自动化语言 | 什克洛夫斯基《词语的复活》 |
| 多义性与确定性 | 多义、非指向、内涵式 | 确定、指向、指称式 | 伊格尔顿《二十世纪西方文学理论》；韦勒克《文学理论》 |

| 内置性与外置性 | 内置性、自主性、内向性 | 外置性、他指性、外向性 | 施蒂尔勒《虚构文本的阅读》；弗莱《批评的解剖》 |
| 情感表现与信息传递 | 情感表现、可感性 | 信息传递、非可感性 | 瑞恰兹（新批评） |
| 生成性与惰性 | 生成性语言 | 惰性语言 | 保罗·利科《言语的力量：科学与诗歌》 |
| 伪陈述与陈述 | 伪陈述，事实真伪不重要 | 陈述，讲究真伪、证伪、逻辑 | 海德格尔论诗 |
| 塑形语言与记述语言 | 塑形语言：许诺、暗示、劝说读者 | 记述语言：对事物的客观描述 | 塞尔《言语行动》《表达和意义》；奥斯汀《如何以言行事》；卡勒《文学理论入门》 |
| 字面意与修辞意的矛盾 | 含蓄意与字面意反差极大 | 含蓄意维持在日常标准之内 | 保罗·德曼《阅读的寓言》；维姆萨特（新批评） |

* 九条不是九个互不相干的标签，而是从不同侧面反复逼近同一个问题：同一套语言，凭什么一进入文学就不一样了。

## 文学的情感性

### 情感为何是文学的门槛

* 基本认定：文学作品应该具有情感性——没有情感性的文本，不能称之为文学。

* 判别例：公园简介（建于哪一年、几几年改建扩建、有多少处景观）与产品说明书同样运用语言、描述外在的现实现象，却不被当作文学——它们是冷冰冰的文字，仅仅是客观、冷静、具体的介绍，读来读去没有渗透出情感，作品背后看不到写作的那个人和他的个性。

### 情感的来源

* 人们创作文学是因为有话要说，而如果现状极为满足，就不会有话要说；有话要说源于两种情况：

    * 现实有着某种匮乏——现实缺了什么东西，所以要通过言说、表达的方式去填补这个匮乏。

    * 源于某种审美理想——觉得现实还不够，要把那个真正应该呈现出来的样子呈现出来。

* 文学是表达情感的一个非常重要的、独特的方式，它的独特在于通过语言来表达。

* **情感是生命本质的体现**：人之所以为人，很重要的就是我们有着自己独特的个性和情感，而且需要通过各种媒介表达出来。

* 绑定关系：作家有话要说，就表现出他的一定情感；这种绑定渗透到阅读中——读作品时更多看到的是作品的个性，并透过作品的个性去发现这个社会的共性。

### 情感表达的中国传统

* 中国古代有一个特别强大的传统：诗言志——文学作品、艺术作品背后表达的是作家的思想感情；类似概念还有诗缘情、司马迁的「发愤著书」、韩愈的「不平则鸣」、以及「诗穷而后工」——特别强调文学作品是作家情感的表达。

* 由此形成「文如其人」的信念：文学要表达情感，且是极具个性的情感，所以文跟人是对应的、或者说应该是对应的。

* > **易错点**：绝对客观性的文学作品是不存在的——哪怕写作时尽可能克制、「它是什么样，我就把它写成什么样」，也是带着你作家的主观视角在写，写出来的东西多多少少带有主观性；纯客观描绘只是情感性稍弱，仍然是情感表达。

## 后情感文学

### 后情感的生成

* 理解一切「后X」类概念（后结构、后现代等）抓两条：它还是原来那个东西；但它变了味儿，对原来那个东西构成批判性关系。

* > **定义**：后情感文学指情感被建构起来的文学现象——情感本应是主体（个体）对现实生活深切体验中产生的独特、个人的情感，但在消费社会的今天、在文化工业产业的今天，你的情感很有可能是被建构起来的（「我想让你爱上我，是有方法的」）。

* 这是当今时代才有的现象：古代人不会这么想，古代人觉得情感是真实的；「多一些真诚，少一些套路」的流行，说明当今充斥着太多不是真实情感的情感——学术点讲叫话语，通俗讲就是某种套路，它是可以被建构起来的。

* 样本：某些青春文学作品文笔漂亮却像话术——满篇华丽比喻（月光下的水域、黑色的巨浪、寒冷寂静的深渊）最后落在「青春如同悬在头顶的点滴瓶，一滴一滴地流逝干净」，呈现的不是独特的青春压抑感，而是普遍的、大家觉得「青春就是那样」的东西，再找几个漂亮的词一形容；看不到属于这部作品的独特性。

* 集体感伤：当今很多网络文学、青春文学的基调是「没有感伤就不叫青春」——青春当然有感伤，但每个人都有自己的感伤；在青春文学的包裹之下，你的感伤被放大了。对照《青春万岁》式的对大学生活的正能量书写，可见这种基调是选择性的。

* 类型化生产：网络文学论坛把文学分成各种类型（很多类型闻所未闻）——分类背后意味着某种情感、主题、特色已经被模式化，可以像商品一样被生产出来。

### 后情感社会的三特性

* 学术源头：社会学家梅斯特罗维奇《后情感社会》，针对当今整个消费文化当中的社会状况（不光中国，西方也是如此）。

* **虚拟性**：所有的表达并非来自真实的情感——情感本应先有切身体验再表达出来，但现实很可能是你根本没体验，也觉得「我确实有这样的情感」。

* **表演性**：当你「体会到」的时候，这个情感根本就不是你自己的情感——你是在表演，在想象一个角色，而且好像还很入戏。

* **代理性**：此时此刻，你是一个情感的代理人。

* 最高级的建构就是建构你的情感——让你从心底认同这个东西；怀旧、唯美感伤、自恋这样的情怀，是消费市场中的重要代表。

### 认同的生产机制

* 村上春树《挪威的森林》现象：读者认同的不是村上的独特体验（渡边多少是其个人形象的化身，写的是特定日本文化时代的故事），而是找到了某种好像属于你、但其实根本不属于你的情感——在整个社会文化当中被放大了的一种情感。

* 书店的印证：最显眼位置摆的是村上春树（《挪威的森林》《刺杀骑士团长》）、东野圭吾，欧美的是马尔克斯、米兰·昆德拉——都是所谓文艺青年爱看的作品（80 年代文艺青年爱看「三斯」：乔伊斯、博尔赫斯、马尔克斯）；大家看的时候看的是经典性吗？不是，是「我能看」「我在看」——作品的内容已经不重要了。

* 网络文学的「写手」机制：网络上管那些人不叫作家，叫写手——我是一个生产机器，读者爱看什么我就生产什么；排行榜机制驱动下形成套路和模式，跟商品生产没什么区别；由此导致文学本应该具有的主体性渐渐被抽空。

* 判定争议：判定哪些作品是后情感文学本身是有争议的（被判为后情感的作品确实写了悲伤故事，有人认为那里有独特的经验、是「我的情感真实」）——涉及读者的理解、对作品意义阐释的差异；但这种现象毫无疑问是存在的。

### 后情感文学的三个特点

* 特点一：情感是一种可复制的产品——情感失去了内在体验，变成了一种可以复制、批量传播的话语。

* 特点二：情感有意地拉开与主体间的距离——判定作品好坏的重要方式是看独特性，而独特性的核心就是情感跟主体之间的距离（这个情感是不是属于你独特经验中感受出来的）；套路化的情感「放在这个人身上可以，放在那个人身上也可以，放在所有人身上都可以」——它被创作出来就是为了让大家都认同。经典作家、好作家根本不考虑「作品能不能被大家接受」：我就把我自己最独特的那个经验写出来，大众买不买账不重要。

* 特点三：情感话语的泛滥，导致了情感的无节制的贬值。

### 感伤情怀的代际变迁

* 感伤作为主题一直都在——古典时代有，现代主义有，当今时代也有；但不同时代的感伤情怀内核不太一样：

| 时代 | 感伤情怀的内核 |
| :--- | :--- |
| 古典时代 | 个人理想与现实的格格不入——壮志难酬 |
| 现代主义 | 人在现代社会当中被异化 |
| 当今时代 | 一种流行符号 |

* 译者林少华谈村上春树：「村上作品中最能让我动心或引起共鸣的，乃是其提供的一种生活模式、一种人生态度——把玩孤独，把玩无奈」——关键词是「把玩」：不是真的孤独，而是像欣赏一样把玩孤独；村上作品在接受的过程当中让人形成这种感觉，提供了把玩孤独、把玩青春、把玩感伤的空间。

## 形象性与语言的公共性

### 为什么必须借形象抒情

* 文学要靠形象来抒发情感：古诗词当中直抒胸臆的少、借景抒情的多——顶多一句两句直抒胸臆，几乎很少有作品没有任何形象、从头到尾直接抒情。

* 表情包的道理：说「我很崩溃」不如发一个「我裂开了」的形象——抒发感情是一回事，在抒发感情的过程当中以什么中介来抒发，是另一回事。

### 语言的公共性与情感的私人性

* 语言的公共性：语言最开始并不是用来进行文学创作的，它最重要的目的是交流——整个社会都要靠语言传递意思，必须创造一套大家共同认可的文化符号系统；所以语言往往是一种理性的存在。

* 情感的私人性：文学要表达的内容是情感，情感是私人的、为你所独有——往往是非理性的存在。

* 矛盾与后果：私人性的情感要通过公共性的媒介来表达，中间必然产生信息的损耗——你总觉得用语言表达情感没有办法说清楚内心的真实愿望；「词穷」（只会说「我很激动、我很开心、我很高兴」）就是损耗的极端形态，词汇量大的好作家找的词就比较准确。

| | 语言（文学所用的媒介） | 情感（文学要表达的内容） |
| :--- | :--- | :--- |
| 属性 | 公共性，大家都得认 | 私人性，为你所独有 |
| 性质 | 往往是一种理性的存在 | 往往是非理性的存在 |

### 形象的转移作用

* 形象以一种转移的方式，让本来公共性的语言能够表达私人性的情感。

* 「月亮代表我的心」：爱情的深浅跟月亮本来没有关系，是强行拉进关系——月亮洁白＝爱是纯洁的；月亮从古到今一直挂在那里（「今人不见古时月，今月曾经照古人」）＝爱超越时空、永恒；月亮阴晴圆缺＝留下解读的空间。用一个形象，立马就会产生联想。

* 《挪威的森林》「春天的熊」：把抽象的情感转移到具象的画面——春天的原野上毛活像天鹅绒、眼睛圆鼓鼓的小熊，抱着它顺着长满三叶草的山坡咕噜咕噜滚下去整整玩一大天；这就是考验文学水平、考验作家想象联想能力的时刻。

* > **注意**：形象是看具体情况起作用的——假设听者小时候被熊袭击过，「抱着熊滚下去」就不是可爱而是可怕；同一个形象换语境就失效。

* 形象能够表达出来一些语言表达不出来的东西；一旦作家把不可言说的情感表达出来，就有了文学理论当中的经典命题——形象大于思想。

## 形象大于思想

### 两重含义

* > **定义**：第一重含义——作品形象所包含的含义，超过了作者的主观意图。

* > **定义**：第二重含义——作品形象所表现出来的意义，与作者的意图存在矛盾。

* 前提：作者一经创作、借用形象一经创作出来之后，它所产生的生命力，一定要比最初的创作意图复杂得多、深刻得多。

* 高低判据：真正伟大的作品、好作品，形象与思想之间的差异程度一定是极大的；一般作品（如小学生作文）形象与思想基本对应、没有拉开差距，文学性就不强。

* 作者通常拒绝回答「你这个小说表达什么意思」——作为作者，要是一句话能把小说说清楚，读者就不会看这小说了；这本身就是形象大于思想。

```text
第一种情况：形象 A 把作者意图 B 整个包在里面（A 远大于 B）

    +----------------------------+
    |  A  作品形象所包含的含义   |
    |                            |
    |        +------------+      |
    |        | B 作者意图 |      |
    |        +------------+      |
    |                            |
    +----------------------------+

第二种情况：形象 A 与作者意图 B 完全不相交（互相矛盾）

    +------------+
    | B 作者意图 |
    +------------+

    +--------------------+
    | A 形象所产生的意义 |
    +--------------------+
```

### 《威克菲尔德》的多种读法

* 故事梗概：一个男人跟妻子说去外地办事、深情一吻后离家出走，其实就住在自家隔壁街道租来的房间里——二十年透过窗户看自己家、看妻子进出，始终不与家里联系；二十年后回到家，对他而言仿佛只过了一天，对妻子而言过去了二十年。

* 读法一（霍桑本人）：呈现逃离社会之网的欲望——现代社会每个人都被纳在一张既定的网里，每个时刻走到哪里都被安排好，从没想过脱离这张网会发生什么；小说想象脱离社会之网的可能性，是对人的存在方式的反思。

* 读法二：呈现时间概念的主观性——二十年对威克菲尔德像一晚，对妻子是二十年；时间具有主观性、不具有客观性。

* 读法三：窥探欲的寓言——重要的不是窥探到了什么，而是窥探这个行为本身（连窥探对象都是自己家）；这是一个呈现人的心理欲望的象征性寓言。

* 三种解读都未必符合作者创作的原意——作者创作的时候肯定没想那么多。

### 经典例证

* 第一重含义（含义超过意图）：

    * 《红楼梦》：正统解读「封建社会大家族（贾、史、王、薛四大家族）的没落」绝非曹雪芹的创作意图——他的意图就是把家里那点事儿写出来（有亲身经历，所以日常生活写得那么细）；但作品呈现出的美学价值、历史价值、社会价值，比他真正想要呈现的意图复杂得多。

    * 反证（藏拙）：《红楼梦》一旦写底层人民就薄弱——刘姥姥写得滑稽，但以刘姥姥第一人称视角写的段落仍是一种站在上层往下看的感觉，看不到底层人真正的心路历程；不善于写的就不写，底层人多一笔带过——印证曹雪芹的经验边界，也印证形象的意义不由意图设定。

    * 巴尔扎克《人间喜剧》：他在政治上是一个典型的正统派，写的时候绝对没想那么多，作品却被读出了丰富的时代内容。

* 第二重含义（形象意义与意图矛盾）：

    * 巴金《秋》：最初设想让淑贞十五岁就嫁出去，写到第三十九章她跑到后花园时，突然想到后花园还有一口井——人物走向已不在巴金当初的设计里。

    * 普希金《叶甫盖尼·奥涅金》（诗体长篇小说）：「我最开始写的时候，没想到塔吉亚娜会嫁人——写着写着，她就嫁人了。」人物一旦活了，连作者都拦不住。

    * 曹禺《雷雨》：创作时约二十三岁、在清华外语系读书，并没有「暴露封建大家族罪恶」的宏大意图，仅仅是年轻想写个剧——却一不小心写成经典（处女作即代表作即巅峰之作，《日出》《原野》都不如它）；它把各种戏剧矛盾完全激化、在一个空间内展现，意义和价值非常复杂。

* 机制：作家是借由人物形象来创作的——人物形象起初受作家控制，写着写着自己就活了、动起来了，作家渐渐变成仅仅一个代言人、代笔者；形象的活力不受作家控制，而且越是好的作品越是这样。

### 形象大于思想的原因

* 原因一：形象的间接性和不确定性——形象并不直接对应某一个特定的诉求，人物是活的（虽然活在想象当中），其目的没办法被确定，作者主观意图容易失控。

* 原因二：接受主体的主观能动性，包括两个方面：

    * 读者方面：阅读的过程是一次再创造——按我的理解、以我的方式去了解、体验作品，不同人读出不同意思，与作者主观意图发生差异是正常的。

    * 历史方面：作者创作时受特定时代、时空背景限制，但作品会流传下去，不同时代会给予不同解读，作品的意义、内涵越来越丰富。

* 原因三：作者自身思想的矛盾——作家的主观意图不等于作家的全部思想，作家的思想在不同时候、不同阶段会发生变化。

    * 典型：托尔斯泰对俄国社会的认识与他自身的地位、阶级性具有极复杂的矛盾；恰恰是这种矛盾体现到作品当中，呈现出当时社会丰富的、多样的可能性。

    * > **易错点**：「托尔斯泰的作品是俄国社会的一面镜子」的真正含义不是「如实反映」，而是「矛盾造就丰富」——自身立场的复杂矛盾，恰恰是作品呈现丰富可能性的来源。

* 推论：不要认为作者的主观意图决定一切。

## 文学的真实性

### 两种教材的分歧

* 分歧缘起：马工程《文学理论》明确有一节「文学是真善美的统一」，而「文学不求真、不求善、求美」也是可以成立的观点——两个观点都对，关键在于对「真」的理解不一样。

* 教材背景：现在大部分学校中文系用的是两套主流教材——童庆炳的《文学理论教程》与马工程的《文学理论》。

* 对「真」的理解直接涉及文学理论史上对现实主义的理解：怎么反映现实生活才叫真，历来争议非常大。

* 方法提醒：人文科学根本无所谓对和错，只不过就是能不能站得住脚、能不能自圆其说的问题。

### 教材里的三种说法

| 说法 | 核心主张 | 一追问就露出的破绽 |
| :--- | :--- | :--- |
| 反映说 | 文学是对生活的某种反应；能反映现实生活真相（本来面目）的作品才有真实性 | 「现实生活的真相」是什么？《西游记》《九歌》反映了什么真相？ |
| 本质真实说 | 真相不是现象真实，而是本质真实（反映某种精神、文化、宗教追求等） | 「本质」说不清；若本质＝共性，《少年维特之烦恼》揭示了什么共性？ |
| 艺术真实说 | 社会科学是逻辑的真实，文学艺术是艺术的真实：用形象揭示现实生活的本质规律 | 「本质规律」仍悬而未决，教材与论文争议不断 |

* 三种说法都有道理，但都存在解释不了的地方。

### 文学的认知性

* 「真」强调与现实相符——相符就是一个认识的过程，所以文学有认知性：读《诗经》能认识很多花鸟鱼虫的名字；中国古代「诗史互证」的研究方法也体现出文学的认知性。

* > **易错点**：认知性是文学的功能，不是文学的本质特征——把「真」只停留在认知维度上来讲是不够的；认知过程仅仅是文学的副产品（外国人学唐诗能够帮助他认识汉字，但不能说唐诗的意义就在于认识汉字）。

### 事实之真与价值之真

* 「真」具有多义性，至少两个层面：**事实之真**（实然层面——实际上是不是如此、是否如实反映）与**价值之真**（应然层面——它应该是什么样子）。

| 维度 | 事实之真 | 价值之真 |
| :--- | :--- | :--- |
| 所属层面 | 实然层面：实际上是不是如此、是否如实反映 | 应然层面：它应该是什么样子 |
| 文学的态度 | 不求 | 追求 |

* 读完一部小说说「很真实、很感动」——两个成分都有：符合现实是事实之真；但真正让你感动的那个点一定是价值。

* 流水账为什么不行：记叙文写成流水账，是因为写的都是事实之真（事实就是这样，如实记下来）；好文章要有技巧、有组织，把它组织成一个「应然」的东西——一个大家觉得这个世界应该呈现出来的样子；流水账跟好文章的区别就在这个层面。

* 人们在阅读文学作品的时候，更多的不是关心事实是怎么样，而是关心这个事实应当怎么样：「黄河之水天上来」表现的就是人们的价值、符合人们觉得「应该的那个样子」。

* 作家虚构但写出价值之真就够了：《岳阳楼记》很经典很有名，据说范仲淹从来没去过岳阳——事实之真不重要，重要的是能不能写出价值之真。

* **文学不求事实之真，文学追求价值之真**——这就是对「文学求不求真」这个问题的解答。

## 审美意识形态论争

### 肯定派的谱系

* 孔智光（1982）《论艺术时空》：提出「艺术的本质是意识形态」——给人感觉只是顺嘴一提、并未作为核心论点去论证，但在中国学术界最早。

* 钱中文（1982）《文学评论》文章《试论人性共同形态及其评价问题》：文艺是一种具有审美特征的意识形态；基础是他提出的**审美反映论**——文学的本质是一种审美反映：文学首先是对现实生活的一种反映，但不是一般的反映，而是审美的反映。此后他发表多篇文章继续论述扩充。

* 王元骧（1989）《审美反映与艺术创造》：强调文学的独特性就是审美反映——文学以审美体验的形式、通过各种方式对现实的一种审美反映；其教材《文学原理》第一章第一节就强调审美反映论。

* 童庆炳（1992）《文学理论教程》：文学是显现在话语蕴藉中的审美意识形态（第五版第四章末尾第 84 页的结论，个别用词微调、意思一致）；九十年代之后全中国很多高校中文系都用它，专科、业大教材也是如此，自考、专升本的文学概论课程也多由他主编——教材广泛传播之后，「文学是审美意识形态」基本坐实。

* 1999 年童庆炳发表专文：「审美意识形态是文艺学的第一原理」——直接把这个判断抬到文艺学第一原理的高度。

### 反对派的攻击点

* 董学文（北京大学，1988 年起发表系列文章）：承认文学具有意识形态性，但文学还具有非意识形态性——文学是意识形态性与非意识形态性的集合；基本逻辑：只要证明文学具有一丁点非意识形态性，「文学是审美意识形态」就不能成立。

* 董学文的第二发力点是抠概念出处：马克思《〈政治经济学批判〉序言》原文说的是「意识形态的形式」——意识形态形式不等于意识形态：哲学、宗教等等只是意识形态的各种形式（类型）之一。他后来出版北京大学出版社的《文学原理》，通篇只用「意识形态形式」。

* > **易错点**：「意识形态的形式」与「意识形态」一字之差，是这场论争里最见功力的细节——从「文学是意识形态形式之一」跳到「文学是意识形态」，在反对派看来中间隔着一道没有论证的坎。

* 周忠厚（人民大学，2003）：文艺不是一种意识形态。

* 陆贵山（人民大学，2006）：「文艺是审美意识形态」是一个值得商榷、值得推敲的学术命题；著有《文学·审美·意识形态》。

* 论争于九十年代末到 2000 年代趋于白热化，参战者均为知名学者（陆贵山、周忠厚在人民大学，董学文在北京大学，童庆炳在北京师范大学，王元骧在浙江大学）；钱中文也反驳过反对派观点，又牵扯出更多问题。

| 立场 | 学者（单位） | 时间 | 关键文献／说法 |
| :--- | :--- | :--- | :--- |
| 肯定 | 孔智光 | 1982 | 《论艺术时空》：「艺术的本质是意识形态」（中国学界最早） |
| 肯定 | 钱中文 | 1982 | 《文学评论》文章：「文艺是一种具有审美特征的意识形态」；审美反映论 |
| 肯定 | 王元骧（浙江大学） | 1989 | 《审美反映与艺术创造》：文学的独特性是审美反映；另有教材《文学原理》 |
| 肯定 | 童庆炳（北京师范大学） | 1992／1999 | 《文学理论教程》：「文学是显现在话语蕴藉中的审美意识形态」；专文称「文艺学第一原理」 |
| 反对 | 董学文（北京大学） | 1988 起 | 「文学是意识形态性与非意识形态性的集合」；抠原文「意识形态形式」不等于「意识形态」；北大社《文学原理》 |
| 反对 | 周忠厚（人民大学） | 2003 | 「文艺不是一种意识形态」 |
| 反对 | 陆贵山（人民大学） | 2006 | 「审美意识形态」命题值得商榷；著有《文学·审美·意识形态》 |

* 人文社科的官司打不清：理工科可以靠实践、实验证明；人文学科有一个特点——没办法证明谁说的对。不要把教材当中的结论当成绝对真理——质疑是文学理论课传递的重要思维方法。

### 教材的论证逻辑

* 童庆炳《文学理论教程》第四章的三步论证：

    * 第一步：文学是一种意识形态（第一节强调，引《〈政治经济学批判〉序言》的经典论述）。

    * 第二步：文学不是一般的意识形态，是特殊的意识形态——特殊在「审美」。

    * 第三步：文学又是一种特殊的审美意识形态——特殊性体现在**话语蕴藉**上（后面几节专门讲）。

    * 结论：文学就是显现在话语蕴藉中的审美意识形态。

* 马工程《文学理论》（约 2010 年前后启动的国家教材建设工程产物，各主干课统一编定、代表权威性与普适性）的处理：回避文学和意识形态的关系问题、回避「审美意识形态」这个概念，专门设「文学的性质」章——但文学性质（文学的独特性）本质上就是文学本质。

* 马工程的三层次：文学是社会意识形态（讲倾向性、认识性等）→ 文学是审美的艺术（审美性）→ 文学是语言的艺术（模糊性、情感性等）。

* 两套教材表述不同、逻辑几乎一致：

| 论证步骤 | 童庆炳《文学理论教程》 | 马工程《文学理论》 |
| :--- | :--- | :--- |
| 圈定大类 | 文学是一种意识形态 | 文学是社会意识形态（倾向性、认识性……） |
| 第一层种差：审美 | 文学是特殊的意识形态，特殊在「审美」 | 文学是审美的艺术（审美性……） |
| 第二层种差：语言 | 显现在话语蕴藉中（话语蕴藉落在语言上） | 文学是语言的艺术（模糊性、情感性……） |

```text
意识形态（属）
 ├── ……（其他意识形态类型）
 ├── 审美意识形态（第一层种差：审美）
 │     ├── ……（其他审美意识形态类型）
 │     └── 文学（第二层种差：跟语言有关——显现在话语蕴藉中／语言的艺术）
 └── ……
```

* 局限：属加种差的思路清晰、定位快（经纬度立马定位准确），但两个根本问题没有回答——到底什么是意识形态？到底什么是审美？

> **提示**：读理论教材先拎章节、后进细节——把每一章在这条论证链条上处在哪一步先标出来，整本书的思路自然就显形了。

## 意识形态的内涵

### 本质是想象

* > **定义**：意识形态的本质是一种想象——它不是知识，也不是科学，不能用科学的方式、实验的方式去证明一个判断的对与错。

* 例证：该不该给彩礼、孩子要不要随父姓——这类问题再怎么用科学的方式也论证不出来，本质上是人的一种观念；却根深蒂固，而且每个人都不一样（「我姐结婚的时候就给了」「大家都这么做，我也就这么做」）。

* 可争性判据：科学知识没什么可争的；正因为意识形态没办法证明，当今网络上的讨论大部分都是意识形态之争——观念到底应该这样还是不该这样，一放上网络立马蹿火、立马热搜。

* > **定义**：意识形态是个体与现实的想象性关系（阿尔都塞）——你怎么去想象这个现实生活，以及你跟这个现实生活之间的关系。

* 日常例证：每天出门穿什么不是随随便便随手一抓——你在想象一个自我（我应该是什么样的人），用外在的东西定义自我，以特定的身份、面貌跟社会和周遭环境接触；在学校与将来在职场的衣着选择不同，就是这个想象性关系在起作用。

### 「本该如此」的想象

* 意识形态这种想象，是一种「本该如此」的想象——你就觉得就应该如此、天然就这样。

* papi 酱事件：有网友评论她「开了公司赚了那么多钱，生了孩子还不是得随父姓」——一方站在女权主义立场（女人在男权文化中「不配拥有姓名」，要推翻子承父姓的制度），一方站在个人选择立场（人家爱姓什么姓什么）；两边吵得极为热烈，本质是每个人都有一个「本该如此」：当事件跟你的想象不一样时，你不能接受，于是为维持稳定的想象秩序去辩论。

* 吃狗肉之争（曾闹到玉林狗肉节层面）：反对者的观念不光要求自己这么做——还认为整个周遭世界都必须如此，只有这样他那套想象性的秩序才会完完整整。

* 「女司机」「女博士」的新闻标题：开车好坏跟性别有没有关系？有什么证据？强调这个标签，背后携带出大量意识形态——报道者觉得本该如此。

### 本不属于自我的想象

* 意识形态这种想象，往往还是一种本不属于自我的想象——从某种程度上讲，想象是被建构起来的。

* 例证：毕业生「想进大厂」「想当语文老师」的想象看似找到了自我，其实社会就像提供商品一样提供了各种关于未来的想象，你只是在现成的想象里选了一种——你以为选择是自己的，实际上你的想象是别人的、是别人提供给你的。

* 没有绝对不受他人影响的自我：人不是生下来一张白纸自行书写，而是被家庭、社会、方方面面建构出现在的状态；「我们总是欲望着别人的欲望」——这个观点比较接近阿尔都塞。

* 学习态度的落点：很多人不愿意反思自己那个「本该如此」；学理论的人一定要反思——当我认为一件事情本该如此的时候，我是不是哪里有问题、哪里出错了。

### 作用于实践的想象

* 意识形态还是一种作用于实践的想象：想象如果仅仅停留在想象，那就是空想；但很多人建构了个体与现实的关系的想象之后，还要付诸行动。

* 例证：认为社会优胜劣汰、胜者为王的人，会努力向上爬、采取各种手段碾压竞争者，并认为这是应该的；认为社会应公平正义、每个人都应获取幸福的人，对职场尔虞我诈往往抱不屑的态度——同一件事，两种态度截然相反，因为观念、意识形态不一样。

* 意识形态从来不悬在半空：彩礼给不给、孩子随谁姓、出门穿什么、毕业进大厂还是当老师、向上爬还是不屑于斗——它就在这些最日常的判断底下推着你走。

### 召唤与循环

* > **定义**：意识形态建构一个人的方式是「循环」（阿尔都塞）——它不断地召唤着你，把个体建构为主体；说白了，就是让你成为谁。

* 循环链条：召唤 → 建构「本该如此」的想象 → 建构认同 → 行动 → 再召唤——意识形态不是一次性的说服，认同落到行动后又让你更深地待在这个循环里。

```text
召唤 ──► 建构「本该如此」的想象 ──► 建构认同 ──► 行动
  ▲                                          │
  └───────────────── 再召唤 ◄─────────────────┘
```

* 最典型、最重要的循环载体是广告——广告的重要方式就是建构你「本该如此」的想象（我该买它）：

    * 直播带货：李佳琦管观众不叫观众，叫「宝宝们」——把自己摆成母亲的形象，观众成了要听话的孩子；话术密集、刀刀戳到心上，成为顶流不是没有道理。

    * 成功学演讲：「听懂了吗？」「听懂的举手！」「听懂掌声！」——说的多是没用的话、正确的话，你在不断点头的过程当中就进去了、认同了。

    * 影视广告与网红景点：不介绍产品，而是制造一个完美的想象性空间——小红书网红景点「看着很好看，到了那儿——什么玩意儿」，据说中国有十好几个「小奈良」；网红景点的厉害之处不在照片本身，而在让你「确确实实去了」——想象已经先把你召唤过去了。

* 巴黎记者会的反例解读：有记者问巴黎市长「如何避开中国游客」——他的巴黎想象是浪漫之城、周围的人都得是蓝眼睛、街头到处接吻；一抬头全是黑头发黄皮肤的中国游客，想象被破坏了。

* 哈弗汽车广告「老爸开哈弗汽车，儿子上哈佛大学」：开不开哈弗汽车跟孩子上不上哈佛大学没有半点关系，但这句广告语在心中种下一颗种子；定位精准（中年男性、家里有孩子、对孩子教育最关心）；为什么是「哈佛大学」而不是「北京大学」——几层意识形态全部叠加在一句简单标语当中。

* 想象性的东西往往没有逻辑，但它不需要有太多逻辑——在心中种下一颗种子就够了，时间一长，总会有发挥作用的时候。

## 文学与意识形态

### 文学是建构意识形态的重要形式

* 衔接点：文学有一个重要维度——想象性、虚构性；意识形态又是建构想象的，所以文学很容易建构人的意识形态——恰恰是在虚构的、你认同的世界当中，你关于「这个世界本该如此」的想象不断地被建构起来。

* > **定义**：文学 = 虚构 + 让你信以为真——文学虽然是虚构，它要干的事情是让你信以为真；一旦你信以为真了，它背后传递出来的意识形态，你也就接受了。

* 接受的日常性：你的价值观有时候不是在上课的时候接受的，而是在平时日常的大众文化当中接受的——看什么样的电视剧、小说，听什么样的音乐，在这个过程中无时无刻不在塑造你关于「美好世界应该是什么样」「美好的爱情应该是什么样」「人生中的另一半是什么样的」「家庭应该是什么样」的想象；这样的想象一旦建立起来，就成了你的现实、成了「本该如此」，进而影响你的一生。

* 作用机制补论：「自古以来女人都不如男人，因为历史上各行各业出类拔萃的人基本都是男人」这类观点没法反驳的原因是——父权制社会给了男人更多的机会，才导致更多男人变得优秀；观念先作用于实践、制造出现实，现实再被拿来当观念的「证据」。

* > **易错点**：拿结果反证前提，正是这类观点看起来「没法反驳」的原因——不能反过来拿观念制造出的现实，去否认产生它的那个观念。

### 意识形态批评的入手处

* 意识形态批评是文学批评当中比较难（甚至最难）的批评方式——很多人看不出来、不知道如何下手；需要读大量的作品、读大量的文艺批评著作，才能不断提高这种能力。

* **入手处一：分析作品如何建构了自我与现实的想象关系**（顺着三个方向展开）：

    * 人物形象——作品里那面「认同」之镜：意识形态是一个镜像序列（阿尔都塞），它提供一面镜子让你在镜子中认出「那就是我」；文学作品当中的很多文学形象，本质上就是意识形态当中的某个镜像——在镜子中照见自己、形成认同的那一刻，形象背后携带的意识形态也就一并收下了。

    * 案例：郁达夫《春风沉醉的晚上》——「官方」解读有「底层劳动人民美好而纯洁的友谊」「底层劳动人民的反抗（陈二妹讨厌烟卷公司却不知怎么反抗）」；它真正的影响力来自人物形象提供的镜像：都市人（类似当今「社畜」）生活的孤独感，以及性方面的压抑感——情感上的孤独加生理上的压抑，以一种高度道德化的压抑方式呈现；很多读者从中看到自我、看到自我的向往，同时又获得升华与超脱。

    * 写法分析：一男一女并置在同一封闭空间、陈二妹回屋必须经过「我」的房间——情节设定天然引向情感走向的想象；小说里只有「我」的心理描写，其中更多是性幻想（想抱住她又不敢，「你别在这儿作孽了」式的自我呵斥正是欲望被道德摁住的瞬间）；这是典型的男性视角——只看得到女性的反应，看不到女孩的内心。

    * 谱系延伸：黄子平论述从《琵琶行》到元杂剧、小说直到郁达夫的「同是天涯沦落人」传统——中国文人的自我想象，而这种想象必定伴随一个女性，是典型的男性想象、男性空间；这种想象关系造就了他的某种意识形态。

    * 对照：《沉沦》把主人公的性苦闷直接跟国家、祖国的发展联系在一起（这种联系相当生硬，学界有不同看法）；娄烨的电影《春风沉醉的夜晚》跟小说没有直接关系，但迁移了意象——因为小说人物形象的孤独感跟当代人的生活处境密切相关。

    * 叙事策略——讲什么不重要，怎么讲才重要：他表达什么东西不重要，但讲述的过程引诱着你去认同。

    * 警匪剧套路（《无证之罪》一类网络剧、《扫黑风暴》）：主角一定是侦破能力极强却身份暧昧的人——本是被开除出体制的优秀警察，卷入案子、以不合规不合法的方式自由侦破、立功后恢复警察名分；直接宣传「坏人没有好下场、好人有好报、正义终将伸张」是说大话，观众不会认同，所以要塑造平民化的、体制外自由的主角建立代入感——当你认同了这个人物，顺着他走到最后的结果，也就认同了整个剧传递的价值观。

    * 成长叙事：好莱坞电影、动画片（《狮子王》《冰雪奇缘》之类）本质上都是成长故事——小白主角不断成长，容易产生认同感；认同建立后背后价值观登场：西方式的个人主义、英雄主义（英雄成就之后抱得美人归）。

    * 中国革命题材电影（《地雷战》《地道战》《小兵张嘎》《红色娘子军》）本质上也是成长故事（小人物走向革命、认同革命），但内含意识形态矛盾：按唯物史观，历史是人民创造的，不是英雄创造的；而讲成长故事会给人「历史是英雄创造的」的感觉——解决位置是：英雄成为英雄的那个时刻，也是他融入到人民当中的那个时刻（《董存瑞》牺牲时镜头切到人民的洪流涌上来；《小兵张嘎》成为真正军人后走向军队的行列、拉一个远景）。这是英雄史观（英雄革命观）与唯物史观之间的张力在叙事层面被解决的位置。

| | 好莱坞成长故事 | 中国革命题材成长故事 |
| :--- | :--- | :--- |
| 背后的价值观 | 西方式的个人主义、英雄主义 | 讲的是英雄故事，最终要落到人民史观 |
| 高潮时刻的处理 | 成为英雄，抱得美人归 | 英雄成为英雄的时刻，正是融入人民的时刻 |

    * 叙事类型——穿越小说为什么让人上头：其一，新奇感加代入感——主人公穿越（或被车撞）后以第一人称讲述陌生环境，再制造悬念，读者立马读进去（如《步步惊心》一类穿越到历史的作品）；其二，中国的穿越小说大多往回穿——穿越者知道历史、知道历史会发生什么，握有心理优势，影射现实中每个人都无法把握自己的命运，小说提供想象性满足（「当你知道了历史会怎么发展的时候，你将做如何抉择？」）；其三，穿越者带去现代的平等自由观念，与古代人发生价值观对立，于是起引领者作用——先感化收编的人，再感化更多的人，影射现实中没办法影响更多的人；其四，很少穿越到平民社会，多为上层社会、宫廷——在复杂的斗争与权力关系中纵横。与其说它是穿越小说，不如说是现今人们某种焦虑的影射。

| 现实中的焦虑 | 穿越小说给的想象性解决 |
| :--- | :--- |
| 没办法把握自己的命运 | 穿越者知道历史走向，握有心理优势 |
| 力量弱小，影响不了更多的人 | 以现代观念做引领者，先感化收编的人，再感化更多人 |
| 尔虞我诈的关系处理不过来 | 被放进上层社会，在复杂的权力关系网络里纵横 |

    * 穿越小说一定要提供这种想象性解决，才会有受众、有市场，否则就没有人看；同样的追问可以推广到性转文等其他类型——为什么这类文章有市场？

* **入手处二：离心结构——作者携带出来的深层价值观**

    * > **定义**：离心结构（马舍雷）指作品表层所说的意思之外，不经意间携带出来的深层价值观——表层传达的东西是中心，深层携带出来的东西呈离心的状态。

    * 例：擦皮鞋的故事表层想传递的意思是「要当一个好人」，但它不经意间呈现出了作者携带出来的某些价值观——对劳动的蔑视、对面子的追求、对富人仇视的心态。

    * 意识形态分析不能只停在表层说了什么——更重要的是分析它不经意间携带出来的那些更深层的价值观。

* **入手处三：接受、改写与误读——文学传播过程中的变形**

    * 《卖火柴的小女孩》：原著对小女孩最后的死亡以及死亡中的一系列幻想，持「死亡是一种解脱」的态度，背后是西方典型的基督教思想；故事传到中国之后，基督教词汇与倾向在翻译中几乎消失，更多体现为「这么好的小姑娘最后没吃的没喝的」——因为中国人没有基督教传统，原样翻译不会有人接受，它不符合中国人心目当中「本该如此」的意识形态。

    * 《皇帝的新装》：中文语境习惯读成讽刺（讽刺拍马屁的人、讽刺不敢戳破真相的虚伪）；原著写的却是——虚伪是人内心当中一个非常真实而且脆弱的情感，体现的更多是对当时的人的同情，而不是讽刺。

    * > **提示**：误读不是简单的「读错了」——它恰恰照出了误读者自身文化的意识形态；分析这些误读，非常有助于对一个作品有更清晰的理解。
