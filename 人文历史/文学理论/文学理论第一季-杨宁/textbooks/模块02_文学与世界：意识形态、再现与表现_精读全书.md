## 文学如何成为一种意识形态
> 对应块：BLK09 | 覆盖分集：P09 | 块标题（分集名）：《20191012 文学与世界（1）：文学与意识形》

上一轮我们把"文学是什么"这个问题收到了文学性的四个维度上。这一讲翻到新的一章，还是从那组最基础的四要素入手：作者、读者、文本、世界。四要素两两之间都能拉出一条关系，这一章先谈"世界"这一头。文学与世界要分几块讲，今天只处理第一块——文学与意识形态。

### 从金庸的武侠世界说起

先给一个基本结论：文学是意识形态。真正要费口舌的不是这个判断，而是后面那半句——它是什么样的意识形态，意识形态又到底是什么东西。

"意识形态"这个词，大家在中学多多少少碰过。一谈到它，很多人的脸色会凝重起来，总觉得它跟某种政治的东西绑得很紧，好像是某种不可言说的东西。其实没那么复杂。

讲这个概念之前，我想先说一段自己的经历。

去年十月、十一月的时候，文学界出了一件很重要的事：金庸去世。那几天朋友圈里反复有人悼念他、转发他，然后开始谈自己读金庸的经历。金庸在文学界的影响力很大，但这个"大"不在于他是个经典作家——他在当代文学史上可能还进不了文学史——而在于他在中国人心里构建了一个武侠世界。很多人可能不知道鲁迅写了什么、不知道老舍写了什么，但他知道金庸写了什么；他可能不知道金庸是谁，但他知道杨过、小龙女、郭靖。这一系列人物，可谓深入人心。

看到金庸去世的消息，我也不由自主地想起自己小时候读金庸小说的经历。

我是上初中的时候第一次接触金庸的作品，第一本读的是《神雕侠侣》。为什么是这本？因为当时热播了一部同名电视剧。《神雕侠侣》的电视剧有很多版本，我看的是任贤齐演杨过、吴倩莲演小龙女的那一版，北京电视台每天晚上播两集。那时候还没有网络，每天就守在电视机前等那两集。

看着看着我就很着急，老想知道后面怎么了，可它每天只播两集。你开始追问"接下来会怎么样"的那一刻，就是文学开始不断发挥作用的时候——文学的魅力就在这儿。就像一个小孩听母亲讲故事，讲到一半，母亲突然去做饭了、去接个电话，小孩追着母亲问：那个人后来怎么着了？一个虚构的人物，能让这个小孩如此关心。

后来我实在忍不住，就去买了《神雕侠侣》这本书——当时没钱，是偷了家里的钱去买的。

读了小说之后，我第一次发现小说真的比电视剧有意思得多。原因很简单：小说里喜欢杨过的女孩，比电视剧里多得多。

再往下想，我为什么爱看那部电视剧？是因为我不自觉地把自己想象成了杨过。郭襄一开口叫"杨大侠""杨哥哥"，我就觉得好像是在叫我自己。后来很长一阵子，我就把自己想象成杨过，还总结过杨过为什么那么优秀，总结出两个重要原因：第一，他特别聪明，学武艺一学就会；第二，他特别勤奋刻苦。就是这两条让他后来成为大侠。所以我也朝这个方向努力——因为这样我觉得会有很多女孩喜欢我。

后来我才发现，我漏掉了杨过的另一个特点：长得帅。

上大学之后我做过一次调查，挨个问班里的女生：你到底喜欢什么样的男生？得到的结论是，80% 的女生都说两点——第一是长得帅，第二是风趣幽默。没有一个女生说喜欢学习好的。这个结论让我很难过。

把这些串起来看：金庸构建了一个武侠世界，却对人有如此大的影响力。这种影响力本身，从某种程度上讲，就是文学作为一种意识形态发挥运作的一个重要方式。

> **结论**：意识形态并不像大家想象的那样神秘，它就是你正在坚信着的东西。

### 文学在社会结构中的位置

谈意识形态，绕不开马克思。第一个要弄清的问题是：文学在整个社会结构当中占什么位置。

这里说的是经典马克思主义的框架。社会结构分两大部分：经济基础与上层建筑。这组东西中学政治课就学过，高考要考，考研政治要考，文学理论也考。两者的关系是：经济基础决定上层建筑，上层建筑反作用于经济基础。很辩证。

经济基础自己又包含两块：生产力与生产关系。生产力是**人类改造自然的能力**；生产关系通俗说就是在改造自然的过程中人与人之间的关系，里面还分物质资料的分配方式等几项——那些不是今天的重点。

重点是上层建筑。上层建筑分两部分：一部分是比较具体的、实在的，叫**实体性上层建筑**，比如法庭、军队、政府、监狱；另一部分是**观念性上层建筑**，这部分又分两层。一层比较形而下、稍微接地气一点，比如政治、法治观念，甚至道德。再往上一层，是人类社会上层建筑里最高级的那一层：哲学、宗教，还有文学、艺术。

```text
社会结构
├─ 经济基础
│   ├─ 生产力（人类改造自然的能力）
│   └─ 生产关系（改造自然过程中人与人的关系）
└─ 上层建筑
    ├─ 实体性上层建筑：军队、法庭、政府、监狱
    └─ 观念性上层建筑
        ├─ 形而下：政治、法治观念、道德
        └─ 最高级：哲学、宗教、文学、艺术
```

顺着这张图往上看，文学在社会结构里的位置是比较高级的，而且高到了"最高级"那一层。这话不是我说的高级，是马克思说的。所以这个专业其实非常高级——中国劳动关系学院所有专业里，只有咱们专业到了这个层面，法学那些专业全都在咱们之下。

（这话说大了，掐掉。）

位置定下来，就能推出一个很重要的结论。既然文学处在离经济基础最远的那一层，它跟经济基础的关系就比较远；受经济基础的制约比较弱，受经济基础的决定性也比较弱。于是就出现一种现象：**文学艺术的发展经常跟经济发展不成正比，也不一定同步**。有时候经济很繁荣，文学未必繁荣；反过来，还有"国家不幸诗家幸"的说法——越是国家衰落的时候，越会诞生一批忧国忧民的作家，写出影响力非常伟大的诗篇。这都是完全可能的。

> **易错点**：不要因为"经济基础决定上层建筑"这句话，就以为经济一好文学必然好。决定关系要经过中间若干层传递，越往上越松，所以文学与经济之间呈现的是不平衡关系，而不是简单的同步关系。

### 意识形态的三种含义

刚才说的观念性上层建筑里那些东西——政治、法治观念、道德、哲学、宗教、文学、艺术——全是意识形态。但"意识形态"这个词本身究竟指什么？在进入正题之前，得先把传统观念里的三种含义交代清楚。

第一种是最初的定义，跟这个词的起源有关：**意识形态是一门学科**，专门研究人的观念。这个说法来自 18 世纪法国著名学者特拉西。一谈意识形态这个概念，最初都要追溯到他。他建立了一套"观念学"，也就是一门专门研究人的观念的学问。要注意，这里的"观念"不是某一个想法、不是你的 idea，而是某种观念体系。

后两种都从马克思那里来。

第二种偏贬义：意识形态是一种**虚假意识**，是一个谎言系统——说白了，它说的是假的，而且是骗你的，具有某种欺骗性。重点在于，它是统治阶级欺骗被统治阶级的一种方式；说得更狠一点，甚至是专门用来洗脑的，是暴力的控制。

第三种偏中性：意识形态是一种**信念体系**，或者叫观念体系、思想体系。比如社会主义是一种意识形态，资本主义也是一种意识形态——都是成套的观念体系。

| 出处 | 含义 | 色彩 |
| :--- | :--- | :--- |
| 特拉西（18 世纪法国） | 一门专门研究人的观念的学科，即"观念学" | 中性，学科义 |
| 马克思 | 虚假意识、谎言系统，统治阶级欺骗被统治阶级的方式 | 贬义 |
| 马克思 | 信念体系、观念体系、思想体系 | 中性 |

马克思自己在使用这个词的时候，有时偏向贬义，有时中性化处理。两种用法都成立，关键看你把它放在哪个语境里。

### 阿尔都塞：谎言与坚信

接下来要谈的是今天真正要用的那套意识形态概念，来自法国理论家路易·阿尔都塞。

先交代一句：今天讲的很多内容教材里没有，而且看上去好像跟文学没关系。但第一节课就强调过，文学理论很多是借助其他学科的理论长出来的；学文学，你得什么都知道，关键看会不会运用。

阿尔都塞严格意义上是一个**西方马克思主义者**。西方马克思主义者跟经典马克思主义者有区别：他们不满于"经济基础决定上层建筑"这么一个简单的决定论，觉得它太简单了；尤其在文化问题、艺术问题上，不存在这么简单的决定与被决定的关系。所以他们对经典理论做某种修正。

阿尔都塞的切口非常小，但很锋利。经典马克思主义说意识形态是一种虚假意识、是一种谎言。他反问一句：**当你指认出来一个谎言是谎言的时候，它就已经不是谎言了。**

这句话要多想一遍。谎言最大的功能是欺骗。可当你指着对方说"你这是在说谎、你在骗我"，欺骗的功能就已经失效了——它没法再骗你了。既然功能失效，它就不再是谎言。

```text
你信它   ──→  它在骗你  ──→  欺骗功能生效，它是谎言
你指认它 ──→  骗术被看破 ──→  欺骗功能失效，它不再是谎言
```

那么谎言到底是什么？阿尔都塞说：谎言不是那个你能指认出来欺骗你的东西，谎言是**你此时此刻正在坚信的东西**——你觉得这是对的，这才叫谎言。当你说"那是错的、那是骗我的"，那已经不叫谎言了，因为它的功能已经失效。

就在这么一点点细微的差异上，阿尔都塞长出了他的一整套理论。这套理论非常适合用来形容文学与世界的关系：文学是一种意识形态，但是阿尔都塞意义上的那种意识形态。

> **定义**：阿尔都塞意义上的意识形态，不是一套被人识破的骗术，而是一套你身处其中、尚未反思、因而正在坚信的观念结构。它的力量恰恰来自"你不觉得它是意识形态"。

有兴趣的话，可以去看他 1970 年写的一篇长文章《意识形态与意识形态国家机器》。这篇文章非常有名，影响极大，可以说是他的代表作，网上一搜就能搜到。稍微有点长，但不够一本书的分量，就是一篇长文章。

### 国家机器与意识形态国家机器

在这篇文章里，阿尔都塞先做了一个很有洞见的区分：一个是**国家机器**，一个是**意识形态国家机器**。

国家机器就是前面说的实体性上层建筑——军队、法庭、监狱等等。它有一个很重要的特征：**暴力性**。它发挥作用就靠暴力，说白了就是你不听我就打你，你不听我就抓你，你不听我就把你关起来，没什么可商量。也正因为靠暴力，它在运作的时候往往都是可见的、随处可见的，并且在公共领域对每个人都如此。

可是道理大家都清楚：如果一个统治阶级仅仅靠国家机器来维持统治，这个统治能长久运行下去吗？你不听我就打你，走到最后的结果必然是制造矛盾、矛盾激化，最后被推翻。所以一个统治要想维持下去，仅靠国家机器还不够，还要靠另一样东西——意识形态国家机器。

阿尔都塞举的例子很有意思：宗教、教育、家庭、工会、传媒、文化体育等等。

两者的差别，正好可以对着看：

| 比较项 | 国家机器 | 意识形态国家机器 |
| :--- | :--- | :--- |
| 手段 | 暴力：不听就打、就抓、就关 | 非暴力：通常表现为"我是服务于你的""我是让你愉悦的" |
| 可见性 | 可见，随处可见 | 隐形，不可见 |
| 作用领域 | 公共领域 | 私人领域 |
| 举例 | 军队、法庭、政府、监狱 | 宗教、教育、家庭、工会、传媒、文化体育 |

> **提示**：这两类机器不是"一个管硬的、一个管软的"这么简单。关键差别在于是否被感知为**强制**：国家机器把强制写在脸上，意识形态国家机器把强制藏进服务、愉悦和日常习惯里，所以后者反而更难拒绝。

阿尔都塞提出这几个意识形态国家机器的时候，很多人觉得奇怪：这些东西到底怎么发挥意识形态国家机器的功能？下面挨个看。

### 意识形态国家机器的运作现场

#### 宗教：先跪下，才相信

宗教要渗透自己的意识形态，往往借助一个很重要的方式——**仪式**。你几乎找不到没有仪式的宗教，世界上很少有宗教不借助仪式。有了仪式，人就有了仪式感，然后信仰就产生了。

阿尔都塞在这里说过一句很有名的话：

> **结论**：不是因为你相信上帝，所以你才跪下；而是你跪下来以后，你就相信上帝了。

这句话第一次听往往转不过来。它的意思是：**先有仪式，才有仪式感**，而不是先有仪式感才需要仪式；仪式恰恰是建构仪式感的重要方式。

这一点在宗教场所里看得最清楚。我不是信宗教的，我是党员，但有时候会去教堂。教堂的建筑有个共同特点：特别高，高耸入云，而且从地面往上中间没有任何横梁和障碍物。你一走进教堂，立刻感到自己很渺小，然后不知不觉就想跪下；跪下之后，后面那一整套东西就跟着来了，崇高感就是这么建立起来的。

雍和宫也是一样。走到里面有一尊巨大的佛像，高了两层，你一进去看那个佛像，头必须仰起来；一边仰视，腿就软了，就跪下了。那一刻，崇高感、自己的渺小感，以及由它引申出来的对佛像的崇敬和敬畏，全是油然而生的。

但你仔细分析一下，这些情感是怎么产生的？不是在观念上产生的，而是外在形式先建构了这种心态。

```text
外在形式（高耸的建筑、需要仰视的造像、跪拜的姿势）
        ↓
身体反应（自觉渺小、腿软、跪下）
        ↓
情感与观念（崇高感、敬畏、信仰）
```

图里箭头只有一个方向：从形式到身体，再到观念。把顺序倒过来理解——"因为心里先信了，所以才有这些形式"——就把因果关系弄反了。

#### 商品拜物教：我买故我在

宗教离日常生活可能还远一点，但日常生活里也有另一种"宗教"，马克思批判过，叫**商品拜物教**。我们崇敬的不再是某种神，而是商品。尤其在消费社会，商品成了大家日益追逐的东西。

要说钱就太俗了——其实我也崇拜钱，但我崇拜的不是钱本身，是钱的功能。钱那个东西不重要，它就是个符号；重要的是它的功能。

商品拜物教的关键在于：我们为什么这么追求商品？其实是想通过商品来定义自己是什么样的人。比如买衣服，衣服不是简单为了保暖，更重要的是好看；而且光是好看还不够，这个好看要确认我的身份和品位——"我怎么能穿那样的衣服呢？那衣服不符合我的品位。"于是非要穿成那样，才显得我高级。

笛卡尔说过"我思故我在"；在消费社会，很多人实际相信的是"我买故我在"。你怎么定义自己？通过你买的东西：我戴这副眼镜、穿这件衣服、用这个书包……一整套东西定义了"我是这样的人"。于是人对商品本身产生了极强烈的追逐感，甚至会有一种感觉：**是商品在影响你，而不是你在主宰商品**。这背后就是另一种意识形态的运作方式。

#### 教育：答题套路与升旗仪式

教育当然也是意识形态国家机器。从小到大，教育就是灌输某种意识形态的必然方式：你必须按照教育体制内规定的方式学习，而且它还会定期考核你。

考核方式在语文上最明显：你不能有其他的、自主性的答案，必须按照规定的答题套路、答题思路来解答才能得分。这就是另一种观念、另一种意识形态。

整个教育过程里还布满了各种仪式，比如每星期一升国旗——这是建构爱国主义意识形态的一种重要方式。

#### 家庭：在你出生之前就已开始

有人会问：家庭怎么可能是意识形态？难道从小到大我爸我妈对我的爱也是一种意识形态吗？

仔细想想，好像是的。家庭生活里，父母对孩子的潜移默化直接建构着这个孩子的价值观、人生观。你们当学生可能没有感受，我当了老师就有感受：看一个孩子是什么样，大概就能知道他家里是什么样的人、家里的基本情况、爸妈大概是干什么的。当然没那么神，但确实能感受到——因为每个人之间的差别太大了，从外在到内在接触了解一遍，基本就有数了。公务员家庭、父母都经商的家庭、父母都是农民的家庭，出来的孩子状态是不一样的。你以为这是偶然性吗？不是，这是整个潜移默化的结果。

更要紧的是它会影响你的价值观念。比如男孩将来要娶一个什么样的老婆、女孩将来要嫁给一个什么样的老公——这些东西你以为是你自己产生的吗？一部分是在大众文化里受影响，另一部分就是整个家庭给的。

甚至不是出生之后才开始。你在出生之前，就已经在受影响。

有一个动画短片，本来讽刺的是美国高等教育的高收费。故事是这样的：一个中产阶级男性回到家里，妻子对他说"老公我怀孕了"，他立刻非常慌张，翻箱倒柜地找东西，终于找到一个小本本，上面写着一个英文单词——普林斯顿大学。意思是：我们有孩子了，我们将来的孩子要上普林斯顿大学，所以我们要攒钱，从现在开始攒钱、开始记账。

这个短片让我看到的却是另一面：家庭当中的意识形态，在你还未出生之前就已经开始发生作用。你还在母体当中，还没见到这个世界，父母就已经在想我家的孩子将来要上什么样的大学、我要把孩子培养成什么样的人。

顺着这条线，我一直很想研究一个题目：中国当代文学作品当中男女主人公的起名。父母给孩子起名字，一方面当然饱含了爱，但同时也饱含了某种意识形态。这两天正是建国 70 周年，电视上有个节目就叫《我的名字叫建国》。你会发现，某个年代叫"建国""建军"的特别多，名字背后打上了鲜明的时代烙印；后来有一批人叫"卫红""卫东"，那是文革的烙印；文革结束之后，很多人名字里带"白"、带"洁"——因为文革是比较苦难的、需要反思的、需要洗刷阴霾的，所以要有一种干净的、走向新时代的感受；到了 80 年代，很多人叫"硕"、叫"博"，那是一个教育救国的时代；90 年代初开始，孩子的名字里叠词特别多，芳芳、圆圆、琳琳——那是独生子女时代，孩子的小名几乎就成了大名。

所以有时候你一看人的名字，基本上就能判断出他是哪个时代的。

你们是零零后，我看了半天，名字里倒没有什么特别的，但有时也能体现出来。08 年出生的孩子，我会特意关注一下有没有叫"奥运"的；01 年申奥成功，就有叫"申奥"的。

> **结论**：起名这个看起来最私人的行为，本身就是被意识形态穿透的。它既是爱的表达，也是时代的签名。

#### 传媒与体育：同款与支持哪一队

传媒文化跟咱们这个领域直接相关，是意识形态国家机器发挥作用的重要场所。最典型的是广告：广告要卖的是**附加值**，不仅卖这个东西本身的使用价值，还要卖它背后更高的文化价值，而这个文化价值的作用就是让你看起来比较高级。

比如在淘宝上，它怎么让你觉得自己高级？让你看明星同款。同款这个东西很有意思：它为什么要给你看照片、说明这个明星曾经穿过？因为你买下、穿上以后，会有一种"我跟这个明星如此接近"的感觉，"我跟他是同样品味的人"的感觉——他是一个多么高高在上的人，我穿上以后好像跟他也一模一样。这依旧是某种意识形态，只是换了一种独特的方式在发挥作用。

体育也一样。体育运动不就是追求更高、更快、更强吗？没这么简单，体育运动从来都没有这么简单。

举个例子：中国队跟法国队踢，你支持谁？当然支持中国队，这好像天然如此，没什么问题。那法国队跟日本队踢，你支持谁？这就涉及问题了——这就是意识形态。日本队跟韩国队踢，你支持谁？都不支持。

你以为支持哪个球队、热爱哪个球队是件很简单的事，背后全部都是意识形态。这些东西都是隐形的、不可见的，但它确确实实推动着你的实践。

### 自然化：把"从来如此"说成"天然如此"

有了国家机器与意识形态国家机器的区分，阿尔都塞重点研究的就落在后者身上：它到底是怎么发挥作用的？

意识形态国家机器的功能和目的，说穿了很简单，就两个：**自然化**与**合法化**。这一讲把自然化讲透，合法化先点个名。

什么叫自然化？就是告诉你这个东西是天然如此的、自然而然的、从来都是如此的。

这里有一条给人文专业的人的建议，我觉得比任何一条具体知识都值钱：以后遇到一件事、遇到一种观念，千万不要认为它从来如此。只要这件事找不到道理、你说不清楚道理，而它看起来又从来如此，那你就有必要去质疑它。

#### 性别：自然化最典型的现场

最典型的例子是性别问题。男权文化经常告诉女人：女人天生头发长见识短，女人天生是情感动物，女人天生力量小，所以女人天生就弱，所以女人天生就应该接受男人的统治。

女人接受吗？肯定不接受。那意识形态怎么发挥作用？把它**自然化**。

你们当然不接受——好，那我这么告诉你：我们有科学依据。你去看科学，男人跟女人的激素水平、身体各方面组织是不是不一样？你看到最后得出结论：男人就是比女人强。这不是我说的，这是科学。

你信不信？你得信吧。你既然信了科学，接下来对不起，你就得听这个。把它以自然化的方式呈现出来，有的女生就会觉得"好像是这样，有道理"，然后接上一句"我们没办法，生而为女人没办法，这是命啊"。再往后，背后那一整套观念从小到大陆续渗透进来，从家庭开始就渗透进来了。

#### 科学：当权威变成意识形态

这里说句题外话。我对科学有不一样的认识。我从小到大是学文科出身的，我总觉得，科学只是阐释世界的一种方式而已——只是阐释世界的一种方式。有太多太多的东西一定是科学无法阐释的，因为它根本不是按照科学那种阐释方式可以被阐释的东西。

问题在于：当科学太过强大，强大到成为某种权威的时候，它就容易变成某种意识形态。它太强大，以至于我们必须相信它；以至于一个东西如果无法纳入科学，它就非法、就不合理。

最典型的代表是中医。中医不符合科学，所以中医就是错的？那问题就来了：你科学的合法性又是如何建立的呢？你凭什么说"因为你不符合我，所以你是错的"？

> **提示**：这里质疑的不是科学的价值，而是"科学"这个词被当成终审法庭之后的那个位置。一门知识一旦取得"不符合我就不合法"的资格，它就已经不只是知识，而在承担意识形态的功能。

在当今社会，事情就是这样。我自己的经历也能说明一点：我高中时学得最好的学科是数学，高考数学是满分——文科数学。当年刚分文理的时候，我数学很好，理科其他科目也还可以，但我毅然决然进了文科。为什么？因为我一直有这样一个观念：理科、自然科学永远是治标的，人文科学才是治本的。无论科学再怎么发达，它永远解决不了一个问题——我站在你面前，你到底爱不爱我，你心里到底在想什么。人文科学才在解决这件事。所以自然科学永远只能是人文科学的一个工具。这也是文科的伟大之处，学人文科永远要比学理科更高级。

但没办法，在这个时代里，理科已经成为一种权威，而且是以自然化的方式成为权威的：天然如此，"科学就是这么说的""科学就是对的""不符合科学全是错的"。

女权主义者做的反击也是从这儿下手的：你既然说从科学角度看女人不如男人，好，那我们就从科学角度来谈。有一本书叫《圣杯与剑》，是一位著名的美国女性主义学者写的。她从考古学的角度证明：母系氏族社会过渡到父系氏族社会，其实是人类本质上的一个退步。她通过考古学研究发现，母系氏族社会是一个多么和谐安宁的社会；到了父系社会，才有了杀戮、征服等一系列野蛮的事情。

这本书背后的意思是：历史发展并不像我们想象的那样一定是进步的、一定是线性进步的。它某种程度上充满了偶然性。

#### 刻板印象：娘娘腔与女汉子

只要一种观念告诉你"天然如此""从来如此"，就值得分析一下。

比如小品演员小沈阳当年很火。他为什么火？除了唱得好、演得好之外，很重要的一点是：他给大家呈现的形象是一个娘娘腔的男性形象。

我当时就在反思一个问题：一个娘娘腔的人，为什么让大家觉得很可笑？

因为在我们的观念当中，男人应该是阳刚的、应该是冷峻的、应该是比较 man 的。所以一个男的特别像女的，就觉得很有意思。反过来，一个女性比较像男人，我们会说她是"女汉子"。女汉子搁在一个女生身上，是个好词吗？好像不是。有女生爱把自己形容成女汉子吗？不会的。

那为什么女人不能成为女汉子、男人不能娘娘腔？这是一种观念。这种观念一旦形成刻板印象，再以自然化的方式呈现出来，就很值得分析、很值得反思。

我觉得一个理想社会当中的两性状态是这样的：大家觉得一个男人娘娘腔没问题——小沈阳你娘娘腔就娘吧，这很正常；一个女人很汉子就很正常。这才是理想化的两性关系，而不是我们觉得一个男人娘就不对、就觉得好笑。

这就是一个问题。今天先说到这儿，休息一会儿。

## 意识形态如何运作：从询唤主体到症候阅读
> 对应块：BLK10 | 覆盖分集：P10 | 块标题（分集名）：《20191012 文学与世界（2）：意识形态与症》

### 自然化：天然如此，必然如此

意识形态干的第一件事，是把某个说法讲成天经地义。

它一定要把个体说成天然如此、必然如此、就应该如此。这样一来，你当然就容易相信它。可事实上，很多问题只要稍微往下追问一层，就会露出破绽——尤其是那些所指不明的东西。

> **提示**：一个符号有两面，能指是它的声音和字形，所指是它指向的意义。能指可以很稳定，所指却可能悬空。汉语里、乃至整个人类的语法系统里，都有一批词是所指不明的，而意识形态恰恰是从这个空隙里钻进去的。

最典型的一个词是"爱情"。能指早就建立起来了，可你问所指是什么——什么是爱情？说不清楚，每个人都有不同的理解。

一种理解是：爱情是伟大的、无私的，是不计回报的奉献，不朽的爱情可以战胜死亡。另一种理解是：爱情没那么伟大，也没那么神圣，它不过是人类荷尔蒙分泌出来的一种幻觉。

你到底相信哪一个？这取决于你选择了哪种意识形态。而你相信了哪一个，你就会付诸哪一种行动：相信爱情可以战胜死亡，你会做出一种选择；相信它只是荷尔蒙的幻觉，你会做出另一种选择。

所以，看到社会现象、社会问题的时候，要学会去挖它背后的意识形态。有些意识形态不是摆在表面上说给你听的，绝大多数都藏在背后。

很多年前，《非诚勿扰》上有一句话很有名。一个女嘉宾理直气壮地说：我宁肯在宝马后面哭，也不愿在自行车后面笑。

她理直气壮地说出这句话的时候，你会发现，这句话背后代表了这个社会当中的某种意识形态。是什么呢？是拜金——拜金已经到了人的异化那种程度。

我当时看的时候，第一个感觉就是奇怪。人活在这个世界上，最重要的难道不是追求幸福吗？说白了，不就是追求"笑"这件事吗？你让自己笑就行了，你管自己是在宝马车里笑，还是在自行车后面笑？你开心不就完了吗？那你为什么还要宁肯在宝马车后面哭呢？人已经异化到这种程度，我就觉得很奇怪。

后来我跟其他人讨论这个问题，得到的回应让我更加悲哀。朋友说：现在社会的问题是你坐在自行车后面，你还笑得出来吗？你一旦选择了坐在自行车后面，对不起，你笑不出来。即便你自己想笑，各种各样的谩骂、侮辱、瞧不起，也使得你想笑也笑不出来。

我说这个问题，并不意味着我反对拜金主义。我认为追求钱没有问题。问题在于，当钱成为衡量一切问题的标准的时候，它就成问题了。因为可以追求钱，但在此之外，我们应该还有更多别的追求。

可当它成为标准，问题就来了：你衡量一个艺术家的艺术水平，拿他赚了多少钱来衡量；你衡量一个作家的水平，也拿这个来衡量。

这几天诺贝尔奖刚出来，我就发现，关注诺贝尔奖的人都是圈外人，不是搞文学圈内的人。文学圈内根本不认诺贝尔奖，或者说并不把它当一件多重要的事。诺贝尔奖为什么这么重要？一个很重要的原因是他奖金最高——它是所有文学奖里奖金最高的一个。至于其他方面，它的地位其实并不那么重要，它的颁奖标准也并不被主流文学界那么认可。

于是就出现了这样的推论：莫言获奖，莫言就是中国最伟大的作家。为什么呢？因为莫言获奖之后有名了、有钱了，"你看人家赚了多少钱"。

这种场面我经常遇到。跟朋友讨论一个演员、一个明星、一个作家，大家都认同这人特别讨厌，水平不行，审美能力不行，各方面甚至道德水平也不行。但往往一句话就能封闭这场讨论——"但是，人家赚到钱了。"一句话就够了，前面说的全部无效。

> **结论**：这就是社会当中存在的某种意识形态。这种意识形态把人异化，使其他多元的选择性开始消失，而某一种观念以一种自然化的方式呈现出来——它不像是被谁塞给你的，倒像是事情本来就该这样。

### 合法化：替胜利者写理由

第二条功能是合法化。说白了一点，就是为统治者的统治提供合法性。

文学研究里有一个流派叫新历史主义，它的核心观点概括起来两句话：第一，历史都是由胜利者书写的；第二，一切历史都是当代史。

这两句话是连着的。因为你永远带着当代人的视角去看待历史，带着当代人的有色眼镜去看历史，所以一切历史都是当代史。而历史书写写的是什么呢？写的是"胜利者为何必然胜利、失败者为何必然失败"背后的那套逻辑。它永远会取消、或者说抹除掉其他一些复杂性的问题。

我读博士的时候，到北京大学去听一个博士生的课。博士生的课比较自由，老师上课经常跟学生一块儿讨论问题。那次我就听到一个博士生发表了一系列言论，核心内容是讴歌美国的民主制度：美国民主怎么好，怎么民主自由，等等。他没说出来的潜台词是：中国怎么怎么不好。

他说完这番话，我就看那个老师的表现——老师可能有点不高兴，于是开始跟他争辩。老师的基本观点是：美国的民主并不像你想象或看上去那样民主，它背后有很多财力的支持、资金的支持，有很多复杂的原因，其实它也并不民主。

争论的过程里，老师的地位比较高、牙口比较老，学生渐渐发现自己争不过。争不过，心里又有点不服气，最后甩下一句话结束了讨论。那句话让我听完背后一凉。

他说：不管怎么样，那也是有钱人选出来的政府。

我一听就意识到，这两个人的争论不是观点上的争论，而是两种不同意识形态的争论。这句话背后的意识是：有钱人就是有能力的人；有能力的人统治没能力的人，天经地义、理所当然。

你们认不认同这套逻辑？你会发现，在我们这个社会当中，就有一种逻辑在蔓延，有一种意识形态在蔓延：有钱人就是有能力的，他之所以能赚那么多钱，是因为他能力强、他优秀，他比别人优秀得多。

所以前两年刘强东出那桩丑闻的时候，很多人都说：刘强东肯定不可能干那种事情，他那么优秀的人、那么有钱的人，有必要去干那件事吗？

> **结论**：某种观念、某种意识形态，对错和真假都不重要，关键是当你发表这个言论的时候，某些观念已经在发挥作用了。解读一件事，要学会解读它表层背后的那些观念。

### 建构个体为主体

意识形态的运作方式是什么？一句话：建构个体为主体。

这句话听着有点哲学化，先不急着给它下定义，看它的核心——建构个体与现实的想象性关系。

个体，就是每一个具体的人。我如何想象我自己在这个世界当中的位置？比如你会说：我是一个大学生，劳动关系学院的大学生，大一的学生，中文系的学生。这些结论是从哪来的？从某种程度上说，它们是意识形态建构起来的。

> **定义**：所谓想象性关系，就是你对自己在世界中所处位置的那一整套想象——你是谁、你属于哪一类人、你该怎样行事。它不是被论证出来的，而是被建构出来的。

这套东西怎么建构？它有步骤，阿尔都塞都分析过。

我到这儿得插一句。上这课的时候，你们的表情都很凝重，我知道你们在想什么：你们总觉得我讲的这些问题，会担心我犯错误。放心，我不会的，什么该讲、什么不该讲，我心里很清楚。

上个礼拜所有老师开党员会，院长还专门分析过：现代汉语课不会触及这些问题，讲死了也不会；古代文学课估计也不会；然后就点到我——文学理论课很有可能会触及，要注意。这门课的特点就是这样，它涉及思想层面，涉及理解的问题，不是固化的东西，一旦涉及哲学问题，有些东西就绕不开。

但我在这里说清楚：我从来没有说意识形态是一个不好的东西，我没有这个意思。我只是一直在客观地说它是怎么发生作用的。

从头到尾，人类一直处在意识形态当中，你不要认为你可以逃离到意识形态之外。你说爱国主义是意识形态，我承认；那恨国主义就不是意识形态吗？你说香港那帮人逃离意识形态之外了吗？不，在我看来他们依旧在某种意识形态之中，甚至正因为以为自己脱离了意识形态，他们会被某种意识形态捆得更加根深蒂固。

所以这是一个极客观的问题，要极客观地去看，而不是简单地说某种倾向——我没有倾向。

#### 询唤：先给你一个身份

第一步，把个体询唤为主体。所谓询唤，就是质询、召唤——这个词的译法不一，你在别的书上也可能碰到"召唤"这个说法。

举一个很简单的例子。你们高考结束之后，最怕的一件事是什么？是怕出成绩。怕出成绩本质上是怕什么？是怕考不上。

你为什么怕考不上？因为如果你考不上大学，背后可怕之处就在于：你就是一个个体，你没有主体身份。考不上之后，你接下来怎么办？你在这个社会当中算啥？你什么都不算——你没有身份。

那你怎么办？要么再考一年，要么去工作。可不论再考一年，还是高中毕业就去工作，工作好找吗？好像不太好找。不管你干什么，你都急需找一个身份，因为高考结束之后，你已经摆脱了中学生这个身份，接下来你到底是谁？

于是，高考这个行为本身就是一个召唤过程、一个询唤过程："来吧，上大学吧。"上了大学，你就有了一个身份，一个主体身份。

同样，大学毕业之后，如果你不读研究生，你最怕什么？最怕找不到工作。因为大学毕业后没有工作，你在这个社会上又是一个无业游民。

你焦虑的其实不是"没工作、不赚钱"这件事——说实话，你即便工作，也赚不了多少钱。你最焦虑的是没有身份的依托。

而一旦有一个公司要你，你很开心，因为你立马就成为了主体。所以公司招聘，接下来就是一个询唤过程："来吧，来我公司吧。"你去了之后，你就从个体变成了主体，你有了公司。到了公司，他上来还要做岗前培训，让你先了解了解他们的企业文化。了解半天，你终于说出那一句："我是这个公司企业的人。"

当你说出"我是这个公司企业的人"的时候，你就建构了自己个体与现实的想象性关系。

#### 臣服：subject 的另一半

第二步，在询唤的过程当中，个体要对主体臣服。

阿尔都塞在这里玩了一个很有意思的文字游戏。考一下英语：哲学上的"主体"英语怎么说？是 subject，客体是 object。那 subject 作动词是什么意思？是"使屈服、使服从"。

所以你发现：你要想成为主体，你首先得臣服。

这道理很简单。你要去找工作，你想成为这个公司里边的人，那你得先谦卑一点，不要那么狂。人家问你："你对我们公司有什么薪资要求吗？""没有没有，给多少钱都行，只要先让我进来就行。"

我自己来学校应聘，也是这个过程。学校会问我很多问题：我们学校分两个校区啊，不光在北京有校区，在涿州也有校区，今天就要在涿州上课；你要来我们学校，就得在涿州上课，那你愿意不愿意在涿州上课呢？"愿意啊愿意。"——其实心里是不太愿意的。但没有办法，你首先得臣服，因为你想成为一个主体，你必须先臣服于他。

#### 互认：骂中文系就是骂我

第三步，主体与主体的互认。

你上了大学之后，发现周围有很多同学，都是大学生。你们之间互相抱团取暖，形成了一种共识："我们都是大学生，我们都是中文系的大学生。"意识形态的作用就在这时发挥出来。

它怎么发挥作用？比如网上有人开始说一句话：我觉得中文系的学生其实什么水平都没有，就学那点风花雪月的事情。

他根本没指你，他也没说你是那个人。但是你很生气。为什么？因为你觉得他跟你是绑定在一起的。这就是专业意识形态对你的作用——它建构你跟现实的想象性关系。人家并没有骂你，人家骂的是中文系，可你总觉得"我好像就是跟中文系有点关系的"，"你骂中文系就是在骂我，我就是中文系学生"。

就像前面说过的金庸小说。他写的是杨过的故事，可我读完了以后，就觉得他好像跟我一样。接下来，他会建构我的行动。

真的，我当时看完金庸小说之后，一度有想上少林寺的冲动。我真去过少林寺。到了那儿，看见和尚扎马步，把地上砸出一大堆坑，我突然间就想：算了，还是别去了，还是回来参加高考比较好一点。

三步连起来，是一条完整的链条：

```text
个体 ──① 询唤──▶ 主体 ──② 臣服──▶ 有身份的主体 ──③ 互认──▶ "我们"
```

读图注意三处：起点是"没有身份的个体"，终点不是孤零零的主体，而是一个"我们"；中间的两次转折都不是靠说服完成的，一次靠一声召唤，一次靠一次低头。

| 步骤 | 阿尔都塞的说法 | 日常场景 |
| :--- | :--- | :--- |
| 询唤 | 把个体询唤为主体 | 高考录取、公司招聘 |
| 臣服 | 个体对主体臣服 | 面试时"给多少钱都行" |
| 互认 | 主体与主体的互认 | "我们都是中文系的大学生" |

### 意识形态是一个镜像序列

再往下问：意识形态是什么？——是一个镜像序列。

这里要提到一个概念。法国著名的精神分析理论家、结构主义理论家拉康，提出过"镜像阶段"。

拉康研究的是自我的形成过程，他也研究人的意识到底是如何形成的。他从婴儿开始研究，发现婴儿出生以后，尤其在六到十八个月这段时间——他管这个阶段叫镜像阶段。

六到十八个月之前，你把一个刚出生的婴儿抱到镜子面前让他照镜子，他能不能认出来镜子里那个孩子是他自己？认不出来，他觉得镜子里那孩子是另外一个人。但到了六到十八个月，他开始发现：镜子里那个人是我。

而且在这个阶段之后，你会发现这个孩子很兴奋。一旦"里面那个人是我"，他很激动，因为他第一次有了控制的感觉——我一动，那里面也一动。于是他就开始狂魔乱舞。这是他第一次产生那种快感的过程。

由这个现象，拉康开始追问：人如何形成自我观念？我到底是一个什么样的人？比如我到底长什么样——你是怎么知道自己长什么样的？

你是真的见到你自己了吗？你这辈子永远见不到那个真实的你自己。不是镜子，不是照片，那都是假相。真实的那个你，你看得到吗？你永远无法看到，好像科技无论如何发达，你都见不到。你见到的永远是一个个的镜像。

然后你就照镜子：呀，我长得还挺好看的。就是这种感觉。

不光是长相。你关于自我性格的认知、关于自我能力的认知、关于自我各个方面的认知，其实都是通过一面面镜子。

这些镜子来自哪？从小到大，你的父母、你的同学、你的老师，周围环境里所有人给你的反馈。人家说"哎呀你怎么这么闹腾"，哦，原来我是个闹腾的人，我跟别人不一样在这儿；人家说"你怎么那么安静，天天就知道学习"，哦，我是个爱学习的人。就是这样不断地反馈，一面面镜子告诉你，你才是一个什么样的人。

我们不是天然就知道自己是什么样子的。我们是通过一面面镜子反馈，才知道自己是什么样的人。

由此，阿尔都塞把"镜像阶段"这个概念引了过来：意识形态就是一个个的镜像序列——它给你呈现一面面镜子，让你找到"哦，那就是我"。

当你指认出"哦，那就是我"的时候——就像我在杨过身上看到"那就像我"的时候——意识形态就已经发挥出作用了。

### 意识形态没有历史

再往下，是阿尔都塞一个很悲观的表述：意识形态没有历史。

这句话理解起来很简单：从来如此。

我们找不到意识形态到底从什么时候开始。换句话说，人类只要一开始活着、一开始出现，只要一开始有了某种观念，他就必然性地处在某种意识形态当中。

爱国主义是一种意识形态，恨国主义也是一种意识形态；集体主义是一种意识形态，个人主义是不是？也是。

那有没有可能，一个人不在任何意识形态之内？不。只要你坚信某一种东西，你就是在某一种意识形态之内。那能不能一切东西都不坚信？一切东西都不坚信，那也是一种坚信。

所以你永远在某种意识形态之中，你找不到它产生的过程。

也正因如此，我在讲意识形态的时候，从来没有说任何一个偏向：意识形态从来如此，你不在这个里边，就在那个里边，没有哪个是对的、哪个是错的。

在这个过程里，阿尔都塞完成了最开始说的那件事——对经济基础与上层建筑关系的一个反驳。他说，经济基础与上层建筑之间，没有那么强烈的、简单的决定关系，而是一种多元跨越的关系，背后的关系很复杂。它通过各种方式、各种各样的镜像，建构起个体对现实的认识。

> **注意**："没有历史"不是说意识形态一成不变，而是说它没有一个可以被指认的起点——你无法站到它外面去给它纪年。

### 症候阅读：从症状追到病因

说到这儿，都是理论问题。接下来要把这个概念、把阿尔都塞的意识形态理论，扯到文学上面。

阿尔都塞提出了一种阅读方法，叫"症候阅读"。

症候阅读的本质，就是挖掘作品中的意识形态。

为什么非得挖？因为很多作品有表层结构，也有深层结构，而且表层和深层是不一样的。当然有的作品表里一致——你看的什么样，它实际上也是什么样——这种作品就没什么可挖的。值得挖的是那些：表面上声称的话，跟背后深层结构不一样的东西。重点要挖在这儿，而深层的东西，还是那个意识形态的东西。

"症候"这个概念本来是医学诊断学提出来的。发烧、流鼻涕等等，这些都是症状，是一个个的"症候"。但诊断的医生要通过这些症状，最后判断你到底是什么病因：你到底是不是感冒？怎么引起的感冒？因为同样的症状可能由不同的病因引起，不同的病因也可能引发同样的症状。

阅读的过程，或者说阅读文学作品的过程，也是这样一个过程。你看到的那些文字只是表面的症状，接下来你需要挖掘背后潜层面的东西。

```text
表层结构：作品明面上说出来的话（症状）
        │
        │  症候阅读：追问"它为什么这样说、又为什么不这样说"
        ▼
深层结构：没有说出来的意识形态（病因）
```

读图看两个位置：上面那一层是你读一遍就能复述的内容，下面那一层是作品自己不会交代的内容；症候阅读的动作，就是从上面那一层往下面那一层落。

### 童话：反复讲述的那些观念

最容易建构意识形态的东西，要从童话说起。

为什么是童话？因为童话故事我们小的时候一直都听，而且反复被人传颂。你小时候不断地阅读、反复地接受，它就一直在潜移默化地建构你与现实的想象性关系，潜移默化地影响你的价值观。

我建议，将来写毕业论文或者学年论文的时候，可以研究一下童话故事当中的意识形态问题。童话故事看起来特别美好，但只要你认真一思考，真的是细思极恐，背后有很多问题值得琢磨。

《白雪公主与七个小矮人》表面上是一个很美好的故事：白雪公主经历了很多磨难，尤其是皇后各种各样的追杀，最后跟王子结婚。但你仔细想一下整个故事的流程。

首先，有一个国王，有一个王后。王后生下了一个女儿，长得特别漂亮，但生下来之后，这个王后死了。

然后国王又娶了一位，等于给白雪公主娶了一个后妈。

这里就出现了一个文学史上——甚至整个西方文学史、中国文学史上——非常典型的女性形象：继母形象，后妈形象。后妈形象是什么样的形象？想想都知道，不好。

这里面渗透了一种观念：现在只要你妈稍微对你不好，你就会说"这不是我亲妈吧"。我们总觉得亲妈一定是好的，后妈绝对不是好的。但事实上来讲，后妈也有可能是好的，问题是我们有一种天然的意识形态，好像后妈不好。

接下来，这个王后每天干一件事：对着镜子问——魔镜魔镜，谁是世界上最美的女人？

刚开始魔镜说：你才是世界上最美的女人。后来说：有一个叫白雪公主的，比你美一万倍。

这个过程当中有两点值得关注。第一，这个皇后、这个后妈，关注自己的是什么？外貌。女性比较关注自己的外貌，而且一定要胜过全世界所有的女人。第二，魔镜是站在什么角度回答她的？站在一个男性的视角上回答——它是一个评判者的角度，告诉你你才是世界上最美的，或者你不是。魔镜的视角是一个典型的男性视角。

皇后发现自己原来不是最美的，还有一个叫白雪公主的最美，于是开始了对白雪公主的追杀。

第一步，她找了一个猎人，想让他杀了白雪公主。但猎人最后心软了，不忍心杀。这里面体现出一件很重要的事：女人跟女人之间的争斗多么狠，但男人见到女人之后会立马心软。猎人拿了点猪肝之类的东西交回去。

再一问，还不行，白雪公主还活着。于是第二步，她自己行动：

1. 先给她一把梳子，一把毒梳子，没成；
2. 又给她一个苹果。这个苹果给得很有心机——一半有毒，一半没毒。怕白雪公主怀疑，她先咬了一口没毒的，再把有毒的那一半递过去。

白雪公主吃下苹果，死了。七个小矮人也救不了她，只好把她放进一具水晶的、玻璃的棺材里。

这时候谁看到了？王子看到了。你要知道，他看到的是尸体。稍微想象一下那个场面：看到一具尸体，他觉得——好美啊。

然后王子做了一件事：亲吻了一下尸体。接下来，白雪公主就醒了。

当然这个故事有不同的版本。在原来的版本当中，王子并没有亲吻尸体，是七个小矮人抬着她的过程中不小心把毒苹果咳了出来；也有一个版本是白雪公主被王子亲吻了一下，这个亲吻有特殊的魔力，让她活了过来。

你甭管哪个版本，背后渗透的观念是一样的：女孩啊，你只需要长得漂亮就够了。你哪怕是个尸体，都会有男人爱你。

最后，白雪公主跟王子终成眷属。而那个王后还要追杀过来，后来阴谋被撕破，带着镣铐跳舞。

整个故事看下来，白雪公主是一个什么样的形象？作为一个人、作为一个女人，她毫无主动的行动能力。她没有思想，没有独立的思考，没有独立的判断，永远是被动的，任人摆布。

白雪公主整个人物形象的特点就是"傻、白、甜"。她聪明吗？看不出来。她善良吗？看不出来。她整个思想、整个头脑是空洞的，就一个特点：美。而美的特点还落在"白"上。

一个小孩学了这个童话之后，会有什么感受？我不知道你们小时候读了什么，反正我记得我小时候，很多女孩读了这个，天天对着魔镜说"啊，谁是最美丽的人"，或者想办法把自己打扮得特别白。

它就是用这种潜移默化的方式，影响一个人关于审美的观念——到底什么样才是一个美丽的人。它建构了"白的人才是最美丽的"这样的观念，建构了一个人的价值观。

再取一个童话：灰姑娘。我觉得灰姑娘的故事，可以跟另一个故事对应上——海的女儿。

海的女儿的故事告诉我们什么？女孩对待喜欢的男孩，不要太主动。太主动，付出、奉献太多，到最后，你付出越多，死得越惨。

灰姑娘的故事告诉我们：女孩面对男孩，不应该主动，要学会欲擒故纵，要学会勾引。当你发现这个男孩对你有兴趣之后，你赶紧跑；跑的时候不要光傻顾着跑，你还要留下一只鞋子，让他有迹可循，过来找你。你越这样，一个男人就越加……

| 故事 | 教给女孩的规则 |
| :--- | :--- |
| 海的女儿 | 不要太主动；付出越多，死得越惨 |
| 灰姑娘 | 欲擒故纵；跑，但要留下一只鞋 |

你可以说这里有过度解读的嫌疑。但在潜在的意识形态上，你要知道：很多童话被反复阅读、反复接受，在这个过程当中，一个孩子就建立起"男人应该是什么样子、女人应该是什么样子"的观念。

你以为这样的观念是从小到大被人灌输的吗？不。你就是在阅读文学作品当中，在轻松愉悦当中，潜移默化地接受了。

所以这些东西很可怕。真的，你不断去读就会感受到。

### 影像：中国在画面里的位置

童话之外，影视作品是另一块好材料。

很多年前有一部好莱坞灾难片叫《2012》。这种好莱坞大片我是不爱看的，我觉得没兴趣，当时它热播，我也不想看。但上映之后，豆瓣上有一篇评论引起了广泛关注，题目叫《2012，中国拯救了世界》。评论说这片子真好，因为片子讲了一个中国拯救世界的故事。

我很惊讶：美国好莱坞大片，怎么会讲中国拯救世界的故事？这很奇怪。受这个驱使，我到电影院看了这部电影。看完才发现，我被骗了。

它为什么说中国拯救世界？因为这部电影当中出现了中国——那个诺亚方舟是在中国造的。

但这个呈现，恰恰不是中国拯救了世界，恰恰相反：它呈现的是中国依旧是世界的加工厂。诺亚方舟依旧是 made in China。而且它呈现中国，呈现的是西藏；里面出现的中国人，也都被处理成一副特定的模样。这个背后渗透着极强烈的政治问题，就是美国人对待中国的观念问题。

那反过来问：为什么中国人看到这部电影里出现中国，就激动了呢？

背后有一个潜在的、极强烈的心理：哎呀，美国电影居然出现中国了，太好了，太棒了。只要中国出现一点点元素，我们就觉得很高兴。这背后那种谄媚，那种对美国、对某种美国梦的渗透，你可以自己去体会。

到2015年，又有一部电影极为类似，也说中国拯救世界，叫《火星救援》——中国帮助了美国。很多人看完很激动，我看完一点也不激动。我不知道这个背后的观念到底是从哪来的。

### 商业片与民族叙事

再说一部你们大概都看过的：《我不是药神》。这片子挺火，评分也很高，票房也不错。

这个电影好不好？整体我觉得还不错，但有些地方不太够。

第一，它太商业片了。太商业片导致了一个问题：看到后半程，我感觉这就是一部典型的描述个人英雄的电影。它从一个药品的医疗问题切入，这是一个很好的切入点；但到后面，观众关注的不再是药品涨价的问题，而是程勇能不能被抓的问题。这种变化，其实是削弱了背后本身的社会的矛盾内涵。

第二，它为了拔高程勇这个人物形象，塑造了一个反面形象——那个卖药的商家，一副资本家的形象，往那一站，"你们都是……"，一副"我就是岿然不动"的样子。它没有把这个问题复杂化，没有讲述这个药的价格为什么不能降下来的原因。因为一旦讲述那个，程勇这个个人形象就弱了。所以为了拔高，它必须把卖药厂家的形象贬低化，然后让你去喜欢这个英雄人物。

为什么要这样处理？因为这样更商业化，大家看得更爽、更痛快。但事实上，它有问题。

还有一部电影，我不吐不快——张艺谋拍的《金陵十三钗》。

这个电影我看完以后，可能因为我这个人有点奇葩，我的感受跟大多数人的感受一点都不一样。所以我得出一个结论：我不能跟别人谈论电影。我一谈论电影，最后的结果就会发现——哇塞，意识形态真的是不一样。

怎么不一样呢？我看完《金陵十三钗》的第一感受是：这是典型的汉奸电影。

你们可能都惊讶了。为什么说它是汉奸电影？

很显然，如果你看过的话，片子里经常呈现一群穿旗袍的歌女——那十三个歌女，一排，向着银幕走来。这个场面呈现了好多次。它在干嘛？它在给观众看；与其说给观众看，不如说在给谁看？给西方人看，给西方的白男人看。它想呈现东方佳丽的风姿，让西方观众得到满足。

事实上，张艺谋拍这部电影，就是为了冲击奥斯卡。为了冲奥，他直接设置了一个西方白男人的人物角色，让这个白男人拯救了所有的中国女人。而影片当中唯一一个——也不是唯一一个，就是很重要的一个——真真正正的中国男人形象，佟大为演的那个，在影片三分之一处你必须要死掉。接下来，让这个西方白男人来拯救世界。

东方文化是一个女性文化，西方文化才是一个阳刚的男性文化。

如果你没有这个体会，我再说我讨厌这个电影的第二点。这一点要跟另外一件事情连起来说，因为它是一个普遍的文化现象。

2019年六七月份，有一条新闻：林志玲结婚了。这件事在网上引起轩然大波，很多中国人开始骂。这很奇怪——人家结婚，你不祝福，你还骂。

为什么骂？因为她嫁给了一个日本人，而且好像还是一个其貌不扬的日本人。

按道理讲，别人结婚，她嫁给谁是她自己的事，你为什么要干涉？但在这个过程当中，你会发现有东西干涉进来了——民族主义情绪干涉进来了。

第二，林志玲在中国的大众文化形象当中是一个什么样的形象？女神形象。与其说是女神形象，不如说是一个男性的欲望对象。我们中国男人的欲望对象被一个日本男人夺走了，怎么可能。

这背后渗透的是什么观念？是把林志玲，或者说以林志玲为代表的这样的女性物化的特点。而更重要的是，它动用了那个潜在的、底层的意识形态：用女性的身体被玷污，来承担民族的耻辱。

这个跟《金陵十三钗》背后的逻辑是一样的。你会发现很多抗战神剧当中，一定要呈现一个场景——我特别讨厌这种场景：中国的一个良家妇女被日本人强奸，好像只有这样才叫体现出民族仇恨。

你觉得它能呈现仇恨，可以。但你为什么觉得这样才能呈现仇恨？

而在《金陵十三钗》当中，你会看到这个逻辑反复呈现：到最后，他用妓女换女学生，十三个妓女换十三个女学生。为什么是十三个？背后没说出来的逻辑很简单：因为你们已经是妓女了。说白了，你们已经受过一次伤害了，再受一次伤害又有何妨？

这个逻辑，我不能认同。

所以有空的时候，需要去琢磨更多没说出来的意识形态。你还会解读出文学作品背后更丰富的内容。

### 本讲提到的题目

> **题目**（问答题）：简要回答你所理解的阿尔都塞的意识形态理论。也可能换个问法：简要回答一下你所理解的意识形态。把背后的逻辑讲清楚即可。

**解析**：这道题要答的是一条链，不是几个名词。按四层铺开：

1. **功能**：意识形态国家机器干两件事——自然化，把某种说法讲成天然如此、必然如此；合法化，为统治者的统治提供合法性，历史由胜利者书写，写的正是"胜利者为何必然胜利"。
2. **运作方式**：建构个体为主体，核心是建构个体与现实的想象性关系。三步走——把个体询唤为主体（高考、招聘），个体对主体臣服（subject 作动词即"使屈服"），主体与主体的互认（"我们都是中文系的大学生"）。
3. **形态**：意识形态是一个镜像序列。人无法见到真实的自己，只能通过一面面镜子（父母、同学、老师、周围所有人的反馈）指认"那就是我"；意识形态提供的正是这一面面镜子。
4. **性质与后果**：意识形态没有历史，从来如此，你不在这个意识形态里，就在那个意识形态里，"一切都不信"也是一种信。正因如此，经济基础与上层建筑之间不是简单的决定关系，而是复杂的多元跨越关系。

若题目落到文学上，再补一层：症候阅读——把作品表层的话当症状，追问深层没有说出来的意识形态，就像医生从发烧、流鼻涕追到病因。

> **提示**：答题时不要把意识形态直接等同于"骗人的虚假观念"。这门课反复强调的是：对错真假不是关键，关键是它已经在发挥作用；而没有人能站到意识形态之外。

> **承前启后**：上一节讲完「意识形态如何运作：从询唤主体到症候阅读」，下一节接着讲「再现：为什么没有一种呈现是如实的」。

## 再现：为什么没有一种呈现是如实的
> 对应块：BLK11 | 覆盖分集：P11 | 块标题（分集名）：《20191014 文学与世界（3）：再现与模仿》

### 文学再现的到底是哪个世界

文学与世界到底是什么关系？这是“文学与世界”这一章要回答的总问题。上一讲我们从意识形态那一头切进去，最后落到一种读法上——症候阅读。它要挖的是文本背后那些没有说出来、但已然说出来的意识形态。这种读法不好学：你得有大量的阅读基础和阅读经验，才可能发现那些“它没说”的东西；因为大多数人很容易就掉进去了，掉进文本已经告诉你、并且声称告诉你的那部分内容里。这一讲换一个更朴素、也更接近常识的入口：文学是再现世界的。

听起来没什么可争的。可只要多问一句，麻烦就来了：那个“再现”，再现的到底是哪个世界？

有人说，再现的是现实生活，是自然生活。有道理。但你马上会碰到《西游记》这样的作品：它再现的那个生活，跟我们现实生活的逻辑几乎完全不一样。它是神话，不符合现实生活的规律，可它依旧是经典。那它再现的是什么？我们当然也可以说，它再现的是一个虚幻的世界，一个象征性的世界。

也还有另一种情况。有的作品几乎不谈什么社会现实，它只是抒发人的情感。裴多菲那几句诗——“生命诚可贵，爱情价更高。若为自由故，两者皆可抛。”它再现什么现实生活了吗？没有。它就是表达一种思想感情。那么它再现的，可能是人的情感世界，是主观世界。

> **提示**：所以“文学再现世界”这句话本身是不完整的。在讨论再现得像不像、真不真之前，先得交代清楚说的是哪个世界。同一个“再现”，指向自然生活、指向虚幻象征、指向主观情感，后面整套讨论都不一样。

这一讲我们把“世界”限定在一个最窄、也最基础的含义上：自然，自然生活。正因为有了这样的理论，整个西方才长出了一整套关于“文学再现自然”“文学再现现实生活”的艺术观念和艺术理论。要进这套理论，先得把“再现”这个词本身拆开看。

### 再现：外部事物在作品中的呈现

“再现”与“模仿”常被并提，这一路理论在西方长得很深，得先把“再现”这个词本身交代清楚。

再现是艺术理论、美学领域里的一个重要概念，英文是 Representation，也有译成“表征”的——某种表征，就是某种呈现。

> **定义**：再现，就是外部事物、外在现象在作品中的呈现。

这个定义说起来不复杂。有的同学会想：再现那不就很简单嘛，我呈现一个事物，对吧。从日常生活经验上讲，确实简单。可从理论上讲，很多问题细思下去，你会发现有很大的问题。

#### 再现的前提是那个东西不在场

首先，当我们去再现一个事物的时候，它是有前提条件的。什么前提？往往都是这个事物本身不在场。

甚至可以再往前推一步：从某种意义上说，艺术之所以会诞生、会出现，很重要的一个原因就是事物本身不在场。

举个例子。远古时代，我到一个地方去玩，玩完回来跟小伙伴介绍：那个地方可美了，我去了海南，三亚那个地方可美了。可你光跟他说“美”不行，我得把那个事物呈现给你看。那个时代又没有摄影机、摄像机，怎么办？我可以给你画出来。画的时候，我就把那个“怎么美”呈现出来了。

当然，不同的人画，结果完全不一样。技术水准不一样，画的水平不一样，于是就有了高低之别。渐渐地，就会出现一种人：他在绘画领域能力极强，再现能力极高。于是他就成了艺术家。

从某种程度上讲，很多艺术都是这样诞生的，包括我们的文学。文学是语言的艺术，那语言是怎么产生的？语言产生的一个很重要的原因，同样是事物不在场。我说“那天我看见了一棵树”，这就是在给你呈现，我在描绘那棵树的样子。正因为那棵树不在场，我才必须描绘，必须发明一套语言去指称它。反过来说，如果所有事物都在场，我似乎根本不需要发明一个符号去指称它。

所以再现是某种呈现的过程。但问题恰恰出在这个“过程”上。

#### 呈现的同时就是转化

在呈现的过程当中，会产生一系列问题。最要紧的一条是：当我在呈现一个事物的时候，它一定意味着某种事物发生了某种转化。

假设这间教室里发生了一场斗殴。我把这件事转告给另一个教室里的人。以往我们总觉得，这就是一次简单的呈现，一次如实的描绘。可你仔细看这个转述过程，它已经变了。

本来是一个空间里、一个三维空间里发生的事情，可我必须借助语言来转述，那我就必须先说什么、后说什么。两件事可能是同时发生的，但同时发生的事情，我能用语言同时说出来吗？不能。我必须先说一件，后说一件。而先说哪件、后说哪件，可能直接影响意义的表达效果、它产生的作用效果，以及听者的倾向。

```text
   三维现场：甲挥拳、乙后退、旁人惊呼，同时发生
        │
        │  换成语言这个媒介，只能一件一件说
        ▼
   一维链条：先说什么、后说什么
        │
        ▼
   顺序 → 因果解释 → 意义、效果、听者的倾向
```

读图说明：上头是现场，几件事挤在同一瞬间；下头是转述，它被迫排成一条先后相续的线。顺序一旦排定，听者就会自动把“先说”读成起因、把“后说”读成结果。

所以把一件事直接转述出去，这个再现的过程，就是把三维空间里的事情，赋予了一个时间性的一维链条，把它以线性的方式呈现出去。这个转换当中，一定会消失掉很多东西。

再把问题复杂化一点。假如这场斗殴全班同学都看到了，每个人回去都把这个事情描绘一遍，你会发现每个人描绘的都不一样——角度不一样，甚至立场也不一样。在这个过程里，你还要给它赋予因果的解释，赋予某些时间性的链条，等等。

> **结论**：再现远不是简单的一种呈现。只要它是再现，它就绝不可能是如实的。它一定有某种转化，一定有某种损失，绝不会像电脑的复制、粘贴那样原原本本。

那接下来要问的就是：这场转化，究竟被哪些东西左右？有三个层面值得盯住——媒介及其文化规定、文本的编码，以及作品背后的生产机制。

### 媒介不是透明的

第一个，也是最容易被忽略的一个：再现的媒介本身。因为媒介总给人一种它是透明的感觉——它好像自然而然就把东西呈现出来了。

#### 监控、画框与“无图无真相”

一个小孩在那边看到一件事，转述给你，你就觉得他说的好像都是真的。但假设那个场景内部有个监控摄像，你先看监控，再听他转述，你会发现有差异。为什么有差异？因为两者再现的媒介不一样：一个是通过语言转述，一个是通过图像呈现。语言转述的时候，我们觉得好有道理，一二三四，条理清楚；一看到图像，你会发现未必是那么回事。媒介本身，经常会影响我们对这件事物的认知。

那监控摄像呈现的东西，就一定是那个事件本身、那个真实的本身吗？我们往往觉得是。但未必。

我有一个观点：越是那种让我觉得它可能是真实的东西，越具有欺骗性。因为它越真实，就越容易骗你。

我们经常在网上说“无图无真相”。这句话背后的逻辑是：图像要比语言更具真实性。一个图像摆出来，那才叫真的；光用语言说没用，得呈现图。可图像就真有真实性吗？咱且不说 PS 的问题，就算是它呈现的是真的，你也得知道：所有的图像都有一个东西存在——画框。

只要它以图像的方式呈现，它就有画框。既然是画框，就必然有“什么可以被纳入这个画框、什么被排除在画框之外”。那我就有可能在这个过程当中有选择地呈现某些东西，排除掉某些我不想让你看见的东西。它的欺骗性更强。

> **易错点**：不要把“更接近现场”直接等同于“更接近真实”。语言有语言的选择，图像有图像的选择，区别只在取舍的方式，不在有无取舍。

很多年前有个“文章出轨”的事件。爆料一定要爆一张照片，光说不行，得要这张照片。我在网上一看，老远一看，好像那个人很像文章，可好像又说不像。反正就是你觉得很像。但网友就已经觉得坐实了。到底是不是，我也不知道。可我们总有一种感觉：好像图像很真实。

| 比较项 | 语言转述 | 图像呈现 |
|:---|:---|:---|
| 给人的感觉 | 有条理、有因果，容易被说服 | 直观、具体，被当成“证据” |
| 转化的方式 | 三维压成一维时间链，先说什么后说什么 | 用画框截取，框内框外就是取舍 |
| 欺骗性的来源 | 顺序与因果被悄悄安排 | 越像真的，越容易被当成真的 |

所以在很多问题上，我都要强调媒介本身。你要意识到一个再现问题，首先应当知道它是以什么样的媒介方式存在的，然后再去讨论其他问题：它是靠语言说的，还是靠图像呈现的。

#### 改编、访谈与作者的自我阐释

这就涉及一个很常见的毛病。我指导学生写论文的时候，有同学爱做一件事：研究一个小说，然后直接把这个小说改编的电影跟小说相等同。因为他觉得那个电影高度还原了小说的内容，于是就不想太多地看小说，觉得看这个电影就够了。

我要说的是：它俩是不同的媒介。而且因为媒介不同，它再现的内容就有极大的不同，你不能简单地等同。

中文系的学生尤其要注意。你要看《红楼梦》，千万不要认为看了一遍电视剧版的《红楼梦》，就是看过《红楼梦》了。有同学会这么问：老师，我没看过《红楼梦》，我看过电视剧版的，算不算我看过一次《红楼梦》？我只能这么说：你要看的是老版的《红楼梦》，勉强算你看过一次；你要看的是新版的《红楼梦》，算你负一次——你还得再去看。那是两个完全不同的媒介。

还有一种更隐蔽的等同。有同学写毕业论文，会去找作者访谈、创作者访谈，然后拿这些材料去研究小说：作者为什么写这个小说，写这个小说的目的是什么，等等。我看到这儿就会追问一句：你忽略了，创作者对自己小说的阐释，其实也是一个文本，它跟小说一样，也是一个文本。可你把它当成了真实——这是最大的问题。

在我看来，创作者对自己小说的阐释跟小说本身，都是不同的再现，只不过用了一种不同的媒介：一个是小说，一个是访谈。访谈这种方式给人的感觉好像更真实一点，所以你就觉得它好像更真实。其实不是，你犯了一个很重要的错误。

> **注意**：作者的自我阐释是理解作品的旁证，不是作品的“底稿”。它提供的是一个视角，不是一把标尺。

有的同学会拿这个来跟我抬杠。我在课上对哪个作品发表了意见，他就站在某些角度反驳我，理由是这个：“老师，这个作者不是这么说的，作者对自己作品的阐释是这么说的。”甚至会说：“老师，我跟吴京见过面，我认识吴京，他不是这么说的。”你要知道，就算你跟吴京很熟，吴京对自己作品的阐释，也是另外一个再现，也是一个再现文本。

没有哪个再现是绝对真实的。尤其是那种声称自己是真实的东西——比如一部影片，它是纪录片。纪录片就比电影更真实吗？不。但因为它声称自己是真实的，所以它更加具有欺骗性。

### 文化规定：读之前你已经被预设了

媒介背后还有一层东西，叫媒介的文化规定性。

什么叫文化的规定性？就是我预先告诉你这是什么。给你一个作品，你没看过，但我告诉你，它是一个小说；或者我告诉你，它是一部诗歌——你会发现，你的阅读期待是不一样的。当它是小说的时候，我们有一整套关于小说的文化规定：小说是要讲故事的，小说是要人物、情节、环境的。同样，作家在再现一个事物的时候，还是这场教室里的斗殴，我以小说的方式去再现，和我以诗歌的方式去再现，因为媒介背后的文化规定不一样、关于小说和诗歌的理解不一样，再现的方式也会不一样。

这种规定也不只限于文体。比如我告诉你，这个作品是虚构的还是非虚构的，它的影响、它的效果、再现的效果完全不一样。

#### 两部“真实事件改编”的电影

十一的时候，我去看了《我和我的祖国》。里面有很多段小故事，有些就是真实事件改编的。比如第一个故事：历史上真的有这样一个人，是开国大典国旗的设计者，一个工程师；开国大典前一夜，他经历了种种斗争，很不容易。

但我看这个电影的时候，有些地方让我感到不适。让我不适的，一定不是那段史实的真实，而是导演在史实基础上做的艺术加工。

片子里有一个情节：黄渤演的那个设计师，发现一个小球有问题，需要加固。怎么办呢？他需要一些稀有的金属元素。于是接下来就经常出现一个人到房顶上拿着大喇叭喊。我没有考证过，但我觉得这不太真实。下面的场景就更不真实：恨不得全城的人都来到这儿，然后说“我给你这个，给你那个”。

我一看到这儿，就明显知道导演要在这儿让观众哭一下。我看电影的时候一般是这样：我知道这儿该哭了，立马要回头看看大家都哭没哭。我这个人，很讨厌。然后发现，有的泪点低的人就开始哭了。这个时候我就知道——我是有理论素养的人，我不能这么容易就成为导演眼中的理想观众。我眼泪不是那么好骗的。我背后要琢磨一下：他采取了一个什么样的方式让我哭。

那个场景肯定是导演的加工。而这个加工反而让我看得不真实：他为了营造情感，设计了一个稍微廉价一点的、悲情一点的小手段。这个小手段显得不是很真实。

可问题在于，因为这个故事宣称自己是“根据真实事件改编”，大家看的时候就忽略了它有可能有些地方是导演的艺术加工，进而相信这个故事全部内容几乎都是真实的。而且你不相信还不行——你一说不符合真实，你就是不了解历史。这是很大的问题。

国庆我还看了《中国机长》，也是真实事件改编。因为大家都知道这是真实事件改编，看的时候就觉得里边所有情节好像都是真的。可我能吐槽的地方，我相信都是导演自己加的戏。比如副机长跟空姐之间那段有点半调情的戏码，总觉得很奇怪；尤其到最后，机长都已经那样了，两个人还互相调情，就感觉那么矫揉造作。那个场景，我相信应该不是真实的。

还有更明显的：看到后半段，只要音乐一起来，我就觉得完了，他又想让我哭了。我看的时候一直在看表，就想看它整个的节奏。这件事本来没有多长时间，它讲了两个小时，怎么讲？我发现到半个小时的时候，飞机就已经开始出问题、开始破裂了；后面一个半小时都在不断地渲染，而渲染的主要方式，在我看来就是背景音乐。

有同学问过我：老师，你怎么判断一个作品、尤其一部电影的好和坏？这个很难说，很难说。但我有几个形而下的标准。第一个：艺术水准高的电影几乎不用背景音乐；艺术水准低的，几乎背景音乐从头贯到尾。你去看好莱坞的很多片子——这话可能会得罪人——很多漫威的电影，很多灾难片、大片，你仔细去听，几乎音乐从头贯到尾。为什么？因为音乐最容易带节奏，最容易带动人的情感。那个场景其实一点都不感人，但音乐一起，情感立马就走起来了，你就不自觉地想哭。真正有水准的不需要音乐去带节奏。所以你会发现，越是艺术片、越是文艺片——当然也不是说所有文艺片都是好片——越没有背景音乐。

所以我看《中国机长》的时候，也觉得它稍微有点矫情。但因为这件事又是根据真实事件改编的，很多人在这过程当中就觉得，背后很多东西都是真的、绝对真实的。不是那么简单。他把背后很多艺术性的问题给忽略掉了。

#### 类型成规：什么叫“吸血鬼电影”

再举一个轻松点的例子。大概十年前，有一部全球流行的小说，在中国也很流行，后来改编成电影，也非常流行，叫《暮光之城》。

它讲的是什么故事？吸血鬼的故事，吸血鬼的爱情故事。因为全球流行，诞生了很多“暮迷”。当时有两派：一派是哈利波特的迷，一派是暮光之城的迷。据说暮迷跟哈迷不共戴天。哈利波特是我从小看到大的，不过我对《暮光之城》这个小说没什么兴趣。

《暮光之城》讲的是吸血鬼的爱情。当时很多人看完小说、看完电影，觉得这个爱情故事好伟大：它超越了阶级，超越了种族，甚至超越了人和鬼之间——“什么都没有”的爱情。很伟大。于是很多人觉得这个作品很好。

但还有一批人，看完之后的反应是：这哪叫吸血鬼电影啊？看到最后也没看见谁咬谁。这些吸血鬼从来不怕圣水、不怕大蒜、不怕十字架。他说这不好，这电影一点都不好，因为它根本就不叫吸血鬼电影。

他为什么能得出这个结论？因为他非常了解这类作品的文化规定。

而那些第一次看、觉得这个作品很伟大的人，知道了原来有一类作品叫吸血鬼小说、吸血鬼电影，带着这样的期待去看别的吸血鬼电影，感受是：哎呀，太恶心了，原来吸血鬼是这样的，不像《暮光之城》那样子。

所以读很多作品，背后其实有它整套的文化规定。你带着哪一套规定进去，看到的就是哪一个作品。

#### 《色戒》与《红高粱》：评判背后的前见

十年前，我在上大学，上大三，学文学理论课——我们那个文学理论课都是大三上的。有一次，我们那位老师有事，那节课没来，说下节课也来不了。可课还得上，怎么办呢？让课代表放一个电影，大家看两节课就过去了。

放的是什么？李安导演的《色戒》。这个电影在当时让我们印象很深刻：香港刚上映，内地还没有上映，他也不知道从哪找到一张光盘。当时我们非常激动。到了下节课，一般来讲老师不来，很多学生觉得不就是看电影嘛，就不来了；但那次全班同学全来了。不光全班来了，同学们还奔走相告，很多外系的同学也都来了。我估计，大家主要想看的是：他放的到底是删减版，还是未删减版。

看完以后，大家都很激动。果然，放的是删减版。

下节课他再上课，不能光看，还得讨论。一讨论，班里一个女同学特别义愤填膺，跟老师说：“老师，我觉得这电影一点都不真实。”为什么不真实？因为删的东西太多了。删得太多，就导致人物内心情感的变化——主要人物王佳芝的内心情感变化——我感受不到。所以说它一点都不真实。

我当时在底下就想：如果不删的话，你就能感受得到了？

她为什么说这个东西不真实？我的解读是：因为她觉得这个东西被删了，它才不真实；她不是真真正正感觉到了不真实。那么这个“不真实”的评判背后，潜台词是对审查制度背后那种暴力的反抗——“你怎么能这样，这样的东西都给删掉了，其实这样的东西最能体现人物的情绪心理”。说实话，我也不觉得它能体现出什么心理。但她背后的那种否定，在我看来是具有某种政治性的，而不是简单地对艺术性做一个评判。

这种评判，跟我们当年对《红高粱》的评判几乎是一致的。

《红高粱》是莫言写的小说，后来被张艺谋改编成电影，在欧洲的国际电影节上获了大奖。先在西方获奖，然后在内地上映。上映之后很多人进去看，看完的反应是：没意思。为什么？想看的东西没看到。

看《红高粱》想看什么呢？你琢磨一下背后的文化逻辑就明白了。它在西方获了奖，得到了西方社会的认可。而那个年代，西方社会在人们的联想里是什么？是腐朽的、肮脏的、没落的。腐朽、肮脏、没落又等同于什么？等同于性，等同于性的暴露。所以它到国内上映的时候，人们看的就是看这个。结果发现没有，或者没那么什么。于是很多人觉得：哎，没意思。

这套逻辑是潜在的。你不去了解背后的文化规定，就只会觉得“观众口味奇怪”；了解了才知道，他们带着一整套前见走进电影院。

### 编码：把作品当文本读

第二个层面，是再现的编码层面，也就是文本。

还是那场斗殴。有人把它转述到另一个教室之后，你首先要关注媒介本身以及媒介背后的文化规定；第二个要关注的，就是他说的内容本身。内容本身就要进行文本细读，而文本细读要求你去关注这个文本背后的形式、结构、修辞，甚至音韵。

关于文本的解读、文本的细读，背后有很多方法，这里不展开，留到讲“文学与文本”那一章再谈。

### 生产机制：作品也是商品

第三个层面，是再现的社会层面，也就是生产机制：从文化生产、文化消费的角度去研究作品。

很多作品，本质上跟市场、商业有着密切的联系。尤其在当今时代，一个作家要想成为作家，必须进入市场。最简单的例子：你要想成为作家，首先得写出来。光写出来还不行，还得出版，得找出版社，甚至联系报社、出版社。书出完了得定价，定了价就得放到书店里去卖。这个时候，这本书就成为了一个商品，它必然跟生产、消费产生联系。

于是你会发现，有些作品就是为了流行而写作的，说得更俗一点，就是为了钱写作的。

但这并不意味着为了钱写作的作家都写不出好作品。很多作家都是为了钱写作。比如法国著名的现实主义作家巴尔扎克，他的写作其实就是为了赚点稿费。那个时候稿费虽然不多，但能够维持生计：没钱了，写点文章、写点小说赚点稿费；又没钱了，再写点小说。所以你看，巴尔扎克的很多小说都不长，都很短，但写得还挺好。

不过，因为你知道了这个目的——他有的时候是为了流行而写作——你考察的时候，有些角度就会变。

#### 从稿费到诺贝尔文学奖

前两天，诺贝尔文学奖刚颁。每年诺奖一出来，很多网友都会提到一个日本作家：村上春树。然后开始说，哎呀，他又陪跑了一年。

我在这里告诉你：村上春树是绝对不可能获得诺贝尔奖的。他这辈子都不可能，下辈子也不可以。当然，这话你们就一听，万一他明年就获得了，打脸了，这也不赖我。但我觉得他是绝对不可能的。

为什么？因为他是典型的通俗流行作家。至少在文学界，很多人把村上春树划到通俗性写作里。相当于中国的郭敬明——当然可能比郭敬明好点，比郭敬明稍微高级一点。郭敬明是典型的为了流行而写作。村上春树有他的原创性作品，可在原创性作品之后，他就开始不断复制自己的写作模式。一旦开始不断复制，这就形成了一种商业化，就跟生产、商业生产一样。

而诺贝尔奖颁给的是什么样的人？非常小众、非常具有独创性的、所谓极高品位的作家。基本上往往是大家没有听说过的，但又体现出某种原创性、独创性的“艺术桂冠诗人”式的作家。通俗作家，你越流行，往往越不会给你。

之前有一个作家叫格雷厄姆·格林，据说 26 次提名诺贝尔文学奖，但从来没得过。为什么？因为他的小说写得太好看了，太多人爱看了。为什么那么多人爱看？因为你迎合了很多人的趣味。而迎合了很多人的趣味，就意味着你在不断的创作过程当中，势必遵循某种商业性的、复制自己的写作模式。村上的小说你一看就有感觉：后面那些基本上都在不断循环，写得都差不多。所以他就进不了诺贝尔奖的法眼。

> **提示**：这里说的不是“畅销即原罪”。讲的是生产机制如何反过来塑造写作方式：当复制成功模式成为最稳的收益路径，作品的独创性就会被这套机制一点点磨掉。

#### 《金瓶梅》里被删去的文字

从生产的角度，我再举一个例子。

我读博士的时候，有一个同学专门研究明代文学，他的毕业论文写的是《金瓶梅》。我一看到他的论文题目就很有兴趣，说：你这文章让我看看，你到底研究什么问题。结果发现，他专门去研究《金瓶梅》当中那些被删去的文字——“此处删去多少字”那种。我就更有兴趣了：你为什么要研究这些？

他不光是研究，还把这些文字跟整个明代文学、尤其民间文化当中的一些文本联系起来。他发现，《金瓶梅》当中那些被删去的文字，说白了就是那些色情场景的描述，都是当时坊间书坊的套话。

什么意思？如果明代要出十本流行的色情小说，十本当中会有八本都出现那些被删掉的文字——它是一些套话。

这说明什么？说明《金瓶梅》里那些色情文字，跟西门庆这个人物形象、跟潘金莲这个人物形象，没有什么直接必然的联系。因为当时这种叙述方式已经成为一种流水线式的生产方式：你既然想吸引读者注意，那好，我就得有一些色情描写。这些色情描写已经被市场形成了一种套话。《金瓶梅》也不例外，也去描写这些东西。

接下来的问题是：当我们把《金瓶梅》作为一个经典作品——大家都知道它是四大奇书之一，跟《西游》《水浒》这些并列——我们就认为《金瓶梅》的所有内容似乎都是作者的原创。我们就忽略了，它在生产的过程当中，其实有一整套背后的生产机制、那种非原创的东西在里面。

看到这篇文章的时候，我就在想唐代的很多诗人。比如某一句诗非常有名，但它其实是化用前人的诗句。这个过程，我们当然可以说是诗人的独创；可如果再深入到当时整个社会的生产，可能诗歌已经形成了一整套流行的套话，那么改编前人、化用前人的诗句，也成了某种生产方式。这个时候，某些经典作家、经典作品的原创性，就没有那么高。

这些东西，如果你不关注生产机制，很容易忽略。你很容易认为，李白的某一句诗就是他原创的、就是他天才的表现；但你忽略了，可能他在读了大量作品之后，很多诗歌创作已经形成了一种套路——就跟我们今天的流行歌词在写作的时候也会形成套路一样。这些问题，你不了解生产机制是不会发现的。

```text
   书店上架，成为商品
    ↓
   销量与口碑
    ↓
   稿费与下一部的选题：反过来规定怎么写
```

读图说明：作品一旦进入这条链，写作就不再只是表达，它同时是一次生产决策；链条末端收上来的销量与口碑，会回头改写下一部的写法。

回到最开始那个问题：文学再现的是哪个世界？我的答案是，先别急着回答“哪个世界”，先看清楚它被谁、用什么、在哪一层改写过。媒介决定了它怎么被看见，编码决定了它被组织成什么样子，生产机制决定了它为什么长成这个样子。只要它是再现，它就已经不是那个东西本身了——这句话，是这一讲真正要你记住的。

## 床、镜子与显微镜：文学怎样再现世界
> 对应块：BLK12 | 覆盖分集：P12 | 块标题（分集名）：《20191014 文学与世界（4）：镜子说、现实》

我们刚才一直在谈再现这个概念。说白了你要是从理解上能理解到那儿，其实也就行了——后面这部分是我的延伸，有点深。假设这是研究生的课，这部分内容是重要的内容，因为"再现"没有那么简单；但作为本科生，你理解到这儿就够了，这就是一个最浅层面的理解。

接下来我们谈第二个。后面谈的东西都比较好理解，而且比较重要。因为再现是一种艺术观念，整个人类文明史上，围绕它形成了各种不同的说法：最早有模仿说和镜子说，到19世纪、20世纪以后，又长出了现实主义与自然主义这套更复杂的理论。这些都是文学向外看的那一半。等这一半讲完，我们还要翻到向内的一半去，看看表现与抒情。

### 柏拉图的床：模仿的模仿

最早提出模仿说的是古希腊哲学家柏拉图，比他的学生亚里士多德还要早一点。柏拉图在《理想国》里有一个著名的关于床的比喻——这是他几个重要比喻之一，之前我们讲过洞喻，这里讲的是床喻。

他讲的是艺术的模仿。什么是艺术？艺术是对现实生活的某种模仿。他举的例子是一张床。

现实生活当中有一张床。这张床本身就是一个模仿：工匠在打造床的时候，是按照脑子里那个床的印象、那个理念、那个概念制造出来的。大家都能知道，工匠还没把床打造出来，脑子里已经有了关于床的一个概念，然后他照着这个概念打造了一张床。而画家画的是现实生活当中的床。所以艺术就是对现实生活的模仿。

这样就有三层东西：

```text
理念世界（真实的存在，说不清道不明，但一说床人人都有关于床的认识）
    ↓ 工匠照着理念打造
现实世界（工匠造出的那张床，模仿得像与不像，看工匠的手艺）
    ↓ 画家照着现实中的床作画
艺术世界（画出来的床，模仿的模仿）
```

读图说明：每往下走一层，就离"真实的存在"远一层；艺术落在第三层，所以它是"影子的影子"。

第一个是理念世界，第二个是现实世界，第三个是艺术世界。理念世界是一种真实的存在——虽然你根本说不清那理念到底是什么，但好像冥冥之中一说床，我们大家都有一个关于床的认识，这是一个说不清道不明的东西，但它是理念。现实世界是对理念的模仿。当然，既然是模仿，就有模仿得像和不像：不同的工匠打造出来的床不太一样，有的好有的不好，这是模仿能力的高低问题。艺术世界呢？是模仿的模仿。

因为它是模仿的模仿，它离真实的存在是比较近还是比较远？比较远。所以在柏拉图那里，艺术的地位是高还是低？很低。因为它是对模仿的模仿，是影子的影子。柏拉图认为理念才是最真实的、最高级的存在，艺术跟真实之间隔了三层，所以他认为艺术实践是很低级的。

也正因为如此，在《理想国》里，诗人的地位极低。他觉得诗人说的都是些无关痛痒的东西，诗人永远跟随在现实生活的后面，不可能对这个社会有多大的推动。

但柏拉图这套说法里，有一样东西留了下来，而且影响极大：他建构了一个二元关系——一个是原本，一个是摹本。原本是现实生活的世界，摹本是艺术。艺术永远只是一个摹本，只是一个影子。

> **结论**：柏拉图把艺术放在"原本—摹本"的下游，这个结构比"艺术很低级"这个具体判断活得更久。后来的模仿说、镜子说、现实主义，都是在跟这个结构打交道。

### 这套说法真正的破绽

当然，按照我们现在的看法，你们觉得他哪儿有问题？有同学说：这是唯心。你要非这么说，也对；但我建议大家以后不要简单地用唯物、唯心来评判所有事情。唯物唯心是一个框架，你很容易就把它归成"这是唯物的""这是唯心的"；一旦标签化，就会忽略它内部的很多差异。比如康德，严格意义上讲当然是唯心的，但唯心跟唯心可不一样。唯物唯心在中学阶段需要你了解，上了大学就不要再拿这个东西来概括了。

而且你仔细想：柏拉图认为艺术是对现实世界的一种模仿——这不就是认为意识是对物质的一种反映吗？从这个角度讲，它反而像是唯物的。但它这个"唯物"，忽略了人的主观能动性。

所以真正的问题不在标签上，而在两处。

第一，他忽略了艺术家的创造性。难道艺术家只是对现实生活里那张床进行模仿吗？他不会创造出一个别的床吗？他没有别的想象力吗？创造性在哪里？如果只是一种模仿，创造性就没有位置了。

第二，艺术是对现实生活的某种模仿，这个我承认；但模仿的对象到底有两个东西：一个是表象，一个是本质。柏拉图认为艺术模仿的是表象还是本质？只是表象。正因为它只抓表象，他才觉得艺术离那个本质的真实存在特别远。可问题是：艺术能不能模仿本质？能不能呈现现实生活当中的某些本质规律？应该是能的——我们现在当然觉得应该是能的。这才是他最大的问题。

> **易错点**："艺术模仿现实"和"艺术只能复制表象"是两句话。柏拉图的问题在后一句，不在前一句；模仿说本身并不必然否认艺术能揭示本质。亚里士多德要做的，正是在这个关节上把柏拉图的结论扳回来。

### 亚里士多德：诗比历史更真实

接下来说第二个人。他也是从模仿出发——这是柏拉图的学生，亚里士多德。他写过一本跟文艺理论有关的著名著作，叫《诗学》。

听说过吗？没听说过。建议大家人手一册，这本书是名著。我经常跟学生说，你的书架上一定要摆几本能够证明你读过中文系的书。不要摆《红楼梦》——没学过中文系的人书架上也有《红楼梦》，那证明不了什么。要摆《说文解字》《文心雕龙》，哪怕《论语》《孟子》，一看就知道这是中文系的书架，而不是文艺青年版的。你可以没看过，但你一定得有，不然大学真是白读了。

版本就选商务印书馆的。那一整套"汉译世界学术名著丛书"，红皮的哲学类，我也有这么一套。我也必须承认，我不是全看过，有的书只看了一半；但至少家里有，感觉心里很踏实——这是一种文化资本，你知道吧。

亚里士多德在模仿这一点上继承了柏拉图的观念：他也强调艺术创作是一种模仿，创作过程是模仿过程。但他往前走了一步——他认为现实生活是个别与一般的结合，是普遍性与特殊性的结合。正是这两个观点的结合，他在《诗学》原文里提出了一句话：诗比历史更真实。

#### 先把"诗"的范围弄清楚

这里要解释一下：《诗学》里的"诗"，不是我们现在理解的诗歌，也不是史诗，它的范围更大。往大了说，一切艺术都可以叫诗；往小了说，所有文学都可以叫诗。

所以我们有时候看到"中国诗学"这样的题目，它研究的内容不光是诗歌——中国诗学从某种程度上就是文学理论，中国的文学理论就叫诗学。大家要有这个意识：诗学并不只是诗的学问，它是文学的学问，甚至是整个艺术学的理论。所以"诗比历史更真实"里的"诗"，说的不是诗歌比历史更真实，而是文学、甚至所有艺术比历史更真实。

#### 可能发生的事，与已经发生的事

那问题就来了：历史是真实发生的事情，诗呢？文学艺术往往都是胡编乱造的。他为什么说诗比历史更真实？

亚里士多德的解释是：诗描述的是可能发生的事情，历史描述的是已经发生的事情。这是两者最大的区别。

这个区别背后说明什么？诗呈现的是本质的规律、本质性的东西、规律性的东西；而历史呈现的是个别的东西、个别性的、特殊性的东西。所以在这个意义上，诗比历史更真实，因为它能够反映出某种本质规律。

你可能会反问：柏拉图不是说理念世界才是最真实的吗？没错，理念世界就是世界当中的某种本质规律——诗才能呈现，历史不能呈现。

> **结论**：亚里士多德依旧承认原本与摹本的关系，但他认为艺术能够呈现现实世界的本质规律，而不仅仅只是再现现实世界的表象。这是他对柏拉图的一个推进。

而恰恰是这样的推进，影响了整个欧洲现实主义的理论基础。

### 镜子说：越像就越好吗

从亚里士多德再往后，到了文艺复兴时期，出现了另外一种说法，叫镜子说。

#### 达芬奇：绘画是一面镜子

镜子说产生于文艺复兴时期，重要的代表人物是达芬奇。严格意义上讲，他不是一个作家，他是个画家——反正各种"家"，好像他什么都行。甚至这个人到底是不是全才，之前有本小说叫《达芬奇密码》探讨过，这个不重要。

他从绘画的角度提出一个观点：什么是绘画艺术？绘画艺术就是一面镜子。我为什么要画画？就像你为什么要照照片一样。那时候没有照片，怎么办呢？我画下来，把这个镜像呈现出来、永久保留下来，就像镜子一样呈现事物。

同样的道理，放到文学领域，塞万提斯、莎士比亚这些文艺复兴时期的人，顺着达芬奇的观点就说：文学是什么？文学就是用语言影射自然。

#### 当"像"成为标准

当他把文学或者艺术比喻为一面镜子的时候，他要求的是什么？艺术反映现实要完全反映，丝毫不差地反映。

由此就会得出一个结论：艺术的水准、艺术的水平，跟什么东西成正比？跟模仿的准确度成正比。模仿的准确程度越高，你越如实反映，艺术水准就越高。

那问题来了：如果是这样，你觉得好不好？有没有道理？反正就是模仿得越像，水准越高。

这就有点像周星驰电影里的一个桥段。很多年前我看的，具体片名忘了：两个人比画画，画鱼。一个人画得特别像，一看就是鱼。周星驰采取了另外一种办法——他说，你不要让我评判谁画得好、谁画的鱼像，我也画了一条鱼。他在纸上随便画了两笔。旁人一看，说这个不像。周星驰就说：那到底谁说了算？人说像不像不算，猫说了算。他抓来一只猫，把两幅画往这一摆——猫对那个人画的鱼一点兴趣都没有，扑上去就抓周星驰画的那条鱼。为什么？因为他在画上沾了一点鱼腥的东西，猫就开始抓那幅画。

我看到这儿的时候就觉得，这背后体现出了某种理论问题：他觉得画必须要真实，真实到连猫都觉得见到这画就要抓上去。且不说人能不能做到如此；如果人真能做到如此了，这是不是好的艺术？在我们看来，尤其是在今天看来，应该说不是好的艺术。

为什么？因为当你把艺术模仿的准确程度跟艺术水平等同起来的时候，这其实是一种真理的符合论——它把"真"等同于"像"。

#### 为什么偏偏是文艺复兴

再回头说，为什么文艺复兴的时候达芬奇会提出这样的镜子说？这跟文艺复兴的背景有关系。文艺复兴时期自然科学的发展，导致当时那种科学理性精神极为强烈，所以他们在艺术上也追求这样的目标。

但这样的目标不是一个好目标，或者说不是一个很好的追求。大家一定要有这样一个认识：在人文学科里，它的发展绝对不遵循"后代一定比前代好"的必然规律。有太多太多的现象说明，人文学科的发展——小说的发展、诗歌的发展、散文的发展——往往是倒退的。有这个认识就好。

### 现实主义与自然主义：能动与复制

接下来我们说到19世纪、20世纪以后，兴起了一整套文学作品，文学作品当中形成了更复杂的理论基础。最典型的代表、跟再现有关的就是现实主义和自然主义。

#### 现实主义：作家要有眼光

现实主义兴起于18世纪末、19世纪初，它继承了模仿说。它特别强调什么？所谓现实主义，强调的是文学作品要对现实有能动的反映和再现。

这是一种非常独特的文学反映论。什么叫"能动"？还用我解释吗？不用了吧，学文科的应该知道。这个反映不是机械的，不是被动的，不是像镜子一样有什么我就呈现什么；相反，作家在这个过程中有主观的意识、有主观的选择、有主观的创造。

它的核心其实还是沿承着柏拉图那个原本与摹本的结构：它要求作家通过处理社会生活现实，揭示、透视这个社会的本质规律。所以18世纪末、19世纪初的很多作品，背后的目的都是要揭示社会生活的本质规律。文学家看问题要透彻，对社会的认识要深刻，你才能写出好的作品。

典型代表有很多：巴尔扎克、雨果，等等。比如《悲惨世界》《巴黎圣母院》。还有司汤达的《红与黑》——你就看一个小人物如何一步步往社会上爬，在往上爬的过程当中，他一定要经历很多迫不得已的事情；你去挖掘他背后的很多人物问题，就会得出对整个社会更深入的思考和分析。

说到《悲惨世界》，我之前看《我和我的祖国》，其中有一段叫《白昼流星》。我一看《白昼流星》，就突然想到《悲惨世界》里的一个桥段。《悲惨世界》都看过吧？没看过也不要紧，那个桥段太有名了：主人公冉阿让从监狱里逃出来，来到一个老人的家里；第二天早上起来，他偷了老人的银器跑了；被抓回来，跟老头对峙，老头说，哎呀，这个银器其实是我送你的。这个桥段后来被陈凯歌用到了《白昼流星》里。我当时一看——当然我个人认为这一段是整个《白昼流星》里讲故事讲得最不好的一段，无论是内容、情节，还是他想表达的东西，都让我觉得那么不顺畅。

19世纪现实主义小说要求反映社会现象的本质。他们背后的一个主要观点是：社会现象只是表象，经过艺术处理和加工的摹本，才能够揭示出社会的意义。

#### 自然主义：把显微镜对准每一寸土地

自然主义兴起于19世纪后期，它特别强调客观的真实、科学的真实，强调文学对自然的一种无条件的复制和记录。

它要求描写社会生活时把所有内容都纳入进来——你要反映社会现实，那怎么反映？要把很多细节呈现出来，呈现出一种客观的真实。

比如说我要写一片叶子。一般来讲，你说"一片绿色的叶子"就行了；自然主义者不行，因为那在现实生活里不够细致。你要把叶子具体的形象、颜色、状态，甚至里边的叶脉，都描绘得很清楚。他说，这才叫真实。

再比如我要描绘这个教室：我要把教室当中每一寸土地都呈现出来，每一个角落都要写下来，这才叫如实的再现。你觉得可能吗？不可能。说实话，这个教室的场景，我用1万字能描绘，10万字也可以，30万字、300万字我都能描绘——我就带着显微镜去看每一寸土地。按照自然主义，你就应该这样，这才叫科学的真实、客观的真实。

但这样一来，这还叫艺术吗？

当然，它有一个好处：特别注重描写，注重环境描写。所以你看自然主义的作家，小说都有一个特点——特长。因为他描绘得特别细致，其实废话也特别多。你去看看，那些小说都是大部头、好几卷，真正的情节没多少，真正的内容没多少。这是它的一个特点。

#### 进步还是倒退

如果把自然主义和镜子说、模仿说对照起来看：自然主义有点像镜子说，现实主义有点像模仿说。

从现实主义到自然主义，时间上当然有先后，但实际上先后关系并不明显；但如果问这是进步还是倒退，应该说也是某种倒退。不过你要知道，这两条线还在不断发展，都有各自的理论支持者。

把这一路走下来的几种说法摆在一起，线索就清楚了：

| 说法 | 兴起时间 | 核心主张 | 艺术的位置 |
| :--- | :--- | :--- | :--- |
| 模仿说 | 古希腊 | 艺术模仿现实，现实模仿理念 | 模仿的模仿，影子的影子 |
| 镜子说 | 文艺复兴 | 艺术是一面镜子，用语言影射自然 | 越准确越高明 |
| 现实主义 | 18世纪末—19世纪初 | 能动地反映现实，揭示本质规律 | 透过表象见本质 |
| 自然主义 | 19世纪后期 | 对自然作无条件的复制和记录 | 细节的客观真实 |

关于再现的理论，我们就说这么多。

### 表现与抒情：向内的一半

接下来该说另外一个：表现与抒情。

从这个角度看，文学与世界的关系里的"世界"指的是什么？指的是人的情感。再现往往是向外的，表现是向内的：再现面对的是外在的、客观的社会现实生活，表现面对的是人的主观情感。

#### 我手写我口

接下来要研究一下抒情这件事。文学的本质是抒情的，这个问题没错；但关于表现、抒情这些概念，你稍微追问一下，会发现也有很多问题值得注意。

比如1917年、1918年，中国兴起了新文化运动。新文化运动的一个重要改良和变化，就是用白话文代替文言文。为什么白话文要代替文言文？按照当时很多作家、文人的说法，就是"我手写我口"——用我的手写我的口，我怎么说的，我就怎么写。为什么？因为文言文不方便，文言文有束缚。

事实上也是如此。你们中学用文言文写过作文没有？写过吧，你自己感受；写格律诗束缚更多，总觉得那么不顺畅。白话文呢，我嘴上怎么说，我就怎么写就行了；文言文还得较着劲儿、憋着劲儿。于是很多人就觉得，"我手写我口"、白话文运动代替文言文，是一次非常自由的运动，直接抒情很好。

#### 自由了，诗却没有更好

但问题来了。古代写诗要讲格律，到了现代、当代，不用讲格律了，你可以写新诗了。问题是：诗歌自由了、随便了、想怎么写了，诗歌写得更好了吗？中国当代诗歌跟古代诗歌比，从艺术水准上讲哪个更高？肯定是古代的更高。

可你要知道，古代人写诗，那是戴着镣铐写的——必须押韵，必须符合格律。当代人随便写，为什么反而不如古代人写得好？

这个问题你会发现：往往有的时候自由了以后，问题就出现了。自由了以后，好像把束缚给你打破了，你会发现问题好像根本不在束缚本身。抒情当然可以直接抒情，但直接抒情要想抒情得到位、抒情得好，不是简单地靠打破外在的规矩就能做到的。在这个过程当中，抒情可能确实要遵循某种规律，有些规律是不能被人打破的。

如果你去了解中国现代文学史，要知道第一部诗集是胡适的《尝试集》。大家听说过吗？那里边有很多"乱七八糟"的诗，胡适写的。你有空去图书馆找《尝试集》看看，就能感受到他当时尝试用白话文写诗的水平很次。比如里边有一首诗叫《两只蝴蝶》，写两只蝴蝶，一只忽然飞还，剩下那一只"孤单怪可怜"，"也无心上天，天上太孤单"——就这水平，并且有很强的格律诗的痕迹。

那么这个背后我要说：抒情要遵循某种话语规律。到底是什么话语规律，下节课我们来说。

> **承前启后**：上一节讲完「床、镜子与显微镜：文学怎样再现世界」，下一节接着讲「抒情与表现：情感怎样被构造」。

## 抒情与表现：情感怎样被构造
> 对应块：BLK13 | 覆盖分集：P13 | 块标题（分集名）：《20191021 文学与世界（5）：表现与抒情》

上节课讲的是再现，这节课讲表现。在文学理论里，这两个词是对着站的：再现盯着外部世界，表现盯着写作者自己。可一转到表现，麻烦就来了——诗歌，尤其是诗歌，很多时候根本不在再现什么社会现实，它抒发的是诗人的主观情感。这样的东西该怎么看？

### 从一句“我是一条天狗”念起

我让一个男生站起来念郭沫若的《天狗》。念之前先交代一句：这首诗里所有的“底”，都按“的”读。

他念得没什么感情，我让他大点声，要读出那种“爆”的感觉。诗是这样的：

> 我是一条天狗呀！我把月来吞了，我把日来吞了，我把一切的星球来吞了，我把全宇宙来吞了。
>
> 我飞奔，我狂叫，我燃烧。我如烈火一样地燃烧！我如大海一样地狂叫！我如电气一样地飞跑！
>
> 我剥我的皮，我食我的肉，我吸我的血，我啮我的心肝。
>
> 我便是我呀！我的我要爆了！

念完我问他：这诗写得怎么样？他说，从艺术上讲，基本没什么。

这个判断不算离谱。听下来的感觉就是“要干点啥”，一种命也不要了的感觉。但这首诗是典型的抒情，而且抒得如此直白，直白到让人尴尬症都要犯了。

这样的东西不是孤例，它是中国现当代诗歌刚起步时的普遍样子，以胡适为代表。胡适的《尝试集》有空可以翻翻，里面那首写蝴蝶的诗，就是那个状态——当时的人根本不知道该怎么用白话文写诗。所以那批尝试并不成功。

对比之下，鲁迅就比较鸡贼：他基本没写过新诗，写的全是小说。而中国现代白话小说一开篇水平就很高，一出手便是高峰。诗歌不一样，诗歌是从“小学水平”起步的。

什么时候才像样？到新月派，徐志摩、闻一多，开始强调诗歌的音韵美。这里有一层道理值得琢磨：当初要用白话文代替文言文，理由之一是文言有束缚、白话没束缚，没规矩，你随便写。可一旦真的随便写了，问题立刻来了——随便写出来的，就是好诗吗？未必。

梁启超说过一件事，很能说明这个道理。他说自己成名有点晚，结果早年写的那些烂诗烂文章，后来都被人翻出来了。反过来，成名越早，你写东西的时候就知道它是会有影响的，于是就不敢乱写。

这个道理搬到抒情上是一样的：以为抒情就是“我手写我口”，怎么想就怎么写，情感直接倒出来——后来人们发现，这条路不行。

### 抒情到底在抒什么

先把定义摆出来。抒情强调的是情感表现，是主观情感的呈现，是自我内心体验的表达。说白了就是：我怎么想的，我心里的那些情感，我直接抒发出来。这样一来，抒情就天然带着某种表现性。

> **定义**：抒情——以情感表现、主观情感呈现、自我内心体验表达为核心的一种表达方式。它与“再现”相对，重心不在外部世界像不像，而在写作者内心如何被呈现。

西方那边，意大利理论家克罗齐有一个很有名的说法：艺术即直觉，直觉即表现。他还专门写过一本《美学原理》。在这套说法里，艺术不是对现实的摹写，而是内心情感被直观地“表现”出来的那一刻。

### 再现看像不像，表现看能不能创造

把这两个概念摆在一起，差别就清楚了。

再现更多强调的是主观跟客观的相符合程度。你甭管是模仿说，还是自然主义，背后的核心都在这里：写出来的东西，跟外部世界对得上多少。

表现更多强调的是主观的创造能力。这种能力具体落在想象能力、个性、天赋、天才上——它们在作品构成当中起什么作用。所有这一切的核心，是主体的创造能力。

| 比较项 | 再现 | 表现 |
| :--- | :--- | :--- |
| 核心问题 | 主观与客观相符合的程度 | 主体的创造能力 |
| 代表理论 | 模仿说、自然主义 | 直觉即表现、迷狂说 |
| 作品的重心 | 像不像外部世界 | 情感、想象与天赋如何被呈现 |

沿着“主体创造能力”这条线，柏拉图有一个重要说法：诗人创作时要进入一种迷狂状态，所谓“迷狂说”。这是古希腊早期的说法——诗人创作的时候处在迷狂里，说白了就是疯癫。

今天看，“疯”不是一个好状态，是不正常。但古希腊人不这么看：一个人疯了，在他们眼里往往是神灵附体。而且他们还发现了一条规律：人在不正常的时候能写出伟大的诗篇，正常的时候反而写不出好诗。所以迷狂不是病，是神住在你身上的时刻，是一个很好的状态。

> **提示**：我们之前做过这个“实验”——你按正常逻辑写，永远写不出好诗。这话听着像玩笑，背后却是柏拉图那条思路：创作力的来源不在日常理性里。

中国这边是同一个结构。一提李白，就要提他跟酒的关系；再往上是魏晋的竹林七贤。鲁迅专门写过一篇文章讨论这件事，题目就叫《魏晋风度及文章与药及酒之关系》，探讨魏晋风度与酒的关系。那种醉的状态，能够激发诗人的创造能力。

### 那个“我”并不孤立

抒情强调自我，这是它的本色。但这里要补一句容易漏掉的：抒情的自我表现里，一定蕴含着社会内涵。

自我不是完全孤立的，它是特定时代、特定语境当中的自我。

《天狗》就是例子。你要理解它，一定要放回特定的语境里去看：那个时代的人抒发情感的时候，是比较找不到很好的把握方式的。你之所以觉得它不好，很大程度上是因为你读了太多的经典——经过大量筛选和阅读经验之后，你当然能看出它的问题在哪里。

这件事我每年秋天都会碰上一回。秋季学期我要教两个年级，一个是大一，一个是大四。大一的学生刚进校，朝气蓬勃，对大学生活充满憧憬；过两天去给大四上课，状态完全不一样——他们在准备考研，十二月就要考试，很焦虑。

焦虑的时候就会问问题。有个学生问我：文学史那么多作品，有些我能读出好来，比如《红楼梦》，虽然我不觉得特别好、不是特别喜爱，但你让我读，我能读出好；可有些作品是经典，我就是读不出来好，比如巴金的作品。这到底是我有问题，还是教材有问题？

我的回答是：如果你读一个经典作家的作品，读了半天不觉得好，看了别人对他的评论也还是不觉得好，翻来覆去都不觉得好——这不是你的问题。

为什么？因为你读一个文学作品的时候，一定只是带着你自己的标准、你自己的视野。而文学史的标准，是多重的历史筛选过程，绝对不是以一个人的标准来筛的。

所以你会看到，文学史上那些经典作品，有的你看得入眼，有的你看不入眼，因为那个标准不是你喜欢的那个标准。但它也是一种标准。

更要紧的是，有些作品的意义和价值不在艺术上，而在独创性上。“我是一条天狗”，你接着改成“我是一条天猫”，就一点意思也没有了——这就是独创性：他第一个敢这么写，后面的人再这么写就不行。文学史上他的名字留下了，而他的名字之所以留下，并不是按审美原则来标榜的。这个大家要搞清楚：要弄明白它背后的命名原则，它到底经典在哪里。

于是回到抒情本身：一个人抒发感情的时候，抒情背后一定蕴含着某种评价——对社会现象、社会情感的某种评价，某种信仰，甚至某种理想。既然是主观的情感，它就必定带有主观性。什么叫主观性？就是“我觉得好的坏的应该是这样的，不应该是那样的”。这背后涉及某些评价、某些信仰、某些理想，需要你在作品里仔细去揣摩，而不是简简单单看他说了个什么情、抒了个什么心。

### 抒情是释放，更是构造

抒情需要什么？需要创造性地选择和组织抒情话语。这句话里的“抒情话语”先放着，后面再说；先说一个更靠前的前提——抒情要抒得到位，第一步是超越原发情感。

什么叫原发情感？就是此时此刻我有一种感情，我要把它表达出来。如果直接抒发，写出来的作品就是《天狗》那个样子：你读的时候，能感到作者当时那种疯了一样的状态，所有情感喷涌而出。这说明什么？说明他没有超越他的原发情感——他有一种情感，他就直接把它抒出来了。

更好的状态是超越它：你要感受你的感受。把之前那个感受当成一个对象，去整理它、梳理它。这样表达出来的情感，才会比较到位。

所以有一句话：情感激烈的时候，往往不能写诗。你这时候特别气愤、特别悲伤、特别高兴，写出来的诗往往是一种宣泄，而不是抒情。

真正抒情是什么样子？我激动了、高兴了、兴奋了、悲伤了，过后平复一下，冷静一下，再回头审视我之前的那份情感——把有用的摘出来，没用的删掉，然后通过艺术加工，把之前那种情感或放大、或缩小。

> **结论**：抒情是情感的释放，但更是情感的构造。

这是一个很辩证的认识。整个过程可以画成这样：

```text
原发情感（此刻的激动、悲愤、狂喜）
      │
      │  拉开距离：把“那份感受”当成对象来看
      ▼
审视、整理、梳理（有用的留下，没用的删掉）
      │
      │  艺术加工：放大或缩小
      ▼
构造意象、组织抒情话语
      │
      ▼
能够传达到位的情感（情感真实）
```

从“我有一种情感”，到“作品里的情感”，中间隔着一道工序。这道工序就是构造——它才是抒情真正的技术含量所在。

### 背下来不算学会

说到“辩证”，这里必须插一句：学文学理论，一定要学会辩证思维。

大四的学生尤其能体现这一点。到了大四，很多人在准备考研，文学理论这门课可能就剩我这一门了，于是死死抓住我不放。有同学每节课都拿一道自己做的真题来：“老师你看我这题答得行不行。”

学古代文学、学现代汉语，乃至学别的很多科目，都有一个很重要的前提能力，一个字：背。你先甭管三七二十一，先背下来，这是基本功夫。

但到了文学理论，背不重要。你把《文学理论教程》从头到尾背下来，考试时我说考到什么，你就默写下来——我告诉你，我要是老师，我瞧不起你。因为你只会背。

我要的是你学会超越教材。吸收教材内容是前提，它帮你建构理论框架；但最重要的是在这个基础之上，提出你自己的认识。因为很多问题不是绝对的，我在黑板上写下的所有结论都是可以被推翻的，都不是板上钉钉的事。

当然，不能胡说，你得有证据、有论述。如果你的论述能体现出你对这个问题更进一步的认识，我就觉得这学生有意思，这是个好学生——这是文学理论最看重的东西。

这也是我们这个专业跟别的专业不太一样的地方。别的专业老觉得中文系有个特点：你们不就是背吗？这时候你可以把文学理论书拿出来跟他说：我们不只是背，我们也有玩智商的层面，而且玩得比你们深奥得多——文学理论走着走着就进入哲学层面了，那个东西就有意思了，也就悬了。

所以一般来讲，如果你要考研究生、考文艺学这个方向，我最喜欢什么样的学生？基本两个要求：一是有思辨能力，考虑问题极其严谨周密、有逻辑，而且掌握的材料很多；二是对文本有极强的感受力，别人看一个小说都觉得“就是这个意思”，你能挖到别人挖不到的东西。有这两样，你就很适合做文学理论的研究。

### 情感要靠形象落地

回到构造。构造，本质上在构造什么？构造意象。

我在讲文学性的四个维度时，把情感性和形象放在了一起。为什么要把情感和形象放在一处？因为情感的抒发是通过形象来完成的。

这就带出我们熟悉的一对概念：直接抒情和间接抒情。间接抒情不直抒胸臆，而是通过形象来完成——借景抒情，这个你们中学都学过。

那直接抒情呢？问题就来了：文学作品里直接抒情，到底好不好？回头看《天狗》，它其实也借助了意象，但即便借助了意象，也算不上什么好事。

### 通篇直抒胸臆行不行

那就反过来问：如果通篇不借助意象、全是直接抒情，有没有可能写好？

再具体一点：中国古代诗歌里，有没有通篇没有意象、却依然是经典、被人传唱的诗？

有人先想到《咏鹅》。鹅鹅鹅，曲项向天歌——可“鹅”不就是意象吗？而且这诗是骆宾王七岁写的，算什么好事。它之所以“经典”，很大程度上是因为它是你从小到大背的第一首诗。

再看《登幽州台歌》：前不见古人，后不见来者。念天地之悠悠，独怆然而涕下。这首好像真没什么意象；就算你非要说“天地”是意象，它也不是以意象性为突出的。通篇从头到尾就是在抒发情感。而它是经典。

> **结论**：通篇直接抒情，可以成立。

但有前提。这种不借助意象抒发的情感，往往都是人类共通的、大号的共同感——不是小情小爱，而是宏大的、关于历史与人生的苍茫感、苍凉感。

《古诗十九首》和汉魏的很多古诗都是这样：很多句子并不以意象见长，但它要呈现的是人生的苍茫感。

### 抒情与宣泄的分界

顺着这个思路，得把两个容易混的概念分开：抒情和宣泄。

宣泄是主体完全沉浸在情绪之中。抒情的主体，是情绪的创造者，是情感的建构者。

| 比较项 | 宣泄 | 抒情 |
| :--- | :--- | :--- |
| 主体位置 | 完全沉浸在情绪之中 | 情绪的创造者、情感的建构者 |
| 自由程度 | 不自由：受生理情感的导向 | 自由：能审视并建构情感 |
| 与情感的关系 | 被情感推着走 | 把情感当作对象来加工 |

两个一比较就清楚了：宣泄是不自由的，因为你受制于自己的生理情感，它在导向你往这个方向走、往那个方向走。抒情不是这样，抒情有一种“我自己审视我的情感”的感觉，所以它在另一个层面上建构了某种情感。

### 无理而妙：情感真实的逻辑

现在说抒情话语。抒情话语的本质，是不追求外表真实，而追求情感真实。

> **定义**：抒情话语——以情感真实为旨归的话语方式。它可以不遵循外部现实的逻辑，但必须遵循情感的逻辑。

所谓情感真实，就是逻辑上说不通，但情感上说得通。

日常生活里我们天天遇到这种事。两个女生聊天，聊得很嗨，但完全不遵循逻辑：一个说“那天我在哪儿看见一件衣服特好看”，另一个说“对了，那天我在哪儿看的另外一件也很好看”，然后一个说“我跟你说那件衣服怎么样怎么样”，另一个说“我看见我那件也怎么样怎么样”。从头听到尾，你会发现两个人说的完全是两回事情，可俩人聊得很嗨。

为什么？因为她们共同找到了一个情绪的体验——发现一个新事物时的那种喜悦感。她们在交流这份喜悦感，至于交流的那个事物是不是同一个，不重要。日常生活中我们经常是在聊一种情绪，根本不是在聊事实。你要是非要纠缠那个事实，就太天真了。

文学作品里更典型。海明威有一篇小说叫《白象似的群山》。海明威写小说讲“冰山原则”，这篇的场景很小：西班牙一个特别小的火车站，一对情侣来等车，火车还有四十分钟才到站，两人就到站边一个类似咖啡馆的地方坐下聊天。聊的过程中，女生好像很有心事——她好像怀孕了。男生表现得很不在乎，意思是希望她去做堕胎手术，女生很不乐意。

就在这个过程里，女生有一段对白。她望着远处说：你看那群山，像一群白象。男生说：像吗？我觉得一点都不像。女生说：你是不会觉得像的。

“你是不会觉得像的”，这句话背后是什么意思？是“你根本不会懂”“你不会理解我为什么会觉得像”。女生表面上在说一个外在的现实，其实是在抒发情感；而男生一直在纠缠符号与现实之间的对应关系——他说不像，就是真的在讨论像不像。

> **提示**：学文学有一个很实际的好处——谈恋爱的时候能读懂对方的潜台词。潜台词背后有很复杂的含义，读懂了，你才知道对方真正在说什么。情感才是文学最要抓的东西，至于话的内容是什么，在很多作品里并不重要。

因为追求的是情感真实、遵循的是情感逻辑，中国古代文论里有一句话叫“无理而妙”：恰恰是看似无理、不遵循现实生活的逻辑，它反而妙；要真按现实逻辑来，就不妙了。

王维那句“人闲桂花落”就是这样。你要是把桂花老老实实当成春天开的那种花去坐实，这首诗就没意思了；恰恰是这处反常，形成了独特的美感。

### 高考题的是非

这种“按现实逻辑还是按情感逻辑”的分歧，在两道高考题上看得特别清楚。这两道题我放进幻灯片里了——这节课我终于用上了 PPT，真是不容易，我只是想证明一下，我也是会做 PPT 的。

#### 约客：朋友没来，该是什么心情

诗是《约客》：黄梅时节家家雨，青草池塘处处蛙。有约不来过夜半，闲敲棋子落灯花。

题目问哪一项赏析不正确，标准答案是 C 项：“生动地表现出诗人此时闲适恬淡的心情。”判它错的理由是：按现实生活的逻辑，约好的朋友放了鸽子，诗人就该焦躁、无奈、落寞，怎么能是闲适恬淡？

我有不同意见。我第一次读到这首诗的时候，真没从最后一句里读出无奈和落寞，相反，我看到的就是闲适淡然：今天这个朋友没来，没关系，无所谓。难道我们的生活就因为朋友不来，自己就开始起情绪的波澜吗？没有必要。你不来，我自己玩行不行？

这背后表现的恰恰是“我不受外界环境干扰”——我不会因为朋友的来或不来，在情绪上有任何变化，我依旧是那副很闲的样子。这反而体现出一种更高的人生境界：朋友来不来这件事不在乎，看淡人世间的沉沉浮浮。

从这个角度解释 C 项，没毛病。

但高考题就得选 C，没有办法。因为高考题站在现实生活的逻辑上：朋友没来，你就应该生气，就应该不高兴，你怎么还能恬淡闲适？难道做人恬淡闲适不是一种更高级的境界吗？它不这么理解。所以我觉得这道题出得很有问题。

底下有同学笑。你们是不是看我们批判高考题，觉得很爽，有一种终于出了一口气的感觉？

#### 鹳雀楼：被砍掉的最后两句

第二道题给的四句是：迥临飞鸟上，高出尘世间。天势围平野，河流入断山。题目问“这首诗的赏析不恰当的两项”，标准答案是 B、E。

B 项说这诗“真实客观”。从文学理论的角度讲，所有的事都不可能绝对真实客观，所有的事都是在表达作者的主观情感，它不可能真实客观。而且题目给了个注释，告诉你鹳雀楼是一座三层楼——三层楼怎么可能“迥临飞鸟上”？所以 B 项肯定不对。

E 项说：全诗的主旨是抒发诗人登上鹳雀楼、凭高四望时胸中所涌起的壮志豪情。出题人的思路是：这首诗只写景、没抒情，所以你说它抒发了壮志豪情，不对——四句从头到尾都是写景。

这一条很值得商榷。因为一切景语皆情语。如果他没抒情，那他到底说的是什么情？就看这四句的字面：迥临飞鸟上，高出尘世间，天势围平野，河流入断山——这么个场景，作者能抒发什么感情？顶多就是壮志豪情，你看不出别的来。如果非要说情感，只能是壮志豪情。

我回头查了这首诗，才明白出题人为什么敢断定 E 项不对：这四句不是原诗的全句，它是一首律诗中间的四句。你不觉得这四句的押韵很不对吗？很不像绝句的押韵——因为它前面还有两句，后面还有两句，最后两句才是抒情的，被砍掉了。你拿被砍掉抒情部分的四句，说人家“抒壮志豪情”，你哪来的？

但话又说回来：即便你砍了两句，你也不能说我仅仅写景、就是不抒情。就看目前这四句，表达的也是“这楼真高”背后的那点情感——这仍然是抒情。

在这个意义上，E 项很值得商榷。

高考题当中，外省卷、全国卷我不太了解，但北京卷几乎年年语文卷子都有问题，或多或少。比如有一年高考语文卷，文言文原卷的断句都是错的，而且这个断句直接影响到一道选择题的选项。这些问题一般人看不出来，所以也就没人管了——但是我看出来了。

我的感觉是：高考题里的现代文阅读、文言文阅读、古诗词，都出得不怎么样；出得最好的一种题，是作文题。那个是真见功夫——你让我出，我出不出来。

### 本讲提到的题目

**《约客》赏析题**

题干：阅读《约客》——“黄梅时节家家雨，青草池塘处处蛙。有约不来过夜半，闲敲棋子落灯花。”下列对这首诗的理解和赏析，不正确的一项是。其中 C 项为“生动地表现出诗人此时闲适恬淡的心情”。

答案：C。

解析：命题按现实生活逻辑判断——约好的朋友没来，诗人应当焦躁、无奈、落寞，故“闲适恬淡”不成立。但若按情感逻辑读，“闲敲棋子落灯花”恰恰写出不为外物所扰的从容，是一种更高的人生境界，因此这一项本身并非不能成立。详见“约客：朋友没来，该是什么心情”一节。

**鹳雀楼赏析题**

题干：阅读“迥临飞鸟上，高出尘世间。天势围平野，河流入断山”（注释：鹳雀楼为三层楼），选出对这首诗赏析不恰当的两项。B 项称其“真实客观”，E 项称“全诗的主旨是抒发诗人登上鹳雀楼、凭高四望时胸中所涌起的壮志豪情”。

答案：B、E。

解析：B 项错在“真实客观”——诗总是表达主观情感，且三层楼不可能“迥临飞鸟上”。E 项被判定错误，是因为所给四句在原诗中只是中间两联，末两句抒情已被删去，通篇看上去只有写景；但按“一切景语皆情语”，这四句本身仍含壮志豪情，故该项可商榷。详见“鹳雀楼：被砍掉的最后两句”一节。

## 向内的再现：从抒情、浪漫主义到文学真实
> 对应块：BLK14 | 覆盖分集：P14 | 块标题（分集名）：《20191021 文学与世界（6）：再现与表现、》

前面几讲谈"再现"，谈的一直是朝外看的那一路：现实主义对着社会现实，自然主义对着更粗粝的社会现实，模仿说、镜子说，说的都是符号怎么去贴合眼前这个世界。

可讲完这些，还有一个东西没有安置——抒情。

抒情和再现是什么关系？我先把结论摆出来：抒情的本质，也是一种再现。

这话乍听别扭，但只要把"再现"这个词放宽一点就通了。顺着这条线往下走，会依次碰到三样东西：抒情的特殊性、浪漫主义与唯美主义这两个流派，以及一个更硬的问题——文学的真实到底是什么。

### 抒情是一种向内的再现

先把"再现"这个词定住。

> **定义**：再现，是符号与客观世界之间相符的程度。

按这个定义，前面讲的全是"向外"的一路：现实主义、自然主义，模仿说、镜子说，说到底都是再现客观的社会现实、再现外部事物。

但这里有个前提值得追问：既然讲的是符号和对象之间的关系，那这个"对象"为什么非得是外部世界？

它也可以是内心世界。一个向外，一个向内。向内的一路，对象是人的内心，是情感、是精神——抒情干的正是这件事。

所以抒情的本质也是一种再现，只不过它再现的不是外部世界，而是内心世界。这也是我一再讲"再现理论很重要"的原因：只要从广义上理解，它罩得住整个文学——向外的一路罩得住，向内的一路也罩得住。

这条"向内"的路不是一步到位的，它有自己的坡度：抒情把对象换成内心，浪漫主义把作家的内心抬到第一位，唯美主义再把浪漫主义推到极端，推到连内心都不剩。

```text
再现：符号与对象之间的符合度
│
├── 向外：对象是外部社会
│       现实主义、自然主义、模仿说、镜子说
│
└── 向内：对象是内心世界
        抒情
         └── 浪漫主义：把作家的内心世界抬到第一位
               └── 唯美主义：连内心也抽掉，只剩艺术自身
```

这张图画的是这一讲的路线：同一个"再现"的结构，对象一级一级往里退，退到最后连"里"都没有了。

### 抒情的三重特殊性

只说"抒情也是再现"还不够，还得说清它特殊在哪儿。特殊性在三条上。

**第一，它再现的是社会生活的精神方面。**

现实主义的再现，对象是现实生活本身；抒情再现的不是现实生活，是精神。

**第二，它对客观世界的再现带有某种主观性。**

它确实也是对客观世界的再现，但这种再现是带着主观视角的。我们常说"情人眼里出西施"，为什么？因为看世界的那个视角本身就是主观的。所以抒情虽然也会用到客观世界的意象，可用出来是"物皆着我之色彩"。

说到这儿就要提王国维的《人间词话》。他分"有我之境"和"无我之境"：有我之境是"以我观物，故物皆著我之色彩"；无我之境是"以物观物"。抒情走的正是有我之境这一路——以我观物，所以它的再现天然带着主观性。心情高兴的时候，看外在的事物都是高兴的；心情不好，看什么都不开心。物没变，色彩变了。

**第三，抒情对现实的再现带有某种评价性。**

它暗含着某种价值判断。这一条比较复杂：现实主义的再现其实也有某种评价性，只是跟抒情那种不一样。

> **提示**：不要把"抒情"（表现）和"再现"当成两套互斥的东西。抒情当中有再现，再现当中也有抒情，两者缠得很紧；只是分析的时候可以剥离开来，分开看。

所以"抒情与再现的关系"是一个非常复杂的问题。这一讲后面的浪漫主义、唯美主义，就是沿着"向内"这条线继续往下走的两个流派。

### 浪漫主义：把镜头对准作家的内心

浪漫主义兴起于 19 世纪上半叶，18 世纪末的时候已经有雏形了。

雏形的代表是席勒。他写过一篇著名的文章，叫《论素朴的诗与感伤的诗》。所谓"素朴的诗"，就是现实主义那一路；"感伤的诗"，就是浪漫主义那一路。所以后来很多人说，浪漫主义的前身就是感伤主义。

浪漫主义兴起时有好几个流派。你们可能没学过文学史，不知道也不要紧：英国有湖畔派诗人，德国有狂飙突进运动。狂飙突进的代表人物是歌德，他有一部著名的小说《少年维特之烦恼》。

这部小说写的是什么呢？维特这个少年喜欢上了一个姑娘，可这姑娘已经结婚了。道德上他过不去，可他又非常喜欢，于是百爪挠心。小说百分之八九十的内容，写的全是维特内心的焦灼——每天都在想她，又不能跟她在一起，因为道德的束缚。那位姑娘（绿蒂）知道，甚至她的丈夫也知道，都很同情维特，也只能安慰他一下，谁也没有办法。到最后，这件事也没有一个能走通的结果。

可正是因为它把那种浪漫主义的强烈情感写出来了——没有冲破太多的道德束缚，但把人的某种情感写出来了——小说一经发表，整个欧洲就形成一种风潮，很多人去模仿维特。顺便说一句，这也说明当时第三者确实很多。

浪漫主义特别强调什么？强调艺术要再现作家的内心世界。所以它格外看重想象、激情、个性、自由。

它衡量文学的标准也跟着变了：情感的真挚性、作品的原创性、创作的自发性——这三样才是它看作品的东西。

### 唯美主义：把浪漫主义推到极端

19 世纪后半叶，又兴起了一个流派：唯美主义。

打个比方：从现实主义到自然主义是某种倒退，唯美主义呢，是把浪漫主义推向了某种极端。

它的口号只有一句：为艺术而艺术。

它的实质，是把艺术与生活的关系整个颠倒过来。不再是艺术模仿现实生活，而是生活即艺术、艺术就是生活，把生活与艺术直接等同；甚至说生活是在模仿艺术，而不是艺术模仿生活；再往前一步——生活根本就不存在，整个人生就是艺术，艺术就是人生。艺术就是为了再现自身，它只呈现它自己。

到这一步，连作家的内心世界、连作家这个主体都被抽空了：艺术就是艺术，艺术跟什么都无关。

这就引出一个后果：美和真这两者之间的关系，本来应该具有某种统一性，在唯美主义这里被否定了。它否定了文学真实的存在——它不认为文学有"真实"这回事。

| 对比项 | 浪漫主义 | 唯美主义 |
| :--- | :--- | :--- |
| 兴起时间 | 19 世纪上半叶，18 世纪末已有雏形 | 19 世纪后半叶 |
| 核心主张 | 艺术再现作家的内心世界 | 为艺术而艺术 |
| 看重什么 | 想象、激情、个性、自由 | 艺术自身，与一切无关 |
| 衡量作品的标准 | 情感的真挚性、原创性、创作的自发性 | 只认美，不认真 |

再往后，等你们学外国文学，会看到从浪漫主义到唯美主义，还有感伤主义、直觉主义，都是走内心派的，这里就不多说了。

### 文学真实：我们凭什么说一个作品"真"

说完了抒情、表现，说完了浪漫主义和唯美主义，接下来这个问题非常重——期末考试里也是个重点：真实。

其实前面上课已经反复碰到这个概念，只是一直没把它拎出来单独讲。什么叫做文学真实？

日常里我们看一部文学作品，甚至看一部影视作品，常会说"这个作品很真实""那个作品不真实"。我们到底是在什么意义上说真实？这句话背后到底是什么意思？

先说真实的力量。有时候一个人看了一个作品，受影响极深：他认为作品里的人物都是真的；或者他明明知道那些人物是假的，可这个作品能影响他一生。看武侠小说就离家出走了，看《麦田里的守望者》就逃学了——这种现象比比皆是。

反过来的例子也有一个，去年的事，很有意思：有人炮轰刘震云和冯小刚，后来不知怎么间接打到了范冰冰身上，一大堆事就出来了。

起因在十多年前：刘震云写了一个小说叫《手机》，冯小刚把它拍成了电影。

《手机》讲的是手机引发的种种婚姻问题——出轨、婚内情。主人公严守一，是当时全国知名的主持人，很火，但他出现了婚外情，小三武月要上位，他又压不住，最后无奈，让武月进了电视台，当另一个节目的主持人。

这个故事一出来，很多人都说这是在影射《实话实说》——后来叫《小崔说事》。那个节目后来换了一个年轻漂亮的女主持人，很多人就猜测到底是怎么换的。

当事人的感受是实打实的："你从头到尾都在影射我。"他去找刘震云："即便是这样，你也得提前跟我说一声。你都不跟我说，你就这样把电影上映了。"对方回了一句："我们就想给你个惊喜。"——这句话等于默认了。

有人劝他告：这涉嫌污蔑诽谤，你觉得告得赢吗？为什么告不赢？因为没有依据。电影是电影，小说是小说，现实是现实，你非要把两者挂上钩，对不起，它不是证据。

后来《手机2》要上映，他说"你又想恶心我一下"；刘震云说这次跟当年那个完全不一样，你不要担心。他实在不能接受，就开始各种各样的炮轰，后来不小心把范冰冰带出来，后面爆出很多料——不过那是误伤。《手机2》到现在也没上映。最开始是范冰冰发了一条微博说电影杀青了，他很不满，也确实有点一朝被蛇咬的那种感觉。

从法律的角度讲，文学是文学，现实是现实。假设我写了一个小说、拍了一个电影，我就是讽刺你，法律上你会发现：对不起，你还真没办法拿我怎么着。因为法律上没有绝对的支撑——它们是两个不同的世界。

可另一边，文学作品对现实生活的影响又如此之大。这就不得不让我们追问：到底什么叫做文学的真实？

第一层，先把"真实"这个词本身说清楚：文学的真实，就是符号模仿某个对象的逼真程度。

> **定义**：文学的真实，是符号模仿某个对象的逼真程度。

这个尺子放到别处也成立。我们说一张照片真实不真实、一份社会调查真实不真实，甚至说一件古董赝品"很真"——这个"真"是什么？就是两者的符合度。

那为什么我们这么在意这个符合度？因为它背后体现了人性当中对真的一种执着和偏爱。

你想，如果全是假的——假如人人都说谎话，会导致什么效果？语言的沟通成为不可能，语言就没有意义了。我们假设人人说的都是谎话，或者你根本搞不清他说的是真话还是谎话，那我们还要语言干什么？还有法沟通吗？沟通无意义，这个社会也就无意义，也就失去了秩序。

所以一个社会建立的基本前提是信任；信任的前提是真实；真实的前提是——我说的话跟事实是相符的。所以我们特别崇尚真实，讨厌虚假，虚假难以接受。

### 文学真实的三个层面

具体到作品里，"真实"这个词就更滑了：我们说一个作品真实不真实，往往是从不同角度、不同层面说的。这个人说的真实和那个人说的真实，意思可能根本不一样。

这时候可以把文学四要素的理论拿出来用。真实的第一个方面，是作品与世界的关系。

#### 作品与世界：写得像不像

这个层面最直白：作品的内容与社会生活、与外部世界的符合度。

现实主义理论基本强调的就是这一条。

所以有一类作品——我也不知道该怎么归类，就叫玄幻类——看到这样的作品，很多人的反应是：瞎拍，什么乱七八糟的，一点都不真。他说的这个"真"是什么？是外部世界，而且是现实生活世界：一个人飞来飞去、各种各样的超能力，他就觉得不真实。他就是按这个逻辑在谈真实的。

#### 作品与作者：初衷的真假

第二个方面是作品与作者的关系。这时的真实，指的是作者创作初衷、创作动机的真与假，涉及的是作家的责任和道德。

我们都特别喜欢一个作家写作的时候是抱着担当的——对现实社会生活有自己独到的感受，才去写作品。

反过来，假设你看一个作品特别感动，见到了这位作家，他告诉你："其实我最开始写的时候，就是想为了赚点钱。"你立刻就觉得被骗了："你作为一个作家，怎么能这样呢？作家要有职业道德。"什么叫职业道德？就是创作的时候不能光想着钱，要为艺术而艺术。

但这里有个关键，一定要分清。

> **易错点**：创作初衷的真假、功利性还是非功利性，不影响作品本身的好坏。完全有可能他就是奔着赚钱去的，但他写出了好作品。

可另一方面，你要是知道了他的初衷是功利性的，你就是会觉得这个作品不真实。这跟现实生活里一样：一个人帮了你，你很感谢；帮完之后他说"其实我当时帮你就顺手一帮，最开始也没想真帮你"。结果是一样的，变的只是你对动机的了解——态度立马就不一样了。

#### 作品与读者：经验的参照

第三个方面是作品与读者的关系，这里涉及的是读者个体经验的差异。

同一个作品，你看觉得好真实，我看觉得不真实。这时候问题就来了：这好像跟作品没关，跟什么有关？跟读者的经验有关。

我举个自己的例子。我从小在北京长大，小时候住的是北京的四合院，胡同里长大的。你们以为在北京住四合院很好吗？现在很好，以前可不是这样。

那时候最痛苦的一件事是上厕所。屋子里没有厕所，你得出去上公共厕所。最可怕的是冬天，晚上想上厕所怎么办？外边下着大雪，你还得穿上衣服，跑到厕所里去。那个厕所还很简陋，叫旱厕，不是水厕——就是一大堆坑，坑里堆着屎，时间长了堆得老高，定期有人来清理。所以我一般都赶在刚有人清理完之后立马去。时间一长，里边就全是各种各样的苍蝇，夏天一进去，扑面而来全是苍蝇，底下你都能看到苍蝇的卵在那儿爬。上厕所基本上要带两样东西：一样是报纸，不断地扇，因为我总怕苍蝇飞到我身上；第二样是一根树杈，用来挑那些爬行的小白东西。

这是我的个人经验。我告诉你：一个小说作家要写这段，他要是没这个经验，我刚才说的这些细节他写不出来，绝对的。

那没有这个经验的作家也想呈现北京的胡同，他呈现的就是那种"大家想象的样子"——现在你去看后海、南锣鼓巷，就是那个状态。你要没有这种经验，一看：哦，北京胡同不就是后海、南锣鼓巷这样吗？觉得挺真实。我一看：这也叫胡同？不真实。

这时候，读者说真实还是不真实，参照的是什么？是个体经验。跟我的经验相符合，它就叫真实；跟我的经验不符合，它就不叫真实。这时候，跟外部世界的符合程度不重要，跟他创作初衷的真假也不重要，跟个体经验很重要。

你参照什么来谈真实——这个问题很重要。

### 文学真实与生活真实：制约与超越

再说一个我自己的经验。小时候住平房，除了上厕所，还有一件最担心的事：下大雨漏水。印象很清楚，屋里拖鞋都飘起来了，我跟我爸就往外舀水。屋顶是瓦片做的，防水不可能做得那么好，一般的雨没问题，大暴雨基本上就扛不住了。

还有拆迁。小时候那个院子要拆的时候，全院的人都等着、盼着拆迁——赶紧拆，赶紧住上楼房，因为楼房不用出去上厕所了。现在大家都觉得北京拆迁是好事，也都说住四合院好；现在让你选住四合院还是住楼房，你肯定选四合院，因为钱多。

这两段经验放在这儿，是想说生活与作品的关系：制约与超越。

第一是制约，现实生活制约文学。文学创作的内容逃不出现实生活。除了现实生活之外，文学还有第二个创作对象吗？没有。你再怎么去想象，它都一定源自现实生活。所以我们经常说"文学源于生活"——什么样的生活，什么样的作品，都要源于生活。

第二是超越，文学对生活具有超越性。

这里我一定要说"超越"，不想说"高于"。我们老说"文学源于生活，但高于生活"，可这个"高"字我总觉得那么奇怪——你怎么去理解这个"高"？不如说：文学超越现实生活。

超越是什么意思？文学创作完全可以不遵循现实生活的某些逻辑，它有自己的创作方式和表达态度。

于是它就不再追求与现实的"真实"了，它追求的是另一个东西——真实感。

> **定义**：真实感，就是让你相信你看到的文字不是虚构，它诱导你忽略眼前的文字是个虚构，好像这就是真的发生过的事情。

有些作品正是因为有了这种自信，写作的时候就敢于完全不遵循现实生活的逻辑，尤其现代、后现代的作品。

举个例子：卡夫卡。他的作品荒谬得很，可你看完之后，不觉得它只是一个荒谬的小小说——它真的好像在传递着某种真实性。

### 一篇等着被解读的小说：《河的第三条岸》

为了把"真实感"这个问题戳透，我给大家看一篇小说。先预告一下：期末考试必考一篇小说。

你放心，期末给你一篇小说让你分析，绝对不会是莫泊桑、欧·亨利那种——不会让你看"哟，这个项链"那种小说。往往是这种小说。

小说叫《河的第三条岸》。我把情节过一遍。

父亲是一个尽职本分、坦白的人，并不比谁更愉快或更烦恼，只是更沉默寡言一些。是母亲而不是父亲在掌管着我们家，她天天都责备我们——哥哥、姐姐和我。

但有一天发生了一件事：父亲竟自己去订购了一条船。他对船的要求很严格：要用含羞草特制，牢固得可以在水上漂二三十年，大小恰好可供一个人使用。

母亲唠叨不停、牢骚满腹：丈夫是突然想去做渔夫吗？父亲什么也没有说。

离家不到一英里，有一条大河流过。水流平静，又宽又深，一眼望不到对岸。

小船送来的那天，父亲并没有显示出什么特别的神情。他像往常一样戴上帽子，对我们说了一声再见，没带食物，也没拿别的什么。我原以为母亲会大吵大闹，但她没有，脸色苍白，从头到尾只说了一句话："如果你出去，就待在外面，永远别回来。"

父亲没有吭声。他温柔地看着我，示意我和他一起出去。我们一起向河边走去，我强烈地感到无畏和兴奋："爸爸，你会带我上船吗？"他只是看着我，为我祝福，然后做了一个手势，要我回去。

我假装按照他的意思做了，但当他转过身去，我伏在灌木丛后面偷偷地观察。父亲上了船，划远了。

父亲再没有回来。其实他哪儿也没去——他就在那条河里划来划去，漂来漂去。

每个人都吓坏了：从未发生过也不可能发生的事，现在却发生了。每个人都猜想父亲疯了。母亲觉得羞辱，但她几乎什么都不讲，尽力保持着镇静。

无论白天黑夜，都没见父亲踏上陆地一步。他像一条被遗弃的船，孤独地、毫无目的地在河上漂流。

人们一致认为，对父亲而言食物是个大问题，他一定会离开大河回到家中。他们大错特错了。父亲有一个秘密的补给来源，那就是我。我每天偷了食物带给他。后来我惊异地发现，母亲知道我做的一切，而且总是把食物放在我轻易就能偷到的地方——她怀有很多不曾流露的情感。

日复一日，年复一年。父亲从不踏上泥土、草地或河岸一步，从没生过火，没有一丝光亮。他的身体怎样不停地摇桨，要消耗他多少精力？河水泛滥时，他又怎么能幸免于难？我常常这样问自己。

姐姐生了一个男孩，她坚持要让父亲看看外孙。那天天气好极了，我们全家来到河边。姐姐穿着白色的新婚纱裙，高高地举起婴儿，姐夫为他们撑着伞。我们呼喊，等待，但父亲始终没有出现。姐姐哭了，我们都哭了。

后来姐姐搬走了，哥哥也到城里去了，母亲最后也走了，和女儿一起生活去了。只剩下我一个人留了下来。

我从未考虑过结婚。我独自留下来，独自面对一生中的困境。父亲孤独地在河上漂流。父亲需要我，我知道他需要我，尽管他从未告诉我们，他为什么要这样做。不管怎么样，我都不会因这件事责怪父亲。

我的头发渐渐灰白了。我到底有什么不对？我到底有什么罪过？渐渐地，我因年老而精疲力竭，生命踌躇不前。终于有一天他会精疲力竭，只好让小船翻掉，或者听任河水把小船冲走，直到船内积水过多而沉入激流之中。

哦，天哪。我等待着，等待着。终于，他在远方出现了，那儿，就在那儿。我庄重地指天发誓，尽可能大声地叫着："爸爸，你在河上浮游得太久了，你老了，回来吧。你不是非这样下去不可，回来吧。无论何时，我会踏上你的船，顶上你的位置。"

他听见了，站了起来，挥动船桨向我划过来。他接受了我的提议。

我突然浑身战栗——因为他举起手臂向我挥舞，这么多年来，这是第一次。

我不能。我害怕极了，发疯似的逃掉了。因为他像是从另一个世界来的人。

极度的恐惧带给我一种冰冷的感觉。我病倒了。从此以后，没有人再看见过他，听说过他。

小说到这儿就结束了。

这篇小说选自某年的高考现代文阅读题——我记得是广东卷，应该是 08 年。我看到这道题的第一反应是：很大胆，真敢出题。我印象当中高考要是出小说阅读，都会出莫泊桑、欧·亨利那种，至少让你看得懂情节，顶多结尾来个出人意料又在情理之中。没想到出了一篇这样的。

后来我看了那几道题，倒出得无关痛痒：环境描写怎么样啊，请说一下母亲的人物形象啊，这种题都很简单，按套路做就行。

我要问的不是这些。我就提一个问题：这篇小说，你觉得它想表达的是什么含义？

课堂上我把这个问题抛出去，叫了几位同学起来说。头一位说完，我说：这不难，想多了，没有那么难。第二位想不出来。第三位说没看懂。第四位说，是父亲对于自己人生的一种追求和别人不一样——然后就没有了。大家都比较腼腆，不要紧张。

时间关系，今天先说到这儿。下节课我们还要讲这篇小说。我在网上看了一下：高考用的是删掉一半的节选版，还有一个更原版的，人物形象和动机更加丰满。大家仔细看一下，关键是要表达什么样的含义，下节课继续讨论。

## 文学真实：诗意的真实与经验的边界
> 对应块：BLK15 | 覆盖分集：P15 | 块标题（分集名）：《20191028 文学与世界：文学真实问题》

### 从一条不肯上岸的小船说起

上节课我们最后讲了一部小说，罗萨的《河的第三条岸》。下课之后有不少同学来找我讨论，我觉得讨论大部分都是有道理的。在接着往下谈之前，我想借这部小说讲一个更大的问题：文学的真实感。

这部小说读完之后，我不知道你们有没有这个感觉——反正我的第一感觉是荒谬，但同时又觉得它挺有意思，好像背后有些什么东西想说，只是需要你去挖掘，不是一望而知的。所以它比较难懂。

类似的小说在文学史上还有很多，它们身上有一种共同的感觉：打破了我们关于现实真实的那个概念。它根本不符合现实生活的逻辑，也不符合现实生活里整个过程的那种逻辑，人物形象也不符合。那么问题就来了：这样的作品，我们凭什么说它真实，或者不真实？

这里要先强调一点：文学的真实感，遵循的往往不是现实生活的逻辑。我们管这种真实叫"诗意的真实"。

> **定义**：诗意的真实——文学不靠复刻现实生活的表象来获得真实，而是通过牺牲表象的真实，去换取另一种更根本的真实。

诗意的真实，往往是通过牺牲掉表象的真实换来的。甚至有的时候，它因为太过追求某种真实的道理，会去蔑视原始的真实，蔑视现实生活的真实，结果是文学因此享有了更多的自由。

所以这种诗意的真实，背后的本质是什么？是把事实的表象转换为真实的哲理。

文学作品从某种意义上讲，都是在探寻人生哲理。探寻人生哲理，当然可以通过反映现实生活的方式；可有时候现实还不足以支撑那个道理，怎么办？那就让表象失实，让它不符合现实生活的逻辑——为了把那个哲理呈现出来。

这样的小说，我相信大家在中学阶段读得不多。但你去翻世界文学史，会发现经常有作品呈现出这种特点。

### 小说里的人读到了小说自己

比如说塞万提斯的《堂吉诃德》，骑士文学的代表作，大家听说过吧。这部小说分上下两部，到下部的时候有一个情节很重要：主人公堂吉诃德读到了《堂吉诃德》上部这本书。

也就是说，小说当中的人物，读到了这部小说本身。你不觉得很奇怪吗？他有一天读到一个新出的小说，这个小说就叫《堂吉诃德》，内容跟上部写的一模一样。这个逻辑不是很有意思吗？

而且这样的现象还不止一处，很多作品里都出现过。

莎士比亚的悲剧《哈姆雷特》里有这么一个情节：哈姆雷特自导自演了一出戏，请他的叔叔来看；而这出戏呈现的内容，正是叔叔杀死父亲、以及整个复仇的过程。也就是说，哈姆雷特作为剧当中的人物，看了《哈姆雷特》这个故事本身。

再比如《一千零一夜》。大家都知道这部书是怎么来的：国王每娶一个妃子，当天晚上就要把她杀掉；有一个妃子为了保命，每天晚上给他讲一个故事，于是保住了命。其中有一天晚上，这位妃子讲的故事是什么？就是《一千零一夜》这个故事本身。

如果往更早的时期看，印度两大史诗《摩诃婆罗多》和《罗摩衍那》里也有这样的情节：主人公听到了史诗本身，那时他还没有认出自己的两个儿子是谁；等那位诗人把诗念完，他才恍然——原来我的两个儿子就是那两个儿子。

你不觉得这样的故事很奇怪吗？但它反映了什么呢？

后来有一位著名的作家开始反思这个问题，他开始脑洞大开，去思考背后更深层的哲理：在这些作品里，都是小说中的人物读到了作品本身；既然小说中的人物可以读到作品本身，那么有没有可能，我们在读这部小说的时候，读者本身也是某个被虚构出来的人物呢？

这就像你去照镜子：你看到的是镜子里的像，你认为是你在照镜子——有没有可能，镜子里的人其实是在照你，你才是那个像？这么一想很玄幻，甚至有点可怕。

真有这样一位作家，阿根廷的国宝级作家，非常有名，差一点拿了诺贝尔文学奖——以他的资质，已经足够拿诺贝尔文学奖了。他的每一部作品都是这样：以诗意的表象换取真实的哲理。

这个作家叫博尔赫斯，听说过吗？

中国八九十年代的时候，文艺青年最爱的"三斯"，你要是想装文艺，书架上一定要有这三个人的作品：一个是博尔赫斯，一个是马尔克斯，还有一个是乔伊斯——乔伊斯写的是《尤利西斯》。三个名字都带一个"斯"字，书架上摆着，甭管看得懂看不懂，再说；至少能够显出你的范儿。

### 《小径分岔的花园》：一座穷尽时间的迷宫

博尔赫斯有一篇非常著名的小说，很短，叫《小径分岔的花园》。它有点类似于我们现在说的侦探小说，读起来好像很有意思，但琢磨起来细思极恐。它依旧是那个路子：以事实的表象换取诗意的真实，也就是哲理的真实。

小说里的中国人叫余准，是青岛大学的教授，那个时候青岛还在德国人手里。余准给德国人当特务，刺探英国军方的情报，经常要把英国那边的情况上报给德国。有一次他突然发现，自己的身份好像暴露了——英国人经常跟踪他，估计没两天他就会被抓走。他很着急。

偏偏这时候他拿到一个情报：英国接下来要攻打德国的一座城市。他必须把这个情报传出去，但他发现自己已经被盯上了。怎么办？

情急之下他想：反正我最后也是被英国人抓走，那不如就……他知道英国人要攻打的那座德国城市叫阿尔伯特。于是他找来一本老式的电话本，就是那种一页一页印着名字的本子，一页页翻，看有没有哪家哪户的人名字就叫阿尔伯特。找到了这个人，然后把他杀了。

接下来的事情是这样：杀了人，这件事就会登上报纸——一个叫余准的中国人，杀了一个叫阿尔伯特的人。报纸一登出来，德国军方情报局那边的人天天盯着英国这边的事，一看：我们的情报员莫名其妙地杀了一个叫阿尔伯特的人，这说明什么？说明他肯定是要传递信息。再一查：我们这边有没有一座城市叫阿尔伯特？果然有。于是就明白了。

好，余准开始行动，去找这个叫阿尔伯特的人家。他来到一个小镇上，一下车，很多小孩子就围过来，好像知道他要干什么，直接问他：你是不是要找阿尔伯特博士？他说是啊，你们怎么知道的？小孩说不用管，你就告诉我你要去哪儿——你沿着这条路直走，到一个岔口右转，然后直走，再右转就到了。

这是什么走法？走迷宫的方式。一般走迷宫的人都知道，不会走的话，往往就是遇到一个岔路就往右转，再遇到一个岔路再往右转。

他沿着这么走，果然找到了阿尔伯特家。见到本人之后，余准发现这个阿尔伯特见到他不但不惊讶，相反还很欢迎——因为这个阿尔伯特特别喜欢中国人，而且他本来就是一位汉学专家，研究的恰恰是余准的祖父。

余准的祖父是个什么人？他在事业生涯走到一半的时候，辞去了自己所有的职务，专门干一件事：写出一部超越《红楼梦》的伟大著作。他确实写出来了，但后来人们发现这部小说好像也没什么；而他自己说，所有关于人生的思考、所有的秘密都藏在这部小说里了。阿尔伯特研究的，就是余准祖父的这部小说。

所以一见面，阿尔伯特说：原来你就是他的孙子，太好了，咱们来聊聊天。聊的过程里，绕着一个问题：这部据称超越《红楼梦》的小说，背后到底藏着什么秘密，藏着怎样的人生思考。

阿尔伯特说：我终于破解了这部小说背后的谜底，很简单，两个字——时间。

他打了个比方：猜谜的时候，假设一个谜的谜底是"棋"，那么谜面里最不能出现的字是什么？就是"棋"这个字。他读你祖父的小说，发现从头到尾每次涉及时间，从来没有出现过"时间"这个词，每次一遇到它，就换一种方式绕开。所以你祖父要思考的，肯定是时间问题。

小说里也提到，祖父说这部小说写完之后要传给后世。他为什么非要思考时间？因为他发现，时间是一个困扰人生的永恒命题。他要写的，是一部能够穷尽所有时间可能性的著作。

什么叫穷尽所有时间的可能性？你写一个人物、写一个人物的行动，会发现：这个人物面临绝境的时候，他有两种选择，往左走、往右走；他选择了往左。往左之后，下面又遇到一个情境，又有一个选择，往左还是往右；他又往一个方向走了。于是你只看到一种可能性——当初那个往右的可能性，你看得到吗？看不到。

而事实上，人生就是由无数种选择构成的。比如你今天上完课，接下来就要开始抉择：我是去吃饭呢，还是去图书馆？去图书馆，我是去一层，还是去三层？到最后你看到的只是一种可能性。可是那个本可以选择去吃饭的"你"，你看得到吗？看不到。小说也是如此。

```text
                        ┌── 往左 ──┬── 再往左 ── …  （被写出来的那条路）
   人物面对一个岔口 ────┤          └── 再往右 ── …  （只存在于"本可以"里）
                        └── 往右 ──┬── 往左 ── …  （同样没被写出）
                                   └── 往右 ── …
```

每一次分岔都是一条可能的人生，小说只写出其中一条，其余的全都沉在"本可以"里。祖父想写的，是把所有分支都同时写出来的那部书。

所以祖父想呈现的，就是一部能够穷尽所有选择、所有时间可能性的小说。可你去想：这样的小说有可能实现吗？不可能。它背后体现的是人生当中的某种困境和某种无奈——我们没办法穷尽人生当中的所有可能性。人生可能就是由某些偶然的选择组成的：你之所以成为你，你之所以跟别人不一样，就是因为每一个分岔路口，你选择了走这儿，他选择了走那儿，到最后我们的路径不一样。就像走迷宫一样。

### 偶然还是必然：没追上的那班车

两个人在那个场景里聊了很多很多话题。余准聊了半天，还没忘干正事：他掏出一把枪，把阿尔伯特杀了，阿尔伯特当场就死了。

按正常的逻辑，余准肯定会被捕；整篇小说，就是他被捕之后在监狱里的供词。而且这篇小说的形式还很有意思：供词的前两页缺失了，你读到的只是后面几页。

小说最后说：我知道德国成功了。为什么？因为我已经在前天的报纸上看到，英国攻打阿尔伯特这座城市没有成功。而结尾还留了一笔，非常耐人寻味：同一天的报纸上，还刊登了另外一则消息——一个叫余准的人，杀了一个叫阿尔伯特的人。

发现没有？按道理，余准杀阿尔伯特这件事，不可能跟德国那件事发生在同一天，可它们出现在同一天的报纸上。小说就这样结束了。

这个结尾背后想呈现什么？余准到底是成了，还是没成？我的解读是：它想传达的是，我们每个人到最后的结果，到底是通过一个个偶然性导致的，还是可能有其必然性。

举个最简单的例子：你们来到劳动关系学院，你觉得到底是高考时填的那个偶然的志愿导致的，还是这个偶然的志愿里其实蕴含着某种必然？说到底，你得这样问自己。你们平时没思考过这样的问题吧。

我还读到过一篇小说，叫《车站》，也很荒谬，很短。一个人早上起来，刷牙漱口，整理衣服、穿衣服，坐下来吃早点，然后下楼，要去上班；一看时间不够了，赶紧走；路上看到一辆公交车，就追，追的过程当中赶上了，然后开始上班——这是第一章。

第二章特别有意思：所有的文字内容几乎跟第一章一模一样。也是一个男人起床，吃早饭、刷牙漱口，也看到一辆公交车，也开始追——唯独结尾不一样：没追上，被车撞死了。小说就结束了。

它想呈现的是什么？我们的人生当中，很有可能在某一瞬间，你的命运就会发生改变，但你不知道。其实你已经逃过一劫，你可能已经走上了那条正确的路；你觉得这一切都是自然而然的，但那可能只是一个偶然的结果。

所有这一类小说，都是在通过牺牲表象的真实，来探寻真实的哲理。

### 回到那条小船：被拉长的因果

说回《河的第三条岸》。网上还能看到一个完整版本——上节课给大家念的是高考试卷的版本。如果你看了完整版，会发现它增加了很多细节。我觉得其中一个细节非常关键，却在高考卷子里被删掉了，就是那个结尾。

结尾写的是：我看到父亲坐着小船过来，我很害怕，然后我跑了；接下来是一系列心理活动——我也要买一条小船，躺在上面，把自己沉入河底。

这个细节给了我很大的提示，对理解这部小说的主题是个很大的提示。

那么我们追问一个问题：父亲当初为什么要买一条小船，在河上走，在河上不下来？为什么？而最后的结尾是，"我"也想要买一条小船，沉入河底——这好像是某种循环。

儿子这个逻辑就很奇怪：他为什么要沉入河底？因为他觉得自己好像背叛了父亲，他要用这样的方式完成救赎。

但你可以想象，他绝不会第二天就立马去买一条小船沉入河底。他会怎么样？他会接下来该干嘛干嘛：娶妻、生子、结婚，人生当中一切该办的事情都办完了之后，有一天他觉得可以了，于是他买条小船，到河上去。

如果这样的解读成立，它背后呈现的是：人生当中有些经验，因果关系不是那么明显的。

你打我一拳，我立马回你一拳，这个因果关系很明显——因为你打我，所以我要打你。但人生当中有没有这样一种经验和可能：你打我一拳，这一拳当时我没有感觉，但是十年之后、二十年之后，我突然间感觉到疼？

这么一听，你觉得很荒谬。但比如你的亲人去世了，当时你没有感觉，十年之后、二十年之后某一天，你突然觉得好悲伤。今天这个果，是由十多年前那个因导致的，只不过这个因果关系拉的时间特别长；导致当你悲伤的那一瞬间，周围所有人都觉得你的悲伤毫无来由，不知道你怎么回事——只有你知道，那跟三十年前的那件事有关系。

```text
   因（很多年前）────────── 长长的延迟 ──────────► 果（某一天突然疼、突然悲伤）
        │                                                  │
        └──────────── 这条线只有当事人看得见 ──────────────┘
                        旁人只看见孤零零的一个"果"
```

因果并没有消失，只是被时间拉长到超出了旁人的观察范围；小说做的，是把这条被拉长的线推到极端，让它在荒谬的形式里显形。

所以回到《河的第三条岸》：当所有人都觉得父亲买一条小船到河上去这件事很荒谬的时候，很有可能，父亲在很多年前也曾以某种方式背叛或辜负过他的父亲；很多年之后，他选择了一种救赎，而周围人不能理解他的救赎。这是人生当中的另外一种经验，小说以一种非常荒谬的方式，把它推向极端的形式呈现了出来。我觉得这是这部小说令人着迷的地方。

当然，上节课结束之后，我还看到有些同学对它的解读，我觉得也有道理，也是一种大家比较公认的解读：父亲到河中去，背后是寻找一种另类生活的可能性。

这就有点像《月亮与六便士》——我就想去画画，不行吗？假设一个人的追求，就是想到河边、到河中心去生活，难道不行吗？可在世俗生活当中，我们总觉得人生应该按"这样"过，于是对那些不按这样过的人，我们就认为是不正常的；但有可能在他们眼里，你才是不正常的。每个人都有选择自己生活方式的可能性。在这个意义上，第三条岸可能就是另类出路、另类选择的一种方式。

对这部小说有不同的解读，关键在于你能不能自圆其说。

> **易错点**：读这一类作品，最容易犯的错是拿现实生活的逻辑去核对它——人物不合常理、事件不合流程，就判它"假"。以后读文学作品，尤其是西方现代小说，不光是西方，中国现代的很多小说也一样，你要学会不按现实生活的逻辑去遵循它，而是去探寻它背后的哲理。

比如我读《河的第三条岸》，就立马想到村上春树的一部小说，叫《国境以南太阳以西》。这部小说也很荒谬，讲的是一个关于"西伯利亚歇斯底里症"的问题：有一个人天天朝着太阳看，想琢磨太阳落山的那一边是什么，看着看着，他就朝那边走过去了，再也没回来。你就觉得很荒谬——但人生当中可能就是有这样一群人，做了一群荒谬的事，而那也是出于他自己的一种探究和选择。

### 现实生活对艺术的模仿

前面我们讲了两面：一个是现实生活对文学的某种制约，第二个是文学对现实生活的某种超越。接下来你会发现，其实并不只是文学在模仿现实或者超越现实——甚至反过来，是现实生活模仿艺术、模仿文学作品。

| 关系方向 | 具体内容 | 在这一讲里的位置 |
| :--- | :--- | :--- |
| 现实 → 文学 | 现实生活对文学的某种制约 | 前面讲过 |
| 文学 → 现实（超越） | 文学对现实生活的某种超越 | 前面讲过 |
| 文学 → 现实（模仿） | 现实生活模仿艺术，艺术先给出"原来还可以这样"的脚本 | 这一节展开 |

这样的例子比比皆是。举一个稍微不太恰当的例子。2001年，你们刚刚出生，但那一年在全世界范围内发生了一件大事，一件非常重要、改变了整个世界格局的事情。

我那时上初中，印象很清楚：电视里几乎不播别的事，从头到尾你反复能看到那个画面——飞机冲向双子座大厦，然后大厦轰然倒塌。

我看到那个场景的时候，第一感觉是：这个场景似曾相识，总觉得在哪儿见过。后来仔细想想，这不就是好莱坞科幻大片里的场景吗？

据说后来有人做过调查：在9·11之前，美国的世贸大厦、双子座大厦，在好莱坞电影里已经被飞机撞过十多次了。只不过这一次是真的。

于是问题就来了：不只是艺术模仿现实生活，有的时候是现实生活模仿艺术。看完好莱坞灾难片，有人想的是——原来还可以这么玩。电影给他们提供了一种新的可能性，于是他们真的这么干了，还干成了。

这种情形在我们身边随处可见。比如说中学生的早恋：他们哪懂什么爱情？他不懂爱情，他是在电视剧上看了太多爱情。那些谈恋爱的孩子，在没谈恋爱之前，已经看了太多谈恋爱的东西了。谈恋爱的套路、表白的套路、说话的套路、撒娇的套路、生气的套路，完全是从电视剧当中带来的——从某种程度上，这就是一种模仿。

我相信没有人是在谈恋爱之前，一部爱情作品都没看过的吧？那问题就来了：你谈恋爱的时候，真的是你在谈恋爱吗？其实是人家教你的——是电视剧里某个小公主的形象，在建构你的生活。以至于现在的中学生早恋都毫无创造性，全部按照韩剧的模式来，连接吻的方式都一样。

再比如当年演《红楼梦》的那些人。87版《红楼梦》电视剧非常有名、非常经典。后来你会发现，那些演员演完《红楼梦》之后，很多人难以从这个作品当中走出来；以至于后来很多人去跟踪这些演员，发现他们后来的人生轨迹，跟他们在《红楼梦》里扮演的人物角色极为相近。演林黛玉的，先是出家，后来就去世了；演薛宝钗的，据说过上了荣华富贵的生活。

所以你就很难说，现实生活与艺术之间真的是一个"被模仿与模仿"的关系，两者之间的纠缠很复杂。

### 文学真实与情感真实：作者的经验不是保证

接下来换个维度：从作者这一边谈真实，也就是作品与作者之间的关系。

我先问一个问题：一个作家要想写某一类题材的作品，有没有必要事先亲身经历一下？

假设我是一个作家，我想写军旅题材，那可以；那有没有必要先到部队里去体验一下生活？有人说有：你想写军旅，赶紧到部队体验一下——你们还没军训呢，是吧，军训的时候体验一下。

按我们日常生活的逻辑，好像作家肯定要体验：体验完了之后你才知道，他在那个过程当中承受的压力、他的情感，你才有真切的体验。你想写厨师，就要到厨师的生活里去体验；你想写运动员，就要到运动员那儿去体验。

前两天我看新闻，说大年初一要上一部讲中国女排的电影，巩俐演郎平。巩俐要演郎平，首先得干什么？到中国女排去进行大量的了解：女排到底怎么训练，郎平尤其是——她要演郎平，那郎平到底是一个什么样的人、有什么特点，她要不断地记笔记。这是一种方式。

可是你想想：假设我是作家，我要写一个杀人犯的心路历程，怎么办？我先杀个人试试？那还写得出来吗？有些事是可以体验的，比如我要写一个吸毒者的心路历程，我先吸个毒体验一下？这怎么办？你会发现，不是所有的人生经历你都能体验。

事实也是如此。中国古代的很多诗人，尤其是写边塞诗的，根本没去过边塞。你想想，很多文人，真正去过边塞的没几个——也有，但没几个。可他写出来的边塞诗很好，这并不影响他。

这里面就涉及一个问题：文学真实与作家的情感经验之间，到底是一种什么样的关系？

#### 作者的情感经验是作品真实的一种保证

首先必须承认一点：作者有经验，要比没经验好一些。因为有了亲身体验之后，你才能挖掘到我们之前上课讲的细节的东西、细枝末节的东西，你才能够有深切的体验。

没有经验，往往写出来的东西很容易被人指认出来有问题：假，一看就是你没亲身经历过。

所以作家写到某一类题材的时候，第一步往往要采风，要深入生活。比如我要写农村题材，那我就得到农村生活一下、体验一下，这个时间有的时候是一个月，甚至更长，几年；真正融入到那个生活境况当中，把自己真正变成那样的人了。那当然没问题。

#### 并非所有生活都需要亲身经历

但问题也就来了：是不是所有生活都要体验？那不一定。

很多作家没经历过死亡，但他能写出濒死的体验来；很多作家没有杀过人，但他能写出一个杀人犯的体验来。

这源于什么？源于他强大的"模拟能力"——这是我造的词。模拟能力是什么呢？就是他好像大脑当中有一个模拟的软件，能自我模拟那样一个情境，能自我想象在那个情境之下人物的情节、心理动机，他能想象到每一个细节。

这就跟我们之前课上做的那个实验一样：你想象自己在沙漠里边发现了一堆金子，一大堆细节。好的作家就能把所有的细节都想象到，不需要亲身经历。这是一个强大的模拟能力。

> **提示**："模拟能力"不是凭空瞎编。它靠的是把一个情境里的人物、动机、细节一步步推演到位——推演得越细，写出来的东西越经得起读者的核对。

所以有的时候，作者的情感经验跟作品的真实，未必是绝对划等号的。

相反，有的时候你有经验未必是好事。比如我想写军旅题材，你能体验多长时间？体验俩月？恰恰相反，你体验俩月，可能还不如不体验。比如边塞诗人写边塞诗，你到了边塞，你体验到的那种东西也是浮光掠影式的体验；他那种是情感体验，你没法比。

所以在这个过程当中，即便有经验，经验的多与少，也成了文学真实的一个重要要素。

这里我要强调一点：作者的情感经验，不等于文学作品的真实。不要拿"他有情感经验、他亲身体会过"来说这部作品一定能成为好作品，不一定。

我经常会看到这样的评价：拿到一个作品，认为它是好作品，为什么？因为这个作家真深入生活了，作家深入生活了，他有了情感经验，有真切的体验——然后背后就划等号：有真切体验，他写出来的就一定是好作品；或者说，当然不一定是好作品，但一定是真实的作品。未必。

#### 创作动机的真诚也不等于真实

第三个问题：创作动机的真诚，也不等于文学作品的真实。

换句话讲，作家可以很真诚——我就是为了写出一部伟大作品，才来写这个作品。也有作家写这个小说就是为了钱。

一个作家为了钱写出一个小说，有没有可能写出好作品？有可能。有没有可能写出一个真实的作品？也有可能。所以创作动机真诚与否，也不能作为评判作品真实与否的重要依据。

日常生活里就涉及这样的事：一个作家自己说了，我写这个小说就是为了钱；另一个作家说我写这个小说可不是为了钱，我是为艺术。有人就因为这两者创作动机的不同，说：为艺术的那个肯定写得真实、到位、高级；为钱的那个一定写不出好小说。不一定。

关键不在于经验饱满与否，也不在于动机是否真诚，关键在于你是否符合艺术创作规律。你只要符合了，这就够了。所以在这个问题上，没有一定之规。

| 常被当作"真实"凭证的东西 | 实际分量 | 原因 |
| :--- | :--- | :--- |
| 作者有亲身经历、情感经验饱满 | 是加分项，不是保证 | 经验能带来细节和深切体验，但经验有深浅多寡，浮光掠影的体验可能还不如不体验 |
| 作者没经历过，全凭想象 | 也能写出真实 | 强大的"模拟能力"可以把情境、动机与细节推到经得起核对的程度 |
| 创作动机真诚，不为钱只为艺术 | 与作品真实无关 | 为钱写作同样可能写出好作品，关键看是否合乎艺术创作规律 |

从某种程度上说，文学真实如果放到作者这个层面上，说它就是作者的情感真实、经验真实，未必很恰当。但事实是，现实生活当中我们往往会把它跟作者的情感真实、经验真实画等号——这是一个问题。

### 文学真实与读者经验：同一部作品，两种真实

最后一个层面：文学真实与读者经验，探讨的是作品和读者的关系。

在日常当中经常会有这样的问题：面对同一个作品，有的人觉得好真实，有的人觉得不真实。这个时候你会发现，所谓的真实与不真实，好像跟作品本身没关系，而是跟读者的个人经验有关系——他参照着什么来谈真实？

这两天我闲得没事，看了一个节目，叫《演员请就位》。我其实也不是非常关注这类节目，一开始是看到一条新闻，标题大概是"郭敬明大战李成儒"，我心想：郭敬明又出来了，好长时间没他消息了，他又出什么事了？新闻里配了一小段节目片段，是他俩的一段争论。

我这人看问题，你光给我截一段片段是不能说明什么问题的，我得把这个事情的前因后果都看。于是我在网上把这个节目从头到尾看了一遍——三个小时，111分钟，一秒不落，不带快进地看完了。真是闲得无聊。

看完之后我发现：这个节目确实很无聊，但郭敬明看待很多问题的态度，跟赵薇、李少红完全不一样，他们经常产生分歧，有的时候甚至完全相反。

看节目的时候，大家也都有这个经验：不光要看节目，还得开弹幕——弹幕有的时候很关键，弹幕里边有人才。我经常看到弹幕里有人说"我认同郭敬明说的"、"我改变了对郭敬明的看法"，也有人认为赵薇说得对，等等。

那么对于同样一段表演、同样一段作品，为什么不同的人有不同的认识？为什么有人说这个很真实，有人说很不真实？

他参照的是自己的个人经验。而这个个人经验，往往受制于这个人的文化背景、知识结构等等一系列背后的东西。他参照着这套经验，得出了真实或者不真实的判断。

所以同一部作品在不同读者那里得到相反的真实判断，并不是作品长出了两副面孔，而是两套经验在替它作证。真实感在这里不再是作品单方面的属性，而是读者的经验与作品相遇时产生的东西。

## 世界就是文本：叙事语法、角色功能与符号矩阵
> 对应块：BLK16 | 覆盖分集：P16 | 块标题（分集名）：《20191028 文学与世界：结构主义、形式与结》

### 同一场表演，两种"不真实"

同一部作品摆在面前，一个人说它真，一个人说它假，吵到最后往往不是作品的问题，是两个人各自带着什么样的经验走进去的问题。

《演员请就位》最开始那场争议就是个现成的例子。舞台上是一段表演，内容是中学生谈恋爱，两个人马上就要亲上，底下观众一阵起哄。李诚儒看完的反应很直接：天天就中学生谈恋爱，天天就呈现这个——太廉价、太简单。我把他的意思翻译一下：这类青春片拿出来的东西，廉价、简单，他不接受。郭敬明随后有他的反驳，我本来以为他会在"真实性"上下点功夫，结果他的反驳听起来有点绕。

真正值得琢磨的是李诚儒那句判断的来路。他说这东西"不真实"，依据的其实是他自己的经验：他对青春片、对中学生恋爱、对观众起哄这一整套东西的接受度，决定了他看到什么会觉得别扭。经验一变，"真实"的判定就跟着变。

> **结论**：关于真实的认知差异，往往源于读者经验的不同。

这话听着像常识，但把它推到极端，会出来一个很尖锐的场面。我读研究生的时候，学校请过一位日本学者来做讲座，讲电影、讲文化。这位学者从头到尾用中文讲，中文说得非常好，好到我听着听着就忘了他是个日本人。他讲课时爱提问，有一次点到我，问：你喜欢看什么电影？

我想都没想，张口就来：《鬼子来了》。

为什么？因为前天晚上我刚看完姜文的这部片子，觉得还挺好，第二天他这么一问，我就说了。话一出口我立马意识到完蛋——那个场面你可以想象，空气都是凝固的，所有人都不知道说什么，都在等着看这位日本教授怎么回应。

他说：《鬼子来了》我也看过，正好我也看过，但是我不太喜欢这部电影，我觉得它不真实。

我心里想，我可坏了：本来一个友好的学术讨论环境，被我把民族问题都弄上来了，这真是搞事情，最赖我。

但他接下来给出的理由，让我觉得很有意思。他说：我为什么觉得《鬼子来了》不真实？因为我看这部电影的时候，里面所有日本兵说的那些日语，是太纯正的"日本普通话"。而事实上在那个年代，参战的日本兵都是来自日本乡村的，那些人说话一定带着脏字，一定带着口音、带着方言，而且方言还很明显。但在姜文的电影里，我完全听不出来。所以我觉得这部电影很不真实。

他这么一说，我立马觉得有点意思：他参照了他的经验，获得了一个我们无法获得的经验。姜文可能很认真，找了非常好的日本翻译，把里面所有人的台词都翻成日语——但他忽略了说话人的身份和当时的语境。于是在日本人看来，这部电影不真实；而我们没有这样的参照，反而可能觉得它很真实。

> **提示**：同一部作品在不同文化、不同经验的人那里会被判成不同的"真实度"，这不是谁眼力好、谁眼力差，而是各自拿来核对的参照系不同。

真实与否，跟个人经验有很大的关系。再往前推一步，不同的文化都有关于"真实"的经验性规定。

在原始社会，什么叫真实？真实并不在逻辑的真实，也不在细节的真实，而在一种超验性的感受的真实。所以神话不追求逻辑，也不追求细节的真实。到了科学主义的时代，标准就变了：要追求细致的、细节的真实。

关于文学与真实的问题，我们就说这么多。

### 除了再现与表现，还有形式与结构

文学与世界的关系，我们讲了两个方向。一个是再现，再现的是外在的客观性、社会现实；一个是表现，表现的是人的内心情感。一个向外，一个向内。

那么除了向外和向内这两个维度，还有没有别的维度？文学与世界的关系，还有没有可能呈现别的东西？

有的。这个世界，就是文本。

这句话要慢慢拆。在这个维度里，文学与世界的关系，归根到底跟外在的客观现实没有直接关系，跟内心的情感也没有直接关系。文学呈现的是什么？呈现的是自身的形式和结构。文学就是为了呈现自身，它也不是为了呈现什么别的东西。这个世界就是文本，文本本身是一个自足的小世界。

> **定义**：所谓形式与结构这一维度，是把"世界"从外在现实和内心情感里挪开，直接等同于文本——作品不指涉别处，它只呈现自己的形式与结构。

这样的观点怎么理解？它跟整个西方六十年代以来的结构主义思潮有密切的联系，尤其是在法国兴起的结构主义。结构主义是一个很庞大的哲学思潮，把它坐落在文学上，文学研究里就有一个基本共同的观点：

> **结论**：文学作品具有内在的共通结构。

这里要停一下，因为这句话最容易被人当成废话。我们看到现在呈现给我们的文学作品，往往是千差万别、千变万化、丰富多彩的。结构主义者要问的不是"它们有什么不同"，而是反过来：这些千差万别的作品底层，会不会有某种共通的结构，支撑起了这么多种多样的样态？

拿音乐打个比方就好懂了。写歌写到后来是有乐理知识的，不是随便唱什么都行——它有这样的规则。音乐是为了呈现这个规则；你了解了这个规则之后，就可以按照这个规则编出成百上千套音乐来。文学作品也是一样，只不过比音乐复杂得多。

顺着这个比方往下走，问题就变成了：小说的"乐理"是什么？

### 写小说是可以按套路来的

我上大学的时候，写作课老师教给我们一种方法：你要想写小说，要想构思一个小说，其实很简单——只要记住几个关键词就行了。哪几个关键词？目标、阻碍、努力、结果、意外、转弯、结局。

万事开头难，你不知道从何下手，怎么办？把这几个关键词记住，这就是一个小说的基本套路。

拿凡尔纳的《八十天环游地球》走一遍，这套东西立刻就显形了。

主人公福格先立了一个目标：他跟人打赌，说自己八十天可以绕地球一圈，并且以全部财产作为赌注。目标有了，接下来上路。

环游地球当然不会那么顺利，一定会遇到各种阻碍。比如他被误认为是强盗；比如路上常常因为自己的善意耽误行程——救人这类事情，一做就耽误时间。

遇到阻碍没关系，他会用各种办法努力追赶时间：骑着大象跑、抄捷径、搭火车，各种方式走捷径。

结果是什么？他确实环游了地球一圈，但用的时间是八十天零五分钟。当初打的赌是八十天之内，他用了八十天零五分钟，所以他输掉了赌局。

接下来是意外。这里涉及一个问题：他是向东走、环游地球一圈的。结合一下地理知识——向东走，每越过一个时区，钟表就要拨快一小时，绕地球一圈累计多拨了二十四小时，所以他自己的日历比伦敦的日期多了一天。按伦敦的日期算，应该减一天：其实他只用了七十九天零五分钟。

转弯于是出现了：他赢了这场比赛。结局是：不仅赢了比赛，还抱得美人归。

| 要素 | 《八十天环游地球》里对应的情节 |
| :--- | :--- |
| 目标 | 福格以全部财产打赌，要在八十天内环游地球一圈 |
| 阻碍 | 被误认为强盗；因救人等善意举动耽误行程 |
| 努力 | 骑大象、抄捷径、搭火车，想尽办法追赶时间 |
| 结果 | 实际用了八十天零五分钟，超过期限，输掉赌局 |
| 意外 | 一路向东，日历比伦敦多一天，按伦敦算其实是七十九天零五分钟 |
| 转弯 | 他赢了这场比赛 |
| 结局 | 抱得美人归 |

写作课的老师讲完这个套路，接下来就让每位同学按这个套路自己编一个小说，现场编。编起来其实很好编。点到我，我说：有一个小孩，从小到大有一个目标——长大后要成为一个足球明星。但是他遇到了一个阻碍。我话还没说完，底下有人喊：腿断了。腿断了？没有腿了？我的天哪，这是一个非常励志的故事，可这个故事得能讲下去才行。

我当时想的是：他遇到的阻碍是没有俱乐部要他。为什么没有俱乐部要他？你们都把这个弄成先天的原罪，我一定要弄成后天的——为什么？我要有铺垫。他的父亲因为赌球、打假球，名声不好；于是所有的俱乐部都不要这个父亲的孩子。

但是他很努力。他终于加入了一个俱乐部——一个什么样的俱乐部？最烂的那个，马上就要解散，总共连十一个人都凑不齐。

接下来他在这个俱乐部里努力，获得了一个非常好的成绩。但拿到好成绩之后，他依旧不能被人认可，因为父亲那个污名还在。

怎么办？意外出现了：有一天一个偶然的情况，他发现当年父亲打假球是被污蔑的，其实不是他父亲干的。于是有了转弯：他澄清了自己。结局：他成了球星。

把故事串起来之后，接下来你要做的一件事，就是不断地丰富它的细节、不断地丰富它的因果关系——一个故事就串联出来了。主人公可以换，目标可以换，那多了去了。

顺便告诉大家：写小说、当编剧，其实是一件比较容易的事情。你不要认为讲故事那么难，讲故事都是有套路的。你去看看好莱坞电影，都是有套路的。只要按套路，就可以像手工作坊生产商品一样，一个一个地生产故事。

> **注意**：按套路写出来的故事，可以让你写成一个"看得过去"的故事，但绝对不可能让你写出一个好故事。好故事需要天赋，需要机遇，需要各种各样的因素。套路解决的是"能不能写出来"，不是"写得好不好"。

后来我把这个模式再归因了一次，发现它比"套路"还整齐。目标相当于"因为"；阻碍相当于"但是"；努力和结果相当于"所以"；意外和转弯相当于"但是"；结局相当于"所以"。

```text
因为  ──→  但是  ──→  所以  ──→  但是  ──→  所以
目标       阻碍      努力/结果     意外/转弯     结局
```

一条链读下来：所有的故事，都是按照因果关系排列出来的一系列情节。而一个故事，特别像一个句子——只不过是一个比较复杂的句子。

### 叙事作品是一个大句子

故事像一个句子，这个直觉不是我们独有的，已经有很多理论家发现了它。这就涉及一个很重要的概念：叙事语法。

叙事语法的想法是这样的：好多好多的文学作品，你不断去简化它、简化它，抽到最后就是一个句子；而这个句子又是按照某种语法结构安排起来的。所以他们有一句很经典的话：

> **结论**：叙事作品是一个大句子。

一部几十万字的小说，在结构主义者看来，其实就是一句话的展开——把一句话展开成了几十万字。

对这个问题，有两位理论家做过更深入的分析。

罗兰·巴特，《叙事作品结构分析导论》——我们在讲符号学的时候碰到过他。他提出：所有的叙事作品都具有句子的性质，都像是句子，只不过它要分成几个层面。这个问题在大一的课上没有必要讲得那么复杂，了解一下就行；有空可以自己去看，那是更高一层的研究过程当中才会细讲的东西。

托多罗夫，《文学作品的分析》。他说：组成情节的最小单位是一个个的叙述句，而一个叙述句里有很多要素。他举的例子是这样的：X 是一个姑娘，Y 是 X 的母亲，Z 有一天抢走了 X。

在这个例子里，X、Y、Z 都是一个个的行动单元；构成它们之间关系的是谓语——"是""是……的母亲""抢走了"这样的关系。

```text
一个大句子（整部作品）
   │
   ├── 叙述句（情节的最小单位）
   │      ├── 行动单元 X
   │      ├── 行动单元 Y
   │      └── 行动单元 Z
   │
   └── 谓语：把行动单元之间的关系接起来
```

读图：作品往下拆是叙述句，叙述句往下拆是行动单元，行动单元之间靠谓语连接。所以叙事语法认为，所有的叙事作品都是一个个的语言单位，它有成分、有语法，成分和语法的不同排列组合，形成了一个个不同的故事情节。

举几个例子，都是初中就学过的。

《最后一课》，都德的。整个故事简单来说就是：阿尔萨斯沦陷后，我听韩麦尔先生讲最后一节法语课。一句话就概括完了。

《故乡》，鲁迅的。简要而言就是：我为接母亲搬家而返回故乡这么一个过程。当然在这个过程当中发生了一系列的事情。

《西游记》，就是唐僧师徒战胜妖魔、西天取经的这样一个故事。

它们都压得成一句话。

> **易错点**：这种叙事语法的分析有一个弊端——它仅限于概括，还没有进入细致的分析过程。你把《西游记》压成一句话，压得很准，但这句话并不能告诉你这部小说是怎么组织起来的。概括是起点，不是终点。

### 普罗普：三十一个功能，七个角色

正因为概括不够，接下来就有理论家往细里做。第一位是俄国理论家普罗普，他写的书叫《民间故事形态学》，1928 年出版。他是二十世纪初俄国一位重要的理论家，被誉为结构主义民间文艺的奠基人。

这本书对一百个俄罗斯的神奇故事、民间故事做了比较分析。他发现，这些民间故事、传说故事好多都是大同小异，或者说你总觉得它们有相似的地方。

他举了四个例子：

1. 沙皇赠给好汉一只鹰，鹰把好汉带到了另一个王国。
2. 老人赠给苏森科一匹马，马把苏森科带到了另一个王国。
3. 巫师赠给伊万一只小船，小船把伊万带到了另一个王国。
4. 公主赠给伊万一只指环，从指环里出来的英俊青年把伊万带到了另一个王国。

四个故事的细枝末节千差万别：赠东西的人不一样（沙皇、老人、巫师、公主），赠的东西不一样（鹰、马、小船、指环），负责把主人公带走的也不一样（鹰、马、小船、指环里出来的青年）。但读下来你总觉得它们差不多，因为骨架是同一个：某人赠给主人公一件东西，这件东西把主人公带到另一个王国。

> **结论**：故事换的是零件，不换的是结构。

顺着这个发现，普罗普在《民间故事形态学》里挖到了他的结论：所有的民间故事不超过三十一个固定功能，而这三十一个功能又组成七个角色圈。

先把七个角色说清楚。

| 角色 | 一句话定位 |
| :--- | :--- |
| 对手 | 加害者、追捕者 |
| 赠与者 | 提供者，把宝物交给主人公 |
| 相助者 | 帮手，助主人公完成艰难任务 |
| 公主 | 要找的那个人 |
| 派遣者 | 派任务的那个人 |
| 主人公 | 行动的主体 |
| 假冒主人公 | 冒名顶替的假英雄 |

一个一个展开。

对手，指的是加害者、追捕者。你把它稍微扩大一下，它往往暗示着有些东西是破坏社会安宁的那个要素。放到现代社会，这个对手可能未必是个人——有可能是一种险恶的、异化的环境，也有可能是某个人内心的心理创伤。这些都是对手。

赠与者，指的是在普罗普所研究的作品里，把宝物提供给主人公的那个人。民间故事里往往要有一个宝物，宝物交给主人公，主人公保管，然后不小心弄丢了——这样的场景很常见。所以赠与者往往就是提供帮助的人，或者是山中高人：山中高人有一本武林秘籍，交给主人公。

相助者，就是在主人公行动的过程里承担一个重要角色的人：帮助主人公完成艰难的任务。在好莱坞电影里，你要知道他完成了帮助的任务之后，往往要死掉。为什么要死掉？因为不能太拖沓，不能成为拖累；而且死掉的过程有很强的煽情作用——他帮助了你，是你前进道路上的一个重要帮手，但他死掉了，这个时候太好煽情了，赶紧往里渗。你会发现作品里最爱提前死掉的，往往是最无辜、最单纯的那个人，一定要先死掉，这样才让你觉得悲情。

公主，就是要找的那个人，要找的对象。

派遣者，是派遣任务的那个人。他背后是某种社会的象征。

主人公，是行动的主体。有的时候派遣者跟主人公是同一个人——任务也是主人公自己发出的，也由主人公自己去行动。

假冒主人公，在民间故事里经常出现：《西游记》里的真假孙悟空，《水浒传》里的李逵和李鬼。为什么老要出现？有一个假的英雄形象在这里面，一路上经常会闹出些笑话，有意思。

> **易错点**：这套东西的局限也要看清楚。它只做出了这样的归类——有人觉得已经很不错，有人觉得还不够。尤其是"假冒主人公"，显然不符合现代：不是所有作品里都有假冒主人公。

### 格雷马斯：六个行动元

接下去是法国的结构主义理论家格雷马斯，他写过一本书叫《结构语义学》。他是非常重要的一位法国结构主义理论家，他的结构语义学理论，可以说是很多研究文学、研究文学作品的人都要谈到、甚至必须用到的理论。

他做的第一件事，是把普罗普的七个角色单元再改造一次，归结为六个行动元：主体、客体、发送者、接收者、辅助者、反对者。

```text
发送者（派遣者） ──→ 客体（公主/目标） ←── 接收者（受益者）
                      ↑
                      │
辅助者（相助者） ──→ 主体（主人公） ←── 反对者（对手）
```

读图：上面一行是"任务—对象—受益"这条线，下面一行是"推动—行动—阻挡"这条线。主体去追求客体，发送者把任务和意义赋予客体，接收者最终受领它；辅助者在下面推着主体往前走，反对者在对面挡着。

拿它跟普罗普的七个角色对着看，你会发现几乎是一个翻版。

| 普罗普的七个角色 | 格雷马斯的六个行动元 |
| :--- | :--- |
| 主人公 | 主体 |
| 公主（要找的人） | 客体 |
| 对手 | 反对者 |
| 相助者 | 辅助者 |
| 派遣者 | 发送者 |
| 赠与者 | 接收者（对不太上） |
| 假冒主人公 | 取消 |

唯独不太对应的是接收者，它跟赠与者好像不太能对上。而且格雷马斯取消了一个人物元素：假冒主人公没有了，假英雄没有了——因为他觉得可以归纳到其他类别当中去。

格雷马斯背后的意思是：

> **结论**：几乎任何作品、任何文学作品当中的人物形象或者情节单元，几乎都逃不出这六个行动元。

随手举个例子。《我不是药神》：

- **主体**：程勇，主人公。
- **客体**：他要找的是什么？他要干的是什么？拯救白血病人——白血病人就是他的客体。
- **发送者**：给他任务的那个人。他一开始并不是自己想要干这件事的，得有一个人把任务递给他——吕受益。"我这有药，你想不想赚钱？想赚钱，你来帮我拿这个药。"
- **辅助者**：一大群帮手——黄毛，还有那个老头，一系列的那些人。
- **接收者**：还是白血病人。
- **反对者**：卖假药的，以及挡在他前面的对立力量。

你会发现，整个作品当中所有的人物形象，全部可以归到这几个类型里去。这就是格雷马斯的一个创建：他把所有的结构都化约、化约，化约到最简单的结构、最底层的结构，不过是这些。

当然，不是说所有作品里每一个角色都齐备；但只要有，都可以划归到这里边。

### 符号矩阵与《老人与海》

格雷马斯做的第二件事，是提出了符号学矩阵。

一提到"矩阵"这两个字，就很像数学了——这也是文学理论"高级"的地方，像数学的地方。

矩阵是什么样子？四个格子：x、反 x、非 x、非反 x。

它特别像什么？像你们中学学的原命题、逆命题、否命题、逆否命题。（当然我们现在说的不是命题，没有关系。）

```text
        x ─────────────── 反 x
        │ ╲                │
        │   ╲              │
        │     ╲            │
        │       ╲          │
        │         ╲        │
      非 x ─────────────── 非反 x
```

读图：四个格子两两成对。上面一对是 x 与反 x，下面一对是它们的否定；两条竖线把 x 与非 x、反 x 与非反 x 各连起来，斜线把 x 与非反 x 接上。所有的人物和情节，最后都被塞进这四个位置里。

格雷马斯说：所有的人物关系也好、情节关系也好，都可以放到二项对立里去。为什么可以？因为他发现这六个行动元本身都有点二元对立——有主体就有客体，有发送者就有接收者，有辅助者就有反对者，都是二项对立的。把这些二项对立再抽象一次，就成这样一个结构模式。以它为圆心，我们就可以拿这个模式去分析很多作品。

拿《老人与海》走一遍。这是海明威著名的中短篇，他恰恰是因为这部小说获得了诺贝尔奖。

第一步，列要素。《老人与海》里有什么？有老人，有海，有一条鱼——不是鲨鱼，是马林鱼（当然也有鲨鱼，但鲨鱼跟海差不多了）；然后上岸之后还有一群其他的人：游客、一个小孩，等等。后面这些人我们统称为"他人"。整个故事就这四个要素。

第二步，把它们放进矩阵。

| 矩阵位置 | 填入的要素 |
| :--- | :--- |
| x | 老人 |
| 反 x | 他人 |
| 非 x | 马林鱼（老人的对象） |
| 非反 x | 大海 |

第三步，分析这几个要素之间的关系。

老人与他人，是个体与群体的关系。小说一上来就写得很清楚：这个老人八十四天没有打到鱼了。那他这次为什么还要出海打鱼？从某种程度上说，是一种自我证明。而这种自我证明，更重要的是来自他人——他人形成了一种权力话语。你要想被认可，最重要的是赢得他人的认可；在这个社会当中，社会对你的评价、对你的肯定或者否定，其实决定了你作为个体的地位和价值。于是老人为了在他人面前证明自己，出海打鱼。

老人与鱼，是斗争的关系、杀戮的关系。这背后是人与自然的关系，而这里的人与自然，往往强调的是斗争与杀戮，是胜者为王，是优胜劣汰。老人凭自己多年的技巧，终于打到了这条鱼。

老人与大海，大海象征着某种绝对的自然。故事的最后，老人打到了鱼，但拖上来的只剩一副鱼骨头。从某种程度上讲，你会觉得这个老人好"hold 不住"——个体在整个大自然面前的某种无助、某种渺小。而在整个时间的冲刷之下，一个人的一切努力都会消失得无影无踪。

把《老人与海》的意义结构分析出来，一共三层：

1. **个体与群体的关系**：老人要的是自我确证。
2. **人与自然的关系**：优胜劣汰、杀戮，而且没有所谓的绝对强者。
3. **人与海的关系**：这是时间意义的关系，进而体现出人生的价值问题——我们做这些事情值得吗？有意义吗？

三层摆开之后，你就可以根据自己的理解得出一个结论：老人到底真正是失败还是胜利？

表面上看，在人与自然的斗争当中，老人可能是失败者。从时间的意义上讲，老人绝对是失败者——他没有带回来任何有用的东西。但恰恰是这样，老人才升华了自己的意义，因为他根本不在乎物质上的纯粹获得或失去。问题最后落在"胜利之后"的态度上。

### 让文学研究成为一门科学

我拿《老人与海》举例，是想呈现格雷马斯的结构语义学是怎么分析一部文学作品的。这种分析方法追求的目的只有一个：科学。

为什么非要科学？因为我们分析一部文学作品的时候，经常出现一个很实际的问题：这部作品你读完了，我也读完了，大家都读完了，你说的啥意思？我说的啥意思？接下来可能会有不同的解读；有争议，而在争议面前，谁也说不清谁一定是对的、谁一定是错的。怎么办？

格雷马斯说：我们干脆这样，把文学研究科学化，按照一个一个的、程序化的步骤来解读文学作品。于是他发明了符号学矩阵，流程是这样：

```text
列要素
  │
  ↓
放进矩阵
  │
  ↓
找对立关系
  │
  ↓
从对立关系里抽离出意义
  │
  ↓
用这个意义解读作品的深层含义
```

读图：五步走完，一部作品的"意义"就被生产出来了，不再依赖读者各自的感受。

他的目的是：文学研究不要太主观化，应该给文学研究一整套的科学方法，这样文学研究才叫研究，这样文学研究才显得科学。这是整个格雷马斯式结构主义背后探寻的目的。

这种研究好不好、对不对？

首先你会发现它很有效。你在网上随便一搜"格雷马斯"去分析中国古代作品——分析《红楼梦》也好，分析鲁迅作品也好——会发现特别多。基本模式是：论文里都得画这么一个框。以后你考研也好、让你分析一个作品也好，怎么才显得专业？先画一个框，先画一个矩阵——这是别人画不出来的，是非专业的人不懂的——然后再去扯它们之间的关系。

但也有人说了：这种分析容易造成太僵化、太死板。难道所有作品都只有这四个要素吗？当然也有人把这个方法发挥出了新的模式。

这是一个方法。除此之外还有另外几种方法，下节课接着讲。
