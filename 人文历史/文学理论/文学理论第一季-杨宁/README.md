# 文学理论课程全集 第一季（杨宁）（32 讲）

杨宁老师 2019 年秋季《文学理论》全集第一季（32 讲），是国内人文公开课里口碑最高的一门理论课。课程按「文学四要素」组织：文学与世界、文学与文本、文学与作者、文学与读者，从本质主义之争讲到陌生化话语，从意识形态与症候式阅读讲到叙事学、精神分析、原型批评，最后以接受美学收束。讲法特点是概念史梳理清晰、例子鲜活、不断自我设问，32 讲整编为 5 册模块全书与 8 篇主题复习笔记。

- **原视频**：[文学理论课程全集 第一季 （32讲）（ 2019年秋）](https://www.bilibili.com/video/BV1LE411e7NE) — Bilibili，BV1LE411e7NE
- **全 32 讲**，已产出 5 册模块全书、8 篇复习笔记、32 份逐字稿

## 怎么学

- **先立框架再填内容**：绪论把「文学理论是什么、四种形态」立住之后，全课都挂在「四要素」框架上，笔记01 是全课地图。
- **本质论是地基**：本质主义与反本质主义之争、文学话语的陌生化，决定了后面每一个「文学是什么」的回答立场，笔记02 值得反复读。
- **四要素各成一篇**：与世界（意识形态/再现表现）、与文本（叙事学）、与作者（精神分析/原型）、与读者（接受美学）——每篇笔记开头都有该要素的理论谱系图，先看谱系再进细部。
- **西方文论名词别死背**：镜子说、陌生化、症候式阅读、召唤结构、隐含读者这类概念，配合讲师举的文学案例记，笔记里案例都保留着。
- **跨季衔接**：第二季（28 讲）是同一框架的深化，学完第一季再看第二季，术语体系无缝衔接。
