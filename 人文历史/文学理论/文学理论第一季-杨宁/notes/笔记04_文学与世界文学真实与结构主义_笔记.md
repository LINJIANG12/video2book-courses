# 文学与世界：文学真实与结构主义

## 诗意的真实

### 表象的牺牲与哲理的转换

* **诗意的真实**

    * > **定义**：文学不靠复刻现实生活的表象来获得真实，而是通过牺牲表象的真实，去换取另一种更根本的真实。

    * 本质：把事实的表象转换为真实的哲理。

    * 条件：现实材料不足以支撑要讲的道理时，让表象失实、让人物与事件不符合现实生活的逻辑，哲理才被呈现出来。

    * 收益：牺牲表象的真实，换来文学更多的自由；有时因为太追求某种真实的道理，会去蔑视原始的真实、蔑视现实生活的真实。

    * 边界：文学的真实感遵循的往往不是现实生活的逻辑；用生活流程去核对，核对不出真假。

    * 阅读感受：第一感常是荒谬，但又觉得背后有话要说，需要挖掘，不是一望而知，所以比较难懂。

    * > **易错点**：拿现实生活的逻辑去核对作品——人物不合常理、事件不合流程，就判它"假"。读这类作品要学的不是核对流程，而是探寻背后的哲理；不光是西方现代小说，中国现代很多小说也一样。

* **反现实逻辑的作品**

    * 共同特征：不符合现实生活的逻辑，也不符合现实生活整个过程的逻辑，人物形象也不符合。

    * 代表：罗萨《河的第三条岸》——父亲买一条小船到河上，再也不下来。

    * 问题：这样的作品凭什么说它真实或不真实；它遵循的是诗意的真实，不是生活逻辑。

    * 分布：这类作品在文学史上很多；中学阶段读得不多，但翻世界文学史会经常遇到。

### 自我指涉的叙事

* **自我指涉**

    * > **定义**：小说中的人物读到了这部小说本身，作品把自身作为情节元素纳入叙事。

    * 《堂吉诃德》：分上下两部；下部里堂吉诃德读到新出的《堂吉诃德》上部，内容与上部一模一样。

    * 《哈姆雷特》：哈姆雷特自导自演一出戏请叔叔来看，戏的内容正是叔叔杀父与复仇的过程；剧中人物看了《哈姆雷特》这个故事本身。

    * 《一千零一夜》：妃子每晚讲一个故事保命，其中一夜讲的故事就是《一千零一夜》本身。

    * 《摩诃婆罗多》《罗摩衍那》：主人公听到史诗本身；诗人念完，他才恍然那两个儿子就是自己的儿子。

    * 共同点：都打破了关于现实真实的概念，不符合现实生活逻辑与人物形象。

* **镜像结构**

    * 推论起点：既然小说人物能读到作品本身，读这部小说的读者是否也可能是某个被虚构出来的人物。

    * 比喻：照镜子时以为自己在照镜子，也可能镜中人才是在照你，你才是那个像。

    * 作者定位：阿根廷作家博尔赫斯每部作品都走"以诗意的表象换取真实的哲理"这条路。

    * 效果：读起来好像有意思，琢磨起来细思极恐。

### 《小径分岔的花园》：时间与分岔

* **情节骨架**

    * 余准：青岛大学教授，青岛当时在德国人手里；给德国人当特务，刺探英国军方情报，察觉身份暴露、被英国人跟踪。

    * 情报：英国接下来要攻打德国城市阿尔伯特；他被盯上，必须另想办法把情报传出去。

    * 传递：找来老式电话本，一页页翻，找到名叫阿尔伯特的人并把他杀掉；"余准杀阿尔伯特"登报后，德国情报局由此推出城市名。

    * 找路：小孩围上来直接问是不是找阿尔伯特博士，指路"直走—到岔口右转—再直走—再右转"；这是不会走迷宫的人遇到岔路就往右转的走法。

    * 见面：阿尔伯特是汉学专家，研究的正是余准祖父；见到余准很欢迎。

    * 形式：整篇是余准被捕后在监狱里的供词，供词前两页缺失。

    * 结尾：前天的报纸既刊"英国攻打阿尔伯特未成功"，又刊"余准杀阿尔伯特"。

* **谜底：时间**

    * 祖父：事业生涯走到一半时辞去所有职务，专写一部超越《红楼梦》的著作。

    * 书的神秘：书写出来了，别人觉得没什么；他自己说所有关于人生的思考、所有秘密都藏在里面。

    * 破谜方法：猜谜时若谜底是"棋"，谜面里最不能出现的就是"棋"字；祖父小说通篇涉及时间，却从不出现"时间"一词，每次遇到就换方式绕开。

    * 谜底：时间。

    * 写作目标：写一部能穷尽所有时间可能性的著作，并传给后世。

    * 动机：时间困扰人生的永恒命题。

* **分岔与穷尽**

    * 人物面对绝境只有两种选择（往左/往右）；选左之后又遇新情境、再分岔；写出来的只有一条路。

    * 未被写的分支并非不存在，它们沉在"本可以"里；人生也由无数选择构成，你看到的只是一种可能性。

    * 图示：

    ```text
                            ┌── 往左 ──┬── 再往左 ── …  （被写出来的那条路）
       人物面对一个岔口 ────┤          └── 再往右 ── …  （只存在于"本可以"里）
                            └── 往右 ──┬── 往左 ── …  （同样没被写出）
                                       └── 往右 ── …
    ```

    * 不可实现：穷尽所有选择、所有时间可能性的小说不可能实现。

    * 背后：人生困境与无奈——没办法穷尽所有可能性；人生可能由某些偶然选择组成，每个岔路口的选择不同，路径就不同，像走迷宫。

* **偶然与必然**

    * 结尾的错位：按道理余准杀阿尔伯特与英国攻城不可能发生在同一天，两件事却出现在同一天报纸上。

    * 问题：余准到底成了没成；每个人最后的结果是偶然导致，还是偶然里含必然。

    * 类比：一个人来到某所学校，是高考填志愿那个偶然导致的，还是那个偶然里蕴含某种必然。

    * 《车站》：第一章男人起床、刷牙漱口、穿衣、吃早点、下楼上班，追公交车赶上；第二章文字几乎一模一样，唯独结尾没追上、被车撞死。

    * 主题：某一瞬间命运就可能改变而当事人不知道；以为自然而然的结果，可能只是偶然。

### 《河的第三条岸》：结尾与救赎

* **完整版结尾**

    * 试卷版删掉了关键结尾，完整版另有结尾。

    * 完整版：我看到父亲坐着小船过来，很害怕，然后跑了；随后一系列心理活动——我也要买一条小船，躺在上面，把自己沉入河底。

    * 提示作用：这个细节对理解主题是很大的提示。

    * 循环：父亲买船上河不下来，"我"最后也想买船沉河。

* **救赎式解读**

    * 儿子沉河的原因：觉得自己背叛了父亲，要用这种方式完成救赎。

    * 时间尺度：不会第二天就买船，而是娶妻、生子，把人生该办的事办完，某天觉得可以了，才买船上河。

    * 推到父亲：父亲很多年前也可能以某种方式背叛或辜负过他的父亲；多年后他选择一种周围人不能理解的救赎。

### 因果的时间延迟

* **日常因果与延迟因果**

    * 日常因果：甲打乙一拳，乙立马回一拳，因果关系明显。

    * 延迟因果：甲打乙一拳，乙当时没感觉，十年、二十年后突然觉得疼。

    * 现实对应：亲人去世时当时没有感觉，十年、二十年后某一天突然悲伤；周围人觉得悲伤毫无来由，只有当事人知道它连着三十年前那件事。

    * 机制：因果没有消失，只是被时间拉长到超出旁人的观察范围；旁人只看见孤零零的一个"果"。

    * 图示：

    ```text
       因（很多年前）────────── 长长的延迟 ──────────► 果（某一天突然疼、突然悲伤）
            │                                                  │
            └──────────── 这条线只有当事人看得见 ──────────────┘
                            旁人只看见孤零零的一个"果"
    ```

* **判断意义**

    * 旁人判断人物荒谬，是因为只看见果、看不见因。

    * 小说把这条被拉长的因果线推到极端，让它在荒谬的形式里显形，荒谬就有了来路。

### 另类生活的解读

* **另类生活可能说**

    * 另一种比较公认的解读：父亲到河中去，是寻找另类生活的可能性。

    * 类比《月亮与六便士》：我就想去画画，不行吗；一个人想在河中心生活，难道不行。

    * 世俗预设：人生应该按"这样"过；不按这样过就被认为不正常，但在对方眼里你才是不正常。

    * 第三条岸：另类出路、另类选择的一种方式。

* **多解判准**

    * 《河的第三条岸》存在救赎说与另类生活说两种解读，两种都被视为有道理。

    * 判准只有一条：能否自圆其说。

* **同类作品**

    * 村上春树《国境以南太阳以西》："西伯利亚歇斯底里症"——一个人天天朝太阳看，想琢磨太阳落山的那一边是什么，看着看着就朝那边走过去，再也没回来。

    * 共同点：人物做荒谬的事，出于自己的探究与选择。

## 现实生活对艺术的模仿

* **三种关系方向**

    * 关系共有三个方向：现实对文学的制约、文学对现实的超越、现实生活模仿艺术。

    * 第三个方向是重点：现实生活也会模仿艺术、模仿文学作品。

| 关系方向 | 具体内容 |
| :--- | :--- |
| 现实 → 文学 | 现实生活对文学的某种制约 |
| 文学 → 现实（超越） | 文学对现实生活的某种超越 |
| 文学 → 现实（模仿） | 现实生活模仿艺术，艺术先给出"原来还可以这样"的脚本 |

* **9·11 与好莱坞**

    * 2001 年电视反复播放飞机冲向双子座大厦、大厦轰然倒塌的画面。

    * 第一感觉：场景似曾相识，像好莱坞科幻大片。

    * 调查说法：9·11 之前，世贸大厦、双子座大厦在好莱坞电影里已被飞机撞过十多次，只不过这一次是真的。

    * 机制：灾难片提供"原来还可以这么玩"的新可能性，有人真的照做，还干成了。

* **日常生活的模仿**

    * 中学生早恋：不懂爱情，是在电视剧里看了太多爱情；谈恋爱、表白、说话、撒娇、生气的套路全从电视剧带来。

    * 追问：谈恋爱时真的是自己在谈吗，其实是作品教出来的；某个"小公主"形象在建构生活。

    * 现象：早恋缺乏创造性，全按韩剧模式，连接吻方式都一样。

* **87 版《红楼梦》**

    * 演员演完很难走出作品；后来跟踪发现，人生轨迹与扮演角色极为相近。

    * 演林黛玉的先是出家，后来去世；演薛宝钗的据说过上荣华富贵的生活。

    * 结论：现实与艺术不是简单的"被模仿与模仿"关系，两者纠缠很复杂。

## 作者经验与文学真实

### 经验的作用与限度

* **经验是加分项**

    * 有经验比没经验好：亲身体验才能挖掘细节、细枝末节，才有深切体验。

    * 没经验容易被指认：假，一看就没亲身经历过。

    * 常规做法：写某类题材先采风、深入生活；写农村就到农村生活，时间一个月甚至更长、几年，真正融入，把自己变成那样的人。

* **经验不是必需**

    * 反例：很多作家没经历过死亡，能写濒死体验；没杀过人，能写杀人犯体验。

    * 反例：中国古代写边塞诗的诗人，真正去过边塞的没几个，写出来的边塞诗很好，不影响。

    * 不可体验的题材：写杀人犯心路历程不能先杀个人；写吸毒者不能先吸毒。

    * 结论：不是所有人生经历都能体验，也不是所有生活都需要体验。

* **经验未必越多越好**

    * 体验时长有限：写军旅体验两个月，可能还不如不体验。

    * 边塞诗：到边塞得到的也是浮光掠影式体验，比不上真正的情感体验。

    * 结论：经验的多与少也是文学真实的重要要素。

* **经验与真实的非等号**

    * 作者的情感经验不等于文学作品的真实。

    * 常见误判：作家深入生活、有情感经验、有真切体验，就推出作品一定真实、一定是好作品。

    * 结论：未必；经验只是加分项，不是保证。

### 模拟能力

* **模拟能力**

    * > **定义**：作家在头脑中自我模拟一个情境，把人物、情节、心理动机与细节一步步推演到位的能力。

    * 表现：没经历过死亡也能写到濒死细节；像大脑里装了一个模拟软件。

    * 作用：把情境、动机与细节推到经得起读者核对的程度。

* **模拟的边界**

    * 不是凭空瞎编：要靠一个情境里的人物、动机、细节一步步推演到位。

    * 检验方式：与"想象自己在沙漠里发现一堆金子"的实验同理，好作家能把所有细节想象到。

### 动机真诚与艺术规律

* **动机真诚不等于真实**

    * 作家可以很真诚地为艺术写作，也可以就是为了钱。

    * 为钱写小说可能写出好作品，也可能写出真实的作品。

    * 反例逻辑：不能因为"为艺术"就判定真实、高级，也不能因为"为钱"就判定一定写不好。

    * 关键：不在经验饱满与否，也不在动机是否真诚，而在是否符合艺术创作规律；符合了就够了，没有一定之规。

* **三种凭证的分量**

    * 常见误判：把作者的经历、想象方式、创作动机当作作品真实的凭证。

    * 判断：把文学真实等同于作者的情感真实、经验真实，未必恰当。

    * 现实倾向：日常生活中往往这样画等号，这是一个问题。

    * 三种凭证的实际分量见下表。

| 常被当作"真实"凭证的东西 | 实际分量 | 原因 |
| :--- | :--- | :--- |
| 作者有亲身经历、情感经验饱满 | 加分项，不是保证 | 经验能带来细节和深切体验，但经验有深浅多寡，浮光掠影的体验可能还不如不体验 |
| 作者没经历过，全凭想象 | 也能写出真实 | 强大的"模拟能力"可以把情境、动机与细节推到经得起核对的程度 |
| 创作动机真诚，不为钱只为艺术 | 与作品真实无关 | 为钱写作同样可能写出好作品，关键看是否合乎艺术创作规律 |

## 读者经验与真实判定

### 参照系的分歧

* **同一作品，相反判断**

    * 现象：同一部作品，有人觉得好真实，有人觉得不真实；真实与否好像跟作品本身没关系，跟读者的个人经验有关系。

    * 参照系：读者参照自己的个人经验谈真实，个人经验受文化背景、知识结构等一系列背后东西制约。

    * 结论：真实感不是作品单方面的属性，而是读者的经验与作品相遇时产生的东西。

    * 边界：同一作品得到相反判断，不是作品长出了两副面孔，而是两套经验在替它作证。

* **《演员请就位》的争议**

    * 舞台内容：中学生谈恋爱，两人马上要亲上，底下观众起哄。

    * 李诚儒：天天就中学生谈恋爱、天天呈现这个，太廉价、太简单；他不接受这类青春片拿出来的东西。

    * 郭敬明：随后反驳，但听起来有点绕，没有在"真实性"上下工夫。

    * 判定来路：李诚儒说"不真实"，依据是自己对青春片、中学生恋爱、观众起哄这一整套东西的接受度；经验一变，"真实"判定就跟着变。

* **《鬼子来了》的日语**

    * 场合：日本学者讲座提问喜欢看什么电影，答《鬼子来了》。

    * 学者判断：这部电影不真实。

    * 理由：片中日本兵说的是太纯正的"日本普通话"；那个年代参战日本兵来自日本乡村，说话一定带脏字、口音、方言，而且方言很明显；电影里完全听不出来。

    * 成因：姜文可能很认真，找了很好的日本翻译把台词都译成日语，但忽略了说话人的身份与当时语境。

    * 结论：学者参照了我们无法获得的经验，所以判定不真实；我们没有这个参照，反而可能觉得很真实。

    * > **提示**：同一作品在不同文化、不同经验的人那里会被判成不同"真实度"，不是眼力高低，而是各自拿来核对的参照系不同。

### 真实标准的历史与文化差异

* **原始社会**

    * 真实不在逻辑的真实，也不在细节的真实，而在一种超验性的感受的真实。

    * 所以神话不追求逻辑，也不追求细节的真实。

* **科学主义时代**

    * 标准变为追求细致的、细节的真实。

    * 与原始社会的标准构成前后变化。

* **经验性规定**

    * 不同文化都有关于"真实"的经验性规定。

    * 判定真实与否，跟个人经验有很大关系。

## 形式与结构：文本的自足性

* **第三种维度**

    * 已有两方向：再现——再现外在的客观性、社会现实（向外）；表现——表现人的内心情感（向内）。

    * 第三种：形式与结构——文学呈现自身的形式和结构，与世界的外在现实、内心情感都没有直接关系。

    * 命题：这个世界，就是文本。

    * > **定义**：形式与结构维度把"世界"从外在现实和内心情感里挪开，直接等同于文本——作品不指涉别处，只呈现自己的形式与结构。

    * 文本的地位：文本本身是一个自足的小世界；文学为了呈现自身，不为呈现别的东西。

* **结构主义的共同观点**

    * 背景：与西方六十年代以来、尤其法国兴起的结构主义思潮密切相关。

    * 核心判断：文学作品具有内在的共通结构。

    * 提问方向：不问千差万别的作品"有什么不同"，而问这些样态底层是否有某种共通结构支撑。

    * 音乐类比：写歌到后来有乐理，不是随便唱什么都行；音乐为了呈现规则，懂规则就能按规则编出成百上千套音乐。

    * 类推问题：小说的"乐理"是什么。

## 小说套路与情节链

* **七要素套路**

    * 关键词：目标、阻碍、努力、结果、意外、转弯、结局。

    * 用途：不知从何下手时，按这套关键词搭骨架；主人公与目标可以随意更换。

    * 后续工作：不断丰富细节、丰富因果关系，故事就串出来了。

    * 规模判断：写小说、当编剧比较容易；好莱坞电影都有套路，可以像手工作坊生产商品一样一个个生产故事。

    * > **注意**：套路只能写成"看得过去"的故事，不能写出好故事；好故事需要天赋、机遇等各种因素。套路解决"能不能写出来"，不解决"写得好不好"。

* **《八十天环游地球》的七要素**

    * 意外的机理：向东走每越一个时区钟表拨快一小时，绕地球一圈累计多拨二十四小时，自己的日历比伦敦多一天；按伦敦日期减一天，实际只用了七十九天零五分钟。

    * 转弯的依据：不是新增事件，而是计时口径造成的错位——他以为输了，按伦敦日期其实赢了。

    * 七要素在这部小说里逐一对应如下表。

| 要素 | 对应情节 |
| :--- | :--- |
| 目标 | 福格以全部财产打赌，要在八十天内环游地球一圈 |
| 阻碍 | 被误认为强盗；因救人等善意举动耽误行程 |
| 努力 | 骑大象、抄捷径、搭火车，想尽办法追赶时间 |
| 结果 | 实际用了八十天零五分钟，超过期限，输掉赌局 |
| 意外 | 一路向东，日历比伦敦多一天，按伦敦算其实是七十九天零五分钟 |
| 转弯 | 他赢了这场比赛 |
| 结局 | 抱得美人归 |

* **因果链改写**

    * 目标相当于"因为"；阻碍相当于"但是"；努力和结果相当于"所以"；意外和转弯相当于"但是"；结局相当于"所以"。

    * 图示：

    ```text
       因为  ──→  但是  ──→  所以  ──→  但是  ──→  所以
       目标       阻碍      努力/结果     意外/转弯     结局
    ```

    * 结论：所有故事都是按因果关系排列出来的一系列情节。

## 叙事语法

* **叙事作品是一个大句子**

    * 核心判断：叙事作品是一个大句子。

    * 操作：不断简化作品，抽到最后是一个句子；这个句子按某种语法结构安排。

    * 规模换算：几十万字的小说，在结构主义者看来是一句话的展开。

    * 前提直觉：故事像一个句子，这不是独有的直觉，已有很多理论家发现。

* **罗兰·巴特**

    * 文献：《叙事作品结构分析导论》。

    * 主张：所有叙事作品都具有句子的性质，都像句子，只不过要分成几个层面。

    * 研究层级：分层问题更复杂，属于更高一层的研究。

* **托多罗夫**

    * 文献：《文学作品的分析》。

    * 主张：组成情节的最小单位是一个个叙述句；一个叙述句里有很多要素。

    * 例：X 是一个姑娘，Y 是 X 的母亲，Z 有一天抢走了 X。

    * 分析：X、Y、Z 是行动单元；"是""是……的母亲""抢走了"是谓语，谓语构成行动单元之间的关系。

    * 结构层级：整部作品（大句子）→ 叙述句（情节最小单位）→ 行动单元；行动单元之间靠谓语连接。

    * 结论：所有叙事作品都是语言单位，有成分、有语法；成分与语法的不同排列组合形成不同故事情节。

* **一句话压缩**

    * 《最后一课》：阿尔萨斯沦陷后，"我"听韩麦尔先生讲最后一节法语课。

    * 《故乡》："我"为接母亲搬家而返回故乡的过程。

    * 《西游记》：唐僧师徒战胜妖魔、西天取经。

    * 共同点：都能压成一句话。

    * > **易错点**：叙事语法分析仅限于概括，还没进入细致分析；把《西游记》压成一句话压得很准，但这句话不能告诉你小说是怎么组织起来的。概括是起点，不是终点。

## 普罗普：功能与角色

### 方法与四个例子

* **方法与发现**

    * 著作：《民间故事形态学》，1928 年出版。

    * 地位：二十世纪初俄国重要理论家，被誉为结构主义民间文艺的奠基人。

    * 材料：对一百个俄罗斯神奇故事、民间故事做比较分析；发现它们大同小异，总有相似处。

    * 数量结论：所有民间故事不超过三十一个固定功能，三十一个功能组成七个角色圈。

* **四个例子的同一骨架**

    * 四个故事的表层零件各不相同，骨架完全一样。

    * 差异：赠东西的人、赠的东西、负责把主人公带走的角色都不同。

    * 同一骨架：某人赠给主人公一件东西，这件东西把主人公带到另一个王国。

    * 一句话概括：故事换的是零件，不换的是结构。

| 赠者 | 受赠者 | 赠物 | 负责带走主人公者 |
| :--- | :--- | :--- | :--- |
| 沙皇 | 好汉 | 鹰 | 鹰 |
| 老人 | 苏森科 | 马 | 马 |
| 巫师 | 伊万 | 小船 | 小船 |
| 公主 | 伊万 | 指环 | 指环里出来的英俊青年 |

### 七个角色

* **角色表**

    * 三十一个功能组成七个角色圈，七个角色如下表。

| 角色 | 一句话定位 |
| :--- | :--- |
| 对手 | 加害者、追捕者 |
| 赠与者 | 提供者，把宝物交给主人公 |
| 相助者 | 帮手，助主人公完成艰难任务 |
| 公主 | 要找的那个人 |
| 派遣者 | 派任务的那个人 |
| 主人公 | 行动的主体 |
| 假冒主人公 | 冒名顶替的假英雄 |

* **对手与赠与者**

    * 对手：加害者、追捕者；扩大后暗示破坏社会安宁的要素。

    * 对手的现代形态：可能不是人，而是险恶、异化的环境，或某个人内心的心理创伤。

    * 赠与者：把宝物提供给主人公的人；民间故事里常有宝物交给主人公、主人公保管、不小心弄丢的场景。

    * 赠与者的常见形象：提供帮助的人，或山中高人——山中高人有一本武林秘籍，交给主人公。

* **相助者与公主**

    * 相助者：在主人公行动过程中承担重要角色，帮助完成艰难任务。

    * 好莱坞规律：相助者完成帮助任务后往往要死掉——不能太拖沓、不能成为拖累，死亡过程有很强的煽情作用。

    * 死亡人选：最爱提前死掉的往往是最无辜、最单纯的那个人，这样才让人觉得悲情。

    * 公主：要找的那个人、要找的对象。

* **派遣者、主人公与假冒主人公**

    * 派遣者：派遣任务的人，背后是某种社会的象征。

    * 主人公：行动的主体；有时派遣者与主人公是同一人——任务自己发出，也由自己行动。

    * 假冒主人公：冒名顶替的假英雄；《西游记》真假孙悟空，《水浒传》李逵与李鬼；作用是一路上闹出笑话、有意思。

    * > **易错点**：这套东西只做出了归类，有人觉得不错，有人觉得不够；尤其"假冒主人公"显然不符合现代——不是所有作品都有假冒主人公。

## 格雷马斯：行动元与符号矩阵

### 六个行动元

* **从七角色到六行动元**

    * 著作：《结构语义学》；法国结构主义理论家，其结构语义学是研究文学的人常要谈到、甚至必须用到的理论。

    * 六元：主体、客体、发送者、接收者、辅助者、反对者。

    * 结构位置：

    ```text
    发送者（派遣者） ──→ 客体（公主/目标） ←── 接收者（受益者）
                          ↑
                          │
    辅助者（相助者） ──→ 主体（主人公） ←── 反对者（对手）
    ```

    * 读图：上面一行是"任务—对象—受益"这条线，下面一行是"推动—行动—阻挡"这条线。

    * 主体追求客体；发送者把任务和意义赋予客体，接收者最终受领它；辅助者在下面推着主体，反对者在对面挡着。

    * 与普罗普对照：几乎是一个翻版；不对应处是接收者与赠与者，取消项是假冒主人公。

    * 取消理由：假冒主人公可以归纳到其他类别当中去。

    * 核心判断：几乎任何作品、任何文学作品里的人物形象或情节单元，几乎都逃不出这六个行动元。

    * 边界：不是所有作品每个角色都齐备；但只要有，都可以划归到这六类。

| 普罗普的七个角色 | 格雷马斯的六个行动元 |
| :--- | :--- |
| 主人公 | 主体 |
| 公主（要找的人） | 客体 |
| 对手 | 反对者 |
| 相助者 | 辅助者 |
| 派遣者 | 发送者 |
| 赠与者 | 接收者（对不太上） |
| 假冒主人公 | 取消 |

* **《我不是药神》**

    * 主体：程勇，主人公。

    * 客体：拯救白血病人——白血病人就是他的客体。

    * 发送者：吕受益——"我这有药，你想不想赚钱？想赚钱，你来帮我拿这个药"，任务由他递给程勇。

    * 辅助者：黄毛、老头等一系列帮手。

    * 接收者：白血病人。

    * 反对者：卖假药的，以及挡在他前面的对立力量。

    * 结论：作品里所有人物形象都能归到这几个类型；格雷马斯把结构化约到最简单、最底层。

### 符号矩阵

* **四格结构**

    * > **定义**：用 x、反 x、非 x、非反 x 四个位置组成的二项对立结构，把作品的人物关系与情节关系全部放进这四个格子。

    * 类比：像中学的原命题、逆命题、否命题、逆否命题（这里谈的不是命题）。

    * 来源：六个行动元本身有二元对立——主体/客体、发送者/接收者、辅助者/反对者；把二项对立再抽象一次，得到这个结构模式。

    * 用法：以矩阵为圆心分析作品；所有人物关系、情节关系都可以放进二项对立。

    * 图示：

    ```text
            x ─────────────── 反 x
            │ ╲                │
            │   ╲              │
            │     ╲            │
            │       ╲          │
            │         ╲        │
          非 x ─────────────── 非反 x
    ```

* **《老人与海》填格**

    * 作品：海明威著名的中短篇，他恰恰因为这部小说获得诺贝尔奖。

    * 要素：老人、海、马林鱼（不是鲨鱼；鲨鱼跟海差不多）、上岸后的一群其他人（游客、一个小孩等），后一类统称"他人"。

    * 填格见下表。

| 矩阵位置 | 填入的要素 |
| :--- | :--- |
| x | 老人 |
| 反 x | 他人 |
| 非 x | 马林鱼（老人的对象） |
| 非反 x | 大海 |

* **三层意义**

    * 老人与他人：个体与群体。老人八十四天没打到鱼，仍出海，是自我证明；自我证明更重要地来自他人——他人形成权力话语，社会评价、肯定或否定决定个体地位与价值。

    * 老人与鱼：斗争、杀戮；背后是人与自然的关系，强调斗争与杀戮、胜者为王、优胜劣汰；老人凭多年技巧打到鱼。

    * 老人与大海：大海象征某种绝对的自然；打到鱼却只剩一副鱼骨头，个体在大自然面前无助、渺小；时间冲刷之下，一切努力消失得无影无踪。

    * 三层归纳：个体与群体（自我确证）；人与自然（优胜劣汰、杀戮，没有绝对强者）；人与海（时间意义→人生价值：做这些事值得吗、有意义吗）。

* **失败还是胜利**

    * 表面：人与自然斗争中可能是失败者。

    * 时间意义：绝对是失败者，没带回任何有用的东西。

    * 升华：正因如此，老人升华了自己的意义；他根本不在乎物质上的纯粹获得或失去。

    * 落点：问题最后落在"胜利之后"的态度。

### 文学研究科学化的追求

* **动因**

    * 现实问题：同一部作品，不同读者各有各的解读；有争议时，谁也说不清谁一定对、谁一定错。

    * 方案：把文学研究科学化，按一个个程序化步骤解读作品。

* **五步流程**

    * 列要素 → 放进矩阵 → 找对立关系 → 从对立关系里抽离出意义 → 用这个意义解读作品的深层含义。

    * 效果：五步走完，作品的"意义"被生产出来，不再依赖读者各自的感受。

    * 目的：文学研究不要太主观化；给文学研究一整套科学方法，才叫研究、才显得科学。

    * 范围：这是整个格雷马斯式结构主义背后探寻的目的。

* **有效性与局限**

    * 有效：网上搜"格雷马斯"分析中国古代作品（《红楼梦》、鲁迅作品）特别多；基本模式是论文里都画一个框。

    * 专业标志：分析作品时先画一个矩阵，这是非专业的人不懂的，然后再去谈要素之间的关系。

    * 局限：容易太僵化、太死板；难道所有作品都只有这四个要素吗。

    * 变体：也有人把这个方法发挥出新的模式。
