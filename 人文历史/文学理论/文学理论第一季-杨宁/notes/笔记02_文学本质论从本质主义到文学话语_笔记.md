# 文学本质论：从本质主义到文学话语

## 文学本质作为元问题

* **文学理论的五个研究方面**

    * 文学本质论、文学活动论、文学创作论、文学文本论、文学接受论，由文学四要素（世界、作家、作品、读者）推出。

    * 后四者与四要素逐项对应，本质论是超出的、更哲学化的一支。

    | 研究方面 | 对应的四要素 |
    | :--- | :--- |
    | 文学本质论 | 不直接对应任何一项，追问“文学是什么” |
    | 文学活动论 | 世界 |
    | 文学创作论 | 作家 |
    | 文学文本论 | 作品 |
    | 文学接受论 | 读者 |

* **元问题（meta-question）**

    * > **定义**：最基本、最根本的问题；哲学中的“人是什么”“美是什么”“自由是什么”都属此类。

    * “文学是什么”是文学理论中的哲学元问题，具体化为“文学与非文学的界限在哪里”。

    * 难处在于：人人都在用这个词、都能辨认实例，却无法用一句话给出定义。

* **边界追问的实例链**

    | 例子 | 第一反应 | 追问后松动之处 |
    | :--- | :--- | :--- |
    | 《红楼梦》《三国演义》 | 算 | 几乎无争议 |
    | 《史记》 | 有人说算，有人犹豫 | 它是史书，记的是历史 |
    | 《三国志》 | 疑惑更大 | 与《三国演义》的差别只在“更真实” |
    | 《论语》 | 本能觉得算 | 说是“先秦诸子散文”，本质却是课堂笔记 |
    | 新闻报道、讲课记录 | 说不清 | 算不算取决于“怎么写”，不取决于文体 |

* **争议背后的两个硬问题**

    * 文学是否必须虚构：把《史记》《三国志》挡在门外的那条理由，正是“记载真实的不算文学”这一预设。

    * 是谁把它读成了文学：同一文本算不算文学，取决于读者的读法，而不只取决于文体归属。

    * 《论语》是孔子弟子及再传弟子记录孔子言行的书，实质是课堂笔记；若课堂笔记算文学，则学生听课所记的笔记也成了文学创作。

## 本质主义与反本质主义

### 本质与反本质

* **本质主义（essentialism）**

    * > **定义**：认为现象背后有本质；本质是一个事物存在的根据，是它区别于其他事物的特性。

    * 例证逻辑：苹果与梨同属水果而彼此不同，因为各自具备使其成为该类的那组特征；生物学分类即按此运作。

    * 日常形态：见彩虹追问光的折射，见母亲催穿秋裤读出“怕你着凉”的关怀。

* **反本质主义（anti-essentialism）**

    * > **定义**：认为现象背后没有本质，事物只有现象。

    * 比喻：追问本质如同剥洋葱，一层层剥下去，最后什么都没有。

    * 文学上的操作：先列诗的特征（押韵、形象性修辞、表达思想、简短分行），再逐条挑衅；梨花体只保留“分行”仍被认作诗。

    * 推论：只要把它读成诗它就是诗，只要把作品读成文学它就是文学——看似“没有本质，看谁来读”。

* **梨花体**

    * 作者赵丽华。《一个人来到田纳西》：“毫无疑问／我做的馅饼／是全天下／最好吃的”。

    * 《我坚决不能容忍》：“我坚决不能容忍／那些／在公共场所／的卫生间／大便后／不冲刷／便池／的人”。

    * 作者身份为国家一级作家、鲁迅文学奖评委、曾任《诗刊》编辑部主任，说明文学界确实把这类文本认作诗。

### 反本质与无本质

* **反本质主义的真正所指**

    * 反掉的是“用一句话概括出来的、教条化的本质”，不是“使某物成为某物的根据”。

    * 审美判断因人而异，但“他为什么读成了、为什么没读成”这个原因仍然存在，那个原因就是本质。

    * 追问方向由此确定：不是给文学下定义，而是找“使得你认为它是文学的那个原因”。

* **一句话概括的破产**

    * 任何教材都在试图用一句话概括文学本质，但每一家的概括都有漏洞，稍加推敲即崩塌。

    * 结论：文学本质绝不是用“一言以蔽之”能够概括的。

* > **易错点**：把“反本质主义”直接读成“没有本质”。它否掉的是教条化的定义，不是事物成立的根据；两层一混，“文学性”就无从谈起。

### 文学性

* **文学性（literariness）**

    * > **定义**：使一部作品成为文学的特性，是一个作品存在的根据；由俄国形式主义者雅各布森提出。

    * 它把“文学是什么”的追问，从给文学下定义，转为找那个让文本变成文学的特性。

* **“怎么写”作为判定位置**

    * 新闻报道本身不决定它是不是文学，决定权在写的人怎么写。

    * 报告文学本质上都在记事，却可以写得让人读来如小说；同一件事，枯燥或津津有味取决于写法。

## 文学作品的存在方式

* **观念性存在**

    * > **定义**：文学作品是精神性的、观念性的存在，不是物质性的存在。

    * 思想实验：烧掉全世界的《红楼梦》的书、删掉电子文本与影像，作品仍在——被销毁的只是载体。

    * 剧本不必印成纸：打在电脑里存在，只在脑中想好每个字、每个情节也存在。

    * 由此确定讨论层面：文学性不能到物质层面上去找，物质载体不构成文学。

* **载体与作品的关系**

    ```text
    物质载体层：书、纸张、硬盘、屏幕
            │
            │  全部销毁
            ▼
    观念性的作品本身
            │
            │  不随载体消失
            ▼
          依然存在
    ```

* **口头文学**

    * 《诗经》的流传是口传心授，背下来传给下一人，没有任何物质存在方式。

    * 存在方式的判定先于文学性的讨论：先确认作品不在纸上，才谈得上在语言、情感、虚构里找文学性。

## 审美维度：真、善、美

### 审美文化

* **文学作为文化的一部分**

    * 文学是文化的一部分，中国与西方皆然；先秦时诗、音乐、舞蹈合一。

    * 《诗经》不只是词，可以唱，也可能可以跳；当时人没有“这是音乐”“这是舞蹈”“这是歌词”的分野。

* **审美性的位置**

    * 文学性的重要特征在于它是审美的，具有审美性。

    * 审美与真、善并列，是人类把握世界的三种方式；文学被定在美上，不定义在真上，也不定义在善上。

### 文学与真

* **真实感而非真实**

    * > **定义**：文学追求的是真实感，不是与事实相符的真实；事情可以是编的，只要编得像真的。

    * 《三国志》比《三国演义》更符合史实，但给孩子讲三国人物仍选《三国演义》，因为《三国志》没意思。

    * 以史学求真态度讲三国（曹操才代表历史发展方向、草船借箭无此事、空城计原为张飞所使），并未改变人们继续读《三国演义》。

    * 读者要的是刘关张的义气、诸葛亮不损一兵退敌的爽感，不是史实核对。

* **作文课的真实误区**

    * “雨中送伞”“生病发烧吃药”写得再真，仍会被判“不真实”，因为题材被写烂。

    * 判准不在事情是否发生过，而在写出来是否让人信。

### 文学与善

* **不以善为最高目的**

    * 结论：文学往往不以善为最高目的，而以美为最高目的。

    * 名著主人公大量不合道德：《安娜·卡列尼娜》的出轨者被同情；《麦田里的守望者》的逃学少年在美国被禁；《洛丽塔》的亨伯特恋童加乱伦仍是世界名著。

    * 原因：读者在小说里被允许体验现实中受道德约束而无法体验的本能欲望。

* **林黛玉与薛宝钗**

    | 比较项 | 林黛玉 | 薛宝钗 |
    | :--- | :--- | :--- |
    | 选班长选谁 | 不选 | 都选 |
    | 原因 | “作”：喜欢谁就百分之百好，不喜欢谁就百分之百不好 | 对谁都好，看不出喜恶 |
    | 审美上的位置 | 更高 | 较低 |
    | 成因 | 体现了人性的光辉 | 被文明规训，太“文明”而近于虚伪 |

    * 林黛玉的“作”在生活上不得体，在美学上却是人性的光辉：她的好恶不打折扣。

    * 薛宝钗是封建传统文化教育出的集大成者，礼数周全到让人感到“你所说的只是教育让你说的”。

    * 文明始于压制本能：从看见姑娘就抢，到“关关雎鸠，在河之洲，窈窕淑女，君子好逑”而辗转反侧不去抢，就是文明的开端；压抑过度则近于虚伪。

### 美作为最高目的

* **美是本能需求**

    * 一个人可以不求真、不求善，但必须求美；美是人的最本能的需求，也是人光辉的体现。

    * 文学的审美本质使这一专业最接近人性。

* **审美与道德的错位**

    * 生活上更愿意选薛宝钗、与她交朋友，美学上却公认林黛玉价值更高。

    * 这个矛盾是《红楼梦》的核心矛盾之一：它塑造了一个美学上的好人，一个在生活上可能不得体的人。

## 审美态度与美的本质

### 无功利与三种态度

* **朱光潜《谈美》的三种人**

    * 科学家看古松：追问属什么门、纲、目——求真的态度。

    * 木商看古松：算能出多少木材、卖多少钱——实用的态度。

    * 画家看古松：把它画下来，静静看——审美的态度。

    * 分水岭：前两者都想把木头为我所用，画家不占有、不利用、不折算价格。

* **无功利（disinterestedness）**

    * > **定义**：把对象从实用目的里摘出来看；面对对象时不追问它对我有什么用处，也不把它折算成别的东西。

    * 桂林竹排的船夫天天守着山水却不觉得美，因为山水对他是“靠山吃山、靠水吃水”的收入来源；游客没有利害关系，才看见美。

    * “距离产生美”不成立：非洲、中东距离更远，未必觉得美；真正起作用的是与实用性之间的距离。

### 无目的与合目的

* **康德《判断力批判》的四个契机**

    * 契机即关于美的四个方面的定义；此处讲前两个。

    * 第一个：美是无目的的合目的性。

* **命题拆解**

    * “无目的”＝没有功利性，不先想它为我所用。

    * “合目的”＝审美仍满足人的某种需要：去欣赏一幅画、看电影打发时间，都是目的，只是比卖钱、研究更精神性、更高级。

    * 结论：审美不服务于低级功利，却服务于人的精神需要；两句说的是同一件事的两面。

### 无概念而具有普遍性

* **三个判断的分野**

    | 判断 | 属于什么 | 是否要求别人也认同 |
    | :--- | :--- | :--- |
    | 这个水瓶是透明的 | 客观事实判断，几乎不带主观性 | 要求，靠感官都正常 |
    | 这个水瓶是凉的 | 主观感受 | 不要求，你觉得热就热 |
    | 这个水瓶是美的 | 主观感受，却带着普遍性的要求 | 要求，而且很强烈 |

* **命题含义**

    * 美无法像物理、数学概念那样定义，所以不是概念；但它又要求普遍性，要求所有人都同意。

    * 概念本身带普遍性，美不是概念却要求普遍性，两面都占，是康德辩证之处。

* **审美争论的代价**

    * 审美品位是一个人从出生到现在全部经历的总和建构的；否定一个人的审美，等于否定他前半生的全部经历。

    * 美没有绝对标准，争论必然升级，故聊天时不轻易否定别人的审美。

### 美学与审美的分界

* **两个概念**

    * > **定义**：美学是一个学科；审美是人的一种活动。美学是研究审美活动的学科。

    * 六个人逛商场不约而同看中同一件衣服，这是审美活动，尚未构成美学问题。

    * 回宿舍后追问“没有事先约定，为什么不约而同认为它漂亮”，这才成为美学问题。

* **美是客观还是主观**

    * 客观论：那件衣服本身真的漂亮，美在客观事物身上。

    * 主观论：几个人三观一致，换个群体可能觉得不美，美是主观的。

* > **易错点**：把“美学”当成“审美”。觉得衣服好看是经验，追问“为什么不约而同觉得好看”才是学科对象。

### 美是人的本质力量的对象化

* **本质力量**

    * > **定义**：人之所以区别于其他动物的那些品质。

    * 证明人类伟大不能靠喊，要靠造房屋、造器物这类做出来的事；艺术作品、文学作品都是人的本质力量的对象化。

* **黑格尔的打水漂**

    * 小男孩甩石片，看它在水面一跳一跳而获得审美享受，享受的是“我能把水漂打出花来”这个能力。

    * 能力无法自证，必须借外在客观事物呈现；人创造艺术作品同理，表面在表达，实则在欣赏自己。

    * 看画觉得伟大，欣赏的是“人能画出这样的画”这一本质力量的对象化。

### 美是理念的感性显现

* **柏拉图的理念（eidos，亦译理式）**

    * 洞喻：囚徒自出生被绑在山洞，面朝墙壁、背朝洞口，只见墙上影子，便把影子当作真实；一人松绑出洞，先找自己的影子，很久才明白影子只是投影。

    * 猫的实验：猫被关十年，每天十点从小孔送食，便认定“十点掉食物”是客观必然规律；人认定太阳东升西落为必然，同理可疑。

    * 二分世界：现象世界／现象背后的本质（理念世界）；墙上影子是更次一层的摹本。

* **感性显现**

    * 理念本身看不见，唯有美能让理念以感性方式显现。

    * 画鸡蛋求神似不求形似：画某个具体鸡蛋越像，离理念越远；画的是人脑中“鸡蛋”的理念，才符合审美。

    * 小说写的是编造的故事却让人有代入感，因为它符合某种日常生活规律，那个规律就是理念。

* 结论：好小说反映规律、反映社会本质；具体某一家的事产生不了共鸣，能共鸣的是理念性的东西。

## 语言符号维度

### 审美维度的局限

* **只分艺术与非艺术**

    * “文学是审美的”只能把艺术与非艺术分开；音乐、绘画、雕塑同样具有审美性。

    * 要区分文学与其他艺术门类，必须找媒介差异。

* **媒介差异**

    * 文学通过语言，音乐通过音符，绘画通过图像。

    * 它们都有审美性，但只有文学具有语言特性；语言符号由此成为文学性的第二个维度。

### 索绪尔的三对概念

* **索绪尔（Ferdinand de Saussure）与《普通语言学教程》**

    * 瑞士语言学家；该书由课堂讲义汇编而成，非亲笔。

    * 全书用二项对立方式展开，成对概念是研究语言入门的思维方式。

    * 三对最要紧：能指与所指、语言与言语、组合与聚合；另有历时与共时。

* **能指与所指（signifier / signified）**

    * > **定义**：能指是符号本身；所指是符号的指称对象。

    * “红”这个字是能指，它指的颜色是所指；红灯的红色是能指，“停”是所指；book 是能指，手里的书是所指。

    * 二者无逻辑必然关系，具有任意性；成立前提是约定俗成，学语言就是建立这种联系。

* **语言与言语（langue / parole）**

    * > **定义**：语言是词汇系统、语法系统，是一整套规则；言语是日常的、个体的语言活动。

    * 说出的每句话都是言语，能被听懂是因为符合语法规则，那套规则就是语言。

    * 两者是抽象与一般的关系。

* **组合与聚合（syntagmatic / paradigmatic）**

    * > **定义**：组合是横向的句段关系；聚合是纵向的联想关系。

    * 以“我读书”为例：

    | 关系 | 主语位置 | 谓语位置 | 宾语位置 |
    | :--- | :--- | :--- | :--- |
    | 组合（横向，句段关系） | 我 | 读 | 书 |
    | 聚合（纵向，联想关系） | 你、他、众人 | 看、写、撕 | 诗、报、画 |

    * 横向连起来成句是组合，纵向每列可替换、彼此引起联想是聚合；一句话摊开就是一个坐标。

### 二级符号系统

* **罗兰·巴特（Roland Barthes）《神话学》**

    * > **定义**：能指与所指的对应只是一级符号系统；整个一级系统可以再充当一个新的能指，指向新的所指，构成二级符号系统。

    * 一级：玫瑰（词或那朵花）→ 带刺、有香味的花。

    * 二级：（“玫瑰”＋那朵花）→ 爱情。

    * 一级符号指物，二级符号指文化含义；文化正是在二级系统里进来的。

* **文化的规定性**

    * “梅花”一出口，反应的不是一种花，而是品格与精神；梅兰竹菊皆然。

    * “姑娘”不只是“年轻女性”，还隐含单纯、善良、漂亮等潜台词。

    * 能指与所指的对应在特定历史时期有特定文化对应；电影《风》结尾男孩抱女孩尸体走向夕阳，在当时语境中被读出了清晰的政治含义。

### 汉语符号的两套系统

* **语音与文字分立**

    * 西方语音与文字一体，看文字即可读出；汉语不然，语音与文字是两套系统，由此构建了一整套符号网络。

    * 甲骨文一个字可表示“一个女人出门被毒蛇咬死了”，只有符号，没有读音。

    * 无读音的符号大量存在：“招财进宝”合体字；陕西 biángbiáng 面的字字典无正式发音，biáng 是后人凑出的读音。

    * 文言文与口语分离：《红楼梦》《水浒传》基本代表古代口语水平，可见古人写一套、说一套。

* **符号意义的叠加**

    * “菊”的层积：屈原“朝饮木兰之坠露兮，夕餐秋菊之落英”赋予高尚品格；陶渊明“采菊东篱下，悠然见南山”赋予隐士品格；孟浩然“待到重阳日，还来就菊花”使其成为秋天与重阳的象征；杜甫“丛菊两开他日泪，孤舟一系故园心”带上岁月之感；黄巢“满城尽带黄金甲”生出冲天杀气；明代梅兰竹菊并称四君子。

    * 罗兰·巴特：语言是符号编织的一张网络，所有符号的意义都极深。

* **唐后无典**

    * 盛唐诗歌极盛，靠的是每个符号的表现力都极强；唐以后诗衰，不是创造力衰落，而是文化符号叠加到难以承受的程度。

    * 故说“唐后无典”：唐朝以后的典故不宜再用，再用诗就没法读了。

### 语言即世界

* **无主题的诗**

    * 李商隐《锦瑟》、杜甫《秋兴八首》一类作品主题不明确，仍为名作。

    * 中学“懂得音韵美就够了”的讲法不足以说明问题。

* **符号丛林**

    * 语言是符号的丛林、一个世界；诗人与读者进入其中即可流连忘返，美感不必来自主题。

    * 主题本身没有那么重要，文学的美感并不完全来自主题。

## 话语

### 话语的提出

* **福柯（Michel Foucault）**

    * 二十世纪影响最大的人文学者之一，据说也是被引用最多的人文学者；研究不分学科，文学、哲学、社会学、法学、经济学都会涉及。

    * 著作：《疯癫与文明》《规训与惩罚》《知识考古学》《词与物》《性史》。

    * 研究对象偏边缘：精神病、同性恋、监狱。

* **精神病作为权力的划界**

    * 问题：历朝历代区分正常人与精神病人的界限是否始终如一？若在变，“精神病”是医学概念还是权力的规定物？

    * 福柯的答案：精神病是区隔人的一种方式；社会必须先确定一拨“不正常的人”，才能确认自己是正常的。

    * 标准历朝历代都在变，正因它在变，说明它是权力与规训，不是病。

* **全景敞视（panopticon）**

    * 边沁从功利主义出发提出。走廊式监狱需狱警来回巡逻，走到这头那头闹，监视成本极高。

    * 圆形监狱：中央一座塔，牢房围在四周；塔里放三个狱警即可让全部犯人自我表现良好。

    * 关键在于单向玻璃：里面看得见外面，外面看不见里面；狱警即便在睡觉，犯人因不知道何时被看而自我约束。

    * 福柯称之为现代性的微观权力：马路监控探头哪怕是假的、坏的，司机照样守规矩；教室的空间安排（学生在下、教师在上、讲台更高）本身意味着话语权。

* **两种监狱的空间**

    ```text
    走廊式：牢房沿走廊排开，狱警来回巡逻
    ┌────┬────┬────┬────┐
    │ 1  │ 2  │ 3  │ 4  │
    ├────┼────┼────┼────┤
    │ 5  │ 6  │ 7  │ 8  │
    └────┴────┴────┴────┘

    全景敞视：中央一座塔，牢房围在四周
       ┌───────────────────┐
       │  C    C    C    C │
       │    ┌─────────┐    │
       │ C  │    T    │  C │
       │    └─────────┘    │
       │  C    C    C    C │
       └───────────────────┘

    C = 牢房    T = 中央监视塔
    ```

### 话语的构成

* **话语（discourse）**

    * > **定义**：语言是交际工具；话语大于语言，是语言的社会存在形态。

    * 同一句“你得癌症了”：宿舍同学说出，答“你才有病”；医生说出，就信。字面一字未变，意义完全不同。

    * 语言的意义不仅由字面决定，还由语境、说话人与受话人的身份地位等外在因素决定，这些总和就是话语。

* **五个层面**

    * 说话人（身份、地位、态度，含语气表情）、受话人（身份、期待）、文本、沟通（双方意图与期待）、语境（场合、氛围、身份、规则，贯穿各环节）。

    * 只有“文本”这一层是语言本身，其余四层都在语言之外，而语言之外的东西对意义起决定作用。

    * 结论：研究语言最好进入话语层面，才能精准把握。

* **祥林嫂的“你放着吧”**

    * 鲁迅写祥林嫂不写她如何被打，而写她想干活而不得；捐门槛后刚搬东西，别人一句轻柔的“你放着吧”成了压死她的最后一根稻草。

    * 同一句话，寒假回家拖地时父亲说出，是让你清闲；对祥林嫂则意味着“想当奴隶而不得”。

    * 字面相同而意义相反，证明语境对话语意义的决定作用。

* **“你真的很努力了”**

    * 只强调过程而不说结果，事情做完后这样评价往往不是好话。

    * 高考完、爱情结束后听到这句话都别扭，因为听者会追问“那后来呢”。

## 陌生化与细节

### 自动化与陌生化

* **陌生化（defamiliarization）**

    * > **定义**：把熟悉的东西变得陌生，使对象重新被“感觉到”，而不只是被“知道”；提出者为俄国形式主义者什克洛夫斯基。

    * 对立面是自动化：日常语言以传达信息为目的，要求要点清楚、语言简练，不用比喻与排比。

* **两株枣树**

    * 日常语言：“我家门前有两棵枣树。”文学语言：“我家门前有两棵树，一株是枣树，另一株也是枣树。”

    * 后者拉长了感受的时间与长度，使人像第一次看见这个场景，并带出阴冷、冷峻的感受。

    * 同类仿写：“我的家乡风很大，一年刮两次，一次刮六个月”，比“一年四季都刮风”多出感受的难度与复杂度。

* **感受的时间与难度**

    * 文学语言故意设置阻碍，让读者多揣摩一层，文学性由此达到。

    * 文学传递感受，不传递信息结果；门前有两棵树这个结果不重要，那种阴冷感才重要。

    * 同一块石头，常人只说“这儿有块石头”，作家看到纹理、红色的变化与像什么，写出来便让人有初次见到的新鲜与冲击。

* **“打得表嵌入腕中”**

    * “打得鼻青脸肿”是自动化表达，听者脑中不出现具象。

    * 徐志摩记学生冲进张宗祥家打人，写“打得表嵌入腕中”，一块表被打进手腕，感觉立刻清晰。

    * 陌生感产生感受，感受因此传递得更清楚。

### 一切艺术的共同本质

* **音乐**

    * 音乐本质上是对说话的模仿，歌唱艺术就是对人说话的模仿。

    * 办法是不好好说话：把声音拉长或缩短，再带上节奏，有节奏地说话就成了说唱。

* **舞蹈**

    * 舞蹈是对人走路的陌生化：走路本是正常走路，舞蹈偏不这么走。

    * 扭动肢体、不断变化，走路被变得陌生，于是有了舞蹈。

* **共同公式**

    * 所有艺术的本质都是把熟悉的东西变得陌生，陌生化之后要增加感受。

    * 这句话往下推一步落到文学：文学传递感受，传递感受靠描绘细节。

### 细节与敏感

* **细节作为看家本领**

    * 结论：想当作家，首先要训练的不是修辞手法与人生阅历，而是想象细节的能力。

    * 一吨黄金的思想实验：搬不走要叫人（败露）→ 需切割机（买时不能让人知道、不会操作、机器可能搬不动）→ 切成小块搬回（一吨黄金家里放不下、藏在何处）→ 变现（一吨黄金抛入市场会冲击经济、被发现）。

    * 能把过程中一点点细节像亲历一样想到，好小说就诞生了。

* **形象思维与抽象思维**

    * 太聪明的人不太适合写小说，因为聪明人上来就想结果，不愿想细节。

    * 小说家用形象性思维，聪明人常用抽象性思维。

* **一滴蓝墨水与一泡尿渍**

    * 为写《敌后武工队》到华北晋察冀（河北保定一带）搜集史实，听到真事：日军扫荡杀光一家人，起因是墙角一滴蓝墨水——钢笔质量差要甩，甩到墙上，说明家有识文断字之人，说不出是谁，一家没了。

    * 剧中改编：汉奸见妇女衣上有钢笔水，跟回家；搜不到人，却在灶房角落看到位置偏高的尿渍。

    * 河北农村男人可到后院甚至大街方便，女人一般在家，故灶房出现男人尿渍，说明这男人不能见人。

    * 从细节写起，故事才惊心动魄；抗日神剧的毛病是凭观念胡编，不进入日常细节。

* **敏感度的形态**

    * 《半生缘》：顾曼桢与沈世钧相爱而受阻；顾曼璐靠舞女工作养家，嫁祝鸿才后为拴住丈夫设局让祝鸿才强暴妹妹；沈世钧被挡回南京，两人断了联系；顾曼桢生下孩子后逃出，顾曼璐病逝，祝鸿才破产，她为孩子回到最恨的男人家里。

    * 两句话：“我本来以为，我跟姐姐是不一样的人，但是没有想到，我只是比她慢了一步。”“我发现，一直恨一个人，就像一直爱一个人一样，一样的难。”

    * 收束细节：多年后打通电话，顾曼桢全程笑着说自己过得好；挂掉电话后“嘴唇粘到了牙龈上”——假笑到嘴干才会如此。

    * 判断标准：不是抒情、不是议论，而是把一个别人看不见、也不会去记的身体反应写准。

* **其他细节样本**

    * 不识字的情侣读信：她让人念“我想你”“我爱你”，再问这几个字怎么写，看着不认识的弯曲线条流泪。

    * 《最后的诊断》：士兵腿已截肢，说“我这条腿有点痒，帮我挠一下”；医生找到锯下的腿挠了一挠。

## 文学语言与日常语言的对照

### 九组对照

| 对照维度 | 文学语言 | 日常语言 |
| :--- | :--- | :--- |
| 与熟悉的关系 | 陌生化 | 自动化 |
| 与事实的关系 | 非指涉性 | 指涉性，一一对应 |
| 意义的形态 | 多义性 | 确定性 |
| 真伪 | 虚拟性 | 现实性 |
| 目的 | 重情感表现 | 重信息传递 |
| 指向 | 内指性，指向人的内心 | 外指性 |
| 感受 | 可感性 | 非可感性 |
| 深度 | 有深度，含义复杂 | 没有深度，没有复杂含义 |
| 生命力 | 生成性 | 惰性 |

* **逐组要义**

    * 自动化是陌生化的反面：日常语言用久了，听见了却没真正听见，所以文学要把它重新变陌生。

    * 内指与外指由情感表现推出：指向情感，故指向人的内心。

    * 可感与非可感由“文学传递感受”直接推出。

    * 深度：文学语言因多义而有深度；班长发的通知没有复杂含义可挖。

    * 生成与惰性是深度的延伸：多义故能生成，日常语言是惰性的。

* **对照的来源与用法**

    * 九组标签来自不同文学理论教材在区分这两个概念时给出的成对说法。

    * 这些轴可以继续往下补，补得越多，对文学语言的认识越深；认识文学语言，才谈得上认识文学性乃至文学本身。

### 旧定义的循环论证

* **被否掉的定义**

    * 早期教材常定义“文学语言就是文学家用来塑造艺术形象的语言”。

* **循环论证的症结**

    * 这等于说“文学语言就是文学的语言”，没有回答“塑造艺术形象的语言有什么特点”。

    * > **易错点**：把这类等价说法当成定义。它没有给出区别性特征，属循环论证。

### 三层答题骨架

* **目的层**

    * 日常语言以传达信息为目的，要点清楚、语言简练，故不靠修辞。

    * 文学语言以传递感受为目的，结果是次要的，感受才是要传达的东西。

* **形态层**

    * 日常语言是自动化的，“打得鼻青脸肿”是典型，脑中不产生形象。

    * 文学语言是陌生化的，“一株是枣树，另一株也是枣树”拉长感受的时间与难度。

* **手段层**

    * 增加感受的时间与难度靠描绘细节：一吨黄金要切割、要藏、要变现；一滴蓝墨水暴露一个识字的人；一泡位置偏高的尿渍暴露一个不能见人的男人。

    * 细节是文学把感受钉在具体事物上的办法。

## 非指涉性、多义性与拟陈述性

### 非指涉性

* **指涉性与非指涉性**

    * > **定义**：指涉性是一一对应，所说与事实对应；文学语言的非指涉性是在此过程中产生多义，即歧义；提出者为特里·伊格尔顿。

    * 日常语言不允许歧义，歧义即病句；文学语言往往就是要产生歧义。

* **一个西红柿的两种红**

    * “我想要一个最红最红的西红柿”——老板明白，能照着挑。

    * “我想要一个红得像我初恋一样的西红柿”——无对应物，老板无从下手。

    * 结论：文学语言的多义性分两层——语表的具体性（用具体形象呈现）与语里的多义性（含混）。

### 多义性

* **一首词的喜与愁**

    * 周晋《点绛唇·访牟存叟南漪钓隐》：“午梦初回，卷帘尽放春愁去。昼长无侣。自对黄鹂语。絮影蘋香，春在无人处。移舟去。未成新句。一砚梨花雨。”

    * 读愁：明写“春愁”，“卷帘尽放”用拟物（把愁当成可卷可放之物），“昼长无侣，自对黄鹂语”写孤寂，“春在无人处”写无人赏识。

    * 读喜：愁已放出去；无人说话却可与黄鹂说话；春色别人看不到而“我”看得到。

    * 基调是愁是喜没有标准答案；没有标准答案恰是文学语言指向多义而非确定的证据。

* **主题的多义**

    * 《红楼梦》：爱情故事？人生感慨与悲剧？四大家族没落与封建家族必然腐朽？都有道理，但也都不是。

    * 主题确定的作品往往不是好作品；好作品都不确定。多义带来琢磨，琢磨增加感受，感受增加才有通向伟大的可能。

    * 《老人与海》：情节是打到鱼、拖回只剩鱼骨头；成功还是失败两难——追求过程还是追求结果，作品因此通向伟大。

    * 《边城》：把小说当故事读就只剩“翠翠、两个男的、老大死了老二跑了”，而最美的点不在情节。

* > **易错点**：把多义当成“怎么解读都行”。多义是文本给足了指向不同理解的具体材料、几种读法都能在文本里找到落点；凭空编一个解读是另一回事。

### 两难结构

* **《赛鸽》**

    * 养鸽人养一千多只，年年参赛从未获奖；终于有一只天赋异禀，别的鸽子十天飞回，它八天就到。

    * 临近终点时受惊，飞回自家楼顶上空盘旋，不再向前；第一天怎么轰都没用，第二天仍在盘旋。

    * 作家的处理：养鸽人举起猎枪，对准这只鸽子，小说结束。

* **两难的分支**

    ```text
    举起猎枪，对准鸽子
    ├─ 开枪 ───→ 赢得比赛，失去鸽子
    └─ 不开枪 ─→ 留住鸽子，失去比赛
    ```

    * 两条路各得一半、各失一半，读者替他想哪条都觉得亏，纠结与焦虑被调动起来，这才叫好作品。

    * 提出“搬家”是解决问题的思维，会引向确定结局，不是小说家的思维。

### 拟陈述性

* **拟陈述性（pseudo-statement）**

    * > **定义**：文学语言是具有虚拟性的语言，无关真伪；它表现情感性的东西，不指向外在事实，而指向内在的心灵世界；提出者为瑞恰慈（I. A. Richards，英美新批评）。

    * 古诗词难欣赏的两种解释：入声字消失导致音韵美感流失；情境改变导致情感方式无法理解（高铁不卖站台票，已无法送别）。

    * 情境改变恰恰使读古诗词能补充今人没有的体会。

* **“更”字的力道**

    * 王维《送元二使安西》：“渭城朝雨浥轻尘，客舍青青柳色新。劝君更尽一杯酒，西出阳关无故人。”

    * 敬酒需要由头：“渭城朝雨”是天色好，“客舍青青柳色新”是柳色新；一杯接一杯都在找理由，因为真正想说的是“我不想分别”，却不愿点破。

    * 理由找尽才说“劝君更尽一杯酒”，最后点出“西出阳关无故人”；“更”字把“都知道、不想说、又不得不说”的力道全部托出。

    * 前两句写景不是闲笔，是为这个爆发做铺垫；诗歌里看似写景处，往往指向感情。

* **《江雪》的造境**

    * 柳宗元《江雪》：“千山鸟飞绝，万径人踪灭。孤舟蓑笠翁，独钓寒江雪。”

    * 这是一首造境之诗，没有观察者：诗人站在何处才能看到“千山鸟飞绝，万径人踪灭”？

    * 四句是层层隔绝：与外在世界隔绝、与人间世界隔绝、与整个空间隔绝，最后专注做一件事。

    * 若非要说主题，是“专注”，是一种隔绝外在世界的独享感；看似客观陈述，实为主观心情。

* 结论：看上去是客观陈述，事实上描绘主观心情；文学注重情感表现，日常语言注重准确。

### 情感表现

* **借雨说话的对白**

    * 徐志摩冲到林徽因家，四目相对无话，窗外下雨。

    * 林徽因：“下雨了，你该回去了。”徐志摩：“下雨了，再也回不去了。”

    * 两人都借“下雨”说自己的情感：一个拒绝，一个宣告情感已不可收回；平白语言指向内心，才是高手。

* **“我只是渴了”**

    * 女孩到男生家帮插花，生气后把插花的水喝下去；男生惊问，她答“没有啊，我只是渴了”。

    * 渴了为何喝这里的水、不去别处喝？暗含“我渴望你的关注，你却看不到我”。

* **一只水晶球**

    * 《泡在福尔马林里的时间》：家庭教师初到女学生家，环顾四周看到桌上水晶球，透过它看到伏案学生扭曲的脸。

    * 水晶球是最好的中介物，借环境直接透射人物精神状态。

    * 结论：环境描写不是瞎描写，能写到人物内心去的才是高手。

## 超越语言

### 言不尽意

* **先秦的命题**

    * 言不尽意最早由老子提出；庄子接着讲“得意忘言”，作了更细致的方法论解读。

    * 道家认为语言不重要，重要的是“意”——借语言要表达的思想感情与内容。

* **文论中的接续**

    * 陆机《文赋》开篇：“意不称物，文不逮意。”——心里想的配不上那个物，写出的文章又追不上心里想的。

    * 《文心雕龙》：“意翻空而易奇，言征实而难巧。”——意凌空翻飞故易出奇，言要落到实处故难精巧。

    * 比喻：建筑设计师可以天马行空，落到工程师手里要落实处，创意就要受限制、受阉割。

### 语言公共性与思想私人性

* **根本矛盾**

    * 语言是交流工具，谁都能用、谁用都明白，具有公共性与普遍性。

    * 思想是个人性、私人性的，每个人的经验都独特；私人经验经公共工具表达，必然受限。

    * 人利用语言，语言同时限制人的思维方式与表达。

* **跨文化与跨语言**

    * 文化冲突归根到底是语言冲突：表达方式、语法方式决定思维方式。

    * 比较文学中的跨文化，形而下地说就是跨语言：美英文化背景基本一致，美印差异极大，因为跨语言了。

### 自动化写作

* **布勒东与精神分析**

    * 自动化写作代表人物布勒东，理论基于弗洛伊德精神分析：意识下面还有潜意识，全部意识受潜意识推动。

    * 任务是把意识表层下的潜意识挖出来。

* **意识流小说**

    * 意识流写意识的流动：把脑中对某一片段的想象与想法毫不剪裁地记录下来。

    * 传统小说要剪裁、围绕主题；一剪裁就说明在有意识地规划，意识里的东西就漏掉了。

    * 代表作《墙上的斑点》《追忆逝水年华》；后者几乎无人能从头读到尾，因为实在无聊。

    * 目的不是供阅读，而是实验：小说能不能这么写。但一旦写出来仍要落实为语言，所以并未真正超越语言。

* **集体写诗**

    * 四十一人分两拨，一拨用“每当”开头，一拨用“就会”开头，各写一句短而稍带诗意的句子，逐句读出连成一首。

    * 效果例：“每当太阳升起的时候，就会想起漫天星斗”“每当我饿了，就会想到那些再也回不去的日子”。

    * 原理：用日常语言与传统方式写，想的都是别人想过的；打乱惯性、拼接跳跃，才可能凑出正常人想不出的句子。

    * 诗人往往“都是疯的”，因为跳跃性与联想不同于常人。

### 言外之路

* **中国人的做法**

    * 强调“言外”，指向象外、景外；呈现了什么形象不重要，言外的东西才重要。

    * 评判好诗不在说了什么，而在没说什么；没说的越多，诗越好。

    * 用有限的语言呈现无限的广阔空间，才叫好诗。

    * 理由：言永远不尽意；语言若只停留在能指所指的指称层面，诗就一般。

* **两条路子的差别**

    | 比较项 | 自动化写作 | 言外之路 |
    | :--- | :--- | :--- |
    | 对语言的态度 | 语言在限制意识，要把这层限制绕过去 | 承认言不尽意，不跟语言硬碰 |
    | 具体做法 | 取消剪裁，把潜意识直接倒出；或众人凑句，打乱惯性 | 经营言外，以有限之象指向无限之境 |
    | 常见例子 | 意识流小说；众人合写一首诗 | 中国古典诗学 |
    | 落点 | 意识本身 | 言外之意、象外之景 |

## 情感与形象

### 情感作为根本动机

* **抒情是创作的起点**

    * 一切文学创作的根本动机都源于情感，最重要的目的是抒情。

    * “我要表达”“我要呈现”里的“要”就是欲望，这个欲望就是抒情；看上去抒情性不强的作品亦然。

    * 抒发的未必宏大浪漫，很多是日常琐事，中国古代诗歌尤其如此。

* **古诗的真相**

    * 课本所收是经典中的经典，读大量其他诗之后才会发现真正的好诗仍集中在课本里，大量古诗水平并不高。

    * 《全宋诗》七十二册，能装满一个书架；补正项目又补出多册，作者有“易老翁”“一钓手”“无名氏”这类连名字都没有的人。

    * 读这类诗比读经典更需要文学感受力：读《春江花月夜》谁都能读出美，读边角料要靠专业训练。

    * 经典是被筛选下来的；古人作诗的目的往往只是记录日常生活的小事。

* **陆游的日常化写作**

    * 现存九千多首，估计一生写上万首；扣除前后各二十年，中间三十年约一天一首。

    * 写诗当日记：天冷写、逗猫写、失眠上街写、喝晕了写。

    * 这种日常化写作构成古人的日常，也比今天的某些俗事高雅。

* **叙事作品的抒情性**

    * 《木兰辞》：开头准备、结尾铺排都在做情感铺垫，十年从军只用“万里赴戎机”几句带过；前为家庭与父亲之爱，后为对祖国之爱。

    * 《西厢记》：情节简单，留在人们印象里的是唱段——“晓来谁染霜林醉，总是离人泪”。

    * 《西游记》等叙事作品同样以抒情为重。

### 形象作为抒情手段

* **判断标准**

    * 文学抒情要借助形象；判断作品好坏，可看它是否借助形象、形象运动是否恰到好处。

    * 形象用得太少，诗就太直白。

* **裴多菲《自由与爱情》**

    * “生命诚可贵，爱情价更高。若为自由故，二者皆可抛。”

    * 在中国古代诗人眼里绝不好：太直白、思想太抽象，通篇没有一个意象。

    * 直译应为：“在生命与爱情面前，我选择爱情；在爱情与自由面前，我选择自由。”其中国家喻户晓靠的是翻译，不是文学性。

### 自然景物意象的成因

* **季风性气候**

    * 中国是季风性气候，四季分明，古人对四季变化特别敏感。

    * 四季变化最明显体现在植物上，叶子黄了、枯了非常明显；动物身上不明显。

* **文人一生在路上**

    * 未做官时游山玩水，做官后被贬或升迁又在路上；苏轼被贬之地多到有“苏轼贬谪地联合会”。

    * 一步一步走，沿途一花一草看得清楚，故对自然景物认识密切。

* **情感对意象的选取**

    * 香山红叶：抱着游客心情看，风一吹红叶飘落是快乐的，不会悲秋；失恋者则不然。

    * 杜牧《山行》“霜叶红于二月花”、《西厢记》分别时见红叶，情感指向各不相同。

    * 花还是那个花，枫叶还是那个枫叶；变的是主观情感及由它带出的情感指向。

### 物象、意象、意境

* **三级链条**

    ```text
    物象（客观之物）
       │
       │ 注入主观情感
       ▼
    意象（带情感倾向的物象）
       │
       │ 情景交融，多个意象组合
       ▼
    意境（众多意象合成的整体氛围）
    ```

* **意象（image）**

    * > **定义**：意象是注入了作者主观情感的物象；没有情感的东西不能叫意象。

    * 刘勰：“登山则情满于山，观海则意溢于海。”

* **意境（artistic conception）**

    * > **定义**：意境是众多意象形成的一种气氛、一种氛围。

    * “枯藤老树昏鸦，小桥流水人家”：全是意象，且是枯藤、老树、昏鸦，组合出悲凉苍凉的深秋氛围。

* **情感作为取景框**

    * 站在国贸八十层：往东往西是长安街灯红酒绿，往南是一片黑（CBD 尚未改造）。

    * 写盛赞繁华，就只取灯红酒绿，那片黑当没看见。

    * 写“盛世下的危机”“繁华背后的隐忧”，就专写那一小块黑，灯红酒绿全不要。

    * 结论：情感决定选择什么意象进入意境；从物象到意象、从意象到意境，情感始终起决定作用。

## 形象的概括性

### 形象与观察

* **形象（image）**

    * > **定义**：形象是客观事物的特征与主观情感的特征相互结合。

    * 第一步是观察生活、了解客观事物；光观察不够，还要对生活有所概括、有所提炼，这才是塑造形象的功夫。

* **观察与观看**

    * 观看往往没有目的，眼睛扫过去，看见了也就过去了。

    * 观察有特定目的、有选择性：盯什么、略过什么都带着意图；作家看生活用后一种眼光。

### 概括性的两个效果

* **抓特点而非描摹**

    * 王昌龄“秦时明月汉时关，万里长征人未还”：讲互文（秦汉时的明月、秦汉时的关）只是表层，真正要问的是为何偏选明月与关、为何说秦汉。

    * 这两个意象有概括性，一呈现历史沧桑感就出来，读者自行往下联想。

    * 舒婷《致橡树》是核心意象，却一句没写橡树长什么样、南方北方、冬天春天。

    * 闻一多《死水》“这是一沟绝望的死水，清风吹不起半点漪沦”，从不说是哪个城市的死水，要的就是那个特点本身。

* **强化特点与激发联想**

    * 强化特点：抓住一点，把那一点推到最亮处，其余退到暗处。

    * 激发联想：“春风得意马蹄疾”抓马蹄——一见马蹄，读者脑中还原出整匹马；马蹄的特点又是快、是动态、是奔跑，与“春风得意”一碰，欢快场景与情感同时出来。

    * 最终目的：让读者进行自由的、合理的想象，激发读者的感受力；文学最本质的东西是传达感受。

### 四市的文本现象

* **文本现象**

    * “东市买骏马，西市买鞍鞯，南市买辔头，北市买长鞭。”不在一个地方买齐，顺序本身也不正常。

* **准备的郑重与意气**

    * 读来顺口是一个原因；营造忙碌氛围是第二层。

    * 可能有互文手法，未必真跑四个市场；正因不是真实情形而偏要这样写，才有可琢磨处。

    * 四句写的是准备的充分与对待准备的那股劲头：一样一样置办才显得郑重，其中还有替父从军的自豪感与意气风发。

    * 改写成“在某个小摊上把东西全买下来”，效果弱得多；独特特征被呈现，读者才会产生更多层面的联想。

### 剪刀与菜刀的取舍

* **《咏柳》的比喻**

    * 贺知章：“碧玉妆成一树高，万条垂下绿丝绦。不知细叶谁裁出，二月春风似剪刀。”

    * 写柳叶抓的是细、甚至有点尖；“春风似剪刀”的联想极到位。

* **为何不是菜刀**

    * 陌生化解释成立但不充分：“二月春风似菜刀”更陌生，为什么不好？

    * 第一层在字面：“不知细叶谁裁出”有“裁”字，汉语联想机制已浮出剪刀，下句“剪刀”正落在期待上。

    * 第二层在整首诗：碧玉、妆是女性妆扮，绿丝绦是身姿，细叶是纤巧，全篇把柳树当女性写；古代剪刀是闺房之物——女性的、室内的、针线活的，与全诗氛围吻合。

    * 结论：好意象不只求陌生，还要在陌生之后落回一个更大、更贴切的文化意象里。

* **方法告诫**

    * 不要简单评判作品好坏，好坏太容易判断也太主观。

    * 要多追问一步：好，为什么好？好在哪里？给不出理由、逻辑与背后支撑的点，就是没想清楚。

    * 把剪刀解释成“人民创造性的劳动”，是不能满意的读法，因为它没有回答这个意象好在何处。

## 想象与虚构

### 假定的真实

* **迟到者的故事**

    * 编剧迟到九十分钟（三小时的课），从见秘书到上台只有二十秒想对策。

    * 先讲贵妇人投诉火车噪音的故事：家住离铁道十公里，工程师到客厅听不见，被要求躺到床上听；丈夫回来撞见，工程师答“我躺在你老婆床上，就是想听一下火车经过的声音”。

    * 结论先立：“有些看上去不可能的事情，事实上是真的。”再说“今天迟到是因为被外星人劫持”，并埋钩子“两个秘密散场再说”。

    * 收网：“外星人告诉我的秘密就是你迟到了，必须要学会道歉。”结果不但没丢讲课费，还预支了三次课酬。

    * 起作用的不是最后那句道理，而是第一步：先把“不可能的事可能是真的”塞进听众脑子，后面越荒谬越容易被悬置判断。

* **故事的力量**

    * 请假条的关键不在理由正当与否，而在这个理由是不是一个中文系学生能说出来的：只说“买不着票”无法解释为何非今天回。

    * 讲故事不是号召说谎，而是在劣势位置说服对方时，把人带进一个独特情境，让人觉得那都是真的。

    * 追剧明知瞎编仍要看下一集，孩子听故事听到一半会追问“然后呢”。

* **假定性真实**

    * > **定义**：文学是一种假定的真实；它是假的，但它又是真的。

    * 独特处在于：明知是假，却相信它是真的；能不能让每个情节、每条逻辑都到位，就是作家的本事。

    * 理论表述：艺术是一种逼真的幻觉。鲁迅用第一人称写的“我”也不等于作者本人，须假定为虚构存在。

### 逼真的两种主张

* **斯坦尼斯拉夫斯基**

    * 《演员的自我修养》；体系强调投入与体验：演一个角色就要有一样的经历，体验过才可能达到绝对真实。

    * 推到极端就是演员得真的经历一遍角色的生活；没有体验，就没有真实。

* **布莱希特**

    * 主张相反：间离化，要产生距离，不要太投入，不要让观众觉得太逼真。

    * 手法是打破第四堵墙：舞台左、右、后三堵实墙之外，演员与观众之间还有一堵看不见的墙；传统表演中两者不能交流，像隔一道屏障。

    * 中国小剧场把这套手法用到反方向：演员走入观众；沉浸式话剧无舞台，观众在演员身边，可以从任何角度观看，甚至被卷进演出。

* **第四堵墙的归属**

    * > **提示**：这堵墙最容易记反。留着墙、演员假装台下没人、观众像透过玻璃往里看，属斯坦尼一路；拆掉墙、演员走出台口直接对观众说话以打断幻觉，属布莱希特一路。

* **两派的分歧点**

    * 斯坦尼认为逼真到分不清生活与艺术才叫艺术；布莱希特反问：若艺术与现实没有区别，还要艺术做什么，直接看生活不就完了。

    * 另一条支持间离的理由：失恋当下写不出好诗，写出来全是骂人的话；十年后回看那场奋不顾身的爱情，才写得出好诗。这就叫间离——离开了。

* **一枪打死演员**

    | 比较项 | 斯坦尼斯拉夫斯基 | 布莱希特 |
    | :--- | :--- | :--- |
    | 核心主张 | 投入、体验，达到绝对真实 | 间离化，制造距离 |
    | 对第四堵墙 | 保留，演员假装台下无人 | 拆掉，演员直接对观众说话 |
    | 目的 | 让观众忘记在看戏 | 让观众始终知道这是戏 |
    | 打死演员的评价 | 世界上最好的演员 | 世界上最差的演员 |

    * 剧场演反派演得太逼真，台下军官忘了在看戏，掏枪把演员打死；演员死后墓上立碑，有人说他是世界上最好的演员。

    * 中国演《白毛女》也有观众要开枪打反派，被旁边人把枪抬起。

    * 两派都能成派，说明两边都有道理。

### 诗中的名物

* **《枫桥夜泊》的考证**

    * 张继：“月落乌啼霜满天，江枫渔火对愁眠。姑苏城外寒山寺，夜半钟声到客船。”

    * 张继仅此一首传世，生卒年不详，与张若虚相类。

    * 疑问一：月落已深夜，乌鸦该睡了，何来乌啼？考证说乌啼是寒山寺附近的乌啼山。

    * 疑问二：江枫是植物、渔火是火光，性质不同如何“对”？愁眠是情感又如何对？考证说愁眠是愁眠山。

    * 反问：先有诗还是先有山？寒山寺因这首诗才叫寒山寺，诗人凭吊之后周围物象才因此得名。

    * 另一公案：哪有寺庙半夜敲钟？考证说唐诗中夜半钟声不止一首。但寒山寺如今每到过年敲钟并现场直播，本不需要合理。

* > **易错点**：拿现实世界的逻辑核对诗里的名物，越考越像学问，方向从一开始就反了。

* **《鸟鸣涧》的桂花**

    * 王维：“人闲桂花落，夜静春山空。月出惊山鸟，时鸣春涧中。”

    * 矛盾：夜静春山空写春天，桂花却是秋天。考证结论是有春桂花（学名山矾花）春天开。

    * 反问：这样解决伤害更大。诗的美感在“月出”之静与“鸟鸣”之动形成的张力；用桂花正因为花型极小，才有落地无声之感。

    * 山矾花花型极大，至少是桂花四倍以上，一解释意境就毁了；补上破绽，意境就没了。

* **艺术世界与现实世界**

    * 诗歌世界是虚构的独特世界，遵从那个世界的逻辑即可，不必遵从现实生活逻辑。

    * 艺术的本质不是如实描绘，而是创造、是虚构；它不但不遵从世界，还会再造出另外一个现实。

### 四个维度的判定

* **四个维度**

    * 审美的、文化的、语言符号的，以及情感与形象、想象与虚构。

    * 作用不是“是或否”的判定，而是程度上的判定；是一把尺子、一个参照系。

* **程度判定的示例**

    | 对比 | 结论 | 理由 |
    | :--- | :--- | :--- |
    | 《红楼梦》与《史记》 | 《史记》更弱 | 想象虚构性不明显 |
    | 《史记》与《论语》 | 《论语》更弱 | 语言不是陌生化的语言 |

    * 文学性是动态的、相对的概念，不是贴在作品身上的标签。
