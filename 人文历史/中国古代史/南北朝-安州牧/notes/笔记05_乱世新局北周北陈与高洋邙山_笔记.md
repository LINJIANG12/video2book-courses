# 乱世新局：北周、北陈与高洋、邙山

## 550年：北方换天与南方内耗

* **北齐开国**

    * 公元550年5月，东魏齐王高洋接受皇帝元善见的禅让登基称帝，建立北齐，北方改朝换代就此尘埃落定。

* **南梁宗室割据**

    * 萧衍死后，江陵的萧绎、襄阳的萧詧、夏口的萧纶、益州刺史萧纪各据一方窥视皇位，整个南梁陷入宗室内斗的漩涡，客观上给了侯景扩张的时间。

* **宇宙大将军**

    * 侯景发兵占据三吴，派任约西进，江州刺史萧大心投降；9月侯景进位相国、封汉王、增邑二十郡，一个月后自封「宇宙大将军、都督六合诸军事」。

    * 「宇」指上下四方的一切空间、「宙」指古往今来的一切时间；简文帝萧纲见到侯景自命的诏书，惊呼「将军乃有宇宙之号乎！」。

* **宇文泰的试探**

    * 高洋称帝后，宇文泰以元魏正统的名义整顿兵马讨伐；从弘农北渡黄河抵达建州时，听闻高洋亲率大军驻晋阳东城、军容威武，判断高洋已取得政权内部各方派系的认可。

    * 西魏大军又逢连绵阴雨、进军困难，宇文泰叹「难道高欢没有死吗」，自蒲坂班师，接受高洋称帝建国的既成事实。

## 西魏的制度手术

### 府兵制与八柱国

* **盟主不是主公**

    * > **定义**：宇文泰在西魏的真实身份——不是至高无上的主公，而是四股势力联盟的盟主：宇文泰嫡系班底、贺拔岳的武川旧部、兼并贺拔岳与侯莫陈悦后的部众、孝武帝元修西逃带来的元魏宗室与部分军队。

    * 他急需解决两个问题：把各派系将领的私兵变成自己掌控的军队；取得关陇地方豪强的支持以巩固和扩大实力。

* **府兵制**

    * > **定义**：宇文泰顺应六镇以来反汉化潮流、把各派将领及其私兵整合为六军的制度——表面遵循周礼「天子有六军」，实质恢复鲜卑部落兵制，各军以氏族血缘为纽带，反而加强了凝聚力和战斗力。

    * 公元550年（大统十六年）是学界普遍认可的府兵制基本成型时间。

* **八柱国**

    * 至550年先后受封柱国大将军者共八位，每个名额都对应一股势力：

    * | 柱国大将军 | 出身背景 |
      | :--- | :--- |
      | 宇文泰 | 联盟盟主，府兵最高统帅 |
      | 元欣 | 原西魏宗室，挂名不领兵 |
      | 李弼 | 侯莫陈悦派系里地位最高者 |
      | 独孤信 | 贺拔胜死后其旧部中资望最高者 |
      | 赵贵 | 贺拔岳旧部里资望最高者 |
      | 侯莫陈崇 | 贺拔岳旧部里资望最高者 |
      | 于谨 | 宇文泰嫡系心腹 |
      | 李虎 | 西魏禁军将领中资历最深者 |

    * 除宇文泰、元欣外，其余六位柱国每人统两名大将军，且大将军与顶头柱国分属不同派系——独孤信（贺拔胜旧部）麾下的宇文导（宇文泰之侄）与元阔（西魏宗室）即分属不同利益团体。

    * 交叉制衡把反汉化催生的部落私兵制转化为制衡各派的手段，实现军权的初步中央集权化；八柱国也从军事将领转变为政治贵族、宇文泰身边的开国元勋。

### 乡兵入府

* **广募关陇豪右**

    * 公元543年东西魏邙山大战后，宇文泰的鲜卑六军损失惨重，遂「广募关陇豪右以增军旅」，把地方豪强的乡兵吸纳进府兵系统。

    * 汉人坞堡势力自西汉末年萌芽、五胡入华后遍地自保，甚至能携州郡之地转投阵营；鲜卑人丁居劣的西魏需要汉人兵员。

* **管控与结构变化**

    * 宇文泰授予统帅乡兵的豪强都督、帅都督、大都督名号，完成政权对乡兵的直接管控，加强中央集权。

    * 乡兵把汉人坞堡兵农结合的模式带入府兵；此后府兵主体逐渐从六镇鲜卑兵过渡为汉人士兵。

    * 此时能进入府兵系统的并非底层百姓，而是有一定资产的地主阶层，其地位提升又强化了宇文泰在军中的威望。

### 赐复胡姓

* **政策节奏**

    * 公元549年西魏下诏：孝文帝汉化以来改汉姓者一律恢复胡姓；554年又大规模为军中汉人统帅赐胡姓。

    * 正史与金石碑刻可考的赐姓共72处、涉及32姓：

    * | 人物 | 所赐胡姓 |
      | :--- | :--- |
      | 李弼 | 徒河氏 |
      | 李虎 | 大野氏 |
      | 杨忠 | 普六茹氏 |
      | 赵贵 | 乙弗氏 |
      | 韦孝宽 | 宇文氏 |

* **三层用意**

    * 将领受赐胡姓时麾下士兵一并改姓，府兵中胡汉无法从姓氏分辨民族，消解了军队内部的民族矛盾。

    * 关陇汉人士族庶族改鲜卑姓后打破门第之别，客观提升寒门庶族地位；对原本的高门第者则伴以官爵升迁，营造「获得赐姓是极高荣誉」的氛围，削减接受阻力。

    * 恢复鲜卑姓满足六镇旧部反汉化的心理，选择性赐姓又不全盘否定汉姓、照顾汉人宗法情结——政策未招致大量社会矛盾，反使宇文泰在鲜卑族与汉族上层同时收获极高威望。

* **私心**

    * 72例赐姓中被赐北魏皇室宗族之姓与勋臣八姓者兼而有之，而被赐宇文氏者多达32人——借赐姓培植自己羽翼的用意不言自明。

    * > **提示**：孝文帝改革与宇文泰改革互为反向镜像——一个用汉姓换民族融合却激化矛盾，一个用胡姓换凝聚力反而两边买好；差别不在姓氏本身，而在是否照顾到各方既有利益与情感。

## 侯景之乱的终局

### 南线攻守

* **萧纶之死**

    * 萧纶弃夏口后辗转齐昌向北齐求援，获高洋册封梁王，北齐却作壁上观坐看内耗；萧纶在萧绎与任约两面夹击下逃亡汝南。

    * 萧纶在汝南休养士卒、计划偷袭西魏安州，被安州刺史密报宇文泰；杨忠领兵一万增援安陆后反手围攻，仅一天攻破汝南，萧纶被杀。一个月后西魏皇帝元宝炬去世，太子元钦即位。

* **建康政变**

    * 侯景西进期间，南康王萧会理联合宗室萧进通密谋政变、计划斩杀谋主王伟，因建安侯萧贲等告密而败露；王伟先下手尽斩萧会理等人。

    * 萧纲虽未参与，但因与萧会理的亲缘关系遭侯景怀疑；前线未解，侯景匆匆返回建康稳定局势。

* **夏口突袭**

    * 梁将徐文盛东下击败任约（退守西阳）、收复武昌进抵郢州；侯景先派宋子仙领军两万救援，后挟太子萧大器为人质亲自西进，与徐文盛隔江对峙。

    * 侯景首战不利后获知夏口（郢州）防备空虚，派宋子仙、任约率轻骑四百渡江突袭，郢州陷落；侯景全军满帆顺风无视徐文盛大营入驻夏口，徐文盛部沦为孤军溃散，逃回江陵。

* **巴陵三策**

    * 萧绎的预判：侯景水陆两道直指江陵为上策；聚守夏口、囤积兵粮为中策；全力攻巴陵为下策。

    * 判断依据：巴陵城小而固、王僧辩足可委任；侯景攻城不拔自然无所恋战；暑疫时起、兵疲食竭，破之必矣。

    * 侯景果然走下策猛攻巴陵，始终无法攻克；粮草耗尽、军中起疫、士卒死伤过半。

* **赤矶夹击与宋子仙之死**

    * 萧绎派胡僧祐增援并嘱其不与任约纠缠；任约误判对方畏惧而疯狂追击，追到赤矶时遭信州刺史陆法和迎面拦截，胡僧祐回身两面夹击，任约惨败被俘。

    * 侯景留宋子仙守郢州、连夜烧营退走；王僧辩攻克郢州外城围住内城，假意应允宋子仙献城求和并备一百艘大船，趁其全军停止抵抗时突袭，宋子仙兵败被杀。

    * 王僧辩随后东进攻克湓城、收复江州，与陈霸先部会师。

### 称帝与败亡

* **禅让闹剧**

    * 王伟进言「自古篡立必须先行废立」；侯景废黜萧纲、大肆诛杀太子萧大器等宗室，迎立豫章王萧栋，三个月后照猫画虎完成禅让，登基称帝、国号汉。

* **七庙**

    * 王伟请设七庙（天子祭祀祖上七代）；侯景只记得父亲名侯标、埋在朔州，「哪儿来建康的香火」；祖父名侯仪靠旧部回忆，其余五代先祖名讳全由王伟编造。

* **建康决战**

    * 联军连克南陵、鹊头、东阳、芜湖、姑孰，王僧辩先头部队直接进入秦淮河兵临建康；侯景急令石头城守将凿沉船只封堵秦淮河入江口，并在北岸修筑营垒。

    * 陈霸先吸取柳仲礼十万大军隔水对峙、始终不进北岸而致败的教训，主张围石头城必须登陆北岸，自任先锋在石头城西落星山立营；侯景在石头城东北筑寨对峙，亲率大军一万、铁骑八百列阵城西。

    * 陈霸先趁侯景进攻时派弓箭手偷袭其后军，待其回撤保护后军时，再率铁骑与王僧辩主力正面突击；侯景首尾难顾败退，石头城守军开城投降。侯景又以百余骑猛攻陈霸先营垒，殊死战而逐渐溃散，被一路追击至建康西明门外。

* **侯景之死**

    * 侯景逃回建康不敢入台城，城下骂王伟「是你们让我为帝，今日误我」；王伟以「自古岂有叛逃的天子」拉缰劝阻，侯景叹昔日破葛荣、扬名河朔，渡江后平台城、败柳仲礼如反掌，「今日天亡我也」，马驮两个幼子带百余亲信东逃。

    * 侯景沿途收拢士兵数千、舰船二百余艘，败于侯瑱追兵后与数十心腹乘小船准备东入大海；部下羊鲲趁其入睡挟持船夫掉头京口，并称「吾等为王效力多矣……不如取你人头去领富贵」，侯景跳船逃生时被长矛刺中毙命。

    * 尸体运回建康，首级送江陵，身体被百姓争相分食；持续三年有余的侯景之乱落幕。

* **建康浩劫**

    * 建康百姓以为迎来曙光，王僧辩部众入城后却大肆劫掠，石头城至东府嚎哭遍野；当夜台城失火，焚毁太极殿及东西堂，宫中器物珍藏大量遗失。

### 门阀的灭顶之灾

* **新贵取代高门**

    * 萧衍的优待延续了世家门阀的政治生命，侯景之乱对建康及三吴的门阀则近乎灭顶之灾；以讨伐侯景为名崛起的新贵中：寒门十一人、庶族平民八人、少数民族酋帅十五人、世家高门仅十二人，门阀在南朝的衰落进一步加剧。

* **北强南弱定局**

    * 台城围城的破坏与随后的蝗灾、饥荒致人口大量死亡，南朝社会生产力遭极大摧残；北强南弱的趋势自侯景之乱已然形成定局。

## 萧纪东征与益州易手

* **出师无名**

    * 552年4月侯景之乱在萧梁宗室的争相出力下平定；北齐趁乱蚕食淮河一线，西魏同年5月由达奚武攻克南郑、打开入蜀门户。

    * 萧绎处死萧栋、552年11月正式称帝；益州的萧纪随后在成都称帝，553年3月发兵东进仍宣称讨伐侯景——信息滞后使其出师无名，麾下士兵人心思归。

    * 当年萧绎曾以「孙权刘备各安境界」的书信劝阻萧纪东出，兄弟终究兵戎相见。

* **两面受敌**

    * 萧绎欲诱捕王琳（建康劫掠百姓、火烧宫殿系其部众所为）反激起兵变：萧绎派去接管襄州的官员激起王琳部曲不满，众人在陆纳率领下占据襄州，王僧辩被迫回师讨伐，萧绎无力正面阻挡萧纪。

    * 萧绎一面让法师作法、一面送还俘虏的侯景部众证明侯景已灭；镇守巴东的太子萧圆照扣押使者，并以「天无二日，国无二主」催促萧纪强行东进。

* **借刀西魏**

    * 萧绎致书宇文泰「子纠亲也，请君讨之」，借《左传》齐国公子纠的典故请西魏替自己灭掉亲弟弟；宇文泰视之为「取蜀制梁，在此一举」。

    * 满朝文武只有宇文泰的外甥尉迟迥赞同伐蜀：蜀地与中原隔绝百余年、依仗山川险阻从不设防，铁骑直进无不克；尉迟迥率六军甲士一万二千、战马万匹出散关。

    * 萧纪大军刚抵巴郡即分兵回援成都；当年想任梁州刺史却被安排去做潼州刺史、一直耿耿于怀的杨乾运举潼城投降，尉迟迥不费吹灰之力兵围成都。

* **王琳归营**

    * 萧绎释放王琳送去襄州平叛；陆纳等人见王琳归来跪地叩拜大哭，要求放王琳入城被王僧辩拒绝；萧绎再次把王琳送回，王琳入长沙，陆纳率军归降，王僧辩、王琳各自带部众西进支援前线。

* **金饼画饼**

    * 萧纪在阵前摆出一百箱金饼（每个重一斤）、五倍于金饼的银饼与无数锦绣绸缎激励士气，战后却全部收回；反复多次后士兵明白自己只有「大饼」，部下劝用财货招募勇士也被拒，军中人心离散。

* **萧纪之死**

    * 萧纪正面无法突破防线、身后成都被围，进退维谷中遣使求和；使者看出败局已定，反将萧纪粮草短缺、人心厌战告知萧绎，和谈被拒。

    * 任约反攻连克长江沿岸十四座营垒，切断萧纪西逃后路；萧纪乘船东逃，被游击将军樊猛追杀，掷出装满黄金的袋子只求见萧绎一面——萧绎战前已嘱樊猛「杀了你，金子也是我的」。

    * 萧纪被杀，萧圆照押往江陵斩首；萧纪被从族谱除名、赐姓饕餮。

    * 成都被围五十余日后守军开城投降，西魏占领益州，尉迟迥获封大都督、都督益潼等十二州诸军事、益州刺史，南梁宗室乱斗告一段落。

    * > **提示**：萧纪临死前最后一笔投资血本无归——这逻辑与强盗一模一样：打死你，这也是我的。

## 高洋立国与英雄天子时代

### 上位与制衡

* **高欢的旧账**

    * 行台郎中杜弼以「文武在位多贪污」进言整肃；高欢解释不急反腐的原因：麾下将领家属多在关西、宇文泰常借此招揽，人情去留未定；江东萧衍专事衣冠礼乐、中原士大夫视之为正朔所在——此时急于肃正纲纪，诸将尽归宇文泰、士族皆奔萧衍，人物流散无以为国。

    * 国内稳定后高欢借世子高澄之手打击贪腐、削弱六镇勋贵，高澄倚重崔暹、崔季舒等汉族士人，并通过改革官员选拔方式提升汉人官员地位；被打压的勋贵集团由此对高澄心生不满。

    * 背景：东魏北齐行胡汉分治，高欢在晋阳建霸府后把散落河北的六镇军民迁回晋阳周边，合称「六州鲜卑」，成为东魏北齐的主要军事力量。

* **高洋的制衡策略**

    * 高洋长期受高澄猜忌、被迫韬光养晦，晋阳旧臣宿将普遍轻视他，勋贵集团成为登上帝位的最大阻碍；高洋出走晋阳再次开会，称帝之事获汉人士族高德政、杨愔大力支持。

    * 身份认同上自认鲜卑人的高洋，执政后仍延续「提升汉人士族制衡勋贵」的策略。

### 治绩

* **民生新政**

    * 颁布兴办儒学、减免赋税、铸造新币等措施稳定民生；所铸常平五铢质地精良、值得信赖，在乱世货币中相当难得。

* **监察与律法**

    * 御史监察官职地位提升，御史定期巡行州郡、暗察百官成为长期制度，河北之地百年吏治混乱的局面得以好转。

    * 高欢、高澄主导的麟趾格在高洋时代进一步加强完善；法制史学者程树德评价：南北朝诸律北优于南，而北朝又以齐律为最。

### 军事亲征

* **两支主力**

    * 从六镇部众中挑选以一敌百者组建「百保鲜卑」，从汉人中选取勇力绝伦者组建「勇士」，成为此后征战的主力。

* **十一次亲征**

    * | 时间 | 战事 |
      | :--- | :--- |
      | 552年正月 | 大破北方库莫奚，俘获杂畜十余万 |
      | 553年正月 | 驱逐契丹 |
      | 553年9月 | 击败来犯的突厥 |
      | 553年12月 | 亲征突厥，迫使其称臣请降 |
      | 554年正月 | 击破契丹主力，彻底平定 |
      | 554年4月至7月 | 重创犯边的柔然 |

    * 登基后五年先后十一次率军亲征，作战时露头肉袒、身先士卒；缓解了六镇起义以来东魏北齐受制于北方游牧民族的压力，突厥佗钵可汗称其为「英雄天子」。

* **修长城**

    * 继承北魏以来兴建长城的策略，至557年连同北魏、东魏时代的长城，北齐境内所修长城已长达三千余里。

## 江陵之陷与南梁三分

### 战前

* **西魏内部清洗**

    * 553年尚书元烈密谋刺杀宇文泰败露被杀；皇帝元钦暗中谋除宇文泰，被告发后遭废黜，改立其弟元廓，并令元廓及皇族改回拓跋姓，同时大规模为各军将领和部曲赐鲜卑姓。

* **开战借口**

    * 西魏使节归国禀报萧绎接待时态度傲慢；萧绎又来信要求恢复两国旧有边界，宇文泰大怒：古人有言「天之所赐，谁能废之」，说的就是萧绎这种人。

    * 553年5月李迁哲平定境内两州叛乱后乘势南下，巴州刺史牟安民投降，巴州及周边大小十八州并入西魏；9月于谨、宇文护、杨忠率兵五万攻打南梁。

* **于谨预判**

    * 于谨的三策推演：萧绎若陈兵汉沔、任西魏席卷渡江直取建康为上策；迁走外城居民、退保内城加强城防待援为中策；不做移动、据守大城为下策。

    * 判断萧绎必用下策：萧氏保江南数十年靠的是中原战乱无暇顾及、西魏又有北齐之患；萧绎懦弱无谋、多疑少断，普通人尚且留恋故居不愿迁移，自然据守大城。

* **段韶江北解围**

    * 几乎同期，北齐占领的宿预百姓在东方白额带领下举城降梁，晋陵太守杜僧明率三千支援，陈霸先部将严超达自丹徒渡江围广陵；北齐段韶留兵围宿预、亲率长驱南下，途中吓退将袭盱眙的梁军，击破严超达解广陵之围，再以劝降为饵杀东方白额——南梁恢复江北领土的计划告吹。

    * 段韶的战前判断：梁室骚乱、国无定主、人心离散，强者从之、弱者背之；陈霸先等外托同德、内有离心，诸君不足虑。

### 围城与焚书

* **木栅防线焚毁**

    * 于谨令宇文护、杨忠率精骑抢占江津断萧绎后路；宇文护攻克武宁郡，西魏大军渡汉水兵临城下时，萧绎苦心购置的城外木栅（绵延六十里）突遭大火，殃及百姓数千家、城楼二十五座，一夜毁于一旦。

* **迟疑的守君**

    * 西魏军至樊城与萧詧会合；萧绎派王琛西探，王琛至石梵未见魏军，回报「边境安然无恙，此前传闻皆是儿戏」；萧绎继续讲授老子，同时召王僧辩回荆州。

* **城破**

    * 于谨筑高墙四面围城；萧绎登城作诗、写信催王僧辩「我坚持着不死，正是等你们前来」；守军多次突围铩羽，都督东城诸军事胡僧祐中流矢阵亡，士气大挫；有人打开外城西门，萧绎退入内城请和，被于谨拒绝。

* **焚书**

    * 萧绎命人烧毁东阁殿宇，所藏十四万卷古籍付之一炬；自陈焚书理由：「读书万卷，犹有今日，故焚之。」

    * 萧绎放弃皇家仪仗、白马素衣出东门，拔剑砍门扇叹「我萧绎，竟落到如此地步了吗」；西魏随后处死萧绎。

* **西梁傀儡**

    * 西魏扶持萧詧为帝，史称西梁；以江陵周边三百里之地换取萧詧的襄阳；萧詧自率军驻江陵东城，西魏军驻西城，名为协防。

### 三分格局

* **南梁三分**

    * ```text
      西魏扶植 ──→ 江陵 · 萧詧（西梁，傀儡政权）
      北齐推举 ──→ 贞阳侯萧渊明（拟立为南梁皇帝）
      萧梁余脉 ──→ 建康 · 萧方智（王僧辩、陈霸先拥立）
      ```

* **北齐动作**

    * 北齐援军行至半途江陵已陷，南梁郢州刺史陆法和举州降齐；高洋听闻南梁无主，立即推出手上的老人质贞阳侯萧渊明，计划立为南梁皇帝——江南社稷将在多方干预中迎来南朝最后的王朝。

## 突厥代柔然

* **土门崛起**

    * 铁勒部进攻柔然之际，阿史那土门率突厥袭击铁勒军队大胜，收降铁勒部众五万余帐，实力大涨。

* **锻奴之辱**

    * 阿史那土门向柔然可汗郁久闾阿那瑰求亲被断然拒绝，使者辱骂突厥是给柔然打铁的「锻奴」；土门勃然大怒，斩杀使者、断绝往来。

* **伊利可汗**

    * 一年后土门大破柔然，阿那瑰兵败自杀、宗室残部投奔北齐；土门自称伊利可汗，草原步入突厥可汗时代。

* **柔然灭亡**

    * 555年末，木杆可汗阿史那俟斤对柔然残部发动最后进攻，可汗郁久闾邓叔子率部投奔西魏，柔然汗国退出历史舞台。

    * 突厥西破嚈哒、东走契丹，完全取代柔然昔日地位，威服塞外诸国。

## 三方傀儡博弈与王僧辩之死

### 抢立傀儡

* **三方代理人**

    * 西魏破江陵后扶萧詧为帝；王僧辩、陈霸先在建康推举年仅十三岁的江州刺史萧方智为梁王；北齐高洋派兵护送贞阳侯萧渊明南下——三方都想拥立自己的代理人接管南梁。

    * 建康方面的原计划是攻打西魏安州以分散其注意力、救援江陵，援军行至半途江陵已陷。

* **北齐施压**

    * 高洋多次写信劝王僧辩迎立萧渊明，均被拒绝；北齐分兵攻克谯郡、晋州、东关，兵锋与建康仅一江之隔。

    * 北齐以军事压力迫使王僧辩派使者和谈，共识为萧方智立为太子；北齐撤军并归还孤悬于外的颍州。

* **迎立萧渊明**

    * 555年5月王僧辩最终迎立萧渊明为帝、延续南梁国祚，向北齐称藩。

### 袭杀王僧辩

* **王陈反目**

    * 陈霸先强烈反对萧渊明继统：他是萧衍兄长萧懿之子，于情于理都难服人心。

    * 萧绎死后王僧辩进位录尚书事、都督中外诸军事，独掌军政，二人从合作走向暗中防备；王僧辩令陈霸先远离中枢、置于对齐前线，想借北齐之刀削弱其实力，又以女婿杜龛出任吴兴太守、兄弟王僧智出任吴郡太守、韦载出任义兴太守——义兴是陈霸先家乡、宗族皆在此，用意不言自明。

* **夜袭石头城**

    * 陈霸先调侯安都、周文育、徐度、杜棱，赏赐金帛，水陆并进连夜袭取王僧辩所在的石头城；杜棱临阵退缩，被陈霸先用手巾勒晕关入密室以防泄密。

    * 侯安都先抵石头城见陈霸先未至，上岸斥责「今日做贼，事势已成……在后不前，欲何所望？若败俱死，待在后面就能免得了砍头吗」，陈霸先由此确认其心意。

    * 侯安都自石头城北面登陆、持长刀翻城闯入王僧辩府邸；王僧辩率数十亲信且战且退至南门城楼，城楼被火焚，父子被逼出逮捕，当夜绞杀；次日陈霸先发布檄文，声明只诛王僧辩父子兄弟，其他人一概不究。

* **事后收束**

    * 短短四个月，陈霸先晋升尚书令、都督中外诸军事、车骑将军、扬南徐二州刺史。

    * 陈霸先向北齐送文书称王僧辩谋反被诛，南梁依旧称臣于齐、永为藩国；高洋明知真相也毫无办法，承认事实并订盟约。

### 反弹与建康保卫战

* **长城县守御**

    * 杜龛派兵五千攻打陈霸先家乡亲族；其侄陈蒨提早回乡，在长城县收拢部众、构筑防御工事，以数百人面对五千敌军神情自若，稳定了城内人心。

* **义兴弩阵**

    * 周文育攻打义兴受挫：城中陈霸先旧部擅长用弩，韦载将数十名弩手用锁链连在一起押上城墙，下令「一箭不中者斩」，弩手箭无虚发；陈霸先亲率大军来攻，破城外水栅后派韦载族弟入城劝降，韦载开城投降，部将裴忌随后攻克吴郡。

* **石头城易手**

    * 陈霸先刚离建康，王僧辩外甥徐嗣徽即联合南豫州刺史任约率五千袭占石头城；留守的侯安都闭宫门、收旗帜、禁人登城窥探以示弱，待敌当晚回城、次日大意逼降时，率甲士三百自东西掖门杀出大破之。

    * 徐嗣徽在王僧辩死后已举州降齐；北齐派兵五千渡江增援，安州、楚州、淮州三地刺史合兵一万自湖熟运送马匹粮草入石头城，建康危在旦夕。

* **韦载献策**

    * 韦载分析：齐军若分兵断绝建康通三吴之路再向东略地，则大事去矣；当速赴秦淮河南岸、借侯景留下的营垒筑城，保护与东方各地的后勤周转，再分兵断敌粮道——敌将之首指日可待。

    * 侯安都夜袭湖熟，焚毁北齐运粮船一千余艘，截断粮道；齐军退至秦淮河南岸筑垒与守军隔河对峙。

* **琵琶与鹰**

    * 徐嗣徽再攻建康，被陈霸先击退于西宁门外；侯安都渡江偷袭攻入徐嗣徽府宅，夺其琵琶与鹰，次日送还并附言「昨夜至君家得此，谨以相还」，徐嗣徽极为惊恐。

    * 陈霸先在冶城架设浮桥猛攻南岸齐军，齐军大败退入石头城；城内缺水，遣使求和。

* **和谈人质**

    * 建康自侯景之乱后城池残破、物资欠缺，朝中百官期待早日和谈；约定石头城齐军安全返回江北，陈霸先以侄子陈昙朗、王孝庄及丹阳尹之子王珉送北齐为质。

## 陈霸先建陈

### 三吴平定与梁山决战

* **杜龛之死**

    * 556年正月陈蒨、周文育会师攻打吴兴，杜龛在部将杜泰内应下被擒——酒醉不醒的杜龛被陈蒨带至项王祠斩首。

    * > **易错点** ⚠️：杜龛的结局另有版本——《梁书》与《陈书》记载他是经杜泰劝说出城投降后，被陈霸先诛杀。

    * 王僧智与其弟豫章太守王僧愔投奔北齐；陈蒨、周文育再破会稽、斩张彪，三吴平定。

* **残余割据**

    * 三吴平定后，南梁境内仍有襄州王琳、江州侯瑱、广州萧勃拥兵割据；陈霸先遣周文育攻打江州湓口，侯安都、周铁虎屯驻梁山。

* **梁山决战**

    * 北齐十万大军在仪同三司萧轨指挥下进攻梁山；徐嗣徽把战船沿长江东西排开拦截周文育归路，周文育战鼓冲锋，徐嗣徽水军不敢阻拦反被斩一将，惶恐弃船从芜湖上岸退往丹阳。

    * 萧轨攻南梁受挫后转由芜湖登陆向北推进，六月暗中翻越钟山试图绕攻建康北面，却被南梁军趁机在幕府山截断大军补给。

    * 北齐军失粮草，被围困于幕府山、钟山与玄武湖之间，连绵阴雨又致营中大量积水；天气放晴之际，陈霸先倾尽一切兵力猛攻一身泥泞的齐军，萧轨及徐嗣徽等四十六将被俘——来自北齐的威胁暂告终结。

### 登基节奏

* **江州乱局**

    * 王琳攻破萧纪后受萧绎猜忌被派往广州，旋即急调襄州刺史回援江陵，行至长沙闻江陵陷落，遂占襄州拥兵自重。

    * 部将侯平因与西凉作战立功而轻视王琳、举兵反叛，袭杀巴州驻防援军后逃往江州；失去大将的王琳只好向北齐、西魏两边称臣维持生存。

    * 侯平与江州刺史侯瑱结拜为兄弟，却趁侯瑱领兵外出占据其大后方、劫掠烧城后投奔建康；侯瑱在新淦县作战时后方被毁、部众溃散，经部下劝说降陈，南梁收复江州；陈霸先查明原委后斩杀侯平，九月晋升丞相、录尚书事、扬州牧，封义兴郡公。

* **剪除萧勃**

    * 557年二月，盘踞广州的萧勃向陈霸先宣战；周文育南下不到一个月击溃其前锋，德州刺史陈法武与前衡州刺史谭世远攻入广州斩萧勃；四月底各地割据势力次第平定，陈霸先声望达到顶峰。

* **官阶五连跳**

    * 八月进位太傅、加黄钺殊礼、赞拜不名；一个月后晋位相国、总百揆、封陈公，备九锡、设陈国、置百司；十月获封陈王；三天后萧方智完成禅位——这是557年的第二次禅让。

    * 陈霸先即帝位，国号陈，史称南陈。

### 南陈初局危机

* **郢州之败**

    * 陈霸先受禅的消息传到讨伐王琳的前线，侯安都叹「吾今兹必败，战无名矣」——奉南梁皇帝之命讨不臣的名义，随禅让消失。

    * 侯安都、周文育平级互不相属、部下时常摩擦，大军推进至郢州后各自为战；王琳援军抵达决战，陈军大败，侯安都、周文育悉数被擒。

    * 558年春陈霸先再调十余万部队征讨王琳；王琳向北齐求援，请送萧绎之孙、南梁永嘉王萧庄南渡立为南梁新主。

* **周文育之死**

    * 前线作战不力使中间派豫章太守熊昙朗动摇，密谋斩周文育投王琳；部下劝先下手，周文育以「我兵少，彼军多，若先动手人人惊惧，王琳必至，不如推心以辅之」拒绝，数日后在熊昙朗营中宴会上被斩杀。

* **陈霸先驾崩**

    * 559年6月周文育灵柩抵达建康，本已抱恙的陈霸先身穿素服失声痛哭，次日病情加重，卒于璇玑殿，享年五十七岁，谥号武皇帝。

    * 亲子陈昌自552年入江陵为质，江陵陷落后被掳往长安未能归国；中领军杜棱与皇后章氏议定隐瞒死讯、朝政如旧，急召临川王陈蒨返京，侯安都班师经南皖与之同返。

* **带剑上殿**

    * 章氏仍期待亲子陈昌继位；侯安都带剑上殿宣示「今四方未定，何暇甚远？临川王有大功于天下，须共立之。今日之事，后应者斩」，并请皇后交出皇帝玺绶；陈蒨即位，是为南陈文帝。

## 北周代魏与宇文护专权

### 托孤与建周

* **牵屯山托孤**

    * 巡视北方的太师宇文泰在牵屯山卧病不起，召侄子宇文护至荆州嘱托「吾诸子皆幼，外寇方强，天下之事，托付于汝，宜努力以成吾志」，随后病逝于云阳。

    * 年仅十五岁的世子宇文觉承袭官爵；受命辅政的宇文护在朝中名望不足，无法执掌朝政。

* **于谨定策**

    * 宇文护求助宇文泰心腹、大司寇于谨；于谨表态「今日之事，必以死争之」，次日在朝上当众定策：嗣子年幼，受顾命重托的中山公宇文护理应管辖军国之事。

    * 宇文护以「此乃家事，护虽庸昧，何敢有辞」接话，用家事之名断绝外臣干预；在于谨声色严厉的震慑下，朝中大臣无不畏服，宇文护自此掌握国政。

* **受禅建周**

    * 宇文觉先进封周公、以岐阳为封邑；557年正月，宇文护安排宇文觉接受西魏皇帝拓跋廓的禅让，自称天王，国号周，史称北周；宇文护官拜大司马。

    * 西魏立国二十二年而亡；宇文泰、高欢所代表的后六镇时代勋贵联盟权力模式迎来最后的震荡。

### 赵贵独孤信之死

* **告发与诛除**

    * 与宇文泰地位齐平的八柱国赵贵不满晚辈宇文护大权独揽，谋除之；同样位重权高的独孤信力劝收手；开府仪同三司宇文盛将密谋告发。

    * 赵贵入朝觐见时被伏兵当场抓捕诛杀；独孤信受牵连免官，不到一个月被赐毒酒自尽。

* **过渡完成**

    * 诛杀八柱国中地位最高的赵贵、独孤信，标志政权内部完成了由西魏勋贵联盟到北周宇文氏集权的过渡。

### 宇文觉之死

* **近臣挑拨**

    * 十六岁的天王宇文觉性格刚果，忧虑宇文护专制；宇文泰旧幕僚李植、孙恒联合宫伯乙弗凤、贺拔提轮番进言：宇文护将不守臣节，且自比周公——「周公摄政有七年之久，陛下安能坐以待毙？」

    * 宇文觉暗中在皇宫内组建武士、日常操练；李植又拉拢宫伯张光洛——宫伯是《周礼》天官属官，北周复古改制沿用此官名，掌管宫中侍卫。

* **告密与瓦解**

    * 张光洛把密谋暗告宇文护；宇文护外调李植为梁州刺史、孙恒为同州刺史以瓦解布局，并屡次阻止宇文觉把二人调回，表白心迹「天下至亲，无过兄弟……愿陛下勿信谗臣之言，疏弃骨肉」，疑虑始终未消。

    * 乙弗凤等谋趁宇文护进宫赴宴时动手，因张光洛在场再被告发；宇文护对宇文觉动起废帝之念。

* **废弑**

    * 宇文护令统管禁军的领军尉迟纲抓捕乙弗凤等人、解散宫内卫兵，派贺兰祥进攻、逼宇文觉逊位；又召集公卿议废宇文觉为略阳公、立岐州刺史宇文毓，百官只称「公家之事，敢不唯命是听」。

    * 李植、孙恒、乙弗凤、贺拔提尽皆被杀；逊位一个月后宇文觉也被诛杀——北周第一个被杀的天王；宇文毓即天王位，是为北周明帝。

### 归政试探与宇文毓之死

* **归政试探**

    * 559年正月宇文护上表归政：他废宇文觉时打的旗号是「废昏立明」，如今宇文泰长子宇文毓已26岁，必须还权才能维持忠君体国的形象，更要借机观察皇帝的野心。

    * 宇文毓毫不推辞、自此亲理万机；宇文护的后手是交出的权力不含军权，并提议改都督诸州军事为总管，试图把地方实权再收归己手。

* **宇文毓反击**

    * 宇文毓身着甲胄出动天子六军举行盛大阅兵；随即任命六弟宇文直出镇蒲州、加大将军，5月授最受喜爱的四弟宇文邕大司空、封鲁国公、领宗师、参预政事并掌起草宣行诏令，宇文宪受封益州总管（都督益宁巴泸等二十四州诸军事、进封齐国公），另对19名勋贵官员赐封以笼络人心。

    * 8月宇文毓接受崔猷建议，由天王改称皇帝——提拔宗室、笼络勋贵、正式称帝，加强皇权压制权臣的目的呼之欲出。

* **毒杀与遗诏**

    * 560年4月，宇文护指派膳部中大夫李安在宇文毓膳食中投毒。

    * 宇文毓弥留之际留遗诏「朕子年幼，未堪当国。鲁公宇文邕，朕之介弟，宽仁大度，海内共闻，能弘我周家，必此子也」——长子宇文贤才刚一岁，传位十八岁的宇文邕以防大权再落宇文护之手；一天后宇文毓去世，年仅27岁。宇文邕登基，是为北周武帝。

## 乾明之变

### 政变前夜

* **乾明之变**

    * > **定义**：公元560年（北齐乾明元年）由高演、高湛策划、太皇太后娄昭君背书的宫廷政变——宗室勋贵一举摧毁汉人辅政集团，废高殷立高演。

    * 高洋临终任命尚书令杨愔、领军大将军高归彦、侍中燕子献、黄门侍郎郑颐四人辅政；百官大声嚎哭，却除杨愔外无一人流泪。

* **辅政格局**

    * 十五岁太子高殷即位；高演、高湛以叔辈身份手握大权，反成皇权最大威胁。

    * 四名辅政中仅高归彦是宗室，杨愔等三人皆汉人——受胡汉分治影响，汉人在北齐始终无法染指军权，要保住自身与皇权就必须争夺宗室手中的权力，皇权与宗室的矛盾由此又添一条。

* **娄昭君的偏向**

    * 高洋葬礼期间高演居宫中理事，娄昭君本就想立高演；高殷即位后朝政悉由高演决断，宗室勋贵在主少国疑之下纷纷向高演靠拢。

    * 领军大将军可朱浑天和进言「若不去二王，幼主无自安之礼」；燕子献密谋把太皇太后娄昭君移置北宫、由太后李祖娥出面主政。

* **杨愔出招**

    * 高殷按惯例赴晋阳安抚勋贵前，杨愔令总管禁军的高归彦秘密安排五千禁军以防不测，并把留守晋阳的高演改为随驾返邺，防止其在晋阳与勋贵结盟；又改革封爵，扭转高洋后期封爵泛滥、凸显皇权独尊。

    * 急躁的打压适得其反：被夺封爵者与斛律金、贺拔仁等晋阳勋贵纷纷投向二王；高归彦因杨愔瞒着他调动禁军而分道扬镳，常将杨愔等人行迹暗报高演。

* **李昌仪告密**

    * 杨愔计划外放二王为地方刺史，怕高殷不准径直禀报太后李祖娥；李祖娥与同姓的李昌仪（高仲密之妻、后为高澄纳入府中）关系密切，将密谋相告，李昌仪转头密报娄昭君——二王由此得知杀机。

### 尚书省之变

* **宴会擒拿**

    * 杨愔等改任高湛出镇晋阳、高演留邺城，二王欣然领命；尚书省就职仪式大宴百官时，郑颐劝「情势尚不明朗」，杨愔坚持「吾等至诚体国，岂可常山王拜职而有不赴之理」。

    * 高湛连敬两杯酒即令埋伏在后室的家仆冲出按倒殴打杨愔等人；杨愔流血满面大呼「诸王反逆，欲杀忠良也！尊天子、削诸侯，赤心奉国，何罪之有」；燕子献力大挣脱，被斛律光追擒；郑颐在尚药局被抓；高演、高湛、高归彦、贺拔仁等自云龙门闯宫，不从者皆杀。

* **昭阳殿对峙**

    * 昭阳殿外有禁军甲士两千余人，只待高殷一声令下即可勤王；因手刃囚徒落下的口吃在紧急关头加重，高殷根本无法言语，禁军将领娥永乐（深得高洋器重）扣刀仰视苦等无命。

    * 娄昭君以太皇太后之名两次厉声呵斥禁军，娥永乐含泪收刀入鞘，殿内禁军全部退出。

    * 高演跪陈「杨愔等欲独擅朝政、威福自己……若不早图，必为宗社之害」，自称并无废帝之意、只求驱除威胁；面对「何不安慰尔叔」的追问，口吃的高殷说不成句——天子尚且不敢向叔父乞求，杨愔等人任凭叔父处分。

* **两副面孔**

    * 娄昭君先问「杨郎何在」，闻杨愔被打出一只眼球而叹「杨郎何所能为，留之岂不佳也」，随即话锋一转斥其为逆贼：「此等逆贼欲杀我二子，次将及我……岂可使我母子受人摆布！」

    * > **提示**：先惋惜杨郎、后厉声斥逆贼的两副面孔，正是政变和平收场的幕后推手——既保住女婿杨愔的体面（从府库取黄金铸成眼球放入其眼中），又为二王清君侧给出名分。

### 定性与影响

* **人事洗牌**

    * 杨愔等尽数斩杀；高演进位大丞相、都督中外诸军事、录尚书事，高湛为太傅，京畿大都督段韶为大将军，高归彦为司徒，高淹为太尉，高浟为尚书令——宗室勋贵完全掌控朝局；高演移驻晋阳，军国大事由晋阳遥控裁决。

    * 五个月后（560年8月），娄昭君终于废高殷、立二十六岁的高演为帝。

* **定性**

    * 表面上是鲜卑集团对皇帝重用汉人的不满、历来被当作北齐第一次大规模胡汉冲突；实质是北齐在皇权集中路上与宗室勋贵集团的又一轮交锋。

* **后遗症**

    * 汉人士族遭重创：连高演的心腹幕僚、汉人王晞，也因宗室对汉人门阀的残酷报复从此不敢参与机要，整个河北汉人集团对北齐态度转冷。

    * 皇帝视角下，宗室勋贵在政变中展现的巨大势力使此后历代北齐皇帝将其列为重点防范对象，不断猜忌屠杀宗室与晋阳勋贵，北齐内耗严重、国力衰落。

## 高洋的堕落与死亡

* **高岳之死**

    * 平秦王高归彦自幼由清河王高岳抚养而恩情甚薄，得高洋重用后进谗，高洋从此防备高岳。

    * 高洋夜游歌舞伎薛氏家，其姐趁机为父求司徒一职，被当场吊起锯杀；高洋怀疑好色的高岳与薛氏有奸情，赐毒酒杀高岳；后又斩薛氏，把首级藏入袖中赴宴当众抛出，用她的大腿骨做成琵琶，满座愕然失声；事后又称「家人难再得」，收拾遗骸、披发痛哭而去。

* **黑衣谶言**

    * 高洋信术士「亡高者黑衣」之说，从此出门不见僧侣（僧衣为黑）；又问左右「何物最黑」得答「无过于漆」，以漆谐音「七」指向七弟高涣，下令征召，高涣被迫出逃。

* **司马消难降周**

    * 北豫州刺史司马消难娶高欢之女而夫妻不睦，其妻常向高洋抱怨；高涣出逃后人们猜测他去了虎牢，被派去视察的使者恰与司马消难一家不和，一到便控制其典签家僮；司马消难察觉凶险，暗中向北周请降。

    * 北周派达奚武、杨忠率五千经小路赴虎牢；中途音讯断绝，达奚武两度下令撤退，杨忠坚持率一千骑进抵关下，从关内打更声判断有变，待内应开城才冲入；北齐二千甲士戍守东城交战，达奚武认定难克难守，劫掠后携司马消难西撤，杨忠率三千骑断后从容班师，达奚武叹「我达奚武自认是天下健儿，今日服矣」。

* **太子高殷**

    * 高洋嫌太子「得汉家性质，不似我」；为锻炼勇武逼高殷手刃囚徒，高殷几番迟疑不忍下手，遭马鞭重击，十来岁惊吓过度，从此口吃、精神昏扰。

    * 高洋多次醉酒扬言「太子性懦，社稷事重，终当传位常山王」；六弟高演因屡屡劝谏被施以刑罚，险些丧命。

* **财政窘迫**

    * 北筑长城、南服萧庄政权使兵马劳顿、死者数十万，加上不间断的大兴土木，北齐府库迅速见底；高洋不开源只节流：减百官之禄、撤军人廪给、并省州郡县镇戍之职；官员审讯置法律于不顾、滥加酷刑，冤假错案大量出现。

* **诛高德政**

    * 辅佐高洋登基的高德政劝谏无果称病避祸；欲独揽大权的杨愔进言「陛下若用高德政为冀州刺史，病当自愈」，高德政以为可外避祸端而喜笑颜开，反触怒高洋——被召入宫「治病」，小刀割身、拖出殿外斩足，行刑的故交刘桃枝不忍下手，被斥「再不动手，你自己的头就要落地」，只得斩断三根脚趾。

    * 次日高德政之妻把府上财货堆放厅堂、准备寄存亲族家，恰逢高洋造访；查明是元魏宗室为求活命所送的贿赂后，高德政夫妻被杀。

    * 此前高洋已在崔暹府上吊唁时手起刀落斩其遗孀李氏——只因李氏答「想念」亡夫，便被令「自己过去见崔暹」。

* **元氏灭族**

    * 高洋问特进彭城公元韶「汉光武何以中兴」，元韶答「因为王莽没有杀尽刘氏一族」；高洋遂将元氏一族无论男女老幼七百二十一人尽数杀害、尸体投入漳水，元韶最终饿死狱中；下游百姓因鱼腹中发现人的指甲，很长时间不再食鱼。

* **临终与身后**

    * 559年11月，长期酗酒的高洋病危，对李祖娥言「人生必有死，何足致惜。但怜高殷年幼，他人将夺之耳」，又嘱高演「江山任你夺去，但勿杀高殷」；随后病逝，享年三十岁。

    * 回顾高洋当年：在杨愔、高德政等汉人士族策划下，借手握晋阳重兵的表弟段韶之力完成率军入邺、改朝换代；此后一面拉拢晋阳勋贵、一面提升高氏宗亲与汉人士族限制勋贵军政大权，去世时宗室已掌握大部分军政实权——幼主高殷面对叔辈权宗，皇权与宗室之矛盾成为北齐新的乱源。

## 解毒高洋：皇权与勋贵的棋局

### 二元权力结构与霸府

* **四大利益团体**

    * 534年高欢立元善见建东魏；高欢集团内部细分为六镇豪帅、河北世家、洛阳胡汉贵族、尔朱荣残部四大利益团体，鲜卑人占据明显主导。

* **晋阳遥控邺城**

    * 高欢把分散河北的六镇流民收拢到以晋阳为核心的区域并行胡汉分治，士兵绝大多数是鲜卑人，形成晋阳军事力量遥控邺城朝廷的二元结构。

    * ```text
        晋阳（军事中心）              邺城（朝廷所在）
    ┌────────────────┐          ┌────────────────┐
    │ 六镇勋贵集团    │          │ 汉人文官系统    │
    │ 外兵省·骑兵省   │  遥  控  │ 尚书省等政务    │
    │ 鲜卑族军队      │ ───────→ │ 崔暹·崔季舒等   │
    └────────────────┘          └────────────────┘
     军权在这里（称帝前）      政务在这里
      ```

* **霸府**

    * > **定义**：霸府——权臣不居朝廷官署、以晋阳为基地组建的私人权力中枢；称帝即意味着霸府解散、权力收归皇帝。

* **一荣俱荣**

    * 高欢与六镇豪帅不是严格的主仆关系，而是靠个人威望建立的一荣俱荣关系网；高欢为大丞相，侯景、孙腾、司马子如等官至司徒、领军将军、尚书令，六镇豪帅随之晋升为六镇勋贵集团。

### 装傻与接班

* **兄弟眼中的呆子**

    * 高欢十五子中，长子高澄与老三以下诸子几乎都获正面评价；唯独二子高洋，兄弟眼中一副呆傻模样——《北齐书》《北史》则称他外表平庸、内心聪明。

* **快刀斩乱麻**

    * 高欢以一堆乱丝测试诸子才能，高洋以「快刀斩乱麻」解题获赞；此后却长期表现呆傻——次子受长子高澄猜忌，为求保全不得不隐忍、刻意隐藏才干，直到高澄遇刺。

* **威望赤字**

    * 高澄遇刺时，高洋正任邺城领军将军、尚书令、中书监、京畿大都督，老臣推其主持大局；高洋收起伪装、处变不惊，稳住邺城局势。

    * 接班后第一件事是拉拢勋贵集团——所谓「政令不便者」，正是高澄打压权贵贪污的那批政令。

    * 装得太好适得其反：兄弟与六镇勋贵都认定他平庸，掌握晋阳霸府之初威望不及高澄，难获勋贵全心支持。

* **高澄遇刺悬案**

    * 高澄借陈元康献策摘取颍川战功以资威望、暂稳人心，正欲把目光投向皇帝宝座时，被兰京刺杀身亡。

    * > **易错点** ⚠️：「高洋是幕后主使」只是因高澄死后他立刻继任而生的猜测，受存世史料限制已成悬案，各方推测都不能认定为历史真相。

### 称帝豪赌

* **赌注**

    * 称帝意味着高氏与六镇勋贵从盟友变主仆：霸府解散、权力收归皇帝、勋贵降为臣子——在勋贵眼中，一个看着长大的庸才要登基并重新分配权力，回答当然是否定的。

* **娄昭君反对**

    * 高洋表示要逼元善见禅位时，母亲娄昭君斥责：「汝父如龙，汝兄如虎，犹以天位不可妄据，终身北面；汝独何人，欲行舜禹之事乎！」

* **汉人文官押注**

    * 支持称帝的高德政与被其劝动的杨愔都是汉人文官：他们此前在晋阳霸府中仅居从属地位、在勋贵监控下处理政务，唯有依附皇权，才能趁勋贵地位下降进位到与之平等的臣席。

    * 高洋靠这股力量找到了对抗勋贵集团的支持，完成改朝换代。

* **有限胜利**

    * 高洋撤销晋阳霸府，但保留相府外兵曹、骑兵曹改称外兵省、骑兵省——军事大权仍被六镇勋贵集团掌控。

### 灭魏搁浅与性情突变

* **灭魏大计搁浅**

    * 高洋的规划：驱逐柔然、突厥等外患，平定山胡等内忧后讨灭西魏、完成北方统一；但调动全国军力的阻力十分强大——军队将领统鲜卑士兵，北齐主要军事力量在晋阳勋贵之手。

    * 勋贵的算盘：东西实力已从东强西弱转为持平，举倾国之力伐魏风险太大；且只要西魏存在，晋阳军事中心的地位与战功勋贵集团的利益就能长久维持。

    * 556年北齐攻建康屡屡受挫，军事层面的不得力促使高洋更加倚重宗室与汉人士族加强皇权。

* **胡风与礼法的冲突**

    * 高洋本人崇尚胡风；重用汉人后，汉人大臣以儒家礼法约束劝谏，引起他强烈反感。

* **性情突变的三种解释**

    * 自555年、556年（天保六年、七年）起，高洋从英雄天子的巅峰滑向纵酒暴虐。解释一：李百药《北齐书》认为是功业有成后的倦怠与放纵；解释二：今日普遍猜测高欢与娄昭君的诸子可能患有精神疾病；解释三：结合成长经历的心理分析——自幼被迫装傻求活、得势面对满朝质疑、拼尽全力仍未改变格局，遂以纵酒自我麻醉、以暴虐刑法彰显权力。

    * > **易错点** ⚠️：三种解释没有一个盖棺定论——史料只证明高洋变了，没证明他为什么变；把「前明后暗」归因于单一理由，恰恰是最容易犯的错。

### 皇权与勋贵的长期矛盾

* **历史趋势**

    * 古代政治的趋势之一是地方不断集权于中央、中央不断集权于皇帝；高欢、宇文泰代表的后六镇权力模式，在两家迈向称帝时必然被打破——皇权集中与勋贵分权是一对难以调和的矛盾。

    * 西魏宇文氏借府兵制等改革使自身地位独尊，仍免不了诛杀赵贵、独孤信以绝后患。

* **比例递减**

    * | 时期 | 勋贵集团担任诸公官职的比例 |
      | :--- | :--- |
      | 高欢去世时 | 45% |
      | 高洋时期 | 33% |
      | 公元569年 | 12% |

    * 北齐通过任用宗室和汉人门阀的方式不断抑制六镇勋贵集团。

* **联姻绑定**

    * 宗室与勋贵常有联姻惯例，部分宗室利益与勋贵集团绑定；北齐后期六镇勋贵、皇帝、宗室三者间的冲突以胡汉矛盾的形式频繁爆发，国力在一场场内斗中消耗，最终灭亡于北周。

## 南梁落幕：芜湖之战

* **王琳东进**

    * 559年10月陈霸先死讯传至郢州，南梁丞相王琳亲率大军东进抵栅口，北齐自寿阳派军进抵长江北岸声援；11月王琳攻大雷，陈蒨派侯瑱、侯安都、徐度抵御。

    * 南陈安州刺史吴明彻夜袭湓口实施绕后，被王琳麾下巴陵太守任忠击败，仅以身免。

* **相持与偷袭**

    * 王琳屯濡须口之南、陈军屯芜湖，相持百余日，王琳始终无法突破防线；北周获知王琳东进，立即出兵围攻其大本营郢州，王琳军人心溃散。

* **西南风与火攻**

    * 江面刮起西南风，王琳率主力顺风而下直指建康；侯瑱舰队自芜湖西面出发，顺着风向咬在王琳身后，王琳再度陷入被动。

    * 情急之下王琳动用火攻，火势逆风刮回烧了自己的舰船；侯瑱趁势猛攻，梁军舰队连同岸上北齐军大败，王琳乘小船突围逃回湓城，收拢部队无人响应，只得携家人逃往北齐。

* **南梁终结**

    * 南陈乘胜西进；北周围郢州已克外城、内城难下，见陈军大部袭来退军；留守的南梁官员把小皇帝萧庄送往北齐，举城投降——南梁在长江以南的割据政权彻底灭亡。

    * 自502年萧衍入主建康到557年陈霸先受萧方智禅位，南梁帝国共55年。

* **陈昌沉船**

    * 北周突然放归陈昌；陈昌致陈蒨的文书措辞傲慢；陈蒨故意从容言道「太子将要归国，我须求封一处藩国作为归老之地」，侯安都答「自古岂有被代天子！臣不敢奉诏」。

    * 百官心领神会上表请赐封爵；陈昌受封骠骑将军、湘州牧、衡阳王，一个月后船行长江中心突然去世，奉命迎接的侯安都报告溺水身亡，事后加封清远郡公。

## 湘州对峙：贺若敦的粮堆诡计

* **背景**

    * 556年王琳趁陈霸先平定江州派兵占据湘州，南陈与其长期争夺；558年江陵西梁政权趁王琳重心东移夺取长沙、武陵、南平等地；王琳败亡后侯瑱率军西进，逼近巴、湘二州。

    * 北周司马贺若敦屯湘川、独孤盛屯杨叶洲水陆救援，侯瑱驻军巴丘山。

* **粮堆诡计**

    * 雨季洪水围营、粮草短缺，贺若敦一面派兵劫掠补充军需，一面命士兵营中堆土、以所剩不多的粮食覆顶，造出「粮食堆积如山」的假象；再借村民入营打听消息之机，让其看到粮堆。

    * 侯瑱从周边居民处得知「北周大军粮草充足」，加上贺若敦不断加固营垒，不敢贸然进攻。

* **伪装民船**

    * 巴州、罗州当地人常用船载米粟鸡鸭资助陈军；贺若敦命士兵藏身船内伪装当地船只，待陈军靠近接收物资时突然冲出——陈军从此不敢再接受任何资助。

* **僵持恶化**

    * 僵持到冬天，侯瑱攻杨叶洲迫独孤盛退军上岸筑城自保；陈蒨再派侯安都增援；巴陵城内北周守将投降，独孤盛率水军经洞庭湖撤离，留下贺若敦部六千人对峙；三个月后湘州也降南陈，贺若敦处境更艰。

    * 长期缺粮使贺若敦部六千人减员已达十之五六。

* **体面北返**

    * 侯瑱提出和谈：撤围并提供船只放贺若敦北返；贺若敦顾虑对方施诈（当年王僧辩便用此招骗杀宋子仙），但僵持下去必是死局，遂约定「湘州归还退走，但须退兵百里之外」，侯瑱留空船领军后撤，贺若敦得以北还。

    * 陈军随后西进连克武陵、天门、南平、义阳、河东、宜都；宇文护认为贺若敦损兵失地，将其贬为平民。

## 高演高湛兄弟阋墙

* **高演新政**

    * 高演登基后大刀阔斧革除高洋后期的社会积弊，并听尚书左丞苏珍之等谏言，在淮南、河内、平州等地屯田——北齐南、中、北三面军旅粮草自此自足。

* **太弟之诺落空**

    * 乾明之变时高演曾许诺事成立高湛为太弟，事后却立子高百年为太子，并把高湛的心腹调任外地削弱其实力；高湛压下教令拒不奉行。

* **高元海三策**

    * 高演闻邺城有天子气，派高归彦接废帝高殷赴晋阳；高湛误以为要对自己动手，问计高元海——高元海先以「皇太后万福，陛下孝友异常」的场面话搪塞，被关后堂一夜后给出三策。

    * 上策：效仿西汉梁孝王刘武，带禁兵亲赴晋阳谒太后、见主上，主动交出兵权、保证至死不过问政事，必保泰山之安；中策：上表自陈威权太盛恐招诽谤，请求外任青、齐二州刺史，从此不生二心；下策（高元海自认一说出口恐招灭族之祸）：召集邺城文武百官，拿出废帝高殷的敕令，逮捕皇帝一党、斩高归彦，拥立高殷复位、号令天下以顺讨逆。

    * 高湛对前两策不屑，闻下策反而大喜；但性格怯弱不敢起事，占卜皆不吉，只得放弃，乖乖送高殷赴晋阳。

* **高殷之死**

    * 高殷到晋阳后，被高演毒杀。

* **高演之死与传位**

    * 高演出城打猎坠马伤肋、生命垂危；娄昭君探病问高殷所在，高演面露愧色迟迟不答，娄昭君怒斥「杀之矣！不用吾言，死其宜矣！」转身离去——高洋临终「勿杀高殷」的嘱托与扶持高演登基前的叮嘱，终究败给权力。

    * 高演羞愧中下诏传位长广王高湛，遗书嘱「百年无罪，你可任意处置，但不要效仿我而杀他」，当天去世，谥号孝昭皇帝。

    * 高湛疑心这是引蛇出洞，遣使开棺验尸后方赴晋阳登基，是为北齐武成帝。

* **高归彦失势**

    * 高归彦因乾明之变表现突出受高演器重，高湛登基后升太宰、冀州刺史；因骄恣专横、广结亲贵，被高元海等以「威权震主」进言，诏令赴冀州、宫门卫兵不许其入宫；当日纵酒大醉，次日欲进宫被拦才察觉有变——旧臣退场，高元海、和士开等靠阿谀奉承升迁的新臣自此成为北齐内耗的新力量。

## 侯安都之死

* **地方割据**

    * 表面统一的南陈，地方上仍有名义服从建康、实则拥兵割据的势力，实力较大者为江州刺史周迪、缙州刺史留异、闽州刺史陈宝应，三者暗中勾结、待机反叛。

* **周迪攻周敷**

    * 豫章太守周敷一心拥朝廷、率先赴建康朝见受褒奖，惹恼上司周迪；周迪攻豫章被周敷击败，又谋派兵伪装商船袭湓口，未及出动消息已走漏。

* **陈蒨的忌惮**

    * 百官建言由鹰派侯安都征讨周迪（侯瑱去世后他确是最佳人选）；但侯安都自拥立陈蒨后日益骄横——拥立之功常挂嘴边、借取皇帝仪仗、自己坐在主位，陈蒨对他越发忌惮。

* **分兵平叛**

    * 陈蒨改派吴明彻为江州刺史，率高州刺史黄法氍、豫章太守周敷讨周迪；侯安都被派往缙州征讨留异；陈蒨同时暗中从侯安都的部下入手搜集罪证。

* **桃枝岭之战**

    * 留异料定侯安都会从钱塘走水路，侯安都却由诸暨直袭永康，令留异江边部署全部落空；留异逃桃枝岭筑城固守（地形险峻、易守难攻）。

    * 侯安都身中流矢仍坚持指挥；趁大雨山洪抬升水位修造舰船，使船楼与城墙齐平，舰船猛烈撞击下留异营垒大溃，父子投奔陈宝应。

* **周迪败亡**

    * 吴明彻攻临川久不能克，改派刚归国的安成王陈顼接替围困；至563年正月周迪无力支撑，弃城南下投奔陈宝应。

* **蔡景历举报与赐死**

    * 两面战事结束，侯安都才察觉陈蒨的防备，嘱托别驾联络舍人蔡景历打探朝廷动向；蔡景历转头举报他拉拢朝臣、图谋不轨。

    * 陈蒨怕直接召其来建康引起警觉，趁江州平定改任侯安都为江州刺史；侯安都屯军石头、入建康谢恩，在嘉德殿会面时被逮捕，部将在尚书省被集体缴械；蔡景历拿出罪证后治罪，次日赐死。

## 高湛的疯狂与联军压境

* **高湛恶行**

    * 娄昭君去世时高湛不着丧服、不举哀；以李祖娥之子为要挟逼其就范并生下一女；李祖娥弃养女婴，高湛当其面殴杀其子高绍德，再把她送妙胜寺出家。

    * 和士开、高元海等近臣内斗不止，还将矛头对准劝谏的宗室，北齐朝堂混乱不堪。

* **周突联盟**

    * 北周使者与突厥木杆可汗阿史那俟斤达成联姻计划、共同伐齐；北齐立即携重金几乎买动俟斤毁约转与北齐联姻，多亏北周使者杨荐据理力争，联盟方得维持。

* **杨忠请战**

    * 宇文邕召集公卿议方略：群臣认为北齐据半壁天下、国富兵强，自漠北入并州极为险阻、斛律光未必可当，非十万不可；柱国杨忠立断「兵贵精而不在众，一万足矣；斛律光竖子，亦何能为！」

    * 宇文邕令杨忠领一万骑兵走北路、达奚武领步骑三万出平阳走南路，约定晋阳会师；杨忠连克北齐二十余城，与南下的突厥十万大军会合后兵分三路南下。

* **兵临晋阳**

    * 564年正月北周大军兵临晋阳城下；高湛自邺城带兵救援，临阵畏敌，甚至想带宫人东逃——沉寂许久的东西大战再度擂响战鼓。

## 晋阳解围与高湛杀侄

### 雪地解围

* **止退与授权**

    * 高湛见周突兵势强盛萌生退意，赵郡王高睿等拦马劝阻，遂令高睿统率六军、并州刺史段韶总管军事；斛律光领军三万屯驻平阳，抵御南面的北周达奚武部。

* **眼中有铁**

    * 突厥可汗阿史那俟斤到晋阳城下，见齐军军容齐整、富有斗志，归营埋怨北周使者「尔言齐乱，故来伐之。今其人眼中亦有铁，何可当也！」——开打之前信心已经动摇。

* **以逸待劳**

    * 北周以步兵为先锋自西山而下、距晋阳二里列阵；诸将请战，段韶以「不足」拒之：对方是步兵、形势于我有利，积雪深厚迎战不利，宜坚守待劳——彼劳我逸，破之必矣。

    * 周军踏着数尺积雪艰难抵达晋阳城门，北齐守军集中精锐突然擂鼓杀出；俟斤引军退上西山不肯策应，失去援军的北周大军惨败而归。

    * 突厥随即北还，沿途七百余里烧杀抢掠、人畜无遗；段韶率军追击，直至塞下才班师。

* **鸿鹄信**

    * 达奚武屯平阳尚不知杨忠已败；斛律光致信「鸿鹄已翔于寥廓，罗者犹视于沮泽」，达奚武读信即退兵；斛律光趁势反攻，劫掠北周人口两千余返回晋阳。

    * 高湛抱着斛律光大哭，直到任城王高堦进言「何至于此」才止住。

* **攻守易势**

    * 高洋执政初期北齐军力强盛、四方征伐未有不服，每当入冬西魏要凿碎河上冰面防备北齐西进；如今北齐朝政腐败、东西攻守易势——每年凿冰防备的换成了东面的北齐，而北齐皇帝对此危机毫无察觉。

### 高湛杀侄

* **敕字引祸**

    * 天象接连异常，深信天象的高湛竟准备杀侄高百年化解；恰逢教高百年写字的先生，把高百年无意写下的「敕」字（帝王专属御用字）呈奏高湛，杀机更盛。

* **玉玦诀别**

    * 高百年自知凶多吉少，把随身玉玦交给妃子斛律氏诀别；高湛令其再写「敕」字、比对确认笔迹后暴怒，令左右在殿内边拖拽边殴打，九岁的高百年血流遍地，奄奄一息仍哀求「愿与阿叔做奴」，仍被斩杀、扔进水池、葬于玄都苑。

* **斛律氏之死**

    * 斛律氏绝食自尽，死时手握成拳无人掰开，直到斛律光前来才打开——掌中正是高百年的玉玦。

## 邙山之战

### 二十万大军

* **邙山之战**

    * > **定义**：564年冬北周宇文护征发二十万大军分三路攻洛阳、北路先溃，北齐段韶、高长恭、斛律光在邙山反击大破周军的战役——北齐大获全胜，兰陵王因此战扬名。

* **出兵缘由**

    * 564年8月北周柱国杨忠再次与突厥合兵攻齐；高湛提出送羁留晋阳的宇文护之母赴长安换退兵——生性孝顺的宇文护迎回35年未见的母亲，杨忠班师，宇文护本打算短期停止对齐用兵。

    * 已结盟的突厥先后两次催促北周进兵；宇文护担心毁盟使突厥倒向北齐，只得征发二十四军府兵、左右厢军、秦陇巴蜀之兵与羌胡内附者共20万，亲率进抵潼关。

* **三路部署**

    * 十月兵分三路：中路尉迟迥领精锐十万为先锋攻打洛阳；南路权景宣率山南之兵攻打悬瓠；北路杨檦出轵关，阻断北齐晋阳向洛阳的救援。

* **杨檦败亡**

    * 北路的失败来得最快：杨檦此前镇守邵州与齐交兵未尝败绩，此战轻敌深入不设防，遭北齐太尉娄睿进攻大败、投降北齐——晋阳通洛阳的道路重新打开。

* **围洛阳与致命疏忽**

    * 周军垒土山、挖地道，围洛阳三十余日不克；宇文护得知杨檦败讯后命人切断河阳通洛阳的道路，投入大军精锐全力攻城。

    * 各军自恃人数众多、认定齐军不敢来犯，四周只安排斥候部队——这个疏忽即将要他们的命。

### 决战邙山

* **段韶南下**

    * 高湛先派兰陵王高长恭、大将军斛律光援洛阳，二人见周军众多，屯邙山不敢向前；轵关通道打开后，段韶以「北虏侵边，事如疥癣；今西羌窥逼，便是膏肓之病」自请南行，率精锐骑兵一千五天渡河抵洛阳。

* **太和谷遭遇**

    * 连日阴雨中，段韶率两百骑至邙山侦察周军，行至太和谷与周军迎面遭遇，急令集结：段韶自领左军、高长恭领中军、斛律光领右军。

    * 周军以步兵攻山，段韶且战且退消耗其登山的体力；待周军精疲力竭，北齐左中右三军齐出，周军溃败，跌入山谷、投水而死者不计其数。

* **高长恭入阵**

    * 高长恭率中军五百骑突入周军围城部队，直冲至金墉城下；守军认不出来人，高长恭脱下头盔示明身份，守军派弓箭手出城反击周军。

* **王雄之死与溃退**

    * 前锋一败，军事才能平平、本无意此征的宇文护自乱阵脚慌忙撤退，邙山至谷水三十余里堆满丢弃的军械营帐。

    * 断后的宇文宪、达奚武、王雄中，王雄追击身边只剩一名奴仆一支箭的斛律光、一心生擒，反被一箭射中额头伤重身亡；周军营中人心惶惶，宇文宪想整军再战被达奚武劝阻，北周退军。

    * 南路权景宣虽攻克悬瓠，闻北、中两路皆败只好弃城退回；北路的杨忠也随后退兵。

### 战后

* **兰陵王入阵曲**

    * 邙山之战北齐大获全胜；高长恭麾下武士创作《兰陵王入阵曲》纪念此战大功。

* **封赏**

    * 段韶升任太宰，斛律光为太尉，高长恭为尚书令。

## 南陈平叛与陈顼篡位

### 周迪与陈宝应

* **诱杀周敷**

    * 逃亡闽州的周迪再集军队，由东兴起兵攻克宣城；南豫州刺史周敷在定川与之对峙，周迪以「吾昔日与你戮力同心……我愿认罪还朝」相邀、请求先共同盟誓；周迪在江州深得人心，周敷信其言赴营，登台之际被拔刀斩杀。

* **章昭达破陈宝应**

    * 护军章昭达屯闽水上游讨伐陈宝应；趁天降大雨河水暴涨，把所有木筏推入水中借水势一举冲破其木栅防线，跟进猛攻；混战之际余孝顷自海路抵达夹击，陈宝应前后受敌大败逃往浦口，与留异一同被擒、送建康斩首。

    * 半年后独木难支的周迪被陈军击败，逃入山林，为武士所杀，传首建康。

### 陈蒨托孤

* **五人顾命**

    * 566年3月陈蒨病重，先以国事付尚书仆射到仲举、五兵尚书孔奂；病情加重后召集到仲举、孔奂、安成王陈顼、吏部尚书袁枢、中书舍人刘师知五人托付后事——太子陈伯宗年仅15岁。

* **兄终弟及试探**

    * 陈蒨先向陈顼表示想传位于弟，陈顼流涕叩拜不肯从命；又对到仲举、孔奂说想效仿晋成帝传位其弟与殷商兄终弟及的故事，孔奂流泪回应：太子春秋鼎盛、圣德日积，安成王有介弟之尊、尊为周公辅佐即可，「若有非礼之心，臣等必以死相抗」。

    * 陈蒨去世，时年45岁，谥号文皇帝；陈伯宗即位，陈顼进位骠骑大将军、司徒、录尚书事、都督中外诸军事。

### 陈顼的清洗

* **矫诏风波**

    * 不到一年辅臣矛盾爆发：刘师知联合到仲举、东宫通事舍人殷不佞等，派殷不佞假传敕令「今四方无事，安成王可回东府经理州务」；陈顼被突如其来的命令打乱阵脚，茫然欲从命。

    * 毛喜点醒：陈朝初立祸患不断，大王入宫总揽政务出自太后深思熟虑，「今日一旦出外，从此将受制于人」，并举曹爽想做富家翁而三族被灭为例。

    * 陈顼称病不出，一边召刘师知闲聊，一边派毛喜求见太后确认未曾下过此令、再觐见陈伯宗——皇帝答「此是师知等所为，真不知也」；陈顼当场囚禁刘师知，入宫弹劾并让皇帝签署诏命，当夜赐死刘师知，殷不佞等治罪，到仲举被夺职归家。

* **韩子高之死**

    * 右卫将军韩子高手握建康城内兵力最多的一支军队；陈顼疑其参与密谋，毛喜却反请增其兵马钱粮使其安心——先帝陵寝初定、边寇尚多，此时收之恐其不认罪或激祸患，应推心安处、伺机图之，届时一壮士便能拿下。

    * 韩子高惶惶上书求外任杭州、广州而无批复；到仲举每回穿女装、乘小轿与其密会商议；行迹被告发后，陈顼以尚书省商议立太子为名诱二人赴会，入省即被逮捕——还是同样的套餐，赐死狱中。

* **华皎之乱与郢州水战**

    * 湘州刺史华皎参与密谋，闻韩子高死讯自知难保，笼络人心并向北周、西梁求援；陈顼看破其心思，表面同意调任广州，实则任吴明彻为湘州刺史、领军三万入郢州、增兵五万为后援，另遣杨文通攻茶陵、黄法慧攻醴陵。

    * 北周遣襄州总管宇文直率权景宣等出兵，西梁遣柱国王操率两万，三方合兵东进：宇文直屯鲁山、华皎屯白螺与吴明彻对峙；另一支陈军在徐度带领下由陆路西进偷袭湘州，直捣华皎大本营。

    * 郢州城外水上决战：吴明彻先以小船消耗联军攻击器械，再以大船猛攻大破之；联军乘风势火攻反遭风向逆转，火船掉头冲向自己的舰船，三方联军兵势大溃；华皎、宇文直侥幸逃往江陵。

    * 吴明彻平叛后趁西梁新败北上围攻江陵，攻坚百余日不克，兵败退兵。

* **废帝自立**

    * 568年11月，陈顼彻底肃清朝野内外反对势力后，借太皇太后章氏之名污蔑陈伯宗参与刘师知、华皎等密谋，称此刻完成陈蒨当年欲传位陈顼的遗命；废陈伯宗为临海王，登基称帝，是为南陈孝宣帝。

    * 《陈书》对这场政变记载颇简；而当年在陈蒨面前信誓旦旦拥护陈伯宗的孔奂，在到仲举等人的密谋中隐身、清洗中未受波及，反在陈顼篡位前夕被外放江州任职、陈顼继位后更受赏识——结合这些细节回顾托孤场景，谁是真的、谁在演，更加清晰。

## 和士开与北齐佞幸集团

### 高湛之死与顾命

* **和士开其人**

    * 高湛获封长广王时（高洋天保元年），26岁的和士开入府任开府行参军；因说话好听、善迎合、又擅长高湛喜爱的游戏而成形影不离的玩伴；高湛登基后官至中书监，二人亲密已不似君臣、更像兄弟。

* **排挤徐之才**

    * 568年4月，身体在尚书左仆射徐之才治疗下渐有起色的高湛，被和士开判定「用不着了」；和士开将徐之才外放兖州刺史，自得尚书右仆射之位。

    * 此后半年高湛不遵医嘱、毫无节制地纵情酒色，旧疾复发；徐之才奉召急返，尚未入城高湛已死——时年32岁，谥号武成皇帝。

* **密不发丧**

    * 高湛临终认定和士开有伊霍之才，握其手嘱「勿负我也」；和士开成为顾命大臣却密不发丧，称要效仿当年高欢驾崩秘不发丧的旧例。

    * 黄门侍郎冯子琮点破他素与太尉高睿、领军娄定远不合，欲借机除掉二人，并警告陛下驾崩之事路人皆传、久而不举恐生变，和士开方才公布死讯。

    * 侍中、尚书左仆射元文遥担心身为太后妹夫的冯子琮借胡太后干政，说动和士开、高睿将其外放郑州刺史；冯子琮出局后胡太后越发倚重和士开，二人竟至私通。

### 北齐八贵

* **八贵名单**

    * 先帝托孤重臣、新君推戴功臣、太后情人三重加持下，和士开与司空娄定远、赵彦深、元文遥、唐邕、綦连猛、高阿那肱、胡长粲并称「北齐八贵」。

* **八贵内斗**

    * 八贵间随即爆发内斗，首先被集火的正是风头最盛的和士开：太尉赵郡王高睿联合宗室大司马高润、安德王高延宗，与八贵中的娄定远、元文遥，谋将其排挤出朝廷。

### 绝地反杀

* **宴席交锋**

    * 胡太后设宫宴时高睿当面数其罪状（先帝弄臣、受贿贪污、秽乱宫闱），太后回敬「先帝在时，王等何不说？今欲欺负我孤儿寡母也」，命散席改日再议；高睿等人有的拂衣而起、有的把头冠摔在地上。

    * 次日高睿等集于云龙门，令元文遥三次入宫进奏；胡太后求助左丞相段韶，以「先帝梓宫尚未出殡便突然罢免托孤重臣」劝退众人。

* **缓兵之计**

    * 和士开向太后献策：对高睿等称元文遥与自己「俱受先帝任用，既然要动，当一并外任」，暂保官爵、待梓宫安葬后再行遣发；任命传出（和士开兖州刺史、元文遥西兖州刺史），高睿等不再紧逼。

    * 梓宫下葬后和士开仍无动身之意；太后再拖称过百日祭再放人，高睿坚持立即外放、不再松口。

* **送礼演戏**

    * 和士开携两名美女、一套珠帘登门娄定远，自称蒙其保全得以外任、本志只求长为大州刺史；娄定远彻底放下警惕、收礼送客，还应允其入宫向太后辞行。

    * 和士开入宫即上演苦情戏：哭诉与陛下父子恩深天地，朝贵们的意思是想让陛下成为「第二个高殷」，臣出朝之后必有大变——太后慌乱问计，和士开称已入宫无虞，只需几行诏书。

* **两道诏书与高睿之死**

    * 两道诏书随即发出：一贬司空娄定远为青州刺史，一责赵郡王高睿不臣之罪；和士开复官侍中、尚书右仆射，宣告这场内斗的赢家。

    * 次日高睿执意入宫面见太后，家人与路人先后警示「恐有变」，他答「社稷事重，吾宁死事」「无上不负天，死亦无恨」；力争不欢而散，行至永巷被埋伏武士押至华林园，由北齐专事杀宗王的鹰犬刘桃枝拉杀。

    * 娄定远连忙送还美女珠帘、外加更多珍宝以求保命。

### 陆令萱登场

* **乳母出身**

    * 陆令萱因丈夫骆超谋反连坐，与其子骆提婆一同没入宫中为奴；被指派为高纬乳母后，凭察言观色获胡太后赏识，由底层婢女飞升至郡君、后宫独擅威福，后被加封女侍中。

    * 和士开、高阿那肱为攀附竟拜其为养子；骆提婆子凭母贵，整日陪高纬游戏玩乐，迅速升任开府仪同三司、护军大将军。

* **佞幸集团成形**

    * 高纬周围形成以和士开、陆令萱、高阿那肱、韩凤等为首的佞幸团体，彼此利益绑定、长期祸乱朝政，与北齐宗室朝臣争权不断。

## 祖珽沉浮

### 劝进传位

* **幸臣难题**

    * 祖珽早年凭一身才华与爱偷盗占便宜的癖好声名狼藉，高洋爱其才、任中书省主客郎；此时攀附和士开，抛出幸臣都要面临的最大难题：皇帝一旦去世，您依靠谁？

    * 计策：对主上进言文襄、文宣、孝昭之子已不可再继承大统，不如令皇太子高纬早登大位、以定君臣之分——事成则皇后、少主感恩，万全之计。

* **彗星定策**

    * 恰逢彗星出现，太史奏「除旧布新之象，应当换立新君」；祖珽深知高湛迷信，趁机上书称传位于太子正应天道。

    * 高湛以北魏献文帝拓跋弘传位孝文帝拓跋宏的故事，禅位于太子高纬。

### 正面刚与地牢

* **谋揭发事泄**

    * 567年祖珽因进言之功升秘书监，又暗与黄门侍郎刘逖联合，准备揭发昔日盟友和士开及赵彦深、元文遥的罪名、图谋宰相之位；刘逖不敢上书、祖珽自己也未上，事被密告赵彦深，三人抢先上报太上皇高湛。

* **当庭对骂**

    * 高湛诘问「何故毁我（们）」，祖珽当庭传奏三人多年来结朋党、弄权卖官、贪赃之事，末了补一句「陛下不以为意，臣恐大齐之业倾矣」。

    * 高湛斥其诽谤，祖珽反问：百姓挨饿，臣尚且收养其子女；陛下何不开仓赈粮，却把抢来的民女买入后宫？——气得高湛刀环击嘴、鞭杖乱下欲诛。

    * 祖珽以「不杀臣，陛下得美名；杀臣，臣得美名」并许诺为陛下炼制金丹暂保性命，却又自比范增、扬言张良都不如我（张良保太子尚须请商山四皓，我非辅政重臣却劝成禅位），并讥高湛凭父兄基业、未必轻视得起项羽——被用土塞嘴、鞭二百、配甲坊为奴。

* **地牢失明**

    * 祖珽被贬光州、关入地牢；服刑期间长期以芜菁子油照明，双目失明。

### 复起

* **重新起用**

    * 高湛死后，高纬想起这位昔日恩人，起用为海州刺史；祖珽又写信给陆令萱之弟、仪同三司骆提婆：赵彦深心腹深沉、欲行伊霍之事，「您姐弟又岂得平安？何不早用志士也？」

    * 陆令萱与和士开商议后认定祖珽是难得的智囊，不计前嫌、虚心以待；陆令萱趁高纬思念之际重提旧功，祖珽升秘书监、加开府仪同三司。

* **助诛胡长仁**

    * 祖珽加入后，和士开成功把高纬的舅舅、陇东王胡长仁赐死，进一步垄断自己在朝中的地位。

## 宜阳汾北拉锯

### 韦孝宽情报网

* **情报大师**

    * 北周柱国韦孝宽因玉璧之战名扬天下，北周武帝为其设勋州、任刺史；他借玉璧地处两国交界，大量培植间谍进入北齐、以财货收买人心，织成覆盖北齐朝野的情报网——北齐朝中一举一动，远在长安都了如指掌。

    * 效力印证：北齐降将许盆，韦孝宽只需一道命令，身在北齐的间谍便将其首级送到帐下。

* **筑城预警**

    * 宜阳战事胶着之际，韦孝宽写信提醒宇文护：当提早在汾水沿岸筑城，防备北齐转攻汾北；宇文护以没有合适人选驻守为由拒绝。

### 两年拉锯

* **斛律光的地位**

    * 斛律光是北齐股肱之臣，位高权重且为北周所忌惮；宜阳、汾北的战事正是由他独力支撑。

* **宜阳对峙**

    * 北周孔城防主被杀、起事者向北齐县城投降，齐公宇文宪领兵东进包围宜阳；斛律光率三万救援，多有斩获却不能退敌，双方对峙近一年。

* **斛律光经营汾北**

    * 斛律光由晋阳发兵，在汾水北岸先后修筑华谷、龙门等十五座新城，并在定阳城南新设南汾州，累计拓地五百里、尽收汾北；韦孝宽率军出击试图打破城垒防线，被斛律光击败、折戟而归。

* **互攻易位**

    * 北周调围攻宜阳的宇文宪北上支援汾水；他趁斛律光北进由龙门渡河东进、连克五座城垒，而斛律光攻克北周姚襄城；北周又趁斛律光南下之机以宇文纯攻克宜阳；斛律光率步骑五万南下，北周则在姚襄城南筑新城、挖长沟连通定阳。

* **段韶定阳**

    * 五月，带病的段韶进抵汾北，与姚襄城守军里应外合大破周军；六月转攻定阳，汾州刺史杨敷舍命坚守，一个月只攻下外城，段韶一度下令屠城。

    * 段韶判断此城三面重险、唯东南一路可突围，令高长恭率一千精兵伏于东南山涧；当夜杨敷果然由此突围，被伏兵擒获。

    * 段韶病情加重先退回晋阳；斛律光抵达宜阳，攻克北周四座城垒、俘千余人班师——这场跨宜阳、汾北两地、耗时一年有余的拉锯，最终以北周占据宜阳、北齐占据汾北告终。

* **解散风波**

    * 战事刚结束，高纬便匆忙令斛律光解散部队；斛律光以士兵有功未赏为由，请求遣使宣慰士卒、自己继续率兵行进。

    * 部队已至邺城之西而朝廷迟迟不派使者，斛律光察觉不对、令全军原地驻扎不敢前进；高纬闻其手握重兵直逼京师大惊，一面召其入宫、一面遣使宣慰并令原地解散——自此对斛律光更加忌惮。

## 琅琊王之变

### 杀和士开

* **高俨其人**

    * 琅琊王高俨为高湛第三子，自幼深受太上皇高湛与胡氏宠爱，十岁即加封京畿大都督、领军大将军、御史中丞，日常用具与出行仪仗完全比照皇帝——不顾后果的溺爱把他推入险境。

    * 和士开、骆提婆察觉其不满，在高纬面前暗示高俨有「天子之貌」；高纬遂送高俨居北宫、五日一朝，和士开仍担心其京畿兵权与北宫武库，进一步谋使其出宫、夺其兵权。

* **假敕布局**

    * 时年14岁的高俨向姨父、侍中冯子琮问计「士开最重而欲杀之，何如」；久受和士开打压的冯子琮力挺其行事，还期待届时一举废掉高纬。

    * 高俨上疏弹劾和士开并请逮捕；冯子琮利用侍中职务把奏疏混进其他文书呈报，高纬不加审阅便批复「准许」；领军将军库狄伏连觉得事有蹊跷请示复核，冯子琮以「琅琊王受陛下敕令，何必再奏」压下，调禁军埋伏神虎门外。

* **神虎门之杀**

    * 571年7月25日清晨，和士开照常赴神虎门准备朝会；库狄伏连上前握手称「今儿有一大好事」，王子宜递文书称有敕命、淮阳王和士开前往尚书省——四面埋伏的禁军将其带到尚书省，不由分说就地斩杀。

### 千秋门对峙

* **围门与召见**

    * 高俨原计划只杀和士开一人，事已至此无法收手，在幕僚劝说下调京畿禁军三千围住千秋门；高纬先派刘桃枝率八十禁军召见，高俨缚刘桃枝、余众四散，又拒绝冯子琮之召。

    * 高俨隔宫放话：和士开罪该万死、我奉敕诛之，要入宫须陆令萱出面——实为诱杀；陆令萱吓得瑟瑟发抖不肯出面，韩凤再召仍被拒，双方僵持许久。

* **孝昭帝旧事**

    * 广宁王高孝珩、安德王高延宗赶来责问为何不带兵入宫；随从答兵少，高延宗环顾数千人：「孝昭帝杀杨愔才八十人，今有数千，何谓少？」

* **斛律光调解**

    * 高纬向胡太后哭诉，太后不忍兄弟相残召斛律光；高俨也派人拉拢，斛律光抚掌大笑「龙子所为，固自不似凡人」，入宫受步骑四百却不主战。

    * 斛律光担心开战不可控，谏高纬亲至千秋门相见；高俨部众见皇帝驾到自乱阵脚四逃，斛律光以「天子弟杀一夫，何所苦」拉高俨到高纬面前，以年少轻狂求情；高纬用刀环捣乱其头发许久方才释放，库狄伏连、王子宜等尽数被杀。

### 高俨之死与太后幽禁

* **冯子琮之死**

    * 胡太后责问主使者，高俨供出冯子琮，冯子琮被绞杀于内省；此后高俨留居太后身边，每份饭食都经太后亲尝。

* **高俨被杀**

    * 杀和士开、又想杀陆令萱的高俨终招报复：一个月后在陆令萱、祖珽的双重蛊惑下，高纬禀报太后以狩猎为名把高俨接往晋阳；凌晨等在房门外的刘桃枝将其带至晋阳大明宫拉杀，四名遗腹子随后全部被杀。

* **昙献事件**

    * 高纬闻胡太后与沙门昙献私通、世人戏称昙献为「太上皇」；起初未轻信，觐见时见两名尼姑颇有姿色召来，竟发现是两名男子——高纬斩昙献等人，幽禁太后于北宫，北齐朝堂纷争暂告一段落。

## 内斗的轮回

* **三国形态对比**

    * | 政权 | 内斗形态 | 标志事件 |
      | :--- | :--- | :--- |
      | 北齐 | 幼主、宗室、勋贵、汉人士族四方摊牌 | 乾明之变（560年，娄昭君废高殷立高演） |
      | 北周 | 辅政的侄子对少年天王的挤压 | 宇文护连杀赵贵、独孤信，废杀宇文觉，毒杀宇文毓 |
      | 南陈 | 武力强臣现场夺位 | 侯安都带剑上殿拥立陈蒨，后又因骄横被赐死 |

* **高纬亲政后的新局**

    * 和士开死后高纬亲政，第一件事便是外放昔日仇人赵彦深为兖州刺史，继而与陆令萱等佞幸狼狈为奸、继续把持朝政。

    * 位高权重、为北周所忌惮的斛律光，在解散风波之后即将迎来人生最大的危机。

* **共同缺口**

    * 三个政权谁都没能建立起稳固的权力传承秩序——内部整合完成之前，谁也走不出内斗的轮回，这正是南北朝后期走向统一前的门槛。
