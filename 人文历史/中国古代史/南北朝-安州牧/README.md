# 南北朝（安州牧·完结合集）

安州牧的《一口气看完170年的乱世南北朝》完结合集，44 个分 P 约 16 小时，从刘宋开国讲到隋灭陈、重归一统：诸王内乱与血色宫闱、萧齐短祚、梁武帝时代与钟离之战、六镇起义与白袍北伐、东西魏的沙苑与玉壁、侯景之乱、北周与北陈并立、邙山之战、太建北伐，最后是杨坚建隋与南北一统。44 集合并为 21 块，整编为 4 册模块全书与 6 篇主题复习笔记。

## 怎么学

- **按四朝顺序读**：宋 → 齐 → 梁 →（东西魏）→ 周陈并立 → 隋，4 册书沿这条主线排下来。
- **南朝看皇位更迭**：刘宋诸王内乱、萧齐篡位、梁末侯景之乱，是同一出戏的三次重演，笔记 01–02、04 连读。
- **北朝看大战与融合**：钟离之战、沙苑、玉壁、邙山四场大战决定了南北均势，笔记 03–05 把战役因果串成线。
- **两段「解毒」别错过**：讲师对萧衍与高洋的专题解毒（P30 缺字幕暂缺、P36 已收），是把人物放回时代的评论视角。
- **结尾接《隋朝》**：太建北伐失败到杨坚统一，笔记 06 与本系列前作《两晋十六国》的结尾正好衔接。
- **考前只看 `notes/`**：6 篇笔记按王朝阶段重组，战役、政变与制度要点并排放置。
