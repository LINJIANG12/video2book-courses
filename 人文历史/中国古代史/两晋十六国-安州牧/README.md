## 怎么学

- **按政权线索读**：东晋（权谋与北伐）— 汉赵/后赵/成汉/冉魏 — 前秦兴衰 — 后燕后秦与胡夏 — 刘宋，2 册书正好各覆盖一段。
- **淝水之战是转折点**：笔记 02 把苻秦全盛、盛世幻影、淝水之战、北方分崩串成一条因果线，先读它再回头看第一册。
- **人物成对看**：桓温与刘裕（两次北伐的对照）、苻坚与王猛、慕容垂与拓跋珪，笔记里都做了并置。
- **北伐为什么总失败**：从折戟枋头到长安长安，地理、后勤与侨姓士族的态度是讲师反复强调的三个变量。
- **考前只看 `notes/`**：4 篇笔记按政权阶段重组，事件、人物与制度要点并排放置。
