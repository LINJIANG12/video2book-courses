# 明清制度、经济与社会、学术与文化

## 中枢权力结构

### 相权的两次分流

   * **宰相废除**

       * 洪武年间废相，宰相权力一分为二：行政那一块归六部，六部地位因此明显提高；另一大块直接归皇帝，宰相的活儿由皇帝自己接过来。

       * 废相留下的不是权力真空，而是工作量：后世皇帝并非人人都干得了这么多活，机构只能接着变形。

   * **内阁（Grand Secretariat）**

       * > **定义**：明中期仁宗、宣宗以后定型的辅政机构，替皇帝处理他从宰相处收回的那摊政务，被称为"外内阁"。

       * 内阁制度定型的同时，宦官参政也逐渐制度化；皇帝从宰相手里拿过来的权力，此后基本由内阁与司礼监分割。

       * "外内阁"与"内内阁"是一对：内阁离皇帝远一点，司礼监贴得近一点，两者有配合，不同时期权力分割的比重又有演变。

   * **司礼监**

       * > **定义**：宦官机构，与内阁并列分割皇帝收归的那部分权力，被称为"内内阁"。

       * 距皇帝的远近就是权力性质的差别：一个在朝堂，一个在皇帝身边。

   * **皇帝不勤政而国政照转**

       * 明中后期皇帝可以长期不上朝、天天玩而不处理政务，国家机器仍能运转，因为那部分权力没有丢掉，只是转到别人手里替他运转。

### 军机处（Grand Council）

   * **设置背景**

       * 清代内阁还在，但作为秘书机构已经正规化、品级提高，不大好指挥，用起来也不大方便；名义上保留，实际重要性下降。

       * 军机处把最机密的那部分事务分走，内阁处理的就只剩常行事务。

   * **与皇帝的关系**

       * 清代皇帝比较勤政，即使军机处拿走的最机密事务，也主要起辅佐作用，绝大部分重要决策、重大事情由皇帝自己决断，这一点清代一直没有被破坏。

       * 明代出现过皇帝什么都不干、或特别信任宦官、权力等于由别人代理的情形，清代没有出现过。

   * **文书分流**

       * 密折、奏折直达御前，绕过内阁，皇帝让军机处的人帮忙处理，内阁根本搞不清这部分内容。

       * 赵毅的概括：雍正以后"本章归内阁，机务及用兵由军机大臣承旨"。

   * **只供传述缮撰**

       * 军机处办这些事，不等于军机处本身有多大权力，它完全在皇帝的指挥下工作，"只供传述缮撰，而不能稍有赞画于其间"。

   * **君权与臣权的相对说法**

       * 晚清人的比较：军机处虽为政府，其权属于君；内阁则全属于臣。

       * 军机处一边是官僚机构在那边的代表，一边又代表皇帝对官僚机构发号施令；内阁更偏向官僚机构一侧，所以"全属于臣"。这是相对说法，什么权属于君、什么权属于臣本来分不了那么清楚。

   * **简、速、密**

       * 军机处的三个长处：手续特别简单、办得很快、能保密；作为一个秘书机构，它就具备这三点。

       * 它在宫中的办事处只是隆宗门外的几间房，不像正规大衙门那样复杂——因为它就是一个办公室。

   * **随皇帝移动**

       * 皇帝常驻颐和园、圆明园时，军机大臣与军机章京在附近盖房租房，北大南边那条"军机处"胡同由此得名；地名恰好印证军机处必须跟在皇帝身边。

## 中央机构

### 六部与司

   * **六部官制**

       * 明代一套清代基本照搬，官名如尚书等完全一样，差别只在部下面的司。

   * **司的分法**

       * 唐：每部四司，共二十四司，特别整齐。

       * 明：多数部仍是四司；户部、刑部按省分司，全国13省即各13司。

       * 清：户部、刑部按省分得更多，事务也更繁；其余部仍是四司。

| 时期 | 部的下设 | 户部、刑部的特殊之处 |
| :--- | :--- | :--- |
| 唐 | 每部四司，共二十四司 | 无 |
| 明 | 多数部四司 | 按13省分司，各13司 |
| 清 | 多数部四司 | 按省分司，省份更多、事务更繁 |

   * **连续性**

       * 六部的基本骨架与前代连续，特殊之处只有户部、刑部跟着省走。

### 九卿、七卿与六科

   * **都察院（Censorate）**

       * > **定义**：由御史台改名而来的监察机构，级别与六部相平。

       * 名目是新的，实质仍是御史台，管监察。

   * **大理寺**

       * 与刑部分工：刑部审案，大理寺管案件复审；设这道复审，出于强调判案要慎重。

       * 大理寺地位也很高，级别与六部基本一样。

   * **通政使司**

       * 收发机构，主管信息上传下达：皇帝诏书由它往下转发，各机构报告、官员奏章由它汇总上转。

   * **九卿**

       * 六部加大理寺、都察院、通政使司，级别基本一样、彼此平级，合称九卿；古代有三公九卿，明代正好也有九个级别较高的机构。

   * **七卿**

       * 九卿中大理寺、通政使司稍次要，于是又有七卿之说：只有六部与都察院并列。

       * 《明史》设《七卿年表》，逐年列出这七个机构的长官，说明这七家最重要。

   * **六科**

       * 长官五品、给事中七品，属中级甚至中下级机构，不在九卿、七卿之列。

       * 工作与六部一一对应，对六部对口进行行政监督，并就六部的问题向皇帝提意见。

       * 六科与都察院都叫言官：不直接管具体行政，负责提意见、挑错找问题；两者合称科道官，明代言官因此非常活跃。

### 清代的增删

   * **六科的弱化**

       * 明代党争激烈、言官活跃，清代认为这样不好，要打压，整个监察系统都有点弱化；六科后来没那么重要，好多工作并进六部，比明代差很多。

   * **理藩院**

       * 名为"院"，官制却是六部的架子：长官也叫尚书，副官叫侍郎，下面设若干司，有郎中等。

       * 专管边疆事务，主要是以蒙古为主的北方、西北方少数民族事务；清代边疆管理有成效，这个机构起了很大作用。

   * **内务府**

       * 管宫廷事务，把明代宦官二十四衙门的事基本包了过来，全部宦官纳入内务府管理。

       * 管事者不是宦官，而是皇帝的包衣（家仆，其中有当年打仗俘获的汉人），日久可以出去做大官，曹雪芹的祖先即由此出身。

       * 用包衣管宦官，把宦官压在不高地位，杜绝宦官专政，效果明显。

   * **十三衙门铁牌**

       * 明代二十四衙门到清裁剩十三个，故有"十三衙门"之称；顺治专门刻铁牌严禁其干政。

       * 清代宦官专权基本没有发生，晚清只有李莲英个别人得势，地位远不能与明代相比。

## 地方行政与政区

### 三司分权

   * **分解行省的动因**

       * 元行省权力太大、地盘大、级别高，朱元璋不放心，明初把它拆成几个互不统属的机构。

   * **三司**

       * 行省直接改名布政使司（藩司），管一般行政；军事分出来设都指挥使司（都司）；监察提到与二者平级，设按察使司（臬司），司法与监察归它。

       * 三司互不统属，直接对中央负责。

```text
行省（权力大、地盘大、级别高）
   │  一分为三
   ├──▶ 布政使司（藩司）——行政：府 / 直隶州 → 县 / 属州
   ├──▶ 都指挥使司（都司）——军事：卫 → 千户所 → 百户所
   └──▶ 按察使司（臬司）——司法·监察
```

   * **两级三建制**

       * 布政使司下，府管县是最正常的一路；州分两种，直隶州与府平级、属州与县平级，所以基本是两级机构，却可能出现三种名称。

       * 都指挥使司下设卫—千户所—百户所。

### 督抚与道

   * **督抚出现的机理**

       * 三司分解后对中央威胁低了，但效率受损：没有真正的一把手总协调，什么事都容易扯皮；明中期以后社会问题多、起义与边疆战事频仍，扯皮就要出事。

       * 巡抚出现早、总督较晚，都不是正式的官，始终挂中央官名义出外，以钦差大臣身份协调某地某项工作。

   * **所挂头衔**

       * 巡抚挂都察院头衔（巡抚都御史）；总督除都察院外再加兵部侍郎，因为总督经常与军事相关。

       * 事情办完就回朝，不能长期坐镇一地，尾大不掉之局就不易出现。

   * **明后期到清的转变**

       * 明后期边疆紧张、内地农民起义，督抚长期留在地方回不去；但辖区大小、设在哪里仍不一定，未完全变成地方官。

       * 清代都指挥使司系统取消（不用卫所兵制），布政使、按察使仍在，但督抚固定下来逐渐成为地方官，布、按反成督抚下手；省一级另有学政管教育、盐运使管盐法等专官。

   * **道**

       * 清代一省太大、事太多，又没有现代管理手段，于是分片派几个人代管，这就是道；道始终不算很正规的一级行政机构，但管很多事、设了撤不掉。

       * 道分守道、分巡道（由布政使派出与由按察使派出，名目不同），有的兼专门工作如粮储道；明代已有，清代成熟。认真说，清代管理体系实际应算四级。

### 政区与边疆

   * **明代政区**

       * 两京十三布政使司：北京、南京附近称北直隶、南直隶，其余各片称某某布政使司，也简称省。

   * **清代政区**

       * 18省，有的由明代的省进一步细分而来，与今天中国内地的省已经基本一样。

       * 18省之上分大片由总督管理，全国八大总督：直隶、两江、四川、陕甘、湖广、闽浙、两广、云贵；每省必有一巡抚，有的两省或三省一总督，个别一省一总督，也有不设总督、由巡抚管的省。

   * **边疆特殊政区**

       * 明代东北设辽东都司、奴儿干都司，不设布政使司。

       * 清代东北设将军、外蒙古设将军，下有盟旗，因地制宜，属特殊政区。

| 项目 | 明 | 清 |
| :--- | :--- | :--- |
| 高层政区 | 两京十三布政使司 | 18省 |
| 省级以上 | 督抚多为临时差遣，辖区不定 | 八大总督固定，每省一巡抚 |
| 军事系统 | 都指挥使司—卫所 | 废卫所兵制，都司系统取消 |
| 省下层级 | 府（直隶州）—县（属州） | 府（直隶州）—县（属州），另有道分片 |
| 边疆 | 辽东都司、奴儿干都司 | 将军辖区、盟旗等特殊政区 |

### 繁简与冲繁疲难

   * **明以前的划分**

       * 各朝基本按人口把地方分上、中、下三等（上州中州下州、上县中县下县，或只分上下两等），人多事多难管，是最朴素也最好理解的标准。

   * **明代的两条标准**

       * 税粮：府15万石以上、州7万石、县3万石为重要；粮与人口有关但不成正比，经济发达、产量高的地方征额也高。

       * 地理位置：有驻军、处驿站交通要道者，送往迎来、供应不堪，即使人少也一定很累，要另眼看待。

       * 达标或位置重要者为"繁"，不达标者为"简"，府、州、县各分两档。

   * **繁简的用处**

       * 吏部选任要看能力：能干者放到繁缺，只熬年资者放到简缺；提拔时一看经历，在繁缺干过的升得快，久在简缺的升得慢。

   * **清代的四字标准**

       * 冲：地当孔道，地理位置重要；繁：政务纷纭，事情多；疲：赋多逋欠，税额高又常收不上来；难：民风彪悍，爱闹事、出案子。

       * 四字俱全为最要缺，占三字为要缺，占两字为中缺，占一字或不占为简缺。

| 四字情形 | 缺的等级 |
| :--- | :--- |
| 冲、繁、疲、难俱全 | 最要缺 |
| 占三字 | 要缺 |
| 占两字 | 中缺 |
| 占一字或不占 | 简缺 |

   * **亲民官**

       * 真正与百姓打交道的只有县，以及一部分与县平级的州，合称州县，属"亲民官"；府以上只处理下面的呈报和公务。

       * 清初收附加税"火耗"只能靠州县，因为只有它直接面对百姓；州县收上后逐层往上分送，府管许多县，所得相当不少。

## 学校与科举

### 学校与国子监

   * **学校的两重功能**

       * 一为科举做准备；二是学校出身者可以不考科举，直接申请参加工作，只是出身比科举低一档，算其次一等。

       * 《明史·选举志》的次序："科目为盛，卿相皆由此出，学校则储才以应科目者也。其径由学校通籍者，亦科目之亚也，此外则杂流矣。"

   * **科举必由学校**

       * 考科举必须先有学校出身、并积累一定成绩才能报名；民间自学成才直接报考，唐宋可以，明清不接受。

       * 学校出身做官要熬到国子监才作数：府、州、县学的诸生只有进入国子监才可能得官，不入国子监就不能得官。

   * **监生名目**

       * 以举人身份入监为举监，以地方学校学生保送入监为贡监，凭父祖官荫入监为荫监，花钱捐得为例监。

       * 地方学校向国子监保送，又有岁贡、选贡、恩贡、纳贡等名目。

### 科举阶梯

   * **童生与童试**

       * 未进学校、只在家中读过些经史的人称童生；童生里有很老的人，一辈子卡在这一关。

       * 童试分县试、府试、院试，由县、府分别主持，属预备考试，较简单、录取面稍广；通过即入某校为生员（秀才），成为国家承认的读书人。

   * **乡试与举人**

       * 生员在校继续考试、熬到年头资历，取得科举身份（科举生员）后才能报名乡试；乡试为各省考试，中者为举人。

       * 举人可径赴吏部报名候选，制度上已有做官资格；这是最关键的一关，身份与百姓一下子拉开。

   * **会试、殿试与庶吉士**

       * 会试由礼部主持，通过者为贡士，这一关非常关键；殿试基本不淘汰，只重新排名，排到前面即为状元，故第二关考得一般、第三关排得好仍占大便宜。

       * 新进士中挑少量人不即做官，入翰林院再读三年，为庶吉士（明代新发明），散馆后授官，这是台阶的尽头。

```text
童生
  │  童试（县试·府试·院试）
  ▼
生员（秀才）
  │  乡试（各省）
  ▼
举人 ──▶ 可赴吏部候选入仕
  │  会试（礼部）
  ▼
贡士
  │  殿试（不淘汰，只排名）
  ▼
进士
  │  庶吉士（翰林院再读三年）
  ▼
散馆授官
```

   * **两关淘汰、一关排名**

       * 真正淘汰人的是乡试与会试；殿试只排名不淘汰；庶吉士则是进士之上的再加一层。

   * **举人的上限**

       * 中举即可在地方上发威，但想求更大发展仍须再考，光是个举人再往上就不够了。

       * 曾国藩各层学位全部拿到、表现又好，即使没有太平天国也会做大官；左宗棠止于举人，若无战事便无由显达，后来靠军功才做到与曾同等。

   * **实物与谚语**

       * 国子监存有将近200块题名碑，同一届进士刻名纪念；公布榜文在当时也是大事。

       * 谚语"不敢望子弟为圣贤，亦当望子弟为鼎甲"：成圣贤的标准不好把握，考到鼎甲却是能把握的；科举是社会流动的重要渠道。

### 考场与题式

   * **号房三天**

       * 一考连考三天，人只能在号房内，白天答卷、晚上睡在里面；内有两块木板，一高一低架起当凳桌，放平即床。

   * **《聊斋志异》七似**

       * 进场"白足提篮似丐"：衣不能多、鞋也简单，篮中只放生活必需品与文具，怕夹带。

       * "唱名时官呵隶骂似囚"：点名时差役推搡呵斥、搜身，很不受尊重。

       * 入号房"孔孔伸头，房房露脚，似秋末之冷蜂"；出场"神情惝恍，天地异色，似出笼之病鸟"。

       * 等成绩"似被絷之猱"；闻落榜"嗒然若死，似饵毒之蝇"；日久缓过来"似破卵之鸠"，只得重新营巢、再等三年。

   * **题式的来源**

       * 《四书》总字数有限，出不了新花样，于是出怪题：摘三字成题为单句题，整句、整段为节题，整章为一章题。

       * 最怪的是截搭题：取半句与另一处半句硬拼，两句本无关系，却要据此成文；这种题正规考试不出，只作练习与文字训练。

## 八股文

### 三条要求与格式

   * **为何考经义**

       * 考文学（唐诗赋）与现实关系不大；考经学若如唐之明经，只是死记硬背，也不算真功夫；于是改为出经书题、写一篇文章，兼考表达与思想。

       * 问题在判卷标准难掌握，于是对经义的要求越来越严，形成固定格式：强制在一个很死的格式里把思想充分表现出来。

   * **祝总斌的三条**

       * 经义：题目从经书里出。

       * 代圣贤立言：模仿圣贤口气，设想孔子或孔子学生如何阐发；不违反儒家思想，且不能用后代典故、后代知识。

       * 八股对仗：写出来的文章还要对仗。

   * **格式骨架**

       * 破题、承题、起讲、入题是铺垫；主体为起二股、中二股、后二股、束二股四组排比；最后大结收束。

       * 字数与意思要同时到位：不能意思说完而文章未满，也不能八股用完而意思还差一截；文字完、意思完，气脉还要连贯。

```text
破题 → 承题 → 起讲 → 入题
起二股 → 中二股 → 后二股 → 束二股
大结
```

   * **对仗的讲究**

       * 不必如魏晋骈体那样四六整齐、字字相对，但关键处必须对上：句式、主谓宾结构、实词虚词位置、起承转合关系都要对应。

       * 字面看似不同，意思要前后连贯，抑扬顿挫与音节还得顺；两股之间必有逻辑关系。归有光"一言以蔽之曰思无邪"一题即其例。

### 评价与边界

   * **确实难写**

       * 在固定字数、固定格式里把意思说得流畅，要求相当高；周作人、钱基博都说过，八股写得好的人肯定不笨，干别的工作也不差。

   * **顾炎武骂的是什么**

       * 今人骂八股骂其束缚思想、封建礼教；古人骂的是另一件事：写八股不必真懂经书、不必是儒学大师，熟读范文与程墨即可中式。

       * 类比：号称考马列，却少有人去读原著，都看复习指导、按套路答题；真去读原著的人反而未必及格。

       * > **易错点**：八股挨骂的要害不是"考的内容太正统"，而是"考的方式让正统内容变得可以不读"；目标写着考经义，实操考的是文体手艺。

   * **为何废不掉**

       * 争论很久，说它选不出人才、常选骗子，但不考八股也拿不出更好的办法；任何标准只要靠判卷，选拔就必有问题，不拘一格又无从判卷。

       * 它起码有一个基本尺寸：能拿到这个标的人里总还出些人才，进官僚队伍后再筛选淘汰，有能力的干上去、没能力的慢慢出不来；所以清代仍接着用。

   * **判卷的弹性**

       * 归有光是当时八股高手，习作印成书广为流传，乡试一考即中，会试却连考六七次不中，直到六十岁才中；考官屡次以为文风像他、拆封却另有其人。

       * 文章考试有弹性：格式再严，不同人看来仍有高低之分；能力是一方面，偶然性是另一方面。

   * **科举之外的窄门**

       * 况钟（《十五贯》里审案的清官）是吏员出身，从吏那条路熬出来；这种出身在元代正常，在明清非常少。

       * 李卫是捐纳出身，靠花钱买官入仕，后因干得好而上去；此类人极少，绝大部分仍须由科举。

## 监察与考核

### 科道官与巡按

   * **科道之分**

       * 六科按"科"分，一科对一部；都察院下的监察御史按"道"分，共十三道，按各省省名设道；一科一道合称科道官。

       * 六科设在中央，针对国家几项重要行政做监察；都察院面向全国，地方上也有监察任务，故经常派御史出巡、出差、定点检查。

   * **巡按御史与巡抚的区别**

       * 巡抚全称"巡抚都御史"，挂都察院副长官（副都御史）头衔，级别很高，后来主要驻地方，等于成了行政长官。

       * 巡按只是监察御史，七品，派出去巡视，级别低、年纪轻，始终没有转向行政，就是个言官；《明史》说巡按御史相当于代天子巡狩。

   * **小官为何管得住大官**

       * 七品、中年以下、朝气蓬勃、疾恶如仇，与地方关系网尚未建立，又希望办大案出名以求升迁，故做事认真。

       * 藩、臬、守、令中布政使、按察使是三品，比巡按高许多级，见了巡按却得巴结；巡按参一本，官就可能丢。

   * **代价**

       * 有的巡按存在感太强，也会徇私；地方官被搞得过度紧张，正事不干，天天走门路、拍马屁、前呼后拥地伺候。

       * 场面：相见之际知府以下长跪不起，布政以下列为随行；中央不断派御史（巡盐御史、清军御史、巡抚都御史），来一个就得伺候一个，自己的工作便干不了。

       * > **提示**：这套监察的代价不在监察本身，而在被监察者的时间；正事都耗在迎来送往上。

   * **戏曲里的巡按**

       * 套路是书生受小姐资助赴考，久无消息，小姐被坏人霸占，书生忽然以八府巡按身份出现，手持上方宝剑处置一切。

       * 这说明巡按多是刚入官场不久、且科举考到最高一级的年轻人。

### 考满与考察

   * **考满**

       * 给任满官员做鉴定：官员基本三年一任，任满即鉴定一次，积三个三年共九年再做一次大鉴定。

       * 原则宽松，基本都能通过，多给"不错""合格"，重在奖励提升；干得特别好、考分高的还可能超级提拔。

   * **考察**

       * 不管任满与否，全国一刀切的大检查：京官六年一次、外官三年一次，到期工作都放下等着检查，重在挑毛病、以惩罚为主。

       * 考满容易通过，是因为有考察在后面兜着：考察没把你刷下去，考满自然也就差不多。

   * **八项与处置**

       * 贪、酷：革职为民；浮躁、才力不及：降级使用；年老、有疾：办退休，不能再干；疲软无为、素行不谨：冠带闲住。

       * 八项两两成对：贪与酷是品行，浮躁与才力不及是性格与能力，年老与有疾是身体条件，疲软无为与素行不谨是够不上大罪的小毛病。

| 考察结论 | 具体所指 | 处置 |
| :--- | :--- | :--- |
| 贪、酷 | 贪婪，或者残酷 | 革职为民，官就丢了 |
| 浮躁、才力不及 | 办事毛糙，或者水平不高 | 降级使用 |
| 年老、有疾 | 年纪过大、身体不好，不适合做官 | 办退休，不能再干 |
| 疲软无为、素行不谨 | 能力欠缺、办事糊涂，或小的生活作风问题 | 冠带闲住 |

       * > **定义**：冠带闲住——保留官的身份与一些基本待遇，人回家当老百姓，官场不要你了。

   * **执行之难**

       * 年老有疾多数人会隐瞒，但考察查出即须退休，没有身体条件就不能再当官。

       * 制度设计不错，定期把不称职者拿下来；但能否做到去坏留好，全在操作的人。

   * **党争中的考察**

       * 明后期党争激烈，考察与党争合流：一派掌握考察之权（主要是六科中的吏科），就把另一派全部拿下，过两年对方掌权再反过来清一遍。

       * 制度本身好，人心不正或有意借它迫害人，制度就成了工具。

### 清代的变化

   * **考满与考察合一**

       * 考察已够严，考满只是走形式，干脆合一；合一后仍以考察为主，任满也不必再做鉴定。

       * 清代考察不只抓坏人，也表彰好人：表现特别好、能力特别强的打高分，作为提拔参考。

   * **记录与加级**

       * 对官员立功、表现好有一套很细的表彰制度，叫记录、加级，实质是一种打分。

       * 日常无大事可立，小事干得好、小问题解决得漂亮也能加分；分攒多了，任满调职时有用，犯错挨处分时也可用分抵。

   * **顶戴花翎**

       * 花翎在清初是奖赏，很严格，不是人人可戴，本身还分级别，由皇帝赐给表现好、立功的官员。

       * 大约到晚清才用烂，几乎人人都有；电视剧里每人一翎、摇头晃脑是晚清以后的样子，"摘去顶戴花翎"的说法并不完全准确。

## 吏、幕友与长随

### 吏

   * **吏与官的区别**

       * 官经考试等渠道进来即有级别，进入有级别的队伍；吏是官府里的普通公务员、跑腿的，没有级别，在下面具体干事。

       * 历朝都有吏，明清一样；问题是政府离不开吏，又总想约束防范，却老不见效。

   * **官为何离不开吏**

       * 科举出来的官没有行政管理经验，经书、文学知识多，管理经历没有。

       * 清代任官回避本籍，必须到外省，风土人情不了解、人生地不熟，甚至语言方言不通，不考虑这些工作根本没法干。

   * **吏为何管不住**

       * 吏升不上去，也不想升，只想长期霸占岗位、做点手脚、鱼肉乡里，在下头过好日子。

       * 限任期无效：改个名、换套材料又来了，还行贿；即使本人不来，也让儿子、弟弟来——他们家就是干这个的。

   * **赶车的比喻**

       * 来办事的人像客人，衙门像车，吏是赶车的人，官是拉车的骡子；鞭子往左，骡子就往左。

       * 因为资料吏最熟、条文吏最清楚，实际是吏在赶车、官在拉车。

### 师爷与长随

   * **幕友（师爷）**

       * 明清地方权力集中，真正拿主意的是"一把手"，一州一县事务繁杂，既需吏帮忙，又得请私人助手，即幕友、师爷、幕宾。

       * 与吏最大的不同是与官一条心：官去哪个县就跟到哪个县，属私人关系，等于官出钱雇的秘书。

       * 一般有文化、有行政知识，甚至经过专业培训，对地方行政事务、赋税、法律都很熟；不请几个，地方就搞不好。

   * **长随与开销**

       * 官府固定设置的跑腿者是衙役；官往往还自带一批私人衙役，叫长随。所以官的助手有公家配的，也有自己私人的。

       * 私人助手要官自己出钱发工资，薪水就不能低，低了养家与养助手都不够；后来养廉银发得高，与此有关。

   * **刑名与钱谷**

       * 师爷分两大专业：刑名管司法，钱谷管财政。

       * 因为地方官的任务主要就两项：把税收上来、把案子审了；税交不上、案审错了，官就丢了，所以必须用这两种人。

       * 师爷一业以绍兴人最多，都干成传统；他们自己写过不少教材、教科书，流传很广。

## 法律与司法

### 法典体系

   * **大明律**

       * 唐律分十二篇，大明律改为七篇三十卷：按六部为吏、户、礼、兵、刑、工六篇，前面加总则名例律，六篇之下再分目。

       * 清代继承这一套，明清属同一法律体系。

   * **律不动，例在变**

       * 律作为基本框架不动，对律的修改补充都通过"例"完成：例是临时加入的条文或小的变通，审案是律例结合着用，例也更丰富。

       * 王朝隔一段把例筛选修订、编到律后，故清代修成《大清律例》：律只有436条，所带之例有1700多条。

   * **会典**

       * 秦有律令体系，唐有律、令，宋也有令；明清基本不用"令"这个词，对应的东西叫会典。

       * 会典是把各种法规制度正面汇编成书，即国家的行政法规汇编；明编过两次，清编过五次，越编越细，后来分出总则与细则，还带图。

       * 清入关前在东北即以《大明会典》为参考，全书翻译且生搬硬套，引起过批评。

### 秋审与热审

   * **立决与监候**

       * 死刑分两种：斩立决、绞立决是马上处死；斩监候、绞监候是判了死刑先不杀，关起来等候复审，即死缓。

       * 复审时间：明制在每年霜降以后，清原则上地方定在阴历八月，前后差不多。

   * **秋审四类**

       * 情实（证据确凿该杀）→ 秋后处决；缓决（材料不明确、杀了有疑问）→ 暂缓一年；可矜（证据不够、判重了）→ 减刑按流刑、徒刑处理；留养承嗣（独子、杀了绝后）→ 不杀，放回奉养父母。

       * 留养承嗣者等父母过世或自己又有了儿子再处理，时间一长多半也就逃过去了；这是儒家礼教重传宗接代的产物。

| 结论 | 判断依据 | 处置 |
| :--- | :--- | :--- |
| 情实 | 确实该杀，证据确凿 | 秋后处决 |
| 缓决 | 证据、材料不很明确，杀了有疑问 | 暂缓一年，暂缓执行 |
| 可矜 | 判死刑的证据不够，判重了 | 减刑，按流刑、徒刑处理 |
| 留养承嗣 | 可能该杀，但是独子，杀了绝后 | 不杀，放回奉养父母 |

       * > **提示**：这套标准放到今天无法执行，因为独生子女太多；它是清代分档处理的特点。

   * **热审**

       * 主要在京师，针对的不一定是死刑犯，主要是监狱里关押的疑犯，定期清查、从简从轻、能放就放。

       * 因为古代犯人怕的不是判刑而是久关不判：监狱条件极差，有牢头狱霸，天热卫生差、疾病危险，很多人被关死；而审判要等证据、等证人，官府拿不准就拖，案子积压轮不到。

       * 罪行大、确实不能放的不放；能判的先判、能放的就放，属应急处理。

   * **勾决之"勾"**

       * 秋审最后有题本，经刑部、大理寺复审，谁杀谁不杀都已定好；这个"勾"不是打勾的勾，被勾到的人即要杀掉。

       * > **易错点**：皇帝一拍桌子"推出斩首"在清代极少发生；他要杀人可以杀，但通常仍走法律程序：先大怒，再交办，最后办成一个大案。

       * 清代办大案常是冤案，却办得像铁案：说谋反能罗列九十二项大罪，证据人证俱全；随口斩首是低水平，走完程序才是高水平。

## 军事制度

### 卫所与营兵

   * **卫所的性质**

       * 明代基本兵制是卫所，但卫所其实是预备兵，真要打仗得重新编组，很麻烦；所以明后期开始招兵、募兵。

   * **两套军官系统**

       * 卫所系统管军户、是兵源，平时屯守并不打仗。

       * 营兵系统才是真打仗的一套：队长、把总、游击、参将、总兵，直到总督。

```text
明代军官的两套系统

卫所系统                营兵系统
军户管理                队长、把总、游击
平时屯守，并不打仗      参将、总兵、总督
                        ——真打仗靠这一套
```

       * 卫所后来慢慢废弛，主要就靠募兵。

### 八旗与绿营

   * **八旗**

       * 以满族为主，是核心部落、国家根本；全国总额二十万人，后来不再增加，许多满族人也不在其中招募。

       * 驻全国要害：一半驻北京周围，另在沿海、沿江、边疆重要据点集中驻几个甲，不是全国散住。

   * **绿营**

       * 招来的兵，国家发粮饷，不像军户自备装备；分散驻扎全国各州县，与八旗互相配合，八旗居中起控制作用。

       * 招兵即成家兵：一旦招了兵，家就跟着来，儿子不能干别的，父死子顶、孙再顶，"以后永远都是咱们家"；明代已有此趋势，清代更明显。

   * **中衰**

       * 清中叶八旗、绿营都不行了；乾隆自己说巡视所见是"射箭箭虚发，驰马人落地"。

       * 但老打仗仍有些部队可用："十全武功"中几次恶战八旗绿营都打不了，就从东北调索伦兵（鄂温克等善猎民族）。

## 土地占有

### 官田的两层含义

   * **广义官田**

       * > **定义**：所有权属于国家、不归任何私人的土地；它可能正被某人使用或占着，但此人没有完全所有权，不能买卖、不能自由处理。

       * 《明史·食货志》："明土田之制，凡二等：曰官田，曰民田。"来源包括继承宋元、没收入官、学校田产、皇帝皇族皇亲的庄田、国家墓地坟地。

       * 数量以明中期为准：弘治十五年，官田视民田得七之一，即约七分在私人、一分归国家；前后有变化，但不会太大。

   * **狭义官田**

       * 专指国家占有并用来出租的那部分土地：国家以地主身份把地租出去、收地租。

       * 唐鹤征说其来路是"抄没入官"：地归国家而国家不能自己种，仍由百姓种；种者不是所有者，只是国家的佃户。

       * 故其所交粮食性质是地租而非赋税；"官田，官之田也，国家之所有，而耕者犹人家之佃户"。

       * > **定义**：同一块地交上去的东西叫"租"还是叫"赋"，取决于是不是自己的地——租是使用他人土地付的价，赋是有田产对国家尽的义务。

   * **三种处置方式**

       * 赏赐给贵族、功臣、皇亲，地仍是国家的、不能卖；作为屯田用军队或军事化方式耕种；国家当地主出租收租——只有最后一类才是狭义官田。

### 江南重赋的由来

   * **贾似道的公田法**

       * 南宋末年财政困难，宰相贾似道强制"购买"民间超额土地：按等级定额，超过标准的部分必须卖给政府一部分。

       * 政府所付极少，或不付、拖欠，或以度牒之类有价证券抵账；度牒当时已成流通证券，行情好时能炒得很高。

   * **元代与明初的承接**

       * 元朝把南宋政府的这些地宣布为国有，理由充分：原是南宋政府的，今归元朝政府，百姓照旧种，元朝出租，再传到明朝。

       * 元末苏松常嘉湖是张士诚的地盘，朱元璋与之对抗多年，消灭后这一带土地大量被没收。

       * 明初打击贪官污吏与民间豪强，又没收不少，在这种地方特别多。

   * **重赋的两个原因**

       * 这里土地本身高产，赋税标准就比较高。

       * 更要紧的是大量土地为国有：按地租比例缴纳，数目极大；而私有土地所有者交赋比例很小，地租却总得交到一半的量级，两头一比，政府从这儿收的粮自然多。

   * **数字**

       * 洪武年间全国每年税粮将近三千万石，分布很不平均：浙江一省占十分之一，苏州一府也占十分之一。

       * 苏州一府一年交两百八十多万石、将近二百九十万石，松江、常州也都很高。

       * > **提示**：江南重赋常被解释成"经济发达所以赋税重"，其实还有一半原因藏在土地性质里——这里国家佃户多；同一片田按赋交是五升、按租交是几斗，差出十几倍。

### 官田的收场

   * **管理崩坏**

       * 起初政府管得严：清楚哪块国有哪块私有，分别按高低标准征收，国有原则上不得买卖，只能由政府出租或收回另给他人种。

       * 时间一长账本找不着；有人把种着的地偷卖并声称是自家的，甚至伪造土地证；地换了几手，接手者干脆不认账，收租变得极麻烦。

   * **均摊与三斗起征**

       * 明中后期所有权搞不清，政府最后不管也不查：收的粮一分不能少，把官田与民田的税额平均起来分摊，一律当私有，只要保证总数不少。

       * 苏州民田五升起科（低档标准），官田原按产量对半收租，减免后仍要七斗——七斗是五升的十四倍。

       * 混同之后一律按新标准"三斗起征"：原种官田者赚了，真正的私有土地所有者亏了。

| 田类 | 起科标准 | 缴纳性质 | 能否买卖 |
| :--- | :--- | :--- | :--- |
| 民田 | 五升起科，属低档标准 | 赋税 | 可以 |
| 官田 | 按产量对半收，减免后仍七斗 | 地租 | 原则上不可 |
| 混同之后 | 一律三斗起征 | 名为赋税，实按私有土地征 | 事实上已可流转 |

       * > **结论**：官田到这一步名存实亡——不再被当作国有，而被当成一种高额赋税的私有土地；到清代与民田完全混在一起，只剩"赋比较重"这一特征。

   * **屯田三类**

       * 军屯：军队直接开荒耕种，相当于生产建设兵团。

       * 民屯：把无地流亡人口组织起来，用军事化管理方式种地；地不是他们的，剥削率很高，但未列入军队编制，故称民屯。

       * 商屯：商人在边疆占田，到内地招穷人来种，管理较严，粮食就地交给政府。

```text
商人 ──招募内地贫民──▶ 边疆占田开垦
  ▲                          │
  │                          │ 粮食就地交割
  │                          ▼
政府 ◀──────────────────── 粮仓
  │
  │ 发给盐引、盐票（专卖权）
  ▼
商人 ──▶ 盐场买盐 ──▶ 运销各地 ──▶ 利润
```

       * 商屯的实质是以粮换盐引：商人以民间资源替国家养边，换来食盐运销的许可。

       * 屯田特点一句话：管理严密、剥削率高，不低于官田，因为与兵团一样是军队那一套；土地本来很多，但随卫所瓦解而早衰。

       * 崇祯时下令不查了，无论军屯民屯一律照民田起科，就当私有土地收赋。

       * 与官田处理不同：官田把国有高税额与民田低税额合并均摊，落到中间数；屯田直接按民田低标准收，未做平均。原因是屯田多在北方，生产不发达、地力差，收不了太高。

### 庄田、更名田与旗地

   * **庄田**

       * 国家赏赐给官僚贵族的土地，作为福利由其自己经营、也出租；所有权仍属国家，受赐者不能卖、不能自由处理，只有临时使用权，国家需要时有权收回。

       * 皇帝自己也搞庄田（皇庄）：国库的钱花起来有人提意见，皇帝要有小金库随意花，于是开商店、买土地、置产业。

       * 赏赐面越铺越开，另有民间"投献"：穷人要避赋役，宁可把地献给贵族挂在其名下，受其剥削也不愿受政府临时摊派之扰；政府禁止却禁不住。

       * > **提示**：投献那笔账要算清——交给贵族的租可能比交给国家的赋还重，但省掉的是徭役与无休止的临时摊派，那两项没法预算、说来就来。

   * **更名田**

       * 清初庄田占有者（明代贵族、宦官、藩王）多已被打倒，地主要在北方，由农民耕种，等于无主而所有权不清。

       * 康熙定原则"谁种归谁"、政府不收回：若宣布为国有、按地租征收可多收，但管理麻烦、有操作成本，不如做一件德政。名目换了说法，实质是主人换了，这部分地由此私有化。

   * **旗地**

       * 清入关后在华北圈占，分给八旗官兵；当时荒地多，圈占方便，也发生过侵害汉族地主、农民利益的事。

       * 性质与庄田同：只有使用权、不能卖，是国家给的福利；清后期管不住，有私卖、有私下转让，晚清与一般民田无别。

   * **共同轨迹**

| 类型 | 名义 | 政府最初的做法 | 最后的归宿 |
| :--- | :--- | :--- | :--- |
| 官田 | 国家占有的出租地 | 收高额地租，禁止买卖 | 税额均摊，一律三斗起征，视同私有 |
| 屯田 | 军队与民力屯种 | 军事化管理，剥削率高 | 崇祯照民田起科，明末基本私有化 |
| 庄田 | 赏赐给官僚贵族 | 只给使用权，可随时收回 | 清初更名田，种者即其主 |
| 旗地 | 分给八旗官兵 | 只有使用权，不得买卖 | 晚清与民田无别 |

       * 四类地在制度上都写着国有、不可买卖，没有一类守得住；政府最后都选同一条退路——承认既成事实、把税额固定，不再追问所有权。

       * 原因：国家在理念上可以把所有土地看作自己的，实际没有能力天天盯；地要出租、要分散经营、要靠一层层人去收，时间一长官僚机构效率下降，账册散失，转手、伪造、不认账，最后只能承认私有化。

       * 长时段看：宋代国有土地最少（经济较自由、干预少），元朝加强国有化，明清继承；但趋势不可能永远国有化。

### 私田与《卖田说》

   * **私田的规矩**

       * 私人占有、互相买卖，政府完全承认；但买卖要到政府办手续、交地产交易税，不交即犯法，交易款可能被没收一大部分。

       * 政府只管两件事：地卖出后仍须承担赋役；交易必须交税。宋以后土地买卖非常频繁。

   * **契约与契尾**

       * 清代契约实物写明：谁把地卖给谁、地四至在哪里、原交多少赋税；签完到官府办手续交费，官府撕一张纸贴在后面，即契尾。

       * 贴上契尾，契约才完整、才有法律效力，将来打官司政府才认；私下签约转让、不贴契尾不交税，政府不认。

       * > **易错点**：契尾不是"合同的附件"，而是官府的完税凭证与认证标记；地权转移的效力不在双方签字，而在官府这一贴。

   * **《卖田说》的现象**

       * 清后期四川李调元所作，宗旨是教子读书，论说有夸饰，但间接反映的农村土地经营情况可信。

       * 现象：许多人把自家土地卖掉，用卖地钱作押金，去押另一个地主的土地佃种。

       * 原因：大家庭一次次分家，地越分越碎，只剩十亩，出产供不上全家，还要交赋税；最要命的是地方官府的临时抓差与摊派，这点地吃不消。

       * 佃种也要本钱：租地须先交一大笔押金，太穷的人拿不出；十亩地卖的钱可押一百亩来种，规模一下大十倍。

       * 剥削虽重（一般对半），但地多可兼营副业，且成了佃户便无财产，朝廷赋役与官府摊派不再找上门。

   * **官身是护身符**

       * 主人问：有这好处我也卖地去当佃户。答：你不用卖，你是官，有特权保护，杂派摊派落不到你头上。

       * 但须"世世子孙读书有官；若一日无官，诚恐亦我辈等"——一旦无官，便与普通佃户一样。

       * > **提示**：这篇文章留下的账很清楚：地权越分越碎，赋役与临时摊派压在自耕农头上，押金是当佃农的入场券，官身是免于杂派的护身符。

## 租佃制

### 佃农的额外负担

   * **名目**

       * 押金：租地先交一笔，将来退还；礼金：为保证租佃权、不被夺佃而送，不退。

       * 额外交纳：冬牲之类鸡鸭白送；预收地租：未到期即来收。

       * 大斗大秤：收租时在量具上作弊，一平斛的粮要堆出尖来（踢斛淋尖）。

       * 送租上门：地主不来取，佃户送到他家，路费自出；质量挑剔：对米百般挑剔、压级压价；逾期利息：不能按期交纳即收息。

   * **性质**

       * 佃农处在弱势地位，实际剥削程度超出契约之外；这类材料非常多，是普遍现象。

### 佃农占上风的情形

   * **地多人少**

       * 农民起义或大乱之后，有的地方土地多而劳动力不足，有地没人种。

       * 此时地主反过来求佃户：给优惠、送礼物、请客吃饭，都得来。

   * **抱团抗租**

       * 佃农联合起来不交租：虽有契约就是不交，理由是租额定得太高，必须降，不降只交五成、七成。

       * 集体抗租在清代不少地方有材料；据说谁照额交租，反而会受大家攻击、群殴，因为个别人交了，团结就破了。

       * > **结论**：租佃关系的主流是地主剥削佃农，但不能读成一成不变的单项压迫；地少人多时佃农挨宰，地多人少或佃农抱团时地主让步——决定强弱的是人地比例与组织程度，不是身份标签。

### 定额租与永佃权

   * **分成租与定额租**

       * 分成租按比例分（五成、六成、四成不定），收多收少与地主收益直接相关，故地主必须严管紧盯，佃户偷懒少打几斗，地主的租就少。

       * 定额租是签约定数，每年交一石或五斗，不管收成多少；地主遂不再管佃户种什么、是否转手，农民自由度大得多，明清越来越多。

   * **永佃权**

       * 佃农有永远耕种之权，四代相传；所有权名义仍属地主，但原则上不能收回，佃农可传子孙、可转佃，地主不能管。

       * 来源多是荒地或战乱荒芜之地：农民投下很大工本把荒地整治成熟田，地主作为补偿允其永种、不收回。

       * 所有权与使用权分离较彻底，中间可夹进一层甚至几层佃户，生产上自由度高，也可能出现多层剥削。

```text
地主（所有权，只收租）
  │  定额租 / 永佃权
  ▼
佃户（使用权，可传子孙、可转佃）
  │  转佃
  ▼
次佃户（实际耕作）
```

   * **与城市化的关系**

       * 地主土地多在农村，人却愿进城住；一进城便管不了地，不能天天盯、不能干预经营，最好的办法就是定额租，其次是永佃权。

       * 故两者在明清后期发展较大，是当时经济自由化的一种表现。

       * > **结论**：官田的三斗起征、租佃的定额租与永佃权连起来看是一条线——国家从土地所有权上后退，地主从经营上后退，实际种地的人手里空间变大。

## 人身等级

### 三个层级

   * **奴婢**

       * 自古以来就有，不完全是一个农业生产的角色，什么都干，很多时候是家内服务；人身自由全无，地位极低。

   * **佃仆**

       * 一种特殊的佃农，主要生活在皖南（安徽南部），身份在普通佃农之下。

   * **普通佃农**

       * 租种别人的地要交押金，还要自己准备种子、农具，属租佃关系。

   * **雇工人**

       * 手工业的雇佣劳动或农业雇工，一无所有，只有身体，只能出卖劳动力，是纯然的雇佣关系。

       * 身份低于佃农、高于奴婢，正好夹在两者之间；从明到清束缚有放松趋势，法律上对短工、临时性雇工渐按一般人承认。

   * **地域差异**

       * 若只看人身自由度，总趋势是往上走的：宋代奴婢少、主要用雇佣，元代奴婢突增，明代仍不少，清代还很多；但这只是平均数。

       * 落到具体地方有松有紧；国家大、社会复杂，两种趋势并存都不奇怪。

       * > **提示**：佃农与雇工的分界不在穷富，而在关系性质——佃农租地交租，还握着一套生产资料；雇工卖力气拿工钱，只有身体。

## 赋役制度

### 黄册与鱼鳞册

   * **黄册（yellow registers）**

       * 户口册，登记整个户口；因用黄纸作封面得名，布政司、府、县各存一本。

       * 配套里甲：十户为一甲，十甲为一里；编里甲是为了服役，一里十甲轮流，每年由一甲应役，十年轮一遍，十年后重造户口、重编里甲再轮。

       * 对政府要求很高：十年必须重新登记一次，登记很细，一做要做好几本。

   * **四柱式**

       * 黄册以户为单位，"详具旧管、新收、开除、实在之数为四柱式"。

| 项目 | 含义 |
| :--- | :--- |
| 旧管 | 原来有多少 |
| 新收 | 这十年里增加了多少 |
| 开除 | 这十年里减少了多少 |
| 实在 | 现在还剩多少 |

       * 因为十年一造，这十年户口必有变化，故每次都要写明原有、增加、减少、现存四个数；这是会计、统计上很讲究的做法。

       * > **定义**：四柱式不是静态余额，而是一段区间内的存量、流入、流出与期末余额；凡要核对"这十年发生了什么"的账，都绕不开这四项。

   * **鱼鳞册（fish-scale registers）**

       * 丈量土地后写明情况并画图；一大片地属好多家，每家画成一块，拼起来像鱼鳞，故名。

       * 有总图也有分图；每块要写形状、四至（东南西北到哪儿）、面积、赋税标准、地理位置，做起来很麻烦。

       * 是否全国普遍实行还有疑问，经济发达地区肯定实行了；人与地在两册中对上，赋与役就有了着落。

   * **好制度，坏执行**

       * 丈量成本太高、太费劲，后来很少丈量，只有张居正认真搞过一次；再往后地方官府拿旧本子抄一遍交差，也没人查。

       * 更省事的办法是预先造假：反正十年查一次，先把十年后的册子做好，来查就给这个看。清初接收明朝档案时不明其故，其实多是地方官府糊弄上面预做的。

       * > **结论**：黄册鱼鳞册的失败不在设计，而在执行成本；十年一造、逐块丈量都是极重的行政负担，负担一旦超过基层能力，账册就从管理工具退化成交差文书。

### 役与一条鞭法

   * **赋与役的难易**

       * 赋税沿用两税法那套基本操作方式，原则与体系比较清楚，但各地收多少不固定、差别很大，与土地质量等因素挂钩。

       * 役麻烦得多：有地方派的、常规的、临时的，各级机构都可能临时来要，名目繁多、摊派原则五花八门。

   * **役的三大类**

| 名目 | 计征单位 | 说明 |
| :--- | :--- | :--- |
| 里甲（甲役） | 户 | 以户计 |
| 均徭（徭役） | 丁 | 以丁计 |
| 杂泛（杂役） | 临时 | 上命非时，临时派下 |

       * 同是服役，一个按户一个按丁，落到具体人家头上结果可以差很远；役中有的要出人，有的折成钱。

   * **一条鞭法的操作**

       * 先确认该地赋税总数；再确认每年所派各种役的总量；把役折算成银；把这笔钱分摊下去；分摊后的钱与赋税凑成一个数，一块征收。

```text
  田赋总额  ─┐
  役折成银  ─┴─→ 合并成一个总数 ─→ 按田亩分摊 ─→ 一次征收（折银）
```

       * 合并发生在"总额"这一层，不是发生在一户一户；分摊的落点是土地，不是人头。

       * 实质是"赋役合一、计亩征银"：简化赋役名义、简化农民负担、统一收钱、一块交政府。

   * **与两税法的异同**

       * 两税法也是把各种东西往一块合并，一条鞭法也合并，但多了一个要紧内容——都要交银子。

       * 对农民是好事，但时间一长地方仍会有各种摊派；一般性摊派、临时加派总免不了，只是不能太过分。

   * **易知由单与赋役全书**

       * 易知由单是发给农民、让其一见就懂的单子：每年交多少钱、为什么收、赋多少、役本有多少、算到你这儿是多少，笔笔写清。

       * 赋役全书是省级预算书：全省赋税多少、应派役多少、折银多少、合并后总数多少，再逐府逐县分下去，如《河南赋役全书》。

       * 做一遍很费劲，但以后每年只需稍作调整，故好多地方都在做。

### 丁银与摊丁入亩

   * **两笔钱**

       * 一条鞭法简化到最后，农民交给政府的钱分两部分：跟土地走的田赋，跟人头走的丁银；丁银全由原来按人头派的役折出。

   * **永不加赋**

       * 康熙五十一年（1712）宣布丁银全国总额固定、不再增加，以康熙五十年的人丁数为准，"滋生人丁，永不加赋"。

       * 道理：丁银随人口增长变动大；田赋定了一块地就动不了，除非再开荒，而清代新开荒地已不多。故把易变的一项固定。

       * 双赢：农民不必担心加人加钱，政府不必动不动下去调查。

   * **定额后的分摊难题**

       * 人丁增加的户好办，一家只交原额；人丁减少的户麻烦：原三丁变一丁，那两份丁银只能转给邻居、亲戚，谁都不愿承接，又要扯皮。

       * 各处丁数多寡不同：原只有一丁而今有数十百丁者共同分担一丁之银，很占便宜；人变少处一丁要承二十丁之银，就很难公平。

   * **摊丁入亩**

       * 总额既已固定，最简便的办法是把它摊进田赋：地多多带、地少少带，不必再为"怎么往人头上分摊"发愁。

       * 规模上也顺：田赋总数大、丁银总数小，把小的散进大的，每亩承担的附加并不多，对一般百姓也有好处。

       * > **提示**：摊丁入亩之所以可行，前提正是"永不加赋"把丁银变成常量；定额一旦确定就不再需要人丁作分母，也就不必再跟人头绑定。两步是一条链上的前后环，不能倒过来看。

## 士绅与宗族

### 士绅的构成

   * **谁算士绅**

       * 在任的官不算：他是职业的政府工作人员，从政府角度考虑问题，归入官僚那一部分。

       * 不在任的官算：有了做官身份而无岗位，在等缺或准备再考；退休的官算：离开官僚队伍回家，官的身份没丢、人脉还在。

       * 预备的官算：主要是秀才这类正朝官的方向走的人。

| 类别 | 是否算士绅 | 说明 |
| :--- | :---: | :--- |
| 在任的官 | 不算 | 职业的政府工作人员，从政府角度考虑问题 |
| 不在任的官 | 算 | 有做官身份而无岗位，在等 |
| 退休的官 | 算 | 离开官僚队伍回家，身份没丢、人脉还在 |
| 预备的官 | 算 | 秀才等，正拼命往官的圈子里挤 |

       * 士绅是老百姓之上、政府之间的中间阶层，称谓有绅士、士绅、缙绅；分类有上层/下层、官绅/学绅、绅/衿，所指基本是拼起来的那几块。

       * > **提示**：判断是不是士绅，看的不是他现在在不在衙门里坐着，而是他有没有那个身份；身份是终身的，职务是流动的。

   * **身份与职务脱钩**

       * 科举自第一级预备考试起，考上任何一档即与一般人不同，有特殊照顾；每上一级身份即变一次，而且终身拥有，与做不做官关系不大。

       * 正因为身份与职务脱钩，社会上才稳定地长出一个士绅群体；张仲礼《中国绅士》估计晚清太平天国前全国士绅约110万，后增至150万。

### 生员之弊

   * **两面**

       * 好的一面：有人代表地方利益与贪官污吏抗争，有人办地方福利事业，有权有势、在地方有号召力。

       * 坏的一面：鱼肉乡里、欺压百姓，利用特权逃避赋役、强占土地，家中奴仆出去打人，强买强卖；有官身者特权更突出，作恶的资料更多。

   * **顾炎武《生员论》的两个角度**

       * 干扰地方行政：有文化有地位，可以跟官府叫板，人多了很厉害；有时代表合理要求，有时就是捣乱、干扰司法与行政诉讼。朱元璋本规定生员不得干政，但执行得不好。

       * 结党营私：一旦中举即拉帮结派，同年、师生的关系复杂，把官场风气也搞坏。

       * > **易错点**：顾炎武骂得未必客观全面，但所指的问题确实存在；读这类材料要分开"他骂得偏不偏"与"他说的事有没有"，两件事不能互相取消。

   * **清代**

       * 清初结合民族矛盾，对南方士绅镇压较狠，气焰被打下去一些；晚清士绅形象似有好转，骂的人相对少了，但这个阶层一直存在。

### 宗族

   * **与周代宗法制、魏晋士族的分野**

       * 宗族制是家族的放大：一批人认定一个共同祖先，结成组织；周代有宗法制，魏晋士族讲血统、修族谱、分高门低门，做法相近而实质不同。

       * 明清宗族比较实用、实体性强；不讲大宗小宗、嫡庶，谁有地位谁当核心、当族长。

       * 不讲门第：大家都修族谱，但不认为自家是高门第一门，也不互相攀比高低；主要功能是控制基层百姓。

   * **祭祖放开**

       * 明代规定老百姓祭祖可不受代数限制；此前按礼教，一般百姓祭祖不得超过五代，只有天子与高官贵人可祭多代。

       * 放开后许多地方能追到很远的祖先，世系或实或虚拟；一旦成组织就不同：选出族长、立祠堂、定族规、置族田。

```text
  共同祖先（实系或虚拟）
          │
        族长
          │
          ├─ 祠堂：祭祀场所
          ├─ 族规：成文约束
          ├─ 族田：共有经济
          └─ 族众：在册人丁
```

   * **两面性与南北差异**

       * 协助政府管理基层，减轻行政成本；有时也与政府不对付，居中闹事、聚众械斗，不走法律程序而用武斗。

       * 对政府有利的一面较大；宗族在南方最活跃、北方差一些，与南方人口密度大、基层管理需求高、文化发达、士绅力量强都有关系。

       * 清中期朱轼说北方士大夫讲不到五代以上祖先，而他江西老家农民动不动就说"我宋祖某某、唐祖某某、周秦汉祖某某"。

## 农业与手工业

### 农业

   * **技术已到顶**

       * 农具、播种、耕耘、除草、施肥这些，明清与以前相比没有太大变化；中国传统手工劳动的农业经营方式早已定型，技术没有太大拓展余地。

   * **增量在作物**

       * 农业的发展主要表现为新品种、新作物的种植：甘薯、玉米、土豆（马铃薯）、高粱等，多为过去没有的。

       * 有些新作物对解决吃饭问题极重要：高产、对土地要求低，可以到处种。

       * > **结论**：明清农业的进步不在"怎么种"，而在"种什么"；工具与工序已经到顶，增量来自作物结构，直接冲着吃饭问题去。

### 手工业

   * **纺织**

       * 《天工开物》记载一种大型纺织机械叫花机，是手工机械但很复杂，似乎用于制作花纹很复杂的丝织品；以前是否有这么大的机器还不大肯定。

   * **制瓷**

       * 从宋代单色瓷，到元代青花瓷，再到明清，图案与色彩更丰富、造型更美观。

       * 清代有专门卖给外国人的出口瓷，图案按外国人的形象来画：东西是中国的，样子照买主喜好做。

   * **珐琅器**

       * 明清才有的新东西，与制瓷工艺有点像而材料不同：胎是铜（金属胎），上釉后用各种料做出花纹，看上去像瓷器。

       * 从国外传来，但制造技术在中国有很大发展，因为中国人做它时用了陶瓷、漆器等传统手工艺技术。

   * **其他**

       * 《天工开物》还提到风箱、采煤的瓦斯排放与巷道支护等技术；其他行业所知不丰富。

       * 总的说，传统经济好像到头了，再进步也是小进步；农业靠新作物，手工业个别行业有进步但不算大。

## 商品经济

### 长途贩运与市镇

   * **波浪式的高峰**

       * 战国秦汉是一个高峰（西汉非常活跃），宋代是一个高峰，元代也还行；明前期是低谷，政策限制极严，明后期又起来。

       * 明代这一次再起来，比以前的水平又要高一点点；每次发展都要比原来强一点。

   * **长途贩运**

       * 各地土特产品远程销售、长途贩运；本地所需的东西也从别处长途买进，产品不再局限在小范围，而可能走很远的路到大范围里流通。

       * 福建的材料最典型：什么地方出什么特产写得清清楚楚，这些东西并不在本地卖，而走海路用船运到很远的地方；福建所需之物也要从很远的地方买入。

   * **市镇**

       * 中国古代人口多的地方多以官府管理机构为中心发展，故城市大部分时候是政治型城市：先有官府设点，再人口聚集、供应跟上，城市才扩大。

       * 明清新起的市镇好多与官府无关，纯靠经济：聚人生产、做生意，越聚越多，到很大规模官府才来设镇。

```text
政治型城市：官府设点 ──→ 人口聚集 ──→ 供应跟上 ──→ 城市扩大

经济型市镇：生产、交易聚集 ──→ 规模变大 ──→ 官府才来设镇
```

       * 例：江苏盛泽镇以丝绸业带起，江西景德镇靠制瓷业；都有某种产业做支撑，与政治关系较小。

### 商帮与会馆

   * **徽商**

       * 皖南山多耕地有限，农业养不活那么多人，只能出外谋生；而皖南周围都是经济发达地区，江南、江西多手工业产地与产品，消费水平高，离海岸线也近。

       * 生活条件逼着经商，经商环境又有利，两个条件同时具备，别处没有这么厉害。

       * 与安土重迁的传统不同：结婚没几年就出去，出去多年不回来，不混出样不回家；商业道德好，不造假货，正当经营竞争。

       * 组织性、地方色彩强；明代倭寇的主要头目多为徽商，可见其活动能力。资料主要见于顾炎武编的《肇域志》。

   * **晋商**

       * 发展比徽商晚一点，主要经营金融业：存钱、放贷、汇款，也贩卖货物，但主营方向是金融。

       * 搞这一行必须有极好的商业信誉，否则无人敢存钱、借钱、托其汇款；山西人有精明、精打细算、生活勤俭的传统。

       * 发展原因说法不一：一说大量钱款存在他们那里、资金丰富；一说顾炎武替他们制定管理方案与规则（不一定可靠）。

   * **会馆**

       * 外地人集资所建、供同乡住宿落脚的地方，如开封的山陕会馆、北京专为绍兴金融业者设的绍兴银号会馆。

       * 会馆普遍出现反映社会流动增加：人人不出门就不需要会馆；明中期以后会馆开始比较普遍。

   * **奢侈与服务业**

       * 城市经济繁荣、高消费倾向带动城市服务业；高消费可增加就业、拉动产业，这道理今天好懂，古代却不易想通。

       * 古代经济思想一直提倡勤俭节约、视奢侈为大忌；明清出现新思想：高消费有好处，不能乱打击，因为它可能拉动经济。

       * 苏州的材料说，苏州许多行业养活多少人；该地经济与生活水平高，一旦压低消费，这些行业马上垮，人全部没饭吃。

### 白银流入

   * **贸易结构**

       * 明中期以后新航路开通，所谓全球化开始，但还很不成熟；中国长期未与西方形成军事冲突，主要是一种经济关系。

       * 中国产品大量输出、白银大量流入：出去的是丝绸、瓷器、茶叶等制成品，进来的是贵金属。

```text
  中国 ── 丝绸、瓷器、茶叶 ──→ 海外
  中国 ←── 白银 ────────────── 海外
```

       * 白银持续流入改变了中国的货币结构：明后期与清代白银货币化，主要货币是白银，其次才是铜钱。

   * **世界体系中的位置**

       * 中国当时在逐渐落后于西方，但并非一开始就落后，是慢慢落后，很长时间里落后得不多、不明显。

       * 中国是大国、人多、产品多，很多产品国外没有，外销量很大；19世纪以前、到18世纪为止白银大量流入，有人甚至说那几百年中国是世界贸易体系的中心。

       * 一般看法是经济落后、生产关系陈旧、近代挨打；但仅就经济而言，挨打之前那一段，其经济实力、产品总量与贸易地位在世界上仍很领先；《白银资本》即强调中国的重要性。

       * > **提示**：明清的商品经济已不完全是一个国内问题，它在某种程度上被拉进世界体系；此前的几个商品经济高峰没有这个问题，这是明清与此前最不一样的地方。

## 资本主义萌芽

### 新现象

   * **手工业的自由雇佣**

       * 明代已有大量材料：纺织、榨油、陶瓷、冶铁等行业，南方很多行业、很多地方都有开厂雇工的做法。

       * 古代手工业基本用奴隶、徒弟学徒、官府控制的工匠，都是人身自由度低、受束缚重的劳动；能干出活，但不是自由雇佣。

       * 自由度高的人身照样能干出很多活，差别就在这里。

   * **农业的经营地主**

       * 不出租土地，而自己开农场，集中管理、集中经营；雇工劳动而非租佃；搞成本核算，为市场服务，追求最大利润。

       * 与收租是两套逻辑：收租关心租额稳不稳，经营农场关心投入产出比。

### 概念争论

   * **"萌芽"二字的预设**

       * 这个概念涵盖一个假设：如果让它自由成长，它就会长成资本主义。

       * 现在较普遍的看法是：现象确实有、也值得注意，但指望它在中国自由成长不太可能，故最好不叫"资本主义萌芽"以免误会；教材已不怎么提这个词。

       * > **易错点**："明清出现了自由雇佣劳动"是事实判断，"这叫不叫资本主义萌芽"是概念判断；前者资料支持得住，后者带着一整套关于发展方向的预设，混为一谈争论就打偏。

   * **总体定位**

       * 中国社会的特点是政治权力比较强大；明清虽出现这些新东西，占主导地位的还是旧的生产关系，离新的生产关系非常遥远。

       * 如果没有后来西方的进入与侵略，恐怕不能指望这些东西自己长起来；它重要、值得研究，但也许不称之为"资本主义萌芽"更好。

## 理学与心学

### 理学四条特征

   * **广义与狭义**

       * 广义的理学可以把心学包括进去，狭义的专指程朱一派。

   * **陈来归纳的四条**

       * 为儒家思想提供宇宙论和本体论的论证，即讨论世界本源这类问题；传统儒家不太涉及，理学家讨论得多。

       * 是一种理想主义的人生观、道德理想主义：讲圣人、讲理想人格，希望人达到圣人的精神境界并以此为人生终极目的；先秦儒学也这样提，但没有讲得这么清楚、这么绝对。故有学者说理学就是一场学圣人的思想运动。

       * 讨论圣人境界的可行性与必要性：基本道德原则在每个人身上都有内在基础，是隐含的、蕴含的，这是人与动物的区别；故人都应把它开发出来，做到"存天理，去人欲"。

       * 具体怎么开发、怎么存天理去人欲，途径五花八门：修养的方法与原则主要来自四书及北宋一些学者的讨论，各家发挥不同，尤多讲修身养性。

   * **分歧所在**

       * 前三条各家大部分相同，对一般社会影响不算关键；最关键的不同在第四条——修养的途径与方法。

### 八条目

   * **《大学》的位置**

       * 理学家关于人生观、修养的讨论主要来自四书，特别是《大学》；朱熹把《大学》列为四书次序的第一部，是最基础的一步。

   * **次序**

       * 八条目：格物、致知、诚意、正心、修身、齐家、治国、平天下，是境界提升、人格完善乃至终极成功的次序。

       * 《大学》汉代已有，但这几个概念过去未特别受注意；到宋代特别是南宋朱熹才做较多阐释，并严格按八条目阐述修养理论。

   * **承认与不承认**

       * 承认八条目的基本次序与完整性，大概就是理学；不承认，或只认一部分、不认为八者之间都有联系且都必要，严格说就不是理学。

```text
              格物  致知  诚意  正心  修身  齐家  治国  平天下
程朱理学        ●     ●     ●     ●     ●     ●     ●     ●
事功学派        ✕     ✕     ✕     ✕     ●     ●     ●     ●
乾嘉考据学      ●    （●）   ✕     ✕     ✕     ✕     ✕     ✕
```

       * 事功学派（陈亮、叶适）与颜李学派：不必一步步来，可以直接治国平天下或修身齐家，去做具体工作。

       * 乾嘉考据学只讲格物、或再加一部分致知，后面的诚意正心修身不管：格物本身就是学术研究、经典考证、文献整理，可以格一辈子；治国平天下与诚意正心可有可无。

       * 朱熹则一步都不能少，而且越靠前的环节越要重视、越不能着急，必须循序渐进，故讲得最多的是"格物致知"。

### 格物致知与发明本心

   * **天理的三个层面**

       * 全世界的本源、万事万物的本源。

       * 具体到每一物，各有其构成原则与基本规律，即其理。

       * 在每个人身上是一种理想的人性，即仁义礼智信这些道德，是善的一面。

       * 天理总起来是一个，体现在万事万物上，也体现在每个人身上。

   * **朱熹的格物**

       * 致知是对天理的认识、体验与把握；领会之后才能诚意、正心，成为比较完美的人，再修身齐家治国平天下。头两步最重要，头两步里的第一步又特别重要。

       * "即物而穷其理"：就天下之物，因其已知之理而益穷之，用力之久而一旦豁然贯通，则众物表里精粗无不到，吾心全体大用无不明。

       * 何时贯通不好说，看功夫，也可能与资质、运气有关；但最基础的功夫是积累，没有积累想坐着忽然贯通不可能。

   * **陆九渊的方向**

       * 终极目标与程朱一样是治国平天下，但重点在致知而非格物，可以先知后格。

       * 因为天理就在每个人心里，对自己的内心反省、沉思、静坐即可体会，不必一件件去格物；先体会到天理，再格物就非常简单。

       * "宇宙便是吾心，吾心便是宇宙"；"苟此心之存，则此理自明"。

   * **对待学习与经典**

       * 一般人教学生是加担子，让学生学很多东西；他带学生是减担子，让学生把很多东西丢掉。

       * "学苟知本，六经皆我注脚"：经典是次要的，关键是内心的体验、认识与把握。

   * **两派对照**

| 比较项 | 程朱理学 | 陆王心学 |
| :--- | :--- | :--- |
| 天理所在 | 万事万物各有其理，须即物而穷 | 就在每个人心里，反省静坐即可体会 |
| 功夫次序 | 先格物，后致知 | 先致知，后格物 |
| 认识方向 | 由外向内，积累而后贯通（归纳） | 由内向外，推致于事事物物（演绎） |
| 对待经典 | 四书为阶梯，逐条阐释 | 六经皆我注脚 |
| 主要风险 | 容易僵化、教条化 | 以自我为准，末流不可控 |

       * 南宋时两派争论激烈，后来朱熹一派占上风，陆九渊一派比较边缘化。

       * > **易错点**：心学并不否认治国平天下的目标，也不否认格物本身；分歧在次序与重心——先知后格，还是先格后知。

## 阳明学

### 致良知

   * **时代背景**

       * 明初思想界全是朱熹一派统治，时间长了比较僵化、没有新东西；任何思想一旦成为统治意识形态，总会有投机分子打其旗号干坏事，破坏其形象。

       * 《明史·儒林传》："学术之分，则自陈献章、王守仁始。"陈献章影响小（学生少、传播不够），王守仁带很多学生，且很致力于学术的传播与扩张。

       * 王守仁又是大名人：不只是学者，还是政治家、军事家，明武宗时宁王叛乱即由他镇压；既能格物致知又能治国平天下，名气大，学派影响也大。

       * 《明史》说在其门徒影响之下，"嘉隆而后，笃信程朱、不迁异说者，无复几人矣"。

   * **吾性自足**

       * 他起初走科举、文章之学，遍读考亭之书，按朱熹的路子格物，却觉得达不到致知境界，一度放弃，又研究佛、老。

       * 折腾之后恍然："格物致知之旨，吾性自足，不假外求。"关键都在我心里，不必到外面去积累。

       * 他认为宋儒向外的积累太迂回、太麻烦、靠不住。

   * **与佛教的界限**

       * 有人说其学近禅，因为禅宗讲顿悟、立地成佛，这种倾向在他这里确实有。

       * 他辩解：佛教只管修养、只管自己的问题，不管外部世界与环境；我们终归还要向外，要内外合一，天地万物的问题都要解决，只是先把内心问题搞清楚，再由内向外推。

       * 故他仍支持格物致知、最后仍要治国平天下，是关心世事的、用世的，不是出世的；但就修养、如何致知这一段，确实很像佛教，这一点早有人批评。

   * **致良知的含义**

       * 朱熹是格物而后致知；王守仁是先知后格，致知即"把知识送出去"——"致吾心之良知于事事物物也"。

       * 内心天理已认识到，再把它推广到外面，用它观照外物，万事万物自然各得其理。

       * 认识过程由内往外推，是演绎；朱熹是归纳，最后总体通了。两边方向正好相反，终点相同。

```text
朱熹（归纳，由外向内）                王守仁（演绎，由内向外）
格物：即物穷理，一件件积累             致知：先明本心，认得良知
        │                                      │
        ↓                                      ↓
致知：积累久了，豁然贯通               格物：以良知观照事物，各得其理
        │                                      │
        ↓                                      ↓
诚意 · 正心 · 修身                     诚意 · 正心 · 修身
        │                                      │
        ↓                                      ↓
齐家 · 治国 · 平天下                   齐家 · 治国 · 平天下
```

       * 他强调做学问主要是"明其心"：心本纯洁，被杂念蒙蔽，恢复本性即认识到天理；一开始就往外面折腾是走弯路。此喻来自佛教，禅宗讲"心如明镜台"。

       * 天理无处不在，存在于天地之间也存在于每个人心里；人因有形体把天理切开，各得内部这一块，但总体相通。认识了自己心里的天理，就认识了整个世界。

### 良知

   * **定义与例子**

       * 良知是人心里的那一刹那的善念、基本的冲动与感觉；"心自然会知"。

       * "见父自然知孝"：见到家人自然有一种感情。

       * 乍见小孩要掉进井里，任何人都会一急要去拉，好人也罢坏人也罢，那一刹那反应一样；若经思虑（怕被赖上）就不一定去救——良知是未经思虑的第一反应，是"本来面目"。

   * **自家痛痒自家知**

       * "知得良知却是谁？自家痛痒自家知。"良知在自己身上，问别人就完全走偏。

       * 王畿讲得更直：良知首先是是非之心，"其机存乎一念"——第一感觉该干就勇敢去做，第一感觉不该干就打死也不能干。

   * **个人主义的风险**

       * 良知靠内心判定，每个人未必一样；情形一复杂，各人反应是否完全相同也不一定。

       * 他的态度是坚持自己的感觉与判断，即使与多数人不同也不放弃，故个人主义、主观主义色彩明显。

       * 王畿："幸得良知致时，独往独来，如珠之走盘，不待拘管。"只要不出盘子，随便怎么滚；惊世骇俗、特立独行，与师长教导、经典告诫不同也不要紧，一律以我为准。

       * 这套东西发展下去不可控，也是朱陆之争中陆学不占上风的原因之一：心学初看很好，发展下去就控制不了，对统一思想、保持一致不利。

       * 但在明代，因程朱统治太久、比较僵化，总得出点新东西，所以这帮人出来，一传播还很快。

### 四句教与泰州学派

   * **四句教**

       * "无善无恶心之体，有善有恶意之动，知善知恶是良知，为善去恶是格物。"

       * 心体无善恶，意念有善恶，良知知善恶，格物即革除恶念、发扬善念；这四句还不算太超越理学范畴。

   * **四无说**

       * 王畿推为：心无善无恶之心，意亦无善无恶之意，知亦无善无恶之知，物亦无善无恶之物。

       * 什么都无善无恶，基本取消了价值判断：善恶没有区别，关键是你怎么感觉，乐就乐。这就超出了伦理道德框架，是心学可能冲出去的危险。

   * **李贽的童心说**

       * "童心者，绝假纯真、最初一念之本心也。"即第一下的感觉，最真挚，感觉到什么就表达出来。

       * 小孩最明显：一疼就哭，不管环境适不适合；想吃就要，不给就哭，不管该不该吃、是否卫生。他认为这就是良知，最可贵的是保持它。

       * 良知的概念听着还可以，走到童心就麻烦：若人人如婴儿、全无理性，看见什么就抢、不给就哭，并不合适；但这一派到后来很多人正是这样想，认为加了框框就完蛋、就没价值。

   * **泰州学派**

       * 黄宗羲："其人多能以赤手搏龙蛇，传至颜山农、何心隐一派，遂复非名教之所能羁络矣。"即要打破名教，什么都不认。

       * 颜山农、何心隐不好念书，到处讲学、带很多学生；有人说他们连句子都断不开、字也不识几个，却能高谈阔论，比较唬人。

       * 他们讲好色贪财也没关系，这就是本性：良知讲到童心，童心看不出善恶，便可理解为基本欲望；顺其自然，不要刻意束缚。

       * 这套话在中下层劳动人民、以及反感说教大道理的人中比较受欢迎；其思想带叛逆性，今有书称之为启蒙思想家，说与近代某些观念暗合，也有可能。

       * 但要说它代表一个新社会的到来，或如经济上的"资本主义萌芽"那样有高地位与发展潜力，还很难说。
