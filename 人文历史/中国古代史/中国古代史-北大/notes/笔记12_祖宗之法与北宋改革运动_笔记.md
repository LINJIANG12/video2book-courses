# 祖宗之法与北宋改革运动

## 祖宗之法

* **祖宗之法（祖宗家法）**

    * > **定义**：太祖、太宗两朝订立、由士大夫参与整理阐发的一套规矩与法度。它不是成文法典，而是制定各类成文法时依循的指导原则，也是宋朝一贯的统治基调。

    * 太祖致赵普书札自述：「朕与卿定祸乱以取天下，所创法度，子孙若能谨守，虽百世可也。」可见立国之初已有使法度世代承袭的自觉。

    * 太宗即位诏提炼为八字：「先皇帝创业垂二十年，事为之防，曲为之制。」真宗、仁宗、英宗的即位诏书、登基赦书都有意思相近的表示。

    * 这些诏书不能只当套话看：套话流行本身反映当时的政治环境与文化背景，而在宋代，它确实起到了统治基调的作用。

* **事为之防，曲为之制**

    * > **定义**：防弊之政的确切表述——所有事情预先防范，并以委曲周全的方式细密设限。

    * 事为之防：防弊要防在事前，不是弊端发生之后再来补救。

    * 曲为之制：曲是委曲周全，制约要全面、细致，落到具体环节上。

    * 操作原则是防微杜渐：使弊端不至于发生，至少不至于影响太大。

* **不成文的性质**

    * 祖宗之法没有条款可数、无法翻检条文，与唐代那套成文法体系分属两类；宋代另有自己的成文法，祖宗之法在其之上。

    * 正因不成文，解释边界是活的：北宋、南宋官员各按自己的理解阐发，说法差别很大。

    * 哲宗朝宰相吕大防侧重皇族内部关系与君臣关系；也有人把它说成处理文武关系的原则；陈傅良（马端临《文献通考》引）把收商税的具体办法也算作祖宗之法。

    * > **易错点**：不要把祖宗之法当成一部可按条引用的法规汇编。它是一套原则，谁都能引，也谁都能按自己的需要解释。

* **不杀士大夫**

    * 相传太祖立碑三条，其一为不杀士大夫及上书言事之人；另有一说认为实际上并无此碑，碑之有无存疑，但这一原则在宋代确有实效。

    * 程颐举「三代以后本朝超越古今者五事」：百年无内乱；四圣百年；受命之日市不易肆；百年未尝诛杀大臣；至诚待夷狄（指澶渊之盟）。

    * 元丰年间陕西五路伐夏失利，神宗内批欲斩一名漕臣；宰相蔡确以「祖宗以来没有杀过士人」拦下，改为刺字发配烟瘴之地；门下侍郎章惇以「士可杀不可辱」再争，神宗怒称「快意事也做不得一件」，章惇答「如此，快意事不做也好」。

    * 与后来金、元、明士人公开受廷杖形成对照，宋代士大夫的待遇与地位明显不同。

* **谁的法**

    * 祖宗之法是皇帝与士大夫集体政治智慧的结晶：「稍夺其权，制其钱谷，收其精兵」出自赵普建议，许多法度都是吸纳士大夫建议之后形成的。

    * 祖宗形象经士大夫筛选包装而成：石介撰《三朝圣政录》进呈仁宗，性质是帝王学教材；韩琦指出书中「太祖因宠姬晚朝而杀之」一事「此岂可为万世法」，石介遂删去。

    * 祖宗之法对皇帝构成约束：祖宗是帝王自己的祖先，经整理的嘉言善行从伦理与法度两面形成限制，缓解了「如何制约皇帝」这一纽结。

    * 它不是单纯的「回头看」：因有阐释空间，可以回应当下政治问题，本身蕴含着现实政治发展的需要。

## 地方集权

* **三条路径**

    * 赵普概括为九个字：稍夺其权，制其钱谷，收其精兵。一句话对一个口子，正好拆成三层。

    * 中央一线的两条：控制禁军兵权（如杯酒释兵权）、建立最高官僚机构的制衡方式。

* **稍夺其权**

    * 唐末五代节度使兼握军权、行政权、监察权，故藩镇势盛。

    * 宋陆续派文臣出任知州、知府，「知」即全面管理州务。

    * 关键在于改隶属关系而非换人：州府由隶属节度使改为直接听命于中央。

    * 通判为州的副长官，与知州并存。

    * 罢支郡：节度使驻节之州为治所，其余归其管辖而不驻节的州为支郡；罢支郡不是废州，而是使这些州不再从属于该节度使。此事自太祖至太宗才完成。

* **制其钱谷**

    * 各州财富除本州必需之外一律上归中央。

    * 接两税三分旧账：一份上供、一份送使、一份留州；此时送使一份取消，除留州外皆归中央。

    * 收归中央很大程度上是账面上的调拨与控制，不是把粮食实物全部运往开封再按需运回。

* **收其精兵**

    * 先选身高体壮的年轻军士若干人合成标准，称「兵样」，派往各地，凡高矮可比者抽补禁军。

    * 兵样不足时改用木棍比高，称「等长杖」，凡高于此杖者抽至中央。

    * 太祖时全国禁军约二十二万余人，开封聚集约十万，外地约十万，近似唐前期关内集中约四成的格局。

* **战略取向**

    * 太宗雍熙北伐失败后对外政策内缩，定下强干弱枝：中央军事力量要压倒地方，使地方无力与中央匹敌。

    * 同时定守内虚外：视内忧为主要威胁，外患次之。

    * 开封为四战之地，无天险可守，故宋人主张「以兵为险」，以兵立国是根本战略方针之一。

    * > **易错点**：「重文轻武」不足以概括宋制。太祖、太宗本人出自军旅，环境又是强敌环伺；枢密院由文臣负责属制衡设计，不是轻视武装。军队战胜机会少，要从制度带出的深层弊端去找原因。

## 二府制与中枢

* **二府制**

    * 北宋中前期中枢称二府制：中书门下（民政、行政）与枢密院（军政、机要）对称「二府」。

    * 另有掌财政的三司与负责监察的机构。范镇语：中书主民，枢密主兵，三司主财。

    * 民政、军政、财政、监察四线并列，横向谁都不吞掉谁；纵向最后都收到皇帝面前的御前会议。

```text
皇  帝
  └─ 御前会议（国家最重大决策在此议定）
       ├─ 中书门下 ····· 民政、行政，正副宰相集体处理政事
       ├─ 枢密院 ······· 军政、机要，通常由文臣负责
       ├─ 三司 ········· 财政
       └─ 监察机构 ····· 监察
```

* **中书门下与御前会议**

    * 唐代三省长官在政事堂议事；宋代皇帝亲自参与宰相议事，称御前会议，国家最重大决策在皇帝面前议定。

    * 政事堂此时成为中书门下的代称；中书门下办事地点设在禁中，与唐代中书省、门下省在禁中一脉相承。

    * 中书门下是正副宰相集体处理政事的最高行政机构。

* **枢密院**

    * 性质三变：唐为宦官掌机要；五代因朱温尽除宦官，改由皇帝亲信掌领；宋成为外朝机构，掌全国机要特别是军政。

    * 与掌民政的中书门下平起平坐，略低一等。

    * 通常由文臣负责，称「文臣知枢密」，属制衡而非轻武。

* **三司**

    * 名称来自唐代盐铁使、度支使、户部使三职合并，但在宋代是一个部门而非三个部门。

    * 首长三司使主管国家财政，称「计相」，为亚执政，位仅次于执政（参知政事与枢密院长官）。

    * 元丰改制后三司撤销，职能并入恢复的三省六部体制。

* **宰执称谓层级**

    * 中书门下垂官：同中书门下平章事（宰相）、参知政事（副宰相）。

    * 枢密院长官：资深者为枢密使，副手枢密副使；无资深者则由皇帝指定，称知枢密院事，副手同知枢密院事。职责相同，名称之别反映本人身份层级。

    * 执政狭义指参知政事加枢密院长官；广义指协助皇帝的重臣；最外一层合称宰执。

    | 名目 | 所指 |
    | :--- | :--- |
    | 宰相 | 同中书门下平章事 |
    | 执政（狭义） | 参知政事、枢密院长官 |
    | 执政（广义） | 协助皇帝的重臣 |
    | 宰执 | 宰相与执政的合称 |

    * > **易错点**：北宋前期所说「中书」不是中书省，而是中书门下；「枢密」也不是唐代宦官掌领的内职，而是外朝机构。三省制此时已名存实亡。

## 元丰改制

* **时间与依据**

    * 元丰三年至五年（1080—1082）由神宗主持，基本效法《唐六典》。

    * 这是北宋官僚制度「前期」与「后期」的分界。

* **恢复三省**

    * 把合并后的中书门下改回中书省、门下省、尚书省三省，等于把唐代走过的路倒着走一遍。

    * 尚书省下恢复六部。

    * 三省分工沿用旧原则：中书省出令、门下省审核、尚书省执行；中书省、门下省仍设在禁中。

    * 有臣僚主张连枢密院一并拆开（唐前期本无枢密院），神宗不同意，枢密院保留。故改制结果与唐制并不相同。

* **体制名称**

    * 改制前为二府（两府）体制；改制后中书门下拆为三省、枢密院保留，称三省枢密院体制。

    * 这一体制为此后北宋后期的基本格局，并一直延续。

    * > **易错点**：元丰改制号称复唐制，实际是三省加枢密院的混合体；中书门下也不等于中书省。

* **以阶易官**

    * 让台省寺监之官实典职事，「领空名者一切罢去」。

    * 把原唐代执事官名称换成「某某大夫」「某某郎」，如六曹侍郎改为正议大夫。

    * 新名称淡化职司色彩，只承担定品级、定俸禄的功能，称寄禄官（寄禄阶）。

    * 原带职事的六曹尚书、侍郎等称谓恢复实职，与本曹事务重新对应——改回三省制、六部须有人管事，正需要把旧名号腾出来。

    * 本官系统自此发生根本变化：旧官称不再暗示职掌。

    * > **定义**：以阶易官，即用大夫、郎这一套阶官名称取代原职事官名称，名称一换，旧官称就不再暗示职掌，只负责定品级、定俸禄。

## 军制

* **枢密院—三衙体制**

    * 分割办法先分「调」与「管」：调遣权在枢密院，调哪一部分军队、发什么样的作战命令皆由枢密院发出；军队日常训练与管理归三衙。

    * 三衙为殿前司（殿前都指挥使司，首脑殿前都指挥使）、侍卫马军司、侍卫步军司；机构合称三衙，首脑合称三帅。

    * 殿前都点检在太祖即位后不再设置，故殿前司首脑改为殿前都指挥使。

    * 分三衙的目的是相互制约：某一禁军统帅图谋不轨，其余禁军统帅可以制约他。

```text
      枢密院                  三衙
     （掌调遣）            （掌训练管理）
         │                     │
         └─────────┬───────────┘
                   ▼
           战时：临时指定将领
                   │
                   ▼
        军  队 ────？──── 将  领
                素无了解
```

    * 太祖本人即殿前都点检，正常状态下管不了马军司、步军司；只有对外作战需要集中兵力、任命统帅时，三衙部队才会集合起来，这为其发动兵变提供了便利。

* **地方统军与出征**

    * 地方统军为都部署，原为方面军总指挥，统一过程基本完成后变为地方大军区负责人，各分一地。

    * 因避英宗赵曙讳，都部署改称都总管，二者是同一官职的前后名称，不是两个官。

    * 出征作战时临时调拨部队、临时派任将领。

    * 神宗语意：军队分散设置是为相互维系制约；军队不直属于宰相而保留枢密院，是为军政与行政相互制约。

* **募兵制**

    * 唐后期已行募兵，宋代沿用，性质是职业雇佣兵。

    * 太祖视募兵为保持国家稳定的重要原因：流民多、灾害多的地方大规模招兵，由国家供应吃穿，以军队纪律把可能威胁国家的人口整合进保卫国家的力量。

    * 另一面是代价：募兵的全部供应出自国家财政，宋代财政长期喘不过气与此直接相关。

* **军队类型**

    | 类型 | 性质 | 主要职责 |
    | :--- | :--- | :--- |
    | 禁军 | 最精锐的部队 | 国家核心军事力量 |
    | 厢军 | 国家供养但非精锐野战军 | 地方杂役、地方治安 |
    | 乡兵 | 地方民兵、预备役性质 | 地方防卫 |
    | 蕃兵 | 边境少数民族军队 | 边境防务 |
    | 土兵、弓手 | 不在正规军队编制内 | 地方巡防捕盗 |

    * 厢军与禁军之别不在是否由国家供养，而在是否承担精锐野战任务；厢军主要承担地方杂役与治安，修桥铺路、堵堤决口也往往由厢军去做。

## 台谏

* **台谏合流**

    * 御史台与谏院合称台谏，二者在宋代有合流趋势，职责接近，同为帝王的「言路」。

    * 御史台首长唐代为御史大夫，宋代为御史中丞；无御史中丞时由侍御史知杂事（知杂侍御史）出任首长。

    * 职能是对百官监察、对国家大政参与意见，被称为「立国的元气」；执政遭台谏弹劾，往往引咎辞职、待皇帝发落。

* **风闻言事**

    * 台谏官可据传闻议论某官，不必交代信息来源。

    * 一面保护台谏官，一面保护信息源头，同时也会带来负面问题。

    * 宋人视之为防范弊端的祖宗之法，属防微杜渐所不可少。

* **诏狱**

    * 皇帝指定审理的重大案件称诏狱，台谏官与唐代一样参与审理。

    * 岳飞案即诏狱：御史中丞何铸「引飞至庭，诘其反状」，岳飞解衣示背，刺「尽忠报国」四字；何铸以此向秦桧称无造反证据，后被换下，改由万俟卨审理，冤案乃成。

    * > **易错点**：岳飞背刺是「尽忠报国」，不是「精忠报国」。后者是与高宗赐旗「精忠岳飞」一事混传而成。

## 地方层级

* **路**

    * 宋代原则上地方为两级：府州军监（州级）与县；路设于州之上，但不是正式行政区，如同汉代十三州部，处在向行政区过渡的过程中。

    * 初设转运使路，共十五路；后因一路事务增多而析分，神宗时二十三路，北宋最多二十四路。

    * 路名已接近后世省名：河北东路、河北西路合为后来的河北省，两浙路为浙江省，福建路为福建省。

    * 一路不设唯一长官，此即其非行政区的证据之一；北宋中期以后每路有四个机构。

    | 机构 | 简称 | 长官 | 职掌 |
    | :--- | :--- | :--- | :--- |
    | 安抚使司 | 帅司 | 安抚使（由首州知州兼任） | 协调一路军政 |
    | 转运使司 | 漕司 | 转运使 | 财政、赋税，四司中最重要 |
    | 提点刑狱司 | 宪司 | 提点刑狱 | 司法、狱讼 |
    | 提举常平司 | — | 提举常平 | 常平仓、地方贸易、榷卖，多与新法相关 |

    * 首州是一路中最重要之州（如福建路以福州为首州），首州知州即兼任本路安抚使。

    * 转运使司、提点刑狱司、提举常平司合称监司。

    * 提举常平司设立最晚，王安石变法期间才在全国普遍设置，此后曾废复。

* **府州军监与县**

    * 四个称谓行政级别相同，均为州级；称「府」者「体制稍尊」，地位较高。

    * 北宋四个京府：东京开封府（首都）、西京河南府、南京应天府、北京大名府；其余为次府。

    * 应天府原为宋州：赵匡胤曾任归德军节度使，治所在宋州，故升州为府，取顺应天意之义。大名府在河北，因建为北京。

    * 皇帝封王之地往往升州为府，如晋州改平阳府。

    * 州为常规建制；军为曾驻军或军事要地，规模较小；监为有国家采矿、冶炼产业之地，规模亦小。

    * 府有知府、州有知州，县有知县或县令；县下乡、里属差役性质，不是正式行政层级。

    * 这套设置在分权基础上形成层级之间的统合与制衡，各机构各管一摊、互成制约。

## 官、职、差遣

* **名实分离的总格局**

    * 《文献通考》：「名号品秩，一切袭用唐旧……三省、六曹、二十四司，类以他官主判，虽有正官，非别敕不治本司事，事之所寄，十亡二三。」

    * 只有名号（名称）与品秩（级别）沿用唐制；三省六曹二十四司的运作已变：多由他官典领，带本司官衔而不到本司任事，名衔与实际职务吻合者十无二三。

    * 六曹即尚书省六部，每部四司，共二十四司。

* **三样名号**

    * 官（本官）：官以寓禄秩、叙位著——决定俸禄等级与朝班位次。本官名称都取自唐代三省六部的职事官名。

    * 职：职以待文学之选，特指馆阁职。三馆为昭文馆、史馆、集贤院（集贤殿）；阁有秘阁、龙图阁、天章阁等。

    * 差遣：差遣以治内外之事——实际掌管的事务，三者中最有实质意义。

    * 馆职另有标识序列之用：宰相带昭文馆大学士者为首相，带监修国史者次之，带集贤院（殿）大学士者又次之。

    * 职有资格限制，须科举出身或有文采、清望者方可得；且不必到馆阁任事，名号贴附于身，故称贴职。

    * 官、职、差遣之外还有阶、勋、爵，名号体系极为复杂，但最主要的是把握差遣。

    | 名号 | 作用 | 是否决定实际职务 |
    | :--- | :--- | :--- |
    | 官（本官） | 定俸禄等级、定朝班位次 | 否 |
    | 职 | 馆阁之职，标榜文学出身，多为贴职 | 否 |
    | 差遣 | 实际掌管的事务 | 是 |

* **阶官化**

    * > **定义**：官称还在、职事已失，剩下的名称只用于定品级、定待遇、定朝会排班位置，成为身份层级的象征。

    * 成因是使职差遣增多，三省六部的事权被抽走。陆长源语：兵部不问戎政，户部没有版图，金部仓部管不了钱谷，光禄寺不供酒，卫尉寺不供帐幕，秘书省不校勘，著作局不修撰。

    * 机理：户部司原管天下赋税，但国家临时调拨来不及走程序；刘晏等兼租庸使、青苗使，直接对政事堂、中书门下负责，户部一司小官无从管辖。机构仍在而形同虚设，一司如此，各司皆然。

    * 使职（转运使、节度使）在官品令上没有位置，入朝排班仍须依本官衡量身份——这正是旧官称得以保留的原因。

    * 官与权背离早有先例：西汉御史六百石而可监督二千石，称「官小而权之众」；唐代散官标身份、职事官掌权责，本为两个系统，非宋代始有。

* **结衔读法**

    * 包拯结衔：龙图阁直学士（贴职）、刑部郎中（本官，自江宁调来时升右司郎中）、权知开封府（差遣）。职未变、官升一级、差遣更换。

    * 欧阳修结衔：功臣号—观文殿学士（贴职）—特进（散官）—行兵部尚书（本官）—知青州、充京东路安抚使（差遣）—上柱国（勋）、乐安郡开国公（爵）、食邑四千三百户、食实封一千二百户。

    * 青州为京东路首州，故其知州兼任本路安抚使，此为差遣而非本官。

    * 判读规则：带「知、判、充、提点、提举、管勾、管干、监」字样者多半为差遣；差遣也多半与这类字样相关。

    * > **易错点**：见「龙图阁直学士」不等于在龙图阁办公。贴职是荣誉性馆阁头衔，定身份与清望；真正的差事是「知开封府」。

* **名实分离的收益**

    * 王禹偁罢去差遣后，其子代为交涉，要求本官照旧升迁，此要求后来为各方接受：撤差遣而升本官，渐成惯例。

    * 效果是俸禄与基本待遇上升、实际职责可能下降；人事调整有了缓冲，人员较易接受，整个体系运转更灵活。

    * 手法上是「拿走实权的同时抬升身份」，既调整岗位又保住体面。

## 科举取士

* **开放性来自严密性**

    * 郑樵《通志·氏族略》：隋唐而上，选官与婚姻皆据家世谱牒，原则是「贵有常尊，贱有等威」；五代以来变为「取士不问家世，婚姻不问阀阅」。

    * 科举报名仍写家世背景，但不构成录取时的影响；缔结婚姻也不再以门第为主。阀阅即世家背景。

    * 社会身份由恒定转为流动，科举提供了流动最重要的契机。

    * 表面看「开放」与「严密」相反，实际正是锁院、糊名、誊录、别头试这套严密手段，把人情因素挡在门外，才撑起了向所有人开门。

* **三级考试**

    * 科举隋代已出现，唐代渐受重视，宋代正式形成三级考试与录取程序。

    | 层级 | 主持与地点 | 考中所得 | 第一名称谓 |
    | :--- | :--- | :--- | :--- |
    | 解试（乡试） | 州郡，地方主持 | 解，即文状、文凭 | 解元，亦称解头 |
    | 省试 | 尚书省礼部，知贡举主持 | 中式，取得殿试资格 | 省元；称会试时称会元 |
    | 殿试 | 殿陛之上，皇帝亲策 | 及第并排定名次 | 状元 |

    * 省试之「省」指三省（尚书省、中书省、门下省），非元代以后的行省；唐以来科举由尚书省礼部主持，故名。明清改称会试，第一名即会元。

    * 知贡举之「知」即负责。白居易以主客郎中知贡举、苏轼亦曾知贡举，本官与差遣分离于此可见。

    * 殿试唐代偶有而未成制度，宋代才制度化；用意是把门生变成天子门生——过去知贡举者为座主、被取者为门生，取士之权与人际观念绑定，皇帝不踏实。

    * 解试、省试、殿试皆为第一，称「连中三元」。

* **防范手段**

    | 手段 | 做法 | 主要防什么 |
    | :--- | :--- | :--- |
    | 锁院 | 知贡举入院出题，不得回家、不与外界接触 | 请托、考前串通 |
    | 糊名（封弥） | 折糊卷头姓名部分 | 考官认人、按名录取 |
    | 誊录 | 另派吏人重抄全部试卷 | 笔迹、特殊暗记 |
    | 对读 | 专人校对抄本与原卷 | 誊录抄错 |
    | 别头试 | 考官亲属另设考场、另派命题人 | 亲属避嫌 |

    * 唐代知贡举在外，请托者可以直接送来门生旧作；宋代锁院之后此路不通。

    * 成本与投入极高，但确实大幅压缩了考官作弊与考生考官勾结的空间。

    * 糊名挡得住姓名，挡不住文风：元祐三年苏轼领贡举，李廌应考，苏轼认文风置一篇为第一，拆号却是章援（章惇之子）。李廌落第，苏轼赠诗「平时谩说古战场，过眼终迷日五色」，末句「知子无怨亦无德」。

    * 真正起作用的不只是「考官认不出谁是谁」，而是拆号之后无可更改的程序。

* **录取率与解额**

    * 解试约十取一，省试大体亦十取一，总录取率约百分之一，甚至更低。西北报考者少，录取率相对高；东南报考者众，解试本身录取率就低。

    * 福州：乾道元年（1165）解试生员一万七千余人，解额六十二；淳熙元年（1174）两万余人，取四十二。

    * 解额如何分配极为敏感，欧阳修与司马光在仁宗朝曾就此激烈争论。

    * 宋代按年均计算的取士数额为历代最高，尽管其领土非最大、人口非最多。

* **正奏名与特奏名**

    * > **定义**：正奏名是正式考中者；特奏名是多次参加省试或殿试未中、但满足「终场」与一定举数（或年龄）的落第举人，由朝廷特予照顾，直接参加殿试。

    * 终场指坚持考完全部场次；某场自度不佳即弃考者不算。

    * 举数标准前后变化大：北宋前期年年开科，曾规定考满十五次者给特别机会；改为三年一开科后举数放宽；未达举数而年龄已高者亦可获照顾。

    * 嘉祐二年以后殿试不再黜落：通过省试者一律录取，殿试只负责排名次。

* **登科录与平民出身**

    * 宝祐四年（1256）登科录录取分五甲，第一甲第一名文天祥。当年共录取进士六百零一人，其中平民出身四百一十七人。

    * 平民出身指三代无官：曾祖、祖父、父亲皆无官职。文天祥三代皆无官，登科录上三格空白。

    * 第二名曾祖、祖父无官而父为迪功郎；迪功郎为元丰以后选人阶中从九品的最低一阶，得此阶者常无实际差遣，身份仍须写入。

    * 同年指同一年通过科举，不是同龄；同年录（登科录）即同榜者名册，存世仅绍兴十八年同年小录与宝祐四年登科录两种。

    * > **易错点**：三代无官只覆盖父、祖、曾祖，兄、叔、岳家为官皆不反映；官宦之家也未退出，主要另有恩荫一途。这组数据不能单独证明社会流动的全貌。

* **恩荫与新型士人**

    * 恩荫亦称荫补、任子：荫是大树底下的阴凉，这片阴凉由朝廷的恩而来。子孙乃至孙辈可不经科举入仕，但升迁路径不同、速度较慢。

    * 榜下捉婿：《墨客挥犀》载富贵之家就放榜处择婿，甚至派仆人将中榜少年簇拥回家；一少年被拥至富家，答「我本来出身寒微，能够托迹高门，这是我的幸运——等我回家跟我太太商量商量」，众人哄堂大笑而散。

    * 通过科举、恩荫等途径涌现出一批新型士人，其思想倾向、政治态度、文化品格与前代大不相同。

    * 能力素质上与前代判然有别：唐代姚崇、宋璟事功显赫而诗文无闻，李白、杜甫诗名极盛而事功无闻；宋代王安石、范仲淹、欧阳修、苏轼则政治家、思想家、学者、文士集于一身。

    * 余英时称这一时期「政与学兼收并蓄」：学术之路与从政之路尚未截然分开。《岳阳楼记》「先天下之忧而忧，后天下之乐而乐」是一代人的自我期许，非一人之襟怀。

    * 文彦博在变法期间提出「与士大夫治天下」，意涵不止于士大夫作为统治工具，而是共治；士大夫成为政治的主体，主动参与治理方针的建设，此种方针当时称「国是」。

## 学校与士人养成

* **官学体系**

    * 国子监总管全国学事。中央在开封设太学、国子学、律学、算学、书学；地方为州学—县学两级，南宋地方学事由设在临安的提举学事司掌管。

    * 国子学、太学、四门学的教材与课程设置基本相同，区别在入学资格——家庭背景决定进哪一所，不在专业、课程或水平高低。

    * 苏颂称宋代无国子、太学、四门之别，指身份区别被淡化，非谓名称不存；国子学后来不再单独招生，名称尚存而身份之别落空。

    * 北宋中期三次兴学：庆历、熙宁、崇宁；郡县建学、太学加强，真正得到强化的是太学。

* **三舍法**

    * 熙宁年间王安石创立，又称三舍考选法、三舍选察升补法，目的是为变法提供更多人才。

    * 分外舍、内舍、上舍三等；州县学生入学先进外舍。

```text
州县学生 ──> 外　舍 ──私试·公试屡优──> 内　舍 ──屡优──> 上　舍
                                                          │
                                            上舍生中突出者 ──> 直接取得进士身份
```

    * 私试每月一次，由学校教师自行出题；公试每年一次，较为重要。屡次私试、公试成绩优异者逐级升舍；上舍生中突出者可直接取得进士身份，不经科举。

    * 实质是学校升贡：靠多次选拔积累升进，不是一考定终身；此法一度推广到州县学校。

    * 宋代曾有很短时期废除科举、进士全出上舍，后即恢复。

* **三经新义**

    * 三经为《诗》《书》《周礼》；《周礼义》由王安石自作注释，《诗义》《书义》非其本人所注。

    * 成书后成为太学主要教材，也成为科举录取的标准；此期为三舍取士与科举考试并行的阶段。

* **太学的性质**

    * 官办学校的主要任务是「一道德」、实施教化，是控制学生思想的阵地，与今天「教育人才、普及知识」的学校概念不同。

    * 太学不从识字教起，性质是科举预备班与培训基地；学生多先到开封游学一段时间，以适应实务策考试、接触政治信息。开封是政治信息汇聚点，太学亦为新思想的发源地。

    * 时人称太学「有发头陀寺，无官御史台」：生活清苦如寺院而留有头发；参与国家大事、发表意见如同御史台而无官无责。

    * 靖康年间金人围城，太学生在陈东等带领下伏阙请愿，人多至堵塞交通，追问宦官并动手，迫使已发出的决定撤回。

* **书院**

    * 唐代已有，初为民间教育组织，早期名称如精舍、书院、经舍，与禅宗山林修行、坐禅体悟的方式有关。

    * 宋代获国家资助三途：赐额（登记在案、颁给匾额）、赐书（国子监刻书颁赐）、资助钱粮；另有私人捐赠或国家拨给田产。山长有时由州县学教授兼任，故渐成半民半官的地方教育组织，亦有较纯粹的民间学术团体。

    * 南宋白鹿洞、岳麓为陆九渊、张栻等讲学之地，象山书院属陆九渊，丽泽书院为吕祖谦讲学处，总数三百多所。

    * 对官学与科举态度双重：一面批判官学，一面其培养者多以科举为出身之途；总体上是理学传播与延续的活动中心。

    * 白鹿洞书院揭示四条：父子有亲、君臣有义；言忠信、行笃敬；正其谊不谋其利，明其道不计其功；博学之、审问之、慎思之、明辨之、笃行之。前三讲做人，末一条讲治学路径，落脚在「笃行」。

    * 文天祥曾在白鹭洲书院读书，后赴临安应试中状元。

* **基层教育**

    * 真正在民间、农村、基层起普及作用的是私学、乡校、家学、蒙学，不是官学与书院。

    * 庆历年间材料载「负担之夫」日求升合之粟以活妻儿，仍每日挪出一文两文积作学课，使子入学识字，至少将来不被人欺负。

    * 陈亮科举不顺时「聚二三十小秀才」教书糊口，靠束脩度日，下次再考；落第者中相当一部分成为「乡先生」，对文化普及作用甚大。

    * 陆游诗写冬学：阴历十月农闲，各家送子入冬学，学《杂字》《百家姓》一类村书。

    * 《百家姓》以「赵钱孙李」起首：赵为国姓，钱为吴越国主之姓，故当成于北宋前期、吴越旧地江浙一带，出自当地儒生之手。

    * 理学家所编《三字经》等童蒙教材朗朗上口，为儒学理念向广大人群渗透提供了重要途径。

    * 齐白石幼时陪东家小少爷上学，在门外听会了四书却一字不识，可见基层教育影响是逐层扩展的。

## 户等与阶级结构

* **主户与客户**

    * 唐代主户指土著户（可与「土户」互换），客户指流动户；两税法「户无主客，以贫富为差」即不论流至何处皆须在当地纳税，属地理、乡里概念。

    * 宋代主户指有常产之户，常产即不动产等较恒定的财产；客户指无常产之户。本地人若无固定土地房产，仍为客户。这是经济、财产概念，不是区域概念。

    * 主户原则上都是税户；主户分五等，通常一、二、三等国为上户，四、五等为下户。

    * 分等标准各地掌握不一，也有主张一、二等为上户、三至五等为下户者；较固定的是五等户，肯定是半自耕农。

    * 下户为自耕农或半自耕农，土地不足自养，须兼作佃农；客户多为佃农，约占民户三分之一上下。

    * 宋代「不废九等户之说」，原则上承认九等，实际行五等户制。

    * > **易错点**：宋代的主户、客户与唐代同名而实不同——唐代分的是土著与流动，宋代分的是有产与无产。

* **形势户**

    * 形势户是宋代特有的名称，指主户中握有某种权势者；它不是与主户并列的第四类，而是主户中被单拎出来的一批人。

    * 三类：州县及官司中作吏者（书手、保正、耆长等）；品官之家；非贫非弱之乡里强豪（家中无人做官而地方势力大者）。

    * 吏无正式俸禄，但跟官府关系密切，故有势力、有影响——官员出行前头打「回避」「清道」旗子的即是。这样人家称吏户。

* **官户**

    * 唐代官户指官府所有之户，多因家人犯罪被没收、收归官府，不能享有完全的人身自由。

    * 宋代官户指家中有人做官之户，可免除部分赋役。

    * > **易错点**：主户、客户、官户三词唐宋两朝含义都变过。作名词解释须先辨明是哪一朝，才知该说哪个意思。

* **坊郭户**

    * 指居住城市、坊郭之中的民户，多为工商业者、小手工业者。

    * 唐代长安除宫城外分为若干坊，人居坊中；「坊郭户」之名宋代才有，标志城市固定居民增多、城市人口增加。

## 两税与附加税

* **两税（正税）**

    * > **定义**：按土地亩数征收、分夏秋两次的农业税，是宋代财政收入中最正统、最稳定的一块。

    * 宋代赋税基本延续唐代两税（二税），按田亩夏秋两次征收。

    * 正税有凝固化倾向：宋三百年间征收额变化不大。故宋代赋税之「重」不重在正税。

    * 赋与役是两回事：赋是向国家缴纳的实物或钱，役是出人力。

* **沿纳**

    * 沿纳即沿袭旧例仍须缴纳的杂变之赋，各地名目不一；宋初将各种名目整合为一，故又称杂变。

    * 主要整合的是各种「耗」：省耗、仓耗、雀鼠耗，皆为补偿运输与仓储损耗而加征。

    * 一般每亩征一斗；粮要运到仓库，路上下船可能翻、入仓可能被雀鼠吃掉，光交一斗就不够一斗，须再加一份补足。各地征收方式不同。

    * 沿纳中另有身丁钱米，按人头征收。单项都不是大头，但每次征收都带上一笔附加。

* **支移**

    * 支移不是独立税种，而是两税的缴纳方式：由纳税户自送粮食到官府指定地点，不一定是本县。

    * 家离县城七八十里已非小负担；战时临时指定他路，如河北用兵、粮草集中河北，虽非本县亦须送往。

    * 元丰年间宽恤规定支移最远不超过三百里，从这条宽恤可见其常态负担之重。

    * 缴纳方式本身变成劳役，遂成在原税额之外凭空增加的负担。

    * 变通办法是缴脚钱由官府雇人代送；日久脚钱固定为一项附加税，且缴了脚钱仍可能被派往别处送纳。

* **折变**

    * 折变同为缴纳方式，特点是临时变更、反复折纳，折到最后即成加税。唐代杨国忠时已有折纳、估价之法，折变即由此而来。

    * 操作：原交粮食，改交绢；再改交钱。百姓不能造钱，只能卖粮换钱。

    * 症结在估价权在官府：粮价本随行市，官府不问行情，径行指定一个「估」，不管你能否按此价卖出。虽有按市价平均估价之说，实际做不到。

    * 包拯陈州之例：陈州去冬大雨雪，桑枣冻死，蚕只及三五分，二麦不熟；地方请免支移折变，转运司只免大小麦支移，仍令本州送纳现钱。大小麦每斗折现钱一百文，脚钱二十文，支移头子钱二十文，共一百四十文；而市上小麦每斗只卖五十文。

    * 包拯算出的结论是「于灾伤年份二倍诛剥平民」，民间无钱可出。

    * 名义上是缴纳方式，落到农户身上就是加税：荒年不免、估价不随行就市，负担一层层压下来。

* **赋税结构的变化**

    * 取唐天宝（最盛期）与宋真宗天禧、仁宗嘉祐、哲宗元祐三个断面比较，全国征收谷物大体持平——正税凝固在数字上看得清楚。

    * 钱数差别极大：天宝约二百万贯，天禧、嘉祐、元祐都是数千万贯。

    * 布帛越来越少，原因是绢帛身份变了：过去绢既能穿又能作交换中介，与钱同为媒介；宋代交换皆用钱，后来甚至用纸币，国家征绢自然减少。

    | 项目 | 唐天宝 | 北宋天禧、嘉祐、元祐 | 走势 |
    | :--- | :--- | :--- | :--- |
    | 谷物 | 全国征收数较高 | 与之大致相当 | 基本持平，正税凝固 |
    | 钱 | 约二百万贯 | 数千万贯 | 成倍上翻 |
    | 布帛 | 征收量大，兼作交换中介 | 明显减少 | 职能被钱与纸币顶替 |

    * 钱的数字跳升，说明货币在整个经济中扮演的角色越来越重。

* **禁榷与商税**

    * 取太宗朝、真宗天禧、神宗熙宁三个断面比较，正税（出自土地）相当稳定；变化在禁榷（盐、茶、矾等专卖）与商税，两者收入都数倍增加。

    * 结果是出现了中国古代罕见的一幕：非农业税第一次超过农业税的比重。此前常态约农业六成、非农业四成；熙宁时农业税只占 28%，非农业占 72%。

    | 时期 | 农业税比重 | 非农业税比重 |
    | :--- | :--- | :--- |
    | 此前常态 | 约六成 | 约四成 |
    | 熙宁 | 28% | 72% |

    * 流行的解释是农民负担相对减轻、工商业发展贡献增大；但这一说法不能简单接受。

    * 真正数额变化大的是禁榷。茶、酒可算奢侈品，盐却是人人离不了，故盐利实际上仍是一种人头税——表面不是强征，实质仍与人口相连。

    * > **易错点**：非农业税比重升到七成，不等于农民负担减轻。正税按财产征收确是进步趋势，但禁榷收入很难说是工商业发展带来的，它在某种程度上保留了按人头征收的不合理方式。

## 役法与赋重役轻

* **职役（差役）**

    * 役分两类：职役（差役）通常由主户承担，力役则多半落在下户身上。

    * 上户承担的差役有衙前（管运送官物、看管府库）、里正与户长（催督赋税）；催督收粮时一斗多寡都握在这些人手里。

    * 同一套制度落在不同户等头上，一个是权、一个是苦：上户差役特权成分较大，下户差役负担较重而特权少。

    * 王安石变法时，职役、差役改为募役（雇募）：不论轮差与否，所有人向国家交钱，由国家统一雇人服役。

* **力役（夫役）**

    * 力役即出苦力的活：春夫是春汛前加高堤坝，急夫是堤防决口时临时堵口，造桥修路也在其中。

    * 由自耕农与佃农按人丁承担。

    * 熙宁时已有免夫钱：不去服役可以交钱，用这笔钱雇人代役，力役也渐渐向财产税方向过渡。

    * 官户享有免役特权，理由是其家中已有人当官，当官即相当于出了这份差役。

    * 地方治安、修桥铺路、大堤堵口往往由厢军承担，也是役的替代来源。

* **赋重役轻**

    * 宋代总体情形是赋重役轻。原因是原来由征发徭役承担的当兵、修桥铺路及各种杂事，大多转由禁军之外的厢军担当；军役基本消失，因为行募兵制，不再征发百姓当兵。

    * 转化链条：募兵制使国家财政压力变大，税收随之加重，附加税与各种名目增多，而这些名目基本按财产征收——役就这样一部分一部分变成了赋。

    * 所以赋重役轻不是国家宽厚，而是役换了形态：一部分由募兵与厢军顶掉，代价转成按财产征收的赋税，落在正税与附加税上。

    * 趋势上，随着募役法出现，富者交钱且交得更多、贫者去服役，征派赋役的原则越来越向田亩、财产和户等倾斜，这是中国地主制时期后一段的基本走向。

## 西夏

* **国号与族属**

    * 西夏是宋朝人从中原王朝立场给的名称——因「夏」在西北，故称西夏；其自称大夏，西夏文写作「邦泥定国」，译过来大体是「白上」或「白高」。

    * 关于「白」有三说：一指当地白河（白龙江），标地理位置；二指尚白，突厥、吐蕃皆以白为上、以白衣为贵；三说「白」即「播」的对音，与藏族有文化关联。

    * 属羌族一支，内部并非单纯民族而为民族共同体，有八部之说，最强的是拓跋部，其首领自称鲜卑后裔。

    * 亦称唐古、唐兀，多为译音不同而有不同汉字。

    * > **提示**：汉文史料里的「西夏」不是自称。同一政权在两三种文字里有三套名字，读材料先分清这个名称是谁在说，再谈它说了什么。

* **世系与三段**

    * 立国前沿革：唐代中后期活动于陕西横山一带，自称大夏后裔、姓李；唐末拓跋思恭参与剿讨，被赐姓李，领数州，任定难军节度使。宋初为稳定西北又赐姓赵（李继捧、李继迁一辈），与宋对立后即放弃赵姓。

    * 李继捧较内附；李继迁之子李德明转而与宋和好，换取宋承认其定难军节度使并封西平王，南顾无忧后全力向西扩张，取甘州回鹘与吐蕃在河西的力量，占住东西通道的中继位置，同时结好于辽。

    * 1031年李德明死，元昊继位：放弃汉姓赵，改本族嵬名氏，恢复旧俗服饰，创年号、制西夏文字。

    * 年号上的试探：时刘太后听政，年号天圣、明道；元昊以父名李德明须避讳为由，提出不能使用「明道」，改为「显道」，以此探测宋朝反应。1038年才正式建大夏国、建元，自称「邦泥定国兀卒」。

    | 时期 | 主要君主 | 特征 |
    | :--- | :--- | :--- |
    | 建立期 | 元昊、毅宗、惠宗 | 立国、创文字与年号；汉化与旧俗来回反复 |
    | 兴盛期 | 崇宗、仁宗 | 周旋于辽宋金之间；崇儒崇佛并行，疆土最盛 |
    | 衰亡期 | 襄宗、神宗、桓宗、末帝 | 国势下滑，最后三十年走向灭亡 |

    * 建立期的反复：元昊死时毅宗仅一岁，权在母族后族；惠宗亦只七八岁。毅宗成年一度恢复汉姓、汉仪，惠宗前期又复本族旧俗。反复反映王室与本族旧族、贵族势力之间的合作与斗争。

    * 兴盛期：崇宗正当两宋之交，辽先亡于金、金再灭宋，西夏在三方之间摇摆以求出路；仁宗一手崇儒、一手崇佛，孔子封号由「文宣王」进为「文宣帝」正在其时，疆土亦达最广。

    * 衰亡期：桓宗自1193年，至末帝1227年，前后约三十年；末帝那年蒙古大汗死于六盘山，秘不发丧，西夏随即投降。

* **文字与文献**

    * 西夏文自称「国字」，字形方整而笔画繁复，远看似汉字、近看一字不识，是在汉字笔画基础上增繁另行组合而成。

    * 研究程度较好，一般认为约七成可以识读；得益于西夏留下的字书、词典。最常举者为《番汉合时掌中珠》（西夏文与汉文双语双解语汇词典），黑水城出土的《文海》亦提供语言文字与社会历史材料。

    * 西夏文未挤掉汉字：即便在西夏境内亦与汉字同时行用，汉文仍通行；双边文书往来仍写汉文。居庸关石刻中有西夏文，说明亡国后西夏文在社会上仍有影响。

    * 黑水城遗址在今内蒙古额济纳旗，出土大量西夏文与汉文文献；20世纪初俄国人在此发掘，故大批文献藏于彼得堡，俄罗斯因此成为西夏研究重镇；斯坦因亦在此发掘。相关材料陆续整理为《英藏黑水城文献》等。

* **官制与法律**

    * 时人谓西夏「设官之制，多与宋同」，拆开骨架几乎照搬北宋前期：官分文武班，设中书、枢密、三司、御史台——中书主政、枢密主兵、三司掌财政、御史台掌监察。

    * 执行部门有六司、两院（飞龙院、文思院）；最有意思的是其首都管理机构也叫「开封府」，与宋同名同职。

    * 官员「分命蕃汉人为之」，兼用本族人与汉人；并招揽汉地儒生、僧人，行中国之风。

    | 机构 | 职掌 | 对照北宋 |
    | :--- | :--- | :--- |
    | 中书 | 主政 | 二府之一 |
    | 枢密 | 主兵 | 二府之一 |
    | 三司 | 掌财政 | 财政总汇 |
    | 御史台 | 掌监察 | 监察机构 |
    | 开封府 | 首都衙门 | 同名同职 |
    | 六司、两院 | 分门处理具体事务 | 具体执行 |

    * 汉号与蕃号之关系有争议：蔡美彪、吴天墀主张蕃汉并行（如辽之北面官治蕃、南面官治汉）；亦有学者认为只有一套系统、两套名称，汉名与党项名对译，如皇帝即「兀卒」，太后、大王皆可对译，「宁」为王、「令」为大、形容词后置，故「令宁」即大王。

    * 反常现象：越是与中原王朝打交道的官员与文书，越倾向称蕃号。这既是坚持本民族称谓，也含民族歧视与回避政治敏感称谓之意——把「兀卒」译成皇帝即等于承认对方为帝，故不译，彼此心照不宣。

    * 《天盛改旧新定律令》为天盛年间在旧律令基础上改定，是中国历史上第一部用少数民族文字编纂的综合性王朝法典，全书二十卷、二十余万字，详细程度当时空前。来源两路：党项部族习惯法与宋、辽制度。

* **宋夏战争**

    * 「兀卒」入汉人之耳即「吾祖」，蔡襄、欧阳修等愤然抗议，认为西夏自称「吾祖」不成体统，双边文书无从措辞。元昊上表自称文武衣冠具备、创文字、有礼乐，吐蕃、达靼、张掖皆愿服从，仅以王号称之不合体统，请割地建国为万乘之邦，宋不能允。

    * 一个反差值得算：西夏对宋的骚扰远多于辽，国力却不如辽。原因是辽的建立远在北宋之前、是继承下来的既成事实，宋无力改变；西夏的建立是宋眼前发生的事，故特别不为宋所容。不被承认的邻居，摩擦自然多。

    * 1040年至1042年间宋夏数次大战，均以宋方失利告终；宋调兵遣将，把夏竦、韩琦、范仲淹等重臣派往前线。

    * 宋方边境民谣「军中有一韩，西贼闻之心胆寒；军中有一范，西贼闻之惊破胆」；西夏方面的传言则是「夏竦何曾耸，韩琦未足奇。满川龙虎辈，犹自说兵机」。前者不太能得到史实印证，两边传言各抬各人。

    * 地形与堡寨：古代无路时河谷即天然道路，西夏蚕食宋边多沿河谷进行。黄土高原一带无太行那样深峻山谷、无山隘关口可守，宋遂在河谷边广筑堡寨，堡寨成了「人造的关口」，作用近似碉堡炮楼——扼守一条道路或一片区域。

    * 建制层级为军统城、城统堡寨：镇戎军与州同级而规模较小、为驻军之地，堡寨约两个足球场大，驻少量军队。此策不能完全奏效（堡寨之间仍有道路与河谷可穿插），但进可攻退可守，至少保住据点、部分抵御渗透。

    * 延州（今延安）守臣即知延州范仲淹；延河河谷即一条可行军之路。《渔家傲》又名《麟州词》，故也有人认为写于麟州（今陕西神木，杨家将老家），词境沉雄开阔而又苍凉悲壮。

* **庆历和议与三方格局**

    * 宋方关键一手是对西夏的物资封锁：西夏地处宁夏、陕西一带，物资有限，过去多靠榷场与宋贸易；开战后宋封锁边界贸易，对西夏形成很大供应压力。但宋方财政、军事压力同样不堪忍受。

    * 庆历四年宋夏议和，原则为：西夏接受宋的正朔、对宋称臣；宋每年「赐」银、绢、茶若干；双方重开榷场，允许民间贸易。夏与辽之间亦有矛盾与议和。此后形成北宋、辽、西夏三足鼎立的基本局面。

    * 和议之后宋夏仍打打停停、互有进退，有一次甚至要把童贯带领的西北边军调回江南。这是西夏自北宋中期至后期与宋关系的大致状况。

    * 科举失意者外流：仁宗时张元、吴昊自负文韬武略，赴边地求为边帅所用而不得，愤而越境入西夏，到处题名引起注意，终至元昊面前成为谋主，张元还提出过整套战略安排。二人之名恰合「元昊」，故有人疑为传闻，或谓入夏后为引起注意而改名。此事与嘉祐二年以后殿试不黜落的动因之一相关——高层注意到了这类现象。

## 北宋中期的财政困局

* **军事财政**

    * 宋代强敌环伺，外部局面与内政互有进退、互相影响；内政始终与财政问题拴在一起。

    * 首都选开封之利在邻近运河、粮草转输方便；弊在四战之地、无天险可守，北边天险已因石敬瑭而放弃，故只能「以兵为先」。

    * 有学者因此从财政角度提出：宋前期有辽、西夏，后来有金、蒙古，其财政一直是一种军事财政——为应对军事问题，征收方式与压力都成为国家不得不面对的重大挑战。

* **三冗三费**

    * 宋祁《景文集》有专谈三冗三费的奏章，自问「何为三冗」而自答：一是「天下有定官，无限员」（官冗）；二是「厢军不任战而耗衣粮」（兵冗）；三是僧尼道士越来越多。

    * 今教科书通常作冗官、冗兵、冗费，其中冗费由冗官冗兵而来。前两项大致能与宋人原话对应，第三项明显不同。

    * > **易错点**：教科书的三分法是概括，别拿它直接去套宋人原话。宋祁奏章里的第三项是僧尼道士，不是「冗费」。

    * 蔡襄曾为三司使，称「养兵之费常居六七」；另一条材料说天下所收财物五六分用于养兵。

    * 禁军人数：仁宗时八十二万，北宋后期接近一百万；总内外之兵（禁军、厢军，中原与边疆合计）约一百万。

    * 三冗之中真正吃钱的是冗兵，这正是宋代财政被称作军事财政的原因；禁军人数增长主要出于对西夏作战的压力。

* **积贫积弱**

    * 检索宋人文章，有说「积贫」的、有说「积弱」的，但没有把两者并提的；「贫」在当事人话里主要指财政用度不足，不是百姓贫穷；「积」是多年积攒之意。

    * 钱穆《国史大纲》论宋代积贫积弱，教科书多沿用；近年有学者如李裕民撰文质疑，认为不宜简单以此概括宋代状况。

    * 两头压力是实打实的：说「积贫」指财政，说「积弱」宋人基本都指军事。《文献通考》谓募兵「起于府兵之废」。

    * 募兵原则是把天下「失职」之人（无业、游民、无地、被土地甩出者）收编，尤其是年轻力壮的「犷悍之徒」：强壮者入禁军，矮弱者入厢军；平时备战，战时由其余人供应。

    * 战斗力之低，时人谓拉不开弓弦、「目不能辨旗帜」（认不准本队主帅之旗而掉队失散）；又有「将从中御」，临时指挥权不能应变。叶适亦言养兵而战斗力不足。

    * 财政赤字：庆历年间立国已八十余年，账面上亏空渐大。统计口径为「贯、石、匹、两」（铜钱、粮食、绢帛、丝绵）。

    | 时期 | 收支状况 |
    | :--- | :--- |
    | 天禧 | 收入有余 |
    | 皇祐 | 收支大致持平 |
    | 治平 | 收入抵不上支出 |

    * 治平已在庆历之后，正值王安石变法的前夜：外部战事压出边防，边防压出军费，军费压出赤字。

## 庆历新政

* **开天章阁**

    * 庆历三年九月，仁宗召范仲淹、富弼、韩琦、欧阳修等入天章阁，命他们就地把对朝政的意见写下来。

    * 天章阁是真宗去世后仁宗为父亲所建，收藏其生前书籍、墨宝、字迹，与龙图阁之为太宗而建同理。开天章阁让大臣写意见，是在父辈、祖宗面前表达决心，属于特别隆重的表示。

    * 奏章并非当场写毕，但这个动作本身已把皇帝的态度摆了出来。庆历新政即由这批中青年官员发动，因年号得名。

    * 范仲淹最高只做到参知政事（副宰相），当时的宰相并不看好这场改革。

* **《答手诏条陈十事》**

    * 皇帝亲笔手诏来问，范仲淹与同仁商议后逐条答上，即《答手诏条陈十事》，被视为新政的纲领与目标；磨勘法、恩荫等皆在其中。

    * 诊断是四个字：纲纪日削月侵——制度一天天、一月月被侵蚀削薄，不能原原本本执行。

    * 潜在前提：祖宗时候的纲纪本来完备，若照原样执行就不该出这些问题；病因不是制度不好，而是没有严格执行。

    * 大方向：欲正其末，必端其本；欲清其流，必澄其源。澄源之处，是「前代帝王之道、本朝祖宗之烈」——从祖宗的功业中找治理今天的精神资源与思想原则。

    * > **提示**：这正回答「祖宗之法是否等于倒退」的疑问。范仲淹要往前推进、要改革，而改革的旗帜恰恰是「祖宗之烈」。同一套祖宗之法，可以被解释成维持现状的理由，也可以被解释成非改不可的依据，关键在于后人的阐发。

    * 十条集中于两大项：吏治与财政；出发点是先从整顿吏治入手，再往外推。

    * 切口是「人」而不是「钱」，这一点决定了阻力形态——整顿官僚队伍必然触动中上层既得利益。

* **阻力之一：朋党**

    * 主要批评不是说某条法规不对，而是说人不对：范仲淹、欧阳修、富弼、韩琦、杜衍等是一伙，构成小集团，即「朋党」。

    * 从君主角度看，臣僚结党极其忌讳、必须高度警惕，故这顶帽子一出来压力极大——哪怕说这些人凑在一起干的都是好事，皇帝也不愿其结党。

    * 欧阳修作《朋党论》辩称小人不会结党，只有君子有共同目标才会形成群体。

    * > **易错点**：《朋党论》文章极漂亮，却没有解决问题。仁宗并不因这篇文章就满意，政治上的猜忌靠文章辩不倒。

* **阻力之二：按察使**

    * 按察使是中央派往地方考察官员之人，查出不胜任即可报中央撤换；此制的派出是范仲淹、欧阳修等强力主张的结果，也是反对最集中的着力点。

    * 反对者不限于既得利益者，包拯亦反对。其理由是干扰地方正常事务运转，比喻即「一会儿来一个检查组」：为应付检查，很多人就在那里作假，既影响正常事务，又带坏官场风气。

    * > **提示**：这条反对意见不是说「不该整顿吏治」，而是说「这种整顿方式本身会制造新问题」。批评可以从治理成本出发，未必出于私利。

    * 恩荫（任子之恩）被限制、范围缩小，被限者自然不满；磨勘（考核）规矩越来越多，想靠资历混日子者不便。反对声浪因此越来越强，人心不自安。

* **夭折**

    * 庆历四年边境已与西夏缔约，但问题未全解决。范仲淹一边承受极强压力，一边见仁宗犹豫不定，遂主动提出赴边重看军队实情；仁宗顺水推舟，范仲淹从此离开朝廷，再未回来。

    * 此后新政等于夭折：有的措施尚未推出，已推出的后来也不再实行；同志陆续出朝。自庆历三年九月至结束前后不到两年。

    * 失败不是某一项政策的技术性失误，而是「结党」之名、官僚集团集体反弹、皇帝决心动摇三者合力；范仲淹自请赴边，实为给皇帝递台阶。

    * 遗留下的矛盾一个也没有解决。吕思勉谓此种国家真觉无可下手：要改革则皇帝不支持，照旧下去则积重难返，故「不能不佩服神宗和王安石的热心与勇气」。

    * > **注意**：庆历失败不是让改革议题消失，而是让它更急、更难——问题在积累故急，一次失败抬高了「改革」一词的政治成本故难。王安石后来从财政入手而不从官僚入手，正是对这一成本的回应。

## 熙宁变法

* **万言书**

    * 王安石后封荆国公，称王荆公。嘉祐四年（仁宗末年）上《上仁宗皇帝言事书》，一万余字，故称「万言书」。

    * 核心判断：「现在的法度多不合于先王之政」。此「先王」不是宋朝祖宗，而是三皇五帝，故其立论有意回到三代、借阐发儒家经典以立说，对「祖宗之法」构成一种修正。

    * 对时局的观察：内不能无以社稷为忧，外不能无惧于夷狄；天下财力日益困穷，风俗日益败坏。

    * 理财主张：因天下之力以生天下之财，取天下之财以供天下之费。

    * 奏上无回应——仁宗在位四十二年，此时身体亦不佳，对连篇长奏无甚反应。但奏章副本在社会上流传，引起很多注意；后来司马光谓当时「所有的人都把希望寄托在你身上，认为王安石不出来则已，只要他出来，这个国家的问题都能解决」。

    * > **易错点**：万言书常被说成熙宁新法的纲领。细看其中一些构想尚不明朗，把它当作「同一份东西的早期版本」可以，当成「已经定稿的蓝图」就过头了。

* **开源与节流**

    * 司马光、蔡襄一路主张节流：病根在三冗三费（官多、兵多、开销大），办法是缩减官僚与军队规模，把总支出压下来。

    * 王安石一路主张开源：通过扩大生产来扩大国家收入。他并非不要节流，但主要目标与出路在开源。

    * 其说上承《史记·平准书》与汉代桑弘羊：可以做到「民不益赋而国用饶」——百姓负担不增而国家收入增多。

    * 司马光等认为不可能，理由是一个硬假定：国家收入即社会财富，基本是常数；国家聚敛得多，百姓必然贫困化。

    | 比较项 | 节流一路（司马光、蔡襄等） | 开源一路（王安石） |
    | :--- | :--- | :--- |
    | 病根判断 | 三冗三费，官多兵多开销大 | 生产不广，财源未开 |
    | 着手处 | 缩减官僚与军队规模，压总支出 | 扩大生产，做大国家收入 |
    | 对「民不益赋而国用饶」 | 认为不可能 | 认为可行 |
    | 财富总量的假定 | 近乎常数 | 可以增大 |

    * 这不是「一个要改革、一个不要改革」的差别，而是「往哪个方向改」的差别，后面司马光与王安石的交锋会反复回到这一点。

* **神宗与四类法度**

    * 仁宗无子，英宗为过继，在位仅四年（治平年号仅四年）即去世；神宗继位，锐气较强，在宫中曾穿铠甲给祖母看，问像不像领兵打仗的。

    * 神宗问：若让你执政，先做什么？王安石答：变风俗，立法度，这两桩最重要——最前面的不是钱、不是兵，而是先改人心取向、再立行事规矩。

    * 所立法度大致四类：以富国、富天下为目标；以强兵为目标；以培养人才为目标；以及配合这些目标的机构与制度调整。

    * 富国与富天下不尽相同：富国主要指国家政权这一头，富天下则把天下百姓包括在内，使整个社会更富足。

* **富国之法**

    * 以富国为目标的一组数量最多、也最主要；其中争议最大、琢磨时间最长、反复最久、反弹最烈的是青苗法与免役法。

    * 共同点是都落在钱上，都落在国家与民户之间的收支关系上。

    * 各法条文不逐一展开，只点出争议最大的两项与其余各法的名称归属。

    * > **提示**：单个法的内容不必逐一记忆，抓共同点——它们调整的都是国家与民户之间的钱物往来，这正是王安石从财政入手的直接体现。

* **强兵之法**

    * 包括将兵法、保甲法、保马法，以及设军器监。

    * 将兵法所扭的正是「兵不知将、将不知兵」：枢密院调兵、三衙管训，战时临时指定将领，该将领与所部素无了解，不知哪支能冲、哪支精锐、哪支敢死。

    * 这种设计本为防止兵将结成过密关系而再现藩镇牙兵之弊；但关系不密，上阵无人肯出死命。

    * 将兵法把军队分为若干「将」：「将」既是将领，又是编制单位；每一将辖其训练的禁军，称「系将禁军」；较不精锐者称「不系将禁军」。禁军中的精锐部分皆系将。

    * > **易错点**：「将」在此有双重身份——既是军官，也是编制单位。宋代兵制材料里的「某将」通常指编制，不是某位将领本人。

* **育才之法**

    * 熙宁四年改革教育与学校制度：太学行三舍法，《三经新义》成为教材。

    * 又有铨试：过去进士得资格即可做官，自熙宁四年起考中进士还须考法律，懂得如何判案才分配差遣；因由铨选部门主持，故称铨试。

    * 与之相辅的还有机构设施调整与用人原则的改变。

* **推行方式**

    * 时间表极密：熙宁二年二月王安石任参知政事，七月即推行新法；七月、九月、闰十一月连续颁法；次年有保甲法；熙宁四、五、六年陆续推出。熙宁七年第一次罢相，不久复归；熙宁九年十月第二次罢相，退居江宁（今南京），再未回朝。

    * 元丰年间王安石已不在相位，神宗仍坚持推行，故称「熙宁新法」而非只是熙宁年间的法；元丰间另有官制改革即元丰改制。元丰八年神宗去世，其母高氏以太皇太后身份执政，召司马光为相，新法陆续废罢。

    * 新法呈现出两个特征：其一，内容大多集中在财政方面，与庆历从官僚队伍下手大不相同——吏治问题王安石并非未注意到，多半是吸取庆历教训，先不动官僚的切身利益；其二，法令一条接一条，颁布与执行跟得很紧。

    * 人事配套：中央派专属使者到地方核查新法推行；推行不力之处即派新官取代旧官，新官多是「资浅的新进少年」，正处上升期、锐意更革，与老成持重者倾向不同。

    * 代价是组织上有效、政治上很贵：用新人换旧人，把每一处的推行阻力都变成人事冲突，中央到地方都受到很大冲击。

    * 刘挚批评：「二三年间，开阖动摇」，如地震一般，「举天地之内，无一民一物得安其所者」；又说「数十百事交举并作，欲以岁月变化天下」——要在一年一月之间让天下大变。诸法交错颁布、交错实行，地方官刚适应一法又来一法，极难适应。

* **三不足**

    * 三说：天变不足畏、祖宗不足法、人言不足恤（亦作「流俗之言不足惧」，恤即顾及）。

    * 硬证据是司马光《传家集》所存一道策问：今之论者或曰——天地与人，了不相关，薄蚀、震摇，皆有常数，不足畏忌；祖宗之法，未必尽善，可革则革，不足循守；庸人之情，喜因循而惮改为，可与乐成，难与虑始，纷纭之议，不足听采。「愿闻所以辩之。」

    | 策问分句 | 对应论调 |
    | :--- | :--- |
    | 天地与人，了不相关，薄蚀、震摇，皆有常数，不足畏忌 | 天变不足畏 |
    | 祖宗之法，未必尽善，可革则革，不足循守 | 祖宗不足法 |
    | 庸人之情，喜因循而惮改为……纷纭之议，不足听采 | 人言不足恤（流俗之言不足惧） |

    * 本题关键全在末句「愿闻所以辩之」：要求应试者为这三条作辩驳，而不是替它们作论证。把它读成「请阐发此意」，整篇方向就反了。

    * 此题到神宗手中，神宗怒称「朝廷何尝有此」，召王安石问是否听说；王安石答「没听说过」，随后作长段解释：对「天变」回避不答，对「祖宗不足法」「人言不足恤」正面回应。

    * 其论祖宗不足法：仁宗在位时自己颁布的诏令，后来自己也修改过；若祖宗一说出口后人便不能动，祖宗自己何以要改？故「祖宗之法不足守，固当如此」。

    * > **易错点**：三不足是否出自王安石本人之口，本有不同说法，不宜一上来就当原话引用。且宋代阳奉阴违、不守祖宗之法的多有人在，敢在皇帝面前当面说出的，只有王安石一人。

    * 馆阁考试由资深学士三人各出一题、皇帝点一题；司马光此题说明当时是把三不足当作需驳斥的异论看待的。此题未留下司马光的答卷。

* **分歧与评价**

    * 司马光与王安石本为「嘉祐四友」中人，交情极深：王安石初被召时命子先到开封找房，其子称父亲挑剔，非要与司马十二丈（司马光）作邻居；王安石称司马光行己修身、治家处处有法。

    * 熙宁间迅速分道：司马光致书谓其「必欲力战天下之人」，所行是动摇宋之根基而非稳固；王安石答，若批评我在相位上未能助皇帝大有作为、未给百姓带来好处，我知罪；但说「你什么都不应该干，只守着祖宗做法就行」，此意不解。

    * 此后司马光拒不外出，赴洛阳修《资治通鉴》。

    * 两人都是一流思想家，选择之异不在聪明程度或道德高下，而在对「合法性的来源」给出两个不兼容的答案：一个放在祖宗成法，一个放在三代先王、放在法度是否合于先王之意。

    * 新法推行之速，苏轼《王安石赠太傅制》作「用能于期岁之间，靡然变天下之俗」——字面是赞叹效率，实与刘挚「欲以岁月变化天下」同义，只是以褒语出之。此文系司马光主张厚道、不许落井下石而后作，追赠太傅。

    * 南宋人认为新法全败，且以王安石变法招来小人、颠覆传统而致北宋灭亡；实际新法部分达到富国强兵之效，人才培养方面的影响亦长期存在。

    * 王安石变法可称宋代政治史的纽结：过去的问题在此集中，后来的问题由此发散。评价本身亦有变化史——过去批评居多，梁启超始彻底翻盘，近代以来如钱穆多持肯定，谓范仲淹、王安石的抱负虽未完全实现，其精神义气仍为后人所师法。

    * 影响延及当代：1972年日本田中首相访华，中方即用「人言不足恤」之典；后来温家宝亦引「天变不足畏，祖宗不足法，人言不足惧」。

    * > **注意**：把庆历与熙宁放在一条线上看，两场改革回答的是同一个问题——积攒了八十年的制度还能不能改、该从哪里改。庆历从人入手，两年即折；熙宁从钱入手，撑了十几年，终亦废于一旦。两次都留下同一样东西：改革本身成了此后宋代政治不能再回避的议题。
