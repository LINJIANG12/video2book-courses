# 中国古代史（北大公开课·172 讲）

北京大学历史学系的中国古代史公开课，阎步克、邓小南等主讲，从中国民族的古老起源一路讲到清朝前期的政治、制度、经济与学术文化。全课标称 172 讲，B 站实际提供 171 个分 P，按约 50 分钟一块合并为 98 块，整编为 14 册模块全书与 17 篇主题复习笔记。

## 怎么学

- **按朝代顺序读**：先秦 → 秦汉 → 魏晋南北朝 → 隋唐 → 两宋辽金 → 元 → 明 → 清，14 册正好沿这条主线排下来，先通读再回看。
- **抓两条线索**：一条是政治制度（分封、郡县、三省六部、祖宗之法、内阁与军机处），一条是人群结构（士人、门阀、军功阶层、士大夫），两条线在每册里都成对出现。
- **先秦与秦汉是地基**：封建与郡县的转换、百家争鸣与秦制，是后面两千年反复回响的母题，笔记 01–04 值得细读。
- **魏晋南北朝看「胡汉」**：孝文帝汉化与北齐北周的胡化，是理解隋唐帝国气质的前置条件，笔记 06–07 连读。
- **宋以后看「祖宗之法」**：宋代制度设计与改革运动的张力，贯穿笔记 11–12，也是明清皇权集中的对照面。
- **考前只看 `notes/`**：17 篇笔记按朝代与专题重组，制度沿革与人物事件并排放置。
