# 赵玉平《百家讲坛》系列合集（十季合辑）

赵玉平老师在《百家讲坛》的十个系列讲座合集，147 个分 P 约 74 小时，全部围绕「从历史人物身上读管理」：从向历史人物借智慧、向诸葛亮借智慧，到曹操的启示、跟司马懿学管理、刘备的谋略，再到品读水浒人物、水浒智慧、孙权的智慧，另有面向个人的「人生自我管理必修课」与收官的管理专题「选人用人之道」。147 集合并为 113 块，整编为 14 册模块全书与 10 篇系列复习笔记。

- **147 集全部整编**：113 块 / 14 册模块全书 / 10 篇复习笔记 / 113 份逐字稿（其中 11 块为听音补录，其余为平台字幕）

## 怎么学

- **按系列读**：十大系列彼此独立，先挑最感兴趣的人物（曹操、司马懿、刘备、孙权、诸葛亮），再回补方法论篇（人生自我管理、选人用人之道）。
- **三家对照看**：曹操（进取与决断）→ 司马懿（隐忍与时机）→ 刘备（仁义与团队）→ 孙权（守成与平衡），四套生存策略同场竞技，笔记 03–05、09 连读效果最好。
- **水浒是另一面镜子**：品读水浒人物（笔记 06）偏人物性格与命运，水浒智慧（笔记 08）偏组织与招安困局，先读前者再看后者。
- **方法论收尾**：人生自我管理必修课（笔记 07）把前面的历史案例落回个人时间、情绪与习惯；选人用人之道（笔记 10）是全系列的用人总纲。
- **考前只看 `notes/`**：10 篇笔记按系列重组，人物、案例与要点并排放置。
