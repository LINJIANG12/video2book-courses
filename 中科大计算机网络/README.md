# 中科大计算机网络（69 讲）

这是中国科大郑烇、杨坚老师基于 Kurose、Ross《计算机网络：自顶向下方法》开设的经典教材课，全 69 集、约 44.8 小时。课程沿自顶向下顺序，从应用层经传输层、网络层讲到数据链路层，并配套各章习题课。每章习题（第一章、第六章、第八章等）单独成集，套接字编程另设专册，重在中国学生视角下的协议理解与手写计算题训练。

- **原视频**：[中科大郑烇、杨坚全套《计算机网络（自顶向下方法，James F. Kurose，Keith W. Ross）》](https://www.bilibili.com/video/BV1JV411t7ow/) — Bilibili，BV1JV411t7ow
- **全 69 集**，已产出 12 册模块全书、12 篇复习笔记、61 份逐字稿

## 怎么学

- **先用第 1～2 册搭好自顶向下五层模型**：把应用层、传输层、网络层、链路层和物理层串成坐标轴，理解每层解决什么问题、向相邻层提供什么，再进入协议细节。
- **主课之后立刻做对应习题课**：第一章、第六章、第八章等习题都单独成集，不能只听懂例题；合上答案独立画流程、写计算步骤，是本课程最不能省的一步。
- **把第 3 册的套接字编程真正做起来**：沿“API → 系统调用 → 协议栈”把 HTTP、DNS、TCP 客户端串起来，代码能跑通后再回看对应报文与服务端行为。
- **第 4～9 册按机制链复盘**：可靠传输与拥塞控制 → 路由与转发 → 链路访问与交换 → 安全，逐层补齐状态、报文头和算法，不要把各章当成孤立名词。
- **计算与大题集中放到最后两册练**：前九册先形成模型，再用第 11～12 册集中突破时延、带宽、路由、IP 编址、TCP 等计算题型，并总结易错条件。
- **复习时用 12 篇笔记串主干、用 61 份逐字稿查原话**：笔记开头的知识拓扑树适合快速回顾，逐字稿则用来核对老师的推导顺序和习题讲评。
