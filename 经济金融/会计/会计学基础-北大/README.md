# 会计学基础（北京大学公开课）（45 讲）

北京大学《会计学基础》公开课，从「会计是什么」讲到三大报表，是一条零基础友好的完整入门线：先立会计恒等式与借贷记账法，再用费用利润与试算平衡把账做平，然后读资产负债表、利润表、现金流量表及其钩稽关系，接着过债券筹资与对外股权投资两类业务的核算，最后落到生产成本归集与本年利润结转。45 个分 P 整编为 4 册模块全书与 6 篇主题复习笔记。

## 怎么学

- **恒等式先立住**：资产 = 负债 + 所有者权益是全课的地基，笔记01 用逐笔举例把「每笔业务怎么同时动两边」演透，这一步不牢后面全晃。
- **借贷方向背口诀更要懂逻辑**：笔记02 按五类账户整理借贷方向规则，配合 T 型账户演练，试算平衡才能一次做平。
- **三表钩稽是期末高频**：笔记04 把利润表 → 资产负债表 → 现金流量表的钩稽关系画成一张流向图，先看图再回教材。
- **业务核算分两条线**：筹资（债券）与投资（股权）的核算分录在笔记05 并排对照，发行方/投资方两个视角别混。
- **成本与利润结转走全流程**：从生产成本三构成归集，到本年利润结转与利润分配，笔记06 是从做账到报表的最后一公里。
