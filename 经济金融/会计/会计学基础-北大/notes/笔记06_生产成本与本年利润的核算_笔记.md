# 生产成本与本年利润的核算

## 存货的四段身份

* **原材料（Raw Materials）**

    * > **定义**：存放在仓库、尚未投入生产的材料，归在资产项下的存货里。

    * 仓库发出材料形成发料单，材料按用途分流，账上的名字随之改变。

* **生产成本（Work in Process，WIP）**

    * > **定义**：生产过程中尚未完工的在产品所承担的代价，是存货停留在车间阶段的账上名字。

    * 借方余额代表期末尚未完工的在产品的代价；产品完工转出后该账户清空。

* **库存商品（Finished Goods）**

    * > **定义**：完工验收入库的产成品，仍属存货，只是位置从车间换到了仓库。

    * 借方余额反映尚未卖出的商品所含的生产成本。

* **主营业务成本（Cost of Goods Sold，COGS）**

    * > **定义**：已售商品对应的生产成本，从存货转为费用，出现在利润表里。

    * > **易错点**：结转主营业务成本时贷记的是库存商品，不是生产成本；完工入库与销售结转是两个环节，各转一次，不能合并成一笔。

同一个东西走到哪一步，报表上的身份就变一次；时点搞混，资产负债表和利润表会一起错：

| 走到哪一步 | 东西在哪 | 账上叫什么 | 报表里的身份 |
| :--- | :--- | :--- | :--- |
| 领了料、还没做完 | 车间 | 生产成本（在产品） | 资产——存货 |
| 做完了、还没卖掉 | 仓库 | 库存商品 | 资产——存货 |
| 已经卖掉了 | 客户手里 | 主营业务成本 | 费用 |

## 生产成本的三个来源

* **生产环节代价的封闭清单**

    * 只有三类：直接材料、直接人工、制造费用；三类之外的生产性支出不进产品成本。

    * 落点：能追溯到具体产品的两项直接进生产成本；追溯不到的先进制造费用，再分配进生产成本。

* **直接材料、直接人工的判定**

    * 判据是"能不能识别出它是为生产这个具体产品而发生的"，与谁领用、谁干活无关。

    * 造车例：四个轮胎是直接材料；张三装车门、方向盘、轮子是直接人工，很容易对应到这辆车。

* **期间费用**

    * 生产环节以外的销售、管理、研发、广告支出，记营业费用、管理费用等账户，不进产品成本。

    * 会计要素里没有"成本"这一项，成本的说法放在费用要素里面；只有在生产环节发生的代价，在财务会计里才称为成本。

    * > **易错点**：把广告费、销售运费也叫成成本——它们是期间费用，与产品成本没有关系。

* **产品成本的固定结构**

    ```text
    生产成本
      ├── 直接材料    追溯进来（a 17170 / b 20406）
      ├── 直接人工    追溯进来（工资 a 8000 / b 10000，福利费按 14% 计提）
      └── 制造费用    分配进来（a 4024 / b 5026，合计 9050）
    ```

    * 两个"追溯"加一个"分配"，就是产品成本的全部来源；凡进不了这三条的支出，都不在产品成本里。

## 生产账户的借贷结构

* **统一的提问方式**

    * 对每个账户问两句：这笔钱的使用结果是什么，记借方；这笔钱的来源是谁提供的，记贷方。

    * 记生产环节主要用生产成本、制造费用两个账户，再加完工后才出场的库存商品。

| 账户 | 借方：资金使用结果 | 贷方：资金来源 | 借方余额说明 |
| :--- | :--- | :--- | :--- |
| 生产成本 | 领用的材料、消耗的人工、分配进来的间接代价 | 提供给完工产品（库存商品） | 尚未完工的在产品 |
| 制造费用 | 本期发生的各项间接费用 | 通过分配提供给生产成本 | 全部摊出后不再保留 |
| 库存商品 | 完工入库产品的生产成本 | 提供给销售环节 | 尚未卖出的商品 |

* **制造费用的特殊之处**

    * 贷方提供给生产成本，但这条提供不是直接给，而是通过分配给过去的。

    * 归集完、全部分摊出去之后，制造费用不再保留余额。

* **整条资金流**

    * 钱从原材料、从人工、从各项费用流进生产成本，再从生产成本流进库存商品，最后从库存商品流进销售环节。

    * 每一步都是同一件事：一方的使用结果，对应另一方的资金来源。

## 直接材料与直接人工

### 材料领用

* **发料单必须回答的三个问题**

    * 领了什么材料（甲、乙、丙各多少）、单价与金额是多少、这些材料为什么目的领用。

    * 第三项才是记账的分水岭：是生产用的还是非生产用的；若是生产用的，能不能具体到某个产品。

* **按用途分流的记账**

    * 例：a 产品用料 17,170、b 产品用料 20,406 进生产成本；车间一般耗用丙材料 50 公斤 3,085 进制造费用；非生产环节领用丙材料 70 公斤 4,319 进管理费用；贷记原材料 44,980。

    * 三个借方对应三种去向：能对应到产品的进生产成本，生产用但对应不到产品的进制造费用，根本不是生产用的进管理费用。

    * > **易错点**：车间领走的料不一定都进制造费用；判据是"能不能对应到具体产品"，不是"谁领的"。

* **明细核算的必要性**

    * 只在生产成本一个总数 37,576 上记账太粗，发料单上的产品、材料品种信息全部丢失。

    * 应下设在产品明细（a 产品 17,170、b 产品 20,406）与原材料明细（甲、乙、丙）。

    * 记得越细账越有用，随时能回答"某个产品这个月到底吃了多少料"。

### 工资与福利费

* **先干活后付钱的时间差**

    * 生产时先估计并认下本月人工代价：借生产成本（a 产品 8,000、b 产品 10,000）、制造费用 2,000（车间技术、维修、管理人员）、管理费用 5,000（厂部工程师与管理人员）；贷应付工资 25,000。

    * 员工已经干了活、企业还没付钱，等于员工以外部身份给企业垫了一笔资金；贷方是对员工的负债。

* **工资的发放**

    * 借应付工资 25,000（对员工的义务得到清偿）；贷银行存款 25,000（这回是企业内部自有资源提供）。

    * 同一个账户两次出场站在两条边上：计提时在贷方作资金来源，发放时在借方冲义务。

* **福利费按工资 14% 计提**

    * 借生产成本（a 产品 1,120 = 8,000 × 14%、b 产品 1,400 = 10,000 × 14%）、制造费用 280（2,000 × 14%）、管理费用 700（5,000 × 14%）；贷应付福利费 3,500。

    * 福利费是生产环节的一笔代价，但计提时只是认下一笔义务，钱还在企业手里，不一定马上付出去。

## 制造费用的归集

### 间接费用的范围

* **四类常见内容**

    * 间接材料：如贴标签用的胶水，理论上可追溯，但精确计量到每件产品的代价太大，故放进制造费用。

    * 间接人工：生产部门的修理人员、技术人员、生产管理人员。

    * 设备与无形资产使用带来的损耗，通过估计折旧与摊销体现。

    * 低值易耗品、包装物，以及水电费、生产部门的差旅费、运输费、办公费。

* **共同特征**

    * 为生产环节发生，但没办法一一追溯到单个品种的产品上。

### 归属判定

* **同一费用项目按用途分账户**

    * 办公费：支付本月办公费 2,000，车间用 1,200、厂部用 800；借制造费用 1,200、管理费用 800，贷银行存款 2,000。

    * 折旧：本月计提折旧 3,800，车间设备 2,200、厂部设备 1,600；借制造费用 2,200、管理费用 1,600，贷累计折旧 3,800。

    * 租金：现金支付仓库场地租金 285，与生产有关却说不清给哪个产品用，全额借制造费用，贷现金 285。

* **判定规则**

    * 用途决定账户，账户决定进不进产品成本；项目名称相同不代表落点相同。

### 累计折旧

* **不直接冲减固定资产的理由**

    * 固定资产可用两三年，每一段使用都有损耗；若直接把损耗从固定资产账户减掉，过一年账上只剩下一个"今天值多少钱"。

    * 想对照"重新买一台要花多少钱"时，当年买价已经看不出来。

    * 处理方式：固定资产账户只反映历史上购置的代价，使用中的损耗另设累计折旧反映。

* **两个数要一起看**

    * 原值减累计折旧是净值；原值本身是历史成本，累计折旧是已损耗的部分。

    * 一条信息变成两条：净值、原值、累计损耗同时可得，信息更完整，也更容易拿出来运用和沟通。

    * > **提示**：只留一个数就丢了一半信息——既看不出当初花了多少，也看不出损耗累积到什么程度。

### 归集结果

* **本期制造费用合计**

| 项目 | 金额 | 来处 |
| :--- | ---: | :--- |
| 间接材料 | 3,085 | 丙材料 50 公斤，车间一般耗用 |
| 间接人工——工资 | 2,000 | 车间技术、维修、管理人员 |
| 间接人工——福利费 | 280 | 2,000 × 14% |
| 办公费 | 1,200 | 车间部分 |
| 折旧 | 2,200 | 车间设备 |
| 租金 | 285 | 仓库场地 |
| 合计 | 9,050 | |

* **归集后的状态**

    * 9,050 全部堆在制造费用借方，是这一期为生产发生、却还没落到具体产品上的代价，等着下一步摊出去。

## 制造费用的分配与完工结转

### 分配率与分配标准

* **按直接人工工资比例分配**

    * a 产品工人工资 8,000、b 产品 10,000，合计 18,000；待分配制造费用 9,050。

    * $$\text{分配率} = \frac{9050}{18000} \approx 0.503$$

    * 含义是每 1 元生产工人工资要承担 5 毛左右的制造费用。

    * a 产品分到 $0.503 \times 8000 \approx 4024$，b 产品分到 $9050 - 4024 = 5026$（尾差由后者承担）。

* **分配分录**

    * 借生产成本（a 产品 4,024、b 产品 5,026）；贷制造费用 9,050。

    * 这一步做完，生产成本的三个来源全部到位，制造费用借方清零。

* **分配标准属于会计政策**

    * 可以按人工比例分，也可以按产品数量分；办法不同，分出来的结果就不一样。

    * 选哪个不是算术问题而是判断问题——标准选得合不合理，直接决定每种产品算出来的成本准不准。

    * 企业可以自己选择最合适的一种办法做会计处理。

### 在产品计价

* **为什么必须切一刀**

    * 生产是连续的，而会计分期报告有节点（月末、季末），节点上的生产线必然一部分已完工、一部分未完工。

    * 于是要在在产品与完工产品之间对生产成本做分配；分配办法不同，算出的代价也不同。

* **本例的切分**

    * a 产品本月完工 1,000 只并验收入库，另有 100 只未完工，期初无在产品。

    * 企业在产品单位成本：直接材料 3 元、直接人工 2.4 元、制造费用 1.5 元，合计 6.9 元一只；100 只即 690 元，继续留在生产成本里。

    * a 产品本月生产成本共 30,314，减去期末在产品 690，得 $$30314 - 690 = 29624$$ 即 1,000 只完工品的代价。

* **完工入库分录**

    * 借库存商品（a 产品 1,000 只 29,624）；贷生产成本 29,624。

    * a 产品生产成本就此清空，钱从"在车间"换到"在仓库"，完成链上的第二次换名字。

    * > **易错点**：在产品计价标准（6.9 元一只）是估计出来的，不是算出来的；标准一变，留在生产成本的数和转入库存商品的数同时变，完工产品成本从来没有唯一解。

## 销售确认与费用配比

### 四个账户

* **主营业务收入**

    * 贷方是资金来源，企业销售产品获得收入，这笔收入归所有者所有。

    * 借方是资金使用结果，把金额提供给利润计算；期末没有余额。

* **主营业务成本**

    * 借方是资金使用结果：销售产品时应承担的生产成本。

    * 贷方是资金来源：为计算本年利润提供资金来源；期末一般也没有余额。

* **税金及附加**

    * 除增值税、所得税以外的其他税金及附加费，本质上是一笔代价。

* **营业费用**

    * 借方记本期发生或支付的各种销售费用；贷方是转入利润计算时转出、作为资金来源的提供方；期末同样没有余额。

### 收入与销项税额

* **销售款拆两块**

    * 不含增值税的销售款构成主营业务收入；增值税部分叫销项税额，是替政府收的，构成对政府的负债。

* **已收款的销售**

    * a 产品 500 只、每只 50 元（不含税），销项税额 4,250，货款与税款已存入银行。

    * 借银行存款 29,250（25,000 + 4,250）；贷主营业务收入 25,000、应交税金——应交增值税（销项税额）4,250。

    * 这 29,250 有两个来源：25,000 由不含税售价提供，4,250 是政府提供的资金，企业同时欠政府一笔。

* **未收款的销售**

    * b 产品 1,000 只、每只 80 元，销项税额 13,600，客户分文未付，企业取得的是向对方收款的权利。

    * 借应收账款 93,600（80,000 + 13,600）；贷主营业务收入 80,000、应交税金——应交增值税（销项税额）13,600。

* **缴税与收款**

    * 缴增值税：销项税额减进项税额，差额 8,199.95；借应交税金——应交增值税 8,199.95，贷银行存款 8,199.95。

    * 收回应收款：借银行存款 93,600，贷应收账款 93,600；来源不是外部，而是企业内部资源——原来的收款权利变现。

### 费用配比

* **结转已售商品成本**

    * a 产品 500 只、每只 30 元，合计 15,000；b 产品 1,000 只、每只 55 元，合计 55,000。

    * 借主营业务成本 70,000（a 15,000、b 55,000）；贷库存商品 70,000。

    * 存货变费用就是在这一笔上完成的；贷方是库存商品，不是生产成本。

* **运费与广告费**

    * 运费 1,000，可拆 a 产品 300、b 产品 700；借营业费用 1,000，贷银行存款 1,000。

    * 广告费 10,500 无法与具体产品一一对应，在发生支付时直接记为当期代价：借营业费用 10,500，贷银行存款 10,500。

* **消费税**

    * a 产品应承担 1,000、b 产品 2,000，合计 3,000；借税金及附加 3,000，贷应交税金——应交消费税 3,000。

    * 消费税由企业自己算出、主动去税务局缴纳；算出未缴时占用的是政府资金，构成一笔负债。

* **销售环节闭环**

    * 确认收入，再确认收入之后的费用配比：主营业务成本、税金及附加、营业费用三块各自到位。

## 利润总额的构成

* **两层结构**

    * 利润总额包含营业利润与营业外利润两部分，营业外利润即营业外收入扣掉营业外支出。

    * $$\text{利润总额} = \text{营业利润} + \text{营业外收入} - \text{营业外支出}$$

* **营业利润的算法**

    * $$\text{营业利润} = \text{营业收入} - \text{营业成本} - \text{税金及附加} - \text{营业费用} - \text{管理费用} - \text{财务费用} + \text{投资收益}$$

    * 不同企业经营的业务不一样，利润表项目会有增减，"等等"不是客套。

* **结构树**

    ```text
    利润总额
    ├── 营业利润
    │   ├── 加：主营业务收入（以及其他营业收入、投资收益等）
    │   ├── 减：主营业务成本
    │   ├── 减：税金及附加
    │   ├── 减：营业费用
    │   ├── 减：管理费用
    │   └── 减：财务费用
    └── 营业外利润
        ├── 加：营业外收入
        └── 减：营业外支出
    ```

## 本年利润与期末结转

* **本年利润账户（Current Year Profit）**

    * > **定义**：为计算财务成果专门设置的过渡性汇总账户，不存放具体资产，也不代表债权或债务。

    * 贷方是资金来源方：把收入转到这里；借方是资金使用结果方：把成本、费用、支出转到这里。

    * 期末余额在贷方表示盈利，在借方表示亏损。

    * > **提示**：余额方向不是人为规定的，是收入与费用比较的结果；看到余额先看方向，再看金额。

* **账户的工作方式**

    * 把这一期的收入全部倒进来，再把这一期的成本费用全部倒进来，两边一碰，差额就是这一期的经营成果。

    * 结转收入、结转成本费用、结转所得税、转入未分配利润四步依次走完，账户余额归零。

### 结转收入

* **结转分录**

    * 借主营业务收入 60,125；贷本年利润 60,125。

    * 把利润公式想象成容器，先把收入填进去；这一步只完成加项，费用还没进来。

* **为什么必须转空**

    * 主营业务收入平时记贷方表示增加，期末要从借方转出，余额才归零。

    * 收入类账户记录的是这一期发生了多少收入，不是期末还剩多少收入，所以期末必须转空；下一期再从零开始记。

### 结转成本费用

* **方向由公式的减号决定**

    * 利润等于收入减费用，费用前面是减号，所以费用类账户从贷方转出、本年利润在借方接住。

    * 费用平时记借方表示发生，期末从贷方转出后余额归零。

* **结转分录**

    * 借本年利润 42,630；贷税金及附加 5,200、营业费用 23,745、管理费用 9,465、财务费用 1,505、营业外支出 2,715。

    * 五项相加 5,200 + 23,745 + 9,465 + 1,505 + 2,715 = 42,630，借方一个总数、贷方分项列示，金额必须对上。

* **利润总额落地**

    * 本年利润贷方 60,125、借方 42,630，贷方多出 17,495，这个余额就是利润总额。

### 计提并结转所得税

* **计提**

    * 一般企业所得税税率 25%：$$17{,}495 \times 25\% = 4{,}373.75$$

    * 借所得税 4,373.75；贷应交税金——应交所得税 4,373.75。

    * 所得税是企业有了经营成果才产生的代价，赚了钱才有这笔税，所以要作为费用记录，报表上叫所得税费用；未缴之前构成对政府的负债。

* **结转**

    * 借本年利润 4,373.75；贷所得税 4,373.75。

    * 所得税账户第一笔在借方、第二笔在贷方，借贷金额相同，结转后期末没有余额。

    * > **提示**：所得税走两步——先确认费用与负债（这笔代价是什么、欠谁），再结转进本年利润（这笔代价从本期利润里扣掉）；两步分开，来龙去脉才清楚。

* **净利润**

    * 本年利润借方合计 42,630 + 4,373.75 = 46,993.75，贷方 60,125，差额 13,121.25 即税后利润。

### 转入未分配利润

* **结转分录**

    * 借本年利润 13,121.25；贷利润分配——未分配利润 13,121.25。

* **结转的完整过程**

| 步骤 | 摘要 | 借方 | 贷方 | 余额 |
| :--- | :--- | ---: | ---: | :--- |
| 1 | 结转收入 | | 60,125.00 | 贷 60,125.00 |
| 2 | 结转成本费用 | 42,630.00 | | 贷 17,495.00 |
| 3 | 结转所得税 | 4,373.75 | | 贷 13,121.25 |
| 4 | 转入未分配利润 | 13,121.25 | | 0 |

* **归零的理由**

    * 本年利润只回答"这一年赚了多少"，而企业从成立至今每年的经营成果要累计下来，未分配利润才是完整的家底。

    * 本年利润是过渡性汇总账户，利润算出来后属于所有者权益，应与以前年度累计的未分配利润放在一起。

    * 不转空则下一年收入与费用无法从零开始汇总；转空既是对这一年的收尾，也是对下一年的准备。

## 利润分配

### 分配顺序

* **三个去处依次排列**

    * 第一，弥补以前年度的亏损；第二，按一定比例计提盈余公积；第三，向投资者分配利润或分配股利。

    * 以前亏得太多、今年利润不够补的，只能等以后赚了钱再补。

* **硬约束**

    * 以前年度亏损没有完全弥补掉，就不能对今年利润做其他打算；不能一边留着亏损不补，一边提公积、一边分红。

    * 补亏排在第一位不是习惯问题，是分配的基础问题。

* **本例的前提**

    * 企业以前没有亏损、以前还有利润累积，所以不需要补亏，可以直接从本期税后利润里提盈余公积。

### 提取盈余公积

* **按税后利润 10% 提取**

    * $$13{,}121.25 \times 10\% = 1{,}312.13$$

    * 借利润分配——提取盈余公积 1,312.13；贷盈余公积 1,312.13。

* **借贷两方的含义**

    * 借方是利润分配下的明细项目，表示利润被指定了用途；贷方是所有者权益里的盈余公积账户，表示这笔钱留在企业里转成了公积。

* **公积的作用**

    * 从每年利润里留出一部分，为以后改善员工福利、为企业发展做储备；不提则利润可以全部分红，企业发展和员工福利都没有额外资金来源。

    * 提公积不是把钱藏起来不用，而是给未来留一个蓄水池。

    * > **易错点**：借方是"利润分配——提取盈余公积"，贷方才是"盈余公积"；写反等于减少公积、增加可分配利润，意思正好相反。

### 向投资者分红

* **基数是累计未分配利润**

    * 不是本年利润的 60%，而是截至该时点以前年度加本年度利润、再扣掉已提盈余公积后的未分配利润。

    * 基数：$24{,}000 + 13{,}121.25 - 1{,}312.13 = 35{,}809.12$。

    * 分 60%：$35{,}809.12 \times 60\% = 21{,}485.47$。

* **决策程序与分录**

    * 董事会作出决定，还要经股东大会同意；形成决议后依决议做会计分录。

    * 借利润分配——支付利润 21,485.47；贷应付股利 21,485.47。

    * 决议形成而钱未付出，这笔义务先挂在负债上；实际支付时再冲减应付股利和银行存款。

    * > **易错点**：直接拿 13,121.25 去乘 60%，就把以前年度留下来的利润漏掉了。

### 明细结平

* **把利润分配的各条明细转到未分配利润**

    * 借利润分配——未分配利润 22,797.60；贷利润分配——提取盈余公积 1,312.13、利润分配——支付利润 21,485.47。

    * 借方 22,797.60 正好是贷方两项之和：1,312.13 + 21,485.47 = 22,797.60。

* **未分配利润余额**

| 事项 | 借方 | 贷方 | 余额 |
| :--- | ---: | ---: | :--- |
| 期初 | | | 贷 24,000.00 |
| 本年利润转入 | | 13,121.25 | 贷 37,121.25 |
| 提取盈余公积、支付利润转入 | 22,797.60 | | 贷 14,323.65 |

* **余额含义与分录去向**

    * 期末 14,323.65 仍在贷方，是到年末为止企业还留在账上、没有分配出去的利润。

    * 提公积、分红都在利润分配账户里走，不再回到本年利润；利润已经算完，分配是对结果的安排，不是对利润的再计算。

    * 提公积是所有者权益内部的搬移，分红是把一部分利润转成对投资者的负债，两者都不进利润表。

## 结账

* **结账的含义**

    * 把过去这一年各个财务成果账户结转完成：收入、费用、本年利润全部转空，该合的去处合完，该留的留在未分配利润里。

* **结账的硬性含义**

    * 一旦结账就不能再调整、不能再改变各账户的记录，过去这一年就锁上了；后面发现差错是下一期的事，走别的程序，不是把已结的账翻开来改。

* **结账与整个循环的关系**

    * 结账是会计循环的分界线：结账之前账还可以调，结账之后这一期的数字就定型了。

    * 所以结账前的调整、财产清查、对账，一步都不能省。

## 资产负债表

* **试算平衡表会少掉一批账户**

* **资产方要合并与抵减**

    * 货币资金不是一个账户：要把银行存款和库存现金合在一起，放进货币资金这一项。

    固定资产原值            51,650.00

    固定资产净值            49,110.00

## 报表勾稽与水分

### 恒等式推导

* **把两个恒等式合起来**

    * 不考虑所有者增资、利润分配等影响权益的变动时，期末所有者权益等于期初所有者权益加本期利润：$$\text{资产} = \text{负债} + \text{期初所有者权益} + \text{利润}$$

    * 再把利润换成收入减费用并移项：$$\text{资产} + \text{费用} = \text{负债} + \text{期初所有者权益} + \text{收入}$$

* **推出的结论**

    * 费用和资产在性质上高度相似，都是企业投入的资源，区别只在于使用的时间点。

    * 一笔支出如果受益期跨过期末，未消耗部分留在资产里，已消耗部分转到费用里；同一笔资源站在期末，一部分在资产、一部分在费用。

### 三类水分

* **资产水分**

    * 资产实际已被消耗，本应从资产变成费用，账上仍留在资产里；表现是少估损失、少估损耗、少估减值、少算摊销和折旧。

    * 结果是账面价值超过实际价值，费用被少计，利润虚增。

* **负债水分**

    * 负债显得多、义务看着重，事实上不是义务，而是隐藏收入的手段：号称欠了别人钱，实际并没有欠那么多。

    * 常见形式是预收账款、其他应付款——服务已提供、商品已发出，就是不确认收入，挂在负债里。

    * 结果是收入被人为压缩，利润虚减，与资产水分的方向正好相反。

* **所有者权益水分**

    * 资金出逃：注册资本 500 万且股东已实际投入，股东又通过各种方式把这 500 万转到个人账户；企业记借其他应收款 5,000,000、贷银行存款 5,000,000。

    * 这么一记，资产总额没变、负债加所有者权益总额也没变，报表看上去还是平的，但钱已被抽走，权益上的金额是空的。

    * 利润水分：利润虚增，转到所有者权益里的未分配利润、盈余公积也是虚构的；利润表造假最后一定沉淀到所有者权益。

    * 资本公积一类项目的水分，例如没有及时转出。

| 水分位置 | 常见手法 | 对利润表的影响 |
| :--- | :--- | :--- |
| 资产 | 少估减值、损耗、摊销、折旧 | 费用少计，利润虚增 |
| 负债 | 已实现的收入挂在预收账款、其他应付款 | 收入少计，利润虚减 |
| 所有者权益 | 股东抽逃资本、利润造假、资本公积未及时转出 | 权益虚增，与真实盈利能力脱节 |

* **看表的方法**

    * 抽逃资本的隐蔽之处在于它不破坏会计恒等式：资产方一增一减总额不变，权益方纹丝不动，只盯左右是否相等看不出来。

    * 要盯"其他应收款"这类股东往来科目有没有异常膨胀。

    * 两张表是同一个恒等式的两种看法，一处发生变化，尤其在不谨慎或造假的做法下，一定会在另一张表留下对应变化。

## 现金流量表

### 编制基础

* **与前两张表的基础不同**

    * 利润表和资产负债表建立在权责发生制上，可以直接从试算平衡表、各账户抄过来。

    * 现金流量表建立在收付实现制上，考察现金的变动，必须依据权责发生制记录的信息做调整，把"应计"还原成"现金"。

* **三类活动的构成**

    * 经营活动：累计经营成果（通俗说就是本年利润）扣减流动资产里非现金部分的变化金额，加上负债里非债务义务的变化结果。

    * 投资活动：非现金的非流动资产在两个时点之间的金额变化，前面加负号，因为投资意味着资金流出企业。

    * 筹资活动：债务义务的金额变化，加所有者投入的金额变化，再减利润分配（资金返还给投资者，是流出）。

    ```text
    现金流量表（收付实现制）
    ├── 经营活动现金流
    │   ├── 起点：本年利润（净利润）
    │   ├── 减：非现金流动资产的变化
    │   ├── 加：非债务流动负债的变化
    │   └── 加：折旧、摊销、资产减值等不付现的费用
    ├── 投资活动现金流
    │   └── 非现金非流动资产两时点间的变化，取负号（现金流出）
    └── 筹资活动现金流
        ├── 加：债务的变化
        ├── 加：所有者投入的变化
        └── 减：利润分配（股利、利息等）
    ```

### 间接法

* **起点与四类调整**

    * 起点是净利润（本年税后利润），然后逐项剔除三类混入物。

    * 调整损失或利得：影响了净利润，但不属于经营活动的现金收支。

    * 减去非现金流动资产的增加：应收账款、存货增加意味着钱被占用，没有收回或压在货上。

    * 加上非债务流动负债的增加：应付账款、预收账款增加意味着费用已确认但钱没付、或钱先收了；要付利息的负债不走经营活动，属筹资活动。

    * 加上不付现的费用：折旧、资产减值估计、摊销，利润表上扣了利润但没有真金白银流出。

* **符号规则**

    * 把期初与期末余额相减；期末比期初多时，资产方加负号，负债及所有者权益方（贷方）用正号。

* **本例的经营、投资、筹资**

| 项目 | 期末 - 期初 | 带入现金流的符号 | 归属 |
| :--- | ---: | ---: | :--- |
| 应收账款 | +35,000 | -35,000 | 经营活动 |
| 存货 | +10,000 | -10,000 | 经营活动 |
| 累计折旧 | +10,000 | +10,000 | 经营活动（加回） |
| 应付账款 | +20,000 | +20,000 | 经营活动 |
| 预收账款 | +2,000 | +2,000 | 经营活动 |
| 应付职工薪酬 | +1,000 | +1,000 | 经营活动 |
| 固定资产 | +125,000 | -125,000 | 投资活动 |
| 应付债券 | +100,000 | +100,000 | 筹资活动 |
| 未分配利润 | +13,000 | 拆解处理 | 经营与筹资 |

* **经营活动的计算**

    * 起点不取净利润 20,000，而取付利息和付所得税之前的利润 24,000（20,000 + 利息 4,000）。

    * $$24{,}000 - 35{,}000 - 10{,}000 + 10{,}000 + 20{,}000 + 2{,}000 + 1{,}000 = 12{,}000$$，经营活动现金净流入 12,000。

    * 未分配利润的 +13,000 不能原样加：它是净利润 20,000 减去股利 7,000 的余额，已被拆成两半——净利润那半进经营活动，股利那半进筹资活动；原样加既混淆性质，又与后面的净利润起点重复。

* **投资与筹资**

    * 投资活动：非流动资产只有固定资产，期末比期初多 125,000，加负号后为 −125,000，表示花钱买固定资产的现金流出。

    * 筹资活动：应付债券增加 100,000 记正号；利息 4,000 已在经营活动加回，这里要作为筹资代价扣掉；再加发放股利 7,000。

    * $$100{,}000 - 7{,}000 - 4{,}000 = 89{,}000$$；所有者投入本期没有发生，第三部分为零。

* **三部分合计**

    * $$12{,}000 - 125{,}000 + 89{,}000 = -24{,}000$$，这一年现金净减少 24,000。

    * > **易错点**：利息费用在间接法里出现两次、方向相反——先在经营活动加回到 24,000，再在筹资活动作为现金流出扣掉；这不是重复计算而是分类，利息不属于经营活动，只加回不扣除经营现金流会虚增。

### 直接法

* **思路与代价**

    * 直接看经营过程中哪些是现金收入、哪些是现金支出；理论上可把银行存款、现金账户流水逐笔拎出，正的放收入、负的放支出。

    * 但企业资金进出频繁，很难分辨每笔是收是支、是经营还是非经营，逐笔判断的成本高得难以承受。

    * 实务上仍以利润表为起点，把权责发生制下的收入、成本、费用逐项换成现金口径。

* **收入与成本的换算**

    * 营业收入 125,000 调成现金收款：减应收账款增加 35,000（活干了钱没收），加预收账款增加 2,000（钱先收了活没干）；125,000 − 35,000 + 2,000 = 92,000。

    * 营业成本 60,000 调成现金支付：减预付账款增加 10,000（先付钱没用货），加应付账款增加 20,000（用了货没付钱）；−60,000 − 10,000 + 20,000 = −50,000。

* **费用逐项换算**

    * 折旧 10,000 不需付现，来源于累计折旧增加 10,000：−10,000 + 10,000 = 0。

    * 工资费用 20,000，应付职工薪酬多 1,000 说明这部分还没付：−20,000 + 1,000 = −19,000。

    * 其他费用 11,000 全部用现金支付，直接记 −11,000。

| 项目 | 计算 | 金额 |
| :--- | :--- | ---: |
| 现金收款 | 125,000 - 35,000 + 2,000 | 92,000 |
| 营业成本付现 | -60,000 - 10,000 + 20,000 | -50,000 |
| 折旧费用 | -10,000 + 10,000 | 0 |
| 工资付现 | -20,000 + 1,000 | -19,000 |
| 其他费用 | 现金支付 | -11,000 |
| 现金支付合计 | -50,000 + 0 - 19,000 - 11,000 | -80,000 |
| 经营活动现金流 | 92,000 - 80,000 | 12,000 |

* **两法互验与分工**

    * 调整项合计 −35,000 − 10,000 + 10,000 + 20,000 + 2,000 + 1,000 = −12,000，息税前利润 24,000 减这 12,000 得 12,000，与直接法结果一致。

    * 间接法从净利润出发往回倒，适合看"利润和现金差在哪里"；直接法从营业收入出发往前推，适合看"现金到底从哪些项目收进来、付出去"。

    * 两条路调整的是同一批权责发生制与收付实现制之间的差异，所以必然在同一个数上会合。
