## 怎么学

- **先修衔接**：假定你已熟悉供需均衡与弹性；蛛网理论正是弹性的应用题，笔记01 从「供给弹性 vs 需求弹性」的比较切入。
- **消费者理论抓「两条效应的分解」**：替代效应与收入效应的方向组合决定了正常品、低档品、吉芬品的差别，笔记02 把分解步骤画成了可照抄的流程。
- **显示偏好是「从行为反推偏好」**：弱公理与强公理的条件边界是易混点，对照笔记02 的反例表记忆。
- **市场结构用一张对照表收束**：三种市场的短期/长期均衡条件与效率评价，笔记04 开头的对照表是全课的收束点，先看表再回书。
- **博弈论先掌握记号再做题**：占优策略、纳什均衡的判定步骤在笔记06 里有逐步示例，囚徒困境的重复博弈结论单独记。
