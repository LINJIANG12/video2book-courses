## 成本函数：生产函数的另一面
> 对应块：BLK04 | 覆盖分集：P09 | 块标题（分集名）：《成本函数》

### 成本函数是生产函数的函数

这一讲讲成本函数。这个知识点说到底就两块：短期的成本函数，长期的成本函数。在讲这两块之前，本来还得先交代几个概念——什么是机会成本，什么是显性成本，什么是隐性成本，什么是经济利润。这几个概念我不讲，你们自己看书都看得懂，在这儿念一遍纯属浪费时间，咱们直接从短期和长期开始。

不过动手之前，得先花一分钟把"成本函数到底是什么"钉住，因为上一讲讲的是生产函数，这两样东西是一根绳上的。

生产函数说的是：自变量是 K 和 L 这些要素，因变量是产量 Q。要素对产量的影响，就叫生产函数。

$$Q = f(L, K)$$

成本函数换了个方向：它反映的是成本与产出之间的关系，产出是自变量，成本是因变量。

$$TC = f(Q)$$

而 Q 本身又是 L 和 K 的函数，代进去，成本最终也落在 L 和 K 上。

> **结论**：成本函数就是生产函数的函数。影响生产函数的、影响成本函数的，归根到底都是 L 和 K。

"函数"这两个字叠着用不是口误：生产函数先把 $(L, K)$ 映射成产量 Q，成本函数再把 Q 映射成成本，两层复合起来，起点还是要素，终点是钱。

但是——影响它们的根本因素虽然一样，画法和分析方式完全是两套。

### 横纵轴先钉死：两张图别画反

先看生产函数：横轴是 L，纵轴是 Q。自变量是 L，因变量是 Q。

再看成本函数：横轴是 Q，纵轴是 C。自变量是 Q，因变量是 C。

> **易错点**：这两张图长得非常像，回头看的时候十有八九会犯迷糊。生产函数的纵轴是 Q、横轴是 L；成本函数的纵轴是 C、横轴是 Q，这个千万不要混淆。

到底谁是横轴，决定了这条曲线在讲"投多少要素能产出多少"，还是在讲"产出多少要花多少钱"。方向反了，整道题就废了。

| 对比项 | 生产函数 | 成本函数 |
| :--- | :--- | :--- |
| 表达式 | $Q = f(L, K)$ | $TC = f(Q)$ |
| 自变量 | L、K | Q |
| 因变量 | Q | C |
| 横轴 | L | Q |
| 纵轴 | Q | C |

记法只有一个：先把生产函数记下来，成本函数自然就出来了——因为两者互为反函数，图像是对称的。

生产函数怎么画？起笔像一个对号，然后再折过来画一个弯。先画一个对号，再画一个弯，这就是生产函数。成本函数不用另记一套形状，把这条曲线翻成对称的样子就行。

```text
   生产函数 Q = f(L)                 成本函数 C = f(Q)
   Q                                 C
   ^                                 ^
   |              ,-'                |            ,-'
   |           ,-'                   |         ,-'
   |        ,-'                      |      ,-'
   |     ,-'                         |   ,-'
   |  ,-'                            | ,-'
   +----------------> L              +----------------> Q
      先画一个"对号"，再画一个"弯"       取它的对称图形
```

读图：左手边这条是生产函数，右手边这条是它的镜像，也就是成本函数；记住一条，另一条就能画出来。

### 互为反函数的底账：边际与平均都是倒数

"互为反函数、图像对称"这话不能只背结论，得看它从哪儿来。答案藏在两个倒数关系里：边际产量与边际成本、平均产量与平均可变成本。

先把总成本拆开。总成本等于总可变成本加上总固定成本：

$$TC = TVC + TFC$$

短期里 K 是常量，只有 L 变动，所以雇劳动力的那笔钱就是全部的可变成本：

$$TVC = wL$$

边际成本是对总成本求导：

$$MC = \frac{dTC}{dQ} = \frac{d(wL + TFC)}{dQ}$$

TFC 是常数，对常数求导得 0，所以只剩 $wL$ 那一项。w 是要素价格，也是常数，可以提到导数外面：

$$MC = w\frac{dL}{dQ}$$

而 $\dfrac{dQ}{dL}$ 正是边际产量 $MP_L$，那么 $\dfrac{dL}{dQ} = \dfrac{1}{MP_L}$：

$$MC = \frac{w}{MP_L}$$

平均可变成本同理：

$$AVC = \frac{TVC}{Q} = \frac{wL}{Q} = \frac{w}{Q/L} = \frac{w}{AP_L}$$

> **结论**：边际成本与边际产量互为倒数，平均可变成本与平均产量互为倒数。w 是同一个常数，所以产量这边的曲线"先升后降"，成本那边的曲线就必然"先降后升"——两张图对称的底账就在这儿。

> **提示**：一直用 Q 表示产量，到了边际产量、平均产量这里却写成 MP、AP，这个点特别容易记混。其实 Q 和 P 指的都是产量：说"产量是多少"的时候用 Q，说"边际产量、平均产量"的时候用 P。看到 Q 和 P，不要当成两个不同的概念。

### 短期要记七个成本函数

短期生产函数假定 K 是常量，只有 L 变；短期成本函数也一样，K 不变，只有 L 变。

$$TC = wL + rK \qquad (K \text{ 为常数})$$

$wL$ 里的 L 会变，这一项叫可变成本；$rK$ 里的 K 不变，这一项叫固定成本。

> **注意**：区分可变成本和固定成本只在短期成立。到了长期，所有要素都可变，就不再有固定成本这回事。

正因为短期要分可变和固定，短期成本函数一共要记七个。硬背很容易背混，我当时是这么记的：

1. 先把三条总量写下来：总成本 TC、可变成本 TVC、固定成本 TFC；
2. 每一条再分出"边际"和"平均"两个函数，三条一共六个派生；
3. TFC 是常数，对常数求导得 0，所以边际固定成本等于零，这个函数不存在，划掉一个；
4. 边际总成本与边际可变成本是同一个东西（TFC 那一项求导为 0，两者只差一个常数），合并记作一个 MC，再少一个。

三个总量加上六个派生，减掉不存在的边际固定成本，再减掉合并掉的重复项，正好剩七个。

| 函数 | 记号 | 定义式 |
| :--- | :--- | :--- |
| 总成本 | TC | $TC = TVC + TFC$ |
| 总可变成本 | TVC | $TVC = wL$ |
| 总固定成本 | TFC | $TFC = rK$ |
| 平均总成本 | AC | $AC = \dfrac{TC}{Q}$ |
| 平均可变成本 | AVC | $AVC = \dfrac{TVC}{Q}$ |
| 平均固定成本 | AFC | $AFC = \dfrac{TFC}{Q}$ |
| 边际成本 | MC | $MC = \dfrac{dTC}{dQ} = \dfrac{dTVC}{dQ}$ |

按这个顺序推一遍，既不会遗漏，也不会记混。

### 先画三条总量曲线

要画平均和边际，得先把三条总量曲线画出来。原因很直接：边际是曲线上某一点自身的斜率，平均是曲线上某一点与原点连线的斜率。总量曲线不在，斜率的读法就无从谈起。

三条里最好画的是 TFC：它是常数，所以是平行于横轴的一条水平线。

TVC 一定过原点。短期可变成本就是雇劳动力带来的成本，产量为 0 意味着一个劳动力都没投入，可变成本自然是 0。

TC 一定不过原点。就算劳动力投入为 0，厂房、固定资产的消耗仍然在那儿等着。

```text
TC = TVC + TFC

  TVC = w·L   →  L 会变，随产量一起增长；产量为 0 时，高度为 0
  TFC = r·K   →  K 不变，是一笔常数；产量为 0 时，照样存在

于是：TVC 从原点起笔，TC 从纵轴的 TFC 处起笔。
      两条曲线斜率处处相同，垂直间距恒等于 TFC，所以 TC 永远不过原点。
```

读图：TC 就是把 TVC 整条往上平移 TFC，所以它从纵轴的 TFC 处起笔，永远不会经过原点。

### 平均与边际：斜率的两种读法

#### 三条平均曲线

平均总成本 $AC = TC/Q$，几何上就是 TC 曲线上一点与原点连线的斜率。看这条连线怎么动：从原点往右扫，连线先是越来越平缓，斜率变小；过了某一点之后又越来越陡，斜率变大。

所以 AC 先下降、再上升。

AVC 同样是从 TVC 上读：TVC 上一点与原点连线的斜率，先减后增，所以 AVC 也是先降后升。

AFC 不一样。分子 TFC 是常数，分母 Q 越来越大，比值一路变小，与原点连线一路变缓，所以 AFC 从左上一直往下掉，全程单调递减。

| 平均函数 | 读法 | 走向 |
| :--- | :--- | :--- |
| AC | TC 上一点与原点连线的斜率 | 先降后升 |
| AVC | TVC 上一点与原点连线的斜率 | 先降后升 |
| AFC | TFC 上一点与原点连线的斜率 | 一直下降 |

#### 平均可变成本为什么先见底

AC 和 AVC 都是先降后升，但两个最低点不在同一个位置：AVC 先到最低点，AC 后到。

原因在起点：TVC 过原点，TC 不过原点。TC 相当于 TVC 整条往上平移了一段固定成本，平移之后，与原点连线斜率最小的那个点被推到了更右边。

也可以从加法上看：$AC = AVC + AFC$。AVC 触底之后开始往上走，可在这一段上 AFC 还在继续往下掉，两者相加，AC 还得再滑一段才到底。

#### 短期边际成本

$SMC = \dfrac{dTC}{dQ}$，就是 TC 曲线自身的斜率。看斜率怎么变：开始那一段比较陡，往前走变得平缓，斜率在减小；再往前又变陡，斜率在增大。

所以 SMC 也是先下降后上升。

### 边际和平均的关系：60 个学生和 85 分

边际和平均之间有一条铁律：

- 边际大于平均，就拽着平均往上走，平均上升；
- 边际小于平均，就拽着平均往下坠，平均下降；
- 边际等于平均，平均正好停在最低点。

这条规律拿班里的分数想最清楚。假设班里 60 个学生，期末平均分 85。这时候转来一个学生：

- 他考 90，比 85 高，算上他的 61 个人，平均分就高于 85；
- 他考 84，比 85 低，算上他的 61 个人，平均分就低于 85。

转来的这个学生就是"边际"，班里原来的平均分就是"平均"。新来的比平均数高，平均数被拉上去；新来的比平均数低，平均数被拽下来。

套到成本上：SMC 小于 AVC 时，AVC 处在下降段；SMC 大于 AVC 时，AVC 处在上升段；两者刚好相等时，正好是 AVC 的最低点。AC 同理，SMC 也从 AC 的最低点穿过去。

所以短期这一整套图形，最后就落在两条结论上：三条总量曲线打底；MC 从 AVC 和 AC 的最低点穿过。

### 长期成本函数只剩三个

长期和短期的分水岭只有一句话：K 变不变。

短期：K 是常数，只有 L 变。长期：L 和 K 都变。

长期成本函数里没有常数项，所以也就没有固定成本。没有固定成本，可变成本和总成本就是一回事，函数个数从七个掉到三个：长期总成本 LTC、长期平均成本 LAC、长期边际成本 LMC。

LTC 的画法和短期一样，还是跟生产函数对着记：先把生产函数那个"对号加一个弯"画出来，再取它的对称图形。

LAC 是从 LTC 上读出来的——LTC 上一点与原点连线的斜率，先变小再变大，所以 LAC 先降后升，是个 U 型。

LMC 是对 LTC 求导，也就是 LTC 每一点自身的斜率，先平缓后陡峭，所以 LMC 也是先降后升的 U 型。

LMC 与 LAC 的关系和短期完全一样：LMC 小于 LAC 时 LAC 下降，LMC 大于 LAC 时 LAC 上升，两者相等时 LAC 到最低点。换句话说，LMC 从 LAC 的最低点穿过。

### 一套能通吃的画图法则

短期的七个、长期的三个都过了一遍，把方法抽出来其实只有三步。生产函数、成本函数，短期、长期，全都按这个走：

```text
第一步   画总量曲线
         （总产量 / 总成本 / 总可变成本 / 总固定成本）
              |
              v
第二步   边际 = 总量曲线上每一点自身的斜率
         平均 = 总量曲线上每一点与原点连线的斜率
              |
              v
第三步   用"边际大于平均则平均上升、小于则下降"校验交点位置
```

读图：总量曲线是根，边际和平均都是从它身上量出来的两个斜率，量完再用边际—平均关系把交点对一遍，图就出来了。

三步缺一不可。少了总量曲线，平均和边际没地方量；少了斜率读法，平均和边际画不出来；少了边际—平均关系，两条曲线在哪儿相交就说不清。

### 长期总成本曲线：从六条短期曲线包出来的一条线

接下来讲长期和短期之间的关系。先看总成本。

LTC 还有个名字，叫长期计划曲线。道理是：短期里厂商不能立刻把规模调到最优，只能在现有规模上生产；长期时间够长，可以先挑一个最优规模，然后一直按这个规模生产下去。所以长期总成本讲的是"计划"，短期总成本讲的是"已经在跑的那个规模"。

关键前提是：长期里厂商可以调整自己的生产规模。

假设厂商手上有六个可选规模，从 STC1 一直到 STC6。要生产 Q1 这么多产量，六个规模其实都做得到，但哪个最省？

画一条竖线上去，六条曲线在同一产量上的成本高度一目了然，最低的那个点对应的规模就是最优规模。Q1 处 STC1 最低，所以选 STC1。

再找一个更大的产量，还是 STC1 最低——一直低到一个临界点为止。

临界点就是 STC1 与 STC2 的交点。在这个产量上，两个规模花的钱一样多，选哪个都行；过了这个点，STC2 更省。

怎么判断哪个规模大？把曲线往左补到纵轴，看截距。截距表示的就是这个规模所耗费的固定成本，谁与纵轴的交点高，谁的固定成本就大，规模也就大——大厂要引更多设备、更多机器，固定投入本来就更重。

交点处到底选哪个？如果今后打算扩产，就选大的那个规模，对后面有利；如果就想维持现在的产量，选小的那个接着用。这一条不是重点，跟长短期关系的主线关系不大，提一句就够。

把每个产量区间里最省的那一段接起来：OR、RS、ST、TU、UV。这五段连成的折线，就是厂商的长期总成本曲线。

```text
C
|
|                                      ,-'  LTC
|                                ,-'
|                          ,-'
|                    ,-'
|              ,-'
|        ,-'
|,-'
+----|-----|-----|-----|-----|-----|--------> Q
     O     R     S     T     U     V
     每一段都由一条 STC 承包，段与段的交界就是相邻两条 STC 的交点
```

读图：这条折线就是"六个规模里每次挑最省的那个"拼出来的结果；可选规模越多，每一段就越短。

但六个规模只是举例。现实里厂商能选的规模有无数个，从 STC1 一直到 STCn。

这就是微分的想法。段数从 6 加到 n，每一段的弧越来越小；无限细分下去，每一段短到几乎变直、甚至缩成一个点，折线就成了一条光滑的曲线。这条光滑曲线才是最终的 LTC。

当年考研的时候我在这儿卡了很久：只听说"无限细分"，可想不明白到底怎么分、怎么就一下由曲变直了。所以这一段我讲细一点。

把规模从六个扩到十个，画出来就清楚多了：每加一个规模，就多一个交点、多一小段，折线被切得更碎。扩到十个，趋势已经能看出来了；要是有张无限大的纸，一路画到 n 条当然更彻底。

n 个规模的情形的本质是：每一条 STC 与纵轴的交点彼此无限接近。截距挨得越近，相邻两条曲线的交点就挨得越近，切出来的弧就越小。弧小到极限，折线自然就平滑了。

这一段我讲得细，但也不敢保证一次就能听透；真绕不过来的地方，随时来问。

### 长期平均成本与短期平均成本：相切，但一般不切在最低点

平均这一层的推导和总成本一个路子，只是换到平均曲线上做。前面短期那个 AC，在跟长期做对比时写成 SAC，好和 LAC 一眼对上。

每个产量上挑出 SAC 最低的那条，把各条 SAC 的最优段接起来；规模数从五个扩到 n 个，同样用微分的想法无限细分，就得到一条圆滑的 LAC。

> **结论**：LAC 是无数条 SAC 的下包络线，它与每一条 SAC 都相切。

但相切的位置很有讲究，这是画图时最容易出错的地方：

| LAC 上的位置 | 切点落在该 SAC 的哪一段 |
| :--- | :--- |
| LAC 的最低点处 | 正好切在该 SAC 的最低点 |
| LAC 最低点的左侧 | 切在该 SAC 最低点的左边 |
| LAC 最低点的右侧 | 切在该 SAC 最低点的右边 |

也就是说，并不是每条 SAC 都拿自己的最低点去和 LAC 相切。只有 LAC 自己最低的那一点，才与某条 SAC 的最低点相切；左边那些切点都落在各自 SAC 最低点的左侧，右边那些都落在右侧。

> **易错点**：别把每条 SAC 的最低点都摆到 LAC 上。只有 LAC 最低点那一处，切点才和 SAC 的最低点重合。

### 长期边际成本与短期边际成本：必有一个交点

画法是这样的：先由 SAC 得到 LAC（下包络），再由 LAC 反推 LMC。因为边际与平均的关系是通用的——LMC 从 LAC 的最低点穿过，LAC 下降的那一段对应 LMC 小于 LAC，上升的那一段对应 LMC 大于 LAC。

LMC 与 SMC 之间还有一层必然的联系：两条曲线一定有一个交点，在这一点上两者相等。

道理只有一句。LAC 与某条 SAC 相切，切点处两条曲线的斜率相等；而 SAC 的斜率就是 SMC，LAC 的斜率就是 LMC。斜率相等，就意味着那一点上 SMC 等于 LMC。

> **结论**：LMC 与 SMC 必在 LAC 与 SAC 的切点处相交。切点在哪，交点就在哪。

到这里，长期与短期在三条曲线上的关系就齐了：

| 曲线对 | 关系 |
| :--- | :--- |
| LTC 与 STC | 下包络：每个产量上取成本最低的那条 STC 的一段，无限细分后平滑成线 |
| LAC 与 SAC | 下包络且相切：只有 LAC 最低点处才切于 SAC 的最低点 |
| LMC 与 SMC | 在 LAC 与 SAC 的切点处相等 |

### 成本最小化：拉格朗日的固定套路

最后一块是成本最小化问题，这块往往出现在计算题里。

题目是：假设两种生产要素为 L 和 K，价格分别为 w 和 r，在既定的产出下求最小成本。

求极值、求最值，数学上的标准武器是拉格朗日函数，这里用的也是同一套。对拉格朗日函数不熟的话，回去把数学那块稍微补一补，这块本身不难，做题就是一个固定套路，一共两步。

```text
第一步   找目标函数 + 找约束条件
              |
              v
第二步   构造拉格朗日函数，对各变量求偏导，令其为零
              |
              v
         两式相除消掉乘子，得到要素价格比与边际产量比的关系
```

读图：两步走完答案就出来了，所有"既定产量下成本最小"的题都是这个骨架。

第一步，找目标函数。找法很朴素：题目让你求什么，什么就是目标函数。这里求的是最小成本，那成本函数就是目标函数：

$$\min \; C = wL + rK$$

约束条件是"既定产出"，也就是生产函数：

$$\text{s.t.} \quad Q = f(L, K)$$

第二步，构造拉格朗日函数。先把目标函数原样抄下来，再加上乘子 $\lambda$ 乘以约束条件。注意括号里不能写成等式——外面已经有一个等号了，里面要写成 $Q - f(L, K)$ 这种形式：

$$M = wL + rK + \lambda\,[\,Q - f(L, K)\,]$$

这里把拉格朗日函数记作 M 而不是 L，因为 L 在这道题里已经是劳动力了，两个 L 摆在一起容易看花眼。

接下来有三个自变量：L、K、$\lambda$，所以要求三个偏导：

$$\frac{\partial M}{\partial L} = w - \lambda\frac{\partial f}{\partial L} = 0$$

$$\frac{\partial M}{\partial K} = r - \lambda\frac{\partial f}{\partial K} = 0$$

$$\frac{\partial M}{\partial \lambda} = Q - f(L, K) = 0$$

把前两式整理一下，记作一式、二式：

$$w = \lambda\frac{\partial f}{\partial L}, \qquad r = \lambda\frac{\partial f}{\partial K}$$

两式相除，$\lambda$ 约掉：

$$\frac{w}{r} = \frac{\partial f / \partial L}{\partial f / \partial K}$$

$f$ 就是生产函数，对 L 求偏导是劳动的边际产量 $MP_L$，对 K 求偏导是资本的边际产量 $MP_K$：

$$\frac{w}{r} = \frac{MP_L}{MP_K}$$

> **结论**：当两种要素的价格之比等于它们的边际产量之比时，成本达到最小。

第三个方程就是约束本身，和前两式联立，解出 L 和 K 的取值，再代回成本函数，最小成本也就有了。

这块要是还没听透也不用急，后面有专门的计算题专项，会把这类题拆得更细。

### 本讲提到的题目

**题目**：假设两种生产要素为 L 和 K，价格分别为 w 和 r，在既定的产出下求最小成本。

**答案**：当要素价格之比等于边际产量之比，即 $\dfrac{w}{r} = \dfrac{MP_L}{MP_K}$ 时，成本最小。拉格朗日函数的构造、三个偏导与相除消去 $\lambda$ 的完整过程，见上文《成本最小化：拉格朗日的固定套路》一节。

最后再啰嗦一句：成本函数一定要和生产函数对比着记，横纵轴别画反，七个和三个别记混，两边的曲线是对称的，记一边就够了。
