## 完全竞争市场：价格为什么轮不到厂商来定
> 对应块：BLK05 | 覆盖分集：P10 | 块标题（分集名）：《完全竞争市场》

### 四个市场，一条按垄断程度排下来的队

市场不止一种。按垄断程度由浅到深排下来，一共四种：完全竞争排在最前面，垄断程度最浅；后面依次是垄断竞争、寡头、完全垄断，一档比一档更垄断。这四种我打算分开讲，一种一讲。

每讲一种市场，我都按同一套问题过一遍，一共五个方面：

- 厂商有多少家，买方和卖方各是什么规模；
- 产品的差异程度，是完全同质还是有差别；
- 厂商对价格的控制程度；
- 进入和退出这个行业难不难；
- 买卖双方对市场信息的掌握程度。

同一把尺子量四个市场，横向一摆，差别自己就出来了。

完全竞争是这四档里最特殊的一个，因为它是**绝对理想化**的市场：分析里到处都在用它，现实生活里基本上不存在。真要在现实里找一个最接近的行业，那就是农产品。

基本情况就这些，下面正式进入完全竞争市场。

### 完全竞争的含义与四个条件

#### 含义：无穷分之一，等于没有定价权

完全竞争市场又叫**纯粹竞争市场**。它的定义抓住的是一点：每家厂商都不必考虑自己的行动会给整个市场带来什么影响，因为它在市场里占的份额微不足道。

把这句话反过来读，就是它的实质——厂商没有价格的决定权。

原因只有两条，而且这两条是绑在一起的：厂商无穷多，产品完全同质。同质到什么程度？外表、质量、特点，一模一样。既然消费者买谁家的都一样，就没有任何一家能靠"我的东西更好"把价格抬起来，也没有任何一家需要靠降价把顾客拉过来。

> **结论**：完全竞争厂商是价格的接受者（price taker），不是价格的制定者。后面所有的推导，都是从这一句话里长出来的。

#### 条件：无数、同质、要素流动、信息完全

完全竞争市场的条件有四条。

第一，有无数买者和卖者。无数这个说法要落到实处：每一个买者、每一个卖者都只占 $\frac{1}{\infty}$，也就是无穷分之一。无穷分之一就是微不足道，微不足道就没有价格决定权，所以每一个人都只能被动接受价格。

第二，产品是同质的。这一条和上一条是配套的：光有无数家厂商，如果各家的东西不一样，厂商照样能靠差别定价；反过来，产品同质但只有两三家，那两三家一样能操纵价格。两条同时成立，价格才真正被钉死。

第三，要素可以自由流动。注意不只是商品能自由流动，生产要素也要能自由流动——劳动力、土地、资本，发展到现在还要加上服务，这些东西都能自由进出。这一条管的是进入和退出：要素能流动，行业才进得去、也出得来。短期里它被时间卡住，长期里才真正生效。

第四，信息是完全的。买者和卖者既完全掌握自己的信息，也完全掌握对方的信息。这一条有个很实在的推论：广告的价值很小。产品本来就一模一样，谁也做不出差别来，广告没有东西可讲。

| 条件 | 说的是什么 | 直接后果 |
| :--- | :--- | :--- |
| 无数买者卖者 | 每一家只占无穷分之一 | 谁都无法影响价格，只能接受 |
| 产品同质 | 外表、质量、特点完全一样 | 消费者没有偏好，只认价格 |
| 要素自由流动 | 劳动、土地、资本、服务都能进出 | 长期可自由进入退出，利润被抹平 |
| 信息完全 | 双方掌握自己和对方的信息 | 没有信息差可利用，广告近乎无效 |

这四条不难，但它们是地基。后面讲需求曲线为什么水平、讲长期为什么只能拿正常利润，用的全是这里的两句话：厂商无穷多，产品同质。

### 两条需求曲线：厂商水平，市场倾斜

完全竞争厂商的第一个重点，是它的需求曲线。

先把一个容易含混的地方挑明：在完全竞争市场里，厂商有需求曲线，市场也有需求曲线，但这两条线长得完全不一样。厂商的需求曲线是一条**水平线**；市场的需求曲线是一条**向右下方倾斜**的线，也就是我们第一章学过的那种正常的需求曲线。

#### 先把需求曲线是什么说清楚

需求曲线表示的是价格和需求量之间的关系。

按这个定义去读那两条线：

- 厂商的需求曲线水平，意思是无论需求量是多少，价格都是同一个定值，不随销量变动；
- 市场的需求曲线向右下方倾斜，意思是价格随需求量变动，量大了价就低。

于是问题聚焦成一个：为什么厂商的价格是固定的，它为什么不随自己的销量改变价格？

#### 厂商为什么只能接受价格

答案要从含义和条件里找。

市场上有无数厂商，每一家都是无穷分之一，微不足道，没有价格决定权，只能被动接受价格。对单个厂商来说，市场价格是给定的：在这个既定价格下，它能决定的只有自己想卖多少，不能决定卖什么价。卖多卖少，都是一个价。

那它能不能自己提价？不能。整个市场上有无数卖者，产品一模一样，消费者不是傻子——只要有一家把价格抬上去，消费者立刻转去买别家的，这一家的需求量会直接掉到零。提价的厂商什么也得不到。

降价呢？也没有必要。按既定价格它已经能把想卖的卖完，降价只是白白少收钱。

于是提价没人干、降价没人干，全行业就停在同一个既定价格上。用数学说就是：$P$ 是常数，无论 $Q$ 是多少，$P$ 都不变。这就是那条水平线。

> **提示**：这条水平线不是"需求量无限大"的字面意思，而是说在既定价格上，市场要多少它就能卖多少，价格一分不动——单个厂商的销量对价格没有丝毫影响力。

#### 市场为什么仍然向右下方倾斜

厂商那条线通了，市场的这条为什么还是斜的？

关键在于：**市场和厂商是两个完全不同的概念**。我们说的厂商，指的是某一个固定行业里的厂商。同一行业里所有厂商的产品同质，彼此可以完全替代——正因为可以完全替代，谁都没有定价权，只能按一个价卖，这就是厂商那条水平线。

市场不是这样。市场不单独指哪一个行业。行业和行业之间是不能互相替代的：服装行业不可能被餐饮行业替代，粮食也不可能被汽车替代。行业之间替代不了，这个行业整体的价格就不会被别的行业直接压住，它自己的价格仍然由本行业的供求决定，会随需求量变化——画出来，还是那条向右下方倾斜的线。

把话说白一点：厂商面对的是同行给的一个既定价格，无数个一模一样的竞争者把价格钉死了；市场面对的则是这个行业里所有买者加总起来的需求，价格高一点，总购买量就少一点。

> **易错点**：不要把这两条线混成一个问题。水平说的是"行业里的某一家"，倾斜说的是"市场，也就是行业整体"。判断的标准只有一条——看它面对的是同行，还是面对全体买者。

### 收益不等于利润：四线合一

需求曲线讲完，接着是收益曲线。收益用 $TR$ 表示。

什么是收益？你卖了多少钱，收益就是多少。它其实就是**销售额**。

这里必须把收益和利润分开，这一条一定要记住：收益是销售额；利润是销售额再把成本减下去。收益大不等于利润大，两回事。

既然收益就是销售额，公式直接写出来：

$$TR = P \cdot Q$$

在完全竞争厂商这里，$P$ 是一个定值、一个常数，$Q$ 是会变的。所以 $TR$ 和 $Q$ 是正相关：价格不动，销量涨多少，收益就涨多少，画出来是一根过原点的直线，斜率就是那个不变的价格。

```text
TR
│              ╱
│            ╱          ← TR = P·Q，斜率就是不变的价格 P
│          ╱
│        ╱
│      ╱
│    ╱
└────────────────── Q
```

读图一句话：价格不变，所以收益随销量按固定比例往上走，是一条直线而不是曲线。

有了 $TR$，平均收益和边际收益都能算出来。

平均收益是单位销量摊到的收益：

$$AR = \frac{TR}{Q} = \frac{P \cdot Q}{Q} = P$$

边际收益是多卖一单位多拿到的收益，也就是 $TR$ 对 $Q$ 求导。因为 $P$ 是常数，求导之后 $P$ 原样留下来：

$$MR = \frac{dTR}{dQ} = P$$

于是 $AR$、$MR$ 都等于 $P$；而刚才讲过，厂商面临的需求曲线本身就是高度为 $P$ 的那条水平线。四条线落在同一条水平线上：

$$P = AR = MR = d$$

```text
P
│
│   d = AR = MR = P      ← 需求曲线、平均收益、边际收益重合
│ ────────────────────────────────
│
└──────────────────────────── Q
```

读图一句话：价格定在哪个高度，需求曲线、平均收益线、边际收益线就一起画在哪个高度，看上去只有一条线。这就是"四线合一"，也是完全竞争厂商最好用的一条性质——想找 $MR$，直接看价格就行。

### 利润最大化：把导数令成零

下一个知识点是利润最大化的均衡条件。这个条件用图形能推，用公式也能推，公式更简明。

思路就是求最值：先把利润函数写出来，求导，令导数为零。

利润是收益减成本：

$$\pi = TR - TC$$

对 $Q$ 求导，$TR$ 的导数是 $MR$，$TC$ 的导数是 $MC$：

$$\frac{d\pi}{dQ} = \frac{dTR}{dQ} - \frac{dTC}{dQ} = MR - MC = 0$$

移项就得到：

$$MR = MC$$

这就是利润最大化的均衡条件：**边际收益等于边际成本**。在完全竞争市场里要实现利润最大化，必须满足这一条。

图形上的道理和公式是一回事，就看 $MC$ 与 $MR$ 谁在上面：

- $MC < MR$ 的区间，每多生产一单位，增加的收入大于增加的成本，这一单位是赚钱的。厂商是利益驱动者，这时候它只会继续提高产量，不会停下来。
- $MC > MR$ 的区间，每多生产一单位都要倒贴，厂商不会让自己继续亏下去，会把产量往回减。
- 只有在 $MR = MC$ 那一点，多生产一单位的得失正好抵平，产量不再变——这就是均衡。

```text
MC < MR  ── 每多一单位都赚钱 ──→ 继续扩产
MC > MR  ── 每多一单位都亏钱 ──→ 往回减产
MC = MR  ── 得失正好抵平     ──→ 产量不动，均衡
```

> **提示**：这个条件不是完全竞争独有的，它是"利润最大化"这件事本身的一阶条件。完全竞争的特殊之处只在于 $MR$ 恰好等于价格，所以后面所有判断都能直接用价格去比成本，不必再单独算一条 $MR$ 线。

### 均衡为什么以厂商为主

下面这一块是这一讲最重要也最难的部分：完全竞争的均衡。

教材上这一节的标题是"完全竞争厂商的均衡"，我特意把它写成"完全竞争的均衡"，因为只写厂商会造成误导：完全竞争里不是只有厂商才均衡，**市场也是有均衡的**。

那书上为什么只写厂商？因为市场的均衡太简单了。市场的需求曲线就是一条正常的、向右下方倾斜的需求曲线，供给曲线照常，两条线一相交就是均衡点——需求等于供给，均衡就成立了。简单到没什么可讲的。

厂商不一样。从讲需求曲线起它就不寻常：它的需求曲线不是一条正常的需求曲线，而是一条水平线。开局就特殊，讲到均衡自然还是它特殊。所以研究的分量压在厂商这一头，市场均衡一句话带过。

### 短期均衡：先定产量，再判盈亏，最后判停产

#### 短期的两个前提

第一，短期内企业不能进入也不能退出。时间太短，新企业来不及进来，旧企业也来不及退出。

第二，短期里 $L$ 是可变的，$K$ 是不变的。多雇几个工人、少雇几个工人很容易；但短期内想一下子筹到一大笔资金去买设备，很难。所以劳动可变，资本是个常数。

#### 盈亏看价格与 SAC

短期里厂商只盯两件事：一是盈亏状况，什么时候赚、什么时候亏；二是停产决策，亏了以后什么时候该停。

这两件事都靠**价格**判断。而这个价格不是随便定的，它是 $MR = MC$ 定出来的均衡价格——先用均衡条件定下产量和价格，再拿这个价格去比成本。

先看盈亏。利润可以写成：

$$\pi = (P - SAC) \cdot Q$$

$P$ 是销售价格，$SAC$ 是生产这些商品平均每单位花的成本。价格减平均成本，就是每卖一单位赚到的钱；再乘以销量，就是总利润。

因为 $Q > 0$，$\pi$ 的正负完全由括号决定：

| 价格与成本的关系 | 利润 | 盈亏 |
| :--- | :--- | :--- |
| $P > SAC$ | $\pi > 0$ | 盈利 |
| $P = SAC$ | $\pi = 0$ | 不盈不亏 |
| $P < SAC$ | $\pi < 0$ | 亏损 |

#### 停产看价格与 AVC

停产决策和盈亏状况是两件事。赚钱的时候没人想着把公司关掉，这个不用讨论；亏损的时候才要考虑停不停。

但**亏损不等于马上停产**。企业有固定资产：房租已经付了，设备已经买了。亏得不多的时候，卖货收回来的钱还勉强能弥补固定资产的损耗，那就没有必要停。亏到连固定资产都补不上，才不得不停。

所以判断停产，得把固定成本从利润函数里单独显出来：

$$\pi = TR - TC = PQ - (TVC + TFC) = PQ - AVC \cdot Q - FC = (P - AVC)Q - FC$$

这里用了 $TVC = AVC \cdot Q$。式子的意思是：卖货收回来的钱先扣掉可变成本，剩下的 $(P - AVC)Q$ 拿去补固定成本 $FC$，补不完的部分就是净亏损。

拿它和"一点都不生产"比。$Q = 0$ 的时候 $\pi = -FC$：一单位都不生产，固定成本照样白耗。

- $P > AVC$：$(P - AVC)Q > 0$，所以 $\pi > -FC$。比停产强，多多少少补回一点固定成本，**继续生产**。
- $P = AVC$：$\pi = -FC$，和完全不生产一模一样。生产也行，不生产也行，这一点叫**关闭点**。
- $P < AVC$：$\pi < -FC$，生产比停产还糟，多生产一单位多亏一单位，**必须停产**。

> **结论**：盈亏看 $P$ 与 $SAC$，停产看 $P$ 与 $AVC$。两个判断用的是两条不同的成本线，不能混着用。

#### 五种情况走一遍

把价格从高到低排开，五种情况一次走完。顺序永远是三步：先由 $MR = MC$ 定出价格，再比 $SAC$ 判盈亏，只有亏了才比 $AVC$ 判停产。

```text
                     ┌─ P > SAC ───────────── 盈利，继续生产
                     │
MR = SMC ── 定出 P ──┼─ P = SAC ───────────── 不盈不亏（正常利润）
                     │
                     └─ P < SAC ── 亏损 ──┬─ P > AVC ── 继续生产
                                           ├─ P = AVC ── 关闭点
                                           └─ P < AVC ── 必须停产
```

读图一句话：上半段只判盈亏，下半段才判停产；停产判断只在亏损这个分支里出现。

| 情形 | 价格位置 | 盈亏 | 是否停产 |
| :--- | :--- | :--- | :--- |
| 第一种 | $P_1 > SAC$ | 盈利 | 不考虑 |
| 第二种 | $P_2 = SAC$ | 不盈不亏 | 不考虑 |
| 第三种 | $AVC < P_3 < SAC$ | 亏损 | 继续生产 |
| 第四种 | $P_4 = AVC$ | 亏损 | 关闭点，产与不产一样 |
| 第五种 | $P_5 < AVC$ | 亏损 | 必须停产 |

第二种情况值得多看一眼：价格线刚好切在 $SAC$ 的最低点上，厂商拿到的是正常利润，一分超额利润也没有。这个点后面讲长期均衡还要回来。

### 短期供给曲线：从厂商到行业

#### 厂商的那一段：AVC 最低点以上的 SMC

供给曲线表示的是价格和供给量之间的关系。

有一个前提要先立住：**至少不停产，才有供给**。停产了就没有供给可谈。而不停产的条件是 $P \geq AVC$，所以供给曲线一定在 $AVC$ 之上——更准确地说，在 $AVC$ 的最低点以上。

具体怎么定一个点？给定价格 $P_1$，由 $MR = MC$，而 $MR$ 又等于 $P$，所以就是拿 $P_1$ 这条水平线去和 $SMC$ 相交，交点对应的量是 $q_1$。换一个价格 $P_2$，同样得到一个 $q_2$。价格有无数个，交点也有无数个，这些交点连起来，恰好就是 $SMC$ 这条线本身。

```text
P
│             SMC
│            ╱
│   P1 ─────●────→ q1
│          ╱
│  P2 ────●─────→ q2
│        ╱
│ ──────●────────── AVC 最低点（关闭点）
│      ┆
│      ┆   ← 这一段在 AVC 以下，不生产，没有供给
└────────────────── Q
```

读图一句话：实线那一段（$AVC$ 最低点以上的 $SMC$）才是厂商的短期供给曲线；$AVC$ 最低点以下那一段要画虚线，因为厂商在那里根本不生产。

> **结论**：完全竞争厂商的短期供给曲线，是 $AVC$ 最低点以上那一段 $SMC$。

#### 行业的曲线：横向加总

行业的短期供给曲线，就是所有厂商短期供给曲线的加总——同一个价格下，把各家愿意供给的量加起来。形状和走势跟单个厂商完全一样，只是整体更靠右。这一条不用多绕。

### 长期均衡：超额利润一定会被抹平

#### 长期的两个前提

第一，厂商可以随意进入和退出这个行业，所以行业里的厂商数量是会变的。

第二，$K$ 和 $L$ 都可以变。

#### 为什么长期只能拿到正常利润

短期有五种情况：可能拿到超额利润，可能不盈不亏，也可能亏损。不盈不亏就是拿到**正常利润**，也叫平均利润，也就是利润为零。

长期只剩一种：只能拿到正常利润，拿不到超额利润。

原因就在"可以随意进入"。假设某个行业现在有超额利润，行业外的厂商看得眼红，一窝蜂涌进来，供给一下子增加，甚至供给大于需求；供给一多，价格就一路往下掉，掉到不盈不亏为止。到那时候新厂商看看没油水可捞，也就不再进了，局面稳定下来。

反过来也一样。一个行业长期亏损，旧厂商干不下去陆续撤出，供给减少；供给少了，物以稀为贵，价格回升，回升到刚好能拿到正常利润为止，剩下的厂商也不再退出。

所以长期均衡的标志就是：不盈不亏。

> **提示**：这里的"利润为零"指的是超额利润（经济利润）为零。正常利润已经算在成本里了，所以"利润为零"恰恰意味着该拿的报酬一分没少拿——这正是长期均衡能稳住的原因。

#### 那个连等式是怎么来的

判断盈亏用的是价格和平均成本。短期比 $SAC$，长期就比 $LAC$。长期不盈不亏，所以：

$$P = LAC$$

价格线是水平的，$LAC$ 是 U 形的，水平线要和它相切，只能切在最低点。所以 $P = LAC$ 的位置就是 $LAC$ 的最低点。

再往下推，全靠成本曲线本身的几何关系：$LAC$ 的最低点和 $SAC$ 的最低点相切；$LMC$ 一定穿过 $LAC$ 的最低点；$SMC$ 一定穿过 $SAC$ 的最低点。四条成本线在同一点会合，于是：

$$P = MR = LMC = SMC = LAC = SAC$$

```text
P
│            LMC   SMC
│              ╲   ╱
│               ╲ ╱
│  P* ───────────●───────────  四线同交
│               ╱ ╲
│          LAC ╱   ╲ SAC
│             ╱     ╲
└──────────────────────────── Q
```

读图一句话：在 $P^*$ 这一高度上，$LMC$、$SMC$、$LAC$、$SAC$ 四条线交于同一点，价格同时等于它们四个。

这个连等式不要硬背，硬背一定会漏项。记法只有一条：长期不盈不亏，所以 $P = LAC$；剩下的用成本曲线的几何关系一项一项推出来。

### 行业的长期供给曲线：三种成本情形

#### 长期为什么没有厂商的供给曲线

这里有个疑问值得先解开。短期我们是先讲厂商的供给曲线，再讲行业的（加总）。到了长期，为什么直接跳到行业，不讲厂商的了？

因为长期厂商只有一种情况：只能拿到正常利润。只有那一个价格、那一个规模能让它不盈不亏，它的"供给曲线"就缩成了一个点。一个点算不上一条曲线，所以说长期厂商的供给曲线不存在，只看行业的。

行业的长期供给曲线要分情况，分三种：成本固定不变行业、成本递增行业、成本递减行业。

#### 共同的动作：需求冲击、进入、供给右移

三种情形的推法完全一样，只是成本曲线动不动不一样。

假设因为某种原因需求增加了，需求曲线由 $D_1$ 移到 $D_2$，供给暂时不动。初始均衡是 $D_1$ 与 $S_1$ 的交点，记作 $a$，对应价格 $P_1$。需求一移，新的短期交点是 $D_2$ 与 $S_1$ 的交点，价格升到 $P_m$——行业赚钱了，有了超额利润。

接下来就是那套固定的动作：

```text
需求增加：D1 → D2
      │
      ▼
价格升到 Pm，高于正常利润价格 → 行业出现超额利润
      │
      ▼
行业外厂商眼红，大量涌入 → 供给 S1 开始右移
      │
      ▼
价格回落，直到只剩正常利润 → 停止进入，S 停在 S2
      │
      ▼
a（D1 与 S1 的交点）与 b（D2 与 S2 的交点）的连线
      =  行业长期供给曲线
```

读图一句话：$a$ 是起点，$b$ 是终点，中间那段"涨价—进入—降价"走完，两点连起来就是长期供给曲线。三种行业的区别只在一点——成本曲线会不会随着供给扩大而移动，从而把新的正常利润价格 $P_2$ 抬到 $P_1$ 之上，或者压到 $P_1$ 之下。

#### 成本不变行业：水平线

成本固定不变，指的是随着供给改变，成本还是原来那个成本，一动不动。

既然成本不动，那么按原来的价格 $P_1$ 卖就仍然只能拿到正常利润。所以供给曲线右移到价格回到 $P_1$ 的时候，就不再动了，最终均衡点 $b$ 与 $a$ 同高。两点连线是一条水平线。

#### 成本递增行业：向右上方倾斜

成本递增，指的是供给增加的时候，成本跟着往上走。

道理不复杂：行业扩大，对要素的需求变大，要素价格被推上去，成本曲线整体上移——$SMC_1$ 上移到 $SMC_2$，$LAC_1$ 上移到 $LAC_2$。成本抬高了，能拿到正常利润的价格也就抬高了，新的正常利润价格 $P_2 > P_1$。

所以供给曲线右移，价格不必回到 $P_1$，只要降到 $P_2$ 就够了——在 $P_2$ 上厂商已经不盈不亏，不会再有人进入，供给就停住。最终均衡点 $b$ 比 $a$ 高，两点连线向右上方倾斜。

#### 成本递减行业：向右下方倾斜

成本递减，指的是供给增加的时候，成本反而往下走。

成本降了，能拿到正常利润的价格也降了，新的正常利润价格 $P_2 < P_1$。供给右移之后，价格要一直降到 $P_2$ 才停住，最终均衡点 $b$ 比 $a$ 低，两点连线向右下方倾斜。

```text
   成本不变              成本递增              成本递减
P                     P                     P
│  LS                 │      LS             │  LS
│ ─────────           │     ╱               │   ╲
│                     │   ╱                 │    ╲
│                     │ ╱                   │     ╲
└────── Q             └────── Q             └────── Q
```

读图一句话：三条线都从初始均衡点出发、终止于新的长期均衡点，形状的差别完全由"供给扩大时成本往哪边走"决定。

| 行业类型 | 供给扩大时成本曲线 | 新的正常利润价格 | 长期供给曲线 |
| :--- | :--- | :--- | :--- |
| 成本不变 | 不动 | $P_2 = P_1$ | 水平 |
| 成本递增 | 上移 | $P_2 > P_1$ | 向右上方倾斜 |
| 成本递减 | 下移 | $P_2 < P_1$ | 向右下方倾斜 |

### 这一讲的三块骨架

完全竞争这一块，抓三块就够。

第一块是概念和条件，等于地基。厂商无数、产品同质、要素自由流动、信息完全。后面所有的结论都是从这四条推出来的。

第二块是需求曲线。厂商的需求曲线是水平的，而且四线合一：$P = AR = MR = d$。市场的需求曲线是正常的，向右下方倾斜。

第三块是均衡，分短期和长期两头。

- 短期：$MR = MC$ 定出价格；$P$ 比 $SAC$ 判盈亏；亏了再用 $P$ 比 $AVC$ 判停产。厂商的短期供给曲线是 $AVC$ 最低点以上的 $SMC$，行业的短期供给曲线是厂商的加总。
- 长期：只能拿到正常利润，$P = LMC = SMC = LAC = SAC$。行业有长期供给曲线——成本不变是水平，成本递增向右上，成本递减向右下；厂商的长期供给曲线不存在。

## 完全垄断：定价权、均衡与价格歧视
> 对应块：BLK06 | 覆盖分集：P11 | 块标题（分集名）：《完全垄断市场》

有一个词得先钉死：这里每次说「垄断」，指的都是**完全垄断**，不是垄断竞争。两个词只差两个字，可混着用，后面每一条曲线都会跟着画歪。

钉死这个词，骨架也就清楚了：先看垄断市场凭什么成立，再看它的需求曲线和收益曲线长什么样，然后分别处理短期均衡和长期均衡，最后落到价格歧视和定价法则上。短期均衡要掌握三件事，长期均衡要掌握两件事；至于自然垄断和政府管制，理解起来不难，自己翻书过一遍就够。

| 板块 | 要掌握的内容 |
| :--- | :--- |
| 垄断市场的条件 | 行业里只有唯一厂商、产品无相近替代品、别人进不来 |
| 需求曲线与收益曲线 | 为什么向右下方倾斜、AR 与 MR 各自长什么样 |
| 短期均衡 | 均衡条件、三种盈亏情况、有没有供给曲线 |
| 长期均衡 | 能不能长期拿超额利润、均衡条件是什么 |
| 价格歧视 | 一级、二级、三级的区别，消费者剩余归谁 |
| 自然垄断与政府管制 | 概念层面，理解为主 |

### 垄断市场凭什么成立

> **定义**：完全垄断市场，是指整个行业当中只有唯一一个厂商的市场组织。

一个行业里只有一家在生产、在销售，这就是垄断。这样的市场要成立，得同时满足三个条件：

1. 市场上只有唯一的一个厂商生产和销售产品；
2. 这个厂商生产的产品没有任何相近的替代品；
3. 其他任何厂商进入这个行业都极为困难，或者说根本不可能。

三条缺一不可。第二条管的是「消费者有没有退路」，第三条管的是「潜在的对手能不能进来」——把退路和对手同时掐死，唯一的那家厂商才真正坐稳了位置。

> **结论**：正因为具备这三个条件，垄断厂商才能够控制和操纵市场价格，从而实现自己的利润最大化。

### 需求曲线为什么向右下方倾斜

先回忆完全竞争。完全竞争市场上，单个厂商面对的需求曲线是一条**水平线**：它永远按一个既定的价格销售商品，卖多卖少都是这个价。原因在于完全竞争市场里每个厂商生产的产品都是同质的——你家的和别人家的没有区别，你一涨价，买家立刻走光，所以你只能接受价格。

垄断厂商不是这样。它的需求曲线**向右下方倾斜**：销售量和市场价格呈反方向变动，想多卖一点，就得把价格降下来。

为什么？还是那三个条件在起作用。整个行业只有它一家，产品又找不到替代品，于是它手里握着价格决定权；只要厂商拥有价格决定权，它的需求曲线就不可能是水平的，只能是向右下方倾斜的。

由此可以提炼出一个很省事的判据：

> **提示**：判断需求曲线是水平还是向右下方倾斜，只看一件事——厂商有没有价格决定权。而价格决定权又从产品上看：产品同质、谁都能替代，就没有定价权；产品基本找不到替代品，就有定价权。

既然垄断厂商这么牛，价格决定权这么大，那它是不是可以随意定价，把价格定得非常高？

当然不可能。道理很朴素：不管完全垄断厂商、完全竞争厂商还是垄断竞争厂商，卖东西都是为了获利。价格定到天上，消费者买不起，销售量就是零，利润自然也是零——把价格定那么高，一点意义都没有。

所以垄断厂商的真实选择是：价格一定比完全竞争市场高很多，但一定落在消费者买得起的范围之内。最终那个价格落在哪，要看需求曲线。

> **易错点**：有价格决定权，不等于有「随意定价权」。垄断厂商能挑的是需求曲线上的哪一个点，不能跳到需求曲线之外另立规矩。

### 收益曲线：平均收益就是那条需求曲线

收益有三个：总收益 TR、边际收益 MR、平均收益 AR。先看平均收益。

$$AR = \frac{TR}{Q} = \frac{P \cdot Q}{Q} = P$$

算出来就是 P。而这里的 P 不是某个固定的数，它反映的是 P 和 Q 之间的关系——垄断厂商的定价受消费者需求影响，它的需求曲线又向右下方倾斜，所以这个 P 代表的是一条线，一条反映 P 与 Q 关系的线。需求曲线反映的恰恰也是 P 与 Q 的关系，两者说的是同一件事。

> **结论**：完全垄断厂商的平均收益曲线 AR 与它的需求曲线重合。

### 边际收益：斜率是需求曲线的两倍

边际收益是总收益对产量的导数。把需求曲线写成

$$P = a - bQ$$

（a、b 为正，Q 前面取负号，表示 P 与 Q 反向变动。）那么总收益

$$TR = P \cdot Q = (a - bQ)Q = aQ - bQ^2$$

边际收益

$$MR = \frac{dTR}{dQ} = a - 2bQ$$

两条线摆在一起，差别就很清楚了：

| 曲线 | 表达式 | 纵轴截距 | 斜率 | 与横轴的交点 |
| :--- | :--- | :---: | :---: | :---: |
| 需求曲线 D | $P = a - bQ$ | $a$ | $-b$ | $a/b$ |
| 边际收益 MR | $P = a - 2bQ$ | $a$ | $-2b$ | $a/(2b)$ |

同一起点（纵轴截距都是 $a$），MR 的斜率刚好是需求曲线斜率的两倍；与横轴的交点，需求曲线在 $a/b$ 处，MR 在 $a/(2b)$ 处——正好是前者的一半。

这个「一半」还带出一个几何结论：把 MR 与横轴的交点往上延伸，这条竖线正好穿过需求曲线的中点。换句话说，走到 $Q = a/(2b)$ 这个位置时，D 还挂着 $a/2$ 的高度（这就是中点 E，此处 $E_d = 1$），MR 却已经降到零；两条线从同一个纵轴截距出发、MR 的斜率又是 D 的两倍，所以 MR 全程走在 D 的下方。

### 需求弹性：中点恰好等于一

接下来要用到一个结论：D 的中点，恰好是需求弹性等于 1 的位置；中点以上（价格更高的一段）弹性大于 1，中点以下弹性小于 1。

这个结论本该在讲弹性的时候就吃透，这里再倒一遍。

需求弹性的公式是

$$E_d = \frac{dQ}{dP} \cdot \frac{P}{Q}$$

在这条直线需求曲线上，每一点的 $dQ/dP$ 都相同——直线斜率固定，斜率的倒数自然也就固定。

取线上任意一点 F 来算。设 F 到横轴的垂足为 M（$OM$ 就是产量 $Q$，$FM$ 就是价格 $P$），需求曲线与横轴的交点为 B，与纵轴的交点为 C。于是：

- $dQ/dP$ 是斜率的倒数，等于 $MB/FM$；
- $P/Q$ 等于 $FM/OM$。

两式相乘，$FM$ 正好约掉：

$$E_d(F) = \frac{MB}{FM} \cdot \frac{FM}{OM} = \frac{MB}{OM}$$

再由相似三角形，$\dfrac{MB}{OM} = \dfrac{FB}{CF}$。

> **结论**：直线需求曲线上任何一点的需求弹性，等于「这一点以下的那一段 ÷ 这一点以上的那一段」。F 点是 $FB/CF$；换一个更靠下的点，就是下面那段比上面那段。

三个位置由此一目了然：

- 中点：上下两段等长，比值恰好为 1；
- 中点以上：下方那段长、上方那段短，分子大于分母，弹性大于 1；
- 中点以下：下方那段短、上方那段长，分子小于分母，弹性小于 1。

> **提示**：中点不是一个「弹性最大」的点，它是分界线。越往左上弹性越大，越往右下弹性越小，中点是 1 所在的刻度。

### 总收益曲线：跟着边际收益走

TR 的图像主要根据 MR 来画，因为 MR 是 TR 的导数：

- MR 大于零：导数大于零，TR 上升；
- MR 等于零：TR 到达最大值；
- MR 小于零：TR 下降。

把弹性接进来，就得到一组很实用的对应关系：

| 需求弹性 | 边际收益 | 总收益 | 产品属性 |
| :---: | :---: | :---: | :--- |
| $E_d > 1$ | $MR > 0$ | 上升 | 富有弹性 |
| $E_d = 1$ | $MR = 0$ | 达到最大 | 单位弹性 |
| $E_d < 1$ | $MR < 0$ | 下降 | 缺乏弹性 |

为什么富有弹性的产品总收益是增加的？富有弹性意味着价格变动一点点，需求量就会改变很大——需求量的变动幅度压过了价格的变动幅度，降一点价，多卖出去的量把降价让掉的钱补回来还有余，总收益当然上升。

缺乏弹性正好相反：价格变动很大，需求量还是挪不动多少，价格的降幅盖过了销量的增幅，总收益就往下走。

```text
TR
^
|              *
|            *   *
|          *       *
|        *           *
|      *               *
|    *                   *
|  *                       *
|*                           *
+-------------+---------------+-----> Q
O            Qm
             ↑ MR = 0，Ed = 1，TR 达到最大
```

曲线的顶点正好落在 $Q_m$ 上：再往左，MR 为正，曲线还在往上走；越过这一点，MR 转负，曲线开始往下掉。

### 短期均衡：先定产量，再定价格

垄断厂商短期均衡的条件是

$$MR = MC$$

理由和完全竞争市场一样：厂商追求利润最大化，而利润最大化的条件就是边际收益等于边际成本。这个推导在讲完全竞争市场时已经做过一遍，不必重来。

> **提示**：以后一看见「最大化」，第一反应就该是边际收益等于边际成本。

条件只有一个，结果却有三种：盈利、亏损、不盈不亏。判断的步骤，我习惯说成「先别管三七二十一」——

1. **定产量**：找到 MR 与 MC 的交点，交点对应的产量就是 $Q^*$；
2. **定价格**：从 $Q^*$ 垂直往上，与需求曲线 D 相交，交点对应的价格就是 $P^*$；
3. **比高低**：比较 $P^*$ 与 $Q^*$ 处的短期平均成本 SAC。

第二步为什么非要回到需求曲线上去读价格？因为垄断厂商再牛也不能随便定价，它得参照消费者的接受能力，而消费者的接受能力就是这条需求曲线。产量定下来之后，价格只能在这条曲线上读——读到的那一点，正是消费者愿意支付的最高价格。

第三步的比较规则就三条：

| 价格与短期平均成本 | 结论 |
| :---: | :--- |
| $P^* > SAC$ | 盈利 |
| $P^* = SAC$ | 不盈不亏 |
| $P^* < SAC$ | 亏损 |

盈利的金额是 $(P^* - SAC) \times Q^*$：高是价格与平均成本之差，宽是产量，画出来就是一块矩形。

```text
第一步：MR 与 MC 的交点            → 定出产量 Q*
第二步：Q* 垂直上伸，交 D          → 定出价格 P*
第三步：在 Q* 处比较 P* 与 SAC
        P* > SAC  →  盈利
        P* = SAC  →  不盈不亏
        P* < SAC  →  亏损
```

> **易错点**：这里比的不是 MR 和 SAC，是 $P^*$ 和 SAC。价格要从需求曲线上读，不能拿着交点处的 MR 去跟成本比。

三种情况的定位动作一模一样，唯一的区别是 SAC 的高度：它落在 $P^*$ 下面就是赚，正好压在 $P^*$ 上就是白干，顶在 $P^*$ 上面就是亏。

### 垄断厂商没有供给曲线

结论先摆出来：完全垄断厂商的供给曲线**不存在**。这句话好记，但「为什么不存在」很可能考一道简答题，得能自己从头讲一遍。

先明确供给曲线是什么：它反映的是价格和供给量之间的关系，而且是**一一对应**的关系——一个价格对应一个供给量，一个供给量对应一个价格。所以要判断垄断厂商有没有供给曲线，只看一件事：它的价格和供给量之间有没有这种一一对应。

拿两组情形试一试。

第一组：需求曲线 $D_1$，对应边际收益 $MR_1$。让 $MR_1 = MC$，得到供给量 $Q_1$；把 $Q_1$ 上伸到 $D_1$，读出价格 $P_1$。于是「产量为 $Q_1$ 时，价格为 $P_1$」。

第二组：换一条需求曲线 $D_2$，对应另一条边际收益 $MR_2$。同样让 $MR_2 = MC$——成本曲线没动，交点仍然落在 $Q_1$ 上，产量还是那个产量。

可是价格变了：从 $Q_1$ 上伸到 $D_2$，读出来的是 $P_2$，跟 $P_1$ 不是同一个数。

```text
            ┌── D1 ──→ 读出 P1
Q1 ─────────┤
            └── D2 ──→ 读出 P2
```

同一个 $Q_1$，既对着 $P_1$，又对着 $P_2$。一一对应被打破了：可能一个 Q 对着两个 P，也可能一个 P 对着两个 Q。

> **结论**：完全垄断厂商的价格与供给量之间不存在一一对应关系，所以它没有供给曲线。

> **提示**：这道题绕不开这几步——先说供给曲线要求一一对应，再构造两组 MR 与 D，用同一个产量读出两个价格，最后点明对应关系不成立。答全了，简答题的分就稳了。

### 长期均衡：超额利润赖着不走

长期均衡只要想清楚一件事，剩下的都好办：完全垄断厂商在长期能不能获得超额利润？

先回顾完全竞争的长期。完全竞争厂商在长期只能获得**正常利润**，拿不到超额利润。为什么？因为长期里厂商可以自由进入、自由退出。

- 行业里利润很高，外面的人就眼红，大量厂商涌进来，供给大于需求，价格被压下去，利润水平跟着降——降到只够正常利润，就没有新厂商愿意再进来了；
- 行业里亏得厉害，原有厂商就退出一批，供给小于需求，价格被抬上去——抬到刚好只获得正常利润，就没有厂商再愿意退出了。

两头都朝「正常利润」这个位置收敛，所以完全竞争长期均衡时超额利润为零。

垄断厂商不一样。行业里只有它一家，别的厂商进不来；它自己也没有退出的压力。这种绝对的垄断地位，让它可以把超额利润长期揣在兜里。

> **结论**：完全垄断厂商在长期均衡时能够获得超额利润。

具体能拿多少？这个没法确定——长期里它可以调整生产规模，成本会变，需求也可能变，所以数额是不确定的。能确定的只有均衡条件：

$$MR = LMC = SMC$$

也就是说，长期看，边际收益既等于长期边际成本，也等于短期边际成本。

> **易错点**：别把「长期能拿超额利润」记成「长期利润一定更大」。长期均衡锁定的只是 $MR = LMC = SMC$ 这个条件，利润的绝对水平是没法算出来的。

### 价格歧视：同一件产品，卖不同的价

> **定义**：价格歧视，是指在完全垄断市场上，一个卖者面对无数个买者，以不同的价格销售同一件产品。

说白了就是看人下菜碟：同一件产品，卖给不同的人，收不同的价。完全垄断厂商有足够强的垄断势力，才有能力这么干，而这么干的目的仍然是利润最大化。

#### 一级价格歧视：把每一分消费者剩余都拿走

一级价格歧视又叫**完全价格歧视**：厂商对每一单位产品，都按照消费者所愿意支付的最高价格出售。

意思是厂商能猜到每个消费者最高愿意出多少钱，然后把价格顶到那个数上。一个杯子消费者最多接受十块，厂商就报十块，消费者也真的按十块买走——消费者原本「便宜点我就赚了」的那部分好处，一分不剩地变成了厂商的超额利润。

> **结论**：一级价格歧视下，全部消费者剩余都转化为垄断利润。

这当然是完全理想化的情况，现实当中几乎不可能实现——卖者没有那么神通广大，不可能把每个消费者心里那个数都摸清楚。

用图像理解：$MR = MC$ 定出产量，往上伸到需求曲线读出价格 P，这个 P 就是消费者能接受的最高价格。厂商按这个价格卖，等于在按每个消费者的最高支付意愿卖。而且一级价格歧视要求厂商对**每一单位**产品都这样定价，不是只对第一件这么干。

#### 二级价格歧视：按购买量分段定价

二级价格歧视，是厂商把需求曲线分成不同的几段，根据不同的购买量确定不同的价格。

因为分了段，就不可能把全部消费者剩余都拿走，只有一部分能转成超额利润。

看分段就明白：把需求曲线分成 ab、bc、cd 几段，ab 这一整段统一按某个价格卖。这样一来，段内只有最下面那一点刚好落在消费者愿意支付的最高价格上；段内更靠上的买家本来愿意出更高的价，实际却只按这个统一价付了钱——差价留在了他们自己手里。

再往下的每一段都是同样的道理。所以二级价格歧视只能获得一部分消费者剩余。

#### 三级价格歧视：把人分成几群，分别定价

三级价格歧视，是垄断厂商对同一种产品，在不同市场上、对不同消费群收取不同的价格。

这里要记牢一点：三级价格歧视仍然是「对不同的人收不同的价」，只是不像一级那样细分到每一个人。它把消费者粗粗分成几群——学生一个价（学生票），成人一个价（成人票），团体一个价（团体票），但不会去判断张三比李四能多掏多少钱。

画法是这样：同一种产品，MC 只有一条，而两个市场各有一条需求和一条边际收益。

```text
                 ┌── 市场一：MR1 = MC → Q1 → 在 D1 上读出 P1
同一条 MC ───────┤
                 └── 市场二：MR2 = MC → Q2 → 在 D2 上读出 P2
```

每个市场各自按 $MR = MC$ 定产量，再回到自己的需求曲线上读价格，于是同一件产品在两个市场卖出两个不同的价。

#### 三种歧视怎么区分

把三种摆在一起，区别就两条线：按「人」分还是按「量」分；按人分的话，分得细不细。

| 类型 | 定价依据 | 消费者剩余的归属 | 现实性 |
| :--- | :--- | :--- | :--- |
| 一级 | 每个消费者的最高支付意愿 | 全部转为垄断利润 | 理想化，几乎不可能 |
| 二级 | 购买量分段 | 一部分转为垄断利润 | 可实现 |
| 三级 | 消费者群体 | 一部分转为垄断利润 | 可实现（学生票、团体票） |

> **提示**：一级和三级都是看人下菜碟，差别只在粗细——一级细分到每一个人，三级只把人分成几等；二级根本不看人，它看的是买多少。三种里面，只有一级能把全部消费者剩余吃干净。

### 定价法则：为什么价格一定高于边际成本

最后一个公式，重点不是记住它，而是推得出来。

出发点还是利润最大化：

$$MR = MC$$

把 MR 展开。总收益是价格乘产量，对产量求导要按乘积法则来：

$$MR = \frac{dR}{dQ} = \frac{d(PQ)}{dQ} = P + Q \cdot \frac{dP}{dQ}$$

第二项里的 $\dfrac{dP}{dQ}$ 看着眼熟——需求弹性 $\dfrac{dQ}{dP} \cdot \dfrac{P}{Q}$ 里，正好有它的倒数。把弹性取倒数：

$$\frac{1}{E_d} = \frac{dP}{dQ} \cdot \frac{Q}{P}$$

两边同乘 P：

$$\frac{P}{E_d} = Q \cdot \frac{dP}{dQ}$$

代回 MR 的展开式：

$$MR = P + \frac{P}{E_d} = P\left(1 + \frac{1}{E_d}\right)$$

再令它等于边际成本：

$$MC = P\left(1 + \frac{1}{E_d}\right) \quad\Longrightarrow\quad P = \frac{MC}{1 + \dfrac{1}{E_d}}$$

因为 $1/E_d$ 往往是负值，所以 $1 + 1/E_d$ 是一个小于 1 的数；MC 除以一个小于 1 的数，结果必然大于 MC 本身。

> **结论**：$P > MC$。定价高于边际成本，这正是完全垄断厂商能够获得超额利润的原因。

顺带还能自查一件事：既然均衡处 $MR = MC > 0$，而前面已经证明 MR 大于零对应需求富有弹性，那么垄断厂商的均衡点一定落在需求曲线中点以左的那一段上——它不会跑到缺乏弹性的区域去生产。两条结论在这里正好接上。

最后一块是自然垄断和政府管制。这两块理解起来不难，自己把书翻一遍就够了，这里不再赘述。

### 本讲提到的题目

**题目**：完全垄断厂商的供给曲线为什么不存在？

**解析**：供给曲线要求价格与供给量之间是一一对应的关系，一个价格对一个供给量，一个供给量对一个价格。取两组情形来检验：第一组由 $D_1$ 与 $MR_1$ 出发，令 $MR_1 = MC$ 得到产量 $Q_1$，上伸到 $D_1$ 读出价格 $P_1$；第二组换成 $D_2$ 与 $MR_2$，令 $MR_2 = MC$，成本曲线没动，交点产量仍是 $Q_1$，但上伸到 $D_2$ 读出的价格变成了 $P_2$。同一个产量对应两个不同的价格，一一对应不成立。

**答案**：完全垄断厂商的价格与供给量之间不存在一一对应关系，因此不存在供给曲线。

## 垄断竞争、三个市场的总账与寡头模型
> 对应块：BLK07 | 覆盖分集：P12-P13 | 块标题（分集名）：《垄断竞争市场+前三个市场的总结》

一个厂商想降价。理由朴素得不能再朴素：价格低一点，总能多卖一点，多多少少能多赚一些。

他脑子里有一条曲线，告诉他价格从 p0 降到 p1 之后销量会一路涨到 q3。市场上真实发生的却是另一条曲线，给出的答案是另一个数——比 q3 小得多。垄断竞争市场之所以在四个市场里最特殊，就特殊在这里：同一个厂商手里握着两条需求曲线，一条是他以为的，一条是实际发生的。

这两条曲线怎么来的、差在哪，是这一讲要讲的第一件事。讲完垄断竞争，第二件事是把完全竞争、完全垄断、垄断竞争这三个市场摆到一张桌子上对账——它们的讲法完全一样，都是"定义和条件 → 需求曲线 → 短期均衡和长期均衡 → 供给曲线"，不并起来看，非常容易记混。第三件事是寡头市场，讲法跟前三个完全不同：只有两个模型，一个考计算，一个考图形。

### 垄断竞争：介于两者之间

#### 含义：既垄断，又竞争

垄断竞争这个词本身就是它的定义：既有垄断，又有竞争，是垄断和竞争相结合的一种市场结构类型。

说得具体一点，是许多厂商销售相类似、但又不完全相同的商品的市场。这一句里有两个关键词——"许多厂商"和"相类似但不完全相同"。后面所有的结论，都是从这两个词里长出来的。

#### 三条特征，条条卡在中间

书上写的特征比三条更多，我把它凝练成三条。这三条的讲法是同一个套路：拿完全竞争比一次，拿完全垄断比一次，垄断竞争就卡在中间。

第一，市场上存在许多买者和卖者，而且这些厂商大多是中小企业，所以它能施加给市场的影响是有限的。完全竞争厂商对市场的影响是零，完全没有影响力；完全垄断厂商对市场的影响是百分之百，拥有完全的垄断权力。垄断竞争夹在两者之间，影响力是"有限的"。

第二，各厂商生产的产品存在着差别。完全竞争市场上产品完全同质，一模一样；完全垄断市场上只有一家厂商，产品谈不上差别，也谈不上替代。垄断竞争的产品是"相类似但不完全相同"——有差别，所以彼此不能完全替代；相类似，所以彼此又是竞争对手。

第三，厂商进入或退出行业比较容易。完全竞争可以随意进出；完全垄断只有一家厂商，别的厂商既进不来，它也退不出去。垄断竞争是"比较容易"——注意是"比较"，不是"随意"。

| 特征 | 完全竞争 | 垄断竞争 | 完全垄断 |
| :--- | :--- | :--- | :--- |
| 厂商对市场的影响 | 零 | 有限 | 百分之百 |
| 产品 | 完全同质 | 有差别 | 只此一家，无差别可言 |
| 进出行业 | 随意 | 比较容易 | 不能进也不能出 |

> **提示**："比较容易"这四个字是有分量的。它在长期均衡那一节会直接决定结论——只要能自由进出，长期就只能拿到正常利润。所以别把"比较容易"读成"很难"。

### 两条需求曲线：他以为的，和实际发生的

#### 小 d 与大 D

教科书给这两条曲线下的定义长得很像，差别只在最后半句。

小 d 说的是：在垄断竞争生产集团当中，某个厂商改变产品价格，而其他厂商的产品价格都保持不变的时候，这个厂商的产品价格和销售量之间的关系。

大 D 说的是：某个厂商改变产品价格的时候，其他厂商也使价格发生改变，这时候产品的价格和销售量之间的关系。

一句话的差别：别人跟不跟着动。

哪一种更符合现实？一个厂商改了价，同行会无动于衷吗？当然不会。所以大 D 更符合实际，它叫实际需求曲线，也叫客观需求曲线。

小 d 描述的是"其他厂商对这次调价毫无反应"的情形——这只能是厂商自己脑子里的想象。所以小 d 叫主观需求曲线。

> **定义**：小 d 是主观需求曲线，假定只有自己一家调价；大 D 是实际（客观）需求曲线，假定同行会跟着调价。两条曲线都经过同一个均衡点，斜率不同。

#### 降价：他以为能卖到 q3，实际只到 q1

设原来的均衡价格是 p0、均衡产量是 q0，两条曲线在这一点相交，记作 A 点。

现在这个厂商想降价，把价格从 p0 降到 p1。他降价的动机很朴素：便宜一点总能多卖一点，多卖一点总能多赚一点。

如果他自以为是——觉得自己降了价，别的厂商很傻、发现不了，不会跟着降——那么整个市场只有他一家便宜。消费者一看，这家卖得比别家都便宜，自然全涌到他店里来。他的销量会从 q0 一路涨到 q3。q3 落在小 d 上。

但同行不是傻子。看到他降价，别人也会把自己的价格往下调一些。消费者就不会都挤到他一家，会分散到其他也降了价的店里去。所以降价带来的销量增长到不了 q3，只到 q1。q1 落在大 D 上。

同一笔降价，主观预期给的答案是 q3，实际给的答案是 q1。

#### 涨价：他以为会掉到 q2，实际只掉到 q4

反过来，价格从 p0 提到 p2。

他以为别人不会跟，全市场的顾客都不来了，销量会从 q0 掉到 q2。

可他为什么要涨价？没有谁愿意无缘无故涨价——涨价必然掉销量。他涨价的理由，要么是成本上去了，要么是政策压着，总之是被迫的。既然是成本或政策逼的，那别的厂商也在同一个市场里采购原料、雇同样的劳动力，凭什么只有他一家成本上升？别人有同样的苦衷，也会跟着涨。

所以全市场不止他一家涨价，他的销量掉不到 q2，只掉到 q4。

> **结论**：降价的时候，现实没有他想的那么好；涨价的时候，现实也没有他想的那么糟。主观需求曲线在两头都比实际需求曲线更"夸张"。

#### 把两次变动合起来看

```text
    P
    |   (d)               (D)
    | \                 \
    |     \              \
 P2 |         \           \
    |             \        \
    |                 \     \
    |                     \  \
 P0 |                         A
    |                          \  \
    |                           \     \
    |                            \        \
 P1 |                             \           \
    |                              \              \
    |                               \
   +------------------------------------------------- Q
            q2            q4  q0  q1            q3
```

平缓的那条 `(d)` 是主观需求曲线，陡的那条 `(D)` 是实际需求曲线，两线交于 A 点，A 对应的价格是 p0、产量是 q0。价格上移到 p2，小 d 只给出 q2 这么小的量，大 D 给的是 q4；价格下移到 p1，小 d 给出很大的 q3，大 D 只给出 q1。

把四个点排一排：

$$q_2 < q_4 < q_0 < q_1 < q_3$$

同一个价格变动，小 d 给出的产量变动幅度永远比大 D 大，所以小 d 更平坦。换成弹性的话说，小 d 的需求弹性更大。这一点在讲寡头那个弯折的需求曲线时还要再用一次。

A 点本身也有讲究。两条曲线在这里相交，说明在均衡点上，厂商的主观预期和市场的客观结果恰好一致——他以为降价会怎样，实际就怎样，但只在这一个价格上成立。价格一偏离 p0，"他以为"和"实际上"立刻分叉：降价时他乐观过头，涨价时他悲观过头。

### 短期均衡：先定产量，再定价格

定均衡产量还是老规矩：边际收益等于边际成本。

$$MR = MC$$

定价格就不一样了。价格不能由边际成本说了算，得看消费者愿意出多少——所以要回到需求曲线：把 q 往上延伸，与需求曲线相交，交点对应的价格就是 p。

垄断竞争在这里有个特殊之处：手里有两条需求曲线，所以 q 必须往上延伸到两条曲线的交点处，才能定出 p。原因也简单——只有在这个交点上，厂商的主观预期和市场的实际结果是同一个点，这个价格才有意义。

p 定出来之后，判断盈亏只剩一件事：拿 p 和短期平均成本 SAC 比。

- p 高于 SAC：卖一份赚一份，盈利；
- p 等于 SAC：不盈不亏；
- p 低于 SAC：成本比售价还高，亏损。

三种情况对应同一张图里三条不同位置的 SAC 曲线，除此之外没有区别。垄断竞争的短期均衡判断到 p 与 SAC 这一步就结束了，比完全竞争少一道 AVC 的手续。

### 长期均衡：只能拿正常利润

在动手画长期均衡之前，得先回答一个问题：长期里，这个厂商能拿到正常利润，还是超额利润？

这两个答案对应的画法完全不同。如果只能拿正常利润，价格就必须等于长期平均成本；如果能拿超额利润，价格就落在 LAC 之上。

垄断竞争的答案是：只能拿正常利润。

理由不在成本，在厂商数量。垄断竞争市场在长期里，厂商的数量是可以改变的——厂商能自由进出。它的进出自由度没有完全竞争那么大，没到"随意"的程度，但长期内终归可以自由进出。只要可以自由进出，结论就定死了。

看它是怎么定死的：

- 行业很赚钱的时候，行业之外的厂商眼红，大量涌入。供给大于需求，价格被压下来。压到什么时候为止？压到只够拿正常利润为止。
- 行业很亏损的时候，行业里原有的厂商大量往外走。供给减少，供给小于需求，价格被抬上去。抬到什么程度？抬到厂商不再往外走、行业回到正常利润水平为止。

所以均衡的标志不是"价格等于某个数"，而是"厂商不再进、也不再出"。而厂商停止流动的那个点，恰好就是只能拿正常利润的点。

均衡的画法因此也定下来了：MR = MC 定出 q；q 往上延伸，交于两条需求曲线的交点 n，读出 p0；然后让 LAC 在产量 q0 处的值恰好等于 p0。这样画出来，p 与 LAC 相等，不盈不亏，正好是正常利润。

> **结论**：判断任何一个市场的长期均衡，只需要问一句——长期能不能自由进出。能，就只能拿正常利润，画法是"定出 p 之后让 p 与 LAC 相等"；不能，就能拿超额利润，p 落在 LAC 之上。进出的自由度有多大并不重要：完全竞争是百分之百自由，垄断竞争没那么自由，但只要能进出，结论就是同一个。

这一段是后面那笔总账的钥匙。三个市场的长期均衡图，其实都是这一句话的三种画法。

### 三个市场的总账

#### 为什么要合起来算这笔账

市场一共四个。前三个——完全竞争、完全垄断、垄断竞争——讲法是同一条流水线：

定义 → 条件 → 需求曲线 → 短期均衡 → 长期均衡 → 有没有供给曲线。

第四个市场不走这条线，它讲的是几个模型加几道计算题，跟前面三个没什么可比性。所以这笔账只算前三个。

为什么要算？因为它们相似程度太高。三个市场都要回答同样四个问题：需求曲线长什么样、短期均衡怎么定、长期均衡怎么画、有没有供给曲线。不摆到一起，非常容易记混，而且乱糟糟的；摆到一起，脉络才出来。

#### 需求曲线怎么画

**完全竞争**：一条水平线。因为它没有价格决定权，只能按一个既定的价格卖，所有厂商都按这个价格卖。这里还有一个必须记住的点——四线合一：价格线、需求曲线、边际收益曲线、平均收益曲线，是同一条水平线。

**完全垄断**：一条向右下方倾斜的线。最需要记的是两个数量关系：MR 曲线的斜率，刚好是需求曲线（也就是平均收益曲线）斜率的二倍；MR 曲线与横轴的交点，刚好落在需求曲线与横轴交点的二分之一处。

**垄断竞争**：两条。大 D 是实际（客观）需求曲线，小 d 是主观需求曲线。除此之外，垄断竞争的需求曲线和完全垄断的是一回事，只不过它有两条。

| 市场 | 需求曲线 | 必须记住的点 |
| :--- | :--- | :--- |
| 完全竞争 | 一条水平线 | 没有价格决定权；价格线、需求曲线、MR、AR 四线合一 |
| 完全垄断 | 一条向右下方倾斜的线 | MR 斜率是需求曲线（即 AR）斜率的二倍；MR 与横轴交点是需求曲线与横轴交点的 1/2 |
| 垄断竞争 | 两条，一平一陡 | 大 D 实际、小 d 主观；除条数之外与完全垄断一致 |

#### 短期均衡的三步走

三个市场的短期均衡，用的是同一套三步：

```text
第一步   MR = MC                              ──►  定出均衡产量 q
第二步   q 向上延伸，与需求曲线相交            ──►  读出均衡价格 p
         （完全竞争跳过这一步：四线合一，MR 本身就是 p）
第三步   p 与 AC 比较
         p > AC   ──►  盈利
         p = AC   ──►  不盈不亏
         p < AC   ──►  亏损
         （完全竞争再加一步：亏损时比较 p 与 AVC，判断是否停产）
```

第二步是三个市场唯一不一样的地方。完全垄断和垄断竞争都得老老实实往上延伸找交点，因为它们的 MR 和 p 是两条线。完全竞争不用找——它的 MR 曲线本身就是一条水平的价格线，四线合一，找到 MR 就等于找到 p，这一步直接省掉。

第三步判断盈亏，三个市场完全一样。但完全竞争还要多一道手续：亏损的时候再比较 p 和 AVC，判断要不要停产。

- p 大于 AVC：亏损，但继续生产；
- p 等于 AVC：停产与不停产正好卡在临界点上，两种选择都成立；
- p 小于 AVC：必须停产。

这个临界点把"亏损还干活"和"亏损就关门"两件事分开了，所以完全竞争才要分五种情况：

| 情形 | p 与 SAC | p 与 AVC | 结论 |
| :--- | :--- | :--- | :--- |
| 一 | p > SAC | — | 盈利 |
| 二 | p = SAC | — | 不盈不亏 |
| 三 | p < SAC | p > AVC | 亏损，继续生产 |
| 四 | p < SAC | p = AVC | 停产与不停产的临界点 |
| 五 | p < SAC | p < AVC | 必须停产 |

完全垄断和垄断竞争只有三种情况：盈利、不盈不亏、亏损。因为它们判断完 p 和 SAC 就结束了，不需要再过 AVC 这一道。

#### 长期均衡只问一句：能不能自由进出

长期均衡的判断只有一条：长期能不能自由进出。

- 能自由进出 → 只能拿正常利润 → p 必须等于 LAC；
- 不能自由进出 → 能拿超额利润 → p 落在 LAC 之上。

完全竞争和垄断竞争都能自由进出，所以这两个市场的长期均衡都要求 p 与 LAC 相等。完全垄断不能自由进出，所以它的 p 落在 LAC 之上。

完全竞争还能再往下推一步。均衡点是 MR = MC 定出的 q 和 p，而 p 又必须等于 LAC；同时，长期边际成本 LMC 一定穿过 LAC 的最低点，短期边际成本 SMC 一定穿过 SAC 的最低点。三个条件叠在一起：

$$p = LAC = LMC = SAC = SMC$$

五个量在均衡点上全部相等。这是完全竞争长期均衡的标志，也是它区别于另外两个市场的地方。

| 市场 | 长期能否自由进出 | 利润 | 均衡时的关键等式 |
| :--- | :--- | :--- | :--- |
| 完全竞争 | 能，且完全自由 | 只能正常利润 | p = LAC = LMC = SAC = SMC |
| 完全垄断 | 不能 | 超额利润 | p > LAC |
| 垄断竞争 | 能，自由度不及完全竞争 | 只能正常利润 | p = LAC |

#### 供给曲线：谁有，谁没有

供给曲线的定义里，要害是"一一对应"——它反映的是价格与供给量之间一一对应的关系。少了这四个字，供给曲线就不成立。

完全垄断和垄断竞争都没有供给曲线，理由一模一样：p 和 q 不是一一对应的。价格和产量配不成一对一，就画不出一条"给一个价格、回一个产量"的曲线。

完全竞争的供给曲线分两层记：

短期记厂商的供给曲线，是 AVC 以上的 SMC 那一段。为什么是"AVC 以上"这一段，跟前面停产那三种情况是同一件事——低于 AVC 的产量它根本不会供给。

长期记行业的供给曲线，只有三种情况：成本递增，行业长期供给曲线向右上方倾斜；成本不变，是水平的；成本递减，向右下方倾斜。

| 市场与期限 | 有无供给曲线 | 具体形态 |
| :--- | :--- | :--- |
| 完全竞争·短期 | 有，记厂商的 | AVC 以上的 SMC 段 |
| 完全竞争·长期 | 有，记行业的 | 成本递增→右上倾斜；成本不变→水平；成本递减→右下倾斜 |
| 完全垄断 | 无 | p 与 q 不一一对应 |
| 垄断竞争 | 无 | 同上，理由完全相同 |

三个市场的账到这里算完。需求曲线看几条、短期均衡走几步、长期均衡的 p 落在 LAC 的哪一侧、有没有供给曲线——四个问题答得出来，这一章就不会再乱。

### 寡头：换一套讲法

前三个市场是一路走下来的：定义、性质、条件，然后是需求曲线，然后是短期均衡和长期均衡，最后是供给曲线。寡头不这么走。

寡头市场的定义是：少数几家厂商控制整个市场。完全垄断是一家厂商控制整个市场，寡头是少数几家共同控制。所以它既有竞争市场的特点，又有垄断市场的特点，但更接近完全垄断。这几家厂商的产量在行业里占的份额很大，市场上每一家都举足轻重——一家动一动，整个市场的价格都要跟着变。

它的考点很单一。作为题出现，要么让你解释某个模型，要么作为计算题出现。所以这一章就按这两件事准备：讲几个模型，做几道计算题，就算过去了。

书上的模型大概四到五个，不同书写得不一样，有的写四个，有的写五个。这里只讲两个：古诺模型，和弯折的需求曲线，也叫斯威齐模型。

为什么是这两个？古诺最重要、也最有代表性——出计算题基本就是它，而且把古诺的计算题彻底搞清楚，别的模型思路差不多，换汤不换药。弯折的需求曲线则是因为图像特殊：它的需求曲线是折的，这张图必须自己会画。

顺带说一句分量：四个市场里前三个是重头戏，寡头这一块出题的概率远不及前三个。概率低不等于可以不看，两个模型的图都得动手画一遍。

### 古诺模型：把对手的产量当成已知

#### 四个假设

第一，只有两家企业，而且生产完全相同的产品。

第二，企业的生产成本为零，因而边际成本也为零。这一条要留个余地：有的计算题不会让成本等于零，会给一个具体的数值。真碰上了也不用慌，把成本减掉就行，后面写利润函数时一眼就能看出该在哪里减。不过大多数题是按成本为零出的。

第三，每个厂商都认为，不论自己的产量是多少，对手都会保持产量不变。换个说法：每个厂商都是根据对方的产量来决定自己的产量的。

这一条用个例子理解最省事。假设整个市场一共能消化一百件产品。我是厂商一，要定自己产多少，肯定先想一下厂商二会产多少：如果我估计它产得多，我就少产一点，产多了卖不出去，压在手里滞销；如果我估计它产得少，我就多产一些。所以每个厂商的产量，都是照着对手的产量调出来的。

第四，企业的决策变量是产量。这一条要特意点出来，因为有的模型里决策变量是价格——决策变量不一样，整个模型就不一样。

#### 价格由两家产量之和决定

已知需求函数，也就是 p 和 q 之间的关系。市场里只有这两家企业，而且同时生产，所以市场价格由两家的产量之和决定：

$$p = f(q_1 + q_2)$$

q1 是第一家的产量，q2 是第二家的产量。价格是产量的函数，产量是两家的合计，所以价格自然就是两家产量之和的函数。

#### 反应函数：从一家算起

只分析企业一就够了。市场上统共两家，一家的产量定了，另一家的产量自然就定下来了。

企业一心里对企业二的产量有个预判。设它估计企业二会生产 q2，那么市场上的总供给就是 q1 + q2，价格就是 f(q1 + q2)。它的总收益是价格乘自己的产量，利润是总收益减成本：

$$\pi_1 = f(q_1 + q_2)\cdot q_1 - C(q_1)$$

利润最大化就是让这个式子对 q1 的偏导数为零，解出 q1。解出来的 q1 里一定还带着 q2——因为 q2 是它给定的前提。这个"给定对手产量时我的最优产量"，就是反应函数：

$$q_1 = R_1(q_2)$$

企业二同理，得到 q2 = R2(q1)。

> **定义**：反应函数（反应曲线）描述的是一个厂商的最优产量如何随对手的产量变化。在古诺模型里，它就是边际收益等于边际成本解出来的那个关系式，只不过对手的产量作为参数留在了式子里，没有被消掉。

古诺均衡就是两条反应曲线的交点：企业一的最优产量由企业二的产量决定，企业二的最优产量由企业一的产量决定，两个"给定对方"同时成立，谁也没有动机单方面改变自己的产量。

#### 一道题走完整个流程

> 某寡头市场只有两家企业，市场需求函数为 p = 30 − Q，其中 Q = q1 + q2；两家企业的生产成本均为零。求：（1）厂商一与厂商二的产量反应曲线；（2）均衡价格、各自的均衡产量与利润。

第一问，求反应曲线。

企业一的利润函数：

$$\pi_1 = p\,q_1 = (30 - q_1 - q_2)q_1 = 30q_1 - q_1^{\,2} - q_2 q_1$$

成本为零，所以利润函数就是总收益，最后那一项 TC 干脆不用写。这里还有一层：两家产品完全同质，所以厂商一和厂商二面对的是同一个 p，只是各自的 q 不同。

对 q1 求偏导，令其为零：

$$\frac{\partial \pi_1}{\partial q_1} = 30 - 2q_1 - q_2 = 0$$

移项解出来：

$$q_1 = 15 - \frac{1}{2}q_2$$

这就已经是反应曲线的形式了——q1 被写成了 q2 的函数。

企业二同理。真到考场上，这一步可以直接写"同理"带过，不必重算。要重算也就是三行：

$$\pi_2 = p\,q_2 = (30 - q_1 - q_2)q_2 = 30q_2 - q_1 q_2 - q_2^{\,2}$$

$$\frac{\partial \pi_2}{\partial q_2} = 30 - q_1 - 2q_2 = 0 \;\Longrightarrow\; q_2 = 15 - \frac{1}{2}q_1$$

第二问，求均衡产量、均衡价格和利润。

把两条反应曲线联立：

$$q_1 = 15 - \frac{1}{2}q_2,\qquad q_2 = 15 - \frac{1}{2}q_1$$

两个式子完全对称，解出来必然是 q1 = q2。代进去：

$$q_1 = 15 - \frac{1}{2}q_1 \;\Longrightarrow\; \frac{3}{2}q_1 = 15 \;\Longrightarrow\; q_1 = 10$$

所以 q1 = q2 = 10，市场总产量 Q = 10 + 10 = 20。

代回需求函数：p = 30 − 20 = 10。

利润把 q1 = q2 = 10 代回前面已经写好的利润函数：

$$\pi_1 = 30\times 10 - 10^2 - 10\times 10 = 300 - 100 - 100 = 100$$

厂商二对称，也是 100。

> **提示**：成本为零时，利润函数就是总收益，求导时不必再减 TC。这一步是题目条件给的便利，不是通例。题目若给了非零成本，只在 π 里多减一项 C(q)，求导、联立、代回三步一动不动——这就是前面说"成本不为零也不要慌，把它减掉就行"的意思。

### 斯威齐模型：价格为什么不肯动

寡头的价格常常是黏的：成本变了，价格不动。弯折的需求曲线模型就是来解释这件事的。

#### 提价没人跟，降价全都跟

这个模型的全部力气，都花在一个不对称的假设上。

厂商提价：行业里其他厂商都不会跟着改价。全市场只有他一家涨价。对同行来说，这等于白白少了一个竞争对手，别人巴不得只有他一个涨价。结果消费者不会选他，他的销量一下子掉很多。价格只上去一点点，销量掉下来一大截——这就是需求弹性很大。

弹性大对应什么斜率？需求弹性和需求曲线的斜率是反向关系：弹性大，斜率小；斜率小，在图上就是平缓。所以均衡价格以上那一段需求曲线是平缓的。

厂商降价：其他厂商一定会紧跟其后，把价格降到同一水平。为什么？因为这个厂商一降价，顾客都跑到他那儿去了；别人要是不动，市场份额就白白流失，为了守住销量不得不跟着降。所以第一个降价的厂商，销量增加得很少——他本来预期降价能多卖不少，结果被同行的跟进抵消掉了。价格降一点，销量只增加一点，需求弹性小。

弹性小对应斜率大，图上是陡。所以均衡价格以下那一段需求曲线是陡的。

上段平缓、下段陡峭，两条线段在均衡价格处接成一个折角——这就是"弯折的需求曲线"的来历。

```text
    P
    |\
    |  \
    |     \
    |       \
    |          \
    |            \
    |               \
 P1 |                 B
    |                  \
    |                  \
    |                   \
    |                    \
    |                    \
    |                     \
   +------------------------------------------------- Q
                    Q1
```

B 是折点，对应均衡价格 p1 和均衡产量 q1，也就是市场上一切风平浪静时的那组价格和产量。B 以上那段平缓，是提价的情形；B 以下那段陡峭，是降价的情形。

> **易错点**：两段的弹性千万别记反。提价没人跟 → 顾客全跑到没涨价的店里 → 销量掉得狠 → 弹性大 → 平缓；降价大家都跟 → 抢来的顾客又被摊薄 → 销量涨得少 → 弹性小 → 陡峭。

#### 断开的边际收益与价格刚性

两段需求曲线，各有一条自己的边际收益曲线。

上半段平缓，对应的 MR 下降得很快；下半段陡峭，对应的 MR 从折点下方很低的位置重新开始。两段 MR 在折点处接不上，中间留下一段垂直的空档。

```text
    P MR1
    |     \
    |       \
    |         \
    |           \
    |             \
    |               \
    |                 |
    |                 |
    |                 |
    |                 |
    |                 \ MR2
    |                     \
    |                        \
    |                            \
   +------------------------------------------------- Q
                    Q1
```

图中那条竖直的线就是断档，它的横坐标正是 q1——折点所对应的产量。

这段垂直空档，就是价格刚性的来源。边际成本曲线只要落在这段垂直范围内，不论它在里面怎么上下移动，与 MR 的交点横坐标都是 q1；从 q1 往上延伸，交到需求曲线上的点还是折点 B，价格还是 p1。

成本涨了一点，价格不动；成本降了一点，价格还是不动。这就是"价格刚性"——在某一段范围之内，价格不会轻易改变。反过来，一旦边际成本移出这段垂直范围，这个结论也就不再成立了。

### 本讲提到的题目

> **题目**：某寡头市场只有两家企业，市场需求函数为 p = 30 − Q，其中 Q = q1 + q2；两家企业的生产成本均为零。求：（1）厂商一与厂商二的产量反应曲线；（2）均衡价格、各自的均衡产量与利润。

**解析**：三步。

第一步写利润函数。成本为零，利润就是总收益，π1 = (30 − q1 − q2)q1，π2 对称。

第二步对自家产量求偏导并令其为零，整理成 qi 关于 qj 的表达式，这一步得到的就是反应曲线：q1 = 15 − ½q2，q2 = 15 − ½q1。

第三步联立两条反应曲线。两式对称，故 q1 = q2，代入得 q1 = 10；市场总产量 Q = 20，回代需求函数得 p = 10；再回代利润函数得 π1 = π2 = 100。完整推导见前面古诺模型那一节。

**答案**：

- 反应曲线：$q_1 = 15 - \frac{1}{2}q_2$，$q_2 = 15 - \frac{1}{2}q_1$
- 均衡产量：$q_1 = q_2 = 10$，市场总产量 $Q = 20$
- 均衡价格：$p = 10$
- 利润：$\pi_1 = \pi_2 = 100$
