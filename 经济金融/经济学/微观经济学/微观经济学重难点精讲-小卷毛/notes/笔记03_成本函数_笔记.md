# 成本函数

## 成本函数与生产函数

* **成本函数（Cost Function）**

    * > **定义**：以产出 $Q$ 为自变量、以成本 $C$ 为因变量的函数，记作 $TC = f(Q)$，回答的是"产出多少要花多少钱"。

    * 成本函数是生产函数的函数：生产函数先把要素 $(L, K)$ 映射为产量 $Q = f(L, K)$，成本函数再把 $Q$ 映射为成本，两层复合之后起点还是要素、终点是钱。

    * 影响生产函数与成本函数的根本因素同为 $L$ 与 $K$，但两者的画法与分析方法分属两套。

* **互为反函数的图像**

    * 生产函数横轴为 $L$、纵轴为 $Q$；成本函数横轴为 $Q$、纵轴为 $C$。

    * 两者互为反函数、图像对称，先记住生产函数，把曲线翻成对称的样子就得到成本函数。

    * 生产函数起笔先画一个"对号"，再折过来画一个"弯"；成本函数不用另记一套形状。

    * > **易错点**：两张图外形极像，回头看时极易犯迷糊——生产函数纵轴是 $Q$、横轴是 $L$，成本函数纵轴是 $C$、横轴是 $Q$。横轴决定这条曲线在讲"投多少要素能产出多少"还是"产出多少要花多少钱"，方向反了整道题作废。

| 对比项 | 生产函数 | 成本函数 |
| :--- | :--- | :--- |
| 表达式 | $Q = f(L, K)$ | $TC = f(Q)$ |
| 自变量 | $L$、$K$ | $Q$ |
| 因变量 | $Q$ | $C$ |
| 横轴 | $L$ | $Q$ |
| 纵轴 | $Q$ | $C$ |

```text
   生产函数 Q = f(L)                 成本函数 C = f(Q)
   Q                                 C
   ^                                 ^
   |              ,-'                |            ,-'
   |           ,-'                   |         ,-'
   |        ,-'                      |      ,-'
   |     ,-'                         |   ,-'
   |  ,-'                            | ,-'
   +----------------> L              +----------------> Q
      先画一个"对号"，再画一个"弯"       取它的对称图形
```

## 成本与产量的倒数关系

* **边际成本与边际产量**

    * 总成本拆为 $TC = TVC + TFC$；短期 $K$ 为常数、只有 $L$ 变动，雇劳动力的那笔钱就是全部的可变成本，$TVC = wL$。

    * 对总成本求导：$MC = \dfrac{dTC}{dQ} = \dfrac{d(wL + TFC)}{dQ}$。$TFC$ 是常数、求导得 0，要素价格 $w$ 也是常数、可以提到导数外，只剩 $w\dfrac{dL}{dQ}$。

    * $\dfrac{dQ}{dL}$ 正是劳动的边际产量 $MP_L$，故 $\dfrac{dL}{dQ} = \dfrac{1}{MP_L}$，得到 $MC = \dfrac{w}{MP_L}$。

* **平均可变成本与平均产量**

    * $AVC = \dfrac{TVC}{Q} = \dfrac{wL}{Q} = \dfrac{w}{Q/L} = \dfrac{w}{AP_L}$。

    * 边际成本与边际产量互为倒数，平均可变成本与平均产量互为倒数；$w$ 是同一个常数，产量那边的曲线"先升后降"，成本这边的曲线就必然"先降后升"，两张图的对称由此而来。

    * > **提示**：$Q$ 与 $P$ 都指产量——说"产量是多少"时用 $Q$，说"边际产量、平均产量"时用 $P$，看到两者不要当成两个不同概念。

## 短期成本函数的七个函数

* **短期总成本的构成**

    * 短期生产函数假定 $K$ 为常数、只有 $L$ 变，短期成本函数同理：$TC = wL + rK$（$K$ 为常数）。

    * $wL$ 中的 $L$ 会变，这一项是可变成本；$rK$ 中的 $K$ 不变，这一项是固定成本。

    * > **注意**：区分可变成本与固定成本只在短期成立；到了长期所有要素都可变，就不再有固定成本这回事。

* **七个函数的记法**

    * 先把三条总量写下来：总成本 $TC$、总可变成本 $TVC$、总固定成本 $TFC$。

    * 每条再分出"边际"与"平均"两个派生，三条共六个派生；$TFC$ 是常数、求导得 0，边际固定成本不存在，划掉一个。

    * 边际总成本与边际可变成本只差一个常数（$TFC$ 求导为 0），合并记作一个 $MC$，再少一个；三个总量加六个派生、减掉两项，正好剩七个。

| 函数 | 记号 | 定义式 |
| :--- | :--- | :--- |
| 总成本（Total Cost） | TC | $TC = TVC + TFC$ |
| 总可变成本（Total Variable Cost） | TVC | $TVC = wL$ |
| 总固定成本（Total Fixed Cost） | TFC | $TFC = rK$ |
| 平均总成本（Average Cost） | AC | $AC = \dfrac{TC}{Q}$ |
| 平均可变成本（Average Variable Cost） | AVC | $AVC = \dfrac{TVC}{Q}$ |
| 平均固定成本（Average Fixed Cost） | AFC | $AFC = \dfrac{TFC}{Q}$ |
| 边际成本（Marginal Cost） | MC | $MC = \dfrac{dTC}{dQ} = \dfrac{dTVC}{dQ}$ |

## 短期总量曲线

* **总固定成本曲线**

    * $TFC = rK$ 是常数，图形为平行于横轴的一条水平线，三条总量曲线里它最好画。

* **总可变成本曲线**

    * $TVC = wL$ 一定过原点：短期可变成本就是雇劳动力带来的成本，产量为 0 意味着一个劳动力都没投入，可变成本自然是 0。

* **总成本曲线**

    * $TC = TVC + TFC$，相当于把 $TVC$ 整条向上平移 $TFC$，从纵轴的 $TFC$ 处起笔，永远不过原点。

    * 就算劳动力投入为 0，厂房、固定资产的消耗仍然在那儿等着，所以产量为 0 时成本不为 0。

    * 两条曲线斜率处处相同，垂直间距恒等于 $TFC$。

```text
TC = TVC + TFC

  TVC = w·L   →  L 会变，随产量一起增长；产量为 0 时，高度为 0
  TFC = r·K   →  K 不变，是一笔常数；产量为 0 时，照样存在

于是：TVC 从原点起笔，TC 从纵轴的 TFC 处起笔。
      两条曲线斜率处处相同，垂直间距恒等于 TFC，所以 TC 永远不过原点。
```

## 平均与边际的曲线推导

### 斜率的两种读法

* **自身斜率与连线斜率**

    * 边际 = 总量曲线上某一点自身的斜率；平均 = 总量曲线上某一点与原点连线的斜率。

    * 必须先有三条总量曲线：总量曲线不在，斜率的读法就无从谈起。

* **三条平均曲线**

    * $AC = \dfrac{TC}{Q}$ 就是 $TC$ 上一点与原点连线的斜率。从原点往右扫，连线先越来越平缓、斜率变小，过某一点之后又越来越陡、斜率变大，故 $AC$ 先下降再上升。

    * $AVC$ 同样从 $TVC$ 上读，连线斜率先减后增，故 $AVC$ 也先降后升。

    * $AFC$ 的分子 $TFC$ 是常数、分母 $Q$ 越来越大，比值一路变小，与原点连线一路变缓，从左上一直往下掉，全程单调递减。

| 平均函数 | 读法 | 走向 |
| :--- | :--- | :--- |
| AC | TC 上一点与原点连线的斜率 | 先降后升 |
| AVC | TVC 上一点与原点连线的斜率 | 先降后升 |
| AFC | TFC 上一点与原点连线的斜率 | 一直下降 |

### 最低点的先后

* **AVC 先见底**

    * 原因在起点：$TVC$ 过原点、$TC$ 不过原点。$TC$ 相当于 $TVC$ 整条向上平移了一段固定成本，平移之后与原点连线斜率最小的那个点被推到了更右边。

    * 也可以从加法上看：$AC = AVC + AFC$。$AVC$ 触底之后开始往上走，可这一段上 $AFC$ 还在继续往下掉，两者相加，$AC$ 还得再滑一段才到底。

* **短期边际成本（Short-run Marginal Cost，SMC）**

    * $SMC = \dfrac{dTC}{dQ}$，就是 $TC$ 曲线自身的斜率：开始一段比较陡，往前走变得平缓、斜率减小，再往前又变陡、斜率增大，故 $SMC$ 先下降后上升。

    * $SMC$ 从 $AVC$ 与 $AC$ 的最低点穿过。

## 边际与平均的关系

* **边际—平均法则**

    * > **定义**：边际大于平均，就把平均拽着往上走，平均上升；边际小于平均，就把平均往下坠，平均下降；边际等于平均，平均正好停在最低点。

    * 用分数理解最清楚：班里 60 个学生平均 85 分，转来一个考 90 分的，61 人的平均分高于 85；转来一个考 84 分的，平均分低于 85。转来的这个学生就是"边际"，原来的平均分就是"平均"。

    * 套到成本：$SMC$ 小于 $AVC$ 时 $AVC$ 处在下降段，$SMC$ 大于 $AVC$ 时 $AVC$ 处在上升段，两者刚好相等时正是 $AVC$ 的最低点。

    * $AC$ 同理，$SMC$ 也从 $AC$ 的最低点穿过去；短期整套图形最后落在两条结论上——三条总量曲线打底，$MC$ 从 $AVC$ 与 $AC$ 的最低点穿过。

## 长期成本函数

* **长短期之分**

    * 分水岭只有一句话：$K$ 变不变。短期 $K$ 是常数、只有 $L$ 变；长期 $L$ 与 $K$ 都变。

    * 长期成本函数里没有常数项，因而没有固定成本；没有固定成本，可变成本与总成本就是一回事，函数个数从七个掉到三个。

* **长期总成本（Long-run Total Cost，LTC）**

    * 画法与短期一样，仍跟生产函数对着记：先画"对号加一个弯"，再取它的对称图形。

* **长期平均成本（Long-run Average Cost，LAC）**

    * 从 $LTC$ 上读：一点与原点连线的斜率先变小再变大，故 $LAC$ 先降后升，是个 U 型。

* **长期边际成本（Long-run Marginal Cost，LMC）**

    * 对 $LTC$ 求导，即 $LTC$ 每一点自身的斜率，先平缓后陡峭，故 $LMC$ 也是先降后升的 U 型。

    * $LMC$ 与 $LAC$ 的关系同短期完全一样：$LMC$ 小于 $LAC$ 时 $LAC$ 下降，$LMC$ 大于 $LAC$ 时 $LAC$ 上升，两者相等时 $LAC$ 到最低点，即 $LMC$ 从 $LAC$ 的最低点穿过。

## 画图法则

* **三步法**

    * 第一步，画总量曲线（总产量、总成本、总可变成本、总固定成本）。

    * 第二步，量斜率：边际 = 总量曲线上每一点自身的斜率，平均 = 总量曲线上每一点与原点连线的斜率。

    * 第三步，用"边际大于平均则平均上升、小于则下降"校验交点位置。

    * 三步缺一不可：少了总量曲线，平均和边际没地方量；少了斜率读法，平均和边际画不出来；少了边际—平均关系，两条曲线在哪儿相交就说不清。

```text
第一步   画总量曲线
         （总产量 / 总成本 / 总可变成本 / 总固定成本）
              |
              v
第二步   边际 = 总量曲线上每一点自身的斜率
         平均 = 总量曲线上每一点与原点连线的斜率
              |
              v
第三步   用"边际大于平均则平均上升、小于则下降"校验交点位置
```

* **适用范围**

    * 短期七个、长期三个都按这三步走；生产函数与成本函数同理，只是横纵轴互换。

## 长期总成本曲线

* **长期计划曲线**

    * > **定义**：$LTC$ 又叫长期计划曲线——长期时间够长，可以先挑一个最优规模、再一直按这个规模生产；短期不能立刻把规模调到最优，只能在现有规模上生产，讲的是"已经在跑的那个规模"。

    * 关键前提是：长期里厂商可以调整自己的生产规模。

* **最优规模的选取**

    * 设厂商手上有六个可选规模 $STC_1$ 到 $STC_6$。要生产 $Q_1$，六个规模都做得到，画一条竖线上去，同一产量上成本高度最低的那条曲线所对应的规模就是最优规模。

    * 成本最低的规模会一直用到某个临界点为止，临界点是相邻两条 $STC$ 的交点；在交点处两个规模花的钱一样多，过了这个点更大的规模更省。

    * 判断规模大小看纵轴截距：截距就是该规模所耗费的固定成本，与纵轴交点越高、固定成本越大、规模也就越大。

    * 交点处若今后打算扩产，就选大的那个规模；若只想维持现有产量，就选小的接着用。

* **折线到光滑曲线**

    * 把每个产量区间里最省的那一段接起来（$OR$、$RS$、$ST$、$TU$、$UV$），这条折线就是厂商的长期总成本曲线。

    * 六个规模只是举例，现实里可选规模有无数个：段数从 6 加到 n，每一段弧越来越小；无限细分下去，每段短到几乎变直、甚至缩成一个点，折线成了一条光滑曲线。

    * 本质是每条 $STC$ 与纵轴的交点彼此无限接近——截距挨得越近，相邻两条曲线的交点就挨得越近，切出来的弧越小，折线自然平滑。

```text
C
|
|                                      ,-'  LTC
|                                ,-'
|                          ,-'
|                    ,-'
|              ,-'
|        ,-'
|,-'
+----|-----|-----|-----|-----|-----|--------> Q
     O     R     S     T     U     V
     每一段都由一条 STC 承包，段与段的交界就是相邻两条 STC 的交点
```

## 长期平均成本与短期平均成本

* **下包络与相切**

    * > **定义**：$LAC$ 是无数条 $SAC$ 的下包络线，与每一条 $SAC$ 都相切。

    * 短期 $AC$ 与长期对比时写作 $SAC$，以便与 $LAC$ 一眼对上。

    * 推导：每个产量上挑出 $SAC$ 最低的那条，把各条 $SAC$ 的最优段接起来；规模数从五个扩到 n，同样用无限细分，得到一条圆滑的 $LAC$。

* **切点位置**

    * 只有 $LAC$ 自己最低的那一点，才与某条 $SAC$ 的最低点相切。

    * $LAC$ 最低点左侧的切点，落在各自 $SAC$ 最低点的左边；右侧的切点落在各自 $SAC$ 最低点的右边。

    * > **易错点**：别把每条 $SAC$ 的最低点都摆到 $LAC$ 上——只有 $LAC$ 最低点那一处，切点才与 $SAC$ 的最低点重合。

| LAC 上的位置 | 切点落在该 SAC 的哪一段 |
| :--- | :--- |
| LAC 的最低点处 | 正好切在该 SAC 的最低点 |
| LAC 最低点的左侧 | 切在该 SAC 最低点的左边 |
| LAC 最低点的右侧 | 切在该 SAC 最低点的右边 |

---

## 长期边际成本与短期边际成本

* **LMC 的获得**

    * 先由 $SAC$ 得到 $LAC$（下包络），再由 $LAC$ 反推 $LMC$。

    * 依据是通用的边际—平均关系：$LMC$ 从 $LAC$ 的最低点穿过，$LAC$ 下降的那一段对应 $LMC$ 小于 $LAC$，上升的那一段对应 $LMC$ 大于 $LAC$。

* **LMC 与 SMC 的交点**

    * > **定义**：$LMC$ 与 $SMC$ 必在 $LAC$ 与 $SAC$ 的切点处相交，切点在哪，交点就在哪。

    * 道理只有一句：$LAC$ 与某条 $SAC$ 相切，切点处两条曲线的斜率相等；$SAC$ 的斜率就是 $SMC$，$LAC$ 的斜率就是 $LMC$，斜率相等即 $SMC$ 等于 $LMC$。

| 曲线对 | 关系 |
| :--- | :--- |
| LTC 与 STC | 下包络：每个产量上取成本最低的那条 STC 的一段，无限细分后平滑成线 |
| LAC 与 SAC | 下包络且相切：只有 LAC 最低点处才切于 SAC 的最低点 |
| LMC 与 SMC | 在 LAC 与 SAC 的切点处相等 |

## 成本最小化

* **问题设定**

    * 两种生产要素 $L$ 与 $K$，价格分别为 $w$ 与 $r$，在既定产出下求最小成本。

    * 目标函数按"题目让你求什么，什么就是目标函数"确定：$\min C = wL + rK$；约束条件是既定产出，即 $Q = f(L, K)$。

* **拉格朗日函数**

    * 先把目标函数原样抄下来，再加上乘子 $\lambda$ 乘以约束条件：$M = wL + rK + \lambda\,[\,Q - f(L, K)\,]$。

    * 记作 $M$ 而不记作 $L$，因为 $L$ 在这道题里已经是劳动力，两个 $L$ 摆在一起容易看花眼。

    * > **注意**：括号里不能写成等式，外面已经有一个等号，须写成 $Q - f(L, K)$ 这种形式。

    * 三个自变量 $L$、$K$、$\lambda$ 各求偏导并令其为零：

$$\frac{\partial M}{\partial L} = w - \lambda\frac{\partial f}{\partial L} = 0$$

$$\frac{\partial M}{\partial K} = r - \lambda\frac{\partial f}{\partial K} = 0$$

$$\frac{\partial M}{\partial \lambda} = Q - f(L, K) = 0$$

    * 前两式整理为 $w = \lambda\dfrac{\partial f}{\partial L}$、$r = \lambda\dfrac{\partial f}{\partial K}$，两式相除约掉 $\lambda$。

    * $\dfrac{\partial f}{\partial L}$ 是劳动的边际产量 $MP_L$，$\dfrac{\partial f}{\partial K}$ 是资本的边际产量 $MP_K$，于是得到 $\dfrac{w}{r} = \dfrac{MP_L}{MP_K}$。

    * 成本最小的一阶条件是要素价格之比等于边际产量之比；第三式就是约束本身，与前两式联立解出 $L$ 与 $K$，再代回成本函数，最小成本就出来了。
