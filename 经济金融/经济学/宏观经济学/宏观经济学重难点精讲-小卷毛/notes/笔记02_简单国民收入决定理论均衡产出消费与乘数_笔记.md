# 简单国民收入决定理论：均衡产出、消费与乘数

## 模型边界与两套叫法

### 核算与决定的分工

   * **国民收入核算（national income accounting）**

       * > **定义**：事后记账，回答一个经济体在过去一段时间里生产了多少、收入了多少。

   * **国民收入的决定（determination of national income）**

       * > **定义**：回答一个经济社会的生产和收入究竟由什么定下来，也就是 $y$ 是怎么被决定的。

       * 宏观中的 $y$ 同时表示总产出与总收入，这不是两个东西共用一个字母的巧合，而是同一件事的两个侧面。

### 总需求与总供给

   * **总需求（aggregate demand，AD）**

       * > **定义**：两部门假设下居民消费与企业投资之和，回答"谁需要市场里的东西"。

       * 表达式为 $AD=c+i$：居民消费买走市场里的消费品，企业投资要买设备、建厂房，买的同样是市场里的东西。

       * 事前看叫总需求，事后看叫总支出——想要拿到东西就必须付钱。

   * **总供给（aggregate supply，AS）**

       * > **定义**：居民储蓄与企业生产之和，回答"谁愿意把东西提供到市场里"。

       * 表达式为 总供给 = 居民储蓄 + 企业生产：企业把产品投放到市场，居民把兜里的钱以储蓄的形式放进市场。

       * 事前看叫总供给，事后看叫总收入——市场平白增添了价值，用钱来算就是新增的收入。

   * 前提是只有家庭与企业两个部门：家庭只做消费与储蓄两件事，企业只做投资与生产两件事；部门超过两个时题目条件会给出。

| 视角 | 需求侧 | 供给侧 |
| :--- | :--- | :--- |
| 事前（打算） | 总需求：居民消费 + 企业投资 | 总供给：居民储蓄 + 企业生产 |
| 事后（核算） | 总支出：得到东西必须付钱 | 总收入：市场新增的价值 |

   * > **提示**：总需求与总支出、总供给与总收入是同一件事在事前与事后两个时点上的两种叫法，方向记对了，两个式子不用背。

### 产品市场这一个切面

   * 凯恩斯的学说涉及四个市场：产品市场、货币市场、劳动市场、国际市场。

   * 简单的国民收入决定理论只研究其中的产品市场，它还有一个名字叫国民收入决定的收入支出模型。

   * 只取一个市场的原因：四个市场同时研究、用国民收入来核算一定会重复计算，所以只能从一个面切进去。

   * 两部门设定里所说的"市场"，隐含指的就是产品市场。

## 均衡产出

### 最简单经济关系的两个假设

   * **最简单经济关系**

       * > **定义**：只有家庭与企业两个部门、不存在政府、不存在对外贸易的经济。

       * 家庭的钱只有消费与储蓄两个用途，企业的钱只有生产与投资两个用途。

   * **外生投资**

       * > **定义**：由模型之外的因素决定、不受模型本身影响。

       * 具体到模型里就是投资不随利率和产量的变动而变动，作为给定常量进入。

   * **凯恩斯定律（Keynes's law）**

       * > **定义**：不论需求量为多少，经济社会都以不变的价格提供相应的供应量。

       * 换句白话：社会总需求变动时，只会引起产量和收入的变动，不会引起价格的变动。

       * 图形表现是一条水平的总供给曲线，需求怎么移动，交点对应的价格都不动，动的只有产量 $y$。

       * 成立背景是大萧条时期工人大批失业、资源大量闲置，需求增加只让闲置资源得到利用，不会推高资源的价格。

       * 它解释的是短期内价格不易变动、价格具有粘性：需求变动时企业首先调整产量，而不是先改价格。

       * > **易错点**：⚠️ 凯恩斯定律不等于"价格永远不变"，它有明确的适用条件——短期分析，且经济中存在大量闲置资源。

### 实际产出、计划需求与非计划存货投资

   * **实际产出（actual output）**

       * > **定义**：企业实际生产出来、投放到市场上的量。

       * 它可能大于、小于或正好等于市场上真正能卖出去的量，实际生产了多少，实际产出就是多少。

   * **计划需求（planned demand）**

       * > **定义**：事前定下来的、打算购买的量，也叫计划支出。

       * 站在生产者角度，就是它在投产之前预估消费者会买走多少，所以叫"计划"。

       * 宏观里需求与支出记成同一回事。

   * **非计划存货投资（unplanned inventory investment）**

       * > **定义**：预估失误、没人买而积压下来的那部分产出，也叫非意愿存货投资。

       * 恒等式为：实际产出 = 计划需求 + 非计划存货投资。

| 概念 | 例子中的数值 | 说的是什么 |
| :--- | :--- | :--- |
| 实际产出 | 1200 亿美元 | 企业实际生产出来、投放到市场上的量 |
| 计划需求（计划支出） | 1000 亿美元 | 事前打算购买、事后真正卖出去的量 |
| 非计划存货投资 | 200 亿美元 | 预估失误、没人买而积压下来的部分 |

   * 事后核算时实际产出与实际支出是同一个数：生产 1200 亿就对应 1200 亿支出，其中 1000 亿被买走，剩下 200 亿被动记成企业的存货投资。

### 均衡产出的两个条件

   * **均衡产出（equilibrium output）**

       * > **定义**：企业计划生产的量正好等于消费者想要购买的量时的产出水平。

       * 条件一：计划产出 = 计划需求（计划支出）。

       * 条件二：非计划存货投资 = 0。

   * 推导链：均衡时计划产出 = 计划需求；计划产出从事前看是计划、从事后看就是实际产出，故实际产出 = 计划需求；而恒等式是实际产出 = 计划需求 + 非计划存货投资，两相比较只能有非计划存货投资 = 0。

   * 举个最直白的例子：事前打算生产 100 斤，事后真的生产了这 100 斤，同一批产出在两个时点上换了名字——事前叫计划，事后叫实际。

   * 换成收入支出的说法：产出即总供给即收入，计划支出即计划需求，所以均衡产出也可以理解为全社会的收入正好等于全体居民和企业想要的支出。

### 四十五度线与总需求曲线的交点

   * 横坐标是收入、纵坐标是支出；从原点出发的 45 度线上每点横纵坐标相等，本身就是一条收支相抵的线；AE 曲线表示总需求，比 45 度线更平缓。

```text
均衡产出 b
├── 条件一：落在 45° 线上   →  全社会的支出 = 收入
└── 条件二：落在 AE 曲线上 →  企业产出 = 总需求，非计划存货投资 = 0
```

   * 只落在 45 度线上不行：那条线上收支相抵的点有无数个，但在那些点上企业产出的量与消费者真正需要的量未必相等。

| 产出与总需求 | 结果 |
| :--- | :--- |
| 产出 > 总需求 | 生产出来的比需要的多，一定有剩余，形成存货投资 |
| 产出 = 总需求 | 刚好卖完，非计划存货投资为零，这就是均衡 |
| 产出 < 总需求 | 供给小于需求，留下一个缺口 |

   * 三种情形里只有第二种同时满足两个条件，所以均衡产出就是 AE 与 45 度线的交点。

   * 想提高均衡产出，能改的只有总需求：45 度线固定不动，AE 上移则交点沿 45 度线往右上方走，均衡产出随之变大。

### 计划投资等于计划储蓄

   * 起点是均衡条件 计划产出 = 计划支出，换成收入支出的说法即 计划收入 = 计划支出。

   * 两边拆开：计划支出 = 计划消费 + 计划投资，即 $c+i$；计划收入 = 计划消费 + 计划储蓄，即 $c+s$。

   * 代入得 $c+i=c+s$，两边约掉 $c$，最终落在 $i=s$：经济达到均衡时，计划投资等于计划储蓄。

   * > **注意**：这里的 $i$ 与 $s$ 都是计划的量；一旦企业判断失误出现非计划存货投资，事后的实际投资就不等于计划投资，这个等式也不再是均衡条件。

## 消费理论的枝干结构

### 凯恩斯这一支

   * 这一支挂四样东西：消费函数、储蓄函数、消费函数与储蓄函数之间的关系、凯恩斯的消费之谜。

   * 家庭消费函数与社会消费函数同属这一支，不展开也不影响后面的主线。

   * 核心式是 $c=a+by$ 与 $s=y-c$，后面的推导都从这两式出发。

### 非凯恩斯这一支

   * 理论其实不少，只学三种：生命周期假说、相对收入消费理论、永久收入消费理论。

   * 三种理论做的是同一件事：找出凯恩斯错在哪，解释长期 $APC$ 为什么不变。

   * 两支之间是"立"与"破"的关系：凯恩斯消费函数被数据否定，才有了消费之谜，有了谜才有后来者去解释它。

## 凯恩斯消费函数

### 消费由收入决定

   * 古典学派的解释：消费由利率决定，两者负相关，链条是利率上升、储蓄回报变高、人们更愿意储蓄，用来消费的自然变少。

   * 凯恩斯的反驳：利率再高，手里没有钱同样既不能储蓄也不能消费，利率高低与消不消费关系不大。

   * 凯恩斯承认利率在理论上多少影响消费，但真正起作用的只有一个因素——收入。

   * 两派的分歧不在"储蓄到消费"这一环，而在自变量到底是利率还是收入。

### 消费函数的构成

   * **消费函数（consumption function）**

       * > **定义**：消费与收入之间的依存关系，凯恩斯写作 $c=a+by$。

       * $a$ 是自主性消费：不依存于收入，取决于维持生命的基本需要，一分钱收入没有也必须花。

       * $by$ 是引致消费：随收入变动而变动，收入动了它才动。

       * $b$ 是边际消费倾向，表示收入每增加一单位消费增加多少，取值 $0<b<1$。

       * $b<1$ 的依据是消费的增量不会大于收入的增量，背后是凯恩斯对人的判断：人多多少少是节俭的，不会把全部收入拿去消费。

   * 图像从纵轴上的 $a$ 出发，收入为零时消费仍是 $a$；线性式是一条直线，一般形态是逐渐平缓的曲线。

### 边际消费倾向与平均消费倾向

   * **边际消费倾向（marginal propensity to consume，MPC）**

       * > **定义**：收入每增加一单位所增加的消费，$MPC=\Delta c/\Delta y=dc/dy$。

       * 几何读法是消费曲线上该点切线的斜率：边际就是求导，求导在图上就是切线斜率。

       * 曲线越往右越平缓，每一点的切线斜率都在变小，所以 $MPC$ 递减。

   * **平均消费倾向（average propensity to consume，APC）**

       * > **定义**：消费与收入之比，$APC=c/y$。

       * 几何读法是该点与原点连线的斜率：$c$ 与 $y$ 构成一个直角三角形，$c/y$ 是这个角的正切。

       * 点沿曲线右移时连线越来越平，$APC$ 递减。

   * 代数关系：$APC=a/y+b$，$MPC=b$，故 $APC>MPC$ 恒成立，缺口正好是 $a/y$，收入越低缺口越大。

| 概念 | 代数定义 | 图上怎么读 | 随收入的变化 |
| :--- | :--- | :--- | :--- |
| $MPC$ | $\Delta c/\Delta y$，即 $dc/dy$ | 该点切线的斜率 | 递减 |
| $APC$ | $c/y$ | 该点与原点连线的斜率 | 递减 |

   * > **提示**：$c=a+by$ 是线性写法，此时 $MPC=b$ 是一个常数；"$MPC$ 递减"说的是更一般的非线性消费曲线，两者不冲突。

   * > **易错点**：⚠️ $MPC$ 读的是切线斜率，$APC$ 读的是过原点连线的斜率，读混了走势就会判断错。

### 凯恩斯消费理论的三条核心

   * 消费由收入决定，不由利率决定，这是与古典学派的分歧点。

   * 表达式 $c=a+by$ 与它的图像，公式要会写、图要会画。

   * $APC$ 与 $MPC$ 都递减，而且 $APC$ 大于 $MPC$；前两条靠记，第三条要证。

## 储蓄函数与两条曲线的关系

### 储蓄函数

   * **储蓄函数（saving function）**

       * > **定义**：储蓄随收入变化的关系，记作 $s=s(y)$，储蓄同样由收入决定。

       * 由收入的两个去处推出 $s=y-c$，代入消费函数得 $s=y-(a+by)=(1-b)y-a$。

   * **边际储蓄倾向（marginal propensity to save，MPS）**

       * > **定义**：增加一单位收入中用于增加储蓄的比率，$MPS=\Delta s/\Delta y=1-b$。

   * **平均储蓄倾向（average propensity to save，APS）**

       * > **定义**：储蓄与收入之比，$APS=s/y=1-b-a/y$。

   * $APS$ 在 $1-b$ 的基础上又减掉一个正的 $a/y$，故 $APS<MPS$ 恒成立，缺口同样是 $a/y$，与消费侧的 $APC>MPC$ 是同一个缺口的两面。

### 消费函数与储蓄函数的关系

   * 互为补数：$y=c+s$，收入固定时 $c$ 越大 $s$ 越小，想让储蓄多一点消费就得少一点。

   * 走势相反：$APC$、$MPC$ 随收入增加而递减且 $APC>MPC$；$APS$、$MPS$ 随收入增加而递增且 $APS<MPS$。

   * 两个恒等式：$APC+APS=1$，$MPC+MPS=1$；逐对相加时 $a/y$ 与 $-a/y$、$b$ 与 $-b$ 分别抵消。

| 量 | 定义式 | 表达式 | 走势（一般形态） |
| :--- | :--- | :--- | :--- |
| $APC$ | $c/y$ | $a/y+b$ | 递减 |
| $MPC$ | $dc/dy$ | $b$ | 递减 |
| $APS$ | $s/y$ | $1-b-a/y$ | 递增 |
| $MPS$ | $ds/dy$ | $1-b$ | 递增 |

   * 表里的递增递减描述的是消费曲线的一般形态；在线性简化式 $c=a+by$ 下，$MPC$ 恒为 $b$、$MPS$ 恒为 $1-b$。

   * > **提示**：这套关系不用死记，把 $c$、$s$ 和四个倾向写出来逐对相加即可现推，推一遍比背错了强。

## 凯恩斯的消费之谜

### 绝对收入假说与数据的冲突

   * **绝对收入假说（absolute income hypothesis）**

       * > **定义**：凯恩斯的消费理论，认为消费取决于当期的绝对收入水平。

       * 二战后对现实数据的计量统计分析表明，这套假说与现实经济运行并不吻合。

       * 消费之谜这个名字是体面说法：凯恩斯当时声望极高，即使错了也不便直呼"凯恩斯的错误"。

   * 错因不是逻辑推不出来，而是推出来的结论与现实数据对不上：凯恩斯说 $MPC$、$APC$ 都递减，经验数据一算不是这么回事。

### 长短期消费函数的形态差异

   * 短期凯恩斯是对的，$APC$ 递减；长期 $APC$ 不是递减，而是不变。

   * 凯恩斯当年没有区分长期和短期，笼统地说两个倾向都递减；现实中的消费函数必须分长短，画出来是两条形态不同的线。

   * 短期消费函数有截距 $a>0$，不过原点；长期消费函数无截距，过原点。

   * 过原点则 $c$ 与 $y$ 同比例变动，$c/y$ 恒等于这条线的斜率，$APC$ 自然是一个常数。

| 口径 | 函数形态 | 是否过原点 | $APC$ 的走势 |
| :--- | :--- | :--- | :--- |
| 短期消费函数 | 有截距 $a>0$ | 不过原点 | $a/y+b$，随收入递减 |
| 长期消费函数 | 无截距 | 过原点 | 为常数，不随收入变化 |

   * > **提示**：凯恩斯并不是在长期上另说了一套，而是根本没提长短期这回事；他的结论是"无论长短都递减"，数据证明的却是"短期递减、长期不变"，谜就出在这个缺口上。

   * 后来者要回答的就是为什么短期成立、长期不成立，三条路子最终都落到 $APC$ 上：谁把"长期 $APC$ 为什么不变"讲通了，谁就解开了这个谜。

## 三个修正理论

### 生命周期假说

   * **生命周期假说（life cycle hypothesis）**

       * > **定义**：莫迪利亚尼提出，把一生按退休切成工作与退休两段，人希望一生保持平滑的消费水平。

       * 变量含义：从现在起还要生活 $t$ 年，初始财富为 $W$，到退休还有 $r$ 年、这 $r$ 年每年挣 $y$。

       * 一个人能支配的全部资源是 $W+ry$，即"一出生就有的"加"工作挣来的"。

       * 把总资源摊到 $t$ 年：$C=\dfrac{W+ry}{t}=\dfrac{1}{t}W+\dfrac{r}{t}y$，写成 $C=\alpha W+\beta y$，其中 $\alpha=1/t$ 是财富的边际消费倾向、$\beta=r/t$ 是收入的边际消费倾向。

       * 平滑的具体含义：工作那 $r$ 年把花不完的部分存起来，退休那 $t-r$ 年没有收入靠存款过日子，年轻时正储蓄、年老时负储蓄，两段合起来正好把 $W+ry$ 花完。

   * 对谜的解释：两边同除以 $y$ 得 $APC=\alpha\dfrac{W}{y}+\beta$，$\alpha$、$\beta$ 都是常数，$APC$ 完全由 $W/y$ 决定。

   * 短期一年一年看，收入不可能全部转化为财富，$\Delta y>\Delta W$，$W/y$ 的分母涨得比分子快，比值下降，$APC$ 递减。

   * 长期一生来看，有些年份花得多、有些年份攒得多，正负抵消后 $\Delta y=\Delta W$，$W/y$ 不变，$APC$ 不变。

   * 一句话结论：短期 $APC$ 递减、长期 $APC$ 不变，凯恩斯的短期结论被保留，只在长期上做了修正。

### 相对收入假说

   * **相对收入假说（relative income hypothesis）**

       * > **定义**：杜森贝利提出，消费不取决于现期的绝对收入水平，而取决于相对收入水平。

       * 相对有两个方向：相对于别人，对应攀比；相对于自己历史上的最高收入，对应消费习惯。

   * **棘轮效应（ratchet effect）**

       * > **定义**：消费具有习惯性，某期的消费不受当期收入影响，而受过去所达到的最高收入和最高消费影响，因而具有不可逆性。

       * 棘轮只能单向转，消费也一样，上去了就下不来，说白了就是"由俭入奢易，由奢入俭难"。

   * **示范效应（demonstration effect）**

       * > **定义**：消费受别人影响，取决于别人的相对收入水平而不是自己的绝对收入。

       * 即使手头没钱，攀比之心也会把消费维持在一个较高的状态。

   * 两个效应合起来结果一致：收入波动而消费不大波动，长期看 $APC$ 不变。

   * > **易错点**：⚠️ 棘轮效应对应"相对于自己的历史最高收入"，讲的是习惯；示范效应对应"相对于别人"，讲的是攀比，两个方向不要对调。

### 永久性收入假说

   * **持久性收入（permanent income）**

       * > **定义**：弗里德曼的划分中，人们预期可以一直获得的那部分收入，也叫永久性收入。

       * 收入被拆成两块：$y=y_p+y_t$，$y_p$ 是持久性收入，$y_t$ 是暂时性收入。

   * **永久性收入假说（permanent income hypothesis）**

       * > **定义**：只有持久性收入决定消费，暂时性收入不进消费函数。

       * 消费函数为 $c=\alpha y_p$；求 $APC$ 得 $APC=\alpha\dfrac{y_p}{y}$，完全由持久性收入与现期收入之比决定。

       * 短期分两种：现期收入暂时升到持久性收入之上（$y>y_p$）时 $y_p/y$ 变小、$APC$ 暂时下降；现期收入暂时降到持久性收入之下（$y<y_p$）时 $y_p/y$ 变大、$APC$ 暂时上升。

       * 翻译过来就是高收入的年份 $APC$ 反而低，低收入的年份 $APC$ 反而高。

       * 长期收入变动取决于持久性收入，$y$ 与 $y_p$ 同比例变动，$y_p/y$ 成为常数，$APC$ 不变。

### 三条路子的对照

| 理论 | 代表人物 | 消费由什么决定 | 长期 $APC$ 为什么不变 |
| :--- | :--- | :--- | :--- |
| 生命周期假说 | 莫迪利亚尼 | 财富与收入 | 一生中 $W$ 与 $y$ 同比例变动，比值稳定 |
| 相对收入假说 | 杜森贝利 | 相对收入（他人，以及自己的历史最高） | 棘轮效应与示范效应压住了消费波动 |
| 永久性收入假说 | 弗里德曼 | 持久性收入 | $y_p/y$ 长期稳定 |

   * 三条路子切入角度不同：生命周期从财富与收入的关系切，相对收入从人与人的比较、人与自己过去的比较切，永久性收入从收入的可预期性切。

   * 三者回答的是同一个问题：凯恩斯在长期上错在哪，为什么长期 $APC$ 不变。

   * > **提示**：记忆要抓的是对应关系——谁提出、从哪个角度、结论是什么；名字与角度对不上，式子写得再熟也用不上。

## 国民收入的决定

### 均衡收入与求解思路

   * **均衡收入（equilibrium income）**

       * > **定义**：计划支出恰好等于计划收入时所对应的那个收入水平。

       * 不管几个部门，研究的都是均衡收入；所有乘数都架在均衡点上，收入从一个均衡挪到另一个均衡，中间过程不管。

   * 求解思路只有一条：把 $C$ 用消费函数写开，代进均衡条件，解方程。

   * 后续部门不必每种方法都推一遍：消费法与储蓄法结论完全一样，多推一遍不会多出信息，只会多出出错的机会。

### 两部门

   * 计划支出写成 $Y=C+I$，计划收入写成 $Y=C+S$，均衡即两者相等。

   * 消费法：$Y=\alpha+\beta Y+I$，移项得 $Y(1-\beta)=\alpha+I$，两边同除 $1-\beta$ 得 $Y=\dfrac{\alpha+I}{1-\beta}$。

   * 储蓄法：均衡条件即 $I=S$，而 $S=Y-C=Y-(\alpha+\beta Y)=-\alpha+(1-\beta)Y$，联立解得同一结果。

   * > **提示**：$I$、$S$、$Y$ 用大写或小写都无所谓，只要一篇里前后一致。

### 三部门与可支配收入

   * **可支配收入（disposable income，$Y_d$）**

       * > **定义**：挣到的收入扣掉税收、加上政府转移支付之后，真正可以由居民支配的部分。

       * 表达式为 $Y_d=Y-T+TR$，直接记住即可。

   * 支出构成变成 $Y=C+I+G$，消费函数仍用同一个形状，但里面的收入换成 $C=\alpha+\beta Y_d$。

   * 不能直接拿 $Y$ 去消费的原因：有了政府，挣的钱不全是自己能花的，一部分要纳税，同时政府也会给转移支付。

### 两种税制

   * **定量税（定额税）**

       * > **定义**：交的税是一个定值，与收入没有关系。

       * 收入增加它不增加，收入减少它也不减少。

   * **比例税**

       * > **定义**：税额随收入变动，$T=tY$，$t$ 是税率。

       * 挣得多就多交，挣得少就少交。

   * 两种税的差别只落在可支配收入这一行式子上，往下推的路径完全相同。

### 定量税下的均衡收入

   * 可支配收入 $Y_d=Y-T+TR$，代进消费函数得 $C=\alpha+\beta(Y-T+TR)$，再代进 $Y=C+I+G$。

   * 展开并把带 $Y$ 的项移到左边：$Y-\beta Y=\alpha-\beta T+\beta TR+I+G$，两边同除 $1-\beta$ 得

$$Y=\frac{\alpha+I+G-\beta T+\beta TR}{1-\beta}$$

   * 分子的符号不是背出来的，是从 $Y_d=Y-T+TR$ 一路带下来的：$T$ 前面是负号，因为收税是从居民口袋里往外拿钱；$TR$ 前面是正号，因为转移支付是往口袋里放钱；$I$ 与 $G$ 是正号，它们是直接的需求。

### 比例税下的均衡收入

   * $Y_d=Y-tY+TR=(1-t)Y+TR$：每一块钱收入先被税拿走 $t$，剩下 $(1-t)$ 才是自己的，这一部分再按 $\beta$ 的比例变成消费。

   * 代进消费函数与均衡条件：$Y=\alpha+\beta(1-t)Y+\beta TR+I+G$，移项得

$$Y=\frac{\alpha+I+G+\beta TR}{1-\beta(1-t)}$$

   * 与定量税式子相比只有两处变化：分母由 $1-\beta$ 变成 $1-\beta(1-t)$；分子里的 $-\beta T$ 不见了，税不再是常数，被 $t$ 吸收进分母。

   * > **提示**：比例税式子记不记都行，往下讲乘数一概只考虑定量税；真要用时把 $1-\beta$ 换成 $1-\beta(1-t)$ 现推也来得及。

### 出口、进口与边际进口倾向

   * 四部门在三部门基础上加进出口，净出口写成 $X-M$，$X$ 是出口、$M$ 是进口。

   * 出口从本国角度看不是自己能决定的，所以看作常量；进口随本国居民收入增加而增加，写成收入的函数 $M=M_0+\gamma Y$。

   * **自发进口（$M_0$）**

       * > **定义**：跟收入没有关系、无论如何都要进口的那一部分。

   * **边际进口倾向（marginal propensity to import，$\gamma$）**

       * > **定义**：收入每增加一块钱，进口增加多少。

### 四部门的均衡收入

   * 四个式子摆齐：$Y=C+I+G+X-M$，$C=\alpha+\beta Y_d$，$Y_d=Y-T+TR$，$M=M_0+\gamma Y$。

   * 把 $C$ 与 $M$ 都代进第一个式子：$Y=\alpha+\beta(Y-T+TR)+I+G+X-(M_0+\gamma Y)$，注意 $X-M$ 里减的是整个 $M_0+\gamma Y$，展开即减 $M_0$ 再减 $\gamma Y$。

   * 把带 $Y$ 的项全部移到左边，$-\gamma Y$ 移过去要变号，得 $Y-\beta Y+\gamma Y=\alpha-\beta T+\beta TR+I+G+X-M_0$：

$$Y=\frac{\alpha+I+G+X-\beta T+\beta TR-M_0}{1-\beta+\gamma}$$

   * 分母为 $1-\beta+\gamma$：进口与消费一样随收入增加而增加，所以 $\gamma$ 和 $\beta$ 一样从左边减掉、移项之后落到分母上。

   * > **易错点**：⚠️ 四部门的分母是 $1-\beta+\gamma$，不是 $1-\beta-\gamma$；$\gamma Y$ 原来在等号右边是减项，移到左边就成了加项。

### 均衡收入的四种情形

| 部门 | 均衡条件 | 定量税下的 $Y$ | 比例税下的 $Y$ |
| :--- | :--- | :--- | :--- |
| 两部门 | $Y=C+I$ | $\dfrac{\alpha+I}{1-\beta}$ | 不涉及 |
| 三部门 | $Y=C+I+G$ | $\dfrac{\alpha+I+G-\beta T+\beta TR}{1-\beta}$ | $\dfrac{\alpha+I+G+\beta TR}{1-\beta(1-t)}$ |
| 四部门 | $Y=C+I+G+X-M$ | $\dfrac{\alpha+I+G+X-\beta T+\beta TR-M_0}{1-\beta+\gamma}$ | 不涉及 |

   * 三个部门的表达式串起来看，差别只在分子多出的项与分母的形式：多一个部门就多一项需求，多一种税就改一次分母。

   * 记忆按部门走：先问几个部门，再问是国民收入的决定还是某个乘数，$Y$ 的表达式就不会记乱。

## 乘数原理

### 乘数的含义与算法

   * **乘数（multiplier）**

       * > **定义**：因变量变化量与引起它的自变量变化量之比，$\Delta Y/\Delta X$，本质是一个边际量、一个倍数。

       * 投资增加 500 亿，国民收入增加的量会大于 500 亿、是它的若干倍，这个"若干倍"就是乘数。

   * 成倍的原因：投资增加不是只在一个点上发生，一个行业的投资会给周边有关联的行业带来订单和收入，那些行业的人有了钱再花又带动下一轮，连锁反应加总后国民收入成倍增长。

   * 算法上是求偏导：$\dfrac{\partial Y}{\partial I}$、$\dfrac{\partial Y}{\partial G}$、$\dfrac{\partial Y}{\partial T}$ 分别是投资乘数、政府购买乘数、税收乘数；求什么乘数就让 $Y$ 对哪个自变量求偏导，其余一律当常数。

   * > **提示**：乘数不是独立的知识点，它是国民收入决定的下游；顺序永远是先写出该部门的 $Y$ 表达式再求偏导，式子写错乘数一定跟着错。

### 投资乘数

   * **投资乘数（investment multiplier，$k_I$）**

       * > **定义**：收入的变化与带来这种变化的投资支出变化之间的比率，$k_I=\Delta Y/\Delta I$。

       * 两部门 $Y=\dfrac{\alpha+I}{1-\beta}$，拆成 $\dfrac{\alpha}{1-\beta}+\dfrac{I}{1-\beta}$ 后对 $I$ 求偏导，第一项为零，第二项就是 $I$ 的系数：$k_I=\dfrac{1}{1-\beta}$。

       * 换成倾向写法：$k_I=\dfrac{1}{1-\mathrm{MPC}}=\dfrac{1}{\mathrm{MPS}}$。

       * 边际消费倾向越大、边际储蓄倾向越小，投资乘数越大：$1-\mathrm{MPC}$ 在分母上，分母越小分数越大。

       * 三部门（定量税）的 $Y$ 式子里 $I$ 的系数仍是 $\dfrac{1}{1-\beta}$，$T$、$TR$、$G$ 全是常数，所以结果相同。

       * 四部门也能求，但不作重点，掌握到三部门即可。

### 政府购买乘数

   * **政府购买乘数（government purchase multiplier，$k_G$）**

       * > **定义**：收入变化与带来这种变化的政府购买变化之间的比率。

       * 两部门没有政府，谈不上这个乘数；它只有引入政府之后才存在。

       * 三部门定量税下 $k_G=\dfrac{\partial Y}{\partial G}=\dfrac{1}{1-\beta}$，与投资乘数一模一样。

       * 相同的原因：$Y=C+I+G$ 里 $I$ 与 $G$ 是同一层级的加项，都是直接的需求，位置对称，系数自然相同。

### 税收乘数与政府转移支付乘数

   * **税收乘数（tax multiplier，$k_T$）**

       * > **定义**：收入变化与带来这种变化的税收变化之间的比率，$k_T=\dfrac{-\beta}{1-\beta}$。

       * 负号是关键：政府多收税，居民手里的钱就少，消费跟着少，国民收入往下走。

       * 从大小看，它的绝对值是政府购买乘数的 $\beta$ 倍。

   * **政府转移支付乘数（transfer payment multiplier，$k_{TR}$）**

       * > **定义**：收入变化与带来这种变化的转移支付变化之间的比率，$k_{TR}=\dfrac{\beta}{1-\beta}$。

       * 正号：政府多给补贴，可支配收入增加、消费增加、国民收入上升。

   * 两个乘数大小相等、符号相反：一个是从居民手里拿走钱，一个是往居民手里放钱，方向相反是应该的。

   * 两者都只在三部门及以后才存在，两部门既没有税也没有转移支付。

### 平衡预算乘数

   * **平衡预算乘数（balanced budget multiplier）**

       * > **定义**：政府收入和支出同时以相等数量增加或减少时，国民收入变动与政府收支变动的比率。

       * "政府收支"不是一个词而是两个词：收是政府收入、主要就是税收，支是政府支出、这里就是政府购买，转移支付不计入政府支出。

       * 前提是 $\Delta G=\Delta T$：政府多收多少税就多买多少东西。

       * 总变动由两部分组成，$\Delta Y=k_G\cdot\Delta G+k_T\cdot\Delta T$；代入两个乘数并把 $\Delta T$ 换成 $\Delta G$，得 $\Delta Y=\dfrac{1-\beta}{1-\beta}\Delta G=\Delta G$。

       * 于是 $\dfrac{\Delta Y}{\Delta G}=\dfrac{\Delta Y}{\Delta T}=1$，这就是平衡预算乘数。

```text
政府收支等量变动
   ├─ 收入端：税收 T 增加 → 居民手里钱变少 → 国民收入减少
   └─ 支出端：购买 G 增加 → 政府买走人民生产的东西 → 国民收入增加
   两股力量方向相反，总变动 = 一正一负相加
```

   * 政府购买为什么是正向的：政府到市场上买原材料、买办公设备，这些东西是人民生产的，钱流到居民手里，国民收入增加。

   * > **提示**：平衡预算乘数其实不是一个数而是两个数——$\Delta Y/\Delta G$ 与 $\Delta Y/\Delta T$；之所以能合成一个名字，是因为算完发现两个比值相等，都等于 1。

### 数值试算

   * 三部门、定量税，$\beta=0.8$。

   * 政府购买增加 200 亿：$k_G=\dfrac{1}{1-0.8}=5$，$\Delta Y=5\times200=1000$ 亿。

   * 税收增加 200 亿：$k_T=\dfrac{-0.8}{1-0.8}=-4$，$\Delta Y=-4\times200=-800$ 亿。

   * 两笔合起来净增 $1000-800=200$ 亿，正好等于政府收入和政府支出各自增加的量，这就是"平衡"两个字的来历。

| 操作 | 乘数 | 国民收入变动 |
| :--- | :--- | :--- |
| 政府购买增加 200 亿 | $k_G=5$ | $+1000$ 亿 |
| 税收增加 200 亿 | $k_T=-4$ | $-800$ 亿 |
| 两项同时等量变动 | 平衡预算乘数 $=1$ | $+200$ 亿 |

   * > **易错点**：⚠️ $k_G=5$ 与平衡预算乘数等于 1 不矛盾：前者是只有政府购买动、税收不动，后者是两个变量等量反向变动，1000 的正效应被 800 的负效应抵掉大半，剩 200 不是乘数失效。

### 乘数总表

| 乘数 | 两部门 | 三部门（定量税） | 四部门 |
| :--- | :--- | :--- | :--- |
| 投资乘数 | $\dfrac{1}{1-\beta}$ | $\dfrac{1}{1-\beta}$ | 可求，不作重点 |
| 政府购买乘数 | 无 | $\dfrac{1}{1-\beta}$ | 不作重点 |
| 税收乘数 | 无 | $\dfrac{-\beta}{1-\beta}$ | 不作重点 |
| 政府转移支付乘数 | 无 | $\dfrac{\beta}{1-\beta}$ | 不作重点 |
| 平衡预算乘数 | 无 | $1$ | 不作重点 |

   * 这些乘数不必死记硬背，现推只有一步：写出 $Y$ 的表达式，然后求偏导。

   * 整套推导里真正稍微复杂的只有每个部门的 $Y$ 怎么表达，这一段通了乘数是体力活，这一段卡住乘数背下来也没用。
