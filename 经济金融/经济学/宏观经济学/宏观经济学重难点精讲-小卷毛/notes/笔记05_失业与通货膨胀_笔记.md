# 失业与通货膨胀

## 从 AD-AS 到失业率

* **短期均衡与充分就业（full employment）**

    * > **定义**：总需求曲线与短期总供给曲线的交点只是短期均衡点；把它与垂直的长期总供给曲线比较，才能判断就业是否充分。

    * 短期总供给曲线水平或向右上方倾斜，长期总供给曲线垂直，位置由潜在产出 $Y_f$ 决定。

    * 短期均衡落在长期总供给曲线左侧为失业，正好落在其上为充分就业，落在右侧为超充分就业均衡。

    * 图示关系：

    ```text
     P
     ^
     |                 LRAS
     |                   |
     |        AS         |
     |       /           |
     |      /            |
     |     E             |
     |    / \            |
     |   /   \  AD       |
     |  /     \          |
     | /       \         |
     +----------------------> Y
           Y1           Yf
    ```

    * 读图：$E$ 在 $LRAS$ 左侧，$Y_1 < Y_f$，该短期均衡达不到充分就业，对应失业。

* **失业与通货膨胀的判定口径**

    * 只看产出 $Y$：$Y$ 减少即失业，不论价格 $P$ 如何变动。

    * 只看价格 $P$：$P$ 上升即通货膨胀，不论产出 $Y$ 是增是减。

    * $Y$ 减少与 $P$ 上升同时发生，是失业与通货膨胀并发的更麻烦情形。

* **四种组合的取舍**

    * 总需求与总供给移动可组合出 $Y$ 增 $P$ 增、$Y$ 增 $P$ 减、$Y$ 减 $P$ 增、$Y$ 减 $P$ 减四种结果。

    * $Y$ 增加是经济繁荣，不属于需要处理的问题，故只研究失业、通货膨胀、以及两者同时严重这三种。

* **失业率（unemployment rate，$u$）**

    * > **定义**：劳动力中没有工作、而又在寻找工作的人所占的比例，等于失业人数除以劳动力人数。

    * 分子须同时满足「没有工作」与「在寻找工作」；没有工作且不想工作的人不计入失业。

    * 分母是劳动力人数，等于就业人数加失业人数，既不是总人口，也不是已就业人数。

## 自然失业率

* **自然失业率（natural rate of unemployment，$u^*$）**

    * > **定义**：经济社会在正常情况下的失业率，即劳动力市场处于供求稳定状态时的失业率；稳定状态指既不会推动通货膨胀、也不会导致通货紧缩的状态。

    * 「供求稳定」指劳动力供给稳定、劳动力需求稳定，即二者都不变，不是供求相等。

    * 失业等于劳动力供给减劳动力需求，对应供给大于需求的那一段；供求相等意味着人人就业，就不存在失业可研究。

    * 失业人数固定是定义要求，不是价值判断：多一个不行，少一个也不行。

    * > **易错点**：把「供求稳定」读成「供求相等」。相等即无失业；稳定只要求失业人数固定。

* **稳态的流量条件**

    * 失业人数固定，必然要求失业者中找到工作的人数等于就业者中失去工作的人数，一进一出恰好抵消。

    * 记失业人数 $U$、就业人数 $E$、就职率 $f$、离职率 $l$，稳态条件为 $fU = lE$。

    * 图示：

    ```text
             fU（失业者找到工作）
        U ----------------------> E
          <----------------------
             lE（就业者失去工作）
    ```

    * 数值感：上个月 100 人失业，下个月仍须 100 人失业；变成 99 人或 101 人都不是自然失业率状态。

* **公式与决定因素**

    * 劳动力总数 $N = E + U$，故 $E = N - U$。

    * 代入稳态条件 $fU = lE$，得 $fU = l(N-U)$，整理为 $(f+l)U = lN$。

    * 两边同除以 $N(f+l)$，得

    $$\frac{U}{N} = \frac{l}{l+f}$$

    * 自然失业率由离职率与就职率共同决定：离职率越高、就职率越低，自然失业率越高。

    * 符号提醒：离职率 $l$ 是小写字母 L，不是字母 i；失业人数用大写 $U$，失业率用小写 $u$。

## 失业的经济学解释

### 市场出清与古典学派

* **市场出清（market clearing）**

    * > **定义**：价格具有充分灵活性、可以自行调整，从而使需求与供给迅速达到均衡的状态。

    * 等同于供求均衡：既无资源闲置，也无超额供给或超额需求。

    * 只在没有疫情、金融危机、战争等大波动时成立；市场达不到出清，说明社会已出现大的波动。

* **古典学派的失业解释**

    * 前提是市场出清、价格绝对灵活，劳动供给与劳动需求相交，形成均衡工资 $W^*$ 与均衡就业量 $N_e$。

    * 均衡就业量左侧，需求曲线高于供给曲线，企业愿付工资高于工人要求工资，这段人均可就业。

    * 均衡就业量右侧，供给曲线高于需求曲线，工人要求工资高于企业愿付工资，这段为自愿失业：岗位存在，只是工资达不到其预期。

    * 古典学派只承认自愿失业，把失业归因于工人要价高于均衡工资。

    * 图示：

    ```text
     W
     ^
     |  D \            / S
     |     \          /
     |      \        /
     |       \      /
     |        \    /
     |   W*    \  /        均衡工资
     |          \/
     |          /\
     |         /  \
     +--------------------> N
               N_e
    ```

### 凯恩斯学派

* **工资刚性（wage rigidity）**

    * 市场波动时看不见的手不能完全发挥作用，调节过程很慢，工资回不到 $W^*$，停在更高的 $W^{**}$。

    * 在 $W^{**}$ 上，劳动需求为 $N_1$、劳动供给为 $N_2$，$N_1 < N_2$，二者之间的差额即非自愿失业。

    * 图示：

    ```text
     W
     ^
     |  D \            / S
     |     \          /
     | W**  +--------+       工资停在 W**，高于均衡
     |       \      /
     |        \    /
     |   W*    \  /
     |          \/
     |          /\
     |         /  \
     +--------------------> N
               N1   N2
    ```

* **非自愿失业（involuntary unemployment）**

    * > **定义**：在现行工资水平下愿意接受工作、却仍然找不到工作的失业。

    * 与自愿失业的分界：自愿失业是不想干，非自愿失业是想干却干不了。

    * 工资 $W^{**}$ 下供求双方都接受该价格，但需求只有那么多；供给 10 人而只需 8 人，必有 2 人失业。

    * 成因归于有效需求不足：大冲击使总需求不足，劳动力需求下降，岗位数量不够。

### 两派分歧

* **框架差异**

    * 古典学派以市场出清为前提，价格绝对灵活；凯恩斯以市场不能出清、存在不均衡为前提。

* **归因差异**

    * 古典学派只承认自愿失业，归因于工人要价高于均衡工资；凯恩斯在自愿失业之外承认非自愿失业，归因于有效需求不足。

* **逐项对照**

| 对比项 | 古典学派 | 凯恩斯学派 |
| :--- | :--- | :--- |
| 市场状态 | 市场出清，看不见的手完全发挥作用 | 市场不能出清，存在不均衡 |
| 工资 | 灵活调整，回到均衡工资 $W^*$ | 降不下来，停在 $W^{**}$ |
| 失业类型 | 只有自愿失业 | 自愿失业之外还有非自愿失业 |
| 失业归因 | 工人要价高于均衡工资 | 有效需求不足，岗位不够 |
| 一句话标签 | 均衡、完美 | 萧条 |

## 失业的类型

* **摩擦性失业（frictional unemployment）**

    * > **定义**：从一份工作换到下一份工作需要时间，在这段空窗期内形成的失业。

    * 岗位与劳动者都存在，缺的只是匹配所需的时间。

    * 记忆钩子：空窗期。

* **结构性失业（structural unemployment）**

    * > **定义**：劳动力供给与需求不匹配所造成的失业。

    * 特征是既有失业又有职位空缺，重要来源是工资刚性。

    * 典型情形：新兴产业大量缺人，夕阳行业大量裁人，被裁者不具备新岗位所需技能，岗位在、人也在，但配不上。

    * 一种理解：此类失业集中出现在结构转型时期，从农业到手工业、手工业到工业、工业到信息，故称结构性。

    * 记忆钩子：没能力。

* **周期性失业（cyclical unemployment）**

    * > **定义**：经济周期的衰退与萧条阶段，因需求下降而造成的失业，又称凯恩斯失业。

    * 由整个经济的支出与产出下降造成。

    * 记忆钩子：看到「衰退」「萧条」即对应凯恩斯与周期性失业。

## 奥肯定律

* **奥肯定律（Okun's law）**

    * > **定义**：描述实际产出偏离潜在产出与失业率偏离自然失业率之间反向关系的经验规律。

    * 公式：

    $$\frac{Y-Y_f}{Y_f} = -\alpha(u-u^*)$$

    * $Y$ 为实际产出，$Y_f$ 为潜在产出，$\alpha$ 为大于零的参数，$u$ 为失业率，$u^*$ 为自然失业率。

    * 该式不是推导出来的，而是用 1947 年至 1996 年的数据回归拟合出的数值关系。

* **两条推论**

    * 失业率不变：$u-u^*$ 与 $\alpha$ 均为常数，右边为常数，故左边也须为常数；$Y_f$ 随技术进步与人口增长不断上升，$Y$ 必须与 $Y_f$ 同速增长。

    * 失业率下降：$u-u^*<0$，右边为正，故 $Y-Y_f>0$，实际产出增速须高于潜在产出增速。

    * 只讨论「$u$ 不变」与「$u$ 下降」两个方向，因为该定律是给政策做参考：问的是把失业率按住甚至压下去，产出要跑多快。

    * 题型：名词解释说清它反映哪两个量之间的关系；计算题直接套公式。

## 通货膨胀的定义与衡量

### 定义与价格指数

* **通货膨胀（inflation）**

    * > **定义**：大多数商品和劳务的价格连续在一段时间内普遍上涨的现象。

    * 要件一「连续」：价格上涨须持续一段时间，偶发一次上涨不算。

    * 要件二「普遍」：大多数商品和劳务都在涨，少数几种上涨不算。

    * 两个要件同时满足，才构成通货膨胀。

    * > **易错点**：把单一商品涨价或短期一次性涨价当作通货膨胀。

* **价格指数（price index）**

    * > **定义**：选定一年为基期、把该年价格水平定为 1，其余各年的价格水平与基期相比所得的数值。

    * 指数大于 1 表示相对基期上涨，小于 1 表示相对基期下跌。

    * 衡量通货膨胀主要用消费价格指数（CPI）与生产者价格指数（PPI），另有工业价格指数、投资价格指数等。

    * 具体数值可直接取自统计年鉴的价格指数栏目，不需自行计算。

* **通货膨胀率（inflation rate，$\pi$）**

    * 用价格指数的变动幅度衡量，指数上升即价格水平上涨。

    * 价格指数最早出现在股市，后来才被用于宏观经济与各类产业。

### 三种分类

* **按价格上升速度**

    * 温和的：上涨比较平缓。

    * 奔腾的：上涨比较快。

    * 超级的：快到难以想象的地步。

* **按对不同商品价格的影响**

    * 平衡的：每种商品按相同比例上涨。

    * 非平衡的：各商品各涨各的比例。

* **按人们的预期**

    * 未预期到的：涨幅超出预料，甚至根本没料到会涨。

    * 预期到的：涨幅已被预料到。

    * 并非所有通货膨胀都能被预期到，未预期到的通货膨胀在现实中反而更常见。

## 通货膨胀的成因

* **三条解释路线**

    * 货币数量论路线即货币学派对通货膨胀的解释，强调货币在通货膨胀中的重要性，把通货膨胀视为一种货币现象。

    * 总需求与总供给路线从需求拉动与成本推动两个方向解释物价水平的上涨。

    * 经济结构路线从经济结构因素的变化解释通货膨胀，与前两条路线无关。

* **货币数量论（quantity theory of money）**

    * 基本命题：每一次通货膨胀的背后，都是货币供给的迅速增长。

    * 机理：货币供给大幅增加而货币需求不变，钱变得不值钱，物价随之上涨。

* **费雪方程式（Fisher equation）**

    * 公式：

    $$MV = PY$$

    * $M$ 为货币供给量，$V$ 为货币流通速度，$P$ 为价格水平，$Y$ 为实际收入水平。

    * $V$ 表示同样一笔钱转手了几次；$Y$ 既可叫收入也可叫产出，看作产品数量更直观。

    * 左边 $MV$ 是社会的总支出，右边 $PY$ 是实际产出值多少钱即名义收入，故等式含义为总支出等于名义收入。

    * 例：社会只有 100 元货币且只转手一次，只交换一件价格 100 的商品，则 $100 \times 1 = 100 \times 1$。

* **通货膨胀率表达式**

    * 两边取变化率，$m$ 为货币增长率、$y$ 为产量增长率、$v$ 为流通速度变化率、$\pi$ 为通货膨胀率，得

    $$\pi = m - y + v$$

    * 通常假定 $V$ 不变即 $v=0$，式子简化为 $\pi = m - y$。

    * $m=y$ 时 $\pi=0$，多发行的货币恰好全部转化为产量增加；$m>y$ 时 $\pi>0$，多出的货币未转化为产量，只推高物价；$m<y$ 时物价总体下行，为通货紧缩。

    * 产量增长率 $y$ 视为常数，故 $\pi$ 完全由 $m$ 决定，通货膨胀的根源在货币供给。

* **需求拉动通货膨胀（demand-pull inflation）**

    * > **定义**：总需求超过总供给，把整个社会的物价水平拉高所形成的通货膨胀，又称超额需求通货膨胀。

    * 形象说法「过多的货币追求过少的商品」：需求都要用货币支付，供给是生产出的商品，需求大于供给即货币多、商品少。

    * 商品少而想要的人多，商家提价，出价高者得，物价被推上去。

    * 图形：AD 右移，均衡点沿向右上方倾斜的 AS 从 $A$ 移到 $B$，价格由 $P_1$ 升到 $P_2$，产出由 $Y_1$ 增到 $Y_2$。

    * 需求拉动型通货膨胀往往与经济增长同时出现。

    * > **提示**：答题画 AD-AS 图只画正常区域向右上方倾斜的那一段供给曲线即可，把水平段、正常段、古典段全画上反而容易自乱。

* **成本推动通货膨胀（cost-push inflation）**

    * > **定义**：在没有超额需求的情况下，由供给方成本的提高所引起的一般物价水平持续上涨。

    * 问题出在供给方：原材料、要素、工资等成本上升，生产者不能赔本卖，只能提价弥补。

    * 工资推动：工资上涨使生产者支付的劳动成本增加，产品成本上升，价格随之提高。

    * 利润推动：垄断企业利用市场势力谋取过高利润，导致一般物价水平上涨。

    * 利润推动的主体须有市场势力，能影响甚至控制产量与价格，通常是一家独大。

    * 记法：工资推动看成本，利润推动看垄断。

* **结构性通货膨胀（structural inflation）**

    * > **定义**：既不存在需求拉动、也不存在成本推动，仅由经济结构因素的变化导致价格水平持续、普遍上涨的通货膨胀。

    * 根源：资本与技术在不同部门特征不同，且难以从一个部门顺畅转移到另一个部门。

    * 生产率高的部门往往是新兴产业，其工资先涨；其他部门员工看到后也要求涨薪，有工会时更追求工资平等化，低生产率部门同样要求同步。

    * 全社会工资水平被拉高后，又回到成本推动的渠道，物价随之上升。

## 菲利普斯曲线

### 定义与公式

* **菲利普斯曲线（Phillips curve）**

    * > **定义**：反映失业率与通货膨胀率之间关系的曲线。

    * 最初是根据数据画出的一条经验曲线，没有推导过程，向右下方倾斜：失业率越低，通货膨胀率越高；失业率越高，通货膨胀率越低。

    * 图示：

    ```text
       π
       ^  \
       |   \
       |    \       菲利普斯曲线
       |     \
       |      \
       |       \
       +--------\--------> u
       0        u*
    ```

* **公式与基准点**

    * 公式：

    $$\pi = -a(u-u^*)$$

    * $-a$ 为负数常数，无实际经济含义；$u^*$ 为自然失业率。

    * $u>u^*$ 时 $u-u^*>0$，$\pi<0$，通货膨胀率下降；$u<u^*$ 时 $u-u^*<0$，$\pi>0$，通货膨胀率上升；$u=u^*$ 时 $\pi=0$。

    * $u^*$ 不是装饰，它钉住「失业处于自然率时通货膨胀率为零」这一基准点；写成 $u-u^*$ 而非单独的 $u$，正是为了保留该基准。

    * > **易错点**：$\pi$ 是通货膨胀率而非价格水平，$\pi<0$ 表示价格在下降即通货紧缩，不是价格水平为负。

### 从 AD-AS 推导

* **推导链条**

    * 设 AS 不变、AD 右移，均衡点沿 AS 上移，价格 $P$ 上升，故 $\pi$ 上升。

    * 同一过程中产出 $Y$ 增加；资本 $K$ 不变时 $Y=f(N)$，就业 $N$ 随之增加，失业率 $u$ 下降。

    * $P$ 与 $Y$ 同向变动，$\pi$ 与 $u$ 反向变动，连起来即向右下方倾斜的菲利普斯曲线。

* **记忆要点**

    * $\pi$ 直接看 $P$，$P$ 涨就是通货膨胀。

    * $u$ 不能直接看，须经 $Y \to N \to u$ 三级传导；判断 $u$ 怎么变，看 $Y$ 就够。

    * 固定套路：假设 AS 不变、AD 增加并画图，一头看 $P$ 得 $\pi$，一头看 $Y$ 得 $N$ 再得 $u$，两边一比即得反向关系。

### 传统与附加预期

* **传统菲利普斯曲线**

    * 即 $\pi = -a(u-u^*)$，向右下方倾斜，不分长期短期。

* **附加预期的菲利普斯曲线（expectations-augmented Phillips curve）**

    * > **定义**：在传统菲利普斯曲线左边减去预期通货膨胀率的版本，公式为

    $$\pi-\pi^e=-a(u-u^*)$$

    * $\pi^e$ 为预期通货膨胀率；$\pi-\pi^e$ 衡量预期准不准，其正负决定失业率偏离自然率的方向。

* **类别与长短期**

    * 菲利普斯曲线先分两类：传统菲利普斯曲线与附加预期的菲利普斯曲线；长期、短期之分只在附加预期框架下讨论。

    * 界定的唯一标准是从预期到实际发生之间的时间长短：间隔短为短期，间隔长为长期。

* **考试口径**

    * 题目只说「菲利普斯曲线」或「附加预期的菲利普斯曲线」、未强调长期时，默认写短期那条。

    * 附加预期的菲利普斯曲线与短期菲利普斯曲线在应试口径上是同一条；只有明确说「长期菲利普斯曲线」才写竖线。

    * > **易错点**：题目不特指长期时自作主张写长期曲线；「附加预期」一出现，默认就是短期。

### 预期与实际的三种情形

* **曲线来历**

    * 20 世纪 70 年代石油危机后，美国出现失业率与通货膨胀率同时上升，并向全球蔓延。

    * 1966 年至 1969 年 $\pi$ 与 $u$ 同向上升，呈正相关，传统曲线无法解释；1981 年至 1982 年、1989 年至 1992 年又大致向右下方倾斜，数据看起来时正时负。

    * 弗里德曼指出传统曲线忽略了工人对工资的预期：劳资双方谈新工资协议时会预期协议期内的通货膨胀率，并据以调整名义工资；预期通胀率越高，名义工资涨得越快。

* **预期与实际相等**

    * $\pi=\pi^e$，即 $\pi-\pi^e=0$，由 $-a(u-u^*)=0$ 得 $u=u^*$。

    * 名义工资按预期定下后购买力恰好符合预期，双方都满意，无人新失业，失业率停在自然率。

* **实际通胀高于预期**

    * $\pi>\pi^e$，即 $\pi-\pi^e>0$，得 $u-u^*<0$，即 $u<u^*$。

    * 名义工资按较低预期谈定，实际购买力低于预想，厂商实际用工成本变便宜，扩大生产与雇佣，失业率降到自然率以下。

* **实际通胀低于预期**

    * $\pi<\pi^e$，即 $\pi-\pi^e<0$，得 $u-u^*>0$，即 $u>u^*$。

    * 名义工资按较高预期谈定，实际购买力强于预想，厂商用工成本变贵，减少生产与雇佣，失业率升到自然率以上。

* **共同机理**

    * 合同期内名义工资改不了，先动的是厂商的雇佣量。

    * 工人事后发现买亏或占便宜，会在下一轮谈判中要求调整，预期由此不断被修正。

### 长期菲利普斯曲线

* **垂直的成因**

    * 长期中人们会根据实际发生的情况不断调整预期，时间足够长则预期与实际趋于一致，故长期的前提是 $\pi=\pi^e$。

    * 代入 $\pi-\pi^e=-a(u-u^*)$ 得 $0=-a(u-u^*)$，即 $u=u^*$。

    * 失业率固定在自然率上，不增不减，横轴上落在一个点，故曲线是垂直于 $u^*$ 的直线。

    * 图示：

    ```text
       π
       ^          |
       |          |
       |          |  长期菲利普斯曲线
       |          |
       |          |
       +------------------> u
       0          u*
    ```

    * > **易错点**：教材在竖线之外另画了两条斜线，长期曲线的答案只有垂直于 $u^*$ 的竖线这一种。

* **长期与短期的差别**

    * 长期中预期有足够时间随实际结果反复修正，最终与实际一致；短期中预期来不及充分调整，名义工资由合同锁定。

    * 短期曲线因此可以向右下方倾斜，长期曲线只能垂直于自然失业率。

### 完整框架

* **三类曲线对照**

| 曲线 | 公式 | 图形 | 要点 |
| :--- | :--- | :--- | :--- |
| 传统菲利普斯曲线 | $\pi=-a(u-u^*)$ | 向右下方倾斜 | 不分长期短期 |
| 附加预期（短期） | $\pi-\pi^e=-a(u-u^*)$ | 向右下方倾斜 | 题目不特指长期时默认写此条 |
| 附加预期（长期） | $\pi-\pi^e=-a(u-u^*)$ | 垂直于 $u^*$ | $\pi=\pi^e$，$u=u^*$ |

* **短期图形的边界**

    * 严格说短期曲线画成向右下方还是向右上方倾斜，取决于 $\pi$ 与 $\pi^e$ 的关系；取不同预期下的点连线，可能出现向右上方倾斜的一段。

    * 现实数据里正相关的年份即由此而来；教材只讨论向右下方倾斜这一种，考试也只记这一种。
