## 怎么学

- **按模型链条走**：国民收入核算 → 均衡产出与乘数 → IS-LM → AD-AS 是一条层层嵌套的主线，前面的推导是后面的地基，不要跳着读。
- **图和式子一起记**：IS-LM 与 AD-AS 的每条曲线都有「代数推导 + 图形移动」两个面，笔记里两者并排放，看图忘了式子、看式子忘了图都能互相救。
- **政策效果抓「斜率决定论」**：财政与货币政策谁更有效，取决于 IS 与 LM 的斜率形态，这一条是简答题与选择题的双高频，笔记06 有完整对照。
- **开放经济单独过一遍**：蒙代尔-弗莱明的「一个假设、两条曲线、四种结局」自成一体系，与封闭经济结论容易混，建议用笔记07 隔离复习。
- **考前只看 `notes/`**：8 篇笔记按章主题重组，公式、图形结论、易错点并排放置，适合冲刺期快速过。
