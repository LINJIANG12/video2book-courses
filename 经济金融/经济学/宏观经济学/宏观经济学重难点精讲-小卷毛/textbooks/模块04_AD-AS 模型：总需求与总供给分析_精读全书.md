## 总需求曲线：从 IS-LM 跨到 AD-AS
> 对应块：BLK10 | 覆盖分集：P09 | 块标题（分集名）：《【宏观经济学】第十五章：AD-AS模型（1）：A》

刚把 IS-LM 模型啃下来，翻到第十五章，坐标轴忽然从 r-y 换成了 P-y，曲线名字也从 IS、LM 变成 AD、AS——很多人到这一步会觉得前面白学了，两套图在脑子里打架。这种混乱很正常，因为它俩本来就在回答两个层次不同的问题。这一讲先把这层关系理顺，再专心把 AD 曲线吃透。

### 先把 IS-LM 和 AD-AS 的关系理顺

第十五章讲国民收入的决定，整章三块：总需求曲线，也就是 AD-AS 模型里的 AD；总供给曲线，也就是 AS；等 AD 和 AS 都搞懂了，再把两者合到一起做 AD-AS 分析。这一讲只干第一件事——AD 曲线。

AD 这一块要掌握的东西，归拢起来是四样：含义，总需求曲线到底在描述什么；推导，怎么从别的模型把它推出来；斜率，也就是它为什么向右下方倾斜；移动，什么因素会让整条曲线搬家。

这里有个说法要先对齐：推导和斜率，问的其实是同一件事。书上和题目有时说"推导 AD 曲线"，有时说"解释 AD 曲线的斜率"，落到纸上都是那一问——为什么它向右下方倾斜。答案有三条效应（财富效应、利率效应、汇率效应），另外还可以用 IS-LM 模型推一遍，那是第四条路子。除这几样之外，其他枝节不作为重点。

为什么要先分清 IS-LM 和 AD-AS？因为上一章的讲法是先 IS、后 LM。IS 说的是产品市场达到均衡时，利率 r 和国民收入 y 之间的关系；LM 说的是货币市场达到均衡时，r 和 y 之间的关系。这两句话里反复出现"均衡"，而均衡的定义就是需求等于供给：产品市场上总需求等于总供给，产品市场才均衡；货币市场上货币的总需求等于货币的总供给，货币市场才均衡。

问题就在这儿——上一章是把"总需求等于总供给"当作已知条件直接发给你的。它没让你研究这个总需求、总供给各自是什么、由什么决定、长什么形状，你只要接受"它俩相等"，把产品市场均衡那条线推出来，IS 就学完了。

这一章要做的，恰恰是把那个前提掀开：当产品市场达到均衡时，那个"总需求"和"总供给"到底是什么。总需求就是 AD，总供给就是 AS。这就是两章之间的接口——不是两套互不相干的模型，而是同一个均衡条件的两个层次。

再往下一层，两套模型最大的不同在坐标：IS-LM 研究的是 r 和 y 的关系，AD-AS 研究的是 P 和 y 的关系。记住这一句，两套图就不会再打架。

### 从微观的供求曲线到宏观的总供求

讲需求这件事，你们应该不陌生——微观里从头到尾都在讲它。微观的套路是：价格记作 p，产量记作 q，p 和 q 由供给曲线和需求曲线共同决定。需求曲线 d 向右下方倾斜，供给曲线 s 向右上方倾斜，两条线一交，均衡价格和均衡产量就出来了。

这套道理到了宏观照样成立，变的是对象：微观里供求决定的是个别商品的价格和产量；宏观里供求决定的是整个社会的价格水平和产量。微观盯的是"某一种产品"的需求和供给怎么形成价格，宏观把镜头拉到整个社会。

坐标轴的摆法没变，还是纵轴价格、横轴产量，但有两处必须改口。

第一，横轴要写成 y，不能还写 q。宏观里总产量还有另一个名字——国民收入。为什么总产量能叫国民收入？前面讲国民收入核算的时候说得够清楚了，这里不重复；忘了就回去补一眼，哪怕当时看过、现在又忘了，也回去补。这一步含糊，后面所有曲线都读不顺。

第二，曲线名字前面多一个 A：需求曲线变 AD，供给曲线变 AS。这个 A 不是"全部、所有"这种笼统的说法，是 aggregate，加总、总计的意思——宏观研究的是加总后的量，不是把所有个体简单罗列一遍。所以 AD 就是总需求，AS 就是总供给。

| 对比项 | 微观经济学 | 宏观经济学 |
| :--- | :--- | :--- |
| 供求决定的对象 | 个别商品的价格和产量 | 整个社会的价格水平和产量 |
| 纵轴 | 价格 p | 价格水平 P |
| 横轴 | 产量 q | 产量 y（即国民收入） |
| 需求与供给曲线 | d、s | AD、AS |

把这张表记住，宏观的 AD-AS 图就是微观供求图的放大版——同一套供求逻辑，换了个观察尺度。

### 总需求曲线长什么样

先给定义。

> **定义**：总需求是经济社会对产品和劳务的需求总量，这一需求总量通常以产出水平 y 来表示。

定义里有个容易被忽略的限定：产品和劳务，不包括货币。总需求统计的是社会对最终产品和劳务的需求，不是对货币的需求——货币需求是 LM 曲线那边的事，别混进来。这个概念本身不难，微观里已经把"需求"讲得很透了，这里只是把观察对象从一种商品换成整个社会。

这个需求总量由四部分构成：消费需求 c、投资需求 i、政府需求 g、国外需求（净出口）nx。写成式子就是

$$y = c + i + g + nx$$

AD 曲线上的每一个点，都是某个价格水平下对应的这个需求总量。

图形照微观的规矩摆：纵轴是价格水平 P，横轴是国民收入 y，AD 向右下方倾斜，同一条图上还有一条向右上方倾斜的 AS。

```text
  P
  |           AS
  |          /
  |         /
  |        /
  |   \   /
  |    \ /
  |     X
  |    / \
  |   /   \
  |  /     \   AD
  +-------------- y
```

图里纵轴是价格水平，横轴是国民收入；AD 向右下方倾斜，AS 向右上方倾斜，两条线的交点决定均衡的价格水平与产量。这一讲只负责把 AD 这一条线讲透，AS 那条留到下一讲。

含义和图形都不难，AD 真正的难点不在"它是什么"，而在"它为什么长这个形状"。下面进入正题。

### 向右下方倾斜：三条效应

解释 AD 的斜率，标准答案是三个效应：财富效应、利率效应、汇率效应。书上上的原话写得比较绕，但三条链的结构其实一致——起点都是物价水平 P 下降，终点都是国民收入 y 增加，中间各自绕一个变量。区别只在绕的是谁：财富效应绕消费 c，利率效应绕投资 i，汇率效应绕净出口 nx。

#### 财富效应：走消费这条路

书上的说法是：物价水平下降，提高了货币的真实价值，使消费者变得相对富有，于是鼓励他们更多地支出；支出增加，对产品和劳务的需求量就更大，y 也就增加。翻成因果链就是 P 下降最后落到 y 增加，两者反向变动，所以 AD 向右下方倾斜。

书上这几句话浓缩得太厉害，展开来看其实很朴素。

物价水平下降，也就是 P 下降。假设你拿到手的工资没变——这一点是关键，名义收入不跟着物价一起降——那你这些钱能买到的东西就变多了。举一组具体数字：你每个月挣 3000 元，上个月一件衣服 1000 元，你只能买三件；这个月物价下来了，同样一件衣服变成 100 元，工资还是 3000 元，你就能买三十件。同样是 3000 元，能换回的东西从三件变成三十件。

这个"能换回多少东西"，就是货币的真实价值，写成 W/P：W 是名义货币收入，P 是物价水平。P 下降而 W 不变，W/P 上升，货币的真实价值上升，你手里这点钱变得更值钱了，人就会觉得自己相对富有了。

觉得自己富有了会怎样？更愿意花钱。支出增加，就是消费 c 增加。回到总需求的构成 y = c + i + g + nx，在 i、g、nx 都不变的前提下，c 增加，y 就增加。整条链就闭合了：

```text
  P↓ ──► W/P↑（货币真实价值上升）──► 相对富有 ──► c↑ ──► y↑
```

> **提示**：这条链能成立，靠的是"名义收入不变"这个隐含前提。如果物价下降的同时名义工资按同样幅度下降，W/P 不动，货币的真实价值没变，消费就不会因为"变富"而增加。书上默认短期内名义工资黏住不动，所以这条链才走得通。

落脚点很清楚：财富效应是从消费 c 这一路推出来的。

#### 利率效应：走投资这条路

看到"利率效应"三个字，第一反应应该是对上 i：r 上升，投资减少；r 下降，投资增加。这是投资本来的方向。难的不是这个方向，而是"物价水平怎么就跟利率扯上了"。

书上的说法是：物价水平是货币需求量的一个决定性因素。当物价水平降低时，家庭为了购买想要的物品与劳务需要持有的货币减少，于是家庭会把一些钱借出去，试图减少货币持有量；由于家庭想把货币换成有利息的资产，利率就下降；低利率又使借款变得便宜，投资增加；投资增加，y 增加。拆开就是 P↓ → L↓ → r↓ → i↑ → y↑。

第一步，P 下降为什么让货币需求 L 下降。这里的 L 就是货币需求，讲 LM 的时候拆过：交易性需求、预防性需求、投机性需求，L = L1(y) + L2(r)。物价水平下来了，你应付日常交易、应付突发情况、留着伺机投机，需要用现金撑住的盘子都变小了——手里不需要囤那么多钱，也够应付后面想干的那些事。所以 L 下降。

第二步，也是最容易卡住的一步：L 下降，为什么 r 就下降？

关键是把利率看成货币的价格。你向银行借钱，成本是什么？是你要付给银行的利息，而利息就是利率的体现。所以 r 就是借钱的价格，也就是货币的价格——把钱当成一种商品看，r 就是它的标价。

只要接受"r 是货币的价格"，剩下的事就回到最朴素的道理：物以稀为贵。任何东西，需求少、供给多，也就是供过于求，价格一定往下走，货币也不例外。这里货币需求 L 下降，假设货币供给不变，就是货币的需求小于货币的供给，货币不值钱了，它的价格 r 自然下降。

第三步顺理成章：r 下降，借钱的成本变低，投资 i 增加。回到 y = c + i + g + nx，c 和 g 不变，i 增加，y 增加。

```text
  P↓ ──► L↓ ──► r↓ ──► i↑ ──► y↑
```

> **易错点**：L 下降导致 r 下降，并不是"钱变少了所以变贵了"，恰恰相反——是持币需求变少、货币相对过剩，货币变便宜了。方向别记反：需求下降，价格下降，而货币的价格就是利率。

落脚点：利率效应是从投资 i 这一路推出来的。

#### 汇率效应：走净出口这条路

书上的说法是：当本国物价水平下降时，会引起本国利率下降，本国货币在外汇市场上的真实价值下降，从而增加物品与劳务的需求量，y 增加。

前两步和利率效应完全一样：P 下降，持币需求 L 下降；L 下降，货币的价格 r 下降。这两步上面已经推过，这里不再重复。

新的一步在 r 之后：r 下降，说明本国货币的价格下降了，本国货币在外汇市场上就不那么值钱，也就是本币贬值。本币一贬值，出口就变多。

为什么？拿汇率举例。原先 1 美元换 6 元人民币，现在 1 美元能换 7 元人民币——同样一笔美元能换回更多人民币，说明人民币便宜了、美元贵了。出口商干的是什么？把货卖到国外，收回来的是美元，再拿美元换成本国货币在国内花。假定他出口一批货还是挣 30 美元，按 6 元的汇率能换回 180 元，按 7 元的汇率能换回 210 元。同样一批货，换回的本币变多了，出口当然更划算，出口商更愿意出口，出口就增加。

出口增加、进口不变，净出口 nx 就增加。回到 y = c + i + g + nx，前三个不变，nx 增加，y 增加。

```text
  P↓ ──► L↓ ──► r↓ ──► 本币贬值 ──► 出口↑ ──► nx↑ ──► y↑
```

落脚点：汇率效应是从净出口 nx 这一路推出来的。

三条链摆在一起，结构一目了然：

| 效应 | 传导链 | 落脚的分项 |
| :--- | :--- | :--- |
| 财富效应 | P↓ → W/P↑ → 相对富有 → c↑ | 消费 c |
| 利率效应 | P↓ → L↓ → r↓ → i↑ | 投资 i |
| 汇率效应 | P↓ → L↓ → r↓ → 本币贬值 → 出口↑ → nx↑ | 净出口 nx |

入口都是 P 下降，出口都是 y 增加，所以三条都指向同一个结论：P 和 y 反向变动，AD 向右下方倾斜。它们的差别只在中间绕的是哪个分项，这也是三个效应各自名字的由来。

考试如果问"为什么总需求曲线向右下方倾斜"，把这三条答出来就够了。答题时最好把每条链落到对应的分项上——财富效应落在 c，利率效应落在 i，汇率效应落在 nx——比笼统写一句"物价下降需求增加"要清楚得多。

### 用 IS-LM 再推一遍

除了三条效应，还有一条更模型化的路子：直接拿上一章的 IS-LM 模型把 AD 推出来。这条路在框架图里不一定写，但它是理解 AD 与 IS-LM 关系的最好方式。

做法是给价格水平换两个值，看 IS-LM 的均衡点怎么动。

设价格水平为 P1，此时产品市场和货币市场同时均衡，对应的国民收入是 y1，利率是 r1。先把这一组记下来。

现在让价格下降，从 P1 降到 P2。问题来了：IS 和 LM，哪条线会动？

答案是只有 LM 会动。把两条曲线的式子摆出来就清楚了。IS 曲线的出发点是 y = c + i + g，一路推下去得到 r 和 y 的关系，但式子里从头到尾没有 P。LM 曲线是 L = m = L1(y) + L2(r)，而这个 m 不是名义货币供给，是实际货币供给——我们能统计到的只有名义货币量 M，必须除以价格水平才是实际的购买力，所以 m = M/P，LM 的式子写成

$$L_1(y) + L_2(r) = \frac{M}{P}$$

P 只出现在 LM 里，价格一变，动的只能是 LM，IS 原地不动。

P 从 P1 降到 P2，M/P 变大，实际货币供给增加，LM 向右移动，从 LM(P1) 移到 LM(P2)。IS 不动，新的交点给出 r2 和 y2。

对照两组结果：价格从 P1 降到 P2，国民收入从 y1 变到 y2，而 y2 大于 y1。价格下降，收入上升——P 和 y 反向变动，AD 向右下方倾斜，证完。

```text
  P1  =>  LM(P1) 与 IS 交于 (r1, y1)
   |
   |  P 下降，M/P 上升，LM 右移
   v
  P2  =>  LM(P2) 与 IS 交于 (r2, y2)，且 y2 > y1
   |
   v
  结论：P 下降，y 上升，AD 向右下方倾斜
```

图里 IS 始终不动，只有 LM 因为 M/P 变化而平移；价格下降对应 LM 右移，均衡收入随之变大。把 (P1, y1) 和 (P2, y2) 这两组点画到 P-y 平面上连起来，就是 AD 曲线——所以 AD 上的每一点，背后都站着一个 IS-LM 的均衡。

这条路和三个效应不冲突，它是同一件事的模型版。三个效应回答"为什么降价会让人多买"，IS-LM 回答"在模型里，降价是通过移动哪条线改变均衡收入的"。前者给直觉，后者给结构。

### 曲线移动：只记左右

最后一块是 AD 曲线的移动。AD 的式子摆在这儿：

$$AD = c + i + g + nx$$

凡是能影响 c、i、g、nx 中任何一项的因素，都会让整条 AD 曲线移动。除此之外，货币供给也会移动 AD。所以说"决定因素"和"移动"其实是一回事——问的是同一批变量。

方向很好记：使某一项增加的因素，让 AD 向右移；使它减少的，让 AD 向左移。

```text
  P
  |
  |    AD0      AD1
  |     \        \
  |      \        \
  |       \        \
  |        \        \
  |         \        \
  +---------------------- y
```

同一价格水平下，AD1 对应的收入大于 AD0，这就叫右移；反过来向左，就是需求收缩。

> **注意**：曲线的移动只有左右，没有上下。AD 的纵轴是价格水平，P 的变化是同一条曲线上的"沿线滑动"，不叫移动；只有价格之外的因素变化，才是整条线平移。把"沿曲线变动"和"曲线移动"混在一起，是这一章最常见的失分点。

把这些因素归个类，其实就两类政策。

一切使 c 增加、i 增加、g 增加、nx 增加的因素，统统叫扩张性财政政策。政府减税、增加购买、刺激投资和出口，都会把 AD 往右推。

货币供给增加，叫扩张性货币政策。M 变大，同样的价格水平下 M/P 更大，LM 右移，均衡收入更高，AD 也往右移。

所以一句话收口：扩张性的财政政策和扩张性的货币政策，都使 AD 向右移动。

这一讲真正花力气的地方在中间那块——AD 为什么向右下方倾斜。含义一句话就交代完了，图形看一眼就有，移动记住左右也不难；三条效应加 IS-LM 那条推导，才是这一章反复考、也反复错的地方。把三条链合上书自己能默写出来，AD 这一关就算过了。

## AS 曲线之前的两块地基：生产函数与劳动市场
> 对应块：BLK11 | 覆盖分集：P10 | 块标题（分集名）：《【宏观经济学】第十五章：AD-AS模型（2）：A》

上一讲把总需求曲线讲完了。当时我们反复强调，AD 曲线最要紧的地方在斜率——它为什么向右下方倾斜。解释有三条：财富效应、利率效应、汇率效应；此外还可以从 IS-LM 模型把这条向右下方倾斜的线推出来。AD 这一半交代清楚，这一讲轮到 AS。

但真要动手画 AS 曲线，得先停一步。很多同学一直有个点没弄明白：总供给曲线和劳动市场到底有什么关系？推导总供给曲线的时候，劳动市场怎么就冒出来了，还从头到尾绕着一个 N 转。所以这一讲不碰 AS 曲线本身，只铺它前面的地基：生产函数，加上劳动市场的均衡。这两块理顺了，AS 曲线才学得清楚。

顺便交代一句我每讲开头都要说的话。我先说清楚这一讲讲什么，是让你们自己判断要不要听：听完觉得这块确实不懂、想听，就往下听；觉得自己理解起来没什么问题，这一讲对你就是浪费时间，跳过完全可以。考研时间本来就紧，没必要每一讲都刷一遍，也没必要靠刷课求心理安慰。看多少课和真正掌握多少东西，从来不成正比。

### 总供给为什么要从劳动市场倒推

总供给是什么？在宏观经济学里，总产量和国民收入是同一个东西——最终产品加总起来的总产量，也叫国民收入。如果这一点还有疑问，得回到前面讲国民收入核算的地方去看：为什么总产量也能叫国民收入。总供给通常就用 $Y$ 表示，指的是经济社会投入资本、劳动这些基本资源所生产出来的产量。

> **定义**：总供给是经济中投入各种生产要素所生产的总产量。宏观经济学里总产量与国民收入等价，统一记作 $Y$。

那么，描述总产量和投入要素之间关系的合适工具是什么？生产函数。这里的逻辑要理清楚：我们想研究的是总供给，总供给就是总产量，总产量取决于投入，而刻画投入与产出关系的就是生产函数。所以研究总供给，一路落下去，落到最后就是研究生产函数。

而生产函数里的主角是谁？短期里资本不动，产量就由就业量 $N$ 决定。$N$ 又由谁决定？劳动市场。这条链子画出来是这样：

```text
AD-AS 模型
   ├─ AD 总需求曲线：上一讲已完成
   └─ AS 总供给曲线：这一讲要铺的路
            ↑
      总供给 ≡ 总产量 ≡ 国民收入 Y
            ↑
      生产函数 Y = F(N, K)   其中 K 视为不变
            ↑
      就业量 N
            ↑
      劳动市场：劳动需求 Nd 与劳动供给 Ns 的均衡
```

读图的时候从下往上看，就是这一讲的推进顺序：先把劳动市场讲清楚，就知道就业量 $N$ 是怎么定的；$N$ 定了，生产函数把 $N$ 换算成总产量 $Y$；总产量就是总供给；总供给清楚了，AS 曲线就清楚了。再加上上一讲的 AD，AD-AS 模型的两条腿才算都站稳。

这也是为什么学 AS 的时候会发现满篇都是 $N$——$N$ 是就业量，就业量是劳动市场决定的。劳动市场出现在这里一点都不突兀，它是 AS 曲线之前必须铺好的一块地基。这一讲的内容，说到底是“总供给的一般说明”。

### 生产函数：宏观版只换了两个字母

生产函数我们其实一点都不陌生。微观里整整一章都在讲它，这里只需要把结论捡回来。

#### 短期与长期的分界

微观的短期生产函数假设劳动可变、资本不变。为什么短期里资本不动？因为短期就是这么几天、最多一个礼拜。你想想，给你三天时间，让你一下子多弄出一百万、两百万甚至一千万的资金，很难；可给你三天时间，让你多雇五个人、十个人甚至一百个人，或者裁掉一百个人，都容易得很。所以短期里资本当成不变的，劳动当成可变的。

长期则相反，$K$ 和 $L$ 都可变。长期有多长？没有确切规定，反正就是长到你有足够时间把劳动和资本都调整一遍。

#### 字母换了，逻辑没换

宏观生产函数和微观生产函数，在逻辑和公式上没有大差别，差别只在字母。

第一处，微观用 $Q$ 表示产量，宏观换成 $Y$。原因前面说过：宏观里不爱说“总产量”，爱说“国民收入”，而这两者在宏观里是同一个东西，所以产量就用国民收入的 $Y$ 来表示。

第二处，微观用 $L$ 表示劳动，宏观换成 $N$。至于为什么非得换成 $N$，我也说不清楚，大概是经济学的鼻祖当年就这么定的，后来一直沿用下来。你们记住在宏观里别再用 $L$ 表示劳动力就行，书上怎么写就怎么记，这个真没必要纠结。

> **提示**：宏观的生产函数叫总量生产函数，表示的是总投入与总产出之间的关系，而不是单个厂商的投入产出。字母换了，含义也升了一级。

还有一个问题：投入要素其实有三个——劳动、资本、技术，为什么公式里只写了劳动和资本？技术不重要吗？恰恰相反，技术非常非常重要。不写进去纯粹是为了避免复杂。我们现在学的这些模型，基本都是几百年前就被经济学家推出来的基础模型；技术水平一旦放进公式，那就算扩展的、接近现代的模型了。就像后面要讲的经济增长模型：最基础的索洛模型里不带技术，扩展的索洛模型才把技术水平加进投入要素。现在这个阶段，把古老的传统的东西学懂就够了。

#### 短期生产函数的两条性质

短期宏观生产函数写作：

$$Y = F(N, \bar{K})$$

$\bar{K}$ 上面那一横表示资本不变，技术水平同样假定不变。于是在一定的技术水平和资本存量下，总产量 $Y$ 只取决于就业量 $N$——总产量是就业量的函数，随就业量变化而变化。

它有两条很重要的性质：

第一条，总产量随总就业量的增加而增加；

第二条，边际报酬递减——随着总就业量增加，总产量的增速越来越慢。

```text
  Y
  │                   ____────
  │              ____─
  │          ___─
  │       __─
  │     _─
  │   _─
  │  _
  └───────────────────────── N
  O
```

横轴是就业量 $N$，纵轴是总产量 $Y$。曲线一路向上，说明产量随就业增加而增加；越往右越平，斜率越来越小，这就是增速在放慢。两条性质一张图就说完了。

#### 长期生产函数与潜在产量

长期里 $N$ 和 $K$ 都能变。时间足够长，人口可以增长到充分就业应有的数量，资本也能积累到一个令人满意的存量。说白了，所有投入变量都能调到一个最适合生产的量。

长期宏观生产函数写成：

$$Y_f = F(N^*, K^*)$$

星号表示“最优、最好”：$N^*$ 是充分就业量，$K^*$ 是合适的资本存量。这时的产量 $Y_f$ 就是充分就业时的产量，也叫**潜在产量**。

> **提示**：潜在产量有可能出成一道小概念题，名词解释要写得出：它是各投入要素都达到最优水平、经济处于充分就业时所能生产的产量。

顺便交代一句实情：长期里技术水平其实是可以大幅进步的，能达到一个相当高的水平。但我们这套模型的假设前提就是技术不变，所以公式里始终不出现技术。说清楚这一点，是让你们知道真实世界是什么样，而模型里为什么这么假设。

这一讲只走短期这条线，长期先放一放。短期里 $K$ 不变，产出由 $N$ 决定，于是有一个直接的推论：**总供给主要由总就业水平决定**。问题随之而来——总就业水平又由谁决定？

### 劳动市场：先挑最简单的那个版本

要谈总就业水平，就必须引入另一个市场——劳动市场。这一步在微观里其实已经打过照面。

#### 要素市场与它的四种组合

微观有一章叫要素市场。当时讲得很清楚：要素市场不能单独分析，得和产品市场放在一起，两两组合就得到四种情况——要素市场和产品市场都完全竞争；要素市场完全竞争、产品市场不完全竞争；要素市场不完全竞争、产品市场完全竞争；两边都不完全竞争。

劳动力本身就是一种要素，所以劳动市场是要素市场的一种，同样分完全竞争和不完全竞争两类。

关键在于：不管完全竞争还是不完全竞争，解释就业的逻辑是一样的。

> **结论**：两类市场在解释就业上走的是同一套逻辑，那就挑最简单的那个来用——完全竞争的劳动市场。

劳动市场在我们这里只起桥梁作用。我们不是要研究劳动市场本身，而是要通过它搞清楚就业水平是怎么定的；需求与供给一相交，就业量就出来了。既然逻辑一样，用最省事的版本完全够用。

#### 完全竞争的四个条件

书上给了四条，括号里的解释比条文本身有用：

第一，劳动力要素的供求双方人数都很多。供给方是谁？就是你们，工人；需求方是谁？就是老板，雇主。这句话说白了就是工人很多、老板也很多。

第二，要素之间没有任何区别。工人和工人之间没有差别，技能、品质，任何方面都完全一样，所以老板雇谁都一样。

第三，供求双方都具有完全的信息。工人知道老板的全部情况，老板也知道工人的全部情况。

第四，要素可以充分自由流动。工人可以给这个老板干，也可以给另一个老板干，随时能跳槽。

#### 企业按什么雇人

在这样的市场里，企业只能接受既定的市场工资和产品的市场价格，然后选一个就业水平，使得劳动的边际产量等于实际工资——只有在这个就业水平上，利润才最大：

$$MP_L = \frac{W}{P}$$

这句话很多同学会卡住：为什么偏偏是“边际产量等于实际工资”的时候利润最大？下面先把实际工资和名义工资分开，再分别用公式和账本两种办法把这件事说透。

### 边际产量等于实际工资，利润才最大

#### 名义工资与实际工资

$W$ 单独写出来是名义工资，$W$ 除以价格水平 $P$，得到的 $W/P$ 才是实际工资。

名义工资是面值，就是这张钱上印着多少；实际工资是这些钱能买到多少东西。名义工资用钱衡量，实际工资用物品衡量。

举个例子。你上个月开 3000 块，这个月也开 3000 块，两个月的名义工资一样，都是 3000 元。假设工资全拿去买馒头：上个月馒头 3 块一个，3000 块能买 1000 个；这个月馒头涨到 10 块一个，3000 块只能买 300 个。名义工资一分没少，实际工资却从 1000 个馒头掉到 300 个馒头。

> **易错点**：实际工资一定要除以价格水平 $P$。只盯着 $W$ 的数值，看到名义工资没降就以为购买力没降，是把名义当成了实际。

#### 用公式推一遍

短期生产函数里劳动可变、资本不变。设劳动价格为 $W$、产品价格为 $P$、固定成本为 $TFC$。要求利润最大化，先把利润表示出来。利润记作 $\pi$，等于总收益减去总成本：

$$\pi = TR - TC$$

总收益是卖出去的钱，$TR = P \cdot Q$；总成本分两块——劳动的成本 $W \cdot L$，资本的成本因为资本不变，是固定成本 $TFC$：

$$TC = W \cdot L + TFC$$

于是

$$\pi = P \cdot Q - W \cdot L - TFC$$

想求最大值，对产量求导并令导数为零：

$$\frac{d\pi}{dQ} = P - W \cdot \frac{dL}{dQ} = 0$$

这里的 $\frac{dL}{dQ}$ 看着眼熟吧？讲生产函数那一章见过它，只不过当时是倒过来的 $\frac{dQ}{dL}$——那才是劳动的边际产量 $MP_L$，即每增加一单位劳动投入带来的产量增加。所以

$$\frac{dL}{dQ} = \frac{1}{MP_L}$$

代回去整理：

$$P = \frac{W}{MP_L} \quad \Rightarrow \quad W = P \cdot MP_L \quad \Rightarrow \quad MP_L = \frac{W}{P}$$

证完。利润最大化的条件就是劳动的边际产量等于实际工资。

> **提示**：中间那步求导把 $L$ 看成 $Q$ 的函数，因为产量由劳动投入决定，$Q = F(L)$；所以对 $Q$ 求导时，成本项要按复合函数求导的链式法则带出 $\frac{dL}{dQ}$。这是很基础的数学，这里卡住的话值得回头补一补。

#### 用老板的账本再想一遍

公式之外还有一层更直白的道理。

$MP_L$ 是每多雇一个人多出来的产量，多出来的产量卖掉就是多出来的钱——所以 $MP_L$ 可以理解成老板挣的钱。$W/P$ 是老板付给工人的实际工资——所以它是老板花的钱。利润最大化，就在这两笔钱刚好持平的地方。

| 边际产量与实际工资 | 每多雇一人 | 老板会怎么做 |
| :--- | :--- | :--- |
| $MP_L > W/P$ | 挣的比花的多 | 继续增雇，还能赚 |
| $MP_L < W/P$ | 挣的补不上花的 | 减少雇工，越雇越亏 |
| $MP_L = W/P$ | 收支刚好持平 | 不再增也不再减，利润最大 |

老板一定是追求财富的人。挣的比花的多，他绝不会就此收手，一定继续往里投人；挣的补不上花的，多雇一个亏一个，他一定往回撤。只有两者相等，他才既不增也不减——这就是利润最大化的那个点。

### 劳动需求为什么是实际工资的减函数

书上有一句话，我困惑了很久：

> 由于劳动的边际产量随着劳动投入的增加而降低，所以劳动的需求函数是实际工资的减函数。

前半句说的是边际产量和劳动投入的关系，后半句忽然跳到劳动需求和实际工资的关系，中间那个“所以”是怎么接上的？我一直没找到确切的答案，下面是我自己的理解。

关键在一步转译：把“劳动投入”读成“劳动需求”。老板要劳动力干什么？投到生产里去。所以老板对劳动投入的量，就是他对劳动的需求量。

再串一遍：边际产量 $MP_L$ 随着劳动投入增加而递减，也就是 $MP_L$ 和劳动需求反向；而在利润最大化下 $MP_L$ 又等于实际工资 $W/P$；所以 $W/P$ 和劳动需求也是反向的——实际工资越高，劳动需求越少。这就把“劳动需求函数是实际工资的减函数”接上了。

```text
劳动投入增加
     → 边际产量 MP_L 递减
     → 利润最大化下 MP_L = W/P
     → W/P 与劳动需求反向
     → 劳动需求是实际工资的减函数
```

不过说句实话，翻翻国外的教材，这类话基本一句话带过，人家觉得没什么可解释的。国内教材有个通病：为了显得高大上，把本来很好理解的东西非要复杂化——当然，也可能是我学识太浅薄，实在理解不了那些写法。

从逻辑上讲，“劳动需求是实际工资的减函数”一句话就能说通：劳动需求是老板对劳动力的需求，老板雇人主要看工资。工资低，对老板来说成本低，他就愿意多雇；工资高就少雇，如此而已。

只是这里的工资必须是剔除了价格因素的工资。老板精明得很，他雇人时一定要把通货膨胀、价格因素都刨掉，按实际工资来算。工人也不傻，决定供给多少劳动时，看的同样是实际工资——工人挣钱是要买生活用品的，名义工资只是个面值，实际工资才决定这些钱最终能买到多少东西。

> **结论**：劳动的需求和供给，两边看的都是实际工资。考研层面记住这个结论就够了：劳动需求是实际工资的减函数，劳动供给是实际工资的增函数。

写成函数：

$$N^d = N^d\left(\frac{W}{P}\right), \qquad N^s = N^s\left(\frac{W}{P}\right)$$

$N^d$ 是劳动需求，$N^s$ 是劳动供给，括号里写 $W/P$，意思就是两者都受实际工资影响；方向上，需求是减函数，供给是增函数——工资越高，愿意出来干活的人越多。

### 均衡、充分就业与潜在产量

把两条线画在一张图上：

```text
    W/P
    │        Ns
    │       /
    │      /
    │     ●          ← 均衡点
    │    / \
    │   /   \
    │  /     \   Nd
    │ /       \
    └──────────────── N
```

供给曲线向上，需求曲线向下，两条线一相交，劳动市场就均衡了。交点决定均衡的实际工资和均衡就业量。

关于这个均衡，有两点值得记住。

第一，$N^d = N^s$ 的时候，一定是充分就业状态。需求和供给相等，需要多少劳动力就得到多少劳动力，想工作的人也都工作上了——这不就是充分就业吗。

> **提示**：严格地说，即使存在摩擦性失业和结构性失业，这种状态仍然叫充分就业，这部分后面会详细讲。现在为了好记，就按“供求刚好匹配”来理解。

第二，$N^d = N^s$ 这个式子说明，劳动市场在经济的总供给方面处于主导地位。因为 $K$ 假定不变，影响 $Y$ 的主要是 $N$，而 $N$ 由劳动市场决定——层层往回追，总供给的源头落在劳动市场上。

在价格和工资具有完全伸缩性的情况下，市场会自动调整到 $N^d = N^s$。既然调整到了充分就业，产量就是充分就业时的产量，也就是潜在产量。

> **易错点**：不要把“潜在产量”理解成“有潜力、还没实现”的产量。它就是充分就业状态下生产出来的那个产量——所有投入要素都达到最优水平时的、最好的产量。“潜在”在这里是“最优”的意思，和潜力没什么关系。

最后把这一讲的路再走一遍：总供给就是总产量，总产量用生产函数刻画；短期里资本不变，产量由就业量决定；就业量由劳动市场决定，劳动需求和劳动供给都看实际工资，需求减、供给增，交点就是充分就业；充分就业对应的产量就是潜在产量。把这条链子理顺，下一讲真正画 AS 曲线的时候，才不会晕在满篇的 $N$ 里——$N$ 是就业量，就业量归劳动市场管，这条线必须提前铺好。

> **承前启后**：上一节讲完「AS 曲线之前的两块地基：生产函数与劳动市场」，下一节接着讲「总供给曲线的三种画法：垂直、水平与右上倾斜」。

## 总供给曲线的三种画法：垂直、水平与右上倾斜
> 对应块：BLK12 | 覆盖分集：P11 | 块标题（分集名）：《【宏观经济学】第十五章AD-AS模型（3）：AS》

今天我们继续第 15 章，国民收入的决定，AD-AS 模型。

前面已经把两件事办完了：总需求曲线讲清楚了，总供给曲线里和劳动力市场相联系的那一节也讲清楚了。今天剩下的活，是把总供给曲线的后半截补完——具体三个目标：一是知道什么是古典总供给曲线，二是知道什么是凯恩斯总供给曲线，三是知道什么是正常的总供给曲线，并且能说清楚这条"正常"的、也叫"中间区域"的曲线，为什么是向右上方倾斜的。

三条线共用一套坐标：纵轴是价格 $P$，横轴是产出，也就是国民收入 $Y$。

### 复习一下：总需求曲线只要记两件事

花两分钟把 AD 曲线复盘一遍，因为它的记法和 AS 曲线正好是一对参照。

总需求曲线的内容其实就两点。

第一点，它怎么画。这个简单，只有一种画法：向右下方倾斜，没有第二种可能。

第二点，它为什么向右下方倾斜。三个原因：财富效应、利率效应、汇率效应。真要算上第四个，用 IS-LM 模型也能把 AD 曲线推导出来，但我们主要记的就是前三个。

所以你看，当时学 AD 曲线，学的就是这两个重点——知道它怎么画，知道它为什么这么倾斜，到此为止。现在还没到讲它的移动、讲它的扩展，单纯就这一条线，掌握这些就够了。

### 总供给曲线：先记形状，再解释倾斜

到了 AS 曲线，事情复杂了一档。不是因为它更难懂，而是因为它的图像不唯一——有三种画法。

- **古典总供给曲线**：垂直的。
- **凯恩斯总供给曲线**：水平的。
- **常规（正常）总供给曲线**：向右上方倾斜的。

前两种是极端情况。除了这两种之外的，我们统称为常规，或者叫正常区域。为什么说它们极端？等讲到各自的假设前提你就明白了：一个假设价格和货币工资的伸缩性无限大，想怎么调就怎么调；另一个假设它们根本调不动。一个"完全能"，一个"完全不能"，这可不就是两个极端。

把三条线画在同一张图上，就是完整的总供给曲线：

```text
P │
  │                          │  ← 古典区间：垂直，Y 锁在 Y_f
  │                        ╱
  │                     ╱
  │                  ╱        ← 正常区域：向右上方倾斜
  │               ╱
  │────────────╱
  │  ← 凯恩斯区间：水平
  └──────────────────────────── Y
  0                          Y_f
```

看图记位置：左下那一段水平的是凯恩斯区间，中间上斜的一段是正常区域，右上趋近 $Y_f$ 时立起来变成垂直，那是古典区间。

> **提示**：这里有个很多人第一次学都会卡住的疑问——AS 曲线明明有三种画法，为什么第二个问题只问"为什么向右上方倾斜"？因为解释的重心放在正常区域：现实里绝大多数时候经济处在中间那一段。至于垂直和水平，在讲古典和凯恩斯的时候会顺带把它们各自的道理讲透，三种形状的成因就都交代完了。

### 古典总供给曲线：长期、伸缩性与看不见的手

古典总供给曲线还有另一个名字：长期总供给曲线。它是一条垂直线。这两个名字其实是一回事，讲下来你就知道它为什么又叫长期。

先说"古典"这个名字。这是西方古典学派所支持的一套理论画出来的总供给曲线，学派的名字给了它名字。

古典学派的核心主张，说穿了是经济学里最古老也最核心的那个东西——看不见的手。

具体到工资和价格上，他们的说法是：在长期，货币工资和价格都具有完全的伸缩性，而且这个伸缩性特别强。"伸缩性"三个字听着抽象，意思很朴素：它们能自己调节。社会一旦偏离均衡，通过价格的调整和货币工资的调整，又能回到一个相对均衡、相对稳定的状态。落到劳动力市场上，就是货币工资跟着供求关系走——劳动供过于求，劳动不值钱了，货币工资就下降；供不应求，劳动值钱了，货币工资就上升。而且反应非常敏感，这才叫"完全"伸缩。

换句话说，古典学派相信：即使没有政府干预，这只看不见的手也能让市场在稳定的状态下运行，能自动实现均衡和充分就业。

那"长期"又是怎么回事？因为这种伸缩性有前提——得给足够长的时间。你不可能指望在很短的时间里，价格和货币工资就一步调整到最适合当前经济运行的状态。时间足够长，它们才有足够的时间去调，调到适合均衡的位置。也正因为时间足够长，劳动供给和劳动需求才有足够的时间实现均衡；而劳动供求均衡时形成的就业水平，就叫充分就业；对应的产量，就叫潜在产量——前面讲过，那是最好、最大的那个产量。

> **定义**：古典总供给曲线，是在"长期内货币工资与价格都具有完全伸缩性"这一前提下导出的总供给曲线。因为长期中劳动市场总能回到充分就业、产量总能回到潜在产量，它的图形是一条位于 $Y_f$ 处的垂直线，所以也叫长期总供给曲线。

形状的来历就这么直接。AS 曲线的纵轴是 $P$，横轴是 $Y$。既然就业已经是充分就业、产量已经是潜在产量，两者都到了最优——已经最好，就不可能再好。而 $Y$ 又是由 $N$ 决定的：

$$Y = f(N,\ \bar{K})$$

资本存量 $\bar{K}$ 假设不变，所以 $Y$ 完全跟着 $N$ 走，$N$ 增 $Y$ 增、$N$ 减 $Y$ 减。现在 $N$ 顶在充分就业上，$Y$ 就顶在潜在产量上，不管 $P$ 怎么变，$Y$ 就是那么多。价格再涨，也不会有更多产品被生产出来，因为人和机器都已经用满了。所以是一条垂直线。

这也是上一节要把劳动力市场单独拎出来讲的原因：不把 $N$ 和 $Y$ 的关系先说清楚，这里突然冒出一个 $N$、一个就业，人就被绕晕了。

> **提示**：这一段可以拎成一条线索来记——古典 = 长期 + 看不见的手 + 货币工资和价格完全伸缩 → $N$ 充分就业、$Y$ 潜在产量 → 垂直。

把书上的官方说法再压一遍，它的假设前提就两句，大前提一定要记住：首先是在长期内；其次是价格和货币工资都具有完全的伸缩性。也就是说，货币工资随着劳动力市场供求关系的变化而变化——供过于求时工资下降，供不应求时上升，而且对这种变化反应极其敏感。这是古典学派最基础的一条前提。

### 古典学派的政策含义：需求政策只推高价格

AS 是垂直的，这个结论一画出来，政策含义几乎是自明的。

把 AD 曲线往右推，从 $AD_0$ 移到 $AD_1$——这就是总需求增加的政策。均衡点沿着垂直的 AS 走，从 $AD_0$ 与 AS 的交点挪到 $AD_1$ 与 AS 的交点。看这两个点：变了的只有价格，从 $P_0$ 涨到 $P_1$；没变的是 $Y$，总产出和国民收入一动没动。

> **结论**：在古典学派看来，增加需求的政策并不能改变产量，只能改变价格——说白了，只会造成通货膨胀。

理解这一块最省力的办法，不是背这条结论，而是记住"AS 垂直"这一件事。记住了它，任何政策分析你现画一遍图就想清楚了：需求线怎么挪，交点都只能上下走，横坐标被锁死。

### 凯恩斯总供给曲线：工资刚性与大量失业

先交代背景，再讲假设。凯恩斯为什么不赞同古典学派？

看到不同的学派，你就要知道他们 99% 是对立的；不对立，也没必要另立门户。所以凯恩斯一定是不赞同古典学派的。

原因有两层。一层是他自己就不主张把研究重心放在长期上，这和他的想法有关；更重要的是另一层——凯恩斯所处的那个年代，经济社会里是大量失业人口和过剩的生产能力。一个人的理论，是在他所看到的世界的基础上建立起来的，环境和经历会直接决定他相信什么。

在这样的环境里，古典学派那句"货币工资具有完全伸缩性、可以随便调"就站不住了。凯恩斯提出了工资刚性：货币工资不会轻易变动。

工资为什么不会轻易变？大体三个来源：工会的力量——在西方国家，工会的组织力量非常强大；最低工资法；还有合同。有这些东西在，工资本身就不会轻易动。

对比着记最清楚：古典学派说货币工资可以随便调，具有完全伸缩性；凯恩斯说货币工资有刚性，不会轻易变。一个"能随便动"，一个"动不了"，AS 的形状自然一个竖一个平。

> **定义**：工资刚性，指货币工资不易变动、对劳动市场供求变化反应迟钝的性质。凯恩斯认为这是短期中的常态，也是他的总供给曲线呈水平状的关键假设。

正因为货币工资刚性，凯恩斯的推论是：当产量或者说国民收入 $Y$ 增加的时候，价格和货币工资均不会发生变化。价格水平 $P$ 不动、货币工资 $W$ 也不动，厂商在这个既定价格上愿意供给多少就供给多少——总供给曲线是一条水平线。

这条水平线怎么记？给你一个很土但很好用的记法。

把 $P$ 看成工资水平。在工资只有一点点、或者说不那么高、就停在某个既定水平上的时候，工资并不需要涨、不需要变，产出却可以增加很多。产出凭什么能增加很多？因为愿意就业的人多了。

再往生活里挪一步。想想疫情那几年：很多人失业，找不到工作。这时候有一家公司，只要让你干就行，哪怕给的工资不多，也会有很多人争着抢着去。劳动投入一增加，$Y$ 自然就上去了。

所以凯恩斯这条水平线，你就记成一句话：工资一点点，就有很多人愿意来干，产出 $Y$ 就能往上加。

这背后是有理论条理在的，不是顺口溜。按正常的逻辑，AS 曲线是这么导出来的：

```text
P  ──→  W/P  ──→  N  ──→  Y
价格     实际工资     就业     产出
```

价格 $P$ 先影响实际工资 $W/P$；实际工资直接影响就业 $N$；$N$ 又直接决定产出 $Y$。最后这一步靠的是生产函数——资本存量不变，$Y$ 完全由 $N$ 决定，所以判断 $Y$ 是增是减，全看 $N$。

这条链上有两对"一条绳上的蚂蚱"：

- $P$ 和 $W/P$ 是一对。一般假设名义工资 $W$ 不变，$P$ 一变，$W/P$ 必然跟着变。
- $N$ 和 $Y$ 是一对。$N$ 增 $Y$ 就增，$N$ 减 $Y$ 就减，两个干脆看成一个整体。

各捆成一捆，链条就缩成了两节：$P$（等同于 $W/P$）→ $Y$（等同于 $N$）。

现在代入凯恩斯的假设，做两次替换就出来了。

第一步，"在一个固定的 $P$ 之下，可以有无限大的产出 $Y$"——把 $P$ 换成 $W/P$，就成了"在一定的工资水平之下，会有无限大的产出"。

第二步，再把 $Y$ 换成 $N$，就成了"在一定的工资水平 $W/P$ 之下，有很多人愿意提供劳动，$N$ 可以无穷大"。

$W/P$ 就是实际工资，也就是工资水平。翻译成人话：工资水平不怎么高的时候，就有很多人愿意来就业。失业大军在那里摆着，厂商只要按既定的工资招人，要多少有多少，产出自然可以一路加上去。

所以图像才是水平的：$P$ 不动，$Y$ 可以一直往右延伸。

> **提示**：凯恩斯这条线的大前提，是那个年代的特殊环境——大量失业、大量闲置产能、工资刚性。哪天想不明白，就把疫情那几年的场景调出来对照一遍，比背定义管用。

### 常规总供给曲线：为什么向右上方倾斜

前面两条线都是极端。垂直的那条，假设货币工资和价格水平的弹性无限大，可以随意调整；水平的那条，假设它们完全不能调整。一个"完全能"，一个"完全不能"，而这样的状态是几十年、几百年才可能遇上一次的。

我们生活里绝大多数时候，落在常规情况下。这时候的总供给曲线是一条向右上方倾斜的线：价格水平 $P$ 越高，$Y$ 就越大，经济中的总产出就越多。

对古典和凯恩斯，主要掌握的是图像的形状——你真会把它们的形状画出来，其实就已经掌握了它们为什么这么画。而正常区域，最重要的就是回答一个问题：它为什么向右上方倾斜？

三种解释：工资粘性模型、粘性价格模型（也叫价格粘性模型）、工人错觉模型。

#### 工资粘性模型：工资慢半拍

先看定义。什么叫工资粘性？就是工资被粘住了。粘住了是什么状态？不变，或者变得很慢——被黏住、被拽住了，动起来费劲。

> **定义**：工资粘性，指工资率的变动慢于劳动供求的变动。

正常来说，劳动供小于求，劳动力的价格 $W/P$ 应该上升；劳动供给大于需求，劳动力不值钱，工资应该下降。而且按完美的理论逻辑，只要出现供小于求，$W/P$ 就该马上做出变动，至少不能拖得太晚。

工资粘性强调的恰恰是"慢"：已经供小于求很久了，$W/P$ 可能才慢慢地往上涨。这种迟滞非常强，强到像被黏住一样——工资率不能对劳动供求的变动做出及时而迅速的反应。

反应一慢，就必然留下一段失衡的时间：供求信号早就变了，工资还没跟上。

> **易错点**：工资粘性不是"工资不变"。$W/P$ 不是永远钉在一个定值上，它也会根据供给和需求的关系变动，只不过反应慢半拍。抓住"慢"这个字，不要记成"不动"。

模型的基本假设只有两条：名义工资 $W$ 保持不变；价格水平 $P$ 上升。

链条这么走：

```text
W 不变，P 上升
      ↓
W/P 下降（实际工资下降）
      ↓
企业雇人的劳动成本下降
      ↓
企业愿意多雇人，劳动投入 N 增加
      ↓
产出 Y 增加
```

$W/P$ 是工人的实际工资。$W$ 不动、$P$ 上涨，实际工资就下降；换个说法，老板雇佣工人的成本降低了。成本降了，老板自然愿意多雇一些。劳动投入增加，产出水平 $Y$ 跟着增加。

于是 $P$ 和 $Y$ 之间是同向变动：价格越高，产出越多。这就解释了总供给曲线为什么向右上方倾斜。

这段逻辑也能拆成三幅图来画：第一幅是 $P$ 与 $W/P$，价格上升、实际工资下降；第二幅是 $W/P$ 与劳动投入，实际工资越低，企业雇的人越多；第三幅是 $P$ 与 $Y$，两者同向。三幅图首尾相接拼起来，就是一条向右上方倾斜的 AS。

#### 粘性价格模型：合同与菜单成本

工资会粘，价格也会粘。粘性价格模型的假设是：相对于需求的变化，企业并不会立即调整产品的价格。

工资为什么粘？合同、工资法、工会。价格为什么粘？首先是企业和客户之间的长期合同——合同已经签好了，哪怕你现在本该降价或者涨价，也改不了；硬改就是违约。其次，即使客户和企业之间没有正式协议，企业为了自己的诚信，或者为了避免价格变动带来的各种麻烦，也会尽量让产品价格稳定。

经济学家为此提出了一个概念：菜单成本。

> **定义**：菜单成本，指改变一个既定价格所要付出的高昂代价。饭馆改价要重印菜单，企业调价要改标价、通知客户、重做系统，这些都是代价。代价一高，干脆就不改了——价格于是粘住。

只要"变得慢"，中间就留出一段空档，就会出现失衡，这和工资粘性是完全同一个道理。工资粘性是说工资变得慢，价格粘性是说价格变得慢。

这个模型还有一段形式化推导，我觉得不难，你们自己看就能看懂，这里就不展开了。

#### 工人错觉模型：只盯名义工资

工人错觉模型和工资粘性模型的逻辑是一样的，区别在视角：工资粘性是从企业那一侧、也就是劳动需求的角度说的；工人错觉是从工人那一侧、也就是劳动供给的角度说的。不管从哪边切入，最后都落到 $P$ 和 $Y$ 的同向变动上，所以这两个模型不用在细节上分得特别清。

那什么叫工人错觉？说得直白一点：工人在这件事上比较"傻"，他只看名义工资。

比如上个月开 3000 块，这个月开 4000 块，名义工资涨了，他很开心，觉得日子好起来了。可他没有算通货膨胀：上个月的 3000 块也许还能买一件衣服，这个月的 4000 块连半件都买不上。名义工资确实比上个月多，能买到的东西却远不如上个月。

> **定义**：工人错觉，指工人只关注名义工资、忽略价格水平变动，把名义工资的上涨误当成实际工资（生活水平）的提高。

生活水平到底有没有提高，要看这笔钱能买多少东西，要看的是实际工资 $W/P$。但工人不往这层想，他只在乎名义工资——错觉就出在这里。

推一遍逻辑。物价上涨，名义工资也跟着涨：老板这种物种，不会无缘无故给你加工资，涨工资的原因只能是整个物价也涨了。关键在于，名义工资上涨的幅度小于价格上涨的幅度。两个一除，实际工资不升反降。

实际工资降了，等于企业的用工成本降了，企业愿意多雇人，劳动需求增加；工人这头被名义工资骗着，觉得工资涨了、值得多干，也愿意多提供劳动。两边一凑，就业 $N$ 增加；$N$ 一增，$Y$ 也跟着增。最后还是 $P$ 与 $Y$ 同向：价格越高，产出越多。

到这里，正常区域为什么向右上方倾斜就解释完了。

### 两条线各自要掌握什么

AD 和 AS 两条线单独讲完了，下一节要把它们合起来，讲 AD-AS 模型。合之前先把清单过一遍。

总需求曲线两个知识点：图像怎么画（只有一种，向右下方倾斜），以及为什么向右下方倾斜（财富效应、利率效应、汇率效应）。就这一条线而言，掌握这些就够了。

总供给曲线也是两个知识点，但每个都比 AD 重一些：图像怎么画（三种画法都要会），以及正常区域为什么向右上方倾斜（三个模型）。

三条曲线并排看：

| 曲线 | 关键假设 | 图形 | 对应区间 |
| :--- | :--- | :--- | :--- |
| 古典总供给曲线 | 长期内货币工资与价格完全伸缩 | 垂直，$Y$ 锁在 $Y_f$ | 长期、充分就业 |
| 凯恩斯总供给曲线 | 货币工资刚性，存在大量失业与过剩产能 | 水平 | 短期、萧条 |
| 常规总供给曲线 | 工资粘性、价格粘性或工人错觉 | 向右上方倾斜 | 中间区域 |

三个模型并排看，抓住"粘"字就够：什么粘性，就是什么变得慢——工资粘性是工资变得慢，价格粘性是价格变得慢；工人错觉则是工人盯着名义工资，把账算错了。三个模型讲的是同一件事的三个入口：$P$ 一变，$W/P$ 或相对价格跟着变，企业的用工成本和定价、工人的判断跟着变，$N$ 变，$Y$ 变，于是 $P$ 和 $Y$ 同向。

## 把 AD 和 AS 放进同一个坐标系
> 对应块：BLK13 | 覆盖分集：P12 | 块标题（分集名）：《【宏观经济学】第十五章：AD-AS模型（4）：A》

前面几节，AD 曲线和 AS 曲线是分开讲的。回过头看，AD 曲线的重点其实只有一个：它为什么向右下方倾斜。AS 曲线要麻烦一些，一来它多引进了一个市场——劳动力市场；二来它的画法不止一种，而是三种：水平的凯恩斯区域、向右上方倾斜的正常区域、垂直的古典区域，其中要重点掌握的是正常区域为什么向右上方倾斜。

现在把这两条曲线放进同一个坐标系，让它们相交，AD-AS 模型就搭起来了。这也是国民收入决定这一章的最后一节。这一节要讲的东西，说到底就两个字：移动。哪些因素能让 AD 曲线移动，哪些因素能让 AS 曲线移动，两条线一起移动又会移动出什么局面——把这几件事捋清楚，这一章就算学完了。

### 模型里为什么画三条线

先认符号。AD 是总需求曲线；SRAS 是短期总供给曲线，对应讲 AS 时那条向右上方倾斜的正常区域；LRAS 是长期总供给曲线，对应古典区域那条垂直线。

疑问马上就来了：讲 AS 的时候明明有三种画法，跟 AD 结合的时候，凭什么只用正常区域这一种？

答案不复杂——构建模型的时候，AD 和正常区域的 SRAS 相交，这个组合才叫 AD-AS 模型。水平的凯恩斯区域不参与建模。

第二个疑问紧跟着：既然只用正常区域，图上为什么还要多画一条垂直的 LRAS？

因为古典区域还有另一个名字，叫长期总供给曲线。它表示的是一种最理想的状态：就业是充分就业，产出是潜在产出，社会上所有指标都达到了最好的水平。既然它代表"最好"，那它就可以当一把尺子——短期均衡点落在它上面、左边还是右边，直接决定这个均衡点是好的、差的，还是好过头了。

> **提示**：总需求曲线从来不区分长期短期。它不管在长期还是短期，都只有向右下方倾斜这一种画法，没有区分的必要。供给曲线不一样，必须说清楚是短期还是长期：短期是向右上方倾斜的正常区域，长期是垂直的古典区域。

还有一句要提前交代：凯恩斯区域那条水平线，在后面的均衡分析里百分之百用不到。它只在回答"AS 曲线有几种画法"的时候出场。所以千万别把三种画法当成三种分析工具——分析时真正要盯住的，只有正常区域的 SRAS 和古典区域的 LRAS，把这两条线搞清楚就够了。

判断一个均衡点的好坏，固定两步：

1. 让 AD 与 SRAS 相交，得到短期均衡点；
2. 把这个点拿去和 LRAS 比，看它落在线的哪一边。

```text
      P
      ↑
      |                  LRAS
      |                   |
      |  AD               |              SRAS
      |   \               |              /
      |    \              |             /
      |     \             |            /
      |      \            |           /
      |       \           |          /
      |        \          |         /
      |         \         |        /
      |          \        |       /
      |           \       |      /
      |            \      |     /
      |             \     |    /
      |              \    |   /
      |               \   |  /
      |                \  | /
      |                 \ |/
      |                  \|/
      |                   *   ← 短期均衡点正好落在 LRAS 上
      |                   |
      +-------------------+-----------→ Y
      0                   Yf
```

读图说明：横轴是产出 $Y$，纵轴是价格 $P$；向右下方倾斜的 AD 与向右上方倾斜的 SRAS 相交，交点正好压在垂直的 LRAS 上。这个交点就是短期均衡点，而 LRAS 是那把用来判断好坏的尺子——交点偏到它左边或右边，结论就完全不同。

### 短期均衡与长期均衡的三种关系

短期均衡点找出来只是第一步，它本身说明不了好坏。真正的判断在第二步：拿它和 LRAS 比。一比，只有三种可能，而这三种可能，就是 AD-AS 模型的三种均衡状态。

#### 正好落在长期总供给曲线上

短期均衡点不偏不倚压在 LRAS 上。这条线上对应的就业是充分就业、产出是潜在产出，所以这个点既满足短期均衡，又满足长期均衡——短期之内形成的均衡，放到长期看依然是均衡。这是最好的一个点，短期和长期在这里握手言和。

不过要有个心理准备：这种状态一定存在，但它往往是少数。太完美的状态不会天天出现。

#### 落在左边：失业均衡

短期均衡点落在 LRAS 左侧。LRAS 上那个 $Y_f$ 才是充分就业、潜在产出对应的产出水平，而这个点比它小：就业没有达到充分就业，产出也没有达到潜在产出。这种均衡叫失业均衡——离最好还差一截。

#### 落在右边：超充分就业均衡

短期均衡点落在 LRAS 右侧。它对应的产出比潜在产出还高，用大白话说就是"比最好还好"。这种均衡叫超充分就业均衡。

现实生活里这个点是不是真实存在，可以先放一边；理论分析中它一定算一种状态。

```text
                    LRAS
                      |
   -------------------+-------------------> Y
                     Yf
```

读图说明：LRAS 把横轴切成两段。均衡点落在线上，是充分就业均衡；落在左边，是失业均衡；落在右边，是超充分就业均衡。判断只看相对位置，不看别的。

三种关系归拢成一张表：

| 短期均衡点与 LRAS 的相对位置 | 名称 | 状态含义 |
| :--- | :--- | :--- |
| 恰好落在线上 | 充分就业均衡 | 既是短期均衡，又是长期均衡 |
| 落在线的左边 | 失业均衡 | 未达充分就业，产出低于潜在产出 |
| 落在线的右边 | 超充分就业均衡 | 超过充分就业，产出高于潜在产出 |

> **易错点**：AD-AS 模型有三种画法，不是因为 AS 有三种画法。很多人一看 AS 有水平、向右上方倾斜、垂直三种，就顺推出"AD-AS 模型也有对应的三种画法"，这个推理是错的。模型之所以有三种形态，是因为短期均衡和长期均衡的关系有三种。

这也正是考试常问的地方：短期均衡和长期均衡是什么关系？AD-AS 模型可能达到几种均衡状态？答案都是三种。

### 那条垂直线凭什么当标杆

有人会卡在这里：凭什么说 LRAS 表示的就业最好、产量也最好？

先看形状。LRAS 是垂直的，意思是无论价格 $P$ 多大、怎么变，$Y$ 都不动，就固定在那里。价格涨也好、跌也好，产出不为所动——说明这个 $Y$ 已经是最大值，不会再随价格改变。$Y$ 是产出，所以这个点上的产出就是潜在产出。

再看就业为什么也是最好的。产出是这么来的：

$$Y=f(N,K)$$

其中 $N$ 是劳动力，也就是就业量；$K$ 是资本，前面一直假设它不变。既然 $K$ 没有话语权，$Y$ 就完全由 $N$ 决定：$N$ 怎么样，$Y$ 就怎么样。

所以 $Y$ 和 $N$ 是一条绳上的蚂蚱，在整个宏观经济学里基本可以当成同一个东西来看。$Y$ 是最好的，$N$ 自然也是最好的——所有人都就业了，这就是充分就业。

> **结论**：LRAS 垂直，所以它对应产出最大；产出又由就业决定，所以它同时对应充分就业。两个"最好"说的是同一个点。

这一段前面讲过，这里再啰嗦一遍，是因为后面判断失业、判断衰退全都要用到它。

### 冲击就是移动

经济波动还有一个更洋气的名字，叫冲击。冲击是什么？冲击就是移动。需求冲击就是需求曲线移动，也就是 AD 移动；供给冲击就是供给曲线移动，也就是 AS 移动。看到"冲击"两个字不必紧张，它的小名就叫移动。

光知道线动了还不够，要知道它动完之后会造成什么后果。常见的后果主要有三种。

第一种，失业和衰退。失业是 $N$ 减少，衰退是 $Y$ 减少。为什么把这两件事当成一件？还是那个式子：$Y=f(N,K)$，$K$ 不变，$Y$ 由 $N$ 决定，$N$ 减少，$Y$ 就减少。所以在图像上，只画 $Y$ 减少就够了。

这里多说一句：图像横轴是 $Y$、纵轴是 $P$，从头到尾没有 $N$ 的位置。$N$ 是背后的桥梁，台面上光鲜亮丽的指标都让 $Y$ 代表了，$N$ 从来没有抛头露面过。所以答题时也很少说"$N$ 怎么样"，一律用 $Y$ 来说——但心里要清楚，两者的变化完全同步。

第二种，通货膨胀。物价在短时间内大幅上涨，并且持续一段时间，就是通货膨胀，落到图上就是 $P$ 增加。判断通货膨胀，不用管 $Y$ 是增是减：$Y$ 增加、$P$ 也增加，叫通货膨胀，只不过是在经济增长的同时发生了通胀；$Y$ 减少、$P$ 增加，也叫通货膨胀，只不过这时候很惨，一边通胀一边衰退。

第三种，最惨的一种：$P$ 增加的同时 $Y$ 减少。物价上涨、经济衰退，两样占全。

判断规则可以压成两句话：

> **结论**：只要 $Y$ 减少，就一定有失业或衰退，不用管 $P$ 怎么变；只要 $P$ 增加，就一定是通货膨胀，不用管 $Y$ 怎么变。两句话同时踩中，就是最惨的那种。

你可能发现了，这里只列坏情况，经济增长这种好事一句没提。不是漏了——教材分析和考试出题，主要就是这几种。我们分析的都是"什么时候会失业""什么时候会衰退""什么时候通胀""什么时候最惨"，好的情况轮不到被分析。说到底，宏观经济学的"问题"，本来就是专门说不好的事情。

### 短期影响：谁变谁动

后果分两层：短期影响和长期影响。

短期影响的定义特别简单：谁变就谁动，另一条线不变，也不跟着做出反应。

比如总需求减少，AD 向左移，那它就向左移，动完就完了，AS 待在原地不动。按道理，市场机制这只看不见的手会自动调节，AD 变了，AS 迟早要跟着反应；但现在研究的是短期——太短了，看不见的手还没来得及调整。所以题目说谁变，就只让谁变。

#### 总需求左移

AD 左移，AS 不动。新的交点相对原交点：$P$ 下降，$Y$ 下降。$Y$ 下降意味着失业或衰退。$P$ 也降了，但按前面的规矩，$P$ 下降本身不是要报告的问题，所以结论写"失业与衰退"就够了。

#### 总需求右移

AD 右移，AS 不动。新交点：$P$ 上升，$Y$ 上升。$Y$ 上升是经济增长，是好事，不去提它；$P$ 上升是通货膨胀，这个要写下来。所以这一格的结论是通货膨胀。

"宏观经济的问题"只记问题，经济增长这种好消息不用专门表扬。

#### 总供给左移

AS 左移，AD 不动。新交点：$P$ 上升，$Y$ 下降。两样都踩中——既通货膨胀，又经济衰退。这就是前面说的最惨的那一种。

| 冲击 | $P$ 的变化 | $Y$ 的变化 | 对应后果 |
| :--- | :--- | :--- | :--- |
| AD 左移 | 下降 | 减少 | 失业与衰退 |
| AD 右移 | 上升 | 增加 | 通货膨胀 |
| AS 左移 | 上升 | 减少 | 通货膨胀叠加衰退 |

> **提示**：短期影响唯一容易错的地方，不是判断 $P$ 和 $Y$ 怎么变，而是忘了"另一条线不能动"。很多同学知道曲线怎么移会带来什么结果，却分不清短期和长期差在哪——差别就在这：短期是题目让谁变谁才变，另一条线不作出反应。

### 长期影响：看不见的手把经济拉回标杆

长期影响和短期影响的差别只有一句话：一条线变动之后，另一条线也要随之做出反应，最终回到长期均衡点上。

短期为什么不动？因为时间太短，看不见的手来不及大展身手。长期为什么一定会动？因为时间够长，市场自我调节机制总要发挥作用。

拿感冒打个比方。刚开始感冒、流鼻涕，这一两个小时里，免疫系统就算想调节也调节不过来，你就是感冒了——这是短期。但身体不会眼睁睁看着你一直感冒下去，免疫系统一定会自我调节，最后不管它怎么调，总会把你送回原来那个健康状态——这是长期。

回到图上。最初是一个漂亮的均衡：AD₁ 与 SRAS₁ 的交点 a 恰好落在 LRAS 上，充分就业、潜在产出，各项指标都是最好。

然后假设战争爆发，社会总需求下降，AD₁ 左移到 AD₂。

第一步先看短期：SRAS 不动，均衡点从 a 移到 b。b 在 LRAS 左边，是失业均衡——$Y$ 下降，叫失业也好、叫衰退也好，总之不理想。这个阶段看不见的手发挥不了作用，只能眼看着 $Y$ 从 $Y_f$ 掉到 $Y_2$。

但看不见的手慢慢反应过来了。它是什么？就是市场自我调节机制：市场上是各种各样的消费者和厂商，经济一冷，每个人自己就能感受到变化，然后自己做出调整。

经济冷到什么程度？工作非常不好找，能有一份工作就不错了，还要什么自行车——所以工人愿意接受很低的工资。企业也一样，东西卖不动，愿意低价出售商品。

工资和价格一降，同样一份钱能雇到更多的人，同样一个价格下厂商能生产出更多的商品。以前这个价格可能只雇得起五个人，现在能雇十个；以前这个价格只能生产十件，现在能生产二十件——这就是供给增加，SRAS 向右移，从 SRAS₁ 移到 SRAS₂。

移到哪里才停？移到 SRAS₂ 与 AD₂ 的交点重新落回 LRAS 为止。这个新交点 c 又回到了标杆上：充分就业回来了，潜在产出也回来了。市场自我调节机制完成了目的，也就不再推动 AS 了。

```text
  初始长期均衡 a
  AD₁ 与 SRAS₁ 的交点，恰好落在 LRAS 上
        │
        │  总需求下降（战争爆发）：AD₁ 左移到 AD₂
        ▼
  短期均衡 b
  AD₂ 与 SRAS₁ 的交点，落在 LRAS 左边 → 失业与衰退
        │
        │  工资与价格下调：SRAS₁ 右移到 SRAS₂
        ▼
  新的长期均衡 c
  AD₂ 与 SRAS₂ 的交点，重新落回 LRAS：Y 回到 Yf，P 更低
```

读图说明：整条链路是"冲击—短期失衡—长期回归"。a 到 b 这一段，只有 AD 在动，SRAS 不动；b 到 c 这一段，轮到 SRAS 动，AD 停在 AD₂ 上。最终 c 与 a 在同一根垂直线上，$Y$ 一样，$P$ 更低。

这里有个细节要交代：没法判断 SRAS 是不是一次就移到 SRAS₂，只能确定它一定向右移，并且会一直移到均衡点重新落回 LRAS 才停下。

还有个疑问：$Y$ 是回来了，可 $P$ 回不去了，甚至比原来更低。这不要紧。判断经济有没有恢复，只看 $Y$——$Y$ 回来了就算回来了。$P$ 要回到原位需要时间，不可能所有指标一下子全复原，先让一个指标回来，另一个慢慢来。

也正因为如此，现实里政府不会看着这种状态不管，它一定会出手，想办法让 $P$ 也快点回到原来的水平。这是后话，理论讲到这里就够用了。

### 把时间放进来：标杆自己也会移动

前面讲的短期也好、长期也好，都还是静态的 AD-AS 模型——没有把时间因素放进去。所谓"长期"，其实还不够长。

把时间因素引进来，情况就变了。随着时间的推移，人口会增加，社会财富会增加，技术水平也会提高。落到生产上就是三件事：劳动力增加、资本增加、技术提高。

这三样一增加，潜在产出就增加。潜在产出是什么？是这个社会拼尽全力能生产出来的最大量。

打个具体的比方。假设去年全社会只有十个劳动力、五万块资本，技术水平记作 0.1，往死了生产、拼死生产，最多能生产十件商品。好多年过去，社会上变成一百个人、十万块资本，技术水平到了 0.2——这是绝对量的增长。这时候再拼一把，可能就能生产五十件商品。同样一个社会，最大产量从十件变成五十件，潜在产出增加了。

潜在产出增加，LRAS 一定右移：标杆自己往前挪了。同样的道理，SRAS 也会右移；大家手里都有钱了，AD 也会右移。

所以什么叫考虑时间因素的 AD-AS 模型？一句话：这个社会绝对的产出能力提高了，短期总供给、长期总供给、总需求，三条线一起增加，没有一个东西是固定的。

和不考虑时间因素的模型对比一下就清楚了：

- 静态模型里，不管 AD 怎么折腾、AS 怎么折腾，最后都要和那条不动的 LRAS 比；
- 考虑时间因素后，AD、AS 照样折腾，但 LRAS 这个标杆自己也变了——整个社会的标准更高了，能生产出来的最大值增加了。

### 这一章到底要记住什么

AD 曲线只有一个重点：它为什么向右下方倾斜。

AS 曲线有两个重点：一是它有几种画法——水平、向右上方倾斜、垂直；二是正常区域为什么向右上方倾斜。

把两条线合起来就是 AD-AS 模型，模型讲的是移动，也就是冲击。移动分三层：

- 短期：题目说谁变谁就变，另一条线不动，因为看不见的手还没来得及调节；
- 长期：另一条线随之反应，最终把均衡点拉回 LRAS；
- 考虑时间因素：连标杆本身都移动了，整个社会的最大产出水平提高了。

除此之外还有一个更基础的东西必须掌握：短期均衡和长期均衡的三种关系。先找短期均衡点，再拿它和 LRAS 比——落在线上是充分就业均衡，落在左边是失业均衡，落在右边是超充分就业均衡。

| 情形 | 谁会移动 | LRAS 这根标杆 |
| :--- | :--- | :--- |
| 短期影响 | 题目指定的一条线，另一条不动 | 不动 |
| 长期影响 | 另一条线随之调整，直到均衡点回到 LRAS | 不动 |
| 考虑时间因素 | 三条线全都移动 | 自己也在右移 |
