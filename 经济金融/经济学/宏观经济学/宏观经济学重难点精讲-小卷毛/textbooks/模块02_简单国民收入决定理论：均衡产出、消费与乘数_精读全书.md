## 均衡产出：国民收入是怎么被定下来的
> 对应块：BLK02 | 覆盖分集：P02 | 块标题（分集名）：《【宏观经济学】第十三章：国民收入的决定（1）：均》

### 从核算到决定：这一章要回答什么

上一章讲的是国民收入核算，这一章讲国民收入的决定。两个词只差一个字，问的却是两件事：核算回答"过去这一年，这个国家一共生产了多少、收入了多少"，是事后记账；决定回答"这个经济社会里的生产和收入，究竟由什么定下来"。

先把名字拆开。国民收入的决定，说白了就是讨论国民收入是怎么决定的——这个经济社会当中的生产和收入是怎样决定的，或者更直接一点：这个 $y$ 是怎么决定的。

在宏观里一提到 $y$，你就要立刻反应过来：它既表示总产出，也表示总收入。这不是两个东西碰巧共用一个字母，后面你会看到，生产出来多少和收入多少，本来就是同一件事的两个侧面。

这一章正式的名字叫简单的国民收入决定理论，知识点是这几个：

- 均衡产出；
- 凯恩斯的消费理论；
- 关于消费函数的其他理论，也就是凯恩斯之外的其他经济学家对消费函数的理解；
- 国民收入的决定，按两部门、三部门、四部门分别讨论；
- 乘数的含义和概念；
- 节俭的悖论。

这一讲只讲第一个：均衡产出。

顺便说一句，学每一章之前先弄清楚这一章到底要讲什么，比上来就背公式重要得多。很多人觉得某一章难，其实不是知识点本身难，是从头到尾都不知道这一章在干什么。

### 总需求与总供给：先把方向搞对

学宏观，有一组概念必须先分清，而且我敢说很多人一直没真正搞清楚：什么是总需求，什么是总供给。

讨论这两个概念之前，得先有假设前提。一般来说我们以两个部门为假设；如果超过两个部门，题目条件里一定会告诉你。

两个部门里，家庭只干两件事：消费、储蓄。企业也只干两件事：投资、生产。

在这个前提下：

- 总需求 = 居民的消费 + 企业的投资；
- 总供给 = 居民的储蓄 + 企业的生产。

这两个式子大多数人背得出来，但不知道为什么要这么写。你画一个框框就明白了。

#### 画一个框框当市场

把框框当成市场。注意前提：只有两个部门，而且是简单的宏观经济。

总需求问的是：市场里这些东西，谁需要它？

居民消费需要——消费就是消费市场里的东西。企业投资也需要——投资要买设备、建厂房，买的还是市场里的东西。所以需要市场里这些东西的，就是居民消费加上企业投资，这就是总需求。

总供给问的是另一句：谁愿意把东西提供到市场里？

企业生产出来的产品提供到市场，这是企业的供给。居民呢？居民把自己兜里的钱拿出来放到市场当中，这叫储蓄，也是给市场提供了一样东西。所以总供给 = 居民储蓄 + 企业生产。

拆开看，需求侧和供给侧各问一句话，各自对应两件事：

```text
[ 市 场 ]

需求侧：谁需要市场里的东西
  ├── 家庭 —— 消费 C
  └── 企业 —— 投资 I
      → 总需求 = C + I

供给侧：谁往市场里放东西
  ├── 家庭 —— 储蓄 S
  └── 企业 —— 生产
      → 总供给 = S + 生产
```

图里"生产"指的是企业投放到产品市场上的产出，它的价值量就是整个经济的收入——这一点下一小节马上要用到。

> **提示**：这一块之所以有人一直绕不过来，不是式子记不住，是方向没搞懂。总需求是"谁需要市场里的东西"，总供给是"谁愿意把东西提供到市场里"。方向对了，这两个式子根本不用背。

#### 事前是供给与需求，事后是收入与支出

在宏观里，总需求还有一个名字叫支出，总供给还有一个名字叫收入。这就是为什么 $y$ 一会儿被叫成总产出、一会儿又被叫成总收入，把人搞懵。

先看总供给为什么也叫总收入。事前看，居民储蓄和企业生产是把东西往市场里放，给市场提供东西，这个角度叫总供给。事后看，他们都往市场里提供东西了，市场平白无故增添了很多东西，用钱来算，这不就是市场新增的收入吗？

总需求为什么也叫总支出，道理一样。事前看，居民需要消费市场里的东西，企业投资也需要市场里的东西。事后看，他们既然需要，能白白把这些东西拿走吗？不可以，他们必须支出。所以总需求换一个角度说，就是总支出。

| 视角 | 需求侧 | 供给侧 |
| :--- | :--- | :--- |
| 事前（打算） | 总需求：居民消费 + 企业投资 | 总供给：居民储蓄 + 企业生产 |
| 事后（核算） | 总支出：要拿到东西就得付钱 | 总收入：市场新增的价值 |

> **结论**：总需求 = 总支出，总供给 = 总收入。这两组别名不是文字游戏，是同一件事在事前和事后两个时点上的两种叫法。

这些最基本的概念关系必须先理清楚，后面的宏观才学得下去。$y$ 的双重身份，根子就在这里。

### 四个市场，这一章只研究产品市场

凯恩斯是现代宏观经济学的奠基人，他的学说的中心内容就是国民收入均衡决定理论。他的全部理论涉及四个市场：产品市场、货币市场、劳动市场、国际市场。

我们这一章研究的是简单的国民收入决定理论——只研究这四个市场当中的产品市场。所以这一章不要想太多，把产品市场了解清楚就够了。它还有一个名字，叫国民收入决定的收入支出模型。

这里多说几句，关于宏观为什么难学。

宏观太大了。正常意义上的宏观，四个市场都要研究，而且一提宏观，这四个市场就得紧密联系在一起。你学不懂的时候想找一个具体例子套一下，发现找不到——它没有一个具体的范围。

微观其实也研究这几个市场：产品市场、要素市场、货币市场、劳动力市场。差别在于，微观在每个市场里只研究单个个体。而且你回想一下微观教材，十五六章里可能十四章讲的都是产品市场，要素市场只有一章简单提了一点，货币市场在微观里完全不提，劳动力市场顶多提了一个向后倒弯的劳动供给曲线。所以微观的研究对象其实已经被局限在产品市场上了——学不懂的时候，至少能想起一个具体例子，一想就觉得不难了。

宏观没有这个便利。那怎么办？看每一章的前言。每一章开头都会明确告诉你这一章研究哪个市场：这一章开篇就说了"简单的国民收入决定"，所以只研究产品市场；后面几章也会提前交代，顶多研究两个市场——产品加货币，或者产品加劳动力。

还有一层原因：如果四个市场同时研究，拿国民收入来算，一定会重复计算。所以只能从某一个市场来看。这四个市场就像是几个不同的面，你要研究一个东西，不能四个面都看，找一个面切进去就够了。这一章的切入口，就是产品市场。

顺带说一句，前面那套"家庭消费储蓄、企业投资生产"的两部门设定，其实还隐含了一句没写出来的话：这里说的市场，只是产品市场。

### 最简单的经济关系：两个部门

先看均衡产出。它的第一个知识点，是最简单的经济关系。

"最简单"这三个字是在限定范围：

- 只有家庭和企业两个部门；
- 不存在政府；
- 不存在对外贸易。

家庭的钱主要只有两个用途：消费、储蓄。企业的钱主要也只有两个用途：生产、投资。

然后是一个关键假设：假定企业的投资是外生的。

什么叫外生？就是不受这个模型本身影响，由模型之外的因素决定。具体到这儿：投资不随利率和产量的变动而变动。

这就是第一个假设。第二个假设，是凯恩斯定律。

### 凯恩斯定律：需求变了，价格为什么不动

第二个假设是这样一句话：不论需求量为多少，经济社会都以不变的价格提供相应的供应量。

翻成白话：社会总需求变动的时候，只会引起产量和收入的变动，不会引起价格的变动。这条就叫凯恩斯定律。

放到图上看，它的供给曲线是一条水平线：不管需求量是多少，经济社会都按不变的价格供货。需求怎么移动，交点对应的价格都不动，动的只有产量——也就是 $y$，因为 $y$ 既是产量也是收入。

凯恩斯是怎么得出这个结论的？要看他生活的背景：大萧条。那个时期工人大批失业，资源大量闲置。在这种条件下，社会总需求增加，只会让闲置的资源得到利用、生产增加，但不会让资源的价格上升。

你可以结合生活想一想。社会上好多东西卖也卖不出去，生产也没地方生产，都快变成废品、变成没人要的垃圾了。这时候社会总需求突然增加，就好比来了个救世主，来救这些快要被当垃圾丢弃的资源。它本来都快被处理掉了，突然有人要用它，它感激不尽，哪还有脸要求价格上升？所以价格一定不会涨。但资源被投入进去，生产就增加了。

劳动力市场是同一个道理。你失业了很久很久，一直没人要你，突然社会对劳动力的需求增加了，有老板来雇佣你了，这时候你会要求很高的工资吗？你想的是：有个人要我就不错了，还要什么自行车。

> **易错点**：凯恩斯定律不是说"价格永远不变"。它有明确的适用条件——只适用于短期分析，而且成立的经济背景是存在大量闲置资源。正因为如此，它才能解释为什么短期内价格不易变动、为什么说价格具有粘性：社会需求变动时，企业首先考虑的是调整产量，而不是改变价格。

### 均衡产出与非计划存货投资

均衡产出这一节真正的重点，是非计划存货投资。为什么是重点？因为这里一会儿实际产出、一会儿计划需求、一会儿计划支出，自己看书特别容易搞混。我们一点一点捋。

先把前面说过的结论拿过来：总需求也叫总支出。所以

$$y = c + i$$

消费者需要市场里的东西、企业投资也需要市场里的东西，他们不能白拿，得支出才能得到，所以总需求和总支出是一回事。这个式子先记住。

然后引入一个新概念：实际产出。

$$\text{实际产出} = \text{计划需求} + \text{非计划存货投资}$$

计划需求也可以叫计划支出——在宏观里，需求和支出你就记成同一回事。

这个式子不好理解，看例子。

假定生产部门错误地估计了形势。企业在生产之前不可能盲目生产，它得先预测一下：等东西生产出来的时候，社会大概是个什么形势，然后再决定自己生产多少。但这个估计可能对、也可能错。这个企业就估计错了：它生产了 1200 亿美元的产品，等卖的时候发现市场实际只需要 1000 亿美元，于是白白剩下 200 亿美元。这 200 亿美元，就是企业的非意愿存货投资，也叫非计划存货投资。

| 概念 | 例子中的数值 | 说的是什么 |
| :--- | :--- | :--- |
| 实际产出 | 1200 亿美元 | 企业实际生产出来、投放到市场上的量 |
| 计划需求（计划支出） | 1000 亿美元 | 事前打算购买、事后真正卖出去的量 |
| 非计划存货投资 | 200 亿美元 | 预估失误、没人买而积压下来的部分 |

把这三个概念逐个说清楚。

实际产出，就是企业实际生产出来的量。它可能大于市场上真正能卖出去的，也可能小于，也可能正好等于；不管哪种情况，实际生产了多少，实际产出就是多少。

计划需求，或者叫计划支出，是事前定下来的、打算购买的量。站在生产者的角度说，就是它在投产之前预估消费者会买走多少——所以叫"计划"。估准了，这个数就正好等于事后真正卖出去的量；估错了，差额就落到非计划存货投资上。

非计划存货投资，就是他没想到会剩下的那部分，是预判失误的产物。

> **提示**：事后核算的时候，实际产出和实际支出是同一个数——生产出来 1200 亿，就对应 1200 亿的支出，其中 1000 亿被消费者买走，剩下 200 亿被动记成企业的存货投资。所以这两个词有时会混着用，指的都是那 1200 亿。

那什么是均衡产出？

均衡产出就是刚刚好达到均衡：企业计划生产的量，正好等于消费者想要购买的量。写成式子就是

$$\text{计划产出} = \text{计划需求}$$

书上一直写的是计划产出等于计划支出，其实是一回事，因为计划需求就是计划支出。要是你容易把"产出"和"支出"记混，就记成"计划产出等于计划需求"——生产者刚刚好猜对了消费者想要多少。

这里还要分清事前和事后。

计划产出，从事前的角度看是计划产出；从事后的角度看，它就是实际产出。举个最直白的例子：我在生产之前说我要计划生产 100 斤，后来真的生产了这 100 斤——这 100 斤从事前看是我的计划，从事后看就是实际。等于你之前打算了一件事，之后梦想成真了：事前那叫计划，事后那就变成了实际。

于是可以往下推了：

- 均衡产出时，计划产出 = 计划需求；
- 计划产出事后就是实际产出，所以 实际产出 = 计划需求；
- 而恒等式是 实际产出 = 计划需求 + 非计划存货投资；
- 两相比较，非计划存货投资只能等于零。

从逻辑上想更直接：均衡就是我刚好猜到了消费者要多少，生产出来的量刚刚好满足了这个需要，不会有剩余；既然没有剩余，非计划存货投资当然是零。

所以，在均衡的产出水平上要满足两个条件：

1. 计划产出 = 计划支出（计划需求），也就是企业计划生产的量和消费者需要的量刚好相等；
2. 非计划存货投资 = 0，也就是没有卖不掉的剩余。

再换一个角度。前面讲过，总供给可以理解为收入，总需求可以理解为支出；产出和总供给是一个意思，计划支出和计划需求是一个意思。所以上面那个条件换一种说法，就是收入等于支出：

> **结论**：均衡产出，也可以理解为社会经济的收入，正好等于全体居民和企业想要的支出。

### 45 度线与总需求曲线的交点

把这个关系放到图上：横坐标是收入，纵坐标是支出。

图上有两条线。一条是从原点出发的 45 度线，这条线上每一个点的横纵坐标都相等，也就是支出等于收入——所以它本身就是一条"收支相抵"的线。另一条是向右上方倾斜的 AE 曲线，表示总需求，它比 45 度线更平缓。

均衡产出在哪里？不是 45 度线上随便哪一点，而是两条线的交点，也就是图上的 b 点。

为什么？因为均衡要同时满足两个条件：

```text
均衡产出 b
├── 条件一：落在 45° 线上   →  全社会的支出 = 收入
└── 条件二：落在 AE 曲线上 →  企业产出 = 总需求，非计划存货投资 = 0
```

只满足第一条不行。45 度线上收支相抵的点有无数个，但在那些点上，企业产出的量和消费者真正需要的量未必相等——可能多了，形成存货投资；也可能少了，留下一个缺口。

| 产出与总需求 | 结果 |
| :--- | :--- |
| 产出 > 总需求 | 生产出来的比需要的多，一定有剩余，形成存货投资 |
| 产出 = 总需求 | 刚好卖完，非计划存货投资为零，这就是均衡 |
| 产出 < 总需求 | 供给小于需求，留下一个缺口 |

三种情形里，只有中间那一种同时满足两个条件，所以均衡产出就是 AE 与 45 度线的交点 b。

最后一个问题：想提高均衡产出，能改什么？

45 度线是固定的，它就是那么画的，动不了。唯一能改的是总需求：AE 往上移，交点沿着 45 度线往右上方走，均衡产出就变大了。所以，增加均衡产出的关键，在于增加总需求。

### 计划投资等于计划储蓄

均衡产出这一节的最后一个知识点：投资等于储蓄。达到均衡的时候，一路化简下来，最后得到的式子是投资等于储蓄。为什么？一点一点推。

起点是均衡条件：

$$\text{计划产出} = \text{计划支出}$$

前面说过，产出可以理解为收入，需求可以理解为支出，所以这个式子也可以写成

$$\text{计划收入} = \text{计划支出}$$

然后把两边拆开：

- 计划支出 = 计划消费 + 计划投资，即 $c + i$；
- 计划收入 = 计划消费 + 计划储蓄，即 $c + s$。

代进去：

$$c + i = c + s$$

两边的 $c$ 约掉：

$$i = s$$

所以经济达到均衡的时候，化简到最后就是计划投资等于计划储蓄。

> **注意**：这里的 $i$ 和 $s$ 都是"计划"的量。一旦企业判断失误、出现非计划存货投资，事后的实际投资就不等于计划投资，这个等式也就不再是均衡条件了。

到这里，均衡产出这条链走完了一圈：从"谁需要市场里的东西"开始，经过实际产出、计划需求、非计划存货投资，最后落在"计划投资等于计划储蓄"。

> **承前启后**：上一节讲完「均衡产出：国民收入是怎么被定下来的」，下一节接着讲「消费理论：凯恩斯消费函数与三个反驳者」。

## 消费理论：凯恩斯消费函数与三个反驳者
> 对应块：BLK03 | 覆盖分集：P03 | 块标题（分集名）：《【宏观经济学】第十三章：国民收入决定（2）：消费》

收入-支出模型这一章，上一程我们只走完了第一个知识点——均衡产出。这一程接着往下，把凯恩斯的消费理论，以及关于消费函数的其他理论，一起走完。这两块可以合成一个词来记：消费理论。

这一讲要解决的问题也很清楚：凯恩斯的消费函数当年被当成定论，后来却被数据打了脸，于是有了一串新理论来解释它错在哪。这条"立起来—被推翻—再解释"的线，就是整讲的骨架。

### 消费理论就两大块

消费理论的内容看着零散，但按两根枝干去记，一点都不乱：一根和凯恩斯有关，一根是非凯恩斯的。

凯恩斯这一根上挂四样东西：消费函数、储蓄函数、消费函数与储蓄函数之间的关系、凯恩斯的消费之谜。家庭消费函数和社会消费函数也归在这一支里，这一讲不展开。

非凯恩斯那一根，理论其实不少，我们只学三种：生命周期假说、相对收入消费理论、永久收入消费理论。

两根枝干之间还有一条因果线：凯恩斯的消费函数后来被证明站不住脚，才有了"消费之谜"这个说法；有了谜，才有后来者去解释它。所以那三种理论干的都是同一件事——找出凯恩斯错在哪。

```text
消费理论
├── 凯恩斯消费理论
│   ├── 消费函数  c = a + b·y
│   ├── 储蓄函数  s = y − c
│   ├── 消费函数与储蓄函数的关系
│   └── 凯恩斯的消费之谜
└── 非凯恩斯消费理论
    ├── 生命周期假说（莫迪利亚尼）
    ├── 相对收入假说（杜森贝利）
    └── 永久性收入假说（弗里德曼）
```

上半支是"立"，下半支是"破"，三种非凯恩斯理论全挂在"破"下面。

按这张图去学，每一块该往哪儿放，心里就有数了。

### 凯恩斯消费函数

#### 消费由收入决定，而不是利率

在凯恩斯之前，古典学派对消费有一套很顺的解释：消费由利率决定，两者负相关。

逻辑链是这样走的：利率上升，储蓄的回报变高，人们更愿意储蓄；储蓄多了，用来消费的自然就少。所以影响消费的主要因素是利率。这套说法延续了很久。

凯恩斯不接受。他的反问很直接：利率再高，我没有钱去储蓄，不也同样没有钱消费？利率高低，跟我消不消费关系真不大。

真正决定我消不消费的，是收入。银行利率再高，我手里没钱，我去哪里消费。

```text
古典学派：利率 ↑ → 储蓄 ↑ → 消费 ↓
凯恩斯：  收入 ↑ → 消费 ↑
```

两派的分歧不在"储蓄到消费"这一环，而在自变量到底是利率还是收入。

> **结论**：凯恩斯承认利率在理论上多少会影响消费，但真正起作用的只有一个因素——收入。所以他笔下的消费函数，自变量只留收入。

写成式子：

$$c = a + by$$

c 是消费，y 是收入。两个部件要分清。

- $a$：自主性消费。不依存于收入，取决于维持生命的基本需要。哪怕一分钱收入都没有，为了活下去也必须花的那部分，就是它。
- $by$：引致消费。随收入变动而变动，收入动了它才动。

$b$ 是边际消费倾向，说的是收入每增加一单位，消费会增加多少，取值范围是 $0<b<1$。

为什么一定小于 1？因为消费的增量不会大于收入的增量。这背后是凯恩斯对人的一个判断：人多多少少是节俭的，不会把全部收入都拿去消费。

#### 两个斜率：边际消费倾向与平均消费倾向

教科书上画消费函数，多数画成一条直线。我更愿意画成一条弯的、逐渐平缓的曲线，因为这样两个"倾向"在图上怎么读，一眼就明白。

这条曲线从纵轴上的 $a$ 出发：收入为零时，消费就是那笔维持生命的自主性消费，一分也不能少。

先看边际消费倾向。边际就是求导，求导在几何上就是曲线在该点切线的斜率。所以曲线上每一点的斜率，就是该点的 MPC。曲线越往右越平缓，MPC 就越小——递减。

再看平均消费倾向，$APC=c/y$。在图上取一点，它的 c 和 y 构成一个直角三角形，$c/y$ 就是这个角的正切，而正切正是斜边的斜率。那条斜边，就是这一点与原点连成的线。所以平均消费倾向，是消费曲线上一点与原点连线的斜率。

点沿曲线往右移，这条连线越来越平，APC 也就递减。

> **易错点**：MPC 读的是切线的斜率，APC 读的是过原点连线的斜率。两条线不是一回事，读混了走势就会判断错。

| 概念 | 代数定义 | 图上怎么读 | 随收入的变化 |
| :--- | :--- | :--- | :--- |
| 边际消费倾向 $MPC$ | $\Delta c/\Delta y$，即 $dc/dy$ | 该点切线的斜率 | 递减 |
| 平均消费倾向 $APC$ | $c/y$ | 该点与原点连线的斜率 | 递减 |

> **提示**：$c=a+by$ 是线性写法，此时 $MPC=b$ 是一个常数；而"$MPC$ 递减"说的是更一般的非线性消费曲线——曲线越往右越平缓，每一点的切线斜率都在变小。两者不冲突：线性式是便于计算的简化写法，递减描述的是消费曲线的一般形态。

#### 凯恩斯消费理论的三条核心

消费函数讲完，核心内容只记三条。

第一，消费由收入决定，不由利率决定。这是凯恩斯与古典学派的分歧点。

第二，消费函数的表达式 $c=a+by$，以及它的图像——公式要会写，图要会画。

第三，$APC$ 与 $MPC$ 的走势：两个都递减，而且 $APC$ 大于 $MPC$。

前两条靠记，第三条要证。为什么平均消费倾向必然大于边际消费倾向？

把消费函数两边同除以 y：

$$APC=\frac{c}{y}=\frac{a}{y}+b$$

边际消费倾向是：

$$MPC=\frac{\Delta c}{\Delta y}=\frac{dc}{dy}=b$$

$\Delta y$ 趋于零时，差商就过渡成导数。两式一比：$APC$ 是在 $b$ 的基础上又加了一项 $a/y$；a、y、b 都是正数，所以 $a/y+b>b$。

> **结论**：$APC>MPC$，缺口正好是 $a/y$——收入越低，这个缺口越大。

### 储蓄函数

储蓄函数仍然是在凯恩斯这套框架里推出来的，它描述储蓄随收入变化而变化，记作 $s=s(y)$——储蓄同样由收入决定。

推导很轻。我们假设收入只有两个去处：一部分消费，一部分储蓄。于是：

$$s=y-c$$

把 $c=a+by$ 代进去：

$$s=y-(a+by)=(1-b)y-a$$

这就是储蓄函数。消费那边讨论了边际和平均，储蓄这边照样要讨论。

边际储蓄倾向，是增加一单位收入中用于增加储蓄的那部分比率：

$$MPS=\frac{\Delta s}{\Delta y}=\frac{ds}{dy}=1-b$$

平均储蓄倾向：

$$APS=\frac{s}{y}=\frac{(1-b)y-a}{y}=1-b-\frac{a}{y}$$

两者一比：$APS$ 在 $1-b$ 的基础上又减掉了一个 $a/y$，而 $a/y>0$，所以 $APS$ 恒小于 $MPS$。

> **结论**：$APS<MPS$，缺口同样是 $a/y$。这与消费那边的 $APC>MPC$ 是同一个缺口的两面。

### 消费函数与储蓄函数的关系

三条。

第一，互为补数，两者之和等于收入：

$$y=c+s$$

收入固定时，c 越大 s 就越小。你收入就那么多，想让储蓄多一点，消费就得少一点；想让消费多一点，储蓄就得少一点。

第二，$APC$、$MPC$ 随收入增加而递减，且 $APC>MPC$；$APS$、$MPS$ 随收入增加而递增，且 $APS<MPS$。

为什么消费的两个倾向往下走，储蓄的两个倾向就往上走？因为两者互补，一个多另一个就少。消费那部分的平均和边际都随收入增加而递减，储蓄这边自然就随收入增加而递增。

第三，两个恒等式：

$$APC+APS=1 \qquad MPC+MPS=1$$

这三条都能现推。把四个量摆出来：

$$c = a + by$$

$$s = y - c = (1-b)y - a$$

$$APC=\frac{a}{y}+b \qquad MPC=\frac{dc}{dy}=b$$

$$APS=1-b-\frac{a}{y} \qquad MPS=\frac{ds}{dy}=1-b$$

逐对相加：

$$APC+APS=\left(\frac{a}{y}+b\right)+\left(1-b-\frac{a}{y}\right)=1$$

$$MPC+MPS=b+(1-b)=1$$

$a/y$ 与 $-a/y$ 抵消，$b$ 与 $-b$ 抵消，结果都是 1。

| 量 | 定义式 | 表达式 | 走势（一般形态） |
| :--- | :--- | :--- | :--- |
| $APC$ | $c/y$ | $a/y+b$ | 递减 |
| $MPC$ | $dc/dy$ | $b$ | 递减 |
| $APS$ | $s/y$ | $1-b-a/y$ | 递增 |
| $MPS$ | $ds/dy$ | $1-b$ | 递增 |

表里的"递增/递减"描述的是消费曲线的一般形态；在线性简化式 $c=a+by$ 下，$MPC$ 恒为 $b$，$MPS$ 恒为 $1-b$。

这套关系不用死记，考场上现推完全来得及。但我还是建议背熟——上了考场分秒必争，能省的时间都要省。真怕记混，就老老实实现推，推一遍总比背错了强。

凯恩斯这一支还有两个概念：家庭消费函数和社会消费函数。这里不展开，感兴趣可以自己看，不影响后面的主线。

### 凯恩斯的消费之谜

"消费之谜"这个名字本身就值得说一句。凯恩斯的消费函数后来被证明是错的，可他当时声望极高、极有权威，即使错了，学界也不便直呼"凯恩斯的错误"，于是换了个体面的说法——凯恩斯的消费之谜。

所以要记住：消费之谜说的就是凯恩斯这套理论错了。

错在哪？不是逻辑推不出来，而是推出来的结论和现实数据对不上。凯恩斯说 $MPC$ 和 $APC$ 都递减，可二战后的经验数据一算，不是这么回事。

> **定义**：凯恩斯的消费理论又叫绝对收入假说——消费取决于当期的绝对收入水平。二战后对现实数据的计量统计分析表明，这套假说与现实经济运行并不吻合。

不吻合具体在哪？分长短看：

- 短期：凯恩斯是对的。
- 长期：$APC$ 不是递减，而是不变。

凯恩斯当年分析消费函数，没有区分长期和短期，笼统地说 $APC$ 递减、$MPC$ 递减。但现实中的消费函数必须分长短，画出来是两条形态不同的线：短期的不过原点、有截距；长期的过原点。

| 口径 | 函数形态 | 是否过原点 | $APC$ 的走势 |
| :--- | :--- | :--- | :--- |
| 短期消费函数 | 有截距 $a>0$ | 不过原点 | $a/y+b$，随收入递减 |
| 长期消费函数 | 无截距 | 过原点 | 为常数，不随收入变化 |

过原点这一条尤其关键：线过原点，c 与 y 就同比例，$c/y$ 恒等于这条线的斜率，$APC$ 自然是一个常数，不再随收入变化。

> **提示**：凯恩斯并不是在长期上另说了一套，而是根本没提长短期这回事。他的结论是"无论长短都递减"，数据证明的却是"短期递减、长期不变"。谜就出在这个缺口上。

既然短期对、长期不对，后来者要回答的就是：为什么短期成立、长期不成立？三个代表性人物，三条路子。

- 莫迪利亚尼：生命周期假说
- 杜森贝利：相对收入假说
- 弗里德曼：永久性收入假说

后面看这三条时，抓住一个共同点：它们最终都要落到 $APC$ 上。凯恩斯错在对 $APC$ 的理解，谁把"长期 $APC$ 为什么不变"讲通了，谁就解开了这个谜。

### 生命周期假说：把一生摊平

莫迪利亚尼的切入点，是把一生按退休切成两段。

```text
时间轴（从今往后 t 年）
├─ 前 r 年：工作阶段，每年挣 y
└─ 后 t−r 年：退休阶段，没有收入

总资源 = 初始财富 W + r·y
平滑消费 C = (W + r·y) / t
```

假设很干净：退休之前是工作阶段，能获得收入；退休之后是退休阶段，没有收入，只能靠工作阶段攒下的存款生活。

再设几个量：从现在起还要生活 t 年；初始财富是 W；从现在到退休还有 r 年，这 r 年每年挣 y。

> **提示**：几个字母别搞混。t 是余生总年数，r 是还要工作的年数，W 是起点就有的财富（比如父母留下的），y 是工作期间的年收入。

初始财富是哪怕没工作也已经在手里的钱，所以一个人能支配的全部资源是：

$$W+ry$$

即"一出生就有的"加"工作挣来的"。

生命周期假说的核心假设是：人希望一生保持平滑的消费水平。把总资源摊到 t 年：

$$C=\frac{W+ry}{t}=\frac{1}{t}W+\frac{r}{t}y$$

平滑的意思很具体：工作那 r 年，每年挣的 y 里花不完的部分存起来；退休那 t−r 年没有收入，靠这笔存款过日子。年轻时正储蓄，年老时负储蓄，两段合起来正好把 $W+ry$ 花完。

式子说明，消费既取决于财富，也取决于收入。把两个系数各用一个字母表示：

$$C=\alpha W+\beta y$$

对照上式，$\alpha=1/t$ 是财富的边际消费倾向，$\beta=r/t$ 是收入的边际消费倾向。

现在拿它解释消费之谜。两边同除以 y：

$$APC=\frac{C}{y}=\alpha\frac{W}{y}+\beta$$

$\alpha$、$\beta$ 都是常数，所以 $APC$ 完全由 $W/y$ 决定：这个比值变，$APC$ 就变；这个比值不变，$APC$ 就不变。

那么 $W/y$ 短期、长期各是什么样？先把"财富"定清楚：财富是你攒下的全部钱，是你拥有的全部；收入只是财富的一部分。

短期，一年一年地看，财富和收入不成比例变动。因为收入不可能全部转化为财富——收入增加了，大部分还是要花掉。所以 $\Delta y>\Delta W$。

举个具体的：这一年收入多了 5 万，财富可能只多了 1 万。多出来的 5 万里，几万块拿去旅游、买东西，只有一小部分沉淀下来。除非一分钱不花、全攒起来，收入和财富才会等比例增长——这可能吗？不可能。

$\Delta y>\Delta W$，放进 $W/y$ 里就是分母涨得比分子快，比值下降，于是短期 $APC$ 递减。凯恩斯在短期是对的。

长期，一生来看，收入和财富成比例变动，$\Delta y=\Delta W$。这里可以用极限的眼光看：相当于人走到生命尽头，回头做一次事后观察。某些年份花得多（$\Delta y>\Delta W$），某些年份攒得多（$\Delta y<\Delta W$），但从一生看，正负抵消，增量回到同一比例。

于是 $W/y$ 不变，$APC$ 不变。

> **结论**：生命周期假说一句话——短期 $APC$ 递减，长期 $APC$ 不变。凯恩斯的短期结论被保留，只在长期上做了修正。

### 相对收入假说：攀比与习惯

杜森贝利，美国经济学家。他的出发点是先指出凯恩斯假设的错误，再给出自己的答案：消费并不取决于现期的绝对收入水平，而取决于相对收入水平。

相对，相对谁？两个方向。

一个方向是相对于别人。我不看自己真实收入是多少，我看别人是多少。背后是攀比心理，虚荣心作祟：即使挣得不多，也要让消费尽量跟别人持平。所以消费不会随自己的收入增减而大起大落。

另一个方向是相对于自己历史上的最高收入。以前收入一直不错，突然降下来，人适应不了，消费习惯没法轻易改。这就是"由俭入奢易，由奢入俭难"。

两个方向对应两种效应：

- 棘轮效应：消费具有习惯性，某期的消费不受当期收入影响，而受过去所达到的最高收入和最高消费影响，消费因此具有不可逆性。棘轮只能单向转，消费也一样——上去了就下不来，说白了就是"由俭入奢易，由奢入俭难"。
- 示范效应：消费受别人影响，也就是攀比。人们的消费不取决于自己的绝对收入，而取决于别人的相对收入水平；即使手头没钱，攀比之心也会把消费维持在一个较高的状态。

两个效应合起来，结果一致：收入波动，消费不大波动，保持平稳。所以长期看，$APC$ 不变。

> **易错点**：棘轮效应对应"相对于自己的历史最高收入"，讲的是习惯；示范效应对应"相对于别人"，讲的是攀比。两个方向别对调。

### 永久性收入假说：只认能一直拿到的那部分

弗里德曼的入手点，是给收入重新分类。他认为收入不该笼统地看，要拆成两块：

$$y=y_p+y_t$$

$y_p$ 是持久性收入，$y_t$ 是暂时性收入。持久性收入也叫永久性收入，两种叫法说的是一个东西。

> **定义**：持久性收入，是人们预期可以一直获得的那部分收入。

关键假设：两块收入不是都影响消费，只有持久性收入才决定消费。于是消费函数写成：

$$c=\alpha y_p$$

注意，暂时性收入根本不进这个式子。

还是那件事——解释 $APC$。两边同除以 y：

$$APC=\frac{c}{y}=\alpha\frac{y_p}{y}$$

$\alpha$ 是常数，所以 $APC$ 完全由 $y_p/y$ 决定，也就是持久性收入与现期收入之比。

短期分两种情况：

- 现期收入暂时升到持久性收入之上（$y>y_p$）：分母大于分子，$y_p/y$ 变小，$APC$ 暂时下降。
- 现期收入暂时降到持久性收入之下（$y<y_p$）：分母小于分子，$y_p/y$ 变大，$APC$ 暂时上升。

翻译过来：高收入的年份，$APC$ 反而低；低收入的年份，$APC$ 反而高。

长期，收入变动取决于持久性收入，y 与 $y_p$ 同比例变动，$y_p/y$ 又成了常数，$APC$ 不变。

> **结论**：永久性收入假说在短期给出"有时升、有时降"两种情况，在长期给出"$APC$ 不变"。

### 两条枝干，各记什么

到这里，消费函数这一块走完了。储蓄函数虽然单列一节，但它本来就是从消费函数倒过来的，所以整块内容都可以归到消费函数名下。

凯恩斯这一支，记四点：

- 消费由收入决定，公式 $c=a+by$ 会写，图像会画；
- 四个量的关系：$APC$、$MPC$、$APS$、$MPS$，以及两个恒等式 $APC+APS=1$、$MPC+MPS=1$（记不住就现推）；
- $APC$ 递减、$MPC$ 递减，且 $APC>MPC$；$APS$、$MPS$ 递增，且 $APS<MPS$；
- 凯恩斯的消费之谜：理论结论与现实不符，根因是没分长短期——短期站得住，长期站不住，因为长期 $APC$ 不变。

非凯恩斯这一支，三个理论各记一句：

| 理论 | 代表人物 | 消费由什么决定 | 长期 $APC$ 为什么不变 |
| :--- | :--- | :--- | :--- |
| 生命周期假说 | 莫迪利亚尼 | 财富与收入 | 一生中 $W$ 与 $y$ 同比例变动，比值稳定 |
| 相对收入假说 | 杜森贝利 | 相对收入（他人，以及自己的历史最高） | 棘轮效应与示范效应压住了消费波动 |
| 永久性收入假说 | 弗里德曼 | 持久性收入 | $y_p/y$ 长期稳定 |

三条路子切入的角度不同：生命周期从财富与收入的关系切，相对收入从人与人的比较、人与自己过去的比较切，永久性收入从收入的可预期性切。但要回答的是同一个问题——凯恩斯在长期上错在哪，为什么长期 $APC$ 不变。

> **提示**：这三个理论在记忆上要抓的是对应关系——谁提出、从哪个角度、结论是什么。名字和角度对不上，式子写得再熟也用不上。

一条消费函数立起来，三种理论把它修正到符合数据，消费理论到这里就闭环了。

> **承前启后**：上一节讲完「消费理论：凯恩斯消费函数与三个反驳者」，下一节接着讲「国民收入的决定与乘数：从写式子到求偏导」。

## 国民收入的决定与乘数：从写式子到求偏导
> 对应块：BLK04 | 覆盖分集：P04 | 块标题（分集名）：《【宏观经济学】第十三章：国民收入决定（3）：乘数》

国民收入这一章讲到最后，还剩两个知识点：一个是国民收入的决定，一个是乘数。乍一看是两件事，其实是同一件事的两截——前一半只干一件事，把 $Y$ 写成"$Y$ 等于什么什么"的形状；后一半拿这个式子去求偏导。式子写对了，乘数就是顺手的事。

先把话说清楚：国民收入的决定，说白了你就是要算出来 $Y$ 怎么表达。但要分情况——两部门、三部门、四部门，$Y$ 的表达公式都不一样，所以得分成三种情况分别写。

这三种情况有一个共同的前提，必须先钉死：不管几个部门，我们研究的这个国民收入都是**均衡收入**。

> **定义**：均衡收入，就是计划支出恰好等于计划收入时所对应的那个收入水平。

这一点一定要记住。后面所有的乘数，都架在这个均衡点上面：收入从一个均衡挪到另一个均衡，中间的过程我们不管。

### 两部门：从 C + I 出发

两部门最简单，只有居民户和企业。这时候计划支出写成：

$$Y = C + I$$

这个 $C + I$ 也可以叫计划需求。均衡的时候计划支出等于计划收入，而计划收入用同样的方式表达，就是 $Y = C + S$。所以求均衡收入的路子很直接：把 $C$ 用消费函数写开，解方程。

消费函数是：

$$C = \alpha + \beta Y$$

代进去：

$$Y = \alpha + \beta Y + I$$

把带 $Y$ 的项都移到左边：

$$Y - \beta Y = \alpha + I$$

两边同除 $1 - \beta$：

$$Y = \frac{\alpha + I}{1 - \beta}$$

这就是两部门的均衡收入。

同一个问题，用储蓄函数也能做。均衡时计划支出等于计划收入，也就是 $C + I = C + S$，两边把 $C$ 消掉，只剩：

$$I = S$$

这就是均衡条件的另一种写法：计划投资等于计划储蓄。再把储蓄函数写出来——储蓄是收入减消费：

$$S = Y - C = Y - (\alpha + \beta Y) = -\alpha + (1 - \beta)Y$$

和 $I = S$ 联立：

$$I = -\alpha + (1 - \beta)Y$$

移项解出来，还是：

$$Y = \frac{\alpha + I}{1 - \beta}$$

两条路，一个结果。

> **提示**：正因为消费法和储蓄法结论完全一样，后面三部门、四部门就不必两种都推一遍了，选消费这条走。多推一遍不会多出信息，只会多出出错的机会。

还有个细节不用纠结：$I$、$S$、$Y$ 这些符号，用大写写也行，用小写写也行，都无所谓，只要一篇里前后一致。

### 三部门：政府进来，多出两个变量

三部门就是在两部门的基础上加一个政府部门。政府一进来，会多出两个经济变量：一个是税收，一个是政府支出。支出的构成变成：

$$Y = C + I + G$$

消费函数还是那个形状，但里面的收入换了：

$$C = \alpha + \beta Y_d$$

这里的 $Y_d$ 是**可支配收入**。为什么不能直接拿 $Y$ 去消费？因为有了政府，你挣的钱不全是你能花的：其中一部分要拿去纳税。但反过来，政府也会给你补贴，这就是转移支付 $TR$。所以：

$$Y_d = Y - T + TR$$

$Y$ 是你最初挣的钱，减掉交给政府的税 $T$，再加上政府给你的转移支付 $TR$，剩下的才是可支配收入。这个式子直接记住就行。

税要分两种。一种是**定量税**，也叫定额税：你交的税是个定值，和收入没有关系，收入增加它不增加，收入减少它也不减少。另一种是**比例税**：税额随收入变，挣得多就多交，挣得少就少交，写成 $T = tY$，$t$ 是税率。

两种税的差别，只落在可支配收入这一行式子上。下面分开推。

### 定量税：税额是个定值

税是定值 $T$，可支配收入就是 $Y_d = Y - T + TR$。代进消费函数：

$$C = \alpha + \beta (Y - T + TR)$$

再代进三部门的均衡条件：

$$Y = \alpha + \beta (Y - T + TR) + I + G$$

展开：

$$Y = \alpha + \beta Y - \beta T + \beta TR + I + G$$

把带 $Y$ 的项移到左边：

$$Y - \beta Y = \alpha - \beta T + \beta TR + I + G$$

两边同除 $1 - \beta$：

$$Y = \frac{\alpha + I + G - \beta T + \beta TR}{1 - \beta}$$

到这儿，"国民收入的决定"这件事就算办完了——$Y$ 已经被写成"$Y$ 等于什么什么"的形状。

这个式子的分子值得多看一眼符号：$T$ 前面是负号，因为收税是从居民口袋里往外拿钱，可支配收入少了，消费就少；$TR$ 前面是正号，因为转移支付是往居民口袋里放钱，可支配收入多了，消费就多；$I$ 和 $G$ 都是正号，它们是直接的需求。符号不是背出来的，是从 $Y_d = Y - T + TR$ 那一行一路带下来的。

### 比例税：税额跟着收入走

比例税下 $T = tY$，可支配收入变成：

$$Y_d = Y - tY + TR = (1 - t)Y + TR$$

每一块钱收入里，先被税拿走 $t$，剩下 $(1 - t)$ 才是自己的，这一部分再按 $\beta$ 的比例变成消费。代进消费函数：

$$C = \alpha + \beta[(1 - t)Y + TR]$$

再代进 $Y = C + I + G$：

$$Y = \alpha + \beta(1 - t)Y + \beta TR + I + G$$

移项：

$$Y - \beta(1 - t)Y = \alpha + I + G + \beta TR$$

$$Y = \frac{\alpha + I + G + \beta TR}{1 - \beta(1 - t)}$$

和定量税那个式子比，两处变了：分母从 $1 - \beta$ 变成 $1 - \beta(1 - t)$；分子里的 $-\beta T$ 不见了——税不再是常数，被 $t$ 吸收进分母里去了。

> **提示**：比例税这个式子记不记都行。往后讲乘数，一概不考虑比例税，只讨论定量税的情形。真要用比例税，把 $1 - \beta$ 换成 $1 - \beta(1 - t)$ 现推也来得及。

### 四部门：出口是常数，进口跟着收入走

四部门在三部门的基础上再加进出口，净出口写成 $X - M$，$X$ 是出口，$M$ 是进口。

出口这块，从我们国家的角度看，出口多少不是自己能决定的，所以把它看作一个常量。进口就不一样了：本国居民收入增加以后，买外国货的欲望也会变大，所以进口写成收入的函数：

$$M = M_0 + \gamma Y$$

$M_0$ 叫自发进口，是跟收入没有关系、无论如何都要进口的那一部分；$\gamma$ 叫边际进口倾向，收入每增加一块钱，进口增加多少。

把四个式子摆齐：

$$
\begin{aligned}
Y &= C + I + G + X - M \\
C &= \alpha + \beta Y_d \\
Y_d &= Y - T + TR \\
M &= M_0 + \gamma Y
\end{aligned}
$$

把 $C$ 和 $M$ 都代进第一个式子：

$$Y = \alpha + \beta(Y - T + TR) + I + G + X - (M_0 + \gamma Y)$$

这里有个括号容易掉：$X - M$ 里的 $M$ 是整个 $M_0 + \gamma Y$，减的是整体，展开就是减 $M_0$ 再减 $\gamma Y$。

$$Y = \alpha + \beta Y - \beta T + \beta TR + I + G + X - M_0 - \gamma Y$$

把带 $Y$ 的项全部移到左边，注意 $-\gamma Y$ 移过去要变号：

$$Y - \beta Y + \gamma Y = \alpha - \beta T + \beta TR + I + G + X - M_0$$

$$Y = \frac{\alpha + I + G + X - \beta T + \beta TR - M_0}{1 - \beta + \gamma}$$

四部门的也表达清楚了。分母变成 $1 - \beta + \gamma$：进口和消费一样，都随收入增加而增加，所以 $\gamma$ 和 $\beta$ 一样要从左边减掉，移项之后落到分母上。

> **易错点**：四部门的分母是 $1 - \beta + \gamma$，不是 $1 - \beta - \gamma$。$\gamma Y$ 原来在等号右边是减项，移到左边就成了加项。

到这为止，两部门、三部门（定量税和比例税）、四部门的 $Y$ 全写出来了。这块不难，方法掌握之后人人可以现推。

### 乘数就是倍数

乘数这两个字，拆开就是"倍数"。拿 $X$ 泛指那个引起变动的自变量，用式子写就是因变量的变化量比上自变量的变化量：

$$\frac{\Delta Y}{\Delta X}$$

它其实就是一个边际量。

举个例子：投资增加 500 亿，这 500 亿砸下去，国民收入会增加多少？增加的量会大于 500 亿，是 500 亿的若干倍。这个"若干倍"就是乘数。

为什么会成倍？因为投资增加不是只在一个点上发生。一个行业的投资增加了，会给周边相似的、有关联的行业带来订单和收入；那些行业的人有了钱再去花，又带动下一轮。这种连锁反应有一点多米诺骨牌的意思，加总到最后，国民收入就是成倍增长，而不是只增加最初那一笔。

顺着这个思路，乘数在算法上很像数学里的求导——变化量比变化量，就是导数。只不过 $Y$ 的自变量不止一个，所以求的是偏导：

$$\frac{\partial Y}{\partial I}, \qquad \frac{\partial Y}{\partial G}, \qquad \frac{\partial Y}{\partial T}$$

这三个偏导，分别就是投资乘数、政府购买乘数、税收乘数。求什么乘数，就让 $Y$ 对哪个自变量求偏导，其余一律当常数。

> **提示**：乘数不是独立的知识点，它是"国民收入的决定"的下游。顺序永远是：先把那个部门的 $Y$ 表达式写出来，再求偏导。式子写错，乘数一定跟着错。

### 投资乘数：先在两部门立个标杆

投资乘数的定义是：收入的变化，与带来这种变化的投资支出变化之间的比率。说白了，投资变动一块钱，收入变动几块钱。

$$k_I = \frac{\Delta Y}{\Delta I}$$

两部门的 $Y = \dfrac{\alpha + I}{1 - \beta}$，拆开写：

$$Y = \frac{\alpha}{1 - \beta} + \frac{I}{1 - \beta}$$

对 $I$ 求偏导：$\alpha$、$\beta$ 都是常数，第一项求导为零，第二项求导就是 $I$ 的系数。

$$k_I = \frac{\partial Y}{\partial I} = \frac{1}{1 - \beta}$$

把 $\beta$ 换成 $\mathrm{MPC}$（边际消费倾向），$1 - \beta$ 就是 $\mathrm{MPS}$（边际储蓄倾向），所以：

$$k_I = \frac{1}{1 - \mathrm{MPC}} = \frac{1}{\mathrm{MPS}}$$

从式子上能读出一个结论：**边际消费倾向越大，投资乘数越大**。因为 $\mathrm{MPC}$ 越大，$1 - \mathrm{MPC}$ 越小；它在分母上，分母越小，分数越大。反过来，边际储蓄倾向越小，乘数越大。

三部门（定量税）的投资乘数也一样。三部门 $Y$ 的式子里 $I$ 的系数还是 $\dfrac{1}{1 - \beta}$，对 $I$ 求偏导，$T$、$TR$、$G$ 全是常数，结果还是：

$$k_I = \frac{1}{1 - \beta}$$

所以投资乘数在两部门和三部门都是 $\dfrac{1}{1 - \beta}$。四部门当然也能求，但那不是重点，掌握到三部门就够了。

### 政府购买乘数：三部门才有

两部门没有政府，所以谈不上政府购买乘数——这个乘数只有引入政府之后才存在。四部门也有，但不讨论，还是掌握到三部门。

三部门、定量税下：

$$Y = \frac{\alpha + I + G - \beta T + \beta TR}{1 - \beta}$$

对 $G$ 求偏导，$G$ 的系数就是结果：

$$k_G = \frac{\partial Y}{\partial G} = \frac{1}{1 - \beta}$$

和投资乘数一模一样。这也不奇怪：在 $Y = C + I + G$ 这个式子里，$I$ 和 $G$ 是同一层级的加项，都是直接的需求，位置对称，系数自然相同。

### 税收乘数与政府转移支付乘数

这两个乘数也是三部门才有。两部门连政府都没有，既没有税，也没有转移支付，自然没有这两个乘数。

税收乘数是让 $Y$ 对 $T$ 求偏导：

$$k_T = \frac{\partial Y}{\partial T} = \frac{-\beta}{1 - \beta}$$

负号是关键。政府多收税，居民手里的钱就少了，消费跟着少，国民收入往下走。从大小上看，它的绝对值是政府购买乘数的 $\beta$ 倍：$\dfrac{\beta}{1 - \beta}$ 就是 $\dfrac{1}{1 - \beta}$ 再乘上 $\beta$。

政府转移支付乘数，是让 $Y$ 对 $TR$ 求偏导：

$$k_{TR} = \frac{\partial Y}{\partial TR} = \frac{\beta}{1 - \beta}$$

正号。政府多给补贴，居民可支配收入增加，消费增加，国民收入上升。

把两个放在一起看：大小相等，符号相反。一个是从居民手里拿走钱，一个是往居民手里放钱，方向相反是应该的。

### 平衡预算乘数：名字容易唬人

平衡预算乘数是这一块里稍微绕一点的地方。它的定义是：政府收入和支出同时以相等数量增加或减少时，国民收入变动与政府收支变动的比率。

这句话读起来拗口，主要卡在"政府收支"这四个字上——它不是一个词，是两个词：收是收入，支是支出。

- 政府收入，主要就是税收。政府的钱绝大多数来自税收。
- 政府支出，在这里就是政府购买。注意，我们不把转移支付算进政府支出，而是假设政府支出只有政府购买这一项。

收和支都会让国民收入发生成倍的变动，也就是一个倍数的变动，但两者方向相反。

```text
政府收支等量变动
   ├─ 收入端：税收 T 增加 ──→ 居民手里钱变少 ──→ 国民收入减少
   └─ 支出端：购买 G 增加 ──→ 政府买走人民生产的东西 ──→ 国民收入增加
                          ↓
                两股力量方向相反，总变动 = 一正一负相加
```

读图：上面一行是收，下面一行是支，箭头末端是它们各自把国民收入推向的方向。平衡预算要看的，是这两行同时发生之后净剩多少。

政府购买为什么是正向的？政府到市场上去买原材料、买办公设备，这些东西是谁生产的？是人民生产的。政府买了人民生产的东西，钱就流到居民手里，国民收入增加。政府越愿意花钱，这个正向作用越大。

政府收入为什么是反向的？税收增加，居民税负加重，手里的钱变少，消费就少，国民收入下降。

平衡预算乘数的前提是：政府收入和支出以相同的数量变动，$\Delta G = \Delta T$。政府多收多少税，就多买多少东西。

国民收入的总变动由两部分组成：

$$\Delta Y = k_G \cdot \Delta G + k_T \cdot \Delta T$$

一部分是政府购买变化带来的，一部分是税收变化带来的。把两个乘数代进去：

$$\Delta Y = \frac{1}{1 - \beta}\Delta G + \frac{-\beta}{1 - \beta}\Delta T$$

因为 $\Delta G = \Delta T$，把 $\Delta T$ 换成 $\Delta G$：

$$\Delta Y = \frac{1}{1 - \beta}\Delta G - \frac{\beta}{1 - \beta}\Delta G = \frac{1 - \beta}{1 - \beta}\Delta G = \Delta G$$

系数相加正好等于 1。于是：

$$\frac{\Delta Y}{\Delta G} = \frac{\Delta Y}{\Delta T} = 1$$

这就是平衡预算乘数。

> **提示**：平衡预算乘数其实不是一个数，是两个数——$\Delta Y / \Delta G$ 和 $\Delta Y / \Delta T$。之所以能合成一个名字，是因为算完发现这两个比值相等，都等于 1。所以问它等于多少，答 1；问它怎么定义，答政府收支等量变动时国民收入变动与政府收支变动的比率。

### 拿 200 亿走一遍

光看符号容易飘，代个数进去。三部门，定量税，$\beta = 0.8$。

政府购买增加 200 亿。政府购买乘数：

$$k_G = \frac{1}{1 - 0.8} = \frac{1}{0.2} = 5$$

$$\Delta Y = k_G \times \Delta G = 5 \times 200 = 1000$$

政府购买增加 200 亿，国民收入增加 1000 亿。

再看税收。税收增加 200 亿，税收乘数：

$$k_T = \frac{-0.8}{1 - 0.8} = \frac{-0.8}{0.2} = -4$$

$$\Delta Y = k_T \times \Delta T = -4 \times 200 = -800$$

税收增加 200 亿，国民收入减少 800 亿。

两笔合起来：

$$\Delta Y = 1000 - 800 = 200$$

国民收入净增加 200 亿，正好等于政府收入和政府支出各自增加的量。这就是"平衡"两个字的来历：收 200 亿、支 200 亿，最后收入也动 200 亿。

$$\frac{\Delta Y}{\Delta G} = \frac{200}{200} = 1, \qquad \frac{\Delta Y}{\Delta T} = \frac{200}{200} = 1$$

有人会在这里卡一下：前面讲乘数，不是说政府支出增加会导致国民收入增加好多倍吗？怎么到了这儿，政府支出增加 200 亿，国民收入只增加 200 亿？

因为前提变了。前面那个 5 倍，是"只有政府购买动、税收不动"时的倍数；这里是"政府购买和税收同时、等量动"，两股力量对撞，净效应才剩 1 倍。1000 的正效应被 800 的负效应抵掉大半，剩下的 200 不是乘数失效，是抵消之后的结果。

> **易错点**：$k_G = 5$ 和平衡预算乘数等于 1 不矛盾。前者是单一变量变动，后者是两个变量等量反向变动。看到"政府支出增加 200 亿、国民收入增加 200 亿"，别以为乘数没起作用。

### 把所有式子摆到一张表上

这一块推导多，容易记乱。按部门摆开，脉络就清楚了：不管什么概念，先问几个部门，再问是国民收入的决定还是某个乘数。

国民收入的决定：

| 部门 | 均衡条件 | 定量税下的 Y | 比例税下的 Y |
| :--- | :--- | :--- | :--- |
| 两部门 | $Y = C + I$ | $\dfrac{\alpha + I}{1 - \beta}$ | 不涉及 |
| 三部门 | $Y = C + I + G$ | $\dfrac{\alpha + I + G - \beta T + \beta TR}{1 - \beta}$ | $\dfrac{\alpha + I + G + \beta TR}{1 - \beta(1 - t)}$ |
| 四部门 | $Y = C + I + G + X - M$ | $\dfrac{\alpha + I + G + X - \beta T + \beta TR - M_0}{1 - \beta + \gamma}$ | 不涉及 |

乘数：

| 乘数 | 两部门 | 三部门（定量税） | 四部门 |
| :--- | :--- | :--- | :--- |
| 投资乘数 | $\dfrac{1}{1 - \beta}$ | $\dfrac{1}{1 - \beta}$ | 可求，不作重点 |
| 政府购买乘数 | 无 | $\dfrac{1}{1 - \beta}$ | 不作重点 |
| 税收乘数 | 无 | $\dfrac{-\beta}{1 - \beta}$ | 不作重点 |
| 政府转移支付乘数 | 无 | $\dfrac{\beta}{1 - \beta}$ | 不作重点 |
| 平衡预算乘数 | 无 | $1$ | 不作重点 |

表里有两件事值得再说一句。

一是这些乘数不必死记硬背。现推完全来得及，因为推导本身只有一步：写出 $Y$ 的表达式，然后求偏导。

二是整套推导里真正稍微复杂的，只有"每个部门的 $Y$ 怎么表达"这一段——也就是国民收入的决定。这一段通了，乘数是体力活；这一段卡住，乘数背下来也没用。

> **结论**：这块内容的骨架只有一句话——先把每个部门的 $Y$ 写成"$Y$ 等于什么什么"，再对你要的那个自变量求偏导。前者是国民收入的决定，后者是乘数。平衡预算乘数要单独搞清楚：$\Delta G$ 和 $\Delta T$ 等量变动时，政府购买的正效应与税收的负效应相加，系数正好凑成 1。
