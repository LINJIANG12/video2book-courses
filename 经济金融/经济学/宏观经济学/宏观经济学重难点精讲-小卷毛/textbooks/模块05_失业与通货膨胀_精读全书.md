## 失业：从 AD-AS 走到奥肯定律
> 对应块：BLK14 | 覆盖分集：P13 | 块标题（分集名）：《【宏观经济学】第十六章：失业和通货膨胀（1）：失》

这一讲要抓的重点很集中：失业的概念（尤其是自然失业率）、失业的类型和成因、失业的影响，还有奥肯定律。反失业的政策我不展开，自己看书——高鸿业第七版里这块可能已经没有了，即使没有，也自己找点资料看一看。为什么要看？考试里如果出简答题或者论述题，前面问你失业的类型、失业的影响，最后一定会点一下题，让你结合实际说怎么缓解失业。这部分不能空着。

在正式讲失业之前，先把前面几章串一遍，看看失业是怎么被推出来的。

### 失业从哪里来：先回到 AD-AS

我们最早讲的是国民收入核算，然后过渡到 IS-LM 模型，再往后是 AD-AS 模型。AD-AS 讲的是总供给和总需求：什么是总供给，什么是总需求，以及两条曲线相交构成的模型。说白了，AD-AS 研究的就是总需求和总供给相交的情形。

但总需求和总供给未必总相交在充分就业点上。回忆一下总供给曲线的三种形态：一种是水平的，一种是向右上方倾斜的，还有一种是垂直的。水平和向右上方倾斜的都属于短期，垂直的那条是长期。所以 AD 和短期总供给曲线的交点，只是一个短期均衡点。

找到短期均衡点之后，要拿它和长期总供给曲线比。长期总供给曲线垂直，位置由潜在产出决定。三种情况：短期均衡点正好落在长期总供给曲线上，那它既是短期均衡也是长期均衡，对应的就业情况就是充分就业；落在长期总供给曲线左边，说明这个短期均衡达不到充分就业，就是失业；落在右边，叫超充分就业均衡，不是这一讲的重点。

```text
 P
 ^
 |                   LRAS
 |                     |
 |          AS         |
 |         /           |
 |        /            |
 |       E             |
 |      / \            |
 |     /   \   AD      |
 |    /     \          |
 |   /       \         |
 |  /         \        |
 +-------------------------> Y
        Y1             Yf
```

读图：横轴是产出 Y，纵轴是价格 P；向上倾斜的 AS 是短期总供给，垂直的 LRAS 是长期总供给，位置落在潜在产出 $Y_f$ 上；向下倾斜的 AD 与 AS 交于 E。图中 E 在 LRAS 左侧，这个短期均衡达不到充分就业，对应的就是失业；E 正好落在 LRAS 上就是充分就业；落在右侧则是超充分就业均衡。

为什么从 AD-AS 一下就跳到了失业？因为现实中总需求和总供给会移动——外界的干扰也好，各种情况也好，它们动得非常常见。一旦不交在充分就业点上，价格 P 和产出 Y 就一定会变，于是就有了失业和通货膨胀。

判定口径上一讲已经给过，很简单：只看 Y，Y 减少就叫失业，别管 P 怎么样；只看 P，P 增加就叫通货膨胀，别管 Y 是增是减。如果 Y 减少和 P 增加同时发生，那就是更麻烦的一种情形。

总需求和总供给移动，能组合出四种情况：Y 增加、P 增加；Y 增加、P 减少；Y 减少、P 增加；Y 减少、P 减少。但这么多情况我们管不过来，也不可能每一种都研究。研究问题是为了解决问题，Y 增加是经济繁荣，是好事，不是我们要处理的问题。所以只记住三种：失业、通货膨胀，以及失业和通货膨胀同时发生而且都很严重的那种。其他的不管。

这一讲只把失业讲清楚。

### 失业率：谁才算失业

失业的数据这一块，书上的篇幅不算小，但其实只说明一件事：每个国家都存在失业，所以失业值得研究。要记的概念只有一个——失业率。

> **定义**：失业率是劳动力中没有工作、而又在寻找工作的人所占的比例，等于失业人数除以劳动力人数。

这里面的失业人数有门槛：必须是没有工作、但想工作的人。一个人没有工作，也根本不想工作，他不算失业。

> **提示**：分母是劳动力人数，也就是就业人数加失业人数，不是总人口，也不是单指已经在业的人数。后面的公式里，这个劳动力总数就是 N。

### 自然失业率：稳定不等于相等

这是整讲里最容易被轻轻放过、后面却到处都要用的概念。它本身不算大，但你要是没弄明白，往后学什么都是云里雾里的。

书上给自然失业率下定义时，用的说法是“劳动力市场处于供求稳定状态时的失业率”。这句话里最要命的是“供求稳定”四个字——很多人一眼扫过去，就把它读成了“供求相等”。

> **定义**：自然失业率是经济社会在正常情况下的失业率，也就是劳动力市场处于供求稳定状态时的失业率。这里的稳定状态，指达到了既不会推动通货膨胀、也不会导致通货紧缩的状态。

接下来是最容易搞混的一步。

> **易错点**：供求稳定不是供求相等。

为什么不能理解成相等？劳动力需求等于劳动力供给，意思是我需要多少劳动力，就有多少劳动力来；那不就是每个人都有工作了吗？每个人都能就业，就不存在失业，那还研究什么？所以这里的“稳定”绝不是“均衡”。

“供求稳定”拆开看，就是供给稳定、需求稳定；稳定就是不变。劳动力供给不变，劳动力需求也不变。

失业等于劳动力供给减去劳动力需求。供给不变、需求不变，失业自然也不变。

> **提示**：别记反了——失业对应的是供给大于需求的那一段，是“供给减需求”。想工作的人比岗位多，多出来的那一部分才是失业。

举个最直白的例子：上个月有 100 个人失业，下个月还得是 100 个人失业。如果下个月变成 99 个，或者 101 个，那都不叫自然失业率的状态。

有同学可能会想：少一个人失业不是更好吗？不行。这里的“不变”是一个定义要求，不是让你评判好坏——多一个不行，少一个也不行，就必须是那么多人失业。这一点别绕进去。

> **结论**：自然失业率对应的是失业人数固定不变的状态，不是劳动力市场供求相等。

既然失业人数固定，就有一个必然的推论：找到工作的人数，必定等于失去工作的人数。原来失业的那批人里，有 3 个人找到了工作；要让失业人数保持不变，就必须让原来有工作的人里有 3 个人失业。少一个补不上，多一个就超了。

```text
        f·U（失业者找到工作）
   U -----------------------> E
     <-----------------------
        l·E（就业者失去工作）
```

读图：U 是失业人数，E 是就业人数。上面的箭头是失业者找到工作，流量为 $fU$；下面的箭头是就业者失去工作，流量为 $lE$。自然失业率要求失业人数固定，所以这两个流量必须相等，一进一出刚好抵消。

如果你已经想明白了，这一段可以跳过；如果还没有，就静下心听我啰嗦一遍——肯定有人是没弄懂的。这个概念小归小，不弄清楚，后面讲奥肯定律的时候你还会卡住。

### 自然失业率的公式

先把符号记住：

- N：劳动力总人数；
- E：就业人数；
- U：失业人数；
- l：离职率——这是小写字母 L，不是 i，打印出来很容易看错；
- f：就职率。

劳动力总人数等于就业人数加失业人数：

$$N = E + U$$

所以

$$E = N - U$$

自然失业率的前提是失业人数维持不变，也就是找到工作的人数等于失去工作的人数。原来失业的人里找到工作的是 $fU$，原来就业的人里失去工作的是 $lE$，于是

$$fU = lE$$

把 $E = N - U$ 代进去：

$$fU = l(N - U) = lN - lU$$

把带 U 的项挪到一边：

$$fU + lU = lN$$

$$(f + l)U = lN$$

两边同除以 $N(f + l)$，就得到

$$\frac{U}{N} = \frac{l}{l + f}$$

这就是自然失业率。整个推导的前提只有一个：先框定“找到工作的人数等于失去工作的人数”，再在这个条件下求失业率 $U/N$。

从这个式子能直接读出一件事：自然失业率由离职率和就职率共同决定，离职率越高、就职率越低，自然失业率就越高。它不是一个拍脑袋的数，背后是两个可以观察的劳动力流动量。

### 市场出清：看不见的手把价格推到位

在讲失业的经济学解释之前，先补一个小概念：市场出清。它其实很早就出现过——讲经济学假设的时候，理性人假设之后，最后一个假设就是市场出清。

> **定义**：市场出清指价格具有充分的灵活性、可以自行调整，从而让需求和供给迅速达到均衡的状态。说白了，就是看不见的手在起作用。

市场出清可以直接理解成供求均衡。出清的市场上不会有资源闲置，也不会有超额供给或者超额需求。

在没有大的经济波动的情况下——没有疫情，没有金融风险、金融危机，没有大地震、战争这类大灾难——市场都能自己达到均衡，看不见的手都能发挥作用。反过来说，市场达不到出清，就说明这个社会已经有很大的波动了。

记法就一句：市场出清就是供给和需求相等。

### 古典学派：失业只能怪自己

对失业的经济学解释，主流就两家：古典学派和凯恩斯学派。这两家的总差别一句话就能说清：古典学派是在市场出清的框架下解释失业，凯恩斯是在市场不能出清、存在不均衡的框架下解释失业。

古典学派坚信看不见的手能完全发挥作用，价格有绝对的灵活性，市场自己就能调整，供给和需求总能平衡。落到劳动力市场上也一样：劳动供给和劳动需求相等，形成一个均衡点，对应的就业量就是充分就业量，工资就是均衡工资 $W^*$。

```text
 W
 ^
 |  D \        / S
 |     \      /
 |      \    /
 |       \  /
 |        \/
 |     W* /\
 |       /  \
 |      /    \
 |     /      \
 +------------------> N
        N_e
```

读图：横轴是劳动力数量 N，纵轴是工资 W；向下倾斜的 D 是劳动需求，向上倾斜的 S 是劳动供给，两者交于均衡点，均衡工资是 $W^*$，均衡就业量是 $N_e$。

在这种状态下，理论上不该有失业——需要多少人，就有多少人就业。那现实里确实有失业，古典学派怎么解释？它说，这种条件下的失业只能是自愿失业。不是社会不让你工作，岗位是有的；是你自己不愿意工作，因为你对工资的预期高于均衡工资。

怎么看这个图？在某个就业量上，需求曲线的高度是企业愿意出的工资，供给曲线的高度是工人要求的最低工资。均衡就业量左边，需求曲线在供给曲线上方，企业愿意出的工资高于工人要求的工资，这一段的人都能就业。均衡就业量右边，供给曲线在需求曲线上方，工人要求的工资高于企业愿意出的工资，这一段就是自愿失业——岗位有，你也能干，但你觉得工资不够高，宁缺毋滥，所以不干。

古典学派的态度非常明确：这跟看不见的手一毛钱关系都没有。按照理论，所有人都能工作；之所以有人失业，是他们自己好高骛远，给自己定的目标工资太高。你找不到工作，那是你自己的事，是你自己不愿意工作。

这也是古典学派在所有知识点上的底色：均衡、完美。它认为就业一定能达到充分就业产出，一定能达到潜在产出。

### 凯恩斯：想干，也干不了

凯恩斯不认这个账。他说，谁说所有失业都是自愿的？一定有一部分是非自愿失业。

凯恩斯的出发点是：市场有波动的时候，看不见的手不能完全发挥作用，市场的调节过程非常慢，回不到均衡状态。工资会停在比均衡工资更高的位置——也可能更低，但只有更高才有失业好讲。古典学派认为工资不管怎么着都会回到 $W^*$；凯恩斯认为回不去，工资就停在 $W^{**}$。

```text
 W
 ^
 |  D \        / S
 |     \      /
 |  W** +------+        <- 工资停在 W**，高于均衡
 |       \  /
 |        \/
 |     W* /\
 |       /  \
 |      /    \
 |     /      \
 +------------------> N
        N1    N2
```

读图：工资停在 $W^{**}$，高于均衡工资 $W^*$。在这个工资水平上，劳动需求只有 $N_1$，劳动供给有 $N_2$，供给大于需求，$N_1$ 到 $N_2$ 这一段就是非自愿失业。

非自愿失业和自愿失业的区别，说到底就一句话：自愿失业是不想干，非自愿失业是想干却干不了。

自愿失业是老板开了一个工资，工人觉得不够高，不愿意干。非自愿失业是老板开的这个工资，工人自己能接受，甚至觉得满意，但还是找不到工作。为什么？因为在 $W^{**}$ 这个工资下，供给方和需求方都能接受这个价格，但需求只有那么多。比如供给 10 个人，只需要 8 个，那一定有 2 个人失业。

凯恩斯把原因归到有效需求不足。大的冲击——疫情也好，别的也好——都会造成有效需求不足；有效需求不足，对劳动力的需求就不需要那么多了，供给就显得多了，于是出现非自愿失业。说得直白一点，这些人已经很卑微了：老板开多少都愿意，还是失业，因为大环境萧条了，岗位就是不够。

所以两家摆在一起，差别一目了然：

| 对比项 | 古典学派 | 凯恩斯学派 |
| :--- | :--- | :--- |
| 市场状态 | 市场出清，看不见的手完全发挥作用 | 市场不能出清，存在不均衡 |
| 工资 | 灵活调整，回到均衡工资 $W^*$ | 降不下来，停在 $W^{**}$ |
| 失业类型 | 只有自愿失业 | 自愿失业之外，还有非自愿失业 |
| 失业的归因 | 工人自己要价高于均衡工资 | 有效需求不足，岗位不够 |
| 一句话标签 | 均衡、完美 | 萧条 |

### 失业的类型：空窗期、没能力、萧条期

失业的原因，换一个说法就是失业的类型。书上讲了三种：摩擦性失业、结构性失业、周期性失业。书上的定义挺详细，我这里用最土的话讲一遍，你先把它理解透，要背官方表述再回书上背。

#### 摩擦性失业

摩擦性失业，简单说就是从这份工作换到下一份工作需要时间，这段空档期里的失业就叫摩擦性失业。

打个比方，好比失恋：你和一个人分手之后，总得有一段空窗期，才能找到下一个。这段空窗期就是摩擦性失业。

#### 结构性失业

结构性失业，是指劳动力的供给和需求不匹配造成的失业。它的特点是既有失业，又有职位空缺；一个重要来源是工资刚性——就是刚才凯恩斯图里工资停在 $W^{**}$ 降不下来那件事。

用最土的话说：你想工作，但你没能力。

举个例子。IT 行业刚兴起的时候，互联网行业需要大量人才，岗位有大量空缺；与此同时，夕阳行业在逐渐退出市场，很多手工业人员失业。这些从夕阳行业出来的人，就算看见 IT 行业大把的空缺，也只能看着——因为 IT 不是拽一个人过来就能干的，他没有相应的技能，胜任不了。岗位在，人也在，但配不上，这就是“既有职位空缺又有失业”。

至于为什么叫“结构性失业”，我是这么理解的：这种失业往往发生在结构转型的时期，从农业时代转到手工业时代，从手工业时代转到工业时代，从工业时代转到信息时代，每次结构转型，这种失业都更容易集中出现，所以叫结构性失业。这个理解是我自己猜的，我还没找到理论依据，你听听就行。

#### 周期性失业

周期性失业，是在经济周期的衰退和萧条阶段，因为需求下降而造成的失业。这种失业由整个经济的支出和产出下降造成，也可以叫凯恩斯失业。

只要看到“衰退”“萧条”这几个字，马上想到凯恩斯，就对了。

三种类型各给一个记忆钩子：摩擦性失业记“空窗期”，结构性失业记“没能力”，周期性失业记“萧条期”。

这里多说一句宏观里的流派。宏观经济学里流派不少，预期学派、货币学派等等，但活跃最广泛的是凯恩斯和古典。倒不是说这两家的观点今天还多么站得住脚——有些已经不太能站得住脚了——而是因为他们经典，所以永恒，大多数知识点里都一定有他们两个。你如果不把他们的核心观点先搞清楚，学每一个知识点都会觉得“这是什么玩意儿”。凯恩斯永远和萧条联系在一起；古典永远和均衡、完美联系在一起。

### 奥肯定律：产出要跑多快，失业才会降

失业的影响这一块我不展开，很简单，自己看书。这一节的重点是奥肯定律。

奥肯定律讲的是产出和失业率之间的关系，所以它的公式里主角一定是 Y 和 u。先记一句话：它描述的是实际产出偏离潜在产出、与失业率偏离自然失业率之间的反向关系。

这个公式不是推出来的，是回归出来的。你不用去推它，也推不出来——它是拿数据拟合出来的。用计量软件——EViews、Stata、SPSS 这些——拿数据做回归，奥肯用的是 1947 年到 1996 年的数据，做的是最简单的回归，回归出一个数值关系：

$$\frac{Y - Y_f}{Y_f} = -\alpha (u - u^*)$$

式子里，Y 是实际产出，$Y_f$ 是潜在产出，$\alpha$ 是一个大于零的参数，u 是失业率（小写 u，和前面表示失业人数的 U 区分），$u^*$ 是自然失业率。左边是产出相对潜在产出的偏离幅度，右边是失业率相对自然失业率的偏离幅度，前面带一个负号——产出越高，失业率越低，两者反向。

奥肯定律的重要结论可以拆成两块，都用这个式子看。

第一块：如果想让失业率 u 不变。$u^*$ 是自然失业率，它不变；$\alpha$ 是常数；u 又假设不变，所以右边整个是一个常数。右边是常数，左边就必须是常数。但 $Y_f$ 是会变的——技术进步、人口增长，潜在产出一直在增加，这一点在 AD-AS 那里讲过。$Y_f$ 在变，左边这个整体还要保持不变，那 Y 就必须和 $Y_f$ 有同样大的增长速度。

第二块：如果想让失业率 u 下降。u 下降，$u - u^*$ 就变成负值；$\alpha$ 是正的，前面还有一个负号，负负得正，右边变成正值。右边是正的，左边也必须是正的，也就是 $Y - Y_f > 0$，Y 大于 $Y_f$。换成增长的说法：实际产出的增速要高于潜在产出的增速，失业率才会下降。

> **结论**：想让失业率不变，产出要跟潜在产出同速增长；想让失业率下降，产出必须比潜在产出增长得更快。

那为什么只讨论“u 不变”和“u 下降”，不讨论“让 Y 上升”？因为这条定律是拿去给政策做参考的——报告给国家，问的是“要把失业率按住、甚至压下去，产出得跑多快”，而不是反过来讨论产出上升会怎样。

考试里奥肯定律一般两种出法。名词解释：说清它反映哪两个量之间的关系、说的是什么事。计算题：直接套公式。

## 通货膨胀与菲利普斯曲线
> 对应块：BLK15 | 覆盖分集：P14 | 块标题（分集名）：《【宏观经济学】失业和通货膨胀（2）：通货膨胀、菲》

上一讲把失业讲完了，这一讲把剩下的两块一次讲完：通货膨胀和菲利普斯曲线。

通货膨胀要学的东西不多，说到底就两块：一是它的定义是什么，二是它的成因是什么，也就是哪些原因导致了通货膨胀。菲利普斯曲线也一样，先知道它的定义和概念——它是一条反映失业和通货膨胀率之间关系的线；然后要知道它有不同的版本，从传统的菲利普斯曲线，到附加预期的菲利普斯曲线，最后是长期的菲利普斯曲线。

### 通货膨胀的定义与衡量

先从通货膨胀讲起。这部分基本上是概念性的东西，比较简单，过一遍就好。书上先列了一堆数据来证明通货膨胀的存在，那些数据看一看就能明白，不用专门记。

#### 连续与普遍：两个词定生死

衡量通货膨胀，先得知道它是什么。

> **定义**：当大多数商品和劳务的价格连续在一段时间内普遍上涨的时候，就说明发生了通货膨胀。

这个定义里真正要记的就两个词：连续、普遍。

连续，是说价格上涨必须持续一段时间，偶尔涨一下不算；普遍，是说社会上大多数商品和劳务的价格都在涨，只有少数几种涨也不算。两个条件同时满足，才叫通货膨胀。

#### 价格指数：拿一年当标尺

那用什么来衡量通货膨胀率？主要靠价格指数。

很多同学听到“价格指数”不知道是什么，其实说白了就是：选一年当基期，把那一年的价格水平定成 1，之后每一年的价格都换算成跟这一年相比的一个数。基期是 1，其他年份可能算出一点几，也可能算出零点几——一点几说明比基期涨了，零点几说明比基期跌了。所以价格指数就是衡量价格变动的一个数，消费者价格也好、生产者价格也好，都是这个思路。

这东西最早出现在股市里，后来才被用到宏观经济和各种产业上。

具体怎么算，不需要会。中国统计年鉴里专门有一栏叫价格指数，写论文的时候直接去那里找就行。这块本身不算重要，但不弄明白后面没法听，所以说细一点。

价格指数有很多种，工业价格指数、投资价格指数……一般用来衡量通货膨胀的主要是三个，其中最常打交道的两个是消费价格指数（CPI）和生产者价格指数（PPI）。有个大致印象就够了：通货膨胀率靠价格指数衡量，价格指数去统计年鉴找，自己不用算。不过以后读研写论文，凡是涉及钱的数据都要做平减，那时候价格指数会经常用到。

### 通货膨胀的三种分类

分类这块有三套标准，都好理解，列成表更清楚。

| 分类标准 | 类型 | 怎么分 |
| :--- | :--- | :--- |
| 价格上升的速度 | 温和的、奔腾的、超级的 | 涨得比较平缓是温和；涨得比较快是奔腾；快到难以想象的地步是超级 |
| 对不同商品价格影响的大小 | 平衡的、非平衡的 | 每种商品都按相同比例上涨是平衡；各涨各的比例是非平衡 |
| 人们的预期 | 未预期到的、预期到的 | 涨幅超出预料，甚至根本没想到会涨，是未预期到；反之是预期到 |

三种分类里，第三种值得多说一句：并不是所有通货膨胀都能被预期到，所以未预期到的通货膨胀在现实里反而更常见。

### 从货币看通货膨胀：费雪方程式

通货膨胀的成因是这一讲的难点，也是重点。对同一个问题，经济学界不同流派给出了不同的解释，大致可以归成三个方面：第一，传统货币数量论，也就是货币学派对通货膨胀的解释，它强调货币在通货膨胀中的重要性；第二，从总需求和总供给的角度解释；第三，从经济结构因素的角度解释。一般记住这三条就够了。

这三条里，我个人觉得最不好理解的是第一条——把通货膨胀看成一种货币现象。所以这条要慢慢讲。

货币学派的基本思想，一句话：每一次通货膨胀的背后，都是货币供给的迅速增长。

逻辑其实很好懂：货币供给一下子增加很多，而货币需求还是原来那样，钱不就变得不值钱了吗？钱不值钱了，物价就涨，这就是通货膨胀。

难就难在，货币学派不喜欢只讲这个逻辑，他们要拿出一个式子——费雪方程式。

$$MV = PY$$

很多同学对这个式子很熟，但熟的程度只到“知道它怎么写”：书上告诉你 $M$ 是什么、$V$ 是什么、$P$ 是什么、$Y$ 是什么，你也能背下来，但式子到底在说什么，还是不清楚。我也翻过一些资料，没看到有谁把它讲得特别透，下面说我自己的一层理解，不一定百分之百对。

先把每个字母的意思摆清楚：

| 符号 | 含义 | 一句大白话 |
| :--- | :--- | :--- |
| $M$ | 货币供给量 | 社会上一共有多少钱 |
| $V$ | 货币流通速度 | 同样一笔钱转手了几次 |
| $P$ | 价格水平 | 一件东西卖多少钱 |
| $Y$ | 实际收入水平 | 一年生产出多少东西 |

$V$ 这一项最容易含糊。拿 100 块钱做例子：这 100 块钱经过几个人的手，就是 $V$ 的含义。

$Y$ 这一项，第一章就说过，宏观经济学里它既可以叫收入，也可以叫产出。为什么？因为看的角度不同：$Y$ 说的是这个国家一年生产出多少东西；从“这些东西值多少钱”来看，它叫收入；从“生产出多少产品”来看，它叫产出。所以不用再纠结它到底是收入还是产出，看哪个解释更顺就用哪个。在这个式子里，书上写的是“实际收入水平”，但把它理解成产品数量会更清楚。

式子里的字母都认识了，它到底在说什么？举一个例子最清楚。

假设社会上只有两个人，A 和 B；只有 100 块钱的货币供给，而且这 100 块完完全全在 A 手里。B 一分钱没有，但 B 能生产东西，别的一概忽略不计。

B 想要这 100 块，就对 A 说：你把钱给我。A 同意了，于是 A 把 100 块给 B，B 把东西给 A。

套进式子里：$M$ 是 100；这 100 块只转手了一次，$V$ 是 1；$P$ 是这件东西的价格，100；$Y$ 是 A 拿这 100 块买到的东西数量，也就是 1。于是

$$100 \times 1 = 100 \times 1$$

两边相等，式子成立。

再看两边的经济含义。左边 $MV$ 是什么？是 A 把这 100 块付给 B，也就是这个社会的总支出——这是第一章的知识点，也可以理解成一种需求。右边 $PY$ 是什么？是这个社会实际生产出来的东西值多少钱，也就是这个社会的名义收入水平。

所以 $MV = PY$ 说的其实是：总支出等于名义收入。

> **提示**：没有哪所学校会考“请解释费雪方程式的含义”。应试的话，直接把 $MV = PY$ 记住就行。讲这个例子只是为了让你知道它是怎么来的——有些同学学一个东西，非得知道它的来龙去脉才记得住，那就结合实际理解一下。

有了这个式子，通货膨胀率就能写出来了。把两边取变化率：$M$ 的增长率记作 $m$，$Y$ 的增长率记作 $y$，$V$ 的变化率记作 $v$，$P$ 的增长率就是通货膨胀率 $\pi$。于是

$$\pi = m - y + v$$

$\pi$ 是通货膨胀率，$m$ 是货币增长率，$y$ 是产量增长率。这个式子的意思是：通货膨胀率等于货币增长率减去产量增长率，再加上流通速度的变化。

为什么？货币增长得比产量快，多出来的那部分货币并没有带来实实在在的产量增加，它相当于白发行的，唯一的效果就是让同样的钱买不到同样的东西——这就是通货膨胀。

后面那个 $v$ 呢？它有点像添油加醋：本来货币发行已经超过产量增长、已经造成通货膨胀了，流通速度再一快，等于火上浇油，通胀率更大。不过一般来说我们假定 $V$ 是不变的，$v$ 就是 0，可以不看它。式子就简化成

$$\pi = m - y$$

三种情况一目了然：

- $m = y$：多发行的货币刚好全部转化为产量增加，$\pi = 0$，没有通货膨胀；
- $m > y$：多出来的货币没有变成产量，成了没用的钱，钱不值钱，$\pi > 0$，通货膨胀；
- $m < y$：货币增长跟不上产量增长，物价总体往下走，通货紧缩。

而产量的增长率一般被看作固定不变的，所以 $y$ 也是常数。那么 $\pi$ 就完全由 $m$ 决定了——货币供给的增长速度一大，通货膨胀率就上去。这就从货币的角度解释了通货膨胀：通货膨胀之所以发生，就是因为货币供给多了。

> **结论**：货币学派这条线，记三步就够了。第一步，记住费雪方程式 $MV = PY$；第二步，由它写出通货膨胀率的表达式 $\pi = m - y + v$；第三步，知道 $V$ 和 $Y$ 都不变，所以 $\pi$ 完全由 $m$ 决定。三步走完，货币学派的观点也就验证了：通货膨胀的根源在货币供给。

### 需求拉动：过多的货币追求过少的商品

第二条路是从总需求和总供给的角度解释，叫需求拉动通货膨胀，也叫超额需求通货膨胀。

道理一句话：总需求超过总供给，整个社会的物价水平就被拉上去，通货膨胀就发生了。

供给在市场上表现为商品和服务，需求表现为用于购买和支付的货币。所以这种通货膨胀还有一个更形象的说法：过多的货币追求过少的商品。

书上写了这句话，不少同学卡在这里：明明在讲需求和供给，怎么突然变成货币和商品了？逻辑是这样——需求是什么？你想要这个东西，就得付钱；你对这个社会的需求，都要用货币去支付，所以需求可以理解成你要支付的货币。供给是什么？是这个社会生产出来的商品。需求大于供给，翻译过来就是支付的货币大于生产出来的商品，也就是货币多、商品少。所以叫“过多的货币追求过少的商品”。

商品少、想要的人多，商家会怎么办？提价。谁能买？谁出价高就卖给谁。物价就这么上去了。

图形上更清楚：

```text
   P                                        AS
    ^                                     /
    |                 AD2     \         /
    |                            \  B /
P2  |-------------------------------*
    |              \              / |  \
    |                 \         /   |     \
    |              AD1   \    /     |        \
P1  |-----------------------*       |           \
    |                     / |A \    |             \
    |                   /   |     \ |               \
    |                 /     |       |\
    |               /       |       |   \
    +------------------------------------------> Y
                           Y1      Y2
```

横轴是产出 $Y$，纵轴是价格 $P$。向右上方倾斜的是供给曲线 AS，两条向右下方倾斜的是需求曲线：AD1 是原来的总需求，AD2 是总需求增加之后的位置。总需求增加，需求曲线从 AD1 右移到 AD2，均衡点从 A 移到 B，价格从 $P_1$ 升到 $P_2$，产出从 $Y_1$ 增到 $Y_2$。

$P$ 上涨就是通货膨胀，$Y$ 增加就是经济增长——所以需求拉动型通货膨胀往往和经济增长同时出现。不过我们研究的是通货膨胀，经济增长怎么变可以先不管，只要 $P$ 涨了，就说明通货膨胀确实发生了。

这里有个应试上的提醒。书上把供给曲线的三段都画出来了：水平的一段、正常的一段、古典区域的一段。其实答题没必要，只画正常区域这一段就足够解释，画全了反而容易把自己绕进去。当然你怎么画都行，只画正常段也可以。

> **提示**：答题画 AD-AS 图，只画正常区域那一段向右上方倾斜的供给曲线就够了。

### 成本推动：成本涨了，价格只能跟着涨

第三条路是从供给方找原因，叫成本推动的通货膨胀，也叫成本通货膨胀、供给通货膨胀。

> **定义**：在没有超额需求的情况下，由于供给方成本的提高所引起的一般物价水平的持续上涨，叫成本推动的通货膨胀。

注意，这条和需求方没多大关系，问题出在供给方。供给方为什么提价？因为他买原材料、买要素的成本增加了。成本涨了，他总不能赔本卖，一定要把价格提一点，才能弥补成本上升的损失。

生产者的成本有很多项：买原材料的钱是成本，雇工人的工资也是成本。所以成本上升的原因很多，主要记两种理论就够了：工资推动和利润推动。

先说工资推动。工资推动很好理解：工资涨了，生产者付给劳动者的钱多了，成本就上去了，产品价格只能跟着提。

再说利润推动。利润推动说的是垄断企业利用市场势力谋取过高利润，导致一般物价水平上涨。

能这么干的企业，本身一定有某种优势、某种市场势力，能影响甚至控制产量和价格；通常是一家独大，有完全的操控权，想让东西涨价就涨价，想让它降价就降价。既然有这个能力，让物价上去也就不奇怪了。

这一条记两个字就行：垄断。

### 结构性通货膨胀：各部门不一样，工资却要一样

最后一种是结构性通货膨胀。

> **定义**：在经济运行过程中，既不存在需求拉动，也不存在成本推动，仅仅由于经济结构因素的变化，就导致价格水平持续、普遍地上涨，这叫结构性通货膨胀。

这种理论认为，通货膨胀的起因和前面几种都没关系。比如现在很提倡经济结构转型，转型过程本身就会带来通货膨胀——因为各个部门的特点千差万别。

根源在这里：资本和技术在不同经济部门里有不同的特征，而现代社会的经济结构很难让资本和技术从一个部门顺畅地转移到另一个部门。生产率高的部门——往往是新兴产业——工资先涨；其他部门的员工看到那边工资高，也会要求涨。尤其在西方社会，有工会，大家追求工资平等化，生产率低的部门、发展慢的部门也会向工会提要求：凭什么他们工资那么高，我们也要涨到那个程度。结果整个社会的工资水平都上去了。

工资一涨，又回到了成本推动那条路，物价自然跟着上升。

这一条不用挖太深，知道结构性通货膨胀是什么意思就够了。真正要掌握的是前面几条：货币学派、需求拉动、成本推动。

### 菲利普斯曲线是一条什么线

通货膨胀讲完，下面是这一讲另一个重点：菲利普斯曲线。它不算难，但有一点乱。

先说它是什么。

> **定义**：菲利普斯曲线是一条反映失业率和通货膨胀率之间关系的曲线。

这个概念的来历很朴素：它最初是根据数据得出来的一条经验曲线，没有什么推导过程，把数据画出来，就是一条向右下方倾斜的线。

```text
   π
    ^  \
    |   \\
    |     \\          菲利普斯曲线
    |       \\
    |         \
    |          \\
    |            \\
    |              \\
    +----------------\-----> u
   0                u*
```

横轴是失业率 $u$，纵轴是通货膨胀率 $\pi$。曲线从左上方向右下方走，失业率越低，通货膨胀率越高；失业率越高，通货膨胀率越低。

用公式表示就是

$$\pi = -a(u - u^*)$$

$\pi$ 是通货膨胀率，$u$ 是失业率，$u^*$ 是自然失业率，$-a$ 没有什么实际含义，就是一个负数常数。

这里有个很多人会问的问题：既然是反向关系，直接写成 $\pi = -a \cdot u$ 不就行了，为什么非要写成 $u - u^*$，不是多此一举吗？

不是。这就要用到前面讲过的自然失业率。先看符号，$-a$ 是负数：

- 当 $u > u^*$ 时，$u - u^* > 0$，负数乘正数，$\pi < 0$，通货膨胀率在下降；
- 当 $u < u^*$ 时，$u - u^* < 0$，负数乘负数，$\pi > 0$，通货膨胀率在上升；
- 当 $u = u^*$ 时，$\pi$ 正好等于零。

$u = u^*$ 是什么状态？社会上原来有多少人失业，之后还是多少人失业，不会多一个，也不会少一个——失业停在一个稳定的水平上，这就是自然失业率。

所以式子里的 $u^*$ 不是装饰，它把“失业处在自然率时通货膨胀率为零”这个基准点钉住了；$u$ 相对 $u^*$ 偏高还是偏低，才决定通胀率是往下走还是往上走。

> **提示**：$\pi$ 是通货膨胀率，不是价格水平。$\pi < 0$ 表示价格在往下走，也就是通货紧缩，不是“价格水平为负”。

### 从总需求总供给推出菲利普斯曲线

这条经验曲线后来有了理论推导，路径是从 AD-AS 模型推过来。

还是用前面那张 AD-AS 图：假设总需求增加，AD1 右移到 AD2，AS 不变，均衡点从 A 移到 B，价格从 $P_1$ 升到 $P_2$，产出从 $Y_1$ 增到 $Y_2$。

然后分两头看。

一头看价格。$P$ 上升，就是通货膨胀，$\pi$ 增加。

另一头看产出。$Y$ 增加。前面讲过一个式子，产出由就业量决定——生产函数里资本 $K$ 假定不变，于是 $Y = f(N)$，$N$ 是就业量。所以 $Y$ 增加意味着 $N$ 增加，也就是就业增加；而就业和失业是反向的，$N$ 一增，$u$ 就下降。

```text
总需求增加（AS 不变）
   │
   ├─ 价格 P ↑ ──→ 通货膨胀率 π ↑
   │
   └─ 产出 Y ↑ ──→ 就业量 N ↑ ──→ 失业率 u ↓
```

合起来就是：$\pi$ 上升，$u$ 下降。两者反向变动，画出来就是一条向右下方倾斜的曲线——菲利普斯曲线就这么推出来了。

这个推导怎么记？关键是想清楚每个变量从哪来：通货膨胀率 $\pi$ 看价格 $P$，$P$ 涨就是通胀；失业率 $u$ 不能直接看，要先看产出 $Y$——$Y$ 决定就业 $N$，$N$ 反过来决定 $u$。所以想知道 $u$ 怎么变，直接看 $Y$ 就行。

> **结论**：推导的固定套路是——假设 AS 不变、AD 增加，画出图；一头看 $P$ 推出 $\pi$，一头看 $Y$ 推出 $N$ 再推出 $u$；两边一比，$\pi$ 和 $u$ 反向，曲线向右下方倾斜。

### 菲利普斯曲线的两大类与长短

接下来这块是这一讲最容易乱的地方。书上写得不太统一：一会儿说附加预期的菲利普斯曲线，一会儿又说短期菲利普斯曲线，下一个知识点又讲长期菲利普斯曲线，看完不知道它到底怎么分类。

我的理解是这样：菲利普斯曲线首先分两大类——传统的菲利普斯曲线，和附加预期的菲利普斯曲线。

传统的就是刚才那条 $\pi = -a(u-u^*)$，向右下方倾斜，它不分长期短期。附加预期的菲利普斯曲线出来之后，传统的就少有人提了；后来大家说的长期、短期，其实都是在附加预期的框架下讨论的。

短期和长期怎么界定？就看从预期到实际发生之间的时间长短：间隔短的是短期菲利普斯曲线，间隔长的是长期菲利普斯曲线。

```text
菲利普斯曲线
  ├─ 传统菲利普斯曲线：π = -a(u - u*)，向右下方倾斜
  └─ 附加预期的菲利普斯曲线：π - π^e = -a(u - u*)
       ├─ 短期：从预期到实际间隔短，向右下方倾斜
       └─ 长期：从预期到实际间隔长，垂直于 u*
```

考试口径要记牢：只要题目说“菲利普斯曲线”或者“附加预期的菲利普斯曲线”，没有特意强调长期，那就默认写短期的。换句话说，附加预期的菲利普斯曲线和短期菲利普斯曲线，其实是一回事；只有题目明确说“长期菲利普斯曲线”，才写长期那条。

> **易错点**：题目不特指长期时，不要自作主张写长期曲线。“附加预期”四个字一出现，默认就是短期。

### 附加预期的菲利普斯曲线是怎么来的

先说它是怎么来的。

20 世纪 70 年代石油危机爆发，美国出现了一个反常现象：失业率上升，通货膨胀率也同时上升。这种局面还在全球范围内蔓延开来。

按传统菲利普斯曲线，$\pi$ 和 $u$ 应该是反向的，画出来是一条规整的向右下方倾斜的线。但现实数据不是这样：从 1966 年到 1969 年，$\pi$ 和 $u$ 是同向上升的——一个涨，另一个也涨，正相关。光这几年，就足以让传统曲线站不住脚。

可有意思的是，又有些年份是符合传统曲线的：1981 到 1982 年就很正常，向右下方倾斜；1989 到 1992 年也大致可以看成向右下方倾斜。于是数据看起来乱七八糟：有的年份正相关，有的年份负相关。

这时候弗里德曼出现了。他是货币主义的代表人物，但他给出的关键词只有两个字：预期。

他指出传统菲利普斯曲线有一个重要缺陷——它忽略了影响工资变动的一个重要因素：工人对工资的预期。

逻辑是这样的：劳资双方谈新工资协议的时候，人们会对协议期间的通货膨胀率做一个预期，并根据这个预期去调整名义工资。预期通胀率越高，名义工资涨得越快。通俗地说，工人如果预感到接下来钱要不值钱了，就会在跟老板谈合同时要求把名义工资定高一点。

这里可能有人要问：我们研究菲利普斯曲线，讲的一直是 $\pi$ 和 $u$ 的关系，扯名义工资干什么？

答案在下面的式子里。把预期加进去，式子就变成

$$\pi - \pi^e = -a(u - u^*)$$

怎么记？就是在传统公式的左边多减一个 $\pi^e$。$\pi^e$ 是预期通货膨胀率。

$\pi - \pi^e$ 的含义很直白：你今年预期明年的通胀率是多少，到了明年才知道这个预期准不准；$\pi - \pi^e$ 量的就是“你当时预期得准不准”。准不准，决定了这条曲线往哪走。

### 预期准不准，决定失业率往哪边走

分三种情况看。三种情况里，最重要的是相等那一种，因为长期菲利普斯曲线全靠它。

#### 预期与实际相等

$\pi = \pi^e$，也就是 $\pi - \pi^e = 0$。代进式子，右边 $-a(u-u^*) = 0$，而 $-a$ 不是零，所以只能 $u - u^* = 0$，即 $u = u^*$。

经济含义：工资合同是提前签的，签的时候双方按预期通胀率把名义工资定下来。到了第二年，如果实际通胀刚好等于预期，每个人拿到手的工资正好就是当初想要的那份，大家都满意，都愿意继续干，没有人新失业，失业率就停在自然失业率上。

这种情况在现实里当然少见，预期和实际很难刚好吻合。但只要不相等，失业率就会偏离自然率——往哪边偏，就看预期是偏高还是偏低。

#### 实际通胀高于预期

$\pi^e < \pi$，即 $\pi - \pi^e > 0$。左边为正，右边也必须为正：$-a(u-u^*) > 0$，$-a$ 是负数，所以 $u - u^* < 0$，得到 $u < u^*$。

文字上怎么理解？名义工资是按较低的通胀预期谈定的。实际通胀比预期高，这份名义工资的实际购买力就比当初预想的低——对厂商来说，实际用工成本变便宜了。好比原本以为要花十块钱才雇得到一个人，结果只花了五块钱，那当然愿意多雇几个。厂商扩大生产、增加雇佣，失业率就降到自然率以下。

这里的关键是：合同已经签了，名义工资短期改不了，所以先动的是厂商的雇佣量。工人事后发现自己买亏了，会在下一轮谈判里要求补回来——这正是预期会被不断修正的原因。

#### 实际通胀低于预期

$\pi^e > \pi$，即 $\pi - \pi^e < 0$。同样推：$-a(u-u^*) < 0$，$-a$ 是负数，所以 $u - u^* > 0$，得到 $u > u^*$。

经济含义反过来：名义工资按较高的通胀预期谈定，结果实际通胀更低，这份工资的购买力比预想的强。对厂商来说，等于原本以为五块钱能雇到的人，实际要花十块钱，用工成本变贵了，于是减少生产、少雇人，失业率升到自然率以上。

这两种情况的文字解释，书上没有展开。但不把它们搞清楚，后面长期菲利普斯曲线为什么是竖直的，就理解不了。

### 长期菲利普斯曲线为什么是竖直的

长期和短期的分界，还是从预期到实际的时间长短。

按西方学者的说法，在长期中，人们会根据实际发生的情况不断调整自己的预期。时间足够长，你一直在做预期这件事，就会越来越有经验，预期和实际迟早会走到一致。所以长期菲利普斯曲线的前提就是：$\pi = \pi^e$。

把这个条件代进式子：

$$\pi - \pi^e = -a(u-u^*) \quad\Longrightarrow\quad 0 = -a(u-u^*) \quad\Longrightarrow\quad u = u^*$$

失业率等于自然失业率。这意味着什么？不会有人新失业，也不会有新人进入就业，失业水平不增不减，固定在一个位置上。横轴上固定在一个点，画出来就是一条竖线：

```text
   π
    ^            |
    |            |
    |            |  长期菲利普斯曲线
    |            |
    |            |
    |            |
    |            |
    |            |
    +---------------------> u
   0            u*
```

所以长期菲利普斯曲线就是一条垂直于 $u^*$ 的直线。书上在垂直线之外还画了两条斜线，那容易让人犯迷糊：长期曲线到底是斜的还是竖的？答案就是竖的那条。

> **提示**：长期菲利普斯曲线的形状只有一个答案——垂直于自然失业率的竖线。预期可以不断调整，所以长期里失业率总会回到 $u^*$。

### 菲利普斯曲线的完整框架

最后把菲利普斯曲线的分类收成一个框架。

| 曲线 | 公式 | 图形 | 要点 |
| :--- | :--- | :--- | :--- |
| 传统菲利普斯曲线 | $\pi = -a(u-u^*)$ | 向右下方倾斜 | 不分长期短期，记公式和图像即可 |
| 附加预期（短期） | $\pi - \pi^e = -a(u-u^*)$ | 向右下方倾斜 | 题目不特指长期时，默认写这一条 |
| 附加预期（长期） | $\pi - \pi^e = -a(u-u^*)$ | 垂直于 $u^*$ | 预期与实际一致，$u = u^*$ |

短期的图像其实不止一种画法。严格说，它画出来是向右下方倾斜还是向右上方倾斜，取决于 $\pi$ 和 $\pi^e$ 的关系；拿不同预期下的点连起来看，就可能出现向右上方倾斜的一段——现实数据里那些“乱七八糟”的年份就是这么来的。但书上只讨论向右下方倾斜这一种，那考试就记这一种，不用多此一举再去记右上倾斜的画法。心里知道有这么回事就行。

长期就简单了：$\pi = \pi^e$，实际通胀和预期通胀吻合，曲线是竖直的。

这一讲要讲的就是这些：通货膨胀的定义、衡量、分类和几条成因，加上菲利普斯曲线的定义、推导、分类，以及预期在短期和长期里扮演的不同角色。
