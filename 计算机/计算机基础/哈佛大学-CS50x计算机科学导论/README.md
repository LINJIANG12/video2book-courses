# 哈佛大学 CS50x：计算机科学导论（2026）

哈佛大学 David Malan 开设的 CS50x 计算机科学导论（2026 季），公认最好的计算机入门课之一，面向零基础与非专业学生。全课先用 Scratch 建立编程直觉，再用 C 语言自底向上拆开一台计算机，随后依次引入算法复杂度、内存与指针、数据结构、Python、SQL、人工智能搜索，最后以 HTML/CSS/JavaScript 与 Flask 收尾，做出一个真正能跑的 Web 应用。

- **原视频**：https://www.bilibili.com/video/BV1XQ6mBWEoS — Bilibili，BV1XQ6mBWEoS
- **12 集**，已产出 12 册模块全书、11 篇复习笔记、31 份逐字稿

## 怎么学

- **先建立直觉** → 模块 01 用 Scratch 与二进制把「程序到底在做什么」讲透，零基础务必从这里开始
- **用 C 看清底层** → 模块 02、03 讲命令行工具链、控制流、数组与字符串，CS50 的编译调试环境是全课的主线
- **吃透算法与内存** → 模块 04~06 覆盖 O 记号、排序搜索、指针与堆管理、链表与哈希表，是 CS 与数据结构的地基
- **换语言与换范式** → 模块 07、08 讲 Python 的简洁与字典建模，再进入 SQL 的关系模型与多表查询
- **做出一个应用** → 模块 09~11 从 HTTP 讲到 Flask 路由、模板与会话管理，目标是交付一个完整 Web 项目
- **复盘** → `notes/` 下的 11 篇笔记按知识体系聚合，适合考前速查与二次整理成脑图
