# 基数排序LSD与计数排序

## 排序算法稳定性与多关键字级联

### 稳定性核心机理

* **稳定性（Stability）**
    * > **定义**：待排序序列中若存在键值相等的等价元素，在排序完成后其相对先后物理次序严格保持不变的算法属性。
    * 数学判准：设输入序列中存在元素对 $(A_i, A_j)$，其对应键值为 $Key(A_i) = Key(A_j)$；若在输入中索引满足 $i < j$，排序后在新序列中的最终索引 $i'$ 与 $j'$ 恒满足 $i' < j'$。
    * 多关键字级联排序规则：先按次要关键字完成排序，再基于主要关键字执行稳定排序；高位稳定排序通过保留同键分组内部原序，自动达成多字段层级有序。
    * > **易错点**：若在多关键字级联排序的后续轮次中使用不稳定排序，同类内部已排好的低位有序性会被跨距离交换彻底破坏。

### 经典排序算法稳定性判定

* **经典算法稳定性判定**
    * > **定义**：由排序算法的底层元素交换机制决定的等价元素相对位置保全特征。
    * 插入排序（Insertion Sort）：稳定。向前寻位扫描时比较条件严格限定为小于才后移，遇相等元素立即停步，杜绝跨越。
    * 归并排序（Mergesort）：稳定。合并两个有序半区时，当左右两指针元素相等，强制优先提取左半区元素。
    * 堆排序（Heapsort）：不稳定。堆化与下沉调整过程中，父子节点在二叉树层级之间长距离跳跃交换，无视初始物理顺序。
    * 快速排序（Quicksort）：实现相关。原地双指针头尾对调（Hoare 或 Lomuto 分区）破坏相对顺序；开局随机打乱（Shuffle）直接摧毁稳定性；非原地三路划分按原序追加至新空间则可保持稳定。

### 工业级双轨排序选型设计

* **双轨排序选型机制（Dual-Track Sorting Architecture）**
    * > **定义**：标准库根据待排数据的物理类型及附加属性特征，在底层路由至不同排序实现的工程设计。
    * 引用类型数组（Object[]）：底层采用 TimSort（自适应归并排序）。对象类型通常包含多维卫星数据（Satellite Data），必须保障排序稳定性以支持多级排序逻辑。
    * 原始基本类型数组（Primitive Types）：底层采用双轴快速排序（Dual-Pivot Quicksort）。基本数值本身无任何附加属性，等价项无相对顺序区分语义，优先追求极致运行速度与 $O(1)$ 原地辅助空间。

## 计数排序与非比较排序下界突破

### 比较排序理论下界与非比较绕行路径

* **比较排序下界（Comparison Sort Lower Bound）**
    * > **定义**：基于两两比较决定相对次序的排序算法，在最坏情况下的信息论理论下限。
    * 判定树模型推导：$N$ 个不同元素的全排列共有 $N!$ 种可能；高度为 $h$ 的二叉判定树叶子数至多为 $2^h$；由 $2^h \ge N!$ 推得下界 $T(N) = \Omega(N \log N)$。
    * 非比较绕行机理：摒弃元素间的两两比对，通过数值直接映射物理时间或数组下标，打破基于比较的下界约束。
* **单值直接寻址排序（Direct Addressing Sort）**
    * > **定义**：利用键值到数组连续物理下标的单射关系，以空间换时间实现无比较原位映射的排序机制。
    * 约束条件：键值必须落在紧凑的离散有限区间，且要求各记录键值互不重复。

### 稳定计数排序执行流程

* **计数排序（Counting Sort）**
    * > **定义**：通过统计键值出现频次并计算前缀累加偏移量，将元素直接派发至目标连续区间的非比较稳定排序算法。
    * 算法执行时序：
        ```text
        原数组 (N 个元素):
          [黑桃 Lauren] -> [红桃 Delbert] -> [梅花 Alice] -> [黑桃 Jason]
               |
               v (步骤 1: 频次统计 Counts, 耗时 Θ(N))
          counts 数组: [梅花: 3, 黑桃: 2, 红桃: 4, 方块: 3]
               |
               v (步骤 2: 计算前缀和 Starts, 耗时 Θ(R))
          starts 数组: [梅花: 0, 黑桃: 3, 红桃: 5, 方块: 9]
               |
               v (步骤 3: 正向遍历，写出并自增偏移，耗时 Θ(N))
        输出数组:
          [0: 梅花 Alice] ... [3: 黑桃 Lauren] [4: 黑桃 Jason] [5: 红桃 Delbert]
        ```
    * 步骤一（Counts）：单次遍历原数组，统计各离散键值频次，时间开销 $\Theta(N)$。
    * 步骤二（Starts）：累加频次数组生成前缀和，得到各分类在目标数组中的起始下标，时间开销 $\Theta(R)$。
    * 步骤三（Target Placement）：正向扫描原数组，查验 Starts 数组写入目标位置，对应起始偏移量递增，时间开销 $\Theta(N)$。
    * 稳定性保障机制：正向遍历时，同键元素先扫描者必定先入较小偏移槽位，原始相对顺序完整保留。
    * > **提示**：计数排序总时间复杂度为 $\Theta(N + R)$，辅助空间复杂度为 $\Theta(N + R)$，其中 $R$ 为离散键值取值范围大小。

### 计数排序与快速排序的参数博弈

* **双变量博弈模型（Two-Variable Trade-off）**
    * > **定义**：排序算法效能由数据规模 $N$ 与值域范围 $R$ 共同决定的非对称竞争模型。
    * $R \gg N$ 场景（值域离散跨度极大，如全球前 100 大城市按人口数量排序）：计数排序受制于超大频次数组的内存分配与清零初始化，性能被 $\Theta(R)$ 拖垮；快速排序消耗 $\Theta(N \log N)$ 显著占优。
    * $N \gg R$ 场景（海量数据且基数极小，如百万用户按 4 种花色排序）：计数排序呈现线性 $\Theta(N)$，相比快速排序的 $\Theta(N \log N)$ 具有绝对优势。
    * > **易错点**：不可盲目套用线性时间标签；当值域范围 $R = \Omega(N \log N)$ 时，计数排序的实际执行效率劣于比较排序。

## LSD基数排序与高位分治扩展

### 逐位排序与字符集降维

* **逐位排序（Digit-by-Digit Sorting）**
    * > **定义**：将复合键拆分为多个定宽符号位，依位权权重分别执行单字段排序的算法架构。
    * 字符集降维：将大取值范围 $R$（如数值区间 $[0, 43000]$）降解为多位固定基数（如十进制字符集 $R=10$ 或英文字母集 $R=26$），消除计数排序的空间膨胀。
    * 级联正确性约束：各轮次排序算法必须具备绝对稳定性，高位排序在将同键归入同一区间时，严格保留前次排序建立的低位相对有序性。

### LSD基数排序执行规范与对齐法则

* **最低有效位基数排序（LSD Radix Sort）**
    * > **定义**：从最低有效位开始向最高有效位单向推进，每轮针对当前数位执行稳定计数排序的算法。
    * 数据对齐法则：以序列中最长键位宽 $W$ 为基准，短数据在高位（左侧）隐式补零（Zero-padding），空位作为字符集最小符号参与统计分布。
    * 执行状态转移时序：
        ```text
        待排序数据 (宽度 W=3, 基数 R=10): [043, 817, 009, 033]

        第 1 轮 (按个位 3, 7, 9, 3 稳定排序):
          输出: [043, 033, 817, 009]  (个位同为 3 的项保持相对次序)

        第 2 轮 (按十位 4, 3, 1, 0 稳定排序):
          输出: [009, 817, 033, 043]  (十位按 0, 1, 3, 4 排列)

        第 3 轮 (按百位 0, 8, 0, 0 稳定排序):
          输出: [009, 033, 043, 817]  (全局升序达成)
        ```

### LSD时间复杂度三参数推导

* **三参数运行时间（Three-Parameter Complexity Model）**
    * > **定义**：算法运行时性能由输入规模 $N$、最大位宽 $W$、字符基数 $R$ 联合约束的复杂度度量。
    * 时间复杂度公式：$T(N, W, R) = \Theta(W \cdot (N + R))$。
    * 空间复杂度公式：$S(N, R) = \Theta(N + R)$。
    * $W \cdot R$ 项不可约减机理：即使在物理内存中复用大小为 $R$ 的频次数组，每一轮在开始提取当前位前，必须耗费 $\Theta(R)$ 步执行数组清零及前缀累积，该代价累计发生 $W$ 轮，严谨写作 $\Theta(W \cdot (N + R))$。
    * > **易错点**：将空间复用等同于时间复用，误把复杂度记为 $\Theta(W \cdot N + R)$。

### MSD高位优先基数排序的分治机理

* **最高有效位基数排序（MSD Radix Sort）**
    * > **定义**：自最高有效位向低位推进，并在每一位派发后划分子问题执行递归处理的分治基数排序算法。
    * LSD 长键性能瓶颈：针对前缀区分度极高的超长文本，LSD 必须强制执行全量 $W$ 轮计数排序，导致低位无意义遍历。
    * MSD 跨桶交叉陷阱：若自左向右排序时不拆分子问题而直接全局排序，次高位的全局计数会直接冲跨最高位建立的分组边界。
    * 分治隔离机制：最高有效位排序完成后，依据首字符划分为物理隔离的独立子桶，各子桶内部独立递归处理下一位，严禁跨桶混合计算。
