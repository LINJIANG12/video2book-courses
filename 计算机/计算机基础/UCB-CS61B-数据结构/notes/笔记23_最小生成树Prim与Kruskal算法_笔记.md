# 最小生成树Prim与Kruskal算法

## 图论基础与割性质定理

### 生成树与最小生成树

* **生成树（Spanning Tree，ST）**
    * > **定义**：包含连通无向加权图中全部 $V$ 个顶点，且边数恰好为 $V - 1$ 的极小连通无环子图。
    * 边数条件：顶点数为 $V$ 的图，其生成树必然包含且仅包含 $V - 1$ 条边。
    * 拓扑约束：生成树内严禁存在环路（Cycle），且图内不存在任何孤立节点。
    * 图属性：生成树是整张图的全局结构，不依附于任何指定源点。
    * > **易错点**：生成树必须连通全图所有顶点，边数少于 $V - 1$ 会导致非连通，边数多于 $V - 1$ 会导致成环。

* **最小生成树（Minimum Spanning Tree，MST）**
    * > **定义**：连通无向加权图的所有合法生成树中，边权重绝对累加和最小的生成树。
    * 唯一性判定：若图中所有边的权重互不相等，则图的最小生成树唯一确定。
    * 非唯一性条件：若存在两条或多条权重相同的边，图可能存在多棵总权重相等的最小生成树。
    * 适用图类型：标准最小生成树及割性质仅适用于无向图，有向图中的树形结构属于最小树形图（Arborescence）。
    * > **易错点**：图存在多棵最小生成树时，各生成树的总权重必然严格相等，但边的拓扑组合各不相同。

```text
       原加权无向图                                 最小生成树 (MST)
     (B)-------(2)-------(C)                     (B)-------(2)-------(C)
    /   \               /   \                   /                     \
  (4)   (1)           (3)   (5)               (4)                     (5)
  /       \           /       \               /                         \
(A)-------(6)-------(D)-------(7)-------(E) (A)             (D)-------(7)-------(E)
                                                              \
                                                              (3)
```

### 割与横切边

* **割（Cut）**
    * > **定义**：将图的顶点集合 $V$ 划分为两个互不相交且非空的子集 $S$ 与 $V \setminus S$ 的二元划分。
    * 状态标记：子集 $S$ 的顶点可抽象标记为集合一，子集 $V \setminus S$ 的顶点标记为集合二。
    * 划分任意性：全图共有 $2^{V-1} - 1$ 种非平凡割的划分方案。

* **横切边（Crossing Edge）**
    * > **定义**：一端端点属于集合 $S$，另一端端点属于集合 $V \setminus S$ 的边。
    * 判定规则：两端点位于同一顶点集合内部的边不是横切边。
    * > **易错点**：只有跨越两个划分集合边界的边才计入横切边，内部连边不具备横切属性。

### 割性质定理与反证法推导

* **割性质定理（Cut Property Theorem）**
    * > **定义**：对于连通无向加权图的任意割，跨越该割的所有横切边中权重最小的边，必然属于该图的最小生成树。
    * 并列最小情形：若存在多条并列最小权重的横切边，则至少存在一棵最小生成树包含其中之一。

* **割性质的反证法推导**
    * 假设反论：设割划分集合为 $S$ 与 $V \setminus S$，$e$ 为跨越该割的最小权重横切边。反设 $e$ 不属于图的最小生成树 $T$（$e \notin T$）。
    * 强行加边成环：将边 $e$ 加入最小生成树 $T$ 中，得到的子图 $T \cup \{e\}$ 必然存在且仅存在一个简单环。
    * 导出回路横切：边 $e$ 跨越了割 $S$ 与 $V \setminus S$，环上路径必须再次跨越该割回到起点，因此环上必然存在另一条不同于 $e$ 的横切边 $f$（$f \in T$ 且 $f \neq e$）。
    * 换边重构生成树：删除边 $f$，定义新子图 $T' = T \cup \{e\} \setminus \{f\}$。$T'$ 连通全图且无环，满足生成树定义。
    * 权重极小性矛盾：由 $e$ 是该割的最小横切边可知 $\text{Weight}(e) < \text{Weight}(f)$，则 $\text{Weight}(T') = \text{Weight}(T) + \text{Weight}(e) - \text{Weight}(f) < \text{Weight}(T)$。
    * 推导结论：$T'$ 的总权重小于最小生成树 $T$ 的总权重，与 $T$ 为最小生成树的前提矛盾，反设不成立，割性质成立。

### 随机割算法的工程局限

* **随机割构造策略**
    * 算法步骤：抛硬币将顶点随机分流至两个子集构造割，取横切边中权重最小者入树，循环至收集满 $V - 1$ 条边。
    * 正确性：每一次基于割性质挑选的最小横切边均在数学上保证合法。
    * 工程缺陷：随机生成割无法保证状态收敛，存在盲目重叠与空转开销，算法期望耗时不可控。

## Prim算法原理与单边松弛机制

### 动态割增长模型

* **概念版 Prim 算法**
    * > **定义**：以单顶点为起点，将已访问树顶点作为集合 $S$、未访问顶点作为集合 $V \setminus S$ 构成动态割，每步挑选最小横切边向外扩张的生成树算法。
    * 起始点无偏性：任选图内任意顶点作为算法起点，输出的最小生成树总权重与形态均相同。
    * 割动态演进：每吸纳一个新顶点加入树集合，割即刻发生位移，横切边集合随之动态重构。
    * 并列边处理：出现并列最小横切边时任选其一加粗，严禁同时加入导致结构成环。
    * 扫描性能瓶颈：全量暴力扫描所有跨越树内与树外的横切边，单步时间复杂度高达 $O(E)$。

```text
步骤 1: 割为 {A} vs {其余}                  步骤 2: 吸收最近点 C, 割为 {A,C} vs {其余}
      [A] ----横切候选边---- (B)                  [A] ================== (C)
       |                      |                    \                    /   \
   横切候选边             横切候选边              横切候选边          横切候选边  (其余点)
       |                      |                      \                /       /
      (C) ------------------ (D)                      (B) ---------- (D)
```

### 优先队列与按树松弛实现

* **按树单边松弛（Relaxation to Tree）**
    * > **定义**：考察顶点到当前生成树的最短单边距离，而非到起始源点的累积路径距离的松弛机制。
    * 松弛方程：考察边 $(u, v)$ 时，更新判据为 $\text{weight}(u, v) < \text{distTo}[v]$。
    * > **易错点**：Dijkstra 算法松弛方程为 $\text{distTo}[u] + \text{weight}(u, v) < \text{distTo}[v]$（累积距离），Prim 算法严禁累加源点路径，仅比对单边权重 $\text{weight}(u, v)$。

* **边状态晋升机制**
    * 待定状态（虚线边）：节点松弛成功时写入的前驱边，记录当前已知的最小接入权重，可被后续更小权重边覆写。
    * 确定状态（加粗边）：节点在优先队列中取得全局最小键值并出队标记的瞬间，对应前驱边永久加入最小生成树。
    * 割性质支撑：节点出队时刻，该边为连接“树内已处理顶点集”与“未处理顶点集”的最小横切边，边权具有不可替代性。

```text
       Dijkstra: 以源点为核心辐射最短路径树            Prim: 依赖割性质横向蔓延的最小生成树
                 [源点 S]                                     (A)========(C)
                /   |   \                                      \\        //
              (A)  (B)  (C)                                    (B)      (E)
             /      |     \                                              \\
           (D)     (E)    (F)                                            (D)====(G)====(F)
```

### Prim算法复杂度模型

* **成本模型分解（基于二叉堆优先队列）**

| 底层数据结构操作 | 对应算法动作 | 执行次数上限 | 单次耗时（二叉堆） | 总耗时 |
| :--- | :--- | :--- | :--- | :--- |
| `insert(v, priority)` | 将全图顶点压入优先队列 | $V$ | $O(\log V)$ | $O(V \log V)$ |
| `removeSmallest()` | 弹出并标记距离树最近的顶点 | $V$ | $O(\log V)$ | $O(V \log V)$ |
| `changePriority(v, p)` | 松弛成功更新未访问节点的树边距 | $E$ | $O(\log V)$ | $O(E \log V)$ |

* **渐近运行时间**
    * 串行耗时累加：$\text{Total Time} = O(V \log V) + O(V \log V) + O(E \log V) = O((V + E) \log V)$。
    * 连通图收敛界：连通无向图满足 $E \ge V - 1$，主导项由边数决定，时间复杂度记为 $O(E \log V)$。

## Kruskal算法与双数据结构协同

### 边权贪心策略与割性质映射

* **自下而上贪心加边**
    * > **定义**：将全图所有边按权重升序排列，依次检验各边，在不破坏无环约束的前提下逐条将边收编进生成树的算法。
    * 初始状态：全图由 $V$ 个独立的单节点连通分量组成，呈现“森林”结构。
    * 终止条件：成功收编 $V - 1$ 条边后立即停止计算。

* **Kruskal算法的割性质映射**
    * 割的构造：考察待选候选边 $e = (u, v)$，若加入 $e$ 不成环，则将当前包含顶点 $u$ 的连通分支设为集合 $S$，其余所有顶点设为 $V \setminus S$。
    * 极小性证明：算法严格依照边权升序遍历。在考察 $e$ 之前，没有任何横切边能够连接 $S$ 与 $V \setminus S$；后续待考察边的权重均不小于 $e$。
    * 割性质应用：边 $e$ 是该割中被访问的第一条横切边，即该割的最小权重横切边，必然属于最小生成树。

### 优先队列与加权并查集协同

* **双数据结构职责分离**
    * 边权提取：由最小优先队列（Min-PQ）维护边集或直接对边集数组执行快速排序。
    * 环检测（Cycle Detection）：由带路径压缩的加权并查集（Weighted Quick Union with Path Compression，WQU-PC）维护顶点连通状态。

* **并查集判环状态转换**
    * 连通性测试：从堆中取出候选边 $(u, v)$，调用 `isConnected(u, v)`：
        * 若返回 `true`：两点已在同一连通分量内部，加入该边必然成环，丢弃该边。
        * 若返回 `false`：两点位于不同连通分量，加入该边绝不成环，收编进树。
    * 集合合并：收编候选边后，调用 `union(u, v)` 将两个连通分量合并。

```java
// Kruskal 核心骨架伪代码
MinPQ<Edge> pq = new MinPQ<>(edges);
WeightedQuickUnionPC uf = new WeightedQuickUnionPC(V);
List<Edge> mst = new ArrayList<>();

while (!pq.isEmpty() && mst.size() < V - 1) {
    Edge e = pq.removeSmallest();
    int u = e.either(), v = e.other(u);
    if (!uf.isConnected(u, v)) {
        uf.union(u, v);
        mst.add(e);
    }
}
```

### Kruskal算法复杂度模型

* **成本模型分解（基于最小堆与加权并查集）**

| 底层数据结构操作 | 对应算法动作 | 执行次数上限 | 单次耗时 | 总耗时 |
| :--- | :--- | :--- | :--- | :--- |
| `PQ.insert(e)` | 初始化将全图边插入优先队列 | $E$ | $O(\log E)$ | $O(E \log V)$ |
| `PQ.removeSmallest()` | 按序取出边权最小的候选边 | $E$ | $O(\log E)$ | $O(E \log V)$ |
| `WQU.isConnected(u, v)` | 检查边两端端点是否成环 | $E$ | $O(\alpha(V))$ | $O(E \alpha(V))$ |
| `WQU.union(u, v)` | 合并不成环的两个连通分支 | $V - 1$ | $O(\alpha(V))$ | $O(V \alpha(V))$ |

* **渐近运行时间**
    * 逆阿克曼函数：$\alpha(V)$ 为单调增长极其缓慢的函数，实际物理范围内值小于等于 4，可视为常数级 $O(1)$。
    * 综合总耗时：优先队列处理边的排序开销主导整体性能瓶颈，总时间复杂度为 $O(E \log V)$。

### 预排序优化与高阶理论边界

* **边预排序特化边界**
    * 触发场景：输入边列表天然按权重非降序排列，可完全省略优先队列构建。
    * 特化耗时：仅保留指针扫描与并查集操作，算法运行时间降为 $O(E \cdot \alpha(V))$，达到近似线性时间。

* **高级优先队列与理论极限**
    * 斐波那契堆优化：Prim 算法若基于斐波那契堆实现，因 `decreaseKey` 摊还耗时为 $O(1)$，时间复杂度优化至 $O(E + V \log V)$。
    * 稠密图适配性：在完全图或稠密图（$E \approx V^2$）中，基于斐波那契堆的 Prim 算法时间复杂度为 $O(V^2)$，优于 Kruskal 算法的 $O(V^2 \log V)$。

## 算法横向对比与核心推导题

### 最小生成树与最短路径树本质对比

* **MST 与 SPT 核心特征对照**

| 比较维度 | 最小生成树（MST，Prim / Kruskal） | 最短路径树（SPT，Dijkstra） |
| :--- | :--- | :--- |
| 优化目标 | 全图所有边权之和全局最小 | 从指定源点到各顶点的路径累积距离最短 |
| 源点依赖 | 无源点，属于无向图的整体属性 | 强依赖固定源点，以源点为拓扑根 |
| 松弛计算准则 | $\text{weight}(u, v) < \text{distTo}[v]$（单边权） | $\text{distTo}[u] + \text{weight}(u, v) < \text{distTo}[v]$（累积路径） |
| 树的拓扑形态 | 跨越割横向蔓延，无发散核心 | 以源点为核心向外辐射 |

### 典型计算与推导分析题

* **Kruskal 算法操作成本与渐近时间推导**
    * 题干：建立数据结构操作成本模型，推导基于最小优先队列与带路径压缩加权并查集实现的 Kruskal 算法在最坏情况下的渐近时间复杂度。
    * 解析依据：
        * 顶点数为 $V$、边数为 $E$ 的连通图，最小堆初始化容纳 $E$ 条边，总耗时为 $O(E \log E) = O(E \log V)$。
        * 最坏情况下需要弹出全量 $E$ 条边，堆的 `removeSmallest` 操作执行 $E$ 次，单次耗时 $O(\log E)$，总耗时为 $O(E \log V)$。
        * 判环调用 `isConnected` 最多 $E$ 次，合并集合调用 `union` 恰好 $V - 1$ 次。带路径压缩的加权并查集均摊单次耗时为 $O(\alpha(V))$，并查集部分总耗时为 $O((E + V) \alpha(V))$。
    * 参考答案：
        $$\text{Total Time} = O(E \log V) + O(E \log V) + O((E + V)\alpha(V)) = O(E \log V)$$

* **最小生成树与最短路径树等价性反例判定**
    * 题干：给定一张无向连通带权图，图中各边权值均严格互不相等。由该图生成的最小生成树（MST）是否一定与以任意顶点为源点生成的单源最短路径树（SPT）拓扑重合？说明判定理由。
    * 解析依据：
        * 最短路径树依赖单源点的累积权值松弛，优化的是从特定源点出发到达其余顶点的点对点距离最小化。
        * 最小生成树依据割性质，优化的是全图 $V - 1$ 条边的标量和全局最小化。
        * 考察三顶点三角环图：顶点 A、B、C，边权为 $AB=1$、$BC=1$、$AC=1.5$。全图最小生成树选边为 $AB$ 和 $BC$，总权重为 2。若以源点 A 构建最短路径树，源点 A 到 C 的最短路径为单边直达 $AC$（长度 1.5，小于经由 B 转接的路径长度 $1 + 1 = 2$），此时最短路径树选边为 $AB$ 与 $AC$。两者拓扑结构不一致。
    * 参考答案：不一定重合。最小生成树优化全图总边权代价，最短路径树优化点对点单源累积路径，二者的局部贪心选择与终态拓扑存在本质差异。
