# 最短路径进阶与A星搜索

## Dijkstra 算法机制与时间开销

### 优先队列与边松弛

* **边缘集（Fringe / Priority Queue）**
    * > **定义**：算法执行期间用于动态维护待处理候选顶点集合及其已知最短距离估计值的优先队列数据结构。
    * 起始状态下起点自身距离显式设为 0，其余所有顶点的已知最短距离全部初始化为 $\infty$。
    * 顶点按照已知距离由小到大的最佳优先顺序（Best-First Order）依次出队。

* **边松弛操作（Edge Relaxation）**
    * > **定义**：考察经由当前出队顶点抵达其邻接顶点的累加路径开销，并在发现更低开销时刷新目标顶点状态的比对更新操作。
    * 数值判定准则：若 $\text{distTo}[u] + w(u, v) < \text{distTo}[v]$，则判定松弛成功。
    * 状态覆写规则：更新距离标量 $\text{distTo}[v] = \text{distTo}[u] + w(u, v)$，并重置前驱指针 $\text{edgeTo}[v] = u$。
    * 堆同步规则：目标顶点 $v$ 在优先队列中对应的键值被减小，触发优先级重置操作。
    * 剪枝机制：若 $\text{distTo}[u] + w(u, v) \ge \text{distTo}[v]$，该边不具备优化价值，直接丢弃且不修改任何拓扑状态。

```text
       distTo[u]              w(u, v)
[起点 S] --------> [当前顶点 u] --------> [邻接顶点 v]
  \                                          ^
   \----------------------------------------/
                  distTo[v] (旧路径)
```

### 正确性证明与关键不变量

* **非递减出队不变量（Non-decreasing Extraction Invariant）**
    * > **定义**：在全图边权非负的前提下，顶点从优先队列中出队的次序与起点到该顶点的实际最短距离单调不减，且一旦顶点出队，其最短路径即刻锁定。
    * 基准推导：设除起点外与起点直连的最小权重出边指向顶点 $V_1$，权值为 $C$；此时边缘集中其余节点距离均 $\ge C$ 或为 $\infty$，故 $V_1$ 必定在第二步出队。
    * 单调性保证：对任意在 $V_1$ 之后出队的顶点 $P$，其已知距离严格满足 $\text{distTo}[P] \ge C$。
    * 反向穿透封闭：若存在一条从后访问顶点 $P$ 指向已出队顶点 $V_1$ 的有向边，权重记为 $W$；当 $W \ge 0$ 时，经由 $P$ 抵达 $V_1$ 的新代价为 $\text{distTo}[P] + W \ge C + 0 = C$，该松弛判断恒为假。
    * > **易错点**：该封闭性仅在所有边权 $W \ge 0$ 时成立；若边权允许为负数，反向松弛可突破下界导致已锁定顶点距离被重写。

### 渐近复杂度拆解

* **基于二叉堆的操作开销（Binary Heap Operation Costs）**
    * > **定义**：Dijkstra 算法的时间复杂度本质上由优先队列核心原语的调用频次与其单次树高调整代价的乘积决定。
    * 初始建堆插入（`insert`）：全图 $V$ 个顶点逐一入队，单次开销 $O(\log V)$，总耗时为 $O(V \log V)$。
    * 提取最小元素（`removeMin`）：主循环中每个顶点仅有一次出队机会，单次下沉开销 $O(\log V)$，总耗时为 $O(V \log V)$。
    * 优先级上浮调整（`changePriority`）：全图 $E$ 条边在算法生命周期中最多被松弛一次，单次上浮开销 $O(\log V)$，总耗时为 $O(E \log V)$。
    * 总体时间复杂度：合并上述开销得到 $O((V + E) \log V)$；在连通图（$E \ge V$）中渐近表示为 $O(E \log V)$。
    * 空间复杂度：优先队列、距离数组与前驱边数组共计消耗 $O(V)$ 空间。

## 负权图失效与平移谬误

### 负权边导致的不变量破坏

* **负权截断失效（Negative Edge Failure）**
    * > **定义**：距离起点较远且晚出队的顶点，经由负权边使得已出队并锁定的顶点距离进一步缩小的拓扑破坏现象。
    * 破裂实例：顶点 $X$ 已锁定 $\text{distTo}[X] = 82$ 并出队；随后访问的顶点 $Y$ 开销为 $\text{distTo}[Y] = 101$；若存在边 $Y \to X$ 且权值为 $-67$，累加代价计算得出 $101 + (-67) = 34 < 82$。
    * 级联崩塌机理：算法缺乏已出队节点的二次回滚入队机制，$X$ 的邻接边无法再次被松弛，导致从 $X$ 出发的整棵子树全部停留在次优解状态。
    * > **易错点**：负权图会导致贪心最优子结构假设彻底不成立，不能通过简单修改入队次数来修复，必须切换至 Bellman-Ford 等重松弛算法。

### 边权加常数平移谬误

* **全局常数平移（Uniform Constant Shift Fallacy）**
    * > **定义**：试图通过给图中所有边的权值统一增加固定正数常数消除负权值的路径等价性修正策略。
    * 失效原因：不同候选路径所跨越的边数（Hop Count）存在天然差异。
    * 边数惩罚效应：设常数平移量为 $C$，对于包含 $k$ 条边的路径，其总路径长度被强行放大了 $k \cdot C$。
    * 排序逆转：单跳长边路径仅被增加 $1 \cdot C$，而多跳低权短边路径被叠加了多次常数，导致原本最优的多跳路径总权重反超劣质路径。
    * > **注意**：加常数变换破坏了路径总权重的相对偏序关系，无法通过跑完 Dijkstra 算法后减去常数来恢复最短路径。

```text
候选路径 1 (单跳直达)：
  S --------(原权重 10)--------> T
  统一加上常数 C = 5 后：权重变为 10 + 5 = 15

候选路径 2 (多跳绕行)：
  S --(原权 2)--> A --(原权 2)--> B --(原权 2)--> T
  原总权重为：2 + 2 + 2 = 6 (路径 2 优于路径 1)
  统一加上常数 C = 5 后：
  新总权重变为：(2 + 5) + (2 + 5) + (2 + 5) = 21 (路径 1 优于路径 2，原最优解被扭曲)
```

## A* 定向搜索算法

### 启发式评估机制

* **A* 搜索算法（A* Search Algorithm）**
    * > **定义**：在 Dijkstra 算法骨架中，优先队列出队依据从已知真实开销改造为“已知开销 + 目标未来预估开销”的点对点定向启发式搜索算法。
    * 优先级评估函数：$\text{Priority}_{A^*}(v) = \text{distTo}[v] + h(v)$。
    * 函数成分：$\text{distTo}[v]$ 表示从起点到节点 $v$ 的已知最小真实开销；$h(v)$ 为节点 $v$ 到目标终点的启发式预估距离。
    * 搜索波前形态：Dijkstra 算法表现为以起点为中心的各向同性全域圆形扩散；A* 算法将波前沿终点矢量方向拉伸为定向狭长椭球。
    * 典型空间启发函数：在平面几何寻路中，常用欧几里得直线距离或曼哈顿距离作为 $h(v)$ 的基准实现。

```text
Dijkstra 搜索波前 (盲目辐射)：
               [全域同心圆扩散]

A* 搜索波前 (定向拉伸)：
[起点 S] =======(沿目标矢量压窄的椭圆波前)=======> [目标终点 T]
```

### 停机准则与启发式边界

* **提前终止准则（Early Exit Criterion）**
    * > **定义**：在单目标搜索任务中，目标顶点首次作为最小元素从优先队列中出队时直接宣告搜索结束并退出的策略。
    * 收益机制：无需完整生成全局最短路径树，避开了背离目标方向的所有远端节点的展开与松弛。
    * 正确性前提：终止信号必须绑定在目标节点的“出队（Poll/RemoveMin）”时刻，绝对不能在目标节点被发现并“入队（Insert/Add）”时提前停机。

* **启发式函数相容性与边界（Admissibility & Boundary Conditions）**
    * > **定义**：确保 A* 算法所求得路径具备全局最优性所必须遵守的数学边界约束。
    * 可采纳性（Admissibility）：对于图中任意顶点 $v$，预估值必须满足 $h(v) \le h^*(v)$（其中 $h^*(v)$ 为 $v$ 到终点的真实物理最短距离，即绝不可高估）。
    * 下限退化：若全图启发式函数满足 $h(v) = 0$，A* 优先队列计算公式完全等价于 $\text{distTo}[v]$，算法无缝退化为标准 Dijkstra 算法。
    * 过高估计惩罚灾难：若人为设定极大的启发值，导致某些中间节点开销被虚夸，优先队列将强制诱导搜索波前绕行次优通道，破坏最优解保证。
    * > **易错点**：启发函数过大不仅破坏贪心选择性质，更会导致算法丢失真正的全局最短路径。

## 最小生成树与割性质

### 生成树判定准则

* **生成树（Spanning Tree）**
    * > **定义**：在无向连通加权图 $G = (V, E)$ 中，包含全部 $V$ 个顶点且边集连通且无回路的极小子图。
    * 顶点与边数恒等式：任意包含 $V$ 个顶点的生成树，其包含的边数严格恒等于 $V - 1$ 条。
    * 连通性限制（Connected）：所选子图必须保证任意两点间均存在可行走路径，不允许退化为多个孤立块。
    * 无环性限制（Acyclic）：子图内不得包含任何回路，任何两点之间的简单路径有且仅有一条。
    * 全顶点覆盖（Spans all vertices）：原图每一个顶点都必须被该子图边集覆盖，覆盖度必须为 100%。

* **最小生成树（Minimum Spanning Tree，MST）**
    * > **定义**：在连通加权图的所有合法生成树中，所有边的权值代数和达到全局绝对最小的生成树。
    * 唯一性边界：若全图中所有边的权值互不相同，该图的最小生成树唯一；若存在等权边，可能存在多棵代数和相等的生成树。

### 割性质理论

* **割与跨越边（Cut & Crossing Edge）**
    * > **定义**：割是指将图的顶点集合 $V$ 任意二分为两个互不相交的非空子集 $S$ 与 $V \setminus S$ 的操作；跨越边为一端端点在 $S$、另一端端点在 $V \setminus S$ 的边。
    * 划分自由度：顶点的二分完全任意，两个子集所包含的顶点数量无需平衡。
    * 拓扑边分类：两端点同属于集合 $S$ 或同属于集合 $V \setminus S$ 的边为内部边；端点横跨两界的边为跨越边。

```text
+-----------------------+           +-----------------------+
|      顶点子集 S       |           |     顶点子集 V \ S    |
|    [A]        [B]     |           |     [D]        [E]    |
|      \        /       |           |       \        /      |
|       \      /        |  跨越边   |        \      /       |
|        \    /         |---------> |         \    /        |
|         [C]-----------+---(w=2)---+--------->[F]          |
+-----------------------+           +-----------------------+
```

* **割性质定理（Cut Property Theorem）**
    * > **定义**：对于任意连通加权无向图的任意合法割，在连接该割两端集合的所有跨越边中，权重最小的那条边（Light Edge）必然属于该图的某棵最小生成树。
    * 贪心算法根基：Prim 算法与 Kruskal 算法的核心挑选逻辑均直接建立在割性质的局部最优选择证明之上。
    * 判定独立性：判定最小权跨越边归属于 MST 时，完全不需要获知全图剩余边在未来将如何闭合，具有绝对的局部决定权。

## 经典图算法实战推演

### 无向图环检测机制

* **深度优先搜索环检测（DFS Cycle Detection）**
    * > **定义**：通过维护路径遍历状态并在邻接扩展中剔除双向边天然折返的回路发现算法。
    * 遍历追踪：维护全局布尔数组 `visited`，对未访问顶点展开递归搜索。
    * 父节点屏蔽规则：在无向图中，节点 $u$ 的邻接列表中必然存在反向通往其调用来源 $parent$ 的边，遍历邻接点时若 $v == parent$，必须显式跳过。
    * 成环判据：若探测到邻接顶点 $v$ 满足 $v \ne parent$ 且 `visited[v] == true`，则立即断定图存在环结构。
    * 复杂度指标：时间复杂度为 $O(V + E)$，空间复杂度为递归栈深及标记数组占用的 $O(V)$。

* **加权并查集环检测（Disjoint Sets Cycle Detection）**
    * > **定义**：将各顶点视为独立连通分量，借助并查集按边迭代合并与连通性判断的代数成环检测算法。
    * 初始化：全图 $V$ 个顶点初始化为独立的互斥单元素集合。
    * 逐边扫描推演：遍历图中的每一条无向边 $(u, v)$，执行集合根查询 `rootU = find(u)` 与 `rootV = find(v)`。
    * 状态分流逻辑：
        * 若 `rootU != rootV`：表明两节点尚处于非连通分量，执行 `union(u, v)` 进行集合合并；
        * 若 `rootU == rootV`：表明引入当前边之前两点已存在可行通路，当前边作为冗余连接必然闭合形成回路，直接停机判定存在环。
    * 复杂度指标：时间复杂度为 $O(V + E \cdot \alpha(V))$（$\alpha$ 为反阿克曼函数），运行效率优于显式图遍历。

### 生成树拓扑合法性检验

* **子图形态判定规则（Spanning Subgraph Verification）**
    * > **定义**：针对给定的加权无向子图边集，验证其是否满足生成树拓扑充要条件的三步核对法。
    * 连通缺陷判定：若选取的边集导致全图分离为两个或更多互不连通的独立子网络，直接判定非生成树。
    * 环路冗余判定：若选取的边集中包含闭合环路（如三点环），则边数超过 $V - 1$ 导致结构冗余，直接判定非生成树。
    * 合法生成树形态：无环路、全连通且选取的边数恰好为 $V - 1$ 的子图，判定为合法生成树。

### 割性质最小权跨越边选取

* **最小权跨越边判决（Light Edge Extraction）**
    * > **定义**：依据割的两极划分快速锁定必属于 MST 组成边的实战推演流程。
    * 端点有效性初筛：核对候选边的两端端点颜色；若两端点均为同一子集（同灰或同白），属于集合内边，直接排除。
    * 跨界集合比对：收集所有一端锚定在子集 $S$、另一端锚定在子集 $V \setminus S$ 的边，构成该割的跨越边集合。
    * 贪心极小值输出：在确立的跨越边集合中提取标量权重最小的边；根据割性质定理，该边百分之百属于原图的某棵最小生成树。
