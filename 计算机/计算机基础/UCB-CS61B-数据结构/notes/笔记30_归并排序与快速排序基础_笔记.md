# 归并排序与快速排序基础

## 排序底层核心机制与归并排序

### 典型排序底层驱动操作对比

* **排序底层原子操作（Sorting Atomic Primitives）**
    * > **定义**：驱动各类排序算法执行数据重排的最底层不可拆分核心动作。
    * 选择排序通过全局扫描提取极值，堆排序依赖堆化调整（Heapify）维护偏序树，归并排序通过双指针执行有序序列合并（Merge），插入排序通过连续相邻交换（Swap）推进元素滑移，快速排序通过基准值比较执行划界分区（Partition）。
    * 各排序算法的核心驱动操作在数据流向与比较维度上均具有排他性互斥特征。

* **堆排序缓存局部性缺陷（Poor Cache Performance of Heap Sort）**
    * > **定义**：堆排序在数组实现形态下因内存访问存在大跨度跳跃而导致 CPU 高速缓存命中率极低的系统级性能缺陷。
    * 数组二叉堆中父节点 $i$ 与子节点 $2i, 2i+1$ 之间呈倍数跳跃关系，导致内存寻址频繁跨越 Cache Line 边界。
    * 原地堆排序虽具备紧凑的 $\Theta(N \log N)$ 渐进时间上限且额外空间为 $O(1)$，但在现代多级存储体系下的实际吞吐量显著受制于缓存失效开销。

### 归并排序双指针合并机制

* **双指针合并（Two-pointer Merge）**
    * > **定义**：利用两个递增游标同步单向遍历两个已排序子数组并输出全局有序序列的线性重构操作。
    * 指针 $i$ 指向左半部分起始端，指针 $j$ 指向右半部分起始端，每轮比较较小者并写入目标数组，对应指针递增；相等元素任选其一写入。
    * 一侧指针抵达边界后，另一侧未耗尽子数组剩余元素直接按顺序批量追加至末尾。
    * 两个规模为 $N/2$ 的子序列合并仅需单次线性扫描，操作复杂度严格为 $\Theta(N)$。

```text
左子数组: [ 2,  15, 32 ]        右子数组: [ 17, 19, 26 ]
          ^                               ^
          i                               j
------------------------------------------------------------------
比较 A[i]=2 与 B[j]=17  --> 2 较小写入目标区，i 右移
写入: [ 2 ]

比较 A[i]=15 与 B[j]=17 --> 15 较小写入目标区，i 右移
写入: [ 2, 15 ]

比较 A[i]=32 与 B[j]=17 --> 17 较小写入目标区，j 右移
写入: [ 2, 15, 17 ]

比较 A[i]=32 与 B[j]=19 --> 19 较小写入目标区，j 右移
写入: [ 2, 15, 17, 19 ]

比较 A[i]=32 与 B[j]=26 --> 26 较小写入目标区，j 右移
写入: [ 2, 15, 17, 19, 26 ]

右侧已耗尽，将左侧剩余元素 32 追加至末尾
结果: [ 2, 15, 17, 19, 26, 32 ]
```

* **归并排序时间渐进界（Merge Sort Time Bounds）**
    * 递归树执行深度为 $\log_2 N$，每一层级所有子节点合并操作工作量代数和恒为 $N$。
    * 归并排序在最好情况、最坏情况与平均情况下的渐进时间复杂度恒定为 $\Theta(N \log N)$。

### 归并排序空间复杂度生命周期

* **临时缓冲区复用模型（Buffer Lifecycle and Reuse）**
    * > **定义**：归并排序通过按需申请与即时释放或全局共享预分配缓冲区，避免辅助空间随递归深度倍增的内存管理机制。
    * 递归树单支向下探索时产生的子任务临时数组生命周期随合并结束而终止，不与其他兄弟分支重叠。
    * 在执行生命周期的任意特定时间切片内，系统仅需一个长度为 $N$ 的连续缓冲区即可承载各层合并写入。
    * 归并排序的额外辅助空间复杂度严格收敛于 $O(N)$，不存在 $O(N \log N)$ 空间膨胀。
    * > **注意**：理论上的原地归并排序（In-place Merge Sort）虽然存在，但因涉及复杂的块交换与位编解码，常数时间因子过大，工业级通用库均选择接受 $O(N)$ 辅助内存。

```text
第 3 层: [N/8] [N/8]  --> 合并结束，局部空间即刻废弃
第 2 层:    [ N/4 ]   --> 合并结束，局部空间即刻废弃
第 1 层:        [   N/2   ]  --> 合并结束，局部空间即刻废弃
第 0 层:            [         N         ]
```

## 插入排序与逆序对消解

### 原地插入排序与旅行者模型

* **旅行者模型（Traveler Model）**
    * > **定义**：将未排序区间的首个元素视作向左回溯的游标对象，通过连续相邻交换将其沉降至已排序区间对应位置的原地处理范式。
    * 游标从左到右依次推进，每个被激活的元素持续与紧邻左侧元素进行比较。
    * 当且仅当左侧元素大于旅行者自身时触发交换，遇到小于等于自身的元素或抵达数组下标 0 时终止回溯。
    * 排序过程完全在原数组内部进行，空间复杂度为严格的 $O(1)$。

```text
初始状态: [ 32, 15,  2, 17, 19, 26, 41 ]

考察 15: 与 32 颠倒，交换并落位首端
         [ 15, 32 |  2, 17, 19, 26, 41 ]

考察  2: 连续向左穿透 32 与 15
         [  2, 15, 32 | 17, 19, 26, 41 ]

考察 17: 与 32 交换，遇 15 停止
         [  2, 15, 17, 32 | 19, 26, 41 ]

考察 19: 与 32 交换，遇 17 停止
         [  2, 15, 17, 19, 32 | 26, 41 ]

考察 26: 与 32 交换，遇 19 停止
         [  2, 15, 17, 19, 26, 32 | 41 ]

考察 41: 大于左侧 32，就地停止
完成状态: [  2, 15, 17, 19, 26, 32, 41 ]
```

### 逆序对数学性质与复杂度分析

* **逆序对（Inversion）**
    * > **定义**：序列中满足索引偏序 $i < j$ 但数值偏序 $A[i] > A[j]$ 的离散元素二元偶对 $(i, j)$。
    * 完全升序数组的逆序对数量为 0，完全降序数组的逆序对数量达到极大值 $N(N - 1) / 2$。

* **单步交换消解定理（Single Swap Reduction Theorem）**
    * 插入排序中任意一次相邻元素交换，仅改变参与交换的两个元素之间的相对位置，序列中其他元素相对于该两元素的空间偏序均保持恒定。
    * 任意一次相邻交换操作，导致且仅导致全序列逆序对总量精确减少 1。
    * 插入排序执行的物理交换总次数，严格等于输入数组初始包含的逆序对绝对数量。

* **时间复杂度极值边界**
    * 最好情况：输入数组完全有序，全数组逆序对数为 0，每个元素仅需执行 1 次比较且 0 次交换，渐进时间复杂度为 $\Theta(N)$。
    * 最坏情况：输入数组呈完全降序，逆序对数为 $N(N - 1) / 2$，渐进时间复杂度为 $\Theta(N^2)$。

### 插入排序工程优势场景

* **近乎有序序列自适应处理（Nearly Sorted Arrays）**
    * 序列中绝大部分元素处于单调位置，仅存在常数级错位项时，全局逆序对总量呈现 $O(N)$ 线性特征。
    * 插入排序天然感知输入数据的局部有序度，整体运行耗时直接收敛至 $\Theta(N)$。
    * 堆排序与归并排序均无法感知初始偏序关系，仍会执行完整堆化下潜或机械切分合并流程。

* **小规模序列阈值优化（Small Subarrays Optimization）**
    * 当问题规模缩减至极小阈值（如 $N \le 15$）时，算法常数因子与递归栈帧分配开销主导整体耗时。
    * 插入排序内部逻辑由紧凑的双层内联循环构成，小数据量下指令周期显著短于高级分治算法。
    * > **提示**：工业级通用混合排序系统（包括 TimSort 与双轴快速排序 Dual-Pivot Quicksort）均设置有小数组阻断阈值，递归基底不再切分至 1，而是直接调用插入排序收尾。

## 快速排序与分区机制

### 快速排序历史成因与磁带扫描优化

* **磁带流式检索模型（Tape Sequential Access Optimization）**
    * 物理磁带等外存介质仅支持高开销顺序寻道，随机访问需承受频繁物理倒带与快进延迟。
    * 在顺序介质上执行二分查找会导致磁头剧烈抖动与机械耗损。
    * 将待匹配查询项预先排序后，磁带介质仅需执行单次单向连续扫描（Single Pass）即可完成全部词条比对。

* **快速排序（Quick Sort）**
    * > **定义**：通过动态选取基准点并将待排区间划分为互斥子区间进而实施分治求解的排序算法。
    * 由托尼·霍尔（Tony Hoare）于 1960 年在优化机器翻译磁带查询系统时设计成型。

### 单次分区核心规则与多解性

* **分区机制（Partition）**
    * > **定义**：在序列中选定一个基准元素（Pivot），通过重排使小于等于基准的元素均位于其左侧、大于等于基准的元素均位于其右侧的核心原子操作。
    * **基准绝对归位**：执行完毕后，Pivot 本身落入最终完全排序状态下的绝对物理索引位置，后续所有递归流程永不移位。
    * **子任务解耦互斥**：以 Pivot 为中介隔墙，左侧子序列全体元素数值严格小于等于右侧子序列全体元素数值，两端元素绝无穿透可能。
    * > **易错点**：分区仅保证左右子数组关于 Pivot 具备区间偏序性，绝不要求子数组内部具备有序性；同一基准值存在多种合法的分区重排输出。

```text
原始未分区序列: [ 6,  3,  8,  2,  9,  1,  7 ]，选定 Pivot = 6

合法输出形态 A: [ 3, 2, 1,  6,  8, 9, 7 ]
                 \_____/    ^   \_____/
                  <= 6    Pivot   >= 6

合法输出形态 B: [ 1, 3, 2,  6,  7, 9, 8 ]
                 \_____/    ^   \_____/
                  <= 6    Pivot   >= 6
```

### 线性时间三色分区模型

* **三色分区（Three-color Partition）**
    * > **定义**：将待排元素按与基准值的关系严格离散化切分为小于、等于、大于三个连续物理区间的操作机制。
    * 三趟扫描法（Three-pass Scan）在允许 $O(N)$ 辅助空间时提供确定性线性时间解：
        * 第一趟单向遍历原始数组，过滤所有严格小于 Pivot 的元素顺序写入辅助空间左侧。
        * 第二趟单向遍历原始数组，过滤所有严格等于 Pivot 的元素紧随写入辅助空间中部。
        * 第三趟单向遍历原始数组，过滤所有严格大于 Pivot 的元素顺序写入辅助空间右侧。
    * 算法整体遍历次数为 3，执行步数为严格的 $3N$，时间复杂度为严格的 $O(N)$。

### 分区递归树与分治解耦

* **快速排序递归执行拓扑（Quick Sort Recursion Tree）**
    * 递归基底（Base Case）：子数组元素数量小于等于 1 时，递归立即收敛返回。
    * 选定 Pivot 并执行分区，获取就位下标。
    * 对 Pivot 左侧边界构成的子问题递归调用快速排序。
    * 对 Pivot 右侧边界构成的子问题递归调用快速排序。
    * 子树切分平衡度由基准值在数据集合中的分位数决定，不具备归并排序机械平分的结构刚性。

```text
               以 32 为基准进行全局分区
               [ 15, 2, 17, 19, 26 | 32 | 41 ]
                      /                   \
        以 15 为基准递归分区           单元素递归基底 (Base Case)
        [ 2 | 15 | 17, 19, 26 ]               [ 41 ] 落位
         /         \
    [ 2 ] 落位    以 19 为基准递归分区
                 [ 17 | 19 | 26 ]
                   /         \
              [ 17 ] 落位   [ 26 ] 落位
```

## 典型排序问题分析

### 近乎有序海量数据重排序选型

* **单点异常数组的算法选型（Single-element Displaced Selection）**
    * **场景描述**：在包含 100 万个已序整型数据的数组中，仅修改单一下标（如第 62.5 万项）的数值引发局部失序。
    * **最优解选型**：插入排序（Insertion Sort）。
    * **机制判定依据**：数组全局逆序对总数上限为 $N$。
        * 插入排序遍历未受影响的 999,999 个在位元素时，首轮比较均满足非递减条件，无交换终止回溯。
        * 仅单一错位元素作为旅行者触发连续物理滑动，其单次穿越路径长度上限不超过 $N$ 次交换，整体耗时逼近严格的线性时间 $\Theta(N)$。
    * **劣势算法归因**：
        * 堆排序在建堆阶段打乱数组现有偏序，造成高额无效堆化与缓存失效开销。
        * 归并排序无法感知既有有序结构，仍会执行完整的 $O(N \log N)$ 拆分与缓冲区写入。
        * 选择排序仍需执行全量未排序区间极值检索，耗时恒定为 $\Theta(N^2)$。

### 基准值分区有效性判定

* **分区合法性判据（Partition Validity Predicate）**
    * **判定准则**：设基准元素所在索引为 $k$，数组必须恒定满足区间约束：
        $$\forall i < k, A[i] \le A[k] \quad \land \quad \forall j > k, A[j] \ge A[k]$$
    * **等值元素分布规则**：数值等于 Pivot 的冗余元素在左侧子序列或右侧子序列中存在均属合法，不打破边界约束。
    * **候选判定用例**（设定基准 Pivot = 10）：
        * 用例 A `[3, 2, 6, 10, 15, 12, 17]`：左侧全集 $\le 10$，右侧全集 $\ge 10$，判定为合法。
        * 用例 B `[2, 6, 3, 10, 12, 15, 17]`：左侧无序但均满足 $\le 10$，右侧均满足 $\ge 10$，判定为合法。
        * 用例 C `[6, 3, 2, 10, 10, 12, 15]`：冗余等值元素 10 落位右侧子序列，满足 $\ge 10$ 边界，判定为合法。
        * 用例 D `[3, 2, 6, 10, 4, 15, 12]`：基准右侧区间出现元素 4，违背右侧下界约束，判定为非法。

### 线性时间辅助空间三色重排

* **辅助数组三趟收集算法（Three-pass Auxiliary Collection Algorithm）**
    * **求解约束**：允许 $O(N)$ 辅助空间，时间复杂度约束为严格的 $O(N)$，重排标准为红（$< 6$）、白（$= 6$）、蓝（$> 6$）。
    * **状态定义与流程**：
        * 开辟长度为 $N$ 的输出数组 `aux`，维护目标写入指针 `idx = 0`。
        * **Pass 1**：扫描原序列，遇到小于 6 的元素直接赋值给 `aux[idx++]`。
        * **Pass 2**：再次从头扫描原序列，遇到等于 6 的元素赋值给 `aux[idx++]`。
        * **Pass 3**：最后扫描原序列，遇到大于 6 的元素赋值给 `aux[idx++]`。
    * **渐进性质验证**：空间开销为单个大小为 $N$ 的连续内存块，遍历常数项严格为 3，渐进时间复杂度完全收敛于 $O(N)$。
