# 树与图的深度优先与广度优先遍历

## 树的结构定义与拓扑模型

### 树的拓扑特征

* **树（Tree）**
    * > **定义**：任意两个节点之间存在且仅存在一条路径的无向连通无环图。
    * 判定条件：连通性与唯一路径性，结构内绝对不存在闭合回路。
    * 退化结构：单链表属于二叉树退化的合法树拓扑。
    * > **易错点**：只要任意两节点间存在两条或以上不同路径，或者局部闭合成环，结构立即失去树的属性。

```text
      (A)            (1)               (X)
     /   \            |               /   \
   (B)   (C)         (2)            (Y)   (Z)
   / \                |              |
 (D) (E)             (3)            (W)

   [有效树 1]      [有效树 2]       [有效树 3]
  (分支分叉)      (单链退化)       (任意两点路径唯一)
----------------------------------------------------
      (P)                 (M)
     /   \               /   \
   (Q)---(R)           (N)   (O)
     \   /               \   /
      (S)                 (K)

   [非树 1]             [非树 2]
 (存在环路与多条路径) (从顶到底可走左或走右)
```

### 有根树的层级划分

* **有根树（Rooted Tree）**
    * > **定义**：从无根树中指定任意单一节点作为根节点，其余节点受层级支配自然垂挂的树形结构。
    * 相对性原理：对于同一无向无环拓扑，选取不同的节点作为根，会产生不同外观但拓扑等价的有根树。
    * 父节点（Parent）：当前节点通向根节点的唯一路径上紧邻的上位节点。
    * 子节点（Child）：远离根节点方向紧邻当前节点下位的所有节点。
    * 叶子节点（Leaf）：不存在任何子节点的终端节点。

```text
    (A)---(B)---(C)                 (A)                        (B)
     |     |                       /   \                      / | \
    (D)   (E)                    (D)   (B)                  (A)(C)(E)
                                      /   \                  |
                                    (C)   (E)               (D)

    [原始无根树]              [选 A 为根拎起]              [选 B 为根拎起]
```

## 树的深度优先遍历机制

### 递归遍历模式与应用场景

* **前序遍历（Pre-order Traversal）**
    * > **定义**：在递归访问子树之前优先处理当前节点自身的深度优先遍历策略。
    * 访问顺序：根节点 $\to$ 左子树 $\to$ 右子树。
    * 核心递归模板：
        ```java
        public void preOrder(Node x) {
            if (x == null) return;
            print(x.key);
            preOrder(x.left);
            preOrder(x.right);
        }
        ```
    * 典型应用场景：带层级缩进的文件目录结构打印（如 `tree` 命令），父级目录必须先于其内部子项输出。

* **中序遍历（In-order Traversal）**
    * > **定义**：递归处理完左子树所有节点后访问当前节点，最后递归处理右子树的遍历策略。
    * 访问顺序：左子树 $\to$ 根节点 $\to$ 右子树。
    * 核心递归模板：
        ```java
        public void inOrder(Node x) {
            if (x == null) return;
            inOrder(x.left);
            print(x.key);
            inOrder(x.right);
        }
        ```
    * 二叉搜索树特征：在二叉搜索树（BST）上执行中序遍历，输出序列严格单调递增。

* **后序遍历（Post-order Traversal）**
    * > **定义**：必须等待左子树与右子树完全处理完毕后，才最终访问当前节点自身的遍历策略。
    * 访问顺序：左子树 $\to$ 右子树 $\to$ 根节点。
    * 核心递归模板：
        ```java
        public void postOrder(Node x) {
            if (x == null) return;
            postOrder(x.left);
            postOrder(x.right);
            print(x.key);
        }
        ```
    * 终极位置法则：整棵树的根节点必然位于后序遍历序列的最末位。
    * 典型应用场景：磁盘文件夹总容量计算（如 `du` 命令），父目录容量依赖所有子项容量汇总结算。

```text
         (D)
       /     \
     (B)     (F)
    /   \   /   \
  (A)   (C)(E)   (G)

前序遍历序列: D, B, A, C, F, E, G
中序遍历序列: A, B, C, D, E, F, G
后序遍历序列: A, C, B, E, G, F, D
```

### 逆时针外沿巡游速算法

* **外沿绕圈法（Contour Tour Method）**
    * > **定义**：沿整棵二叉树的外围轮廓线逆时针巡游一周，依据轨迹擦过节点的几何方位快速写出遍历序列的人工速算技巧。
    * 前序记录法则：巡游轨迹触碰或擦过节点左侧外沿的瞬间记录该节点。
    * 中序记录法则：巡游轨迹掠过节点正下方底部的瞬间记录该节点。
    * 后序记录法则：巡游轨迹从节点右侧外沿离开上升的瞬间记录该节点。

```text
       ╭───────( 1 )───────╮
      ╱       ╱     ╲       ╲
     │      ( 2 )   ( 3 )    │
     │     ╱    ╲       ╲    │
     │   (4)    ( 5 )   ( 6 )│
     │         ╱    ╲       ╲│
     │       (7)    (8)     (9)
      ╲_______│______│_______╱

前序输出 (擦过左侧): 1, 2, 4, 5, 7, 8, 3, 6, 9
中序输出 (掠过下方): 4, 2, 7, 5, 8, 1, 3, 6, 9
后序输出 (离开右侧): 4, 7, 8, 5, 2, 9, 6, 3, 1
```

## 图论基础模型与复杂度

### 简单图与拓扑术语体系

* **图（Graph）**
    * > **定义**：由顶点集合 $V$ 以及连接顶点对的边集合 $E$ 所构成的非线性抽象数据结构。
    * 树与图的归属关系：树是满足无环且全连通约束条件的特化图结构。

* **简单图（Simple Graph）**
    * > **定义**：不包含自环且任意两顶点间不存在平行边的图结构。
    * 无自环规则（No Self-loops）：任何边的两个端点必须为不同顶点，严禁顶点连向自身。
    * 无平行边规则（No Parallel Edges）：任意一对顶点之间最多仅允许存在一条边。

```text
    (1)───────(2)            ╭───╮                (1)
       \     /              │   │               // \\
        \   /               └──(A)             (2)   (3)
         (3)
     [简单图]              [含自环: 非简单图]   [含平行边: 非简单图]
 (无自环，无平行边)       (边起点终点同为 A)   (1 与 2 间有双重边)
```

* **图论基础属性（Graph Properties）**
    * > **定义**：用于界定图连接状态与拓扑特性的量化指标。
    * 有向图（Digraph）与无向图（Undirected Graph）：边是否具备单向流动箭头。
    * 顶点的度（Degree）：连接至该顶点的边的总数目。
    * 简单路径（Simple Path）：顶点序列中不存在重复顶点的连续通行路径。
    * 环（Cycle）：起点与终点重合且边数大于等于 3 的简单路径。
    * 连通图（Connected Graph）：图中任意两个不同顶点之间均至少存在一条可行路径。

### 经典图论判定问题

* **欧拉回路（Eulerian Tour）**
    * > **定义**：在连通图中恰好经过每一条边一次且仅一次并回到起点的闭合回路。
    * 判定法则：图中每个顶点的度数必须全为偶数。
    * 计算复杂度：线性时间复杂度 $O(V + E)$。

* **哈密顿回路（Hamiltonian Cycle）**
    * > **定义**：在连通图中恰好经过每一个顶点一次且仅一次并回到起点的闭合回路。
    * 理论属性：NP 完全问题（NP-Complete）。
    * 计算复杂度：目前已知最优算法为指数级时间复杂度 $O(2^V)$，尚无多项式时间解法。

## 图的深度优先搜索与路径重构

### 顶点访问标记与死循环规避

* **访问标记机制（Marking Mechanism）**
    * > **定义**：在遍历图顶点时维护全局状态数组，记录已踏足顶点以防止重复访问的防环技术。
    * 状态容器：布尔数组 `boolean[] marked` 或哈希集合 `Set<Integer> visited`。
    * 搜索前置条件：仅对 `!marked[neighbor]` 的邻居顶点发起递归调用。
    * > **易错点**：无向图的边为双向互通，若不设置标记，递归将在两个相邻节点之间往返调用，导致栈溢出异常（StackOverflowError）。

```text
       (0) ─── (1) ─── (2) ─── (5) ─── (6) ─── (7)
                        |       | \
                        |       |  (8)
                        |      (4)
                        |       |
                        ╰──────(3)
```

### 前驱数组与路径还原

* **前驱记录数组（edgeTo[]）**
    * > **定义**：在图遍历树中记录首次发现并访问当前顶点的前驱顶点的映射数组。
    * 写入时机：当从已访问顶点 $v$ 探测到未访问顶点 $w$ 时，执行赋值 `edgeTo[w] = v`。
    * 路径重构算法：从目标终点 $t$ 开始，循环查询 `current = edgeTo[current]` 直至回溯至源点 $s$，随后反转序列即可还原正向通路。
    * 非最短路径属性：DFS 仅保证找到连通路径，不保证路径包含的边数最少。
    * > **注意**：无权图的最短路径求解必须采用广度优先搜索（BFS），严禁使用 DFS 结果作为最短路径。

| 目标顶点 $v$ | 前驱来源 `edgeTo[v]` | 物理意义 |
| :---: | :---: | :--- |
| `0` | `-` | 遍历起点（源点） |
| `1` | `0` | 从 0 出发首次访问 1 |
| `2` | `1` | 从 1 出发首次访问 2 |
| `3` | `4` | 从 4 出发首次访问 3 |
| `4` | `5` | 从 5 出发首次访问 4 |
| `5` | `2` | 从 2 出发首次访问 5 |
| `6` | `5` | 从 5 出发首次访问 6 |
| `7` | `6` | 从 6 出发首次访问 7 |
| `8` | `5` | 从 5 出发首次访问 8 |

### 图遍历的时间时序序列

* **图 DFS 前序与后序（DFS Pre-order and Post-order）**
    * > **定义**：基于深度优先搜索过程中递归调用栈的压栈与弹栈时刻所记录的拓扑次序。
    * 图 DFS 前序序列：顶点被标记并进入调用栈（Push）的物理时刻先后次序。
    * 图 DFS 后序序列：顶点完全结束所有邻接顶点的探索并从调用栈弹出（Pop）的物理时刻先后次序。
    * 追踪示例前序序列：`0, 1, 2, 5, 4, 3, 6, 7, 8`。
    * 追踪示例后序序列：`3, 4, 7, 6, 8, 5, 2, 1, 0`。
    * > **提示**：图 DFS 后序序列的逆序输出构成了有向无环图（DAG）拓扑排序的核心求解结果。
