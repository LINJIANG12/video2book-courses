# 渐近分析基础

## 算法效率评估范式

### 物理时钟度量局限

* **时钟时间（Wall-clock Time）**
    * > **定义**：程序在物理设备上从执行起点到终止点所消耗的实际流逝时间。
    * 平台强依赖性：不同硬件主频、指令集架构、Java 虚拟机 JIT 编译器优化策略导致测量绝对值无法跨机器复现。
    * 环境强耦合性：系统后台进程争夺计算资源、上下文切换开销与 CPU 缓存冷热状态直接引发读数剧烈扰动。
    * 输入偏置干扰：测试用例局部特征（如数组首两位即命中重复元素）可能触发快速返回，掩盖算法整体效率差异。

### 操作计数法与符号模型

* **微观操作计数（Micro-operation Counting）**
    * > **定义**：统计程序执行过程中所有底层独立指令（包括赋值、比较、自增、内存解引用）的离散发生频次。
    * 机器无关性：操作频次完全由算法控制流与输入形态决定，属于不随硬件转移的客观量化指标。
    * 硬件映射断层：底层体系结构中不同指令周期的非均一性，叠加现代处理器的超标量流水线、分支预测及多级缓存机制，导致操作累加和与真实耗时并不构成线性正比关系。
* **符号化扩展分析（Symbolic Scaling Analysis）**
    * > **定义**：将具体数据规模固定值抽象为代数符号 $N$，建立基本操作总次数关于规模 $N$ 的函数映射。
    * 扩展性识别：用于捕捉当数据体量向无限大延伸时，算法运算负荷呈现的数学几何形态。
    * 消除繁琐统计：避开对微观常数步骤的机械盘点，专注识别计算规模膨胀时的敏感度。

## 增长阶与四步简化模型

### 核心增长形态对比

* **渐进行为（Asymptotic Behavior）**
    * > **定义**：当输入规模趋向于无穷大（$N \to \infty$）时，算法资源开销函数随输入规模扩张的极限发展趋势。
    * 阶数压制效应：高阶多项式及指数函数的增长动能具有绝对优势，低阶函数附带任意有限大乘性常数均无法扭转终局。
    * 常见形态全序关系：$\Theta(1) < \Theta(N) < \Theta(N^2) < \Theta(N^3) < \Theta(2^N) < \Theta(N!)$。

```text
操作量

  |                                        / 抛物线：2N^2
  |                                    . -'
  |                                . -'  / 直线：500N

  |                    . -'  . -'

  |            . -'. -'  (交叉点 N = 250)
  |        . -'.-'

  +---------------------------------------------> 规模 N
```

### 四步简化法则

* **最坏情况分析（Worst-case Analysis）**
    * > **定义**：在规模为 $N$ 的所有合法输入集合中，以产生最大运算开销的输入实例作为性能评价基准。
    * 确定性边界：为系统吞吐与响应延迟提供绝对的性能上限兜底。
* **成本模型（Cost Model）**
    * > **定义**：在算法代码的最深层执行路径中，挑选出具有代表性且执行频次最高的基础操作，以其频次映射算法整体耗时。
    * 瓶颈锚定规则：必须选取最深层循环体内部的高频操作，严禁选取外层循环控制变量的初始化或步进语句。
    * > **易错点**：错误选取外层循环控制语句作为成本模型，会导致完全丢失深层嵌套带来的阶数膨胀。
* **低阶项舍弃原则（Ignore Lower Order Terms）**
    * > **定义**：针对多项式型耗时函数，直接剔除所有次数严格低于最高阶项的分量。
    * 数学极限依据：满足 $\lim_{N \to \infty} \frac{a_k N^k + a_{k-1} N^{k-1} + \dots + a_0}{a_k N^k} = 1$。
* **乘性常数忽略原则（Ignore Multiplicative Constants）**
    * > **定义**：将最高阶主导单项式前面的恒定常数系数强制归一化为 1。
    * 抽象一致性规则：在舍弃硬件微观指令周期差异后，保留常数系数在渐进意义下不具备严格物理价值。

### 嵌套循环代数与几何推导

* **高斯连续求和模型（Gauss Summation Model）**
    * > **定义**：双重循环中内层迭代次数随外层索引单调递减时构成的代数求和模式。
    * 代数求解形式：$C = \sum_{k=1}^{N-1} k = \frac{N(N-1)}{2} = \frac{1}{2}N^2 - \frac{1}{2}N$。
    * 简化归纳：剔除低阶项 $-\frac{1}{2}N$ 与系数 $\frac{1}{2}$ 后，其增长阶收敛为二次方阶 $N^2$。
* **直角三角形几何网格法（Right-Triangle Geometry Method）**
    * > **定义**：将双重循环所有取值组合映射至二维离散坐标网格，通过几何图形投影面积评估操作量的推导方法。
    * 网格剖分机理：外层索引与内层索引构成的全集为 $N \times N$ 的离散方阵，实际执行路径严格占据主对角线上方直角三角形区域。
    * 面积极限投影：有效区域面积为 $\frac{1}{2} \times \text{底} \times \text{高} \approx \frac{1}{2}N^2$，面积放大倍率完全由二次方扩张速度决定。

## 渐近分析数学定义

### 大 $\Theta$ 记号形式化定义

* **大 $\Theta$ 记号（Big-Theta Notation，$\Theta$）**
    * > **定义**：若存在正实数常数 $k_1$、$k_2$ 以及正整数 $N_0$，使得对任意规模 $N \ge N_0$，均满足不等式 $k_1 \cdot f(N) \le R(N) \le k_2 \cdot f(N)$，则称 $R(N) \in \Theta(f(N))$。
    * 函数集合本质：$\Theta(f(N))$ 在严谨数学上属于一个具有相同渐进增长速率的函数集合体系。
    * 渐近紧确界：大 $\Theta$ 严格约束了目标函数在无穷大极限下的双向包络边界，兼具紧确上界与紧确下界。
    * > **易错点**：文献中常见的等号写法 $R(N) = \Theta(f(N))$ 实质指代集合从属关系 $\in$，不可对其应用对称性或代数等价代换。

### 三明治夹逼准则

* **夹逼准则（Sandwich Theorem）**
    * > **定义**：通过构建同阶函数的常数放大倍数 $k_2 f(N)$ 与常数缩小倍数 $k_1 f(N)$，将真实运行时间函数 $R(N)$ 截获在通道内的渐近证明范式。
    * 局部波动滤波机理：对于包含有界正弦、余弦或局部震荡项的多项式，通过放缩常数包络线即可完全滤除周期震荡对宏观增长阶的干扰。

```text
耗时 R(N)
    ^
    |                                / 上界：k_2 * f(N)
    |                            . -'
    |                        . -'   ~ ~ 真实波动曲线 R(N)
    |                    . -'  ~ ~ '
    |                . -' ~ ~ '    / 下界：k_1 * f(N)
    |            . -'~ ~ '     . -'
    |        . -'~ '       . -'
    |    . -'          . -'
    |.-'           . -'
    +------------------------------------> 规模 N
                 N >= N_0
```

## 经典分析实战题解

### 有序查重复杂度与内存访问比

* **双重循环遍历查重（dup1 Implementation）**
    * > **定义**：对未经过排序优化的线性表进行两两遍历对比的穷举验证逻辑。
    * 算法实现：
    ```java
    public static boolean dup1(int[] A) {
        for (int i = 0; i < A.length; i += 1) {
            for (int j = i + 1; j < A.length; j += 1) {
                if (A[i] == A[j]) {
                    return true;
                }
            }
        }
        return false;
    }
    ```
    * 复杂度评定：最坏无重复情况下内层相等比对执行 $\frac{N(N-1)}{2}$ 次，属于二次方渐进复杂度 $\Theta(N^2)$。
* **相邻元素线性查重（dup2 Implementation）**
    * > **定义**：借助数组元素有序的先验单调性，仅针对相邻索引执行差分比对的高效查重算法。
    * 算法实现：
    ```java
    public static boolean dup2(int[] A) {
        for (int i = 0; i < A.length - 1; i += 1) {
            if (A[i] == A[i + 1]) {
                return true;
            }
        }
        return false;
    }
    ```
    * 比较增长阶判定：循环索引从 $0$ 遍历至 $N - 2$，相等比较总频次严格为 $N - 1$，其增长阶为线性阶 $\Theta(N)$。
    * 两倍内存访问成因：单次判断执行 `A[i] == A[i + 1]` 时，CPU 必须分别执行针对地址偏移 $i$ 与 $i + 1$ 的独立内存解引用，单次比较直接关联两次读取操作，在最坏情况下总内存读取次数严格为 $2(N - 1)$ 次。

### 高阶多项式主导项提取

* **主导项收敛化简（Dominant Term Reduction）**
    * > **定义**：对多项式微观耗时函数进行极限筛选与主分量提纯的过程。
    * 待求解函数：$R(N) = 100N + 2N^3 + 5000$。
    * 低阶项剔除：当 $N \to \infty$ 时，多项式中一次项 $100N$ 与常数项 $5000$ 相对高阶项的比值极限为零。
    * 系数归一化：最高阶项为 $2N^3$，剔除常数因子 2，提取最终渐近增长阶为三次阶，形式化记作 $R(N) \in \Theta(N^3)$。

### 震荡函数与常数阶夹逼判定

* **常数函数的 $\Theta$ 判定（Constant Function Bound）**
    * > **定义**：函数输出完全不随输入规模自变量变动而产生响应的极值情形。
    * 待求解函数：$f_1(N) = 5$。
    * 构造夹逼：选取正实数参数 $k_1 = 1$、$k_2 = 10$ 及 $N_0 = 1$，使不等式 $1 \cdot 1 \le 5 \le 10 \cdot 1$ 对所有 $N \ge 1$ 恒成立，判定 $f_1(N) \in \Theta(1)$。
* **含周期项扰动函数的 $\Theta$ 判定（Oscillatory Function Bound）**
    * > **定义**：主导增长函数上叠加有界非发散周期项的混合函数渐近确界推导。
    * 待求解函数：$f_2(N) = 4N^2 + 40\sin(N)$。
    * 周期扰动界定：正弦函数值域严格属于 $[-1, 1]$，导致扰动项极值边界为 $[-40, 40]$。
    * 构造夹逼：选取常数参数 $k_1 = 3$、$k_2 = 5$ 及阈值 $N_0 = 10$，当 $N \ge 10$ 时，不等式 $3N^2 \le 4N^2 + 40\sin(N) \le 5N^2$ 严格成立，判定 $f_2(N) \in \Theta(N^2)$。
