# 有向无环图与拓扑排序

## 拓扑排序与有向无环图

### 依赖关系与图模型结构

* **有向无环图（Directed Acyclic Graph，DAG）**
    * > **定义**：不包含任何有向环路的方向图结构。
    * 结构差异：DAG 允许顶点具备多个入度，树结构为每个非根节点入度严格为 1 的 DAG 特例子集。
    * 依赖建模：有向边严格表征不可逆的执行依赖与因果偏序约束。
* **拓扑排序（Topological Sort）**
    * > **定义**：针对有向图顶点的一种线性排列，使得图中任意有向边 $u \to v$，$u$ 在序列中均出现在 $v$ 之前。
    * 存在性定理：图存在拓扑排序的充分必要条件为图必须是有向无环图。
    * 解的非唯一性：互不依赖的分支节点排列顺序可自由交换，DAG 通常存在多种合法的拓扑排序序列。
    * > **易错点**：包含环路的有向图无法选取任何不具前置依赖的起点，拓扑排序必然无解。

### 反向深度优先搜索后序遍历算法

* **反向深度优先搜索后序遍历（Reverse Postorder DFS）**
    * > **定义**：通过 DFS 记录顶点访问回溯完毕的时序列表，将该后序序列完全翻转以构造拓扑序列的方法。
    * 执行机理：递归触底至出度穷尽的节点时将其写入后序列表，深层依赖顶点先于浅层前置顶点完成入列。
    * 时间复杂度：遍历全图顶点与边各一次，计算复杂度为 $O(V + E)$。
    * 空间复杂度：系统调用栈深度与访问标记数组占用 $O(V)$ 辅助空间。
    * > **注意**：当图包含多个弱连通分量或存在多个零入度源点时，必须使用外部循环检测未访问节点并重启 DFS，且绝对不能重置已有的访问标记。
* **后序逆转特性（Reverse Postorder Property）**
    * > **定义**：DAG 中任意边 $u \to v$ 的终点 $v$ 必然先于起点 $u$ 完成调用并加入后序列表，翻转后 $u$ 必然排布在 $v$ 左侧。
    * 起点选取倾向：重启遍历时优先选取入度为 0 的顶点，能够使递归生成树形态与逻辑拓扑依赖高度吻合。
    * > **易错点**：正向先序遍历直接翻转无法得到拓扑排序，分支回溯会造成非依赖节点的线性位置倒置。

### 拓扑序列的几何单向性

* **无后向边定理（No Back-Edge Property）**
    * > **定义**：将图顶点按拓扑序列自左向右水平排开，图中所有有向边均严格从左指向右。
    * 环路判定：排布序列中一旦出现从右向左指回的反向边，即直接判定图中存在有向环。
    * 拓扑流向模型：拓扑排序将网状依赖结构解耦为单向流动的流水线结构。

```text
拓扑序列几何排布示意图：
C ----> F ----> G ----> A ----> D ----> B ----> E ----> H
|                               |       |       ^       ^
|                               +-------|-------+       |
|                                       +---------------+
（全图所有有向箭头方向均严格由左侧指向右侧）
```

## 有向无环图单源最短路径

### 负权边对贪心最短路径算法的破坏机制

* **Dijkstra 算法贪心失效（Dijkstra Greed Invalidation）**
    * > **定义**：在包含负权边的图中，Dijkstra 算法出队节点即为全局最优距离的贪心不变量被破坏，导致下游节点无法更新而计算失真。
    * 失效机理：已标记完成的节点被后续更长路径通过负边二次缩短，但已出队节点无法重新激活，导致其下游所有连带节点的距离更新链条永久中断。
    * 通用图修复代价：在通用图上处理负权边需使用 Bellman-Ford 算法，时间复杂度上升至 $O(V \times E)$。
    * > **易错点**：给通用图所有边权累加统一常数无法修复 Dijkstra 的负权缺陷，不同跳数的路径累加常数权重不同，会导致原图最短路径发生结构性位移。

### 拓扑序线性松弛算法

* **DAG 单源最短路径算法（DAG Single-Source Shortest Paths，DAG-SSSP）**
    * > **定义**：在 DAG 上依照拓扑排序序列，依次对每个顶点的所有出边执行标准松弛操作以计算单源最短路径的算法。
    * 时间复杂度：拓扑排序阶段消耗 $O(V + E)$，按序线性松弛各边消耗 $O(V + E)$，全流程总时间复杂度为 $O(V + E)$。
    * 空间复杂度：距离数组与路径前驱数组占用 $O(V)$ 存储空间。
    * 队列依赖消除：完全去除优先队列等重型数据结构，仅依赖普通数组或链表进行线性扫描。
    * 松弛方程：针对边 $u \to v$（权重 $w$），执行条件判断 $\text{distTo}[u] + w < \text{distTo}[v]$ 并更新极值。

```text
算法流程：DAG-SSSP(G, S)
1. 调用反向 DFS 后序遍历获得拓扑序列 topoOrder；
2. 初始化 distTo[S] = 0，对其余所有顶点 v 设置 distTo[v] = ∞；
3. 按照 topoOrder 顺序依次遍历每个顶点 u：
       遍历从 u 出发的每一条出边 u -> v (权重为 w)：
           if distTo[u] + w < distTo[v]:
               distTo[v] = distTo[u] + w
               edgeTo[v] = u
```

### 松弛收敛性与负权免疫机制

* **单向信息收敛（Unidirectional Information Convergence）**
    * > **定义**：在 DAG 中能够到达顶点 $u$ 的所有前置中继节点在拓扑序中均严格位于 $u$ 的左侧。
    * 收敛不变量：当指针处理至顶点 $u$ 时，所有能够抵达 $u$ 的可能路径均已完成探索与松弛，$\text{distTo}[u]$ 达到全局确定收敛。
    * 负权免疫机理：由于图无环，右侧后续节点绝无任何反向边回指到左侧节点，右侧存在的负权边绝对无法影响已完成收敛的左侧节点。

## 算法规约与有向无环图最长路径

### 算法规约范式

* **问题规约（Reduction）**
    * > **定义**：将未知问题实例转换为已知成熟问题的输入，外包给黑盒算法求解后将输出反向映射还原的解题范式。
    * 规约三部曲：
        * 预处理（Pre-processing）：将原问题输入转换为目标已知算法能够理解的合法数据结构；
        * 黑盒求解（Solve via Blackbox）：将转换后数据交由成熟算法执行运算；
        * 后处理（Post-processing）：将黑盒算法输出进行逆向解码还原为原问题的最终解。
    * 跨领域实例：渗流物理模型规约至并查集算法，布尔 3-SAT 逻辑命题规约至图论独立集问题。
    * > **提示**：规约是计算机理论科学中用于判定问题复杂度边界与可解性分类的基石工具。

```text
规约标准执行流：
[原问题输入: DAG 最长路径]
          |
          v (预处理: 边权取反 w' = -w)
[目标算法输入: 带负权的 DAG]
          |
          v [黑盒算法: DAG-SSSP 线性松弛]
[黑盒输出结果: 最短距离 dist']
          |
          v (后处理: 结果取反 dist = -dist')
[最终计算结果: 原图真实最长路径]
```

### 单源最长路径规约求解

* **通用图最长路径计算壁垒（General Longest Path Barrier）**
    * > **定义**：在通用图上求解简单最长路径属于 NP-hard 问题，当前已知算法时间复杂度呈指数级（$O(2^V)$）。
    * 环路约束边界：最长路径计算图绝对禁止存在正权环，否则路径权重可在环内循环累加至无穷大。
* **DAG 最长路径规约算法（DAG Longest Paths via Reduction）**
    * > **定义**：通过边权取反操作，将 DAG 最长路径问题规约到 DAG-SSSP 进行求解的线性算法。
    * 极值转换原理：数学上最大化权重和等价于最小化反向权重和，即 $\max \sum w_i = - \min \sum (-w_i)$。
    * 规约实现规程：
        * 预处理阶段：遍历边集将所有边权乘以 $-1$ 生成图 $G'$，耗时 $O(E)$；
        * 黑盒调用阶段：在 $G'$ 上以源点 $S$ 运行 DAG-SSSP 算法，耗时 $O(V + E)$；
        * 后处理阶段：将距离数组所有元素乘以 $-1$ 还原真实极值，耗时 $O(V)$。
    * 算法复杂度：全流程在 $O(V + E)$ 线性时间内彻底收敛。
    * > **易错点**：该规约算法在非 DAG 通用图上失效，取反后图中的正权边变成负权边，会引发负权环导致通用最短路径算法彻底崩溃。

## 经典算法推演与综合验证

### 拓扑排序全流程追踪

* **多分支无环图拓扑排序推演（Multi-Branch DAG Topological Sort Trace）**
    * > **定义**：使用反向 DFS 后序遍历追踪多分支 DAG 获取拓扑序列的标准过程。
    * 拓扑结构实例：

```text
    (A) -------> (B) -------> (C)
     |            |            |
     |            v            v
     +---------> (D) -------> (E) -------> (F)
```

* 遍历执行轨迹：
    * 步骤一：选取全图唯一零入度顶点 $A$ 作为初始起点进入 DFS；
    * 步骤二：递归推进路径 $A \to B \to C \to E \to F$；
    * 步骤三：顶点 $F$ 出度为 0，递归返回，后序列表压入：`[F]`；
    * 步骤四：回溯至 $E$，$E$ 的出边已全部处理，返回，后序列表压入：`[F, E]`；
    * 步骤五：回溯至 $C$，$C$ 的出边已全部处理，返回，后序列表压入：`[F, E, C]`；
    * 步骤六：回溯至 $B$，$B$ 递归访问未访问邻居 $D$；
    * 步骤七：顶点 $D$ 检测出边至 $E$，邻居 $E$ 已标记访问，跳过，$D$ 返回，后序列表压入：`[F, E, C, D]`；
    * 步骤八：回溯至 $B$，$B$ 的出边已全部处理，返回，后序列表压入：`[F, E, C, D, B]`；
    * 步骤九：回溯至 $A$，$A$ 检测出边至 $D$，邻居 $D$ 已标记访问，跳过，$A$ 返回，后序列表压入：`[F, E, C, D, B, A]`；
    * 步骤十：对全图最终后序序列翻转，获取合法拓扑序列：`[A, B, D, C, E, F]`。
* 边向单向性验证：
    * 边 $A \to B$：序号 1 指向 2（向右）；
    * 边 $A \to D$：序号 1 指向 3（向右）；
    * 边 $B \to D$：序号 2 指向 3（向右）；
    * 边 $B \to C$：序号 2 指向 4（向右）；
    * 边 $D \to E$：序号 3 指向 5（向右）；
    * 边 $C \to E$：序号 4 指向 5（向右）；
    * 边 $E \to F$：序号 5 指向 6（向右）；
    * 结论：图内全量边均严格满足左向右流向，拓扑序列合法。

### 单源最长路径规约证明与实现

* **DAG 线性最长路径规约推导（Linear Longest Path Reduction Proof）**
    * > **定义**：在包含任意实数权重的无正环 DAG 上，运用边权反转规约到最短路径的严格证明逻辑。
    * 输入实例条件：有向无环图 $G = (V, E)$，允许正权边与负权边共存，指定起点 $S$。
    * 规约映射构建：
        * 构造拓扑结构完全同构图 $G' = (V, E')$，设定每条边权满足 $w'(e) = -w(e)$；
        * 任意路径 $P$ 在原图权值为 $L(P) = \sum_{e \in P} w(e)$，在反转图权值为 $L'(P) = \sum_{e \in P} (-w(e)) = -L(P)$；
        * 最大化目标 $\max L(P)$ 严格等价于最小化目标 $-\min L'(P)$。
    * 算法执行步骤：
        * 步骤一（图转换）：线性遍历边集生成 $G'$，耗时 $O(E)$；
        * 步骤二（拓扑序生成）：在 $G'$ 上执行反向 DFS 后序遍历生成拓扑序列，耗时 $O(V + E)$；
        * 步骤三（外包线性松弛）：按拓扑序扫描各顶点并对出边执行标准松弛操作，更新 $\text{distTo}'[v] = \min(\text{distTo}'[v], \text{distTo}'[u] + w')$，耗时 $O(V + E)$；
        * 步骤四（结果还原）：输出真实最长距离 $\text{distTo}[v] = -\text{distTo}'[v]$，前驱边数组 $\text{edgeTo}$ 保持原样输出，耗时 $O(V)$。
    * 结论：算法通过规约范式避开 NP-hard 计算复杂度，以严格 $O(V + E)$ 线性代价求解最长简单路径。
