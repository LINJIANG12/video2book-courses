# 基础排序算法选择与插入排序

## 排序理论基石与度量模型

* **全序关系（Total Order）**
    * > **定义**：定义在特定集合上的二元比较关系，满足任意两元素均可比较且具备严格单调传递性。
    * 三歧性（Trichotomy）：对集合内任意元素 $A$ 与 $B$，$A < B$、$A = B$ 与 $A > B$ 三种情况互斥且完备，必有且仅有一种情况成立。
    * 传递性（Transitivity）：若 $A < B$ 且 $B < C$ 成立，则必有 $A < C$。
    * 排序目标：依据给定的全序关系，将包含 $N$ 个元素的输入序列重新排列为满足 $A_1 \le A_2 \le \dots \le A_N$ 的非递减序列。
    * > **提示**：当数据集中存在键值并列的元素时，满足非递减全序定义的合法输出结果可能不唯一。

* **逆序对（Inversion）**
    * > **定义**：序列中相对位置关系违背全局非递减目标序的元素对，即满足索引 $i < j$ 但数值 $A[i] > A[j]$ 的无序二元组。
    * 候选基数：规模为 $N$ 的数组中包含的所有可能元素对总数为 $\binom{N}{2} = \frac{N(N-1)}{2}$。
    * 度量属性：逆序对总数精确量化序列与完全有序状态的偏离程度，完全有序时逆序对数量为 0，完全逆序时达到理论上限 $\frac{N(N-1)}{2}$。
    * 计算本质：比较排序算法的物理执行过程等价于逐步消除序列内部的逆序对，直至逆序对计数彻底清零。

* **额外辅助空间（Auxiliary Space）**
    * > **定义**：算法在执行计算任务过程中额外申请的动态内存或执行栈空间，严格排除输入数据本身占据的物理存储。
    * 评估基准：输入数组属于调用方持有的预分配外部空间，不计入算法自身开销。
    * 原地特性（In-place）：当且仅当算法执行期间的额外辅助空间复杂度收敛于 $\Theta(1)$ 时，该排序算法被判定具备原地属性。

## 选择排序机制与复杂度模型

* **选择排序（Selection Sort）**
    * > **定义**：通过反复在未排序区间中线性扫描全局极值，并将其与未排序区间起始元素对调冻结的就地比较排序算法。
    * 运行机制：维护已排序前缀与未排序后缀边界；每轮完整遍历未排序区间定位最小值，与未排序区首位执行一次位置互换，已排序边界向右推进一位。
    * 推进轨迹：
    ```text
    初始状态:    [ 32, 15,  2, 17, 19, 26, 41, 17 ]
    第 1 轮扫描: [  2 | 15, 32, 17, 19, 26, 41, 17 ] (2 与 32 对调，2 冻结)
    第 2 轮扫描: [  2, 15 | 32, 17, 19, 26, 41, 17 ] (15 原位就绪，冻结)
    第 3 轮扫描: [  2, 15, 17 | 32, 19, 26, 41, 17 ] (17 与 32 对调，冻结)
    第 4 轮扫描: [  2, 15, 17, 17 | 19, 26, 41, 32 ] (后位 17 与 32 对调，冻结)
    ```
    * 比较开销：比对次数呈现严格的等差数列求和 $N + (N - 1) + \dots + 1 = \frac{N(N + 1)}{2}$。
    * 复杂度界限：无论输入序列初始分布形态，最佳、最坏与平均时间复杂度均恒定为 $\Theta(N^2)$。
    * 空间利用：仅需常数级别的局部循环游标变量，额外辅助空间复杂度为 $\Theta(1)$。
    * > **易错点**：选择排序无法感知数据的局部既有序性，即便是完全有序的输入数组，算法依然会机械执行完整的二次方比较扫描。

## 堆排序演进与内存极限优化

* **朴素堆排序（Naive Heapsort）**
    * > **定义**：利用外部二叉优先队列作为数据缓冲载体，依次完成全量灌堆与极值倒序填充的两阶段排序算法。
    * 阶段一（最大堆构建）：逐个将 $N$ 个元素插入独立的最大堆，单次插入上浮开销为 $O(\log N)$，总构建耗时为 $\Theta(N \log N)$。
    * 阶段二（排空与逆序填装）：循环从最大堆提取堆顶最大项，倒序填入独立的输出数组末端，单次下沉调整开销为 $O(\log N)$，总提取耗时为 $\Theta(N \log N)$。
    * 瓶颈代价：尽管时间复杂度优化至 $\Theta(N \log N)$，但因额外引入独立的堆数组与输出结果数组，额外辅助空间复杂度劣化至 $\Theta(N)$。

* **单数组双向复用机制（Array In-place Dual-Reuse）**
    * > **定义**：基于最大堆工作边界收缩与有序序列增长的物理互补性，在单一连续存储空间内实现零额外内存接力的原地布局方案。
    * 物理映射模型：
    ```text
    数组状态变迁轨迹:
    初始阶段: [               最大堆工作区 (大小为 N)               ]
    交接阶段: [ 有效最大堆 (0 至 k-1) | 递增有序序列 (k 至 N-1)     ]
    终态阶段: [               完全有序序列 (大小为 N)               ]
    ```
    * 移位规则：堆顶最大值被弹出后，将原堆尾元素（位置 $k-1$）转移至堆顶执行下沉，空出的物理位置 $k-1$ 恰好承接刚弹出的堆顶最大值，实现存储拓扑复用。

* **自底向上堆化（Bottom-up Heapification）**
    * > **定义**：在无序完全二叉树对应的层序数组上，依循逆层序自底向上对非叶子节点依次执行下沉修复的线性建堆策略。
    * 遍历起点：依完全二叉树层序性质，起始节点定位于最后一个非叶子节点，索引下界为 $\lfloor N/2 \rfloor - 1$，倒序迭代至全局根节点 0。
    * 归纳成立依据：底层叶节点无子代，天然满足堆序公理；当处理特定父节点时，其左、右子树已由先前迭代修复完毕，仅需执行单次下沉即可令该父节点辖下的整棵子树合法化。
    * 下沉调整推演：
    ```text
                    32 (0)
                 /          \
              15 (1)        2 (2)
             /      \      /     \
           17 (3)  19 (4) 26 (5) 41 (6)
          /
        17 (7)

    逆层序调整时序:
    1. 叶节点集合 {17, 19, 26, 41, 17} 属于无子树结构，跳过下沉。
    2. 处理节点 2: 子节点 26 与 41 中 41 较大，2 与 41 对调，右侧子树合规。
    3. 处理节点 15: 子节点 17 与 19 中 19 较大，15 与 19 对调，左侧子树合规。
    4. 处理根节点 32: 左右子节点 19 与 41 中 41 较大，32 与 41 对调；32 降至索引 2 处大于子节点 26 与 2，调整终止。
    ```
    * 堆化复杂度推导：
      $$\sum_{h=0}^{\lfloor \log N \rfloor} \frac{N}{2^{h+1}} \cdot O(h) = O\left( N \sum_{h=0}^{\infty} \frac{h}{2^h} \right) = \Theta(N)$$
    * 线性加速根源：底层规模庞大的叶子与次低层节点仅需极短下沉路径，树高达到 $\log N$ 的长路径仅对应根节点极少项。

* **原地堆排序（In-place Heapsort）**
    * > **定义**：集成自底向上原地堆化与双向复用退火机制，仅在原始数组内部完成全量排序的高效算法。
    * 阶段耗时组合：堆化耗时 $\Theta(N)$ 与 $N$ 次堆顶删除下沉耗时 $\Theta(N \log N)$ 叠加，整体时间复杂度为 $\Theta(N \log N)$。
    * 辅助空间收敛：全程免除额外动态空间开辟，辅助空间复杂度严格达到 $\Theta(1)$。
    * 排序算法特征对照：
    ```text
    +-----------------+------------------+------------------+----------------+
    | 算法名称        | 最坏时间复杂度   | 最佳时间复杂度   | 额外空间复杂度 |
    +-----------------+------------------+------------------+----------------+
    | 选择排序        | Theta(N^2)       | Theta(N^2)       | Theta(1)       |
    | 朴素堆排序      | Theta(N log N)   | Theta(N log N)   | Theta(N)       |
    | 原地堆排序      | Theta(N log N)   | Theta(N log N)   | Theta(1)       |
    +-----------------+------------------+------------------+----------------+
    ```

* **硬件缓存局部性衰减（Cache Locality Degradation）**
    * > **定义**：堆排序在下沉计算中频繁在非连续离散内存之间跨层跃迁，导致现代 CPU 高速缓存行预取机制失效的性能退化现象。
    * 访存空间失配：节点 $i$ 的后代索引分别为 $2i + 1$ 与 $2i + 2$，数据规模增大时，单次比较伴随巨大的内存地址跨度。
    * 硬件停顿代价：无法利用连续物理地址的缓存行预取优势，频繁产生 L1/L2/L3 级缓存未命中（Cache Miss），迫使 CPU 流水线停顿等待主存加载。
    * 现实架构表现：由于物理缓存常数因子严重偏大，原地堆排序在工业生产库中的真实运行耗时往往显著劣于平均情况下的快速排序或归并排序。
