# 不相交集并查集

## 抽象数据类型与模型跃迁

### 接口规范与数学抽象

* **不相交集（Disjoint Sets）**
    * > **定义**：用于维护一组互不相交的动态集合，并支持动态合并与连通性查询的数据结构。
    * 核心接口由 `connect(int p, int q)` 与 `isConnected(int p, int q)` 构成。
    * 连通关系满足自反性、对称性与传递性（Transitivity）。
    * 连通状态变更具有单向不可逆性，元素一经连通无法动态撤销断开。
    * 预设约束为固定规模 $N$，元素编号对应 $0$ 到 $N - 1$ 的连续整数。
    * 核心接口方法签名定义如下：
    ```java
    public interface DisjointSets {
        void connect(int p, int q);
        boolean isConnected(int p, int q);
    }
    ```

* **连通分量（Connected Component）**
    * > **定义**：图论中任意两顶点间皆存在连通路径的极大子图等价类。
    * 视角跃迁：由记录具体连线拓扑转变为维护顶点所属的等价类集合归属。
    * 查询判定：两节点是否连通完全等价于两节点是否属于同一个连通分量集合。
    ```text
    拓扑连线视角 (冗余关注具体路径):
      0 ----- 1 ----- 2
      \              /
       \----- 4 ----/

    集合归属视角 (关注等价类划分):
      集合 A: { 0, 1, 2, 4 }
      集合 B: { 3, 5 }
    ```

### 朴素集合容器模型

* **集合列表实现（List of Sets）**
    * > **定义**：以列表容器嵌套集合对象（`List<Set<Integer>>`）维护各等价类分量的朴素表示法。
    * 初始化机制：为 $0$ 到 $N - 1$ 各自创建独立的单元素集合并存入动态列表。
    * 查询机理：遍历列表检索包含目标元素的集合，最坏时间复杂度为 $O(N)$。
    * 合并机理：线性扫描定位两个元素所属集合，全量搬移元素合并后注销空集，最坏时间复杂度为 $O(N)$。
    * > **易错点**：由于每轮操作均需线性遍历列表扫描集合，嵌套容器的高额开销导致大规模调用吞吐率极低。

## 树状层次结构与加权平衡

### 扁平数组与父指针拓扑

* **快速查找（Quick Find，QF）**
    * > **定义**：使用一维数组直接记录每个元素所属集合标识 ID 的扁平化实现模型。
    * 底层数组：开辟长度为 $N$ 的数组 `int[] id`，索引为元素编号，数值为集合 ID。
    * 连通查询：直接判断 `id[p] == id[q]`，单次查询时间复杂度为 $\Theta(1)$。
    * 合并流程：遍历整个数组，将所有与 `id[p]` 相同的元素重写为 `id[q]`，单次合并时间复杂度为 $\Theta(N)$。
    * > **易错点**：合并操作必须全盘扫描替换所有相同标签的元素，调用 $N$ 次合并会导致总耗时恶化至 $O(N^2)$。

* **快速合并（Quick Union，QU）**
    * > **定义**：使用父指针数组构建森林结构，各连通分量通过有向树层级表达的模型。
    * 底层数组：维护 `int[] parent`，`parent[i]` 存储节点 $i$ 的直接父节点索引，根节点特殊标记为 `-1`。
    * 寻根操作：从当前节点出发持续沿父指针攀爬，直到抵达数组值为负数的根节点。
    * 连通查询：分别计算 `find(p)` 与 `find(q)`，比对两者的根节点是否相同。
    * 集合合并：通过 `parent[rootP] = rootQ` 将一棵树的根节点直接接入另一棵树的根节点。
    ```text
    树状层级拓扑与底层数组映射:
           0           3
          / \          |
         1   4         5
         |
         2
    索引 i:       0    1    2    3    4    5
    parent[i]: [ -1 |  0 |  1 | -1 |  0 |  3 ]
    ```
    * > **易错点**：执行合并时必须作用于两个集合的根节点，严禁直接让底层非根节点建立父子连接。
    * 拓扑退化：任意指定挂载方向会导致树高度不可控，最坏情况下退化为高度为 $N$ 的单向长链，使操作退化为 $O(N)$。

### 尺寸加权与空间优化

* **加权快速合并（Weighted Quick Union，WQU）**
    * > **定义**：在合并两棵树时始终将节点总数较小的树挂载到较大树的根节点下方的优化策略。
    * 核心规则：合并前比对两集合的大小权重，严格执行小树根并入大树根（Union-by-Size）。
    * 深度变化：大树内所有原节点深度维持不变，仅并入的小树内部节点深度加 $1$。
    * 尺寸与高度权衡：按大小合并与按高度合并渐进性能相同，但追踪节点总数比维护树高在编码实现上更直接。

* **对数树高界限（Logarithmic Height Bound）**
    * > **定义**：通过小树并入大树规则限制树高增长，使其严格受制于节点总数对数级规模的数学特性。
    * 树高增长充要条件：树高仅在两棵高度完全相同且节点规模相当的树合并时递增 $1$。
    * 规模倍增公式：树高达到 $h$ 时所需最少节点总数满足 $N \ge 2^h \implies h \le \log_2 N$。
    * 性能跃迁：`find`、`connect` 与 `isConnected` 的时间复杂度上限全部被压缩至 $O(\log N)$。
    ```text
    树高增长与最少节点倍增推演:
    高度 0: (1 个节点)      高度 1: (至少 2 节点)      高度 2: (至少 4 节点)
        O                     O                        O
                              |                       / \
                              O                      O   O
                                                         |
                                                         O
    ```

* **负数复用根节点标记（Negative Root Trick）**
    * > **定义**：在单个 `parent` 数组中通过数值正负性同时表示父节点指向与树规模的工程编码技术。
    * 内部编码约定：非负值 `parent[i] >= 0` 表示其父节点索引；负数值 `parent[r] < 0` 标记该节点为树根。
    * 权重存储约定：根节点存储的负数绝对值 `|parent[r]|` 直接代表该树包含的节点总数。
    * 状态转移：初始化为 `-1`；合并时直接累加负数值，无需额外开辟独立的 `size[]` 数组。

## 路径压缩与性能全景

### 路径扁平化与渐进极限

* **路径压缩（Path Compression）**
    * > **定义**：在寻根遍历回溯阶段将查询路径上途径的所有节点直接重定向挂载至根节点的操作。
    * 代码机理：利用递归回溯执行赋值更新，使得全路径节点深度直接降为 $1$。
    ```java
    private int find(int i) {
        if (parent[i] < 0) {
            return i;
        }
        parent[i] = find(parent[i]);
        return parent[i];
    }
    ```
    * 自愈特性：树结构随调用次数增加持续扁平化，后续操作具备极强的访问加速效果。
    ```text
    路径压缩前后拓扑对比:
    压缩前:               压缩后:
        0 (根)                0 (根)
        |                 / / | \
        1                1 5 11 15
        |
        5
        |
       11
        |
       15
    ```

* **反阿克曼函数（Inverse Ackermann Function，$\alpha(N)$）**
    * > **定义**：阿克曼函数增长率对应的极缓增长反函数。
    * 增长极限：对于宇宙中一切物理计算规模（$N < 2^{65536} \approx 10^{19728}$），$\alpha(N) \le 5$。
    * 综合复杂度：结合加权快速合并与路径压缩后，单次操作的均摊时间复杂度为 $O(\alpha(N))$，工程上等价于 $O(1)$。

### 综合性能对比与实战推演

* **算法复杂度全景对比**
    * > **定义**：并查集各阶段演进方案在底层表示、接口耗时与结构限制上的横向指标对照。
    * 各实现模型关键指标对照表：

| 方案版本 | 底层数据表示 | `isConnected` 复杂度 | `connect` 复杂度 | 核心瓶颈 / 演进驱动 |
| :--- | :--- | :--- | :--- | :--- |
| **连线集合列表** | `List<Edge>` | $O(N)$ | $O(1)$ | 连通查询需进行全图路径搜索 |
| **集合列表** | `List<Set<Integer>>` | $O(N)$ | $O(N)$ | 容器嵌套过重，增删遍历开销过大 |
| **快速查找 (QF)** | `int[] id` | $\Theta(1)$ | $\Theta(N)$ | 合并必须全量扫描数组改写标签 |
| **快速合并 (QU)** | `int[] parent` | $O(N)$ | $O(N)$ | 树形易退化为单链表导致深度失控 |
| **加权快速合并 (WQU)** | `int[] parent` + 尺寸权重 | $O(\log N)$ | $O(\log N)$ | 小树并入大树，树高对数受限 |
| **WQU + 路径压缩** | `int[] parent` + 递归扁平化 | $O(\alpha(N))$ | $O(\alpha(N))$ | 访问路径完全拍平，达到常数级均摊 |

* **加权跨集挂载推演（Weighted Union Evaluation）**
    * > **规则**：执行连接前必先定位各自根节点，再依据两根节点的大小权重决定挂载从属关系。
    * 场景设定：树 $A$ 根节点为 $0$（权重大小为 $6$），树 $B$ 根节点为 $6$（权重大小为 $4$），执行 `connect(3, 8)`。
    * 寻根过程：递归求得节点 $3$ 归属根节点 $0$，节点 $8$ 归属根节点 $6$。
    * 权重裁定：比较尺寸发现树 $B$（大小 $4$）小于树 $A$（大小 $6$），执行小树挂大树。
    * 底层修改：修改小树根的父指针，使其直接指向大树根，执行底层赋值 `parent[6] = 0`。
    * > **易错点**：不可将操作节点的父指针直接相连，修改 `parent[3] = 8` 或 `parent[8] = 3` 会割裂连通分量拓扑。
