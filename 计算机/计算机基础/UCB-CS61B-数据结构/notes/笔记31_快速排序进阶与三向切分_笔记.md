# 快速排序进阶与三向切分

## 数组分区机制与运行时间边界

### 分区核心定义与递归树模型

* **分区操作（Partitioning）**
    * > **定义**：通过挑选基准重排数组，使基准左侧元素均不大于基准、右侧均不小于基准，使基准落入最终全局有序位置的操作。
    * 状态隔离：分区完成后基准两侧生成互不干扰的子问题，左右子数组可独立递归求解。
    * 递归基：子数组长度小于等于 1 时天然有序并终止递归。

```text
原始数组:   [ 32, 15, 19, 17, 41, 26,  2 ]
                 |
               以 32 为基准进行分区 (Partition)
                 v
分区结果:   [ 15, 19, 17, 26,  2 ]  32  [ 41 ]
            \___________________/       \____/
                 全部 <= 32             全部 >= 32
```

* **最好运行时间（Best-case Runtime）**
    * > **定义**：每次选取的基准恰好平分子问题，产生严格平衡递归树时的时间复杂度。
    * 递推关系：$T(N) = 2T(N/2) + \Theta(N)$。
    * 树高与层开销：递归树深度为 $\log_2 N$，每层各子问题分区总工作量之和恒为 $N$。
    * 渐进复杂度：理论最优时间复杂度为 $\Theta(N \log N)$。

```text
第 0 层:                 [      N 个元素      ]         -> 分区耗时: N
                             /            \
第 1 层:          [ N/2 个元素 ]        [ N/2 个元素 ]    -> 分区耗时: N/2 + N/2 = N
                    /        \            /        \
第 2 层:        [ N/4 ]    [ N/4 ]    [ N/4 ]    [ N/4 ]  -> 分区耗时: 4 * (N/4) = N
                 ...        ...        ...        ...
第 log2 N 层:   [ 1 ] [ 1 ] [ 1 ] [ 1 ] ... [ 1 ] [ 1 ]   -> 单元素天然有序
```

* **最坏运行时间（Worst-case Runtime）**
    * > **定义**：每次切分均产生规模极度不对称的子问题，使递归树深度退化为线性时的时间复杂度。
    * 触发场景：数组完全有序或完全逆序，且每次固定选择首端元素作为基准。
    * 递归树退化：子问题规模按 $N, N-1, N-2, \dots, 1$ 递减，递归树退化为直角三角形单链结构。
    * 渐进复杂度：累加代价 $\sum_{i=1}^N i = \frac{N(N+1)}{2} = \Theta(N^2)$。
    * > **易错点**：归并排序的物理切分不依赖数据内容而始终维持 $\Theta(N \log N)$，快速排序的运行时间严重受制于输入数据的初始序列状态与基准选取策略。

```text
第 0 步 (规模 N):     [ Pivot ] [  剩余 N - 1 个元素全部在右侧  ]   -> 分区工作量: N
                                      /
第 1 步 (规模 N-1):              [ Pivot ] [ 剩余 N - 2 个元素 ]  -> 分区工作量: N - 1
                                                /
第 2 步 (规模 N-2):                        [ Pivot ] [ ... ]   -> 分区工作量: N - 2
```

### 非对称划分时间证明

* **固定比例划分假说（Asymmetric Partitioning, 10%-90% Split）**
    * > **定义**：每次分区子问题规模均维持固定比例常数倾斜的划分模型。
    * 每层开销：各层包含的所有子节点规模总和不超过原数组容量，每层分区总工作量恒满足 $0.1N + 0.9N = N$。
    * 最深路径缩减方程：数据量下降最慢的路径满足 $(0.9)^k N = 1 \implies k = \log_{10/9} N$。
    * 对数换底收敛：$k = \frac{\ln N}{\ln(10/9)} \approx 9.49 \ln N = \Theta(\log N)$。
    * 渐进时间上限：总工作量满足 $T(N) \le k \times N = \Theta(N \log N)$。
    * > **提示**：只要每次划分保留的子问题规模是固定比例因子而非单元素剥离，算法渐进复杂度即可维持在对数高度区间，不会退化至平方级。

```text
第 0 层:                          [ 100% N ]                    -> 工作量: N
                                  /        \
第 1 层:                  [ 10% N ]        [ 90% N ]            -> 工作量: 0.1N + 0.9N = N
                          /       \        /       \
第 2 层:              [ 1% N ]  [ 9% N ] [ 9% N ]  [ 81% N ]    -> 工作量: 0.01N + 0.09N + 0.09N + 0.81N = N
```

## 算法同构性与期望比较开销

### 朴素二叉搜索树同构映射

* **二叉搜索树排序同构（BST Sort Isomorphism）**
    * > **定义**：快速排序中元素之间产生的两两比较关系集合，与将相同数据流按输入次序依次插入朴素二叉搜索树所发生的比较集合完全等价的映射性质。
    * 全局基准等价性：快速排序第一轮基准必须与所有其他元素比较一次，等价于所有数据插入朴素 BST 时必须与根节点比较一次。
    * 子树划分等价性：分区后小于基准的数据进入左子数组且仅在内部比较，等价于后续节点落入左子树后绝不与右子树节点发生比较。
    * 拓扑退化映射：随机序列构建 BST 的平均高度为 $O(\log N)$，对应快排期望运行时间 $\Theta(N \log N)$；有序序列构建 BST 退化为单链表，对应快排退化为 $\Theta(N^2)$。

```text
【BST 插入轨迹】                         【快排以 5 为基准的分区】
       5 (根节点)                       基准 = 5
      / \                              比 5 小的进入左侧: [3, 2, 1, 4]
     3   7                             比 5 大的进入右侧: [7, 8, 6]
    / \   \
   2   4   8                           左侧递归以 3 为基准: [2, 1] 3 [4]
  /       /                            右侧递归以 7 为基准: [6] 7 [8]
 1       6
```

### 随机输入期望分布

* **期望比较次数（Expected Comparisons）**
    * > **定义**：在均匀随机分布的输入序列假设下，完成规模为 $N$ 的数组排序所需元素比较总数的数学期望。
    * 解析公式：期望比较总数公式为 $C_N \approx 2N \ln N \approx 1.386 N \log_2 N$。
    * 实验样本分布：对于规模 $N = 1000$ 的随机数组，理论比较基准 $N \log_2 N \approx 10,000$，统计密集分布区间落在 $11,000 \sim 13,000$ 次。
    * 极差对比：最坏情况比较次数为 $\frac{N(N-1)}{2} \approx 500,000 \sim 1,000,000$ 次，与随机均值存在近百倍的数量级鸿沟。
    * > **注意**：随机输入由于置换群全排列而精确命中单调排序的概率为 $1/N!$，在无特意攻击场景下触发百万次最坏情况属于极小概率事件。

## 退化防御机制与架构权衡

### 随机化与近似中位数策略

* **洗牌防御（Shuffle Defense）**
    * > **定义**：在排序执行前对全数组进行线性时间原地随机打乱，或在每次分区前随机选取基准索引的策略。
    * 破坏确定性：彻底瓦解输入数据中潜在的有序、逆序或周期性排列模式。
    * 开销代价：预处理洗牌耗费 $\Theta(N)$ 时间与 $\Theta(1)$ 额外空间。
* **三数取中法（Median-of-Three）**
    * > **定义**：在子数组的首端、中间与尾端三个固定位置中提取数值中位数作为基准的近似取样策略。
    * 规避极端值：以常数级比较开销防止基准选取到全区间最小或最大值。
    * > **易错点**：未排序数组的物理正中索引 `arr[mid]` 所存数值并非中位数，不能不经比较直接将其视作划分中位数。
* **对抗性输入漏洞（Adversarial Inputs / Killer Inputs）**
    * > **定义**：针对不包含随机熵的确定性基准选择算法，通过逆向构造特化序列诱发最坏情况的攻击载荷。
    * 漏洞成因：完全基于固定偏移采样的算法逻辑缺乏随机扰动，攻击者可通过构造特化分支数据引发拒绝服务攻击。

### 运行自省与精确中位数陷阱

* **自省排序机制（Introspective Sort, IntroSort）**
    * > **定义**：在快速排序执行期间动态监控递归深度，并在深度超标时主动切换为确定性对数级排序算法的混合控制策略。
    * 阈值设定：工业实现通常将递归深度上限设为 $2 \log_2 N$。
    * 止损降级：递归深度越界即切换为堆排序（Heapsort）或归并排序，消除平方级最坏情况。
* **精确中位数寻找陷阱（Exact Median Overhead）**
    * > **定义**：通过引入线性选择算法强制追求每次划分绝对对称而导致的工程性能恶化现象。
    * 性能实测反差：双指针配合洗牌的快排耗时仅需 0.9 秒，采用精确中位数的快排耗时剧增至 15.0 秒。
    * 瓶颈根源：单次分区引入复杂的线性扫描常数开销，消除树高倾斜获得的收益无法弥补常数项剧增造成的损耗。

## 原地分区设计与工程实测

### 三遍扫描分区缺陷

* **三遍扫描法（Three-Scan Partitioning）**
    * > **定义**：开辟等大临时缓存空间，分三次遍历原数组并分别复制小于、等于、大于基准元素的分区策略。
    * 空间复杂度：需要额外开辟 $\Theta(N)$ 辅助内存。
    * 性能瓶颈：单轮分区对数据内存执行三次全量遍历与搬移，破坏 CPU 缓存局部性，实测耗时达 3.2 秒（落后于归并排序的 1.3 秒）。

### 霍尔相向双指针原地分区

* **霍尔原地分区法（Hoare In-place Partitioning）**
    * > **定义**：在原数组两端设立双指针相向移动，通过就地交换违背偏序关系的元素对以实现分区的双指针算法。
    * 空间复杂度：严格维持 $\Theta(1)$ 原地置换。
    * 左指针推进规则：$L$ 指针从左向右扫描，遇到 $\le Pivot$ 持续前进，遇到 $> Pivot$ 驻足停滞。
    * 右指针推进规则：$G$ 指针从右向左扫描，遇到 $> Pivot$ 持续左进，遇到 $\le Pivot$ 驻足停滞。
    * 元素对换逻辑：当 $L$ 与 $G$ 双双停滞且尚未交叉时，交换两指针所指的元素。

```text
初始状态:
[  17,   15,   19,   32,    2,   26,   41,   17  ]
   ^                                           ^
Pivot                                          G 指针
   L 指针

首次停滞与交换:
[  17,   15,  [19],   32,    2,   26,   41,  [17] ] -> 交换 19 与 17
                ^                               ^
                L                               G

二次停滞与交换:
[  17,   15,   17,   [32],  [2],   26,   41,   19  ] -> 交换 32 与 2
                       ^     ^
                       L     G
```

### 指针交叉与基准归位规则

* **指针交叉终止态（Pointer Crossing）**
    * > **定义**：当左指针 $L$ 越过右指针 $G$ 时，全数组元素巡视完毕并触发的分区终止状态。
    * 核心不变量：扫描停止时，$G$ 及其左侧所有项均满足 $\le Pivot$，$L$ 及其右侧所有项均满足 $\ge Pivot$。

```text
交叉终止状态:
[  17,   15,   17,    2,    32,   26,   41,   19  ]
                      ^      ^
                      G      L
```

* **基准最终归位（Pivot Final Swap）**
    * > **定义**：分区扫描终止后，将首端基准元素置换至两子区间分割交界的收尾步骤。
    * 置换目标：基准元素必须且只能与 $G$ 指针最终指向的位置进行交换。
    * > **易错点**：交叉后 $L$ 停滞在大元素区域（$> Pivot$），$G$ 停滞在小元素区域（$\le Pivot$）。若误将基准与 $L$ 交换，大元素会被换至数组首部，直接破坏分区有效性。

```text
执行基准归位 (Swap Pivot with G):
[   2,   15,   17,   [17],   32,   26,   41,   19  ]
                       ^
                   基准成功就位
  \______________/           \__________________/
     全部 <= 17                   全部 >= 17
```

### 分区变体实测基准对照

* **算法变体性能测试指标（Benchmark Comparison）**
    * 快排变体 B（霍尔双指针分区 + 预洗牌）：0.9 秒。
    * 归并排序（标准归并排序实现）：1.3 秒。
    * 快排变体 A（三遍扫描分区法 + 预洗牌）：3.2 秒。
    * 快排变体 C（精确中位数基准 + 霍尔双指针分区）：15.0 秒。
    * 工程决策原则：极低常数的单次相向原地扫描结合随机化防御，在软硬件缓存架构下具备最优综合性能。
