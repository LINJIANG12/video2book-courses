# MSD基数排序与排序综合对比

## 最高位优先基数排序机制

### 算法动机与执行陷阱

* **最高位优先基数排序（Most Significant Digit Radix Sort，MSD）**
    * > **定义**：从键值的最高有效位向最低有效位推进，利用分治隔离与递归分桶实现全序排列的非比较排序算法。
    * 启发逻辑：长字符串比较时首字符差异即可决定全局偏序，提前处理高位可避免扫描低位冗余字符。
    * 执行架构：逐级生成多路递归树，不同高位前缀的数据划分到不同子数组后互不干扰。
    * > **易错点**：不可直接将低位优先（LSD）的全局计数排序循环逆序执行。若不在高位分桶后隔离子数组，后续低位计数排序会直接打乱并覆盖高位已确立的相对顺序。

```text
原始输入与第一轮（按第 1 位排序）：
[ADDY]  -- 首字母 A 排在前面
[BAD ]  -- 首字母 B 排在后面

第二轮（按第 2 位全局排序导致交叉错位）：
[BAD ]  -- 第二位是 A，被违规排到最前
[ADDY]  -- 第二位是 D，被错误置于其后
```

### 分治分桶与递归结构

* **子问题切分准则（Subproblem Partitioning Rule）**
    * > **定义**：以当前数位字符作为键值执行桶划分，并为各个前缀桶确立严格物理边界的分治策略。
    * 处理步骤：针对当前数位进行计数分桶；为每个字符分支建立独立子数组；将规模大于 1 的子桶递推到下一位继续递归处理。
    * 递归基（Base Case）：子桶内元素规模为 1，或待比对字符指针到达字符串末尾。
    * 稳定性要求：子桶内部递归处理下一数位时不再强制要求数位排序的绝对稳定性，子桶间的边界隔离已确保全局有序。

```text
全部输入数据
   │
   ├── [A 开头桶] ── 内部递归按第 2 位分桶
   │      ├── [AC...] ── 子规模为 1，触发 Base Case 终止
   │      └── [AD...] ── 子规模为 1，触发 Base Case 终止
   │
   ├── [B 开头桶] ── 内部递归按第 2 位分桶
   │      └── [BEE, BE...] ── 子规模为 2，继续向下递归
   │
   └── [F 开头桶] ── 子规模为 1，触发 Base Case 终止
```

### 复杂度特征与非对称性

* **基数排序非对称性（Asymmetry of Radix Sorts）**
    * > **定义**：LSD 与 MSD 在数据流向、控制流结构及子问题划分机制上的根本拓扑差异。
    * 结构差异：LSD 依赖全局平铺的稳定计数循环；MSD 依赖动态分裂的树状分治递归。
    * 最好情况复杂度：输入字符串首位完全互异时，仅需一次分桶即全部落入大小为 1 的桶中，耗时为 $\Theta(N)$。
    * 最坏情况复杂度：输入字符串完全相同或前缀高度一致时，算法必须完整下钻至第 $W$ 位，耗时为 $\Theta(W N)$。

## 基数排序与比较排序的理论成本核算

### 字符串比较开销修正

* **长对象比较代价（Cost of Long Key Comparisons）**
    * > **定义**：在基于比较的排序中，非原生基本类型对象比较操作消耗的非常数级检查成本。
    * 判定模型：两个字符串比较耗时取决于公共前缀长度；最好情况（首字符不同）耗费 $O(1)$，最坏情况（完全一致或极长前缀一致）耗费 $\Theta(W)$。
    * 归并排序复杂度修正：考虑字符串长度 $W$ 时，实际时间复杂度区间为 $[N \log N, W N \log N]$。
    * 理论优势分水岭：极端相似数据集下，基数排序 $\Theta(W N)$ 理论上优于归并排序 $\Theta(W N \log N)$；极端互异且 $W$ 极大时，归并排序 $\Theta(N \log N)$ 优于 LSD 的 $\Theta(W N)$。

### 字符检查成本模型

* **字符访问计数模型（Characters Examined Cost Model）**
    * > **定义**：通过量化算法执行期访问字符的总次数，精确评估字符串排序算法开销的理论模型。
    * 计数规则：比较排序单次字符比较读取 2 个字符，计为 2 次字符检查；基数排序单次桶计数提取 1 个字符，计为 1 次字符检查。
    * 边界设定：待排元素数量 $N = 100$，元素长度 $W = 1000$，且所有字符串完全相等。

### 极端全同场景定量推演

* **基数排序账单推导（Radix Sort Cost Derivation）**
    * > **定义**：在完全平局状态下基数排序遍历所有数位的字符检查量核算。
    * 计数过程：每轮计数排序对 $N$ 个字符串各提取 1 次字符，共扫描 $W$ 轮。
    * 总检查量：$100 \times 1000 = 100,000$ 次字符检查。

* **归并排序账单推导（Merge Sort Cost Derivation）**
    * > **定义**：在完全平局状态下归并排序合并阶段产生的逐位字符比对开销核算。
    * 单次全同比较开销：比对双方所有数位均相等，单次比较耗费 $2 \times 1000 = 2000$ 次字符检查。
    * 单层合并开销：规模为 $N$ 的合并需要进行 $N/2$ 次比较（左半区耗尽即结束，右半区直接复制），单层检查量恒定为 $(N / 2) \times 2000 = 100,000$ 次。
    * 递归树总开销：归并树深度为 $\log_2(100) \approx 6.64$ 层，累计字符检查总量约为 $100,000 \times 6.64 \approx 664,000$ 次。
    * 理论倍率预测：归并排序检查量为基数排序的约 6.6 倍，理论预期耗时落后 6.6 倍。

```text
归并递归树                每层合并工作量
       [ 100 ]            --> 顶层合并：50 次比较 = 100,000 次字符检查
      /       \
   [ 50 ]   [ 50 ]        --> 第二层：2 × 25 次比较 = 100,000 次字符检查
   /    \   /    \
  [25] [25] [25] [25]     --> 第三层：4 × 12.5 次比较 ≈ 100,000 次字符检查
         ...              --> 树总深度共约 log2(100) ≈ 6.64 层
----------------------------------------------------------------------
总字符检查量：约 664,000 次
```

## 实证基准测试与运行时底层机理

### 基准性能反转现象

* **理论预测与实测背离（Theoretical Divergence Phenomenon）**
    * > **定义**：在高度相似的大规模数据集下，理论复杂度更高的归并排序实际执行时间反超基数排序的工程异象。
    * 实测数据特征：小规模（$N \le 10^5$）时两者性能相近；大规模（$N \ge 10^6$）时，归并排序耗时显著低于 MSD 基数排序。

### 理论模型缺陷与隐性常数

* **计数模型的局限性（Limitations of Abstract Cost Models）**
    * > **定义**：仅统计核心操作次数而忽略内存布局与系统级开销导致的分析失真。
    * 忽略的开销分量：MSD 在每一层递归和数位切分中频繁申请辅助计数数组、计算前缀和、分散写回内存。
    * 局部性差异：归并排序内存访问具备连续性与空间局部性；MSD 深层递归散列入桶造成高频跨缓存行访问与指针跳跃。

### 即时编译器优化机制

* **即时编译（Just-In-Time Compilation，JIT）**
    * > **定义**：JVM 在运行时监测热点执行代码并直接将其动态编译为本地物理机硬件指令的编译优化技术。
    * 热点编译与内联：连续高频执行的方法与紧凑循环被直接扁平化为纯机器指令，消除方法调用栈开销。
    * 死代码消除（Dead Code Elimination）：结合逃逸分析（Escape Analysis），若探测到新建对象未逸出作用域且无外部副作用，直接在编译产物中剔除对象内存分配与初始化指令。
    * 硬件协同：归并排序紧凑的双指针遍历极大受益于 CPU 乱序执行、分支预测与 L1/L2 高速缓存连续预取。

```text
代码未作修改时的循环执行耗时演变：
第 1 次执行  : [##########################] 26,000 ns (解释执行/冷启动)
第 100 次执行: [##] 1,500 ns (JIT 探测热点并编译为本地机器码)
第 200 次执行: [#] 458 ns (深度内联与机器码级循环展开)
第 400 次执行: [.] 200 ns (逃逸分析识别无用分配，彻底消除指令)
```

### 纯解释执行验证

* **解释模式对照（Interpreter Mode Baseline）**
    * > **定义**：通过虚拟机参数 `-Xint` 强制关闭 JIT 动态优化，使代码纯粹以字节码逐行解释方式运行的验证手段。
    * 测试表征：全局运行耗时增长百倍以上；在此环境下归并排序实测速度慢于 MSD 基数排序约 3 倍。
    * 判定结论：去除底层硬件优化与编译器介入后，宏观渐近分析与字符检查模型在定性维度重新成立。

## 整数基数排序与工程参数权衡

### 固定位宽数据排序优势

* **固定位宽线性排序（Linear Sorting for Fixed-width Keys）**
    * > **定义**：针对物理位宽固定（如 32 位、64 位）的原始整数类型，利用基数排序在常数轮次内达成严格 $\Theta(N)$ 的排序策略。
    * 渐近突破：规避比较排序 $\Omega(N \log N)$ 理论下界。
    * 适用边界：海量数据处理中，固定键长使得数位参数 $W$ 蜕化为纯常数因子。

### 进制抽象与位运算提取

* **基数映射抽象（Radix Abstraction）**
    * > **定义**：将二进制比特流按任意预设位宽进行逻辑切块并映射为 $R$ 进制离散数值的表示方法。
    * 权值分解：对于数值 $V$，在基数 $R$ 下分解为 $\sum_{i=0}^{W-1} d_i \cdot R^i$。
    * 硬件级优化：通过逻辑右移 `>>` 与掩码位与 `&` 提取当前数位键值，完全替代高开销的除法与求模指令。

```text
数值 512,312 在不同基数下的权值与位数映射：
十进制   (R=10) : [ 5 ][ 1 ][ 2 ][ 3 ][ 1 ][ 2 ]   --> 6 轮排序
十六进制 (R=16) : [ 7 ][ 13][ 1 ][ 3 ][ 8 ]       --> 5 轮排序
256 进制 (R=256): [ 7 ][ 209 ][ 56 ]               --> 仅需 3 轮排序
```

### 基数与位宽平衡准则

* **基数大小权衡（Radix Size Trade-off）**
    * > **定义**：在总体耗时公式 $\Theta(W(N + R))$ 中，针对数位轮次 $W$ 与桶表规模 $R$ 进行的最优工程选择。
    * 增大 $R$ 的收益：表示数据所需的数位 $W$ 减小，外层计数排序轮次减少。
    * 增大 $R$ 的损耗：每轮排序初始化与扫描大小为 $R$ 的计数数组开销增大，破坏缓存常驻能力。
    * 32 位整数工程最优解：选取基数 $R = 256$（按 8 位单字节切分），此时 $W = 4$。
    * 架构收益：只需 4 轮循环；计数数组大小为 256 个整型单元，能完全常驻在 CPU L1 缓存中；位运算提取掩码为 `0xFF`。

## 典型分析与计算案例

### MSD基数排序极端情况分析

* **输入敏感性复杂度评估（MSD Input Sensitivity Analysis）**
    * 最好情况输入特征：输入集合中全部 $N$ 个字符串的最高有效位（第 1 位）完全互异。
    * 最好情况运行耗时：首轮按第 1 位执行计数排序后，每个子桶内元素数量均为 1，全部分支命中递归终止条件返回，无需向下递归。时间复杂度为 $\Theta(N + R)$，在 $R$ 为常数时退化为 $\Theta(N)$。
    * 最坏情况输入特征：输入集合中全部 $N$ 个字符串完全相等，或具有长度为 $W$ 的完全相同前缀。
    * 最坏情况运行耗时：在当前数位执行计数排序后无法拆分子问题，全部元素始终集中在单一子桶，算法必须递归下钻至第 $W$ 位终止。时间复杂度为 $\Theta(W N + W R)$，在 $R$ 为常数时退化为 $\Theta(W N)$。

### 数据集特征与算法选型判定

* **全同数据集渐近对比（Identical Dataset Comparison）**
    * 归并排序开销：由于字符串完全相同，每次元素比较都必须比对完全部 $W$ 个字符，单次比较耗时 $\Theta(W)$，全量数据合并总耗时为 $\Theta(W N \log N)$。
    * 基数排序开销：LSD 基数排序按位扫描 $W$ 轮，每轮耗时 $\Theta(N)$，总耗时为 $\Theta(W N)$。
    * 理论选型结论：完全全同场景下，基数排序理论上相比归并排序节省 $\log N$ 的渐近倍率，理论上优先选用基数排序。

* **长串低前缀相似数据集渐近对比（Long Key Distinct Prefix Comparison）**
    * 归并排序开销：字符串长度 $W$ 极大，但首字符差异显著。元素间比较通常只需比对首个字符即可判定偏序，单次比较耗时为 $O(1)$，总耗时趋近于 $\Theta(N \log N)$。
    * 基数排序开销：LSD 基数排序无论数据内容如何，必须无条件自右向左跑完全部 $W$ 轮计数排序，耗时恒定为 $\Theta(W N)$。
    * 理论选型结论：当 $W \gg \log N$ 且公共前缀极短时，归并排序的耗时下界显著优于 LSD 基数排序被巨大 $W$ 拖累的线性项，应优先选用归并排序或具备剪枝能力的 MSD 基数排序。

### 海量固定位宽整数排序工程方案

* **32位整数最优排序配置（32-bit Integer Optimal Sort Configuration）**
    * 目标规约：对 $N = 10^6$ 个 32 位整型数据进行升序排序。
    * 核心算法选择：基于字节分块的 LSD 基数排序。
    * 渐近复杂度依据：32 位数据位宽固定，基数排序耗时为严格线性 $\Theta(N)$，渐近性能突破比较排序 $\Omega(N \log N)$ 的理论下界。
    * 进制参数选型：取基数 $R = 256$（$2^8$，对应 1 个字节），数位宽度 $W = 4$。
    * 硬件与内存适配性：避免十进制除法取模带来的算术逻辑单元（ALU）阻塞，提取第 $k$ 位时直接执行位运算 `(val >> (k * 8)) & 0xFF`；大小为 256 的计数数组直接驻留 CPU L1 Data Cache，杜绝高速缓存未命中。
