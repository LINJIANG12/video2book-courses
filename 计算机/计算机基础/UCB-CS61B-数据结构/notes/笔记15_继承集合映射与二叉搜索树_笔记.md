# 继承集合映射与二叉搜索树

## 面向对象继承机制与代码复用

### 继承语义与关键字规范

* **类继承（Class Inheritance, extends）**
    * > **定义**：面向对象体系中同类层级之间的功能拓宽机制，用于在现有实体或抽象定义基础上进行行为扩展与逻辑延展。
    * 子类声明 `extends SuperClass` 后将直接继承父类的实例变量、方法、静态成员与嵌套类。
    * 接口之间进行同类层级派生扩展时同样使用 `extends` 关键字。
    * 派生类可直接继承父类既有算法实现，并在此基础上按需追加专有领域方法。
    * > **注意**：Java 类层级严格遵循单继承约束，一个类仅允许显式指定一个父类。
* **接口实现（Interface Implementation, implements）**
    * > **定义**：跨越抽象边界、为抽象接口协议赋予具体物理代码落地的语法机制。
    * 实现类必须显式实现接口中声明的全部抽象方法，完成从纯粹规范到具象实体的转化。
    * 单个类允许同时声明实现多个不同接口，以此实现多维度的多态行为组合。
* **匿名类（Anonymous Class）**
    * > **定义**：在代码表达式内部就地定义并实例化无独立类名派生子类对象的内联语法机制。
    * 适用于比较器等单一用途接口的即时构造，在方法体内现场完成接口方法重写。
    * 底层运行逻辑等价于编写私有静态嵌套类，编译期由编译器自动生成带编号的专用类文件。

### 构造链与封装屏障

* **构造函数隐式链接（Constructor Chaining）**
    * > **定义**：子类对象实例化过程中由运行时环境保证自底向上依次触发的构造器递归调用链条。
    * 子类若未显式声明构造函数，编译器自动合成默认无参构造函数并在首行隐式执行 `super()`。
    * 父类构造逻辑严格优先于子类特有属性初始化逻辑执行。
    * 链表哨兵节点等底层依赖结构的初始化强依赖父类构造函数，调用链路截断将引发运行时空指针异常。
    * ```text
    子类实例化触发流程:
    new RotatingSLList() ──► 子类默认无参构造 ──► 隐式触发 super() ──► 父类 SLList() 执行 ──► 完成哨兵节点内存分配
    ```text
* **私有封装隔离（Private Encapsulation）**
    * > **定义**：基类通过访问控制修饰符阻止派生类直接寻址底层私有内部状态的内存保护屏障。
    * 父类被标记为 `private` 的成员变量依然完整驻留在子类实例对象的堆内存空间中。
    * 子类不可直接通过引用标识符访问父类私有字段，所有交互必须借助父类开放的受保护或公开接口完成。
    * > **易错点**：继承并不授予子类破坏封装的权限，派生类无法绕过访问屏障强行修改父类的私有内部状态。
* **专用化泛型派生（Generic Specialization）**
    * > **定义**：派生类在继承通用泛型基类时显式锁定具体类型参数以构建特定领域结构的架构模式。
    * 派生类可直接继承成熟类库的高性能红黑树或哈希底座，同时隔离底层数据结构的直接操作细节。
    * 继承层级示例结构：`TimeSeries extends TreeMap<Integer, Double>`。
    * ```text
    类型绑定层次拓扑:
    Map<K, V> (Interface)
       ▲
       │ implements
    TreeMap<K, V> (Class)
       ▲
       │ extends (固定类型绑定: <Integer, Double>)
    TimeSeries (领域方法: plus)
    ```

## 数据结构演进与二叉搜索树拓扑模型

### 检索维度的拓扑跃迁

* **抽象数据类型（Abstract Data Type, ADT）**
    * > **定义**：纯粹由外部行为契约与支持的操作集合进行形式化定义、完全独立于具体物理实现的数据模型。
    * 集合与映射等 ADT 的行为约束与底层采用数组、链表或树状拓扑实现的细节完全解耦。
* **有序单向链表（Sorted Linked List）**
    * > **定义**：内部数据节点按照全序规则单向离散串联的线性存储容器。
    * 容量查询 `size()` 通过常数维护计数器可达到 $\Theta(1)$ 复杂度。
    * 迭代器获取 `iterator()` 直接返回首节点游标，耗时为 $\Theta(1)$。
    * 包含判断 `contains(x)` 与插入定位 `add(x)` 最坏情况下必须执行全表扫描，时间复杂度为 $\Theta(N)$。
    * 拓扑缺陷表现为缺乏随机跨度寻址路径，无法直接利用元素有序性跳跃搜索区间。
* **跳表（Skip List）**
    * > **定义**：在基础有序链表上方按照特定几何分布构建多层稀疏索引通道的对数级检索结构。
    * 查询过程首先在高层稀疏通道快速跃迁逼近目标，再逐层下沉至底层链表进行精细位移。
    * 检索与插入操作的数学期望耗时达到对数阶 $\Theta(\log N)$。
    * ```text
    跳表多层拓扑通道:
    索引层 2:  [ A ] -----------------------------> [ E ]
    索引层 1:  [ A ] -------------> [ C ] ---------> [ E ] ---------> [ G ]
    原始链表:  [ A ] -> [ B ] -> [ C ] -> [ D ] -> [ E ] -> [ F ] -> [ G ]
    ```text
* **拓扑升维与二分决策固化（Binary Search Solidification）**
    * > **定义**：将双向链表的折半检索逻辑在几何空间垂直拉伸、固化为分层树状分支连接的物理演进过程。
    * 选取有序序列中位数节点作为顶层唯一入口，向左半区间与右半区间的中位数节点分别建立单向专用引用通道。
    * 二叉搜索树在物理拓扑上直接固化了有序数组二分查找的折半状态转移路径。
    * 检索时每一次左右分支的抉择均在物理层面剪除后续待比对空间的一半数据量。
    * ```text
    折半拉伸升维过程:
                 ┌─────────── [ D ] ───────────┐
                 ▼                             ▼
         ┌─── [ B ] ───┐               ┌─── [ F ] ───┐
         ▼             ▼               ▼             ▼
       [ A ]         [ C ]           [ E ]         [ G ]
    ```

### 形式化定义与结构不变量

* **树与有根树（Tree & Rooted Tree）**
    * > **定义**：图论中任意两顶点间有且仅有一条简单路径的连通无环无向图。
    * 拥有 $N$ 个节点的树有且仅有 $N-1$ 条边，存在任意回路结构即退化为通用图。
    * 有根树中存在唯一根节点置于顶层，其余非根节点有且仅有一个唯一的父节点。
    * 没有任何下级子节点的端点被称为叶节点。
    * ```text
    连通无环树对比环路图:
       合法树: (A)                非法环路图: (A)
              /   \                          /   \
            (B)   (C)                      (B)───(C)
    ```text
* **二叉树（Binary Tree）**
    * > **定义**：树中任意节点的最大子节点数量不超过两个（度数 $\le 2$）的有序树形拓扑结构。
    * 每个节点所连接的两个分支具有严格的左右方向区分，分别称为左孩子与右孩子。
* **二叉搜索树不变量（BST Invariant）**
    * > **定义**：二叉树中任意节点其左子树内所有键均严格小于该节点键、右子树内所有键均严格大于该节点键的全局拓扑约束。
    * 全局性约束：不仅直接子节点需满足大小偏序，整棵子树范围内的所有后代节点均受该规则限制。
    * 工业实现与标准数学定义中严格禁止插入重复键，确保树中任意键的寻址路径唯一。
    * > **易错点**：不变量是全局子树性质，仅满足“父节点大于左孩子且小于右孩子”并不能保证整棵树是合法二叉搜索树。
* **全序关系（Total Order）**
    * > **定义**：集合中任意两元素均可进行严格一致性比较的数学公理集合。
    * 完备性：对任意非等元素 $P$ 与 $Q$，$P < Q$ 与 $Q < P$ 必有且仅有一者成立。
    * 传递性：若 $P < Q$ 且 $Q < R$，则必然成立 $P < R$。
    * 反对称性：若 $P \le Q$ 且 $Q \le P$，则推导得出 $P = Q$。
    * > **提示**：二叉搜索树的 `compareTo` 排序逻辑必须恪守全序公理，非全序属性（如字符串长度）会导致结构产生大面积歧义冲突。

## 二叉搜索树核心算法与映射泛化

### 递归检索与插入机制

* **二叉搜索树检索（BST Search）**
    * > **定义**：根据结构不变量沿单一路径向左或向右递归推进的对数级定位算法。
    * 若当前节点引用为 `null`，判定该分支查找落空并返回 `null`。
    * 目标键与当前节点相等时命中目标，立即返回该节点。
    * 目标键小于当前节点键时递归进入左子树，目标键大于当前节点键时递归进入右子树。
    * 代码实现：
    ```java
    static BST find(BST T, Key key) {
        if (T == null) {
            return null;
        }
        int cmp = key.compareTo(T.key);
        if (cmp == 0) {
            return T;
        } else if (cmp < 0) {
            return find(T.left, key);
        } else {
            return find(T.right, key);
        }
    }
    ```text
* **茂盛度与树高（Bushiness & Height）**
    * > **定义**：二叉树内部节点填充饱满程度及自顶向下跨越的连接深度层级。
    * 完美饱满形态下的树高 $h$ 与节点总数 $N$ 严格服从对数关系 $h = \lfloor \log_2 N \rfloor$。
    * 容纳 15 个节点的茂盛二叉树铺满 4 层节点，最深路径比较链接数为 3。
    * 节点规模翻倍至 31 个节点时，高度仅增加 1 层，最深路径比较链接数为 4。
    * 茂密形态下的检索操作最坏时间复杂度为 $\Theta(\log N)$。
* **函数式递归插入（Functional Recursive Insertion）**
    * > **定义**：通过递归返回值重写各层指针并在底端空虚位置创建新节点的函数式插入算法。
    * 基准情形命中 `T == null` 时实例化新叶节点并将其返回给上一层调用。
    * 递归调用栈回溯期间，祖先节点的左右指针重新接收原引用，唯独最底端的空指针精准捕获新节点地址。
    * 规避了父节点越级窥探子节点状态的隔空操作，消除了特殊的边界分支判断代码。
    * 代码实现：
    ```java
    static BST insert(BST T, Key ik) {
        if (T == null) {
            return new BST(ik);
        }
        if (ik < T.key) {
            T.left = insert(T.left, ik);
        } else if (ik > T.key) {
            T.right = insert(T.right, ik);
        }
        return T;
    }
    ```text
    * ```text
    函数式递归回溯绑定机制:
    下潜过程: [ dog ] ──► left ──► [ bag ] ──► right 为 null (触发 T == null)
    回溯赋值: bag.right = 新创建 [ cat ] (关键指针在此处被绑定)
              dog.left  = 原节点 [ bag ]  (旧引用重赋自身，保持无损)
    ```

### 希巴德删除算法

* **无子节点删除（Leaf Deletion）**
    * > **定义**：待剔除节点不包含任何子节点时的直接引用切断操作。
    * 父节点指向待删除节点的引用直接覆写置为 `null`。
    * 目标节点脱离活跃对象引用链，直接由垃圾回收器释放内存。
* **单子节点删除（Single-Child Deletion）**
    * > **定义**：待剔除节点仅持有一个有效子节点时的指针越级搭桥操作。
    * 父节点跨过待删节点直接牵引其唯一的子节点。
    * 待删节点的整个子树本身已满足相对父辈的偏序条件，局部移花接木不破坏整体不变量。
* **双子节点删除与后继替换（Hibbard Deletion）**
    * > **定义**：待删除节点坐拥左右双子树时通过极值替代维持二叉搜索树全局不变量的经典算法。
    * 寻找后继候选人：进入待删节点的右子树，沿左孩子指针一路下潜至最左下角的终点节点。
    * 剥离后继节点：在右子树中递归删除该后继节点，由于后继节点绝不可能拥有左孩子，该步骤无条件退化为单子或无子删除场景。
    * 覆盖写入原槽位：将剥离出的后继节点键值完整覆写到待删除节点的存储空间，保持原物理拓扑框架不变。
* **前驱与后继节点（Predecessor & Successor）**
    * > **定义**：在全序序列中数值严格排在目标键紧邻前一位与紧邻后一位的极值节点。
    * 前驱节点为待删节点左子树中的最大值节点，其右孩子指针必然恒等于 `null`。
    * 后继节点为待删节点右子树中的最小值节点，其左孩子指针必然恒等于 `null`。
    * 极值方向子指针必定缺失的拓扑保证，确保对其执行二次剥离时绝不会产生嵌套双子分支冲突。

### 映射与集合抽象实现

* **键值载荷分离（Key-Value Decoupling）**
    * > **定义**：在树节点内部将负责指引折半寻址的键与承载具体业务数据的载荷进行隔离存储的设计机制。
    * 集合实现仅需在节点中驻留用于拓扑路由与排重的 `Key`。
    * 映射实现为节点追加 `Value val` 字段作为随行绑定的业务数据载荷。
    * 树拓扑的分支流向完全由 `Key` 的比较结果全权决定，`Value` 字段不参与任何寻址计算。
    * 代码实现：
    ```java
    public class BSTMap<Key, Value> {
        private class Node {
            Key key;
            Value val;
            Node left, right;
        }
        public Value get(Key key) {
            Node x = find(root, key);
            return x == null ? null : x.val;
        }
    }
    ```
* **单向索引不对称性（Asymmetric Indexing）**
    * > **定义**：树形映射基于键构建单向偏序导致按键高效而按值低效的性能倾斜特征。
    * 按键寻址 `get(Key)` 依托二叉树折半拓扑可实现 $\Theta(\log N)$ 级别的高效检索。
    * 按值反查 `containsValue(Value)` 因树节点未对载荷进行任何排序组织，必须执行全树遍历，时间复杂度退化为 $\Theta(N)$。
    * > **易错点**：标准 `Map` 仅对键建立索引通道，按值检索时无法享受二分折半的剪枝加速收益。
