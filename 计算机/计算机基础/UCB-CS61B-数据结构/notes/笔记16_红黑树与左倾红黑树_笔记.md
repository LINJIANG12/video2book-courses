# 红黑树与左倾红黑树

## 树形重塑与旋转机制

### 旋转基础操作

* **左旋（Rotate Left）**
    * > **定义**：以目标节点为轴向左下沉，其右子节点提升为新根，并转移右子节点左子树归属权的常数时间指针变换操作。
    * 支点节点 $G$ 下沉为其右子节点 $P$ 的左子节点。
    * 介于两支点之间的子树 $K$（满足 $G < K < P$）从上位节点 $P$ 的左侧解绑，转为挂载至下沉节点 $G$ 的右侧。
    * 拓扑变换结构：
    ```text
    左旋前：                  左旋后：
            G                        P
           / \                      / \
         (A)  P         ===>       G  (C)
             / \                  / \
            K  (C)              (A)  K
    ```
    * 前置结构约束：目标节点必须包含非空的右子节点。
    * > **易错点**：对缺乏右子节点的节点执行左旋会触发空指针解引用异常导致程序崩溃。

* **右旋（Rotate Right）**
    * > **定义**：以目标节点为轴向右下沉，其左子节点提升为新根，并转移左子节点右子树归属权的常数时间指针变换操作。
    * 支点节点 $P$ 下沉为其左子节点 $G$ 的右子节点。
    * 介于两支点之间的子树 $K$（满足 $G < K < P$）从上位节点 $G$ 的右侧解绑，转为挂载至下沉节点 $P$ 的左侧。
    * 拓扑变换结构：
    ```text
    右旋前：                  右旋后：
              P                      G
             / \                    / \
            G  (C)      ===>      (A)  P
           / \                        / \
         (A)  K                      K  (C)
    ```
    * 前置结构约束：目标节点必须包含非空的左子节点。
    * > **提示**：右旋与左旋在拓扑变换语义上互为严格逆操作。

### 旋转代数性质与维护模式

* **中序遍历不变量（Inorder Invariance）**
    * > **定义**：二叉搜索树在经历任意方向与次数的旋转后，其键值集合与中序遍历单调序列始终保持恒等的代数性质。
    * 旋转仅调整局部树高分布与父子指向，不增删任何键值数据。
    * 包含 $N$ 个节点的二叉搜索树在任意两种合法拓扑形态之间至多需要 $2N - 6$ 次旋转即可完成转换。
    * > **提示**：旋转操作是重塑树形且保持二叉搜索性质成立的核心拓扑工具。

* **预防性维护（Preventative Maintenance）**
    * > **定义**：在每次元素插入时即时沿访问路径执行常数级局部修正，避免全局累积失衡的事前防范机制。
    * 区别于事后消耗 $O(N)$ 代价遍历全树重建，该策略将单次操作增量开销约束在 $O(1)$ 局部指针重定向。
    * 保证树高在插入过程中始终处于对数边界之内，消除退化为单链表的风险。
    * > **注意**：预防性维护依赖于插入回溯时的递归栈，必须自底向上连续消除违规特征。

## 2-3 树与左倾红黑树的双射投影

### 结构映射机理

* **红链接（Red Link）**
    * > **定义**：在普通二叉搜索树中用于逻辑绑定同一 3-节点内部两个元素的有向指针标记。
    * 物理存储仅占用 1 个布尔值或颜色位，底层仍为标准二叉节点引用。
    * 被红链接绑定的双节点组合体对外提供 3 条出边，等价承接 2-3 树 3-节点对应的 3 个子树分支。
    * > **提示**：红链接仅为逻辑内聚标记，二叉搜索比较逻辑完全无需区分红边与黑边。

* **左倾红黑树（Left-Leaning Red-Black Tree，LLRB）**
    * > **定义**：通过强制规定所有红链接必须向左倾斜，从而与 2-3 树建立严格一一对应关系的二叉搜索树变体。
    * 左倾契约：拆解 3-节点时，较小元素必须作为左子节点通过红链接挂载在较大元素下方。
    * 拓扑等价模型：
    ```text
    2-3 树 3-节点形态：             LLRB 左倾红链接表达：
           [ D | F ]                          F
          /    |    \           ===>        // \
       子树1  子树2  子树3                 D    子树3
                                         / \
                                      子树1 子树2
    ```
    * 双射性质：任意合法 2-3 树与唯一合法左倾红黑树形成双向一一映射。
    * 查找透明性：LLRB 键值查找代码与普通二叉搜索树完全通用，时间复杂度不受颜色标记干扰。
    * > **易错点**：若允许右倾红链接存在，同一棵 2-3 树将对应多种红黑二叉树形态，破坏状态机判决的唯一性。

### 不变量与高度边界

* **折叠还原检验法（Folding Test）**
    * > **定义**：将红链接两端节点水平聚合还原为 2-3 树节点，依据 2-3 树公理检验红黑树合法性的判别方法。
    * 红链接非连续性：路径上严禁出现连续两条红链接，连续红链接折叠后产生容纳 3 个元素的非法 4-节点。
    * 完美黑平衡：折叠后所有外部空链接到根节点的黑色链接数量处处严格相等。
    * > **易错点**：全黑链接构成的失衡二叉树折叠后等价于自身，因叶子黑深度参差不齐而判定为非法结构。

* **对数树高极值界限（Logarithmic Height Bound）**
    * > **定义**：LLRB 的最大拓扑高度由对应 2-3 树高度及红链接交替出现上限所确定的数学边界。
    * 设对应 2-3 树高度为 $H_{23}$，且满足 $H_{23} \le \log_2(N + 1)$。
    * 最好情况：全树由 2-节点构成，树中无任何红链接，$H_{\text{LLRB}} = H_{23}$。
    * 最坏情况：从根到最深叶子的路径全由 3-节点展开构成，呈现黑红严格交替链条。
    * 红链接数量上限受黑链接数量制约，满足 $\text{红链接数} \le \text{黑链接数} = H_{23}$。
    * 极限高度公式：$H_{\text{LLRB}} \le 2 \cdot H_{23} \le 2 \log_2(N + 1) = O(\log N)$。
    * > **注意**：常数系数 2 不改变渐近复杂度，LLRB 查找与插入最坏时间复杂度保持严格对数级别。

## 左倾红黑树的动态维护算法

### 插入修复状态机

* **红链接叶子插入规则（Red Link Insertion Rule）**
    * > **定义**：新节点落位于二叉搜索树底部叶子时，其与父节点的连接边必须无条件标记为红色的初始化规则。
    * 机理：模拟 2-3 树中新插入键值优先合流入底层叶子节点、将 2-节点扩展为 3-节点的吸收行为。
    * > **注意**：若以黑链接插入新节点，将直接破坏全局黑平衡不变性。

* **右倾红链接修复规则（Right-Leaning Fix Rule）**
    * > **定义**：当节点的右子链接为红且左子链接为黑时，通过左旋操作纠正倾斜朝向的结构规范化规则。
    * 触发判据：`isRed(h.right) && !isRed(h.left)`。
    * 执行动作：对当前节点 $h$ 执行一次左旋。
    * 修复转换示意：
    ```text
    右倾非法态：                左旋修复态：
        E                          S
         \\          ===>         //
          S                      E
    ```
    * > **提示**：左旋后上位的新根节点继承原父节点颜色，原父节点被标为红色。

* **连续左倾红链接修复规则（Consecutive Left-Leaning Fix Rule）**
    * > **定义**：当节点的左子链接及其左孙子链接皆为红时，通过右旋将其重构为对称暂态的平衡化规则。
    * 触发判据：`isRed(h.left) && isRed(h.left.left)`。
    * 执行动作：对当前祖父节点 $h$ 执行一次右旋。
    * 修复转换示意：
    ```text
    连续左倾红：                右旋对称化：
            C                      B
           //        ===>        // \\
          B                     A     C
         //
        A
    ```
    * > **提示**：右旋后形成根节点左右两侧同时悬挂红链接的临时 4-节点对称形态。

* **颜色翻转分裂规则（Color Flip Rule）**
    * > **定义**：当节点的左右子链接均为红时，通过反转局部三条边颜色以模拟 4-节点分裂的原子操作。
    * 触发判据：`isRed(h.left) && isRed(h.right)`。
    * 执行动作：将左、右子链接由红置黑；将当前节点连向父节点的边由黑置红。
    * 分裂转换示意：
    ```text
    翻转前（临时 4-节点）：         翻转后（子节点独立，中值上位）：
             (父)                           (父)
              |                              //
              B                              B
            // \\          ===>             / \
           A     C                         A   C
    ```
    * 结构效应：左右子树脱离为两个独立的 2-节点，中值节点以红链接形态向上层父节点传递合并。
    * 根节点边界修剪：若全树根节点的父链接被翻转为红，递归回溯终点必须将其强制重置为黑。
    * > **易错点**：颜色翻转完全不发生拓扑旋转，节点指针拓扑关系保持原样不变。

### 插入算法实现框架

* **自底向上递归修复框架（Bottom-Up Recursive Balancing）**
    * > **定义**：将插入下探与回溯状态机融于统一递归过程的极简 BST 平衡算法实现。
    * 核心递归代码结构：
    ```java
    private Node put(Node h, Key key, Value val) {
        if (h == null) return new Node(key, val, RED);

        int cmp = key.compareTo(h.key);
        if      (cmp < 0) h.left  = put(h.left,  key, val);
        else if (cmp > 0) h.right = put(h.right, key, val);
        else              h.val   = val;

        if (isRed(h.right) && !isRed(h.left))      h = rotateLeft(h);
        if (isRed(h.left)  && isRed(h.left.left)) h = rotateRight(h);
        if (isRed(h.left)  && isRed(h.right))     flipColors(h);

        return h;
    }
    ```
    * 执行时序：三条平衡判据按照左旋、右旋、翻转的固定先后次序于回溯期严格顺序判定。
    * > **提示**：根节点在每次调用插入方法返回后必须显式执行 `root.color = BLACK`。

## 拓扑推演与典型判例

### 旋转重构演练

* **退化单链树的平衡重塑（Degenerate Stick Restructuring）**
    * > **定义**：利用局部互逆旋转序列将极度单挂的细长 BST 变换为标准平衡二叉树的拓扑演练。
    * 初始形态：按序列 $[1, 2, 3]$ 顺序插入形成的右斜单链（根为 1，右孩子为 2，2 的右孩子为 3）。
    * 重构步序：
        * 第一步：对节点 3 执行右旋微调局部拓扑；
        * 第二步：对根节点 1 执行左旋，拉升节点 2 为整棵树新根，节点 1 沉降为左子节点。
    * 转换示意：
    ```text
    初始右斜单链：         节点 3 右旋局部调整：    节点 1 左旋终态：
        1                       1                    2
         \                       \                  / \
          2          ===>         2        ===>    1   3
           \                       \
            3                       3
    ```
    * 拓扑结论：单侧极端退化树无需重建内存节点，通过常数次就地旋转可完全恢复平衡树高。

* **3-节点孪生映射推演（3-Node Twin Projection）**
    * > **定义**：将 2-3 树中包含键值对 $[U \mid W]$（$U < W$）的三叉结构规范化为二叉红黑形式的推导过程。
    * 映射规则：较大键值 $W$ 上位作为二叉父节点，较小键值 $U$ 通过左倾红链接挂载于 $W$ 的左子节点分支。
    * 子树挂接：小于 $U$ 的子树挂在 $U$ 的左侧，介于 $U$ 与 $W$ 之间的子树挂在 $U$ 的右侧，大于 $W$ 的子树挂在 $W$ 的右侧。
    * 书面规范：无彩色绘制场景下，使用双实线或 `//` 标示红链接。
    * > **提示**：其余标准 2-节点及外部子树连接边均原样对应普通黑色二叉链接。

### 结构合法性判决判例

* **连续左红结构判定（Consecutive Left-Red Validation）**
    * > **定义**：对分支包含连续双红链接结构合法性的判定准则。
    * 构型特征：根节点经红链接连向左子节点，左子节点复经红链接连向左孙子节点。
    * 折叠检验：将两条红链接折叠合并后，形成包含 3 个键值的节点。
    * 判定结论：非法。2-3 树节点容量上限为 2，容纳 3 个键值的 4-节点不能作为稳态结构长期留存。

* **非均衡黑深度判定（Unequal Black-Depth Validation）**
    * > **定义**：对存在红链接但叶子节点黑高度不一致拓扑的判定准则。
    * 构型特征：树中包含孤立左倾红链接，但左右两翼叶子节点经历的黑色边跳数不相等。
    * 折叠检验：折叠红链接还原回 2-3 树后，各叶子节点所处深度参差不齐。
    * 判定结论：非法。2-3 树公理规定所有叶子必须严格处在完全相同深度，该形态在 2-3 树空间无物理原型。

* **全黑失衡二叉树判定（All-Black Unbalanced BST Validation）**
    * > **定义**：对全由黑链接构成但整体结构倾斜失衡树形的判定准则。
    * 构型特征：树中不存在任何红链接，但左右子树高度相差较大导致叶子深度不均。
    * 折叠检验：全黑链接导致折叠映射为自身，还原后的 2-3 树各叶子节点深度不一致。
    * 判定结论：非法。该树无法通过合法的 2-3 树或 LLRB 插入算法生成，不满足完美黑平衡条件。

* **标准合规 LLRB 判定（Standard Compliant LLRB Validation）**
    * > **定义**：对满足左倾红链接与绝对黑平衡约束拓扑的肯定性判定准则。
    * 构型特征：所有红链接严格向左单挂、全树无连续红链接且根到所有叶子的黑链接跳数绝对一致。
    * 折叠检验：红链接折叠后得到合规 3-节点，所有叶子严格处于同一深度。
    * 判定结论：唯一合法。该形态与合法的绝对平衡 2-3 树严格双射成立。
