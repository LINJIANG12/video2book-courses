# UC Berkeley CS61B：数据结构与抽象数据类型

UC Berkeley CS61B《数据结构与抽象数据表示》课程（Fall 2025 季）。课程以 Java 为教学语言，从课程介绍与 ADT 概念出发，依次讲列表、集合、映射、引用与递归，再进入渐近分析，并沿树、堆、图、最短路、最小生成树、散列一路推进，最后落到字典树、各类排序、压缩与软件工程实践。

- **原视频**：https://www.bilibili.com/video/BV1Ly7G6kEhK — Bilibili，BV1Ly7G6kEhK
- **38 集**，已产出 37 册模块全书、37 篇复习笔记、37 份逐字稿

## 怎么学

- **先立 ADT 与复杂度** → 模块 01、09~10 讲课程导引、渐近分析与自由问答，是全课的方法论前提
- **手写链表** → 模块 02~07 从 IntList 到 LinkedList、DoublyList 与循环数组，务必跟着敲一遍代码
- **树与堆** → 模块 14~17 覆盖二叉搜索树、B 树、红黑树与优先队列，理解平衡与堆序的取舍
- **图论主线** → 模块 18~24 讲遍历、Dijkstra、A*、最小生成树与拓扑排序，配合画图推演
- **散列与字典** → 模块 24~25、27 讲散列设计与动态扩容，以及字典树的前缀检索
- **排序与工程** → 模块 26、28~37 覆盖比较排序下界、基数排序、霍夫曼压缩与软件工程实践
- **按讲速查** → `notes/` 目录逐讲整理，便于跟课时同步回顾
