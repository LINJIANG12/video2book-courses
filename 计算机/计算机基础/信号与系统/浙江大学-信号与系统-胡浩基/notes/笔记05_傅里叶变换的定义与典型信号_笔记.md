# 傅里叶变换的定义与典型信号

---

## 复傅里叶变换的定义

### 从复傅里叶级数到复傅里叶变换

* **复傅里叶级数（complex Fourier series）**

    * > **定义**：用一串指数基 $\sum_k a_k e^{jk\omega_0t}$ 表示周期为 $T_0$ 的信号，系数 $a_k$ 由一个周期上的积分确定。

    * 级数式：$x(t)=\sum_{k=-\infty}^{+\infty}a_ke^{jk\omega_0t}$。

    * 系数式：$a_k=\frac{1}{T_0}\int_{\text{一个周期}}x(t)e^{-jk\omega_0t}dt$。

    * 成立前提两条：$x(t)$ 以 $T_0$ 为周期；$\omega_0=2\pi/T_0$。

    * 被"周期"绑死的三处：积分上下限写不出来只能标"一个周期"；$1/T_0$ 明挂在系数前；$T_0$ 藏在指数里经 $\omega_0$ 无法消去。

* **非周期函数的含义**

    * > **定义**：非周期函数就是周期 $T_0$ 等于正无穷大的函数，即任何地方都没有周期。

    * 这一条理解贯穿整个推广过程：$T_0\to+\infty$ 意味着 $\omega_0=2\pi/T_0\to0$。

* **定义 $X(j\omega)$**

    * 把系数公式里的积分单独拎出来：$X(j\omega)\triangleq\int_{\text{一个周期}}x(t)e^{-j\omega t}dt$。

    * 与 $a_k$ 对照：$1/T_0$ 不动、积分变量 $t$ 不动，只有指数里的 $k\omega_0$ 换成自变量 $\omega$，而 $\omega$ 在 $a_k$ 中恰好取成 $k\omega_0$。

    * 结论：$a_k=\frac{1}{T_0}X(jk\omega_0)$。

    * 整张系数表由"一列离散的数 $a_k$"变成"一条连续曲线 $X(j\omega)$，只不过只在 $k\omega_0$ 这几个点上采样它"。

* **放走 $T_0$**

    * 代回级数并用 $\omega_0T_0=2\pi$：$x(t)=\frac{1}{2\pi}\sum_{k=-\infty}^{+\infty}X(jk\omega_0)e^{jk\omega_0t}$。

    * 改动一：积分区间"一个周期"随 $T_0$ 撑开成 $(-\infty,+\infty)$。

    * 改动二：$\omega_0$ 就是 $\omega$ 轴上相邻采样点之间的距离（黎曼和的"间隔"），$\Delta\omega=\omega_0\to0$，求和号变成积分号。

    * 改动三：由 $\Delta\omega=\omega_0$ 与 $\omega_0T_0=2\pi$ 得 $1/T_0=\Delta\omega/2\pi$，系数变成 $1/(2\pi)$。

    * 整条推导链：级数（仅周期）→ 拎出 $X(j\omega)$、$a_k=X(jk\omega_0)/T_0$ → 代回并用 $\omega_0T_0=2\pi$ → $T_0\to+\infty$ 令区间变全轴、$\Delta\omega\to0$、$1/T_0\to1/(2\pi)$ → 复傅里叶变换。

### 傅里叶变换对与记号

* **复傅里叶变换与复傅里叶反变换**

    * > **定义**：$X(j\omega)=\int_{-\infty}^{+\infty}x(t)e^{-j\omega t}dt$ 叫 $x(t)$ 的复傅里叶变换；$x(t)=\frac{1}{2\pi}\int_{-\infty}^{+\infty}X(j\omega)e^{j\omega t}d\omega$ 叫 $X(j\omega)$ 的复傅里叶反变换。

    * 这一对公式要能默写，不是"会用就行"的熟悉。

    * 与复傅里叶级数的关系：级数是给周期信号准备的一串**级数**，变换是给非周期信号准备的**积分式**，二者只是 $T_0$ 有限与 $T_0$ 无穷的两种写法。

* **三种常见记法**

    | 记法 | 正变换 | 反变换 |
    | :--- | :--- | :--- |
    | 最常见 | $X(j\omega)=\displaystyle\int_{-\infty}^{+\infty}x(t)e^{-j\omega t}dt$ | $x(t)=\frac{1}{2\pi}\displaystyle\int_{-\infty}^{+\infty}X(j\omega)e^{j\omega t}d\omega$ |
    | 方括号 | $X[j\omega]$ | $x(t)$ |
    | 算子符号 | $\mathcal{F}\{x(t)\}=X(j\omega)$ | $\mathcal{F}^{-1}\{X(j\omega)\}=x(t)$ |

    * 三套记法意思相同，选哪一套取决于教材与考试要求。

* **时域与频域**

    * > **定义**：$x(t)$ 一侧叫时域（时间域，time domain），自变量是时间 $t$；$X(j\omega)$ 一侧叫频域（频率域，frequency domain），自变量是频率 $\omega$。

    * 每个变换对左边是时域、右边是频域，是两套完全不同的坐标；看表时把自变量搞混，做题就不是算错而是答非所问。

* **$X(j\omega)$ 里的 $j$**

    * $j$ 本身没有任何数学意义：它后面没有挂 $e^{j\omega t}$ 这种因子，也不能读成"复数域"。

    * $X$ 的自变量只有 $\omega$ 一个，$j$ 只是占位符。

    * 写上 $j$ 的唯一作用是与离散傅里叶变换在记号上区分开——那一边才是 $j$ 真正有内容的场合。

    > **易错点**：$X(j\omega)$ 中的 $j$ 纯粹是占位符，$X$ 的自变量是 $\omega$，不是 $j\omega$。

### 两个公式的直接互推

* **不用级数做过渡**

    * 两个公式可以相互推出，完全不需要借复傅里叶级数做中间环节。

    * 唯一的支点是 $\lim_{\omega\to+\infty}\frac{\sin\omega t}{t}=\pi\delta(t)$；推不出来往往不是推不动，而是不知道这条公式。

* **四步证明**

    * 第一步处理符号冲突：$\omega$ 既是积分变量又出现在 $X(j\omega)$ 里，而 $X$ 定义式的自变量 $t$ 又与外层 $t$ 撞车，把定义式里的 $t$ 换成 $u$。

    * 第二步交换积分次序：$x(u)$ 提到前面，指数合并 $e^{j\omega t}e^{-j\omega u}=e^{j\omega(t-u)}$，整个证明压到方括号里的那一个积分上。

    * 第三步算里层积分：用欧拉公式 $e^{j\alpha}-e^{-j\alpha}=2j\sin\alpha$ 化简，得 $\lim_{\omega\to+\infty}\frac{2\sin[\omega(t-u)]}{t-u}$。

    * 第四步套冲激：把 $t$ 换成 $t-u$ 即得 $2\pi\delta(t-u)$，$\frac{1}{2\pi}$ 与 $2\pi$ 正好约掉，最后靠冲激的筛选性质 $\int x(u)\delta(t-u)du=x(t)$ 回到 $x(t)$。

    * 反方向（由反变换求正变换）沿用同一条支点，过程完全对称。

* **常用支点公式**

    * $\lim_{\omega\to+\infty}\frac{\sin\omega t}{t}=\pi\delta(t)$：正反互推以及后面每一次推导都要用。

    * $e^{j\alpha}-e^{-j\alpha}=2j\sin\alpha$ 及其姊妹式 $e^{j\alpha}+e^{-j\alpha}=2\cos\alpha$。

    * $\int_{-\infty}^{+\infty}x(t)\delta(t)dt=x(0)$。

    * $\lim_{T\to\infty}\frac{\sin\omega T}{\pi T}=\delta(\omega)$。

    * $\int_{-\infty}^{+\infty}\frac{\sin a\omega}{\omega}d\omega=\pi$（$a>0$；$a<0$ 时等于 $-\pi$）。

## 典型信号变换对总表

### 八个变换对

| 时域 $x(t)$ | 频域 $X(j\omega)$ |
| :--- | :--- |
| $e^{-at}u(t)$，$a>0$ | $\dfrac{1}{a+j\omega}$ |
| $\delta(t)$ | $1$ |
| $1$ | $2\pi\delta(\omega)$ |
| 矩形窗 $g_\tau(t)$（$\lvert t\rvert\le\tau/2$ 时为 1） | $\tau\,\mathrm{Sa}\!\left(\dfrac{\omega\tau}{2}\right)$ |
| $\dfrac{\sin\omega_ct}{\pi t}$ | 方波：$\lvert\omega\rvert<\omega_c$ 时为 1，其余为 0 |
| $\cos\omega_ct$ | $\pi\left[\delta(\omega-\omega_c)+\delta(\omega+\omega_c)\right]$ |
| $\sin\omega_ct$ | $\dfrac{\pi}{j}\left[\delta(\omega-\omega_c)-\delta(\omega+\omega_c)\right]$ |
| $u(t)$ | $\dfrac{1}{j\omega}+\pi\delta(\omega)$ |

* **$\mathrm{Sa}$ 函数**

    * > **定义**：$\mathrm{Sa}(x)=\dfrac{\sin x}{x}$，取 $x=0$ 处的极限值为 1。

    * $\sin$ 与 $\mathrm{Sa}$ 是两个东西，$\sin 3\omega$ 不等于 $\mathrm{Sa}(3\omega)$。

* **三对配对**

    * $\delta(t)\leftrightarrow1$ 与 $1\leftrightarrow2\pi\delta(\omega)$ 是一对。

    * 矩形窗与 $\dfrac{\sin\omega_ct}{\pi t}$ 是一对，一句话就是"方波与 sa 互为傅里叶变换"。

    * $\cos\omega_ct$ 与 $\sin\omega_ct$ 是一对，两者相加除以 2 就是指数对。

    * 记配对比把八个硬背省一半力气。

* **写法上的三条经验**

    * 一律按书上的写法记，考试要按讲义上那个名字答，答案才对得上。

    * 矩形窗那一对有 $\mathrm{Sa}$ 形式与 $\sin$ 形式两种写法，可互相化简。

    * $\sin\omega_ct$ 那一条里负号在括号内还是在 $\dfrac{\pi}{j}$ 内，常记混，需回看。

    * $\cos$ 与 $\sin$ 两条合并写，讲义上算七个；真拆开数就是八个。

## 单边指数信号

### 推导与成立条件

* **变换对**

    * $e^{-at}u(t)\;\longleftrightarrow\;\dfrac{1}{a+j\omega}$，$a>0$。

    * 它是整张表里唯一一个推导要从头做起的式子，后面七个都建立在它与定义式之上。

* **四步计算**

    * 第一步背定义式，把 $x(t)$ 换成 $e^{-at}u(t)$。

    * 第二步看 $u(t)$：它在乘在哪就把哪里的负半轴压成零，$t<0$ 段全零，积分限压成 $[0,+\infty)$。

    * 第三步指数凑对：$e^{-at}e^{-j\omega t}=e^{-(a+j\omega)t}$。

    * 第四步直接积分：$\left.\frac{e^{-(a+j\omega)t}}{-(a+j\omega)}\right|_{0}^{+\infty}$。

* **$a>0$ 不是装饰**

    * 当且仅当 $a>0$ 时，$-(a+j\omega)$ 的实部为负，$e^{-(a+j\omega)(+\infty)}$ 才收敛到 0，结果为 $\frac{1}{a+j\omega}$。

    * $a<0$ 时实部为正，指数跑到 $+\infty$，该项发散，积分不存在。

    > **易错点**：$a<0$ 时不能靠"发散就当作 0"蒙混过关。$e^{-(a+j\omega)(+\infty)}$ 不是 0，是无穷大，除出来是 0 还是无穷取决于理解方向，这个式子在那里根本不成立。

* **时域形状**

    * $u(t)$ 一乘，负半轴全零，只在 $t=0$ 处起步并取值 1；$t>0$ 因 $a>0$ 一路指数衰减。

    * $a$ 越大衰减越快，画三条 $a$ 取小、中、大的曲线差别一眼可见；这个参数在后续系统分析里是要调的。

    ```text
      x(t)
       1 ┤        ●
         │        │╲
         │        │ ╲
         │        │  ╲___
         │        │      ╲______
       0 ┼────────┴─────────────────────→ t
         │        0
         │        │
         │        └── a 越大，掉得越快
    ```

### 幅度谱与相位谱

* **复数画不出来，要拆模和相**

    * $\dfrac{1}{a+j\omega}$ 带 $j$，是复数，纸面上画不出来；频域里不按实部虚部分别画图，而是拆成模与相。

    ```text
            X(jω) = 1/(a + jω)          ← 是个复数，图上画不出来
                     │
                     ├──────────────►  取模    |X(jω)| = 1/√(a² + ω²)     幅度谱（偶函数）
                     │                      ω=0 处最高为 1/a，|ω|→∞ 趋于 0
                     │
                     └──────────────►  取辐角  ∠X(jω) = −arctan(ω/a)     相位谱（奇函数）
                            ω→+∞ 趋于 −π/2，ω→−∞ 趋于 +π/2
    ```

* **定义与算法**

    * > **定义**：$|X(j\omega)|$ 叫幅度谱（amplitude spectrum），$\angle X(j\omega)$ 叫相位谱（phase spectrum）；幅度谱因本身即频谱，也常直接叫幅度谱。

    * 复数 $z=a+jb$ 的模为 $\sqrt{a^2+b^2}$、辐角为 $\arctan\frac{b}{a}$，套到本题：$|X(j\omega)|=\dfrac{1}{\sqrt{a^2+\omega^2}}$，$\varphi(\omega)=-\arctan\dfrac{\omega}{a}$。

    * 负号的来源：$\dfrac{1}{a+j\omega}$ 与 $\dfrac{a-j\omega}{a^2+\omega^2}$ 只差一个相位取反，$\arctan$ 是奇函数，负号带过来即得。

    * 模的极限用洛必达再走一步：$\lim_{\omega\to\infty}\dfrac{1}{\sqrt{a^2+\omega^2}}=0$。

* **两谱的形状**

    * 幅度谱是偶函数：$\omega=0$ 处最高为 $1/a$，左右对称，往两边随 $|\omega|$ 增大而降低并趋于 0。

    * 相位谱是奇函数：$\omega$ 取负值时 $\arctan$ 给负、外面负号给正，所以左半边为正、右半边为负；$\omega\to+\infty$ 趋于 $-\frac{\pi}{2}$，$\omega\to-\infty$ 趋于 $+\frac{\pi}{2}$。

    * "远处趋于 0"这条今后会反复用到。

### 低通滤波器与截止频率

* **低通滤波器**

    * > **定义**：幅度谱在 $|\omega|$ 小的地方大、$|\omega|$ 大的时候小的形状叫低通滤波器（low-pass filter），即频率低的地方放过去、频率高的地方抑制住。

* **截止频率**

    * > **定义**：幅度衰减到最高幅度一半时对应的频率叫截止频率（cut-off frequency）；高通、带通用的是同一个定义。

    * 取 $\omega=\sqrt{3}a$ 代入 $\dfrac{1}{\sqrt{a^2+\omega^2}}$，分母为 $\sqrt{a^2+3a^2}=2a$，幅度为 $\dfrac{1}{2a}$，恰好是最高值 $1/a$ 的一半；负的 $\sqrt{3}a$ 一侧对称。

    * $a>0$ 的单边指数所对应的低通滤波器，截止频率为 $\omega_c=\sqrt{3}a$。

* **3 dB 的来历**

    * dB 是以 $\log_{10}$ 为单位再乘 10 的量；幅度衰减到原来的 $\frac{1}{2}$ 时 $10\lg\dfrac{1}{2}\approx-3\ \text{dB}$。

    * 所以"衰减 3 dB"与"衰减到一半"是同一件事。

## 冲激与常数

### 冲激的变换

* **$\delta(t)\longleftrightarrow 1$**

    * 代入定义式：$X(j\omega)=\int_{-\infty}^{+\infty}\delta(t)e^{-j\omega t}dt$。

    * 用 $\int_{-\infty}^{+\infty}x(t)\delta(t)dt=x(0)$，这里 $x(t)=e^{-j\omega t}$，得 $X(j\omega)=e^{-j\omega\cdot0}=1$。

    * 结果与 $\omega$ 无关，是个常数：时域一个冲击，频域一个值。

* **冲激的筛选性质**

    * > **定义**：$\int_{-\infty}^{+\infty}x(t)\delta(t)dt=x(0)$。

    * 用的时候必须把自变量整体换掉：积分变量是 $\omega$ 时 $\delta(\omega)$ 对应的是 $x(\omega)$，结果是 $x(\omega=0)$。

### 常数的变换

* **$1\longleftrightarrow2\pi\delta(\omega)$ 的简单做法（从右边推）**

    * 直接代入反变换：$X(j\omega)=\frac{1}{2\pi}\int_{-\infty}^{+\infty}2\pi\delta(\omega)e^{j\omega t}d\omega$。

    * $2\pi$ 与 $1/2\pi$ 约掉，再用筛选性质，此处 $x(\omega)=e^{j\omega t}$，$x(\omega=0)=1$，结果为 $1$。

* **从左边硬推**

    * $X(j\omega)=\int_{-\infty}^{+\infty}e^{-j\omega t}dt$，先做关键化简 $e^{-j\omega t}=\cos\omega t-j\sin\omega t$。

    * $\cos\omega t$ 偶、$\sin\omega t$ 奇，奇函数在关于原点对称的区间上积分为零，所以 $j$ 那一项自己没了，上下限可缩成 $[-n,n]$。

    * 代原函数后用 $e^{-j\omega n}-e^{j\omega n}=-2j\sin\omega n$，得 $\lim_{n\to\infty}\frac{2\sin(n\omega)}{n\omega}$。

    * 再用 $\lim_{T\to\infty}\frac{\sin\omega T}{\pi T}=\delta(\omega)$，把字母一一对调，得 $\lim_{n\to\infty}\frac{\sin(n\omega)}{n}=\pi\delta(\omega)$，于是 $X(j\omega)=2\pi\delta(\omega)$。

    * 左推右与右推左两个方向都成立，两个都得会；两式左推右做的事完全一样。

## 方波与 sa 互为傅里叶变换

### 矩形窗

* **变换对**

    * $g_\tau(t)$ 在 $|t|\le\frac{\tau}{2}$ 范围内取值 1，其余为 0。

    * $g_\tau(t)\;\longleftrightarrow\;\dfrac{2\sin(\omega\tau/2)}{\omega}=\tau\,\mathrm{Sa}\!\left(\frac{\omega\tau}{2}\right)$。

* **左推右的推导**

    * 方波左右全零，积分限直接缩成 $\left[-\frac{\tau}{2},\frac{\tau}{2}\right]$：$X(j\omega)=\int_{-\tau/2}^{\tau/2}1\cdot e^{-j\omega t}dt=\frac{e^{-j\omega\tau/2}-e^{j\omega\tau/2}}{-j\omega}$。

    * 用 $e^{-j\alpha}-e^{j\alpha}=-2j\sin\alpha$ 使 $j$ 相消，得 $\dfrac{2\sin(\omega\tau/2)}{\omega}=\tau\cdot\frac{\sin(\omega\tau/2)}{\omega\tau/2}$。

* **写答案时的提醒**

    * 书上把它简写成"矩形窗 ↔ $\mathrm{Sa}(\omega\tau/2)$"，那个 $\mathrm{Sa}$ 只负责描述**形状**。

    * 自己做题时前面的 $\tau$ 不会自己消失——它就是那个脉冲的**面积**，写答案别把 $\tau$ 吞了。

* **典型例题（五秒钟题）**

    * 高度为 1、左右边界分别在 $t=-3$ 和 $t=3$ 的矩形脉冲：先由 $\frac{\tau}{2}=3$ 定出 $\tau=6$，再代入得 $X(j\omega)=\dfrac{2\sin3\omega}{\omega}=6\,\mathrm{Sa}(3\omega)$。

    * 这题唯一需要动脑的是先定 $\tau$；写出的 $\sin(3\omega)$ **不是** $\mathrm{Sa}(3\omega)$，中间少一个 $\frac{2}{\omega}$。

### 除以 $\pi t$ 的信号

* **变换对**

    * $\dfrac{\sin\omega_ct}{\pi t}\;\longleftrightarrow\;$ 方波，$|\omega|<\omega_c$ 时为 1，其余为 0。

    * 前置结论（第一章）：$\dfrac{\sin\omega t}{\pi t}\;\longleftrightarrow\;$ $\omega>0$ 时 1、$\omega<0$ 时 $-1$；记住 $t$ 在分母、正弦在分子，分母上没有 $\pi$ 时要把这个 $\pi$ 补回去。

* **推导与奇偶性**

    * 把指数拆开 $e^{-j\omega t}=\cos\omega t-j\sin\omega t$ 后只需盯住被积函数的奇偶性。

    ```text
            X(jω) = ∫ [ sin(ωc t)/πt ] · e^(−jωt) dt
                                        │
                                        └─ 拆开：e^(−jωt) = cos ωt − j·sin ωt

       ┌───────────────────────────────┴───────────────────────────────┐
       │                                                               │
       │  sin(ωc t)/πt · cos ωt              sin(ωc t)/πt · j·sin ωt │
       │  sin 是奇函数，t 也是奇函数，          偶函数 再乘 奇函数        │
       │  一除变成偶函数；偶 × 偶 = 偶         = 奇函数                │
       │  偶函数，积分不为零，活着              奇函数，±∞ 上积分为 0，扔 │
       └───────────────────────────────────────────────────────────────┘
    ```

    * 于是只剩第一项，再用积化和差 $\sin\alpha\cos\beta=\frac{1}{2}[\sin(\alpha+\beta)+\sin(\alpha-\beta)]$ 拆成两项，分别调用上面的前置结论。

* **三种情况（前提 $\omega_c>0$）**

    * $\omega<-\omega_c$：$\omega_c+\omega<0$ 取 $-1$，$\omega_c-\omega>0$ 取 1，得 $\frac{1}{2}[(-1)+1]=0$。

    * $-\omega_c<\omega<\omega_c$：两项都取 1，得 $\frac{1}{2}[1+1]=1$。

    * $\omega>\omega_c$：$\omega_c+\omega>0$ 取 1，$\omega_c-\omega<0$ 取 $-1$，得 $\frac{1}{2}[1+(-1)]=0$。

    * 汇总即方波，$\omega=\omega_c$ 那一点也等于 0。

    ```text
            X(jω)
         1   ┤        ┌────────────┐
             │        │            │
             │        │            │
         0   ┼────────┘            └────────→ ω
                  −ωc   0        ωc
    ```

    * 矩形窗的右推左与本条的左推右原理完全一样：都是拆指数、看奇偶。

### sa 系数的确定规则

* **记法约定**

    * 把 $\mathrm{sa}$ 的写法固定成 $a\,\mathrm{sa}(b\omega)$，等价于 $a\cdot\dfrac{\sin(b\omega)}{b\omega}$，后面所有题都按这个记法落笔。

    * 看到左边是方波，先把 $\mathrm{sa}$ 整个框出来，再往里填三个要素。

* **第一要素：变量是谁**

    * 时域自变量是 $t$，频域自变量就是 $\omega$，所以这个 $\mathrm{sa}$ 里必然有一个 $\omega$。

* **第二要素：$\sin$ 括号里的数**

    * $\sin$ 括号内 $\omega$ 的系数就是时域方波的截止点；方波在 $\pm3$ 断开就写 3。

* **第三要素：括号外的数**

    * > **结论**：括号外的系数等于**方波的面积**。

    * 证明链：由定义令 $\omega=0$，$X(j0)=\int_{-\infty}^{+\infty}x(t)dt$，右边正是方波面积；左边若写成 $a\,\mathrm{sa}(\omega)$，则 $X(j0)=a\,\mathrm{sa}(0)=a\times1=a$（用 $\lim_{t\to0}\frac{\sin t}{t}=1$）。

    * 链条到这里就断了——不需要验算，把面积抄上去即可。

    > **易错点**：算 $a$ 时不要把 $\sin$ 前面的系数当成 $a$。$a$ 是面积，不是高度。

* **不转弯的做法**

    * 任何形如 $\dfrac{\sin c\omega}{\omega}$ 的表达式都是 $\mathrm{sa}(c\omega)$，不必先化到显式 $\mathrm{sa}$ 写法；对应的时域方波截止点就是 $\sin$ 括号里的 $c$。

    * > **结论**：$a=\dfrac{\text{频域积分值}}{2\pi}$，即 $x(0)=\frac{1}{2\pi}\int_{-\infty}^{+\infty}X(j\omega)dt$。

    * 用 $\int_{-\infty}^{+\infty}\frac{\sin a\omega}{\omega}d\omega=\pi$（$a>0$）一步得系数：从右边 $\mathrm{sa}$ 的写法出发、从左边 $X(0)$ 出发，两头一夹。

    ```text
            sin(cω)
           ──────────
                ω
                │
                ▼
        它就是一个 sa(cω)
                │
                ├────────► 时域：方波，截止 ±c
                │
                └────────► 系数 a：取 x(0) = (1/2π)∫X(jω)dω
    ```

* **反着出题**

    * 给 $\mathrm{sa}$ 画方波时，宽度由截止点定（$2\tau$），高度由面积除以宽度定（$\frac{\text{面积}}{2\tau}$）。

    > **易错点**：反着出题最容易错在**横纵坐标搞反**，这两步不要混。

### 正着出与反着出

* **正着出：给方波写 sa**

    * 截止 $\pm5$、面积 10 的方波：$10\,\mathrm{sa}(5\omega)=\dfrac{2\sin5\omega}{\omega}$。

    * 从 $-1$ 到 $1$、高度为 2 的方波：面积 $2\times2=4$，截止点 1，得 $4k$，其中 $k\equiv\dfrac{\sin\omega}{\omega}$。

    * 截止 $\pm3$、高度为 2 的方波：面积 12、截止 3，得 $12\,\mathrm{sa}(3\omega)=\dfrac{4\sin3\omega}{\omega}$。

* **反着出与转弯题**

    * $\pi\,\mathrm{sa}(2\omega)$ 的反变换：截止点从 $\sin$ 括号读得 $\pm2$，宽度 4，面积为 $\pi$，高度 $\frac{\pi}{4}$。

    * $15\,\mathrm{sa}(3\omega)$ 的反变换：不转弯的做法是先认出 $5\frac{\sin3\omega}{\omega}$ 也是 $\mathrm{sa}$，截止点直接取 3、宽度 6，系数用 $x(0)=\frac{1}{2\pi}\cdot5\cdot\pi=\frac{5}{2}$，故高度为 $\frac52$。

    * $X(\omega)=\frac{1}{2}\cdot\frac{\sin3\omega}{\omega}$：截止 $\pm3$，面积 $=\frac{\frac12\pi}{2\pi}=\frac14$，高度 $=\frac14\div6=\frac1{24}$。

    * $X(\omega)=\frac{1}{2}\cdot\frac{\sin\omega}{\omega}$：截止 $\pm1$，面积 $=\frac{\frac12\pi}{2\pi}=\frac14$。

* **$\sin(nt)/t$ 这一族**

    * $\dfrac{\sin3t}{t}$：写成 $3\cdot\frac{\sin3t}{3t}$，换元 $u=3t$ 后回到最基本的一对 $\dfrac{\sin u}{u}\leftrightarrow\pi[\cdot]_{\lvert\omega\rvert<1}$，答案是一块高度为 $\pi$ 的平台，支撑在 $|\omega|<3$ 上。

    * 不要死记 $\sin3t/t$ 这一条，而要记住生成它的积分：$\int_{-\infty}^{+\infty}\frac{\sin3t}{t}dt=\pi$，$\int_{-\infty}^{+\infty}\frac{\sin5t}{t}dt=\pi$。

    * 谁被 3 除、被 5 除、被 2 除，$\pi$ 就跟着缩一次，宽度跟着变一次；$\pi$ 从分母跑到常数上去了。

    * $\dfrac{\sin5t}{3t}$ 的变换是 $|\omega|<5$ 上取 $\frac{\pi}{3}$；常见错误是范围对了但把 $\pi$ 漏掉写成 $\frac13$。

    * 反向也一样：给定一块 $\pi$ 高的平台，反变换写成 $\frac{\sin3t}{t}$，平台常数对应 $\sin$ 括号里的那个数。

* **半分钟四题（过关线）**

    | 题目 | 答案的关键参数 |
    | :--- | :--- |
    | $\mathrm{sa}(2\omega)$ 配面积 12 | 截止 $\pm2$、宽度 4、高度 3 |
    | $\sin5t$ 除以 $3t$ 那一族 | 平台高 $\frac16$，支撑在 $\lvert\omega\rvert<5$ |
    | 第五对那一族 | 面积 $\frac{\pi}{2}$、截止 $\pm5$、宽度 10、高度 $\frac{\pi}{20}$ |
    | $2k$ | 截止 $\pm1$、宽度 2、高度 1 |

    * 第二题的落笔顺序：认出 $\frac{\sin5t}{t}$ 那一族的 $\pi$ 台阶是 $\pi$，被 3 除成 $\frac{\pi}{3}$，再被 $2\pi$ 除得 $\frac16$，落在 $|\omega|<5$ 内。

    * 第三题先当 $\mathrm{sa}$ 认出，方波截止 $\pm5$、宽度 10、面积 $\frac{\pi}{2}$，高度 $\frac{\pi}{20}$；最后一题 $2k$ 就是 $2\,\mathrm{sa}(\omega)$。

    * > **结论**：公式四和公式五不是生硬地背记公式，而是做这些题；储备公式要**用做题的方式储备**，正着写反着写都要练到五秒钟之内落笔。

## 单位阶跃信号的傅里叶变换

### 变换对与右推左

* **变换对**

    * $\mathcal{F}\{\varepsilon(t)\}=\dfrac{1}{j\omega}+\pi\,\mathrm{PV}\{\delta(\omega)\}$。

    * $\varepsilon(t)$ 就是常写的 $u(t)$：$t>0$ 时为 1、$t<0$ 时为 0。

    * 它与前面所有信号不同的地方在于**在整个实轴上不衰减**，因此频域里同时出现一个 $1/\omega$ 和一个 $\delta$，两项都要留意。

* **右推左（频域拼回时域）**

    * 按反变换定义 $\varepsilon(t)=\frac{1}{2\pi}\left[\frac{1}{j\omega}+\pi\,\mathrm{PV}\{\delta(\omega)\}\right]e^{j\omega t}d\omega$，拆成两项分别算。

    * 第二项 $\pi\,\mathrm{PV}\{\delta(\omega)\}$ 较易：$\frac{1}{2\pi}\cdot\pi\cdot\delta(\omega)e^{j\omega t}\big|_{\omega=0}=\frac{1}{2\pi}\cdot\pi\cdot1=\frac12$。

    * 第一项展开 $\frac{1}{2\pi}\int\frac{e^{j\omega t}}{j\omega}d\omega=\frac{1}{2\pi}\int\frac{\cos\omega t}{j\omega}d\omega+\frac{1}{2\pi}\int\frac{\sin\omega t}{\omega}d\omega$，$j$ 跟 $j$ 约掉。

    * 剩下的 $\frac{1}{2\pi}\int\frac{\sin\omega t}{\omega}d\omega=\frac{1}{2\pi}\cdot\pi\cdot\mathrm{sgn}(t)$，即 $t>0$ 时 $\frac12$、$t<0$ 时 $-\frac12$；这里要用第一章那条公式，把 $\omega$ 与 $t$ 整体互换，$a>0$ 的条件换成 $t>0$。

    * 两半拼起来：$\varepsilon(t)=\frac12\,\mathrm{sgn}(t)+\frac12$，$t>0$ 时 1、$t<0$ 时 0。

    ```text
       X(jω) = 1/(jω)  +  π·PV{δ(ω)}
          │
          ├── 1/(jω) 这一项
          │     (1/2π)∫ e^{jωt}/(jω) dω
          │        = (1/2π)·[ ∫cos(ωt)/(jω)dω  +  ∫sin(ωt)/ω dω ]
          │                       奇函数, 积分为 0        = π/2   (t>0)
          │                                             = -π/2  (t<0)
          │
          └── π·PV{δ(ω)} 这一项
                (1/2π)·π·δ(ω)·e^{jωt}|_{ω=0} = (1/2π)·π·1 = 1/2
    ```

### 左推右与那一项为什么等于零

* **硬推过程**

    * $X(j\omega)=\int_{-\infty}^{+\infty}\varepsilon(t)e^{-j\omega t}dt$，$t<0$ 段为 0，积分限换成从 0 开始。

    * $\int_{0}^{+\infty}e^{-j\omega t}dt$ 不收敛，乘除一个 $e^{-j\omega t}$（它的原函数就是它自己）把它变成能算的样子。

    * 展开 $e^{-j\omega n}=\cos(n\omega)-j\sin(n\omega)$ 后得三项：第一项 $\frac{1}{j\omega}$ 直接成立；第三项 $\lim_{n\to\infty}\frac{\sin n\omega}{\omega}=\pi\delta(\omega)$（讲 $\delta(t)$ 时学过，把 $t$ 换成 $\omega$ 把 $\pi$ 拿过来）；第二项按道理应等于零。

    ```text
           u(t)  ──►  ∫₀^∞ e^{-jωt} dt
                         │
                         │  乘除 e^{-jωt}，它的原函数就是它自己
                         ▼
              (1/jω)·[ 1 - lim_{n→∞} e^{-jωn} ]
                         │
                         │  e^{-jωn} = cos(nω) - j·sin(nω)
                         ▼
              X(jω) = 1/(jω) - (1/jω)·lim_{n→∞}cos(nω) + lim_{n→∞}sin(nω)/ω

              第一项 ──────────────── 直接成立
              第二项 ──────────────── 广义意义 = 0（要用狄利赫雷三条件证）
              第三项 ──────────────── = π·δ(ω)（讲 δ(t) 时学过）
    ```

    > **易错点**：右推左时那项 $\frac{\cos\omega t}{j\omega}$ 的陷阱是随时关注被积函数的奇偶性。$\cos\omega t$ 是 $\omega$ 的偶函数、$1/\omega$ 是奇函数，**偶函数除以奇函数仍是奇函数**，奇函数在 $(-\infty,+\infty)$ 上积分为零，这一项直接没了。

* **第二项为零的证明**

    * "等于零"不是指每一点都等于零，而是**广义地等于零**：任取 $f(\omega)$，若 $\lim_{n\to\infty}\int\frac{\cos(n\omega)}{\omega}f(\omega)d\omega=0$，即可把该函数记成零。

    * 工具是狄利赫雷三条件：若 $x(\omega)$ 满足该条件，则 $\lim_{n\to\infty}\int x(\omega)\cos(n\omega)d\omega=0$；变化不剧烈的函数做强烈振荡积分为零。

    * 但这里不能直接用，因为分母为零时临时不满足三条件——$\omega=0$ 是个奇点；用"减一项再加一项"的技巧处理。

    ```text
            f(ω)/ω   撑不住奇点 ω=0, 不能直接套狄利赫雷三条件
               │
               │  减一项再加一项
               ▼
       f(ω)/ω = [ f(ω) - f(0) ]/ω   +   f(0)/ω
                      │                    │
                      │                    └── 奇函数 × cos(nω) 仍是奇函数
                      │                        全轴积分 = 0
                      │
                      └── 在 ω=0 处连续，处处满足狄利赫雷三条件
                          lim_{n→∞}∫[f(ω)-f(0)]/ω · cos(nω)dω = 0
    ```

    * 第二块 $f(0)/\omega$ 在 0 之外是奇函数，乘上偶函数 $\cos(n\omega)$ 仍是奇函数，全轴积分为零。

    * 第一块 $\frac{f(\omega)-f(0)}{\omega}$ 在 $\omega=0$ 处连续（取值就是 $f'(0)$），处处满足狄利赫雷三条件，直接用定理归零。

    * 两块加起来都为零，于是

        $$X(j\omega)=\frac{1}{j\omega}+\pi\,\mathrm{PV}\{\delta(\omega)\}$$

    * 许多书上对 $u(t)$ 的傅里叶变换是直接给公式、正反都不推；按已学知识其实不难，其中反着推尤其不难。

## 二维信号的傅里叶变换

### 定义与反变换

* **二维傅里叶变换**

    * > **定义**：对二维灰度图像 $f(x,y)$（$x,y$ 是位置坐标、$f(x,y)$ 是该点的灰度值），$F(u,v)=\displaystyle\int_{-\infty}^{\infty}\int_{-\infty}^{\infty}f(x,y)e^{-j(ux+vy)}dx\,dy$。

    * 与一维"非常像，只是每个地方都多长出一截"：一维是 1 个自变量 $t$ 配 1 个频率 $\omega$，二维是 2 个自变量 $x,y$ 配 2 个频率 $u,v$，$x$ 配 $u$、$y$ 配 $v$，$u,v$ 与一维的 $\omega$ 完全同源。

    * 核心在指数里：一维 $e^{-j\omega t}$，两个自变量就把频率劈成两个分量。

* **二维傅里叶反变换**

    * $f(x,y)=\dfrac{1}{(2\pi)^2}\displaystyle\int_{-\infty}^{\infty}\int_{-\infty}^{\infty}F(u,v)e^{j(ux+vy)}du\,dv$，照样是把符号换回来，前面补上归一化系数 $(2\pi)^{-2}$。

    * > **易错点**：归一化系数是 $(2\pi)^{-2}$ 而不是 $(2\pi)^{-1}$——做两次一维逆变换就得除两次 $2\pi$，这个数记错，后面所有二维滤波的推导会全盘歪掉。

* **谱的含义**

    * 幅度谱与相位谱跟一维完全一样：幅度谱是实部平方加虚部平方再开根号，相位谱是虚部除以实部再取 $\arctan$。

    * 证明反变换公式的关键是不把一维那套硬搬过来硬算，而是充分利用已掌握的一维结果，拆成两次一维逆变换去做。

    * 拆法：把 $F(u,v)$ 代进去交换积分次序，先固定 $u$ 与一个待定的 $v_0$，对固定的 $y'$ 把方括号按 $u$ 分组，其中关于 $x'$ 那一层正是某个一维函数的傅里叶变换，调用一维反变换（$\omega\leftrightarrow u$、$t\leftrightarrow x$）得 $G(u;x)=2\pi\int_{-\infty}^{\infty}f(x,y')e^{-jv_0y'}dy'$；外层括号再是一次一维反变换，剩下的只是原式的恒等变形。

* **判对错的两招**

    * 两边作用完再正变换一次必须回到 $F(u,v)$。

    * 看归一化系数——两次一维反变换，$2\pi$ 就要除两次。

### 图像与幅度谱的对应规律

* **时域等距重复，频域就是等距亮点**

    * 幅度谱横轴上每隔一个固定区间出现一个亮点，对应时域图像在横坐标上每隔一小段重复一次。

    * 时域的周期性在频域里变成离散性；时域重复得越整齐，频域里的亮点越集中、越干净。

    ```text
        时域 x 方向：   [一小段图案][同样一小段][同样一小段][同样一小段] ...
                            等距重复
                                ↓  二维傅里叶变换
        频域 u 方向：   ·    ●    ·    ●    ·    ●    ·    ●    ·    ...
                              等距出现的亮点
    ```

* **建筑物的窗户与树林里的竖线**

    * 建筑图像的窗户横着有间隔、竖着也有间隔地重复，对应幅度谱上横、竖两个方向都出现有规律的重复，整个谱规整好看。

    * 杂乱无章的树林图像，时域越杂乱意味着能量在频域铺得越开，谱更糊、更弥散。

    * 树林那张横轴亮度比竖轴低，是因为画面里树干都是竖着的，竖直方向上的规律性内容明显更多，竖轴那侧亮度就更大。

    * > **结论**：别指望对所有图像都能做出精确的一一对应；但对具体的某一张，可以从幅度谱上的结构反过来分析时域里到底有什么。

* **最亮的点永远是原点**

    * 不管哪幅图，幅度谱上最亮的点永远是 $(u,v)=(0,0)$。

    * 这跟一维是同一回事：一维里 $\omega=0$ 那一段通常最值钱（直流分量全堆在那儿），二维对应原点；它位于频谱图正中间，顺带把谱分成上下左右四个象限。

    * 从图像写出幅度谱与相位谱的程序要等学到离散傅里叶变换那一章；现在先把"看谱反推时域"的手感建立起来。

## 四个不常用信号

### 四个变换对

* **双边指数信号**

    * $x(t)=e^{-a\lvert t\rvert}$，$t=0$ 处最高等于 1，两边以 $e^{-a\lvert t\rvert}$ 对称衰减。

    * $X(j\omega)=\dfrac{2a}{a^2+\omega^2}$。

* **高斯脉冲信号**

    * $x(t)=Ee^{-(t/\tau)^2}$，以原点为中心、高度为 $E$ 的钟形脉冲。

    * $X(j\omega)=\sqrt{\pi}E\tau e^{-\left(\frac{\omega\tau}{2}\right)^2}$。

    * > **结论**：高斯脉冲的傅里叶变换**还是高斯**，是少数几个"变换完形状不变"的信号，后面讲滤波、讲时频分析还会反复用到。

* **半波余弦信号**

    * $x(t)=\begin{cases}E\cos\left(\frac{\pi t}{\tau}\right),&|t|<\frac{\tau}{2}\\0,&|t|>\frac{\tau}{2}\end{cases}$：在 $-\frac{\tau}{2}$ 到 $\frac{\tau}{2}$ 之间取一个完整余弦波、峰值 $E$，之外一刀切掉。

    * $X(j\omega)=\dfrac{2E\tau}{\pi}\dfrac{\cos\left(\frac{\omega\tau}{2}\right)}{1-\left(\frac{\omega\tau}{\pi}\right)^2}$。

* **奇对称斜线**

    * $x(t)=\dfrac{E}{T}t$，$-T<t<T$，其他时间为 0；就是从 $-T$ 到 $T$ 一条笔直斜线，左端 $-E$、右端 $E$。

    * $X(j\omega)=j\dfrac{E}{T}\left[\dfrac{2T\cos(\omega T)}{\omega}-\dfrac{2\sin(\omega T)}{\omega^2}\right]$。

    * 推法只有一步：$\frac{d}{d\omega}e^{-j\omega t}=-jt\,e^{-j\omega t}$，所以 $t\cdot e^{-j\omega t}$ 的变换等于对应变换对 $\omega$ 求导的 $-\frac{1}{j}$ 倍，于是 $X(j\omega)=\frac{jE}{T}\frac{d}{d\omega}\left[\frac{2\sin(\omega T)}{\omega}\right]$，括号内等于 $\int_{-T}^{T}e^{-j\omega t}dt$，求导展开即得。

    * 自查：括号内是 $O(\omega^3)$，故 $X(j\omega)\approx-j\frac{2}{3}ET^2\omega$，纯虚、从原点过，符合奇对称信号的直觉。

### 共轭对称性自查

* **性质对照**

    * > **结论**：实偶 $\rightarrow$ 实偶，实奇 $\rightarrow$ 虚奇；记公式不如记性质，性质记牢了，公式忘了也能反推回去。

    * 双边指数、高斯脉冲、半波余弦都是实偶函数，变换后还是关于 $\omega$ 的实偶函数。

    * 斜线信号是实奇函数，对应虚奇，所以 $X(j\omega)$ 里带一个 $j$；式子里 $\sin$、$\cos$ 都是奇函数，两者相乘抵消成偶，再被 $\frac{1}{\omega^2}$ 一除变回奇，整体确实是纯虚的奇函数，与性质完全一致。

* **掌握标准**

    * 讲这四个的理由是让知识体系完备，以及让人知道"这个我能自己推出来"——公式可以不死记。

    * 期末考试里这四对十几年没有考过，第一个偶尔还会考到一点点，另外三个很多年没出现过；但一些学校的考研、研究生试题里仍见过。

    * 建议标准是"大致知道有这件事就行，真考到了在考场上自己也能推出来"，达到这个程度就够了。
