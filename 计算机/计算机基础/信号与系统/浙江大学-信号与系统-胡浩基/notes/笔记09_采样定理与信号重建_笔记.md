# 采样定理与信号重建

## 采样与离散化

* **采样（sampling）**

    * > **定义**：以一个采样周期 $T$ 定周期地取值，把连续信号 $x(t)$ 变成离散序列 $x[n]$，两者关系为 $x[n] = x(nT)$，$n \in \mathbb{Z}$。

    * 采样点在 $0$、$T$、$2T$、$3T$、$4T$、$5T$ 处，往回看 $-T$、$-2T$、$-3T$ 处同样各踩一个点。

    * 离散信号一律用方括号记号，连续信号用圆括号记号，采样前后只差这一对方括号。

    * 采样必然丢信息：两个相邻采样点之间那一段的取值不进入序列，必须对这种损失有充分估计。

* **采样频率（sampling frequency, $\omega_s$）与采样周期**

    * $\omega_s = \dfrac{2\pi}{T}$，$T$ 为采样周期；用频率制 $f$ 记时，$\omega_s = 2\pi f$。

    * $\omega_s$ 大意味着 $T$ 小，采样踩得越密，从 $x[n]$ 里能得到的信息越多，所以 $\omega_s$ 越大越好。

    * 一旦 $\omega_s > 2\omega_m$，所有信息都可以恢复；低于这个门槛就出现混叠。

* **两拍之间脑补出的曲线不唯一**

    * 观察到的采样点若能同时被一条弯弯绕绕的曲线和一条平缓的曲线穿过，这两条曲线傅里叶变换差别极大。

    * 弯弯绕绕那条变化剧烈，频率分量铺得开，$\omega_m$ 较大；平缓那条频率集中在零附近，$\omega_m$ 较小。

    * 出现"看起来还有别的答案"的情形，不是定理有错，而是那个 $\omega_m$ 大的候选根本不满足 $\omega_s > 2\omega_m$。

## 带限信号与采样定理

* **带限信号（band-limited signal）**

    * > **定义**：$X(j\omega)$ 在 $|\omega| > \omega_m$ 处恒等于零的信号；$\omega_m$ 称为带限信号的截止频率。

    * 频谱形状是一段硬邦邦的平台，宽度恰为 $2\omega_m$，平台之外严格为零，而不是"大约有这么宽"。

    * 作图时把峰值高度先定为基准值（取 $1$ 或取 $e$ 皆可），后面所有幅度变化都以此为参照逐级盯住。

* **采样定理（sampling theorem）**

    * > **定义**：若 $x(t)$ 带限、$X(j\omega)$ 在 $|\omega| > \omega_m$ 处为零，且采样频率满足 $\omega_s = \dfrac{2\pi}{T} > 2\omega_m$，则 $x(t)$ 可由采样序列 $x[n] = x(nT)$ 唯一恢复。

    * 两个条件缺一不可：带限是前提，$\omega_s > 2\omega_m$ 是充分必要条件。

    * 恢复公式不是凭空给的，它是把 $X_p(j\omega)$ 乘一只低通滤波器再反变换的直接结果。

* **三个公式与三张图**

    * 这套内容是采样一章的全部底子，其余结论都是往这三张图上套。

    * 三张图分别是：带限信号及其频谱、冲激串采样及其频谱、离散采样值及其变换。

    * 三个公式分别是 $X(j\omega)$、$X_p(j\omega)$、$X(e^{j\Omega})$，三者的纵向高度全部是 $e$、$\dfrac{e}{T_s}$、$\dfrac{e}{T_s}$ 这条链。

    * 横向坐标的分量同步换算：带限项 $\omega_m \to \omega_m T_s$，重复周期 $\omega_s \to \omega_s T_s = 2\pi$。

    * 从测试基本功的角度，要求完全不看书记忆，凭记忆把这三张图的下标与幅度全部画对。

## 记号约定

* **连续时间与离散时间的傅里叶变换**

    * 连续时间信号一律写成 $X(j\omega)$、$X_p(j\omega)$、$X_0(j\omega)$、$X_1(j\omega)$。

    * 离散时间信号写成 $X(e^{j\Omega})$，横轴 $\Omega$ 属于离散角频率，以 $2\pi$ 为周期。

    * > **易错点**：同一条曲线在连续域叫 $X(j\omega)$、在离散域叫 $X(e^{j\Omega})$，不是两个东西，只是按离散时间的规矩换了记号。三者的数学意义也各不相同，上面两个是连续时间傅里叶变换，下面那个是离散时间傅里叶变换。

* **两个 $F$ 与第三个 $F$**

    * $X(j\omega)$ 与 $X_p(j\omega)$ 属于连续时间信号的傅里叶变换，是复指数形式的傅里叶变换。

    * $X(e^{j\Omega})$ 属于离散时间信号的傅里叶变换，定义式为 $X(e^{j\Omega}) = \sum_{n=-\infty}^{\infty} x[n]\,e^{-j\Omega n}$。

## 冲激串采样

* **冲激串采样 $x_p(t)$**

    * > **定义**：每隔 $T_s$ 在 $x(t)$ 该时刻的取值高度上踩一个冲激，$x_p(t) = \sum_{n=-\infty}^{\infty} x(nT_s)\,\delta(t - nT_s)$。

    * 每个冲激的高度就是 $x(t)$ 在 $nT_s$ 时刻的值，原样搬过去，不做任何缩放。

    * 形状记牢：以 $T$ 为周期，每隔 $T$ 一个冲激，越过原点向两侧同样排列。

    * 公式与图形一一对应：求和号里每一个求和项，对应图上一个冲激。

* **$x_p(t)$ 与 $x(t)$ 的乘积关系**

    * 令 $p(t) = \sum_{n=-\infty}^{\infty}\delta(t - nT_s)$ 是周期冲激串，则 $x_p(t) = x(t)\,p(t)$。

    * 这一步的依据是抽样性质 $x(t)\delta(t - t_0) = x(t_0)\delta(t - t_0)$，取 $t_0 = nT_s$。

    * $p(t)$ 是周期函数，所有冲激一样高；先算傅里叶级数，在一个周期 $[-\frac{T_s}{2},\frac{T_s}{2}]$ 上积分得 $a_k = \dfrac{1}{T_s}$ 对一切 $k$ 成立。

    * 于是 $p(t) = \dfrac{1}{T_s}\sum_{k=-\infty}^{\infty}e^{jk\omega_0 t}$，其中 $\omega_0 = \dfrac{2\pi}{T_s} = \omega_s$。

    * 其频谱为 $P(j\omega) = \dfrac{1}{T_s}\sum_{k=-\infty}^{\infty}2\pi\,\delta(\omega - k\omega_s)$。

## 冲激串采样的频谱

* **核心公式**

    $$X_p(j\omega) = \frac{1}{T_s}\sum_{k=-\infty}^{\infty}X\Big(j\big(\omega - k\omega_s\big)\big),\qquad \omega_s = \frac{2\pi}{T_s}$$

* **公式的两个读法**

    * 原频谱 $X(j\omega)$ 以 $\omega_s$ 为周期不断重复：零点处一份，$\omega_s$ 处一份，$2\omega_s$ 处一份，左侧 $-\omega_s$、$-2\omega_s$ 同理。

    * 公式前面挂着一个 $\dfrac{1}{T_s}$，所以每一份的峰值都由原峰值除以 $T_s$ 得到。

    * 每一份的宽度仍是原谱宽度 $2\omega_m$，只是搬了家；副本中心落在 $k\omega_s$ 上。

* **推导链**

    * 时域相乘对应频域卷积除以 $2\pi$：$X_p(j\omega) = \dfrac{1}{2\pi}X(j\omega) * P(j\omega)$。

    * 把 $P(j\omega)$ 代回后 $2\pi$ 与 $2\pi$ 约掉，剩下与 $\delta$ 卷积，用 $x(t)*\delta(t-t_0) = x(t-t_0)$ 收尾。

    * > **易错点**：写平移结果时要看清 $\delta$ 的中心在 $k\omega_s$，频率变量要写成 $\omega - k\omega_s$，是减号。顺手写完回看一眼，这一步最容易写成加号。

* **离散采样值 $x[n] = x(nT_s)$**

    * 与 $x_p(t)$ 的区别在于这里是实实在在的采样点，不再是冲激；$x[n]$ 是把 $x(t)$ 各时刻的取值"搬"过来。

    * 两条路算出的式子形式完全一致：一条是离散傅里叶变换的定义式代入 $x[n] = x(nT_s)$，另一条是用傅里叶变换定义算 $X_p(j\omega)$。

    * 两式对比后令 $\omega T_s = \Omega$，即 $\omega = \dfrac{\Omega}{T_s}$，得到

    $$X(e^{j\Omega}) = X_p\!\left(j\frac{\Omega}{T_s}\right) = \frac{1}{T_s}\sum_{k=-\infty}^{\infty}X\!\left(j\frac{\Omega - 2k\pi}{T_s}\right)$$

    * 横坐标换算是把每处下标乘 $T_s$：$\omega_m \to \omega_m T_s$，$\omega_s \to \omega_s T_s = 2\pi$，所以重复周期变成 $2\pi$ 而不是 $\omega_s$。

    * > **结论**：$x_p(t)$ 与 $X_p(j\omega)$ 是连接连续与离散的桥梁，只有经由这个桥梁，连续时间频谱才能搬到离散时间频谱上。

## 混叠通式

* **混叠（aliasing）通式**

    * > **定义**：所有与观测结果无法区分的真实角速度，恰好是观测到的那个值加上整数倍的采样角频率，$\omega_m = \omega_0 + k\,\omega_s$，$k \in \mathbb{Z}$。

    * 推导入口是"每拍只能辨认出模 $2\pi$ 的余数"：实际走过的角度 $\omega_m T$ 与观测角度加上 $2k\pi$ 在拍频上完全一样。

    * 由 $\omega_m T = \omega_0 T + 2k\pi$ 除以 $T$ 即得 $\omega_m = \dfrac{\omega_0}{T} + \dfrac{2k\pi}{T} = \omega_0 + k\omega_s$。

    * 对余弦 $\cos(\omega_m t)$ 同样成立，因为 $\cos$ 加 $2k\pi$ 后函数值不变，且 $\cos$ 是偶函数，负频率会自动折回成正频率答案。

    * 推导中把 $\cos$ 换成 $\sin$ 全程不变，两者都以 $2\pi$ 为周期。

    * **采样定理的本质**就在这条通式上：信号能分解成各频率正弦余弦分量之和，于是 $\omega_m$ 与 $\omega_0$ 永远分不开，只剩一族候选。

## 手电筒例与车轮例

* **手电筒观测指针**

    * 设定：时钟在黑暗中，手电筒每隔 $T = 1$ 秒照一次，每次看到指针顺时针走 $\dfrac{\pi}{6}$（30 度）。

    * 于是 $\omega_s = \dfrac{2\pi}{T} = 2\pi$，表观转速 $\omega_0 = \dfrac{\pi}{6}$。

    * 约定弧度为正表示顺时针转、为负表示逆时针转；$\dfrac{\pi}{6} - 2\pi = -\dfrac{11}{6}\pi$ 对应逆时针 330 度，看上去仍是顺时针 30 度。

    * 所有无法区分的真实转速：

    | 实际的 $\omega_m$ | 一拍内实际转过的角度 | 看上去的样子 |
    | :--- | :--- | :--- |
    | $\dfrac{\pi}{6}$ | $\dfrac{\pi}{6}$（30°） | 顺时针 30° |
    | $\dfrac{13}{6}\pi$ | $2\pi + \dfrac{\pi}{6}$ | 顺时针 30° |
    | $\dfrac{25}{6}\pi$ | $4\pi + \dfrac{\pi}{6}$ | 顺时针 30° |
    | $-\dfrac{11}{6}\pi$ | $-2\pi + \dfrac{\pi}{6}$，即逆时针 330° | 顺时针 30° |
    | $-\dfrac{23}{6}\pi$ | 逆时针一整圈，再逆时针 330° | 顺时针 30° |

    * 通式在 $T = 1$ 的具体情形下写成 $\omega_m = \dfrac{\pi}{6} + 2k\pi$。

* **正转与反转的分界线**

    * 看上去顺时针 30 度是正着转，看上去逆时针 330 度等价于顺时针 30 度，分界线因此正好落在 $\pm 180°$ 上，即半个混叠周期。

    * 落在 $\omega_0 + k\omega_s$ 上的每一个点，单看都只呈现为"顺时针走了 30 度"。

    * > **结论**：人的感官（听、看、触、闻）是天然的低通滤波器，总是倾向于寻找最简单、变化最小的解释，因此很难第一眼想到多转整圈的答案。

* **电影胶片与三辐条车轮**

    * 胶片每秒 $f = 50$ 帧，$\omega_s = 2\pi f = 100\pi$；单根辐条每隔 $2\pi$ 重合，三根辐条每隔 $\dfrac{2\pi}{3}$ 就重合一次。

    * 因此通式要改写成 $\omega_m = \omega_0 + \dfrac{2k\pi}{3T} = \omega_0 + \dfrac{k}{3}\omega_s$。

    * 相邻两个解相差 $\dfrac{2\pi}{3T} = \dfrac{100\pi}{3}$ 弧度/秒，也就是 $\dfrac{50}{3}$ 转/秒。

    * 转速 $n$（转/秒）与看起来的方向：

    | 转速区间 | 看起来 |
    | :--- | :--- |
    | $0 < n < \dfrac{25}{3}$（$0 \sim 500$ rpm） | 正着转 |
    | $\dfrac{25}{3} < n < \dfrac{50}{3}$（$500 \sim 1000$ rpm） | 反着转 |
    | $\dfrac{50}{3} < n < 25$（$1000 \sim 1500$ rpm） | 正着转 |
    | $25 < n < \dfrac{100}{3}$（$1500 \sim 2000$ rpm） | 反着转 |
    | $\cdots$ | 每 $1000$ rpm 重复一次 |

    * > **易错点**：片子里"轮子倒转"的镜头绝大多数不是特效，而是老老实实拍出来的——那是顺时针转得太快，快到看起来像逆时针。

    * 螺旋桨启动时"先正、再反、又正"，是因为 $\omega_m$ 一路往上扫，依次穿过正转区、反转区、再正转区；人眼的等效采样频率大约在 100 帧每秒量级。

* **余弦采样例**

    * 设 $x(t) = \cos(\omega_m t)$，以 $T = 0.2$ 秒采样，表观值 $\omega_0 = 4\pi$（相当于 0.5 秒一个周期）。

    * 此时 $\dfrac{2\pi}{T} = 10\pi$，故 $\omega_m = 4\pi + 10k\pi$，$k \in \mathbb{Z}$。

    | $k$ | $\omega_m = 4\pi + 10k\pi$ | 等价的余弦 |
    | :--- | :--- | :--- |
    | $-2$ | $-16\pi$ | $\cos(16\pi t)$ |
    | $-1$ | $-6\pi$ | $\cos(6\pi t)$ |
    | $0$ | $4\pi$ | $\cos(4\pi t)$ |
    | $1$ | $14\pi$ | $\cos(14\pi t)$ |
    | $2$ | $24\pi$ | $\cos(24\pi t)$ |
    | $3$ | $34\pi$ | $\cos(34\pi t)$ |

    * 采样点管不住余弦的变化时，相邻两点之间会多转一个周期，再往下又多一个周期——与手电筒例"多转一圈"是同一件事。

## 条件来源与奈奎斯特采样频率

* **为什么必须是 $\omega_s > 2\omega_m$**

    * 核心是 $X_p(j\omega)$ 把 $X(j\omega)$ 以 $\omega_s$ 为周期铺开：原谱中心在零、占据 $[-\omega_m, \omega_m]$，向右重复一份后中心移到 $\omega_s$，左边缘落在 $\omega_s - \omega_m$。

    * 判据是右一份的左边缘必须比左一份的右边缘更靠右，即 $\omega_s - \omega_m > \omega_m$，整理后就是 $\omega_s > 2\omega_m$。

    * 满足时两份谱彼此分开，没有任何频率点同时含两份信息，可以从 $X_p(j\omega)$ 把原谱剥出来。

    * 不满足时两块形状叠在一起，边界混成锯齿；每个混叠点上只能知道两块之和，无法分解成两个不同取值。

    * > **定义**：这种频谱副本相互叠加的现象称为频率混叠，也叫频域混叠（aliasing）。

* **奈奎斯特采样频率**

    * > **定义**：带限信号截止频率的两倍 $2\omega_m$ 称为奈奎斯特采样率（奈奎斯特采样频率），记作 $\omega_N$。

    * 它决定该信号能够被唯一恢复所需的最低采样频率：低于它混叠且无解，高于它才谈得上恢复。

* **奈奎斯特采样频率的求法**

    * 套路只有一条：时域相乘对应频域卷积，然后找卷积结果的最高点。

    * 对 $x(t) = 2 + \cos(1000\pi t) + \sin(3000\pi t)$：常数项给出 $\omega = 0$ 处冲激，余弦在 $\pm 1000\pi$ 各一个冲激，正弦在 $\pm 3000\pi$ 各一个冲激（系数带 $j$，两者符号相反）。取最高点得 $\omega_m = 3000\pi$，故 $\omega_N = 6000\pi$。

    * 对 $x(t) = \sin(\omega_c t)\cdot[\text{宽度为 }T_s\text{ 的方波脉冲}]$：方波频谱是以原点为中心、截止在 $\omega_c$ 的矩形，$\sin(\omega_c t)$ 的频谱是 $\pm\omega_c$ 处的冲激，两者卷积得三角形，从 $-2\omega_c$ 铺到 $2\omega_c$，在 $\pm\omega_c$ 处两个矩形错开一半拼成阶梯，在 $0$ 与 $\pm 2\omega_c$ 处最高。于是 $\omega_m = 2\omega_c$，$\omega_N = 4\omega_c$。

* **等号为什么不能取**

    * 取 $x(t) = \sin(\omega_0 t)$，其 $X(j\omega) = \dfrac{\pi}{j}\left[\delta(\omega + \omega_0) - \delta(\omega - \omega_0)\right]$，从 $\omega = 0$ 起就有值，$\omega_m = \omega_0$。

    * 按定理取 $\omega_s = 2\omega_m = 2\omega_0$，则 $T = \dfrac{2\pi}{\omega_s} = \dfrac{\pi}{\omega_0}$，采样点恰为 $0$、$\dfrac{\pi}{\omega_0}$、$\dfrac{2\pi}{\omega_0}$……

    * 这些点全是 $\sin(\omega_0 t)$ 的零点，采出来的序列恒等于零，与"信号本来就是零"完全无法区分。

    * > **易错点**：$\omega_s = 2\omega_m$ 这个等号取不得，临界也不行；只有严格大于才谈得上完全恢复。

## 内插公式

* **低通内插公式**

    * 要回答的问题是：满足采样定理的前提下，如何由 $x[n] = x(nT)$ 恢复 $x(t)$。

    * 路线是频域相乘：$X(j\omega) = X_p(j\omega)\,H(j\omega)$，滤波器通带 $|\omega| \le \omega_0$、通带高度 $T$。

    * 截止频率的约束是 $\omega_m < \omega_0 < \omega_s - \omega_m$，落在两点之间即可随意取。

    * 高度取 $T$ 的原因：$X_p(j\omega)$ 的峰值已从 $1$ 掉到 $\dfrac{1}{T}$，需要乘 $T$ 补回。

    * 时域为 $h(t) = T\dfrac{\sin \omega_0 t}{\pi t}$，于是 $x(t) = x_p(t) * h(t)$。

    * 把 $x_p(t)$ 代入并用 $x(t)*\delta(t-t_0) = x(t-t_0)$（取 $t_0 = nT$）得

    $$x(t) = \frac{T}{\pi}\sum_{n=-\infty}^{\infty}x[n]\,\frac{\sin\big(\omega_0(t-nT)\big)}{t-nT}$$

    * 书上用 $\mathrm{sa}(\cdot)$ 记号书写，推出来的表达式与书上写法小有区别，两边都对。

* **带通内插公式**

    * 当 $X(j\omega)$ 不在基带而长在 $\pm\omega_s$ 附近时，要把乘的滤波器换成带通。

    * 通带为 $\omega_s - \omega_0$ 到 $\omega_s + \omega_0$，以及关于原点的镜像 $-\omega_s - \omega_0$ 到 $-\omega_s + \omega_0$。

    * 高度是 $\dfrac{T}{2}$ 而不是 $T$：该处原始高度为 $\dfrac{1}{2}$，除以 $T$ 后为 $\dfrac{1}{2T}$，要还原成 $\dfrac{1}{2}$ 就得乘 $\dfrac{T}{2}$。

    * $\omega_0$ 的约束与低通情形相同：$\omega_m < \omega_0 < \omega_s - \omega_m$。

    * 时域脉冲响应可写成和差形式，再化和差为积：

    $$h(t) = \frac{T}{2\pi t}\left[\sin\big((\omega_s+\omega_0)t\big) - \sin\big((\omega_s-\omega_0)t\big)\right] = T\frac{\sin(\omega_0 t)\cos(\omega_s t)}{\pi t}$$

    * 内插结果为

    $$x(t) = \frac{T}{2\pi}\sum_{n=-\infty}^{\infty}x[n]\,\frac{\sin\big((\omega_s+\omega_0)(t-nT)\big) - \sin\big((\omega_s-\omega_0)(t-nT)\big)}{t-nT}$$

    * 把 $\omega_s$ 换成 $n\omega_s$ 后推导照旧成立，因为采样点上恒有 $\sin(k\omega_s nT) = \sin(2k\pi n) = 0$、$\cos(k\omega_s nT) = \cos(2k\pi n) = 1$，插值性质不受影响；$2\omega_s$、$3\omega_s$、$4\omega_s$ 都可以。

* **两种内插公式的对比**

    | 名称 | 用到的滤波器 | 恢复公式 |
    | :--- | :--- | :--- |
    | 低通内插公式 | 通带 $\lvert\omega\rvert < \omega_0$，高 $T$ | $x(t) = \frac{T}{\pi}\sum_n x[n]\dfrac{\sin\big(\omega_0(t-nT)\big)}{t-nT}$ |
    | 带通内插公式 | 通带 $\omega_s-\omega_0 < \lvert\omega\rvert < \omega_s+\omega_0$，高 $T/2$ | $x(t) = \frac{T}{2\pi}\sum_n x[n]\dfrac{\sin\big((\omega_s+\omega_0)(t-nT)\big) - \sin\big((\omega_s-\omega_0)(t-nT)\big)}{t-nT}$ |

    * 名称的由来就是滤波器类型：低通那一支把 $\omega_s$ 附近的副本滤掉，带通那一支只把 $\pm\omega_s$ 附近的副本留下。

    * 同一个 $x[n]$ 用两种公式恢复出来的 $x(t)$ 是不同的，各有各的道理，两者都恰好在 $t = nT$ 处把 $x[n]$ 插回来，但形状不一样。

* **同一个 $x[n]$ 背后的多条 $x(t)$**

    * $X(j\omega)$ 不同的时候，生成的 $X_p(j\omega)$ 完全可以是同一个值。

    * 具体例子：一种是整个平台高度为 $1$；另一种平台高 $1$ 而肩部高 $\dfrac{1}{2}$。

    * 除以 $T$ 并以 $\omega_s$ 为周期重复后，中央平台都是 $\dfrac{1}{T}$；$\pm\omega_s$ 处是 $\dfrac{1}{2T} + \dfrac{1}{2T} = \dfrac{1}{T}$（两块肩部恰好接在一起），$\pm 2\omega_s$、$\pm 3\omega_s$ 处同理。

    * 结果处处都是 $\dfrac{1}{T}$，与"只有一个平台"的情形完全一样，所以 $X_p(j\omega)$ 与 $x[n]$ 相同却对应完全不同的 $x(t)$。

    * 要做完全恢复，就得指明到底认哪一路的 $X(j\omega)$——换哪只滤波器，就恢复哪一路。

## 采样频率不足是否一定混叠

* **判断题**

    * 命题"$\omega_s$ 小于两倍的 $\omega_m$，则频谱一定会混叠"是错的。

    * 关键在于 $\omega_m$ 的定义取的是频谱平台上最右边那一个频率。

    * 对带通信号，设通带为 $\omega_s - \omega_0$ 到 $\omega_s + \omega_0$ 及其镜像，则按该定义 $\omega_m = \omega_s + \omega_0$，$\omega_s$ 明显小于 $2\omega_m$，但采样不混叠。

    * 原因是 $0$ 到最高频率之间存在大片空白，副本落下去踩到的只是零。

    * > **结论**：$\omega_s > 2\omega_m$ 是基带信号不混叠的充分条件；真正要保证的是相邻频谱副本之间不重叠。带通信号的采样频率甚至可以比 $2\omega_m$ 小不少。

## 四种基本滤波器

* **频域形状与时域脉冲响应**

    | 滤波器 | 频域 $H(j\omega)$ | 时域 $h(t)$ |
    | :--- | :--- | :--- |
    | 低通 | 通带 $\lvert\omega\rvert < \omega_0$ 高 1，带外为 0 | $\dfrac{\sin \omega_0 t}{\pi t}$ |
    | 高通 | 带外高 1，带内为 0 | $\delta(t) - \dfrac{\sin \omega_0 t}{\pi t}$ |
    | 带通 | 只在 $\omega_0 < \lvert\omega\rvert < \omega_s$ 高 1 | $\dfrac{\sin \omega_0 t \cos \omega_s t}{\pi t}$ |
    | 带阻 | 与带通相反，除 $\omega_0 < \lvert\omega\rvert < \omega_s$ 外全高 1 | $\delta(t) - \dfrac{2\sin \omega_0 t \cos \omega_s t}{\pi t}$ |

* **形状与关系**

    ```text
       低通 LPF                高通 HPF
         _______                 _______
        |       |               |       |
     ---|-------|----       ----|-------|----
        |_______|               |_______|
         -w0    w0               -w0    w0

       带通 BPF                带阻 BRF
    --------|-------|----  ----|-------|--------
            |       |            |       |
            |_______|            |_______|
           -w0      w0          -w0      w0
    ```

    * 带通与带阻互为 $1 -$ 关系，是一对。

    * 截止频率的标法有各种 variation，形状大同小异。

    * 低通那一支把 $\omega_s$ 附近的副本滤掉，带通那一支只保留 $\pm\omega_s$ 附近的副本，两种内插公式的几何形状由此而来。

## 零阶保持

* **为什么要有保持**

    * 最理想的采样方式是 $x_p(t) = x(t)\delta(t)$，即拿冲激去乘，$x(t)$ 在每个采样时刻的取值直接成为那根冲激的强度。

    * $\delta(t)$ 是理想化函数：零附近有无穷大冲击，离开零就全是零，电路做不出无穷窄、无穷高的脉冲，实测也不存在这种东西。

    * 工程上改用保持：在 $t = 0$ 采样后把这个值保持一小段，到 $t = T$ 再采再保持，小段长度取 $T$。

    * 零阶保持：每隔 $T$ 采样一次，采到的值在整个区间 $[kT, (k+1)T)$ 内保持不变，得到阶梯曲线 $x_0(t)$。

    * 阶梯拐点全部落在 $-2T$、$-T$、$0$、$T$、$2T$、$3T$ 上，每级宽度都是 $T$，高度就是该时刻 $x(t)$ 的值。

    ```text
      x_0(t)：零阶保持，采到样就保持 T 长

          ^
        ┌───┐   ┌───┐   ┌───┐
        │   │   │   │   │   │
        └───┘   └───┘   └───┘
      +---+---+---+---+---+---+----> t
       -2T -T  0   T   2T  3T
    ```

* **与冲激串的卷积关系**

    * $x_0(t) = x_p(t) * h_0(t)$，其中 $h_0(t) = \begin{cases} 1, & 0 \le t \le T \\ 0, & \text{其他} \end{cases}$。

    * 验证方式是翻转、平移、滑过去：矩形扫过 $t = kT$ 时把 $x(kT)$ 整段搬过来，铺满 $[kT, (k+1)T)$，于是这段被抬到 $x(kT)$ 的高度上。

    * > **易错点**：$h_0(t)$ 是 $[0, T]$ 上的矩形，不是 $[-T, 0]$ 上的。两者效果一样（整体延时不同），但书写时必须与自己画的那一小段对上。

## 一阶保持

* **定义与几何形状**

    * 一阶保持（first-order hold）把相邻的采样点用直线连起来，也叫线段相连。

    * 零阶保持是每个点自己延续一小段；一阶保持把这一段换成相邻两点之间的一条直线段，结果是一条穿过所有采样点的折线。

    ```text
      x_1(t)：一阶保持，相邻样点直接用直线相连

                 ●               ●
               ╱   ╲           ╱   ╲
             ╱       ╲       ╱       ╲
           ╱           ╲   ╱           ╲
         ●               ●               ●
       +-------+-------+-------+-------+------> t
       -2T     -T      0       T       2T
    ```

* **卷积基函数是三角形**

    * $x_1(t) = x_p(t) * h_1(t)$，$h_1(t)$ 是以 $0$ 为顶点、高度为 $1$、向两边线性下降到 $\pm T$ 处为零的三角。

    * $h_1(t) = \begin{cases} 1 - \dfrac{|t|}{T}, & |t| \le T \\[4pt] 0, & \text{其他} \end{cases}$。

    * 在 $t \in [0, T]$ 上卷积结果为 $x_0\,\Lambda(t) + x(T)\Lambda(t-T) = x(0)\left(1 - \dfrac{t}{T}\right) + x(T)\dfrac{t}{T}$，两个权重之和恒为 $1$ 且各自对 $t$ 线性，故合成结果正是两点之间的直线段。

    ```text
      h_1(t)

          ^
        1 |       /\
          |      /  \
          |     /    \
          |    /      \
          |   /        \
          |  /          \
          | /            \
        0 +---------------+------> t
         -T       0        T
    ```

    * 验证方式同样是翻转、平移、滑过去：三角走到某处时一部分取左边样点、另一部分取右边样点，两个幅度合成的权重刚好凑成一条直线。

## 保持的频域形式

* **零阶保持的频域**

    * 时域相乘对应频域相乘：$X_0(j\omega) = X_p(j\omega)H_0(j\omega)$。

    * 由矩形拆成两个阶跃之差再整体乘 $\dfrac{1}{T}$，得 $H_0(j\omega) = \dfrac{1}{T}\int_0^T e^{-j\omega t}dt = \dfrac{1 - e^{-j\omega T}}{j\omega}$。

    * 换角度看：矩形中心在 $\dfrac{T}{2}$，写成宽度 $T/2$ 的矩形乘 $\dfrac{1}{T}$ 再乘 $e^{-j\omega T/2}$，用频移性质得

    $$H_0(j\omega) = \frac{\sin(\omega T/2)}{\omega T/2}\;e^{-j\omega T/2}$$

    * 两个因子各管一件事：$\dfrac{\sin(\omega T/2)}{\omega T/2}$ 是矩形窗自身形状的频响，$\omega = 0$ 处为 $1$、往两边按 $\dfrac{1}{x}$ 掉；$e^{-j\omega T/2}$ 是矩形不在原点、整体挪了半个采样周期带来的半格延时。

    * 恢复时要把这两项都除掉：$X(j\omega) = X_0(j\omega)\cdot\dfrac{\omega T/2}{\sin(\omega T/2)}\cdot e^{j\omega T/2}$。

    * 整个恢复过程三步：把 $x_0(t)$ 变到频域得到 $X_0(j\omega)$；先乘 $e^{j\omega T/2}$ 把半格延时补回、再乘 $\dfrac{\omega T/2}{\sin(\omega T/2)}$ 把窗形状除掉；得 $X(j\omega)$ 后反变换回到 $x(t)$。

* **一阶保持的频域**

    * 三角由两个矩形卷出来，故频谱是 sinc 因子的平方再乘总面积 $T$：

    $$H_1(j\omega) = T\left[\frac{\sin(\omega T/2)}{\omega T/2}\right]^2$$

    * 恢复公式为 $X(j\omega) = X_1(j\omega)\cdot\dfrac{1}{T}\left[\dfrac{\sin(\omega T/2)}{\omega T/2}\right]^2$。

    * 写成从 0 开始的因果形式 $h_1(t) = \dfrac{1}{T}\left[u(t) - 2u(t-T) + u(t-2T)\right]$，频谱为 $\dfrac{1}{T}\cdot\dfrac{\left(1 - e^{-j\omega T}\right)^2}{j\omega}$，比中心对称写法多出一个整体的 $e^{-j\omega T}$ 延时因子；两种写法描述同一条折线。

* **两种保持的对比**

    | | 零阶保持 $x_0(t)$ | 一阶保持 $x_1(t)$ |
    | :--- | :--- | :--- |
    | 相邻样点之间怎么做 | 保持上一点的值，做成台阶 | 用直线把两点连起来 |
    | 卷积基函数 $h(t)$ | $[0,T]$ 上的矩形，值为 1 | $[-T,T]$ 上的三角，$t=0$ 处为 1、$t=\pm T$ 处为 0 |
    | $H(j\omega)$ | $\dfrac{\sin(\omega T/2)}{\omega T/2}\,e^{-j\omega T/2}$ | $T\left[\dfrac{\sin(\omega T/2)}{\omega T/2}\right]^2$ |
    | 恢复 $x(t)$ 要除掉什么 | $\dfrac{\sin(\omega T/2)}{\omega T/2}\,e^{-j\omega T/2}$ | $\dfrac{1}{T}\left[\dfrac{\sin(\omega T/2)}{\omega T/2}\right]^2$ |

* **恢复滤波器的可实现性**

    * 整套公式都建立在一个除法上，而除法有代价。

    * 要除的 $\dfrac{\sin(\omega T/2)}{\omega T/2}$ 在 $\omega = \dfrac{2\pi k}{T}$ 处等于零，除以零是发散的。

    * 一阶保持的平方形式更明显：整个保持器的频谱只在 $|\omega| < \Omega_s/2$ 上非零，除以它等于把整个频带无限放大。

    * 理想上写出来的恢复滤波器实际实现不了，除法要跨过无穷大，模拟电路和数字滤波器里都过不去；如何构造这样的滤波器是很难的问题，这类问题要到滤波器设计与数字信号处理里一并解决。

* **半格平移序列的离散时间傅里叶变换**

    * 求 $h[n] = \dfrac{\sin\pi\left(n - \frac{1}{2}\right)}{\pi\left(n - \frac{1}{2}\right)}$ 的 $H(e^{j\omega})$，答案为 $e^{-j\omega/2}$，$-\pi \le \omega \le \pi$（以 $2\pi$ 为周期重复）。

    * 第一步把 $n$ 换成连续变量 $t$，在连续域认出它：基本对 $\dfrac{\sin \pi t}{\pi t} \longleftrightarrow \begin{cases} 1, & -\pi < \omega < \pi \\ 0, & \text{其他} \end{cases}$，题里的形式无非是整体平移了 $\dfrac{1}{2}$，故连续域频谱为 $e^{-j\omega/2}$。

    * 第二步取 $T = 1$，$h[n] = h(n)$，分母变成 $\pi n - \dfrac{\pi}{2} = \pi\left(n - \dfrac{1}{2}\right)$，恰好回到题目给的形式。

    * 第三步套 DTFT 公式 $H(e^{j\omega}) = \dfrac{1}{T}\sum_{k=-\infty}^{\infty}H\left(\dfrac{\omega - 2\pi k}{T}\right)$：$\omega_m = \pi \cdot T = \pi$ 落在连续谱主瓣边界上，频谱在 $0$、$\pm 2\pi$、$\pm 4\pi$ 处逐段重复，基本区间内只有 $k = 0$ 那一段算数。

    * > **易错点**：直接从离散域下手会卡住，因为 $\sin\pi\left(n - \frac{1}{2}\right)$ 在整数 $n$ 上是 $\pm 1$ 与 $0$ 交替，完全看不出原式是个移位 sinc；正确的入口永远是先把 $n$ 换回 $t$，在连续时间域认出它。

## 连续系统的离散实现

* **替换链路**

    * 目标是把一个连续 LTI 方框完全替代掉，$x(t)$ 进去 $y(t)$ 出来，结果仍然正确。

    ```text
      x(t) ─►[ 采样 ]─► x[n] ─►[ h_d[n] ]─► y[n] ─►[ 零阶保持 ]─►[ 一串重建滤波 ]─► y(t)
                  方括号里的 n 对应          离散冲激响应     y[n] = y(nT)     末端是低通
                  原来圆括号里的 nT
    ```

    * 采样把 $x(t)$ 变成 $x[n]$，方括号里的序号 $n$ 正对应原来圆括号里的 $nT$。

    * 数字滤波器的输出 $y[n]$ 等于连续输出 $y(t)$ 在采样点上的取值。

    * 零阶保持把 $y[n]$ 接回连续时间，得到的阶梯记作 $y_0(t)$。

    * 末端那一串重建滤波包含相移因子、除以 $j\omega$ 的一项、$2\sin(\omega T/2)$ 的一项，末端再乘一个低通，**那个低通不能省**。

    * 整条链子上只有 $h_d[n]$ 不明确，其余每块在前面的推导里都已确定。

* **数字滤波器设计公式**

    * > **定义**：在 $x(t)$、$y(t)$、$h(t)$ 都满足采样定理的前提下，$h_d[n] = T\,h(nT)$。

    * 读作：把连续冲激响应以 $T$ 为周期采样得到 $h(nT)$，再乘一个 $T$。

    * > **易错点**：那个 $T$ 不能当成归一化常数随手扔掉，它有明确来源而且必须有。

* **$T$ 因子的直觉来源**

    * 连续侧是积分 $y(t) = \int_{-\infty}^{+\infty}x(\tau)h(t-\tau)d\tau$，离散侧是求和 $y[n] = \sum_{k=-\infty}^{\infty}x[k]h_d[n-k]$。

    * 积分本质是把每点底下的面积一块一块加起来，求和只把每点的值加起来。

    * 要让两者对得上，必须在求和这一侧把每个点的宽度 $T$ 补上，于是每个点值都要乘 $T$。

    * 补上宽度之后，$h_d[n]$ 就必须等于连续那一侧采样点值再乘 $T$，即 $h_d[n] \approx T\,h(nT)$。

* **频域证明**

    * 设 $X(j\omega)$ 带限于 $[-\omega_m, \omega_m]$、峰值 $E_x$；$H(j\omega)$ 带限于 $[-\omega_k, \omega_k]$、峰值 $E_h$；时域卷积对应频域相乘，$Y(j\omega) = X(j\omega)H(j\omega)$，带宽取并、峰值 $E_xE_h$。

    * 采样后的 DTFT 是周期延拓、每片乘 $\dfrac{1}{T}$：$X_1(e^{j\omega})$ 峰值 $\dfrac{E_x}{T}$，$Y_1(e^{j\omega})$ 峰值 $\dfrac{E_xE_h}{T}$。

    * 离散世界里 $y[n] = x[n] * h_d[n]$，做 DTFT 得相乘，于是 $H_d(e^{j\omega}) = \dfrac{Y_1(e^{j\omega})}{X_1(e^{j\omega})}$。

    * 基带内两边各只剩中心一片，商的形状就是 $H(j\omega)$ 的形状并以 $\omega_s$ 为周期重复；关键在峰值 $\dfrac{E_xE_h/T}{E_x/T} = E_h$，所以 $H_d$ 的峰值必须是 $E_h$。

    * 而 $h(nT)$ 本身（不加系数）的 DTFT 记作 $H_1$，形状与 $H_d$ 分毫不差，峰值按 $\dfrac{1}{T}$ 的规矩只有 $\dfrac{E_h}{T}$。

    * 两张图上下对齐只看最高点对不上，唯一办法是把 $T$ 乘上去消掉它：$H_d(e^{j\omega}) = T\cdot H_1(e^{j\omega})$，回到时域即 $h_d[n] = T\,h(nT)$。

    | 频谱 | 结构 | 峰值 |
    | :--- | :--- | :--- |
    | $X(j\omega)$ | 带限于 $[-\omega_m, \omega_m]$ | $E_x$ |
    | $H(j\omega)$ | 带限于 $[-\omega_k, \omega_k]$ | $E_h$ |
    | $Y(j\omega)=XH$ | 带宽取并，$[-\omega_m, \omega_k]$ | $E_xE_h$ |
    | $X_1(e^{j\omega})$ | $X$ 按 $\omega_s = 2\pi/T$ 重复，每片 $\times 1/T$ | $E_x/T$ |
    | $Y_1(e^{j\omega})$ | $Y$ 按 $\omega_s$ 重复，每片 $\times 1/T$ | $E_xE_h/T$ |
    | $H_d(e^{j\omega})=Y_1/X_1$ | 形状同 $H$，按 $\omega_s$ 重复 | $E_h$ |
    | $H_1(e^{j\omega})=h(nT)$ 的 DTFT | 形状同 $H$，按 $\omega_s$ 重复 | $E_h/T$ |

    * 最后两行形状一样、峰值差一个 $T$，差出来的这个 $T$ 就是全部答案。

* **数字延时器**

    * 题目：给定纯延迟 $y(t) = x(t - t_0)$，求它的离散实现。

    * 频域一步到位：$H(j\omega) = \dfrac{Y(j\omega)}{X(j\omega)} = e^{-j\omega t_0}$。

    * 时域对应 $h(t) = \delta(t) - \delta(t - t_0)$。

    * > **注意**：这里是减号。纯延迟相当于把 $x(t)$ 往前挪，挪不动的那部分要用原信号减掉。

    * $h_d[n] = T\,h(nT)$ 这一步遇到麻烦：$h(t)$ 是冲激函数，采样与 $\delta$ 碰上的处理比一般函数更需谨慎，课程未在此展开，此处暂不作结论。

## 采样系统的频谱例题

* **题目结构与参数**

    * 框图为 $x(t) \xrightarrow{\text{时域采样 } \delta_T(t)} x_s(t) \xrightarrow{H(j\omega)} y(t)$，滤波器通带 $-2 \sim 2$、增益 $1$。

    * 已知 $x(t) = 1 + \cos t$，$\delta_T(t) = \sum_{n=-\infty}^{+\infty}\delta\left(t - \dfrac{\pi}{3}n\right)$。

    * 三个小问：求 $x_s(t)$ 的频谱及频谱图；求 $x[n] = x(nT)$ 的频谱及频谱图；求 $y(t)$。

    * 参数从框图上直接读：采样函数的通项写成 $t - \dfrac{\pi}{3}n$，所以 $T = \dfrac{\pi}{3}$，$\omega_s = \dfrac{2\pi}{T} = 6$。

    * $X(j\omega) = 2\pi\delta(\omega) + \pi\delta(\omega + 1) + \pi\delta(\omega - 1)$，即 $\omega = 0$ 处高 $2\pi$、$\omega = \pm 1$ 处各高 $\pi$。

    * 时域采样后的 $x_s(t)$ 就是前面那个 $x_p(t)$，两个名字指同一个东西。

* **$X_s(j\omega)$ 的画法**

    * 公式 $X_s(j\omega) = \dfrac{1}{T}\sum_{k=-\infty}^{\infty}X\big(j(\omega - k\omega_s)\big)$，两步走：以 $\omega_s$ 为周期不断重复，所有高度除以 $T$。

    * $\omega_s = 6$ 时，中心一组在 $0$、$1$、$-1$；右移一组在 $6$、$7$、$5$；再右一组在 $12$、$13$、$11$；左侧 $-6$ 一组为 $-6$、$-5$、$-7$。

    * 高度：中央 $2\pi \div \dfrac{\pi}{3} = 6$，两侧 $\pi \div \dfrac{\pi}{3} = 3$，每组都是 $6, 3, 3$，冲激落在 $6k-1$、$6k$、$6k+1$。

    ```text
      X_s(jω)   以 6 为周期重复，每组三个冲激

       6  3  3     6  3  3     6  3  3     6  3  3
       ↑  ↑  ↑     ↑  ↑  ↑     ↑  ↑  ↑     ↑  ↑  ↑
     ──┴──┴──┴─────┴──┴──┴─────┴──┴──┴─────┴──┴──┴──→ ω
      -7 -6 -5    -1  0  1      5  6  7     11 12 13
    ```

    * 图上一定要打足够多的点，表明谱是无限重复下去的，不是画三组就完事。

* **$X(e^{j\omega})$ 的画法**

    * 公式 $X(e^{j\omega}) = X\!\left(j\dfrac{\omega}{T}\right) = \dfrac{1}{T}\sum_{k=-\infty}^{\infty}X\!\left(j\dfrac{\omega - 2k\pi}{T}\right)$。

    * 下标全部乘 $T$：$\omega_m = 1$ 变成 $1 \times \dfrac{\pi}{3} = \dfrac{\pi}{3}$，$-1$ 变成 $-\dfrac{\pi}{3}$；重复周期 $\omega_s = 6$ 变成 $2\pi$，可验证 $6 \times \dfrac{\pi}{3} = 2\pi$。

    * 冲激位置为 $2k\pi - \dfrac{\pi}{3}$、$2k\pi$、$2k\pi + \dfrac{\pi}{3}$。

    ```text
      X(e^jω)  以 2π 为周期重复

         2π  π  π     2π  π  π     2π  π  π
         ↑   ↑  ↑     ↑   ↑  ↑     ↑   ↑  ↑
     ──┴───┴──┴─────┴───┴──┴─────┴───┴──┴──┴───→ ω
       -π/3  0  π/3           2π          5π/3
    ```

* **高度不能照搬**

    * 直觉上会把 $6, 3, 3$ 原样抄下来，这个高度是错的。

    * 原因是被代入的式子里含 $\delta$，而 $\delta\left(\dfrac{\omega}{T}\right) = T\delta(\omega)$，频谱被压缩时冲激的面积必须守恒，高度要乘回去。

    * 于是中心那个 $6$ 变成 $6 \times \dfrac{\pi}{3} = 2\pi$，答案是每组 $2\pi, \pi, \pi$。

    * > **易错点**：只在含 $\delta$ 的时候 $X(e^{j\Omega})$ 的高度才不能照搬 $X_p(j\omega)$；除非 $\delta$ 的系数里本身没有那个标度因子，否则抄一遍就是错的。

* **三张图与三个公式的分工**

    * 复习用的三张图说白了就是系统框图、频谱复制图、换元图，三个公式就是采样那一组加能量那一组。

    * 题都是往这三张图上套，六道题的汇编与解答放在课程平台上自行下载对照。

## 由样值序列计算能量

* **结论与成立条件**

    * > **结论**：对带限且满足采样定理的 $x(t)$，有 $\int_{-\infty}^{+\infty}|x(t)|^2 dt = T\sum_{n=-\infty}^{+\infty}|x[n]|^2$。

    * 成立条件是 $x(t)$ 带限且采样定理成立，即 $\omega_s = \dfrac{2\pi}{T} > 2\omega_m$，等价于 $\omega_m T < \pi$。

    * 物理含义：$T$ 是每个样值所代表的那一段时长，样值平方乘上它代表的长度再求和，就把连续的能量积攒出来了；$T$ 越密每项越小但项数越多，严格等值而非凑数。

* **两座桥**

    * 连续时间帕斯瓦尔定理：$\int_{-\infty}^{+\infty}|x(t)|^2 dt = \dfrac{1}{2\pi}\int_{-\infty}^{+\infty}|X(j\omega)|^2 d\omega$。

    * 离散时间帕斯瓦尔定理：$\sum_{n=-\infty}^{+\infty}|x[n]|^2 = \dfrac{1}{2\pi}\int_{-\pi}^{\pi}|X(e^{j\omega})|^2 d\omega$。

    * 待证的就是这两者只差一个 $T$ 因子。

* **推导链**

    * 从离散一侧推更顺：代入采样定理公式得 $\sum_n |x[n]|^2 = \dfrac{1}{2\pi T^2}\int_{-\pi}^{\pi}\left|X\left(j\dfrac{\omega}{T}\right)\right|^2 d\omega$。

    * 积分区间内只剩 $k = 0$ 一项：满足采样定理时 $\omega_m T < \pi$，整条带宽折到 $\omega$ 轴上还塞不满 $[-\pi, \pi]$，其余项刚好落在区间之外。

    * 换元令 $\dfrac{\omega}{T} = \Omega$，则 $d\omega = T\,d\Omega$，上下限变为 $\Omega \in \left[-\dfrac{\pi}{T}, \dfrac{\pi}{T}\right]$，整体得 $\dfrac{1}{T}\cdot\dfrac{1}{2\pi}\int_{-\frac{\pi}{T}}^{\frac{\pi}{T}}|X(j\Omega)|^2 d\Omega$。

    * 因为 $\dfrac{\pi}{T} > \omega_m$，积分限已罩住全部谱，可写成负无穷到正无穷，再与连续帕斯瓦尔定理一合即得结论。

    * > **易错点**：整条链上采样定理条件只在两处真正被用到——离散积分区间内只剩 $k = 0$ 一项，以及换元后 $\dfrac{\pi}{T}$ 罩住整个带宽；两处都靠 $\omega_m T < \pi$ 撑着，少了它结论不成立。

* **条件失效时的情形**

    * 若 $x(t)$ 不带限或采样率不够，式子立刻失效：混叠进来的高频分量在 $x[n]$ 里与真正的低频分量长得一模一样，能量无法分开。

## 用程序打印声音的频谱

* **读入得到的是离散序列**

    * `audioread` 一次交回两个东西：`[x, Fs] = audioread('voice.wav');` 中 $x$ 是 $1325056 \times 2$ 的 double 矩阵，两列分别是左声道和右声道。

    * 计算机只能处理离散量，所以交到手上的不可能是 $x(t)$，只能是 $x[n] = x(nT)$，$n$ 从 $0$ 数到 $1325055$。

    * $F_s = 44100$，采样周期 $T = \dfrac{1}{f_s} = \dfrac{1}{44100}$，时间轴写成 `(1:length(x))/Fs`。

    * 时长为 $\dfrac{1325056}{44100} \approx 30$ 秒。

    * 双声道取平均 `x = mean(x, 2);` 塌成单声道；也可以直接取 `x(:,1)` 或 `x(:,2)`，后面代码一个字不用改。

    * > **提示**：`Fs` 必须被用起来，它同时决定时间轴怎么画和最后横坐标上的频率数字从哪来，44100 这个数不能丢。

* **画频谱是两步不是一步**

    * 第一步由 $x[n]$ 画 $X(j\omega)$：横轴是数字角频率 $\omega$，量纲 rad/sample，范围 $0 \sim 2\pi$，每隔 $\dfrac{2\pi}{N}$ 取一个点。

    * 第二步由 $X(j\omega)$ 得到 $X(j\Omega)$，把横轴换成真正的模拟角频率，连续与离散在这一步串起来。

    ```text
       x(t)   连续时间信号，只在 t ∈ [0, 30] 秒有值
         │
         │  理想采样，采样周期 T = 1/Fs
         ▼
       x[n] = x(nT)              audioread 真正交到手上的，是这一层
         │
         │  ① FFT（第四章）：离散 → 离散频域
         │     横轴 ω ∈ [0, 2π]，间隔 2π/N
         ▼
       X(jω)                     复数，只能看 abs() 和 angle()
         │                       fftshift 之后横轴变成 −π … π
         │  ② 换轴（第五章）：离散 ↔ 连续
         │     f = ω / (2πT) = ω·Fs / (2π)
         ▼
       X(jΩ) 的幅度谱 + 相位谱     横坐标单位：Hz
    ```

* **FFT 与 fftshift**

    * `y = fft(x);` 把 $X(j\omega)$ 在 $0 \sim 2\pi$ 上采成 $N$ 个点，起点为 $0$，之后依次是 $\dfrac{2\pi}{N}$、$\dfrac{2\pi}{N}\times 2$，一直到 $2\pi$，每点间距 $\dfrac{2\pi}{N}$。

    * > **易错点**：`y` 是复数，不能直接 `plot(y)`，必须 `plot(abs(y))` 才拿到 $|X(j\omega)|$。

    * FFT 只算 $0 \sim 2\pi$，本该画到图左边的 $-\pi \sim 0$ 那一半在图上是空的，这不是程序写错而是 FFT 天生如此。

    * `y = fftshift(y);` 把中间切一半、把这一半搬到那边去，横轴从 $0 \sim 2\pi$ 变成 $-\pi \sim \pi$，下标也跟着变。

    ```text
         fft 之后：下标 0 … N-1，横轴 0 → 2π
         ┌──────────────┬──────────────┐
         │    0 … π     │    π … 2π    │
         └──────────────┴──────────────┘
                       │
                       │   fftshift：把右边这一半搬到左边
                       ▼
         fftshift 之后：横轴 −π → π
         ┌──────────────┬──────────────┐
         │    π … 2π    │    0 … π     │
         └──────────────┴──────────────┘
    ```

    * 搬完再画图才正常；两个版本画的是同一条曲线，但 `plot(abs(y))` 的第一个点对应 $\omega = 0$，`plot(abs(fftshift(y)))` 的第一个点对应 $\omega = -\pi$。

* **横纵坐标换算**

    * 图上横坐标标着 $-\pi$ 到 $\pi$，但每个点的值没标出来；已知的只是 $-\pi$ 到 $\pi$ 之间均匀采了 $N$ 个点，现在要把每个下标换成 $f$。

    | 点 | FFT 频点 $\omega_k$ | 换到横轴 $f_k = \dfrac{\omega_k}{2\pi T}$ |
    | :--- | :--- | :--- |
    | 第 $1$ 个点 | $-\pi$ | $-\dfrac{1}{2T} = -\dfrac{f_s}{2} = -22050$ Hz |
    | 第 $2$ 个点 | $-\pi + \dfrac{2\pi}{N}$ | $-\dfrac{1}{2T} + \dfrac{1}{NT}$ |
    | 第 $k$ 个点 | $-\pi + (k-1)\dfrac{2\pi}{N}$ | $\dfrac{1}{T}\left(-\dfrac{1}{2} + \dfrac{k-1}{N}\right)$ |
    | 第 $N$ 个点 | $\pi$ | $+\dfrac{1}{2T} = +22050$ Hz |

    * 间隔由 $\Delta f = \dfrac{2\pi/N}{2\pi T} = \dfrac{1}{NT} = \dfrac{f_s}{N}$ 给出，这就是 FFT 分辨率的来历。

    * 锚点 $\dfrac{\pi}{T} = \pi f_s$，是"数字频率"与"真实频率"之间的那把尺子，横轴靠它定标。

    * 纵轴同样要乘时间尺度，程序里写成把 `abs(y)` 除以 `Fs`，除以 $f_s$ 就是乘 $T$，这一步最容易看漏。

    * 相位谱没有尺度问题，把 `abs` 换成 `angle` 即可。

    ```matlab
    % ① 读入：audioread 一次给回 x 和 Fs
    [x, Fs] = audioread('voice.wav');      % x: 1325056×2，Fs: 44100

    % ② 双声道取平均 → 单声道；并把时间轴搭出来（T = 1/Fs）
    x = mean(x, 2);
    t = (1:length(x)) / Fs;

    % ③ 先在时域里看看原始信号：一百多万个点，画出来非常密
    plot(t, x);

    % ④ 第一步：x[n] → X(jω)，频点落在 0…2π，间隔 2π/N
    y = fft(x);
    y = fftshift(y);                        % 右半段搬到左半段，横轴变成 −π…π

    % ⑤ 第二步：按上表把每一个横坐标换成 f（Hz），纵轴乘上时间尺度
    plot(abs(y) / Fs);                      % 幅度谱：除以 Fs 就是乘 T
    plot(angle(y));                         % 相位谱：只把 abs 换成 angle
    ```

* **与采样定理相互验证**

    * 最终图上是上面幅度谱、下面相位谱，横坐标已经是 Hz；画到 22050 Hz 以后就没有值。

    * 这正对应采样定理的 $\dfrac{f_s}{2} = \dfrac{44100}{2} = 22050$ Hz，即 $f_s > 2f_m$ 蕴含 $f_m \le 22050$ Hz。

    * 往这段声音里塞一个高于 22050 Hz 的成分会发生什么，正是采样定理要管的事。

* **实信号的谱性质**

    * 实信号的幅度谱是偶函数，相位谱是奇函数，换一段实信号跑同一套程序即可验证。

    * 判据两条：幅度谱曲线关于纵轴左右对称，相位谱曲线关于原点上下反对称。

    * > **易错点**：相位只在幅度非零的地方才有定义；幅度压到零的那一段算出来的是数值噪声，不能当成"相位谱不对称"的证据。

## 希尔伯特变换的定义

* **因果性是前提**

    * 因果信号在 $t < 0$ 一段处处为零，即 $x(t) = x(t)u(t)$。

    * 时域相乘对应频域卷积且前面带 $\dfrac{1}{2\pi}$，再代入阶跃的频谱 $U(j\omega) = \dfrac{1}{j\omega} + \pi\delta(\omega)$。

    * 卷积被劈成两半：$\delta(\omega)$ 那一下把 $X$ 原样搬过来，$\dfrac{1}{j\omega}$ 那一下做卷积积分，于是 $X(j\omega) = \dfrac{1}{2}X(j\omega) + \dfrac{1}{2j\pi}\int_{-\infty}^{\infty}\dfrac{X(j\nu)}{\omega - \nu}d\nu$。

    * 把右边那个积分记成 $K(\omega)$，整理得 $X(j\omega) = \dfrac{1}{j\pi}K(\omega)$。

    * 接下来用实信号的共轭性质 $X(-j\omega) = X^{*}(j\omega) = R(\omega) - jI(\omega)$，而 $X(j\omega) = R(\omega) + jI(\omega)$；这一对只差 $\omega$ 的正负号，卷积变量 $\nu \leftrightarrow \omega - \nu$ 的互换下是同一个被积函数，于是实部虚部分别对位相加减。

* **频域与时域两式**

    * > **定义**：$\mathcal{H}\{f\}(\omega) = \dfrac{1}{\pi}\,\text{p.v.}\int_{-\infty}^{\infty}\dfrac{f(\nu)}{\omega - \nu}d\nu$ 称为希尔伯特变换（Hilbert transform）。

    * 因果信号实虚部互为希尔伯特变换：$R(\omega) = \dfrac{1}{\pi}\int_{-\infty}^{\infty}\dfrac{I(\nu)}{\omega - \nu}d\nu$，$I(\omega) = -\dfrac{1}{\pi}\int_{-\infty}^{\infty}\dfrac{R(\nu)}{\omega - \nu}d\nu$。

    * 写成卷积更顺眼：$R(\omega) = I(\omega)\circledast\dfrac{1}{\pi\omega}$，$I(\omega) = -R(\omega)\circledast\dfrac{1}{\pi\omega}$。

    * 时域形式为 $\hat{x}(t) = x(t)\circledast\dfrac{1}{\pi t} = \dfrac{1}{\pi}\text{p.v.}\int_{-\infty}^{\infty}\dfrac{x(\tau)}{t - \tau}d\tau$，以及 $x(t) = \hat{x}(t)\circledast\left(-\dfrac{1}{\pi t}\right) = -\dfrac{1}{\pi}\text{p.v.}\int_{-\infty}^{\infty}\dfrac{\hat{x}(\tau)}{t - \tau}d\tau$。

    * 习惯在信号头顶加三角帽号表示它的希尔伯特变换，看到 $\hat{x}$ 就应想到这是 $x$ 做了希尔伯特变换。

    * > **注意**：书中对应这两条时域公式的两个编号公式，右边积分的分子印错了，写成了 $x(t)$、$\hat{x}(t)$；积分变量明明是 $\tau$，尖括号也只在卷积里才成立，正确写法分子应为 $x(\tau)$、$\hat{x}(\tau)$。

    * > **提示**：积分号上的 p.v. 是柯西主值，不能当成可以跳过的记号——被积函数在 $\nu = \omega$ 处有奇点，主值取法是整条公式能成立的前提。

## 希尔伯特变换的频域乘子

* **核函数的频谱**

    * $\dfrac{1}{\pi t} \longleftrightarrow -j\,\mathrm{sgn}(\omega)$，是一个幅度恒为 $1$ 、只在相位上做文章的理想 $\dfrac{1}{\pi}$ 一项器。

    * 形状：幅度全频段恒为 $1$；相位在 $\omega > 0$ 一侧为 $-\dfrac{\pi}{2}$，$\omega < 0$ 一侧为 $+\dfrac{\pi}{2}$，过原点处取 $0$。

    * 短推导三步：先由 $u(t) \longleftrightarrow \dfrac{1}{j\omega} + \pi\delta(\omega)$ 与 $\dfrac{1}{2} \longleftrightarrow \pi\delta(\omega)$ 相减，得 $u(t) - \dfrac{1}{2} \longleftrightarrow \dfrac{1}{j\omega}$。

    * 再用对偶性质 $X(jt) \longleftrightarrow 2\pi x(-j\omega)$ 拐弯，得 $\dfrac{1}{jt} \longleftrightarrow 2\pi\left[u(-j\omega) - \dfrac{1}{2}\right]$。

    * 最后由 $\dfrac{1}{jt} = -\dfrac{j}{t}$ 把系数拉直并整体除以 $\pi$，得 $\dfrac{1}{\pi t} \longleftrightarrow 2j\left[u(-j\omega) - \dfrac{1}{2}\right] = -j\,\mathrm{sgn}(\omega)$，末步用到 $u(-x) = 1 - u(x)$ 与 $\mathrm{sgn}(\omega) = 2u(\omega) - 1$。

* **一次希尔伯特变换在频域的等价操作**

    * $\hat{x}(t) \longleftrightarrow -j\,\mathrm{sgn}(\omega)\,X(j\omega)$。

    * 含义是：正频率部分乘 $-j$、负频率部分乘 $+j$、直流分量处直接置零。

    * 这一条把时域公式与频域公式焊在一起，后面所有性质用这个乘子去看都能一眼说清。

## 希尔伯特变换的性质

* **变换两次等于取负**

    * 把 $\hat{x}(t)$ 再做一次希尔伯特变换，频域里被乘两次 $-j\,\mathrm{sgn}(\omega)$：$\left[-j\,\mathrm{sgn}(\omega)\right]^2 X(j\omega) = -X(j\omega)$。

    * 频谱乘 $-1$ 在时域就是把整个信号取负，故 $\hat{\hat{x}}(t) = -x(t)$。

    * > **结论**：$\mathcal{H}$ 作用两次等于乘 $-1$，即 $\mathcal{H}^{-1} = -\mathcal{H}$；这同时解释了为什么反变换公式里带着那个负号。

* **与自身变换正交**

    * $\int_{-\infty}^{\infty}x(t)\hat{x}(t)\,dt = 0$，即 $x(t)$ 与它的希尔伯特变换正交。

    * 频域证法：设 $y(t) = x(t)\cdot\hat{x}(t)$，则 $Y(j\omega) = \dfrac{1}{2\pi}\int_{-\infty}^{\infty}X(j\nu)\left[-j\,\mathrm{sgn}(\omega - \nu)\right]X(j(\omega - \nu))d\nu$。

    * 把被积函数在 $\nu$ 轴上按 $\nu < 0$、$0 < \nu < \omega$、$\nu > \omega$ 三段摊开，权重只随 $\omega - \nu$ 的正负取 $-j$ 或 $+j$。

    * 作变量替换 $\nu \leftrightarrow \omega - \nu$ 后被积函数本身不变而权重里的符号被换掉，$\nu < 0$ 与 $\nu > \omega$ 两段贡献两两抵消，剩下 $0 < \nu < \omega$ 一段的积分等于自身的相反数，也是零。

* **正弦与余弦互为希尔伯特变换**

    * $\mathcal{H}\{\cos(\omega_0 t)\} = \sin(\omega_0 t)$，$\mathcal{H}\{\sin(\omega_0 t)\} = -\cos(\omega_0 t)$。

    * 证明只需看乘子：$\cos(\omega_0 t)$ 的频谱是 $\pi\left[\delta(\omega - \omega_0) + \delta(\omega + \omega_0)\right]$，正频率处乘 $-j$、负频率处乘 $+j$ 得 $\pi\left[-j\delta(\omega - \omega_0) + j\delta(\omega + \omega_0)\right]$，正是 $\sin(\omega_0 t)$ 的频谱。

    | $x(t)$ | $\hat{x}(t) = \mathcal{H}\{x\}$ | 反变换 $\mathcal{H}^{-1}\{x\}$ |
    | :--- | :--- | :--- |
    | $\cos(\omega_0 t)$ | $\sin(\omega_0 t)$ | $-\sin(\omega_0 t)$ |
    | $\sin(\omega_0 t)$ | $-\cos(\omega_0 t)$ | $\cos(\omega_0 t)$ |

    * 更一般地，任何信号与它的希尔伯特变换之间，"乘 $-j$ 一次"和"取负一次"是同一件事。

## 窄带信号的包络与瞬时相位

* **窄带信号的希尔伯特变换**

    * 窄带信号写成 $x(t) = a(t)\cos\left[\omega_0 t + \phi(t)\right]$，其中 $a(t)$ 与 $\phi(t)$ 相对于 $\cos(\omega_0 t)$、$\sin(\omega_0 t)$ 变化缓慢。

    * 此时 $\hat{x}(t) \approx a(t)\sin\left[\omega_0 t + \phi(t)\right]$。

    * 证法是先做相位和差展开，再套 $\cos \to \sin$、$\sin \to -\cos$，最后用慢变假设把 $a(t)$ 当常数提出来。

    * 那个约等号就卡在把 $a(t)$ 当常数这一步，包络越慢近似越准。

* **三条定义式**

    | 物理量 | 记号 | 由 $x$ 与 $\hat{x}$ 算出的表达式 |
    | :--- | :--- | :--- |
    | 瞬时包络（幅度） | $a(t)$ | $\sqrt{x^2(t) + \hat{x}^{\,2}(t)}$ |
    | 瞬时相位 | $\varphi(t)$ | $\arctan\dfrac{\hat{x}(t)}{x(t)}$ |
    | 瞬时角频率 | $\omega(t)$ | $\dfrac{d\varphi(t)}{dt} = \omega_0 + \dfrac{d\phi(t)}{dt}$ |

    * 定理里那个 $\phi(t)$ 是慢变相位；定义出来的 $\varphi(t) = \omega_0 t + \phi(t)$ 才是完整的瞬时相位，对它求导才是瞬时角频率。

    * 把 $x$ 与 $\hat{x}$ 当作一对直角边，斜边就是包络。

    * 包络与相位可以完全不一样地变化，它们只是"慢"，并没有被绑成某种固定波形。

* **求解流程**

    ```text
       任意 x(t)
          │
          ├──► 求 ˆx(t) 的傅立叶变换：  X̂(jω) = [−j·sgn(ω)]·X(jω)
          │
          ├──► 与 X(jω) 合在一起：  [1 + sgn(ω)]·X(jω)
          │
          ├──► 反变换 ──────────────►  z(t) = x(t) + j·ˆx(t)
          │                            频谱只剩正频率那半边
          │
          ├──► 模长 ────────────────►  a(t) = √[x²(t) + ˆx²(t)]
          ├──► 辐角 ────────────────►  φ(t) = arctan[ˆx(t)/x(t)]
          └──► 对 φ 求导 ───────────►  ω(t) = dφ(t)/dt
    ```

    * 整条流水线只用到一次希尔伯特变换，换回时域就是一个只含正频率的复信号，从它的模和辐角里分别读出包络与瞬时相位。
