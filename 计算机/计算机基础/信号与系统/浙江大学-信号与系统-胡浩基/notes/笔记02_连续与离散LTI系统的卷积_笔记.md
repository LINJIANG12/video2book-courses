# 连续与离散LTI系统的卷积

## LTI 系统的三条性质

* **线性（linearity）**

    * > **定义**：任意输入通过系统得到输出之后，任意实数倍的输入得到任意实数倍的输出（齐次性）；两个输入分别的输出相加，等于两个输入相加后的输出（叠加性）。

    * 齐次性：$x[n]\to y[n]$，则 $a\,x[n]\to a\,y[n]$，$a$ 为任意实数。

    * 叠加性：$x_1[n]\to y_1[n]$、$x_2[n]\to y_2[n]$，则 $x_1[n]+x_2[n]\to y_1[n]+y_2[n]$。

    * ⚠️ **易错点**：输入翻倍输出也翻倍这件事只在**线性**系统里成立。时不变系统完全可以不是线性的，那时输入翻倍输出未必翻倍。出现系数 $a$ 时它对应的是齐次性，不是时不变性。

* **时不变（time invariance）**

    * > **定义**：$x(t-t_0)$ 的输出就是 $y(t-t_0)$，即输入平移多少，输出同步平移同样多，形状与取值不变。

    * 离散的坐标必须是整数，所以时不变性定义里的 $n_0$ 必须规定为某一个整数，不能是任意实数。

    * 连续情形下 $t_0$ 是任意实数。

* **性质分工**

    * 齐次性管缩放，时不变性管平移，叠加性管两个输入相加。

    * 三条合起来才是全部工具：任何一条缺失，$h[n]$ 推不出任意输入的响应。

* **LTI 系统的串联与并联**

    * > **定义**：两个 LTI 系统串联，或者并联，得到的仍然是 LTI 系统。

    * 串联的齐次性：输入放大 $a$ 倍，第一级输出变 $a\,z_1(t)$，第二级再放大 $a$ 倍，最终输出 $a\,y(t)$。

    * 串联的叠加性：输入 $x_1+x_2$，第一级给 $z_{11}+z_{12}$，第二级再给 $y_1+y_2$。

    * 并联同理，输出写成 $y(t)=z_1(t)+z_2(t)$，把两项分别展开后 regroup 仍然等于 $y_1+y_2$。

## 单位脉冲响应与卷积的定义

* **单位脉冲序列（unit impulse）**

    * > **定义**：$\delta[n]$ 在 $n=0$ 处为 1、其他处为 0 的离散序列。

    * 缩放性质：$a\,\delta[n-k]$ 的幅度就是 $a$。

    * 移位性质：$\delta[n-k]$ 是把单位脉冲右移 $k$ 个单位，$k<0$ 时等价于左移 $-k$ 个单位。

* **单位脉冲响应（unit impulse response）**

    * > **定义**：$\delta[n]$ 通过线性时不变系统所得到的输出，记作 $h[n]$。

    * 连续时间对应量为**冲激函数** $\delta(t)$ 与**冲激响应** $h(t)$。

    * 卷积不是新引入的规矩，就是「把 $h$ 按 $x$ 的每一个值缩放、平移，再全部加起来」这套繁琐算法的缩写写法。

    * $h[n]$ 是 LTI 系统唯一的标识：只要 $h[n]$ 相同，两个 LTI 系统对任意输入的输出都相同。

    * > **注意**：这里说的是 LTI 系统。对于非 LTI 系统，$h[n]$ 只是 $\delta[n]$ 对应的一个普通输出，没有任何特殊地位。

* **卷积（convolution）**

    * > **定义**：LTI 系统中任意输入的输出等于该输入与系统冲激响应的卷积。

    * 离散：$$y[n]=x[n]*h[n]=\sum_{k=-\infty}^{+\infty}x[k]\,h[n-k]$$

    * 连续：$$y(t)=x(t)*h(t)=\int_{-\infty}^{+\infty}x(\tau)\,h(t-\tau)\,d\tau$$

    * 离散求和换成连续积分，两者形式一模一样，需要背下来。

    * 任何信号与 $\delta$ 卷积等于它本身：$x(t)*\delta(t)=x(t)$。

* **冲激函数为什么出现在这一章**

    * 已知条件只能是有限宽度的方波，而要把任意 $x(t)$ 近似成阶梯函数，已知的那个波必须窄到极限才是唯一出路。

    * 由此得到的信号宽度趋零、高度趋无穷，它有专门的名字 $\delta(t)$。

## 离散卷积的计算：列表法

* **列表法（table method）**

    * > **定义**：把 $h[n]$ 铺成表格第一行，$x[n]$ 的每一个值单独把 $h[n]$ 整行乘一遍、按它在 $x[n]$ 里的位置整行右移相应格数，最后竖着求和。

    * 四步顺序：定范围 → 铺 $h[n]$ → 逐个 $x[n]$ 乘一遍并按位右移 → 竖着加。

* **取值范围**

    * $y[n]$ 最左边 $=x[n]$ 最左边 $+h[n]$ 最左边。

    * $y[n]$ 最右边 $=x[n]$ 最右边 $+h[n]$ 最右边。

    * 机理：卷积是「位移相加」，$x$ 相对零的位移量加上 $h$ 相对零的位移量。

* **逐项右移的规则**

    * $x[n]$ 最左格那一行不右移；第二行右移一位；第三行右移两位；依次类推。

    * 右移的是乘出来的每一整格，不只是第一格。

* **竖着加**

    * ⚠️ **易错点**：不要把第一行的 $h[n]$ 加进去，它只是被乘被移的工具，不参与求和。

    * 列表法的最大问题：错了一个数，后面基本会全错。卷积公式法是一个一个算的，$y[0]$ 错不影响 $y[1]$、$y[2]$ 算对。

* **读图方式**

    * $x$ 那一行钉死不动，$h$ 那一行每往右挪一格，把重叠格子的数逐点相乘再加起来，加出来的就是那一项 $y[n]$。

    * 零格直接划掉不算。

### 列表法的完整算例

$x[n]$ 在 $n=-1,0,1,2$ 处依次为 $3,2,1,-1$，$h[n]$ 在 $n=-1,0,1,2$ 处依次为 $1,1,2,-1$。

| $n$ | -2 | -1 | 0 | 1 | 2 | 3 | 4 |
| :--: | :--: | :--: | :--: | :--: | :--: | :--: | :--: |
| $h[n]$（不加） | | 1 | 1 | 2 | -1 | | |
| $x[-1]=3$ | 3 | 3 | 6 | -3 | | | |
| $x[0]=2$ | | 2 | 2 | 4 | -2 | | |
| $x[1]=1$ | | | 1 | 1 | 2 | -1 | |
| $x[2]=-1$ | | | | -1 | -1 | -2 | 1 |
| **$y[n]$** | **3** | **5** | **9** | **1** | **-1** | **-3** | **1** |

同样地，$x[n]=2\delta[n]+\delta[n-1]$ 的响应是 $y[-1]=2$、$y[0]=3$、$y[1]=5$、$y[2]=0$、$y[3]=-1$，其余为零。

$2\delta[n]$ 由齐次性让输出整体乘 2，$\delta[n-1]$ 由时不变性让输出整体右移一位。

### 同一道题的第二种问法

    * 直接给 $x[n]$ 与 $h[n]$ 的取值表求卷积，与「$\delta[n]$ 输入输出为 $h[n]$，求 $x[n]$ 的响应」是同一道题。

    * 看到第二种写法要立刻翻译回第一种：单位脉冲的响应能不能推出别的输入的响应。

### 带 $\delta$ 的写法与序列取值的对应

    * $\delta[n+1]=\delta[n-(-1)]$ 对应 $k=-1$、系数 $x[-1]$；$\delta[n-0]$ 对应 $k=0$。

    * 某一处没写出下标，意味着那里取值为零，不是「这一项没有」。

    * 通式：$$x[n]=\sum_{k=-\infty}^{+\infty}x[k]\,\delta[n-k]$$

    * 读法：$\delta[n-k]$ 是把单位脉冲右移 $k$ 个单位，$x[k]$ 乘上第 $k$ 个位置上 $x$ 的值，全部加起来。

    * > **提示**：符号一多就发怵时不要硬背整条式子，退回「一个单位脉冲挪到位，乘上该位置的值，加起来」这句话，式子就自己长出来了。

## 卷积公式及其证明

* **离散卷积计算公式**

    * > **定义**：$x[n]*h[n]=\displaystyle\sum_{k=-\infty}^{+\infty}x[k]\,h[n-k]$。

* **逐步证明**

    * 第一步（定义）：$\delta[n]\ \xrightarrow{\mathrm{LTI}}\ h[n]$。

    * 第二步（时不变性）：$\delta[n-k]\ \xrightarrow{\mathrm{LTI}}\ h[n-k]$。

    * 第三步（齐次性）：$x[k]\delta[n-k]\ \xrightarrow{\mathrm{LTI}}\ x[k]h[n-k]$。

    * 第四步（叠加性）：把 $k$ 从 $-\infty$ 到 $+\infty$ 的所有项加起来，$\sum_k x[k]\delta[n-k]\ \xrightarrow{\mathrm{LTI}}\ \sum_k x[k]h[n-k]$。

    * 左边由 $\sum_k x[k]\delta[n-k]=x[n]$ 认出就是 $x[n]$，右边正是卷积的定义，公式成立。

    * ⚠️ **易错点**：定义、时不变性、齐次性、叠加性四步分别用在四个地方，不能串位。要求证明时先把该用的性质名字写在等号旁边。

    * 时不变性在公式里承担的是「$k$ 作为求和变量遍历全实数」这件事。

### 公式的推导链

```text
   xΔ(t)  ──[ 时不变 ]──►  δΔ(t-kΔ)              →  hΔ(t-kΔ)
          ──[ 齐次性 ]──►  x(kΔ)·δΔ(t-kΔ)·Δ       →  x(kΔ)·hΔ(t-kΔ)·Δ
          ──[ 叠加性 ]──►  Σ …                     →  Σ …
          ──[ Δ → 0   ]──►  x(t)                   →  ∫ x(τ)·h(t-τ)·dτ
```

## 卷积公式法：翻转、平移、相乘、求和

* **四步口诀**

    * > **结论**：翻转、平移、相乘、求和。

    * 公式改写成 $y[n]=\sum_k x[k]h[-(k-n)]$ 后四步就对应出来了。

* **翻转**

    * 对应公式里 $h$ 自变量上的负号，也就是沿纵轴把整个序列左右翻身。

    * $h$ 从左往右 $1,1,2,-1$，则 $h[-n]$ 从左往右是 $-1,2,1,1$，即把 $h$ 从右往左抄一遍。

* **平移**

    * 把翻转后的 $h[-n]$ 右移 $n$ 个单位；$n<0$ 时右移 $n$ 个单位等于左移 $-n$ 个单位。

* **相乘**

    * 平移之后与 $x[n]$ 逐点相乘。

* **求和**

    * 把所有重叠处的乘积加起来。

* **谁翻转就平移谁**

    * ⚠️ **易错点**：翻转 $h$ 就得平移 $h$、与 $x$ 相乘；翻转 $x$ 就得平移翻转后的 $x$、与 $h[n]$ 相乘。不能翻转 $h$ 之后去平移 $x$，因为公式里被求和加权的那一项就是 $h[n-k]$，翻转和平移都冲着它去。

    * 由于卷积具有交换性，翻转 $x$ 也是允许的。

* **定范围**

    * 与列表法完全一样：最左边等于两者最左边之和，最右边等于两者最右边之和。

* **同一算例的逐列验算**

    * $y[-2]$：只有 $k=-1$ 重合，$3\times 1=3$。

    * $y[-1]$：$k=-1,0$ 重合，$3\times 1+2\times 1=5$。

    * $y[0]$：$k=-1,0,1$ 重合，$3\times 2+2\times 1+1\times 1=9$。

    * $y[1]$：四个格子全重合，$3\times(-1)+2\times 2+1\times 1+(-1)\times 1=1$。

    * $y[2]$：$2\times(-1)+1\times 2+(-1)\times 1=-1$。

    * $y[3]$：$1\times(-1)+(-1)\times 2=-3$。

    * $y[4]$：只有 $k=2$ 重合，$(-1)\times(-1)=1$。

## 卷积的长度与计算复杂度

* **长度公式**

    * > **结论**：长度为 $n_1$ 的序列与长度为 $n_2$ 的序列卷积，结果长度为 $n_1+n_2-1$。

    * 算的是从 0 到 $n_1-1$ 与 0 到 $n_2-1$ 的情形：结果最左 $0+0$，最右 $(n_1-1)+(n_2-1)$。

    * 换任何起点重述，长度都一样（植树问题的想法）。

* **列表法的运算次数**

    * 乘法次数：每个格子都要与 $h$ 里的一个数相乘，共 $n\times n$ 个格子，即 $n^2$ 次。

    * 加法次数：重叠格数依次为 $1,2,\dots,n-1,n-2,\dots,1$，每列内部两两相加的次数是格子数减一，故为 $(n-1)^2$ 次。

    * 计算复杂度 $O(n^2)$。

* **快速傅立叶变换**

    * 1977 年前后两位美国数学家和计算机科学家把计算卷积的复杂度由 $n^2$ 降到 $n\log n$，方法叫快速傅立叶变换（fast Fourier transform，FFT）。

    * $n=10^5$ 时 $n^2$ 是 $10^{10}$，$n\log n$ 只有百万量级，规模越大差距越不可同日而语。

* **两种方法的关系**

    * 考场两种方法任选，能做出来即可。

    * 在计算机眼里列表法与卷积公式法是同一个方法，加法乘法次数完全一样，只是运算顺序不同，时间复杂度相同。

## 离散卷积的编程实现

* **`conv` 的行为**

    * `conv` 做的就是两个序列的卷积，但**完全不管下标**。

    * 它默认下标是「$x$ 最左边 $+$ $h$ 最左边」到「$x$ 最右边 $+$ $h$ 最右边」，只把值算出来扔给你。

    * $x=[1,2,1,1]$、$h=[1,-1,0,-1,1]$ 时 `conv` 输出长度为 $4+5-1=8$：`1 1 -1 -1 -2 1 0 1`。

    * $x$ 与 $h$ 都是 5 个 1 时输出 `1 2 3 4 5 4 3 2 1`。

* **列表法的实现**

    * 输出长度先由 `length(a)+length(b)-1` 定出并全部置零，置零不能省——后面是往里加，不是往里赋值。

    * 循环体每轮做同一件事：把 $b$ 整段右移 $(i-1)$ 格，整段乘上 $a(i)$，加进 $c$ 的第 $i$ 个窗口。

```matlab
function c = conv6(a, b)
c   = conv(a, b);
n   = length(a) + length(b) - 1;
c   = zeros(1, n);
for i = 1:length(a)
    c(i:i+length(b)-1) = c(i:i+length(b)-1) + a(i) * b;
end
```

* **两条语法细节**

    * 数组与序列可以用逗号直接连起来用，「窗口 $+$ 标量乘向量」一行就能写完。

    * 冒号从 1 到 `length(b)` 自己就知道有多长。

* **暴力测试**

    * 两个长度 10000 的序列取 0 到 1 之间随机数，`conv` 输出正好 19999 个数，瞬间返回。

    * 两个长度 100000 时，列表法版本基本跑不动。

    * 即使用 FFT 写一版，也不见得能打过 MATLAB 自带的那个——那个库是从 1970 年代集成进 FORTRAN 的算法被无数轮优化叠出来的。

* **连续信号侧的正误对照**

    * $y(t)=7t\cdot x(t)$ 这个系统是线性的但不是时不变的，它的 $h(t)=7t\,\delta(t)\equiv 0$，而 $t=0$ 处的结果是零、$t\neq 0$ 处 $\delta$ 本来就是零。

    * 由此算出的 $\int_{-\infty}^{\infty}|h(t)|dt=0<\infty$ 会误判它稳定；实际上取有界输入 $x(t)\equiv 1$，输出 $y(t)=7t$ 直接跑到无穷大。

    * 错不在推导而在前提：这个系统不是 LTI，拿 $h$ 描述它的方法压根不适用。

## 连续卷积公式的推导

* **矩形式脉冲 $\delta_{\Delta}(t)$**

    * > **定义**：宽度为 $\Delta$、高度为 $\frac{1}{\Delta}$ 的方波。

    * 高度取 $\frac{1}{\Delta}$ 是为了保持面积为 1。

    * 取极限 $\lim_{\Delta\to 0}\delta_{\Delta}(t)=\delta(t)$：宽度趋零的同时高度 $\frac{1}{\Delta}$ 趋于无穷大。

    * $\delta(t)$ 的画法（一个向上的箭头、底下标 1）是人为规定的，物理意义是这一族脉冲在 $\Delta\to 0$ 时的极限。

* **用一串 $\delta_{\Delta}$ 铺出 $x(t)$**

    * > **定义**：$$x_{\Delta}(t)=\sum_{k=-\infty}^{+\infty}x(k\Delta)\,\delta_{\Delta}(t-k\Delta)\,\Delta$$

    * 每一项中 $\delta_{\Delta}$ 的高度 $\frac{1}{\Delta}$ 乘上 $\Delta$ 变成 1，再被 $x(k\Delta)$ 调制，得到该段上高度为 $x(k\Delta)$ 的横条。

    * 第 $k$ 项占据区间 $[k\Delta,(k+1)\Delta]$，自变量写成 $t-k\Delta$ 正是为了把它右移 $k\Delta$ 格。

    * $\lim_{\Delta\to 0}x_{\Delta}(t)=x(t)$：把 $\Delta$ 取得足够小，阶梯函数就与 $x(t)$ 一致。

* **三条性质依次落到推导链上**

    * 时不变性：$\delta_{\Delta}(t-k\Delta)\ \xrightarrow{\mathrm{LTI}}\ h_{\Delta}(t-k\Delta)$。

    * 齐次性（此处 $a=x(k\Delta)\Delta$）：$x(k\Delta)\delta_{\Delta}(t-k\Delta)\Delta\ \xrightarrow{\mathrm{LTI}}\ x(k\Delta)h_{\Delta}(t-k\Delta)\Delta$。

    * 叠加性：全部加起来。

    * 之后 LTI 部分翻篇，剩下的全是数学：让 $\Delta\to 0$。

* **两步化简**

    * 第一步由 $h(t)=\lim_{\Delta\to 0}h_{\Delta}(t)$，把 $h_{\Delta}(t-k\Delta)$ 换成 $h(t-k\Delta)$。

    * 第二步由黎曼和的定义，等于积分 $\int_{-\infty}^{+\infty}x(\tau)h(t-\tau)\,d\tau$。

## 冲激函数的性质

* **积分性质**

    * > **结论**：$\displaystyle\int_{-\infty}^{+\infty}\delta(t)\,dt=1$。

    * 直接由定义得到：宽为 $\varepsilon$、高为 $\frac{1}{\varepsilon}$ 的矩形面积恒为 1，与 $\varepsilon$ 无关，取极限仍是 1。

* **区间版积分**

    * > **结论**：$\displaystyle\int_a^b\delta(t)\,dt=\begin{cases}1,&a<0<b\\ -1,&a>0,\ b<0\\ 0,&\text{其它}\end{cases}$

    * 本质在问「这根针有没有被你的区间包住」，以及扫描方向。

    * ⚠️ **易错点**：不是「区间里含有 0 就等于 1」，必须一边小于 0、另一边大于 0、原点被夹在区间内部。反着积（从大的往小的方向）会得到 $-1$ 而不是 $+1$。

    * $a=0$ 或 $b=0$ 的边界情形按端点不影响积分处理，答案仍是 $1$ 或 $0$。

* **抽样性质（带积分）**

    * > **结论**：$\displaystyle\int_{-\infty}^{+\infty}x(t)\,\delta(t)\,dt=x(0)$。

    * 平移变种：$\displaystyle\int_{-\infty}^{+\infty}x(t)\,\delta(t-t_0)\,dt=x(t_0)$。

    * 推导：套上 $\delta$ 的定义后积分上下限立刻收缩到 $[0,\varepsilon]$，再用积分中值定理 $\int_0^\varepsilon x(t)dt=x(\xi)\varepsilon$，两个 $\varepsilon$ 约掉后 $\xi\to 0$。

    * 用积分中值定理的前提是 $x(t)$ 在该段上连续；碰上不连续信号只能给出上下界，给不出等号。

* **加权性质（不带积分）**

    * > **结论**：$x(t)\delta(t)=x(0)\,\delta(t)$，平移变种 $x(t)\delta(t-t_0)=x(t_0)\delta(t-t_0)$。

    * 与抽样性质的分界一句话：带积分的是抽样，结果是普通函数 $x(0)$；不带积分的是加权，结果还是带 $\delta$ 的函数 $x(0)\delta(t)$。

    * 积分性质是抽样性质在 $x(t)\equiv 1$ 时的特例。

* **缩放性质**

    * > **结论**：$\delta(at)=\dfrac{1}{|a|}\delta(t)$，$a\neq 0$。

    * $a>0$ 时等于 $\frac{1}{a}\delta(t)$；$a<0$ 时等于 $\frac{-1}{a}\delta(t)$，符号跟着箭头方向走。

    * $a=0$ 时 $\delta(0)$ 无定义，不在讨论范围内。

    * 变种：$\delta(at+b)=\dfrac{1}{|a|}\delta\!\left(t+\dfrac{b}{a}\right)$，把 $at+b$ 看成 $a\left(t+\dfrac{b}{a}\right)$ 再套一次缩放性质即可。

    * ⚠️ **易错点**：绝对值是换元时「积分限被颠倒」换来的，不是抄上去的。$a<0$ 那一档忘了负号会整体差一个符号。

* **复合冲激公式**

    * > **结论**：若 $f(t)$ 在 $t=t_k$ 处为零（实根），则 $\delta(f(t))=\displaystyle\sum_k\frac{1}{|f'(t_k)|}\,\delta(t-t_k)$。

    * 规则一句话：把 $f(t)=0$ 的每一个实根找出来，各自在 $t=t_k$ 处放一个权重为 $\frac{1}{|f'(t_k)|}$ 的冲激。

    * 分母是 $|f'(t_k)|$ 而不是 $f'(t_k)$，这是本条最要命的特点：分母不加绝对值时，像 $\delta(at)$ 里 $a=-1$ 的情况冲激面积会变成 $-1$、直接翻了向。

* **冲激导数**

    * > **定义**：$\delta'(t)=\dfrac{d\delta(t)}{dt}$，即那个使对任意 $x(t)$ 都有 $\int_{-\infty}^{\infty}x(t)\delta'(t)dt=-x'(0)$ 的广义函数。

    * 它与 $\delta(t)$ 的定义方式完全不同：$\delta(t)$ 靠零点上那根高无穷的细杆定下来，$\delta'(t)$ 靠「作用在别人身上之后是什么反应」定下来，先有反应后有函数。

    * 证明用广义函数的分部积分：$\int x(t)\delta'(t)dt=-\int x'(t)\delta(t)dt-[x(t)\delta(t)]_{-\infty}^{+\infty}$，边界项为零，剩下的一项搬 $\delta$ 的采样性质得 $-x'(0)$。

    * 负号来自广义函数的求导规则 $\langle\delta',x\rangle=-\langle\delta,x'\rangle$，不是从边界项冒出来的。

    * 取 $x(t)\equiv 1$ 白捡一个推论：$\displaystyle\int_{-\infty}^{\infty}\delta'(t)dt=0$，冲激导数有正有负正好抵平，别与 $\int\delta\,dt=1$ 混淆。

### 复合冲激的算例

    * $\delta(t^2-3t+2)$：因式分解得 $(t-1)(t-2)$，根为 1 与 2；$f'(t)=2t-3$，$f'(1)=-1$、$f'(2)=1$；两个权重都是 1，结果为 $\delta(t-1)+\delta(t-2)$。

    * $\delta(\cos t)$：零点为 $t_k=k\pi+\frac{\pi}{2}$，$k\in\mathbb{Z}$；$f'(t)=-\sin t$，$f'(t_k)=-(-1)^k$，绝对值恒等于 1；结果为 $\displaystyle\sum_{k}\delta\!\left(t-k\pi-\frac{\pi}{2}\right)$。

    * 这正是绝对值存在的全部理由：不取绝对值时 $k$ 为偶数的项权重是 1、为奇数的是 $-1$，整串冲激正负号就乱了，面积也不再是 1。

    * 读图：$\delta(\cos t)$ 是一条以 0 为中心、间隔恒为 $\pi$ 的等权冲激串；$t=0$ 处没有冲激，因为 $\cos 0=1\neq 0$。

    * $\delta(\sin t)$：零点 $t=k\pi$，$f'(t)=\cos t$，$f'(k\pi)=(-1)^k$，绝对值同样恒为 1，结果为 $\displaystyle\sum_k\delta(t-k\pi)$。

* **积分算例**

    * $\displaystyle\int_{-2\pi}^{2\pi}(1+t)\delta(\cos t)\,dt$：区间 $[\pm\frac{5\pi}{2}]$ 处的冲激落在外面，里面只有 $\pm\frac{3\pi}{2}$、$\pm\frac{\pi}{2}$ 四个，权重全为 1。

    * 逐项用抽样性质取值：$\left(1-\frac{3\pi}{2}\right)+\left(1-\frac{\pi}{2}\right)+\left(1+\frac{\pi}{2}\right)+\left(1+\frac{3\pi}{2}\right)=4$。

    * 积分限不是全轴也能用抽样性质：区间外根本没有冲激，区间内的冲激全都落在里面，贡献一分不少。

## 「两个函数相等」的判定

* **三种定义**

    * | 定义 | 怎么说 |
    | :--- | :--- |
    | 定义一 | 对任意 $t_0$，$f_1(t_0)=f_2(t_0)$，则两函数相等 |
    | 定义二 | 两函数只在有限的点上不相等、其他点相等，则相等 |
    | 定义三 | 对任意 $y(t)$，两边乘起来积满全轴相等，则相等 |

* **勒贝格意义下的定义（定义三）**

    * > **定义**：$f_1(t)=f_2(t)$ 当且仅当对任意函数 $y(t)$，都有 $\displaystyle\int_{-\infty}^{+\infty}y(t)f_1(t)\,dt=\int_{-\infty}^{+\infty}y(t)f_2(t)\,dt$。

    * 在黎曼积分框架下说得通：有限个点上不一样，积分值不变。

    * 收敛性上两边必须配套存在，不能一边趋于正无穷而另一边没有。

    * 差了一段区间就不再相等：取 $y(t)=1$ 作反例，两侧积分不等。

* **加权性质的证明**

    * 取 $f_1=x(t)\delta(t)$、$f_2=x(0)\delta(t)$，对任意 $y(t)$ 算两边积分。

    * 左边 $=\big[y(t)x(t)\big]_{t=0}=y(0)x(0)$（把 $y(t)x(t)$ 整体当作被采样函数）。

    * 右边先把常数 $x(0)$ 提出来再走一次抽样性质，也得 $x(0)y(0)$。

    * 难点不在证明本身，而在它所依赖的「两个函数相等」这个定义。

* **阶跃函数在跳变点的取值**

    * $t\ge 0$ 取 1 的 $u_1$ 与 $t>0$ 取 1 的 $u_2$ 只在 $t=0$ 这一个点上不一样，按定义三它们是同一个函数。

    * 所以 $u(0)$ 可以等于 0、可以等于 1、写成 0.37 也行。

* **黎曼积分与勒贝格积分**

    * 黎曼积分是竖着数钱：把 $t$ 轴切成薄竖条，每条取一个函数值乘以条宽求和。

    * 勒贝格积分是横着数钱：把 $y$ 轴切成薄横条，每条取落进这一层的 $t$ 的总宽乘以层厚求和。

    * 凡是能被黎曼积分积出来的函数都能被勒贝格积分积出来，且两个值一样。

    * 狄利克雷函数（有理数处取 1、无理数处取 0）在 $[0,1]$ 上黎曼积不出、勒贝格积分为 0：任何一段小区间里必然既有有理数又有无理数。

    * 换成勒贝格积分后，两个函数在所有无理数上相等、在所有有理数上不相等，仍然可以称为相等——改动落在可数个点上，测度为零。

* **可数与不可数**

    * > **定义**：设 $A$、$B$ 是两个集合，若存在从 $A$ 到 $B$ 的一一映射，就说 $A$ 与 $B$ 一样多（等势），也称基数相同。

    * 一个集合如果与自然数集一样多，就叫可数集（简称可数）。

    * 自然数集与偶数集、整数集、奇数集、有理数集全都一样多；有理数用沿反对角线之字形前进的折线排序排成一串即可。

    * 实数集不可数。反证：假设 $(0,1)$ 可数排成 $x_1,x_2,\dots$，构造 $y$ 使它第 $n$ 位小数与 $x_n$ 的第 $n$ 位不同，则 $y$ 与每个 $x_n$ 都不同，而 $y$ 也是 $(0,1)$ 里的实数，矛盾。

    * $(0,1)$ 与 $(3,7)$、乃至与 $(-\infty,+\infty)$ 一样多，后者可用 $b=\frac{2a}{1-4a^2}$ 这类端点发散的严格单调构造实现。

    * 线段 $[0,1]$ 上的点与整个正方形 $[0,1]^2$ 里的点一样多，靠交错小数：把 $c$ 的奇数位拼成 $a$、偶数位拼成 $b$。

    * > **注意**：这些结论学完记住即可，不要抬杠式地用来质疑单点取值。例如问 $u(3)$ 等于几时，理论上它在单点上可取任意值，但不必真的拿这套去跟常规答案较劲。

* **卷积对「相等」的继承**

    * > **定理**：若 $h_1(t)=h_2(t)$，则对任意 $x(t)$，都有 $x(t)*h_1(t)=x(t)*h_2(t)$。

    * 这个等号不是「逐点相等」那个等号，所以中间「把两个函数逐点代进卷积公式」这一步没有依据，必须老老实实回到定义。

    * 证明四步：展开卷积公式；换元 $\tau'=\tau-t_1$（$t_1$ 有限，上下限纹丝不动）；把 $\tau'$ 改记为 $\tau$（此处用到卷积交换律）；取检验信号 $y(t)=x(t-\tau)$，落在定义三的「任意」合法范围内。

    * 换元那一步最容易写错：不要想成「一个数减掉负无穷变成了正无穷」，那是把常数当成无穷大了。

    * 逆命题同样成立：对任意 $x(t)$ 都有 $x*h_1=x*h_2$，则 $h_1=h_2$。取 $x(t)=\delta(t)$，两边变成 $\int\delta(\tau)h_i(t-\tau)d\tau=h_i(t)$。

    * ⚠️ **易错点**：取的是**输入信号** $x(t)=\delta(t)$，不是「两个函数相等」定义里的**检验信号** $y(t)$；$y$ 不能取 $\delta$，$x$ 可以。这个论证默认卷积积分存在。

## 冲激函数的多样性与那条极限

* **唯一的判定标准**

    * > **定义**：要证明一个函数 $f(t)$ 就是 $\delta(t)$，只需证明对任意函数 $y(t)$ 有 $\displaystyle\int_{-\infty}^{+\infty}y(t)f(t)\,dt=y(0)$。

    * 它由两条拼成：$\delta$ 的抽样性质，加上「两个函数相等」的判定。

    * 「任意」的实际含义是「对所有满足条件的 $y(t)$ 都成立」，不是随便挑一个试试。

    * 脉冲的形状、宽度、高度可以换，只要面积恒为 1、$\varepsilon\to 0$ 时宽 $\to 0$ 高 $\to+\infty$，就收敛到同一个 $\delta(t)$：例如高 $\frac{1}{2\varepsilon}$ 宽 $2\varepsilon$、或高 $\frac{1}{\varepsilon}$ 宽 $\varepsilon$，都对。

* **必须记住的极限**

    * > **结论**：$\displaystyle\lim_{\omega\to+\infty}\frac{\sin\omega t}{\pi t}=\delta(t)$。

    * 形状：$t=0$ 处取极限值 $\frac{\omega}{\pi}$，零点为 $\pm\frac{\pi}{\omega}$、$\pm\frac{2\pi}{\omega}$ 等，且对 $\omega>0$ 有 $\displaystyle\int_{-\infty}^{+\infty}\frac{\sin\omega t}{\pi t}dt=1$。

    * $\omega$ 增大时主峰直冲 $+\infty$，其余各瓣被 $\frac{1}{\omega}$ 压扁到横轴，所有零点朝 0 挤去，整体被无限往里压缩，面积恰好仍是 1。

* **证明所需的引理**

    * > **定义**：只要 $x(t)$ 不是无限震荡函数，就有 $\displaystyle\lim_{\omega\to+\infty}\int_{-\infty}^{+\infty}x(t)\sin(\omega t)dt=0$，$\cos$ 情形同样为零。

    * 机理：相邻的正负半周期里 $x(t)$ 的值大致相同，正负面积成对抵消；只有 $x(t)$ 自身变化比振荡还剧烈（快到无穷）时才抵消不掉。

    * $x(t)$ 可导时可直接分部积分证明；可导只是特别好用的充分条件，不是引理本身的要求。

* **证明的关口**

    * 目标：对任意 $y(t)$，$\displaystyle\lim_{\omega\to+\infty}\int_{-\infty}^{+\infty}y(t)\frac{\sin\omega t}{\pi t}dt=y(0)$。

    * 难点全在 $t=0$：设 $x(t)=\frac{y(t)}{\pi t}$，它从左边趋 $-\infty$、从右边趋 $+\infty$，是货真价实的无限震荡函数，引理的假设在这里被破坏，不能武断地当零处理掉。

    * 做法是等量代换：拆出常数项 $y(0)$，对剩下的 $\frac{y(t)-y(0)}{\pi t}$ 用引理。

    * 换元后剩下的函数在 $t=0$ 处不再发散，由洛必达法则取值为 $\frac{y'(0)}{\pi}$，故不是无限震荡函数。

    * 余下的一片恒等于 $y(0)\times 1=y(0)$，两片相加得证。

* **历史脉络**

    * 1833 年前后狄利克雷用 $\delta(t)$ 证明傅立叶变换中的收敛性；直到 1905 年前后勒贝格开创实变函数才把它彻底讲明白，人类花了 70 多年。

    * 傅立叶约 1807 年发表论文，到 1830 年前后狄利克雷才严格证明傅立叶级数的收敛性。

## 连续信号卷积的计算

* **图解法四步**

    * 离散时间与连续时间的前三步完全一样（翻转、平移、相乘），只有第四步离散叫求和、连续叫积分。

    * 硬把表达式写出来往公式里塞会很郁闷，要结合「移来移去」的直观。

* **单边指数信号的卷积**

    * $x(t)=e^{-bt}u(t)$、$h(t)=e^{-at}u(t)$：$u(\tau)$ 与 $u(t-\tau)$ 共同为 1 的区间是 $0<\tau<t$。

    * > **提示**：这两个 $u$ 改变的是积分限，不是被积函数本身。

    * $t<0$ 时区间 $0<\tau<t$ 不存在，卷积恒为零；$t>0$ 时

    $$y(t)=\int_{0}^{t}e^{-b\tau}e^{-a(t-\tau)}d\tau=e^{-at}\int_0^t e^{(a-b)\tau}d\tau$$

    * 结果：$$y(t)=\frac{e^{-at}-e^{-bt}}{b-a}\,u(t)$$

    * ⚠️ **易错点**：代换 $t\to\tau$ 时别带错符号，$x(\tau)$ 里是 $-b\tau$，$h(t-\tau)$ 里是 $-a(t-\tau)=-at+a\tau$，里面的 $\tau$ 带正号。

    * 最后乘一个 $u(t)$ 把 $t<0$ 那段直接归零，是一个式子全包住的常用技巧。

* **矩形卷三角形**

    * $x(t)$ 是 $[0,1]$ 上高度为 1 的矩形，$h(t)$ 是 $[0,1]$ 上的三角形、峰值 1 落在 $t=0$ 处向右下降。

    * 范围：$y$ 只在 $[0,2]$ 上有值。

    * 翻转后的 $h$ 落在 $[-1,0]$ 上，向前平移 $t$ 个单位后落在 $[t-1,t]$，沿 45° 斜边升到 $\tau=t$ 处高度 1。

    * 剩下的事情就是数重叠的阴影面积。

    * | 区间 | 重叠形状 | $y(t)$ |
    | :--- | :--- | :--- |
    | $t<0$ 或 $t>2$ | 无重叠 | $0$ |
    | $0<t<1$ | 梯形（平行边 $1-t$ 与 $1$，高 $t$） | $\dfrac{t(2-t)}{2}$ |
    | $1<t<2$ | 三角形（底与高均为 $2-t$） | $\dfrac{(2-t)^2}{2}$ |

    * 形状：从 $t=0$ 起来一路朝上弯，$t=1$ 处取到最大值 $\frac12$，然后对称降回零。

* **临界点验算**

    * > **结论**：除非 $x(t)$ 或 $h(t)$ 里有冲激函数（有跳变），否则卷积积分不会跳变，在所有临界点上必然连续。

    * 机理：积分是平滑过程，端点挪动一点点，积分值只会变一点点，不可能突然蹦一下。

    * 三处临界点都验一遍：$t=0$ 两侧都是 0，$t=1$ 两侧都是 $\frac12$，$t=2$ 两侧都是 0。

    * 验不过就说明某一段的重叠形状画错了——初版把梯形的左底写成 $t$，正确的是 $1-t$。

* **方波与方波**

    * > **结论**：两个宽度一致的方波，卷积是三角波；两个宽度不一致的方波，卷积是梯形波。

    * 一般情形：$x(t)$ 在 $[-a,a]$ 上高 $e_1$、$h(t)$ 在 $[-b,b]$ 上高 $e_2$，$a>b$。

    * 四个关键点：左端 $-(a+b)$、平台左端 $b-a$、平台右端 $a-b$、右端 $a+b$。

    * 平台高度：$2b\,e_1\,e_2$（小波宽度 $2b$ 乘两个波的高度）。

    * 平台右端的算法：$(b-a)+2a-2b=a-b$。

    * 因为 $b-a$ 与 $a-b$ 互为相反数，这个梯形是等腰的。

    * 特别地，$x$ 与 $h$ 均为 $[-t_0,t_0]$ 上高 1 的方波，卷积是三角波，支撑 $[-2t_0,2t_0]$，峰值 $2t_0$ 落在 $t=0$。

    * 峰值高度一律按「短波宽度 $\times$ 两个波的高度」计算，落在两个方波支撑的中间位置。

    * 斜坡段之所以是直线：底下移动多少个单位，重叠面积就相应变化多少，是线性关系。

### 方波卷积的算例

    * $x$ 在 $[-3,3]$（宽 6）、$h$ 在 $[-1,1]$（宽 2），高度都取 1：支撑 $[-4,4]$，峰值出现在 $t=-2$（起始 $-4$ 加上短波宽度 2），峰值 $2\times1\times1=2$。

    * 从 $-2$ 开始有四个单位的平台保持 2 不变（长波宽度 6 减短波宽度 2），一直到 $t=2$；再右移 2 个单位于 $t=4$ 归零。

    * 考试难度的多段方波：$x$ 在 $[-2,-1]$ 上为 1、$[-1,0]$ 上为 $-2$，$h$ 在 $[0,1]$ 上为 1、$[1,2]$ 上为 2。

    * 关键点：翻转后 $h$ 在 $[-2,-1]$ 上是 2、$[-1,0]$ 上是 1；$y(-2)=0$、$y(-1)=1$、$y(0)=2-2=0$、$y(1)=-2\times 2=-4$、$y(2)=0$。

    * 中间各段都是直线拉到底，答案就是 $(-2,0)$、$(-1,1)$、$(0,0)$、$(1,-4)$、$(2,0)$ 连成的折线，区间之外恒为 0。

    * 做题三个要点：不要求难；把几个关键点的值算出来；这种多个方波叠加的卷积中间各段全是直线。

    * 定取值范围永远是第一步，不要一上来就发挥想象力画图。

* **周期方波卷三角脉冲**

    * $x(t)$ 是周期 2 的方波（$[0,1]$ 上取 1、$[1,2]$ 上取 $-1$），$h(t)$ 是宽 2、高 1 的三角脉冲（$h(0)=0$、$h(1)=1$、$h(2)=0$）。

    * $x$ 无穷长但周期为 2，卷积结果也是周期 2 的函数，只画一个周期即可。

    * $t=0$ 处由 $0+1-1$ 得 0；$t=1$ 处 $1^2+0^2-1=0$，与另一段 $1-0^2-1^2=0$ 接得上。

    * $0\le t\le 1$：三角被切成两块红（对应 $x=+1$）与一块绿（对应 $x=-1$），红色面积之和减去绿色面积

    $$y(t)=\frac{t^2}{2}+\frac{(1-t)^2}{2}-\Big(1-\frac{t^2}{2}-\frac{(1-t)^2}{2}\Big)=t^2+(1-t)^2-1$$

    * $1\le t\le 2$：角色互换，绿色面积减去两块红色面积

    $$y(t)=1-(t-1)^2-(2-t)^2$$

    * 形状：$t=0$ 为 0，下行到 $t=0.5$ 的 $-0.5$，回到 $t=1$ 的 0，上行到 $t=1.5$ 的 $0.5$，$t=2$ 回到 0，然后以 2 为周期重复。

* **冲激随自变量变换时的幅度**

    * 已知含一个两倍冲激和一段 $[2,4]$ 的矩形，求 $x\!\left(\frac32-\frac t2\right)$。

    * 矩形的四步：翻转（$[2,4]\to[-4,-2]$）、伸缩（系数 $\left|-\frac12\right|<1$，拉伸 2 倍到 $[-8,-4]$）、平移（$-\frac ba=3$，右移 3 格到 $[-5,-1]$）、高度不变。

    * 系数小于一是拉伸、系数大于一是收缩。

    * ⚠️ **易错点**：这道题最容易错的不是位置而是**幅度**。$2\delta(t-1)$ 带进去得 $2\delta\!\left(-\frac12(t-1)\right)=\frac{2}{|-\frac12|}\delta(t-1)=4\delta(t-1)$。

    * 结论：$\delta$ 拉伸两倍则幅度乘上两倍，压缩两倍则幅度下降两倍。

## 卷积的代数性质

* **交换律**

    * > **结论**：$x(t)*h(t)=h(t)*x(t)$，离散为 $x[n]*h[n]=h[n]*x[n]$。

    * 证明：令 $\tau'=t-\tau$，则 $\tau=t-\tau'$、$d\tau=-d\tau'$，$\tau=-\infty$ 对应 $\tau'=+\infty$、$\tau=+\infty$ 对应 $\tau'=-\infty$；$d\tau$ 带出的负号正好把倒过来的积分限再翻回去。

    * 系统角度：一个框把 $x$ 送进去、冲激响应是 $h$；另一个把 $h$ 送进去、冲激响应是 $x$。两个输出相等，说明这两个 LTI 系统其实是同一个系统。

    * 镜像理解：镜前看到的是 $x$ 的正面和 $h$ 的背面，镜后看到的是 $h$ 的正面和 $x$ 的背面；运动是相对的，翻转哪一个不影响重叠面积，交换律天然成立。这套理解对连续与离散一样管用。

    * $y$ 的取值范围也不因交换而改变。

* **结合律**

    * > **结论**：$[x(t)*h_1(t)]*h_2(t)=x(t)*[h_1(t)*h_2(t)]$。

    * 与交换律合起来意味着所有卷积项可以任意调换位置，项数再多结果都一样。

    * 难的做法：从左边出发作换元 $\tau_1'=\tau_1$、$\tau_2'=\tau_2-\tau_1$，雅可比行列式 $J=\left|\begin{smallmatrix}1&0\\1&1\end{smallmatrix}\right|=1$，积分区域与测度都不变；右边作完全一样的换元得到同一式式，所有撇号都可去掉。

    * 漂亮的做法：只要证明红框（先过 $h_1$ 再过 $h_2$）与绿框（先过 $h_2$ 再过 $h_1$）框出的两个系统是同一个系统。

    * 依据是两条：两者都是 LTI（串联与并联保持 LTI）；给两者都喂 $\delta(t)$，输出分别是 $\delta*h_1*h_2=h_1*h_2$ 与 $h_2*h_1$，由交换律相等，而 $\delta$ 是 LTI 的唯一标识。

* **分配律**

    * > **结论**：$x(t)*[h_1(t)+h_2(t)]=x(t)*h_1(t)+x(t)*h_2(t)$。

    * 不必另证：卷积定义里本来是一次积分（离散是一次求和），积分与求和都有分配性，把分配性带进去公式自己就出来了。

### 值得单独记的公式

* **方波等于两个阶跃之差**

    * > **结论**：从 $a$ 到 $b$ 的方波 $=u(t-a)-u(t-b)$。

    * 记不住这条的题会被展开成四项，每项都要单独积。$[u(t-1)-u(t-3)]*[u(t+1)-u(t-1)]$ 一眼就是两个宽 2、高 1 的等宽方波：起点 0、终点 4、顶点 $t=2$、顶点高度 2。

* **与单位阶跃卷积**

    * > **结论**：$x(t)*u(t)=\displaystyle\int_{-\infty}^{t}x(\tau)d\tau$，$x[n]*u[n]=\displaystyle\sum_{k=-\infty}^{n}x[k]$。

    * 离散那个叫累加器。

    * 推法：$u(t-\tau)$ 只在 $t-\tau>0$ 即 $\tau<t$ 时等于 1，积分上限被 $t$ 卡死。

    * 图形上就是每平移一次就把重叠的部分积起来，平移到 $t$ 就等于把 $x$ 从 $-\infty$ 到 $t$ 全积过来。

* **微分搬进卷积**

    * > **结论**：$\dfrac{d}{dt}[x(t)*h(t)]=x'(t)*h(t)=x(t)*h'(t)$。

    * 搭桥的是微分器：它是 LTI，喂 $\delta$ 出来 $\delta'(t)$，所以它的冲激响应是 $h_D(t)=\delta'(t)$。

    * 推导全程只用了微分器的冲激响应与卷积的交换律、结合律。

* **卷积的时移不变性**

    * > **结论**：$x(t+t_0)*h(t-t_0)=x(t)*h(t)$。

    * $x$ 左移 $t_0$、$h$ 右移 $t_0$，两者「最左端之和」与「最右端之和」都不变。

    * 卷积过程是翻转、平移、逐点相乘累加，$x$ 与 $h$ 的形状没动、下标关系没动，所以每个累加点上的值都没变。

* **三道极易混淆的题**

    * ① $x(t+2)\cdot\delta(t-3)=x(5)\,\delta(t-3)$：这里是**乘**，$\delta$ 的冲激性质不参与运算，$\delta$ 得原样留着。

    * ② $\int_{-\infty}^{\infty}x(t+2)\delta(t-3)dt=x(5)$：多一个积分，$\delta$ 被积没了，结果是一个数而不是函数。

    * ③ $x(t+2)*\delta(t-3)=x(t-1)$：这里是**卷积**，左移 2 与右移 3 移量不等，不能套时移不变性；展开得 $\int x(t+2-\tau)\delta(\tau-3)d\tau=x(t-1)$。

    * ⚠️ **易错点**：① 写成 $x(5)$ 就把 $\delta$ 弄丢了，等于把 ① 直接做成了 ② 的答案。

    * 三问的答案分别是「信号、常数、信号」，形状像但完全不是一路东西。

## LTI 系统的稳定性与因果性

* **稳定性**

    * > **定义**：稳定就是有界输入换来有界输出。

    * > **结论**：LTI 系统稳定 $\iff\displaystyle\int_{-\infty}^{+\infty}|h(t)|dt<\infty$，离散为 $\displaystyle\sum_n|h(n)|<\infty$。

    * 这是充要条件，两头都得证。

    * 充分性：用交换律先对调 $x$ 与 $h$，再取绝对值，$|y(t)|\le\int|h(\tau)||x(t-\tau)|d\tau\le M\int|h(\tau)|d\tau<\infty$，第一步用积分绝对值不等式。

    * 必要性：利用「任意」二字专门挑一个与 $h$ 对着干的有界输入 $x(\tau)=+1$ 当 $h(-\tau)<0$、$-1$ 当 $h(-\tau)>0$，绝对值恒为 1。

    * 这样 $y(0)=\int x(-\tau)h(\tau)d\tau=-\int|h(\tau)|d\tau$，两边取绝对值得 $|y(0)|=\int|h(\tau)|d\tau$；系统稳定使 $y(0)$ 有界，积分就被卡住了。

    * ⚠️ **易错点**：这条定理只对 LTI 有效。用之前先回头确认这个系统到底时不变。

* **因果性**

    * > **定义**：输出 $y(t)$ 只由 $t$ 时刻及以前的输入决定。

    * > **结论**：LTI 系统因果 $\iff h(t)=0$（$t<0$），离散为 $h(n)=0$（$n<0$）。

    * 充分性：$y(t_0)=\int_{-\infty}^{\infty}x(\tau)h(t_0-\tau)d\tau$ 中，$\tau>t_0$ 时 $t_0-\tau<0$，只要 $h$ 在负半轴恒为零，右边这一整段积分就是零，于是 $y(t_0)=\int_{-\infty}^{t_0}x(\tau)h(t_0-\tau)d\tau$。

    * 必要性：若 $h$ 在 $t<0$ 处不为零，取 $t^*<0$ 使 $h(t^*)\neq 0$，则 $\tau=t_0-t^*>t_0$ 处的输入就能影响 $y(t_0)$，因果被破坏。

    * 图解上：翻转平移后的 $h(t_0-\tau)$ 在 $\tau>t_0$ 处恒为零，$y(t_0)$ 只用到 $x$ 在 $t_0$ 之前的那一段。

    * > **提示**：有人会问「$h$ 在 $t<0$ 处孤零零来一个值，$t=-1$ 那种，这个定理岂不是不成立」——按「两个函数相等」的定义，孤立的点不影响积分，在那里放一个孤立值和不放是同一个函数，卷积积分里本来就取不到那个点。

## 为什么叫「卷积」

* **命名来源**

    * 把积分写成 $\int_{-\infty}^{+\infty}x(\tau)h\bigl(-(\tau-t)\bigr)d\tau$，括号拆开负号在最外面、再减去 $t$。

    * 负号即沿纵轴翻转，减去 $t$ 即平移，相乘、求和（或积分）跟在后面，四步合起来是：翻转、平移、相乘、求和。

    * 「卷」指翻转、「积」指相乘，正好各取四步中的一步。

    * 英文 convolution，这个词被认为是工程与科学领域翻译得最好的译名之一。

## 卷积公式的最终形态

* **离散与连续并列**

    * 离散：$x[n]*h[n]=\displaystyle\sum_{k=-\infty}^{+\infty}x[k]h[n-k]$。

    * 连续：$x(t)*h(t)=\displaystyle\int_{-\infty}^{+\infty}x(\tau)h(t-\tau)d\tau$。

* **两者可互推**

    * 把离散公式里的求和项换成宽度 $\Delta$ 的横条、令 $\Delta\to 0$，求和就变成黎曼和，黎曼和就是积分，连续公式直接掉出来。

* **共同的操作内核**

    * 翻转、平移、相乘、求和（连续为积分），四步对连续与离散完全一致。
