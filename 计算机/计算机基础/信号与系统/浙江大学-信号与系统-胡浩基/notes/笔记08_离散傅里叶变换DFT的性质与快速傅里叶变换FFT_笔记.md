# 离散傅里叶变换DFT的性质与快速傅里叶变换FFT

## 周期信号的傅里叶级数与傅里叶变换

* **用傅里叶变换反求级数系数**

    * > **定义**：周期为 $T$ 的信号 $x(t)$，其复指数傅里叶级数系数等于它一个周期的傅里叶变换在 $k\omega_0$ 处采样后再除以 $T$，即 $a_k=\dfrac{1}{T}X(jk\omega_0)$。

    * 起点是级数系数定义式 $a_k=\dfrac{1}{T}\displaystyle\int_{-T/2}^{T/2}x(t)e^{-jk\omega_0t}\,\mathrm dt$，积分区间只能取一个周期。

    * 把这个积分看成「一个周期内的傅里叶变换」，只要令 $\omega=k\omega_0$、整体除以 $T$，桥梁公式立刻得到。

    * 完整动作链：求一个周期的傅里叶变换 → 在 $k\omega_0$ 处采样 → 除以 $T$ → 代回级数合成 $x(t)$ → 对 $x(t)$ 再做一次变换得冲激串。

    * $\omega_0=2\pi/T$，分母上的 $T$ 就是信号整周期长度。

    * > **易错点**：$\omega_0$ 是 $2\pi$ 除以**周期**，不是 $2\pi$ 乘以周期；做题时手里常常还捏着脉冲宽度 $T_1$，两个 $T$ 极易串味。

    * 选哪一段周期都可以：换成别的一段相当于整体平移 $t_0$，变换多乘 $e^{-j\omega t_0}$；位移量取周期的整数倍时该因子恒等于 $1$，两种做法算出的 $a_k$ 没有差别。

* **周期方波与周期三角脉冲的系数**

    * 周期方波（高 1、宽 $2T_1$，$t$ 从 $-T_1$ 到 $T_1$）单周期变换 $P(j\omega)=\dfrac{2\sin(\omega T_1)}{\omega}=2T_1\dfrac{\sin(T_1\omega)}{T_1\omega}$。

    * 代入桥梁公式得 $a_k=\dfrac{\sin\left(\frac{2k\pi T_1}{T}\right)}{k\pi}$，$a_0=\dfrac{2T_1}{T}$；$a_0$ 直接代 $k=0$ 会得到 $0/0$，必须取极限。

    * $a_0$ 的一般直觉校验：一个周期内的面积除以周期。矩形得 $2T_1/T$，三角得 $T_1/(2T)$。

    * 周期三角脉冲单周期变换 $P(j\omega)=\dfrac{8\sin^2\left(\frac{T_1\omega}{4}\right)}{T_1\omega^2}$，$\omega\to0$ 时回到 $T_1/2$，与面积自洽。

    * 系数为 $a_k=\dfrac{2T\sin^2\left(\frac{k\pi T_1}{2T}\right)}{k^2\pi^2T_1}$，$a_0=\dfrac{T_1}{2T}$。

    * 两者的 $a_k$ 都是偶序列：分子 $\sin(\cdot)$ 与分母 $k$ 同为奇函数，相除得偶，因此正负 $k$ 的 $\sin$ 项对消、$\cos$ 项加倍合并，可直接写成实形式级数。

* **周期信号自身的傅里叶变换**

    * > **定义**：$X(j\omega)=2\pi\displaystyle\sum_{k=-\infty}^{+\infty}a_k\,\delta\!\left(\omega-k\omega_0\right)$。

    * 推导只有一步：把 $x(t)$ 写成复指数级数，对每一项用平移性质，由 $\mathcal{F}\{1\}=2\pi\delta(\omega)$ 得 $\mathcal{F}\{e^{jk\omega_0t}\}=2\pi\delta(\omega-k\omega_0)$。

    * 这个式子里 $k=0$ 那一项是 $a_0$ 乘 $2\pi\delta(\omega)$；方波例（$T=4T_1$）中 $a_k=\dfrac{\sin(k\pi/2)}{k\pi}$、$a_0=\dfrac12$，变换为 $2\displaystyle\sum_k\dfrac{\sin(k\pi/2)}{k}\delta(\omega-k\omega_0)$。

    * > **易错点**：单周期的变换 $P(j\omega)$ 不是整个周期信号的 $X(j\omega)$，它只是其中一段的傅里叶变换，不能当最终答案。

    * 傅里叶级数的性质本身不另证：既然 $a_k$ 就是傅里叶变换在 $k\omega_0$ 处的采样，那么级数的绝大多数性质都能直接从已经很熟的变换性质「翻译」出来。

* **周期冲激串**

    * > **定义**：$\delta_T(t)=\displaystyle\sum_{k=-\infty}^{\infty}\delta(t-kT)$，其傅里叶变换为 $X(j\omega)=\dfrac{2\pi}{T}\displaystyle\sum_{k=-\infty}^{\infty}\delta(\omega-k\omega_0)$。

    * 单周期内只有 $\delta(t)$ 一个冲激，$P(j\omega)=1$，故 $a_k=1/T$ 对一切 $k$ 成立。

    * 时域是周期为 $T$ 的冲激串，频域仍是周期冲激串：周期变为 $\omega_0=2\pi/T$，每个冲激的强度为 $2\pi/T$，而 $2\pi/T$ 正好又等于 $\omega_0$。

    ```text
        时域：周期 T 的冲激串，每个 δ 的强度都是 1

                  ↑     ↑     ↑
              ────┼─────┼─────┼────
                 −2T    0     T
                ←──── T ────→
                        │
                        │   F
                        ▼
        频域：周期 ω₀ = 2π/T 的冲激串，每个 δ 的强度都是 2π/T = ω₀

                  ↑     ↑     ↑
              ────┼─────┼─────┼────
                −2ω₀   0    ω₀
              ←───── ω₀ ─────→
    ```

## 离散时间信号的傅里叶变换

* **符号约定**

    * > **定义**：连续信号 $x(t)$ 的傅里叶变换记作 $X(j\omega)$，离散信号 $x[n]$ 的傅里叶变换记作 $X_1(j\omega)$，这是一个纯人为的区分规定。

    * $X(j\omega)$ 的反变换是连续的 $x(t)$，$X_1(j\omega)$ 的反变换是离散的 $x[n]$。

    * > **易错点**：两者自变量都是 $\omega$，只靠下标 $1$ 区分；做题做到一半把连续结论写成 $x[n]$ 就全错了。每道题动笔前先在脑子里过一遍这个对应关系。

* **变换对本身**

    * > **定义**：离散时间信号的傅里叶变换由一对公式构成：$X_1(j\omega)=\displaystyle\sum_{n=-\infty}^{+\infty}x[n]e^{-j\omega n}$ 与 $x[n]=\dfrac{1}{2\pi}\displaystyle\int_{2\pi\text{ 周期}}X_1(j\omega)e^{j\omega n}\,\mathrm d\omega$。

    * 正变换是**求和**，不是积分。

    * $X_1(j\omega)$ 是以 $2\pi$ 为周期的**连续**函数，这是它与连续傅里叶变换最大的结构差异。

    * 反变换的积分区间可取 $[-\pi,\pi]$，也可取 $0\to2\pi$ 或任何起点加上 $2\pi$ 的区间，结果完全一样。

    * $e^{j\omega n}$ 本身也以 $\omega$ 为变量、以 $2\pi$ 为周期，两个 $2\pi$ 周期函数相乘仍是 $2\pi$ 周期，所以「在一个周期内积分」这一步成立。

* **周期性与反变换的证明**

    * $2\pi$ 周期性的关键一步：$X_1(j\omega+2k\pi)$ 中多出因子 $e^{-j2kn\pi}$，而 $2kn$ 是偶整数，故该因子恒等于 $1$。

    * 反变换证明中把正变换里的下标改记为 $k$（目标下标 $n$ 不能重名），然后交换求和与积分次序。

    * 剩下的核函数 $\displaystyle\int_{2\pi}e^{j\omega(n-k)}\,\mathrm d\omega$ 只认 $n=k$：$n=k$ 时积分为 $2\pi$；$n\neq k$ 时被积函数为等比数列，取原函数后上下限指数相差 $2\pi(n-k)$，因子 $e^{-j2\pi(n-k)}=1$，两指数项相减为零。

    * 代回后整个和式里只有 $n$ 这一项活下来，外面的 $\frac{1}{2\pi}$ 与 $2\pi$ 正好约掉，$x[n]$ 原样还原。

    * 整条链条只靠三件事：下标是整数所以频谱 $2\pi$ 周期、$e^{j\omega n}$ 也 $2\pi$ 周期所以积分可取任意一个周期、周期函数在整周期上的积分把 $k\neq n$ 的项一次性筛掉。

* **七个典型变换对**

    | $x[n]$ | $X(e^{j\omega})$ |
    | :--- | :--- |
    | $a^n u[n]$ | $\dfrac{1}{1-ae^{-j\omega}},\ \lvert a\rvert<1$ |
    | $\delta[n]$ | $1$ |
    | $1$ | $2\pi\displaystyle\sum_{k=-\infty}^{\infty}\delta(\omega-2k\pi)$ |
    | $u[n+n_1]-u[n-n_1-1]$ | $\dfrac{\sin\left[\left(n_1+\tfrac12\right)\omega\right]}{\sin\tfrac{\omega}{2}}$ |
    | $\dfrac{\sin(\omega_0 n)}{\pi n}$ | $1,\ \lvert\omega\rvert<\omega_0$（$2\pi$ 周期重复） |
    | $u[n]$ | $\dfrac{1}{1-e^{-j\omega}}+\pi\displaystyle\sum_{k=-\infty}^{\infty}\delta(\omega-2k\pi)$ |
    | $\cos(\omega_0 n)$ | $\pi\displaystyle\sum_{k}\left[\delta(\omega-\omega_0-2k\pi)+\delta(\omega+\omega_0-2k\pi)\right]$ |
    | $\sin(\omega_0 n)$ | $j\pi\displaystyle\sum_{k}\left[\delta(\omega-\omega_0-2k\pi)-\delta(\omega+\omega_0-2k\pi)\right]$ |

    * 这七个与连续时间的七个一一对应，背熟它们是后面所有推导和做题的入口；做题真正用到的往往只有第一条加线性、平移。

    * > **易错点**：$\delta[t]$ 是一个**冲击**，$\delta[n]$ 只是一个「零处为 1、别处为 0」的普通离散序列；式子写法相同，来路和含义不同，不要混。

    * 常数序列 $1$ 在离散里不能画成一条横线，它是**每一个离散点都等于 1**；频谱是在 $\omega=0,\pm2\pi,\pm4\pi,\dots$ 处各有一根高 $2\pi$ 的冲激。

* **单边指数衰减 $a^n u[n]$**

    * $u[n]$ 把负半轴清零，求和下限可由 $-\infty$ 改成 $0$，得到等比数列 $\displaystyle\sum_{n=0}^{\infty}(ae^{-j\omega})^n$；因 $\lvert a\rvert<1$，末项极限为零，故 $X(e^{j\omega})=\dfrac{1}{1-ae^{-j\omega}}$。

    * 幅度谱 $\lvert X(e^{j\omega})\rvert=\dfrac{1}{\sqrt{1+a^2-2a\cos\omega}}$，相位谱 $\theta(\omega)=-\arctan\dfrac{a\sin\omega}{1-a\cos\omega}$。

    * $a>0$ 时：峰值 $\dfrac{1}{1-a}$ 落在 $\omega=0,\pm2\pi,\pm4\pi,\dots$，谷值 $\dfrac{1}{1+a}$ 落在 $\omega=\pm\pi,\pm3\pi,\dots$；$a<0$ 时最高点与最低点刚好互换。

    * 与连续的 $e^{-at}u[t]\longleftrightarrow\dfrac{1}{a+j\omega}$（$a>0$）配对：两者核心物理内容一致，只是一个离散、一个连续。

* **矩形序列**

    * $x[n]$ 从 $-n_1$ 到 $n_1$ 全为 1，写成 $u[n+n_1]-u[n-n_1-1]$，其变换为 $\dfrac{\sin\left[\left(n_1+\tfrac12\right)\omega\right]}{\sin\tfrac{\omega}{2}}$。

    * 推导只靠两招：把 $\sum_{n=-n_1}^{n_1}e^{-j\omega n}$ 按 $n=0$ 与正负配对拆成 $1+2\cos\omega+2\cos2\omega+\cdots+2\cos n_1\omega$；再乘 $\sin\tfrac{\omega}{2}$ 用积化和差把所有中间项逐个约掉，只剩最后一项 $\sin\left[\left(n_1+\tfrac12\right)\omega\right]$。

    * $\omega=0$ 处分子分母同时为零，取极限得 $\dfrac{n_1+\tfrac12}{\tfrac12}=2n_1+1$；也可直接把 $\omega=0$ 代进定义式，数出 $2n_1+1$ 个 1，两者一致。

    * 它的 $2\pi$ 周期性值得单独一说：把 $\omega$ 换成 $\omega+2k\pi$ 后分子分母各自都带一个 $(-1)^k$（用到 $\sin(\theta+k\pi)=(-1)^k\sin\theta$），上下约掉才得到 $2\pi$ 周期。**分子与分母单独看都不是 $2\pi$ 周期的**，各自只以 $4\pi$ 为周期。

* **抽样函数与它的方波**

    * > **定义**：把自变量写成 $x$，$\dfrac{\sin(\Omega_0 x)}{\pi x}$ 称为抽样函数，它是唯一一个「连续时积分、离散时求和给出同一个值」的函数。

    * 右推左一行搞定：$x[n]=\dfrac{1}{2\pi}\displaystyle\int_{-\Omega_0}^{\Omega_0}e^{j\omega n}\,\mathrm d\omega=\dfrac{\sin(\Omega_0 n)}{\pi n}$。

    * 左推右要先求导去掉 $n$，得 $f'(\Omega)=\displaystyle\sum_k\left[\delta(\Omega+\Omega_0-2k\pi)-\delta(\Omega-\Omega_0-2k\pi)\right]$；再积分回去得 $\displaystyle f(\Omega)=f(0)+\sum_k\left[u(\Omega+\Omega_0-2k\pi)-u(\Omega-\Omega_0-2k\pi)\right]$。

    * 常数由经典和式定出：$f(0)=\dfrac{\Omega_0}{\pi}+\dfrac{2}{\pi}\displaystyle\sum_{n=1}^{\infty}\dfrac{\sin(n\Omega_0)}{n}=1$。

    * 在 $[-\pi,\pi]$ 上数冲激个数即得方波：中间 $|\Omega|<\Omega_0$ 为 1，两侧为 0，$\pm2\pi$ 处的冲激负责把曲线接起来。

    * 第二条路是拆奇偶：$\dfrac{\sin(\Omega_0n)}{n}$ 偶、$\sin(\Omega n)$ 奇，虚部整支归零，只剩实部。

    * $n=0$ 处取极限 $x[0]=\dfrac{\Omega_0}{\pi}$。

    * 成立条件是 $0<\Omega_0<\pi$；一旦 $\Omega_0$ 跑出这个区间，上面的方波结论就要打折扣。

* **$\Omega_0$ 出界以后的通用处理**

    * 第一步：减去若干个 $2k\pi$，把 $\Omega_0$ 折回 $(-\pi,\pi)$，依据是 $\sin\big((\Omega_0+2k\pi)n\big)=\sin(\Omega_0 n)$ 对整数 $n$ 恒成立。

    * 第二步：若折完落在负半轴，把负号提到前面。

    * 第三步：折的过程在 $n=0$ 处不成立，那边差多少就补上多少倍的 $\delta$。

    * 第四步：用线性性质把这个 $\delta$ 加进去。

    * $\Omega_0=-\dfrac{\pi}{4}$：负号提到最前，$n=0$ 处一起翻，**不需要补 $\delta$**，结果是第一题方波整体取负。

    * $\Omega_0=\dfrac{5\pi}{4}$：$\sin\left(\frac{5\pi}{4}n\right)=-\sin\left(\frac{3\pi}{4}n\right)$，两边在 $n=0$ 的极限分别是 $\dfrac54$ 与 $-\dfrac34$，差 $2$，故 $x[n]=-\dfrac{\sin\left(\frac{3\pi}{4}n\right)}{\pi n}+2\delta[n]$；频谱是 $\left(-\frac{3\pi}{4},\frac{3\pi}{4}\right)$ 上为 1、两侧为 2 的方波。

    * $\Omega_0=\dfrac{9\pi}{4}$：折回 $\dfrac{\pi}{4}$，$n=0$ 处极限 $\dfrac94$ 与 $\dfrac14$ 差 $2$，补 $2\delta[n]$；频谱是 $\left(-\frac{\pi}{4},\frac{\pi}{4}\right)$ 上为 3、两侧为 2。

    * 另一条等价算法：直接按原 $\Omega_0$ 套「中间为 1 的方波」，再按 $2\pi$ 复制并在 $[-\pi,\pi]$ 内数重叠。两种算法必给同一答案，因为频谱天生 $2\pi$ 周期，而时域拆开分别变换再相加与频域整体观察本是一回事。

    * > **易错点**：$\delta[n]$ 的变换是与频率无关的常数，所以「抬高 $2$」是整条曲线一起抬，不是只抬中间那一段。

* **单位阶跃序列与临界点**

    * $u[n]$ 的变换为 $\dfrac{1}{1-e^{-j\Omega}}+\pi\displaystyle\sum_k\delta(\Omega-2k\pi)$；后一项是把 $e^{-jN\Omega}$ 拆成余弦正弦后，正弦部分收敛成狄利克雷梳的结果。

    * 连续侧一一对应：$u(t)\longleftrightarrow\dfrac{1}{j\omega}+\pi\delta(\omega)$。

    * 四个式子串起来看：$\lvert a\rvert<1$ 时级数绝对收敛、不出现 $\delta$ 项；离散侧临界点 $a=1$、连续侧临界点 $a=0$，两处的**非 $\delta$ 项都是把 $a$ 代进 $\dfrac{1}{1-ae^{-j\Omega}}$ 得到的**，$\delta$ 项则是新冒出来的。

    * 两个 $\delta$ 项形状相同——$0$ 处一个冲激、按 $2\pi$ 复制一串；离散写成 $\sum_k\delta(\Omega-2k\pi)$、连续写成 $\pi\delta(\omega)$，只是同一件事的两种记法。

* **常数序列 $1$ 的频谱画法**

    * 从逆变换入手最省事：$[-\pi,\pi]$ 内只有一个冲激落在 $\omega=0$，用 $\displaystyle\int_{-\pi}^{\pi}\delta(\omega)f(\omega)\,\mathrm d\omega=f(0)$ 一行得 $x[n]=1$。

    * 反过来从 $\sum_{n=-\infty}^{\infty}e^{-j\omega n}$ 出发，前两步（拆成 $1+2\cos\omega+2\cos2\omega+\cdots$、再乘 $\sin\tfrac\omega2$ 逐项约分）需要掌握，后面证明它等于冲激串要用到勒贝格积分公式，篇幅很长，只需记住结论。

    * 推荐的画法是「一个周期 + 两条虚线」：只画 $[-\pi,\pi]$，在 $\pm\pi$ 处标出周期边线，说明其余部分按 $2\pi$ 重复，这与把 $[-2\pi,2\pi]$ 全画出来完全等价。

## DFT 的性质

* **线性**

    * $a x_1[n]+b x_2[n]\longleftrightarrow aX_1(e^{j\omega})+bX_2(e^{j\omega})$，即齐次性加叠加性，与连续完全一致。

    * 实用价值在于它允许「看到任何一个 $\omega$ 的表达式就放心拆成几块分别变换再加起来」；做题习惯是先看出答案的结构组合，再去核对系数，而不是先硬凑。

    * 典型应用：频谱外圈为 1、中间为 2 的形状可直接写成 $\dfrac{\sin\left(\frac14\pi n\right)}{\pi n}+\delta[n]$。

* **符号函数的变换**

    * > **定义**：$n>0$ 时为 $1$、$n=0$ 时为 $0$、$n<0$ 时为 $-1$ 的序列 $\mathrm{sgn}[n]$。

    * > **易错点**：离散侧**不能**照抄 $\mathrm{sgn}(t)=2u(t)-1$。因为离散里 $u[0]=1$，$n=0$ 处 $2u[n]-1=1$ 而 $\mathrm{sgn}[0]$ 要求是 $0$，必须再减一个 $\delta[n]$：$\mathrm{sgn}[n]=2u[n]-1-\delta[n]$。连续里没有这个坑，因为 $u(t)$ 在 $t=0$ 的取值根本不参与积分。

    * 代入三对公式后两坨 $\pi$ 冲激正好约掉，得 $\dfrac{2}{1-e^{-j\omega}}-1=\dfrac{1+e^{-j\omega}}{1-e^{-j\omega}}$。

    * 用**配方**技巧把分子分母同乘 $e^{-j\frac{\omega}{2}}$，括号内立刻凑成 $\cos$ 与 $\sin$，得 $\dfrac{1}{j\tan\left(\frac{\omega}{2}\right)}=-j\cot\dfrac{\omega}{2}$。

    * 之所以非化到底不可：$\mathrm{sgn}[n]$ 是实奇函数，实奇的变换必须是虚奇的；先判断奇偶性往往直接告诉你该往哪个方向化。

* **时域平移与频域平移**

    * $x[n-n_0]\longleftrightarrow X(e^{j\omega})e^{-j\omega n_0}$，证明是一次换元 $n'=n-n_0$；$n$ 从 $-\infty$ 到 $+\infty$ 减去有限常数后上下限不变，求和限不用改。

    * $e^{j\omega_0n}x[n]\longleftrightarrow X\!\left(e^{j(\omega-\omega_0)}\right)$，证明只在 $e^{-j\omega n}$ 里凑出 $e^{-j(\omega-\omega_0)n}$ 这一步。

    * 一句话概括：时域平移是乘相位，频域平移是挪位置。

    * > **易错点**：用频移性质时必须随时准备着 $e^{j\omega_0n}=e^{j(\omega_0+2k\pi)n}$，它以 $2\pi$ 为周期循环。$\omega_0$ 跑出 $(-\pi,\pi)$ 就先加减 $2k\pi$ 搬回来，$\cos$、$\sin$ 同理。

* **由频移得到 $\cos$ 与 $\sin$ 的变换对**

    * $\cos(\omega_0n)=\tfrac12e^{j\omega_0n}+\tfrac12e^{-j\omega_0n}$：前者把冲激串整体右移 $\omega_0$、后者左移 $\omega_0$，两个 $\frac12$ 把 $2\pi$ 里的 2 约成 $\pi$。

    * $\sin(\omega_0n)=\frac{1}{2j}e^{j\omega_0n}-\frac{1}{2j}e^{-j\omega_0n}$：系数再除一个 $j$ 变成 $\dfrac{\pi}{j}$，是纯虚数，画图时用虚线表示。

    * 记忆口诀：**正号右上左下，负号左上右下**。$\omega_0$ 处为正、$-\omega_0$ 处为负时是右上左下；前面带负号就翻成左上右下。

    * > **易错点**：只画 $0$ 附近那一根冲激、只画一个周期而不标 $\pm\pi$ 处的周期边线，只能得大部分分数；记图比记式子稳，图记住了式子随手能写，死背式子反而容易在 $\pm\pi$ 处漏掉周期项。

* **$\omega_0$ 出界的标准动作**

    * 减加 $2\pi n$ 搬回范围内；若带出负号，$\cos$ 是偶函数可以顺手消掉，$\sin$ 是奇函数负号得留在外面。

    * $\cos\left(\frac54\pi n\right)=\cos\left(\frac34\pi n\right)$；$\cos\left(\frac94\pi n\right)=\cos\left(\frac14\pi n\right)$，与 $\cos\left(\frac14\pi n\right)$ 的谱完全一样。

    * $\sin\left(\frac54\pi n\right)=-\sin\left(\frac34\pi n\right)$，谱在 $\pm\frac34\pi$ 处各一根冲激、符号翻成左上右下。

* **临界点上的 $\cos(\pi n)$ 与 $\sin(\pi n)$**

    * $\sin(\pi n)\equiv0$，因为整数 $n$ 上取到的永远是 $\sin0$、$\sin\pi$、$\sin2\pi$……全为零，变换也是 0。

    * 从频域看更清楚：$\pi$ 处一根 $\frac{\pi}{j}$ 冲激、$-\pi$ 处一根 $-\frac{\pi}{j}$ 冲激，但它们各自按 $2\pi$ 重复后在同一点相遇，**互为相反数、逐点对消**，所以结果是零而不是碰巧。

    * $\cos(\pi n)$ 照抄公式得 $\pm\pi$ 处各一根 $\pi$ 冲激，**这不是最终答案，差一个系数**：红笔那串左移 $2\pi$ 落到 $-\pi$，蓝笔那串右移 $2\pi$ 落到 $\pi$，两处各叠成 $2\pi$，同理 $3\pi$、$5\pi$ 等。

    * $$\cos(\pi n)\longleftrightarrow2\pi\sum_{k=-\infty}^{\infty}\delta\!\left(\omega-(2k+1)\pi\right)$$

    * > **提示**：这个脑筋急转弯要背熟——$\cos(\pi n)=e^{j\pi n}=e^{-j\pi n}=(-1)^n$。以后问「$(-1)^n$ 的傅里叶变换是什么」，答案就是上面那张图。

    * 用平移公式验证也一致：把 $1$ 的谱整体右移 $\pi$ 得 $2\pi\sum_k\delta(\omega-\pi-2k\pi)$，与上式相同；写成左移 $\pi$ 结果也一样，因为 $X(e^{j\omega})$ 以 $2\pi$ 为周期，$X(e^{j(\omega+\pi)})\equiv X(e^{j(\omega-\pi)})$。

* **周期不是 $2\pi$ 的频谱图**

    * 横坐标在 $\pm\frac38\pi$、$\pm\frac18\pi$ 上、外圈高 1 中间高 2 的图形，按 $2\pi$ 重复时是两个方波之和：$x[n]=\dfrac{\sin\left(\frac38\pi n\right)+\sin\left(\frac18\pi n\right)}{\pi n}$。

    * 若改成按 $\pi$ 重复，拆法就变成「一份 $2\pi$ 周期的图」加「它右移 $\pi$ 的一份」，而频域右移 $\pi$ 对应时域乘 $(-1)^n$：$x[n]=\big(1+(-1)^n\big)\dfrac{\sin\left(\frac38\pi n\right)+\sin\left(\frac18\pi n\right)}{\pi n}$。

    * $1+(-1)^n$ 的直观含义：**偶数下标放大一倍、奇数下标清零**；「以 $\pi$ 为周期」在时域里翻译过来就是「隔一个抽一个、剩下的乘二」。

    * 通用动作：遇到「这个频谱是几倍周期的图」，就拆成「一份最小周期 + 若干份平移副本」；平移 $\pi$ 乘 $(-1)^n$，平移 $\frac{2\pi}{N}$ 乘 $e^{-j\frac{2\pi}{N}n}$。

* **乘 $(-1)^n$：低通变高通**

    * 频域解释：低通是靠近 $0$ 的地方值大，乘 $(-1)^n$ 就是频谱移 $\pi$，大的那块搬到 $-\pi$ 和 $\pi$ 附近，在主值区间里看就是高频通；再乘一次又变回低通，因为 $(-1)^{2n}=1$。

    * 时域解释更直白：低通滤波器对应时域**变化缓慢**的序列；乘上 $(-1)^n$ 后正负交替倒下去、倒上来，是**剧烈震荡**，正是高通。

    * 看到频谱图上有「移位过」的怪形状，第一反应应该是「它是不是被 $\pm\pi$ 平移过」，立刻补出左右相邻周期，很多题当场解开。

* **离散高通滤波器的时域形式**

    * 频谱在 $[-\pi,-\frac34\pi]\cup[\frac34\pi,\pi]$ 上为 1、其余为 0；离散里靠近 $\pm\pi$ 是高频、靠近 $0$ 是低频，所以这是在问离散高通滤波器的时域形式。

    * 第一条路（频域相减）：全 1 减去中央矩形，$x[n]=\delta[n]-\dfrac{\sin\left(\frac34\pi n\right)}{\pi n}$。

    * 第二条路（把图当低通平移 $\pi$）：$x[n]=(-1)^n\dfrac{\sin\left(\frac14\pi n\right)}{\pi n}$。

    * 两者严格相等：$n=0$ 时都是 $\frac14$；$n\neq0$ 时用 $\sin(\omega+n\pi)=(-1)^n\sin\omega$ 可得 $-\sin\left(\frac34\pi n\right)=(-1)^n\sin\left(\frac14\pi n\right)$。

    * 这也是离散变换对题不出得太偏的原因之一：不同做法给出形式迥异的答案，但顺奇偶性与周期性推到底大概率会汇合。

* **时域差分与时域累加**

    * 时域差分：$x[n]-x[n-1]\longleftrightarrow(1-e^{-j\omega})X(e^{j\omega})$，直接用时移相减，不必展开。

    * 时域累加的完整式子很长，不必背；**只要记住 $y[n]=\displaystyle\sum_{k=-\infty}^{n}x[k]=x[n]*u[n]$**，剩下的交给卷积性质现场推。

    * 由 $u[n]$ 的变换乘上 $X$ 出发，两步化简即得书上式子：先用 $X(\omega)\delta(\omega-\omega_0)=X(\omega_0)\delta(\omega-\omega_0)$ 把 $X$ 从冲激里采样出来；再由周期性得 $X(e^{j2k\pi})=X(e^{j0})$，化简结果如下。

        $$Y(e^{j\omega})=\frac{X(e^{j\omega})}{1-e^{-j\omega}}+\pi X(e^{j0})\sum_{k=-\infty}^{\infty}\delta(\omega-2k\pi)$$

* **时域扩展：离散版是插零**

    * > **定义**：$x_{(k)}[n]=x[n/k]$（当 $n$ 是 $k$ 的整数倍）否则为 $0$；直观地说，它就是在 $x[n]$ 的**每两个相邻下标之间插入 $k-1$ 个 0**。

    * $k=2$：$n=0,2,4,6,\dots$ 取 $x[0],x[1],x[2],x[3],\dots$，奇数下标全为 0；负方向同理。

    * $k=3$：$n=0,3,6,9,\dots$ 取样，中间每点插两个 0。

    * 结论 $x_{(k)}[n]\longleftrightarrow X(e^{jk\omega})$，证明只需注意求和中只有 $n=pk$ 不为零，把指标换元即可。

    * 后果：$X(e^{j\omega})$ 以 $2\pi$ 为周期，$X(e^{jk\omega})$ 的周期就**缩成 $\frac{2\pi}{k}$**——时域胖 $k$ 倍、频域瘦 $k$ 倍这条规律在离散这边一点没变，只是填的是零。

    * 例：$x[n]$ 在 $-2$ 到 $2$ 全为 1 时 $X(e^{j\omega})=\dfrac{\sin\left(\frac52\omega\right)}{\sin\left(\frac12\omega\right)}$；$x_{(2)}[n]$ 在 $0,\pm2,\pm4$ 处为 1，$X_{(2)}=\dfrac{\sin(5\omega)}{\sin\omega}$。

    * 反向题「$\dfrac{\sin(5\omega)}{\sin\omega}$ 对应什么 $x[n]$」目前没考过，答案是 $0,\pm2,\pm4$ 处为 1、其余为 0；类比地 $\dfrac{\sin(7\omega)}{\sin\omega}$ 对应 $0,\pm2,\pm4,\pm6$ 处为 1。做法就是把矩形序列公式和抽样函数公式融到一起用。

* **频域微分**

    * $n\,x[n]\longleftrightarrow j\dfrac{\mathrm dX(e^{j\omega})}{\mathrm d\omega}$，与连续的 $t\,x(t)\longleftrightarrow j\dfrac{\mathrm dX(j\omega)}{\mathrm d\omega}$ 完全一样。

    * 威力在于把带 $n$ 的序列变成带平方分母的表达式：$n a^n u[n]\longleftrightarrow\dfrac{ae^{-j\omega}}{\left(1-ae^{-j\omega}\right)^2}$，再与 $a^nu[n]$ 的变换相加通分即得

        $$(n+1)a^n u[n]\longleftrightarrow\frac{1}{\left(1-ae^{-j\omega}\right)^2}$$

    * 一般式：$\dfrac{(n+r-1)!}{n!(r-1)!}a^n u[n]\longleftrightarrow\dfrac{1}{(1-ae^{-j\omega})^{r}}$，靠反复求导即可推出；$r$ 取 2 以上在本地考试中多年未考，其他学校考研仍在考。

* **时域卷积**

    * $x[n]*h[n]\longleftrightarrow X(e^{j\omega})H(e^{j\omega})$，时域卷积等于频域相乘。

    * 证明只靠两步：颠倒两重求和的顺序；把 $e^{-j\omega n}$ 拆成 $e^{-j\omega k}\cdot e^{-j\omega(n-k)}$。

    * 内层那个下标 $n-k$ 看着绕，但无论 $k$ 取哪个固定值，当 $n$ 遍历整数轴时 $n-k$ 也遍历整个整数轴，所以那一串就是 $H(e^{j\omega})$；也可以老实换元 $n'=n-k$。

    * 这条性质是整个 LTI 频域分析的立足点：时域里要算无穷和的卷积，频域里只剩一次乘法。

* **一个高频出现的凑法**

    * $$u[n]-\frac12\longleftrightarrow\frac{1}{1-e^{-j\omega}}$$

    * 做法：用 $u[n]$ 的变换减去 $\frac12$ 倍的常数序列变换（$1\longleftrightarrow2\pi\sum_k\delta(\omega-2k\pi)$，乘 $\frac12$ 得 $\pi\sum_k\delta$），两坨 $\pi$ 冲激正好抵消。

    * 它在时域的形状是：$n\ge0$ 处全为 $\frac12$，$n<0$ 处全为 $-\frac12$。

* **端到端的一道综合题**

    * 目标：反演 $(1-e^{-j\omega})\dfrac{\sin\left(\frac52\omega\right)}{\sin\left(\frac12\omega\right)}$。

    * 第一弯：$\dfrac{\sin\left(\frac52\omega\right)}{\sin\left(\frac12\omega\right)}$ 正是 $N_1=2$ 的矩形序列（$-2$ 到 $2$ 全 1）那一对。

    * 第二弯：$(1-e^{-j\omega})$ 拆成 $1-\text{右移}$，对应时域 $x[n]-x[n-1]$。

    * 第三弯：频域相乘要求时域卷积，参与卷积的是 $\dfrac{1}{1-e^{-j\omega}}$，即 $u[n]-\frac12$。

    * 翻转平移逐点累加得答案：$n\le-3$ 为 $-\frac52$；$n=-2$ 为 $-\frac32$；$n=-1$ 为 $-\frac12$；$n=0$ 为 $\frac12$；$n=1$ 为 $\frac32$；$n\ge2$ 为 $\frac52$。

    * 形状：左边一路 $-\frac52$ 平台，中间以步长 1 线性爬升，右边一路 $\frac52$ 平台。

    * > **易错点**：这道题的分水岭不是想不到灵感，而是想到灵感之后算不完。卷积一定要在草稿纸上老老实实列出翻转、平移后的图，不要凭想象心算。

* **调制性质与圆卷积**

    * $$x[n]\,y[n]\longleftrightarrow\frac{1}{2\pi}\int_{2\pi}X(e^{j\theta})Y\!\left(e^{j(\omega-\theta)}\right)\,\mathrm d\theta$$

    * 右边是**打了圆圈的卷积**（圆卷积／循环卷积／周期卷积），严格说是「时域相乘对应频域卷积除以 $2\pi$」，那个 $\frac{1}{2\pi}$ 平时不挂嘴上。

    * 与普通卷积的唯一区别在积分限：普通卷积从 $-\infty$ 积到 $+\infty$，圆卷积只积一个 $2\pi$ 周期。

    * > **易错点**：这个「只积一个周期」不是可以省略的修饰。若从 $-\infty$ 积到 $+\infty$，只要一个周期里积出一点点正值或负值，整个积分就奔着 $+\infty$ 或 $-\infty$ 去了。圆卷积的意义正在于把计算锁在一个周期内。

    * 证明的核心技巧：把外层的 $e^{j\omega n}$ 拆成 $e^{j\theta n}$ 与 $e^{j(\omega-\theta)n}$，双重积分裂成两个单重积分，分别就是 $x[n]$ 与 $y[n]$；后者之所以成立，是因为 $2\pi$ 周期函数在一个完整周期上平移积分值不变。

    * 一个可自己验证的普适结论：两个 $2\pi$ 周期函数做圆卷积，结果必然还是 $2\pi$ 周期函数；而用 $-\infty$ 到 $+\infty$ 的普通积分卷积不保证这一点。

    * 两个等宽、中心都在 0 的方波做圆卷积得三角波，底边与峰高按重叠长度算，末了别忘了除以 $2\pi$。

* **圆卷积四题**

    * $\left(\dfrac{\sin\left(\frac\pi4 n\right)}{\pi n}\right)^2$：两个 $\left(-\frac\pi4,\frac\pi4\right)$ 高 1 的方波做圆卷积，得支撑 $\left(-\frac\pi2,\frac\pi2\right)$、峰高 $\frac14$ 的**三角波**，$2\pi$ 周期重复。

    * 反过来，$\left(-\frac\pi4,\frac\pi4\right)$ 上为 1 的方波的反变换是 $8\left(\dfrac{\sin\left(\frac\pi8 n\right)}{\pi n}\right)^2$：拆成两个 $\left(-\frac\pi8,\frac\pi8\right)$ 方波的卷积，要求 $\frac\pi4 AB\cdot\frac{1}{2\pi}=1$，即 $AB=8$，取 $A=8$、$B=1$。

    * $\left(-\frac34\pi,\frac34\pi\right)$ 上为 1 的方波的反变换是上一题的答案乘 $(-1)^n$，即 $8(-1)^n\left(\dfrac{\sin\left(\frac\pi8 n\right)}{\pi n}\right)^2$；关键是**多画一个周期**，一眼就能看出它是全 1 的频谱平移了 $\pi$。

    * $\left(\dfrac{\sin\left(\frac34\pi n\right)}{\pi n}\right)^2$：两个方波各宽 $\frac32\pi$，直接卷积支撑冲到 $\pm\frac32\pi$、顶出主值区间，普通卷积完全失效，必须按圆卷积定义算；结果是一个周期内 $0$ 处 $\frac34$、从 $\pm\frac\pi2$ 起降为 $\frac12$ 并平齐到 $\pm\pi$ 的梯形，再按 $2\pi$ 重复。

        $$\begin{cases}\dfrac34-\dfrac{|\omega|}{2\pi}, & |\omega|\le\dfrac\pi2\\[4pt] \dfrac12, & \dfrac\pi2\le|\omega|\le\pi\end{cases}$$

    * 按定义算时的画面：两份方波都按 $2\pi$ 铺开，只统计 $[-\pi,\pi]$ 内它们重叠的宽度——平移量 $0$ 时重叠 $\frac32\pi$，平移到 $\frac\pi2$ 时重叠 $\pi$，继续移则一块退出多少另一块就补进多少，于是出现平顶。

    * > **结论**：圆卷积唯一需要背的操作口诀是三步——**先算直接卷积 → 结果按 $2\pi$ 为周期重复 → 重合的地方相加**。第二步里尖峰落在 $\pm\frac\pi2$ 处、$0$ 处被抬到 $2\pi$，第三步每一处都是「一上斜 + 一下斜」，宽度相同斜率相反，相加处处相等，所以那段平顶由此而来。

    * 还有一条完全不碰圆卷积的路：$\sin^2\left(\frac34\pi n\right)=\sin^2\left(\frac14\pi n\right)$ 对 $n\neq0$ 成立，但 $n=0$ 处两边极限是 $\frac9{16}$ 与 $\frac1{16}$，差 $\frac12$，故严格写法是在右边补上一项 $\frac12\,\delta[n]$。

        $$\left(\frac{\sin\left(\frac34\pi n\right)}{\pi n}\right)^2=\left(\frac{\sin\left(\frac14\pi n\right)}{\pi n}\right)^2+\frac12\,\delta[n]$$

        右边第一项的谱是峰高 $\frac14$ 的三角，第二项把整条谱抬高 $\frac12$，加完正好是上面那个梯形。

    * > **提示**：圆卷积的概念请务必掌握，它做题更快也更可靠；理解「离散序列在 $n=0$ 处可能差一个 $\delta[n]$」则能多一条捷径。

* **帕斯瓦尔定理**

    * $$\sum_{n=-\infty}^{\infty}|x[n]|^2=\frac{1}{2\pi}\int_{-\pi}^{\pi}|X(e^{j\omega})|^2\,\mathrm d\omega$$

    * 与连续形式 $\displaystyle\int_{-\infty}^{\infty}|x(t)|^2\mathrm dt=\frac1{2\pi}\int_{-\infty}^{\infty}|X(j\omega)|^2\mathrm d\omega$ 的差别只有两处：时域积分变求和、频域全轴变一个 $2\pi$ 周期；交叉着记，做多了记一个就够。

    * 证明从右边倒推：$|X|^2=X\cdot X^*$，用 $(AB)^*=A^*B^*$ 与 $(e^{-j\omega n})^*=e^{j\omega n}$ 把与 $\omega$ 无关的 $x^*[n]$ 提出积分号，括号里恰好是反变换公式，等于 $x[n]$。

    * 实际最常见的用法是**验算**：把频谱拆成几块、每块都认得出反变换时，用它对一下总能量就能立刻判断有没有算错。

* **共轭对称性**

    * 第一句：实偶对实偶，实奇对虚奇。

    * 第二句：实函数的傅里叶变换实部偶、虚部奇；配合奇偶分解 $x[n]=\frac12\big(x[n]+x[-n]\big)+\frac12\big(x[n]-x[-n]\big)$，偶部对应 $\mathrm{Re}\{X\}$、奇部对应 $j\,\mathrm{Im}\{X\}$。

    * 第三句：实函数的幅度谱偶、相位谱奇；因为 $\lvert X\rvert=\sqrt{\mathrm{Re}^2+\mathrm{Im}^2}$ 中两平方都偶、开根号仍偶，而 $\theta=\arctan\frac{\mathrm{Im}}{\mathrm{Re}}$ 是奇除偶再取 $\arctan$，仍为奇。

    * > **易错点**：这三条的前提都是 **$x[n]$ 为实函数**。题目不明确说时一般默认按实序列处理，但自己分析时必须先确认这一点，否则整个共轭对称都不成立。

* **离散 LTI 系统的频域分析**

    * 时域 $y[n]=x[n]*h[n]$ 在频域塌缩成 $Y(e^{j\omega})=X(e^{j\omega})H(e^{j\omega})$。

    * 求 $H(e^{j\omega})$ 有两条路且结果必须一致：逐项变换 $y[n]$ 与 $x[n]$ 后由 $Y=XH$ 解出；或令输入为 $\delta[n]$ 直接读出 $h[n]$。判定系统类型时先试 $h[n]$ 那条路往往更快。

    * 差分器 $y[n]=x[n]-x[n-1]$：$H(e^{j\omega})=1-e^{-j\omega}$，两路（代数与 $h[n]=\delta[n]-\delta[n-1]$）一致。

    * 累加器 $y[n]=\displaystyle\sum_{k=-\infty}^{n}x[k]$：$h[n]=u[n]$，$H(e^{j\omega})=\dfrac{1}{1-e^{-j\omega}}+\pi\sum_k\delta(\omega-2k\pi)$。

    * 延时器 $y[n]=x[n-n_0]$：$H(e^{j\omega})=e^{-j\omega n_0}$。

    * 两个一阶系统级联：$\alpha=\beta$ 时 $Y=\dfrac{1}{(1-\alpha e^{-j\omega})^2}$，对应 $y[n]=(n+1)\alpha^n u[n]$；看到分母有平方项就该想到这条。

    * $\alpha\neq\beta$ 时做部分分式分解：系数为 $\dfrac{\alpha}{\alpha-\beta}$ 与 $-\dfrac{\beta}{\alpha-\beta}$，反变换得 $y[n]=\dfrac{\alpha^{n+1}-\beta^{n+1}}{\alpha-\beta}u[n]$。

    * 由输出反求系统函数：$x[n]=\left(\frac12\right)^nu[n]$、$y[n]=3\left(\frac12\right)^nu[n]-2\left(\frac13\right)^nu[n]$ 时，先通分——分子中 $e^{-j\omega}$ 项恰好抵消、只剩常数 $1$——再除以 $X$，得 $H(e^{j\omega})=\dfrac{1}{1-\frac13e^{-j\omega}}$，即 $h[n]=\left(\frac13\right)^nu[n]$。

    * 余弦输入：$Y(e^{j\omega})=\pi H(e^{j\omega_0})\delta(\omega-\omega_0)+\pi H(e^{-j\omega_0})\delta(\omega+\omega_0)$，反变换得

        $$y[n]=\frac12H(e^{j\omega_0})e^{j\omega_0n}+\frac12H(e^{-j\omega_0})e^{-j\omega_0n}=\big\lvert H(e^{j\omega_0})\big\rvert\cos\big(\omega_0n+\theta(\omega_0)\big)$$

        即纯余弦进 LTI，出来还是同频纯余弦，只是幅度乘 $\lvert H\rvert$、相位加上 $\arg H$。

* **差分方程的完整解法**

    * 例：$y[n]-\frac16y[n-1]-\frac16y[n-2]=x[n]$。左边三项都能提出一个 $Y(e^{j\omega})$，故可直接写出

        $$H(e^{j\omega})=\frac{1}{1-\frac16e^{-j\omega}-\frac16e^{-j2\omega}}$$

    * 分解因式：$1-\frac16e^{-j\omega}-\frac16e^{-j2\omega}=\left(1-\frac12e^{-j\omega}\right)\left(1+\frac13e^{-j\omega}\right)$（常数项与二次项系数均可验）。

    * 部分分式的两个系数用「盖起来算其他」：算 $\frac35$ 那一项令 $e^{-j\omega}=2$；算 $\frac25$ 那一项令 $e^{-j\omega}=-3$。

    * 系数可用三种方式互相校验：盖起来算其他；两者之和为 1；$e^{-j\omega}$ 的系数之和为 0。做题时挑两种验一遍就够，是速度与准确度的平衡点。

    * > **易错点**：$\dfrac{1}{1+\frac13e^{-j\omega}}$ 必须改写成 $\dfrac{1}{1-\left(-\frac13\right)e^{-j\omega}}$，反变换才是 $\left(-\frac13\right)^nu[n]$；把 $-\frac13$ 直接代成 $\frac13$ 是这一类题最常见的翻车点。

    * 最终 $h[n]=\frac35\left(\frac12\right)^nu[n]+\frac25\left(-\frac13\right)^nu[n]$。

    * 当 $x[n]=\left(\frac12\right)^nu[n]$ 时，$Y$ 出现平方项，拆成三项：最高次的 $A$ 和最低次的 $C$ 仍可盖，**中间那一项 $B$ 盖不干净**。

    * $A=\frac35$（令 $e^{-j\omega}=2$）；$C=\dfrac{1}{\left[1-\frac12(-3)\right]^2}=\left(\frac25\right)^2=\frac4{25}$（别忘了外面还套着一个平方）；$B$ 把 $e^{-j\omega}$ 设成 0（$\omega\to\infty$ 的形式值），左边为 1、右边为 $\frac35+B+\frac4{25}$，得 $B=\frac6{25}$。

    * 验算：再代 $e^{-j\omega}=1$，左边 $\dfrac{1}{(\frac12)^2\cdot\frac43}=3$，右边 $\frac{12}{5}+\frac{12}{25}+\frac3{25}=\frac{75}{25}=3$，对上才敢往下走。

    * 最终 $y[n]=\frac35(n+1)\left(\frac12\right)^nu[n]+\frac6{25}\left(\frac12\right)^nu[n]+\frac4{25}\left(-\frac13\right)^nu[n]$。

    * > **提示**：这一整类题真正用到的公式只有一个，难点全在细心，不在公式。

* **四个条件定一个序列**

    * 已知：$n>0$ 时 $x[n]=0$；$x[0]>0$；$\mathrm{Im}\{X(e^{j\omega})\}=\sin\omega-\sin2\omega$；$\displaystyle\int_{-\pi}^{\pi}|X(e^{j\omega})|^2\mathrm d\omega=6\pi$。

    * 四个条件里第三个信息量最大，它直接把虚部给了出来。

    * 把 $\sin$ 展开成指数后 $j$ 全部约掉：$j(\sin\omega-\sin2\omega)=\frac12e^{j\omega}-\frac12e^{-j\omega}-\frac12e^{j2\omega}+\frac12e^{-j2\omega}$。

    * 对照定义式 $X(e^{j\omega})=\sum_n x[n]e^{-j\omega n}$ 逐项读下标：$x_o[1]=-\frac12$、$x_o[-1]=\frac12$、$x_o[2]=\frac12$、$x_o[-2]=-\frac12$，是个奇序列。

    * 再用条件一（$n>0$ 处全零）反推负半轴：$x[-1]=1$、$x[-2]=-1$。

    * $n=0$ 这点还定不下来，因为 $x[n]-x[-n]$ 在 $n=0$ 恒为 $0$，奇部提供不了任何信息；条件一说的是「$n>0$ 为 0」，并未说 $n=0$ 为 0。

    * 用条件四走帕斯瓦尔：$\sum_n|x[n]|^2=3$，于是 $1+1+x[0]^2=3$，得 $x[0]=\pm1$；最后用条件二取正号。

    * 答案：$x[0]=1$、$x[-1]=1$、$x[-2]=-1$，其余为 0。四个条件被均衡地用完，一个不多一个不少。

    * > **易错点**：题面没有明说 $x[n]$ 是实函数，这是不严谨之处；不假设这一点，条件二三四全都失去意义。做这类题第一步永远是确认「是不是实序列」。

    * 可迁移的套路：先找信息量最大的条件把序列主体定下来，剩下的少数自由量再逐个用其他条件钉死。

## 离散傅里叶级数

* **四种傅里叶变换的分工**

    | 时域 \ 频域 | 离散 | 连续 |
    | :--- | :--- | :--- |
    | 连续 | 傅里叶级数 | 傅里叶变换 |
    | 离散 | 离散傅里叶级数 | 离散傅里叶变换 |

    * 四种变种的核心关系就是连续与离散的对应关系。

    * 另一条规律是**离散对应周期**：频域离散对应时域周期（傅里叶级数那一格）；时域离散对应频域周期（离散傅里叶变换的 $2\pi$ 周期）；两边都离散的离散傅里叶级数则两边都是周期的。

    * 离散傅里叶级数是其中最重要的一种，因为计算机只能处理离散量，其余三个变换它都处理不了。

* **从 DTFT 推到 DFS 的三步**

    * 第一步：把无限变成有限，假设 $x[n]$ 只在 $n=0,1,\dots,N-1$ 有值，于是 $X(e^{j\omega})=\displaystyle\sum_{n=0}^{N-1}x[n]e^{-j\omega n}$。

    * 起点选在 $0$ 到 $N-1$ 只是约定：起点挪一下，变换只多乘一个 $e^{-j\omega n_0}$，靠的正是时移性质。

    * $N$ 不是信号自带的属性，而是为了用计算机做分析而人为设定的数；例如 3 秒语音、采样率 $22500$ Hz 时，$N=22500\times3=67500$。

    * 第二步：$X(e^{j\omega})$ 虽然写出来是连续曲线，但它是一个「**虚假的连续信号**」——只要知道它在一个周期内的 $N$ 个值，就能确定它在所有 $\omega$ 上的值。

    * 第三步：在一个周期内取 $N$ 个不同的频率点，把公式逐个展开，得到一个 $N$ 元一次方程组，未知数正是 $x[0],\dots,x[N-1]$。

    * 写成矩阵就是范德蒙型方程组；只要这个矩阵可逆，就能由 $N$ 个频域采样值反解出时域序列，再回到第一步的公式求出全部 $\omega$ 上的频谱。

* **可逆性：范德蒙行列式**

    * > **定义**：令 $e^{-j\omega_i}=v_i$，系数矩阵即为范德蒙矩阵，其行列式为 $\det\mathbf{V}=\displaystyle\prod_{0\le i<j\le N-1}(v_j-v_i)$。

    * $N=2$ 时行列式就是 $v_1-v_0$；$N=3$ 时是 $(v_1-v_0)(v_2-v_0)(v_2-v_1)$。

    * 定理：只要 $\omega_0,\dots,\omega_{N-1}$ 是一个 $2\pi$ 周期内两两不同的频率点，矩阵就可逆。因为 $\omega$ 两两不同则 $e^{-j\omega_i}$ 两两不同，相减都不为零，行列式的连乘自然非零。

    * 用高斯消元做矩阵求逆的复杂度是 $O(N^3)$；通用矩阵求逆目前已知能到约 $O(N^{2.8\ldots})$，离理论下界还有多远尚无定论。

    * > **易错点**：由频谱反解时域这一步不能随意做——一旦系数矩阵不可逆，整套做法就整个塌掉。

* **等间距取点的转机**

    * 1960 年中期 Cooley 与 Tukey 提出离散傅里叶级数，其关键在于不随便取点，而是在 $[0,2\pi)$ 上**等间距**地取

        $$\omega_0=0,\quad\omega_1=\frac{2\pi}{N}\times1,\quad\cdots,\quad\omega_{N-1}=\frac{2\pi}{N}(N-1)$$

    * 间距恒为 $\frac{2\pi}{N}$，于是 $v_i=e^{-j\omega_i}$ 成一串等比数，矩阵立刻呈现出高度的结构性，解方程组的代价不再是那个刺眼的 $N^3$。

    ```text
       在 [0, 2π) 这一个周期上，等间距地取 N 个点

        ω₀        ω₁        ω₂        ···        ω_{N-1}
        ●─────────●─────────●───────── ··· ───────●
        0        2π/N     2π·2/N                2π(N−1)/N
        ↑                                             ↑
        └────────── 每相邻两点的间距恒为 2π/N ────────┘
    ```

* **一条「非 $N$ 即 0」的求和**

    * $$\sum_{k=0}^{N-1}e^{-j\frac{2\pi}{N}km}=\begin{cases}N, & m=0\\[4pt]0, & m\neq0\end{cases}\qquad\text{（$m$ 取遍整数且 $|m|\le N-1$）}$$

    * $m=0$ 时每一项都是 1，$N$ 个 1 加起来就是 $N$。

    * $m\neq0$ 时用等比数列公式 $\frac{1-q^N}{1-q}$：分子 $q^N=e^{-j2\pi m}=1$（整数 $m$ 绕 $m$ 圈回到原地），分子归零，整个和为零。

    * 推导时把第 $n_1$ 项与第 $n_2$ 项逐项相除，指数相减后 $k$ 被消掉、冒出差值 $n_1-n_2$，整条和就改写成同一个式子。

    * 分母只在 $n_1-n_2$ 是 $N$ 的整数倍时才为零；约定下标取遍 $0\sim N-1$，$|n_1-n_2|\le N-1$，所以这一支只能是 $n_1=n_2$，单独数 $N$ 个 1 即可。

    * 人话讲法：它是一台**筛子**——撞对了乘 $N$ 放行，撞错了一丝不漏全部筛掉。离散时间信号与系统的正交性、帕斯瓦尔、卷积定理背后都是这台筛子在干活。

    * > **易错点**：$m=0$ 这一支不能直接套等比数列求和公式，因为分母同时为零；正因为 $|m|\le N-1$，这一支才只能单独数。

* **正变换与反变换**

    * > **定义**：设 $x[n]$ 是周期为 $N$ 的离散序列，$\omega_k=\dfrac{2\pi k}{N}$，$k=0,1,\dots,N-1$，则有正变换（分析式）与反变换（合成式）两条式子：

        $$a_k=\sum_{n=0}^{N-1}x[n]e^{-j\frac{2\pi}{N}nk},\qquad x[n]=\frac1N\sum_{k=0}^{N-1}a_ke^{j\frac{2\pi}{N}nk}$$

    * 第一条是正变换（分析式），第二条是反变换（合成式）。

    * $1/N$ 只出现一次；把它挂在正变换还是反变换上两种写法都自洽，但**千万别混着记**，混了以后做题时 $N$ 会凭空多出一个或少掉一个。

    * 反变换的证明：把正变换的表达式代进右边，展开双求和、换序后内层正是那条「非 $N$ 即 0」的求和，哑变量是外层下标减内层下标，只有两者相等时不为零，于是内层和为 $N$，外面的 $\frac1N$ 恰好抵消，剩下 $x[n]$。

    * > **易错点**：证明「双求和换序」时最容易出的错是变量重名。必须把 $a_k$ 里带的那个下标改记成另一个字母（例如 $u$），否则等号把自己绊住；改完之后同一个内层和里只剩一个哑变量，目标下标才被释放出来。

    * 结论：$N$ 个样点与 $N$ 个系数之间一一对应，正反变换互为逆运算。

* **直接算的代价**

    * 由 $x[n]$ 求 $a_k$：$N$ 个输出，每个输出 $N$ 项乘加，量级为 $O(N^2)$；反方向一模一样。

    * $k=0$ 时系数全为 1，那一行的乘法可以省掉，但不影响量级。

## 快速傅里叶变换

* **奇偶分组：FFT 的全部思路**

    * 观察：指数 $e^{-j\frac{2\pi}{N}nk}$ 关于 $n$ 有周期结构，把 $n$ 拆成 $n=2m$ 与 $n=2m+1$ 两支，求和自动分成两个子序列。

    * $$\sum_{n=0}^{N-1}x[n]e^{-j\frac{2\pi}{N}nk}=\underbrace{\sum_{m=0}^{\frac N2-1}x[2m]e^{-j\frac{2\pi}{N}(2m)k}}_{\text{偶数抽取}}+\underbrace{\sum_{m=0}^{\frac N2-1}x[2m+1]e^{-j\frac{2\pi}{N}(2m+1)k}}_{\text{奇数抽取}}$$

    * 偶支只有约分动作；奇支的下标多一个 1，把它拆成 $2m$ 加 1，多出来的常数会在括号外析出一个公共因子 $e^{-j\frac{2\pi}{N}k}$。

    * > **易错点**：$x[2m]$ 与 $x[2m+1]$ 抽的是**样点**不是系数；两支的输出要按 $W_N^k$ 与 $W_N^{k+N/2}$ **交叉**连到输出端，不能把两支的第 $k$ 个输出一一对上。

* **八点的例子**

    * $a_k=\Big[x[0]+x[2]e^{-j\frac{2\pi}{4}k}+x[4]e^{-j\frac{2\pi}{4}2k}+x[6]e^{-j\frac{2\pi}{4}3k}\Big]+e^{-j\frac{2\pi}{8}k}\Big[x[1]+x[3]e^{-j\frac{2\pi}{4}k}+x[5]e^{-j\frac{2\pi}{4}2k}+x[7]e^{-j\frac{2\pi}{4}3k}\Big]$

    * 第一个括号就是 $\{x[0],x[2],x[4],x[6]\}$ 的四点离散傅里叶级数，第二个括号就是 $\{x[1],x[3],x[5],x[7]\}$ 的四点离散傅里叶级数——四个系数与四点公式的系数逐一完全相同，不用再验。

    * 八点直接算是 $8\times8=64$ 次乘加；拆开之后是两个四点变换（$2\times4\times4=32$ 次）加上 4 次旋转因子乘法。

    * 八点离散傅里叶级数 = 一个四点变换加另一个四点变换，各自乘个权重再相加。

* **蝴蝶图（信号流图）**

    * 画图约定：方框直接叫「四点 FFT」；箭头一律从左打到右；旋转因子只挂在从下支路出来的那条线上。

    ```text
     x[0] ----+                         x[1] ----+
     x[2] ----+                         x[3] ----+
     x[4] ----+--> [ FFT4 ] --> Yk     x[5] ----+--> [ FFT4 ] --> Zk
     x[6] ----+   even samples          x[7] ----+   odd samples

                                    Yk ----+
                                            +----> [ + ] ----> a[k]     k = 0,1,2,3
                                    Zk ----+--> * W8^k
                                            +----> [ - ] ----> a[k+4]   k = 0,1,2,3
    ```

    * 合成关系：$a_j=A_j+W_8^jB_j$，$a_{j+4}=A_j-W_8^jB_j$，其中 $A$ 来自偶数序列、$B$ 来自奇数序列（$j=0,1,2,3$）。

    * 旋转因子取值：$W_8^0=1$、$W_8^1=e^{-j\pi/4}$、$W_8^2=e^{-j\pi/2}=-j$、$W_8^3=-e^{-j3\pi/4}$。

    * 底下那组由对称得到：$W_8^{k+4}=e^{-j\frac{2\pi}{8}(k+4)}=-W_8^k$，所以标准蝴蝶图下边四条线上各标一个「$-1$」，这正是四个减号的位置。

* **逐个系数回验**

    * $a_0$：所有旋转因子都退化成 1，$a_0=(x_0+x_2+x_4+x_6)+(x_1+x_3+x_5+x_7)=\displaystyle\sum_{n=0}^{7}x_n$，与直接代入定义完全一致。

    * $a_1$：$a_1=(x_0-x_4)+(x_2-x_6)e^{-j\pi/2}+e^{-j2\pi/8}\big[(x_1-x_5)+(x_3-x_7)e^{-j\pi/2}\big]$，与定义展开逐字对得上。

    * $a_4$：四点里没有第 4 个点，$4$ 对 $4$ 取模回到 $0$，所以取法与 $a_0$ 相同；区别只在权重 $W_8^4=e^{-j\pi}=-1$，走减法那条连线：$a_4=(x_0+x_2+x_4+x_6)-(x_1+x_3+x_5+x_7)$。

    * $a_5$：**不要单独去算 $W_8^5$**。把 5 拆成 $4+1$，$e^{-j2\pi\cdot5/8}=e^{-j\pi}\cdot e^{-j2\pi/8}=-e^{-j2\pi/8}$，所以图上只需在 $W_8^1$ 旁边多画一个 $\times(-1)$ 的小方块，$a_5=A_1-e^{-j2\pi/8}B_1$，一次新的复数乘法都没多。

    * 同一个招在四点那层也用得上，但结果正好相反：$e^{-j2\pi\cdot5/4}=e^{-j2\pi\cdot4/4}\cdot e^{-j2\pi\cdot1/4}=1\cdot e^{-j2\pi/4}$，不冒出负号；八点那层之所以多一个 $-1$，是因为 $e^{-j2\pi\cdot4/8}=e^{-j\pi}=-1$。

    * > **结论**：这些点全都是以 4 为周期循环的，$a_k$ 与 $a_{k+4}$ 只差一个旋转因子。

* **四点再拆两点**

    ```text
      x0        x1        x2        x3
       |         |         |         |
       +---------+         |         |
       |         |         +---------+
       v         v         v         v
     (x0+x2)  (x0-x2)   (x1+x3)   (x1-x3)
       |         |          |         |
       |         |          |    x W4^k
       |         |          |         |
       +---------+----------+---------+
       |                                |
       v                                v
      A0                               A2
    ```

    * 第一级把输入两两配对各做一个两点变换；第二级用旋转因子 $W_4^k$ 把右边那支加权后与左边那支相加。

    * 四个输出：$A_0=(x_0+x_2)+(x_1+x_3)$（$W_4^0=1$）；$A_1=(x_0-x_2)+W_4^1(x_1-x_3)$；$A_2=(x_0+x_2)-(x_1+x_3)$（$W_4^2=e^{-j\pi}=-1$，两点变换的第 2 个输出与第 0 个输出本是一回事）；$A_3=(x_0-x_2)-W_4^1(x_1-x_3)$。

    * > **易错点**：$A_3$ 那条支路上不是再乘一个「新的」旋转因子，而是 $-W_4^1$，也就是在 $W_4^1$ 前面再加一个 $\times(-1)$。看漏了它，$A_3$ 整个算错，而且错得毫无征兆——数还是那几个数，只是符号反了。

    * 两点变换本身最简单：$b_0=x_0+x_1$、$b_1=x_0-x_1$。

    * 把两个四点盒子都换成上面拆开的样子，整张八点蝴蝶图就闭合了。

* **顺手走的追踪练习**

    * 规则：在 $0\sim7$ 里任取 $n$ 与 $k$，从图上 $x_n$ 顺着线走到 $a_k$，路上乘过的所有系数的乘积应当正好等于 $e^{-j\frac{2\pi}{N}nk}$。

    * $n=2,k=3$：$x_2$ 走上支路，在四点这一层拿到的系数是 $e^{-j2\pi/4}$，通往 $a_3$ 的支路上还挂着一个 $\times(-1)$，乘积 $-e^{-j2\pi/4}=e^{-j2\pi\cdot6/8}$，与定义里的 $e^{-j2\pi\cdot2\cdot3/8}$ 一致。

    * $n=5,k=4$：$x_5$ 走下支路，在奇数四点变换的第 0 个输出里系数就是 1，路上只挂着一个 $W_8^4=-1$，乘积 $-1=e^{-j2\pi\cdot20/8}$，同样吻合。

    * 这正是 FFT 真正在干的事：那些本该一次算一个的复指数系数被拆成好几个简单因子的连乘，图上每一个 $\times(-1)$、每一个 $\times W^k$ 都在替你省下一次昂贵的复数乘法。

* **为什么是 $N\log N$**

    * 层数就是 $\log_2N$：八点三层（第一层 4 个小蝴蝶、第二层 2 个、第三层 1 个），十六点四层，三十二点五层。

    * 每一层的加法与乘法次数大致是 $N$ 个（数成 $2N$ 个也对），乘上 $\log_2N$ 层就是 $N\log_2N$，写成 $N\log N$ 是因为底数在大 $O$ 里无关紧要。

    * 每拆一层点数减半、子问题个数翻倍，所以每层是 $O(N)$；库利与图基这一手正是直接决定了整个信号处理领域的计算效率。

* **不限于二的幂**

    * $N=9=3\times3$：按**下标除以 3 的余数**分成三组，令 $n=3m+r$ 换元后，原式就能拆成内外两层求和。

        $$a_k=\sum_{m=0}^{2}\sum_{r=0}^{2}x_{3m+r}e^{-j2\pi(3m+r)k/9}=\sum_{m=0}^{2}e^{-j2\pi mk/3}\left(\sum_{r=0}^{2}x_{3m+r}e^{-j2\pi rk/3}\right)$$

    * 括号里是三个标准三点变换，输入分别是 $(x_0,x_3,x_6)$、$(x_1,x_4,x_7)$、$(x_2,x_5,x_8)$；外面挂的旋转因子在 $m=0,1,2$ 时依次为 $1$、$e^{-j2\pi/3}$、$e^{-j2\pi\cdot2/3}$。

    * 指数里的 9 能约掉，靠的是 $9/3=3$、$6/3=2$ 这类关系。

    * 更一般地，若 $N=N_1N_2\cdots N_m$（一路拆到素因子），就照这个套路一级级拆，每级做一个小变换、加权合并。

    * $N$ 是质数时**没有办法**，定义式一项都省不掉，只能老老实实按定义算。

    * > **结论**：在 $x[n]$ 是一个 $N$ 点序列的前提下，$a_k$ 就是 $x[n]$ 的离散傅里叶变换，$\omega_k=2\pi k/N$ 取遍 $[0,2\pi)$。$a_0$ 是全部 $N$ 个点加和，$a_k$ 是 $X(e^{j\omega})$ 在 $\omega=2\pi k/N$ 处的采样值。

* **补零：采样点不够时**

    * $x[n]=[1,1,1,1,1]$ 取 $N=5$ 时，$a_0=5$ 而其余四个全是零。

    * 原因：包络的分子 $\sin(5\omega/2)$ 在 $\omega=\frac{2\pi}{5},\frac{4\pi}{5},\frac{6\pi}{5}$ 处过零，而采样点 $\omega_k=2\pi k/5$ 一个不多一个不少全踩在这些零上；换个角度看 $[1,1,1,1,1]$ 相当于把支撑在 $-2\sim2$ 的一段整体右移两位，零点位置一点没动。

    * > **易错点**：这是「$N$ 不够」的典型后果，采样点太少时可能**全**踩在包络零点上。别把这当成「信号没有频谱」。

    * 补零即可解决：补到 10 点后 $a_0$ 仍是 5，而 $a_1$ 的采样位置变成 $2\pi/10$、不再踩零点，$a_2$ 又踩回 $2\pi/5$……一路错开。

    * 补零的点数决定频域网格的密度，**补得越多越能看清真实频谱的形状**。

    * 更实际的例子：$N=17$ 时先补零到二的整数次幂 $2^7=128$（补 111 个零）再用 FFT 一次算完。

    * $2\pi/17\approx(2\pi/128)\times7.5294$，$2\pi\cdot2/17\approx(2\pi/128)\times15.0588$，即前两个真实采样点分别落在网格第 8 与第 9 点之间、第 16 与第 17 点之间。

    * 落进点缝里的值靠插值取回：最朴素的是在相邻两点间画一条直线（线性差值），用更复杂的差值也行。

    * 一句话收住：FFT 算出来的是频谱在一串等距网格点上的值，**补零决定网格多密，差值决定能不能把网格之间真正想要的值捞回来**。

## 用 FFT 计算线性卷积

* **循环移位**

    * > **定义**：$N$ 点序列的循环移位为 $x[(n-m)]_N=\big\{x[(n-m)\bmod N]\big\}$，即序列整体右移，**移出去的那个点不扔掉，而是绕回来接到队首**。

    * $x[n]=[1,2,3,4]$（$N=4$）为例：

        ```text
        n              0     1     2     3
        x[n]           1     2     3     4
        x[(n-1)]_N     4     1     2     3
        x[(n-2)]_N     3     4     1     2
        x[(n-3)]_N     2     3     4     1
        ```

    * 一般情形：第 $0$ 位是 $x[N-m]$，第 $1$ 位是 $x[N-m+1]$，一直到第 $N-1$ 位是 $x[N-1]$；前半段搬过来的是 $x[0],\dots,x[N-m-1]$。

    * > **易错点**：与普通移位最根本的区别就在「绕回来」三个字，别当成普通移位去做。

    * 更省脑的等价看法：先作周期为 $N$ 的**周期延拓**，再整体右移 $m$ 个单位，最后只取 $n=0,\dots,N-1$ 这一段；前两步都在无限长序列上理解，绕回来的效果由第一步自动带来。

    * 由周期延拓的定义直接可见：循环右移 $N$ 个单位等于什么都没做，所以循环移位的周期就是 $N$。

* **圆卷积**

    * > **定义**：两个 $N$ 点序列的 $N$ 点圆卷积 $y[n]=x[n]\circledast h[n]$ 定义为 $y[n]=\displaystyle\sum_{m=0}^{N-1}x[m]\;h[(n-m)]_N$，$n=0,1,\dots,N-1$。

    * 与线性卷积只差一处：右边那项的下标带了圈，**超范围就绕回**；线性卷积里超范围的部分直接不参与。

    | | 线性卷积 | 圆卷积 |
    | :--- | :--- | :--- |
    | 记号 | $x[n]\ast h[n]$ | $x[n]\circledast h[n]$ |
    | 求和范围 | $m=0,\dots,N_1+N_2-2$ | $m=0,\dots,N-1$ |
    | $h$ 下标越界 | 超出部分不参与 | 下标减 $N$ 绕回开头 |
    | 两序列长度 | 可以不一样 | **必须一样长** |
    | 输出长度 | $N_1+N_2-1$ | $N$ |

    * > **易错点**：圆卷积要求两个序列都是 $N$ 点。只要长度不一样，圆卷积是**不存在**的——没有「自动补零对齐」这种说法，补零是后面单独设计的一步。

* **手算圆卷积的固定套路**

    * 第一步：把 $h[n]$ 反过来得 $g[m]=h[(-m)]_N$。好记的窍门是**第一个数照抄，剩下 $N-1$ 个数翻转**；下标折算时负下标一律加 $N$。

    * 例：$h=[2,1,-1,0]$ 第一个 $2$ 照抄，$[1,-1,0]$ 翻转成 $[0,-1,1]$，得 $g=[2,0,-1,1]$（原下标 $-1$ 的 $1$ 折到 $3$、下标 $-2$ 的 $-1$ 折到 $2$）。

    * 第二步：把 $g$ 循环右移零位，逐项乘 $x$ 求和得 $y[0]$；之后每右移一位依次得 $y[1],y[2],\dots$。

    * $x=[1,2,3,4]$、$h=[2,1,-1,0]$ 逐步算得 $y[0]=3$、$y[1]=1$、$y[2]=7$、$y[3]=9$，即 $y=[3,1,7,9]$，长度与输入相同。

    * > **提示**：写 $[1,2,3,4]$ 这类简写时隐含了下标是 $0,1,2,3$，因为定义里求和上限是 $N-1$，下标必须从 0 数起。

* **圆卷积定理**

    * > **结论**：设 $x[n]$、$h[n]$ 都是 $N$ 点序列，DFT 分别为 $X[k]$、$H[k]$。若 $y[n]=x[n]\circledast h[n]$，则 $Y[k]=X[k]H[k]$，且 $y[n]$ 仍是 $N$ 点序列。

    * 证明从 $Y[k]$ 的定义出发，把圆卷积定义代进去，然后把循环移位项与指数项合并。

    * 胜负手：令 $r=(n-m)\bmod N$，此时 $n$ 与 $(m+r)$ 相差 $N$ 的整数倍，指数上多出的因子 $e^{-j\frac{2\pi}{N}kqN}=e^{-j2\pi kq}=1$，所以**循环移位根本不影响指数项的值**。

    * 合并后双重求和直接裂成 $X[k]$ 与 $H[k]$ 的乘积，没有做任何额外假设。

* **补零大法**

    * > **结论**：把两个序列都补零到 $N_1+N_2-1$ 点，此时它们的 $N_1+N_2-1$ 点圆卷积**逐点等于**原来的线性卷积。

    * 例：$[1,2,3]$ 与 $[4,5,6]$ 各补 2 个零成 5 点，圆卷积得 $[4,13,28,27,18]$，与线性卷积一模一样；逐项对照可见 $g$ 里乱窜的两个零每轮都恰好落在补出来的零上，一分贡献都没有。

    * 补零奏效的全部原因是：补零后的结果长度恰好等于线性卷积长度，一分不多一分不少，所以圆卷积里「绕回来」的那部分根本无处可绕。

    * 线性卷积和「补零后的圆卷积」本质上是同一件事的两种写法。

* **用 FFT 算卷积的标准三步**

    * 第一步：补零。给 $x[n]$ 补 $N_2-1$ 个零、给 $h[n]$ 补 $N_1-1$ 个零，两者都变成 $N_1+N_2-1$ 点。

    * 补到 $N_1+N_2-1$ 只是理论下限；**实际一律往上补，补到 $2^k$**，蝶形运算才跑得顺畅，算完把后面挂着的零丢掉。

    * 第二步：各做一次正变换 $X[k]=\mathrm{FFT}\{x[n]\}$、$H[k]=\mathrm{FFT}\{h[n]\}$。

    * 第三步：逐点相乘再做一次逆变换 $Y[k]=X[k]H[k]$、$y[n]=\mathrm{IFFT}\{Y[k]\}$。

    * 复杂度账：补零 $O(N)$、两次正变换 $2\times O(N\log N)$、逐点相乘 $O(N)$、一次逆变换 $O(N\log N)$，合计 $3N\log N+N$，即 $O(N\log N)$；直接做线性卷积则是 $O(N^2)$。

    * > **结论**：$N$ 越大差距越夸张——序列长到几万、几百万点时，$N^2$ 算到天荒地老也出不来，$N\log N$ 只是多转几遍。这就是 FFT 的全部意义。

## MATLAB 实现

* **两点基例**

    * 理论下标从 0 开始：$A_0=x(0)+x(1)$，$A_1=x(0)-x(1)$；写进 MATLAB 变成 `A0 = x(1) + x(2)`、`A1 = x(1) - x(2)`。

    * > **易错点**：写这类递归算法时，脑子的 0 基下标与 MATLAB 的 1 基下标必须随时换算。忘了换算程序不报错，但算出来的东西是错的。

* **fft6 的三步骨架**

    * 第一步：把所有序列长度补到 $2$ 的整数次方——这不是礼节性操作，而是整个递归的地基，长度必须是 2 的幂才能一层层对半劈到 2 个点。

    * 第二步：把序列拆成奇偶两支，`x1 = x(1:2:n)`、`x2 = x(2:2:n)`；`1:2:n` 就是「从 1 开始、每次往后跳 2」。

    ```matlab
   x = [x1 x2 x3 x4 x5 x6 x7 x8]     ← MATLAB 下标
        0  1  2  3  4  5  6  7       ← 理论下标

        ├── x(1:2:n) = [x1 x3 x5 x7]  →  理论上的偶数位  0 2 4 6
        │                                  └── 递归调用自己，算 4 点 FFT
        │
        └── x(2:2:n) = [x2 x4 x6 x8]  →  理论上的奇数位  1 3 5 7
                                           └── 递归调用自己，算 4 点 FFT

   两路 4 点结果出来之后，再按蝶形合并回 8 点。
   ```

    * 第三步：递归调用自己，`y1 = fft6(x1)`、`y2 = fft6(x2)`，两路结果拿来做蝶形合并。

    * 合并部分：

        ```matlab
        N = length(x1) * 2;
        for k = 0 : N-1
            if k < N/2
                y(k+1) = y1(k+1) + exp(-1j*2*pi*k/N) * y2(k+1);            % 前半段：加
            else
                y(k+1) = y1(k+1-N/2) - exp(-1j*2*pi*k/N) * y2(k+1-N/2);    % 后半段：减
            end
        end
        ```

    * 一句话概括：每一条来自 y2 的输出都要先乘上 $e^{-j2\pi k/N}$ 这个**旋转因子**，再跟前一半相加；因子只挂在 y2 那一侧。

* **速度与精度的现实**

    * 自己照算法翻译的版本跑 10 万点已经有点卡、50 万点明显慢于内置函数。

    * > **结论**：写得出和跑得快是两件事。内置的那个版本是 1970 年前后用 Fortran 写的，被调用了几十年、早被优化过无数遍。

    * 自己版本的结果最后几个数与内置的有一点点不一样，那是精度影响、比较小的数基本一致，不是算法错。

* **ifft6**

    * 正反变换公式只差一处符号：正变换指数上是负号，反变换指数上是正号。

    * 因此代码只有两处改动：指数里的 `-1j` 全改成 `+1j`；最后整体除以 2。

    * > **提示**：为什么是每层除以 2 而不是最后除以 $N$？因为递归一共 $\log_2N$ 层，每层除一次 2，$k$ 个 2 连乘就是 $2^k=N$，与在顶上一次性除以 $N$ 完全等价。这是把归一化因子摊到每一层的常见套路。

* **卷积代码**

    ```matlab
    L = length(x) + length(y) - 1;      % 卷积结果的长度

    x = [x zeros(1, L - length(x))];   % x 补零到 L
    y = [y zeros(1, L - length(y))];   % y 补零到 L

    c = real(ifft(fft(x) .* fft(y)));   % 频域相乘，再反变换回来
    ```

    * 四句话顺序不能乱：先算结果该有多长，再补零，再变换，再变回来。

    * 最后的 `real` 有讲究：补零、变换、反变换走一圈回来理论上应是纯实数，但中间复数运算会留下一点点虚部误差，取实部即可。

    * 两个 10 万点序列相卷积，自带的直接卷积已经慢到屏幕数字半天不动，FFT 版本秒出，结果看着完全一样。

* **画 DTFT 的两条路**

    * 直接代公式：$\omega$ 从 $-\pi$ 到 $\pi$、步长 $0.01$，把 $\dfrac{\sin\left[(n_1+\tfrac12)\right]\omega}{\sin(\omega/2)}$ 代进去取模画图。

        ```matlab
        n1 = 50;
        w  = -pi:0.01:pi;
        y  = abs(sin((n1 + 0.5)*w) ./ sin(w/2));
        plot(w/pi, y)
        ```

    * 走 FFT：

        ```matlab
        n1 = 50;
        x = ones(1, 2*n1+1);       % 101 个点，下标 0 … 2n1
        w = -pi:0.01:pi;           % 六百多个频率点

        x = [x zeros(1, length(w) - length(x))];   % ① 补零到 w 的长度

        y = fft(x);                                % ② 频域值
        y = y .* exp(1j*w*n1);                     % ③ 补回时间平移
        y = real(y);                               % ④ 只取实部
        ```

    * 补零这一步很关键：$x$ 只有 101 个点，不补零的话频域上只拿得到 101 个值；**频域采样点的密度，就是你在时域补了多少零决定的**。

    * 第三步的「乘回去」是因为 FFT 用的下标是 $0\sim2n_1$ 而题目序列是 $-n_1\sim n_1$，两边差一个移位。由 $X_1(j\omega)=\displaystyle\sum_{n=-n_1}^{n_1}x(n)e^{-j\omega n}=e^{+j\omega n_1}\sum_{m=0}^{2n_1}x(m)e^{-j\omega m}$，要乘 $e^{+j\omega n_1}$ 把平移补回来。

    * 走完之后虚部全为零，这与题目里的 $x(n)$ 是实的实序列、其 DTFT 本来就共轭对称相吻合。

    * > **易错点**：这段代码里 FFT 内部的频率下标 $k$ 从 0 开始，而 MATLAB 数组下标从 1 开始，所以遍历时写 $k$ 要写 `i-1`、写 $\omega$ 要写 `w(i-1)`；这个 `i-1` 是两套下标体系的换算，不是手滑。

* **fftshift：把乱掉的频谱摆正**

    * 走 FFT 画出来的图形状眼熟、虚部为零，但**它是乱的**：是一整段一段重复下去的图。

    * 原因：FFT 的每个 $\omega$ 是 $0\sim2\pi$ 均匀采样的，而真实谱本来是 $2\pi$ 为周期、一直重复的；从 $0$ 到 $2\pi$ 看就是两个周期首尾拼起来。

    * 解决办法是在正中间下刀，把后一半原封不动搬到前一半，与它贴上：

        ```text
           fftshift 在正中间下刀，后一半搬到前一半，原封不动：

           索引     0        1        2        3        4
           频率    -π      -π/2       0       π/2       π
           取值    Y(2)     Y(3)     Y(4)     Y(0)     Y(1)
        ```

        ```matlab
        subplot(2,1,1), plot(w/pi, y)                % fftshift 之前：两段重复
        subplot(2,1,2), plot(w/pi, fftshift(y))       % fftshift 之后：正确
        ```

    * 做完移位之后，它与暴力求解画出来的那张图完全一样，两张图叠在一起严丝合缝。

    * 自己编一个 `fftshift` 的核心就一句话：把序列从中间截断，把后面那一半搬到前面去；偶数长度与奇数长度的处理稍有不同，中间那一个算在哪一边要自己想清楚。
