# 拉普拉斯变换解常微分方程与初值终值定理

## 初值定理与终值定理

### 定理陈述与适用对象

* **初值定理（initial value theorem）**

    * > **定义**：对因果信号 $x(t)$，若拉氏变换为 $X(s)$，则 $x(0)=\lim_{s\to+\infty}sX(s)$。

    * 适用对象被第一条就钉死为**因果信号**，非因果信号不适用。

* **终值定理（final value theorem）**

    * > **定义**：对因果信号 $x(t)$，若拉氏变换为 $X(s)$，则 $\lim_{t\to+\infty}x(t)=x(+\infty)=\lim_{s\to0}sX(s)$。

* 两条定理的极限方向正好相反，不要写颠倒。

    * $s\to+\infty$ 那条给出信号刚起来那一刻的值。
    * $s\to0$ 那条给出信号稳定下来之后的值。
    * 两条定理的共同根源都是「因果」这一条件：因果才使 $X(s)$ 的积分下限为 $0$，两条极限过程才成立。

### 初值定理的推导

* 推导链条共四步。

    * 第一步，因果信号满足 $x(t)=x(t)u(t)$，因为 $t<0$ 时它为零，补一个单位阶跃什么也不改变。
    * 第二步，把 $x(t)$ 泰勒展开为 $x(t)=x(0)+x'(0)t+x''(0)\frac{t^2}{2!}+\cdots$。
    * 第三步，逐项做拉氏变换，用到对应对应关系

        $$t^{n-1}u(t)\;\longleftrightarrow\;\frac{(n-1)!}{s^n},\qquad \mathrm{Re}(s)>0$$

        于是 $u(t)$ 取 $n=1$ 得 $\frac{0!}{s}=\frac{1}{s}$，$tu(t)$ 取 $n=2$ 得 $\frac{1!}{s^2}$，$t^2u(t)$ 取 $n=3$ 得 $\frac{2!}{s^3}$，前面的 $\frac{1}{2!}$ 恰好约掉。
    * 第四步，左右同乘 $s$ 后取极限

        $$X(s)=\frac{x(0)}{s}+\frac{x'(0)}{s^2}+\frac{x''(0)}{s^3}+\frac{x'''(0)}{s^4}+\cdots$$

        $$sX(s)=x(0)+\frac{x'(0)}{s}+\frac{x''(0)}{s^2}+\cdots\;\xrightarrow{\,s\to+\infty\;}\;x(0)$$

* > **易错点**：定理要有成立条件。要证明严谨必须保证 $x(t)$ 里不含 $\delta(t)$ 以及 $\delta(t)$ 的导数项，否则 $x'(0)$、$x''(0)$、$x'''(0)$… 中会出现无穷大，$1/s$ 压不住，$s\to+\infty$ 的极限不存在，定理随之失效。

### 终值定理的推导

* 核心是考察同一个积分 $\int_{0}^{+\infty}x'(t)e^{-st}dt$，朝 $s\to0$ 的方向算，分成两条路。

    * 算法一：让 $e^{-st}$ 自己走到 $1$，积分变成 $\int_{0}^{+\infty}x'(t)dt=x(+\infty)-x(0)$。
    * 算法二：把 $x'(t)dt$ 看成 $d(x(t))$，对同一个积分做分部积分。无穷远处的边界项 $x(t)e^{-st}$ 在 $t\to+\infty$ 时取极限为零，$t=0$ 处 $e^{-s\cdot0}=1$ 只剩 $-x(0)$，另一项积分正好是 $X(s)$，结果为 $sX(s)-x(0)$。
    * 两条路的结果一对比即得 $\lim_{s\to0}sX(s)=x(+\infty)$。

* 两种算法的分岔结构如下。

    ```text
          同一个积分  ∫₀^∞ x'(t)·e^(-st)dt ，令 s→0
                        |
            ┌───────────┴───────────┐
            ▼                       ▼
      算法一：e^(-st) → 1      算法二：x'(t)dt 看成 d(x(t))
            |                       |
    ∫₀^∞ x'(t)dt = x(+∞) − x(0)   分部积分
            |                       ├─ 边界项 [x(t)e^(-st)]₀^∞ → 0
            |                       └─ −∫₀^∞ x(t)d(e^(-st))
            |                          = −x(0) + s·X(s)
            └───────────┬───────────┘
                        ▼
        lim_{s→0} s·X(s)  =  lim_{t→+∞} x(t)  =  x(+∞)
    ```

* 算法二里之所以能把 $X(s)$ 当成从 $0$ 积，是因为 $x(t)$ 是因果信号：常规定义从 $-\infty$ 积到 $+\infty$，而 $-\infty$ 到 $0$ 那一段贡献为零，等效于从 $0$ 起积。

### 用 $e^{-at}u(t)$ 试算

* 取 $x(t)=e^{-at}u(t)$，其拉氏变换为 $\frac{1}{s+a}$，收敛域 $\mathrm{Re}(s)>-a$。

    * 代初值定理：$x(0)=\lim_{s\to+\infty}\frac{s}{s+a}=1$，与 $e^{-at}$ 在 $t=0$ 处取 $1$ 一致。
    * 代终值定理：$x(+\infty)=\lim_{s\to0}\frac{s}{s+a}=0$，与指数衰减到零一致。
    * 这一例正说明两条定理成立的前提是「因果信号」这一条件。

## 单边周期信号的拉氏变换

### 定义与推导

* **单边周期信号（unilateral periodic signal）**

    * > **定义**：只在 $t>0$ 时有值、$t<0$ 那一段为空的周期信号。

    * 它与前面讲的周期信号不同：普通周期信号在整条时间轴上双向铺开，单边周期信号不往 $t<0$ 一侧回铺。

* 由时移性质，$x(t-nT)$ 的拉氏变换为 $e^{-nsT}X(s)$，收敛域仍是 $X(s)$ 原来的收敛域 $R$。

* 把全部平移量加起来构成 $x_T(t)=\sum_{n=0}^{+\infty}x(t-nT)$，其拉氏变换为一个无限和式：

    $$X_T(s)=\Big[1+e^{-sT}+e^{-2sT}+\cdots+e^{-nsT}\Big]X(s)$$

* 该和式是等比级数，用等比求和公式并取 $n\to+\infty$，得到结论式：

    * > **结论**：$X_T(s)=\dfrac{X(s)}{1-e^{-sT}},\qquad \mathcal{R}_T=R\cap\{\mathrm{Re}(s)>0\}$。

    * 化简时要求 $\lim_{n\to+\infty}e^{-(n+1)sT}=0$，前提条件正是 $\mathrm{Re}(s)>0$。
    * 收敛域由两部分相交得到：原收敛域 $R$ 与右半平面 $\mathrm{Re}(s)>0$ 的交集。

### 两道例题

* 冲激串 $\delta_T(t)u(t)=\sum_{n=0}^{+\infty}\delta(t-nT)$：在 $0$、$T$、$2T$、$3T$… 处各有一个强度为 $1$ 的冲激，只在 $t\ge0$ 一侧铺开。

    * 直接套公式，$\delta(t)$ 的拉氏变换是 $1$、收敛域为全平面，所以 $X(s)=1$。
    * 结果为 $X_T(s)=\dfrac{1}{1-e^{-sT}}$，收敛域是全平面与 $\mathrm{Re}(s)>0$ 相交，得 $\mathrm{Re}(s)>0$。

* 单边矩形串：每个周期内前一半为 $1$（$0$ 到 $T/2$）、后一半为 $0$（$T/2$ 到 $T$），此后一直重复。

    * 先只求一个周期内那段 $0$ 到 $T/2$ 为 $1$ 的信号，由直接积分得 $\int_{0}^{T/2}e^{-st}dt=\frac{1}{s}\big(1-e^{-s\frac{T}{2}}\big)$。
    * 再乘上周期化因子，结果为 $\frac{1}{s}\big(1-e^{-s\frac{T}{2}}\big)\cdot\frac{1}{1-e^{-sT}}$。
    * 单个矩形是时限信号、收敛域为整个平面，故总收敛域为 $\mathrm{Re}(s)>0$。

### 两种算法的答案一致

* 同一段矩形脉冲，用傅里叶变换绕一圈算出的拉氏变换与直接积分完全相同。

    * 矩形的傅里叶变换为 $\frac{T}{2}\,\mathrm{Sa}\big(\frac{T}{4}\omega\big)e^{-j\omega\frac{T}{4}}$，三件事分别是：矩形脉冲本身的频谱 $\mathrm{Sa}\big(\frac{T}{4}\omega\big)$、右移 $T/4$ 乘上的相位因子 $e^{-j\omega\frac{T}{4}}$、面积 $\frac{T}{2}$。
    * 做拉氏变换时把 $\omega$ 换成 $\frac{s}{j}$ 即可：$\frac{1-e^{-j\frac{T}{2}\omega}}{j\omega}$ 中的 $j\omega$ 直接认作 $s$，得到 $\frac{1-e^{-s\frac{T}{2}}}{s}$，与直接积分结果一致。

* > **结论**：拉氏变换表达式可由傅叶变换表达式把 $\omega$ 换成 $\frac{s}{j}$ 得到，这条路走通等于在同一道题上把两个变换各练一遍。

## 常微分方程的三种表达形式

### 三种形式是同一系统的三套语言

* 三种形式分别是公式形式（微分方程等式）、系统函数形式 $H(s)$、系统框图形式。

    * 三者描述的不是三个不同系统，而是同一个 LTI 系统的三种写法，彼此可随时互相翻译。

* 通用二阶常系数方程写作

    $$a_2y''(t)+a_1y'(t)+a_0y(t)=b_2x''(t)+b_1x'(t)+b_0x(t)$$

* 实际书写中常把自变量 $t$ 省掉、撇号直接写在符号后面：

    $$a_2y''+a_1y'+a_0y=b_2x''+b_1x'+b_0x$$

### 公式形式与系统函数形式的互化

* **公式形式（differential equation form）**

    * 输入为 $x$、输出为 $y$，$y$ 侧的二阶导、一阶导、本身的线性组合系数分别记作 $a_i$，$x$ 侧对应记作 $b_i$，得到一个常系数微分方程。
    * 读系数时按项数，$x$ 侧不存在的导数项其系数是 $0$ 而不是「不用管」；例如 $y''+\frac{3}{2}y'+\frac{1}{2}y=x$ 对应 $a_2=1$、$a_1=\frac{3}{2}$、$a_0=\frac{1}{2}$、$b_0=1$、$b_1=b_2=0$。

* **系统函数形式（system function form）**

    * 对应表达式为 $H(s)=\dfrac{b_2s^2+b_1s+b_0}{a_2s^2+a_1s+a_0}$，长得和微分方程几乎一样，但不是猜的。
    * 推导只用时域微分性质一条：微分对应乘 $s$，即 $y'\leftrightarrow sY(s)$、$y''\leftrightarrow s^2Y(s)$（$x$ 侧同理）。
    * 该性质的适用前提是 $x(t)$、$y(t)$ 的收敛域至少包含全实轴，自己算题时不能忽略这一隐含条件。
    * 逐项变换后提公因式得 $(a_2s^2+a_1s+a_0)Y(s)=(b_2s^2+b_1s+b_0)X(s)$；又因微分器是 LTI 系统、线性组合仍是 LTI 系统，时域卷积对应拉氏域相乘，故 $H(s)=Y(s)/X(s)$。

* 互化是纯代入，不需要推导。

    * 方程 → 系统函数：分子按 $b_i$ 配、分母按 $a_i$ 配。$y''+3y'+2y=x''+2x$ 直接得 $H(s)=\frac{s^2+2}{s^2+3s+2}$。
    * 系统函数 → 方程：把 $s^n$ 换回第 $n$ 阶导数。$H(s)=\frac{s^2+3s+2}{s^2+5s+6}$ 得 $y''+5y'+6y=x''+3x'+2x$。

* > **易错点**：$x(t)$ 那一侧的导数项「没有」不等于「系数随便写」，它是 $0$。判断 $b_1$、$b_2$ 要按项数，不要凭感觉。

### 框图形式与中间变量定理

* **中间变量定理**

    * > **定义**：若 $w(t)$ 是方程 $a_2w''+a_1w'+a_0w=x$ 的解，则 $y=b_2w''+b_1w'+b_0w$ 是方程 $a_2y''+a_1y'+a_0y=b_2x''+b_1x'+b_0x$ 的解。

    * 它的实质是引入中间变量 $w$：先由 $x$ 生成 $w$，再由 $w$ 线性组合出 $y$。框图能画出来正是因为这条定理。
    * 证明骨架只有一句：由 $y=b_2w''+b_1w'+b_0w$ 逐阶求导，把 $a_2y''+a_1y'+a_0y$ 按 $b_i$ 归并成 $b_2(a_2w^{(4)}+a_1w'''+a_0w'')+b_1(a_2w'''+a_1w''+a_0w')+b_0(a_2w''+a_1w'+a_0w)$，再把「$w$ 满足的那个方程」整体代入，导数阶数自动降下来。

* 框图分两步画。

    * 第一步画 $w$ 的生成部分，依据是移项除以 $a_2$ 得 $w''=\frac{1}{a_2}\big(x-a_1w'-a_0w\big)$：输入进加法器，出来乘增益 $\frac{1}{a_2}$ 得 $w''$，经一个积分器得 $w'$，再经一个积分器得 $w$；同时从 $w'$ 引反馈乘 $-a_1$、从 $w$ 引反馈乘 $-a_0$，一起送回输入端加法器。
    * 第二步画 $y$ 的合成部分：由 $y=b_2w''+b_1w'+b_0w$，从 $w''$、$w'$、$w$ 三个节点各引一支，分别乘 $b_2$、$b_1$、$b_0$ 后相加得 $y(t)$。
    * $w''$、$w'$、$w$ 三个节点既是后半段合成 $y$ 的取样点，又是前半段负反馈的取样点，这就是整个框图的全部结构。

    ```text
    x(t) ─► (Σ) ─► [×1/a₂] ─► w″ ─► [∫] ─► w′ ─► [∫] ─► w
              ▲                          │          │
              │                          ▼          ▼
              │                    [×(−a₁)]    [×(−a₀)]
              │                          │          │
              └──────────────────────────┴──────────┘

    w″ ─► [×b₂] ─┐
    w′ ─► [×b₁] ─┼─► (Σ) ─► y(t)
    w  ─► [×b₀] ─┘
    ```

* 两个积分符号把 $w''$ 变成 $w$，依据就是积分式 $w'(t)=\int_{-\infty}^{t}w''(\tau)d\tau$、$w(t)=\int_{-\infty}^{t}w'(\tau)d\tau$。

* 化简框图的两条口诀。

    * > **结论**：系数为 $1$ 可以不写，系数为 $0$ 可以不画。

    * 系数为 $1$ 不写是因为该处增益本就是 $1$，不写也得知道它是 $1$；出题时也常这么出，所以**不写的系数就是 $1$**。
    * 系数为 $0$ 表示那条支路根本不存在，画出来既难看也无意义。
    * 以 $y''+4y'+3y=x'+2x$ 为例：$a_2=1$ 故 $\frac{1}{a_2}=1$，反馈为 $-4$、$-3$，输出侧 $b_2=0$（不画）、$b_1=1$（不写）、$b_0=2$。

* > **易错点**：画框图时**信号流向不能省**，不画流向严格意义上是错的。另外可以在 $w''$、$w'$、$w$ 三个节点上直接标出记号，这不算错且是好习惯。

* > **易错点**：给方程让你写 $H(s)$，写错了微分方程本身仍然对，后面照着解还能解对；给框图让你写微分方程，一旦写错，后面照着它解就肯定错。**从框图往回推的错误率明显更高。**

* 三种形式互译的典型题目与答案。

    | 题目 | 答案 |
    | :--- | :--- |
    | $y''+3y'+2y=x''+2x$，求 $H(s)$ | $\dfrac{s^2+2}{s^2+3s+2}$ |
    | $H(s)=\dfrac{s^2+3s+2}{s^2+5s+6}$，求微分方程 | $y''+5y'+6y=x''+3x'+2x$ |
    | $y''+4y'+3y=x'+2x$，求 $H(s)$ 并画框图 | $H(s)=\dfrac{s+2}{s^2+4s+3}$，$a_2=1,a_1=4,a_0=3,b_1=1,b_0=2$ |
    | 给框图（反馈 $-3$、$-2$，输出侧增益 2 与 1），求方程与 $H(s)$ | $3y'+2y=2x'+x$；$H(s)=\dfrac{2s+1}{s^2+3s+2}$ |
    | $H(s)=\dfrac{s+3}{s^2+5s+6}$，求框图 | $a_2=1$、$a_1=5$、$a_0=6$、$b_1=1$、$b_0=3$，照模板填数即可 |

### 积分器为什么写成 $1/s$

* 由积分式 $y(t)=\int_{-\infty}^{t}x(\tau)d\tau=x(t)*u(t)$ 做拉氏变换并用卷积性质，得

    $$Y(s)=\frac{1}{s}X(s),\qquad \mathrm{ROC}=R\cap\{\mathrm{Re}(s)>0\}$$

    * 所以积分符号与 $\frac{1}{s}$ 是同一回事，两种写法都对。

* 框图偏好积分器而非微分器，原因是**框图就是电路图**：微分器同样能搭出系统，但一个电容就能实现积分，硬件上极容易，所以现实中的大多数框图都基于 $\frac{1}{s}$ 的积分器画出。

* 分子分母约分等价于系统中某些环节可以消掉。

    * $\dfrac{s^2+3s+2}{s^2+7s+6}=\dfrac{(s+1)(s+2)}{(s+1)(s+6)}=\dfrac{s+2}{s+6}$，对应方程约简为 $y'+6y=x'+2x$，框图只剩一个积分器。
    * 考场上若把题出成化简前的形式，画化简前或化简后的框图都可以，但心里要有「约分等价于环节消掉」这根弦。

### 读不懂的框图就倒着标 $s$ 域量

* 有的框图画法与标准画法形状差别很大，本质只是同一张图转了 $90^\circ$。

* 通用做法是从输出节点开始倒着标 $s$ 域的量。

    * 输出节点是 $Y(s)$；往回过一个 $\frac{1}{s}$，上游节点就是 $sY(s)$；再往回过一个 $\frac{1}{s}$，就是 $s^2Y(s)$。
    * 标完后加法器各输入就全清楚了：来自 $s^2Y(s)$ 的那一条、来自负反馈支路的那几条、剩下那个是输入 $X(s)$。
    * 以 $H(s)=\frac{1}{s^2+3s+2}$ 为例，汇总得 $s^2Y(s)=X(s)-3sY(s)-2Y(s)$，化简即 $(s^2+3s+2)Y(s)=X(s)$，故 $H(s)=\frac{1}{s^2+3s+2}$。
    * 同法验证 $y'+y=x$ 那类图：设输出节点为 $Y(s)$，上游即 $sY(s)=X(s)-Y(s)$，整理得 $H(s)=\frac{1}{s+1}$。

* > **结论**：碰到看不懂的信号流图，就用「从输出倒着标 $s$ 域量」的办法推。方法繁琐，但总归能推出来。

* 另有一个工具叫梅森公式：给定信号流图，按闭合环路个数用一个公式直接写出 $H(s)$。

    * 它与倒推法本质是同一件事，也可以不学；真碰到不会画的图，按倒推法自己推一遍结果肯定一样。

### 串联型与并联型

* **串联型（cascade form）**

    * 把 $H(s)$ 拆成两级相乘，每级各画一个「输入进加法器、反馈乘 $-a$、再过一个 $\frac{1}{s}$」的模块，首尾相接。
    * 以 $H(s)=\frac{1}{s^2+3s+2}=\frac{1}{(s+1)(s+2)}$ 为例，拆成 $\frac{1}{s+1}\times\frac{1}{s+2}$，于是 $Y(s)=\frac{1}{s+1}\cdot\frac{1}{s+2}X(s)$。

    ```text
    x(t) ─► (Σ₁) ─► [1/s] ─► ● y₁ ─► (Σ₂) ─► [1/s] ─► ● y(t)
              ▲               │            ▲               │
              └──[ ×(−1) ]────┘            └──[ ×(−2) ]────┘
    ```

* **并联型（parallel form）**

    * 把 $H(s)$ 做部分分式展开，输入一分为二，各走一级 $\frac{1}{s}$ 加自身反馈的模块，末端求和。
    * 同一例做部分分式展开得 $\frac{1}{s^2+3s+2}=\frac{1}{s+1}-\frac{1}{s+2}$，上半支路对应 $\frac{1}{s+1}$、增益为 $1$，下半支路对应 $\frac{1}{s+2}$ 且整体带负号，两路在末端相加。

    ```text
              ┌────────[ ×(−1) ]◄────────┐
              │                           │
    x(t) ──┬──►(Σ₁)──►[ 1/s ]──►[ ×1 ]────┴──►(Σ)──► y(t)
           │    ▲                                ▲
           │    └────[ ×(−2) ]◄──┐               │
           │                      │               │
           └──►(Σ₂)──►[ 1/s ]─────┴──►[ ×(−1) ]───┘
    ```

* > **结论**：串联型与并联型不要求主动去画，但**考场上出到了要能看懂，并能通过它把 $H(s)$ 算出来**。

## 用拉氏变换解常微分方程的三种题型

### 三种题型的划分

* 三种题型的区别只在于「多给了什么条件」。

    | 题型 | 已知的东西 | 要求的东西 | 核心动作 |
    | :--- | :--- | :--- | :--- |
    | 一 | 微分方程 + 输入 $x(t)$ | 输出 $y(t)$ | 直接取 $H(s)=Y(s)/X(s)$，部分分式，反变换收工 |
    | 二 | 微分方程 + 在 $t<0$ 也有定义的输入 | 输出 $y(t)$ | 补定理，把输入拆成指数信号，逐个过系统再叠加 |
    | 三 | 微分方程 + 输入 + **输出的初值** | 输出 $y(t)$ | 单边拉氏变换，答案拆成零输入响应 + 零状态响应 |

* 题型一做熟了根本不用想，题型二要多想一层，题型三多一整套工具。

### 题型一：给方程、给输入

* 标准流程是先写系统函数、查表得输入变换、相乘得 $Y(s)$、做部分分式、反变换。

    * 例：$y''+3y'+2y=x$，$x(t)=e^{-t}u(t)$。

        * $H(s)=\frac{1}{s^2+3s+2}=\frac{1}{(s+1)(s+2)}$，$X(s)=\frac{1}{s+1}$（收敛域 $\mathrm{Re}(s)>-1$）。
        * $Y(s)=\frac{1}{(s+1)^2(s+2)}=\frac{A}{s+1}+\frac{B}{(s+1)^2}+\frac{C}{s+2}$。
        * 反变换用 $t^ne^{-at}u(t)\longleftrightarrow\frac{1}{(s+a)^{n+1}}$，取 $n=1,a=1$ 得 $te^{-t}u(t)\longleftrightarrow\frac{1}{(s+1)^2}$。
        * 结果 $y(t)=\big[e^{-2t}-e^{-t}+te^{-t}\big]u(t)$。

* 部分分式系数的取法与结果。

    | 系数 | 取法 | 值 |
    | :--- | :--- | :--- |
    | $B$ | 盖住 $(s+1)^2$，令 $s=-1$ | $1$ |
    | $C$ | 盖住 $(s+2)$，令 $s=-2$ | $1$ |
    | $A$ | 分子分母同乘后取恒等式，代特殊值 $s=0$（或比较系数） | $-1$ |

* > **易错点**：$(s+1)$ 与 $(s+1)^2$ 是两个不同的因子，拆的时候都要出现。只有分子次数小于分母时才可以整块约掉，分子是常数时永远约不掉 $(s+1)$。

* > **易错点**：求挂一次因子那个系数时不能直接盖。$A$ 前面挂着 $(s+1)$，直接盖会把 $(s+1)^2$ 里剩下的一层也带进分子，值就错了；要么通分后取恒等式代特殊值，要么比较系数。

* 求出系数后必须验算，最省事的办法是再代一个特殊值。

    * 上例代 $s=1$：原式 $\frac{1}{(1+1)^2(1+2)}=\frac{1}{12}$，部分分式 $\frac{1}{3}-\frac{1}{2}+\frac{1}{4}=\frac{4-6+3}{12}=\frac{1}{12}$，两边对上才说明系数算对。

* 例：$y''+\frac{3}{2}y'+\frac{1}{2}y=x$，$x(t)=5e^{-3t}u(t)$。

    * $H(s)=\frac{1}{(s+1)(s+\frac12)}$，$X(s)=\frac{5}{s+3}$（收敛域 $\mathrm{Re}(s)>-3$）。
    * $Y(s)=\frac{5}{(s+1)(s+\frac12)(s+3)}=\frac{A}{s+1}+\frac{B}{s+\frac12}+\frac{C}{s+3}$。
    * 三个系数：盖住 $s+1$ 代 $s=-1$ 得 $A=-5$；盖住 $s+\frac12$ 代 $s=-\frac12$ 得 $B=4$；由通分后 $s^2$ 系数为零得 $-5+4+C=0$，故 $C=1$。
    * 验算：盖住 $s+3$ 代 $s=-3$ 得 $\frac{5}{5}=1$；看常数项 $-5\cdot\frac12\cdot3+4\cdot1\cdot3+1\cdot1\cdot\frac12=5$，与分子 5 对上。
    * 结果 $y(t)=\big[-5e^{-t}+4e^{-\frac12 t}+e^{-3t}\big]u(t)$。
    * 这一版默认 $y(0^-)=y'(0^-)=0$；若额外给了输出初值，就属于题型三，要换方法重做。

### 题型二：输入在负半轴也有定义

* 这类输入在负半轴不衰减，拉氏变换发散，常规的 $Y(s)=H(s)X(s)$ 用不了，必须先补定理。

    * 例：$i''+4i'+3i=r''+3r$，输入 $r(t)$、输出 $i(t)$，$r(t)$ 在 $t>0$ 时为 $4$、$t<0$ 时为 $2$。
    * 这类题的固定套路是：拆输入 → 常数部分用定理 → 剩下的 $u(t)$ 部分回到题型一 → 按拆开的份数把输出叠加回去。

* **指数信号过 LTI 系统定理**

    * > **定义**：设 $x(t)$ 通过系统函数 $H(s)$ 得到 $y(t)$。若 $x(t)=e^{s_0t}$ 且 $s_0$ 在 $H(s)$ 的收敛域内，则 $y(t)=H(s_0)e^{s_0t}$。

    * 一句话含义：指数信号过 LTI 系统，出来仍是同一个指数，系数就是 $H$ 在 $s_0$ 处的取值。
    * 证明从卷积出发：$y(t)=\int_{-\infty}^{+\infty}h(\tau)e^{s_0(t-\tau)}d\tau=e^{s_0t}\int_{-\infty}^{+\infty}h(\tau)e^{-s_0\tau}d\tau=H(s_0)e^{s_0t}$，括号里那一块正是 $H(s_0)$。

* > **易错点**：条件 $s_0$ 在收敛域内绝对不能丢。不在收敛域里时上面那个积分发散，定理不成立，这也是拆输入时必须先确认收敛域的原因。

* 把输入拆成两个指数信号。

    * 上例中 $r(t)=2+2u(t)$，两个输入的叠加对应输出的叠加。

        ```text
           r(t) = 2 + 2u(t)
                  |
                  +--> 输入[1] 常数 2 : s₀ = 0 属于 ROC(H)
                  |                        |
                  |                        v
                  |                  i₁(t) = H(0)·2 = 2
                  |
                  +--> 输入[2] 2u(t)  : 回到题型一, X(s) = 2/s
                                           |
                                           v
                                  i₂(t) = [2 − 4e^(−t) + 4e^(−3t)]u(t)

           LTI 系统：输入可叠加 → 输出可叠加

           i(t) = i₁(t) + i₂(t) = 2 + [2 − 4e^(−t) + 4e^(−3t)]u(t)
        ```

    * > **提示**：那个「$2+$」是必须补上的。$2u(t)$ 只描述了 $t>0$ 的部分，$t<0$ 那一段的常数 2 本身就是一个非零输入项，不能扔掉。很多人拆输入就栽在这里。

* 常数输入那一路用定理算。

    * 常数 $2$ 就是 $2\cdot e^{0\cdot t}$，即 $s_0=0$ 的指数信号。
    * 系统函数 $H(s)=\frac{s^2+3}{s^2+4s+3}=\frac{(s+1)(s+3)}{s^2+3}$，代 $s=0$ 得 $H(0)=\frac{3}{3}=1$，故输出为 $2H(0)=2$。
    * 也可直接看微分方程验证：令输入恒为 $2$，则 $r'$、$r''$ 均为零，右端剩 $3\times2=6$；输出取常数 $2$ 时 $i'$、$i''$ 也都为零，左端同样是 $3\times2=6$，对得上。

* $2u(t)$ 那一路回到题型一。

    * $X(s)=\frac{2}{s}$，$Y(s)=\frac{2(s^2+3)}{s(s+1)(s+3)}=\frac{A}{s}+\frac{B}{s+1}+\frac{C}{s+3}$。
    * 盖住 $s$ 代 $s=0$ 得 $A=2$；盖住 $s+1$ 代 $s=-1$ 得 $B=-4$；由通分后 $s$ 的系数为零得 $8-12+C=0$，故 $C=4$。
    * 验算：盖住 $s+3$ 代 $s=-3$ 得 $\frac{24}{6}=4$；看常数项 $2\times1\times3=6$ 与左边 $2\times(0+3)=6$ 对上。
    * 反变换得 $i_2(t)=\big[2-4e^{-t}+4e^{-3t}\big]u(t)$。

* 最后按份数把输出加回来：$i(t)=i_1(t)+i_2(t)=2+\big[2-4e^{-t}+4e^{-3t}\big]u(t)$。

* > **易错点**：算出 $i_2(t)$ 就以为做完了，忘了前面还有一个常数贡献 $2$ 没加回来。做第二类题凡是拆过输入，最后一定要回去检查：拆出来的每一份输入，是不是都有对应的输出被加回去。

* 只写 $[4-4e^{-t}+4e^{-3t}]u(t)$ 的写法在 $t>0$ 上与此答案完全一致（因为 $2+2u(t)$ 在 $t>0$ 等于 $4u(t)$），但它没有给出 $t<0$ 的那一段。

    * 题目问的是 $i(t)$，漏掉 $t<0$ 总归不完整：$t<0$ 时输入确为常数 $2$，按定理输出恒等于 $2H(0)=2$。

* 难在求导那一步的考研原题：因果连续 LTI 系统 $y''+4y'+3y=x'+2x$，$x(t)=u(-t)+2u(t)$。

    * 核心是求导：$x'(t)=-\delta(t)+2\delta(t)=\delta(t)$，一正一负正好抵消。
    * $\delta(t)$ 的拉氏变换是 $1$，故 $sX(s)=1$，$X(s)=\frac{1}{s}$，题目立刻退化成标准题型一。
    * $Y(s)=\frac{s+2}{s(s+1)(s+3)}=\frac{\frac23}{s}-\frac{\frac12}{s+1}-\frac{\frac16}{s+3}$，得 $y(t)=\big[\frac23-\frac12 e^{-t}-\frac16 e^{-3t}\big]u(t)$。
    * 三个系数的取法：盖住 $s$ 代 $s=0$ 得 $\frac23$；盖住 $s+1$ 代 $s=-1$ 得 $-\frac12$；由通分后 $s^2$ 系数为零得 $\frac12-\frac23+$ 问号 $=0$，故问号为 $-\frac16$，再盖住 $s+3$ 代 $s=-3$ 验证。

### 题型三：还要给输出的初值

* 题型三的核心特征是除了输入还要给**输出**的初值，不是输入的初值。

    * 例：$y''+\frac{3}{2}y'+\frac{1}{2}y=x$，$x(t)=5e^{-3t}u(t)$，$y(0^-)=1$，$y'(0^-)=0$。
    * 它必须用单边拉氏变换，原因是常规拉氏变换会把 $t<0$ 那一段也积进去，而题型三的答案恰恰由 $t<0$ 的初值决定，那一段不能丢。

## 单边拉氏变换

### 定义与记号

* **单边拉氏变换（unilateral Laplace transform）**

    * > **定义**：$X_+(s)=\int_{0}^{+\infty}x(t)e^{-st}dt$，常规双边拉氏变换则是 $X(s)=\int_{-\infty}^{+\infty}x(t)e^{-st}dt$。

    * 两个定义的唯一区别是**积分下限**：常规从 $-\infty$ 起积，单边从 $0$ 起积。
    * 记号上可以区分：常规写 $X(s)$，单边在 $X(s)$ 上加一杠写成 $\bar X(s)$。

* > **结论**：对**因果信号**，单边拉氏变换等于常规拉氏变换，即 $\bar X(s)=X(s)$（当 $x(t)=0,\ \forall t<0$）。

    * 道理是因果信号在 $t<0$ 为零，常规变换里从 $-\infty$ 到 $0$ 那段积分贡献为零，整个丢掉即可。

### 单边与双边不一定相等

* 求 $x(t)=e^{-at}u(t+1)$ 的双边与单边拉氏变换，两者结果不同。

    * 双边：令 $g(t)=e^{-at}u(t)$，则 $x(t)=g(t+1)=g(t-t_0)$，其中 $t_0=-1$，套时移性质得 $X(s)=e^{-st_0}\cdot\frac{1}{s+a}=\frac{e^{s}}{s+a}$。
    * 单边：$t>0$ 时 $u(t+1)$ 恒为 $1$，积分退化为 $\int_{0}^{+\infty}e^{-(s+a)t}dt=\frac{1}{s+a}$。
    * 两者收敛域都是 $s>-a$。

* 差别来自信号本身的形状：该信号是 $e^{-at}u(t)$ 整体左移一位，$[-1,0)$ 这一段在双边变换里要算、单边变换里压根不出现。

    ```text
    x(t)
     ^
     |                     /
     |                   /
     |                 /
     |               /
     |_____________./________________> t
                    -1   0
                    |<--->|
                    单边不算的这一段

       [-1, 0) 这一段：双边变换里要算，单边变换里压根不出现
       所以两个积分当然不会一样
    ```

* > **结论**：同一条曲线，单边与双边拉氏变换**不相等**；单边丢掉的正是 $t<0$ 那一段。

### 时域微分性质

* **单边时域微分性质**

    * > **定义**：若 $x(t)$ 的单边拉氏变换为 $\bar X(s)$，则 $\mathcal{L}_+\big[x'(t)\big]=s\bar X(s)-x(0^-)$。

    * 用不上的初值在这里露头，这是单边与双边最要命的一处差别。
    * 一句话概括：$x'$ 的单边拉氏变换等于 $x$ 的单边拉氏变换乘 $s$，再减掉 $x(0^-)$。

* 推导走分部积分，取 $u=x'(t)$、$dv=e^{-st}dt$，则 $v=-\frac{e^{-st}}{s}$。

    * 无穷远处那一项取极限为零（只要 $\bar X(s)$ 收敛），$t=0$ 时 $e^{0}=1$，只剩 $-\frac{x(0)}{s}$；剩下那一项积分把 $\frac1s$ 与负号消化掉，正好是 $\bar X(s)$。
    * 于是结果为 $-\frac{x(0)}{s}+\bar X(s)=\frac{s\bar X(s)-x(0)}{s}$，通分即得 $s\bar X(s)-x(0^-)$，与书上写法是同一件事。

* > **提示**：这里的 $x(0^-)$ 取的是 $0$ 左侧的极限值。信号若在 $0$ 处跳变，一定要分清跳变前后，别把 $x(0^+)$ 顺手写上去。

* 二阶与高阶导数由一阶反复套用得到：

    $$\mathcal{L}_+\big[x''(t)\big]=s^2\bar X(s)-sx(0^-)-x'(0^-)$$

    $$\mathcal{L}_+\big[x'''(t)\big]=s^3\bar X(s)-s^2x(0^-)-sx'(0^-)-x''(0^-)$$

    * 规律是 $s^n$ 配一串初值往下排，$s$ 的幂每降一级，导数的阶数升一级。
    * 三阶公式不常考，但真要写也应该能写出来。

* > **易错点**：单边与双边这两套公式长得极像，区别只在有没有那一串初值项。用拉氏变换解常微分方程，解出来的东西**只对 $t\ge0$ 成立**，初值必须写成 $0^-$。

## 零输入响应与零状态响应

### 定义与拆分口诀

* **零输入响应（zero input response，$y_{zi}$）与零状态响应（zero state response，$y_{zs}$）**

    * > **定义**：零输入响应是把输入置零、只靠初值自己跑出来的那部分响应；零状态响应是初值全置零、只靠输入激励出来的那部分响应。

    * 两者可以分开求、最后相加，这就是线性系统的可分解性，与「输入叠加对应输出叠加」是同一个道理。

* > **结论**：拆分口诀——零输入响应是 $t>0$ 没输入、$t<0$ 有状态；零状态响应是 $t<0$ 没状态、$t>0$ 有输入。

    * 所以拿一道题就能当场劈成两道题：零输入那版只把方程右边令为零、初值照抄；零状态那版方程左边照抄、保留输入、初值全清零。

* 第二类题型同样适用这套拆法。

    * 零输入那版把输入里只在正时间存在的部分去掉、$t<0$ 的状态保留，初值从原题抄。
    * 零状态那版初值全清、保留 $t>0$ 的输入。
    * 原输入里像 $2-2u(t)$、$4u(t)$ 这样的表达式之所以会出现，是因为原始输入里既有只在某一侧存在的分量、又有始终存在的常量，两道题各自只留一半。

* 拆法能成立的依据是 LTI 系统的基本性质：同一初始状态下两个输入的响应之和，等于两个输入相加之后的响应；反过来把原输入劈成「只有初始状态起作用」和「只有输入起作用」两半，各求一次再相加，结果与不劈相同。

### 求全响应的完整流程

* 逐项把方程两边往单边拉氏变换上带。

    * $y''\longrightarrow s^2\bar Y(s)-sy(0^-)-y'(0^-)$，$\frac{3}{2}y'\longrightarrow\frac{3}{2}\big[s\bar Y(s)-y(0^-)\big]$，$\frac{1}{2}y\longrightarrow\frac{1}{2}\bar Y(s)$，$x=5e^{-3t}u(t)\longrightarrow\frac{5}{s+3}$。
    * 输入那一项是 $\frac{5}{s+3}$，是因为 $u(t)$ 为因果信号、其单边变换等于双边变换，查表即得，收敛域 $s>-3$。

* 代初值 $y(0^-)=1$、$y'(0^-)=0$ 后整理，先把所有 $\bar Y(s)$ 提出来。

    * $y'(0^-)=0$ 这一项直接划掉；$-sy(0^-)=-s$ 与 $-\frac{3}{2}y(0^-)=-\frac{3}{2}$ 各自挪到右边、符号变号。
    * 得到 $\bar Y(s)\big(s^2+\frac{3}{2}s+\frac12\big)=\frac{5}{s+3}+s+\frac{3}{2}$。
    * 因式分解 $s^2+\frac{3}{2}s+\frac12=(s+1)\big(s+\frac12\big)$。

* 在 $(s+3)$ 上通分之前先做来源标注，不要提前合并。

    $$\bar Y(s)=\underbrace{\frac{5}{(s+1)\big(s+\frac12\big)(s+3)}}_{\text{来自 }X(s)}\;+\;\underbrace{\frac{s+\frac32}{(s+1)\big(s+\frac12\big)}}_{\text{来自初值}}$$

    ```text
      在 (s+3) 上通分后的分子 =    5          +  (s + 3/2)(s + 3)
                                 |                  |
                由 X(s) = 5/(s+3) 带来      由 y(0⁻)、y′(0⁻) 带来
                                 v                  v
                           零状态响应            零输入响应


      拆下来就是：

      Ȳ(s)  =   5 /[(s+1)(s+1/2)(s+3)]   +   (s+3/2) /[(s+1)(s+1/2)]
                 |---- 零状态响应 -----|       |--- 零输入响应 ---|
    ```

    * 左边那一项由 $X(s)$ 带来，对应零状态响应；右边那一项由 $y(0^-)$、$y'(0^-)$ 带来，对应零输入响应。
    * 强行写成单个分式时分子为 $5+\big(s+\frac32\big)(s+3)=s^2+\frac92s+\frac{19}{2}$。

* 部分分式分解要严格跟着上面的标注走，不要自己乱归堆。

    * 零状态那一项：$s=-1$ 得 $-5$，$s=-\frac12$ 得 $4$，$s=-3$ 得 $1$。验算看 $s^2$ 系数 $-5+4+1$ 刚好消掉，常数项 $-\frac{15}{2}+12+\frac12=5$ 正是原分子。
    * 零输入那一项：$s=-1$ 得 $-1$，$s=-\frac12$ 得 $2$。不必盖起来硬展开，验算 $-1\cdot(s+\frac12)+2(s+1)=s+\frac32$ 对上即可。
    * 反变换得 $y_{zs}(t)=-5e^{-t}u(t)+4e^{-\frac12 t}u(t)+e^{-3t}u(t)$，$y_{zi}(t)=-e^{-t}u(t)+2e^{-\frac12 t}u(t)$。
    * 合并得 $y(t)=-6e^{-t}u(t)+6e^{-\frac12 t}u(t)+e^{-3t}u(t)$，与书上答案一致。

* 若题目只求全响应、不要求分开零状态与零输入，就不必把分子分成两段标注，直接算，可省一半功夫。

    * 例：$y''+3y'+2y=x'+3x$，$y(0^-)=1$、$y'(0^-)=0$、$x(t)=e^{-3t}u(t)$。
    * 左边得 $s^2Y(s)-sy(0)-y'(0)+3\big[sY(s)-y(0)\big]+2Y(s)$，右边得 $sX(s)+3X(s)=(s+3)\cdot\frac{1}{s+3}=1$。
    * 整理得 $Y(s)(s^2+3s+2)=1+s+3=s+4$，即 $Y(s)=\frac{s+4}{(s+1)(s+2)}=\frac{3}{s+1}-\frac{2}{s+2}$。
    * 结果 $y(t)=3e^{-t}u(t)-2e^{-2t}u(t)$。

### 自由响应与强迫响应

* **自由响应与强迫响应**

    * > **定义**：自由响应是由系统极点（$H(s)$ 的极点）造成的响应；强迫响应是由输入 $X(s)$ 的极点造成的响应。

* 仍以上题为例：$H(s)=\frac{1}{(s+1)(s+\frac12)}$ 的极点在 $-1$ 与 $-\frac12$，由这两个极点带来的 $-6e^{-t}u(t)$ 与 $6e^{-\frac12 t}u(t)$ 是自由响应；$X(s)=\frac{5}{s+3}$ 的极点在 $-3$，由它带来的 $e^{-3t}u(t)$ 是强迫响应。

* 这套刀法与零输入 / 零状态完全是两套，**不要混**。

    ```text
      y(t)  =   -6e^(-t)u(t)   +   6e^(-t/2)u(t)   +   e^(-3t)u(t)
                |----------- 自由响应 ----------|   |-强迫响应-|
                 极点 -1            极点 -1/2         极点 -3

      刀口：按极点归属切
            自由响应 <- H(s) 的极点
            强迫响应 <- X(s) 的极点


      零输入 / 零状态：按来源切（刀口与上面交叉，注意对照）

      y(t)  =   [ -e^(-t) + 2e^(-t/2) ]   +   [ -5e^(-t) + 4e^(-t/2) + e^(-3t) ]
                   |--- 零输入响应 ---|       |------- 零状态响应 --------|
                    由初始状态造成                由输入造成
    ```

* 同一个 $e^{-t}$ 项，在自由 / 强迫这套刀法里归左边，在零输入 / 零状态这套刀法里归右边；两套拆法的刀口不在一个方向上，各有各的用处。

## 系统函数、冲激响应与稳定性

### 系统函数与冲激响应

* 例：$y''+3y'+2y=x'+3x$，求 $H(s)$ 与 $h(t)$。

    * $H(s)=\frac{s+3}{s^2+3s+2}=\frac{s+3}{(s+1)(s+2)}$，做部分分式得 $\frac{2}{s+1}-\frac{1}{s+2}$。
    * 因是因果系统、收敛域在最右边极点的右边，直接写 $h(t)=\big(2e^{-t}-e^{-2t}\big)u(t)$。

* 该系统的 $S$ 域框图画法有一个「稍微变一下」的地方。

    * 输入的微分项不用单独接一路到输出求和，而是在第一个求和点就与 $3x$ 加起来，再往下微分一级送进输出求和。

    ```text
       x(t) ──┬──►[ ×3 ]──────────┐
              │                    │
              └──►[ d/dt ]──► x' ──┴──►( Σ1 )──► v(t) ──┐
                                                         │
                                                         ▼
                                                     [ d/dt ]
                                                         │
                                                         ▼
       y(t) ──►[ ×(−1) ]──► -y  ──┐              ( Σ2 )───┴──► y''(t)
                                    │                 ▲
       y'(t) ─►[ ×(−2) ]──► -2y' ──┴─────────────────┘

       Σ1 的输出： v = 3x + x'                → 对应分子 s + 3
       Σ2 的输出： y'' = v - y - 2y'          → 对应分母 s² + 3s + 2

       数一数增益：-1 一处，-2 一处，3 一处；两个微分器；一个输出求和节点
    ```

* 收敛域取最右边极点的右边，是**因果有理系统**的固定套路，其条件是分子次数小于分母次数、系数为正实、右半平面无零点。

### 收敛域、零极点图与稳定性

* 上例 $H(s)=\frac{s+3}{(s+1)(s+2)}$ 的零极点图：两个极点在 $-1$、$-2$ 打 $\times$ 号，零点在 $-3$ 用圈表示，因为 $H(s)$ 在 $-3$ 取零。

* 因果系统的收敛域是最右边极点之右，此处为 $\mathrm{Re}\,s>-1$ 这一整片。

* 判断稳定性看的是**收敛域有没有罩住 $j\omega$ 轴**，不是看极点在哪。

    * $j\omega$ 轴是 $\mathrm{Re}\,s=0$ 那条竖轴，正好落在 $\mathrm{Re}\,s>-1$ 里面，所以该系统稳定。

* > **易错点**：这类题的前一问往往只写「画出模拟框图」或只说 $S$ 域框图，没有交代因果还是稳定，后一问却会突然冒出「由于是因果系统」。读到这种话要立刻回头确认前一问写没写因果，没写就别硬塞，按前一问的结论往下推。

* > **结论**：第六章试题汇编里的题基本都考过，值得整体过一遍；这类题型几乎必考，且基本上位于第六章最后的知识点。
