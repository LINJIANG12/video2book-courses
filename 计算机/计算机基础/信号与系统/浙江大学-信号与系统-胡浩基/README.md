# 浙江大学信号与系统（60 讲）

这是浙江大学胡浩基老师 2022 年开设的《信号与系统》课，全 60 集、约 56 小时。课程从「什么是信号、什么是系统」起步，经卷积与 LTI 系统、傅里叶级数与傅里叶变换，一路推进到离散傅里叶变换与快速傅里叶变换、采样定理，最后落到拉普拉斯变换与 Z 变换这两把解常微分方程和差分方程的工具。全程配 MATLAB 演示，把抽象公式落到可运行的程序上。

本课程是 408 考纲里「信号与系统」科目的完整覆盖：卷积与冲激函数、频域分析、采样定理、Z 变换与差分方程、系统的因果性与稳定性，都在课中逐个推导并配例题讲解。

## 怎么学

- **第 1 册打底**：先把信号按维度、连续/离散、一维/二维分清楚，再把系统的线性、时不变、因果、记忆、可逆、稳定六条性质逐条过；这六条后面每章都在用，判不清会一路卡住。
- **第 2 册是全课的地基**：卷积公式要能从推导走一遍，而不是背下来；连续卷积的图解法、冲激函数的性质、卷积与因果性/稳定性的关系，这三样不牢，后面的频域法就没有支点。
- **第 3～5 册按「周期 → 非周期」的顺序推进**：先学傅里叶级数（周期信号）与狄利赫里三条件，再学傅里叶变换（非周期信号）及其九条性质，性质每条都要会「从哪条推出来、用于什么题」。第 4～5 册末尾的调制解调与理想低通滤波器是性质的一次集中应用。
- **第 6～7 册是 DFT/FFT**：课程用 P34 一整集（4 小时 13 分）把 DFT 的九条性质与蝶形运算全部推完，务必跟着推导看，别只记 FFT 结论。这一册也是考试计算题的高发区。
- **第 8 册的采样定理要会证**：奈奎斯特采样率的推导、频谱混叠的直观理解、以及零阶/一阶保持的频谱差异，都是可考内容。
- **第 9～10 册是两把解题工具的对照**：拉普拉斯变换（连续）与 Z 变换（离散）结构完全平行，把一边学熟另一边就是映射。务必掌握收敛域——它决定因果性与稳定性。
- **复习时用 12 篇笔记串主干、用 79 份逐字稿查原话**：每篇笔记开头的知识拓扑树适合快速回顾，逐字稿则用来核对老师的推导顺序与例题讲评。
