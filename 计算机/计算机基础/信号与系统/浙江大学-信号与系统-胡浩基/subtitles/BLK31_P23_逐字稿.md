接下来我们讲今天的课。上一次关于 5.3 节 119 页还留了一个尾巴，就是例 3-17。它稍微难一点，例 3-17 说因果 LTI 系统，它的微分方程是这样的，输入 $x(t) = e^{-t}u(t)$，求输出信号 $y(t)$。我试着给大家做一遍，中间会有一些新的知识点出来，然后我会在间隙给大家讲。

首先你看这里的情况，你把这个微分方程傅里叶变换。微一次分出一个 $j\omega$，所以这里出两个 $j\omega$：
$$(j\omega)^2 Y(j\omega) + 4j\omega Y(j\omega) + 3Y(j\omega) = j\omega X(j\omega) + 2X(j\omega)$$
你相当于把微分方程的每一项都经过傅里叶变换。再接下来你把它写得更详细一点：
$$[(j\omega)^2 + 4j\omega + 3]Y(j\omega) = (j\omega + 2)X(j\omega)$$
在这里：
$$Y(j\omega) = \frac{j\omega + 2}{(j\omega)^2 + 4j\omega + 3}X(j\omega)$$
这一项可以因式分解，它等于：
$$\frac{j\omega + 2}{(j\omega + 1)(j\omega + 3)}X(j\omega)$$
到目前为止没有做错。接下来 $x(t) = e^{-t}u(t)$，那么 $X(j\omega) = \frac{1}{j\omega + 1}$。这两个合并，你会发现有个问题，出现了一个平方项：
$$Y(j\omega) = \frac{j\omega + 2}{(j\omega + 1)^2(j\omega + 3)}$$

当出现平方项的时候，我们怎么把它进行分解？这是我下面要讲的内容。

你看，当
$$Y(j\omega) = \frac{j\omega + 2}{(j\omega + 1)^2(j\omega + 3)}$$
你首先检查，分子是 $j\omega$ 的一次项，分母是 $j\omega$ 的三次项，它是满足分子次数小于分母次数的，它可以用盖起来算其它。但是由于这里有一个平方项，我们必须把它拆成三项：
$$\frac{A}{j\omega + 1} + \frac{B}{(j\omega + 1)^2} + \frac{C}{j\omega + 3}$$

接下来我要说的是，盖起来算其它对于底下这个一次项仍然有用，换句话说，对于 $j\omega + 3$ 这一项依然有用。同时我告诉大家，大家自己可以去推一下、想一下它的道理，盖起来算其它对于这个平方项仍然有用。但是盖起来算其它对 $j\omega + 1$ 这一项没有用。那我们要做的事件是什么呢？我们要做的事件是先把有用的两项用盖起来算其它把它求出来，然后，再接下来我们用观察的方法再把这一项求出来。

这是整个过程，我试着给大家做一遍。

盖起来算其它，我们首先来求这一个。我们算哪一个盖哪一个，我们盖住它。再接下来把 $j\omega = -3$ 带进去。上面分子是 $-3 + 2 = -1$，下面是 $(-3 + 1)^2 = 4$。这里就会得到减掉 $\frac{1}{4}$。

接下来我们来算这一项。这一项我说过，它仍然可以用盖起来算其它来做。我们盖住这一项，把 $j\omega = -1$ 带进去，那么我们将会得到：分子是 $2 - 1 = 1$，分母是 $3 - 1 = 2$。这里是 $\frac{1}{2}$。

接下来我们来看怎么算盖起来算其它没有用的这一项？书上有一个很繁琐的算法，我喜欢用简单的算法。简单的算法是这样——观察法算这一个。

你看，观察法是我喜欢的算法：你把 $j\omega$ 等于一个特殊的值带到左边和右边去，把这个问号算出来。比如你把 $j\omega = 0$ 带进去。你想，$j\omega = 0$，左边将会得到的是 $\frac{2}{1 \times 3} = \frac{2}{3}$。右边我们要算这个问号，这个问号除以 $1$ 就是这个问号；加上 $\frac{1}{2} \div 1^2 = \frac{1}{2}$；再减掉 $\frac{1}{4} \div 3 = \frac{1}{12}$。

你这样一做，这个问号将会等于：
$$\frac{2}{3} + \frac{1}{12} - \frac{1}{2} = \frac{8 + 1 - 6}{12} = \frac{3}{12} = \frac{1}{4}$$
你把 $\frac{1}{4}$ 带进去，这里将会得到 $\frac{1}{4}$。

同学们，当你算完了这里过后，你怎么去验算它呢？验算是这样子的：你再带一个 $j\omega$ 等于特殊的值进去，你看左右两边相不相等。比如你设 $j\omega = 1$ 带进去。左边的分子是 $1 + 2 = 3$，分母是 $2^2 \times 4 = 16$，左边将会得到 $\frac{3}{16}$。右边将会等于 $\frac{1}{4} \div 2 = \frac{1}{8}$，第二项是 $\frac{1}{2} \div 4 = \frac{1}{8}$，第三项将减掉 $\frac{1}{4} \div 4 = \frac{1}{16}$。这明显是相等的，$\frac{2}{16} + \frac{2}{16} - \frac{1}{16}$ 刚好等于 $\frac{3}{16}$，是对的。

我个人认为这种方式是最简单的方式。就是有一个不能用盖起来算其它来做的时候，你带一个特殊的值进去把它算出来。

当你这样做完了过后，你知道你的分解是没有错的，然后接下来是一步一步地写了：
$$y(t) = \frac{1}{4}e^{-t}u(t) - \frac{1}{4}e^{-3t}u(t)$$
关键是中间这一项，你要背公式啊！这个公式将会是什么呢？
$$t e^{-at}u(t) \stackrel{\mathcal{F}}{\longleftrightarrow} \frac{1}{(a + j\omega)^2}$$
有这样一个公式，在前面两节课之前我们是学过的。在书上 116 页，最上面那个续表的最下面那一项，就是 14 个的那一行有这个公式。所以这样一背公式的话，这里将会是加上 $\frac{1}{2}t e^{-t}u(t)$。

这是关于这一道题最后的答案。它的答案就是这样子的。
