第一个知识点：常微分方程的三种表示形式。

第一种表示形式就是大家最常用的、最常见的，它就是一个直接的关系式。公式的形式表达：
$$a_2 y''(t) + a_1 y'(t) + a_0 y(t) = b_2 x''(t) + b_1 x'(t) + b_0 x(t)$$

第一种形式叫做公式的形式。它相当于是说我们要解常微分方程。我相信大家学过微分方程这一门课，所以说大家对这种形式一定是不陌生的。换句话说，输入是 $x$，输出是 $y$。那么它在这里相当于是二阶导、一阶导和原来的 $y$，然后 $x$ 的二阶导、一阶导和原来的 $x$，然后用一些 $a$ 和 $b$ 去做线性的组合，以至于最后能够获得一个常系数的微分方程。

这样的例子在书上有很多，随便举几个。比如说这样子的，238页例6-22：
$$y''(t) + \frac{3}{2}y'(t) + \frac{1}{2}y(t) = x(t)$$

这就是公式形式。为什么呢？这里二阶导，$a_2 = 1$；一阶导，$a_1 = \frac{3}{2}$；$a_0$ 在这里，它是 $y(t)$ 的系数等于 $\frac{1}{2}$。而这里 $x(t)$，$b_0 = 1$，$x(t)$ 就是它，然后 $x(t)$ 的导数项和二阶导数项都没有。这就是一个公式形式的例子。

再接下来我们经常换一种写法，换一种简便的写法：
$$a_2 y''(t) + a_1 y'(t) + a_0 y(t) = b_2 x''(t) + b_1 x'(t) + b_0 x(t)$$
这两种是一样的，它只是把二阶导写成两撇，一阶导写成一撇，这边也是二阶导、一阶导分别写成两撇和一撇，它是一样的。

还有更简单的，你可以 $t$ 也不要，直接写：
$$a_2 y'' + a_1 y' + a_0 y = b_2 x'' + b_1 x' + b_0 x$$
这样写也是对的，都一样的，实际上 $t$ 也可以不要。这是第一种表达方式。

第二种表达方式是拉氏变换表达，第二种是拉氏变换表达式。我们试着把拉氏变换表达式写出来。首先，这一个微分方程如果我直接写拉氏变换表达式，就这么写：
$$H(s) = \frac{b_2 s^2 + b_1 s + b_0}{a_2 s^2 + a_1 s + a_0}$$

这是它的形式。这种形式这样一写，跟上面这个形式是完全一样的。接下来我要讲它是怎么推出来的。我试着给大家推一遍，其实这个东西很简单。

我们首先来看这个微分方程，我们用这种简便的形式：
$$a_2 y'' + a_1 y' + a_0 y = b_2 x'' + b_1 x' + b_0 x$$

接下来我们试着来推一下。两边同时拉氏变换。这里能够得到的是：假设 $y(t)$ 的拉氏变换是 $Y(s)$，那么假设 $x(t)$ 的拉氏变换是 $X(s)$。若
$$y(t) \leftrightarrow Y(s),\quad x(t) \leftrightarrow X(s)$$
则有 $y'(t)$ 拉氏变换根据时域微分性质是 $sY(s)$。这是时域的微分性质，在书上拉氏变换的时域微分性质，在书上222页第(5)下面那里。当然收敛域至少包含 $R$，假设收敛域是 $R$，那么收敛域至少是 $R$。同理，
$$x'(t) \leftrightarrow sX(s)$$
再接下来，$y''(t)$ 拉氏变换相当于是此 $y'$ 的基础之上再做了一个微分，所以相当于是整个这个再乘以一个 $s$，得到的是 $s^2 Y(s)$。同理，$x''(t)$ 的拉氏变换将会得到的是 $s^2 X(s)$。

在这种情况之下，我们用这几个公式就可以把拉氏变换求出来，它将等于：
$$a_2 s^2 Y(s) + a_1 s Y(s) + a_0 Y(s) = b_2 s^2 X(s) + b_1 s X(s) + b_0 X(s)$$
这里相当于是把每一项都进行了拉氏变换。

再接下来你可以把它化简。化简的话相当于是这边三项提一个 $Y(s)$ 出来：
$$(a_2 s^2 + a_1 s + a_0) Y(s) = (b_2 s^2 + b_1 s + b_0) X(s)$$
这边提了一个 $Y(s)$ 出来，这边提了一个 $X(s)$ 出来。再接下来：
$$\frac{Y(s)}{X(s)} = \frac{b_2 s^2 + b_1 s + b_0}{a_2 s^2 + a_1 s + a_0}$$

又由于你可以把这个微分方程看作是一个LTI系统。首先，如果你把 $x(t)$ 看成是输入，把 $y(t)$ 看成是输出，我们在第一章就讲过微分是一个LTI系统，它们叠加起来也是LTI系统。你假设把 $x(t)$ 看成是一个输入，通过系统 $h(t)$ 得到 $y(t)$，这是时域的情况。当然你也可以画一个频域的情况：输入是 $X(s)$，系统是 $H(s)$，输出是 $Y(s)$。在这种情况下一个LTI系统，根据卷积性质：
$$H(s) = \frac{Y(s)}{X(s)}$$
所以直接得出 $\frac{Y(s)}{X(s)} = H(s)$。

所以说，拉氏变换对于微分方程的表达是这样一个简明扼要的形式，直接写 $H(s)$ 等于这个式子。

它的意思是啥呢？首先第一点，我们把微分方程写出来：
$$a_2 y'' + a_1 y' + a_0 y = b_2 x'' + b_1 x' + b_0 x$$

接下来我们要通过一个定理来讲这个框图表达。在68页2.6节里面这些内容都有。这里有一个定理，这个定理是这样说的：

若 $w(t)$ 是以下微分方程的解：
$$a_2 w'' + a_1 w' + a_0 w = x$$
则
$$y = b_2 w'' + b_1 w' + b_0 w$$

$$a_2 y'' + a_1 y' + a_0 y = b_2 x'' + b_1 x' + b_0 x$$

这个东西有点绕。请大家看一下它主要说的意思：如果某一个 $w$ 是以下这个方程的解（换言之这也是一个微分方程，它的输入是 $x$，它的输出是 $w$），换句话说这个关系式是成立的，那么我们把这些 $w$ 组合成一个 $y$，这个 $y$ 就是底下这个方程的解。

相对来说有点绕，我试着给大家证明一下。我们从这里开始证：

$$y = b_2 w'' + b_1 w' + b_0 w$$

$$y' = b_2 w''' + b_1 w'' + b_0 w'$$

$$y'' = b_2 w^{(4)} + b_1 w''' + b_0 w''$$

再接下来你可以把这个东西代进去：

这样我们就证完了。它的意思就是引入了一个中间变量 $w$，假设它是这个方程的解，那么用这些 $w$ 去组合成 $y$，得到了原来的解。

通过这个证明，接下来我们来告诉大家怎么样子画系统的框图。

我们首先来把 $w$ 画出来。因为有这个公式：
$$a_2 w'' + a_1 w' + a_0 w = x$$
你把这个关系式稍微变一下，它将得到：
$$w'' = \frac{1}{a_2} (x - a_1 w' - a_0 w)$$
这当然是成立的，把这两项移过来然后再除以 $a_2$。接下来我们就用这个关系式来画框图的第一部分。

输入是 $x(t)$，通过一个加法器，乘以增益 $\frac{1}{a_2}$ 得到 $w''$；
$w''$ 经过一个积分模块 $\int$ 得到 $w'$；
$w'$ 经过一个积分模块 $\int$ 得到 $w$；
$w'$ 反馈引出，乘以 $-a_1$ 送入输入加法器；
$w$ 反馈引出，乘以 $-a_0$ 送入输入加法器。

这个图就是这个公式。为什么呢？首先我们看这一路，这个符号叫做积分符号。我们假设这里是 $w''$，它经过一次积分将会得到 $w'$。这个积分符号如果写出来的话：
$$w'(t) = \int_{-\infty}^{t} w''(\tau) d\tau$$
它是一个积分的符号。同理：
$$w(t) = \int_{-\infty}^{t} w'(\tau) d\tau$$
这都是两个积分符号，把 $w''$ 变成 $w'$，再变成 $w$。

箭头是信号流的流向。仔细看一下，这里是 $w''$，它等于输入 $x(t)$ 加上反馈的 $-a_1 w'$，再加上反馈的 $-a_0 w$，再乘以 $\frac{1}{a_2}$。你仔细对比这个公式和这张图，你会发现这张图把这个公式完全画了出来。

再接下来我们要画 $y$。由于公式：
$$y = b_2 w'' + b_1 w' + b_0 w$$
我们如果要画 $y$ 的话，只需要在这里引出来加上另外一半：
从节点 $w''$ 引出一条支路，乘以增益 $b_2$；
从节点 $w'$ 引出一条支路，乘以增益 $b_1$；
从节点 $w$ 引出一条支路，乘以增益 $b_0$；
三路相加，输出得到 $y(t)$。

我们刚才已经解释了为什么这里会是 $w''$、这里会是 $w'$、这里会是 $w$。然后 $y$ 由于等于 $b_2 w'' + b_1 w' + b_0 w$，这样一加将会得到 $y$。

所以说，这样一个信号流图表达的就是这样一个微分方程。这是关于信号流图它所说的意思。
