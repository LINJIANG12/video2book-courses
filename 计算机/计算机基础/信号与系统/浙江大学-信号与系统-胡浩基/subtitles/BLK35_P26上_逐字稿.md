我不按照书上的讲，我觉得书上讲得太繁琐，我按照我的想法讲。请大家记住几句话，当然你也要记住这几句话所说的道理，你就能够知道了。
首先请大家记住两句话，叫做：实偶对实偶，实奇对虚奇。
这是重点，我要告诉大家这是重点。除了考试是重点，对于傅里叶变换的理解，这里也是重点。

我依次给大家讲。这两句话叫做实偶对实偶，实奇对虚奇，它的意思是什么？
它的意思是说，如果小的 $x(t)$——第一个我们看实偶对实偶的意思——如果小的 $x(t)$ 是关于 $t$ 的偶函数，那么大的 $X(j\omega)$ 它的傅里叶变换是关于 $\omega$ 的偶函数。同时，小的 $x(t)$ 是一个实函数，同时是一个偶函数，叫做实偶函数，那么它的大 $X(j\omega)$ 它也是一个实函数加偶函数。
同样的道理，如果小的 $x(t)$ 是实函数，同时是奇函数，那么大的 $X(j\omega)$ 它也是 $\omega$ 的奇函数，当然它是一个纯虚的奇函数。

证明其实很好做，你看：
$$X(j\omega) = \int_{-\infty}^{+\infty} x(t) e^{-j\omega t} dt = \int_{-\infty}^{+\infty} x(t) \cos(\omega t) dt - j \int_{-\infty}^{+\infty} x(t) \sin(\omega t) dt$$
接下来根据这个公式我们就来分析。

假设 $x(t)$ 是一个实函数，就它没有虚部，同时它是一个偶函数，就叫做实偶函数，我们来看将会出现什么情况。
首先第一点，当 $x(t)$ 是实函数，你能够马上得到这一块是实函数。$j$ 之后这一块它也是实函数。因为 $x(t)$ 是实函数，$\cos$ 是实函数，这么一积起来，它也是实函数，它也是实函数。
再接下来，$x(t)$ 假设是偶函数的话，导致的结果将会是这一片等于 0。为什么呢？偶函数乘以奇函数等于奇函数，负无穷大到正无穷大积分，奇函数是等于 0 的。这一块将会等于 0，那么我们 $X(j\omega)$ 只有这一块。
当这一片等于 0 了过后，你马上能够得到，因为 $x(t)$ 是实函数，这一片也是实函数，因此它也是实函数。

我们再来看 $X(j\omega)$ 是不是偶函数。你可以看，假设 $X(-j\omega)$ 它将等于多少呢？$\omega$ 变负，这里打一个负，这里也打一个负。但是 $\cos(-\omega t) = \cos(\omega t)$，所以说 $X(-j\omega) = X(j\omega)$，你非常容易能够看到，所以说它也是偶函数。
这就是实偶对实偶的原因。实偶函数对应着的是实偶函数。

接下来我们要证明下一个：实奇对虚奇。
它说的意思是，$x(t)$ 是一个实奇函数，那么我们来看一下 $X(j\omega)$ 将会是一个什么样的函数。
同样的分析，这里是实函数，以至于这一块和这一块它都是实函数。再接下来，由于 $x(t)$ 是奇函数，你马上得到的结果是这一块等于 0。为什么呢？这是奇函数，这是偶函数，它们一乘得到奇函数，负无穷大到正无穷大积分它是等于 0 的。那就只剩下这一块了。
首先，由于这一块是实函数，加了一个 $j$，它就变成了一个纯虚函数。所以说这是虚函数。
那么我们再看，在这一块等于 0 的情况下，它是不是一个奇函数？你可以看到，假设这里 $X(-j\omega)$，它意味着这里加一个负号。这一片反正都等于 0 了，它就等于这里加一个负号。当这里加出一个负号的时候，它刚好就是等于 $-\sin(\omega t)$，负号被拿出去，所以说 $X(-j\omega) = -X(j\omega)$。所以说它就是虚函数，而且是奇函数。

这里我们通过这样的探讨，证明了实偶对实偶，实奇对虚奇。
当然你还有另外一种记法。如果你对傅里叶变换的性质有更深刻的理解，你能够用更好的方式来记它。它的意思是：
若 $x(t)$ 是实偶函数，则它的傅里叶变换 $X(j\omega)$ 只有余弦分量。
第二句话当然是这样子的：若 $x(t)$ 是实奇函数，则 $X(j\omega)$ 只有正弦分量。

这个意思是一样的，它的推导也是一样的。因为余弦是偶函数，正弦是奇函数。所以说这边是偶函数，它跟余弦和正弦作用，它的奇函数那部分就没有了，它只有跟它同样的偶函数部分。同样的道理，如果 $x(t)$ 是奇函数，那么它一作用，余弦的偶函数的部分就没有了，它只有正弦的部分奇函数。这里讲到的是实偶对实偶，实奇对虚奇。

当你掌握了实偶对实偶、实奇对虚奇的时候，你看傅里叶变换的样子，你会觉得很有趣。你看，这里比如一个方波，$-T_0$ 到 $T_0$ 这里是 1，它是实偶函数，它的傅里叶变换一定是实偶函数。它大致是一个这样的形状，这里是实偶，这里也必然是实偶。

你再看这里，这是 $\text{sgn}$ 函数，这里是实奇函数，这是 1 这是 -1，它的傅里叶变换等于 $\frac{2}{j\omega}$，它是一个虚的奇函数。你仔细去看，你会发现这个道理是完全没有问题的。

记住了实偶对实偶和实奇对虚奇，接下来我们要记第二句话。第二句话更重要：
若 $x(t)$ 是实函数，则 $X(j\omega)$ 实部偶函数，虚部奇函数。

我要告诉大家，这句话：$x(t)$ 是实函数，那么 $X(j\omega)$ 实部是偶函数，虚部是奇函数。为什么？它的原因在这：
$$x(t) = \frac{x(t) + x(-t)}{2} + \frac{x(t) - x(-t)}{2}$$
这是第一章第一课的内容。这里叫做 $x_e(t)$，这叫做偶分量加奇分量。所以说这是一个偶函数，$\frac{x(t)+x(-t)}{2}$ 这是一个偶函数，而这是一个奇函数。

根据傅里叶变换的线性性质，它等于这个东西的傅里叶变换。这里不仅是偶函数还是实偶函数；这里不仅是奇函数还是实奇函数。实偶对实偶，这边得到的将会是比如 $\text{Re}[X(j\omega)]$，就是说 $X(j\omega)$ 的实部，实偶对实偶，这里它是实偶。这里加上一个 $j$ 倍的 $\text{Im}[X(j\omega)]$，这是虚部，实奇对虚奇，所以说虚部这里是奇函数，这里是虚奇函数。
通过这个方式很容易就证明，知道了这两个，你马上就能够证明它的实部是偶函数，虚部是奇函数。这是我们讲到的第二句话。

我要说的是，这句话反过来也是对的。如果 $X(j\omega)$ 实部偶函数，虚部奇函数，$x(t)$ 一定是一个实函数。你自己想一下，因为傅里叶变换它是能够反回去的。如果这里实部偶函数虚部奇函数，对应回去，请大家注意，这是相互对应的。你自己回去证一下你就能够知道，这两个东西完全相互对应的。所以说在这种情况下的话，$x(t)$ 它一定是实函数。

当然，这句话还能够换一种说法：
若 $x(t) \stackrel{\mathcal{F}}{\longleftrightarrow} X(j\omega)$，且 $x(t)$ 是实函数，则
$$\frac{x(t) + x(-t)}{2} \stackrel{\mathcal{F}}{\longleftrightarrow} \text{Re}[X(j\omega)]$$
同时
$$\frac{x(t) - x(-t)}{2} \stackrel{\mathcal{F}}{\longleftrightarrow} j \text{Im}[X(j\omega)]$$
这两个它也是对的。

为什么呢？这里因为，它由傅里叶变换的唯一性，你很容易能够看出来。就是 $x(t)$ 傅里叶变换是 $X(j\omega)$，且 $x(t)$ 是实函数。要知道这两个条件缺一不可。那么偶分量的傅里叶变换是 $X(j\omega)$ 的实部，奇分量的傅里叶变换是 $X(j\omega)$ 的虚部。这里当然也是对的。

接下来还有一句，还有一句话也是对的。第三句话是：若 $x(t)$ 是实函数，设 $X(j\omega) = |X(j\omega)| e^{j\theta(\omega)}$，（我把它写完下课），则这是幅度与相位，则幅度 $|X(j\omega)|$ 是偶函数，同时 $\theta(\omega)$ 是奇函数。

又由于在第二我们这里说了，它的实部是偶函数，虚部是奇函数，所以这个平方了过后两个都是偶函数，偶函数相加也是偶函数，开个根号这里仍然是偶函数。所以这里幅度谱就是偶函数。而相位谱，由于上面的虚部是奇函数，下面的实部是偶函数，这样一除，奇函数除以偶函数得到奇函数。$\arctan$ 也是一个奇函数，所以通过这样子一组合，你能够非常容易地得到 $\theta(\omega)$ 是一个奇函数，相位谱是一个奇函数。

若实因果信号 $x(t)$ 的傅里叶变换 $X(j\omega)$ 的实部 $\text{Re}\{X(j\omega)\} = \frac{1}{\omega^2 + 1}$，求 $x(t)$。就这么一句话，这道题该怎么做？

首先，实信号，这里如果说是实信号的话，它的这个 $\text{Re}$，它的实部对应的傅里叶反变换，根据第二点，实信号的傅里叶变换的实部对应的傅里叶反变换就是 $\frac{1}{2}[x(t)+x(-t)]$。所以通过这样一个条件你马上能够得到是什么呢？$\frac{1}{2}[x(t)+x(-t)]$ 它的傅里叶变换就是 $\frac{1}{\omega^2 + 1}$。

接下来你要背公式，你要带公式。这个公式不是最常用，我待会儿也会讲到的，叫做双边指数信号 97 页的那个公式。97 页的公式它说的是什么？它说的是 $e^{-a|t|}$ 傅里叶变换等于 $\frac{2a}{a^2 + \omega^2}$。这是 97 页最下面的那个公式，这个公式在书上 98 页 (3-52)。所以你带这个公式你马上能够得到什么呢？$\frac{1}{2}[x(t)+x(-t)]$ 它等于什么呢？这里是 1，$a$ 是 1，这里 2，所以它是 $\frac{1}{2}e^{-|t|}$。你看带这个公式你能够很容易地得到它的反变换就是它。

接下来你把它画出来，你看 $\frac{1}{2}[x(t)+x(-t)] = \frac{1}{2}e^{-|t|}$，它将是一个什么样的信号？它将是一个这样的信号。$\frac{1}{2}e^{-|t|}$，0 的时候是 $\frac{1}{2}$，然后这边拖下去，这里拖下去，它是一个偶函数。它大致是一个这样的信号。

再接下来，你还要用到叫做因果信号。因果信号的意思是什么呢？你看 $x(t)$ 因果，这是第一章的知识，你可以推出来 $x(t) = 0$ 当 $t < 0$ 时。你能够推出它。然后接下来你能够猜出来 $x(t)$ 将会是什么东西吧？$x(t)$ 将会是它，它在 $t < 0$ 的时候是 0，所以这边 $x(t)+x(-t)$ 把它翻转了回来除以 2 得到它，那么 $x(t)$ 就应该是这里 1，这里是它，这样子的一个把它往上延伸这样的一个信号。为什么呢？因为如果 $x(t)$ 是它，它既满足因果，同时你看 $x(t)+x(-t)$ 这里将会得到的就是这样一个信号，这里是 1，然后 $\frac{x(t)+x(-t)}{2}$ 的话，它将会是这样的信号，这里将会是 $\frac{1}{2}$。所以说 $x(t)$ 就是它。你要把它写出来 $x(t)$ 等于什么呢？它就等于 $e^{-t}u(t)$。这是最后的答案。

当然请大家想一下，如果你把它稍微地改一下，把这个条件稍微地改一下，你在这里多加一个字，叫做反因果信号。假设实的反因果信号，什么叫反因果信号呢？反因果信号的意思是 $x(t)=0$ 当 $t > 0$ 的时候。$t > 0$ 的时候它等于 0，那么这种情况下 $x(t)$ 又是多少、又是什么呢？这种情况下的话刚好它就会变掉，它会变成这样，$x(t)$ 将会变成这样，这里是 1，然后这边拖下去。它等于什么呢？能够写出来吗？这是 $t$，$e^t u(-t)$。所以如果是反因果信号的话，得到的将会是这个答案。

这是这一道题目，也就是它相对难的一道题目了。还有一点是这样，在出题的时候如果不加这个“实”字，严格地说它是不严谨的，但是我们在信号与系统里面分析的所有时域的信号，我们默认它都是实信号。请大家认真地想一下，虚数信号的话在时域上虚数的信号只有理论意义，我们基本上分析的都是实信号。所以你在这里不写这个“实”字，基本上也是可以的，虽然它出题不那么严谨，但是你不写这个“实”字的话，我们也要默认时域上所有的信号，也就是说在我们信号与系统里面，我们默认时域上的信号都是实信号。这里是我讲到的第二点。

第三点，你如果有兴趣你可以做一下。假设这里是因果，我们就把因果在这里做一下。因果刚才我说了，这样得到的 $x(t)$ 它将等于 $e^{-t}u(t)$。你试着看一下它的实部是不是这个东西，它的实部是不是等于它。你看你试一下，$x(t)$ 它是 $e^{-t}u(t)$，它的傅里叶变换等于的是 $\frac{1}{1+j\omega}$，这是你的第一个公式。它等于的是你看，$\frac{1-j\omega}{(1+j\omega)(1-j\omega)}$，它将等于的是 $\frac{1-j\omega}{1+\omega^2}$，它就等于 $\frac{1}{1+\omega^2} - j\frac{\omega}{1+\omega^2}$。它的实部刚好就是它，没有任何的矛盾。你可以看到，它也满足因为这是实信号，它也满足实部偶函数、虚部奇函数这样一个限制条件。你看一下你就能够知道，非常容易能够把它做出来。
