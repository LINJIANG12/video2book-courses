### 4.4.8 时域卷积性质

离散的时域卷积性质它是这样写的，若

$$x[n] \stackrel{\mathcal{F}}{\longleftrightarrow} X(e^{j\omega}), \quad h[n] \stackrel{\mathcal{F}}{\longleftrightarrow} H(e^{j\omega})$$

则

$$x[n] * h[n] \stackrel{\mathcal{F}}{\longleftrightarrow} X(e^{j\omega}) H(e^{j\omega})$$

时域卷积等于频域相乘，这跟连续的情况是一模一样的。时域卷积等于频域相乘。

我们复习一下连续，底下是复习。因为这个性质很重要，所以我们讲详细一点。连续的卷积性质，若

$$x(t) \stackrel{\mathcal{F}}{\longleftrightarrow} X(j\omega), \quad h(t) \stackrel{\mathcal{F}}{\longleftrightarrow} H(j\omega)$$

则

$$x(t) * h(t) \stackrel{\mathcal{F}}{\longleftrightarrow} X(j\omega) H(j\omega)$$

时域卷积等于频域相乘。

接下来我们证明一下离散。它的证明跟连续也是完全差不多的，大家去看一下连续的证明你会发现基本上是一模一样。我试着给大家做一遍。

$$\mathcal{F}\{x[n] * h[n]\} = \mathcal{F}\left\{ \sum_{k=-\infty}^{+\infty} x[k] h[n-k] \right\}$$

这里第一步把卷积变成了定义 $\sum_{k=-\infty}^{+\infty} x[k] h[n-k]$。大家学到后面不要忘了前面，这是第二章必须记住的卷积公式。所以它将等于：

$$\sum_{n=-\infty}^{+\infty} \left( \sum_{k=-\infty}^{+\infty} x[k] h[n-k] \right) e^{-j\omega n}$$

这是算出卷积过后的序列乘以 $e^{-j\omega n}$，然后加到一起，$n = -\infty$ 到 $+\infty$。它相当于这里求出来的是卷积过后的 $x$，假设 $y[n] = x[n] * h[n]$ 的话，这里求出来的就是 $y[n] e^{-j\omega n}$。

稍微地组合一下：

$$\sum_{k=-\infty}^{+\infty} x[k] e^{-j\omega k} \sum_{n=-\infty}^{+\infty} h[n-k] e^{-j\omega (n-k)}$$

这里用到的技巧，首先是把这里的两个求和的顺序颠倒了，这边是 $k$，这边是 $n$，但是每一项都有。核心的技巧是把 $e^{-j\omega n}$ 拆成了 $e^{-j\omega k} \cdot e^{-j\omega (n-k)}$，这当然是成立的。

在这种情况下一眼可以看出来，这里这一串它就等于 $X(e^{j\omega})$。而这一串相对来说不是那么容易看，但是你要知道 $n$ 等于负无穷大到正无穷大，你不管 $k$ 等于哪一个值，这里都是遍历所有的 $h$。同样的道理，这里遍历了所有的 $h$ 的话，它的下标对应这里的指数部分，所以说这一块它就是 $H(e^{j\omega})$。

当然你可以换一下，像微积分里面连续时候的换元，设 $n - k = n'$，把它换出来，这里就是 $n'$ 从负无穷到正无穷大，这里是 $h[n'] e^{-j\omega n'}$，然后再得到这一步。换句话说，你通过这样子的一个拆分，能够知道时域卷积等于频域相乘是对的。

接下来我们讲4.4节这里最后一个知识点，帕斯瓦尔定理（Parseval定理）。也不是最后一个知识点，因为后面还有一点点。

先来讲帕斯瓦尔定理。帕斯瓦尔定理说的是能量守恒：
若 $x[n]$ 的傅里叶变换是 $X(e^{j\omega})$，则：
$$\sum_{n=-\infty}^{+\infty} |x[n]|^2 = \frac{1}{2\pi} \int_{2\pi} |X(e^{j\omega})|^2 d\omega$$

这是帕斯瓦尔定理离散的形式。

连续的形式给大家复习一下：
$$\int_{-\infty}^{+\infty} |x(t)|^2 dt = \frac{1}{2\pi} \int_{-\infty}^{+\infty} |X(j\omega)|^2 d\omega$$

这是连续的形式。连续形式在书上112页 3.4.8。

连续形式我们是讲过的。这两个完全是一样的，这里时域是连续的，以至于它积分，而这里是离散的；离散这里，时域的连续这里积分变成求和；而这边负无穷大到正无穷大为周期，这里是在 $2\pi$ 范围类去积分。这两个其实可以交叉起来记，其实是同一个公式。做久了过后，只需要记一个，其实另外一个基本上也都能八九不离十地做出来。

我们来证明离散情况下的证明。

从右边推过来，左边也能够推：
$$\frac{1}{2\pi} \int_{2\pi} |X(e^{j\omega})|^2 d\omega = \frac{1}{2\pi} \int_{2\pi} X(e^{j\omega}) X^*(e^{j\omega}) d\omega$$

这个模的平方就是原来的函数乘以它的共轭，这是定义。

它等于：
$$\frac{1}{2\pi} \int_{2\pi} X(e^{j\omega}) \left( \sum_{n=-\infty}^{+\infty} x[n] e^{-j\omega n} \right)^* d\omega$$

这一步用到的是 $X(e^{j\omega})$ 的定义，它的共轭摆在里头。

每一个函数都共轭，它将等于：
$$\frac{1}{2\pi} \int_{2\pi} X(e^{j\omega}) \sum_{n=-\infty}^{+\infty} x^*[n] (e^{-j\omega n})^* d\omega$$

这一步用到的是 $(ab)^* = a^* b^*$，这个在复数当中肯定是成立的。而 $(e^{-j\omega n})^*$ 直接就是 $e^{j\omega n}$。

这一步用到的是 $(e^{-j\omega n})^* = e^{j\omega n}$。

再接下来是不是已经看出来了：
$$\sum_{n=-\infty}^{+\infty} x^*[n] \left( \frac{1}{2\pi} \int_{2\pi} X(e^{j\omega}) e^{j\omega n} d\omega \right)$$

这里每一项，$x^*[n]$、$\frac{1}{2\pi}$、积分、$X(e^{j\omega})$、$e^{j\omega n}$ 全有。

而这一项刚好是 $x[n]$：
$$\sum_{n=-\infty}^{+\infty} x^*[n] x[n] = \sum_{n=-\infty}^{+\infty} |x[n]|^2$$

这样直接就证明了。这个证明跟连续的证明几乎是一样的，所以在这里不再特别详细地去讲它。

在做这些题之外还要再讲一个性质，叫做共轭对称性。

离散的共轭对称性在书上跟连续的是完全一样的，我都不用去证明了，我相信大家也都能证明得出来。

离散的共轭对称性在157页续表这里，“时序列的共轭对称性”。续表那里从上到下数第7行、第8行、第9行、第10行，第七、第八、第九、第十。但是在我们这里我觉得跟连续的时候是完全一样的，这里是 $x[n]$，这里我都不用改的，这是 $X(e^{j\omega})$。

记住三句话：
第一句：实偶对实偶，实奇对虚奇。
第二句：实函数傅里叶变换实部偶、虚部奇。

而且除了记这个，还要记这个：
$$x[n] = \frac{1}{2}(x[n] + x[-n]) + \frac{1}{2}(x[n] - x[-n])$$
进行奇偶性分解。傅里叶变换是：
$$\text{Re}\{X(e^{j\omega})\} + j \text{Im}\{X(e^{j\omega})\}$$

前提条件是实函数，实函数才有这样，$x[n]$ 是实函数。能够知道它的傅里叶变换，这是偶部 $x_e[n]$，这是奇部 $x_o[n]$。$\frac{1}{2}(x[n] + x[-n])$ 它的傅里叶变换是实部 $\text{Re}$，$\frac{1}{2}(x[n] - x[-n])$ 的傅里叶变换是虚部 $j \text{Im}$。当然这个箭头两边打都是可以的。所以说实函数傅里叶变换实部偶、虚部奇，它的 $\frac{1}{2}(x[n] + x[-n])$ 对应着的是 $\text{Re}$ 这个，这边 $\frac{1}{2}(x[n] - x[-n])$ 对应着的是 $\text{Im}$。这是第二部。

第三句话仍然是这样的：实函数幅度谱偶、相位谱奇。

什么是幅度谱、相位谱？$X(e^{j\omega})$ 的三个公式：
$$X(e^{j\omega}) = |X(e^{j\omega})| e^{j\theta(\omega)}$$
把 $|X(e^{j\omega})|$ 写出来：
$$|X(e^{j\omega})| = \sqrt{\mathrm{Re}^2\{X(e^{j\omega})\} + \mathrm{Im}^2\{X(e^{j\omega})\}}$$
相位：
$$\theta(\omega) = \arctan\left(\frac{\mathrm{Im}\{X(e^{j\omega})\}}{\mathrm{Re}\{X(e^{j\omega})\}}\right)$$

所以这里一个是偶，一个是奇，平方了都偶，根号当然是偶，幅度谱当然是偶的。相位谱一个奇一个偶，除出来是奇，反正切保留奇，所以 $\theta(\omega)$ 是奇的。这些都是一样的。

接下来做题，做几道题大家可能印象会相对深刻一点。书后面的题，试着给大家做一下。有一道比较常考的题，173 页 4-18。

这道题其实是考聪明程度的题。设 $x[n]$ 傅里叶变换为 $X(e^{j\omega})$，满足四个条件：

这是一道考聪明程度的题。1、2、3、4 哪一个信息量最大？有一个问题再次强调，这里我们都说实函数怎样，如果不明确说某信号，一般假设 $x[n]$ 是实函数。题目出得不严谨在这，这里应该假设 $x[n]$ 是实函数，后面这些推导才有意义。

假设 $x[n]$ 是实函数，那么哪一个最有、这四个条件哪一个条件有最大信息量？我认为第三个条件最大信息量。为什么呢？第三个条件直接把这个东西给出来。把这个东西给出来，根据这张图，直接这个你就能算出来了。你想想是不是这样？它把虚部这里给出来了，以至于这里 $\frac{x[n] - x[-n]}{2}$，它的傅里叶变换刚好对应等于 $j$ 倍的虚部。所以这个东西可以直接算出来，试着算一遍。

有同学做到这不知道该怎么做了，再接下来请看我做：

一定要看清楚所有的这个，这是虚部，这里要乘以 $j$，然后它的傅里叶变换是 $\frac{x[n] - x[-n]}{2}$。这里所有的 $j$ 都约掉了，这里将会等于：
$$\frac{1}{2}e^{j\omega} - \frac{1}{2}e^{-j\omega} - \frac{1}{2}e^{j2\omega} + \frac{1}{2}e^{-j2\omega}$$

接下来我要问，哪一个 $x[n]$ 它的傅里叶变换是它？第一次做的同学可能没经验，但是我这里是能够直接写的，请大家认真的看。

这个公式主要是在这，你要记住这个公式：
$$X(e^{j\omega}) = \sum_{n=-\infty}^{+\infty} x[n] e^{-j\omega n}$$
你要记住这个公式。当你记住这个公式，你能够看出这里吗？这里说明的是什么？说明是：

所以这个东西你要直接这样作，根据刚才的分析：
$\frac{x[n] - x[-n]}{2}$ 将会是这样一个序列：

$n = 2$ 的时候，它是 $\frac{1}{2}$；
接下来，$n = -1$ 的时候，它是 $\frac{1}{2}$；
接下来，$n = -2$ 的时候，它是 $-\frac{1}{2}$。

大概是这样一个，这肯定是个奇函数，没有错，它就是一个奇函数。

再接下来我们要看哪一个、要用哪一个了？1、2、3、4 四个条件。用了条件 3，接下来我们要用条件 1：$x[n] = 0$，当 $n > 0$ 时 $x[n] = 0$。你直接能够写出来 $x[n]$ 大概是一个什么样子。这是 $\frac{x[n] - x[-n]}{2}$，所以 $x[n]$ 大概是这样子的：$n > 0$ 的时候它是 0，所以这里两个点、这边都是 0。那这边呢？这边 $-1$ 的时候它应该是 1，$-2$ 的时候它应该是 $-1$。只有这样，你认真的想想，这边长成原来的两倍，减掉 $x[-n]$ 的时候，或者这边除以 2 的时候，刚好就是它。这里核心是 $n > 0$ 的时候 $x[n] = 0$，所以你只看小于 0 的时候。所以 $x[n]$ 直接做出来了。

有一个问题，既然通过这两个条件把 $x[n]$ 确定出来了，那么 2 和 4 还要来干嘛？我们这样做，只确定了 $n \neq 0$ 的时候，但是在 $n = 0$ 的时候，这里还有可能有一个值。$n = 0$ 的时候假设它是一个 $A$ 这个值。因为不管是什么值，在这种情况下 $x[n] - x[-n]$ 在 0 这个点，0 这个点上它等于 0，它是为 0 的，因为减掉了两个 $A$。所以我们这样确定了过后，唯一不能确定的是 0 这个点上的值。因为这里写的是 $n > 0$ 的时候值等于 0，它并没有说在 0 的时候是不是等于 0。

接下来还用哪个条件呢？就要用这个条件。这个条件用帕斯瓦尔定理：
$$\sum_{n=-\infty}^{+\infty} |x[n]|^2 = \frac{1}{2\pi} \int_{-\pi}^{\pi} |X(e^{j\omega})|^2 d\omega = \frac{6\pi}{2\pi} = 3$$
这是第四个条件。你可以说所有的东西模的平方加起来等于 3。按照这种方式，你直接试一下就知道，$-1$ 这里的平方等于 1，这里也是 1，这里是 $A^2$，等于 3：
$$1 + 1 + A^2 = 3$$
所以：
$$A^2 = 1$$
$A$ 只能取 $+1$ 和 $-1$。

最后你再用第二个条件：$x[0] > 0$。所以 $A$ 只能取 1。这样推出 $A$ 只能取 1，所以 $A$ 在这里直接写 1。
