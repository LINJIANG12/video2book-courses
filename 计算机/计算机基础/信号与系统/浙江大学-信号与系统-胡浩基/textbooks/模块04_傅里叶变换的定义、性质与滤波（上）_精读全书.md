## 从复傅里叶级数到复傅里叶变换
> 对应块：BLK25 | 覆盖分集：P20 | 块标题（分集名）：《傅里叶变换的定义》

上一讲把复傅里叶级数讲完了。今天要做的事只有一件：把这套专门用来对付周期函数的家伙，从周期函数上推广到非周期函数上去。

之所以非推广不可，是因为级数这套写法的门槛全卡在"周期"两个字上。积分区间写不出来，只能标一句"一个周期"；前面还必须挂一个 $1/T_0$，而这个 $T_0$ 在指数里也躲不掉，因为 $\omega_0 = 2\pi/T_0$。信号一旦不有周期了，整个框框就塌了。

所谓复傅里叶变换，说白了就是把 $T_0$ 慢慢地放到无穷大以后，剩下的那个极限。

### 先把级数的两个公式摆出来

后面每一步都围着这两个式子转，所以先写在这：

$$x(t) = \sum_{k=-\infty}^{+\infty} a_k e^{jk\omega_0 t}$$

要记住两个前提条件：第一，$x(t)$ 是以 $T_0$ 为周期的；第二，$\omega_0 = 2\pi/T_0$。系数则是

$$a_k = \frac{1}{T_0}\int_{\text{一个周期}} x(t)e^{-jk\omega_0 t}dt$$

这两个公式本身当然是对的，但你看它们被"周期"绑得有多紧：积分的上、下限根本写不出来；$T_0$ 也消不掉，$1/T_0$ 明着挂在前面，$\omega_0$ 藏在指数里。

所以核心目的就一句话：**把复傅里叶级数，从周期函数推广到非周期函数上。**

而"非周期函数"这件事，理解起来很简单——它就是周期 $T_0$ 等于正无穷大的函数，也就是任何地方都没有周期、到处都没有周期。这句理解后面要反复用，先放在这儿。

### 先定义 X(jω)，系数立刻换了一张脸

第一步先做一个很小的动作：把系数公式里那个积分单独拎出来，定义

$$X(j\omega) \triangleq \int_{\text{一个周期}} x(t)e^{-j\omega t}dt$$

定义完立刻回来对照两个式子。$a_k$ 那边的 $1/T_0$ 原样不动，积分变量 $t$ 原样不动，指数上只有 $k\omega_0$ 被换成了自变量 $\omega$。而在 $a_k$ 里面，$\omega$ 恰好被取成了 $k\omega_0$。所以一眼就能看出来：

$$a_k = \frac{1}{T_0}X(jk\omega_0)$$

差别就这一点点。整张系数表由"一列离散的数 $a_k$"，变成了"一条连续的函数曲线 $X(j\omega)$，只不过我们只在 $k\omega_0$ 这几个点上去采样它"。后面所有的推广，都建立在这个替换上。

### 那个 j 只是一个占位符

这里插一句，因为初学的人经常在这一处搞混。

$X(j\omega)$ 里这个 $j$ 本身没有任何数学意义——它后面既没有挂着 $e^{j\omega t}$ 这种因子，也不能读成"复数域"或者别的什么。这里 $X$ 的自变量只有 $\omega$ 一个，$j$ 就是个占位符而已。

大多数《信号与系统》都沿袭 Oppenheim 那本书的写法，在中间塞一个 $j$；我个人觉得这里完全可以不写。

> **易错点**：$X(j\omega)$ 中的 $j$ 纯粹是占位符，$X$ 的自变量是 $\omega$，不是 $j\omega$。

当然它也不是完全多余的闲笔：写上这个 $j$，是为了跟第四章的**离散傅里叶变换**在记号上区分开——那一边讨论的才是 $j$ 真正有内容的场合。所以第四章的时候我们再回过头来，把这个 $j$ 到底是怎么回事彻底交代清楚。现在先记住这一条就够了。

### 把 T₀ 放走，求和就变成了积分

现在把 $a_k = X(jk\omega_0)/T_0$ 代回级数：

$$x(t) = \frac{1}{T_0}\sum_{k=-\infty}^{+\infty} X(jk\omega_0)e^{jk\omega_0 t}$$

再把 $\omega_0 = 2\pi/T_0$ 用上：$\omega_0 \cdot T_0 = 2\pi$，两边同时除以 $T_0$、乘上 $\omega_0$，就得到

$$x(t) = \frac{1}{2\pi}\sum_{k=-\infty}^{+\infty} X(jk\omega_0)e^{jk\omega_0 t}$$

非周期函数按前面的理解就是 $T_0 = +\infty$，那么 $\omega_0 = 2\pi/T_0 \to 0$。这时候同时发生两件事：

一是**积分区间**。"一个周期"随着 $T_0$ 撑开，变成了 $(-\infty, +\infty)$。

二是**求和号**。注意 $\omega_0$ 本身就是 $\omega$ 轴上相邻两个采样点之间的距离，也就是黎曼和里的那个"间隔"。间隔趋于 0，求和号就变成了积分号。这一点值得看清楚，把系数里的 $1/T_0$ 翻译成间隔的形式——因为 $\Delta\omega = \omega_0$ 且 $\omega_0 T_0 = 2\pi$，所以 $1/T_0 = \Delta\omega/2\pi$，于是

$$x(t) = \frac{1}{2\pi}\sum_k X(jk\omega_0)e^{jk\omega_0 t}\cdot\Delta\omega$$

求和号里，$X(jk\omega_0)e^{jk\omega_0t}$ 是被采样的那一份，$\Delta\omega$ 是两个采样点之间的间隔。每一份被采样的值，前面都乘上它旁边那段间隔——这正是黎曼积分的定义式。$\omega_0 \to 0$ 的时候，它就精确地变成了

$$x(t) = \frac{1}{2\pi}\int_{-\infty}^{+\infty} X(j\omega)e^{j\omega t}d\omega$$

整条推导链条如下：

```text
      复傅里叶级数（只对周期信号成立）
        x(t) = Σ_k a_k e^{jkω₀t}
        a_k  = (1/T₀) ∫(一个周期) x(t) e^{-jkω₀t} dt
        ω₀ = 2π/T₀
        │
        │  ① 把系数公式里的积分单独拎出来，定义
        │     X(jω) = ∫(一个周期) x(t) e^{-jωt} dt
        │  ② 两式一对，令 ω = kω₀
        │     a_k = X(jkω₀) / T₀
        │  ③ 把 a_k 带回级数，用 ω₀·T₀ = 2π
        │     x(t) = (1/2π) Σ_k X(jkω₀) e^{jkω₀t}
        ▼
      让 T₀ → +∞   （于是 ω₀ = 2π/T₀ → 0）
        积分区间：(一个周期) → (-∞, +∞)
        Δω = ω₀ → 0，求和 → 黎曼积分
        系数  ：1/T₀ → Δω/2π，即 1/(2π)
        ▼
      复傅里叶变换（对非周期信号成立）
        正变换  X(jω) = ∫_{-∞}^{+∞} x(t) e^{-jωt} dt
        反变换  x(t) = (1/2π) ∫_{-∞}^{+∞} X(jω) e^{jωt} dω
```

读图：整条路只做了一件事，就是把周期 $T_0$ 往无穷大放。三处改动一次到位——求和号变积分号、$1/T_0$ 变 $1/(2\pi)$、"一个周期"变整个实轴。

于是复傅里叶变换的一对公式就出来了：

$$X(j\omega) = \int_{-\infty}^{+\infty} x(t)e^{-j\omega t}dt$$

$$x(t) = \frac{1}{2\pi}\int_{-\infty}^{+\infty} X(j\omega)e^{j\omega t}d\omega$$

上面这个叫傅里叶变换公式，下面这个叫傅里叶反变换公式。

到这里两条路的关系也就清楚了：复傅里叶级数是给周期信号准备的一串**级数**，复傅里叶变换是给非周期信号准备的**积分式**，它们不过是 $T_0$ 有限与 $T_0$ 无穷的两种写法。

> **结论**：这两个公式是需要被记下来、需要背下来的。不是"会用就行"的那种熟悉，而是能默写。

### 记号怎么写，时域和频域怎么分

$X(j\omega)$ 叫 $x(t)$ 的**复傅里叶变换**，反过来说，$x(t)$ 叫 $X(j\omega)$ 的**复傅里叶反变换**。

写法上，正反一对公式常见的记法有这么几种，书上一般都能见到：

| 记法 | 正变换 | 反变换 |
| :--- | :--- | :--- |
| 最常见 | $X(j\omega) = \displaystyle\int_{-\infty}^{+\infty} x(t)e^{-j\omega t}dt$ | $x(t) = \frac{1}{2\pi}\displaystyle\int_{-\infty}^{+\infty} X(j\omega)e^{j\omega t}d\omega$ |
| 方括号 | $X[j\omega]$ | $x(t)$ |
| 算子符号 | $\mathcal{F}\{x(t)\} = X(j\omega)$ | $\mathcal{F}^{-1}\{X(j\omega)\} = x(t)$ |

意思全都是一样的，选哪一套看你的教材和考试要求，别到考场上两个记法混着写。

> **定义**：$x(t)$ 这一边叫**时域**（也叫时间域，time domain），因为它的自变量是时间 $t$；$X(j\omega)$ 那一侧叫**频域**（也叫频率域，frequency domain），因为它的自变量是频率 $\omega$。整章的"频域分析"，分析的就是右边这一侧。

### 不借傅里叶级数，两个公式直接互推

到这儿为止，推导是顺着周期推过来的。但更值得追问的是：既然它们是一对，能不能**不借傅里叶级数**，从一个式子直接推出另一个？

我记得二十多年前第一次上信号与系统课的时候，讲到这里我就放弃了。为什么？因为以我当时那个水平，我没法直接从一个公式推到另一个——中间非得过一遍级数，我推不出来。

后来教了这么多课，学的东西多了，我才发现现在自己有了些想法：就盯着这两个公式，不碰中间那一段推导，也能相互地推。所以今天我试着给大家做一遍，让大家体会一下什么叫做"相互推"。

题目是这么一道证明题：若

$$X(j\omega) = \int_{-\infty}^{+\infty} x(t)e^{-j\omega t}dt$$

求证

$$x(t) = \frac{1}{2\pi}\int_{-\infty}^{+\infty} X(j\omega)e^{j\omega t}d\omega$$

**第一步：处理符号冲突。**

看等号右边，$\frac{1}{2\pi}\int X(j\omega)e^{j\omega t}d\omega$——这里 $\omega$ 既是积分变量，又出现在 $X(j\omega)$ 里面，而 $X(j\omega)$ 的定义式用的自变量又叫 $t$，跟外面的 $t$ 撞了。两个符号撞车，怎么办？还是老办法：**换掉自变量**。把定义式里的 $t$ 换成 $u$：

$$X(j\omega) = \int_{-\infty}^{+\infty} x(u)e^{-j\omega u}du$$

把它带下来，等号右边就变成

$$\frac{1}{2\pi}\int_{-\infty}^{+\infty}\left[\int_{-\infty}^{+\infty}x(u)e^{-j\omega u}du\right]e^{j\omega t}d\omega$$

我们要证明的就是它等于 $x(t)$。

**第二步：交换积分次序。**

把 $x(u)$ 提到前面去，剩下关于 $\omega$ 的那部分合并成一个积分：

$$\frac{1}{2\pi}\int_{-\infty}^{+\infty} x(u)\left[\int_{-\infty}^{+\infty}e^{j\omega t}e^{-j\omega u}d\omega\right]du$$

指数合并，$e^{j\omega t}\cdot e^{-j\omega u} = e^{j\omega(t-u)}$，所以

$$= \frac{1}{2\pi}\int_{-\infty}^{+\infty} x(u)\left[\int_{-\infty}^{+\infty}e^{j\omega(t-u)}d\omega\right]du$$

现在整个证明压到方括号里那一个积分上了。

**第三步：算里层的积分。**

它等于

$$\int_{-\infty}^{+\infty}e^{j\omega(t-u)}d\omega = \lim_{\omega\to+\infty}\left[\frac{e^{j\omega(t-u)}}{j(t-u)}-\frac{e^{-j\omega(t-u)}}{j(t-u)}\right]$$

两个 $j$ 在这里约掉，两个 $2$ 被提出来，得到

$$= \lim_{\omega\to+\infty}\frac{2\sin[\omega(t-u)]}{t-u}$$

这一步用的就是欧拉公式 $e^{j\alpha}-e^{-j\alpha} = 2j\sin\alpha$。它的姊妹式 $e^{j\alpha}+e^{-j\alpha} = 2\cos\alpha$ 顺手再重温一遍——这个公式已经写过很多遍了，但它永远不会嫌多。

**第四步：套冲激函数。**

现在只剩一个极限。上一讲我们反反复复强调过的那条公式，这时候派上用场了：

$$\lim_{\omega\to+\infty}\frac{\sin \omega t}{t} = \pi\delta(t)$$

把这里的 $t$ 换成 $t-u$：

$$\lim_{\omega\to+\infty}\frac{\sin[\omega(t-u)]}{t-u} = \pi\delta(t-u)$$$

所以里层那个积分等于 $2\pi\delta(t-u)$。代回整式，$\frac{1}{2\pi}$ 与 $2\pi$ 正好约掉：

$$x(t) = \frac{1}{2\pi}\int_{-\infty}^{+\infty} x(u)\cdot 2\pi\delta(t-u)du = \int_{-\infty}^{+\infty}x(u)\delta(t-u)du$$

最后一步用冲激函数的**筛选性质**，$\int x(u)\delta(t-u)du = x(t)$。证毕。

> **结论**：两个公式可以相互推，而且**完全不需要**借助复傅里叶级数做过渡。唯一的支点就是 $\lim_{\omega\to+\infty}\sin(\omega t)/t = \pi\delta(t)$。
>
> 上一讲之所以要一个劲地强调这条公式，就是因为后面每推一个公司都要用到它。很多时候推不出来，不是因为推不出来，而是因为你不知道这条公式；一旦知道了，而且能准确地把它用出来，这些式子你都能非常干净地推出来。

### 本讲提到的题目

**题目一（本讲现场证明的证明题）**：若

$$X(j\omega) = \int_{-\infty}^{+\infty}x(t)e^{-j\omega t}dt$$

求证

$$x(t) = \frac{1}{2\pi}\int_{-\infty}^{+\infty}X(j\omega)e^{j\omega t}d\omega$$

*解析与答案*：见上面「不借傅里叶级数，两个公式直接互推」一节。四步走完——换自变量 $t \to u$ 消除符号冲突、交换积分次序、内层积分用欧拉公式化简、内层用 $\lim_{\omega\to+\infty}\sin(\omega t)/t = \pi\delta(t)$，最后靠冲激的筛选性质回到 $x(t)$。$\pi$ 与 $2\pi$ 全程刚好约掉，两边严格相等。

**题目二（作业，反着推一遍）**：若

$$x(t) = \frac{1}{2\pi}\int_{-\infty}^{+\infty}X(j\omega)e^{j\omega t}d\omega$$

求证

$$X(j\omega) = \int_{-\infty}^{+\infty}x(t)e^{-j\omega t}dt$$

这就是上面那道题反着来一遍，沿途要用的支点还是那条 $\lim_{\omega\to+\infty}\sin(\omega t)/t = \pi\delta(t)$——这也是当初反复强调它的原因。题面到这里，解答留给课后。

## 八个典型信号的傅里叶变换对
> 对应块：BLK26 | 覆盖分集：P21上 | 块标题（分集名）：《典型信号的傅里叶变换》

这一节在书上就是 97 页往后的 3.2.3，翻过去才几页纸的样子，你别看它薄——考试里至少 15 到 20 分压在这里，这还是保守说法。

更要紧的不是考试。是整门课后面所有的东西都要回来查这张表：滤波器的设计、系统的频域分析、采样定理、调制解调，全都要拿它当字典用。所以 3.2.3 你千万不要当例题看，**要看成要把它背下来的东西**。

我教了这么多年，年年都要自己检查一遍：不看书、不翻讲义，我能不能把这几个式子从头到尾默出来。每年总有一两个公式我是要想一下才知道正的负的，所以干脆趁着这节课一开始，我把黑板擦干净，从头到尾写一遍，写完再一个一个讲。写的时候我在旁边标了号——一共八个。讲义上算七个，因为我一般把第六、第七写在一起。

写之前先把坐标的事说清楚：下面每一个式子，**左边是时域，右边是频域**。左边的自变量是 $t$，右边的自变量是 $\omega$。这是两套完全不同的坐标，看的时候千万别把自变量搞混——搞混了以后你做题就不是算错，是答非所问。

### 八个公式先摆在这儿

| 编号 | 时域 $x(t)$ | 频域 $X(j\omega)$ |
| :--- | :--- | :--- |
| ① | $e^{-at}u(t)$，$a>0$ | $\dfrac{1}{a+j\omega}$ |
| ② | $\delta(t)$ | $1$ |
| ③ | $1$ | $2\pi\delta(\omega)$ |
| ④ | 矩形窗 $g_\tau(t)$（$\lvert t\rvert\le \tau/2$ 时为 1） | $\tau\,\mathrm{Sa}\!\left(\dfrac{\omega\tau}{2}\right)$ |
| ⑤ | $\dfrac{\sin\omega_c t}{\pi t}$ | 方波：$\lvert\omega\rvert<\omega_c$ 时为 1，其余为 0 |
| ⑥ | $\cos\omega_c t$ | $\pi\left[\delta(\omega-\omega_c)+\delta(\omega+\omega_c)\right]$ |
| ⑦ | $\sin\omega_c t$ | $\dfrac{\pi}{j}\left[\delta(\omega-\omega_c)-\delta(\omega+\omega_c)\right]$ |
| ⑧ | $u(t)$ | $\dfrac{1}{j\omega}+\pi\delta(\omega)$ |

> **定义**：$\mathrm{Sa}(x)=\dfrac{\sin x}{x}$，取 $x=0$ 处的极限值为 1。很多同学 $\sin$ 和 $\mathrm{Sa}$ 分不清，这是两个东西，$\sin 3\omega$ 不等于 $\mathrm{Sa}(3\omega)$，后面考试专门考这一刀。

> **结论**：八个里有三对"配对"，记配对比八个硬背省一半力气——
> **② 与 ③ 是一对**（$\delta(t)\leftrightarrow 1$，$1\leftrightarrow 2\pi\delta(\omega)$）；
> **④ 与 ⑤ 是一对**，一句话就是"方波与 sa 互为傅里叶变换"；
> **⑥ 与 ⑦ 是一对**（cos 和 sin），这两个加起来除以 2 就是指数对。

另外有几条经验：

- 我在黑板上写的时候**一律按书上的写法来**。不是记不住，是我不想跟书上的定义变得不一致——考试你得按讲义上那个名字答，答案才对得上。
- 第④个有两个写法，$\mathrm{Sa}$ 形式和 $\sin$ 形式可以互相化简，化简的那一步我也带大家走一遍。
- 第⑦个里头那个负号在括号里还是在 $\frac{\pi}{j}$ 里面，我到现在还经常记混，每次都得回头看一眼。
- 第⑥、⑦我干脆合并写；要是真拆开数，那就是八个。今天和下节课开头的主要任务，就是把这八个式子弄熟。

### 单边指数信号：整张表的起点

书上 97 页、3.2.3 的第一个式子，编号（3.51）：

$$
e^{-at}u(t) \;\longleftrightarrow\; \frac{1}{a+j\omega}
$$

它是整张表里唯一一个**推导要从头做**的，后面七个都建立在它和定义式上面，所以我们从它开始。

#### 带公式进去，一步步算

第一步永远是背定义式：

$$
X(j\omega)=\int_{-\infty}^{+\infty}x(t)e^{-j\omega t}\,\mathrm{d}t
$$

把 $x(t)$ 换成 $e^{-at}u(t)$：

$$
X(j\omega)=\int_{-\infty}^{+\infty}e^{-at}u(t)\,e^{-j\omega t}\,\mathrm{d}t
$$

第二步看 $u(t)$。它是个大于零取 1、小于零取 0 的信号，乘在哪儿就在哪儿把负半轴整个压成零。$t<0$ 的那一段反正全是零，不用考虑了，所以积分限直接压成 $[0,+\infty)$：

$$
X(j\omega)=\int_{0}^{+\infty}e^{-at}e^{-j\omega t}\,\mathrm{d}t
$$

第三步把两个同底的幂合并，这一步用了我前面讲过的指数凑对：$e^{-at}e^{-j\omega t}=e^{-(a+j\omega)t}$。

$$
X(j\omega)=\int_{0}^{+\infty}e^{-(a+j\omega)t}\,\mathrm{d}t
$$

第四步直接积分：

$$
X(j\omega)=\left.\frac{e^{-(a+j\omega)t}}{-(a+j\omega)}\right|_{0}^{+\infty}
=\frac{e^{-(a+j\omega)\cdot 0}-e^{-(a+j\omega)(+\infty)}}{a+j\omega}
$$

#### $a>0$ 这三个字不是装饰

$t=0$ 那头 $e^0=1$，中间那一大坨就集中在分子上那个无穷大的指数了。这里必须回头把 $a$ 拿进来看：

- **当且仅当 $a>0$** 时，$-(a+j\omega)$ 的实部是负的，$-(a+j\omega)\to+\infty$ 往 $-\infty$ 跑，$e^{-(a+j\omega)(+\infty)}$ 才能收敛到 0，最后得到 $\dfrac{1}{a+j\omega}$。
- **当 $a<0$** 时实部是正的，那个指数跑到 $+\infty$，$1$ 除以一个正无穷大发散，这一项根本不收敛，积分不存在。

所以你必须严格地说：这个公式只在 $a>0$ 时成立。书上 97 页"单边指数信号"那一行顶上打了个括号，写的就是 $x(t)=e^{-at}u(t)$，$a>0$——不是我啰嗦，是真的非有不可。

> **易错点**：$a<0$ 的时候不能靠"发散就当作 0"蒙混过关。$e^{-(a+j\omega)(+\infty)}$ 不是 0，它是无穷大，除出来是 0 还是无穷要看你从哪个方向理解，这个式子在那儿根本不成立。

#### 时域长什么样

推出这个式子还不是最要紧的。每一个信号我都要求自己**时域的形状和频域的形状都了如指掌**，所以两边我都要画一遍加深印象。

时域这边：$u(t)$ 一乘，负半轴全是零，它只在 $t=0$ 处起步。$t=0$ 这里取值是 1，接着因为 $a>0$，指数一路往下掉：

```text
  x(t)
   1 ┤        ●
     │        │╲
     │        │ ╲
     │        │  ╲___
     │        │      ╲______
   0 ┼────────┴─────────────────────→ t
     │        0
     │        │
     │        └── a 越大，掉得越快
```

$a$ 越大，衰减越快，这条你一定要有体感：画三条曲线，$a$ 分别取小、中、大，差别一眼就出来了。这个参数后面做系统分析时是要调的，不能只当个符号看。

#### 频域画不出来，就拆成模和相

时域那边是实的，能画；频域这边就麻烦了。$\dfrac{1}{a+j\omega}$ 有 $j$，是个复数，画在纸上看不见。

第一次遇到这种情况，我用比较复杂的方式带一下：把它展开成有理式，分母有理化，拆成实部虚部，虚部实部各画一张图。但这样画在频域里是不常规的——频域里我们不这么画。

```text
        X(jω) = 1/(a + jω)          ← 是个复数，图上画不出来
                 │
                 ├──────────────►  取模    |X(jω)| = 1/√(a² + ω²)     幅度谱（偶函数）
                 │                      ω=0 处最高为 1/a，|ω|→∞ 趋于 0
                 │
                 └──────────────►  取辐角  ∠X(jω) = −arctan(ω/a)     相位谱（奇函数）
                        ω→+∞ 趋于 −π/2，ω→−∞ 趋于 +π/2
```

> **定义**：把 $X(j\omega)$ 取模得到的 $|X(j\omega)|$ 叫**幅度谱**（amplitude spectrum），取辐角得到的 $\angle X(j\omega)$ 叫**相位谱**（phase spectrum）。因为它就是频谱，所以幅度也常直接叫幅度谱。

模和相怎么算？高中知识，不用我多讲。任何一个复数 $z=a+jb$，它的模是 $\sqrt{a^2+b^2}$，它的辐角是 $\arctan\dfrac{b}{a}$。套上来：

$$
|X(j\omega)|=\frac{1}{\sqrt{a^2+\omega^2}},\qquad \varphi(\omega)=\arctan\frac{\omega}{a}
$$

$\varphi$ 前面要加个负号——因为 $\frac{1}{a+j\omega}$ 和 $\frac{a-j\omega}{a^2+\omega^2}$ 只差一个相位取反，$\arctan$ 是奇函数，负号带过来就是它。

我给大家一分钟左右自己先推一遍再公布答案会比较牢。书上 98 页已经推好了，但你试过一遍再去看，感觉完全不一样。模的极限要用洛必达往上走一步：$\lim_{\omega\to\infty}\dfrac{1}{\sqrt{a^2+\omega^2}}=0$。

有了这两个，谱就能画了：

- **幅度谱**：$\omega=0$ 处最高，等于 $1/a$；左右对称（它是偶函数）；往两边 $|\omega|$ 越大越低，直接趋于 0。这条"远处趋于 0"你们今后会反复用到。
- **相位谱**：它是个奇函数，$\omega$ 取负值时 $\arctan$ 给负、外面再套个负号给正，所以左半边是正的、右半边是负的。$\omega\to+\infty$ 趋于 $-\dfrac{\pi}{2}$，$\omega\to-\infty$ 趋于 $+\dfrac{\pi}{2}$。

#### 顺手预热：低通滤波器与截止频率

讲到这儿我们插一段后面的知识，先预热一下，你暂时记不住也没太多关系，后面讲滤波器的分析和设计会再深挖。

刚才那条幅度谱，$|\omega|$ 小的地方幅度大、$|\omega|$ 大的地方幅度小——这种形状我们叫做**低通滤波器**（low-pass filter）。它的意思就是把频率低的地方放过去、把频率高的地方抑制住。

这里我们还需要一个数。假设 $\omega$ 取到 $\sqrt{3}a$，把 $\omega=\sqrt{3}a$ 代进 $\dfrac{1}{\sqrt{a^2+\omega^2}}$，分母变成 $\sqrt{a^2+3a^2}=\sqrt{4a^2}=2a$，所以幅度是 $\dfrac{1}{2a}$。负的 $\sqrt{3}a$ 那一侧对称，也是 $\dfrac{1}{2a}$。书上 98 页把这个点画出来了，但没有细讲。

这两个点重要在哪？在低通滤波器里我们经常要算一件事：**幅度衰减到最高点的一半时，对应的频率是多少**。这个频率叫**截止频率**（cut-off frequency）。

> **结论**：$a>0$ 的单边指数对应的低通滤波器，截止频率是 $\omega_c=\sqrt{3}a$。高通、带通也都是同一个定义——幅度衰减到最高幅度一半时的频率。

那"一半"为什么还有个别的名字叫**3 dB**？这里有点历史包袱，我一直觉得工程上引入了太多奇怪的概念，以至于都得让我们记。它其实就是一个对数公式：dB 是以 $\log_{10}$ 为单位、再乘以 10 的量。幅度衰减到原来的 $\dfrac{1}{2}$，

$$
10\lg\frac{1}{2}\approx -3\ \text{dB}
$$

所以"衰减 3 dB"和"衰减到一半"其实是一回事，这就是那个数字的来历。

### 冲激和常数，它们是一对

接下来这组特别快，因为它俩是**互推**的——从右边推到左边好推，从左边推到右边稍微费点劲，两个方向我都要走一遍。

#### 冲激的变换就是那个常数

$\delta(t)\longleftrightarrow 1$。还是把定义式摆出来，把 $x(t)$ 换成 $\delta(t)$：

$$
X(j\omega)=\int_{-\infty}^{+\infty}\delta(t)e^{-j\omega t}\,\mathrm{d}t
$$

这一步要用的是 $\delta$ 的性质里最熟的那一条：

$$
\int_{-\infty}^{+\infty}x(t)\delta(t)\,\mathrm{d}t=x(0)
$$

这里 $x(t)$ 就是 $e^{-j\omega t}$，所以

$$
X(j\omega)=e^{-j\omega\cdot 0}=1
$$

跟 $\omega$ 一点关系都没有，是个常数。你可以画个图理解：时域里 $\delta(t)$ 是一个冲击，它的变换就是一个值——书上 98 页、式（3.53）画的正是这个。

#### 常数的变换：先从右边推回来

$1\longleftrightarrow 2\pi\delta(\omega)$。

这个有简单的做法也有复杂的做法。**从右边 $\leftarrow$ 左边是简单做法**，书上就是这么写的：

$$
X(j\omega)=\frac{1}{2\pi}\int_{-\infty}^{+\infty}2\pi\delta(\omega)e^{j\omega t}\,\mathrm{d}\omega
$$

$2\pi$ 跟 $1/2\pi$ 一约掉，再用同一条 $\delta$ 性质。但这里有个坑你要特别注意：**公式是 $\int x(t)\delta(t)\,\mathrm{d}t=x(0)$，用的时候必须把自变量整体换掉**。这次积分的变量是 $\omega$，不是 $t$，所以 $\delta(\omega)$ 要换成 $x(\omega)$，结果是 $x(\omega=0)=e^{j\omega t}\big|_{\omega=0}=e^0=1$。

#### 反过来推，三角恒等式加无穷远处的极限

还有一点点时间，我们把难的那个也试一遍——**从左边 $\rightarrow$ 右边**。书上没这么推，我带一遍。

$$
X(j\omega)=\int_{-\infty}^{+\infty}x(t)e^{-j\omega t}\,\mathrm{d}t=\int_{-\infty}^{+\infty}e^{-j\omega t}\,\mathrm{d}t
$$

先做一个很关键的化简：$e^{-j\omega t}=\cos\omega t - j\sin\omega t$。其中 $\cos\omega t$ 是偶函数、$\sin\omega t$ 是奇函数，**奇函数在关于原点对称的区间上积分为零**，所以整个积分只剩下 cos 那一份，$j$ 的那一项自己没了。于是上下限可以对称地缩成 $[-n,n]$：

$$
X(j\omega)=\lim_{n\to\infty}\int_{-n}^{n}e^{-j\omega t}\,\mathrm{d}t
$$

代进原函数：

$$
X(j\omega)=\lim_{n\to\infty}\frac{e^{-j\omega n}-e^{j\omega n}}{-j\omega}
$$

这一步要用到我前面讲过很多次的一个常用公式：$e^{j\alpha}-e^{-j\alpha}=2j\sin\alpha$。这里正是它的反面，$e^{-j\omega n}-e^{j\omega n}=-2j\sin\omega n$。$j$ 跟 $j$ 约掉，$n$ 跟分母凑一约：

$$
X(j\omega)=\lim_{n\to\infty}\frac{2\sin(n\omega)}{n\omega}
$$

现在答案已经摆在眼前了。前面我们专门强调过要记住的那个结论：

$$
\lim_{T\to\infty}\frac{\sin\omega T}{\pi T}=\delta(\omega)
$$

把这里的字母一一对调：$\omega$ 换成 $t$、$t$ 换成 $\omega$、再把 $t$ 换成 $n$，你手里就握着 $\lim_{n\to\infty}\dfrac{\sin(n\omega)}{n}=\pi\delta(\omega)$。所以

$$
X(j\omega)=2\pi\delta(\omega)
$$

整条路就通了——这个式子和前面那个只不过是把变量换来换去而已，**左推右、右推左两个方向都成立**，你两个都得会。

至此这组公式互相能推通了。② 的左推右跟 ③ 做的事情完全一样，你自己回去推一遍就会了：$\delta(t)$ 乘 $e^{-j\omega t}$ 积分，结果就是 $e^{-j\omega\cdot 0}=1$。

> **提示**：这一次的作业应该是最难的。我会让大家用**正交基**的那些性质去证明，还要编程序。具体内容课后再说。

### 方波与 sa 互为傅里叶变换

后面这几个是今天的重点，我会花大半节课。四和五合起来就一句话，记住这一句比什么都强：

> **结论**：**方波与 sa 互为傅里叶变换**。

这句话的意思是——时域是方波，频域就是 sa；反过来，时域是 sa（$\sin t/t$ 这种形状），频域就是方波，两头对调，形状照样对得上。你要记住的第一件事就是它。

第二件事，是把这两个式子的具体写法完整地记住。推导我先走一遍，然后告诉你怎么记。

#### 矩形窗，左推右

第④个信号就是矩形窗函数。我按书上写，不自作主张改定义。它长这样：$|t|\le \dfrac{\tau}{2}$ 的范围内取值 1（$e$ 的读音，滑过去就是"幺"），其余地方全是零。

左推右其实不难。$X(j\omega)=\int_{-\infty}^{+\infty}x(t)e^{-j\omega t}\,\mathrm{d}t$，因为它是方波，左右两边全是零，只有 $[\,-\dfrac{\tau}{2},\dfrac{\tau}{2}\,]$ 这一段有值，所以积分限直接缩成这一段：

$$
X(j\omega)=\int_{-\tau/2}^{\tau/2}1\cdot e^{-j\omega t}\,\mathrm{d}t
=\frac{e^{-j\omega\tau/2}-e^{j\omega\tau/2}}{-j\omega}
$$

还是那个老公式，$e^{-j\alpha}-e^{j\alpha}=-2j\sin\alpha$，$j$ 与 $j$ 相消：

$$
X(j\omega)=\frac{2\sin(\omega\tau/2)}{\omega}=\tau\cdot\frac{\sin(\omega\tau/2)}{\omega\tau/2}
$$

最右边的那个东西，就是 $\mathrm{Sa}$。所以这一对的完整写法是

$$
g_\tau(t)\;\longleftrightarrow\;\frac{2\sin(\omega\tau/2)}{\omega}=\tau\,\mathrm{Sa}\!\left(\frac{\omega\tau}{2}\right)
$$

> **提示**：书上把它简写成"矩形窗 ↔ $\mathrm{Sa}(\omega\tau/2)$"，那个 $\mathrm{Sa}$ 只负责描述**形状**。但你自己做题的时候，前面的 $\tau$ 不会自己消失——它就是那个脉冲的**面积**。写答案的时候别把 $\tau$ 吞了。

#### 那个除以 $\pi t$ 的信号：三种情况讨论

第⑤个：时域是 $\dfrac{\sin\omega_c t}{\pi t}$，频域是一个方波：$\lvert\omega\rvert<\omega_c$ 时为 1，其余为 0。

书上推的是"右推左"，我把它换成"左推右"讲一遍——因为做完了这个，五的左推右和四的右推左用的原理就是完全一样的，你自己就能把另一边也做出来。

$$
X(j\omega)=\int_{-\infty}^{+\infty}\frac{\sin\omega_c t}{\pi t}e^{-j\omega t}\,\mathrm{d}t
$$

又是把指数拆成 cos 和 sin。这里有一个**奇偶性的坑**，请大家认真看，它是这一段最值钱的一句：

```text
        X(jω) = ∫ [ sin(ωc t)/πt ] · e^(−jωt) dt
                                    │
                                    └─ 拆开：e^(−jωt) = cos ωt − j·sin ωt

   ┌───────────────────────────────┴───────────────────────────────┐
   │                                                               │
   │  sin(ωc t)/πt · cos ωt              sin(ωc t)/πt · j·sin ωt │
   │  sin 是奇函数，t 也是奇函数，          偶函数 再乘 奇函数        │
   │  一除变成偶函数；偶 × 偶 = 偶         = 奇函数                │
   │  偶函数，积分不为零，活着              奇函数，±∞ 上积分为 0，扔 │
   └───────────────────────────────────────────────────────────────┘
```

所以这一大坨直接等于零，只剩下第一项：

$$
X(j\omega)=\int_{-\infty}^{+\infty}\frac{\sin\omega_c t}{\pi t}\cos\omega t\,\mathrm{d}t
$$

接下来用积化和差：$\sin\alpha\cos\beta=\dfrac{1}{2}\big[\sin(\alpha+\beta)+\sin(\alpha-\beta)\big]$，拆成两项：

$$
X(j\omega)=\frac{1}{2\pi}\int_{-\infty}^{\infty}\frac{\sin(\omega_c+\omega)t}{t}\,\mathrm{d}t
+\frac{1}{2\pi}\int_{-\infty}^{\infty}\frac{\sin(\omega_c-\omega)t}{t}\,\mathrm{d}t
$$

对第二项，很多同学看到这儿就卡住了。这个要用第一章的一个结论，请一定记住它的用法：

$$
\frac{\sin\omega t}{\pi t}\;\longleftrightarrow\;
\begin{cases}1, & \omega>0\\ -1, & \omega<0\end{cases}
$$

当 $\omega>0$ 时它等于 1，当 $\omega<0$ 时等于 $-1$。**记住 $t$ 在分母上、正弦在分子上，就对上了**；分母上没有 $\pi$ 的话记得把这个 $\pi$ 的因子补回去。

现在分三种情况讨论。前提条件是 $\omega_c>0$。

**情况一：$\omega<-\omega_c$。** 此时 $\omega_c+\omega<0$ 取到 $-1$，$\omega_c-\omega>0$ 取到 1，两者相消：

$$
X(j\omega)=\frac{1}{2}\left[(-1)+1\right]=0
$$

**情况二：$-\omega_c<\omega<\omega_c$。** 此时 $\omega_c+\omega>0$、$\omega_c-\omega>0$，两个都取到 1：

$$
X(j\omega)=\frac{1}{2}\left[1+1\right]=1
$$

**情况三：$\omega>\omega_c$。** 此时 $\omega_c+\omega>0$ 取到 1，$\omega_c-\omega<0$ 取到 $-1$，又是相消：

$$
X(j\omega)=\frac{1}{2}\left[1+(-1)\right]=0
$$

三档一汇总你就看明白了：$\lvert\omega\rvert$ 小于 $\omega_c$ 的时候等于 1，大于 $\omega_c$ 就等于 0，中间还有一个 $\omega=\omega_c$ 的点也等于 0。它就是一个**方波**。

```text
        X(jω)
     1   ┤        ┌────────────┐
         │        │            │
         │        │            │
     0   ┼────────┘            └────────→ ω
              −ωc   0        ωc
```

这就是"方波与 sa 互为傅里叶变换"的后一半。五讲完了，四的右推左用的原理和五的左推右一模一样——都是拆指数、看奇偶、自己回去做一遍就通了。

### 本讲提到的题目：考场上只有五秒钟

```text
     x(t)
   1 ┤    ┌──────────┐
     │    │          │
   0 ┼────┘          └────────────→ t
         −3          3          (中间那段的跨度是 τ)
```

**题目**：已知 $x(t)$ 是高度为 1、左右边界分别在 $t=-3$ 和 $t=3$ 的矩形脉冲，求它的傅里叶变换 $X(j\omega)$。要求在考场上**五秒钟之内**写出来。

**答案**：

$$
X(j\omega)=\frac{2\sin(3\omega)}{\omega}=6\,\mathrm{Sa}(3\omega)
$$

**解析**：这题没有第二步，就是把公式④直接代进去。三下子：
1. 看清左右边界是 $-3$ 和 $3$，所以 $\dfrac{\tau}{2}=3$，$\tau=6$——**先把 $\tau$ 定下来，这是唯一需要动脑的地方**；
2. 代 $\tau=6$：$\dfrac{2\sin(6\omega/2)}{\omega}=\dfrac{2\sin 3\omega}{\omega}$；
3. 想写成 sa 形式就是 $6\,\mathrm{Sa}(3\omega)$。

最后那个提醒也是考点：写出来的 $\sin(3\omega)$ **不是** $\mathrm{Sa}(3\omega)$，中间少一个 $\dfrac{2}{\omega}$。上课的时候我专门叫了一位同学上来写，五秒钟他没敢动笔，我就提醒了一句 $\tau/2=3$，他一下就写出来了。

至于我自己在五秒钟里怎么把它写出来——怎么配对、怎么联想、怎么下笔顺序不出错——这是我这节课最后要讲的东西，我们就先停在这儿，下次课从这里接着往下讲。

先把已经讲过的六对典型变换摆在桌面上：一、二、三大家都已经熟了，这一讲讲的是**公式四、公式五、公式六**。

公式四和公式五——方波与 $\mathrm{sa}$ 互为傅里叶变换、$\dfrac{\sin 3t}{t}$ 与 $\pi\,[\cdot]$——我已经花了将近一节课来讲"怎么记"。这一讲真正的内容不是背新公式，是把这两对**练成手速**：五秒钟之内正着写、反着写，全部写出来。

### 一个方波，频域里那个 sa 是谁

先看一份刚收上来的答案。

左边时域画的是方波，右边我们往里填频域的表达式。请大家认真听，第一位你要知道的就是这句话：

> **结论**：**方波与 $\mathrm{sa}$ 互为傅里叶变换**。

所以当你看到左边是方波的时候，你明确地知道在频域上是 $\mathrm{sa}$——不妨先把 $\mathrm{sa}$ 整个框出来，再往里填数。

再看这个 $\mathrm{sa}$ 里要填的三个要素：

$$\mathrm{sa}(x)=\frac{\sin x}{x}$$

**第一，变量是谁。** 时域用的自变量是 $t$，那么频域的自变量就是 $\omega$。所以这个 $\mathrm{sa}$ 里必然有一个 $\omega$。

**第二，括号里那个数。** $\sin$ 括号里的 $\omega$ 的系数，就是时域方波的截止点。这个方波在 $\pm 3$ 断开，那 $\sin$ 里面就写 $3$。

**第三，括号外面那个数。** 这是最容易错的：它的系数等于**方波的面积**。这里方波高度是 2、宽度是 6，底下是 $2\times 6=12$，所以直接写 12。

于是

$$12\,\mathrm{sa}(3\omega)=12\cdot\frac{\sin 3\omega}{3\omega}=\frac{4\sin 3\omega}{\omega}$$

12 和 3 一约，得 4。这位同学写的是对的。

> **提示**：为了后面少绕弯子，我们把 $\mathrm{sa}$ 的写法固定下来——写成 $a\,\mathrm{sa}(b\omega)$，等价于 $a\cdot\dfrac{\sin(b\omega)}{b\omega}$。后面的每一道题都按这个记法落笔。

### 为什么 sa 的系数恰好是方波的面积

$\mathrm{sa}$ 和方波的具体对应关系我这里不展开（$\mathrm{sa}$ 里的 $\pi$ 跟那边截止频率怎么配，也不在这儿耗）。但是**为什么系数是面积**这件事必须讲清楚，因为它比任何一条公式都省事，比任何一条公式都可靠。

从傅里叶变换的定义出发，令 $\omega=0$：

$$X(j\omega)=\int_{-\infty}^{+\infty}x(t)e^{-j\omega t}\,\mathrm{d}t$$

把 $\omega$ 取成 0，$e^{-j\omega t}$ 就等于 1，于是

$$X(j0)=\int_{-\infty}^{+\infty}x(t)\,\mathrm{d}t$$

右边是什么？**就是方波的面积。**

再看左边。我们假设它等于 $a\,\mathrm{sa}(\omega)$，那么

$$X(j0)=a\,\mathrm{sa}(0)=a\times 1=a$$

为什么 $\mathrm{sa}(0)=1$？因为 $\mathrm{sa}$ 就是 $\dfrac{\sin t}{t}$，而 $\displaystyle\lim_{t\to 0}\frac{\sin t}{t}=1$。这一点前面讲过，这里再用一次。

两句话一对：$a=$ 面积。这条链条到这里就断了——**你不需要验算，只需要把面积抄上去**。

> **易错点**：算 $a$ 的时候，不要把 $\sin$ 前面那个系数直接当成 $a$。$a$ 是 $\mathrm{sa}$ 的系数，也就是方波的**面积**，而不是高度。

### 正着出题：给方波，写 sa

搞懂这一条之后我们继续布置题目，还是五秒钟、三秒钟能写出来的那种。

**第一题**，正着出：截止在 $\pm5$、面积为 10 的方波。

$$\text{答案}=10\,\mathrm{sa}(5\omega)=10\cdot\frac{\sin 5\omega}{5\omega}=\frac{2\sin 5\omega}{\omega}$$

**第二题**，还是正着出：时域是一个从 $-1$ 到 $1$、高度为 2 的方波。面积是 $2\times 2=4$，截止点是 1，于是直接得

$$\text{答案}=4k,\qquad k\equiv\frac{\sin\omega}{\omega}$$

到这里为止，你已经能在五秒钟之内把这两道题写完了。这个速度就是我想要的水平。

### 反着出题：给 sa，画方波

接下来我把题目**反过来出**——这个方向才是真正拉开差距的地方。

**第三题**：什么东西的傅里叶变换等于 $\pi\,\mathrm{sa}(2\omega)$？

倒着做，步骤是完全对称的：$\mathrm{sa}$ 对应着的时域就是方波，先把方波画出来；截止点从 $\sin$ 括号里读，这里是 $\pm2$；横坐标宽度 4；面积是 $\pi$，那么纵坐标只能是 $\pi/4$。

> **易错点**：反着出题最容易错在**横纵坐标搞反**。宽度由截止点定：$2\tau$；高度由面积除以宽度定：$\dfrac{\text{面积}}{2\tau}$。这两步不要混。

这两道题还不算最难。待会我会逐步地上升难度。这里我暂时不叫同学上来做了，我只自己来做一遍。

### 转好大一圈弯，和一眼认出来

第四题稍微转个弯：**什么东西的傅里叶变换等于 $15\,\mathrm{sa}(3\omega)$**？

我请一位同学上来做，做得非常好，完全正确。先讲**稍微复杂的做法**：

第一步，把它写成 $\dfrac{15\sin 3\omega}{3\omega}$。这里系数是 15，所以这个 $\mathrm{sa}$ 的系数 $a$ 是 15。

第二步，把这个 $\mathrm{sa}$ 搬到方波上去。宽度是 $2\times 3=6$。

第三步，面积要等于 15，所以高度 $=15\div 6=5/2$。

这是一个要转来转去、转很多大弯儿的做法。但是我要说的是：**我把题目做熟了以后，看到它仍然是五秒钟写。**

接下来我告诉大家我是怎么做的——**不转弯的做法**。

**第一步**：你要先知道 $\dfrac{5\sin 3\omega}{\omega}$ 这个东西**也是 $\mathrm{sa}$**。它没有 $\mathrm{sa}$ 那样显式的写法，但只要满足"$\sin$ 括号里有一个 $\omega$、分母也有一个 $\omega$"这样的形式，它一定就是 $\mathrm{sa}$。

```text
        sin(cω)
       ──────────
            ω
            │
            ▼
    它就是一个 sa(cω)
            │
            ├────────► 时域：方波，截止 ±c
            │
            └────────► 系数 a：取 x(0) = (1/2π)∫X(jω)dω
```

**第二步**：既然是 $\mathrm{sa}$，对应的时域就是方波，而且**方波的截止点跟 $\sin$ 括号里面这个值完全一样**。这里是 3，直接拿过来，截止就是 $-3$ 到 $3$。

**第三步，关键**：$a$ 等于多少？反过来看 $a$ 有两条路。

- 刚才那条路是 $a=$ 时域面积，宽度 6，再除；
- 更快的这条路是 $a=$ **频域面积除以 $2\pi$**，也就是 $x(0)$：

$$x(0)=\frac{1}{2\pi}\int_{-\infty}^{+\infty}X(j\omega)\,\mathrm{d}\omega$$

代进去（用 $5\sin 3\omega/\omega$ 这个写法更省事）：

$$x(0)=\frac{1}{2\pi}\cdot 5\int_{-\infty}^{+\infty}\frac{\sin 3\omega}{\omega}\,\mathrm{d}\omega=\frac{1}{2\pi}\cdot 5\cdot\pi=\frac{5}{2}$$

这里我用到了一个整你早就背下来的公式：

$$\int_{-\infty}^{+\infty}\frac{\sin a\omega}{\omega}\,\mathrm{d}\omega=\pi,\qquad a>0$$

（$a<0$ 时等于 $-\pi$。这个公式在第一章讲过，后面还会反复用到。）

一眼扫过去：前面的 5 乘上 $\pi$，再除以 $2\pi$，刚好是 $5/2$。

> **结论**：$a=\dfrac{\text{频域积分值}}{2\pi}$。在脑子里少走一步路——从右边 $\mathrm{sa}$ 的写法出发，从左边 $X(0)$ 出发，两头一夹，$a$ 就出来了。

请大家认真地想一想这里各种各样的道理：为什么是面积、为什么除以 $2\pi$、为什么能一眼看出 $\pi$。

### 认得出 sa，比算得快得多

知道了这个道理，我们继续出题。还是同一套路子，我一笔写出来。

**$X(\omega)=\dfrac{1}{2}\cdot\dfrac{\sin 3\omega}{\omega}$** 是什么信号的变换？

一眼就是 $\mathrm{sa}$，截止 $\pm3$。$a$ 怎么来？频域积分值 $=\frac{1}{2}\cdot\pi=\frac{\pi}{2}$，除以 $2\pi$ 就是 $\frac14$。所以这个方波的**面积是 $\frac14$**，截止 $\pm3$、宽度 6，于是高度 $=\frac14\div 6=\frac1{24}$。

**$X(\omega)=\dfrac{1}{2}\cdot\dfrac{\sin\omega}{\omega}$** 呢？截止 $\pm1$，面积 $=\frac{\frac12\pi}{2\pi}=\frac14$。

### 公式五：sin(nt)/t 与那块 π 高的平台

前面这些做完，来看公式五。公式五我一样用出题的方式来讲——**这是最简单的一道题**。

**$\dfrac{\sin 3t}{t}$ 的傅里叶变换是多少？**

代公式。答案是一块高度为 $\pi$ 的平台，支撑在 $|\omega|<3$ 上。

为什么是 $\pi$？我们把 $\dfrac{\sin 3t}{t}$ 写成 $3\cdot\dfrac{\sin(3t)}{3t}$，换元 $u=3t$ 之后就回到了最基本的那一对：$\dfrac{\sin u}{u}\leftrightarrow \pi\,[\cdot]_{|w|<1}$。**$\pi$ 在这里换了个位置，从分母跑到常数上去了。**

不要死记 $\sin 3t/t$ 这一条，而是记住生成它的那条积分：

$$\int_{-\infty}^{+\infty}\frac{\sin 3t}{t}\,\mathrm{d}t=\pi$$

$$\int_{-\infty}^{+\infty}\frac{\sin 5t}{t}\,\mathrm{d}t=\pi$$

都是 $\pi$。谁被 $3$ 除、被 $5$ 除、被 $2$ 除，$\pi$ 就跟着缩一次，宽度就跟着变一次。

**再来一道**：$\dfrac{\sin 5t}{3t}$ 的傅里叶变换是多少？

我把一位同学请上来做。同学写的是 $|\omega|<5$ 上取 $\dfrac13$，范围对了，**但 $\pi$ 被你擦掉了**。你看这里是 $\frac13$，那么前面那个 $\pi$ 放到哪里去了？$\dfrac{\sin 5t}{t}$ 的积分是 $\pi$，被 3 除得 $\dfrac{\pi}{3}$——$3$ 在分母上，$\pi$ 不会凭空消失。正确的答案是

$$X(j\omega)=\frac{\pi}{3},\qquad |\omega|<5$$

换句话说，这位同学请坐。**公式四和公式五不是生硬地背和记公式，而是做这些题。** 请大家认真地理解：这两条你做熟、做多了，这两对变换在手上就是手到擒来；我要求的是四种题、五秒钟之内把正变换反变换完全写出来。

反着也一样：给定一块 $\pi$ 高的平台，反变换写出来就是 $\dfrac{\sin 3t}{t}$。上面这块常数对应着 $\sin$ 括号里的那个数，这边是多少就是多少。

### 公式六：单位阶跃的傅里叶变换

公式六是 $\varepsilon(t)$——单位阶跃——的傅里叶变换：

$$\mathcal{F}\{\varepsilon(t)\}=\frac{1}{j\omega}+\pi\,\mathrm{PV}\{\delta(\omega)\}$$

> **提示**：$\varepsilon(t)$ 就是我们常写的 $\mathrm{u}(t)$，它在 $t>0$ 时为 1、$t<0$ 时为 0。这是一个**阶跃函数**，跟前面所有信号都不一样的地方在于：它在整个实轴上不衰减，所以它的频域里出现了一个 $1/\omega$ 和一个 $\delta$，两项都得留意。

上一节课是从右推到左推了一遍的，推得比较快。今天我们把它**再推一遍**，印象会深一点；然后再把左推右也走一遍。

右推左相对简单，左推右有难。

#### 右推左：把 ε(t) 从频域拼回来

按反变换的定义：

$$\varepsilon(t)=\frac{1}{2\pi}\left[\frac{1}{j\omega}+\pi\,\mathrm{PV}\{\delta(\omega)\}\right]\cdot e^{j\omega t}\,\mathrm{d}\omega$$

我们把它拆成两项，分别算。

```text
   X(jω) = 1/(jω)  +  π·PV{δ(ω)}
      │
      ├── 1/(jω) 这一项
      │     (1/2π)∫ e^{jωt}/(jω) dω
      │        = (1/2π)·[ ∫cos(ωt)/(jω)dω  +  ∫sin(ωt)/ω dω ]
      │                       奇函数, 积分为 0        = π/2   (t>0)
      │                                             = -π/2  (t<0)
      │
      └── π·PV{δ(ω)} 这一项
            (1/2π)·π·δ(ω)·e^{jωt}|_{ω=0} = (1/2π)·π·1 = 1/2
```

**先算相对容易的第二项。** $\pi$ 跟 $\pi$ 先约掉，剩下 $\dfrac{1}{2}$。再用 $\delta$ 函数的筛选性质：$\int_{-\infty}^{+\infty}x(\omega)\delta(\omega)\,\mathrm{d}\omega=x(0)$，这里 $x(\omega)=e^{j\omega t}$，$x(0)=e^{j\cdot 0\cdot t}=1$。**所以整项就是 $\dfrac12$。**

**再看第一项**，稍微有点难。但你如果有一些经验，马上能够知道。我做一个分解动作——做熟了你可以直接过渡到连续动作。展开指数函数：

$$\frac{1}{2\pi}\int\frac{e^{j\omega t}}{j\omega}\,\mathrm{d}\omega=\frac{1}{2\pi}\int\frac{\cos\omega t}{j\omega}\,\mathrm{d}\omega+\frac{1}{2\pi}\int\frac{\sin\omega t}{\omega}\,\mathrm{d}\omega$$

$j$ 跟 $j$ 约掉。

> **易错点**：右边这一项有个高频陷阱——**随时关注被积函数的奇偶性**。$\cos\omega t$ 是 $\omega$ 的偶函数，$1/\omega$ 是奇函数，**偶函数除以奇函数，还是奇函数**；奇函数在 $(-\infty,+\infty)$ 上的积分等于零。所以这一项直接没了。

剩下的那一项就是刚才那个老熟人：

$$\frac{1}{2\pi}\int\frac{\sin\omega t}{\omega}\,\mathrm{d}\omega=\frac{1}{2\pi}\cdot\pi\cdot\mathrm{sgn}(t)=\begin{cases}\dfrac12,&t>0\\[2pt]-\dfrac12,&t<0\end{cases}$$

这里要用第一章那条公式，把 $\omega$ 和 $t$ 整个互换一下：原来的 $\sin at/t$，换成 $\sin t/\omega$，$\sin$ 外面那一位 $a>0$ 的条件换成 $t>0$，结论还是 $\pi$。**在第一章就讲过这个互换**，你记住的话，这里立刻就能拿到。

现在把两半拼起来：

$$\varepsilon(t)=\frac{1}{2}\cdot\mathrm{sgn}(t)+\frac{1}{2}=\begin{cases}\dfrac12+\dfrac12=1,&t>0\\[2pt]-\dfrac12+\dfrac12=0,&t<0\end{cases}$$

刚好就是 $\varepsilon(t)$。大家认真地看一下这个就知道了。

#### 左推右：硬推，以及那一项为什么等于零

左推右有难，但我觉得值得给大家讲一遍，来加深印象。

$$\varepsilon(t)\ \xrightarrow{\mathcal{F}}\ X(j\omega)=\int_{-\infty}^{+\infty}\varepsilon(t)e^{-j\omega t}\,\mathrm{d}t$$

$\varepsilon(t)$ 在 $t<0$ 的部分是 0，直接擦掉，把积分限换成 $0$ 开始：

$$X(j\omega)=\int_{0}^{+\infty}e^{-j\omega t}\,\mathrm{d}t$$

这个积分不收敛。我们乘除一个 $e^{-j\omega t}$——它自己的原函数就是它自己——把它变成能算的样子：

```text
   u(t)  ──►  ∫₀^∞ e^{-jωt} dt
                     │
                     │  乘除 e^{-jωt}，它的原函数就是它自己
                     ▼
        (1/jω)·[ 1 - lim_{n→∞} e^{-jωn} ]
                     │
                     │  e^{-jωn} = cos(nω) - j·sin(nω)
                     ▼
        X(jω) = 1/(jω) - (1/jω)·lim_{n→∞}cos(nω) + lim_{n→∞}sin(nω)/ω

        第一项 ──────────────── 直接成立
        第二项 ──────────────── 广义意义 = 0（要用狄利赫雷三条件证）
        第三项 ──────────────── = π·δ(ω)（讲 δ(t) 时学过）
```

把 $e^{-j\omega n}$ 展开成 $\cos(n\omega)-j\sin(n\omega)$，整理一下就得到下面这三项。

**第一项 $\dfrac{1}{j\omega}$**：出来了，我们要找的就是它。

**第三项 $\lim\limits_{n\to\infty}\dfrac{\sin n\omega}{\omega}$**：这个我们也学过。在讲 $\delta(t)$ 那一节我们记过一条公式——$\lim\limits_{n\to\infty}\dfrac{\sin n\omega}{\omega}=\pi\,\delta(\omega)$。把所有的 $t$ 换成 $\omega$，把 $\pi$ 拿过来，这一项就有了。$\pi\,\mathrm{PV}\{\delta(\omega)\)$ 也就有了。

**麻烦的是第二项。** 按照道理你要核对的话，这一项应该等于零。你能感觉得到这一项等于零吗？——这明显不等于零啊，每一个点都不等于零。**这就是一个相对来说复杂的问题。**

注意，这里的"等于零"**不是说每一个点都等于零，它是广义地等于零**。按勒贝格意义下两个函数相等的定义：任取一个函数 $f(\omega)$，它跟这个函数相乘起来积分为零，那么我们就可以把这个函数记成零。所以我们要证明的是

$$\forall f(\omega),\qquad \lim_{n\to\infty}\int_{-\infty}^{+\infty}\frac{\cos(n\omega)}{\omega}\,f(\omega)\,\mathrm{d}\omega=0$$

用到的工具我们曾经讲过：**若 $x(\omega)$ 满足狄利赫雷三条件，则 $\lim\limits_{n\to\infty}\int x(\omega)\cos(n\omega)\,\mathrm{d}\omega=0$**。换句话说，任何一个变化不是那么剧烈的函数，去做一个非常强烈的振荡积分，它是等于零的。

可是在这里**你不能直接用**，因为分母等于零的时候临时不满足三条件——$\omega=0$ 是个奇点。怎么办？还是我们前面讲过很多次的那个技巧：**减一项，再加一项。**

```text
        f(ω)/ω   撑不住奇点 ω=0, 不能直接套狄利赫雷三条件
           │
           │  减一项再加一项
           ▼
   f(ω)/ω = [ f(ω) - f(0) ]/ω   +   f(0)/ω
                  │                    │
                  │                    └── 奇函数 × cos(nω) 仍是奇函数
                  │                        全轴积分 = 0
                  │
                  └── 在 ω=0 处连续，处处满足狄利赫雷三条件
                      lim_{n→∞}∫[f(ω)-f(0)]/ω · cos(nω)dω = 0
```

- **第二块**：$f(0)/\omega$ 在 $0$ 之外是奇函数，乘上偶函数 $\cos(n\omega)$ 还是奇函数，全轴积分等于零。
- **第一块**：把整个 $\dfrac{f(\omega)-f(0)}{\omega}$ 看成某个 $f'(\omega)$ 型的函数，它在 $\omega=0$ 处连续（取值就是 $f'(0)$），在任何一个地方都满足狄利赫雷三条件，直接用定理，归零。

两块加起来都为零，所以这一项就是零。

> **结论**：$$X(j\omega)=\frac{1}{j\omega}+\pi\,\mathrm{PV}\{\delta(\omega)\}$$

我看到很多信号与系统的书，$u(t)$ 的傅里叶变换都是**直接给一个公式，从来没有正着推和反着推**。实际上按照我们学到的知识，尤其是反着推，其实并不难。正着推我也给大家推过了，书上是在一个很小的地方——第 107 页式 (3.83)。

至于 $u(t)$ 的拉普拉斯变换，书上是在**另一个地方**。

接下来我要说的是公式七：$\cos\omega t$ 和 $\sin\omega t$ 的傅里叶变换。我们待会儿再讲。我们先把公式一到公式六过一遍——有了这六条，我们其实已经能够做很多事了。

#### 一、方波与 sa 的对认（公式四）

**题目**：写出下列信号的傅里叶变换。
1. 截止 $\pm5$、面积 10 的方波；
2. 时域从 $-1$ 到 $1$、高度为 2 的方波；
3. 截止 $\pm3$、高度为 2 的方波（点评用的那一道）。

**答案**：
1. $10\,\mathrm{sa}(5\omega)=\dfrac{2\sin 5\omega}{\omega}$；
2. 面积 $4$、截止 $1$，得 $4k$，$k=\dfrac{\sin\omega}{\omega}$；
3. 面积 $12$、截止 $3$，得 $12\,\mathrm{sa}(3\omega)=\dfrac{4\sin 3\omega}{\omega}$。

**解析**：见「一个方波，频域里那个 sa 是谁」与「为什么 sa 的系数恰好是方波的面积」。三条并行的线索一次填完——$\sin$ 括号里的 $\omega$ 系数取截止点，括号外的系数取面积。

#### 二、反着出：给 sa 画方波

**题目**：写出 $\pi\,\mathrm{sa}(2\omega)$ 的反变换。

**答案**：宽度 $4$（截止 $\pm2$）、高度 $\dfrac{\pi}{4}$ 的方波。

**解析**：见「反着出题：给 sa，画方波」。横坐标由截止点定，纵坐标由「面积 ÷ 宽度」定。

#### 三、转弯题与不转弯做法

**题目**：写出 $15\,\mathrm{sa}(3\omega)$ 的反变换。

**答案**：截止 $\pm3$、宽度 $6$、高度 $\dfrac52$ 的方波。

**解析**：见「转好大一圈弯，和一眼认出来」。不转弯的做法是：先认出 $5\dfrac{\sin3\omega}{\omega}$ 也是 $\mathrm{sa}$，截止点直接取 $\sin$ 括号里的 $3$，系数用 $x(0)=\dfrac{1}{2\pi}\int X(j\omega)\,\mathrm{d}\omega=\dfrac{1}{2\pi}\cdot 5\cdot\pi=\dfrac52$。

#### 四、公式五：sin(nt)/t

**题目**：
1. 写出 $\dfrac{\sin 3t}{t}$ 的傅里叶变换；
2. 写出 $\dfrac{\sin 5t}{3t}$ 的傅里叶变换。

**答案**：
1. $X(j\omega)=\pi$，$|\omega|<3$，其余为 0；
2. $X(j\omega)=\dfrac{\pi}{3}$，$|\omega|<5$，其余为 0。

**解析**：见「公式五：sin(nt)/t 与那块 π 高的平台」。$\pi$ 的来源是 $\int_{-\infty}^{+\infty}\dfrac{\sin at}{t}\,\mathrm{d}t=\pi\ (a>0)$；被几除，$\pi$ 跟着缩几倍，宽度跟着变成几。第 2 题的常见错误是把 $\pi$ 漏掉写成 $\dfrac13$。

#### 五、半分钟四题（过关线）

**题目**：30 秒内写出下列四个结果：$12\,\mathrm{sa}(2\omega)$ 的反变换；$\sin 5t$ 除以 $3t$ 那一族的傅里叶变换；第五对那一族的反变换；$2k$ 的反变换。

**答案**：分别是——宽度 $4$、高度 $3$ 的方波；$|\omega|<5$ 上高 $\dfrac16$ 的平台；面积 $\dfrac{\pi}{2}$、截止 $\pm5$、宽度 $10$、高度 $\dfrac{\pi}{20}$ 的方波；宽度 $2$、高度 $1$ 的方波。

**解析**：见「半分钟四题：这是过关线」。全部用同一条链：认 $\mathrm{sa}$ → 读截止点 → 用 $a=\dfrac{1}{2\pi}\int X(j\omega)\,\mathrm{d}\omega$ 求系数 → 面积 ÷ 宽度得高度。下节课开头还会抽人做这四道题。

## 傅里叶变换的性质：七块积木和搭积木的规则
> 对应块：BLK28 | 覆盖分集：P22上 | 块标题（分集名）：《傅里叶变换的性质（线性、时移、频移、微分、卷积）》

### 这一讲的分量，以及我打算怎么讲

先说清楚今天这三节课的分量。今天虽然只有三节课，但考试里或多或少会用到这三节课内容的题目，至少占 20%，甚至可能到 30%。想拿高分的，今天必须认真听。

今天讲的是书上 3.4 节「连续时间傅里叶变换的性质」，从 103 页一直到 116 页，性质很多。我先说清楚我打算怎么讲：这些性质我会一个一个给大家讲明白，但**不需要大家死记**。真正需要你们记的，是两类题目。

这两类题是：

- 给一个时域信号 $x(t)$，迅速写出它的傅里叶变换 $X(j\omega)$；
- 给一个频域信号 $X(j\omega)$，迅速写出它的时域信号 $x(t)$。

就这两种。今天这三堂课所做的题目，全部都是这两种，没有例外。

那性质本身怎么办？它们不用背，它们是**工具**。我把讲法给你们摆出来：

> **结论**：不记性质，记题目。把题目做熟，性质自然就了然于胸。

工具就是两样东西。第一样是那七个常用的傅里叶变换对，我们叫它**七块积木**。任何看起来千奇百怪的非周期信号，本质上都是这七块积木搭出来的。第二样是 3.4 节这一串性质，我们叫它**搭积木的规则**——告诉你积木怎么挪、怎么叠、怎么拆。

> **结论**：用七块积木，加上 3.4 节的规则，能搭出一大堆信号的傅里叶变换和反变换。

所以今天做题的方式就很固定：看到题，先想「这个信号能拆成哪几块积木」，而不是先去翻公式表硬算。

我说得再直白一点：这些题目对我来说全是五到十秒钟的事情。大家如果考试想拿高分，或者以后要能非常随意地翻书、能很快理解更复杂的内容，这就是基本功。今天我把速度摆出来给你们看，你们要学的是**这个拆积木的过程**，不是最后那个答案。

时域的平移性质我放在第二个讲，它和线性性质不一样，是一个**大进步**的方法——学完它，很多原来要硬拆的题一下子就有捷径了。

### 线性性质

线性性质的写法是：若 $x_1(t) \leftrightarrow X_1(j\omega)$，$x_2(t) \leftrightarrow X_2(j\omega)$，则

$$
a\,x_1(t) + b\,x_2(t) \quad\longleftrightarrow\quad a\,X_1(j\omega) + b\,X_2(j\omega)
$$

系数 $a$、$b$ 可以是任意常数，这和前面讲的线性系统那一套是一样的。也可以反过来理解：整体先缩放再平移，和先分别缩放平移再相加，两条路得到的结果一样，所以你可以选拆开做，也可以选合成做，看哪条路顺。

这个性质我不去证明了。它就是一个积分，$\int_{-\infty}^{+\infty}(\cdot)e^{-j\omega t}dt$，而积分的线性性你们早就用了一整个学期了——非重不叠区间上分段积分、错开相减再求和，说的就是同一件事。真要证明，把 $a x_1 + b x_2$ 代进积分、把积分拆成两项、再把两项分别认出来，三行就完了，没必要在纸上再写一遍。

下面直接用这条性质搭积木。

在动手之前，先把一块积木的记账方法说清楚，后面每一道题都要用：

> **结论**：一个高度为 $h$、在 $[-T, T]$ 上取值的矩形，它的傅里叶变换就是「面积 $2Th$ 乘上 $\mathrm{Sa}(T\omega)$」。**面积乘在前面，$\mathrm{Sa}$ 的括号里放半宽乘 $\omega$。**

#### 凸字型信号：拆成两块矩形

第一道题由简单到复杂。$x(t)$ 是个「凸字型」：在 $[-3,-1]$ 上是 1，在 $[-1,1]$ 上是 2，在 $[1,3]$ 上是 1，其他地方是 0。问它的傅里叶变换。

```text
        -3      -1       1       3
         |       |       |       |
    2    |       |#######|       |    ← 块 B：rect[-1,1]，高 1
    1    |#######|#######|#######|    ← 块 A：rect[-3,3]，高 1
    0    +------------------------------→ t
```

读图：底下那一层是 $[-3,3]$ 上高度为 1 的大矩形，上面那一层是 $[-1,1]$ 上高度为 1 的小矩形，叠起来就是原信号。

所以 $x(t)$ 等于「$[-3,3]$ 上的一块 1」加上「$[-1,1]$ 上的一块 1」。按刚才的记账法，大矩形面积是 6、半宽 3；小矩形面积是 2、半宽 1，于是

$$
X(j\omega) = 6\,\mathrm{Sa}(3\omega) + 2\,\mathrm{Sa}(\omega)
$$

就这样，没有积分，没有硬算。中间那一段之所以是 2，就是因为有两块积木摞在一起。

#### 两端一块、中间挖掉

第二道题还是用线性性质，但换个拆法。这个信号在 $[-4,-2]$ 和 $[2,4]$ 上是 1，在 $[-2,2]$ 上是 0。它等于「$[-4,4]$ 上的 1」减去「$[-2,2]$ 上的 1」，所以

$$
X(j\omega) = 8\,\mathrm{Sa}(4\omega) - 4\,\mathrm{Sa}(2\omega)
$$

面积分别是 8 和 4，括号里分别是 $4\omega$ 和 $2\omega$。

我找了位同学上来写，答案是完全正确的。写对了之后我总要问一句「为什么是这样」——因为它就是拆开来了，$[-4,4]$ 一块、$[-2,2]$ 一块，一块加一块减一块。这种题一点技巧都没有，就是账要记清楚，别把面积和半宽搞混。

（顺便说一句：似乎女生比男生要厉害。这道题我一次就叫对了人。）

#### 两端是常值尾巴、中间为 0 的信号

这道题是研究生考试的考题，五分。我曾经判过卷子，有个印象非常深的画面：考场上有的同学直接套傅里叶变换的公式去硬算，算了半天没算出来。这道题稍微难一点，但你想通了其实也不难。

信号在 $[-3,3]$ 之外是 1，$[-3,3]$ 之内是 0。这个信号等于「整条时间轴上的 1」减去「$[-3,3]$ 上的 1」。整条轴上的 1，它的傅里叶变换是 $2\pi\delta(\omega)$；$[-3,3]$ 上的 1 是 $6\,\mathrm{Sa}(3\omega)$。所以

$$
X(j\omega) = 2\pi\delta(\omega) - 6\,\mathrm{Sa}(3\omega)
$$

这道题主要是个**眼光**的问题：你能不能一眼看出「整条轴上的 1」是一块现成的积木。有人会去硬套那个无穷区间的积分公式，硬算到一半发现算不下去，就卡死在那儿了。你只要先把整体那个 1 认出来，剩下的就是一个有限区间，一秒钟的事。

#### 符号函数：答案是 $2/(j\omega)$

再上一道难的。这道题要是你能做出来，说明你相当聪明。函数叫 $\mathrm{sgn}(t)$，符号函数，书上也有：$t>0$ 时取 1，$t<0$ 时取 $-1$。求它的傅里叶变换。书上给了一种做法，但我不认为那是最简单的，我希望你们**用线性性质把它做出来**。

关键是眼光问题，是怎么猜的问题。猜成积木——1、2、3、4、5、6、7 全都在这里，关键是你到底拆成**哪两块**。

拆法是：

$$
\mathrm{sgn}(t) = 2u(t) - 1
$$

验证一下：$t>0$ 时 $u(t)=1$，$2\times 1-1=1$；$t<0$ 时 $u(t)=0$，$2\times 0-1=-1$。对了。也可以看成 $u(t)-u(-t)$，画一条虚线把整条轴上的 $-1$ 拉过去，再加一个 $u(t)$，一个道理。

$u(t)$ 的傅里叶变换大家都自己凑得出来：$\pi\delta(\omega) + \dfrac{1}{j\omega}$。所以

$$
X(j\omega) = 2\left[\pi\delta(\omega) + \frac{1}{j\omega}\right] - 2\pi\delta(\omega) = \frac{2}{j\omega}
$$

那个 $\pi\delta(\omega)$ 一正一负正好抵消，只剩下 $\dfrac{2}{j\omega}$。这就是 $\mathrm{sgn}(t)$ 的傅里叶变换。

书上是 108 页例 3.7，用的是另外一种做法。我觉得没有我这里这种方法简单。

#### 三块积木叠加

最后这一道，难度不算大，但**只要不犯错**就可以了。这道题我在别处用线性性质做的时候，觉得这是最难提出的一个——难度已经到顶了，接下来只是繁琐。

信号可以拆成三块积木：

- $[-3,-2]$ 上一段高度为 3 的矩形；
- 「整条轴上的 1」减去「$[-3,3]$ 上的 1」；
- $[-2,2]$ 上的 1，整块都是 1。

第二块给出 $2\pi\delta(\omega) - 6\,\mathrm{Sa}(3\omega)$，第三块给出 $4\,\mathrm{Sa}(2\omega)$。第一块刚要写，我说了一句「休息一下，下节课继续」，那块积木的变换就留在黑板上了。

线性性质就先讲到这里。

### 时移性质：换个原点，同一个信号

时域的平移性质是这么说的：若 $x(t) \leftrightarrow X(j\omega)$，则

$$
x(t-t_0) \quad\longleftrightarrow\quad X(j\omega)e^{-j\omega t_0}
$$

时域往右挪 $t_0$，频域就乘上一个 $e^{-j\omega t_0}$。

#### 证一遍：换元之后三个撇全部消掉

证明我一步一步写详细一点，因为这个换元的套路以后会反复用。

$$
\begin{aligned}
\mathcal{F}\{x(t-t_0)\}
&= \int_{-\infty}^{+\infty} x(t-t_0)\, e^{-j\omega t}\,dt
\end{aligned}
$$

按定义，接下来要算的是 $x(t-t_0)$ 的变换，所以从定义出发。换元，令 $\tau = t - t_0$，也就是 $t = \tau + t_0$。上下限也要一起换：$t \to -\infty$ 时 $\tau = t-t_0$ 还是 $-\infty$；$t \to +\infty$ 时 $\tau$ 还是 $+\infty$，所以上下限不变。$t_0$ 是常数，所以 $dt = d\tau$。

$$
\begin{aligned}
&= \int_{-\infty}^{+\infty} x(\tau)\, e^{-j\omega(\tau+t_0)}\,d\tau
\end{aligned}
$$

这里 $t=\tau+t_0$ 替进去，$e$ 里就出现了 $e^{-j\omega\tau}e^{-j\omega t_0}$。$x(\tau)$、$e^{-j\omega\tau}$、$d\tau$ 这三个 $\tau$ 是同一个东西，直接把撇全消掉：

$$
\begin{aligned}
&= \int_{-\infty}^{+\infty} x(\tau)\, e^{-j\omega\tau} e^{-j\omega t_0}\,d\tau \\
&= e^{-j\omega t_0} \int_{-\infty}^{+\infty} x(\tau)\, e^{-j\omega\tau}\,d\tau
\end{aligned}
$$

之所以能把 $e^{-j\omega t_0}$ 提到积分号外面，是因为它里面根本没有 $\tau$——它是一个关于 $t$ 的常数，而这个积分是对 $\tau$ 做的。括号里那一项刚好就是 $X(j\omega)$，所以

$$
\mathcal{F}\{x(t-t_0)\} = X(j\omega)\,e^{-j\omega t_0}
$$

> **易错点**：换元之后上下限**不跟着平移**。$t\to\pm\infty$ 减掉一个常数还是 $\pm\infty$，这一点跟定积分换元不一样，别记反了。另外 $\tau$ 只在积分变量里出现，跟积分号外的任何东西都无关——这就是三个撇能全部消掉的原因。

#### $0$ 到 $2$ 的方波：两种拆法

第一道题：$x(t)$ 在 $0\sim 2$ 上是 1，求它的傅里叶变换。

先给 20 秒钟想。我写的时候大概五秒钟，但**我知道我用的是时移性质**——时移性质已经记在脑子里面了，不用查。你们把这样的题做熟了，这个性质自然就记住了。

**拆法一**，用七块积木里现成的方块。设 $y(t)$ 在 $[-1,1]$ 上是 1，那么 $Y(j\omega)=2\,\mathrm{Sa}(\omega)$。现在 $x(t)=y(t-1)$，是 $y$ 往右移一位，$t_0=1$，所以

$$
X(j\omega) = 2\,\mathrm{Sa}(\omega)\,e^{-j\omega}
$$

**拆法二**，这是我更常用的拆法：$x(t)=u(t)-u(t-2)$。$u(t)$ 的变换是 $\pi\delta(\omega)+\dfrac{1}{j\omega}$；$u(t-2)$ 是它右移两位，乘 $e^{-j2\omega}$。相减：

$$
X(j\omega) = \left[\pi\delta(\omega)+\frac{1}{j\omega}\right] - e^{-j2\omega}\left[\pi\delta(\omega)+\frac{1}{j\omega}\right]
= \frac{1}{j\omega}\left(1-e^{-j2\omega}\right)
$$

把 $1-e^{-j2\omega}$ 提出来整理一下，就是 $2\,\mathrm{Sa}(\omega)e^{-j\omega}$，跟拆法一完全一致。

我写这种题的时候已经形成条件反射了：看到「$0\sim 2$ 上是 1」，脑子里自动跳出 $\mathrm{Sa}$、跳 $\omega$、再乘上面积。你做任何一道题做很多次分解动作之后，都会形成这种肌肉记忆。

#### 用时移重做双端矩形：$4\,\mathrm{Sa}(\omega)\cos 3\omega$

第二道题我们用线性性质做过一遍，现在**用时移性质再做一遍**。这个信号在 $[-4,-2]$ 和 $[2,4]$ 上是 1。这个给大家一分钟时间，大家自己做一做，才能大致知道在干嘛。

我先给你们展示答案，再展示推理。

推理是这样的——这里不止用到时移，还叠加用了线性性质：

- $[-4,-2]$ 这一段，是 $[-1,1]$ 那个方块**左移三个单位**。$x(t+3)$ 对应 $t_0=-3$，变换是 $Y(j\omega)e^{+j3\omega}$，也就是 $2\,\mathrm{Sa}(\omega)e^{j3\omega}$；
- $[2,4]$ 这一段，是同一个方块**右移三个单位**，$t_0=3$，变换是 $2\,\mathrm{Sa}(\omega)e^{-j3\omega}$。

两块加起来：

$$
X(j\omega) = 2\,\mathrm{Sa}(\omega)\left(e^{-j3\omega} + e^{j3\omega}\right)
$$

> **提示**：这里要用的是第一章第一节课就讲过的「加号左移、减号右移」——$x(t+t_0)$ 是左移，$t_0$ 记成 $-3$；$x(t-t_0)$ 是右移，$t_0$ 记成 $3$。中间那个负号被吸收进指数里了，看到 $t+3$ 的时候要立刻想到 $t_0=-3$。

写到这里完全可以交卷了，我不会扣你分。但**还能化简**，而且化简以后才是这道题漂亮的地方：

$$
e^{-j3\omega}+e^{j3\omega} = 2\cos 3\omega
$$

这个 $e^{j\theta}+e^{-j\theta}=2\cos\theta$ 是非常常用的公式。所以

$$
X(j\omega) = 4\,\mathrm{Sa}(\omega)\cos 3\omega
$$

回头对一下：$4\,\mathrm{Sa}(\omega)\cos3\omega$ 和我们用线性性质得到的 $8\,\mathrm{Sa}(4\omega)-4\,\mathrm{Sa}(2\omega)$ 是同一个东西。同一道题，两条路，两种完全不同的样子。

#### 关于 $t_0$ 对称的一对：一律乘 $2\cos(\omega t_0)$

上面那道题其实是一类题的特例，这一类很值钱，你们请想清楚。

如果 $x(t) \leftrightarrow X(j\omega)$，那么 $x(t-t_0) + x(t+t_0)$ 在时域里长什么样？它是一个**以 $t=0$ 为对称轴、同时关于 $t=t_0$ 和 $t=-t_0$ 呼应**的形状——一正一负两个位移放在一个对称轴上。

它的傅里叶变换用时移加线性，直接得到：

$$
\boxed{\;\mathcal{F}\{x(t-t_0)+x(t+t_0)\} = 2X(j\omega)\cos(\omega t_0)\;}
$$

道理特别朴素：这一边拿去傅里叶变换，会多出一个 $e^{-j\omega t_0}$；那一边拿去傅里叶变换，会多出一个 $e^{j\omega t_0}$；两个东西加到一起就是 $2\cos(\omega t_0)$。

所以以后凡是看到时域里「关于某个点对称的一对 $x$」，第一反应应该是：

> **结论**：把中间那个信号的变换写出来，乘上 $2\cos(\omega t_0)$ 就完事。

这是一个相对深度的技巧。我做题做到后面，看到这种 y 轴对称的组合，会本能地在草稿纸上先写那个 $X(j\omega)$，然后在后面缀一个 $2\cos(\omega t_0)$，中间怎么拆都不写。

#### 两个阶跃的移位，以及 $\delta(\omega)$ 的小把戏

一次出两道题，都是阶跃。第一道是 $u(t-1)$，就是在 $t=1$ 处跳变的阶跃。第二道是 $u(-t-1)$，在 $t=-1$ 处跳变、方向相反的阶跃。我把它写成 $u(-1-t)$ 这样可能好看一点。

第一道：$u(t-1)$ 是 $u(t)$ 右移一位，直接套时移：

$$
X(j\omega) = \left[\pi\delta(\omega)+\frac{1}{j\omega}\right]e^{-j\omega}
= \pi\delta(\omega)e^{-j\omega} + \frac{e^{-j\omega}}{j\omega}
$$

到这儿也没错，但还能化简一步。要用到的是这个恒等式：

> **易错点**：$X(j\omega)\delta(\omega) = X(0)\,\delta(\omega)$。指数在 $\delta(\omega)$ 上取的值就是它的下标处，也就是 $e^{\pm j\omega}\delta(\omega)=\delta(\omega)$。

所以答案化简成

$$
\pi\delta(\omega) + \frac{e^{-j\omega}}{j\omega}
$$

你要是写成 $\pi e^{-j\omega}\delta(\omega) + \dfrac{e^{-j\omega}}{j\omega}$，我也不判你错，但你得知道这里还能再化一步。

第二道：$u(-t-1)$ 稍微复杂一点。$u(-t)$ 的变换是 $\pi\delta(\omega) - \dfrac{1}{j\omega}$，$u(-t-1)$ 是它**左移一位**，所以

$$
X(j\omega) = \left[\pi\delta(\omega)-\frac{1}{j\omega}\right]e^{j\omega}
$$

然后照旧把 $\delta$ 上那个指数吃掉，得到

$$
\pi\delta(\omega) - \frac{e^{j\omega}}{j\omega}
$$

到这里也还能再化一步。记住这两道题的样子，后面做相关运算的时候会一直遇到它们。

#### 反变换：频域的线性相位就是时域上的延时

最后一道题是反变换，也是时移性质里相对难的一道题，它需要一点想象力。这道题书上似乎有类似的题，我找了半天没找到，下次找到了再说。我们自己把它做一遍。

题目是把 $X(j\omega)$ 写成模和相位相乘的形式。模是这样的：

```text
  |X(jω)|
    │
  1 ┤     ┌────────┐
    │     │        │
  0 ┼─────┘        └──────────→ ω
          -2        2

  θ(ω)
  0 ┼──╲
    │   ╲
    │     ╲     斜率 k = -2
    │       ╲
  ──┴─────────╲────────────────→ ω
         -2
```

读图：模是一个从 $-2$ 到 $2$ 的通带，之外为 0；相位是 $\theta(\omega) = -2\omega$，一条过原点的直线，斜率 $k=-2$。**相位是线性的**，这就是全部的突破口。

分两步走。

第一步只看模。$X(j\omega)=1$、$|\omega|\le 2$、其他为 0，这是积木表里的公式：

$$
1 \ \text{（}\lvert\omega\rvert \le 2\text{）} \quad\longleftrightarrow\quad \frac{2}{\pi}\,\mathrm{Sa}(2t)
$$

第二步处理相位。$e^{j\theta(\omega)}=e^{-j2\omega}$，这在时移性质里有一个一一对应：频域里乘 $e^{-j\omega t_0}$，时域就是**延时 $t_0$**。这里要让它等于 $e^{-j\omega \times 2}$，所以 $t_0=2$，那边就延时两个单位。

于是

$$
x(t) = \frac{2}{\pi}\,\mathrm{Sa}\big(2(t-2)\big)
$$

为什么这里会冒出一个线性相位？因为信号在时域里延后了 2 个单位，频域的相位就得补上一条斜率为 $-2$ 的直线。两者是一枚硬币的两面。

> **结论**：**频域上的线性相位，对应时域上一个确定的延时；延时的时间，就是这条线性相位的斜率。** 这个概念很重要，后面我们还会讲到。看到频域里有一条直线相位，第一反应就应该是「时域里有个延时，去把中心挪过来」。

这道题请大家体会一下。做的时候你先想：模对应的是哪个积木？相位这个因子对应时域里的什么操作？两步拼起来，答案就出来了。

### 频移性质：cos 和 sin 是怎么长出来的

时域里的平移讲完了，接下来是频域里的平移。它的说法是：若 $x(t)\leftrightarrow X(j\omega)$，则

$$
x(t)e^{j\omega_0 t} \quad\longleftrightarrow\quad X\big(j(\omega-\omega_0)\big)
$$

时域里乘一个复指数，频谱就整体搬移 $\omega_0$。

证明比时移还简单，直接带进去：

$$
\begin{aligned}
\mathcal{F}\{x(t)e^{j\omega_0t}\}
&= \int_{-\infty}^{+\infty} x(t)e^{j\omega_0t}e^{-j\omega t}\,dt \\
&= \int_{-\infty}^{+\infty} x(t)e^{-j(\omega-\omega_0)t}\,dt \\
&= X\big(j(\omega-\omega_0)\big)
\end{aligned}
$$

两个指数一合并就完了，不用换元。

拿它推两个东西。$e^{j\omega_0 t}$ 和 $e^{-j\omega_0 t}$ 的变换你自己试着推一下——左边是 $x(t)=e^{j\omega_0t}$，右边直接由 $1\leftrightarrow 2\pi\delta(\omega)$ 平移得到，不用积分：

$$
e^{j\omega_0t} \longleftrightarrow 2\pi\delta(\omega-\omega_0),\qquad
e^{-j\omega_0t} \longleftrightarrow 2\pi\delta(\omega+\omega_0)
$$

有了这两条，cos 和 sin 就是白送的了。用欧拉公式把它们拆成指数，再用线性性质加起来：

$$
\cos(\omega_0 t) = \frac{1}{2}\left(e^{j\omega_0t}+e^{-j\omega_0t}\right)
\quad\Longrightarrow\quad
\pi\big[\delta(\omega-\omega_0)+\delta(\omega+\omega_0)\big]
$$

$$
\sin(\omega_0 t) = \frac{1}{2j}\left(e^{j\omega_0t}-e^{-j\omega_0t}\right)
\quad\Longrightarrow\quad
\frac{\pi}{j}\big[\delta(\omega-\omega_0)-\delta(\omega+\omega_0)\big]
$$

算的时候只要记住一件事：**$1$ 的傅里叶变换是 $2\pi\delta(\omega)$**，那个 $\frac12$ 就是从这儿约出来的，两个 $\pi$ 也是从这儿分出来的。$\cos$ 的两个冲激在 $\omega=\pm\omega_0$ 处高度相同，$\sin$ 的正负号是反的。

把这两个冲激的图形画出来，cos 就是关于原点对称的一对等高峰，sin 则是右边正、左边负。频域里这两条曲线长得如此简单对称，原因就是它们在时域里是最简单的两个信号——这正好又回到我们今天开头说的那句话：一切从七块积木搭起。

## 傅里叶变换的性质：微分、频移与卷积
> 对应块：BLK29 | 覆盖分集：P22中1 | 块标题（分集名）：《傅里叶变换的性质（线性、时移、频移、微分、卷积）》

这一讲开头是上一段的收尾：我们把 $e^{-at}$ 一路往 0 送，$e^{-at}\cos\omega_0t$、$e^{-at}\sin\omega_0t$ 的变换都已经算到了最后一步。把这两个结果收干净之后，我要把几条真正会反复用到的性质一口气过完——乘指数、频移、求导、乘 $t$，最后停在整节课里最重的那一条：**时域卷积等于频域相乘**。

这一条为什么重要？因为有了它，"搭积木"的办法一下子多了一大截，以前根本不敢想的信号，现在都能硬算出来。这一讲后面所有的例题，都是拿它当砖头垒出来的。

### 从 cos、sin 的冲激谱说起

$\cos$ 那一支的结论落在这里：

$$
X(j\omega)=\pi\delta(\omega+\omega_0)+\pi\delta(\omega-\omega_0)
$$

图像也就长这样：

```text
                X(jω)
                  ↑
        ↑ π       │         ↑ π
        │         │         │
  ──────┼─────────┼─────────┼──────→ ω
       -ω₀        0        ω₀
```

读图：横轴上 $\omega=\pm\omega_0$ 两个位置各立着一个强度为 $\pi$ 的冲激，中间和别处全是零。

> **提示**：$\pi$ 这个系数不是凭空冒出来的，它是 $1/(a+j\Omega)$ 在 $a\to 0^+$ 时的极限——$\int e^{-at}e^{-j\Omega t}dt = 1/(a+j\Omega)$，而 $\lim_{a\to 0^+}1/(a+j\Omega) = 2\pi\delta(\omega-\Omega)$。$\cos$ 那一支前面带了 $1/2$，所以每个点只剩 $\pi$。

$\sin$ 那一支的来历和 $\cos$ 完全一样，$\sin\omega_0t = \frac{1}{2j}\left(e^{j\omega_0t}-e^{-j\omega_0t}\right)$。**唯一不同的只有一处**：$\cos$ 前面写的是 $\frac{1}{2}$，$\sin$ 前面写的是 $\frac{1}{2j}$，于是每一项都多除以一个 $j$、指数前的系数多带一个 $j$。结果也是照抄一遍：

$$
X(j\omega)=\frac{\pi}{j}\delta(\omega-\omega_0)-\frac{\pi}{j}\delta(\omega+\omega_0)
$$

```text
                X(jω)
                  ↑
        ↑ +jπ     │         ↑ -jπ
        │         │         │
  ──────┼─────────┼─────────┼──────→ ω
       -ω₀        0        ω₀
```

同样是两个冲激，只不过一正一负、互为相反数。

> **易错点**：图上标的到底是 $\pi$ 还是 $j\pi$，取决于你在式子里写没写 $\frac{\pi}{j}$。两者是一回事：$\frac{\pi}{j}=-j\pi$。看图的时候把它换算成带符号的冲激高度，就不会再被"朝上还是朝下"绕晕。

这两个式子连同两张图都要记，它就是第六个公式。我自己到现在都常常记混——到底是 $\delta(\omega-\omega_0)$ 接 $\pi$ 还是接 $-\pi$，$\sin$ 那两个冲激谁朝上谁朝下，我时常记不住是哪个接哪个。所以这里再强调一遍：希望你们不要像我这样，能顺利地把这两个记下来。

还有一件事必须提前说清楚：**有些书上 $\sin$ 这一条不是这么写的**。有的书把负的那一项挪到前面，有的干脆两边一起乘 $-j$。看着像是换了个写法，其实完全是一回事——你把其中一项挪到另一项的下面，两个符号正好正负颠倒，加起来还是原来那个和。**两种写法都是对的，考试写哪一种我都不会给你打错**。后面我会按照书上那个写法讲。

### 乘上指数，频谱就整体挪一下

这一条叫频移性质，书上也叫调制性质。先看最基本的两个：

$$
x(t)e^{j\omega_0t}\ \longleftrightarrow\ X\big(j(\omega-\omega_0)\big)
$$

$$
x(t)e^{-j\omega_0t}\ \longleftrightarrow\ X\big(j(\omega+\omega_0)\bigr)
$$

证起来只有一行，就是把定义式里的指数并起来：

$$
\begin{aligned}
\mathcal{F}\{x(t)e^{j\omega_0t}\}
&=\int_{-\infty}^{\infty}x(t)e^{j\omega_0t}e^{-j\omega t}\,dt\\
&=\int_{-\infty}^{\infty}x(t)e^{-j(\omega-\omega_0)t}\,dt\\
&=X\big(j(\omega-\omega_0)\big)
\end{aligned}
$$

指数一合并，$\omega_0$ 直接跑到括号里去了。负指数那边同理，得到 $X(j(\omega+\omega_0))$。

把它和 $\cos$ 的分解式一拼，$\cos$ 调制就出来了。$\cos\omega_0t=\frac{1}{2}\left(e^{j\omega_0t}+e^{-j\omega_0t}\right)$，两边同时乘 $\frac{1}{2}$，再用线性性质把两项加起来：

$$
x(t)\cos\omega_0t\ \longleftrightarrow\ \frac{1}{2}\left[X\big(j(\omega-\omega_0)\big)+X\big(j(\omega+\omega_0)\big)\right]
$$

书上把这个括号里的两项写成了另一个顺序，就只是交换了一下位置，没有别的差别，这里再强调一次：两个都对。

这一节我讲得很快，**不是它不重要，是现在这样写还不够直观**。等到后面真正把调制性质那一段讲完，这个结论会突然变得非常自然；到时候我还会回到这里来。

顺着这个流程，3.4.4 和 3.4.6 这两节我们先跳过——不是不重要，是我打算放到后面再讲。**微分与积分（3.4.5）**我这里只讲微分，积分我拿到卷积那一段去讲；然后直接跳到这节课最终最重要的那一块。

### 微分性质：反过来证更好证

#### 时域微分：求导等于乘一个 $j\omega$

这一条说的是：若 $x(t)\longleftrightarrow X(j\omega)$，则

$$
\frac{dx(t)}{dt}\ \longleftrightarrow\ j\omega X(j\omega)
$$

怎么证？**记住，反过来证是更好证的**——不要从 $\mathcal{F}\{dx/dt\}$ 出发去凑，从反变换出发，一步就出来了。

$$
x(t)=\frac{1}{2\pi}\int_{-\infty}^{\infty}X(j\omega)e^{j\omega t}\,d\omega
$$

两边对 $t$ 求导。注意右边只有 $e^{j\omega t}$ 这一项含 $t$，别的地方全是 $\omega$，所以只有它参与求导：

$$
\frac{dx(t)}{dt}=\frac{1}{2\pi}\int_{-\infty}^{\infty}X(j\omega)\cdot j\omega\cdot e^{j\omega t}\,d\omega
$$

把 $j\omega$ 拿到积分号外面看——这整个式子就是 $j\omega X(j\omega)$ 的反变换。左边求导、右边求导，而左右两边正好互为傅里叶变换，所以结论成立。

这一条最好用的地方，是它能把 $\delta$ 的各阶导数一次性打包。已知 $\delta(t)\longleftrightarrow 1$，那么

$$
\delta'(t)\ \longleftrightarrow\ j\omega\cdot 1=j\omega
$$

$$
\delta^{(n)}(t)\ \longleftrightarrow\ (j\omega)^n
$$

$n$ 阶导数就是这么干净的一个式子，$\delta$ 家族的整个频谱表都从这一行长出来。

#### 频域微分：乘一个 $t$ 等于频域求导

严格地说，微分性质应该分两种。刚才那条是时域微分；书上在最后总结时还留了一条叫频域微分：

若 $x(t)\longleftrightarrow X(j\omega)$，则

$$
t\,x(t)\ \longleftrightarrow\ j\frac{dX(j\omega)}{d\omega}
$$

书上只在性质表里一笔带过（翻到 114 页那张表，第 11 条），没有完整展开，我们在这儿把它证干净。

还是从定义出发，只不过这次对 $\omega$ 求导：

$$
X(j\omega)=\int_{-\infty}^{\infty}x(t)e^{-j\omega t}\,dt
$$

$$
\frac{dX(j\omega)}{d\omega}=\int_{-\infty}^{\infty}x(t)\cdot(-jt)\cdot e^{-j\omega t}\,dt
$$

这一步的关键和刚才一样：**右边只有 $t$ 参与求导**，$e^{-j\omega t}$ 对 $\omega$ 求导只是把外面的 $j\omega$ 拿进来。所以两边同时乘上 $-1/j$（由线性性质，两边乘同一个数，谁也不吃亏），就得到

$$
\int_{-\infty}^{\infty}t\,x(t)e^{-j\omega t}\,dt=j\frac{dX(j\omega)}{d\omega}
$$

左边正是 $t\,x(t)$ 的傅里叶变换。证完。

### 一道算例：$t^n e^{-at}u(t)$ 怎么推

顺手做个练习：$e^{-at}u(t)$ 的傅里叶变换等于多少？

直接用变换对再配这条性质就行。书上附录那张"典型傅里叶变换表"的最后一行就有（116 页）：

$$
e^{-at}u(t)\ \longleftrightarrow\ \frac{1}{a+j\omega},\qquad a>0
$$

那再往前一步，$t\,e^{-at}u(t)$ 呢？用刚证完的频域微分：

$$
\begin{aligned}
\mathcal{F}\{t\,e^{-at}u(t)\}
&=j\frac{d}{d\omega}\left[\frac{1}{a+j\omega}\right]\\
&=j\cdot\left(-\frac{1}{(a+j\omega)^2}\right)\cdot j\\
&=\frac{1}{(a+j\omega)^2}
\end{aligned}
$$

这里有两个细节特别容易漏，我专门点一下：**第一个 $j$ 是性质带来的，别丢；第二个 $j$ 是求导时对 $\omega$ 求导带出来的，别丢**。然后外面那个负号也不要忘。三个东西一凑，两个 $j$ 相乘等于 $-1$，再跟求导带来的负号一约，剩下的正好是正的 1。

再推一层，$t^2e^{-at}u(t)$ 就是把上一步的结果再求一次导：

$$
\mathcal{F}\{t^2e^{-at}u(t)\}=j\frac{d}{d\omega}\left[\frac{1}{(a+j\omega)^2}\right]=\frac{2}{(a+j\omega)^3}
$$

到这一步，通式已经很明显了：

$$
\boxed{\ t^n e^{-at}u(t)\ \longleftrightarrow\ \frac{n!}{(a+j\omega)^{n+1}}\ }
$$

$n=1$ 分子是 $1$，$n=2$ 是 $2$，$n=3$ 是 $6$（三的阶乘），确实如此。这个写法和我记得的书上那个写法形式上有一点点出入，但答案完全一样，自己用数学归纳法就能证。

最后说两句考试上的实话：这条通式在**有些学校的考研题里被考到**；但就浙大本科考试来说，我们很少考到 $a+j\omega$ 分母平方以上的情况，基本上到平方为止。$n>1$ 的情况，我说过已经 10 年没有考过了。原因是这类东西写起来繁琐，只是徒增加记公式的负担，**我这里讲的都是最简单、最常用、一定要记牢的那几个**。

> **提示**：就算这个通式你记不住，考场上真碰到了也能现推。只要你记得时域微分、频域微分这两条性质，知道它大概是怎么来的，推出来只是多花几分钟而已。考试真正考的是性质，不是这张背下来的表。

### 时域卷积等于频域相乘

来了，这一节课最终最重要的知识。书上 112 页 3.4.9 时域卷积性质，我在这个地方要写一个括号——**很重要**。

结论先摆出来：若 $x(t)\longleftrightarrow X(j\omega)$，$h(t)\longleftrightarrow H(j\omega)$，则

$$
x(t)*h(t)\ \longleftrightarrow\ X(j\omega)H(j\omega)
$$

> **结论**：时域卷积等于频域相乘。这句话本身也要背下来。

证明要把第二章的知识全部串起来。设 $y(t)=x(t)*h(t)$，第一步把卷积的定义搬过来：

$$
y(t)=\int_{-\infty}^{\infty}x(\tau)h(t-\tau)\,d\tau
$$

第二步上傅里叶变换，把 $y(t)$ 的定义代进去：

$$
Y(j\omega)=\int_{-\infty}^{\infty}\left[\int_{-\infty}^{\infty}x(\tau)h(t-\tau)\,d\tau\right]e^{-j\omega t}\,dt
$$

第三步是关键：换元。令 $t=\tau+\lambda$，则 $h(t-\tau)=h(\lambda)$，$dt=d\tau$ 换成 $d\lambda$——严格一点要算雅可比行列式：$\frac{\partial t}{\partial\tau}=1$，$\frac{\partial t}{\partial\lambda}=1$，行列式等于 1，所以 $dt=d\lambda$ 一步不差。

第四步换完元，指数就被拆开了：$e^{-j\omega(\tau+\lambda)}=e^{-j\omega\tau}\cdot e^{-j\omega\lambda}$，这个乘积拆分是整个证明的枢纽。

第五步把两个积分的变量各自独立出来——相当于交换积分次序，右边立刻变成两个单积分的乘积：

$$
\begin{aligned}
Y(j\omega)
&=\int_{-\infty}^{\infty}\int_{-\infty}^{\infty}x(\tau)h(\lambda)e^{-j\omega\tau}e^{-j\omega\lambda}\,d\lambda\,d\tau\\
&=\left[\int_{-\infty}^{\infty}x(\tau)e^{-j\omega\tau}\,d\tau\right]\cdot\left[\int_{-\infty}^{\infty}h(\lambda)e^{-j\omega\lambda}\,d\lambda\right]\\
&=X(j\omega)H(j\omega)
\end{aligned}
$$

整个流程长这样：

```text
x(t) * h(t)  =  ∫ x(τ) h(t-τ) dτ                  ← 时域卷积
      │  上傅里叶变换，把定义代进去
      ▼
∫∫ x(τ) h(t-τ) e^{-jωt} dτ dt
      │  换元 t = τ + λ    （雅可比行列式 = 1）
      ▼
∫∫ x(τ) h(λ) e^{-jω(τ+λ)} dλ dτ
      │  拆指数 e^{-jω(τ+λ)} = e^{-jωτ}·e^{-jωλ}
      ▼
∫∫ x(τ) h(λ) (e^{-jωτ})(e^{-jωλ}) dλ dτ
      │  交换积分次序，两个积分各自独立
      ▼
[∫ x(τ) e^{-jωτ} dτ] · [∫ h(λ) e^{-jωλ} dλ]
      ▼
   X(jω) · H(jω)                                     ← 频域相乘
```

> **易错点**：真正吃劲的只有两步——**交换积分次序**和**把指数拆成两个**。式子看着长，其实就这么点内容。

有了这条性质，我们终于讲到了第二章开始的那个问题，大家记得认真地去看一眼。不过我先按住不表，等这一讲收尾再回去说。

现在先说它的用处：**搭积木的方法一下子丰富了很多**。我们可以搭出很多以前根本没见过的信号的傅里叶变换。下面几道题，全是当场出的。

### 方波卷出来的三角波和梯形波

#### 先记住一条定标规则

矩形的傅里叶变换就是那个 $\mathrm{Sa}$：宽度 $2a$、高为 1 的方波（$[-a,a]$）对应 $\mathrm{Sa}(a\omega)$。所以两个矩形一卷，频域就是两个 $\mathrm{Sa}$ 相乘。

但相乘之后差一个系数。这个系数不用凑、也不用硬算，**答案就是结果的面积**：

$$
X(0)=\int_{-\infty}^{\infty}x(t)e^{-j\cdot 0\cdot t}\,dt=\int x(t)\,dt
$$

而每个 $\mathrm{Sa}$ 在零处都等于 1，所以只要把那个系数补成"图形的面积"，整条式子就对了。

> **结论**：$n$ 个矩形卷出来的信号，频谱 = 各个 $\mathrm{Sa}$ 相乘 × 结果图形的面积。三角形的面积用"底×高÷2"，梯形的面积用"（上底+下底）×高÷2"。

#### 三角波：两个方波一卷就有

第一道题：给一个三角波，落在 $[-2,2]$，问傅里叶变换。

难点只有一个：**那两个方波到底怎么定**。答案是——分解方法不止一种。只要两个方波**幅度乘起来**是同一个数，随便你怎么凑都对。比如你可以凑成 $1\times1$，也可以凑成 $2\times\frac{1}{2}$，最后结果一模一样。

标准答案十秒钟能写：两个都是 $[-1,1]$ 的单位方波，两个变换都是 $\mathrm{Sa}(\omega)$，打平方，然后乘三角形的面积——底 4、高 2，面积 $4\times2\div2=4$：

$$
X(j\omega)=4\,\mathrm{Sa}^2(\omega)
$$

第二个方波凑法我也现场写一遍给你看：取 $1\times1=1$ 和 $2\times\frac{1}{2}=1$，两个幅度的乘积相同，前者贡献 $\mathrm{Sa}(\omega)^2$、后者贡献 $\mathrm{Sa}(\omega)\cdot 2\mathrm{Sa}(\omega)$，答案还是它。**所以别在凑参数上卡住，能凑出来就行。**

第二道题"完全跟那个一样"，只是加宽：两个 $[-2,2]$ 的单位方波卷积。频域是 $\mathrm{Sa}(2\omega)$ 打平方，三角形底 8、高 4，面积 $8\times4\div2=16$：

$$
X(j\omega)=16\,\mathrm{Sa}^2(2\omega)
$$

顺便对一下书：107 页例 3.6 那一道题，书上做得多么复杂——它老老实实去求 $\frac{t^2}{2}$ 这类式子的变换，得到一个 $\mathrm{Sa}(\omega/2)$ 的平方，再配上移位因子，绕了一大圈。我用十秒钟的写法：拆成两个方波，$\mathrm{Sa}(a\omega)$ 打平方，前面乘三角形的面积。

就这么两行，和 108 页式（3.85）的答案完全一样。

#### 梯形波：$a$、$b$ 的通用模板

第三个稍微绕一点：给一个梯形，横轴上标着 $-3$、$-1$、$1$、$3$，问傅里叶变换。

这个模板我以前专门说过，**这块需要背下来**：$[-a,a]$ 的方波与 $[-b,b]$ 的方波卷积，其中 $a>b>0$，结果是一个梯形，**底下的坐标一定要背**：

```text
   幅值
    2b ┤        ╭──────────╮
        │      ╱            ╲
        │    ╱                ╲
     0  ┼──┴────────────────────┴──────→ t
          -(a+b)  -(a-b)   a-b   a+b
```

| 特征 | 位置 / 数值 |
| :--- | :--- |
| 支撑区间 | $[-(a+b),\ a+b]$ |
| 平台段 | $[-(a-b),\ a-b]$，高度 $2b$ |
| 两侧 | 直线斜边 |

有了这张表，读图就是读数：题目里那个 $3$ 是 $a+b$，那个 $1$ 是 $a-b$，一解得 $a=2$、$b=1$——原来就是 $[-2,2]$ 和 $[-1,1]$ 两个方波。频域就有两个 $\mathrm{Sa}$：$\mathrm{Sa}(2\omega)$ 和 $\mathrm{Sa}(\omega)$。至于前面那个系数，道理跟刚才一模一样，两个 $\mathrm{Sa}$ 在零处都等于 1，所以它就是**梯形的面积**——上底 2、下底 6，按公式算：

$$
\frac{(\text{上底}+\text{下底})\times\text{高}}{2}=\frac{(2+6)\times 2}{2}=8
$$

所以

$$
X(j\omega)=8\,\mathrm{Sa}(2\omega)\mathrm{Sa}(\omega)
$$

> **易错点**：算梯形面积时，那个"高"是 $2b$（图上 $b=1$ 时就是 2），别顺手当成 1。要是写成 $\frac{(2+6)\times1}{2}=4$，整个结果会整整差一倍——而快速核对的方法是 $X(0)=\int x\cdot\int h = 4\times2 = 8$。

这几道题共同的地方在于：以前大家是"看到信号就慌"，现在变成"看到信号就拆成方波"，而拆完以后的计算是一个固定的套路。有了前面的基础，这些题十秒钟一个。

### 卷积加时移：现场出一道

接着把卷积和前面讲的时移性质结合起来练一道。这道题是**我现场出的**，坐标是 $-4$、$-2$、$4$ 和 $3$、$3$，外加中间那块高度为 1 的东西。

我一步一步做分解动作给你看。

**中间那块**，$x(t)$，看形状就知道它是两个 $[-\frac{1}{2},\frac{1}{2}]$ 的方波卷出来的三角波。频域是 $\mathrm{Sa}(\omega/2)$ 和 $\mathrm{Sa}(\omega/2)$ 相乘——这一步先不算面积——前面那个系数是三角形面积：底 2、高 1，$2\times1\div2=1$，所以就是 $\mathrm{Sa}^2(\omega/2)$。

**右边那块**，把它往右移三个单位，就是 $x(t-3)$，由时移性质直接多乘一个 $e^{-j3\omega}$：

$$
\mathrm{Sa}^2\left(\frac{\omega}{2}\right)e^{-j3\omega}
$$

**左边那块**，左移三个单位，落在 $[-4,-2]$、中心在 $-3$，对应 $x(t+3)$：

$$
\mathrm{Sa}^2\left(\frac{\omega}{2}\right)e^{j3\omega}
$$

最后用线性性质把三项加起来：

```text
   1 ┤    ╱╲        ╱╲        ╱╲
     │   ╱  ╲      ╱  ╲      ╱  ╲
   0 ┼──┴────┴────┴────┴────┴────┴──→ t
       -4   -2   -1    1    2    4
        └──┬──┘     └─┬─┘     └┬─┘
        x(t+3)      x(t)     x(t-3)
```

$$
\begin{aligned}
X(j\omega)
&=\mathrm{Sa}^2\left(\frac{\omega}{2}\right)+\mathrm{Sa}^2\left(\frac{\omega}{2}\right)e^{-j3\omega}+\mathrm{Sa}^2\left(\frac{\omega}{2}\right)e^{j3\omega}\\
&=\mathrm{Sa}^2\left(\frac{\omega}{2}\right)\left[1+e^{-j3\omega}+e^{j3\omega}\right]\\
&=\mathrm{Sa}^2\left(\frac{\omega}{2}\right)\left[1+2\cos 3\omega\right]
\end{aligned}
$$

最后一步只用到一条性质：$e^{-j\theta}+e^{j\theta}=2\cos\theta$。所以频域上就是"一个 $\mathrm{Sa}^2$，再乘上一段余弦"。

这个套路练熟以后，考场上我全都是十秒钟写完。这些题都是我临场出的，我也能临场写出来——需要的不是记更多公式，而是把上面这几步推理练到不用想。

### 最难的一题：把 u(t) 卷进来

继续。这道题如果说能做出来，大家很聪明——**在求卷积这一类题里，除了 $\operatorname{sgn}$ 那个符号函数，就数它最难**。

我先请了一位同学上来做。他的做法是：把信号拆成 $1 + u(t)$ 那一类的东西，然后强行积分——求导的时候用 $j\omega$ 那一套，硬把 $\frac{1}{j\omega}$ 和 $\pi\delta(\omega)$ 顶出来，再把两部分加起来。这条路**当然是对的**，我认可。

还有一位同学的做法更妙：把它拆成无穷多个三角形，从这里一个一个往上加，加出一串 $e^{-j\omega}+e^{-2j\omega}+\cdots$。这个也有意思，做出来结果是对的，但**不是最简单**——这种做法我给 8 到 9 分，道理我都懂，但我知道你大概画不出那个图，所以扣一点。

我公布标准答案。请认真看：**它等于某个东西和 $u(t)$ 卷积**。这一下就简单了。

走的时候靠的就是 $\mathcal{F}\{u(t)\} = \frac{1}{j\omega} + \pi\delta(\omega)$：

$$
X(j\omega)=Z(j\omega)\left[\frac{1}{j\omega}+\pi\delta(\omega)\right]=\frac{Z(j\omega)}{j\omega}+Z(0)\,\pi\delta(\omega)
$$

两点要交代清楚。第一，$Z$ 里装的是 $\mathrm{Sa}(\omega/2)$ 加上一个几何级数因子 $\frac{1}{1-\frac{1}{2}e^{j\omega}}$——**这正是"无穷多个三角形加起来"的那条路**，只是把它收成了一个分式，不用一项一项加了。第二，$\delta(\omega)$ 那一项乘上的是 $Z(0)$ 而不是别的；把 $\omega=0$ 代进去，两处都是 1，所以 $\pi\delta(\omega)$ 这一项原封不动地留了下来。

> **易错点**：$\delta$ 那一项别丢。$\frac{1}{j\omega}$ 看着像就够了，其实少了 $Z(0)\pi\delta(\omega)$。检验方法永远是 $X(0)=\int x(t)\,dt$——代进去对一下，就知道有没有漏。

这道题考试的时候做对的同学很多，因为不少人就是暴力求解上去的——**只要算得对，我不会给你打错分**。把信号拆成无穷多个三角波那样做也可以，上面那段推导就是给它准备的。

到这里我们就把这一讲最重的两条工具——频移、微分、卷积——都用过了。有了卷积这个公式，我们还能做的事，后面再说。

## 时域卷积、频域相乘：系统函数，以及微分器、积分器、延时器
> 对应块：BLK30 | 覆盖分集：P22下 | 块标题（分集名）：《傅里叶变换的性质（线性、时移、频移、微分、卷积）》

### 开头那道题：已知 x 和 y，怎么求 h

下课之前我还在想，还有什么要讲的。想起来了——上节课留的那个编程作业。

题目是这样的：$x(t)$ 卷积 $h(t)$ 得到 $y(t)$，$h(t)$ 是什么我们不知道，$x(t)$ 和 $y(t)$ 都给你了，要求 $h(t)$。上节课末尾我没怎么细推，现在你们应该已经知道它是怎么推出来的了。

推法就一行：

$$
Y(j\omega) = X(j\omega) \cdot H(j\omega) \quad\Longrightarrow\quad H(j\omega) = \frac{Y(j\omega)}{X(j\omega)}
$$

这里就冒出来一个新名字。我们把 $H(j\omega)$ 叫做 **LTI 系统的系统函数**，它也就是**冲击响应 $h(t)$ 的傅里叶变换**。有的书上把时域那一侧的 $h(t)$ 也直接叫"系统函数"——我觉得这两个说法都有道理，都对。

> **提示**：学完第三章的最高境界是什么？是你看 $h(t)$ 和你看 $H(j\omega)$，在你的眼里是同一个东西。不管谁说的是时域、谁说的是频域，你看到的就是同一个东西——那你就学到第三章的最高境界了。

这一讲讲的就是怎么把这些性质真正用起来，而不是把它们背下来。

### 习题课：四道题，和一条练公式的捷径

开练之前先说两句。

第一句是关于速度的：这些题练熟了应该是一分钟一道。但就我的水平，都要超过一分钟。所以你们要是能一分钟一道，那已经很可以了。

第二句是关于方法的。这些题都有那么一点点复杂，不是那么直观，但我觉得都应该在你们的能力范围之内。如果有几位同学能相互出题来做，我觉得这是熟悉第三章公式的一个非常好的办法——这些题里面有一些本来就是考试题，我平时出题也就是这么出出来的。你们互相出题、互相做，比一个人闷头刷题快得多。

我们抽了四道题连着做。

#### 第一题：三角波就是两个方波的卷积

这四道题里相对简单的一道。我先把同学的做法在黑板上还原一遍。

分子上的那个三角波，这是等长的两个方波卷积出来的——**方波卷积方波得三角波**，所以到了频域，就变成两个矩形的频谱相乘，也就是 sinc 的平方：

$$
Y(j\omega) = \operatorname{sinc}^2(\omega) \times (\text{面积})
$$

接着看常数。三角波这里面的面积是 $4 \times 1 = 4$，所以这个常数应该是四；分母那边还带着一个二，要做除法。

我在黑板上核对的就是这个常数：同学的答案在这个地方写成了二，其实是四。剩下的推导他是对的。

> **易错点**：这类题最容易被扣分的地方不是方法，是**常数**。三角波 $\leftrightarrow$ sinc 平方、方波 $\leftrightarrow$ sinc，这些关系式本身只管形状；面积、宽度带来的那一个常数因子，一定要在"识别出形状"之后再单独乘上去。

#### 第二题：一路分解动作

第二位同学说不会。我跟大家说：当你说"不会"的时候，应该仔细地想一想。这一小段时间真的需要大家努力——我说的这两三堂课基本涵盖到周五，这三堂课会占考试 20% 以上的分数。

那我不抽了，我自己带着做一遍。这道题我写起来会非常快，关键在**分解动作**，拆成四步。

第一步，把分子拆成两个能一眼看出时域的东西卷积。其中一个的频域会贡献 sinc 那一族乘上另一个的 sinc 平方，它前面的那个常数就是它的面积，$2 \times 1 = 2$。

第二步，看右移。看这里，二和四这里三——它相当于这个东西又**右移了三个单位**。按移位性质，一个 sinc 平方的东西右移三个单位，频域就乘上 $e^{-j3\omega}$。

第三步，看左移。另一边是**左移三个单位**，得到的频域要乘上 $e^{+j3\omega}$。这一项和上一项相减：$e^{-j3\omega} - e^{+j3\omega}$。

第四步，化简。这里有一个必须记住的恒等式：

$$
e^{j\alpha} - e^{-j\alpha} = 2j\sin\alpha
$$

而我们手上这一项的顺序是反过来的——先负后正。所以：

$$
e^{-j\alpha} - e^{+j\alpha} = -2j\sin\alpha
$$

最后把 $-2j\sin(3\omega)$ 代回去，和前面分母里的东西一约，答案就出来了。

> **提示**：整条链条上真正省时间的只有两步——**移位性质**（时域移 $n$ 个单位 ↔ 频域乘 $e^{\mp j\omega n}$）和**欧拉公式拆项**（$e^{\mp j\alpha}$ 的和差直接换成正负 $\sin\alpha$）。这两步熟了，指数形式的频谱就能一路降成三角函数形式。

#### 第三题：除了一个平方

第三个其实不算很难，除了一个平方。

频域上的答案被他写成两项相乘的样子，两项都是 sinc 那一族，乘起来以后频域相乘就对应**时域卷积**。

所以做法是：把这两项分别反变换回时域。其中一项反变换出来的是一个 $[-3,\ 3]$ 的方波，面积为 $\frac{1}{2}$——这一步就是"反变换里带了个 $\frac{1}{2\pi}$，再算一下积分，别漏掉"。

两个等长方波卷积，得到三角波，支撑区间是 $[-6,\ 6]$。接下来唯一要确定的是顶点值。顶点在两个方波**完全重合**的那一点上：

$$
\text{顶点} = 6 \times \frac{1}{2} = 3
$$

所以第三个的答案是支撑在 $[-6,\ 6]$、峰值 $3$ 的三角波。

#### 第四题：矩形谱、移位因子，和左右对称复制

第四个是目前推起来**最不顺手、也最难**的一道。我先拿一道简单的题热身——这道跟上节课讲的题目是完全一样的。

热身题的做法分三步，每一步都是"看到频域的形状，立刻认出时域"。

第一步，频域是一段矩形，从 $-1$ 到 $1$，高度是 $1$。它的反变换就是那个 sinc 型的函数——写出来就是 $\dfrac{\sin t}{t}$。

第二步，这个矩形右边还挂着一个移位因子 $e^{-j\omega}$。把它和常数 $1$ 相乘，乘出来还是 $e^{-j\omega}$，也就是 $\cos\omega - j\sin\omega$，相当于加了一个负的 $\omega$。

> **概念**：加一个负的 $\omega$ 的相位，就是加了一个**线性相位**。线性相位对应延时线，非线性的相位才对应超前。所以这里 $e^{-j\omega}$ 就是**延时一个单位**；频谱是 $[-1,\ 1]$，所以这"45 度"对应的就是延时一个单位。

时域这边，所有 $t$ 都换成 $t-1$：

$$
x(t) \;\Longrightarrow\; x(t-1) = \frac{\sin(t-1)}{t-1}
$$

第三步，左右对称复制。**同一个东西沿着 $y$ 轴左右对称地复制**，对应的频域操作是**乘上 $2$ 倍的 cos 那一族**。这个性质要是熟了，这道题一笔就能写出来。

我随后又把这个答案用分解动作验了一遍：把那个 $2\cos$ 拆成两个指数，分别对应**右移三个单位**和**左移三个单位**；它们在频域里就是 $e^{-j3\omega}$ 和 $e^{+j3\omega}$，加起来刚好是 $2\cos(3\omega)$ 这一项，和直接写的答案完全一致。

这一步背后的公式就是书上 3.4.3 那条移位性质：

$$
\mathcal{F}\{\,f(t)\, e^{-j\omega_0 t}\,\} = F(j\omega - \omega_0)
$$

所以这一整道题真正考的是三件事：矩形谱看宽度、移位因子看相位（线性相位就是时移）、左右对称复制就是乘 $2\cos$。

### 卷积性质：时域卷积，频域相乘

好，前面是一开始的部分。接下来继续讲上节课的内容：**卷积性质**（书上 3.4.9）。这一块比起上一节课要简单一点，我也希望讲得有趣一点。

公式本身极其简洁：

$$
x(t) * h(t) = y(t) \quad\Longleftrightarrow\quad X(j\omega) \cdot H(j\omega) = Y(j\omega)
$$

> **结论**：时域卷积对应频域相乘。

#### 同一张框图，搬到频域

我们前面说过一个 LTI 系统，时域经常画成这样：

```text
        x(t)                              X(jw)
          |                                 |
          v                                 v
     +----------+                     +----------+
     |  LTI / h |                     |  LTI / H |
     +----------+                     +----------+
          |                                 |
          v                                 v
        y(t)                              Y(jw)

   y(t) = x(t) * h(t)                Y(jw) = X(jw) * H(jw)
```

读图：上面那个框图画的是**时域形式**的 LTI 系统，时域我们习惯说输入卷积这个系统的系统函数（或者叫冲击响应）就得到输出。第二个框图是同一个系统的**频域形式**：把输入输出都做傅里叶变换进去之后，输出的频谱等于输入的频谱乘以这个冲击响应的频谱。

有时候我们图上不写 LTI，只写这么个框——但只要是这么个图，我们就知道它讨论的是线性时不变系统。**卷积性质清楚的时候，你知道这两个框图表达的意思是完全一样的。**

而且从右边那个框图可以直接解出来：

$$
H(j\omega) = \frac{Y(j\omega)}{X(j\omega)}
$$

这就是开头那道题的答案。

> **提示**：卷积性质好用在这儿——三角波我们能非常快地写出它的傅里叶变换，因为三角波就是方波卷积方波；上节课那道相当于 $x(t)*u(t)$ 的题也一样，代进 $u(t)$ 的傅里叶变换就出来了。但卷积性质的核心**不只是做题**——它让你对整个 LTI 系统的性质有一个更深刻的理解。我今天就是用卷积性质来重新考察线性时不变系统的。

#### 用它把那道编程题做完

现在回到开头那道题。我一步一步带大家推，因为上节课末尾我没有过于详细的推导，这么讲能让理解更深刻。

先认形状。$x(t)$ 是一个 $[-1,\ 1]$ 的方波，**右移一个单位**，所以它实际占 $[0,\ 2]$；$y(t)$ 呢，是一个 $[-1,\ 1]$ 的三角波（也就是 $[-1,\ 1]$ 的方波自卷积），也**右移一个单位**，占 $[0,\ 2]$，顶点高度为 $1$。题目就是：已知这两个，求 $h(t)$。

$Y(j\omega) = X(j\omega)H(j\omega)$，所以

$$
H(j\omega) = \frac{Y(j\omega)}{X(j\omega)}
$$

这里我插一句：写到这儿我有点不好意思，因为中间有一些相对繁琐的推导，我现在的写法已经跳过去了。你们回去以后不妨自己认真想一想，每一步之间隐含了什么。

先写 $X(j\omega)$。一个 $[-1,\ 1]$ 的方波，面积是 $2$，右移一个单位乘上 $e^{-j\omega}$：

$$
X(j\omega) = \operatorname{sinc}(\omega) \cdot 2 \cdot e^{-j\omega}
$$

（这里 $\operatorname{sinc}(\omega) = \dfrac{\sin\omega}{\omega}$，把宽度和高度的影响都归到面积里去。）

再写 $Y(j\omega)$。三角波的傅里叶变换是 sinc 的平方，宽度这一层就体现成 $\operatorname{sinc}(\omega/2)$；面积 $2\times 1 = 2$；再右移一个单位乘上 $e^{-j\omega}$：

$$
Y(j\omega) = \operatorname{sinc}^2\!\left(\frac{\omega}{2}\right) \cdot 2 \cdot e^{-j\omega}
$$

> **易错点**：写三角波频谱时漏掉面积那一个常数，是这一类题最常见的失分点。形状（sinc 平方）和大小（面积）是两件事，要分开乘。

相除，两个 $e^{-j\omega}$ 直接消掉：

$$
H(j\omega) = \frac{\operatorname{sinc}^2(\omega/2)}{\operatorname{sinc}(\omega)} = \frac{4\sin^2(\omega/2)}{\omega \sin\omega} = \frac{2\sin(\omega/2)}{\omega\cos(\omega/2)}
$$

现在轮到关键的一步：**怎么反变换回去**。写成积分形式，

$$
h(t) = \frac{1}{2\pi}\int_{-\infty}^{\infty} H(j\omega)\, e^{j\omega t}\, d\omega
$$

别急着算，先看奇偶性。上面这个 $H(j\omega)$ 的分子 $4\sin^2(\omega/2)$ 是**偶函数**；分母里 $\omega$ 是奇函数、$\sin\omega$ 也是奇函数，两个奇函数相乘也是偶函数；偶除偶，整体是**实偶函数**。

> **结论**：一个实偶的 $H(j\omega)$，反变换时把 $e^{j\omega t} = \cos(\omega t) + j\sin(\omega t)$ 拆开——乘上 $\cos(\omega t)$ 的那一项是偶函数，积下来非零；乘上 $j\sin(\omega t)$ 的那一项是奇函数，在整个对称区间上积分**等于零**。所以最后只剩 cos 那一项：

$$
h(t) = \frac{1}{2\pi}\int_{-\infty}^{\infty} H(j\omega)\cos(\omega t)\,d\omega = \frac{1}{\pi}\int_{0}^{\infty} H(j\omega)\cos(\omega t)\,d\omega
$$

这正是我们上一节课讲到的那个公式。

把 $H(j\omega)$ 代进去，做一些化简，你就能画出我做那道编程题时候画的函数了。**这个图大家回去自己试着画**，我不在这儿替你们画了。

把整道题收一下：已知 $x(t)$、已知 $y(t)$，要求 $h(t)$——**把 $y(t)$ 做傅里叶变换，两个傅里叶变换相除，得到 $h(t)$ 的傅里叶变换，然后再做一次傅里叶反变换，直接得到 $h(t)$ 的时域形式。** 这就是时域卷积性质给我们的、处理一个 LTI 系统的新视角。

### 一道判断题：LTI 系统到底有多好刻画

讲完上面这个，我考大家一道判断题，举手表决。

> 对于线性时不变系统，如果我们知道了它的**任何一个不为零的输入**对应的输出，那么我们就知道了这个线性时不变系统**所有输入**对应的输出。这句话对吗？

我看到大部分同学举了手——但你们举得不那么坚决。

答案是：**这句话当然是对的**。但请注意，我已经把它限制得非常死非常死了——我说的是"**任何一个不为零的**输入对应的输出"。

如果不加"不为零"这三个字，这句话仍然是**错的**。而且错得很典型，有一种抬杠的做法：我输入是零，输出肯定是零啊——对于线性时不变系统来说，输入是零，输出一定是零。那这一对零输入零输出告诉了我们什么？什么也没告诉。

**请大家想一想为什么**——根据叠加性质非常容易推出来。

现在给出完整的理由。"不为零的输入"就意味着 $x(t)$ 不为零，也就意味着 $X(j\omega)$ 不为零。于是：

$$
H(j\omega) = \frac{Y(j\omega)}{X(j\omega)}
$$

系统函数就算出来了。做傅里叶反变换，$h(t)$ 也就算出来了。

那么接下来，对于任何一个**别的**输入 $\tilde{x}(t)$，它通过这个 LTI 系统得到的输出是什么？$\tilde{x}(t)$ 卷积这个 $h(t)$——而这个 $h(t)$ 我们已经从"那一对不为零的输入输出"里算出来了。所以新的输入进来，跟这个算出来的 $h(t)$ 一卷积，输出直接就得到了。

> **结论**：LTI 系统是一个非常简单、非常"好刻画"的系统。只要知道了它**任意一对不为零的输入和输出**，我们就已经知道了这个系统所有的性质——因为我们已经知道它对所有输入的输出会是什么样子了。

### 积分性质：不用背，它是顺理成章的

接下来是积分性质，在书上 106 页 3.4.5。

但我要先说一句：**这个你们不需要去记**，它实际上是顺理成章的。

要证的式子是：

$$
\int_{-\infty}^{t} x(\tau)\,d\tau \quad\Longleftrightarrow\quad \frac{X(j\omega)}{j\omega} + \pi x(0)\delta(\omega)
$$

怎么来的？在第二章的补充知识里我讲过：

$$
\int_{-\infty}^{t} x(\tau)\,d\tau = x(t) * u(t)
$$

既然它是这样子，它的傅里叶变换就是 $X(j\omega)$ 乘上 $u(t)$ 的傅里叶变换。而 $u(t)$ 的傅里叶变换背下来很容易：

$$
\mathcal{F}\{u(t)\} = \frac{1}{j\omega} + \pi\delta(\omega)
$$

乘开：

$$
X(j\omega)\left(\frac{1}{j\omega} + \pi\delta(\omega)\right) = \frac{X(j\omega)}{j\omega} + \pi X(j\omega)\delta(\omega)
$$

最后再用一次公式 $X(j\omega)\delta(\omega) = x(0)\delta(\omega)$（因为 $\delta(\omega)$ 只在 $\omega=0$ 处取值，把 $\omega$ 置零即可），得到：

$$
\boxed{\ \int_{-\infty}^{t} x(\tau)\,d\tau \quad\Longleftrightarrow\quad \frac{X(j\omega)}{j\omega} + \pi x(0)\delta(\omega)\ }
$$

这就是书上 107 页最上面那个公式的来历和由来。看到了推导过程，这个式子你根本不需要背。

### 进入 3.5 节：三个必须记住的系统函数

接下来讲的是比较重要的东西——这节课的重点（三）：书上 116 页，3.5.1，**LTI 系统的频域分析**，也就是连续时间 LTI 系统的频域分析。

3.5 节有例 3.5.1 到例 3.5.3 三个例子，我们一个一个来。三个都是超级简单的题——但是请注意，**这三道题虽然简单，我们要通过这三道题建立一些概念**。这三个概念建起来之后，后面的东西就顺了。

#### 微分器

第一道题：求微分器的 $H(j\omega)$。

先把概念说清楚。微分器就是

$$
y(t) = \frac{d x(t)}{dt}
$$

第一章的内容，把输入进行微分。第一章我们也学过，微分器是 LTI（线性时不变）系统，我在那里给大家严格证明过。

接下来这个定义，**你心里面一定要清楚**：一个线性时不变系统的 $h(t)$ 意味着什么？

> **定义**：$h(t)$ 就是把**单位冲激 $\delta(t)$ 输进这个系统**得到的输出。$h(t)$ 叫系统函数，也叫**冲击响应**。

所以微分器的 $h(t)$ 是把 $\delta(t)$ 代进去：

$$
h(t) = \frac{d\,\delta(t)}{dt} = \delta'(t)
$$

知道了 $h(t)$，$H(j\omega)$ 自然就知道了——它是 $h(t)$ 的傅里叶变换。书上 106 页的微分性质就是

$$
\frac{d x(t)}{dt} \quad\Longleftrightarrow\quad j\omega X(j\omega)
$$

而 $\delta(t)$ 的傅里叶变换是 $1$，所以 $\delta'(t)$ 的傅里叶变换就是 $j\omega$。于是：

$$
\boxed{\ H(j\omega) = j\omega\ }
$$

#### 积分器

第二个更简单。积分器是

$$
y(t) = \int_{-\infty}^{t} x(\tau)\,d\tau
$$

这也是第一章就讲过的。求它的 $h(t)$：

$$
h(t) = \int_{-\infty}^{t} \delta(\tau)\,d\tau
$$

这个积分怎么算？只有 $t>0$ 的时候，积分区间才**覆盖 $\delta$ 取值的那一点**，$\delta$ 在那一点的积分等于 $1$；$t<0$ 时积分区间根本没碰到那一点，结果等于 $0$。所以：

$$
h(t) = u(t)
$$

于是积分器的系统函数是 $U$ 的傅里叶变换：

$$
\boxed{\ H(j\omega) = \frac{1}{j\omega} + \pi\delta(\omega)\ }
$$

当然这个结果还有另一种得到方式。我曾经告诉大家，$\int_{-\infty}^{t} x(\tau)\,d\tau = x(t)*u(t)$；那么 $y(t) = x(t)*h(t)$ 就意味着 $u(t)$ 直接等于 $h(t)$——这两者肯定是一样的，因为 LTI 系统里"输入 $\delta(t)$ 得到 $h(t)$"是定义出来的。**不然整个 LTI 系统的理论就已经矛盾了。**

> **结论**：微分器的系统函数是 $j\omega$，积分器的系统函数是 $\dfrac{1}{j\omega}$，一个是微分，一个是积分，正好互为反运算。这两个必须记住。

#### 延时器

第三个叫**延时器**：

$$
y(t) = x(t - t_0)
$$

求 $h(t)$——把 $x$ 换成 $\delta$ 就行了：

$$
h(t) = \delta(t - t_0)
$$

那 $H(j\omega)$ 是什么？

$$
\boxed{\ H(j\omega) = e^{-j\omega t_0}\ }
$$

> **易错点**：这里的 $\omega$ 别丢，也不要写成 $e^{-\omega t_0}$——必须是 $j\omega$。这个式子就是"时移性质"在 $\delta(t)$ 上的特例，$t_0$ 落在指数里而不是外面。

要是你想看我写**分解动作**的样子：$\delta(t-t_0)$ 按移位性质写成 $\delta(t)$ 移位，$\delta(t)$ 的傅里叶变换是 $1$，移位 $t_0$ 乘上 $e^{-j\omega t_0}$，所以结果就是 $1 \cdot e^{-j\omega t_0}$。

当然，如果你的性质已经很熟了，直接写就行：$y(t) = x(t-t_0)$，你直接做傅里叶变换，这边等于 $X(j\omega)$ 乘 $e^{-j\omega t_0}$，直接就能得到 $H(j\omega)$。**这两种方式都是没有矛盾的。**

三个系统放在一起对照，这张表就是这一讲最该带走的东西：

| 系统 | 时域关系 $y(t)=$ | 冲击响应 $h(t)=$ | 系统函数 $H(j\omega)=$ |
| --- | --- | --- | --- |
| 微分器 | $\dfrac{d}{dt}x(t)$ | $\delta'(t)$ | $j\omega$ |
| 积分器 | $\displaystyle\int_{-\infty}^{t} x(\tau)\,d\tau$ | $u(t)$ | $\dfrac{1}{j\omega} + \pi\delta(\omega)$ |
| 延时器 | $x(t-t_0)$ | $\delta(t-t_0)$ | $e^{-j\omega t_0}$ |

读表：左边一列是系统做什么，右边两列是同一件事在时域和频域的两种描述。再强调一遍——你能把这张表左右对起来看，这一讲的内容就真的进了脑子。

#### 编程题（上节课的作业，本讲完整推导）

**题干**：$x(t)$ 是 $[-1,\ 1]$ 的方波右移一个单位（高度为 $1$），$y(t)$ 是 $[-1,\ 1]$ 的三角波（高度为 $1$）右移一个单位，且 $y(t) = x(t) * h(t)$。求 $h(t)$。

**解析**（正文《用它把那道编程题做完》一节有完整推导，这里只列骨架）：

1. 由时域卷积对应频域相乘，得 $H(j\omega) = \dfrac{Y(j\omega)}{X(j\omega)}$——这是开头那道判断题里也用到的核心式子；
2. 形状识别：方波 $\leftrightarrow$ sinc，三角波 $\leftrightarrow$ sinc 平方，移位 $\leftrightarrow$ 乘 $e^{\mp j\omega}$，面积单独乘上去；
3. 奇偶性收尾：$H(j\omega)$ 是实偶函数，反变换时奇的那一项积分为零，只剩 cos 项。

**答案**：

$$
X(j\omega) = 2\operatorname{sinc}(\omega)\,e^{-j\omega},\qquad Y(j\omega) = 2\operatorname{sinc}^2\!\left(\tfrac{\omega}{2}\right)e^{-j\omega}
$$

$$
H(j\omega) = \frac{\operatorname{sinc}^2(\omega/2)}{\operatorname{sinc}(\omega)} = \frac{4\sin^2(\omega/2)}{\omega\sin\omega} = \frac{2\sin(\omega/2)}{\omega\cos(\omega/2)}
$$

$$
h(t) = \frac{1}{\pi}\int_{0}^{\infty} H(j\omega)\cos(\omega t)\,d\omega
$$

时域的具体形状按这句话自己画，画出来就是编程题原本给的那条曲线。

## 盖起来算其他：用傅里叶变换算卷积、解微分方程和电路
> 对应块：BLK31 | 覆盖分集：P23 | 块标题（分集名）：《用傅里叶变换计算信号卷积》

这一讲是 3.5.2——**用傅里叶变换的卷积性质来计算卷积**。我们还是一个一个地来出题。

不过这一讲真正的收获不在某一道题，而在中间冒出来的那个技术：**盖起来算其他**。这是第一次接触它，后面还会用很多次。

### 同一道题，换一条路再走一遍

书上例 3-14：求 $e^{-at}u(t)$ 与 $e^{-bt}u(t)$ 的卷积。为了方便，我让 $a 
eq b$，而且它们都大于零。

这道题第二章我们做过。既然如此，我们就把第二章的做法和第三章的做法各做一遍，看看两条路出来的东西是不是一样。

#### 时域积分：第二章的做法

第二章的做法就是把卷积公式直接摊开：

$$
y(t) = \int_{-\infty}^{+\infty} x(\tau)h(t-\tau)\,d\tau
$$

把 $x$、$h$ 带进去：

$$
y(t) = \int_{-\infty}^{+\infty} e^{-a\tau}u(\tau)\cdot e^{-b(t-\tau)}u(t-\tau)\,d\tau
$$

接下来就是这道题的全部麻烦所在：**这个 $\tau$ 该在哪些范围上有值？**

这里是 $u(\tau)$，它是**阶跃函数**——只在 $\tau > 0$ 时取值 1；这里是 $u(t-\tau)$，它是**只有 $t > \tau$ 时**才有值 1。所以被积函数非零的条件是同时满足两条：

$$
\tau > 0 \quad\text{且}\quad \tau < t
$$

先处理 $t < 0$。请大家想一想为什么这时候 $y(t) = 0$。因为 $t$ 小于 0 的时候，$\tau$ 要有值就必须 $\tau < t$，也就是 $\tau$ 是负的；但 $\tau$ 是负的，$u(\tau)$ 就等于 0 了。这两个东西**必有一个为零**，所以结果一定是零。

> **提示**：阶跃函数在卷积积分里干的事，就是替你**划定积分区间**。看到两个 $u$，先别急着算，先问一句"哪一段 $\tau$ 上它俩同时非零"。

所以只有 $t > 0$ 的时候才要讨论。这时候积分上下限是 $0$ 到 $t$：

$$
y(t) = \int_{0}^{t} e^{-a\tau}e^{-b(t-\tau)}\,d\tau = e^{-bt}\int_{0}^{t} e^{(b-a)\tau}\,d\tau
$$

接下来分两种情况。

第一种，$a = b$。这时 $b - a = 0$，指数项恒为 1：

$$
y(t) = t\,e^{-bt},\qquad t > 0
$$

第二种，$a 
eq b$：

$$
y(t) = e^{-bt}\cdot \frac{1}{b-a}\left[e^{(b-a)t} - e^{(b-a)\cdot 0}\right] = \frac{e^{-bt}}{b-a}\left(e^{(b-a)t} - 1\right)
$$

把 $e^{-bt}$ 乘进来：

$$
y(t) = \frac{1}{b-a}\left(e^{-at} - e^{-bt}\right),\qquad t > 0
$$

到这里，把两种情况和 $t < 0$ 的结论合到一起，$t < 0$ 等于 0 这一条直接乘一个 $u(t)$ 就被包进去了：

$$
\boxed{\ y(t) = \frac{1}{b-a}\left(e^{-at} - e^{-bt}\right)u(t)\ } \quad (a 
eq b)
$$

$$
\boxed{\ y(t) = t\,e^{-at}u(t)\ } \quad (a = b)
$$

（$a = b$ 时写 $te^{-at}u(t)$ 和 $te^{-bt}u(t)$ 是一回事。）

这是第二章的答案。

#### 频域相乘：第三章的做法

请大家仔细看。既然有了**时域卷积等于频域相乘**这条性质，做法就变成一个固定套路。

第一步，把两个信号各自做傅里叶变换。这两下都用的是同一条公式——也就是那七个公式里的**第一个**：

$$
e^{-at}u(t) \ \overset{\mathcal{F}}{\longleftrightarrow}\ \frac{1}{a + j\omega}
$$

所以：

$$
X(j\omega) = \frac{1}{a + j\omega},\qquad H(j\omega) = \frac{1}{b + j\omega}
$$

第二步，频域相乘：

$$
Y(j\omega) = X(j\omega)H(j\omega) = \frac{1}{(a + j\omega)(b + j\omega)}
$$

第三步，分两种情况做反变换。

**$a = b$** 的时候，$Y(j\omega) = \dfrac{1}{(b+j\omega)^2}$。这个式子我们上节课推过，就在书上 111 页例 3-10 那条微分性质里，直接带公式：

$$
y(t) = t\,e^{-bt}u(t)
$$

和第二章完全对上了。

**$a 
eq b$** 的时候，麻烦来了：$\dfrac{1}{(a+j\omega)(b+j\omega)}$ 这个式子，怎么变回时域？它不在那七个基本公式里。是"高中知识"——**待定系数法**，部分分式分解：

$$
\frac{1}{(a + j\omega)(b + j\omega)} = \frac{A}{a + j\omega} + \frac{B}{b + j\omega}
$$

我先公布答案：

$$
A = \frac{1}{b-a},\qquad B = \frac{1}{a-b} = -\frac{1}{b-a}
$$

于是：

$$
Y(j\omega) = \frac{1}{b-a}\left(\frac{1}{a + j\omega} - \frac{1}{b + j\omega}\right)
$$

这一步开始就舒服了——两个分母都是第一条公式的**原样**，直接用反过来：

$$
y(t) = \frac{1}{b-a}\left(e^{-at}u(t) - e^{-bt}u(t)\right)
$$

两个 $u(t)$ 提出来：

$$
y(t) = \frac{1}{b-a}\left(e^{-at} - e^{-bt}\right)u(t)
$$

核对答案，跟第二章那边**一字不差**。

> **结论**：时域卷积对应频域相乘。有了它，卷积的计算不必真的去卷。

那第二章和第三章的办法，到底哪个更快？我要告诉大家的是：**没有一个一定的规则**。有些题第二章快，有些题第三章快。这一道题上，两种方法**一样快**——因为两边要用的东西我们都刚好熟。但对某些特殊的题，第三章会明显更快。

而且第三章这条路的价值不止于算得快：它整条链条上只用到**一条基本公式**，套的是**一个固定的机械流程**。这种题放到考场上，是最不该失手的类型。

### 盖起来算其他

上面那个 $A$ 和 $B$，我是直接看出来的。但我坦白讲：**刚才我并没有完全备课，这两个系数我是直接能看出来的。** 所以接下来这个技术很重要——我要告诉大家**怎么把它算出来**。

这个方法叫"**盖起来算其他**"。第一次接触，后面还会反复用到。

#### 怎么盖，怎么代

要算的式子是：

$$
\frac{1}{(a + j\omega)(b + j\omega)} = \frac{A}{a + j\omega} + \frac{B}{b + j\omega}
$$

我要算的是 $A$。**第一步的口诀是：算什么，盖什么。**

$A$ 的分母是 $a + j\omega$，那我就把它**盖起来**——用红笔盖住。盖起来之后，原式右边就剩下：

$$
\frac{1}{b + j\omega}
$$

**第二步：把盖起来的分母等于 0 的那个 $j\omega$ 带进去。**

盖住的是 $a + j\omega$，令它等于 0：

$$
a + j\omega = 0 \quad\Longrightarrow\quad j\omega = -a
$$

把它代到盖不动的那部分里，直接得到：

$$
A = \left.\frac{1}{b + j\omega}\right|_{j\omega = -a} = \frac{1}{b-a}
$$

就这么一步。**算 $B$ 完全同理**：算什么盖什么，我盖住 $b + j\omega$，令 $b + j\omega = 0$ 得 $j\omega = -b$，代进剩下那部分：

$$
B = \left.\frac{1}{a + j\omega}\right|_{j\omega = -b} = \frac{1}{a-b}
$$

把它写成 $b - a$ 的样子，就是 $-\dfrac{1}{b-a}$。

> **提示**：整个动作就是两句话——**算什么盖什么，把盖掉的那块等于 0 的值代到别的地方去**。之所以能代，是因为盖掉的那块代进去以后**分子分母同为零**，谁也除不掉它。

#### 为什么这样盖是对的

先讲怎么做，现在讲道理。

假设这个等式是成立的。那我们把左边和右边**同时乘以 $a + j\omega$**。左边直接约掉：

$$
\frac{1}{b + j\omega} = A + B\cdot\frac{a + j\omega}{b + j\omega}
$$

大家看出来了吗？在这个式子里把 $j\omega = -a$ 代进去，左边是 $\left.\dfrac{1}{b+j\omega}\right|_{j\omega=-a}$；右边，$A$ 原样留着，第二项的**分子** $a + j\omega$ 在 $j\omega = -a$ 时**直接等于 0**，所以整个第二项是 0。于是：

$$
\left.\frac{1}{b + j\omega}\right|_{j\omega = -a} = A + 0
$$

这就是"盖起来算其他"的道理：**盖掉一个分母，等价于把两边同乘这个分母；让这个分母等于 0 代入，恰恰是让含它的那一项自己消失。** $B$ 同理。

#### 例 3-15：已知 x 和 y，反推 h

这个技术马上就用上。例 3-15，119 页：

$$
x(t) = e^{-2t}u(t),\qquad y(t) = \frac{1}{2}\left(e^{-t} - e^{-3t}\right)u(t)
$$

求 $h(t)$。要不要自己先试着做一下？我给大家两分钟。

我觉得自己做一遍可能感觉会好一点。这道题**用到的傅里叶变换公式只有一个**，就是第一条 $e^{-at}u(t) \leftrightarrow \dfrac{1}{a+j\omega}$——就靠它，这类题目全都能直接做出来。

我带一遍。

第一步，$X(j\omega)$：

$$
X(j\omega) = \frac{1}{2 + j\omega}
$$

第二步，$Y(j\omega)$。把 $\dfrac{1}{2}$ 拿下来，$e^{-t}u(t)$ 用 $a=1$，$e^{-3t}u(t)$ 用 $a=3$：

$$
Y(j\omega) = \frac{1}{2}\left(\frac{1}{1 + j\omega} - \frac{1}{3 + j\omega}\right)
$$

通分：

$$
Y(j\omega) = \frac{1}{2}\cdot\frac{(3+j\omega)-(1+j\omega)}{(1+j\omega)(3+j\omega)} = \frac{1}{2}\cdot\frac{2}{(1+j\omega)(3+j\omega)} = \frac{1}{(1+j\omega)(3+j\omega)}
$$

第三步，由 $Y = X\cdot H$ 求系统函数：

$$
H(j\omega) = \frac{Y(j\omega)}{X(j\omega)} = \frac{\dfrac{1}{(1+j\omega)(3+j\omega)}}{\dfrac{1}{2+j\omega}} = \frac{2+j\omega}{(1+j\omega)(3+j\omega)}
$$

第四步，部分分式：

$$
\frac{2+j\omega}{(1+j\omega)(3+j\omega)} = \frac{A}{1+j\omega} + \frac{B}{3+j\omega}
$$

盖起来算其他。算 $A$：盖住 $1+j\omega$，把 $j\omega = -1$ 带进去，分子 $2-1$，分母 $3-1$：

$$
A = \frac{2-1}{3-1} = \frac{1}{2}
$$

算 $B$ 我还能继续用盖起来算其他。但同学们，**如果知道 $A = \dfrac{1}{2}$，你们能不能观察出 $B$ 等于几？**

我觉得能观察出来，它肯定也等于 $\dfrac{1}{2}$。为什么？请看通分之后那个约束——$\dfrac{1}{2}$ 要乘以分母上这一项的 3，问号那一项要乘以 1，两项之和等于分子 2：

$$
\frac{1}{2}\times 3 + (?) \times 1 = 2
$$

这里等于几？一眼就该是 $\dfrac{1}{2}$。

不过你觉得不保险，就再检查 $j\omega$ 的系数那一项：$\dfrac{1}{2}$ 乘以这里的 $j\omega$ 得到 $\dfrac{1}{2}j\omega$，另外 $\dfrac{1}{2}$ 再乘一个 $j\omega$ 又是 $\dfrac{1}{2}j\omega$，加起来正好一个 $j\omega$，跟分子对上了。**两项都对上了，这就是对的。**

不想观察，就老老实实用盖起来算其他：算 $B$ 就盖住 $3+j\omega$，把 $j\omega = -3$ 带进去，分子 $2-3$，分母 $1-3$：

$$
B = \frac{2-3}{1-3} = \frac{-1}{-2} = \frac{1}{2}
$$

> **提示**：得到一个系数以后，用**两种方法**去求另一个，是做题里非常值得养成的习惯。盖起来算其他算一遍，通分观察一遍，两边对上了，你才能确信分解没有错。这不是多余的步骤——它比不出错值钱。

第五步，$h(t)$ 就非常容易写了，直接用第一条公式反着套：

$$
h(t) = \frac{1}{2}\left(e^{-t} + e^{-3t}\right)u(t)
$$

跟书上答案完全一样。

#### 什么时候不能盖：先除一下

最后我要讲一个**盖起来算其他成立的条件**。这里有一个很重要的条件，请大家注意：

> **结论**：**分子的次数必须小于分母的次数**，才能直接用盖起来算其他。

为什么前面那道题能用？看清楚——分子是 $j\omega$ 的**一次**项，分母是 $j\omega$ 的**二次**项，2 大于 1，所以可以直接盖。

**如果分子次数跟分母次数相等，或者分子次数比分母还大，就不能直接盖。** 好消息是处理方法也很简单：**直接把它除一下就行。**

我们做一道这样的题。若

$$
H(j\omega) = \frac{(j\omega)^2 + j\omega + 1}{(j\omega)^2 + 3j\omega + 2}
$$

求 $h(t)$。

这里分子分母都是二次，**不能直接盖**。有同学会这么干：先把它写成

$$
\frac{(j\omega)^2 + j\omega + 1}{(j\omega + 1)(j\omega + 2)}
$$

然后对 $j\omega+1$ 和 $j\omega+2$ 分别盖起来算其他。**这样做是不对的**，稍微有点不对。

正确做法是**先做一次除**。看分子跟分母只差了一项：

$$
H(j\omega) = \frac{(j\omega)^2 + 3j\omega + 2 - 2j\omega - 1}{(j\omega)^2 + 3j\omega + 2} = 1 - \frac{2j\omega + 1}{(j\omega)^2 + 3j\omega + 2}
$$

除完之后，分子次数就小于分母次数了。

继续做。分母因式分解：

$$
H(j\omega) = 1 - \frac{2j\omega + 1}{(j\omega + 1)(j\omega + 2)}
$$

把它拆成：

$$
H(j\omega) = 1 - \left[\frac{A}{j\omega + 1} + \frac{B}{j\omega + 2}\right]
$$

这里可以用盖起来算其他。$A$：盖住 $j\omega+1$，把 $j\omega = -1$ 带进去，上面 $-2+1 = -1$，底下 $-1+2 = 1$，所以 $A = -1$。

既然 $A = -1$，这里等于几？同学们，这里等于几？**3。** 因为 $-1$ 乘以 $2$ 就是 $-2j\omega$，3 乘以 1 就是 3，合起来 $-2j\omega + 1$，正好匹配。

不信再用盖起来算其他算一遍 $B$：盖住 $j\omega + 2$，把 $j\omega = -2$ 带进去，分子 $-4+1 = -3$，分母 $-2+1 = -1$，$B = 3$。没问题。

所以：

$$
H(j\omega) = 1 - \left[-\frac{1}{j\omega+1} + \frac{3}{j\omega+2}\right]
$$

最后问 $h(t)$ 等于什么？$1$ 的反变换是 $\delta(t)$：

$$
\boxed{\ h(t) = \delta(t) + e^{-t}u(t) - 3e^{-2t}u(t)\ }
$$

如果分子次数跟分母次数一样——就像这道题——请大家自己回去做一遍。如果分子次数比分母次数**还多**，做法也是一样的：**先做除，让分子次数小于分母次数**，然后照常盖起来算其他。

### 四道题，把公式跑顺

上一件事交代完，我们做一组练习。这组题基本上是**考场上原样会出现的形式**。

先说标准。我看一部分同学已经做好了。**如果不能在 10 分钟之内做好的同学，熟练程度需要进一步提升和加强**。这四道题，我自己的时间是 5 分钟左右。

#### 第一题：$e^{-2t}u(t-1)$

已知的是 $e^{-2t}u(t) \leftrightarrow \dfrac{1}{j\omega+2}$，七条公式里的第一条。

要处理的东西带一个**时移**，先把它拆开：

$$
e^{-2t}u(t-1) = e^{-2(t-1)}u(t-1)\cdot e^{-2}
$$

（$e^{-2}$ 跟 $e^{-1}$ 一乘是 $e^{-2}$。）然后套时移性质，频谱要乘上 $e^{-j\omega}$：

$$
\mathcal{F}\{e^{-2t}u(t-1)\} = \frac{1}{j\omega+2}\cdot e^{-(j\omega+2)}
$$

$$
\boxed{\ \frac{1}{j\omega+2}e^{-(j\omega+2)}\ }
$$

公式熟、时移性质熟，一下子就出来了。

> **易错点**：有的同学在考场上看到带 $u(t-1)$ 就想直接去算积分。当然你做对了，我不会有什么意见——但实际上，**大多数考题是不需要大家在考场上再去做积分的**。

#### 第二题：$\dfrac{\sin(3t)\cos(4t)}{\pi t}$

用**积化和差**：

$$
\frac{\sin(3t)\cos(4t)}{\pi t} = \frac{1}{2}\cdot\frac{\sin(7t) - \sin(t)}{\pi t} = \frac{1}{2}\left[\frac{\sin(7t)}{\pi t} - \frac{\sin(t)}{\pi t}\right]
$$

接下来一个一个来。这两个的傅里叶变换用的是**第五条公式**：$\dfrac{\sin(Wt)}{\pi t}$ 对应 $[-W, W]$ 上高度为 1 的矩形。

所以 $\dfrac{\sin(7t)}{\pi t}$ 对应 $[-7, 7]$ 上是 1，再乘外面的 $\dfrac{1}{2}$；$\dfrac{\sin(t)}{\pi t}$ 对应 $[-1, 1]$ 上是 1，再乘 $\dfrac{1}{2}$。

一减，结果自然就出来了：**在 $1$ 到 $7$ 之间是 $\dfrac{1}{2}$，在 $-7$ 到 $-1$ 之间也是 $\dfrac{1}{2}$，中间整段为 0。**

#### 第三题：三个一次项的部分分式

$$
\frac{1}{(j\omega + 1)(j\omega + 2)(j\omega + 3)} = \frac{A}{j\omega + 1} + \frac{B}{j\omega + 2} + \frac{C}{j\omega + 3}
$$

盖起来算其他，算什么盖什么。

**$A$**：盖住 $j\omega+1$，把 $j\omega = -1$ 带到没盖住的地方。分子是 1，分母 $(2-1)(3-1) = 2$，所以 $A = \dfrac{1}{2}$。

**$B$**：盖住 $j\omega+2$，把 $j\omega = -2$ 带进去。分子还是 1，分母 $(-2+1)(-2+3) = -1$，所以 $B = -1$。

**$C$**：可以盖起来算其他，也可以先观察再验算。这里 $C = \dfrac{1}{2}$——为什么一眼能看出来？通分的时候，$\dfrac{1}{2}$ 要乘以两个 $j\omega$，得到 $\dfrac{1}{2}(j\omega)^2$；中间那一项 $-1$ 乘以两个 $j\omega$，得到 $-(j\omega)^2$；再假设这一项是问号，它也乘以两个 $j\omega$。三项的 $(j\omega)^2$ 合起来是 $\left(\tfrac{1}{2} - 1 + ?\right)(j\omega)^2$，而**分子上只有常数 1，根本没有 $(j\omega)^2$ 这一项**，所以这一项必须等于 0：

$$
\frac{1}{2} - 1 + C = 0 \quad\Longrightarrow\quad C = \frac{1}{2}
$$

再用盖起来算其他验一遍：盖住 $j\omega+3$，把 $j\omega = -3$ 带进去，分子是 1，分母 $(-3+1)(-3+2) = (-2)(-1) = 2$，正是 $\dfrac{1}{2}$。跟刚才的观察一模一样，说明分解没有错误。

一旦分解写成这样，$x(t)$ 就不言而喻了：

$$
\boxed{\ x(t) = \left[\frac{1}{2}e^{-t} - e^{-2t} + \frac{1}{2}e^{-3t}\right]u(t)\ }
$$

#### 第四题：矩形谱的反变换

第四题是这里面**最简单的一道，基本上不拐弯**。

$X(j\omega)$ 等于：$[-2\pi, -\pi]$ 上是 1，$[\pi, 2\pi]$ 上也是 1，中间 $[-\pi, \pi]$ 是 0。

把它拆成两个矩形相减：$[-2\pi, 2\pi]$ 上是 1，**减掉** $[-\pi, \pi]$ 上是 1。

反变换就是 $\dfrac{\sin(2\pi t)}{\pi t}$，减掉 $\dfrac{\sin(\pi t)}{\pi t}$：

$$
\boxed{\ x(t) = \frac{\sin(2\pi t) - \sin(\pi t)}{\pi t}\ }
$$

当然你也可以把分母拉通，底下只写一个 $\pi t$，就是我上面写的那样。

### 从微分方程求输出：平方项怎么拆

上一次关于 3.5 节 119 页还留了一个尾巴——例 3-17。它稍微难一点。一个**因果 LTI 系统**，微分方程是这样的，输入 $x(t) = e^{-t}u(t)$，求输出 $y(t)$。

我带着做一遍，中间会有一些新知识点，我在间隙给你们讲。

第一步，**把微分方程做傅里叶变换**。微分一次分出一个 $j\omega$，所以这里出两个 $j\omega$：

$$
y'' + 4y' + 3y = x' + 2x
$$

$$
(j\omega)^2Y(j\omega) + 4j\omega Y(j\omega) + 3Y(j\omega) = j\omega X(j\omega) + 2X(j\omega)
$$

写得更整齐一点：

$$
\left[(j\omega)^2 + 4j\omega + 3\right]Y(j\omega) = (j\omega + 2)X(j\omega)
$$

第二步解出系统函数并因式分解：

$$
Y(j\omega) = \frac{j\omega + 2}{(j\omega)^2 + 4j\omega + 3}X(j\omega) = \frac{j\omega + 2}{(j\omega + 1)(j\omega + 3)}X(j\omega)
$$

到这里没有做错。接下来 $x(t) = e^{-t}u(t)$，$X(j\omega) = \dfrac{1}{j\omega+1}$，两者合并：

$$
Y(j\omega) = \frac{j\omega + 2}{(j\omega + 1)^2(j\omega + 3)}
$$

**发现问题了：出现了一个平方项。** 出现平方项的时候怎么分解，这就是下面要讲的内容。

先检查条件：分子是 $j\omega$ 的**一次**项，分母是**三次**项，满足分子次数小于分母次数，**可以用盖起来算其他**。但由于有一个平方项，我们必须把它拆成**三项**：

$$
\frac{j\omega + 2}{(j\omega + 1)^2(j\omega + 3)} = \frac{A}{j\omega + 1} + \frac{B}{(j\omega + 1)^2} + \frac{C}{j\omega + 3}
$$

这里有三点要注意，我先说清楚：

> **提示**：盖起来算其他对**一次项**和**平方项**都仍然有用（道理你们自己可以去推一下、想一下），唯独对 $j\omega + 1$ 这一项**没有用**。所以做法是：**先用盖起来算其他把好用的两项弄出来，再用观察法把剩下那一项补上。**

**算 $C$**：算它就盖住 $j\omega + 3$，把 $j\omega = -3$ 带进去。分子 $-3+2 = -1$，分母 $(-3+1)^2 = 4$：

$$
C = -\frac{1}{4}
$$

**算 $B$**：盖住 $(j\omega + 1)^2$，把 $j\omega = -1$ 带进去。分子 $2-1 = 1$，分母 $3-1 = 2$：

$$
B = \frac{1}{2}
$$

**算 $A$**：这一项盖起来算其他没用，**用观察法**。书上有一个很繁琐的算法，我喜欢用简单的：**把 $j\omega$ 等于一个特殊的值，带到左右两边去，把这个问号算出来。**

取 $j\omega = 0$。左边是：

$$
\frac{2}{1 \times 3} = \frac{2}{3}
$$

右边是：问号除以 1 就是问号本身；加上 $\dfrac{1}{2} \div 1^2 = \dfrac{1}{2}$；再减去 $\dfrac{1}{4} \div 3 = \dfrac{1}{12}$。所以问号等于：

$$
A = \frac{2}{3} + \frac{1}{12} - \frac{1}{2} = \frac{8 + 1 - 6}{12} = \frac{3}{12} = \frac{1}{4}
$$

**算完怎么验算？** 换**另一个** $j\omega$ 的特殊值带进去，看左右两边相不相等。比如取 $j\omega = 1$：左边分子 $1+2 = 3$，分母 $2^2 \times 4 = 16$，得 $\dfrac{3}{16}$；右边是 $\dfrac{1}{4} \div 2 = \dfrac{1}{8}$，加上 $\dfrac{1}{2} \div 4 = \dfrac{1}{8}$，减去 $\dfrac{1}{4} \div 4 = \dfrac{1}{16}$：

$$
\frac{2}{16} + \frac{2}{16} - \frac{1}{16} = \frac{3}{16}
$$

相等的，验算通过。

> **结论**：我认为**观察法是最简单的方式**——碰到盖起来算其他搞不定的那一项，带一个特殊的值进去把它算出来，再换一个值验算一遍，就完事了。

分解确定之后，就是一步一步写反变换：

$$
Y(j\omega) = \frac{1}{4}\cdot\frac{1}{j\omega+1} + \frac{1}{2}\cdot\frac{1}{(j\omega+1)^2} - \frac{1}{4}\cdot\frac{1}{j\omega+3}
$$

前两项反变换好写，关键在**中间这一项要背公式**：

$$
t\,e^{-at}u(t) \ \overset{\mathcal{F}}{\longleftrightarrow}\ \frac{1}{(a + j\omega)^2}
$$

这条我们在前面两节课之前学过，书上 116 页续表最下面那一行、十四的那一条。于是：

$$
\boxed{\ y(t) = \frac{1}{4}e^{-t}u(t) + \frac{1}{2}t\,e^{-t}u(t) - \frac{1}{4}e^{-3t}u(t)\ }
$$

这里我要多说一句考试上的事：**分母带平方项的试题，我们这儿已经五年没有考过了。** 但我看很多其他学校的考研辅导——考信号与系统的辅导——发现有些学校经常考这里。所以你**大致理解**一下怎么算就行。

但**核心要大家掌握的是：分母全是一次项的时候，怎么用盖起来算其他把它算出来。** 出现二次项的时候，你大致知道有那么回事就可以了。至于这类内容的完整处理方法，第六章讲拉普拉斯变换的时候我们还会再遇到一次——这是第一次提，所以我讲得稍微细一点。

### 用傅里叶变换解电路题

最后看 123 页例 3-18，**用傅里叶变换解电路题**。

这样的题你们在电路分析、电路原理那门课上学过。我不想细致讲，因为它**也不是考试的重点**——至少不是浙江大学这里的重点。但所有电路题我就讲一道，这道相对简单一点。

题目里有电阻 $R$、电容 $C$、还有电感 $L$。把 $v(t)$ 当作输入，$v_c(t)$ 当作输出：

```text
            R
      o---/\/\/\---o
      |           |
  v(t)          v_C(t)
   +   ~  |     +   ~
   -      |     -   ~
      |    C    |
      o----| |---o
            |

   输入：v(t)        输出：v_C(t)（电容两端）
```

读图：输入电压 $v(t)$ 加在整个串联支路上，$R$ 在前、$C$ 在后，输出 $v_c(t)$ 取在电容两端（极性上正下负）。

做法就三步：**先把 R、C、L 的伏安关系都搬到频域，然后搭出 $H(j\omega)$，最后挂上输入。**

**第一步：三个元件的频域伏安关系。**

电阻 $R$ 上的电压和电流是 $u(t) = R\cdot i(t)$，两边做傅里叶变换：

$$
U_R(j\omega) = R\cdot I_R(j\omega)
$$

电容 $C$ 麻烦一些。书上 122 页 3-133 那里，$u(t) = \dfrac{1}{C}\displaystyle\int_{-\infty}^{t} i(\tau)\,d\tau$。我们前面讲过，**从 $-\infty$ 到 $t$ 的积分，对一个信号来说等于它卷积一个 $u(t)$**（这里指电容上的电压，记 $u_C$）。两边做傅里叶变换，卷积变乘：

$$
U_C(j\omega) = \frac{1}{C}I_C(j\omega)\left(\frac{1}{j\omega} + \pi\delta(\omega)\right)
$$

$$
= \frac{1}{j\omega C}I_C(j\omega) + \frac{\pi}{C}I_C(j0)\,\delta(\omega)
$$

这里要用到 $X(\omega)\delta(\omega) = X(0)\delta(\omega)$：**一般分析电路的时候，我们假定 $I_C(j0) = 0$**，那一项就被扔掉了，只剩下：

$$
U_C(j\omega) = \frac{1}{j\omega C}I_C(j\omega)
$$

电感 $L$ 最简单，$u_L(t) = L\dfrac{d\,i_L(t)}{dt}$，两边做傅里叶变换、微分性质：

$$
U_L(j\omega) = j\omega L\,I_L(j\omega)
$$

三个元件并排放一起，其实是一句统一的话：**用傅里叶变换看过去，伏安关系全都成了"电压频谱 = 一个系数 × 电流频谱"。**

| 元件 | 时域伏安关系 | 频域伏安关系 | 系数 |
| --- | --- | --- | --- |
| 电阻 $R$ | $u_R(t) = R\,i_R(t)$ | $U_R(j\omega) = R\,I_R(j\omega)$ | $R$ |
| 电容 $C$ | $u_C(t) = \dfrac{1}{C}\displaystyle\int_{-\infty}^{t} i_C(\tau)\,d\tau$ | $U_C(j\omega) = \dfrac{1}{j\omega C}I_C(j\omega)$ | $\dfrac{1}{j\omega C}$ |
| 电感 $L$ | $u_L(t) = L\dfrac{d i_L(t)}{dt}$ | $U_L(j\omega) = j\omega L\,I_L(j\omega)$ | $j\omega L$ |

读表：时域那一列是电路分析课上的原始写法，频域那一列是它的傅里叶变换版本。R、C、L 三个系数**只差一个 $j\omega$ 的幂次**，因为它们分别对应微分、积分、无记忆三种关系。

**第二步：求系统函数。**

对电容这个网络，输入输出之比：

$$
H(j\omega) = \frac{V_C(j\omega)}{V(j\omega)} = \frac{\dfrac{1}{j\omega C}}{R + \dfrac{1}{j\omega C}}
$$

化简一步：

$$
H(j\omega) = \frac{1}{j\omega RC + 1}
$$

123 页例 3-18 给的条件是 $\dfrac{1}{RC} = 2$，带进去：

$$
H(j\omega) = \frac{1}{j\omega\cdot\frac{1}{2} + 1} = \boxed{\ \frac{2}{j\omega + 2}\ }
$$

**第三步：挂上输入。**

输入 $x(t) = u(t)$，求 $v_c(t)$。$u(t)$ 的傅里叶变换背公式：

$$
V(j\omega) = \frac{1}{j\omega} + \pi\delta(\omega)
$$

输出频谱：

$$
V_C(j\omega) = \frac{2}{j\omega(j\omega+2)} + \frac{2\pi\delta(\omega)}{j\omega+2}
$$

**看第一项**，部分分式：

$$
\frac{2}{j\omega(j\omega+2)} = \frac{A}{j\omega} + \frac{B}{j\omega+2}
$$

盖起来算其他。算 $A$：盖住 $j\omega$，把 $j\omega = 0$ 带进去，上面是 2，下面也是 2，$A = 1$。

既然 $A = 1$，这里等于几？一眼就能看出来是 $-1$：$1 \times 2 - 1 \times 0$ 的常数项是 2，跟分子匹配；$1$ 倍 $j\omega$ 减掉 $1$ 倍 $j\omega$，$j\omega$ 那一项刚好消掉。**两项都检查过，你甚至不用再在这里盖一次。**

**看第二项**，它带的是 $\delta(\omega)$，用 $X(\omega)\delta(\omega) = X(0)\delta(\omega)$：

$$
\frac{2\pi\delta(\omega)}{j\omega+2} = \frac{2\pi\delta(\omega)}{0+2} = \pi\delta(\omega)
$$

**第四步：反变换。** 现在频谱长这样：

$$
V_C(j\omega) = \frac{1}{j\omega} - \frac{1}{j\omega+2} + \pi\delta(\omega)
$$

三项各自背公式：$\dfrac{1}{j\omega} + \pi\delta(\omega)$ 的反变换是 $u(t)$，$\dfrac{1}{j\omega+2}$ 的反变换是 $e^{-2t}u(t)$：

$$
\boxed{\ v_C(t) = \left(1 - e^{-2t}\right)u(t)\ }
$$

跟书上答案完全一样（书上 124 页）。

> **提示**：电路题看着吓人，其实**整条路只有三步**——写元件的频域伏安关系、串并联算 $H(j\omega)$、挂输入做乘法。它考查的其实是信号与系统，不是电路。前提是你在电路分析课上那三条伏安关系还记得；忘了就翻书，那三条是第一章就有的东西。

### 本讲提到的题目

#### 例 3-14：两个单边指数信号的卷积

**题干**：求 $x(t) = e^{-at}u(t)$ 与 $h(t) = e^{-bt}u(t)$ 的卷积，其中 $a 
eq b$ 且 $a > 0, b > 0$。

**解析**：正文的《时域积分：第二章的做法》与《频域相乘：第三章的做法》两节给出了完整推导。两条路都要走，关键是第二章路里由两个 $u$ 定出积分区间 $[0, t]$，第三章路里用待定系数法拆出 $A$、$B$。

**答案**：

$$
y(t) = \frac{1}{b-a}\left(e^{-at} - e^{-bt}\right)u(t)\quad (a 
eq b),\qquad y(t) = t\,e^{-at}u(t)\quad (a = b)
$$

#### 例 3-15：已知输入和输出，反推系统

**题干**：$x(t) = e^{-2t}u(t)$，$y(t) = \dfrac{1}{2}\left(e^{-t} - e^{-3t}\right)u(t)$，求 $h(t)$。

**解析**：正文《例 3-15：已知 x 和 y，反推 h》一节完整给出。步骤为：由 $H = Y/X$ 求系统函数 $\dfrac{2+j\omega}{(1+j\omega)(3+j\omega)}$；盖起来算其他或通分观察求系数，两法互验。

**答案**：

$$
h(t) = \frac{1}{2}\left(e^{-t} + e^{-3t}\right)u(t)
$$

#### 例 3-17：因果 LTI 系统由微分方程定输出

**题干**：因果 LTI 系统的输入输出微分方程为 $y'' + 4y' + 3y = x' + 2x$，输入 $x(t) = e^{-t}u(t)$，求 $y(t)$。

**解析**：正文《从微分方程求输出：平方项怎么拆》一节完整给出。要点：微分方程整体做傅里叶变换得到系统函数，代入 $X$ 后分母出现 $(j\omega+1)^2$；平方项须拆三项，一次项与平方项用盖起来算其他，$A$ 用观察法（取 $j\omega=0$ 求出，再取 $j\omega=1$ 验算）；最后靠 $t e^{-at}u(t) \leftrightarrow \dfrac{1}{(a+j\omega)^2}$ 还原。

**答案**：

$$
y(t) = \frac{1}{4}e^{-t}u(t) + \frac{1}{2}t\,e^{-t}u(t) - \frac{1}{4}e^{-3t}u(t)
$$

#### 例 3-18：用傅里叶变换解 RC 电路

**题干**：串联 RC 电路，电阻 $R$、电容 $C$，输入电压 $v(t)$，输出取电容两端电压 $v_c(t)$。已知 $\dfrac{1}{RC} = 2$，输入 $x(t) = u(t)$，求 $v_c(t)$。

**解析**：正文《用傅里叶变换解电路题》一节完整给出。要点：电容伏安关系中 $\dfrac{\pi}{C}I_C(j0)\delta(\omega)$ 一项在分析电路时按 $I_C(j0)=0$ 舍去；再由 $H = \dfrac{1/(j\omega C)}{R + 1/(j\omega C)}$ 化简；最后 $V_C(j\omega)$ 两项分别处理，第二项靠 $X(\omega)\delta(\omega)=X(0)\delta(\omega)$。

**答案**：

$$
H(j\omega) = \frac{2}{j\omega+2},\qquad v_c(t) = \left(1 - e^{-2t}\right)u(t)
$$

#### 课上连做的四道练习

这四道题当场就出在黑板上，题面如下，答案均在正文对应小节中给出完整推导。

1. **求 $e^{-2t}u(t-1)$ 的傅里叶变换。** 拆成 $e^{-2(t-1)}u(t-1)\cdot e^{-2}$，用第一条公式加时移性质。结果：$\dfrac{1}{j\omega+2}e^{-(j\omega+2)}$。
2. **求 $\dfrac{\sin(3t)\cos(4t)}{\pi t}$ 的傅里叶变换。** 积化和差拆成两个 $\dfrac{\sin(Wt)}{\pi t}$，用第五条公式。结果：$[\,1, 7\,]$ 与 $[-7, -1\,]$ 上高度为 $\dfrac{1}{2}$ 的带通矩形。

## 调制性质：时域相乘，频域卷积
> 对应块：BLK32 | 覆盖分集：P24 | 块标题（分集名）：《傅里叶变换的调制性质》

### 它跟卷积性质刚好是一对

先把卷积性质翻出来，我们对着看一遍。

$$x(t)*h(t)\ \longleftrightarrow\ X(j\omega)H(j\omega)$$

时域里卷一下，频域里乘一下——就这么一句话。现在把时域和频域对调一下，把"卷积"和"相乘"也对调一下，会得到什么呢？会得到今天这条性质：

设 $x_1(t)$ 的傅里叶变换是 $X_1(j\omega)$，$x_2(t)$ 的傅里叶变换是 $X_2(j\omega)$，那么

$$x_1(t)x_2(t)\ \longleftrightarrow\ \frac{1}{2\pi}\left[X_1(j\omega)*X_2(j\omega)\right]$$

**时域相乘，等于频域卷积，还要再除以 $2\pi$。**

对照一下这两条，你会发现它们刚好是一对镜像。

```text
                        时域                        频域
                 ┌──────────────────┐      ┌──────────────────┐
   卷积性质      │   x(t) * h(t)    │  ⇄   │  X(jω) · H(jω)   │   无 2π
                 └──────────────────┘      └──────────────────┘

   调制性质      │   x₁(t) · x₂(t)  │  ⇄   │ [X₁(jω) * X₂(jω)] │
                 └──────────────────┘      └────────────────┬─┘
                                                             │
                                                  额外 ÷ 2π  ─┘
```

读图：上面一行是时域卷积、频域相乘，下面一行是时域相乘、频域卷积——左右两个格子左右互换，就是彼此。唯一的差别是下面那行右边多挂了一个 $2\pi$ 的除号。

> **易错点**：卷积性质那边**没有** $2\pi$，调制性质这边**有** $2\pi$。这个 $2\pi$ 千万别顺手抄掉，也千万别忘掉。

有的同学会问，凭什么不对称。其实很自然：卷积定义里自带一个 $1/(2\pi)$，而反变换的核里也自带一个 $1/(2\pi)$，两边一凑就冒出 $2\pi$ 来。后面证明的时候你会亲眼看到它是从哪儿冒出来的。

> **结论**：这两条性质不是两个互不相干的公式，而是同一件事的两面。凡是"时域做一件事，频域做它的对偶"，你都要在心里先问一句：这个对偶要不要补一个 $2\pi$。

---

### 拿定义把证明走一遍

接下来我们试着证明一下这个性质。

设

$$Y(j\omega)=\frac{1}{2\pi}\left[X_1(j\omega)*X_2(j\omega)\right]=\frac{1}{2\pi}\int_{-\infty}^{+\infty}X_1(j\tau)X_2(j(\omega-\tau))\,d\tau$$

要证明的是：$Y(j\omega)$ 的反变换刚好等于 $x_1(t)x_2(t)$。

第一步，直接照抄反变换公式：

$$
y(t)=\frac{1}{2\pi}\int_{-\infty}^{+\infty}Y(j\omega)e^{j\omega t}\,d\omega
$$

第二步，把刚才那一长串 $Y(j\omega)$ 塞回积分号里面：

$$
y(t)=\frac{1}{2\pi}\int_{-\infty}^{+\infty}\left[\frac{1}{2\pi}\int_{-\infty}^{+\infty}X_1(j\tau)X_2(j(\omega-\tau))\,d\tau\right]e^{j\omega t}\,d\omega
$$

到这里为止都是机械活。真正干活的是下一步。

#### 最核心的那一步技巧

**核心技巧就一句话：把指数拆开。**

$$e^{j\omega t}=e^{j\tau t}\cdot e^{j(\omega-\tau)t}$$

因为 $\tau+(\omega-\tau)=\omega$，指数一拆，两个因子就分别"认得"卷积里的两项了。

我们一项一项核对。代入之后，把 $e^{j\tau t}$ 和 $e^{j(\omega-\tau)t}$ 分别拉到对应的因子前面，内层对 $\omega$ 的积分就被凑成了标准形状：

$$
\begin{aligned}
y(t)
&=\frac{1}{(2\pi)^2}\int_{-\infty}^{+\infty}X_1(j\tau)e^{j\tau t}
   \left[\int_{-\infty}^{+\infty}X_2(j(\omega-\tau))e^{j(\omega-\tau)t}\,d(\omega-\tau)\right]d\tau\\[4pt]
&=\frac{1}{(2\pi)^2}
  \left[\int_{-\infty}^{+\infty}X_1(j\tau)e^{j\tau t}\,d\tau\right]
  \left[\int_{-\infty}^{+\infty}X_2(j\omega')e^{j\omega't}\,d\omega'\right]\\[4pt]
&=\frac{1}{(2\pi)^2}\cdot(2\pi x_1(t))\cdot(2\pi x_2(t)}\\[4pt]
&=x_1(t)x_2(t)
\end{aligned}
$$

你把这一段拆开看就明白了：

- 两个 $1/(2\pi)$ 一起被拿到了前面，最后变成 $1/(2\pi)^2$；
- $X_1(j\tau)e^{j\tau t}$ 被拿到了第一个括号里——**这就是 $x_1(t)$ 的反变换**，按定义直接认出来；
- $X_2(j(\omega-\tau))$ 被拿到了第二个括号里。虽然你表面上看着是对 $\omega-\tau$ 做的积分，但把 $\omega-\tau$ 整个当成一个新的 $\omega$ 来看待，它同样是标准的反变换积分，结果就是 $x_2(t)$；
- 剩下的 $d\tau\,d\omega$ 也各自跟着进了对应的括号。

三个因子归位，剩下 $2\pi\cdot 2\pi$ 正好把 $(2\pi)^2$ 抵掉，证明结束。

> **提示**：这里的卷积公式和时域卷积公式长得一模一样，唯一区别就是**积分变量跑到了频率上去**。记住"带积分号的那个自变量在频域，指数上的那个也在频域"，就不会混。

#### 想更严格一点：用雅可比行列式

上面那一步有个"稍微有一点点不严格"的地方：我这里写的是对 $\omega-\tau$ 积分，指数上写的是 $e^{j\omega t}$，然后我直接把 $\omega-\tau$ 换了个名字当 $\omega$ 用。这个换元本身是对的，但严格写起来应该把换元的行列式摆出来。

怎么摆？设

$$\tau'=\tau,\qquad \omega'=\omega-\tau$$

即 $\tau=\tau'$，$\omega=\tau'+\omega'$。换元的雅可比行列式是

$$
\frac{\partial(\tau',\omega')}{\partial(\tau,\omega)}
=\begin{vmatrix}
\dfrac{\partial\tau'}{\partial\tau} & \dfrac{\partial\tau'}{\partial\omega}\\[6pt]
\dfrac{\partial\omega'}{\partial\tau} & \dfrac{\partial\omega'}{\partial\omega}
\end{vmatrix}
=\begin{vmatrix}1 & 0\\ -1 & 1\end{vmatrix}
=1
$$

行列式等于 $1$，所以 $d\tau\,d\omega=d\tau'\,d\omega'$，一比一，不多不少。

再看指数：$\omega=\tau'+\omega'$，于是

$$e^{j\omega t}=e^{j\tau't}e^{j\omega't}$$

指数也在这次换元下自动劈成了两半。这时候那个双重积分就严格地劈成了两个单积分的乘积：

$$
\begin{aligned}
y(t)
&=\frac{1}{(2\pi)^2}\int\!\!\int X_1(j\tau')X_2(j\omega')e^{j\tau't}e^{j\omega't}\,d\omega'\,d\tau'\\[4pt]
&=\frac{1}{(2\pi)^2}
  \left[\int_{-\infty}^{+\infty}X_1(j\tau')e^{j\tau't}\,d\tau'\right]
  \left[\int_{-\infty}^{+\infty}X_2(j\omega')e^{j\omega't}\,d\omega'\right]\\[4pt]
&=\frac{1}{(2\pi)^2}(2\pi x_1(t))(2\pi x_2(t))=x_1(t)x_2(t)
\end{aligned}
$$

一眼就能看出来：这里就是 $x_1(t)$，那里就是 $x_2(t)$。

> **易错点**：这里有三个 $\omega$ 在同时活动——$\omega$、$\omega-\tau$、$\omega'$。它们看着像，其实在不同的积分里扮演不同角色。写推导的时候老老实实做一次换元、把行列式算出来，比"我看它们长得一样就并了"要稳得多。考试时这么写不扣分，写混了反而要扣分。

### 例题：sin 2t 除以 t 的平方

调制性质这块，题目会变得非常多。我们就从这道开始：$\left(\dfrac{\sin 2t}{t}\right)^2$ 的傅里叶变换等于多少？大家先自己动笔做一下，然后我们对答案。

每一步你都要大致知道它的原因在哪。

第一步，看结构。$\left(\dfrac{\sin 2t}{t}\right)^2=\dfrac{\sin 2t}{t}\cdot\dfrac{\sin 2t}{t}$，正好是"两个时域信号相乘"，调制性质直接搬上来。取

$$x_1(t)=x_2(t)=\frac{\sin 2t}{t}$$

第二步，两个 $X$ 直接查表。$\dfrac{\sin 2t}{t}$ 命中的是第三个公式——

$$\frac{\sin \omega_c t}{\pi t}\ \longleftrightarrow\ \operatorname{rect}\!\left(\frac{\omega}{2\omega_c}\right)$$

取 $\omega_c=2$：$\dfrac{\sin 2t}{\pi t}\leftrightarrow \operatorname{rect}\!\left(\dfrac{\omega}{4}\right)$，所以

$$X_1(j\omega)=X_2(j\omega)=\pi\,\operatorname{rect}\!\left(\frac{\omega}{4}\right)$$

也就是两个高为 $\pi$、底宽为 $4$ 的方波。

第三步，代进调制性质：

$$X(j\omega)=\frac{1}{2\pi}\left[\pi\operatorname{rect}\!\left(\frac{\omega}{4}\right)*\pi\operatorname{rect}\!\left(\frac{\omega}{4}\right)\right]$$

这里有两笔账可以提前化简，能省很多笔墨：一是 $1/(2\pi)$ 和外面的 $\pi$ 约掉，留 $\pi/2$；二是外面整体的 $\pi$ 和分母的 $2\pi$ 约掉，留 $1/2$。合起来就是

$$X(j\omega)=\frac{\pi}{2}\left[\operatorname{rect}\!\left(\frac{\omega}{4}\right)*\operatorname{rect}\!\left(\frac{\omega}{4}\right)\right]$$

第四步，剩下的活就是算两个方波的卷积。两个等宽方波卷出来是三角波，底宽是原来底宽的两倍，也就是从 $-4$ 到 $4$，顶点在 $\omega=0$。顶点的高度怎么算？看它整个面积就行：**底下的长度 $4$，乘以这一个高度 $\pi$**，得到 $4\pi$；再乘以另一个方波的高度 $\pi$，三角波的顶点高度就是 $4\pi^2$。

最后回到化简后的式子，$\dfrac{\pi}{2}\times 4=2\pi$。

$$\left(\frac{\sin 2t}{t}\right)^2\ \longleftrightarrow\ 2\pi\,\Lambda\!\left(\frac{\omega}{4}\right)$$

> **结论**：答案是 $2\pi$。一个以 $\omega=0$ 为顶点、高 $2\pi$、底边铺在 $[-4,4]$ 上的三角波。

> **提示**：这类题最省事的写法，就是**一开始就把 $1/(2\pi)$ 和 $\pi$ 一起化简掉**。别一路留着 $2\pi$ 留着 $\pi$ 走到最后再约，越拖越容易乱。

### 顺手一问：那个从负无穷到正无穷的积分

这类题里偶尔还会碰到比上面这道更狠一点的。比如问你：

$$\int_{-\infty}^{+\infty}\frac{\sin t}{t}\,dt = ?$$

大家能马上给出答案吗？

马上就能，因为它考的就是刚才那个公式：$\int_{-\infty}^{+\infty}x(t)\,dt=X(j0)$——**全频域在零频处的取值，就是时域信号的直流分量（积分）**。

$x(t)=\dfrac{\sin t}{t}$ 命中同一个第三个公式，取 $\omega_c=1$：

$$\frac{\sin t}{\pi t}\ \longleftrightarrow\ \operatorname{rect}\!\left(\frac{\omega}{2}\right)
\quad\Longrightarrow\quad
X(j\omega)=\pi\,\operatorname{rect}\!\left(\frac{\omega}{2}\right)$$

所以 $X(j0)=\pi$，答案就是

$$\int_{-\infty}^{+\infty}\frac{\sin t}{t}\,dt=\pi$$

顺手把它的姊妹公式也记下来：**频域的总面积等于 $2\pi$ 乘以时域在零点的取值**，

$$\int_{-\infty}^{+\infty}X(j\omega)\,d\omega=2\pi\,x(0)$$

代到刚才这个例子上，$x(0)=1$，于是 $\int_{-\infty}^{+\infty}X(j\omega)\,d\omega=2\pi$。这一条在做面积题、算直流分量的时候特别好用。

> **提示**：这两条公式其实就是 $X(j0)$ 和 $x(0)$ 这两个"零频/零点"的换算关系，跟时移性质、卷积性质是一家的东西，能推着你就不用死记。

### 更狠一道：给你频域，反求时域

调制性质真正的威力，在这类"反着给"的题里才彻底露出来。

现在我给你一张频域图，问你：**什么东西的傅里叶变换等于它？**

图上是两块一模一样的三角形：一块底边压在 $-4$ 到 $-2$ 之间，一块压在 $2$ 到 $4$ 之间，顶点高度都是 $1$，顶点分别落在 $\omega=-3$ 和 $\omega=3$。

```text
       X(jω)
       1                       /\          /\
                             /  \        /  \
                           /    \      /    \
       0       ---------------/----\----/----\---------------> ω
                            -4 -3 -2  2 3  4
```

读图：左边那块三角形的底边正好落在 $-4$ 与 $-2$ 之间、顶点对准 $-3$；右边那块对称地落在 $2$ 与 $4$ 之间、顶点对准 $3$；两块的峰高都是 $1$。

来做。

**第一步，分解动作。** 这两块是左右对称的两片，先只处理中间那片（底宽 $2$、峰高 $1$、顶点在 $0$），做完再用时移性质把它搬到两边去。

怎么把中间这片写出来？它正好是一个卷积：两个高为 $1$、底宽为 $2$ 的方波卷起来，峰高是 $2\cdot 1=2$、底宽是 $4$；再整体乘 $\dfrac12$，就压回峰高 $1$、底宽 $2$。所以

$$X_0(j\omega)=\frac{1}{2}\left[\operatorname{rect}(\omega)*\operatorname{rect}(\omega)\right]$$

**第二步，返回去。** 用表里那一对：$\operatorname{rect}(\omega)\leftrightarrow\dfrac{\sin(t/2)}{\pi(t/2)}$。乘积对应相乘，得到

$$
x_0(t)=\frac{1}{2}\left[\frac{\sin(t/2)}{\pi(t/2)}\right]^2
=\frac{2\sin^2(t/2)}{\pi^2 t^2}
$$

一个 $2\pi$ 从 $\left[\frac{\sin(t/2)}{\pi(t/2)}\right]^2$ 的分母里化出来，两个 $\sin(t/2)$ 一个不少，就得到这个结果。我们把这个结论先写在这儿：

$$x_0(t)=\frac{2\sin^2(t/2)}{\pi^2 t^2}$$

**第三步，用时移性质搬位置。** 时域乘一个 $e^{\mp j3t}$，频域整块平移三格：

- $x_0(t)e^{-j3t}$ 的频域往左搬三格，落在 $-4$ 到 $-2$，顶点在 $-3$；
- $x_0(t)e^{j3t}$ 的频域往右搬三格，落在 $2$ 到 $4$，顶点在 $3$。

两块加起来就是原图：

$$x(t)=x_0(t)e^{-j3t}+x_0(t)e^{j3t}$$

**第四步，合并。** $e^{j3t}+e^{-j3t}=2\cos 3t$，所以

$$
\boxed{\;x(t)=\frac{2\sin^2(t/2)}{\pi^2 t^2}\cdot 2\cos 3t\;}
$$

> **提示**：最后这一步要是做得熟，你根本不用先写两个指数项再合并——直接看到"两块关于原点对称"，脑子里立刻跳出 $2\cos(3t)$，把 $\frac{2\sin^2(t/2)}{\pi^2 t^2}$ 乘上去就完事了。到这个地步，性质就已经变成条件反射了。

这道题之所以比前面那道难，难在**顺序**：先要用卷积把频域拆开、用调制定理把频域相乘，再用时移性质整体搬家，最后用欧拉公式收口。四种性质串在一起用，这才是调制性质该有的考法。

到这里你会发现，用调制性质出题的手段会变得非常丰富：正着给时域求频域、反着给频域求时域、给你一个式子问它是谁的变换、再混合着给你时移和对称性——全都是这一条性质加上它的兄弟们。

## 信号的调制与解调
> 对应块：BLK33 | 覆盖分集：P25上

### 先从两个生活里的问题说起

打开收音机，里面报出一串数字：**"调频 91.5 兆赫"**。这个数是什么意思？它是整首歌的频率，还是电台自己的频率？

还有一个更切身的问题：手机通话的时候，整个城市上空就那么一小块无线信道，成千上万的人同时在打电话，信号满天飞。可你接起来电话，耳朵里干干净净，只有对面那一个人的声音。别人在打电话，你一个字也听不见。这两件事凭什么能同时成立？

这两件事的核心，是同一套东西——现代通信系统里的**调制与解调**。而它们用到的数学工具，正是我们刚刚才学完的**调制性质**。

> **定义**：调制（modulation）的反面叫解调（demodulation）。要说 modulation 这个词的意思，我觉得它翻译成"调制"其实不够贴切，倒更像"规范化"——把一个信号按某种规则重新整制一遍，变成另一个可以传的东西。

---

### 带限信号：先把话说清楚

要调制，先得知道我们打算搬的是个什么东西。

假设有一个信号 $x(t)$，它的傅里叶变换 $X(j\omega)$ 恰好只在 $[-\omega_0, +\omega_0]$ 这一段里有值，出了这段就全是 0。**这样的信号叫带限信号**——它的频带只被限制在一个有限的范围之内，其余频率上一片空白。

这个概念你其实每天都在听。打电话的时候你有没有觉得，电话里对方的声音跟自己当面说话不太一样？闷闷的、有点糊？原因就在这里：

$$f \in [-4000,\ +4000]\ \text{Hz} \quad\Longleftrightarrow\quad \omega_0 = 2\pi\times 4000$$

**这是电话系统在上世纪 70 年代就定死的规定**，沿用到今天。四十多年过去了，5G 的带宽早就能支持远比这清楚得多的信号，可这 4000 Hz 就是没动——纯粹是历史包袱。

顺便说个冷知识：高保真音响、高保真唱片的频带定在 $\omega_0 = 22150$ Hz。有些资料上写 **44100**，那也是对的——因为一个声音有左右两个声道，算上双声道就把频带宽度扩大了一倍。两个数说的是同一件事。

#### 怎么把一个带限信号"变"成带限信号

现在有个问题：**如果 $x(t)$ 原本不是带限信号、频谱撒得满世界都是，我们怎么把它弄成带限的？**

做法简单得让人意外：频域里直接乘一个 $H(j\omega)$。

$$X(j\omega)\ \longrightarrow\ X(j\omega)H(j\omega)$$

只要让 $H(j\omega)$ 在 $[-\omega_0, \omega_0]$ 之内等于 1、在外面等于 0，那么 $X(j\omega)H(j\omega)$ 就被老老实实地砍成了带限信号——超出截止频率的那两大片，全部被压成了 0。

**这个 $H(j\omega)$ 有一个专门的名字：低通滤波器（low pass filter）**，那个 $\omega_0$ 叫做**截止频率**。

时域里它长什么样？我们回忆一下频域相乘等于时域卷积这条性质——

$$x(t)*h(t) \longleftrightarrow X(j\omega)H(j\omega) \quad\Longrightarrow\quad h(t) = \frac{\sin(\omega_0 t)}{\pi t}$$

所以理想低通滤波器在时域的冲激响应，就是那个大名鼎鼎的 $\dfrac{\sin(\omega_0 t)}{\pi t}$。**你可以用截止频率任意地裁剪信号的频带宽度**——想要多宽就有多宽，这是一把尺子。

### 调制：把信号搬上载波

现在进入正题。假设我们有一个通信系统要传输信号 $x(t)$。

**第一步，调制。**我们不直接传 $x(t)$，而是传

$$y(t) = x(t)\cos(\omega_c t)$$

这个做法叫**双边带正弦载波幅度调制**——双边带，是因为搬完以后频谱在载波上下两侧各出现一份；正弦载波，是因为搬它用的载波是 $\cos$；幅度调制，是因为信息藏在载波的**幅度**变化里。

这里的 $\omega_c$ 叫做**载波角频率**，$\omega_c$ 对应的载波就叫**载波**（carrier wave / carrier signal）。

> **提示**：收音机里报的"调频 91.5 兆赫"，说的就是这个 $\omega_c$。因为频率与角频率的关系是
> $$f_c = \frac{\omega_c}{2\pi} = 91.5\ \text{MHz}$$
> **它报的是载波的频率，不是电台里那首曲子的频率。**你想：一个电台的音乐音频只占几 kHz，怎么可能塞进 91.5 MHz 这个数字里？那个数字说的是"我们这一整台发射机架在 91.5 MHz 上"。每一个频道——电视频道、收音频道、手机里的每一个人——都要把自己的信号乘上一个属于自己的载波。

#### 第一道题：画出 $Y(j\omega)$

现在来算这道题。已知 $x(t)$ 是带限的，$X(j\omega)$ 在 $[-\omega_0, \omega_0]$ 上高度为 1，求

$$y(t) = x(t)\cos(\omega_c t) \quad\Longrightarrow\quad Y(j\omega) = ?$$

有两种画法，我都想给你看，因为它们的用处不一样。

**第一种：直接用调制性质。**

$\cos(\omega_c t)$ 的傅里叶变换是

$$\mathcal{F}\{\cos(\omega_c t)\} = \pi\left[\delta(\omega-\omega_c) + \delta(\omega+\omega_c)\right]$$

于是

$$Y(j\omega) = \frac{1}{2\pi}\left[X(j\omega) * \mathcal{F}\{\cos(\omega_c t)\}\right]$$

$\dfrac{1}{2\pi}$ 和两个 $\pi$ 一约，两边各剩 $\dfrac12$。于是卷积的对象变成了：**一片高度为 1、宽度 $2\omega_0$ 的矩形**，去和**位于 $\pm\omega_c$、面积为 $\pi$ 的两个冲激**做卷积。

做卷积的四步，翻转、平移、相乘、求和：

1. **翻转**——矩形关于 $\omega$ 轴（纵轴）左右对称，翻不翻一个样，所以翻转这步可以跳过；
2. **右移**——冲激从 $\omega_c$ 出发，往右平移。它要移多远才会"擦"到矩形的左边缘？移 $\omega_c-\omega_0$；要移多远才完全擦过去？移到 $\omega_c+\omega_0$；
3. **相乘求和**——在 $[{\omega_c-\omega_0},\,{\omega_c+\omega_0}]$ 这整段上，冲激的高度 $\dfrac12$ 与矩形的高度 1 相乘，再乘上区间宽度 $2\omega_0$，得到的仍是一块**高度为 $\dfrac12$、宽度为 $2\omega_0$** 的矩形；
4. 另一个冲激往左移，同理在 $[{-\omega_c-\omega_0},\,{-\omega_c+\omega_0}]$ 上擦出一块同样大小的矩形。

**第二种：把 $\cos$ 拆开，用频移性质。**

这条路更短。把 $\cos(\omega_c t)$ 写成指数形式：

$$y(t) = x(t)\cos(\omega_c t) = \frac12 x(t)e^{j\omega_c t} + \frac12 x(t)e^{-j\omega_c t}$$

右半项 $x(t)e^{j\omega_c t}$ 的频谱就是 $X(j\omega)$ 整体右移 $\omega_c$、幅度乘 $\frac12$；左半项就是整体左移 $\omega_c$、幅度乘 $\frac12$。两块一加：

$$Y(j\omega) = \frac12\left[X\big(j(\omega-\omega_c)\big) + X\big(j(\omega+\omega_c)\big)\right]$$

两种画法殊途同归，但第二种明显省事。

> **为什么要把两种都讲一遍？**第一种（卷积）是**概念上最直观的**——你亲眼看到"频带被搬走了"。第二种（频移）是**计算上最省事的**。而等到下一节我们要处理**两个信号**的时候，第二种就彻底做不动了：两个信号的频谱搬来搬去会互相咬合，只有第一种那种"一块一块地刷过去算高度"的笨办法才能不出错。所以第一种是为了看懂，第二种是为了算快，两个都得会。

搬完的结果长这样：

```text
            Y(jw)
             ^
    1/2      |        ┌──────────┐              ┌──────────┐
             |        |          |              |          |
  --------- +--------+----------+--------------+----------+----> w
        -wc-w0    -wc   -wc+w0  0            wc-w0   wc   wc+w0
```

读图：原来那一块在原点、高度为 1 的频谱，被整体复制成了两份，分别搬到了 $\pm\omega_c$ 上，**高度从 1 掉成了 $\dfrac12$**。

> **易错点**：这个 $\dfrac12$ 不是抄错的，它是 $\dfrac{1}{2\pi}\times\pi$ 的直接结果——调制性质里那个 $2\pi$ 在这里被 $\cos$ 变换里的两个 $\pi$ 约掉了。**时域里乘一个 $\cos$，等于把频谱一分为二、每份砍掉一半高度。**这个"砍一半"在后面解调时要原样还回来，忘掉它就再也对不上了。

---

### 解调：再乘一次载波

信号传过去了，接收端拿到了 $y(t)$，可我们真正想要的是 $x(t)$。怎么办？

**第一步，把 $y(t)$ 再乘一次载波。**

$$w(t) = y(t)\cos(\omega_c t)$$

既然 $y(t) = x(t)\cos(\omega_c t)$，那这一步做出来的是

$$w(t) = x(t)\cos^2(\omega_c t)$$

直觉上这很怪：我们想要的 $x(t)$ 被套上了 $\cos^2$，离目标更远了才对。但别急，关键在于 $\cos^2$ 这个东西的频谱形态。

#### 第二道题：画出 $W(j\omega)$

还是老规矩，先出题：$x(t)$ 带限、$X(j\omega)$ 在 $[-\omega_0, \omega_0]$ 上高度为 1，$Y(j\omega)$ 我们刚画完。现在求 $w(t) = y(t)\cos(\omega_c t)$ 的频谱。

做卷积的对象变成了：$Y(j\omega)$ 里那两块高度 $\dfrac12$ 的矩形，卷上位于 $\pm\omega_c$、高度也是 $\dfrac12$ 的两个冲激。

**先看中心那块。**一个冲激从 $+\omega_c$ 往左移、一个从 $-\omega_c$ 往右移，两者都在 $\omega=0$ 处相遇。两块矩形完全重合，高度是

$$\frac12\times\frac12 + \frac12\times\frac12 = \frac12$$

——注意**不能只算一次**，两边都得算上，否则你会得到 $\dfrac14$ 这种错误答案。这一块落在 $[-\omega_0, \omega_0]$ 上，高度 $\dfrac12$。

**再看外面的。**这是这道题真正的陷阱所在：冲激移完中心那一波**不会停**！从 $-\omega_c$ 出发的那个继续往右移，从 $+\omega_c$ 出发的继续往右移——等它们跑完 $2\omega_c$ 的路程时，又会在 $\omega = 2\omega_c$ 处撞上对方，又擦出一块来。这次只有一次相遇，所以高度是

$$\frac12 \times \frac12 = \frac14$$

落在 $[2\omega_c-\omega_0,\ 2\omega_c+\omega_0]$ 上。同理在 $-2\omega_c$ 处还有一块，高度也是 $\dfrac14$。

```text
  W(jw)
   ^
1/2|      ┌────────┐                                        ┌────────┐
   |      |        |                                        |        |
1/4|      |        |      ┌────────┐            ┌────────┐   |        |
   |      |        |      |        |            |        |   |        |
---+------+--------+------+--------+------------+--------+---+--------+----> w
 -2wc-w0 -2wc -2wc+w0 -w0      0   w0  2wc-w0  2wc 2wc+w0
```

读图：**想要的信号在正中间，高度是原来的一半；两翼各有一堆 $\dfrac14$ 的"镜像残渣"，分别坐在 $\pm 2\omega_c$ 上。**

#### 第二步：低通滤波，把残渣滤掉

现在 $x(t)$ 就在 $w(t)$ 里好好待着，只是被缩成了 $\dfrac12$，外面还飘着一堆 $\pm 2\omega_c$ 处的干扰。**再来一个低通滤波器就够了。**

滤完之后要等于原来的 $X(j\omega)$（高度 1），而滤进来的高度是 $\dfrac12$，所以低通滤波器的通带增益必须是 **2**：

$$H(j\omega) = \begin{cases} 2, & |\omega| \le \omega_p \\ 0, & \text{其它} \end{cases}$$

时域形式跟前面一样，只是整体放大了一倍：

$$h(t) = \frac{2\sin(\omega_p t)}{\pi t}$$

于是 $x(t)$ 被原样还原。

> **提示**：这个"通带增益取 2"不是凑出来的。$x(t)$ 处高度是 1，$W(j\omega)$ 在对应位置的高度是 $\dfrac12$，想让输出回到 1，滤波器就必须在通带里乘 2 把这 $\dfrac12$ 补回来。看图时把这个数字关系对着看一遍就明白了。

**截止频率 $\omega_p$ 有硬约束。**它必须满足

$$\omega_0 < \omega_p < 2\omega_c - \omega_0$$

左边的 $\omega_0$：滤波器要把整个有用频带 $[-\omega_0, \omega_0]$ 都放进来。右边的 $2\omega_c-\omega_0$：那是最近那堆 $\dfrac14$ 残渣的**起始位置**，放进来就前功尽弃。只要 $\omega_p$ 落在这个开区间里，不管取哪个值，出来的都是 $x(t)$。

> **易错点**：这一节里 $\omega_p$ 是**低通滤波器的截止频率**，$\omega_c$ 是**载波角频率**。两个字母长得不一样但都是 $\omega$ 打头，看图的时候千万别串。

#### 换个角度看：$\cos^2$ 到底是什么

同样的结论，换一个更省脑子的角度可以得到。前面那个 $x(t)\cos^2(\omega_c t)$，用二倍角公式拆开：

$$w(t) = x(t)\cos^2(\omega_c t) = \frac12 x(t) + \frac12 x(t)\cos(2\omega_c t)$$

**这一项是想要的**（在原点，高度 $\dfrac12$）；**这一项是残渣**（被搬到了 $\pm 2\omega_c$ 上，各高 $\dfrac14$）。低通滤波器只留下第一项，再乘 2 放大，$x(t)$ 就回来了。

这个视角其实更好记：$\cos^2$ 在时域看着是个"越乘越小的"东西，可它在**频域里恰好就是一份基带 + 一份高频搬移**——而低通滤波器天生就是"只留基带"的那道门。

### 为什么非要调制不可

到这里为止，你可能会有个非常合理的疑问：

> **既然乘了载波再解回来这么绕，为什么不干脆直接传 $x(t)$？**

答案是：**单个信号的时候，调制确实毫无优势，跟直接传一模一样。但两个信号的时候，它就是压倒性的优势。**我们把两个信号的情况推一遍，你就明白了。

假设要在同一条信道里同时传 $x_1(t)$ 和 $x_2(t)$。做法是：**给每一个信号分配一个专属的载波**，然后全部加起来一起发。

$$y(t) = x_1(t)\cos(\omega_{c1}t) + x_2(t)\cos(\omega_{c2}t)$$

这里 $x_1(t)$ 带限在 $[-\omega_0, \omega_0]$、高度 $E_1$，$x_2(t)$ 同样带限、高度 $E_2$，且假设 $\omega_{c1} < \omega_{c2}$。

由前面刚证过的结论，$Y(j\omega)$ 就是四块矩形：$x_1$ 的那两块在 $\pm\omega_{c1}$、各高 $\dfrac{E_1}{2}$；$x_2$ 的那两块在 $\pm\omega_{c2}$、各高 $\dfrac{E_2}{2}$。**它们在频域上互不重叠，看上去只是一大团"混在一起"的频谱，谁也认不出谁。**

接收端要怎么办？**把你想收的那个信号的载波乘上去。**

#### 解调 $x_1(t)$

$$w_1(t) = y(t)\cos(\omega_{c1}t)$$$

这一下可就有难度了——**千万不要画漏**。$Y(j\omega)$ 里现在有四块矩形，全部被冲激拖一遍。算下来 $W_1(j\omega)$ 一共有八块：

| 位置 | 中心频率 | 高度 | 来源 |
| :--- | :--- | :--- | :--- |
| 正中 | $0$ | $\dfrac{E_1}{2}$ | $x_1$ 的两块在原点重合（两边都要算） |
| 次近 | $\pm(\omega_{c2}-\omega_{c1})$ | $\dfrac{E_2}{4}$ | $x_2$ 的冲激撞上 $x_1$ |
| 再次 | $\pm(\omega_{c1}+\omega_{c2})$ | $\dfrac{E_2}{4}$ | $x_2$ 的两块对穿 |
| 最远 | $\pm 2\omega_{c1}$ | $\dfrac{E_1}{4}$ | $x_1$ 自己的两块二次相遇 |

**只有正中间那一块是我们要的 $x_1$，其余七块全是垃圾。**好在它们离得足够远——这就是为什么必须给载波留足间隙。

接一个低通滤波器（增益 2），只留 $[-\omega_0, \omega_0]$，出来就是 $x_1(t)$，一点杂质都没混进来。

#### 解调 $x_2(t)$

完全一样的套路，只是换成乘 $\cos(\omega_{c2}t)$：

$$w_2(t) = y(t)\cos(\omega_{c2}t)$$

只是这一次，$W_2(j\omega)$ 里正中间那块是 $\dfrac{E_2}{2}$，跑得最远的垃圾变成了 $\pm 2\omega_{c2}$ 处的 $\dfrac{E_1}{4}$，中间的两堆 $\dfrac{E_1}{4}$ 和 $\dfrac{E_2}{4}$ 依然在 $\pm(\omega_{c2}\pm\omega_{c1})$ 上。同一把低通刀一切，$x_2(t)$ 干净地出来了。

**看到了吗？**同一个 $y(t)$，乘不同的载波，就能挑出不同的信号。这就是调制的全部意义——**在同一个物理信道上，用频率把不同的用户劈开。**

#### 最后一组约束：四个量之间的关系

要让上面这一整套严格成立，$\omega_0$、$\omega_p$、$\omega_{c1}$、$\omega_{c2}$ 不能随便取。

**第一条**：那堆离原点最近的垃圾坐在 $\pm(\omega_{c2}-\omega_{c1})$，它自己还占着宽度 $2\omega_0$。要让它的左边缘 $\omega_{c2}-\omega_{c1}-\omega_0$ 待在 $\omega_0$ 之外，就必须

$$\omega_0 < \omega_{c2} - \omega_{c1} - \omega_0 \quad\Longleftrightarrow\quad \boxed{\ \omega_0 < \frac{\omega_{c2} - \omega_{c1}}{2}\ }$$

**第二条**：低通滤波器的截止频率要卡在有用信号和最近那堆垃圾之间，

$$\boxed{\ \omega_0 < \omega_p < \omega_{c2} - \omega_{c1} - \omega_0\ }$$

两条同时成立，这一整套才能跑通。

换个说法：**任意两个载波之差的一半，必须大于信号的截止频率 $\omega_0$。**这就是"各个信号之间的载波必须要留有足够的间隙"这句话的数学写法。

> **提示**：为什么是"载波差的一半"而不是整个载波差？因为**每一路信号的频带在搬移时会向两边各扩展 $\omega_0$**，你为用户 1 占了 $[\omega_{c1}-\omega_0, \omega_{c1}+\omega_0]$，为用户 2 占了 $[\omega_{c2}-\omega_0, \omega_{c2}+\omega_0]$，这两个区间**本身就不许重叠**。而解调时更狠——乘一次载波会让频带**再翻一倍**，于是两边各扩成 $\omega_0$，间距要求就变成了"载波差的一半要大于 $\omega_0$"。**你看，约束不是凭空定的，是从频谱图上一块一块量出来的。**

回到收音机的例子就明白了：为什么你几乎听不到"调频 91.6 兆赫"的电台？因为 91.5 和 91.6 之间那 0.1 MHz 的间隔，摊到两边又被解调翻一倍，很可能就装不下一个 $\omega_0$ 那么宽的音频频带了。**载波之间不能挤，挤了就串台。**

---

### N 个信号与完整的一般结论

两个信号的例子推广到 $N$ 个信号，道理一字不改。设 $\omega_{c1}, \omega_{c2}, \dots, \omega_{cN}$ 分别是各路的载波：

$$y(t) = \sum_{i=1}^{N} x_i(t)\cos(\omega_{ci}t)$$

接收端要做的事，看起来只有一行，其实里面藏着两步：

1. 把 $y(t)$ **乘以对应那一路的载波** $\cos(\omega_{ci}t)$；
2. 把乘出来的结果过一个**低通滤波器**。

两件事做完，$x_i(t)$ 就回来了。限制条件也就两条，形式和两个信号时一模一样：

**条件一**：任意两个载波相减除以 2，要大于等于 $\omega_0$（假定 $\omega_{ci} > \omega_{cj}$），即

$$\frac{\omega_{ci} - \omega_{cj}}{2} \ge \omega_0$$

**条件二**：低通截止频率 $\omega_p$ 要大于 $\omega_0$，小于任意两个载波相减再减去 $\omega_0$，即

$$\omega_0 < \omega_p < \min_{i 
e j}(\omega_{ci} - \omega_{cj}) - \omega_0$$

这两条说的是同一件事：**各个信号之间的载波必须留有足够间隙。**

> **提示**：条件二还有个更严格的说法——$\omega_p$ 还得小于**最小那个载波的两倍**再减去 $\omega_0$。这一条值得自己回去在图上量一遍，看看它到底是被哪一块频谱卡住的。

### 电路怎么实现：四种电路

上面这一整套东西，是可以用**真实的电路**搭出来的。有一门课叫**高频电子线路**，从前是必修，现在改成了选修——因为随着数字信号处理的发展，用连续电路实现调制解调这套变得不那么重要了，我们学院大概在五六年前把它降成了选修。

我们这里讲的只是最基本的正弦波幅度调制（AM）。更复杂的调制方式——比如现在更常用的频率调制（FM）——会在后面的**通信原理**里学。

那么要用电路实现上面这些公式，你需要哪几种电路？

#### 产生载波的电路

给定一个 $\omega_c$，要**精确地**产生出 $\cos(\omega_c t)$ 或 $\sin(\omega_c t)$。这个电路叫**晶体振荡器 / 晶体振荡电路**，简称**晶振**。

原理是：晶体足够纯粹，给它一个激励，它就能靠晶体与电路的**自激振荡**产生相当精确的正弦波。

这件事**并不容易**。想想为什么：假如发送端和接收端产生的 $\cos$ 有那么一点点差别——$\omega_c$ 上差那么一丁点——**解出来的信号就全乱了**。而且 $\omega_c$ 越高越难做，这正是这门课叫"高频电子线路"的原因。

#### 相乘与相加的电路

要产生 $y(t)$，得把每个 $x_i$ 和对应的 $\cos$ 乘起来，再把所有乘积加起来。

**相加**容易——直接用电压相加或电流相加就行。

**相乘**就没那么简单了：给你两个信号，你要怎么把它们乘起来？这是高频电路里要专门研究的问题。

#### 低通滤波器电路

前面那个把残渣滤干净、增益为 2 的东西，必须用电路实现。

#### 锁相电路

这个电路**最不容易看出来**。上面三类都有了——载波有了、相乘有了、相加有了、低通也有了——看上去所有事都解决了。但还有一件：**发送端和接收端的"时间 $t$"必须精确同步。**

假设两端的时间不对齐，解出来的东西就是一团乱麻。所以需要一个电路把两端的相位锁死——这就是**锁相电路（PLL）**。它的任务是把发送端的相位**原封不动**地传给接收端。原理依据还是那条熟悉的关系：

$$x(t-t_0)\ \longleftrightarrow\ X(j\omega)e^{-j\omega t_0}$$

**相位同步，就是把时移 $t_0$ 精确地锁定在零。**

不过随着数字信号处理的发展，这一段未必非得用电路做了。数字做法其实更简单：**在每一段传来的数据前面加一个事先约定的同步序列**（比如一串 24 位的 1010），解调端一看到这段重复的序列，就知道"相位在这里"，从它后面开始解就行了。上世纪 90 年代还全靠模拟电路去锁时间，现在已经换了思路。

### 无线频带的划分

回到我们最开始的那个问题：这么多人在同一片天空里同时通信，凭什么不打架？

**凭 ITU-T 制定的全球无线频带划分。**

这套规则把整个无线信道从 1000 Hz、10 kHz 一路排到太赫兹，每一段都分配给了特定的用途：

| 频段 | 典型用途 |
| :--- | :--- |
| 10 kHz | 航空无线电 |
| 1 MHz | AM 广播（我们平时听的广播大致在这一带） |
| 10 MHz | 国际无线电、业余无线电 |
| 100 MHz | 电视、FM 广播 |
| 100 MHz 以上 | 移动通信 |
| 1 GHz ~ 100 GHz | 实验信道、导航信道、雷达、移动通信 |
| 0.1 THz ~ 10 THz | 太赫兹——6G 要实现的技术 |

对照一下你的生活经验就知道这张表有多准：调频 91.5 MHz，稳稳落在 100 MHz 那一档里。

**为什么不能一直往上加频段？**因为当频率高到 $10^8$、$10^9$ 这个量级，调制解调电路会出现**量子效应**——电路的工作模式会跟传统那一套完全不一样。在那个领域，要用上更高频段就必须先有新的研究。

而频带越大，同样多的信号跑起来的速度就越快。这就是 6G 眼巴巴盯着太赫兹的原因。

### 当规则不遵守：干扰与跳频

规则是假定**全世界所有人都遵守**的前提下才成立的。那么当敌对双方互相不遵守呢？

2012 年的一条新闻大致是：韩国媒体称，朝鲜的电磁波干扰影响了韩国七成的武器系统。听明白了——朝鲜不遵守频带划分这套国际协议，直接在武器系统使用的那个频段上倾泻电磁噪声，于是那些导弹系统、各种各样的系统全都失灵。

**敌对双方互相干扰，怎么办？**办法不止一种。

**最暴力的一种：把载波频率使劲往上提高。**回到刚才那条逻辑——如果我能做出太赫兹频段的通信系统而你做不出来，那你就**根本没有能力来干扰我**。技术代差本身就是最好的防护。

**第二种相对温和，也正是我们今天上网、打手机、用 Wi-Fi 时真正在用的技术：跳频通信 / 扩频通信。**

思路一句话：**让发送端和接收端一起，不断随机地变换载波频率。**

比如第一秒载波在这个频率，第二秒跳到那里，第三秒再跳到别处。**发送端和接收端事先约定好同一串随机数**，用同一个伪随机数发生器来驱动，因此只有它俩知道此刻该待在哪个频率上。

这么做带来两个好处：

**第一，干扰方不知道往哪儿打。**除非它把整个频段全覆盖——但那会导致"你也用不了你的通信系统，我也用不了我的"，是同归于尽的结果。刘慈欣有篇中篇科幻小说就叫《全频带阻塞干扰》，讲的就是这个极端场景。反过来说，**只要干扰方破不了那串密码，它就没法精准地干扰你**。

**第二，干扰被均摊。**想象信道里只有十个"座位"：第一分钟十个人分别坐在座位 1 到 5 号……第十分钟轮换一遍。这样一来，如果某个特定频段因为天气原因或者别的什么受到干扰，**它造成的损耗会被平均分摊到每一个人头上，而不是让恰好坐在那儿的那个人彻底打不了电话**。

这套技术用在 **CDMA** 和 **Wi-Fi** 里。你甚至可以把每个人的电话号码理解成一个随机数发生器——正是它让你的声音信号在载波中不停变换频率。

#### 一段花絮

跳频通信的发明人是一位好莱坞非常漂亮的女性，**海蒂·拉玛（Hedy Lamarr）**。她演电影退役之后就开始搞发明。上世纪三四十年代，她和另一位工程师一起申请了右边那件发明的专利。

但那个年代，这套技术并没有得到广泛应用——因为**不断变换频率的电路那时候还造不出来**。

直到上世纪 90 年代，Wi-Fi 和无线电话真正起来之后，他们的专利才被广泛使用。而海蒂·拉玛死于 1980 年代，**恰好没有看到自己的发明被兑现**。如果再多活几年，她就能亲眼看见了。这个专利也没有为她带来多少收入。

$$\omega_0 < \frac{\omega_{c2}-\omega_{c1}}{2}$$

低通截止频率则必须卡在两者之间：

$$\omega_0 < \omega_p < \omega_{c2}-\omega_{c1}-\omega_0$$
