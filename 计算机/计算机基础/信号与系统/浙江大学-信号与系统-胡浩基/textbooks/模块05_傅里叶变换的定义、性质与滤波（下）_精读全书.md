## 把信号乘上一个余弦：调制与解调的来龙去脉
> 对应块：BLK34 | 覆盖分集：P25下 | 块标题（分集名）：《信号的调制与解调》

先问两个问题，都是日常生活里天天遇到、但没人细想过的问题。

第一个：打开收音机，主持人报台的时候会说"调频 93.5 兆赫"。这个"调频 93.5 兆赫"到底是什么意思？它在说哪一个物理量？

第二个：现在人人手里都有手机，你在打电话，旁边另外两个人也在打电话，三个人同时占用同一片无线信道、同时在往基站发信号，为什么你接起来只听到对面那一个人的声音，愣是听不到空间里另外两个人的？

这两个问题的答案是同一件事：现代通信系统的调制与解调。而它们背后真正在动的，只有一个我们已经学过的性质——傅里叶变换的调制性质。今天我们花一节课多一点的时间，把"为什么它叫调制性质"这件事彻底讲清楚。书上的位置是 197 页、5.5 节"正弦载波幅度调制"，真正要动手的是 198 页的 5.5.1"双边带正弦载波幅度调制与同步解调"。

顺便说个题外话。`modulation` 这个词，中文译成"调制"，我老觉得译得不准；按字面意思，它更接近"规范化"——把一个东西按照某种规则做出来。调制的反面是 `demodulation`，解调。今天这一讲走到最后，你会发现这整套东西漂亮的地方在于：**发送端和接收端做的是完全相同的两个动作**，一次相乘、一次低通，中间没有任何额外的复杂度。

> **提示**：这一讲的主线是"频谱搬移"。凡是遇到乘一个余弦，先想到频谱会往两边搬两座山；凡是要把山搬回来，也就是再乘一次同一个余弦。

### 先把前提摆出来：带限信号与低通滤波器

要往下走，得先把两个概念垫在桌面上：什么是带限信号，以及我们用什么工具把信号裁成带限的。

#### 什么叫带限，电话里为什么听着不一样

假设一个信号 $x(t)$，它的傅里叶变换 $X(j\omega)$ 画出来是这样一坨：只在 $-\omega_0$ 到 $\omega_0$ 这一段上有值，出了这段就全是零。

```text
             X(jω)
               ▲
           E   │      ┌────────────┐
               │      │            │
               │      │            │
  ─────────────┼──────┴────────────┴──────────────► ω
               0     −ω₀            ω₀
```

这种信号就叫**带限信号**：信号的频带只在一个有限范围内存在，其他地方都是 0。

大家其实听过带限信号。打电话的时候有没有觉得，电话那头的声音跟你在旁边说话听着不太一样？原因就在这儿——电话里的声音是带限信号，而且带宽是被硬性规定死的：从 $-4000$ Hz 到 $+4000$ Hz。注意这个单位是赫兹 $f$，要换成角频率还得乘 $2\pi$，所以电话信号对应的 $\omega_0 = 2\pi \times 4000$。

这个 4000 Hz 的规定，是上世纪七十年代左右定下来的，一直沿用到今天。哪怕这些年 5G 通信早就起来了，我们能支持比电话声音清楚得多、频带宽得多的信号传输，但 4000 Hz 这个数因为历史原因一直没改——你现在打电话，通话频带还是 4000 Hz。

顺带再说一个大家更熟悉的数：高保真唱片的频带，也就是 $\omega_0$，定在 $22150$ Hz。这也是一个规定好的数，大家听数字音乐、听 MP3，频带基本上就是它。有时候你会看到 $44300$ 这个写法，这也是对的——那是一个声音分左右两个声道，算左声道加右声道的时候带宽翻了一倍。两种写法说的是同一件事，频带宽度大致如此。

#### 用一个低通，把非带限信号裁成带限信号

那么问题来了：手头有一个信号，它在很远的地方也还有值，不是带限的，我们怎么把它变成带限的？

做法很简单：**在频域直接乘一个 $H(j\omega)$**。

```text
             H(jω)
               ▲
           1   │      ┌────────────┐
               │      │            │
               │      │            │
  ─────────────┼──────┴────────────┴──────────────► ω
               0     −ω₀            ω₀
```

相乘之后得到 $X(j\omega)H(j\omega)$，超出的那两截全被压成 0，剩下的正好落在 $-\omega_0$ 到 $\omega_0$ 之间。一个非带限信号，就这样变成了带限信号。

那这个 $H(j\omega)$ 在时域里是什么？既然是频域相乘，时域就是卷积，而卷积的这两个东西互为傅里叶变换，所以时域里那个核就是 $H(j\omega)$ 的反变换：

$$\frac{\sin(\omega_0 t)}{\pi t}$$

给它一个正式名字：**低通滤波器**（low-pass filter）。

> **定义**：低通滤波器所做的事，就是把一个不是带限的信号变成带限信号；它的傅里叶变换在 $|\omega| \le \omega_0$ 内为常数、在外为 0，时域形式是 $\dfrac{\sin(\omega_0 t)}{\pi t}$，$\omega_0$ 叫它的**截止频率**。

有了它，你就可以**任意地选择原有信号频带的宽度**——截止频率想要定在哪就定在哪。下节课我会放给大家听：一个声音信号经过不同截止频率的低通滤波器之后，分别是个什么听感。

### 一道题：$x(t)$ 乘上 $\cos(\omega_c t)$，频谱会变成什么样

调制这一块我们从一道题开始，这是整讲的主干。

假设 $x(t)$ 是带限信号，$X(j\omega)$ 在 $-\omega_0$ 到 $\omega_0$ 之间，**峰值为 1**。现在问：$y(t) = x(t)\cos(\omega_c t)$ 的傅里叶变换 $Y(j\omega)$ 大致是什么样子？尤其是，那边的最高点会是多少？

这道题有两种画法，我把两种都走一遍——第一遍是为了把概念立起来，第二遍才是真正好用的。

#### 画法一：调制性质，频域卷积

先做第一种，用调制性质。

调制性质说的是：$x(t)$ 乘一个 $\cos$，频谱等于两个频谱的卷积再乘 $\frac{1}{2\pi}$。而 $\cos(\omega_c t)$ 的傅里叶变换我们早就会了：

$$\pi\big[\delta(\omega-\omega_c) + \delta(\omega+\omega_c)\big]$$

画出来就是 $\omega_c$ 和 $-\omega_c$ 处各有一个强度为 $\pi$ 的冲激。

```text
        FT{ cos(ω_c t) } = π[ δ(ω−ω_c) + δ(ω+ω_c) ]

                  │                    │
      ────────────┼────────────────────┼──────────► ω
                −ω_c                  ω_c

                 强度 = π             强度 = π
```

现在两边一卷积，$\frac{1}{2\pi}$ 跟这两个 $\pi$ 正好约掉，剩下的系数都变成 $\frac{1}{2}$。

卷积怎么算？四个字：**翻转、平移、相乘、求和**。这里做两点假设：$x(t)$ 的频谱关于纵轴对称；以及 $\omega_c \gg \omega_0$，也就是载波比信号带宽宽得多。

因为 $\cos$ 的频谱关于纵轴对称，**翻转了这一步等于没翻**，可以跳过。然后平移：右边那个强度 $\frac12$ 的冲激往右走，从 $\omega_c - \omega_0$ 开始跟 $X(j\omega)$ 相遇产生作用，一直作用到 $\omega_c + \omega_0$ 才结束。作用的过程你可以想象成"一个强度 $\frac12$ 的刷子刷过整片频带"，所以刷出来的东西跟原来的形状一模一样，只是整体平移了。

$Y(j\omega)$ 就长这样：

```text
                          Y(jω)
                            ▲
             E/2            │            E/2
         ┌──────────┐      │      ┌──────────┐
         │          │      │      │          │
  ───────┼──────────┼──────┼──────┼──────────┼──────► ω
    −(ω_c+ω₀)  −(ω_c−ω₀)   0   ω_c−ω₀  ω_c+ω₀

          中心 −ω_c                中心 +ω_c
```

每座"山"的最高点是 $\frac{1}{2} \times 1 = \frac12$，中心分别在 $\omega_c$ 和 $-\omega_c$。这就是 $Y(j\omega)$。

#### 画法二：把余弦拆成两个指数

第一种画法其实有点抽象，我们用第二种，相对而言简单得多：

$$y(t) = x(t)\cos(\omega_c t) = \frac{1}{2}x(t)e^{j\omega_c t} + \frac{1}{2}x(t)e^{-j\omega_c t}$$

用频移性质看这两项：第一项把频谱**搬到 $\omega_c$、幅度乘 $\frac12$**；第二项把频谱**搬到 $-\omega_c$、幅度也乘 $\frac12$**。两个加起来，正是上面那张图。

两种画法结果完全一样，但我要先讲第一种，是因为等一下**当不止一个信号进来的时候，第一种的概念更有通用性**——你会发现"多个 $\frac12$ 的冲激轮番插到不同的山上"这个图像，会一直用下去。

> **结论**：$x(t)$ 乘 $\cos(\omega_c t)$ 做的事，用频域语言说就是——**原频谱复制两份，分别乘 $\frac12$，一份搬到 $+\omega_c$、一份搬到 $-\omega_c$**。

### 解调：再乘一次同一个载波

发送端的事情讲完了：我们不直接传 $x(t)$，传的是 $y(t) = x(t)\cos(\omega_c t)$。

接收端收到 $y(t)$，第一步要把 $x(t)$ 恢复出来，做法是——**再乘一次同一个载波**：

$$w(t) = y(t)\cos(\omega_c t) = x(t)\cos^2(\omega_c t)$$

看着像绕了一圈回去了，但这正是这套方案的全部魔法所在。我们来看 $w(t)$ 的频谱。

#### $W(j\omega)$ 上有几样东西

老规矩，继续考大家：请把 $W(j\omega)$ 画出来。$Y(j\omega)$ 我们已经有了，$\cos(\omega_c t)$ 的频谱也有，还是老一套，$\frac{1}{2\pi}$ 跟 $\pi$ 约掉，两边各剩一个 $\frac12$ 的冲激。

我把推导摆在黑板上，你跟着看。

先看靠近原点的地方：右移的冲激在 0 附近跟 $Y$ 左边那座山相乘，得到一块；左移的冲激在 0 附近跟右边那座山相乘，也得到一块。这两块**完全一样**——因为它们来自同一个 $x$。高度是多少？是 $\frac12 \times \frac12$，而且要**两块加起来**，所以

$$\frac12 \times \frac12 + \frac12 \times \frac12 = \frac12$$

中心在 0，跨越 $-\omega_0$ 到 $\omega_0$，高度 $\frac12$。这一块是我们想要的。

**但事情没完。** 请你再往下想一层：那个右移的冲激，会一直往右走。它走到哪里才会撞上**自己**的那座山（中心在 $\omega_c$）的中心？它得走满 $2\omega_c$。所以在 $2\omega_c$ 处，还会有一样东西。

它多高？只有这一次相乘，没有两块叠加，所以是

$$\frac12 \times \frac12 = \frac14$$

跨越 $2\omega_c - \omega_0$ 到 $2\omega_c + \omega_0$，中心在 $2\omega_c$。左移那个冲激同理，在 $-2\omega_c$ 处还有一块，高度也是 $\frac14$。

合起来：

```text
                              W(jω)
                                ▲
    1/4                    1/2                    1/4
      ┌───────┐          ┌───────┐          ┌───────┐
      │       │          │       │          │       │
  ────┼───────┼──────────┼───┬───┼──────────┼───────┼──────► ω
      −2ω_c         −ω₀    0    ω₀         2ω_c

   跨越 ±(2ω_c∓ω₀)   我们要的就是这一块   跨越 ±(2ω_c±ω₀)
```

> **易错点**：最容易被漏掉的就是 $\pm 2\omega_c$ 处这两块 $\frac14$ 的东西。讲到"没有结束"那一步时，一定要替学生把"冲激要走满 $2\omega_c$ 才回到自己那座山中心"这个换算补上，否则整个频谱图就是残缺的。

#### 低通滤波器的增益必须是 2

接下来是解调的第二步：把 $w(t)$ 送进一个低通滤波器。

到这里几乎是一目了然的——$W(j\omega)$ 里那些 $\pm 2\omega_c$ 的东西在很远的地方，低通一刀切掉，只留中间那块 $\frac12$ 的就完事了。**问题是高度对不上。**

看图说话：$X(j\omega)$ 的峰值是 1，而 $W(j\omega)$ 中间这块的峰值是 $\frac12$。我们想要的输出高度是 1，所以这个低通的通带增益**必须取 2**——$2 \times \frac12 = 1$，才刚好把原来的 $X(j\omega)$ 还原出来。

截止频率 $\omega_p$ 也有约束，不能随便取。它必须大于 $\omega_0$（不然会把要留的东西也切掉），又必须小于 $\omega_c - \omega_0$（不然会把 $2\omega_c$ 那块 $\frac14$ 放进来）：

$$\omega_0 < \omega_p < \omega_c - \omega_0$$

只要 $\omega_p$ 落在这个范围内，切在哪都无所谓，出来的都是 $x(t)$。

时域上，低通滤波就是卷积：

$$x(t) = w(t) * \frac{2\sin(\omega_p t)}{\pi t}$$

把上面那些抄成一个完整链条，信号流向是这样的：

```text
    发送端                          信道                    接收端

  x(t) ──┬─► ×cos(ω_c t) ──► y(t) ═══════════► y(t) ──┬─► ×cos(ω_c t) ──► w(t) ──┬─► LPF(增益2, 截止ω_p) ──► x(t)
         │      调制          搬移搬频                     │      相乘                  │      滤掉 ±2ω_c
         │                                                            ◄──── 解调 ────►

  频谱：−ω₀…ω₀        ω_c±ω₀ 与 −ω_c±ω₀      每项峰值为 E/2        中心 E/2，±2ω_c 处 E/4
```

你的手机里就装着这么一圈电路：把你的声音乘以 $\cos(\omega_c t)$ 发出去，同时接收别人发来的 $y(t)$，再乘回同一个 $\cos(\omega_c t)$，经过低通滤波，拿到原来的 $x(t)$。

#### 换个角度看：把 $\cos^2$ 展开成两项

上面是一遍频域账，我们再用一遍时域账，因为它更短，而且会让你确信刚才那张图没有画错。

从 $w(t) = x(t)\cos^2(\omega_c t)$ 出发，用恒等式 $\cos^2\theta = \frac12(1 + \cos 2\theta)$：

$$w(t) = \frac12\big[1 + \cos(2\omega_c t)\big]x(t) = \frac12 x(t) + \frac12 x(t)\cos(2\omega_c t)$$

一眼就能对上账了：$\frac12 x(t)$ 贡献的就是中间那块 $\frac12$；$\frac12 x(t)\cos(2\omega_c t)$ 贡献的就是 $\pm 2\omega_c$ 处那两块 $\frac14$——注意搬移频率从 $\omega_c$ 变成了 $2\omega_c$。

低通把第二项滤掉，只留第一项，再乘 2，就直接得到 $x(t)$。

> **结论**：解调就两步——**乘一次载波，再过一个增益为 2 的低通**。没有第三步。

### 为什么要多此一举：两个信号挤在同一个信道里

现在回到开头第二个问题。为什么不直接传 $x(t)$？非要乘一个余弦再解出来？

**看单个信号的时候你发现不了任何优势**——调制解调跟直接传的结果一模一样，多此一举。但看两个信号的时候，优势就"超级明显"了。我们推一遍。

#### 合成 $y(t)$：每个信号配一个自己的载波

要在一个信道里同时传 $x_1(t)$ 和 $x_2(t)$，做法是这样的：

$$y(t) = x_1(t)\cos(\omega_{c1}t) + x_2(t)\cos(\omega_{c2}t)$$

意思很直白：**每一个信号配一个专门的载波**。$x_1$ 用 $\omega_{c1}$，$x_2$ 用 $\omega_{c2}$。要是有三个、四个信号，就一个一个往下分。

$Y(j\omega)$ 跟前面的推导**完全一样**，只是多了一条叠加性：$X_1$ 的频谱（峰值为 $E_1$）搬出 $\pm\omega_{c1}$ 处的两座 $E_1/2$ 的山，$X_2$ 的频谱（峰值为 $E_2$）搬出 $\pm\omega_{c2}$ 处的两座 $E_2/2$ 的山，一共四座。

```text
                            Y(jω)
                              ▲
          E₁/2          │             E₂/2          │
       ┌────────┐       │       ┌────────┐         │       ┌────────┐
       │        │       │       │        │         │       │        │
  ─────┼────────┼───────┼───────┼────────┼─────────┼───────┼────────┼────► ω
      −ω_c1    0                  −ω_c2           ω_c1   ω_c2

       （−ω_c2、ω_c2 两座峰值为 E₂/2 的山对称分布于左右，此处省略对称支）
```

打比方：两个信号的载波必须**分得足够开**，开得像收音机里 91.5 兆赫和 91.6 兆赫那样——不，那还不够，得再开。所以下面会算出具体的间隔要求。

#### 解调 $x_1(t)$：频谱上多出来的那一堆

把 $y$ 传过去，接收端开始解调。**怎么解调 $x_1$？把整个 $y$ 乘以 $x_1$ 自己的那个载波**：

$$w_1(t) = y(t)\cos(\omega_{c1}t)$$

请大家画 $W_1(j\omega)$。这道题开始有难度了，**千万不要画漏**。（假设 $\omega_{c1} < \omega_{c2}$。）

用三支笔：紫色是 $x_1$ 的两座山，绿色是 $x_2$ 的两座山，蓝色是待卷积的冲激。$Y$ 与 $\frac12[\delta(\omega-\omega_{c1})+\delta(\omega+\omega_{c1})]$ 卷积，还是 $\frac{1}{2\pi}$ 跟 $\pi$ 约掉，两边各剩 $\frac12$。

四个冲激轮番往两边插到山上，插出来的块一共这些：

| 位置 | 高度 | 从哪来 |
| :--- | :--- | :--- |
| $0$，跨越 $-\omega_0 \sim \omega_0$ | $\frac{1}{2}E_1$ | 两座紫色山在原点叠加，$\frac12\times\frac12 E_1$ 加两次 |
| $\pm(\omega_{c2}-\omega_{c1})$ | $\frac{1}{4}E_2$ | $\omega_{c2}$ 处的冲激插进 $\omega_{c1}$ 处的绿色山 |
| $\pm 2\omega_{c1}$ | $\frac{1}{4}E_1$ | $-\omega_{c1}$ 处的冲激右移 $2\omega_{c1}$，插回 $\omega_{c1}$ 的紫色山 |
| $\pm(\omega_{c1}+\omega_{c2})$ | $\frac{1}{4}E_2$ | $-\omega_{c1}$ 处的冲激继续右移，插进 $\omega_{c2}$ 的绿色山 |

**中间那一块是我们要的，其余全部都是干扰。** 低通一刀切掉，只留 $0$ 附近那块，高度是 $\frac12 E_1$——所以这个低通的通带增益仍然取 **2**，时域上就是卷积

$$x_1(t) = w_1(t) * \frac{2\sin(\omega_p t)}{\pi t}$$

#### 解调 $x_2(t)$：同样的把戏

解调 $x_2$ 是完全一样的操作，只是换一个载波：

$$w_2(t) = y(t)\cos(\omega_{c2}t)$$

$W_2(j\omega)$ 里原点那块的高度换成 $\frac12 E_2$，干扰块的位置也跟着整体换了重心：

| 位置 | 高度 |
| :--- | :--- |
| $0$，跨越 $-\omega_0 \sim \omega_0$ | $\frac{1}{2}E_2$ |
| $\pm(\omega_{c2}-\omega_{c1})$ | $\frac{1}{4}E_1$ |
| $\pm(\omega_{c1}+\omega_{c2})$ | $\frac{1}{4}E_2$ |
| $\pm 2\omega_{c2}$ | $\frac{1}{4}E_2$ |

再用增益为 2 的低通，出来的就是 $x_2(t)$。

你看，$x_1$ 和 $x_2$ 明明是挤在同一条 $y(t)$ 上同时传过来的，却能被各自用一个余弦原封不动地挑出来。这就是最开始那两个问题的答案。

#### 让整套东西成立的不等式

现在到了这一讲最难的一道题，我留给大家，现在讲答案。

要让这一整套**完全成立**，请写出 $\omega_{c1}$、$\omega_{c2}$、$\omega_p$ 以及 $\omega_0$ 这四个量之间的不等关系。四个字：**不等关系**。这四个数不能随便取。

看图说话。$W_1$ 里，原点那块右边缘在 $\omega_0$；最近的那块干扰（$\frac14 E_2$ 那座山）左边缘在 $\omega_{c2}-\omega_{c1}-\omega_0$。低通的截止频率 $\omega_p$ 要夹在中间：

$$\omega_0 < \omega_p < \omega_{c2} - \omega_{c1} - \omega_0$$

再整理一下第一个不等式，它说的是"最近的那两座干扰山不能压到信号山上"：

$$\omega_0 < \frac{\omega_{c2} - \omega_{c1}}{2}$$

**这两个关系必须同时成立，整套东西才成立。** 直觉上很好理解：如果你把两个载波取得特别近，紫色那座山就会跑到绿色那座山上去干扰它，最后根本滤不出来。另一边同理。

> **易错点**：$\omega_0 < \frac{\omega_{c2}-\omega_{c1}}{2}$ 和 $\omega_0 < \omega_p < \omega_{c2}-\omega_{c1}-\omega_0$ 是两道**不同的**门槛，不能只写一道就以为万事大吉。第一道管"山与山不打架"，第二道管"低通的刀刃卡在两山之间"。

比喻一下：如果把每个信号看成一个人，那么载波与载波之间，就相当于给这个人分配了一个座位。座位之间**不能相互重叠**，一重叠就全乱了。

### 从两个信号推广到 N 个信号

上一节课我们是以两个信号举例的，大家回去想一想：多个信号叠加，道理完全一样。

假设有 $N$ 个信号，合成就是

$$y(t) = \sum_{i=1}^{N} x_i(t)\cos(\omega_{ci}t)$$

——**每个信号乘以自己相应的载波，然后加在一起**。$\omega_{c1},\omega_{c2},\dots,\omega_{cN}$，每个信号一个。

接收端收到 $y(t)$，恢复每一个 $x_i$ 的公式一行就写完了：

$$x_i(t) = \left[\, y(t)\cos(\omega_{ci}t)\,\right] * \frac{2\sin(\omega_p t)}{\pi t}$$

就这一行，看着不起眼，其实刚才那一整套推导都蕴含在里面：第一，$y(t)$ 乘以**与你要解的那个信号相对应的载波**；第二，把乘出来的结果过一个低通。时域上我把低通滤波器直接写成了一个卷积。

限制条件有两个方向：

**第一个**，任意两个载波相减除以 2，必须大于等于 $\omega_0$。这里约定 $\omega_{ci} > \omega_{cj}$ 时取正差：

$$\frac{|\omega_{ci} - \omega_{cj}|}{2} \ge \omega_0$$

**第二个**，低通滤波器的截止频率 $\omega_p$，它应该大于 $\omega_0$，小于任何两个载波相减再减去 $\omega_0$：

$$\omega_0 < \omega_p < \min_{i 
e j}\left(|\omega_{ci}-\omega_{cj}|\right) - \omega_0$$

不过有同学当场指出来，这一条还不够严谨——**它还应该小于最小的那个载波的两倍**，也就是 $2\omega_{c1}$。至于两倍那里还要不要再减掉一个 $\omega_0$，这里我没有当场定死，大家回去自己推一下这两条限制条件。

换句话说，这两条限制条件说的其实是一件事：**各个信号之间的载波，必须留有足够的间隙**。

这就是大家听广播时的实际情形。比如有一个台叫"调频 91.5 兆赫"，91.5 兆赫就是它的载波。如果另一个台就在旁边说"调频 91.6 兆赫"，你就很难同时听清——因为按刚才推的规矩，要传输 $\omega_0$ 这个带宽的信号，两个载波之间的距离除以 2 必须大于它。**载波之间不能挤。**

### 用电路实现：四种电路，一门被改成选修的课

以上这一整套东西，公式都写完了，但它归根结底是一套电路。这就要引出今天课程表上早就不再单独开的一门课：**高频电子电路**。

这门课以前是必修，最近改成了选修。我们学院应该是在五六年前改的。为什么？因为随着数字信号处理的发展，"用连续电路去实现调制与解调"这一套，变得没那么重要了。

它在讲什么？讲的就是怎么用电路实现上面这一套（当然也不完全，因为我们这里讲的只是最基本的正弦波幅度调制，频率调制那些更常用的方式要到《通信原理》里去学）。

我会用大概十分钟，把这几页幻灯片上的东西讲清楚。我得先声明一句：**我不是学做电路的，只能以我有限的知识来讲**，如果哪里说得有点错，请大家包涵，以你们后续专业课的张老师讲的为准。

那么问题来了：上面这么多公式，如果想用电路实现，你需要规划哪几种电路？给大家十秒钟想一想——我猜大家答不出来。它需要**四种**。

#### 载波从哪里来：晶体振荡器

**电路一，产生载波。** 你给一个 $\omega_c$，这个电路要精确地产生 $\cos(\omega_c t)$ 或者 $\sin(\omega_c t)$。

这个电路有专门的名字：**晶体振荡器**，简称**晶振**。

这里的"晶"是一种晶体。晶体越纯粹，给它一个刺激，它能产生越精确的 $\cos(\omega_c t)$ 波形。它利用的是晶体和周围电路的**自激振荡**来产生正弦和余弦。

这件事**并不容易**，而且难点很明确：假如发送端和接收端产生的余弦有"稍微那么一点点"差别——$\omega_c$ 上差那么一点点频率——你解出来的信号就完全不对了。所以必须严格保证：输入一个 $\omega_c$，我要非常精确地产生对应的 $\cos$。而 $\omega_c$ 越高，这件事越难——这也正是这门课为什么叫"**高频**电子线路基础"。

#### 相乘和相加

**电路二，相乘和相加。** 我们要产生 $y(t)$，得先把每个 $x_i$ 产生出来、每个余弦也产生出来，然后——把它们乘起来，以此类推——再加起来。

相加的电路好做，直接用电压相加或者电流相加就可以了。相乘的电路也不那么好做：给你两个信号，怎么把它们乘起来？（这个大家以后学过高频线路会知道办法，现在不讲。）

#### 低通滤波器电路

**电路三，低通滤波器电路。** 今天讲到这里，下节课就会讲到它，大概是个什么感觉。

我们上面所有的卷积，都必须用一个真实的低通滤波器电路来实现。

#### 锁相电路：把发送端的时间 $t$ 原封不动传过去

**电路四，这个就不是那么好看得出来的。**

你回头看上面那张框图：余弦有了，相乘有了，相加有了，低通滤波器也有了——好像所有事情都解决了。但**还差一样东西**。

看框图左右两边：这边是发送端，这边是接收端。它们的**时间 $t$ 必须精确同步**。

请你认真想一下这件事：如果发送端的 $t$ 和接收端的 $t$ 不精确同步，解出来的信号将会**是一团乱码**。

所以我们要做一个电路，把发送端和接收端精确地同步。回忆一下 $x(t-t_0)$ 的傅里叶变换：

$$x(t-t_0) \longleftrightarrow X(j\omega)e^{-j\omega t_0}$$

**精确同步时间 $t$，就意味着要把相位锁住。** 于是这个东西叫**锁相电路**——把发送端的相位锁住，原封不动地传给接收端。

这里也提一下，随着数字信号处理的发展，这一块不见得非要用电路实现。如果用数字信号来做，反而更容易：在每一个传过来的信号前面加一段**同步信号**，这个序列你自己定就行——比如事先约定一段 24 位的 1010 序列。接收端一看到这段重复的序列，就知道"相位在这儿了"，从这段序列之后的一个规定位置开始解调即可。用数字实现锁相，就这么简单。

但在**上世纪 90 年代全都是模拟信号**，所以那时候必须用一些电路去把发送端传过来的 $t$ 锁住，让接收端跟它完全同步。这就是锁相环存在的历史理由。

至于这四种电路具体长什么样，幻灯片上有，我这里就不一笔一笔念了；高频电子线路那门课会讲得更透。现在的实际系统里，调制解调电路已经被做成了一块**芯片**，芯片外围再配搭一些电路，核心就是这块芯片，因为目前都标准化、模块化了。（这部分我自己也不完全懂，大家有兴趣就去钻研每一块为什么这么搭。）

### 无线频带是怎么划的

接下来是最后一个大话题：**无线频带的划分**。

前面说过，每一个信号是一个人，你要给他划分一个载波，以及一块**跟其他信号不重叠的区域**。我们把这一块频带叫做**频带**——在频率域上划一块地，让这个信号跟别的信号不重叠。

既然划了，那后面来用无线信道的人也必须遵守同样的规则。如果他不遵守、他无视你的划分，本来你在这个频段传信号，他也在这个频段传他自己的信号，结果就是**你们两个信号相互干扰，谁都传不好**。

于是国际标准委员会（ITU-T）制定了一套规则，把无线信道从低到高划开。这张图是我从一本叫《数字通信》的书上第三页的插图截下来的，我大致念几个，因为我也算不上专业：

| 频段 | 用途 |
| :--- | :--- |
| 10 kHz | 航空无线电 |
| 1 MHz | AM 广播，我们平时听到的那些广播基本在这个范围 |
| 10 MHz 上下 | 国际无线电、业余无线电 |
| 100 MHz | 电视和 FM 广播 |
| 再往上 | 移动通信 |
| 1 GHz ~ 100 GHz | 实验用信道、导航信道、雷达、移动通信等 |
| 0.1 THz ~ 10 THz | 太赫兹频段——6G 要实现的技术 |

"调频 91.5 兆赫"落在 100 MHz 那一档里，跟我们的日常经验完全对得上。

**为什么不能无限地把频率加高？** 因为当频率范围达到 $10^8$、$10^9$ 的时候，调制和解调的电路会出现所谓的**量子效应**——所有电路的运行模式、各种各样的情况会变得跟传统这一套完全不一样。所以在这种情况下必须做更多的研究，才能利用更高频段的信号。

6G 大家都说能实现太赫兹通信。反过来也成立：**当频带范围变得更大的时候，要传输同样多的信号，传输速率就会比以前大得多。**

#### 有人不守规矩的时候

当然，上面这套是**假定全世界所有人都遵守**的。那要是不遵守呢？

比如打仗的时候，或者敌对势力之间——我这儿摘录过一则 2012 年的新闻：韩国媒体称朝鲜的电磁波干扰将影响七成韩国的武器。大意是朝鲜并不遵守这套国际无线频带划分的协议，在武器所在的频带上对它进行电磁波干扰。干扰一过去，导弹系统、各种各样的系统就会失灵。所以敌对双方之间可以形成"干扰"与"被干扰"的状态。

那么，我们该怎么应对干扰？一个人想搞垮你的通信，你用这些频带，有哪些应对方式？

**第一种，最暴力：把载波频率使劲提高。** 我前面说过，到了太赫兹甚至更高的频段，会出现一种局面——我如果技术好，我能做出在高频段通信的系统，而你做不出来；你做不出来，你也就没办法干扰我。

**第二种，相对优雅：跳频通信技术**（也叫扩频通信技术）。这就是我们目前上网、打手机、用 Wi-Fi 所采用的技术，被用在 CDMA 和 Wi-Fi 里面，也是一种常用的抗干扰方式。

怎么做？让**发送端与接收端不断随机变换载波频率**。发送端和接收端事先约定好：第一秒钟载波频率在这儿，第二秒钟在这儿，第三秒钟在这儿，第四秒钟在这儿。用一串随机数生成器，把双方在每个规定时间内的载波频率行为约定死。

这样做的结果是：**你不知道该干扰我的哪一段。** 除非你把整个频段全部干扰掉。但整段全干扰的结果是——你也用不了你的通信系统，我也用不了我的，谁都别想好过。

> 刘慈欣写过一部中篇小说叫《全频带阻塞干扰》，讲的就是这个：要把整个频段都干扰掉，那谁都用不了这个频段了。而我如果不断随机变换频率，你根本不知道干扰我哪里——**因为解不出"密码"，就没法干扰我**。

这套技术还有一个约束条件，顺便说一下：如果这里能提供 10 个座位，10 个人同时通信，第一分钟他们坐在 1、2、3、4、5 这样；第二分钟 2、3、4、5、1 轮换着坐。这样一来，某个特定频段如果因为天气等原因受到了干扰，**损耗会被平均分摊到每一个人身上**，而不是某一个人完全通信不了。

> **小花絮**：跳频通信的发明人是一位好莱坞非常漂亮的女星，叫**海蒂·拉玛**。她演电影退役之后就开始搞发明，在上世纪三四十年代和另一位工程师申请了专利。但那时候并没有获得广泛应用——不断变换频率的跳频电路在那时还真不是那么容易做出来。直到上世纪 90 年代 Wi-Fi 和无线电话发展起来，他们的专利才被广泛使用。她死于 1987 年，刚好没看到自己的发明被利用起来；如果再多活几年就能看到了。所以这个专利也没给她带来多少收入。

### 本讲提到的题目

这一讲里我留了一道题，现在把答案一并给你。

**题目**：要让"一个信道同时传 $x_1(t)$ 和 $x_2(t)$，接收端分别解调出 $x_1$ 和 $x_2$"这一整套完全成立，请写出 $\omega_{c1}$、$\omega_{c2}$、$\omega_p$ 和 $\omega_0$ 这四个量之间的不等关系。

**答案**（要求两式同时成立）：

$$\omega_0 < \frac{\omega_{c2}-\omega_{c1}}{2} \qquad \text{且} \qquad \omega_0 < \omega_p < \omega_{c2}-\omega_{c1}-\omega_0$$

推导就在正文「让整套东西成立的不等式」一节里：不等式一管**山与山不打架**（最近那两座 $\frac14$ 的干扰山不能压到信号山上），不等式二管**低通的刀刃卡在两山之间**。

还有一个遗留问题在正文里也标出来了：推广到 $N$ 个信号时，低通截止频率除了要小于最小载波间距减 $\omega_0$，是否还必须小于最小载波的两倍、并且再减掉 $\omega_0$，我当场没有定死，需要大家回去自己推。

## 傅里叶变换的几条硬性质：尺度、对偶、能量与共轭对称
> 对应块：BLK35 | 覆盖分集：P26上 | 块标题（分集名）：《傅里叶变换的性质（尺度变换、共轭对称、对偶、帕斯》

这一讲是第三章的收尾。前面把傅里叶变换的基本性质（线性、时移、频移、共轭）过完了，剩下的全是"看起来像顺便提一句、实际上做题必须会用"的几条。我一直觉得这些性质里最被低估的是尺度变换和共轭对称性——尤其是共轭对称性，它不像时移频移那样直接给你一个式子，而是给了你一整套关于"实信号谱长什么样"的约束，考试里出综合题全靠它。

我们按讲义的顺序走一遍：先尺度变换，再对偶性，再帕斯瓦尔定理，最后花大篇幅把共轭性和共轭对称性的三句话讲透。

### 时域胖则频域瘦：时间与频率的尺度变换

书上 109 页 3.4.6，时间与频率的尺度变换。它说的是：若

$$x(t) \longleftrightarrow X(j\omega)$$

则

$$x(at) \longleftrightarrow \frac{1}{|a|} X\left(j\frac{\omega}{a}\right)$$

注意右边两处改动是**同时**发生的：$\omega$ 变成 $\frac{\omega}{a}$，前面还要乘一个 $\frac{1}{|a|}$。这两处都别漏。

#### 换元证明：a 的符号决定积分限要不要翻

从定义出发。傅里叶变换对是

$$X(j\omega) = \int_{-\infty}^{+\infty} x(t) e^{-j\omega t} dt$$

所以

$$\mathcal{F}\{x(at)\} = \int_{-\infty}^{+\infty} x(at) e^{-j\omega t} dt$$

这里要做换元。设 $at = t'$，那么 $dt = \frac{1}{a} dt'$。麻烦就在换元之后积分限怎么走，$a$ 的符号会翻转无穷远的走向，所以我们得分两种情况。

**情况一：$a > 0$。** $t$ 从 $-\infty$ 走到 $+\infty$ 时，$t' = at$ 也是从 $-\infty$ 走到 $+\infty$，方向不变：

$$\int_{-\infty}^{+\infty} x(t') e^{-j\omega \frac{t'}{a}} \frac{1}{a} dt'$$

把 $t'$ 统一擦掉，注意到 $-\frac{\omega}{a} t' = -\frac{\omega}{a} t'$，括起来就是标准的指数形式，跟上面那个定义式一对，直接得到

$$\frac{1}{a} X\left(j\frac{\omega}{a}\right)$$

**情况二：$a < 0$。** $t = -\infty$ 时 $t' = a(-\infty) = +\infty$；$t = +\infty$ 时 $t' = -\infty$。上下限对调了，于是

$$\int_{+\infty}^{-\infty} x(t') e^{-j\frac{\omega}{a}t'} \frac{1}{a} dt'$$

积分上下限一换，前面自动多出一个负号；同时 $\frac{1}{a}$ 本身也是负的，两负得正，但 $\frac{1}{a}$ 得单独提出来看更清楚：负号提到积分号外面，剩下 $\frac{1}{a}$ 留在里面。整理后是

$$-\frac{1}{a} X\left(j\frac{\omega}{a}\right)$$

把两种情况合并，就得到了带绝对值的那一条：

$$\boxed{\ \mathcal{F}\{x(at)\} = \frac{1}{|a|} X\left(j\frac{\omega}{a}\right)\ }$$

> **易错点**：绝对值里的 $a$ 是**时域**那个 $a$，不是频率。频率那侧永远是 $\omega/a$，永远不带绝对值。很多人写成 $X\left(j\frac{a}{\omega}\right)$ 或者把 $a$ 翻成 $\frac1a$，一旦画图立刻会发现自己画的频率轴刻度反了。

#### 从方波看图：压缩与展开

这条性质我不觉得例题本身重要，但它**说明的意思**重要，我给它归结成一句口诀：

> **时域胖则频域瘦，时域瘦则频域胖。**

我用一个已经算过的例子把它画出来。宽度为 $2T_0$、幅度为 1 的方波

$$x(t) = \begin{cases} 1, & |t| \le T_0 \\ 0, & \text{其他} \end{cases}$$

它的傅里叶变换前面写过了，是 $Sa(T_0\omega)\cdot 2T_0$，其中 $Sa(x) = \frac{\sin x}{x}$。把它化简开：

$$2T_0 \cdot \frac{\sin(T_0 \omega)}{T_0 \omega} = 2 \frac{\sin(T_0\omega)}{\omega}$$

一个 $T_0$ 被约掉了。画图时看三个东西：$\omega = 0$ 处 $Sa$ 取极限值 $1$，所以频谱高度是 $2T_0$；过零点由 $\sin(T_0\omega) = 0$ 给出，即 $T_0\omega = \pm\pi, \pm 2\pi, \ldots$，换算成频率坐标是

$$\omega = \pm\frac{\pi}{T_0},\ \pm\frac{2\pi}{T_0},\ \pm\frac{3\pi}{T_0}, \ldots$$

也就是说，**零点间距是 $\frac{\pi}{T_0}$**。$T_0$ 越大，时域在 $[-T_0, T_0]$ 上铺得越宽（越胖），零点间距 $\frac{\pi}{T_0}$ 越小，主瓣被挤得越窄——频域反而更瘦。

```text
   频谱 |X(j omega)|

      ^
 2T0  |        /\
      |       /  \
      |  .---'    '---.
   0  +------|---------|----.----.----.----> omega
            -pi/T0    pi/T0
          过零点：±pi/T0, ±2pi/T0, ...

      T0 越大  ->  零点越密  ->  主瓣越窄 = 频域越"瘦"
```

那为什么是这样？回到性质本身。假设 $|a| > 1$，用第一章第一节课的知识，$x(at)$ 是把 $x(t)$ 沿时间轴**往里压**：原来横坐标 $t$ 处的值，现在挪到了 $\frac{t}{a}$ 处，横向压缩 $\frac{1}{|a|}$ 倍。对应的频谱 $\frac{1}{|a|}X\left(j\frac{\omega}{a}\right)$ 里的 $\frac{\omega}{a}$ 表示：频谱横坐标每个点被压缩了 $\frac{1}{|a|}$，等效于图形往两边**往外展** $\frac{1}{|a|}$ 倍，同时整体高度乘 $\frac{1}{|a|}$。

```text
   |a| > 1（压时间）                     |a| < 1（拉时间）

     t:  -aT0   0   aT0                   t:  -T0/a  0  T0/a
        |------|------|                     |-----|------|-----|
          < 变 窄 >                          < 变 宽 >

   omega:  -pi/|a|  0  pi/|a|             omega:  -|a|pi  0  |a|pi
        |----|----|----|----|                  |------|------|------|
          < 变 宽 >                             < 变 窄 >

      高度同时乘以 1/|a|                     高度同时乘以 |a|
```

所以"这边压缩多少、那边就展开多少"是完全配对的，这就是时域越瘦频域越胖的来源。

#### 最极端的情形，以及"平缓 = 带限"

口诀推到极限就得到两条必须背熟的基本变换对：

$$\delta(t) \longleftrightarrow 1, \qquad\qquad 1 \longleftrightarrow 2\pi \delta(\omega)$$

$\delta(t)$ 在时域上只是一个冲击，瘦到了极致；它的谱在整个频率轴上都是 1，胖到了极致。反过来，常数信号 $1$ 在时域上胖到无处不在（整个实轴都是 1），谱却瘦成了一个 $2\pi$ 的冲激。这两条是"时域胖频域瘦"的最强版本，任何时候拿它们当标尺去验别的结论，都不会错。

不过我们还可以再往前走一步，换一个角度理解这条口诀，这个角度考试不出、但理解傅里叶变换特别关键。

**时域胖，意味着变化很平缓。** 一个胖信号 $x(t)$ 意味着我到处都有它，它在整个时间跨度上起伏得很慢。既然如此，把它拆开看傅里叶变换里那个指数：

$$e^{-j\omega t} = \cos(\omega t) - j \sin(\omega t)$$

设想一个变化很平缓的 $x(t)$。如果频率 $\omega$ 给得很低，$\cos(\omega t)$ 和 $\sin(\omega t)$ 变化得跟 $x(t)$ 一样慢，二者乘起来在整个积分区间上**同号堆积、不怎么互相抵消**，积出来的值就比较大；反过来，如果给一个比 $x(t)$ 剧烈得多的频率，$\sin$ 和 $\cos$ 在正负半周里飞快地换符号，$x(t)$ 又是缓变的，来不及跟着翻转，于是积出来的正负项一路对消，结果趋近于零。

> **结论**：时域上变化平缓的信号，它在频域上只在一个有限的频率范围内有值，也就是**带限信号**。反过来，时域跳变剧烈的信号（比如方波、冲激），它的频谱要一直铺到高频里去。

这就是"时域胖频域瘦"的物理图像，而不是一条需要死记的口诀。

下节课我还会做一个有趣的实验：放好几段声音给大家听，同时把它们的频谱图摆在旁边，让大家猜哪个声音对应哪个频谱。核心就一句——**你听着平缓的声音，频带一定窄；你听着高高低低、起伏不断的声音，频带一定宽**。到那时候你会发现，前面这些公式全都能对上耳朵。

### 对偶性：把 X(j omega) 搬到时域去当信号

接下来是书上 110 页 3.4.7，对偶性。它说的是：若小的

$$x(t) \longleftrightarrow X(j\omega)$$

则大的

$$X(t) \longleftrightarrow 2\pi x(-\omega)$$

> **定义**：这里"小"和"大"指的是变换对两侧谁在时域。若小的是 $x(t)$、大的是 $X(j\omega)$，那么交换之后，左边变成大的 $X$ 但自变量从 $\omega$ 换成 $t$（即把 $X(j\omega)$ 里的 $\omega$ 全部替换成 $t$），右边则是 $2\pi$ 乘以小 $x$ 把自变量 $t$ 全部替换成 $-\omega$。

这一个式子，**非常容易混**。真正动手时要做的是两件事：左边把 $\omega$ 改名成 $t$ 搬到左边，右边把 $t$ 改名成 $-\omega$ 并乘上 $2\pi$。

#### 两个例子先热热身

**例一：$\delta(t) \leftrightarrow 1$。** 这是针对 $\omega$ 的 1。现在用对偶性把这个 1 搬过来当成关于 $t$ 的函数，它的傅里叶变换是多少？照抄 $2\pi$，右边 $x(-\omega)$ 是把 $\delta(t)$ 里所有的 $t$ 换成 $-\omega$，得到

$$1 \longleftrightarrow 2\pi \delta(-\omega)$$

而 $\delta(\omega) = \delta(-\omega)$，因为由 $\delta(at) = \frac{1}{|a|}\delta(t)$ 可以看出 $\delta$ 是偶函数。所以结果就是熟悉的

$$1 \longleftrightarrow 2\pi \delta(\omega)$$

**例二：方波与 Sa 互为变换。** 一个 $-\tau$ 到 $\tau$、幅度为 1 的方波，它的傅里叶变换是 $2\tau Sa(\tau\omega)$。现在用对偶性把它翻过来：左边的大 $X(t)$ 就是把 $2\tau Sa(\tau\omega)$ 里的 $\omega$ 换成 $t$，即 $2\tau Sa(\tau t)$；它的傅里叶变换等于 $2\pi x(-\omega)$，也就是 $2\pi$ 乘上小 $x$、把 $t$ 换成 $-\omega$——对偶性在这里做了两件事：把整个函数搬到时域，同时把幅度乘了 $2\pi$。

然后还要处理 $x(-\omega)$：把它沿 $y$ 轴翻转一下。但方波是偶对称的，翻转跟没翻转一样。所以结论就是我们在方波那一节反复用过的那条著名公式——**方波的傅里叶变换是 Sa，Sa 的傅里叶变换是方波**（把幅度归一化后，就是我们一直在用的"第五个公式"）。

> **提示**：对偶性本质上是一种**搭积木**的方法。你会做正向变换，就会做反向的。反向搭积木的代价是：左边得搬一次家，右边得翻转一次。所以考场上如果非要用对偶性去搭积木，会比正向变换多绕两道弯，作答时间明显变长。所以初考阶段，能正着做就正着做，对偶性留到最后当"救命手段"。

#### 证明：三次改写，两次换名

证明不难，我们把它做完。小的 $x(t)$ 先用反变换公式：

$$x(t) = \frac{1}{2\pi} \int_{-\infty}^{+\infty} X(j\omega) e^{j\omega t} d\omega$$

把 $2\pi$ 提到左边：

$$2\pi x(t) = \int_{-\infty}^{+\infty} X(j\omega) e^{j\omega t} d\omega$$

**第一步，交换 $\omega$ 与 $t$ 的名字。** 上式里所有的 $\omega$ 换成 $t$，所有的 $t$ 换成 $\omega$。$\omega$ 和 $t$ 不过是两个哑变量，交换是合法的，交换后得到

$$2\pi x(\omega) = \int_{-\infty}^{+\infty} X(jt) e^{j\omega t} dt$$

**第二步，把 $\omega$ 打成 $-\omega$。** 左边变成 $2\pi x(-\omega)$，右边指数里那个 $\omega$ 也要跟着变号：

$$2\pi x(-\omega) = \int_{-\infty}^{+\infty} X(jt) e^{-j\omega t} dt$$

**第三步，认出来。** 右边这个积分，把 $X(jt)$ 里的哑变量 $t$ 改叫 $\tau$，它就是 $X(\tau) e^{-j\omega \tau}$ 对 $\tau$ 的积分——这正是 $\mathcal{F}\{X(t)\}$ 的定义式。于是

$$\boxed{\ \mathcal{F}\{X(t)\} = 2\pi x(-\omega)\ }$$

证完了。三步走里最关键的是**第二步的换号**：没有这一步指数还是 $+j\omega t$，就凑不成正变换的形式。

#### 三道题：前两道热身，第三道要转好几道弯

对偶性讲完直接上题。第一题先给你 30 秒：

$$\frac{1}{1 + jt} \text{ 的傅里叶变换是多少？}$$

第一题要背公式：

$$e^{-t} u(t) \longleftrightarrow \frac{1}{1 + j\omega}$$

于是把公式里的 $\omega$ 拿过来当 $t$，就有 $\frac{1}{1+jt} \longleftrightarrow 2\pi x(-\omega)$。$x(-\omega)$ 的意思是所有 $t$ 用 $-\omega$ 去代：$e^{-t}$ 里的 $t$ 换成 $-\omega$，负负得正成了 $e^{\omega}$；$u(t)$ 换成 $u(-\omega)$。答案

$$\frac{1}{1 + jt} \longleftrightarrow 2\pi e^{\omega} u(-\omega)$$

> **易错点**：$e^{-(-\omega)} = e^{\omega}$ 这一步最容易看漏。看到 $x(-\omega)$ 就要条件反射地把每个自变量替成 $-\omega$，然后把负号代进去再看整体。$u(-\omega)$ 是**左边沿阶跃**，$\omega < 0$ 时为 1。

第二题：$\frac{1}{t^2 + 1}$。已知

$$e^{-|t|} \longleftrightarrow \frac{2}{\omega^2 + 1}$$

这里把所有的 $\omega$ 变成 $t$ 搬过去，再用对偶性：$\frac{1}{1+jt}$ 那道题的骨架一模一样，右边 $2\pi x(-\omega)$，其中 $x(-\omega)$ 就是把 $e^{-|t|}$ 里的 $t$ 换成 $-\omega$——绝对值管不了负号，$|-(-\omega)| = |\omega|$。所以

$$\frac{1}{t^2 + 1} \longleftrightarrow \pi e^{-|\omega|}$$

两道都简单，本质是同一个动作。

**第三道是道难题**，上一次布置作业的时候要用的：

$$\frac{1}{\pi t} \text{ 的傅里叶变换。}$$

这个就不是能一眼写出来的了。一分钟思考时间，然后公布答案。它有一个专门的名字，叫**希尔伯特变换**——我后面出的题和第五章都会用到它，大体有两道题会碰上。

来做。第一步，先问：什么东西的傅里叶变换等于 $\frac{1}{\omega}$？（等价地，也可以问 $\frac{1}{\pi\omega}$ 是什么的变换。）大致方向是 $\text{sgn}$ 函数那一类，但记不得也没关系，我们现推。用两条老公式：

$$u(t) \longleftrightarrow \frac{1}{j\omega} + \pi\delta(\omega), \qquad 1 \longleftrightarrow 2\pi\delta(\omega)$$

第二条取一半，把 $\frac{1}{2}$ 拿过来，两式相减，$\pi\delta(\omega)$ 正好抵消：

$$u(t) - \frac{1}{2} \longleftrightarrow \frac{1}{j\omega}$$

根据线性性质，$j$ 可以拿到右边来（等价地把左边整体乘 $j$）：

$$j\left[u(t) - \frac{1}{2}\right] \longleftrightarrow \frac{1}{\omega}$$

再把 $\pi$ 拿到左边——为了配合题目问的 $\frac{1}{\pi\omega}$，左边要除以 $\pi$，这样 $\pi$ 和右边分母上的 $\pi$ 就约掉了：

$$\frac{j}{\pi}\left[u(t) - \frac{1}{2}\right] \longleftrightarrow \frac{1}{\pi\omega}$$

我们拿到 $\frac{1}{\pi\omega}$ 了。回头看看这东西是怎么搭出来的：**$u(t)$ 减 $\frac{1}{2}$ 得到 $\frac{1}{j\omega}$，再把 $j$ 乘回去**。三块积木，两次线性组合。

第二步，用对偶性把 $\frac{1}{\pi\omega}$ 搬过去：$x(t) = \frac{j}{\pi}[u(t) - \frac12]$，$X(j\omega) = \frac{1}{\pi\omega}$，于是

$$\mathcal{F}\left\{\frac{1}{\pi t}\right\} = 2\pi x(-\omega) = 2\pi \cdot \frac{j}{\pi}\left[u(-\omega) - \frac{1}{2}\right]$$

$\pi$ 跟 $\pi$ 约掉：

$$\boxed{\ \mathcal{F}\left\{\frac{1}{\pi t}\right\} = 2j\left[u(-\omega) - \frac{1}{2}\right]\ }$$

把它画出来会清楚得多。$u(-\omega)$ 是往左的阶跃，$u(-\omega) - \frac{1}{2}$ 把它整体下移 $\frac{1}{2}$（左半边 $+1 \to +\frac{1}{2}$，右半边 $0 \to -\frac{1}{2}$），再乘 2 得到 $+1$ 和 $-1$，最后还有个 $j$ 不要忘，$+1 \to +j$，$-1 \to -j$：

```text
   F{1/(pi t)} = 2j[ u(-w) - 1/2 ]

     Im
      ^
  +j  |████████████
      |████████████|
      |████████████|
    0 +------------|---------------->  Re = w
      |            |
      |            |   -----------
  -j  |            +████████████
      |            +████████████|

        w < 0 : +j            w > 0 : -j
```

为什么要叫它 90 度移相器？看这个 $j$。因为 $j = e^{j\frac{\pi}{2}}$，也就是 $\cos\frac{\pi}{2} + j\sin\frac{\pi}{2}$，它是一个**纯虚的单位量**，作用是把所有频谱分量统一乘上一个 $e^{j\pi/2}$——相当于绕原点转了 90 度，幅度一点没动，相位整整挪了四分之一圈。这个东西后面在信号处理里还会大量出现，记牢它。

这道题之所以算难，是因为要转好几道弯：先用线性组合拼出 $\frac{1}{\pi\omega}$，再用对偶性搬一次。考场上遇到这种题怎么办？先把转弯的大方向规划出来就已经很厉害了，剩下的交给熟练度。

### 帕斯瓦尔定理：时域和频域的能量守恒

书上 3.4.8。若

$$x(t) \stackrel{\mathcal{F}}{\longleftrightarrow} X(j\omega)$$

则

$$\boxed{\ \int_{-\infty}^{+\infty} |x(t)|^2 \, dt = \frac{1}{2\pi} \int_{-\infty}^{+\infty} |X(j\omega)|^2 \, d\omega\ }$$

意思就一句话：**傅里叶变换的能量守恒**。时域上这个东西叫求能量——模的平方、从负无穷积到正无穷；频域上也是求能量。两边的能量相等，只差一个 $2\pi$ 的系数。

#### 证明：把一个因子换成共轭

证明不算特别容易，我们做一遍。左边写成

$$\int_{-\infty}^{+\infty} |x(t)|^2 dt = \int_{-\infty}^{+\infty} x(t) x^*(t) dt$$

这里冒出个**共轭**。所谓共轭，就是 $(a + jb)^* = a - jb$——实部不变，虚部反号。

现在把反变换公式套进 $x^*(t)$：

$$x(t) = \frac{1}{2\pi} \int_{-\infty}^{+\infty} X(j\omega) e^{j\omega t} d\omega$$

它带一个共轭时怎么处理？指数部分先变号，因为 $(e^{j\omega t})^* = e^{-j\omega t}$；积分变量 $\omega$ 是实数所以不动；$X$ 取共轭：

$$x^*(t) = \frac{1}{2\pi} \int_{-\infty}^{+\infty} X^*(j\omega) e^{-j\omega t} d\omega$$

代进去：

$$\int_{-\infty}^{+\infty} x(t) \left[ \frac{1}{2\pi} \int_{-\infty}^{+\infty} X^*(j\omega) e^{-j\omega t} d\omega \right] dt$$

**交换积分次序**，把 $\frac{1}{2\pi}$ 提到最外面：

$$\frac{1}{2\pi} \int_{-\infty}^{+\infty} X^*(j\omega) \left[ \int_{-\infty}^{+\infty} x(t) e^{-j\omega t} dt \right] d\omega$$

方括号里那个积分你天天见——它就是正变换，等于 $X(j\omega)$。整个式子立刻塌缩成

$$\frac{1}{2\pi} \int_{-\infty}^{+\infty} X^*(j\omega) X(j\omega) d\omega = \frac{1}{2\pi} \int_{-\infty}^{+\infty} |X(j\omega)|^2 d\omega$$

证完。整个证明的技术核心只有两个：**共轭把指数翻成负号**，以及**交换积分次序后内层积分正好是正变换**。

#### 同一道积分的两种做法

有了定理就能解题。第一题：

$$\int_{-\infty}^{+\infty} \left(\frac{\sin t}{t}\right)^2 dt = \ ?$$

半钟时间。这题有两种做法，都做一遍你会看出它们的关系。

**方法一，直接套帕斯瓦尔。** $x(t) = \frac{\sin t}{t}$ 的傅里叶变换我们已经知道了——它就是 $[-1, 1]$ 上高度为 $\pi$ 的矩形：

```text
   x(t) = sin(t)/t                X(j omega)

        /\                              ______
       /  \                            |      |
  ----+----\----> t               ----|------|----> omega
  --          /                     |      |   pi
             /                      |______|
            /
         x(0) = 1                 区间 [-1, 1]，高度 pi
```

于是在 $[-1, 1]$ 上 $|X|^2 = \pi^2$，别处为零：

$$\int_{-\infty}^{+\infty} \left(\frac{\sin t}{t}\right)^2 dt = \frac{1}{2\pi} \int_{-1}^{1} \pi^2 \, d\omega = \frac{1}{2\pi} \cdot \pi^2 \cdot 2 = \pi$$

**方法二，换个方向：先算平方的变换。** 直接求 $\left(\frac{\sin t}{t}\right)^2$ 的傅里叶变换，这是 $\frac{\sin t}{t} \cdot \frac{\sin t}{t}$，用调制性质（上次做过）就是两个矩形做卷积，前面挂个 $\frac{1}{2\pi}$：

$$\frac{1}{2\pi} \left( [-1,1] \text{ 上的 } \pi \right) * \left( [-1,1] \text{ 上的 } \pi \right)$$

$\pi$ 跟 $\pi$ 约掉、$\frac{1}{2\pi}$ 提出去，剩下的是**两个宽度 2、高度 1 的矩形卷积**，结果是 $[-2, 2]$ 上的三角形，峰顶在原点，峰值等于底宽的一半乘高度，也就是 $2 \times \frac{1}{2} \times \pi$：

```text
   F{ (sin t / t)^2 }  =  底 [-2, 2] 的三角形，峰顶在 0，峰值 pi

                    /\
                   /  \
                  /    \
        ---------/------\---------
              -2   0   2      > omega
                   峰值 = pi
```

然后用另一个性质——**傅里叶变换在 $\omega = 0$ 处的值等于原函数的积分**：

$$\int_{-\infty}^{+\infty} x(t) dt = X(j0)$$

在 0 点上是 $\pi$，答案立刻也出来了：

$$\int_{-\infty}^{+\infty} \left(\frac{\sin t}{t}\right)^2 dt = X(j0) = \pi$$

两种方法答案一样。看到这个巧合了吗？帕斯瓦尔本质上就是告诉你：**频域里 $\frac{1}{2\pi}$ 乘上 $|X|^2$ 的积分，等于时域里的模平方积分**；而方法二做的那件事——先求平方的变换、再取零点值——走的是"频域 $\to$ 时域"这条路。两边撞到同一个结果，是因为它们背后是同一条恒等式。

#### 书上例 3-16：两个条件解一个未知数

书上 134 页 3-16 是道典型的综合题。已知 $x(t) \stackrel{\mathcal{F}}{\longleftrightarrow} X(j\omega)$，且满足两个条件：

$$\mathcal{F}^{-1}\left[(2 + j\omega) X(j\omega)\right] = A e^{-t} u(t), \quad A > 0$$

$$\frac{1}{2\pi} \int_{-\infty}^{+\infty} |X(j\omega)|^2 d\omega = 1$$

求 $x(t)$。我个人觉得这种题出得不算好——它把两个完全不同的工具（乘常数多项式、逆变换、帕斯瓦尔）硬凑在一起。但既然出了，我们做一遍。

**第一个条件翻译成 $X(j\omega)$ 的方程。** $\mathcal{F}^{-1}[\cdot] = Ae^{-t}u(t)$ 的意思是：$Ae^{-t}u(t)$ 的傅里叶变换正好等于 $(2+j\omega)X(j\omega)$。而 $e^{-t}u(t)$ 的傅里叶变换是 $\frac{1}{1+j\omega}$（这是我们的第一个公式，直接用），所以

$$(2 + j\omega) X(j\omega) = \frac{A}{1 + j\omega}$$

解出来：

$$X(j\omega) = \frac{A}{(1+j\omega)(2+j\omega)}$$

这里可以**部分分式**拆开，而且拆得非常漂亮：

$$\frac{1}{(1+j\omega)(2+j\omega)} = \frac{1}{1+j\omega} - \frac{1}{2+j\omega}$$

（验算：右边通分后分子是 $(2+j\omega) - (1+j\omega) = 1$，对上了。）所以

$$X(j\omega) = A\left[\frac{1}{1+j\omega} - \frac{1}{2+j\omega}\right]$$

反变换逐项查表，$x(t)$ 就出来了：

$$x(t) = A\left(e^{-t} - e^{-2t}\right) u(t)$$

**现在只剩 $A$ 待定。** 第二个条件说的是什么？根据帕斯瓦尔定理，$\frac{1}{2\pi}\int|X|^2d\omega = 1$ 就是说**时域能量为 1**：

$$\int_{-\infty}^{+\infty} |x(t)|^2 dt = 1$$

把刚求出来的 $x(t)$ 代进去。因为有 $u(t)$，积分区间从 0 开始：

$$A^2 \int_{0}^{+\infty} \left(e^{-t} - e^{-2t}\right)^2 dt = 1$$

把平方展开成三项指数，各自积分：

$$A^2 \left( \frac{1}{2} - \frac{2}{3} + \frac{1}{4} \right) = 1 \quad\Longrightarrow\quad A^2 \cdot \frac{1}{12} = 1$$

所以 $A^2 = 12$，又因为题目给了 $A > 0$，**只取正根**。题目给这个 $A > 0$ 的条件就是为了让解唯一——如果没有它，$\pm 2\sqrt{3}$ 两个答案都合法（信号整体反号，能量不变）。

```text
   A 的确定：  A^2 · (1/2 - 2/3 + 1/4) = 1
                A^2 · 1/12 = 1   =>   A = 2*sqrt(3)   (A > 0)

   x(t) = 2*sqrt(3) * ( e^{-t} - e^{-2t} ) * u(t)

      |x(t)|
         ^
    1    |    /\
         |   /  \
   ------+--/----\---------------> t
        0 /        \
           峰值在 t = ln2 处，之后以 e^{-t} 衰减
```

这道题的方法值得记住：**先把 $X$ 从第一个条件里挖出来，再把 $A$ 从能量条件里定死**。别一上来就想凑 $x(t)$。

### 共轭性与共轭对称性：三句话就够了

现在进入今天的重点，书上 105 页 3.4.4。书上写得太繁琐，我不按书上的讲，我按我的想法讲：记住几句话，同时也记住这几句话背后的道理，就全知道了。

这一节我们会碰三句话：**实偶对实偶，实奇对虚奇**；**$x(t)$ 实则谱实部偶虚部奇**；**幅度谱偶、相位谱奇**。前两句话是同一件事的两次落地，第三句是第二句的直接推论。

#### 第一句：实偶对实偶，实奇对虚奇

> **定义**：若小的 $x(t)$ 是**实偶函数**，则大的 $X(j\omega)$ 是**实偶函数**；若小的 $x(t)$ 是**实奇函数**，则大的 $X(j\omega)$ 是**纯虚的奇函数**。

先说为什么这两句这么重要。考试上它是必考的点；对理解傅里叶变换本身，它也是核心——它等于告诉你，一个实信号的谱长什么样，能是几重奏。

**证明其实很好做**，从欧拉公式展开：

$$X(j\omega) = \int_{-\infty}^{+\infty} x(t) e^{-j\omega t} dt = \underbrace{\int_{-\infty}^{+\infty} x(t)\cos(\omega t) dt}_{A(\omega)} - j \underbrace{\int_{-\infty}^{+\infty} x(t)\sin(\omega t) dt}_{B(\omega)}$$

这两块分别叫实部和虚部（差一个负号而已），我们就看它们在 $x(t)$ 是实函数、偶函数、奇函数三种情况下分别发生什么。

**情形一：$x(t)$ 是实偶函数。**

先看**实不实**。因为 $x(t)$ 是实函数、$\cos(\omega t)$ 也是实函数（$\omega$ 和 $t$ 都是实数），两者相乘再积分，$A(\omega)$ 一定是实数；同理 $B(\omega)$ 也是实数。所以两块都是实数。

再看**哪一块消失**。$\sin(\omega t)$ 是 $\omega$ 的奇函数（也是 $t$ 的奇函数），而 $x(t)$ 是偶函数。**偶函数乘奇函数是奇函数**，奇函数从负无穷积到正无穷等于零。所以 $B(\omega) = 0$，虚部整块消失，只剩 $A(\omega)$。

最后看**偶不偶**。$A(\omega)$ 里换 $\omega \to -\omega$：因为 $\cos(-\omega t) = \cos(\omega t)$，积分值一模一样，

$$X(-j\omega) = X(j\omega)$$

得证：$X(j\omega)$ 既是实函数又是偶函数，即**实偶**。

```text
   x(t) 实偶  --F-->  X(jw) 实偶

   x(t):    ___                      X(jw):      ___
            |   |       (左右对称)              |     |
        ----|---|-----> t                       \___/      （实，无虚部）
        -T0  0  T0                               pi/T0
                                                    左右对称 = 偶
```

**情形二：$x(t)$ 是实奇函数。**

**实不实**：结论一样，两块各自都是实数。

**哪一块消失**：这次 $x(t)$ 是奇函数，$\cos(\omega t)$ 是偶函数，**奇乘偶还是奇**，积分等于零。所以 $A(\omega) = 0$，实部整块消失，只剩 $-j B(\omega)$。

**纯不纯虚**：$B(\omega)$ 是实数，前面挂个 $-j$，所以是**纯虚**函数。

**奇不奇**：$X(-j\omega)$ 里 $\omega$ 变号，$A$ 那块反正已经是 0 了，$-j$ 的负号从指数里拿出来刚好抵消，只剩 $B$ 部分变号；而 $\sin(-\omega t) = -\sin(\omega t)$，所以

$$X(-j\omega) = -X(j\omega)$$

得证：$X(j\omega)$ 是纯虚的奇函数。

举例印证一下。方波（$-T_0$ 到 $T_0$，高度 1）是实偶函数，它的谱 $2\frac{\sin(T_0\omega)}{\omega}$ 就是实偶的；$\text{sgn}$ 函数是实奇函数，取值 $+1 / -1$，它的谱是 $\frac{2}{j\omega}$，纯虚、纯奇。回头看看，$\frac{2}{j\omega} = -\frac{2j}{\omega}$，$\frac{1}{\omega}$ 是奇函数，$-2j$ 是纯虚常数，两个一乘，虚、奇，两个性质都占。

**另一种记法，更贴近直觉**：

> 若 $x(t)$ 是实偶函数，则它的傅里叶变换**只有余弦分量，没有正弦分量**；若 $x(t)$ 是实奇函数，则它的傅里叶变换**只有正弦分量，没有余弦分量**。

为什么？因为余弦是偶函数、正弦是奇函数。实偶信号跟偶函数（余弦）作用时，奇的那部分自动被积分成零，只剩下同类相乘；实奇信号同理，余弦那一半被积分掉，只剩正弦。推导跟上面一模一样，换了个说法而已。这句话在做题时其实更顺手——你一眼就能看出 $X(j\omega)$ 里哪些项会活下来。

#### 第二句：实信号的谱，实部偶、虚部奇

第一句只管了"完全对称"的那两种极端。第二句是它的延伸，而且我认为比第一句更好用：

> 若 $x(t)$ 是**实函数**，则 $X(j\omega)$ 的**实部是偶函数，虚部是奇函数**。

注意这里 $x(t)$ 只要求实，不要求偶或奇。

**证明的办法第一章第一节课就给了。** 任何一个函数都能拆成偶分量加奇分量：

$$x(t) = \underbrace{\frac{x(t) + x(-t)}{2}}_{x_e(t),\ \text{偶分量}} + \underbrace{\frac{x(t) - x(-t)}{2}}_{x_o(t),\ \text{奇分量}}$$

$x(t)$ 是实函数，所以它的偶分量、奇分量**也都是实函数**。再根据傅里叶变换的线性性质：

- $x_e(t)$ 是实偶函数 → 它的谱是**实偶**的 → 这个谱就是 $X(j\omega)$ 的实部 $\text{Re}[X(j\omega)]$，所以**实部是偶函数**；
- $x_o(t)$ 是实奇函数 → 它的谱是**纯虚奇**的 → 这个谱就是虚部 $j\,\text{Im}[X(j\omega)]$，所以**虚部是奇函数**。

> **易错点**：说"虚部是奇函数"时严格讲的是 $j\,\text{Im}[X(j\omega)]$，也就是虚部那个纯虚的表达式。如果你把 $X(j\omega) = A(\omega) - jB(\omega)$ 记成 $A$ 和 $B$，那么被 $j$ 放大的那一块（记作 $B$）在 $x$ 为实偶时等于 0、在 $x$ 为实奇时为实奇。两种记法都对，但做题时别把符号弄混。

把这两句合起来写成一对变换关系：

$$\frac{x(t) + x(-t)}{2} \stackrel{\mathcal{F}}{\longleftrightarrow} \text{Re}[X(j\omega)]$$

$$\frac{x(t) - x(-t)}{2} \stackrel{\mathcal{F}}{\longleftrightarrow} j\, \text{Im}[X(j\omega)]$$

也就是：**$X(j\omega)$ 实部的反变换是 $x(t)$ 的偶分量，虚部的反变换是 $x(t)$ 的奇分量**。为什么这么干净？因为傅里叶变换满足唯一性——$x(t)$ 的谱是 $X(j\omega)$（这个条件）加上 $x(t)$ 是实信号（这个条件），**两个条件缺一不可**；有了它们，谱的实部虚部就唯一地把偶分量奇分量分出来了。

而且这两句话是**双向对应**的：反过来，如果 $X(j\omega)$ 的实部是偶函数、虚部是奇函数，那么 $x(t)$ 一定是一个实函数。因为傅里叶变换是能反回去的，你可以自己证一遍。

```text
   实信号 x(t) 的"解剖图"

              x(t)   =  x_e(t)  +  x_o(t)
                       (偶分量)    (奇分量)

     x(t)                        x_e(t)                 x_o(t)
     ____                        ____                   __
    |    |        拆            |    |      +          |  \
  --+----+--> t          ==>  --+----+--> t  ---->  --+---+--> t
      \                            \                    \
                 偶+奇叠加           纯对称              左右反号
                                       |                   |
                                       v                   v
                                  实部 Re{X}          虚部 j Im{X}
                                  (实、偶)             (纯虚、奇)
```

#### 第三句：幅度谱偶、相位谱奇

现在把 $X(j\omega)$ 写成极坐标形式：

$$X(j\omega) = |X(j\omega)| e^{j\theta(\omega)}$$

这里 $|X(j\omega)|$ 叫**幅度谱**（幅度频谱的简称），$\theta(\omega)$ 叫**相位谱**。第三句话是：

> 若 $x(t)$ 是实函数，则 **$|X(j\omega)|$ 是偶函数，$\theta(\omega)$ 是奇函数**。

**证明几乎是白送的**，因为幅度和相位都能直接由实部虚部算出来——这就是高中复数运算那一套：

$$|X(j\omega)| = \sqrt{ \left[\text{Re}[X(j\omega)]\right]^2 + \left[\text{Im}[X(j\omega)]\right]^2 }$$

$$\theta(\omega) = \arctan\frac{\text{Im}[X(j\omega)]}{\text{Re}[X(j\omega)]}$$

按第二句：实部是偶函数、虚部是奇函数。**平方**之后，偶函数的平方还是偶，奇函数的平方也变成偶了；两个偶函数相加还是偶函数；再开个根号，仍然是偶函数。所以 $|X(j\omega)|$ 是偶函数。

相位谱这边：分子虚部是**奇**函数，分母实部是**偶**函数，**奇除偶得奇**；而 $\arctan$ 本身也是奇函数（$\arctan(-z) = -\arctan z$），所以复合之后 $\theta(\omega)$ 是奇函数。

```text
   x(t) 实  =>  Re{X} 偶 , Im{X} 奇
                     |        |
                     v        v
              平方后都变偶  -->  和是偶  -->  开根号
                     |
                     v
              |X(jw)|  幅度谱 = 偶函数      (左右对称的钟形)

              Im/Re = 奇/偶 = 奇  -->  arctan 也是奇  -->  相位谱 = 奇函数
              (原点附近通常有一个 ±pi/2 的跳变)
```

这条结论在工程上的意思值得体会一下：**一个实信号的频谱幅度必然左右对称**——你随便拿一段真实录音去看它的频谱图，左半边和右半边长得一模一样，连噪声的毛刺都是对称的。而相位谱是反对称的。这不是巧合，是数学强制的结果。

#### 例题 3-17：从实部反解出一个因果信号

最后来一道题，书上习题 134 页 3-17，也是这块相对难的一道：

> 若**实因果**信号 $x(t)$ 的傅里叶变换的实部为 $\text{Re}\{X(j\omega)\} = \frac{1}{\omega^2 + 1}$，求 $x(t)$。

**第一步，用第二句。** 实信号的谱，其实部的反变换就是 $x(t)$ 的偶分量：

$$\frac{1}{2}[x(t) + x(-t)] \stackrel{\mathcal{F}}{\longleftrightarrow} \frac{1}{\omega^2 + 1}$$

**第二步，带公式。** 这里要用一条书上 97 页最下面、98 页式 (3-52) 的**双边指数信号**公式：

$$e^{-a|t|} \longleftrightarrow \frac{2a}{a^2 + \omega^2}$$

这个公式我课上没讲，但书上自己推一下不难。取 $a = 1$，得 $e^{-|t|} \longleftrightarrow \frac{2}{1 + \omega^2}$，两边除以 2：

$$\frac{1}{2}[x(t) + x(-t)] = \frac{1}{2} e^{-|t|}$$

到这里我们手里只有 $x$ 的**偶分量**，还没拿到 $x$ 本身。把它画出来：

```text
   x(t) 未知                   x_e(t) = 1/2 e^{-|t|}  已知
   (实 + 因果)                (偶对称的衰减双肩)
      ?                              |
      |                         1/2 |*******
      |                             |  `----.
   ---+-----------> t           0 ---+-----.----> t
                                     |     `---
   x(t)=0 对 t<0                   0 |        |        (左右完全一样)
```

**第三步，用"因果"这个条件把 $x$ 补出来。** 因果信号的意思是 $x(t) = 0$ 当 $t < 0$，这是第一章的知识，推得出来。既然 $t < 0$ 时 $x(t) = 0$，那么偶分量表达式 $\frac{1}{2}[x(t) + x(-t)]$ 在 $t > 0$ 处就退化成 $\frac{1}{2}x(t)$。也就是说 $x_e(t)$ 的**右半边**是 $\frac{1}{2}x(t)$，把它抬回原位（翻倍）并往左延伸补零：

$$x(t) = e^{-t} u(t)$$

验证一下：$x(t) + x(-t)$ 在 $t>0$ 处是 $e^{-t} + 0 = e^{-t}$，$t<0$ 处是 $0 + e^{t} = e^{-|t|}$，除以 2 正好是 $\frac{1}{2}e^{-|t|}$ ✓，跟已知的偶分量完全吻合。

**第四步，也是最好玩的一步——把答案代回去检验。**

$$X(j\omega) = \mathcal{F}\{e^{-t}u(t)\} = \frac{1}{1+j\omega}$$

有理化：

$$\frac{1}{1+j\omega} = \frac{1-j\omega}{(1+j\omega)(1-j\omega)} = \frac{1-j\omega}{1+\omega^2} = \frac{1}{1+\omega^2} - j\frac{\omega}{1+\omega^2}$$

实部正好是 $\frac{1}{1+\omega^2}$，跟题目给的完全一致 ✓。而且顺便验证了第二句：实部 $\frac{1}{1+\omega^2}$ 是偶函数，虚部 $-\frac{\omega}{1+\omega^2}$ 是奇函数，一切自洽。

```text
   x(t) = e^{-t} u(t)             X(jw) = 1/(1+jw)

        /\                              .\
       /  \                            /   \
   ---+----\----> t                 --+-----\--> w
   -1     \                         -1       \
          \                                    \
    指数衰减(实+因果)            实部偶、虚部奇 = 满足全部约束
```

**变体：把"因果"改成"反因果"。** 反因果信号的意思是 $x(t) = 0$ 当 $t > 0$。这时候奇偶分解里的关系镜像过来，答案变成往左衰减：

$$x(t) = e^{t} u(-t)$$

- **提示**：这类题有一个共同的坑——题目经常不写"实"字。严格来说这不严谨，但在信号与系统里我们**默认所有时域信号都是实信号**（复信号在时域上基本只有理论意义），所以不写"实"字我们就按实的处理，这个意识要有。看到"实因果""实反因果"这类词组时，先把它们拆成两个独立约束分别用：**"实"** 用来把偶分量/奇分量分离出来，**"因果"或"反因果"** 用来决定往哪边补零。

$$\boxed{\ \frac{1}{1+t^2} \longleftrightarrow \pi e^{-|\omega|}\ }$$

**三、$\frac{1}{\pi t}$ 的傅里叶变换**（上次作业里要用的，课上叫"难题"）。

解析：先用 $u(t) \leftrightarrow \frac{1}{j\omega} + \pi\delta(\omega)$ 与 $1 \leftrightarrow 2\pi\delta(\omega)$ 相减拿掉 $\delta$ 项，再靠线性性质拼出

$$\frac{j}{\pi}\left[u(t) - \frac{1}{2}\right] \longleftrightarrow \frac{1}{\pi\omega}$$

然后对偶：$\frac{1}{\pi t} \leftrightarrow 2\pi \cdot \frac{j}{\pi}[u(-\omega) - \frac{1}{2}]$。

$$\boxed{\ \mathcal{F}\left\{\frac{1}{\pi t}\right\} = 2j\left[u(-\omega) - \frac{1}{2}\right]\ }$$

它就是希尔伯特变换，也叫 90 度移相器（$j = e^{j\pi/2}$，幅度不变、相位整体转 90 度）。这道题后面第五章还会用到。

**四、$\int_{-\infty}^{+\infty}\left(\frac{\sin t}{t}\right)^2 dt$。**

解析（法一，帕斯瓦尔）：$\frac{\sin t}{t} \leftrightarrow \pi$（限于 $[-1,1]$），故

$$\frac{1}{2\pi}\int_{-1}^{1}\pi^2\,d\omega = \frac{\pi^2 \cdot 2}{2\pi} = \pi$$

解析（法二，调制 + $\int x(t)dt = X(j0)$）：$\left(\frac{\sin t}{t}\right)^2 \leftrightarrow$ 底为 $[-2,2]$、峰顶在原点、峰值 $\pi$ 的三角形，取 0 点值得 $\pi$。

$$\boxed{\ \int_{-\infty}^{+\infty}\left(\frac{\sin t}{t}\right)^2 dt = \pi\ }$$

### 换元：尺度律是怎么来的

109 页 3.4.6，时间与频率的尺度变换。它说的是：若

$$x(t) \stackrel{\mathcal{F}}{\longleftrightarrow} X(j\omega)$$

则

$$x(at) \stackrel{\mathcal{F}}{\longleftrightarrow} \frac{1}{|a|} X\left(j\frac{\omega}{a}\right)$$

结论很短，但它是这一整节里唯一一个"看起来一眼就知道、证明起来却会卡住"的东西，所以我们老老实实证一遍。

从定义出发：$X(j\omega) = \int_{-\infty}^{+\infty} x(t) e^{-j\omega t} dt$。要算的是

$$\mathcal{F}[x(at)] = \int_{-\infty}^{+\infty} x(at) e^{-j\omega t} dt$$

换元。令 $at = t'$，于是 $t = t'/a$，$dt = dt'/a$。麻烦全在积分限上——$a$ 的符号会决定极限往哪儿走，所以我们必须分两个情况讨论。

#### a 大于零的时候

$t$ 从 $-\infty$ 走到 $+\infty$；因为 $a > 0$，$t' = at$ 是同向单调的，$t'$ 仍然从 $-\infty$ 走到 $+\infty$。积分限不用动。

代入后：$x(t') \cdot e^{-j\frac{\omega}{a}t'} \cdot \frac{1}{a} dt'$，把这几个 $t'$ 的撇都擦掉，指数再整理成 $\frac{\omega}{a} t'$，于是

$$\mathcal{F}[x(at)] = \int_{-\infty}^{+\infty} x(t') e^{-j\frac{\omega}{a}t'} dt' \cdot \frac{1}{a} = \frac{1}{a} X\left(j\frac{\omega}{a}\right)$$

对照上面那个公式，直接就对上了。这是 $a > 0$ 的情形。

#### a 小于零的时候

$t = -\infty$ 的时候乘上一个小于零的数，$t'$ 恰好变成 $+\infty$；同理 $t = +\infty$ 时 $t'$ 变成 $-\infty$。这两个积分限要交换。

交换积分限就等于前面多出一个负号（$(-\infty, +\infty)$ 区间反过来读是先从 $+\infty$ 到 $-\infty$，再取负号纠正），所以

$$\mathcal{F}[x(at)] = -\int_{-\infty}^{+\infty} x(t') e^{-j\frac{\omega}{a}t'} dt' \cdot \frac{1}{a} = -\frac{1}{a} X\left(j\frac{\omega}{a}\right)$$

而 $-\frac{1}{a} = \frac{1}{|a|}$（因为此时 $a < 0$，$|a| = -a$）。综合一和二：

$$\mathcal{F}[x(at)] = \frac{1}{|a|} X\left(j\frac{\omega}{a}\right)$$

> **易错点**：绝对值不是"记号偷懒"，它是两个分支合并的结果。考试里如果只写 $\frac{1}{a}$，一旦碰上 $a < 0$ 就整题错了。看公式时重点看两处：时域那边是 $a$（不是 $|a|$），幅度这边是 $\frac{1}{|a|}$，频率轴那边是除以 $a$。

### 口诀：时域胖，频域瘦

这个性质当然会有一些例题，但我觉得例题不是最重要的。真正重要的是它说明的那件事，我给大家归结成一句口诀：

> **时域胖，则频域瘦；时域瘦，则频域胖。**

先看一个例子验证口诀。幅度为 1、宽度为 $2t_0$ 的矩形脉冲（从 $-t_0$ 到 $t_0$），它的傅里叶变换我们前面写过了，是 $2t_0 \cdot \text{Sa}(t_0\omega)$。化简一下：

$$2t_0 \cdot \frac{\sin(t_0\omega)}{t_0\omega} = \frac{2\sin(t_0\omega)}{\omega}$$

$t_0$ 跟 $t_0$ 约掉，所以它就是 $\frac{2\sin(t_0\omega)}{\omega}$。

画图的话：$\omega = 0$ 的时候，两个 $\sin$ 的极限相约，得到 $2t_0$；整个形状是一个 $\text{Sa}$（也就是 $\sin x / x$），它的过零点分别在

$$\omega = \pm\frac{\pi}{t_0},\quad \pm\frac{2\pi}{t_0},\quad \pm\frac{3\pi}{t_0},\ \ldots$$

```text
            t₀ 小（时域瘦）              t₀ 大（时域胖）

时域  ┌────┐                          ┌────────────┐
   1 ┤    ├────                     1 ┤            ├────
      └────┘                          └────────────┘
   0 ┬───┬───→ t                    0 ┬────────────┬───→ t
     -t₀  t₀                           -t₀          t₀

频域  ╱╲    ╱╲                        ╱╲      ╱╲
     ╱  ╲  ╱  ╲      (幅度 2t₀)      ╱  ╲    ╱  ╲
  ───┴────┴────┴──→ ω             ───┴────┴────┴──→ ω
    -π/t₀  0  π/t₀                    -π/t₀  0  π/t₀
```

读图：横轴 $\omega$ 上第一对过零点在 $\pm\pi/t_0$。当 $t_0$ 比较大、时域在 $-t_0$ 到 $t_0$ 之间展得很宽（时域胖）的时候，这两个零点就往里压缩，离原点越来越近。时域越胖，频域越瘦——口诀成立。

（频谱幅度是 $2t_0$，零点按 $\pm k\pi/t_0$ 往两边无限延伸、交替正负。）

#### 为什么会这样：从压缩和展开看

假设 $a$ 是一个绝对值大于 1 的数。用第一章第一节课的知识，$x(at)$ 就是要把 $x$ 往里压；频率这边对应着除以 $a$，也就是乘以一个小于 1 的数，那就是**往外展**。这边压缩出来多少，那边就往外展开多少。

反过来，假设 $|a| < 1$，时域是往外展，频域就是往里压。跟上面一模一样。

所以一个信号只要时域胖，它一定在频域瘦；时域瘦，一定在频域胖。

#### 极端情况与"平缓"的另一种理解

最极端的情况是什么？

$$\delta(t) \stackrel{\mathcal{F}}{\longleftrightarrow} 1$$
$$1 \stackrel{\mathcal{F}}{\longleftrightarrow} 2\pi\delta(\omega)$$

$\delta(t)$ 在时域上只是一个冲击，瘦到了极致；而频域那边胖到了极致，是从 $-\infty$ 到 $+\infty$ 全是一条水平线。$1$ 正好反过来：时域胖到极致，频域瘦成一个 $2\pi$ 的冲击。

还有一种理解方式，我觉得比死记口诀更管用——**时域胖意味着在时域上变化很平缓**。

请认真想一下这是不是这么回事。一个信号在时域上很胖，意味着我到处都有它，它的变化很平缓。而变化很平缓的时候，它对应着的频率只在有限的一段范围内有值。为什么？回到这个公式：

$$X(j\omega) = \int_{-\infty}^{+\infty} x(t) e^{-j\omega t} dt, \qquad e^{-j\omega t} = \cos(\omega t) - j\sin(\omega t)$$

对于这样一个平缓的信号，你把它跟同样平缓的 $\cos$、$\sin$ 乘起来再积分，正负面积不相消，得到的值会比较大，甚至很大。反过来，对于一个变化比它剧烈得多的多的 $\sin$ 和 $\cos$，你看这个平缓的信号乘上去之后，它所有的积分区间上的点全都会互相抵消，整个积分趋近于零。

所以：**时域上变化很平缓的信号，它对应着的频率有可能就是一个带限信号**。

下节课我们会有一些有趣的实验展示。我会把好几个声音放出来给大家听，然后要大家去猜这些声音的频谱，就是 $X(j\omega)$，右边是那些图像，看一下你们能不能把声音和它们相对应的频谱相互对上号。核心就是这一条：你听起来比较平缓的声音，它在频域上一定是频带范围比较窄的；你听起来很高昂、高高低低起伏不断的声音，它在频带上一定是展得更宽的。这就是时间与频率变换告诉我们的道理。

### 对偶性：把一对变换对反过来用

110 页 3.4.7，对偶性。它说的是：若

$$x(t) \stackrel{\mathcal{F}}{\longleftrightarrow} X(j\omega)$$

则

$$X(t) \stackrel{\mathcal{F}}{\longleftrightarrow} 2\pi x(-\omega)$$

这里非常容易混，所以我把话说清楚。左边那个"大的 $X(t)$"，是把右边 $X(j\omega)$ 里面所有的 $\omega$ 换成 $t$，然后拿到左边；右边那个 $x(-\omega)$，是把左边小的 $x(t)$ 里面所有的 $t$ 用 $-\omega$ 替换掉。

```text
   已知的“左块”                       对偶换来的“右块”

   x(t)  ──F──▶  X(jω)      ⇒      X(t)  ──F──▶  2π x(-ω)
                       │                          │
                 ω 全部换成 t                t 全部换成 -ω
```

举两个例子大家就明白了。

第一个，$\delta(t) \stackrel{\mathcal{F}}{\longleftrightarrow} 1$。这是针对 $\omega$ 的 1。现在把这个 1 拿过来当作针对 $t$ 的 1，放到左边。它的傅里叶变换是什么？把 $2\pi$ 照抄，右边 $x(-\omega)$ 是把 $\delta(t)$ 里所有的 $t$ 换成 $-\omega$，得到 $\delta(-\omega)$。而

$$\delta(\omega) = \delta(-\omega)$$

这是因为 $\delta$ 是个偶函数。也可以用公式看：$\delta(at) = \frac{1}{|a|}\delta(t)$，代进去 $\delta(-\omega) = \frac{1}{1}\delta(\omega)$。所以结果就是 $2\pi\delta(\omega)$。

第二个例子更漂亮，我们下节课休息一下继续讲这个。

#### 方波与 Sa 的互证

我们已经知道：$-\tau$ 到 $\tau$、幅度为 1 的方波，它的傅里叶变换是 $2\tau\text{Sa}(\tau\omega)$，化简之后得到 $\frac{2\sin(\tau\omega)}{\omega}$ 这样的形式。

现在拿对偶性的公式来看。大的 $X(t)$ 是什么意思？就是把 $X(j\omega)$ 里所有的 $\omega$ 换成 $t$ 拿过来。它的傅里叶变换将会是"小的"乘 $2\pi$，也就是 $2\pi x(-\omega)$。

相当于把这个东西拿过来，同时把它的幅度乘了 $2\pi$；然后 $x$ 的 $-\omega$，你要把它沿着 y 轴翻转一下。但是由于它是一个偶对称的方波，所以翻转跟没翻转是一样的。

这样就得到那个非常著名的式子——我们的第五个公式。这里取 $\tau = 1$，方波就是 $-1$ 到 $1$ 高度为 1，它对应的大 $X$ 拿出来是 $\frac{2\sin t}{t}$，傅里叶变换等于 $2\pi$ 乘上方波。把两边的 2 都拿掉：

$$\frac{\sin t}{t} \stackrel{\mathcal{F}}{\longleftrightarrow} \pi \cdot \text{（[-1,1] 上的门函数）}$$

跟前面完全一致的。

#### 对偶性的证明

在讲怎么用对偶性搭积木之前，我还是先证明一下。这个证明不难。

先用反变换公式：

$$x(t) = \frac{1}{2\pi} \int_{-\infty}^{+\infty} X(j\omega) e^{j\omega t} d\omega$$

把 $2\pi$ 拿过来：

$$2\pi x(t) = \int_{-\infty}^{+\infty} X(j\omega) e^{j\omega t} d\omega$$

接下来把 $\omega$ 与 $t$ 相互交换。因为 $\omega$ 和 $t$ 只是一个变量而已，换了不犯法。右边 $X(j\omega)$ 变成大的 $X(t)$，$e$ 里面的 $j\omega t$ 交换之后仍然是 $j\omega t$，$d\omega$ 变成 $dt$，于是

$$2\pi x(\omega) = \int_{-\infty}^{+\infty} X(t) e^{j\omega t} dt$$

右边写一个负号出来，左边的 $\omega$ 也就跟着变成负号，这右边就是 $X(t) e^{-j\omega t}$，它刚好等于 $\mathcal{F}[X(t)]$。所以

$$\mathcal{F}[X(t)] = 2\pi x(-\omega)$$

证完。

#### 三道例题

对偶性是一种相对复杂的搭积木的方法。考题里如果用到对偶性来搭这块积木，会变得更加复杂。所以我们来看三道。

**第一题**：$\frac{1}{1 + jt}$ 的傅里叶变换等于多少？

因为要背公式：$e^{-t}u(t) \leftrightarrow \frac{1}{1 + j\omega}$。用 $t$ 拿过来，$\frac{1}{1+jt} \leftrightarrow 2\pi x(-\omega)$。你首先把 $2\pi$ 乘上去，$x(-\omega)$ 的意思是所有的 $t$ 用 $-\omega$ 去代。所以 $e^{-t}$ 就等于 $e^{\omega}$，$u(t)$ 呢就等于 $u(-\omega)$。答案

$$\frac{1}{1 + jt} \stackrel{\mathcal{F}}{\longleftrightarrow} 2\pi e^{\omega} u(-\omega)$$

**第二题**：$e^{-|t|} \leftrightarrow \frac{2}{\omega^2 + 1}$，那么 $\frac{1}{t^2 + 1}$ 的傅里叶变换是多少？

还是代公式 $2\pi x(-\omega)$。左边是把所有的 $\omega$ 变成 $t$，得到 $\frac{2}{1+t^2}$；右边 $2\pi$ 乘上小的 $x(-\omega)$，$e$ 的负 $t$ 用 $-\omega$ 去代，这里有个绝对值，$|-\omega|$ 就是 $|\omega|$。所以

$$\frac{2}{1+t^2} \stackrel{\mathcal{F}}{\longleftrightarrow} 2\pi e^{-|\omega|}
\quad\Longleftrightarrow\quad
\frac{1}{1+t^2} \stackrel{\mathcal{F}}{\longleftrightarrow} \pi e^{-|\omega|}$$

**第三题是道难题**：求 $\frac{1}{\pi t}$ 的傅里叶变换。这道题上一次布置作业的时候要用到。

这就不是那么容易写出来了。它之所以难，是因为你得先"转好几道弯"才能把已知的东西凑出来。而且这个傅里叶变换有个专门的名字，叫**希尔伯特变换**，第五章还会再大致讲一下。

我们的做法是这样。第一步，先反过来问：什么东西的傅里叶变换等于 $\frac{1}{\omega}$？

大致是一个 $\text{sgn}$ 函数。如果你记不得，我把过程再给你做一遍：因为

$$\mathcal{F}\{u(t)\} = \frac{1}{j\omega} + \pi\delta(\omega)$$

又因为

$$\mathcal{F}\{1\} = 2\pi\delta(\omega)$$

所以这边拿一个 $\frac{1}{2}$ 来，这两个一减：

$$\mathcal{F}\left\{u(t) - \frac{1}{2}\right\} = \frac{1}{j\omega}$$

根据线性性质，$j$ 可以拿到左边来：

$$\mathcal{F}\left\{j\left[u(t) - \frac{1}{2}\right]\right\} = \frac{1}{\omega}$$

当然你也可以把 $\pi$ 拿到这里来，写成 $\frac{1}{\pi\omega}$。它是用几种东西搭出来的：$u(t)$，$\frac{1}{2}$，一减得到 $\frac{1}{j\omega}$，再把 $j$ 乘回去。

第二步，再用对偶性质。这边把 $\frac{1}{\pi\omega}$ 拿过来，$X(j\omega)$ 变成 $X(t)$，这里将会得到 $\frac{1}{\pi t}$ 的傅里叶变换。它等于 $2\pi x(-\omega)$：把 $2\pi$ 抄过去，然后把这个东西拿过去，把所有的 $t$ 变成 $-\omega$，

$$2\pi \cdot \frac{j}{\pi}\left[u(-\omega) - \frac{1}{2}\right]$$

$\pi$ 跟 $\pi$ 约掉，这里将会得到

$$2j \left[u(-\omega) - \frac{1}{2}\right]$$

画一下它的图，可能能够得到更清楚一点。$u(\omega)$ 翻转过去就是 $u(-\omega)$，在负半轴是 1、正半轴是 0；$u(-\omega) - \frac{1}{2}$ 刚好把它往下挪，负半轴变成 $\frac{1}{2}$、正半轴变成 $-\frac{1}{2}$；$2$ 拿过来跟它一乘，变成 1 和 $-1$；再接下来还有一个 $j$ 不要忘了。

| $\omega$ | $u(-\omega) - \frac12$ | $2j\left[u(-\omega) - \frac12\right]$ | 相位 |
| :--- | :--- | :--- | :--- |
| $\omega < 0$ | $+\frac{1}{2}$ | $+j$ | $+90°$ |
| $\omega > 0$ | $-\frac{1}{2}$ | $-j$ | $-90°$ |

所以最后得到的结果，$\frac{1}{\pi t}$ 的傅里叶变换正半轴是 $-j$、负半轴是 $j$，也就是 $-j\,\text{sgn}(\omega)$。这个东西我们叫做 90 度的移相器——因为乘以一个 $j$ 的话，由于 $j = e^{j\frac{\pi}{2}}$，正负半轴的相位分别被推到 $+90°$ 和 $-90°$，所以我们把这个东西叫做 90 度的移相器。

这种题就是难题了，但是你用对偶性质，也能很自如地把它做出来。

### 帕斯瓦尔定理：能量守恒

3.4.8 帕斯瓦尔定理。它说的是：若 $x(t) \leftrightarrow X(j\omega)$，则

$$\int_{-\infty}^{+\infty} |x(t)|^2 dt = \frac{1}{2\pi} \int_{-\infty}^{+\infty} |X(j\omega)|^2 d\omega$$

这叫做帕斯瓦尔定理。它的意思是：**傅里叶变换能量守恒**。

换句话说，在时域上，模的平方从负无穷到正无穷大积分叫做求能量。时域上的能量跟频域上的能量是相等的，差一个 $\frac{1}{2\pi}$ 的系数。

#### 证明

这个证明相对来说还不是那么容易，我试着给大家做一遍。

$$\int_{-\infty}^{+\infty} |x(t)|^2 dt = \int_{-\infty}^{+\infty} x(t) x^*(t) dt$$

这个东西叫做共轭。换句话说，$a + jb$ 它的共轭将等于 $a - jb$。

把反变换公式带进来：

$$x(t) = \frac{1}{2\pi} \int_{-\infty}^{+\infty} X(j\omega) e^{j\omega t} d\omega$$

这里加一个共轭，就等于：

$$x^*(t) = \frac{1}{2\pi} \int_{-\infty}^{+\infty} X^*(j\omega) e^{-j\omega t} d\omega$$

因为 $e^{j\omega t}$ 的共轭就等于 $e^{-j\omega t}$。

把 $x^*(t)$ 代入原式：

$$\int_{-\infty}^{+\infty} x(t) \left[ \frac{1}{2\pi} \int_{-\infty}^{+\infty} X^*(j\omega) e^{-j\omega t} d\omega \right] dt$$

然后交换一下积分次序，把 $\frac{1}{2\pi}$ 拿到外面：

$$\frac{1}{2\pi} \int_{-\infty}^{+\infty} X^*(j\omega) \left[ \int_{-\infty}^{+\infty} x(t) e^{-j\omega t} dt \right] d\omega$$

方括号里这个东西就是正变换的公式，它刚好是 $X(j\omega)$。所以

$$\frac{1}{2\pi} \int_{-\infty}^{+\infty} X^*(j\omega) X(j\omega) d\omega = \frac{1}{2\pi} \int_{-\infty}^{+\infty} |X(j\omega)|^2 d\omega$$

证好。

#### 例题：$\int_{-\infty}^{+\infty} \left(\frac{\sin t}{t}\right)^2 dt$

这道题有两种方法可以做。

**方法一**，直接用帕斯瓦尔。假设 $x(t) = \frac{\sin t}{t}$，你想想它的傅里叶变换是什么？直接代公式能够把它做出来——因为 $\frac{\sin t}{t}$ 的傅里叶变换是一个门函数，在 $[-1, 1]$ 之间值为 $\pi$。根据帕斯瓦尔定理：

$$\int_{-\infty}^{+\infty} \left(\frac{\sin t}{t}\right)^2 dt = \frac{1}{2\pi} \int_{-\infty}^{+\infty} |X(j\omega)|^2 d\omega = \frac{1}{2\pi} \int_{-1}^{1} \pi^2 d\omega = \frac{1}{2\pi} \cdot \pi^2 \cdot 2 = \pi$$

你如果死去做积分，稍微是有点难度的。

**方法二**，直接算这个东西平方的傅里叶变换，然后求它在 0 那个点的值，也是一样的。

$\left(\frac{\sin t}{t}\right)^2$ 的做法是 $\frac{\sin t}{t} \cdot \frac{\sin t}{t}$。根据调制性质，它的傅里叶变换等于 $\frac{1}{2\pi}$ 乘以这两个东西傅里叶变换的卷积，也就是两个在 $[-1, 1]$ 幅值为 $\pi$ 的门函数进行卷积：

$$\frac{1}{2\pi} [\text{门函数}] * [\text{门函数}]$$

$\pi$ 跟 $\pi$ 约掉，$\frac{1}{2}$ 拿过来，这两个东西卷积最后将等于一个三角形，区间在 $[-2, 2]$，在 0 这个点的值是 $2 \times \frac{1}{2} \times \pi = \pi$。

再根据这个性质：

$$\int_{-\infty}^{+\infty} x(t) dt = X(j0)$$

在 0 这个点上是 $\pi$，马上就得到它的答案也是 $\pi$。两种方法做出来的答案都是一样的。

#### 书上例题 3-16

书上 134 页 3-16。它说的是：$x(t) \leftrightarrow X(j\omega)$，且满足以下两个条件。

第一个条件：

$$\mathcal{F}^{-1}\{(2 + j\omega)X(j\omega)\} = A e^{-t} u(t), \quad A > 0$$

第二个条件：

$$\frac{1}{2\pi} \int_{-\infty}^{+\infty} |X(j\omega)|^2 d\omega = 1$$

求 $x(t)$。

第一个条件它的意思是这个逆变换是它，就意味着

$$\mathcal{F}\{A e^{-t} u(t)\} = (2 + j\omega)X(j\omega)$$

而这里的傅里叶变换直接代公式，它应该等于 $\frac{A}{1 + j\omega}$。所以这两个东西相等：

$$(2 + j\omega)X(j\omega) = \frac{A}{1 + j\omega}$$

你直接能够得到：

$$X(j\omega) = \frac{A}{(1 + j\omega)(2 + j\omega)} = A \left( \frac{1}{1 + j\omega} - \frac{1}{2 + j\omega} \right)$$

（这一步的部分分式很好验：两个分母相减的分子正好是 1。）

所以接下来 $x(t)$ 将会等于：

$$x(t) = A (e^{-t} - e^{-2t}) u(t)$$

现在只是这个 $A$ 待确定。根据帕斯瓦尔定理，第二个条件说的是：

$$\int_{-\infty}^{+\infty} |x(t)|^2 dt = 1$$

代进来得到：

$$A^2 \int_{0}^{+\infty} (e^{-t} - e^{-2t})^2 dt = 1$$

把积分积出来：$(e^{-t}-e^{-2t})^2 = e^{-2t} - 2e^{-3t} + e^{-4t}$，所以

$$A^2 \left( \frac{1}{2} - \frac{2}{3} + \frac{1}{4} \right) = A^2 \cdot \frac{1}{12} = 1$$

又由于 $A > 0$，只取正的那一个数，$A = 2\sqrt{3}$，整个题目就解决了。

#### 实偶对实偶，实奇对虚奇

第一句话：**实偶对实偶，实奇对虚奇**。这是重点，除了考试是重点，对于傅里叶变换的理解，这里也是重点。

它的意思是：如果 $x(t)$ 是关于 $t$ 的实偶函数，那么它的傅里叶变换 $X(j\omega)$ 也是关于 $\omega$ 的实偶函数；如果 $x(t)$ 是实奇函数，那么它的 $X(j\omega)$ 是一个纯虚的奇函数。

我们先来证明一下。把指数拆开：

$$X(j\omega) = \int_{-\infty}^{+\infty} x(t) e^{-j\omega t} dt = \underbrace{\int_{-\infty}^{+\infty} x(t) \cos(\omega t) dt}_{\text{实部}} - j \underbrace{\int_{-\infty}^{+\infty} x(t) \sin(\omega t) dt}_{\text{虚部}}$$

根据这个公式我们就来分析。假设 $x(t)$ 是一个实函数，同时它是一个偶函数：

首先第一点，当 $x(t)$ 是实函数，$\cos$ 和 $\sin$ 都是实函数，你能够马上得到这两块积分本身都是实函数。再接下来，假设 $x(t)$ 是偶函数——偶函数乘以奇函数等于奇函数，负无穷到正无穷大积分等于 0——虚部这一块将会等于 0。那么 $X(j\omega)$ 就只有实部这一块，因此它也是实函数。

我们再来看它是不是偶函数。如果把 $\omega$ 变负，$\cos(-\omega t) = \cos(\omega t)$，所以 $X(-j\omega) = X(j\omega)$，它也是偶函数。这就是实偶对实偶的原因。

接下来我们证明实奇对虚奇。$x(t)$ 是一个实奇函数：这里 $x(t)$ 是实函数，两块积分都是实函数。由于 $x(t)$ 是奇函数，奇函数乘以偶函数得到奇函数，积分等于 0，实部这一块等于 0，那就只剩下虚部这一块。这一块是实函数，加了一个 $-j$，它就变成了一个纯虚函数。在实部等于 0 的情况下，如果把 $\omega$ 变负，$\sin(-\omega t) = -\sin(\omega t)$，负号提出来，它刚好等于 $-X(j\omega)$，所以它是一个奇函数。这就是实奇对虚奇。

```text
实偶 x(t)  ──F──▶  只有 cos 分量，X(jω) 是实偶
实奇 x(t)  ──F──▶  只有 sin 分量，X(jω) 是虚奇
```

当你掌握了实偶对实偶和实奇对虚奇的时候，你看傅里叶变换的样子，你会觉得很有趣。你看这里比如说一个方波，$-t_0$ 到 $t_0$ 这里是 1，它的傅里叶变换——它是实偶函数，它的傅里叶变换一定是实偶函数，它大致是 $\text{Sa}$ 这个形状，这里是实偶，这里也必然是实偶。

你再看这里，这是 $\text{sgn}$ 函数：这是实奇函数，正半轴是 1、负半轴是 $-1$。它的傅里叶变换等于 $\frac{2}{j\omega}$，它是一个虚奇函数。你仔细去看，你会发现这个道理是完全没有问题的。

#### 实部偶，虚部奇

第二句话更重要。若 $x(t)$ 是实函数，则 $X(j\omega)$ 的实部是偶函数，虚部是奇函数。

为什么？原因在这——把 $x(t)$ 拆成偶分量加奇分量，这是第一章第一课的内容：

$$x_e(t) = \frac{x(t) + x(-t)}{2}, \qquad x_o(t) = \frac{x(t) - x(-t)}{2}$$

前者是偶函数，后者是奇函数。根据傅里叶变换的线性性质，$X(j\omega) = \mathcal{F}\{x_e\} + \mathcal{F}\{x_o\}$。因为 $x(t)$ 是实函数，偶分量和奇分量也都是实函数——所以这里是实偶函数，这里是实奇函数。实偶对实偶，$\mathcal{F}\{x_e\}$ 得到的就是 $\text{Re}\{X(j\omega)\}$，也就是 $X(j\omega)$ 的实部，它是实偶；加上一个 $j$ 倍的 $\text{Im}$，这是虚部，实奇对虚奇，所以说虚部这里是奇函数，是虚奇。

所以你知道了这两条，马上就能够证明它是偶函数、它是奇函数：就是它的实部是偶函数，虚部是奇函数。

> **提示**：这句话反过来也是对的。如果 $X(j\omega)$ 实部是偶函数、虚部是奇函数，$x(t)$ 一定是一个实函数。你自己想一下，因为傅里叶变换它是能够反回去的。请大家注意，这里是相互对应的——实偶对应实偶，你自己回去证一下就知道，这两个东西完全相互对应。

这句话还能够换一种说法：若 $x(t)$ 的傅里叶变换是 $X(j\omega)$，且 $x(t)$ 是实函数，则

$$\frac{x(t) + x(-t)}{2} \;\longleftrightarrow\; \text{Re}\{X(j\omega)\}, \qquad \frac{x(t) - x(-t)}{2} \;\longleftrightarrow\; j\text{Im}\{X(j\omega)\}$$

这两个也是对的。为什么呢？由傅里叶变换的唯一性你很容易就能看出来：偶分量的傅里叶变换是 $X(j\omega)$ 的实部，奇分量的傅里叶变换是 $X(j\omega)$ 的虚部。这里当然也是对的。

要注意的是，"$x(t)$ 是实函数"和"$x(t)$ 的傅里叶变换是 $X(j\omega)$"这两个条件缺一不可。

#### 幅度谱偶，相位谱奇

第三句话是上次没有讲完留的一个尾巴。若 $x(t)$ 是实函数，设

$$X(j\omega) = |X(j\omega)| e^{j\theta(\omega)}$$

这里 $|X(j\omega)|$ 叫做幅度谱（幅度频谱简称幅度谱），$\theta(\omega)$ 叫做相位谱。则幅度 $|X(j\omega)|$ 是偶函数，同时 $\theta(\omega)$ 是奇函数。

证明起来非常容易。因为幅度谱和相位谱，你有了傅里叶变换的实部和虚部过后，可以用这两个公式算出来——这其实就是高中学过的复数运算：

$$|X(j\omega)| = \sqrt{\text{Re}^2\{X(j\omega)\} + \text{Im}^2\{X(j\omega)\}}$$
$$\theta(\omega) = \arctan\left(\frac{\text{Im}\{X(j\omega)\}}{\text{Re}\{X(j\omega)\}}\right)$$

又由于第二条里说了它的实部是偶函数、虚部是奇函数，所以这个平方了过后两个都是偶函数，偶函数相加也是偶函数，开个根号这里仍然是偶函数，所以幅度谱就是偶函数。

而相位谱呢，由于上面的虚部是奇函数、下面的实部是偶函数，这样一除，奇函数除以偶函数得到奇函数，$\arctan$ 也是一个奇函数，所以 $\theta(\omega)$ 是一个奇函数，相位谱是一个奇函数。

#### 例题 3-17：已知实部与因果性求原信号

书上的习题 3-17，134 页 3-17，是一道经典题目，我试着给大家做一遍。

> 若**实因果**信号 $x(t)$ 的傅里叶变换 $X(j\omega)$ 的实部 $\text{Re}\{X(j\omega)\} = \frac{1}{\omega^2 + 1}$，求 $x(t)$。

就这么一句话，这道题该怎么做了？

首先，实的信号，根据第二点，实信号的傅里叶变换的实部对应的傅里叶反变换就是 $\frac{x(t) + x(-t)}{2}$。所以通过这样一个条件，你马上能够得到：

$$\frac{x(t) + x(-t)}{2} \stackrel{\mathcal{F}}{\longleftrightarrow} \frac{1}{\omega^2 + 1}$$

接下来你要背公式、代公式。这个公式不是最常用，待会儿我也会讲到，叫做双边指数信号 97 页最下面的那个公式（书上 98 页 3-52）：

$$e^{-a|t|} \stackrel{\mathcal{F}}{\longleftrightarrow} \frac{2a}{a^2 + \omega^2}$$

代这个公式（取 $a = 1$，分子 $\frac{1}{1+\omega^2}$ 正好对上）你马上能够得到：

$$\frac{x(t) + x(-t)}{2} = \frac{1}{2} e^{-|t|}$$

所以接下来你把它画出来：$\frac{1}{2}e^{-|t|}$ 在 0 的时候是 $\frac{1}{2}$，然后朝下拖下去，它是一个偶函数，大致是这样：

```text
   x(t)=e^{-t}u(t)      x(-t)=e^{t}u(-t)        [x(t)+x(-t)]/2
 1 ┤╲                   ╱│                      ┌─╲────  1/2
   │ ╲                 ╱ │                     ╱        ╲
 0 ┼──╲────→ t       ─┼─┼────→ t            ──┼──────────┼──→ t
      0                 0                       0
```

（图中 $x(t)$ 在 $t<0$ 处为 0，是因果的；$x(-t)$ 是它沿 y 轴的翻转；两者相加除以 2，恰好是那个偶的双边指数。）

再接下来，你还要用到的叫做**因果信号**。因果信号的意思是什么呢？因果信号的意思是，你看 $x(t)$ 因果，这是第一章的知识：你可以推出来 $x(t) = 0$ 当 $t < 0$ 时。

你能够推出它，然后接下来你能够猜出来 $x(t)$ 将会是什么东西吧？$x(t)$ 在 $t < 0$ 的时候是 0，所以 $x(t) + x(-t)$ 把它翻转了回来除以 2 得到 $\frac{1}{2}e^{-|t|}$，那么 $x(t)$ 就应该是把它往上延伸的这样一个信号。

为什么呢？因为如果 $x(t)$ 是它，它既满足因果，同时你看 $x(t) + x(-t)$ 这里将会得到的就是 1 为高的双边指数；然后 $\frac{x(t) + x(-t)}{2}$ 的话它将会是 $\frac{1}{2}$ 为高的双边指数。所以说 $x(t)$ 就是它。写出来：

$$x(t) = e^{-t}u(t)$$

这是最后的答案。

**如果你把条件稍微改一下**，在这里多加一个字，叫做**反因果**信号。什么叫反因果信号呢？反因果信号的意思是 $x(t) = 0$ 当 $t > 0$ 的时候。那么这种情况下 $x(t)$ 就会变掉，它会变成 $t = 0$ 处为 1 然后往正方向拖下去的一个信号，写出来是：

$$x(t) = e^{t}u(-t)$$

所以说如果是反因果信号的话，得到的将会是这个答案。

最后再做一个验证。假设这里是因果，我们得到 $x(t) = e^{-t}u(t)$。你试着看一下它的实部是不是这个 $\frac{1}{1+\omega^2}$：$e^{-t}u(t)$ 的傅里叶变换等于 $\frac{1}{1+j\omega}$，这是你的第一个公式。它等于

$$\frac{1}{1 + j\omega} = \frac{1 - j\omega}{(1 + j\omega)(1 - j\omega)} = \frac{1 - j\omega}{1 + \omega^2} = \frac{1}{1 + \omega^2} - j\frac{\omega}{1 + \omega^2}$$

它的实部刚好就是它，实部是偶函数、虚部是奇函数，没有任何的矛盾。你可以看到它也满足这个限制条件，非常容易能够验证。

> **易错点**：出题的时候如果不加"实"这个字，严格地说是不严谨的——只给实部是定不出 $x(t)$ 的（虚部还差一个 $j$ 的符号自由度），所以"实"字和"因果/反因果"这两个条件缺一不可。不过我们在信号与系统里面分析的所有时域的信号，默认都是实信号——虚数信号在时域上只有理论意义，我们基本上分析的都是实信号。所以不写这个"实"字，基本上也是可以的，虽然出题不那么严谨，但我们默认时域上所有的信号都是实信号。

## 理想低通滤波器

### 回到调制与解调：它到底被用在哪两处

先把调制和解调的过程再写一遍，因为理想低通滤波器就是从这里冒出来的。

设两个基带信号 $x_1(t)$、$x_2(t)$。调制的动作是把它们各自搬上自己的载波，再加起来送出去：

```text
   调制：把两个基带信号各自搬上自己的载波

     x1(t) -->[ x sin(wc1 t) ]--+
                                +-->( + )--> y(t) = x1(t)sin(wc1 t) + x2(t)sin(wc2 t)
     x2(t) -->[ x sin(wc2 t) ]--+

   解调：乘回各自的载波，再各接一个低通

     y(t) -->[ x sin(wc1 t ) ]-->[ LPF ]--> x1(t)
     y(t) -->[ x sin(wc2 t ) ]-->[ LPF ]--> x2(t)
```

解调端这两个方框里写的就是低通滤波器。它们不是"顺手加上的"——它们之所以必须是这个样子，正是因为我们要讲的理想低通滤波器。

而且请注意一件事：**它在调制这一端也被用到了**。

### 理想低通滤波器的严格定义

我们先给它一个严格的定义。它的时域表达式是

$$h(t)=\frac{\sin\omega_c t}{\pi t}$$

在频率上是

$$H(\omega)=\begin{cases}1, & |\omega|\le \omega_c\\[4pt] 0, & \text{其他}\end{cases}$$

这里的 $\omega_c$ 就叫**截止频率**，左边是 $-\omega_c$，右边是 $+\omega_c$。这就是书上给的定义。

> **定义**：时域是一个以 $t=0$ 为中心的 sinc 波形、频域是一块以原点为中心的矩形通带的滤波器，就叫理想低通滤波器。

你可能会问：这里通带的幅度我写的是 1，为什么不是 2？写 2 行不行？

行，完全行。你能做出幅度是 1 的，也能做出幅度是 2 的——因为做幅度比较容易。**关键不是这个系数，关键是你必须做出 $\sin(\omega_c t)/\pi t$ 这个式子，同时频域得是这么一块矩形。** 所以以后我们会看到各种系数写法的理想低通滤波器，它们说的是同一件事，不要被系数晃到。

### 带限信号是怎么来的

那它为什么这么重要？因为调制端也要用它。

假设有一个 $x(t)$，它的频谱 $X(\omega)$ 一般是什么样子的？是一路无限延伸下去的曲线——频率轴上哪儿都不为零。这样的信号怎么变成一个**带限信号**？

就在频域上乘一个理想低通滤波器。把 $X(\omega)$ 乘上 $H(\omega)$，把绝对值大于 $\omega_c$ 的部分全部变成 0，剩下的就限制在 $-\omega_c$ 到 $\omega_c$ 之间了，这样就得到了一个带限信号。

```text
   frequency domain:  X(w) ---[ x ]--- H(w) ---[ keep only -wc <= w <= wc ]--> X(w)H(w)
   time domain:       x(t) ---[ * ]--- h(t)  = sin(wc t)/(pi t)                 --> y(t)
```

看到这两行了吧——**在频域上是相乘，在时域上就是卷积**。把 $x(t)$ 卷积上 $\sin(\omega_c t)/\pi t$，它的傅里叶变换拿回来，就是一个带限信号。

> **结论**：带限信号不是天生长成这样的，它是拿理想低通滤波器滤出来的。

### 调制端不做这一步会怎样

我要问大家一个问题：如果在调制端不做这样的滤波，直接把 $x(t)$ 送进去，会有什么结果？

你自己去分析一下调制的那个过程就会发现：如果输入的不是带限信号，那么它们的频谱会在某些频段范围内混叠，以至于最后谁都解不出一个比较好的信号。

所以在这种情况下，把每段频谱的频宽限制在一个合理的范围内，是非常重要的。

这就像一个人扛着大包小包上车。每一个车上、每一趟民航都有规定：你的行李箱不能超过 20 kg 这样的平台限制。频宽就是那个行李。这就是同一个道理——我们必须用低通滤波器把这件事做出来。

所以理想低通滤波器要被认真研究，是因为它非常有用：调制端、解调端，都在用它。

### 书上那一版：多出来的一个时延

我这里写的和书上稍微有那么一点点不一样。请大家看书上的定义：时域上多了一个 $t_0$，

$$h(t)=\frac{\sin[\omega_c(t-t_0)]}{\pi(t-t_0)}$$

频域上的幅频部分和我们一样，但相位多了一个负指数：

$$H(\omega)=e^{-j\omega t_0},\qquad |\omega|\le\omega_c$$

换句话说，书上那一版和我这里写的相比，就是多了一个 $t_0$。

多一个 $t_0$ 是可以被接受的。为什么可以接受？你自己推一下就知道了。假设

$$y_1(t)=x(t)*\frac{\sin\omega_c t}{\pi t},\qquad y_2(t)=x(t)*\frac{\sin[\omega_c(t-t_0)]}{\pi(t-t_0)}$$

卷积对延时是可交换的，两个结果之间只差一个整体平移：

$$y_2(t)=y_1(t-t_0)$$

在我们实际做低通滤波系统的时候，一个微小的延时是可以被接受的。打个比方：我们拿起麦克风说话，声音进到麦克风里、被这一套低通系统处理、再放大送出去，中间有那么一点点的时间差——这是可以被接受的。理想低通滤波器带上这么一点 $t_0$ 的延迟，谁也不会有意见。

> **结论**：后面分析的时候我只用第一种形式（$t_0=0$）。因为一和二是一样的——既然已经知道二只比一多一个延时，那我只要分析完一，分析二的时候把所有结果加上一个延时就行了。方便、简单。

### 第一个软肋：非因果

理想低通滤波器的缺点有两个。第一个叫**非因果**，第二个我待会儿讲。

先看第一个。为什么它是非因果的？看它的时域波形 $\sin\omega_ct/\pi t$。

在 $t=0$ 的时候它取 $\omega_c/\pi$；然后向两边无限延伸，过零点的位置依次是 $\pm\pi/\omega_c$、$\pm2\pi/\omega_c$、$\pm3\pi/\omega_c$……一直到无穷远。这就是第二章里学过的 sa 函数（Sinc 函数），一个偶函数，两边对称地一直振荡下去。

第二章 53 页 2.3.3 讲过 LTI 系统的因果性：要让整个 LTI 系统是因果的，前提条件是这个 $h(t)$ 在 $t>0$ 的时候有值，而在 $t<0$ 的时候没有值。

但这里 $h(t)$ 在 $t<0$ 明显还有一大堆值。这将导致什么结果？如果你看 $h(t)$ 的图看不出来，就把 $y(t)$ 的卷积再写一遍：

$$y(t)=x(t)*h(t)=\int_{-\infty}^{+\infty}x(\tau)\,\frac{\sin[\omega_c(t-\tau)]}{\pi(t-\tau)}\,\mathrm{d}\tau$$

我要说的是：对于每一个 $t$，它需要的输入 $x(\tau)$，是从 $-\infty$ 到 $+\infty$ 全都要的。

> **易错点**：因果系统的判据不是"输入不含未来成分"这么含糊的一句话，而是 $h(t)=0$（当 $t<0$）。判据落在冲激响应上，别落在时域卷积的直觉上。

这意味着什么呢？假设我想做一个低通滤波器，目的是比如说把我的声音变得更加低沉一点。那么如果我用理想的低通滤波器，它的意思是什么呢？

它的意思是：我从头到尾无限地说下去，它说"把这整个话全说完了"，然后他才对这个低通滤波器进行处理，然后才能够得到每个 $y(t)$ 时刻的值。

那么我们想做一个麦克风，或者我们想做一个实时的通信，可不可以？如果 $h$ 是非因果的，我们做不出来。因为它要求 $t$ 时刻的输出，不只需要 $t$ 之前的 $x(t)$ 的值，它还要求 $t$ 之后的 $x(t)$ 的值——可是 $t$ 之后的值还没有发生，它怎么能够拿到 $t$ 之后的 $x(t)$ 的值？

所以要做实时的通信系统，非因果是做不出来的。

### “物理上不可实现”这句话，我觉得有歧义

这里经常有一个误解。书上会这么说，大家也会这么说：理想低通滤波器物理上不可实现。

我觉得这句话是有歧义的。请大家认真听我说。

假设我们现在把一段音频拿出来，比如某一个人做了大概一个小时的讲话，我们把这一段一个小时的音频用理想低通滤波器对它进行处理，得到 $y(t)$，可不可以？

**当然是可以的。** 因为我们已经知道在这一个小时里每一个点上 $x(t)$ 的值了，在这种情况下用理想低通滤波器，是能够把这一整段音频处理出来的。

但是如果把条件变成实时性呢？一个人正在讲话，我通过麦克风讲话，我这一套低通系统要实时地对它的声音进行处理。那么在 $t$ 这个时刻，我们能获得的是 $t$ 这个时刻之前他讲话的 $x(t)$ 的值，$t$ 之后的值我们没有办法获得，那么用这个公式就算不出来了。

> **结论**：更准确的一句话应该是——**理想低通滤波器不能实现实时的 LTI 系统**，而不是笼统地说它"物理上不可实现"。录下来的一段音频，它当然可以处理。

但由于它做不出实时的系统，这本身已经是一个非常大的局限了。这就意味着我们没有办法实现实时的通话和通信。

那接下来我们怎么做呢？因为我们要做的事情是要做一个因果的 $h(t)$——换句话说，我们要做一个 $h(t)$，让 $t<0$ 的时候它都等于零。

怎么做到？现在大家的知识还做不到。学完第七章之后，或者在数字信号处理当中，有很多知识专门教大家怎么做，这叫**滤波器设计**。它第一位的诉求就是：做一个近似的、但是因果的 $h(t)$，部分地代替和实现理想低通的功能。

### 第二个软肋：年轮效应

理想低通滤波器的第二个大问题，叫**年轮效应**。这个词是我自己的总结，不是书上的说法。一和二我们慢慢讲。

> **定义**：理想低通滤波器会把陡峭的上升沿信号，变成一环一环、逐渐衰减的波纹，这种波纹就叫年轮。

书上 127 页图 3-32 有这个例子：它把一个陡峭的上升沿 $u(t)$ 在零这个时刻从零跳变到 1，通过理想低通滤波器之后，波形会变成一圈一个的波纹振荡，一直震荡到无穷远。书上把它叫做**衰减振荡**。

书上有老大一堆推导。我们先看直观的感觉，直觉对了，推导就容易做了。

#### 主瓣和旁瓣

理想低通滤波器在时域上的图形 $\sin(\omega_ct)/\pi t$ 我们都很熟了。它的过零点依次是 $\pm\pi/\omega_c$、$\pm2\pi/\omega_c$、$\pm3\pi/\omega_c$……，波形如下：

```text
   h(t) = sin(wc t) / (pi t)
   zeros at +-p, +-2p, +-3p, ...  (p = pi/wc)

                                        ###
                                       ## ##
                                      #     #
                                     #*     *#
                                    ##       ##
                       #####       ##         ##       #####
  ######################---###----##-----------##----###---######################--> t
                  ##         ######             ######         ##
  |            |      |     |     |      |      |     |     |      |            |
  -6p            -4p      -3p     -2p     -p      0      p     2p     3p      4p            6p
  main lobe ~1.18, first side lobes ~0.09 each
```

请大家记住这几样东西。中央最大的那一瓣，我们叫它**主瓣**（main lobe）；它左右紧邻的两瓣，叫**旁瓣**（side lobe）。

> **提示**：这批专有名词记住就行——主瓣、旁瓣，后面讲滤波器设计的时候还会一直用到。

这几个面积我们用积分算一下。归一化之后：

- 主瓣的面积大约是 **1.18**；
- 两个第一旁瓣，每瓣面积大约是 **0.09**；
- 再往外的第二旁瓣、第三旁瓣、第四旁瓣更小，我记得大概是 0.03 还是 0.02 上下。

请注意，**这三个数字只是一个比例关系**——意思是假设主瓣是 1.18，那么两个第一旁瓣每一个都是 0.09。你可以自己回去试着做一下积分验证。

#### 卷积怎么一步步算出来

$y(t)=u(t)*\dfrac{\sin\omega_ct}{\pi t}$ 就是拿这两样东西来卷积。卷积三步：翻转、平移、相乘求和。

这里第一步可以省掉：$h(t)$ 是一个偶函数，**翻转跟不翻转是一样的**。这一点请大家想清楚。

然后就是平移。我们以 $u(t)$ 的跳变点为零为界，看它往右移。

```text
   u(t) = 1 :        _______|_______

   t = 0     jump sits at the centre of the main lobe
             overlap area = half of the whole sinc integral = 1/2

   t = p      jump has moved right, the first zero crossing has just
             passed under it
             area = 1.18 - 0.09 = 1.09          (maximum)

   t = 2p     the fat part of the main lobe has moved past zero
             area = 1.18 - 0.09 - 0.09 = 1.00   (minimum)

   t -> +inf  every new side lobe that comes in is smaller than the last:
             the positive part pushes the value up a little, a bigger
             negative part pushes it back down -> oscillation, forever decaying
```

我们一个一个来试。

**$t=0$ 的时候。** 你算的是这边的面积。因为整个 $\sin(\omega_ct)/\pi t$ 在 $-\infty$ 到 $+\infty$ 上积分是等于 1 的——这是第一章学过的内容——而它又是偶函数，所以这边记一半刚好是 $\frac12$。于是 $y(0)=\frac12$。

**$t>0$，朝右边逐渐移动。** 这时候跟它卷积的面积从来都是超过零的，这一块的面积将会不断增大。什么时候达到最大？请大家认真想一想——大致就是移动到第一旁瓣刚好越过零点的时候，也就是 $t=\pi/\omega_c$。

这个最大值是多少？是这里的 1.18 减去这里的 0.09，约等于 **1.09**。

**再朝右移。** 因为主瓣中间那一大块已经跑到零的右边去了，所以它将会不断逐渐地减小。什么时候到最小？到 $t=2\pi/\omega_c$ 的时候，就是这里 1.18 减 0.09 再减 0.09，大概是 **1.00** 左右。

**再往右。** 后面的这些东西又过来了，它又会增大一些。但是你会看到这次的峰值是 1.00，比上一次的 1.09 小；再下一个峰就更小。

为什么会这样？因为它的**旁瓣越来越小**。每一个旁瓣进来的时候，上面大于零的地方进来，它增大一点点；小于零的地方移出去，它又减少一点点。两个作用叠加起来，以至于导致的结果就是，它在不断地、越来越小。

所以它这里将会是一个不断衰减的振荡。

再看**向左移**，也就是求 $t<0$ 时候的值。你可以看到，这就是右边关于零点的镜像：它跟右边重合的部分越来越小，大概是一个朝下的走势。当左移了 $\pi/\omega_c$ 这么多的时候，纵坐标约等于 **负的 0.09**；再往外，第二旁瓣、第三旁瓣再来一轮，同样是逐渐衰减的振荡。

这就是我们说的，用理想低通滤波器会出现这种逐渐衰减振荡的**年轮效应**。

### 年轮效应的后果与滤波器的设计准则

这意味着什么意思？如果你用理想低通滤波器去处理信号，对于这种快速上升的信号，它将会出现年轮的效应。

你可以在声音信号当中想象一下：本来是没有声音的，突然有个人喊了一嗓子——突然没有，突然有——这就是一个快速上升的信号。如果说这个信号经过理想低通滤波，大家想一想这个声音将会是什么样子？

它将会先是一小会儿那种类似于杂音似的东西，然后往下降、再往下降，变成一个很弱的、要逐渐逐渐趋于无穷远的东西——在时间轴上将会拖出一条朝无限远逐渐衰减的尾巴。

如果是图像呢？假设你用理想低通滤波器处理一幅二维的图像，比如这里是一个橙色的太阳区域，底下是黑色的背景。把它通过理想低通之后会变成这样：首先这个橙色变淡了一些，往外走变得更淡；然后隔了一小圈，又出现一圈橙色；再远一点，还有一小圈更弱的。你会发现它是一圈一圈的，越往外那一圈越大，也越往外越淡。这个就是年轮效应导致的。

于是我们在设计滤波器的时候，就有了一个非常大的准则：**在时域上增加主瓣面积，减少旁瓣的面积。**

> **结论**：主瓣面积占比更大、旁瓣面积更小的滤波器，是一个更好的滤波器——它能比较好地降低年轮的效应。

所以大家后面学到很多设计滤波器的方法——巴特沃斯滤波器、切比雪夫滤波器、椭圆滤波器等等——它们都有一个非常重要的参数，就是**主瓣面积和第一旁瓣面积各自占总面积的比例**。

现在回头看就明白为什么这个要被叫作"理想"低通滤波器、又为什么它基本上不用了：由于非因果和年轮效应太强这两个缺点，在真正的滤波器设计里它基本上是不用的。我们用到的都是一些经过了近似之后的东西——首先，所有实时通信系统当中的低通滤波器全都是因果的；其次，各种滤波器设计方法想了很多很多种，其目的都是为了增加主瓣面积、减小旁瓣面积，让这种逐渐衰减的振荡变得更加在可控的范围之内。

### 阶跃响应：把答案写成 Si 函数

最后把书上的一些推导写一写，就是理想低通滤波器的阶跃响应。

我们要求的是 $u(t)$ 卷积理想低通滤波器的冲激响应：

$$y(t)=u(t)*\frac{\sin\omega_c t}{\pi t}=\int_{-\infty}^{+\infty}u(\tau)\,\frac{\sin[\omega_c(t-\tau)]}{\pi(t-\tau)}\,\mathrm{d}\tau$$

把 $u(\tau)$ 这个部分拿掉——它只有在 $\tau>0$ 的时候才不为零——所以积分区间变成从 $-\infty$ 到 $t$：

$$y(t)=\int_{-\infty}^{t}\frac{\sin[\omega_c(t-\tau)]}{\pi(t-\tau)}\,\mathrm{d}\tau$$

现在把它写成能用的形式。我们把它拆成两半来看。

**第一项**，也就是积到 0 为止的那一段。由于 $\sin(\omega_ct)/\pi t$ 在 $-\infty$ 到 $+\infty$ 上积分为 1，而它又是偶函数，所以这一项直接等于 $\frac12$。

**另外一项**，做一个换元会好看一点。令 $\tau'=\omega_c\tau$，那么

- $t-\tau$ 变成 $\dfrac{t-\tau'}{\omega_c}$；
- $d\tau=\dfrac{\mathrm{d}\tau'}{\omega_c}$；

$\omega_c$ 一进一出刚好约掉，剩下 $\pi$ 分之一：

$$\frac{\omega_c}{\pi}\cdot\frac{1}{\omega_c}\int_0^{\omega_c t}\frac{\sin\tau'}{\tau'}\,\mathrm{d}\tau'=\frac{1}{\pi}\int_0^{\omega_c t}\frac{\sin\tau'}{\tau'}\,\mathrm{d}\tau'$$

书上把 $\int_0^x\dfrac{\sin\tau}{\tau}\mathrm{d}\tau$ 这个函数专门记作 **Si 函数**：

$$\mathrm{Si}(x)=\int_0^{x}\frac{\sin\tau}{\tau}\,\mathrm{d}\tau$$

于是阶跃响应就可以写成这么干净的样子：

$$y(t)=\frac{1}{2}+\frac{1}{\pi}\mathrm{Si}(\omega_c t)$$

Si 函数画出来大概是这样：过一个原点、不断衰减的振荡曲线：

```text
   step response   y(t) = 1/2 + Si(wc t)/pi
   (the flat line is the ideal unit step level 1)

                                              #####
  -------------------------------------------##---####-##########################   <-- u(t) = 1
                                            #        ###
                                           ##
                                          *#
                                          #
                                         ##
                                         #
                                        ##
                                        #
                                       #*
                                      ##
                           ###        #
  ##########################-####---##---------------------------------------------> t
                                #####
  |            |      |     |     |      |      |     |     |      |            |
  -6p            -4p      -3p     -2p     -p      0      p     2p     3p      4p            6p
  max ~ 1.09 at t = p          min ~ -0.09 at t = -p
```

这里最高能到多少？$\mathrm{Si}$ 在 $x=\pi$ 处取到正的最大值，约为 1.85，除以 $\pi$ 约等于 0.59，于是阶跃响应在 $t=\pi/\omega_c$ 处达到 $\frac12+0.59\approx1.09$；反过来，在 $x=-\pi$ 处取到负的最小值约 $-1.85$，阶跃响应在 $t=-\pi/\omega_c$ 处就是 $\frac12-0.59\approx-0.09$。

**这两个数字，前面算年轮效应的时候我们已经算出来过一次了**——完全对得上。

书上式 (3-156) 和式 (3-157) 基本上说明了这个问题，和我这里推导的是完全一样的。

## 把两句话装进一个声音：调制解调、频谱与滤波器的演示课
> 对应块：BLK38 | 覆盖分集：P28 | 块标题（分集名）：《第三章MATLAB程序演示(信号的调制与解调、理》

先听两段声音。一段是我念书，另一段是别人念的——把它们塞进同一个文件里，听上去还是一个人在正常说话，你根本听不出里面藏了什么；然后再从这个文件里把两段声音分别取出来，一模一样。有意思吧？这一节课的代码，就是干这两件事的。顺手还会带出两个更要紧的问题：频谱上你到底能看出什么，以及滤波器作用在图像上的时候，到底发生了什么。

### 读入两个声音：双声道、采样频率与时长

MATLAB 里第一步就一句话：

```matlab
[x1, fs] = audioread('voice1.wav');
```

在这句后面打个断点，运行，看第一个声音被读进来到底是什么。`x1` 是一个 **1460724 × 2** 的数组。

> **易错点**：为什么是乘以 2？

因为这个声音有左声道和右声道，两个声道，所以要乘以 2。它是一列一列存的，左右声道各占一列。你要是在命令行里直接敲 `x1`，它会把一百万多个点全打出来，屏幕根本显示不完，得按 `Ctrl+C` 停下来。只看左声道就写 `x1(:, 1)`——一个冒号代表第一个维度的全部，再加个 `,1`，就是只取第 1 列，也就是左声道；右声道是 `x1(:, 2)`。这里为什么会用冒号，等下讲调制公式的时候会再撞回来一次。

接下来还要把 `fs` 也读出来，它跟这段声音同样重要。

> **定义**：`fs` 叫**采样频率**，告诉你这个声音文件每秒钟采了多少个点。

这里 `fs = 44100`，就是每秒钟 44100 个点。那么每一个点对应的时间间隔就是 $1/44100$ 秒。这一点第五章会正式讲，现在你只要知道它意味着"一秒钟被切成了多少片"就够了。

现在我给大家算一笔账。`x1` 一共 1460724 个点，每秒 44100 个点，那么这段声音持续了多少秒？

$$
T = \frac{1460724}{44100} = 33.1230 \ \text{秒}
$$

在 MATLAB 里验证：

```matlab
n = size(x1, 1);      % 1460724
n / fs                % 33.1230
```

`x2` 同样处理，持续 20.4330 秒。

| 信号 | 数组大小 | 采样频率 | 时长 |
| :--- | :--- | :--- | :--- |
| `x1` | 1460724 × 2 | 44100 Hz | 33.1230 s |
| `x2` | — | 44100 Hz | 20.4330 s |

> **提示**：我很喜欢 MATLAB 的一个地方，就是你在运行的过程当中可以随时跑到命令行里，查查看所有你想看的值。往上翻箭头还能把以前执行过的操作恢复回来。所以这种"一行一行加断点、跑一步看一眼"的演示方式才玩得起来——换成写个完整脚本一次跑完，你根本不知道中间发生了什么。

### 调制的核心公式，以及 `t` 到底是什么

`x1` 和 `x2` 长度不一样，不能直接相加。统一长度这一步其实很简单：**把比较短的那个声音用零去占位、加长到最长那个的长度**。跑完这一步，两个信号就一样长了。

调制的核心是这一个式子：

$$
y(t) = x_1(t)\cos(\omega_{c1}t) + x_2(t)\cos(\omega_{c2}t)
$$

一眼就能看出，这不就是两路基带信号各自乘一个载波再叠加嘛。载波频率我们仍然用 `f` 来设定：

```matlab
fc1 = 8000;    fc2 = 27000;
w1  = 2*pi*fc1;    w2 = 2*pi*fc2;     % ωc1 = 2π·fc1, ωc2 = 2π·fc2
```

现在到了最该认真想一想的细节。请大家盯着这一行：

```matlab
t = (0:N-1)/fs;
```

公式里的 `t` 是时间，是一个标量；可这里是**一串数组**，每一个元素代表一个采样点。而 $1/f_s$ 的含义是——每个点持续 $1/f_s$ 秒。所以 MATLAB 里第 $i$ 个点（$i$ 从 1 数起）对应的时间就是

$$
t_i = \frac{i-1}{f_s}
$$

这一步想清楚了，后面所有东西都顺了。你编程序的时候，这些细节会被不断地拿来拷问你：`t` 在这里是标量还是数组？`1/fs` 到底是干什么的？第 `i` 个点到底是第 `i/fs` 秒还是第 `(i-1)/fs` 秒？想不清楚，代码就一定跑不对。

把整句加起来：

```matlab
N = max(length(x1), length(x2));     % 统一到最长那个的长度
x1(end+1:N) = 0;   x2(end+1:N) = 0; % 短的那个用零占位
t = (0:N-1)/fs;
x3 = x1.*cos(w1*t) + x2.*cos(w2*t);  % 调制的核心公式
audiowrite('voice1_and_voice2_after_modulation.wav', x3, fs);
```

> **易错点**：`audiowrite` 的第三个参数千万别忘了，那就是 `fs`——你得告诉它这个文件每秒钟采了多少个值，否则写出来的东西时间轴是错的，播放速度会不对。

`audiowrite` 前面两句，也就是取左声道那两句，我特意留在前面写了：这里读出来是两声道，我们只取左声道，右声道是一样的。这样每一个 `x` 就都只是一个 $N\times 1$ 的向量了，后面才方便。

来听一下 `x3`。这两个声音的载波频率分别被搬到了 8000 Hz 和 27000 Hz——听上去就是**完全混在一起的一团乱码**，你一个字也听不出来。

这里有一个很有意思的现象，后面讲理想高通的时候会再遇到：明明是两个人在说话，两个不同频率的载波，听起来却像一团乱码；但它确实完整地携带了这两段信息，等下就能原样取回来。

### 解调：一个低通滤波器还原一切

解调在数学上简单得让人怀疑：把 `x3` 各自再乘一次**同一个载波**，然后过同一个低通滤波器。

```matlab
x1_after = x3 .* cos(w1*t);     % 乘回 8000 Hz 的载波
x2_after = x3 .* cos(w2*t);     % 乘回 27000 Hz 的载波
```

这两个信号里面，除了我们要的那一路以外，还混着一堆别的东西：`x1` 乘回自己的载波，变成了直流加两倍频；`x2` 乘上 `x1` 的载波，变成了两个载波之差和两个载波之和。所以必须再过一遍低通——注意，是**前面已经建好的那一个**低通滤波器，代码不用重写，直接拿来用。

```matlab
x1_demod = filter(b, 1, x1_after);
x2_demod = filter(b, 1, x2_after);
audiowrite('voice1_after_demodulation.wav',  x1_demod, fs);
audiowrite('voice2_after_demodulation.wav',  x2_demod, fs);
```

听一下 `voice1_after_demodulation.wav`——"高明"，跟原来一模一样；再听 `voice2_after_demodulation.wav`——"决策树……规则……"，也完全恢复出来了。

> **结论**：整个调制—解调程序就这么点代码。它真正在做的事情，是让两段信号在频域上互不重叠地各占一段，各自乘载波搬个地方，接收端再乘回来、用同一个低通把搬去的地方以外的东西全部滤掉。

#### 那个低通滤波器是怎么来的

程序里低通滤波器用 `fp` 来设：

```matlab
fp = 3000;              % 截止频率 3000 Hz
wp = 2*pi*fp;           % ωp = 2π·fp = 2π×3000
wn = fp / (fs/2);       % 归一化：设计滤波器时必须除以 fs/2
b  = fir1(N, wn);       % FIR 低通滤波器系数（具体设计要到第七章）
y  = filter(b, 1, x1);  % 过一遍，得到 x1_lp
```

`ωp = 2π · fp` 这一句大家应该已经很熟了，角频率和频率之间就差一个 $2\pi$。真正要问的是：**为什么要除以 `fs/2`？**

因为设计滤波器的时候要先把整个频率轴**归一化**。归一化的意思就是把频率除以奈奎斯特频率 $f_s/2$，把整个频轴压到 $[0,1]$ 上去，这样设计出来的系数才是和采样率无关的纯数字。

这里用的是 **FIR 低通滤波器**，不是理想低通。原因我以前说过：理想低通那一大堆问题，这一节大家还不见得能看得懂，要到第七章大家才能真正看懂它是怎么"实现"的。

> **提示**：那把 3000 Hz 截止的低通过一遍，声音听起来几乎没有区别。因为普通人的声音、以及电话信号，频谱基本上在 4000 Hz 就截止了；我这里是 3000 Hz。除非你是个很高很high音的歌唱家，不然我觉得普通人的声音，3000 Hz 基本上够了。第二个人的声音能稍微听出低了一点点——低通滤波器所做的事就是把高的频率给去掉，整个声音当然会变低。待会儿我会弄一个极端的案例，就是一个高音歌唱家，你们到时候再好好体会。

### 把两个载波拉近：混叠，还有小时候调不准的收音机

好，程序跑通了，我们试点别的。**我把其中一个载波改成 1 万赫兹**，也就是把 8000 和 27000 拉到很近很近，重新运行，再听解调出来的结果。

结果是：两个信号将会混叠，双方都解不出来，或者解出来的效果很差。

原理不难想：两路信号乘上载波以后在频域上是要分开摆放的，你解调的时候靠的就是"低通能把其它频率的东西滤掉"这一件事。一旦两个载波靠得太近，被滤掉的那一路就躲进了保留的那一路的范围里，低通拦不住了，混进输出成为干扰。你听一下，会发现还能捞回来一点点，但已经糊得不成样子了。

> 这个现象你们不觉得熟悉吗？就像我小时候收收音机，搜不准的时候，就是这个情况。实际上收音机搜不准，多半就是频率偏了，两边的信号混在了一起，也会听到一些串台的声音。

### 幅度谱是偶函数，相位谱是奇函数

我们看这两个声音的频谱。这是声音一的时域波形，这是声音二的时域波形；这是声音一的**幅度谱** $|X(j\omega)|$，这是它的**相位谱** $\angle X(j\omega)$。

先讲一个你们可能从来没仔细想过的结论：

> **定义**：对于一个**实信号**，它的幅度谱是**偶函数**，相位谱是**奇函数**。

幅度谱那条曲线是关于纵轴对称的，这不用多说。相位谱那条就有点意思了——它看上去杂乱无章，完全看不出什么规律。真的，你回去自己运行程序，把那个相位谱放大到最大再看：**它是关于原点中心对称的**，那就是奇函数。别的地方有点缺，这边也有个缺，这边短的缺对应那边短的，这边长长的缺对应那边长长的缺——那就是奇函数。

> **易错点**：这条结论只对**实信号**成立。$X(-j\omega)$ 才是 $X^*(j\omega)$ 的这件事，请自己回去推一遍，这里我不展开。

下面来一个当场的小测验。我放两个声音——第一个，"决策树与哈哈哈……"；第二个，是那段讲规则的——然后我问大家：哪一个是声音一，哪一个是声音二？

大多数人指着高频分量多的那个说："它在这里高频的分量比这声音要多得多。"

对的，完全正确。

> **结论**：高频分量多，意味着远离零点的那些幅度谱的值会更多一些。你看这张谱——高频那一侧鼓起来了，所以对应的就是声音二。

学到这门课的最高境界是什么？是**你听一个声音，就能大致知道它的频率成分长什么样**。这就是现在你们在做的事。

> 下节课我再做一个实验：把两张图和它们对应的频谱图分别画出来，再让你们来选一次。

### 图像是二维信号：二维理想低通与"能量都往低频跑"

声音是一维信号，**图像是二维信号**。频率在图像里有两个维度，所以二维的理想低通滤波器大概长这个样子：在频率域上靠近原点的那一片取 1，其他地方取 0。

如果要给二维理想低通滤波器"照一张相"，你会看到频率平面上一个很亮的圆圈，圆圈里面很亮、外面很黑。

```text
        二维理想低通 H(u,v)              一维理想低通 |H(jw)|
              (u,v) 平面                        w 轴
        ┌───────────────┐
        │               │
        │      ●        │   圆内取 1（很亮）
   -wc  │    (0,0)      │  wc
        │               │
        └───────────────┘

        圆外取 0（很黑）                 |<-- wc -->|<-- wc -->|

        等价说法：把一维的理想低通绕着纵轴（w 轴）转一圈
```

再看一张原图，它的频谱图（也就是做一次傅里叶变换）大致是这样的形状：能量**高度集中在零附近**这一小片低频区域。

> **结论**：除非是特别乱的那种噪声图，我们人眼能看到的图，相对来说都是低频分量更多。

为什么？我给大家说一点点知识，我觉得需要大家记住：**低频分量对应的是变化。**

- **变化缓慢的，贡献低频分量。** 比如图里某个亮的点，周围一圈都是黑的，邻居的像素值都差不多，这一块在像素上就是缓慢的变化，它贡献的是低频。
- **大片连续的同色区域也是缓慢变化。** 比如整块黑色的背景，一整片都是均匀的，它同样贡献一大片低频。
- **变化剧烈的贡献高频分量。** 比如噪声，黑点白点在同一个空间里剧烈跳变，全是高频。
- **有规律性的重复，贡献一个确定的频率亮点。** 你看这张图横轴上，每隔一小段就有一个黑点，每个间隔都差不多。如果这个间隔是某个固定的值，那么这圈黑点就会在频谱图上贡献出一个**亮亮的点**。这里的 `'a'`、那里的 `'a'`，不断按一定节奏重复，就会在某个固定的频率上打出一个亮点。

这一点刚才在声音的例子里非常明显：歌唱家突然来一个特别高的音，那一下快速变化对高频分量起作用；而我刚才念书那种比较缓慢的声音，作用就更多落在低频分量上。

所以我常说，有经验的同学看到一张频谱图，几乎就能猜出原图长什么样——虽然我不能说哪个点对应哪个。

### 年轮效应，以及理想高通

我们来看图过一遍二维理想低通滤波器：左边两张是原图，中间是理想低通，右边是结果。

这个叫做**年轮效应（振铃）**。

它表现为：帽子的边缘被放大了，边缘那一条被不断地放大、以波纹的形式传递到整张图上；这张脸的边缘会变得更加模糊；同时这些波纹状的东西向四周扩散，一圈一圈地叠起来，最后形成一张模模糊糊的图片。右边这张更明显——比如那个 `'a'` 的边缘，它被传到了这儿、又传到了这儿，影响逐渐向外传递。

**核心就在那个年轮效应。**

理想的**高通**滤波器跟理想的低通刚好是反着的。它的冲激响应可以直接写出来，是单位冲激减去理想低通那一项：

$$
h(t) = \delta(t) - \frac{\omega_c \sin(\omega_c t)}{\pi t}
$$

所以：

- 低通的时候，是把**低频分量**通过，也就是把图像缓慢的变化通过；
- 高通的时候，是把**高频分量**通过，也就是把图像快速的变化通过。

看高通的结果吧：图像的边缘被强调了，每一条边缘都亮起来，其余地方基本全是黑的。

> **易错点**：为什么高通的结果几乎全是黑的？因为在正常的图像和声音里，低频分量本来就更多。这可能是多年进化的结果——在一个图像或声音产生的空间里，相邻的点大致都是相似的，缓慢变化才是常态。所以低频分量天然占大头，高通自然只剩边缘那点信息。理想高通只把边缘信息保留住，其他全部去掉，看起来就是这样。

理想低通的另一个用法是改变 $\omega_c$ 的大小来控制保留的能量。把 $\omega_c$ 由小变大（半径一路调到 230 像素），保留的能量依次是 92%、94.6%、96.4%、98%、99.5%。你看到保留下来的能量越来越高时，得到的图跟原图就越来越没有区别了；保留 99.5% 的时候，几乎看不出差别。

> **提示**：理想低通有两个绕不开的毛病——**非因果、无法实施**，还有**明显的年轮效应**。下面这一节就是冲着这两条来的。

### 巴特沃斯滤波器：能搭电路、能实时，3 dB 截止频率

> **定义**：**巴特沃斯（Butterworth）低通滤波器**是最著名的一种低通滤波器，它的幅度响应是

$$
|H(j\omega)| = \frac{1}{\sqrt{1+\left(\dfrac{\omega}{\omega_c}\right)^{2n}}}
$$

注意这里是 **$2n$ 次方**，不是平方。$n$ 是阶数。

它的相位我就不细说了，但这是一个特别不好的消息：**只有理想低通有线性相位**。其他滤波器，你要非常精确地设计，才可能有线性相位。巴特沃斯的相位大致形如 $e^{-j\theta(\omega)}$ 这种缓慢变化的因子，跟理想低通的线性相位相比还是有一些差距的。

巴特沃斯最大的特点是：**它可以用电路搭出来。** 电阻串联各种电容和电感，有一个公式直接告诉你：有 $k$ 个级别的时候，每一级的电容和电感大致取什么值，照着搭就能得到一个巴特沃斯滤波器。

> **结论**：一个物理上可以用电路实现的滤波器，就意味着它是**因果的**——它的系统函数 $h(t)$ 是因果的。这就是它相对理想低通最实在的优势。

#### 幅度响应上三个躲不掉的定点

我们画 $|H(j\omega)|$：

```text
 |H(jw)|
 1.0  ●  (w=0 恒为 1)
      |\
      | \
      |  \____
0.707 |----●---------------●------   三个定点，n 怎么变都不动
      |     \____     ____/
      |          \___/
 0.0  +------------------------------> w
        -wc        0        +wc
```

- $\omega = 0$ 时，值是 **1**；
- $\omega = \pm\omega_c$ 时，值是 $1/\sqrt{1+1} = \sqrt{1/2} \approx 0.707$；
- $|\omega| \to \infty$ 时，值趋近于 **0**。

不管 $n$ 取多少，这三个点都是一样的，变的只有中间下弯的陡峭程度。

那我考大家一个问题：图上画了三条不同 $n$ 的曲线，蓝色、白色、橙色，**最大的 $n$ 是哪一条？**

想一下——**$n$ 越大，衰减越快**。所以橙色是最大的 $n$，蓝色是最小的 $n$。阶数越高，过渡带越窄，截止点之后掉得越快。

#### 截止频率为什么是 3 dB

对任何一个低通滤波器，我们把**幅度掉到 $1/\sqrt2 \approx 0.707$ 的那个频率**叫做**截止频率**，也写作 $\omega_c$。用分贝表示：

$$
20\lg\left(\frac{1}{\sqrt2}\right) \approx -3\ \text{dB}
$$

所以叫 3 dB 衰减点。

> **易错点**：为什么理想低通不这么定义？因为理想低通是"刀切"的：$|\omega| < \omega_c$ 是一，$|\omega| > \omega_c$ 就是零，中间根本没有过渡带。但是我们在设计真实滤波器的时候，必须用一些**缓慢的变化**去过渡。所以我们人为地规定：滤波器的截止频率定义为 **3 dB 衰减**处。
>
> 所以以后你们看到任何题目说"截止频率是多少"，心里就应该自动翻译成"3 dB 衰减点在哪"。不管设计的是哪个滤波器，规则都是这一条。

#### 相对理想低通，年轮效应小得多

对比一下：左边是理想低通，右边是巴特沃斯低通。它跟理想低通比，最大的优势不是主瓣、也不一定是第一旁瓣，而是**第二、第三以及更远的旁瓣比理想低通要小**。

结果就是：**年轮效应会变得更小。** 理想低通那边能看到很大一圈这样的圆环，巴特沃斯这边第一圈还是黑的，但更远处就没有了——因为它的第二、第三及更远的旁瓣更小，波纹往外扩的成分就少了。低通和高通都是这个样子。

不过它也不是万能的。那张图巴特沃斯还是搞不定，原因是**这张图的边缘信息实在太多了**，年轮效应还是会有一定的叠加。这是问题本身所在，不是换滤波器就能解决的。

### 声音演示：为什么理想低通听着没有年轮效应

最后我们做一个声音的演示程序：一个声音分别过理想低通和巴特沃斯低通，看听感上有什么差别。这个声音大概就是刚才那个高音歌唱家的声音。

> **提示**：这个程序里的每一行，大家学完第五章应该都能看懂。它不涉及滤波器设计，只涉及频率的变化。现在看不懂的原因，大家有没有想过？**因为计算机只能处理离散的信息，而我们讲的全都是连续的信息。** 我们一直在讲连续的 $x(t)$，所以在连续和离散之间有一条沟。这条沟要用第四章和第五章把它抹平：：第四章讲的是离散信号的傅里叶变换，也就是 DTFT；第五章讲采样定理，它是沟通连续和离散在频域上的一座桥。有了这两章，大家完全能看懂这个程序。

先看理想低通。截止频率 `fc1 = 4000 Hz`，你仔细看幅度谱，4000 Hz 以上的**全变成零了**（纵轴那根 0.5×10⁴ 的刻度），相位谱也是同理，在 4000 以上我们全把它清成零了。

听一下。哪怕是这么高的音，高于 4000 Hz 的成分也不是很多，还行。听一下原来的音做个对比——我估计还是稍微低了一点。

我们再做个实验，把截止频率降到 **2000 Hz**，截得更狠一点，再听。

这一下终于能明显感受到声音被截掉很多了。

> **结论**：那不是说理想低通有年轮效应吗，怎么听不出来？还有，你不是说它不能实施吗，为什么能用？

原因在于：**我们是把整个声音从头到尾都保留下来了。** 对于每一个输出的 $y$，我们都是用这个声音所有的点去计算的——每个输出点都用到了整段信号。这种非因果的、全知全用的做法下，理想低通的效果其实还不错。

但你如果要做到**实时**，就不行了：对于每一个固定的 $t$，你不能再用 $t$ 之前、$t$ 之后的值去计算，这样问题就大得多。

> 所以我的看法是：理想低通不是不能用，而是**不能实时地用**。

再看巴特沃斯。截止频率同样设成 4000，但你会看到 4000 Hz 以上**还是有那么一点点**，不是严格的零。因为巴特沃斯的截止不是一刀切，哪怕 $\omega$ 取得很远，它也不会完全衰减到零。听一下它的结果——也还是挺好的。

最后是高通。这里有一个非常好用的等式，请你仔细想想：

$$
\text{高通结果} = \text{原信号} - \text{低通结果}
$$

> **易错点**：这个关系成立的前提是低通与高通互补，也就是 $\omega_c$ 取在同一个位置。

所以听一下理想高通的结果：他把那个最高的音给我保留下来了，变成"吱——吱——吱"的那种声音。这就是这个信号当中**很快速的变化被保留了下来**的样子——你回想一下前面说的，低频对应缓慢变化，高频对应快速变化，这里就是最直接的印证。巴特沃斯高通的结果也是类似的，年轮效应会更小一点。

## 二维图像的傅里叶变换，与四个不常用信号的傅里叶变换
> 对应块：BLK39 | 覆盖分集：P29-P30 | 块标题（分集名）：《二维信号的傅里叶变换》

开场先把上一次没讲完的演示过一遍。这里有个知识点，不在考试范围里，但我觉得挺重要。

我们先对照一下一维傅里叶变换的正反变换公式：

$$F(\omega) = \int_{-\infty}^{\infty} f(t) e^{-j\omega t} dt$$

$$f(t) = \frac{1}{2\pi} \int_{-\infty}^{\infty} F(\omega) e^{j\omega t} d\omega$$

如果输入有两个维度——比如一幅二维灰度图像，记作 $f(x,y)$，$x,y$ 是图像上的位置坐标，$f(x,y)$ 是那个点上的灰度值——那么它的傅里叶变换该怎么定义？

答案是跟上面那个公式非常地像，只是每个地方都多长出一截。

```text
一维：
    f(t)   --[ ∫ f(t) e^{-j w t} dt ]-->   F(w)
              1 个自变量  t      ↔      1 个频率  w

二维：
    f(x,y) --[ ∫∫ f(x,y) e^{-j(ux+vy)} dxdy ]-->  F(u,v)
              2 个自变量  x, y   ↔      2 个频率  u, v
              x 配 u，y 配 v；u、v 与一维的 w 完全同源
```

核心就在指数里：一维是 $e^{-j\omega t}$，自变量只有一个就写一个 $t$、一个 $\omega$；二维底下既然有 $x$ 和 $y$ 两个自变量，那频率上就必须劈成两个分量，$u$ 跟着 $x$ 的变化走、$v$ 跟着 $y$ 的变化走。于是

$$F(u,v) = \int_{-\infty}^{\infty}\int_{-\infty}^{\infty} f(x,y) e^{-j(ux+vy)} dx\, dy$$

反变换照样是把符号换回来，前面补上归一化系数 $(2\pi)^{-2}$：

$$f(x,y) = \frac{1}{(2\pi)^2} \int_{-\infty}^{\infty}\int_{-\infty}^{\infty} F(u,v) e^{j(ux+vy)} du\, dv$$

幅度谱和相位谱跟一维完全一样：幅度谱是实部平方加虚部平方再开根号，相位谱是虚部除以实部再取 $\arctan$。

> **提示**：证明这个反变换公式我留给你们当作业了。关键是别把一维那套整个硬搬过来硬算——充分利用你已经掌握的一维傅里叶变换的结果，把它拆成两次一维的逆变换去做，会顺很多。

### 三幅图，三张谱

接下来是正戏。屏幕上摆着三幅图，下面是它们各自二维傅里叶变换的幅度谱——相位谱太乱，我们不看，只看 $|F(u,v)|$。

上下的顺序还故意打乱了，跟图一、图二、图三并不一一对应。我先请你们自己判断：这张对应图几？觉得是图一的举手，觉得是图二的举手，觉得是图三的举手。

**图二是对的**，举手最多的那批人选中了它。

剩下两张争议不小，两边差不多人数。公布答案：一张对应图三，一张对应图一。

为什么？接下来我把判断的依据一条一条说清楚。说实话这个问题有点复杂，上一次大致看过其中一张的幅度谱，所以做对的人稍微多一点。但它确实是能看出来的。

### 时域里等距重复，频域里就是等距亮点

先看最有规律的那张。它的横轴上，每隔一个固定的区间段就有一个亮点；你仔细沿着横坐标数过去：这里一个亮点，隔一段又一个亮点，再隔同样的一段又是一个亮点，规律得非常干净。

对应到时域上，这句话的意思是：**图像在横坐标上，每隔一小段就重复一次**。既然时域等距重复，那么按前面那个积分公式去算，在那些固定的频率上就会各自聚起一个亮点。

```text
时域 x 方向：   [一小段图案][同样一小段][同样一小段][同样一小段] ...
                        等距重复
                            ↓  二维傅里叶变换
频域 u 方向：   ·    ●    ·    ●    ·    ●    ·    ●    ·    ...
                      等距出现的亮点
```

规律就是这么朴素：时域的周期性，在频域里就变成离散性；时域里重复得越整齐，频域里的亮点就越集中、越干净。

### 建筑物的窗户与树林里的竖线

剩下两张也能看，但要看对地方。

一张是相对杂乱无章的树林和路，另一张里有建筑。建筑这个对象特别有意思：看它的窗户——这一段是窗户，隔一段又是一段窗户，大致一致的间隔，重复着往上排、往上堆。**横着有间隔、竖着也有间隔地重复**，那它对应的幅度谱上，横方向、竖方向都会出现有规律的重复，整个谱看上去相当"好看"，规整得让人舒服。

另一张就不同了：它比前两张杂乱得多。时域越杂乱，意味着能量在频域上铺得越开、分布越广阔；它那个谱看上去就更"糊"一些、更弥散。

不过这一张还藏着一个细节，我觉得特别值得看：**它横轴方向的亮度，比竖轴方向的亮度要低一些**。为什么？

因为画面里全是树木，树干都是竖着的。也就是说，这幅图在竖直方向上、竖直的直线条纹，明显比水平方向要多。按照前面那个公式一算，竖直方向上的规律性内容越多，竖轴那边的亮度就越大。

> **结论**：所以别指望对所有图像都能做出精确的一一对应。但对具体的某一张，你可以认真去看幅度谱上的这些结构，然后反过来分析它的时域里到底有什么。

图一与图三具体谁对谁，答案是当场公布的；不过你只要抓住上面这两条规律，自己判也判得出来。

### 频谱最亮的那个点，一定是原点

最后看一个共性：不管哪幅图，幅度谱上**最亮的点永远是 $(u,v)=(0,0)$**。

这跟一维是同一回事：一维里 $\omega=0$ 那一段通常是最值钱的（直流分量全堆在那儿），二维里对应的就是原点。它在频谱图的正中间，顺带把整个谱分成了上下左右四个象限。

> **提示**：怎么从一个图像把幅度谱和相位谱的程序真正写出来？你们得学到第四章，学完第四章我再给大家演示。现在先把这个"看谱反推时域"的手感建立起来。

### 四个不常用的傅里叶变换

接下来这一块不是重点：四个不常用信号的傅里叶变换。

那为什么要讲？两个理由。第一，为了让知识点变得**完备**——常见的、不常见的，凑齐了才算这门课的知识体系没有窟窿。第二，你们平时在外面看到这四个信号时，**公式可以不死记，但心里必须知道"这个我能自己推出来"**。

#### 双边指数信号

$$x(t) = e^{-a|t|}$$

形状很好认：$t=0$ 处最高，等于 1，两边以 $e^{-a|t|}$ 对称地衰减下去。这个我们前面讲过。

$$X(j\omega) = \frac{2a}{a^2 + \omega^2}$$

书上 97 页 3.2.3 的第二个括号里提到它，具体公式在 98 页的 3-52。

#### 高斯脉冲信号

$$x(t) = E e^{-(t/\tau)^2}$$

一个以原点为中心、高度为 $E$ 的钟形脉冲。

$$X(j\omega) = \sqrt{\pi} E \tau e^{-(\frac{\omega\tau}{2})^2}$$

公式在书上 99 页最底下那一行，整个推导和结果在 100 页的 3-58。这个推导起来不那么容易——你们去翻我的讲义，我在讲义上认真推过一遍，有兴趣的同学自己看。

值得注意的对比是：高斯脉冲的傅里叶变换**还是高斯**。这是少数几个"变换完形状不变"的信号，你们现在记住这条，后面讲滤波、讲时频分析还会反复用到。

#### 半波余弦信号

$$x(t) = \begin{cases} E \cos\left(\frac{\pi t}{\tau}\right), & |t| < \frac{\tau}{2} \\ 0, & |t| > \frac{\tau}{2} \end{cases}$$

它在 $-\frac{\tau}{2}$ 到 $\frac{\tau}{2}$ 之间取一个完整的余弦波，峰值 $E$，到了 $\frac{\tau}{2}$ 之外直接截断成零。可以理解成把 $\cos(\frac{\pi t}{\tau})$ 在区间外面一刀切掉。

$$X(j\omega) = \frac{2E\tau}{\pi} \frac{\cos\left(\frac{\omega\tau}{2}\right)}{1 - \left(\frac{\omega\tau}{\pi}\right)^2}$$

这个公式看着有点繁琐，但我相信你们直接用傅里叶变换的定义、或者用变换的性质，就能把它推出来。

#### 奇对称斜线

第四个看上去最简单，实际上真要推还有点难。

$$x(t) = \frac{E}{T} t, \quad -T < t < T$$

其他时间为 0。就是从 $-T$ 到 $T$ 之间一条笔直的斜线，左端 $-E$、右端 $E$。

它的傅里叶变换呢？输入这么简单，公式却复杂：

$$X(j\omega) = j \frac{E}{T} \left[ \frac{2T \cos(\omega T)}{\omega} - \frac{2 \sin(\omega T)}{\omega^2} \right]$$

推法很短，就一步：$\frac{d}{d\omega} e^{-j\omega t} = -jt\, e^{-j\omega t}$，所以 $t \cdot e^{-j\omega t}$ 的变换等于对应变换对 $\omega$ 求导的 $-1/j$ 倍。于是

$$X(j\omega) = \frac{jE}{T} \frac{d}{d\omega} \underbrace{\left[ \frac{2\sin(\omega T)}{\omega} \right]}_{\;=\; \int_{-T}^{T} e^{-j\omega t} dt}$$

求导展开就是上面那个式子。顺手可以验证一下 $\omega=0$ 附近的行为：括号内 $O(\omega^3)$，所以 $X(j\omega)\approx -j\frac{2}{3}E T^2 \omega$，纯虚、从原点过，符合奇对称信号的直觉。

#### 拿共轭对称性自查一下

你们还记得我讲过的傅里叶变换的**共轭对称性**吧？把这四个往里一套，全都对得上：

- 斜线信号是实奇函数，对应实奇对虚奇，所以它的 $X(j\omega)$ 里带一个 $j$，整体关于 $\omega$ 是奇的——上面那个式子里头，$\sin$、$\cos$ 都是奇函数，两个奇函数乘出来正好抵消成偶的，再被 $1/\omega^2$ 一除变回奇，所以整个表达式确实是个纯虚的奇函数，完全一致。
- 双边指数、高斯脉冲、半波余弦都是实偶函数，实偶对实偶，变换后还是关于 $\omega$ 的实偶函数。

> **结论**：记公式不如记性质。**实偶 $\rightarrow$ 实偶，实奇 $\rightarrow$ 虚奇**。性质记牢了，这四个变换就算忘了公式，你也能反推回去。

这四个我在讲义上 1、2、3、4 全都认真推了一遍，课上就不细推了。除了第二个高斯脉冲，其余几个我觉得你们都很容易自己推出来。

最后提醒一下考试形势：期末考试里，这四个**十几年没有考过了**——准确地说，第一个偶尔还会考到一点点，另外三个确实很多年没出现过。但我在一些学校的考研、研究生试题里还见过它们。所以我的建议是：**你大致知道有这件事就行，真考到了，你在考场上自己也能推出来**，达到这个程度就够了。

### 本讲提到的题目

**题目**：已知二维傅里叶变换的定义为

$$F(u,v) = \int_{-\infty}^{\infty}\int_{-\infty}^{\infty} f(x,y) e^{-j(ux+vy)} dx\, dy$$

证明它的反变换公式为

$$f(x,y) = \frac{1}{(2\pi)^2} \int_{-\infty}^{\infty}\int_{-\infty}^{\infty} F(u,v) e^{j(ux+vy)} du\, dv$$

**解析**：不要去背一维的证明，把它当成两次一维逆变换。

把 $F(u,v)$ 代进待证式右边，交换积分次序：

$$f(x,y) = \frac{1}{(2\pi)^2} \int\!\!\int \left[ \int\!\!\int f(x',y') e^{-j(ux'+vy')} dx' dy' \right] e^{j(ux+vy)} du\, dv$$

先固定 $u$ 和一个待定的 $v_0$，把整个方括号按 $u$ 分组，其中关于 $x'$ 的那一层是

$$G(u; x) = \int_{-\infty}^{\infty} \left[ \int_{-\infty}^{\infty} f(x',y') e^{-j v_0 y'} dy' \right] e^{-j u x'} dx'$$

**对固定的 $y'$，括号里那一整项关于 $x'$ 就是一个一维函数**。而它正好是那个一维函数的傅里叶变换。于是直接调用一维反变换公式（$\omega \leftrightarrow u$，$t \leftrightarrow x$），得到

$$G(u; x) = 2\pi \int_{-\infty}^{\infty} f(x,y') e^{-j v_0 y'} dy'$$

原式化为

$$f(x,y) = \frac{1}{2\pi} \int_{-\infty}^{\infty} \underbrace{\left[ \int_{-\infty}^{\infty} G(u; x) e^{j u x} du \right]} e^{j v_0 y} dv$$

括号里同样是一次一维反变换，作用完之后剩下 $\frac{1}{2\pi}\int\int f(x,y) e^{-jv_0 y}dy$ 这一串，它只是原式的恒等变形（$v_0$ 换回 $v$），不引入任何新东西。

**答案**：待证式成立。注意归一化系数是 $(2\pi)^{-2}$ 而不是 $(2\pi)^{-1}$——做两次一维逆变换就得除两次 $2\pi$，这个系数是二维与一维最容易记混的地方。

**答**：反变换公式按上式成立。判断答案对不对有两招：一是两边作用完再正变换一次必须回到 $F(u,v)$；二是看归一化系数——两次一维反变换，$2\pi$ 就要除两次，这个数记错，后面所有二维滤波的推导会全盘歪掉。
