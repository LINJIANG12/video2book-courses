## 常用信号的傅里叶变换表与周期信号的傅里叶变换
> 对应块：BLK39 | 覆盖分集：P90-P92 | 块标题（分集名）：《3.15常用信号的傅里叶变换表（1)》

傅里叶变换的性质终于讲完了。不过在讲性质的过程中，我们又陆陆续续推导了一堆信号的傅里叶变换——把它们和最早讲的那些常用信号凑到一起，就得到了这一讲要总结的总表。这张表加上前面讲的性质，就是我们以后做傅里叶变换的两样武器：一个信号的傅里叶变换，往往就是靠「常用信号的变换 + 傅里叶变换的性质」拼出来的。所以性质要背，这张表更要背。

这一讲的后半段，我们还要回答一个悬了很久的问题：周期信号能不能做傅里叶变换？答案是可以的，而且推出来的结果会反过来解释这张表里最后一个"神秘嘉宾"——冲激序列——为什么排在了重点位置。

### 这张表怎么记：公式小本与"变相的重点"

先把记表的态度说清楚。表里有些条目比较重要，有些没那么重要。但有意思的是：

- **重要的那些，你都不用刻意去记。** 做题做多了，自然而然就记下来了。
- **不那么重要的那些，你反而要花时间去记。** 因为平时遇得少，忘的概率很大——没画重点号，反而是变相的重点。

为什么整张表最好都记下来，而不是"考试现场推"？因为虽然重要条目能推、冷门条目也能推，但推导是需要时间的，何况考试那个高度紧张的环境中，你可能就忘了它是怎么推的了。所以还是平时多记：把这张表抄进你的公式小本，没事翻一翻；忘了就翻，忘一时记一时。等到考前再突击也可以，但那样压力是不是有些大呀？考前你还要背政治、背英语，所以包括数学在内，公式多、难背的，我都建议准备一个公式小本，每天翻一翻。信号与系统是公式特别多的课，高数也是，背公式是一定要克服的难题——有些问题，公式记下来了其实就解决了。

> **提示**：前面讲的傅里叶变换性质同样要背，但那边不用我再总结，每本教材都会给，按教材记就行。

### 逐个过一遍总表

#### 冲激、冲激偶与阶跃

$\delta(t)$ 的傅里叶变换是 $1$，很好记，也很重要。$\delta'(t)$ 的傅里叶变换是 $j\omega$，这个也很重要。$\delta'(t)$ 的价值在哪？对一个信号求导，你可以写成这个信号与 $\delta'(t)$ 做卷积，再根据卷积定理，时域卷积对应频域相乘，得到的就是 $j\omega F(\omega)$——这正是我们讲过的时域微分性质。

$u(t)$ 的变换稍微有点难记：

$$u(t) \leftrightarrow \pi\delta(\omega) + \frac{1}{j\omega}$$

#### $t\,u(t)$、常数与符号函数

$t\,u(t)$ 的变换是

$$t\,u(t) \leftrightarrow j\pi\delta'(\omega) - \frac{1}{\omega^2}$$

这一条不记也可以——它就是 $u(t)$ 乘以 $t$，用频域微分性质可以推；或者用时域相乘对应频域卷积（频域微积分）那条性质也能自己推。但我还是那句话：你自己推，在考场上推是不是需要时间？万一推错了呢？万一紧张想不起来怎么推呢？所以能记的最好还是记一记，何况这个并不复杂。

常数 $c$ 的变换是 $2\pi c\,\delta(\omega)$，很重要，也很好记。符号函数 $\operatorname{sgn}(t)$ 的变换是 $\dfrac{2}{j\omega}$，这条没那么重要，但很好记——两边形式都很简单。

#### 单边指数与双边指数

单边指数信号比较重要：

$$e^{-at}u(t) \leftrightarrow \frac{1}{a+j\omega}, \quad a > 0$$

注意这里 $a$ 要大于零。单边指数这个信号，在接下来要讲的拉普拉斯变换里才是更为重要的主角，这里先单独记一下。

双边指数 $e^{-a|t|}$ 就没那么重要了，变换是 $\dfrac{2a}{a^2+\omega^2}$。但别忘了前面说的：没那么重要的，你反而要记，这是变相的重点。

#### 正余弦与虚指数

虚指数最重要：

$$e^{j\omega_0 t} \leftrightarrow 2\pi\delta(\omega - \omega_0)$$

$\cos\omega_0 t$ 用欧拉公式拆成两个虚指数的和，就得到

$$\cos\omega_0 t \leftrightarrow \pi\delta(\omega+\omega_0) + \pi\delta(\omega-\omega_0)$$

它的频谱当时没画，这里补上：就是在 $\pm\omega_0$ 处各一个冲激，冲击的强度都是 $\pi$。

$$\sin\omega_0 t \leftrightarrow j\pi\delta(\omega+\omega_0) - j\pi\delta(\omega-\omega_0)$$

$\sin$ 的频谱也是 $\pm\omega_0$ 处两个冲激，但 $+\omega_0$ 处是正的、$-\omega_0$ 处是负的，而且前面还乘了个 $j$——所以它其实还带着一个相位，不像 $\cos$ 那样"标准"。

带相位的 $\cos(\omega_0 t + \varphi)$、$\sin(\omega_0 t + \varphi)$ 这两条怎么推？我也交给你们了：还是欧拉公式，只是多了一个常数相位因子而已——每个冲激后面多乘一个 $e^{\pm j\varphi}$，$\sin$ 那边相位正好反过来再多个 $j$。这两条可以不背，但如果你把不带相位的记熟了，带相位的用频移性质一推就出来。

#### 门函数与三角脉冲

门函数很重要：

$$g_\tau(t) \leftrightarrow \tau\operatorname{Sa}\left(\frac{\omega\tau}{2}\right)$$

幅度为 $1$、宽度为 $\tau$ 的门函数，变换就是 $\tau\operatorname{Sa}(\omega\tau/2)$。这个我相信你现在就已经记下来了，因为前面讲课的时候我们已经多次用过这个结论。

三角形脉冲也经常出现，用到的频率虽然没有门函数那么多，但还是会碰到。取两边各 $\tau/2$、总底宽为 $\tau$、高度为 $1$ 的三角脉冲，它的变换是：

$$\frac{\tau}{2}\operatorname{Sa}^2\left(\frac{\omega\tau}{4}\right)$$

> **易错点**：三角脉冲这条最容易错在宽度的代入上。总底宽是 $\tau$（两边各 $\tau/2$），Sa 里的参数就要用 $\omega\tau/4$、系数配 $\tau/2$；要是你的三角总底宽取的是 $2\tau$，那对应的才是 $\tau\operatorname{Sa}^2(\omega\tau/2)$。公式必须得对，宽度跟参数一定要配平，不然差一倍就全错了。

这一条你其实可以自己推——三角可以看成两个门卷出来的，我教过怎么推。但还是那句话：推荐你记。为什么不记呢？我们所做的一切准备，都是为了考试那一刻，能现在做的就不要留到考试那一刻。

利用对称性，"门对应 Sa、三角对应 $\operatorname{Sa}^2$"反过来看就得到频域那两条：$\operatorname{Sa}(at)$ 对应一个门函数，幅度 $\dfrac{\pi}{a}$、宽度 $2a$；$\operatorname{Sa}^2(at)$ 对应一个三角，幅度 $\dfrac{\pi}{a}$、宽度 $4a$。注意这个三角比对应的那个矩形要宽一倍，是它的两倍。

#### $t$、$\dfrac{1}{t}$ 与冲激序列

最后这几条，说实话可能是整张表里最冷门的，遇到的可能性比较小。但最好也背。

$$t \leftrightarrow 2\pi j\delta'(\omega), \qquad \frac{1}{t} \leftrightarrow -j\pi\operatorname{sgn}(\omega)$$

这两条如果你自己推，是根据对称性来推。但真到题目里突然出现，反而不太好想：尤其是 $\dfrac{1}{t}$，一般很难想到从"$\operatorname{sgn}(t)$ 的变换是 $\dfrac{2}{j\omega}$"出发去用对称性——因为这个变换本身我们就很陌生，何况还要再绕一道对称性。所以我怕题目单独拿它出来命题，直接问你 $\dfrac{1}{t}$ 的傅里叶变换是什么——如果你背过，那岂不是很好。

冲激序列这一条之前还没正式讲过，这里提前写在表里：

$$\delta_T(t) = \sum_{n=-\infty}^{+\infty}\delta(t - nT_1) \leftrightarrow \omega_1\sum_{n=-\infty}^{+\infty}\delta(\omega - n\omega_1)$$

冲激序列的傅里叶变换在频域上也是一个冲激序列。**这是一个重点**：接下来对周期信号做傅里叶变换，我们会经常用到这个信号，它是非常有用的一个信号。至于它到底用来做什么，下面这一节就见分晓。

### 傅里叶级数与傅里叶变换，到底差在哪

回到第三章一开始。那时我们讲了傅里叶级数：一个周期信号可以展开成无穷多个三角函数、或者无穷多个复指数函数的和。但我们当时并没有就此满足——一个周期信号能做傅里叶级数，那能不能做傅里叶变换呢？是可以的。虽然周期信号可能并不满足绝对可积的条件，但因为我们引入了奇异函数、引入了冲激，它就可以做傅里叶变换了。

在做之前，先把傅里叶级数和傅里叶变换的区别提一下。对信号 $f(t)$ 做傅里叶变换，得到的是 $F(\omega)$——注意，结果完全是一个以 $\omega$ 为自变量的函数。也就是说，我们本来在时域上分析、观察 $f(t)$，做完变换之后就完全跑到频域上去了。

傅里叶级数不是这样。它是 $f(t) = \sum$，可以拆成比如 $2\cos(\omega_1 t) + 3\cos(2\omega_1 t) + \cdots$——注意这里是一个**等号**：$f(t)$ 拆成这些信号的和，拆开之后还是在时域上，自变量仍然是 $t$。这就是它与傅里叶变换的区别。你要想从频域上分析傅里叶级数，得去画它的频谱，从频谱上分析才算是频域分析。

### 周期信号的傅里叶变换：一条推导主线

设周期信号为 $f_T(t)$，大 $T$ 就代表它是个周期信号。既然它已经能展开成傅里叶级数，那就先展开——展成哪种形式？复指数形式，因为它非常简洁美观：

$$f_T(t) = \sum_{n=-\infty}^{+\infty} F_n e^{jn\omega_1 t}$$

傅里叶级数是个等式，两边相等。那对 $f_T(t)$ 做傅里叶变换，不就相当于对右边做变换吗？右边是一个求和，由线性性质，对求和做变换等于先各自变换再求和，把求和号提到外边：

$$\mathcal{F}[f_T(t)] = \sum_{n=-\infty}^{+\infty} \mathcal{F}\left[F_n e^{jn\omega_1 t}\right]$$

这里 $F_n$ 是跟 $n$ 有关的数，而做傅里叶变换时变量是 $t$，所以 $F_n$ 可以当常数提出来——但注意别提太狠，别提到求和号前面去，因为求和号的变量还是 $n$。于是

$$\mathcal{F}[f_T(t)] = \sum_{n=-\infty}^{+\infty} F_n\,\mathcal{F}\left[e^{jn\omega_1 t}\right]$$

而 $e^{jn\omega_1 t}$ 的变换我们会求：$e^{j\omega_0 t} \leftrightarrow 2\pi\delta(\omega-\omega_0)$，把 $\omega_0$ 换成 $n\omega_1$ 就是 $2\pi\delta(\omega - n\omega_1)$。$2\pi$ 是纯常数，连 $n$ 都跟它没关系，可以提到最前面：

$$\mathcal{F}[f_T(t)] = 2\pi \sum_{n=-\infty}^{+\infty} F_n\,\delta(\omega - n\omega_1)$$

这就是周期信号傅里叶变换的基本形式：**无穷多个冲激的和**。这无穷多个冲激都在什么位置、强度是多少？一代 $n$ 就看出来了：$n=0$ 时是原点处的冲激，强度 $2\pi F_0$；$n=1$ 时冲激在 $\omega_1$ 处，强度 $2\pi F_1$；$n=2$ 在 $2\omega_1$ 处，强度 $2\pi F_2$；左边同理，$n=-1$ 时在 $-\omega_1$ 处，强度 $2\pi F_{-1}$。剩下的无穷多项画不完，但规律已经清楚——

> **结论**：周期信号的傅里叶变换，就是把它傅里叶级数的那些离散谱线位置全部换成冲激，冲激强度等于对应的 $F_n$ 乘上 $2\pi$。

```text
   傅里叶级数频谱（离散谱）            对应的傅里叶变换频谱（冲激谱）

     |       |       |               2pF-1     2pF0     2pF1
     |       |       |                 |        |        |
  ---+-------+-------+---+--> w    ---+---+----+---+----+---+---> w
        -w1      0      w1             -w1      0       w1
   (只在 n*w1 处有定义)             (冲激在 n*w1 处，其余处处为零)
```

上图两边位置一一对应：级数的每根谱线，在变换的频谱里变成同一位置、强度 $2\pi F_n$ 的冲激。这里有一个根本上的不同要说清楚：傅里叶变换得到的频谱是**连续谱**——其他地方不是没有，而是幅度为零；傅里叶级数得到的是**离散谱**——其他地方压根就没有定义，只在 $\omega = 0, \pm\omega_1, \pm 2\omega_1, \ldots$ 这些地方才有值。另外 $F_n$ 本身是复数，直接把强度当"高度"画出来不太标准，但这么画直观，我们就直接这么画。

拿老朋友练一下：之前对周期矩形脉冲做傅里叶级数分解时画过它的频谱，包络是一个抽样函数。现在问它的傅里叶变换频谱是什么？按刚才的结论，在离散谱所在的位置把谱线换成冲激、强度乘 $2\pi$ 即可。比如 $0$ 处那个谱线值随手给个 $2$，那 $0$ 处冲激的强度就是 $2\times 2\pi = 4\pi$；$\pm\omega_1$ 处的值是 $\dfrac{3}{2}$，那冲激强度就是 $\dfrac{3}{2}\times 2\pi = 3\pi$。整条冲激序列照样被抽样函数的包络罩着。所以看一眼级数频谱，变换频谱就直接出来了。

### 求 $F_n$ 的捷径：单脉冲的傅里叶变换

看这个表达式，要求周期信号的傅里叶变换，关键是求谁？关键是求 $F_n$。$F_n$ 一出来，其余都好写。可 $F_n$ 怎么求？定义式是：

$$F_n = \frac{1}{T_1}\int_{-\frac{T_1}{2}}^{\frac{T_1}{2}} f(t)\,e^{-jn\omega_1 t}\,dt$$

其中 $f(t)$ 是周期信号**一个周期**的表达式。式子看起来挺简单，但我们具体求过——计算量其实很大。所以这里介绍一种新方法。

把 $-\dfrac{T_1}{2}$ 到 $\dfrac{T_1}{2}$ 这一段单独截出来，就得到这个周期信号的单脉冲信号 $f_0(t)$。对它做傅里叶变换：

$$F_0(\omega) = \int_{-\frac{T_1}{2}}^{\frac{T_1}{2}} f(t)\,e^{-j\omega t}\,dt$$

把两个式子摆在一起看：被积的 $f(t)$ 相同（本来就是从那里截出来的）、上下限相同、都是指数形式配 $dt$。区别只有两点：一个前面带 $\dfrac{1}{T_1}$，一个没有；一个指数上是 $e^{-jn\omega_1 t}$，一个是 $e^{-j\omega t}$。那就显然了——把 $F_0(\omega)$ 里的 $\omega$ 换成 $n\omega_1$，再除以 $T_1$：

$$F_n = \frac{1}{T_1}\,F_0(n\omega_1)$$

这就是 $F_n$ 的新求法。什么时候用它？当周期信号一个周期的傅里叶变换好求的时候——$F_0(\omega)$ 好求，$F_n$ 就好求，肯定比直接代定义式快捷。比如周期矩形脉冲，它一个周期就是个门函数，门函数的变换我们再熟悉不过，套公式一求非常快。反过来，如果这个周期信号一个周期的变换你压根没见过、不好求，那就别用这招，老老实实代定义式——它虽然计算量大，但步骤很固定。两种方法恰当地选取。

### 例题：周期矩形脉冲的级数与变换

理论说完了，来一道例题操练一下：求周期矩形脉冲 $f(t)$（幅度 $E$、脉宽 $\tau$、周期 $T_1$）的傅里叶级数和傅里叶变换。

小节标题明明是"周期信号的傅里叶变换"，为什么还要顺带求傅里叶级数？因为刚才学了一种新的求 $F_n$ 的方法——$F_n$ 求出来，级数就出来了；而求傅里叶变换，要求的也是 $F_n$。一个 $F_n$，两个全出来，划算。

那就用新方法。取单脉冲 $f_0(t)$：在 $-\dfrac{\tau}{2}$ 到 $\dfrac{\tau}{2}$ 之间截取，它就是一个幅度 $E$、宽度 $\tau$ 的门。门函数的变换是 $\tau\operatorname{Sa}(\omega\tau/2)$，再由线性性质乘上 $E$：

$$F_0(\omega) = E\tau\operatorname{Sa}\left(\frac{\omega\tau}{2}\right)$$

代公式求 $F_n$，把 $\omega$ 换成 $n\omega_1$：

$$F_n = \frac{1}{T_1}F_0(n\omega_1) = \frac{E\tau}{T_1}\operatorname{Sa}\left(\frac{n\omega_1\tau}{2}\right)$$

$F_n$ 求完，这道题其实已经求完了——可以看到这种方法求 $F_n$ 就是快，比起乘上 $e^{-jn\omega_1 t}$ 再硬做积分要快得多，前提是单脉冲的变换好求。

先代傅里叶级数的公式：

$$f(t) = \sum_{n=-\infty}^{+\infty}\frac{E\tau}{T_1}\operatorname{Sa}\left(\frac{n\omega_1\tau}{2}\right)e^{jn\omega_1 t}$$

这个常数 $\dfrac{E\tau}{T_1}$ 跟谁都没关系，可以提到求和号外边。

再代傅里叶变换的公式：

$$F(\omega) = 2\pi\sum_{n=-\infty}^{+\infty}F_n\,\delta(\omega - n\omega_1)$$

把常数都提到最外边，其中 $\dfrac{2\pi}{T_1}$ 就是 $\omega_1$：

$$F(\omega) = E\tau\omega_1\sum_{n=-\infty}^{+\infty}\operatorname{Sa}\left(\frac{n\omega_1\tau}{2}\right)\delta(\omega - n\omega_1)$$

两个频谱简单画一下：级数频谱是离散谱，变换频谱是把离散谱换成的冲激，但它们包络都是抽样函数。具体数值我就不标了，大致形状就是这样。

### 最重要的周期函数：冲激序列

最后来求一个**最重要的**周期函数的傅里叶变换——为什么说它最重要，等会就说。它就是冲激序列：

$$\delta_T(t) = \sum_{n=-\infty}^{+\infty}\delta(t - nT_1)$$

它的波形就是无穷多个冲激的叠加：$n=0$ 时是 $\delta(t)$，强度 $1$；$n=1$ 时是 $T_1$ 处的冲激，强度还是 $1$；左边 $-T_1$、$-2T_1$ 处同理。每隔 $T_1$ 一个冲激，强度全为 $1$。

方法跟之前完全一样，关键还是求 $F_n$，而求 $F_n$ 只需求它一个周期的变换。取它的单脉冲——显然就是一个冲激，$\delta(t)$，简单到家：$\delta(t)$ 的傅里叶变换就是 $1$，所以 $F_0(\omega) = 1$。代公式：

$$F_n = \frac{1}{T_1}F_0(n\omega_1) = \frac{1}{T_1}$$

$F_0(\omega)$ 里压根没有 $\omega$，就是个常数 $1$，怎么换它还是 $1$。再代入周期信号变换的公式，$\dfrac{1}{T_1}$ 是常数可以提到最外边：

$$\mathcal{F}[\delta_T(t)] = \frac{2\pi}{T_1}\sum_{n=-\infty}^{+\infty}\delta(\omega - n\omega_1) = \omega_1\sum_{n=-\infty}^{+\infty}\delta(\omega - n\omega_1)$$

频域上也是一个冲激序列，间隔变成 $\omega_1$、强度 $\omega_1$。这个结果就是开头表格里提前列出的那一条。

#### 为什么它最重要：任意周期函数都是"单脉冲卷冲激序列"

因为**任意周期函数都可以表示为它的单脉冲信号（也就是它的一个周期）与 $\delta_T(t)$ 的卷积**。

拿周期矩形脉冲验证一下：它的一个周期就是那个门函数。回忆第二章讲的性质：

$$f(t) * \delta(t - t_0) = f(t - t_0)$$

与冲激卷积就是对 $f(t)$ 做一个相应的时移。所以这个门函数卷上 $t_0$ 处的冲激，结果就是整个门函数向右搬移 $t_0$，中心从原点挪到 $t_0$ 处。逐项来看：门卷原点的冲激，是它本身（$f(t)*\delta(t) = f(t)$）；卷 $T_1$ 处的冲激，右移 $T_1$，不就得到了下一周期的那个门吗？卷 $2T_1$ 处的，右移 $2T_1$；卷 $-T_1$ 处的，左移 $T_1$。冲激序列里有无穷多个冲激，每个冲激都搬出一个对应位置的门，再根据线性把它们加起来——

```text
        f0(t)          *          dT(t)          =       周期矩形脉冲

          ___                    ^     ^     ^              ___     ___     ___
         |   |                   |     |     |             |   |   |   |   |   |
  -------+   +-----...    -------+--+--+--+--+--...    ---+---+---+---+---+---+---...--> t
                                 -T1    0    T1                 -T1     0     T1
```

读图：左边是截出来的单脉冲，中间是每隔 $T_1$ 一个、强度为 $1$ 的冲激序列；每个冲激把单脉冲搬到自己所在的位置，无穷多个平移副本相加，右边的周期信号就复原了。写成表达式：

$$f(t) * \delta_T(t) = f(t) * \sum_{n=-\infty}^{+\infty}\delta(t - nT_1) = \sum_{n=-\infty}^{+\infty} f(t - nT_1)$$

把求和展开就是 $\delta(t) + \delta(t-T_1) + \delta(t-2T_1) + \cdots + \delta(t+T_1)$，逐个卷过去得到 $f(t) + f(t-T_1) + f(t-2T_1) + \cdots + f(t+T_1)$，无穷多项。周期矩形脉冲是这样，我说任意一个周期函数都可以这么来：画出它的一个周期，跟冲激序列一卷，就还原出原来的周期函数。

#### 顺着卷积定理再推一步

这个结论无疑是非常有用的。因为讲傅里叶变换性质时讲过：时域卷积，频域相乘。现在对 $f(t) * \delta_T(t)$ 两边做变换，设 $\mathcal{F}[f(t)] = F(\omega)$，而 $\delta_T(t)$ 的变换我们刚求过：

$$\mathcal{F}\left[f(t) * \delta_T(t)\right] = F(\omega)\cdot\omega_1\sum_{n=-\infty}^{+\infty}\delta(\omega - n\omega_1)$$

其实推到这儿已经够用了：任意周期函数的变换，就是你先求出单脉冲的 $F(\omega)$，再乘上冲激序列的变换。但我们继续往后推一推，看看这两个相乘还能化成什么样。这里要用第一章讲的冲激函数的性质：

$$f(t)\,\delta(t - t_0) = f(t_0)\,\delta(t - t_0)$$

$F(\omega)$ 乘的是无穷多项冲激的和，那就一项一项看：$n=0$ 这项是 $F(\omega)\delta(\omega)$，等于 $F(0)\delta(\omega)$；$n=1$ 这项是 $F(\omega)\delta(\omega-\omega_1)$，等于 $F(\omega_1)\delta(\omega-\omega_1)$；$n=2$ 同理得 $F(2\omega_1)\delta(\omega-2\omega_1)$。发现规律没有？$\delta$ 后面是 $\omega$ 减多少，前面就取 $F(\cdot)$ 在多少处的值——它已经是个常数了。所以：

$$F(\omega)\cdot\omega_1\sum_{n=-\infty}^{+\infty}\delta(\omega - n\omega_1) = \omega_1\sum_{n=-\infty}^{+\infty}F(n\omega_1)\,\delta(\omega - n\omega_1)$$

这个式子跟之前推的那个 $2\pi\sum F_n\delta(\omega-n\omega_1)$ 是同一个结论（两边本来都是任意周期函数的傅里叶变换）。

但如果你选择用这种方法去做，前面那个 $2\pi\sum F_n\delta(\omega-n\omega_1)$ 的公式就都不用单独记了：只要知道任意周期函数都能写成单脉冲卷冲激序列，再记住冲激序列对应的傅里叶变换，这一串就可以自己推出来。其实推的过程并不复杂——刚才为了通俗易懂，我们还把每一项都讨论了一遍，其实你自己不用，我相信不用。

## 抽样定理：抽样之后，信息去哪了
> 对应块：BLK40 | 覆盖分集：P93 | 块标题（分集名）：《3.17抽样定理》

### 从"数字化时代"说起

"数字化时代"这个词，前些年提得特别多——我们已经走进了数字化时代。什么叫数字化时代？就是我们传输的信号都变成了数字信号。计算机能处理的信号只有数字信号，0 和 1。可是现实生活中的大量信号都是模拟信号，想把它们交给计算机处理、转换成数字信号去传输，就要做一个操作，叫**模数转换**（A/D）。关于模拟信号、数字信号的概念，第一章已经简单提过。

模数转换是怎样的一个过程呢？它要先把模拟信号进行**抽样**。这一小节叫抽样定理，所以我们主要研究抽样的这个过程。

抽样本身很好理解：每隔一段时间抽一次、取一次。比如对一个信号，每隔一个大 T 取一个值，再过一个大 T 再取一次，以此类推，就得到了抽样后的信号。但你注意，抽样之后，信号在很多位置上都没有了、变为零了——换句话说，很多信息在抽样的过程中被"弄没了"。

于是就有两个问题摆在面前，这一讲全程都在回答它们：

- **问题一**：信号经过抽样之后，还能不能保留原来信号的全部信息？换句话说，我们能否用抽样信号反过来还原、恢复出原信号？
- **问题二**：我们现在不局限于只从时域去观察信号了，从频率上分析也是一个很好的方法。那么这个被抽样后的信号，它的频谱是什么样的？

带着这两个问题，我们先把抽样的过程本身讲清楚。

### 抽样的数学实现：冲激串的取样特性

怎么把"每隔一段时间取一个值"这件事写成数学？工具在第一章就有了——冲激函数。冲激信号有一个**取样特性**（也叫取样性质）：

$$f(t)\,\delta(t-t_0) = f(t_0)\,\delta(t-t_0)$$

$f(t)$ 乘上 $t_0$ 位置的一个冲激，就得到 $f(t)$ 在 $t_0$ 时刻的值 $f(t_0)$ 再乘上那个冲激——这就相当于进行了一次取样。

> **提示**：这里要把"冲激的面积"和"冲激的强度"分清楚。写 $\delta(t-t_0)$ 时，括号里的东西指的是冲激的**面积**（比如 $\delta(t-t_0)$ 面积为 1）；而冲激的强度无论如何都是无穷大。这两个词不是一回事，别混。

具体看图：随便画一个 $f(t)$，让它乘上 $t_0$ 处面积为 1 的一个冲激。冲激只有在 $t_0$ 这一刻有值，其他地方都为零，所以两者相乘的结果只在 $t_0$ 处还有一个冲激，且这个冲激的面积被乘上了 $f(t_0)$——括号里要写成 $f(t_0)$。这样，通过冲激的面积我们就得到了 $f(t)$ 在 $t_0$ 时刻的值，完成了一次取样。

一次取样不够，我们要的是"每隔 $T_s$ 取一次"。前面刚讲过一个信号叫 $\delta_T(t)$——**冲激序列**，它是很多很多冲激信号的叠加：

$$\delta_T(t) = \sum_{n=-\infty}^{+\infty} \delta(t - nT_s)$$

它的波形就是每隔一个 $T_s$ 有一个冲激，每个冲激的面积都是 1。那 $f(t)$ 与它相乘呢？不就能得到 $f(t)$ 在很多个时刻的值了吗？它相当于和很多个冲激分别相乘再相加。逐项看：$t=0$ 处冲激面积变成 $f(0)$，$t=T_s$ 处变成 $f(T_s)$，$t=2T_s$ 处变成 $f(2T_s)$……得到的波形已经完成了对 $f(t)$ 的抽样——**这些冲激的面积就是抽样得到的值**。

表达式也很好写。由基本结论 $f(t)\,\delta(t-t_0)=f(t_0)\,\delta(t-t_0)$，逐项套用即得：

$$f(t)\cdot\delta_T(t) = \sum_{n=-\infty}^{+\infty} f(nT_s)\,\delta(t-nT_s)$$

令 $n=0$ 就得到 $f(0)\delta(t)$ 这一项，令 $n=1$ 就得到 $f(T_s)\delta(t-T_s)$，和波形一一吻合。

这里的间隔 $T_s$ 不是死的，它可以调整：取得小，两次采样就挨得近；取得大，间隔就拉开。所以它就是**采样周期**——每隔多少时间采一次样。字母 $s$ 就是 sample（采样）的意思。把这个冲激串记作 $p(t)$，抽样信号就是：

$$f_s(t) = f(t)\,p(t) = \sum_{n=-\infty}^{+\infty} f(nT_s)\,\delta(t-nT_s)$$

#### 乘是抽样，卷积是搬移

上面为了通俗易懂，我们是把乘积拆开来一项项看的。其实没有这个必要——你总不能每做一次题都拆开看一遍吧。这里直接给出两条一劳永逸的结论，理解了之后可以直接看出来：

**乘上冲激串 = 抽样**：

$$f(t)\cdot\sum_{n=-\infty}^{+\infty}\delta(t-nT_s) = \sum_{n=-\infty}^{+\infty} f(nT_s)\,\delta(t-nT_s)$$

波形上的直观体现：一个信号乘上冲激序列，得到的是每个冲激位置上都带着对应 $f(t)$ 值的冲激序列。

**卷上冲激串 = 搬移**：

$$f(t)*\sum_{n=-\infty}^{+\infty}\delta(t-nT_s) = \sum_{n=-\infty}^{+\infty} f(t-nT_s)$$

因为一个信号与一个冲激卷积，相当于把这个信号搬移到冲激所在的位置，所以与冲激串卷积就是把波形复制一份搬到每个冲激位置上再叠加。

这两个性质后面反复要用，记住这一条就够了。

### 抽样信号的频谱：整排复制的原频谱

回到开头的问题二：抽样后的信号，频谱会变成什么样？

抽样信号 $f(t)\,p(t)$ 是两个信号**相乘**的形式，那就用**频域卷积定理**：时域上相乘，频域上就是卷积——但别忘了要乘 $\dfrac{1}{2\pi}$。

冲激串 $p(t)$ 的傅里叶变换之前已经求过：它还是一个冲激串。

$$P(\omega) = \frac{2\pi}{T_s}\sum_{n=-\infty}^{+\infty}\delta(\omega - n\omega_s), \qquad \omega_s = \frac{2\pi}{T_s}$$

$\omega_s$ 就是**采样角频率**。$f(t)$ 我们没有给出具体是什么，就假设它的傅里叶变换 $F(\omega)$ 是一个任意的波形——我们遇到的信号大部分是实信号，根据实函数频谱的对称性，幅度谱是偶对称的；为了方便，相位就设为零。

两者卷积的结果，就是**把 $F(\omega)$ 搬移到每个冲激所在的位置上**。这是因为 $F(\omega)$ 卷上一个 $\delta(\omega-\omega_s)$ 就得到 $F(\omega-\omega_s)$；冲激串有很多项，根据线性拆开来逐项卷、再合并，就得到：

$$F(\omega) * P(\omega) = \omega_s\sum_{n=-\infty}^{+\infty} F(\omega - n\omega_s)$$

再补上频域卷积定理要求的 $\dfrac{1}{2\pi}$。由于 $\dfrac{\omega_s}{2\pi} = \dfrac{1}{T_s}$，最终干净利落：

$$F_s(\omega) = \frac{1}{T_s}\sum_{n=-\infty}^{+\infty} F(\omega - n\omega_s)$$

画成图一目了然：

```text
      F(ω)（原信号频谱）                Fs(ω)（抽样信号频谱）
        ┌──┐                          ┌──┐    ┌──┐    ┌──┐
    ────┘  └─────                ─────┘  └─┐  ┌┘  ┌─┘  └─┐  ┌──
      -ωm  ωm                        -ωs  -ωm  0  ωm   ωs  ωs+ωm
                                    原频谱以 ωs 为间隔被整排复制
```

原信号的频谱 $F(\omega)$ 被原封不动地复制了一份又一份，摆放在 $\omega_s$ 的每一个整数倍位置上（卷积结果里每一份的幅度先变成 $\omega_s$ 倍，再乘 $1/2\pi$ 后净剩 $1/T_s$ 倍）。到这里，开头两个问题中的第二个已经解决了。

### 现实中的抽样：矩形脉冲

不过上面做的这一切都有一个问题：我们是用**冲激信号**对信号进行抽样，而冲激函数是一个非常理想化的信号，现实中是不可能真正得到一个冲激的。我们不可能只停留在理论分析上——现实中怎么抽样？

得不到冲激，就只能**退而求其次：用矩形脉冲来近似代替冲激**。这也正是冲激当初的来历——一个面积固定为 1 的矩形，让宽度 $\tau$ 一直变小、趋向于零，高度就趋向于无穷，这就得到了冲激。现实中 $\tau$ 当然不能真的趋向于零，但可以取得很小；$\tau$ 很小时，矩形脉冲就可以近似看成冲激。所以刚才那种理想化的抽样叫**理想抽样**，现实中的做法叫**矩形脉冲抽样**。

取幅度为 1、宽度为 $\tau$、周期仍为采样周期 $T_s$ 的周期矩形脉冲，记作 $p(t)$，用它去乘 $f(t)$。结果直接看波形就能看出来：$p(t)$ 只有"为零"和"为一"两种取值——为零的地方乘出来是零，为一的地方乘出来还是 $f(t)$ 本身。所以乘积就是这些矩形脉冲所在位置上的 $f(t)$，其余位置全为零。这当然也是抽样，只不过 $\tau$ 看起来有些大时抽样效果不好；$\tau$ 取小一点效果就更好；而效果最好的当然还是用冲激去抽——可惜现实中做不到，所以只能退而求其次，让 $\tau$ 尽量小一点。

它的频谱套路完全一样：还是频域卷积定理，时域相乘对应频域卷积，别忘了乘 $\dfrac{1}{2\pi}$。周期矩形脉冲的傅里叶变换，在周期信号的傅里叶变换那一小节已经做过这道例题：幅度为 $E$、周期为 $T_1$ 的周期矩形脉冲，其傅里叶变换为

$$P(\omega) = \frac{2\pi E\tau}{T_1}\sum_{n=-\infty}^{+\infty} \mathrm{Sa}\!\left(\frac{n\omega_1\tau}{2}\right)\delta(\omega - n\omega_1)$$

现在只需把 $E$ 取 1、周期换成 $T_s$、$\omega_1$ 换成 $\omega_s$：

$$P(\omega) = \frac{2\pi\tau}{T_s}\sum_{n=-\infty}^{+\infty} \mathrm{Sa}\!\left(\frac{n\omega_s\tau}{2}\right)\delta(\omega - n\omega_s)$$

它的频谱也是一排冲激，只是每个冲激的面积不再相同，按 $\mathrm{Sa}$ 函数的规律衰减。

卷积的时候注意一点：之前讨论过"信号卷冲激串"，那时每个冲激面积都是 1；现在各个冲激的面积不同。其实很简单，无非是前面多了一个系数——就像 $f(t)$ 卷上 $\dfrac{1}{2}\delta(t-t_0)$ 等于 $\dfrac{1}{2}f(t-t_0)$ 一样，**搬移的幅度要跟着冲激的面积走**。

还有一个细节值得点破：$P(\omega)$ 看起来很复杂，但整个表达式里只有 $\delta(\omega-n\omega_s)$ 这一处出现了 $\omega$，前面的 $\mathrm{Sa}(\cdot)$ 是常量。这就跟 $f(t)\delta(t-t_0)=f(t_0)\delta(t-t_0)$ 是同一个道理——好好一个 $t$ 的函数，乘上冲激后被"同化"成常数。所以卷积结果就是把每个 $\delta$ 换成对应的 $F$：

$$F(\omega)*P(\omega) = \frac{2\pi\tau}{T_s}\sum_{n=-\infty}^{+\infty}\mathrm{Sa}\!\left(\frac{n\omega_s\tau}{2}\right)F(\omega-n\omega_s)$$

最后再乘 $\dfrac{1}{2\pi}$（其中 $\dfrac{\omega_s}{2\pi}=\dfrac{1}{T_s}$）：

$$F_s(\omega) = \frac{\tau}{T_s}\sum_{n=-\infty}^{+\infty}\mathrm{Sa}\!\left(\frac{n\omega_s\tau}{2}\right)F(\omega-n\omega_s)$$

和理想抽样相比，唯一差别是每份复制的频谱前面多了一个按 $\mathrm{Sa}$ 包络衰减的系数。结构没变：频谱依然是以 $\omega_s$ 为间隔整排复制。

### 能否恢复原信号：频谱混叠

现在回到更关键的问题一：抽样后的信号，究竟有没有保留原信号的全部信息？要满足什么条件才能恢复出原信号？我们以理想抽样为例来讲——矩形抽样结论完全一样，讲完理想抽样大家就懂了。

把一个信号理想抽样之后，它的频谱就是刚才那幅图：原频谱的一份本尊加上一排副本。想恢复原信号，其实不用死盯着时域——第三章不就教会了我们这样一件事吗：**时域上看起来复杂的东西，在频率上看就可能变得简单**。这件事在频率上看确实非常直观、一目了然。

试想：只要把抽样信号的频谱 $F_s(\omega)$ 恢复成原信号的频谱 $F(\omega)$，那对应的时域上不就把抽样信号恢复成原信号了吗？而做法非常简单——**加一个低通滤波器，加一个窗**，换句话说就是乘一个门函数：门的高度为 1，截止位置落在 $\omega_m$ 与 $\omega_s-\omega_m$ 之间即可。门函数往右的部分和频谱往左的部分相乘都是零，两边副本全被切掉，只剩中间这一份与门相乘；而门在这个区间里取值是 1，波形不变——乘完正好得到 $F(\omega)$。恢复就是这么简单。

但这个"加窗就能恢复"其实默认了一个条件：这些副本**一个一个互不搭界、没有交集**。如果 $\omega_s$ 不够大，第一个副本的左端点跑到本尊右端点的左边去了，会发生什么？波形就会交叠、叠加在一起。这时你再怎么加门函数也恢复不出来了——中间这部分已经掺进了别的副本的贡献，跟原来长得不一样了。这就是**频谱混叠**。

```text
   不混叠（ωs > 2ωm）                   混叠（ωs < 2ωm）
     ┌─┐    ┌─┐    ┌─┐                 ┌──┐    ┌──┐
  ───┘ └────┘ └────┘ └───          ────┘  └─┐┌─┘  └───
     ωm   ωs-ωm   ωs                    ωm  ωs-ωm
   门函数能干净地切出中间一份          副本与本尊交叠，加谁也救不回来
```

那要满足什么条件才不混叠？看图上的几何关系就够了：本尊右端点在 $\omega_m$，第一份副本的左端点在 $\omega_s-\omega_m$。要求后者在本尊右侧，即

$$\omega_s - \omega_m > \omega_m \quad\Longrightarrow\quad \omega_s > 2\omega_m$$

对称地，负频率一侧要求 $-\omega_s+\omega_m < -\omega_m$，移项后也是同一句话：$\omega_s > 2\omega_m$。

这里还藏着一个前提条件：你想让 $\omega_s > 2\omega_m$，那 $\omega_m$ 起码得是有限的——若 $\omega_m$ 等于无穷，$\omega_s$ 怎么可能大于无穷？而 $\omega_m$ 是 $F(\omega)$ 频谱的左右端点，也就是说 $F(\omega)$ 必须是有限长的频谱。所以 $f(t)$ 得是一个**频带有限信号**（带限信号），这是抽样定理成立的隐含前提。

矩形脉冲抽样也是同样的结论。它的频谱虽然每份的幅度按 $\mathrm{Sa}$ 包络衰减，但形状与位置跟理想抽样只有幅度上的差别。副本不交叠，加门函数就能把中间这份恢复出来；一旦交叠，发生了混叠，这部分已经变得和原来不一样了，加谁也救不回来了。

还有一点要注意：$\omega_s$ **等于** $2\omega_m$ 的情况比较特殊。不同的教材有不同的说法——有的写 $\omega_s \geq 2\omega_m$ 时能恢复，有的写必须 $\omega_s > 2\omega_m$。这个要看你手里的教材来。我个人观点是写"大于"比较好，因为恰好等于 $2\omega_m$ 时，有时能恢复出来、有时恢复不出来，等会儿从时域上分析抽样定理时，我们会看到它为什么不好。

### 抽样定理：奈奎斯特给出的界限

把上面的结论正式总结一下，这就是**抽样定理**，也叫**奈奎斯特抽样定理**：

> **结论**：要想从抽样后的信号恢复出原信号，必须满足
> $$\omega_s > 2\omega_m$$
> 其中 $\omega_s$ 是抽样角频率，$\omega_m$ 是原信号频谱的最高角频率。（有的教材写 $\geq$，具体以你的教材为准。）

由 $\omega = 2\pi f$ 换个单位，同一句话可以写成三种形式：

$$f_s > 2f_m, \qquad T_s < \frac{1}{2f_m}$$

只是换算单位而已，本质是同一件事。这条界限本身也有名字：

- $f_s = 2f_m$ 称为**奈奎斯特频率**；
- $T_s = \dfrac{1}{2f_m}$ 称为**奈奎斯特间隔**。

三者之中，最关键、必须牢牢记住的就是 $\omega_s > 2\omega_m$ 这一条。

### 时域实验：给余弦信号抽个样

抽样定理通常在频率上证明，因为频率上更直观、也更严谨；时域上看就没那么严谨了，更多是直观感受。但直观感受恰恰最能说明"为什么"。我们拿余弦信号 $\cos(2\pi t)$ 做实验。

要套用抽样定理，先得知道它的 $\omega_m$，所以先做傅里叶变换。余弦的傅里叶变换非常简单：

$$\cos(2\pi t) \;\longleftrightarrow\; \pi\,\delta(\omega+2\pi) + \pi\,\delta(\omega-2\pi)$$

频谱只在 $\pm 2\pi$ 处有两个面积为 $\pi$ 的冲激。这和直观感觉完全吻合：$\cos(2\pi t)$ 本来就是角频率为 $2\pi$ 的信号。于是 $\omega_m = 2\pi$，从而 $f_m = \dfrac{\omega_m}{2\pi} = 1\,\text{Hz}$——这正是这个三角函数自身的频率；它的周期 $T = \dfrac{2\pi}{\omega_m} = 1$ 秒。下面把抽样频率从高到低一路降下来，看会发生什么。

#### 足够快：8 Hz 和 4 Hz

先取 $f_s = 8\,\text{Hz}$，即 $T_s = \dfrac{1}{8}$ 秒，一个周期取 8 个采样点。把这些点连起来看——采样点所在的位置已经很好地描述出了余弦的轮廓，一连线和余弦非常接近，凭直觉就能判断：能恢复。而且这一组 $f_s = 8 f_m$，远远大于 $2f_m$，按抽样定理本来就肯定没问题。

再降到 $f_s = 4\,\text{Hz}$，$T_s = \dfrac{1}{4}$ 秒，一个周期取 4 个点。连线之后发现已经有点像三角形了，没有刚才漂亮，但这个三角形和余弦差得也不算多，还是能看出、能感觉出这是个余弦的形状。此时 $f_s = 4 f_m$，仍然大于 $2f_m$，所以也是可以恢复的，只是效果不如 8 Hz 那组好。

#### 恰好 2 倍的尴尬：fs = 2fm

接下来是一个很敏感的位置：$f_s = 2\,\text{Hz}$，恰好等于 $2f_m$，一个周期只能取两个采样点。

如果采样点选得不错——取在波峰和波谷上——连起来是个三角形。前面说过，三角形这种形式你也可以把它近似看成余弦，凑着凑着也能恢复出原信号，虽然效果肯定不好。

但我们也可以选另外一组采样点：取在过零的位置。这些点全部落在一条直线上。这时候你还能看出它是个余弦信号吗？想象力再丰富，你也想象不出它的原身是个余弦——这些采样点连成一条直线，它跟余弦一点边都不搭。

这就是 $f_s = 2f_m$ 尴尬的地方：采样点选得好，也许能恢复；选得不好，就彻底恢复不出来。时有时无、看运气，这就是它不好的原因。所以我们要取 $f_s > 2f_m$。

#### 低于 2 倍：频率混淆

再退一步，让 $f_s < 2f_m$：取 $f_s = 1.5\,\text{Hz}$，$T_s = \dfrac{2}{3}$ 秒，每隔 $\dfrac{2}{3}$ 秒取一个点，采样点落在 $t=0,\ \dfrac{2}{3},\ \dfrac{4}{3},\ 2,\ \dots$ 处。

单看这些点，似乎还有点余弦的意思。但你绝对不可能把它恢复成原来频率为 1 Hz 的那个余弦——因为如果只看这些点，你会给它恢复成另一个**频率更低的余弦**：你会认为相邻的点就是直接相连的，中间那段是按低频余弦平滑过去的。要让点还原成 1 Hz 的原信号，等于要脑补出一段从这儿拐个大急弯的曲线——这属于脑补太多，你第一个想象到的肯定是那条简单的低频余弦。

换句话说：这两个余弦信号，在抽样周期为 $\dfrac{2}{3}$ 秒时得到的**采样点是完全一样的**。我们的大脑在做出判断时，总倾向于认为事物是简单的——看到这些点就按最简单的方式连接，而不会认为它们按复杂的方式连接。这就带来了错觉和误会：我们已经搞不清原信号的频率到底是什么了。这叫**频率混淆**；与此同时，在频率上它也发生了频谱混叠。两件事是一体的。

所以 $f_s < 2f_m$ 是不可取的——此时我们已经搞不清楚它的频率了。

### 转盘与照相机：抽样定理的生活版

再看一个更贴近生活的例子：一个转盘上有一根指针，周期 $T = 1$ 秒，即每秒转一圈，频率 $f = \dfrac{1}{T} = 1\,\text{Hz}$，所以 $f_m = 1\,\text{Hz}$。

现在拿照相机对它拍照。指针本来是连续变化的，拍照只留下几个瞬间——**对转盘拍照的过程，就相当于取样的过程**；拍照间隔就是抽样周期。我们换四种拍照速度，把这个定理从慢到快走一遍。

| 拍照间隔 | $f_s$ | 与 $2f_m$ 的关系 | 看到的效果 |
| :---: | :---: | :---: | :--- |
| 1/4 秒 | 4 Hz | $f_s > 2f_m$ | 四张照片指针步步前进，能自然感觉到在顺时针匀速转 |
| 1/2 秒 | 2 Hz | $f_s = 2f_m$ | 确实能感觉到它在转，但分不清是顺时针还是逆时针 |
| 3/4 秒 | 4/3 Hz | $f_s < 2f_m$ | 每张照片指针"退回"一段，看起来在逆时针慢转（错觉） |
| 5/4 秒 | 4/5 Hz | $f_s < f_m$ | 看起来每次只转 90°，实际每两张之间已整整转了一圈 |

逐组看。每 $\dfrac{1}{4}$ 秒一张时，$f_s=4\,\text{Hz}$ 显然大于 $2f_m$，四张照片我们很清楚地感觉到指针在顺时针一直转、一直转，能够很自然地想象它的变化——没什么问题。

每 $\dfrac{1}{2}$ 秒一张时，$f_s = 2\,\text{Hz}$，恰好等于 $2f_m$。看这些照片确实能感觉到它在转，但问题来了：**看不出来它到底是顺时针转还是逆时针转**——指针转到这个位置，顺时针转过来可以，逆时针转过来也可以。这就是 $f_s = 2f_m$ 的弊端，跟余弦实验里"看运气"是同一件事。

每 $\dfrac{3}{4}$ 秒一张时，$f_s = \dfrac{4}{3}\,\text{Hz} < 2f_m$，已经不满足抽样定理了。单看这些照片，第一直觉肯定是：指针在做逆时针运动——第一张在这儿，第二张退回来一点，很自然地认为它是逆时针转过来的；谁会想到它是顺时针转了那么大老远过来的？而实际我们知道指针是顺时针转的，每张照片之间它顺时针转了 $\dfrac{3}{4}$ 圈。错觉就这么产生了。

最后再过分一点：每 $\dfrac{5}{4}$ 秒拍一张，$f_s = \dfrac{4}{5}\,\text{Hz}$——注意它已经不单单是小于 $2f_m$，而是**小于 $f_m$** 了。此时每两张照片之间，指针已经转了一整圈还多转一段。如果你不知道这个前提，单独看这一串照片，你会想到它每张之间转了一整圈吗？不会。你只会认为第一张到第二张转了 90°，第二张到第三张又转了 90°——很自然地觉得指针在一格一格慢慢走，而绝不会想到它其实每张之间已经跑完一整圈又转回来了。这就更离谱了。

这个例子从时域上简单说明了：为什么我们必须满足 $f_s > 2f_m$。满足它，我们看到的世界是真实的；不满足它，我们看到的是一个被抽样"骗"过的世界。

### 频域抽样定理：对称的另一半

除了时域抽样定理，还有一条**频域抽样定理**。它的重要性远远不及时域抽样定理，而且证明方法与时域那条完全类似，所以粗略讲一下，只说理想抽样。

频域抽样是反过来玩：在频率上让 $F(\omega)$ 乘上一个冲激串，看时域会发生什么。频域相乘，根据卷积定理对应时域卷积。频率冲激串 $\displaystyle\sum_{n=-\infty}^{+\infty}\delta(\omega-n\omega_1)$ 的傅里叶逆变换我们是知道的：由 $\displaystyle\sum_n \delta(t-nt_1) \longleftrightarrow \omega_1\sum_n\delta(\omega-n\omega_1)$，把 $\omega_1$ 挪到左边去，逆变换就是面积为 $\dfrac{1}{\omega_1}$ 的时域冲激串。

于是"乘"变成"卷"：把 $f(t)$ 的波形搬移到每个冲激位置 $nt_1$ 上，幅度再乘 $\dfrac{1}{\omega_1}$：

$$F(\omega)\cdot\sum_{n=-\infty}^{+\infty}\delta(\omega-n\omega_1) \;\longleftrightarrow\; \frac{1}{\omega_1}\sum_{n=-\infty}^{+\infty} f(t-nt_1)$$

也就是说，**频域抽样对应时域周期化**——原信号的波形被复制一排、首尾相接。

想从这样的周期化波形里取出原来那一份，同样加一个时域的窗（门函数）即可，前提当然是各份副本不混叠。设 $f(t)$ 集中在 $[-t_m,\ t_m]$，相邻副本间隔 $t_1$，第一份副本的左端点在 $t_1 - t_m$，不混叠要求

$$t_1 - t_m > t_m \quad\Longrightarrow\quad t_1 > 2t_m$$

这就是频域抽样定理——与时域那条 $\omega_s > 2\omega_m$ 互为镜像，推导就这几步，你自己推也很好推。

至此，开头的两个问题都有了完整答案：抽样信号的频谱是原频谱以 $\omega_s$ 为间隔的整排复制；而只要原信号带限、且 $\omega_s > 2\omega_m$，复制出的副本互不打架，一个低通滤波器就能干净地把原信号请回来——信息一个都没丢。

## 帕塞瓦尔定理与系统函数
> 对应块：BLK41 | 覆盖分集：P94-P95 | 块标题（分集名）：《3.18帕塞瓦尔定理》

帕塞瓦尔定理（Parseval's theorem）其实有两种形式，分别针对傅里叶级数和傅里叶变换。这一讲我们把这两种形式都讲清楚——不只是背公式，而是把等式两端各自的含义、以及右边为什么长那个样子，都说明白。最后用一个具体的例子看看，这个定理到底能帮我们省多少事。讲完定理，我们顺势进入新的一大节：把傅里叶分析用到通信系统上，第一个主角就是系统函数 $H(\omega)$。

### 傅里叶级数形式：平均功率守恒

对于周期信号 $f(t)$，帕塞瓦尔定理说的是：

$$\frac{1}{T}\int_{0}^{T}|f(t)|^2\,dt=\sum_{n=-\infty}^{+\infty}|F_n|^2$$

即一个周期信号的平均功率，就等于它全部谐波分量的平均功率之和。

等式左边很好理解：先取模、再平方、在一个周期上积分、最后除以周期 $T$——这不就是我们熟悉的求（平均）功率的模式吗？所以左边没什么问题，它就是 $f(t)$ 的平均功率。

那为什么右边是全部谐波分量的平均功率之和呢？我们简单说明一下。学过傅里叶级数，我们知道能把 $f(t)$ 分解成指数形式：

$$f(t)=\sum_{n=-\infty}^{+\infty}F_n\,e^{jn\Omega t}$$

其中 $F_n e^{jn\Omega t}$ 这一项，就是它的 $n$ 次谐波。现在我们就来求一求这个 $n$ 次谐波的平均功率。求平均功率就带那个公式：取模平方、在一个周期上积分、再除以 $T$：

$$\frac{1}{T}\int_{0}^{T}|F_n e^{jn\Omega t}|^2\,dt$$

这里取模可以用一个复数性质：$|ab|=|a|\cdot|b|$，乘积的模等于模的乘积。所以可以把两项拆开来，拆成 $|F_n|^2$ 乘上 $|e^{jn\Omega t}|^2$。

注意后面这一部分：它的模恒等于 $1$。因为这相当于一个旋转矢量，$e^{jn\Omega t}$ 这种东西幅度永远是 $1$，相位才是那个随时间变的部分，所以它的模显然是 $1$，直接划掉不看。

于是就只剩 $|F_n|^2$ 了。而 $F_n$ 里有 $t$ 吗？没有——$t$ 刚才已经被我们处理掉了。没有 $t$，那它就是一个常数，对常数做积分，就是这个常数乘上积分上限减下限：

$$\frac{1}{T}\cdot|F_n|^2\cdot T=|F_n|^2$$

所以 $|F_n|^2$ 其实就是 $n$ 次谐波分量的平均功率。前面再加上一个从 $-\infty$ 到 $+\infty$ 的求和，它自然就是全部谐波分量的平均功率之和了。

> **结论**：$|F_n|^2$ 就是第 $n$ 次谐波分量的平均功率，这就是帕塞瓦尔定理级数形式右端每一项的物理含义。

### 傅里叶变换形式：能量守恒

再看针对傅里叶变换的帕塞瓦尔定理。它的内容是：对于能量信号 $f(t)$，如果它的傅里叶变换是 $F(\omega)$，则

$$\int_{-\infty}^{+\infty}|f(t)|^2\,dt=\frac{1}{2\pi}\int_{-\infty}^{+\infty}|F(\omega)|^2\,d\omega$$

也就是信号在时域上计算的能量，与在频域上计算的能量是相等的。

左边显然是求能量的公式——第一章就讲过，能量信号求能量、功率信号求功率，套路就是求模、平方、再在相应区间上做积分。右边其实也是在频率上求能量，但你注意，它前面多了一个 $\frac{1}{2\pi}$。这个是为什么呢？

我们可以把变量 $\omega$ 换成 $f$ 的形式。这里是以角频率 $\omega$ 为自变量，我们也可以换成以频率 $f$ 为自变量。我们知道 $\omega=2\pi f$，那做一个还原：

$$\frac{1}{2\pi}\int_{-\infty}^{+\infty}|F(2\pi f)|^2\,d(2\pi f)=\int_{-\infty}^{+\infty}|F(2\pi f)|^2\,df$$

$\frac{1}{2\pi}$ 和 $d\omega=2\pi\,df$ 里的 $2\pi$ 直接抵消了。这样就得到一个完美的求能量公式——如果自变量取的是小 $f$，那这里就是一个不含任何系数的、标准的求能量公式。

> **提示**：$\frac{1}{2\pi}$ 这个系数不是帕塞瓦尔定理多出来的玄机，它只是 $\omega=2\pi f$ 这个换算关系的残留。一旦换成以 $f$ 为自变量，公式形式就与"时域求能量"完全对称了。

两种形式放在一起看，一个守恒的是平均功率，一个守恒的是能量，对应的正好是周期（功率）信号与能量信号这两类对象：

| 形式 | 适用对象 | 时域 | 频域 |
| :--- | :--- | :--- | :--- |
| 级数形式 | 周期信号 | $\frac{1}{T}\int_{0}^{T}\lvert f(t)\rvert^2 dt$ | $\sum_{n=-\infty}^{+\infty}\lvert F_n\rvert^2$ |
| 变换形式 | 能量信号 | $\int_{-\infty}^{+\infty}\lvert f(t)\rvert^2 dt$ | $\frac{1}{2\pi}\int_{-\infty}^{+\infty}\lvert F(\omega)\rvert^2 d\omega$ |

### 用帕塞瓦尔定理解题：绕开求 $F(\omega)$

学这个定理有什么用呢？能不能用它来解决一些问题？我们举一个例子来看一下。

题目给了 $f(t)$ 的波形：在 $-1$ 到 $0$ 这一段，它是一条斜率为 $1$ 的上升线段；在 $0$ 到 $1$ 这一段，它是一个常数 $1$；其他地方为零。让你求 $\int_{-\infty}^{+\infty}|F(\omega)|^2\,d\omega$。

这个题应该怎么做？直接去求 $F(\omega)$ 其实也并不复杂，因为 $f(t)$ 的形式比较简单。你可以直接用定义去积；或者利用微积分性质，把它求个导——上升段求导变成一个常数，平顶段求导变成零，$t=1$ 处的跳变求导变成一个向下的冲击——求导之后它的傅里叶变换更好求。求出 $F(\omega)$ 之后，取模、平方、做积分，就能得到结果。

但我说，这么做显然就麻烦了。为什么？大家看要求的这个形式：$\int_{-\infty}^{+\infty}|F(\omega)|^2\,d\omega$——这种形式熟不熟悉？太熟悉不过了，我们刚讲完帕塞瓦尔定理，它和定理右端是不是完全一样的？所以说，一个求 $F(\omega)$ 的问题，可以直接转换成一个求 $f(t)$ 的问题。而 $f(t)$ 的波形题目已经告诉我们了，直接把定理反过来写：

$$\int_{-\infty}^{+\infty}|F(\omega)|^2\,d\omega=2\pi\int_{-\infty}^{+\infty}|f(t)|^2\,dt$$

$f(t)$ 本身就是一个实信号，而且各处取值都是正的，所以模就是它本身。先把 $f(t)$ 的表达式写出来：上升段斜率是 $1$，但它不经过原点——如果斜率为 $1$ 又过原点，应该从 $0$ 升到 $1$；现在它是在 $t=-1$ 处从 $0$ 开始上升，相当于整体左移了 $1$，所以是 $t+1$；平顶段就是常数 $1$：

$$f(t)=\begin{cases}t+1, & -1<t<0\\[2pt] 1, & 0<t<1\\[2pt] 0, & \text{其他}\end{cases}$$

$|f(t)|^2$ 就是各段取平方：$(t+1)^2$ 还是平方，常数 $1$ 平方还是 $1$。其他地方都是零，所以积分只需要对这两段做：

$$\int_{-\infty}^{+\infty}|f(t)|^2\,dt=\int_{-1}^{0}(t+1)^2\,dt+\int_{0}^{1}1\,dt$$

第二段太简单了，直接就是 $1$。第一段打开是 $t^2+2t+1$，原函数是 $\frac{1}{3}t^3+t^2+t$。代入上限 $0$ 得 $0$；代入下限 $-1$，是 $-\frac{1}{3}+1-1=-\frac{1}{3}$，上下限相减得 $\frac{1}{3}$。所以

$$\int_{-\infty}^{+\infty}|f(t)|^2\,dt=\frac{1}{3}+1=\frac{4}{3}$$

别忘了前面还要乘一个 $2\pi$，最终结果就是 $\dfrac{8\pi}{3}$。

你看，用帕塞瓦尔定理就能把这个问题转换成很简单的高数积分问题，傅里叶变换本身根本不用求。课后题就是这样解决的。

### 傅里叶分析为什么重要：从时域卷积到频域乘积

接下来进入新的一大节。我们刚才讲了傅里叶变换的定义、性质，包括一些常用信号的傅里叶变换，也具体做了一些习题。我们在第三章一开始就说过，傅里叶分析这一章是非常重要的一章。这是为什么呢？因为这些傅里叶分析的方法，可以应用于通信系统之上，能很方便地解决通信中的一些问题，所以它重要。这一大节我们就来说一说傅里叶分析应用于通信系统的问题，先看第一部分——系统函数。

之前讲傅里叶变换性质的时候，说过其中很重要的一个性质：卷积特性。它的内容是：时域卷积，其傅里叶变换就是频域乘积。这个性质为什么重要？因为它把时域上一个很复杂的操作——卷积，转换到了频域上一个很简单的操作——乘积，这个简化程度非常大，能大大简化运算。

在这门课最开始的时候我们就说过，信号与系统有一个基本的问题：一个输入信号经过一个系统，输出信号是什么？在第二章我们解答过这个问题，写出了它的数学形式：输入信号设为 $x(t)$，系统的单位冲激响应是 $h(t)$，那么

$$y(t)=x(t)*h(t)$$

就得到输出信号 $y(t)$——当然，这个 $y(t)$ 是零状态的。

你注意，这里就出现了一个卷积。卷积的过程其实是很复杂的，但第二章当时我们没有别的方法，虽然知道它复杂，也只能硬着头皮算。如今不一样了，今非昔比了：我们已经学了傅里叶分析，知道傅里叶变换能将时域卷积转换成频域乘积。所以对这个等式两端做一个傅里叶变换，设 $x(t)$、$h(t)$、$y(t)$ 的傅里叶变换分别为 $X(\omega)$、$H(\omega)$、$Y(\omega)$，就有

$$X(\omega)\,H(\omega)=Y(\omega)$$

时域上的卷积，就变成了频域上的乘积。

### 系统函数 $H(\omega)$

上面这个 $H(\omega)$，我们就叫做系统函数。

时域上一个复杂的卷积问题，只需要做一个傅里叶变换，就得到了一个简单的乘法问题。有些同学觉得傅里叶变换这块的题难，尤其是一些让你去分析系统的综合题。其实这块的题主要就是一个大原则：**时域上如果不好分析，你就去频域；频域上不好分析，那你就去时域。** 我们学了时域和频域，就要灵活转换——怎么转换？做一个傅里叶变换或傅里叶逆变换，就能从时域到频域、频域到时域。同时，要把常用的傅里叶变换对和傅里叶变换的性质牢记，因为这些是解题经常用的。这个掌握了，这块的综合题很大一部分也就没有问题了。

当然，从 $y(t)=x(t)*h(t)$ 得到 $X(\omega)H(\omega)=Y(\omega)$，有一个前提：它们各自的傅里叶变换都得存在。所以系统函数等于 $h(t)$ 的傅里叶变换，它存在的前提是 $h(t)$ 的傅里叶变换得存在。傅里叶变换存在的条件我们之前讲过：

$$\int_{-\infty}^{+\infty}|h(t)|\,dt<\infty$$

这个式子看起来熟不熟悉？我们好像见过——这不就是系统稳定的定义吗？第二章说过，一个系统稳定，要求它的冲激响应的模在负无穷到正无穷上积分小于无穷。也就是说，**对于一个稳定的系统，我们才能求它的系统函数**。

> **易错点**：系统函数不是随便什么系统都有的。$H(\omega)$ 存在的前提是 $h(t)$ 绝对可积，而这恰好就是稳定系统的条件——所以"能写出 $H(\omega)$"和"系统稳定"是一件事的两个说法。

### 幅度与相位的拆分

把 $X(\omega)H(\omega)=Y(\omega)$ 改写一下：

$$H(\omega)=\frac{Y(\omega)}{X(\omega)}$$

所以想求系统函数 $H(\omega)$，只需要求出 $Y(\omega)$ 和 $X(\omega)$，它俩一除就得到了。$Y(\omega)$ 是输出信号的傅里叶变换，$X(\omega)$ 是输入信号的傅里叶变换。

$H(\omega)$ 是一个复函数，所以也可以写成模乘相位的形式：

$$H(\omega)=|H(\omega)|\,e^{j\phi(\omega)}$$

同理，$Y(\omega)$、$X(\omega)$ 也都是复函数——一个信号的傅里叶变换就是复函数，有幅度有相位：

$$Y(\omega)=|Y(\omega)|\,e^{j\phi_y(\omega)},\qquad X(\omega)=|X(\omega)|\,e^{j\phi_x(\omega)}$$

代入 $H(\omega)=\dfrac{Y(\omega)}{X(\omega)}$：

$$|H(\omega)|\,e^{j\phi(\omega)}=\frac{|Y(\omega)|\,e^{j\phi_y(\omega)}}{|X(\omega)|\,e^{j\phi_x(\omega)}}$$

指数相除可以写成指数相减，分母的 $e^{j\phi_x(\omega)}$ 翻上去变成 $e^{j(\phi_y(\omega)-\phi_x(\omega))}$。对照等式两边，模对应模、相位对应相位，显然有：

$$|H(\omega)|=\frac{|Y(\omega)|}{|X(\omega)|},\qquad \phi(\omega)=\phi_y(\omega)-\phi_x(\omega)$$

也就是说，系统函数的幅度是输出幅度与输入幅度之比，系统函数的相位是输出相位减去输入相位。

## 系统对正弦信号的响应、无失真传输与理想低通滤波器
> 对应块：BLK42 | 覆盖分集：P96-P98 | 块标题（分集名）：《3.20系统对正弦信号的响应》

系统函数这个概念本身其实挺简单的，但它真正的价值在于：能用它去解决一串别的问题。这一讲就是一次集中的"收割"——先用系统函数拿下复指数信号和正弦信号的响应，再顺手把无失真传输的条件、理想低通滤波器的来龙去脉一并讲清楚。

### 从复指数信号想起：输出只是"乘个模、加个相位"

回忆一下第三章最开始讲的内容：系统对复指数信号的响应，我们其实早就讨论过了。当时说，当输入为 $e^{j\omega t}$ 时，输出是：

$$y(t)=h(t)*e^{j\omega t}=\int_{-\infty}^{+\infty}h(\tau)e^{j\omega(t-\tau)}\,d\tau$$

这个过程我们做过，这里再重复一遍。积分变量是 $\tau$，所以 $e^{j\omega t}$ 这一项与 $\tau$ 无关，可以直接提到积分号外面：

$$y(t)=e^{j\omega t}\int_{-\infty}^{+\infty}h(\tau)e^{-j\omega\tau}\,d\tau$$

看积分号里面这一块——这不就是傅里叶变换的定义吗？而 $h(\omega)$ 的傅里叶变换我们叫它 $H(\omega)$，也就是系统函数。所以：

$$y(t)=e^{j\omega t}H(\omega)$$

而 $H(\omega)$ 是一个复函数，可以写成幅度和相位的形式 $H(\omega)=|H(\omega)|e^{j\varphi(\omega)}$，于是两个指数可以合并：

$$y(t)=|H(\omega)|\,e^{j(\omega t+\varphi(\omega))}$$

可以看到：当输入为 $e^{j\omega t}$ 时，输出就是在它前面乘上了系统函数的幅度，相位上又加上了系统函数的相位。

> **结论**：输入 $e^{j\omega t} \;\longrightarrow\; y(t)=|H(\omega)|e^{j(\omega t+\varphi(\omega))}$。

那如果输入为 $e^{-j\omega t}$ 呢？做法完全一样。把它代进卷积：

$$y(t)=\int_{-\infty}^{+\infty}h(\tau)e^{-j\omega(t-\tau)}\,d\tau=e^{-j\omega t}\int_{-\infty}^{+\infty}h(\tau)e^{+j\omega\tau}\,d\tau$$

注意此时积分号里这一项**不是**傅里叶变换的定义了——因为这里是正的 $j\omega\tau$，而不是负的。但我们之前也处理过类似的式子：把 $H(\omega)$ 中的 $\omega$ 换成 $-\omega$，不就正好是它吗？所以这个积分就是 $H(-\omega)$：

$$y(t)=|H(-\omega)|\,e^{j(-\omega t+\varphi(-\omega))}$$

既然 $e^{j\omega t}$ 和 $e^{-j\omega t}$ 都有了，那就可以大胆地加以推广：如果输入为 $e^{j\omega_0 t}$，其中 $\omega_0$ 是一个具体的常数，那输出就应该是 $|H(\omega_0)|e^{j(\omega_0 t+\varphi(\omega_0))}$。这个证明过程和前面完全类似，可以自己推一遍：把 $e^{j\omega_0 t}$ 提出积分号，剩下的 $\int h(\tau)e^{-j\omega_0\tau}d\tau$ 非常像傅里叶变换的定义，只是差了点东西——原来那里是变量 $\omega$，现在是常数 $\omega_0$。而 $\omega$ 在 $H(\omega)$ 中只以这一个身份出现，把 $\omega$ 换成 $\omega_0$ 就是它，所以结果就是 $H(\omega_0)$。

> **结论**：输入 $e^{j\omega_0 t} \;\longrightarrow\; y(t)=|H(\omega_0)|e^{j(\omega_0 t+\varphi(\omega_0))}$。用法就是：求出系统函数 $H(\omega)$，把 $\omega$ 代入具体的值 $\omega_0$，取模、取相位，一带入公式输出就出来了。

举个更具体的例子：输入为 $e^{jt}$，这就是 $\omega_0=1$，输出就是 $|H(1)|e^{j(t+\varphi(1))}$。这个结论是很好用的。

### 复指数输入的例题：两条路都走一遍

**例题**：求输入信号 $f(t)=e^{j2t}\cdot e^{j\frac{\pi}{6}}$ 通过 $h(t)=e^{-2t}u(t)$ 的系统后的零状态响应。

题目里让你求"零状态响应"；有的题甚至不显式说，你也得知道它让你求的肯定是零状态响应——第一，它压根什么初始状态都没给你；第二，这里都涉及到 $h(t)$ 了，所以求的肯定是零状态响应。

有同学一看，说这里不是 $e^{j\omega_0 t}$ 的形式啊。你得学会变通：把输入拆成 $e^{j2t}\cdot e^{j\frac{\pi}{6}}$，$e^{j\frac{\pi}{6}}$ 不就是一个常数嘛。常数根据线性可以先不管，最后再乘回去。所以它本质上就是一个复指数信号，$\omega_0=2$。思路就定了：求出 $H(\omega)$，代入 $\omega=2$，求模和相位，带入结论。

#### 先求 $H(2)$ 的模和相位

$h(t)=e^{-2t}u(t)$ 是单边指数信号，它的傅里叶变换是 $\dfrac{1}{a+j\omega}$ 的形式（这里 $a=2$）：

$$H(\omega)=\frac{1}{2+j\omega},\qquad H(2)=\frac{1}{2+2j}$$

求这种 $\dfrac{a+jb}{c+jd}$ 形式复数的模和相位，可以直接套公式：

$$\left|\frac{a+jb}{c+jd}\right|=\frac{\sqrt{a^2+b^2}}{\sqrt{c^2+d^2}},\qquad \varphi=\arctan\frac{bc-ad}{ac+bd}\quad(\text{前提：}ac+bd>0)$$

幅度很好求：

$$|H(2)|=\sqrt{\frac{1}{2^2+2^2}}=\sqrt{\frac{1}{8}}=\frac{\sqrt{2}}{4}$$

相位要先检查条件：这里 $a=1$、$b=0$、$c=2$、$d=2$，$c,d$ 都大于零，所以 $ac+bd=2>0$，条件没问题。直接代公式：

$$\varphi(2)=\arctan\frac{-ad}{ac}=\arctan\frac{-d}{c}=\arctan(-1)=-\frac{\pi}{4}$$

于是 $H(2)=\dfrac{\sqrt{2}}{4}e^{-j\frac{\pi}{4}}$。代入结论，$e^{j2t}$ 过系统的输出是 $\dfrac{\sqrt{2}}{4}e^{j(2t-\frac{\pi}{4})}$，别忘了前面还有常数 $e^{j\frac{\pi}{6}}$，乘回去并把指数合并：

$$y(t)=\frac{\sqrt{2}}{4}\,e^{j\left(2t-\frac{\pi}{4}+\frac{\pi}{6}\right)}=\frac{\sqrt{2}}{4}\,e^{j\left(2t-\frac{\pi}{12}\right)}$$

#### 传统方法也做一遍

如果说没想到这个结论，也可以用传统的那种分析方法：$y(t)=f(t)*h(t)$，两边做傅里叶变换，$Y(\omega)=F(\omega)H(\omega)$，求出 $Y(\omega)$ 后再做一个傅里叶逆变换就得到 $y(t)$。这种方法也并不复杂，走一遍看看。

输入的傅里叶变换：$e^{j\frac{\pi}{6}}$ 是常数，根据线性直接拿出来；而 $e^{j2t}$ 是复指数信号，对复指数信号做傅里叶变换我们讲过，结果是 $2\pi\delta(\omega-2)$。所以：

$$F(\omega)=e^{j\frac{\pi}{6}}\cdot 2\pi\delta(\omega-2)$$

于是：

$$Y(\omega)=\frac{1}{2+j\omega}\cdot e^{j\frac{\pi}{6}}\cdot 2\pi\delta(\omega-2)$$

观察 $Y(\omega)$ 的形式：前面是常数，后面出现了一个 $\delta(\omega-2)$。这时就要用到冲激函数的性质：$f(t)\cdot\delta(t-t_0)=f(t_0)\,\delta(t-t_0)$。这里是 $F_1(\omega)\cdot\delta(\omega-2)$ 的形式，所以把 $\omega=2$ 代进去取样，$Y(\omega)$ 变成：

$$Y(\omega)=\frac{1}{2+2j}\,e^{j\frac{\pi}{6}}\cdot 2\pi\delta(\omega-2)$$

现在前面这些系数全是常数了（冲激把那个随 $\omega$ 变的因子"冻结"成了常数），做傅里叶逆变换时只看冲激这一项：$2\pi\delta(\omega-2)$ 的逆变换不又回来了吗？就是 $e^{j2t}$。所以：

$$y(t)=\frac{1}{2+2j}\,e^{j\frac{\pi}{6}}\,e^{j2t}$$

把 $\dfrac{1}{2+2j}$ 写成模和相位的形式 $\dfrac{\sqrt{2}}{4}e^{-j\frac{\pi}{4}}$，它和前面得到的形式完全一样——两种方法结果相同。

可以看到法二其实也并不麻烦，但比起法一它肯定慢了一些，毕竟法一是根据一个固有的结论来做的。不过法一有它的局限性：只有输入为复指数的时候才能这么做；而法二是解决问题的一般方法，什么输入都能对付。

#### 顺带说一句考试的事

既然牵扯到求模和相位，不同学校在考试中的要求是不一样的。有的学校允许带计算器——这种时候要买一个稍微贵一点的计算器，因为贵一点的可以直接求复数的模和相位。能带计算器就千万不要手算，计算器又快又准。所以你要提前买好，而且不要买好就在那放着，得提前试一试、用一用，把这些功能练熟。允许带计算器的考场，也可能出现一些比较复杂的复数，那些求模求相位手算起来更麻烦，就更要交给计算器。

如果不让带计算器，它也可能让你求模和相位，但此时绝对不会让你求很难的复数的模和相位，都会是一些很简单的复数——直接用上面那个公式求一下就行，就算不背公式，自己现场简单推一下也能推出来。

### 余弦信号的响应：还是"乘模、加相位"

刚才讨论的是系统对复指数信号的响应，但别忘了这一节的标题是"系统对**正弦**信号的响应"。为什么先讨论复指数？因为正弦和复指数它们是一家的，用欧拉公式可以互相转化。研究完复指数，接下来就轮到正弦了。

为了一般性，设输入信号为 $A\cos(\omega t+\varphi_0)$，幅度为 $A$，相位是 $\varphi_0$。用欧拉公式展开成复指数的形式：

$$A\cos(\omega t+\varphi_0)=\frac{A}{2}e^{j\varphi_0}e^{j\omega t}+\frac{A}{2}e^{-j\varphi_0}e^{-j\omega t}$$

注意 $e^{j\varphi_0}$ 和 $e^{-j\varphi_0}$ 都是常数，可以各自单独提出来。剩下两个复指数作为输入的响应情况我们已经讨论过了：

- 输入 $e^{j\omega t}$，零状态响应为 $|H(\omega)|e^{j(\omega t+\varphi(\omega))}$；
- 输入 $e^{-j\omega t}$，零状态响应为 $|H(-\omega)|e^{j(-\omega t+\varphi(-\omega))}$。

现在假定 $h(t)$ 是一个实信号，或者说这个系统是一个实系统。实际上我们见到的 $h(t)$ 绝大多数都是实函数——你见过 $h(t)$ 是复数的吗？肯定没见过，所以这个条件基本都能成立。此时傅里叶变换有一个性质叫**奇偶虚实性**：幅度谱是偶函数，$|H(-\omega)|=|H(\omega)|$；相位谱是奇函数，$\varphi(-\omega)=-\varphi(\omega)$。在这种前提下，第二项的响应可以改写成：

$$|H(\omega)|\,e^{-j(\omega t+\varphi(\omega))}$$

两项都是"常数 × 复指数"，根据线性，各自乘上系数再相加就是总响应：

$$y(t)=\frac{A}{2}|H(\omega)|e^{j(\omega t+\varphi_0+\varphi(\omega))}+\frac{A}{2}|H(\omega)|e^{-j(\omega t+\varphi_0+\varphi(\omega))}$$

注意括号内是"一正一负"的指数形式——这不又可以变回去变成 $\cos$ 的形式吗？我们刚才是把 $\cos$ 拆分成复指数，现在反过来，$\frac{1}{2}(\text{正}+\text{负})=\cos$，两个 $\frac{A}{2}|H(\omega)|$ 合起来正好消掉 $\frac{1}{2}$：

> **结论**：输入 $A\cos(\omega t+\varphi_0) \;\longrightarrow\; y(t)=A|H(\omega)|\cos\big(\omega t+\varphi_0+\varphi(\omega)\big)$。

跟复指数时的结论很类似：幅度乘上 $|H(\omega)|$，相位加上 $\varphi(\omega)$。同样可以代入具体的 $\omega_0$：比如输入为 $\cos 2t$，那就是取 $H(2)$，求出 $|H(2)|$ 和 $\varphi(2)$ 带进来，输出就是 $|H(2)|\cos(2t+\varphi(2))$。

这里再提一个小结论：当 $H(\omega)$ 存在时，如果激励是**周期信号**，那么其引起的响应即为零状态响应，同时也为**稳态响应**。比如 $\cos$ 就是一个周期信号，看上面得到的响应——它依然是一个 $\cos$，波形一直稳定存在，显然是稳态响应。

那如果输入是 $\sin$ 呢？完全类似，不重复证明了。而且 $\sin$ 和 $\cos$ 只有一个相位的差别：$\sin$ 和 $\cos$ 相位差了二分之派，所以

$$A\sin(\omega t+\varphi)=A\cos\left(\omega t+\varphi-\frac{\pi}{2}\right)$$

把 $\varphi_1=\varphi-\frac{\pi}{2}$ 当作新的相位套用刚才的结论，输出为 $A|H(\omega)|\cos(\omega t+\varphi_1+\varphi(\omega))$，再把 $\varphi_1$ 恢复回去，得到的还是：

$$y(t)=A|H(\omega)|\sin\big(\omega t+\varphi+\varphi(\omega)\big)$$

所以对正弦输入，结论和 $\cos$ 的是一样的：幅度乘 $|H(\omega)|$，相位加 $\varphi(\omega)$。

### 正弦输入求稳态响应的例题

**例题**：已知 LTI 系统的频率响应 $H(\omega)=\dfrac{4}{2+j\omega}$，输入信号 $f(t)=3\sin 2t$，求稳态响应 $y_{ss}(t)$。

这个题很好，它直接把频率响应都告诉我们了——之前那个例子给的是 $h(t)$，还得再做一次傅里叶变换才能得到 $H(\omega)$。做法就是套结论：输入是正弦信号，$\omega=2$，直接代入：

$$H(2)=\frac{4}{2+2j}=\frac{2}{1+j}$$

求幅度：

$$|H(2)|=\frac{4}{\sqrt{2^2+2^2}}=\frac{4}{2\sqrt{2}}=\sqrt{2}$$

求相位：$a=4,b=0,c=2,d=2$，$a,b,c,d$ 都大于零，$ac+bd=8>0$ 可以直接用公式；$b=0$ 让分子只剩 $-ad$，约掉 $a$ 后是 $\arctan(-\frac{d}{c})=\arctan(-1)=-\frac{\pi}{4}$（因为 $\arctan\frac{\pi}{4}$ 对应的正切值是 1，取负就是 $-\frac{\pi}{4}$）。所以：

$$H(2)=\sqrt{2}\,e^{-j\frac{\pi}{4}}$$

知道幅度、知道相位，代入结论。稳态响应有的书上用 $y_{ss}$ 表示，有的书上用 $r_{ss}$ 表示，这无所谓，只是一个符号而已：

$$y_{ss}(t)=3\times\sqrt{2}\,\sin\left(2t-\frac{\pi}{4}\right)=3\sqrt{2}\,\sin\left(2t-\frac{\pi}{4}\right)$$

可以看到非常简单。但如果不知道这个结论，做起来花的时间就多得多了：你得先对 $3\sin 2t$ 求傅里叶变换，然后乘上 $H(\omega)$ 得到零状态响应的傅里叶变换，再做一个傅里叶逆变换，还要用到"激励是周期信号时响应即为稳态响应"那个结论才能确认结果。不是不能做，做起来也并不麻烦，但麻烦多了。所以这个结论大家要记一下，做题会用到。

### 无失真传输：只许变幅度，不许变波形

接下来看第三部分，无失真传输。所谓无失真传输，是指输出信号与输入信号相比，**只有幅度的大小和出现时间的先后不同，而没有波形上的变化**。即：

$$y(t)=K\,f(t-t_d),\qquad t_d>0$$

输出信号的幅度是输入信号的 $K$ 倍，然后比输入信号延时了 $t_d$。注意 $t_d$ 要大于零，所以这里是延时。为什么 $t_d$ 不能小于零？因为现实生活中，输出肯定是在输入信号之后的：你得先发一个输入信号，可能过了几秒得到一个输出，这是没问题的；但不可能输出信号反而出现在输入信号之前——我还没输入呢，你就输出了，这是不可能的，我们现在没有这种"预知"的能力，做不到。

画个图更直观。比如传输这样一个信号：

```text
   f(t)                         y(t) = K·f(t−td)
     │      ⌒⌒⌒                    │        ⌒⌒⌒
     │    ⌒     ⌒                  │      ⌒     ⌒
     │   ⌒       ⌒                 │     ⌒       ⌒
 ────┼─────────────→ t         ────┼───┼──────────→ t
                          （幅度乘 K，整体延时 td，拱形不变）
```

这两个信号波形是相同的，虽然幅度有变化，但我给它乘以一个常数 $1/K$ 就能变回去——这就是无失真传输。但如果本来是这样的信号，传输之后变成了别的形状，两个波形不一样了，这就称为失真。

时域的条件有了，我们也可以对它做一个傅里叶变换，到频域上去看。对 $y(t)=K f(t-t_d)$ 两端做傅里叶变换：常数 $K$ 根据线性直接拿下来；$f(t-t_d)$ 是延时，用时移特性，它的傅里叶变换是 $F(\omega)e^{-j\omega t_d}$。所以：

$$Y(\omega)=K\,F(\omega)e^{-j\omega t_d}$$

而我们又知道 $Y(\omega)=H(\omega)F(\omega)$，对照一下，$F(\omega)$ 之外剩下的那部分就是系统函数：

> **结论**：无失真传输系统的频率响应（系统函数）为 $H(\omega)=K\,e^{-j\omega t_d}$。这就是无失真传输的**频率条件**。

上面说的是时域的条件，这个 $H(\omega)$ 的幅度和相位都非常好写：

$$|H(\omega)|=K,\qquad \varphi(\omega)=-\omega t_d$$

两个表达式都特别简单，因此可以很轻松地画出这个系统的幅频特性和相频特性：

```text
     |H(ω)|                          φ(ω)
       │                               │
   K   │────────────────               │   （斜率为 −td < 0，
       │                               │     过原点的下降直线）
       └───────────────────→ ω         └───────＼───────→ ω
                                                ＼
```

幅度那条线其实很直观：无失真传输允许幅度改变，可以乘以一个常数，所以 $|H(\omega)|$ 就是一个常数 $K$，这条线从来不出问题。但相位那条线，可能就有同学不理解：为什么相位是一条过原点的直线？

### 相位为什么必须是一条过原点的直线

书上那句解释——"激励中各频率分量滞后相同的时间，才能无失真"——确实看起来很抽象，我们得举一个具体的例子来看。

设输入信号为 $\sin\omega_1 t+\sin 2\omega_1 t$，$\omega_1$ 是一个常数。可以看到这两部分的角频率不同：第一部分是 $\omega_1$，第二部分是 $2\omega_1$。我们想让这个信号进行无失真传输，也就是变成 $K$ 倍再延时 $t_0$——把 $t$ 换成 $t-t_0$。幅度我们不关心，主要关心相位：

```text
   输入:  sin(ω₁t) + sin(2ω₁t)
                    │ 无失真传输：t → t−t₀
                    ▼
   输出:  sin[ω₁(t−t₀)] + sin[2ω₁(t−t₀)]
        = sin(ω₁t − ω₁t₀) + sin(2ω₁t − 2ω₁t₀)
```

读图说明：对两个不同频率的正弦信号做了**相同的延时** $t_0$，但把括号打开后会发现，它们的**相位变化是不同的**——第一项相位变化了 $-\omega_1 t_0$，第二项相位变化了 $-2\omega_1 t_0$。

可以看到，相位的变化量加上负号后，与信号本身的频率**成正比**。这里只举了 $\omega_1$ 和 $2\omega_1$ 两个例子，多举几个也是一样的。所以这就是为什么 $\varphi(\omega)=-\omega t_d$ 是一条过原点的直线：要保证各频率分量在时间上滞后相同，相位的变化就必须与频率成正比，反映在图像上就是这么一条过原点的直线。

### 理想低通滤波器：低于 ωc 的无失真放行，高于的归零

接下来看第四部分，理想低通滤波器。它的系统函数表达式是一个分段函数：

$$H(\omega)=\begin{cases}e^{-j\omega t_0}, & |\omega|\le\omega_c\\[4pt] 0, & |\omega|>\omega_c\end{cases}$$

它的幅度特性和相位特性长这样：

```text
     |H(ω)|                             φ(ω)
       │    ┌───────┐                      │    ／
       │    │       │                      │   ／
   1   ┼────┘       └────                  │  ／
       │    │       │                      │ ／
       └────┼───────┼───────→ ω            └──────────→ ω
           −ωc      ωc                （|ω| ≤ ωc 内为 −ωt₀ 直线）
```

试想一个信号 $f(t)$，它的频谱 $F(\omega)$ 随便画一下。$F(\omega)$ 与 $H(\omega)$ 相乘：如果 $|\omega|>\omega_c$，由于这里 $H(\omega)=0$，而 0 与任何数相乘都为 0，所以相乘的结果就是把 $|\omega|>\omega_c$ 的部分都化为 0——这部分相当于被截断了，没有了。而剩下的 $|\omega|<\omega_c$ 这一部分和它相乘，幅度没有变化，但相位是有变化的。

而这个相位是什么呢？大家熟不熟悉？我们刚说过，它就是**无失真传输的相位条件**。所以：

> **结论**：理想低通滤波器的作用，就是将角频率低于 $\omega_c$ 的信号**无失真地传输**——通带内幅度是一个常数（而且是 1，没有任何变化），相位也满足无失真传输的条件；高于 $\omega_c$ 的分量直接乘 0，完全滤掉。

其实理想低通滤波器的幅度特性就是一个门函数，不过它多了一个相位。所以 $H(\omega)$ 也可以表示成频域门函数乘上一个相位：

$$H(\omega)=e^{-j\omega t_0}\,g_{2\omega_c}(\omega)$$

门函数的宽度是 $2\omega_c$，正好对应通带。这里还要注意一点：$\varphi(\omega)=-\omega t_0$ 中的 $t_0$ 是可以为 0 的。如果 $t_0=0$，那 $\varphi(\omega)=0$，其实 $H(\omega)$ 就是一个纯粹的门函数——$\varphi=0$ 相当于时域上没有时移，因为时移会带来相位的改变。

顺便把前面的话接上：之前讲抽样信号的时候，说将抽样信号的频谱还原成原信号的频谱，当时说是在那里加了一个门函数——现在也可以换一种说法，那就是加了一个理想低通滤波器。

### 冲激响应与"理想"二字的分量

知道了频域特性，那它时域是什么样的？我们来求一求冲激响应 $h(t)$。因为门函数的傅里叶逆变换是我们所熟知的，就从门函数形式入手，对 $H(\omega)=e^{-j\omega t_0}g_{2\omega_c}(\omega)$ 做傅里叶逆变换。

这里要用到那对经典的傅里叶变换对——取样函数（Sa 函数）的傅里叶变换是门函数：

$$\text{Sa}(at)\;\longleftrightarrow\;\frac{\pi}{a}\,g_{2a}(\omega)$$

我们这里是 $g_{2\omega_c}(\omega)$，所以把 $a$ 换成 $\omega_c$ 即可。当然前面还多出来一个系数：不能无缘无故多一个 $\frac{\pi}{\omega_c}$，前面得乘上 $\frac{\omega_c}{\pi}$，这样两个系数相乘就是 1。于是 $g_{2\omega_c}(\omega)$ 的逆变换就是 $\frac{\omega_c}{\pi}\text{Sa}(\omega_c t)$。

那前面的 $e^{-j\omega t_0}$ 怎么处理？不用单独做逆变换——我们知道时移性质：$f(t)$ 时移成 $f(t-t_0)$，在频域上就相当于 $F(\omega)$ 乘上 $e^{-j\omega t_0}$。反过来，频域上乘了它，时域上只需要把 $t$ 换成 $t-t_0$ 即可。所以：

$$h(t)=\frac{\omega_c}{\pi}\,\text{Sa}\big[\omega_c(t-t_0)\big]$$

这就是理想低通滤波器的冲激响应。画个大概的波形——它就是对 Sa 函数做了一个时延，Sa 函数本来中心在原点，时延之后中心挪到了 $t_0$ 那里：

```text
   h(t) = (ωc/π)·Sa[ωc(t−t₀)]

     │           ⌒⌒⌒
     │         ⌒     ⌒
 ────┼──────────┼──────────→ t
     │          t₀      （t < 0 处波形并不为零 → 非因果）
```

这里就有一点值得注意了：对于一个因果信号/因果系统，要求 $t<0$ 时 $h(t)$ 都等于 0。而我们这里的 $h(t)$ 显然不满足——冲激信号是在 $t=0$ 时刻接入的，可它的响应在 $t<0$ 就已经存在了，相当于我还没有接入冲激信号，就已经有冲激响应了。这在现实中显然是不可能实现的，非因果信号在现实中不可能实现。

所以别忘了我这个小节的标题——"**理想**低通滤波器"。什么是理想？"理想"这两个字的意思就是：现实中实现不了。但在理论上我们需要它，理论分析上离不开它；只是现实中它是不能实现的，这是要注意的一点。当然不是说个人的理想实现不了，不是那个意思——这里"理想"这个名词指的是现实上实现不了，不是梦想那个理想。

### 顺带认一认其他滤波器

我们说的是低通滤波器：让频率比较低的分量通过，频率比较高的变为 0。借此机会把其他种类的滤波器也认一认，题干中可能会出现"一个信号经过带通滤波器""经过高通滤波器"这样的说法，简单知道这几个词是什么意思就行：

| 种类 | 让谁通过 | 谁被滤为 0 |
| :--- | :--- | :--- |
| 低通 | $\|\omega\|\le\omega_c$（低频） | 高频 |
| 带通 | $\omega_1<\|\omega\|<\omega_2$（一个频率区间） | 区间之外 |
| 高通 | $\|\omega\|>\omega_c$（高频） | 低频 |
| 带阻 | 低频和高频都通过 | 某一段区间通不过 |

带通滤波器只让一个频率范围之内的信号通过，其他地方都为 0：比如只让 $\omega_1<|\omega|<\omega_2$ 这一段频率区间的信号通过。高通滤波器反过来，只让 $|\omega|>\omega_c$ 的高频分量通过，低频都为 0。带阻滤波器则是频率比较低的能通过、频率比较高的也能通过，唯独中间一段通不过。一眼扫过，这几种滤波器就都认识了。

## 调制与解调：频谱搬移的完整闭环
> 对应块：BLK43 | 覆盖分集：P99-P100 | 块标题（分集名）：《3.23调制与解调》

### 从课后题说起：调制解调到底怎么考

通信中调制和解调的方式非常多，具体的调制解调方法会在通信原理课里去学；在信号系统这门课里，我们不去详细讲那些具体方法。但题目确实可能让你去做一个调制、或者做一个解调——如果考，它**一定会把调制解调的过程告诉你**，你照着它说的过程慢慢去做就可以了。这个"照过程做"，本质上就是一个傅里叶分析的问题：时域上搞不明白，就去频率上做；频率上比较复杂，再回到时域上做。课后题 5-27、5-28 就是这种题（在另一个视频里已经讲过，感兴趣可以去看看）。

这一讲先用一个最简单的例子把调制与解调的完整过程走一遍，再用两道例题把它落到考场上。

### 调制：乘一个余弦，频谱一分为二搬上高频

设 $f(t) \leftrightarrow F(\mathrm{j}\omega)$，频谱集中在 $-\omega_m \sim \omega_m$ 的低频段。现在想对 $f(t)$ 进行调制——把它的频谱搬移到高频，这样便于传输。做法是让它乘一个余弦：

$$f(t)\cos\omega_0 t$$

$\cos\omega_0 t$ 的傅里叶变换是**必须背下来**的公式：

$$\cos\omega_0 t \leftrightarrow \pi\left[\delta(\omega+\omega_0)+\delta(\omega-\omega_0)\right]$$

它的频谱就是在 $\pm\omega_0$ 处的两个冲激，两个冲激的面积都是 $\pi$。

时域相乘，频域卷积，别忘了再乘 $\dfrac{1}{2\pi}$。而一个信号与冲激相卷积，就是把这个信号搬移到冲激所在的位置：$F(\mathrm{j}\omega)$ 与 $\pi\delta(\omega-\omega_0)$ 卷积，整体向右搬 $\omega_0$；与 $\pi\delta(\omega+\omega_0)$ 卷积，整体向左搬 $\omega_0$。冲激面积是 $\pi$，幅度要乘 $\pi$，但还乘了一个 $\dfrac{1}{2\pi}$，所以幅度净变为原来的 $\dfrac{1}{2}$：

$$f(t)\cos\omega_0 t \leftrightarrow \frac{1}{2}F\big(\mathrm{j}(\omega-\omega_0)\big)+\frac{1}{2}F\big(\mathrm{j}(\omega+\omega_0)\big)$$

```text
        F(jω)                        f(t)·cos(ω0t) 对应的频谱
          ┌────┐
          │ 1  │                             ┌────┐       ┌────┐
          │    │                             │1/2 │       │1/2 │
   ───────┴────┴──────→ ω                ─────┴────┴───────┴────┴────→ ω
         -ωm   ωm                              -ω0    0     ω0
```

左图是原信号的低通型频谱；右图是调制之后的频谱：整个频谱幅度降低一半，向左、向右各搬移 $\omega_0$，原来的低频分量搬到了 $\pm\omega_0$ 附近的高频处。到这里，调制——把频谱搬上高频便于传输——就完成了。

### 解调：再乘一次余弦，低通滤波器收尾

信号传输过去之后，我们肯定还是想把它还原成原来的信号，这就需要对它进行解调。做法：对已调信号再乘一个同频的 $\cos\omega_0 t$。

频域上做一遍同样的操作。现在的频谱是 $\pm\omega_0$ 处幅度 $\dfrac{1}{2}$ 的两块，再与 $\pm\omega_0$ 处面积为 $\pi$ 的两个冲激卷积，一块一块地看：

- 左边那块向右搬 $\omega_0$，回到零点处；
- 左边那块向左搬 $\omega_0$，搬到 $-2\omega_0$ 处；
- 右边那块同理：一块回零点，一块到 $+2\omega_0$。

同时每块的幅度又要变为原来的 $\dfrac{1}{2}$，也就是 $\dfrac{1}{4}$。于是中间原点处的两块 $\dfrac{1}{4}$ 叠加，变回 $\dfrac{1}{2}$；而 $\pm 2\omega_0$ 处各多出一块 $\dfrac{1}{4}$——这两部分肯定是我们不想要的。

```text
       ┌────┐          ┌────────────┐          ┌────┐
       │1/4 │          │     1/2    │          │1/4 │
  ─────┴────┴──────────┴────────────┴──────────┴────┴─────→ ω
            -2ω0           0             2ω0
```

再乘一次 $\cos\omega_0 t$ 之后：中心两块各 $\frac{1}{4}$ 叠回 $\frac{1}{2}$，而 $\pm 2\omega_0$ 处多出两块 $\frac{1}{4}$，它们是要被滤掉的高频残余。

我们想让它变回原来的样子，只需要加一个**低通滤波器**，把 $\pm 2\omega_0$ 处的两块滤掉。低通滤波器的幅度可以稍微调整一下：把它的幅度设为 2，这样 $2\times\dfrac{1}{2}$ 刚好变回原来的 1。它与低通滤波器一乘，两边都没有了，中间乘 2，就恢复出了原信号。频谱恢复了，时域信号也就恢复成原来的 $f(t)$。

> **结论**：解调 = 再乘一个 $\cos\omega_0 t$，然后加一个增益为 2 的低通滤波器。

解调的过程也可以从时域上分析。原来 $f(t)$ 乘 $\cos\omega_0 t$，现在又乘一个 $\cos\omega_0 t$，两个 cos 频率相同，可以合在一起：

$$f(t)\cos^2\omega_0 t = f(t)\cdot\frac{1}{2}\left(1+\cos 2\omega_0 t\right) = \frac{1}{2}f(t)+\frac{1}{2}f(t)\cos 2\omega_0 t$$

第二项显然是高频分量。随便画一个 $f(t)$ 的波形，它乘上一个 cos 之后，会变成幅度随 $f(t)$ 包络起伏的高频振荡——两个信号相乘就会开始"振动"（第一章讲过）。把高频分量去掉，剩下 $\dfrac{1}{2}f(t)$，再乘 2，就恢复了原来的 $f(t)$。

### 例题一：乘法器加低通滤波器

题目：如图所示系统，已知乘法器的一个输入为 $f(t)=\dfrac{\sin 2t}{t}$，另一个输入为 $\cos 3t$；乘法器的输出再经过一个频率响应为 $H(\mathrm{j}\omega)$ 的系统（$|\omega|<3$ 时为 1，其余为 0），求输出 $y(t)$。

这是一个很典型的用傅里叶变换去分析通信系统的问题。按系统一步一步来看：乘法器输出 $x(t)=f(t)\cos 3t$；再乘上 $H(\mathrm{j}\omega)$ 得 $Y(\mathrm{j}\omega)$，反变换得 $y(t)$。

为什么不能在时域上做？$x(t)$ 要与系统的冲激响应 $h(t)$ 作卷积，而 $H(\mathrm{j}\omega)$ 显然是一个低通滤波器（门函数），门函数的傅里叶逆变换是 Sa 函数——一个信号卷上一个 Sa 函数，这个计算量你根本承受不了，或者说你根本就不会做。所以这一章的基本思路就是：**时域不好做，就去频率上做**——一个信号经过一个系统，在时域上是卷积，在频域上是乘积。

#### 求乘法器输出的频谱

$x(t)$ 是两项乘积的形式，两部分的傅里叶变换都很好求。

第一项虽然写成了 $\dfrac{\sin 2t}{t}$ 的形式，但要能一眼认出它其实是一个 Sa 函数——这个题就是想看看你能不能看出来。凑一下：$\dfrac{\sin 2t}{t}=2\cdot\dfrac{\sin 2t}{2t}=2\,\mathrm{Sa}(2t)$。由 $\mathrm{Sa}(at)\leftrightarrow\dfrac{\pi}{a}g_{2a}(\omega)$，$\mathrm{Sa}(2t)\leftrightarrow\dfrac{\pi}{2}g_4(\omega)$，别忘了前面还有一个 2：

$$F(\mathrm{j}\omega)=\pi g_4(\omega)$$

高度为 $\pi$、宽度为 4 的门函数。

第二项是 $\cos 3t$，直接套必背公式（$\omega_0=3$，注意 cos 对应的是加法）：

$$\cos 3t \leftrightarrow \pi\left[\delta(\omega+3)+\delta(\omega-3)\right]$$

时域相乘频域卷积、乘 $\dfrac{1}{2\pi}$：两个 $\pi$ 相乘变成 $\pi^2$，再乘 $\dfrac{1}{2\pi}$，约掉一个 $\pi$：

$$X(\mathrm{j}\omega)=\frac{\pi}{2}\left[g_4(\omega-3)+g_4(\omega+3)\right]$$

其实这里不硬算也行——画出波形会更直观。$g_4(\omega)$ 与冲激卷积，就是把门函数整体搬到 $\pm 3$ 处，幅度乘 $\pi$，再乘 $\dfrac{1}{2\pi}$，得 $\dfrac{\pi}{2}$。著名的数学家华罗庚说过："数形结合百般好。"而且这个表达式的波形是非常好画的。

```text
   X(jω)：高 π/2、宽 4 的两块门函数
         π/2
         ┌────┐                  ┌────┐
         │    │                  │    │
   ──────┴────┴──────────────────┴────┴─────→ ω
        -5   -1                  1    5

   H(jω)：|ω|<3、高 1 的门函数（低通）
         1
    ┌────────────────┐
    │                │
────┴────────────────┴─────────→ ω
   -3                3
```

#### 波形相乘，Y(jω) 直接看出来

接下来 $Y(\mathrm{j}\omega)=X(\mathrm{j}\omega)\cdot H(\mathrm{j}\omega)$。如果硬让两个表达式相乘，最后得到的式子会很复杂——直接让他俩的波形相乘不就得了。两波形画在同一张坐标上，只要有一个为零，乘积就为零：$[-3,-1]$ 与 $[1,3]$ 内两者都不为零；中间 $|\omega|<1$ 内 $X$ 为零，$|\omega|>3$ 内 $H$ 为零。所以乘积只剩下两段公共部分，宽度为 2，高度 $\dfrac{\pi}{2}$ 没有变化：

$$Y(\mathrm{j}\omega)=\frac{\pi}{2}\left[g_2(\omega-2)+g_2(\omega+2)\right]$$

```text
   Y(jω)：只留下公共部分 [-3,-1] 与 [1,3]
         π/2
           ┌──┐               ┌──┐
           │  │               │  │
   ────────┴──┴───────────────┴──┴────────→ ω
           -3 -1               1  3
```

通过波形相乘得到 $Y(\mathrm{j}\omega)$，非常简单、非常直观。数就是信号的表达式，形就是信号的波形——这提醒我们数形结合。

#### 反变换收尾与快捷方式

为了逆变换方便，把 $Y(\mathrm{j}\omega)$ 写成门函数形式：中心那个门宽 2、高 $\dfrac{\pi}{2}$，即 $\dfrac{\pi}{2}g_2(\omega)$；再一个向左移 2、一个向右移 2。由 $\mathrm{Sa}(t)\leftrightarrow\pi g_2(\omega)$ 反查，$\dfrac{\pi}{2}g_2(\omega)\leftrightarrow\dfrac{1}{2}\mathrm{Sa}(t)$。接下来处理平移：

$$y(t)=\frac{1}{2}\mathrm{Sa}(t)\,e^{\mathrm{j}2t}+\frac{1}{2}\mathrm{Sa}(t)\,e^{-\mathrm{j}2t}$$

> **易错点**：频域平移与时域平移的指数符号最容易搞混。频域右移 $F\big(\mathrm{j}(\omega-\omega_0)\big)$ 对应时域乘 $e^{\mathrm{j}\omega_0 t}$；时域平移 $f(t-t_0)$ 对应频域乘 $e^{-\mathrm{j}\omega t_0}$。这两对方向千万不要记反。

第二部分根据欧拉公式合并：$\dfrac{1}{2}\left(e^{\mathrm{j}2t}+e^{-\mathrm{j}2t}\right)=\cos 2t$，所以

$$y(t)=\mathrm{Sa}(t)\cos 2t$$

其实求这个逆变换还有一种更为简单的方式。注意 $Y(\mathrm{j}\omega)$ 频谱的形状：左右对称的两块，相当于把中心的一个频谱向左、向右各搬移 2 得到。谁能做到这种频谱搬移的效果？就是我们的余弦函数——$f(t)\cos\omega_0 t$ 在频域上正是 $\dfrac{1}{2}F\big(\mathrm{j}(\omega-\omega_0)\big)+\dfrac{1}{2}F\big(\mathrm{j}(\omega+\omega_0)\big)$。反过来看 $Y(\mathrm{j}\omega)$：把中心谱的幅度加倍还原到原点，得 $\pi g_2(\omega)\leftrightarrow\mathrm{Sa}(t)$，再乘 $\cos 2t$ 即可。如果你对 cos 这个信号足够熟悉，就可以这么去做——这是一个快捷方式。

### 例题二：周期斜坡信号过三角形滤波器

第二道题，我觉得它绝对配得上一套卷子的最后一道压轴题：它会用到很多以前学过的知识，而且有一个比较大的计算量；但其实整体的思路不难，怎么做很容易想。

题目：如图所示系统，滤波器的 $H(\mathrm{j}\omega)$ 如图所示（三角形：$\omega=0$ 处为 2，随 $|\omega|$ 增大线性下降，到 $|\omega|=4\pi$ 处为 0）；输入 $f(t)$ 从波形上可以看到是一个周期信号，周期 $T_1=1$，一个周期内（$0\sim 1$）表达式非常简单：$f(t)=t$。求输出 $y(t)$，并画 $y(t)$ 的波形。

```text
   f(t)：周期 T1 = 1，一个周期内 f(t) = t
    1 -    /|       /|       /|
       |  / |      / |      / |
       | /  |     /  |     /  |
       |/   |    /   |    /   |
    0 -+----+---+----+---+----+---→ t
       0    1        2        3

   H(jω)：三角形滤波器（0 处为 2，±4π 处为 0）
    2 -             /\
      |            /  \
      |           /    \
      |          /      \
    0 +---------/--------\--------→ ω
               -4π   0    4π
```

思路非常简单：$f(t)$ 经过滤波器得 $y(t)$，先求 $F(\mathrm{j}\omega)$，乘上 $H(\mathrm{j}\omega)$ 得 $Y(\mathrm{j}\omega)$，再反变换。但注意这里**一定要在频率上做**，时域上做是不可能的：单周期斜坡的傅里叶变换没有现成结论，而周期信号本身就比较复杂，再在时域卷一个 Sa 型的函数，这显然是一个很难完成的任务。

这是对周期信号求傅里叶变换，用之前讲过的知识点：

$$F(\mathrm{j}\omega)=\sum_{n=-\infty}^{+\infty}2\pi F_n\,\delta(\omega-n\omega_1),\qquad \omega_1=\frac{2\pi}{T_1}$$

只要求出复系数 $F_n$ 代入公式即可（如果不想背这个公式，也可以把周期信号看成一个单脉冲信号与一个冲激串的卷积，效果一样）。

求 $F_n$ 我们讲过两种方法：

- **方法一**：直接代傅里叶级数系数公式 $F_n=\dfrac{1}{T_1}\displaystyle\int f(t)\,e^{-\mathrm{j}n\omega_1 t}\,\mathrm{d}t$。$f(t)$ 形式简单时这个积分不复杂，形式复杂时求积分就有些困难。
- **方法二**：取周期信号的一个周期（单脉冲），求它的傅里叶变换得 $F_0(\mathrm{j}\omega)$，再把其中的 $\omega$ 全换成 $n\omega_1$、除以 $T_1$：$F_n=\dfrac{1}{T_1}F_0(\mathrm{j}\omega)\big|_{\omega=n\omega_1}$。如果单周期的傅里叶变换好求，方法二显然更简单。

这道题两种方法的工作量差不多（一个周期的表达式比较简单），我们就两种方法都做一遍。先定参数：$T_1=1$，$\omega_1=\dfrac{2\pi}{T_1}=2\pi$。

还有一个积分区间的小讲究：求 $F_n$ 的积分区间**只要是一个周期**（$t_0\sim t_0+T_1$）就可以，不一定非取对称区间 $-\dfrac{T_1}{2}\sim\dfrac{T_1}{2}$。这个信号若取对称区间，还得分段表示（$-\frac12\sim 0$ 一段、$0\sim\frac12$ 一段），反而麻烦；取 $0\sim 1$ 这个周期，表达式一下就写出来：$f(t)=t$。

#### 方法一：定义积分，表格法分部积分

$$F_n=\int_0^1 t\,e^{-\mathrm{j}2\pi n t}\,\mathrm{d}t\qquad(n \neq 0)$$

这是一个多项式乘一个指数，显然用分部积分；分部积分用之前说过的快捷方法——**表格法**：上行对 $t$ 逐次求导（$t\to 1\to 0$），下行对 $e^{-\mathrm{j}2\pi nt}$ 逐次积分（每次把 $t$ 前面的系数放到分母：第一次得 $\dfrac{e^{-\mathrm{j}2\pi nt}}{-\mathrm{j}2\pi n}$，第二次得 $\dfrac{e^{-\mathrm{j}2\pi nt}}{(-\mathrm{j}2\pi n)^2}$，注意 $(-\mathrm{j})^2=-1$）。斜向相乘、代入上下限 1 和 0（足够熟练的话可以不用非得列出来，直接代即可）：

- 第一项：代入 1 得 $\dfrac{e^{-\mathrm{j}2\pi n}}{-\mathrm{j}2\pi n}$；代入 0 时 $t=0$，乘积为零。
- 第二项：代入 1 前面是负号，得 $-\dfrac{e^{-\mathrm{j}2\pi n}}{-(2\pi n)^2}$；代入 0 前面是正号，得 $+\dfrac{1}{-(2\pi n)^2}$。

现在又要用到那个结论：$e^{-\mathrm{j}2\pi n}=1$。$n$ 每增大 1，就相当于在复平面上转一整圈，永远都回到 1（也可以欧拉展开验证：$\cos 2\pi n-\mathrm{j}\sin 2\pi n$，正弦项显然为零、余弦为 1）。于是第二项一加一减没了，只剩下第一项：

$$F_n=\frac{1}{-\mathrm{j}2\pi n}=\frac{\mathrm{j}}{2\pi n}\qquad(n \neq 0)$$

#### n=0 要单独讨论：直流分量一眼看出

注意 $F_n$ 的表达式里 $n$ 出现在了分母上，不能直接代入 $n=0$，所以 $F_0$ 必须单独讨论。$n=0$ 时指数部分就是 1：

$$F_0=\int_0^1 t\,\mathrm{d}t=\frac{1}{2}$$

> **易错点**：$F_n$ 的表达式中 $n$ 出现在分母上时，$F_0$ 不能由该式代入 $n=0$ 得到，必须单独积分（或者用物理意义直接看出）。这是容易忽视的情况。

$F_0$ 的物理意义是**直流分量**。看波形就能一眼看出来：这个信号的直流分量就是 $\dfrac{1}{2}$；如果把这条水平分量去掉，剩下的信号就没有直流分量了。有时候直流分量不需要去求，一下就看出来了。

#### 方法二：单脉冲加微分特性

取周期信号的一个周期，得单脉冲 $f_0(t)$（同样选 $0\sim 1$ 这个周期，表达式很简单；选对称区间取到的信号表达式就复杂多了）。

如果直接按定义求 $F_0(\mathrm{j}\omega)$，那就是 $\displaystyle\int_0^1 t\,e^{-\mathrm{j}\omega t}\,\mathrm{d}t$——这跟我们方法一求的那个积分一模一样，那你还不如直接求 $F_n$ 呢。所以这里改用傅里叶变换的性质。

$f_0(t)$ 是一个斜率为 1 的斜坡，对它求导：$0\sim 1$ 内变成常数 1（相当于一个宽为 1 的门函数右移 $\dfrac{1}{2}$）；另外这一段千万不要忘了——信号在 $t=1$ 处从 1 跳回 0，这里产生了一个向下的冲激 $-\delta(t-1)$：

$$f_0'(t)=g_1\!\left(t-\frac{1}{2}\right)-\delta(t-1)$$

导数的频谱显然更好求，所以利用傅里叶变换的微积分特性反推。$f_0(t)$ 是有始有终的时间有限信号，频谱中没有冲激分量，可以放心地除回去：记 $f_0'(t)\leftrightarrow F_1(\mathrm{j}\omega)$，则

$$F_0(\mathrm{j}\omega)=\frac{F_1(\mathrm{j}\omega)}{\mathrm{j}\omega}$$

逐项求 $F_1(\mathrm{j}\omega)$：

- 门函数 $g_1(t)$：宽度为 1，即 $\tau=1$，$\leftrightarrow \mathrm{Sa}\!\left(\dfrac{\omega}{2}\right)$；右移 $\dfrac{1}{2}$，时移乘 $e^{-\mathrm{j}\omega/2}$：$g_1\!\left(t-\dfrac12\right)\leftrightarrow \mathrm{Sa}\!\left(\dfrac{\omega}{2}\right)e^{-\mathrm{j}\omega/2}$。
- $-\delta(t-1)$：$\delta(t)\leftrightarrow 1$，时移得 $e^{-\mathrm{j}\omega}$，带上前面的负号：$-\delta(t-1)\leftrightarrow -e^{-\mathrm{j}\omega}$。

$$F_0(\mathrm{j}\omega)=\frac{1}{\mathrm{j}\omega}\left[\mathrm{Sa}\!\left(\frac{\omega}{2}\right)e^{-\mathrm{j}\omega/2}-e^{-\mathrm{j}\omega}\right]$$

$F_0(\mathrm{j}\omega)$ 求出来之后，$F_n$ 也就出来了：前面乘 $\dfrac{1}{T_1}$（$T_1=1$，所以就是 1），把 $\omega$ 都换成 $n\omega_1=2\pi n$：

$$F_n=\frac{\mathrm{Sa}(\pi n)\,e^{-\mathrm{j}\pi n}-e^{-\mathrm{j}2\pi n}}{\mathrm{j}2\pi n}$$

又出现了跟之前一样的状况——$n$ 在分母上，$F_0$ 得单独讨论。$n \neq 0$ 时 $\mathrm{Sa}(\pi n)=0$，剩下的 $e^{-\mathrm{j}2\pi n}$ 我们已经见过很多次了，它就是 1，于是分子剩下 $-1$；把分母的 $\mathrm{j}$ 拿到分子上，负号与 $-1$ 消掉：

$$F_n=\frac{\mathrm{j}}{2\pi n}\ (n \neq 0),\qquad F_0=\frac{1}{2}$$

跟方法一完全一致。

#### 过滤波器：只剩三根冲激

把频谱写出来。观察 $F(\mathrm{j}\omega)$ 的形式：它是由无穷多个冲激组成的，每隔 $2\pi$ 一个冲激；每个冲激的面积我们先不急着关心，因为——别忘了这个题还没做完——它还得经过一个滤波器。虽然这里有很多冲激，但乘上 $H(\mathrm{j}\omega)$ 之后，可能就只剩下其中的一部分了：

$$F(\mathrm{j}\omega)=\sum_{n=-\infty}^{+\infty}2\pi F_n\,\delta(\omega-2\pi n)$$

把 $H(\mathrm{j}\omega)$ 的波形重画一下（三角形，$\omega=0$ 处为 2，$\pm 4\pi$ 处为 0），与冲激串对照着看：

- $|\omega|>4\pi$ 的那些冲激：$H(\mathrm{j}\omega)$ 为零，全都变为零了；
- $\omega=\pm 4\pi$（即 $n=\pm 2$）处的冲激：$H$ 恰好也等于零，没了；
- 所以只剩下 $\omega=0,\ \pm 2\pi$ 这么三根冲激。

各点的 $H$ 值：$H(\mathrm{j}\omega)$ 在 $\omega=0$ 时等于 2；三角形是线性下降的，$\omega=\pm 2\pi$ 处为 1。三根冲激各自的面积：

| $n$ | 冲激位置 | $2\pi F_n$ | $H$ 取值 | 乘积（冲激面积） |
|:---:|:---:|:---:|:---:|:---:|
| $-1$ | $-2\pi$ | $-\mathrm{j}$ | $1$ | $-\mathrm{j}$ |
| $0$ | $0$ | $\pi$ | $2$ | $2\pi$ |
| $1$ | $+2\pi$ | $\mathrm{j}$ | $1$ | $\mathrm{j}$ |

（$n=0$ 时冲激为 $\delta(\omega)$，面积 $2\pi F_0=2\pi\cdot\frac12=\pi$，还要再乘以 $H$ 的 2；$n=1$ 时 $2\pi F_1=2\pi\cdot\frac{\mathrm{j}}{2\pi}=\mathrm{j}$；$n=-1$ 同理为 $-\mathrm{j}$。）于是

$$Y(\mathrm{j}\omega)=-\mathrm{j}\,\delta(\omega+2\pi)+2\pi\,\delta(\omega)+\mathrm{j}\,\delta(\omega-2\pi)$$

把两个波形画出来，它们一乘是什么效果，非常直观。

#### 反变换与画波形

逐项做傅里叶逆变换：$2\pi\delta(\omega)\leftrightarrow 1$；$\delta(\omega\mp 2\pi)\leftrightarrow\dfrac{1}{2\pi}e^{\pm\mathrm{j}2\pi t}$。合并两个复指数项时要凑 sin——这一步是必须要做的，因为题目还让我们画 $y(t)$ 的波形，复指数形式没法画，得变成三角函数形式：

$$\frac{\mathrm{j}}{2\pi}e^{\mathrm{j}2\pi t}-\frac{\mathrm{j}}{2\pi}e^{-\mathrm{j}2\pi t}=\frac{\mathrm{j}}{2\pi}\cdot 2\mathrm{j}\sin 2\pi t=-\frac{1}{\pi}\sin 2\pi t$$

$$y(t)=1-\frac{1}{\pi}\sin 2\pi t$$

画波形时还是得好好画，先把波形的关键点标出来。怎么画：先画 $-\dfrac{1}{\pi}\sin 2\pi t$——先看正弦的周期 $T=\dfrac{2\pi}{2\pi}=1$，是一个周期为 1 的正弦；乘了一个负号，上下颠倒；幅度变为 $\dfrac{1}{\pi}$。然后加 1，整体上移。注意 $\pi$ 约等于 3.14，所以 $\dfrac{1}{\pi}\approx\dfrac{1}{3}$，而 1 显然比 $\dfrac{1}{3}$ 大：画的时候先画一条 $y=1$ 的虚线，在这个虚线上画这条颠倒、缩小了的正弦，峰值为 $1+\dfrac{1}{\pi}$，谷值为 $1-\dfrac{1}{\pi}$，过虚线处为 1。

```text
   y(t) = 1 - (1/π)·sin(2πt)，周期 T = 1
   1+1/π -                 ___
         |               /     \
         |             /         \
```

## 希尔伯特变换：因果系统的实虚部制约，与拉普拉斯变换的开场
> 对应块：BLK44 | 覆盖分集：P101-P103 | 块标题（分集名）：《3.25希尔伯特变换》

现实中的系统都是因果系统——只有因果的系统我们才能具体把它做出来，才是可实现的。而这门课里分析的系统，绝大部分也都是因果系统。因果系统在时域上的特征我们已经很熟了：冲击响应满足 $h(t) = h(t)u(t)$，也就是 $t<0$ 时冲击响应为零。

但因果性不只体现在时域上。系统函数 $H(j\omega)$ 的**实部和虚部之间也存在相互制约的特性**：知道实部，就能推出虚部；知道虚部，也能推出实部。这种制约关系，正是用这一讲的主角——希尔伯特变换（Hilbert Transform）——来表现的。

### 实部和虚部到底怎么互相推出

已知时域条件 $h(t) = h(t)u(t)$，想知道频率域上 $H(j\omega)$ 的实部和虚部有什么关系，那就对这个条件做一个傅里叶变换呗。

时域是乘积，频域就要卷积，再乘 $\dfrac{1}{2\pi}$：

$$H(j\omega) = \frac{1}{2\pi} H(j\omega) * \mathcal{F}[u(t)] = \frac{1}{2\pi} H(j\omega) * \left[\pi\delta(\omega) + \frac{1}{j\omega}\right]$$

我们关心的是实部和虚部，所以把 $H(j\omega)$ 展开成"实部加虚部"的形式。令

$$H(j\omega) = R(\omega) + jX(\omega)$$

代入右边，一项一项把卷积拆开：

- $R(\omega) * \pi\delta(\omega) = \pi R(\omega)$——卷上冲激就是它本身；
- $R(\omega) * \dfrac{1}{j\omega}$ 先保留；
- $jX(\omega) * \pi\delta(\omega) = j\pi X(\omega)$；
- $jX(\omega) * \dfrac{1}{j\omega}$，$j$ 和 $\dfrac{1}{j}$ 约掉，剩 $X(\omega) * \dfrac{1}{\omega}$。

四个项里两个带 $j$、两个不带 $j$，按"带 $j$ 的归虚部、不带 $j$ 的归实部"分组，整理后：

$$R(\omega) + jX(\omega) = \frac{1}{2}\left[R(\omega) + X(\omega) * \frac{1}{\pi\omega}\right] + \frac{j}{2}\left[X(\omega) - R(\omega) * \frac{1}{\pi\omega}\right]$$

两边实部对实部、虚部对虚部，实部相加要凑出 $R(\omega)$、虚部相加（乘 $j$ 后）要凑出 $jX(\omega)$，于是得到一对核心等式：

$$R(\omega) = X(\omega) * \frac{1}{\pi\omega}, \qquad X(\omega) = -R(\omega) * \frac{1}{\pi\omega}$$

写成积分定义的形式，就是把 $\dfrac{1}{\pi}$ 提出来，把其中一个 $\omega$ 换成 $\lambda$：

$$R(\omega) = \frac{1}{\pi}\int_{-\infty}^{+\infty} \frac{X(\lambda)}{\omega - \lambda}\, d\lambda, \qquad X(\omega) = -\frac{1}{\pi}\int_{-\infty}^{+\infty} \frac{R(\lambda)}{\omega - \lambda}\, d\lambda$$

> **结论**：一个因果信号（因果系统函数）的实部和虚部，是一对希尔伯特变换对。对因果信号而言，只要知道实部或者虚部中的任何一个，另一部分就完全确定了，可以通过希尔伯特变换的关系求出来。

注意右边那条式子多出来的那个负号——它马上还会再出现一次，而且是个常考的坑。

### 希尔伯特变换的定义与"再变一次要变号"

希尔伯特变换本身只是一种数学运算，定义成与 $\dfrac{1}{\pi t}$ 的卷积。它不只可以在频率域上应用，在时域上同样可以：

$$\hat{f}(t) = f(t) * \frac{1}{\pi t} = \frac{1}{\pi}\int_{-\infty}^{+\infty} \frac{f(\lambda)}{t - \lambda}\, d\lambda$$

$\hat{f}(t)$（上面一个小尖，读作 "$f$ hat"）就叫 $f(t)$ 的希尔伯特变换，$f(t)$ 和 $\hat{f}(t)$ 是一对希尔伯特变换对。

那反过来呢？回看实部虚部那对式子就明白了：$R(\omega)$ 是 $X(\omega)$ 的希尔伯特变换，但 $X(\omega)$ 是 $R(\omega)$ 的希尔伯特变换**再加一个负号**。时域同理：

$$f(t) = -\hat{f}(t) * \frac{1}{\pi t}$$

也就是说，对 $\hat{f}(t)$ 再求一次希尔伯特变换，得到的是 $-f(t)$：

$$\mathcal{H}\{\hat{f}(t)\} = -f(t)$$

有的教材把 $f(t)$ 的希尔伯特变换记作 $\hat{f}(t)$，也有的教材用大 $H$ 记作 $\mathcal{H}[f(t)]$，不管哪种记法，这条"变两次多一个负号"的结论是不变的。

### 时域做希尔伯特变换，频域在干什么

对 $f(t) * \dfrac{1}{\pi t}$ 做傅里叶变换，时域卷积对应频域乘积：

$$\mathcal{F}[\hat{f}(t)] = F(j\omega) \cdot \mathcal{F}\left[\frac{1}{\pi t}\right]$$

$\dfrac{1}{\pi t}$ 的傅里叶变换，靠对称性就能推出来。我们知道符号函数

$$\mathrm{sgn}(t) \leftrightarrow \frac{2}{j\omega}$$

由对称性：若 $f(t) \leftrightarrow F(j\omega)$，则 $F(t) \leftrightarrow 2\pi f(-\omega)$。把 $\dfrac{2}{j\omega}$ 里的 $\omega$ 换成 $t$，得 $\dfrac{2}{jt}$ 的傅里叶变换是 $2\pi\,\mathrm{sgn}(-\omega)$。$\mathrm{sgn}$ 是奇函数，负号提出来，再消掉 2：

$$\frac{2}{jt} \leftrightarrow -2\pi\,\mathrm{sgn}(\omega) \quad\Longrightarrow\quad \frac{1}{t} \leftrightarrow -j\pi\,\mathrm{sgn}(\omega)$$

我们要求的是 $\dfrac{1}{\pi t}$ 而不是 $\dfrac{1}{jt}$，给它乘一个 $j$ 再除一个 $\pi$：

$$\frac{1}{\pi t} \leftrightarrow -j\,\mathrm{sgn}(\omega)$$

所以对 $f(t)$ 做希尔伯特变换，在频域上就是给频谱乘上 $-j\,\mathrm{sgn}(\omega)$：

- $\omega > 0$：乘 $-j$，幅度不变，相位**减 $\dfrac{\pi}{2}$**；
- $\omega < 0$：乘 $j$，幅度不变，相位**加 $\dfrac{\pi}{2}$**；
- $\omega = 0$：乘 $0$，直接归零。

> **结论**：时域上做希尔伯特变换，是在频域上按频率的正负分别做相位减 $\dfrac{\pi}{2}$、加 $\dfrac{\pi}{2}$ 的"移相"。时域里它是个复杂的卷积，频域上却非常直观。

所以求一个信号的希尔伯特变换，完全可以**从频域入手**，乘完 $-j\,\mathrm{sgn}(\omega)$ 再做一次反变换，就得到变换后的信号。

### 例题：余弦的希尔伯特变换是正弦

这是非常重要、非常常用的一个结果：求 $\cos(\omega_0 t)$ 的希尔伯特变换。

在时域上求卷积总是很困难的，所以我们从频域上分析。先把原信号的频谱写出来——$\cos$ 的傅里叶变换同学们再熟悉不过：

$$F(j\omega) = \pi\left[\delta(\omega + \omega_0) + \delta(\omega - \omega_0)\right]$$

频谱就是正负两个冲激：一个在 $-\omega_0$ 处，一个在 $\omega_0$ 处，强度都是 $\pi$。按正负频率分别处理：$+\omega_0$ 处（正频率）乘 $-j$，$-\omega_0$ 处（负频率）乘 $j$，再把 $j\pi$ 提出来：

$$\hat{F}(j\omega) = j\pi\,\delta(\omega + \omega_0) - j\pi\,\delta(\omega - \omega_0)$$

看着眼不眼熟？这不就是 $\sin(\omega_0 t)$ 的傅里叶变换吗。所以

$$\mathcal{H}\{\cos(\omega_0 t)\} = \sin(\omega_0 t)$$

> **易错点**：那么 $\sin(\omega_0 t)$ 的希尔伯特变换是不是 $\cos(\omega_0 t)$？**不对**。应该是 $-\cos(\omega_0 t)$。用同样的方法推导一遍就会发现那个负号；而且这正是前面"实部虚部互推"那对公式里不对称性的体现——$X(\omega)$ 那条等式带负号。变一次得 $\sin$，再变一次回到 $-\cos$，恰好印证"变两次等于乘 $-1$"。

关于 $\omega = 0$ 这个点也可以交代一句：$\mathrm{sgn}(0)$ 有时候定义为零，有时候定义为一，也有的时候干脆不定义，这个零点大可不必深究。如果把 $\mathrm{sgn}(t)$ 定义成"$t \ge 0$ 时为 $1$、$t < 0$ 时为 $0$"，也完全符合定义。

从**移相的角度**还能直观看懂"变两次变负号"：$\omega>0$ 的分量相位减 $\dfrac{\pi}{2}$ 再减 $\dfrac{\pi}{2}$，最后减 $\pi$；$\omega<0$ 的分量加 $\dfrac{\pi}{2}$ 再加 $\dfrac{\pi}{2}$，最后加 $\pi$。而无论是减 $\pi$ 还是加 $\pi$，效果都相当于乘 $-1$，因为

$$e^{j\pi} = e^{-j\pi} = -1$$

所以两次希尔伯特变换，就是 $-f(t)$。

### 拉普拉斯变换：重要、不难、要稳稳拿住

走过了漫长的第三章，我们终于迎来第四章——拉普拉斯变换。这是一个很令人开心的变换：它在试卷上的分值经常占比很高，是重点，但**并不很难**。第四章的很多题是很有套路的，只要你做过一些，这些题就没有什么问题。所以第四章是我们要"稳稳的幸福"、稳稳拿住分的一章。

#### 从复指数响应引出定义

第三章一开始就讲过：复指数信号 $e^{st}$ 经过冲击响应为 $h(t)$ 的系统，零状态响应为

$$y(t) = H(s)\, e^{st}, \qquad H(s) = \int_{-\infty}^{+\infty} h(t)\, e^{-st}\, dt$$

当时我们只取了 $s = j\omega$ 这个特殊情况：

$$H(j\omega) = \int_{-\infty}^{+\infty} h(t)\, e^{-j\omega t}\, dt$$

这个形式大家很熟悉，就是对 $h(t)$ 做傅里叶变换。但 $s = j\omega$ 只是一种特殊情况——$s$ 本来是一个复数，有实部和虚部，应该写成

$$s = \sigma + j\omega$$

只有 $\sigma = 0$（实部为零）的时候，$s$ 才等于 $j\omega$。那对于 $\sigma 
e 0$ 的一般情况，直接看上面那个式子，它就是对 $h(t)$ 做了一次**拉普拉斯变换**。

> **定义**：对 $f(t)$ 做拉普拉斯变换，记作 $F(s) = \mathcal{L}[f(t)]$：
> $$F(s) = \int_{-\infty}^{+\infty} f(t)\, e^{-st}\, dt$$
> 积分限为 $-\infty$ 到 $+\infty$ 的，叫**双边拉普拉斯变换**。把积分限换成 $0$ 到 $+\infty$ 的，是**单边拉普拉斯变换**——实际中我们用得更多的是单边拉氏变换，后面还会专门介绍。

有了正变换自然也有逆变换。拉普拉斯逆变换记作花体的 $\mathcal{L}^{-1}$，对 $F(s)$ 求逆变换就变回 $f(t)$。它的定义式写出来就比较复杂了：

$$f(t) = \frac{1}{2\pi j}\int_{\sigma - j\infty}^{\sigma + j\infty} F(s)\, e^{st}\, ds$$

可以看到这个形式看起来很复杂，所以做拉氏逆变换的时候，我们**一般不用定义**——后面会专门介绍求拉普拉斯逆变换的方法。

#### 傅里叶变换做不到的，拉普拉斯变换为什么能做到

第三章刚讲完傅里叶变换，这里又讲拉氏变换，两者到底有什么不同、为什么要引入拉氏变换？傅里叶变换确实很好，但它有不足之处。

傅里叶变换要满足**绝对可积**的条件才能进行。当然，因为我们引入了奇异函数（冲激函数等），一些即使不满足绝对可积的信号——比如 $u(t)$、$\mathrm{sgn}(t)$——也能借助冲激做傅里叶变换。但注意，这些信号在 $t \to \infty$ 时总还是"有限制"的。而像

$$e^{at}u(t), \quad a > 0$$

这种 $t \to \infty$ 时趋于无穷大的信号，是**不能做傅里叶变换**的。而拉普拉斯变换恰恰可以对它进行变换——为什么，马上解释。

再一个：傅里叶变换只能求**零状态响应**，回想一下整个第三章，确实没有用傅里叶变换求过零输入响应吧。而拉氏变换既可以求零状态响应，也可以求**零输入响应**，这是拉氏变换的优势。

但傅里叶变换也有它独到的好处：**物理意义清晰明确**。对信号做傅里叶变换，本来是从时域上观察一个信号，现在换到频率域上看它各个频率分量都是什么情况，物理意义非常清楚。而拉氏变换的物理意义就很难一两句话说清了，这是它的劣势。以上种种，区分开了傅里叶变换和拉氏变换，也导致它们的应用场景不同：**傅里叶变换主要用来分析通信系统**（第三章已经看到用它分析会简便很多），**拉氏变换主要用来解微分方程和复杂电路系统**——第二章讲微分方程求解时就说过，我们有更好的方法；有些微分方程在时域上求解困难且复杂，一到拉氏变换就变得很简单，复杂电路系统的运算也能大大简化。

| 对比项 | 傅里叶变换 | 拉普拉斯变换 |
| :--- | :--- | :--- |
| 存在条件 | 要求绝对可积（借助奇异函数可放宽一部分） | 乘 $e^{-\sigma t}$ 压制后极易满足 |
| 能求的响应 | 只能零状态响应 | 零状态 + 零输入响应 |
| 物理意义 | 清晰明确（频域分量） | 很难一两句话说清 |
| 主要应用 | 通信系统分析 | 微分方程、复杂电路系统 |

#### 增长的指数信号，乘一个衰减因子就压下去了

回到刚才那个问题：$e^{at}u(t)$（$a>0$）不绝对可积、不能做傅里叶变换，为什么能做拉氏变换？

把两个变换的定义并排写出来看差别在哪：

$$\text{傅里叶：}\int_{-\infty}^{+\infty} e^{at}u(t)\, e^{-j\omega t}\, dt \qquad \text{拉氏：}\int_{-\infty}^{+\infty} e^{at}u(t)\, e^{-st}\, dt$$

其中 $s = \sigma + j\omega$，把 $e^{-st}$ 展开成 $e^{-\sigma t} \cdot e^{-j\omega t}$，拉氏那一式就变成

$$\int_{-\infty}^{+\infty} \left[e^{at} e^{-\sigma t}\right] e^{-j\omega t}\, dt$$

这下看清楚了：两个式子**就差了一项 $e^{-\sigma t}$**。下面这个相当于把 $e^{at}e^{-\sigma t}$ 这个整体拿去做傅里叶变换。而 $\sigma$ 是一个常数，是可以任意选取的——选 $\sigma > 0$，$e^{-\sigma t}$ 就是一个单调衰减的指数信号。

高数里学过：指数函数的增长速度比任何 $t$ 的幂都快，$\lim\limits_{t\to\infty} \dfrac{t}{e^{t}} = 0$。同样的道理，增长的 $e^{at}$ 乘上衰减的 $e^{-\sigma t}$，只要 $\sigma$ 取得够大，就能把原来的增长信号压制下去，使 $t \to \infty$ 时趋于零。

举个具体例子，取 $a = 3$：信号是 $e^{3t}u(t)$，我们取 $\sigma = 4$，则

$$e^{3t} \cdot e^{-4t} = e^{-t}$$

本来单调增长的信号，乘上一个衰减的尺度信号之后，变成了单调衰减的信号——显然绝对可积，也就可以做傅里叶变换了。

> **结论**：$e^{-\sigma t}$ 像一个"压制器"，把原来不绝对可积的信号压成绝对可积的信号，所以 $e^{at}u(t)$（$a>0$）的拉普拉斯变换是存在的。

当然也有压不下去的个例。比如 $e^{t^2}$：它太猛了，$e^{t^2}$ 本身就比任何 $e^{\sigma t}$ 高一个层次，$\lim\limits_{t\to\infty} \dfrac{e^{\sigma t}}{e^{t^2}} = \infty$，$\sigma$ 不管怎么取都压不住，所以 $e^{t^2}$ 不存在拉普拉斯变换。

反过来也有 $\sigma$ 怎么取都存在的信号：比如一个只在有限区间 $[a, b]$ 上非零的（可积的）信号，$f(t)e^{-\sigma t}$ 中两个因子在有限区间上都是有限值，相乘还是有限值，在有限区间上积分肯定没问题——所以不管 $\sigma$ 怎么取，它的拉氏变换都存在。

于是自然而然就出现了一个问题：既然 $\sigma$ 可以任意选取，那**到底怎么选取 $\sigma$，才能保证这个积分存在**，也就是让拉氏变换存在呢？这就引出了**收敛域**的问题：只有当 $\sigma$ 满足一定条件时，$f(t)$ 的拉普拉斯变换才是存在的——这正是接下来要展开的内容。

## 拉普拉斯变换的收敛域与常用信号的拉氏变换
> 对应块：BLK45 | 覆盖分集：P104-P105 | 块标题（分集名）：《4.2拉普拉斯变换的收敛域》

求拉氏变换不是代个数进去就完事——同一个信号，$\sigma$ 取某些值时积分存在，取另一些值时积分干脆不存在。这一讲我们就把"积分什么时候存在"这件事彻底说清楚：先从因果信号算起，再看反因果信号和双边信号，引出我们真正的主角——单边拉氏变换；最后用它把几个常用信号的拉氏变换逐一求出来。

### 因果信号：从 $e^{\alpha t}u(t)$ 算起收敛域

我们建得最多的信号是因果信号：$t<0$ 时 $f(t)=0$，也就是带个 $u(t)$ 的那种信号。收敛域怎么求？办法很直接：对信号做拉氏变换，看 $\sigma$ 取什么值时积分存在、取什么值时积分不存在，存在的那部分 $\sigma$ 就是收敛域。

举个具体例子，设

$$f_1(t) = e^{\alpha t} u(t)$$

按定义（现阶段我们也只会用定义）做拉氏变换：

$$F_1(s) = \int_{-\infty}^{+\infty} e^{\alpha t} u(t)\, e^{-st}\, dt$$

因为有 $u(t)$ 在，积分线可以分成两段：负无穷到零那一段，$u(t)=0$，整个积分为零；零到正无穷那一段，$u(t)=1$，可以直接省略。于是

$$F_1(s) = \int_{0}^{+\infty} e^{\alpha t} e^{-st}\, dt = \int_{0}^{+\infty} e^{(\alpha - s)t}\, dt$$

这就是一个最简单的指数积分：把 $t$ 前面的系数放到分母上，

$$F_1(s) = \left. \frac{e^{(\alpha - s)t}}{\alpha - s} \right|_{0}^{+\infty} = \frac{1}{\alpha - s}\left[\lim_{t \to +\infty} e^{(\alpha - s)t} - 1\right]$$

代入下限 $t=0$ 得到 $1$；我们主要关心上限这一项。把 $s$ 写成 $\sigma + j\omega$ 的形式，因为收敛域本来就是讨论 $\sigma$ 的取值范围：

$$e^{(\alpha - s)t} = e^{(\alpha - \sigma)t} \cdot e^{-j\omega t}$$

拆成了两项。后面这一项 $e^{-j\omega t}$ 我们说过，它是一个旋转矢量——$t\to\infty$ 时它一直在转，本质是一个震荡。如果旋转矢量不好理解，用欧拉公式改写成三角形式就是 $\cos\omega t - j\sin\omega t$，$t\to\infty$ 时显然在震荡。

再看前面这一项，它就是一个普通的指数信号。指数信号有三种形态：单调递减、单调递增，以及指数为零时恒等于 $1$ 的这种特殊形态。所以就分三种情况讨论：

**第一种，$\alpha - \sigma < 0$，即 $\sigma > \alpha$。** 指数单调递减，$t\to\infty$ 时趋于零，而后面那个是震荡——无穷小乘以震荡，还是无穷小。所以极限为零，整个结果是

$$F_1(s) = \frac{1}{\alpha - s}(0 - 1) = \frac{1}{s - \alpha}$$

**第二种，$\alpha - \sigma = 0$，即 $\sigma = \alpha$。** $e^0 = 1$，是固定的常数，剩下的只有 $e^{-j\omega t}$ 在震荡，极限不存在，积分发散。

**第三种，$\alpha - \sigma > 0$，即 $\sigma < \alpha$。** 指数单调递增，$t\to\infty$ 时整体趋向无穷，积分发散。

三种情况讨论完，只有第一种积分存在。所以只有当 $\sigma > \alpha$ 时拉氏变换才存在：

> **结论**：$e^{\alpha t}u(t)$ 的拉氏变换为 $\dfrac{1}{s-\alpha}$，收敛域为 $\sigma > \alpha$。

### 在 s 平面上画出收敛域

$\sigma > \alpha$ 这个收敛域可以在 $s$ 平面上画出来。先介绍一下什么是 $s$ 平面：$s$ 是一个复数，有实部 $\sigma$ 和虚部 $\omega$（$s = \sigma + j\omega$），要把它表示出来自然需要一个二维平面——横轴是 $\sigma$，纵轴是 $j\omega$，平面上一个点就对应一个 $s = \sigma_0 + j\omega_0$。

想表示 $\sigma > \alpha$，就是在平面上 $\sigma = \alpha$ 这条竖线的右侧。$\alpha$ 具体是多少没有给我们，随便画一个位置即可：

```text
              jω
               │
               │ ░░░░░░░░░
               │ ░░░░░░░░░
          ─────┼──────────→ σ
              α   ░░░░░░░░░
                  ░░░░░░░░░
```

竖线右侧的整个区域都满足 $\sigma > \alpha$，这就是收敛域在 $s$ 平面上的样子。

这个结论虽然是从一个个例推出来的，但对一般的因果信号都成立：**因果信号拉氏变换的收敛域就是 $\sigma > \alpha$ 这种形式**，$\alpha$ 是某个常数。当然，如果这个因果信号同时还是一个有限时宽信号——信号只在有限区间内非零，积分上限实际上取不到无穷——那么收敛域就是 $\sigma > -\infty$，也就是 $\sigma$ 任取。

### 反因果信号：收敛域掉头向左

说完因果信号，再来看反因果信号，一样是先举个例子、再推广出结论。例子取

$$f_2(t) = e^{\beta t} u(-t)$$

还是直接代定义（现在我们只会用定义嘛）：

$$F_2(s) = \int_{-\infty}^{+\infty} e^{\beta t} u(-t)\, e^{-st}\, dt$$

$u(-t)$ 的波形和 $u(t)$ 正相反：$t>0$ 时为零，$t<0$ 时为一。所以积分拆成负无穷到零、零到正无穷两部分：零到正无穷那段因为 $u(-t)=0$，整体为零；负无穷到零那段 $u(-t)=1$，可以直接省略：

$$F_2(s) = \int_{-\infty}^{0} e^{(\beta - s)t}\, dt = \left. \frac{e^{(\beta - s)t}}{\beta - s} \right|_{-\infty}^{0} = \frac{1}{\beta - s}\left[1 - \lim_{t \to -\infty} e^{(\beta - s)t}\right]$$

代入 $t=0$ 得 $e^0 = 1$；代入负无穷相当于取极限。把 $s = \sigma + j\omega$ 拆开，同样的老套路：

$$e^{(\beta - s)t} = e^{(\beta - \sigma)t} \cdot e^{-j\omega t}$$

后面这一项还是旋转矢量，$t\to -\infty$ 时显然是震荡的。前面这一项按指数信号的三种形态讨论：

**第一种，$\sigma > \beta$。** 这时 $\beta - \sigma < 0$，指数是单调递减的。但注意，我们这里是 $t$ 趋向**负**无穷——一个单调递减的指数信号往回走（$t\to -\infty$）显然趋向无穷，所以极限是无穷，无界，拉氏变换不存在。

**第二种，$\sigma = \beta$。** $e^0 = 1$，只剩后面的震荡项，极限不存在。

**第三种，$\sigma < \beta$。** 这时 $\beta - \sigma > 0$，指数是单调递增的，当 $t\to -\infty$ 时它趋向零。无穷小乘以震荡还是无穷小，极限为零，结果为

$$F_2(s) = \frac{1}{\beta - s}$$

只有 $\sigma < \beta$ 时拉氏变换才存在，这就是它的收敛域：

> **结论**：$e^{\beta t}u(-t)$ 的拉氏变换为 $\dfrac{1}{\beta - s}$，收敛域为 $\sigma < \beta$。

画在 $s$ 平面上就是 $\sigma = \beta$ 这条竖线的**左侧**——和因果信号正好掉了个头：

```text
              jω
               │
      ░░░░░░░░ │
      ░░░░░░░░ │
      ─────────┼─────────→ σ
               β
```

同样，这个个例的结论对一般的反因果信号都成立：反因果信号拉氏变换的收敛域就是 $\sigma < \beta$ 的形式，$\beta$ 是某常数；若它还是有限时宽信号，收敛域就是 $\sigma < +\infty$，也相当于 $\sigma$ 任取。

### 双边信号：带状收敛域，也可能压根不收敛

因果、反因果都说完了，最后一种情况是双边信号：正时间这部分不为零，负时间这部分也不为零，两边都有值。

其实任意的双边信号总可以写成

$$f(t) = f(t)u(t) + f(t)u(-t)$$

因为双边信号可以拆成右边这一部分加上左边这一部分：右边不就是它本身乘 $u(t)$ 吗，左边不就是它本身乘 $u(-t)$ 吗。而前者就是前面讲的因果信号，后者就是反因果信号。

我们举个例子，就把它俩相加：

$$f(t) = e^{\alpha t} u(t) + e^{\beta t} u(-t)$$

这不正是刚才算过的那两个例子吗。按定义做拉氏变换，$u(t)$ 和 $u(-t)$ 把积分线分成两段，两段分别是我们已经算过的结果：

- 第一项（因果部分）在 $\sigma > \alpha$ 时收敛；
- 第二项（反因果部分）在 $\sigma < \beta$ 时收敛。

要让整个信号的拉氏变换存在，两项必须同时收敛，也就是

$$\alpha < \sigma < \beta$$

画在 $s$ 平面上，就是中间的一条带状区域：

```text
              jω
               │
               │      ░░░░
               │   ░░░░░░░░
          ─────┼──────────→ σ
               α          β
```

但注意，你能画出这条带的前提是 $\beta > \alpha$。如果 $\beta \le \alpha$，"$\sigma$ 既小于 $\beta$ 又大于 $\alpha$"这个条件根本不可能满足——一个 $\sigma$ 怎么可能既小于靠左的线又大于靠右的线呢？比如 $\alpha > \beta$ 时，$\sigma<\beta$ 的区域和 $\sigma>\alpha$ 的区域没有交集：

```text
          ─────────┬───────┬────→ σ
                   β       α
      （σ<β 与 σ>α 无交集 → 收敛域不存在）
```

此时收敛域压根不存在，双边拉氏变换也就不存在。

> **结论**：双边拉氏变换可以用来分析双边信号，但收敛条件是比较苛刻的——左右两部分的收敛域必须有公共区间，这也就限制了它的应用。

### 单边拉氏变换：我们真正讨论的主角

通常我们遇到的信号都有一个初始时刻——信号是从某个时刻才开始有的。把这个初始时刻设为 $t=0$，那么 $t<0$ 时 $f(t)$ 都为零（信号还没出现嘛）。对这样的信号做双边拉氏变换：

$$F(s) = \int_{-\infty}^{+\infty} f(t)\, e^{-st}\, dt$$

由于 $t<0$ 时 $f(t)=0$，负无穷到零这一段的积分为零，整个积分就等于从零到正无穷的积分。对于这种下限为零、上限为正无穷的拉氏变换，我们管它叫**单边拉普拉斯变换**：

$$F(s) = \int_{0^-}^{+\infty} f(t)\, e^{-st}\, dt$$

> **定义**：积分下限为零、上限为正无穷的拉氏变换叫单边拉氏变换；下负无穷到正无穷的叫双边拉氏变换。我们主要讨论单边拉氏变换——它运算更简便，用途也更广泛。

单边拉氏变换其实相当于对一个因果信号 $f(t)u(t)$ 做双边拉氏变换，而这个我们前面已经做过了：因果信号的收敛域是 $\sigma > \alpha$ 的形式。所以**单边拉氏变换的收敛域都是 $\sigma > \alpha$ 这种形式**。

顺带说一句，有的教材——比如奥本海姆的教材——是以双边拉氏变换为主框架的。我们这里不可能面面俱到，主要以单边拉氏变换为讲授内容，所以大家听课之余还要多翻一翻教材。

关于单边与双边的关系，有几点值得记住：

- 双边和单边其实只差一个积分下限。对常见的因果信号 $f(t)u(t)$，它的单边拉氏变换和双边拉氏变换显然是一样的——因为负半轴本来就是零。即使是奥本的教材，也大量出现对 $f(t)u(t)$ 这种信号做双边拉氏变换的题，我们知道对它做单边是完全一样的。
- 但对 $f(t)u(-t)$ 这样的信号，就不能做单边拉氏变换了，只能做双边。这样的信号怎么做双边，之后会单独讲到。
- 单边和双边只差一个下限，所以它们的性质也基本相同，差别的地方我们都会讲到。
- 做拉氏**逆**变换时：单边拉氏变换收敛域固定是 $\sigma>\alpha$，所以做单边逆变换不用考虑收敛域；双边则不同——收敛域不同，结果也可能不同，所以必须考虑收敛域。怎么考虑，到时候再讲。
- 对双边信号做单边和做双边，结果显然不同：单边相当于只截取 $t>0$ 的这一部分。要做双边也很简单，把它拆成 $f(t)u(t) + f(t)u(-t)$，这两部分的双边变换你都会求，整个信号的双边变换就出来了。

### 阶跃信号：老朋友的拉氏变换

接下来看常用信号的拉氏变换。这里提到的拉氏变换都是**单边**的——以后如果没有特别提及双边，默认就是单边。

这里还要提一点：单边拉氏变换无需写出收敛域，因为它的收敛域非常简单，全是 $\sigma > \alpha$ 的形式；但对双边拉氏变换，写出收敛域是很重要的一步，一定要写，一定要写。我们做单边变换就可以不写收敛域了（下面为了证明完整，我们会把收敛域标出来）。

先来看老朋友——阶跃信号 $u(t)$。直接带定义：

$$\mathcal{L}[u(t)] = \int_{0}^{+\infty} u(t)\, e^{-st}\, dt$$

在 $0$ 到 $+\infty$ 范围内 $u(t)$ 显然恒为 $1$，可以直接省略。这里提一句：对 $u(t)$ 这样的因果信号做双边拉氏变换 $\int_{-\infty}^{+\infty} u(t)e^{-st}dt$，结果也是 $\int_0^{+\infty} e^{-st}dt$——因为 $t<0$ 时 $u(t)=0$，负半轴积分为零，两个是相同的。

剩下的就是对指数积分，很简单：把 $t$ 前面的东西放到分母上，$e^{-st}$ 放在上面不动，代入上下限。代入上限 $t\to\infty$ 时要注意了，把 $e^{-st}$ 写成 $e^{-\sigma t}\cdot e^{-j\omega t}$：前者是指数信号，$\sigma>0$ 时单调递减才能趋于零；后者是旋转矢量，一直在震荡。三种情况中只有 $\sigma > 0$ 这一种收敛。所以上限代入得零，下限代入 $e^0 = 1$：

$$\mathcal{L}[u(t)] = 0 - \left(-\frac{1}{s}\right) = \frac{1}{s}, \qquad \sigma > 0$$

### 指数信号 $e^{-at}$：阶跃其实是它的特例

第二个是指数信号。$e^{-at}$ 这个信号其实之前已经讨论过一次了，这里正式求它的单边拉氏变换。$a$ 可以大于零也可以小于零：$a>0$ 时是单调递减的指数；$a<0$ 时是单调递增的。注意如果 $a=0$，$e^0 = 1$，单边变换下就相当于对 $u(t)$ 做拉氏变换——那就是第一种情况。

按定义：

$$\mathcal{L}[e^{-at}] = \int_{0}^{+\infty} e^{-at} e^{-st}\, dt = \int_{0}^{+\infty} e^{-(a+s)t}\, dt = \left. \frac{e^{-(a+s)t}}{-(a+s)} \right|_{0}^{+\infty}$$

上限代入这一步我们已经讨论过很多次了，再写一遍：把 $s$ 展开成 $\sigma + j\omega$，

$$e^{-(a+s)t} = e^{-(a+\sigma)t} \cdot e^{-j\omega t}$$

要让 $t\to\infty$ 时前面这一项趋于零（后面那项只是震荡），就得 $a + \sigma > 0$，也就是 $\sigma > -a$。此时上限为零，下限为 $1$：

$$\mathcal{L}[e^{-at}] = 0 - \frac{1}{-(a+s)} = \frac{1}{s + a}, \qquad \sigma > -a$$

再看 $a$ 趋向零的情形：结果 $1/(s+a)$ 趋向 $1/s$，收敛域 $\sigma > -a$ 趋向 $\sigma>0$——这不就是阶跃信号那一组吗。所以 $u(t)$ 其实可以看成指数信号的一种特例。

> **结论**：$\mathcal{L}[e^{-at}] = \dfrac{1}{s+a}$（$\sigma > -a$）；$\mathcal{L}[u(t)] = \dfrac{1}{s}$（$\sigma>0$）是它 $a\to 0$ 的特例。这两个结论非常重要，大家必须牢记。

### 同一个变换结果，三个不同的信号

单边拉氏变换是从零到正无穷积分的，在这个区间上积分，$t<0$ 时的函数值与变换结果显然无关。这就导致一个后果。

看下面三个信号：$f_1(t) = e^{-at}u(t)$、$f_2(t) = e^{-at}$、$f_3(t) = e^{-a|t|}$（左边是 $e^{at}$，右边是 $e^{-at}$）。它们是显然不同的三个信号，但当 $t>0$ 时表达式都是 $e^{-at}$，所以对它们三个做**单边**拉氏变换，结果一样，都是

$$\frac{1}{s+a}$$

而它们的**双边**拉氏变换显然不同——毕竟人家本来就不是同一个信号嘛。

现在反过来问：对 $1/(s+a)$ 做拉氏逆变换会得到什么？我们知道 $e^{-at}$ 的单边拉氏变换是 $1/(s+a)$，所以逆变换的结果就是 $e^{-at}$。但要注意，我们只能得到 $t\ge 0$ 的结果，因为做的是单边拉氏变换。有的教材这里也直接写成

$$\mathcal{L}^{-1}\!\left[\frac{1}{s+a}\right] = e^{-at} u(t)$$

把这个特点写进了结果里。

这个特点并没有给单边拉氏变换的应用带来不便。因为在系统分析问题中，往往只需要求 $t\ge 0$ 的系统响应，而 $t<0$ 的情况是由激励接入以前系统的状态所决定的。

> **易错点**：单边拉氏变换"看不见"负半轴。三个负半轴各不相同的信号可以有同一个单边变换 $1/(s+a)$；单边逆变换也只还原 $t\ge 0$ 的部分，不要误以为它能唯一确定整个时域信号。

### 积分下限为什么取 $0^-$

看 $e^{-at}u(t)$ 这样的信号图形：函数在 $t=0$ 时刻发生了跳变，突然从零变成一。这样的话，初始条件 $f(0)$ 就容易产生混淆——$f(0)$ 到底是等于零还是等于一？

为了使 $f(0)$ 有明确的意义，我们把它区分为 $f(0^-)$ 和 $f(0^+)$：$f(0^-)$ 是从左端趋向零的值，$f(0^+)$ 是从右端趋向零的值。上面这个信号显然 $f(0^-)=0$，$f(0^+)=1$。

函数在零点处有跳变，它的导数就会出现一个冲激。为了方便研究在零点处发生跳变的现象，我们规定：**单边拉氏变换的积分下限从 $0^-$ 开始**，即

$$F(s) = \int_{0^-}^{+\infty} f(t)\, e^{-st}\, dt$$

这样规定有两个好处：

- 积分区间 $0^-$ 到 $+\infty$ 把 $t=0$ 包了进来，而 $t=0$ 处是可能发生跳变的——也就是把 $t=0$ 处冲激函数的作用考虑在变换之内。
- 利用拉氏变换解微分方程时（这个方法之后会介绍），因为定义的是 $0^-$，可以直接引用起始状态 $f(0^-)$ 就求出结果。第二章里我们为了由 $f(0^-)$ 得到 $f(0^+)$ 还专门讲过一个方法，这里就可以省略这个步骤，不用专门算零负到零正的跳变了。

其实积分下限选 $0^+$ 也可以，那叫拉氏变换的 $0^+$ 系统；我们这一套叫拉氏变换的 $0^-$ 系统，$0^-$ 系统是更为好用的。之后讲的过程中都用 $0^-$ 系统——如果不加标注，积分下限的"零"指的都是 $0^-$。

### 冲激信号 $\delta(t)$：正好验证 $0^-$ 的意义

最后一个常用信号，还是按定义来，对 $\delta(t)$ 做拉氏变换：

$$\mathcal{L}[\delta(t)] = \int_{0^-}^{+\infty} \delta(t)\, e^{-st}\, dt$$

注意这里的零其实是 $0^-$，我们刚说过。在 $0^-$ 到 $+\infty$ 的范围内，冲激 $\delta(t)$ 是被包含在内的，所以这个积分应该等于一；如果下限取的是 $0^+$，那 $0^+$ 到 $+\infty$ 对 $\delta(t)$ 积分就应该等于零了——刚才我们也说了，选择积分下限为零负，就是为了把 $t=0$ 处冲激函数的作用考虑在变换之内。

具体算：根据冲激函数的取样性质 $f(t)\delta(t) = f(0)\delta(t)$，

$$\delta(t)\, e^{-st} = e^{-s\cdot 0}\,\delta(t) = \delta(t)$$

所以

$$\mathcal{L}[\delta(t)] = \int_{0^-}^{+\infty} \delta(t)\, dt = 1$$

如果下限真的取 $0^+$，结果就是零。冲激信号的拉氏变换恒等于 $1$，这也正是积分下限取 $0^-$ 最直接的验证。

把这一讲的结果归拢成一张表（都是单边拉氏变换）：

| 信号 | 拉氏变换 $F(s)$ | 收敛域 |
| :---: | :---: | :---: |
| $u(t)$ | $\dfrac{1}{s}$ | $\sigma > 0$ |
| $e^{-at}$ | $\dfrac{1}{s+a}$ | $\sigma > -a$ |
| $\delta(t)$ | $1$ | 全平面 |

这三对结论是后面一切部分分式分解、逆变换、解微分方程的地基，务必记牢。

## 拉普拉斯变换的性质（一）：线性、微分、积分、尺度与时移
> 对应块：BLK46 | 覆盖分集：P106 | 块标题（分集名）：《4.4拉式变换的性质（1）》

前面我们只求了几个基本信号的拉普拉斯变换——这远远不够。这一讲开始讲拉普拉斯变换的性质，而且这些性质不是讲完就完：我们会一边讲性质，一边用性质去继续推导更多常用信号的拉氏变换。也就是说，性质本身就是求变换的工具，学一个用一个。

还有一点先说清楚：这一讲如果没有特别强调双边，拉氏变换指的都是**单边拉普拉斯变换**。后面好几个性质的"讲究"，全都是单边带来的。

### 线性性质

线性这个性质大家太熟悉了，讲哪儿都有它。内容就是：若 $f_1(t) \leftrightarrow F_1(s)$，$f_2(t) \leftrightarrow F_2(s)$，$k_1$、$k_2$ 为常数，则

$$k_1 f_1(t) + k_2 f_2(t) \leftrightarrow k_1 F_1(s) + k_2 F_2(s)$$

证明非常简单，直接按定义来。对左边做拉氏变换（用单边来证，因为这个性质对单边、双边都成立）：

$$\int_0^{+\infty} \left[ k_1 f_1(t) + k_2 f_2(t) \right] e^{-st} \, \mathrm{d}t$$

根据积分的性质，它可以拆成两项；常数又能提到积分号外面。于是第一项变成 $k_1 \int_0^{+\infty} f_1(t) e^{-st} \mathrm{d}t$，这不就是 $f_1(t)$ 拉氏变换的定义式吗？题目条件已经告诉我们它等于 $F_1(s)$。第二项同理等于 $k_2 F_2(s)$。合起来证毕。

#### 用线性求 $\sin\omega t$ 与 $\cos\omega t$ 的拉氏变换

> **易错点**：题目里写 $f(t)=\sin\omega t$ 和写 $f(t)=\sin\omega t \cdot u(t)$，求单边拉氏变换的结果是完全一样的。因为即使是 $\sin\omega t$，我们也只看它 $t>0$ 的一边，左边不看。所以两种写法都可以，只要我们求的是单边拉氏变换。

怎么求 $\sin\omega t$ 的拉氏变换？用线性：欧拉公式把 $\sin$ 展开成两个复指数相加的形式：

$$\sin\omega t = \frac{1}{2\mathrm{j}} \left( e^{\mathrm{j}\omega t} - e^{-\mathrm{j}\omega t} \right)$$

而指数信号的拉氏变换之前已经讲过了：$e^{\mathrm{j}\omega t}$ 的单边拉氏变换是 $\dfrac{1}{s-\mathrm{j}\omega}$，$e^{-\mathrm{j}\omega t}$ 的是 $\dfrac{1}{s+\mathrm{j}\omega}$（就是 $e^{-at} \leftrightarrow \dfrac{1}{s+a}$ 那个结论，直接套）。前面的 $\dfrac{1}{2\mathrm{j}}$ 只是常数，根据线性提出来：

$$\mathcal{L}[\sin\omega t] = \frac{1}{2\mathrm{j}} \left( \frac{1}{s-\mathrm{j}\omega} - \frac{1}{s+\mathrm{j}\omega} \right)$$

通分合并：给第一项分子分母同乘 $(s+\mathrm{j}\omega)$，分母变成 $s^2 - (\mathrm{j}\omega)^2 = s^2 + \omega^2$（平方差公式，两个相乘是 $-\omega^2$，减去负的就是加），分子是 $s+\mathrm{j}\omega$；第二项同乘 $(s-\mathrm{j}\omega)$，分子变成 $s-\mathrm{j}\omega$。相减后 $\mathrm{j}\omega$ 抵消，分子是 $2\mathrm{j}\omega$，与前面的 $\dfrac{1}{2\mathrm{j}}$ 约掉：

$$\sin\omega t \leftrightarrow \frac{\omega}{s^2 + \omega^2}$$

$\cos\omega t$ 同样的路数。欧拉公式是 $\cos\omega t = \dfrac{1}{2}\left( e^{\mathrm{j}\omega t} + e^{-\mathrm{j}\omega t} \right)$，两项的分母通分后都是 $s^2+\omega^2$，分子是 $(s+\mathrm{j}\omega) + (s-\mathrm{j}\omega) = 2s$，再乘 $\dfrac{1}{2}$：

$$\cos\omega t \leftrightarrow \frac{s}{s^2 + \omega^2}$$

> **易错点**：这两个结果只差分子上的一个字母——$\cos$ 是 $s$，$\sin$ 是 $\omega$。不要记混了。

### 原函数微分性质

先交代一个记号：拉氏变换类似于傅里叶变换，我们把"$f(t)$ 的拉氏变换是 $F(s)$"简写成 $f(t) \leftrightarrow F(s)$，双箭头一来一回，后面全用这个写法。

微分性质说的是：若 $f(t) \leftrightarrow F(s)$，则

$$\frac{\mathrm{d}f(t)}{\mathrm{d}t} \leftrightarrow sF(s) - f(0^-)$$

二阶导、$n$ 阶导也都有对应形式：

$$\frac{\mathrm{d}^2 f}{\mathrm{d}t^2} \leftrightarrow s^2 F(s) - s f(0^-) - f'(0^-)$$

$$\frac{\mathrm{d}^n f}{\mathrm{d}t^n} \leftrightarrow s^n F(s) - s^{n-1} f(0^-) - s^{n-2} f'(0^-) - \cdots - f^{(n-1)}(0^-)$$

$n$ 阶的通式有规律可循：$s$ 的幂次从 $n-1$ 一路降下来，分别乘 $f(0^-)$、$f'(0^-)$……最后一项是 $f$ 的 $n-1$ 阶导代入 $0^-$，前面系数为 1。想象一下就能知道下一项该是 $s^{n-3} f''(0^-)$，它是有规律的。

#### 一阶导的证明

用定义来证。记 $f'(t)$ 的拉氏变换为

$$\int_0^{+\infty} f'(t) e^{-st} \, \mathrm{d}t$$

关键一步：把 $f'(t)$ 凑到 $\mathrm{d}$ 后面去，变成 $e^{-st} \, \mathrm{d}f(t)$。这就成了 $u\,\mathrm{d}v$ 的形式，可以分部积分：

$$\int_0^{+\infty} e^{-st} \, \mathrm{d}f(t) = \left. e^{-st} f(t) \right|_0^{+\infty} - \int_0^{+\infty} f(t) \, \mathrm{d}\left( e^{-st} \right)$$

第二项把 $\mathrm{d}e^{-st}$ 变回 $\mathrm{d}t$ 的形式：$e^{-st}$ 对 $t$ 求导前面多一个 $-s$（因为 $e^{at}$ 求导等于 $a$ 倍的 $e^{at}$），所以这一项是 $-\int_0^{+\infty} f(t) \cdot (-s) e^{-st} \mathrm{d}t = s \int_0^{+\infty} f(t) e^{-st} \mathrm{d}t$。

再看第一项的上下限。代入上限 $t \to +\infty$ 时，这里有个 $t$ 趋向无穷的问题。注意已知条件是 $f(t)$ 的拉氏变换 $F(s)$ 存在——这正是第一章最开始讲过的：为什么一些信号的傅里叶变换不存在、而拉氏变换却存在？因为 $e^{-st}$ 把 $f(t)$ 压制成了绝对可积的信号。既然拉氏变换存在，我们总能选取适当的 $\sigma$，使 $f(t) e^{-\sigma t}$ 当 $t \to +\infty$ 时趋于零。至于 $e^{-st}$ 里 $\mathrm{j}\omega$ 的那一部分，它只是个震荡因子，不影响——乘上去之后极限照样是零。所以上限代入得零。

下限代入 $t=0$：$e^0 = 1$，剩 $f(0^-)$。合起来：

$$\mathcal{L}[f'(t)] = 0 - f(0^-) + sF(s) = sF(s) - f(0^-)$$

> **易错点**：积分下限虽然写着零，但它其实是 $0^-$。代入的一定是 $0^-$！因为有时候 $f(0^-) \neq f(0^+)$——如果零时刻发生一个跳变，两边的值就不同了。这个一定要记住。

当然，如果 $f(0^-) = 0$，这个性质就简单了：$f'(t) \leftrightarrow sF(s)$。

#### 二阶导与 $n$ 阶导：套娃即可

二阶导怎么证？注意二阶导就是一阶导再求一次导，所以拿一阶导当基底，再用一次这个性质就行了。

把 $f'(t)$ 看成一个整体，记 $g(t) = f'(t)$，则 $g'(t) \leftrightarrow sG(s) - g(0^-)$。而 $G(s) = sF(s) - f(0^-)$，$g(0^-)$ 是 $f'(t)$ 代入 $0^-$ 的值，即 $f'(0^-)$。展开：

$$s\left[ sF(s) - f(0^-) \right] - f'(0^-) = s^2 F(s) - s f(0^-) - f'(0^-)$$

三阶导？再套娃一次，以此类推，$n$ 阶导的公式就全出来了。

> **结论**：若 $f(0^-)$、$f'(0^-)$、$f''(0^-)$ 这些初始值全为零，则 $n$ 阶导的拉氏变换简化为 $s^n F(s)$。当然，这是单边拉氏变换才有的讲究。

双边拉氏变换没有 $f(0^-)$ 这一说：$\dfrac{\mathrm{d}f}{\mathrm{d}t} \leftrightarrow sF(s)$，$n$ 阶导就是 $s^n F(s)$，干干净净。这个证明我们就不证了，结论记住就行。

#### 例：$\delta(t)$ 的 $n$ 阶导

已知 $\delta(t) \leftrightarrow 1$，求 $\delta^{(n)}(t)$ 的拉氏变换。

先求一阶导 $\delta'(t)$：套微分性质，$\delta(t)$ 只在零时刻有值，$f(0^-)$ 显然为零，所以 $\delta'(t) \leftrightarrow s \cdot 1 = s$。

二阶导就是一阶导再求一次导，再乘一个 $s$，得 $s^2$。不管是 $\delta$ 的几阶导，它代入 $0^-$ 都是零，所以一直乘下去：

$$\delta^{(n)}(t) \leftrightarrow s^n$$

顺带提一句：对于 $f(t)u(t)$ 这种形式的信号，代入 $0^-$ 也都是零，因为 $u(0^-) = 0$。

#### 例：用微分性质从 $\cos$ 求 $\sin$

现在已知 $\cos t$ 的拉氏变换 $F(s) = \dfrac{s}{s^2+1}$（刚才线性那部分已经求过了），让你求 $\sin t$ 的拉氏变换。题目特意告诉你 $\cos$ 的结果，其实就是在暗示你：用原函数微分这个性质。

因为 $\sin t = -\left(\cos t\right)'$（$\cos t$ 求导是 $-\sin t$），所以

$$\mathcal{L}[\sin t] = -\left[ sF(s) - f(0^-) \right] = -s \cdot \frac{s}{s^2+1} + f(0^-)$$

这里 $f(0^-) = \cos(0^-) = 1$。于是

$$-s \cdot \frac{s}{s^2+1} + 1 = -\frac{s^2}{s^2+1} + 1 = \frac{-(s^2) + (s^2+1)}{s^2+1} = \frac{1}{s^2+1}$$

和之前线性那套推出来的 $\dfrac{\omega}{s^2+\omega^2}$ 代入 $\omega = 1$ 的结果完全吻合，没问题。

#### 例：从 $\cos t \cdot u(t)$ 求 $\sin t \cdot u(t)$——$f(0^-)$ 变了

题目改一下：已知 $f(t) = \cos t \cdot u(t)$ 的拉氏变换为 $\dfrac{s}{s^2+1}$，求 $\sin t \cdot u(t)$ 的拉氏变换。还能用微分性质，但要注意：此时是对 $\cos t \cdot u(t)$ 求导了，复合函数求导，前导后不导、加上前不导后导：

$$f'(t) = -\sin t \cdot u(t) + \cos t \cdot \delta(t)$$

后一项里 $u'(t) = \delta(t)$，而 $f(t)\delta(t) = f(0)\delta(t)$，$\cos 0 = 1$，所以就是 $\delta(t)$。把 $\sin t \cdot u(t)$ 移到等式一边：

$$\sin t \cdot u(t) = \delta(t) - f'(t)$$

两边分别做单边拉氏变换。$\delta(t) \leftrightarrow 1$；$f'(t)$ 用微分性质，$sF(s) - f(0^-)$。注意此时 $f(0^-) = \cos(0^-) \cdot u(0^-) = 0$——刚才那道题里 $f(0^-)$ 是 1，这里一旦乘了 $u(t)$，$u(0^-)$ 为零，整体就是零。这是两道题不一样的地方。于是

$$\mathcal{L}[\sin t \cdot u(t)] = 1 - s \cdot \frac{s}{s^2+1} = \frac{s^2+1-s^2}{s^2+1} = \frac{1}{s^2+1}$$

两道题一个是由 $\cos t$ 得到 $\sin t$，一个是由 $\cos t \cdot u(t)$ 得到 $\sin t \cdot u(t)$，过程有所不同、$f(0^-)$ 一个是 1 一个是 0，但最后结果一样。这不难理解：$\sin t \cdot u(t)$ 和 $\sin t$ 做单边拉氏变换，结果本来就必然相同。

### 原函数积分性质

有微分性质就有积分性质。内容是：若 $f(t) \leftrightarrow F(s)$，则

$$\int_{-\infty}^{t} f(\tau) \, \mathrm{d}\tau \leftrightarrow \frac{F(s)}{s} + \frac{\displaystyle\int_{-\infty}^{0^-} f(\tau) \, \mathrm{d}\tau}{s}$$

后面那一项 $\int_{-\infty}^{0^-} f(\tau)\mathrm{d}\tau$ 是个常数——积分上限里没有 $t$，积出来自然是常数。为什么这么表示？因为有时我们对 $f(t)$ 做变上限积分会记成 $f^{(-1)}(t)$，做两次就记 $f^{(-2)}(t)$；而当 $t=0$ 时，这一项恰好就是 $\int_{-\infty}^{0^-} f(\tau)\mathrm{d}\tau$。

这个性质的证明就不证了，没啥意思，还有些麻烦。

双边拉氏变换的形式有些不同：

$$\int_{-\infty}^{t} f(\tau) \, \mathrm{d}\tau \leftrightarrow \frac{F(s)}{s}$$

没有第二项了。特别地，如果信号是 $f(t)u(t)$ 的形式——也就是在 $(-\infty, 0^-)$ 上全为零——那它在 $(-\infty, 0^-)$ 上的积分显然为零，第二项就没了，单边情形也退化成 $\dfrac{F(s)}{s}$。注意这里的零都是 $0^-$，我们之前说过，这个零默认为零负。

#### 例：从 $u(t)$ 一层层积出 $t^n u(t)$

求 $t^n u(t)$ 的拉氏变换。这题就能用到原函数积分性质，因为我们之前已经求过 $u(t) \leftrightarrow \dfrac{1}{s}$。

第一步，$u(t)$ 做一次变上限积分（第一章就出过）：$\int_{-\infty}^{t} u(\tau)\mathrm{d}\tau = t\,u(t)$，是个斜坡信号。按积分性质，它的拉氏变换是 $\dfrac{F(s)}{s} = \dfrac{1}{s^2}$，而后面积分常数项 $\dfrac{1}{s}\int_{-\infty}^{0^-} u(\tau)\mathrm{d}\tau$——$u(t)$ 这种 $f(t)u(t)$ 形式的信号，负无穷到零负全为零，这一项没有。

第二步，对 $t\,u(t)$ 再积一次：

$$\int_{-\infty}^{t} \tau\, u(\tau) \, \mathrm{d}\tau$$

这里有个第二章讲过的化简技巧：里头是 $f(t)u(t)$ 形式时，变上限积分可以把积分限从 $(-\infty, t)$ 改写成 $(0, t)$，把 $u(\tau)$ 提到后面去，直接写成 $\left[ \int_0^t \tau \, \mathrm{d}\tau \right] u(t)$。

可能有同学忘了为什么可以这么提，简单提一下：把积分拆成 $(-\infty, 0)$ 和 $(0, t)$ 两段。第一段里 $\tau < 0$，$u(\tau) = 0$，积分为零，只看第二段。第二段要对 $t$ 的取值分情况：$t > 0$ 时，区间 $(0, t)$ 整个在正半轴上，$u(\tau) = 1$，积分就是 $\int_0^t \tau \, \mathrm{d}\tau$；$t < 0$ 时，区间是 0 到一个负数，整个范围小于零，$u(\tau) = 0$，式子为零。所以 $t>0$ 时它取积分值、$t<0$ 时取零——这正是"积分结果乘一个 $u(t)$"的定义。于是：

$$\int_0^t \tau \, \mathrm{d}\tau \cdot u(t) = \frac{1}{2} t^2 u(t)$$

按积分性质（它是 $f(t)u(t)$ 形式，第二项自然为零），$\dfrac{1}{2}t^2 u(t) \leftrightarrow \dfrac{1}{s^3}$。

接着再积一次：$\int_0^t \dfrac{1}{2}\tau^2 \mathrm{d}\tau = \dfrac{1}{2} \cdot \dfrac{1}{3} t^3$，对应 $\dfrac{1}{s^4}$。当然我们不可能一层一层一直做到 $n$ 次方，多做几次找规律就行：

| 层数 | 时域 | 复频域 |
| :--- | :--- | :--- |
| 0 | $u(t)$ | $\dfrac{1}{s}$ |
| 1 | $t\,u(t)$ | $\dfrac{1}{s^2}$ |
| 2 | $\dfrac{1}{2}t^2 u(t)$ | $\dfrac{1}{s^3}$ |
| 3 | $\dfrac{1}{2}\cdot\dfrac{1}{3}t^3 u(t)$ | $\dfrac{1}{s^4}$ |
| 4 | $\dfrac{1}{2}\cdot\dfrac{1}{3}\cdot\dfrac{1}{4}t^4 u(t)$ | $\dfrac{1}{s^5}$ |

系数是 $\dfrac{1}{2}$、$\dfrac{1}{2\times3}$、$\dfrac{1}{2\times3\times4}$……积到 $t^n$ 时系数就是 $\dfrac{1}{1}\cdot\dfrac{1}{2}\cdot\dfrac{1}{3}\cdots\dfrac{1}{n}$（前面其实也可以写成 $\dfrac{1}{1}$，才一个一嘛），分母合起来就是阶乘 $n!$。时域 $t$ 的幂次和复频域 $s$ 的幂次也差一：$t^3$ 对应 $s^4$，$t^4$ 对应 $s^5$，所以 $t^n$ 对应 $\dfrac{1}{s^{n+1}}$。

把阶乘系数挪过去，就得到结论：

$$t^n u(t) \leftrightarrow \frac{n!}{s^{n+1}}$$

一层一层推、找规律，就这么得到了这个结果。

### 尺度变换性质

内容：若 $f(t) \leftrightarrow F(s)$，$a > 0$，则

$$f(at) \leftrightarrow \frac{1}{a} F\!\left( \frac{s}{a} \right)$$

注意 $F(s)$ 中的所有 $s$ 都要换成 $\dfrac{s}{a}$。

为什么限制 $a > 0$？原因很简单：我们做的是单边拉氏变换，讨论的是 $t \geq 0$ 这一边。如果 $a < 0$，尺度变换会对信号做一个反转，反转之后信号不就跑到 $t<0$ 那边去了吗？而单边拉氏变换不研究那边，所以限制 $a$ 大于零。

证明跟傅里叶变换里尺度变换的证明很类似，而且因为 $a$ 限制了大于零，还更好证。对 $f(at)$ 按定义展开：

$$\int_0^{+\infty} f(at) e^{-st} \, \mathrm{d}t$$

做换元，令 $at = x$（因为 $f(t)$ 的拉氏变换我们是知道的，要换成 $f(x)$ 的形式），则 $t = \dfrac{x}{a}$，$e^{-st}$ 变成 $e^{-\frac{s}{a}x}$，$\mathrm{d}t$ 变成 $\dfrac{1}{a}\mathrm{d}x$。积分限：原来 $t$ 从 0 到正无穷，现在 $x = at$，$a > 0$，0 乘 $a$ 还是 0，无穷乘正数还是无穷，积分限不变。提出常数 $\dfrac{1}{a}$：

$$\frac{1}{a} \int_0^{+\infty} f(x) \, e^{-\frac{s}{a}x} \, \mathrm{d}x$$

这一项和原来的拉氏变换定义式只差一个什么？原来积分号里是 $e^{-st}$，现在是 $e^{-\frac{s}{a}x}$。而积分变量叫什么无所谓，把 $x$ 换回 $t$，再看：如果把这个积分里的 $s$ 换成 $\dfrac{s}{a}$，它就是 $F\!\left(\dfrac{s}{a}\right)$。证毕。

双边拉氏变换下，自然没有 $a>0$ 的限制了——双边你转什么转呗，反正是在 $(-\infty, +\infty)$ 上讨论的。但没有这个限制，证明过程就要分 $a>0$ 和 $a<0$ 两种情况讨论（傅里叶变换里那个尺度变换性质的证明我们已经讨论过一次，方法完全类似）。结论是前面变成 $\dfrac{1}{|a|}$：

$$f(at) \leftrightarrow \frac{1}{|a|} F\!\left( \frac{s}{a} \right) \quad (\text{双边})$$

和傅里叶那边 $f(at) \leftrightarrow \dfrac{1}{|a|}F\!\left(\mathrm{j}\dfrac{\omega}{a}\right)$ 一模一样，只不过把 $\mathrm{j}\omega$ 换成了 $s$。

### 延时性质

第五个性质。内容：若 $f(t) \leftrightarrow F(s)$，$t_0 > 0$，则

$$f(t - t_0)\, u(t - t_0) \leftrightarrow F(s)\, e^{-st_0}$$

可以看到这个延时特性和傅里叶变换里的时移特性很像——我们那里是乘 $e^{-\mathrm{j}\omega t_0}$，这里是乘 $e^{-st_0}$。

#### 为什么必须是 $u(t-t_0)$ 而不是 $u(t)$

说完 $t_0 > 0$ 这个限制，肯定有同学会有疑问：为什么性质里要带 $u(t-t_0)$？为什么不是"$f(t-t_0)$ 就对应 $F(s)e^{-st_0}$"，非要多出这么一项？

注意：对有些信号来说，$f(t-t_0)$ 和 $f(t-t_0)\,u(t-t_0)$ 是完全不同的两个信号。我们举个例子，用一个双边信号来看（有时候我们确实要对双边信号做单边拉氏变换）：

```text
 f(t)                    f(t-t0)                   f(t-t0)u(t-t0)
   ┌────┐                    ┌────┐                      ┌────┐
   │    │                    │    │                      │    │
───┘    └────          ────┘    └────          ───────────┘    └────
 0 ← 只看右边           0                    0 ← 从这里才开始有信号  t0
```

设 $f(t)$ 是上面这样的双边信号。对它做单边拉氏变换，其实只考虑了它的右半部分，左边那半部分是什么无所谓——等效于 $f(t)u(t)$。

现在看 $f(t - t_0)$：这是 $f(t)$ 整体向右平移 $t_0$。对它做单边拉氏变换，我们是对哪一部分做？是零到正无穷这一部分，左边不关心。所以它等效于 $f(t)u(t)$ 整体向右移 $t_0$。

而 $f(t-t_0)\,u(t-t_0)$ 呢？是 $f(t)u(t)$ 向右平移 $t_0$。

这两个波形显然不同：对 $f(t)u(t)$ 做平移，得到的是"整个波形右移"的那个；而单边拉氏变换实际看到的是前者（从 $t=0$ 开始积分的那部分整体右移），它比 $f(t-t_0)u(t-t_0)$ 在中间多出来了一段——这一段我们压根儿就没做过积分。如果性质写成 $f(t-t_0) \leftrightarrow F(s)e^{-st_0}$，就等于凭空多了这一段，显然不对；真要那样，性质也得再加上一部分内容，而不是单纯乘个指数就了事了。

所以说，这个性质一定要注意：是 $f(t-t_0)\,u(t-t_0)$，这里可不是 $u(t)$！只有这样，它对应的才是 $F(s)e^{-st_0}$。

#### 为什么 $t_0$ 只能大于零：为什么叫"延时"

还有一个问题：为什么这个性质叫延时特性，不叫时移特性？也就是为什么 $t_0$ 只能大于零，它难道不能小一点吗？

这个问题和上面那个很类似，还是因为单边拉氏变换。画一个信号：往右移没问题——它原来是多少，往右移还是这些，我们还是对同样的内容做积分，只不过位置变了。但往左移呢？往左移会有一部分跑到 $t<0$ 的区域，而我们做的是单边拉氏变换，从零到无穷做起，小于零的那部分就被忽略了——信号缺失了一部分，少了一部分当然不行；就像上面多了一部分也不行一样。

这就是这里之所以叫延时特性的原因，也是为什么这里是 $u(t-t_0)$ 的原因。

#### 证明

证明非常简单，还是用定义。对 $f(t-t_0)\,u(t-t_0)$ 做拉氏变换：

$$\int_0^{+\infty} f(t - t_0)\, u(t - t_0)\, e^{-st} \, \mathrm{d}t$$

先看 $u(t-t_0)$ 的波形：$t_0 > 0$，当 $t > t_0$ 时它是 1，当 $t < t_0$ 时全为零。和这样的信号相乘，积分限就可以改：从 $(0, +\infty)$ 改成 $(t_0, +\infty)$——因为 $0$ 到 $t_0$ 这一段被乘成零了，积分结果肯定也是零：

$$\int_{t_0}^{+\infty} f(t - t_0)\, e^{-st} \, \mathrm{d}t$$

接下来换元，令 $\tau = t - t_0$（已知的是 $f(t)$ 的变换，要凑出 $f(\tau)$）。则 $t = \tau + t_0$，指数变成 $e^{-s(\tau + t_0)}$，$\mathrm{d}t = \mathrm{d}\tau$（$t_0$ 是常数）。积分限：$t = t_0$ 时 $\tau = t_0 - t_0 = 0$；$t = +\infty$ 时，无穷减 $t_0$ 还是无穷——无穷跟 $t_0$ 说，你谁啊？地位太低了。所以：

$$\int_0^{+\infty} f(\tau)\, e^{-s\tau} \cdot e^{-st_0} \, \mathrm{d}\tau$$

$e^{-st_0}$ 跟 $\tau$ 无关，是常数，提出来；剩下的部分正是单边拉氏变换的定义，等于 $F(s)$：

$$f(t - t_0)\, u(t - t_0) \leftrightarrow F(s)\, e^{-st_0}$$

结论就是：把 $f$ 延时 $t_0$，在 $s$ 域上只需要乘一个 $e^{-st_0}$ 即可。因为做的是单边拉氏变换，才有这么多讲究——只能延时，而且要多一个 $u(t-t_0)$。双边拉氏变换这些问题都没有：$f(t-t_0) \leftrightarrow F(s)e^{-st_0}$，不要求 $t_0$ 必须大于零，也没有 $u(t-t_0)$。

#### 例：矩形脉冲的拉氏变换

求如图所示的矩形脉冲（幅度 $E$，从 $t=0$ 持续到 $t=t_0$）的拉氏变换。

```text
 f(t)
   ┌────────┐ E
   │        │
───┘        └─────────
   0        t0
```

这个题如果让你求傅里叶变换你会怎么求？我们做过类似的题：这显然是一个门函数做一个时移，门函数的傅里叶变换是我们熟知的 Sa 函数，再加上傅里叶变换的时移特性就能解决。但注意，拉氏变换里可没有那一套——因为我们讨论的都是单边拉氏变换，积分范围是零到无穷，而门函数显然不满足这个条件（它对称分布在原点两侧）。

那这个矩形脉冲除了用门函数表示以外还可以怎么表示？用阶跃：第一章讲阶跃信号的时候就讲过它的特点。这个脉冲等于两个阶跃相减：

$$f(t) = E\left[ u(t) - u(t - t_0) \right]$$

$u(t)$ 减去 $u(t-t_0)$，就只剩下中间这段矩形脉冲。$u(t)$ 的拉氏变换我们非常熟悉，是 $\dfrac{1}{s}$；$u(t-t_0)$ 用刚才的延时特性，对应 $e^{-st_0} \cdot \dfrac{1}{s}$。根据线性合并，再乘上幅度 $E$：

$$F(s) = \frac{E}{s}\left( 1 - e^{-st_0} \right)$$

#### 例：单边周期冲激串的拉氏变换

求 $\displaystyle\sum_{n=0}^{+\infty} \delta(t - nT)$ 的拉氏变换（$T > 0$）。

这个信号大家很眼熟，因为第三章见过类似的。但注意，当时我们是 $\sum_{n=-\infty}^{+\infty}$，冲激串从负无穷到正无穷都有；而我们这里 $n$ 从零开始，到正无穷——因为我们讨论的拉氏变换是单边的，所以 $n$ 从零开始。

把求和打开，逐项写出来：$n=0$ 时是 $\delta(t)$，$n=1$ 时是 $\delta(t - T)$，$n=2$ 时是 $\delta(t - 2T)$，一直下去。逐项求变换：$\delta(t) \leftrightarrow 1$，非常简单；$\delta(t-T)$ 用延时特性，延时 $T$，对应 $1 \cdot e^{-sT}$；$\delta(t-2T)$ 对应 $e^{-2sT}$；后面每一项都是这么求。对整体做拉氏变换，结果是：

$$1 + e^{-sT} + e^{-2sT} + e^{-3sT} + \cdots$$

这是一个什么形式？等比级数！公比就是 $q = e^{-sT}$，每次都乘一个它。上限是无穷，所以共有无穷多项。高数学过：等比级数若收敛，收敛于 $\dfrac{1}{1-q}$；收敛条件是公比的模小于 1。

那它的模能不能小于 1？可以的。把 $e^{-sT}$ 拆开：$s = \sigma + \mathrm{j}\omega$，所以 $e^{-sT} = e^{-\sigma T} \cdot e^{-\mathrm{j}\omega T}$。乘积的模等于模的乘积，而后一个因子 $e^{-\mathrm{j}\omega T}$ 是旋转因子，模恒为 1，所以只需要看 $e^{-\sigma T}$ 的模。$\sigma$、$T$ 都是实数，它就是个正实数（$e$ 指数恒大于零），可以写成 $\dfrac{1}{e^{\sigma T}}$——只要分母大于 1，整体就小于 1。而 $e^{\sigma T}$ 当然能大于 1：只要 $\sigma > 0$。所以说满足收敛条件没问题，只需要 $\sigma > 0$。

于是这个冲激串的拉氏变换：

$$\sum_{n=0}^{+\infty} \delta(t - nT) \leftrightarrow \frac{1}{1 - e^{-sT}}, \quad \sigma > 0$$

这个结论很有用，之后我们还会用到。

## 拉氏变换的性质（下）：s 域平移、卷积定理与初值终值定理
> 对应块：BLK47 | 覆盖分集：P107 | 块标题（分集名）：《4.4拉式变换的性质（2）》

上一讲结尾我们刚说完延时特性——它本质上就是时域的平移。那有时域的平移，自然也有 s 域的平移。这一讲把拉氏变换剩下的性质一口气讲完：s 域平移、时移与尺度的组合使用、卷积定理、s 域微分与积分，最后是两个"偷懒神器"——初值定理与终值定理。它们能让你不解出 $f(t)$ 就直接读出信号的初值和终值，但用错条件的代价也很大，这一讲会专门花力气把"什么时候不能用"讲清楚。

### s 域平移：时域乘个指数，s 整体搬家

> **定义**：若 $f(t) \leftrightarrow F(s)$，则 $f(t)\,e^{-at} \leftrightarrow F(s+a)$。

时域里给 $f(t)$ 乘一个指数 $e^{-at}$，它的拉氏变换就是把 $F(s)$ 里的 $s$ 整体换成 $s+a$——对 s 域做了一次平移。

这个性质非常简单，证明也非常简单，直接按定义来：

$$\mathcal{L}\left[f(t)e^{-at}\right] = \int_0^{+\infty} f(t)\,e^{-at}\,e^{-st}\,\mathrm{d}t = \int_0^{+\infty} f(t)\,e^{-(s+a)t}\,\mathrm{d}t$$

两个指数合并之后，这个积分和拉氏变换的定义式只差一处：定义式告诉我们 $\int_0^{+\infty} f(t)e^{-st}\mathrm{d}t = F(s)$，而这里把 $s$ 换成了 $s+a$。所以结果就是 $F(s+a)$，证明完毕。

举两个例子：求 $e^{-at}\sin\omega t\,u(t)$ 和 $e^{-at}\cos\omega t\,u(t)$ 的拉氏变换。$\sin\omega t$、$\cos\omega t$ 的拉氏变换之前求过了，这两个必须记住，不要记混：

> **结论**：
> $$\sin\omega t\,u(t) \leftrightarrow \frac{\omega}{s^2+\omega^2}, \qquad \cos\omega t\,u(t) \leftrightarrow \frac{s}{s^2+\omega^2}$$

现在乘上了 $e^{-at}$，正好套 s 域平移：把上面两个式子里的 $s$ 全部换成 $s+a$ 即可。

$$e^{-at}\sin\omega t\,u(t) \leftrightarrow \frac{\omega}{(s+a)^2+\omega^2}, \qquad e^{-at}\cos\omega t\,u(t) \leftrightarrow \frac{s+a}{(s+a)^2+\omega^2}$$

很简单，我们又顺手得到了两个常用的结论。

### 时移与尺度变换联手：先动谁有讲究

时域变换特性讲完了，延时特性也讲完了，这两个结合起来使用，其实如果不专门讲，你自己应该也会——这里还是简单过一遍，因为里面有一个特别容易翻车的点。

若 $f(t)\,u(t) \leftrightarrow F(s)$，则

$$f(at-b)\,u(at-b) \leftrightarrow \frac{1}{a}\,e^{-\frac{b}{a}s}\,F\!\left(\frac{s}{a}\right), \qquad a>0,\ b>0$$

从 $f(t)u(t)$ 到 $f(at-b)u(at-b)$，第一章就说过总共有两种办法：先时移，或者先尺度变换。两种走法都看一眼。

**路径一：先时移，再尺度。** 先不动 $t$——之前就说过，碰到 $f(at+b)$ 这种形式，$t$ 最好先别动，不然会给你带来麻烦。先把 $f(t)u(t)$ 时移成 $f(t-b)u(t-b)$，按时移特性，$F(s)$ 要乘上 $e^{-bs}$；然后做尺度变换，把 $t$ 前面乘上 $a$，变成 $f(at-b)u(at-b)$，按尺度特性前面多出 $\frac{1}{a}$。注意这里的关键：**尺度变换要把所有的 $s$ 都换成 $\dfrac{s}{a}$**——不单单是 $F(s)$ 里的 $s$ 要换，指数 $e^{-bs}$ 里也出现了 $s$，同样要换：

$$e^{-bs}F(s)\ \longrightarrow\ \frac{1}{a}\,e^{-\frac{b}{a}s}\,F\!\left(\frac{s}{a}\right)$$

**路径二：先尺度，再时移。** 先把 $f(t)u(t)$ 尺度变换成 $f(at)u(at)$，得 $\frac{1}{a}F\!\left(\frac{s}{a}\right)$；然后再做延时。大家注意：**你做的延时是针对 $t$ 而言的，可不是针对 $at$ 而言的**。得这么写：

$$f(at-b)\,u(at-b) = f\!\left(a\left(t-\frac{b}{a}\right)\right)u\!\left(a\left(t-\frac{b}{a}\right)\right)$$

也就是说实际延时的是 $\dfrac{b}{a}$——$at$ 才是减去一个 $b$ 嘛，前面那个 $a$ 你可不要给它带上。于是要乘 $e^{-\frac{b}{a}s}$：

$$\frac{1}{a}F\!\left(\frac{s}{a}\right)\ \longrightarrow\ \frac{1}{a}\,e^{-\frac{b}{a}s}\,F\!\left(\frac{s}{a}\right)$$

两种方法肯定会得到相同的结论。这个结论其实不用刻意去记，只要知道它是怎么做出来的就行，很简单嘛。唯一必须记住的关键点就一句话：

> **易错点**：一切的变化都是针对 $t$ 而言的。尺度变换时 $b$ 不要动；做延时时 $a$ 不要带上。

### 卷积定理：时域卷积，s 域相乘

> **定义**：若 $f_1(t) \leftrightarrow F_1(s)$，$f_2(t) \leftrightarrow F_2(s)$，则 $f_1(t) * f_2(t) \leftrightarrow F_1(s)\,F_2(s)$。

这和傅里叶变换那里的卷积定理非常像：时域卷积，对应变换域乘积。乘积这个操作可比卷积简单多了，所以卷积定理的重要性毋庸置疑——它能大大简化我们的计算。

学傅里叶变换的时候我们知道，卷积定理其实有一对：一个是"时域卷积、频域相乘"，另一个是"时域相乘、频域卷积（还要再乘 $\frac{1}{2\pi}$）"。在傅里叶变换那一章，这两个性质都很重要；但在拉氏变换这里，我们所讲的卷积定理只有时域卷积这一半——至于时域相乘那一半，它太麻烦、太繁琐，一般用不到，这里就不讲了。

还有一点要提：因为我们做的是**单边**拉氏变换，所以 $f_1(t)$、$f_2(t)$ 都要求是因果信号，即 $t<0$ 时 $f(t)=0$。这个定理的证明我们就不证了，直接来看一道例题。

### 用卷积定理求有始周期信号的拉氏变换

求有始周期矩形脉冲信号 $f(t)$ 的拉氏变换——这个周期矩形脉冲信号我们在第三章就见过了，波形是从 $t=0$ 开始、周期为 $T$，每个周期内是 $[0,\tau)$ 上的一截矩形。现在新加了一个限定词：**有始**。也就是说这个周期信号在 $t=0$ 时刻之前是没有的，从 $t=0$ 之后才开始有。

怎么求？回忆一下第三章求周期矩形脉冲的傅里叶变换是怎么做的：当时有一种方法，就是把它看成**一个单周期信号**卷上**一个冲激串**——冲激串卷积的作用就是把那个单周期信号搬移到每个冲激出现的位置，两者一卷积就得整个周期信号。而时域上做卷积，就相当于频域上乘积，所以只要求出单周期信号的变换和冲激串的变换，一相乘就得到周期信号的变换了。

这里完全可以效仿这种做法，因为冲激串的拉氏变换我们之前已经求过了：

$$\sum_{n=0}^{+\infty}\delta(t-nT) \leftrightarrow \frac{1}{1-e^{-sT}}$$

把有始周期矩形脉冲写成"第一周期"卷"冲激串"：

$$f(t) = f_0(t) * \sum_{n=0}^{+\infty}\delta(t-nT)$$

其中第一个周期就是 $[0,\tau)$ 上的那截矩形，可以看成两个阶跃相减：

$$f_0(t) = u(t) - u(t-\tau)$$

它的拉氏变换之前也求过：$u(t)$ 对应 $\dfrac{1}{s}$，$u(t-\tau)$ 按时移特性对应 $\dfrac{1}{s}e^{-s\tau}$，两者相减：

$$F_0(s) = \frac{1}{s}\left(1-e^{-s\tau}\right)$$

根据刚讲的卷积定理，时域卷积就是 s 域乘积，两者一乘：

$$F(s) = \frac{1-e^{-s\tau}}{s\left(1-e^{-sT}\right)}$$

这样有始周期矩形脉冲信号的拉氏变换就求完了。做完这个例子，其他有始周期信号的拉氏变换应该也都会求了：取它的第一个周期，卷上冲激串；把第一周期的拉氏变换求出来，冲激串的拉氏变换是现成的 $\dfrac{1}{1-e^{-sT}}$，根据卷积定理一乘，就能求出任何一个有始周期信号的拉氏变换。

### s 域微分：时域乘 t，s 域求导

> **定义**：若 $f(t) \leftrightarrow F(s)$，则
> $$(-t)\,f(t) \leftrightarrow \frac{\mathrm{d}F(s)}{\mathrm{d}s}, \qquad (-t)^n f(t) \leftrightarrow \frac{\mathrm{d}^n F(s)}{\mathrm{d}s^n}$$

由一阶到 $n$ 阶是很容易推的：比如对 $F(s)$ 求二阶导，其实就相当于是对一阶导再求一阶导；而一阶导对应的时域因子是 $(-t)$，再求一阶导就再乘一个 $(-t)$，也就是 $(-t)^2$。照此推下去，$n$ 阶导对应的时域因子就是 $(-t)^n f(t)$。

**这个结论的证明过程不同于往常。** 往常我们都是从左往右证：求 $f(t)$ 的拉氏变换，用定义看看它是什么，然后往右推。这次要从右往左推：现在已经知道

$$F(s) = \int_0^{+\infty} f(t)\,e^{-st}\,\mathrm{d}t$$

那我们就对它求一个导，看看会得到什么、能不能拉到左边去。

积分求导会得到什么？这里先给大家介绍一个公式。不是说你必须得记，但我想这个公式会大大减轻你在高数里的一些计算。高数中我们经常遇到变限积分求导的问题：对比较简单的情形，

$$\frac{\mathrm{d}}{\mathrm{d}x}\int_{a(x)}^{b(x)} f(t)\,\mathrm{d}t = f\big(b(x)\big)\,b'(x) - f\big(a(x)\big)\,a'(x)$$

这大家滚瓜烂熟。但有时被积函数里也带着 $x$，变成 $f(t,x)$，做起来就有些复杂了，可能还要做换元之类的操作。下面这个公式让你不用再换元，直接代入就能做：

$$\frac{\mathrm{d}}{\mathrm{d}x}\int_{a(x)}^{b(x)} f(t,x)\,\mathrm{d}t = f\big(b(x),x\big)\,b'(x) - f\big(a(x),x\big)\,a'(x) + \int_{a(x)}^{b(x)} \frac{\partial f(t,x)}{\partial x}\,\mathrm{d}t$$

这个公式确实有点长、不太好记，但记下来对你肯定有好处——接下来它会帮你解决任何变限积分求导的问题。它是高数课本上的公式，大纲是不要求掌握的；在信号系统里可能用处没那么大，我们这里推导正好可以用一下。

回到证明。我们的积分里既有 $s$ 又有 $t$，正好利用这个公式；注意这里的积分上下限都是常数，常数求导是零，所以第一项、第二项都为零，只剩第三项。被积函数里只有 $e^{-st}$ 含 $s$，它对 $s$ 求导得 $(-t)\,e^{-st}$：

$$\frac{\mathrm{d}F(s)}{\mathrm{d}s} = \int_0^{+\infty} (-t)\,f(t)\,e^{-st}\,\mathrm{d}t$$

得到这个形式，你发现被积函数里不就是一个拉氏变换的形式嘛——只是前面多了一个 $(-t)$。那其实可以把 $(-t)$ 和 $f(t)$ 放在一起，看成一个新的关于 $t$ 的函数，给它起个名字叫 $g(t)$，$g(t) = -t\,f(t)$。于是右边就是 $\int_0^{+\infty} g(t)e^{-st}\mathrm{d}t$，即对 $g(t)$ 做拉氏变换。所以对 $(-t)f(t)$ 做拉氏变换，就得到 $F(s)$ 的导数——结论证明完。证明本身不重要，但刚才那个变限积分求导的公式，我觉得很好用，最好你能记一下。

来举几个例子。

**例一**：求 $t^2 e^{-at}u(t)$ 的拉氏变换。$e^{-at}u(t)$ 的拉氏变换我们是知道的：$\dfrac{1}{s+a}$。现在时域乘了两个 $t$，而 $(-t)^2 = t^2$，正负号没问题，相当于对 $s$ 求两次导：

$$\mathcal{L}\left[t^2 e^{-at}u(t)\right] = \frac{\mathrm{d}^2}{\mathrm{d}s^2}\left(\frac{1}{s+a}\right) = \frac{2}{(s+a)^3}$$

这就是很简单的求导问题。先求一阶导，等于 $-\dfrac{1}{(s+a)^2}$；再求一次导，得 $\dfrac{2}{(s+a)^3}$。这个结论很多同学高数里就记下来了。不放心也可以现场推：分数求导，上导下不导——分子是常数，导数为零；减去上不导下导，分母导数是 $1$，比上分母的平方。再导一次同理：下导是 $2(s+a)$，分母平方是 $(s+a)^4$，约去一个，$-1$ 和 $-1$ 变成 $+1$，结果就是 $\dfrac{2}{(s+a)^3}$。

其实这里还有另外一种做法。$t^n u(t)$ 的拉氏变换之前已经求过：$\dfrac{n!}{s^{n+1}}$。取 $n=2$，$t^2u(t) \leftrightarrow \dfrac{2!}{s^3} = \dfrac{2}{s^3}$（$2! = 1\times 2 = 2$）；现在再乘一个 $e^{-at}$，按 s 域平移那个性质，把式子里的 $s$ 都换成 $s+a$，得 $\dfrac{2}{(s+a)^3}$。我们发现这样也得到了相同的结果，而且第二种反而还快一些。

**例二**：求 $t\cos\omega t\,u(t)$ 和 $t\sin\omega t\,u(t)$ 的拉氏变换。这两个结论是要记的，但它们出现的频率确实不高、出题的可能性比较小，所以肯定会有很多同学记不住，或者不太想记。不想记可以，但你起码得会推导——万一出现了呢？推导就可以利用 s 域微分这个性质：由 $(-t)f(t) \leftrightarrow F'(s)$，根据线性把负号移过去，得

$$t\,f(t) \leftrightarrow -\frac{\mathrm{d}F(s)}{\mathrm{d}s}$$

而基座还是那两个不能不会的变换（也不要搞混）：$\cos\omega t \leftrightarrow \dfrac{s}{s^2+\omega^2}$，$\sin\omega t \leftrightarrow \dfrac{\omega}{s^2+\omega^2}$。

先求 $t\cos\omega t\,u(t)$，就是对其象函数求一阶导再加负号。这是一个分式求导：上导下不导，分子导数是 $1$，得 $s^2+\omega^2$；减去上不导下导，分母导数是 $2s$，得 $2s^2$；分母是 $(s^2+\omega^2)^2$。注意负号别忘了：分子是 $\omega^2-s^2$，前面还有一个负号，所以是 $s^2-\omega^2$：

$$t\cos\omega t\,u(t) \leftrightarrow \frac{s^2-\omega^2}{\left(s^2+\omega^2\right)^2}$$

再求 $t\sin\omega t\,u(t)$：分子 $\omega$ 是常数，求导是零，第一项没有了；只剩第二项，上不导下导得 $-\omega\cdot(-2s)$，负号负号一约：

$$t\sin\omega t\,u(t) \leftrightarrow \frac{2\omega s}{\left(s^2+\omega^2\right)^2}$$

这样我们就求出了它们两个的拉氏变换：

| 信号 | 拉氏变换 |
| :--- | :--- |
| $t\cos\omega t\,u(t)$ | $\dfrac{s^2-\omega^2}{(s^2+\omega^2)^2}$ |
| $t\sin\omega t\,u(t)$ | $\dfrac{2\omega s}{(s^2+\omega^2)^2}$ |

最好记住；记不下来的话，你得会推，这个推导也并不麻烦，前提是得知道 s 域微分这个性质。但我还是希望大家能记住：考场上你现推的话，一是浪费时间，二是高度紧张的情况下你可能推错——即使不紧张，你也可能推错。所以能在考场之外做的事，就尽量在考场之外做，不要留到考试的时候做。做好万全的准备，才能打胜仗嘛。

这两个结果还可以写得更复杂一些，比如再乘一个 $e^{-at}$，求 $t\,e^{-at}\cos\omega t\,u(t)$ 的拉氏变换。多了一项不要怕——我们有 s 域平移的性质嘛，时域乘 $e^{-at}$，就是把 $s$ 换成 $s+a$。我们已经得到了它的拉氏变换，那把式子里的 $s$ 全部换成 $s+a$：

$$t\,e^{-at}\cos\omega t\,u(t) \leftrightarrow \frac{(s+a)^2-\omega^2}{\left((s+a)^2+\omega^2\right)^2}, \qquad t\,e^{-at}\sin\omega t\,u(t) \leftrightarrow \frac{2\omega(s+a)}{\left((s+a)^2+\omega^2\right)^2}$$

### s 域积分：时域除个 t

有 s 域微分，自然就有 s 域积分。这个性质确实用得比较少，简单介绍一下：

> **定义**：若 $f(t) \leftrightarrow F(s)$，则
> $$\frac{f(t)}{t} \leftrightarrow \int_{s}^{+\infty} F(\lambda)\,\mathrm{d}\lambda$$

注意这不是我们传统上做的那种不定积分，它的下限是 $s$、上限是无穷——实际上是一个变下限积分，这是要注意的。

什么时候会用到呢？比如题目给你 $f(t)$ 的拉氏变换，让你求 $\dfrac{f(t)}{t}$ 的拉氏变换；又比如我们已经知道 $\sin t$ 的拉氏变换，让你求 $\dfrac{\sin t}{t}$ 的拉氏变换——这时就需要对 $F(s)$ 做这样一个积分。因为这个性质确实用得比较少，例子就不举了，证明过程也不写了，就这样吧。

### 初值定理：不解出 f(t)，直接读出 f(0⁺)

> **定义**：若 $f(t) \leftrightarrow F(s)$，则
> $$\lim_{t\to 0^+} f(t) = \lim_{s\to+\infty} s\,F(s)$$

注意这是一个等号：两个极限值相同。所谓初值，就是 $f(t)$ 在 $t$ 趋于 $0^+$ 时的极限，有的教材直接写成 $f(0^+)$。

这个定理有什么用？有时题目会直接给我们一个 $F(s)$，让我们求它的初值。要是不会初值定理，你只能先求拉氏逆变换得到 $f(t)$，再把 $t=0^+$ 代进去。现在有了这个定理，直接求 $sF(s)$ 在 $s$ 趋于无穷时的极限即可。

举个例子。$F(s) = \dfrac{1}{s+1}$，求 $f(0^+)$：

$$f(0^+) = \lim_{s\to+\infty} \frac{s}{s+1} = 1$$

这个极限很简单，一下就求出了初值。一般出题时，如果想考初值定理，它会专门给你一个 $F(s)$，让你求 $f(0^+)$——这时候你就懂了，它其实就是考你初值定理这个点。

#### 真分式与假分式

初值定理有一个要注意的地方：$F(s)$ 要求为**真分式**；如果 $F(s)$ 为假分式，需先将 $F(s)$ 化为真分式，再用初值定理。这里提到两个概念——假分式和真分式——之前介绍过，这里再来讲一遍。

我们所讨论的 $F(s)$ 大多数都是有理分式的形式，即两个多项式之比，一般形式为

$$F(s) = \frac{b_m s^m + b_{m-1}s^{m-1} + \cdots + b_1 s + b_0}{s^n + a_{n-1}s^{n-1} + \cdots + a_1 s + a_0}, \qquad b_m \neq 0$$

- **真分式**：分子的最高阶次 $m$ **小于**分母的最高阶次 $n$。真分式其实是我们见到更多的，比如 $\dfrac{s+1}{s^2+10s+5}$ 就是一个真分式。
- **假分式**：分子的最高阶次 $m$ **大于或等于**分母的最高阶次 $n$。注意 $m=n$ 也是假分式，比如 $\dfrac{s^2+1}{s^2+10s+5}$，分子分母最高都是两阶，此时它就是一个假分式。

对于一个假分式，它总可以拆成一个真分式加上一个有理多项式的形式。用什么方法拆？就用我们之前介绍过的长除法。

举一个例子，拆 $F(s) = \dfrac{s^4+8s^3+25s^2+31s+15}{s^3+6s^2+11s+6}$。长除法做起来：分子最高是 $s$ 的四次方、分母最高是三次方，商的首项就是 $s$；$s$ 乘分母得 $s^4+6s^3+11s^2+6s$，相减余下 $2s^3+14s^2+25s+15$；余式最高是三次方，谁乘 $s^3$ 等于 $2s^3$？显然是 $2$，上 $2$：$2$ 乘分母得 $2s^3+12s^2+22s+12$，再减余下 $2s^2+3s+3$。当然还可以继续往下除，但我们求到余式的最高次数已经小于除式的最高次数为止——这 $2$ 已经小于 $3$ 了，我们已经完成任务了：

$$F(s) = s + 2 + \frac{2s^2+3s+3}{s^3+6s^2+11s+6}$$

商 $s+2$ 就是那个多项式，剩下的余式比上原来的分母，就是那个真分式。就这么拆。

#### 为什么假分式不能直接用初值定理

回过头看使用条件：若 $F(s)$ 为假分式，需将其化为"多项式 + 真分式"的形式，而初值定理只对那个真分式部分使用，前面拆出来的有理多项式部分不管它：

$$\lim_{t\to 0^+} f(t) = \lim_{s\to+\infty} s\,F_1(s)$$

其中 $F_1(s)$ 为真分式。为什么有这样的要求？举一个具体的例子来说明。

取 $F(s) = \dfrac{s+2}{s+1}$，求初值 $f(0^+)$。求初值我们自然首先想到初值定理，于是对 $F(s)$ 乘一个 $s$、取 $s$ 趋于无穷的极限：

$$\lim_{s\to+\infty} \frac{s(s+2)}{s+1}$$

分子最高是 $s^2$，分母只是 $s$；$s\to\infty$ 时分子是分母的高阶无穷大，这个极限肯定是无穷——不存在。想一想假分式的定义：分子的最高阶次要大于等于分母；而初值定理还要再乘一个 $s$，乘完之后分子的最高阶次必然高于分母的最高阶次，$s\to\infty$ 时上面就是下面的高阶无穷大，结果肯定是无穷、不存在。所以对假分式直接用初值定理，只会得到一个"数值不存在"的结果。

可是用了初值定理发现数值不存在，它的数值真的不存在吗？用以前传统的方法算一下：先求 $F(s)$ 的拉氏逆变换，再代入 $t=0^+$，看看初值到底等于什么。这个假分式可以写成多项式加真分式的形式，一眼能抽出来：

$$F(s) = \frac{s+2}{s+1} = \frac{(s+1)+1}{s+1} = 1 + \frac{1}{s+1}$$

常数 $1$ 的拉氏逆变换是 $\delta(t)$，$\dfrac{1}{s+1}$ 对应 $e^{-t}u(t)$，所以

$$f(t) = \delta(t) + e^{-t}u(t)$$

现在代入 $t=0^+$：注意 $\delta(t)$ 只有在 $t=0$ 这一点上取无穷大的值，在 $t=0^+$、$t=0^-$ 处都是零，所以它在这里根本就没有影响——或者说没有它也一样；第二项代入 $0^+$ 得 $e^0 = 1$。所以

$$f(0^+) = 1$$

这个数值并不是不存在，这么算发现初值等于 $1$。那为什么刚才直接套定理会得到无穷呢？问题就出在 $\delta(t)$ 身上：

> **关键**：$\delta(t)$ 在时域上对初值没有任何影响——它在 $t=0^+$ 处是零；但它却在 s 域上带来了很大的影响——它对应的那一项常数，让原本的真分式变成了假分式。

具体看：$\dfrac{1}{s+1}$ 本来是一个真分式，加上常数 $1$ 之后变成假分式了，而假分式套初值定理得到的结果肯定是无穷。现在如果把时域上的 $\delta(t)$ 剔除——对应到 s 域，就是把那个常数 $1$ 不看了——剩下的 $\dfrac{1}{s+1}$ 是真分式，对它用初值定理：

$$\lim_{s\to+\infty} \frac{s}{s+1} = 1$$

这样不就对上了嘛。

不只常数这一项。$F(s)$ 的多项式部分还可能出现 $s$、$s^2$、$s^3$ 这些项，它们的拉氏逆变换都是 $\delta(t)$ 的一系列导数——前面我们已经证明过 $\delta(t)$ 的 $n$ 阶导对应的拉氏变换就是 $s^n$。这些冲击函数的导数一旦代入 $t=0^+$ 也是零，所以它们在时域上对初值同样没有影响；但它们一旦到了频率上，就会让我们这个真分式变成假分式，从而使初值定理失效、变为无穷。这就是为什么对假分式要先把多项式部分剔除掉、化成真分式，再用初值定理的原因。

#### 完整算一遍：先拆，再用

现在把前面长除法拆出来的那个 $F(s)$ 用起来，求它的初值：

$$F(s) = \frac{s^4+8s^3+25s^2+31s+15}{s^3+6s^2+11s+6}$$

求初值就可以用初值定理，但注意这个 $F(s)$ 是假分式，可不能直接乘一个 $s$ 然后代 $s=\infty$——否则分子最高是 $s$ 的五次方、分母最高是三次方，上面是下面的高阶无穷大，极限只会是无穷。所以得先把这个假分式拆分为一个多项式加真分式的形式（长除法结果见前），然后只对真分式那部分单独用初值定理：

$$f(0^+) = \lim_{s\to+\infty} \frac{s\,(2s^2+3s+3)}{s^3+6s^2+11s+6} = \lim_{s\to+\infty} \frac{2s^3+3s^2+3s}{s^3+6s^2+11s+6}$$

怎么做？学极限的时候大家应该都做过这类题：就是看分子分母最高次项前面的系数，一比就行。这里相当于"无穷的三次方"比"无穷的三次方"——分子后面的低阶项在 $2s^3$ 面前不值一提，都可以忽略；分母也是同理，只有 $s^3$ 值得留下（当然我这么说不很标准，不能真写"无穷的立方"；严格的做法是分子分母同除 $s^3$，得 $\dfrac{2+\frac{3}{s}+\frac{3}{s^2}}{1+\frac{6}{s}+\frac{11}{s^2}+\frac{6}{s^3}}$，$s\to\infty$ 时这些负幂次项显然都趋零）。最高次系数一比，自然就是二比一：

$$f(0^+) = \frac{2}{1} = 2$$

直接看系数一比其实就很简单——你只要明白这个原理。所以初值等于 $2$，其实就是一个简单的求极限题。

### 终值定理：s 趋于零，读出 f(∞)

之前说的是初值，这个是终值。

> **定义**：若 $f(t) \leftrightarrow F(s)$，则
> $$\lim_{t\to+\infty} f(t) = \lim_{s\to 0} s\,F(s)$$

$t\to\infty$ 时 $f(t)$ 的极限就是它的终值，有的教材直接写成 $f(\infty)$。名字上先提醒一句：这个"终"是终点的终，不是数学分析里拉格朗日中值定理的那个"中值"，别混淆。

终值定理有什么用？它与初值定理很类似：如果题目直接给我们一个 $F(s)$，让你求它的终值，有了定理之后，你就不必先求拉氏逆变换得到 $f(t)$、再对 $f(t)$ 取 $t$ 趋于无穷的极限，而是直接在 s 域上乘一个 $s$、取 $s$ 趋于零的极限即可。这就简便了我们的计算。

举个例子。$F(s) = \dfrac{1}{s+2}$，求它的终值。

**不会定理怎么做**：得先对 $F(s)$ 做拉氏逆变换求出 $f(t)$。$\dfrac{1}{s+2}$ 是 $\dfrac{1}{s+a}$ 的形式，对应的是衰减指数信号，所以 $f(t) = e^{-2t}u(t)$；然后再取极限 $\lim_{t\to+\infty} e^{-2t}u(t)$——$e^{-2t}$ 是衰减的指数函数，$t\to\infty$ 时显然为零，终值就是 $0$。

**学会定理之后**：直接在 s 域上进行操作，乘一个 $s$、取 $s\to 0$ 的极限：

$$f(\infty) = \lim_{s\to 0} \frac{s}{s+2} = \frac{0}{2} = 0$$

$s\to 0$ 时分子趋于零、分母趋于 $2$，结果就是零。可以看到得到了一样的结果。

#### 终值存在的条件：先认识极点

终值定理和初值定理类似，也有使用条件，而且这些使用条件一定要注意：**终值存在，才能使用终值定理**。所谓终值存在，就是 $\lim_{t\to+\infty}f(t)$ 这个极限存在。在 s 域上怎么提前判断？有一条判据：

> **结论**：$F(s)$ 的极点全部位于左半平面，或者在 $s=0$ 处只有一阶极点——满足该条件，终值才存在；极点不满足该要求，则终值不存在。

这里涉及到一个新概念——**极点**。关于极点，它的概念以及极点和信号波形的对应关系，后面还会详细展开，这里先简单介绍一下什么是极点。

我们的 $F(s)$ 一般都是有理分式，即多项式之比：分子是一个多项式，分母也是一个多项式。

> **定义**：**极点**就是分母多项式等于零的根；**零点**就是分子多项式等于零的根。

这两个名字起得很巧妙：分子多项式等于零，整个分式就等于零了，所以叫**零点**；分母多项式等于零，分母为零，整个分式不是趋向于无穷大了嘛——无穷大就是极大的，所以它是一个**极点**。

拿几个例子体会一下这条判据：

- $F(s) = \dfrac{1}{s+2}$：极点是 $s=-2$，$-2<0$，在左半平面。它对应衰减指数信号 $e^{-2t}u(t)$，$t\to\infty$ 时趋于零，终值肯定存在，而且为零。
- $F(s) = \dfrac{1}{s}$：只有一个 $s=0$ 处的极点，而且是一阶的。它对应 $u(t)$，$u(t)$ 的终值显然存在，等于 $1$。
- $F(s) = \dfrac{1}{s^2}$：$s=0$ 处是**二阶**极点，就不满足"原点处只能一阶"的要求了。

#### 一个反例：sin t 骗过了终值定理

看这道题：$F(s) = \dfrac{1}{s^2+1}$，求 $\lim_{t\to+\infty}f(t)$。这就是一个求终值的题，那就用终值定理：

$$\lim_{t\to+\infty} f(t) = \lim_{s\to 0} \frac{s}{s^2+1} = \frac{0}{1} = 0$$

$s\to 0$ 时分子趋于零、分母趋于一，零比一就是零，结果显然是零。

但是，这个结果对吗？**不对。**我们对 $F(s)$ 做一个拉氏逆变换看看。$\dfrac{1}{s^2+1}$ 是 $\dfrac{\omega}{s^2+\omega^2}$ 的形式取 $\omega=1$，而 $\dfrac{\omega}{s^2+\omega^2}$ 对应的拉氏逆变换就是 $\sin\omega t$，所以它的逆变换是 $\sin t$。而 $\sin t$ 的波形我们知道，它一直在震荡，$\lim_{t\to+\infty}\sin t$ 这个极限不存在——终值根本不存在。可我们直接用终值定理，却得到了"终值等于零"这样的结果，显然是一个错误结果。

错误的原因，就是它并不满足我们的前提条件：终值并不存在。看一下它的极点：$s^2+1=0$ 的根，$s=\pm\mathrm{j}$。把它们画在 s 平面上——横轴 $\sigma$ 代表实部的取值，纵轴代表虚部的取值：

```text
                    jω
                     |
             ×  (0, j1)
                     |
    —————————————————+—————————————————→ σ
                     |
             ×  (0, -j1)
                     |
```

$s=\pm\mathrm{j}$ 的实部为零、虚部分别为 $+1$ 和 $-1$，两个极点都落在虚轴上。注意，**左半平面指的是 $\sigma<0$，不包括 $\sigma=0$ 这条中轴**——实部必须严格小于零。这两个极点显然不满足"都在左半平面"的要求，而且它们也不是 $s=0$ 处的一阶极点，那么终值就不存在，我们不能直接用终值定理——这就是产生错误的原因。

当然，做题时如果题目给一个 $F(s)$，你不可能先求一个拉氏逆变换、看它终值存不存在，然后再决定用不用定理——你都求出逆变换了，为什么不直接在逆变换上代入 $t=\infty$ 取极限呢？所以这么做是不好的。通常的做法是：**直接看 $F(s)$ 的极点分布，就能判断能不能使用终值定理。**

#### 假分式在终值定理里反而不用拆

之前讲初值定理的时候说过：如果 $F(s)$ 是假分式，得把它化成真分式加上多项式的形式，然后只对真分式单独用初值定理。终值定理需不需要这样？不需要。你直接对这个 $F(s)$——不管它是真分式还是假分式——乘一个 $s$、取 $s\to 0$ 的极限就行了。

但其实，终值定理如果你也想把它拆成一个真分式加上多项式、然后只对真分式用终值定理，也会得到一样的结果，两种做法都可以。举例说明一下为什么可以。设一个假分式，它总可以写成

$$F(s) = \left(s^k + b_{k-1}s^{k-1} + \cdots + b_1 s + b_0\right) + F_1(s)$$

其中 $F_1(s)$ 是真分式，前面括号里是有理多项式。对等式两端分别乘 $s$、取 $s\to 0$ 的极限：左边多项式那些项乘上 $s$ 之后是 $s^{k+1}, s^k, \ldots, s$，$s$ 趋于零时**这些全部都为零**，于是

$$\lim_{s\to 0} sF(s) = \lim_{s\to 0} sF_1(s)$$

也就是说，多项式部分对终值没有任何贡献。所以对假分式不用非得变成"真分式加多项式"再用终值定理，直接用就行；当然你非要拆了再用，也对，结果是一样的。

最后把这一讲的两个极限定理放在一起对照记：

| 定理 | 结论 | 使用前提 |
| :--- | :--- | :--- |
| 初值定理 | $f(0^+) = \lim\limits_{s\to+\infty} sF(s)$ | $F(s)$ 须为真分式；假分式先拆，多项式部分不参与 |
| 终值定理 | $f(\infty) = \lim\limits_{s\to 0} sF(s)$ | 终值须存在：极点全在左半平面，或原点处仅一阶极点；假分式不必拆 |

这一讲里，初值定理和终值定理的使用条件大家一定要记住。如果出错的话，很有可能就出在这里——初值定理别忘了先拆假分式，终值定理别忘了先看极点。

## 常用拉氏变换对表：一张表吃透
> 对应块：BLK48 | 覆盖分集：P108 | 块标题（分集名）：《4.5常用拉式变换对表》

讲到这里，拉氏变换的性质和一些常用的拉氏变换对就都讲完了。前面常用拉氏变换对讲得比较零散，东一个西一个，所以这里列一个表格来总结一下。至于拉氏变换的性质就不专门总结了——那个我们本来就是一条一条讲的，而且性质表书上都有，大家翻翻教材也可以。

下面带大家把这张常用拉氏变换对表过一遍，顺便回忆每一对是怎么来的。

### 最常用的三对，不用刻意背

$$\delta(t) \leftrightarrow 1, \qquad u(t) \leftrightarrow \frac{1}{s}, \qquad \mathrm{e}^{-t}u(t) \leftrightarrow \frac{1}{s+1}$$

这三对是我们最为常用的三个拉氏变换对。我想不用刻意去记，因为太常用了——做题做到自然就刻在脑子里了。

接下来是延时版本：

$$\delta(t - t_0) \leftrightarrow \mathrm{e}^{-st_0}$$

这个其实就是对 $\delta(t) \leftrightarrow 1$ 利用一次延时（时移）特性就能得到的结果。

### 从性质推出来的几对

其他的拉氏变换对，我们往往也能由常用的变换对出发，结合拉氏变换的性质推导出来。表里这几对就是典型：

**冲激函数的 $n$ 阶导数**：

$$\delta^{(n)}(t) \leftrightarrow s^n$$

这用的是原函数微分性质——每求一次导，s 域就乘一次 $s$，推出来就是 $s^n$。

**$t^n u(t)$**：

$$t^n u(t) \leftrightarrow \frac{n!}{s^{n+1}}$$

这一对也挺重要，但就不太好记了，所以这个大家要专门去记一下。记不住通式也没关系，代入 $n = 1, 2, 3$ 就能得到具体结果：

| 时域信号 | $s$ 域像函数 |
| :--- | :--- |
| $t\,u(t)$ | $\dfrac{1}{s^2}$ |
| $t^2 u(t)$ | $\dfrac{2}{s^3}$ |
| $t^3 u(t)$ | $\dfrac{6}{s^4}$ |

> **提示**：表里我们写的时候后面都带了 $u(t)$，但其实如果求的是单边拉氏变换，这个 $u(t)$ 不加也可以——$t^n$ 做单边拉氏变换和 $t^n u(t)$ 做单边拉氏变换，结果是一样的。所以有时候 $u(t)$ 可以省略。

### 正弦余弦：好记，但千万别记混

$$\sin(\omega_0 t)\,u(t) \leftrightarrow \frac{\omega_0}{s^2 + \omega_0^2}, \qquad \cos(\omega_0 t)\,u(t) \leftrightarrow \frac{s}{s^2 + \omega_0^2}$$

这两对其实还挺好记的，但你不要记混了：分母都是 $s^2 + \omega_0^2$，区别在分子——正弦的分子是 $\omega_0$，余弦因为本质是偶函数、带直流成分，分子是 $s$。这里不要记混了。

再往下是乘了 $t$ 的两个：

$$t\sin(\omega_0 t)\,u(t) \leftrightarrow \frac{2\omega_0 s}{(s^2 + \omega_0^2)^2}, \qquad t\cos(\omega_0 t)\,u(t) \leftrightarrow \frac{s^2 - \omega_0^2}{(s^2 + \omega_0^2)^2}$$

这两个表达式里又是二又是平方的，出现频率相对就比较小了，但还是希望大家最好记一下；如果平时记不住，考试前记一记也可以。关键是——万一考场上你突然忘了，你要会推这两个表达式。怎么推？利用 s 域微分性质：时域上乘一个 $t$，就相当于对原来的像函数 $F(s)$ 求一次导，再添一个负号：

$$t\,f(t) \leftrightarrow -\frac{\mathrm{d}F(s)}{\mathrm{d}s}$$

拿 $\sin(\omega_0 t)u(t) \leftrightarrow \dfrac{\omega_0}{s^2+\omega_0^2}$ 求导加负号一算，$t\sin(\omega_0 t)$ 的结果就出来了；余弦同理。不过话虽如此，还是推荐大家直接记住。

### 冲激串与有始周期信号

接下来是冲激串：

$$\sum_{n=0}^{\infty} \delta(t - nT) \leftrightarrow \frac{1}{1 - \mathrm{e}^{-sT}}$$

注意这里的 $n$ 是从零开始的，因为我们是单边拉氏变换。

> **结论**：一旦知道冲激串的拉氏变换，对于任意的有始周期信号，我们都有统一套路——任何一个有始周期信号，都可以看成它的第一个周期部分与这个冲激串做卷积。

这时再用拉氏变换的卷积定理：时域卷积对应 s 域乘积。分别求出第一周期部分的拉氏变换 $F_1(s)$ 和冲激串的拉氏变换，一相乘，就能得到这个有始周期信号的拉氏变换：

$$F(s) = \frac{F_1(s)}{1 - \mathrm{e}^{-sT}}$$

这是处理有始周期信号求拉氏变换最省力的路子。

### 表加性质，一招通吃

还有一条规律值得点破：如果 $f(t)$ 乘上一个 $\mathrm{e}^{-at}$，那就是把像函数里的 $s$ 换成 $s + a$ 即可——这就是 s 域平移特性。

所以说，这些常用的拉氏变换对，还要结合拉氏变换的性质一起用，这样我们就能得到非常多的拉氏变换。碰到一个你不熟悉的拉氏变换，就可以想一想：用哪个性质，能把我们熟悉的那个拉氏变换变成它？

把这张变换对表和那些性质都结合起来，其实我们就能解决大部分拉氏变换的问题了。

## 拉普拉斯逆变换怎么求：部分分式展开法
> 对应块：BLK49 | 覆盖分集：P109 | 块标题（分集名）：《4.6拉普拉斯逆变换（1）》

### 从正变换里"顺"出来的逆变换

到目前为止，我们并没有专门拿出来讲过什么"傅里叶逆变换"，对吧？但它其实你早就会了。正着看，Sa 函数的傅里叶变换是一个门函数；那反过来看呢？它不就是傅里叶逆变换了嘛——门函数的傅里叶逆变换就是一个 Sa 函数。拉普拉斯变换也是同理。$e^{-at}u(t)$ 的拉氏变换是 $\frac{1}{s+a}$，那要问 $\frac{1}{s+a}$ 的拉氏逆变换是什么，把这对变换对倒过来读不就得出答案了。所以在讲正变换的过程中，我们已经间接地把逆变换讲了大半。

定义式也摆出来看一看。傅里叶逆变换的定义并不复杂：

$$f(t)=\frac{1}{2\pi}\int_{-\infty}^{+\infty}F(j\omega)e^{j\omega t}\,d\omega$$

遇到形式比较简单的 $F(j\omega)$，直接用定义算它的傅里叶逆变换是可以的。但拉普拉斯逆变换的定义式就非常复杂了：

$$f(t)=\frac{1}{2\pi j}\int_{\sigma-j\infty}^{\sigma+j\infty}F(s)e^{st}\,ds$$

积分路径是复平面上从 $\sigma-j\infty$ 到 $\sigma+j\infty$ 的一条竖线。它不是不能用来求——是能求的，只不过太复杂，我们肯定有更简单的方式。接下来就介绍这种更简单的方式。

### 老变换对配上性质一起用

有时候题目给我们的 $F(s)$，并不是常用拉氏变换表里的形式，但只要结合一下拉氏变换的性质，就能求出它的拉氏逆变换。比如

$$F(s)=\frac{1}{s+2}\,e^{-2s}$$

$\frac{1}{s+2}$ 我们当然会：它的逆变换就是 $e^{-2t}u(t)$。前面多乘的那个 $e^{-2s}$ 怎么办？回忆时移性质：若 $f(t)$ 的拉氏变换是 $F(s)$，则

$$f(t-t_0)u(t-t_0)\leftrightarrow F(s)\,e^{-st_0}$$

这里乘的 $e^{-2s}$，相当于 $t_0=2$。所以只需要把 $e^{-2t}u(t)$ 里的 $t$ 换成 $t-2$：

$$f(t)=e^{-2(t-2)}u(t-2)=e^{-2t+4}u(t-2)$$

所以常用变换对要和拉氏变换的性质放在一起使用。正变换是如此，逆变换当然也是如此。

### 有理分式：先把假分式收拾干净

我们所见到的 $F(s)$，绝大多数都是有理分式的形式。所以一旦学会了有理分式的拉氏逆变换，拉氏逆变换的问题也就基本解决了。有理分式之前已经介绍过一次，它的基本形式是：分子分母都是关于 $s$ 的多项式，俩一除：

$$F(s)=\frac{b_ms^m+b_{m-1}s^{m-1}+\cdots+b_1s+b_0}{s^n+a_{n-1}s^{n-1}+\cdots+a_1s+a_0}$$

各系数均为实数——这个条件后面有大用，先记着。之前也说过：$m\ge n$ 时它是假分式，$m<n$ 时是真分式。做拉氏逆变换时遇到假分式，老规矩，用长除法把它拆成一个多项式加上一个真分式。比如之前讲长除法时算过的那个例子（分子最高四次、分母最高三次，肯定是假分式）：

$$F(s)=s+2+\frac{2s^2+3s+6}{s^3+6s^2+11s+6}$$

注意，做拉氏逆变换时这个多项式部分可不能扔，我们还得要！以前为了别的目的只留真分式那部分，现在全都要。多项式部分的逆变换我们其实早就会了：$\delta(t)$ 的 $n$ 阶导数的拉氏变换是 $s^n$，所以常数对应 $\delta(t)$，$s$ 对应 $\delta'(t)$，$s^2$ 对应 $\delta''(t)$……比如这里的 $s+2$，逆变换就是 $\delta'(t)+2\delta(t)$。

于是问题只剩下：真分式部分的拉氏逆变换怎么求？这就用到我们的绝招——部分分式展开法。真分式还要分几种情况讨论，依据就是分母多项式的根：可能是实根，可能是复根，还可能有重根。根的情况不同，部分分式展开的处理方法也有所不同。

```text
F(s)
 │
 ├─ 假分式 (m ≥ n) ──长除法──▶ 多项式 + 真分式
 │                              多项式 → δ(t) 及其各阶导数
 │
 └─ 真分式 (m < n)
       └─ 按分母多项式的根分类
            ├─ 实根且无重根 → 部分分式展开，逐项查表
            ├─ 共轭复根     → 代公式法 / 凑三角法
            └─ 重根         → 处理方法后面再讲
```

这张图就是本讲的整体作战地图：先把假分式打回真分式，再按根的类型挑兵器。

### 单实根：一条公式加一根大拇指

第一种情况：极点（也就是分母多项式的根）全为实数、无重根。设 $F(s)=\frac{A(s)}{(s-p_1)(s-p_2)(s-p_3)}$，其中 $p_1,p_2,p_3$ 互不相等，分子 $A(s)$ 的最高次数低于分母（保证是真分式，是常数、一次、两次都行）。初中学过，这样的分式可以拆成

$$F(s)=\frac{K_1}{s-p_1}+\frac{K_2}{s-p_2}+\frac{K_3}{s-p_3}$$

$K_1,K_2,K_3$ 都是常数。怎么定它们？初中的办法叫待定系数法——这里我就不带大家回忆了，因为这个我们不用，它太慢了，我们有一个更好的方法。

以求 $K_1$ 为例：等式两端同时乘上 $(s-p_1)$，左边剩 $K_1$，右边另外两项的分母里还留着别处的因子。然后代入 $s=p_1$：那两项的分子都变成了零（$p_1,p_2,p_3$ 互不相等，分母不为零，代人合法），于是

$$K_1=\left.F(s)(s-p_1)\right|_{s=p_1}$$

同理，$K_2$ 就是乘上 $(s-p_2)$ 再代 $s=p_2$，$K_3$ 就是乘上 $(s-p_3)$ 再代 $s=p_3$。公式非常简单，实际算起来更快。顺带一提，这个方法不只信号与系统里有用：你在高数里做题时，有时也想把这样的分式拆开，用待定系数法就有些太慢，同样可以用这里的办法去拆——这算信号与系统在高数里的一次反哺。

举一个具体的例子：

$$F(s)=\frac{10(s+2)(s+5)}{s(s+1)(s+3)}$$

分母的根分别是 $0,-1,-3$，显然都是实根而且没有重复的，正好满足上面的形式。有时题目给的分子分母不是这种因式连乘的形式，而是展开后的多项式，那就求一下根、把它化回来——简单的比如 $s^2+3s+2$，一眼就该看出是 $(s+1)(s+2)$，不必非得走"求根公式"那道工序。

具体求系数的时候，也没必要照着公式死板地写一遍再代入。比如求 $s=0$ 处的系数，就是 $F(s)$ 乘上一个 $s$——相当于把分母里那个 $s$ 消掉——再代入 $s=0$：你可以直接拿大拇指把分母里的 $s$ 盖住，然后代入：分子 $10\times2\times5=100$，分母 $1\times3=3$，所以

$$K_1=\frac{100}{3}$$

求 $s=-1$ 处的 $K_2$，就把 $s+1$ 用大拇指盖住、代入 $s=-1$：分子 $10\times1\times4=40$，分母 $(-1)\times2=-2$，所以 $K_2=-20$。对口算不够自信就写两笔：求 $K_3$ 时把 $s+3$ 那项抹掉、代 $s=-3$，分子 $10\times(-1)\times2=-20$，分母 $(-3)\times(-2)=6$，所以 $K_3=-\frac{10}{3}$。你看，求这三个系数非常快，非常套路化。

剩下最后一步：逐项做拉氏逆变换。$\frac{1}{s}$ 的逆变换是 $u(t)$，$\frac{1}{s+1}$ 是 $e^{-t}u(t)$，$\frac{1}{s+3}$ 是 $e^{-3t}u(t)$，各自带上前面的系数：

$$f(t)=\frac{100}{3}u(t)-20e^{-t}u(t)-\frac{10}{3}e^{-3t}u(t)$$

有的教材不写 $u(t)$，写成 $\frac{100}{3}-20e^{-t}-\frac{10}{3}e^{-3t}\ (t\ge0)$，也可以，具体按照你手头教材的口径来就行。

### 复根为什么总是成对出现

接下来第二种情况：根里有复数。注意，有理分式各项前面的系数都是实数，这一点决定了它如果有复根，一定是一对共轭复根一起出现。为什么？假如有一对共轭复根 $-\alpha\pm j\beta$，对应的两个因子是

$$(s+\alpha-j\beta)(s+\alpha+j\beta)$$

这不就是平方差公式嘛——$a-b$ 乘 $a+b$ 等于 $a^2-b^2$：

$$(s+\alpha)^2-(j\beta)^2=(s+\alpha)^2+\beta^2$$

因为 $j^2=-1$。展开是 $s^2+2\alpha s+\alpha^2+\beta^2$，各项系数全是实数，一点 $j$ 的影子都没有。反过来，如果某个复根的共轭伙伴不在根里，把它乘回去就一定会冒出复数系数——和"系数全为实数"矛盾。所以遇到复根，放心，它们必然共轭成对。

这种情况下，$F(s)$ 的分母由两部分拼成：一部分 $D(s)$ 的根全为实数（注意，可没说它没有其他极点了——它的根若都是单根，处理方法前面已经讲过；若是重根，处理方法后面马上就讲），另一部分就是共轭复根贡献的 $(s+\alpha-j\beta)(s+\alpha+j\beta)$，分子最高次数仍低于分母。这里写成 $s+\alpha$ 而不是 $s-\alpha$ 是有讲究的：$\alpha$ 一般大于零，这样得到的逆变换里是 $e^{-\alpha t}$，单调递减——我们希望得到单调递减的结果，因为这样才稳定。

最直接的想法是照搬上一节的套路，把每个因子都当单根拆。比如分母是 $(s+2)(s+3)(s+2-j3)(s+2+j3)$，就拆成 $\frac{K_1}{s+2}+\frac{K_2}{s+3}+\frac{K_3}{s+2-j3}+\frac{K_4}{s+2+j3}$。$K_1,K_2$ 还是老办法：盖住对应因子，代 $s=-2$、$s=-3$。代入时剩下的共轭因子恰好互为共轭，相乘用平方差公式，所以算起来还好。但 $K_3,K_4$ 就惨了：得把 $s=-2+j3$ 这样的复数代进每一个因式里做复数运算，每个 $s$ 都要代复数，计算量一下子大很多。能做，当然最后也能求出来，但没必要受这个罪。所以我们有必要去找更简便的方法——而且刚才做题的过程中其实已经埋了一个伏笔：那两个复指数项，还可以用欧拉公式合并。

### 代公式法：只求一个系数

先给出一个结论：

> **结论**：因为 $F(s)$ 是实系数多项式之比，所以其共轭复根前面的展开系数也是一对共轭复数——知道其中一个，另一个就是它的共轭，白送。

这个结论能大大方便分析：我们只需要求两个系数中的一个。设 $\frac{1}{s+\alpha-j\beta}$ 这一项的系数是 $K_1=a+jb$，那么 $\frac{1}{s+\alpha+j\beta}$ 那项的系数就是 $K_2=a-jb$。现在对这两项做拉氏逆变换：

$$(a+jb)\,e^{-(\alpha-j\beta)t}+(a-jb)\,e^{-(\alpha+j\beta)t}$$

把公共的 $e^{-\alpha t}$ 提出来，里面剩下一正一负两个指数：

$$e^{-\alpha t}\left[(a+jb)e^{j\beta t}+(a-jb)e^{-j\beta t}\right]$$

一正一负，有没有让你想到什么？凑三角！三角的形式是我们更喜欢、更常见到的：$\frac{1}{2}(e^{j\beta t}+e^{-j\beta t})=\cos\beta t$，$\frac{1}{2j}(e^{j\beta t}-e^{-j\beta t})=\sin\beta t$。把系数配平（括号里拿一个 $\frac{1}{2}$、外面就得补一个 $2$；带 $j$ 的那组把 $j$ 挪去分母要多出一个负号），整理得

$$2e^{-\alpha t}\left(a\cos\beta t-b\sin\beta t\right)$$

于是共轭复根这部分的整体逆变换就是

$$f_2(t)=2e^{-\alpha t}\left(a\cos\beta t-b\sin\beta t\right)u(t)$$

看看这个公式里有哪些参数：$\beta$、$\alpha$、$a$、$b$，四个。$\alpha$ 和 $\beta$ 不用求——它们明明白白写在 $F(s)$ 的分母因子 $s+\alpha\mp j\beta$ 里。$a$ 和 $b$ 才是要求的东西：它们就是 $\frac{1}{s+\alpha-j\beta}$ 这一项系数 $K_1=a+jb$ 的实部和虚部，用老办法求：

$$a+jb=K_1=\left.F(s)(s+\alpha-j\beta)\right|_{s=-\alpha+j\beta}$$

> **易错点**：$K_1$ 必须取 $s+\alpha-j\beta$ 这一项前面的系数，不要弄成它共轭伙伴那项的；代入的复数是 $s=-\alpha+j\beta$，符号别反。

$a$ 和 $b$ 一旦知道，$\alpha,\beta$ 一代，直接套公式就出结果——既不用求第二个系数，也不用再做拉氏变换。这无疑比"求一对共轭系数、各做一次逆变换"快多了。但是说实话，这种方法依然不是我最为推荐的方法：首先公式得背，其次 $a+jb$ 本身还是个复数运算，计算量也不小。先拿例题走一遍，另一种方法马上讲。

#### 例题走一遍代公式法

求

$$F(s)=\frac{s^2+3}{(s+2)\left[(s+1)^2+4\right]}$$

的逆变换。先看分母的根是什么形式：$s+2$ 是一个单实根；另一个二次因式用求根公式可以求根——顺带提一句，如果考场上允许带计算器，求根这种活直接交给计算器，算出来就知道根是什么形式了；不让带计算器就手算。其实这里不求大家也应该看得出来：$(s+1)^2+4=(s+1)^2+2^2$，正是 $(s+\alpha)^2+\beta^2$ 的模样，由平方差得来，观察力足够敏锐的话能直接看出根是 $-1\pm j2$，一对共轭复根。于是拆成三项：

$$F(s)=\frac{K_0}{s+2}+\frac{K_1}{s+1-j2}+\frac{K_2}{s+1+j2}$$

$K_2$ 不用求（它是 $K_1$ 的共轭），只要求出 $K_0$ 和 $K_1$，代入公式结果就出来了。注意 $K_1$ 一定是 $s+\alpha-j\beta$ 这一项前面的系数，别弄混。

$K_0$：不看 $s+2$ 这项，代 $s=-2$。分子 $4+3=7$；剩下的因子 $(-2+1-j2)(-2+1+j2)$ 按平方差就是 $(-1)^2+2^2=5$，所以 $K_0=\frac{7}{5}$。

$K_1$：这个计算量就稍微有点大了，得慢慢算。不看 $s+1-j2$ 这项，代 $s=-1+j2$：

$$K_1=\left.\frac{s^2+3}{(s+2)(s+1+j2)}\right|_{s=-1+j2}$$

分子：$(-1+j2)^2+3=1-j4-4+3=-j4$。分母：$s+2=1+j2$，$s+1+j2=j4$，相乘得 $j4+j^2 8=-8+j4$。分母里还有复数，分子分母同乘它的共轭 $(8+j4)$：分母按平方差思路化成实数，$(-8+j4)(8+j4)=-64-16=-80$；分子 $(-j4)(8+j4)=16-j32$。所以

$$K_1=\frac{16-j32}{-80}=-\frac15+j\frac25$$

即 $a=-\frac15$，$b=\frac25$。套公式，$\alpha=1$，$\beta=2$：

$$2e^{-t}\left(-\frac15\cos2t-\frac25\sin2t\right)u(t)$$

别忘了前面还有一部分：$\frac{7/5}{s+2}$ 的逆变换是 $\frac{7}{5}e^{-2t}u(t)$。合起来：

$$f(t)=\frac{7}{5}e^{-2t}u(t)-\frac{2}{5}e^{-t}\cos2t\,u(t)-\frac{4}{5}e^{-t}\sin2t\,u(t)$$

可以看到，虽然用了公式，计算量还是不小，主要就刷在求 $K_1$ 上——只要沾了复数，乘除就麻烦。而且公式要记住，代入时那个"系数取哪一项"的易错点也得盯紧。

### 凑三角法：不背公式也能做

现在讲另一种方法。先看两条老朋友的变换对：

$$\sin\omega t\,u(t)\leftrightarrow\frac{\omega}{s^2+\omega^2}\qquad \cos\omega t\,u(t)\leftrightarrow\frac{s}{s^2+\omega^2}$$

如果 $F(s)$ 的分母只有一对共轭复根，形如 $(s+\alpha)^2+\beta^2$，有没有办法把这两条用起来？把式中的 $s$ 换成 $s+\alpha$ 就是了——复频域平移，时域上乘一个 $e^{-\alpha t}$：

$$e^{-\alpha t}\sin\beta t\,u(t)\leftrightarrow\frac{\beta}{(s+\alpha)^2+\beta^2}\qquad e^{-\alpha t}\cos\beta t\,u(t)\leftrightarrow\frac{s+\alpha}{(s+\alpha)^2+\beta^2}$$

这个形式和我们要处理的 $F(s)$ 是不是很像？只要能把 $F(s)$ 分解为这两个形式的和，根据变换对直接就能写出逆变换。带着这个思路来做。一般地，设

$$F(s)=\frac{s+\gamma}{(s+\alpha)^2+\beta^2}$$

先凑 cos 还是先凑 sin？分子的理想形状是 $s+\alpha$（对准 cos 模板），那就硬凑：$s+\gamma=(s+\alpha)+(\gamma-\alpha)$，拆成两项：

$$F(s)=\frac{s+\alpha}{(s+\alpha)^2+\beta^2}+\frac{\gamma-\alpha}{(s+\alpha)^2+\beta^2}$$

第一项直接对应 $e^{-\alpha t}\cos\beta t\,u(t)$。第二项分子是个常数，而 sin 模板的分子是 $\beta$——注意分母上是 $\beta^2$，模板里的"那个数"就是 $\beta$，所以要把分子凑成 $\beta$ 的倍数，不是凑成 $1$。常数变常数非常简单，乘一个 $\beta$ 再除一个 $\beta$：

$$\frac{\gamma-\alpha}{\beta}\cdot\frac{\beta}{(s+\alpha)^2+\beta^2}\;\longrightarrow\;\frac{\gamma-\alpha}{\beta}\,e^{-\alpha t}\sin\beta t\,u(t)$$

这样凑成了 cos 加 sin 的形式，做一次逆变换就得到最后结果：

$$f(t)=e^{-\alpha t}\cos\beta t\,u(t)+\frac{\gamma-\alpha}{\beta}\,e^{-\alpha t}\sin\beta t\,u(t)$$

还有一个细节要注意：如果分子里 $s$ 前面的系数不是 1 呢？比如 $F(s)=\frac{2s+\gamma'}{(s+\alpha)^2+\beta^2}$，那应该凑 $2\alpha$——把 2 提出去，凑成 $2(s+\alpha)$ 加一个常数，保证分子不变就行；系数是 $\frac12$ 就凑 $\frac{\alpha}{2}$，把 $\frac12$ 提出去。凑谁，由 $s$ 前面的系数决定。

举一个数字的例子：

$$F(s)=\frac{s}{s^2+2s+3}$$

第一步，用配方法把分母凑成 $(s+\alpha)^2+\beta^2$ 的形状——只要根是共轭复根，就一定能凑成这种形式；凑不成的话，说明它就不是共轭复根。$s^2+2\alpha s+\alpha^2$ 对照 $s^2+2s$，$2\alpha=2$ 给 $\alpha=1$，所以补一个 $1$ 再补一个 $2$：

$$s^2+2s+3=(s+1)^2+2,\qquad \beta=\sqrt2$$

第二步凑三角。凑 cos，就是凑一个 $s+1$：

$$\frac{s}{(s+1)^2+2}=\frac{s+1}{(s+1)^2+2}-\frac{1}{(s+1)^2+2}$$

第一项显然就是 cos。第二项还得再凑一刀：模板分子是 $\beta=\sqrt2$，现在是 $1$，所以乘 $\sqrt2$ 再除 $\sqrt2$：

$$\frac{1}{(s+1)^2+2}=\frac{1}{\sqrt2}\cdot\frac{\sqrt2}{(s+1)^2+2}$$

两项各自对号入座，逆变换直接写出：

$$f(t)=e^{-t}\cos\sqrt2\,t\,u(t)-\frac{1}{\sqrt2}\,e^{-t}\sin\sqrt2\,t\,u(t)$$

一气呵成，不用记任何公式，所以这个方法相当实用。

### 单实根和复根混在一起怎么办

刚才做的例子，分母只有共轭复根这一种成分。要是分母里还混着单实根呢？比如

$$F(s)=\frac{s^2+3}{(s+2)(s^2+2s+5)}$$

这正是前面代公式法那道例题，现在换一种方法重新做它。这时显然就不能直接上凑三角了——得先把 $F(s)$ 处理掉才能用。基本思路：把 $F(s)$ 化成一个 $\frac{\text{常数}}{s+2}$ 加上一个 $\frac{K_2s+K_3}{s^2+2s+5}$ 的和；前一部分的逆变换很轻松，后一部分再用凑三角。当务之急的问题就是：如何把 $F(s)$ 变成它们俩的合并。这里就不得不对我们之前嫌弃过的待定系数法道个歉了——这里还真得用它。

#### 待定系数法

回忆一下用法：第二块的分母是二次，分子就要设到比分母最高次低一次，即 $K_2s+K_3$；分母若是三次，就设 $K_2s^2+K_3s+K_4$；分母是一次的话，上面设一个常数就可以。按这个规律设好分子，通分相加：

$$\frac{K_1(s^2+2s+5)+(s+2)(K_2s+K_3)}{(s+2)(s^2+2s+5)}=\frac{s^2+3}{(s+2)(s^2+2s+5)}$$

分母已经一样，不用管，只要让分子相加等于 $s^2+3$。把括号打开，按 $s$ 的幂次归队：

$$K_1s^2+2K_1s+5K_1+K_2s^2+K_3s+2K_2s+2K_3=s^2+0\cdot s+3$$

熟悉的话其实不必展开，直接盯着没展开的式子看：哪些项贡献 $s^2$、哪些贡献 $s$、哪些贡献常数，加在一起对照就行。右边 $s^2$ 的系数是 $1$，$s$ 的系数是 $0$（没写就是 $0$），常数是 $3$，于是

$$\begin{cases}K_1+K_2=1\\[2pt] 2K_1+2K_2+K_3=0\\[2pt] 5K_1+2K_3=3\end{cases}$$

这个方程组解起来其实还得算一会儿。但大家想一想：三个系数里哪个不好求？主要就是 $K_2,K_3$ 不好求，$K_1$ 是不是很好求？老办法伺候：$F(s)$ 乘上 $s+2$、代 $s=-2$——分子 $4+3=7$，分母 $(-2+1)^2+2^2=5$，$K_1=\frac{7}{5}$（这道题我们前面刚做过）。有了 $K_1$，剩下两个一下就出来了：由第一式 $K_2=1-\frac75=-\frac25$；由第三式 $5\times\frac75+2K_3=3$，得 $K_3=-2$。

第一块：$\frac{7/5}{s+2}\to\frac{7}{5}e^{-2t}u(t)$，直接抄答案。

第二块：$\frac{-\frac25s-2}{(s+1)^2+4}$。分母已经是 $(s+1)^2+2^2$ 的形式（这个配方我们前面刚做过一遍），开始凑三角。先凑 cos，注意分子带着 $-\frac25$ 这个系数，所以凑 $-\frac25(s+1)$，让 $-\frac25$ 能提出去；凑了不能白凑，减掉多少要补回多少：

$$-\frac25s-2=-\frac25(s+1)-\frac85$$

于是第二块拆成两项：

$$\frac{-\frac25(s+1)}{(s+1)^2+4}-\frac{\frac85}{(s+1)^2+4}=-\frac25\cdot\frac{s+1}{(s+1)^2+4}-\frac45\cdot\frac{2}{(s+1)^2+4}$$

前者对应 $-\frac25e^{-t}\cos2t\,u(t)$（系数 $-\frac25$、衰减 $e^{-t}$、频率 $2$），后者的分子已经凑成 $\beta=2$ 的倍数，对应 $-\frac45e^{-t}\sin2t\,u(t)$。合起来：

$$f(t)=\frac{7}{5}e^{-2t}u(t)-\frac{2}{5}e^{-t}\cos2t\,u(t)-\frac{4}{5}e^{-t}\sin2t\,u(t)$$

最后这个结果可以验证一下——和前面用代公式法做出的结果完全一样。

#### 相减法：$K_2,K_3$ 的另一种求法

如果 $K_1$ 率先求出来了，$K_2,K_3$ 也可以不用待定系数法。思路很直观：$F(s)$ 你知道，$\frac{K_1}{s+2}$ 你也知道，那它俩一减，不就得到了第二块吗？来试一下：

$$\frac{s^2+3}{(s+2)(s^2+2s+5)}-\frac{7/5}{s+2}=\frac{s^2+3-\frac75(s^2+2s+5)}{(s+2)(s^2+2s+5)}$$

为了相减，两项先通成同样的分母。分子整理：$s^2-\frac75s^2=-\frac25s^2$，$s$ 项是 $-\frac{14}{5}s$，常数 $3-7=-4$，即

$$-\frac25s^2-\frac{14}{5}s-4=-\frac25\,(s^2+7s+10)$$

我们想要的是分母为 $s^2+2s+5$ 的形式，所以分子里的 $(s+2)$ 必须能约掉。有时得到的形式比较简单，你直接能看出来分子分母能约；不太好看的话，先提一个常数：提出 $-\frac25$ 后剩 $s^2+7s+10$，数学感比较好的同学一眼能看出它是 $(s+2)(s+5)$——$2\times5=10$，$2+5=7$ 嘛；看不出来的话，用求根公式分解一下也行。约掉 $(s+2)$：

$$\frac{-\frac25(s+5)}{s^2+2s+5}=\frac{-\frac25s-2}{s^2+2s+5}$$

和待定系数法那里得到的形式完全一样，之后的步骤自然也完全一样。

求共轭复根这块的系数，$K_2,K_3$ 用这两种方法都可以：相减法更好想、更直观；待定系数法计算量会稍微小一些，但也差不太多。看你个人喜好，想要哪种就哪种。

### 两种方法怎么挑

到现在，带共轭复根的 $F(s)$ 我们手里有了两套武器：先讲的代公式法，和后来的凑三角法。怎么选？

如果分母只有共轭复根，形如 $\frac{\cdots}{(s+\alpha)^2+\beta^2}$，凑三角法显然更快，直接用就好。但如果分母里还混着 $s+2$ 这样的实根因子，凑三角法得先把 $F(s)$ 拆成两项——一块实根的、一块复根的——这个拆的过程（不管用待定系数还是相减）还是稍微有些麻烦，此时它相对代公式法就不再有那么大的优势了。而代公式法呢，毕竟还要去记公式，求 $K_1$ 时也免不了复数运算，计算量其实同样不小。

| | 代公式法 | 凑三角法 |
| :--- | :--- | :--- |
| 需要背的东西 | 一条结果公式 | 两条常用变换对 |
| 复数运算 | 求 $K_1=a+jb$ 时躲不掉 | 全程实数 |
| 分母只有共轭复根 | 可用，略绕 | 明显更快 |
| 分母混有实根因子 | 省去二次拆分，优势不明显 | 要先拆两项，优势缩小 |

所以这两种方法都可以，看个人喜好。我个人还是推荐凑三角法：不用记公式，做起来的感觉也特别顺、特别顺滑。
