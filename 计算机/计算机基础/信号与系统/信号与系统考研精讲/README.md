# 信号与系统考研精讲（155 讲）

一门面向考研的《信号与系统》全程课：以「信号的表示与奇异信号 → 卷积与 LTI 系统时域分析 → 傅里叶级数与傅里叶变换 → 抽样与调制 → 拉普拉斯变换与系统函数 H(s) → z 变换与离散系统 H(z) → 状态变量分析」为主线，把考研大纲里的四大变换体系与系统函数、零极点、频响特性串成一条完整的解题路线。每章都以例题收尾，公式推导与解题套路并重，适合从零基础到强化冲刺全程使用。

- **原视频**：[信号与系统考研课程](https://www.bilibili.com/video/BV17r4y1e74i) — Bilibili，BV17r4y1e74i
- **全 155 集**，已产出 8 册模块全书、18 篇复习笔记、72 份逐字稿

## 怎么学

- **先抓卷积这一条主线** → 卷积是时域分析的核心，笔记 05 把定义、图解法、运算律、与奇异信号卷积、微积分特性等 9 个块合编成一篇，适合集中攻克
- **四大变换对照着学** → 傅里叶变换（笔记 09-11）、拉普拉斯变换（笔记 13-15）、z 变换（笔记 16-17）的性质体系高度平行，学完一个回头比对另一个，收敛域与性质条件是易错点
- **零极点是后半场的钥匙** → 笔记 15 与 17 分别从 H(s) 与 H(z) 讲零极点与时域波形、收敛域、频响特性的关系，矢量作图法要动手画
- **考前按主题速查** → 18 篇笔记按知识体系归并（而非按讲次），每篇开头的知识拓扑树可导入 Markmap 或 XMind 生成脑图
- **逐字稿核对原话** → 例题推导卡住时，去 `subtitles/` 按块定位讲师的原讲解
