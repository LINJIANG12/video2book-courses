# 傅里叶级数与信号频谱

## 狄利克雷条件

   * **狄利克雷条件（Dirichlet condition）**

       * > **定义**：周期信号 $f(t)$ 能进行傅里叶展开的一组**充分条件**——满足了一定可以展开；不满足也不一定不能展开。

       * 三条内容：在一周期内，间断点的数目有限；在一周期内，极大值和极小值的数目有限；在一周期内信号绝对可积，即 $\int_{t_1}^{t_1+T}|f(t)|\,dt < \infty$（$T$ 为周期）。

       * 课程中遇到的周期信号通常都满足狄利克雷条件；若某信号不满足，题目会明确指出，可放心直接求傅里叶级数。

       * > **提示**：三条内容本身不必背，但条件的名称必须知道；不同教材的表述有差异，意思一致，按自己的教材为准。

## 正交与完备正交函数集

### 函数的正交

   * **正交（orthogonal）**

       * > **定义**：定义在区间 $(t_1, t_2)$ 上的两个函数 $f_1(t)$、$f_2(t)$，若 $\int_{t_1}^{t_2} f_1(t)f_2(t)\,dt = 0$，则称二者在该区间上正交。

       * 正交是平面"垂直"概念的延伸：平面上任意矢量都能按三角形法则分解为 $x$、$y$ 两个相互正交方向的分量之和，且再也找不到与两者都垂直的第三个方向。

       * 直观例子：一个前半段取 $+1$、后半段取 $-1$ 的信号与恒为 $1$ 的信号相乘后积分，正负面积刚好抵消为零，二者正交。

### 完备正交函数集的定义

   * **完备正交函数集（complete orthogonal function set）**

       * > **定义**：$n$ 个函数 $f_1(t),\cdots,f_n(t)$ 构成的函数集满足两个条件——$i \neq j$ 时 $\int_{t_1}^{t_2} f_i(t)f_j(t)\,dt=0$（两两正交）；$i = j$ 时 $\int_{t_1}^{t_2} f_i^2(t)\,dt = k_i \neq 0$（自身平方积分为非零常数）——且除此之外不存在其他函数 $g(t)$ 与每一个 $f_i(t)$ 都正交。

       * $i = j$ 条件的作用是排除零信号：恒为零的函数平方积分为零、与任何函数乘积积分也为零，没有意义，故完备正交函数集把零排除在外。

       * "完备"回答了"为什么信号能分解为三角和指数的和"：信号空间里存在这样一组两两正交、又找不到"漏网之鱼"的基函数，任何满足条件的信号才能像矢量分解一样展开为它们的组合。

### 三角函数集的正交性

   * **三角函数集**

       * 成员为 $\left\{1,\ \cos\omega_1 t,\ \cos 2\omega_1 t,\ \cdots,\ \sin\omega_1 t,\ \sin 2\omega_1 t,\ \cdots\right\}$，$\cos$ 族与 $\sin$ 族都是**无穷多项**。

       * 开头的 $1$ 就是 $\cos 0\cdot\omega_1 t$；集合中没有 $\sin 0$ 项，因为 $\sin 0$ 恒为零，是零信号。

       * 积分区间取 $t_0 \sim t_0+T_1$（$T_1 = \dfrac{2\pi}{\omega_1}$ 为基波周期）：$T_1$ 是集合中每一个成员的周期；两个周期信号乘积的周期是二者周期的最小公倍数，必含 $T_1$；$t_0$ 任意取不影响结果。

       * 任选两个成员相乘在 $T_1$ 上积分，全部满足正交性；完备性不做证明，知道它是完备的即可。

| 被积函数 | 条件 | 一周期积分值 |
| :--- | :--- | :--- |
| $\cos m\omega_1 t\cos n\omega_1 t$ | $m \neq n$ | $0$ |
| $\cos m\omega_1 t\cos n\omega_1 t$ | $m = n \neq 0$ | $\dfrac{T_1}{2}$ |
| $\cos m\omega_1 t\cos n\omega_1 t$ | $m = n = 0$ | $T_1$ |
| $\sin m\omega_1 t\sin n\omega_1 t$ | $m \neq n$ | $0$ |
| $\sin m\omega_1 t\sin n\omega_1 t$ | $m = n \neq 0$ | $\dfrac{T_1}{2}$ |
| $\sin m\omega_1 t\cos n\omega_1 t$ | 任意 $m, n$ | $0$ |
| $\cos n\omega_1 t$ 或 $\sin n\omega_1 t$ 单独积分（$n$ 为非零整数） | —— | $0$ |

       * 处理工具是**积化和差**；只有 $m = n$ 时出现 $\cos 0 = 1$ 变成常数积分，积出 $\dfrac{T_1}{2}$（$m=n=0$ 时积出 $T_1$），其余项都是正余弦的整周期积分，正负面积抵消为零。

       * $\sin$ 乘 $\cos$ 恒为零的原因：积化和差后只剩正弦项，即使 $m = n$，$\sin(m-n)\omega_1 t$ 也变成 $\sin 0 = 0$。

### 虚指数函数集的正交性

   * **虚指数函数集**

       * 成员为 $\left\{e^{\mathrm{j}n\omega_1 t}\right\}$，$n = 0, \pm 1, \pm 2, \cdots$，包含负整数；积分区间同样取 $t_0 \sim t_0 + T_1$。

       * > **定义**：复函数正交的定义比实函数多一个**共轭**：$\int_{t_1}^{t_2} f_1(t)f_2^{*}(t)\,dt = 0$；实数的共轭是它自身，故实函数正交可视为其特例，二者可统一。

       * 验证：$e^{\mathrm{j}n\omega_1 t}$ 的共轭是 $e^{-\mathrm{j}n\omega_1 t}$，乘积化为 $\int_{t_0}^{t_0+T_1} e^{\mathrm{j}(m-n)\omega_1 t}\,dt$；$m \neq n$ 时用欧拉公式展开，正余弦项整周期积分全为零，$m = n$ 时积出非零常数 $T_1$，满足正交定义。

       * 完备性同样不做证明，知道它是完备的即可。

## 三角形式傅里叶级数

### 展开式与系数公式

   * **三角形式傅里叶级数（trigonometric Fourier series）**

       * 适用前提：被分解信号是**实信号**（题目要求展开为三角函数时，信号必然是实的）。

       * 展开式（周期 $T_1$，角频率 $\omega_1 = \dfrac{2\pi}{T_1}$，频率 $f_1 = \dfrac{1}{T_1}$）：

$$f(t) = a_0 + \sum_{n=1}^{\infty}\left(a_n\cos n\omega_1 t + b_n\sin n\omega_1 t\right), \quad n \text{ 为正整数}$$

       * 三条系数基本公式（必须记住）：

$$a_0 = \frac{1}{T_1}\int_{t_0}^{t_0+T_1} f(t)\,dt, \qquad a_n = \frac{2}{T_1}\int_{t_0}^{t_0+T_1} f(t)\cos n\omega_1 t\,dt, \qquad b_n = \frac{2}{T_1}\int_{t_0}^{t_0+T_1} f(t)\sin n\omega_1 t\,dt$$

       * $a_0$ 对应**直流分量**（一周期积分除以周期），恒为 $1$ 的信号直流分量显然是 $1$；积分区间任取一个周期均可，常取 $-\dfrac{T_1}{2} \sim \dfrac{T_1}{2}$ 对称区间以利用奇偶性，有时取 $0 \sim T_1$。

       * 有的教材把直流系数写成 $\dfrac{2}{T_1}\int f(t)\,dt$、展开式直流项换成 $\dfrac{a_0}{2}$：完全等价，好处是直流与交流系数形式统一（都是 $\dfrac{2}{T_1}$，且 $n=0$ 时 $\cos n\omega_1 t = 1$），记一种即可。

   * **角频率的辨析**

       * 对 $\sin\omega t$，三角函数自带的角频率就是 $\omega$，对应周期 $T = \dfrac{2\pi}{\omega}$。

       * > **易错点**：⚠️ $\lvert\sin\omega_1 t\rvert$ 作为周期信号，周期是正弦的一半 $T_1 = \dfrac{\pi}{\omega_1}$，其角频率是 $\dfrac{2\pi}{T_1} = 2\omega_1$ 而非 $\omega_1$——周期信号的角频率和三角函数自带的角频率不一定是同一个，必须区分。

### 系数公式的推导思路

   * **推导要点**（不要求掌握，理解即可）

       * 思路：对展开式两边做与系数公式相同的操作（直接积分、乘 $\cos n\omega_1 t$ 积分、乘 $\sin n\omega_1 t$ 积分），利用"正余弦整周期积分为零"与对称区间奇偶性，右端只剩目标项。

       * > **易错点**：推导 $a_n$ 时必须把求和指标 $n$ 换成 $m$：求和结果与指标字母无关，而新乘上去的 $\cos n\omega_1 t$ 中的 $n$ 在积分后仍保留（结果为 $\dfrac{a_n T_1}{2}$），两个 $n$ 意义不同，不换会产生歧义。

       * 区间选 $t_0 \sim t_0+T_1$ 也能证，只是每一步都要老实做积化和差；选对称区间则 $\sin$（奇）乘 $\cos$（偶）为奇函数，直接积分为零，省去这一步。

       * 求 $b_n$ 时 $\sin$ 乘 $\sin$ 为偶函数，不能靠奇偶性判零，仍用积化和差：只有 $m = n$ 时出现 $\cos 0 = 1$ 积出非常值，$m + n = 0$ 永远做不到（$m$、$n$ 都是正数），最后只剩 $\dfrac{b_n T_1}{2}$。

### 系数的奇偶性与高数公式换元

   * **系数的奇偶性**

       * $a_{-n} = a_n$：$n$ 只出现在 $\cos n\omega_1 t$ 一处，$\cos$ 是偶函数，故 $a_n$ 是关于 $n$ 的**偶函数**（$a_{-n}$ 不出现在展开式中，但在数学推导中有用）。

       * $b_{-n} = -b_n$：$\sin$ 是奇函数，换 $n$ 为 $-n$ 时负号提到最前面，故 $b_n$ 是关于 $n$ 的**奇函数**。

   * **与高数课本公式的关系**

       * 数学书的 $a_n$、$b_n$ 公式只是做了换元 $x = \omega_1 t$：$\mathrm{d}t = \dfrac{\mathrm{d}x}{\omega_1}$，上下限 $\pm\dfrac{T_1}{2}$ 变为 $\pm\pi$（$T_1\omega_1 = 2\pi$），系数 $\dfrac{2}{T_1}\cdot\dfrac{1}{\omega_1} = \dfrac{1}{\pi}$，即得 $\dfrac{1}{\pi}\displaystyle\int_{-\pi}^{\pi} f(t)\cos nx\,\mathrm{d}x$ 的形式，仅形式不同。

### 合并同频项的余弦形式

   * **振幅与相位形式**

       * 合并公式：$a\cos\omega_0 t + b\sin\omega_0 t = \sqrt{a^2+b^2}\,\cos\left(\omega_0 t - \arctan\dfrac{b}{a}\right)$（仅对 $a>0$、$b>0$ 的常见情形直接成立）。

       * 令 $c_0 = a_0$、$c_n = \sqrt{a_n^2 + b_n^2}$、$\varphi_n = -\arctan\dfrac{b_n}{a_n}$，得另一种三角形式 $f(t) = c_0 + \sum\limits_{n=1}^{\infty} c_n\cos(n\omega_1 t + \varphi_n)$，$c_n$ 是**振幅**、$\varphi_n$ 是**相位**。

       * $\varphi_n$ 的完备写法须按 $a_n$、$b_n$ 的符号分情况（$\arctan$ 本身不是完备的）：

| 条件 | $\varphi_n$ |
| :--- | :--- |
| $a_n > 0$（$b_n$ 正负均可） | $-\arctan\dfrac{b_n}{a_n}$ |
| $a_n < 0,\ b_n > 0$ | $-\pi - \arctan\dfrac{b_n}{a_n}$ |
| $a_n < 0,\ b_n < 0$ | $\pi - \arctan\dfrac{b_n}{a_n}$ |

       * > **易错点**：⚠️ $\sin t + \cos t$ 与 $-\sin t - \cos t$ 用 $\sqrt{a^2+b^2}\cos(t - \arctan\frac{b}{a})$ 算出的结果相同，但两个信号明显不同（差一个负号）——$a < 0$ 时该公式失效，必须查表分情况。

       * $c_{-n} = c_n$：$b_{-n} = -b_n$ 的负号被平方吸收，$c_n$ 是关于 $n$ 的**偶函数**。

       * $\varphi_{-n} = -\varphi_n$：结合 $a_{-n} = a_n$、$b_{-n} = -b_n$ 与 $\arctan$ 是奇函数逐条对照三种情况可得，$\varphi_n$ 是关于 $n$ 的**奇函数**。

       * 物理含义：这套分解把每个频率分量的幅度与相位完整给出，是讨论频谱的出发点。

## 单边幅度谱与单边相位谱

### 谐波分量与画谱规则

   * **谐波（harmonic）**

       * $f(t) = C_0 + \sum C_n\cos(n\omega_1 t + \varphi_n)$ 中：$C_0$ 叫**直流分量**；角频率 $\omega_1$ 的项叫**基波**（一次谐波）；角频率 $2\omega_1$、$3\omega_1$ 的项依次叫**二次谐波**、**三次谐波**，以此类推。

       * 直流分量可视为角频率为零的分量：$\cos 0 = 1$，角频率为零意味着不振动，不振动的就是直流。

       * 每次谐波都有自己的幅度与相位：$\omega_1$ 分量幅度 $C_1$、相位 $\varphi_1$；$2\omega_1$ 分量幅度 $C_2$、相位 $\varphi_2$，依此类推。

   * **单边谱（one-sided spectrum）**

       * 画法：以角频率为横轴，$\omega = 0$ 处标 $C_0$，$\omega_1$ 处标 $C_1$，$2\omega_1$ 处标 $C_2$……得到单边幅度谱；同理标 $\varphi_n$ 得到单边相位谱（直流分量没有相位，记 $0$）。

       * > **定义**："单边"指谱线只在频率轴**正半轴**，从 $0$ 开始往 $\omega_1, 2\omega_1, \ldots$ 一路画上去，负频率一边没有谱线。

       * > **结论**：单边幅度谱与单边相位谱都是**离散谱**——角频率只能取 $0, \omega_1, 2\omega_1, 3\omega_1, \ldots$ 这些离散值，不能连续取。

       * 缺某次谐波时该频率处就是空的：如 $f(t) = 1 + 2\cos\left(\omega_1 t + \frac{\pi}{4}\right) + \cos\left(3\omega_1 t - \frac{\pi}{2}\right)$ 没有二次谐波，$2\omega_1$ 处无谱线；其余谱线为 $0$ 处幅度 $1$、$\omega_1$ 处 $2$ 相位 $\frac{\pi}{4}$、$3\omega_1$ 处 $1$ 相位 $-\frac{\pi}{2}$。

### 非标准形式的化简步骤

   * **化标准形式的三步**

       * 第一步：$\sin$ 化 $\cos$，用 $\sin\left(\alpha + \dfrac{\pi}{2}\right) = \cos\alpha$；注意括号内是**减** $\dfrac{\pi}{2}$（把原括号内整体作为 $\alpha$），不要搞反。

       * 第二步：消 $\cos$ 前的负号，用 $\cos(\alpha + \pi) = -\cos\alpha$（左移或右移 $\pi$ 波形上下翻转）；加 $\pi$ 还是减 $\pi$ 由约束决定——**相位必须落在 $(-\pi, \pi]$ 内**，不在范围可加减 $2\pi$ 调整（相位加减 $2\pi$ 不改变正余弦信号）。

       * 第三步：找各频率的**最大公约数**确定 $\omega_1$，把每项改写成 $n\omega_1$ 形式；最大公约数不限于整数，如 $\dfrac{\pi}{4}$ 与 $\dfrac{\pi}{3}$ 的最大公约数是 $\dfrac{\pi}{12}$。

       * > **易错点**：⚠️ 不能令 $C_n = -6$ 来吸收 $\cos$ 前的负号——$C_n = \sqrt{a_n^2+b_n^2}$ 是开方所得，必然为正，幅度谱的谱线只往上画。

       * 例：$f(t) = 5 - 6\cos\left(\dfrac{\pi}{4}t - \dfrac{2\pi}{3}\right) + 4\sin\left(\dfrac{\pi}{3}t - \dfrac{\pi}{6}\right)$ 化简后为 $f(t) = 5 + 6\cos\left(3\omega_1 t + \dfrac{\pi}{3}\right) + 4\cos\left(4\omega_1 t - \dfrac{2\pi}{3}\right)$，$\omega_1 = \dfrac{\pi}{12}$；单边幅度谱为 $0$ 处 $5$、$3\omega_1$ 处 $6$、$4\omega_1$ 处 $4$（$\omega_1$、$2\omega_1$ 处无谱线），单边相位谱为 $3\omega_1$ 处 $\dfrac{\pi}{3}$、$4\omega_1$ 处 $-\dfrac{2\pi}{3}$。

       * > **提示**：形式与频率序号并不总是一眼对应——$\frac{\pi}{4}t$ 那一项实际是**三次**谐波，必须化成 $n\omega_1$ 形式才看得清谱线位置。

## 指数形式傅里叶级数

### 从欧拉公式到统一形式

   * **指数形式傅里叶级数（exponential Fourier series）**

       * 推导桥梁：欧拉公式 $\cos x = \dfrac{e^{\mathrm{j}x} + e^{-\mathrm{j}x}}{2}$、$\sin x = \dfrac{e^{\mathrm{j}x} - e^{-\mathrm{j}x}}{2\mathrm{j}}$，把三角形式中的 $\cos$、$\sin$ 都展成复指数（$\dfrac{b_n}{2\mathrm{j}}$ 可把 $\mathrm{j}$ 提到分子变成 $-\dfrac{\mathrm{j}b_n}{2}$）。

       * 合并同频率项：$e^{\mathrm{j}n\omega_1 t}$ 的系数为 $\dfrac{a_n - \mathrm{j}b_n}{2}$（记作 $F(n\omega_1)$），$e^{-\mathrm{j}n\omega_1 t}$ 的系数为 $\dfrac{a_n + \mathrm{j}b_n}{2}$，后者利用 $a_n$ 偶、$b_n$ 奇恰好等于 $F(-n\omega_1)$。

       * 对后一个求和换元 $-n = k$ 后两个求和形式相同，只缺 $n = 0$；令 $F(0) = a_0$ 补上，即得统一形式（记 $F_n = F(n\omega_1)$）：

$$f(t) = \sum_{n=-\infty}^{+\infty}F_n e^{\mathrm{j}n\omega_1 t}$$

       * 优点：只要求一个系数 $F_n$，不用分别求 $a_0$、$a_n$、$b_n$ 三套。

### Fn 的计算与性质

   * **系数 $F_n$**

       * 计算公式：

$$F_n = \frac{1}{T_1}\int_{-T_1/2}^{T_1/2} f(t)e^{-\mathrm{j}n\omega_1 t}\,dt$$

       * > **易错点**：⚠️ 展开式 $f(t) = \sum F_n e^{\mathrm{j}n\omega_1 t}$ 里指数是**正**的，求 $F_n$ 的积分里指数是**负**的，一正一负记的时候不要混淆。

       * 求 $F_n$ 一般利用不到奇偶性（被积函数是复指数，没有 $\sin$ 奇、$\cos$ 偶的待遇），积分上下限可直接换成 $0 \sim T_1$，往往更好算（代入 $0$ 总是最好代的）。

       * 常用结论：$e^{\mathrm{j}n\omega_1 T_1} = e^{\mathrm{j}n2\pi} = 1$（$n$ 为整数时恒成立）——旋转矢量理解是相位每增 $2\pi$ 矢量转一圈回到原点；欧拉展开理解是 $\cos 2\pi n = 1$、$\sin 2\pi n = 0$。

       * $F_n$ 本身没有奇偶性（$a_n$ 偶与 $b_n$ 奇的混合），但 $F_{-n} = \dfrac{a_n + \mathrm{j}b_n}{2} = F_n^{*}$（$F_{-n}$ 就是 $F_n$ 的共轭），由此得到幅度偶对称、相位奇对称。

### 三套系数的关系

   * **系数关系**（画双边谱的全部依据）

| 关系 | 含义 |
| :--- | :--- |
| $F_0 = C_0 = a_0$ | 直流处不砍半，直接相等；$F_0$ 是实数 |
| $\lvert F_n\rvert = \dfrac{1}{2}C_n$（$n \neq 0$） | 指数形式的幅度是三角形式的一半 |
| $\lvert F_{-n}\rvert = \lvert F_n\rvert$ | 幅度关于 $n$ 偶对称 |
| $\varphi_{-n} = -\varphi_n$ | 相位关于 $n$ 奇对称，且与三角形式的 $\varphi_n$ 形式完全相同 |
| $F_n + F_{-n} = a_n$，$\mathrm{j}(F_n - F_{-n}) = b_n$ | 可由 $F_n$ 反求三角形式系数 |

       * $\lvert F_n\rvert = \dfrac{1}{2}C_n$ 的来源：$F_n$ 的模是实部平方加虚部平方再开根号，$\sqrt{\left(\frac{a_n}{2}\right)^2 + \left(-\frac{b_n}{2}\right)^2} = \dfrac{1}{2}\sqrt{a_n^2+b_n^2}$。

       * $F_n$ 的相位分四种情况讨论：把 $F_n$ 对号入座写成 $\dfrac{a_n}{2} + \mathrm{j}\left(-\dfrac{b_n}{2}\right)$ 再套求相位结论（$a_n > 0$ 时为 $-\arctan\dfrac{b_n}{a_n}$；$a_n < 0$ 时再各加减一个 $\pi$），结果与 $C_n\cos(n\omega_1 t + \varphi_n)$ 里的 $\varphi_n$ 形式完全相同。

## 双边幅度谱与双边相位谱

### 由单边谱画双边谱

   * **双边谱（two-sided spectrum）**

       * > **定义**：指数形式中 $n$ 从 $-\infty$ 到 $+\infty$ 都能取，谱线在频率轴正负两侧都有，故称双边谱。

       * 幅度谱转换口诀：**零处不变，非零处砍一半，再对称到左边**——$F_0 = C_0$ 原地不动；$n \neq 0$ 处 $\lvert F_n\rvert = \dfrac{1}{2}C_n$；左半边按 $\lvert F_{-n}\rvert = \lvert F_n\rvert$ 偶对称镜像，不必重新算。

       * 相位谱转换：右半边与单边相位谱逐点相同（$F_n$ 的相位与三角形式的 $\varphi_n$ 形式一致），直接照抄；左半边按 $\varphi_{-n} = -\varphi_n$ 奇对称取反镜像。

       * 例：对 $f(t) = 5 + 6\cos\left(3\omega_1 t + \dfrac{\pi}{3}\right) + 4\cos\left(4\omega_1 t - \dfrac{2\pi}{3}\right)$（$\omega_1 = \dfrac{\pi}{12}$），双边幅度谱为 $0$ 处 $5$、$\pm 3\omega_1$ 处 $3$、$\pm 4\omega_1$ 处 $2$；双边相位谱为 $3\omega_1$ 处 $\dfrac{\pi}{3}$、$-3\omega_1$ 处 $-\dfrac{\pi}{3}$、$4\omega_1$ 处 $-\dfrac{2\pi}{3}$、$-4\omega_1$ 处 $+\dfrac{2\pi}{3}$。

       * 对三角函数形式，先用欧拉公式换成复指数再求双边谱可行但麻烦；已有单边谱时直接用系数关系转换更简单。

### 复指数形式直接画双边谱

   * **负系数的处理**

       * 第一步仍是求 $\omega_1$：找各项频率的最大公约数，如 $e^{\mathrm{j}t}$ 与 $e^{-\mathrm{j}2t}$ 中 $1$ 与 $-2$ 的最大公约数为 $1$，故 $\omega_1 = 1$，两项分别在 $+\omega_1$ 与 $-2\omega_1$ 处。

       * > **易错点**：⚠️ 幅度谱必须都为正，系数 $-1$ 不能直接画成 $-1$，也不能平白无故改成 $+1$——要把负号**转嫁到相位上**（在相位上做手脚）。

       * 依据：$e^{\mathrm{j}\pi} = e^{-\mathrm{j}\pi} = -1$（旋转矢量逆时针、顺时针各转半圈都落在 $-1$；欧拉展开 $\cos\pi = -1$、$\sin\pi = 0$），故相位加减 $\pi$ 等价于幅度乘 $-1$；想把 $-A$ 改正，就写成 $A\cdot e^{\mathrm{j}\pi}$。

       * 加 $\pi$ 还是减 $\pi$ 仍受**相位范围 $(-\pi, \pi]$** 约束；若加减 $\pi$ 都回不到范围内，可再加减 $2\pi$（$e^{\mathrm{j}2\pi} = e^{-\mathrm{j}2\pi} = 1$，相位等效不变）。

       * 例：$-1\cdot e^{\mathrm{j}\left(-2t - \frac{\pi}{3}\right)}$ 改写为 $1\cdot e^{\mathrm{j}\left(-2t + \frac{2\pi}{3}\right)}$（$-\frac{\pi}{3} + \pi = \frac{2\pi}{3}$ 落在范围内，减 $\pi$ 得 $-\frac{4\pi}{3}$ 出范围）；于是双边幅度谱为 $\omega_1$ 处 $2$、$-2\omega_1$ 处 $1$，双边相位谱为 $\omega_1$ 处 $-\dfrac{\pi}{3}$、$-2\omega_1$ 处 $\dfrac{2\pi}{3}$。

## 周期矩形脉冲的频谱

### 傅里叶级数展开

   * **周期矩形脉冲信号**

       * 波形：幅度 $E$、宽度 $\tau$ 的矩形脉冲以周期 $T_1$ 无限重复，相邻脉冲中心相距 $T_1$。

```text
  E ─┐  ┌───────┐       ┌───────┐
     │  │       │       │       │
  ───┘  └───────┘───────┘       └──────────→ t
       -τ/2  τ/2           T1-τ/2 T1+τ/2
        |←─ τ ─→|←──  T1  ──→|
```

       * > **易错点**：⚠️ 周期是 $T_1$ 而不是 $\tau$——脉冲之间的零电平也是周期的一部分，别看漏。

       * $a_0 = \dfrac{1}{T_1}\cdot E\tau = \dfrac{E\tau}{T_1}$：一周期内只有 $-\tau/2 \sim \tau/2$ 段是 $E$、其余为零，直流分量即一周期内信号的平均值。

       * $a_n$：被积函数 $f(t)\cos n\omega_1 t$ 是偶（常数 $E$）乘偶（$\cos$），对称区间折半翻倍，得 $a_n = \dfrac{4E}{T_1}\int_{0}^{\tau/2}\cos(n\omega_1 t)\,dt = \dfrac{2E}{n\pi}\sin\left(\dfrac{n\omega_1\tau}{2}\right)$。

       * 凑成 Sa 函数形式（两形式完全等价，画频谱、看趋势时 Sa 形式顺手得多）：$a_n = \dfrac{2E\tau}{T_1}\,\mathrm{Sa}\left(\dfrac{n\omega_1\tau}{2}\right)$，其中抽样函数 $\mathrm{Sa}(t) = \dfrac{\sin t}{t}$；凑法是外乘外除同一因子补齐差出的系数。

       * $b_n = 0$：$f(t)$（偶）乘 $\sin n\omega_1 t$（奇）为奇函数，对称区间积分为零，一行积分不用算。

       * 三角形式级数（$b_n$ 全为零，只剩余弦项）：

$$f(t) = \frac{E\tau}{T_1} + \sum_{n=1}^{\infty}\frac{2E\tau}{T_1}\,\mathrm{Sa}\left(\frac{n\omega_1\tau}{2}\right)\cos(n\omega_1 t)$$

       * 指数形式不必重新积分，由 $b_n = 0$ 时 $F_n = \dfrac{a_n}{2}$ 直接得到：$F_n = \dfrac{E\tau}{T_1}\,\mathrm{Sa}\left(\dfrac{n\omega_1\tau}{2}\right)$，$f(t) = \dfrac{E\tau}{T_1}\displaystyle\sum_{n=-\infty}^{+\infty}\mathrm{Sa}\left(\dfrac{n\omega_1\tau}{2}\right)e^{\mathrm{j}n\omega_1 t}$（常数可提到求和号外）。

### 通项分母的特殊点

   * **分母含 $n$ 的通项**

       * 通项里 $n$ 跑到分母上（如本题 $\dfrac{2E}{n\pi}$）时 $n$ 不能取该值（分母不能为零）；本题 $a_0$ 单独求，通常不冲突。

       * 若通项形如 $\dfrac{\text{什么什么}}{n-1}$，则 $n = 1$ 不能代入——只写通项时照写，但要的是 $a_1$ 时不能用这个式子。

       * > **易错点**：⚠️ $a_n$ 在 $n = 1$ 处没有定义，不代表 $a_1$ 不存在——$a_1$ 是有的，只是通项在该点失效，求法有二：回定义式 $\dfrac{2}{T_1}\int f(t)\cos\omega_1 t\,dt$ 老实积分，或在 $n$ 还没跑到分母上之前的那一步就代入 $n = 1$。

### 频谱形状与包络

   * **频谱形状**

       * $F_n = \dfrac{E\tau}{T_1}\mathrm{Sa}(\cdot)$ 中各因子全是实数，$F_n$ 本身是实数，幅度谱与相位谱可**合画在一张图上**（此时谱线正负都可以，不再要求翻正）。

       * 离散谱：谱线落在 $\omega = 0, \pm\omega_1, \pm 2\omega_1, \dots$，相邻谱线间隔 $\omega_1 = \dfrac{2\pi}{T_1}$；整体包络呈 Sa 形。

       * $T_1$ 越大（两个矩形离得越远）$\omega_1$ 越小、谱线间距越小，频谱越**稠密**；$T_1$ 越小谱线间距越大，频谱越**稀疏**。

       * 分开画幅度谱时把负谱线翻上来，代价是翻上来相当于乘了 $e^{\mathrm{j}\pi}$（或 $e^{-\mathrm{j}\pi}$）：为保证相位的奇对称性，$\omega > 0$ 的这部分相位取 $\pi$、$\omega < 0$ 的取 $-\pi$，未被翻动的谱线相位为零。

   * **包络与第一个零点**

       * 把谱线的连续包络写出（把 $n\omega_1$ 换成连续变量 $\omega$，谱线只在 $n\omega_1$ 处取样，包络处处连续）：$F(\omega) = \dfrac{E\tau}{T_1}\,\mathrm{Sa}\left(\dfrac{\omega\tau}{2}\right)$。

       * 包络在 $\omega = 0$ 处高度为 $\dfrac{E\tau}{T_1}$（$\mathrm{Sa}(0)$ 恒等于 $1$）。

       * 过零点：由 $\mathrm{Sa}$ 在 $t = m\pi$（$m = \pm1, \pm2, \dots$）处为零，得 $\omega = \dfrac{2m\pi}{\tau}$，**第一个零点**在 $\omega = \dfrac{2\pi}{\tau}$。

       * 各分量幅度总体随频率增高而减小（中间个别回升不改总趋势），信号能量主要集中在第一个零点以内。

### 频带宽度

   * **频带宽度（bandwidth）**

       * > **定义**：取 $0 \sim \dfrac{2\pi}{\tau}$ 这一段为周期矩形脉冲信号的**频带宽度**：以角频率计 $B_\omega = \dfrac{2\pi}{\tau}$；以频率计 $B_f = \dfrac{B_\omega}{2\pi} = \dfrac{1}{\tau}$。

       * 脉宽 $\tau$ 与带宽成**反比**：脉冲越宽，频带宽度越窄；频带宽度越宽，脉冲越窄。这一关系后面会一再见到。

       * 完整传输无穷多个频率分量很难做到、代价极大，实际在允许一定失真的条件下只传能量集中的这一段。

       * 现实中频率都是正的，负频率只是为便于分析引入的概念。

### 周期趋于无穷的极限

   * **$T_1$ 趋于无穷**

       * 幅度上 $F_n \propto \dfrac{1}{T_1}$：$T_1$ 增大时 Sa 包络压扁、整个频谱幅度变小。

       * 极限图景：$T_1 \to \infty$ 时第二个矩形再也看不见，周期信号变成**非周期信号**；谱线极度紧密，离散谱变**连续谱**；频谱幅度趋于零。

       * 幅度趋零但信号并不"消失"——这是为**傅里叶变换**做的铺垫，届时会把趋于零的幅度乘上一个无穷大的周期"补回来"。

## 函数对称性与傅里叶系数

### 偶函数与奇函数

   * **偶函数**（$f(t) = f(-t)$）

       * $a_n = \dfrac{4}{T_1}\int_{0}^{T_1/2} f(t)\cos(n\omega_1 t)\,dt$：$f(t)$ 偶乘 $\cos$（偶）仍为偶，对称区间折半翻倍；$a_0$ 同样可取半区间乘二。

       * $b_n = 0$：偶乘奇为奇，对称区间积分为零。

       * $F_n = \dfrac{a_n}{2}$（因 $b_n = 0$），是**实数**。

   * **奇函数**（$f(t) = -f(-t)$）

       * $a_n = 0$（含 $a_0$——$a_0$ 本质是乘了偶函数 $1$）；$b_n = \dfrac{4}{T_1}\int_{0}^{T_1/2} f(t)\sin(n\omega_1 t)\,dt$（奇乘奇为偶，折半翻倍）。

       * $F_n = -\dfrac{\mathrm{j}b_n}{2}$，是**纯虚数**。

### 奇谐函数

   * **奇谐函数（odd harmonic function）**

       * > **定义**：若 $f(t) = -f\left(t \pm \dfrac{T_1}{2}\right)$（$T_1$ 为周期），即平移半个周期后与原信号刚好上下颠倒，则称 $f(t)$ 为奇谐函数。

       * 傅里叶级数**只含奇次谐波**（$n = 1, 3, 5, \dots$ 的 $a_n$、$b_n$），偶次谐波全为零；直流 $a_0$ 归在偶次一边，且**所有奇谐函数一周期积分恒为零**（左右半周期面积相同、上下颠倒，积分互相抵消），故 $a_0$ 恒为零。

       * 证明核心（以 $b_n$ 为例）：把定义代入并换元 $t + \dfrac{T_1}{2} = \tau$，被积函数出现 $\sin(n\omega_1\tau - n\pi)$；$n$ 为偶数时它等于 $\sin(n\omega_1\tau)$，推出 $b_n = -b_n$，故 $b_n = 0$；$n$ 为奇数时它等于 $-\sin(n\omega_1\tau)$，负号抵消后推出 $b_n = b_n$——对奇次谐波**没有任何限制**（存在但大小不定）。

       * 反过来的结论：去除直流分量后满足 $f(t) = -f\left(t \pm \frac{T_1}{2}\right)$ 的信号，只含直流分量和奇次谐波。

### 偶谐函数

   * **偶谐函数（even harmonic function）**

       * > **定义**：若 $f(t) = f\left(t \pm \dfrac{T_1}{2}\right)$（定义中没有负号），即平移半个周期后与原信号**重叠**，则称 $f(t)$ 为偶谐函数。

       * 傅里叶级数只有**偶次谐波**（奇次谐波全为零；偶次谐波是否为零不定，故 $a_0$ 可为零也可非零）。

       * > **易错点**：⚠️ 偶谐函数的周期**不能取最小正周期**——取最小正周期则平移半个周期后与原信号不重叠，就不再是偶谐函数；必须选比最小正周期更大的周期。这也是该概念令人迷惑之处（有的教材干脆不讲）。

### 展开周期的选取与分解唯一性

   * **换周期展开的验证**

       * 直流分量与所选周期无关：波形没变，平均值当然不变。

       * 设最小正周期对应的特征长度为 $a$，分别用 $T_1 = a$ 与 $T_1 = 2a$ 展开：取 $2a$ 时信号可看作偶谐函数，奇次谐波全为零，其第一项是 $a_2$；对比 $a_1$（周期 $a$）与 $a_2$（周期 $2a$）——被积函数同为 $f(t)\cos\left(\dfrac{2\pi}{a}t\right)$，一个在 $\left[-\frac{a}{2}, \frac{a}{2}\right]$（一个周期）上积分乘 $\dfrac{2}{a}$，一个在 $[-a, a]$（两个周期）上积分乘 $\dfrac{1}{a}$，结果相同。

       * 结论：不管周期选多少，$a_0$、$a_n$、$b_n$ 都一样——**傅里叶级数分解是唯一的**。

### 对称性结论对照

| 函数类型 | $a_0$、$a_n$ | $b_n$ | $F_n$ |
| :--- | :--- | :--- | :--- |
| 偶函数 | $a_n=\dfrac{4}{T_1}\displaystyle\int_{0}^{T_1/2}f(t)\cos(n\omega_1 t)\,dt$（$a_0$ 同样可取半区间乘二） | $0$ | $F_n=\dfrac{a_n}{2}$，实数 |
| 奇函数 | $0$（含 $a_0$） | $b_n=\dfrac{4}{T_1}\displaystyle\int_{0}^{T_1/2}f(t)\sin(n\omega_1 t)\,dt$ | $F_n=-\dfrac{\mathrm{j}b_n}{2}$，纯虚数 |
| 奇谐函数 | 直流恒为零；仅 $n$ 为奇数时 $a_n=\dfrac{4}{T_1}\displaystyle\int_{0}^{T_1/2}f(t)\cos(n\omega_1 t)\,dt$，偶次为零 | 仅 $n$ 为奇数时 $b_n=\dfrac{4}{T_1}\displaystyle\int_{0}^{T_1/2}f(t)\sin(n\omega_1 t)\,dt$，偶次为零 | $F_n=\dfrac{a_n-\mathrm{j}b_n}{2}$，按常规公式算 |

   * 做题先判对称性再动积分，能省一大半计算量；奇谐函数遇到的也不多，偶谐函数实际用不到（一般都选最小正周期），故表中不列。

   * 奇谐函数的余弦、正弦分量也可把积分限换成 $0 \sim \dfrac{T_1}{2}$、前面乘二，但**只对 $n = 1, 3, 5, \dots$ 奇次成立**，偶次谐波直接为零；$F_n$ 无捷径，就是常规的 $\dfrac{a_n - \mathrm{j}b_n}{2}$。
