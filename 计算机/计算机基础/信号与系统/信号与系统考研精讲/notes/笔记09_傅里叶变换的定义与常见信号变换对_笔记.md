# 傅里叶变换的定义与常见信号变换对

## 傅里叶级数系数的直接计算

    * **指数形式傅里叶级数系数（$F_n$）**

        * > **定义**：$F_n=\dfrac{1}{T}\displaystyle\int_{-\frac{T}{2}}^{\frac{T}{2}}f(t)\,e^{-\mathrm{j}n\omega_1 t}\,\mathrm{d}t$，其中 $\omega_1=\dfrac{2\pi}{T}$；$F_n$ 一求出，指数形式级数 $f(t)=\sum\limits_{n=-\infty}^{\infty}F_n e^{\mathrm{j}n\omega_1 t}$ 随之确定。

        * 求系数第一步是找周期 $T$，第二步是选一段"一个周期"的表达式。

        * > **易错点**：级数对"取哪一段当周期"不敏感，但对**计算量**极其敏感——选区间前先扫一眼波形，哪一段表达式最简单就选哪一段。例如 $0\sim\frac{T}{2}$ 与 $\frac{T}{2}\sim T$ 表达式不同的波形，改选 $-\frac{T}{2}\sim\frac{T}{2}$ 可能就是一条过原点的直线 $f(t)=\frac{2}{T}t$，无需分段。

        * > **易错点**：求 $F_n$ 的公式里指数是 $e^{-\mathrm{j}n\omega_1 t}$（负的）；级数合成时指数是 $e^{+\mathrm{j}n\omega_1 t}$（正的）。两个符号不可混淆。

    * **分部积分表格法**

        * 适用形态：多项式（如 $t$）乘指数（如 $e^{-\mathrm{j}n\omega_1 t}$）的积分；分部积分 $\int u\,\mathrm{d}v=uv-\int v\,\mathrm{d}u$ 一定能算，但表格法写得更快。

        * 用法：多项式部分放**上面逐次求导**（$t\to 1\to 0$），指数部分放**下面逐次积分**（指数不变，把 $t$ 前的系数放到分母，得 $\frac{e^{-\mathrm{j}n\omega_1 t}}{-\mathrm{j}n\omega_1}$、再积一次分母为 $(-\mathrm{j}n\omega_1)^2$）；然后**对角线相乘、符号一加一减**；是定积分就带上下限。

        * > **易错点**：积分算完别丢前面的系数——表格法求出的只是积分值，积分外提出的常数（如 $\frac{2}{T^2}$）必须乘回去。

    * **结论 $e^{\mathrm{j}n\pi}=(-1)^n$**

        * 完整链条：$e^{\mathrm{j}n\pi}=e^{-\mathrm{j}n\pi}=\cos n\pi=(-1)^n$，傅里叶分析里出场率极高。

        * 理解一（旋转矢量）：$n$ 每加 $1$，相位转半圈，$1,-1,1,-1$ 交替；$e^{-\mathrm{j}n\pi}$ 只是顺时针转，结果相同。

        * 理解二（欧拉公式）：$e^{\mathrm{j}n\pi}=\cos n\pi+\mathrm{j}\sin n\pi$，而 $\sin n\pi=0$，$\cos n\pi$ 对 $n=0,1,2,3,\dots$ 取 $1,-1,1,-1,\dots$。

        * 代上下限的典型用途：$\omega_1\cdot\left(\pm\frac{T}{2}\right)=\pm\pi$，指数上出现 $e^{\pm\mathrm{j}n\pi}$，全部换成 $(-1)^n$ 后成对的项常互相抵消或合并。例如 $\int_{-\frac{T}{2}}^{\frac{T}{2}}t\,e^{-\mathrm{j}n\omega_1 t}\mathrm{d}t=\frac{T(-1)^n}{-\mathrm{j}n\omega_1}$，配合外层系数得 $F_n=\dfrac{(-1)^n}{-\mathrm{j}n\pi}$。

    * **三角形式还是指数形式**

        * 题目不指定形式时按信号特点选，只求一种即可——另一种可用两套系数的关系推出来，没让求两个就不要两个都硬算。

        * 有奇偶性 → 三角形式：奇偶性结论保证 $a_n$、$b_n$ 中必有一个为零，少求一个，且三角函数积分更熟。

        * 无奇偶性 → 指数形式：三角形式得把 $a_n$、$b_n$、$a_0$ 全求一遍，不如只求一个 $F_n$ 干净。

## 从傅里叶级数到傅里叶变换

    * **极限过程（$T_1\to\infty$）**

        * > **定义**：让周期信号的周期 $T_1$ 趋向无穷大，谱线间隔 $\omega_1=\dfrac{2\pi}{T_1}$ 趋向无穷小，频谱由**离散谱**变为**连续谱**，周期信号就过渡为非周期信号。

        * 极限中各频率分量的幅度趋向无穷小，得到"连续谱、但幅度无穷小"的怪图像，无法直接画频谱，需要新工具。

    * **幅度为何趋于无穷小（功率信号与能量信号）**

        * 可积的周期信号是**功率信号**，能量无穷，分给离散的有限多个谱线点分得开。

        * 非周期信号是**能量信号**，能量有限，还要分给无限多个 $\omega_1$，每处分到的能量趋向无穷小，幅度随之趋向无穷小。

        * > **注意**：虽然各分量幅度都无穷小，但彼此**原有的比例关系不变**——原来谁大现在谁还是大，只是大小关系不易直接看出。

    * **频谱密度（Spectral Density，$F(\omega)$）**

        * > **定义**：$F(\omega)=\lim\limits_{T_1\to\infty}F_n\cdot T_1$，用无穷小乘无穷大得到有限常数，用以描述非周期信号的频谱；有的教材记作 $F(\mathrm{j}\omega)$，只是记号差异。

        * 等价写法：利用 $\omega_1=\frac{2\pi}{T_1}$，$F(\omega)=\lim\limits_{\omega_1\to 0}\dfrac{2\pi F_n}{\omega_1}$。

        * "密度"的含义：类比 $\rho=\frac{m}{V}$——那一小块体积小、质量也小，一除得到常数密度；频谱密度就是**单位频带宽度上的"新幅值"** $\frac{F_n}{\omega_1}$（$2\pi$ 是常数可不计），与概率论的概率密度同型。

        * 无穷小指的是 $F_n$ 的**模**：$F_n$ 是复数、相位在 $-\pi$ 到 $\pi$ 内，相位不变而模趋于零，复数整体必趋于零。

## 傅里叶正变换与逆变换

    * **傅里叶正变换（Fourier Transform，记作 $\mathcal{F}[f(t)]$）**

        * > **定义**：$F(\omega)=\displaystyle\int_{-\infty}^{\infty}f(t)\,e^{-\mathrm{j}\omega t}\,\mathrm{d}t$，由 $F_n T_1=\int_{-\frac{T_1}{2}}^{\frac{T_1}{2}}f(t)e^{-\mathrm{j}n\omega_1 t}\mathrm{d}t$ 令 $T_1\to\infty$ 而来。

        * 推导要点：上下限 $\pm\frac{T_1}{2}$ 变成 $\pm\infty$；$\omega_1$ 是**隐藏的 $T_1$**——$T_1\to\infty$ 时 $\omega_1\to 0$，离散的 $n\omega_1$ 连续化为 $\omega$，$\mathrm{j}n\omega_1$ 变 $\mathrm{j}\omega$。

    * **傅里叶逆变换（记作 $\mathcal{F}^{-1}[F(\omega)]$）**

        * > **定义**：$f(t)=\dfrac{1}{2\pi}\displaystyle\int_{-\infty}^{\infty}F(\omega)\,e^{\mathrm{j}\omega t}\,\mathrm{d}\omega$，由指数形式级数 $f(t)=\sum F_n e^{\mathrm{j}n\omega_1 t}$ 两边乘 $T_1$、右边除 $T_1$ 后取极限而来。

        * 逐块替换：$F_n T_1\to F(\omega)$；$\frac{1}{T_1}=\frac{\omega_1}{2\pi}$，$\omega_1$ 的无穷小写成微分 $\mathrm{d}\omega$；$n\omega_1\to\omega$；求和 $\Sigma\to$ 积分 $\int$（积分本来就是求和取极限）。

        * > **易错点**：正变换指数是 $e^{-\mathrm{j}\omega t}$（负），逆变换指数是 $e^{\mathrm{j}\omega t}$（正），且逆变换前面多一个 $\frac{1}{2\pi}$——两处不同都要当心。

        * 推导链条骨架：

```text
    傅里叶级数(周期信号, 离散谱)               傅里叶变换(非周期信号, 连续谱)
    Fn = (1/T1)∫ f(t)e^(-jnω1 t)dt  ──乘 T1──▶  Fn·T1 ──T1→∞──▶  F(ω)
    合成: f(t)=Σ Fn·e^(+jnω1 t)     ──除 T1──▶  (1/T1)→dω/2π, Σ→∫, nω1→ω
                                                    f(t) = (1/2π)∫ F(ω)e^(+jωt)dω
```

    * **频率 $f$ 作自变量的写法**

        * 一些教材（尤其通信原理）不用角频率 $\omega$ 而用频率 $f$（$\omega=2\pi f$），正变换改写为 $F(f)=\displaystyle\int_{-\infty}^{\infty}f(t)\,e^{-\mathrm{j}2\pi ft}\,\mathrm{d}t$。

## 频谱密度函数的性质

    * **$F(\omega)$ 是复函数**

        * 两种等价写法：模相形式 $|F(\omega)|e^{\mathrm{j}\varphi(\omega)}$，或实部虚部形式 $R(\omega)+\mathrm{j}X(\omega)$。

        * 频谱图画**幅度谱** $|F(\omega)|$ 与**相位谱** $\varphi(\omega)$ 两张，都是**连续谱**（横轴为连续变量）——画的对象是密度函数 $F(\omega)$，它已不是无穷小量。

        * 若 $F(\omega)$ 是实函数，幅度谱与相位谱可合并画在一张图上（幅值为负的瓣相当于相位翻了 $\pi$）。

    * **代特值得到的面积结论**

        * 正变换令 $\omega=0$：$F(0)=\displaystyle\int_{-\infty}^{\infty}f(t)\,\mathrm{d}t$，即 $f(t)$ 波形下的面积等于 $F(0)$。

        * 逆变换令 $t=0$：$f(0)=\dfrac{1}{2\pi}\displaystyle\int_{-\infty}^{\infty}F(\omega)\,\mathrm{d}\omega$，即 $F(\omega)$ 曲线下的面积等于 $2\pi f(0)$。

    * **绝对可积条件**

        * > **定义**：傅里叶变换（理论上）存在的条件是 $\displaystyle\int_{-\infty}^{\infty}|f(t)|\,\mathrm{d}t<\infty$，与傅里叶级数的存在条件同类；前面的推导在数学上并不十分严格。

        * 该条件会把熟悉的信号挡在门外：阶跃信号、一些周期信号不绝对可积，**不能用定义**求变换。

        * 出路是**奇异函数**（如冲激）：正因引入了它们，周期信号、阶跃信号、符号函数等虽不能用定义去做，却能用其他方法求出傅里叶变换——周期信号也可以做傅里叶变换。

## 频域视角的价值

    * **复杂波形与简单频谱**

        * 波形弯绕叠加、肉眼看不出规律的信号，表达式可能极简单，如 $f(t)=\sin 2t+\sin 3t$：频域上只有 $\omega=2$、$\omega=3$ 两根谱线，幅度均为 $1$、相位均为 $-\frac{\pi}{2}$（因 $\sin t=\cos\left(t-\frac{\pi}{2}\right)$）——看着谱线图，表达式张口就来。

        * 剔除某一频率分量在频域极易实现：去掉对应那根谱线即可；在时域从波形里剔除 $\sin 3t$ 这一部分则很难。

    * **卷积化为乘法**

        * 时域卷积是较复杂的积分；在频域，卷积积分变成**乘法**（卷积定理，后续内容）——这是频域分析的又一大便利。

## 用定义求常见信号的傅里叶变换

    * **冲激函数 $\delta(t)$**

        * 利用取样性质 $\delta(t)f(t)=f(0)\delta(t)$，$e^{-\mathrm{j}\omega t}$ 被取样成 $e^{0}=1$，积分剩 $\delta(t)$ 的面积 $1$。

        * > **定义**：$\delta(t)\leftrightarrow 1$——频谱密度在 $(-\infty,+\infty)$ 区间处处相等，称**白色频谱**（一条高度为 $1$ 的水平线）。

    * **冲激偶 $\delta'(t)$**

        * 用到的性质：$\displaystyle\int_{-\infty}^{+\infty}f(t)\,\delta'(t)\,\mathrm{d}t=-f'(0)$——对 $e^{-\mathrm{j}\omega t}$ 求导得 $-\mathrm{j}\omega e^{-\mathrm{j}\omega t}$，代 $t=0$ 再带外面的负号，负负得正。

        * > **定义**：$\delta'(t)\leftrightarrow \mathrm{j}\omega$。

        * 冲激偶不如冲激常用，但其性质考前要记；它的价值还在于：信号求导可写成与 $\delta'(t)$ 卷积，由卷积定理得到 $\mathrm{j}\omega F(\omega)$，即时域微分性质。

    * **门函数（矩形脉冲，$g_{\tau}(t)$）**

        * > **定义**：$g_{\tau}(t)=\begin{cases}1,&|t|<\frac{\tau}{2}\\ 0,&|t|>\frac{\tau}{2}\end{cases}$，宽度 $\tau$、幅度 $1$ 的"门"。

        * 定义式积分限从 $(-\infty,+\infty)$ 缩为 $[-\frac{\tau}{2},\frac{\tau}{2}]$（为零的部分积分为零），对指数积分并用欧拉公式凑 $\sin$：

        * $$F(\omega)=\frac{2\sin(\omega\tau/2)}{\omega}=\tau\,\mathrm{Sa}\!\left(\frac{\omega\tau}{2}\right)$$

        * 凑成 Sa 形式的目的：$\mathrm{Sa}$ 函数图像非常有特征，把频谱画成 Sa 的形式非常利于作图；凑法是给 $\sin(\omega\tau/2)$ 配分母 $\frac{\omega\tau}{2}$，分子同乘补回。

        * 画频谱抓两点——**幅度**：$\mathrm{Sa}(0)=1$，峰值 $F(0)=\tau$；**零点**：$\frac{\omega\tau}{2}=m\pi\ (m=\pm1,\pm2,\dots)$，$m$ 不取 $0$（$\mathrm{Sa}(0)=1$ 不是零），第一零点 $\omega=\dfrac{2\pi}{\tau}$，往后依次 $\frac{4\pi}{\tau},\frac{6\pi}{\tau},\dots$，$\mathrm{Sa}$ 是偶函数，两边对称，旁瓣正负交替、逐级变小。

```text
F(w)
  tau ---.
        |\      /|\      /|
        | \    / | \    / |
        |  \  /  |  \  /  |
      0 +---\/---+---\/---+-----+---> w
         -4p/t -2p/t  0  2p/t 4p/t    (p = pi, t = tau)
```

        * 频带宽度：能量集中在 $-\frac{2\pi}{\tau}\sim\frac{2\pi}{\tau}$（只看正频率为 $0\sim\frac{2\pi}{\tau}$，化成频率 $f$ 单位即 $0\sim\frac{1}{\tau}$）；**从零频率到第一个零点所在频率之间的频段**定义为信号的频带宽度，门函数 $B=\dfrac{1}{\tau}$。

        * > **易错点** ⚠️：时域脉冲宽度与频带宽度成反比——$\tau$ 越窄 $B=\frac{1}{\tau}$ 越宽，$\tau$ 越大带宽越小，这一条要记牢。

    * **单边指数信号 $e^{-at}u(t)\ (a>0)$**

        * $u(t)$ 把积分限缩到 $(0,+\infty)$，两个指数合并：$F(\omega)=\displaystyle\int_0^{+\infty}e^{-(a+\mathrm{j}\omega)t}\mathrm{d}t$；$t\to+\infty$ 处 $e^{-at}\to 0$ 乘上模恒为 $1$ 的旋转矢量 $e^{-\mathrm{j}\omega t}$ 仍趋于 $0$。

        * > **定义**：$e^{-at}u(t)\leftrightarrow\dfrac{1}{a+\mathrm{j}\omega}\quad(a>0)$——$a>0$ 保证衰减趋势；这是前面几种结果里**第一次出现复数**，幅度谱与相位谱必须分开画。

        * 模与相位：$|F(\omega)|=\dfrac{1}{\sqrt{a^{2}+\omega^{2}}}$（偶函数，$\omega=0$ 处取最大值 $\frac{1}{a}$，随 $|\omega|$ 增大一直减小）；$\varphi(\omega)=-\arctan\dfrac{\omega}{a}$（奇函数，S 形，两边趋于 $\mp\frac{\pi}{2}$，$\frac{1}{a}$ 与 $1$ 谁大不确定、压缩扩展都可能，画趋势并标上 $\pm\frac{\pi}{2}$ 即满分）。

        * 画频谱的方法论：先判断 $\omega$ 的整体趋势（$\omega$ 在分母则越大越小，在指数上则越大越大），再抓**关键点**——极值点与 $\omega=0$、$\omega\to\pm\infty$ 的取值；不要求精细，但不能乱画。

    * **双边指数信号 $e^{-a|t|}\ (a>0)$**

        * > **易错点** ⚠️：双边不是把 $u(t)$ 去掉那么简单——$e^{-at}$ 直接铺到负半轴，$t\to-\infty$ 发散，面积无穷大，**不绝对可积**，不满足变换存在条件。

        * 正确构造：$f(t)=e^{-a|t|}=\begin{cases}e^{-at},&t>0\\ e^{\ \,at},&t<0\end{cases}$，用一个绝对值完成分段，两侧都衰减、绝对可积。

        * 分段积分合并：$F(\omega)=\dfrac{1}{a+\mathrm{j}\omega}+\dfrac{1}{a-\mathrm{j}\omega}=\dfrac{2a}{a^{2}+\omega^{2}}$——结果为实函数，频谱为偶函数，$\omega=0$ 处峰值 $\dfrac{2}{a}$，随 $|\omega|$ 增大趋于 $0$。

    * **符号函数 $\operatorname{sgn}(t)$**

        * > **定义**：$t<0$ 取 $-1$、$t>0$ 取 $+1$、$t=0$ 取 $0$（有的教材 $t=0$ 处也定义为 $1$，单点取值不重要，图像就是一负一正两个台阶）。

        * 不绝对可积（负半轴翻上去面积无穷大），**不能直接用定义**，改用极限技巧。

        * 构造替身 $f_1(t)=\begin{cases}-e^{\ \,at},&t<0\\ e^{-at},&t>0\end{cases}(a>0)$：把双边指数的左边翻下去；它绝对可积（翻上去就是双边指数）。参数 $a$ 代表衰减快慢——$a$ 越大衰减越快、越小越慢；$a\to 0^{+}$ 时衰减慢到看不出，极限就是 $\operatorname{sgn}(t)$：$\operatorname{sgn}(t)=\lim\limits_{a\to 0^{+}}f_1(t)$。

        * 先算 $F_1(\omega)=-\dfrac{1}{a-\mathrm{j}\omega}+\dfrac{1}{a+\mathrm{j}\omega}=\dfrac{-2\mathrm{j}\omega}{a^{2}+\omega^{2}}$，再取极限得：

        * > **定义**：$\operatorname{sgn}(t)\leftrightarrow\dfrac{2}{\mathrm{j}\omega}$（过程中默认 $\omega\neq 0$；$\omega=0$ 时"0 比无穷小"极限为零，此处不予考虑）。

        * 幅度与相位：$\dfrac{1}{\mathrm{j}}=-\mathrm{j}=e^{-\mathrm{j}\pi/2}$，拆出幅度 $\frac{2}{\omega}$、相位 $-\frac{\pi}{2}$；但 $\omega<0$ 时幅度为负不合要求，须给相位**加 $\pi$**（不能减 $\pi$，相位要保持在 $-\pi\sim\pi$）补偿符号翻转。

        * 结果：$|F(\omega)|=\dfrac{2}{|\omega|}$（偶函数，$\omega\to 0$ 趋于无穷大）；$\varphi(\omega)=\begin{cases}\frac{\pi}{2},&\omega<0\\ -\frac{\pi}{2},&\omega>0\end{cases}$（两段水平线）。

        * > **易错点** ⚠️：$\sqrt{\omega^{2}}=|\omega|$ 而不是 $\omega$——$\omega$ 可正可负，$(-2)^2$ 开根号还是 $2$。

        * 复数快速求相角公式在此**不适用**：其前提 $ac+bd>0$，此处 $ac+bd=-2\omega$ 并非恒正，相位须自己按 $\omega>0$、$\omega<0$ 分别看。

## 复数快速求模与相角

    * **公式（针对分式复数 $\dfrac{a+\mathrm{j}b}{c+\mathrm{j}d}$）**

        * $$\left|\frac{a+\mathrm{j}b}{c+\mathrm{j}d}\right|=\frac{\sqrt{a^{2}+b^{2}}}{\sqrt{c^{2}+d^{2}}},\qquad \varphi=\arctan\frac{bc-ad}{ac+bd}\ \ \big(ac+bd>0\big)$$

        * 相位公式较难记但值得记；相比"分子分母同乘共轭、平方差化实、拆实虚、套第一章公式"的常规流程，计算量小得多。

    * **推导要点**

        * 分子分母同乘 $c-\mathrm{j}d$，分母变实数 $c^{2}+d^{2}$，分子展开为 $(ac+bd)+\mathrm{j}(bc-ad)$（$a\cdot c$ 与 $\mathrm{j}b\cdot(-\mathrm{j}d)=+bd$ 是实的，$\mathrm{j}bc$ 与 $-\mathrm{j}ad$ 是虚的）。

        * 模：分子平方和 $(ac+bd)^2+(bc-ad)^2$ 展开后交叉项 $2abcd$ 一正一负抵消，归并成 $(a^{2}+b^{2})(c^{2}+d^{2})$，与分母约分即得结论。

        * 相位：实部为 $\frac{ac+bd}{c^{2}+d^{2}}$，分母恒正，故只看 $ac+bd$ 的符号；第一章的相位公式分十种情况，这里只覆盖**实部大于零**这一最简单情形。

        * > **注意**：使用前先验证 $ac+bd>0$——多数题目满足（如 $\frac{1}{a+\mathrm{j}\omega}$：$b=0$，$ac=1\cdot a>0$），但不满足时不能硬套。

## 常用傅里叶变换对总表

    * **记表策略**

        * 重要条目做题多了自然记住；**冷门条目反而是变相的重点**——平时遇得少、忘的概率大，要专门花时间记。

        * 所有条目都建议抄进公式小本、平时翻看，而不是指望考场现场推：推导要花时间，高度紧张的环境下可能忘了怎么推。

        * 求一个信号变换的两样武器：**常用信号变换对 + 傅里叶变换的性质**，两者配合拼出结果；性质按教材记即可。

    * **总表**

| 时域信号 | 傅里叶变换 | 记忆提示 |
| :--- | :--- | :--- |
| $\delta(t)$ | $1$ | 很重要，好记；白色频谱 |
| $\delta'(t)$ | $\mathrm{j}\omega$ | 求导 $=$ 与 $\delta'(t)$ 卷积 |
| $u(t)$ | $\pi\delta(\omega)+\dfrac{1}{\mathrm{j}\omega}$ | 重要，稍难记 |
| $t\,u(t)$ | $\mathrm{j}\pi\delta'(\omega)-\dfrac{1}{\omega^{2}}$ | 可由频域微分推，仍建议记 |
| 常数 $c$ | $2\pi c\,\delta(\omega)$ | 很重要，好记 |
| $\operatorname{sgn}(t)$ | $\dfrac{2}{\mathrm{j}\omega}$ | 好记 |
| $e^{-at}u(t)$ | $\dfrac{1}{a+\mathrm{j}\omega}\ (a>0)$ | 重要；拉氏变换里更重要 |
| $e^{-a\lvert t\rvert}$ | $\dfrac{2a}{a^{2}+\omega^{2}}$ | 冷门反而要记 |
| $e^{\mathrm{j}\omega_0 t}$ | $2\pi\delta(\omega-\omega_0)$ | 很重要 |
| $\cos\omega_0 t$ | $\pi\delta(\omega+\omega_0)+\pi\delta(\omega-\omega_0)$ | $\pm\omega_0$ 处冲激、强度 $\pi$；使用频率相当高 |
| $\sin\omega_0 t$ | $\mathrm{j}\pi\delta(\omega+\omega_0)-\mathrm{j}\pi\delta(\omega-\omega_0)$ | 带 $\mathrm{j}$，有相位 |
| $\cos(\omega_0 t+\varphi)$ | $\pi\left[e^{\mathrm{j}\varphi}\delta(\omega-\omega_0)+e^{-\mathrm{j}\varphi}\delta(\omega+\omega_0)\right]$ | 可不背，欧拉/频移可推 |
| $\sin(\omega_0 t+\varphi)$ | $\mathrm{j}\pi\left[e^{-\mathrm{j}\varphi}\delta(\omega+\omega_0)-e^{\mathrm{j}\varphi}\delta(\omega-\omega_0)\right]$ | 相位与 $\cos$ 反过来 |
| $g_{\tau}(t)$ | $\tau\operatorname{Sa}\!\left(\dfrac{\omega\tau}{2}\right)$ | 很重要，多次使用 |
| 三角脉冲（底 $\tau$、高 $1$） | $\dfrac{\tau}{2}\operatorname{Sa}^{2}\!\left(\dfrac{\omega\tau}{4}\right)$ | 宽度与参数要配平 |
| $\operatorname{Sa}(at)$ | 幅度 $\dfrac{\pi}{a}$、宽度 $2a$ 的门函数 | 对称性反推 |
| $\operatorname{Sa}^{2}(at)$ | 幅度 $\dfrac{\pi}{a}$、宽度 $4a$ 的三角脉冲 | 三角比矩形宽一倍 |

    * **带相位正余弦的推导**

        * 还是欧拉公式，只多一个常数相位因子：每个冲激后面多乘一个 $e^{\pm\mathrm{j}\varphi}$，$\sin$ 一边相位再反过来多乘 $\mathrm{j}$。

        * 记熟不带相位的两条后，带相位的用频移性质一推就出，可以不单独背。

    * **正余弦频谱的对比**

        * $\cos$：$\pm\omega_0$ 处各一个冲激，强度都是 $\pi$，"标准"无相位。

        * $\sin$：$\pm\omega_0$ 处也是两个冲激，但 $+\omega_0$ 处为正、$-\omega_0$ 处为负，且整体乘 $\mathrm{j}$——携带相位，不像 $\cos$ 那样标准。

    * **三角脉冲易错**

        * > **易错点** ⚠️：总底宽 $\tau$（两边各 $\tau/2$）、高 $1$ 的三角对应 $\frac{\tau}{2}\operatorname{Sa}^{2}\left(\frac{\omega\tau}{4}\right)$；若总底宽取 $2\tau$，对应的才是 $\tau\operatorname{Sa}^{2}\left(\frac{\omega\tau}{2}\right)$。宽度与参数必须配平，差一倍就全错。

        * 三角可看成两个门卷出来的，能自己推，但推荐直接记。

    * **对称性反推的两条**

        * "门对应 Sa、三角对应 $\operatorname{Sa}^2$"利用对称性反过来看：$\operatorname{Sa}(at)$ 对应幅度 $\frac{\pi}{a}$、宽度 $2a$ 的门；$\operatorname{Sa}^2(at)$ 对应幅度 $\frac{\pi}{a}$、宽度 $4a$ 的三角——这个三角比对应的矩形宽一倍。

        * $t$ 与 $\frac{1}{t}$ 两条也是由对称性来推；但 $\frac{1}{t}$ 很难想到从"$\operatorname{sgn}(t)\leftrightarrow\frac{2}{\mathrm{j}\omega}$"出发再绕一道对称性，题目单独拿它命题时背过的人占优。

## 傅里叶级数与傅里叶变换的区别

    * **级数是时域等式**

        * 傅里叶级数 $f(t)=\sum F_n e^{\mathrm{j}n\omega_1 t}$ 是**等号**：$f(t)$ 拆成各谐波分量之和，拆开后仍在时域、自变量仍是 $t$；要从频域分析得去画它的频谱。

    * **变换完全进入频域**

        * 傅里叶变换的结果 $F(\omega)$ 是一个以 $\omega$ 为自变量的函数：时域观察 $f(t)$，做完变换就**完全跑到频域**上去了。

## 周期信号的傅里叶变换

    * **为什么可以做**

        * 周期信号可能不满足绝对可积条件，但引入奇异函数（冲激）之后就可以做傅里叶变换。

    * **推导主线（无穷多个冲激的和）**

        * 把周期信号展开为复指数形式的傅里叶级数 $f_T(t)=\sum\limits_{n=-\infty}^{+\infty}F_n e^{\mathrm{j}n\omega_1 t}$，对两边做变换：由线性性质把求和号提到外面；$F_n$ 对 $t$ 而言是常数可提出，但**别提到求和号前面去**（求和变量是 $n$）。

        * 代入 $e^{\mathrm{j}n\omega_1 t}\leftrightarrow 2\pi\delta(\omega-n\omega_1)$（把 $\omega_0$ 换成 $n\omega_1$；$2\pi$ 连 $n$ 都无关，提到最前）：

        * $$\mathcal{F}[f_T(t)]=2\pi\sum_{n=-\infty}^{+\infty}F_n\,\delta(\omega-n\omega_1)$$

        * > **定义**：周期信号的傅里叶变换，就是把它傅里叶级数的各离散谱线位置全部换成冲激，冲激强度等于对应 $F_n$ 乘 $2\pi$——$n=0$ 在原点强度 $2\pi F_0$，$n=\pm1$ 在 $\pm\omega_1$ 强度 $2\pi F_{\pm1}$，依此类推。

```text
   傅里叶级数频谱（离散谱）            对应的傅里叶变换频谱（冲激谱）

     |       |       |               2pF-1     2pF0     2pF1
     |       |       |                 |        |        |
  ---+-------+-------+---+--> w    ---+---+----+---+----+---+---> w
        -w1      0      w1             -w1      0       w1
   (只在 n*w1 处有定义)             (冲激在 n*w1 处，其余处处为零)
```

        * 根本区别：傅里叶变换得到**连续谱**——其他位置幅度为零（不是没有定义）；傅里叶级数得到**离散谱**——只在 $\omega=0,\pm\omega_1,\pm2\omega_1,\dots$ 处有值，其他地方**压根没有定义**。

        * 画图注意：$F_n$ 本身是复数，把强度当"高度"画出来不太标准，但直观。

    * **求 $F_n$ 的捷径：单脉冲的傅里叶变换**

        * 对比两个式子——$F_n=\frac{1}{T_1}\int_{-\frac{T_1}{2}}^{\frac{T_1}{2}}f(t)e^{-\mathrm{j}n\omega_1 t}\mathrm{d}t$ 与单脉冲 $f_0(t)$ 的变换 $F_0(\omega)=\int_{-\frac{T_1}{2}}^{\frac{T_1}{2}}f(t)e^{-\mathrm{j}\omega t}\mathrm{d}t$：被积函数、上下限相同，只差系数 $\frac{1}{T_1}$ 与指数上的 $n\omega_1$ 对 $\omega$。

        * > **定义**：$F_n=\dfrac{1}{T_1}\,F_0(n\omega_1)$——把单脉冲变换里的 $\omega$ 换成 $n\omega_1$ 再除以 $T_1$。

        * 适用判断：周期信号**一个周期的变换好求**时用（如周期矩形脉冲的单脉冲就是门函数）；单脉冲变换不好求就老老实实代定义式——计算量大但步骤固定。

    * **例题：周期矩形脉冲（幅度 $E$、脉宽 $\tau$、周期 $T_1$）**

        * 单脉冲是幅度 $E$、宽度 $\tau$ 的门，由线性性质 $F_0(\omega)=E\tau\operatorname{Sa}\!\left(\dfrac{\omega\tau}{2}\right)$。

        * 求 $F_n$：$F_n=\dfrac{1}{T_1}F_0(n\omega_1)=\dfrac{E\tau}{T_1}\operatorname{Sa}\!\left(\dfrac{n\omega_1\tau}{2}\right)$——$F_n$ 一出，级数与变换两个全出来。

        * 傅里叶级数：$f(t)=\sum\limits_{n=-\infty}^{+\infty}\dfrac{E\tau}{T_1}\operatorname{Sa}\!\left(\dfrac{n\omega_1\tau}{2}\right)e^{\mathrm{j}n\omega_1 t}$，常数 $\frac{E\tau}{T_1}$ 与谁都没关系，可提至求和号外。

        * 傅里叶变换：$F(\omega)=E\tau\omega_1\sum\limits_{n=-\infty}^{+\infty}\operatorname{Sa}\!\left(\dfrac{n\omega_1\tau}{2}\right)\delta(\omega-n\omega_1)$，其中 $\dfrac{2\pi}{T_1}=\omega_1$；级数谱与变换谱的包络都是抽样函数。

    * **冲激序列 $\delta_T(t)$**

        * > **定义**：$\delta_T(t)=\displaystyle\sum_{n=-\infty}^{+\infty}\delta(t-nT_1)$，每隔 $T_1$ 一个、强度全为 $1$ 的无穷冲激叠加。

        * 单脉冲就是 $\delta(t)$，$F_0(\omega)=1$（没有 $\omega$，怎么换都是 $1$），故 $F_n=\dfrac{1}{T_1}$，代周期信号变换公式得：

        * $$\mathcal{F}[\delta_T(t)]=\omega_1\sum_{n=-\infty}^{+\infty}\delta(\omega-n\omega_1)$$

        * 频域上也是一个冲激序列：间隔变成 $\omega_1$、强度 $\omega_1$。这是总表里提前列出的重点条目。

    * **任意周期函数 $=$ 单脉冲卷冲激序列**

        * > **定义**：任意周期函数都可表示为它的单脉冲信号（一个周期）$f_0(t)$ 与 $\delta_T(t)$ 的**卷积**：$f(t)*\delta_T(t)=\sum\limits_{n=-\infty}^{+\infty}f(t-nT_1)$。

        * 机理：与冲激卷积就是时移，$f(t)*\delta(t-t_0)=f(t-t_0)$——冲激序列里每个冲激把单脉冲搬到自己所在位置（卷原点的是它本身，卷 $T_1$ 处的右移 $T_1$ 得下一周期），无穷多个平移副本按线性相加即还原周期信号。

```text
        f0(t)          *          dT(t)          =       周期矩形脉冲

          ___                    ^     ^     ^              ___     ___     ___
         |   |                   |     |     |             |   |   |   |   |   |
  -------+   +-----...    -------+--+--+--+--+--...    ---+---+---+---+---+---+---...--> t
                                 -T1    0    T1                 -T1     0     T1
```

    * **顺着卷积定理再推一步**

        * 对 $f(t)*\delta_T(t)$ 两边做变换：$\mathcal{F}[f(t)*\delta_T(t)]=F(\omega)\cdot\omega_1\sum\limits_{n=-\infty}^{+\infty}\delta(\omega-n\omega_1)$，推到这已够用——任意周期函数的变换 $=$ 单脉冲的 $F(\omega)$ 乘冲激序列的变换。

        * 再用冲激取样性质 $f(\omega)\delta(\omega-\omega_0)=f(\omega_0)\delta(\omega-\omega_0)$ 逐项化简：$F(\omega)$ 乘无穷多项冲激，每项变成 $F(n\omega_1)\delta(\omega-n\omega_1)$——$\delta$ 后面是 $\omega$ 减多少，前面就取 $F(\cdot)$ 在多少处的值（已是常数）：

        * $$F(\omega)\cdot\omega_1\sum_{n=-\infty}^{+\infty}\delta(\omega-n\omega_1)=\omega_1\sum_{n=-\infty}^{+\infty}F(n\omega_1)\,\delta(\omega-n\omega_1)$$

        * 这个式子与 $2\pi\sum F_n\delta(\omega-n\omega_1)$ 是同一结论（两边都是任意周期函数的傅里叶变换）。

        * 推论：只要知道"任意周期函数 $=$ 单脉冲卷 $\delta_T$"，再记住 $\delta_T(t)$ 对应的变换，$2\pi\sum F_n\delta(\omega-n\omega_1)$ 这条公式就都不用单独记，整串可以自己推出来。
