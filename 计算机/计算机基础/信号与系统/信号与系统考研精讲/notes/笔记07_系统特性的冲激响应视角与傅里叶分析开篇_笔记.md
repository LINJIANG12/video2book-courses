# 系统特性的冲激响应视角与傅里叶分析开篇

## 冲激响应视角的总前提

* **线性时不变前提（LTI，Linear Time-Invariant）**

    * > **定义**：第二章的一切系统特性分析都默认系统是线性时不变的，这是整个时域分析的大前提。

    * 线性时不变特性本身没有新的判定方法：要判断一个系统是否线性时不变，仍用第一章的方法。
    * 下面所有用冲激响应 $h(t)$ 判定记忆性、因果性、稳定性的方法，都建立在这个前提之上。

## 无记忆性的冲激响应判定

* **有记忆与无记忆（Memory / Memoryless）**

    * > **定义**：输出仅仅取决于当前时刻的输入，为无记忆；不仅仅取决于当前输入（可能取决于过去或将来），为有记忆。

    * 时刻记号：当前时刻为 $t$，$t-\tau$ 中 $\tau>0$ 是过去时刻，$\tau<0$ 是将来时刻，$\tau=0$ 即当前。例如 $t=0$、$\tau=1$ 时 $t-1=-1$ 为过去；$\tau=-1$ 时 $t-(-1)=1$ 为将来。

* **一般 LTI 系统是有记忆的**

    * 零状态响应是卷积：$r_{zs}(t) = e(t) * h(t) = \int_{-\infty}^{+\infty} e(\tau)\,h(t-\tau)\,d\tau$。
    * 做换元 $t-\tau=u$、再换名 $u\to\tau$，得等价形式 $r_{zs}(t) = \int_{-\infty}^{+\infty} e(t-\tau)\,h(\tau)\,d\tau$。
    * 该式中 $e(t-\tau)$ 遍历过去与将来的输入，输出与过去和将来的输入都有关，所以一般情况下系统有记忆。

* **无记忆的条件：$h(t)=K\delta(t)$**

    * > **定义**：无记忆 LTI 系统的冲激响应必形如 $h(t) = K\,\delta(t)$，$K$ 为非零常数。

    * 机理：当 $\tau\neq 0$ 处 $h(\tau)=0$、仅 $\tau=0$ 处非零时，卷积中除当前输入 $e(t)$ 外的项全为零，输出只取决于当前输入。
    * 只有 $\tau=0$ 处不为零、其余处处为零的函数正是冲激函数；$K$ 的具体取值不影响无记忆性。
    * 此时 $y_{zs}(t) = e(t) * K\delta(t) = K\,e(t)$：输入经过无记忆系统只有幅度变化，没有时移。

    * > **易错点**：$K=0$ 不可取。$h(t)$ 全为零时任何输入的卷积都是零，输出连当前输入都无关了，该情况没有意义，不予讨论。

* **离散情形**

    * 结论完全类似、证明过程完全类似（卷积和换元，只是把积分换成求和）：$h[n] = K\,\delta[n]$，$y_{zs}[n] = K\,x[n]$（$K\neq 0$）。

## 因果性的冲激响应判定

* **因果性（Causality）**

    * > **定义**：输出只取决于现在和过去的输入，则系统因果。

    * 与记忆性的关系：记忆性看输出是否只取决于"现在"，因果性看是否只取决于"现在和过去"，两者证明方法完全类似。
    * 判定条件：令 $\tau<0$ 时 $h(\tau)=0$。因为 $\tau<0$ 时 $t-\tau$ 代表将来时刻，$h$ 在那里为零就把将来的输入全乘成零，输出只剩现在和过去。

* **结论与两种卷积写法**

    * > **定义**：因果系统的冲激响应满足 $h(t) = 0,\quad t < 0$。

    * 此时卷积积分去掉为零的部分：$r_{zs}(t) = \int_{0}^{+\infty} e(t-\tau)\,h(\tau)\,d\tau$。
    * 再换元 $t-\tau=u$ 并整理，得因果系统的另一种等价写法：$r_{zs}(t) = \int_{-\infty}^{t} e(\tau)\,h(t-\tau)\,d\tau$。

* **直观理解与离散情形**

    * 直观：冲激响应的输入 $\delta(t)$ 只在 $t=0$ 处有值；因果系统在输入还没出现的 $t<0$ 时段不该有输出，所以 $h(t)$ 在 $t<0$ 必为零——输入未出现，输出不会先出现。
    * 离散结论：当 $m<0$ 时 $h[m]=0$ 即因果，即 $h[n] = 0,\ n < 0$。
    * **因果信号**：把当 $n<0$（或 $t<0$）时取值为 0 的信号称为因果信号。

## 稳定性的定义与绝对可积判据

* **为什么原定义不好用**

    * > **定义**：系统对任意有界输入，输出都有界，则系统稳定。

    * 判"不稳定"容易：只要找到**一个**有界输入使输出无界即可。
    * 判"稳定"难：找不到无界的反例并不能说明稳定——可能输入存在只是没找到；必须对**所有**有界输入都验证输出有界，这一过程有时非常麻烦，所以需要用冲激响应给出更概括的判据。

* **有界的数学语言**

    * $x(t)$ 有界 $\iff$ 存在正数 $B$，使得对所有的 $t$ 有 $|x(t)|<B$。"任意"对应对所有 $t$ 成立，"有界"对应存在正数 $B$ 包住信号。

* **关键不等式：积分的绝对值不超过绝对值的积分**

    * $\left| \int f(x)\,dx \right| \le \int |f(x)|\,dx$。
    * 直观：积分是面积。信号有正有负时，先积分再取绝对值是正负面积相减（如 $|3-2|=1$），先取绝对值再积分是面积相加（$3+2=5$）；全在横轴上方或下方时两边相等。
    * 证明骨架：由 $-|f(x)| \le f(x) \le |f(x)|$ 三边各自在 $a$ 到 $b$ 上积分（要求上限 $b>$ 下限 $a$），再对积分结果的符号分类讨论：大于零用右半边不等式，小于零用左半边乘 $-1$ 变向，有正有负则分段相加。
    * 复信号推广：实信号读"绝对值"，复信号两杠是模；$\left|\int f\,dx\right| \le \int |f|\,dx$ 对模同样成立。
    * 配套结论：$|a|\cdot|b| = |ab|$，对绝对值和模都成立（对 $ab$ 的正负性讨论即可）。

* **连续系统：绝对可积判据**

    * > **定义**：LTI 系统稳定的充要判断依据是冲激响应绝对可积：$\int_{-\infty}^{+\infty} |h(\tau)|\,d\tau < \infty$。

    * 推导链：对有界输入 $|x(t)|<B$（对所有 $t$），输出 $y(t)=\int_{-\infty}^{+\infty} h(\tau)x(t-\tau)d\tau$ 两边取模，依次用"积分的绝对值 $\le$ 绝对值的积分"、$|a||b|=|ab|$ 拆积、由 $t$ 的任意性得 $|x(t-\tau)|<B$ 把常数提出积分号，得 $|y(t)| < B\int_{-\infty}^{+\infty}|h(\tau)|\,d\tau$。
    * 只要 $\int|h(\tau)|d\tau$ 是有限常数，$B$ 乘它仍是常数，$|y(t)|$ 小于常数即输出有界，系统稳定。
    * 整条链的核心是把 $|y(t)|$ 一路放缩，最后收敛到"$\int|h(\tau)|d\tau$ 是否有限"这一个判据上。

* **离散系统：绝对可和判据**

    * > **定义**：单位样值响应 $h[n]$ 绝对可和，即 $\sum_{k=-\infty}^{+\infty} |h[k]| < \infty$，则系统稳定。

    * 证明与连续完全类似，把积分换成求和，用"和的绝对值小于等于绝对值的和"：$\left| \sum a_i \right| \le \sum |a_i|$。全为正或全为负取等号，有正有负取小于号（如 $|1-2|=1 < 3$）。
    * 复数情形：$x[n]$、$h[n]$ 为复数时两杠是模，$\left| \sum z_i \right| \le \sum |z_i|$ 依然成立。复数含实部虚部，在复平面上用向量表示；两向量首尾相接构成三角形，"和的模"是第三边长，"模的和"是两邻边长之和，三角形两边之和大于第三边；两向量指向同一方向时取等号。

* **例：积分器不稳定**

    * 系统 $y(t) = \int_{-\infty}^{t} x(\tau)\,d\tau$，求冲激响应：令 $x(t)=\delta(t)$，得 $h(t) = \int_{-\infty}^{t} \delta(\tau)\,d\tau = u(t)$（这就是阶跃）。
    * 检验判据：$\int_{-\infty}^{+\infty} |u(t)|\,dt = \int_{0}^{+\infty} 1\,dt = +\infty$，不小于无穷，积分器**不稳定**。

    * > **易错点**：⚠️ 不能凭直觉觉得"积分器很温和所以稳定"，必须老老实实求出 $h(t)$ 代入绝对可积判据检验。

## 反求冲激响应例题

* **题面与思路定向**

    * 已知零状态响应 $y_{zs}(t) = \int_{t-2}^{+\infty} e^{t-\tau} f(\tau - 1)\, d\tau$，求系统的冲激响应 $h(t)$。
    * 常规题是"给 $h(t)$ 和输入求零状态响应"（做卷积）；本题反其道而行，给积分形式的零状态响应反求 $h(t)$。
    * 积分形式是明显的诱导：它与卷积形式相似。卷积有两种写法 $\int_{-\infty}^{+\infty} f(\tau)h(t-\tau)d\tau = \int_{-\infty}^{+\infty} h(\tau)f(t-\tau)d\tau$，应选**第一种**。
    * 选型理由：题目里 $f(\tau-1)$ 与 $f(\tau)$ 相像，与 $f(t-\tau)$ 不像；而 $e^{t-\tau}$ 正好带 $h(t-\tau)$ 需要的 $t-\tau$ 结构。

* **第一步换元：把 $f(\tau-1)$ 变成 $f(x)$**

    * 令 $\tau-1=x$，即 $\tau=x+1$，逐项替换：$f(\tau-1)\to f(x)$；$e^{t-\tau}\to e^{t-x-1}$；$d\tau\to dx$（$d(x+1)$ 中的常数不写）；下限 $\tau=t-2\to x=t-3$，上限 $+\infty$ 仍为 $+\infty$。
    * 得 $y_{zs}(t) = \int_{t-3}^{+\infty} e^{t-x-1} f(x)\, dx$，积分变量字母不同（$x$ 与卷积式的 $\tau$）无妨。

* **第二步请出阶跃：把下限改成负无穷**

    * 给被积函数乘"开关"：在 $x<t-3$ 段乘零、$x>t-3$ 段乘一，则负无穷到 $t-3$ 的积分贡献恒为零，下限可改成 $-\infty$ 而积分结果不变。
    * 能做到"左边为零、右边为一"的是阶跃信号：$u\big(x-(t-3)\big)$。注意积分变量是 $x$，$t-3$ 可视为常数；$x>t-3$ 时括号为正 $u$ 取一，$x<t-3$ 时括号为负 $u$ 取零。
    * 得 $y_{zs}(t) = \int_{-\infty}^{+\infty} e^{t-x-1} f(x)\, u\big(x-t+3\big)\, dx$。

* **第三步对照卷积定义，读出 $h(t)$**

    * 把括号整理成 $t-x$ 结构：$x-t+3 = 3-(t-x)$，得 $y_{zs}(t) = \int_{-\infty}^{+\infty} e^{t-\tau-1} f(\tau)\, u\big(3-(t-\tau)\big)\, d\tau$（$x$ 换回 $\tau$ 亦可）。
    * 对照 $f(t)*h(t) = \int_{-\infty}^{+\infty} f(\tau)\,h(t-\tau)\,d\tau$，$h(t-\tau)$ 对应剩余部分，把 $t-\tau$ 换成 $t$ 得：

    $$h(t) = e^{t-1}\, u(3-t)$$

* **暴力解法：直接令 $f(t)=\delta(t)$**

    * 冲激响应的本质是输入为 $\delta(t)$ 时的零状态响应；零状态响应表达式已给定，令 $f(\tau-1)\to\delta(\tau-1)$：

    $$h(t) = \int_{t-2}^{+\infty} e^{t-\tau}\, \delta(\tau-1)\, d\tau$$

    * 用冲激信号的取样性质 $f(t)\,\delta(t-t_0) = f(t_0)\,\delta(t-t_0)$：积分变量是 $\tau$，$t$ 当常数，故 $e^{t-\tau}\delta(\tau-1) = e^{t-1}\delta(\tau-1)$，$e^{t-1}$ 提到积分外。
    * 余下积分按范围讨论：$\delta(\tau-1)$ 只在 $\tau=1$ 处有面积为一的冲激；$t-2<1$（即 $t<3$）时范围含 $\tau=1$，积分为 $1$；$t>3$ 时冲激在范围外，积分为 $0$。
    * "在 t<3 时为 1、在 t>3 时为 0" 正是阶跃 $u(3-t)$，于是 $h(t) = e^{t-1}\, u(3-t)$，与第一种方法殊途同归。

    * > **易错点**：⚠️ 取样时千万别被表象迷惑——积分变量是 $\tau$ 不是 $t$，是把 $\tau$ 换成 $1$ 得 $e^{t-1}$，不是把 $t$ 换成 $1$。

    * > **易错点**：⚠️ 这里阶跃方向与传统的相反（传统是 $t$ 大于某值为 $1$），必须把 $t$ 改成 $-t$ 再加常数 $3$ 写成 $u(3-t)$ 才能得到想要的效果。

## 过渡之章的知识归拢

* **第二章核心概念**

    * 零输入响应、零状态响应、冲激响应 $h(t)$：出现频率非常高，基本上每张卷子都会遇到；概念不难但很重要。
    * 响应分类：强迫响应、自由响应、瞬态响应、稳态响应，定义简单，有时要求求解，必须清楚含义与求法。
    * **卷积**是这一章的主角：性质、定义、常用卷积结论、图解法都要掌握；输入 $f(t)$ 卷上冲激响应 $h(t)$ 得零状态响应、全响应。

* **微分方程与差分方程**

    * 信号与系统里微分方程的解法与数学中略有不同：多了 $0_-$ 到 $0_+$ 的跳变，求跳变用**冲激函数匹配法**，过程程序化、套路化，并不难。
    * 但此法用得不多：微分方程后面可用拉氏变换解决，差分方程可用 $z$ 变换解决，变换域方法更常用。

* **系统特性的第二次讨论**

    * 因果性、稳定性等第一章的性质，在引入冲激响应后做了第二次讨论；用 $h(t)$ 判定有时更简单、更有效。

## 傅里叶分析总览

* **课程定位**

    * 第三章傅里叶分析是整门课的高潮：重点也是难点，学得好坏直接决定能否考高分，是拉开分差的地方。
    * 三部分内容：**傅里叶级数**（看起来难其实不难，计算量大，重要性相对低）、**傅里叶变换**（重点之中的重点，确实有难度）、**通信系统的应用**（通过傅里叶变换解决，常作为试卷最后一道大题）。

## 特征函数与特征值

* **连续：$e^{st}$ 过 LTI 系统**

    * 让复指数信号 $e^{st}$ 经过冲激响应为 $h(t)$ 的 LTI 系统，零状态响应为卷积 $y(t) = \int_{-\infty}^{+\infty} h(\tau)\, e^{s(t-\tau)}\, d\tau$（$h$ 的 $t$ 换成 $\tau$，输入的 $t$ 换成 $t-\tau$）。
    * $e^{st}$ 对积分变量 $\tau$ 是常数，提出积分号：$y(t) = e^{st} \int_{-\infty}^{+\infty} h(\tau)\, e^{-s\tau}\, d\tau$。
    * 右边积分积完 $\tau$ 消失、只剩 $s$，是以 $s$ 为变量的函数，记 $H(s) = \int_{-\infty}^{+\infty} h(\tau)\, e^{-s\tau}\, d\tau$（须假定收敛），于是 $y(t) = H(s)\, e^{st}$。

* **概念与要点**

    * > **定义**：$e^{st}$ 称为特征函数；给定 $s$ 后 $H(s)$ 成为复常数，是与 $e^{st}$ 对应的特征值。

    * $H(s)$ 对 $t$ 而言可看成常数，其值取决于 $s$；$s$ 是**复数**，这点不要忽略。
    * 一切操作的大前提是 LTI 系统。

* **离散：$z^n$ 过系统**

    * 离散的复指数信号是复指数序列 $z^n$（$z$ 为复数）；$a^n$ 才是普通指数序列，把 $a$ 换成复数即复指数序列，与连续的 $e^{st}$ 本质一样，只是习惯写法不同。
    * 经过单位脉冲响应为 $h(n)$ 的系统，卷积变卷积和：$y(n) = \sum_{k=-\infty}^{+\infty} h(k)\, z^{n-k} = z^n \sum_{k=-\infty}^{+\infty} h(k)\, z^{-k} = H(z)\, z^n$（$z^n$ 与 $k$ 无关可提出，求和完剩 $z$，同样假定收敛）。
    * $z^n$ 是特征函数，$H(z)$ 是与 $n$ 无关的特征值。

* **连续与离散对照**

    | | 连续系统 | 离散系统 |
    | :---: | :---: | :---: |
    | 输入信号（特征函数） | $e^{st}$ | $z^n$ |
    | 输出（零状态响应） | $H(s)\, e^{st}$ | $H(z)\, z^n$ |
    | 特征值 | $H(s)$（与 $t$ 无关的复常数） | $H(z)$（与 $n$ 无关的复常数） |

    * 只要 $H(s)$、$H(z)$ 好求，求输出只需把输入乘上对应的特征值即可。

* **过渡到第三章：$s=j\omega$**

    * 第三章仅讨论 $s$ 为纯虚数的情况，即 $s = j\omega$（实部为零），此时 $y(t) = H(j\omega)\, e^{j\omega t}$。
    * 有的教材写 $H(j\omega)$，有的写 $H(\omega)$，两者一样，因为 $j\omega$ 是一个常数。

## 从欧拉公式到傅里叶的断言

* **特征函数结论的局限**

    * 推导要求输入是复指数信号（或复指数序列），要求苛刻、适用面窄。
    * 三角信号可以用：欧拉公式 $\cos\omega t = \frac{1}{2}\left(e^{j\omega t} + e^{-j\omega t}\right)$ 表明 $\cos\omega t$ 是复指数信号的组合；每个复指数分量用上述结论，再由**线性**即得 $\cos\omega t$ 的输出。

* **核心问题与傅里叶断言**

    * 呼之欲出的问题：**什么信号能用复指数信号叠加表示？**
    * > **定义**：傅里叶断言——任何周期信号都能由无穷多的正弦信号叠加表示。

    * 正弦可表示则余弦亦可（只差一个相位）；能由无穷多正弦叠加表示，则由欧拉公式也能由无穷多复指数叠加表示。

## 傅里叶、拉格朗日与狄利克雷

* **论文风波**

    * 傅里叶在论文《热的理论》中首次提出该结论（他当时研究热学）；审稿人有拉普拉斯和拉格朗日，前者赞成，后者反对。
    * 拉格朗日的质疑："我亲爱的傅里叶，你将如何用正弦信号去表示一个有棱角的信号呢？"傅里叶被问住，加上拉格朗日威望极高，论文被拒收。
    * 几年后傅里叶把傅里叶级数推广到非周期信号，即傅里叶变换；拉格朗日仍以"不够严格和普遍"为由阻挠，文章仍未顺利发表。
    * 拉格朗日与傅里叶曾是**师生关系**。

* **理论的完善**

    * 傅里叶的理论伟大但确有不完备之处；**争论总能推动理论的发展**——多年后狄利克雷提出**狄利克雷条件**，完善了傅里叶级数的理论，解决了拉格朗日的问题。
    * 轶事：傅里叶痴迷热学、相信热能包治百病，大热天紧闭门窗烤火炉，最终因此丧命；他与拿破仑也有交集，可查阅相关科学史。
