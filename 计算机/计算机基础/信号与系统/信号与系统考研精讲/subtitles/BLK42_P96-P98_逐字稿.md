接下来看第四部分，理想低通滤波器。

理想低通滤波器它的系统函数表达式就是：

$$H(\omega) = \begin{cases} e^{-j\omega t_0}, & |\omega| \le \omega_c \\ 0, & |\omega| > \omega_c \end{cases}$$

它的幅度特性和相位特性就是这两张图。

试想如果一个信号 $f(t)$ 它的频谱 $F(\omega)$，我们这里随便画一下，比如 $F(\omega)$ 这样。$F(\omega)$ 与 $H(\omega)$ 相乘，显然如果 $|\omega| > \omega_c$ 的话，它们两个相乘结果就为 0，因为这里为 0，0 与任何数相乘都为 0。所以它们两个相乘的话，就会相当于把这里 $|\omega| > \omega_c$ 的部分都化为 0，这一部分和这一部分就相当于没有了，截断了。而剩下的这一部分，也就是 $|\omega| < \omega_c$ 的这一部分和它相乘，幅度没有变化，但是相位是有变化的。

而这个相位是什么呢？这个相位大家熟不熟悉？我们刚说过，它是无失真传输的相位条件。所以理想低通滤波器的作用就是将角频率低于 $\omega_c$ 的信号无失真地传输。可以看到这里的幅度就是一个常数，而且是 1，也就是没有变化；相位也是满足无失真传输的一个条件。而高于 $\omega_c$ 的直接就变为 0 了，因为 $H(\omega)$ 当 $|\omega| > \omega_c$ 的时候它是为 0 的，所以与 $F(\omega)$ 一乘直接也为 0，完全滤掉了，变为 0 了。

其实理想低通滤波器它的幅度特性就是一个门函数，不过它多了一个相位，所以 $H(\omega)$ 我们也可以给它表示成一个频域的门函数再乘上一个相位，就是：

$$H(\omega) = e^{-j\omega t_0} g_{2\omega_c}(\omega)$$

它的宽度是 $2\omega_c$，所以 $H(\omega)$ 我们也可以这么表示。这里还要注意一点，我们这个 $\phi(\omega)$ 它是 $-\omega t_0$。$t_0$ 是可以为 0 的，如果说 $t_0$ 为 0，那 $\phi(\omega)$ 它就是 0，其实 $H(\omega)$ 就是这样的一个门函数。$\phi(\omega) = 0$ 其实也相当于在时域上是没有时移的，因为时移会带来相位的改变。

所以之前我们在讲抽样信号的时候，说将一个抽样信号的频谱还原成原信号的频谱，当时说是在这里加了一个门函数，其实也可以说在这里加一个理想低通滤波器。

现在我们知道了它的频域特性，那它时域是什么样的呢？我们也可以来求一求。我们就可以根据这个来求，因为门函数它的傅里叶逆变换是我们所熟知的。我们对 $H(\omega)$ 求一个傅里叶逆变换，那就等于对 $e^{-j\omega t_0} g_{2\omega_c}(\omega)$ 做傅里叶逆变换。

我们这里就要用到这对经典的傅里叶变换对，就是取样函数（$\text{Sa}$ 函数）它的傅里叶变换是门函数：

$$\text{Sa}(at) \leftrightarrow \frac{\pi}{a} g_{2a}(\omega)$$

我们这里是 $g_{2\omega_c}(\omega)$，所以把这里的 $a$ 换成 $\omega_c$ 即可。当然前面还有一个 $\frac{\pi}{a}$，我们得凑出来一个 $\frac{\pi}{a}$，这里就是 $\frac{\pi}{\omega_c}$。你不能无缘无故多出来一个 $\frac{\pi}{\omega_c}$，前面还得乘上一个 $\frac{\omega_c}{\pi}$，这样的话它们两个相乘就是 1 了。

而这一部分它的傅里叶逆变换就是 $\text{Sa}(\omega_c t)$，前面这一部分它只不过是一个常数而已，所以它的傅里叶逆变换就是 $\frac{\omega_c}{\pi} \text{Sa}(\omega_c t)$。但别忘了前面还有一个 $e^{-j\omega t_0}$。为什么这个没有处理，也没有做一个傅里叶逆变换呢？因为我们知道这样的一个性质：一个信号在时域上时移，就是 $f(t)$ 变成 $f(t - t_0)$，在频域上 $F(\omega)$ 就是相当于乘上一个 $e^{-j\omega t_0}$。所以在频域上乘上一个它，我们只需要在时域上把 $t$ 换成 $t - t_0$ 即可。

所以得到：

$$h(t) = \frac{\omega_c}{\pi} \text{Sa}[\omega_c (t - t_0)]$$

这样我们就得到了它的一个冲激响应。

我们大概地画一下这个 $h(t)$，这就相当于对 $\text{Sa}$ 函数进行一个时延。$\text{Sa}$ 函数本来应该是在中间的，因为它进行了一个时延，所以它的中心应该是在大于 0 的这一部分。它大概的一个波形就是这样。

这里就有一点值得注意的地方：我们说对于一个因果信号/因果系统，要求 $t < 0$ 的时候 $h(t)$ 它都得是等于 0 的。我们这里 $h(t)$ 显然不满足这个条件，所以说这并不是一个因果信号。我们知道冲激信号它是在 $t = 0$ 时刻接入的，这就相当于我还没有接入冲激信号，就已经有了一个冲激响应 $h(t)$ 了。这在现实中显然是不可能实现的，非因果信号在现实中是不可能实现的。

所以小节的标题大家不要忘了，它是“理想低通滤波器”。什么是理想？“理想”这两个字就是我们现实中其实是实现不了的。但是理论上我们需要它，在理论分析上我们需要它，但现实中它是不能实现的，这是要注意的一点。当然不是说你个人的理想实现不了，不是这个意思，就是“理想”这个名词它指的是现实是实现不了的，不是说梦想那个理想。

我们这里说的是低通滤波器，低通滤波器就是让频率比较低的信息通过，频率比较高的就变为 0。借此机会我们再介绍一下其他种类的滤波器：

比如说带通滤波器。它是能只让一个频率范围之内的信号通过，其他地方都为 0。比如说这里是 $\omega_1$，这里是 $\omega_2$，它只让 $\omega_1 < |\omega| < \omega_2$ 这样一段频率区间的信号通过，其他地方都为 0，所以这个叫带通滤波器。

如果是这样的一个滤波器，这些地方都为 0，这里是一个 $\omega_c$，这里是一个 $-\omega_c$。它只让 $|\omega| > \omega_c$ 的信号通过，其他地方都为 0，那就只让高频分量通过，低频都为 0，所以这个是高通滤波器。

最后，频率比较低的也能通过，频率比较高的也能通过，但就这一段通过不了，此时我们叫做带阻滤波器。

顺便也介绍了这几种滤波器的种类。在题干中可能也会介绍，说一个信号经过带通滤波器、经过高通滤波器什么的，简单知道这几个词是什么意思。
