接下来修正弦稳态响应。这部分我们之前在第四章也说过，离散的这块和连续这块的结论是非常类似的。

我们这里看一下，若输入是正弦序列 $A \sin(n\omega_0 + \varphi)$，则因果稳定系统的稳态响应（我们所讨论的系统大多都是因果稳定系统），它的稳态响应就是正弦序列，就是我们原来这个序列它的幅度乘上 $|H(e^{j\omega_0})|$。那这个就是频率响应的一个模，但是这里注意，我们 $\omega$ 是等于 $\omega_0$ 的。然后这里相位也加上频率响应的相位，注意这里 $\omega$ 它也是变成 $\omega_0$ 了。这里和我们之前第四章那个结论非常地类似。

这里我们的输入，这个正弦序列它是 $A \sin(n\omega_0 + \varphi)$，后面是有 $u(n)$ 的。如果说把这个 $u(n)$ 去掉，这个结论依然是成立的。但是注意，此时我们不但是稳态响应，它还是零状态响应。

上面这个结论的证明方法和我们第三章哪里的证明方法是类似的？我们第三章也讲过一个系统对正弦信号的一个响应。上面这个结论的证明方法和我们第四章正弦稳态响应那里的证明方法是类似的。这两个结论我想我就不证明了吧，证明的话有点啰嗦了。

同学们只要把这两个结论记住就行。这个结论和我们前面是很类似的，所以记起来是很容的。所以这里不管我们输入正弦序列它带不带 $u(n)$，它的输出都是它的模乘上频率响应的模，然后 $\omega$ 是 $\omega_0$；相位加上频率响应的相位，然后这里 $\omega$ 也是 $\omega_0$。

我们具体地看一个例子。看这个例题，已知因果系统的系统函数为 $H(z) = 0.5 + 0.5z^{-1}$。其实这个 $H(z)$ 我们之前研究过，我们之前讲频率响应的时候举的例题，它的 $H(z)$ 就是这个，我们当时还画出了它的幅频特性曲线和相频特性曲线。现在若输入 $x(n) = 5\cos(\frac{n\pi}{2})$，这就是一个正弦序列。这里虽然是余弦，但我们知道正弦和余弦只有一个相位的差别。然后求系统的稳态响应 $y_{ss}(n)$。

这里其实是第二种情况，这个稳态响应其实它也就是零状态响应，因为我们这个零状态响应它全部都是稳态响应，所以这两个都可以。

那我们就求一下，求哪个？就求一下这个 $|H(e^{j\omega_0})|$ 和 $\varphi(\omega_0)$ 即可。虽然我们之前已经画出了它的幅频特性曲线和相频特性曲线，但是我们具体做的时候不用去画幅频特性曲线和相频特性曲线，因为我们所研究的只是一点，只是 $\omega_0$ 这一点，而不是整个 $H(e^{j\omega})$。

所以我们这里这个 $\omega_0$ 是谁？这个 $\omega_0$ 就是 $\frac{\pi}{2}$。我们只要算出 $|H(e^{j\frac{\pi}{2}})|$ 和 $\varphi(\frac{\pi}{2})$ 即可。

我们首先要求出 $H(e^{j\omega})$，那就令 $z = e^{j\omega}$ 即可：
$$H(e^{j\omega}) = 0.5 + 0.5e^{-j\omega}$$

我们现在带入 $\omega = \frac{\pi}{2}$，那就是：
$$H(e^{j\frac{\pi}{2}}) = 0.5 + 0.5e^{-j\frac{\pi}{2}}$$
$e^{-j\frac{\pi}{2}}$ 是谁？就是 $-j$，所以这就是 $0.5 - j0.5$。

这样一个复数，我们只要算出它的模和相位，也就求出了它和它；求出它和它，我们这个系统的稳态响应也就求出来了。这个复数的模和相位都很好求。

模就是根号下实部的平方加上虚部的平方：$\sqrt{0.25 + 0.25}$，也就是 $\sqrt{\frac{1}{2}}$，或者写成 $\frac{1}{\sqrt{2}}$，同乘一个 $\sqrt{2}$ 也可以写成 $\frac{\sqrt{2}}{2}$。

然后看相位，相位就是 $\arctan\frac{-0.5}{0.5}$，就是 $\arctan(-1)$，也就是 $-\frac{\pi}{4}$。

所以我们这两个求出来之后，我们就能写出它的稳态响应了。$y_{ss}(n)$ 它就等于这个幅度乘上一个 $\frac{\sqrt{2}}{2}$，这里是 $\frac{5}{2}\sqrt{2}\cos(\frac{n\pi}{2})$，它的相位要减去 $\frac{\pi}{4}$，我们就求出了它的稳态响应。

所以其实很简单的，关键是求幅度和相位，这两个求出来了就搞定了。如果说考场上带计算器的话，千万不要忘了我们可以用计算器处理这个复数，可以看到它的幅度和相位。
