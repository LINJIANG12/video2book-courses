[听音转录 · P125 4.21系统函数H（s）与正弦稳态响应]
> 来源：**听音转录**——非平台字幕，由讲师原声转录

接下来，说系统函数与正弦稳态响应。所谓正弦稳态响应，就是一个正弦信号经过一个系统，它所得到的稳态响应。

其实在第三章，我们也分析过类似的问题，大家还记得吗？就是一个输入信号，比如说输入信号是 $A\cos(\omega t + \phi_0)$，它经过一个系统，我们当时系统函数是 $H(\omega)$，它经过系统得到的一个响应会是什么？就是我们这样一个正弦信号，它的幅度乘上 $|H(\omega)|$，然后它的相位加上我们 $H(\omega)$ 的一个相位。

$$\text{幅度} \cdot |H(\omega)|, \quad \text{相位} + \angle H(\omega)$$

就是这样的一个表达式。

我们现在第四章又来讨论一下这个问题了，就是当我们输入为正弦信号时，它经过一个系统得到的响应会是什么。但我们这里与第三章有明显的两点不同：第一，我们现在讨论的拉氏变换都是单边拉氏变换，所以我们这个正弦信号其实是相当于一个 $\cos(t)u(t)$ 或者是 $\sin(t)u(t)$ 的形式，我们之前第三章是在 $-\infty$ 到 $+\infty$ 都有的一个正弦，这是第一点区别；第二点，我们这里提到了一个稳态响应，就是我们要求的是这个正弦信号经过系统得到的一个稳态响应。

而我们在第三章这里得到的叫什么？这里得到的是一个零状态响应。当然我们这个零状态响应，因为它是 $\cos$ 的形式，所以它其实也是稳态响应。

在这里我们不是专门去求稳态响应，是因为它零状态响应就是稳态响应；而在这里我们是要专门求它的稳态响应，它的零状态响应和稳态响应是不相等的。

现在我们就来看一看，在第四章我们怎么去做一下这个问题。

我们这里设系统函数就是 $H(s)$，然后我们的一个输入信号 $e(t)$，它是等于 $E_m$（这是它的一个幅度），然后乘上一个 $\sin(\omega_0 t)$。为了写起来简捷，我们这里这个 $\sin(t)$ 就不加相位了。当然我们知道如果说它加一个相位，$\sin(\omega_0 t + \phi_0)$，我们其实可以用一个 $A\sin(\omega_0 t) + B\cos(\omega_0 t)$ 将它表示出来了。这个 $\cos(\omega_0 t)$ 和 $\sin(\omega_0 t)$ 的结论是一样的，所以我们这里就取这个 $\sin(\omega_0 t)$ 的例子来说明。

我们可以对这个输入信号做一个拉氏变换，因为我们现在是用拉氏变换的方法去分析。$\sin(\omega_0 t)$ 其实就是 $\sin(\omega_0 t)u(t)$，它对应的一个拉氏变换就是：

$$\frac{\omega_0}{s^2 + \omega_0^2}$$

前面还有一个幅度 $E_m$，这就是它的一个拉氏变换，这个我们叫做 $E(s)$。

所以我们现在有了这个 $H(s)$，有了这个 $E(s)$，我们就能得到最后的一个零状态响应 $R(s)$，这里我们用 $R(s)$ 来表示。输入信号、输出信号，不同的教材表示方法都有所不同，如果说用 $r(t)$ 来表示这个输出信号的话，那它的拉氏变换自然就用大写 $R(s)$ 来表示。这个 $R(s)$，这个零状态响应，自然就等于 $H(s) \cdot E(s)$，输入信号的拉氏变换乘上 $H(s)$。这个 $E(s)$ 的表达式我们这里已经给出了，就是：

$$\frac{E_m \omega_0}{s^2 + \omega_0^2} H(s)$$

现在我们想求这个 $r(t)$，自然就得对 $R(s)$ 做一个拉氏逆变换。做一个拉氏逆变换，我们首先可以对这样一个有理分式进行一个部分分式展开。前面这里 $s^2 + \omega_0^2$，它的分母的根其实是 $j\omega_0$ 和 $-j\omega_0$，所以这里我们可以拆成：

$$\frac{K(j\omega_0)}{s - j\omega_0}$$

上面的系数其实就是我们这里 $R(s)$ 这个整体乘上 $s - j\omega_0$，然后带入 $s = j\omega_0$，就是它的一个根。所以这里我们就写作 $K(j\omega_0)$。然后再加上：

$$\frac{K(-j\omega_0)}{s + j\omega_0}$$

上面的系数其实就是不看这一项，然后其余的都代入一个 $s = -j\omega_0$，所以这里我们叫做 $K(-j\omega_0)$。

然后这个 $H(s)$ 它也得进行一个部分分式展开，我们假设它有 $n$ 个根，那我们这里就可以写成：

$$\frac{k_1}{s - p_1} + \frac{k_2}{s - p_2} + \dots + \frac{k_n}{s - p_n}$$

我们所分析的系统大部分都是稳定系统，如果这个系统是一个稳定系统，那我们知道它的极点都是在 $s$ 平面左半平面，这个 $p_1$、$p_2$ 这些它都是小于 0 的。

然后我们就来求一求这上面的一个系数 $K(j\omega_0)$、$K(-j\omega_0)$。这两个系数我们求一个就行，因为我们之前讲拉氏逆变换的时候讲到，对于这种共轭复根的情况，它们的系数也是一对共轭复数，所以我们只需要求一个 $K(j\omega_0)$ 即可。

这个 $K(j\omega_0)$ 它就等于我们整个 $R(s)$ 然后乘上这个 $s - j\omega_0$，然后再带入 $s = j\omega_0$。我们看一下 $R(s)$ 乘上一个 $s - j\omega_0$，这里 $s^2 + \omega_0^2$ 它是 $(s - j\omega_0)(s + j\omega_0)$，所以它是等于：

$$\left. \frac{E_m \omega_0}{s + j\omega_0} H(s) \right|_{s = j\omega_0}$$

这里带入 $j\omega_0$，下面自然就是 $2j\omega_0$。这个 $\omega_0$ 和分子上的 $\omega_0$ 就约掉了，所以是：

$$\frac{E_m}{2j} H(j\omega_0)$$

这个 $H(j\omega_0)$ 我们知道它是一个复数，复数我们可以给它写成这种幅度跟相位的形式。我们令：

$$H(j\omega_0) = |H_0| e^{j\phi_0}$$

这个 $|H_0|$ 就是这个复数的一个幅度，这个 $\phi_0$ 就是它的一个相位。此时我们这里就可以这么表示：

$$\frac{E_m |H_0| e^{j\phi_0}}{2j}$$

这样 $K(j\omega_0)$ 我们就求完了。

接下来我们需要看一看这个 $K(-j\omega_0)$。但这个 $K(-j\omega_0)$ 不需要我们再利用相同的方法再求一遍了，因为我们说了，$K(j\omega_0)$ 和 $K(-j\omega_0)$ 它们是一对共轭复数，我们只需要取它的共轭就可以。

这个分母上有一个 $j$，$j$ 其实它就是一个相位，因为我们知道：

$$\frac{1}{j} = -j = e^{-j\frac{\pi}{2}}$$

它其实就是一个相位，所以我们这里也可以写成：

$$\frac{E_m |H_0|}{2} e^{j\left(\phi_0 - \frac{\pi}{2}\right)}$$

没问题吧？此时我们再求它的共轭就非常的简单了，因为前面都是一个常数、都是一个系数。我们知道 $A e^{j\phi_0}$ 它的共轭应该是什么？就是 $A e^{-j\phi_0}$，负的 $j\phi_0$。这个大家懂吧？或者说你不理解，你可以对这个指数进行一个欧拉展开，拆成三角的形式，这就懂了。

对它取一个共轭，就是这个 $e$ 指数前面多一个负号。所以我们这个：

$$K(-j\omega_0) = \frac{E_m |H_0|}{2} e^{-j\left(\phi_0 - \frac{\pi}{2}\right)}$$

当然这里我们也可以变回这种形式，就是把括号给它打开，一项是 $e^{-j\phi_0}$，一项是 $e^{j\frac{\pi}{2}}$。$e^{j\frac{\pi}{2}}$ 我们知道它其实也等于 $j$，$j$ 如果放在分母上就是 $-\frac{1}{j}$，所以它也可以写成：

$$\frac{E_m |H_0|}{-2j} e^{-j\phi_0}$$

这样我们就求完了它们两个的系数。那我们就先求一求这两项，它们的一个拉氏逆变换是什么样的。

这两项其实这一部分和这一部分是完全相同的吧，所以它们两个相加我们可以把这一部分提出来：

$$\frac{K(-j\omega_0)}{s + j\omega_0} + \frac{K(j\omega_0)}{s - j\omega_0} = \frac{E_m |H_0|}{2j} \left[ \frac{e^{j\phi_0}}{s - j\omega_0} - \frac{e^{-j\phi_0}}{s + j\omega_0} \right]$$

我们对它求一个拉氏逆变换其实很简单的，因为这里就是一个 $s - a$ 的形式，这个 $e^{j\phi_0}$、$e^{-j\phi_0}$ 这些只不过是一个常数而已。我们对它做一个拉氏逆变换：

$$\mathcal{L}^{-1}\left\{ \frac{K(-j\omega_0)}{s + j\omega_0} + \frac{K(j\omega_0)}{s - j\omega_0} \right\}$$

这一部分就是一个常数，所以直接就拿出来，根据线性：

$$= \frac{E_m |H_0|}{2j} \left[ e^{j\omega_0 t} e^{j\phi_0} - e^{-j\omega_0 t} e^{-j\phi_0} \right] u(t)$$

因为 $\frac{1}{s - a}$ 对应 $e^{at}u(t)$，第一部分它就对应着 $e^{j\omega_0 t} \cdot e^{j\phi_0}$，这里就是一个常数而已；第二项它就是 $e^{-j\omega_0 t}$，然后上面是乘上一个 $e^{-j\phi_0}$，后面别忘了 $u(t)$。

我们对它做完拉氏逆变换之后，不知道大家对这种形式有没有感觉到熟悉。这分母上有一个 $2j$，完了这里是一个 $e$ 正，这里是一个 $e$ 负，而且我们可以把它们两个合并一下吧。这里不就是 $e^{j(\omega_0 t + \phi_0)}$，这里不就是 $e^{-j(\omega_0 t + \phi_0)}$ 吗？这不刚好是那个 $e$ 正减 $e$ 负的形式吗？

所以根据欧拉公式，我们就能直接得到这一部分它就是一个 $\sin$ 的形式，所以最后就是：

$$E_m |H_0| \sin(\omega_0 t + \phi_0) u(t)$$

所以最后得到的形式是非常好的。

这里我们只是对前两项做了一个拉氏逆变换，我们这里这个 $R(s)$ 它后面还有很多项。对后面这些项做一个拉氏逆变换也很简单，比方说 $\frac{k_1}{s - p_1}$，它不就对应着 $k_1 e^{p_1 t}$ 吗？

所以我们对整体做一个拉氏逆变换，那就是 $r(t)$ 了。

$$r(t) = \mathcal{L}^{-1}\{R(s)\} = E_m |H_0| \sin(\omega_0 t + \phi_0) u(t) + \left[ k_1 e^{p_1 t} + k_2 e^{p_2 t} + \dots + k_n e^{p_n t} \right] u(t)$$

第一项就是它，前两项的拉氏逆变换就是它，然后后面都是一些 $k_1 e^{p_1 t} + k_2 e^{p_2 t}$ 一直加到 $k_n e^{p_n t}$，然后后面给一个 $u(t)$。

虽然这里有很多项，但是如果说我们这个系统是一个稳定系统，这个 $H(s)$ 它的极点都在 $s$ 平面左半平面吧，所以这里 $p_1, p_2, \dots, p_n$ 这些都是小于 0 的。一旦 $t \to \infty$，我们这里是不是都趋向于 0 了？所以这一部分其实它们都是瞬态响应。

只有前面这一部分是稳态响应，就是一个 $\sin$ 的形式，当 $t \to \infty$ 时，$\sin$ 一样是稳定的存在着。

如果说想求它的一个稳态响应，稳态响应我们可以用 $r_{ss}(t)$ 来表示，那就是第一项：

$$r_{ss}(t) = E_m |H_0| \sin(\omega_0 t + \phi_0) u(t)$$

可以看到，它的零状态响应和它的稳态响应是不同的，它的稳态响应就是这样的一个正弦的形式。

我们看一下它对比原来的一个输入信号 $e(t)$ 有什么区别。原来我们 $e(t)$ 它是等于 $E_m \sin(\omega_0 t) u(t)$。可以看到，我们这里就是幅度乘上一个 $|H_0|$，然后相位加上一个 $\phi_0$。

这个 $|H_0|$、$\phi_0$ 它是什么呢？这个其实就是我们刚才设的，我们刚才设这个 $H(j\omega_0)$，它就等于 $|H_0| e^{j\phi_0}$。所以这个 $|H_0|$ 就是这个 $H(j\omega_0)$ 的一个幅度，这个 $\phi_0$ 就是 $H(j\omega_0)$ 的一个相位。

就是 $H(s)$ 带入 $s = j\omega_0$ 得到 $H(j\omega_0)$，然后我们可以把它写成幅度相位的形式：

$$H(j\omega_0) = |H_0| e^{j\phi_0}$$

我们只需要对这个输入信号它的幅度乘上一个 $|H_0|$，相位加上 $\phi_0$，我们就能得到稳态响应。

所以说我们现在知道这个结论之后，我们就能很快地解决一些问题了。如果说一个题目它告诉你系统函数 $H(s)$，然后它的输入信号是这种正弦或者余弦的形式，比如说 $\cos(t)u(t)$，然后它要你求一个稳态响应，那我们就不必说还得先对 $\cos(t)u(t)$ 做一个拉氏变换，然后它们俩相乘，乘完之后我们再看其中的哪一部分是稳态响应。

我们就不必要那么做了，我们可以直接利用这个结论来做。我们就是直接令这个 $H(s)$ 中的 $s = j\omega_0$。这里是 $\cos(t)$，所以这个其实是 $\cos(1 \cdot t)$，$\omega_0 = 1$ 嘛，其实就是代入 $s = j$ 得到 $H(j)$，然后求一下这个 $H(j)$ 它的幅度跟相位。求幅度跟相位的方法我之前也已经教给大家了。然后它的稳态响应就是原来的这个输入信号乘上它的一个幅度，即 $|H(j)|$，然后它的相位也加上它的一个相位，这个复数的一个相位。这样我们就直接求出了它的稳态响应。

这一部分的例题我想我们就不举了，因为这一部分和我们第三章那里是不是很相像啊？这里只不过你要注意它要我们求的是一个稳态响应。然后它比我们第三章只多了一步，就是我们这个 $H(s)$ 它首先要代入 $s = j\omega_0$。假如我们这里是 $\cos(t)$，你就代入 $s = j$，就多了这一步，其它地方都是一样的。
