[听音转录 · P78 3.6指数形式的傅里叶级数]
> 来源：**听音转录**——非平台字幕，由讲师原声转录

说完了三角形式的傅里叶级数，我们再来介绍一下指数形式的傅里叶级数。

在最开始的时候我们就说过，我们可以把一个周期信号分解为无穷多三角函数的和，或者说把它分解为无穷多复指数的和。而我们之前已经讲了三角形式的傅里叶级数，它就是把一个周期信号分解为无穷多三角函数的和。

我们又知道三角函数和复指数函数他们两个是有关系的，我们学过欧拉公式。欧拉公式就提供了他们两个之间的一个关系。既然我们已经把周期信号分解为无穷多三角函数的和，也就是三角形式的傅里叶级数，那我们利用一下欧拉公式，就可以将这个周期信号分解为无穷多复指数的和，这样我们就能得到指数形式的傅里叶级数。

思路已经明确了，我们接下来就做一做。首先我们把欧拉公式再写一遍：
欧拉公式是 $\cos x = \frac{e^{jx} + e^{-jx}}{2}$，$\sin x = \frac{e^{jx} - e^{-jx}}{2j}$。

然后我们把三角形式的傅里叶级数先写下来：
$$f(t) = a_0 + \sum_{n=1}^{\infty} \left[ a_n \cos(n\omega_1 t) + b_n \sin(n\omega_1 t) \right]$$

我们就用一下欧拉公式，把 $\cos$ 和 $\sin$ 都展成复指数的形式。$a_0$ 还是不变，求和也不变。这里 $a_n$ 就变成 $\frac{a_n}{2}$，$\cos$ 就变成 $e^{jn\omega_1 t} + e^{-jn\omega_1 t}$；$\sin$ 就变成 $\frac{b_n}{2j}$，这里是 $e^{jn\omega_1 t} - e^{-jn\omega_1 t}$。

我们可以把 $e^{jn\omega_1 t}$ 都合并在一起，把 $e^{-jn\omega_1 t}$ 也合并在一起：
$$f(t) = a_0 + \sum_{n=1}^{\infty} \left[ \dots \right]$$
先把它们合并在一起：它前面的系数是 $\frac{a_n}{2}$，后面这项前面的系数是 $\frac{b_n}{2j}$。$\frac{b_n}{2j}$ 也可以把 $j$ 提到分子上，那就是 $-\frac{j b_n}{2}$。所以这里是 $\frac{a_n - jb_n}{2} e^{jn\omega_1 t}$。然后再加，这里是 $\frac{a_n}{2}$，后面是 $-\frac{b_n}{2j}$，而 $-\frac{b_n}{2j}$ 自然就等于 $\frac{jb_n}{2}$ 了，所以 $e^{-jn\omega_1 t}$ 前面的系数是 $\frac{a_n + jb_n}{2}$。我们就得到了这样一个表达式。

我们可以令这一部分给它起一个名，我们令：
$$F(n\omega_1) = \frac{a_n - jb_n}{2}$$

后面这一部分我们不用先起名了，我们可以利用一下 $a_n$ 和 $b_n$ 的奇偶性把它推过来。$F(-n\omega_1)$ 相当于把这里的 $n$ 换成 $-n$ 了，那这里也把 $n$ 换成 $-n$，它就是 $\frac{a_{-n} - jb_{-n}}{2}$。我们知道 $a_n$ 它是关于 $n$ 的偶函数，$b_n$ 是关于 $n$ 的奇函数，所以它就等于 $\frac{a_n + jb_n}{2}$。这不刚好是这一部分吗？

所以我们这个 $f(t)$ 就可以写成：
$$f(t) = a_0 + \sum_{n=1}^{\infty} \left[ F(n\omega_1) e^{jn\omega_1 t} + F(-n\omega_1) e^{-jn\omega_1 t} \right]$$

我们可以把这个求和拆开来，拆成两项，写成：
$$\sum_{n=1}^{\infty} F(n\omega_1) e^{jn\omega_1 t} + \sum_{n=1}^{\infty} F(-n\omega_1) e^{-jn\omega_1 t}$$
这个应该没有问题吧。举一个简单例子，$\sum_{n=1}^{2} (a_n + b_n)$，它显然是 $a_1 + b_1 + a_2 + b_2$。如果你把它拆开来，结果肯定也是一样的，是 $\sum_{n=1}^{2} a_n + \sum_{n=1}^{2} b_n$，它也是 $a_1 + a_2 + b_1 + b_2$，这显然是相同的。

我们来看一下它的形式：前面这里全是 $n$，后面这里全都是 $-n$。虽然它们的求和上下限都是 $1$ 到 $\infty$，但它们两个显然是不同的。这里我们代一下看看：$n=1$ 时它是 $F(\omega_1) e^{j\omega_1 t}$；如果说 $n=2$，它是 $F(2\omega_1) e^{j2\omega_1 t}$，后面还有很多项。我们再来看后面这个，同样代 $n=1$，它是 $F(-\omega_1) e^{-j\omega_1 t} + F(-2\omega_1) e^{-j2\omega_1 t}$。所以它们两个一个是正的，一个是负的。

这里我们可以令 $-n = k$，那它就变成了 $F(k\omega_1) e^{jk\omega_1 t}$。前面的求和限也要做变换，我们这里是 $n = 1$ 到 $\infty$，换元之后 $k = -n$，也就是 $k = -\infty$ 到 $-1$。我们知道求和对谁求无所谓，对 $k$ 求也一样，对 $n$ 求也一样，所以这里我们再把 $k$ 变回 $n$，那它也可以写成 $\sum_{n=-\infty}^{-1} F(n\omega_1) e^{jn\omega_1 t}$。

在这里我们就可以写成：
$$a_0 + \sum_{n=1}^{\infty} F(n\omega_1) e^{jn\omega_1 t} + \sum_{n=-\infty}^{-1} F(n\omega_1) e^{jn\omega_1 t}$$
可以发现，这里和这里完全是相同的，区别只是前面求和限的不同而已。

所以我们完全可以把它们两个合在一起，它们一个是 $n=1$ 到 $\infty$，一个是 $n=-\infty$ 到 $-1$。我们就想，如果说再来一个 $n=0$ 的情况，是不是就太完美了？那样的话它就可以合成 $n=-\infty$ 到 $+\infty$ 了，这样就太好了。

我们看一下 $n=0$ 时它的值为多少。这里是 $F(0)$，然后这里是 $e^{j0} = 1$，$n=0$ 时它的值就是 $F(0)$。别忘了我们前面还有一个 $a_0$ 没用到呢，我们为了完成这种形式的大统一，我们可以令：
$$F(0) = a_0$$
那样的话它就是 $F(0)$，然后这是一到正无穷，这是负无穷到负一，太完美了，三家归晋了：
$$\sum_{n=-\infty}^{+\infty} F(n\omega_1) e^{jn\omega_1 t}$$

我们这里可以记 $F(n\omega_1)$ 为 $F_n$。这里就可以写成：
$$\sum_{n=-\infty}^{+\infty} F_n e^{jn\omega_1 t}$$
可以看到它这个形式确实非常的简洁，非常的美观。这种形式比起我们的三角形式的傅里叶级数，它一个很明显的好处就是它只用求 $F_n$，而不是像之前还要去求 $a_n$、求 $b_n$、求 $a_0$。

这个 $F_n$ 怎么求呢？别忘了 $F_n$ 是怎么来的，我们是令 $F_n = \frac{a_n - jb_n}{2}$，而 $a_n$ 和 $b_n$ 的求法我们之前已经说过了。所以我们只要把 $a_n$ 和 $b_n$ 求出来，那 $F_n$ 自然也能求出来。

我们这里直接写：
$$F_n = \frac{1}{2} \left[ \frac{2}{T_1} \int_{-T_1/2}^{T_1/2} f(t) \cos(n\omega_1 t) dt - j \frac{2}{T_1} \int_{-T_1/2}^{T_1/2} f(t) \sin(n\omega_1 t) dt \right]$$

这里我们可以给它化简化简：$\frac{1}{2}$ 和 $\frac{2}{T_1}$ 可以约一约，前面变成 $\frac{1}{T_1}$。积分因为上限下限都是 $-\frac{T_1}{2}$ 到 $\frac{T_1}{2}$，这两个积分我们也可以给它合并到一起，那就变成：
$$\frac{1}{T_1} \int_{-T_1/2}^{T_1/2} \left[ f(t) \cos(n\omega_1 t) - j f(t) \sin(n\omega_1 t) \right] dt$$

这里是一个 $\cos - j\sin$ 的形式，大家感不感觉熟悉？我们可以利用欧拉公式再把它变成 $e$ 指数的形式。因为我们知道 $e^{-jx} = \cos x - j\sin x$，所以它们俩就可以合并：
$$F_n = \frac{1}{T_1} \int_{-T_1/2}^{T_1/2} f(t) e^{-jn\omega_1 t} dt$$
这样我们就求出了 $F_n$ 的一个表达式，它就这么求即可。

这里注意一点：我们之前是 $f(t) = \sum F_n e^{jn\omega_1 t}$，这里指数是正的；而这里我们求 $F_n$ 的时候，它是一个负的。这里要注意，这里是负的，这里是正的，记的时候不要混淆。

注意我们在求 $F_n$ 的时候，一般利用不到奇偶性了，不像 $a_n, b_n$ 能利用奇偶性，因为它们乘的是 $\sin, \cos$，$\sin$ 是奇的，$\cos$ 是偶的。这里不行了，所以我们这个积分上下限可以换成 $0$ 到 $T_1$，这样可能更好算一些，因为代入 $0$ 总是好代的。

我们在求 $F_n$ 时总能遇到这样一个式子，就是 $e^{jn\omega_1 T_1}$。我们知道 $\omega_1 T_1 = 2\pi$，所以 $e^{jn2\pi}$ 它等于多少？我想肯定有同学知道，它应该等于 $1$，无论这个 $n$ 等于多少，这 $n$ 是一个整数。

这可以从两方面理解：一方面我们之前讲过旋转矢量，你相位每增加 $2\pi$ 就相当于这个旋转矢量转了一圈。你转了一圈不就又回到原点了吗？所以说它就是 $1$。另外你也可以用欧拉公式去看一下，它就等于 $\cos(2\pi n) - j\sin(2\pi n)$。我们知道 $\cos(2\pi n)$ 无论如何它都为 $1$，而 $\sin(2\pi n)$ 无论如何它都为 $0$，所以结果也为 $1$。所以这是一个常用的，大家要记住。

我们之前讲三角形式的傅里叶级数的时候，介绍了单边幅度谱和单边相位谱。

这里我们讲指数形式的傅里叶级数，它也有，不过它不是单边的了，而是双边的，也就是双边幅度谱和双边相位谱。

这是因为大家看我们指数形式的傅里叶级数，它是 $f(t)$，这里我重写一遍：
$$f(t) = \sum_{n=-\infty}^{+\infty} F_n e^{j n \omega_1 t}$$
不同于三角形式的它是 $n$ 从 $0$ 到正无穷，我们这里的 $n$ 是从哪开始？$n$ 是从负无穷到正无穷。所以我们不再是单边的了，而是双边的了，$n$ 从负无穷到正无穷都能取。

求双边幅度谱和双边相位谱的方式也是跟我们单边的方法是完全类似的，所以其实是很简单的一个过程。

但这里我们给出了非常多的一个关系，就是三角形式傅里叶级数和指数形式傅里叶级数的关系。所以通过这些关系，我们有时候能直接通过单边幅度谱和单边相位谱，直接画出双边幅度谱和双边相位谱。

下面我们举一个例子来介绍一下。

看这道例题。这道例题大家可能感到很熟悉，这个题是不是做过？确实做过。

这里 $f(t)$ 的形式和之前那道题的形式是完全一样的，但注意这里我们要求双边幅度谱和双边相位谱，之前我们要求的是单边幅度谱和单边相位谱。

双边的怎么求呢？有同学就会想，既然求双边的，是不是首先应该把这些余弦都换成复指数的形式，然后再去求？

可以这么做，当然可以。你可以用欧拉公式把这些余弦都转换成复指数，然后画它的双边谱，没问题。但我说这么做就麻烦了。

因为对于这种三角函数的函数形式，我们还是画它的单边幅度谱和单边相位谱是更为简单的，更何况在前一道题我们已经给它画出来了。

所以这里我们直接用刚才讲的那些系数的关系，去从它的单边幅度谱和单边相位谱推导出双边幅度谱和双边相位谱，是更为简单的一种方法。

这里我们将所要用到的一些关系先陈列到这里。

首先是 $|F_n| = |F_{-n}| = \frac{1}{2} C_n$，然后 $F_0 = C_0$。然后它的相位 $\varphi_n$ 是 $\varphi_{-n} = -\varphi_n$。

所以主要用到的结论就是这个 $|F_n|$ 是一个偶函数，然后它的相位是一个奇函数。同时这里 $|F_n| = \frac{1}{2} C_n$，$F_0 = C_0$。注意这里我们 $F_n$ 都是一个复数，但是 $F_0$ 我们知道它就是直流分量，它等于 $C_0$ 等于 $A_0$，它是一个实数，所以这里就是 $F_0 = C_0$。

之前我们已经画过这个信号的单边幅度谱，这里重复一下。这里是 $5$，然后 $\omega_1$、$2\omega_1$ 这都没有，$3\omega_1$ 它的幅度是 $6$，$4\omega_1$ 它的幅度是 $4$。

现在我们由这个单边的要去导出双边的。双边的你就不能只画一边了，两边都要画。这里是 $\omega$，这里是 $|F_n|$。

我们就按照这个关系对应来看一看。首先看 $F_0$，$F_0$ 它就等于 $C_0$。那这里 $C_0$ 是 $5$，它也是 $5$。

接下来看剩下的。剩下的就是 $n \neq 0$ 的一些情况。这里注意，这里 $|F_n| = \frac{1}{2} C_n$，所以这里的幅度是它的一半，对吧？这里 $\omega_1$、$\omega_2$ 都没有，所以它也是 $0$，$0$ 的一半也是 $0$。这里到了 $3\omega_1$，它就变成它的一半了，这里 $6$ 就变成 $3$ 了。然后这里 $4\omega_1$，原来是 $4$，现在变成它的一半了，就变成 $2$。

现在我们把这一边画完了，它是双边的，另外一边我们也要画。我想另外一边你直接给它对称过去就行。因为我们这里 $|F_n| = |F_{-n}|$，它是一个偶对称的。

所以这里是 $-\omega_1$，这里 $-2\omega_1$ 都为 $0$；这里 $-3\omega_1$ 跟 $3\omega_1$ 是一样的，这里是 $3$；$-4\omega_1$ 跟这个 $4\omega_1$ 是一样的，是 $2$，它们都是 $\frac{1}{2} C_n$。

所以怎么由单边幅度谱变为双边幅度谱呢？很简单，就零处不变，零处不变，然后非零处砍一半，然后你再给它对称到左边。我这里总结一下：零处不变，非零处砍一半，再对称到左边。这是单边幅度谱到双边幅度谱，所以这个很简单。

接下来是相位谱。之前这个信号的单边相位谱我们也已经画出来过，我们这里重复一下。

这里是 $\varphi_n$，这里是 $\omega$。然后 $0$、$\omega_1$、$2\omega_1$，这些地方都是 $0$；然后 $3\omega_1$ 这个地方是 $\frac{\pi}{3}$；然后 $4\omega_1$ 这个地方是 $-\frac{2\pi}{3}$。

怎么由单边相位谱变成双边相位谱呢？我们之前说过，这个 $F_n$ 它的 $\varphi_n$ 和我们那里三角形式这个 $C_n \cos(n\omega_1 t + \varphi_n)$，它们的形式是完全相同的。

但是之前我们是单边，现在我们要画双边。那怎么办？我们再利用它的奇对称的性质就可以。

因为它们三角形式和这里 $F_n$ 的 $\varphi_n$ 都是相同的，所以右边肯定是完全一样。

右边也是这个 $0$，然后这里都是 $0$，这里是 $\frac{\pi}{3}$，然后这里 $4\omega_1$ 是负的 $-\frac{2\pi}{3}$。

但原来是单边，现在是双边，左边怎么办？因为这个 $F_n$ 它的相位是奇对称的，所以我们把它奇对称一下即可。

这里 $-\omega_1$、$-2\omega_1$ 都为 $0$，到 $-3\omega_1$ 时它变成 $-\frac{\pi}{3}$，然后到 $-4\omega_1$ 时，它变成了正的 $\frac{2\pi}{3}$，对吧？

所以这样我们就画出了它的双边相位谱。所以这个更简单了，做一个奇对称即可。

这样我们就得到了这个信号的双边幅度谱和双边相位谱，这个题我们就解决了。

再看一道例题。这个例题它就直接是复指数的形式了，所以我们直接根据它的形式画出该信号的双边幅度谱和双边相位谱即可。

跟三角形式画单边的一样，我们这里首先也要去求 $\omega_1$。

因为我们 $f(t) = \sum_{n=-\infty}^{+\infty} F_n e^{j n \omega_1 t}$，这里是 $e^{j 1 t}$，这里是 $e^{j (-2) t}$。我们来找一下 $1$ 和 $-2$ 的最大公约数，这里显然是 $1$，所以 $\omega_1 = 1$。那这里就是 $1\omega_1$，这里就是 $-2\omega_1$。

所以我们直接就来画它的双边幅度谱。这里是 $\omega$，这里是 $|F_n|$。只有当 $\omega$ 为 $\omega_1$ 和 $-2\omega_1$ 时它的幅度为非零的，其它地方都是 $0$。

这里当 $\omega$ 为 $\omega_1$ 时，它的幅度为多少？它的幅度为 $2$。然后当 $\omega$ 为 $-2\omega_1$ 时，它的幅度为多少？前面的系数是 $-1$。所以这里直接画 $-1$ 吗？

注意，我们这里幅度谱应都为正。所以我们想办法要把这个负号给它变为正号。

那我们怎么变？我们不能平白无故地把人家负号变为正号，我们要对它进行一些其它的处理，我们可以对相位做手脚。

相位如果说加减 $\pi$，那么幅度即乘以一个 $-1$。

这个是为什么呢？这是因为 $e^{j\pi} = e^{-j\pi} = -1$。比如你想把 $-A$ 前面的符号改为正号，那你也可以把它写成 $A \cdot e^{j\pi}$。这个 $e^{j\pi}$ 其实它也是一个 $-1$。

那你这么写的话，其实就是改变了它的相位了。比如说这里你乘上一个 $e^{j\pi}$ 的话，那其实就是它相位加上 $\pi$ 了，它就变成 $e^{j(-2t + \frac{2\pi}{3})}$。

这个 $e^{j\pi} = e^{-j\pi} = -1$，同学们应该知道了。这里写一下，可以从两个角度理解：一是我之前讲过的旋转矢量，$e^{j\pi}$ 和 $e^{-j\pi}$ 相当于转了半圈，从这里顺时针转了半圈和逆时针转了半圈最后都是到这，这里是 $-1$。

我们也可以用欧拉公式给它展开一下看一下。这里是 $\cos\pi + j\sin\pi$，这里是 $\cos\pi - j\sin\pi$。$\cos\pi$ 是 $-1$，$\sin\pi$ 是 $0$，所以它们两个都是 $-1$。

我们相位加减 $\pi$ 都可以，那我们是加 $\pi$ 还是减 $\pi$ 呢？我们要使相位它在这样的一定范围之内，这里和我们三角那里是完全一样，相位的范围要在 $(-\pi, \pi]$ 这个范围之内。

所以你看看它是加 $\pi$ 还是减 $\pi$ 回到这个范围之内，你就选那种方式即可。如果说它不在这范围之内，你也可以选择它的相位给它加减 $2\pi$，它是不变的。因为旋转矢量相当于转了一圈，转了一圈自然又转回来了。或者说 $e^{j 2\pi} = 1$，$e^{-j 2\pi}$ 它也是等于 $1$ 的。

所以这里我们可以给 $f(t)$ 改写一下：
$$f(t) = 2 e^{j(t - \frac{\pi}{3})} + e^{j(-2t - \frac{\pi}{3} + \pi)}$$
然后这里我们是加 $\pi$ 还是减 $\pi$ 呢？我们应该加 $\pi$。因为这里原来是 $-\frac{2\pi}{3}$，你加上一个 $\pi$ 变为 $\frac{\pi}{3}$，刚好在 $(-\pi, \pi]$ 之间。

所以我们得到了新的 $f(t)$ 的形式，我们再根据这个形式来画它的双边幅度谱和双边相位谱。

此时当 $\omega = -2\omega_1$ 时，它所对应的幅度应该是 $+1$。

然后再来画它对应的双边相位谱。很简单了，那就是当 $\omega = \omega_1$ 时，它对应的相位是 $-\frac{\pi}{3}$，这里是 $\omega_1$。然后当 $\omega = -2\omega_1$ 时，它所对应的相位是 $\frac{2\pi}{3}$。

这样我们就画好了它的双边幅度谱和双边相位谱。所以画这个过程是很简单的，但你要注意它的形式，你要对它做一些小小的改变。
