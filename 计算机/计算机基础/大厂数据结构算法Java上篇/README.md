# 大厂必备数据结构与算法（Java）上篇

面向 Java 高级工程师的《数据结构与算法》上篇，200 集把面试与工程里最常用的一批结构讲透。课程从算法复杂度的度量与二分查找起步，经数组、链表、递归、队列栈与双端队列，进入二叉树遍历、堆与优先级队列、二叉搜索树，最后收在 AVL 树与红黑树的平衡维护上。每个结构都从「为什么需要它」讲到「手写实现 + 复杂度证明」，并且大量使用并发工具类的源码（阻塞队列、优先队列）做对照，学完能直接对标大厂面试题。

- **原视频**：https://www.bilibili.com/video/BV1Lv4y1e7HL — Bilibili，BV1Lv4y1e7HL
- **200 集**，已产出 8 册模块全书、18 篇复习笔记、53 份逐字稿

## 怎么学

- **复杂度是全课标尺** → 模块 01 与笔记 01、02 讲 O 记号与二分查找的边界手艺，后面每个结构选什么实现，依据都来自这里，务必先建立「用复杂度做决策」的意识
- **线性结构打地基** → 模块 02、04 讲数组、链表、队列、栈与双端队列，笔记 03~05 的链表反转/删除/合并/判环是笔试高频题，务必自己敲一遍
- **递归是全篇枢纽** → 模块 03 与笔记 06、07 讲递归思想、尾递归与爆栈、以及用递推式做复杂度分析，后面二叉树、B 树、动态规划全靠它，建议反复过
- **树形结构分两段** → 模块 05~08 是本课主体：二叉树遍历与还原（笔记 12、13）、二叉搜索树增删查与合法性判定（笔记 14~16）、AVL 与红黑树的旋转与调整（笔记 17、18）；手写红黑树删除调整是这一段最难也最能拉开差距的部分
- **配合下篇使用** → 这门课与《大厂必备数据结构与算法（Java）下篇》（B 树、排序、图论、动态规划、缓存设计）是同一系列的前后两篇，先修完本篇再接下篇；两篇笔记的组织方式不同（见下篇课程页）
- **速查** → `notes/` 里 18 篇按结构切分的笔记，可在面试前按「树」「队列」「递归」三种入口速查
