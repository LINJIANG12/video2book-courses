哈尔滨工业大学《编译原理》公开课，按「前端 → 中端 → 后端」的编译器流水线走完一遍：先讲编译系统结构与词法分析（正规式、DFA/NFA），再进自顶向下与自底向上两大语法分析路线（LL(1)、FIRST/FOLLOW、LR(0)/SLR/LR(1)/LALR），然后是语法制导翻译与中间代码生成（类型表达式、数组引用、布尔回填、过程调用），最后落到符号表、代码优化与数据流分析（到达定值、支配结点与回边、归纳变量删除）。81 集整编为 5 册模块全书与 6 篇主题复习笔记。

## 怎么学

- **按流水线顺序走**：词法 → 语法 → 语义/中间代码 → 优化，每一段都是下一段的输入，跳读会在后面反复卡住。
- **两大分析路线要对比着学**：自顶向下（LL(1)）与自底向上（LR 系列）解决的是同一件事的两套思路，笔记 02/03 并排放在一起看最省力。
- **手推项目集是硬功夫**：LR(0)/SLR/LR(1)/LALR 的区别全在「项目集怎么构造、冲突怎么解决」，这部分必须动笔，不能只看结论。
- **语法制导翻译抓「属性与动作」**：S 属性、L 属性、翻译方案与注释分析树的关系是期中期末高频区，笔记 04 有完整对照。
- **优化部分先建数据流框架**：到达定值、活跃变量、可用表达式本质是同一个方程框架换方向，先立框架再记各分析的 gen/kill。
- **考前只看 `notes/`**：6 篇笔记按编译流程六段重组，算法步骤、构造口诀与易错点并排放置。
