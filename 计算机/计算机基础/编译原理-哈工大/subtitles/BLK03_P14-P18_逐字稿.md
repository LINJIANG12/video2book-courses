> 来源：**听音转录**——非平台字幕，由讲师原声转录

同学们好，下面我们来介绍有穷自动机。有穷自动机是词法分析的重要理论基础。

有穷自动机是由两位神经物理学家在 1948 年首先提出的，它是对一类处理系统建立的数学模型。这类系统具有一系列离散的输入输出信息和有穷数目的内部状态。这里的状态概括了对过去输入信息处理的状况。

系统只需要根据当前所处的状态和当前面临的输入信息，就可以决定系统的后续行为。每当系统处理了当前的输入后，系统的内部状态也将发生改变。

我们说电梯控制装置是有穷自动机的一个典型例子。那么顾客的乘梯需求，也就是说他所要到达的层号，是这个装置的输入信息。电梯所处的层数以及它的运动方向是上行还是下行，构成了这个控制装置的状态。

那么电梯控制装置它并不需要记住先前全部的服务要求，它只需要知道电梯当前所处的状态以及还没有满足的服务请求即可。

我们来看 FA 模型的示意图。有穷自动机它由输入带、读头和有穷控制器三部分组成。这个输入带是用来存放输入符号串的。那么这个读头从左向右逐个读取输入符号。读头不能修改，也不能往返移动，也就是说只能从左向右移动，不能从右向左移动。

有穷控制器具有有穷个状态数。它根据当前的状态和当前的输入符号来控制转入下一个状态。

有穷自动机可以用一种称为转换图的有向图来表示。例如这就是一个有穷自动机的转换图。在这个图中，每一个节点表示 FA 的一个状态。例如在这个图所表示的自动机中，它有四个状态，分别是状态 0、状态 1、状态 2 和状态 3。

那么 FA 的状态里面包括两种特殊的状态，一种称为初始状态。初始状态只有一个，它由 start 箭头指向。比如说在这个自动机中，状态 0 就是一个初始状态。

另外还有一种状态是终止状态，也叫接收状态。终止状态可以有多个，它用双圈来表示，比如说这里的状态 3 就是一个终止状态。

那么转换图中除了节点以外，还有一些带有标记的有向边。如果对于输入符号 $a$，存在一个从状态 $p$ 到状态 $q$ 的转换，就在 $p$ 和 $q$ 之间画一条有向边，并标记上符号 $a$。比如说在状态 0 和状态 1 之间标上了符号 $a$，就表示在状态 0 遇到符号 $a$ 的时候，可以进入到下一个状态——状态 1。

好，下面我们来看一下 FA 定义或接收的语言。

给定一个输入串 $x$，如果存在一个对应于串 $x$ 的从初始状态到某个终止状态的转换序列，则称串 $x$ 被 FA 接收。

我们来看一个例子。这是一个有穷自动机的转换图，那么我们来看一下，这个自动机它能不能接收串 $abb\;aabb$ 呢？

首先在初始状态 0，遇到第一个符号 $a$ 的时候，还保持状态 0；接下来遇到两个 $b$ 以后，依然保持状态 0；再接下来遇到这个 $a$ 的时候，还保持状态 0；遇到第二个 $a$ 的时候，那么进入状态 1；接下来遇到这个 $b$ 的时候，进入状态 2；再遇到第二个 $b$ 的时候，进入状态 3，也就是终止状态。可见这个自动机可以接收这个串 $abb\;aabb$。

由一个有穷自动机 $M$ 接收的所有串构成的集合，称为是这个 FA 定义或接收的语言，记为 $L(M)$，这个 $M$ 表示 machine。

好了，那么我们来看一下这个自动机它能接收的语言是什么语言呢？这个自动机它接收的语言是所有以 $abb$ 结尾的 $ab$ 串构成的集合。

好，下面我们来介绍一下有穷自动机在运行过程中所遵循的最长子串匹配原则。

所谓最长子串匹配原则是指，当输入串的多个前缀与一个或多个模式匹配的时候，总是选择最长的前缀进行匹配。

例如在这个自动机中，状态 1 是一个终态，它表示匹配上了单词小于号（`<`）；状态 2 也是一个终态，它表示匹配上了单词小于等于号（`<=`）。那么当输入串是一个小于号加上一个等于号的时候，这个时候它的两个前缀小于号和小于等于号分别与这两个模式都匹配上了。这个时候根据最长子串匹配原则，我们选择的是最长的前缀，也就是小于等于号进行匹配。那么 `++` 这个单词也是类似的情况。

因此在到达某个终态之后，只要输入带上还有符号，有穷自动机就继续前进，以便寻找尽可能长的匹配。

[听音转录 · P15 3-4有穷自动机的分类]
> 来源：**听音转录**——非平台字幕，由讲师原声转录

同学们好，下面我们来学习有穷自动机的分类。

有穷自动机分为两类，一类是确定的有穷自动机，简称 DFA；另一类是非确定的有穷自动机，简称 NFA。

我们先来看 DFA。DFA 被定义为一个五元组，其中的 $S$ 表示的是一个有穷状态集合；$\Sigma$ 表示的是输入字母表，也就是输入符号的集合，这里我们约定，空串不是字母表中的元素；$\delta$ 是将 $S$ 和 $\Sigma$ 的笛卡尔乘积映射到 $S$ 的转换函数，也就是说，对于状态集合中的任何一个状态小 $s$ 以及字母表中的任何一个字母小 $a$，$\delta(s, a)$ 表示的是从状态 $s$ 出发，沿着标记为 $a$ 的边所能到达的状态，也就是状态 $s$ 对应输入符号 $a$ 的后继状态；$s_0$ 表示的是初始状态，或者叫开始状态；$F$ 表示的是终止状态或接收状态的集合。

我们来看一个确定的有穷自动机 DFA 的例子。在这个有穷自动机中，状态集合 $S$ 中包含四个状态，分别是状态 0、状态 1、状态 2 和状态 3；字母表中包含的元素分别是符号 a 和符号 b。下面我们来看一下 $\delta$ 函数，这里我们用一个表的形式来表示 $\delta$ 函数。

根据这个转换图我们可以看出：状态 0 在遇到符号 a 的时候进入到状态 1；状态 0 在遇到符号 b 的时候还是进入到状态 0。同样的道理，状态 1 在遇到符号 a 的时候还保持在状态 1；状态 1 在遇到符号 b 的时候进入到状态 2。状态 2 在遇到符号 a 的时候回到了状态 1，在遇到符号 b 的时候进入状态 3。状态 3 这里我用一个蓝点表示，它是终态。状态 3 遇到符号 a 的时候进入到状态 1；状态 3 遇到符号 b 的时候进入到状态 0。

这个表也称为转换表。我们说，一个有穷自动机既可以用转换图来表示，也可以用转换表来表示，这个转换图跟转换表，它们的功能是等价的。

下面我们再来看一下非确定的有穷自动机。非确定的有穷自动机简称 NFA，它跟确定的有穷自动机 DFA 的唯一区别就是：从状态 $s$ 出发，沿着标记为 $a$ 的边所能到达的状态可能有多个，并不是唯一确定的，所以叫非确定的有穷自动机。因此，这里 $\delta(s, a)$ 表示的是从状态 $s$ 出发，沿着标记为 $a$ 的边所能到达的状态集合。

下面我们来看 NFA 的一个例子。在这个自动机中，从初始状态 0，当它遇到符号 a 的时候，它进入的状态集合中包含状态 0 和状态 1 两个元素；在状态 0 遇到符号 b 的时候，它进入的状态集合只包含状态 0 一个元素。同理，在状态 1 遇到符号 b 的时候，进入到的状态集合只包含状态 2 一个元素；在状态 2 遇到符号 b 的时候，进入的状态集合中只包含状态 3。如果转换函数没有给出对应于某个状态输入对的信息的时候，我们就把空集放入到相应的表项中。

我们说，DFA 和 NFA 具有等价性，也就是说，对于任何一个 NFA $N$，存在识别同一语言的 DFA $D$；相应地，对于任何一个 DFA $D$，也存在识别同一语言的 NFA $N$。

下面我们来看一个例子。这是一个 NFA，刚才我们已经分析过了，它接收的是以 abb 结尾的 ab 串，那么我们可以构造跟它等价的 DFA。在这个 DFA 中，0 号状态是初始状态。在初始状态 0，无论来了多少个 b，都始终保持在状态 0，直到某一个时刻来了一个输入符号 a，这时候进入到状态 1；在状态 1，无论后面来了多少个 a，都始终保持在状态 1，因此状态 1 表示的是当前串以符号 a 结尾；在状态 1 如果遇到了符号 b，这时候就进入到了状态 2，因此状态 2 表示的是当前串以符号 ab 结尾；在状态 2 如果遇到了符号 a，这时候就破坏了状态 2 以 ab 结尾这样一个条件，这时候就退回到状态 1，表示当前串以符号 a 结尾；在状态 2 如果遇到符号 b，这时候就进入到状态 3，状态 3 表示的是当前串以 abb 结尾。

状态 3 是一个终止状态，如果这时候输入带上不再有新的符号出现，就表示这个 DFA 成功接收了一个以 abb 结尾的符号串；如果输入带上还有其他的符号，如果这个符号是 a 的话，那么就进入到状态 1，表示当前的串以符号 a 结尾，如果这个符号是 b 的话，就进入到状态 0。

由此可见，这个 DFA 它也是接收以 abb 结尾的 ab 串，因此这两个自动机它们识别的是同一个语言，因此说它们是等价的。事实上，这两个自动机识别的语言都可以用这个正则表达式来表示，也就是说以 abb 结尾的 ab 串。

事实上，正则表达式跟有穷自动机是等价的，也就是说，给定一个正则表达式，我们就可以构造一个跟它等价的有穷自动机；那么给定一个有穷自动机，我们也可以构造一个跟它等价的正则表达式。

我们在前面讲过，正则文法跟正则表达式也是等价的，因此它们三者之间是相互等价的，也就是说，给定了正则文法，我们可以构造跟它等价的有穷自动机；给定一个有穷自动机，我们也可以构造跟它等价的正则文法。

从这个例子我们可以看出，等价的 NFA 和 DFA 虽然它们可以识别同一个语言，但是从表现形式上来看，NFA 要比 DFA 更加直观。例如从这个 NFA 中，我们可以很容易看出，这个 NFA 识别的是以 abb 结尾的 ab 串；但是对于这个 DFA，我们要通过一系列的分析才能分析出它是识别以 abb 结尾的 ab 串。但是从计算机实现上来讲，DFA 要比 NFA 更容易实现。

事实上，NFA 的有向边上除了标记符号表中的字母以外，还可以标记空串。这样的 NFA 叫做带有空边的 NFA。那么从定义上可以看出，它的输入符号中包含空串。

下面我们来看一个带有空边的 NFA 的例子。在这个自动机中，状态 A 和状态 B 之间有一个标记为空串的有向边，它表示在状态 A 不需要遇到任何符号，就可以直接进入状态 B。但是状态 A 和状态 B 不是一回事，一旦进入了状态 B，就不再接收符号 0，而在状态 A 的时候是可以接收符号 0 的。

同样，状态 B 和状态 C 之间有一条标记为空串的有向边，它表示在状态 B 的时候不需要遇到任何符号，就可以直接进入状态 C，但是一旦进入了状态 C，将不再接收符号 1，而只能接收符号 2。

那么这个带有空边的 NFA，它接收的语言可以用这样一个正则表达式来表示，也就是说由若干个 0 连接上若干个 1，再连接上若干个 2。

事实上，带有空边和不带有空边的 NFA 也具有等价性，也就是说，给定一个带有空边的 NFA，我们可以构造一个与它等价的不带空边的 NFA；而对于一个不带空边的 NFA，我们也可以构造一个等价的带有空边的 NFA。

我们来看一个例子。这是一个带有空边的 NFA，那么通过我们前面的分析知道，这个 NFA 它识别的语言可以用这样一个正则表达式来表示，也就是说若干个 0 连接上若干个 1，再连接上若干个 2。

那么我们可以构造与它等价的不带空边的 NFA。在这个 NFA 中，状态 A 表示当前的串由若干个 0 连接而成，那么状态 B 表示的是当前的串由若干个 0 连接上若干个 1 构成，那么状态 C 表示的是若干个 0 连接上若干个 1，再连接上若干个 2 构成。

那么这里状态 A、状态 B 和状态 C，我们都可以概括为由若干个 0 连接上若干个 1，再连接上若干个 2 构成。因为在状态 A 的时候，我们可以认为 1 和 2 的个数都是 0；那么在状态 B 的情况下，我们可以认为 2 的个数都为 0。因为 A、B、C 都是终态，因此这个自动机它接收的语言也可以用这个正则表达式来表示，也就是说若干个 0 连接上若干个 1，再连接上若干个 2。

我们前面讲到，对于识别同一语言的等价的 NFA 和 DFA，从形式上来说，NFA 要比 DFA 更加地直观，但是从计算机实现上来说，DFA 要更加容易一些。下面我们就来给出 DFA 的算法实现。

这个算法的输入是以文件结束符 EOF 结尾的字符串 $x$；另外输入信息还包括 DFA 的开始状态 $s_0$、接收状态集合 $F$ 以及转换函数 move。这个算法的输出：如果这个 DFA 它接收这个符号串 $x$，则回答“yes”，否则回答“no”。

那么具体的算法如这个图所示：

```text
s = s0;
c = nextChar();
while (c != EOF) {
    s = move(s, c);
    c = nextChar();
}
if (s in F) return "yes";
else return "no";
```

首先将 DFA 的初始状态 $s_0$ 赋给变量 $s$，$s$ 表示的是当前状态；接下来调用 nextChar 函数返回输入串 $x$ 的下一个符号，把它赋给变量 $c$，$c$ 表示的是当前的输入符号。只要 $c$ 不等于文件结束符 EOF，那么就循环执行以下操作：首先调用 move 函数，$\text{move}(s, c)$ 表示从状态 $s$ 出发沿着标记为 $c$ 的边所能到达的状态，把这个状态赋给当前状态 $s$；接下来再返回输入串 $x$ 的下一个符号。

那么这个循环实际上就是依次从每一个状态根据当前的输入符号转移到下一个状态，直到遇到文件结束符号为止。当遇到文件结束符号的时候，如果当前状态在终止状态集合 $F$ 中，就表示这个 DFA 成功接收了这个输入串，我们就返回“yes”，否则的话返回“no”。

同学们好。前面我们学习了正则表达式和有穷自动机。

我们说，正则表达式采用的是一种符号序列的形式，它可以很直观地来描述单词的构成。但是，在构造分析器的时候，我们真正实现或模拟的是 DFA。因此，这就涉及到从正则表达式到 DFA 的转换，也就是我们这一章要介绍的，从正则表达式到有穷自动机。

我们说，从正则表达式直接构造 DFA 是比较困难的。比如说，给定这样一个正则表达式，我们很难直接构造出这个 DFA。所以我们通常是通过 NFA，也就是说，先将正则表达式转换成等价的 NFA。我们前面讲过，NFA 较 DFA 来讲，相对来说更加直观一些。因此，从正则表达式构造 NFA 是比较简单的。接下来，我们再从这个 NFA 来构造等价的 DFA。

我们先来看，根据正则表达式来构造 NFA。

根据前面正则表达式的定义，一个空串是一个正则表达式，它对应的 NFA 如这个图所示。在这个 NFA 中，有一个初始状态，有一个终止状态。在初始状态和终止状态之间，有一个标记为空串的有向边。它表示在初始状态的时候，不需要遇到任何符号，就可以直接进入终止状态，也就是说它接受一个空串。

我们说字母表中的每一个符号也是一个正则表达式，它对应的 NFA 就是在初始状态 $q_0$ 到终止状态 $q_f$ 之间的有向边上，标记输入符号 a。

如果 $r_1$ 和 $r_2$ 都是正则表达式的话，那么 $r_1$ 连接上 $r_2$ 也是一个正则表达式。它对应的 NFA 就是将 $r_1$ 和 $r_2$ 对应的 NFA 串联起来，也就是说首尾相连。

那么，$r_1$ 或 $r_2$ 也是一个正则表达式。它对应的 NFA 就是将 $r_1$ 和 $r_2$ 对应的 NFA 并联起来。

一个正则表达式，它的克林闭包还是一个正则表达式。它对应的 NFA 由这个图所示。我们说，$r_1$ 的克林闭包表示将若干个 $r_1$ 连接起来，因此它的 NFA 也是一个循环的形式。那么在这条可以循环的边上，标记上这个子表达式 $r_1$。

我们来看一个例子。假如说我们要将这样一个正则表达式转换成等价的 NFA。

首先，我们设置一个初始状态，一个终止状态。在初始状态和终止状态之间引一条边，边上标记上待转换的正则表达式。

接下来，我们可以将这个正则表达式进行分解，分解成四个子表达式连接的形式。这样的话，我们就可以把这个 NFA 分解成四部分串联的形式。那么，后三个部分已经不能再分解了。但是第一个部分可以继续分解。它表示的是一个子表达式的克林闭包的形式，那么我们可以把它转换成等价的 NFA 的形式，是一个循环的形式。那么在这条循环的边上，标记上子表达式 a 或 b。

这个边上的表达式可以进一步分解成两个子表达式进行或运算的形式，那么，我们可以对这个自动机进行进一步分解，把它分解成两个子表达式对应的自动机并联的形式，也就是表示成两条边并联的形式。

这样，对于给定的一个正则表达式，我们就构造出了跟它等价的 NFA。

[听音转录 · P17 3-6从NFA到DFA的转换]

同学们好，下面我们来学习从 NFA 到 DFA 的转换方法。

首先我们来看一个例子，这是一个 NFA。从它的初始状态 A，遇到输入符号 a 的时候，既可以进入到状态 A，也可以进入到状态 B。在状态 B 遇到输入符号 b 的时候，既可以进入状态 B，又可以进入状态 C。在状态 C 遇到输入符号 c 的时候，既可以进入到状态 C，又可以进入到状态 D。这就是它对应的转换表。

我们现在来构造跟它等价的 DFA。NFA 中的这个初始状态，在 DFA 中还是初始状态。这个初始状态 A 在遇到输入符号 a 的时候，既可以进入到状态 A，也可以进入到状态 B。虽然我们不能确定它到底是进入 A 还是进入到 B，但是我们可以确定，它肯定是进入二者中的一个。因此，我们构造一个新的状态，它是由状态 A 和 B 构成的集合。那么状态 A 遇到输入符号 a 的时候，肯定进入到这个状态。

事实上，与 NFA 等价的 DFA 中的每一个状态，都是一个由 NFA 中的状态构成的集合，也就是说，NFA 状态集合中的一个子集。

那么，这个状态遇到输入符号 a 的时候，又会进入到哪些状态呢？因为这个状态是由状态 A 和 B 组成的，因此，它遇到 a 时进入的状态，就是由 A 和 B 分别遇到 a 时进入的状态的和集。从转换表我们可以看出，A 和 B 遇到 a 的时候，可以进入的状态和集还是 A 和 B。因此，这个状态遇到 a 的时候，还是进入到状态 AB。

下面我们再来看一个带有空边的 NFA 的例子。这个 NFA 中，我们先来看一下从初始状态 A 遇到输入符号 0 的时候，都能进入到哪些状态。初始状态 A 遇到输入符号 0 的时候，首先能进入到状态 A。进入到状态 A 以后，它不用遇到任何符号就可以直接进入到状态 B，也就是说状态 A 遇到输入符号 0 的时候，除了进入状态 A，还可以进入状态 B。进入了状态 B 以后，它不用遇到任何输入符号，就可以直接进入到状态 C。因此，状态 A 遇到输入符号 0 的时候，除了可以进入状态 A 以外，还可以进入状态 B 和状态 C。

这是它的转换表。状态 A 遇到输入符号 0 的时候，既可以进入状态 A，又可以进入状态 B 和状态 C。

同学们好，下面我们来介绍识别单词的 DFA。

我们先来看识别标识符的 DFA。这是标识符的正则表达式。我们可以看出，标识符的正则表达式由两个子表达式构成，那么它的 DFA 也就由两部分串联起来。第一部分用来识别一个字母或者下划线，第二部分用来识别若干个由字母或下划线或数字组成的串。由于这个 NFA 本身就是一个 DFA，因此不需要进行转换。

下面我们来看识别无符号数的 DFA。这是无符号数的正则表达式，它由三部分构成。

第一部分是长度大于等于 1 的数字串，那么我们可以构造出它的 NFA，就是长度大于等于 1 的数字串。

第二部分是可选的小数部分。根据它的正则表达式，它是由两个子表达式进行或运算得到的。因此这一部分对应的 NFA 就是由两部分并联而成的。上面这一部分对应着第一个子表达式，也就是说小数点后面连接着长度大于等于 1 的数字串。第二部分就对应着第二个子表达式，是一个空串，也就是说从状态 1 可以直接进入状态 3。

数的第三部分，也就是可选的指数部分。根据它的正则表达式，它是由两个子表达式进行或运算得到的。因此它对应的 NFA 是由两部分并联而成。第一部分对应着前面的这个子表达式，也就是说字母 E 后面连接着一个正号或者一个负号，或者一个空串，然后连接着长度大于等于 1 的一个数字串。第二部分对应着第二个子表达式，是一个空串，也就是说从状态 3 可以直接进入到状态 6。

那么这个 NFA 中含有空边，所以我们要把它转换成等价的 DFA。我们这里运用子集构造法。首先 NFA 的初始状态也是 DFA 的初始状态 0。状态 0 在遇到数字 d 的时候，它既可以进入到状态 1，也可以沿着这个空边直接进入到状态 3，还可以沿着这个空边直接进入到状态 6。也就是说初始状态 0 在遇到符号 d 的时候，可以进入到状态 1、3 和 6。因此我们构造一个新的状态，它是由 1、3、6 三个状态构成的一个集合。

我们来看一下 1、3、6 这个状态在遇到一个数字 d 的时候进入到哪些状态。1 遇到数字 d 的时候进入到状态 1，只要进入到状态 1 就可以沿着空边一起进入到状态 3 和 6。状态 1 遇到数字 d 进入到状态 1、3、6。状态 3 遇到数字 d 的时候进入到 3 和 6，状态 6 遇到数字 d 的时候进入到 6。综合以上情况，也就是说状态 1、3、6 在遇到输入符号 d 的时候可以进入到状态 1、3、6，也就是还进入到它自己。

那么状态 1、3、6 除了遇到输入符号 d，还能遇到什么呢？状态 1 还可以遇到点号，状态 1 遇到点号的时候进入到状态 2。状态 3 不接受点号，状态 6 也不接受点号，所以状态 1、3、6 遇到点号的时候就进入到状态 2。

状态 1、3、6 是否还可以遇到其它的输入符号呢？状态 3 还可以遇到输入符号大 E。状态 3 遇到输入符号大 E 的时候进入到状态 4，只要进入到状态 4 就可以沿着这个空边进入状态 5。所以状态 3 遇到大 E 的时候，进入到状态 4 和 5。状态 1 和状态 6 都不接受符号大 E，所以状态 1、3、6 遇到大 E 的时候就是进入到 4 和 5。

我们再来看一下状态 1、3、6 是否还可以遇到其它的符号。不可以再遇到其它符号了。那么我们来看一下状态 2。状态 2 在遇到输入符号 d 的时候可以进入到状态 3，只要进入到了状态 3 就可以进入到状态 6。所以状态 2 在遇到输入符号 d 的时候进入到状态 3 和 6。状态 2 不会再遇到其它的输入符号。

接下来我们来看一下状态 3 和 6。状态 3 和 6 都能遇到哪些输入符号呢？状态 3 在遇到输入符号 d 的时候可以进入到状态 3，从而可以进入到状态 6，所以说状态 3 遇到输入符号 d 的时候进入到状态 3 和 6。状态 6 遇到符号 d 的时候进入到状态 6。把这两种情况结合起来，状态 3 和 6 遇到输入符号 d 的时候就还进入到它本身 3、6。

状态 3 和状态 6 可以遇到输入符号 E。状态 3 遇到输入符号 E 的时候进入到状态 4 和状态 5。状态 6 不会遇到输入符号 E。状态 3 和 6 不会再遇到其它的符号了。

我们再来看状态 4 和 5。状态 4 和 5 遇到正号或者负号的时候进入到状态 5。状态 4 还可以沿着这个空边遇到输入符号 d，状态 4 遇到输入符号 d 的时候进入到状态 6。状态 5 遇到输入符号 d 的时候进入到状态 6。状态 6 遇到输入符号 d 的时候还进入到状态 6。这样我们就构造了一个跟 NFA 等价的 DFA。

我们现在来检验一下这个 DFA 是不是识别无符号数的 DFA。首先从初始状态遇到一个数字 d 以后我们就进入到状态 1、3、6，这个状态可以接收若干个数字。如果此后不再有其它的符号，那么它就成功接收了一个整数。如果后面再有了点号，那么进入状态 2，此时就要继续接收小数部分。遇到数字 d 以后我们就进入到状态 3、6，继续接收若干个数字。如果此后不再有其它的输入符号的话，这个时候我们就成功地接收一个小数。如果此后在遇到输入符号大 E 的话，就说明这个数是带有指数部分的，我们继续往下进行，进行到状态 4、5 之后我们可以继续接收指数部分。我们也可以在整数部分直接通过输入符号 E 连接一个指数部分。因此这个 DFA 确实是一个识别无符号数的 DFA。

下面我们来看一下识别各进制无符号整数的 DFA。

首先来看一下识别十进制数的 DFA。这是识别八进制数的 DFA。这是识别十六进制数的 DFA。下面我们把这三个分别识别不同进制无符号整数的 DFA 整合成为一个统一的、可以识别各进制无符号整数的 DFA。识别后的 DFA 就是这个样子。

从初始状态如果遇到 1 至 9 中的一个数字，我们就进入到状态 1，它可以继续接收若干个 0 至 9 中的数字构成的数字串。最终我们将会识别十进制的整数。识别完之后我们把这个单词的 token 形式表示出来，它的种别码就是 DEC，表示是一个十进制数，后面是它的属性值。

在初始状态，如果遇到输入符号 0 的话，既可以进入到状态 2，又可以进入到状态 3，又可以进入到状态 5，所以我们构造一个新的状态，它是由状态 2、3、5 构成的一个集合。如果在这个状态之后输入串上不再有其它的符号的话，这个时候我们就把这个 0 识别成一个十进制的整数 0，它对应的 token 种别码是 DEC，表示它是一个十进制数，它的值就是 0。

在 2、3、5 这个状态，如果我们继续遇到了一个 1 至 7 中的数字，我们就进入到状态 4。状态 4 可以继续接收若干个 0 至 7 中的数字，最终我们将识别出一个八进制数，它的种别码是 OCT，表示八进制数，后面是它的属性值。

如果在 2、3、5 这个状态继续遇到了输入符号 x，我们就进入到状态 6。状态 6 遇到 1 至 f 中的一个数字以后进入到状态 7。状态 7 可以继续接收若干个由 0 到 f 之间的数字，最终我们可以识别一个十六进制数。

下面我们来看一下识别注释的 DFA。

在初始状态我们遇到斜杠以后进入到状态 1，表示当前的串是以斜杠结尾的。接下来如果我们遇到了星号，就进入到状态 2，表示当前串是以一个斜杠加上一个星结束的。在状态 2 此时如果遇到了星号以外的任何一个符号，我们都保持在状态 2，这个时候表示的是注释的内容，我们一直在状态 2 中接收注释的内容，直到在某一个时刻我们遇到了输入符号星号，这时候我们就进入到状态 3，说明注释结尾的那个星号已经出现了。在状态 3 如果还遇到星号的话，我们就一直保持在状态 3，也就是当前串是以星号结尾的。在状态 3 如果遇到了输入符号斜杠，我们就进入到状态 4，这时就可以成功接收一个注释。如果在状态 3 我们遇到了星号或斜杠之外的任何一个符号，这个时候就破坏了当前串以星号结尾这样一个条件，我们就需要退回到状态 2 重新来等待星号。这就是识别注释的 DFA。

最后我们可以把刚才讲过的识别不同的单词的 DFA 整合成为一个统一的识别各类单词的 DFA。也就是说在初始状态，输入串的第一个符号如果是一个字母或下划线，我们就进入了这个分支来识别标识符。识别完以后把标识符的 token 表示出来，它的种别码是 IDN，后面是它的属性值。如果输入串的第一个符号是一个数字，那么我们就进入这个分支来识别数。如果第一个符号是其它的字符，那么我们就进入到识别运算符和识别界符的分支。

这个 DFA 从初始状态开始，从左至右逐个扫描输入串上的每一个字符，每当识别出一个单词以后就把它表示成 token 的形式，然后退回到初始状态继续识别下一个单词。

在刚才的这个 DFA 中，我们没有提到关键字这个非常重要的单词类型。事实上，关键字它是字母组成的串，那么我们就可以用识别标识符的 DFA 来识别关键字。具体来说也就是每当识别出一个标识符以后，我们来查一下关键字表，如果这个字符串在关键字表中，那么我们就把这个字符串识别成一个关键字，如果不在的话，我们就把它识别成一个普通的标识符。

下面我们来看一下词法分析阶段的错误处理。事实上，词法分析器不仅要负责识别源程序中的单词，它还要负责检测源程序中可能存在的一些词法错误。因为无论程序员多么努力，程序中都会难免有错误。

词法阶段可以检测到的错误主要是单词拼写错误。比如说这就是一个错误的十六进制数，这就是一个错误的指数形式的浮点数。另一类错误就是非法字符。

我们如何检测到错误呢？如果当前的状态与当前的输入符号在转换表对应项中的信息为空，也就是说当前状态不可以遇到当前输入符，那么我们就报错，调用错误处理程序。

我们来看一下错误处理程序是如何做的。根据最长子串匹配原则，错误处理程序查找已扫描字符串中最后一个对应于某终态的字符。如果找到了这样一个字符，那么说明我们已经在前面成功地识别了一个单词。这时我们就将该字符以及前面的字符识别成一个单词，然后将输入指针退回到该字符，扫描器重新回到初始状态，继续识别下一个单词。

如果没找到对应于某终态的字符，也就是说这时确实是出错了。这个时候必须以一定的方式进行处理，使编译器能够继续运行下去，也就是说从错误状态尽快恢复过来，以检测源程序中更多的错误。

这种错误处理的方式就叫做错误恢复。最简单的错误恢复策略是恐慌模式，也就是说从剩余的输入中不断地删除字符，直到词法分析器能够在剩余输入的开头发现一个正确的字符为止。
