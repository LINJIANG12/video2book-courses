[听音转录 · P19 4-1自顶向下分析概述]
> 来源：**听音转录**——非平台字幕，由讲师原声转录

同学们好，今天我们来学习第四章语法分析。我们在第一章绪论中曾经讲过，语法分析的基本任务就是根据给定的文法识别输入句子中的各类短语，并构造它的分析树。

如果输入串的各个单词恰好自左至右地站在分析树的各个叶结点上，那么这个词串就是该语言的一个句子，否则就不是。

按照分析树的构造方向，我们可以把语法分析分为两类。第一类就是从顶部的根结点向底部的叶结点方向构造分析树，这种方法称为自顶向下的语法分析。第二类方法就是从底部的叶结点向顶部的根结点方向构造分析树，这种方法叫做自底向上的分析方法。我们首先来看自顶向下的分析方法。

自顶向下的分析方法是从分析树的顶部根结点向底部叶结点方向构造分析树。由于分析树的根结点对应着文法的开始符号，分析树的叶结点对应着输入串中的各个单词，因此自顶向下的分析可以看成是从文法的开始符号 $S$ 推导出词串 $w$ 的过程。

我们来看一个例子。这是一个简化版本的算术表达式文法，这是一个输入的单词串，我们来构造它的分析树。首先我们构造分析树的根结点，它对应着文法的开始符号 $E$，那么我们就从文法开始符号 $E$ 开始推导。

首先我们对树的根结点应用第一个产生式，那么生成三个子结点 $E+E$。也就是说，从文法的开始符号推导出句型 $E+E$。

接下来，我们对这个结点应用第三条产生式，生成三个子结点：括号、$E$、反括号，也就是说将这个非终结符替换成括号、$E$、反括号。

接下来，我们再对这个结点应用第一条产生式，生成三个子结点，也就是说将这个非终结符替换成 $E+E$。

接下来，我们再对这个结点应用第四条产生式，生成子结点 id，也就是说将这个非终结符替换成 id。

接下来，我们再对这个结点应用第四条产生式，生成一个子结点 id，也就是说将这个非终结符替换成 id。

最后，我们对这个结点应用第四条产生式，生成子结点 id，那么也就是说将这个非终结符替换成 id。那么输入串中的各个单词恰好自左至右地站在分析树的各个叶结点上，因此这个输入的词串就是该语言的一个句子。

在每一步推导中都需要做两个选择。第一个选择就是替换当前句型中的哪一个非终结符；第二个选择就是用该非终结符的哪个候选式进行替换。

为了回答这个问题，我们先来学习两个概念。首先来看一下最左推导。在最左推导中，总是选择每个句型的最左非终结符进行替换。

我们来看刚才这个例子。我们从文法的开始符号 $E$ 进行推导，最开始的时候句型中只有一个符号，就是文法的开始符号，那么它就是当前句型的最左非终结符。我们应用第一条产生式把它替换成 $E+E$。那么当前的句型就是 $E+E$。在这个句型中最左非终结符就是 $E$，我们对它应用第四条产生式，可以把这个 $E$ 替换成 id。这个时候句型的最左非终结符变成了 $E$。这个时候我们再应用第三条产生式，把它替换成括号 $E$。这个时候最左非终结符是这个 $E$，我们再应用第一条产生式，把这个 $E$ 替换成 $E+E$。此时的最左非终结符是 $E$，我们再应用第四条产生式把它替换成 id。这个时候最左非终结符又是 $E$，我们再应用第四条产生式把它替换成 id。那么这个自顶向下的过程就是推导过程，每一步我们都是替换当前句型中的最左非终结符。

与它相反的这个自底向上的过程称为最右规约。最右规约是最左推导的逆过程。从文法的开始符号经过最左推导得到的句型称为最左句型，LM 代表的是最左，leftmost。

下面我们再来看一下最右推导的概念。在最右推导中，总是选择每个句型的最右非终结符进行替换。还是刚才这个例子，我们在每步的推导过程中都是替换最右面的非终结符：把它替换成括号 $E$，再把它替换成 $E+E$，再把它替换成 id，再把它替换成 id，最后把它替换成 id。这个自顶向下的过程就是最右推导，与它相反的自底向上的过程就是最左规约。最左规约是最右推导的逆过程。

我们在后面自底向上分析中将会讲到，自底向上的分析总是采用最左规约的方式，因此把最左规约称为规范规约，与它相对应的最右推导就称为规范推导。

下面我们来看一下最左推导和最右推导的唯一性。给订一个分析树，它对应的推导可能不是唯一的，因为在推导的每一步，我们可以选择当前句型中的任意一个非终结符进行替换。但是每棵分析树它对应的最左推导和最右推导都是唯一的，因为在推导的每一步，当前句型中的最左非终结符和最右非终结符都是唯一的。

例如对于这个分析树来说，这些都是它对应的推导，但是最左推导和最右推导却是唯一的。

由于分析器都是自左向右地扫描输入串，所以自顶向下的语法分析采用最左推导的方式，也就是说总是选择每个句型的最左非终结符进行替换。替换的时候，根据输入流中的下一个终结符来选择最左非终结符的一个候选式。

我们来看一个例子。这是一个文法，这是一个输入的词串。初始的时候，输入指针指向输入词串的第一个单词 id。接下来我们从文法的开始符号来进行推导。文法的开始符号 $E$ 对应着第一条产生式，我们把这个大 $E$ 替换成 $TE'$，得到了句型 $TE'$。这个 $T$ 就是当前句型的最左非终结符。$T$ 对应的产生式是第三条产生式，我们将第三条产生式应用于最左非终结符 $T$，得到了句型 $FT'E'$。这个时候的最左非终结符是 $F$。$F$ 对应着两条候选式，第一个候选式以左括号开头，第二个候选式以 id 开头。由于当前的输入符号是 id，所以我们选择第二条候选式，也就是说把 $F$ 替换成 id。这个时候当前的输入符号 id 被匹配上了，输入指针就移向下一个单词加号。

现在句型中的最左非终结符是 $T'$。$T'$ 对应着两个候选式，第一个候选式是以星号开头，而我们当前的输入符号是加号，所以我们只能选择第二个候选式，把 $T'$ 替换成空。这个时候的最左非终结符就是 $E'$ 了。$E'$ 有两个候选式，第一个候选式以终结符加号开头，我们当前的输入符号恰好是加号，因此我们选择第一个候选式，把 $E'$ 替换成 $+TE'$。这个时候当前的输入单词加号被匹配上了，输入指针指向下一个单词 id。

这个时候的最左非终结符是大 $T$。大 $T$ 只有一个产生式，我们把它替换成 $FT'$。现在最左非终结符是 $F$，$F$ 有两个候选式，我们根据当前的输入符号选择第二个候选式，把 $F$ 替换成 id。这个时候当前的输入符号 id 被匹配上了，输入指针指向下一个单词乘号。

现在最左非终结符变成了 $T'$，它有两个候选式。第一个候选式恰好以当前的输入符号星号打头，我们就采用第一个候选式，把 $T'$ 替换成 $*FT'$。当前的输入单词星号匹配成功，我们将输入指针指向下一个单词 id。

现在最左非终结符 $F$ 有两个候选式，我们根据当前的输入符号选择第二个候选式，把 $F$ 替换成 id。当前输入符号 id 匹配成功，我们将输入指针指向下一个单词。此时 id 是输入串的最后一个单词，后面已经没有单词了，所以输入指针指向了一个空串。

现在最左非终结符是 $T'$。$T'$ 有两个候选式，由于当前的输入指针指向了空串，所以我们就选择它的第二个候选式进行替换，把 $T'$ 替换成空。现在剩下的最后一个非终结符是 $E'$。$E'$ 对应着两个候选式，当前的输入指向空串，所以我们采用第二个候选式，把 $E'$ 替换成空串。

现在输入中的各个单词 $\text{id} + \text{id} * \text{id}$ 恰好自左至右地站在分析树的各个叶结点上，所以这个词串就是该语言的一个句子。我们可以看出，这个文法是用来描述算术表达式的一个文法。

计算机是如何自动实现自顶向下的语法分析的呢？它采用的是递归下降分析。递归下降分析由一组过程组成，每个过程对应一个非终结符，也就是说文法中有多少个非终结符，就有多少个过程。

这是对应于非终结符 $A$ 的过程。在这个过程中，首先根据输入符号选择 $A$ 的一个产生式，假如说这个 $A$ 定义为 $X_1 X_2 \dots X_k$。接下来，我们对产生式右部中的每一个符号来进行操作。如果这个符号 $X_i$ 是一个非终结符的话，它就有它自己对应的过程，这个时候我们就递归调用非终结符 $X_i$ 对应的过程。如果 $X_i$ 不是一个非终结符，那么它就是一个终结符。如果 $X_i$ 等于当前的输入符号，也就是说当前的输入符号匹配成功，这个时候输入指针就指向下一个单词。

我们从文法开始符号 $S$ 对应的过程开始，其中会递归调用文法中其他非终结符对应的过程。如果 $S$ 对应的过程体恰好扫描了整个输入串，那么这个输入串就是该语言对应的一个句子。

在 $A$ 的工作过程中，虽然我们是根据输入符号来选择产生式，但是我们仍然会遇到一些不确定的情况。比如说对于当前的输入符号 $a$，$A$ 存在多个以终结符 $a$ 打头的候选式的时候，这个时候我们就不能确定选择哪一个，那么我们就要按照一定的顺序逐个尝试。如果尝试失败的时候，就要退回到上一步，然后再来看看 $A$ 是否还具有其他的候选式。这个退回到上一步来重新尝试的过程就称为回溯。

回溯会影响分析器的效率，需要回溯的分析器叫做不确定的分析器。如果在分析的过程中，我们能预测出正确的产生式，那么就不需要回溯。这种分析叫做预测分析。

预测分析是递归下降分析技术的一个特例，它通过在输入中向前看固定个数符号，通常是一个，来选择正确的 $A$ 产生式。我们可以对某些文法构造出向前看 $k$ 个输入符号的预测分析器，这类文法也称为 $\text{LL}(k)$ 文法类。预测分析不需要回溯，它是一种确定的自顶向下分析方法。

同学们好，下面我们来学习文法转换。事实上，并不是所有的文法都适合于自顶向下的分析。在这一部分中，我们首先会通过几个例子来说明自顶向下的分析中会遇到什么问题，然后我们来介绍如何改造文法，使这些文法适合于自顶向下的分析。

我们先来看第一个问题。来看这样一个例子，假如由这样一个文法，输入符号串是 $abc$。初始的时候，输入指针指向第一个符号 $a$，那么我们从文法开始符号 $S$ 开始推导。$S$ 的两个候选式都是以当前的输入符号 $a$ 开头的，那么这个时候我们就不能确定选择哪一个，就产生了回溯。也就是说，当同一个非终结符的多个候选式存在共同前缀的时候，就会导致回溯现象。

我们再来看第二个问题，这是一个简化版本的算术表达式文法，这是一个输入的词串。初始的时候，输入指针指向串首的第一个单词 id，我们从文法的开始符号开始推导。文法的开始符号它的各个候选式都不是以终结符 id 开头的，所以我们要逐个尝试。我们先尝试第一个候选式，也就是说从文法的开始符号推导出句型 $E + T$。这个时候，最左非终结符还是 $E$。在刚才的推导过程中，当前的输入符号没有被匹配，因此输入指针还是指向 id。在相同的条件下，意味着我们还要进行相同的选择，就是还选择第一个候选式，把这个 $E$ 替换成 $E + T$，然后把这个 $+ T$ 照抄下来。这个时候，当前句型的最左非终结符还是 $E$，输入指针还是指向 id，也就意味着我们还要进行相同的选择。如此重复下去，将陷入无限循环。

产生这个问题的根源是因为这个产生式的右部的第一个符号与左部是相同的，都是 $E$。这就导致推导之后生成的句型的最左非终结符没有改变，这样我们就要重复采用同样的操作，陷入了无限循环。

我们将含有 $A \to A\alpha$ 形式的产生式的文法称为是直接左递归文法。如果文法中的某一个非终结符 $A$ 可以推导出以 $A$ 打头的串，那么这样的文法就称为是左递归文法。经过两步或两步以上推导产生的左递归称为是间接左递归。刚才这个直接左递归是经过一步推导就可以产生的左递归。左递归文法会使递归下降分析器陷入无限循环，因此我们要想办法消除左递归。

我们先来看如何消除直接左递归。对于直接左递归产生式 $A \to A\alpha \mid \beta$，$\beta$ 是不以 $A$ 开头的串。我们先来看这个 $A$ 产生式它会产生什么样的符号串。我们根据 $A$ 的第一个候选式 $A \to A\alpha$，可以得到 $A$ 可以推导出 $A\alpha$。我们将串首的这个非终结符 $A$ 再应用第一个候选式，可以把它替换成 $A\alpha$，后面的 $\alpha$ 照抄下来，也就是推导出 $A\alpha\alpha$。这个时候我们再将串首的非终结符 $A$ 替换成 $A\alpha$，最后得到 $A\alpha\alpha\alpha$。如此循环下去，我们就会得到一个非终结符 $A$ 打头的 $\alpha$ 串。最后，我们将 $A$ 根据第二个候选式把它替换成 $\beta$，所以这个 $A$ 产生式生成的实际上是一个 $\beta$ 打头的 $\alpha$ 串。因为 $A$ 可以直接替换成 $\beta$，所以 $\alpha$ 的个数可以是 $0$。它对应的正规表达式就是 $\beta\alpha^*$（$\beta$ 连接上 $\alpha$ 的克林闭包）。

现在我们知道了 $A$ 可以推导出 $\beta$ 打头的 $\alpha$ 串，那么我们就要想办法构造一个实现等价功能的不含直接左递归的产生式。因为 $A$ 推导出的串是以 $\beta$ 打头，所以我们可以写成 $A \to \beta A'$，$A'$ 是我们新引入的一个非终结符。这样 $A$ 推导出的符号串肯定就是以 $\beta$ 打头了。$A'$ 的任务就是生成若干个 $\alpha$。这很简单，我们可以将 $A'$ 定义成 $\alpha A'$ 或者是空（$\epsilon$）。因为 $A'$ 可以定义成 $\alpha A'$，所以 $A'$ 可以推导出 $\alpha A'$。我们将后面的 $A'$ 再替换成 $\alpha A'$，可以得到 $\alpha\alpha A'$；将这个 $A'$ 再替换成 $\alpha A'$，可以得到 $\alpha\alpha\alpha A'$。如此循环下去，我们就可以得到若干个 $\alpha$ 后面连接上一个 $A'$。最后我们将这个 $A'$ 替换成空串，得到的就是若干个 $\alpha$。我们在 $A'$ 前面连接上一个 $\beta$，因此 $A$ 就可以推出 $\beta$ 打头的 $\alpha$ 串。由于 $A'$ 可以替换成空，所以 $\alpha$ 的个数是可以为 $0$ 的。这个 $A$ 生成的串也可以用这个表达式来表示。因此，上下两个产生式它们完成的是同样的功能。

事实上，这种消除的过程就是把左递归转换成了右递归。左递归是说 $A \to A\alpha$，右递归就是 $A' \to \alpha A'$。

我们来看一个例子。这个就是我们刚才说的那具有直接左递归的文法，我们用这个算法来对这个文法进行改造。在这里面，$E$ 就对应着算法中的 $A$，$+ T$ 就对应着算法中的 $\alpha$，$T$ 就对应着算法中的 $\beta$。现在我们来进行文法转换。把 $A$、$\beta$ 和 $\alpha$ 代入到这个式子中，把 $A$ 替换成 $E$，把 $\beta$ 替换成 $T$，把 $A'$ 替换成 $E'$，把 $\alpha$ 替换成 $+ T$，把 $A'$ 替换成 $E'$，把空串照抄下来。第一个产生式就改造成了等价的产生式。同样，我们可以将第二个产生式也改造成等价的产生式。第三个产生式由于它不含有直接左递归，因此我们可以把它直接照抄下来。

以上的方法可以很容易地扩展到一般形式。对于直接左递归：

$$A \to A\alpha_1 \mid A\alpha_2 \mid \dots \mid A\alpha_n \mid \beta_1 \mid \beta_2 \mid \dots \mid \beta_m$$

我们将其转换成：

$$A \to \beta_1 A' \mid \beta_2 A' \mid \dots \mid \beta_m A'$$

$A'$ 又定义为：

$$A' \to \alpha_1 A' \mid \alpha_2 A' \mid \dots \mid \alpha_n A' \mid \epsilon$$

消除左递归是需要付出代价的，也就是要引进一些非终结符和空产生式。

刚才消除了直接左递归，间接左递归怎么消除呢？我们来看一个例子。在这个文法中，文法的开始符号 $S$ 可以替换成 $Aa$。这个 $A$ 又根据 $A$ 的第二个候选式可以替换成 $Sd$，然后将 $a$ 照抄下来。也就是说，文法的开始符号 $S$ 经过两步推导，推出了一个 $S$ 打头的串，因此它是一个间接左递归。我们怎么来消除呢？这里我们采用代入的方法。我们将 $S$ 的定义代入到 $A$ 的产生式中，将这里的 $S$ 替换成 $Aa$ 或者 $b$。把这个 $S$ 替换成 $Aa$ 或者替换成 $b$。这个时候我们来消除 $A$ 产生式的直接左递归，得到这样两个产生式。这是 $S$ 产生式，这是 $A$ 产生式。由于 $A$ 产生式中不再含有 $S$，所以不会再产生间接左递归。

这是消除左递归的算法。算法的输入是不含循环推导和空产生式的文法。所谓循环推导就是从非终结符 $A$ 经过若干步推导又推出了非终结符 $A$ 这样的推导。只要文法中不含有循环推导和空产生式，我们就可以输出等价的无左递归的文法。这个算法同学们可以在课下仔细阅读，根据我们刚才给出的例子很容易理解。

现在左递归消除了，我们再回到第一个问题，也就是原文法中的某个符号它的多个候选式存在公共前缀的情况。这个时候我们可以将这个公共前缀提取出来，把它改写成：

$$S \to aS'$$

把这个公共前缀 $a$ 提取出来，后面连接上一个 $S'$。$S'$ 可以定义为：

$$S' \to Ad \mid Be$$

这种方法叫做提取左公因子方法。这个方法实际上是通过改写产生式来推迟决定，等读入了足够多的输入、获得足够信息后，再做出正确的选择。

这是提取左公因子的算法。算法的输入是一个文法，输出的是等价的提取了左公因子的文法。这个算法非常简单，同学们可以课下仔细阅读。

同学们好。下面我们来介绍 LL(1) 文法。

我们在前面讲到，递归下降分析可能会遇到回溯，回溯会影响分析器的效率。如果在分析的每一步我们都能够预测出正确的选择的话，就不需要回溯。这样的分析称为是预测分析。那么，什么样的文法才能使用预测分析技术呢？这就是我们接下来要介绍的 LL(1) 文法。

首先，我们从 S-文法讲起。我们先来看一下预测分析法的工作过程。从文法开始符号出发，在每一步推导过程中，根据当前句型的最左非终结符 $A$ 和当前输入符号 $a$，选择正确的 $A$ 产生式。为了保证分析的确定性，选出的候选式必须是唯一的。要想让分析器以这样的方式进行工作，我们希望文法最好满足以下两个条件：第一个条件就是，每个产生式都以终结符开始；第二个条件是，同一非终结符的各个候选式的首终结符都不相同。这样的话，根据当前的输入符号，我们最多能选出一个候选式，就不会产生冲突。那么，满足这两个条件的文法就叫做是 S-文法。

根据 S-文法的定义我们可以看出，S-文法中不包含空产生式，这就限制了它的应用。那么，如果文法中包含空产生式，会产生什么问题呢？我们先来看一个例子。

假如由这样一个文法，输入的符号串是 $ada$，那么初始的时候，输入指针指向输入串的第一个符号 $a$。我们从文法开始符号 $S$ 开始推导。首先，根据第一个产生式，我们将文法开始符号 $S$ 推导出 $aBC$。这个时候，当前的输入符号 $a$ 匹配成功，那么我们把输入指针指向下一个符号。当前的最左非终结符是 $B$，$B$ 有三个候选式，分别对应着第二个、第三个和第四个产生式。那么当前的输入符号是 $d$，我们应该选择哪个候选式呢？很显然，我们应该选择第三个候选式，把 $B$ 替换成 $d$ 和 $B$。这个时候，当前的输入符号 $d$ 也得到了匹配，我们把输入指针指向下一个符号 $a$。此时的最左非终结符是 $B$，那么 $B$ 遇到 $a$ 的时候，应该选择哪个候选式呢？显然，第二个和第三个产生式都不合适，那么我们只能选择第四个产生式，把 $B$ 替换成一个空串。这个时候，最左非终结符就变成了 $C$。那么 $C$ 遇到 $a$ 的时候，应该选择哪个候选式呢？显然是选择第六个产生式，把 $C$ 替换成 $a$。这样输入中的三个符号就全部匹配成功。

由此可见，在其他候选式都不合适的情况下，如果这个非终结符存在空产生式的话，我们可以使用空产生式。但是，这种方法是否总能见效呢？我们再来看一个例子。

假如输入的符号串是 $ad$ 和 $e$，那么初始的时候，输入指针指向第一个符号 $a$。我们开始推导。首先将文法开始符号根据第一条产生式替换成 $aBC$。这个时候，第一个符号 $a$ 匹配成功，输入指针指向第二个符号 $d$。当前的最左非终结符是 $B$，$B$ 遇到 $d$ 的时候，根据 2、3、4 三个产生式，我们选择第三个产生式，把 $B$ 替换成 $d$ 和 $B$。这个时候，第二个输入符号 $d$ 也匹配成功，输入指针指向第三个符号 $e$。那么最左非终结符 $B$ 遇到 $e$ 的时候，显然第二个产生式和第三个产生式都不合适，那么这个时候我们用第四个产生式，把 $B$ 替换成一个空串。这个时候，最左非终结符变成了 $C$。那么 $C$ 遇到 $e$ 的时候，我们选择哪个候选式呢？我们根据第五个和第六个产生式来看，$C$ 能推导出 $c$ 和 $a$，但是却推导不出 $e$。

从这个例子我们可以看出，空产生式不是可以随便使用的。那么，我们在什么时候可以使用空产生式呢？从这个例子我们可以看出，能否使用 $B$ 的空产生式，关键取决于 $B$ 的后面都能紧跟出现哪些终结符。从这个例子我们可以看出，$B$ 的后面可以连接符号 $C$，而 $C$ 能推导出 $c$ 和 $a$，因此 $c$ 和 $a$ 可以紧跟在 $B$ 的后面出现。因此，当前输入符号是 $a$ 的时候，我们可以使用 $B$ 的这个空产生式；而当前输入符号是 $e$ 的时候，我们用 $B$ 的空产生式就是徒劳的。

那么我们总结一下：如果当前某非终结符 $A$ 与当前输入符 $a$ 不匹配的时候，如果存在 $A$ 的空产生式，可以通过检查 $a$ 是否可以出现在 $A$ 的后面来决定是否使用这个空产生式。当然，如果文法中不存在 $A$ 的空产生式的话，则应该直接报错。由此可见，空产生式的使用取决于当前非终结符它的后面都能紧跟哪些终结符。由此，我们引入非终结符的后继符号集的概念。

非终结符 $A$ 的后继符号集是指可能在某个句型中紧跟在 $A$ 后边的终结符 $a$ 的集合，记作 $\text{FOLLOW}(A)$。那么我们约定，任何一个句子的末尾都隐含地连接着一个特殊的符号——结束符，我们用 dollar 符号（$\$$）表示。因此，如果 $A$ 是某个句型的最右符号，我们就将结束符 $\$$ 添加到 $A$ 的 FOLLOW 集中。

那么我们再回到刚才这个例子，我们通过肉眼可以分析出，$B$ 的后面可以紧跟终结符 $a$ 和 $c$，因此 $B$ 的 FOLLOW 集中就包含 $a$ 和 $c$。那么，当前的输入符号如果是 $b$ 的时候，我们就选择第二个产生式；当前输入符号如果是 $d$ 的时候，我们就选择第三个产生式；如果当前的输入符号是 $a$ 或者 $c$ 的时候，我们就选择第四个产生式——空产生式。由于 $B$ 的这三个候选式对应的输入符号是互不相交的，因此我们可以做出唯一的选择。

为了叙述上的方便，我们引入一个概念，就是产生式的可选集。产生式的可选集是指可以选用该产生式进行推导时对应的输入符号的集合，也就是说，遇到这些输入符号的时候，就可以选用这个产生式。产生式的可选集记为 $\text{SELECT}(\text{产生式})$。那么对于一个产生式，如果它的右部的第一个符号是一个终结符的话，那么这个产生式的 SELECT 集中就只包含这个终结符一个元素，也就是说，只有遇到这个终结符的时候，才可以选用这个产生式。如果产生式的右部是空串的话，那么只有遇到 $A$ 的 FOLLOW 集中的元素的时候，才可以选用这个产生式，因此，这个产生式的 SELECT 集就是 $A$ 的 FOLLOW 集。对于具有相同左部的各个产生式，如果它们的 SELECT 集互不相交的话，我们就可以做出确定的分析。

因此，我们给出 q-文法的定义。q-文法就是每个产生式的右部要么是空串，要么以终结符开始，而且具有相同左部的产生式具有不相交的可选集。

我们可以看出，q-文法较 S-文法功能更加强大，因为它允许产生式的右部是空串。但是，它对产生式的右部限制依然非常严格，它不容许产生式的右部以非终结符打头，这就限制了它的应用。因此，我们需要引入功能更加强大的文法，这就是我们接下来要介绍的 LL(1) 文法。

在 LL(1) 文法中，我们允许产生式的右部以非终结符打头，这就增加了计算可选集的复杂性。由此我们要引入串首终结符集的概念。我们先来看什么是串首终结符。串首终结符是串首的第一个符号，并且是终结符。串首终结符通常也简称首终结符。

给定一个文法符号串 $\alpha$，$\alpha$ 的串首终结符集表示成 $\text{FIRST}(\alpha)$。它被定义为：可以从串 $\alpha$ 推导出的所有串首终结符构成的集合。如果 $\alpha$ 可以推导出空串的话，那么空串也在 $\alpha$ 的 FIRST 集中。那么 $\alpha$ 能推导出空串是什么意思？也就是说，串 $\alpha$ 中的每一个符号都是非终结符，而每一个非终结符都能推导出空串。

有了串首终结符集的概念，我们来重新定义产生式的可选集。对于产生式 $A \to \alpha$：如果 $\alpha$ 的 FIRST 集中不包含空串，也就是说，$\alpha$ 的 FIRST 集中全都终结符的话，那么这个时候，这个产生式的 SELECT 集就是 $\alpha$ 的 FIRST 集；如果 $\alpha$ 的 FIRST 集中包含空串的话，也就是说产生式的右部 $\alpha$ 可以推导出空串的话，那么产生式的 SELECT 集中除了包含 $\text{FIRST}(\alpha)$ 中的终结符以外，还包含 $A$ 的 FOLLOW 集中的元素。

最后我们来定义什么是 LL(1) 文法。文法 $G$ 是 LL(1) 的，当且仅当 $G$ 的任意两个具有相同左部的产生式 $A \to \alpha \mid \beta$ 满足下面的条件：
第一个条件，如果 $\alpha$ 和 $\beta$ 均不能推导出空串，也就是说 $\alpha$ 和 $\beta$ 的 SELECT 集分别是 $\alpha$ 和 $\beta$ 的 FIRST 集，那么这个时候我们要求 $\alpha$ 和 $\beta$ 的 FIRST 集互不相交，这样 $\alpha$ 和 $\beta$ 的 SELECT 集也就互不相交。
第二个条件，$\alpha$ 和 $\beta$ 至多有一个能推导出空串，也就是说不能都推导出空串。因为如果 $\alpha$ 和 $\beta$ 都能推导出空串的话，那么他们俩的 SELECT 集中就都包含 $\text{FOLLOW}(A)$，这样的话他们的 SELECT 集就相交了，所以 $\alpha$ 和 $\beta$ 至多只能有一个推导出空串。
第三个条件，如果 $\beta$ 能推导出空串的话，那么 $\beta$ 的 SELECT 集中就包含 $\text{FOLLOW}(A)$，那么这个时候 $\alpha$ 的 FIRST 集中就不能再包含 $\text{FOLLOW}(A)$ 中的元素，否则的话，$\alpha$ 和 $\beta$ 的 SELECT 集就会相交。同理，如果 $\alpha$ 能够推导出空串的话，那么 $\beta$ 的 FIRST 集中也不能包含 $\text{FOLLOW}(A)$ 中的元素。

那么第三个条件就是为了保证同一非终结符的各个产生式的可选集互不相交。由于 LL(1) 文法中同一非终结符的各个候选式的 SELECT 集互不相交，因此我们可以为 LL(1) 文法构造预测分析器。

最后我们来解释一下 LL(1) 文法中这三个字符的含义。这个 L 是左的意思，Left。第一个 L 表示从左向右扫描输入；第二个 L 表示产生最左推导；那么这个 1 表示在每一步中只需要向前看一个输入符号，就可以决定语法分析器的动作。
