## 数字系统导论：从开关晶体管到时钟同步机器
> 对应块：BLK15 | 覆盖分集：P15 | 块标题（分集名）：《第 14 讲 - 数字系统导论》

今天我们要正式开启一段全新的旅程。

在前几周里，我们一直沉浸在计算机系统的高层软件抽象之中：我们写 C 语言代码，探讨内存布局，分析编译器如何把高级语言翻译成汇编，再看着汇编器与链接器把它们打包成可在机器上运行的二进制机器码。可以说，软件层面的抽象金字塔我们已经全部走通了。

### 穿透抽象层：为什么软件工程师要向下看

#### 站在计算机体系结构的转折点

在深入底层电路之前，我们先跳出来看一眼全景。

回顾计算机的发展史，在过去的经典视角（Old School）里，我们往往只关注一台单核计算机内部的计算与存储。但现代计算机科学（New School）已经发生了天翻地覆的演进：你的笔记本电脑早已拥有多个物理核心，多颗 CPU 协同工作；而在数据中心与仓库级计算机（Warehouse-Scale Computers, WSC）中，数以万计甚至数以百万计的计算节点被高速互联网络交织在一起。

> **定义**：并行性（Parallelism）贯穿于现代计算的各个抽象层次。从仓库级的大规模分布式计算，到单机多核的多线程并发，再到处理器内部的流水线与指令级并行，直至最底层的位级（Bit-level）与门级（Gate-level）硬件逻辑并行。

今天以及接下来的几堂课，我们探讨的正是这个并行世界中最底层、最极致的形态——硬件逻辑中的并行运算。我们将从最简单的逻辑门开始，逐步搭建出算术逻辑单元（ALU）和控制通路。

```text
+-------------------------------------------------------------+
| 高层软件：C / Python / Java 等高级应用程序                     |
+-------------------------------------------------------------+
| 系统软件：操作系统、编译器、汇编器、链接器                      |
+-------------------------------------------------------------+
| 指令集架构（ISA）：软硬件之间神圣的交乘契约（如 RISC-V）        | <--- 汇合点
+=============================================================+
| 微架构与数字逻辑：数据通路、控制器、状态机、ALU                 |
+-------------------------------------------------------------+
| 基础门级电路：与、或、非、与非门、寄存器                         |
+-------------------------------------------------------------+
| 物理底层：CMOS 晶体管与开关网络                               | <--- 我们现在的位置
+-------------------------------------------------------------+
```
*图解：CS61C 硬件抽象层次。我们将从最底层的晶体管开关出发，自底向上构建，最终在 ISA 层与软件无缝对接。*

#### 懂硬件才能写出极致性能

有人可能会问：“我未来大概率是一名纯软件工程师，为什么要花几周时间去折腾这些电路与晶体管？”

我的回答是：如果你完全不懂硬件的真实机理，你永远无法真正写出高性能的代码，更谈不上设计优秀的系统与架构。

试想一下：如果你在写程序时，以为访问内存和执行一条加法指令耗费的时间差不多，你就会在代码里肆无忌惮地到处读写内存。但现实是怎样的呢？

> **提示**：在现代硬件中，一次主存访问的延迟可能是执行一条通用算术指令的数百倍（甚至高达 500 倍）。

当你深刻意识到这 500 倍的时间鸿沟时，你脑海里的性能直觉会发生质的飞跃：你会拼尽全力去复用寄存器，去优化数据局部性以榨干 CPU 缓存，而不是动不动就向内存发起请求。你编写代码的思路会完全脱胎换骨。

此外，放眼加州大学伯克利分校的课程体系（在 HKN 课程依赖树中），CS61C 是整个硬件与芯片方向的核心枢纽。向后延伸，有专攻数字集成电路设计的 CS150/EECS151，有深耕先进计算机架构的 CS152，还有涉及特定领域架构（Domain-Specific Architectures, DSA）的大量前沿课程。近几年诸如苹果公司等产业巨头积极推动的新硅基计划，带动了大量学生直接参与真实的芯片流片（Tape-out）。而所有这一切令人心潮澎湃的工程实践，起点全都在我们今天所讲的这门课里。

### 同步数字系统：节拍与离散的艺术

我们这部分内容的核心主题叫做**同步数字系统**（Synchronous Digital Systems，简称 SDS）。我们的 RISC-V 处理器就是一个典型的 SDS。

这个名字由两个关键词构成：**同步**与**数字**。

```text
               +--------------------------------------+
               | 同步数字系统 (Synchronous Digital)   |
               +------------------+-------------------+
                                  |
         +------------------------+------------------------+
         |                                                 |
         v                                                 v
  【 同步 (Synchronous) 】                          【 数字 (Digital) 】
- 基于统一步调的心跳节奏                           - 抛弃连续模拟量，聚焦离散 0 与 1
- 由石英晶体振荡器驱动                            - 晶体管工作于“双稳态”（彻底导通 / 彻底关断）
- 全局周期性方波时钟 (Clock)                      - 组合成 Word、浮点数、字符等多位语义
```
*图解：同步数字系统的两大核心支柱拆解。*

#### 同步：全局统一的心跳

“同步”意味着整个硬件系统是在同一个节奏、统一步调下运转的。

它靠什么来维持节拍？靠**时钟**（Clock）。在物理硬件中，通常由一个高精度的石英晶体振荡器产生一个固定频率的周期性方波。这个方波信号就像是整个机器的心跳（Heartbeat），以恒定的速率跳动，驱动着芯片内数以亿计的晶体管和寄存器齐步前进。我们在后面分析时序逻辑时，会看到所有数据的交接与运算，都是紧密锚定在时钟跳变的节拍上的。

#### 数字：从连续模拟中提炼纯粹的零与一

“数字”意味着我们完全专注于处理离散的值（Discrete Values），也就是经典的 0 和 1。

这里有一个至关重要的工程认知：物理世界在本质上是模拟的（Analog）、连续的。我们即将打交道的晶体管，在模拟电路领域其实是一个连续的电压/电流放大器——它可以处于从完全截止到完全导通之间的任何中间过渡状态，拥有无限多个连续取值。

但在计算机数字系统里，我们通过抽象将这层连续性彻底抹平，强制让晶体管只工作在**双稳态**（Bistable）：
- 状态一：完全导通，电流畅通无阻（代表一种逻辑状态）；
- 状态二：完全关断，电流彻底截断（代表另一种逻辑状态）。

> **定义**：双稳态（Bistable）是指器件在稳态下只允许呈现两种确定的工作状态。在数字电路中，我们将高于某一阈值的电压抽象为逻辑 1，低于某一阈值的电压抽象为逻辑 0，从而将充满噪声的物理电信号提纯为纯粹的布尔世界。

一旦确立了 0 和 1 的离散抽象，我们就可以像搭积木一样，把多个比特组合在一起：把 32 个比特组合成一个字（Word），或者组合成 ASCII 字符、IEEE 754 浮点数，由此构建出浩瀚的现代计算软件生态。

### 开关与布尔逻辑：接线的数学本质

#### 电路的基本法则与水流比喻

为了理解电路是如何工作的，最直观的物理模型莫过于**水流类比**（Water Analogy）。

在水流模型中：
- **电流（Current）**好比水流。电荷在导线中的定向移动，就像水分子在水管中的流动一样。
- **电压（Voltage）**好比水压。水库大坝积蓄的高水位差产生高压，推动水流涌向低处；电源两端的电势差同样推动电荷从高电位流向低电位。

电路工作的第一铁律是：**电流只有在存在完整闭合回路（Complete Circuit）时才会流动**。如果一根水管在中途被闸门截断，水流无法形成循环流动，系统就会静止；电路也是同理，中间任何一处断开，电荷就无法流通。

我们来看一个最基础的物理电路：包含一个电压源（电池）、一个开关和一个负载（小灯泡）。

```text
           +------------- 开关 A -------------+
           |                                  |
       +-------+                          +-------+
       | +   - |                          |       |
       |  电池  |                          |  灯泡  | Z (输出状态)
       | (3V)  |                          |       |
       +-------+                          +-------+
           |                                  |
           +----------------------------------+
```
*图解：单开关基础闭合回路。只有当开关 A 闭合时，整个回路才导通，灯泡 Z 才会发光。*

对于开关 A：
- 当开关**断开（Open）**时，就像房门打开未扣合一样，两端没有电气接触，形成**开路（Open Circuit）**。此时回路被切断，无电流流过，灯泡熄灭，我们记输入控制信号 $A = 0$，输出状态 $Z = 0$。
- 当开关**闭合（Closed）**时，导线物理连通，形成完整回路，电流从电池正极流出，点亮灯泡，再流回负极，我们记 $A = 1$（被激活 / Active），输出状态 $Z = 1$。

因此，这个简单电路的输入输出关系就是最平实的恒等逻辑：$Z = A$。我在课堂上甚至专门用快接导线做了一个演示板，把电池、开关和小灯泡串在一起，用手机投屏给大家看：手一按开关灯就亮，手一松开关灯就灭。

#### 串联与并联：无需芯片即可涌现的逻辑

当我们把多个开关组合在一起时，奇迹发生了：纯粹的物理接线方式，竟然直接涌现出了高级的数学逻辑！

##### 串联接线（Series）

如果我们将两个开关 A 和 B 头尾相接，串联在同一根导线上：

```text
       输入端 --------[ 开关 A ]--------[ 开关 B ]-------- 输出端 Z
```
*图解：两个开关串联。电流从左流向右必须同时穿过开关 A 和开关 B。*

在这个结构中，电流若想从左端流到右端点亮灯泡，必须满足什么条件？
显然，只有当**开关 A 闭合且开关 B 也闭合**时，中间才存在一条连续不间断的物理通路。只要其中任何一个断开，通路就会被截断。

在逻辑上，这恰好完美对应了布尔逻辑中的**与运算（AND）**：
$$Z = A \text{ AND } B = A \cdot B$$

##### 并联接线（Parallel）

如果我们将两个开关 A 和 B 并排铺设，构成上下两条分流支路：

```text
                  +------[ 开关 A ]------+
                  |                      |
       输入端 ----+                      +---- 输出端 Z
                  |                      |
                  +------[ 开关 B ]------+
```
*图解：两个开关并联。电流既可以走上方的开关 A 支路，也可以走下方的开关 B 支路。*

此时，电流从左向右流动有了两条可选路径：
只要**开关 A 闭合，或者开关 B 闭合**（亦或两者都闭合），左右两端就能建立连通通路。

在逻辑上，这恰好完美对应了布尔逻辑中的**或运算（OR）**：
$$Z = A \text{ OR } B = A + B$$

> **提示**：我们甚至还没有引入任何半导体器件，仅仅通过改变两根铜线的连接拓扑（串联与并联），物理电路就已经自发实现了布尔逻辑！

#### 乔治·布尔的洞见与硬件化简

这一切要归功于伟大的英国数学家乔治·布尔（George Boole）。在 19 世纪中叶，布尔创立了一整套用符号代数处理逻辑命题的数学体系。半个多世纪后，早期计算机先驱们用继电器和开关搭电路时突然顿悟：原来这套物理开关网络的通断规律，与布尔代数存在着百分之百的数学对应！

这个发现不仅具有历史意义，更是整个现代芯片设计的核心基石。

为什么？因为我们可以把极其复杂的控制需求，先用布尔逻辑表达式书写下来，然后利用布尔代数的公理和定律（如结合律、分配律、吸收律、德摩根定律等）进行化简消项——就像你在初等代数中把复杂的多元多项式进行因式分解和约分一样。

化简的终极意义在于：
- **更少的逻辑项** $\rightarrow$ **更少的物理开关/晶体管**；
- 芯片面积更小，制造成本大幅降低；
- 电路切换功耗显著下降，发热更少；
- 信号延迟降低，系统运行更快。

我们在后面的课程中会专门抽出一整讲，系统学习如何运用布尔代数与卡诺图来极限化简逻辑电路。

### CMOS 晶体管：电压控制开关与互补双雄

#### 告别真空管：二十世纪最伟大的发明

开关虽然简单，但如果是靠人手去拨动，那显然无法用来制造计算机。我们需要的是能用电信号自身去自动控制的开关。

在 20 世纪前半叶，工程师们使用的是**真空管（Vacuum Tubes）**。但真空管不仅体积庞大、发热惊人，更要命的是其故障率极高。在由成千上万个真空管组成的庞大早期计算机机房里，几乎每过几分钟就会有一个管子烧坏爆掉，维护人员不得不端着备用真空管在机柜间奔跑排查。

这一切在 1947 年圣诞节前夕被彻底终结——贝尔实验室的科学家们研制出了人类历史上第一个点接触型**晶体管（Transistor）**。

与脆弱易损的真空管相比，基于固态半导体制造的现代晶体管具备惊人的稳定性：在合理工况下，其可用性达到 99.999% 以上，连续工作数年甚至数十年都不会损坏。正如著名科技评论家在 PBS 纪录片中所言，晶体管毫无疑问是整个 20 世纪最伟大的发明，正是它孕育了整个微电子时代。

#### 压控开关与端子辨析（DGS 助记）

现代芯片中最主流的制造工艺被称为 **CMOS**（互补金属氧化物半导体，Complementary Metal-Oxide-Semiconductor）。

在 CMOS 工艺中，晶体管的本质就是一个**电压控制开关（Voltage-Controlled Switch）**。

还记得前面的水流比喻吗？想象一个**水控水闸**：
主水渠里有奔腾的大水流，而在水闸上方有一根细小的控制水管。当细水管中有水压注入时，这股微弱的水压就能顶开沉重的大闸门，从而允许主水渠中巨额的水流倾泻而下；当控制水管撤去水压时，闸门重新关闭，主水渠彻底截流。

```text
               控制电压 (Gate)
                     |
                     v [水闸门]
   电荷源泉 (Source) ========> 排出端 (Drain)
               [主通道大电流]
```
*图解：电压控制晶体管的水闸类比模型。栅极的微弱电压控制着源极到漏极的主电流。*

一个标准的场效应晶体管具有三个关键端子：
1. **源极（Source）**：电荷的源头。好比大坝后方蓄积的大片水库，蕴藏着高电势能；
2. **漏极（Drain）**：电荷流向的排出口。水流最终排出的去向；
3. **栅极（Gate）**：横亘在源极与漏极之间的控制水闸。它的输入电压决定了通道的开合。

> **提示**：如何快速记住这三个引脚？我给大家提供一个助记法——**DGS**。既代表 Drain、Gate、Source，也可以谐音当成 “Dan Garcia's Saying”。记住：Source 是源头大库，Drain 是排水出口，Gate 是中间受控的闸门。

#### NMOS 与 PMOS 的互补对偶

在 CMOS 工艺中，晶体管分为互补的两大流派：**N 沟道（NMOS）** 与 **P 沟道（PMOS）**。

```text
      【 NMOS (正常导通型) 】                  【 PMOS (反向低电平有效型) 】
            Drain                                  Drain
              |                                      |
              +---                                   +---
        Gate  |通道                            Gate  |通道
     o--------+ (导通)                       o---o---+ (导通)
     (高电平1) |                               (低电平0)| (栅极带小圆圈)
              +---                                   +---
              |                                      |
            Source                                 Source
       栅极 = 1 时: 闭合导通                  栅极 = 0 时: 闭合导通
       栅极 = 0 时: 断开开路                  栅极 = 1 时: 断开开路
```
*图解：NMOS 与 PMOS 电路符号及通断特性对比。注意 PMOS 栅极处的小圆圈，它象征着反向/低电平有效。*

它们的工作特性具有一种极其优美的对称性与对偶性（Duality）：

##### NMOS（N 沟道晶体管）
- 我喜欢将其记忆为 **“Normal”**（正常模式）。它的电路符号在栅极处是**没有圆圈**的纯净引脚。
- **高电平闭合**：当栅极电压为高电平（Gate = 1，电压高于源极阈值）时，源极与漏极之间的导电沟道形成，开关**闭合导通**，电流可以通过。
- **低电平断开**：当栅极电压为低电平（Gate = 0，接近地电位）时，沟道关断，开关呈**开路断开**状态，两端绝缘。

##### PMOS（P 沟道晶体管）
- PMOS 的电路符号在栅极处带有**一个小圆圈**。在数字逻辑中，这个小圆圈一律代表反相（Inversion）或“低电平有效”。
- **低电平闭合**：与 NMOS 完全相反！当栅极电压为低电平（Gate = 0）时，开关反而**闭合导通**。
- **高电平断开**：当栅极电压为高电平（Gate = 1）时，开关呈**开路断开**状态。

| 晶体管类型 | 符号特征 | 栅极输入 $G = 0$（低电平） | 栅极输入 $G = 1$（高电平） |
| :---: | :---: | :---: | :---: |
| **NMOS** | 栅极无圆圈（正常型） | **断开**（Open，开路） | **闭合**（Closed，导通） |
| **PMOS** | 栅极带圆圈（反向型） | **闭合**（Closed，导通） | **断开**（Open，开路） |

NMOS 与 PMOS 这种高低电平互反的二元对偶性，正是接下来构建一切逻辑门的核心秘密武器。

### 晶体管网络实战：构建反相器与万能门

#### 电压演进与绝对禁区——严防短路

在我们动手连接晶体管之前，必须确立数字系统里的电位基准，并宣布一条生死攸关的物理红线。

在晶体管电路发展的历史上，工作电压一直在持续演进：
- 在我成长的早期 TTL（晶体管-晶体管逻辑）时代，标准工作电压是 **5V**；
- 后来主流工业界全面转向了 **3.3V 与 3V**；
- 而在当今的高密度现代纳米级微处理器中，为了遏制发热与功耗，核心电压已经被压降到了 **1V 以下**。

在今天的推导中，我们统一以 **3V 代表逻辑 1**（电源正极，标为 $V_{DD}$），以 **0V 代表逻辑 0**（接地，标为 Ground / GND）。

为什么 0V 被称为“地”（Ground）？这真的源于物理上的土壤大地。就像建筑屋顶上的金属避雷针一样，当雷击发生时，数万伏的巨大高压电荷会沿着低阻抗绝缘导线直接导入地底深处的大地。电势能天生具有向最低点释放的物理本能——就像架子顶端的保龄球，一有机会就会尽可能快地滚落到地面一样。大地是一个无穷大的电荷池，其电势被定义为绝对基准零点（0V）。

> **易错点**：**数字芯片设计的头号禁区：绝对不可造成电源直连地线的短路（Short Circuit）！**
> 在现实中，如果你拿一根零电阻的金属跳线直接插进家用插座的正负极，极低的阻抗会引发瞬时失控的暴击大电流，导致火花、跳闸甚至火灾。
> 在芯片内部更是如此：如果你的晶体管网络连接错误，使得 $3\text{V}$ 电源线与 $0\text{V}$ 地线之间在某一瞬间形成了一条纯导通的直通回路，整颗芯片就会因瞬间过热而直接烧毁报废。
> **铁律**：无论输入信号如何变化，任何合法的 CMOS 逻辑网络都必须严格保证电源 $V_{DD}$ 与地 $GND$ 绝不发生直通！

#### 搭建首个逻辑门：CMOS 反相器（NOT 门）

现在，让我们用一个 PMOS 和一个 NMOS，来搭建人生中第一个真正的集成电路——**反相器（Inverter，即 NOT 门）**。

##### 电路拓扑

我们将两个晶体管上下纵向排布：
- 顶部连接 $3\text{V}$（$V_{DD}$），放置一个 **PMOS** 晶体管（管子上拉到电源）；
- 底部连接 $0\text{V}$（$GND$），放置一个 **NMOS** 晶体管（管子下拉到地）；
- 输入信号同时接入上方 PMOS 和下方 NMOS 的栅极；
- 输出端从中间两管相接的节点引出。

```text
                   电源 VDD (3V / 逻辑 1)
                           |
                        +--+--+
                        | PMOS| (带圆圈)
           输入 In -----o     |
           (0V 或 3V)   +--+--+
                           |
                           +----------------- 输出 Out
                           |
                        +--+--+
           输入 In -----| NMOS| (无圆圈)
                        |     |
                        +--+--+
                           |
                     地 GND (0V / 逻辑 0)
```
*图解：CMOS 反相器电路原理图。上部 PMOS 负责将输出拉高到 3V，下部 NMOS 负责将输出拉低到 0V。*

##### 逐状态严格推导

我们来考察两种输入情况，验证其电气行为：

**情况一：输入 $\text{In} = 0\text{V}$（逻辑 0）**
1. 输入端连接到 0V。
2. 观察底部 NMOS：因为栅极是低电平（0V），NMOS 处于断开（开路）状态，输出端 Out 与地 GND 的通路彻底截断。
3. 观察顶部 PMOS：因为栅极是低电平（0V），PMOS 处于闭合导通状态！$3\text{V}$ 电源沿着 PMOS 通路直接连通到输出节点。
4. 结果：输出端 Out 稳稳地连接到 $3\text{V}$，且绝不漏地。输出电平为 $3\text{V}$（逻辑 1）。

**情况二：输入 $\text{In} = 3\text{V}$（逻辑 1）**
1. 输入端连接到 3V。
2. 观察顶部 PMOS：因为栅极是高电平（3V），PMOS 彻底断开，输出端与 $3\text{V}$ 电源完全隔绝。
3. 观察底部 NMOS：因为栅极是高电平（3V），NMOS 处于闭合导通状态！输出端直通底部地线。
4. 结果：输出端 Out 稳稳地连接到 $0\text{V}$，且与电源绝缘。输出电平为 $0\text{V}$（逻辑 0）。

| 输入 $\text{In}$ | 顶部 PMOS 状态 | 底部 NMOS 状态 | 输出 Out 连接状态 | 输出 $\text{Out}$ |
| :---: | :---: | :---: | :---: | :---: |
| **0** (0V) | **导通** (闭合) | **截止** (断开) | 连通 $V_{DD}$，断开 GND | **1** (3V) |
| **1** (3V) | **截止** (断开) | **导通** (闭合) | 断开 $V_{DD}$，连通 GND | **0** (0V) |

> **结论**：输入 0 变 1，输入 1 变 0！我们没有使用任何机械构件，仅凭两个互补晶体管，就在纳秒级时间内完成了逻辑电平的翻转。这就是计算机内部所有非门的微观物理实体。

#### 搭建万能门：CMOS 与非门（NAND 门）

一个非门还不足以构建整个数字世界。接下来我们要构建更高级的双输入门——**与非门（NAND Gate）**。

##### 电路拓扑

与非门由四个晶体管构成：
- 顶部上拉网络：由两个 **PMOS** 晶体管**并联**构成，一端接 $3\text{V}$，另一端接输出端 C；
- 底部下拉网络：由两个 **NMOS** 晶体管**串联**构成，上端接输出端 C，下端直接地线 GND；
- 输入端 A 同时控制左侧 PMOS 和上方 NMOS；输入端 B 同时控制右侧 PMOS 和下方 NMOS。

```text
                     电源 VDD (3V)
                     |           |
                  +--+--+     +--+--+
                  |PMOS |     |PMOS |
        输入 A ---o  A  |     |  B  o--- 输入 B
                  +--+--+     +--+--+
                     |           |
                     +-----+-----+
                           |
                           +----------------- 输出 C
                           |
                        +--+--+
        输入 A ---------|NMOS |
                        |  A  |
                        +--+--+
                           |
                        +--+--+
        输入 B ---------|NMOS |
                        |  B  |
                        +--+--+
                           |
                      地 GND (0V)
```
*图解：CMOS 与非门（NAND）拓扑图。上部 PMOS 并联用于上拉，下部 NMOS 串联用于下拉。*

##### 归纳推导：为什么只需看两类情况

很多同学看四个晶体管的电路容易眼花，其实只要抓住核心矛盾，分析极其简单。我们把四种输入组合归拢为两类：

**第一类：$A = 1$ 且 $B = 1$（真值表的最后一行）**
- 此时 A 和 B 全是高电平。
- 看底部下拉网络：NMOS A 和 NMOS B **同时导通**。因为它们是串联的，串联全通即连通整条直达地线的回路。
- 看顶部上拉网络：PMOS A 和 PMOS B **全部断开**，输出端与电源完全隔离。
- 结论：输出端 C 被拉低到接地电平 $0\text{V}$（逻辑 0）。这是整张真值表里输出为 0 的**唯一**情况！

**第二类：$A$ 或 $B$ 中至少有一个为 $0$（真值表的前三行）**
- 不需要分三种情况机械讨论，逻辑完全一致：
- 只要 A 或 B 里有 0，底部串联的两个 NMOS 中就**至少有一个是断开的**。串联只要断开一路，整条通往 GND 的通路就被彻底切断，输出绝对不可能接地！
- 与此同时，看顶部并联网络：只要 A 或 B 里有 0，对应的那个 PMOS 就**必然闭合导通**。并联电路只要有一路导通，输出端 C 就会立刻连通到 $3\text{V}$ 电源。哪怕两个 PMOS 同时导通，也不过是双路分流供电而已，电位始终是坚固的 $3\text{V}$。
- 结论：输出端 C 稳稳地输出高电平（逻辑 1）。

| 输入 A | 输入 B | 顶部 PMOS A / B | 底部 NMOS A / B | 下拉通路 (到地) | 上拉通路 (到电源) | 输出 C |
| :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| 0 | 0 | 导通 / 导通 | 截止 / 截止 | 断开 | 连通 | **1** |
| 0 | 1 | 导通 / 截止 | 截止 / 导通 | 断开 | 连通 | **1** |
| 1 | 0 | 截止 / 导通 | 导通 / 截止 | 断开 | 连通 | **1** |
| 1 | 1 | 截止 / 截止 | 导通 / 导通 | **连通** | 断开 | **0** |

输出真值向量是标准的 `1, 1, 1, 0`。如果把普通的与门（AND，真值向量 `0, 0, 0, 1`）经过非门取反，得到的就是 `1, 1, 1, 0`。这就是与非门（NAND = NOT AND）。

#### NAND 的全功能完备性：捡零件造计算机

请大家在此处停顿三秒，体会一下这个电路的震撼之处。

在逻辑学与计算机工程中，NAND 门被称为**通用逻辑门（Universal Gate）**，它具有**全功能完备性（Functional Completeness）**。

什么叫全功能完备性？
- **用 NAND 制造 NOT 门**：把 NAND 门的两个输入引脚 A 和 B 短接在一起当成同一个输入端。当输入为 0 时输出 1；当输入为 1 时输出 0。我们当场得到了一个非门！
- **用 NAND 制造 AND 门**：先经过一个 NAND 门，后面紧接一个由 NAND 制成的 NOT 门，负负得正，便得到了标准与门。
- **用 NAND 制造 OR / NOR 门**：根据德摩根定律（$\overline{A \cdot B} = \overline{A} + \overline{B}$，亦即 $A + B = \overline{\overline{A} \cdot \overline{B}}$），只要把输入端分别取反再送入 NAND，就能等价拼装出或门与或非门。

```text
(1) 制造 NOT 门:
    In ----+----[ NAND ]----> Out = NOT(In)
           |
           +--

(2) 制造 AND 门:
    A ---------+
               |--[ NAND ]----+---->----[ NAND ]----> Out = A AND B
    B ---------+              |
                              +--
```
*图解：利用 NAND 的全功能完备性合成 NOT 门与 AND 门。*

> **提示**：这意味着什么？如果你现在跑到电子元件回收站的垃圾桶里翻箱倒柜，哪怕你只能捡到一麻袋的与非门芯片（或者纯粹的 P 型与 N 型晶体管），你不需要任何其他元件，就能独立搭建出加法器、乘法器、寄存器、程序计数器乃至世界上任何一台图灵完备的现代超级计算机！你所需要的一切硬件基石，我们刚才已经在黑板上全部给出了。

### 时序、波形与现实世界的延迟

有了逻辑门，计算机还必须拥有时间的概念。

#### 时钟信号：节拍器的物理度量

在理想状态下，驱动同步系统的**时钟信号（Clock）**是一个完美的对称方波：它不知疲倦地在 $0\text{V}$ 与 $3\text{V}$ 之间跳变。

```text
       3V +       +-------+       +-------+       +-------+
          |       |       |       |       |       |       |
       0V +-------+       +-------+       +-------+       +-------+
                  ^               ^
                  |               |
                  +--- 周期 T ----+ (例如 1 ns -> 频率 1 GHz)
                  上升沿          上升沿
```
*图解：理想时钟方波波形。时序系统普遍以上升沿（Low-to-High）作为动作同步锚点。*

时钟的两个物理量互为倒数：
- **时钟周期（Period, $T$）**：一个完整方波循环所经历的时间跨度。
- **时钟频率（Frequency, $f$）**：一秒钟内方波震荡的次数，$f = 1 / T$。

> **提示**：如果一个处理器的时钟周期 $T = 1\text{ ns}$（纳秒，即十亿分之一秒），那么它的主频就是 $f = 1 / (10^{-9}\text{ s}) = 1\text{ GHz}$。

在数字时序设计中，我们通常约定以时钟信号的**上升沿（Rising Edge）**——即电压由低跳变到高的那一瞬间——作为全局逻辑事件触发的唯一定时基准。

说到 1 纳秒有多长，计算机先驱格蕾丝·霍珀海军上将（Admiral Grace Hopper）有一段非常著名的轶事：当人们向她抱怨卫星通信或计算机为什么会有几微秒、几纳秒的延迟时，她总是随身携带一段大约 **30 厘米长（约 1/3 米，12 英寸）的铜导线**，当场递给对方说：“瞧，这就是一纳秒！”因为光和电信号在真空中以每秒 30 万公里的光速传播，在导线中每走 30 厘米，物理世界就不可逆转地流逝了整整 1 纳秒。距离就是时间，物理极限真实存在。

#### 理想跳变与现实世界的总线向量

在纸面上推演时，我们往往假设导线传输是瞬时的，信号从 0 翻转到 1 没有斜率，垂直完成。如果在波形图上任意切一根垂直参考线，每个时刻信号线都能通过“垂直线测试”得到一个明确的 0 或 1。

但在真实硬件中，总线往往不是单根导线。如果我们要为一个 4 位加法器设计电路，输入端有 4 位的 A 和 4 位的 B，输出端有 4 位的 C。如果我们在图纸上画满一条条并列的细单线，图纸会变得杂乱无章。

因此，硬件工程中引入了**向量总线（Vector Bus）**表示法：
- 用一条带有斜杠标记的粗导线表示多位数据通路，斜杠旁的数字标注车道宽度（比如标注 4，就好比加利福尼亚公路上的 4 车道高速公路）；
- 在时序波形图中，多位信号不再拆成一堆杂乱的 0/1 方波，而是画成一个交织的总线向量通道，通道内部直接标注当前组合出来的等效十六进制或无符号十进制数值（例如 5, 6, 8, 1, 7 等）。

```text
       输入 A [3:0] ====/====\
                         4    \
                               +----------------+
                               | 4位加法器 (CL)  | =====/=====> 输出 C [3:0]
                               +----------------+   4
       输入 B [3:0] ====/====/
                         4
```
*图解：多位向量总线表示法。斜杠表示总线位宽，避免绘制重复杂乱的单线。*

#### 组合逻辑与传播延迟

现在我们把加法器放到时钟驱动的流水线中，残酷的现实立刻露出了獠牙：**噪声（Noise）与传播延迟（Propagation Delay）**。

时钟信号可以由石英谐振器打磨得非常标致，但数据信号在经历逻辑门和长导线时，会产生抖动和衰减；更重要的是，晶体管的通断需要电荷移动，导线分布电容充放电需要时间。

```text
  时钟 CLK  +---+           +---+           +---+
           |   |           |   |           |   |
         --+   +-----------+   +-----------+   +-----------
           ^
  输入 A,B | 准时跳变到达新值 (例如 A=3, B=10)
         --<===============================================
           ^
           |<- 传播延迟 t_pd ->|
  输出 C   |   【不可信窗口】   | 稳定输出正确值
         --<XXXX 震荡 / 旧值 XX><=============== 13 =======
           ^                   ^
           上升沿时刻           稳定可信时刻
```
*图解：组合逻辑的时钟时序与传播延迟示意图。在上升沿之后到传播延迟结束前，输出处于不可信过渡态。*

> **定义**：**传播延迟（Propagation Delay，记为 $t_{pd}$）**是指输入信号发生有效跳变到输出端稳定呈现最终正确结果之间的最大物理时间差。

当输入 A（值为 3）和输入 B（值为 10）在时钟上升沿准时到达加法器输入端时，输出端的求和结果并不会瞬间变成 13！
- 在时钟触发后的这段传播延迟 $t_{pd}$ 窗口期内，加法器内部各个层级的门电路正在逐级翻转、进位链正在从低位向高位级联传递；
- 此时放大查看输出端，它可能还在输出上一周期的旧值（例如 5），或者在未决电平之间剧烈振荡闪烁；
- **核心法则**：在时钟上升沿与传播延迟 $t_{pd}$ 之间的这个时间窗口内，输出数据**绝对不可信**！你必须耐心等待 $t_{pd}$ 走完，电路彻底平息稳定下来，此时读出的数值才是可信的 13。

在芯片工程中，电气工程师们正是使用专业 EDA 工具中的**波形调试器（Waveform Viewer）**来捕捉这些纳秒级的信号翻转。如果在时钟采样时刻信号还没有稳定到达指定逻辑电平，就会引发灾难性的建立时间违例（Setup Time Violation）与电路故障。

### 计算机的两大基石：组合逻辑与状态元件

至此，我们可以对同步数字系统中的所有电路，完成一次决定性的终极二分。

计算机内部的一切电路组件，本质上只属于以下两类之一：

```text
                        +----------------------+
                        | 同步数字系统电路类型  |
                        +----------+-----------+
                                   |
         +-------------------------+-------------------------+
         |                                                   |
         v                                                   v
  【 组合逻辑 (Combinational Logic, CL) 】       【 状态元件 (State Elements) 】
- 无记忆、无内部状态                           - 具备记忆能力，能保存历史信息
- 输出仅仅是当前输入的纯函数                    - 输出取决于当前输入及过去的状态
- 例如：加法器、多路复用器、ALU、逻辑门          - 例如：寄存器、触发器、程序计数器 (PC)
```
*图解：同步数字系统两大电路分支对比。*

#### 纯函数与记忆机制的划分

##### 组合逻辑（Combinational Logic，简称 CL）
组合逻辑好比我们在 CS61A 里学到的**纯函数（Pure Functions）**：
- 它的输出**严格、唯一地取决于当前瞬间的输入值**；
- 它内部没有任何存储介质，没有任何关于“过去”的记忆；
- 如果你给它输入 3 和 10，经过 $t_{pd}$ 之后它一定会吐出 13；输入撤去或改变，旧结果瞬间无影无踪。我们前面讲的门电路、加法器、译码器、ALU 都属于组合逻辑。

##### 状态元件（State Elements）
但是，仅有纯函数根本无法构成能执行程序的计算机——因为计算机必须记住“当前执行到了哪一行代码”（程序计数器 PC）、必须保存“刚刚计算出的中间变量”（通用寄存器堆）、必须维系系统所处的状态。
- 状态元件的输出不仅取决于当前的输入，还**取决于系统过去的历史状态**；
- 它具备在时间维度上跨时钟周期锁存、记忆信息的能力。

#### 寄存器工作原理解析：时钟边沿的采样艺术

最核心的状态元件就是我们每天都在汇编里调用的**寄存器（Register）**。

##### 接口与结构

一个典型的 $n$ 位寄存器黑盒具有：
- 一个 $n$ 位的并行数据输入端（Data In）；
- 一个 $n$ 位的并行数据输出端（Data Out）；
- 一个带**小三角形标记**的特殊输入端——这就是时钟/加载触发端（CLK / Load）。

```text
                  n 位数据输入 In [n-1:0]
                            |
                            v
                     +--------------+
                     |              |
                     |  n位寄存器   | ====> n 位稳定数据输出 Out [n-1:0]
                     |  (Register)  |
                     |              |
                     +-------^------+
                             |
                     时钟信号 CLK (带小三角标志)
```
*图解：n 位寄存器原理框图。小三角标志代表该引脚为边沿敏感的时钟触发端。*

##### 讲师的肢体比喻：转身抓取的采样艺术

为了让大家在脑海中刻下寄存器的工作语义，我通常会用一个夸张的身体动作来演示：

> 想象我本人就是一个硬件寄存器。我背对着身后的输入端，正面对着台下的观众（输出端）。
> 
> 1. 平常时刻（时钟低电平或高电平平稳期），我始终低头面朝前，双手紧紧举着上一次锁存的数据（比如数值 6），稳定展示给台下的所有下游电路。在此期间，无论我身后的输入信号如何疯狂跳变、怎么充满噪声，我都充耳不闻，眼前的输出纹丝不动。
> 2. 当时钟上升沿（CLK Rising Edge）到来的那一瞬间，我以迅雷不及掩耳之势**猛然转身，一把抓取（Sample / Capture）身后输入端的有效数据**（假设此时是全 1，即十六进制的 0xF）；
> 3. 经过极其短暂的内部传输延迟后，我重新转回身，把新抓到的 0xF 展示在正前方的输出端上；
> 4. 随后，我再次冻结，输出端将永远牢牢锁定在 0xF，直到下一个时钟上升沿的口令下达！

```text
  时钟 CLK    +-------+       +-------+       +-------+
             |       |       |       |       |       |
           --+       +-------+       +-------+       +-------
             ^                       ^
             | 瞬间转身抓取输入       | 瞬间转身抓取输入
  输入端 In  X 旧值 X== 新值 6 ======X=======X== 新值 0xF ===
             ^                       ^
             |<- t_clk-to-q ->|      |<- t_clk-to-q ->|
  输出端 Out ----------------<====== 6 ======>----------------<==== 0xF ===
             稳定保持旧数据           新数据稳定锁存           新数据稳定锁存
```
*图解：寄存器时序工作机制。寄存器仅在时钟上升沿对输入进行采样，随后锁定输出，抵抗输入端的波动。*

##### 节拍驱动的程序计数器

这种带有严格节律的心跳机制，正是程序计数器（Program Counter, PC）的基石。

每个时钟周期的上升沿，PC 寄存器瞬间采样下一条指令的地址（例如 $\text{PC} + 4$），然后在整个周期内向指令内存提供极其稳定的地址信号，让指令内存有充裕的时间取出指令编码并送入译码器。

计算机正是由无数个这样的状态元件和组合逻辑交织在一起：
- 组合逻辑负责在周期的间隙里做计算、推进逻辑；
- 状态元件负责在时钟的节拍点上锁存结果、建立边界屏障；
- 整个机器如同一支训练有素的交响乐团，在石英时钟的指挥棒下，一步一拍，永不出错。

### 本讲提到的题目

在课堂尾声，我们进行了一轮在线三连单选题（Peer Instruction / Q&A）。题目形式为三个真假判断题（True / False），全班同学通过投票系统提交了一个 3 比特布尔结果。这三道题目精准拷问了软硬件抽象边界的核心认知。

#### 题目一
**题干**：软件能否在抽象边界之下窥探（Peek under the abstraction barrier）硬件的具体细节以进行针对性优化？

- **选项**：真（True）/ 假（False）
- **正确答案**：**真（True）**
- **解析**：
  软件完全可以跨过抽象边界去探测底层的硬件特征！例如，一段高性能软件可以主动查询底层的 CPU 厂商信息、缓存行大小、是否支持 AVX-512 向量扩展或是否挂载了 GPU 加速器。如果检测到底层具备特定硬件扩展，软件就可以动态走专属优化代码分支；如果检测不到，则回退到通用基准实现。软件工程师为了榨干性能，主动“偷窥”硬件细节不仅是被允许的，在系统工程中更是标准操作。

#### 题目二
**题干**：软件能否依赖（Rely on）指令集架构（ISA）的某种特定硬件微架构实现？

- **选项**：真（True）/ 假（False）
- **正确答案**：**假（False）**
- **解析**：
  软件可以“探查”硬件能力，但**绝对不能硬编码依赖某种具体的硬件实现**。ISA 是软硬件之间神圣的交乘契约：只要硬件正确实现了 RISC-V 规范，软件就只能假定该规范所保证的行为，而绝不能假定该硬件必须用 5 级流水线、必须具备某种内部转发逻辑或执行某条指令必定耗时精确的 3 个周期。一旦软件在逻辑正确性上死死绑定了特定的微架构内部细节，当下一代芯片改进流水线或调整内部电路时，软件就会立刻崩溃。契约的权威性不容破坏。

#### 题目三
**题干**：时序图（Timing Diagram）是电气工程与体系结构工具箱中的关键调试工具吗？

- **选项**：真（True）/ 假（False）
- **正确答案**：**真（True）**
- **解析**：
  正如我们在波形分析小节中所讨论的，物理世界充满了不可避免的门延迟、布线毛刺和时钟偏斜。在实际设计和验证数字系统时，单看逻辑真值表根本无法排查瞬态竞争与时钟冒险。时序图直观展示了各个信号在时间轴上的跳变时序、因果关系与延迟容限，是芯片设计者定位时钟违例、调试硬件 Bug 时须臾不可离身的核心利器。

因此，这三道思考题的标准答案组合为：**真、假、真（True, False, True）**。
