# UC Berkeley CS61C：计算机体系结构（中文版）

UC Berkeley CS61C《计算机体系结构导论》的中文配版（Fall 2024 季）。课程先用 C 语言把指针、内存管理与泛型讲透，再以 RISC-V 为载体，从指令集与数据传输一路讲到单周期数据通路、五级流水线、多级缓存，最后收在并行计算、线程级并行、虚拟内存与 ECC/RAID 等存储主题。

- **原视频**：https://www.bilibili.com/video/BV1gyM26ME4u — Bilibili，BV1gyM26ME4u
- **38 集**，已产出 38 册模块全书、38 篇复习笔记、38 份逐字稿

## 怎么学

- **C 语言地基** → 模块 02~06 讲数字表示、C 基础、指针数组字符串、内存管理与泛型，后面全靠它
- **从 RISC-V 指令集起步** → 模块 07~13 讲 RISC-V 基础、数据传输、条件判断、过程调用与指令格式
- **工具链与数字系统** → 模块 14~17 讲编译器汇编器链接器、数字系统导论、组合逻辑与状态寄存器
- **数据通路与流水线** → 模块 18~24 是全课核心，单周期数据通路到五级流水线逐级演进，重点是冒险与转发
- **存储层次** → 模块 25~28 讲四讲缓存，配合局部性与替换策略反复推演
- **并行与虚拟内存** → 模块 29~38 覆盖线程级并行、分布式计算、虚拟内存与 ECC/RAID
- **按讲速查** → `notes/` 目录逐讲整理，便于跟课时同步回顾
