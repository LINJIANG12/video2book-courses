# RISC-V分支与条件跳转

## 控制流与程序计数器

* **程序计数器（Program Counter，PC）**
    * > **定义**：CPU 内部存储当前正在执行指令地址的寄存器。
    * 正常执行时，每条指令执行完毕后 PC 自动更新为 $PC \leftarrow PC + 4$。
    * 分支跳转的本质是强行修改 PC 的值，使其指向目标指令地址。

* **标签（Label）**
    * > **定义**：汇编语言中为特定内存地址赋予的符号名称，以冒号结尾。
    * 标签不占用机器码空间，仅在汇编阶段被解析为具体的物理地址偏移量。

## 条件分支指令

* **相等性判定**
    * `beq rs1, rs2, Label`：若 `rs1 == rs2`，跳转至 `Label`。
    * `bne rs1, rs2, Label`：若 `rs1 != rs2`，跳转至 `Label`。
    * 比较的是寄存器内部的 32 位比特序列，无需区分有符号或无符号。

* **大小比较判定**
    * `blt` / `bltu`：小于分支（有符号 / 无符号）。
    * `bge` / `bgeu`：大于等于分支（有符号 / 无符号）。
    * > **注意**：大小比较必须区分有符号与无符号，因为同一比特序列在不同解读下大小关系可能倒转。

* **RISC 极简设计原则**
    * RISC-V 不提供 `bgt`（大于）和 `ble`（小于等于）指令。
    * 通过对调操作数位置实现逻辑转换：
        * `if (s1 > s2)` 等价于 `blt s2, s1, Label`。
        * `if (s1 <= s2)` 等价于 `bge s2, s1, Label`。

* **无条件跳转**
    * `j Label`：无条件跳转指令。
    * 采用 J-Format 编码，不读取源寄存器，将所有可用位宽分配给立即数，支持更大范围的跳转。

## 控制结构翻译策略

* **单分支 if 语句**
    * 采用“逆向检查”策略：条件不成立时跳转（branch around），条件成立时顺序执行。
    * 示例：`if (i == j)` 翻译为 `bne x13, x14, Exit` 后接执行体。

* **双分支 if-else 语句**
    * 必须在 `then` 块末尾添加 `j Exit`，防止顺序穿透执行 `else` 块。
    * > **易错点**：遗漏 `then` 块末尾的无条件跳转会导致 `else` 块代码被错误执行。⚠️

* **循环结构（for 循环）**
    * 必须在循环体入口处先进行边界检查，确保循环语义（若初始条件不满足则一次也不执行）。
    * 循环末尾使用 `j Loop` 实现回路闭环。
    * 数组访问必须手动维护指针寄存器，`lw` 指令偏移量仅支持编译期确定的立即数。

## 位逻辑运算

* **基础位运算**
    * `and` / `andi`：按位与，用于提取或屏蔽特定位（掩码）。
    * `or` / `ori`：按位或，用于强制置位。
    * `xor` / `xori`：按位异或，用于条件反相。
    * `sll` / `slli`：逻辑左移，低位补 0，等价于乘以 $2^k$。
    * `srl` / `srli`：逻辑右移，高位补 0，等价于无符号除以 $2^k$。
    * `sra` / `srai`：算术右移，高位补符号位，用于有符号数除法。

* **位运算特性**
    * **掩码（Masking）**：`AND` 与 `0` 相与清零，与 `1` 相与保留；`OR` 与 `1` 相或置 1，与 `0` 相或保留。
    * **条件反相器**：`xor` 配合立即数 `-1`（全 1 比特）可实现按位取反。

## 系统架构与约定

* **编译执行流程（CAL）**
    * 编译（Compile）：源码 `.c` $\rightarrow$ 汇编 `.s`。
    * 汇编（Assemble）：汇编 `.s` $\rightarrow$ 机器码 `.o`。
    * 链接（Link）：目标文件 + 库 $\rightarrow$ 可执行文件。

* **存储程序模型**
    * 程序代码与运行数据存放在同一物理内存空间中。
    * CPU 必须通过 PC 访问内存获取指令，内存访问是性能瓶颈。

* **伪指令（Pseudo-instructions）**
    * `mv rd, rs`：数据复制，展开为 `addi rd, rs, 0`。
    * `li rd, imm`：加载立即数，展开为 `addi rd, x0, imm`。
    * `nop`：空操作，展开为 `addi x0, x0, 0`。

* **寄存器约定（ABI）**
    * `x10` - `x17`（`a0` - `a7`）：用于函数传参及返回值传递。
