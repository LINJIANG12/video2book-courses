# 单周期控制器控制信号设计

---

## 单周期处理器架构

* **单核单周期处理器（Single-core Single-cycle Processor）**

    * > **定义**：整套硬件中只有一个计算核心，且所有指令均在单一时钟周期内完成执行的处理器模型。

    * 核心三要素：程序计数器（PC）、寄存器堆（Register File）、算术逻辑单元（ALU）。

    * 运行假设：时钟频率必须迁就最慢的物理访问（通常为内存访问），确保每条指令在 1 个时钟周期内彻底执行完毕（CPI = 1）。

* **指令生命周期阶段**

    * 指令获取（Instruction Fetch, IF）：从指令内存读出 32 位机器码，计算 $PC + 4$。

    * 指令解码（Instruction Decode, ID）：识别操作码，生成立即数，读取寄存器操作数。

    * 执行计算（Execute, EX）：ALU 执行运算，分支比较器进行条件判定。

    * 访存操作（Memory, MEM）：Load 或 Store 指令访问数据内存。

    * 写回结果（Write Back, WB）：将运算或读取结果写入目标寄存器。

---

## 指令执行逻辑

* **存储字指令（Store Word, sw）**

    * > **注意**：存储指令不修改寄存器，寄存器写使能信号（RegWEn）必须为 0。

    * 数据流向：基址寄存器与立即数相加生成内存地址，寄存器 rs2 的数据写入数据内存。

    * 控制信号：$ASel = 0$（选寄存器），$BSel = 1$（选立即数），$MemRW = \text{Write}$。

* **分支等于指令（Branch If Equal, beq）**

    * > **易错点**：分支指令在比较的同时，ALU 正在并行计算跳转目标地址（$PC + \text{Imm}$），最终由 $PCSel$ 决定是否跳转。

    * 比较逻辑：分支比较器判定 $BrEq$ 信号，无需区分有符号或无符号数（$BrUn = *$）。

    * 跳转判定：若 $BrEq = 1$，则 $PCSel$ 选通 ALU 计算出的目标地址；否则选通 $PC + 4$。

## 时序分析与关键路径

* **关键路径（Critical Path）**

    * > **定义**：指令集中执行时间最长、物理延迟最大的指令路径，决定了处理器的最高时钟频率。

    * 瓶颈指令：加载指令（Load, lw）需走满 IF、ID、EX、MEM、WB 五个阶段，是单周期架构的关键路径。

* **时序约束**

    * 建立时间（Setup Time, $t_{\text{setup}}$）：数据必须在下一个时钟上升沿到来前的特定时间窗口内保持稳定，否则会导致触发器亚稳态。

    * 时钟周期计算：$T_{\text{min}} = t_{\text{IMEM}} + t_{\text{RegRead}} + t_{\text{ALU}} + t_{\text{DMEM}} + (t_{\text{RegWrite}} + t_{\text{setup}})$。

    * 最高频率：$f_{\text{max}} = 1 / T_{\text{min}}$。

## 控制单元实现

* **控制单元接口**

    * 输入信号：指令机器码（`inst[6:2]` 操作码、`inst[14:12]` funct3、`inst[30]` funct7）及比较器反馈（$BrEq, BrLT$）。

    * 输出信号：驱动数据通路的多路选择器（$PCSel, ImmSel, ASel, BSel, WBSel$）及写使能信号（$RegWEn, MemRW, BrUn$）。

* **RISC-V 编码优化**

    * 操作码识别：RV32I 指令最低两位 `inst[1:0]` 恒为 `11`，控制逻辑仅需检查 `inst[6:2]` 即可区分指令大类。

    * 无符号分支判定：在分支指令前提下，当 `inst[13] == 1` 时，操作即为无符号分支。

* **硬件实现方案**

    * 只读存储器（ROM）查表法：将 11 位输入作为地址，通过译码器输出单热编码（One-hot Encoding）选通控制信号行。

    * 组合逻辑阵列（Combinational Logic）：利用积之和（SOP）逻辑，通过与平面（AND-Plane）识别指令，或平面（OR-Plane）汇总控制信号，延迟更低。

    * > **提示**：控制真值表中的“任意态（Don't Care, $*$）”在硬件综合中可用于布尔代数化简，减少逻辑门数量。
