# IEEE浮点数标准与表示法

## 定点数表示

* **定点数（Fixed Point）**

    * > **定义**：通过预先约定的固定位置作为二进制小数点，将比特序列划分为整数部分与小数部分的表示方法。

    * 机理：小数点位置由通信双方事先约定，硬件寄存器中不存储小数点字符，仅存储纯二进制位。

    * 边界：在比特总数固定的前提下，表示范围与表示精度存在不可调和的矛盾；增加整数位会牺牲小数精度，增加小数位会缩减表示范围。

---

## 浮点数核心机制

* **浮点数（Floating Point）**

    * > **定义**：通过将比特位划分为符号、指数、尾数三个字段，使小数点位置可根据数值大小动态漂移的表示方法。

    * 结构：数值 $= (-1)^S \times (1.M)_2 \times 2^E$。

    * 隐含前导一（Implicit Leading 1）：在规范化形式下，二进制小数点左侧恒为 1，硬件不显式存储该位，从而凭空增加一位有效精度。

* **位段划分**

    * 符号位（Sign, S）：占用 1 位，$0$ 为正，$1$ 为负。

    * 指数字段（Exponent, E）：占用 $E$ 位，充当调整小数点位置的“旋钮”。

    * 尾数/小数字段（Fraction/Mantissa, M）：占用 $M$ 位，存储小数点后的有效数字部分。

## IEEE 754 标准

* **单精度与双精度**

| 格式名称 | 总位宽 | 符号位 | 指数位宽 | 尾数位宽 | 指数偏置量 | 有效精度 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 单精度 (FP32) | 32 bit | 1 bit | 8 bit | 23 bit | 127 | 24 bit |
| 双精度 (FP64) | 64 bit | 1 bit | 11 bit | 52 bit | 1023 | 53 bit |

* **偏置表示法（Biased Representation）**

    * > **定义**：将实际指数 $e$ 加上一个固定常数（偏置量 Bias）存储为无符号整数 $E$。

    * 规则：$E = e + \text{Bias}$。

    * 优势：保证了指数的单调性，使得硬件可以直接将浮点数当作无符号整数进行大小比较，无需解码即可实现快速排序与分支判断。

---

## 精度与边界

* **精度断崖（Precision Cliff）**

    * 机理：浮点数在每个指数区间内刻度均匀，但随着指数增加，相邻刻度间的步长呈几何级数翻倍。

    * 边界：当步长增长至 1 时，浮点数失去小数表示能力；当步长增长至 2 时，无法精确表示奇数整数。

    * > **易错点**：⚠️ 浮点数并不总是能精确表示整数，当数值超过 $2^{24}$ 时，奇数整数在 32 位浮点数中无法存储，会发生强制舍入。

* **溢出与下溢**

    * 溢出（Overflow）：数值超过最大指数表示范围，硬件将其推向无穷大。

    * 下溢（Underflow）：数值小于最小规格化数，系统无法分辨其与 0 的差别。

## 特殊值与非规格化数

* **特殊值编码**

| 指数字段 (E) | 小数字段 (M) | 数学含义 |
| :--- | :--- | :--- |
| 0 (全 0) | 0 (全 0) | 零 (±0) |
| 0 (全 0) | 非 0 | 非规格化数 |
| 1 ~ 254 | 任意 | 规格化浮点数 |
| 255 (全 1) | 0 (全 0) | 无穷大 (±∞) |
| 255 (全 1) | 非 0 | 非数字 (NaN) |

* **非规格化数（Denormalized Numbers）**

    * > **定义**：当指数字段全 0 且尾数不为 0 时，用于表示极小数值的特殊格式。

    * 规则：隐含前导位由 1 变为 0，实际指数强制锁定为 $-126$。

    * 作用：实现渐进式下溢，填补 0 与最小规格化数之间的“科罗拉多大峡谷”，保证 $x - y == 0$ 当且仅当 $x == y$。

## 现代浮点架构

* **FP16 与 Bfloat16**

    * FP16（传统半精度）：5 位指数，10 位尾数。因指数范围过窄，在深度学习计算中极易发生梯度爆炸或消失。

    * Bfloat16（脑浮点）：8 位指数，7 位尾数。

    * > **提示**：深度学习模型对动态范围敏感，对精度钝感。Bfloat16 通过保留与 FP32 相同的指数范围，成为 AI 训练的事实标准。

* **硬件算力格式**

    * TF32：英伟达张量核心格式，结合 FP32 的指数范围与 FP16 的精度。

    * FP8：针对超大规模模型推理优化的 8 位浮点格式（E4M3 与 E5M2）。
