# 多路选择器与算术逻辑单元ALU

## 多路选择器（Multiplexer，MUX）

* **定义**：一种组合逻辑电路，拥有多个数据输入端和一个数据输出端，输出信号完全由控制信号（Select）决定。

* **机理**：
    * 输出仅取决于当前输入，无时钟驱动，即时响应。
    * 满足关系：$2^{\text{选择信号位宽}} \ge \text{输入通道数}$。

* **二选一多路选择器（2-to-1 MUX）**
    * > **定义**：具有两个数据输入 $A, B$、一个选择信号 $S$ 的 1 位选择器。
    * 逻辑表达式：$C = \bar{S}A + SB$。
    * 实现：1 个反相器、2 个与门、1 个或门。

* **四选一多路选择器（4-to-1 MUX）**
    * 逻辑表达式：$Out = \bar{S_1}\bar{S_0}A + \bar{S_1}S_0 B + S_1\bar{S_0} C + S_1S_0 D$。
    * 结构：选择信号的 4 种组合互斥，有且仅有一个与项输出为 1。
    * 层级构建：可由 3 个 2:1 MUX 级联构成二叉树结构（半决赛-决赛模型）。

## 算术逻辑单元（Arithmetic Logic Unit，ALU）

* **架构**：
    * 核心：支持加法（ADD）、减法（SUB）、按位与（AND）、按位或（OR）的 32 位运算模块。
    * 控制：由 2 位控制信号 $S$ 经多路选择器决定最终输出。
    * 硬件哲学：硬件始终在运行，所有运算通道并发计算，MUX 仅负责挑选输出。

* **电路阅读规则**：
    * 无圆点交汇：空间跨越，互不连通。
    * 有圆点交汇：物理电气连接，信号分流。

## 加法器（Adder）

* **半加器（Half Adder）**
    * > **定义**：仅处理最低位（LSB）的加法模块，无进位输入。
    * 逻辑：本位和 $S_0 = A_0 \oplus B_0$；进位输出 $C_1 = A_0 B_0$。

* **全加器（Full Adder，FA）**
    * > **定义**：处理通用位 $i$ 的加法模块，包含进位输入 $C_i$。
    * 逻辑：
        * 本位和 $S_i = A_i \oplus B_i \oplus C_i$。
        * 进位输出 $C_{i+1} = A_i B_i + A_i C_i + B_i C_i$（多数电路）。

* **行波进位加法器（Ripple Carry Adder，RCA）**
    * 结构：将 32 个 1 位全加器级联，进位信号由低位向高位逐级传递。
    * 边界：进位串行链路构成关键路径，导致传播延迟，限制系统时钟主频。

## 溢出判定与减法实现

* **无符号溢出**：
    * 判据：最高位全加器的进位输出 $C_n = 1$。

* **补码溢出（Two's Complement Overflow）**
    * 判据：$\text{Overflow}_{\text{signed}} = C_{n-1} \oplus C_n$。
    * 逻辑：当最高位进位输入 $C_{n-1}$ 与进位输出 $C_n$ 不一致时，发生溢出。
    * ⚠️ **易错点**：补码溢出不能仅凭 $C_n=1$ 判断，必须结合 $C_{n-1}$ 进行异或运算。

* **加减法一体化架构**
    * 原理：$A - B = A + \bar{B} + 1$。
    * 实现：利用异或门作为条件反相器，当 $\text{Sub}=1$ 时，将 $B$ 逐位取反，并向 $C_0$ 输入 1。

## 随堂思考题解析

* **真值表行数**：
    * 4 位选择信号的 MUX 拥有 16 路数据输入，总输入引脚为 $16+4=20$ 位。
    * 完整真值表行数为 $2^{20} = 1,048,576$ 行。

* **移位器级联**：
    * 移位逻辑具备层级性，可通过级联单比特移位单元构建任意位宽的移位器。
