# 虚拟内存分页机制与页表结构

## 多任务并发与内存冲突

*   **内存冲突困境**
    *   在多任务并发环境下，若所有程序直接访问物理内存，会导致全局变量覆盖、代码段基地址冲突以及栈指针（Stack Pointer, sp）交错，造成程序崩溃。
    *   现实需求：每个程序必须拥有独立的虚拟地址空间，包含专属的代码段、堆空间与栈空间。

## 虚拟内存核心机制

*   **虚拟内存（Virtual Memory, VM）**
    *   > **定义**：一种内存管理技术，通过软硬件协作，为每个程序营造独占完整地址空间的抽象幻觉。
    *   程序在指令中使用的地址均为虚拟地址，系统在后台将其动态重定向至物理内存。

*   **地址分类**
    *   > **定义**：
        *   **虚拟地址（Virtual Address, VA）**：程序可见的虚构地址，32 位系统下范围为 `0x00000000` 至 `0xFFFFFFFF`。
        *   **物理地址（Physical Address, PA）**：内存硬件芯片上真实存在的电信号选通地址。

## 页式地址映射原理

*   **页（Page）**
    *   > **定义**：虚拟内存管理的基本数据块单位。
    *   **绝对恒等性**：虚拟页与物理页的大小必须严格一致（如 4 KB）。
    *   **映射规则**：以页为单位进行批量映射，而非逐字节映射，大幅压缩映射表体积。

*   **地址结构**
    *   > **定义**：
        *   **虚拟页号（Virtual Page Number, VPN）**：虚拟地址高位，标识虚拟页编号。
        *   **页内偏移量（Page Offset, Offset）**：虚拟地址低位，标识页内字节位置。
        *   **物理页号（Physical Page Number, PPN）**：物理地址高位，标识物理页帧编号。
    *   **转换机理**：硬件将 VA 切分为 VPN 和 Offset，通过 VPN 查表获取 PPN，将 PPN 与原封不动的 Offset 拼接，形成 PA。

## 地址转换与页表结构

*   **页表（Page Table）**
    *   > **核心原则**：系统中的每一个程序必须拥有专属于自己的、独立的页表。
    *   **存储位置**：页表本身是数据，必须驻留在物理内存中。
    *   **存储优化**：页表设计为一维数组，VPN 直接作为数组索引（Index），无需存储 VPN 列。

*   **访存代价**
    *   > **注意**：在虚拟内存系统中，单次内存访问演变为两次物理内存访问：
        1. 第一次访问：查阅页表获取 PPN。
        2. 第二次访问：根据 PA 读取实际数据。
    *   > **易错点**：程序无法跳过页表直接访问物理内存，因为程序仅持有虚拟地址，缺乏物理地址映射信息。

## 缺页处理与按需分页

*   **按需分页（Demand Paging）**
    *   > **定义**：一种惰性加载策略，程序启动时不预分配物理内存，仅在程序真正访问某虚拟页时才触发加载。
    *   **有效位（Valid Bit）**：页表项中的标志位。
        *   `Valid Bit = 1`：页面驻留在物理内存中。
        *   `Valid Bit = 0`：页面在磁盘上，触发缺页错误。

*   **缺页错误（Page Fault）**
    *   > **定义**：当 CPU 访问的页面不在物理内存中时触发的硬件异常中断。
    *   **处理流程**：
        1. 暂停程序，操作系统接管。
        2. 从磁盘定位并读取目标页。
        3. 若物理内存已满，执行页面置换（将牺牲页换出到磁盘）。
        4. 将目标页装入物理内存，更新页表（填入 PPN，置 Valid Bit 为 1）。
        5. 恢复程序，重新执行访存指令。

## 系统参数推导模型

*   **核心旋钮**
    *   **页面大小（Page Size）**：决定 Offset 位数，$\text{Offset 位数} = \log_2(\text{Page Size})$。
    *   **虚拟内存容量（VM Size）**：决定 VA 总位数，$\text{VA 位数} = \log_2(\text{VM Size})$。
    *   **物理内存容量（PM Size）**：决定 PA 总位数，$\text{PA 位数} = \log_2(\text{PM Size})$。

*   **位宽计算法则**
    *   $\text{VPN 位数} = \text{VA 位数} - \text{Offset 位数}$
    *   $\text{PPN 位数} = \text{PA 位数} - \text{Offset 位数}$

*   **页表开销计算**
    *   $\text{页表条目数} = 2^{\text{VPN 位数}}$
    *   $\text{页表总大小} = \text{页表条目数} \times \text{单个页表项大小}$
