> 来源：**听音转录**——非平台字幕，由讲师原声转录

前面我们讲了，线性表可以用顺序存储，也就是说用数组来实现；同样的，顺序表也可以用链表来实现。

线性表用链式存储怎么实现呢？它实际上就是把逻辑上相邻的两个元素，通过链把它连接在一起，而不要求这两个元素在物理上相邻。一个线性表用数组存储的时候，它两个相邻的元素不仅逻辑上是相邻的，而且在物理上也是相邻的。我们前面看到了，插入、删除都要把数组后面的元素往前挪或者往后挪，而在链里面，则只要轻易地修改链就行了，不需要对很多元素进行挪动。

我们来看一下，比方说有这样的一张链表。这个链表每个结点都是一个结构，这个结构里面至少有两个分量：一个分量代表这个结点它所对应的这个数据；另外一个代表它的下一个结点的位置，也就是说是 `Next` 这样的一组指针。

在数组里面，我们知道序号为 $i$ 的元素，想找到这个元素是很简单的，`A[i]` 或者说 `A[i-1]` 就可以了。我们要找数组的线性表的这个长度，我们有个 `Last` 指针，也很容易求得出来。但是如果在一个链表里面，我们光知道一个链表的头，我们怎么知道第 $i$ 个元素在哪里？链表的长度是多少？

所以显然，链式的存储方法跟数组相比，在这两个问题上面就要复杂了。

下面我们来看看，如果按链表的方式来实现我们的线性表，它的主要操作是怎么实现的。

首先一个，求表长。用链表来实现的时候，我们只知道链表的头指针，而且它是单向链表。这个时候要想求这个表里的元素，我们一种方法就是把这个链表遍历一遍，从头到尾一个个看，看到最后一个元素为止。这里就是用链表遍历的方法来求表长。

链表遍历的方法比较简单：一开始，设一个临时的指针 `p` 指向链表的头，在链表里是 `PtrL`；然后我们用个计数器，就是 `j`，一开始设为 0；然后每遍历一个加一个 1，每遍历一个加一个 1。

所以下面是一个循环。循环条件是什么？就是这个链表还没结束，也就是说这个 `p` 指针不等于 `NULL`，那么循环就不断地做。每循环一次，`p->Next` 赋给 `p`，就是让这个链表的指针往后挪一位，同时 `j` 加个 1。一直循环，循环到最后一个结点的时候，它的 `Next` 是一个 `NULL`，所以这个时候 `p` 得到的是个 `NULL`，那么这个循环就退出来。这个时候 `j` 的值就代表了表长的值。它的时间复杂度就等于表的长，是 $O(n)$。

第二个操作，查找。

在数组里面，我们要找第 $K$ 个元素是很简单的，直接 return `A[K-1]` 就可以了。那么在我们的链表里面就没那么简单，我们必须要一个个地往后找，所以这也是采用的方法，也类似于链表这样的一种遍历方法。

我们首先把 `p` 这个临时的指针、临时变量把它设为链表的表头。我们用个 $i$ 来代表第几个元素。一开始的时候 `p` 是指向第一个元素，所以这个时候的 $i$ 就设为 1。

接下来是一个循环。只要 `p` 不等于空，就是链表没结束，就一个个地往后做。当然还有一个条件，就是说我们还没找到第 $K$ 个元素。所以循环有两个条件：一个是表不空，另外一个是 $i < K$。那么这个时候循环体就做两件事情：一件事情把 `p->Next` 赋给 `p`，也就是说往后挪一个结点；第二个把 $i$ 加个 1。所以往后挪一下，$i$ 加个 1，这个循环一直做。

做到这个循环退出来，循环退出来意味着这两个条件里面有一个被破坏了：一个条件就是 `p` 不等于 `NULL`，一个是 $i < K$。所以这个循环退出来就有两种可能：一个是 `p` 等于 `NULL` 了，一个是 $i$ 等于 $K$ 了。这两种可能也是代表了两种不同的情况。

如果 $i = K$，说明是找到了，所以这个时候就 return `p`；否则的话，那就意味着是 `p` 等于 `NULL` 了，所以这个时候就没找到，就 return `NULL`。

这是一种查找。还有一种叫按值查找。已知一个 $X$，然后问你这个 $X$ 是在这个表的哪个位置，你就返回这个结点的指针，这个结点所在的地址。

同样也是一个链表遍历的一种基本方法。一开始 `p` 就设为这个链表的头，就是把 `PtrL` 赋给 `p`。接下来是个循环。循环条件也是两个：一个表不空，`p` 不等于 `NULL`，链表不空；另外一个，我们没找到，没找到就是 `Data != X`。所以只要没找到，而且表不空，就不断地往后挪，往后挪就是 `p->Next` 赋给 `p`。

所以这个循环退出来的时候，也是两个可能：一个可能这个 `Data == X` 了，就找到了。找到了的时候，这个时候你就返回这 $X$ 所在结点的地址，就是 `p`。另外一个，`p` 等于 `NULL` 了。`p` 等于 `NULL` 没找到，没找到你就 return `NULL`。

所以你只要调用这个 `Find` 函数，发现它返回值等于 `NULL` 的时候，就说明肯定是没找到。
