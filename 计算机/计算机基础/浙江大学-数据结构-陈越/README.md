# 浙江大学：数据结构与算法

浙江大学陈越老师的数据结构与算法基础课。课程从数据的组织与算法效率度量出发，依次讲透线性表、栈与队列、树与二叉树、图、查找与排序，每讲都以可运行的手写代码与经典算法题收束。

- **原视频**：https://www.bilibili.com/video/BV1H4411N7oD — Bilibili，BV1H4411N7oD
- **145 集**，已产出 4 册模块全书、8 篇复习笔记、21 份逐字稿

## 怎么学

- **打地基** → 模块 01、02 讲数据组织、空间开销与复杂度渐进表示，是全课的方法论
- **线性结构** → 模块 03~05 覆盖线性表、栈、队列与多项式运算的工程实现
- **树形结构** → 模块 06~08 讲树的表示、遍历、平衡二叉树与二叉堆
- **图与检索** → 模块 09~10 覆盖并查集、图的遍历与核心算法
- **考研冲刺** → 直接查阅 `notes/` 下的复习笔记做速查
