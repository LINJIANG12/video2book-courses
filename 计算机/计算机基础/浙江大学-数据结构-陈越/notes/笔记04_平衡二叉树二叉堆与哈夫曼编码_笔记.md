# 平衡二叉树、二叉堆与哈夫曼编码

## 平衡二叉树与自平衡调整

### 平衡二叉树与平衡因子

* **平均查找长度（Average Search Length，ASL）**

    * > **定义**：在数据结构中成功查找到目标关键字时，与树中节点进行关键码比较次数的数学期望值。

    * 计算公式为 $ASL = \frac{1}{N} \sum_{i=1}^{k} (d_i \times N_i)$，其中 $N$ 为总节点数，$d_i$ 为第 $i$ 层节点的比较次数（根节点计为 1 次），$N_i$ 为第 $i$ 层包含的节点数量。

    * 关键字插入次序直接决定树形与查找效率：以 12 个自然月份英文单词为例，均匀展开形态的树 $ASL = 3.0$；自然月份输入顺序形态的树 $ASL = 3.5$；字典序升序插入导致树彻底退化为单向单链表，$ASL = 6.5$。

* **平衡因子（Balance Factor，BF）**

    * > **定义**：二叉树中某一节点的左子树高度减去其右子树高度的差值，即 $BF = h_L - h_R$。

    * 节点的倾斜状态由平衡因子数值表征：左子树高于右子树时 $BF > 0$；右子树高于左子树时 $BF < 0$；左右子树等高时 $BF = 0$。

* **平衡二叉树（Adelson-Velsky and Landis Tree，AVL 树）**

    * > **定义**：一棵或者为空，或者其任一节点的左右子树皆为平衡二叉树，且所有节点平衡因子的绝对值均不超过 1（即 $BF \in \{-1, 0, 1\}$）的自平衡二叉搜索树。

    * 判定规则为整棵树中的每一个节点都必须满足 $|BF| \le 1$；只要存在任意一个节点的 $|BF| \ge 2$，整棵树即破坏平衡二叉树约束。

* **平衡二叉树的高度界限（Height Bound of AVL Tree）**

    * > **定义**：高度为 $h$ 的平衡二叉树所能容纳的最少节点数下界与树高增长趋势的数学界定。

    * 树的高度 $h$ 定义为树中路径的最大边数：单根节点树高度 $h = 0$，最少节点数 $n_0 = 1$；两层节点树高度 $h = 1$，最少节点数 $n_1 = 2$。

    * 设高度为 $h$ 的 AVL 树最少节点数为 $n_h$，其左右子树必分别为高度 $h-1$ 与 $h-2$ 且节点数最少的 AVL 树，由此确立最少节点数递推关系式：
    $$n_h = n_{h-1} + n_{h-2} + 1$$

    * 最少节点数递推序列与标准斐波那契数列（Fibonacci Sequence）满足通项映射 $n_h = F_{h+2} - 1$（其中标准数列为 $F_0 = 1, F_1 = 1, F_2 = 2, F_3 = 3, F_4 = 5, F_5 = 8, \dots$）。

    * 斐波那契数列呈黄金分割比底数的指数增长（$F_i \approx \frac{1}{\sqrt{5}} \phi^{i+1}$，其中 $\phi = \frac{1+\sqrt{5}}{2} \approx 1.618$），$n_h$ 随树高呈指数级增长，反推可知包含 $n$ 个节点的 AVL 树高度上限为 $h = O(\log_2 n)$，查找操作时间复杂度严格稳定在对数阶。

| 高度 $h$ | 最少节点数 $n_h$ | 斐波那契数列项 | 对应数值 $F_{h+2}$ | 映射关系 |
| :---: | :---: | :---: | :---: | :---: |
| 0 | 1 | $F_2$ | 2 | $n_0 = F_2 - 1 = 1$ |
| 1 | 2 | $F_3$ | 3 | $n_1 = F_3 - 1 = 2$ |
| 2 | 4 | $F_4$ | 5 | $n_2 = F_4 - 1 = 4$ |
| 3 | 7 | $F_5$ | 8 | $n_3 = F_5 - 1 = 7$ |
| 4 | 12 | $F_6$ | 13 | $n_4 = F_6 - 1 = 12$ |

### 平衡旋转调整模式

* **发现者与麻烦节点（Discoverer and Troublemaker）**

    * > **定义**：插入新节点打破平衡二叉树性质后，整棵树中失衡的定位基准节点与引发失衡的触发节点。

    * 发现者为插入新节点后，整棵树祖先路径上平衡因子绝对值变为 2 的节点中，深度最深（位置最靠下）的那一个节点。

    * 麻烦节点为新插入导致平衡性破坏的节点。

    * 调整原则为必须优先针对最底层的发现者执行局部旋转拉平，该子树高度收缩后其上层祖先节点的失衡通常随之消除，同时旋转变换全程必须严格维持二叉搜索树“左小右大”的大小单调序。

* **右单旋（Right-Right Rotation，RR 旋转）**

    * > **定义**：当麻烦节点插入在发现者右子树的右子树上，导致发现者平衡因子恶化为 $-2$ 时执行的单向左旋调整。

    * 调整机制为将发现者 A 的右孩子 B 向上提升为子树新根，A 下沉变为 B 的左孩子，B 原有的左子树 BL 转接为 A 的右子树，原有的 AL 与 BR 维持不动，保持全序 $AL < A < BL < B < BR$。

    ```text
        失衡初始状态 (RR 型)                  RR 单旋调整后状态
               A (发现者, BF=-2)                    B (新根)
              / \                                  / \
            AL   B                                A   BR
                / \                              / \
               BL  BR (含麻烦节点)              AL  BL
    ```

* **左单旋（Left-Left Rotation，LL 旋转）**

    * > **定义**：当麻烦节点插入在发现者左子树的左子树上，导致发现者平衡因子恶化为 $+2$ 时执行的单向右旋调整。

    * 调整机制为将发现者 A 的左孩子 B 向上提升为子树新根，A 下沉变为 B 的右孩子，B 原有的右子树 BR 转接为 A 的左子树，原有的 BL 与 AR 维持不动，保持全序 $BL < B < BR < A < AR$。

    ```text
        失衡初始状态 (LL 型)                  LL 单旋调整后状态
               A (发现者, BF=2)                     B (新根)
              / \                                  / \
             B   AR                               BL  A
            / \                                      / \
    (麻烦) BL  BR                                   BR  AR
    ```

* **左右双旋（Left-Right Rotation，LR 旋转）**

    * > **定义**：当麻烦节点插入在发现者左子树的右子树上，导致发现者平衡因子恶化为 $+2$ 时执行的双向旋转调整。

    * 调整机制聚焦于发现者 A、左孩子 B 及其右孩子 C（大小单调序恒为 $B < C < A$）：数值居中的节点 C 跃升为子树新根，B 降为 C 的左孩子，A 降为 C 的右孩子；C 原有的左子树 CL 挂在 B 的右子树，C 原有的右子树 CR 挂在 A 的左子树，保持全序 $BL < B < CL < C < CR < A < AR$。

    ```text
        失衡初始状态 (LR 型)                  LR 双旋调整后状态
               A (发现者, BF=2)                     C (新根)
              / \                                 /   \
             B   AR                              B     A
            / \                                 / \   / \
           BL  C                               BL CL CR AR
              / \
             CL  CR (含麻烦节点)
    ```

* **右左双旋（Right-Left Rotation，RL 旋转）**

    * > **定义**：当麻烦节点插入在发现者右子树的左子树上，导致发现者平衡因子恶化为 $-2$ 时执行的双向旋转调整。

    * 调整机制聚焦于发现者 A、右孩子 B 及其左孩子 C（大小单调序恒为 $A < C < B$）：数值居中的节点 C 跃升为子树新根，A 变为 C 的左孩子，B 变为 C 的右孩子；C 原有的左子树 CL 挂在 A 的右子树，C 原有的右子树 CR 挂在 B 的左子树，保持全序 $AL < A < CL < C < CR < B < BR$。

    ```text
        失衡初始状态 (RL 型)                  RL 双旋调整后状态
               A (发现者, BF=-2)                    C (新根)
              / \                                 /   \
             AL  B                               A     B
                / \                             / \   / \
               C   BR                          AL CL CR BR
              / \
             CL  CR (含麻烦节点)
    ```

    * > **易错点**：⚠️ 若新节点插入后未引发任何节点的平衡因子绝对值超过 1，整树拓扑虽无需旋转调整，但从插入位置回溯到根节点路径上所有祖先节点的平衡因子均已发生数值改变，必须在递归回溯中完成更新维护。

## 二叉搜索树同构判别与静态链表逆转

### 二叉搜索树同构判别

* **二叉搜索树同构性（Isomorphism of BST）**

    * > **定义**：不同数字插入序列所构建出的二叉搜索树具备完全相同的节点拓扑结构与键值分布。

    * 两个序列同构的前提是其根节点取值相等，且以首元素为界切分出的左子序列与右子序列分别递归同构。

    * 判别方案存在三类权衡：显式建两棵树递归比对开销偏重；不建树的纯序列子集递归拆分需频繁搬移数组；构建基准树的访问标记追踪法兼顾时空开销。

* **标记追踪法（Flag Tracking Method）**

    * > **定义**：在测试集合中仅建立一棵基准二叉搜索树，待测序列直接在基准树上模拟查找路径，依靠节点访问标志位判定拓扑一致性的算法。

    * 树节点增加整型标记 `flag`（0 表示未访问，1 表示已访问）。待测数值 $V$ 沿基准树推进：若当前节点已被访问，则按大小继续深入左右子树，若数值相等说明待测序列存在重复元素判错；若当前节点未被访问且数值等于 $V$，则打上访问标记 `flag = 1` 判定匹配；若当前节点未被访问但数值不等于 $V$，表明路径越过了未出现的空闲节点，插入时序发生错位直接判错。

    * 单个序列比对完成后，必须通过后序遍历调用 `ResetT` 函数递归清零整棵树各节点的 `flag`；整组序列比对完毕后，必须通过后序遍历调用 `FreeTree` 函数彻底释放内存。

    * > **易错点**：⚠️ 在按行读取待测序列时，若在中间某个数值处判定不匹配，函数绝对不能提前退出；若提前退出，该行输入流中剩余的数值将滞留在标准输入缓冲区中，被后续序列错误读取造成评测全盘错位崩溃。必须引入局部状态机，在发现矛盾后关闭校验但坚持使用 `scanf` 读完该行整组数据。

### 静态链表模拟与分段逆转

* **静态链表（Static Linked List）**

    * > **定义**：在缺乏物理原生指针或模拟内存碎片化环境时，使用连续结构体数组与整数下标模拟指针寻址机制的抽象链表实现。

    * 节点的物理地址等价替换为数组下标，指针域（`Next`）存储后继节点的数组下标，空指针 `NULL` 统一定义为 `-1`。

    * 物理指针是硬件物理地址映射的一种特例，指针的抽象本质是能够明确索引到下一个存储单元的地址机制。

* **三指针滑动分段逆转（Three-Pointer Sliding Segment Inversion）**

    * > **定义**：在带虚拟头节点的单链表上，维持三个游标指针协同前推，每 $K$ 个节点进行局部指针反向翻转的迭代算法。

    * 引入带虚拟头节点（Dummy Head）可使首节点与中间节点的逆转遵循完全相同的连接规则，免除头指针特殊边界判断。

    * 运行期间维持三指针：`new` 指针指向已逆转局部新表头，`old` 指针指向未逆转老表头，`temp` 指针用于在指针反转前暂存 `old->Next` 防断链。

    * 单步反转流程：必须先执行 `temp = old->Next;` 锁定后继，再执行 `old->Next = new;` 翻转指针，最后前推游标 `new = old; old = temp;`；循环 $K-1$ 次后，将原区间首节点（现区间尾节点）的 `Next` 缝合指向剩余未翻转表头 `old`，虚拟头节点的 `Next` 重新指向翻转后的新表头 `new`。

* **死节点过滤防御（Dead Node Filtering Defense）**

    * > **定义**：在给定的输入节点集合中，剔除未挂接在有效主链上的游离废弃节点，仅提取有效逻辑链表的预处理机制。

    * 输入给出的 $N$ 个节点可能包含碎片化的孤立死节点。算法必须从给定的 `Head` 地址出发，严格沿着 `Next` 单向遍历直到 `-1`，将触及的有效节点顺序载入独立序列并统计真实有效长度 $N_{valid}$。

    * 任何未被遍历触碰的孤立节点一律丢弃；分段逆转只作用于有效节点序列，末尾不足 $K$ 个的节点严格保持原序输出。

### 算法边界测试设计

* **边界测试（Boundary Testing）**

    * > **定义**：针对输入变量的合法取值范围，在极限上界、下界以及分界拐点处专门设计的测试用例集合。

    * 链表反转题目完备测试必须覆盖：地址范围极限全零 `00000` 与全九 `99999`；元素规模极限 $N = 10^5$；翻转步长极限 $K = 1$（完全不翻转原样输出）与 $K = N$（整条链表彻底全翻转）；整除临界状态 $N \pmod K == 0$（无任何残留尾巴）与余数临界状态剩余节点恰好为 $K - 1$ 个（极限保留不翻转）。

    * 防投机取巧测试必须在输入集合中掺入不属于链表的游离噪声节点，识别并剔除试图通过全局数组乱序排序或盲目遍历冒充链表操作的错误程序。

## 二叉堆与优先队列

### 优先队列与堆结构选择

* **优先队列（Priority Queue）**

    * > **定义**：一种支持插入任意优先级的元素，并支持访问和移出集合中具有最高（或最低）优先级元素的数据结构。

    * 核心抽象操作为 `Insert`（插入新元素）与 `DeleteMax` / `DeleteMin`（删除并返回最大或最小优先级元素）。

    * 最大堆与最小堆在逻辑上完全对称，将数据取相反数存入最大堆即可等价实现最小堆。

| 存储方案 | 插入操作（Insert） | 删除最大值操作（DeleteMax） | 性能瓶颈分析 |
| :--- | :--- | :--- | :--- |
| **无序数组** | $O(1)$（直接追加在数组末尾） | $O(N)$（需全局扫描找最大值，后续元素前移） | 删除时线性扫描代价沉重 |
| **无序链表** | $O(1)$（直接插入在表头或表尾） | $O(N)$（需从头到尾遍历比对，改指针删除） | 查找最大节点耗时极长 |
| **有序数组** | $O(N)$（需查找插入位置，后续元素集体后移） | $O(1)$（末尾即最大值，直接下调大小） | 插入时数据搬迁极其频繁 |
| **有序链表** | $O(N)$（需从头到尾遍历寻找插入点） | $O(1)$（表头或表尾即最大值，直接摘取） | 查找链表插入位置不可跳跃 |

* **二叉搜索树用于优先队列的退化困境（BST Degradation in Priority Queue）**

    * > **定义**：在二叉搜索树中频繁执行删除最大值操作导致树形单侧剥蚀、退化为倾斜链表的结构缺陷。

    * 最大元素恒处于二叉搜索树的最右下端，连续执行 `DeleteMax` 会反复削平右侧枝桠，导致左侧完全失衡，树高由 $O(\log N)$ 恶化为 $O(N)$，丧失对数操作性能。

### 完全二叉树的数组存储与堆序性

* **堆（Heap）**

    * > **定义**：一棵在结构上满足完全二叉树形态，且在有序性上满足任意节点值均大于等于（或小于等于）其左右子树所有节点值的二叉树。

    * 根节点取全局最大值的称为最大堆（Max Heap），根节点取全局最小值的称为最小堆（Min Heap）。从根节点出发沿任意一条分支向下走到叶节点，节点数值呈现严格的单调序列。

* **完全二叉树的数组映射（Array Mapping of Complete Binary Tree）**

    * > **定义**：无需指针域、利用顺序存储数组下标运算直接寻址完全二叉树父子节点拓扑的存储方案。

    * 根节点规定存放于数组下标 1 处，下标 0 保留作哨兵。

    * 对于数组下标为 $i$ 的节点：其父节点下标为 $\lfloor i / 2 \rfloor$；其左儿子下标为 $2i$；其右儿子下标为 $2i + 1$。

    * 判断节点是否存在左儿子的边界条件为 $2i \le Size$；判断是否存在右儿子的边界条件为 $2i + 1 \le Size$。

### 最大堆的核心操作

* **哨兵优化机制（Sentinel Optimization Mechanism）**

    * > **定义**：在数组下标 0 处预置一个大于堆中所有可能元素取值的极大值常量（`MAXDATA`），用于免除插入上滤循环边界判断的技巧。

    * 数组动态分配大小必须设定为 `Capacity + 1`，正式元素从下标 1 开始占用。

    * 在上滤循环中，若插入元素达到全局最大一路冲向树顶，当探查到父节点下标 $i / 2 = 0$ 时，由于 `Elements[0] = MAXDATA` 恒大于插入值，循环条件 `Elements[i / 2] < item` 自然终止，省去每轮迭代中的 `i > 1` 逻辑与运算。

* **上滤插入算法（Percolate Up）**

    * > **定义**：将新元素放置在完全二叉树末尾，顺着父节点路径向上逐级比对并交换空穴，直至恢复堆序性的插入过程。

    * 算法步骤：堆大小递增 1（$i = ++Size$）；考察父节点 $i / 2$，若父节点值小于新元素，则父节点下移至空穴位置 $i$，空穴上移（$i /= 2$）；循环直到父节点值大于等于新元素，将新元素写入空穴。

    * 时间复杂度为 $O(\log N)$，移动最大步数受限于完全二叉树高度。

* **下滤删除算法（Percolate Down）**

    * > **定义**：取走堆顶全局最大值后，将数组末尾元素暂存并置于根部空穴，自顶向下与较大儿子比对并下沉空穴，直至恢复堆序性的删除过程。

    * 算法步骤：取出堆顶 `Elements[1]`，暂存末尾元素 `temp = Elements[Size--]`；从根节点 $Parent = 1$ 出发，在其左右儿子中挑出较大者 $Child$；若 `temp` 大于等于该较大儿子，则下滤终止；否则将较大儿子提升至 $Parent$，空穴下移（$Parent = Child$），重复至底层叶节点；最后将 `temp` 写入确定的 $Parent$ 空穴。

    * 时间复杂度严格为 $O(\log N)$。

    * > **易错点**：⚠️ 在下滤寻找较大儿子时，条件 `Child != H->Size` 是合法访问右儿子 `Elements[Child + 1]` 的绝对边界。若 `Child == H->Size`，表明当前左儿子已是堆中最后一个元素，节点不存在右儿子；此时若越界访问 `Child + 1` 将引发脏读。

### 线性时间快速建堆

* **线性时间建堆算法（Linear Time Build Heap）**

    * > **定义**：将无序元素直接填充进完全二叉树，从最后一个非叶节点自底向上逐级执行下滤调整，在 $O(N)$ 时间内构建合格堆的算法。

    * 连续调用 $N$ 次 `Insert` 建堆的最坏时间复杂度为 $O(N \log N)$；而直接入树后自底向上调整可收敛至线性时间。

    * 算法步骤：将 $N$ 个元素直接填入数组下标 1 至 $N$；叶节点天然成堆无需调整；从倒数第一个拥有儿子的非叶节点下标 $\lfloor N / 2 \rfloor$ 开始，按标号逆序递减推进至根节点 1，依次对每一个节点调用一次下滤操作。

    * 时间复杂度收敛为 $O(N)$ 的数学成因：树中底层节点占据绝大多数（倒数第二层占全树节点约一半），但下滤最多只需移动 1 步；需要较长下滤步数的高层节点数量呈指数级递减（根节点仅 1 个）；所有节点最大下滤移动步数级数累加和不超过 $2N$。

## 哈夫曼树与最优前缀编码

### 带权路径长度与哈夫曼树定义

* **不等长编码诉求（Variable-Length Coding Demand）**

    * > **定义**：依据字符在文本中出现的实际频次分布，对高频字符赋予短位码、对低频字符赋予长位码以极致压缩整体存储体积的编码机制。

    * 标准 ASCII 码采用 8 位固定等长编码，存储 $M$ 个字符恒定占用 $8M$ 位；7 种字符采用等长编码需 3 位（$2^3 \ge 7$）；而不等长编码可突破等长编码下界。

    * 程序决策中的判定树同样依赖频率加权优化：以百分制转五分制为例，高频成绩区间（如 70~89 分占比 70%）优先切分可使加权平均比较次数由朴素判定的 3.15 次下降至 2.22 次。

* **带权路径长度（Weighted Path Length，WPL）**

    * > **定义**：二叉树中所有叶节点的权值与其到根节点路径长度（边数）乘积的总和。

    * 计算公式为：
    $$WPL = \sum_{k=1}^n W_k \cdot L_k$$
    其中 $n$ 为叶节点总数，$W_k$ 为第 $k$ 个叶节点的权值（如字符频次），$L_k$ 为根节点到该叶节点的分支边数。

* **哈夫曼树（Huffman Tree，最优二叉树）**

    * > **定义**：在包含 $n$ 个具有给定权值的叶节点的二叉树中，带权路径长度 $WPL$ 达到严格最小值的二叉树。

### 哈夫曼树的贪心构造与拓扑性质

* **哈夫曼贪心构造算法（Huffman Greedy Construction Algorithm）**

    * > **定义**：每次从候选二叉树森林中挑选根节点权值最小的两棵树合并生成新树，反复迭代直到仅剩一棵树的最优树构造算法。

    * 算法步骤：将 $n$ 个带权节点视作孤立的单节点二叉树森林；利用最小堆（Min Heap）组织树根；循环 $n - 1$ 次，每轮从最小堆中连续弹出两个权值最小的树根 $T_{left}$ 与 $T_{right}$，动态创建一个新父节点 $T$（其权值为左右孩子权值之和），将 $T$ 重新插入最小堆；$n - 1$ 轮后堆中仅剩的树根即为哈夫曼树。

    * 初始建堆开销为 $O(n)$，随后执行 $n - 1$ 轮迭代，每轮包含两次堆删除与一次堆插入（耗时 $O(\log n)$），算法总体时间复杂度为 $O(n \log n)$。

* **哈夫曼树的四大拓扑性质（Topological Properties of Huffman Tree）**

    * > **定义**：哈夫曼树在两两合并构造机制下必然呈现的结构定理与数学推论。

    * 性质一：严格不存在度为 1 的节点（$n_1 \equiv 0$），每个节点要么是叶节点（度为 0），要么是分支节点（度为 2）。

    * 性质二：包含 $n$ 个叶节点的哈夫曼树总结点数严格等于 $2n - 1$。由非空二叉树恒等式 $n_2 = n_0 - 1$ 及 $n_1 = 0$ 推导：
    $$N = n_0 + n_1 + n_2 = n + 0 + (n - 1) = 2n - 1$$

    * 性质三：任意分支节点的左右子树对称镜像互换后，各叶节点深度 $L_k$ 保持不变，整树依然是合格的哈夫曼树。

    * 性质四：权值集合中存在相同数值时，贪心合并的分支选择可能产生不同构的树形拓扑，但最终计算得到的全局最优带权路径长度 $WPL$ 严格唯一。

### 前缀码与哈夫曼编码

* **前缀码（Prefix Code）**

    * > **定义**：在编码字符集中，没有任何一个字符的二进制编码是另一个字符编码的前缀的编码体制。

    * 前缀码是不等长编码在解码端实现单向无歧义、即时唯一可译的充要条件。

    * 若缺乏前缀约束，如分配 `a: 1`、`s: 10`、`t: 11`，接收到流 `1011` 时可产生 `a e a a`、`a e t`、`s t` 等多重二义性切分崩溃。

* **二叉树叶节点与哈夫曼编码映射（Leaf Node Mapping to Huffman Coding）**

    * > **定义**：将待编码字符完全安置于二叉树的叶节点上，以根到叶的走向（左分支 0、右分支 1）天然生成无歧义前缀码的机制。

    * 任何叶节点均不可能处于通向另一叶节点的分支路径上，从几何拓扑层面彻底杜绝了前缀重叠二义性。

    * 字符编码长度等于叶节点深度 $L_k$，文本总二进制传输位数 $\sum (W_k \times L_k)$ 严格等价于树的带权路径长度 $WPL$。

    * 58 字符文本实例（7 种字符：`i: 12` 码长 2、`_: 13` 码长 2、`e: 15` 码长 2、`a: 10` 码长 3、`t: 4` 码长 4、`\n: 1` 码长 5、`s: 3` 码长 5），总编码代价为 146 位；相比 ASCII 码（464 位）节省近 70%，相比等长编码（174 位）进一步压缩 16%。

## 哈夫曼编码方案验证

### 最优编码总长度递归计算

* **带权路径长度递归算法（Recursive WPL Calculation）**

    * > **定义**：利用先序遍历在递归过程中向下传递并递增节点深度，到达叶节点时计算权深乘积并累加子树的算法。

    * 算法步骤：从根节点启动调用 `WPL(T, 0)`；若当前节点为叶节点（左右孩子皆空），递归基返回 `Depth * T->Weight`；若为分支节点（哈夫曼树中必有左右两孩子），返回 `WPL(T->Left, Depth + 1) + WPL(T->Right, Depth + 1)` 之和。

    * 该递归函数返回值即为校验待测方案所需的唯一绝对权威基准 $WPL$。

### 前缀码冲突排查与合法性判定

* **单字符最大编码长度界限（Upper Bound of Single Code Length）**

    * > **定义**：包含 $N$ 个字符的合法前缀码体系中，单个字符允许出现的最大二进制编码长度上限。

    * 在最极端非均匀单链退化拓扑下，哈夫曼树拥有 $N-1$ 个内部节点，最深叶节点所处的最大深度严格为 $N-1$。

    * 任何字符编码字符串长度若达到或超过 $N$（即大于 $N-1$），可直接判定该方案非法。

* **前缀树动态检测与两类冲突场景（Prefix Tree Collision Detection）**

    * > **定义**：按照待测 01 编码串动态构建二叉前缀树（Trie），在遍历与落位过程中实时排查前缀重叠歧义的校验算法。

    * 建树机制：从根节点出发逐位扫描 01 串，遇 0 向左、遇 1 向右，孩子为空则动态分配空节点深入；扫描结束落脚时将字符权重写入节点。

    * 场景一（包含已有前缀）：向下遍历途中，遇到了某个早已打上权重标记的终止叶节点。表明已存在的短码是当前长码的前缀，触发冲突。

    * 场景二（成为已有编码的前缀）：扫描结束落脚于当前节点，但发现该节点已经具备左分支或右分支（非叶节点）。表明当前短码是先前已录入长码的前缀，触发冲突。

    * 合法性裁定准则：必须同时满足（1）所有字符编码总长度累加和严格等于标准 $WPL$；（2）前缀树建树全程零场景一与场景二冲突，每个编码字符均独立落位为崭新叶节点。

    * > **易错点**：⚠️ 在逐行读取待测字符与编码时，若在检查长度（如超过 $N-1$）或建树初期便判定非法，程序绝对不可执行提前跳出；必须坚持将该方案名下剩余的所有字符和编码完整读入，否则输入缓冲区残留数据将导致后续测试用例全盘错位。

## 单源最短路径算法

### 最短路径问题形式化抽象

* **最短路径（Shortest Path）**

    * > **定义**：带权图中两顶点之间所有通路中，边的权值之和最小的路径。

    * 路径起始顶点称为源点（Source），终末顶点称为终点（Destination）。

    * 问题范式划分为单源最短路径（源点唯一固定）与多源最短路径（任意两顶点间最短路）。

    * 现实抽象对应：物理里程最短对应实际路程边权；出行票价最省对应费用边权；经停站点最少对应无权图（所有边权均设为 1）。

* **权值扰动与负值圈陷阱（Weight Perturbation and Negative Cost Cycle）**

    * > **定义**：在有权图中，经过顶点数最少的路径不一定是最短路径；若图中存在环路权值和为负的回路，将导致最短路径无解。

    * 步数与权值脱钩机理：直达边权为 9（1 步），绕行两边权分别为 1、4、1（总权 6，3 步），步数较多者总权更小，简单 BFS 失效。

    * 负值圈导致算法崩溃机理：绕行负值圈每转一圈总权值单调递减，无限循环导致路径权值趋向 $-\infty$，最短路丧失数学定义。经典单源最短路径算法严格限定在图中不存在负值圈且边权均为非负的前提下。

### 无权图单源最短路径

* **无权图单源最短路径算法（Unweighted Single-Source Shortest Path）**

    * > **定义**：以广度优先搜索（BFS）为核心骨架，按照到源点距离递增（非递减）次序逐层向外扩散收录顶点的算法。

    * 距离数组 `dist[w]`：初始化源点为 0（`dist[s] = 0`），其余所有顶点置为 `-1`。`-1` 兼具未被访问的判定功能，免除独立 `visited` 数组。

    * 路径回溯数组 `path[w]`：记录顶点 $w$ 在最短路径上的直接前驱顶点编号，全图初始化为 `-1`。收录时更新 `path[w] = v`。

    * 路径重构机制：从目标终点出发，沿着 `path` 数组向前逆向追溯前驱顶点，将顶点依次压入堆栈（Stack）；追溯至源点后连续执行出栈打印，输出正向最短路径。

    * 时间复杂度：每个顶点进出队列各一次（$2|V|$ 次），每条边在出队扫描邻接点时被检查一次；邻接表存储下时间复杂度严格为线性阶 $O(|V| + |E|)$。

### 有权图单源最短路径与 Dijkstra 算法

* **Dijkstra 算法（Dijkstra's Algorithm）**

    * > **定义**：在非负边权图中，维持已被确立全局最短路径的顶点集合 $S$，按距离非递减次序贪心收录顶点并松弛其邻接点的单源最短路径算法。

    * 未收录顶点定义：对于不在集合 $S$ 中的顶点 $v$，$dist[v]$ 定义为从源点出发、且沿途经停的所有中间顶点完全属于集合 $S$ 的当前最短路径长度。

    * 贪心策略反证法证明：假设未收录顶点中 $dist$ 最小的 $v$ 不是全局最短路，则必存在借道 $S$ 外部节点 $w$ 的更优路径 $s \to \dots \to w \to \dots \to v$；由于边权非负，该绕行路径长度 $\ge dist[w]$；而依据挑选准则 $dist[w] \ge dist[v]$，必然得出绕行路径长度 $\ge dist[v]$，与更优假设矛盾；故贪心挑选出的未收录最小 $dist[v]$ 必已是全局终极最短路径。

    * 邻接点松弛操作（Relaxation）：收录顶点 $v$ 进集合 $S$ 后，考察其直接邻接点 $w$；若满足 $dist[v] + \text{Weight}(v, w) < dist[w]$，则更新 $dist[w] = dist[v] + \text{Weight}(v, w)$ 并令 $path[w] = v$。

    * 初始化规则：源点 `dist[s] = 0`；与源点直连的顶点初始化为直连边权；其余顶点必须初始化为正无穷大（$+\infty$）。

    * > **易错点**：⚠️ 在 Dijkstra 算法中，与源点非直连顶点的初始 $dist$ 绝不可沿用无权图设为 `-1`！松弛判断基于不等式 `dist[v] + Weight < dist[w]`，若 $dist[w] = -1$，正权累加和恒大于负数，松弛更新将永远无法触发导致算法彻底失效。

| :--- | :--- | :--- |
| **单次查找最小顶点** | $O(|V|)$ | $O(\log |V|)$ |
| **单次松弛后更新** | $O(1)$（直接数组赋值） | $O(\log |V|)$（堆上滤调整） |
| **总体时间复杂度** | $O(|V|^2)$ | $O(|E| \log |V|)$ |
