# 树形结构基础与二叉树遍历

## 树与二叉树的表示与基本形态

### 一般树的存储与儿子兄弟表示法

* **一般树表示法（Tree Representation）**

    * > **定义**：在计算机内存中组织多分支层级关系的数据结构实现方案。

    * 一维数组朴素存储困境：数组为线性结构，一般树各节点分支数量高度不确定，单纯线性排列无法直接映射节点的父子从属关系。

    * 动态多指针链表困境：为每个节点按其实际子节点数分配指针域，导致每个节点的结构体类型各异，通用的内存分配、节点遍历与算法编写异常复杂。

    * 定长指针方案与空间浪费：按整棵树的最大分支度统一节点指针域数量。若树包含 $n$ 个节点且每个节点固定分配 $k$ 个指针域，指针域总数为 $kn$ 个；因 $n$ 个节点的树仅有 $n-1$ 条边，有效非空指针数恰好为 $n-1$ 个，空指针数量为：
        $$kn - (n - 1) = (k - 1)n + 1$$
        当最大分支度 $k = 3$ 时，空指针数量为 $2n + 1$，超过三分之二的指针空间被白白浪费。

* **儿子兄弟表示法（First Child - Next Sibling）**

    * > **定义**：树中所有节点结构体完全统一，且每个节点仅包含长子指针与下一个兄弟指针的双指针链式表示法。

    * 统一节点结构：包含数据域 `Data`、指向第一个子节点（长子）的指针 `FirstChild`、指向右侧相邻兄弟节点的指针 `NextSibling`。

    * 空间利用率：$n$ 个节点的树包含 $2n$ 个指针域，有效非空指针为 $n-1$ 个，空指针数量仅为：
        $$2n - (n - 1) = n + 1$$
        空指针占比大幅降低，且彻底消除了结构不一致带来的程序实现障碍。

    * 二叉树转换机理：将儿子兄弟表示法的拓扑结构顺时针旋转 45 度，垂直向下的 `FirstChild` 转化为向左下的左指针，水平向右的 `NextSibling` 转化为向右下的右指针，普通多叉树完全无损变形为标准二叉树。

### 二叉树的概念与特殊形态

* **二叉树（Binary Tree）**

    * > **定义**：由一个根节点以及两棵互不相交的、分别称为根节点的左子树和右子树的二叉树组成的有限节点集合。

    * 五种基本形态：空树、只有根节点、只有左子树、只有右子树、左右子树均非空。

    * > ⚠️ **易错点**：二叉树与度不超过 2 的树存在本质区别。普通度为 2 的树其子树无左右之分；二叉树的子树具有严格的左右次序，即使节点只有一个子节点也必须明确是左孩子还是右孩子，仅有左儿子的树与仅有右儿子的树属于两棵完全不同的二叉树。

* **特殊二叉树形态（Special Binary Trees）**

    * > **定义**：在形态分布或节点拓扑上具备特殊规整性或极端单向倾斜的二叉树构型。

    * 斜二叉树（Skewed Binary Tree）：所有节点均只有左子树（左斜二叉树）或均只有右子树（右斜二叉树），结构完全退化为单向线性链表，树的分治与对数级查找优势完全丧失。

    * 满二叉树（Full Binary Tree，完美二叉树 Perfect Binary Tree）：所有非叶节点的度均为 2，且所有叶节点均排在同一层最底层的二叉树，几何形态高度对称，每一层节点数均达到该层容纳上限。

    * 完全二叉树（Complete Binary Tree，CBT）：深度为 $k$、节点数为 $n$ 的二叉树，其所有节点的位置和编号与深度为 $k$ 的满二叉树从上到下、从左到右编号 $1 \sim n$ 的节点完全一一对应。

    * 完全二叉树判定规则：仅允许在最后一层（最底层）最右侧连续缺失节点；倒数第二层及以上为满二叉树，最后一层叶节点必须自左向右紧密靠拢排列，中间严禁出现空隙。

## 二叉树的核心性质与存储结构

### 二叉树的数学性质与定理

* **节点容量极值性质（Capacity Properties）**

    * > **定义**：基于二叉分支结构在特定层次与特定深度下推导出的节点容纳峰值规律。

    * 层次容量极值：在二叉树的第 $i$ 层上（根节点所在层次为第 1 层），最多容纳的节点数为：
        $$2^{i-1} \quad (i \ge 1)$$

    * 深度总结点容量极值：深度为 $k$ 的二叉树最大总结点数为等比数列求和结果：
        $$\sum_{i=1}^k 2^{i-1} = 2^k - 1 \quad (k \ge 1)$$
        该极值仅在满二叉树构型下达到。

* **叶节点与双分支节点关系定理（Leaf and Degree-2 Node Theorem）**

    * > **定义**：对任何非空二叉树，度为 0 的叶节点总数 $n_0$ 恒等于度为 2 的双分支节点总数 $n_2$ 加 1，即 $n_0 = n_2 + 1$。

    * 节点全集划分：二叉树总结点数 $N$ 严格划分为叶节点 $n_0$、单分支节点 $n_1$ 与双分支节点 $n_2$ 之和，即：
        $$N = n_0 + n_1 + n_2$$

    * 双向统计法证明（Double Counting）：
        * 自下向上统计：除根节点外每个节点上方均有且仅有一条指向父节点的边，边总数 $E = N - 1 = n_0 + n_1 + n_2 - 1$。
        * 自上向下统计：$n_0$ 节点向下贡献 0 条边，$n_1$ 节点向下贡献 1 条边，$n_2$ 节点向下贡献 2 条边，边总数 $E = n_1 + 2n_2$。
        * 等式联立消元：令 $n_0 + n_1 + n_2 - 1 = n_1 + 2n_2$，两边消去公共项 $n_1$ 并整理移项，即得 $n_0 = n_2 + 1$。

### 顺序存储与链式存储

* **完全二叉树顺序存储（Sequential Storage）**

    * > **定义**：将完全二叉树节点按层序编号直接连续存储于一维数组单元的物理表示方案。

    * 数组槽位映射：数组下标 0 空出不用，完全二叉树编号 $1 \sim n$ 与数组下标 $1 \sim n$ 严格对应绑定，下标 1 为根节点。

    * 下标算术计算法则（对数组中任意下标为 $i$ 的非根节点，$1 \le i \le n$）：
        * 父节点下标：位于 $\lfloor i / 2 \rfloor$（即 $i$ 整除 2）。
        * 左儿子下标：位于 $2i$；若 $2i \le n$ 则左儿子有效，若 $2i > n$ 则该节点无左儿子。
        * 右儿子下标：位于 $2i + 1$；若 $2i + 1 \le n$ 则右儿子有效，若 $2i + 1 > n$ 则该节点无右儿子。

    * 存储特性评估：完全二叉树顺序存储借助算术乘除运算取代指针跳转，寻址时间为 $O(1)$ 且空间零浪费。

    * 一般二叉树顺序存储代价：一般二叉树必须强制对齐补齐为空位以模拟完全二叉树；深度为 $k$ 的右斜二叉树仅包含 $k$ 个实际节点，却需开辟 $2^k - 1$ 大小的数组空间，造成严重存储膨胀。

* **二叉链表（Binary Linked List）**

    * > **定义**：每个节点由数据域及分别指向左子树和右子树根节点的两个指针域构成的动态链式存储结构。

    * 节点结构声明：
        ```c
        typedef struct TreeNode *BinTree;
        typedef BinTree Position;
        struct TreeNode {
            ElementType Data;
            BinTree Left;
            BinTree Right;
        };
        ```

    * 空子树表示：当节点不存在左子树或右子树时，对应 `Left` 或 `Right` 指针赋值为 `NULL`。

## 二叉树的遍历算法与控制流机制

### 递归遍历与外围巡回路径

* **深度优先递归遍历（Depth-First Recursive Traversal）**

    * > **定义**：基于二叉树递归定义，按照对根节点、左子树和右子树不同的访问时序遍历整棵树的算法。

    * 先序遍历（Pre-order）：访问次序为根节点 $\to$ 左子树 $\to$ 右子树；根节点在子树遍历之前输出。

    * 中序遍历（In-order）：访问次序为左子树 $\to$ 根节点 $\to$ 右子树；根节点在左右子树之间输出。

    * 后序遍历（Post-order）：访问次序为左子树 $\to$ 右子树 $\to$ 根节点；根节点在左右子树处理完毕后输出。

* **外围巡回路径与三次相遇机理（Perimeter Tour and Three Encounters）**

    * > **定义**：递归遍历中程序控制流沿二叉树外围轮廓单向巡回一周、对每个节点恰好相遇三次的底层运行模型。

    * 物理路径唯一性：先序、中序、后序递归程序在树上走过的实际执行轨迹完全相同。

    * 三次相遇时机：
        * 第一次相遇：刚从父节点进入当前节点、准备深入其左子树时。
        * 第二次相遇：遍历完左子树回到当前节点、准备深入其右子树时。
        * 第三次相遇：遍历完右子树再度回到当前节点、准备向上回退脱离时。

    * 遍历本质映射：先序在第一次相遇时采样输出，中序在第二次相遇时采样输出，后序在第三次相遇时采样输出。

### 基于堆栈的非递归遍历

* **中序非递归遍历（Iterative In-order Traversal）**

    * > **定义**：利用显式堆栈（LIFO）暂存回溯节点，通过循环推进消除函数调用栈的中序遍历算法。

    * 算法状态机流程：
        * 沿左分支一路向深处推进，沿途所有节点依次压入堆栈，直到指针为 `NULL`；
        * 从栈顶弹出一个节点，此操作对应第二次相遇时刻，立即输出该节点数据；
        * 控制指针转向该节点的右子树，开启新一轮左路探寻；
        * 外循环维持条件为控制指针非空或堆栈非空。

    * 核心代码实现：
        ```c
        void InOrderTraversal(BinTree BT) {
            BinTree T = BT;
            Stack S = CreateStack(MaxSize);
            while (T || !IsEmpty(S)) {
                while (T) {
                    Push(S, T);
                    T = T->Left;
                }
                if (!IsEmpty(S)) {
                    T = Pop(S);
                    printf("%c ", T->Data);
                    T = T->Right;
                }
            }
        }
        ```

* **先序与后序非递归遍历扩展（Iterative Pre-order and Post-order Extensions）**

    * > **定义**：依据相遇时刻调整出入栈与访问动作的非递归遍历变体。

    * 先序非递归转换：无需改动控制流框架，仅将输出语句移动至内循环压栈操作 `Push(S, T)` 之前，即在第一次相遇时刻完成输出。

    * 后序非递归机理：节点必须在第三次相遇（右子树处理完毕）后才能出栈输出，需设置访问标志位或记录最近访问的历史节点，以严格区分当前是由左子树返回还是由右子树返回。

### 基于队列的层序遍历与降维

* **结构降维与缓存哲学（Dimensionality Reduction and Buffering）**

    * > **定义**：将二叉树二维分支结构降维压缩为一维线性序列时对未访问分支的缓冲暂存机制。

    * 线性化核心矛盾：计算机沿指针进入某一分支时，若不保存当前节点或另一分支指针，深层处理后对侧分支指针将丢失且不可回溯。

    * 缓存容器对比：
        * 堆栈（Stack）：后进先出（LIFO），沿纵深穿透回溯，支撑深度优先遍历（先序、中序、后序）。
        * 队列（Queue）：先进先出（FIFO），按发现次序逐层平推，支撑广度优先的层序遍历。

* **层序遍历（Level-order Traversal）**

    * > **定义**：严格按照二叉树物理层级，自上而下、每层自左向右依次扫描输出节点的广度优先遍历算法。

    * 算法执行步骤：
        * 初始化将根节点指针压入队列；
        * 循环判断队列非空：取出队头节点 $T$ 并访问其数据域；
        * 若 $T$ 的左儿子非空，将左儿子指针入队；若 $T$ 的右儿子非空，将右儿子指针入队；
        * 队列全部排空时遍历终止。

    * 核心代码实现：
        ```c
        void LevelOrderTraversal(BinTree BT) {
            Queue Q;
            BinTree T;
            if (!BT) return;
            Q = CreateQueue(MaxSize);
            AddQ(Q, BT);
            while (!IsEmptyQ(Q)) {
                T = DeleteQ(Q);
                printf("%c ", T->Data);
                if (T->Left)  AddQ(Q, T->Left);
                if (T->Right) AddQ(Q, T->Right);
            }
        }
        ```

## 二叉树遍历的应用与树的同构

### 遍历框架的典型应用扩展

* **输出叶子节点与递归求树高（Print Leaves and Tree Height）**

    * > **定义**：在遍历递归骨架上嵌入特定业务逻辑以解决属性统计与特征提取的算法。

    * 输出叶子节点：遍历骨架中仅在当前节点左右儿子均为空（`!BT->Left && !BT->Right`）时执行打印，先序、中序、后序遍历均可达成，区别仅在输出次序。

    * 递归求解树高：后序遍历自底向上求解，整树高度满足递推关系：
        $$Height = \max(Height_L, Height_R) + 1$$
        空树高度定义为 0。时序上必须先获取左右子树高度再汇聚计算根节点高度，天然契合后序遍历。

* **二元运算表达式树（Expression Tree）**

    * > **定义**：叶节点表示运算操作数、非叶节点表示运算操作符的二叉树。

    * 遍历映射关系：先序遍历生成前缀表达式（波兰式），后序遍历生成后缀表达式（逆波兰式），中序遍历生成中缀表达式。

    * > ⚠️ **易错点**：直接对表达式树进行朴素中序遍历展开会导致运算顺序失真。表达式树通过层级深度天然锁定优先级（深层优先运算）；中缀遍历展开后运算符号易受常规加减乘除结合律误读，必须在递归遍历左右子树时成对输出括号 `(` 和 `)`。

### 遍历序列唯一重构二叉树

* **遍历序列重构定理（Tree Reconstruction Theorem）**

    * > **定义**：依据两种遍历序列反求并唯一重构二叉树拓扑结构的判定准则。

    * 判定充要条件：已知两个遍历序列要唯一确定一棵二叉树，**两序列中必须包含中序遍历序列**（先序+中序，或后序+中序）。

    * 先序与后序无法唯一确定的根源：先序首元素与后序尾元素仅能确定整树根节点，序列剩余子树边界无法厘清。例如先序 `A, B` 且后序 `B, A` 时，`B` 既可作为 `A` 的左儿子，也可作为 `A` 的右儿子，拓扑结构不唯一。

* **中序重构推演步骤（In-order Reconstruction Procedure）**

    * > **定义**：利用根节点在中序序列中的分割特性自顶向下递归构建左右子树的方法。

    * 步骤一（定位根节点）：从先序序列首元素（或后序序列尾元素）直接获取当前子树根节点。

    * 步骤二（划分中序左右子树）：在中序序列中检索根节点，根节点左侧所有元素严格属于左子树中序序列，右侧所有元素严格属于右子树中序序列。

    * 步骤三（划分先序左右子树）：统计左子树中序序列长度 $k$，在先序序列中根节点之后连续截取 $k$ 个元素作为左子树先序序列，先序序列剩余元素为右子树先序序列。

    * 步骤四（递归缩减规模）：左、右子树分别获得独立的先序与中序序列，递归执行上述三步直至整树构建完成。

### 树的同构判别与静态链表

* **二叉树同构（Tree Isomorphism）**

    * > **定义**：两棵二叉树若可通过若干次交换任意节点的左右子树使其拓扑结构与节点标签完全吻合，则判定两树同构。

* **结构数组静态链表（Static Linked List）**

    * > **定义**：在物理连续的一维结构数组中使用整型下标代替指针构建树形拓扑的存储结构。

    * 结构声明：
        ```c
        #define MaxTree 10
        #define ElementType char
        #define Tree int
        #define Null -1

        struct TreeNode {
            ElementType Element;
            Tree Left;
            Tree Right;
        } T1[MaxTree], T2[MaxTree];
        ```

    * > ⚠️ **易错点**：定义静态链表时严禁使用 C 语言标准宏 `NULL`（其值通常为 0）。数组下标 0 代表数组首个有效存储单元，用 0 表示空会导致空指针与 0 号节点产生严重歧义；必须显式定义宏 `#define Null -1` 表示无子节点。

* **入度排查法寻找树根（Root Finding by Indegree Check）**

    * > **定义**：基于树中除根节点外所有节点入度均为 1（被某节点的左右指针指向）、唯独根节点入度为 0 的图论特征定位树根的算法。

    * 算法实现：
        * 初始化长度为 $N$ 的整型排查数组 `check` 全为 0；
        * 读入每行数据时，若左儿子下标非空，置 `check[Left] = 1`；若右儿子下标非空，置 `check[Right] = 1`；
        * 读入完毕后扫描 `check` 数组，值仍为 0 的单元下标即为整棵树的根节点。

* **同构判别递归算法（Recursive Isomorphism Checking）**

    * > **定义**：比对当前子树根节点 $R_1$ 与 $R_2$ 的递归分类决策机制。

    * 判别分支逻辑：
        * 两树皆为空树：同构，返回 1；
        * 一树为空另一树非空：不同构，返回 0；
        * 两根节点元素不相同：不同构，返回 0；
        * 左子树皆为空：递归比对右子树 `Isomorphic(T1[R1].Right, T2[R2].Right)`；
        * 左子树皆非空且元素相同：未发生翻转，递归比对 `Isomorphic(T1[R1].Left, T2[R2].Left) && Isomorphic(T1[R1].Right, T2[R2].Right)`；
        * 其余情况（左子树元素相异或单一缺失）：发生左右对调，交叉递归比对 `Isomorphic(T1[R1].Left, T2[R2].Right) && Isomorphic(T1[R1].Right, T2[R2].Left)`。

## 二叉搜索树的原理与操作实现

### 二叉搜索树的定义与查找

* **二叉搜索树（Binary Search Tree，BST）**

    * > **定义**：或者是一棵空树，或者是满足非空左子树所有键值均小于根节点键值、非空右子树所有键值均大于根节点键值，且左、右子树本身均为二叉搜索树的非空二叉树。

    * 演进动因：解决静态二分查找在动态增删场景下数据搬移开销高达 $O(N)$ 的缺陷，兼具链式结构快速增删与对数级查找能力。

    * > ⚠️ **易错点**：BST 键值偏序性质必须覆盖左、右子树内的全部节点，而非仅仅约束当前节点的直接左、右孩子。

    * 查找时间复杂度：取决于树的高度 $H$。平衡形态下树高为 $O(\log N)$；若输入键值单调递增或递减，树将严重倾斜退化为单向链表，树高膨胀为 $N-1$，查找复杂度恶化为 $O(N)$。

* **二叉搜索树查找与极值操作（BST Search and Extremum Operations）**

    * > **定义**：利用键值有序性沿单一路径向下比较检索目标键值或极值节点的算法。

    * 键值查找（`Find`）：待查值小于当前节点数据则向左子树查找，大于当前节点数据则向右子树查找，相等则查找命中并返回当前节点指针。

    * 尾递归循环优化（`IterFind`）：查找操作处于分支末端为尾递归，可直接转换为 `while` 循环，消除函数调用栈开销，将辅助空间复杂度压缩至 $O(1)$。

    * 最小值查找（`FindMin`）：由左小右大性质，全局最小值必定位于整棵树的最左端；从根节点出发沿 `Left` 指针一路向左探底，左孩子为空的节点即为最小值。

    * 最大值查找（`FindMax`）：全局最大值必定位于整棵树的最右端；从根节点出发沿 `Right` 指针一路向右探底，右孩子为空的节点即为最大值。

### 二叉搜索树的插入与删除

* **节点插入操作（BST Insert）**

    * > **定义**：在维持 BST 全局键值有序性的前提下，将新节点挂接到正确叶端空位的递归算法。

    * 递归指针挂接范式：函数设计返回插入新节点后子树的根节点指针（`BST->Left = Insert(BST->Left, X)`）；递归探寻至空指针落脚点时动态开辟新节点并返回，上层节点直接用指针域接收完成挂接；若键值已存在则不重复插入。

    * 字典序插入规则：对字符串类数据建立 BST 时，依据英文字典序逐字符比对以决定分支走向。

    * 核心代码实现：
        ```c
        BinTree Insert(BinTree BST, ElementType X) {
            if (!BST) {
                BST = (BinTree)malloc(sizeof(struct TreeNode));
                BST->Data = X;
                BST->Left = BST->Right = NULL;
            } else {
                if (X < BST->Data)
                    BST->Left = Insert(BST->Left, X);
                else if (X > BST->Data)
                    BST->Right = Insert(BST->Right, X);
            }
            return BST;
        }
        ```

* **节点删除操作（BST Delete）**

    * > **定义**：定位并移除指定键值节点，同时重组子树指针以维持 BST 特性的算法。

    * 情形一（被删节点为叶节点）：直接释放该节点内存，父节点指向其的指针赋值置空。

    * 情形二（被删节点只有一个儿子）：父节点指针直接越过当前节点连接到其唯一子节点，随后释放当前节点。

    * 情形三（被删节点有两个儿子）：采用替身替换法化繁为简：
        * 选取左子树最大值（`FindMax(BST->Left)`）或右子树最小值（`FindMin(BST->Right)`）作为替身；
        * 将替身节点数据拷贝覆盖至当前节点；
        * 递归在对应子树中删除该替身节点。

    * 替身转化机理：左子树最大值必无右儿子，右子树最小值必无左儿子；替身节点至多只有一个儿子，后续删除必然完美退化为情形一或情形二。

    * 统合实现逻辑：利用 `!BST->Left` 分支可同时兼容情形二（仅有右儿子）与情形一（叶节点，此时右儿子亦为空指针），结合 `free` 释放内存，实现两行逻辑通解单孩子与叶节点删除。

    * 核心代码实现：
        ```c
        BinTree Delete(BinTree BST, ElementType X) {
            Position Tmp;
            if (!BST) {
                printf("要删除的元素未找到\n");
            } else if (X < BST->Data) {
                BST->Left = Delete(BST->Left, X);
            } else if (X > BST->Data) {
                BST->Right = Delete(BST->Right, X);
            } else {
                if (BST->Left && BST->Right) {
                    Tmp = FindMin(BST->Right);
                    BST->Data = Tmp->Data;
                    BST->Right = Delete(BST->Right, BST->Data);
                } else {
                    Tmp = BST;
                    if (!BST->Left)
                        BST = BST->Right;
                    else if (!BST->Right)
                        BST = BST->Left;
                    free(Tmp);
                }
            }
            return BST;
        }
        ```
