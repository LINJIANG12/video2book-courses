# 散列查找与冲突解决工程实战

## 散列基本概念与机制对比

### 散列冲突与解决范式

* **散列冲突（Hash Collision）**

    * > **定义**：不同的关键字经散列函数映射后计算出完全相同的数组槽位下标的现象。

    * 触发前提：关键字集合空间规模显著大于散列表物理槽位容量。

    * 解决范式：分为开放地址法与分离链接法两大类别；前者坚持在散列表数组内部寻址空槽，后者在槽位外挂接单向链表。

* **开放地址法（Open Addressing）**

    * > **定义**：所有关键字均存放在连续物理数组槽位内、冲突时依据预设增量序列在数组中寻找替代空槽的冲突解决机制。

    * 槽位寻址模型：寻址计算公式为 $Pos_i = (H(key) + d_i) \bmod TableSize$。

    * 增量序列分类：线性探测法取 $d_i = i$；平方探测法取 $d_i = \pm i^2$；双散列探测法取 $d_i = i \times H_2(key)$。

    * 适用边界：装填因子 $\alpha$ 必须严格小于 1，工程建议控制在 $\alpha \le 0.5 \sim 0.85$ 区间。

* **分离链接法（Separate Chaining）**

    * > **定义**：散列表主体为指针数组，每个槽位指向一条存放所有同义词关键字节点的单向链表的冲突解决机制。

    * 内存组织：数据实体存储于动态申请的链表节点堆内存中，数组槽位仅保存链表表头指针。

    * 适用边界：装填因子 $\alpha$ 弹性允许大于等于 1，超载时平均查找代价仅随链表长度线性温和增长。

### 散列查找与树形查找特性对比

* **散列查找（Hash Search）**

    * > **定义**：通过散列函数直接计算关键字物理存储地址以实现常数级定位的查找技术。

    * 核心机理：基于函数**计算**实现直接寻址，以空间冗余降低装填因子以换取时间效率。

    * 时间复杂度：冲突控制在低位时平均查找时间复杂度为 $O(1)$，查询代价与数据规模 $N$ 解耦。

    * 适用场景：Web 搜索引擎关键词索引、网络 URL 快速映射、编译器标识符符号表管理等大规模长字符串查询。

    * 固有局限：散列函数打乱了数据的原始代数偏序关系，无法支持范围查找与极值（最大值、最小值）查询。

* **树形查找（Tree Search）**

    * > **定义**：基于关键字之间的大小关系反复进行代数比较以决定子树分支走向的查找技术。

    * 核心机理：基于关键字**比较**确定搜索路径分支。

    * 时间复杂度：平衡二叉树与二叉搜索树查找时间复杂度与数据规模 $N$ 严格绑定，为 $O(\log N)$。

    * 适用场景：天然支持动态前驱后继判定、快速极值定位以及范围连续遍历检索。

    * 固有局限：处理冗长字符串关键字时，遍历路径上的各节点均需执行多次开销巨大的逐字符比较。

* **散列查找与树形查找机制对比**

| 评估维度 | 散列查找（Hash Search） | 树形查找（Tree Search） |
| :--- | :--- | :--- |
| **底层核心机理** | 基于散列函数直接**计算**物理地址 | 基于关键字代数大小**比较**确定分支路径 |
| **平均时间复杂度** | $O(1)$（与数据规模 $N$ 解耦） | $O(\log N)$（与数据规模 $N$ 紧密绑定） |
| **空间开销策略** | 空间换时间，需保留冗余槽位维持低装填因子 | 空间利用紧凑，额外开销为树节点指针域 |
| **范围与极值查询** | 不支持，必须执行全表暴力扫描 | 天然支持快速范围遍历与最大最小值检索 |
| **长字符串处理性能** | 极高，一次转换为整型散列值后常数级命中 | 较低，遍历路径上各节点均需执行多次字符串比较 |

## 开放寻址冲突探测

### 线性探测

* **线性探测法（Linear Probing）**

    * > **定义**：发生冲突时以单步递增的顺序在散列表中逐一试探紧邻槽位的开放寻址策略。

    * 增量序列：$d_i = i \quad (i = 1, 2, 3, \dots, TableSize - 1)$。

    * 探测公式：$Pos_i = (H(key) + i) \bmod TableSize$。

    * 回卷规则：当试探地址达到表尾时，通过取模运算绕回散列表头部槽位 0 继续向后试探。

    * 终止条件：探测命中关键字则查找成功；探测遇到从未写入的空槽（`Empty`）则判定关键字不存在并终止查找。

* **聚集现象（Primary Clustering）**

    * > **定义**：散列地址相近的关键字在连续物理槽位上堆积蔓延成连续占用块，导致后续新元素无论散列到该块内何处都必须遍历整个块的恶性连锁反应。

    * 产生机理：增量步长 $d_i = i$ 空间跨度极小且均匀，连续占用块的前缘与内部不断吸收新冲突元素。

    * 危害：导致后续插入与查找的冲突探测次数呈现指数级上升，严重恶化平均查找长度。

### 平方探测

* **平方探测法（Quadratic Probing，QP）**

    * > **定义**：以探测步数的多项式二次方作为增量序列在散列表中前后跳跃试探空槽的开放寻址策略。

    * 增量序列：$d_i = \pm i^2 \quad (i = 1, 2, 3, \dots)$，展开为 $+1, -1, +4, -4, +9, -9, \dots$。

    * 探测公式：奇数次探测为 $(H(key) + i^2) \bmod TableSize$；偶数次探测为 $(H(key) - i^2) \bmod TableSize$。

    * 优化效益：前后跳跃打散连续分布，彻底消除线性探测的一级聚集现象。

* **平方探测遍历保障定理（Quadratic Probing Guarantee Theorem）**

    * > **定义**：保证双向平方探测序列能够遍历散列表所有可用槽位而不陷入局部死循环的数论充分条件。

    * 充分条件：散列表表长 $TableSize$ 为形如 $4k + 3$ 的素数（例如 7, 11, 19, 23, 47 等）。

    * 理论边界：在装填因子满足 $\alpha \le 0.5$ 约束下，只要表中尚有空槽，双向平方探测一定能寻址到空槽，绝不发生跳空死循环。

    * 反例特性：若表长为非 $4k+3$ 素数（如 $TableSize = 5$ 对应 $4k+1$），当槽位 0, 1, 2 被占用且新关键字基准地址为 1 时，探测序列仅在槽位 0 与 2 之间往复震荡，无法探查空槽 3 与 4。

* **平方探测步数映射技巧（CNum Step Mapping）**

    * > **定义**：在工程循环中通过单变量整数自增计数器 `CNum` 无浮点运算实现正负交替平方项迭代的编程算法。

    * 映射规则：
        * 奇数探测步（`CNum % 2 == 1`）：偏移步长 $i = (CNum + 1) / 2$，基准地址加上 $i^2$；
        * 偶数探测步（`CNum % 2 == 0`）：偏移步长 $i = CNum / 2$，基准地址减去 $i^2$。

    * 越界回卷处理：正向越界执行 `while (NewPos >= TableSize) NewPos -= TableSize;`；负数越界执行 `while (NewPos < 0) NewPos += TableSize;`。

    * 工程实现结构：
        ```c
        int Find(ElementType Key, HashTable H) {
            int CurrentPos, NewPos;
            int CNum = 0;

            NewPos = CurrentPos = Hash(Key, H->TableSize);

            while (H->TheCells[NewPos].Info != Empty && H->TheCells[NewPos].Element != Key) {
                ++CNum;
                if (CNum % 2) {
                    NewPos = CurrentPos + (int)pow((CNum + 1) / 2, 2);
                    while (NewPos >= H->TableSize) NewPos -= H->TableSize;
                } else {
                    NewPos = CurrentPos - (int)pow(CNum / 2, 2);
                    while (NewPos < 0) NewPos += H->TableSize;
                }
            }
            return NewPos;
        }
        ```

### 双散列探测

* **双散列探测法（Double Hashing）**

    * > **定义**：利用第二个散列函数计算探测步长，使不同关键字在同一基准位置冲突后拥有独立试探跳跃间隔的开放寻址策略。

    * 探测公式：$Pos_i = (H(key) + i \times H_2(key)) \bmod TableSize \quad (i = 1, 2, 3, \dots)$。

    * 机理：将单步增量与关键字内容深度绑定，彻底打破同义词与非同义词的探测轨迹重合。

    * > **易错点**：⚠️ 双散列探测中第二个散列函数 $H_2(key)$ 的返回值绝对不能为 0；若返回值为 0，探测步长恒为 0，算法将陷入原地无限死循环。

* **双散列步长函数（Double Hash Step Function）**

    * > **定义**：能够严格保证输出值落在 $[1, p]$ 且永不为 0 的优质第二散列函数构造模式。

    * 标准形式：$H_2(key) = p - (key \bmod p)$。

    * 参数约束：参数 $p$ 必须为小于 $TableSize$ 的素数。

    * 数值边界：因 $key \bmod p \in [0, p - 1]$，故 $H_2(key) \in [1, p]$，输出值恒大于 0。

### 懒惰删除与槽位状态

* **懒惰删除（Lazy Deletion）**

    * > **定义**：开放地址法中删除元素时不物理清空槽位、仅对槽位施加墓碑标记以维持探测链完整的机制。

    * 查找规则：遇到标记为已删除（`Deleted`）的槽位，算法判定该位置曾有数据，查找链未断裂，必须继续向后探测。

    * 插入规则：遇到标记为已删除（`Deleted`）的槽位，新关键字可直接写入复用该空间，并将状态刷新为占用。

    * > **易错点**：⚠️ 开放地址法中删除元素不可物理置空；若直接将槽位置为 Empty，会截断后续相同散列地址同义词的探测链，导致后续查找错误提前终止判定为不存在。

* **槽位状态枚举（Entry Type）**

    * > **定义**：用于精确标识开放地址法各散列单元生命周期状态的枚举类型。

    * 状态集合：
        * `Legitimate`：槽位当前存放合法有效数据，查找时参与比对，插入时需继续探查；
        * `Empty`：槽位从未被写入过数据，查找时遇到直接返回未命中，插入时可直接落位；
        * `Deleted`：槽位数据已废弃（墓碑状态），查找时穿透继续向后，插入时可直接覆盖写入。

    * 结构体封装定义：
        ```c
        typedef enum { Legitimate, Empty, Deleted } EntryType;

        struct HashEntry {
            ElementType Element;
            EntryType Info;
        };
        ```

## 分离链接与动态扩容

### 分离链接法拓扑结构

* **分离链接法结构与机制（Separate Chaining Structure）**

    * > **定义**：以连续指针数组承载散列槽位、以同义词单向链表承载具体数据的复合存储体系。

    * 插入机制：通过散列函数求得槽位下标后，遍历链表核对关键字；若未找到，分配新节点并采用头插法（Head Insertion）接入单向链表。

    * 拓扑示意：
        ```text
        槽位数组 (TheLists)
        [ 0] ---> [ 22 ] ---> [ 11 ] ---> NULL
        [ 1] ---> NULL
        [ 2] ---> NULL
        [ 3] ---> NULL
        [ 4] ---> [ 37 ] ---> [ 92 ] ---> NULL
        ```

* **分离链接法内存释放机制（Memory Deallocation in Chaining）**

    * > **定义**：分离链接法中从物理堆内存直接解构并归还节点空间的资源回收机制。

    * 节点删除优势：定位到目标节点后直接修改前驱指针绕过目标节点，调用 `free()` 物理释放内存，无需懒惰删除，不破坏任何同义词索引通路。

    * 空间销毁顺序：整表销毁（`DestroyTable`）时需先遍历各槽位逐个 `free()` 释放单链表数据节点，最后 `free()` 释放表头指针数组与表头控制结构体。

### 再散列扩容机制

* **再散列（Rehashing）**

    * > **定义**：当散列表装填因子超过预设安全阈值时开辟约两倍容量的新素数表并将有效数据全部重新映射的扩容过程。

    * 新表容量规则：新表大小取大于原表容量两倍的最小素数：$TableSize_{new} = NextPrime(2 \times TableSize_{old})$。

    * 时间复杂度：遍历旧表并将所有有效节点插入新表的时间复杂度为 $O(N)$。

    * > **易错点**：⚠️ 再散列不可通过内存拷贝直接复制旧数组；因散列函数模数已变更为新表长，所有元素在新表中的散列地址均发生改变，必须逐个取出重新计算地址并插入。

* **装填因子阈值规则（Load Factor Threshold）**

    * > **定义**：决定系统是否强制触发再散列操作的临界装填因子数值区间。

    * 开放地址法阈值：常规安全运行区间为 $\alpha \le 0.5$；若装填因子升至 $0.5 \sim 0.85$ 需高度警惕；一旦 $\alpha > 0.85$，冲突率呈雪崩式爆发，必须立即执行再散列。

    * 分离链接法阈值：通常取 $\alpha \approx 1.0$，使各链表平均长度保持在 1 左右。

### 冲突解决策略工程对比

* **开放地址法与分离链接法工程决策矩阵**

| 评估维度 | 开放地址法（Open Addressing） | 分离链接法（Separate Chaining） |
| :--- | :--- | :--- |
| **物理存储结构** | 纯连续物理数组，数据就地存放 | 连续指针数组 + 离散单向链表节点 |
| **CPU 缓存局部性** | 高（连续内存遍历对缓存行极其友好） | 较低（链表节点动态分散在堆内存各处） |
| **聚集风险（Clustering）** | 存在（线性探测有一级聚集，平方探测有二级聚集） | 无聚集现象，同义词冲突局限在单条链表内 |
| **元素删除复杂度** | 高（必须采用懒惰删除维护探测链完整性） | 极低（直接物理释放节点内存，无需墓碑） |
| **装填因子 $\alpha$ 约束** | 严格限制 $\alpha < 1$（建议控制在 $\le 0.5 \sim 0.85$） | 弹性允许 $\alpha \ge 1$（超载时性能仅呈线性平缓衰退） |
| **内存指针额外开销** | 零指针开销（但需容忍较多空闲槽位冗余） | 每个数据节点需消耗一个指针域字节开销 |

## 散列表查找性能分析

### 平均查找长度理论模型

* **平均查找长度（Average Search Length，ASL）**

    * > **定义**：在散列表中查找一个关键字时所经历的关键码平均探测比较次数。

    * 成功平均查找长度（$ASL_{succ}$）：查找目标存在于表中的平均比较次数。

    * 不成功平均查找长度（$ASL_{unsucc}$）：确信目标不存在于表中所需付出的平均探测比较次数。

    * 决定要素：散列函数的均匀度、冲突解决策略机制、装填因子 $\alpha$ 大小。

* **装填因子（Load Factor，$\alpha$）**

    * > **定义**：散列表中实际存放的有效元素个数 $N$ 与散列表物理槽位容量 $M$（$TableSize$）的比值：$\alpha = N / M$。

* **理想随机散列下各策略期望探测次数理论极限**

| 冲突解决策略 | 成功查找期望比较次数（$S$） | 不成功 / 插入期望比较次数（$U$） |
| :--- | :--- | :--- |
| **线性探测法（Linear Probing）** | $\frac{1}{2} \left( 1 + \frac{1}{1 - \alpha} \right)$ | $\frac{1}{2} \left( 1 + \frac{1}{(1 - \alpha)^2} \right)$ |
| **平方探测 / 双散列探测** | $-\frac{1}{\alpha} \ln(1 - \alpha)$ | $\frac{1}{1 - \alpha}$ |
| **分离链接法（Separate Chaining）** | $1 + \frac{\alpha}{2}$ | $\alpha + e^{-\alpha} \approx \alpha$ |

### 查找长度手算分类推导

* **成功平均查找长度计算（Successful ASL Calculation）**

    * > **定义**：通过累加表中现有各元素的实际探测次数并除以元素总数 $N$ 计算 $ASL_{succ}$ 的手算推演法则。

    * 单元素比较次数定理：任意现存元素的成功查找比较次数，严格等于当初将其插入散列表时所经历的冲突次数加 1。

    * 计算公式：
      $$ASL_{succ} = \frac{\sum_{i=1}^{N} (\text{第 } i \text{ 个元素插入冲突次数} + 1)}{N}$$

    * 数值实例：表长 13、散列函数 $key \bmod 11$、装填 9 个元素时，各元素比较次数分别为 $47(1), 7(1), 29(2), 11(1), 9(1), 84(4), 54(2), 20(4), 30(7)$，成功查找均值为 $ASL_{succ} = 23 / 9 \approx 2.56$。

* **不成功平均查找长度计算（Unsuccessful ASL Calculation）**

    * > **定义**：按散列函数可能取得的所有合法散列地址进行等概率分类、推导各分类探查至首个空槽所需比较步数的手算推演法则。

    * 判定机理：在未发生物理删除前提下，探测指针一旦触碰空槽（`Empty`），即可百分之百断定目标不存在。

    * 等概率分类归纳规则：散列值相同的不同输入，其起始查找槽位与探测轨迹完全相同；若散列函数取模除数为 $M_{hash}$，则将全域划分为 $0 \sim M_{hash}-1$ 共 $M_{hash}$ 种等概率输入场景。

    * 计算公式：
      $$ASL_{unsucc} = \frac{\sum_{h=0}^{M_{hash}-1} (\text{散列值为 } h \text{ 时探查到首个空槽的比较次数})}{M_{hash}}$$

    * 数值实例：表长 13、散列函数 $key \bmod 11$、装填 9 个元素时，余数 $0 \sim 10$ 对应探查到空槽的步数依次为 $3, 2, 1, 2, 1, 1, 1, 9, 8, 7, 6$，不成功查找均值为 $ASL_{unsucc} = 41 / 11 \approx 3.73$。

## 散列表工程综合实战

### 文本单词词频统计系统

* **词法切分与短词过滤规则（Lexical Tokenization and Filtering）**

    * > **定义**：从大规模文本流中提取合法分析单元并剔除无统计价值短词的工程规则。

    * 单词构成规范：由大小写英文字母、数字和下划线构成的连续字符子串；所有非字母数字下划线字符统一界定为分隔符。

    * 过滤门槛：仅录入并统计字符长度严格大于 3 的单词（`strlen(word) > 3`）；长度小于等于 3 的无实义代词与介词直接丢弃。

    * 词典动态更新：以单词为关键字在散列表中检索，命中则执行 `Count++`；未命中则插入新词节点并初始化 `Count = 1`。

* **四步词频统计算法（Four-Step Frequency Count Algorithm）**

    * > **定义**：基于计数排序原理在线性时间内精准筛选输出词频前 10% 单词的高效统计框架。

    * 执行步骤：
        * 扫描极值：单次全表遍历，求得整表中单词的最大出现频次 $MaxFreq$；
        * 直方图累加：动态申请大小为 $MaxFreq + 1$ 的整型直方图数组 `FreqCount`，再次遍历散列表，统计词频恰为 $i$ 的单词个数累加至 `FreqCount[i]`；
        * 倒序逆推阈值：根据有效单词总数计算前 10% 目标配额，从最大频次 $MaxFreq$ 向前倒序累加 `FreqCount[i]`，累加量首次达标时的下标 $i$ 即为准入阈值 $Threshold$；
        * 筛选输出：遍历散列表，输出所有满足 `Count >= Threshold` 的单词及其词频。

    * 复杂度优势：时间复杂度严格受控为 $O(N + MaxFreq)$，彻底避免对全表数万单词进行高开销的快速排序（$O(N \log N)$）。

### 海量通话记录频次统计

* **电话聊天狂人解法权衡（Phone Maniac Approach Trade-off）**

    * > **定义**：海量电话记录场景下对全量排序、直接映射与散列查找三类方案的工程效能裁决。

    * 全量排序局限：$N \le 10^5$ 条通话记录对应最多 $2 \times 10^5$ 个号码；在动态流式插入下，每次查询触发全量排序导致总复杂度退化为 $O(N^2 \log N)$。

    * 直接映射局限：11 位手机号需 64 位整型下标，直接开数组需约 $2 \times 10^{10} \times 2 \text{ 字节} \approx 40\text{ GB}$ 物理内存；最后定位极值需全域线性扫描，查询复杂度同样退化为 $O(N^2)$。

    * 散列方案选型：采用分离链接法，表长 $P$ 选取大于 $2N$ 的最小素数，控制装填因子 $\alpha < 1$，建表与扫描维持稳定 $O(N)$ 线性时间。

* **手机号散列特征截取（Phone Number Feature Extraction）**

    * > **定义**：根据我国 11 位手机号码号段离散度特征实施针对性字段截取的散列设计方案。

    * 号段特征分析：
        * 前 3 位网络号（如 130、138、188 等）全国仅几十种，极易引发严重聚集；
        * 中间 4 位对应归属地区号，在局部采集样本中存在强地域集聚性；
        * 后 4 位随机号离散度好，但容量仅 $10^4$ 种，无法容纳 $2 \times 10^5$ 数据规模（平均每槽挤入 20 个同义词）。

    * 截取规则：截取手机号最后 5 位数字字符串，提供 100,000 理论分散空间，送入素数求模。

    * 偏移转换实现：利用指针算术偏移截取后 5 位，执行 `atoi(Key + KEYLENGTH - 5)` 转换为整数输入模运算。

* **全表极值扫描与并列计数重置（Extremum Scan and Tied Counter Reset）**

    * > **定义**：遍历散列表链表节点提取最高通话频次并精确处理并列狂人的业务逻辑。

    * 最大值刷新规则：当前节点 `Count > MaxCount` 时，更新 `MaxCount = Ptr->Count`，复制当前号码至 `MinPhone`，并重置并列计数器 `PCnt = 1`。

    * 并列累加规则：当前节点 `Count == MaxCount` 时，并列计数器自增 `PCnt++`，并通过 `strcmp(MinPhone, Ptr->Data) > 0` 维护字典序更小的号码代表。

    * > **易错点**：⚠️ 线性扫描更新最大通话频次时，遇到严格更大的 MaxCount 必须同步将并列人数计数器 PCnt 重置为 1；若遗漏重置，并列人数将产生虚高统计错误。

    * 扫描统计实现结构：
        ```c
        void ScanAndOutput(HashTable H) {
            int i, MaxCount = 0, PCnt = 0;
            ElementType MinPhone;
            PtrToNode Ptr;

            MinPhone[0] = '\0';
            for (i = 0; i < H->TableSize; i++) {
                Ptr = H->Heads[i].Next;
                while (Ptr != NULL) {
                    if (Ptr->Count > MaxCount) {
                        MaxCount = Ptr->Count;
                        strcpy(MinPhone, Ptr->Data);
                        PCnt = 1;
                    } else if (Ptr->Count == MaxCount) {
                        PCnt++;
                        if (strcmp(MinPhone, Ptr->Data) > 0) {
                            strcpy(MinPhone, Ptr->Data);
                        }
                    }
                    Ptr = Ptr->Next;
                }
            }
            printf("%s %d", MinPhone, MaxCount);
            if (PCnt > 1) printf(" %d", PCnt);
            printf("\n");
        }
        ```

## 算法逆向辨析与模型转化

### 插入排序与归并排序运行态识别

* **插入排序二段特征判定（Insertion Sort Two-Segment Identification）**

    * > **定义**：依据简单插入排序中间状态严格划分为“手牌有序前缀”与“未碰原始后缀”二段拓扑特征的判定机制。

    * 判定规则：从左向右扫描中间序列，寻找首个逆序断点（$A[i] > A[i+1]$，断点下标 $BreakPoint = i + 1$）；自断点向后比验中间序列剩余元素与原始序列对应元素，若逐项完全一致则确认为插入排序，否则确认为归并排序。

    * 状态特征模型：
        ```text
        原始序列:   [ 3,  1,  2,  8,  7,  5,  9,  4 ]
        某趟插入:   [ 1,  2,  3,  8 ] [ 7,  5,  9,  4 ]
                    |<-- 手牌有序 -->| |<-- 未摸牌完全一致 -->|
        ```

    * 单步推进：判定为插入排序后，直接以 `BreakPoint` 处元素向前执行一趟标准插入下沉，输出下一趟中间态。

* **归并段长倍增试探法（Merge Run Length Doubling Probing）**

    * > **定义**：依据非递归归并排序段长必然呈 2 的幂次几何倍增规律（$L = 2, 4, 8, \dots$）、通过跨段接缝单调性巡检锁定真实段长的算法。

    * 试探机理：初始化段长 $L = 2$，跨步巡检每个 $2L$ 组合块内部相邻小段接缝处的边界元素（下标 $k \cdot 2L + L - 1$ 与 $k \cdot 2L + L$）；若全序列接缝均满足非递减，说明 $L$ 元小段已成功融合为 $2L$ 大段，令 $L \leftarrow 2L$ 继续向上测试；首次遭遇逆序处即可锁定真实段长 $L$。

    * 试探模型：
        ```text
        当前假设段长 L = 2:
        [ A[0], A[1] ]  [ A[2], A[3] ]    [ A[4], A[5] ]  [ A[6], A[7] ]
                  |        ^                        |        ^
                  +-- <= --+                        +-- <= --+
              检查缝隙 1: A[1] <= A[2]          检查缝隙 2: A[5] <= A[6]
        ```

    * > **易错点**：⚠️ 归并段长度判定不可简单选取前缀最长连续有序长度或全序列最短连续有序长度；相邻归并段恰巧单调拼接或末尾残余归并段会导致连续有序长度产生伪特征。

* **排序辨析最小规模边界（Minimum Scale Boundary for Sort Identification）**

    * > **定义**：能够无歧义区分插入排序与归并排序所必需的最小数据规模理论下界。

    * 数值下界：最小区分规模为 $N = 4$；当 $N \le 3$ 时，排序首趟中间态存在不可区分的完全重合。

    * 对抗测试场景：
        * 插入排序第 1 趟恰好无需移位（中间序列与原始序列完全一致）；
        * 归并排序第 1 趟全体元素发生交换；
        * 后缀偶然未变但前缀并非全局有序的防投机用例。

### 约束交换置换环分解

* **置换环分解与空位映射（Permutation Cycle Decomposition and Hole Mapping）**

    * > **定义**：将 $0 \sim N-1$ 全排列唯一正交分解为独立有向置换环、并将数字 0 抽象为唯一可移动物理空位的图论模型。

    * 映射关系：若位置 $i$ 存放数值 $A[i]$，则建立有向位置迁移弧 $i \to A[i]$，有限集合内各连通分支必然形成独立闭合置换环。

    * 物理空位角色：原子操作 `swap(0, *)` 等价于将数字 0 所在的空位与环内目标元素交换，精准实现目标元素归位并将空位转移至目标原位置。

* **置换环分类与最小交换公式（Cycle Classification and Closed-Form Formula）**

    * > **定义**：将全排列置换环按 0 的所属状态划分为三类并推导最少交换次数的闭式代数模型。

    * 环分类与代价模型：

| 置换环类别 | 拓扑物理特征 | 最少交换操作代价 |
| :--- | :--- | :--- |
| **单元环（1-Cycle）** | 元素已在位（$A[i] == i$），自成一环 | $0$ 次 |
| **包含 0 的多元环** | 环内包含空位 0（环大小为 $n_0$） | $n_0 - 1$ 次 |
| **不含 0 的多元环** | 环内不含空位 0（环大小为 $n_i \ge 2$） | $n_i + 1$ 次（1 步拉 0 入环扩为大环，$n_i$ 步内循环） |

    * 闭式终极公式：设全排列元素总数为 $N$，在位单元环数量为 $S$，多元环总数量为 $K$，则全排列归位所需最少交换操作次数为：
      $$Total = (n_0 - 1) + \sum_{i=1}^{K-1} (n_i + 1) = \sum_{i=0}^{K-1} n_i + K - 2 = N - S + K - 2$$

* **反向位置索引寻址（Inverse Position Indexing）**

    * > **定义**：通过构建反向位置查找数组以 $O(1)$ 常数时间获取任意数值当前物理存储下标的工程优化方案。

    * 结构定义：维护数组 $T[val] = pos$，表示数值 $val$ 当前存放于原数组下标 $pos$ 处。

    * 算法效益：遍历环结构时直接通过 $T$ 定位下一跳物理地址，消除 $O(N)$ 暴力扫描，使全环统计与最少交换次数计算以严格 $O(N)$ 线性时间完成。

### 散列逆问题拓扑排序建模

* **线性探测因果偏序关系（Linear Probing Causal Partial Order）**

    * > **定义**：根据线性探测散列表的终态布局反向推导元素历史插入先后依赖因果律的模型。

    * 因果律判定：
        * 若元素停留在理论基准槽位（$pos = H(key)$），其入度为 0，具备在最初被插入的先决资格；
        * 若元素停留在后续偏移槽位，则其从基准槽位 $H(key)$ 出发、沿线性探测路径到达当前槽位之间所途经的所有非空槽位中的元素，**必须早于该元素被插入**。

* **拓扑排序有向图构建（Topological Sort DAG Construction）**

    * > **定义**：将散列表所有非空槽位元素映射为顶点、将冲突探测路径上的前驱占位关系映射为有向边的有向无环图模型。

    * 边构建规则：针对偏离基准的元素 $V$，沿探测路径对其前驱占位元素 $U$ 建立有向边 $U \to V$，并累加 $V$ 的入度计数 `InDegree[V]`。

    * 入度物理意义：顶点的入度为 0 代表通往其目标槽位的探测路线上已无任何前置占位阻碍，该元素可以在当前迭代轮次合法插入。

    * 依赖拓扑模型：
        ```text
        线性探测前驱依赖拓扑图 (表长 11 局部):
          [ 1 ] ----+
                    v
         [ 13 ] --> [ 12 ] --> [ 34 ]
          [ 38 ] --> [ 27 ]
          (所有前驱) --------------> [ 22 ] --------------> [ 32 ]
        ```

* **小顶堆优先队列破局（Min-Heap Priority Queue Selection）**

    * > **定义**：在拓扑排序候选池中存在多个入度为 0 的合法顶点时、利用最小优先队列锁定字典序最小插入序列的算法。

    * 执行流程：
        * 将散列表中所有初始入度为 0 的顶点压入小顶堆（Min-Heap）；
        * 循环弹出堆顶元素（当前就绪候选集中的数值最小值）并写入输出序列；
        * 抹去该顶点的所有出边，对应后继顶点的入度减 1；若某后继顶点入度减至 0，立即将其推入小顶堆；
        * 重复执行直至堆为空，输出的序列即为字典序严格最小的原始插入序列。
