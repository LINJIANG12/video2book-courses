# 计算机组成原理（哈工大刘宏伟）（135 讲）

哈尔滨工业大学刘宏伟教授的《计算机组成原理》国家精品课，135 讲完整覆盖组成原理主干：从计算机系统概览与总线互连出发，经存储系统（主存原理、扩展校验、Cache）、输入输出与数的表示、运算方法与指令系统，最后落到 CPU 结构、指令流水线、中断系统与微程序设计。408 序列里与已收录的计算机网络、操作系统构成完整三件套。135 集整编为 5 册模块全书与 13 篇主题复习笔记。

## 怎么学

- **先立「五大部件 + 总线」骨架**：系统概览篇把运算器、控制器、存储器、I/O 与总线的互连关系立住，后面每一章都是往骨架上挂细节，笔记 01/02 是总纲。
- **存储系统是第一重头**：主存原理（SRAM/DRAM/ROM）、扩展与校验（片选译码、汉明码）、Cache 映射与替换，笔记 03/04/05 三篇连读，这部分占 408 分值最高。
- **数的表示与运算「手算到位」**：原补反移四种机器码、加减法溢出判断、乘除法器流程，必须动笔推，笔记 08/09 是演算模板。
- **I/O 三方式对比着记**：程序查询、中断、DMA 的控制机制与流程差异，笔记 06/07 各自成篇，结尾对照着收束。
- **CPU 篇抓「流水线与微程序」两条线**：指令流水线的结构冲突与数据冲突、控制单元的组合逻辑与微程序设计，笔记 11/12/13 是 408 大题的常客。
- **考前只看 `notes/`**：13 篇笔记按章主题重组，原理、流程图、计算模板并排放置。
