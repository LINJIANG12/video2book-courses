# 机器数的表示：原码、补码、反码与移码

## 原码表示法

* **原码（Sign-Magnitude）**

    * > **定义**：最高位作符号位（正数 0、负数 1），数值部分照抄真值的绝对值；整数用逗号、小数用小数点把符号位与数值位隔开。

    * 小数原码：正数就是真值本身（小数点前一位写 0）；负数按公式 $[x]_原 = 1 - x$（$x$ 为负，实际即 $1 + |x|$）。例：$x = -0.1101$，$[x]_原 = 1.1101$。

    * 小数点前符号位上的 0 与真值小数点前那一位的 0 **意义不同**：前者是符号，后者是真正的数据位。

    * 书写用的逗号和小数点**都不存入计算机**，只是为人阅读方便加的；符号位与数值位之间的分隔在机器里不存在。

    * 求原码必须知道**机器数字长**（且字长含 1 位符号位），否则无法做变换；真值数值位超出机器数值位长度时，末位被丢弃或做舍入处理。

* **原码求真值**

    * 符号位为 0：直接把符号位换成正号，$x = +0.1101$ 这类照抄即可。

    * 符号位为 1：符号位换成负号、数值位照抄。例：$[x]_原 = 1{,}1100$（数值部分 4 位），$x = -1100$；$[x]_原 = 1.0011$，$x = -0.0011$。

    * 也可按定义反推：整数 $x = 2^n - [x]_原$，小数 $x = 1 - [x]_原$（$n$ 为数值位位数）。

* **零的原码**

    * 正零 $[+0]_原 = 0.0000$（整数 $0{,}0000$）；负零 $[-0]_原 = 1.0000$（整数 $1{,}0000$）。

    * > **易错点**：正零和负零的原码**不相等**，零在原码中有两种形式（整数、小数皆如此）。

* **原码做加减法的麻烦**

    * 同是"加法"，运算器实际要做的操作随符号组合而变：

    * | 数一 | 数二 | 实际操作 | 结果 |
      | :--: | :--: | :-- | :-- |
      | 正 | 正 | 加法 | 正数 |
      | 正 | 负 | 减法 | 可正可负，看绝对值谁大 |
      | 负 | 正 | 减法 | 可正可负 |
      | 负 | 负 | 加法 | 负数 |

    * 运算器可能做加法也可能做减法，结果符号还要额外判断——由此引出"用与负数等价的正数替代负数、把减法统一成加法"的需求，即补码要解决的问题。

## 补码与模运算

* **模与补数**

    * > **定义**：有模的计数设备上，负数加上模所得的正数是它的补数，减去该负数与加上其补数效果相同。

    * 时钟以 12 为模：从 6 点调到 3 点，逆时针拨 3 格（$6-3$）与顺时针拨 9 格（$6+9=15$，到 12 归零）效果相同——$+9$ 是 $-3$ 模 12 的补数。

    * 三条结论：负数加上模得补数，**谈补数必须先指定模**；互为补数的一正一负，绝对值之和等于模；**正数的补数是它自己**。

    * 四位寄存器计数到 $2^4=16$ 时最高位进位自动丢弃，是**模 16** 的：$1011 - 1011 = 0$ 可换成 $1011 + 0101 = 1\,0000$（进位丢弃）——$-1011$ 模 16 的补数是 $+0101$（$16-11=5$）。

    * 小数是**模 2** 的：加法结果达到 2 时最高进位被丢掉。$-0.1001$ 的补数用 $2 - 0.1001 = 1.0111$ 计算。

* **符号位的引入**

    * 同一串 $0101$ 既是正数 $0101$ 本身、又是 $-1011$ 的补数，为区分而添一位符号位：正数补数写 $0{,}0101$，负数补数写 $1{,}0101$。

    * 实现方式：求补时多加一个 $2^n$（符号位位权），即以 $2^{n+1}$ 为模——负数 $2^5 - 1011 = 1{,}0101$；正数 $2^5 + 0101 = 10\,0101$，最高位 1 超出符号位被丢掉，仍是 $0{,}0101$。

* **补码定义**

    * 整数（$n$ 为数值位位数，**不含符号位**）：

    $$[x]_补 = \begin{cases} 0,\,x, & 0 \le x < 2^n \\ 2^{n+1} + x, & -2^n \le x < 0 \end{cases}$$

    * 小数：

    $$[x]_补 = \begin{cases} x, & 0 \le x < 1 \\ 2 + x, & -1 \le x < 0 \end{cases}$$

    * 负数段带等号：补码最小可表示到 $-2^n$（整数）/ $-1$（小数），比原码多表示一个数。

    * 整数例：字长 8 位（1 符号 + 7 数值），$x = -1011000$，$[x]_补 = 2^8 + x = 1{,}0101000$。小数例：字长 8 位，$x = -0.1100000$，$[x]_补 = 2 + x = 1.0100000$。

    * 小数补码是模 2 的；也可模 4（小数点前两位）、模 8、模 16，讲溢出时会引入模 4 补码。

* **补码的零与特殊值**

    * 正零负零补码相同：$[-0]_补 = 2 + (-0.0000) = 10.0000$，符号位只有一位，最高位 1 丢弃，得 $0.0000$——与原码两种零对比记。

    * $-1$ 的补码：$2 + (-1) = 1$，即 `1.0000`——**$-1$ 有补码但没有原码**，原码表示不了它。

    * 补码最大的本质好处：**把减法转换成加法**。

* **负数原码转补码的快捷方式**

    * 真值为负时：**符号位不变，数值位每位取反，末位加 1**。前提是真值为负——正数原码补码完全相同，不用变。

    * 推导思路：$2^5 - 1010$ 把 $100000$ 拆成 $11111 + 1$，$11111$ 逐位相减恰好是每位取反，再加末位的 1。

    * 更快规律：从最低位往高位看，**最后一个 1 及其右边的所有位照抄，其余各位（含符号位）全部取反**。例：$-70$ 原码 `1,1000110` → 补码 `0,0111010`（末尾 `10` 照抄，前面取反）。

* **补码转原码 / 求真值**

    * 真值为负时：补码除符号位外数值位每位取反、末位加 1，得原码；再把符号位换成负号即真值。真值为正时两者形式相同，不需要变化。

    * 也可按定义反推：小数 $x = [x]_补 - 2$，整数 $x = [x]_补 - 2^{n+1}$。例：$[x]_补 = 1{,}1110$（$n=4$），$x = -0010$。

* **已知 $[y]_补$ 求 $[-y]_补$**

    * 不论 $y$ 正负：把 $[y]_补$ **连同符号位在内**每位取反、末位加一，即得 $[-y]_补$。

    * 与"负数原码转补码"的区别：那条规则只动数值位，这条**连符号位一起翻**。

    * 例：$[y]_补 = 0.1011$ → $[-y]_补 = 1.0101$；$[y]_补 = 1.1011$ → $[-y]_补 = 0.0101$。

## 反码表示法

* **反码（One's Complement）**

    * > **定义**：负数表示比补码少"末位加一"这一步——正数反码同真值，负数反码为原码数值位每位取反。

    * 整数：正数 $[x]_反 = 0,\,x$（$0 \le x < 2^n$）；负数 $[x]_反 = (2^{n+1} - 1) + x \pmod{2^{n+1}-1}$。

    * 小数：正数 $[x]_反 = x$（$0 \le x < 1$）；负数 $[x]_反 = (2 - 2^{-n}) + x \pmod{2-2^{-n}}$——补码末位加的是 $2^{-n}$，不加这个一相当于把模减掉 $2^{-n}$。

    * 例：$x = -1101$，$[x]_反 = 1{,}0010$（`1101` 每位取反）；$x = -0.1010$，$[x]_反 = 1.0101$。

    * 反码同样是机器数，受机器字长限制，真值数值位超长部分要丢弃。

* **反码求真值与零**

    * 符号位 0：直接得正真值，如 $[x]_反 = 0{,}1110$ → $x = +1110$；符号位 1：数值位每位取反，如 $[x]_反 = 1{,}1110$ → $x = -0001$。

    * 正零反码 $0.0000$、负零反码 $1.1111$（整数同理 $0{,}0000$ / $1{,}1111$）——**零在反码中也有两种形式**，与原码一样。

## 三种机器数小结与编码对照

* **共同点与差异**

    * 原码、补码、反码最高位都是符号位；书写时整数用逗号、小数用小数点分隔符号位与数值位，机器里不存这个分隔符。

    * 正数：三种机器码**完全相同**——符号位 0，数值部分即真值数值部分（仍受字长限制）。

    * 负数：符号位都是 1，数值部分不同——原码照抄真值；数值位取反、末位加一得补码；只取反不加一得反码。

    * 零的形式：**只有补码正零负零同形**，原码和反码都各有两种零。

* **八位字长同一编码的不同解读**

    * | 二进制代码 | 无符号数 | 原码 | 补码 | 反码 |
      | :---: | :---: | :---: | :---: | :---: |
      | `0000 0000` | 0 | +0 | 0 | +0 |
      | `0000 0001` | 1 | +1 | +1 | +1 |
      | `0111 1111` | 127 | +127 | +127 | +127 |
      | `1000 0000` | 128 | −0 | **−128** | −127 |
      | `1000 0001` | 129 | −1 | −127 | −126 |
      | `1111 1110` | 254 | −126 | −2 | −1 |
      | `1111 1111` | 255 | −127 | −1 | −0 |

    * > **易错点**：⚠️ 补码表示范围是 $-2^n \sim 2^n - 1$（$n$ 为数值位数），负方向比原码、反码多一个数——补码把 $-0$ 那个编码让给了 $-2^n$（即 `1000 0000` 表示 $-128$）。

## 移码表示法

* **移码（Excess / Shift Code）**

    * > **定义**：$[x]_移 = 2^n + x$——不管正负，真值统一加上偏移量 $2^n$（$n$ 为数值位位数），整个数轴向右平移。

    * 动机：补码编码大小与真值大小**没有直接对应关系**——字长 6 位时补码 `1,01011`（$-21$）的二进制值大于 `0,10101`（$+21$），按编码比大小会得出 $-21 > +21$ 的错误结论。

    * 改为统一加 $2^n$ 后：$+21 \to$ `1,10101`、$-21 \to$ `0,01011`，编码大小与真值大小一致。

    * 例：$x = 10100$，$[x]_移 = 2^5 + 10100 = $ `1,10100`——**符号位 1 表示正数**；$x = -10100$，$[x]_移 = $ `0,01100`——符号位 0 表示负数，与补码恰好相反。

    * 移码**只有整数定义，没有小数定义**：它用来表示浮点数阶码，而阶码都是整数。

* **移码与补码的关系**

    * 同一真值的移码和补码**只差一个符号位，数值位完全相同**——逻辑实现上只需在符号位上加一个非门取反即可互转。

    * 对照表（数值部分 5 位）：

    * | 真值 | 补码 | 移码 |
      | :---: | :---: | :---: |
      | −100000（−32） | `1,00000` | `0,00000` |
      | −11111（−31） | `1,00001` | `0,00001` |
      | −00001（−1） | `1,11111` | `0,11111` |
      | ±0 | `0,00000` | `1,00000` |
      | +00001（+1） | `0,00001` | `1,00001` |
      | +11111（+31） | `0,11111` | `1,11111` |

* **移码的特点**

    * 零唯一：正零 $2^5 + 0$、负零 $2^5 - 0$ 结果相同，都是 `1,00000`。

    * 最小真值 $-2^n$ 加 $2^n$ 后移码恰好**全零**；最大真值 $2^n - 1$ 加 $2^n$ 后移码**全一**——移码从全零到全一正好对应真值从小到大单调排列，所以判断大小非常容易。

    * 用途：表示**浮点数的阶码**——把真值平移成单调递增的无符号编码，便于直接比较阶码大小，这是移码存在的全部理由。

## 定点表示

* **定点数（Fixed-Point Number）**

    * > **定义**：小数点位置固定、由体系结构**约定**给出、不占硬件的数——计算机中没有表示小数点的专门硬件，硬件实现和软件实现都要遵守约定。

    * 两种约定：小数点在**数符后面**——机器里的数全是小数（补码形式下能表示的唯一整数是 $-1$）；小数点在**数值部分最后**——机器里的数全是整数。

    * 按约定把定点机分成两类：**小数定点机**（小数点在数符后、数值前）与**整数定点机**（小数点在数值位后）。

* **定点数的表示范围**（字长 $n+1$ 位：1 位数符 + $n$ 位数值）

    * | 机器码 | 小数定点机 | 整数定点机 |
      | :--- | :--- | :--- |
      | 原码 | $-(1-2^{-n}) \sim +(1-2^{-n})$ | $-(2^n-1) \sim +(2^n-1)$ |
      | 补码 | $-1 \sim +(1-2^{-n})$ | $-2^n \sim +(2^n-1)$ |
      | 反码 | 与原码相同 | 与原码相同 |

    * 补码负方向边界的编码：小数是数符 1、数值部分**全 0**（即 $-1$）；整数是数符 1、数值全 0（即 $-2^n$）。

    * > **易错点**：⚠️ 补码在负方向上比原码"多挤进去"一个数，靠的正是数值部分全 0、数符为 1 这个编码。

    * 计算机中的数是**离散的**：$n+1$ 位最多 $2^{n+1}$ 个编码，却要用它们表示数据区间内无数个连续实数。

## 浮点表示的引入与格式

* **为什么要引入浮点表示**

    * 早期机器只有定点表示，程序员要自己调整小数点位置、自己校正计算结果，负担很大。

    * 定点机表示范围小：小数定点机表示的值绝对值不大于 1，要同时存大小相差悬殊的数就需要极长字长——太阳质量 $0.2\times10^{34}$ 克与电子质量 $0.9\times10^{-27}$ 克相差 $10^{61}$ 量级，二进制表示需 203 位，且存电子质量时单元高位大量为零。

    * 数据存储单元利用率低——基于这三点引入浮点数据表示。

* **浮点数的形式**

    * > **定义**：$N = S \times r^{\,j}$，其中 $S$ 是尾数（绝对值小于等于 1 的小数），$j$ 是阶码（整数），$r$ 是尾数的基值——与十进制科学计数法同思路。

    * 基值取法：$r=2$ 时尾数一位二进制表示一位；$r=4$ 用两位二进制表示一位四进制；$r=8$ 用三位；$r=16$ 用四位。

    * 同一真值有多种写法：$11.0101_{(2)}$ 可写成 $0.110101 \times 2^{10}$、$0.0110101 \times 2^{11}$、$1.10101 \times 2^{-10}$ 等——尾数每移位，阶码反向调整，真值不变；但机器里尾数必须是小数定点形式（值 $\le 1$），只有尾数是纯小数的写法才能存。

* **浮点数在机器中的存放**

    * 基值由设计约定、本身不用存；存储的是**尾数部分和阶码部分（含数符与阶符）**，各自按约定的机器数形式和位数存放。

    * ```text
```text
      ┌──────┬────────────────┬──────┬─────────────────┐
      │ 阶符 │  j1  j2 …  jm  │ 数符 │  S1  S2 …  Sn   │
      └──────┴────────────────┴──────┴─────────────────┘
         ↑          ↑              ↑          ↑
        阶码符号   阶码(整数)      尾数符号   尾数(n位小数)
                   小数点在数值部分最后        小数点紧跟在数符后面
```
      ```

    * **阶码和尾数共同决定浮点数小数点的实际位置**；阶码本身是定点整数，尾数本身是定点小数。

* **浮点数的表示范围**（不考虑规格化，阶码尾数均用原码，阶码数值 $m$ 位、尾数数值 $n$ 位）

    * 最小负数（绝对值最大）：尾数绝对值最大 $-(1-2^{-n})$，阶码最大 $+(2^m-1)$，即 $-(1-2^{-n}) \times 2^{2^m-1}$。

    * 最大负数（贴近零）：尾数 $-2^{-n}$，阶码 $-(2^m-1)$，即 $-2^{-n} \times 2^{-(2^m-1)}$。

    * 最小正数：尾数 $+2^{-n}$，阶码 $-(2^m-1)$；最大正数：尾数 $+(1-2^{-n})$，阶码 $+(2^m-1)$。

    * 例：$m=4$、$n=10$，总长 16 位（1 阶符 + 4 阶码 + 1 数符 + 10 尾数），可表示 $2^{16}$ 个数——用有限个离散数据表示最小负数到最大正数之间的所有实数。

    * **上溢**：阶码大于最大阶码，按计算出错处理；**下溢**：阶码小于最小阶码、落在贴近零处，按**机器零**处理。

## 浮点数的规格化

* **规格化（Normalization）**

    * > **定义**：调整尾数使有效位数尽可能多的表示形式——$r=2$ 时要求尾数最高数值位（真值）为 1；一般 $r=2^k$ 时要求尾数最高 $k$ 位不全为 0。

    * 目的：**保精度**。不规格化时尾数小数点后可能有一串零（原码下是真零），机器尾数长度有限，超长部分被丢弃，严重影响精度。

    * 基值不同规格化形式不同：$r=4$ 要求最高两位不全为零，$r=8$ 最高三位、$r=16$ 最高四位不全为零。

* **左规与右规**

    * **左规**：尾数左移，丢掉左边的多余零；每左移一位数据扩大 2 倍，阶码减 1。

    * **右规**：尾数右移；每右移一位数据缩小一半，阶码加 1。

    * 基值不是 2 时以基值进制为单位移位：$r=4$ 每次移**两位**二进制位（左规阶码减 1、右规加 1）；$r=8$ 每次移三位。

    * 规格化通过移位加调阶码，保证浮点数真值不变。

* **基值 $r$ 的影响**

    * $r$ 越大，能表示的浮点数**范围**越大、**个数**越多；但**精度**越低——范围、个数与精度是一对交换。

* **规格化后的范围示例**（$m=4$、$n=10$、$r=2$、尾数原码）

    * | 端点 | 尾数（原码） | 阶码（原码） | 值 |
      | :--- | :--- | :--- | :--- |
      | 最大正数 | $0.111\cdots1$ | $0,\,1111$ | $(1-2^{-10})\times 2^{15}$ |
      | 最小正数 | $0.100\cdots0$ | $1,\,1111$ | $\tfrac12\times 2^{-15}=2^{-16}$ |
      | 最大负数 | $-0.100\cdots0$ | $1,\,1111$ | $-2^{-16}$ |
      | 最小负数 | $-0.111\cdots1$ | $0,\,1111$ | $-(1-2^{-10})\times 2^{15}$ |

    * 规格化后最小正数与最大负数被"抬"离了零——尾数不能再是前面带一串 0 的非规格化小数，这正是规格化保精度的直接体现。

* **设计格式题：范围靠阶码，精度靠尾数**

    * 例：字长 24 位，要求表示 $\pm 30000$ 且保证最大精度。$2^{14}=16384 < 30000 < 2^{15}=32768$，阶码数值部分取 4 位（范围可达 $\pm 15$）即覆盖要求；取 5 位则白占位数。

    * 答案分配：1 位数符 + 1 位阶符 + 4 位阶码 + 18 位尾数——先按范围卡出阶码的最短位数，剩下的位数全部让给尾数。

## 浮点例题精算

* **例：$+\dfrac{19}{128}$ 的定点与浮点表示**（数值部分 10 位含 1 数符，阶码 5 位含 1 阶符，尾数规格化）

    * $19 = (10011)_2$，$128 = 2^7$，所以 $\dfrac{19}{128} = (0.0010011)_2$。

    * 定点表示：数值只有 7 位，前面补 3 个零补齐 10 位，得 `0.0010011000`；正数的原码、反码、补码形式相同。

    * 浮点表示：尾数相对小数点左移两位成规格化形式 `0.1001100000`，数据扩大 4 倍，阶码取 $-2$。

    * 阶码为负要按负数分别求：原码 `1,0010`、补码 `1,1110`（`0010` 取反加一）、反码 `1,1101`；尾数为正，三种码都是 `0.1001100000`。

    * > **易错点**：⚠️ 浮点数整体的正负只由数符决定，但阶码和尾数是两段独立的机器数，各变各的——正数的浮点表示里，负阶码照样要按负数求补码、反码。

* **例：$-58$ 写全各种机器数形式**（同上位数要求）

    * $58 = 32 + 16 + 8 + 2 = (111010)_2$；定点负数数值部分 10 位，前面补 4 个零得 `0000111010`。

    * 定点机：原码 `1,0000111010`；反码 `1,1111000101`；补码 `1,1111000110`。

    * 浮点形式：小数点挪到 `0.111010`，数据相对小数点右移 6 位（缩小 $2^6$），再乘 $2^6$ 保持真值：$-58 = -0.1110100000 \times 2^{110_2}$。

    * 阶码真值 $+6$，补码、反码、原码数值部分都是 `0110`，原/补/反码均为 `0,0110`，移码为 `1,0110`；尾数为负分别求：原码 `1.1110100000`、补码 `1.0001100000`、反码 `1.0001011111`（移码阶码配补码尾数）。

    * 注意：阶码数值部分要补齐 4 位；阶码大于零时补码、反码形式不变，不要对正阶码取反。

## 机器零

* **机器零（Machine Zero）**

    * > **定义**：浮点数满足以下两条之一即按机器零处理——① 尾数为零，不管阶码是什么值；② 阶码等于或小于它能表示的最小值，不管尾数是多少。

    * 第一条的依据是规格化要求：非零数规格化后尾数小数点后第一位真值必为 1，尾数全零说明不可能是非零数。

    * 第二条是下溢情形：阶码已小到表示不了，按零处理。$m=4$、补码阶码时，最小阶码 $-16$ 对应的数即机器零。

    * 阶码用**移码**、尾数用补码时：阶码真值 $-16$ 的移码恰好全零，判定规则统一成——**阶码全零或尾数全零即为机器零**。

    * 好处：判零只需判"全零"，非常有利于用硬件电路实现。

## IEEE 754 标准

* **IEEE 754 浮点格式**

    * > **定义**：数符（尾数符号）+ 阶码（含阶符）+ 尾数 M 三段式格式；尾数必须规格化表示，数符与阶码的交界既是尾数的小数点也是阶码的小数点。

    * 基值为 2 时规格化尾数最高数值位真值必为 1，这一位可以**隐含掉**不在数据中表示，计算时补齐——等效增加尾数位数，提高精度。

    * 对实数的三种规定：

    * | 类型 | 总位数 | 数符 | 阶码 | 尾数 |
      | :---: | :---: | :---: | :---: | :---: |
      | 短实数 | 32 位 | 1 位 | 8 位 | 23 位 |
      | 长实数 | 64 位 | 1 位 | 11 位 | 52 位 |
      | 临时实数 | 80 位 | 1 位 | 15 位 | 64 位 |

    * 阶码位数越多表示范围越大，尾数位数越多精度越高。

## 表示范围实战：16 位字长的七种情况

* **无符号整数**

    * 16 位全是数值：最小全零为 0，最大全一为 $2^{16}-1$；推广为 $n$ 个 1 即 $2^n - 1$。

* **原码定点小数**

    * 原码表示范围**关于零对称**：$-\left(1-2^{-15}\right) \sim +\left(1-2^{-15}\right)$；15 个 1 的小数即 $1 - 2^{-15}$。

    * 原码的零有两个：$+0.0\cdots0$ 与 $-0.0\cdots0$。

* **补码定点小数**

    * 两个零合成一个（占正零位置），负数区必须再向左扩展一个最小小数单位 $2^{-15}$ 才能保住 $2^{16}$ 个编码总数。

    * 范围：$-1 \sim +\left(1-2^{-15}\right)$——正数部分与原码相同，负数部分向左多一个单位；原码对称，补码不对称。

* **原码定点整数**

    * 范围 $-\left(2^{15}-1\right) \sim +\left(2^{15}-1\right)$，同样有 $+0$ 和 $-0$ 两个零。

* **补码定点整数**

    * $-0$ 编码让出后负数侧向左多挪一格（整数单位是 1）：$-(2^{15}-1) - 1 = -2^{15}$。

    * 范围 $-2^{15} \sim +\left(2^{15}-1\right)$；$-2^{15}$（1 后面跟 15 个 0）是**原码不能表示、补码能表示**的数。

* **原码非规格化浮点数**（阶码 6 位含 1 阶符、尾数 10 位含 1 数符，均原码）

    * 阶码范围 $-31 \sim +31$（原码整数），尾数范围 $\pm\left(1-2^{-9}\right)$（原码小数）；零是机器零，范围不含零。

    * 正数：$2^{-9} \times 2^{-31} \sim \left(1-2^{-9}\right) \times 2^{31}$；负数与正数对称：$-\left(1-2^{-9}\right) \times 2^{31} \sim -2^{-9} \times 2^{-31}$——记住正数范围，负数直接取相反数。

* **补码规格化浮点数**（阶码尾数均补码）

    * 补码阶码范围 $-32 \sim +31$（负方向多一个数）。

    * 正数：尾数最小 $0.100000000 = 2^{-1}$、最大 $1-2^{-9}$，范围 $2^{-1} \times 2^{-32} \sim \left(1-2^{-9}\right) \times 2^{31}$——与原码相比正数尾数无变化。

    * 负数：**$-\dfrac{1}{2}$ 的补码 `1.1000…0` 不是规格化形式**（补码规格化负数要求形如 $1.0\times\cdots\times$），必须排除，负尾数区间向左移一个单位 $2^{-9}$：绝对值最小的负数为 $-\left(2^{-1}+2^{-9}\right) \times 2^{-32}$；绝对值最大的负尾数移到 $-1$，最小负数为 $-1 \times 2^{31} = -2^{31}$。

    * > **易错点**：⚠️ 补码规格化里 $-\dfrac{1}{2}$ 不合格、$-1$ 反而是合格的规格化尾数——这与直觉相反，是本题最难理解的点。

* **数轴解题心法**

    * 字长定死后编码总个数固定（如 $2^{16}$ 个）；表示范围问题本质是这批编码在数轴上怎么摆：**零占几个位置、省下的位置让哪一侧扩展、扩展的单位是 1 还是 $2^{-15}$ 还是 $2^{-9}$**。

    * 补码比原码负方向多一个数、规格化把正负最小值抬离零，都能用"编码个数守恒、区间平移一个单位"解释；考试中浮点题一般会明确阶码尾数采用什么码，按给定的做。
```
