# 定点运算：加减法、溢出判断与乘除法器

## 补码加减法

   * **补码加减法公式**

       * > **定义**：补码的加减法统一为加法：$[a+b]_补 = [a]_补 + [b]_补$，$[a-b]_补 = [a]_补 + [-b]_补$；整数按模 $2^{n+1}$ 运算，小数按模 $2$ 运算。

       * 统一证明思路：不论 $x$ 正负，$[x]_补 = 2^{n+1} + x \pmod{2^{n+1}}$；两式相加多出的 $2^{n+1}$ 超出模、高位自动丢弃，剩下的正是 $[a+b]_补$；小数把模换成 $2$ 同理。

       * 运算要领：补码的加减法（以及乘法）**连同符号位一起运算**，和的符号由计算过程自动产生，符号位产生的进位自动丢掉，结果即正确。

       * 求 $[-b]_补$ 的规则：对 $[b]_补$ **连同符号位一起取反、末位加 1**（不是只对数值位取反）。

       * 整数型定点机放入位数不足的数时，在数值位**左方**补 0（如 $15$ 在 8 位机中写为 $0,0001111$）。

   * **机器字长意识**

       * 机器数存放在计算机里，必须明确寄存器长度：符号位几位、数值位几位；不做此约定的题目隐含了字长假设，算例前先补齐。

       * > **易错点** ⚠️：机器数不是写在纸上的数，想写多长写多长；不考虑机器字长，就发现不了溢出。

   * **溢出（Overflow）**

       * > **定义**：运算结果超出机器数（定点机）所能表示的范围，称为溢出；表象是两正数相加得负、结果与真值对不上，根子是真值跑出了表示范围。

       * 8 位含 1 位符号位的整数补码表示范围为 $-128 \sim +127$（共 256 个数）：$-97 - 41$ 真值 $-138$ 超界，按补码算出 $+118$，即溢出。

       * 纯小数定点机只能表示绝对值小于 1 的数：$9/16 + 11/16$ 真值 $20/16 > 1$，按补码算出 $-12/16$，同为溢出。

## 算术移位与逻辑移位

   * **移位运算的数学意义**

       * 计算机里的小数点由约定给出、无硬件表示，移位是指**数据相对于小数点**左移或右移，小数点位置不动。

       * 二进制数值相对小数点左移一位，绝对值变为 2 倍；右移一位，绝对值变为 1/2。

       * 移位与加减法配合即可实现乘除法，是乘除法器的基础操作。

   * **算术移位的填补规则**

       * 第一条铁则：**符号位不变**——有符号数移位后正数仍是正数、负数仍是负数。

       * 填补代码总表：

| 机器数形式 | 左移低位补 | 右移高位补 |
| :--- | :---: | :---: |
| 正数（原码＝反码＝补码） | 0 | 0 |
| 负数原码 | 0 | 0 |
| 负数反码 | 1 | 1 |
| 负数补码 | 0 | 1 |

       * 负数反码补 1 的原因：反码中的 1 对应真值的 0，补 1 才等价于真值移位补 0。

       * 负数补码的推导：对形如 $x = -0.x_1x_2\cdots x_k\,1\,00\cdots 0$ 的负小数，$[x]_补 = 1.\bar{x}_1\bar{x}_2\cdots\bar{x}_k\,1\,00\cdots 0$——补码最后一个 1 右侧的 0 对应真值的 0，故左移补 0；左侧是取反形式，真值该补 0 处补码即为 1，故右移补 1。

       * 实例对照：$-26$（8 位机）右移两位，原码、反码得 $-6$，补码得 $-7$——填补规则不同，丢位取整方向不同。

   * **移丢位的后果**

       * 真值为正（三码相同）：左移丢 1 会**出错**（丢的是真值的有效 1），右移丢 1 **影响精度**。

       * 负数原码：数值位即真值，左移丢 1 出错、右移丢 1 影响精度，与正数相同。

       * 负数补码：左移丢 1 无碍（该 1 对应真值的 0），**丢 0 才会出错**；右移丢 1 影响精度。

       * 负数反码：无论左移右移，丢 1 对应真值的 0，不会出错。

       * 定点机右移丢掉小数部分会截掉有效位：$+26$ 右移两位按规则应为 $6.5$，实际得 $6$，精度受损。

   * **算术移位的硬件实现**

       * 填补代码恰与符号位相同时（正数补 0、负数补码/反码补 1），用一条"符号位自我复制"通路同时完成保符号与补位。

       * 负数原码补 0 与符号位（1）不一致，需要另外的补 0 通路。

```text
        ┌────────────→ 符号位自身保持不变
 符号位 ─┤
        └────────────→ 移入数值位最高位（充当填补代码）
 数值位 ────────────→ 整体左移/右移一位，越界的一位被移丢
```

   * **算术移位与逻辑移位的区别**

       * > **定义**：算术移位是有符号数的移位，符号位不动、符号保持不变；逻辑移位是无符号数的移位，所有数值位都参加移位。

       * 逻辑左移：最低位空出补 0，高位丢掉；逻辑右移：高位空出补 0，低位丢掉。

       * 同一数据 $10110010$ 逻辑右移得 $01011001$（全部位参与、高位补 0）；算术右移把它当补码负数处理，得 $11011001$（符号位不动、高位补 1）——用哪条指令取决于把数据当无符号数还是有符号数。

       * 带进位的移位：把移掉的最高位移入进位位保存，用于记录移位过程中丢失的位。

## 溢出判断

   * **一位符号位判溢出**

       * > **定义**：把最高有效位的进位与符号位的进位做**异或**，结果为 1（两进位不相同）即判定溢出。

       * 前提结论：一正一负相加**不可能溢出**（结果仍落在可表示范围内）；溢出只发生在两操作数同号而结果符号与之不同时。

       * 四种进位组合：

| 最高有效位进位 | 符号位进位 | 是否溢出 | 对应情形 |
| :---: | :---: | :---: | :--- |
| 1 | 0 | 溢出 | 两个正数相加 |
| 0 | 1 | 溢出 | 两个负数相加 |
| 0 | 0 | 不溢出 | 同号或异号相加 |
| 1 | 1 | 不溢出 | 异号相加 |

       * 硬件上须同时记录符号位的进位与最高有效位的进位，送异或电路；输出 1 置溢出标志。

   * **双符号位与模 4 补码**

       * 双符号位即把补码的模由 2 改为 4：正数形式为 $00.x_1x_2\cdots$，负数为 $11.$ 后接每位取反、末位加 1 的数值；整数的模相应由 $2^{n+1}$ 改为 $2^{n+2}$。

       * 推广：以 $2^k$ 为模（$k=1,2,3\cdots$）补码的符号部分占 $k$ 位——模 2 一位、模 4 两位、模 8 三位；整数可用 $2^{n+m}$ 为模，正数为 $m$ 个 0 后跟数值，负数为 $m$ 个 1 后跟取反加 1 的数值。

       * 以 4 为模时公式依然成立：$[x]_补 + [y]_补 = [x+y]_补$，$[x-y]_补 = [x]_补 + [-y]_补 \pmod 4$。

       * 判溢出规则：运算结果两符号位**相同**则无溢出；**不同**（10 或 01）即溢出，且**第一符号位（最高符号位）才是真正的符号位**，第二符号位是溢出的数值部分。

## 补码加减法的硬件配置

   * **核心部件**

       * 一个 $n+1$ 位加法器完成两个补码的加法。

       * **ACC（累加器）**：保存被加数；**X 寄存器**：保存加数（减法时为被减数）；两者均为 $n+1$ 位。

       * **GA**：加法标志，做加法置 1；**GS**：减法标志，做减法置 1，并控制求补控制逻辑生效。

   * **减法的求补实现**

       * 减法须把 X 中的 $[y]_补$ 转成 $[-y]_补$（连同符号位各位取反、末位加 1）。

       * 各位取反：在加法器与寄存器之间加反向器即可。

       * 末位加 1：把加法器**最低位的进位输入置 1** 实现——不采用"取反后另做一次加一运算"的办法。

## 原码一位乘

   * **笔算乘法的改造要点**

       * 二进制乘法部分积只有两种：被乘数本身或 0，比十进制笔算更简单。

       * 符号位单独处理：用一个**异或电路**求乘积符号（笔算是"心算"出来的）。

       * 乘数判断：乘数放入移位寄存器，每次判断最低位是否为 1，判断完右移一位，逐位处理。

       * "各部分积一次对齐相加"改为**多次累加**：被乘数位置不动，部分积每次相加后**右移一位**替代被乘数左移，加法效果相同。

       * 乘积位数扩大一倍（n 位 × n 位 → 2n 位）：用两个寄存器保存乘积。

   * **移位加法实现乘法的数学形式**

       * 以 $b = 0.1011$ 为例展开可得

$$a \times b = 2^{-1}\{0 + 2^{-1}[a + 2^{-1}(a + 2^{-1}(0 + a))]\}$$

       * 每层乘 $2^{-1}$ 用部分积**右移一位**实现；式中的 0 是累加和的初始值；乘数从最低位起逐位决定是否加被乘数。

   * **原码一位乘规则**

       * > **定义**：$[x \cdot y]_原 = (x_0 \oplus y_0)\,.\,(x^* \cdot y^*)$——符号位由两操作数符号异或单独得到，数值部分只做绝对值相乘。

       * 递推过程：部分积初值 $z_0 = 0$；由乘数最低位 $y_n$ 决定是否加被乘数的数值部分（1 加、0 加零），加完右移一位得 $z_1$；重复至第 n 步。

       * 数值部分 n 位需 **n 次加法、n 次移位**。

       * > **易错点** ⚠️：原码一位乘是**绝对值运算**，移位一律用**逻辑右移**——看似符号位位置上的值其实是数值，要移进数值部分、左侧补 0。

       * 例：$|x| = 0.1101$、$|y| = 0.1011$，4 轮"判断—相加—右移"后得 $|x \cdot y| = 0.10101111$；符号 $1 \oplus 0 = 1$，故 $[x \cdot y]_原 = 1.10101111$。

   * **原码一位乘的硬件配置**

       * **X 寄存器**：保存被乘数，全程不变，**无移位功能**。

       * **ACC（A 寄存器）**：保存部分积高位（累加和）；其最高位不是符号位，而是数值相加后**向高位的进位**；有移位功能。

       * **MQ（Q 寄存器，乘商寄存器）**：初存乘数；随移位其低位丢乘数已用位、高位被乘积低位填充；有移位功能。

       * **计数器**：记录移位次数，每移一次减 1，减到 0 运算结束；**S**：符号位（异或置值）；**GM**：乘法标志。

       * 加法只发生在被乘数与部分积高位（ACC 部分）之间，与 MQ 中的低位不相加；需要一个加法器。

       * 加法与移位由**乘数最低位**控制：末位为 1 打开控制门送被乘数入加法器累加；为 0 可直接跳过加法只做移位——所以用**移位次数**（而非加法次数）判断乘法结束。

## 原码除法

   * **笔算除法的特点与机器化改造**

       * 二进制除法每步商只能上 1 或 0，比十进制简单得多。

       * 笔算特点：商符心算单独处理；上商靠比较余数与右移后的除数；余数不动、末位补零、除数不断右移；上商位置不固定（5 次上商、4 次移位）。

       * 机器化对应：

| 笔算除法 | 机器除法 |
| :--- | :--- |
| 商符心算，单独处理 | 符号位异或，单独处理 |
| 心算上商 | 做减法，看结果正负决定上 1 还是上 0 |
| 余数不动、除数不断右移 | 除数不动，余数左移一位、低位补零 |
| 需要 $2n$ 位加法器 | 只需 $n+1$ 位加法器 |
| 上商位置不固定 | 上商固定在最低位，商寄存器同步左移 |

       * 余数右移改余数左移是**相对移位**：比较大小效果相同，但余数长度不涨，n 位加法器即可完成。

       * 上商改为试探：余数减除数（加 $[-y^*]_补$），结果为正上 1、为负上 0。

   * **原码除法规则与三条约定**

       * > **定义**：商的符号由 $x_0 \oplus y_0$ 单独获得，数值部分直接用绝对值相除 $x^*/y^*$（$x^* = 0.x_1\cdots x_n$，$y^* = 0.y_1\cdots y_n$），符号位绝不掺和数值运算。

       * 约定一：小数定点机要求**被除数绝对值小于除数绝对值**（商仍为小数）；整数定点机要求被除数绝对值大于除数绝对值。

       * 约定二：被除数不得为零，为零无需除法。

       * 约定三：除数不能为零，否则导致异常操作。

       * 做题应用：小数定点机第一次上商若上的是 1，即商大于 1，直接判定溢出、停止计算。

   * **恢复余数法**

       * 流程：余数（初值＝被除数）加 $[-y^*]_补$ 做减法试探——结果为正，上商 1，直接左移继续；结果为负，上商 0，但这次减法本不该做，须**加 $[y^*]_补$ 恢复余数**，再左移一位与除数比较——"恢复余数"由此得名。

       * > **易错点** ⚠️：除法过程中的移位是**逻辑左移**（如 $0.1011$ 左移成 $1.0110$，数值最高位移到小数点前），不是算术左移。

       * 例：$x = -0.1011$，$y = -0.1101$，5 位机（1 符号 4 数值），备好 $[y^*]_补 = 0.1101$、$[-y^*]_补 = 1.0011$；得 $[x/y]_原 = 0.1101$，余数 $0.0111 \times 2^{-4}$（正）。

       * 次数统计：上商 $n+1$ 次（第一次上商落在小数点前位置，用于**判断溢出**），移位 $n$ 次；小数点前的商经 4 次移位后才移到符号位位置。

   * **加减交替法（不恢复余数法）**

       * 改进依据：恢复余数法中"减多了"那条路为 $(R_i + y^*) \times 2 - y^* = 2R_i + y^*$——化简后等价于**余数左移一位后直接加 $y^*$**，恢复步骤可省。

       * > **定义**：上商 1，余数左移一位后加 $[-y^*]_补$；上商 0，余数左移一位后加 $[y^*]_补$。按当前上商值决定下一步做加还是做减，加减交替进行。

       * 第一步**固定做减法**（加 $[-y^*]_补$）：尚无上商可依据，且顺便判断溢出。

       * 同例 $x = -0.1011$，$y = -0.1101$ 验算得 $[x/y]_原 = 0.1101$，与恢复余数法完全一致，但全程一次"恢复"都没做。

       * 操作次数：上商 $n+1$ 次、移位 $n$ 次、加法 $n+1$ 次（每次上商对应一次加法）；次数确定，可用**移位（或加法）次数**作除法停止的控制依据。

   * **加减交替除法的硬件配置**

       * **A 寄存器**（即 ACC）：保存被除数，运算中渐变为余数；**X 寄存器**：保存除数；**Q 寄存器**：保存商。三者均 $n+1$ 位（原码只 1 位符号 + n 位数值）。

       * 左移时 A、Q 同步左移；加 $[y^*]_补$ 还是加 $[-y^*]_补$ 由 **Q 的最低位**送入移位和加法控制逻辑，控制 $n+1$ 位加法器做加或做减。

       * 配套：**C 计数器**记录移位次数控制停止；**S** 符号位；**V** 溢出标志。

## 浮点加减法运算

   * **对阶**

       * > **定义**：两浮点数 $x = S_x \times r^{j_x}$、$y = S_y \times r^{j_y}$ 做加减前须阶码相同；对阶即求阶差并调整小阶一方，调整时阶码与尾数联动、保持数值不变。讲解中设尾数基值 $r = 2$。

       * 求阶差：两阶码做减法，用补码加法实现；阶差为 0 已对齐，大于 0 说明 $j_x > j_y$，小于 0 说明 $j_x < j_y$。

       * 阶码大的数向小的看齐需尾数**左移**，可能移掉高位有效 1、改变数据大小，**不可行**；小阶向大阶看齐只需尾数**右移**，丢位只损失精度。

       * > **结论**：对阶原则是**小阶向大阶看齐**——小阶方阶码逐次加一、尾数同步右移一位，直到两数阶码相同。

       * 例：$x = 0.1101 \times 2^{0}$，$y = -0.1010 \times 2^{10}$，阶差 $-2$，x 阶码加 2、尾数右移两位（$00.1101 \to 00.0011$），移丢的低位按截断法处理。

   * **尾数求和与规格化**

       * 阶码对齐后，尾数用补码直接加减求和；和往往不是规格化数，需继续处理。

       * 规格化目的：尽可能提高浮点数表示精度，把硬件资源用足。

       * 尾数基值为 2 时规格化定义：$\frac{1}{2} \le |S| < 1$；基值为 4 则下界换成 $1/4$。

       * 规格化形式判别表：

| 码制 | 正数规格化形式 | 负数规格化形式 |
| :--- | :--- | :--- |
| 真值 | $0.1x\cdots x$ | $-0.1x\cdots x$ |
| 原码 | $0.1x\cdots x$ | $1.1x\cdots x$ |
| 补码 | $0.1x\cdots x$ | $1.0x\cdots x$ |
| 反码 | $0.1x\cdots x$ | $1.0x\cdots x$ |

       * 两条实用判据：**原码**——不论正负，数值位最高位为 1 即规格化；**补码**——符号位与数值位最高位**不同**即规格化（硬件用一位异或即可判别）。

       * 实际判断用判据而非套定义，因补码有两个特例。

       * > **易错点** ⚠️：$-1/2$ 按定义 $|S| = 1/2$ 似乎规格化，但其补码 $1.1000$ 符号位与最高数值位相同，按补码体系要当作**非规格化数**处理、需左规。

       * 特例二：$s = -1$ 无原码表示，但补码 $1.0000$ 符号位与最高数值位不同，**是**规格化数。

   * **左规与右规**

       * **左规**：尾数左移一位（值 ×2）、阶码减一，重复至符号位与第一数值位不同为止（补码前提下）。

       * **右规**：尾数右移一位（值 ×1/2）、阶码加一；触发条件是尾数溢出——补码双符号位下尾数呈 $01.xx\cdots x$ 或 $10.xx\cdots x$。两正数尾数相加溢出出现 $01$（前面的 0 才是真符号，后面的 1 是溢出的数值）。

| 方式 | 尾数动作 | 阶码动作 | 使用时机 |
| :--- | :--- | :--- | :--- |
| 左规 | 左移一位 | 减一 | 补码下符号位与最高数值位相同 |
| 右规 | 右移一位 | 加一 | 尾数溢出，双符号位为 01 或 10 |

       * 例（左规）：尾数和 $11.1001$，符号位与最高数值位均为 1，左移一位成 $11.0010$、阶码减一，即得规格化和。

       * 例（右规）：$0.1101 \times 2^{10} + 0.1011 \times 2^{01}$，对阶后尾数和 $01.0010$，右移一位成 $00.1001$、阶码加一，结果 $0.1001 \times 2^{11}$。

   * **舍入处理**

       * > **定义**：数据长度超过存储器件能保存的长度时对低位部分的处理；对阶和右规都会使尾数右移丢位产生误差，舍入用于减小误差。

       * **截断法**：移出的数据直接扔掉，最简单。

       * **零舍一入法**：类似十进制四舍五入——被丢数据的最高位为 1，就在保留数据的最低位加一。

       * **末位恒置一法**：无论丢掉什么，保留数据的最低有效位恒置为 1。

       * 各方法在精度、累积误差、硬件实现难易上各有取舍；计算机中还有其他舍入方法。

   * **浮点数的溢出判断**

       * 此处溢出指**整个浮点数的值**超出机器可表示范围，不是尾数溢出（尾数溢出右规即可消化）。

       * 可表示范围内数据也是**离散的**：数轴上没落在可表示点上的数只能取近似（取左取右取决于舍入方法）。

       * 以阶码、尾数均为补码、尾数规格化、阶符 2 位 + 阶码数值 7 位（$-128 \sim +127$）、数符 2 位 + 尾数 n 位为例的四个边界：

| 边界 | 构造方式 | 值 |
| :--- | :--- | :--- |
| 最小负数（绝对值最大） | 尾数取 $-1$，阶码 $+127$ | $-1 \times 2^{127}$ |
| 最大负数（绝对值最小） | 阶码 $-128$，规格化负尾数最接近 $-1/2$ 但 $-1/2$ 非规格化，最低位改 1 | $-(2^{-1} + 2^{-n}) \times 2^{-128}$ |
| 最小正数 | 尾数 $1/2$，阶码 $-128$ | $(1/2) \times 2^{-128}$ |
| 最大正数 | 尾数全 1，阶码 $+127$ | $(1 - 2^{-n}) \times 2^{127}$ |

```text
        下溢（按 0 处理）       ←———— 可表示范围（内部全是离散点）————→       上溢（出错处理）
 ————┬—————————————————┬——————————┬—————————┬—————————————————┬————
   -1×2^127    -(1/2+2^-n)×2^-128      0       (1/2)×2^-128    (1-2^-n)×2^127
```

       * 阶码超过 $+127$，双符号位呈 $01$，**上溢**——超出表示范围，进入出错处理（数轴负方向超出最大负数同为上溢）。

       * 阶码小于 $-128$，形式为 $10$，**下溢**——计算机中直接按 0 处理即可。

       * > **结论**：上溢必须当错误处理，下溢可当 0 处理；判断依据是阶码是否越出 $[-128, +127]$。

   * **减法例题串联全流程**

       * 求 $x - y$（阶码 3 位、尾数 6 位、双符号位补码）：先求阶差（补码加法），结果 $-1$，x 阶码加一、尾数右移一位完成对阶。

       * 尾数做减法＝加 $[-S_y]_补$，符号位变成 $10$——**尾数溢出**，真正的符号位是 1（负数），右规一位、阶码加一即得最终补码结果。

       * > **提示**：区分两种"溢出"——尾数溢出（双符号位 01/10）靠右规消化，不代表浮点数出问题；浮点数溢出指整个值超出可表示范围，上溢要出错处理。

## 算术逻辑单元与快速进位链

   * **ALU 的外特性**

       * > **定义**：算术逻辑单元（Arithmetic and Logic Unit，ALU）是把算术运算、逻辑运算电路集成在一起的部件；ALU 再与控制器集成构成 CPU。

       * 输入 $A_i$、$B_i$ 为参加运算的数据，结果由 $F$ 输出；控制端 $K$ 决定本次做哪种运算（算术还是逻辑、定点还是浮点中的哪一种）。

```text
        ┌─────────┐
 Ai ──→ │         │ ──→ F    运算结果输出
 Bi ──→ │   ALU   │
        │         │
 K  ──→ │         │          K：控制端，决定本次做哪种运算
        └─────────┘
```

       * ALU 是**组合逻辑电路**，没有记忆功能，输入消失输出即消失；输入端要接寄存器、输出端也要接寄存器来保存并稳定结果。

       * 实例 74181：四位 ALU，能实现四位数的算术与逻辑运算；控制端 M 低电平为算术运算、高电平为逻辑运算，$S_0 \sim S_3$ 四位编码选择具体运算。

   * **进位表达式**

       * 全加器每位三个输入（两位数据 + 低位进位）、两个输出（本位和 $S_i$、向高位进位 $C_i$）。

       * 进位化简（重复 $A_iB_iC_{i-1}$ 项合并提取公因式）：

$$C_i = A_iB_i + (A_i + B_i)\,C_{i-1} = D_i + T_iC_{i-1}$$

       * **本地进位** $D_i = A_iB_i$：本位两数据全为 1 时自行产生进位。

       * **传送条件** $T_i = A_i + B_i$：其为 1 时低位进位直传，$C_i = C_{i-1}$。

       * 和 $S_i$ 依赖 $C_{i-1}$：$A_i$、$B_i$ 随时可从寄存器取得，而 $C_{i-1}$ 须由低位先产生——**进位产生速度决定加法器速度**。

   * **串行进位链**

       * > **定义**：进位链是加法器中传送进位的电路；串行进位链中进位以串行方式逐级向前传送。

       * 四位逐级式：$C_0 = D_0 + T_0C_{-1}$，$C_1 = D_1 + T_1C_0$，$C_2 = D_2 + T_2C_1$，$C_3 = D_3 + T_3C_2$（$C_{-1}$ 为更低位的进位）。

       * 与非门实现：用德摩根定律把每级拆成两级与非——先 $T_i$ 与 $C_{i-1}$ 与非，再与 $D_i$ 的非做与非得 $C_i$；每个进位需两个门延迟。

       * 速度账：产生 $C_0$ 需 $2t_y$，$C_1$ 需 $4t_y$，四个进位共 $8t_y$；n 位时最高位进位需 $2n \cdot t_y$，而全部进位产生后和才能产生。

       * > **结论**：串行进位链是加法器速度的瓶颈；改进方向是并行进位链，分**单重分组跳跃进位链**与**双重分组跳跃进位链**两类。
