# 高速缓冲存储器：映射、替换与辅助存储器

## 直接映射（Direct Mapping）

* **直接映射（Direct Mapping）**

    * > **定义**：主存中任意一个给定的块，只能装载到某一个指定的 Cache 块当中。

    * 做法：拿 Cache 存储主体作"尺子"去度量主存，把主存主体划分成若干个与 Cache 存储体大小相等的区——每个区的字块数与 Cache 的字块数相等，每个区内的字块都从 0 号编到 $2^7 - 1$。

    * 区内块号直接锁死位置：任何一个区的第 0 块只能放进 Cache 的字块 0，第 1 块只能放进 Cache 的第 1 块。

    * 主存地址按映射需要分成三部分：区号（$t$ 位）＋ 对应 Cache 字块地址的区内块号 ＋ 块内偏移地址。

    * 标记（tag）里存的是区号：Cache 第 0 块装载的可能是主存任何一个区的第 0 块，必须靠区号区分它到底是哪个区的。

    * 命中判定：CPU 给出主存地址后，按区内块号直接定位到指定 Cache 块，把该块的标记（区号）与地址给出的区号比较——两者相同即命中；不同即未命中，说明该块还没有被装入 Cache。

    * 优点：结构非常简单、速度也快——地址变换过程中可以根据主存块号直接找到相应的 Cache 块。

    * 缺点：Cache 利用率可能很低，字块调入时冲突概率非常大。

    * 极端例子：第 0 区第 0 块已调入 Cache 块 0，其余 Cache 块（块 1 到 $2^7-1$）全部空闲；程序跳转要用到块 $2^7$（第 1 区的第 0 块）时，按规则它只能放入块 0——尽管其他块都空着也不能用，第 0 区第 0 块被迫从 Cache 退出。

    * > **易错点** ⚠️：直接映射下 Cache 其他空闲块不能救急——主存块的去位只由区内块号决定，哪怕目标块正被占用也只能替换它。

## 全相联映射（Fully Associative Mapping）

* **全相联映射（Fully Associative Mapping）**

    * > **定义**：主存中任何一个块可以被放入 Cache 的任何一个块当中——主存字块 0 可以放到 Cache 任何一个块的位置上。

    * 与直接映射的对照：直接映射是"每个缓存块与若干主存块相对应，但每个主存块只能与一个缓存块相对应"；全相联正好走向另一个极端。

    * 优点：Cache 利用率高——任何块要从主存调入，只要 Cache 中还有空闲字块就可以调入进来。

    * 代价一（比较范围）：调入的块可能在 Cache 任何一块中，主存字块标记要与 Cache 中**所有块**的标记同时比较——有相等即命中，全不相等即未命中、可能触发替换；电路比较复杂，速度也比较慢。

    * 代价二（比较位数）：除块内地址之外，主存地址剩余的部分——区号和区内块号——都要保存到 Cache 的标记中；比较时要对 $t + c$ 位，比较器的长度也比较长。

## 组相联映射（Set Associative Mapping）

* **组相联映射（Set Associative Mapping）**

    * > **定义**：主存中的一个块可以放到 Cache 当中**指定的几个块**里——给定的一个块只能放进给定的一个组，组内的位置任选；是直接映射与全相联映射的折中。

    * 结构：先把 Cache 分成块，块再分成若干个组，每个组里可以放四块、八块甚至十六块。

    * 主存一侧做法与直接映射相似：把主存字块分区，每个区大小与 Cache 总容量相同——Cache 分成多少组，主存每个区的内部结构就与它对应。

    * 映射规则：主存块在区内的编号直接决定它装入 Cache 的哪个组——区内第 0 块可放到 Cache 第 0 组的任何一个位置；设内存块号为 $j$，按模 $Q$ 求余（$Q$ 为 Cache 分组数），余数 $i$ 即区内编号，该块映射到缓存第 $i$ 组的任何一块。

    * 对比直接映射的优势：一个块有多个位置，即使其中一个被占用，另一个空位也能调入，冲突减少。

    * 对比全相联的优势：只需由区内块号找到给定的组，把该组几个块的标记与区号比较即可，不需要与每个 Cache 块的标记比较，比较数量小得多。

    * 硬件：电路结构比较简单——如每组两块只需两个比较器，二者并行地把组内标记与主存字块标记比较，只要有一个相等即命中。

    * 综合评价：结构比直接映射复杂但比全相联简单得多、复杂度可接受；速度比较快，Cache 利用率也比较高——因此是现代计算机中 Cache 映射的常用方法。

    * 两个极端情形：Cache 全部块分成一组 → 组相联退化为全相联；每组只有唯一一块 → 组相联退化为直接映射。

    * 多层次 Cache 中的分工：靠近 CPU 的层次要求高速度，用直接映射或路数较少的组相联；中间层次用组相联（如两路、四路组相联）；距 CPU 最远的层次用全相联——距离越远，对速度的强调越低、对 Cache 利用率的强调越高。

## 三种映射方式对照

| 映射方式 | 映射规则 | 优点 | 缺点 |
| :--- | :--- | :--- | :--- |
| 直接映射 | 某一内存块只能固定映射到某一个缓存块上 | 结构简单、速度快 | 不灵活，冲突概率大，Cache 利用率低 |
| 全相联映射 | 某一内存块能映射到任意一个缓存块当中 | Cache 利用率比较高 | 成本高、速度慢 |
| 组相联映射 | 某一主存块能映射到给定的几个 Cache 块当中 | 速度比较快，Cache 利用率也比较高 | 复杂度介于两者之间，但可接受 |

## 替换算法（Replacement Algorithm）

* **替换算法**

    * > **定义**：当可以放入某内存块的 Cache 位置全部被占用时，选择哪一个 Cache 块从 Cache 中退出的方法。

    * 触发前提：按映射规则放入内存块时，可放入的位置都被占用、没有位置可存放，必须替换出一个 Cache 块。

### 先进先出算法

* **先进先出（First-In First-Out，FIFO）**

    * 思想：最先被放入 Cache 的那个块，CPU 已经用完了、或者在不久的将来不会再利用它的信息，所以让它被替换出去。

    * 缺陷（床头柜类比）：书柜相当于内存，床头柜相当于 Cache——床头柜放满后按 FIFO 换出最早放入的书，而那本书可能恰是常翻的工具书或喜欢的书，不久又要用。

    * 结论：FIFO 并不能很好地体现程序的局部性原理。

### 近期最少使用算法

* **近期最少使用（Least Recently Used，LRU）**

    * 思想：替换出去的应是 CPU 不再用的块——即 Cache 所有块中，CPU 读取或写入该块的时刻距离现在最长的那个块；近期使用得最少的块，将来可能就不用了，或即使用也要很长时间之后。

    * 评价：比较好地体现了程序的局部性原理，应用比较广。

## 辅助存储器（Auxiliary Storage）

* **辅助存储器**

    * > **定义**：用来保存程序、数据、文档和音像资料的存储器。

    * > **注意**：辅存不能直接与 CPU 进行信息交换——程序要运行、数据要被使用，必须先调入主存储器，CPU 经过主存才能对指令、数据或文档进行读写。

    * 最常用的辅助存储器是磁表面的辅助存储器。

## 磁表面存储器的技术指标

* **记录密度**

    * 道密度：硬盘沿径向方向上单位长度有多少条磁道。

    * 位密度：单位长度的磁道上保存多少位二进制信息。

    * > **易错点** ⚠️：磁盘各磁道是同心圆、周长不同，越往外的磁道位密度越低。

* **存储容量**：按"盘面数 × 每面磁道数 × 每条磁道存放的二进制信息位数"相乘计算。

    * $$存储容量 = 盘面数 \times 每面磁道数 \times 每条磁道存放的二进制信息位数$$

* **平均寻址时间**：由寻道时间与等待时间两部分组成。

    * $$平均寻址时间 = 寻道时间 + 等待时间$$

    * 寻道时间：读写头沿磁盘表面径向移动、找到指定磁道所需的时间。

    * 等待时间：找到指定磁道后，读写头停止运动、磁盘旋转，等待指定扇区转到磁头下面所需的时间。

    * 计算存取速度时，一部分时间是寻址，另一部分时间是读写头的读写时间。

* **数据传输率**：与位密度有关——指定磁道转到磁头下方后磁头开始读写，磁道离开磁头读写即结束；用位密度与旋转速度相乘计算。

* **误码率**：出错的信息位数与读出信息总位数之比。

## 磁记录原理

* **写入（磁化方向记录 0 / 1）**

    * 读写头上有一个线圈；写操作时线圈通不同方向的电流，在铁芯内产生不同方向的磁通。

    * 该磁场对磁体表面的磁层进行磁化，磁化方向的不同用来区分写入的是 0 还是 1。

* **读出（感应电势判别 0 / 1）**

    * 读的过程中磁层是运动的——硬盘旋转、磁带转动带动磁层移动。

    * 磁层上的磁场经过读写头切割磁力线，磁通变化使读线圈上产生电流、感应电势发生变化；根据电势变化即可确认磁载体中保存的是 0 还是 1。

## 硬磁盘存储器

### 磁头与盘片的分类

* **按磁头是否固定划分**

    * 固定磁头：磁头不动、盘片旋转——每个磁道都需要一个磁头，磁头数量庞大；但速度快（不需要磁头径向移动寻道，只需等待扇区转到磁头下即可读写），结构非常复杂。

    * 移动磁头：每个盘面上有一个磁头，可沿磁盘径向移动——常用的方式。

* **按盘片是否可更换划分**

    * 可换盘 / 固定盘两种；现在常用的是固定盘——不能随意打开硬盘驱动器取出盘片，一旦取出沾上灰尘，盘片就报废、不能再用。

### 结构与工作原理

* **组成链路**：主机通过总线连磁盘控制器，磁盘控制器连磁盘驱动器，由磁盘驱动器驱动盘组。

       └──────┘        └──────────────┘                 └──────┬───────┘

* **磁盘驱动器**：核心是磁盘组，信息保存在盘面上；盘组固定在主轴上，传动机构带动主轴和各盘片旋转。

* **磁头定位**：磁盘高速旋转后磁头悬浮在盘面上；磁头由小车推动沿径向移动，小车由音圈电机控制——控制器送来目标磁道信息，音圈电机控制小车左右移动读写头。

* **闭环控制**：音圈电机测量小车移动速度送回控制端，同时对读写头做位置控制，整个控制构成闭环、非常精确。

* **磁盘控制器**：接收主机命令并转换成对磁盘驱动器的控制命令；实现主机与驱动器之间数据格式的转换，控制驱动器读写；实质上就是主机与磁盘驱动器之间的接口——对主机经总线连接，同时直接控制硬盘。

* **盘片材质**：一般采用硬质的铝合金结构。

## 软盘

* **软盘与硬盘的对比**

| 对比项 | 硬盘 | 软盘 |
| :--- | :--- | :--- |
| 速度 | 快得多 | 速度很低，已退出现代计算机市场 |
| 磁头 | 有固定、活动两种方式 | 都是活动磁头，经读写口在盘面移动，找指定磁道、扇区读写 |
| 读写方式 | 读写头悬浮在盘面，磁头与盘面之间隔着一层高速空气流 | 磁头直接接触盘片 |
| 盘片 | 固定盘盘组，大部分不能更换 | 塑料基片、塑料外壳，需要时可打开外壳更换盘片 |
| 价格 | 贵得多 | 很便宜 |
| 环境 | 要求非常苛刻，盘面落一粒灰尘都会损伤读写头 | 工作环境没那么苛刻 |

* **三寸软盘结构要点**：内为盘片，中间主轴孔供驱动器主轴压入后带动盘片旋转；外层塑料壳是保护套；衬里清洁材料由聚酯薄膜（一种塑料）制成。

* **写保护口**：口上有一个可上下推的小塑料块——写保护后只能读、不能写。

* **读写口**：形状是腰形的（中间直、两边圆）；三寸盘上一般由金属片保护，只在读写时滑开。

## 光盘存储器

* **光盘存储器**

    * > **定义**：采用光存储技术、利用激光进行读出和写入的存储器。

    * 按介质代际分两种：第一代采用非磁性介质，写入一次性的、不可擦写；第二代采用磁性介质，可擦写、可多次写入。

    * 按使用方式分两种：只读型——厂家做好只能读不能写，或空白盘烧写后信息不能改；可擦可写型——采用磁光材料。

    * 读写机理：一次性或只读型光盘采用热作用，用激光对盘面进行烧灼。

    * 光的存储与传输已被利用；光在计算与控制上的应用是光计算机要解决的问题。
