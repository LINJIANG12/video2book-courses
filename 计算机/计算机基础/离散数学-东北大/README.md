# 离散数学（东北大学公开课）（69 讲）

东北大学《离散数学》全 69 讲，是计算机专业的数学地基课。课程按经典四篇组织：数理逻辑（命题逻辑、谓词逻辑与推理理论）、集合论（集合、关系、函数与计数）、代数结构（群环域、格与布尔代数）、图论（连通性、矩阵表示与树）。讲法循循善诱，定义—定理—例题三段推进，69 集整编为 4 册模块全书与 8 篇主题复习笔记。

## 怎么学

- **按四篇走，不要跳**：数理逻辑是「形式化语言」的入门训练，集合关系是代数结构的预备，图论相对独立可后置，但前三篇的符号体系一以贯之。
- **逻辑篇抓「范式与推理规则」**：命题公式的范式变换、谓词逻辑的量词处理是推理题的全部工具，笔记 01/02 把规则表整理成了速查形式。
- **关系篇抓「性质与闭包」**：自反/对称/传递的判定与闭包构造是等价关系、偏序的前提，笔记 04 有逐性质判定的对照表。
- **代数篇从例子记定义**：群环域的定义抽象，先记住具体例子（整数加群、模 n 剩余类）再回定义，笔记 05/06 按这条线组织。
- **图论篇「定义+矩阵」双轨**：欧拉图、哈密顿图、最短通路的判定条件配邻接矩阵表示一起记，笔记 07/08 是本篇的速查入口。
- **考前只看 `notes/`**：8 篇笔记按主题重组，定理条件与反例并排放置，适合期末与考研基础阶段快速过。
