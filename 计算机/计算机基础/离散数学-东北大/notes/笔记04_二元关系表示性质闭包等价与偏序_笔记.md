# 二元关系：表示、性质、闭包、等价与偏序

## 二元关系的定义与表示

   * **二元关系**

       * > **定义**：设 A、B 是集合，若 $R\subseteq A\times B$，则 R 是从 A 到 B 的二元关系；特别地，若 $R\subseteq A\times A$，则 R 是 A 上的二元关系。二元关系简称关系。

       * 等价的组成定义：任何一个由序偶组成的集合都可以称为二元关系——具体是哪几个序偶不重要，重要的是"序偶的集合"这个身份。

       * 一个序偶属于关系有两种写法：$\langle x,y\rangle\in R$ 叫后缀表示法；$xRy$ 叫中缀表示法，读作"x 与 y 有 R 关系"。

       * 例：大写字母集与五单位代码集之间的一一对应是二者笛卡尔积的子集；$A=\{1,2,3,4\}$ 上的小于等于关系含 $4+3+2+1=10$ 个序偶，是 $A\times A$ 的子集。

       * 实数集上的 $\le$、$\ge$、$=$、$x^2+y^2=4$ 都是关系：序偶看作平面上的点，点集构成图中的线与圆。

   * **定义域（domain）与值域（range）**

       * > **定义**：$\operatorname{dom}R=\{\,x\mid(\exists y)(\langle x,y\rangle\in R)\,\}$ 叫 R 的定义域；$\operatorname{ran}R=\{\,y\mid(\exists x)(\langle x,y\rangle\in R)\,\}$ 叫 R 的值域。

       * 定义域由 R 中全部序偶的第一元素组成，值域由全部第二元素组成；例：由十个序偶组成的 A 上关系，$\operatorname{dom}R=\operatorname{ran}R=\{1,2,3,4\}$。

   * **关系的本质是集合**

       * 关系是笛卡尔积的子集、序偶的集合，因此交、并、差、对称差、补运算可以原样搬过来用。

       * 例：R 是同乡关系、S 是同性关系，则 $R\cup S$ 是"或者同乡或者同性"，$R\cap S$ 是"既同乡又同性"，$R-S$ 是"同乡而不同性"，$\sim R$ 是"不是同乡"，$R\oplus S$ 是"同乡而不同性，或者同性而不同乡"。

   * **关系的四种表示方法**

       * 枚举法：把关系中所有序偶一一列举出来写在大括号内。

       * 谓词公式法：用竖线后的谓词公式刻画什么样的序偶能进集合，如 $R=\{\langle x,y\rangle\mid x<y\}$。

       * 关系图法：用小圆圈节点表示元素，$\langle x,y\rangle\in R$ 时从第一元素向第二元素引一条有向边。

       * 关系矩阵法：$|A|=m$、$|B|=n$ 时得 $m\times n$ 阶矩阵 $M_R$，$\langle a_i,b_j\rangle\in R$ 则 $r_{ij}=1$，否则 $r_{ij}=0$。

       * A 上关系的关系图只需一组节点：$\langle x,x\rangle$ 型序偶画成指向自己的环，其余序偶照画有向边；其关系矩阵用 A 中元素同时做行标和列标。

   * **空关系**

       * > **定义**：空集包含于任何笛卡尔积，因此 $\varnothing$ 也是从 A 到 B（或 A 上）的关系，称为空关系。

       * 关系图中只有节点、没有边；关系矩阵所有元素均为 0。

       * 性质归属：不是自反的；是反自反、对称、反对称、传递的。

   * **完全关系（全域关系）**

       * > **定义**：$A\times B$（或 $A\times A$）本身作为从 A 到 B（或 A 上）的关系，称为完全关系，也叫全域关系。

       * 关系图：每个节点都有指向自己的环，任意两个节点之间都有成对出现的边；关系矩阵所有位置均为 1。

       * 性质归属：自反、对称、传递；不反对称。

   * **恒等关系 $I_A$**

       * > **定义**：$I_A=\{\,\langle x,x\rangle\mid x\in A\,\}$，只能定义在一个集合上，每个序偶的第一、第二元素是同一个元素。

       * $A=\{1,2,3\}$ 时 $I_A=\{\langle 1,1\rangle,\langle 2,2\rangle,\langle 3,3\rangle\}$；矩阵主对角线为 1、其余全 0；关系图每个节点只有一条指向自己的环，再无其他边。

       * 性质归属：自反、对称、反对称、传递。

## 关系的五个性质

> **注意**：五条性质讨论的都是定义在一个集合上的关系，即从 A 到 A 的关系。

   * **自反性**

       * > **定义**：对任何一个 $x\in A$ 都有 $\langle x,x\rangle\in R$（即 $xRx$），则 R 是 A 上的自反关系。

       * 谓词公式：$\forall x\,\big(x\in A\rightarrow\langle x,x\rangle\in R\big)$；实数上的小于等于关系 $\le$ 自反。

       * 有向图：每个节点都有指向自己的环——A 中所有元素都要有环，缺一不可；矩阵：主对角线全为 1。

   * **反自反性**

       * > **定义**：对任意 $x\in A$ 都有 $\langle x,x\rangle\notin R$，则 R 是 A 上的反自反关系。

       * 谓词公式：$\forall x\,\big(x\in A\rightarrow\langle x,x\rangle\notin R\big)$；实数上的小于关系 $<$ 反自反，人群中的父子关系反自反——没有人是自己的父亲。

       * 有向图：每个节点都无环；矩阵：主对角线全为 0。

       * > **易错点**：⚠️ 不是自反的关系不一定就是反自反的，反之亦然——存在既不自反也不反自反的关系：部分节点有环、部分无环，两个定义都不满足。

   * **对称性**

       * > **定义**：对 A 中任何两个元素 x、y，有 $xRy$ 必有 $yRx$，则 R 是 A 上的对称关系。

       * 谓词公式：$\forall x\,\forall y\,\big((x\in A\wedge y\in A\wedge xRy)\rightarrow yRx\big)$；邻居关系、朋友关系是典型的对称关系。

       * 有向图：不同节点之间可以无边，但有边必成对（方向相反的两条）；矩阵：沿主对角线对称的位置取值相同。

   * **反对称性**

       * > **定义**：对 A 中任何两个元素 x、y，若有 $xRy$ 并且有 $yRx$，则一定有 $x=y$，则 R 是 A 上的反对称关系。

       * 两种等价谓词公式：$\forall x\,\forall y\,\big((xRy\wedge yRx)\rightarrow x=y\big)$ 与 $\forall x\,\forall y\,\big((x\neq y\wedge xRy)\rightarrow\langle y,x\rangle\notin R\big)$；实数上的 $\le$ 是典型的反对称关系。

       * 有向图：不同节点之间可以无边，有边至多一条；矩阵：沿主对角线对称的两个位置至多一个 1，不可能同时为 1。

       * > **易错点**：对称与反对称并不对立——空关系、恒等关系既是对称关系又是反对称关系。

   * **传递性**

       * > **定义**：对任何三个元素 x、y、z，有 $xRy$ 和 $yRz$ 就有 $xRz$，则 R 是 A 上的传递关系。

       * 谓词公式：$\forall x\,\forall y\,\forall z\,\big((xRy\wedge yRz)\rightarrow xRz\big)$；传递性在图和矩阵上不易直接看出，必须按定义逐链检查。

       * 前件为假时蕴含式为真：凑不出 $xRy\wedge yRz$ 链条的关系一律算传递——判断传递性要找的是"前件为真而后件为假"的反例。

       * 现成结论：空关系、恒等关系、完全关系都是传递的。

       * 只含一个序偶 $\langle x,y\rangle$（$x\neq y$）的关系也传递：R 中没有以 y 为第一元素的序偶接第二段，任何三元组的前件都为假，每个蕴含项都为真。

| 性质 | 有向图特征 | 矩阵特征 |
| :--- | :--- | :--- |
| 自反 | 每个节点都有指向自己的环 | 主对角线全为 1 |
| 反自反 | 每个节点都无环 | 主对角线全为 0 |
| 对称 | 不同节点间有边必成对 | 沿主对角线对称位置取值相同 |
| 反对称 | 不同节点间至多一条边 | 对称位置至多一个 1 |
| 传递 | 图上不易看出，按定义检查 | 按定义检查 |

## 关系的复合与幂

   * **关系的复合 $R\circ S$**

       * > **定义**：R 是从 X 到 Y 的关系，S 是从 Y 到 Z 的关系，则 $R\circ S=\{\langle x,z\rangle\mid x\in X\land z\in Z\land\exists y\,(y\in Y\land\langle x,y\rangle\in R\land\langle y,z\rangle\in S)\}$ 是一个从 X 到 Z 的关系，称为 R 和 S 的复合。

       * 复合运算用空心圆圈 $\circ$ 表示；两个关系能复合的前提是 R 的终点集与 S 的起点集必须是同一个集合——中间那座桥得架在同一条河上。

       * 引例：r 是兄妹关系、s 是母子关系，a 是 b 的哥哥、b 是 c 的母亲，复合 $r\circ s$ 得到的就是 a 与 c 的舅舅外甥关系。

       * 复合不满足交换律：同一对关系把顺序一颠倒，$S\circ R$ 中可能找不到公共的桥墩，结果为空。

   * **复合的三种算法**

       * 有向图法（俗称"过河拆桥法"）：把中间元素当桥墩，先沿 R 上桥、再沿 S 下桥，把桥一拆，$R\circ S$ 里直接连一条从 x 到 z 的边。

         ```text
                   R                S
              x ────────▶ b ────────▶ z
                        （桥墩）

              R∘S：x ─────────────────▶ z
         ```

       * 枚举法：拿 R 里的每个序偶到 S 里找第一元素相同的序偶去配对——R 中 $\langle 1,2\rangle$ 配 S 中 $\langle 2,1\rangle$，$R\circ S$ 中就有 $\langle 1,1\rangle$。

       * 谓词公式法：实质就是函数的代入——R 把 x 变换为 $x^2+3x$，S 把 y 继续变换为 $2y+3$，则 $R\circ S$ 的第二元素为 $2(x^2+3x)+3=2x^2+6x+3$。

       * 另有矩阵法，要用到关系矩阵的逻辑运算。

   * **复合的运算性质**

       * 结合律：$R\circ(S\circ T)=(R\circ S)\circ T$。

       * 对并是等式：$R\circ(S\cup T)=(R\circ S)\cup(R\circ T)$。

       * 对交只有包含：$R\circ(S\cap T)\subseteq(R\circ S)\cap(R\circ T)$。

       * 证明思路：从左侧任取 $\langle a,c\rangle$，把 $\langle b,c\rangle\in S\cap T$ 拆成两个合取、用幂等律复制公共前提 $b\in B$ 与 $\langle a,b\rangle\in R$，再由存在量词对合取"可分配、不可提取"——拆开的两个存在量词各拿各的 b，未必踩到同一个桥墩，所以反向一般推不回去。

       * 恒等关系充当复合的单位元：$R\circ I_B=I_A\circ R=R$（$I_A$、$I_B$ 分别是 A、B 上的恒等关系）。

   * **关系的幂 $R^n$**

       * > **定义**：$R\circ R$ 简写为 $R^2$，三个 R 复合简写为 $R^3$，n 个 R 复合简写为 $R^n$；特别定义 $R^0=I$，即 A 上的恒等关系。

       * 指数律：m、n 为非负整数时 $R^m\circ R^n=R^{m+n}$，$(R^m)^n=R^{mn}$——m 个接上 n 个合起来 $m+n$ 个；n 组、每组 m 个，一共 $mn$ 个。

       * 幂的图论含义：$\langle x,y\rangle\in R^k$ 当且仅当 R 的有向图上有一条从 x 到 y 的路径，路径上序偶（边）的个数恰好等于幂指数 k——这条结论是证明传递闭包最小性的钥匙。

         ```text
              a ──▶ b ──▶ c ──▶ d

              走两步：⟨a,c⟩ ∈ R²
              走三步：⟨a,d⟩ ∈ R³
         ```

## 逆关系

   * **逆关系 $R^{-1}$**

       * > **定义**：R 是从 A 到 B 的关系，把 R 中所有序偶的两个元素位置互换，得到一个从 B 到 A 的关系，称为 R 的逆关系；$\langle y,x\rangle\in R^{-1}$ 当且仅当 $\langle x,y\rangle\in R$。

       * 有向图上：把 R 的有向图中所有边的方向全部颠倒，得到的就是 $R^{-1}$。

       * 关系矩阵上：$R^{-1}$ 的关系矩阵就是 R 的关系矩阵的转置——$3\times 4$ 的矩阵转置一下即得。

   * **求逆的八条性质**

       * 逆的逆回到原点：$(R^{-1})^{-1}=R$——换两次位，回到原点。

       * 与并、交、差都可直接换位：$(R\cup S)^{-1}=R^{-1}\cup S^{-1}$，$(R\cap S)^{-1}=R^{-1}\cap S^{-1}$，$(R-S)^{-1}=R^{-1}-S^{-1}$。

       * 包含关系在求逆下保持：$R\subseteq S$ 当且仅当 $R^{-1}\subseteq S^{-1}$，证明套路是"换位——用假设——再换回来"。

       * 补与逆谁先谁后都一样：$(\bar R)^{-1}=\overline{R^{-1}}$，其中 $\bar R$ 是 R 的补集。

       * 复合的逆要倒序：$(R\circ S)^{-1}=S^{-1}\circ R^{-1}$——先复合再求逆，等于倒着复合回去。

       * > **易错点**：⚠️ $(R\circ S)^{-1}$ 写的是 $S^{-1}\circ R^{-1}$，不是 $R^{-1}\circ S^{-1}$，书写时最容易在这里顺手写反。

       * 对称的刻画：R 是 A 上的对称关系当且仅当 $R^{-1}=R$。

## 关系的闭包

   * **闭包**

       * > **定义**：R′ 是 R 的自反闭包 $r(R)$，当且仅当 R′ 满足三个条件：$R\subseteq R'$；R′ 是具有自反性的关系；R′ 是最小的——对 A 上另一个包含 R 的自反关系 R″，都有 $R'\subseteq R''$。

       * 对称闭包 $s(R)$、传递闭包 $t(R)$ 的定义照搬：包含 R 的最小的对称关系、包含 R 的最小的传递关系。

       * "最小"是灵魂：闭包不是随便找一个把 R 装进去的超集，而是在所有能补足性质的超集里挑包含序偶最少的那个。

   * **自反闭包与对称闭包**

       * $r(R)=R\cup I$，其中 I 是 A 上的恒等关系——恒等关系给每个元素都补上了自环；最小性：任何包含 R 的自反关系 R″ 必有 $I\subseteq R''$，于是 $R\cup I\subseteq R''$。

       * $s(R)=R\cup R^{-1}$。

   * **传递闭包**

       * 无穷并形式：$t(R)=R\cup R^2\cup R^3\cup\cdots$。传递性：若 $\langle x,y\rangle\in R^i$、$\langle y,z\rangle\in R^j$，则 $\langle x,z\rangle\in R^{i+j}\subseteq R'$。

       * 最小性靠路径结论：$\langle x,y\rangle\in R^i$ 给出一条 i 条边的链，这 i 个序偶都属于任何包含 R 的传递关系 R″，沿链一段一段传递得 $\langle x,y\rangle\in R''$，故 $R'\subseteq R''$。

       * 有限集定律：A 是有限集且元素个数为 n 时，$t(R)=R\cup R^2\cup\cdots\cup R^n$——不必算无穷次幂，至多算到 $R^n$ 即可。

       * 实算三形态：$R^3=\varnothing$ 时更高次幂全为空集（任何关系和空集复合结果都是空集）；$R^3=I$ 时各次幂按 $R,R^2,R^3$ 轮流循环出现；$R^3=R^2$ 时更高次幂都停在 $R^2$——三种情况都只需算到三次幂。

       * > **提示**：还可以基于 R 的关系矩阵，使用 Warshall 算法求传递闭包，可作扩展自学。

## 划分与覆盖

   * **覆盖与划分**

       * > **定义**：X 是非空集合，集合族 $A=\{A_1,A_2,\ldots,A_n\}$ 中每个 $A_i$ 都不是空集、$A_i\subseteq X$，且 $A_1\cup A_2\cup\cdots\cup A_n=X$，则称集合族 A 是 X 的一个覆盖。

       * > **定义**：A 是 X 的一个覆盖，若 A 中任意两个不同的元素 $A_i\cap A_j=\varnothing$，则称 A 是 X 的一个划分；每个 $A_i$ 称为这个划分的一个划分类。

       * 划分一定是覆盖，但覆盖不一定是划分。

       * 最小划分：划分块数最少，只有一个划分块且该划分块就是 X 本身；最大划分：划分块数最多的那种划分。

   * **交叉划分**

       * > **定义**：A 和 B 都是 X 的划分，任取 $A_i\in A$、$B_j\in B$，由所有交集 $A_i\cap B_j$ 所组成的集合 C 就是 A 与 B 两种划分的交叉划分。

       * 例：全体学生集上"男生／女生"与"辽宁籍／非辽宁籍"两种划分，交叉出辽宁籍男生、辽宁籍女生、非辽宁籍男生、非辽宁籍女生四块——任何两块交集为空，并起来恰是 X。

## 等价关系与等价类

   * **等价关系**

       * > **定义**：R 是集合 A 上的关系，若 R 同时满足自反性、对称性和传递性，则 R 是 A 上的等价关系；$\langle a,b\rangle\in R$（简记 $aRb$）称"a 与 b 等价"。

       * 模三同余是典型的等价关系：$\langle x,y\rangle\in R\iff x\bmod 3=y\bmod 3$，判断序偶在不在 R 里只看这一条判据，不必逐个枚举体力活。

       * 有向图结论：等价关系的有向图由若干个独立子图构成，每一个独立子图都是完全关系图。

       * 计数例：三元素集上不同的等价关系共 $1+3+1=5$ 种——三个元素各成一图只有 1 种，拼成两图（两元素抱团、一元素独走）有 3 种，全在同一图只有 1 种。

       * 图例（模三同余）：

         ```text
              1 --- 4
               \    /
                \  /
                 \/
                  7

              2 --- 5        3 --- 6
         ```

         读图：连线代表成对出现的双向边，各节点的自环从略；整张图断成三块互不相连的独立子图，每块内部两两全连。

   * **等价类 $[a]_R$**

       * > **定义**：R 是 A 上的等价关系、$a\in A$，由 $[a]_R=\{x\mid x\in A,\ xRa\}$ 确定的集合称为由 a 构成的 R 等价类。

       * 判定式：$x\in[a]_R\iff aRx$——一个元素进不进 a 的等价类，只看它跟 a 有没有 R 关系。

       * > **提示**：同一个等价类有很多名字——1、4、7 两两等价时 $[1]_R=[4]_R=[7]_R=\{1,4,7\}$ 是同一个类的三种写法，别以为三个不同的数各有一个类。

       * 图上读法：每一个独立子图上的节点构成一个等价类，独立子图的个数就等于不同等价类的个数。

       * 模三同余的三个类：$[1]_R=[4]_R=[7]_R=\{1,4,7\}$（余 1）、$[2]_R=[5]_R=\{2,5\}$（余 2）、$[3]_R=[6]_R=\{3,6\}$（余 0）。

   * **等价类的六条性质**

       * 同类必等价：$x,y\in[a]_R\Rightarrow\langle x,y\rangle\in R$——$aRx$ 对称翻面成 $xRa$，加 $aRy$ 传递一步到位。

       * 不等价则类不相交：$[a]_R\cap[b]_R=\varnothing\iff\langle a,b\rangle\notin R$——两个方向都用反证法，靠对称加传递推出矛盾。

       * 类相等当且仅当元素等价：$[a]_R=[b]_R\iff aRb$。

       * 每个元素都属于且仅属于一个等价类：自反性保证 $a\in[a]_R$；若还有 $a\in[b]_R$，则 $aRb$，由上一条知所谓"另一个类"其实就是同一个类。

       * 任意两个等价类要么相等、要么交集为空，没有第三种可能。

       * 所有等价类构成的集合是 A 的一个划分——所有类的并是 A（盖得住），不同类交空（不重叠）。

   * **商集 $A/R$**

       * > **定义**：R 的所有等价类构成的集合称为 A 关于 R 的商集，记作 $A/R$——集合的一种除运算，装的是一筐 A 的子集，每个子集是一个等价类。

       * 定理：集合 A 上的等价关系 R 决定 A 的一个划分，这个划分就是商集 $A/R$——每个类是 A 的非空子集、不同类交空、所有类的并覆盖 A，三点齐备。

       * 模三同余：$A/R=\big\{\{1,4,7\},\{2,5\},\{3,6\}\big\}$。

       * 三元素集练习：$X/R_1=\big\{\{1\},\{2\},\{3\}\big\}$，$X/R_2=\big\{\{1\},\{2,3\}\big\}$，$X/R_3=\big\{\{1,2,3\}\big\}$——三个商集是三种粗细不同的分法。

   * **从划分造等价关系**

       * 构造法：把划分的每个块 $A_i$ 还原为完全关系 $A_i\times A_i$，再对所有块作并运算 $R=\bigcup_i A_i\times A_i$，则商集 $X/R$ 恰好等于该划分。

       * 传递性的关键一步：不同划分块没有公共元素，b 同时出现在两个块里说明那两块本是同一块，故 a、b、c 全来自同一个划分块，$aRc$ 成立。

       * 定理：集合 X 的一个划分可以确定 X 上的一个等价关系——集合的分堆方式与它上面的等价关系可以互相换算。

## 相容关系

   * **相容关系**

       * > **定义**：r 是集合 X 上的关系，若 r 具有自反性与对称性（传递性不要求），则 r 是 X 上的相容关系。

       * 词例：七个英文单词上"含有相同字母"的关系自反、对称；但 fly 与 any（同含 y）、fly 与 evil（同含 l）都相容，any 与 evil 却没有任何相同字母——传递链断掉，它仅是相容关系，不是等价关系。

   * **简化图与简化矩阵**

       * 图：自反的环统统不用画；对称的成对双向边用一条无向直线代替——一条线顶一对方向相反的边。

       * 矩阵：对角线全 1、沿对角线对称，故用一个不含主对角线的下三角矩阵代替整个关系矩阵。

       * 简化的目的很单纯：方便快速画出相容关系的关系图和关系矩阵。

   * **相容类、最大相容类与完全覆盖**

       * > **定义**：C 是 X 的子集，若 C 中任何两个元素 x、y 都有 $\langle x,y\rangle\in r$（x 与 y 具有相容关系 r），则子集 C 是 r 的一个相容类。

       * > **定义**：相容类 C 不能被其他相容类真包含，则 C 是一个最大相容类——再往里加入任何一个新元素，相容类的定义就保不住了。

       * 找法：在简化关系图中找最大完全多边形——含节点最多、且每个节点都与其他所有节点相连的多边形，其顶点构成的集合就是一个最大相容类。

       * 一至四个节点能构成的最大完全多边形：孤点、一条连线、三角形、四边形——共同点是内部两两全连、节点数已到顶。

       * > **定义**：由 r 确定的所有最大相容类作为元素构成的集合，称为 X 的一个完全覆盖，记作 $C_r(X)$。

       * 词例中四个最大相容类是 $\{x_1,x_2,x_3,x_4\}$、$\{x_3,x_4,x_5\}$、$\{x_1,x_7\}$、$\{x_6\}$——单独一个点也能构成最大完全多边形。

       * 轮形图例：

         ```text
              x1
             / | \
            /  |  \
          x2---x5---x4
            \  |  /
             \ | /
              \|/
               x3
         ```

         读图：$x_1,x_2,x_3,x_4$ 依次相连围成一圈，$x_5$ 居中与四点全连，此外再无别的连线；四个最大完全三边形给出 $C_{r'}(X)=\big\{\{x_1,x_2,x_5\},\{x_2,x_5,x_3\},\{x_3,x_4,x_5\},\{x_1,x_5,x_4\}\big\}$。

       * $x_5$ 出现在全部四个最大相容类里——最大相容类之间允许交叠，这和等价类"要么相等、要么不交"的脾气完全不同。

|  | 等价关系 | 相容关系 |
| :--- | :--- | :--- |
| 要满足的性质 | 自反、对称、传递 | 自反、对称（不要求传递） |
| 关系图结构 | 若干独立子图，每个都是完全关系图 | 每点有环；点间或无边、或成对边 |
| "类"的对应物 | 等价类 | 相容类、最大相容类 |
| 全部类拼成 | 商集 $A/R$，是一个划分 | 完全覆盖 $C_r(X)$，类之间可以交叠 |

## 三种特殊关系的性质拼装

   * **性质积木与三种特殊关系**

       * 五条性质像五块积木，三种特殊关系全是拿它们拼出来的：自反、对称、传递拼出等价关系；自反、对称拼出相容关系；自反、反对称、传递拼出偏序关系。

       * 关系一章的家底：表示方法一共四种（枚举法、有向图法、矩阵法、谓词公式法），性质一共五条（自反、反自反、对称、反对称、传递）。

       * 三种特殊关系的性质归属对照：

| 关系 | 自反 | 对称 | 反对称 | 传递 |
| :--- | :---: | :---: | :---: | :---: |
| 等价关系 | ✓ | ✓ | — | ✓ |
| 相容关系 | ✓ | ✓ | — | — |
| 偏序关系 | ✓ | — | ✓ | ✓ |

   * **读表要点**

       * 三种关系都以自反打底；等价与相容走"对称"一路，偏序独走"反对称"一路；传递性只有等价和偏序要求。

       * 今后再见到一种新关系，按表逐条核对它占不占，性质归属就不会乱。

## 偏序关系

   * **偏序关系与偏序集**

       * > **定义**：R 是集合 A 上的关系，若 R 具有自反性、反对称性和传递性，则 R 是 A 上的偏序关系，并称 $\langle A,\preceq\rangle$ 是一个偏序集。

       * $\preceq$ 泛指任何一个偏序关系，读作"先于等于"；实数上的小于等于、大于等于关系与整除关系 $|$ 都是偏序关系。

       * 关系图三特点：每个节点都有环（自反性决定）；不同节点之间可以没有边、有边至多一条（反对称性决定）；有 $\langle a,b\rangle$、$\langle b,c\rangle$ 必有 $\langle a,c\rangle$（传递性决定）。

   * **哈斯图**

       * > **定义**：偏序关系的关系图按三条规则简化后得到的简化图，称为偏序关系的哈斯图。

       * 规则一：每个节点都有环，环一律省去不画。

       * 规则二：不同节点间至多只有一条边，把序偶第一元素画在下方（或左方）、第二元素画在上方（或右方），靠位置关系反映次序，把箭头省掉。

         ```text
              b           b
              ^           |
              |   ==>     |
              a           a

          a --> b   ==>   a --- b
         ```

       * 规则三：传递性保证的直达边省掉——只画 a—b、b—c 对应的边，a—c 对应的边省去。

       * 例：$\{1,2,3\}$ 上小于等于关系的哈斯图是一条竖链；整除关系的哈斯图把所有能"搭桥"的边（如 1 到 4，因 1 整除 2、2 整除 4）全部省去。

         ```text
              3
              |
              2
              |
              1
         ```

   * **全序关系**

       * > **定义**：对 A 中的任意两个元素 a 和 b，都有 $a\preceq b$ 或 $b\preceq a$，则 R 是 A 上的全序关系。

       * 别名：线性关系、链关系——"链"这个别名与哈斯图里那条竖着的链条是同一个意象。

       * 偏序与全序的含义差：全序说任何两个元素均具有 R 关系（如 $\le$）；偏序说部分元素具有 R 关系——整除关系里 1 与 2、2 与 6、4 与 8 可比，2 与 3、5 与 7、7 与 9 就比不出先后。

   * **极大元与极小元**

       * > **定义**：$\langle P,\preceq\rangle$ 是偏序集、A 是 P 的子集，若 $a\in A$ 且在 A 中找不到一个 $b\neq a$ 使 $a\preceq b$，则 a 是子集 A 的极大元；对偶地，找不到 b 使 $b\preceq a$，则 a 是极小元。

       * 谓词公式：y 是极大元 $\iff y\in A\land\neg\exists x\,(x\in A\land x\neq y\land y\preceq x)$；极小元把不等号掉个头。

       * 直观：极大元"头顶上没有人"，极小元"脚底下没有人"。

       * 极大元、极小元不一定唯一；某一个元素完全可以既是极大元又是极小元。

       * 存在性：总是存在——哈斯图中处于最上层的元素是极大元，处于最下层的元素是极小元。

       * 例：自然数集上整除关系构成偏序集，取子集 $\{2,3,\ldots,9\}$：极大元是 5、6、7、8、9（A 中没有元素能被它们整除），极小元是 2、3、5、7（A 中没有元素整除它们）。

       * > **易错点**：⚠️ 极大元与极小元一定要在这个子集中寻找，不要到全集 P 中去寻找。

   * **最大元与最小元**

       * > **定义**：$\langle P,\preceq\rangle$ 是偏序集、A 是 P 的子集，若 $a\in A$ 且对任意 $b\in A$ 都有 $b\preceq a$，则 a 是 A 的最大元；对任意 $b\in A$ 都有 $a\preceq b$，则 a 是 A 的最小元。

       * 标准：极大元只要求"头顶上没有人"，最大元则要求"压住全部元素"，标准高得多。

       * 唯一性：若存在必唯一——设 a、b 都是 B 的最小元，则 $a\preceq b$ 且 $b\preceq a$，由反对称性 $a=b$；最大元同理。

       * 可能不存在：整除偏序集的子集 $\{2,\ldots,9\}$ 无最大元也无最小元——2 整除不了 3、5、7、9，也不存在被这八个元素全都整除的数。

       * 判据：只要 B 有唯一的极小元（或极大元），这个唯一的极小元（或极大元）才是最小元（或最大元），否则就没有——上例有四个极小元，所以没有最小元。

       * 同样必须在子集中寻找，不要到全集 P 中去找。

   * **上界与下界**

       * > **定义**：$\langle P,\preceq\rangle$ 是偏序集、A 是 P 的子集，若 $a\in P$ 且对任意 $b\in A$ 都有 $b\preceq a$，则 a 是 A 的一个上界；都有 $a\preceq b$，则 a 是 A 的一个下界。

       * > **易错点**：⚠️ 与极大极小、最大最小正好相反——找上界或下界要在全集中寻找，定义里写的是 $a\in P$ 而不是 $a\in A$。

       * 上界、下界可以不唯一，也可以不存在。

       * 例：幂集 $P(\{a,b,c\})$ 上定义包含关系，子集 A 中没有最大元，但到全集中找得到 A 的上界 $\{a,b,c\}$；$\varnothing$ 是 A 的最小元，也是 A 的下界。

       * 最大元（或最小元）如果存在，一定是子集的一个上界（或下界）；反过来不成立。

   * **上确界与下确界**

       * > **定义**：a 是 A 的一个上界，且对 A 的任意上界 b 都有 $a\preceq b$，则 a 是 A 的上确界——所有上界的最小者，即最小上界；对偶地，所有下界的最大者（最大下界）是 A 的下确界。

       * 上下确界若存在必唯一：上界可以有一堆，"上界里最小的那一个"若存在就只有一个。

| 元素 | 在哪里找 | 唯一性 | 存在性 |
| :--- | :--- | :--- | :--- |
| 极大元 / 极小元 | 子集 A 内 | 不一定唯一 | 总是存在（哈斯图最上层 / 最下层） |
| 最大元 / 最小元 | 子集 A 内 | 若存在必唯一 | 可能不存在 |
| 上界 / 下界 | 全集 P 内 | 可以不唯一 | 可能不存在 |
| 上确界 / 下确界 | 全集 P 内 | 若存在必唯一 | 可能不存在 |

## 函数

   * **函数（映射）**

       * > **定义**：f 是从 X 到 Y 的关系，若对任意的 $x\in X$ 都存在着唯一的 $y\in Y$ 使 $\langle x,y\rangle\in f$，则 f 是从 X 到 Y 的函数，或称变换、映射，记作 $f:X\to Y$。

       * 名词对位：那个唯一的 y 称为 x 的象，x 称为 y 的原象；X 称为 f 的定义域，Y 称为 f 的陪域；$f(X)$ 称为 f 的值域，记作 $R_f$；f 是从 X 到 X 的函数时，称 f 是定义在 X 上的函数。

       * 函数和一般关系的差别全在定义里的两个词——"任意"与"唯一"：每个定义域元素都必须有象，而且象只能有一个。

   * **函数判定实例**

       * $y=1/x$：$x=0$ 时在陪域 R 中找不到 0 的象，违反"每个元素都有象"，不是函数。

       * $x^2+y^2=4$：$x=0$ 时在陪域中找到 2 和 $-2$ 两个象，一个元素有两个象，不是函数。

       * $y=x^2$：每个 x 都有唯一的 $y=x^2$ 与之对应，是函数。

       * $y=\log x$：$x\le 0$ 时没有对数、找不到象，不是函数。

       * $y=\sqrt x$：$x<0$ 时找不到 x 的象，不是函数。

       * 违反定义的路径只有两条：某个 x 没有象；某个 x 的象不止一个。

   * **函数的矩阵**

       * 函数的矩阵每行有且仅有一个 1：某一行没有 1 说明存在元素无象，某一行有多个 1 说明存在元素多象，都违反函数定义。

       * 列没有任何限制：某一列整列没有 1 是允许的——该列对应的陪域元素没有原象，正是映内函数的情形；某一列有多个 1 也允许——多个不同的 x 共享同一个象，极端例子是常值函数（所有行在 $y_0$ 那一列全取 1，其余列全为 0）。

   * **全部函数的集合 $Y^X$**

       * $Y^X$ 表示从集合 X 到集合 Y 上全部函数的集合。

       * $|X|=m$、$|Y|=n$ 时 $|Y^X|=n^m$：X 中每个元素取函数值时都有 n 种选择——例：X 含 3 个元素、Y 含 2 个元素，全部函数共 $2^3=8$ 个。

   * **常值函数与恒等函数**

       * 常值函数：存在 $y_0\in Y$ 使定义域中任意元素 x 都有 $f(x)=y_0$，f 的值域只有 $y_0$ 一个元素。

       * 恒等函数：恒等关系 $I_X$ 是一个从 X 到 X 的函数，$I_X(x)=x$——给什么还什么。

   * **函数相等**

       * > **定义**：f 是从 A 到 B 的函数、g 是从 C 到 D 的函数，f 与 g 相等的充要条件是 $A=C$、$B=D$，且对任意 $x\in A$ 有 $f(x)=g(x)$。

       * 函数相等等价于三件事同时成立：定义域相等、陪域相等、对应规律相同——哪怕对应规则一模一样，定义域或陪域不同，也算两个不同的函数。

   * **满射、映内、入射、双射**

       * 满射函数：值域恰好等于陪域 $R_f=Y$，陪域中的任何一个元素在定义域中都有原象。

       * 映内函数：值域真包含于陪域 $R_f\subsetneq Y$，陪域中存在没有原象的元素。

       * 入射函数：定义域里不同的元素在陪域里有不同的象（一对一），且 $R_f\subsetneq Y$。

       * 双射函数：既入射又满射——不同元素象不同，且陪域每个元素都有原象。

       * 入射未必满射："从 X 到 X 的入射函数一定满射、从而双射"只在 X 是有限集合时成立；反例 $f(n)=2n$ 从 N 到 N 是入射的，但奇数找不到原象——无穷集合"装得下自己的一半"。

| 类型 | 值域与陪域 | 一对一 |
| :--- | :---: | :---: |
| 满射 | $R_f=Y$ | 不要求 |
| 映内 | $R_f\subsetneq Y$ | 不要求 |
| 入射 | $R_f\subsetneq Y$ | 要求 |
| 双射 | $R_f=Y$ | 要求 |

   * **函数的复合**

       * > **定义**：f 是从 X 到 Y 的函数、g 是从 Y 到 Z 的函数，$g\circ f=\{\langle x,z\rangle\mid x\in X\land z\in Z\land\exists y\,(y\in Y\land\langle x,y\rangle\in f\land\langle y,z\rangle\in g)\}$ 称为 f 与 g 的复合函数，是一个从 X 到 Z 的函数。

       * 复合能成立的前提：f 的陪域正是 g 的定义域，两头要接得上。

       * 记号为何倒着写：对 x 先做 f 变换、再做 g 变换，写作 $g(f(x))$——先做的 f 挨着 x 躲在里层；为与书写统一，把复合记作 $g\circ f$。

       * 函数复合的本质就是关系的复合运算，计算方法从关系那里继承，一共三种：枚举法、有向图法（过河拆桥）、谓词公式法（直接代入）。

       * > **易错点**：⚠️ 枚举计算复合要从第二个关系开始找起、向第一个关系衔接——f 中有 $\langle 1,2\rangle$，到 g 中找 $\langle 2,5\rangle$，两者首尾相接，复合得 $\langle 1,5\rangle$。

       * 代入实例：$f(x)=3x+1$、$g(x)=x^2+x$ 时，$g\circ f=g(f(x))=(3x+1)^2+(3x+1)=9x^2+9x+2$，而 $f\circ g=3x^2+3x+1$，$f\circ f=9x+4$，$g\circ g=(x^2+x)^2+(x^2+x)$。

       * 函数复合不满足交换律：$g\circ f$ 与 $f\circ g$ 的计算结果不同，顺序不能随手颠倒。

   * **函数复合的四条性质**

       * 结合律：$(h\circ g)\circ f=h\circ(g\circ f)$。

       * 三种射经复合保持：f、g 都满射则 $g\circ f$ 满射（陪域任取 z，先由 g 找 y、再由 f 找 x）；都入射则 $g\circ f$ 入射；都双射则 $g\circ f$ 双射（满射加入射合起来）。

       * 反方向提取：$g\circ f$ 满射则 g 满射，$g\circ f$ 入射则 f 入射，$g\circ f$ 双射则 f 入射且 g 满射——复合"满"了往外层 g 上归，"入"了往内层 f 上归，方向与保持性正好相反。

       * 与恒等函数复合不变：$f\circ I_X=I_Y\circ f=f$——定义域、陪域相同，对应规律 $f(I_X(x))=f(x)$、$I_Y(f(x))=f(x)$ 也与 f 相同。
