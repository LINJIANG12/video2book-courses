# 大厂必备数据结构与算法（Java）下篇

《数据结构与算法》下篇，200 集接上篇继续往进阶走。课程先用 B 树与哈希表把查找类结构讲透，再把排序算法从比较排序一路排到基数排序，随后进入图论（遍历、最短路径、并查集）、递归搜索与哈夫曼树、贪心与动态规划（背包到卡特兰数）、分治与回溯、双指针与字符串匹配（KMP），最后以缓存设计与一组长短链、跳表、LRU/LFU 这类综合设计题收尾，整体按「基础数据结构 → 进阶结构 → 算法范式 → 综合设计」的顺序组织，每节都配 LeetCode 原题。

- **原视频**：https://www.bilibili.com/video/BV1rv4y1H7o6 — Bilibili，BV1rv4y1H7o6
- **200 集**，已产出 9 册模块全书、51 篇复习笔记、51 份逐字稿

## 怎么学

- **承接上篇** → 本篇是《大厂必备数据结构与算法（Java）上篇》的直接续篇，开篇前建议先确认复杂度分析、递归与树形结构的基础已经过关
- **查找与排序是主线** → 模块 01、02 讲 B 树与哈希表，模块 03 讲排序全景；B 树的 split 与删除分步（笔记 03~05）是这一段最容易被问倒的地方，值得逐句对着代码看
- **图论与并查集** → 模块 04 与笔记 18~23 覆盖基本概念、拓扑排序、Dijkstra、Floyd、并查集，Floyd 的两段实现（笔记 21、22）建议自己写一遍矩阵版本和压缩版本
- **算法范式区** → 模块 05~08 是动态规划、贪心、分治回溯、双指针与 KMP，笔记 24~45 按「零钱兑换 → 背包 → 钢条切割 → 旅行商 → Catalan 数」逐题推进；**注意这些笔记是按集生成的**，不是按主题聚合，检索时先看文件名里的 LeetCode 题号
- **综合设计题收官** → 模块 09 与笔记 46~51 覆盖 LRU、LFU、跳表、短网址与股票系列问题，这类题最能检验数据结构选型能力，是面试前最后一块拼图
- **文件名有截断** → 本篇 `notes/` 的文件名被生成侧的长度上限截断在主题 24 字（如「设计短网址-Leet」实为 LeetCode 题、「Floyd-Wa」实为 Floyd-Warshall），课程页链接文字照搬原样；要修得回到生成侧改名后重跑同步
