# 进阶数据结构和算法-313-平方根整数部分-Le

## 平方根的整数部分

* **平方根的整数部分（floor square root）**

    * > **定义**：题目要的是平方根向下取整的结果，小数部分直接扔掉，如 2 取 1、8 取 2。

    * 判定方式：找到"平方首次超过 $x$"的那个候选值，它的前一个数就是 $\lfloor\sqrt{x}\rfloor$。

    * 条件：只要某个数的平方大于 $x$，而它的上一个数平方小于 $x$，那么它前面那个数就是答案。

    * 例：$9^2 = 81 \le 99 < 100 = 10^2$，99 卡在两者之间，$\lfloor\sqrt{99}\rfloor = 9$。

## 二分求平方根

### 线性枚举与二分的差距

* **线性枚举**

    * 从 1 开始一个一个试平方，直到遇到第一个平方超过 $x$ 的数才知道答案。

    * 求 $\lfloor\sqrt{99}\rfloor$ 时要从 1 试到 10，整个过程试了 10 次。

* **二分查找**

    * 每次只取区间中间的那个数与 $x$ 比较：平方大于 $x$ 就收窄右边界，平方小于 $x$ 就放宽左边界。

    * 每一次比较都把区间砍掉一半，这就是二分省下来的时间。

    ```text
    目标 x = 99

    [1, 99]   mid = 50   50² = 2500 > 99   -> 太大，收窄右边界
    [1, 49]   mid = 25   25² = 625  > 99   -> 太大，收窄右边界
    [1, 24]   mid = 12   12² = 144  > 99   -> 太大，收窄右边界
    [1, 11]   mid = 6    6²  = 36   < 99   -> 太小，放宽左边界
    [7, 11]   mid = 9    9²  = 81   < 99   -> 太小，放宽左边界
    [10,11]   mid = 10   10² = 100  > 99   -> 太大，收窄右边界
                                             此时 left > right，退出循环
                                             ans = 9
    ```

    * 六次比较，比一个一个试快得多。

### 二分代码骨架

* **三个变量：左边界 `i`、右边界 `j`、中间值 `m`**

    * 初值：左边界从 1 开始，右边界从 `x` 开始。

    * 循环条件 `i <= j` 表示"这个范围内还有没尝试过的数字"；一旦 `i > j`，说明区间里的数全试完了，该退出。

    * 中间值用 `(i + j) >>> 1` 求出，不写 `/ 2`。

* **右移一位代替除以 2**

    * > **定义**：`>>> 1` 是无符号右移一位，效果等价于整除 2。

    * 条件：`i` 和 `j` 都很大时，`i + j` 这一下加法本身就可能溢出，右移写法把加法彻底绕开了。

* **拿到 `m` 后的三个分支**

    * 先记 `mm = m * m`，再与 `x` 比较。

    * `mm == x`：正好整除，`x` 为 4、中间值为 2 这种情形，直接 `return m`。

    * `mm < x`：这个数偏小，放宽左边界 `i = m + 1`。

    * `mm > x`：这个数偏大，收窄右边界 `j = m - 1`。

* **`ans` 记录变量**

    * 循环体外声明 `ans = 0`，位置很明确：在"平方比 `x` 小"的那个分支里，每次都记一次。

    * 为什么必须记：`mm > x` 那一支执行 `j = m - 1` 后，下一轮 `i > j` 成立，循环直接退出，刚才那个 `m` 的值已经被 `m - 1` 覆盖掉了，退出时根本不知道最后试的 `m` 是多少。

    * 以 99 为例：试到 `m = 9` 时 `81 < 99`，`i` 变成 10；下一轮 `i = 10, j = 11`，中间值又是 10，而 `10² = 100 > 99`，于是走 else，`j = 10 - 1 = 9`；此时 `i = 10 > j = 9`，循环退出。

    * > **易错点**：`ans` 的赋值只能放在 `mm <= x` 这一支。放在别的地方没有意义——只有"平方不超过 `x`"的候选才有资格成为答案。

```java
public int mySqrt(int x) {
    int i = 1;      // 左边界
    int j = x;      // 右边界
    int ans = 0;    // 记录已经确认"平方小于 x"的最大候选值

    while (i <= j) {            // i <= j 说明区间里还有没试过的数
        int m = (i + j) >>> 1;   // 除以 2 用右移，防止 i + j 溢出
        int mm = m * m;         // m 的平方

        if (mm == x) {
            return m;           // 正好整除，直接返回
        } else if (mm < x) {
            ans = m;            // 记下来，这一支随时可能成为答案
            i = m + 1;          // m 偏小，放宽左边界
        } else {
            j = m - 1;          // m 偏大，收窄右边界
        }
    }
    return ans;                 // i > j，所有候选都试完了
}
```

* 验证：99 得 9，4 得 2，8 得 2。

## 等价变换与溢出处理

### 溢出的真正位置

* **越界发生在乘法那一步**

    * 测试用例会传一个非常大的数字，此时中间值本身并没有越界，因为加法已被右移挡住。

    * 但中间值算出来很大，再求它的平方，乘法这一步就越界了。

    * 越界之后再拿两个数做比较其实已经没有意义，所以这个用例通不过。

* **两种解决办法**

    * 第一种：把这里的 `int` 全部扩大成 `long`，让大数乘法不至于越界。

    * 第二种：把乘法换成除法。`x / m` 肯定不会越界，而 `m * m <= x` 恰好等价于 `x / m >= m`（`m` 是正数，区间内 `m` 至少为 1），这个比较既安全又等价。

* **等于条件与小于条件合并**

    * 先做等价变换：把第一个 `if`（`mm == x` 直接返回）与第二个 `else if`（`mm < x`）合到一起去。

    * 平方等于 `x` 时也别急着返回，同样先暂存到 `ans`，将来退出循环时再统一返回 `ans`，等于条件和小于条件合并成小于等于。

    * 这个变换不影响逻辑的正确性，99、4、8 几个用例的结果依然是对的。

```java
while (i <= j) {
    int m = (i + j) >>> 1;

    if (x / m >= m) {     // 等价于 m * m <= x，且乘法不会溢出
        ans = m;
        i = m + 1;
    } else {
        j = m - 1;
    }
}
return ans;
```

* 超大用例求出来是 **46339**，平方根的整数部分确实就是这个数。

## 至少 K 个重复字符的最长子串

### 题意与子串约束

* **至少 K 个重复字符的最长子串（Longest Substring with At Least K Repeating Characters）**

    * > **定义**：给定字符串 `s` 和整数 `k`，把字符串切分成若干子串，要求每个子串里每个字符的出现次数都不低于 `k`，返回这些子串中最长的那个的长度。

    * 例 `AABBC`、`k = 2`：切成 `BBC` 时 C 出现 1 次小于 2，这个子串被舍弃；保留下来的最长子串是 `ABABB`（A 出现 2 次、B 出现 3 次），长度 5。

    * 例 `AAA`、`k = 3`：整段 `AAA` 满足条件，答案长度 3。

    * 例 `AABBC`、`k = 3`：答案为 0。A 全文只出现 2 次小于 3；去掉第一个 A 后只剩 1 个 A 仍小于 3；中间的 A 一去掉字符串就不连续了。

    * > **提示**：子串 ≠ 子序列。子串要保持原有字符顺序、必须连续，字符不能跳着选，只能整段保留或整段丢弃，不能像挑子序列那样挑挑拣拣。

### 分治骨架

* **三步走**

    * 统计字符串中每个字符的出现次数。

    * 把那些出现次数小于 `k` 的字符先移除掉——移除意味着原始字符串被拆分成了多个子串。

    * 对多个剩余的子串，再对它们做递归的重复处理。

* **为什么要先剔除不合格字符**

    * 出现次数太少的字符将来组合子串时谁带上它们谁倒霉：比如有三个 `d`，如果带上一个只出现 1 次的 `x`，整个子串就有一个出现次数为 1 的字符，小于 `k`，不满足；把 `x` 排除掉就满足了。

    * 原始串里 b 一共出现 3 次，但被不合格字符切散后，某些段里只剩 2 次 b，这一整段仍带上 b 就不满足条件，需要递归重复同样的处理。

* **递归终止的两种情况**

    * 子串的长度已经小于 `k`，不够用，直接排除。

    * 剩余的子串里已经没有出现次数小于 `k` 的字符了。

    * 这时在这些子串里面再找一个长度最长的，就是答案。

```text
k = 3，原始串的字符出现次数：
    x → 1 次      c → 2 次      e → 1 次      b → 3 次（散落在多段里）

第一轮：把 x / c / e 全部剔除
    这些"不合格字符"把原串切成若干段，b 也随之被拆散

第二轮：对剩下的每一段重新统计
    有些段里的 b 只剩 2 次  ->  又拿 b 开刀，继续切
    像那三个 d 这样的段    ->  每个字符都 >= 3 次，不用动

收尾：剩下各段里最长的那一段长度是 4，其余都不到 4
```

### 用长度为 26 的数组统计

* **`counts` 数组**

    * > **定义**：一个长度为 26 的 `int` 数组，数组的索引对应字符，数组的值对应这个字符出现了几次。

    * 广义做法用 `HashMap`，key 放字符、value 放它的出现次数；但题目说明字符只可能是英文字母，用定长数组即可。

    * 索引换算：让 `A` 对应索引 0、`B` 对应索引 1，做法是用字符减去 `'A'`（示例代码中写作 `'c' - 'a'` 得 2，`'b' - 'a'` 得 1）。

    * 初始值出现次数都是零，遇到一个直接 `++`。

    * 打印校验：下标 0 对应 A 出现 2 次，下标 1 对应 B 出现 3 次，下标 2 对应 C 出现 1 次。

    * 遍历效率：先把字符串转换成 `char[]` 再遍历，效率会稍微好一些。

```java
int[] counts = new int[26];
```

### 切分与连续字符合并

* **按不合格字符的位置切两段**

    * 遍历原始字符串对应的字符数组，用 `i` 作为遍历变量，后面切分要用到它。

    * 查询当前字符的出现次数：前面已经都统计在 `counts` 里，同样用当前字符减去 `'a'` 换算索引去数组中查询。

    * 先判断次数是否大于 0：大于 0 表示它确实出现了，等于 0 表示根本没这个字符。

    * 对大于 0 并且小于 `k` 的字符，根据它的位置用 `substring` 切成两部分：前半段是 `substring(0, i)`，后半段是 `substring(i + 1)`。

    * 示例里 `C` 后面没东西，第二段其实是个空串，切分效果不明显；改成前面几个 `A`、中间一个 `c`、后面几个 `B` 就看得很清楚。

* **连续块合并切分**

    * 问题：两个连续的 `c` 且 `k = 3` 时，按第一个 `c` 切一次、再按第二个 `c` 切一次，操作明显重复，完全可以一次把这两个连续的 `c` 都排除掉。

    * 做法：除了 `i` 再加一个 `j`。`i` 记录找到的第一个出现次数小于 `k` 的字符的起始位置，`j` 代表它的一块结束位置，只要是连续的就一次切掉。

    * `j` 从 `i + 1` 开始向后扫描，条件是 `j < chars.length && counts[chars[j] - 'a'] < k`，直到遇到一个出现次数大于等于 `k` 的字符才停下来。

    * 切法变成 `substring(0, i)` 与 `substring(j)`，两个连续的 `c` 被一刀切干净。

```java
int j = i + 1;                       // i 已经找到了，从 i+1 继续检查
while (j < chars.length &&           // 别越界
       counts[chars[j] - 'a'] < k) { // 这一处字符的出现次数也小于 k
    j++;
}
// 直到遇到一个出现次数 >= k 的字符才停下来
return Math.max(helper(s.substring(0, i), k),
                 helper(s.substring(j), k));
```

```text
k = 3，s = "AAACCBBB"

  下标  0   1   2   3   4   5   6   7
      ┌───┬───┬───┬───┬───┬───┬───┬───┐
      │ A │ A │ A │ c │ c │ B │ B │ B │
      └───┴───┴───┴───┴───┴───┴───┴───┘
                      ↑   ↑
                      i   j (=5)

  substring(0, i) = "AAA"      substring(j) = "BBB"
```

* **`return` 写在循环体内**

    * 遍历字符数组的循环，每找到一个这样的字符、切完，这个循环就算结束了，不需要继续循环下去，下次在递归里面再分别处理这两个子串。

    * `return` 写在循环里意味着外层循环只会执行一次，不会出现"前面已经切分好了，后面再重复前面这个效果"的问题。

### 递归的两个出口

| 情况 | 含义 | 返回值 |
| :--- | :--- | :--- |
| 子串长度已经小于 `k` | 落选，比如切出来就是一个 `A` 而 `k = 2` | 返回 `0` |
| 子串中没有出现次数小于 `k` 的字符 | 入选，整个循环走完 | 返回 `s.length()` |

* **出口一：子串长度已经小于 `k`**

    * 检查放在方法的一开始，一旦发现子串长度已经小于 `k` 就返回 0。

    * 返回 0 的理由：这个方法返回值的含义是"选中的最长子串的长度"，这个子串落选了，把长度设置为 0 即可。

    * 0 相当于肯定是个最小值，将来跟那些符合条件的子串比较时不会干扰结果。

* **出口二：没有出现次数小于 `k` 的字符**

    * 选中的子串必须把这个循环执行完，因为循环就是去找有没有出现次数小于 `k` 的字符，有就进一步处理。

    * 循环都走完了，说明它所有字符的出现次数都大于等于 `k`，这时字符串长度就是实际要的长度，直接返回它。

* **左右两段取最大值**

    * `Math.max` 的第一项是左边那个递归调用的返回结果，第二项是右边那个的返回结果，二者求一个最大即可——题目要求的是取这些子串长度里最大的。

```java
public int longestSubstring(String s, int k) {
    return helper(s, k);
}

private int helper(String s, int k) {
    // 出口一：子串长度已经小于 k，落选
    if (s.length() < k) {
        return 0;
    }

    // 统计每个字符的出现次数
    int[] counts = new int[26];
    char[] chars = s.toCharArray();
    for (char c : chars) {
        counts[c - 'a']++;
    }

    // 找到出现次数小于 k 的字符，按它所在的一整段切分，然后递归
    for (int i = 0; i < chars.length; i++) {
        if (counts[chars[i] - 'a'] > 0 && counts[chars[i] - 'a'] < k) {
            int j = i + 1;
            while (j < chars.length && counts[chars[j] - 'a'] < k) {
                j++;
            }
            return Math.max(helper(s.substring(0, i), k),
                             helper(s.substring(j), k));
        }
    }

    // 出口二：没有不合格字符，整个子串入选
    return s.length();
}
```

## 回溯

### 回溯的定义与栈帧恢复

* **回溯（backtracking）**

    * > **定义**：把一个程序的运行过程分成多个阶段后，如果能够通过某些手段将数据恢复到之前某一阶段的那个状态，就称之为回溯。

    * 例子：`rec(n)` 在 `n == 3` 时 return；第一次调用 `n = 1`，第二次调用 `n = 2`，第三次调用 `n = 3`，之后逐层返回。

    * 原理：每次方法调用都把当前那个 `n` 记录下来了，它作为局部变量的值被记录在对应的方法栈中。

    * 回到第二次调用时 `n` 就是 2，第二次调用也执行结束后回到第一次调用时 `n` 就被恢复成 1，这就是一种回溯。

    * 机制：一个方法内的局部变量不会被其他方法所干涉、所修改，递归调用前 `n` 里存的是什么，递归调用之后 `n` 里的数据仍然没有变化，这样起到了保存状态的效果。

```text
rec(1)  栈帧里存着 n = 1
  └─ rec(2)  栈帧里存着 n = 2
       └─ rec(3)  栈帧里存着 n = 3
            └─ 结束，逐层返回
                 ↑ 回到 rec(2) 时，n 自动是 2
                   ↑ 回到 rec(1) 时，n 自动是 1
```

### 局部变量自动回滚，引用不会

* **集合参数的实验**

    * 给方法加一个 `List<String>` 类型的集合参数，一开始传空集合，递归调用时也把同一个对象传递进去。

    * 现象：第一次递归调用时集合是空的；第二次递归调用时集合里已经加了一个 `a`；第二次调用结束返回时集合里已经加了两个 `a`；回到第一次递归调用时，集合中仍然是两个 `a`。

    * 结论：这次调用之后并没有把数据恢复成之前的状态。

    * 原因：方法调用有多次，但它们用的都是同一个集合对象。

```java
void rec(int n, List<String> list) {
    System.out.println("before = " + list);   // 递归调用前的打印

    list.add("a");                            // 递归调用前先加点东西

    if (n < 3) {
        rec(n + 1, list);
    }

    System.out.println("after = " + list);    // 递归调用之后的打印
}
```

### 让操作成对出现

* **push 与 pop**

    * > **定义**：push 指向站顶加数据，pop 指从站顶移出数据。

    * 思路：这个操作实际上是个对称的操作，递归调用前往里加了一个数据，递归调用后就可以把这个数据移除。

    * 只要"加数据"跟"移除数据"的方法成对出现，就可以在递归结束之后把状态恢复成之前的状态。

    * 写法：`list.add("a")` 放在递归调用前，`list.remove(list.size() - 1)` 放在递归调用之后。

    * 效果：第一次调用时 list 的状态是空集合，它恢复之后也被恢复成空集合；第二次递归调用时 list 中有一个 `a`，恢复时也会把集合中的元素恢复成一个 `a` 的状态。

```text
rec(1, [])        before=[]          add -> [a]
  rec(2, [a])     before=[a]         add -> [a, a]
    rec(3, [a,a]) before=[a, a]      add -> [a, a, a]
                                     n == 3，不再往下递归
                                     after=[a, a, a]
                                     remove -> [a, a]
  after=[a, a]                        remove -> [a]
after=[a]                             remove -> []
```

* > **结论**：如果用的是可变的集合数据，或者像数组这样的数据，那么必须在递归的前后自己手工恢复数据的状态。方法栈能帮你回滚的，只有基本类型的局部变量。

## 二分与分治经典题目

* **力扣 69：x 的平方根（My Sqrt）**

    * > **定义**：给定一个非负整数 `x`，返回 `x` 的平方根的整数部分（向下取整）。

    * 核心做法：把答案夹在 `[1, x]` 的区间里二分，收窄区间时用 `ans` 记下"平方不超过 `x`"的最大候选。

    * 溢出处理：力扣的大数用例会让 `m * m` 溢出，用 `x / m >= m` 替代乘法即可绕开。

    * 答案示例：99 → 9，4 → 2，8 → 2，超大用例 → 46339。

* **力扣 395：至少 K 个重复字符的最长子串（Longest Substring with At Least K Repeating Characters）**

    * > **定义**：给定字符串 `s` 和整数 `k`，返回最长的连续子串的长度，其中每一个字符的出现次数都至少为 `k`。

    * 三步走：统计字符次数 → 把出现次数小于 `k` 的字符连同它所在的一整段切掉 → 对左右两段递归取 `max`。

    * 两个出口：子串长度已小于 `k` 返回 0；子串中不存在出现次数小于 `k` 的字符，返回子串长度。

    * 答案示例：`s = "AAA"`，`k = 3` → 3；`s = "AABBC"`，`k = 2` → 5（最长子串 `ABABB`）；`s = "AABBC"`，`k = 3` → 0。
