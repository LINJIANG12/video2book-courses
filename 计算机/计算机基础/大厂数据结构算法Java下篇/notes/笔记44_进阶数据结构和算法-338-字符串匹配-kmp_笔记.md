# 进阶数据结构和算法-338-字符串匹配-kmp-

## 暴力匹配的浪费

* **暴力匹配（Brute Force，BF）**

    * > **定义**：模式字符串从原始字符串的每个位置起逐字符比较，撞上不同的字符就换下一个起点。

    * 最好懂，但坏处一眼可见：模式串长成 `AAAAAAA…AG`、原始串里全是 `A` 时，每一轮都是"前面成功一大串、最后一个失败"。

    * 撞上不同字符后 `j` 退回零、起点前进一位，同一段字符被反复比较了无数遍。

    * > **结论**：BF 的浪费不在于"比错了"，而在于"已经比对的那些成功信息，被完全扔掉了"。

## 最长相同前后缀

* **无需对比的那一段**

    * 把已经匹配上的那一段字符一格一格往回看，找最长的相同前后缀。

    * 模式串 `A B A A B A` 与文本中刚匹配成功的那一段对齐时，可以省掉若干次比较：

```text
pattern : A  B  A  A  B  A
index   : 0  1  2  3  4  5
matched : A  B  A  A  B  A     <- 文本中刚匹配成功的那一段
                   |
         lps = 3  ->  下一轮 j 直接跳到 3，前 3 个字符不用再比
```

    * > **定义**：**最长相同前后缀**指在所有"既是模式字符串的前缀、又是已匹配部分的后缀、并且取值完全相同"的片段里，长度最长的那一个。

    * 它的长度就是下一次匹配可以跳过、不需要再比的字符数；能向前走这么远本身就说明前面很多字符是对的，重比一遍是白费力气。

    * 更长的候选不成立：`ABAB` 跟下面那一段 `BABA` 对不上；`ABABA` 虽然跟模式串里某一段一模一样，但那条路已经走过，不必再走一遍。所以最优解是 `ABA`。

    * 例：前缀只有一个 `A` 时省一次比较；前缀与后缀同为 `ABA` 时省三次比较。

| 已匹配长度（用了模式串前几个字符） | 最长的相同前后缀 | 长度 | 失败后 `j` 跳到 |
| :--- | :--- | :--- | :--- |
| 1 | 无 | 0 | 0 |
| 2 | 无 | 0 | 0 |
| 3 | A | 1 | 1 |
| 4 | AB | 2 | 2 |
| 5 | ABA | 3 | 3 |

    * 判定要点：前缀要与**末尾**的后缀比较。已匹配部分为 `AB` 时前缀 `A` 对不上后缀 `B`，最长相同前后缀为 0；已匹配部分为 `ABA` 时前缀想再长是 `AB`、后缀是 `BA`，仍对不上，只能取 `A`，长度 1。

    * > **易错点**：这里比较的永远是"前缀和后缀相等"，不是"出现次数最多"。`A` 在 `ABA` 里出现了两次却不能用，因为前缀 `A` 要和**末尾**的后缀比，`A` 出现在开头不是出现在末尾。

## LPS 数组

* **LPS 数组（longest prefix suffix array，最长的相同前后缀数组）**

    * > **定义**：与模式字符串等长的一维数组，存的是最长相同前后缀的**字符个数**。

    * 规律一：求最长相同前后缀只跟模式字符串有关，跟原始字符串没关系——每次求的"刚匹配成功的那一段"本身就是由模式串的前几个字符决定的。

    * 规律二：模式串的前 `k` 个字符，它的最长相同前后缀长度是确定的，重跑每次都一样。

    * 结论：这张表只需要根据模式串算一次，之后拿它去匹配任何一个原始字符串都能直接复用。

    * **索引**：看你用了模式字符串的前几个字符**减掉一**。用了 1 个字符 → 索引 0；用了 2 个 → 索引 1；用了 3 个 → 索引 2。

    * **值**：最长相同前后缀的长度。存 `3` 就代表最长前后缀是长度为 3 的那一段。

    * 关键性质：这个值恰好就是匹配失败时 `j` 要跳转到的位置。值是 2 失败后 `j` 跳到索引 2，值是 0 下一轮只能从 0 重新开始，查表和跳转是同一个动作。

```text
模式串：  A   B   A   B   A   C   A
索引  ：  0   1   2   3   4   5   6
lps  ： [ 0 ][ 0 ][ 1 ][ 2 ][ 3 ][ 0 ][ 1 ]
```

## KMP 匹配流程

* **KMP 算法（Knuth–Morris–Pratt）**

    * > **定义**：借助 LPS 数组，让 `j` 不再每次回到零、而是回到"更靠后但依然有把握"位置的字符串匹配算法。

    * 准备工作三样：原始字符串、模式字符串、长度与模式串一致的 LPS 数组；定两个指针 `i = 0`、`j = 0`，进入循环不断比两个字符。

    * 三种分支：两字符相等、`j == 0` 时失败、`j != 0` 时失败。

    * 完整实现：

```java
public static int kmpSearch(String text, String pattern) {
    int[] lps = buildLPS(pattern);
    char[] t = text.toCharArray();
    char[] p = pattern.toCharArray();
    int i = 0, j = 0;
    while (p.length - j <= t.length - i) {
        if (t[i] == p[j]) {
            i++;
            j++;
            if (j == p.length) {
                return i - j;
            }
        } else if (j == 0) {
            i++;
        } else {
            j = lps[j - 1];
        }
    }
    return -1;
}
```

### 匹配成功分支

    * 两个字符相等、匹配上了，就 `i++`、`j++` 去比下一段。

    * 当 `j` 加到等于模式字符串长度的时候，整个模式串都被对上了，这就是"找到解"的判据。

    * 返回值：`i` 从零开始，`i` 减去模式字符串长度就是这次匹配在原始字符串中的起始索引；命中这一刻 `j` 刚好等于模式串长度，所以直接 `return j` 和 `return i - j` 得到的是同一个值。

```java
if (t[i] == p[j]) {
    i++;
    j++;
    if (j == p.length) {
        return i - j;
    }
}
```

### 匹配失败且 j 为零

    * `j == 0` 意味着一上来就撞上了不同的字符，它前面根本没有已经匹配好的字符，没有可以借力的信息，**根本用不上 LPS 数组**。

    * 什么都不用算，让 `i++` 去看下一个位置的字符，跟 `p[0]` 重新比一次就完了；注意 `j` 保持零不变。

```java
} else if (j == 0) {
    i++;
}
```

### 匹配失败且 j 不为零

    * `j != 0` 说明前面已经积累了一段匹配成功的公共部分，这时才请出 LPS 数组。

    * 跳几个字符查 `lps[j - 1]`：前面那段的字符数就是 `j`，而 LPS 的索引是"字符数减一"；查到多少，`j` 就跳到多少。

```java
} else {
    j = lps[j - 1];
}
```

```text
pattern : A  B  A  A  B  A
              ^       ^
              |       +--- i 指向原始字符串当前字符
              +----------- j 指向模式串当前字符（第 6 个，值 5）

t[i] = 'X', p[j] = 'A'  ->  失败
查 lps[j - 1] = lps[4] = 3  ->  跳过 "ABA"
j 跳到 3，也就是那个 'B'，从它继续往后比
```

### 循环结束条件

    * 循环条件写成 `while (p.length - j <= t.length - i)`。

    * 模式串长度减去 `j` 是模式串**剩余**的长度，原始字符串长度减去 `i` 是文本**剩余**的长度。

    * 前者一旦大于后者，就说明模式串挂到文本外面去了，这种情况下可以提前结束外层循环。

    * 原条件 `i < text.length` 判断不出来：`i` 还是小于原始字符串长度的，循环会白白再跑几次，直到 `i` 等于 `text.length` 才退出，那最后这几次比较纯属浪费。

    * > **结论**：`i` 和 `j` 谁都不许后退一步把已比过的字符重比一遍——要么 `i` 往前走，要么 `j` 按 LPS 跳转。这正是 KMP 比暴力匹配快的原因。

## LPS 数组的构造

* **上下对照的技巧**

    * 把模式字符串一分为二，上下摆两个一模一样的：上面那个专门用来找前缀，下面那个专门用来找后缀。

    * 只需要关注前面亮色的部分，后面故意涂黑的部分不用管。

    * 目标是求出"用 1 个、2 个、3 个、4 个、5 个字符时"的最长共同前后缀，填进一维数组。

* **相同字符与不同字符**

    * 整个过程可以拆成两种情况理解：遇到相同字符怎么办，以及遇到不同字符怎么办。

    * 不同字符在代码上就是 `if` 没成立、走了 `else if` 或者 `else`，所以这两个分支对应的正是"遇到不同字符"的两种子情况。

### 相同字符：lps[i] = j + 1

    * 遇到相同字符意味着找到了一个共同的前后缀，把长度记到数组里，然后 `i++`、`j++` 去比下一组。

    * 记到**当时 `i` 所指向的位置**：刚开始找到长度 1 就记到 `i` 当时指的地方，接着找到长度 2 还是记到当时的 `i`，所以是 `lps[i]`。

    * 长度就对应**当时的 `j + 1`**：`j` 刚开始是 0，`j + 1 = 1` 正好是找到的第一个长度；接着 `j` 是 1，`j + 1 = 2` 正好是第二个长度。

```java
lps[i] = j + 1;
i++;
j++;
```

### 不同字符且 j 为零

    * 前面没有共同部分，两个字符不一样说明没有共同的前后缀，长度就是 0。

    * 既然得向后找，`j` 就不用动，保持在零这个位置不变，让 `i++`，然后拿 `i + 1` 位置的字符跟 `j == 0` 的位置重新比较。

```java
} else if (j == 0) {
    i++;
}
```

### 不同字符且 j 不为零

    * 前面有共同部分时 `j` 得掉过头往回找，但回退过程中前面那些共同部分的字符不用重新比——问题跟整个匹配问题长得一模一样。

    * 这是整个问题里的一个**子问题**："当你用了前 3 个字符时应该跳过几个字符"，它的解已经算出来了，就在数组的前面。

    * 查到数组中哪个索引取决于前面这些相同部分用了几个字符：现在是 3 个字符，对应的解在索引 2，**所以是 `j - 1`**。

```java
} else {
    j = lps[j - 1];
}
```

### 收尾与验证

    * 数组长度跟模式字符串长度一致，`i` 从 1 开始、`j` 从 0 开始，`i < p.length` 就退出循环。

    * 循环结束时整个数组都被填满了，直接返回它。

    * > **提示**：为了讲清楚，图上画的是上下两个数组，但实际代码里 `i` 和 `j` 指向的是**同一个数组的不同索引**，所以 `i` 和 `j` 有可能落在同一格上，这正是"最长相同前后缀"能一层层往前借力的地方。

```java
public static int[] buildLPS(String pattern) {
    char[] p = pattern.toCharArray();
    int[] lps = new int[p.length];
    int i = 1, j = 0;
    while (i < p.length) {
        if (p[i] == p[j]) {
            lps[i] = j + 1;
            i++;
            j++;
        } else if (j == 0) {
            i++;
        } else {
            j = lps[j - 1];
        }
    }
    return lps;
}
```

    * 用 `AAAAB` 逐长度手推：用 1 个字符没有共同前后缀记 0；用 2 个字符前后缀都是 `A` 记 1；用 3 个字符两个 `A` 对上记 2；用 4 个字符前后缀都是三个 `A` 记 3。

    * 用 5 个字符时把四个 `A` 看成前缀、把 `AAA` 加一个 `B` 看成后缀对不上，于是让 `j` 往前走，往前找的过程中也用 KMP 的思路跳过一些不用比的字符；`AAA` 和 `AAB` 还是对不上就继续让 `j` 减少，找了一圈还是没对应上——说明以 `B` 开头的前缀压根不存在，长度是 0。

```text
模式串：  A   A   A   A   B
lps   ： [ 0 ][ 1 ][ 2 ][ 3 ][ 0 ]
```

    * 用 `ABABACA` 验证代码生成的结果，输出正是 `0, 0, 1, 2, 3, 0, 1`，与前面手推一致。

```text
模式串：  A   B   A   B   A   C   A
lps   ： [ 0 ][ 0 ][ 1 ][ 2 ][ 3 ][ 0 ][ 1 ]
```

## 最长公共前缀

* **最长公共前缀（Longest Common Prefix）**

    * > **定义**：一组字符串共同拥有的最长前缀；不存在共同前缀时返回一个空串。

    * 例：`flower`、`flow`、`flight` 的共同前缀一眼可见，就是 `fl`。

```text
strs[0] = f l o w e r
strs[1] = f l o w
strs[2] = f l i g h t
           ^ ^
           | +-- i = 1：l l l 一样
           +---- i = 0：f f f 一样
```

    * 比较方向：**竖着比**，不是横着比。设两个变量，一个是"第几个字符串"，另一个是"字符串中的第几个字符"。

    * 先看第 0 列——所有字符串下标为 0 的字符都一样，说明找到一个共同前缀；`i++` 到下一列重复同样的判断，一样则前缀又长一截。

    * 到某一列发现不一样就停。上例到 `i = 2` 时这一列是 `o`、`o`、`i`，说明从这里开始已经是不同的前缀了，前面的 `fl` 就是答案。

### 可停止的三种情况

    * 情况一：比较某一列时遇到不同字符，答案是 `i` 之前的那些字符。

    * 情况二：某个字符串长度不够了——不是遇到不同字符，而是某一个字符串因为长度太短已经没有这一列的字符了，答案同样是 `i` 之前的那些字符。

    * 情况三：外层循环自然结束，第一个字符串本身最短，此时它自己就是最长公共前缀。

| 情况 | 触发条件 | 答案 |
| :--- | :--- | :--- |
| 一 | 比较某一列时遇到不同字符 | `i` 之前的那些字符 |
| 二 | 某个字符串长度不够了 | `i` 之前的那些字符 |
| 三 | 外层循环自然结束（第一个字符串本身最短） | 第一个字符串自己 |

### 实现细节

    * 全部比较都拿**第一个字符串**的第 `i` 个字符去和其他字符串的第 `i` 个字符比，所以先把第一个字符串取出来命名成 `first` 并直接转成字符数组；这里不用做合法性检查，因为题目要求至少有一个字符串。

    * 外层循环取 `first[i]`；内层循环去找其他字符串，因为 `j == 0` 就是第一个字符串自己，所以从 `j = 1` 一直到数组长度减一，拿第 `j` 个字符串的第 `i` 个字符跟 `first[i]` 比。

    * 字符不相等（情况一）就说明找到解了，返回 `first` 里从 0 开始、长度为 `i` 的那一段。

    * 长度不够（情况二）的判断是 `s.length == i`，说明 `i` 已经越界了。

    * 情况一与情况二的返回值一模一样，都是小于 `i` 的那一段，二者是"或者"的关系，可以合并成一个 `if`。

    * > **易错点**：**顺序很重要**。长度检查必须放在前面——如果长度都不够了，你再去取 `s[i]`，这个字符就越界了。所以情况二的检查放上面，情况一的检查放下面。

    * 循环自然结束就是情况三，直接返回 `strs[0]` 本身。

```java
public static String longestCommonPrefix(String[] strs) {
    char[] first = strs[0].toCharArray();
    for (int i = 0; i < first.length; i++) {
        for (int j = 1; j < strs.length; j++) {
            char[] s = strs[j].toCharArray();
            if (s.length == i || s[i] != first[i]) {
                return new String(first, 0, i);
            }
        }
    }
    return strs[0];
}
```

    * 用例自检：第一个用例共同前缀是 `fl`；第二个用例没有共同前缀，返回空串；第三个用例共同前缀是 `a`；第四个用例只有一个字符串，直接返回 `dog`，正是情况三。

    * 验证做法：自己写的 KMP 与 Java 自带的 `indexOf` 用完全相同的原始字符串和模式字符串跑，两边返回一致、落在原始字符串的索引 15 上，说明实现正确。

* **LeetCode 14 最长公共前缀**

    * 给定一组字符串，返回它们的最长公共前缀；不存在共同前缀时返回空串。

    * 解法就是竖着比的双层循环：某一列遇到不同字符（`s[i] != first[i]`）或某个字符串长度不够（`s.length == i`）时返回第一个字符串的 `[0, i)` 段；外层循环走完说明第一个字符串最短，直接返回它自己。
