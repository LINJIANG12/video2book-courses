# 进阶数据结构和算法-293-Leetcode58

## 两个字符串的删除操作

### 题目本质与答案公式

* **最少删除操作（LeetCode 583）**

    * > **定义**：给出 `word1`、`word2`，删掉其中的字符使两者相等，求最少删除次数。
    * 题目本质是求一个公共子序列：把公共的部分留下，不公共的删掉。
    * `sea` 与 `eat` 的公共子序列是 `ea`，`sea` 删掉 `s`、`eat` 删掉 `t`，一共 1+1=2 次。
    * 公共部分为 `etco` 的用例里，两个串长度分别是 8 和 4，答案是 (8-4)+(4-0)=4。
    * > **易错点**：这里求的是公共**子序列**，不是公共**子串**。子序列不要求在原串里连续出现，只要次序对得上就算；求子串是另一道题。

* **答案公式**

    * $$m + n - 2L$$
    * $m$、$n$ 分别是两个字符串的长度，$L$ 是最长公共子序列的长度。
    * 换算方式：把两个串的长度加起来，再减去两遍最长公共子序列的长度。
    * 三个用例的公共子序列长度分别是 4、2、3，算出的结果分别是 4、2、3。

```text
        word1 = "sea"                 word2 = "eat"
             │                             │
             └──────── 公共子序列 "ea" ─────┘
                             │
                 ┌───────────┴───────────┐
          sea 删掉 s → "ea"          eat 删掉 t → "ea"
                 └───────────┬───────────┘
                       共删 1 + 1 = 2
```

### 复用最长公共子序列的 DP 表

* **状态与转移**

    * `dp[i][j]` 表示 `word1` 前 $i$ 个字符与 `word2` 前 $j$ 个字符的最长公共子序列长度。
    * 两个字符相等时 `dp[i][j] = dp[i-1][j-1] + 1`。
    * 两个字符不等时 `dp[i][j] = Math.max(dp[i-1][j], dp[i][j-1])`。
    * 内部求解逻辑一行都不用改，搬过来之后求出的 `dp[m][n]` 就是公共子序列的最长长度。

* **唯一改动点**

    * 第一步把参数名称改一下，第二步把最终返回值换掉。
    * 返回值改为 $m+n$ 减去两遍 `dp[m][n]`。

```java
class Solution {
    public int minDistance(String word1, String word2) {
        int m = word1.length();
        int n = word2.length();

        int[][] dp = new int[m + 1][n + 1];
        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                if (word1.charAt(i - 1) == word2.charAt(j - 1)) {
                    dp[i][j] = dp[i - 1][j - 1] + 1;
                } else {
                    dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
                }
            }
        }

        // 核心改动：两个长度加起来，减去两遍最长公共子序列
        return m + n - 2 * dp[m][n];
    }
}
```

### 两处性能优化

* **字符数组替代 charAt**

    * 这段代码直接放到力扣上跑性能并不好、得分不高，问题主要出在字符串的 `charAt` 方法效率不好。
    * 把 `word1`、`word2` 都用 `toCharArray` 转成字符数组，后面直接按索引去数组里找，比用 `charAt` 到字符串里查找性能更高。
    * 改完之后代码里不再出现 `charAt`，比较的是字符数组一按 `i - 1` 取出的字符与字符数组二按 `j - 1` 取出的字符。

* **把不变量提到外层循环**

    * 内层循环里 `j` 每轮都变，但 `i` 根本没变，所以 `i - 1` 自然也不变，可以提到外层循环里。
    * 提成变量 `x` 放在外层，再把 `j - 1` 换成变量 `y`，内层里就是找 `x` 对应的字符与 `y` 对应的字符，看是否相等：相等走一条逻辑，不相等走另一条，其他逻辑不动。
    * 两处小改动放到力扣上跑能击败 99% 的用户。

```java
class Solution {
    public int minDistance(String word1, String word2) {
        int m = word1.length();
        int n = word2.length();

        // 提前摊成字符数组，避免在内层循环里反复调用 charAt
        char[] chars1 = word1.toCharArray();
        char[] chars2 = word2.toCharArray();

        int[][] dp = new int[m + 1][n + 1];
        for (int i = 1; i <= m; i++) {
            char x = chars1[i - 1];   // 提到外层：内层循环里 x 始终是同一个值
            for (int j = 1; j <= n; j++) {
                char y = chars2[j - 1];
                if (x == y) {
                    dp[i][j] = dp[i - 1][j - 1] + 1;
                } else {
                    dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
                }
            }
        }

        return m + n - 2 * dp[m][n];
    }
}
```

> **提示**：优化很多时候就是这么朴素——找到内层循环里那些每次都重新算一遍的东西，把它们搬到外面去。

## 最长递增子序列

### 递增子序列的定义

* **子序列（subsequence）**

    * 数组里随手挑出的一串元素在原数组中都出现，且次序与原数组保持一致，就叫子序列。
    * 例如从数组里挑出 `3 6 2 7`，它在原数组中都出现了，次序也对得上。
    * > **易错点**：`3 6 2 7` 只是子序列，还不是递增子序列。递增要求这些数字必须由小到大排。
    * 例如 `2 3 7 101` 是递增子序列，长度 4；`2 3 7 18` 同样是递增子序列，长度也是 4。

* **递增的含义**

    * 递增要排除掉相等的元素，整个数组元素全相等时相当于只有长度为 1 的子序列，答案是 1。
    * 比较时必须用 `>`，不能用 `>=`。
    * 与最长公共子序列解法不同：公共子序列的答案在表格右下角那一格，递增子序列的结构不一样，得重新推一遍。

### 从列举全部到只留长度

* **手工列举**

    * 拿 `1 3 6 4 9` 把所有递增子序列排出来：`1`、`1 3`、`1 6`、`1 3 6`、`1 4`、`3 4`、`1 3 4`，`4 6` 不成立因为 4 比 6 小。
    * 最后 `9` 与前面四个都能组合：`1 9`、`1 3 9`、`1 6 9`、`1 3 6 9`、`1 4 9`、`1 3 4 9` 全部成立。
    * 列完之后最长的两条是 `1 3 6 9` 和 `1 3 4 9`，长度都是 4。

* **关键转变**

    * 题目并不是要把所有递增子序列求出来，只要长度，所以 DP 表格里一个格子不必再存一整条子序列，存长度就够了。
    * 这个转变是整个解法的关键。
    * 数组的每个元素对应原数组里不同的数字，记着它对应的那个递增子序列的最长长度，所以有一个一维数组就能记住。
    * > **定义**：`dp[i]` 表示「以 `nums[i]` 结尾的最长严格递增子序列的长度」。

### 递推公式与循环边界

* **初始化**

    * 一维数组长度与原始数组保持一致，就是 `nums.length`，个数正好与原数组对得上。
    * 在这些数字跟其他数字组合之前，可以认为它们各自跟它自己组成一个递增子序列，所以最初始的长度都是 1。
    * 用 `Arrays.fill` 把整个 `dp` 填充成 1。

* **两层循环的范围**

    * 外层 `i` 从 1 开始（也就是从 `3` 这个元素开始）一直到 `nums.length`，0 号元素只有一个数自己，不用处理。
    * 内层 `j` 从 0 开始，循环小于 `i` 次：`i` 等于 1 时循环一次，等于 2 时循环两次，以此类推。
    * 因为 `i` 个元素分别要与前面的 `i` 个元素尝试组合，所以内层循环次数恰好是 `i`。

* **递推**

    * 先判断升序条件：当前元素大于前面元素 `nums[j]` 时才需要进一步处理，不满足就跳过。
    * 更新方式是 `dp[i] = Math.max(dp[i], dp[j] + 1)`，用最大值去更新 `dp[i]`。
    * `dp[j] + 1` 中的 `+1` 是拼接后把自己也计入总长度，不能省。

```text
外层 i：从 1 走到 n-1（0 号元素只有一个数自己，不用处理）
  └─ 内层 j：从 0 走到 i-1（i 个候选配对，就循环 i 次）
       if (nums[i] > nums[j])             // 满足严格升序才管，否则跳过
           dp[i] = max(dp[i], dp[j] + 1)   // 在前面最长的那条后面接上自己
```

```java
class Solution {
    public int lengthOfLIS(int[] nums) {
        // dp[i]：以 nums[i] 结尾的最长严格递增子序列的长度
        int[] dp = new int[nums.length];
        Arrays.fill(dp, 1);   // 每个数自己跟自己，长度都是 1

        for (int i = 1; i < nums.length; i++) {
            for (int j = 0; j < i; j++) {
                // 先判断升序条件，不满足直接跳过
                if (nums[i] > nums[j]) {
                    // 取更长的那条，注意 +1 别忘了
                    dp[i] = Math.max(dp[i], dp[j] + 1);
                }
            }
            System.out.println(Arrays.toString(dp));  // 观察执行流程
        }

        return Arrays.stream(dp).max().getAsInt();
    }
}
```

### 执行过程与返回值

* **逐轮推进**（以 `1 3 6 4 9` 为例）

    * 第一轮处理 `3`，与 `1` 组合出 `1 3`，长度更新为 2。
    * 第二轮处理 `6`，先与 `1` 组合得 2，再被 `1 3` 撑成 3。
    * 第三轮处理 `4`，只能与 `1`、`3` 组合，`6` 不满足升序被跳过，取 2+1=3。
    * 第四轮处理 `9`，与 `1`、`3`、`6`、`4` 依次组合，取 3+1=4，后面没有更长的了。

| 轮次 | 当前元素 | 尝试的前面元素 | 本轮结论 | 整行 dp |
| :--- | :--- | :--- | :--- | :--- |
| 初始 | — | — | 每个数各自成一条 | `[1,1,1,1,1]` |
| 第一轮 | `3` | `1` | `1 3` → 长度 2 | `[1,2,1,1,1]` |
| 第二轮 | `6` | `1`、`3` | 先 2，再被 `1 3` 撑成 3 | `[1,2,3,1,1]` |
| 第三轮 | `4` | `1`、`3`、`6`(跳过) | 取 2+1=3 | `[1,2,3,3,1]` |
| 第四轮 | `9` | `1`、`3`、`6`、`4` | 取 3+1=4，后面没有更长的了 | `[1,2,3,3,4]` |

* **返回值不能取末位元素**

    * 直接返回数组最后一个元素的值是错的。
    * 有一个用例整个数组的最长递增子序列长度是 6，像 `7 9 … 10` 那一串，但最后一个数字能组成的递增子序列是 `1 3 4 5 6`，它在 `dp` 里记录的长度只有 5。
    * 正确做法是遍历整个数组找最大值：先把 `dp` 数组转换成流，调用 `max` 方法得到最大值，最后用 `getAsInt` 转成整数。
    * 前面的用例求出最大值 4，末尾那个用例求出最大值 6。

> **提示**：`dp[i]` 的语义是「以 `nums[i]` 结尾的最长递增子序列长度」，不是「`nums` 的最长递增子序列长度」。整个数组的答案是所有 `dp[i]` 里的最大值，所以返回前必须遍历取最大值，不能直接返回 `dp[nums.length - 1]`。

## 不同的二叉搜索树

### 题目与五种形态

* **二叉搜索树（Binary Search Tree，BST）**

    * > **定义**：父节点左侧的节点都要比它小，右侧的节点都要比它大，满足这个条件就是二叉搜索树。
    * 题目（LeetCode 96）要求：给一个整数 $N$，求出 $N$ 个节点能够组成多少种二叉搜索树。

* **$N = 3$ 的五种结果**

    * ① 1 为根，3 直接跟 1 相连，2 在 3 的左侧。
    * ② 1 为根，2 直接跟 1 相连，3 在 2 的右侧。
    * ③ 2 为根，左边 1，右边 3，没有其他可选。
    * ④ 3 为根，1 直接跟 3 相连，2 在 1 的右侧。
    * ⑤ 3 为根，2 直接跟 3 相连，1 在 2 的左侧。
    * 五种加起来正好是 5。

```text
   ①            ②            ③            ④            ⑤
    \             \           / \          /            /
     3             2         1   3        1            2
    /               \                    \          /
   2                 3                    2        1
```

## 卡特兰数

### 术语与头几项数值

* **卡特兰数（Catalan Number）**

    * > **定义**：$N$ 个节点所能组成的二叉搜索树的总数，有一个专门的称呼，就是第 $N$ 个卡特兰数。
    * $C_1 = 1$：就一个节点，没有其他可能。
    * $C_2 = 2$：1 作根时 2 只能放在它的右侧；2 作根时 1 只能放在它的左侧，没有其他选择。
    * $C_3 = C_2 + C_1 + C_2 = 2 + 1 + 2 = 5$：1 作根时右边两个节点有 $C_2$ 种；2 作根时左右各一个，可看作 $C_1$；3 作根时左边两个节点有 $C_2$ 种。
    * $C_4 = 5 + 2 + 2 + 5 = 14$：1 作根右边 3 个节点是 $C_3$；2 作根左边 1 个不变、右边 2 个是 $C_2$；3 作根同理 2 种；4 作根左边 3 个是 $C_3$。
    * $C_5 = 42$，$C_6 = 132$。

### 递推公式

* **通用式**

    * $$C_n = \sum_{k=0}^{n-1} C_k \times C_{n-1-k}$$
    * 规则就是左边的卡特兰数乘上右边的卡特兰数，再把所有相乘的结果相加。

* **下标为什么是 $n-1$**

    * 根节点自己占掉了 1 个，剩下的 $n-1$ 个分给左右两棵子树。
    * 左边的 $k$ 个从比它小的数里选，右边的 $n-1-k$ 个自然从比它大的数里选。
    * 两边互不干扰，可以独立组合，所以相乘；根节点各有各的选择，所以累加。

* **$C_5$ 的拆分**

    * 每个根节点对应一组「左子树规模 / 右子树规模」，五组分别是 $(0,4)$、$(1,3)$、$(2,2)$、$(3,1)$、$(4,0)$。
    * 对应到卡特兰数就是 $C_0 \times C_4$、$C_1 \times C_3$、$C_2 \times C_2$、$C_3 \times C_1$、$C_4 \times C_0$，即 $1\times14$、$1\times5$、$2\times2$、$5\times1$、$14\times1$。
    * 相加得 $14 + 5 + 4 + 5 + 14 = 42$。

```text
5 个节点，每个根节点对应一组「左子树规模 / 右子树规模」：

   根 = 1        根 = 2        根 = 3        根 = 4        根 = 5
  (0, 4)       (1, 3)       (2, 2)       (3, 1)       (4, 0)
   C0 × C4     C1 × C3     C2 × C2     C3 × C1     C4 × C0
   1 × 14      1 ×  5      2 ×  2      5 ×  1      14 × 1
   = 14        =  5        =  4        =  5        = 14

   合计：14 + 5 + 4 + 5 + 14 = 42 = C5
```

> **提示**：`dp[0] = 1` 是这套递推的地基。$C_0$ 代表「空树」，只有一种（什么也不放），看着别扭但必须定成 1——不然 $C_1 = C_0 \times C_0$ 就直接算成 0 了。

### 拆分循环与一维缓存

* **先看拆分**

    * 求 5 的卡特兰数，先把它拆成五组：$(0,4)$、$(1,3)$、$(2,2)$、$(3,1)$、$(4,0)$。
    * 循环从 0 到 $N$，第一个数字就是 `i`，第二个数字的规律是 `n - 1 - i`：5 减 1 得 4，依次减 `i` 得到 4、3、2、1、0。
    * 打印时两个数字用两个 `%d`，中间加一个分隔符。
    * 拆完之后可以看到一个更大的卡特兰数被拆分成了更小的几个卡特兰数，但这些小卡特兰数还不知道，所以还得去算。

* **用动态规划缓存**

    * 为避免重复计算，采用动态规划：用一个一维数组把之前的 $C_0$、$C_1$、$C_2$ 等计算结果先缓存起来。
    * 数组大小选 $N+1$，因为下标是从 0 开始的。
    * 前几项认为已知：$C_0 = 1$、$C_1 = 1$，所以从第 2 项开始算。
    * 外层循环 `j` 从 2 开始直到要求的那个卡特兰数，索引位置是 $N$，所以条件是 `j < N + 1`。
    * 内层循环做第 `j` 个卡特兰数自己的拆分：第一次拆成 $(0,1)$ 和 $(1,0)$，第二次拆成 $(0,2)$、$(1,1)$、$(2,0)$，第三次拆成 4 个组合，第四次拆成 5 个组合。
    * 拆分里出现的 $N$ 不应该写死，写成外层的 `j` 即可，要记住 `j` 的含义是求第 `j` 个卡特兰数。
    * 累加必须写成 `+=`：内层循环完后 `dp[i]` 就存了这个位置正确的卡特兰数。
    * 返回值是最后这个索引处的元素 `dp[n]`；中间那些打印只是为了方便理解，最终注释掉。

```java
// 先只看拆分：把 C5 拆成五组 (左子树规模, 右子树规模)
for (int i = 0; i < 5; i++) {
    System.out.printf("(%d,%d)%n", i, 5 - 1 - i);
}
```

```java
class Solution {
    public int numTrees(int n) {
        // dp[i] = i 个节点能组成的二叉搜索树的种数，也就是第 i 个卡特兰数
        int[] dp = new int[n + 1];
        dp[0] = 1;   // C0 = 1，比较特殊的一项
        dp[1] = 1;   // C1 = 1

        // 外层：算第 i 个卡特兰数
        for (int i = 2; i < n + 1; i++) {
            // 内层：做第 i 个卡特兰数自己的拆分，左 j 个、右 i-1-j 个
            for (int j = 0; j < i; j++) {
                System.out.printf("(%d,%d)%n", j, i - 1 - j);   // 观察拆分过程
                dp[i] += dp[j] * dp[i - 1 - j];                 // 左 × 右，累加
            }
            System.out.printf("C%d = %d%n", i, dp[i]);            // 观察算出来的结果
        }

        return dp[n];
    }
}
```

> **注意**：第一次循环索引 2 的位置被累加成 2，第二次索引 3 被累加成 5，第三次索引 4 被累加成 14，最后一次索引 5 被累加成 42。
