# 进阶数据结构和算法-318-全排列-Leetco

## 全排列问题与手算思路

* **全排列（Permutation）**

    * > **定义**：给定一组数字，返回它们所有可能的排列结果；数字的相对次序全部打乱，每种排列只出现一次。

    * 例：`[1, 2, 3]` 的全排列共 6 种：`123`、`132`、`213`、`231`、`312`、`321`。

    * 结果规模等于每个数字都不重复地从「剩下的数字」里挑一个连起来：$3! = 6$。

* **手算思路**

    * > **结论**：先固定一个，再求剩下几个的排列——这个分解思路保证了整个求排列的过程不遗漏。

    * 对 `1、2、3`：先固定 1 求 2、3 的排列；再固定 2 求 1、3 的排列；再固定 3 求 1、2 的排列。

    * 剩下只有两个数时同样处理：固定其中一个后，剩余那个的位置就唯一确定了。

## 搜索状态的两个数组

* **原始数组（numbers）**

    * > **定义**：存放待排列的那些数字，搜索过程中原样往下传，不做任何修改。

* **状态数组（visited）**

    * > **定义**：布尔数组，记录每个位置的数字有没有被固定（被使用）过；`true` 表示已使用，`false` 表示未使用。

    * 长度与原始数组一致：`numbers.length`；三个数字就有三个布尔值，分别记录它们是否被使用。

    * 已经固定的数字画成灰色，未固定的画成绿色。循环里发现某个数字 `visited[i]` 为 `false`，就把它置 `true` 并固定下来。

* **路径集合（stack）**

    * > **结论**：只要这个集合的内容跟原始数组长度一致了，就表示我们找到了其中一种排列。

* **第一次搜索的状态推进**

    * `T` 表示已使用、`F` 表示未使用。

    * ```text
      起始    numbers = [1, 2, 3]   visited = [F F F]   stack = []

      i=0     1 未使用  -> push  ->  visited = [T F F]   stack = [1]
      i=1     2 未使用  -> push  ->  visited = [T T F]   stack = [1, 2]
      i=2     3 未使用  -> push  ->  visited = [T T T]   stack = [1, 2, 3]
                                             size == numbers.length
                                             -> 找到一种排列: 123
      ```

## 回溯长出剩余排列

* **回溯（Backtracking）**

    * > **定义**：递归深入一层处理完剩余数字后，把当前层对固定状态与路径的改动全部撤销，退回到「还有几个元素没被固定」的状态，再换一种次序继续。

    * 找完 `123` 后先取消 3 的固定（回溯一次），再取消 2 的固定（回溯一次）；此时 3、2 可以换一种固定次序，先固定 3 再固定 2，得到第二个排列 `132`。

    * 「先固定 1」的两种情况做完后，再回溯取消 2、3、1 的固定，恢复到最初始状态，改由固定 2 开头。

    * 固定 2 时同样先固定 1 再固定 3 得到 `213`；回溯后再先固定 3 再固定 1 得到 `231`。

    * 再回溯回到最初始状态，固定 3 开头，得到 `312` 和 `321`。

    * 搜索树的展开形状如下，叶子节点共 6 个：

    * ```text
      fix 1  --+-- fix 2 -- fix 3  --> [1,2,3]
               |     +-- fix 3 -- fix 2 --> [1,3,2]
               |
               +-- unfix 3, unfix 2, unfix 1  (back to the very start)
      fix 2  --+-- fix 1 -- fix 3  --> [2,1,3]
               |     +-- fix 3 -- fix 1 --> [2,3,1]
               |
               +-- unfix 3, unfix 1, unfix 2
      fix 3  --+-- fix 1 -- fix 2  --> [3,1,2]
               +-- fix 2 -- fix 1 --> [3,2,1]

      6 leaves in total
      ```

## DFS 递归方法

* **深度优先遍历（Depth First Search，DFS）**

    * > **定义**：每层固定一个数字后立刻递归下去处理剩下的数字，是执行这类「一层选一个」的枚举搜索最方便的写法；方法名叫 `dfs` 或别的都只是个名字。

    * 外层方法的返回结果是一个大 `List`，里面套多个小 `List`，每个小 `List` 存放一种排列结果。

* **递归方法的参数**

    * | 参数 | 作用 | 说明 |
      | --- | --- | --- |
      | `int[] numbers` | 原始数组 | 原样往下传，不用改 |
      | `boolean[] visited` | 状态数组 | 为 `true` 表示该数字已被使用，为 `false` 表示未被使用 |
      | `List<Integer> stack` | 路径集合 | 记录某一次的排列结果 |
      | `List<List<Integer>> result` | 结果集合 | 存下所有排列，后面补上 |

    * 首次调用：`numbers` 原样传过去；`visited` 布尔数组长度与原始数组一致；第三个参数给一个空 `ArrayList`；`result` 前面已经建好，直接传过去。

    * ```java
      public List<List<Integer>> permute(int[] numbers) {
          List<List<Integer>> result = new ArrayList<>();
          boolean[] visited = new boolean[numbers.length];
          dfs(numbers, visited, new ArrayList<>(), result);
          return result;
      }

      public void dfs(int[] numbers, boolean[] visited,
                      List<Integer> stack, List<List<Integer>> result) {
          if (stack.size() == numbers.length) {
              result.add(new ArrayList<>(stack));
              return;
          }

          for (int i = 0; i < numbers.length; i++) {
              if (visited[i]) {
                  continue;             // 已经固定过了，跳过
              }

              stack.add(numbers[i]);    // 固定：进路径
              visited[i] = true;        // 固定：打标记

              dfs(numbers, visited, stack, result);

              visited[i] = false;                    // 回溯：撤销标记
              stack.remove(stack.size() - 1);        // 回溯：撤销入栈
          }
      }
      ```

    * > **易错点** ⚠️：递归调用结束之后需不需要对当前状态做回溯？需要。这是最容易漏掉的一步。

    * 处理完 1、递归处理 2、3 结束后，接下来要固定 2，所以 1 的 `visited` 必须恢复成 `false`，`stack` 里的 1 也要回溯掉，`push` 过就要 `pop`。

    * 推论：每次都需要把状态恢复成递归调用之前的初始状态，才能尝试下一个候选。

## 递归停在哪

* **两种终止判定**

    * | 判断方式 | 怎么算 | 代价 |
      | --- | --- | --- |
      | 遍历 `visited` | 统计 `true` 的个数是否等于数字个数 | 每次递归都要扫一遍布尔数组，代码长 |
      | 看 `stack.size()` | 路径长度等于数组长度即命中 | 一次比较，直接 |

    * 第一种：看 `visited` 数组里所有位置是否都被标记为 `true`，全部数字都用过就结束递归；判断麻烦，因为要遍历布尔数组统计 `true` 的个数。

    * 第二种：找到一种排列时 `stack` 里加的元素个数也等于数字个数，`stack.size()` 直接能拿到这个个数，等于数字个数就返回；实现上选这一种。

    * > **提示**：返回之前可以把当时 `stack` 的状态打印出来核对；栈长为 3 的那次打印一共会出现六次，正好对应六种排列。

## 结果集与那一层副本

* **结果集合（result）**

    * > **定义**：外层预先建好的大集合，作为参数一路传给递归方法，用来容纳所有排列。

    * 递归方法命中一种排列时，把当时的小集合加进这个大集合即可。

* **副本拷贝**

    * 命中时执行 `result.add(new ArrayList<>(stack))`，新建一个 `ArrayList` 把当时 `stack` 里的元素放进去再收进 `result`。

    * > **易错点** ⚠️：这里直接加 `stack` 本体是不行的。

    * 原因：`stack` 在多次递归调用中内容会变——先由空一直加到 `1、2、3`，随后回溯又会被清空，直接引用同一个对象会让 `result` 里的每一条结果都指向同一份被反复改写的内容。

    * 所有递归结束后 `result` 里就记录了全部排列，返回外层这个 `result`；外面套一层循环把里面的小 `List` 逐个打印，得到那六种排列。

## 重复元素的全排列

* **不重复全排列（Permutation Unique）**

    * > **定义**：给定含重复元素的数组，返回所有互不相同的排列结果，把重复的排列剔除掉。

    * 例：`[1, 1, 3]` 按原来的 `visited` 写法会产出 `113`、`131`、`113`、`311`、`131`、`311`，`131` 与 `311` 都出现了多次。

    * > **结论**：先把原始数组排序，再定一条固定次序的规矩，就能保证排列过程中不出现重复结果。

* **排序的作用**

    * 先对原始数组做排序，目的是让取值相同的数字相邻存放。

    * 为便于称呼，把第一个 1 叫 `1`，第二个 1 叫 `1'`，从读音和视觉上都能区分。

* **规矩：必须先固定 1 再固定 1'**

    * > **定义**：固定两个相等元素的先后次序被确定下来——必须先固定第一个 1，然后才能固定 1'；先固定 1' 再固定 1 的情况视为非法。

    * 固定 1 分支下：`fix 1 → fix 1' → fix 2` 得 `113` 保留；`fix 1 → fix 1' → fix 3` 得 `131` 保留；`fix 1 → fix 3 → fix 1` 与 `fix 1 → fix 3 → fix 1'` 都违反规矩被剪掉。

    * 固定 3 分支下：`fix 3 → fix 1 → fix 1'` 得 `311` 保留；`fix 3 → fix 1' → fix 1` 违反规矩被剪掉。

    * 最终生成 `113`、`131`、`311` 三个排列，六个分支收敛为三条结果。

* **剪枝（Pruning）**

    * > **定义**：把违反固定次序规矩的分支直接判为非法、不再继续递归，使搜索树的分支变少，这个动作形象地称为剪枝。

    * 原原本本有六个分支，因为部分条件没有满足而不继续递归，分支因此变少。

## 剪枝条件怎么写

* **在循环里检查相邻同值**

    * 先在前一个代码的基础上改：第一步对原始数组排序，让有重复值的元素排到相邻位置，这一步是必须的。

    * 在循环里与上一个数字 `numbers[i-1]` 比较来发现相邻的重复值。

    * > **注意**：这个判断要带边界条件——`i` 等于 0 时没有上一个数字，不需要查找，所以必须再加一个前提 `i` 必须大于零。

* **判断条件**

    * `i` 有可能正好代表那个 `1'`，它对应的 `numbers[i-1]` 就是第一个 1。

    * 上一个数字是否已被固定，同样记录在 `visited` 数组里，查 `i-1` 位置即可。

    * `visited[i-1]` 为 `true` 说明上一个已访问过，可以继续递归；为 `false` 说明上一个还没固定，当前选择违反规矩，进入下一轮循环。

    * 该条件必须与「与上一个元素相等」的前提同时成立，所以用一个 `&&` 连接。

    * ```java
      public List<List<Integer>> permuteUnique(int[] numbers) {
          List<List<Integer>> result = new ArrayList<>();
          Arrays.sort(numbers);                          // 1. 让相等元素相邻
          dfsUnique(numbers, new boolean[numbers.length], new ArrayList<>(), result);
          return result;
      }

      public void dfsUnique(int[] numbers, boolean[] visited,
                            List<Integer> stack, List<List<Integer>> result) {
          if (stack.size() == numbers.length) {
              result.add(new ArrayList<>(stack));
              return;
          }

          for (int i = 0; i < numbers.length; i++) {
              if (visited[i]) {
                  continue;
              }

              // 2. 与上一个元素相等，且上一个还没被固定 -> 违反"先 1 后 1'"的规矩，剪掉
              if (i > 0 && numbers[i] == numbers[i - 1] && !visited[i - 1]) {
                  continue;
              }

              stack.add(numbers[i]);
              visited[i] = true;
              dfsUnique(numbers, visited, stack, result);
              visited[i] = false;
              stack.remove(stack.size() - 1);
          }
      }
      ```

    * ```text
      if (i > 0 && numbers[i] == numbers[i-1] && !visited[i-1]) continue;
      #         ^^^^^^  ^^^^^^^^^^^^^^^^^^   ^^^^^^^^^^^^^^^^^^
      #         有上一个   取值与上一个相同      上一个尚未被固定 -> 剪掉本分支
      ```

## 组合问题

* **组合（Combination）**

    * > **定义**：给定 `n` 与 `k`，返回 1 到 `n` 中所有长度为 `k` 的组合，不考虑顺序。

    * `n` 代表可参与组合的数字范围；`k` 代表要拿几个数字来组合；返回大 `List`，其中每个小 `List` 是一种组合。

    * 例：`n = 4, k = 2` 时共有 6 种组合：`1,2`、`1,3`、`1,4`、`2,3`、`2,4`、`3,4`。

* **组合与排列的差别**

    * | | 全排列 | 组合 |
      | --- | --- | --- |
      | 关心什么 | 顺序 | 只要选中了哪些数字 |
      | 1、2 与 2、1 | 两种不同结果 | 同一种结果 |
      | 例子 | 12、21 | 12 |
      | 搜索时每个数字 | 能跟任何剩下的数字配 | 只能跟比自己大的数字配 |

    * 与排列思路非常像：一开始也先固定 1，但光有 1 凑不够 `k` 个，所以 1 要跟后面的 2、3、4 依次尝试组合。

    * 凑满 `k` 个就找到一种有效组合；固定 4 时没有更多数字可配，是无效组合，不计入结果。

* **start 起始数字**

    * > **定义**：一个额外的参数 `start`，代表本层循环的起始处理数字。

    * 处理 1 时要处理 1 到 `n` 全部；处理 2 时不必回头从 1 开始（2 不用再跟 1 组合），只需从 2 开始；处理 3 时循环从 3 开始；处理 4 时没有可配对象。

    * ```text
      handling 1 : start = 1   ->  i takes 1, 2, 3, 4
      handling 2 : start = 2   ->  i takes 2, 3, 4
      handling 3 : start = 3   ->  i takes 3, 4
      handling 4 : start = 4   ->  i takes 4      (nothing left to pair with)
      ```

    * 首次调用时：`start` 从 1 开始，`n` 与 `k` 由外层传入，空 `ArrayList` 新建后传入，`result` 前面建好直接传过去。

## 组合的递归代码

* **参数构成**

    * 除了外层的 `n` 和 `k`，还需要路径小集合 `stack`（存某一次组合结果）和存储所有组合的大集合 `result`。

* **终止条件**

    * `stack` 的大小等于 `k` 就说明找到一种组合，结束递归；结束前要把 `stack` 当前内容复制一份副本再收进结果，因为 `stack` 内容将来会变化。

    * ```java
      public List<List<Integer>> combine(int n, int k) {
          List<List<Integer>> result = new ArrayList<>();
          dfs(n, k, 1, new ArrayList<>(), result);
          return result;
      }

      public void dfs(int n, int k, int start,
                      List<Integer> stack, List<List<Integer>> result) {
          if (stack.size() == k) {
              result.add(new ArrayList<>(stack));   // 凑满了，复制一份收进结果
              return;
          }

          for (int i = start; i <= n; i++) {
              stack.add(i);                        // 先把当前这个数字加入 stack
              dfs(n, k, i + 1, stack, result);     // 再去尝试固定后面的数字
              stack.remove(stack.size() - 1);       // 组合结束，pop 掉，恢复最初状态
          }
      }
      ```

    * 循环变量 `i` 从 `start` 开始到 `i <= n` 结束；`start` 初始为 1、`n` 为 4 时，i 依次取 1、2、3、4，即依次去固定这四个数字。

    * 每次先把当前数字 `push` 进 `stack`（i 等于 1 时把 1 加进去），再递归尝试固定后面的 2、3、4。

    * 第二层递归显然不该再从 `start` 开始：1 已固定，所以应从 2 开始；因此递归调用传 `i + 1`，`n`、`k`、`stack`、`result` 原样不动传过去。这一层做出了 `1,2`、`1,3`、`1,4`。

    * 组合结束后恢复最初状态，把刚 `push` 的元素 `pop` 掉，才能继续尝试固定 2、3、4。

    * > **结论**：有一个 `push` 就必然有一个对应的 `pop`，两者必须成对。

    * 跑一遍得到 `1,2`、`1,3`、`1,4`、`2,3`、`2,4`、`3,4` 六种组合。

* **start 为什么必须是 i + 1**

    * > **易错点** ⚠️：如果递归时不传 `i + 1` 而固定传 1，等于每层循环都从 1 遍历到 `n`，求出来的就不再是组合而是排列。

    * 反例的结果如下：

    * ```text
      pass 1 :  dfs(n, k, 1, ...)
                12 13 14
                21 22 23 24
                31 32 33 34

      this is no longer combination -- it is PERMUTATION
      ```

    * 从排列角度看 `1,2` 与 `2,1` 确实不同，但从组合角度看两者重复，`1,3` 与 `3,1` 同理。

    * 改成传 `i` 也不行：第一轮循环会得到 `1,1`、`1,2`、`1,3`、`1,4`，第二轮是 `2,2`、`2,3`、`2,4`，第三轮 `3,3`、`3,4`，第四轮 `4,4`。

    * 组合中 1 不能跟 1 自己组合，它要跟比他大的数字组合，从比自己大一的那个数字起向后一直到 `n`，所以 `start` 必须等于 `i + 1`。

## k 等于 3 的情形

* **n = 4、k = 3 的搜索过程**

    * 先固定 1，1 先跟 2 组合，个数不够 `k = 3`，于是 `1,2` 再与剩下的 3、4 组合：`1,2,3` 为第一种组合。

    * 回溯一次取消 3，`1,2` 再与 4 组合，得到第二种组合 `1,2,4`；数字用完后回溯两次回到 1，为接下来 1 跟 3 组合做准备。

    * 固定 1 的情况下先跟 3 组合，`1,3` 个数不够，再与剩下的 4 组合，得到第三种组合 `1,3,4`。

    * 再回溯到 1，1 跟 4 组合之后没有更多数字，构不成有效组合，继续把 4 和 1 都回溯掉。

    * 轮到 2：2 先跟 3 组合，个数不够，再与剩下的 4 组合，得到第四种组合 `2,3,4`；回溯到 2 后 2 跟 4 组合个数不够，是无效组合，继续回溯到最初始位置。

    * 轮到 3：3 跟 4 组合同样无效；最后数字 4 再尝试时没人跟它组合。

    * 最终找到 4 种组合：`1,2,3`、`1,2,4`、`1,3,4`、`2,3,4`。

## 题目速查

* **全排列**

    * 题目：给定一个数字数组，返回它所有可能的排列结果。例：输入 `[1, 2, 3]`，输出 6 种。

    * 思路：用 `visited` 布尔数组记录每个位置是否已被固定，用 `stack` 记录当前这条路径；路径长度等于数组长度即命中一种排列，命中时复制一份进 `result` 而不是直接放 `stack` 本体。

    * 答案：`123`、`132`、`213`、`231`、`312`、`321`，共 6 种。

* **不重复的全排列**

    * 题目：给定一个含重复元素的数组，返回它所有互不相同的排列结果。例：输入 `[1, 1, 3]`，输出 3 种。

    * 思路：先排序让相等元素相邻，再定「必须先固定第一个 1 再固定第二个 1」这条规矩，最后用一个条件把违反规矩的分支剪掉。

    * 答案：`113`、`131`、`311`，共 3 种。

* **组合**

    * 题目：给定两个整数 `n` 和 `k`，返回 1 到 `n` 中所有长度为 `k` 的组合。

    * 思路：用 `start` 参数保证每个数字只跟比自己大的数字配对，凑满 `k` 个就复制一份收进结果，每层 `push` 之后必须配对 `pop`。

    * 答案：`n = 4, k = 2` 时为 `1,2`、`1,3`、`1,4`、`2,3`、`2,4`、`3,4`，共 6 种；`n = 4, k = 3` 时为 `1,2,3`、`1,2,4`、`1,3,4`、`2,3,4`，共 4 种。
