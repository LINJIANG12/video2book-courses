# 自动控制原理·卢京潮（80 讲）

西北工业大学卢京潮老师的《自动控制原理》4K 修复版：以「系统建模 → 时域分析 → 根轨迹 → 频域分析与校正 → 离散系统与非线性系统」为主线，把经典控制理论的完整体系从头讲到尾。课程特点是推导与工程直觉并重——每个定理都给证明思路，每种校正方法都配伯德图上的实操画法，末章还有期末真题全卷精讲。适合自动化/电气类本科主干课学习与考研复试打底。

- **原视频**：[【4K修复】自动控制原理 卢京潮 西北工业大学](https://www.bilibili.com/video/BV1LKLPzfEm4) — Bilibili，BV1LKLPzfEm4
- **全 80 集**，已产出 8 册模块全书、9 篇复习笔记、80 份逐字稿

## 怎么学

- **建模是全程的地基** → 笔记 01-02 把微分方程、传递函数、结构图化简与梅森公式收拢，后续每一章的推导都建在这两篇上，信号流图的回路/不接触回路判定要练熟
- **时域抓「三性能 + 两校正」** → 笔记 03 把动态性能指标、稳态误差（型别与静态误差系数）、一阶二阶系统的时域响应、主导偶极子串成一条线
- **根轨迹与频域互为镜像** → 笔记 04-06 是本课分量最重的部分：绘制法则、广义根轨迹、奈奎斯特判据、稳定裕度，再到串联超前/滞后校正的设计步骤，画图题按固定流程走
- **离散与非线性按「工具替换」理解** → 笔记 07-08 用 z 变换替换拉氏变换、用相平面/描述函数替换线性方法，抓住「方法平移」这条主线就不乱
- **考前用真题册** → 第 8 册与笔记 09 是期末真题全卷精讲与串讲，按题复盘整门课的方法调用
