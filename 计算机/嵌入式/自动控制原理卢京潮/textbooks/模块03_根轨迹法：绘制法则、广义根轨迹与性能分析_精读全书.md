## 根轨迹法开篇：基本概念、根轨迹方程与前三条绘制法则
> 对应块：BLK25 | 覆盖分集：P25 | 块标题（分集名）：《第13节课4 根轨迹法4.1 基本概念4.2 法》

### 课程走到哪了：三大分析方法登场

先把课程的体系结构图再审视一遍，看看我们现在站在哪儿。第一章讲了一般概念，第二章把系统模型建立起来了。模型建立以后，课程就剩下两大任务：讲模型和指标之间的关系。正向的关系是——已知模型，把系统"稳、准、快"三项指标拿出来，这叫**分析**；反过来，如果给定的性能指标达不到，那就要在系统当中加上结构参数可调的校正装置，让性能指标达标，这个工作叫**校正**。

到上节课为止，时域法已经讲完了。今天开始进入第四章——复域法，也就是**根轨迹法**。它和时域法、频域法并列，是经典控制理论当中的三大分析方法，都是解决系统分析和校正这两大任务的。

和时域法相比，根轨迹法有它自己的特点：

- 它立足于**画图**来分析系统，是一种图解的方法。既然是做图，就比较直观、比较形象；
- 它特别适合研究一类问题——系统当中的**某一个参数**发生变化时，系统的性能会发生相应的什么变化。研究这类问题，用根轨迹法特别合适；
- 也正因为它是图解方法，手工画图时不一定非常精确，有时带有一定的**近似性**。

顺带说一句，三大方法里频域法是最简单的，用时也最短，四次课就能把它讲完。

### 根轨迹到底是什么

> **定义**：系统当中的某一个参数（通常是根轨迹增益 $K^*$）从零到无穷大变化的过程当中，**闭环极点**在 $S$ 平面当中相应变化所描绘出来的轨迹，就叫根轨迹。

参数变化会影响闭环特征根，特征根也要相应变化。参数从零到无穷大连续变化时，根就在 $S$ 平面当中相应移动，移动出来的轨迹就是根轨迹——根，就是闭环的根的轨迹。

> **易错点**：从概念上讲，根轨迹一定是**闭环的根**的轨迹，没有"开环根轨迹"一说。

### 两个增益先分清：开环增益与根轨迹增益

举个具体例子。有一个系统，结构图是一个一型的、二阶的、增益为 $K$ 的单位反馈系统——这些术语现在都应该熟悉了。现在的问题是：开环增益 $K$ 从零到无穷大变化时，闭环极点会发生什么样的变化。

先把开环传递函数写出来，这是尾一标准型：

$$G(s)=\frac{K}{s(0.5s+1)}$$

这个 $K$ 叫**开环增益**。而在根轨迹法研究的时候，我们习惯上把开环传递函数写成**首一标准型**——把 0.5 提出来：

$$G(s)=\frac{K^{*}}{s(s+2)}$$

写成首一标准型以后，这个系数 $K^{*}$ 就有个名字，叫**根轨迹增益**。

这里要把概念掰清楚：

> **定义**：开环传递函数化成尾一标准型，其系数叫开环增益；化成首一标准型，其系数叫根轨迹增益。

> **易错点**：根轨迹增益**仅对开环而言**。你若把闭环传递函数拿出来化成首一标准型，那个增益可不叫"闭环根轨迹增益"——根本没有闭环根轨迹增益一说。而且这个概念一般只在根轨迹法研究的过程当中使用。

在这个题当中，开环增益和根轨迹增益之间就差个比例（$K^{*}=2K$）。所以"$K$ 从零到无穷大变化"和"$K^{*}$ 从零到无穷大变化"是等价的问题。

### 亲手画一条根轨迹

要研究闭环根的问题，当然要把闭环传递函数写出来，令其特征多项式等于零，得到特征方程：

$$s^{2}+2s+K^{*}=0$$

这是一元二次方程，根可以直接解出来：

$$s_{1,2}=-1\pm\sqrt{1-K^{*}}$$

显然，根的位置和 $K^{*}$ 的值有关：$K^{*}$ 不同，根的位置也不同。

先把 $S$ 平面画出来，把开环极点标上——开环极点有两个，一个在 0，一个在 $-2$；开环零点没有。这就是本题的开环零极点分布图。

现在让 $K^{*}$ 取一系列值，看两个闭环极点怎么走：

| $K^{*}$ 的取值 | 闭环极点 $\lambda_{1,2}$ |
| :---: | :---: |
| $0$ | $0,\ -2$（恰好落在开环极点上） |
| $0.64$ | $-0.4,\ -1.6$ |
| $1$ | $-1$（二重根，两支在分离点会合） |
| $2$ | $-1\pm \mathrm{j}1$（一对共轭复根） |
| $5$ | $-1\pm \mathrm{j}2$ |
| $17$ | $-1\pm \mathrm{j}4$ |

趋势已经看出来了：一个根一直向上走，一个根一直向下走，一直到无穷。取的这些点是离散的；如果让 $K^{*}$ 从零连续地一直走到无穷大，闭环极点就会在 $S$ 平面当中画出一条连续的轨迹来：

```text
                 jω
                  ↑
          │       │
          ↓       │      K*→∞（一支向上趋于无穷）
          │       │
          ✕       │      K*=2：-1±j1
          │       │
          │       │
   ──●───●───●───●──────┼──────→ σ
    -2 -1.6 -1 -0.4     0
          │       │
          ✕       │      K*=2：-1-j1
          │       │
          ↓       │      K*→∞（一支向下趋于无穷）

   K*=0 时两根分别在 -2 与 0（开环极点上）；
   K* 增大，两根沿实轴相向而行，在 -1 处会合（K*=1），
   随后一上一下分开，沿 σ=-1 趋于无穷。
```

这就是闭环极点随 $K^{*}$ 从零到无穷大演变过程当中，在 $S$ 平面当中画出来的轨迹——根轨迹，就这意思。

### 画根轨迹图有什么用：稳、准、快一眼看穿

根轨迹画出来了，它到底有什么用？我们把 $K^{*}$ 从 0 到 $\infty$ 的变化过程，拿 1 当一个中间站点，分两段看动态性能，再看稳和准。

**先看 $K^{*}$ 在 0 和 1 之间。** 这时根轨迹走的是实轴上那一段，取一个值，两个闭环极点是互异的单根——系统呈现**过阻尼**状态，阻尼比大于 1，单位阶跃响应的超调量等于零，没有超调。那调节时间呢？当 $K^{*}$ 从零往一趋近时，两个极点相向而行，一个往左、一个往右，调节时间是越来越**短**的。为什么？这两个极点都对动态性能有影响，但起主导作用的是**靠虚轴近的那个极点**——粗略地看，这个二阶系统可以近似成这个主导极点对应的一阶系统；这个极点离虚轴越来越远，一阶系统的调节时间就越来越短。主导极点的概念，在这里就用上了。

**再看 $K^{*}$ 从 1 往无穷大走。** 这时根轨迹从分离点一上一下分开了，闭环极点成了一对共轭复根，系统呈现**欠阻尼**状态，阻尼比在零和一之间。随着 $K^{*}$ 增大，根越来越往上走，$\beta$ 角越来越大，阻尼越来越小，**超调量越变越大**。而调节时间**基本不变**——按"3 除以根的实部"那个办法算，根的实部没有变，调节时间自然基本不变。

这样一来，"快"的问题看清了。再看"稳"：稳定性取决于是不是所有的闭环极点都在虚轴左边。你看，$K^{*}$ 只要大于零，这两个根就严格地都在虚轴左边——所以不管 $K^{*}$ 取多大，这个系统**始终是稳定的**，这是个**绝对稳定系统**，改变 $K$ 根本不影响稳定性。

最后看"准"：这个系统是一型的，给它输入斜坡信号，稳态后必定有一个非零的常值稳态误差。$K^{*}$ 增加实际上就是 $K$ 增加（两者是两倍关系），查稳态误差表格，误差等于 $1/K$——$K^{*}$ 越大，稳态误差就越小。

> **结论**：根轨迹一画出来，稳、准、快三项指标的变化趋势不用定量精确计算，心里就非常清楚了。这就是画根轨迹、用根轨迹法分析系统的意义所在。

### 闭环零点会不会跟着 K* 跑

不过这里要提出一个问题来。研究系统性能指标，"稳"的问题只和闭环极点有关；但**动态性能指标不仅和闭环极点有关，还和闭环零点也有关**——闭环零点会影响系统响应的模态，也就是前面那些加权系数；加权系数一变，动态响应的形式就变了，超调量、调节时间都不一样。

于是就提出这样的问题：你根据根轨迹来判断动态性能好坏，除了把闭环极点的轨迹画出来，闭环零点是不是也要定？闭环极点随 $K^{*}$ 变化，那闭环零点是不是也随 $K^{*}$ 变化？如果真是这样，你就不但要画闭环极点的根轨迹，还得画闭环零点的轨迹咯？

把这个问题研究一下。给一个系统结构图，前向通道和反馈通道闭起来，用颜色把零极点分开标记：把**红的**看成前向通道开环零点的代表，**蓝的**看成前向通道开环极点的代表，**黑的**是反馈通道开环极点的代表，**绿的**是反馈通道开环零点的代表——每个都可以有很多个。

开环传递函数就是把这一整圈全部乘过来，红绿蓝黑乘到一块。显然：

- 开环的零点 = 前向通道的零点和反馈通道的零点放在一块；
- 开环的极点 = 前向通道的极点和反馈通道的极点放在一块。

系统已经化成首一标准型，$K_1$、$K_2$ 就是根轨迹增益；把各环节常数都提出来化成尾一标准型，例如二、四提出来，三、五也提出来，二四得八除以三五十五，乘上那套东西就是开环增益。所以对特定问题来讲，开环零极点给定后，开环增益和根轨迹增益之间就差一个比例系数，"开环增益从零到无穷大变化"就相当于"根轨迹增益从零到无穷大变化"。

下面推闭环传递函数。用梅逊增益公式：只有这一个回路，特征式 $\Delta$ 就是一减这一圈，也就是"一减开环传递函数"；上面是 $\Delta_1 P_1$，$\Delta_1$ 等于 1，$P_1$ 就是红的蓝的乘到一起。然后把分子分母同时乘上反馈通道分母那一套东西：一乘之后，分母变成"前向通道分母 × 反馈通道分母 ＋ 前向通道分子 × 反馈通道分子"；分子当中呢，有**红的**（前向通道零点），但是没有黑的（反馈通道极点）——把黑的要倒到上面去。

现在看结论：

- 从**分母**来看：开环零极点给定了，$K_1 K_2$ 是根轨迹增益，它一变，特征多项式的系数就变，闭环极点就要变——所以才有研究闭环根轨迹的问题。**闭环极点是随根轨迹增益的变化而变化的**；
- 从**分子**来看：闭环零点是"死的"——红的是前向通道的开环零点，黑的是反馈通道的开环极点，它们都不含 $K^{*}$。

> **结论**：闭环零点 = 前向通道的开环零点 ＋ 反馈通道的开环极点（不含反馈通道的零点，但要加上反馈通道的极点）。它**不随 $K^{*}$ 的变化而变化**，是固定的。

这个结论以后的课程当中还要用到，把它记住。问题现在明确了：我们**不必**研究闭环零点随 $K^{*}$ 变化的问题，它不变，**只研究闭环极点**的问题就行了。闭环极点和开环零点、开环极点以及根轨迹增益都有关；开环零极点确定时，闭环极点随根轨迹增益变化——所以才有画根轨迹的必要。

### 根轨迹方程：问题的根子

根轨迹问题的根子，在**根轨迹方程**上。先举个简单的例子：一个一阶系统加单位反馈。开环传递函数写出来，$K^{*}$ 是根轨迹增益（它已经是首一标准型，而且是开环的）。

要求根的问题，把闭环传递函数写出来，等于"它除以一加它"。讨论根，就是让分母等于零：

$$1+G(s)=0$$

把这个 1 移到一边，就是：

$$G(s)=-1$$

这个方程和特征方程是等价的，我们把它叫做**根轨迹方程**。

开环传递函数是 $s$ 的复函数，所以这是个复方程，有模、有相角的问题。两边取模、取相角，就得到两个条件：

- **模值条件**：开环的模应该等于 1；
- **相角条件**：开环的相角要等于 $-1$ 的相角，即 $(2k+1)\pi$。

#### 矢量怎么看：s−p 就是由极点指向试验点

一个复数在 $S$ 平面当中可以用一个复矢量表示，矢量有了，模和相角不就都有了吗。看开环传递函数里包含的 $K^{*}$：它是个正值，可以用一个矢量表示——从原点指向 $K^{*}$ 这个点，模就是 $K^{*}$，相角零度。而 1 这个矢量呢，模等于 1，相角 $\pi$ 也行、$-\pi$ 也行，反正 $(2k+1)\pi$，$k$ 取零、正一、正二都可以。

那 $s-p$ 这个矢量怎么画？先看 $p$：它是一个开环极点，从原点指向它，这个矢量就是 $p$。$s$ 是个自变量，在 $S$ 平面中任意可取，随便找一点；从原点指向它就是 $s$ 矢量，相角按数学定义从实轴正方向逆时针转过去。$s-p$ 怎么找？把 $p$ 倒过来画，就是 $-p$，从原点指向这个端点的矢量就是 $s-p$；如果不计矢量的起点，**$s-p$ 就是由 $p$ 指向 $s$ 的矢量**：

```text
              jω
               ↑             S（试验点，任意取）
               │           ↗
               │         ╱
               │       ╱    ← 矢量 s−p：由极点 p 指向 S
               │     ╱
       ────────┼──●──────────→ σ
                 p（开环极点）
```

图上从极点 $p$ 引向试验点 $S$ 的那根连线，就是 $s-p$ 矢量：它的模是连线长度，它的相角是从 $p$ 看向 $S$ 时与实轴正方向的夹角。

现在在 $S$ 平面中任取一点，判断它是不是根轨迹上的点——就看它能不能**同时满足**模值条件和相角条件：

- 先看模值条件：矢量有个长度，而 $K^{*}$ 是从零到无穷大可以任取的——我让 $K^{*}$ 就取这个长度，总能保证模值条件成立。所以**第一个条件总是可以满足的**；
- 再看相角条件：随便取的那个点，$s-p$ 矢量的相角显然和 $(2k+1)\pi$ 不一样——不满足。两个条件当中任意一个不满足，方程就不满足，这个点就不是根，不是根轨迹上的点。

换个点再试：取到极点左边实轴上的某一点。模值条件照旧总能满足；相角呢？$s-p$ 就是由 $p$ 指向该点的矢量，相角恰好等于 $180^{\circ}$，落在 $(2k+1)\pi$ 当中——同时满足两个条件，**这个点是根轨迹上的点**。照此推理：从这个极点一直往左、一直到负无穷，全是根轨迹上的点。只不过不同的点对应的 $K^{*}$ 值不一样而已。

### 一般情形的幅值条件与相角条件

看一般的情况。系统由前向通道传递函数和反馈通道传递函数闭起来，把开环传递函数写出来，总可以写成（已经化成首一标准型）：

$$G(s)=\frac{K^{*}\prod\limits_{j=1}^{m}(s-z_j)}{\prod\limits_{i=1}^{n}(s-p_i)}$$

其中 $K^{*}$ 是根轨迹增益，$z_1\sim z_m$ 是 $m$ 个开环零点，$p_1\sim p_n$ 是 $n$ 个开环极点。要把开环增益写出来，就化成尾一标准型，把所有 $z_j$、$p_i$ 都提出来——开环增益和根轨迹增益之间就差一个比例系数，所以开环增益从零到无穷大变化，就相当于根轨迹增益从零到无穷大变化。

根轨迹方程 $1+G(s)=0$，两边取模：左边每个小括号都看成一个复矢量，所有矢量取模乘起来，等于 1。得到：

$$\text{模值条件：}\quad \frac{K^{*}\prod\limits_{j=1}^{m}\left|s-z_j\right|}{\prod\limits_{i=1}^{n}\left|s-p_i\right|}=1$$

相角呢，把分子矢量对应的相角加起来，减去分母所有矢量对应的相角之和，要等于 $-1$ 的相角：

$$\text{相角条件：}\quad \sum_{j=1}^{m}\angle(s-z_j)-\sum_{i=1}^{n}\angle(s-p_i)=(2k+1)\pi$$

这就是根轨迹方程的模值条件和相角条件的一般表达式。

#### 拿一个零型二阶系统逐点验货

用一个具体系统把这两个条件理解透彻。这是个零型的二阶系统——零型的意思是没有积分环节，$V=0$。写成首一标准型：

$$G(s)=\frac{K^{*}}{(s+1)(s+5)}$$

开环极点两个：$-1$ 和 $-5$；开环零点没有。把零极点分布标在 $S$ 平面当中，由此开始讨论。对这个题来讲，模值条件化成：

$$\left|s+1\right|\cdot\left|s+5\right|=K^{*}$$

相角条件化成：

$$\angle(s+1)+\angle(s+5)=(2k+1)\pi$$

现在在 $S$ 平面当中找点，判断这个点是不是在根轨迹上。

**第一个点：$s=-2$。** 连两个矢量：$s+1$ 就是由 $-1$ 指向 $-2$ 的矢量，$s+5$ 就是由 $-5$ 指向 $-2$ 的矢量。模：$|-2+1|\cdot|-2+5|=1\times3=3$，那我就取 $K^{*}=3$，模值条件满足。相角：一个矢量的相角是 $\pi$，另一个是 $0$，加起来等于 $\pi$，刚好落在 $(2k+1)\pi$ 当中——**这个点是根轨迹上的点**。而且可以推断：$-1$ 和 $-5$ 之间这个实轴线段上的任何一个点，都是根轨迹上的点。

**第二个点：$s=-8$。** 连矢量：由 $-5$ 指向它一个，由 $-1$ 指向它一个。相角：一个 $180^{\circ}$，另一个也是 $180^{\circ}$，加起来 $360^{\circ}$——不在 $(2k+1)\pi$ 当中。所以这个点**不是**根轨迹上的点，由此可以判断：$-5$ 以左一直到负无穷的区段，都不是根轨迹。

**第三个点：$s=7+\mathrm{j}4$。** 现在是复数了，模照样能算出一个确定的 $K^{*}$ 值——但这个没有关系，**关键在相角**：两个矢量的相角加起来显然不等于 $(2k+1)\pi$。所以这个点不是根轨迹上的点。

**第四个点：$s=3+\mathrm{j}3$。** 这个点巧在什么地方？它刚好在 $-1$ 和 $-5$ 连线（实轴线段）的**垂直平分线**上，所以构成的三角形是等腰三角形，这个角等于那个角，两个矢量相角加起来恰好是 $180^{\circ}$——**这个点是根轨迹上的点**。由此可以推断：$-1\sim-5$ 这条垂直平分线上的任何一个点，都是根轨迹上的点。

#### 相角条件是充要的

由这些尝试可以推出一个重要结论：

> **结论**：在 $S$ 平面上的任何一个点，总能找到一个 $K^{*}$ 使它满足模值条件——这没问题；但这个点不一定是根轨迹上的点，因为它不一定满足相角条件。反过来，**满足相角条件的点，一定能找到一个 $K^{*}$ 的值使模值条件也满足**。所以：满足相角条件，是点位于根轨迹上的**充分必要条件**；而根轨迹上某一点对应的 $K^{*}$ 值是多少，要由模值条件来确定。

刚才这么一折腾，可能大家心里都凉了半截——这么一个点一个点地画根轨迹，可是有点不切实际。两个点、三个点还凑合，开环零极点分布要比较复杂的话，你找都没法找。所以画根轨迹**不是这么去找的**，是靠**绘制根轨迹的法则**来画的。

### 法则一：起于开环极点，终于开环零点

书上讲了八条法则，今天我们讲四条。画根轨迹就是依据这些法则去画的。

第一条法则说：根轨迹**起始于开环极点，终止于开环零点**。注意，根轨迹都是闭环意义下的根的轨迹。什么叫起点、终点？我们研究的是 $K^{*}$ 从零到无穷大变化的过程：$K^{*}=0$ 时闭环极点的位置就是起点，$K^{*}=\infty$ 时闭环极点的位置就是终点。

推导用模值条件就够了。把模值条件倒过来写：

$$\frac{\prod\limits_{i=1}^{n}\left|s-p_i\right|}{K^{*}\prod\limits_{j=1}^{m}\left|s-z_j\right|}=1$$

把分子分母同时除上一个 $|s|^{n}$，除到里面去：

$$\frac{\prod\limits_{i=1}^{n}\left|1-\dfrac{p_i}{s}\right|}{K^{*}\prod\limits_{j=1}^{m}\left|1-\dfrac{z_j}{s}\right|}\cdot|s|^{\,n-m}=1$$

- **看起点**：令 $K^{*}=0$，这个方程什么时候成立？$s$ 等于 $p_1$、等于 $p_2$、……、等于 $p_n$ 都可以——分子为零。所以根轨迹**起于开环的极点**；
- **看终点**：令 $K^{*}\to\infty$。要么 $s=z_1,\dots,z_m$（让 $\left|1-\dfrac{z_j}{s}\right|=0$）——终止到开环零点；但这只是 $m$ 个结果，还有 $n-m$ 个分支没有着落——它们可以让 $|s|\to\infty$：每一项 $\left|1-\dfrac{p_i}{s}\right|$、$\left|1-\dfrac{z_j}{s}\right|$ 都趋于 1，$|s|^{n-m}$ 那一项恰好被 $K^{*}$ 的无穷大抵消。所以剩下 $n-m$ 条分支**跑到无穷远处**。

> **结论**：根轨迹起始于开环极点，终止于开环零点；开环零点数比开环极点数少的那 $n-m$ 条分支，趋于无穷远。

回看刚才那个二阶例子：只有两个开环极点、没有开环零点，两条分支没有着落，就一上一下都跑到无穷远去了——和法则对上了。

### 法则二：分支数、连续性与对称性

第二条法则包含三件事：

- **分支数**：根轨迹的分支数就是特征方程的阶数。特征方程是几阶，就有几个根；有几个根，就有几条根轨迹分支。而特征方程 $1+G(s)=0$ 写出来，是开环的分母加开环的分子——分母的阶数一般比分子高，所以特征方程的阶数取决于开环的分母，也就取决于开环极点数。**分支数 = 特征方程阶数 = 开环极点数**，这个好理解；
- **连续性**：$K^{*}$ 从零到无穷大连续变化，根也在 $S$ 平面当中连续变化，不会出现断点；
- **对称性**：根轨迹**对称于实轴**。为什么？实际物理系统抽象出来的数学模型，对应的特征方程都是**实系数**的特征方程——从来没有见过复系数的特征方程。实系数特征方程在代数上有定理：它的根要么是单根，要么成共轭对出现，复根一定是共轭成对出现的。这就决定了根轨迹画出来以后，一定关于实轴上下对称。

### 法则三：实轴上的根轨迹

第三条法则说得极为明确：

> **法则**：在 $S$ 平面当中，实轴上从**最右端**的那个开环零点或开环极点向左算起，**奇数**个开环零极点到**偶数**个开环零极点之间的区段，一定是根轨迹；否则一定不是根轨迹。

说明一下为什么。在实轴上任找一点，判断它是不是根轨迹上的点——就看它满不满足相角条件（相角条件是充要的嘛）。把所有的圈圈（零点）叉叉（极点）都向它引矢量：

- **复平面上的共轭零极点对**：一对共轭极点引出的两个矢量相角加起来刚好一圈（$2\pi$），对 $(2k+1)\pi$ 只不过是多绕了一圈，无关紧要；零点也一样，多一圈少一圈的事情。所以**复平面当中的开环零极点都不用考虑**；
- **试验点左边的实轴零极点**：矢量都指向左边，相角个个都是 $0^{\circ}$，对 $(2k+1)\pi$ 没有贡献，不用考虑；
- **试验点右边的实轴零极点**：只要有一个圈圈或叉叉，它就贡献一个 $\pi$（$180^{\circ}$）。

```text
   ────✕────✕──────────●────────○────→ σ
       p*    p̄（共轭对） s         z
       （p*与p̄两矢量的相角相加 = 2π，多绕一圈不影响判定）
                          ↑        ↑
                    s 右侧的极点：  s 左侧的零点：
                    相角 = 180°    相角 = 0°
```

图上试验点 $s$ 右边每有一个实轴零点或极点就贡献 $180^{\circ}$，左边和复平面的贡献要么为零、要么凑成整圈——所以只要数 $s$ **右边**实轴上零极点的总个数：是奇数，总相角一定是 $(2k+1)\pi$，这个点一定是根轨迹上的点。

所以最右端那个零极点向左，第一个区段（右边 1 个，奇数）是根轨迹；再往左，奇数到偶数之间的区段是根轨迹……照此推理一直到无穷。画根轨迹的时候，上来不干别的，**先把实轴上的根轨迹一笔画出来**——这条法则极为明确。

到这里，根轨迹的基本概念、根轨迹方程和前三条法则就立起来了：先判零极点、再定起止、分支数与对称性，然后实轴段一笔画。后面的法则、广义根轨迹以及怎么用根轨迹分析系统性能，接着往下推。

## 根之和法则与复平面上的圆弧根轨迹
> 对应块：BLK26 | 覆盖分集：P26 | 块标题（分集名）：《第13节课4 根轨迹法4.1 基本概念4.2 法》

实轴上的根轨迹我们画过了：从最右端的开环零极点起、从右往左数，奇数到偶数之间的那段才是根轨迹。拿画过的那个例子看，根轨迹从 0 到 -2 这么走过来的那段，就是"奇数到偶数"，这边不是，那边也不是——实轴上的根轨迹就这一条规矩。规矩收了尾，往下还有第四条法则要讲，叫**根之和**。这条法则有的时候不直接能用，但把它弄透了以后，很多情况下会给你带来很多的帮助——后面讲另外四条法则的时候，还要专门去说它。

### 第四条法则：根之和

> **结论**：当 $n-m\ge 2$（$n$ 是开环分母的阶数，$m$ 是开环分子的阶数）时，闭环根之和保持一个常值不变。$K^*$ 从零到无穷大变化的过程中，闭环的根在动、根轨迹在变，但在任何一个时刻把闭环的根全部加起来，都是一个固定的值，增量为零。

这个事情可以证明。设开环传递函数写成一般形式：

$$G(s)H(s)=K^*\frac{\prod\limits_{i=1}^{m}(s-z_i)}{\prod\limits_{j=1}^{n}(s-p_j)}$$

$z_1,\dots,z_m$ 是开环零点，$p_1,\dots,p_n$ 是开环极点，$K^*$ 是根轨迹增益。把分子分母全部乘开，分母就是开环的特征多项式：

$$\prod_{j=1}^{n}(s-p_j)=s^n+a_{n-1}s^{n-1}+\cdots+a_0$$

首一系数不用多说。$s^{n-1}$ 这一项的系数 $a_{n-1}$ 在代数上和开环极点之间有一个关系式：它等于所有开环极点之和再冠以一个负号。不相信的话，找个具体值乘开，把 $s^{n-1}$ 项的系数合并起来看一眼，是不是这个关系——这是中学代数里就学过的根与系数关系。开环传递函数给定之后，开环零极点就给死了，所以 $a_{n-1}$ 是个常值。

再看闭环的。闭环特征多项式等于分母加分子：分母就是上面那串 $s^n+a_{n-1}s^{n-1}+\cdots+a_0$，分子是把 $K^*$ 乘进去以后的开环分子多项式 $K^*(s^m+b_{m-1}s^{m-1}+\cdots+b_0)$。两个加起来：

$$s^n+a_{n-1}s^{n-1}+\cdots+a_0+K^*(s^m+b_{m-1}s^{m-1}+\cdots+b_0)$$

关键就在限制条件 $n-m\ge 2$ 上：最了不起就是 $n-m=2$，那 $m=n-2$，$K^*$ 乘进去的这一大串最高只能加到 $s^{n-2}$ 那一位，**绝不会加到 $s^{n-1}$ 上去**。所以闭环特征多项式的 $s^{n-1}$ 项系数还是 $a_{n-1}$，没有动。

既然是闭环特征多项式，把根解出来就是闭环极点 $\lambda_1,\lambda_2,\dots,\lambda_n$：

$$\prod_{i=1}^{n}(s-\lambda_i)=s^n+c_{n-1}s^{n-1}+\cdots+c_0,\qquad c_{n-1}=-(\lambda_1+\lambda_2+\cdots+\lambda_n)$$

还是那套代数定理：$c_{n-1}$ 又是闭环根之和冠一个负号。可你看这系数没有变呀——它应该等于闭环根之和冠负号，又等于 $a_{n-1}$，而 $a_{n-1}$ 是死的，就是开环根之和冠负号。于是闭环根之和就等于开环根之和，等于一个常数。定理清楚了。

### 一部分向左跑，另一部分一定向右跑

这条定理告诉我们什么事情？如果 $n-m\ge 2$，把根轨迹分成几个不同的部分来看：有一部分向左跑，另一部分合起来一定向右跑，而且左右移动的量是相互抵消的——因为闭环根之和要保持不变。

拿画过的那个两极点系统验证一下：$n=2$、$m=0$，$2-0=2$，恰好满足条件。开环根之和 $0+(-2)=-2$。闭环根跑的时候一定是对称地走：这个根往左走，那个根一定往右走，而且它们要跑到正中间 -1 的地方才相遇——这样才能保证根之和。从分离点出来进到复平面以后，一个向上、一个向下，虚部折销了，实部这一个和那一个折起来永远保持 -2。出来以后还不能偏：往这边偏一点、往那边偏一点，根之和就保持不住了，上下对称也不满足了。

所以根轨迹画出来以后，它的规范是很严格的——这些法则一条都不能践踏。

### 例题：证明复平面上的根轨迹是圆弧

系统开环传递函数已经给你了，单位反馈：

$$G(s)=\frac{K^*(s+2)}{s(s+1)}$$

$K^*$ 就是根轨迹增益，从零到无穷大变化。要你证明：闭环根轨迹画出来以后，复平面当中会出现根轨迹，而且复平面的根轨迹一定是圆弧。

先照规矩来。把开环零极点的分布在 $s$ 平面当中画出来：两个极点在 0 和 -1，一个零点在 -2。画根轨迹，你首先意识到应该做什么？实轴上的根轨迹——从 0 往左数，-1 到 0 这段是；再往下数，-2 以左全是。接下来看起点和终点：根轨迹起于开环极点，一个从 0 出发、一个从 -1 出发，走到中间某一个地方一定要出来，还得照顾对实轴的对称性；终于开环零点，剩下的跑到无穷远。现在一个终点（-2 处的零点）已经有了，另一个终点在无穷远也给你指明了，那中间怎么跨过去？从分离点绕出来，一个往左、一个往右：往右的回到实轴、进到零点 -2，往左的奔向无穷远，有始有终。

分离点左边的分支回到实轴的位置，正是复平面根轨迹和实轴根轨迹的交点——就是判别式刚好等于零的那个情况：判别式大于零是两个不等的实根，小于零是一对共轭复根，等于零正是两个交界的地方。

证明用根的定义直接做。根的问题就是特征方程的解，特征方程等于分母加分子：

$$s(s+1)+K^*(s+2)=0\ \Rightarrow\ s^2+(1+K^*)s+2K^*=0$$

这是二阶的，根的表达式直接写出来：

$$s_{1,2}=\frac{-(1+K^*)\pm\sqrt{(1+K^*)^2-8K^*}}{2}$$

实轴上的根轨迹已经画了，现在讨论复平面：复平面的根轨迹就是判别式小于零的情形。把根号里的负号提出来写成 $j$，得到复根的表达式：

$$s_{1,2}=-\frac{1+K^*}{2}\pm j\,\frac{\sqrt{8K^*-(1+K^*)^2}}{2}$$

根的实部用 $\sigma$ 表示、虚部用 $\omega$ 表示——实部就相当成 $x$，虚部就当成是 $y$。这下实部是 $K^*$ 的函数，虚部也是 $K^*$ 的函数，两个方程了。把两个方程当中的 $K^*$ 约掉，不就得到 $x$ 和 $y$ 之间的关系了吗？这关系如果能整理成一个圆的方程，OK，事情就解决了。

由实部表达式把 $K^*$ 解出来：

$$K^*=-2\sigma-1$$

虚部两边平方、把根号去掉：$\omega^2=\dfrac{8K^*-(1+K^*)^2}{4}$。逐项代入：$\dfrac{8K^*}{4}=2K^*$，而 $(1+K^*)^2=4\sigma^2$，于是

$$\omega^2=2K^*-\sigma^2=-4\sigma-2-\sigma^2$$

整个搬到一边，配项：

$$(\sigma+2)^2+\omega^2=(\sqrt{2})^2$$

这是个圆的方程：圆心在 $(-2,\ 0)$、半径为 $\sqrt{2}$ 的圆。这个圆心在哪？恰好在这个开环零点上。这不是偶然的——虽然举的是这样一个具体的例子，但一般情况下都是这个结论。

让判别式等于零，把两个交界点解出来：$d_1=-0.5858$，$d_2=-3.4142$。你看它们到圆心 -2 的距离都是 $\sqrt{2}$——正是圆和实轴的两个交点，复平面的圆弧就在这两点之间走。半径就是分离点到零点的距离，确定出来以后放心画圆，一点误差都没有。

```text
                    jω
                     │
             *       │
          *     *    │
        *         *  │
       *           * │
═══════*══════•───•═●═╪───→ σ
      d₂    -2  -1 d₁ 0
       *           * │
        *         *  │
          *     *    │
             *       │
                     │
```

读图说明：实轴上 $[-1,0]$ 与 $(-\infty,-2]$ 两段（图中 ═ 段）是实轴根轨迹；两支自 0、-1 相向而行，在 $d_1$ 分离进入复平面，沿以开环零点 -2 为圆心、半径 $\sqrt{2}$ 的圆弧上、下对称绕行，在 $d_2$ 回到实轴，一支进入零点 -2，一支奔向无穷远；原点处的开环极点恰在 $j\omega$ 轴上。

碰到"两个开环极点、一个开环零点、复平面出现根轨迹"这种问题，你放心大胆地去画：一定是以那个开环零点为圆心的圆弧，数学上证明过的，没有问题。

### 从根轨迹看稳、准、快

根轨迹画出来了，图画得挺好看，那它用于系统分析有什么意思呢？当 $K^*$ 从零到无穷大演变的过程当中，稳、准、快三项指标会发生什么样的趋势？我们不定量地精确去算，只从定性的角度分析它变化的规律。

把两个分离点 $d_1$、$d_2$ 作为两个中间站来讨论。

**第一站之前：$0<K^*<0.1716$。** 两个闭环极点是互异的单根，系统呈现出一种过阻尼的状态，超调量是没有的；调节时间是下降的——主导极点总的趋势是离开虚轴越来越远。

**中间一段：$0.1716<K^*<5.8284$。** 过了第一个分离点，极点出来成了一对共轭复根，有复根的系统就是欠阻尼的了。超调量的变化趋势呢？看 $\beta$ 角：从分离点开始 $\beta$ 角越来越大，到什么时候达到最大？相切的时候——$\beta$ 角最大，超调量最大；到最后 $\beta$ 角又小了。所以超调量是先大后小。调节时间呢，这两个根总的来讲是离开虚轴越来越远，而且离开的幅度很大，调节时间会明显地减小。

**$K^*>5.8284$ 之后。** 从第二个分离点往无穷走，一个根往这边、一个根往那边，又呈现出过阻尼的状态，两个互异的单根，没有超调量；那个往 -2 走的根离虚轴越来越近，所以调节时间应该越来越长了。

还有个零点要交代一句：这个开环零点也是前向通道的零点，又是闭环的零点，它也要参与动态性能指标的影响，这里就不去细讨论了。

**稳。** 系统的稳定性怎么样？绝对稳定——整个根轨迹都在虚轴左边，根就不可能跑到右边去，稳定性的问题没有问题。

**准。** 这个系统是个 I 型系统。假如给它输入斜坡函数，当 $K^*$ 从零到无穷大演变的过程当中，稳态误差应该怎么变？查那张 3×3 的表格：I 型系统、斜坡输入，取正中间那一格——$e_{ss}=A/K$，是和输入强度 $A$ 有关的非零常值，与开环增益成反比。那开环增益和 $K^*$ 之间是什么关系？从式子上看，$K=2K^*$。所以 $K^*$ 越大，稳态误差越小。

这个图有了，稳、准、快三项指标随 $K^*$ 从零到无穷大演变的定性变化规律，就完全可以讨论清楚了——根轨迹的意义在这儿又说了一遍。这个事情取决于什么呢？取决于"二阶系统的闭环极点在 $s$ 平面当中移到什么地方时，超调量、调节时间应该怎么变化"这个问题的掌握。这在第三章的知识当中你就应该扎下个根，否则到这儿说不清了。

### 一般定理：圆心就在开环零点

由这个题目引出一个一般性的定理：

> **定理**：如果系统有两个开环极点、一个开环零点，并且复平面当中存在根轨迹，那么复平面的根轨迹一定是以该零点为圆心的圆弧。

刚才举的例子是一个特例，定理在数学上可以严格去证明。遇到这类零极点分布，你上来就果敢地把它画出来，确切无疑、一点误差都没有——有定理给你保证了。

怎么画？先把实轴上的根轨迹画出来，这是一定要有的意识；两个分支相遇以后一定有个分离点，不分离出来它没有归宿；分离点一旦找到，圆心有了——定理告诉你圆心就在零点上，半径也有了——就是分离点到零点的距离，画圆就行了。

画圆有两个方向，往哪边走？往根轨迹该去的那边画。圆心在这、半径这么大，要么从这边画、要么从那边画；从这边画过去交到的那块地方不是根轨迹上的点，所以不能往那边画，只能往这边画——这不是你该去的地方。

还有一种情形要认得：两个极点各自都有归宿——一个从开环极点出发跑到零点去了，一个跑到无穷远也有归宿了——这时候复平面当中画不出根轨迹，就不要勉强。

这个"两极一点"的根轨迹要非常熟练，你遇到它就应该马上把它画出来。

### 根轨迹概念与四条法则回顾

根轨迹的定义再念一遍：系统当中的某一个参数——到目前为止我们都研究 $K^*$ 这个参数，它不一定非是 $K^*$ 不可，也可能是别的参数，碰到别的参数从零到无穷大变化的问题，到后边再去说——从零到无穷大演变的过程当中，闭环极点随着它变化、在 $s$ 平面当中相应描绘出来的轨迹，就是根轨迹。根轨迹一定是闭环意义上的根轨迹，没有"开环根轨迹"一说。

闭环零点与开环零点之间的关系要说清楚：我们之所以研究闭环根轨迹，就是因为闭环极点随 $K^*$ 的变化是变化的；而闭环零点却不随 $K^*$ 变化，不需要去讨论。但你要知道，闭环零点等于前向通道当中的开环零点和反馈通道当中的开环极点的组合。后续课程讲到系统分析、讲到动态性能指标计算的时候，要用到这个结果。

根轨迹方程对应的模值条件、相角条件要理解到位：什么点是根轨迹上的点，全靠相角条件去判断；这个点落在根轨迹上了，它对应的 $K^*$ 值是多少，要反过来拿模值条件去约束。这个地方要好好搞清楚。

绘制根轨迹的四条法则归拢如下：

| 法则 | 内容 |
| :--- | :--- |
| 起点与终点 | 起于开环极点，终于开环零点；剩下的没有着落的分支跑到无穷远处。分支数等于特征方程的阶数，即开环极点的个数，也是闭环极点的个数 |
| 对称与连续 | 根轨迹对称于 $s$ 平面当中的实轴；$K^*$ 连续演变时闭环极点也是连续的轨迹，中间不可能出现断点 |
| 实轴上的根轨迹 | 从实轴最右端的开环零点或极点起、从右往左数，奇数到偶数之间的区段一定是根轨迹，否则一定不是。这条要掌握到位，你上来首先用的就是它 |
| 根之和 | $n-m\ge 2$ 成立时闭环根之和保持常数；一部分根向左跑，其余的根合起来向右跑，两边跑的总量互相抵消 |

## 绘制根轨迹的基本法则：渐近线、分离点与虚轴交点
> 对应块：BLK27 | 覆盖分集：P27 | 块标题（分集名）：《第14节课4.2 绘制根轨迹的基本法则5-8（上》

上节课我们进了第四章——根轨迹法，也叫幅值法，讲了根轨迹的基本概念和前四条绘制法则。这节课不做别的事情，就把剩下的几条法则讲完，全程通过例题来带。希望你们下去通过作业，把绘制根轨迹的法则掌握到位——以后碰到根轨迹的问题，这些都是要牢固掌握的基本功。

# 先把上一讲的账盘清楚

什么叫根轨迹？系统当中某一个参数从零变到无穷大的过程中，它要影响闭环极点，闭环极点相应在 $s$ 平面当中变化所描绘出来的轨迹，就叫根轨迹。注意，这是**闭环意义上**的根轨迹。

闭环极点和谁有关？和开环零点、开环极点以及根轨迹增益 $K^*$ 都有关。一道题的结构图给定以后，开环零极点就定了，剩下的变量只有 $K^*$——所以我们研究的正是 $K^*$ 从零到无穷大变化时，闭环根的绘制问题。

还有一条结论先记在心里，今天暂时用不到，后边要用到：**闭环零点不随 $K^*$ 变化，它是固定的**，等于前向通道的开环零点加上反馈通道的开环极点。也就是说，闭环零点不一定就是开环零点，它是开环零点当中的一部分，再加上开环极点当中的一部分。

根轨迹问题来自根轨迹方程：令闭环分母等于零，即

$$1 + G(s) = 0$$

把 1 挪过去，就是开环传递函数等于 $-1$。因为它是复数方程（幅值方程），可以取模、取相角：取模得到**模值条件**，取相角得到**相角条件**。$s$ 平面当中的任何一个点，只要满足相角条件，它就满足根轨迹方程，就是根轨迹上的点；至于这个点对应的 $K^*$ 是多少，要用模值条件去定。

> **结论**：判断一个点在不在根轨迹上，只看相角条件；求该点对应的 $K^*$ 值，才用模值条件。

开环增益和根轨迹增益之间，对一个特定题目而言，当开环零极点确定之后，两者就差一个固定的比例系数。所以 "$K^*$ 从零到无穷大变化"和"开环增益 $K$ 从零到无穷大变化"是同一个过程。

上节课的四条法则快速过一遍：

- **法则一（起点终点）**：根轨迹起于开环极点，终止于开环零点；剩下 $n-m$ 条分支没有着落，趋近于无穷远点。
- **法则二（分支数、连续性、对称性）**：分支数等于特征方程阶数，也就是开环极点个数，也等于闭环极点个数；$K^*$ 连续变化时每条分支连续变化、不会跳跃；根轨迹对称于实轴。
- **法则三（实轴上的根轨迹）**：只管实轴，不管复平面。从实轴最右端的开环零点或极点往左算起，奇数个零极点之间的区段一定是根轨迹，偶数个的一定不是。画根轨迹时上来先别干别的，先把实轴上的根轨迹划定。
- **法则四（根之和）**：当 $n-m \ge 2$ 时，闭环根之和等于开环根之和，等于一个常数。它告诉我们：一组根轨迹里，若有一组总的趋势向左跑，另外一组一定总的趋势向右跑，而且左右跑的总量之和不变。

另外上节课还给了个定理：两个开环极点、一个开环零点的系统，若复平面能画出根轨迹，那复平面的根轨迹一定是以这个开环零点为圆心的圆弧。碰到这种问题，果断地一笔画准就可以了。

# 渐近线：奔向无穷远的那 $n-m$ 条分支

法则一说根轨迹起于开环极点、终止于开环零点，剩下的 $n-m$ 条分支跑到无穷远去了。那它们是怎么跑过去的？法则五——渐近线——就规范了这 $n-m$ 条分支趋近无穷远时所遵循的规律。

渐近线由两个要素确定：一个点、一个角。点 $\sigma_a$ 是渐近线和实轴的交点：

$$\sigma_a = \frac{\displaystyle\sum_{i=1}^{n} p_i - \sum_{j=1}^{m} z_j}{n - m}$$

角 $\varphi_a$ 是渐近线和实轴正方向的夹角：

$$\varphi_a = \frac{(2k+1)\pi}{n-m}, \quad k = 0, \pm 1, \pm 2, \dots$$

一个点、一个方向，这条线就定了。这两个式子我们要证明一下——证明过了，你理解得就更深刻。

### 交点坐标：站到北极星上看零极点

写根轨迹方程：开环分子多项式 $N(s)$ 比分母多项式 $D(s)$，冠个负号，等于 $K^*$：

$$-\frac{N(s)}{D(s)} = K^* \quad\Longrightarrow\quad \frac{D(s)}{N(s)} = -K^*$$

为了说明方便，举一个具体的例子：某个开环系统有四个开环极点、一个开环零点。那它一共有四条根轨迹分支，一条趋近于这个开环零点，剩下三条都要跑到无穷远处——所以有渐近线问题。

假设某条分支已经顺着轨迹跑到很远很远的地方，$s$ 是这条分支上的一个点，离零极点区域无限远。这个点既然在根轨迹上，就一定满足相角条件：把所有的叉叉（极点）和圈圈（零点）都向它引矢量，零点矢量的相角加起来，减去极点矢量的相角，等于 $(2k+1)\pi$。

"无限远"是什么意义？打个比方：我在中国，你在美国，在地球上咱们远隔千山万水；但你站到北极星上看，美国人也罢、中国人也罢，都相当于站在地球的质心上，是一样的——而且这个 $s$ 到零极点的距离，比地球到北极星还远。这样一来，不管你是叉叉还是圈圈，指向 $s$ 的矢量实际上都可以看成同一个矢量：都由那个"质心" $\sigma_a$ 指向 $s$，长度一样、角度一样。

于是分子上有 $m$ 个 $(s-\sigma_a)$，分母上有 $n$ 个 $(s-\sigma_a)$，一除，右边就成了：

$$\frac{D(s)}{N(s)} \approx (s-\sigma_a)^{n-m}$$

对左边做多项式除法：$D(s)$ 是首一的 $n$ 次多项式，$s^{n-1}$ 次项的系数刚好是开环极点之和冠一个负号；$N(s)$ 的 $s^{m-1}$ 次项系数是开环零点之和冠一个负号。用 $D(s)$ 做被除数、$N(s)$ 做除数除一下，商的首项是 $s^{n-m}$，第二项的系数就是**所有开环极点减去所有开环零点**。

对右边用二项式展开：$(s-\sigma_a)^{n-m}$ 相当于有 $n-m$ 个重根都在 $\sigma_a$，它的 $s^{n-m-1}$ 次项系数，就是这些根加起来再冠一个负号，即 $-(n-m)\sigma_a$。

两个式子首项都是 $s^{n-m}$，第二项的系数必须相等：

$$\sum p_i - \sum z_j = -(n-m)\,\sigma_a$$

把 $n-m$ 除过去，就得到

$$\sigma_a = \frac{\sum p_i - \sum z_j}{n-m}$$

这个点相当于零极点分布的一个**广义重心**坐标，也就是渐近线和实轴交点的坐标。很好算：所有开环极点加起来，减掉所有开环零点，再被 $n-m$ 除。

### 夹角公式：相角条件一写就出来

夹角的推导更直接，还是用刚才那个例子。无穷远的那个点在根轨迹上，满足相角条件。既然距离无限远，所有矢量——圈圈向它的、叉叉向它的——长度一样，角度当然也一样了：都是 $\varphi$。那 $m$ 个零点各贡献 $+\varphi$，$n$ 个极点各贡献 $-\varphi$：

$$(m-n)\varphi = (2k+1)\pi$$

把 $n-m$ 除过来，就是

$$\varphi_a = \frac{(2k+1)\pi}{n-m}$$

有了一个点、有了一个角，渐近线就确定出来了。

### 热身例题：两个极点的系统

设开环传递函数给定，开环零点没有，开环极点一个在 $0$、一个在 $-2$。要绘制根轨迹，先把开环零极点在 $s$ 平面当中的分布画出来，然后按法则一条条走。

实轴上的根轨迹先划定：$-2$ 到 $0$ 这个闭区间，是根轨迹。

再算渐近线：两条分支都要趋近无穷远点。交点坐标：

$$\sigma_a = \frac{0 + (-2)}{2-0} = -1$$

夹角：$(2k+1)\pi / 2$，$k$ 取零是 $90^\circ$，取 $-1$ 是 $-90^\circ$，取正一、正二多少都可以，但最终**独立的方向只有正负 $90^\circ$ 两个**——你除出来有几个 $k$ 没用，独立方向就 $n-m$ 个。正 $90^\circ$ 往上，负 $90^\circ$ 向下。

这个题的根轨迹恰好整个压在渐近线上：一个分支往上、一个向下。这个形状大家是熟悉的。

> **提示**：$k$ 取遍整数得到的角会周期重复，独立方向永远只有 $n-m$ 个，别被 $k$ 的取值迷惑。

# 根之和派上用场：分离点在哪边、图形对不对

下面来个结构图形式的例题。系统是一型的，把开环传递函数整理成首一标准型后：三个开环极点 $0$、$-1$、$-4$，一个开环零点 $-2$，开环增益和根轨迹增益 $K^*$ 差一个固定的比例系数。题目要求先画根轨迹，再回答：三阶系统有三条分支，当一个闭环极点的实部落到 $-1$ 的时候，另外那个闭环根跑到哪里去了？

### 实轴区段与渐近线

实轴上的根轨迹：$-1$ 到 $0$ 一段，$-4$ 到 $-2$ 一段（从最右端往左数，奇数个零极点的区段才是）。

渐近线：$n-m = 3-1 = 2$ 条。交点坐标：

$$\sigma_a = \frac{0 + (-1) + (-4) - (-2)}{2} = -\frac{3}{2}$$

夹角除以 2，肯定是正负 $90^\circ$。

### 分离点在负 0.5 的哪一边

两条分支从 $0$ 和 $-1$ 出发，只能在 $[-1, 0]$ 区间相遇后再分开，所以一定有个分离点。分离点的法则还没讲，但大家现在就能判断：这个分离点是把 $[-1, 0]$ 平分成两半的 $-0.5$ 呢，还是在 $-1$ 和 $-0.5$ 之间，还是在 $-0.5$ 到 $0$ 之间？

凭什么说在 $-1$ 和 $-0.5$ 之间？用的是法则四——根之和。这个系统 $n-m=2$，满足根之和为常数的条件。看根轨迹的特点：$K^*$ 从零往大变的时候，每条根都连续地走，不能停住，或慢或快你都得走。我们把分支分成两部分：$-4$ 那条分支总的趋势是向右跑（往 $-2$ 的零点去），那 $0$ 和 $-1$ 这两条合起来的效应就一定要向左跑。假如这两条恰好在正中间 $-0.5$ 相遇：一条向左挪了半格、一条向右挪了半格，合起来净走零——那第三条根也不用走了。这不符合逻辑。所以汇合的点只能比 $-0.5$ 再靠左一点：分离点在 $-1$ 和 $-0.5$ 之间。

### 渐近线能越过吗？三改草稿的过程

分离点有了、渐近线有了，有人画出这样一个根轨迹：从分离点出来直接甩到渐近线的左边去。这样对不对？

"不能越过渐近线"——这话不错，但凭什么？得有个确切无疑的理由。还是根之和：你看这两条合在一起的根，如果它们越过渐近线继续向左，一条多跑半格、另一条跑一格半，合起来向左挪了两个单位；那第三条根就必须向右也挪两个单位——从 $-4$ 出发恰好到 $-2$。你要是再越过去一点，它就得越过开环零点 $-2$ 跑到右边来，可那边不是它要走的路。所以渐近线你可以坚定地逼近，但不能越过，理由就是根之和。

那不越过、贴在渐近线右边但来回飘着走，行不行？不行。$K^*$ 从零到无穷大连续单调变化的过程中，根也必须单调地走过去。要是根来回摆——$K^*$ 等于某个值时跑到这儿，$K^*$ 更大了又倒回来重新等于这个根——代数上没有这样的事情。

改成往外鼓一个弧线、但两条根合起来向右飘的画法呢？也不行：这两条合起来向右跑了，第三条就得向左跑，不合适。

想来想去只有一种画法是对的：从分离点出来，弯过去，无限逼近渐近线。

```text
                 jω
                  ↑
                  │        │  ← 渐近线：σa = -3/2，方向 ±90°
                  │   ↗    │
                  │  ●     │       ● 分离点 d ≈ -0.55
                  │  │     │
  ───×───○───×────┼──×─────────────→ σ
     -4  -2  -1   │  0
```

两条分支从分离点出发，向上、向下弯过去，从右侧无限贴近渐近线；第三条分支沿实轴从 $-4$ 走向零点 $-2$。

当然有同学问：那我画得再鼓一点、再平一点行不行？这就说不清了——根轨迹法是图解法，拿手画确实有不精确的地方，鼓的尖一点、拉得平一点都没关系，**但趋势必须画对**。

> **易错点**：根轨迹可以无限逼近渐近线，但绝不能越过它；判断依据是根之和，不是"感觉上渐近嘛"。

根之和这条法则，一来可以判断分离点到底在哪边，二来可以检验你画的根轨迹对不对，两个作用。

### 实部为 $-1$ 时，第三条根在哪

回到题目的问题：闭环极点中有一个（一对）的实部落到 $-1$ 时，第三条根跑哪儿去了？

看图形：两条分支从分离点出来向上、向下走，实部从 $-0.55$ 一路往左减小；与此同时 $-4$ 那条根在实轴上连续地向右走。当那两条根的实部都等于 $-1$ 时，第三条根走到哪？用根之和算：

开环根之和 $= 0 + (-1) + (-4) = -5$，它恒等于闭环根之和。设三个闭环根为 $\lambda_1, \lambda_2, \lambda_3$，其中 $\lambda_1, \lambda_2$ 是一对共轭复根、实部都是 $-1$，实部累加起来是 $-2$（虚部正负抵消）。于是

$$\lambda_3 = -5 - (-2) = -3$$

也就是说，那两条根随着 $K^*$ 往上走的过程当中，这条根也连续地往右走；当它们实部落到 $-1$ 时，这条根恰好走到 $-3$，不前不后就在这儿。继续下去，当那两条根贴着渐近线趋向无穷远、实部逼近 $-3/2$ 时，这条根就向开环零点 $-2$ 无限接近。

> **结论**：$n-m \ge 2$ 时，已知若干个闭环极点的位置，根之和立刻给出其余闭环极点的位置——这是它第三个用处。

# 分离点怎么算

刚才的例题留了个尾巴：分离点你到底怎么算？现在给公式。分离点 $d$ 满足：

$$\sum_{i=1}^{n} \frac{1}{d - p_i} = \sum_{j=1}^{m} \frac{1}{d - z_j}$$

即 $d$ 减所有开环极点的倒数和，等于 $d$ 减所有开环零点的倒数和。解这个方程，解出来的 $d$ 就是分离点。

### 公式从哪来：分离点必是重根

严格证明不做了，拿刚才那个例子（极点 $0,-1,-4$，零点 $-2$）说明思路。开环传递函数给定后，闭环特征方程就是分母多项式加分子多项式：

$$D(s) + K^* N(s) = 0$$

现在在分离点上考虑问题。分离点处两根相碰再分开——两个根要碰到一块儿再分开，至少得两个根，所以**分离点至少是二重根**（三个根碰到一起就是三重根，对应三重分离）。于是可以把特征方程写成

$$(s-d)^2 (s - \lambda_3) = 0$$

其中 $d$ 是分离点，$\lambda_3$ 是第三条根（不知道在哪儿，用 $\lambda_3$ 代替）。

$S = d$ 时特征方程等于零；而且因为 $d$ 是二重根，特征方程对 $s$ 求导以后的导函数在 $s = d$ 处也必须等于零。把乘积求导展开，每一项里都至少带着一个 $(s-d)$ 的因子，$s=d$ 时全为零——这就是二重根的含义。

于是我们手里有两个方程：原方程等于零、导数等于零。两个式子里都带着 $-K^*$ 和 $K^*$，把 $K^*$ 消掉——两式相除。整理出来的关系，恰好就是高等数学里"先取对数再求导"的形状：把相乘的因式先写成相加的对数项，再逐项求导，$\ln(s - p_i)$ 的导数是 $\dfrac{1}{s-p_i}$，$\ln(s-z_j)$ 的导数是 $\dfrac{1}{s-z_j}$。落在 $s = d$ 上，就得到上面那个倒数和相等的方程。要是系统没有开环零点，右边整项就是零。

### 试根的功夫

对这个题，把倒数和方程通分一下，得到一个关于 $d$ 的一元三次方程——还真不好解。怎么办？**老老实实试根**。是根就试，别整那些虚头巴脑的。

试也要讲策略：我们已经用根之和把分离点定在 $-1$ 和 $-0.5$ 之间了，就只在这个范围里试，绝不敢从负无穷到正无穷漫无边际地试。

- 先代 $d = -0.5$：方程两边不平衡，比如是左边大右边小，说明 $-0.5$ 还偏右了，往左挪；
- 再代 $d = -0.6$：两边大小关系反过来了——方向对了，但**试过头了**，往回折；
- 再代 $d = -0.55$：基本平了，取 $d \approx -0.55$。

> **提示**：试根到百分之百精确不太可能。按 5% 无差度的口径，差值落在区间长度的 5% 以内就够了。这个技巧掌握到位，一般试三次、最多四次就能到精度。你要是嫌麻烦绕着走，以后碰到这事永远过不了这个坎。

有同学发牢骚：根轨迹法不就是拿法则画图、避免特征多项式求根吗，怎么现在又试起根来了？试根只是试**分离点这一个根**，不是从头到尾都试。实践证明，碰到这种问题，试根是最省事、最省时间的办法，其他你还没有好办法。

分离点 $d \approx -0.55$ 求出来以后，它对应的 $K^*$ 值怎么算？把这个点代到**模值条件**里去。根轨迹是 $K^*$ 从零到无穷大演变出来的轨迹，轨迹上任何一个点都对应一个确定的 $K^*$——不管哪个点，只要在轨迹上，代入模值条件就算出来了。这个题算出来 $K^* \approx 0.589$。

到这里，实轴区段、分离点、渐近线都有了，按前面讨论的走势把根轨迹画出来，这个题就完整了。

# 三条渐近线的例题：一路画到虚轴上

再来一道。系统是一型的三阶系统，$K^*$ 是根轨迹增益，开环传递函数把常数 2 提出来后，开环增益等于 $K^*/2$。开环零点没有，开环极点在 $0$、$-1$、$-2$。画根轨迹。

实轴上的根轨迹：$-1$ 到 $0$ 一段，$-2$ 以左也是一段；$-2$ 到 $-1$ 之间不是。

三条分支都要趋近无穷远，渐近线有三条。交点坐标：

$$\sigma_a = \frac{0 + (-1) + (-2)}{3} = -1$$

夹角 $(2k+1)\pi/3$：三等分，一定是正 $60^\circ$、负 $60^\circ$、$180^\circ$。

### 两个分离点的取舍

$-1$ 到 $0$ 这段的两条分支要相遇再分开， $-2$ 那条有始有终（它自己沿实轴趋向无穷，贴着 $180^\circ$ 渐近线走）。还是用根之和判断分离点的位置：$-1$、$-2$ 那边的分支总趋势向右（往 $0$ 的方向），$0$ 这边的分支就得向左，所以分离点在 $-0.5$ 的右边。

代公式：

$$\frac{1}{d} + \frac{1}{d+1} + \frac{1}{d+2} = 0$$

这个方程通分后是关于 $d$ 的一元二次方程，不用试根，直接解出**两个**解。两个解什么意思？两个分离点？不是——解出来的 $d \approx -1.58$ 落在 $-1.5$ 那一带，那儿根本不是根轨迹上的点，要**舍掉**；只留下 $d \approx -0.42$ 这个，它确实在 $-0.5$ 的右边。把它代入模值条件，对应的 $K^* \approx 0.385$。

> **易错点**：分离点方程的解不一定都是分离点——只有落在根轨迹上的解才有效，不在轨迹上的解一律舍掉。

```text
                    jω
             ╲       ↑       ╱
              ╲      │      ╱    ← 渐近线：σa = -1，方向 ±60°、180°
               ╲     │     ╱
                ●    │    ╱         ● 分离点 d ≈ -0.42
                │ ╲  │  ╱
  ─────────×──×─┼────×─────────────→ σ
           -2 -1 │    0
```

从分离点出来，两条分支贴着渐近线跑，途中一定要越过虚轴。

### 与虚轴的交点：临界稳定点

如果我们把根轨迹与虚轴的交点算出来，画轨迹时中间就多了一个参考点，可以画得比较准。这就引出法则七——与虚轴的交点。

从概念上说，与虚轴的交点实际上就是**系统临界稳定的那个点**：闭环极点跑到虚轴上了。由这个思路出发，有两种求法。

**方法一：劳斯表。**特征方程等于分母加分子：

$$s^3 + 3s^2 + 2s + K^* = 0$$

临界稳定意味着用劳斯表列的时候，第一列肯定会出现全零行。列表：

| $s^3$ | $1$ | $2$ |
|:---:|:---:|:---:|
| $s^2$ | $3$ | $K^*$ |
| $s^1$ | $(6-K^*)/3$ | |
| $s^0$ | $K^*$ | |

系统要稳定，就是 $K^* < 6$ 且 $K^* > 0$。让第一列出现全零行，即令 $\dfrac{6-K^*}{3} = 0$，得 $K^* = 6$。此时用全零行上面那行系数构造**辅助方程**：

$$3s^2 + K^* = 0 \;\Longrightarrow\; 3s^2 + 6 = 0$$

解出 $s = \pm j\sqrt{2}$。这就是与虚轴的交点，对应的 $K^*$ 值是 6。

**方法二：代 $s = j\omega$。**与虚轴的交点，就是有一个根 $s = j\omega$——它同时在根轨迹上。干脆把特征方程里的 $s$ 换成 $j\omega$，令其等于零：

$$-j\omega^3 - 3\omega^2 + 2j\omega + K^* = 0$$

实部、虚部都得等于零，挑出来是两个方程：

$$\begin{cases} K^* - 3\omega^2 = 0 & \text{（实部）} \\ -\omega^3 + 2\omega = 0 & \text{（虚部）} \end{cases}$$

两个方程解两个未知数。从虚部先解：$\omega = 0$ 是一个解，代回去 $K^* = 0$——那对应的是根轨迹的起点，不是我们要的；还有 $\omega^2 = 2$，即 $\omega = \sqrt{2}$，代回实部得 $K^* = 6$。结果和方法一完全一样。

两种方法都可以。就我个人习惯，用底下这个（代 $j\omega$）做好像更便捷一些，你用什么方法做都可以。

### 使系统稳定的增益范围

现在问一个问题：$K^*$ 从零到无穷大变化时，一条根始终在虚轴左边；那两条根一开始在虚轴左边，先是过阻尼，又变欠阻尼，到临界时零阻尼，最后跑右边去不稳定了。使这个系统稳定的开环增益取值范围在哪儿？

看图说话：$K^* = 0$ 是起点（临界），往上走系统稳定，一直到 $K^* = 6$ 那个点——与虚轴交点处——不能再大了。所以

$$0 < K^* < 6$$

那开环增益 $K$ 呢？这个系统开环增益等于 $K^*/2$，凭 $6/2 = 3$：

$$0 < K < 3$$

> **提示**：题里问的是开环增益还是根轨迹增益，看清了再答——两者差一个比例系数，范围要换算。

## 出射角、入射角与根轨迹八法则的综合运用
> 对应块：BLK28 | 覆盖分集：P28 | 块标题（分集名）：《第14节课4.2 绘制根轨迹的基本法则5-8（下》

八条法则讲到这儿，只剩最后一条了。但它绝不是可有可无的收尾——先看一个让人卡壳的例子：实轴段画完了、渐近线也画完了，绝大多数根轨迹分支都有始有终，偏偏剩下两支不知道怎么连。前面那些法则到了这儿全都不好用了，能抓住的信息只有两个角度。

### 还缺的两支：出射角与入射角

题目是一个单位反馈系统，开环传递函数已经给定，画 $K^*$（根轨迹增益）从 0 到无穷大变化时的根轨迹。第一步照例把开环零极点分布画到 $s$ 平面上：一共四个开环极点、三个开环零点，两边各含一对共轭复数。

按法则推进：实轴上的根轨迹段先画出来，先解决一部分；渐近线一数只有一条——那一支本来就要趋近无穷远点，方向就是它，不用另求，这步直接省了。到这一步，几支根轨迹都有始有终了，唯独缺两支：它们肯定从那对复极点出来，而且上下对称，最终要跑到那对复零点去。问题是怎么连？直接连直线肯定不准。

能想象一下：根轨迹从复极点出来的一瞬间，它对实轴正方向的夹角如果知道，这一支起笔就不慌了；而当 $K^*$ 趋于无穷大、根轨迹分支要走到开环零点时，站在零点上看它来的方向，这个角度如果知道，收笔也有把握。其他地方好像没有可参考的了，就这两个角度。

> **定义**：出射角（起始角）——根轨迹离开开环复极点时，与实轴正方向的夹角；入射角（终止角）——根轨迹抵达开环复零点时的来路方向，与实轴正方向的夹角。

### 出射角：把相角条件用到极点跟前

做法的实质就是相角条件。设根轨迹刚从复极点 $p$ 出来，往某个方向走：刚出来的这个测试点离 $p$ 无限近，对应的 $K^*$ 是个很小的正数、几乎为零；既然这个点在根轨迹上，它就满足相角条件——所有零点引向它的矢量相角之和，减去所有极点引向它的矢量相角之和，应等于 $(2k+1)\pi$：

$$\sum_{i=1}^{m}\angle(s-z_i)-\sum_{j=1}^{n}\angle(s-p_j)=(2k+1)\times 180^\circ$$

妙处就在"无限近"三个字：除了 $p$ 自己（矢量不能自己引自己），其他圈圈叉叉引向这个测试点，实际上就相当于引向 $p$——那些矢角全都能按坐标关系算出来。于是方程里只剩一个未知量，就是要求的出射角 $\theta$，解它就行。

回到例题：三个零点引出的矢角量得 $56.5^\circ$、$19^\circ$、$59^\circ$；除自身外的三个极点，矢角分别是 $90^\circ$（来自与它共轭的那个极点）、$108^\circ$、$37^\circ$。四个角度加加减减，令其等于 $-180^\circ$，解出 $\theta=79^\circ$——这支根轨迹就以 79 度的方向从复极点出射。

由此可以写出一般式：

$$\theta_{p_k}=(2k+1)\times 180^\circ+\sum_{i=1}^{m}\angle(p_k-z_i)-\sum_{j
e k}\angle(p_k-p_j)$$

零点矢角取正、极点矢角取负，再加上 $(2k+1)\times 180^\circ$——出射角公式没什么神秘的，就是相角条件在极点跟前的一次"极限拍照"。

> **提示**：方程右边取 $(2k+1)\times 180^\circ$，$k$ 取几都行。为了计算确切，习惯上直接写成 $-180^\circ$；反正给个 $(2k+1)\pi$，最后解出来的方向是唯一的，不用担心多解。

### 入射角：站在零点上看根轨迹来路

同一个方法，换个站位。$K^*$ 趋于无穷大时，这支根轨迹要接近开环零点 $z$。把测试点取在离 $z$ 无限近处：除 $z$ 以外，其他所有零点极点引向测试点，实际上都相当于引向 $z$，矢角都能算出来；$z$ 自己引向测试点的方向，就是要求的入射角 $\phi$。这个点同样满足相角条件，列方程解 $\phi$ 即可：

$$\phi_{z_k}=(2k+1)\times 180^\circ+\sum_{j=1}^{n}\angle(z_k-p_j)-\sum_{i
e k}\angle(z_k-z_i)$$

例题里，除目标零点外的零点矢角量得 $117^\circ$、$90^\circ$（其中 $90^\circ$ 来自它的共轭零点），四个极点的矢角量得 $119^\circ$、$121^\circ$、$153^\circ$、$163.5^\circ$，代入相角条件，解出 $\phi=149.5^\circ$。

至此，这一支 79 度出去、149.5 度过来，底下再补一条与它对称的共轭支，整个根轨迹就有模有样了。

有同学问：79 度出去、149 度回来，中间可以画出很多很多的曲线，画小点也行、大一点也行，到底怎么连？说清楚一点：那张准确的图是计算机画出来的，手工画图本来就不可能绝对准。要画得比较准，可以在分辨率最高的地方——两支之间那条线上——找一个满足相角条件的点，再通过它连过来；不需要这么较真的话，画小一点、大一点都可以，趋势对了就行。

> **提示**：出射角、入射角的全部意义就是把"趋势"钉住。起笔和收笔的方向定了，中间怎么弯，误差不会太大。

### 从结构图到根轨迹：法则的取舍

下面通过例题把法则用起来。系统结构图给定，$K^*$ 是可变参数，从 0 到无穷大变化，画闭环根轨迹。

第一步永远是把开环传递函数拿出来。结构图里有一个小闭环：开环传递函数等于前向那一级乘上小闭环的闭环传递函数。小闭环用梅逊增益公式求——前向通道是它，特征式是 1 减去（负的）回路传递函数——分子分母同乘一个因子整理后，开环传递函数化成

$$G(s)=\frac{K^*}{s(s^2+2s+2)}$$

这里有个容易栽跟头的地方：

> **易错点**：不要一看见 $K$ 就当开环增益。要看它是不是处在尾一标准形分母常数项的位置上——把式中的 2 提出来归一化后，$K=K^*/2$ 才是开环增益，$K^*$ 是根轨迹增益。动笔之前先辨认一下"实质"。

把开环零极点分布画出来：开环极点 0 和 $-1\pm\mathrm{j}1$，没有开环零点。现在八条法则都教给你了，怎么用、什么时候用哪条，你自己决定——并不是一个题要把八条法则全都用一遍，但到了该做什么的时候，得能把相应的那条拿出来。

实轴段：0 以左的负实轴整段都是（右侧只有一个开环极点，奇数）。渐近线：$n-m=3$，三支都要趋近无穷远，渐近线与实轴交点 $\sigma_a=(0-1-1)/3=-2/3$，与实轴正方向的夹角是正负 60 度和 180 度——180 度那条就是实轴段本身，已经有了。

出射角：复平面上孤零零一对复极点，必然有求起始角的问题。测试点取在 $-1+\mathrm{j}1$ 附近：极点 0 引向它的矢角 135 度，共轭极点引来 90 度；没有零点，全是减项：

$$-(135^\circ+90^\circ)-\theta=-180^\circ \quad\Longrightarrow\quad \theta=-45^\circ$$

上半支以 $-45^\circ$ 出射，随后拐向渐近线方向再"这么过来"；下半支与它对称。

与虚轴交点：写出特征方程 $s^3+2s^2+2s+K^*=0$，令 $s=\mathrm{j}\omega$，分解实部虚部——实部 $-2\omega^2+K^*=0$，虚部 $-\omega^3+2\omega=0$。$\omega=0$ 那个解是起点，不是要的交点；取 $\omega^2=2$、$\omega=\sqrt{2}$，代回实部得 $K^*=4$。根轨迹在 $\omega=\sqrt{2}$ 处穿越虚轴，对应的根轨迹增益是 4。

这道题从头到尾只用到了法则中的一部分。八条法则要学活：该用什么就用什么，并不是每个题都从头到尾全用一遍。

### 四支根轨迹：用根之和锁定分离点

第二个例题的开环传递函数里有一个二阶子式，先把它分成两个根，得开环极点 $0$、$-20$、$-2\pm\mathrm{j}4$，没有开环零点，$n-m=4$；同时把开环增益和根轨迹增益之间的关系捋清楚（常数归一后 $K=K^*/400$）。

渐近线：四条。与实轴交点 $\sigma_a=(0-20-2-2)/4=-6$；夹角把 360 度平分四份：正负 45 度、正负 135 度。公式里的 $k$ 取 0、取 1、取 2 都行，反正最终的方向只有这四个，是唯一的。

出射角：复平面上孤零零一个极点放在那儿，肯定有求起始角的问题。量角：极点 0 引向 $-2+\mathrm{j}4$ 的矢角 116.5 度，极点 $-20$ 引来 12.5 度，共轭极点 90 度，没有零点：

$$-(116.5^\circ+12.5^\circ+90^\circ)-\theta=-180^\circ \quad\Longrightarrow\quad \theta=-39^\circ$$

复数对以正负 39 度出射。

分离点：实轴段 $(-20,\,0)$ 上，0 和 $-20$ 出发的两支必相遇后分离。分离点方程照公式写：

$$\frac{1}{d}+\frac{1}{d+20}+\frac{1}{d+2-\mathrm{j}4}+\frac{1}{d+2+\mathrm{j}4}=0$$

两项通分、交叉相乘，得到的是关于 $d$ 的一元三次方程，不好解。这时候不要犹豫——先定性定位。分离点肯定在 0 和 $-20$ 之间，不可能跑到两边去，那里不是根轨迹；再从中间 $-10$ 切开，问它在左边还是右边？用根之和定：$n-m=4\ge 2$，闭环根之和恒等于开环根之和 $-24$，是个常数。复数那一对顺着渐近线往右跑，它们的实部之和只会越来越大；总和锁死是 $-24$，实轴这一对的根之和 $2d$ 就必须越来越小、小于 $-20$——所以分离点必在 $-10$ 左边。心里有数之后试根，最后 $d=-15.1$。试根过程可能还需要那么三步四步，但老老实实把它算一遍，这个问题就掌握住了，将来碰到心里不慌。

顺手把分离点对应的 $K^*$ 算出来：$K^*=13881$——记住这个数，马上要用。

与虚轴交点：特征方程 $s^4+24s^3+100s^2+400s+K^*=0$，令 $s=\mathrm{j}\omega$：实部 $\omega^4-100\omega^2+K^*=0$，虚部 $-24\omega^3+400\omega=0$。$\omega=0$ 是起点，不要；由虚部解出 $\omega^2=400/24$，$\omega\approx 4.1$，代回实部得 $K^*=1389$。

现在问大家一个问题：两对根轨迹分支，一对从复极点出射往右跑，一对在实轴上相向而行——是复数对先到虚轴，还是实轴那对先到分离点？看 $K^*$ 的大小就行：复数对穿越虚轴对应 $K^*=1389$，实轴对相遇对应 $K^*=13881$，比它大了一个数量级。所以复数对先穿过虚轴、已经跑到右边去了，实轴那一对还在半道上，没到相遇的时刻。这也顺带告诉我们：$K^*$ 从 0 到无穷大变化的过程中，根轨迹跑的速度可不是一样的，有时候慢、有时候快。

稳定的增益范围随之而来：$K^*$ 在 0 到 1389 之间时，闭环极点全部位于虚轴左边；折算成开环增益 $K=K^*/400$，大约是 $0<K<3.47$。

### 一个零点牵动整条根轨迹

第三个例题更典型：开环极点 $0$、$+1$ 和一对实部为 $-2$ 的共轭复极点，开环零点 $-1$，$n=4$、$m=1$。要求画根轨迹，而且要确定使系统稳定的开环增益取值范围（$K^*$ 是根轨迹增益）。

实轴段：$(0,\,1)$ 和 $(-\infty,\,-1)$。渐近线：$n-m=3$ 条，$\sigma_a=(0+1-2-2+1)/3=-2/3$，夹角正负 60 度、180 度。

出射角：复极点处照例有起始角问题。零点矢角取正、其余极点矢角取负（共轭极点引来 90 度，另两个极点的矢角量得 120 度和 130.9 度），令其等于 $-180^\circ$，解出 $\theta\approx-54.9^\circ$——上半支以这个方向出射，下半支对称。

分离点：这次有两个。凭什么说 $(0,\,1)$ 段有分离点？0 和 $+1$ 出发的两支肯定要在一处相遇再分离——不分离的话，谁往开环零点跑、谁往无穷远跑？而 $(-\infty,\,-1)$ 段上还有一个：去开环零点的那条路、奔向无穷远的那条路，都必须分离之后才走得通。分离点公式代进去：

$$\frac{1}{d}+\frac{1}{d-1}+\frac{1}{d+2-\mathrm{j}c}+\frac{1}{d+2+\mathrm{j}c}-\frac{1}{d+1}=0$$

其中 $c$ 是复极点的虚部。直接解根比较痛苦，把结果写出来：一个在 $0.49$，一个在负实轴段上。两个解都落在根轨迹上，所以都是分离点——一个管相遇后分开，一个管分开后会合。

与虚轴交点：特征方程令 $s=\mathrm{j}\omega$，偶次项归实部、奇次项归虚部，得两个方程。$\omega=0$ 是起点，不管；把 $\omega$ 约掉，$K^*$ 和 $\omega^2$ 的关系就导出来了，代进去得到关于 $\omega^2$ 的一元二次方程，解出两个交点 $\omega=1.56$ 和 $\omega=2.56$，各自对应的 $K^*$ 用模值条件去算。

该算的都算完了，把根轨迹连一连。这时候分歧来了：这两支在哪儿相遇、分开以后怎么走？可以画出好几种连法——两支在虚轴附近相遇后各奔东西是一种；相遇后拐个弯、倒一下再出去也是一种。到底哪个对？计算机画出的正确结果是：有一个根跑过来又跑回去，另外两个根从上边拐个弯又绕过来。这个题非常典型地说明：根轨迹画成什么样子，完全取决于开环零极点的分布；零极点位置稍微差一点儿，画出来的形状可能就差得比较远。

为什么会这样？想一件事：根轨迹分支的归宿只有两种——跑到开环零点，或者跑到无穷远。跑无穷远是很累的事情，大家都不愿意那么做；能先占住一个开环零点待着休息，它肯定先跑去——近水楼台先得月。这个题里零点离虚轴这边近，复极点那两支趋近它就有优势；可两支不能同时到达，怎么办？在半路相遇打一架（分离点），赢的跑去零点休息，输的跑去无穷远。另外两支为什么先往这边拐一下？因为休息的地方对它有吸引力；可一拐之后人家先到了，它没指望了，于是就这么过去了。

把零点往左挪一点，复极点对抢先到达的优势就逐渐显现；靠得足够近，局面整个翻过来；挪到某个特定位置，四支趋近它的趋势一样强，于是相遇、分离、各奔前程。一个零点往左一点还是往右一点，对根轨迹走向的影响就是这么大。这个题比教学例题复杂，留作业不会留这么多，但通过它可以把这个认识往深再引一步。

> **提示**：画根轨迹画到最后，这八条法则在脑袋里其实是模糊的——完全是一种条件反射。就像骑自行车：刚学的时候满脑子想着往哪边掰，骑熟了根本不用想。开环零极点分布一画出来，随手就能把根轨迹勾出来。现在是老老实实按法则画，将来很大程度上靠的是感觉。做题的时候好好琢磨，把这种感觉早点琢磨出来。

### 稳定范围与动态性能

回到这一讲交代的任务：使系统稳定的开环增益取值范围。$K^*$ 从 0 到无穷大变化，系统可不可以稳定？可以——条件是把所有闭环极点都拢在虚轴左边。有些分支始终在左边，没有问题；麻烦在穿过虚轴的那两支：两个穿越点之间，根轨迹在左半平面，系统是稳定的；出了这段范围就不稳定了。

稳定是稳定，但这个范围里系统动态性能不好：闭环复极点的落点与负实轴的夹角偏大，超调量就大；一对极点彼此又挨得非常近，调节时间要特别长。但毕竟 $K^*$ 在这两个点之间取值时，系统是可以稳定的。把穿越点对应的 $K^*$ 值除以 16（尾一标准形的折算关系），就是使系统稳定的开环增益取值范围。

根轨迹画出来以后，系统稳定不稳定、动态性能怎么样，它都告诉我们一个宏观的信息；要具体计算，把数值代进去定量地算就是。

### 八条法则总复习

到此为止，八条法则全部交给大家了，而且通过例子告诉大家应该怎么用。合上书过一遍：

| 法则 | 要点 |
| :--- | :--- |
| 起点与终点 | 起于开环极点，终止于开环零点；多出来的那些分支跑到无穷远去 |
| 分支数、对称性与连续性 | 分支数等于 $n$（开环极点个数，就是闭环特征方程的阶数）；根轨迹关于实轴对称；$K^*$ 连续变化、只要不跳，根轨迹也不会跳 |
| 实轴上的根轨迹 | 最明确无误的一条：从实轴最右端那个开环零极点向左算起，奇数到偶数之间的区段一定是，否则一定不是 |
| 根之和 | $n-m\ge 2$ 时，闭环根之和等于开环根之和，等于常数 |
| 渐近线 | 规范那些起点终点"还没着落"、趋近无穷远点的分支：求与实轴交点的坐标、与实轴正方向的夹角 |
| 分离点 | 按公式列方程；算出来能解根就直接解，解不了要试根，就老老实实像课堂上那样算一遍，将来碰到心里不慌 |
| 与虚轴交点 | 特征方程令 $s=\mathrm{j}\omega$，实部虚部分别等于零：两个方程解两个未知数——交点位置和相应的 $K^*$ |
| 出射角与入射角 | 它的公式就是相角条件 |

当时创建根轨迹法的那位美国人伊万斯，给出的法则其实不止这么多；但从实践的角度，这八条够用了，把它掌握熟练。根轨迹法的分析和设计，首先是把画根轨迹的功夫掌握到位：不管什么样的开环传递函数拿到手里，都能很熟练、很迅速地把根轨迹画正确——有的地方画得不准没关系，趋势得画对。

## 广义根轨迹：参数根轨迹的构造与绘制
> 对应块：BLK29 | 覆盖分集：P29 | 块标题（分集名）：《第15节课4.3 广义根轨迹（上）》

进入第四章以来，根轨迹法已经讲了两次课，绘制根轨迹的八条法则都交代清楚了。今天上新课之前，先把这些法则串一遍，再用一道例题把"画轨迹—看稳定"的完整流程走一遍——能够熟练地把根轨迹绘制出来，是我们运用根轨迹法分析系统最起码的技能。备齐了这些基本功，再站在根轨迹的高度把开环与闭环、负反馈与正反馈这些老话题重新审视一遍，然后进入这一节的新内容：广义根轨迹。

### 八条法则先串一遍

**起点与终点。** 闭环根轨迹起于开环极点，终止于开环零点；剩下 $n-m$ 条分支没有着落，就奔向无穷远点。根轨迹的分支数就是系统的阶数——特征方程是几阶的，就有几个根，就有几条分支。根轨迹对称于实轴，而且参数从零到无穷大连续变化时，轨迹在 $s$ 平面上描绘的曲线也是连续的，不会出现断点。

**实轴上的根轨迹。** 从实轴上最右端的那个开环零点、极点开始向左数，奇数个到偶数个开环零极点之间的区段一定是根轨迹，否则一定不是。这条规则用起来最快，画图先画它。

**根之和。** 当 $n-m\ge 2$ 时，闭环根之和保持一个常数，等于开环根之和。后面定第三个根，全靠这一条。

**渐近线。** 它描述的是那 $n-m$ 条趋向无穷远的分支所遵循的规律：

$$\sigma_a=\frac{\sum_{i=1}^{n}p_i-\sum_{j=1}^{m}z_j}{n-m},\qquad \varphi_a=\frac{(2k+1)\pi}{n-m}$$

其中 $\sigma_a$ 是渐近线与实轴交点的坐标，$\varphi_a$ 是渐近线正方向与实轴正方向的夹角。

**分离点。** 分离点 $d$ 遵循的方程是

$$\sum_{i=1}^{n}\frac{1}{d-p_i}=\sum_{j=1}^{m}\frac{1}{d-z_j}$$

碰到分离点问题就带这个方程去算：给出来的方程能解就直接解；解不了，就用试根法——试根的方法要掌握住。

**与虚轴的交点。** 令 $s=\mathrm{j}\omega$ 代到特征方程当中去，让实部、虚部分别等于零：两个方程两个未知数，一个是交点处的 $\omega$，一个是交点对应的 $K^*$ 的值。

**出射角与入射角。** 这条法则实际上就是相角条件的应用。

最后叮嘱一句：这八条法则在绘制根轨迹的过程中，未必每一道题都会全用到，该用哪条你自己决断——该用什么法则就用什么法则，能够顺利熟练地把根轨迹画出来，这才是目的。

### 例题复盘：从画图到稳定结论

先举一个例子，把绘制根轨迹的问题回顾一下。系统结构图已给出，开环传递函数等于前向通道传递函数与反馈通道传递函数乘到一起，是尾 1 标准型，其中的 $K$ 叫开环增益；化成尾 1 标准型后那个系数就是根轨迹增益 $K^*$，对本题两者满足 $K^*=3.5K$。讨论 $K^*$ 或 $K$ 从零到无穷大变化，化根是一回事，轨迹形状一样。题目有两个要求：一是绘制 $K^*$ 从零到无穷大变化时的根轨迹，二是根轨迹画出来以后，分析系统稳定性随 $K$ 变化的规律。

把开环零极点画到 $s$ 平面上：三个极点分别在 $-1$（二重，两个摞在一起）和 $+\dfrac{7}{4}$，一个零点在 $-0.5$。

#### 把轨迹一步步画出来

**实轴区段。** 从最右端算起：$+\dfrac74$ 处是一个极点，往左数是 1 个（奇数），到 $-0.5$ 处的零点变成 2 个（偶数）——所以 $\left[-0.5,\ \dfrac74\right]$ 这一段是根轨迹。再往左检验：$-0.5$ 与 $-1$ 之间往右数是 2 个，偶数，不是；越过二重极点 $-1$ 之后是 4 个，还是偶数，也不是。实轴上就这一段。

**渐近线。** $n-m=3-1=2$ 条。交点坐标

$$\sigma_a=\frac{(-1)+(-1)+\frac74-(-0.5)}{2}=\frac18$$

两条渐近线的夹角不用算也知道，肯定是 $\pm 90^\circ$。注意 $\sigma_a=+\dfrac18$ 在虚轴右边，所以渐近线一定穿过虚轴，分支必然要与虚轴相交。

**出射角。** 二重极点 $-1$ 处要定起始角。先凭感觉：两个重合的极点彼此排斥，往右是零点和极点的地盘，走不通，大概往上、往下走——±90°？感觉还不太踏实，那就把出射角算一遍。在 $s$ 靠近 $-1$ 处列相角条件：零点 $-0.5$ 指向 $s$ 的矢量相角是 $180^\circ$；极点 $+\dfrac74$ 指向 $s$ 的矢量相角也是 $180^\circ$；两个重合的极点各自都要向 $s$ 引矢量，共 $2\theta$。于是

$$180^\circ-\left(2\theta+180^\circ\right)=(2k+1)180^\circ \quad\Rightarrow\quad \theta=\pm 90^\circ$$

出射角 $\pm 90^\circ$，踏实了。

**与虚轴的交点。** 特征方程为 $(s+1)^2\left(s-\dfrac74\right)+K^*(s+0.5)=0$，乘 4 去掉分母：

$$4s^3+s^2+(4K^*-10)s+(2K^*-7)=0$$

代 $s=\mathrm{j}\omega$，实部、虚部分别为零：

$$-\omega^2+2K^*-7=0,\qquad -4\omega^3+(4K^*-10)\,\omega=0$$

$\omega=0$ 是一个解，代回实部得 $K^*=3.5$，即 $K=1$——这是实轴分支从 $+\dfrac74$ 左行穿过原点的时刻。$\omega \neq 0$ 时由虚部方程得 $\omega^2=K^*-2.5$，代回实部方程解出 $K^*=4.5$、$\omega=\sqrt2$，即 $K=\dfrac97$——这是共轭分支穿越虚轴的时刻。

```text

        :    |       |

  -----xx-----o--+--x-------> σ

```

读图：从二重极点 $-1$ 出发的两支先按出射角 $\pm 90^\circ$ 竖直向上、向下，随后向右弯，在 $\pm\sqrt2$ 处穿过虚轴，最后沿 $\mathrm{Re}=+\dfrac18$ 的两条渐近线趋于无穷；从 $+\dfrac74$ 出发的一支沿实轴向左，穿过原点，终止于零点 $-0.5$。

#### K 的三个区间与响应形态

| 开环增益 $K$ 的区间 | 闭环极点分布 | 稳定性 | 响应形态 |
| :--- | :--- | :--- | :--- |
| $0<K<1$ | 有一个单实根在右半平面，另两个在左半平面 | 不稳定 | 单调发散 |
| $1<K<9/7$ | 三个极点全在左半平面 | 稳定 | 单调收敛叠加振荡收敛，都慢 |
| $K>9/7$ | 一对共轭复根越过虚轴进入右半平面 | 不稳定 | 振荡发散 |

为什么 $0<K<1$ 是"单调发散"？看闭环极点的分布：右半平面里那个根是一个单根——单根对应一个单模态，它是单调发散的；左半平面那两个根对应的模态虽然是收敛的，但是振荡收敛。随着时间增大，那个发散的模态就占上风了。闭环极点在 $s$ 平面当中的分布，首先就把系统稳定性的问题决定了，因为它决定模态；而系统的响应——特别是单位脉冲响应或者系统的自由响应——就是这些极点所对应模态的线性组合。把这些概念融在一起，才能正确地分析系统。

$1<K<\dfrac97$ 时，那条实轴分支上的极点已经越过虚轴跑到左边来了，但共轭的两支还没有过去——所有闭环极点都在虚轴左边，系统是稳定的。不过那个单根离虚轴比较近，单调收敛但收敛得慢；那两个复根离虚轴也比较近，振荡收敛得也慢。它的响应你可以想象出来是个啥样子：一个单调的过程，上面还叠加了一个波动很厉害、收敛又慢的过程。稳定是稳定了，但动态性能不会好。

$K>\dfrac97$ 时，共轭复根越过虚轴跑到右边去了，对应的模态是振荡发散，系统仍然不稳定。

### 站在根轨迹的高度看系统

学了根轨迹法之后，我们就可以站在根轨迹这个角度去审视一个系统，从更深刻的层次上理解它。

第一件事：开环稳定和闭环稳定之间没有直接的关系，不能划等号，各有各的事情。比方一个系统，开环极点全在虚轴左边，开环显然是稳定的；可你加上闭环、把开环增益逐渐加大的过程中，根轨迹跑到虚轴右边去了，闭环系统就不稳定了——开环稳定，闭环不保证总稳定。

反过来的例子我们时域法当中举过：一个开环系统两个极点全在右边，一个开环零点也在右边，开环显然不稳定；但从根轨迹上看，两个极点、一个零点的问题，根轨迹绕个圆过来——增益从零逐渐增加，闭环先是振荡发散，大到跑过虚轴进入左边，系统就稳定了，是振荡收敛；两支在实轴上相遇分开后变成单调收敛；再大，一支又跑回虚轴右边，又单调发散了。所以只要把增益取到一个合适的范围，闭环系统可以稳定，而且性能还不会太差。开环不稳定，闭环照样能稳。

第三件事：负反馈能改善性能，这话也不是绝对的。比方一个三极点系统，开环是稳定的，画出来的根轨迹表明：闭环要稳定，增益不能随便取，最好取到根在 45° 线上，这时候最好；取得太大，原来稳定的系统反而不稳定了。加了闭环，确实给了你一种把系统动态性能调整好的可能性，但这个可能性的实现，还要你把结构、参数调到合适的值。再看一个二阶系统：负反馈之下增益增大，根往那个方向走，调节时间不会有太大变化，但超调量肯定越来越大；把反馈倒过来用正反馈，根轨迹方向反过来画，参数调到合适的时候，调节时间变化不大，超调量反而改善很多——至少理论上能找到这样的特例。所以话不能说绝了，要具体问题具体分析。学了根轨迹法，就能从更深一层理解系统的性能改善以及开环闭环之间的关系；要善于用学过的东西，去指导控制系统的设计和分析。

### 广义根轨迹与参数根轨迹

广义根轨迹有两种情况，这一讲只讲第一种，叫做**参数根轨迹**。

> **定义**：根轨迹，是系统中某一个参数从零到无穷大变化时，闭环极点在 $s$ 平面上相应变化所描绘出来的轨迹。这个参数未必一定是开环增益或根轨迹增益——在此之前我们研究的都是 $K^*$ 或 $K$ 变化的问题；把"除 $K^*$ 之外的其他参数"从零到无穷大变化时的根轨迹也纳入进来，问题就扩展了，这就是参数根轨迹。

碰到这种问题怎么做？不管参数是什么样，除了 $K^*$ 之外的问题，用前面的方法照样做：

1. 根据原开环传递函数，把系统的特征方程写出来（分母加分子）；
2. 根据特征方程构造**等效开环传递函数**——把含变参数的量放在它的分子上，把不含变参数的项放在它的分母上；
3. 由等效开环传递函数按八条法则去画根轨迹。

道理在哪里？等效开环传递函数对应的特征方程，就是原来那个系统的特征方程，所以它画出来的根轨迹就是原系统的根轨迹。这么一处理，就把参数根轨迹的问题，化成了我们熟悉的 $K^*$ 变化的那种问题。

> **易错点**：等效开环传递函数只负责画根轨迹，根轨迹画出来以后，它的使命就结束了，绝不敢再往下用了——再拿它去算闭环传递函数、算性能，就错了。所以它叫"等效"开环传递函数，不叫"等价"开环传递函数。后续一切分析，都要回到原来的系统当中去。

### 变参数 A：从特征方程到等效开环传递函数

#### A 的双重身份

看一道例题。单位反馈系统，开环传递函数当中有一个变参数 $A$，要研究 $A$ 从零到无穷大变化时闭环根的轨迹；根轨迹画出来以后，再确定当阻尼比等于 1 时闭环传递函数的表达形式怎么写。

这个 $A$ 麻烦在哪儿？你把它提到外边，表面上它相当于一个根轨迹增益那种形式，但它同时又决定了一个开环零点——你画根轨迹的时候，这个零点还在跑，你这根轨迹怎么画？出现问题了。这就是典型的参数根轨迹：$K^*$ 之外的参数从零到无穷大变化的绘制问题。

按老办法来。先把特征方程写出来，把含 $A$ 的项归到一边，整理成

$$s(2s+1)^2 + A = 0$$

对照"$P(s)+AQ(s)=0$"的形式：含参的 $A$ 放分子，其余的放分母，等效开环传递函数就是

$$G^*(s)=\frac{A}{s(2s+1)^2}=\frac{A}{4s(s+0.5)^2}$$

它的特征方程与原系统一模一样，画出的根轨迹就是原系统的根轨迹。零极点分布：三个极点分别在 $0$ 和 $-0.5$（两个摞在 $-0.5$），没有有限零点。

#### 按八条法则画图

**实轴区段。** 最右端 $0$ 处一个极点，往左数 1 个（奇），$\left[-0.5,\ 0\right]$ 是；过 $-0.5$ 之后 3 个（奇），$\left(-\infty,\ -0.5\right]$ 也是。

**渐近线。** $n-m=3$ 条。交点坐标

$$\sigma_a=\frac{0+(-0.5)+(-0.5)}{3}=-\frac13$$

角度是 $\pm 60^\circ$、$180^\circ$。

**分离点。** 列分离点方程：

$$\frac{1}{d}+\frac{1}{d+0.5}+\frac{1}{d+0.5}=0$$

整理出一个关于 $d$ 的一元一次方程，解得 $d=-\dfrac16$。从 $0$ 出发的分支沿实轴向左，从 $-0.5$ 出发的一支沿实轴向右，两支就在 $-\dfrac16$ 相遇，再沿 $\pm 90^\circ$ 方向分开。注意：这时用模值条件求出来的不是 $K^*$ 的值，而是 $A$ 的值——让 $\left|G^*(s_0)\right|=1$，把 $A$ 解出来：

$$A=|d|\cdot|2d+1|^2=\frac16\times\left(\frac23\right)^2=\frac{2}{27}$$

**与虚轴的交点。** 特征方程即 $4s^3+4s^2+s+A=0$，代 $s=\mathrm{j}\omega$，实部、虚部分别为零：

$$-4\omega^2+A=0,\qquad -4\omega^3+\omega=0$$

$\omega=0$ 不用说了，那是起始点（$A=0$）；另一个解 $\omega=\dfrac12$，代回实部得 $A=1$。

```text
                             jω
                /            | j0.5  <- 与虚轴交点 (A = 1)
               / ^           |
              /  |           |
             /   |           |   ±60° 渐近线: 从 σ = -1/3 出发
            /    |           |
   ----xx----------*----x-----> σ
    -0.5(二重)   -1/6  0
            \    |           |
             \   |           |
              \  v           | -j0.5
                \            |
```

读图：从 $0$ 与 $-0.5$ 出发的两支沿实轴在 $-\dfrac16$ 相遇，垂直分开后向右弯，在 $\pm 0.5$ 处穿越虚轴，然后沿 $\pm 60^\circ$ 渐近线趋于无穷；从 $-0.5$ 出发的第三支沿负实轴一直走向 $-\infty$（$180^\circ$ 渐近线）。

### 阻尼比等于 1：回到原系统

第一个问题解决了，现在回答第二个：阻尼比等于 1 时，闭环传递函数的表达式怎么写？

先要把概念摆正：阻尼比一定是针对一个二阶环节而言的。这个系统是三阶的，三个根——离虚轴比较远的那条分支上的极点，对动态性能指标影响不大，是非主导极点；我们说这个系统的阻尼比，实际上针对的是离虚轴近的这条分支上那两个极点所对应的二阶因子。那"阻尼比等于 1"是什么意思？就是这两个分支在分离点处相交——这时候闭环极点是二重根，正好对应 $\zeta=1$ 的那种情况。所以题问的就是：分离点处对应的闭环传递函数怎么写。

分离点处的 $A$ 值刚才已经用模值条件求出来了，是 $\dfrac{2}{27}$。关键一步来了：把等效开环传递函数放下——根轨迹画完，它的功能就到此为止，绝不敢再往下沿用。回到原来的系统开环传递函数当中去，把 $A=\dfrac{2}{27}$ 代进去。系统是单位反馈的，所以闭环传递函数的分子和开环的分子一样，分母等于开环分母加分子（就是特征多项式）：

$$\Phi(s)=\frac{s+\dfrac{2}{27}}{s(2s+1)^2+\dfrac{2}{27}}$$

把这个特征多项式分解因式：既然对应分离点，两根就在 $-\dfrac16$ 重合，必有 $\left(s+\dfrac16\right)^2$；第三个根的位置怎么定？$n-m=3\ge 2$，用根之和——闭环根之和等于开环根之和 $0-0.5-0.5=-1$，所以

$$s_3=-1-2\times\left(-\frac16\right)=-\frac23$$

于是

$$\Phi(s)=\frac{s+\dfrac{2}{27}}{4\left(s+\dfrac16\right)^2\left(s+\dfrac23\right)}$$

再叮嘱一遍：一定要回到原来的系统。根轨迹画完以后，要回到原来那个开环传递函数当中去讨论它——这就是"等效"和"等价"的区别。

### 跟着 A 看动态、稳定与稳态误差

现在 $A$ 不是 $K^*$ 了，讨论 $A$ 从零到无穷大演变的过程中，系统动态性能、稳定性、稳态误差的变化规律。

| $A$ 的区间 | 闭环极点 | 稳定性 | 动态特征 |
| :--- | :--- | :--- | :--- |
| $0<A<2/27$ | 全为负实根 | 稳定 | 单调、无超调；调节时间随 $A$ 增大而减小 |
| $2/27<A<1$ | 分离点后一对共轭复根（左半平面） | 稳定 | 振荡收敛；超调量增大、调节时间变长 |
| $A>1$ | 共轭复根越过虚轴 | 不稳定 | 振荡发散 |

$0<A<\dfrac{2}{27}$ 时，闭环极点全是负实根，系统呈现单调的过阻尼情况，超调量肯定没有。离虚轴最近的那个极点（从原点出发的分支）总的来讲随着 $A$ 增大往左走，所以整个系统的调节时间是减小的。

过了分离点、$A$ 还没到 1 时，主导的两支变成共轭复根，系统主要呈现振荡收敛的趋势，超调量不再等于零；而且随着 $A$ 往 1 靠，闭环极点往右上方走，$\beta$ 角越来越大，超调量越来越大，调节时间也越来越长。

$A$ 一旦大于 1，两个根就跑到虚轴右边去了——那对共轭复根是振荡发散的模态，系统就发散了，而且是振荡发散。所以从稳定性角度讲，$A$ 在 0 到 1 的开区间内系统稳定，大过 1 系统就不稳定。根轨迹画出来以后，稳定性的问题直接就明确了。

稳态误差呢？这个系统是二型系统，输入是加速度信号，查静态误差系数表最右下角那一格：$e_{ss}=a/K_a$。把开环增益代进去，$K_a=\dfrac{A}{4}$，单位加速度输入下

$$e_{ss}=\frac{4}{A}$$

$A$ 越大稳态误差越小，但 $A$ 最大只能取到虚轴交点对应的 $A=1$——再大系统就不稳定了，稳态误差也就没有意义了。所以把 $A$ 的最大值代进去，稳态误差最小也就是 4，不会比它更小了。

把以前时域法当中关于稳定性、稳态误差、动态性能计算的那些方法，都融在这里边，把它弄透——这是这类题的完整套路。

### 变参数 T：分子阶次高了怎么办

#### 倒过来用 1/T

再看一道题。单位反馈系统，二型的三阶系统，开环传递函数中有一个惯性环节，惯性环节的时间常数 $T$ 是变参数，从零到无穷大变化，研究闭环极点的根轨迹。

老办法：特征方程写出来（分母加分子），构造等效开环传递函数，把含 $T$ 的项放在分子上：

$$G^*(s)=\frac{Ts^3}{(s+27.7)(s+587.7)}$$

分母那部分分解因式，可以分出两个零点，分别在 $-27.7$ 和 $-587.7$。这么一放，问题来了：**分子的阶次高了**——以前处理这种问题还没碰到过，怎么办？

倒过来。让 $T$ 分之一倒在上面，让 $\dfrac1T$ 从零到无穷大变化：

$$G^{*}{}'(s)=\frac{1}{T}\cdot\frac{(s+27.7)(s+587.7)}{s^3}$$

这就变成了分母阶次高、分子阶次小的老问题——而且是同一个问题：$\dfrac1T$ 从零到无穷大变化，相当于 $T$ 从无穷大变到零。特征方程没变，画出来的轨迹就是同一条。

零极点分布：三个极点摞在原点（三重极点），两个零点在 $-27.7$ 和 $-587.7$。这两个零点数值上差得很远，图上只能示意地画，看得清楚要紧。

#### 出射角、虚轴交点与分离点

**实轴区段。** 在 $\left(-27.7,\ 0\right)$ 上往右数 3 个（奇），是轨迹；在 $\left(-\infty,\ -587.7\right)$ 上是 5 个（奇），也是；两个零点之间那一段是 4 个（偶），不是。

**出射角。** $\dfrac1T=0$ 的时候，三个极点摞在一起——它们又是同性的，谁都见不得谁，都急着要分开。你想，按照什么规律分开的时候最有效？彼此 120°：$180^\circ$ 的方向已经被实轴分支占住了，那这两个根就应该 $\pm 60^\circ$ 分开，这时候分开的效率最高。感觉归感觉，算一遍才踏实。列相角条件：两个零点都在左边，各自指向 $s$ 的矢量相角是 $0^\circ$；三个重合的极点，每一个都要向 $s$ 引矢量，必须算三个，共 $3\theta$。于是

$$0^\circ+0^\circ-3\theta=(2k+1)180^\circ$$

$k$ 取不同值，独立的方向只有三个：$+60^\circ$、$-60^\circ$、$180^\circ$。出射角出来了。

**与虚轴的交点。** 为什么会和虚轴有交点？分支从 $\pm 60^\circ$ 出发，一开始冲进了右半平面，最后还要绕回来奔向左边的零点，所以一定要跨过虚轴。把特征方程写出来，令实部、虚部分别等于零，由这两个方程解出

$$\omega=126.45$$

代回去把 $T$ 算出来：$T=0.0385$。

**分离点。** 列分离点方程：

$$\frac{3}{d}=\frac{1}{d+27.7}+\frac{1}{d+587.7}$$

整理一下，得到关于 $d$ 的一元二次方程，解出两个根：一个是 $-40.5$，另一个是 $-1190$。$-40.5$ 落在两个零点之间——那里根本不是根轨迹，舍去；取 $d=-1190$。再用模值条件把分离点对应的 $T$ 算出来：$T=0.00055$。

```text
                \                 |

      -1190      -587.7   -27.7    |      0(三重)
        ^两支在此会合               |

```

读图：从三重极点 $0$ 出发，一支沿负实轴直奔零点 $-27.7$（$\left(-27.7,\ 0\right)$ 这段是轨迹）；另两支沿 $\pm 60^\circ$ 出发冲进右半平面，穿过虚轴后折回左方，在 $-1190$ 处会合，再沿实轴分开——一支向左奔 $-\infty$，一支向右终止于零点 $-587.7$；两个零点之间那段实轴不是轨迹。

现在研究的实际上是 $\dfrac1T$ 从零到无穷大变化出来的轨迹。那要研究 $T$ 从零到无穷大变化怎么办呢？倒过来就行了。

### 另一种等效：把极点安在无穷远

碰到分子阶次高的问题，其实还有一个办法。构造等效开环传递函数时，把含 $T$ 的 $Ts^3$ 放在分子上，分母是那两个因子——把分母"乘个 1"：就认为有一个开环极点在负无穷远的地方，写成

$$G^*(s)=\frac{Ts^3}{(s+27.7)(s+587.7)\cdot 1}$$

这样分子分母的阶数一样多了，就好办了。

这么一来你看：原来是叉叉的地方变成圈圈了，原来是圈圈的地方变成叉叉了，还有一个叉叉在无穷远的地方。轨迹形状和刚才那条一样，但方向刚好反过来：$T$ 从零到无穷大，分支从 $-27.7$、$-587.7$ 和无穷远处出发，最后汇到原点的三重零点上。分离点还是 $-1190$，对应的 $T$ 值不变；虚轴交点还是 $\omega=126.45$，对应的 $T$ 比分离点的大——沿 $T$ 增大的方向，先经过分离点，再穿越虚轴。原来在出发点那里算的叫起始角（出射角），现在要在终点算了，叫中止角（进入角），按中止角的方法来做，一样是 $\pm 60^\circ$、$180^\circ$。

所以说，有的时候构造等效开环传递函数未必是唯一的，但你不管怎么去分析、去做，只要做对了就没有问题。

把这一节收拢一下：参数根轨迹——除 $K^*$ 之外的其他参数从零到无穷大变化时根轨迹的绘制问题——解决它的关键就一条：**构造等效开环传递函数**；由等效开环传递函数去画根轨迹；但是根轨迹画出来之后，等效开环传递函数的使命就完结了。

## 零度根轨迹：实质正反馈下的根轨迹
> 对应块：BLK30 | 覆盖分集：P30 | 块标题（分集名）：《第15节课4.3 广义根轨迹（下）》

时间到了，接着上课。广义根轨迹我们讲了第一种——参数根轨迹，它专门解决 $K^*$ 之外的其他参数从零到无穷大变化时的根轨迹绘制问题。广义根轨迹还有另外一种问题，叫做**零度根轨迹**。注意这句话：零度根轨迹是系统**实质上处于正反馈**情况时的根轨迹。这句话现在听起来可能还没有太深的感觉，我们把道理一层一层剥开。

### 零度根轨迹从哪儿来：相角条件里的 −1 换成了 +1

不管是正反馈还是负反馈，开环传递函数总是前向通道传递函数和反馈通道传递函数乘到一起，$G(s)H(s)$ 总能化成首一标准型：

$$G(s)H(s)=\frac{K^*\prod\limits_{i=1}^{m}(s-z_i)}{\prod\limits_{j=1}^{n}(s-p_j)}$$

其中 $K^*$ 叫根轨迹增益，$z_1\sim z_m$ 是开环的 $m$ 个零点，$p_1\sim p_n$ 是开环的 $n$ 个极点。用梅逊增益公式写闭环传递函数时，特征式是 $1$ 减去（正的）$G(s)H(s)$——因为现在是正反馈，那个地方是负的。令分母为零就是特征方程，把 $1$ 拿到等式右边、两边把符号去掉，得到根轨迹方程：

$$G(s)H(s)=1$$

满足这个方程的 $s$ 就是根轨迹上的点。取模：$\lvert G(s)H(s)\rvert=1$。正 $1$ 和负 $1$ 的模都是 $1$，所以**模值条件和负反馈的时候一模一样**。取相角就不一样了：负 $1$ 在 $s$ 平面当中是负实轴方向的矢量，相角是 $(2k+1)\pi$；正 $1$ 是正实轴方向的矢量，相角是 $2k\pi$。于是相角条件改成

$$\angle G(s)H(s)=2k\pi$$

由这对条件画出来的根轨迹就叫零度根轨迹——$2k\pi$ 取 $k=0$ 时是零度，不是 180 度。我们原来经常画的那个 180° 根轨迹，也叫常规根轨迹。

> **定义**：零度根轨迹，就是系统实质上处于正反馈时，按"模值条件不变、相角条件改为 $2k\pi$"画出来的根轨迹。

### 八条法则只改三条

原来绘制常规根轨迹的那八条法则，现在显然不能直接搬过来用了。看一看哪些要变：凡是牵扯到原来是 $(2k+1)\pi$ 的地方，都要改成 $2k\pi$。

| 法则 | 180° 根轨迹（常规） | 零度根轨迹 |
| :--- | :--- | :--- |
| 实轴上的根轨迹 | 右边开环零极点个数为**奇数**的段 | 个数为**偶数**的段 |
| 渐近线与实轴正方向夹角 | $\dfrac{(2k+1)\pi}{n-m}$ | $\dfrac{2k\pi}{n-m}$ |
| 出射角／入射角 | 相角方程右边按 $(2k+1)\pi$ 列 | 相角方程右边按 $2k\pi$ 列 |

其余的照旧沿用：起点终点没有变——正反馈负反馈都是起于开环极点、终止于开环零点，剩下的跑向无穷远；分支数、对称性没有变；根之和没有变——$n-m\ge 2$ 时闭环根之和等于开环极点之和，是个常数；分离点没有变——分离点和 $(2k+1)\pi$ 没有关系，还是把那个方程拿来代就完了；与虚轴交点没有变——还是令 $s=\mathrm{j}\omega$、实部虚部分别等于零。

所以画根轨迹时，只要判定这个系统该画零度根轨迹，就把这三条法则换过来用，别的一律照旧。

### 同一个系统，正负反馈各画一遍

看一个系统结构图，反馈口的符号可以是正的，也可以是负的。$K^*$ 从零到无穷大变化，把负反馈（180°）和正反馈（零度）的根轨迹分别画出来。开环传递函数化成首一标准型：

$$G(s)H(s)=\frac{K^*(s+1)}{s^2+2s+2}=\frac{K^*(s+1)}{(s+1)^2+1}$$

一个开环零点在 $-1$，两个开环极点在 $-1\pm\mathrm{j}$；把分母常数提出来，就得到开环增益与根轨迹增益 $K^*$ 之间的关系。负反馈时用蓝的画，正反馈时用红的画。

#### 负反馈：180° 根轨迹

老老实实地算。实轴上的根轨迹：右边零极点个数为奇数的那段，即 $(-\infty,-1]$。渐近线 $n-m=1$ 条，只有一条，方向就是 180°——这条不用费劲。

出射角：从极点 $-1+\mathrm{j}$ 出发时怎么走？零点就在它的正下方，指向零点的夹角是 $90°$；另一个极点也在正下方，夹角同样是 $90°$。按相角条件列方程，右边取 $-180°$：

$$\theta=-180°+90°-90°=-180°$$

解出来 $\theta=180°$——水平的、向左走。

分离点方程代进去：

$$\frac{1}{d+1+\mathrm{j}}+\frac{1}{d+1-\mathrm{j}}=\frac{1}{d+1}$$

通分、交叉相乘，得到关于 $d$ 的一元二次方程，解出来 $d=-2$ 和 $d=0$ 两个根。$d=-2$ 落在实轴段上，是 180° 根轨迹的分离点，用模值条件把对应的 $K^*$ 算出来等于 $2$。那个 $d=0$ 先记下——它不是 180° 的分离点，就有可能是零度根轨迹的分离点。

其实不这么算也能直接画：两个起点、一个零点，**圆心**有了、**半径**也有了，直接画就完了。一个零点配一对共轭极点，根轨迹就是以零点为圆心的圆——圆心在 $-1$，半径是零点到极点的距离 $1$。180° 根轨迹走左半圆：

```text
                jw
                |
                x                 <- 开环极点 -1+j
            .-' | '-.
          .'    |    '.
  ------x-------o-------x------->
        '    |    '
            '-. | .-'
                x                 <- 开环极点 -1-j

  o = 开环零点 -1（圆心，半径 1）    两侧的 x = 分离点 -2 与 0（对应 K* 都是 2）
  左半圆 + 负实轴：180°根轨迹（负反馈）  右半圆 + [-1,+∞)：零度根轨迹（正反馈）
```

两支从共轭极点出发，贴着左半圆走到 $-2$ 相遇分离，之后一支沿负实轴奔向无穷远，一支折回零点 $-1$。

#### 正反馈：零度根轨迹

实轴上的根轨迹有吗？有。零是偶数，右边零极点个数为偶数的段全是——$[-1,+\infty)$ 整段都是零度根轨迹。实际上你把实轴看明白：**除了是 180° 根轨迹的点，剩下的一定全是零度根轨迹的点**——奇数段归它，偶数段归你，实轴被两类根轨迹瓜分得干干净净。

出射角也有，只是右边不再等于 $-180°$，而是等于 $0°$（$2k\pi$ 取 $k=0$）：夹角还是那两个 $90°$，$\theta=0°+90°-90°=0°$——水平向右。

分离点方程就是刚才那个，解出来除了 $-2$ 还有 $d=0$——它正是零度根轨迹的分离点，对应的 $K^*$ 算出来也是 $2$。把分离点标在原点，画出来是个标准的半圆：两支从共轭极点出发贴着右半圆走到原点相遇分离，一支沿正实轴奔向 $+\infty$，一支折回零点 $-1$。

### 正反馈和负反馈是一件事的两个方面

对着这样一幅图形，你有什么感想？正反馈和负反馈不是对立的东西，**它们是同一个事情的两个方面**。

看这个正反馈系统，特征式是 $1-K^*G(s)H(s)=0$。把这个式子换一个弯去讨论：正号可以写成两个负号相乘，负负得正——一个负号留在原地，另一个顺着回路拖过去，系统是等效的。于是

$$1-K^*G(s)H(s)=0\quad\Longleftrightarrow\quad 1+(-K^*)\,G(s)H(s)=0$$

把 $-K^*$ 看成一个整体的、广义的增益，右边就成了我们熟悉的负反馈特征式。这下两条路都通了：

- $K^*$ 从零往正无穷大变化时，广义增益 $-K^*$ 从零往负无穷大变化，回路实质上处于正反馈——画零度根轨迹；
- $K^*$ 从零往负无穷大变化时，广义增益 $-K^*$ 从零往正无穷大变化，虽然反馈口画的是正号，但这一负，整个回路实质上处于负反馈——画 180° 根轨迹。

把 $K^*=0$ 时的开环极点分布当成一个暂时的基地：$K^*$ 从零往正无穷变，画零度根轨迹，变到 $2$ 时到了分离点；$K^*$ 不继续往正无穷变了，反过来向负无穷变——先从 $2$ 倒回到零，根回到原来的极点上，再往负无穷的过程当中，接续画出 180° 根轨迹。整幅图是连着的一回事。

再进一步，找一个广义增益 $K'=K^*-2$：当 $K'=0$ 时 $K^*=2$，闭环极点恰好落在原来的分离点上——那里成了一个二重极点，"两个叉叉"挪到了这儿；以它为新的起点往负方向画，又是一幅图景。基准点挪到哪里，根轨迹就从哪里画起——**根轨迹是相对的**，正反馈负反馈要统一起来看，辩证地去看。

> **结论**：什么叫正反馈、什么叫负反馈？它们俩是连在一起的。同一个系统，增益往正方向变是一种反馈，往负方向变就成了另一种反馈——不要把它们看成对立的东西。

### 三重极点例题：增益平移与等效开环传递函数

看一个单位反馈系统，开环传递函数给你了：

$$G(s)=\frac{K^*(s+1)}{(s+3)^3}$$

三个重合的极点在 $-3$，一个零点在 $-1$；把 $3\times3\times3=27$ 提出来，就得到开环增益与 $K^*$ 的关系。分别画 180° 和零度根轨迹。

#### 先画两幅根轨迹

**180° 根轨迹（负反馈）**：实轴上的根轨迹是 $(-3,-1)$ 这段。三重极点的出射角：三条出射角均分，算出来一支是 $0°$——沿实轴向右直奔零点；另外两支凭三重极点的对称感觉直接写出 $\pm120°$。渐近线两条：与实轴交点坐标把三个极点加起来、减去零点、再除以二，$(-3-3-3+1)/2=-4$；夹角凭感觉 $\pm90°$，不用算。分离点没有——分离点方程 $3/(d+3)=1/(d+1)$ 解出 $d=0$，它不在实轴段 $(-3,-1)$ 上，舍去。于是：一支从 $-3$ 沿实轴进入零点，另两支以 $\pm120°$ 出发，弯向 $\sigma=-4$ 处的两条竖直渐近线飞向无穷远。

**零度根轨迹（正反馈）**：实轴段换成 $(-1,+\infty)$ 和 $(-\infty,-3)$——蓝的地方一定变红，这不用说了。出射角按 $2k\pi$ 列：$180°$、$\pm60°$。一支沿负实轴直奔 $-\infty$；渐近线不用另算——夹角 $2k\pi/(n-m)$ 算出来是 $0°$ 和 $180°$，两条渐近线就是实轴本身（用公式算交点 $-4$ 也一样没有问题）。分离点方程 $3/(d+3)=1/(d+1)$ 解出 $d=0$，对应的 $K^*$ 值为 $27$。注意这个原点：它既是分离点，也落在虚轴上——两支以 $\pm60°$ 出发向右走，恰好行到原点相遇，与虚轴的交点和分离点重合在这一处；过后一支折回零点 $-1$，另一支沿正实轴奔向 $+\infty$。

#### 把增益平移 27：等效开环传递函数

原来的特征方程是

$$(s+3)^3+K^*(s+1)=0$$

我们找一个 $K^{**}$，让它等于 $K^*+27$，也就是 $K^*=K^{**}-27$，代进去重新整理：

$$(s+3)^3-27(s+1)+K^{**}(s+1)=0$$

把前两项展开：$(s+3)^3-27(s+1)=s^3+9s^2+27s+27-27s-27=s^2(s+9)$，于是

$$s^2(s+9)+K^{**}(s+1)=0$$

构造等效开环传递函数——把 $K^{**}(s+1)$ 甩在分子上、$s^2(s+9)$ 甩在分母上：

$$G_{\mathrm{eq}}(s)=\frac{K^{**}(s+1)}{s^2(s+9)}$$

等效开环的零极点：二重极点在原点，一个极点在 $-9$，一个零点在 $-1$。

$K^{**}=0$ 就是 $K^*=-27$：原系统沿零度根轨迹画到 $-27$ 时，两支刚好走到原点，第三支跑到哪儿了？用根之和去确定它——闭环根之和等于开环极点之和 $-9$，所以第三支在 $-9$。$0$、$0$、$-9$，正是等效开环的那三个极点。

$K^{**}$ 从零往正无穷变化（反馈口为负，画 180° 根轨迹）：$K^{**}=27$ 时刚好是 $K^*=0$，根又回到了三重极点 $-3$；再往大变，就接续原来 180° 根轨迹的走向过去了。

看这里面的相对性：同一个 $d=0$，对原系统来讲（以 $K^*=0$ 时的三重极点分布为基准）它是一个**分离点**；对 $K^{**}$ 来讲（以 $0,0,-9$ 为起点）它是一个**起始点**。无非就差了一个 27——往回倒的时候，它恰好倒回这个地方。

#### 分离角：化成起始角来算

原来求分离点，我们只给出了一个计算公式，那个只能求出分离点的**坐标**。还有一个问题叫**分离角**：分支这么进去、那么出来，到底怎么出来的？有些教科书上给了分离角公式，但那不是一个一般性的公式——分离点的情形各种各样，有的时候这么进这么出，有的时候又换个走法。

把根轨迹相对性的问题搞清楚之后，你就可以把分离点的问题**化成起始角的问题**来处理：把增益平移一下，原分离点在等效系统里变成了一个二重极点（起始点），求它的出射角，分离角问题就解决了——红的是零度根轨迹的起始角，蓝的是 180° 根轨迹的起始角。本题等效系统在原点的二重极点，按 180° 法则列出射角：

$$\theta=\frac{1}{2}\left[(2k+1)\times180°+0°-0°\right]=\pm90°$$

两支垂直离开实轴，这就是原系统在分离点处分合的方向信息。

### 画零度还是画 180°：根子在根轨迹方程

给你一个问题，怎么判断该画零度根轨迹还是 180° 根轨迹？根子在**根轨迹方程**上。把开环传递函数写到等号左边、化成 $K^*$ 从零到正无穷变化的标准型——前面有负号全部搬到等号右边去。等号右边最后画出来是 $-1$，就是 180° 根轨迹；是 $+1$，取相角是正一的相角 $2k\pi$，就是零度根轨迹。

我再说一遍：零度根轨迹，实际上是系统**实质上处于正反馈**情况下的根轨迹。反馈口的负号是负还是正，不算数；看整个闭回路当中那个符号是单数个还是偶数个——包括 $K^*$ 从零往负无穷大变化时带来的那个负号，那个负也算。实质上是正反馈，就画零度根轨迹。

> **易错点**：不要盯着结构图上比较点旁边的正负号下结论。回到根轨迹方程，化成标准型后看等号右边是 $+1$ 还是 $-1$，这才是判断的根子。

到这里，广义根轨迹的两种问题收个尾。参数根轨迹，解决问题的关键在于构造等效开环传递函数——但是要注意，等效开环传递函数的适用范围就是画根轨迹，根轨迹画完以后它的使命就完结了，再不要它了，分析系统性能要回到原来的特征方程去。零度根轨迹，记住绘制法则当中和 180° 不一样的那三条——实轴上的根轨迹、渐近线、出射角入射角，而且要特别会判断该画哪一种。课后把今天讲的内容通过作业好好理解一下。

### 根轨迹对称性定理

根轨迹的对称性，我们在法则二当中说过：根轨迹一定关于 $s$ 平面的实轴上下对称。现在说的是另一回事——**关于平行于虚轴的一条竖线左右对称**的问题。

> **定理**：假如开环零点和开环极点均为偶数个，而且这些开环零点、极点关于平行于虚轴的一条直线左右对称分布，那么画出来的根轨迹一定关于这条直线左右对称。

#### 无零点的四极点对称分布

举例子看。一个系统，开环极点画出来：一个在 $0$，一个在 $4$，还有一对在 $2\pm\mathrm{j}4$；开环零点是零个——都是偶数个，而且 $0$ 与 $4$ 互为镜像、$2\pm\mathrm{j}4$ 就落在 $Re\,s=2$ 这条线上，整体关于这条线左右对称，满足定理。画一下：实轴上 $(4,+\infty)$ 这段是根轨迹；渐近线四条，都要跑到无穷远处，与实轴的交点坐标是零极点分布的一个**广义重心**，恰好就落在 $2$ 这条对称线上；夹角四个，$\pm45°$、$\pm135°$。根轨迹画出来，确实关于这条线左右对称。

这个图形长什么样，完全取决于开环零极点的分布：如果这几个极点挨得近一点、那几个离得远一点，那是这两个先相遇、然后再和那两个相碰；如果两两之间的距离完全一样，四个分支同时到一处相碰，压着四条渐近线直接飞出去。

#### 关于虚轴对称的一道老题

再举个例子。开环零点在 $\pm\mathrm{j}2$，开环极点在 $\pm1$、$\pm3$：零点两个、极点四个，都是偶数个，而且关于虚轴左右对称——满足定理。实轴上的根轨迹是 $(1,3)$ 和 $(-3,-1)$ 两段，互为镜像；渐近线两条，$\pm90°$，而且一定在虚轴上；分离点成对出现。这道题是我们学校 1987 年的一道研究生入学考题，当年得分率是 7%——一百个考生只有七个做对。如果考生知道这个定理，做对的概率就会大很多。像这种题关键在求分离点：表面上看是个四阶的，但你不要轻易放弃用求根的方法求分离点的努力——对称的问题往往可以导出关于 $d^2$ 的一元二次方程，一解就把两个分离点准确无误地求出来，根轨迹自然就没有问题了。完整的题目和解法放在文末。

#### 再看一个对称分布

再看一个：四个极点两两成对、两个零点，全部关于一条平行于虚轴的直线左右对称，都是偶数个。实轴上的根轨迹不用考虑——数一数哪段都不满足。这里有一个出射角的问题，凭对称性直接写：四个出射角，$\pm45°$、$\pm135°$。这个题给你一个启示：求分离点时，把 $s$ 平移到对称线的地方，同样可以导出关于分离点平方的一元二次方程，解它就行了。有了这个定理，以后碰到这种问题，你就不至于在那儿苦思冥想半天还算不对了。

### 本讲提到的题目

**题干**（1987 年研究生入学考题）：系统的开环传递函数为

$$G(s)=\frac{K^*(s^2+4)}{(s^2-1)(s^2-9)}$$

即开环零点 $s=\pm\mathrm{j}2$，开环极点 $s=\pm1,\ \pm3$。试绘制 $K^*$ 从 $0\to\infty$ 变化时的根轨迹。

**解析**：

- 零点两个、极点四个，都是偶数个，且关于虚轴左右对称——由对称性定理，根轨迹关于虚轴左右对称，画右半平面、左半平面镜像即可。
- 实轴段：$s\in(1,3)$ 时右边有 3 个极点（奇数），是根轨迹；$s\in(-3,-1)$ 同理。两段互为镜像。
- 渐近线：$n-m=2$ 条，与实轴交点 $\sigma=\dfrac{\sum p_i-\sum z_j}{n-m}=\dfrac{0-0}{2}=0$，恰在虚轴上；夹角 $\pm90°$——渐近线就是虚轴本身。
- 分离点：由 $\sum\dfrac{1}{d-p_i}=\sum\dfrac{1}{d-z_j}$ 得

$$\frac{2d}{d^2-1}+\frac{2d}{d^2-9}=\frac{2d}{d^2+4}$$

约去 $2d$，令 $v=d^2$，整理得一元二次方程 $v^2+8v-49=0$，解出 $v=-4+\sqrt{65}\approx4.06$（另一根为负，对应虚轴上属于 $K^*<0$ 一侧的分离点，舍去），所以 $d\approx\pm2.02$。这正是"对称问题可以解出关于 $d^2$ 的一元二次方程"——四阶问题照样能准确无误地求出分离点。
- 终点：$K^*\to\infty$ 时，两支终止于零点 $\pm\mathrm{j}2$，另外两支沿虚轴方向的渐近线趋于无穷远。

**答案要点**：根轨迹关于虚轴左右对称；实轴段为 $(1,3)$ 与 $(-3,-1)$；两支分别在 $d\approx\pm2.02$ 处相遇分离；上半平面两支沿渐近线方向运动，其中一支最终落在零点 $+\mathrm{j}2$ 上"休息"，另一支奔向无穷远，下半平面镜像对称。

## 利用根轨迹分析系统性能
> 对应块：BLK31 | 覆盖分集：P31 | 块标题（分集名）：《第16节课4.4 利用根轨迹分析系统性能分析;》

上课之前，先把前两次课讲的绘制根轨迹的八条法则再过一遍。根轨迹法要用它来分析问题、解决问题，前提是你能熟练地把根轨迹画出来；而画根轨迹，最重要的就是把八条法则的具体运用练到滚瓜烂熟。

### 八条法则快速过一遍

**起点、终点与分支数。** 根轨迹起于开环极点，终止于开环零点，剩下的分支跑向无穷远处；根轨迹的分支数就是系统的阶数，也就是特征方程的阶数。根轨迹对称于 $s$ 平面的实轴；当参数从零到无穷大连续变化时，根轨迹也连续变化，不会发生跳跃。

**根之和。** 当 $n-m\ge 2$ 时，闭环极点之和等于开环极点之和，是一个常数。这条结论看似不起眼，后面确定闭环极点位置时要反复用它。

**分离点。** 分离点方程两种根轨迹是同一个。放在那儿能解则解，不能解就试根——试根这个功夫要掌握住。

**与虚轴交点。** 令 $s=\mathrm{j}\omega$，让实部、虚部分别等于零，两个方程解出两个参数：一个是与虚轴的交点，一个是对应的 $K^*$ 值。

**出射角、入射角。** 规矩就是相角条件。

剩下三条——实轴上的根轨迹、渐近线夹角、出射入射角——在负反馈（180° 根轨迹）和正反馈（0° 根轨迹）下是不一样的，列在一起对照着记：

| 法则 | 180° 根轨迹 | 0° 根轨迹 |
| :--- | :--- | :--- |
| 实轴上的根轨迹 | 右侧开环实零极点个数为奇数的区段 | 右侧开环实零极点个数为偶数（含 0）的区段 |
| 渐近线与实轴正方向夹角 | $\dfrac{(2k+1)\pi}{n-m}$ | $\dfrac{2k\pi}{n-m}$ |
| 出射角／入射角（相角条件） | 相角代数和为 $(2k+1)\pi$ | 相角代数和为 $2k\pi$ |

渐近线本身规定的是 $n-m$ 条根轨迹分支趋向无穷远时所遵循的规律，要算两样东西：渐近线与实轴交点的坐标、与实轴正方向的夹角。

### 广义根轨迹的两类问题

上节课讲的广义根轨迹分两种情况。**一种是参数根轨迹**：除了 $K^*$（开环增益）之外的其他参数从零到无穷大变化时的根轨迹。解决它的关键在于：把系统的特征方程拿出来，根据特征方程构造等效开环传递函数，根轨迹就按这个等效开环传递函数画。但画完以后，这个等效开环传递函数就没用了——不要再拿它往下延续。

**第二种是零度根轨迹**：它实际上是系统在实质上处于正反馈时的根轨迹。绘制时要正确区分什么情况下画零度根轨迹、什么情况下画 180° 根轨迹；两者对应的法则里恰好有三条不一样，就是上表列出的那三条。

今天讲第四章的第四节：利用根轨迹来分析系统的性能。讲完这一节，第四章就结束了，下一次课进入第五章。

### 用根轨迹分析性能的完整路数

整个分析可以分这么几步：

1. 根据系统的开环传递函数，把根轨迹画出来；
2. 根据题意，确定闭环极点在根轨迹上的具体位置；
3. 确定闭环零点的位置——它不随 $K^*$ 的变化而变化。估计性能指标时，闭环零点、闭环极点都对动态性能有影响，所以零点的位置也要定下来；
4. 看闭环零、极点在 $s$ 平面上的分布：离虚轴远的非主导零极点去掉，靠得很近的偶极子也去掉，把主导闭环极点留下来；
5. 用前辈们总结出来的零点极点法估算动态性能指标。手算之外，有计算机的话把响应算出来也不在话下。

> **定义**：闭环零点 $=$ 前向通道的开环零点 $+$ 反馈通道的开环极点。

为了说明这套路数，下面用一个三阶系统把四个典型子问题过一遍。这四个小问题是独立的，互相没有直接关系，但都是在"画根轨迹、定闭环极点位置、定闭环零点位置、估算动态性能指标"这条链上碰到的典型问题。

### 例题铺垫：画出三阶系统的根轨迹

系统结构图已经给出，$K^*$ 是根轨迹增益，让它从零到无穷大变化。开环传递函数等于前向通道与反馈通道传递函数乘到一起：

$$G_k(s)=\frac{K^*}{s(s+2)(s+4)}$$

系统是 I 型的，$K^*$ 与开环增益 $K$ 之间的关系是 $K=\dfrac{K^*}{8}$。开环极点三个：$0$、$-2$、$-4$；开环零点没有。

画根轨迹这件事，交给你们了——到现在为止应该弄得滚瓜烂熟了：

- **实轴上的根轨迹**：$[-2,0]$ 与 $(-\infty,-4]$ 两段；
- **渐近线**：$n-m=3$ 条，与实轴交点 $\sigma_a=\dfrac{0-2-4}{3}=-2$，夹角 $\pm 60°$、$180°$；
- **分离点**：两个分支在 $[-2,0]$ 段内一定要分离。分离点方程

$$\frac{1}{d}+\frac{1}{d+2}+\frac{1}{d+4}=0\;\Longrightarrow\;3d^2+12d+8=0$$

  解出两个根：$d=-0.845$ 和 $d=-3.155$。显然 $-3.155$ 这个不是——它不在根轨迹上；$-0.845$ 确实在 $[-2,0]$ 段内，取它。顺便把分离点对应的 $K^*$ 用模值条件算出来：三个矢量的模相乘就是它，

$$K^*=0.845\times1.155\times3.155\approx3.08$$

- **与虚轴交点**：特征方程 $s^3+6s^2+8s+K^*=0$，令 $s=\mathrm{j}\omega$，实部、虚部分别为零，两个方程解两个未知数：$\omega(8-\omega^2)=0$ 与 $K^*=6\omega^2$。$\omega=0$ 是起点，不要它；剩下的 $\omega^2=8$，即 $\omega=\pm2.83$，对应 $K^*=48$。

画出来就是：

```text
                  jω
                   |
                   |     ↗ 渐近线 +60°
                   |   ↗
                   | ↗    与虚轴交于 (0, ±j2.83)，K* = 48
  ×←―――――×―――・―――×――――――――→ σ
 -4     -2  -0.845 0
                   | ↘
                   |   ↘ 渐近线 -60°
                   |
```

读图：$\lambda_3$ 这条分支从极点 $-4$ 出发沿实轴向左跑向无穷远；另外两条分支从 $0$ 和 $-2$ 相向而行，在分离点 $-0.845$（$K^*=3.08$）会合后沿 $\pm60°$ 渐近线趋向无穷，途中在 $\pm\mathrm{j}2.83$（$K^*=48$）穿越虚轴。$K^*=3.08$ 时两个极点正好落到分离点上，$K^*=48$ 时共轭分支正好骑到虚轴上。

### 既稳定又欠阻尼的开环增益范围

第一个子问题：确定使系统既稳定、又处于欠阻尼状态时，开环增益 $K$ 的取值范围。

先不管 $K$，看 $K^*$。系统要稳定，什么意思？所有闭环极点都严格落在虚轴左边——那就要求 $K^*<48$。要欠阻尼，什么意思？闭环极点要落在分离点以后，出现一对共轭复根，阶跃响应才显出震荡收敛的过程——那就要求 $K^*>3.08$。

三阶系统有三个闭环极点：共轭分支上一对，实轴分支上一个。实轴分支上那个闭环极点离虚轴远，是非主导极点，我们不去考虑它；高阶系统要说阻尼比是多少，都是针对主导共轭极点所对应的那个二阶子系统而言的。

所以 $3.08<K^*<48$。开环增益把它除以 8 就行：$0.385<K<6$。对应阻尼比在 0 和 1 之间——既欠阻尼又稳定——$K$ 就取这个范围。第一个问题解决。

### 阻尼比 0.5 时的三个闭环极点

第二个子问题：共轭复极点对应的阻尼比 $\xi=0.5$，也就是 $\beta$ 角等于 60° 时，对应的开环增益是多少？三个闭环极点的具体坐标在什么地方？

把根轨迹中有用的那一半画出来（右边已经不稳定了，不用看）。从原点作一条 60° 的线连到根轨迹上，交点就是要求的 $\lambda_1$，底下对称的是 $\lambda_2$；$\lambda_3$ 用根之和算。问题是：根轨迹是手工画的，本身就画不准；即便画准了，你把它连在这儿，也不一定读得非常准。现在只知道 $\xi=0.5$，怎么把 $\lambda_1$、$\lambda_2$、$\lambda_3$ 精确算出来？

既然是一对共轭复根，就按复根的一般表达形式来设：

$$\lambda_{1,2}=-\xi\omega_n\pm\mathrm{j}\omega_n\sqrt{1-\xi^2},\qquad \xi=0.5$$

$\lambda_3$ 不另设未知数，用根之和把它表示成 $\omega_n$ 的函数。$n-m=3\ge2$，闭环根之和等于开环根之和：$0+(-2)+(-4)=-6$；而 $\lambda_1+\lambda_2=-2\xi\omega_n=-\omega_n$，虚部一加约掉、实部合成，所以

$$\lambda_3=-6+\omega_n$$

这么操作以后解方程少一个变量——要不然最后给出来一个二元二次方程，解起来就不太容易了。

特征方程就是开环传递函数的分母加分子：$s^3+6s^2+8s+K^*=0$。另一方面，三个闭环极点已知，特征多项式又等于

$$(s-\lambda_1)(s-\lambda_2)(s-\lambda_3)=(s^2+\omega_n s+\omega_n^2)(s+6-\omega_n)=s^3+6s^2+6\omega_n s+\omega_n^2(6-\omega_n)$$

两个表达式应该相同，$s^2$ 项系数自动吻合，拿一次项系数和常数项相等列两个方程，解两个未知数（$\omega_n$ 和 $K^*$）：

$$6\omega_n=8\;\Longrightarrow\;\omega_n=\frac43,\qquad K^*=\omega_n^2(6-\omega_n)=\frac{16}{9}\times\frac{14}{3}\approx8.3$$

$\omega_n$ 一旦解决，$\lambda_1$、$\lambda_2$、$\lambda_3$ 都是 $\omega_n$ 的函数，全部定出来：

$$\lambda_{1,2}=-\frac23\pm\mathrm{j}\frac{2\sqrt3}{3}\approx-0.667\pm\mathrm{j}1.155,\qquad \lambda_3=-6+\frac43=-\frac{14}{3}\approx-4.667$$

$K^*=8.3$，除以 8 就是对应的开环增益 $K\approx1.04$——闭环极点落在这些位置上的那个 $K$ 值。有了三个闭环极点的位置，再把闭环零点的位置定下来，动态性能指标的问题就可以进一步估算了。

### 已知一个极点，反求其余

第三个子问题：有一个闭环极点刚好落在 $-5$ 的位置上（实轴分支上离虚轴远的那个根），另外两个极点 $\lambda_1$、$\lambda_2$ 跑哪儿去了？这时候对应的开环增益等于多少？

这个问题的解法不止一种。最直接的想法：既然 $-5$ 是三阶特征方程的一个根，特征多项式就必然能拿 $s+5$ 整除，除完剩下的二阶子式就是 $\lambda_1$、$\lambda_2$ 乘起来的那个因子。做长除：

$$s^3+6s^2+8s+K^*=(s+5)(s^2+s+3)+(K^*-15)$$

余项必须为零——要不然 $-5$ 就不叫根了——所以 $K^*=15$，$K=\dfrac{15}{8}$。于是

$$\lambda_{1,2}:\;s^2+s+3=0\;\Longrightarrow\;\lambda_{1,2}=-0.5\pm\mathrm{j}1.658$$

二阶子式的解就是 $\lambda_1$、$\lambda_2$ 精确的坐标表达。不一定非用这个方法，其他方法也行，但总归要能把它解决。

### K*=4：试根、偶极子与增益

第四个子问题：$K^*=4$ 时，三个闭环极点 $\lambda_1$、$\lambda_2$、$\lambda_3$ 跑哪儿去了？把坐标定下来，另外估计这时候系统的动态性能指标——超调量、调节时间。

#### 先把实根试出来

三阶系统至少有一个实根，设它是 $\lambda_3$。$K^*=4$ 已知，由模值条件可以列方程：

$$|\lambda_3|\cdot|\lambda_3+2|\cdot|\lambda_3+4|=4$$

但这么一做，得到一个关于 $\lambda_3$ 的一元三次方程，不好解。怎么办？除了试根，好像没有什么更好的办法——大家要是能想到别的好办法，完了以后告诉我一声。

但试根不能从负无穷到正无穷盲目地找。用前面做过的工作缩小范围：

- 分离点 $-0.845$ 对应 $K^*=3.08$，此时由根之和 $\lambda_3=-6+2\times0.845=-4.31$；
- $\xi=0.5$ 那个点对应 $K^*=8.3$，此时 $\lambda_3=-4.667$。

现在 $K^*=4$，比 3.08 大，实根已经跑到 $-4.31$ 的后边（更左）；又比 8.3 小，还到不了 $-4.667$。而且 $\lambda_1$、$\lambda_2$ 肯定已经是一对共轭复根。所以 $\lambda_3$ 一定介于 $-4.31$ 和 $-4.667$ 之间，并且和 $-4.31$ 比较接近——就在这附近试。碰到这类问题要想一想：有什么信息可以帮助我们试这个根？

试的结果：$\lambda_3=-4.383$，比 $-4.31$ 稍微负得多一点，还没到 $-4.667$。只要把这一个根试出来，就好办了：拿 $s+4.383$ 去除特征多项式，得到一个二阶子式

$$s^3+6s^2+8s+4=(s+4.383)(s^2+1.617s+0.913)$$

这个二阶子式对应的就是 $\lambda_1$、$\lambda_2$ 的位置，解出来：

$$\lambda_{1,2}=-0.808\pm\mathrm{j}0.509$$

三个闭环极点的位置全部落定。

#### 闭环零点与偶极子的取舍

接下来估算动态性能指标。闭环极点当然决定系统的稳定性，也影响动态性能指标；但影响动态性能指标的除了闭环极点，还有闭环零点——这时候不要忘了：闭环零点等于前向通道的开环零点加反馈通道的开环极点。本例反馈通道的极点 $-4$ 同时是开环极点，按这个公式它同时是一个闭环零点，把它标上。这时图上才是闭环零、极点分布的完整图。

看着这个图，决定下一步怎么做。$\lambda_{1,2}$ 离虚轴的距离是 $0.808$；$\lambda_3$ 离虚轴 $4.383$，已经是 $0.808$ 的五倍多——即便没有这个闭环零点，单看它来讲也可以忽略不计，当非主导极点去掉。何况不但离得远，它周围离它很近的地方还有一个闭环零点：闭环零点和闭环极点的作用是相互抵消的，要是俩干脆挨到一起，那就一点影响没有。所以把 $\lambda_3$ 连同这个零点当偶极子去掉，直接拿剩下两个极点所对应的那个典型欠阻尼二阶系统去估算三阶系统的性能指标，准确度应该相当高。

```text
                 jω
                  |
       • λ₁       |
  (−0.808+j0.509) |
  ―――○――――×――――――+―――――→ σ
     -4  -4.383  0
      ↑    ↑
  闭环零点与 λ₃ 挨得很近，构成偶极子，一起拿掉
```

#### 约掉偶极子时增益要保住

先把闭环传递函数按梅逊增益公式写出来，分子分母同除整理。$K^*=4$ 时：

$$\varPhi(s)=\frac{4(s+4)}{(s+4.383)(s^2+1.617s+0.913)}$$

分子上的因子 $(s+4)$ 和分母上的 $(s+4.383)$：要是完全一样，就是分子分母相对消了，对系统的输入输出特性没有影响；现在它毕竟不一样，但挨得比较近，就近似把它约掉。注意——约掉它的同时，要把这对因子对应的增益保留下来。把它去掉没有关系，但要保证闭环传递函数的增益变换以后和原来一样，要不然闭环增益不一样，单位阶跃响应的稳态值就不一样了。

$(s+4)/(s+4.383)$ 在低频下的增益是 $4/4.383\approx0.913$。没约以前，原系统闭环传递函数的稳态增益是 4；约掉偶极子、把 0.913 保留下来之后，闭环增益 $4\times0.913/0.913=4$，和原来一样。

#### 按典型二阶估算，再用仿真对账

对约化后的典型欠阻尼二阶系统：$\omega_n=\sqrt{0.913}\approx0.956$，$\xi=\dfrac{1.617}{2\omega_n}\approx0.8463$，欠阻尼。先估超调量的量级：$\xi=0.8463$ 比 $0.707$ 大，阻尼比越大超调量越小，所以算出来的超调量必定比 5% 还小——具体结果 $\sigma\%\approx0.69\%$；调节时间 $t_s=\dfrac{3.5}{0.808}\approx4.33$ 秒（$\Delta=5\%$）。

当然，这是按两个主导极点当成典型欠阻尼二阶系统算出来的，忽略了偶极子的影响。计算机上把结果算一下看：红线是没有约之前、闭环零点和这个极点都加在里面的单位阶跃响应；把偶极子约掉、增益保留下来之后是黑线——黑线和红线几乎贴在一起，动态性能指标差别很小。但要是把这因子直接约了、增益不提出来，那就是蓝线了：闭环增益变成 $4/0.913\approx4.38$，比 4 大，单位阶跃响应的稳态值就不再落到 4 了。增益留下来的话，黑线和红线的稳态值是一样的。

> **易错点**：闭环增益的大小对动态性能没有影响，但它影响单位阶跃响应的稳态值。所以约掉偶极子时，"把增益提出来"这一步绝对不能省。

### 第二个系统：开环零极点对消

再来看一个系统。结构图给定，同样让根轨迹增益 $K^*$ 从零到无穷大变化画根轨迹；然后确定复数极点对应阻尼比 $\xi=0.5$（$\beta$ 角等于 60°）时的 $K$ 和闭环极点位置，再估算系统的动态性能指标。

#### 按互质形式画根轨迹

把开环传递函数写出来时发现：前向通道传递函数和反馈通道传递函数乘到一起以后，出现了零极点对消——这两项要约、那两项要约，最后约到互质的那个关系式：

$$G_k(s)=\frac{K^*}{s(s+3)},\qquad K=\frac{K^*}{3}$$

这是开环零极点对消这样一个特殊情况。不管它，就根据互质的这个结果把开环零极点分布画出来。画根轨迹很简单，直接画出来就是：

```text
            jω
             |
     λ₁ ↑    |    ↑ λ₂
        |    |    |
  ×――――――・―――――×―――――→ σ
 -3    -1.5    0
```

两个分支从 $0$ 和 $-3$ 相向而行，在 $-1.5$ 那地方上下分开，沿 $\pm90°$ 方向趋于无穷。

#### 60 度线定极点，模值条件定增益

复数极点要求 $\xi=0.5$，那就从原点画 60° 线（正 60°、负 60°），和根轨迹的两个分支交出这两个复数极点。好在分离点 $-1.5$ 是个准数，60° 角也是准的，交点的位置可以准确写出来：

$$\lambda_{1,2}=-1.5\pm\mathrm{j}\,1.5\tan 60°=-1.5\pm\mathrm{j}2.60$$

有了极点位置，把它带到模值条件当中去算 $K^*$：让模等于 1，取模以后甩到另一边去。看矢量的长度：$\lambda$ 这个矢量从原点指向极点，长度是 3；$\lambda+3$ 这个矢量从 $-3$ 指向极点，实部虚部平方再开方，长度也是 3。所以

$$K^*=3\times3=9,\qquad K=\frac{9}{3}=3$$

#### 对消掉的因子在闭环里还在

碰到开环零极点对消的情况要注意：画根轨迹的时候，用互质的这个结果直接画，没问题。但是你给出来的这个根轨迹，只是闭环根当中的一部分，不是全部！到这个时候，你一定要把闭环传递函数写一下。

按梅逊增益公式写出闭环传递函数，分子分母同除整理，得到

$$\varPhi(s)=\frac{s+4}{(s+2)(s^2+3s+K^*)}$$

看清楚了：随 $K^*$ 变化的那两个根，就是 $s^2+3s+K^*=0$ 的两个根，根轨迹的两个分支表现的就是它们；此外还有**不随 $K^*$ 变化**的闭环零点 $-4$ 和闭环极点 $-2$——刚好就是出现开环零极点对消的那两个点。所以出现对消时，要找全部的闭环零极点，必须把闭环传递函数写出来，把不随 $K^*$ 变化的闭环零点、闭环极点也标上，这才全了。这个系统的闭环极点，不是就随 $K^*$ 变动的那两个。

> **易错点**：开环零极点对消后按互质形式画出的根轨迹，只是闭环极点中随参数变动的那一部分；被对消的因子在闭环传递函数里仍然存在，对应的闭环零点、极点要补标上去。

#### 附加零极点谁说了算

现在的零极点分布：三个闭环极点（共轭一对、固定的 $-2$ 一个），一个闭环零点 $-4$。要估算动态性能指标，如果仅用那两个共轭复根去按典型欠阻尼二阶系统估算，误差就比较大。

先给自己提个问题：只按两个共轭极点算出来的超调量，比实际系统的超调量是大还是小？

这样考虑：把整个系统看成"典型欠阻尼二阶系统 $+$ 附加一个闭环极点 $+$ 附加一个闭环零点"。附加闭环极点的作用是使超调量减小、峰值时间往后移；附加闭环零点的作用刚好相反，使超调量增加、峰值时间靠前。那就看谁距离虚轴更近——离虚轴近的那个闭环零点或闭环极点起的作用大。这里附加的闭环极点 $-2$ 离虚轴比零点 $-4$ 近，极点起的作用大，所以整个系统实际的超调量，要比只按两个共轭极点的典型二阶系统算出来的小，峰值时间要靠后一些。这个定性的结论我们以前讲过。

计算机上对账：蓝线是单独把两个共轭复根当成典型二阶系统估算出来的响应，红线是整个系统的单位阶跃响应——红线超调量更小、峰值时间往后移了，主要就是那个闭环极点造成的影响。而且这个极点 $-2$ 和那对共轭极点离虚轴的距离相差不多，不能把它去掉。

那算的时候应该怎么做？在零点极点法当中，找"两个共轭复根、附加一个极点、附加一个零点"对应的那组公式去算。

## 利用根轨迹分析系统性能：找全零极点、读懂 PID、初尝校正
> 对应块：BLK32 | 覆盖分集：P32 | 块标题（分集名）：《第16节课4.4 利用根轨迹分析系统性能分析;》

### 动态指标的估算：闭环零极点一个都不能漏

"快"这个指标——超调量、调节时间——到底由什么决定？它既和闭环极点有关，也和闭环零点有关。因为闭环极点决定系统的模态，而闭环零点决定每个模态前面那个加权系数。所以确定动态性能指标的时候，一定要把闭环的**所有极点和所有零点**全部在 $s$ 平面中标出来，超调量和调节时间才能唯一确定。

但闭环零极点太多太复杂时，直接计算动态指标就有困难。所以前辈们总结出一个行之有效的工程方法，不管系统阶数多高，都按这个路子走：

1. **先画根轨迹**。根据题目条件，把满足条件的闭环极点在根轨迹上的位置定下来——说穿了，就是找满足相角条件的闭环极点位置；
2. **再找闭环零点**。闭环零点很简单：前向通道的零点加反馈通道的极点；
3. **然后判断主导极点**。零极点全部标在 $s$ 平面上以后，看离虚轴近的极点是不是主导极点。像前面例子那样：其余零极点离虚轴远，而且零极点挨在一起作用相互抵消，就可以用主导极点对应的二阶系统去估算动态指标，差别不会太大。

但有一个特殊情况要特别当心：**开环传递函数出现零极点对消时，闭环的零极点可能被隐去**。你画根轨迹，画的是随 $K^*$ 变化的那些分支，它只是全部闭环极点当中的一部分；开环零极点对消以后，还可能藏着一个不随 $K^*$ 变化的固定闭环极点（或零点）。所以除了在根轨迹上定出随 $K^*$ 变化的极点，还要把闭环传递函数老老实实推一遍，看有没有通过对消隐去的闭环极点和闭环零点——把闭环零极点找全。

> **易错点**：找全以后一看分布，如果隐去的那个零点（或极点）离虚轴近、和主导极点距离相差无几，它就不能作为非主导的舍掉。这时候不能用两个主导极点对应的二阶系统去估算整个系统的动态指标，得老老实实把这些极点和零点全部保留，到零点极点法当中找这种分布对应的公式去算。可以舍的时候用二阶近似，不能舍的时候全部留下——这个分寸要拿捏住。

实际算过的对比很能说明问题：把这些零极点全部保留来算，超调量是 5.17%；如果单用那两个极点对应的二阶系统估算（60° 的 $\beta$ 角对应的超调量），是 16.3%，比实际大得多。为什么实际的小？因为那个隐去的极点离虚轴比较近，起的作用比较大——把它作为基准，把那对挨在一起的零极点看成附加的变换零极点，从这个角度去理解就清楚了。

这类题目的关键就一条：开环传递函数出现零极点对消时，最终要把闭环零极点全部找全——既有不随 $K^*$ 变化的固定闭环零极点，也有随 $K^*$ 变化的极点（根轨迹分支）。前面讲的这些知识，到这个时候要融合起来、贯通起来去运用。

### 用根轨迹看懂 PID

再举个例子，这次的目的有两个：一是从根轨迹这个角度理解 PID 对系统动态性能和稳态精度的提高各起了什么作用；二是以后做控制工程设计时，能**主动**去设计 PID 控制器——到底用 P、PD、PI 还是 PID，根据具体情况去定。

背景先交代一下：PID 就是比例加微分加积分控制器，这种控制方法在工业生产当中用得非常广泛——用的资源少，控制效果好，适用范围非常广。

题目结构：一个被控对象，前面串一个 PID 控制器。为了计算具体，把系数先取定：比例系数 $K_P = 1$，微分系数 $K_D = 0.25$，积分系数 $K_I = 1.5$。然后只让根轨迹增益 $K^*$ 从零到无穷大连续变化，分别看比例控制、比例加微分、比例加积分、比例加微分加积分四种控制方式下，系统的动态指标、稳态精度和稳定性会有什么变化——从定性的角度、从根轨迹的角度去理解。

#### 比例控制：作为比较的基准

P 控制就是把三个通道当中的比例通道连通，微分通道和积分通道打断。这时开环传递函数就是 $K_P$ 乘被控对象（$K_P = 1$），系统是一型的，根轨迹很好画：$K^*$ 从零变起，闭环极点一开始是过阻尼（两个实极点），到分离点之后进入欠阻尼。

欠阻尼这个阶段，闭环极点离开虚轴的距离就变不了了——所以调节时间不能再有明显的改善；超调量呢，把闭环极点放在 45° 线上为最佳。

把这张根轨迹作为一个基准、一个比较的标准，再看后面三种控制方式的根轨迹和它有什么不同。

#### 比例加微分：动态性能明显改善，稳态精度不受影响

PD 控制是把积分通道打断，比例和微分两路连通。开环传递函数就是 $(K_D s + K_P)$ 乘被控对象，代入系数整理后，相当于给系统在原来基础上**附加了一个开环零点**，位置刚好在 $-4$。

先看稳态。用了比例加微分以后，开环增益和系统型别都没有改变——决定稳态误差的就是开环增益 $K$ 和型别 $V$ 这两个量，所以这么做了以后，对稳态精度的改善**没有作用**。

再看动态。附加的开环零点把整个根轨迹往左边搬了，根轨迹的位置比 P 控制有利得多。P 控制时闭环极点离开虚轴的距离最多 1 个单位，调节时间 $3.5 \div 1 = 3.5$ 秒，不会再小了；而 PD 的根轨迹拉成那个形状以后，把 $K^*$ 取到合适的地方，闭环极点可以落在离虚轴更远的位置——调节时间可以比它快得多；同时 $\beta$ 角不大，超调量也可以控制得比较好。而且 $K^*$ 从零到无穷大整个变化过程中，这两个系统都不会不稳定。

根轨迹一拉出来，结论就清楚了：**用比例加微分，稳态精度不会有改善，但动态性能可以发生比较大的改善**。具体数值计算不展开，画完根轨迹都明白了。

```text
        P 控制（基准）                  PD 控制（附加零点 -4）
             jω                             jω
              |                              |   ↖
              | ← 分离点后沿垂直线 σ = -1     |    \    复数分支被零点
              |                              |     \   拉着往左弯
      ────────×━━━━━━━┿━━━━━━━×────→ σ   ━━━━━○──────×━━━┿━━━━━×──→ σ
             -2      -1       0         -4        -2 -1     0
```

左图：P 控制的根轨迹在实轴段 $[-2, 0]$ 上，分离点之后沿垂直线 $\sigma = -1$ 上行，闭环极点离虚轴的距离再也拉不开。右图：PD 控制多出的开环零点 $-4$ 把复数分支往左拉，闭环极点可以落得离虚轴更远。

#### 比例加积分：稳态精度升一档，动态性能付出代价

PI 控制是把微分通道打断，上面和底下（比例与积分）连通。开环传递函数是 $(K_P + K_I/s)$ 乘被控对象，把 $s$ 除到底下整理后是 $\dfrac{K^*(s+1.5)}{s^2(s+2)}$——原来分子上只有一个 $s$，现在变成两个 $s$ 了。

稳态上，系统从原来的一型变成**二型**了。如果这个系统稳定，它跟踪输入信号的能力要比一型高一个档次：原来的系统跟踪斜坡信号有一个常值的稳态误差，现在跟踪斜坡信号的稳态误差等于零。所以比例加积分可以非常有效地改善系统的稳态精度。

但动态上，根轨迹明显变坏了。开环零极点分布：原点是一个二重极点（两个叉叉），$-2$ 是一个极点，$-1.5$ 是一个零点。实轴上的根轨迹是 $-2$ 到 $-1.5$ 之间那一段；原点的二重极点要出射两条分支，出射角凭对称就是 $\pm 90°$——两条分支不能往一个方向走，正负 90° 是最有效的分开方式；出来以后按根之和往左偏：$n - m = 3 - 1 = 2$，有两条渐近线，这两条分支合起来向左偏、趋近于渐近线。渐近线交点算出来是 $-0.25$，从虚轴往左偏，最多偏个 0.25。

这样的根轨迹，对动态性能来讲明显变坏了：不管 $K^*$ 怎么取，闭环主导极点的 $\beta$ 角都非常大，超调量就比较大；而且主导极点离虚轴非常近，调节时间特别长。所以用比例加积分，把稳态精度做好了，但付出了**沉重的代价**——动态性能指标变差了，系统的稳定程度变差了。

归纳成规律：

| 控制方式 | 对稳态精度 | 对动态性能 |
| :--- | :--- | :--- |
| 比例加微分（PD） | 不影响 | 明显改善 |
| 比例加积分（PI） | 明显改善 | 受到损失 |

#### PID 全上：鱼与熊掌兼得

那能不能想一个方案，把比例加微分提高动态性能的"鱼"和比例加积分提高稳态精度的"熊掌"**兼而得之**呢？答案是 PID 全用上。

三个通道加起来再乘被控对象，把 $s$ 除到底下、整理成首一标准形式后，分子是一个二阶因式 $0.25s^2 + s + 1.5$，解出来是一对共轭的负零点（$-2 \pm \mathrm{j}\sqrt{2}$），再把 $0.25$ 和 $K^*$ 提出来。和 PI 相比：型别还是二型，比例加积分改善稳态精度的好处**留着了**——熊掌留着了；同时又引进了两个开环零点——鱼也进来了。

画根轨迹：实轴上是 $-2$ 以左；原点二重极点的出射角还是 $\pm 90°$；到共轭零点那边，把入射角算一下——出射角 $\pm 90°$，入射角 $109.4°$。两条复数分支朝零点方向弯过去，实轴上 $-2$ 这条往左走。和 PI 相比，当 $K^*$ 取得比较有利的时候，闭环极点离虚轴的距离比 1 个单位宽，调节时间要快；而且 $\beta$ 角不会很大，超调量也不会很大。这就把比例加微分的好处和比例加积分的好处全部放在一起了。

这里补充一点：现在这套 PID 系数（$K_P = 1$、$K_D = 0.25$、$K_I = 1.5$）是为了照顾 P、PD、PI、PID 四个方案都可行而定的。如果设计时不管比例微分、比例积分的事，直接就上比例加微分加积分，那么 $K_P$、$K_D$、$K_I$ 三个系数可以任意取值。三个系数取得不一样，那个二阶因式的系数就不一样，两个开环零点在 $s$ 平面当中的位置也就不一样——可以把零点再往左拉，甚至可以拉成两个实数零点，根轨迹就拉得更往左，动态性能改善的余度就会进一步加大。PID 控制的关键就在这里：**根据被控对象的特性来决定 $K_P$、$K_D$、$K_I$ 这三个系数**。

### 附加开环零极点与附加闭环零极点的辨析

针对这个题目再提一个新问题，也是你们联系实验室时要碰到的：实验里要你们通过实验看看附加了开环零极点、附加了闭环零极点以后对系统的影响。这里专门把这两件事辨析一下，机制机理要理解清楚，不要搞糊涂。

#### 附加开环零极点：环节要卡在闭环里边

附加开环零极点时，这个因子要夹在闭环的**里边**。比方说比例加微分那个环节，你要把它卡在闭环里边去，开环传递函数里才会出现那个零点（$-4$ 那个）——这才叫附加开环零点。

引入开环零点有什么用处？把开环零点放在合适的位置，能把整个根轨迹往左边搬，对提高动态性能指标有利。机理是：环节放在闭环里边以后，写特征方程是"分母加分子"，它就影响特征方程，根就不一样了——原来根轨迹那么走，现在变成这么走，闭环极点就改变了。

附加开环极点同样要加在闭环里边。比如在闭环里放一个惯性环节 $\dfrac{1}{\tau s + 1}$，开环传递函数就多了这个因子，相当于多了一个开环极点——多了一个叉叉。附加开环极点以后，根轨迹有一种**向右边搬**的趋势。当然我们特别注重右边，因为右边靠虚轴近，是主导极点所在的那部分，往右边搬了对提高系统动态性能指标是不利的。

> **结论**：不管是附加开环零点还是附加开环极点，环节都要加在闭环的里边，让开环零极点出现在开环传递函数当中——它们都会改变根轨迹的形状、影响闭环根的位置。一般来讲，附加开环零点能把根轨迹向左搬，对提高动态性能有利；附加开环极点使根轨迹向右偏，对提高动态性能不利。

#### 附加闭环零极点：环节要加在闭环外边

这件事前面讲过：第三章结束的时候用过这么一个图形。一个测速反馈的一型二阶典型闭环系统（小闭环），要在这个基础上附加一个闭环零点，需要在闭环的**外边**加一个环节（一阶微分 $\tau s + 1$）。写这个系统的闭环传递函数时，它直接乘在闭环的分子上，成为闭环的一阶复合微分——这就是附加的闭环零点。

用第三章讲过的曲线叠加方法分析：附加了闭环零点以后，使原来系统的超调量变大，峰值时间靠前。而且要注意：附加闭环零点**不会改变**原来系统内部的闭环零极点分布。

附加闭环极点也是在小闭环的外边加一个惯性环节，它乘在闭环传递函数的分母上，就是附加的闭环极点。它的作用恰好和附加闭环零点相反：使系统的超调量减小，峰值时间向后靠。

> **易错点**：连接方式记住一句话——**附加开环的时候加在闭环里面，附加闭环的时候加在闭环的外边**。实验室预习时把这个弄清楚，接系统的时候千万别接错。实验四特别要考这个：附加开环零极点和附加闭环零极点是什么概念，不要弄混。

顺带交代根轨迹法的定位：根轨迹法和时域法、频域法并列，是进行系统分析和校正的三大分析方法之一。分析我们一直在做——把指标算出来；但校正这本教材没有展开写，因为用根轨迹法可以校正的事情，一定可以用频率法来校正，而且用频率法校正更便捷一些，所以校正放到后面的频率响应法去讲。下面只用一个例子看看，用根轨迹法去校正用的是什么思路。

### 用根轨迹做校正：一个例子的完整思路

系统开环零极点是 $0$ 和 $-3.5$，根轨迹增益 $K^*$ 从零到无穷大可以调整。要求：超调量在 16.3% 附近，调节时间在 1 秒附近，允许小幅变化但不要变化太多。如果不加校正装置、直接调 $K^*$ 能满足要求就行；如果调 $K^*$ 还达不到，就要设计串联校正装置的传递函数，让原本达不到指标的系统能达标。这就是校正问题——反过来提出指标，叫你改造系统的结构和参数。

先把系统当成典型欠阻尼二阶系统去设计：由典型二阶系统的超调量、调节时间计算公式反解，满足这个动态指标的闭环极点，阻尼比 $\zeta = 0.5$，无阻尼自然频率 $\omega_n = 7$（调节时间 $3.5/(\zeta\omega_n) = 1$ 秒）。据此把期望闭环极点在 $s$ 平面中的位置定出来。

然后检查：原系统开环零极点是 $0$ 和 $-3.5$，根轨迹画出来——不过这个点。也就是说，调整 $K^*$ 不论怎么调，都不可能把闭环极点调到这个位置上，因为这个点**不满足相角条件**。单独调 $K^*$ 这件事是做不成的。

怎么办？加校正装置，引入它带进来的开环零极点，使这个点满足相角条件、落在根轨迹上。做相角核算：从期望点到极点 $0$ 的矢量夹角是 $120°$，到极点 $-3.5$ 的夹角是 $90°$，加起来 $210°$，比 $(2k+1)180°$ 还多了 $30°$。理论上，引入一个开环零点，让它贡献 $-30°$ 就行了——纯微分（一阶复合微分）就能做到。但一阶复合微分的分子阶数高，物理上不好实现，找电路不好搭。为了好实现，做一个 $\dfrac{s-z}{s-p}$ 形式的环节，分子分母阶数一样高了，用电阻电容就可以搭起来。

于是要找一对开环零极点，使附加的相角凑出 $30°$。设零点 $z = -5$，从零点引向期望点的角度就定下来了；再找一个极点 $p$，利用三角形的外角定理——外角等于与它不相邻的两个内角之和——零点角减极点角刚好 $30°$ 时，期望点就满足相角条件了。有同学问：凭啥定 $-5$？定 $-6$ 或者别的行不行？可以。甚至最简单的方法是把零点压在原来某个极点上直接对消掉一个，再让新极点落在剩下两个极点的垂直平分线上，根轨迹就过期望点了——这也是一个方法。这里不去对消，留有余地：取 $z = -5$，解出极点对应的角度是 $46°$，$p = -9.3$。校正装置的传递函数就写出来了。

问题解决了吧？还有问题。原来做这件事是把它当成典型欠阻尼二阶系统放进去设计的，现在加上校正装置以后成了**三阶系统**，而且那个附加的零点是前向通道的零点、同时又是闭环零点——多了一个闭环零点，和典型二阶系统不是一回事了，**必须校验**。

具体算：$K^* = 57$ 时闭环极点落在设计的那个位置，第三个闭环极点用根之和定出来；闭环零点按"前向通道的零点加反馈通道的极点"找——单反馈、反馈通道没有极点，但那个开环零点 $-5$ 同时也是闭环零点。零极点都齐了。这两个离主导极点足够近吗？不好说，稳妥起见把所有零极点都带进去，用零点极点法（或者用计算机）去算：超调量 21.4%，调节时间 0.76 秒。调节时间没问题，但超调量比原来预计的 16.3% 大了——为什么大了？因为附加的那个零点距离虚轴比较近。

没达标就再调整。当 $K^* = 57$ 时闭环极点在那个位置；把 $K^*$ 往小调，两个主导极点沿根轨迹往回退——$\beta$ 角变小了，有利于超调量减小；但往回退的同时离虚轴近了，调节时间会适当拉长。不过现在是 0.76 秒，距离 1 秒还有余地。所以把 $K^*$ 减小一点试试看。这个校正过程，有时就是要试着去调整。逐渐调整，把 $K^*$ 从 57 调到 40 时，最后算出来超调量 15%、调节时间 0.94 秒，和指标要求吻合了。最终把校正装置的传递函数定下来，$K^*$ 定成 40，而不是 57。

> **结论**：最终目的不是说你把闭环极点放在当初设计的那个理想位置，而是使动态性能指标达标——达标了就 OK。

这个例子说完了根轨迹法进行校正的思想，校正的事情不展开去说了。

### 第四章收束：从模型到指标的完整链条

到现在为止，第四章的内容完了。第四章是最短的一章，学起来是最容易的。回顾一下：第四章只讲了系统的根轨迹法**分析**，没有讲校正——校正的事情，用后面的频率响应法去做就可以了，做起来要方便得多。

什么叫分析？从模型把稳、准、快三项指标计算出来，系统分析就完成了。从数学模型的角度讲，我们有系统的结构图，可以拿出闭环传递函数，可以拿出根轨迹方程；根轨迹方程取模、取相角，分别对应模值条件和相角条件。

**快**的问题（超调量、调节时间）是重头。把闭环所有的极点、所有的零点找出来：先依据八条法则、根据开环传递函数把根轨迹画出来；画出来以后，依据题目要求的条件，把闭环极点的位置定出来——相角条件、模值条件、根之和、比较系数法等等，你有什么方法就用什么方法，把根轨迹上满足条件那个闭环极点的位置定出来。极点全部落实了，记住还有闭环零点：闭环零点等于前向通道的开环零点加反馈通道的开环极点。把所有零极点全部放上 $s$ 平面，保留主导零极点，用零点极点法，动态性能指标的事情就搞定了。

**稳**的问题不需要专门去讨论：只要把根轨迹画出来，系统稳定性的问题就已经明了了。

**准**的问题（稳态误差计算）根轨迹法没有直接去讨论，借用时域分析法——第三章当中讲的静态误差系数法。用静态误差系数法，要知道系统的开环增益 $K$ 和系统型别 $V$，这两样直接从开环零极点分布上读出来：你画开环零极点分布的时候，$s$ 平面原点上画了几个叉叉，$V$ 就是几；定闭环极点的时候不是要确定那个闭环极点对应的 $K^*$ 值吗，$K^*$ 的值有了，开环增益 $K$ 相应也就定了。输入信号形式如果知道，那张 $3 \times 3$ 表格一查，稳态误差就有了。

根轨迹法从模型到指标，就是通过根轨迹的绘制这么倒过来的。第四章这么厚的一章，现在变成半张纸。

最后是作业：下去通过作业，不要嫌作业多——根轨迹法学起来要过一个坎儿，这个坎儿就是通过根轨迹的绘制把法则运用熟练，一直到把根轨迹画出来；这个坎儿过去了，剩下的就是把用根轨迹分析系统性能这个事情掌握住。实验三、实验四大家下去了解，特别是实验四：附加开环零极点和附加闭环零极点是什么概念，不要弄混。
