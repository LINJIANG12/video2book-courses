# 硬件工程师入门教程（零基础全免费）

面向零基础的硬件工程师入门课程，127 集把「会看电路图」到「能独立画一块能工作的板子」这条路径走通。前段按欧姆定律、电阻分压限流、电容储能与滤波、电感感抗与 LC 滤波把无源元件讲透，中段进入二极管整流钳位、三极管与 MOS 管开关电路、比较器与运放的虚短虚断、差分放大与电流采样、恒流源与线性稳压，后段落到开关电源拓扑与电荷泵、纯硬件循迹小车整机电路设计，以及 PCB 封装绘制、器件布局与铺铜。

- **原视频**：https://www.bilibili.com/video/BV1gHSyY3E6q — Bilibili，BV1gHSyY3E6q
- **127 集**，已产出 4 册模块全书、12 篇复习笔记、26 份逐字稿

## 怎么学

- **安全第一** → 模块 01 从设计安全要点和电阻基础开始，硬件入门最容易出事的是上电瞬间，务必先建立安全习惯
- **无源元件打地基** → 模块 01、02 前半讲电阻分压限流、电容储能延时、电感感抗与高低通滤波，这三样是后面所有滤波与供电电路的零件，理解它们的物理特性比背公式重要
- **开关电路动手算** → 笔记 05、06 讲三极管与 MOS 管开关的耐压与栅极设计，这是电源开关、负载驱动的基础，务必自己把参数代进去算一遍
- **模拟信号调理** → 模块 03 讲比较器、运放虚短虚断、差分放大与电流采样，配合笔记 07、08 把「传感器信号怎么变成 MCU 能采的电压」这条链路打通
- **供电与整机闭环** → 模块 04 从线性稳压到开关电源拓扑与电荷泵，再到循迹小车整机电路，是全课唯一把「设计—制板—调试」串起来的一册，务必动手跟着做一遍
- **落到 PCB** → 笔记 12 讲封装绘制、器件布局与铺铜，硬件能力的分水岭往往就在这一关，`notes/` 里的 12 篇笔记可按元件或按设计阶段两种顺序串读
