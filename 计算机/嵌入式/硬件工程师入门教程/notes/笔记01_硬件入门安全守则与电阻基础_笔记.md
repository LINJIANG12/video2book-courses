# 硬件入门安全守则与电阻基础

## 用电安全边界

* **市电（mains power）**

    * > **定义**：从电站拉进家中的电力，是 220V 交流电。

    * 市电是高压的，有触电危险；完全没接触过电路的人直接去玩，一次失手就可能再也不敢碰电，甚至没机会再碰。

* **电压与电流（voltage / current）**

    * > **定义**：对人体真正构成伤害的是流过身体的电流，电压本身并不构成危害。

    * 火线对大地或对零线都是 220V，只要人体与大地之间没有构成回路，就没有电流流过人体，身上带着电压也是安全的。

    * 老电工站在底部绝缘的金属梯上换灯时同样带着电，安全就来自梯子对大地绝缘；换成金属或铝合金梯子时，底端一般也带绝缘胶。

    * 光脚去扶那把梯子的人是导体，手一摸上去就把师傅断开的那一端接通了，回路闭合，本来安全的两个人都有触电危险。

    * 专业人士作业时不要在旁边多此一举地帮忙，乖乖看着就好；人家不会摔，扶一下反而可能把师傅电下来。

    * > **易错点**：有电压不等于会触电，扶梯子之所以危险，正是因为把别人断开的那一端接通了。

    ```text
       触电时电流在人体里的两条可能路径

       左手 ──▶ 躯干 ──▶ 心脏 ──▶ 右手 ──▶ 另一端的负极    （两手分别摸正负极）
       左手 ──▶ 躯干 ──▶ 心脏 ──▶ 腿脚 ──▶ 大地          （赤脚站在地上）

                            ↑
                 流过心脏 = 最危险
    ```

* **人体安全阈值**

    * > **定义**：交流 36V 是人体的安全电压，交流安全电流 10mA；直流安全电压一般 50V 左右，直流安全电流 50mA 左右。

    * 直流到 50V 都不会有危险，实际入门玩 30V 以下已经完全够用。

    * 高压的犯错成本太高，零基础入门应该只学低压。

* **没有仪器时用身体试探的规矩**

    * 最准确的办法始终是用万用表测电源两端的电压，确认输出是不是设定的值。

    * 只能用身体时只用一个手，不要用两个手：两个手分别摸正负极，电流会从左手经躯干、经心脏回到右手；赤脚站在地上时则经腿脚回大地，流过心脏最危险。

    * 用手背去碰：手一旦触电就会收缩，直接抓握会把导线握死在手里甩不掉，手背触碰则会缩回来。

    * 尽量用右手：人的心脏偏左，左手触碰时回流电流更可能流经心脏，右手相对好一点点。

    * > **结论**：电路小白第一次接触电路就不要碰 220V，老老实实买一台直流稳压电源玩 30V 以下。

## 直流稳压电源（DC regulated power supply）

* > **定义**：把 220V 高压交流市电转换成一个低压直流电的仪器，是零基础入门的第一件工具。

* 入门选型：一两百块的型号基本都能用，直流电压范围选 0 到 30V 即可，市面上型号很多。

* 0 到 30V 的直流电压对人体没有危害：输出 5V 时两个手随便摸不会出事，调到 30V 再摸同样没有危险。

* > **注意**：上手直接用手摸电源是错误示范。正经买回来的机器不要这样试，万一台面做得不好会有风险，接触前应该用万用表确认实际输出电压。

## 万用表（multimeter）

* > **定义**：可测电阻值、电压、电流、电容的便携仪器，一些高级的还能测电感和温度。

* **档位与表笔**

    * 电阻档有很多档位，只需挪到比待测阻值大的那一档：测 10Ω 就拧到 200 的位置，这表示可测 200 以下的阻值。

    * 电阻档位选太小会超量程，选太大则白白浪费读数精度。

    * COM 是参考端，一般接黑色表笔。

    * 三个孔里有两个标 mA 和 20A，主要用来测电流；旁边那个标有 V、Ω、电容、二极管、蜂鸣器、温度符号的孔，测电阻、电容、二极管时红表笔插这里。

    * 直接把表笔夹到元件两端就能读数，10Ω 电阻读出来约等于 10Ω。

* **测电流**

    * 表笔插到 mA 这一侧，该侧还有 20A 档以及毫安档、微安档。

    * 档位调到比实际电流大一点的那一档：算出约 100mA 就调 200mA 档。

    * 不知道工作电流时直接调到最大的 20A 档先测，发现结果非常小再换到较小的档位。

    * 测电流时表笔必须与被测电阻**串联**进去，电流必须穿过万用表才测得到。

    * 接线顺序：电源正极 → 电阻一端 → 电阻另一端 → 红表笔 → 万用表内部电流检测电路 → 黑表笔 → 电源负极。

    * 上电前一定要把档位打回直流电流档，直流电流档和交流电流档选错就测不准。

    * > **提示**：只有当被测电阻远大于万用表内阻时，读数才接近真值，这是非理想仪器带来的测量误差，与元件本身的偏差是两码事。

## 欧姆定律（Ohm's law）

* > **定义**：电阻两端的电压等于流过电阻的电流乘以电阻值。

    $$U = I \times R$$

* 两个反推形式：

    $$R = \frac{U}{I}, \qquad I = \frac{U}{R}$$

* 电路里凡是电阻符号的元件，90% 以上都是靠这一个公式算出来的，它是所有电路公式里用得最多的。

* **真实电路的量级**

    * > **提示**：一定要抛开初中在书本上学到的量级。

    * 课本典型算例：220V 电压配 1Ω 电阻，算出电流 220A。

    * 实际做控制电路，电阻一般是千欧级别，也就是 1000Ω 以上。

    * 实际常见的直流电压：24V、15V、12V、5V、3.3V、2.5V、1.8V、0.85V。

    * 实际电流非常小：5V 经 1kΩ 得到 0.005A，也就是 5mA。

* **实测对不上理论时**

    * 10Ω 电阻加 1V，理论电流 $1\text{V}/10\Omega = 0.1\text{A}$，直流稳压电源却显示 0.095A，小了 5mA。

    * 仪器显示值本身就可能不准，不能直接采信，要用万用表交叉验证。

    * 万用表实测阻值 9.9Ω，1V 除以 9.9Ω 应该约等于 0.1A；但接上万用表后电流只有 77mA，因为万用表内部也有几欧电阻，把回路总阻值抬高了。

    * > **结论**：测试结果与理论不符时要思考是哪些东西让总阻值变大了，这个分析思路比记住结论本身更重要。

## 元件的非理想性（tolerance）

* > **定义**：所有元器件都是非理想的，买多少都不等于实际就是多少，总会有偏差。

* 标称 10Ω 的电阻实测可能是 9.9Ω，也可能是 10.1Ω。

* 处在关键位置、参与参数配置或放大电路的电阻，阻值上一点点的偏差就可能决定检测结果准不准。

* 精度按场景选，不要一味买高精度：精度要求不高的场景买 5% 或 10% 即可，要求高的买 1%、0.1% 甚至 0.01%。

* 偏差越小的电阻越贵，不同电阻种类的偏差大小也不一样。

## 阻值的读法

* **色环电阻（color code resistor）**

    * > **定义**：插件直插电阻，用若干道色环把阻值大小和精度印在本体上。

    * 分四色环和五色环两种：四色环的前三环读阻值、最后一环表示精度；五色环的前四环读阻值、最后一环表示精度。

    * 判读方法：读数用的几个色环彼此挨得很近，精度环与读数色环之间的间距明显更大，间距大的那一环就是误差环。

    * 从误差环往回数的那一环是乘数环，乘数就是 $10^n$；再往前的几个环拼起来构成前面的数值。

    * 读数规则：

        $$R = \text{前面拼出的数值} \times 10^n$$

    * 常用颜色对应数值：黑 0、棕 1、红 2、黄 4、紫 7，金对应 0.1 即 $10^{-1}$。

    * 五色环实例：4704，前面三位是 470，乘数环是黄色 4，即 $470 \times 10^4 = 4700000 = 4.7\text{M}\Omega$。

    * 四色环实例：红红黑，$22 \times 10^0 = 22\Omega$，任何数值的 0 次方都等于 1。

    * 实物实例：棕黑黑金棕，棕色是 1，两个黑是 0，前三位拼成 100，金色乘数为 0.1，$100 \times 10^{-1} = 10\Omega$。

* **贴片电阻（SMD resistor）**

    * > **定义**：直接贴在板面上的电阻，用数字或字母把阻值标在表面。

    * 整数型一般有三位数或四位数，不管几位，**最后一位代表 $10^n$**，前面直接照抄下来。

    * 三位数实例：103 → $10 \times 10^3 = 10\text{k}\Omega$。

    * 四位数实例：1003 → $100 \times 10^3 = 100\text{k}\Omega$，位数越多精度越高，算法完全一样。

    * 带小数的用电阻代码中的字母 `R` 表示小数点：5R6 就是 5.6Ω；30R9 就是 30.9Ω；R 前面没有数字表示整数部分为 0。

    * 还有一类用字母而不是数字表示的高精度电阻，遇到直接去网上搜字母代码，对照表查阅即可。

    * 焊接或检修电路时只看表面数值就能定阻值，这个技能对调试很实用。

## 电阻的功率（power rating）

* **功率公式**

    * > **定义**：电阻消耗的功率等于电流乘以电阻两端的电压。

    * 三个等价写法：

        $$P = I^2 R \qquad\qquad P = \frac{U^2}{R}$$

    * 三种写法由欧姆定律互换得到，只要知道电压、电流、电阻中的任意两个就能算出功率。

    * 进入具体电路后，电压或电流总有一个是已知数，另一个需要推出来，而这两者在电路里都很容易获得。

    * > **结论**：算出来的损耗功率一定不能超过电阻的额定功率，超过就发热，一旦过热就可能烧掉。

* **10Ω 电阻实测**

    * 标称 10Ω、额定 $1/4\text{W}$ 的电阻加 $5\text{V}$，功率为 $5^2/10 = 2.5\text{W}$。

    * $1/4\text{W}$ 换成小数是 0.25W，实际损耗是额定功率的十倍，超了十倍烧掉是正常现象，不坏才不正常。

    * 接上的一瞬间就冒烟并发光，表面镀的蓝色膜全部脱落，内部缠绕在基体上的金属薄膜裸露出来——这层金属薄膜才是电阻真正起作用的部分。

    * 把电压提到 10V，一接上去立刻冒烟发光，电流随即变成 0，原因是发热太大已经把内部金属薄膜烧断了。

    * 超额定功率不一定会立刻死掉，发热会变得非常严重。

    * 换成同为 10Ω、额定 $2\text{W}$ 的电阻同样加 $5\text{V}$，不再冒烟，电流表显示 0.5A。

    * 热成像显示温度已飙到 150 多度并持续上升，170 多度时接近平衡，估计最终平衡在 200 度左右。

    * > **注意**：超了功率的电阻即使没坏、还在持续工作，温度也高到可以熔锡、点蚊香。每一颗电阻、每一个元器件都有自己的额定功率，实际工作中超了真的会坏。

## 电阻的限流作用

* **限流（current limiting）**

    * > **定义**：利用电阻限制电荷移动的特性，阻止电路中流过过大的电流。

    * 电阻"限制电荷移动"这个字面含义本身就是限流的物理来源。

    * 典型场景：负载工作电压低于电源电压又没法降压。常见 LED 工作电压一般在 1.8V 到 3V 之间，个别低到 1.6V；若手上只有 3.3V 电源，供电电压就大于负载工作电压，直接接上负载大概率会坏。

* **一颗 LED 的拧电压记录**

    * LED 分正负，**长的脚是正，短的脚是负**，这一条必须记住。

    * 1.4V 接上就能亮；1.7V 已经比较亮；1.9V 是正常亮度且亮得很璀璨。

    * 接到 3.3V 时远看仍然璀璨，但在实际电路里已经能看见它在慢慢变暗，此时还没坏。

    * 3.6V 到 3.9V 远看变化不明显，凑近看确实在变暗；4.4V 到 5V 实际已经很暗，但远处看着还是很亮。

    * 一路加到八点多伏，灯突然之间灭掉，说明电压大得太多，直接烧坏了。

    * > **结论**：供电电压大于负载工作电压时负载是会坏的；正常两伏左右时给 3V 或 3.3V 可能不至于直接坏，大得比较多就一下子灭掉。

* **限流电阻的计算**

    * 电阻按欧姆定律 $R = \frac{U}{I}$ 计算，要先把电阻两端的电压和流过电阻的电流分析出来。

    * ⚠️

      > **易错点**：这里的 $U$ 是**电阻两端的电压**，不是电源电压，初学者常搞混“两端的电压”到底指什么——它就是一个元器件两边之间的电压。

    * 同一个串联回路里所有元器件上的电压加起来等于电源电压：

        $$V_{CC} = V_R + V_{LED}$$

    * 于是电阻两端电压为：

        $$V_R = V_{CC} - V_{LED}$$

    * 示例：电源 3.3V，LED 导通压降按 2V 计，$V_R = 3.3 - 2 = 1.3\text{V}$。

    * 单位不用老实换算，直接用数值做除法、再把结果定成对应单位即可：

    | 电压 ÷ 电流 | 得到的电阻单位 |
    | :--- | :--- |
    | $\text{V} \div \text{A}$ | $\Omega$ |
    | $\text{V} \div \text{mA}$ | $\text{k}\Omega$ |
    | $\text{V} \div \mu\text{A}$ | $\text{M}\Omega$ |

    * $1.3\text{V}$ 除以 $5\text{mA}$，直接 $1.3 \div 5 = 0.26\text{k}\Omega$，与换算成 0.005A 再算出的 260Ω 完全一样。

    * 另一个例子：8V 减去二极管 2V 得 6V，$6 \div 5 = 1.2\text{k}\Omega$。

    | 电源电压 | 负载导通压降 | 电阻两端电压 | 期望电流 | 限流电阻 |
    | :--- | :--- | :--- | :--- | :--- |
    | $3.3\text{V}$ | $2\text{V}$ | $1.3\text{V}$ | $5\text{mA}$ | $260\ \Omega$ |
    | $8\text{V}$ | $2\text{V}$ | $6\text{V}$ | $5\text{mA}$ | $1.2\text{k}\Omega$ |

    * 电阻上的压降把电流限制住，LED 的 2V 之外的电压由电阻分担掉，这本身就是分压，只不过当时没用"分压"这个词。

* **限流回路**

    ```text
           +V_CC = 3.3 V
                 │
           ┌─────┴─────┐
           │           │
          [R]        |>|  LED
           │           │   V_LED ≈ 2 V
           │           │
           └─────┬─────┘
                 │  ← 这一段是 V_R = V_CC − V_LED
                GND

       V_R + V_LED = V_CC   →   V_R = 3.3 − 2 = 1.3 V
    ```

* **实物验证**

    * 没有 $1.2\text{k}\Omega$ 时可以取最接近的 $1.5\text{k}\Omega$，因为实际生产的电阻值不会那么理想，厂家不会正好给你做一个 1.2 出来。

    * 绿色 LED 不串电阻直接接 8.3V，闪了一下就再也不亮了，降回 2V 也不亮，说明已经烧掉。

    * 把烧掉的 LED 和 1.5kΩ 接在一起慢慢拧高电压，拧到 3.1V 还没亮，因为电阻有压降把电流限制住了。

    * 继续拧到 8.3V，LED 不再烧坏，这就是电阻最基础的限流作用。

    * > **提示**：拿电阻限流是最不划算的方式，因为有一半功率被白白消耗掉；最正确的做法是用一个电源把电压降到负载需要的那一档再供电，损耗才最小，那已经属于开关电源的范畴。

## 电阻的分流作用

* **单颗电阻限流的代价**

    * 场景切换到电机：正常工作电压 5V、工作电流 500mA，和 LED 的区别就是电流大得多，单颗电阻限流时电阻上的电流同样是 0.5A，这对电阻已经算大电流。

    * 电源 10V、电机 5V 时，剩下的 5V 全落在那颗电阻上，$P = 5\text{V} \times 0.5\text{A} = 2.5\text{W}$。

    * 电机直接接 10V 会散出金属的焦味，长时间这样接电机本身也会烧掉。

    * 串上一颗 10Ω 后电机确实正常了，但小功率电阻在冒烟——限流做到了，代价是电阻先坏掉。

    * 换成 2W 电阻不会烧但依然很烫；既不希望发烫又要限流，就得改走并联分流。

* **并联分流（current sharing）**

    * > **定义**：把总电流摊到多条并联支路上，让每颗电阻分到的电流变小。

    * 并联有个非常好用的性质：同一支路上所有电阻两端的电压都相等，不管并几只，每颗电阻两端电压都还是 5V，一点没变。

    * 变的是电流：并得越多，每颗电阻上流过的电流越小；电压不变、电流变小，$P = U \times I$ 自然就降下来了。

    * 并联电路中电流的具体走向与数值分配如下。

    ```text
           +10 V
             │
         ┌──┬────┼────┬──┐
         │  │    │    │  │
      [100Ω][100Ω][100Ω]  ... [100Ω]   共 10 颗并联
         │  │    │    │  │              等效 100 ÷ 10 = 10 Ω
         └──┴────┼────┴──┘
             │
             ├──►  (M)  500 mA 电机
             │
            GND

       总电流 0.5 A 被均分 → 每颗电阻只过 0.05 A
       每颗电阻上的电压仍是 5 V → 每颗的 P = 5 V × 0.05 A = 0.25 W  ✔ 不烧
    ```

    * ⚠️

      > **易错点**：并联之后的结果不能发生变化。限流电阻总耗能 2.5W、等效阻值 10Ω，那这 10 颗并起来必须等于 10Ω；直接拿 10 颗 10Ω 并联只会得到 1Ω，根本限制不住电流。

    * 正确做法是用 10 颗 100Ω、额定 0.25W 的电阻并联。

    * 实测结果：10 颗 100Ω 并联接电机，电机温度达到 62 度，电阻温度三十多度，不再冒烟烧掉，但摸上去仍然发热。

    * 手头只有小功率电阻却必须用电阻限流时，就只能用小电阻并联来接上去。

    * 功率较大、负载工作电压又低于电源电压的场景经常要算这套分流公式。

## 电阻的分压功能

* **两条思路**

    * 思路一 · 并联分流：电压不变、电流摊薄，靠降低单颗电阻的损耗功率来扛住大电流。

    * 思路二 · 串联分压：并联这条路走不通时（比如根本凑不出 100Ω 或凑不够 10 只），电流就被锁死在 0.5A 改不动，此时只剩电压这一个变量可调。

    * $I$ 动不了就要求 $P < 0.25\text{W}$，办法是在电机这条路上串更多电阻，把电压压到足够小。

    * 在电机路上串 10 只 1Ω 就是 10Ω，5V 由这 10 只电阻一起分掉，每只只剩 0.5V，功率自然小于额定值。

    ```text
       思路二 · 串联分压

          电源 ── 电机 ──[R1]─[R2]─[R3]─ … ─[R10]── GND

          I 锁死 = 0.5A，5V 由 10 只电阻一起分掉，每只只剩 0.5V
    ```

    * 这两条思路的最终目的只有一个：让电机正常工作，不被电流烧掉。

* **做参考电压的分压**

    * > **定义**：两只电阻串联时，中间点的电压必然小于对应的电源电压，取阻值不同分到的电压也不同。

    * VCC 为 5V、上面 1kΩ、下面 1kΩ 时，中间点变成 2.5V，这就是分压的结果。

    * 完整式：

        $$V_R = V_1 - \frac{V_1 - V_2}{R_1 + R_2}\times R_1$$

    * 课本式 $V_R = V_1 \times \frac{R_2}{R_1 + R_2}$ 只在底部接成 GND、也就是 $V_2 = 0\text{V}$ 时成立——此时 $V_1 - 0$ 还是 $V_1$，$V_2$ 那部分直接化简掉了。

    * ⚠️

      > **易错点**：$V_2$ 不为 0 时照搬课本简化式会算错，必须用完整式；分母是 $R_1 + R_2$，不要少写一个 $R_2$。

    * 仿真验算：$V_1 = 10\text{V}$、$V_2 = 2\text{V}$、$R_1 = 1\text{k}\Omega$、$R_2 = 2\text{k}\Omega$，中间点电压为 **7.3333V**。

    * 手算核对：串联通路电流 $I = \frac{10 - 2}{1\text{k} + 2\text{k}} = 2.6667\text{mA}$，流过 $R_1$ 的压降是 $2.6667\text{mA} \times 1\text{k}\Omega = 2.6667\text{V}$，中间点即 $10 - 2.6667 = 7.3333\text{V}$，与仿真一致。

    * 把 $R_1$ 改成 10kΩ，中间点变成 **3.3333V**，仿真与表格公式同样一致。

    * 电阻分压除了给后级电路做防护，还经常被拿来直接做参考电压。

## 电容（capacitor）

* **结构**

    * > **定义**：两块互不连通的导体，加上中间的绝缘材料，就构成了电容最基本的两极结构。

    ```text
          ┌──────┐         ┌──────┐
    引脚 ─┤ 导体 ├─────────┤ 导体 ├─ 引脚
          │  A   │ 绝缘介质 │  B   │
          └──────┘         └──────┘
    ```

    * 人本身是导体，旁边坐着的人也是导体，两人之间的绝缘材料就是空气，所以人与人之间其实也是一个电容，只是容量太小而被习惯性忽略。

    * 空气也是一种材质，这一点很多人会直接忽略掉。

    * 实际电路中的电容有具体容量，控制容量只有两条路：控制中间绝缘材料的材质，以及控制两个导体之间的相对面积大小。

    * 拆开一只电解电容，外壳只是电容的一件衣服，真正干活的是套在外壳里面的部分。

    * 里面能拆出两块导体，一块在底面，分别连到两个引脚；中间看到的纸不是普通报纸，是浸泡在电解液和电介质上的特殊绝缘材料，表面光滑就是被介质材料浸泡过的结果。

* **极性与耐压**

    * > **定义**：电解电容分正负极，外壳上有一条灰色条纹、灰色那一侧对应的引脚是负极，引脚上长的是正极、短的是负极。

    * > **注意**：电解电容的正负极不能接反，接反了会炸，电解电容正极端的电压不能比负极端的电压低。

    * 实验用的是 $100\ \mu\text{F}$、25V 耐压的电解电容，反接长脚到负极、短脚到正极。

    * 电压 5.3V 时还没炸：电压比较低的时候不会直接坏掉，长时间工作在反向电压下会经过一段比较漫长的时间慢慢损坏，但反向电压比较高时可能一下子就炸。

    * 电压慢慢调高，电流持续变大，外壳摸上去至少有四五十度，温度升高到某个程度就炸了。

    * 爆炸的真正原因是内部发生化学反应产生气体，气体膨胀之后把电解电容撑开。

    * 合格品的防爆阀在顶部，只会在防爆纹的位置炸开，外壳留在原地；外壳整个跳出来说明这只电容质量较差，如果电路板对着自己就可能把人烫伤。

    * 正着接但超过额定耐压同样会炸：标 25V 的电容升到 40 多伏时电流慢慢上升，最后短路。

    * 准备爆炸时电流会自己慢慢增大，电流出现一次跳变就说明快要炸了；厂家留有余量，不一定到 25V 立刻炸。

    * > **结论**：上电之前一定要保证两件事——电容没有反接，电路中的电压不会超过电容的额定耐压。

    * 数量级提醒：$100\ \mu\text{F}$ 炸出来的效果已经像鞭炮，用到 $1\text{mF}$ 甚至 $1\text{F}$ 时威力更不可轻视。

    * 做这类实验要盖上保护罩再打开电源，通电时不要把电路板对着自己，宁可对着地面或天花板，调试电路时也尽量戴防护面罩或头盔。

* **常见类型的脾气**

    * CBB 电容没有方向，两端任意接都可以，耐压可以做得很高，高频特性也相对比较好。

    * 固态电解电容用高分子材料，温度特性比液体电解电容好很多。

    * 最常见的贴片电容是陶瓷电容，MLCC 的特点是 **ESR 非常低**，瞬态电流能力相对较大。

    * 决定高频特性的主要还是 **ESL**；贴片电容的 ESR 和 ESL 都低，所以高频特性才好。

    * 液体电解电容的寿命比较差，因为电解液会挥发，温度越高挥发越快；温度越高寿命越短，衰减曲线掉得非常快。

    * 温度特性上电解电容非常一般，贴片电容的温度特性也比较差，但也有材料不错的类型。

    * 容量、DC 偏置电压、体积这些参数，不同电容类型差别明显。

    * 选型要先了解器件的工作特性再选，方向错了怎么选也选不到合适的：要高电压加大容量就不会选 MLCC，因为它体积就这么一点点、容量本来就上不去，这种需求对应的是电解电容。

* **容量不能突变**

    * > **定义**：电容两端电压不能突变，具体指 A 电极相对于 B 电极的电压不会发生突变。

    * 突变指开关一闭合，中间点电压瞬间从 0V 变成 2.5V，上升过程没有任何延时。

    * 把上面电路中的一个电阻换成电容，同样闭合开关，中间点电压不会一下子升上去，而是慢慢爬升，就不具备突变特性了。

    ```text
       【会突变】开关 + 两个电阻分压

              5V
               │
            [ 开关 ]
               │
               ●──────────── 中间点，电压 = 2.5V
               │
           [ R1 1kΩ ]
               │
           [ R2 1kΩ ]
               │
              GND


       【不突变】把上面的 R1 换成一只电容

              5V
               │
            [ 开关 ]
               │
               ●──────────── 中间点，电压缓慢爬升
               │
            [ 电容 C ]
               │
           [ R2 1kΩ ]
               │
              GND
    ```

    * 原因是改变电容两端的相对电压必须给它充电或放电，充电放电肯定需要时间，需要时间就不可能突变。

    * ⚠️

      > **易错点**：不能突变的是**相对电压**，电容两端的电压是可以同时突变的。

    * 实际电路中电容电压一般是与电路参考地比较，而不是自己的两个电极互比；参考点（如图中的 B 点）本身一旦突然跳变，电容另一端也会跟着突然跳变。

    ```text
                        5V
                         │
                 ┌───────┼───────┐
                 │       │       │
                S2      S3      GND
                 │       │
                 ●───────●───────┤
                A 点    B 点    │
                 │               │
              [ 电容 C ]         │
                 │               │
                 └───────────────┘

         S2 闭合：5V 接到 A 点，电容开始充电
         S3 闭合：5V 接到 B 点，B 点跳变把 A 点抬起来
    ```

    * S2 闭合的一瞬间：电容一开始是空的，两端电压等于 0V，A 点直接跟 5V 短路，A 从 0V 突跳到 5V；因为两端电压可以同时突变，B 点也在这瞬间从 0V 升到 5V。

    * 随后是充电：A 点被 5V 短路锁死一直等于 5V，能变化的只有 B 点，它从 5V 慢慢下降到 0V，两端压差充满到 5V。

    * 断开 S2、闭合 S3 后：5V 短路到 B 点，B 点突然变成 5V；若 A 点不动两端压差就变成 0 了，所以 A 点必须跟着往上抬 5V，这一点的电压变成 **10V**。

    * 示波器实测一致：绿线 A 点在闭合瞬间跳上去、然后慢慢下降；黄线 B 点稳在 3V，把电源正极接到 B 点的瞬间跟着跳一下，拿开就掉下来。

    * 测量细节：两个通道档位不一样时曲线看起来像短接在一起，把绿色通道也调到 2V 一格就清楚了。

    * 储能、滤波、耦合、旁路这些功能看起来很多，但归根结底都源于电容两端电压不能突变这一条。
