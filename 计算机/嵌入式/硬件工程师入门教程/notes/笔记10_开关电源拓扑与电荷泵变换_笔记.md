# 开关电源拓扑与电荷泵变换

## 升压为什么必须靠电感

* **只靠开关与电容升不了压**

    * 一个 5V 电路里只放一个开关再加一个电容，开关一闭合，输出端顶多也就等于一个 5V。
    * 除非堆好几个开关、好几个电容靠电容的自举去升压，理论上能，但那个过程相当复杂。

* **电感的突变特性**

    * > **定义**：电感上的电流不能突变，但它两端的电压可以突变。
    * 就这一条就足够了：电路里放一个电感加一个开关，开关闭合时电流开始流过电感蓄能。
    * 把开关突然断开，电感两端就会产生一个比电源高很多的电压。
    * 既然电感能自己把自己顶上去，升压就成立，关键问题只剩怎么把电感的能量收下来。

* **后级储能器件的作用**

    * 后级再加一个储能器件，比如一个电容，用来收下电感释放的能量。
    * 刚上电时输出是 0V，电源也当作是 0V，开关闭合后 5V 就给电感蓄能。
    * 蓄满了突然把开关断开，断开的一瞬间电感电流还是从左往右走，开关没了这股电流就一股脑灌到后级。

## 台阶式升压机制

* **电感无视后级电压强行放电**

    * 不加电感时输出电容最多只能充到 5V。
    * 加了电感之后，电感在释放自己能量的过程中根本不管你后级现在是 5V 还是 10V。
    * 只要它身上还有能量，比如开关闭合时已经给电感充到了 1A，开关一断开它就会把这一整个 1A 的电流强制性地全部倒到后级去。

* **输出电容电压的来源**

    * 后级电容的电压按 $V = \frac{Q}{C}$ 算。
    * 电感强制性地把一大堆电荷放到后级电容上，$Q$ 上升而 $C$ 不变，$V$ 肯定往上走。
    * 输出电容每被充一次就上升一个台阶，开关闭合一步、断开一步，输出就往上爬一格。

    ```text
    输出电压
      │            ┌───┐        ┌───┐        ┌───┐
      │            │   │        │   │        │   │
      │      ┌───┐ │   │  ┌───┐ │   │  ┌───┐ │   │
      │      │   │ │   │  │   │ │   │  │   │ │   │
      └──────┴───┘─┴───┘──┴───┘─┴───┘──┴───┘─┴───┘──→ 时间
             断    合     断    合     断    合
    ```

## 续流二极管为什么非加不可

* **不加二极管的死循环**

    * 电感每次蓄能都得把开关闭合，而这一闭合会把电容辛辛苦苦在上一周期存下来的能量又释放掉。
    * 每给电感充一次能，下次充能时又顺手把电容的能量放掉一次，等于白干。
    * 必须保证的是：开关闭合的时候这个电容不能被释放能量。

* **加二极管之后的工作时序**

    * 开关闭合时电源给电感蓄能，二极管此时反偏截止，输出电容靠 Vin 侧维持电压。
    * 蓄满了断开，电感强制给后级充电，电流方向来不及改变只能继续左→右，于是通过二极管灌进输出电容，把它抬高一个台阶。
    * 等下一次开关闭合，因为输出点被拉回 0V，二极管就处在反向截止状态，不会再往后级倒能量。
    * 至此一个升压开关电源最基本的拓扑结构就齐了：电容、二极管、开关，再加一个电感。

* **基本拓扑的连接关系**

    ```text
            S               D
    Vin ──o/ o──── L ──────|>|────┬──── Vout
     │                            │
     │                            C
     │                            │
    GND                           GND
    ```

## 仿真里的 Boost 行为

* **必须加载荷**

    * 把负载去掉直接仿真，一上电它就会一路冲到很高的电压去，那就没意思了。
    * 加上负载重新跑，刚上电时电源给后级充电，充满之后输出稳定在 12V 左右。

* **开关动作与输出台阶**

    * 开关闭合时电感电流开始升高，断开时输出电压又上升一个台阶。
    * 断开时间拖得太长时升得非常猛，快速断开就能看到连续的台阶。
    * 闭合、断开、闭合、断开不停地按，输出是一个台阶一个台阶慢慢往上爬。

* **闭环维持输出电压**

    * 在回路里加一个 $1\ \Omega$ 的电阻把电流限制一下，等输出电压先稳住。
    * 闭合断开升一个台阶，再闭合再断开又升一个台阶。
    * 想让输出变成 10V 就不停地这么控制：升到 10V 后电容慢慢放电到 10V 以下，再闭合断开一次又保持在 10V 左右。
    * 只要不停地控制这个开关，输出就会一直维持在约 10V，这是利用电感电流不能突变的特性做出的升压。

## 电感饱和电流的选取

* **饱和电流的取值规则**

    * > **结论**：饱和电流一定要大于电路中理论电流的最大值。
    * 算出来电感的峰值电流是 10A 时，饱和电流一般至少取 1.2 倍也就是 12A，取成 1.5 倍更稳。
    * 取不够就会让电感在工作过程中饱和。

* **饱和意味着电感退化成导线**

    * 电感一旦饱和就不能当成电感来看待了，只能把它当成一根导线。
    * 它的抑制电流上升、缓慢变化的效果完全无效，电流会"唰"一下上升得非常非常快。
    * 实际后果是开关很容易被烧掉、电感发热非常严重、电源也有可能被直接拉死。

* **未饱和时电流变化率是可以算出来的**

    * 电感抑制电流上升的公式是 $V = L \frac{\mathrm{d}i}{\mathrm{d}t}$，换一下就知道 $\frac{\Delta i}{\Delta t} = \frac{V}{L}$。
    * 严格说前面还有个负号，但把它去掉不管；电感正常工作时两端电压 $V$ 不变、电感量 $L$ 也不变，电流变化率就是一定的。
    * 具体数值：加一个 5V，开关闭合后电感两端电压等于 5V，电感是 $10\ \mu\text{H}$ 时电流变化率是 $\frac{5}{10\ \mu\text{H}}$，也就是 $0.5\ \text{A}/\mu\text{s}$。
    * 仿真实测：测 $1\ \mu\text{s}$ 的时间，波形上掉了 500mV，这 500mV 对应的就是 0.5A。
    * 所以只要电感没饱和，它两端的电压就能通过这个公式算出电流的变化率。

* > **易错点**：⚠️ 选开关电源电感时饱和电流必须留足余量。饱和不是精度差一点，而是电感直接退化成导线、电流失去限制。

## 电荷泵升压

* **三个开关加一个电容**

    * 电荷泵这种电源既能升压也能产生负压，工作原理其实比 Boost 更简单。
    * 后级要 10V 而电源只有 5V 时，用一个储电容加一组开关来实现。
    * A、B 两个开关闭合给电容充电，电容被充到 5V，充完之后把这两个开关断开。

* **第三个开关完成电平搬移**

    * 在电容底端再加多一个开关 C。
    * C 一闭合，以其中一点作为参考点是 5V，而电容两端的电压不能突变，那顶端的电压就变成 10V。
    * 顶端直接带一个负载到 GND，这个负载就得到 10V，三个开关加一个电容升压过程就搞定了。

* **升压结果不能直接用**

    * 电容需要持续充电就得把 C 断开、把 A、B 合上，而 A、B 一闭合负载上的电压就从 10V 掉到了 5V。
    * 等 C 再次闭合才又回到 10V，负载额定工作电压就在充电过程中往下掉，这肯定不正常。
    * 总不能跟负载说电容在充电的时候你先别工作、等我充满了你再继续，这不可能。
    * > **提示**：凡是用电容两端电压不能突变造出来的电压，中间都必然夹着一次切换动作；凡是切换，就是电压塌陷的来源。

* **加二极管与输出电容隔离塌陷**

    * 解决办法是加一个二极管、再加一个电容，然后由输出电容去给负载供电。
    * 这一级电路的作用和 Boost 的续流二极管非常相似。
    * A、B 闭合把电容充到 5V，A、B 断开、C 闭合出现 10V，电源就通过这条路径给输出电容充电。
    * 经过多个周期，输出电容每周期高一点、高一点，最终上升到 10V 左右的电压。
    * 由于存在二极管压降，实际会停在 9.7V 左右。
    * 带载时电容储能期间电压会往下掉一点点，只要储能速度足够快，每个开关周期都会给电容提供一部分能量，掉下去一点点很快又上来，反复如此。

* **电荷泵升压的仿真参数与波形**

    * 把电感都删掉只需要几个开关，电容加大到 100 微法。
    * 先不加二极管，直接带一个 100 欧姆的负载，拿示波器看这一点的电压。
    * 还没开始充电时输出等于零，开始充电变成 5V，再切换变成 10V 然后慢慢往下掉；再充电变 5V，再释放变 10V 又慢慢往下降。
    * 这就清楚地看到它确实能升到 10V，但就是在开关充电的时候往下掉，所以要给它加一个二极管再加一个电容。
    * 这时候再仿真，只要不停地开关，输出就约等于 9V 多并一直在跳变，这就是自举升压。

## 电荷泵产生负压

* **负压的接法**

    * 还是从一个 5V 电源出发，先用两个开关 A 和 B 给电容充电。
    * A、B 一闭合，电容充到的是一个上正下负的 5V，也就是上极板比下极板高 5V，充完一样把这两个开关断开。
    * 升压是把 C 开关加到电容的底端；产生负压反过来，只要在 GND 那一支加多一个开关，接到电容的顶端。

* **负压的产生过程**

    * C 开关闭合时，电容下极板这一点的电位就变成零。
    * 下极板这一点比零还要小 5V，那上极板就变成 $-5\text{V}$，负压就这么出来了。

* **负压同样不能直接给负载**

    * 因为开关在切换的过程中电位会发生变化，产生负压后不能直接给负载供电。
    * 解决办法一样：加一个二极管，再加一个电容，然后在这里给负载供电。
    * 这样就能得到一个约等于 $-5\text{V}$ 的电压去给负载供电。
    * 仿真验证：把开关切换一下，二极管换方向，地挪到上面，然后测这一点的电压；点仿真再切一下开关就出现一个负压，不停地切就能看到一个负 4 点多伏的电压。

* > **结论**：电荷泵的升压与负压是同一个电路的两种接法。A、B 负责给储电容充上固定的 5V 压差，第三个开关负责把其中一端顶到 5V（得正压）或钉到 GND（得负压），二极管加输出电容负责把切换时的塌陷挡在负载之外。

## 纯硬件循迹小车的差速原理

* **四步项目流程**

    * 第一步讲工作原理，第二步手把手设计完整原理图并算参数选器件，第三步做 PCB 设计把板子做出来，第四步完成实物调试。
    * 之所以选它做第一个项目，是因为看课的同学基本都是学硬件的、可能对单片机不了解，所以做一个不需要单片机编程的循迹小车。

* **差速是核心原理**

    * 板子底部有两对红外，每一对里一个是用 LED 发射红外光的，一个是用红外接收管接收红外光的。
    * 两对红外一起发射、一起接收，起到的作用就一件事：检测黑线。

* **直行工况**

    * 沿黑线走时两边红外发射管所对应的区域都是白色区域。
    * 白色可以反射所有光谱的光，红外光从下面对准纸面射出去，因为纸面是白的就反射回来被红外接收管接收到。
    * 接收管一收到就自然产生一个控制信号去控制电机转动。
    * 两个发射管打的都是白区、两个接收管都有信号，所以两个车轮一起转，小车就一直往前走。

* **拐弯工况**

    * 走到拐弯处，底部的黑线碰到了左边这个红外发射管。
    * 黑色可以吸收所有的光，左边发射管发出去的红外光就反射不回来了，左边接收管收不到信号，左轮就停。
    * 左边一停，右边发射管还没进入黑色区域，右边接收管照样收得到红外，右轮继续转。
    * 左边不转右边转就有了差速，一差速就实现拐弯，一拐就拐到线对应的方向上去。
    * 拐到一定角度之后左边红外管又会脱离黑色区域，于是又可以继续前进，循迹由此闭合。

* > **易错点**：⚠️ 两个红外管天然是互补的一对，只要有一只进黑区两只的输出就不一样，小车就能分辨出线往哪边偏，所以传感器不需要做任何调制或算法，纯粹靠白反射、黑吸收这条物理规律就够了。

## 电机驱动原理图的搭建

* **工程与库的准备工作**

    * 点文件 → 新建选项目，命名为 `car`，下面对应路径自己新建一个文件夹，点击新建后项目树里就多出一个新的项目文件夹。
    * 项目文件夹只是一个框架，接着要点右键 `Car-1` → 添加新的到工程，往里面添加一个原理图。
    * 原理图封装简单来说就像原理图里的小工具：把整张原理图看成一栋房子，画房子时上面有很多小零件，这些小零件需要一个库就叫原理图库。
    * 所以第一步要把原理图库添加进来，在原理图上点右键用添加已有文档到工程。
    * 里面已经提前画好了一些 PCB 的原理图库和 PCB 库，添加进来之后要把原理图保存好，保存完才能开始画电路。

* **单向电机只需要控制是否接电**

    * 小车的目的很单纯：用红外管检测小车到底到了黑线区域没有，到了让电机停，没到让电机动。
    * 整个循迹小车的工作逻辑就两步，检测黑线，然后根据黑线去控制电机。
    * 因为电机是单向工作的、不需要双方向工作，所以控制一个电机旋转只需要控制它是否接电。
    * 拿一个开关去控制电机的电流，开关闭合电机动，不闭合电机不动，电路里三极管和 MOS 管都可以。

* **器件选择与放置**

    * 三极管用一个 NPN 的就行，NPN 里有个比较经典的型号就是 8050。
    * 操作是点右键 → 组件 → 选择自己的原理图库，直接搜索 `SS` 会出现很多相关元器件，其中 `SS8050` 对应的是一个 8050 的三极管。
    * 三极管底部挂有封装信息，有些元器件里面挂了很多个封装，需要做一次选择。
    * 因为板子是直接贴在车子的结构上面的，不能用插件元器件，插件是有引脚的，焊接时要像 LED 一样插过去焊，会把板子顶起来不能平放，所以要选焊接不需要穿孔的贴片型封装。

* **电机在原理图上的表示**

    * 电机不用画在原理图上，因为它要通过两根线焊接在板子上，板子上只需要留两个孔去焊电机的两根电源线。
    * 这两个孔就是排针，原理图里一般就是 `Header`，`Header 2` 就代表这里有两个洞，封装就是两个洞。
    * 电机上面直接接电源，点右键 → 放置电源端口，把电源命名成 `Vin` 并连起来，三极管底部放一个 `GND` 端口。
    * 这样放完，一个最简单的电机开关控制电路就画好了。

    ```text
                  Motor
            ┌────(     )────┐
            │               │
            │               │
       Vin ─┴──────┐        │
                   │        │
                 C │      [Header 2]
                   │        │
                   └────┬───┘
                        │ E
                  Q1    │
              (NPN 8050)│
                        │
                       GND
    ```

    * 读图：`Motor` 是要焊在 `Header 2` 两根线上的实物，原理图上并不画它只留两个孔。
    * 三极管 `Q1`（NPN 8050）串在电机回路里当开关用，基极给电流通路打开电机转，基极不给电电机停。
