# MOS 管开关电路与电源开关设计

## 热释红外传感器

* **热释红外传感器（Passive Infrared Sensor，PIR）**

    * > **定义**：一块会对入射红外感生出微弱电压 $V_p$ 的热电材料，材料内部再集成一级放大（三极管或 MOS 管），放大后从两端引出可直接送进比较器的信号。

    * 这个电压非常微弱，微弱到必须放大才能用，所以放大这一级是集成在传感器内部的。

    * 红外信号照进热电材料 → 材料两端感生微弱电压 $V_p$ → 内部 MOS 管或三极管放大 → 两端输出放大后的电压信号。

* **放大器件按输入信号性质选**

    * 三极管是电流控制器件，必须先有 $I_B$ 基极电流才会产生 $I_C$，没有 $I_B$ 根本不工作。

    * 热电材料感生出来的是电压信号而不是电流信号，而电压信号恰好是 MOS 管的食物——它只要 $G$ 极上有电压就行，压根不需要电流。

    * > **结论**：输入是电压就配电压控制器件，输入是电流才考虑电流控制器件。

* **上拉电阻与输出电平**

    * 在传感器输出点挂一个上拉电阻接到 $V_{CC}$，把这一点引出来当输出。

    * 无红外进来：MOS 管截止，相当于断开，那一点不会掉电，$V_{out} = V_{CC}$（高电平）。

    * 有红外进来：材料感生出电压把 MOS 管导通，电流 $I$ 流过电阻产生压降 $V_R = I \times R$，这一点电压等于 $V_{CC} - V_R$（低电平）。

    * > **结论**：人体感应灯整个"感知"环节最后落成一句话——让人靠近时输出电压变低。

    * 这个逻辑和红外接收二极管模块一致，都是"有信号时输出被拉低"，区别是一个靠光电材料导通产生光电流，一个靠热电材料感生电压去导通 MOS 管。

* **比较器定门限**

    * 规矩：同相端 $V_+$ 高于反相端 $V_-$ 输出高，反了输出低。

    * 有人＝低电平、无人＝高电平，所以 $V_{ref}$ 必须夹在两个状态之间。例：无人 $V_{in} = V_{CC} = 5V$，有人 $V_{in} = V_{CC} - IR = 3V$，取 $V_{ref} = 4V$ 正好落在中间。

    * $5V > 4V$ → 输出高（无人）；$3V < 4V$ → 输出低（有人）。

    * > **易错点**：$V_{ref}$ 一定要设在两个电平之间。如果它比 $V_{CC}$ 还高，那无论有没有人输出都一样，灯永远只会有一个状态。

    * 只改比较器两个输入端的接法就能换驱动管，传感器信号一个字节都不用改：接法一把 $V_{ref}$ 送到 $V_-$、$V_{in}$ 送到 $V_+$ 输出高，配 PMOS（5V 进 S、漏极出 LED 到 GND）；接法二把 $V_{ref}$ 送到 $V_+$、$V_{in}$ 送到 $V_-$ 输出高，配 NMOS（GND 进 S、漏极出 LED 到 GND）。

    * 两种接法殊途同归，都是有人才亮，不要去纠结哪个更标准。

    * 整个模块的骨架是四块：热释红外传感器 → 比较器 + $V_{ref}$ → 驱动管 P/N → LED + 限流。

* **PIR 的识别限制**

    * 热释红外只能识别移动的发热物体，静止不动的东西识别不了，这是传感器内部的基本特性。

    * 实物现象：站在模块前灯是灭的，手划过去灯立刻亮，手走开灯灭；手停住不动灯就灭，手一晃又亮。

    * > **结论**：静止的发热物体不算"有人经过"。想让人站着不动灯也亮，得换 PIR 模块上带菲涅尔透镜的版本。

## 光控灯

* **光敏电阻（Light Dependent Resistor，LDR）**

    * 阻值 $R$ 跟环境亮度有关，是跟亮度有关最常见的器件。

| 类型 | 亮度升高时 | 特点 |
| :--- | :--- | :--- |
| 正亮度型 | 阻值**变大** | 越亮越"堵" |
| 反亮度型 | 阻值**变小** | 越亮越"通" |

    * 常用的是反亮度型。

    * > **注意**：型号不同特性相反，买之前先看手册。这一步选错，后面全错。

* **分压加比较器**

    * 电路骨架和人体感应灯一模一样：一个分压产生 $V_{in}$，一个比较器做判断，一个三极管当电子开关。

    * 电子开关这一步因为只讲过三极管，用的是 N 管：高电平导通 LED 亮，低电平断开 LED 灭。

    * 分压取固定电阻 $R_1 = 10\ \text{k}\Omega$ 在上、光敏电阻在下接地、中点取出 $V_{in}$，$V_{ref} = 2.5V$ 由两个电阻分压产生，中点电压 $V_{in} = 5 \times \dfrac{R_{LDR}}{R_1 + R_{LDR}}$。

    * 环境非常暗：光敏电阻约 11k，$V_{in} \approx 2.6V > 2.5V$ → $V_+ > V_-$ → 输出高 → 三极管导通 → LED 亮。

    * 环境非常亮：光敏电阻很小，取 1k，$V_{in} \approx 0.45V < 2.5V$ → 输出低 → 三极管断开 → LED 不亮。

    * 实物：正对着一个比较亮的环境上电灯不亮，用手遮住灯立刻亮，手松开又灭，一挡一亮一放一灭。

    * 把红外接收模块、温控风扇模块、人体感应灯、光控灯这些常见电路模块都动手做一遍，比看十遍电路图有用。

## MOS 管的结构

* **MOS 管（Metal-Oxide-Semiconductor Field Effect Transistor）**

    * > **定义**：由 $G$（栅极）、$S$（源极）、$D$（漏极）加底部那块衬底（substrate）四大部分组成，三个电极都长在衬底上，衬底可以理解成它的底盘。

    * 栅极与下方沟道之间隔着氧化层 $SiO_2$ 绝缘体，$G$-$S$、$G$-$D$、$S$-$D$ 三对之间都隔着氧化层，两两都不导通。

* **两两绝缘与三个寄生电容**

    * 四大部分在默认状态下两两都是绝缘的，因为结构上那些位置就是绝缘材料（氧化层）。

    * $G$ 是导体、$S$ 是导体，中间绝缘——两块不连通的导体之间就是一个电容；$GD$ 之间同理，$SD$ 之间也同理。

    * > **结论**：$G$、$S$、$D$ 三个电极两两之间都有一个寄生电容。这是绝缘结构带来的，不是设计者故意加的。

* **掺杂类型与寄生体二极管**

    * 增强型 NMOS：源极和漏极掺杂的半导体材料一般是 N 型，衬底一般是 P 型。

    * 每一处 N 与 P 之间都隔着绝缘层，每个这样的结构就是一个 PN 结，而只要是 PN 结就相当于一个二极管。

    * 所以这个结构里漏极与衬底之间有一个二极管，源极与衬底之间也有一个二极管。

    * 常见 MOS 管在芯片内部用一根导线把源极与衬底短接（符号上中间那条接到 $S$ 极的线就是在表示这件事），一短接，衬底与源极之间的二极管就被短路掉了，所以拿到手的管子 $S$ 与衬底之间看不到二极管。

    * 衬底与漏极之间的二极管没有被短路，它还在。既然 $S$ 和衬底直接短路，那么 $S$ 与 $D$ 之间等效就又多了一个二极管。

    * > **结论**：常见 NMOS 符号里 $S$ 极与 $D$ 极之间多画的那个二极管不是谁画错了，而是结构决定的。

    * PMOS 的掺杂完全对调：衬底是 N 型半导体，$S$ 和 $D$ 是 P 型。所以寄生电容与 NMOS 一样，唯一的区别是体二极管方向反过来。

| 项目 | NMOS（N 沟道增强型） | PMOS（P 沟道增强型） |
| :--- | :--- | :--- |
| 衬底掺杂 | P 型半导体 | N 型半导体 |
| $S$、$D$ 掺杂 | N 型半导体 | P 型半导体 |
| 体二极管方向 | 源 $\rightarrow$ 漏 | 漏 $\rightarrow$ 源 |
| 体二极管阳极／阴极 | 阳极在 $S$，阴极在 $D$ | 阳极在 $D$，阴极在 $S$ |

    * 衬底类型一调换，P 和 N 的位置跟着调换，PN 结的方向自然就反过来。

    * > **结论**：NMOS 与 PMOS 的结构几乎镜像对称，唯一需要额外记住的就是体二极管指向相反。

    * 符号上对应衬底的那根箭头、连到 $S$ 极的那条线，表示的就是"衬底跟源极在芯片内部短接在一起"。

## 导通条件

$$V_{GS} > V_{TH}\ (\mathrm{NMOS}), \qquad V_{GS} < V_{TH}\ (\mathrm{PMOS})$$

* **NMOS 导通条件**

    * 判定式：$V_{GS} > V_{TH}$，即 $V_G$ 比 $V_S$ 大、大过大过 MOS 管的导通电压时 $D$、$S$ 之间导通，否则断开。

    * 例：NMOS 的饱和导通压降 $V_{TH(SAT)}$ 等于 2V，$S$ 极已接 GND 所以 $V_S = 0V$，导通条件简化成 $V_G > 2V$。$G$ 极接 5V 的 $V_{CC}$，5V 大于 2V，$DS$ 闭合，LED 导通点亮。

* **PMOS 导通条件**

    * 判定式：$V_{GS} < V_{TH}$，即 $G$ 极电压比 $S$ 极电压小、小到低于导通电压值时 $DS$ 导通。

    * 例：$S$ 接 5V，下面接电阻加 LED，$V_{TH} = 2V$，那么 $G$ 极电压比 $S$ 极低 2V 以上时（比如 $G$ 变成 3V）就满足导通条件，$DS$ 闭合，电流下来 LED 亮。

* **$V_{TH}$ 为什么是负值**

    * $V_{TH}$ 实际上就是 $V_G$ 减去 $V_S$。PMOS 的导通条件要求 $V_G$ 比 $V_S$ 要小，一减自然是负的。比如 $V_S = 5V$、$V_G = 2V$，$V_G - V_S = -3V$。

    * > **易错点**：PMOS 管的 $V_{TH}$ 在数据手册里通常是一个负值，看到负压不要觉得很奇怪。

    * > **结论**：所谓负压只表示"$G$ 极电压比 $S$ 极电压要小"这一件事，它是一个相对量，不代表电源真的接反了。

## 用 MOS 管替换三极管做开关

* **电压控制与电流控制的分水岭**

    * 三极管是电流控制电流的器件，只有 $I_B$ 基极电流时才会产生 $I_C$。

    * MOS 管是电压控制电流型的器件，$GS$ 之间导通时没有电流，因为三个引脚两两绝缘，加没加电、导没导通那里都不会有电流流过。

    * MOS 管只看一件事：只要 $V_G$ 比 $V_S$ 大到大过导通压降，$DS$ 就导通。

* **照搬规则**

    * > **结论**：MOS 开关电路的设计方法跟三极管一模一样，把一堆东西直接等效搬过来——$D$ 对应 $C$，$S$ 对应 $E$，$G$ 这一边也加个电阻。

    * 原 N 型三极管电路：发射极接地；集电极上面接电阻再接一个 LED 接 5V；基极接一个高电平，开关闭合 $C$、$E$ 之间导通 LED 亮。

    * 换成 NMOS 同样如此：$S$ 极接地；$D$ 极上面接电阻再接 LED 接 5V；$G$ 极这边也加一个电阻。

    * NMOS 验算：开关闭合后 5V 经电阻到达 $G$ 极，$V_G = 5V$，$V_S = 0V$，$V_{GS} = V_G - V_S = 5V - 0V = 5V$。取 $V_{TH} = 2V$，$5V > 2V$，$DS$ 导通，LED 亮。

    * PMOS 照搬 P 型三极管：默认 $S$ 极等于 5V，$G$ 极加一个电阻再接开关到 GND。开关闭合 $V_G = 0V$，$0 - 5 = -5V$，取 $V_{TH} = -2V$，$-5V < -2V$ 满足导通条件，$S$、$D$ 闭合，有电流下来 LED 亮。

    * 两栏的电源、限流电阻、LED 接法完全一致，差别只有 $S$ 端接电源还是接地、$G$ 端用高电平还是低电平驱动。

    * > **提示**：$S$ 极接电源还是接地，取决于用 N 型还是 P 型。NMOS 的 $S$ 接地，PMOS 的 $S$ 接电源，一一对应。

    * 实物上 MOS 管的形状跟三极管一模一样，这不是什么巧合，是芯片封装的问题——封装就是芯片的衣服，内部芯片是什么不用管，只要这衣服穿得上，它就可能以任何意想不到的形式出现。

    * 实物演示：接上电源和 GND，上电灯不亮；把 $G$ 极接到 $V_{CC}$ 灯亮，手一放开灯暗。

* **G 极要不要串电阻**

    * > **易错点**：MOS 管的 $G$ 极控制时实际上可以不串限流电阻，三极管的基极必须串。这是两者最重要的区别之一，记住这一条就够了。

    * 原因一：MOS 管是电压控制的，只要电压过来就行，不靠电流驱动。

    * 原因二：MOS 内部本身就是绝缘结构，不加电阻去限流也没问题。

    * 三极管这边绝对不行，$BE$ 之间本身就是一个二极管，直接用 5V 怼上去一瞬间就坏掉。

    * 也正因为如此才说 MOS 管是电压控制型、三极管是电流控制型。

* **低功耗器件的基础**

    * > **结论**：低功耗＝关掉了不漏电。MOS 管三个引脚两两绝缘，导通也不例外，它开着的时候自己几乎不耗电，天生适合当"关着几乎不耗电的开关"，所以低功耗芯片内部清一色用 MOS 管结构。

## 寄生电容

* **开关断了灯却还亮**

    * 电路：+5V 经开关直接串进 $G$ 极，$D$ 接负载 LED，$S$ 接地。开关闭合 $V_G = 5V$、$V_S = 0$，$V_{GS} = 5V$，$V_{TH} = 2V$，必然导通，LED 亮。

    * 开关断开后：$G$ 极和 $S$ 极之间是绝缘的，寄生电容没有地方放电，上面的开关断了、下面是绝缘的，它就攥着一口 5V 不撒手，于是 $V_{GS}$ 依旧是 5V，MOS 管依旧导通，灯依旧亮着。

    * 仿真里一颗电容都不用画，MOS 管模型本身已经把内部的电容集成进去了，现象照样出现。

    * $G$ 极电压在慢慢往下掉：断开瞬间 4.94V，过一会儿 4.93V，再过一会儿还在往下掉，最终还是会关掉，只是关得很晚。

    * 之所以会掉：没有任何元器件能做到 100% 绝缘，绝缘材料在两端加了电压之后多少都会有一点漏电流，寄生电容就是靠这点漏电慢慢放掉的，只不过过程很漫长。

    * 实物：MOS 管加一颗灯，手一点上去灯亮，手一松灯不是立刻灭而是慢慢暗下去；再点一次再松一次，还是慢慢灭。

    * > **提示**：有些 MOS 管的漏电特性相当好，不给它放电回路的话，开关断开之后能持续导通十几秒，这个现象是实际遇到过的。

    * 对照实验：把 MOS 管换成三极管，同样点上去、松开，手一走开灯立刻就灭了——三极管自身会消耗基极电流，驱动电流一撤，基区储存的电荷很快就被消耗掉，动作干脆利落；而 MOS 管的控制信号就是那口寄生电容上的电压，一旦没有放电路径它就死死攥着不放。

    * > **结论**：MOS 管不是一颗"干净的"开关，不能想当然地觉得"MOS 管就是个电子开关，跟三极管设计电路一样"。

* **给寄生电容留一条放电的路**

    * 办法：在 $G$ 极和 $S$ 极之间并一个电阻，给寄生电容提供一条放电路径。信号撤掉时电荷顺着电阻快速跑光，MOS 管就能立刻关断。

    * 实物：往 $G$、$S$ 之间直接缠一个 $100\ \text{k}\Omega$ 的电阻，再做同样的点开-松开动作，灯是"啪"一下灭的，慢慢变暗的场景没有了。

    * 电阻为什么取 $100\ \text{k}\Omega$ 这么大——其一损耗：电阻接在 $G$-$S$ 之间，只要开关闭合这颗电阻上就一直在分压、一直在耗能，取小了静态功耗吃不消；其二关机速度并不会因此变慢。

    * MOS 管的寄生电容一般是皮法级别，时间常数 $\tau = R \times C$，就算乘上 $100\ \text{k}\Omega$、$C$ 只有 pF 量级，$\tau$ 依然在微秒级，人眼根本反应不过来。

    * > **易错点**：把 $G$-$S$ 电阻取小以求"关得更快"，是白白牺牲静态功耗换一个人类感知不到的差别。

    * 嫌微秒不够快就得换驱动方式，用推挽电路去驱动这颗 MOS 管：拿一颗专用驱动芯片，芯片内部就是两个开关，一个接到 VCC，一个接到 GND，相当于给寄生电容一条"充电腿"和一条"放电腿"，电容被快速灌满、抽干，MOS 管自然快速关断。

    * 三极管那一侧也建议加电阻，除加快关断还有抗干扰作用：不加基极电阻时手一碰上去灯就闪，那是工频在人体上感应出的静电；MOS 管加了 $G$-$S$ 电阻之后同理，这个干扰路径也被掐断了。

## 寄生体二极管

* **方向**

    * MOS 管在 $D$ 和 $S$ 之间天生夹着一个体二极管，NMOS 从源极指向漏极，PMOS 从漏极指向源极。

    * > **易错点**：方向千万别记反，记反了后面所有的分析全得反过来。

* **电源倒灌实例**

    * PMOS 电源开关，导通条件是 $V_{GS}$ 达到 3V（$G$ 极电压比 $S$ 极低的时候 $D$、$S$ 闭合）。$S$ 接一颗 6V 电池，$G$ 由一颗三极管下拉控制。

    * 正常工作逻辑：三极管断开时 $G$ 被 6V 顶住，$V_G = 6V$、$V_S = 6V$，$V_{GS} = 0$，PMOS 断开，负载无电；三极管导通后有电流 $I_C$ 灌下来，$V_G$ 被拉到约 0.3V，$V_{GS} = 6 - 0.3 = 5.7V$ 超过 3V，PMOS 导通，6V 送到负载。

    * 坑在于负载不一定只由这一路电池供电，它可能还接着一路外部电源（外部的 6V 甚至 10V），所以工作逻辑应该是"一识别到外部电源就把开关断开"。

    * 理想情况下 MOS 管一断开电池跟后级再无关系，可体二极管是从负载节点指回电池那一侧的。电池标称 6V，用久了会掉电：掉到 5.5V 时外部 6V 进来，假设体二极管导通压降 0.5V，6V 就顺着体二极管去给电池充电了；万一电池用到 5V，压差 1V 就是一股很大的电流。

    * 仿真量化：电池满电 6V、开关闭合、MOS 管导通时流过约 6mA 给负载供电；电池用到只剩 5V 时断开电池开关、闭合外部开关，示波器上除了 6mA 正常负载电流，还冒出一段安培量级的反向电流（现场读数 -6A）。

    * 这么大的电流往电池里灌，结果只有两种：要么电池坏掉，要么 MOS 管坏掉。

    * > **易错点**：设计完电路再回头把体二极管加进来，重新算一遍"MOS 管断开之后，二极管会对电路造成什么影响"。这一步省不得。

* **调转方向，再串一颗**

    * 办法一：把 MOS 的 $S$、$D$ 对调，同一套连线。体二极管变成从电池指向负载。跑同样的场景：开关闭合电流依旧 6mA 左右；电池掉到 5V、断开电池开关闭合外部开关时没有大电流了，只有 36pA，相当于没有。

    * 方向一调的代价：这颗 PMOS 再也关不断电池对外部的供电。哪怕开关断开，电池依然顺着体二极管给负载供电，达不到完全关断的效果。

    * 办法二：再加一颗 PMOS 反向串接在一起，两个体二极管面对面，$SW1$ 断开时两个同时阻断，两边都不漏，可以利用两个体二极管相互抵消的关系把影响彻底关在门外。

    * 仿真验证：默认断开状态输出没有电压；闭合有电压；再断开这边没有电流、电压约等于 0。电池断开之后闭合外部电源，流过的同样是皮安级别的电流，不会再有反向大电流倒灌。

    * > **结论**：不管设计什么电路，只要用到了 MOS 管，第一步考虑寄生电容，第二步考虑寄生体二极管。还有一条要提前知道——连"用多一颗 MOS 管去关断体二极管"这个方案本身，也是会重新踩到这个坑的。

## NMOS 的 S 极不接地

* **管子把自己掐住**

    * 常规用法 NMOS 的 $S$ 极都接 GND，但半桥（推挽）驱动里上面那颗上管的 $S$ 极没有接 GND。

    * 结论先摆出来：MOS 管不会饱和导通。

    * 推导：控制电压 5V，另一边的电源 4.5V。上电之前所有电压都是 0，$S$ 极也是 0，负载当然不工作。刚接进来的那一瞬间管子还没开通，$V_S = 0V$、$V_G = 5V$，$V_{GS} = 5V$ 大于导通电压，饱和导通。

    * 一饱和导通，4.5V 电源就给负载供上电了，但供电过程中这一点电压是从 0V 慢慢往上升的，不是"啪"一下就到 4.5V。而 $V_G$ 是死的 5V，$V_S$ 一路涨，$V_{GS}$ 就一路掉。

| $V_S$ | $V_{GS} = V_G - V_S$（$V_G = 5V$） | 管子状态 |
| :--- | :--- | :--- |
| 0 V | 5 V | 饱和导通 |
| 1 V | 4 V | 饱和导通 |
| 3 V | 2 V | 临界，恰好等于 $V_{TH}$ |
| 3.001 V | 1.999 V | 掉进放大状态 |

    * 一旦掉进放大状态就不能当开关看了，内部是一个比较大的电阻，电阻产生压降、压降又跟负载分压，这一点电压永远上不去就卡在 3V 附近；它想往上走一点 $V_{GS}$ 就不饱和，电阻又变大——一个自我锁死的循环。

    * 仿真验证：开关闭合输出只有 1.35V，12V 根本过不来，剩下 10.7V 左右全被 MOS 管自己吃掉了，因为它被 $V_{GS}$ 这个导通条件限制死了。

    * 功耗：把负载电阻改成 $10\ \Omega$，一打开电阻上只有 1.3V、流过来的电流约 130mA，130mA 乘上 MOS 管上那 10V 左右的压降，损耗已经有一瓦多，肯定发热。

    * > **结论**：NMOS 当开关用的时候，只要 $S$ 极没接 GND，就极容易掉进放大状态，也就是非饱和导通状态。

* **思路一：把 G 极顶到负载电源之上**

    * 不管 $S$ 极怎么往上走，只要 $G$ 极始终比它高出导通电压以上就行。

    * 负载电源是 4.5V 时 $G$ 极给 10V，$V_G - V_S$ 无论 $S$ 涨到哪里都还有富余，$V_{GS}$ 依然有 5.5V 压差，稳稳饱和导通，4.5V 全部过来。

    * 实物：板上一颗 NMOS 底下挂负载电阻，$G$-$S$ 之间有颗 $100\ \text{k}\Omega$ 电阻负责快速关断（对阻抗回路没有影响），电池盒三节电池 4.5V。电源从 0V 慢慢上调：4.5V 时负载电阻上确实 4.5V 左右；调到 5V 时只有 3.4V，说明 MOS 管开通压降约 1.5V；调到 6V 是 4.4V，接近了；调到 8V 是 4.8V 左右；之后再怎么调都没用，读数死死停在 4.79V 不动。

    * 这个方案的代价是成本：4.5V 要用一个 8V 去驱动，可电路里不会平白无故冒出 8V，得靠电荷泵或者 Boost 升压电路去产生，不管哪种都是多一颗芯片、多一笔成本。

* **思路二：用自举把驱动源整个抬起来**

    * 利用电容两端电压不能突变这个特性就能实现电压自举，用一个很简单的电路解决 $S$ 极不接地时的误关断问题。

    * 结构：把驱动 $G$ 极那颗 5V 电源的 GND，不要接到电路的地，而是接到 $S$ 极上去。

    * 效果：开关闭合前这一点是 0V，开关闭合后直接变成 11.8V，几乎就是满的 12V（这颗 MOS 管是小功率的，流过大电流时有一点压降，0.1V 左右）；而按原来那样接 $G$ 至少得给到 15V 才行。

    * 原因：把这 5V 电源当成一颗电池，电池正极永远比负极高一个电压。开关一闭合，因为负极接的是 $S$ 极、正极接的是 $G$ 极，$V_{GS}$ 恒等于这 5V。管子导通之后 12V 走到 $S$ 极，$S$ 被抬高，$G$ 相对于电路 GND 也会同步被抬高——底下一抬，顶上也跟着抬。

    * 这就像 MOS 管导通之后 12V 的正极被怼到了 5V 电源的负极上，两颗电源相当于串联了，这一点相对于 GND 会被顶到 17V，而 $V_{GS}$ 依旧稳稳保有 5V 压差。

    * 实物：负极接到 $S$ 极后，想让两端得到 4.7V 不需要 8V，给 2V 以上就够。调到 2V（实测 1.9V）输出是 4.78V，再往上调输出还是 4.78V 一动不动，因为这个电压是加在 $G$-$S$ 两端的，电源怎么变 $G$ 都被自举着一起抬起来。

    * 实际电路里用的是电容而不是电池，典型结构内部一般有几个对应的开关、一个电容、一个自举二极管：几颗开关负责控制 $G$ 极的通断，底部那个回路负责给电容充电，充满之后这颗电容就等价于一颗电池，称为自举电容。

    * > **定义**：自举电路——利用电源自身两端电压不能突变的特性，把驱动源连同它的参考地一起抬高，从而在低电压供电下驱动高侧 NMOS 管的一种电路。

    * > **结论**：NMOS 做电源开关最常用的两条路，要么把 $G$ 极的电压顶上去，要么把整个驱动源自举起来。H 桥那一类上下管交替导通的场合，上面那颗 NMOS 的 $S$ 极永远不接 GND，就更是必须走这两条路之一。

## PMOS 电源开关设计

* **用 PMOS 替掉 NMOS**

    * NMOS 做电源开关时 $S$ 极不接 GND 就要加一堆自举电路，各种各样很麻烦，根子在于 NMOS 的导通条件把它的用法限制死了；直接用一颗 PMOS 把 NMOS 换掉最痛快点。

    * PMOS 天生就有这个优势，它是拿来做电源端开关的：$S$ 极通常就接在电源上，导通条件是 $G$ 极电压比 $S$ 极电压低、低过 $V_{TH}$ 就开通，$S$ 极本来就是整个电路的最高点——这和 NMOS"$S$ 极不接 GND 就麻烦"的处境刚好相反。

    * 接法：$S$ 固定接 +12V，$D$ 往下接负载，唯一的控制信号是 $G$ 极——把它拉低管子就开，不拉它（$G$ 悬空或被外部拉高）管子就关；$G$ 脚下再挂一个下拉电阻 $R_{pd}$ 到 GND。

    * 关键一句话：$S$ 接 12V 是电路里的最高点，只要加一个下拉电阻 $G$ 就变成 0V，比 $S$ 低整整 12V，肯定导通；而一旦导通 12V 该还是 12V，对 $V_{GS}$ 不产生任何影响，电路自己就把自己锁在导通状态了，不需要再去维护一个偏置电压。

    * 所以用了 P 管代替 N 管之后，前面那一堆复杂电路全都不需要了，只需要两个电阻加一个开关。

    * 实际电路里一般很少用机械开关，通常是用三极管或者 MOS 管通过单片机去控制，这也是最常见的一种组合方式。

* **G-S 之间的电阻不能省**

    * 用 P 管的设计原则和 N 管完全一样：必须在 $G$-$S$ 之间加一个电阻，用来释放 $G$-$S$ 极间寄生电容的能量。这一点恒定不变，不管设计的是 PMOS 还是 NMOS，$GS$ 之间一定要加电阻。

| 开关频率 | GS 电阻取值 | 代价 |
| :--- | :--- | :--- |
| 不高，比如 100kHz 以下 | 100k 左右就够 | 损耗小，开关速度一般 |
| 非常高 | 适当减小，比如 10k | 开关速度更高，损耗更大 |

    * > **易错点**：电阻越小开关速度会越高，但损耗会越大。不能为了图"响应快"就把 $GS$ 电阻一路往小压。

* **PMOS 的局限**

    * 在大功率场景 PMOS 没有办法替代 NMOS：PMOS 由于自身工艺的原因，在同等成本、同等级别的工艺下做出来的性能就是没有 NMOS 好。

    * 所以在频率比较高或者电流比较大的场景，都是优先考虑用 NMOS 管的。

* **PMOS 防反接电路**

    * 电路结构：$S$ 接 BAT+（12V），$D$ 接后级 VOUT 经降压电路供 MCU；$R_1$、$R_2$ 在后级输出和地之间串成分压，PMOS 的 $G$ 从中间抽头 node A 取出；$Q_1$ 是 NPN，基极由 MCU 的控制信号驱动，$E$ 接 GND。PMOS 内含体二极管，方向 $S \rightarrow D$。

    * 刚接进来时控制信号还是低电平，$Q_1$ 断开，两个电阻上就没有电流、也就没有压降，$G$ 被拉到和后级同一电位（约 11.3V）。12V 和 11.3V 只差 0.7V，远不够 PMOS 导通所需的 $V_{TH}$，所以 MOS 管不闭合。

    * 电从 12V 先经过寄生体二极管跑到后级来，掉一个二极管压降变成 11.3V；这边电都还没过来，MCU 不工作，三极管肯定断开，MOS 管也就不闭合——这正好是一个天然的"先上电、后控制"的顺序。跑过来的 11.3V 一边给负载供电，一边经降压电路送到 MCU。

    * MCU 工作后写程序让它输出高电平，三极管导通，11.3V 经 $R_1$、$R_2$ 分压到大约 6V 送到 $G$ 极，$V_{GS} \approx 6 - 12 = -6V$ 满足导通条件，MOS 管闭合，体二极管被短路，电压就从 11.3V 变回 12V。

    * 反接（下面是 12V、上面是 0V）时如果没有 MOS 管，相当于 12V 直接接到 MCU 的地，MCU 不能承受反向耐压，直接就烧坏。

    * 加了 MOS 管之后虽然 12V 反接确实会来到 MCU 的地，但要损坏 MCU 或其他负载，前提条件是必须要有电流流过；而电路中实际上不会有电流——三极管不会导通，两个电阻也不会有压降，没有电流形成完整回路，电信号走到这个位置会被寄生体二极管给阻断掉。电源即使反接，对后级也不会有影响。

    * > **易错点**：这道防线其实来自体二极管的方向，而不是来自 MOS 管本身。一旦这个二极管方向装反，防护立刻完全失效。

    * 另一种不需要三极管的电路：那一路直接接地，MOS 管的控制就跟 MCU 没有任何关系，直接给 MCU 供电。12V 一接进来这里立刻变 11.3V，分压成 6V，MOS 管立刻导通把二极管短路掉，电压立刻变成 12V，不需要 MCU 参与控制，同样可以形成防反接效果。

## MOS 管电流的双向性

* **为什么能双向流通**

    * 三极管电流是单向流通的：N 管只能从集电极流向发射极，P 管只能从发射极流向集电极，电流不会反过来。

    * MOS 管的电流可以双向流通。很多资料说 MOS 管电流也是单向流的，实际上不是。

    * 结构原因：$G$ 与半导体之间隔着氧化层，栅极电压不会像 BJT 那样形成直流通路。在 $G$ 极和 $S$ 极之间加正向电压后，$G$ 极会在 $D$ 和 $S$ 之间形成一个沟道，电子可以通过沟道从 $S$ 流向 $D$。

    * 沟道就是一条通道，电子理所当然既可以从 $D$ 流向 $S$，也可以从 $S$ 流向 $D$。

    * > **结论**：只要 MOS 管的 $G$-$S$ 之间满足导通条件，$S$ 和 $D$ 就等于一直接在了一起。它的电流不管从 $S$ 流向 $D$ 还是从 $D$ 流向 $S$，其实都是一样的。

* **把电源掉个头实测**

    * 判断标准很简单：只要 MOS 两端电压约等于 0，就说明它正常导通。

    * 正常接法（上正下负）：稳压电源输出从 0V 慢慢调到 5V，电池盒开关还没打开时 MOS 管处于断开状态，测得 $D$-$S$ 两端电压等于 5V；一闭合就变成 0。

    * 把电源掉个头（负极接 $S$ 端、正极接 $D$ 端），控制电路完全一样：先断开电池盒开关，$V_{GS}$ 等于 0，MOS 管不闭合，电流走体二极管，所以测到 $D$-$S$ 之间有 -0.58V 压降，这就是体二管的压降；开关一打开立刻变 0。

    * 因为 MOS 这里有寄生的体二极管，所以开关即使没打下来，12V 也会经过这个寄生体二极管来供电，即使没开通 MOS 管负载也是有电的；一旦导通，电流就不再经过二极管，而是直接从 MOS 管内部过来。

* **背靠背两颗 MOS 管**

    * 单颗 MOS 管单独用确实存在开关没闭合时也有电流的问题，但在现有基础上再加一个反向的 MOS 管就不一样了。

    * 结构：两只 NMOS 背靠背串在正极与负载之间，$S_1$ 与 $D_2$ 在中间节点短接，各自体内二极管的指向正好相反。

    * 好处：开关不闭合时两个 NMOS 都断开，电流走到第一个二极管那里确实可以通过来，但走到第二个 MOS 管的时候会发现上面的二极管跟下面是面对面的、相互抵消的，电流过不去，实现了电源接成下正上负时电路也不能导通；只有开关一闭合，两个 MOS 管都导通，电流才走过去。

    * 这就是模拟开关芯片常用这种结构的原因：MOS 管电流双向流通的特性正是靠这个用起来的。

    * > **结论**：很多资料和同学都以为 MOS 管电流是单方向流的、总觉得那个二极管在那儿作怪，其实二极管是可以通过加多一个 MOS 管把它给抵消掉的。

    * 结构用途：用在用 MOS 管去代替继电器的场合。继电器的开关本身就是双向导通的，拿单个 MOS 管去代替继电器只能规定电流是一个方向，反方向就会误导通，加了两个之后不会出现这种误导通。

* **仿真数据与串联代价**

    * 搭一个正常电路：单颗 NMOS、1k 电阻、12V 电源，$G$-$S$ 之间接 5V。电流探头串在这一点，万用表看 MOS 两端压降。开关闭合时电流等于 12mA，$D$-$S$ 压降只有 1.183mV，说明肯定已经饱和导通。

    * 把 12V 反过来接，开关处于断开状态时（$G$-$S$ 之间最好再加一个下拉电阻，仿真相对更靠谱），$D$-$S$ 压降变成 0.37V，明显是通过寄生体二极管过来的；一开关闭合又变回 1.183mV。

    * 这样 MOS 管实际上控制不了这个 1k 的供电情况——开关断开的时候它照样有电。

    * 解决办法：直接画一个反向的 MOS 管，跟这颗上下镜像一下放到它上面去，就能解决寄生体二极管的问题。

    * 结果：这两个 MOS 管可以当成一个 MOS 管来看待。开关没闭合时两端电压等于 12V、电流非常非常小；开关一闭合两个 MOS 管都导通，压降是叠加的——每颗实测导通压降 1.183mV，两个加起来变成 2mV 左右。

    * 再把电源掉个头：不管外部电源是下正上负还是上正下负，这两个 MOS 管都是可以控制的；开关都断开时电压都等于 12V 左右，同时闭合时压降一样、电流也是约 12mA。

    * > **结论**：用两个 MOS 管反向地串联在一起，就可以相互把自身体二极管误导通的问题给抵消掉，从而形成一种双向导通的开关。

    * > **易错点**：第一次仿真跑出来有漏电流、MOS 没关掉，是因为两只 MOS 管画成了左右并列（体二极管同向），必须改成上下镜像、真正背靠背串接，方向才是相反的。另外仿真模型太理想，实际电路里还要在这个位置加一个 100k 的电阻才能把漏电流压下去。

## 导通电流与 $V_{GS}$ 的关系

$$I_D = g_m \cdot V_{GS}$$

* **跨导关系**

    * $I_D$ 与 $V_{GS}$ 是有关系的，和三极管 $I_C$ 被 $I_B$ 控制类似，只不过 MOS 管这里是用 $V_{GS}$ 去控制 $I_D$。

    * 电流除以这个电压就是常说的跨导 $g_m$，这个参数其实很少关注，大家知道有这样一个关系就好。

    * 公式的成立条件是 MOS 管必须工作在它的线性区或者放大区。

* **特性曲线上的三个区**

    * $V_{GS}$ 之前 $I_D$ 恒为 0，是截止区，MOS 管一直处于断开状态。

    * 越过 $V_{TH}$ 之后 $I_D$ 就开始有电流了，随着 $V_{GS}$ 慢慢变大，$I_D$ 才慢慢越来越大。

    * 再往上曲线明显变平，趋于饱和；4.5V 之后 $R_{DS(on)}$ 已变化很小。

    * 一般常见的 MOS 管，只要 $V_{GS}$ 大于 4.5V 之后基本就接近达到完全饱和导通的状态；$V_{GS}$ 越高，导通的 $R_{DS(on)}$ 会越小、流过的电流也会稍微变大一些，但变化的程度不会大得特别多。

    * > **结论**：MOS 管不是理想开关。普通机械开关一按就开了、关了就是关了，不会处于某个中间态；而 MOS 管和三极管是有中间态的，开了并不见得就一定达到了完全饱和导通、完全开通的状态。

* **实物从 1.9V 到 2.7V**

    * 电路更简单：只有一个 MOS 管，电池正负极直接接到 $D$-$S$ 之间当电源，$G$-$S$ 之间接直流稳压电源，调电压就改变了 $V_{GS}$ 压差。

    * 测 $I_D$：万用表调到电流挡串联到 $D$-$S$ 回路里，路径是电池正极出发 → 万用表 → MOS 管的 $D$ → $S$ → 电池负极。

    * 输出调到 1V 电流一直是 0，再调到 1.9V、2V 仍然没有电流；把电池开关打开继续往上调，1.8、1.9V 能看到有 10mA 了。

    * > **提示**：这颗管子实际测下来在 1.5V 左右就开通了，但万用表精度比较低，20A 挡位下最小采样精度是 10mA，所以要等到 1.9V 才看得见那个 10mA。

    * 继续把电压增大，1.91V 就一点点往上涨：$V_{GS}$ 从 1.9V 变到 2.7V，电流从 10mA 变成了 170mA。

    * 到 4.5V 左右开始进入完全饱和导通状态，再往上拧 $R_{DS(on)}$ 还会更小，但规律一样：随着 $V_{GS}$ 电压上升 $I_D$ 电流越来越高。

    * > **结论**：MOS 管开了并不一定代表完全开通，一定要让 $V_{GS}$ 达到某一定值，才能处于完全把内部沟道打开的状态，这时候才能流过最大值的电流。

## 耐压与选型

* **耐压为什么有限**

    * > **结论**：所有的半导体所组成的器件，耐压都是有限的。

    * 理想开关断开之后可以承受无穷大的电压，但 MOS 管不是理想开关，即使断开了能承受的电压也是有限的。

    * 开关处于断开状态时，后级的电压（比如 12V）会完完全全叠加在 $D$-$S$ 之间，所以这时候 MOS 管承受的电压就等于 12V。

* **选型余量**

    * 比如有一个 100V 的电源，挑 MOS 管的时候至少要挑一个 150V 以上耐压的。

    * 耐压和电流的余量至少要挑到 1.2 倍以上；对成本要求相对没那么高，余量可以挑到两倍甚至三倍；对成本要求高就尽量靠近最大的工作电压，但至少要留 1.2 倍以上。

* **2N7000 的两个耐压**

    * $D$-$S$ 之间的耐压是 60V，最大耐压等于 60V，意味着 $D$-$S$ 之间的电压尽量不要超过 60V。

    * 测 $V_{DS}$：正常应该在 $G$-$S$ 之间加一个电阻保证它一定不能导通，但这里直接接就行。稳压电源最大输出就是 60V，从 0V 慢慢往上加到 60V，电源已经加到 60V 它也没事，不会出现电流突然变得很大的情况，说明还没击穿。

    * 虽然写的是 60V 的耐压，实际上是能够承受 60V 以上的，厂家一般会留一定的余量，不至于按 60V 就刚好炸。

    * $V_{GS}$ 是要重点关注的地方：大部分 MOS 管 $G$-$S$ 之间的耐压都是 $\pm 20V$ 或 $\pm 30V$，当然有一些特殊工艺的 $G$-$S$ 耐压会高很多。

    * 2N7000 实测：调到 20V 还没击穿，再往上调还没击穿；在 29.6V 的时候已经能看到有 1mA 的电流了，说明 $V_{GS}$ 已开始击穿。实际上可能早在 22V 左右就开始了，只是稳压电源显示不出那个小电流。

    * 继续调大：$V_{GS}$ 之间的漏电流越来越大，32V 时变成 4mA，再大一点 7mA，再大一点 11mA。

    * 如果这个时候及时把电压撤下来，电流又变成 0，说明这时候还没有损坏；此时 $G$-$S$ 之间还有一个 7.2V 的电压，再去测它的 $D$-$S$ 是会响的，说明 MOS 管还是正常的。

    * 但如果继续加：30V 时电流慢慢变大，11mA、15mA、20mA、19mA、24mA、30mA、34mA、41mA，突然之间电流没有了——这个 MOS 管已经完全击穿损坏了。击穿之后没有短路，而是处于一个断路的状态，$G$-$S$ 肯定就不能控制 $D$-$S$ 两端的电压了（比如把电压降下来变成 10V，再测 $D$-$S$ 就不会响了）。

    * > **易错点**：选 MOS 管的时候不要只看它 $D$-$S$ 的耐压很高。有一些 MOS 管 $D$-$S$ 能够达到几百伏甚至上千伏，但是 $D$-$S$ 耐压再高，$G$-$S$ 之间的耐压不一定很高，这两个耐压是不一样的。

    * > **易错点**：$G$-$S$ 之间的电压千万不要大于额定的标称值（常见 $\pm 20V$ 或 $\pm 30V$）。设计时宁可加一颗 $G$-$S$ 下拉电阻保证它可靠关断，也不要让 $G$ 极悬空——悬空时任何一点干扰电压都可能击穿栅氧。
