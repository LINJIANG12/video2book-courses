# 电感特性与高低通滤波电路

## 高通滤波电路的作用

* **高通滤波电路（High-pass filter）**

    * > **定义**：让高频信号通过、衰减低频信号的滤波电路，作用与低通滤波电路正好反过来。

    * 典型场景：有用信号本身就是高频信号，上面却叠着一层低频噪声；噪声一来，高频信号的峰峰值就开始来回抖动、慢慢起伏。

    * 最常见的低频噪声是 50 Hz 的市电工频干扰，多因电源端隔离没做好而叠加到信号上。

    * > **易错点**：这里的高频与低频不是「大于 20 MHz 算高频、低于 2 MHz 算低频」这种绝对概念，而是相对于**本级电路自身截止频率**的相对概念；一切以本级电路的截止频率为参照，不要去套 MHz 那一套。

* **处理低频干扰的两条路**

    * 第一条是从根源上把噪声源处理掉：该隔离的隔离好，该接地共地的做共地，从本质上去掉噪声。

    * 第二条是实在改不了时，在信号后面加一个高通滤波把它滤掉。

    * > **提示**：能治本就别治标。高通只是兜底手段，它会顺带把有用信号的下限也一起抬起来。

* **共模噪声要走共模滤波**

    * 工频干扰有可能以共模噪声的形式出现，这时要用共模滤波方法，不要拿单端高通去对付。

    * 差分输入的两条线各做一路共模高通：两路电容、两路电阻左右对称，原理与单端完全一样。

```text
差分输入的两条线，各做一路共模高通

     C1                        R1
 V1 ──||───●─────────────────/\/\/────┐
          │                            │
 V2 ──||───●─────────────────/\/\/────┤
          │                            │
         GND                           GND
```

## RC 高通电路的结构

* **RC 高通电路**

    * > **定义**：由一个电阻和一个电容串联构成、输出取自电阻两端的高通滤波电路。

    * 结构：电容在前、电阻在后，输出电压取的是**电阻两端**的电压。

    * 原理：电阻两端电压 = 输入信号 − 电容上电压；输出电容时是低通，改成输出这两端就变成高通。

    * 截止频率与 RC 低通完全相同：$f_t = \frac{1}{2\pi RC}$。

    * 取 1 μF 电容配 159 Ω 电阻，截止频率约为 1 kHz。

* **RC 低通与 RC 高通对照**

| 对照项 | RC 低通 | RC 高通 |
| :--- | :--- | :--- |
| 电路结构 | R 和 C | R 和 C |
| R、C 的位置 | R 在前，C 在后 | C 在前，R 在后 |
| 输出取自 | 电容两端 | 电阻两端 |
| 放行的是 | 低频 | 高频 |
| 截止频率公式 | $f_t=\frac{1}{2\pi RC}$ | $f_t=\frac{1}{2\pi RC}$ |

* **两者原理同源**

    * > **结论**：高通滤波与低通滤波的原理一模一样，区别只在于输出取的对象不一样。

```text
RC 低通：R 在前，C 在后，输出取电容两端

   Vin ──/\/\/ R───●─────|| C───── GND
                   │
                  Vout


RC 高通：C 在前，R 在后，输出取电阻两端

   Vin ────|| C───●────/\/\/ R──── GND
                  │
                 Vout
```

## RC 高通的幅度响应

* **0.707 倍判定点**

    * 输入信号频率等于截止频率时，输出等于输入的 0.707 倍——这一点与低通相同。

    * 实测：输入 1 kHz、1 Vpp 时，输出峰峰值约 707 mV。

    * 读数不是精确 707，是因为 159 Ω 加 1 μF 算出的截止频率只是约等于 1 k，加上测量本身也有误差。

* **三个频点的表现**

| 输入频率（截止频率 ≈ 1 kHz） | 输出表现 |
| :--- | :--- |
| 100 Hz | 严重衰减，输出幅值很小 |
| 1 kHz | 约为输入的 0.707 倍（1 Vpp → 707 mVpp） |
| 10 kHz | 幅值约等于输入 |

* **50 Hz 噪声骑在 100 kHz 信号上的效果**

    * 不叠噪声时，100 kHz 的峰峰值从头到尾是一条直线；叠上 50 Hz 之后，整条波形变成缓慢起伏、抖动。

    * 经过高通滤波后，输出那一条重新变平，说明 50 Hz 的低频噪声被衰减掉了。

    * 高通与低通的工作机理都是利用电容的充电速度跟不上输入信号的变化速度，只是高通以电阻为输出端，特性刚好反过来。

## 电感的结构

* **电感（Inductor，L）**

    * > **定义**：一根导线加上一个磁芯材料组合成的器件。

    * 磁芯的作用是增强电感量、控制电感量，使电感能在很小的体积下做到较大的电感量。

    * 实物形态多样：最常见是裸露线圈绕在磁芯上；也有贴片型与屏蔽型，屏蔽型方方正正、带屏蔽罩、底部两个贴片，一般是黑色或灰色。

    * 直接绕的线圈电感量很小；把 10 圈减到三四圈，它依然是电感，电感量可能只剩 $0.3\ \mu\text{H}$；剪成一条线依然还是电感，只是电感非常小。

    * 任何一根导线都具有电感特性；任何一根导线除超导材料外都有阻性，所以可以认为任何一根导线都是**一个很小的电阻加一个很小的电感**。

    * 生活中：电机里有磁芯加线圈，喇叭里有一个大线圈加一块大磁铁——所有由线圈所组成的器件都是电感。

* **电容与电感的结构对称**

| 器件 | 底层结构 | 一句话概括 |
| :--- | :--- | :--- |
| 电容 | 两块不连通的导体 | 所有两块不连通的导体都是一个电容 |
| 电感 | 一根导线加上一个磁芯 | 所有由线圈所组成的器件都是电感 |

* **为什么必须先懂结构**

    * 买到手的是导线而不是理想器件，实际拿到的都带着那么一点点寄生的东西。

    * 了解基本结构与生活形态，是为了后期分析**非理想状态下的一些电感器件和电容器件**。

## 电感的基本特性

* **电流不能突变**

    * > **定义**：流过电感的电流不能突变；由电感组成的所有电路功能，都基于这一条特性。

    * 电容对应的是两端的**电压**不能突变，电路中的全部功能都来源于这一条。

* **纯电阻回路与电感回路对照**

    * 纯电阻回路：两个 $10\ \text{k}\Omega$ 电阻配 5 V 电源，开关一闭合，电流**立刻**由 0 变成 $5\text{ V}/20\ \text{k}\Omega = 0.25\ \text{mA}$，断开又瞬间回到 0 A。

    * 纯电阻支路上，分压节点的电压同样瞬间跳到 2.5 V。

    * 换成电感后：电流从 0 **慢慢上升**到 $0.25\ \text{mA}$ 再走平，波形类似于电容充电过程。

    * 电感支路上电阻两端的电压也随之慢慢爬升，而不是瞬间跳变。

    * > **结论**：电感会把电路中的电流抑制住，上升速度被抑制，下降速度同样被抑制。

    * > **注意**：这个电路没有加续流回路，因此开关断开那一瞬间的波形不在此处讨论，只针对上升过程。

```text
纯电阻回路                    带电感的回路

      +5V                          +5V
       │                            │
     [10k] R1                     [10k] R1
       │                            │
       ├──── 开关 ────[10k] R2      ├──── 开关 ────[L]────[10k] R2─── GND
       │                            │
       ▼                            ▼
    电流 I                        电流 I

两端电压波形对照

纯电阻那条支路                 加了电感的那条支路

 U                                U
 │       ┌─────────               │            ╱──────────
 │       │                        │          ╱
 │       │                        │        ╱
 └───────┴────────── t            └──────╱────────────── t
         ↑ 瞬间跳到 2.5V                  ↑ 一点点慢慢爬上去
```

* **实物与示波器验证**

    * 两路电路集成在同一块实物上：两个 10 k 电阻对应纯电阻那条路，中间的电感对应电阻加电感那条路。

    * 接线：A 通道（黄）接纯电阻路的测量点，B 通道（绿）接电感路的测量点，两路共地，电源负极也接在公共地。

    * 用电源突然接入：黄色线立刻从 0 快速上升到 2.5 V 的一条垂直沿；绿色线同一时刻一点一点斜着往上爬。

    * > **结论**：只要电路中有电感，它就会抑制电流的变化速度。

## 电感只改变电流的变化速度

* **稳态电流不受影响**

    * 5 V 电源串一个 10 Ω 电阻，不接电感时电流 $I = \frac{5\text{ V}}{10\ \Omega} = 0.5\text{ A}$。

    * 把电感串进去，电流最终**仍然等于 0.5 A**，最大值没有被压低。

    * 变的是从 0 A 走到 0.5 A 不再是一瞬间的事，而是要花一段时间慢慢爬上去。

    * 线圈总会有一点内阻，确实会影响一点电流值，但基本可以忽略，不改变上述结论。

    * > **结论**：电感限制的只是电流的变化速度，绝不改变电路中电流的最大值。

    * > **易错点**：一听到「抑制电流」就以为稳态电流也会变小，这是最常见的误读；抑制的是变化率，不是那个最终稳定下来的数。

* **实物与仿真的对照**

    * 实物：5 V 直接接到 10 Ω 电阻两端，电流表读数 0.499 A；断开这根线换成电感串进去，电流表读数没有变化。

    * 仿真：电源同为 5 V、电阻同为 10 Ω、电感取 10 μH，两路并排各测电流。按下开关前两路都是 0。

    * 纯电阻那条一瞬间跳到 500 mA（曲线上呈斜线纯粹是仿真精度不够，实际应是直线）；串电感那条慢慢爬上去，但**终点与前一条重合**。

```text
  白色：纯电阻                    红色：串了电感

  I                               I
  │      ┌──────────              │          ╭───────────
  │      │                        │       ╭──╯
  │      │                        │    ╭──╯
  └──────┴────────────── t        └────┴───────────────── t
         ↑ 一瞬间就到 0.5A              ╰── 慢慢爬，但终点一样 0.5A
```

## 回路阻抗突变时的感应高压

* **电流改道寄生电容**

    * 机械开关的本质就是两块不导通的导体，开关一断开，两块导体之间就形成了一个电容，而电容可以储存电荷。

    * 开关闭合时电流爬到 0.5 A；断开那一瞬间电感里还有 0.5 A，电流不能突变，只能改道，把这 0.5 A 灌进开关两个触点之间的寄生电容。

    * 电流乘以极小的电容，两端立刻出现很高的电压：轻轻松松达到几百伏，电感大一点时几千伏、上万伏都有可能。

    * 仿真中把电感取大一点就能看到明显尖峰，示波器刻度为 10 kV 每格，读数在 ±10 kV 量级；仿真与实物有差别，实物产生不了 10 kV，但产生几百伏很轻松。

    * 实物上不用开关、直接用电源接通再断开，探头跨接断点两端，测得 $V_{pp}$ 为 163 V；示波器采样速率低，这个 163 V 不是最真实的值，实际电压还会更高。

* **电感为什么会顶出这么大的电压**

    * 开关一闭合，电流从 0 A 慢慢升到 0.5 A；开关一断开，这个开关相当于变成了一个无穷大的电阻。

    * 电感有一个极端能力：为了让它流过的电流维持不变，它可以感生出无穷大的电压去维持这个电流。

    * 不假设无穷大时：外部回路电阻变成 100 kΩ，电感要维持 0.5 A，就得感生出 $U = 0.5\text{ A} \times 100\ \text{k}\Omega = 50\ \text{kV}$；电源和电阻上的压降相对这个数太小，可以忽略。

    * 反过来，外部电阻是 10 kΩ 就感生 5000 V，是 100 kΩ 就是 50 kV——外部电阻有多离谱，它就顶出多离谱的电压。

    * > **结论**：电感回路上的阻抗绝对不能发生突变；一旦突变，电感就会为了维持电流不变而感生出高压。

    * 如果这个开关是电子开关，它很有可能当场被击穿。

* **插头打火的生活现象**

    * 插某些电器时插头会「啪啪啪」打火，是因为机器里面有电感。

    * 续流回路没做好时，插入过程机械上必然有弹跳，不可能一插就完全到位；开关一下接通、一下断开，电感电流一下有、一下没，反复突变导致开关两端反复产生高压。

### 续流二极管

* **加二极管构成续流回路**

    * 开关闭合时电流该怎么走还是怎么走，一样从 0 A 慢慢爬到 0.5 A。

    * 开关断开后原回路虽然没有了，但电流会发现又有一条新回路，于是不会出现变化剧烈的回路，也就不会产生高压，电流慢慢降回零。

    * 没有二极管时，断开瞬间是一个冲天的尖峰；有了二极管，断开瞬间先往下跳一下，紧接着就被钳住。

    * 钳位点就在二极管的导通压降上，实测时把触发阈值标在 1.33 V；把时间轴拉长看标准波形，能看到电压慢慢上升到约 0.7 V 附近，再随电感能量释放完回到零。

    * 因为电压被钳在很低的水平，加二极管后示波器的档位和触发阈值都要重新往下调。

```text
  S1 闭合：  +5V ──[ S1 ]──→[ L ]──→[ R 10Ω ]──→ 回电源负端   I → 0.5A

  S1 断开：  +5V ──✗ S1      [ L ]──→[ R 10Ω ]──→ 回电源负端
                   │        ↑
                   │        └── 电流方向一点没变，继续维持 0.5A
                   │
                   └──→ 经二极管 D 导通绕回 +5V，续流回路闭合

  没有续流二极管                    加了续流二极管

  V                                 V
  │         ╱╲                      │    ┌──────
  │        ╱  ╲                     │   ╱       ╲___
  │       ╱    ╲                    │  ╱             ╲_______
  │______╱      ╲____________       └───────────────────────── t
  └────────────────────────── t           ↑
        ↑ 断开的瞬间                            被钳在二极管压降附近，
                                                 能量放完再落回 0
```

* **动手时的安全边界**

    * > **提示**：这种高压演示不建议自己在家试，很容易把示波器打坏；真要玩，就把电阻调大一点、电感减小一点，否则高压太大。

## 感抗

* **感抗（Inductive reactance，$X_L$）**

    * > **定义**：描述电感对交流电流阻碍大小的量。

    * 电感和电容一样在电路中不损耗，是储能器件；但对交流电同样有阻碍电流的作用。

    * 公式：$X_L = 2\pi f L$，由信号工作频率 $f$ 与电感量 $L$ 相乘得到。

    * 电感固定时，频率越高感抗越大，对电流阻碍越强；频率一定时，电感量越大感抗越大，阻碍越强。

* **仿真验证与算例**

    * 搭最小电路：交流信号源串一个电感，直接看电流大小就知道感抗的变化。

    * 信号 1 kHz、幅值 1 Vpp，串 1 mH 电感，此时电感上的电流峰峰值约 300 mA。

    * 电感增大则电流减小；电感减小到 100 μH 则电流大很多；频率提高则电流减小很多；频率改成 100 Hz 则电流又大起来。

| 工作频率 f | 电感量 L | 感抗 $X_L$ |
| :--- | :--- | :--- |
| 1 kHz | 100 μH | 0.628 Ω |

* 代入验算：$2\pi \times 10^3 \times 100 \times 10^{-6} \approx 0.628\ \Omega$。

## LR 低通滤波电路

* **LR 低通电路的结构与原理**

    * > **定义**：电感在前、电阻在后、输出取在电阻上的低通滤波电路。

    * 基本概念与 RC 低通相同：输入频率低于截止频率时顺利通过，高于截止频率时输出被衰减。

    * 机理同样是电感电流不能突变：电感抑制输入信号提供给后级的电流，于是高频被挡在后级之外。

    * 用阻抗分压看更清楚：$V_{out} = \frac{R19}{R_L + R19} \times V_{in}$，其中 $R_L$ 就是感抗。

    * 代入感抗后：$\frac{V_{out}}{V_{in}} = \frac{R19}{2\pi f L + R19}$。$R19$ 定死，唯一变量是 $f$；$f$ 越大分母越大、比值越小、$V_{out}$ 越小，这就是「低通」两个字的来历。

* **截止频率的判定与算例**

    * > **定义**：把输入频率一路往上调，调到某一点使 $V_{out}$ 衰减成只剩输入信号的 0.707 倍，这个频率就是 LR 低通的截止频率。

    * 公式：$f_t = \frac{R}{2\pi L}$。

    * 算例：滤波电阻取 100 Ω、滤波电感取 100 μH，$f_t = \frac{100}{2\pi \times 100 \times 10^{-6}} \approx 159\text{ kHz}$。

    * 仿真三点：输入 100 Hz 时远低于截止频率，输入与输出完全重合；输入 1 MHz 时远大于截止频率，输出幅值明显变小；输入 159 kHz 时输入为 $\pm 1\text{ V}$，输出约 $\pm 0.707\text{ V}$（精度提高后测得峰峰值 706.743 mV）。

    * > **易错点**：低通不是把高频「切掉」，高频照样能过去一点，只是会被大幅衰减。

## RC 低通与 LR 低通的分工

* **RC 低通受限于电阻发热**

    * RC 低通的信号线上挂着一个电阻，而电阻是耗能器件，只要有电流流过就会发热。

    * 因此 RC 低通一般只能用在电流很小、后级负载功率比较小的场景，主要滤除信号传输上的噪声。

    * 例外不是没有：像一些运放芯片工作电流比较小，有时也会在运放的电源端用 RC 低通滤除电源噪声。

* **LR 低通适合大电流**

    * 电感不损耗能量，与电阻不同；尽管电流可能很大，电感自身不耗能，对整个电路的损耗比较低。

    * 所以 LR 低通主要适应电流比较大的场景，而电流比较大的地方一般就是电源线上的滤波。

* **实际电路中的落位**

    * 信号线上的高频噪声，用 RC 回路滤除。

    * 电源端上很少见到用一个电阻加一个电容做滤波，一般用电感做对应的低通滤波。

    * 电感种类很多，有分差模的，也有分共模的。

    * 原理相通：一个利用电容电压不能突变，一个利用电感电流不能突变，区别只落在哪个位置。

```text
  RC 低通：  Vin ──[ R ]──┬──[ C ]── GND
                          │
                          └── Vout

  LR 低通：  Vin ──[ L ]──┬──[ R ]── GND
                          │
                          └── Vout
```

## 电感高通滤波电路

* **结构与频率响应**

    * > **定义**：电阻串在前面、电感并在后面、输出取自电感两端的高通滤波电路。

    * 原理与低通完全一样：低通输出从电阻两端取，高通输出从电感两端取，抓住电感「电流不能突变」这条去推，推导过程对称。

    * 截止频率公式不变：$f_t = \frac{R}{2\pi L}$；仿真里只把电感与电阻位置一换、元件值不变，截止频率依旧等于 159 kHz。

    * 仿真一跑输出依旧是输入的 0.707 倍，而且这个 0.707 同样出现在**截止点**上，是分压公式的直接结果。

    * 把激励频率往两边推：频率 1 MHz 时远高于 159 kHz，高通完全放开，输出跟输入基本贴合、几乎看不出差别；频率压到 1 kHz 甚至 10 kHz 时，输出被压下去，红色那条几乎等于 0，把刻度缩小才看得出与输入差着很多。

    * > **结论**：电感高通滤波电路的特性一句话——高频信号通过，低频信号过不来。

```text
LR 低通：输出取自电阻两端

   Vin ──[ L ]──┬──[ R ]── GND
                 │
                 └── Vout

LR 高通：输出取自电感两端

   Vin ──[ R ]──┬──[ L ]── GND
                 │
                 └── Vout
```

* **典型用法与死穴**

    * 最常见的活儿是滤掉高频信号上叠着的低频噪声，最典型的就是 50 Hz 工频干扰。

    * 例：500 kHz 的有用信号上叠了 50 Hz 噪声，叠加后波形变成上去、下来、上去、下来；经过高通滤波后输出重新变成一直平着过去的样子，那层低频波动消失了。

    * 死穴在于电感高通输出取自电感，而**电感的底端是接到地的**，因此电路里不能存在直流偏置。

    * 标准交流正弦（高 1 V、低 −1 V，以 GND 为基准）进到输出能正常工作；骑在 1 V 偏置上的信号则是高 2 V、低 0 V，这 1 V 不是噪声而是信号共存的合法成分。

    * 但直流信号就是 0 Hz，就是最低频的分量，从高通的角度看它和噪声没有任何区别；一用电感高通去滤，这 1 V 偏置和低频噪声一起被滤掉，全没——仿真里给输入加 1 V 电压偏移，输出中那 1 V 直接被电感短路到地。

    * > **易错点**：电感的高通滤波电路只能滤**没有直流偏置**的信号，只要信号带了偏置就绝对不能这么接。

    * > **结论**：信号本身带直流偏置就换电容的高通；电容高通结构与电感的不同，但低频噪声一样会被洗掉。

## LC 低通滤波电路

* **LC 分压结构与二阶滚降**

    * > **定义**：完全由电感和电容直接组成、输出取在电容一端的低通滤波电路，也叫 LC 谐振回路。

    * 分压式：$V_{out} = \frac{R_C}{R_C + R_L} \times V_{in}$，其中 $R_C = \frac{1}{2\pi f C}$、$R_L = 2\pi f L$。

    * RC 低通的对应式子是 $V_{out} = \frac{R_C}{R_C + R} \times V_{in}$；其中频率变化时整个电路里阻抗会变的参数**只有电容一个**：$f$ 变大 $R_C$ 就减小，只有一个变量在动，变化量自然有限。

    * LC 低通则不同：$f$ 变大时容抗减小、感抗增大，分子在缩、分母在涨，两个变量同时朝同一方向使劲，分压比的变化量当然比 RC 大。

    * 衰减速度更快就意味着滤波效果更好；从滤波器阶数看，LC 是二阶低通，LR 和 RC 都是一阶，二阶滚降更陡正是「两个变量一起动」。

| 拓扑 | 串 / 并组合 | 随频率变化的阻抗 | 阶数 | 滚降 |
| :--- | :--- | :--- | :--- | :--- |
| LR 低通 | L 串、R 并 | 只有 $R_L$ 随频率增大 | 一阶 | 慢 |
| RC 低通 | R 串、C 并 | 只有 $R_C$ 随频率减小 | 一阶 | 慢 |
| LC 低通 | L 串、C 并 | $R_L$ 增大、$R_C$ 减小，两个同时动 | 二阶 | 快 |

* **公平对比的设置**

    * 为了让对比公平，仿真把两个电路的截止频率设成一样：电感与电容都取 10 μF，对应谐振频率 15.9 kHz，于是 RC 这边截止频率也设成 15.9 kHz，滤波电阻取 1 kΩ，对应滤波电容为 10 nF（0.01 μF）。

    * 输入 1 kHz 时两个都是低通，输出都应等于输入，两条波形基本重叠，但 LC 那条上会冒出一个谐波。

    * 输入 20 kHz 时两个电路都有衰减，LC 衰减到的幅值明显更小，但谐振成分还在，输出能看到不小的震荡。

### 谐振峰与阻尼电阻

* **谐振点会放大信号**

    * 把输入直接改成 15.9 kHz 的谐振点本身，输入不但不会衰减到自身的 0.707 倍，反而变得很大：输入 $1\ \text{V}_{\text{pp}}$，从 LC 网络出来的输出变成 $10\ \text{V}_{\text{pp}}$。

    * 这 10 倍放大不是错觉，阻尼电阻与谐振增益是对应的；把串联电阻一并考虑进计算表格后，调整阻尼电阻就能直接读出对应的谐振增益。

| 阻尼电阻 | 谐振点上的表现 |
| :--- | :--- |
| $0.1\ \Omega$ | 增益约 10 倍，$1\ \text{V}_{\text{pp}}$ 进，约 $10\ \text{V}_{\text{pp}}$ 出 |
| $1\ \Omega$ | 增益约 1 倍，输出刚好等于输入 |
| 继续往小改 | 阻尼变弱，只要输入又贴近谐振点，增益立刻又跑出来 |

    * 加 $0.1\ \Omega$ 电阻可以把谐波压住；频率提到 20 kHz 时试过 $10\ \Omega$ 加得太大，退到 $5\ \Omega$ 才合适。

    * 挂着一个 $5\ \Omega$ 电阻幅值当然会小，所以要换一种公平的玩法：把阻尼电阻减小，同时把输入频率提到 50 kHz 远离谐振频率，此时谐振带来的放大效果很小，哪怕阻尼电阻减回 $0.1\ \Omega$ 也没问题。

    * > **结论**：噪声水平相同的情况下，LC 的滤波效果相对于 RC、LR 要好很多。

    * > **结论**：LC 低通不单单只干低通这一件事；在谐振点（也就是截止频率那一点）是**不但不衰减、反而会放大**的，LC 回路里电阻比较小时会对谐振频率点产生明显增益，所以必须预留电阻限制放大倍数。

    * > **易错点**：用 LC 电路做低通滤波时，一定要预留阻尼电阻去限制谐振频率的增益，不然很容易出问题。

## 晶体管入门：二极管

* **PN 结与导通压降**

    * > **定义**：二极管的基础结构就是一个 PN 结；P 型半导体与 N 型半导体结合在一起就形成 PN 结，PN 结就是二极管。

    * 材料分三类：绝缘体完全不导电，导体通电就有电流，半导体通电不一定有电流、只有满足某些条件时才有。

    * 半导体可以通过人为掺杂改变性质，掺 P 型材料成为 P 型半导体，掺 N 型材料成为 N 型半导体。

    * 硅管压降一般在 $0.5 \sim 0.7\ \text{V}$；锗管约 $0.3\ \text{V}$ 左右（现在用得较少）；肖特基二极管导通压降更低。

    * 外面看到的只是外壳，真正的二极管封装在里面；用打火机把外壳烧成灰后轻轻刷掉，会看到里面有金属颜色、闪闪发光的小东西。

    * 实测：普通硅二极管 1N4007 在 $5\ \text{mA}$ 时电源显示 $0.67\ \text{V}$，换万用表直接测两端为 $0.69\ \text{V}$；肖特基在同样 $5\ \text{mA}$ 下只有 $0.24\ \text{V}$。

| 类型 | 型号 | $5\ \text{mA}$ 时实测压降 |
| :--- | :--- | :--- |
| 普通硅二极管 | 1N4007 | 约 $0.67\ \text{V}$（万用表测 $0.69\ \text{V}$） |
| 肖特基二极管 | — | 约 $0.24\ \text{V}$ |

* **压降不是常数**

    * > **注意**：流过二极管的电流越大，压降就越大；把电流从 $5\ \text{mA}$ 慢慢往上调，压降会一点点跟着往上爬——不能因为规格书写的是 0.6 V 就认为它一直是 0.6 V，它还跟工作电流有关。

    * 原因是二极管并不是纯二极管模型，它有寄生电阻（ESR）；电流越大，落在寄生电阻上的压降越大。

    * 因此一般建议尽量让二极管工作在 $10\ \text{mA}$ 左右；不同封装不一样，大功率封装的持续电流可以做得很大，就不会发热。

    * 单向导电像一只漏斗：电流方向只能从正极往负极走；把电源反接时二极管不导通，等效断开，电源设 5 V 时万用表测到 4.99 V；一旦导通，两端就约等于导通压降。

    * 例外先记个名字：有一些稳压二极管会工作在击穿区，击穿时电流方向相反。

* **不能直接并联电压源**

    * 从导通特性看：横轴是 $V_D$、纵轴是 $I_D$，拐点之前 $I_D = 0$；越过拐点后 $V_D$ 涨一点点、$I_D$ 就暴涨，且上升不是线性的，后期 $V_D$ 只升一点点电流就变化非常多。

    * 一颗 0.6 V 导通压降的二极管外面直接接 1 V，电流可能直接升到几百毫安甚至几安，发热严重、极易损坏。

    * 从回路算：假设导通压降恒定 0.6 V，二极管与走线的寄生电阻统称 $R$（一般很小，比如 $0.1\ \Omega$），电源 1 V 直接并联，剩的 0.4 V 全加在这个电阻上。

    $$I = \frac{V_{in} - V_D}{R} = \frac{1 - 0.6}{0.1} = 4\ \text{A}$$

    * 实测 1N4007（导通压降约 $0.7\ \text{V}$），限流放到最大（面板显示 5.2 A）后正接、慢慢往上调电压：

| 电源电压 | 二极管电流 |
| :--- | :--- |
| $0.7\ \text{V}$ | 约 $2\ \text{mA}$ |
| $0.8\ \text{V}$ | 约 $50\ \text{mA}$ |
| $0.9\ \text{V}$ | 约 $0.3\ \text{A}$ |
| $1.0\ \text{V}$ | $1.4\ \text{A}$，器件温度已达 167 度 |

    * > **易错点**：二极管一定不要直接跟电压源并联。一旦并联很容易产生很大的电流，要么二极管直接烧掉，要么电源就不正常了。
