# 纯硬件循迹小车整机电路设计

## 整机信号链路与循迹逻辑

### 光强到电平的转换级

* **红外接收二极管**

    * > **定义**：一个受光强控制的电流源。

    * 无红外光时反向电流极小（纳安、皮安或微安级，做分析时可先忽略），接收到红外光时可认为反向导通并产生反向光电流。

    * 唯一规律：接收到的红外光越强，流过它的反向电流就越大。

    * 接取样电阻 $R$（上端 5V、下端 GND，中间点记作 $V_R$）后：$V_R = 5\text{V} - I_R \times R$。

    * 无光时 $I_R \approx 0$，压降为 0，$V_R = 5\text{V}$；有光时 $I_R$ 变大，$V_R$ 掉下来。

    * 结论：**红外光越强，$V_R$ 越低**，电压与光强成反比，这个「反」是后面所有电路的出发点。

    * > **易错点**：外形虽是二极管，工作时是反着接的；顺向使用整条链路都不成立，画原理图必须盯住这一点。

* **黑白两色的电压分档**

    * 取 $R = 1\text{k}\Omega$，白区（有红外光）设 $I_R = 1\text{mA}$，$V_R = 5\text{V} - 1\text{mA} \times 1\text{k}\Omega = 4\text{V}$。

    * 黑区（光被黑色吸收）设 $I_R = 1\mu\text{A}$，$V_R = 5\text{V} - 1\mu\text{A} \times 1\text{k}\Omega = 4.999\text{V}$。

    * 一个连续模拟量被拉成两个可分辨档位，这就是判断「车有没有压线」的全部依据。

    * 白区那个 4V 是可调的：$R$ 越大，白区掉下去的压降越多、$V_R$ 越低，所以**调电阻 $R$ 就是调灵敏度**。

    ```text
                5V
                 │
              [R] 1kΩ     ← 调 R 就是调灵敏度
                 │
       V_R ──────┼──────────► 送比较器反相端
                 │
            ┌────┴────┐
            │ 红外接收 │  ← 反接使用
            │  二极管  │
            └────┬────┘
                 │
                GND
    ```

### 比较器把模拟量变成开关量

* **LM393 作为比较器的接法**

    * 参考电压 $V_+$ 接 4.5V，红外电路的信号 $V_R$ 直接接反相端 $V_-$。

    * 黑区：$V_- = 5\text{V} > V_+ = 4.5\text{V}$，输出低电平。

    * 白区：$V_- = 4\text{V} < V_+ = 4.5\text{V}$，输出高电平。

    * 把 $V_{out}$ 接到三极管基极即连上逻辑：黑线输出低、三极管截止、电机停；白线输出高、基极有电流、电机转。

    * 总结成一句：**红外停在黑线上，电机停；停在白线上，电机走。**

    ```text
       红外信号 V_R ────────► (−)
                              │  ┌──────────┐
       滑动变阻器中点 ──────► (+) │  LM393   │ ───► V_out
                              │  │  比较器  │
                              └──└──────────┘
    ```

    | 区域 | 光照 | $I_R$ | $V_R$ | 与参考电压 | $V_{out}$ | 三极管 | 电机 |
    | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
    | 白线 | 收到红外光 | $1\text{mA}$ | $4\text{V}$ | $V_- < V_+$ | 高电平 | 导通 | 转 |
    | 黑线 | 光被吸收 | $1\mu\text{A}$ | $4.999\text{V}$ | $V_- > V_+$ | 低电平 | 截止 | 停 |

* **三段式转换链路**

    * 红外接收管（光强）→ 取样电阻（变电压）→ 比较器（变开关量）→ 三极管（变电流）→ 电机。

    * 这一条线把「检测黑线」和「控制电机」两件看似不相干的事串在一起。

* **差动实现循迹**

    * 车跟黑线走时两侧接收管都在收光，两个电机一起前进。

    * 走到某处左侧接收管突然收不到红外（黑色吸收了发射管打出的红外光），左轮停、右轮仍转，车就拐过去。

    * 一拐弯，循迹即成立；这套逻辑图就是整机电路的系统框图，设计电路就是把框图逐个方框画进原理图。

### 参考电压必须可调

* **为什么不能用电阻分压代替**

    * 前面分析白区反向电流时是「假设」为 $1\text{mA}$，实际是不是 1mA 事先并不知道。

    * 用 500Ω 与 4.5kΩ 分出个漂亮的 4.5V 装上去往往没用，因为实际电流可能根本不是 1mA，阈值一开始就偏了。

    * 结论：分析得再有道理，落到板子上都必须保证阈值**可调**，所以 $V_+$ 必须接滑动变阻器——一端接 5V、一端接 GND，中间抽头在 0~5V 连续可调，初值取 10k。

    * > **易错点**：把推导时的假设值当成实测值去硬分压，是这类判断电路最常见的翻车点。

## 红外检测电路的原理图落地

### 器件与封装选择

* **红外接收二极管的封装**

    * 属于光敏二极管，直接用光敏二极管封装来画。

    * 封装库底部有一堆封装，其中红外光敏二极管 HWQ 黑色是插件型；点到的是贴片型，不适合本项目。

    * 正确做法是换成有两个洞的那个插件型封装，拖出来才是一颗插件型红外接收二极管。

* **取样电阻的封装**

    * 选 RES（贴片电阻），底部同样一大堆封装。

    * 初学者直接用 **0805**，焊盘大、好焊接。

* **供电与型号替换**

    * $V_{in}$ 先按 5V 接，底部接 GND。

    * 常见比较器型号是 LM393，把运放型号换成 LM393。

    * LM358 可以直接改名成 LM393 使用，因为两者封装可以共用、引脚定义一模一样，实物买来的八脚芯片就是 LM393。

* **快捷键**

    * > **提示**：按住 **Shift** 再用鼠标左键点击元器件一拉，就能拉出一个新的；电阻、三极管都能这么拉，复制整块电路时还要再用一次。

### 检测电路的装配顺序

* **第一步，画红外接收二极管**并接上取样电阻，$V_{in}$ 接 5V、底部接 GND。

* **第二步，画比较器**，把运放型号换成 LM393。

* **第三步，接供电和两路输入**：芯片接 5V 与 VCC；红外信号按推导接**反相端**；$V_+$ 接滑动变阻器中点。

* **第四步，LM393 是 OC 输出，必须加上拉电阻**，再预留一颗基极电阻接到三极管基极。

* 至此「黑线检测 + 电机控制」的最初步电路完成，接下来用比较器驱动后级电机部分。

### LM393 的 OC 输出特性

* **OC 输出的含义**

    * 比较器输出有 OC、OD、推挽三种类型，LM393 属 OC 输出。

    * OC 就是输出端内部挂了一个三极管到地，没有上拉到电源。

    * 用它**必须加一个上拉电阻**，否则 OUT 上根本不存在高电平。

* **双通道引脚划分**

    * 买一颗比较器回来共八个引脚：1、2、3 对应其中一个比较器的三个引脚，5、6、7 是另一个比较器的三个引脚，4 和 8 是电源引脚。

    * 一颗芯片里就已经包含了两颗比较器，两个电机各自要一个比较器却只需一颗芯片，原因就在这里。

    ```text
            ┌──────────────────────────────┐
            │           LM393              │
            │                              │
            │  1 ──┐                ┌── 6  │
            │  2 ──┼── 比较器 A ────┼── 5  │  比较器 B
            │  3 ──┘                └── 7  │
            │                              │
            │  4 ────── 电源引脚 ───── 8   │
            └──────────────────────────────┘
    ```

* **复制整块电路时的两个细节**

    * 两个电机要独立控制，把整块电路复制一份即可（模块化、完全重复的电路没必要手画第二遍）。

    * 复制出来那一路多画的 5V 可以删掉，因为两个通道共用电源。

    * > **易错点**：删 5V 时不要把上拉电阻一起删掉，上拉电阻是每一路都必须的。

## 电机驱动电路

### 续流二极管保命

* **电机是电感模型**

    * 回路阻抗发生突变时会产生很高的感应电动势。

    * 三极管由导通突然断开时，电机两端出现高压；几千伏未必产生，但几十到一百多伏很轻松。

    * 必须给电机加**续流回路**接住电流突变，直接反并联一个二极管即可。

    ```text
              +5V ──────────────┐
                                │
                              ┌─┴─┐
       V_out ──[R_B]─────────┤ Q │  M（电机）
                              └─┬─┘──┬──┐
                                │    │  │
                                └─|◄─┘  │
                                   D     │
                              (续流二极管)
    ```

    * 读图：Q 导通时电流从 5V 经 Q 流向电机；Q 突然截止时，电机电感电流不能突变，自生上正下负的感应电动势，此时 D 导通提供另一条回路，电压被钳位在二极管导通压降附近，MOSFET 两端不会被击穿。

* **续流二极管的选型规则**

    * 开关断开的一瞬间，电机电流会全部流过这颗二极管，导通电流必须大于电机的正常工作电流。

    * TT 电机正常工作电流约 500mA，负载重时更大，且 500mA 只是一瞬间流完，选普通 1N4007 之类的二极管就够。

    * 大功率电机最大电流能到 10A 时，续流二极管必须换成相对大功率的型号，这条没有中间地带。

### 基极电阻必须算

* **饱和导通的判据**

    * $I_B \times \beta = I_C$ 只在三极管工作于放大区时成立。

    * 三极管做开关用，要进入饱和导通，条件是 $\beta \times I_B > I_C$；注意是「大于」不是「等于」，这条不等式是所有计算的出发点。

* **两级计算**

    * $I_C$ 取电机电流 500mA，假设 $\beta = 100$，则 $I_B = 500\text{mA} / 100 = 5\text{mA}$。

    * 两个电阻串联，从 5V 减去导通压降 $V_{BE} = 0.7\text{V}$ 再除以回路电流：$R_{\text{总}} = (5\text{V} - 0.7\text{V}) / 5\text{mA} = 4.3\text{V} / 5\text{mA} = 0.86\text{k}\Omega$。

    * 三极管本身要扛得住电机工作电流；SS8050 的最大导通电流 $I_C$ 够用，只是封装小、散热差，工作时可能发热到五六十度，小项目可接受。

* **电阻分配**

    * 算出的 0.86kΩ 分给两个电阻：**一个取 0Ω，一个取 820Ω**。

    * 不能一个取 0Ω、另一个取满 0.86kΩ，更不能把这条支路直接短接：LM393 是 OC 输出，输出低电平时内部三极管导通把输出点拉到地，短接等于 5V 通过上拉电阻直接灌进 LM393 内部三极管，芯片可能直接烧掉。

    * 取 0Ω + 820Ω 时输出低电平流过的电流约 5mA 稍多一点；比较器和运放输出/吸收电流一般都能达到五六十毫安，吸收 5mA 没问题，输出断开时电流改走这条路径，芯片照常工作。

    * > **易错点**：这一条支路最好**预留一个电阻**在电路里，哪怕值取成 0，它在原理图上也是一颗实打实的器件，后期要留位置调试。

* **初值与实测调整**

    * 上拉电阻初值取 1k，滑动变阻器初值取 10k。

    * 820Ω 是按 $\beta = 100$ 算的，实际很多三极管放大倍数可能是 200 甚至 300，所以初值只是起点。

    * 正确做法：焊上去后必须实测，确认完全饱和导通就把电阻再放大一点点复测，仍饱和就继续放大——对整个电路来说**电阻越大，静态功耗越小**。

## 电源与去耦

### 每一处电源都要电容

* **布放原则**

    * 所有元器件实际工作时电源都不是理想电源，一定带噪声；凡是电源引脚一律考虑加电容滤波，这不是可选项而是基本功。

    * 电机工作电流大且直流有刷电机还会产生高频噪声，电机这一路先并联一个小电容改善高脉冲噪声。

    * $V_{in}$ 一侧先加一颗**储能电容**（用电解电容），再加一颗 **100nF** 专门滤高频噪声。

    * 芯片侧的 5V 要加电容，比较器供电的 5V 要滤波，共用的那一侧 GND 同样要。

    * 取样电阻上也可以并一颗很小的 **100pF**，滤除红外接收二极管收到的高频噪声。

    ```text
       VIN ──┬────────────── 送往取样电阻与 LM393 供电
             │
            ─┴─  储能电容（电解）
             │
            ─┴─  100nF（滤高频）
             │
            GND
    ```

    * 两种画法都行：在这一侧老实把电容都画上，或直接拉一根线连过去，效果完全一样。

### 电机端口电容的两个作用

* **瞬态供电（时间差）**

    * 实际安装时 6V 电源要经过很长走线才接到电池，开关突然闭合时外部提供电流需要反应时间。

    * 画 PCB 时把电容放在电机安装端口旁边，电容就能在开关闭合一瞬间优先给电机提供能量把它顶上去。

* **就近压噪**

    * 电机产生感应电动势或噪声时，近在咫尺的电容立刻把这些噪声压下来。

    * 同一颗电容既在瞬态提供大电流防止电压跌落，又滤掉电机产生的高频干扰。

### 线性稳压的最小压差

* **三路电源结构**

    * 接收、比较器、电机驱动画完后整图已完成约 80%，剩下 20% 是电源。

    * 电源走 6V 输入 → 5V → 3.3V 三路；多加一路 3.3V 属于教学演示（让红外接收管改用 3.3V），实际画图可以不加。

    * 5V 和 3.3V 都只供给信号处理电路，用 LDO 即可，没必要上开关电源。

* **最小稳压压差（Dropout Voltage）**

    * > **定义**：芯片想输出目标电压时，输入必须高于它的那个压差门限。

    * 常见普通稳压芯片的最小压差可能是 0.3V、0.7V、1.4V，甚至更高；查所选芯片数据手册的 `Dropout Voltage` 一项。

    * AMS1117 的 -3.3、-5.0 等型号，最小稳压压差通常大于 1V。

    * > **易错点**：直接摆一颗 LM7805 到 6V 输入上会翻车，忽略最小压差，电路画得再漂亮也是错的。

    * 6V 电池灌进不同最小压差的芯片，实际输出差别很大：

    | 芯片最小压差 | 输出 5V 所需的最低输入 | 6V 电池灌进来的实际输出 |
    | :--- | :--- | :--- |
    | 0.3V（低压差型） | 5.3V | 5.0V，可用 |
    | 0.7V | 5.7V | 5.0V，可用 |
    | 1.2V | 6.2V | 4.8V，差一口气 |
    | 1.5V | 6.5V | 4.8V，不够 |

* **两条对策**

    * 选最小稳压压差只有 0.3V、0.5V 的低压差型芯片，但价格一般会高一点。

    * 选不到就干脆不用它，改用分立元器件搭一个线性稳压。

### 分立搭 5V 稳压

* **稳压管与三极管组合**

    * 稳压管（Zener）导通后两端电压被钉死在 5.6V，稳压管选型是 Z 开头。

    * 三极管工作在放大区与饱和区的临界点，即预饱和区，等效为射极跟随器，输出比基极低一个 $V_{be}$。

    * 让基极为 5.6V，减去一个 $V_{be}$，输出就是约 5V。

    * 器件选取：5.6V 稳压管拉过来后接地，输出即变成 5V 左右。

    ```text
          6V 输入
            │
            ├──[ R（限流电阻）]──┬──────────┐
            │                   │          │
            │                 ┌─┴─┐        │
            │                 │DZ │ 5.6V   │
            │                 └┬─┘        │
            │                  │     ┌────┴────┐
            │                  └─────┤   Q1    │
            │                        │  (NPN)  │
            │                        └────┬────┘
           GND ──────────────────────────┤  C
                                            │
                                            └──────→ 5V 输出
       Q1 发射极 E 接地；集电极 C 就是 5V 输出端
    ```

    * > **提示**：这个分立线性稳压电路建议零基础的同学动手画一遍；以前做过电路的可做可不做。

### 限流电阻取 82Ω 的推导

* **压差是恒定的**

    * 稳压管这一点电压 5.6V、输入电压 6V，稳压管一旦导通电阻两端压差可认为是恒定的 **0.4V**，重点是评估流过电阻的电流。

* **电流的两部分**

    * 第一部分是稳压管的电流：反向导通电流达到 0.5mA 左右就已具备相对稳定的电压，往上范围很宽，最大可能到 20mA 甚至 50mA，取决于封装和额定功率；一般把稳压电流取在 1mA~10mA 之间即可，这里取折中值 5mA 计算。

    * 第二部分是基极电流 $I_b$：三极管在预饱和区，按 $I_c = \beta \times I_b$ 计算，其中 $I_c$ 对应后级电路工作电流。

* **后级电流估算**

    * 后级工作电流很小，主要是供给 10k 分压电阻（其上约流过 0.5mA）以及比较器的电流，加起来大概几毫安。

    * 把所有杂项功耗都算上、上下两路一起估，后级电路最多按 20mA 估算，实际根本达不到。

    * > **易错点**：估的时候要往大了估，宁可算出来的电流大一点，也别留余量不够的风险。

* **算阻值**

    * $I_c = 20\text{mA}$、$\beta = 100$ 时 $I_b = 20\text{mA} / 100 = 0.2\text{mA}$，非常小，基本可忽略。

    * 所以流过电阻的总电流大致取 5mA：$R_5 = 0.4\text{V} / 5\text{mA} = 0.08\text{k}\Omega = 80\Omega$。

    * 实际取标称 82Ω 左右；算出来 80Ω，E24 系列里最接近的是 82Ω，直接往上取。

    * 该电阻电流仅 5mA、功率很小，封装选 0805 即可。

    * 一条链路记下来：**压差 0.4V，电流 5mA，80Ω 取 82Ω，0805 封装。**

### 降到 3.3V 与电源接口配置

* **1117-3.3 的用法**

    * 端口很明确：IN、两个 OUT、GND；两个 OUT 只接其中一个就可以，也可以两个都接。

    * 输入端挂电容是为了让芯片在负载突变时还有电可放，不然输出会跟着抖。

    * 输出端挂电容则是储能兼滤波。

    ```text
        5V ──┬──────── IN ────┐
              │                  │
           [ 10μF ]          ┌───┴───┐
              │              │       │
              │              │ 1117- │
              │              │  3.3  ├── OUT ──┬──→ 3.3V ──┬── [ C ]
              │              │       │        │             │
              │              ├── OUT ┘     [ C ]          GND
              │              │       │        │
              │              └───┬───┘       GND
        GND ──┴──────────────────┴──→ GND
    ```

* **6V 输入接口**

    * 6V 电池模型买来就自带开关，电池电压只要插到板子上，所以原理图上预留两个输入接口插 6V。

    * 6V 进来后依次画：输入电压接口 → 限流电阻 → 5.6V 稳压管（Z 开头）→ 接地，输出即 5V 左右。

    * 再把 1117-3.3V 拉过来接 GND，完成 5V 到 3.3V 的降压。

* **电容配置**

    * 6V 输入进来接一颗小电容即可，不必接大电容，可取 10μF；这里再接一颗 10μF。

    * 这一点最好再加一颗电容做滤波。

    * 5V 输出端要加储能电容，这里接 100nF。

    * 1117 的输出端挂两颗电容，其中一颗可接可不接。

* **统一编号**

    * 原理图画完后在**工具**菜单点击**标注**，选择**静态标注原理图**，系统会自动给原理图元器件统一编号；每次修改完成后重新执行一次。

## 细节完善与调试指示

### 基极下拉电阻

* **作用**

    * 驱动三极管的基极永远要有一个把电平拉回默认态的通路。

    * 悬空的基极就是一个天线，什么噪声都往里灌。

    * 三极管基极位置增加下拉电阻用于增强电路工作的稳定性。

### 红外发射管

* **数量与选型**

    * 实物上共四个光电管：两个红外接收管、两个红外发射管，需在原有电路上补上两个发射管。

    * 发射管封装要选**直插封装**，不要选贴片封装，因为采用直插方式安装。

    * 供电选 5V 或 3.3V 区别不大，这里直接接 5V。

    * 用两个发射管，所以底部对应位置同样要再加一个。

### LED 指示灯

* **接法与选型**

    * 红外接收管接收到红外信号、输出端输出高电平时 LED 点亮，直观反映电机工作状态，也方便后续调试。

    * 指示灯选贴片 0805 封装，限流电阻改为 1k；底部通道同样增加一颗 LED 及 1k 限流电阻。

    * > **提示**：调试时没有指示灯就得一路拿示波器点每个引脚；有指示灯一眼就知道哪一路已经「看见线」，这两个灯省下的调试时间是画它们花的时间的好几倍。

## 自绘原理图封装

### 建库与栅格

* **添加库文件**

    * 可能没有现成的原理图库与 PCB 库，所有器件都需要自行绘制。

    * 点击工程，选择**添加新的原理图库（Schematic Library）**，工程列表中就会生成一个新的原理图库文件。

* **栅格（Grid）设置**

    * 新建原理图库初始为空白，进入编辑界面后第一步务必先调栅格：点**视图**找**栅格**，尺寸一般设为 50mil。

    * 不要随意调成 20mil 或 30mil。

    * > **结论**：原理图库元器件引脚的格点必须与原理图界面的格点保持一致，或呈整数倍关系。

    * 格点不一致时，器件放进原理图引脚无法对齐格点，连线拉不直，画完了看过去线全是斜的。

### 绘制引脚

* **放置与热点朝向**

    * 点**放置**、点**管脚**（也可以直接在文字那一栏点，直接放置管脚）。

    * 管脚上有几个小白点，这个小白点（热点）一定要往外放。

    * > **易错点**：白点朝内意味着热点被压在符号身体里，外面连的线看着接上了，其实根本没接。

    ```text
       对：白点朝外 —— 热点 ● 落在符号外面，信号线直接接得上

                ┌────┐
         ──────┤    ├●─────      ← 热点在右侧，连线拉得直
                └────┘

       错：白点朝内 —— 热点 ● 被压在符号身体里，外部的线碰不到它

                ┌────┐
         ──────┤  ●─┤─────      ← 线看着接上了，其实根本没接
    ```

* **编辑引脚信息**

    * 引脚编号要和 PCB 封装对应起来，画第几个引脚就写几。

    * Name 按数据手册的引脚功能命名：1 脚是 1OUT 就写 OUT1，2 脚是 1IN− 就写对应的反相输入名称，3 脚是 1IN+，第 4 脚对应 GND。

    * 引脚长度一般设 100mil。

    * 画完一个引脚按 **Tab** 键即可再次弹出编辑信息。

### LM393 引脚定义与归属

| 引脚编号 | 名称 | 功能 | 归属部件 |
| :--- | :--- | :--- | :--- |
| 1 | 1OUT | 比较器 1 输出 | Part A |
| 2 | 1IN− | 比较器 1 反相输入端 | Part A |
| 3 | 1IN+ | 比较器 1 同相输入端 | Part A |
| 4 | GND | 地 | Part A |
| 5 | 2IN+ | 比较器 2 同相输入端 | Part B |
| 6 | 2IN− | 比较器 2 反相输入端 | Part B |
| 7 | 2OUT | 比较器 2 输出 | Part B |
| 8 | VCC | 电源 | Part A |

### 外形与引脚名显示

* **补透明矩形**

    * 八个引脚画完一般还要在符号里面加一个外形，即放置一个矩形。

    * 放置矩形后一般要把它变成透明，LDO 这类器件符号里才有文字。

* **让引脚名显示出来**

    * 把引脚全选，点信息窗，看到 Name 这一栏的眼睛是被擦掉的，再点一下就会显示。

    * 显示后发现全乱了不要慌：把引脚全部选择后拉出来，再把框拉长一点点即可。

    * > **易错点**：符号本体只是给人看的，电气连接全靠引脚热点，所以框的大小以「不碰到引脚名字」为准，宁可大一点也别挤成一团。

* **Design ID 与描述**

    * 设计 ID（Design ID）直接设成 LM393。

    * 标号（Designator）芯片类一般以 U 开头再加问号，即 U?，其中也可以写成 LM393。

    * 描述（Description）打成「比较器」即可，打中文没有关系。

* **单部件为什么难用**

    * 单个部件画出来的 LM393 也能用，但电路画出来线绕来绕去，非常难检查。

    * 比较器这类复杂芯片通常要画成多个部件，才能得到每个比较器独立、连线一路直着走的图形。

    ```text
       单个部件画出来的 LM393：能用，但线全绕在芯片周围

         1OUT ──┐   ┌── 2IN+
         1IN- ──┤   ├── GND
         1IN+ ──┤ ▓ ├── 2IN-
         VCC  ──┤   ├── 2OUT
         GND  ──┘   └── 2OUT

       两个部件画出来的 LM393：每个比较器独立，连线一路直着走

            ┌───┐             ┌───┐
      1OUT ─┤ △ ├─── 1IN+ 2OUT┤ △ ├── 2IN-
      1IN- ─┤   ├─── VCC  2IN+─┤   ├── VCC
            └───┘             └───┘
    ```

### 多部件封装

* **新部件不是新器件**

    * 选中符号后点**工具** → **新部件**，符号就分成 Part A 和 Part B。

    * > **易错点**：菜单里**新部件**与**新器件**挨得很近，点错就变成另一个器件了。

* **Part A 的画法**

    * 先放 1OUT（1 脚）、1IN−（2 脚）、1IN+（3 脚）三个引脚。

    * 分成两个部件后，OUT1、OUT2、OUT3 这类名称画不画都可以。

    * 个人习惯是把电源与地引脚画在第一个部件上：VCC 是 8 脚，GND 一般是 4 脚，一并放上去。

    * > **提示**：运放很多时候不叫 GND 而叫 VSS，因为有些运放可以双电源供电，比较器同理。

    * 之后点**放置** → **多边形**画出三角形，把线改成 Small、填充改成透明，再把 Pin 放上去。

* **三角形与引脚差一点点**

    * 希望 Pin 和三角形接在一起：要么把三角形往后挪一点，要么把 Pin 脚变长到 120 或 150。

    * 变长后还差一点伸不上去时，不要把库里的栅格改成 10mil 去硬凑——原理图格点可能是 100 或 50，差值会导致对不齐。

    * 笨但可靠的办法是补放一小段线，把差值吃掉，主体仍然锁在 50mil。

    ```text
       ✗ 把库里的栅格改成 10mil 硬凑

         ▓▓▓▓
         ▓  ▓
         ▓  ●──   ← 这里落在 10mil 格点上，10 的倍数
         ▓▓▓▓        在原理图 50mil 格点下就没法落位

       ✓ 补一小段线把差值吃掉

         ▓▓▓▓
         ▓  ▓
         ▓  │
         ▓  ●   ← 主体仍锁在 50mil，多出来的一小段用线补
         ▓▓▓▓
    ```

    * 这一步做完记得把栅格换回 50mil。

* **引脚名称的开关与写法**

    * Part A：1 脚是 OUT，可把名称关掉；负号写成「负」，3 脚写成「正」。

    * Part B：同法放引脚与三角形，5 脚名称是「正」、6 脚是「负」、7 脚是 OUT2；5、6 脚名称同样要调出来。

    * > **易错点**：两个部件的三角形面积大小必须调成一样，否则画原理图时会发现非常别扭。

    * 使用时选封装会看到分为两个部件，拉出第一个就是 Part A，再选第二个 Part 就是第二个比较器。
