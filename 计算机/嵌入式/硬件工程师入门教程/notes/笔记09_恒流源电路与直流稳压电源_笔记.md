# 恒流源电路与直流稳压电源

## 恒流源的输出天花板

* **运放最大输出电压限制最大负载**

    * > **定义**：电路里输出的最高电压被运放的最大输出电压卡死，再往上是被三极管的 $V_B$ 死死限制住的。

    * 运放拿 12V 供电，最多只能把 12V 吐出来，负载端电压最高只能到 11V 附近。

* **运放最大输出电流限制恒流值**

    * > **定义**：卡死恒流值的往往不是电压，而是运放能吐出的电流。

    * 三极管是电流控制电流型器件，集电极电流由基极电流决定，$I_C = \beta \times I_B$；恒流源里负载电流几乎全部从 $I_C$ 过来。

    * 输出 1A 且 $\beta = 100$ 时，$I_B$ 至少要 10mA；输出 10A 时 $I_C$ 到 10A，$I_B$ 就是 0.1A 也就是 100mA。

    * 基极电流是放大电流之后的量，恒流值越大，对运放输出电流的要求成倍往上翻。

    * 常见运放最大输出电流也就 50mA 上下，专门做信号放大的可能只有十几毫安。

    * 两个天花板各管一头：输出电压管最大负载，输出电流管恒流值。

    * > **易错点**：这正是很多人算完觉得电路没问题、一上电就发现根本不工作的根因。

* **LM358 实测到的电流墙**

    * 用 24V 供电，20V 那一档负载仿真出 1A，没问题。

    * 把负载电阻往下调十倍想给出 10A，实际输出根本没有 10A，只有 2A，运放输出电流只有 19.3mA。

    * 负载改成 1Ω 再看，电流上来到 6 安多，但离 10A 还差一截。

    * 关键在于这一次运放输出电压并没有饱和，只有 9V 多，理论上完全能到 20 多伏，卡住的是输出电流。

    * 运放输出电流量到 40.6mA，这就是 LM358 的最大输出电流，它不能再大了，整个恒流源最后只停在 6A 附近，再怎么调负载电阻也没有用。

### 拆掉这堵墙的两条路

* **换一颗吐得动电流的运放**

    * 把 LM358 换回理想运放，顺带把模型参数调一下：输出电阻改成 1Ω，电源改成 24V。

    * 重新仿真电流老老实实到了 10A，运放输出的 $I_B$ 正好是 101mA，与纸上算的 10A、$\beta=100$、要 100mA 几乎一模一样。

    * 公式是准的，LM358 给不了只是它自己弱。

* **加一颗三极管组成达林顿管**

    * 运放先控制第一颗三极管，再用第一颗的集电极电流去驱动第二颗的基极。

    * 原本需要从运放抽的 100mA，先经一颗三极管放大 $\beta$ 倍之后，后一颗只需要 1mA 出头，所有电流压力由三极管替运放承担。

    * 保持 LM358 不动只加这一颗三极管，电流做到了 4A，而这时运放输出的电流连 1mA 都不需要。

## 判断反馈正负的万能方法

* **运放两条工作特性**

    * > **定义**：当 $V_+$ 大于 $V_-$ 时，运放输出 $V_{out}$ 往上走；当 $V_+$ 小于等于 $V_-$ 时，$V_{out}$ 往下走。

    * 负反馈推到最后一定是 $V_+ = V_-$，也就是虚短。

    * 正反馈推到最后 $V_+$ 不可能等于 $V_-$，运放输出只可能等于 $V_{CC}$ 或者 GND，直接怼到轨。

    * > **易错点**：拿到电路判断不出来是正反馈还是负反馈就别猜，用这条方法硬推。

    * 并非所有负反馈都一定要接反相端，有一些负反馈是会接到同相端的。

## 高端反馈恒流源（NPN）

```text
              +12V
               │
              1Ω   采样/负载电阻
               │
      ┌────────●─────────┐
      │        │ VR      │   ← 高端采样点
      │        │         │
      │    ┌───┴───┐     │
      │    │ NPN   │     │
      │    └───┬───┘     │
      │        E         │
      └────────┼─────────┘
               │
              GND

   运放：  V+ ← VR    （高端反馈接到同相端）
           V- ← Vref
           Vout ─→ NPN 基极
```

* **反馈接同相端的恒流源**

    * 特别之处在于反馈端不接反相端，接的是 V 正（同相端）。

    * 反馈电压由高端采样电阻分压取出：$V_R = 12\text{V} - 1\Omega \times I_C$。

* **Vref 未接时的稳态**

    * 上电瞬间假设所有节点都是 0V，12V 接进来而 Vref 还没进，这时 VR 就是 12V。

    * 此时 $V_-$（Vref）为 0、$V_+$（VR）为 12V，$V_+ > V_-$，运放输出往上走。

    * 输出走到 0.6V 时三极管导通，有电流从这一路下来，VR 开始往下掉，但掉不下去多少。

    * 运放走到 0.8V、三极管已完全饱和（假设饱和压降 0.3V）时，VR 也只能低到 0.5V 附近。

    * 实际仿真 VR 稳定在 6V 左右，也就是 12V 经两个电阻分压出来的值，原因是这一路串着采样电阻、回路电流大、压降就大。

    * 如果 Vref 一直不接进来，稳态就是 VR 稳定在 6V 左右，回路里始终挂着很大的电流，实测约 5.63A。

    * 此时运放输出顶到最大值约 12V，实际电路里还要额外加一个电阻做限流，这一条不能省。

* **Vref 接进来后的收敛过程**

    * Vref 从 0V 啪一下变成 11V，此时 $V_- > V_+$，运放输出往下掉。

    * 输出往下掉 → 三极管的 $I_B$ 减小 → 回路电流 $I_C$ 减小 → 采样电阻上的压降减小 → VR 上升。

    * VR 升到 11V 时 $V_+$ 和 $V_-$ 重新相等；一旦相等 $V_{out}$ 就要往下掉一点点，一掉 VR 冲过 11V 变成 11.001，$V_+$ 反超，输出又往上抬一点点。

    * 就这么来来回回自我调节，最终 VR 停在 11V，这是一个标准的负反馈收敛过程，收敛到虚短状态 $V_+ \approx V_- \approx 11\text{V}$。

    * 有了虚短，输出电流公式非常简单：$I_C = \frac{12\text{V} - 11\text{V}}{1\Omega} = 1\text{A}$。

    * 开关断开时 VR 稳在 6V 多、电流约 5.63A、运放输出顶到约 12V；开关闭合一瞬间 Vref 从 0 跳到 11V，运放输出往下压，VR 上升到 11V 稳住，电流随之从 6A 降到 1A。

## 闭环自激振荡与两条解法

* **振荡的根因与判据**

    * > **定义**：运放的控制速度比反馈速度快太多，反馈跟不上运放，它就振。

    * 更正式的结论：运放的增益大于 1、反馈的相位延迟达到 180° 时，就会出现振荡。

    * 振荡 = 环路增益太大 + 相位滞后，所以解法必然落在两头：要么让运放慢下来，要么让反馈快起来。

* **第一条路：把运放跑慢**

    * 回路里加一个电容把运放带宽压下来，这个电容叫积分电容；有了它运放输出电压的变化速度被压低，反馈就追得上。

    * 换增益带宽积（GBW）的运放同样有效：100MHz 的运放在这个电路里会振，换成 0.1MHz 就不振了。

    * 换成 1MHz 的话前面还会振一点点，但最终能稳住，这说明环路的相位裕度不够，靠系统的阻尼慢慢收敛。

    * 只有当运放带宽高到 100MHz 这个量级、速度非常快的时候，它才会在这个反馈结构下激发出振荡。

* **第二条路：把反馈拉快**

    * VR 从 6V 慢慢升到 11V 靠的是运放输出下降 → $I_B$ 减小 → $I_C$ 减小 → 采样电阻压降减小，所以反馈速度实际上是被三极管的关断速度决定的。

    * 三极管关得越快，VR 涨得越快。

    * 换三极管型号：相同工艺下电流额定值小的三极管开关速度通常更快；只换一颗管子、其它全不动跑仿真对比，原型号在振，换过的不振。

    * 加快反馈路径：在反馈线上串一个分压电阻，再在这个电阻上并一个电容，构成反馈补偿；光加电容不够，必须配分压电阻，反馈电容才能真正加速电压的反馈。

    * 加了分压电阻之后反馈量会产生两倍放大，所以原边这一侧的电压要相应减掉一半。

    * > **易错点**：单靠反馈补偿救不回来时，正确做法不是继续硬调反馈网络，而是老老实实把运放带宽压下来；反馈网络能改的幅度有限，运放的速度才是矛盾的源头。

    * 只调反馈网络时问题并未解决，原因是这一侧三极管的开关速度本身就不够高，最后还是回到第一条路，把运放带宽适当压一点比如加 10pF，VR 不振了，电流回到约 1A，控制环路彻底稳住。

## 负载必须接地时的 P 管高端反馈

```text
              +12V
               │
              1Ω   采样/负载电阻
               │
      ┌────────●─────────┐
      │        │ VR      │   ← 以发射极作为反馈点
      │        E         │
      │    ┌───┴───┐     │
      │    │ PNP   │     │
      │    └───┬───┘     │
      │        C         │
      └────────┼─────────┘
               │
              GND

   运放：  V- ← VR    （反馈接回反相端）
           V+ ← Vref
           Vout ─→ PNP 基极
```

* **换成 P 管的原因与反馈逻辑**

    * 前面那个高端反馈电路输出还是从集电极出去的，有些场合负载必须接地、输出根本没法接在中间，那就得把 N 管换成 P 管。

    * 发射极作为反馈点是没有反向作用的，所以这个负反馈只要接回反相端就够了，即 Vref 接 V+、VR 接 V-。

* **上电瞬间的追赶过程**

    * 三极管还没开通时 Vref 是 11V，VR 因为没电流停在 12V，于是 $V_- > V_+$，运放输出往下走，但它一开始本来就是 0V，往下也走不了哪儿去。

    * 因为基极被拉低、发射极在 12V 这一侧，电流立刻灌下来，VR 从 12V 开始往下掉。

    * VR 往下掉的同时运放输出也在往上走，因为运放内部有输出阻抗，不可能一边输出停在 0V、一边让三极管去承受整整 12V 的压差。

    * 于是出现一个追赶：VR 从 12V 掉到 11.9V 的过程中运放输出可能已经蹿到 8V，但 $V_-$ 依然大于 $V_+$，VR 继续往下走，运放继续往上走。

    * 一直走到 VR 下降穿过 11V 的时候，运放输出那边却被三极管的大电流拉到了 10.3V，停住了。

    * 这个 10.3V 是被 $V_{BE}$ 钳位的结果，不是运放主动往上推的；$V_-$ 一直大于 $V_+$，运放的输出方向是被往下压的，真正把它拉上去的是基极电流从三极管灌进运放输出引脚的那股力，$11 - 0.7 = 10.3$。

    * VR 停在 11V，Vref 也是 11V，$V_+ = V_-$，虚短成立，环路锁死。

    * 之后过程和 N 管版一样只是极性反过来：输出稍微往下走一点点 → $V_{BE}$ 增大 → $I_C$ 增大 → 采样电阻压降增大 → VR 往下掉一点点 → $V_{+}$ 又反超 → 输出再往上抬一点点，最终停在平衡点。

* **上电瞬间的脉冲电流**

    * 仿真里加电流探头看到刚上电那一瞬间运放的电流是负的，电流从 12V 经 1Ω、再经三极管灌回运放那一端，运放在拼命吸收它，峰值能到 -2A 左右。

    * 随着 VR 慢慢上升、运放主动介入控制，这个电流被压下来，后面变得非常非常小。

    * > **注意**：这个脉冲只在两边同时上电、两边一开始都是高压时才会出现；如果 VR 那一路是缓慢上升的，就不会有三极管的竞争，也不会有这个大脉冲；但脉冲电流再大，上限也就是运放能灌的那点电流，实际电路里这里一定要再加一个限流电阻。

    * 知道它是负反馈后，输出电流公式回到老样子：$I_C = \frac{12\text{V} - V_{ref}}{1\Omega}$，$V_{ref} = 11\text{V}$ 代进去就是 1A。

## 带反馈的直流稳压电源

```text
              +12V
               │
             （负载）
               │
      ┌────────●─────────┐  Vout
      │        C         │
      │    ┌───┴───┐     │
      │    │ NPN   │     │
      │    └───┬───┘     │
      │        E         │
      │   运放输出经 1k   │
      │      接到基极     │
      │        ●  V-     │
      │      1k + 1k     │
      └────────┼─────────┘
               │
              GND

   运放：  V+ ← Vref      V- ← 分压点
```

* **带反馈方案的本质**

    * 带反馈的方案本质上就是一个运放，所以只要运放原理都搞定了，分析这一系列直流稳压电源就非常简单。

    * 回路里明显有一条负反馈路径，可以直接用虚短虚断分析：虚短给出 $V_+ = V_- = V_{ref}$。

    * 虚断给出运放输入不吸电流，分压支路可以化简成一个干净的分压器：Vout 下来一个 1k，再下来一个 1k 到地，中间那个点就是 $V_-$。

    * 分压公式 $V_- = V_{out} \times \frac{1\text{k}}{2\text{k}} = \frac{V_{out}}{2}$，两边一合得 $V_{out} = 2 \times V_- = 2 \times V_{ref}$。

    * $V_{ref} = 1.25\text{V}$ 时输出就是 2.5V。

* **从运放工作特性推 2.5V 的由来**

    * 起点是上电时几个点都为 0V，12V 接进来 $V_{ref}$ 立刻变成 1.25V，此时 $V_+ = 1.25$、$V_- = 0$，运放发现 $V_+$ 大，输出往上走。

    | 运放输出 | 输出节点（减 $V_{BE}$） | 分压后 $V_-$ | 谁大 |
    | :--- | :--- | :--- | :--- |
    | 0.6V | 刚好开始导通，节点仍为 0 | 0 | $V_+$ |
    | 1.0V | 0.4V | 0.2V | $V_+$ |
    | 2.0V | 1.4V | 0.7V | $V_+$ |
    | 3.1V | 2.5V | 1.25V | 相等 |

    * 上表是忽略基极到 Vout 之间限流电阻压降的理想推演。

    * 规律很清楚：只要 $V_-$ 还追不上 $V_{ref} = 1.25\text{V}$，输出就一直往上走。

    * 输出走到 3.1V 时输出节点为 $3.1 - 0.6 = 2.5\text{V}$，分压下去正好 1.25V，此刻 $V_+ = V_-$。

    * 运放一往下走到 3.0999V，输出节点变成 2.4999999V，分压后比 1.25V 少那么一丁点，运放立刻又发现 $V_+$ 大于 $V_-$，输出再往上抬一点点，如此往复最终平衡在 2.5V。

    * 仿真里 $V_{ref}$ 稳定在 1.25V，输出侧会出现过冲最高冲到 3V 多，原因是上电那一瞬间因为 $V_+ > V_-$ 运放一瞬间就冲到了比较高的电压，之后从 3V 多开始慢慢往下压直到 2.5V 就稳住了。

    * 真实电路里这个过冲要留意，负载如果对过冲敏感，就得在设计时把启动过程考虑进去。

## 不带反馈的直流稳压电源

* **开环稳压电路的构成与原理**

    * 不带反馈就不需要用运放，只需要一个稳压管、一个三极管、两个电阻和电容就能实现直流稳压。

    * 核心是两条：三极管只要导通 $V_{BE}$ 压降就约等于 0.6V 或 0.7V，这里假设等于 0.6V；$V_{BE}$ 近乎固定，把基极电压 $V_B$ 控制住，输出端的 $V_E$ 就被控制住了。

    * 基极电压靠一颗稳压管控制：稳压管只要导通，它两端的电压基本上就是一个恒定值。

    * 具体数：用 5.6V 的稳压管，输入 12V，12V 经电阻 $R1$ 后稳压管肯定击穿，节点电压变成 5.6V，基极等于 5.6V，发射极就等于 $5.6 - 0.6 = 5\text{V}$，输出被钉在 5V 上。

    * > **定义**："不带反馈"指的是这条电压链路上没有任何东西去回头看输出端的实际电压，它是一条纯粹开环的通路。

```text
   12 V ──[R1]──┬──► Q1 基极 (NPN)
                 │        │
                 │        └──► 发射极 ──┬──► Vout ≈ 5 V ──┬──► 负载
                 │                     │                  │
              [DZ 5.6V]             [C1] ────────────────┘
                 │
                GND
```

* **线性稳压的效率困境**

    * 三极管的 $V_{CE}$ 不等于饱和状态的 0.3V，它等于电源电压 12V 减去输出电压 5V，也就是 7V，调整管会承受 7V 的电压。

    * 负载取 5Ω 时回路电流为 1A，三极管功耗等于 $7\text{V} \times 1\text{A} = 7\text{W}$。

    | 能量去向 | 数值 | 是否有用于 |
    | :--- | :--- | :--- |
    | 电源输入 | $12\text{V} \times 1\text{A} = 12\text{W}$ | —— |
    | 负载上拿到 | $5\text{V} \times 1\text{A} = 5\text{W}$ | 有用功 |
    | 三极管上发热 | $7\text{V} \times 1\text{A} = 7\text{W}$ | 全部是有害功 |

    * 线性稳压电源工作效率就是这么低：三极管主动把电源输出多余的那部分能量全部承载掉，全部变成了热。

## 带反馈与不带反馈的对比

* **差别在输出点的稳定性**

    * 两者最大的区别在于稳定性，这里的稳定性不是指瞬态稳定，指的是输出点的稳不稳。

    * 仿真里让两者输出都设为 5V：带反馈的输出确实是 5V，是个很标准的 5V；不带反馈的不是等于 5V 而是约等于 5V，实测为 5.2V。

    * 原因之一是稳压管有偏差：标着 5.6V 的稳压管实际稳出来有可能等于 5.5V，也有可能等于 5.7V。

    * 原因之二是三极管的 $V_{BE}$ 导通压降本身有区别，而且会跟着工作电流变：

    | 三极管工作电流 | $V_{BE}$ 压降 |
    | :--- | :--- |
    | $1\text{mA}$ | 约 $0.5\text{V}$ |
    | $5\text{mA}$ | 约 $0.6\text{V}$ |
    | $10\text{mA}$ | 约 $0.7\text{V}$ |

    * 换掉负载之后差别被放大：带反馈的输出依旧还是 5V，不带反馈的由 5.2V 变成 5.083V。

    * > **提示**：开环状态相当于一个瞎子，自己觉得后面就是 5V，但实际上是不是 5V 它并不知道；带反馈相当于控制大脑里想着"输出要等于 5V"，并且有一只眼睛去观测，输出小了就把基极抬高一点，输出大了就调小一点。

    * 稳压管和 $V_{BE}$ 这些"看起来差不多"的偏差，在开环状态下没有任何东西去纠正它们。

    * 希望输出更稳定，电路里就必须让它变成一个负反馈系统，因为负反馈系统可以实时自我调节。

* **带反馈的眼睛怎么转**

    * 用 5V 给 1kΩ 供电，电流很小等于 5mA，流过三极管的 $I_C$ 也就约 5mA；假设 $I_C$ 等于 5mA 时 $V_{BE}$ 等于 0.5V，等于 500mA 时 $V_{BE}$ 等于 0.8V（$V_{BE}$ 随 $I_C$、$I_B$ 变，当然还跟温度相关）。

    * 开关闭合前输出已经是 5V 的稳态，此时运放会自动把自己的输出电压调到 5.5V 左右：刚上电时运放"+"端是 0、"−"端是 2.5V，$V_+$ 比 $V_-$ 大，输出从 0 慢慢往上升。

    * 升到 0.5V 时三极管开通导通；继续升到 1.5V 时输出电压是 1V，1V 反馈回分压点变成 0.5V，它还会继续往上升；当刚好升到 5.5V 时输出等于 5V，分压点刚好是 2.5V，于是自动形成稳态。

    * 突然挂一个 10Ω 负载进来，电流从 5mA 变成约 500mA，$V_{BE}$ 立刻变成 0.8V，开关合一瞬间输出从 5V 掉到 4.5V。

    | 时刻 | $I_C$ | 运放输出 $V_B$ | 输出 $V_{out}$ | 分压点 | 运放动作 |
    | :--- | :--- | :--- | :--- | :--- | :--- |
    | 稳态 | $5\text{mA}$ | $5.5\text{V}$ | $5.0\text{V}$ | $2.5\text{V}$ | 平衡 |
    | 接入 $10\Omega$ | $5\text{mA} \to 500\text{mA}$ | $5.6\text{V}$ | 掉到 $4.5\text{V}$ | $< 2.5\text{V}$ | $V_- < V_+$，上调 |
    | 第一次修正 | $500\text{mA}$ | $5.6\text{V}$ | $4.8\text{V}$ | $2.4\text{V}$ | 仍不够，再上调 |
    | 第二次修正 | $500\text{mA}$ | $5.8\text{V}$ | $5.0\text{V}$ | $2.5\text{V}$ | 重新稳态 |

    * 带反馈的好处就是可以实时去监测输出到底够不够，够了就停，不够就增加一点，太大了就减小一点点。

* **不带反馈为什么纠正不了**

    * 把稳压管当成理想稳压管，它一直就等于 5.6V。

    * 带载一开始是 1k，压降是 0.5V，默认状态下就是一个 5.1V 的输出。

    * 突然加一个 10Ω 负载进来，电流从 5mA 变成 500mA，$V_{BE}$ 从 0.5 变成 0.8，输出就从 5.1V 往下降到 $5.6 - 0.8 = 4.8\text{V}$。

    * 这个 4.9 和 4.8 的差别正是初学者容易自己算懵的地方：稳压管钉死的是基极不是输出，输出永远等于稳压管电压减去当时的 $V_{BE}$，$V_{BE}$ 一变输出就跟着掉。

    * 降到 4.8V 之后稳压管并不知道，它像躺平的工作人员一样按了个 5.6 在这里就不管后级到底是多少，所以这种开环状态的输出肯定没有这么稳定。

## 最原始的开关电源模型

* **一个开关、一颗电阻、一颗电容**

    * 开关电源有 Buck、Boost、反激、Buck-Boost 等类型，只要具备开关特性都可以称为开关电源；降压型的就是 Buck。

    * 最原始的模型是 12V 接一个开关，下来加一个电阻再加一个电容，这就是最简单的开关电源拓扑结构。

    * 先假设人就是那个控制电路：输出端接万用表，开关一闭合电容像电池一样被充电，电压慢慢最终充到等于电源电压。

    * 开关一直闭合的话输出电压从 0 最终充到 12V；但想要降到 5V，就盯着万用表：小于 5V 就闭合，闭合后电压慢慢往上升，升到 5V 就断开。

    * 断开之后输出维持在 5V 不变；带上负载后闭合到 5V 断开、电压往下掉，掉到 4.9V 再闭合，冲到 5.1V 左右又断开，来回往复最终输出电压在 5V 上不停抖动。

    * 仿真验证：12V 加开关加电阻加电容，示波器测输出点，什么都不控、开关闭合就一路充，最终肯定冲到 12V；想降压就闭合，升到 5V 断开，它就维持在 5V 附近不变。

    * 再加一个 100Ω 负载：升到约 5V 时断开，断开往下掉，再闭合、升到 5V 再断开，来回往复输出就约等于 5V。

    * > **结论**：这是开关电源最核心的控制思维——我通过一个开关让输出端的能量分批地到达后级，这样就可以控制输出电压的最大值，这和线性稳压把多余的电压压在三极管上烧掉是完全相反的思路。

```text
Vout
12 V ┤        ─────────────────────  不做任何控制，一口气充到 Vin
     │
 5 V ┤    ╭─╮   ╭─╮   ╭─╮         带负载来回切换，抖在 5 V 上
     │   ╱   ╲ ╱   ╲ ╱   ╲
 0   ┼──╯     ─       ─     ─
     └─────────────────────────── t
```

## 把电阻换成电感

* **电阻带来的效率困境**

    * 研发开关电源主要就是为了研发出高效率的降压电路，而电阻会对转换效率产生非常大的影响。

    * 所有电源给后级提供能量都肯定会经过这个电阻，既然有电阻它就肯定会耗能，换成开关结构虽然能降压但耗能会非常高，脱离设计初衷。

* **电阻为什么不能直接去掉**

    * > **易错点**：电阻在这里的作用不是用来耗能，而是给控制电路争取反应时间；电阻就是控制电路的时间预算，一去掉时间预算就没了。

    * 理想状态下把电阻去掉效率确实可以做得非常高，但实际上去掉后不可能实现降压功能。

    * 因为电阻去掉后开关一闭合，12V 给后级电容充电的回路充电电阻 $R$ 变得非常非常非常小。

    * 充放电跟充电时间常数有关：$\tau = R \times C$，$R$ 极小就意味着电容充电速度非常非常快。

    * 于是开关一闭合，电压"唰"一下就从 0 冲到 12V，来不及把开关断开就已经冲到 12V，还怎么控制降压。

    * 仿真里把电阻改成 0Ω，一闭合瞬间输出就已经冲到 12V，哪有时间来把开关断开。

    * 结论是：去掉电阻理论效率确实可以非常高，但对控制电路的速度要求就非常高，而几乎所有控制电路都不可能满足这个条件。

* **换成电感同时解决两个问题**

    * 电感跟电阻有一个非常不同的特点：电感它是不耗能的，电感和电容都是储能器件，理想状态下都不耗能。

    * 电感的电流 $I$ 是不突变的。

    * 加电阻时它限制充电速度，控制电路的要求非常低，随便一个速度快一点点的控制电路都能完成，但坏处就是效率很低。

    * 换成电感后同样能限制电流，电流被限制就意味着电容电压的变化速度也被限制，同时电感还不耗能，一举两得。

    * 人在外面控制这个开关一下子就变得非常简单，这是把电阻换成电感这个替换非常巧妙的地方。

## 续流二极管

* **电感电流不突变带来的新麻烦**

    * 电感的电流不突变解决了电容电压突变的问题，但这件事本身会带来新麻烦。

    * 刚上电时输出为 0，开关闭合，12V 给输出电容充电，电压越来越高，电感电流也从 0A 慢慢往上升。

    * 输出升到约 5V 时要断开开关，假设断开的一瞬间电感电流等于 1A 左右。

    * 开关啪一下断开后电感一开始的电流回路没有了，没有回路就相当于电感上电流回路的电阻发生了突变。

    * 电感的回路电阻是一定不能发生突变的，发生突变会感生出一个非常大的电压，这个电压很轻松就能把开关击穿。

    * 电感在工作过程中会感生出很大的电压，而这个感生电压就是因为开关断开、电感回路电阻发生突变导致的。

* **续流二极管的作用**

    * > **定义**：这个二极管叫续流二极管，它唯一的作用就是给电感提供一条电流不会断掉的回路。

    * 加上之后升到 5V 断开开关，电感因为电流不能突变要把能量释放掉，发现原支路走不通时会找到这个新支路进行续流，有了完整的续流回路就不会产生高压。

    * 换个更狠的角度：不加这个寄生二极管，开关断开的一瞬间电感会强制把能量释放出去，而释放过程其实是对开关的寄生电容充电。

    * 寄生电容的容值非常非常小，电感上的能量转移到它上面时电容两端就会产生一个很高的电压。

    * 如果开关不是理想开关，比如说是 MOS 管，它很轻松就可以被击穿。

* **仿真里的尖峰**

    * 把电阻换成电感重新仿真，开关闭合时输出电压慢慢往上升而且上升得越来越快，上升到 5V 时断开。

    * 刚才看的只是输出电容两端的电压所以确实没看到高压，但把示波器移到开关两端去观察就完全不一样了。

    * 幅值刻度提高到 5000V 每格时，这一个尖峰直接超过了 5000V 还超了很多，大概 1.2 格左右，也就是接近 6000V。

```text
V_sw（开关两端电压）
   ↑
   │   ╷  尖峰 ≈ 1.2 格 × 5000 V/格 ≈ 6000 V
   │   │
12 V┤───┘ └─────────────────  常态就是 Vin 的量级
   │
 0 ┼───────────────────────── t
       开关断开的那一瞬间
```

    * 实际电路中可能不会这么高，但搞个几百伏出来还是一个很简单的问题，如果这里是 MOS 管或者三极管，它坏不坏。

    * 加一个二极管之后重新仿真：断开之后开关两端的电压也会上升，因为这时 SW 节点被续流二极管拉到了输入电压那一侧，但刻度才 5V 每格，没有那个尖峰了。

## Buck 拓扑与实际电路的对应

* **Buck 拓扑结构的来源**

    * 把"小人"删掉、把万用表删掉、把负载删掉，就得到完整的 Buck 拓扑；它不是天上掉下来的，是从一个开关、一颗电阻、一颗电容改出来的。

```text
                   Vin = 12 V
                      │
                   ┌──┴──┐
                   │ Cin │   输入电容
                   └──┬──┘
                      │
        ┌─────────────┴─────────────┐
        │          SWITCH           │  ← VIN → SW，集成在芯片内
        └─────────────┬─────────────┘
                      │
        ┌─────────────┼──────────────┐
        │             │              │
     ┌──┴──┐      ┌───┴───┐      ┌──┴──┐
     │ GND │      │   L   │      │     │
     └──┬──┘      └───┬───┘      │ Cout│  输出电容
        │             │          └──┬──┘
        └─────────────┴──────┬──────┘
                              │
                           Vout ≈ 5 V
                              │
                           ┌──┴──┐
                           │ 负载 │
                           └──┬──┘
                              │
                             GND
```

* **拓扑元件在芯片里的位置**

    * 实际电路由专用芯片控制，开关本身不需要人控制；打开一个 12V 降到 5V 的电机控制电路项目可以看到它整体内部结构就是刚画的这个结构。

    | 拓扑图里的部件 | 在实际电路中的位置 |
    | :--- | :--- |
    | 开关 | 芯片内部，VIN → SW 之间，外部看不见 |
    | 续流二极管 | 芯片内部，集成在 GND 与 SW 之间 |
    | 输出电容 | 板上有两个并联的输出电容 |
    | 电感 | 芯片外部，板上的那颗电感 |
    | "控制电路"（那个小人） | 芯片本体，靠两颗反馈电阻分压采样替代万用表 |

    * 芯片本身充当控制电路、充当"人"的角色；人靠万用表观测输出，芯片则通过两个电阻分压采样把信号送进去，再给内部电路做控制。

    * 分立 Buck 与分立 Boost 项目是把芯片内部结构完全搭建出来的，做完之后再分析开关电源、或用集成芯片设计制作开关电源就会非常简单。

* **降压型开关电源的完整周期**

    * 控制芯片外接两颗反馈电阻将采样信号反馈给芯片，芯片内部的驱动电路去控制开关管，开关管可能是 MOS 管也可能是三极管。

    * 上电时芯片先通过分压电阻检测输出电压，目标是 5V 就判断当前输出是否达到 5V；检测到小于 5V 就让开关导通闭合，或者说让驱动 MOS 管的 PWM 占空比变大。

    * 占空比增大后输入 12V 给后级回路提供的能量越来越多，输出电压逐步上升；上升到 5V 左右时达到平衡，芯片输出占空比进行微调，最终维持在动态平衡状态。

    * 开关导通闭合时电流路径分为两条：一路给电容充电储能，一路给负载供电。

    * 开关断开的一瞬间电感通过续流二极管构成回路续流放电；电感储能释放完毕后，由输出滤波电容持续给负载提供能量。

```text
开关导通（能量向后级输送）
  Vin ──► 开关 ──┬──────────────► 负载
                  │                  ▲
                  └──► Cout 充电储能 ─┘

开关断开（电感 + 电容接力）
  Vin   断开
   │
  SW ●──► D ──► 续流回路：L → Cout → 负载 → GND
   │
   └────► L ────► Cout ────► 负载 ────► GND
   （电感储能释放完毕后，由 Cout 持续给负载供能）
```

    * 回头看开头那个 7W：线性稳压里多出来的电压是被三极管主动承载掉的，开关电源导通时多出来的电压根本没有被压在任何器件上，能量是被分批送到后级的。

    * 同样是一个 12V 降到 5V，差别只在于多出来的那部分是被烧掉还是根本不烧。
