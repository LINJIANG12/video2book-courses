# 比较器与运算放大器的虚短虚断

## 比较器的工作逻辑

* **比较器（Comparator）**

    * > **定义**：专门拿来做电压大小比较的器件，逻辑与名称一致——只比较两个输入电压谁大。

    * 符号外形接近运放，但三角形内部标的是一个大于号，而不是正负号。

    * 输入有两个：同相输入端 $V_+$ 与反相输入端 $V_-$；输出只有一个 $V_{out}$。

    * 判定规则：$V_+ > V_-$ 时输出高电平，$V_+ < V_-$ 时输出低电平。

    * 输出只有高、低两种状态，不做运算、不做放大。

    ```text
                              Vout
                               │
                               ▼
                        ┌──────────────┐
            V+ (同相) ─►│ +            │
                        │              │
            V− (反相) ─►│ −    比较器 ▷ │──►  高电平 / 低电平
                        │              │
                        └──────────────┘

            V+ > V−   ──►   Vout = 高电平
            V+ < V−   ──►   Vout = 低电平
    ```

* **实测电平参考**

    * 仿真中 $V_+ $ 接 3V、$V_- $ 接 1V，输出高电平，高电平约等于 VCC，实测约 4.8V。

    * 把 $V_- $ 改成 4V 后，输出低电平，实测约 0.2V。

    * > **结论**：比较器通过比较两个输入端电压的大小关系来决定输出电平高低，它只回答“谁大”这一个问题。

## 输出级结构与上拉电阻需求

* **推挽输出（Push-Pull）**

    * > **定义**：输出信号线内部接两个开关，一个接到 VCC、一个接到 GND，前面由一大堆控制逻辑电路驱动。

    * 逻辑发现 $V_+ > V_-$ 时让上管闭合，信号线等于 VCC 电压。

    * 逻辑发现 $V_- > V_+$ 时上管断开、下管闭合，输出线与 GND 短路，得到低电平。

    * 能主动输出高低信号线电平，不需要加上拉电阻。

    ```text
                  控制逻辑（比 V+ 与 V−）
                            │
              ┌─────────────┴─────────────┐
              │                           │
          VCC─┤上管                      下管├─GND
              └──────┬──────────────┬─────┘
                     │              │
                     └──────┬───────┘
                            │
                           Vout

     V+ > V−  ─►  逻辑让「上管」闭合  ─►  Vout = VCC（高）
     V− > V+  ─►  逻辑让「下管」闭合  ─►  Vout = GND（低）
    ```

* **开漏／开集电极输出（Open-Drain / Open-Collector，OD / OC）**

    * > **定义**：输出端内部只有一个接到 GND 的开关，没有接到 VCC 的开关，即开漏输出。

    * 开关闭合时信号线与 GND 短路，$V_{out} \approx 0\text{V}$。

    * 开关断开时，信号线接的是后级电路，后级输入阻抗非常非常大。

    * 想在高电平时拿到电平必须外接上拉电阻，否则内部根本没有接到 VCC 的开关去驱动它。

    * 分压验算：后级输入阻抗 10MΩ、上拉电阻 1kΩ 时，$V_{out} = V_{CC} \times \frac{10\text{M}\Omega}{10\text{M}\Omega + 1\text{k}\Omega} \approx V_{CC}$。

    * > **提示**：上拉电阻不是在“帮比较器输出高电平”，它是在**替**比较器把那条线往上拉；开漏输出的高电平，本质是“没人管它，所以它被电阻拉到了 VCC”。

    ```text
        VCC ──[ Rp 上拉电阻 ]──┬──── Vout ──► 后级输入
                               │
                          下管（只有一个）
                               │
                              GND

     下管闭合：信号线与 GND 短路  ─►  Vout ≈ 0V（低）
     下管断开：Rp 与后级输入阻抗分压 ─►  Vout ≈ VCC（高）
    ```

* **去数据手册确认而不是猜**

    * > **提示**：判断要不要加上拉电阻不要靠背型号，掀开数据手册看内部结构图，看输出端到底有几个开关，一眼就明白。

    * LM393 的内部结构图中 $V_{out}$ 只有一个发射极接 GND 的三极管，属于这种结构。

    * 另一颗芯片的输出内部上面一个 P 管接 VCC、下面一个 N 管接 GND，两个开关齐全，不加上拉电阻也能输出高低电平。

    * 同一组仿真对比：两颗芯片 $V_+ $ 都是 2V、$V_- $ 都是 1V，理论都该输出高电平，实际一颗直接是高电平，另一颗是低电平；给后者加上拉到 5V 的上拉电阻后两者都升到高电平。

    * 输出低电平时没有差异：把两边的 $V_- $ 都设成 3V，两边都是低电平。

## OC 与 OD 的区别

* **命名来源**

    * > **定义**：OC 与 OD 的结构其实完全一样，差别只在内部工艺不同、输出端取的管脚不同。

    * 三极管工艺：以三极管的**集电极**作为输出，集电极没接任何东西，open 的集电极简写为 OC。

    * MOS 管工艺：管子一般是 NMOS，输出接到管子的**漏极**，对应 open drain，简写为 OD。

    | 内部工艺 | 输出取的管脚 | 叫法 | 要上拉？ |
    | :--- | :--- | :--- | :--- |
    | 双极型（三极管） | 集电极 (C) | OC | 是 |
    | MOS 管（NMOS） | 漏极 (D) | OD | 是 |
    | 上管 + 下管 | 直接输出 | 推挽 | 否 |

* **判断依据**

    * > **易错点**：⚠️ OC 和 OD 是同一个问题的两种叫法，不是两种不同的行为，判断依据只有一个——数据手册里的内部结构图。不要去背“某颗芯片是 OD、某颗是 OC”，工艺换了叫法就换，但设计动作一样：都得加上拉电阻。

## 推挽输出上加上拉电阻的取舍

* **为什么有人加**

    * 信号线上的每一个电平变化，本质就是对信号线上的**寄生电容**做一次充放电。

    * 从低电平跳到高电平，对应 VCC 给寄生电容充电；开关断开变回低电平，对应寄生电容经开关放电。

    * 没有上拉电阻时充电路径只有一条；加上之后多出一条充电路径，等效充电电阻减小，**上升速度更快**、传输速度更高。

    ```text
        VCC ───────────┐
                       │      Vout ──── 负载 / 后级
        ┌──────────┐   │        │
        │  下管     │   │      ─┬─  寄生电容 Cp
        └────┬─────┘   │       │
             └──────────┴───────┘

     开关闭合  ─►  Cp 由 VCC 充电  ─►  上升沿
     开关断开  ─►  Cp 经下管放电  ─►  下降沿
    ```

* **代价与限值**

    * > **注意**：加上拉电阻后即使输出已经到 0V，仍有电流持续流过上拉电阻，会**增加低电平的损耗**；没有上拉电阻时电容放完电流就断了。

    * 上拉电阻不能随便取小：阻值越小上升沿越快，但低电平时流过电阻的电流随阻值减小而增大。

    * 电流上限由比较器的最大吸收电流决定，数据手册里的“低电平输出电流”就是吸收电流，LM393 约为 6mA。

    * 约束式：$I = \frac{V_{CC} - V_{OL}}{R_p} < 6\text{mA}$。

    * 同系列不同版本差别明显：LM2903 的这一电流能达到 21mA，LM393 的 B 版本也能达到更大的值。

    * > **提示**：取值要**折中**——先满足由上升速度决定的传输速度，再保证低电平时流过上拉电阻的电流不超过开关的最大吸收电流。

## 输入信号范围与越界表现

* **范围约束**

    * > **定义**：比较器的输入信号是有范围的，不是任意取值都能正常工作。

    * 一般来说，比较器与运放的输入信号尽量不要超出供电电源范围。

    * 0 到 5V 单电源供电时，尽量不低于 0V 也不高于 5V；高于 5V 一点点一般没事，允许的超出量大约是一个二极管压降。

    * 容许区间：$V_{IN,min} \geq -0.7\text{V}, \qquad V_{IN,max} \leq V_{CC} + 0.7\text{V}$。

    * > **易错点**：⚠️ 给一个 3.3V 供电的比较器接上 $\pm 5\text{ V}$ 的信号——输入电压跑出供电范围，内部工作点就废了，不要随便越界。

* **越界时的现象**

    * $V_- $ 经电阻接地为 0V，输入有效值 2V 的正弦波，理论上正半周输出高电平、负半周输出低电平。

    * 实测正半周确实是高电平，但从正半周切到负半周后，低电平维持不住：当输入电压低于 -0.7V 时会变回高电平。

    * 换成交流源 $1\text{ }V_{pp}$（即 $\pm 1\text{ V}$）单独仿真时，同样能看到输入负压小到 -6V 时输出翻回高电平。

    * 把供电改成 -5V 就恢复正常：正半周高电平、负半周低电平，且低电平等于 -5V，因为低电平时下管与 $V_{EE}$、$V_{SS}$ 供电端短路。

## 颤振的成因与回滞

* **颤振**

    * > **定义**：输入信号在阈值附近时，输出在高低电平之间反复抖动几下才稳定下来的现象。

    * 典型场景：输入正弦波 0 到 2V、参考电压 1V，本应大于 1V 输出高电平、小于 1V 输出低电平，实测两个跳变沿上都抖好几下才稳定。

    * 成因是多重噪声叠加：参考信号上有噪声、输入信号上有噪声、电源也带噪声；此外比较器还有一个关键参数叫**偏置电压**，它会随电源抖动和输出电流突变而受影响。

    * 本质是工作过程中 $V_+ $ 与 $V_- $ 处于不稳定状态，在两者**交汇的那一个点**最容易抖起来。

* **回滞电路**

    * > **定义**：在参考点上加正反馈，让基准电压形成上下跳变的窗口，使比较信号尽快跳出震荡区域，这种电路称为回滞电路，做出来的比较器称为回滞比较器。

    * 做法只有两个电阻：在参考点输入端串一个小电阻 $R_s $，再从输出反馈一个大电阻 $R_h $ 回到参考点。

    ```text
                              Vout
                                │
                         [ Rh = 100 kΩ ]
                                │
              ┌─────────────────┴─────────────────┐
              │                                   │
           [ Rs = 1 kΩ ]                    参考信号源 (1V)
              │                                   │
              └─────────────────┬─────────────────┘
                                │
                        参考点（同相端）
                                │
                               GND
    ```

    * 例：取 $R_s = 1\text{k}\Omega $、$R_h = 100\text{k}\Omega $，颤振消失，两个跳变沿都不再抖。

    * 机理：输出从低电平变高电平时，参考点电压会从 1V 直接抬到约 1.1V 的小台阶，而此时输入正在往下跳，信号因此尽快跳出震荡区。

    * > **提示**：回滞电阻一般取基准电阻的 100 倍；取完 100 倍**还有**颤振，就要把这个电阻往下调。

    * 噪声大时 $R_h $ 要往 $R_s $ 靠：噪声幅值达 100mV 时 100 倍关系压不住，10k 时回滞窗口变小、颤振变小，5k 时颤振窗口彻底消失。

    * 结论是电阻取值取决于**噪声的大小**：噪声越大，电阻越接近基准电阻，因为越接近时反馈量越大、回差窗口越大。

    ```text
       噪声小  ──►  Rh = 100 × Rs 就够，回滞窗口小，省电流
       噪声大  ──►  Rh 往 Rs 靠（10k → 5k），回滞窗口撑大才压得住
    ```

## 运放的常见作用

* **运算放大器（Operational Amplifier，运放）**

    * > **定义**：运放的中文全称是运算放大器，功能比常见基础元器件强大得多。

    * 常见用途是**信号处理**：信号放大、滤波、积分计算、微分计算、整流。

    * 更高级的用途是直接充当**电路的主控**。

    * 直流稳压电源项目里没有任何单片机，全部由运放作主控，利用**负反馈**实现自我调节，旁边配高端电流检测、过流保护等检测与保护电路。

    * 负载仪项目里两个运放同样承担主控作用，旁边对应电流、电压、温度检测电路；该项目同时预留了 MCU 控制版本，可二选一。

    * Buck 开关电源、Boost 开关电源等项目也都有讲解。

    * > **提示**：正因为功能强大，运放学起来比较复杂，后续需要靠大量实例来消化。

## 运放引脚与开环放大关系

* **五个引脚**

    * 两个供电引脚 VCC 和 GND。

    * 两个输入端：标正号的叫同相输入端 $V_+ $，标负号的叫反相输入端 $V_- $。

    * 一个输出端 $V_{\text{out}}$。

* **开环放大关系**

    * > **定义**：运放的开环放大关系为 $V_{\text{out}} = (V_+ - V_-) \times \text{Gain}$。

    * 运放的开环放大倍数非常大，动辄 10 万倍甚至 100 万倍。

    * 运放输出一定在电源范围以内，是个不大的数；即便假设它等于 12V，除以一个万级数字也约等于 0。

    * 把式子转个方向：$\frac{V_{\text{out}}}{\text{Gain}} = V_+ - V_-$，于是得到 $V_+ = V_-$。

    * > **提示**：这只是纯数学角度的解释，虽然简单，却总让人觉得欠了点什么，所以还要从物理本质上看这件事。

## 虚短的物理本质

* **追平特性**

    * > **定义**：虚短指运放正常工作过程中 $V_+ $ 与 $V_- $ 相等。

    * 内部电路发现 $V_+ > V_- $ 时，$V_{\text{out}}$ 往上走，往上走就是往电源端走。

    * 内部电路发现 $V_+ < V_- $ 时，$V_{\text{out}}$ 往下走，往下走就是往 GND 供电端走。

    * 虚短之所以成立，就是靠这条“追平”特性加上负反馈回路不断把反相端电压往同相端上拉，两股力量合起来把 $V_+ $ 和 $V_- $ 逼到相等。

* **一次 1V 跳变的跟踪过程**

    * 上电之前所有节点都等于 0V；突然上电并给 $V_{\text{in}} $ 加 1V，$V_+ $ 立刻变成 1V，而 $V_- $ 和 $V_{\text{out}} $ 此刻仍为 0V。

    * 从 $V_{\text{out}} $ 到 $V_- $ 是由 1kΩ 和 9kΩ 构成的分压网络，$V_- = V_{\text{out}} \times \frac{1k}{9k + 1k} = \frac{V_{\text{out}}}{10}$。

    | $V_{\text{out}}$ | $V_-$（分压后） | 运放内部看到的 |
    | :--- | :--- | :--- |
    | 0 V | 0 V | $V_+ > V_-$，继续往上升 |
    | 1 V | 0.1 V | $V_+$ 还是大，输出继续往上走 |
    | 5 V | 0.5 V | $V_+$ 还是大，输出继续往上走 |
    | 10 V | 1 V | 相等了，输出停住 |

    * 只有输出走到 10V 时 $V_- $ 才刚好等于 1V，两个输入端电压才真正相等。

    * 相等之后并不静止：输出若降到 9.9999V，分压得 0.99999V，$V_+ $ 又大于 $V_- $，输出再往上走，最终就在两个值之间不停自我调节，稳稳停在约 10V。

    * 示波器上：$V_+ $ 是阶跃跳变、没有过渡过程，$V_{\text{out}} $ 是慢慢往上冲，$V_- $ 通过电阻网络被拉到越来越接近 $V_+ $，最终两条曲线贴合。

    * 开关闭合前三个通道都约等于 0，其中那个很小的默认电压来自运放自身的 $V_{\text{OS}} $，可以忽略。

## 虚短成立的两个前提

* **前提一：一定要有负反馈回路**

    * > **定义**：只要反馈路径能让 $V_+ $ 与 $V_- $ 越来越靠近——不是越来越分散——这种反馈回路就叫负反馈回路。

    * 让 $V_- $ 能等于 $V_+ $ 的唯一原因，就是 $V_- $ 本身可以通过 $V_{\text{out}} $ 的变化去改变，这就是负反馈过程。

    * > **易错点**：⚠️ 没有负反馈回路的话 $V_+ $ 绝对不可能等于 $V_-$：$V_{\text{out}} $ 变化之后改变不了 $V_- $ 去靠近 $V_+ $，这两个电压凭什么相等。分析每一个电路都要先过这一关。

* **前提二：输出不能饱和**

    * > **定义**：运放的 $V_{\text{out}} $ 已经等于供电电压边界的状态称为饱和；0 到 12V 供电的轨对轨运放最大输出 12V、最小输出 0V。输出等于 0 那一侧严格说应叫截止，这里统称饱和。

    * 整个虚短是靠 $V_{\text{out}} $ 去调节 $V_- $ 实现的：$V_{\text{in}} = 1\text{V} $ 时必须 $V_{\text{out}} = 10\text{V} $，$V_- $ 才刚好等于 1V。

    * 把供电从 12V 改成 5V，输出最多走到 5V 就撞上边界再也上不去，$V_- $ 最多只能到 0.5V，虚短随即不成立。

    | 供电 | $V_{\text{out}}$ 最多走到 | $V_-$ 最多走到 | $V_+ $ 是 1V 时 |
    | :--- | :--- | :--- | :--- |
    | 12 V | 10 V | 1 V | 相等，虚短成立 |
    | 5 V | 5 V（撞上边界） | 0.5 V | $V_+ \neq V_-$，虚短不成立 |

    * > **结论**：只要工作在电压的边界值上，$V_+ $ 就不等于 $V_- $ 了，这是虚短成立的第二个基本条件。

## 虚断

* **电阻网络里的虚断**

    * > **定义**：相对于外部电路来说，可以认为运放的输入端口是一个断路状态。

    * 例子：5V 经两个 1kΩ 电阻串下来，中间点电压就是 2.5V。

    * 在下面那个 1kΩ 上并联一个 10MΩ，并联后总电阻基本还是约等于 1kΩ，中间点电压依旧约 2.5V。

    * > **定义**：在一个电阻网络里加进去一个很大很大的电阻，它对原有网络不造成任何影响，但它又真实存在——这时候可以单纯把它当成断路来看待，只不过不是真断路，所以叫虚断。

* **回到运放**

    * 运放的输入端对外部电路来说就是非常非常大的电阻。

    * 同相放大电路外面只挂一个 1kΩ，而输入电阻是兆级别，相对于外部电阻网络就相当于虚断。

    * $V_{\text{in}} $ 是 1V 时，$V_+ $ 这点电压也就约等于 1V。

    * > **提示**：从这里开始就可以把虚短虚断当成“虚拟开关”，把运放电路简化掉；简化之后就是纯电阻网络，剩下的事情全是欧姆定律和代数，复杂的部分交给运放内部，露在外面的电路看得清清楚楚。

## 分析运放电路的标准动作

* **铁律**

    * > **提示**：分析所有运放电路，分析之前一定要先判断它是否满足虚短、虚断这两个条件，只有满足之后才能用它们去分析。

* **第一步：判虚短**

    * 主要看有没有负反馈回路、且输出不饱和这两个条件。

    * 刚开始分析时一般先不管是否饱和，因为信号没进来之前无法预知会不会饱和。

    * 所以前期只看第一条：这个电路里有没有负反馈回路。

* **第二步：判虚断**

    * 条件是运放输入的偏置电流 $I_B $ 远远小于外部电阻网络上的电流。

    * 同相放大电路外部电阻网络都是 k 级别，肯定能满足；$V_+ $ 外面才一个 1kΩ而输入电阻是兆级别，更是绰绰有余。

    * 满足之后就可以放心用虚短虚断，把电路化成纯电阻网络。

## 同相放大电路推导

* **电路结构**

    * (−) 脚接在 9kΩ 与 1kΩ 的分压中点上，9kΩ 上端接输出，这是一条把输出引回反相端的负反馈路径；1kΩ 下端接地。

    * (+) 脚直接接 $V_{\text{in}} $。

    * 反馈条件满足，可以用虚短虚断分析。

    ```text
       Vin ────────► (+)                       out ──────┬────── Vout
                    │   \                        │        │
                    │    \  运放                 │     [9kΩ] R1
                    │    /                       │        │
                    (−) ──────────────────────────┼────────┤
                    │                             │
                   GND                           [1kΩ] R2
                                                   │
                                                  GND
    ```

* **推导步骤**

    * 先只用虚断做独立分析：$V_{in} = V_+$。

    * 再用虚断把输出侧回路简化掉，剩下的就是一个 9kΩ 接 1kΩ 到地的分压网络。

    * 分压公式：$V_- = V_{out} \times \frac{1\text{k}\Omega}{9\text{k}\Omega + 1\text{k}\Omega} = V_{out} \times \frac{R_2}{R_1 + R_2}$。

    * 搬出虚短并联立：$V_{in} = V_{out} \times \frac{R_2}{R_1 + R_2}$。

    * 移项得结论：$V_{out} = \left(1 + \frac{R_1}{R_2}\right) V_{in}$。

    * 代入 $R_1 = 9\text{k}\Omega $、$R_2 = 1\text{k}\Omega $，$9/1 = 9$、$9 + 1 = 10$，所以这是一个**十倍同相放大电路**。

    * 仿真输入 1V 时输出确实是 10V，另外多出的 0.002V（2mV）来自 $V_{\text{OS}} $。

    * > **结论**：电路简化出来就是纯电阻网络，公式推导只要懂欧姆定律就搞得定。

## 反相放大电路推导

* **电路结构**

    * (−) 脚坐在 $R_1 $、$R_2 $ 的中点上，$V_{\text{in}} $ 经 $R_1 $ 接到这个点，$V_{\text{out}} $ 经 $R_2 $ 回接到同一点，是标准的反相结构。

    * (+) 脚经虚断视为接地。

    * $R_2 = 10\text{k}\Omega $ 是从输出下来接到反相端的那只，$R_1 = 1\text{k}\Omega $ 是从反相端接到 $V_{\text{in}} $ 的那只。

    ```text
            R1 = 1kΩ              R2 = 10kΩ
       ┌────[  1k  ]────┬──────────[ 10k ]─────┬──── Vout
       │                │                        │
      Vin              (−)                     out│  运放
       │                                        │
       └────────────────┴────(+)─────────────────┘
                      GND
    ```

* **推导步骤**

    * 虚断后 $V_+ $ 经电阻接地，所以 $V_+ = 0$。

    * 中点电压按分压公式写成 $V_- = (V_{out} - V_{in}) \times \frac{R_1}{R_1 + R_2} + V_{in}$。

    * 由虚短 $V_- = 0$ 代入：$0 = (V_{out} - V_{in}) \times \frac{R_1}{R_1 + R_2} + V_{in}$。

    * 移项：$-(R_1 + R_2) V_{in} = (V_{out} - V_{in}) R_1$。

    * 展开括号并约掉两边的 $-V_{in} R_1 $：$-R_2 V_{in} = V_{out} R_1$。

    * 结论：$V_{out} = -\frac{R_2}{R_1} V_{in}$，代入 $R_2 = 10\text{k}\Omega $、$R_1 = 1\text{k}\Omega $ 就是十倍反相。

* **输出范围与反相含义**

    * 反相指输出与输入反向作用：输入一个正 1V，十倍反相就变成 $-10\text{V}$。

    * 运放输出有范围、不能超出供电，要看到 -10V 就必须用 $\pm 12\text{V}$ 供电，仿真跑出来是 $-9.9999\text{V}$。

    * > **提示**：不是所有运放电路的负反馈路径都是从输出直接到 $V_- $ 的，有些会先经过别的器件最后接到 $V_+ $ 来；判断标准只有一条——反馈让 $V_+ $ 与 $V_- $ 相互靠近就是负反馈，让两者远离就是正反馈。

    * > **提示**：书上一般教用叠加定理去算，叠加定理对电路没学好的同学比较复杂；电路没学好就直接用欧姆定律的方式推，前面每一步都只是在用欧姆定律。

## 单电源反相放大的偏置网络

* **为什么需要偏置**

    * 场景里根本没有负电源、只能给单电源供电时，直接照搬反相放大电路，仿真输出一直等于 0（实际会有 4.0 几毫伏），极易失真。

    * 最简单的解决办法是在反相放大电路里加一个偏置网络，让运放的默认输出电压不等于 0。

    * 例如加一个 5V 的偏置，默认输出就等于 5V；信号进来时反相放大是从 5V 上面往下降，这样就不会输出失真。

* **电路结构与推导**

    * 上半部分是反相网络，$V_{\text{in}} $ 经 $R_1 $、输出经 $R_2 $ 交汇在 (−) 脚；下半部分是偏置网络，5V 经 $R_2 $ 下来、经 $R_1 $ 到地，中点接到 (+) 脚；运放由单侧 5V 供电。

    ```text
      Vout ──┬────[10kΩ R2]────┬────────┐
             │                  │        │
           [1kΩ R1]            (−)     out│  运放
             │                  │        │
            Vin                [1kΩ R1]  │
                                │        │
                         [10kΩ R2]       │
                                │        │
                               5 V ───────┘
    ```

    * 有负反馈回路则虚短成立，外部电阻是 k 级别则虚断成立。

    * 虚断拆掉运放后偏置网络就是一个分压：$V_+ = 5\text{V} \times \frac{R_1}{R_1 + R_2}$。

    * 反相端结构与双电源时一模一样，只是最下面那个不是 GND 而是 $V_{\text{in}} $，所以分压公式形式相同：$V_- = (V_{out} - V_{in}) \times \frac{R_1}{R_1 + R_2} + V_{in}$。

    * 由虚短联立：$5\text{V} \times \frac{R_1}{R_1 + R_2} = (V_{out} - V_{in}) \times \frac{R_1}{R_1 + R_2} + V_{in}$。

    * 化掉 $R_1 + R_2 $：$5 \times R_1 = (V_{out} - V_{in}) \times R_1 + V_{in} \times (R_1 + R_2)$。

    * 再约掉 $R_1 $ 并利用 $\frac{R_1}{R_1} = 1$ 把两个 $V_{in} $ 合并：$V_{out} = 5 - V_{in} \times \frac{R_2}{R_1}$。

* **数值验证**

    * $R_2 = 10\text{k}\Omega $、$R_1 = 1\text{k}\Omega $ 时就是对 $V_{\text{in}} $ 做十倍放大。

    * $V_{in} = 0.1\text{V} $ 时 $0.1 \times 10 = 1$、$5 - 1 = 4$，$V_{out} $ 应为 4V，仿真跑出 4.003V，多出的 003 来自 $V_{\text{OS}} $。

    * $V_{in} = -0.1\text{V} $ 时 $-0.1 \times 10 = -1$、$5 - (-1) = 6$，$V_{out} $ 应为 6V，仿真跑出 6.003V，对上了。

    * 可见加了偏置之后虽然仍是反相放大，但放大后是在 5V 基础上往下掉的，输入为 0 时输出就等于 5V。

## 三种电路推导的共性

| 电路 | $V_+$ 这一侧被虚断拆成什么 | 联立后得到的结论 |
| :--- | :--- | :--- |
| 同相放大 | 直接等于输入 $V_{\text{in}}$ | $V_{out} = \left(1 + \frac{R_1}{R_2}\right) V_{in}$ |
| 反相放大（双电源） | 经电阻接地，等于 0 | $V_{out} = -\frac{R_2}{R_1} V_{in}$ |
| 反相放大（单电源 + 偏置） | 5V 经分压得到的固定电位 | $V_{out} = 5 - V_{in} \times \frac{R_2}{R_1}$ |

* **流程模板**

    * 三道推导是同一套流程的不同变体：先判虚短虚断，再用虚断拆掉运放、把电路化成纯电阻网络，最后用虚短把两个分压关系联立。

    * 变的地方只有一个：$V_+ $ 被虚断拆开之后接到什么。

    * 虚断在这一刻扮演的就是一个虚拟开关——开关一“断”，运放那部分复杂的内部电路整个从图上消失，只剩下手边的几个电阻。

    * 掌握了虚短虚断的本质，再用欧姆定律去推这些公式就非常简单。
