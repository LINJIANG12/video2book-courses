# 二极管的单向导电、整流与钳位功能

## 二极管的基本结构与单向导电

* **PN 结与二极管**

    * > **定义**：P 型半导体材料与 N 型半导体材料组合在一起形成一个 PN 结，PN 结本身就是一只二极管。

    * 二极管的电流只能从一个方向流到另一个方向，反方向流不通。

    * 单向导电包含两条规矩：一是单向导通，二是导通之后两端会出现一个大约 0.7V 的压降（普通硅二极管）。

* **同电源同电阻下的三种接法**

    * 三种电路都用 5V 电源、1kΩ 电阻和一只电压表探头，差别只在二极管的朝向以及它与电阻的先后位置。

    * 二极管顺着电流方向、放在电阻前面：输出 $5 - 0.7 = 4.3\text{ V}$，实测读数 4.35V 左右。

    ```text
              +5V
               |
              SW
               |
               +----|>|----+----[R 1k]----+---- GND
               |           |             |
               |           +----(V)------+
               |                 4.3 V
    ```

    * 二极管反接、仍在电阻前面：与电源方向相反，不导通，$I = 0$，由 $V = I \times R$ 得电阻压降为 0，输出 0V。

    ```text
              +5V
               |
              SW
               |
               +----|<|----+----[R 1k]----+---- GND
               |           |             |
               |           +----(V)------+
               |                 0 V
    ```

    * 二极管反接、并与电阻对调位置：依然没有电流，电阻上没有压降，输出 $5 - 0 = 5\text{ V}$，实测读数 5V。

    ```text
              +5V
               |
              SW
               |
               +----[R 1k]----+----|<|----+---- GND
               |             |             |
               |             +----(V)------+
               |                 5 V
    ```

## 导通压降与器件选型

* **普通硅二极管的导通压降**

    * 硅二极管的导通压降按 0.7V 计算，实际值落在 0.6～0.7V 区间。

    * 真实压降跟电流有关，电流变大时会稍微往上走一点，但基本在这个数附近。

    * > **易错点**：0.7V 与 0.3V 都只是约等值；真拿它当电源用时，不要指望拿到一个精确的 0.7V。

* **肖特基的导通压降**

    * 肖特基的导通压降只有 0.3V，比普通硅管省下 0.4V。

    * 1N5819 装到同一个 5V / 1kΩ 电路里，理论输出 $5 - 0.3 = 4.7\text{ V}$，实测 4.78V。

    * > **易错点**：1N4007 与 1N5819 长得太像、符号上只差一点，装错时读数仍然是 4.3V。实验读数对不上时第一件事永远是核对型号，而不是怀疑电路。

## 反向截止不等于没有电流

* **半导体的普遍漏电流**

    * > **定义**：反向截止不等于完全关断；器件上只要加了反向电压，哪怕它自己不导通，也会有一点点漏电流漏过来。

    * 不只是二极管，所有半导体材料都一样：器件上只要承受着电压，即使处于不工作、不导通状态，也依旧会有漏电流，只是看漏电流多大而已。

    * 对静态工作点要求高、负载非常精密的电路，这点漏电流不能忽略，它会一点点把能量漏掉。

* **漏电流的测量与算式**

    * 把反向接法的二极管换成 1N5819，输入仍是 5V、电阻取 2kΩ。

    * 因为漏电流非常小，电阻两端压降也非常小，万用表要调到最小的挡位再测，读数是 3mV。

    * 漏电流由此算出 $3\text{ mV} / 2\text{ k}\Omega = 1.5\ \mu\text{A}$，小到人会觉得完全无所谓。

    * 换成普通二极管 1N4007，同样条件下读数没有了；把电压升到 40 多伏再测，依然读不出来。

    * > **提示**：表上读不出漏电流不等于没有漏电流，这时二极管其实已经有一点点漏电流，只是被万用表的量程淹没了。

* **硅管与肖特基的权衡**

    * 1N4007 的反向耐压能做到 1000V，40 多伏对它来说连零头都不到；换成 1N5819，这么高的电压早就直接炸了——短路、击穿、彻底损坏。

    * 肖特基并不能工作在所有场景：对漏电流要求高的地方它不适用，反向电压高的地方它也扛不住。

    * 肖特基真正的长处是开关速度比普通二极管快很多，可以直接把它理解成一个高速开关型二极管。省下 0.4V 是它的卖点，漏电大、怕高电压是它的账，项目里选型时这笔账要一起算。

    * > **易错点**：⚠️ 很多特殊场景就是要求漏电流很小，图省事觉得导通压降小就是好而直接上了肖特基，结果一加上去发现漏电流把能量全漏掉了。

| 对比项 | 普通硅二极管（如 1N4007） | 肖特基（如 1N5819） |
| :--- | :--- | :--- |
| 导通压降 | 约 0.7V | 约 0.3V |
| 反向漏电流 | 很小 | 明显更大 |
| 开关速度 | 一般 | 快很多 |
| 反向耐压 | 高，可到 1000V | 较低，约 40~50V |

## 整流功能

* **整流的定义与用途**

    * > **定义**：整流就是把交流电变成直流电，利用的正是二极管的单向导电特性。

    * 电路里总有一些器件只能工作在直流信号下；输入是交流信号而后级元器件只认直流时，就需要整流。

### 半波整流的组成

* **最简结构**

    * 为了看清原理，把后级负载全部忽略掉，只保留输入、二极管、限流电阻和电容。

    * 加电阻是为了限制电容的充电速度，不然电容充得太快，波形细节全糊了。

    ```text
          AC in
            ~
            |
          +-+-+
          | D |
          +-+-+
            |
           [R]
            |
            +----------------+-------- GND
            |                |
            +------||--------+
                   C
            |
          measure here --> Vc = Vin(peak) - 0.7 V
    ```

### 峰值检波

* **0.7V 宽的导通窗口**

    * 电容充电从输入信号等于 0.7V 的时刻开始。

    * 电容上的电压与输入信号电压相差 0.7V 时，充电就停止。

    * 具体算例：某一时刻电容电压是 1V，输入信号从 1.7V 掉到了 1.6V，$1.6 - 1 = 0.6\text{ V}$ 够不到那 0.7V，条件不满足，输入没法继续给电容充电。

    * 既不充也不放时电容电压保持在 1V 直到输入重新涨回 1.7V，充电才重新开始；下一个周期同样卡着一个 0.7V 的压差。

    * 导通窗口只有 0.7V 宽，电容在窗口里爬一级台阶，然后干等一整个周期。

    * 一个周期一个周期地爬，最终停在比输入信号最大值少 0.7V 的位置，之后只要不加负载，这个直流电压就一直保持。

    ```text
          Vin :      /‾\          /‾\
                :     /  \        /  \
                :    /    \      /    \
          ------+---/------\----/------\---------
                |  /        \  /        \
          Vc   :  |/‾‾‾‾‾‾‾‾‾\_/‾‾‾‾‾‾‾‾\_/‾‾‾‾\__
                |  ↑
                |  输入 < 0.7V 时不导通，输入挂在上面
    ```

* **命名由来与示波器实测**

    * > **定义**：二极管的整流功能也叫峰值检波，因为电容上的峰值电压约等于输入电压的峰值减去二极管压降 $V_{in(\max)} - 0.7\text{ V}$。

    * 示波器一个探头测输入交流信号，另一个探头测电容上的信号：直接看第二个周期，信号上来给电容充一次电，输入掉下来电容电压平住，再来一个周期又充一次、保持一个台阶。

    * 到最后输出峰值就是比交流信号小了那么一点点，之后是一条直线，这就是峰值检波的实际工作原理。

### 全波整流与电桥

* **电桥结构**

    * 全波整流的原理与半波非常类似，只是在半波整流的基础上多接几只二极管，做成电桥的样子。

    ```text
                                 +V out
                                 |
                +----------------+----------------+
                |                                 |
               |>|                               |>|
                |                                 |
           AC  o----------------+----------------+o  AC
                |                                 |
               |<|                               |<|
                |                                 |
                +----------------+----------------+
                                 |
                                 -V out
    ```

* **分支电压判定**

    * 电流回到节点后分成两个分支，其中一支的电压是从后级电路绕过来的，而后级电路必然有压降，所以这一支的电压 $V_1$ 一定小于对面那点的电压 $V_2$。

    * 靠 $V_1$ 那一头去导通另一个二极管是不可能的——电压低的一头根本过不去导通压降，所以电流只能原路回到自己的负极。

* **正负半周的输出**

    * 先把电容拿掉当成纯电阻负载：正半周输入上正下负，输出随之上升再下降，但比输入永远低 1.4V，不是在 0.7V 才开始上升。

    * 负半周输入下正上负，到达负载时对负载而言依然是一个正的电压，这个正电压的最大值同样比输入信号小 1.4V。

    * 电阻上看到的波形，是把负半周下面那一部分整个翻上去，再叠在正半周上面；正半波、负半波都用上了，这才叫全波整流。

    * 把电容加回来后输出变成充、充、充到最高，然后慢慢放电，再冲上去、再慢慢放电，输出是一串围绕直流电平小幅波动的锯齿状电压。

    * > **结论**：不管正半周还是负半周，到达负载的电流方向都是一样的，所以负载上拿到的永远是一个正的、可用的电压；代价是比输入峰值低了整整两个二极管压降。

    * > **提示**：不管半波还是全波，都逃不掉 $-0.7\text{ V}$ 这一刀——每只串在回路里导通的二极管都要吃掉一个压降，桥式整流就是两个压降叠加。

## 钳位功能

* **钳位的物理基础**

    * 二极管最重要的特性之一是导通之后两端压降基本恒定，约等于一个规定的导通电压。

    * 一颗硅型二极管额定导通压降 0.7V，只要它导通，两端就是约 0.7V；电流变大时压降会稍微大那么一点点，但基本也在 0.7V 左右。

    * 只要导通、导通时两端电压基本不变，就靠这一条可以实现钳位功能。

### 分压电路上的钳位实测

* **2.5V 被拉回 0.7V**

    * 两个 10kΩ 电阻对 5V 分压，不接二极管时该点电压 $5 \times \frac{10\text{k}}{10\text{k}+10\text{k}} = 2.5\text{ V}$，实测 2.5V 左右。

    * 在这一对电阻上并联一只二极管，2.5V 一落上去二极管就导通，这两点之间被锁死成 0.7V 的压差。

    * 电阻与二极管处于并联状态，所以电阻上的电压也被钳在 0.7V；实测读数是 0.55V，正好处在 0.5V 到 0.7V 这个正常的导通压降区间里。

    ```text
                 +5V
                  |
               [10k]
                  |
                  +-------+-------------+---- GND
                  |       |             |
                  |     |>|  0.7V       |
                  |       |             |
                  +-------+-------------+

              no diode  --> U = 2.5 V
              with diode --> U = 0.7 V (was 2.5 V)
    ```

* **钳位的前提条件**

    * > **易错点**：二极管能钳位是有前提的——外部给的电压必须大于它的导通压降，它才导通、才钳得住。

    * 导通压降是 0.7V 时，电阻分压等于 1V 二极管才导通，一导通就把这 1V 拉下来只剩 0.7V。

    * 如果两个电阻分压本来就只有 0.3V，二极管压根不导通，钳位也就无从谈起；只有当外部条件比导通压降大时，二极管才会导通。

### 真实工程里的钳位用法

* **给运放输入设天花板**

    * 分立开关电源的误差放大器在下面，反馈线上有一只二极管接到了 3.3V，这只二极管就是干钳位活的。

    * 正常情况下该点是开关电源的输出电压，若输出为 10V，按常理经这两个电阻分压后到达运放输入那一点应该是 1.2V，与运放基准电压对上。

    * 电阻焊反或某个器件出错时，10V 的输出电压可能直接跑到运放输入端；运放供电才 3.3V，10V 直接怼进来会让运放工作异常，甚至直接把运放打坏。

    * 当该点电压涨到 4V 时二极管就导通，一旦导通这一点电压永远只能比 3.3V 高 0.7V，4V 这个天花板死死盖住了运放输入口。

    ```text
             Vout (normal 10V, but may surge)
                |
                +-----------[10k]-----------+
                |                           |
                +----------[10k]---+         |
                |                   |         |
                +----|>|-----------+---------+--- +3.3V
                |
              op-amp in (+)  <- clamped to 4.0V max
    ```

* **给信号线设地板与识别方法**

    * 同样的信号线接到 GND 也是钳位，可以保证该点电压最低不会低于 $\text{GND} - 0.7\text{ V}$，也就是不低于 $-0.7\text{ V}$，同样保护了前面的电路。

    * > **提示**：看原理图时，只要发现信号线上挂了两只二极管，一只接 3.3V、一只接 GND，就可以直接判定这是保护电路。

    * 直流稳压电源这类电路在信号线上加的是稳压管，作用同样是保护信号线，只不过它不是靠二极管的正向导通保护，而是靠稳压管的反向击穿来钳位——思路一样，机理换了一条路。

## 反接保护

* **反接保护的定义**

    * > **定义**：把二极管串在电源路上，接反时让它直接截止、从而保护后面电路，这个功能叫反接保护。

    * 直流有刷电机从上到下的电流为正转，从下到上的电流为反转；有些场景只希望它正转，绝不能反转。

### 两种防呆思路

* **机械防呆**

    * 最傻瓜式的设计是把接口做成特殊形状，正极那根线做得特别长、负极做得特别短。

    * 插的时候短的插不进长的孔位，长的一插进去就必然落到位，反着根本插不进去，防呆目的达到。

    ```text
        正线：长针        负线：短针

        长 ───────────    短 ───
          ○    ○            ○  ○

        只能这么插，反了就插不进去
    ```

* **电路防呆**

    * 买特殊座子往往比较贵，贵就有替代方案：在正极这一路串进一块二极管。

    * 正常接（上正下负）时电流穿过二极管，电机照转；接反时电流走到二极管这里过不去，电机干脆不转了——它不会反转，只是干脆不动。

    ```text
        接正：上正下负

            +VCC
              │
              ├──▷|──┐      二极管正向，导通
              │      │
              │  ┌───┴───┐
              │  │  电机  │
              │  └───┬───┘
              │      │
             GND ───┘
             → 电机正转


        接反：下正上负

            +VCC
              │
              ├──|◁──┐      二极管反向，截止
              │      │
              │  ┌───┴───┐
              │  │  电机  │
              │  └───┬───┘
              │      │
             GND ───┘
             → 电机干脆不转，也不会反转
    ```

    * 实物验证时先把电压调低让电机转得慢一点，拆掉其中一头线分别试接；电压高、转得快时根本看不清它是往哪边转的。

    * 电路防呆的落地画法：电源正串一只 `▷|` 后送到后面所有电路的 VCC，电源负直接作 GND。

    ```text
        电源正 ──▷|──┬──→ VCC，送到后面所有电路
                       │
        电源负 ────────┴──→ GND

        接正：▷| 正向导通，VCC 正常
        接反：▷| 反向截止，后面电路全部断电
    ```

* **两种做法的适用场景**

| 做法 | 怎么实现 | 适用场景 |
| :--- | :--- | :--- |
| 机械防呆 | 接口做成防呆结构，反着根本插不进去 | 有定制座子、成本能接受 |
| 电路防呆 | 电源进来这一路串一块二极管，只允许一个方向导通 | 接口没防呆功能、大批量电路 |

### 一律接电源端

* **不能接 GND 那一端的原因**

    * 二极管放电源端可以，放 GND 那一端效果一样，都能防反接，但一般不建议这么做。

    * 二极管串到 GND 上之后，这块电路的地电位并不等于 0V，并没有真正接地，而是浮在 0.7V 上。

    * 二极管的导通压降跟工作电流有关：导通电流越大，导通压降越大，地电位会在工作过程中产生一定幅度的波动，直接干扰整块电路的工作。

    * > **结论**：用二极管做反接保护一律接到电源端，不要接 GND 这一侧。GND 通常是整块电路最关键的那个参考点、动不得，VCC 虽然也关键但相对好处理那么一点点。

## 最大反向耐压

* **最大反向耐压的定义**

    * > **定义**：最大反向耐压是二极管能承受的反向电压上限，超过它就有损坏的风险。

    * 二极管不是一个理想器件，能承受的反向电压不是无穷大的。反向加电压时不导通一直被当作理想前提，这个前提是有范围的。

    * 假设最大反向耐压是 30V，给它的反向电压就一定不能大于 30V。

    ```text
        耐压 30 V 的二极管

         +30 V ──┬──────┐
                 │      │
                ▷│     正常：不导通
                 │      │
          0 V ───┴──────┘


         +45 V ──┬──────┐
                 │      │
                ▷│     远超耐压 → 击穿 → 可能永久损坏
                 │      │
          0 V ───┴──────┘
    ```

### 正向盯电流而不是电压

* **不存在最大正向电压**

    * 正向没有「最大正向电压」，因为二极管正向导通之后压降基本就等于一个很小的值，硅管大约 0.6～0.7V。

    * 往上再加电压，多出来的部分全部变成了电流的推动力，所以正向这边要盯的不是电压而是电流。

    * 流过它的电流不能超过最大电流，超过最大电流它就会很烫，很容易发热损坏。

    * > **易错点**：反向盯耐压，正向盯电流；不要去记一个并不存在的「最大正向电压」。

### 余量与击穿的不可逆

* **标称值是开始击穿的量级**

    * 标 30V 的管子不是一接 30V 立刻就坏：厂家标反向耐压时留了余量，标称 30V 的管子实际可能加到 35V 才开始出现一点点电流。

    * 有微微的电流下来说明已经开始击穿，但还没坏，这时候把电压降下来它是还能恢复的。

    * 35V 继续往上顶、比如干到 45V，那就可能直接被完全击穿，不可恢复，彻底进入损坏状态。

    * > **结论**：正常工作在反向时，反向电压必须留出余量，别贴着最大反向耐压用。耐压标称值是「开始击穿」的量级，不是「还能安全跑」的量级。

* **过压实测的完整过程**

    * 板上有一块二极管和一个 10Ω 电阻，二极管这边是 P、那边是 N，加反向电压时用万用表直流档 200V 量程并联测二极管两端电压。

    * 用的是 1N5819，最大的反向耐压约 40V；电压调到 24V 时读数 2.3V。

    * 从 23、24、25、26、27 一直拧到 36、37、40、42、44，两端电压一直是 22.3V 附近、电流为 0；拧到 40V 以上开始拧一下冒出来一点电流。

    * 再拧到 46、47、48、49、50V，电流又往上蹿了一点，这时候把电压拧下来它还是正常的——确实已经过压，但还没烧坏。

    * 猛地把电压拧上去时，击穿只是一瞬间的事：电压拧到差不多 60V 时 10Ω 电阻冒烟被烧断。

    * 电阻被烧断是因为二极管已经短路了，60V 全部落在 10Ω 上，功率大得直接烧穿；拆下来用万用表蜂鸣档一接上就响，说明二极管已经损坏。

## 稳压二极管

* **稳压二极管的定义**

    * > **定义**：稳压二极管是被设计成可以工作在击穿区的二极管，击穿之后不会直接坏掉，而且两端电压会等于一个额定值。

    * 普通二极管反向击穿就等于报废，稳压管把这条从「损坏区」变成「工作区」。

    ```text
        输入 3 V（低于稳压值 5.6 V）

         7 ──────────────┐
                         │
         3 V ───▷|───────┘      未击穿，等同于断开
                             输出 = 3 V


        输入 7 V（高于稳压值 5.6 V）

         7 ──────────────┐
                         │
         5.6 V ──|◁──────┘      反向击穿，把电压钳在 5.6 V
                             输出 ≈ 5.6 V
    ```

* **与普通二极管的本质区别**

    * 5.6V 稳压管配 3V 供电时还没到击穿电压，这一端相当于断开，输出就是 3V。

    * 电压上到 7V、超过 5.6V 后它就击穿，但它不烧，击穿之后两端就是 5.6V。

    * 这 5.6V 并非纹丝不动：电流越大，电压会慢慢往上漂一点，但仍然约等于 5.6V 附近。这是稳压管与普通二极管反向击穿时最本质的区别。

    * > **结论**：稳压管与普通二极管最大的区别，就在于它能工作在反向击穿区、且击穿之后两端电压等于它的稳压值；利用这一点就能给电路提供一个简易的稳定电压。

### 稳压电流与功耗

* **功耗与稳压电流窗口**

    * 稳压管反向击穿之后电流是有限的：击穿后两端就有一个 5.6V 的压降（不同型号稳压值不一样），流过电流 $I$ 时稳压管上的功耗是 $P = I \times V_Z$。

    * 它会发热，热量超过它的额定功率时稳压管就坏了。

    * 用稳压管稳压时一定要盯住稳压电流，即流下来的电流：这个电流不能太大否则烧管，但尽量也别太小，太小就没那么稳。

    * 一般建议稳压管的工作电流在 5mA 左右就够了；不同型号不一样，大部分稳压管都在 5mA 上下，大一点、小一点通常也不会有太大问题。

* **输入越高越要加大限流电阻**

    * 上电前先把电源电压调到 5V 左右再上，避免一上去就直接击穿损坏。

    * 输入从 5.6V 开始，输出停在 5.6V 不动；输入到 5.7V 仍是 5.6V，说明稳压管已经击穿而且击穿之后还在正常工作。

    * 输入 6.4V、6.5V 时电流已到 6mA 左右，稳压值等于 5.64V；输入顶到 8.8V 时稳压值变成 5.7V；继续调高稳压值还会更高。

    * 调得很高时稳压管会发热，一旦超过额定封装的功率功耗就有可能损坏。

    * > **易错点**：输入电压很高、又想让稳压管稳稳工作，很简单的办法是把限流电阻加大——电阻加大电流就降下来，功耗自然也降下来。

### 接法要求与正接表现

* **必须反接**

    * > **注意**：稳压管要工作在反向击穿状态，接法必须反接，这边接电源、这边接 GND；不反接就无法击穿。

    * 典型电路就是限流电阻加一只稳压管：Vin 经限流电阻到 Vout，稳压管反接在 Vout 与 GND 之间。

    * 稳压管上黑色边的一端是 N 极，无黑边的是 P 极。

    ```text
        Vin ──┬── R（限流电阻）──┬──→ Vout ≈ 5.6 V
               │                  │
               │                 |◁  稳压管（必须反接才击穿）
               │                  │      黑色边 = N 极，无黑边 = P 极
               └──────────────────┴──→ GND
    ```

* **正接就退化成普通二极管**

    * 稳压管正接可以，此时它可以当成一个普通二极管来用。

    * 正接时二极管压降等于 0.8V，相当于一个普通二极管压降；把电压减小还是 0.8V，电流越大它的正向导通电压也跟普通二极管一样慢慢往上升。

    * 正向特性跟普通二极管差不多。

## 三极管的基本结构

* **三极管的材料分布**

    * 二极管由 P 型半导体材料和 N 型半导体材料组成，组合在一起形成一个 PN 结，PN 结就是一个二极管。

    * 三极管由三部分组成，N 型三极管基本结构是上面 N 型半导体、中间夹一层 P 型半导体、下面又是 N 型，从上到下就是 N-P-N 结构，所以叫 N 型三极管。

    * 相邻两层之间各形成一个 PN 结，也就是各一个二极管。

    * P 型三极管的材料分布反过来，是 P-N-P，组成的同样是两个二极管，只不过方向是面对面的。

    ```text
        NPN 的材料分布

            ┌───────────┐
            │  N 半导体  │   ← c
            └─────┬─────┘
                  │   N 与 P 之间 → 一个 PN 结 → 一个二极管
            ┌─────┴─────┐
            │  P 半导体  │   ← b
            └─────┬─────┘
                  │   P 与 N 之间 → 一个 PN 结 → 一个二极管
            ┌─────┴─────┐
            │  N 半导体  │   ← e
            └───────────┘

        PNP：材料分布反过来，P - N - P，
        两个二极管的方向变成"面对面"
    ```

* **两个背靠背的二极管**

    * N 型三极管看上去就像是由两个背靠背的二极管组成：上面那块 N 与中间那块 P 形成一个二极管，下面那块 N 与中间那块 P 又形成一个二极管。

    * P 型的「面对面」是发生在芯片内部的面对面——在外部拿两个二极管面对面接起来，它同样没有三极管功能。

    * > **易错点**：⚠️ 结构像两个背靠背的二极管，并不代表你拿两个背靠背的二极管接上去就能当三极管用；外部直接这么接是没有任何三极管功能的，一定要形成在器件内部才具备三极管功能。

* **三个电极与封装**

    * 三极管的三个部分分别叫基极、集电极、发射极。

    | 电极 | 字母 | NPN 里的位置 |
    | :--- | :--- | :--- |
    | 基极 | B（base） | 中间那层 |
    | 集电极 | C（collector） | 一端 |
    | 发射极 | E（emitter） | 另一端 |

    * 不管 P 型还是 N 型，三极管都由 b、c、e 三个电极组成，区别只在排列组合方式不一样。

    * 外面这个壳只是封装，封装就是芯片的衣服；封装里面所形成的芯片可能是三极管，也可能是 MOS 管或其他芯片结构。

    * > **提示**：不要看到这个样子就断定它是个三极管，衣服是所有芯片都可以穿的，真正要看的是芯片手册里内部到底是个什么东西。

* **用万用表验证内部结构**

    * NPN 按 N-P-N 的材料分布，意味着中间这一层与旁边的两根引脚各自形成一个二极管。

    * 万用表二极管档红表笔接 b、黑表笔接 c，读到 0.6V 压降；红表笔接 b、黑表笔接 e，同样读到 0.6V 压降。

    * 这就印证了中间与旁边两根线各构成一个二极管，是 N 型三极管最基本的结构；P 型三极管同理。

    ```text
        NPN 实物，三个引脚

            ┌───────────┐
        c ──┤           │   c 与 b 之间有一个 PN 结
            │   NPN     │
        b ──┤           │   b 与 e 之间有一个 PN 结
            │           │
        e ──┤           │
            └───────────┘

        万用表二极管档：
          红表笔接 b，黑表笔接 c  → 读到 0.6 V 压降
          红表笔接 b，黑表笔接 e  → 同样读到 0.6 V 压降
    ```

## 三极管的电子开关功能

* **电子开关的存在理由**

    * > **定义**：能用电信号去控制的开关就叫电子开关，三极管就是最常用的那一个。

    * 手动场景下人拿机械开关控制 LED 就够用：手按下去 LED 有电流下来就亮，不按就不亮。

    * 需要自动化时电路里必然有一个主控芯片 MCU，开关的控制就必须由 MCU 来做；MCU 不能像人一样伸手出来摸一下。

    ```text
        机械开关（人用手按）        三极管（MCU 用电信号控）

           A o───o───o B              c o─────o─────o e
                 ↑                       ↑
              按下闭合                 I_b 一来就闭合
             按 / 不按                高 / 低电平
    ```

* **导通条件与 LED 控制电路**

    * 开关有 A、B 两个点，按下时 A、B 短路，不按时 A、B 断开；发射极与集电极和 A、B 两端是对应的，可以把 c、e 分别等效成开关的 A 和 B。

    * > **定义**：b 与 e 之间流过的电流称为基极电流 $I_b$，有 $I_b$ 时 c、e 就会闭合，也就是导通了，这是三极管最简单的导通条件。

    * MCU 输出 3.3V 高电平经过一个电阻再经过 b、e 形成电流，有了 $I_b$ 就闭合，然后就会有 $I_c$ 流过。

    * LED 控制电路：5V 经限流电阻与 LED 接到集电极 c，发射极 e 接 GND，MCU 输出经基极电阻 $R_b$ 接到 b。

    * MCU 输出高电平 → 有 $I_b$ → c、e 闭合 → 有 $I_c$ → LED 亮；基极未接电时灯不亮。

    ```text
                            5 V
                             │
                          ┌──┴──┐
                          │     │
                          ▽     R   限流电阻
                          │     │
                          └─────┘
                             │
                             c
            3.3 V ── R_b ────┤
           （MCU 输出）       │  NPN
                             e
                             │
                            GND

            MCU 输出高电平 → 有 I_b → c、e 闭合 → 有 I_c → LED 亮
    ```

    * 实际电路里这条控制线要接到主控芯片里面去，验证用的板子上并没有接芯片进来。

    * > **提示**：三极管除了当开关还可以放大微弱信号，但放大用得比较少、学起来比较复杂，零基础课程里不展开。

## 从二极管到三极管

* **二极管这一路的分工**

    * 正向单向导通帮你控方向，反向耐压告诉你别超过哪条线，稳压管故意住在击穿区给你定一个电压。

* **三极管多出来的能力**

    * 换成三极管之后它就不再只是被动挡电流，而是能被你用一个基极电流主动开关一整条回路。

* **统一的判断依据**

    * 二极管的导通压降、反向漏电、整流、钳位这四件事背后其实是同一句话：单向导通，且一旦导通压降基本恒定。

    * 之后不管是设计还是调电路，先回到这句话上，很多判断都会变得很快。
