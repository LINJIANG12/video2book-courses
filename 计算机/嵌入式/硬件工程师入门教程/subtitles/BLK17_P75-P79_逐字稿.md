知道了运放的一些基本功能以及作用之后，接下来就一起来看一下运放的重要特性。

运放的重要特性主要就两个，分别对应的就是虚短和虚断。这两个特性我相信只要是学过模电的同学，估计都已经听腻了。但是听腻了也没有办法，只要是要学运放这个东西的，就必须要懂这两个东西。我们这一节课先来跟大家讲一下运放的虚短到底是什么，它在运放电路中可以用来干嘛。

首先我们先来看一下虚短的概念。虚短的概念很简单，指的就是运放在正常的工作过程中，运放的 $V_+$ 和 $V_-$ 是相等的。这句话是什么意思呢？运放一般总共有五个引脚，其中两个引脚是它的 VCC 和 GND，就是它的供电引脚；其中两个是它的输入端，输入端有一个正号的我们把它称之为同相输入端，一般也把它称之为 $V_+$，有一个负号的我们就把它称之为反相输入端，一般把它称之为 $V_-$；还有一个就是输出端 $V_{\text{out}}$。

虚短的意思就是在正常的工作过程中，$V_+$ 是会等于 $V_-$ 的。为什么会存在这样一个特性？我们如果从网上去搜，一般都会得到这样一个解释，会收到这样一个公式：运放的输出电压 $V_{\text{out}}$ 等于 $(V_+ - V_-)$ 再乘以运放的开环放大倍数：

$$V_{\text{out}} = (V_+ - V_-) \times \text{Gain}$$

因为运放的开环放大倍数是非常大的，动不动就给你来一个 10 万倍甚至 100 万倍。因为知道 Gain 是非常大的，我们是不是就可以把这个公式进行一个转换？把 Gain 拉到这边来，就可以得到这样一个结果：

$$\frac{V_{\text{out}}}{\text{Gain}} = V_+ - V_-$$

因为运放的输出一般都是比较小的，肯定是在电源范围以内的。我就假设最多 $V_{\text{out}}$ 输出等于 12V。当然它实际上不能输出饱和电压，等一下我们从物理本质会跟大家解释为什么当它输出一个饱和电压的时候，$V_+$ 可能就不等于 $V_-$。我们从中就可以知道，不管 $V_{\text{out}}$ 是等于多少，反正它在电源范围以内，就是一个比较小的值。因为运放内部的开环放大倍数非常大，要么 10 万甚至 100 万，一个很小的值除以一个万级别的数字，一除下来就非常小了，是不是这就约等于 0？我们从这里面的 $\frac{V_{\text{out}}}{\text{Gain}}$ 得到的结果就约等于 0。既然约等于 0，我们把 $V_-$ 拉过这一边来，得到的结果是不是就等于 $V_+ = V_-$？这个就是从数学公式上面对运放虚短的解释。

从公式上面的解释其实是很抽象的，很多同学包括我自己也一样，很不习惯从数学的角度去解释这一些问题。从数学角度虽然说很简单，但是总感觉欠缺了什么。所以今天就从物理本质上面来跟大家讲一下运放为什么具有虚短的特性。

运放具有虚短主要的原因，还是因为具有这样一个特性。运放中间有一些很复杂的电路，当电路发现同相输入端的电压 $V_+$ 大于反相输入端电压 $V_-$ 的时候，内部的电路就会让它的输出端 $V_{\text{out}}$ 往上走，往上走的意思就是往电源端走。相反的，当运放内部的电路发现同相输入端 $V_+$ 小于 $V_-$ 的时候，内部电路就会让它的输出端 $V_{\text{out}}$ 往下走，往下走的意思就是往 GND 供电端走。就是因为有这样一个特性，所以才形成了虚短的效果。

在这里用一个具体的数值来跟大家解释一下。假设在整一个电路里面，在上电之前所有的电路都是等于 0V。它等于 0，它也等于 0，大家都等于 0。突然之间上电了，上电的同时给 $V_{\text{in}}$ 加一个 1V 上去。加了一个 1V 上去之后，这一端等于 1V，这一点电压也会立刻跟着会等于 1V。一旦等于 1V 之后，这里要注意，这一端等于 1V 之后，下面的反相端还有输出端依旧还是等于 0 的。这时候运放内部的电路就会发现 $V_+$ 大于 $V_-$ 了，所以它的输出就会往上升。

它往上升的时候，当它从 0V 上升到 1V 的时候，随着运放输出电压的上升，是不是会经过反馈回路，导致 $V_-$ 的电压也会上升？你看这里从 0 上升到 1，这一端电压等于 1k 和 9k 的分压，就等于十分之一。随着输出从 0 上升到 1 的过程，$V_-$ 也会从 0 上升到 0.1V。

当它上升到 0.1V 的时候，运放内部电路依旧会发现 $V_+$ 依旧比 $V_-$ 要大，所以这时候它的输出还是会继续往上走的。它就会一直走走走，比如当它走到等于 5V 的时候，$V_-$ 也会从 0 一直走到 0.5V。这时候 $V_+$ 还是大于 $V_-$。

在什么时候 $V_+$ 才会等于或小于 $V_-$ 呢？就只有当输出电压走到等于 10V 的时候，这时候就发现 $V_-$ 的电压就等于 1V 了。这时候我们就发现 $V_+$ 和 $V_-$ 在输出等于 10V 的时候，这两个输入的信号就相等了。一相等之后，按照刚刚所说的，当运放发现 $V_+$ 小于或等于 $V_-$ 的时候，$V_{\text{out}}$ 是会往下降的。这时候往下降就有一个很好玩的事情。假如说它往下降低一点点，比如降到等于 9.9999V，这时候这一端电压是不是就会比 1V 要小一点点，可能就等于 0.99999V？这个时侯 $V_+$ 是不是又比 $V_-$ 大了？所以它这时候又会往上走。最终 $V_{\text{out}}$ 就会不停地在这里自我调节，是不是就约等于一个 10V 的状态？最终运放电路就会达到一个稳定的状态，它的输出就是约等于 10V，然后它的 $V_+$ 和 $V_-$ 就是刚刚好会相等的。

这也正是为什么运放会存在一个虚短的原因。原因就是因为运放存在这样一个工作特性：当运放内部电路发现 $V_+ > V_-$ 的时候，输出就往上升；当 $V_+ < V_-$ 的时候，输出就往下走。然后它通过这里的负反馈回路去改变其中一端的电压，最终它就可以实现 $V_+ = V_-$。

知道了它的本质之后，这时候就要来考虑一下 $V_+$ 等于 $V_-$ 的前提条件了。根据刚刚的这一顿分析，其实是可以知道运放满足虚短是有条件的。有什么条件呢？按照刚刚的分析，可以知道 $V_+$ 内部之所以会等于 $V_-$，主要的一个原因就是因为反相端 $V_-$ 是可以通过 $V_{\text{out}}$ 的变化，从而去改变 $V_-$，让 $V_-$ 慢慢接近于 $V_+$ 的。

这里面的过程就把它称之为负反馈过程。什么叫负反馈呢？可以简单认为，只要反馈路径可以让 $V_+$ 与 $V_-$ 之间越来越接近的，不是越来越分散、而是越来越靠近的，这种反馈回路就把它称之为负反馈回路。按照刚刚的分析就可以知道，随着 $V_{\text{out}}$ 的电压慢慢上升，反相端 $V_-$ 会越来越接近于 $V_+$，这个回路就把它称之为负反馈回路。这是一个基本的前提，运放要想让 $V_+$ 等于 $V_-$，第一个前提条件是什么？它一定要有一个负反馈回路。

$$V_- = V_{out} \times \frac{R_2}{R_1 + R_2}$$

$R_1 = 9\text{k}\Omega$，$R_2 = 1\text{k}\Omega$，$9\text{k}\Omega / 1\text{k}\Omega = 9$，$9 + 1 = 10$，所以我们这时候就可以看到这个电路它对应的就是一个十倍的同相放大电路。

从中我们就可以看到，当我们把虚短、虚断充分理解之后，利用虚短、虚断的概念对电路进行简化，就会发现这里面的这些公式推导只要懂欧姆定律就搞定了。学我们硬件课程，只要你懂欧姆定律是肯定能学懂的。我不敢保证你 100% 的知识点都能看懂，但是我能够保证只要懂欧姆定律，学我的课程，你可以把 80% 的知识点都掌握好。

在这里面把输入改成一个 $1\text{V}$，按照我们刚刚的计算公式，输出会放大 10 倍，所以输出应该就等于 $10\text{V}$。我们点一下仿真来看一下。这时候它的输出电压就等于 $10\text{V}$。当然它还有一个 $0.002\text{V}$，即 $2\text{mV}$ 的偏差，这 $2\text{mV}$ 的偏差实际上是它的 $V_{OS}$ 导致的，这一点我们在后面再讲。这个对应的就是我们同相放大电路基本的推导方法。

同相放大电路推导完了之后，接下来就跟大家一起推导一下反相放大电路。

反相放大也是一样的，在推导运放的输入与输出之前，第一步一定要判断它是否满足虚短、虚断。虚短就是要看它有没有负反馈；它是否饱和，在我们前期分析电路的时候不要去管它，看它有没有负反馈回路就行了。在这里可以看到明显有一个负反馈。

当然在这里提醒一下大家，不是所有的运放电路它的负反馈路径都是从输出到 $V_-$ 的。有一些电路它的负反馈路径经过了一些器件之后，会把它的反馈端接到 $V_+$ 这里来。大家只要知道，只要反馈最终让 $V_+$ 与 $V_-$ 相互靠近，这种电路就叫做负反馈；让 $V_+$ 与 $V_-$ 远离的叫正反馈。在我们这个电路很明显是一个负反馈路径，所以它是满足虚短的。

虚断方面，可以看到电阻都很小，所以肯定是可以满足虚断的。根据虚短、虚断，我们就可以利用这个特性来进行简化。

首先利用虚断对电路进行简化。看这个 $V_+$，虚断这里断开之后，$V_+$ 经过电阻到地，所以我们得到其中的一个公式：
$$V_+ = 0$$

然后根据虚断，我们同样可以把这个回路进行简化。一简化之后，这里对应的是 $V_{out}$，$V_{out}$ 下来之后有一个 $10\text{k}\Omega$ 的电阻，假设这个 $10\text{k}\Omega$ 电阻是 $R_2$；然后再下来有一个 $1\text{k}\Omega$ 的电阻，假设这个 $1\text{k}\Omega$ 电阻是 $R_1$；然后再下来就到 $V_{in}$。

这个就是利用虚断简化之后的结果。这里面的 $V_-$ 与 $V_{out}$、$V_{in}$ 之间的分压公式怎么列？根据分压公式我们就知道：
$$V_- = (V_{out} - V_{in}) \times \frac{R_1}{R_1 + R_2} + V_{in}$$

刚刚说了 $V_+ = 0$，根据虚短，$V_-$ 也等于 $0$，所以得到：
$$0 = (V_{out} - V_{in}) \times \frac{R_1}{R_1 + R_2} + V_{in}$$

把 $V_{in}$ 移项过来：
$$-(R_1 + R_2) V_{in} = (V_{out} - V_{in}) R_1$$

展开括号：
$$-R_1 V_{in} - R_2 V_{in} = V_{out} R_1 - V_{in} R_1$$

两边的 $-V_{in} R_1$ 约掉之后，就得到：
$$-R_2 V_{in} = V_{out} R_1$$

把 $R_1$ 移项过来，我们得到这个结果就是：
$$V_{out} = -\frac{R_2}{R_1} V_{in}$$

只要懂了欧姆定律，然后再充分理解了虚短与虚断，只要学过数学都是能搞定的。这种方法是一种非常简易的分析方法。模电书上一般都是告诉你用叠加定理去算，但是叠加定理对于电路没学好的同学来说还是比较复杂的。如果电路没学好，直接用欧姆定律的方式去算就可以了。

我们紧接着继续讲一个反相放大电路。刚刚讲的反相放大电路是双电源供电的，给大家先仿真看一下。

反相放大的意思就是它的输出与输入有一个反向的作用。比如输入是一个正电压，输出就会变成一个负电压；输入是一个正 $1\text{V}$，反相放大 10 倍就会变成 $-10\text{V}$。运放是有输出范围的，不能够超出电源的供电范围。要想输出 $-10\text{V}$，在这里必须要用一个 $-12\text{V}$ 来给它供电，这时候才能够看到它的输出等于一个 $-10\text{V}$ 的电压，这里可以看到等于 $-9.9999\text{V}$。

如果说在有一些场景中没有负电源，我们给它加一个单电源供电。这时候再放大，它还会有 $-10\text{V}$ 吗？可以看到它的输出一直就等于 $0$ 了。当然它不可能完全接近 $0$，这里会有一个 $4.0$ 几毫伏的电压。所以在单电源的时候，如果我们直接这样子去做一个反相放大，它的输出是非常容易失真的。

那怎么办呢？最简单的一种解决方式就是在反相放大电路中加一个偏置网络。加这么一个偏置网络之后，它可以让运放的默认输出电压不是等于 $0$。比如加了一个 $5\text{V}$ 的偏置电压，默认输出就等于 $5\text{V}$ 的电压。然后当你加一个信号进来之后，反相放大就可以从 $5\text{V}$ 上面往下降，这时候它就不会输出失真。

出现一个失真的问题。这一个电路它是怎么推导的呢？我们一起来简单地推导一下这一个过程。

同样的配方，首先第一步，先看一下它满不满足虚短。虚短是怎么看的？看有没有负反馈。我们这时候可以看到，这里有一个负反馈回路，所以满足虚短，虚短成立。虚断的话，只要你外部的电阻是一个k级别的就没问题，所以也是满足虚断的。那我们接下来就可以利用虚短虚断开始去分析我们这个电路了。

首先利用的是虚断。虚断的话，我们先来看一下 $V_+$ 的这一个回路。$V_+$ 这个回路我们可以首先进行一个简化，简化成啥样呢？一个 5V 下来，就是到一个 10k 的电阻。我们假设这个 10k 等于 $R_2$，1k 是 $R_1$。这个 10k 再下来的话就是到这个 1k，然后接到 GND，中间这一点对应的就是我们的 $V_+$。

根据这里面的电阻网络，我们是可以算出 $V_+$ 与 5V 的关系的，即：
$$V_+ = 5\text{V} \times \frac{R_1}{R_1 + R_2}$$
这一个就是一个很基础的分压公式。

$V_+$ 知道之后，我们接着再简化一下反相端的这一个网络。这个反相端的网络怎么简化呢？也是一样的，你就把这个断开就行了，那不就变成一个电阻的分压网络吗？就是 $V_{out}$ 过来有一个 10k，再下来有一个 1k，然后再下来有一个——这里不是 GND，这里是 $V_{in}$。利用这里面的分压网络，我们一样可以得到一个公式，这里面对等的是 $V_-$。$V_-$ 等于什么呢？就是等于：
$$V_- = (V_{out} - V_{in}) \times \frac{R_1}{R_1 + R_2} + V_{in}$$
这个公式我们在上一节课讲过了。

这样的话我们是不是就得到 $V_+$ 和 $V_-$ 了？然后根据虚短，我们就可以用它和它联立起来。联立起来的结果等于什么呢？就是等于：
$$5\text{V} \times \frac{R_1}{R_1 + R_2} = (V_{out} - V_{in}) \times \frac{R_1}{R_1 + R_2} + V_{in}$$

等于这个之后，接下来又是做数学题。这个数学题还是比较简单的，在这里可以看到 $R_1 + R_2$，先把 $R_1 + R_2$ 化掉，就等于：
$$5 \times R_1 = (V_{out} - V_{in}) \times R_1 + V_{in} \times (R_1 + R_2)$$

接下来可以看到这里有个 $R_1$，这里也有个 $R_1$，那我们就再把 $R_1$ 给化掉，那就等于：
$$5 = V_{out} - V_{in} + V_{in} \times \frac{R_1 + R_2}{R_1}$$
这个应该不是很难，你除以 $R_1$，它也除以 $R_1$，它也除以 $R_1$，得到的就是这个公式。

得到这个公式之后，在里面我们可以看到：$\frac{R_1}{R_1}$ 是不是就等于其中的一个 $V_{in}$，然后再加一个 $V_{in} \times \frac{R_2}{R_1}$。刚好这个 $V_{in}$ 就约掉了。这时候我们就可以看到 $V_{out}$ 等于多少，就是等于：
$$V_{out} = 5 - V_{in} \times \frac{R_2}{R_1}$$

你看，就是利用这一个虚短虚断。这个电路有很难分析吗？只要你懂欧姆定律，只要你理解透了这个虚短虚断就搞定了。

按照我们这里面算出来的结果，我们就用仿真验证一下。比如说我现在 $R_2 = 10\text{k}$，$R_1 = 1\text{k}$，那对应的就是我们这一个电路，就是对 $V_{in}$ 进行一个 10 倍的放大。如果这个时候 $V_{in} = 0.1\text{V}$，0.1 乘上 10 就等于 1，$5 - 1 = 4$。所以我们这时候如果把这个 $V_{in}$ 换成是一个 0.1V 的电压，那这个时候的话，我的 $V_{out}$ 应该就等于 4V。我们在仿真软件里面看一下。

这里我们先拿这一个电路过来。前面的课程我们都已经把这里面的仿真软件画过很多遍了，后面我们就不一一跟大家画了。这里面我们加一个 0.1V 的电压过来，这时候看一下它的输出，点一下仿真。这时候它是等于多少？就等于 4V。4.003V，那个 003 的话就是 $V_{OS}$ 导致的，大家可以先忽略掉。

所以我们这时候可以看到，加了一个偏置之后，加了一个 0.1V，它虽然说是一个反相放大，但是放大之后它是在我 5V 的基础上下降下去的。比如我这里面输入等于 0 的时候，这时候它输出就是等于 5。

相同地，如果这时候输入是一个负压，比如说 -0.1V。-0.1 乘上一个 10 倍就等于 -1，$5 - (-1) = 6$，所以这时候输出应该是等于 6V 的，我们一起来看一下。这时候等于多少？就等于 6.003V。

所以说，我们只要掌握了这一种虚短虚断的本质，然后再利用我们这个欧姆定律，推导这些运放的公式是非常简单的。
