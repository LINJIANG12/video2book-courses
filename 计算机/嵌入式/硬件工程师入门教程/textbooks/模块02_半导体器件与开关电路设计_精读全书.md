## 二极管到底能干什么：单向、漏电、整流与钳位
> 对应块：BLK09 | 覆盖分集：P32-P36 | 块标题（分集名）：《28.二极管的基本功能》

刚刚说完，二极管有一个特性——单向导电。这个特性很好理解：普通二极管的电流就只能从这一边流到那一边，反过来是流不通的。

但"流不通"到底是个什么状态？流不通的时候电阻上还有没有电压？换成肖特基会不会不一样？这些问题光靠背是不行的，我们直接拿三个电路上手，再顺着"单向"这两个字往下推：能单向导通，就有导通压降；导不通的时候真的有零电流吗；把单向导通用到交流电上就是整流；把导通压降用到极限地方就是钳位。这四件事其实是同一根逻辑长出来的。

### 先拿三个电路，把"单向"这两个字摸清楚

我们先看三个电路，都是 5V 电源，都是 1kΩ 电阻，区别只在二极管的位置和方向。

第一个，二极管顺着电流方向串在回路里：

```text
         +5V
          |
         SW
          |
          +----|>|----+----[R 1k]----+---- GND
          |           |             |
          |           +----(V)------+
          |                 4.3 V
```

开关闭合，电源 5V。假设二极管导通压降是 0.7V，二极管一导通就相当于串进去一个 0.7V 的固定压降，所以电阻两端（也就是我们测的那一点）的电压就是 $5 - 0.7 = 4.3\text{ V}$。这个一点都不难，我们拿万用表实测一下：把 5V 电源接上去，表笔跨在电阻两端，读数 4.35V 左右，跟算出来的 4.3V 对得上。

第二个，二极管反过来了：

```text
         +5V
          |
         SW
          |
          +----|<|----+----[R 1k]----+---- GND
          |           |             |
          |           +----(V)------+
          |                 0 V
```

5V 一接过来，二极管和电源方向相反，不导通。电流过不来，$I = 0$；回到前面讲过的那个关系，电阻上的电压 $V = I \times R$，不管 $R$ 是多少，$I$ 等于 0，$V$ 就等于 0。实测也是如此，输出 0V。

第三个电路很多同学就不会分析了——二极管和电阻换了一下位置：

```text
         +5V
          |
         SW
          |
          +----[R 1k]----+----|<|----+---- GND
          |             |             |
          |             +----(V)------+
          |                 5 V
```

二极管还是反的，依然没有电流。电阻上没有电流就没有压降，压降是 0，那么这一点还是 $5 - 0 = 5\text{ V}$。实测读数 5V。

> **结论**：三个电路合起来就是二极管导通特性的两条规矩。第一，它单向导通；第二，一旦导通，它两端会有一个大约 0.7V 的压降（普通二极管）。

### 导通压降 0.7V，和那省下来的 0.4V

普通硅二极管的导通压降我们按 0.7V 算。但前面也讲过肖特基，肖特基的导通压降只有 0.3V。我们把第一个电路里的二极管换成肖特基实测一下。

拿的是 1N5819，一颗标准的肖特基。理论上电阻两端应该是 $5 - 0.3 = 4.7\text{ V}$。拆掉原来的管子接上去、上电——表上显示 4.78V，对上了。

不过这里有个插曲值得记一下：我第一次装上去，读数怎么还是 4.3V？低头一看，台上那个管子焊的是 1N4007，是我拿错了。换成真正那颗 1N5819，4.78V 立刻就出来了。做实验的时候读数对不上，先别急着怀疑电路，第一件事永远是核对型号——1N4007 和 1N5819 长得太像了，符号上就差那么一点点。

> **易错点**：普通硅管 0.7V、肖特基 0.3V，这只是"约等于"。真实压降跟电流有关，电流变大时会稍微往上走一点，但基本就在这个数附近。真正拿它当电源用的时候，别指望它是个精确的 0.7V。

### 反向截止不等于没有电流

看到这里很多人会觉得：单向导通嘛，反过来就是断路，电流干干净净地是 0。前面第二个、第三个电路里我们测到 0V，好像也确实印证了。

但这里有一个特别容易搞错的地方：**二极管反向截止，并不代表完全关断**。

只要你给器件加上一个反向电压，哪怕它自己不导通，一点点漏电流照样会漏过来。而且不只是二极管，所有半导体材料都一样：只要器件上有耐压，哪怕它处于不工作、不导通的状态，器件上依旧会有漏电流，只是看漏电流多大而已。

我们把第二个电路的二极管换成肖特基 1N5819 再测一次。输入还是 5V，电阻取 2kΩ。因为漏电流非常小，电阻两端的压降也就非常小，所以万用表的挡位要调到最小的挡位再测。读数是 3mV。

于是漏电流可以直接算出来：

$$3\text{ mV} / 2\text{ k}\Omega = 1.5\ \mu\text{A}$$

1.5μA，对人来说太小了，小到你会觉得完全无所谓。但对一些静态工作点要求高、负载非常精密的电路来说，这点漏电流就不能忽略了——它会一点点把能量漏掉。

再换成普通二极管 1N4007，同样条件下测，读数没有了。电压提高再测，40 多伏了，还是没有。这说明同等测试条件下 1N4007 的反向漏电流特性比 1N5819 好太多。而且 1N4007 的反向耐压能做到 1000V，40 多伏对它来说连零头都不到。换成肖特基 1N5819 的话，这么高的电压早就直接炸了——短路、击穿、彻底损坏。（后面专门讲二极管耐压功能的时候，我们会再回过头来演示这一条。）

所以这里就出来一个很典型的权衡：

| | 导通压降 | 反向漏电流 | 开关速度 | 反向耐压 |
| --- | --- | --- | --- | --- |
| 普通硅二极管（如 1N4007） | 约 0.7V | 很小 | 一般 | 高，可到 1000V |
| 肖特基（如 1N5819） | 约 0.3V | 明显更大 | 快很多 | 较低，约 40~50V |

很多同学一看肖特基导通压降才 0.3V，就觉得"肖特基好，无脑选它"。这是不行的。肖特基并不能工作在所有场景：对漏电流要求高的地方它不适用，反向电压高的地方它也扛不住。

> **提示**：肖特基真正的长处是开关速度比普通二极管快很多，你可以直接把它理解成一个高速开关型二极管。省下 0.4V 是它的卖点，漏电大、怕高电压是它的账——项目里选型的时候，这笔账要一起算。

> **易错点**：做项目的时候，很多特殊场景就是要求漏电流很小。这时候二极管没选好——比如图省事觉得"导通压降小就是好"，直接上了肖特基，结果一加上去发现漏电流把能量全漏掉了，那肯定是不行的。

### 整流：把交流只放一半过去

接下来我们讲二极管的另一个应用：整流。

什么叫整流？说白了就是把交流电变成直流电。

为什么需要它？因为电路里总有一些器件只能工作在直流信号下。你前面输入的是一个交流信号，但后面那个元器件只认直流，怎么办？利用二极管的单向导电特性，就能把交流变成直流。这就是二极管的整流功能。

#### 电容是怎么被"顶"住的

先看最基本的半波整流。为了方便看清楚原理，我们把后级的负载全部忽略掉，只保留输入、二极管、限流电阻和电容：

```text
  AC in
    ~
    |
  +-+-+
  | D |
  +-+-+
    |
   [R]
    |
    +----------------+-------- GND
    |                |
    +------||--------+
           C
    |
  measure here --> Vc = Vin(peak) - 0.7 V
```

这里加电阻是为了限制电容的充电速度，不然电容充得太快，波形细节全糊了。

我们一步一步跟着波形走。一开始电容上的电压肯定是 0，两端压降就是 0。信号一接进来，输入就给后级充电，但因为限流电阻在，充电速度比较慢，所以电容电压是慢慢跟着涨上去的。

这里请务必记住二极管压降这件事。电容充电是从输入信号等于 0.7V 的时候开始的。它什么时候停止充呢？当电容上的电压跟输入信号电压相差 0.7V 的时候，就停了。

举个具体的数：某一时刻电容电压是 1V，输入信号从 1.7V 掉到了 1.6V。这时候电容是 1V，输入是 1.6V，二极管导通压降 0.7V——1.6V 减去 1V 只有 0.6V，够不到那 0.7V，条件不满足，输入信号就没法继续给电容充电了。

而后面我们暂时没接负载，电容电压要想变化，要么充电要么放电，现在既不充也不放，就只能保持住这 1V，一直维持过去。等输入信号重新涨回 1.7V，充电又开始了，电容电压继续往上抬；下一个周期同样卡着一个 0.7V 的压差，同样维持过去。

就这么一个周期一个周期地爬，最终会停在"比输入信号最大值少 0.7V"的位置上，不再往上走了。之后只要不加负载，这个直流电压就一直保持。

```text
  Vin :      /‾\          /‾\
        :     /  \        /  \
        :    /    \      /    \
  ------+---/------\----/------\---------
        |  /        \  /        \
  Vc   :  |/‾‾‾‾‾‾‾‾‾\_/‾‾‾‾‾‾‾‾\_/‾‾‾‾\__
        |  ↑
        |  输入 < 0.7V 时不导通，输入挂在上面
        |    导通窗口只有 0.7V 宽，
        |    电容在窗口里爬一级台阶，然后干等一整个周期
```

一个交流电经过这样一个二极管加电容的组合，就变成了一个稳定的直流信号。

> **定义**：二极管的整流功能也叫**峰值检波**。因为电容上的峰值电压约等于输入电压的峰值减去二极管压降，即 $V_{in(\max)} - 0.7\text{ V}$，所以叫峰值检波。

#### 拿示波器亲眼看一遍

光看图不够，我们直接上实物。示波器两个探头：一个测输入信号，也就是交流信号那一根；另一个测电容上的信号，也就是滤波之后的结果。

先让示波器输出一个正弦波，波形出来了。放大一下看：第一个周期先不用看，直接看第二个周期。信号一上来，给电容充一下电；充完输入掉下来，电容电压平住；下一个周期信号一上来又继续充，充完又保持一个台阶；再过来再充一次，之后再充一次。

到最后重新采一次样，你会发现输出的峰值就是比交流信号小了那么一点点，之后就一条直线了。这就是峰值检波、也就是整流的实际工作原理。

### 全波整流：加一只电桥，把负半周也翻上来

半波整流只有一个二极管，全波整流跟它的原理非常类似，只是在半波整流的基础上多加了几只二极管，做成电桥的样子：

```text
                         +V out
                         |
        +----------------+----------------+
        |                                 |
       |>|                               |>|
        |                                 |
   AC  o----------------+----------------+o  AC
        |                                 |
       |<|                               |<|
        |                                 |
        +----------------+----------------+
                         |
                         -V out
```

先把电容拿掉，当成一个纯电阻负载来看，我们分析电阻两端的电压和输入电压的波形。

**正半周**：输入信号从 0 慢慢往上升，这时候上面比下面高，是上正下负，电流按这个方向走。走到上面这一排有二极管，二极管是单向导通的，它只能往一边走；走过去之后正好可以经过后级这个负载，再跑回来。跑回来这个点又分成两个分支。

这两个分支大家一定要注意：因为这个点的电压是从后级电路绕过来的，而后级电路肯定有压降，所以这边的电压 $V_1$ 一定比对面那点的电压 $V_2$ 小。既然 $V_1$ 比 $V_2$ 小，靠 $V_1$ 那一头去导通另一个二极管是不可能的——电压低的一头根本过不去导通压降。所以电流只能从这里走，原路回到它的负极。正半周的完整路径就是这么一条。

在这个过程中，输出信号长什么样？输入这样升，输出当然也这样升（前提是只有电阻、没有电容）。但是电阻两端的电压会比输入电压小两个二极管的压降。把两条波形画在一起看：假设红色是输入波形，绿色是输出波形，它不是在 0.7V 开始上升的，而是在 **1.4V** 才开始——因为要减去两个二极管的压降。升上去，到顶，又下降，比输入永远低 1.4V。掉下来之后就停了。

**负半周**：电流方向反过来，变成下正上负。同样走到上面那一排，分支判断的逻辑一模一样：还是那个点的电压被负载压低了，二极管单向导通，电流只能走那一条路。区别是它到达负载之后，对负载来说依然是一个正的电压——这就是"全波"的意思。这个正电压的最大值，同样比输入信号小 1.4V。

所以在电阻上看到的波形，是把负半周下面那一部分整个翻上去，再叠在正半周上面。正半波、负半波都用上了，这才叫全波整流。

那把电容加回来会怎么样？波形立刻不一样了。电容是会储能的，所以后级的波形变成：充、充、充，充到最高；然后慢慢放电；再冲上去，再慢慢放电，再冲上去。输出就变成了一串锯齿状的、围绕在直流电平附近小幅波动的电压。

> **结论**：不管正半周还是负半周，到达负载的电流方向都是一样的，所以负载上拿到的永远是一个正的、可用的电压——代价是比输入峰值低了整整两个二极管压降。

> **提示**：不管半波还是全波，都逃不掉 $-0.7\text{ V}$ 这一刀——每只串在回路里导通的二极管都要吃掉一个压降。桥式整流就是两个压降叠加。

### 钳位：给某一点的电压定一条不许越过的线

刚才说过二极管一个非常重要的特性：当它导通之后，两端压降基本是恒定的。也不能说绝对恒定，它约等于一个规定的导通电压。比如一颗硅型二极管，额定导通压降 0.7V，只要它导通，两端就是约 0.7V。电流变大时压降会稍微大那么一点点，但基本也在 0.7V 左右。

**只要导通，它两端的电压基本不变**——就靠这一条，我们可以实现钳位功能。

看这个电路：两个 10kΩ 电阻分压，电源 5V，开关闭合。如果没有二极管，这一点电压是 $5 \times \frac{10\text{k}}{10\text{k}+10\text{k}} = 2.5\text{ V}$。我们实测一下，2.5V 左右，没错。

现在在这一对上电阻并联一只二极管：

```text
         +5V
          |
       [10k]
          |
          +-------+-------------+---- GND
          |       |             |
          |     |>|  0.7V       |
          |       |             |
          +-------+-------------+

      no diode  --> U = 2.5 V
      with diode --> U = 0.7 V (was 2.5 V)
```

2.5V 一落上去，二极管就导通了。它一导通，这两点之间就被锁死成 0.7V 的压差；电阻和二极管处于并联状态，所以电阻上的电压也被钳在 0.7V。实测读数是 0.55V，正好处在 0.5V 到 0.7V 这个正常的导通压降区间里。

这就是二极管的钳位作用。

#### 前提：分压必须压得过导通压降

> **易错点**：二极管能钳位是有前提的——外部给的电压必须大于它的导通压降，它才导通、才钳得住。

比方说导通压降是 0.7V，那么电阻分压等于 1V 的时候，二极管才导通，一导通就把这 1V 拉下来只剩 0.7V。但如果这两个电阻分压本来就只有 0.3V，二极管压根不导通，钳位也就无从谈起。**只有当外部条件比导通压降大时，二极管才会导通。**

#### 真实工程里，钳位是在救运放的命

钳位在电路里非常有用，通常都是用来做电路防护的。看一个真实原理图——硬件班电子计划里那个分立开关电源：

```text
     Vout (normal 10V, but may surge)
        |
        +-----------[10k]-----------+
        |                           |
        +----------[10k]---+         |
        |                   |         |
        +----|>|-----------+---------+--- +3.3V
        |
      op-amp in (+)  <- clamped to 4.0V max
```

整个开关电源的误差放大器在下面，那一条是输出信号的反馈线。反馈线这一路上有一只二极管接到了 3.3V，这只二极管就是干钳位活的。

正常情况下，这一点是分立开关电源的输出电压。假如它有可能等于 10V，按常理经过这两个电阻分压之后，到达运放输入那一点应该是 1.2V，跟运放的基准电压对上。

但电路要是出异常了呢？焊接的时候电阻焊反了，或者电路里某个器件出了错，就有可能让 10V 的输出电压直接跑到运放输入端上去。而运放的供电才 3.3V，10V 直接怼进来，运放工作必然异常，甚至有可能直接把运放打坏。

怎么解决？还是回到二极管钳位：把某一点的电压钳住，不让它变高。假如电压真要往 10V 跑，实际上它到不了 10V——因为上面接的是 3.3V，当这一点电压涨到 4V 的时候，二极管就导通了；一旦导通，这一点电压永远只能比 3.3V 高 0.7V。4V 这个天花板，就死死地盖住了运放的输入口。

还有一种接法是同样的信号线接到 GND，这一样是钳位：这时候可以保证这一点的电压最低不会低于 $\text{GND} - 0.7\text{ V}$，也就是不低于 $-0.7\text{ V}$，同样保护了前面的电路。

> **提示**：以后看原理图，只要发现信号线上挂了两只二极管，一只接 3.3V、一只接 GND，就可以直接判定：这是保护电路。前面的分立开关电源项目里就实打实用到了。

再往外看一层：直流稳压电源这些电路也是一样，信号线上加的是稳压管，作用同样是保护信号线。只不过它不是靠二极管的正向导通来保护，而是靠稳压管的反向击穿来钳位——思路一样，机理换了一条路。

到这里，二极管从最基本的单向导通出发，我们已经一路走完了：导通压降、反向漏电、整流、钳位。这四件事背后其实是同一句话——**单向导通，且一旦导通压降基本恒定**。后面不管是设计还是调电路，先回到这句话上，很多判断都会变得很快。

> **承前启后**：上一节讲完「二极管到底能干什么：单向、漏电、整流与钳位」，下一节接着讲「二极管控方向、稳压管定电压、三极管当开关」。

## 二极管控方向、稳压管定电压、三极管当开关
> 对应块：BLK10 | 覆盖分集：P37-P41 | 块标题（分集名）：《33.二极管控制电路的电流方向》

### 用一块二极管，挡住接反的电流

刚刚讲完二极管的钳位功能，二极管还有一个很常用的脾气——它只认一个方向。电路里很多时候我们需要**控制电流往哪儿流**，这时候就得把它请出来。

先看一个例子。这儿是一个直流有刷电机，它的工作逻辑简单得很：你给它一个从上到下的电流，我就假设它正转；你给它一个从下到上的电流，那我就反着转。

问题是，有些场景下我们只希望它正转，绝不能反转。怎么办？最傻瓜式的设计是做机械防呆：接口做成特殊形状，正极那根线做得特别长、负极做得特别短，插的时候短的插不进长的孔位，长的一插进去就必然落到位。这样反着根本插不进去，防呆目的就达到了。

```text
    正线：长针        负线：短针

    长 ───────────    短 ───
      ○    ○            ○  ○

    只能这么插，反了就插不进去
```

不过你去买这种特殊座子，往往比较贵。贵就有贵的替代方案——**用二极管控制电流方向**。

没有二极管的时候，上正下负电流顺着走，电机正转；万一一根线插反了变成下正上负，电流就从下往上，电机反转，完蛋。但只要在正极这一路串进一块二极管，情况就变了：正常接（上正下负）时电流能穿过二极管，电机照转；真接反了时，电流走到二极管这里过不去，电机干脆不转了——它不会反转，只是干脆不动。

```text
    接正：上正下负

        +VCC
          │
          ├──▷|──┐      二极管正向，导通
          │      │
          │  ┌───┴───┐
          │  │  电机  │
          │  └───┬───┘
          │      │
         GND ───┘
         → 电机正转


    接反：下正上负

        +VCC
          │
          ├──|◁──┐      二极管反向，截止
          │      │
          │  ┌───┴───┐
          │  │  电机  │
          │  └───┬───┘
          │      │
         GND ───┘
         → 电机干脆不转，也不会反转
```

我们直接拿实物看一遍。拿个电机过来，把电压先调低一点，让它转得慢一点，然后把其中一头线拆掉。这里黑色那条假设接负，褐色那条假设接正，接上去电机已经在转了；把它反接过来，它其实也会转，只是方向相反。不过那时候电压高、转得快，你根本看不清它是往哪边转的。

现在要求电流只能从褐色进去、从黑色出来，方向只能单走。那就在褐色这一路插一块二极管进去。接上电源、地接黑色线，电机正常转；再把电源反接，一上电，电机不动了。它就不会反转。这就是利用二极管控制电流方向最直观的一个例子。

> **定义**：把二极管串在电源路上，接反时让它直接截止，从而保护后面电路——这个功能叫**反接保护**。

实际工程里做反接保护，就两条路：

| 做法 | 怎么实现 | 适用场景 |
| --- | --- | --- |
| 机械防呆 | 接口做成防呆结构，反着根本插不进去 | 有定制座子、成本能接受 |
| 电路防呆 | 电源进来这一路串一块二极管，只允许一个方向导通 | 接口没防呆功能、大批量电路 |

第二种画出来就是这样：

```text
    电源正 ──▷|──┬──→ VCC，送到后面所有电路
                   │
    电源负 ────────┴──→ GND

    接正：▷| 正向导通，VCC 正常
    接反：▷| 反向截止，后面电路全部断电
```

那么问题来了：二极管放电源端可以，放 **GND 那一端**行不行？行，效果一样，都能防反接。

但我们一般不建议这么做。为什么？

因为你把二极管串到 GND 上之后，你这个电路的"地电位"其实就不等于 0 V 了——它并没有真正接地，而是浮在 **0.7 V** 上。更麻烦的是，二极管的导通压降跟它的工作电流是有关的：导通电流越大，导通压降越大。这就意味着你的地会在工作过程中产生一定幅度的**波动**，而这个波动会直接干扰整块电路的工作。

> **结论**：用二极管做反接保护，**一律接到电源端，不要接 GND 这一侧**。因为 GND 通常是整块电路最关键的那个参考点，动不得；而 VCC 虽然也关键，但相对好处理那么一点点。

### 二极管不是理想器件，它扛得住多高反向电压

接着把二极管的关键参数讲一下。二极管反向加电压的时候不导通，这是我们前面一直用的前提。但请注意：**二极管不是一个理想器件**，它能承受的反向电压不是无穷大的，是有范围的，这个参数就叫**最大反向耐压**。

意思很直白：假设这块二极管的最大反向耐压是 30 V，那你给它的反向电压就一定不能大于 30 V。超过 30 V，它就有损坏的风险。

```text
    耐压 30 V 的二极管

     +30 V ──┬──────┐
             │      │
            ▷│     正常：不导通
             │      │
      0 V ───┴──────┘


     +45 V ──┬──────┐
             │      │
            ▷│     远超耐压 → 击穿 → 可能永久损坏
             │      │
      0 V ───┴──────┘
```

很多同学到这里会问一个对称的问题：那正向有没有一个"最大正向电压"？

**没有。** 因为二极管正向导通之后，压降基本就等于一个很小的值（前面讲过，硅管大约 0.6～0.7 V），你往上再加电压，多出来的部分全部变成了电流的推动力。所以正向这边要盯的不是电压，而是**电流**：流过它的电流不能超过最大电流。超过最大电流，它就会很烫，很容易发热损坏。

> **易错点**：反向盯**耐压**，正向盯**电流**。别去记一个并不存在的"最大正向电压"。

当然也不是说标 30 V 的管子，一接 30 V 立刻就坏。芯片厂家标反向耐压时是留了余量的：标称最大值 30 V 的管子，实际可能加到 35 V 才开始出现一点点电流。有微微的电流下来了，说明已经开始击穿，但它还没坏——这时候把电压降下来，它是还能恢复的。可要是 35 V 继续往上顶，比如干到 45 V，那就可能直接被完全击穿，不可恢复，彻底进入损坏状态。

来，动手看。板子上有一块二极管和一个 10 Ω 的电阻，二极管这边是 P、那边是 N，我们要给它加反向电压。

```text
    电源 ──┬──▷| 方向接反，接上反向电压
           │   （万用表二极管/直流档并联测两端电压）
           │
    10 Ω ──┴── 电阻在这里限流
```

先把电压调高到 24 V。这边角度不好看，我用万用表测它的电压，直流档调到 200 V 就行。现在读到 2.3 V。然后慢慢往上拧：我现在用的这块是 1N5819，最大的反向耐压好像是 40 V。

调到二十多伏的时候，电流一直是 0，两端电压一直是 22.3 V——也就是说，此刻二极管承受的反向电压就等于 22.3 V。继续拧：23、24、25、26、27。刚才好像看到有那么一点点电流出来了，先不管，继续往上：36、37、40、42、44。这时候就能看到，拧一下冒出来一点电流，拧一下又冒出来一点。

> **提示**：表上读不出漏电流，不等于没有漏电流。这时候二极管其实已经有一点点漏电流了，只是被万用表的量程淹没了。

再往上拧一点：46，快一点，47、48、49、50。电流又往上蹿了一点点。这时候把它拧下来，它还是正常的——刚刚确实已经过压了，但还没烧坏。

现在我直接猛地把电压拧上去，大家注意看，**击穿只是一瞬间的事**。吓我一跳——电压拧到差不多 60 V 的时候，就看到那个电阻冒烟了。因为电阻只有 10 Ω，值很小，60 V 加进去瞬间就把它烧断了。

电阻为什么会被烧断？因为**二极管已经短路了**，60 V 全部落在 10 Ω 上，功率大得直接烧穿。

拆下来用万用表蜂鸣档测一下，一接上就响了，说明二极管已经损坏。这就是二极管反向耐压的实验。这个实验还是有点好玩的——做完之后我现在都浑身发热。炸电阻、炸电容这类实验虽然说不会有什么危险，但确实很刺激。

> **结论**：正常工作在反向时，反向电压必须留出余量，别贴着最大反向耐压用。耐压标称值是"开始击穿"的量级，不是"还能安全跑"的量级。

### 稳压管：专门住在击穿区里干活的那种二极管

普通二极管反向击穿就等于报废。但有一种特殊的二极管——**稳压二极管**，它就是**被设计成可以工作在击穿区的**。它击穿之后不会像刚才那块一样直接坏掉，而且击穿之后，它两端的电压会等于一个额定值。

```text
    输入 3 V（低于稳压值 5.6 V）

     7 ──────────────┐
                     │
     3 V ───▷|───────┘      未击穿，等同于断开
                         输出 = 3 V


    输入 7 V（高于稳压值 5.6 V）

     7 ──────────────┐
                     │
     5.6 V ──|◁──────┘      反向击穿，把电压钳在 5.6 V
                         输出 ≈ 5.6 V
```

举个 5.6 V 的例子：给它一个 3 V 的 VCC，还没到击穿电压，这一端相当于断开，输出就是 3 V。等到电压上到 7 V，超过 5.6 V 了，它就击穿——但它不烧。击穿之后两端就是 5.6 V。

> **提示**：这 5.6 V 并非纹丝不动。**电流越大，电压会慢慢往上漂一点**，但仍然约等于 5.6 V 附近。这就是稳压管和普通二极管在反向击穿时最本质的区别。

这里有一个**必须注意**的点：稳压管反向击穿之后，它的电流是有限的。因为一旦击穿，它两端就有一个 5.6 V 的压降（不同型号稳压值不一样），流过电流 $I$ 的时候，稳压管上就有功耗了：

$$P = I \times V_Z$$

它会发热。当热量超过它的额定功率时，稳压管就坏了。

所以用稳压管稳压时，一定要盯住**稳压电流**——流下来的电流就叫稳压电流。这个电流**不能太大**，否则烧管；但也**尽量别太小**，太小的话就没那么稳。一般来说，建议稳压管的工作电流在 **5 mA 左右**就够了。不同型号不一样，大部分稳压管都在 5 mA 上下，大一点、小一点通常也不会有太大问题。

上实物。电路非常简单，就是一个电阻加一个二极管。

```text
    Vin ──┬── R（限流电阻）──┬──→ Vout ≈ 5.6 V
           │                  │
           │                 |◁  稳压管（必须反接才击穿）
           │                  │      黑色边 = N 极，无黑边 = P 极
           └──────────────────┴──→ GND
```

**稳压管要工作在反向击穿状态，接法必须反接**：这边接电源，这边接 GND。不反接，怎么击穿？

这里有个操作细节别忽略：**上电之前先把电源电压调回来**，不然一上去就直接击穿损坏。先把它调到 5 V。

我这块是 5.6 V 的稳压二极管。先把万用表接上测两端电压：输入 5 V，小于击穿电压，它是断开的，量到的两端电压也就是 5 V。然后把电源电压往上慢慢调：5.2、5.3、5.4、5.5、5.6、5.7。

注意看，从 5.6 V 开始，输入升到 5.7 V，它**停在 5.6 V 不动了**；输入到 5.8 V，它还是 5.6 V。这就说明稳压管已经击穿了，而且击穿之后还在正常工作，两端电压等于它的击穿电压。

接着，随着输入电压越高，流过它的电流就越大，稳压值会稍微往上漂一点。比如输入变成 6.4 V、6.5 V，电流已经到 6 mA 左右，这时候电压等于 5.64 V。再往上顶到 8.8 V，稳压值变成 5.7 V。继续调高，稳压值还会更高，而且调得很高的时候会发热——一旦超过额定封装的功率功耗，就有可能损坏。

> **易错点**：输入电压很高、又想让稳压管稳稳工作，很简单的办法：**把限流电阻加大**。电阻加大，电流就降下来了，功耗自然也就降下来了。

还有一个问题：稳压管如果不反接，正接可不可以？

**可以。** 正接的时候，它可以当成一个普通二极管来用。把电源反过来接，万用表测量方向也接回来，这边接电源、这边接 GND，打开电源。这时候二极管压降等于 **0.8 V**，相当于一个普通二极管压降。把电压减小，还是 0.8 V；再减小，还是 0.8 V。电流越大，它的正向导通电压也跟普通二极管一样慢慢往上升。正向特性跟普通二极管差不多。

> **结论**：稳压管与普通二极管最大的区别，就在于它**能工作在反向击穿区，而且击穿之后两端电压等于它的稳压值**。利用这一点，就能给电路提供一个简易的稳定电压。

### 三极管长什么样：像两个背靠背的二极管

前面讲完了二极管、电容、电感、电电阻，接下来我们上三极管。三极管简单来说就是一个**电子开关**，只不过这块会涉及到一些更好玩的知识点。

三极管有两种结构符号，一个 N 型、一个 P 型。

```text
    N 型三极管（NPN）              P 型三极管（PNP）

           │                              │
    ───────┤                              ├───
      E    │                          C   │
           │▷                             ◁│
    ───────┤                              ├───
      B    │                          B   │
           │▷                             ◁│
    ───────┤                              ├───
      C    │                          E   │
           │                              │
```

这两个三极管的内部结构是不一样的。前面讲二极管的时候说过，二极管由两种材料组成：一种 P 型半导体材料，一种 N 型半导体材料，组合在一起形成一个 PN 结，PN 结就是一个二极管。

三极管是由**三部分**组成的。N 型三极管的基本结构里，上面是 N 型半导体，中间夹一层 P 型半导体，下面又是 N 型半导体——从上到下就是一个 **N-P-N** 的结构，所以叫 N 型三极管。

```text
    NPN 的材料分布

        ┌───────────┐
        │  N 半导体  │   ← c
        └─────┬─────┘
              │   N 与 P 之间 → 一个 PN 结 → 一个二极管
        ┌─────┴─────┐
        │  P 半导体  │   ← b
        └─────┬─────┘
              │   P 与 N 之间 → 一个 PN 结 → 一个二极管
        ┌─────┴─────┐
        │  N 半导体  │   ← e
        └───────────┘

    PNP：材料分布反过来，P - N - P，
    两个二极管的方向变成"面对面"
```

所以看上去，N 型三极管就像是由**两个背靠背的二极管**组成一样：上面那块 N 和中间那块 P 形成一个二极管，下面那块 N 和中间那块 P 又形成一个二极管。

但是！这里有个特别关键的话我一定要强调：

> **易错点**：结构像两个背靠背的二极管，**不代表你拿两个背靠背的二极管接上去就能当三极管用**。外部直接这么接，它是没有任何三极管功能的。一定是要在这种结构形成在器件**内部**，才具备三极管的功能。

P 型三极管的结构跟 N 型很像，只是材料分布不一样：上面是 P 型半导体，中间是 N 型，下面又是 P 型，组成的同样是两个二极管，只不过方向是面对面的。这个"面对面"是发生在芯片**内部**的面对面——你在外部拿两个二极管面对面接起来，它同样没有三极管功能。

刚才说了三极管有三个部分，这三个部分是有名字的，分别叫**基极、集电极、发射极**，用三个字母表示：

| 电极 | 字母 | NPN 里的位置 |
| --- | --- | --- |
| 基极 | B（base） | 中间那层 |
| 集电极 | C（collector） | 一端 |
| 发射极 | E（emitter） | 另一端 |

右边有对应的三极管实物。但这里有个观念要先立住：**实物外面这个壳只是它的封装**，我们把这个叫封装。封装的意思就是芯片的衣服——芯片的衣服。封装里面所形成的芯片，可能是三极管，可能是 MOS 管，也可能是其他芯片结构。

> **提示**：不要看到这个样子就断定它是个三极管。衣服是所有芯片都可以穿的，真正要看的是芯片手册里内部到底是个什么东西。

所以通过基本结构我们就知道：不管 P 型还是 N 型，三极管都由三个电极组成，分别是 b、c、e，区别只在排列组合方式不一样。

拿实物来测一下，同样是能测到它对应的二极管的。这里拿一个 N 型的三极管，就是 NPN。它有三个电极，分别对应 e、b、c。按照前面说的半导体材料分布是 N-P-N，意味着它相邻之间有一个二极管：中间这一层与旁边的两根线，各自形成一个二极管。

```text
    NPN 实物，三个引脚

        ┌───────────┐
    c ──┤           │   c 与 b 之间有一个 PN 结
        │   NPN     │
    b ──┤           │   b 与 e 之间有一个 PN 结
        │           │
    e ──┤           │
        └───────────┘

    万用表二极管档：
      红表笔接 b，黑表笔接 c  → 读到 0.6 V 压降
      红表笔接 b，黑表笔接 e  → 同样读到 0.6 V 压降
```

我们用万用表实测一下：调到二极管档，红线接中间、黑线接旁边，会读到 0.6 的压降，说明中间和这一根之间是一个二极管；换到另一边，也一样是一个二极管。这就印证了：中间与旁边两根线各构成一个二极管，这就是 N 型三极管最基本的结构。P 型三极管是一样的，大家可以自己回去测一下。

### 三极管当电子开关：MCU 手里没有开关

讲完基本结构，我们来看三极管最基本的一个功能——**开关功能**。三极管可以简单地当成一个电子开关来用。

这个电子开关存在的意义是什么？我们举个例子：这里有一个 LED，假设供电是 5 V，我们想去控制它的亮与灭。人去控制的话，通常就是拿一个机械开关：手按下去，LED 有电流下来，它就亮了；不按，它就不亮。这是最简单的开关功能。

```text
    机械开关（人用手按）        三极管（MCU 用电信号控）

       A o───o───o B              c o─────o─────o e
             ↑                       ↑
          按下闭合                 I_b 一来就闭合
         按 / 不按                高 / 低电平
```

但实际电路里，很多时候都需要实现**自动化**。自动化就意味着电路里肯定有一个主控芯片 MCU。而要实现自动化，开关的控制就必须是 MCU 来做的。

MCU 去控制开关，这个开关当然不可能是机械开关。因为 MCU 不像人，人可以用手去按开关；**MCU 不能伸个手出来摸一下**。

> **结论**：想让 MCU 控制某个器件是否工作，就必须在电路里加一个**电子开关**——简单说，能用电信号去控制的开关，就叫电子开关。而这个电子开关，就是三极管。

三极管跟开关的结构其实非常类似。开关有 A、B 两个点，按下的时候 A、B 短路，不按的时候 A、B 断开。三极管的基本结构里，有一个叫集电极、一个叫发射极——**发射极和集电极跟 A、B 两端其实是对应的**，可以把 c 和 e 分别等效成开关的 A 和 B。

c 和 e 什么时候导通、什么时候关断，是由 MCU 送进来的信号控制的。怎样才能让 c、e 导通呢？当 b 和 e 之间流过一个电流的时候，我们把这个电流称为 **$I_b$（基极电流）**，这时候 c、e 就会闭合——简单来说就是导通了。这就是三极管最简单的导通条件。

串起来看：MCU 输出一个高电平，比如 3.3 V，这 3.3 V 经过一个电阻，再经过 b、e 形成一个电流。**有了 $I_b$，c、e 就闭合**，然后就会有 $I_c$ 流过。

有了 $I_c$，去控制一个 LED 就非常简单了：

```text
                    5 V
                     │
                  ┌──┴──┐
                  │     │
                  ▽     R   限流电阻
                  │     │
                  └─────┘
                     │
                     c
    3.3 V ── R_b ────┤
   （MCU 输出）       │  NPN
                     e
                     │
                    GND

    MCU 输出高电平 → 有 I_b → c、e 闭合 → 有 I_c → LED 亮
```

一样用实物演示。这里做了一个很简单的三极管控制电路：这一坨对应的是 LED，下来有一个电阻，然后这边就是三极管，这里有一个基极电阻，另外有一根线拉过来，对应的就是控制线。现有电路的结构跟刚才画的完全一样。有了这个结构之后，只要这里流过一个 $I_b$，对应的这里就会有 $I_c$，进而它就会亮。

我们把电接上去看：现在已经上电了。因为现在还没有把基极接到电源这里来，所以这时候灯是不亮的。把基极接一下，灯就亮了——很好理解，因为接进来之后这里就有电流流过来，所以它这里就会有电流过来。

实际的电路里，这条控制线是要接到主控芯片里面去的，我们这个板子上没有接芯片进来。

这就是三极管最基本的功能，在电路里通常就是当开关用。

> **提示**：三极管除了当开关，还可以**放大微弱信号**。但放大这一块其实比较少用，而且学起来比较复杂，所以在零基础的课程里就不展开了。现有的硬件课程里有讲到这个知识点，有兴趣的同学可以去看。

到这里，二极管这一路就完整了：正向单向导通帮你**控方向**，反向耐压告诉你**别超过哪条线**，稳压管故意住在击穿区给你**定一个电压**；再往前一步，换成三极管，它就不再只是被动挡电流，而是能被你用一个基极电流**主动开关**一整条回路。

> **承前启后**：上一节讲完「二极管控方向、稳压管定电压、三极管当开关」，下一节接着讲「三极管当开关用：限流电阻不能拍脑袋、饱和怎么判、P 管和 N 管怎么选」。

## 三极管当开关用：限流电阻不能拍脑袋、饱和怎么判、P 管和 N 管怎么选
> 对应块：BLK11 | 覆盖分集：P42-P47 | 块标题（分集名）：《38.三极管开关电路设计注意事项及计算方法》

### 同一个电机，10k 和 510 Ω 差在哪

先摆出我们最熟悉的那个电路：三极管当开关，负载挂在集电极，发射极接地，基极串一个限流电阻。

```text
  V_CC = 5V
     │          ┌─────────┐
     │          │  电机   │ ← I_C（负载电流）
     │          └────┬────┘
    R_B             C
     │         ┌────┴────┐
     B ───────►│         │
     │         │   NPN   │
     E ───────►│         │
     │         └────┬────┘
     └──────────────┤
                    GND
```

电流的路径很清楚：从 5V 出发，一部分经 $R_B$ 注入基极，另一条正路穿过电机从集电极进去、再从发射极出来回到地。$R_B$ 的作用就是限 $I_B$：电阻越大，$I_B$ 越小；电阻越小，$I_B$ 越大。

这里插在所有初学者心里的一根刺，是网上那一大堆"经验法则"。很多同学搜过"三极管限流电阻怎么取"，搜回来的答案往往是：随便取，1k 行，10k 也行，反正没出问题。

这句话在什么前提下成立？你的负载电流 $I_C$ 小于 100 mA。它小，基极电流那一点点余量就够了，随便取确实不出事。

问题在于，一旦电流大一点点。

我现场做给大家看。LED 电流太小，就几毫安，看不出名堂，所以我换了一个电机：这个电机在 5V 下正常工作电流是 500 mA。基极回路里我预先放了两个电阻，一个 510 Ω，一个 10 kΩ。现在按"经验法则"，我就随便取那个 10 kΩ。

```text
  V_CC = 5V
     │          ┌─────────┐
     │          │  电机   │ ← 需要 500 mA
     │          └────┬────┘
    10k              C
     │         ┌────┴────┐
     B ───────►│         │
     │         │   NPN   │
     E ───────►│         │
     │         └────┬────┘
     └──────────────┤
                    GND
```

接线、上电。电机转不转？**不转，一点动静都没有。**

但电流表不是这么说的——表上明明有 100 多毫安在跑。再拿热像仪对着看，这颗三极管已经飙到 116 度了。

于是就出现了极其拧巴的一幕：负载不动，器件在发烧。

> **易错点**：电机不转不等于没电流。这 100 多毫安根本没进电机，全变成了三极管上的热。这正是放大区干的坏事。

理想开关只有两个状态：开，和关。但三极管不是理想开关，它还有第三个状态——好像开了，又没完全开；好像关了，又没完全关。这个中间态就叫**放大状态**。

> **结论**：放大状态绝对不能用来带大电流负载。带了大电流，一边发热巨巨，一边负载不工作。

那把 $R_B$ 换成 510 Ω 再上电。电机唰地转起来了，电流表跳到 500 多毫安——电流比刚才大了四倍多。可热像仪再看，三极管只有 40 多度，比刚才那个"转不起来"的状态凉快得多。

这就是最反直觉的一课：**电流变大了，发热反而小了。** 因为 510 Ω 把三极管牢牢顶进了饱和导通，$V_{CE}$ 压降被压到了极小的那一档；10 kΩ 则把它留在了放大区，那 100 多毫安全耗在了 $V_{CE}$ 上。

所以那些在网上传授"1k、10k 随便取"的大神，很可能一直只做小功率电路——人家电流本来就小，取 1k 确实不出异常。你电流大了一点点还照抄，问题就来了。

> **易错点**：限流电阻不能靠经验法则，一定要按负载电流算。这一点非常重要。

### 判断三极管到底开还是关：只看两个量

那怎么算？先把判据摆清楚，因为只有分清"它到底在哪个状态"，后面的计算才有意义。

从电压角度看，就看 $V_{CE}$：

| 判据 | 条件 | 三极管状态 |
| --- | --- | --- |
| 看 $V_{CE}$ | $V_{CE} = V_{CC}$ | 截止（断开） |
| 看 $V_{CE}$ | $V_{CE} \leq 0.3\text{ V}$ | 饱和导通（完全导通） |
| 看 $V_{CE}$ | $0.3\text{ V} < V_{CE} < V_{CC}$ | 放大（危险） |
| 看 $I_B$ | $I_B = 0$ | 截止（断开） |
| 看 $I_B$ | $I_B \cdot \beta > I_C$ | 饱和导通 |
| 看 $I_B$ | $I_B \cdot \beta = I_C$ | 放大（危险） |

从电流角度看，只有一个不等式：

$$I_B \cdot \beta > I_C$$

$I_B$ 乘上电流放大倍数 $\beta$，如果严格大于集电极电流 $I_C$，三极管就在饱和导通；如果两者正好相等，说明它老老实实待在放大区。

那我们把它当开关用的时候，要求就很明确了：**要么截止，要么饱和导通，中间那个放大态必须绕开。**

> **定义**：饱和导通 = 完全开通。此时 $V_{CE}$ 只剩 0.3 V 甚至更低的那一点点，开关"闭合"得最彻底，发热也最小。

### 限流电阻 $R_B$ 怎么算：四步走

计算一共就四步，走完这四步，$R_B$ 就出来了。

**第一步，找出 $I_C$ 的最大值。** 它就是负载在工作过程中可能出现的最大电流。这个数去哪里查？查负载的数据手册或者产品信息，一般都查得到。我们前面那个电机，5V 下 500 mA：

$$I_C = 500\text{ mA}$$

**第二步，算出 $I_B$ 至少要多大。** 直接搬判据：

$$I_B \cdot \beta > I_C \quad\Longrightarrow\quad I_B > \frac{I_C}{\beta}$$

问题来了，$\beta$ 到底是多少？三极管的 $\beta$ 是会变的，跨度很大，通常 50 到 300 之间，甚至更高，所以我们没法精确知道它。

工程上的做法是：算的时候一律**默认 $\beta = 100$**，宁可保守一点，往大了留余量。于是：

$$I_B > \frac{500\text{ mA}}{100} = 5\text{ mA}$$

**第三步，用欧姆定律反解电阻。** 基极回路里那个回路方程摆在这儿：

$$I_B = \frac{V_{CC} - V_{BE}}{R_B}$$

要求的是 $R_B$，就把它搬过去：

$$R_B < \frac{V_{CC} - V_{BE}}{I_B}$$

其中 $V_{BE}$ 是三极管的导通压降，硅管一般按 0.7 V 算；$V_{CC}$ 我们自己定的，这里是 5 V；$I_B$ 取刚才算出的下限 5 mA。

**第四步，把数代进去。**

$$R_B < \frac{5\text{ V} - 0.7\text{ V}}{5\text{ mA}} = \frac{4.3\text{ V}}{5\text{ mA}} = 0.86\text{ k}\Omega = 860\ \Omega$$

算出来的 860 Ω 是**天花板**，是上限而不是目标值。真正选型的时候要选比它更小的那一档，留足余量——一旦取大了，就有可能一脚踩回放大区，回到"电机不转、器件发烫"那个坑里。

> **结论**：$R_B$ 必须按负载电流算，绝不能用经验法则。哪怕算出来的上限已经很小，也照样按算出来的来。

### 什么时候该用 P 管：N 管挂到上面为什么会发烫

上面这套是 N 管的"标准姿势"——它挂在负载的**下面**。挂下面意味着什么？意味着这个开关控制的是负载的**接地线**，负极那一路。

可现实里很多产品的需求不是这样。很多时候我们要控制的是负载的**电源线**。那把 N 管搬到上面去行不行？先按理想开关的逻辑推一遍：控制信号接基极，从发射极输出，闭合的时候 5V 照样送到负载，看起来一切正常。

```text
  V_CC (5V)
     │
     C
  ┌──┴──┐   B ◄──── R_B ◄──── 控制信号 (5V / 0)
  │ NPN │── E ────────────┐
  └─────┘                  │
                        ┌──┴──┐
                        │ 电机 │ ← 负载
                        └──┬──┘
                           │
                          GND
```

逻辑没问题，**但它特别容易发热**，尤其在功率稍微高一点的场合。为什么？

关键还是那个 $V_{BE}$。三极管 B、E 之间本身就是一个二极管。B、E 之间要流过 $I_B$，前提条件是 $V_{BE}$ 必须达到一个二极管压降，也就是 0.7 V。这个前提条件意味着什么？意味着不管外面给多高的电平，这 0.7 V 都得被扣掉。

举个例子：控制信号高电平 5 V，低电平 0 V。高电平来的时候，这一路电阻取得很小，输出点看起来应该接近 5 V——但实际上它**最高只能到 4.3 V**。因为 4.5 V 的时候，$V_{BE}$ 的导通条件已经不满足了，它就是过不去。

也就是说，输出点与发射极之间永远隔着一个 0.7 V。而这个输出点正是 C、E 之间的回路，结果就是 $V_{CE}$ 至少压着 0.7 V。过这个点的电流一大，发热当然严重。

现场演示：N 管，发射极作输出，基极回路电阻故意取 1 kΩ（实际可以取小一点，为了效果明显我才故意放大）。上电，电机也能转。但热像仪一照——三极管 116 度、120 度往上蹿。

> **易错点**：N 管以发射极作输出时，$V_{CE}$ 天生带一个不小的压差，电流一大就是纯发热。这类接法只适合功率很小的场合。

那怎么解决？最省事的办法就是换成 P 管。

```text
  V_CC (5V)
     │
     E
  ┌──┴──┐   B ◄──── R_B ◄──── 控制信号 (0 时导通)
  │ PNP │── C ────────────┐
  └─────┘                  │
                        ┌──┴──┐
                        │ 电机 │ ← 负载
                        └──┬──┘
                           │
                          GND
```

P 管为什么行？我们对比着看。N 管之所以"发射极输出就带 0.7 V 压降"，根本原因是**B 极的电压被负载这一侧的电压顶死了**，$V_{BE}$ 永远欠着 0.7 V，$V_{CE}$ 自然压不下去。

P 管的结构完全不同。它的电流方向跟 N 管正好相反，$I_B$ 是从**发射极流向基极**的；它的输出可以放在**集电极**上。这样一来，B、E 之间和我们这个负载之间就**没有直接联系**了——$V_{BE}$ 管好它自己那 0.7 V，跟负载这侧无关。

于是前面那套判据原封不动地又能用上：只要保证 E、B 之间流过来的 $I_B$ 乘以 $\beta$ 大于流过负载的 $I_C$，就是饱和导通。而饱和导通的 $V_{CE}$ 压降是非常非常小的，那个死结就解开了。

同样的实物演示，换成 PNP 管：接法换成 V_CC 进发射极、集电极接电机、电机另一头接地，控制信号经电阻进基极。按下 GND，电机转。测温度——只有 50 多度，跟刚才那个 120 度完全不是一个世界。

> **结论**：**P 管控电源，N 管控接地。** P 管是"电源开关"，N 管是"负极开关"，两者的工作场景不一样。

当然也不是绝对。功率比较小的时候，N 管用发射极输出也能凑合。另外有些特殊结构，比如加自举的电路，也能绕开发热问题——但加了自举，成本就上来了。所以常规做法还是老老实实按"P 管管电源、N 管管负端"来分工。

### P 管的 $R_B$，算法跟 N 管一模一样

计算过程一点不复杂，因为原理是同一套。

先确定 $I_C$ 最大值。电机还是那个电机，约 500 mA。

$$I_C = 500\text{ mA}$$

饱和导通的条件还是那个不等式：

$$I_B \cdot \beta > 500\text{ mA}$$

$\beta$ 同样默认取 100：

$$I_B > \frac{500\text{ mA}}{100} = 5\text{ mA}$$

$I_B$ 的下限拿到了，接着反解电阻。基极回路的方程换成 P 管的接法，写法一样：

$$R_B = \frac{5\text{ V} - 0.7\text{ V}}{5\text{ mA}} = \frac{4.3\text{ V}}{5\text{ mA}} = 860\ \Omega$$

上限依旧是 860 Ω，取值思路和 N 管那边完全一致。

顺便解释一下刚才那个演示。之所以测到 50 多度，是因为当时基极回路那个电阻取的是 1 kΩ，偏大了。如果跟前面一样取 510 Ω，温度应该能压到 40 多度。

> **提示**：P 管和 N 管的 $R_B$ 计算方法完全对称，唯一的差别只在电流方向。真正要做的是照着负载把数算一遍，而不是照抄任何人的经验值。

### N 管和 P 管，逻辑刚好相反

我们把两个管子摆在一起对比一下，结论会非常干净。

前面刚说过，B、E 之间就是一个二极管。那么 N 型的 B、E 二极管方向是从 B 指向 E；P 型因为是 PNP 结构，发射极是 P 型半导体、基极是 N 型半导体，它的 B、E 二极管方向是从**发射极指向基极**。

方向一反过来，导通条件就反过来了。

- **N 管**：要让 B 比 E 高出约 0.7 V，B 上必须来一个高电平。所以它是**高电平导通、低电平关断**。
- **P 管**：要让 E 比 B 高出约 0.7 V，那控制端就得是低电平。你把它拉低，E 与 B 之间才拉开电压，才会有 $I_B$ 流过去。

再补一个容易蒙的细节：为什么 P 管的控制端一定要拉低？如果控制信号断开（悬空）或接了 5 V，那么 E 和 B 两边都是 5 V，中间根本没有压差，$V_{BE}$ 不成立，$I_B$ 也就没有。输入从低电平跳到高电平时，这个 P 管是不会导通的。

| 对比项 | N 型（NPN） | P 型（PNP） |
| --- | --- | --- |
| B、E 之间的二极管方向 | B 指向 E | E 指向 B |
| 导通条件 | $V_B$ 比 $V_E$ 高约 0.7 V | $V_E$ 比 $V_B$ 高约 0.7 V |
| 什么电平导通 | 高电平导通 | 低电平导通 |
| 常见位置 | 负载负端（地开关） | 负载电源端（电源开关） |
| $R_B$ 上限（本例） | 860 Ω | 860 Ω |

> **易错点**：N 管和 P 管的工作逻辑是完全相反的。这一点非常容易搞混，设计之前先在纸上把导通条件推一遍。

### 三极管天生的"反相"本领

顺着上面这条逻辑，我们能得到一个非常实用的副产品。

看 N 管：输入低电平时它断开，输入高电平时它闭合。那么如果我们把**集电极**作为输出点，输出的信号跟输入信号之间，就天然存在一个反相。

```text
   V_CC
     │
    R_C
     │
     ├────────── 输出
     │
     C
  ┌──┴──┐
  │     │
  │ NPN ├── E ── GND
  │     │
  └──┬──┘
     B
    R_B
     │
  控制信号（输入）
```

为什么能反相？把 C、E 当成一个开关来看就明白了。

- 输入为 0 时，开关断开，回路电流 $I = 0$，电阻上的压降 $U = 0$，于是输出点电压是 $5 - 0 = 5$ V，高电平；
- 输入为高电平时，三极管导通，相当于把这个点"拉"到了地附近。注意它不是真短路，前面说过最小压降 0.3 V 甚至比 0.3 V 还小——但无论如何都可以等效为低电平，所以输出就是低。

输入 0 输出 1，输入 1 输出 0。这就是反相功能。

那反相能拿来干什么？举一个非常典型的客户需求。

客户有一套控制电路，能输出高低电平信号。他想用这个信号去控制一台机器，逻辑是：**低电平的时候机器工作，高电平的时候机器不工作。**

如果按我们前面讲的，用 P 管直接去控负载——低电平时 P 管导通，电流过去，机器工作；高电平时 $I_B$ 断了，机器停机。这逻辑不是刚刚好就对上了吗？

可现实有时候不这么配合。假设我们公司的 P 型三极管刚好用完了，而公司又在偏远小山区——你又不是在大城市，有电子商城可以骑个小电驴几分钟买到。这种地方你买不到 P 管，但你手上一堆 N 管都是现货。

这时候，就要靠 N 管的反相功能来变魔术了。

单个 N 管做不到这个逻辑。N 管天生高电平导通，画出来就是"低电平不工作、高电平工作"，跟客户要的正好反着。

那就在后级**再加一个三极管**，用第一级把控制信号反相一次，再拿反过相的信号去驱动后级的负载开关：

```text
  控制信号        第 1 级 NPN          第 2 级 NPN
     │          ┌─────────────┐      ┌─────────────┐
    R_B         │             │  R_B │             │
     │          │             │      │             │
     B ────────►│ B         C ├──────►│ B         C ├───┬── V_CC
     E ────────►│             │      │             │  ┌┴──┐
    GND         │        E    ├─GND  │        E    ├─GND│电机│
                  └─────────────┘      └─────────────┘  └┬──┘
                                                          │
                                                         GND
```

跟着电流走一遍就明白了：输入低电平时，第一级三极管不导通，第二级的基极就没有 $I_B$ 灌进来，于是第二级也不导通——可是负载这一侧的电流是通的，负载就工作。输入高电平时，第一级导通，把节点电压拉到接近 0（最多 0.3 V 左右），这点电压根本不足以让第二级三极管导通，负载于是停止工作。

低电平动作，高电平不动作。客户要的逻辑，一个三极管换来的反转，就位。

> **提示**：如果你想省成本，只用一个 N 管也能凑出同样的逻辑，但这种接法有风险。

具体怎么接？把 N 管的发射极接到 MCU 的那个输出引脚上，负载挂在 V_CC 和这个引脚之间：

```text
           V_CC
            │          ┌──────────┐
            ├──────────┤   电机   │ ← 负载电流
            │          └────┬─────┘
           R↑ (上拉)         │
            │          ┌────┴─────┐
            ├──────────┤ E        │
            │          │          │
            │          │   NPN    │
   控制信号 ──R_B──────►│ B        │
                       └──────────┘
                            │
                           GND
```

这个拓扑第一件要注意的事是：**MCU 输出脚的高电平电压必须等于 $V_{CC}$。** V_CC 是 5 V，那这个引脚输出的高电平也得是 5 V。

或者，把这个引脚配置成**开漏输出**模式，这样就不需要它输出高电平了——懂内部结构的同学知道，设成开漏就行，靠外面那个上拉电阻把节点顶到 V_CC。

但就算设成开漏，它**依然有风险**。风险在哪？当这个引脚输出低电平时，电流是从 V_CC 经负载流进这个引脚、再灌进芯片内部的。而芯片的灌电流能力是有限的，一般只有几毫安，最大也就十几、二十几毫安。负载电流要是非常大，芯片就可能被烧掉。

> **结论**：这种单管接法只能工作在小电流场景，通常在毫安级。电流大一点，芯片的吸收能力扛不住。

### 基极悬空是万恶之源：下拉电阻不能省

前面几个例子里，我们其实一直忽略了一个很重要的东西——**基极和发射极之间什么都没接**。这个电路特别容易受干扰。

我现场做给大家看。这次用 LED，简单直接。

最小系统：一个三极管，一个 LED。LED 接负极，发射极接正极，控制信号经导线接到基极。接上电源，用手点一下这根线，灯亮；松开，灯灭。逻辑完全正常。

然后我用**手碰一下这根线**。

灯也亮了。手松开，灯又灭了。我一碰它就亮。

> **易错点**：这不是玄学。基极悬空电路被干扰的概率极高，手只是最容易复现的一种干扰源。

为什么手一碰就有反应？因为人体只要待在这个电器周围，220 V 的工频电压就会在人体上感应出电荷来——这也叫静电感应。更关键的是，这份感应电荷带的是 220 V 交流电的信息，频率是 **50 Hz**。

所以我把手按下去的时候，灯不是稳定地亮，而是**一直在闪**。因为人体在不停地感应出 50 Hz 的电荷，这个电荷通过人体形成了一个 $I_B$ 回路，最终驱动了这颗 LED。

这类现象我们统称为**共模干扰**。本来电路应该只有"我点到电源它才工作"这一个触发路径，结果手随便一碰就多了一条路径。实际产品里，你碰的可能是一台机器——机壳、外壳、某些电路板都处于浮空、悬空状态，人一摸，机器上的数据就莫名其妙地跳。绝大多数就是共模干扰或者外来静电荷捣的乱。

那怎么解决？大方向是做接地处理。对我们这个三极管小电路来说，"接地"其实很简单——**在 B、E 之间加一个电阻**就够了。

```text
      N 型：加下拉                     P 型：加上拉

  控制信号                          控制信号
     │                                 │
    R_B                               R_B
     │                                 │
     ├──────┐                         ├──────┐
     │      │                         │      │
     B     R↓  下拉                   B     R↑  上拉
    ╱│      │                        ╱│      │
   E ╲     GND                      E ╲     │
    │  ╲                             │  ╲   │
   GND                              GND    │
                                           │
                                         V_CC
```

注意这个电阻的位置：**不是**从基极接到地，而是**跨接在 B、E 之间**，跟三极管自身并联。

加上去之后我再演示一遍。电路换一块板子，其它一模一样，唯一的变化就是基极和发射极中间多了这个电阻。

先验证功能：点一下，灯亮；松开，灯灭——正常工作没受影响。然后我再用手摸上去。

**灯不亮了。**

> **结论**：N 管做开关，基极必须加下拉电阻；P 管做开关，基极必须加上拉电阻。这条非常重要。

为什么加了就有用？因为人体感应出来的静电荷，能量是非常非常微弱的。既然微弱，那我加上这个电阻之后，电阻就能帮 $V_{BE}$ 分担掉绝大部分这些小功率噪声，同时给三极管提供一条释放静电、泄放外部干扰的回路。

从回路的角度看更直观：外部只要进来一丁点噪声，这些电荷最终是要到地上去的，它必然要经过 $V_{BE}$ 这个结点。没有这个电阻，噪声电流直接灌进 $V_{BE}$，一点点就足以把三极管点亮了。加了电阻之后，噪声有了另一条阻力小得多的路可走——从电阻泄到地，不再去挤 $V_{BE}$。

而且噪声能量本来就少得可怜，只要它在这个电阻上**建立不起 0.7 V 的压降**，三极管就绝不会导通，灯自然不亮。

P 管是一模一样的道理，只不过悬空线在 P 管这边同样会感应静电荷，泄放通路要相应地改成从 B、E 之间经过上拉电阻回到 V_CC。所以：

> **定义**：基极下拉电阻（N 管）/ 上拉电阻（P 管），是给悬空的基极提供一条确定的静态电平通路，同时充当外部干扰与静电荷的泄放通道。

所以一定要养成习惯：**只要用三极管当开关，基极就要加下拉电阻**；用 P 管，就是上拉。这不是可选项，是电路能稳定工作的前提。

> **承前启后**：上一节讲完「三极管当开关用：限流电阻不能拍脑袋、饱和怎么判、P 管和 N 管怎么选」，下一节接着讲「三极管耐压、比较器与红外感知电路」。

## 三极管耐压、比较器与红外感知电路
> 对应块：BLK12 | 覆盖分集：P48-P53 | 块标题（分集名）：《44.三极管的最大耐压》

前面几节课，我们把三极管当开关用得相当顺手：基极给个高电平，电流下来，负载通电；基极给个低电平，电流断了，负载断电。整个推导干净利落，电路图上一根线都不用多画。

这一回我要先把一句话摆到台面上：**三极管并不是一个理想开关。**

理想开关是什么？断开时电阻无穷大，两端爱承受多少伏都行。这一条不成立，就意味着三极管的两端承受电压是有极限的。往下我们会把这个极限亲手量出来，顺便看清楚三种结的耐压为什么差着一个数量级。

量完耐压，我们换个方向继续往下走：一个开关电路已经解决了"通和断"，但它不会思考。要让电路在没有人干预的情况下自己判断"该不该通"，就得给它装一个会做比较的脑子——这就是比较器；而要给这个脑子一个"外部世界的读数"，就轮到红外接收二极管和热敏电阻了。我们会拿自动出水水龙头和温控风扇这两个实物，把"感知—比较—驱动"这条链条完整走一遍。

### 三极管不是理想开关：耐压这条硬边界

#### 断开了不代表没有电流

很多同学在这里会有一个很自然的思维链条：三极管既然断开了，那就不会有电流下来，对不对？

对，但只对了一半。

请注意这一层：**虽然三极管已经断开了，但它并不是没有电流。** 因为一旦 $V_{\text{CC}}$ 升到某个程度，三极管就承受不住这个电压了。

承受不住会发生什么？会出现一个很危险的状态：有一个电流下来。这个电流刚开始是很小的。如果我们承受了一个很大的电压，但只在很短时间内出现了一点点小电流，随后就把这个电压撤掉，三极管一般还是安全的，甚至还会恢复过来。可如果给它一个很高的耐压，并且长时间都不撤掉，那三极管很可能就被击穿了。

这两者的区别不在电压本身，而在**时间**——一个脉冲是能扛住的，持续的高压是扛不住的。这一点后面讲续流二极管的时候还会再碰到。

#### 实测 VCE：标称 35V，一路加到 60V 也没炸

我们拿一颗 SS8050 来做演示。

接线很简单：基极那边加一个下拉电阻，让它稳稳处于断开状态；然后发射极接出，`VCE` 两端接上可调电源，我一点一点往上加电压。

- 加到 15V，电流一点都没有。
- 加到二十多伏，电流开始有一点点微微抖动——说明已经比较靠近临界状态了。
- 继续加，37、38、39、40V，电流出现的频次明显变高。

这时候当然还不至于炸。SS8050 的 $V_{\text{CE}}$ 耐压标称一般是三十多伏，通常写 35V 或 40V，不同厂家会有一点点差别。**一般加到六十多伏还是不至于炸掉**，只是这时候多少会有一点点漏电流，工作起来肯定也没有那么稳当了。

> **结论**：三极管的 $V_{\text{CE}}$ 耐压标称是 35V、40V 或 45V 这一档，而实测加到 60V 上下仍未击穿。这不是因为它"耐压有一百伏"，而是因为漏电流已经明显上来了，它其实已经在超负荷工作，只是不至于烧。

#### 实测 VBE 反向：十几伏就击穿，温度飙到一百多度

现在把实验对象换成 $V_{\text{BE}}$，景象就完全不同了。

在做这个实验之前，先记住一个操作细节，也请大家一定要记住：**关机之前先把电源调到最低。** 不要等电压一上来就炸给你看。

调好之后，正极接发射极，负极接基极——也就是给 $V_{\text{BE}}$ 加反向电压。慢慢往上拧：1、2、3、4、5、7、8、9、10……到 10V 附近，电流就出来了。**这时候它已经被击穿了，但还没烧。**

不过还没烧不代表没事。我们上手测一下温度：先是 48℃，这时候电流已经降下来了（刚降到 10），温度还只是慢慢往上爬；接着再测，温度立刻就上到一百多度。如果电压再往高推一点，那就不是"炸"了，而是会烧起来、冒很大的烟。

> **提示**：这里顺带把名词辨析一下。硅三极管的 $V_{\text{BE}}$ 反向击穿电压通常只有 6V 上下——这是硅材料本身的属性，不是某颗管子的个体差异。而硅的 $V_{\text{CE}}$ 耐压是几十伏的量级。同一颗管子里，两种结的耐压差了将近一个数量级，差的不是"做工"，是材料特性。

半导体不会像电容那样"炸"开，它是会烧起来的。冒出来的烟非常臭，所以我们就不演示这一段了。

#### 三个结的耐压排序，以及真正该盯的两个参数

把两个实验的结果摆在一起，三极管的耐压关系就很清楚了：

> **定义**：三极管内部有两个 PN 结——BE 结和 BC 结。BE 结工作在正偏时叫 $V_{BE}$，工作在反偏时就是 $V_{\text{BE}}$ 的反向耐压；BC 结则是 $V_{\text{CB}}$。通常所说的耐压大小，指的就是这三个组合的击穿电压。

| 耐压项 | 谁最弱 | 量级（以 SS8050 为例） | 平时要不要盯着它 |
| --- | --- | --- | --- |
| $V_{\text{BE}}$ 反向 | 最弱 | 6 V 上下 | 一般不看；只有电路里存在多个电源时才需要关注 |
| $V_{\text{CE}}$ | 居中 | 标称 35 V / 40 V | **主要看这一个** |
| $V_{\text{CB}}$ | 最高 | 可到 50 V | 基本不看 |

为什么 $V_{\text{CB}}$ 不用看？因为它的耐压一般都会比 $V_{\text{CE}}$ 更高。如果电压真的加到了 $V_{\text{CB}}$ 击穿的程度，那 $V_{\text{CE}}$ 这一部分早都已经先击穿了，根本轮不到它。

所以日常设计里，真正要盯的就两个：$V_{\text{BE}}$ 和 $V_{\text{CE}}$。

$V_{\text{BE}}$ 好办。只要工作电路接得正常，只要电路里不会出现多个电源打架的情况，它的 $V_{\text{BE}}$ 就不会承受反向耐压。**电路是要看情况的**，很多场景我们根本不用去查 $V_{\text{BE}}$ 的反向耐压值；除非电路里有多个电源，那就得来关注一下。

$V_{\text{CE}}$ 才是重灾区，因为三极管绝大多数时候就是当开关用的。当它关断时，CE 之间的电压就等于 $V_{\text{CC}}$。所以要求三极管的 $V_{\text{CE}}$ 耐压大于 $V_{\text{CC}}$——而且注意，这里不叫"反向耐压"，就叫 $V_{\text{CE}}$ 耐压，因为三极管两个端点之间并不分正反向，$V_{\text{CB}}$ 同理。

> **结论**：一般要求 $V_{\text{CE}}$ 的耐压大于 $V_{\text{CC}}$ 的 **1.5 倍以上，甚至 2 倍**，一定要留出余量。

当然，也不是说一超过 $V_{\text{CE}}$ 的耐压值它就一定会烧。前面我们已经量过了——加到 60V 它也没烧，只是漏电流稍微大一点点而已。只不过那时候它工作起来肯定没那么稳定了。

### 自动出水水龙头：从比较器到红外

#### 比较器只做一件事：比大小

先看实物。这个自动出水水龙头里最重要的两个东西：一个是电机，实际就是水泵；另一个是红外发射接收模块，用它来识别前面到底有没有物体。有物体，电机就转；没物体，电机就不转。

上电之后电机是不转的；手一放到前面，电机就转；手一放开，电机就停。再放下去，电机又转起来。我们在商场卫生间里见到的自动出水水龙头，行为模式就是这个：手一伸到位置，水哗啦啦流下来，人一走，它自动停。

那它凭什么知道自己前面有没有东西？这就要用到这一块的关键器件——**比较器**。

比较器的使用注意事项很多，这一篇里我们**一个都不讲**，只抓它最核心的工作特点；其余的特性与注意事项，等讲运放比较器的时候再专门展开。

现在只需要记一个知识点：比较器有两个输入端，分别叫 $V_+$ 和 $V_-$，还有一个输出端。输出端可以输出高电平，也可以输出低电平。什么时候出高、什么时候出低？

$$V_+ > V_- \;\Longrightarrow\; V_{\text{out}} = \text{高电平}$$
$$V_+ < V_- \;\Longrightarrow\; V_{\text{out}} = \text{低电平}$$

就这一条，够了。有这一条，我们就可以拿它去做一些最简单的逻辑控制。

#### 用比较器去开关一台电机

先在同相端加一个参考电压 $V_{\text{ref}}$，在另一个输入端加输入信号 $V_{\text{in}}$。按上面那条规律：

- $V_{\text{in}} > V_{\text{ref}}$，输出高电平；
- $V_{\text{in}} < V_{\text{ref}}$，输出低电平。

现在我手里有一路高低电平，想用它去控制电机转不转。这个逻辑就非常简单了——回到前面讲过的三极管开关电路。

假设这里用的是一颗 N 管：集电极接电机，电机另一端接 5V 电源，发射极接 GND；基极可以直接接比较器的输出。但比较器输出的高低电平一般要做限流，所以这里要串一个电阻；而三极管开关电路最好还要加一个下拉电阻。

```text
              ┌──────────────┐
              │ 比较器输出    │
              └──────┬───────┘
                     │
                     R (限流)
                     │
                     ├────► B ┌─────────┐
              ┌──────┴───┐     │         │
              │ R (下拉) │     │  N 管   │ C ──┬──► 电机 ──► VCC
              └──────┬───┘     │         │     │
                     │         └─────────┘ E ──┴──► GND
                    GND
```

整个过程就是这么走：假设 $V_{\text{CC}} = 5\text{ V}$，当这一点变成高电平 5V 时，它就相当于给 $V_B$ 供电，$V_B$ 里流过 $I_B$，有 $I_B$ 就一定有 $I_C$，于是电机转起来。反过来，当这一点从高电平变成 0V 时，$I_B$ 没有电流，CE 断开，电机就不转。

这就是"比较器控制电机"最简单的框图。

但放到自动出水水龙头上，光有这个还不够——**它缺一个"检测前方有没有物体"的功能。** 水龙头不会自己想什么时候出水就什么时候出水，必须先判断出前面有人，才肯出水。

#### 红外接收二极管：没收到红外的时候才是断开的

要实现这个检测，又要用到一个新元器件：**红外接收二极管和红外发光二极管**。

这里先记住它的基本特性，它是一个很"神奇"的器件——**它在电路里是反向去接的。**

普通二极管我们都很熟：电流从电源经二极管流向 GND，PN 结正偏，这样就能正常工作。红外接收二极管却正好反过来：它的 **P 极接 GND，N 极接电源端**。

反接之后，它有一个非常要紧的特性：

> **定义**：当红外接收二极管没有接收到任何红外信号时，可以简单认为它处于**断开**状态；接收到红外光时，它就**导通**，并流过一定的电流。而且这个电流的大小与红外光的亮度成正比——红外光越亮，电流越大。

原理也很直白。拿个红外遥控器对准它按几下，遥控器发射出红外光，红外光打到接收管上，接收管就导通、就有电流流过。

#### 把两半接起来：4.5V 门槛是怎么算出来的

有了"无红外即断开、有红外即导通"这个特性，就可以拼出自动出水水龙头了。先把红外接收管那一半画出来：

```text
      VCC = 5V
        │
      R = 100 kΩ
        │
        ├──────────────► V   (送比较器)
        │
      ┌─┴─┐
      │ ▼ │  红外接收二极管
      └─┬─┘  (P 接 GND, N 接节点)
        │
       GND
```

我们要实现的逻辑是：**收到红外 → 电机转；没收到红外 → 电机不转。**

先来算这个节点电压 $V$。它等于 $V_{\text{CC}}$ 减去电阻上的压降，也就是减去 $R$ 乘上流过电阻的电流。而流过电阻的电流就等于红外接收二极管的工作电流，我们把它记作 $I_R$：

$$V = V_{\text{CC}} - R \times I_R$$

**情况一：用屏障把红外挡住。** 红外发射管的光射不到接收管，接收管断开，$I_R = 0$。于是

$$V = 5\text{ V} - 100\text{k}\Omega \times 0 = 5\text{ V}$$

**情况二：把屏障拿掉。** 红外射过来，接收管导通，有 $I_R$ 流过。这个电流不会很大，我们假设它是 $10\ \mu\text{A}$；电阻就取 $100\text{k}\Omega$。这一步计算值得展开看，因为它是这类分压电路的通用套路：

$$10\ \mu\text{A} \times 1\text{k}\Omega = 10\text{ mV}$$
$$10\text{ mV} \times 100 = 1\text{ V} \;\Longrightarrow\; 100\text{k}\Omega \times 10\ \mu\text{A} = 1\text{ V}$$

所以

$$V = 5\text{ V} - 1\text{ V} = 4\text{ V}$$

**门槛定在 4.5V。** 在比较器的同相端 $V_+$ 上，用两个电阻分压：上面一颗 $5\text{k}\Omega$ 接 5V，下面一颗 $45\text{k}\Omega$ 接 GND，分出来的电压就是

$$V_+ = 5\text{ V} \times \frac{45\text{k}\Omega}{5\text{k}\Omega + 45\text{k}\Omega} = 4.5\text{ V}$$

而红外检测出来的那个节点电压 $V$，接比较器的**反相端 $V_-$**。

现在两条逻辑就对上了：

| 状态 | $I_R$ | 100 kΩ 上的压降 | $V_-$（检测点） | $V_+$（门槛） | 比较器输出 | 电机 |
| --- | --- | --- | --- | --- | --- | --- |
| 红外被挡住 | 0 | 0 V | 5 V | 4.5 V | 低电平 0 V | 不转 |
| 红外射过来 | 10 μA | 1 V | 4 V | 4.5 V | 高电平 5 V | 转 |

看第二行：$V_+ = 4.5\text{ V} > V_- = 4.0\text{ V}$，输出高电平 5V，基极就有 $I_B$，三极管导通，电机转。第一行反过来，$V_+ = 4.5 < V_- = 5.0$，输出低电平 0V，三极管断开，电机不转。

> **易错点**：检测点一定接**反相端**，门槛电压接**同相端**，不要接反。记忆的办法很简单——问自己一句"哪个电压是随着红外强度往反方向走的"：红外一来，接收管导通，$I_R$ 变大，电阻上的压降变大，检测点电压 $V$ 反而**变低**。所以要让"红外一来就动作"，$V$ 就必须放在反相端。
>
> 这里还有一个反直觉的地方值得停一下：明明是"有红外"的时候，检测点的电压却比"没有红外"的时候**低**。原因就是上拉电阻——没人接收红外时，$I_R$ 恰恰是零，那 100kΩ 上一点压降都没有，节点被完整地拉到 $V_{\text{CC}}$。

#### 实物模块：遥控器、打火机，以及必须关紧的窗

刚才那张图是理想化的分立电路。真实的自动出水水龙头里，红外模块是集成在一起的，看起来复杂，但把它拆开来，其实就是我们左边框起来的那点东西：

- 那个像芯片一样的东西，就是**比较器**；
- 旁边几个贴片电阻，就是我们图里的分压电阻和限流电阻；
- 那个黑不溜秋、像 LED 一样的元件，就是**红外接收二极管**。

而红外发射源就装在旁边。它的电路也很简单：**只跟一个电阻串联**。一供电就有电流下来，红外发光二极管就亮了。

它的原理和前面画的图完全一致，只不过**红外发光二极管正对着红外接收管**。当我用手挡住的时候，发射管发出的红外光射到我的手上，手再把红外光反射回到接收管，接收管收到，模块就输出对应的电平；手不挡的时候，光直接射走了，不往回弹，接收管收不到。

**第一个意外玩法：用遥控器当开关。** 前面有同学可能会想到——既然遥控器能让红外接收管导通，那不挡它、直接拿遥控器对着接收管按，不就能控制电机了吗？确实可以。在那里把红外发光二极管**拔掉**，先上电，电机不会转；这时用遥控器按一下，电机就转一次，同时能看到接收到红外光时那盏灯会亮。

**第二个意外玩法：做火焰检测。** 火焰本身也会发射红外光，所以拿个打火机点着，电机照样会转。

**一个必须记住的调试坑：白天调试要把窗户关紧。** 因为太阳光里也掺杂着红外线。如果窗户没关严，房间里到处都是太阳光里的红外，模块就"不受控"了——不挡和挡的效果看起来一模一样，因为接收管一直在接收红外，电机就一直转。

> **提示**：这也说明，利用这一个电路，我们还可以用来检测环境中红外光的亮度有没有达到某个额定值——本质上它就是一个"光照强度开关"。

#### 少了一枚续流二极管：断开瞬间窜出 18V

现在来看这个电路的缺陷：**少了一个续流二极管。** 大家看实物，电机这一路上确实没有并联任何东西。

我们来做个实验，看没有续流二极管时，开关断开的一瞬间会发生什么。

> **注意**：做这个实验之前，**务必先把示波器档位调大一点，用 $\times 10$ 档**。因为这里很容易产生很高的尖峰电压，档位没调好会直接把探针烧了。

接好线、关掉环境灯光，然后断开：

```text
       VCC = 5V
         │
         ├──────────────┬──────────────┐
         │              │              │
        (阳)           ┌─┴─┐          (阴)
         │            │ 电机 │           │
         │            └─┬─┘           │
         │              │              │
         └──────────────┴──────────────┘
                        │  ← 续流二极管 D
                        C
                     ┌──┴──┐
                     │ N管 │
                     └──┬──┘
                        E
                       GND
```

示波器上一目了然：断开的瞬间，出现了一个很高的脉冲电压，峰峰值 $V_{\text{PP}}$ 读数约等于 **18V**。

注意我们的电源才 5V。5V 的供电，断开一瞬间窜出 18V，而且这 18V **还偏小了**——这个电机功率本来就不大，我们也只是随便测一下；如果拿一台更精密的示波器去测，能看到的电压应该更高。

为什么会这样？因为**电机是电感性负载，而电感有一个特点：电流不能突变。**

开关闭合的时候，电流从上往下走；突然一断开，前面的回路没了，可是电感有个很"变态"的能力——为了让它的电流保持不变，它理论上可以感生出无穷大的电压。所以它就冲出一个比我们电源电压高得多的感生电压。

> **定义**：这个电压本质上就是电感在给开关"充电"的结果。因为电流不能突变方向，能量必须找地方释放，于是开关两端承受了一个远高于电源的尖峰。

如果说你的三极管承受不住那么高的电压，它就击穿了——注意用词，是击穿，不是炸。

**正确做法就是加续流二极管**：把一颗二极管反向并联在电机两端（阴极接 $V_{\text{CC}}$ 侧，阳极接三极管集电极侧）。开关断开的瞬间，感生出来的电动势会自己给这个回路供电流，三极管两端就不必硬扛那个尖峰了。

到这里，自动出水水龙头的工作原理就算讲完了。回头看你会发现，电路真的非常简单——**在商场里用得最多的这类产品，电路就是这么简单。**

### 比较器的两种输出结构：为什么有的必须加上拉电阻

这里还有一个必须注意的事项，而且它是一个特别容易踩的坑。

前面我们说过，$V_+ > V_-$ 时输出高电平，$V_+ < V_-$ 时输出低电平。听起来好像只要接对了就一定是高就是低。但请注意——**并不是所有比较器都能主动地输出高电平和低电平。** 它能不能主动输出高，取决于它的**内部结构**。

**第一种：推挽输出。** 输出端的内部有两个开关，一个接到 $V_{\text{CC}}$，一个接到 GND。

```text
        VCC
         │
        (上开关)  ┌─────┐
         │        │     │
   输出 ─┼────────┤     ├── 输出线
         │        │     │
        (下开关)  └─────┘
         │
        GND
```

上面那个开关闭合时，输出线经它接到 $V_{\text{CC}}$，所以高电平就等于 $V_{\text{CC}}$；上面断开、下面闭合时，输出线通过这个开关与 GND 连在一起，就变成低电平。这种"一个开关接 VCC、一个开关接 GND"的结构，就叫推挽输出。**它可以主动地输出高低电平。**

**第二种：开漏输出（也叫开集电极输出、开集输出）。** 它比推挽少了一个东西——**那两个开关里的上管是没有的**。它的输出信号线上只有一个开关接到 GND，上面那个接到 $V_{\text{CC}}$ 的开关不存在。

```text
        VCC
         │
     [外接上拉电阻]
         │
   输出 ─┼────────┬───────────► 输出线
         │        │
        (开关)   [ 后级输入
         │        │  高阻态 ≈ 大电阻
        GND       │
                  GND
```

这样的结构，输出线**只能被拉到低电平，它自己变不出高电平**。所以我们就得在它外部加一个**上拉电阻**，用它把信号线上拉成等于 $V_{\text{CC}}$。

它是怎么实现的？用分压原理算一遍就明白了。假设上拉电阻是 $1\text{ k}\Omega$，后面接的那个器件作为输入时一般处于高阻态，可以简单认为它是一个**非常大的电阻**到地，比如 $1\text{ M}\Omega$：

$$5\text{ V} \times \frac{1\text{ M}\Omega}{1\text{k}\Omega + 1\text{ M}\Omega} \approx 5\text{ V} = V_{\text{CC}}$$

所以开关断开之后，这一点电压就被上拉电阻拉到了约等于 $V_{\text{CC}}$（因为分母里的 $1\text{k}\Omega$ 相对 $1\text{ M}\Omega$ 实在太小，分出来的电压几乎全在上拉电阻上）。

而当开关闭合时，输出线被比较器内部的开关**短路到 GND**，这一点电压就变成 0。

| | 推挽输出 | 开漏 / 开集输出 |
| --- | --- | --- |
| 输出端内部 | 两个开关：一个接 VCC，一个接 GND | 只有一个开关接 GND |
| 能否主动输出高电平 | 能，高电平 ≈ $V_{\text{CC}}$ | **不能** |
| 是否必须加上拉电阻 | 不必须 | **必须** |
| 接上拉电阻的作用 | 增强输出能力（有些推挽也会加） | 补出高电平 |

所以回到那个问题——**为什么有些比较器一定要接上拉电阻，有些又不用？** 就看内部结构：开漏输出一定要加，推挽可以不加。另外有些推挽结构也会加上拉电阻，加上去是为了加大电路输出电平的能力。

### 温控风扇：把温度换算成一个电压

先看实验效果。接上电，看一下有没有接反——然后效果就非常明显了：用右手去按住热敏电阻，识别到温度高了，电机就转；放开，电机就不转；再按一下，电机又转起来。

还有一个更细致的现象：**随着温度越高，电机的转速可以越快；温度越低，转速越慢；如果温度低到开通阈值以下，电机就直接不动了。**

> **提示**：转速随温度连续变化这件事，靠的不是模拟电路，而是 PWM 调速，后面会讲。

温控风扇的原理很简单：**当电路模块识别到温度达到某个值的时候，就驱动电机。** 电机加上扇叶，就是温控风扇。

电路同样用到了比较器。逻辑我们已经很熟了，$V_+ > V_-$ 输出高，$V_+ < V_-$ 输出低。这里换一种管子来讲——前面举的例子都是 N 管，这次用 **P 管**。

#### 门槛定在 2.5V，和一枚温度越高阻值越小的热敏电阻

我们的工作逻辑是：当温度 $T$ 达到或大于 $36^\circ\text{C}$ 时，要求风扇转；当 $T \leq 36^\circ\text{C}$ 时，让它不转。

> **提示**：如果要取两个不同的温度值来做"带迟滞的开关"，电路得加一个迟滞比较器。这里不做那么复杂的逻辑讲解，只做一个简单的开关功能。

先在**反相端**加一个参考电压。加法非常简单：一个 $1\text{k}\Omega$ 接 5V，另一个 $1\text{k}\Omega$ 接 GND，分压出来就是 $2.5\text{ V}$。

```text
   VCC = 5V
      │
    1 kΩ
      │
      ├──────────► V- = 2.5V
      │
    1 kΩ
      │
     GND
```

要实现温度控制的逻辑，首先必须找到一个**跟温度相关的器件**。最简单的就是**热敏电阻**：可以简单认为它就是一个可变电阻，只不过电阻的变化规律跟温度绑在一起。

热敏电阻有两种特性：

> **定义**：**正温度特性**指温度 $T$ 越大，电阻 $R$ 也越大；**负温度特性**刚好相反，温度越高，阻值越小。

我们这里选**负温度系数的热敏电阻（NTC）**，温度越高阻值越小。

接下来这一步是整个推导的关键，一定要跟住：

- 用 **P 管**驱动电机，P 管是**高电平不导通、低电平才导通**；
- 所以电机要转，比较器必须输出**低电平**；
- 要输出低电平，前提是 $V_+ < V_-$；
- 而 $V_-$ 是那个固定的 2.5V 门槛；
- 于是要求：**温度大于 $36^\circ\text{C}$ 时，$V_+$ 要比 $V_-$ 小**。

翻译成一句话就是——**温度越高，$V_+$ 要越小。** 那就用负温度系数的热敏电阻去做这个"随温度变小"的电压。

#### 从 25℃ 到 36.1℃：把分压算一遍

电路搭成这样：热敏电阻接在下面（对地），上面一颗固定的 $1\text{k}\Omega$ 接 5V，分压点送比较器的同相端。

```text
      VCC = 5V
        │
    R1 = 1 kΩ (固定)
        │
        ├──────────────► V+  (送比较器同相端)
        │
    ┌───┴───┐
    │  NTC   │  热敏电阻
    │ 10kΩ@25℃  1kΩ@36℃
    └───┬───┘
        │
       GND

      V- = 2.5V  ← 1kΩ 接 5V / 1kΩ 接 GND 分压
```

**25℃ 时**：假设热敏电阻等于 $10\text{k}\Omega$。

$$V_+ = 5\text{ V} \times \frac{10\text{k}\Omega}{1\text{k}\Omega + 10\text{k}\Omega} \approx 4.5\text{ V}$$

这时候 $V_+ = 4.5\text{ V}$ 比反相端的 2.5V 要大，$V_+ > V_-$，所以**输出高电平**。高电平时 P 管不导通，于是电机不转。✓

**36℃ 时**：热敏电阻刚好等于 $1\text{k}\Omega$。

$$V_+ = 5\text{ V} \times \frac{1\text{k}\Omega}{1\text{k}\Omega + 1\text{k}\Omega} = 2.5\text{ V}$$

正好等于门槛电压，这是个临界点。

**36.1℃ 时**：温度再高一点点，热敏电阻就比 $1\text{k}\Omega$ 小了。节点电压也跟着变一点点：

$$V_+ = 2.499\text{ V}$$

而 $2.499 < 2.5$，$V_+ < V_-$，于是**输出低电平**。一输出低电平，P 管就导通，电机转起来了。✓

> **结论**：整个温控逻辑就是靠"负温度系数热敏电阻 + 分压 + 比较器"这三件事拼出来的。温度越高，NTC 阻值越小，$V_+$ 越低；一旦 $V_+$ 跌破 2.5V 这个门槛，比较器翻成低电平，P 管导通，风扇转。

| 温度 | NTC 阻值 | $V_+$ | $V_-$ | 比较器输出 | P 管 / 电机 |
| --- | --- | --- | --- | --- | --- |
| 25℃ | 10 kΩ | ≈ 4.55 V | 2.5 V | 高 | 不导通，不转 |
| 36℃ | 1 kΩ | 2.5 V | 2.5 V | 临界 | 临界 |
| 36.1℃ | < 1 kΩ | 2.499 V | 2.5 V | 低 | 导通，转 |

回头再看这张表就会发现一件事：**门槛电压 2.5V 的设计，等价于要求在 36℃ 时 NTC 的阻值刚好等于那颗固定的 $1\text{k}\Omega$。** 所以真正要算的其实是热敏电阻的阻温曲线，而不是随便挑一个 2.5V。

#### 换成 P 管驱动，以及那枚仍被漏掉的续流二极管

来看实物的连接。框图和实物是一模一样的，先断电对比一下：模块对应框图画的那部分，出来有一个电阻对应框图里的电阻，电阻过来接到 P 管，P 管下来到电机，上面接 $V_{\text{CC}}$。

> **提示**：这里再复习一遍前面讲三极管开关电路时的结论——**P 管要加上拉电阻，N 管要加下拉电阻。** 用哪种管子，就得配哪种电阻，这一条别搞混。

这个电路同样有一个缺陷，就是**没有加反向的续流二极管**。正常来说应该再加一个。

本来应该测一下它感生出来的高压，但因为这种尖峰前面已经量过一次了——5V 供电、断开瞬间冲到十几伏甚至更高——这里就不再重复测了。

**最后再演示一遍**：用手握一下热敏电阻，等温度上来，电机就转；一放开就不转。这就形成了温控风扇。

温控风扇经常会用在电脑里面的 CPU 等设备上。电脑 CPU 里的温控风扇是用 **PWM 去调制**的，所以可以实现**温度越高、风扇转速越快；温度越低、转速越慢**——是连续可调的，而不是到了 36℃ 就"啪"一下全速转起来。这也解释了为什么开头演示时，除了转与不转，还能观察到转速快慢的变化。

## 感应灯的"眼睛"，与 MOS 管的开关脾气
> 对应块：BLK13 | 覆盖分集：P54-P58 | 块标题（分集名）：《50.人体感应灯工作原理》

进便利店的时候那句"欢迎光临"，不是有人按了什么按钮，是靠一双看不见的眼睛看见了你。这双眼睛叫热释红外传感器。

这一讲我们把它拆开看：它怎么把"有人"变成一个电压，这个电压又怎么变成灯亮不亮。顺着这条线往下走，还有一个几乎一模一样的问题——太阳出来了灯就该灭，太阳下去了灯就该亮。把"感知红外"换成"感知亮度"，就是一个光控灯。这两件事电路骨架几乎一样。

然后我们正式进入 MOS 管。这个东西和三极管一样是电子开关，但脾气完全不一样：它是电压控制型的，栅极上根本不要电流。理解了这个差别，低功耗芯片为什么爱用它，也就顺理成章了。

### 热释红外传感器：把体温变成电压

热释红外传感器的核心，是一块很特殊的材料。它里面有一块热电材料——红外信号照进来的时候，这块材料的两边就会感生出一个电压。

这个电压非常非常微弱，微弱到必须放大才能用。所以传感器内部还集成了一个三极管或者 MOS 管，负责把这个微弱电压放大。放大之后从两端引出来，就是一个能用的信号。

```text
                  人体 / 发热物体发出的红外辐射
                  ↓   ↓   ↓
    ┌─────────────────────────────────────────────┐
    │          热释敏感材料（热电材料）           │
    └──────────────────────┬──────────────────────┘
                           │ 材料两端感生出微弱电压 Vp
            ┌──────────────┴──────────────────┐
            │  MOS 管（或三极管）把 Vp 放大   │
            └──────────────┬──────────────────┘
                           │
                           ▼
                放大的电压信号，可直接送进比较器
```

> **定义**：热释红外传感器（PIR）＝一块会对入射红外感生出微弱电压的热电材料 ＋ 内部集成的一级放大。

为什么这里应该画 MOS 管而不是三极管？这一点很容易搞错，值得单独说清楚。

三极管是电流控制器件，它必须先有 $I_B$ 基极电流，才会产生 $I_C$ 集电极电流。没有 $I_B$，三极管根本不工作。而我们这块材料感生出来的是**电压信号**，不是电流信号。电压信号恰好是 MOS 管的"食物"——MOS 管是电压控制器件，它只要 $G$ 极上有电压就行，压根不需要电流。

所以选放大器件要看输入信号的**性质**：输入是电压，就配电压控制器件；输入是电流，才考虑电流控制器件。这一条记住了，后面 MOS 管那一节还会再碰见它。

> **提示**：MOS 管的知识点还没正式讲，先记住结论就行——这一级用 MOS 管放大微弱电压，是对的。

#### 加上拉电阻，电压就"跳"出来了

传感器输出的东西是电压，但它得挂在一个能形成"高电平／低电平"的电路里，才好往下游送。做法是加一个上拉电阻接到 $V_{CC}$，然后把这一点引出来当输出。

```text
               V│C
                │                   无红外：MOS 截止 → Vout = VCC（高）
              ┌─┴─┐
              │ R │                 有红外：MOS 导通 → Vout = VCC − I·R（低）
              └─┬─┘
                │   ↑ 上拉电阻      V_R = I × R，电流越大拉得越低
                │───────► Vout
                │
             ┌──┴──┐
             │ MOS │
             └──┬──┘
              GND
```

看图读逻辑，两种状态很清楚：

- **没有红外进来**的时候，MOS 管截止，相当于断开。断开的那一点不会掉电，所以这一点就等于 $V_{CC}$。
- **有红外进来**的时候，材料感生出电压，把 MOS 管导通。导通了就有电流 $I$ 流过电阻，电阻上产生压降 $V_R = I \times R$，所以这一点电压等于 $V_{CC} - V_R$。

结论：有人靠近，输出电压从 $V_{CC}$ 往下掉。

> **结论**：人体感应灯的整个"感知"环节，最后落成一件很简单的事——**让人靠近时，输出电压变低**。

你可能会发现，这个逻辑跟我们前面讲的红外接收二极管有点像。对，逻辑确实差不多：都是"有信号时输出被拉低"，只不过一个靠光电材料导通产生光电流，一个靠热电材料感生出电压去导通 MOS 管。

### 比较器：把连续电压切成"是"和"否"

现在手里只有一个连续变化的电压（没人在 5V 附近、有人在 3V 附近），但我们真正要的是"是"和"否"两个状态——要不要亮灯。要把连续量翻译成开关量，最省事的办法是比较器。

整个模块的骨架就这么四块：

```text
                                 有人 → 亮　　／　　无人 → 灭
  ┌─────────────────┐     ┌─────────────────┐     ┌───────────────┐     ┌───────────┐
  │ 热释红外传感器  │ ───►│  比较器 + Vref  │ ───►│ 驱动管 P / N  │ ───►│LED + 限流 │
  └─────────────────┘     └─────────────────┘     └───────────────┘     └───────────┘
```

传感器那块我们刚讲完。后面的两块，一个是比较器，一个是驱动管。下面把这两块拆开。

#### 先想清楚比较器接哪个脚

比较器的规矩是：同相端（$V_+$）电压高于反相端（$V_-$），输出高；反了，输出低。

人体经过时会发生什么？人只要有热量就会往外辐射红外信号，所以人一过，材料就感生出电压，MOS 管导通，输出电压从 $V_{CC}$ 往下走。

那问题来了：无人时输出 $V_{CC}$（高），有人时输出低。也就是**有人＝低电平，无人＝高电平**。

那么参考电压 $V_{ref}$ 怎么设？它必须夹在两个状态之间：

- 无人时：$V_{in} = V_{CC} = 5V$
- 有人时：$V_{in} = V_{CC} - IR = 3V$
- 于是 $V_{ref}$ 取 4V，正好落在 3V 和 5V 中间

$5V > 4V$ → 输出高（无人）；$3V < 4V$ → 输出低（有人）。

```text
                    传感器信号不变，只把比较器的两个输入对调，就换成另一种驱动管
            接法一：用 P 管驱动                                    接法二：用 N 管驱动
      ┌────────────────┐  Vref → V-（反相端）                ┌────────────────┐  Vref → V+（同相端）
      │     比较器     │  Vin  → V+（同相端）                │     比较器     │  Vin  → V-（反相端）
      └────────┴───────┘                                     └────────┴───────┘
               │                                                      │
               ├───────────► G                                        ├───────────► G
               │                                                      │
         ┌─────┴─────┐                                          ┌─────┴─────┐
         │   PMOS    │                                          │   NMOS    │
5V ────► │S        D │                                 GND ───► │S        D │
         └─────│─────┘                                          └─────│─────┘
               └──► LED + 电阻 → GND                                  └──► LED + 电阻 → GND
                                                       
                                                       
                                                       
                                                       
                                                       Vref 取 4V，落在 3V 与 5V 之间
无人：输出高 → P 管断 → 灯灭                           无人：输出低 → 断 → 灯灭
有人：输出低 → P 管通 → 灯亮                           有人：输出高 → 通 → 灯亮
                                                       
                                                       
                                                       
```

图上这两种接法我都画了，你对着看会发现一件事：**传感器信号一个字节都没改，改的只是比较器两个输入端谁接 $V_{ref}$、谁接 $V_{in}$。** 逻辑极性一翻，下游的驱动管就跟着从 P 管换成 N 管。

> **易错点**：`$V_{ref}$` 一定要设在两个电平之间。如果它比 $V_{CC}$ 还高，那无论有没有人，比较器输出都一样，这个灯就永远只会有一个状态。

选哪个都行，看你手边有什么管子。用 P 管的时候，输出低就导通，LED 一亮就是"有人"；用 N 管的时候把两个输入对调，输出高就导通，一样是有人才亮。这两种接法殊途同归，别去纠结哪个"更标准"。

#### 实物演示

这里可以拿个现成的模块试一下。站在模块前面，灯是灭的；手划过去，灯立刻亮。手走开，灯灭。

这里有个现象特别值得留意：**手停住不动，灯就灭了；手一晃，又亮了。**

热释红外有个特点，就是它只能识别**移动的**发热物体。静止不动的东西，它是识别不了的。这是传感器内部的基本特性，更深一层的工作特性我们后面讲到更深入的地方再展开。

> **结论**：静止的发热物体不算"有人经过"。想让人站着不动灯也亮，得换 PIR 模块上那个带菲涅尔透镜的版本。

### 光控灯：同一副骨架，换一双眼睛

光控灯的原理，我觉得是我们前面这几个模块里最简单的。逻辑跟人体感应灯一模一样，唯一区别是：把"感知红外"换成"感知亮度"。

#### 传感器：光敏电阻

跟亮度有关的器件，最常见的就是光敏电阻。它的阻值 $R$ 跟环境亮度有关。

这里有个坑：光敏电阻分两种。

| 类型 | 亮度升高时 | 特点 |
| :--- | :--- | :--- |
| 正亮度型 | 阻值**变大** | 越亮越"堵" |
| 反亮度型 | 阻值**变小** | 越亮越"通" |

我们这里拿**反亮度型**来做，就是亮度越高、阻值 $R$ 越小的那种。这是现在最常见的光敏电阻。

> **注意**：型号不同特性相反，买之前先看手册。这一步选错，后面全错。

#### 分压 + 比较器

电路骨架跟人体感应灯一模一样：一个分压产生 $V_{in}$，一个比较器做判断，一个三极管当电子开关。

先看电子开关这一步。因为前面只讲了三极管，这里还是用 N 管：高电平导通，LED 亮；低电平断开，LED 灭。跟人体感应灯那段一模一样的做法。

分压这部分的算法跟人体感应灯完全相同，我们直接拿数字来算。设 $V_{ref} = 2.5V$（两个电阻分压就能产生），光敏电阻取反亮度型，假设：

- 环境非常暗时，光敏电阻 ≈ 11k
- 环境非常亮时，光敏电阻 ≈ 100Ω 到 1k

固定电阻 R1 取 10k，把光敏电阻放在分压的上边、Vout 放在中间：

```text
                                   前半段造出跟亮度有关的电压，后半段把它翻译成开／关
             5│                                                         
              │                                                               ┌────────────────┐  V+ ← Vin（光敏分压点）
            ┌─┴─┐                       越暗 LDR 越大 → Vin 越高              │     比较器     │  V− ← Vref = 2.5V
            │R1 │                       11k 时 Vin ≈ 2.6V > 2.5V              └────────┴───────┘
            └─┬─┘                                                                      │
              │   R1 = 10kΩ                                                            ├───────────► G
              │───────► Vin             越亮 LDR 越小 → Vin 越低                       │
              │                         1k 时 Vin ≈ 0.45V < 2.5V                 ┌─────┴─────┐
       ┌──────┴──────┐                                                           │    NPN    │
       │光敏电阻 LDR │                                                  GND ───► │E        C │
       │             │                  接反相端还是同相端，                     └─────┬─────┘
       └──────┬──────┘                  决定了亮灯还是灭灯                             │
             GND                                                                       └──► 限流电阻 → LED → GND
                                                                        
                                                                        
                                                                        Vin 升过 Vref → 输出高 → NPN 通 → 灯亮
                                                                        Vin 落到 Vref 下 → 输出低 → NPN 断 → 灯灭
                                                                        
```

跟人体感应灯一样，两个方向算一遍就明白了：

- **环境非常亮**，光敏电阻很小（假设 1k），跟 10k 分压，中点电压很小，约 0.45V。这点电压比 $V_{ref} = 2.5V$ 小，比较器输出**低** → 三极管断开 → **LED 不亮**。对，天亮了就不该开灯。
- **环境非常暗**，光敏电阻很大（约 11k），中点电压被拉高到 2.5V 以上，$V_+ > V_-$，比较器输出**高** → 三极管导通 → **LED 亮**。对，天黑了就该开灯。

算式跟人体感应灯那节用的是同一个套路，我们就不再重复了。

#### 实物演示

把手上电，正对着一个比较亮的环境，灯是不亮的。用手把光遮住，灯立刻亮；手松开，灯又灭。一挡一亮，一放一灭。

这就是最简单最基本的光控灯。

### MOS 管：电压控制的电子开关

MOS 管和三极管一样是电子开关，但它的结构和控制方式跟三极管截然不同。我们先把内部结构看明白，后面的导通条件就顺理成章。

#### 三极管的三个极，MOS 管的四个部分

三极管你已经很熟了。一个 NPN 三极管，可以简单理解成三块半导体材料组合在一起。

MOS 管要复杂那么一点点，它由**四部分**组成：

```text
                                栅极 G（Metal / Poly）
                                ┌────────────────────┐
                                │         │          │
                                └─────────┴──────────┘
                                          │
                                          │
  氧化层 SiO₂（绝缘体，把 G 与下面的沟道隔开）
                                          │
        ┌─────────────────┐                                 ┌─────────────────┐
        │     源极 S      │                                 │     漏极 D      │
        │                 │                                 │                 │
        └────────│────────┘                                 └────────│────────┘
                 │               ←──── 沟道区 ────→                  │
      ┌─────────────────────────────────────────────────────────────────────────┐
      │                     衬底 Substrate（MOS 管的底盘）                      │
      └─────────────────────────────────────────────────────────────────────────┘

   G–S、G–D、S–D 三对之间都隔着氧化层，两两都不导通，所以每一对都夹着一个寄生电容
```

这四部分分别是：中间的 G 极（**栅极**）、一边的 S 极（**源极**）、另一边的 D 极（**漏极**），以及底部那块**衬底**（substrate）。三个电极都长在衬底上，衬底你可以简单理解成它的底盘。

> **定义**：MOS 管 ＝ G（栅极）＋ S（源极）＋ D（漏极）＋ 衬底，这四大部分。

这里有一个特别关键、特别容易被忽略的性质。

#### 两两绝缘：三个寄生电容的由来

MOS 管这四大部分，**两两之间在默认状态下都是绝缘的**。

你回头看那张结构图上的位置——在真实的 MOS 管里，那些地方就是绝缘材料（氧化层）。所以这四部分两两之间都不导通。

这一条性质，直接推出一个重要结论。

G 是个导体，S 是个导体，GS 之间是绝缘的——两块不连通的导体之间，就是一个电容。GD 之间同理，SD 之间也同理。

```text
        ┌──────────┐      ┌──────────┐
        │          │      │          │
   G ───┤   寄生   ├──────┤   寄生   ├─── D
        │   电容   │      │   电容   │
   S ───┤          ├──────┤          ├─── D
        └──────────┘      └──────────┘
             GS 对              GD 对
        （SD 对同理，图中省略）
```

> **结论**：MOS 管的 G、S、D 三个电极两两之间都有一个寄生电容。这是绝缘结构带来的，不是设计者故意加的。

这个性质后面会再咬人——接大电容负载的时候，G 极电压上不去、开关误动作，根源就在这里。

#### 衬底与寄生体二极管：那个多出来的二极管

除了寄生电容，我们还要注意掺杂类型。

以 NMOS（增强型 MOSFET）为例：源极和漏极掺杂的半导体材料一般是 **N 型**，衬底一般是 **P 型**。

```text
       N (S)         N (D)
        │             │
       ─┤             ├─     每一处 N 与 P 之间都隔着绝缘层
        │    P 衬底   │            ↓
        └───── PN 结 ─┘         每一处都是一个二极管
```

> **提示**：前面讲二极管时有一条结论——只要是 PN 结，就相当于一个二极管。MOS 管里到处都是 PN 结，这个结论在这里直接就能用上。

所以在这个结构中我们看到：**漏极和衬底之间有一个二极管，源极和衬底之间也有一个二极管。**

但事情还没完。在我们常见的很多 MOS 管上，**源极和衬底是通过一根导线在芯片内部连接在一起的**——你看符号上中间那条接到 S 极的线，就是在表示这件事。

一短接，衬底与源极之间的那个二极管就被短路掉了。所以拿到手的 MOS 管，S 和衬底之间是看不到二极管的。

但是，衬底与漏极之间的二极管**没有被短路**，它还在。

再顺着推一步：既然 S 和衬底直接短路了，那么 S 与 D 之间，等效就又多了一个二极管。

```text
   衬底与 S ：内部短接 → 二极管被短路 → 消失
   衬底与 D ：没有短接 → 二极管还在     → 留下来
                    ↓
        等效：S 与 D 之间多了一个寄生二极管
```

> **结论**：这就是为什么我们常见的 NMOS 符号里，S 极与 D 极之间会多画一个二极管。它不是谁画错了，而是结构决定的。

#### PMOS：唯一区别就是二极管反了个方向

PMOS 管的寄生电容跟 NMOS 一样，也是两两之间都有。**它唯一的区别是：寄生体二极管的方向反过来。**

为什么反过来了？道理在掺杂类型里。PMOS 的衬底掺杂的是 N 型半导体，S 和 D 掺杂的是 P 型。

```text
        两边的寄生电容完全一样，唯一的区别就在体二极管的指向
          NMOS（N 沟道增强型）                  PMOS（P 沟道增强型）
                                      
衬底：P 型半导体                      衬底：N 型半导体
S、D 掺杂：N 型半导体                 S、D 掺杂：P 型半导体
                                      
          S ─────▷|───── D                      S ─────|◁───── D
      阳极在 S，阴极在 D                    阳极在 D，阴极在 S
                                      
体二极管方向：源 → 漏                 体二极管方向：漏 → 源
                                      
                                      
```

把两边的掺杂情况并排看一眼就明白了：衬底类型对调了，P 和 N 的位置跟着对调，PN 结的方向自然也就反过来了。

符号上通常看到中间那条箭头，对应的就是衬底。它之所以画一根线连到 S 极，就是在表示"衬底跟源极是短接在一起的"。

> **结论**：NMOS 与 PMOS 的结构几乎镜像对称，唯一需要额外记住的，就是体二极管的指向是相反的：NMOS 是源 → 漏，PMOS 是漏 → 源。

### 导通条件：一个不等号就够了

结构讲完了，接下来看 MOS 管的作用。它是电子开关，那必然有属于它自己的导通条件。

#### NMOS：G 比 S 大就行

先看 NMOS。导通条件一句话：

> **结论**：当 $V_G$ 比 $V_S$ 大到大过 MOS 管的导通电压时，D、S 之间就导通。

写成公式就是：

$$V_{GS} > V_{TH}$$

翻译成人话：**G 极的电压比 S 极的电压大，大到比导通电压还高，D 和 S 就闭合；否则断开。**

举个具体例子。这里有一个 NMOS，想让它控制一个 LED 灯的亮灭。假设它的饱和导通压降 $V_{TH(SAT)}$ 等于 2V（注意是饱和导通）。

S 极已经接到 GND 上了，所以 $V_S = 0V$。那么导通条件就简化成：$V_G > 2V$。

G 极接一个 5V 的 VCC 过来，一闭合开关，5V 大于 2V，DS 闭合，LED 导通点亮。

```text
     VCC = 5V
         │
    ┌────┴────┐
    │         │◄── G（5V > 2V，导通）
    │  NMOS   │
    │         │◄── S = GND（0V）
    └────┬────┘
         │
        LED
         │
        GND
```

#### PMOS：一个方向相反的不等号

PMOS 跟 NMOS 很像，也有公式：

$$V_{GS} < V_{TH}$$

人话就是：**PMOS 的 G 极电压比 S 极电压小，小到低于导通电压值时，DS 导通。**

举同样的例子：S 极接到 5V，下面接一个电阻再加一个 LED。假设 $V_{TH}$ 是 2V，那就意味着当 G 极电压比 S 极电压低 2V 以上时（比如 G 变成 3V），就满足 PMOS 管的导通条件，DS 闭合，电流下来，LED 就亮了。

这里有个坑，我单独强调一遍。

> **易错点**：**PMOS 管的 $V_{TH}$ 在数据手册里通常是一个负值。看到负压不要觉得很奇怪。**

为什么是负值？因为 $V_{TH}$ 实际上就是 $V_G$ 减去 $V_S$。前面讲了导通的条件是 $V_G$ 比 $V_S$ 要小——$V_G$ 既然比 $V_S$ 小，一减就自然是负的了。

比如 $V_S = 5V$、$V_G = 2V$，$V_G - V_S = -3V$。所以你在手册上看到的 $V_{TH}$ 一般都是负值。

> **结论**：所谓负压，指的只是"**G 极电压比 S 极电压要小**"这件事，它是一个相对量，不代表电源真的接反了。

### 开关电路的设计方法：照搬三极管就行

知道导通条件了，接下来就可以做设计了。

#### 为什么 MOS 管电路和三极管电路一模一样

先说清楚两者的本质区别，这个区别是后面所有设计方法的地基。

**三极管是电流控制电流的器件。** 只有当三极管有 $I_B$ 基极电流的时候，才会产生 $I_C$ 集电极电流。

**MOS 管是电压控制电流型的器件。** 它的 GS 之间在导通的时候是没有电流的——前面讲结构的时候说过，三个引脚之间两两绝缘，所以你加没加电、导没导通，它那里都不会有电流流过。

MOS 管只看一件事：**只要 $V_G$ 比 $V_S$ 大到大过导通压降，DS 就导通。**

搞清楚了这一条，剩下的设计就一句话：

> **结论**：MOS 开关电路的设计方法跟三极管一模一样。把一堆东西直接等效搬过来——**D 对应 C，S 对应 E，G 这一边也加个电阻**。

那具体怎么搬？我拿之前的 N 型三极管电路举例。原来是这样：

- 发射极接地
- 集电极上面接电阻，再接一个 LED，接 5V
- 基极接一个高电平过来，开关一闭合，C、E 之间导通，LED 就亮

换成 MOS 管，同样是：

- S 极接地
- D 极上面接电阻，再接一个 LED，接 5V
- G 极这边也加一个电阻

```text
                             照搬三极管开关电路：D 顶替 C、S 顶替 E、G 顶替 B
             NMOS：高电平开                                     PMOS：低电平开
                                                   
                5│                                                 5│
                 │                                                  │
              ┌──┴──┐                                            ┌──┴──┐
              │  R  │                                            │  R  │
              └──┬──┘                                            └──┬──┘
                 ├───────────► G                                    ├───────────► G
                 │                                                  │
            ┌────┴────┐                                        ┌────┴────┐
            │  NMOS   │                                        │  PMOS   │
开关 ──── ► │S      D │                            开关 ──── ► │S      D │
            └────│────┘                            5V ──────────────► LED → 限流电阻 ──►
                 └─► 限流电阻 → LED → GND                           └─► D
                                                   
G 极给高电平就导通，S 极固定接地                   NMOS 与 PMOS 一一对应：NMOS 的 S 接地，PMOS 的 S 接电源
                                                   
                                                   
                                                   
```

> **图注**：两栏的电源、限流电阻、LED 接法完全一致，差别只有 S 端接电源还是接地、G 端用高电平还是低电平驱动。

算一遍 NMOS 那栏，验证一下：

开关一闭合，5V 经过电阻到达 G 极，所以 $V_G = 5V$；S 极接地，$V_S = 0V$。

$$V_{GS} = V_G - V_S = 5V - 0V = 5V$$

假设 $V_{TH} = 2V$，$5V > 2V$，DS 导通，LED 亮。

> **提示**：**MOS 管的 S 极接电源还是接地，取决于你用 N 型还是 P 型。** NMOS 的 S 接地，PMOS 的 S 接电源，这是一一对应的。

PMOS 那栏也是照搬 P 型三极管的做法。默认状态下 S 极等于 5V，G 极加一个电阻再接开关到 GND。开关一闭合，$V_G = 0V$，$0 - 5 = -5V$。假设 $V_{TH} = -2V$，$-5V < -2V$，满足导通条件，S 和 D 闭合，有电流下来，LED 亮。

#### 实物：长得跟三极管一模一样

来看实物。你看这个 MOS 管的形状，跟三极管的形状是一模一样的。

这个不是什么巧合，也不难理解，这就是**芯片封装**的问题。大家不要觉得"结构明明不一样为什么长得一样"——**封装就是芯片的衣服，内部芯片是什么你不用管，只要这衣服穿得上，它就可能以任何一个你意想不到的形式出现在你面前。**

实物演示也很直接。接上电源和 GND，上电，灯是不亮的。把 G 极接到 VCC，灯亮了；手一放开，灯又暗了。

#### 一个特别容易踩的坑：G 极到底要不要串电阻

看刚才那个实物电路——你有没有发现，我在 MOS 管的 G 极**没有加任何电阻**？

对，**MOS 管的 G 极控制时，实际上是可以不加电阻的。**

```text
   MOS 管：G 极可以不串电阻
        5V ────► G        （GS 之间绝缘，本来就没有电流）

   三极管：基极必须串电阻
        5V ──[R]──► B      （BE 本身就是一个二极管）
```

为什么？两个原因，前面都讲过了：

- MOS 管是**电压控制**的，只要电压过来就行了，不靠电流驱动；
- MOS 内部本身就是**绝缘**结构，不加电阻去限流也没问题。

但是三极管这边，绝对不行。三极管的 **BE 之间本身就是一个二极管**，你要是直接用一个 5V 怼上去，这个三极管一瞬间就坏掉了。

> **易错点**：**MOS 管的 G 极可以不串限流电阻，三极管的基极必须串。** 这是两者最重要的区别之一，记住这一条就够了。

也正因为如此，我们才说 MOS 管是电压控制型、三极管是电流控制型。

### 为什么低功耗芯片里到处都是 MOS 管

MOS 管还有一个特性，正好承接这一节的结论。

**MOS 管在工作过程中，导通完之后它是不会有任何电流的。**

MOS 管三个引脚之间两两绝缘，导通也不例外。所以一个 MOS 管开着的时候，它自己几乎不耗电。

你想做低功耗产品——比如低功耗芯片——那大部分低功耗芯片内部，就会选用这种 MOS 管的结构。

> **结论**：低功耗＝关掉了不漏电。MOS 管天生就适合当"关着几乎不耗电的开关"，所以低功耗芯片内部清一色用 MOS 管结构。

## MOS 管开关电路里那两个甩不掉的寄生件
> 对应块：BLK14 | 覆盖分集：P59-P61 | 块标题（分集名）：《55.MOS的寄生电容问题》

前一节课我们把 MOS 管的开关电路画了出来：5V、一颗 LED、一颗 MOS 管，开关闭合灯亮，断开灯灭，逻辑干净得像一条直线。

可我们真拿仿真去跑一遍、再拿手去摸一遍，就会发现这条直线是假的——开关断开，灯还亮着，而且是慢慢暗下去的。

为什么？因为 MOS 管从来就不是一颗"干净的"开关。我们前面讲 MOS 管结构的时候说过，MOS 管内部所有电极之间、以及电极和衬底之间都处于绝缘状态，绝缘就意味着有电容。再加上源极/漏极和衬底之间天生还夹着一个二极管。这两件寄生器件平时不吭声，一旦你把 MOS 管拿来做开关，它们立刻就跳出来给你表演。

> **结论**：只要电路里出现了 MOS 管，就一定要考虑两件事——寄生电容对它控制信号的影响，以及寄生体二极管对电路的影响。这一节先把寄生电容讲透，下一节专门收拾体二极管。

### 开关断了，灯却还亮着

先看最简单的电路。开关直接串在 5V 和 G 极之间，MOS 管漏极接负载（这里是 LED），源极接地：

```text
        +5V
          |
        [ SW ]      SW closed: +5V lands straight on G
          |
          +---------- G
                     |||
                   +-o-o-+
       S --------> | C |   C_GS: G and S are insulated,
       |           +-o-o-+   yet a real capacitance sits between
       |
      LED
       |
      GND
```

按 MOS 管的开关逻辑，只要 $V_G$ 比 $V_S$ 高、高过导通压降，它就导通。开关一闭合，5V 顺着开关灌进 G 极，$V_G = 5\text{ V}$，$V_S = 0$，于是 $V_{GS}$ 就是 5V。假设导通电压 $V_{TH} = 2\text{ V}$，那它肯定导通，LED 亮。

好，现在把开关断开。按理说电源撤走了，灯该灭了。

但请注意，我们前面强调过：MOS 管的 G 极和 S 极之间是绝缘的。所以这颗寄生电容**没有地方放电**——上面的开关断了，下面是绝缘的，它就是攥着一口 5V 不撒手。于是 $V_{GS}$ 依旧是 5V，MOS 管依旧导通，**灯依旧亮着**。

用仿真看更直观。建个原理图，一颗 NMOS、一颗电阻、一颗 LED，开关这一路加不加电阻都不影响演示（真实电路里是应该加一个小电阻的，仿真里都是理想源，就不管了）。跑起来：开关没闭合，LED 灭；开关闭合，LED 亮；再把开关断开——**LED 还在亮**。

有意思的是，仿真软件里我们一颗电容都没画，可 MOS 管模型本身已经把内部的电容集成进去了，所以现象照样出现。

再盯住 G 极的电压看：断开瞬间是 4.94V，过一会儿 4.93V，再过一会儿还在往下掉。

> **提示**：为什么它会掉？没有任何元器件能做到 100% 绝缘，绝缘材料在两端加了电压之后，多少都会有一点漏电流。寄生电容就是靠 MOS 管内部这点漏电慢慢放掉的——只不过这个过程很漫长。所以它最终还是会关掉，只是关得很晚。

那这个"晚"到底是多晚？我们把手上的实物拿过来看：MOS 管加一颗灯，开关点上去灯亮，手一松，灯不是立刻灭的，是慢慢暗下去的。再点一次，再松一次，还是慢慢灭。

**这里最容易搞错的一句提醒**：有些 MOS 管的漏电特性相当好，不给它放电回路的话，开关断开之后它能持续导通十几秒。这个现象我们以前是真遇到过的。所以别再想当然地觉得"MOS 管就是个电子开关，跟三极管设计电路一样"——不一样。

### 电压控制型和电流控制型的分水岭

顺手做个对照实验：把电路里的 MOS 管换成三极管，同样点上去、松开。

三极管点上去灯亮，手一走开，灯**立刻**就灭了。

这就是电压控制型和电流控制型的分水岭。三极管自身是会消耗基极电流的，你把手松开、驱动电流一撤，基区储存的电荷很快就被消耗掉了，动作干脆利落。而 MOS 管是电压控制型的，控制信号就是那口寄生电容上的电压，一旦没有放电路径，它就死死攥着不放。

### 给寄生电容留一条放电的路

解决办法其实朴素得很：**在 G 极和 S 极之间并一个电阻，给寄生电容提供一条放电路径**。

这个电阻的作用就是泄放：信号撤掉的时候，电容上的电荷顺着电阻快速跑光，MOS 管就能立刻关断。

实物演示一遍就很清楚。往 MOS 管的 G、S 之间直接缠一个 100kΩ 的电阻上去，然后再做同样的点开-松开动作——**灯是"啪"一下灭的**，刚才那种慢慢变暗的场景没有了。

电阻为什么取 100kΩ 这么大的值？两个考虑：

其一，**损耗**。电阻是接在 G-S 之间的，只要开关是闭合状态，这颗电阻上就一直在分压、一直在耗能。取小了，静态功耗吃不消。

其二，**关机速度并不会因此变慢**。MOS 管的寄生电容一般是皮法级别的，很小。时间常数 $\tau = R \times C$，就算乘上 100kΩ，$C$ 只有 pF 量级，$\tau$ 依然在微秒级别。人眼根本反应不过来，对电路来说这已经是非常快的关断了。

> **易错点**：把 G-S 电阻取小以求"关得更快"，是白白牺牲静态功耗换一个人类感知不到的差别。

要是还嫌微秒不够快，就得换驱动方式了——用**推挽电路**去驱动这颗 MOS 管。什么意思呢？用一颗专用的驱动芯片，芯片内部就是两个开关：一个接到 VCC，一个接到 GND。推挽驱动相当于给那颗寄生电容一条"充电腿"和一条"放电腿"，电容被快速地灌满、抽干，MOS 管自然就能快速关断了。

顺带一提，三极管那一侧也建议加电阻，除了能加快关断，还有抗干扰的作用。前面我们演示三极管的时候不加基极电阻，手一碰上去灯就闪——那是工频在人体上感应出的静电造成的，这个我们前面讲过，这里不重复。MOS 管加了 G-S 电阻之后同理，这个干扰路径也被掐断了。

### 寄生体二极管的方向，千万别记反

接下来说第二件寄生件：寄生体二极管。

MOS 管在 D 和 S 之间天生夹着一个体二极管，方向必须记死：

```text
   NMOS                          PMOS
   D +----|>|----+ S             D +----|<|----+ S
          S -> D                        D -> S
```

NMOS 的体二极管**从源极指向漏极**，PMOS 的体二极管**从漏极指向源极**。记反了，后面所有的分析全得反过来。

我们拿 PMOS 做一颗电源开关来看看。假设 PMOS 的导通条件是 $V_{GS}$ 达到 3V，也就是 G 极电压比 S 极低的时候 D、S 闭合。

S 极接一颗 6V 电池，G 极由一颗三极管下拉控制：三极管断开时，G 极被 6V 顶住，$V_G = 6\text{ V}$，$V_S = 6\text{ V}$，$V_{GS} = 0$，PMOS 断开，负载无电；三极管导通后有电流 $I_C$ 灌下来，$V_G$ 被拉到约 0.3V，这时 $V_{GS} = 6 - 0.3 = 5.7\text{ V}$，超过 3V，PMOS 导通，6V 送到负载。工作逻辑就这么简单。

**但这个电路有坑。**

坑在于：负载不一定只由这一路电池供电，它可能还接着一路外部电源。比如负载既可能由 6V 电池驱动，也可能由外部的 6V 甚至 10V 供电。既然外部电源进来了，我们当然希望电池别再供电——所以工作逻辑应该是：**一识别到外部电源，就把开关断开**。

理想情况下，MOS 管一断开，电池跟后级再无关系。可它偏偏有个体二极管。

```text
      BAT 6V                                  EXT 6V
        |                                       |
       SW1                                     SW2
        |            D ----|>|---- S             |
        +------------+                    +-----+
                     |                          |
                   [LOAD]-----------------------+
                     |
                    GND

   body diode conducts FROM the load node BACK INTO the battery
```

假设外部电源 6V，电池标称也是 6V。可电池用久了会掉电——用了半天，电量掉到 5.5V。这时候把外部电源接进来、开关联动断开，理论上应该只有外部供电。

但请看上面那张图：体二极管是从负载节点指回电池那一侧的。负载节点被外部电源顶到了 6V，电池只有 5.5V，假设体二极管导通压降是 0.5V——**6V 就顺着体二极管去给电池充电了**。

有人可能会想：差 0.5V 刚好压在导通压降上，好像也没什么大问题。可万一电池用到 5V 呢？6V 经二极管去对 5V 供电，压差 1V，那就是一股很大的电流。

用仿真量化一下：加个电流探头和示波器。电池一开始满电 6V，开关闭合，MOS 管导通，流过约 6mA 给负载供电，正常。走着走着电池用到只剩 5V，此时断开电池开关、闭合外部开关——理论上只有外部供电，可示波器上除了那 6mA 的正常负载电流，还冒出一段**安培量级的反向电流**（现场读数是 -6A）。

这么大的电流往电池里灌，结果只有两种：**要么电池坏掉，要么 MOS 管坏掉**。

> **易错点**：设计完电路再回头把体二极管加进来，重新算一遍"MOS 管断开之后，二极管会对电路造成什么影响"。这一步省不得。

### 调转方向，再串一颗

解决办法也很简单：**把 MOS 调转方向**。

同一套连线，只是 S、D 对调：

```text
      BAT 6V                                  EXT 6V
        |                                       |
       SW1                                     SW2
        |            S ----|>|---- D             |
        +------------+                    +-----+
                     |                          |
                   [LOAD]-----------------------+
                     |
                    GND

   now the body diode points from the battery TOWARD the load
```

再跑一遍同样的场景：开关闭合，电流依旧 6mA 左右；电池掉到 5V，断开电池开关、闭合外部开关——**没有大电流了，只有 36pA，相当于没有**。

但方向一调，新的代价就来了：**这颗 PMOS 管再也关不断电池对外部的供电**。哪怕开关断开，电池依然会顺着体二极管给负载供电，达不到"完全关断"的效果。

想真正做到完全隔离，办法是**再加一颗 PMOS，反向串接在一起**：

```text
      BAT 6V                                  EXT 6V
        |                                       |
       SW1            S --|>|-- D --|>|-- S       SW2
        +-----------+                   +--------+
                    |                   |
                    +-------[LOAD]------+
                              |
                             GND

   two body diodes face each other: when SW1 opens,
   both block at the same time, so neither leaks
```

反向串的好处在于，可以利用两个体二极管**相互抵消**的关系，把寄生体二极管带来的影响彻底关在门外。

仿真验证：默认断开状态，输出没有电压；闭合，有电压；再断开，这边没有电流，电压约等于 0。电池断开之后闭合外部电源，流过的同样是皮安级别的电流，不会再有反向大电流倒灌回去。

> **结论**：不管设计什么电路，只要用到了 MOS 管，第一步考虑寄生电容，第二步考虑寄生体二极管。还有一条要提前知道——**连"用多一颗 MOS 管去关断体二极管"这个方案本身，也是会重新踩到这个坑的**。

### NMOS 的 S 极不接地时，管子会把自己掐住

前面讲的都是 S 极老老实实接 GND 的情况。接下来这一段是 NMOS 做开关时最容易翻车的地方，也是 H 桥里天天要打交道的知识点。

按常规用法，NMOS 的 S 极都接 GND。但有些场景不是这么接的。不知道大家有没有看过半桥驱动电路？简单说就是两颗 NMOS：上面一颗是上管，下面一颗是下管，一个接 GND，一个接 VCC，中间那点作为输出。这就叫半桥驱动，也可以叫推挽电路。

你会发现：**上管那颗的 S 极没有接 GND**。

我们用最简单的电路来看它会怎样：

```text
   VDD = 12V                          VG = 5V
      |                                  |
      +--------[ R_load ]----------------+
                         |        |
                        D        S
                         |        |
                       +-o-o-    +-o-+
                       | NMOS   |
                       +-o-o-    +-+
                                   |
                                   G  (5V)

   measured on the S side: 1.35 V, not 12 V
```

结论先摆出来：**MOS 管不会饱和导通**。

推导过程其实很朴素。假设 MOS 管控制电压是 5V，另一边的电源是 4.5V。上电之前所有电压都是 0，S 极这一点也是 0，负载当然不工作。

突然之间 5V 接进来。刚接进来的那一瞬间，MOS 管还没开通，$V_S = 0\text{ V}$、$V_G = 5\text{ V}$，于是 $V_{GS} = 5\text{ V}$，大于导通电压，**饱和导通**。

一饱和导通，4.5V 的电源就给负载供上电了。但供电过程中这一点电压**不是"啪"一下就到 4.5V 的，而是从 0V 慢慢往上升的**。而 $V_{GS} = V_G - V_S$，$V_G$ 是死的 5V，$V_S$ 一路涨，$V_{GS}$ 就一路掉：

| $V_S$ | $V_{GS} = V_G - V_S$（$V_G = 5\text{ V}$） | 管子状态 |
| --- | --- | --- |
| 0 V | 5 V | 饱和导通 |
| 1 V | 4 V | 饱和导通 |
| 3 V | 2 V | 临界，恰好等于 $V_{TH}$ |
| 3.001 V | 1.999 V | 掉进放大状态 |

一旦掉进放大状态，MOS 管就不能当成开关看了，它内部是一个**比较大的电阻**。电阻产生压降，压降又跟负载分压，结果就是：**这一点电压永远上不去，就卡在 3V 附近**。它想往上走一点，$V_{GS}$ 就不饱和，电阻又变大——一个自我锁死的循环。

仿真验证，开关一闭合，输出只有 **1.35V**，12V 根本过不来。剩下的 10.7V 左右全被 MOS 管自己吃掉了，因为它被 $V_{GS}$ 这个导通条件限制死了。

功耗也吓人。把负载电阻改成 $10\ \Omega$，一打开，电阻上只有 1.3V，流过来的电流约 130mA；130mA 乘上 MOS 管上那 10V 左右的压降，损耗已经有一瓦多——**这么烫，是肯定会发热**。

所以：**NMOS 当开关用的时候，只要 S 极没接 GND，就极容易掉进放大状态，也就是非饱和导通状态。**

### 抬高 G 极，或者用自举把自己举起来

问题的根因就一句话：S 极电压上升，把 $V_{GS}$ 拽下来了。那解法自然也是从这个方向去想——两个思路。

#### 思路一：把 G 极顶到负载电源之上

第一个思路很朴素：**不管 S 极怎么往上走，只要 G 极始终比它高出导通电压以上就行**。

比如负载电源是 4.5V，那 G 极就给一个 10V 试试。开关一闭合，G 极 10V，$V_G - V_S$ 无论 S 涨到哪里都还有富余，4.5V 全部过来，$V_{GS}$ 依然有 5.5V 的压差，稳稳地饱和导通。

这是最省事的解法：**给 G 极加一个比后级负载电源更高的电压**，问题直接消失。

拿实物验证一下。板子上是一颗 NMOS，底下挂一颗负载电阻，G-S 之间有颗 $100\ \text{k}\Omega$ 电阻负责快速关断（对阻抗回路没有影响），电池盒那边是三节电池，两端 4.5V。万用表打电压挡，量负载电阻两端的电压。

直流稳压电源先归零再上电，从 0V 开始慢慢往上调。调到 4.5V 附近时，负载电阻上确实是 4.5V 左右。继续拧到 5V，此时负载电阻上只有 **3.4V**——说明 MOS 管的开通压降约 1.5V，4.5V 根本没全过来。

那就往上加：调到 6V，负载电阻上是 **4.4V**，已经接近了；再调到 8V，负载电阻上是 **4.8V** 左右。之后再怎么调都没用了——已经饱和导通，4.5V 全部过来了，读数死死停在 4.79V 不动。

**这个方案的代价是成本。** 4.5V 要用一个 8V 去驱动，可电路里不会平白无故冒出 8V，得靠电荷泵或者 Boost 升压电路去产生——不管哪种方案，都是多一颗芯片、多一笔成本。

#### 思路二：用自举把驱动源整个抬起来

有没有更省钱的办法？有。

利用**电容两端电压不能突变**这个特性，就能实现电压自举，用一个很简单的电路解决 S 极不接地时的误关断问题。

结构简单到离谱：**把驱动 G 极那颗 5V 电源的 GND，不要接到电路的地，而是接到 S 极上去。**

先看效果。开关闭合前这一点是 0V，开关闭合后直接变成 11.8V，几乎就是满的 12V。因为这颗 MOS 管是小功率的，流过大电流时有一点压降，0.1V 左右。而如果按原来那样接，G 极至少得给到 15V 才行。

再看原因。把这 5V 电源当成一颗电池：电池正极永远比负极高一个电压。开关一闭合，因为负极接的是 MOS 管的 S 极、正极接的是 G 极，所以 $V_{GS}$ 恒等于这 5V。管子导通之后，12V 走到 S 极，S 极被抬高，**G 极相对于电路 GND 也会同步被抬高**——因为电池正极永远比负极高 5V，底下一抬，顶上也跟着抬。

这就像 MOS 管导通之后，12V 的正极被怼到了 5V 电源的负极上，两颗电源相当于串联了。这一点相对于 GND 会被顶到 17V，而 $V_{GS}$ 依旧稳稳地保有 5V 的压差。

实物上再验证一次：把负极接到 S 极，此时想让两端得到 4.7V，**不需要 8V，只要给 2V 以上就够了**。调到 2V（实测 1.9V），输出是 4.78V；再往上调，输出还是 4.78V，一动不动。因为这个电压是加在 G-S 两端的，电源电压怎么变，G 极都被"自举"着一起抬起来，G-S 之间永远等于你加上去的驱动电压。

实际电路里我们用的是**电容**而不是电池。这个结构的典型长相是：内部一般有**几个对应的开关、一个电容、一个自举二极管**——那几颗开关负责控制 G 极的通断，底部那个回路负责给电容充电，充满之后这颗电容就等价于一颗电池，它就叫**自举电容**。驱动这类 MOS 管时，用的就是这种电路结构。自举电容充放电的完整原理我们在硬件课程里有专门讲，逻辑比较复杂，这里就不展开了。

> **定义**：**自举电路**——利用电源自身两端电压不能突变的特性，把驱动源连同它的参考地一起抬高，从而在低电压供电下驱动高侧 NMOS 管的一种电路。

这两条思路，正是 NMOS 管做电源开关时最常用的设计注意事项：**要么把 G 极的电压顶上去，要么把整个驱动源自举起来**。特别是 H 桥那一类上下管交替导通的场合，上面这颗 NMOS 的 S 极永远不接 GND，就更是必须走这两条路之一。

## PMOS 电源开关设计：MOS 管的电流方向、体二极管与耐压
> 对应块：BLK15 | 覆盖分集：P62-P67 | 块标题（分集名）：《58.Pmos的电源开关设计方法》

### 用 PMOS 替掉 NMOS：省掉的那一堆电路

上一节课我们讲 NMOS 做电源开关，S 极不接 GND 的时候，要加一堆自举电路，各种各样，很麻烦。之所以非要这么折腾，根子在于 NMOS 的导通条件把它的用法限制死了。

想把这事儿解决得痛快点，又不想把驱动电路搞得那么复杂，怎么办？直接用一颗 PMOS 把 NMOS 换掉。

**为什么 PMOS 行？** 因为 PMOS 天生就有一个优势——它是拿来做电源端开关的。PMOS 做开关的时候，S 极通常就接在电源上；而它的导通条件是 G 极电压比 S 极电压低、低过 $V_{TH}$ 就开通。S 极本来就是整个电路的最高点，这和 NMOS"S 极不接 GND 就麻烦"的处境刚好相反。

把电路换成这样：

```text
            +12V
              │
              S
        ┌─────┴─────┐
        │           │
   G ───┤   PMOS    │
        │           │
        └─────┬─────┘
              D
              │
            R_load
              │
             LED
              │
            GND

   G 脚下再挂一个下拉电阻 Rpd 到 GND：
        ┌──── G
        │
       Rpd
        │
       GND
```

> 读图：S 极固定在 +12V，D 极往下接负载；唯一的控制信号就是 G 极——把它拉低，管子就开；不拉它，G 悬空或被外部拉高，管子就关。

这里的关键就一句话：S 极本来就接在 12V，是电路里的最高点，只要我给它加一个下拉电阻到 GND，G 就变成 0V，比 S 极低了整整 12V，它肯定导通。而它一旦导通，12V 该还是 12V，对 $V_{GS}$ 不产生任何影响——电路自己就把自己锁在导通状态了，不需要再去维护一个偏置电压。

所以，用了 P 管去代替 N 管之后，前面那一堆复杂电路全都不需要了，**只需要两个电阻加一个开关**。

不过实际电路里一般很少用机械开关，通常是用三极管或者 MOS 管，通过单片机去控制——这是我们最常见的一种组合方式，也就是 PMOS 管解决 NMOS 管 S 极浮空问题的典型方案。

### G-S 之间的电阻不能省，但 PMOS 也不是万能的

这里 尽管用的是 P 管，设计原则和 N 管完全一样：**必须在 G-S 之间加一个电阻，用来释放 G-S 极间寄生电容的能量**。这一点是恒定不变的，不管你设计的是 PMOS 还是 NMOS，GS 之间一定要加电阻。

阻值怎么取？

| 开关频率 | GS 电阻取值 | 代价 |
| --- | --- | --- |
| 不高，比如 100kHz 以下 | 100k 左右就够 | 损耗小，开关速度一般 |
| 非常高 | 适当减小，比如 10k | 开关速度更高，损耗更大 |

> **易错点**：电阻越小，开关速度会越高，但是损耗会越大，这一点一定要特别注意。不能为了图"响应快"就把 GS 电阻一路往小压。

至于什么时候 PMOS 顶不上——在大功率场景，PMOS 是没有办法替代 NMOS 的。因为 PMOS 由于自身工艺的原因，在同等的成本、同等级别的工艺下，做出来的性能就是没有 NMOS 好。所以在频率比较高或者电流比较大的场景，我们都是优先考虑用 NMOS 管的。

### PMOS 防反接电路：反接了为什么也不会烧

我们拿一个 12V 的电源来看。整个电路是这样：

```text
   BAT+ (12V)
      │
      S
   ┌──┴──┐
   │     │      PMOS 内含体二极管，方向 S → D
   │ PMOS│
   │     │ D
   └──┬──┘
      │
      ├─────────────────→ 后级 VOUT ── 降压电路 ──→ MCU ──┐
      │                                                   │
      ├──── R1 ────┬──── G(PMOS)                           │
      │            │                                       │
      │          node A                                     │
      │            │                                       │
      └──── R2 ────┴──── C  Q1 (NPN)  ←───────────────────┘
                       E ──── GND
```

> 读图：R1、R2 在后级输出和地之间串成分压，PMOS 的 G 从中间抽头 node A 取出；Q1 是 NPN，基极由 MCU 的控制信号驱动。Q1 断开时 node A 等于后级电位，管子关；Q1 导通时 node A 被拉到分压值，管子开。

正常上电的过程，我们一步步走一遍。

**刚接进来的时候**：电源是 12V，控制信号此时还是低电平，三极管处于断开状态。三极管断开，两个电阻上就没有电流、也就没有压降，G 被拉到和后级同一个电位（约 11.3V）。12V 和 11.3V 只差 0.7V，远不够 PMOS 导通所需的 $V_{TH}$，所以 MOS 管不闭合。

那电从哪儿来？12V 会先经过**寄生体二极管**跑到后级来，掉一个二极管压降，变成 11.3V。

为什么要先经过体二极管呢？因为 MCU 是由这边供电的。这边电都还没过来，MCU 肯定不工作；三极管肯定断开；MOS 管也就不会闭合。在 12V 真正接进来之前，MCU 其实都是不工作的——**这正好是一个天然的"先上电、后控制"的顺序**。

跑过来的这 11.3V 一边给负载供电，一边经过降压电路送到 MCU。

**MCU 工作之后**：我们写程序让它输出高电平，三极管就导通了。三极管一导通，11.3V 就经过 R1、R2 分压，分到大约 6V 的电压送到 G 极。这时候 $V_{GS} \approx 6 - 12 = -6\text{V}$，满足 MOS 管的导通条件，MOS 管就闭合了。**一闭合，体二极管就被短路了**，所以电压就从 11.3V 变回 12V。这就是它正常导通工作的完整过程。

那万一电池突然接反了呢？也就是说在上电的时候，把电池接成下面是 12V、上面是 0V。

这时候如果**没有** MOS 管，相当于 12V 直接接到 MCU 的地，MCU 不能够承受反向耐压，直接就烧坏了。

但**加了** MOS 管之后会怎样？虽然 12V 反接确实会来到 MCU 的地，但要损坏 MCU 或者其他负载，前提条件是**必须要有电流流过**。

而电路中实际上是不会流过电流的。为什么？电流走到这个位置之后，发现 MOS 管没有导通——MOS 管没导通，是因为这时候三极管不会导通，两个电阻也不会有压降，没有电流流过来形成完整回路。电信号到了这个位置之后，会被**寄生体二极管给阻断掉**。阻断掉自然就不会有电流，电源即使反接，对后级也不会有影响。

> **易错点**：这道防线其实来自体二极管的方向，而不是来自 MOS 管本身。电流之所以走不过去，是因为体二极管把它挡了。一旦这个二极管方向装反，防护立刻完全失效。

还有一种电路不需要用三极管去控制：里面没有三极管，那一路直接接地。这样 MOS 管的控制就跟 MCU 没有任何关系了，直接给 MCU 供电。简单来说，12V 一接进来，这里立刻变成 11.3V；经过两个电阻分压变成 6V，MOS 管立刻导通，把二极管短路掉，电压立刻变成 12V，**不需要 MCU 参与控制**。去掉三极管之后，它最终也是一样会保持导通，同样可以形成防反接的效果。

这就是 PMOS 管防反接电路的基本工作原理。

### MOS 管的电流是双向的

关于 MOS 管，这里一定要知道：它跟三极管是不一样的。**三极管的电流是单向流通的，但 MOS 管的电流是可以双向流通的。**

很多同学、包括网上一些资料，说 MOS 管的电流也是单向流的，实际上不是的。MOS 管的电流可以双向流通。只不过我们在应用的时候，通常不想让它双向流通——因为 MOS 上面是有寄生二极管的，如果这里没有处理好，MOS 管上面就会有一个漏电流。但实际上只要把二极管给处理掉、抵消掉，它的电流在电路中完全可以实现双向流通。

#### 从内部结构看，它为什么能双向

要回答"为什么"，得从 MOS 管的内部结构说起。前面几节课讲过大体结构：一个衬底，三个电极。我们拿一个 N 型的 MOS 管来画，对应的是 S 极、D 极和 G 极。

```text
            G  栅极（金属，氧化层与下方隔离）
  ─────────────────────────────────────────────
   │                                          │
   │   ┌─────────┐         ┌─────────┐       │
   │   │  N+  S  │  沟道   │  N+  D  │       │
   │   └─────────┘         └─────────┘       │
   │                                          │
  ─────────────────────────────────────────────
              P 型衬底（body）
```

> 读图：S 和 D 掺的是 N 型半导体材料，衬底是 P 型半导体材料。G 与半导体之间隔着氧化层，所以栅极电压不会像 BJT 那样形成直流通路。

如果想让电流流过 S、D 之间，就在 G 极和 S 极之间给它加一个正向电压。加了正向电压之后，G 极就会在 D 和 S 之间形成一个**沟道**。形成了沟道之后，电子就可以通过沟道从 S 流向 D。

从沟道结构就可以看出，它就是一条通道。电子理所当然既可以从 D 流向 S，也可以从 S 流向 D。

> **结论**：只要 MOS 管的 G-S 之间满足导通条件，S 和 D 就等于一直接在了一起。它的电流不管是从 S 流向 D，还是从 D 流向 S，其实都是一样的。

#### 把电源掉个头，实测一遍

原理图上看得清楚，我们再拿实物验一遍。

先看这个电路：右边这一个是负载的供电电源，上正下负，这一种接法是比较正常的接法。我们在 G-S 之间接一个开关（并一个 5V 控制），开关一闭合，$V_{GS}$ 就等于 5V，MOS 管就开通，电流就这样子下来。这时候 MOS 管两端的电压其实就是约等于 0 的，这是一个很正常的一种应用电路。

```text
   正常接法（上正下负）        把电源掉个头（下正上负）
   ┌────────────────┐         ┌────────────────┐
   │            S ←─┼── +12V  │            S ←─┼── GND
   │                │         │                │
   │      ┌─────┐   │         │      ┌─────┐   │
   │  G ──┤MOS  ├───┼── 5V    │  G ──┤MOS  ├───┼── 5V
   │      └──┬──┘   │         │      └──┬──┘   │
   │         D      │         │         D      │
   └─────────┼──────┘         └─────────┼──────┘
             │                            │
           R_load                        R_load
             │                            │
            GND                       +12V (负极上接)
```

区别只有一个：控制电路完全一样，不一样的点在于右边这电源我接成了**下正上负**。

这时候有个不同的点。**当开关没有闭合的时候**，因为 MOS 这里有一个寄生的体二极管，所以开关即使没打下来，我们也会发现这个 12V 也会经过这个寄生体二极管来进行供电。也就是说，**即使你没有开通这个 MOS 管，它的负载也是有电的**。

我们先不管这个寄生体二极管带来的影响，假设这时候把开关一闭合，MOS 依旧是会导通的。导通之后你会发现，12V 电源的电流就不会经过二极管了，它是直接从 MOS 管内部过来的。

所以从中就能看到：**只要我们 MOS 管的 G-S 之间满足导通条件，它的 D-S 就是闭合状态的，电流不管是正向流也好还是反向流也好，它都能正常流通。**

实物上我们就是这么验证的：用电池盒代替那个 5V 控制电源，直流稳压电源接在两端供电，然后用万用表直接夹在 MOS 管的 D-S 之间，调到电压挡。判断标准很简单——**只要 MOS 两端电压约等于 0，就说明它正常导通**。

**正常接法**：电源输出 0V，我们慢慢调到 5V。电池盒开关还没打开的时候，MOS 管处于断开状态，测得 D-S 两端电压等于 5V；一闭合，D-S 两端电压就变成 0 了。这就是正常的工作状态。

**把电源掉个头**：把电源负极接到 S 端、正极接到 D 端。先断开电池盒开关，此时 $V_{GS}$ 等于 0，MOS 管不闭合，D-S 不闭合，电流就会走体二极管，所以我们测到 D-S 之间有一个 **-0.58V** 的压降——这就是体二极管的压降，没有问题。一把电池盒开关打开，它立刻就变成 0 了。

所以我们得到的信息是：**MOS 管只要它的 $V_{GS}$ 达到导通要求，它的 D-S 之间的电流方向是可以任意流通的，它是没有方向可言的。** 这一点跟三极管完全不一样——三极管 N 管只能从集电极流向发射极，P 管只能从发射极流向集电极，电流不会反过来；但 MOS 管是可以的。

#### 那它到底有什么用

可能有人会纳闷：我跟你讲这个知识点有什么用？

单单只拿一个 MOS 管的时候，它确实存在开关没闭合时也有电流的问题。但如果在现有的基础上再加一个 MOS 管，就不一样了。

```text
             +12V
               │
     ┌─────────┴─────────┐
     │                   │      两只体二极管面对面，
   D │      NMOS1      S │      中间节点把 S1 与 D2 短接
     │                   │
     └─────────┬─────────┘
               │
     ┌─────────┴─────────┐
     │                   │
   D │      NMOS2      S │
     │                   │
     └─────────┬─────────┘
               │
             R_load
               │
             GND
```

> 读图：两只 NMOS 背靠背串在正极与负载之间，S1 与 D2 在中间短接；各自体内二极管的指向正好相反，一只在阻断一个方向，另一只就阻断相反方向。

这样做的好处是什么呢？开关不闭合的时候，两个 NMOS 都处于断开状态，12V 的电流走到第一个二极管那里确实可以通过来，但是走到第二个 MOS 管的时候，它发现上面这个 MOS 的二极管跟下面是**相互抵消**的，是面对面的。电流能不能经过上面这个二极管？不能。不经过，就实现了：当你那电源接成下正上负的时候，电路也不能导通。

而只有当开关一闭合的时候，我们才会发现这个 MOS 导通了，第二个 MOS 也导通了，这时候电流又可以这样子走过去。

那么这样子有什么用呢？**模拟开关芯片**。不知道有没有同学用过模拟开关芯片——我们模拟开关里面，很多时候都是用这种 MOS 管结构来做的。它为什么电流可以双向流通？就是利用了 MOS 管 D-S 之间没有电流方向这个特性。

这一点是**很重要很重要**的。很多同学一用到 MOS 管就觉得它的电流是单方向流的，为什么呢？他老是觉得那个二极管在那儿作怪。其实**二极管是可以通过加多一个 MOS 管把它给抵消掉的**。

### 用两颗反向 MOS 把体二极管抵消掉

我们刚才不是说了吗，在电路里可以加一个反向的 MOS 管上去，把二极管抵消掉。它究竟如何实现这个功能的？我们搭个仿真来看。

先搭一个比较正常的电路：一个 NMOS 管、一颗 1k 电阻、一路 12V 电源，G-S 之间再接一个 5V 的电压。拿一个电流探头测这一点的电流，再拿一个万用表看 MOS 两端的压降。

正常把开关闭合的时候，电流等于 **12mA**，MOS 两端的压降只有 **1.183mV**。这个压降这么小，说明这个 MOS 管肯定已经饱和导通了。

然后把 12V 反过来接。如果开关处于断开状态（这里 G-S 之间最好再加一个下拉电阻，仿真相对更靠谱一点），这时候 D-S 之间的压降就不是 1.183mV 了，而是 **0.37V**——这明显是通过寄生体二极管过来的。一点问题都没有。然后一把开关闭合，它又变回 1.183mV 了，说明电流又从 MOS 内部过来了，不再走二极管。

现在问题来了：如果就按现在这个电路去工作，**这个 MOS 管实际上控制不了这个 1k 的供电情况**——开关断开的时候它照样有电。怎么办？加多一个 MOS 管。

怎么加？就是在这里直接画一个反向的，跟这个 MOS 管上下镜像一下，放到它上面去。这样子就可以解决我们寄生体二极管的问题了。

重新测一下。这时候我们就可以**把这两个 MOS 管当成一个 MOS 管来看待**。

> **易错点**：第一次仿真跑出来这里有漏电流、MOS 没关掉，是因为两只 MOS 管画成了左右并列（体二极管同向），必须改成上下镜像、真正背靠背串接，方向才是相反的。另外仿真模型太理想，实际电路里还要在这个位置加一个 100k 的电阻，才能把那个漏电流压下去。

这次的结果就对了。

开关没闭合的时候，两端电压等于 12V，电流非常非常小。开关一闭合，两个 MOS 管就都导通了。而且压降是叠加的——**每一个 MOS 管的导通压降刚刚测出来是 1.183mV，两个一加起来就变成 2mV 左右**。

我们再把电源掉个头，把这张原理图也接过来。这时候不管外部电源是下正上负还是上正下负，**这两个 MOS 管都是可以控制的**。我们把两个开关都断开，电压都等于 12V 左右；再把开关同时闭合，压降一样，电流也是约等于 12mA。

所以我们就可以看到：**用两个 MOS 管反向地串联在一起，它们就可以相互把自身体二极管误导通的问题给抵消掉**，从而形成一种双向导通的开关。

#### 这个结构用在哪里

这种双向开关结构，很多时候会用在**用 MOS 管去代替继电器**。

因为继电器的开关就是双向导通的。平时我们拿单个 MOS 管去代替继电器的话，它只能规定电流是一个方向的，不然反方向就会像我们刚刚看到的那样误导通。加了两个 MOS 管之后，就不会出现这种误导通的问题了。

### 导通电流和 $V_{GS}$ 的关系

讲完了电流方向，接下来讲下一个知识点：**MOS 管的导通电流和 $V_{GS}$ 之间是有关系的。**

这一个其实跟我们前面讲的三极管也有点类似。讲三极管的时候我们说过，$I_C$ 会被 $I_B$ 控制，$I_B$ 乘上三极管放大倍数 $\beta$ 就等于 $I_C$。MOS 管这里呢，$I_D$ 其实与 $V_{GS}$ 也是有关系的，只不过它是用 $V_{GS}$ 去控制 $I_D$ 而已：

$$I_D = g_m \cdot V_{GS}$$

这里面也有一个放大倍数，电流除以这个电压，就是我们常说的跨导 $g_m$。这个参数我们其实很少去关注，大家只要知道有这样的一个关系就好。

当然，这个公式的成立条件是：**MOS 管必须工作在它的线性区或者放大区。**

#### 特性曲线上的三个区

我们看 MOS 管的 $V_{GS}$ 与 $I_D$ 之间的关系曲线：

```text
   I_D
    │                                          ─ ─ ─ ─  4.5V 之后
    │                                 ╱ ─ ─ ─ ─            R_DS(on) 已变化很小
    │                          ╱
    │                     ╱
    │                ╱
    │             ╱
    │──────────●╱─────────────────────────────→  V_GS
              V_TH
```

> 读图：横轴 $V_{GS}$ 之前 $I_D$ 恒为 0，是截止区；越过 $V_{TH}$ 之后电流起来，然后随着 $V_{GS}$ 增大而增大；再往上曲线明显变平，趋于饱和。

对应着这条曲线：当 $V_{GS}$ 很小的时候，$I_D$ 一直都等于 0，说明在这一电压之前 MOS 管一直是处于断开状态；当 $V_{GS}$ 达到某一点电压，$I_D$ 就开始有电流了，说明在这个区间 MOS 管开始导通；然后随着 $V_{GS}$ 慢慢变大，$I_D$ 才慢慢地越来越大。

我们为什么要讲这一点呢？主要就是因为有好多同学认为 **MOS 管就是一个开关**。普通机械开关你一按，它开了就开了、关了就是关了，它不会处于某个中间态。但 MOS 管和三极管是**有中间态的**——它开通了之后，并不见得就一定达到了完全饱和导通、完全开通的状态，它是要随着你的 $V_{GS}$ 慢慢变大、大到一定程度，才能够饱和导通的。

这一点一定注意。一般常见的 MOS 管，只要 $V_{GS}$ 大于 4.5V 之后，基本上就已经接近达到完全饱和导通的状态了。当然 $V_{GS}$ 越高，它导通的 $R_{DS(on)}$ 会越小，流过的电流也会稍微变大一些，但是变化的程度不会大得特别多。

#### 实物：从 1.9V 到 2.7V

我们用实物再走一遍。这个电路更简单：**就只有一个 MOS 管**，电池正负极直接接到它的 D-S 之间，相当于电池充当电源；G-S 之间接我们的直流稳压电源进来。通过调节直流稳压电源的电压，就改变了 $V_{GS}$ 的压差，随着 $V_{GS}$ 越来越高，$I_D$ 也就越来越大。

$I_D$ 怎么测？很简单，把万用表（调到电流挡）**串联到 D-S 的回路里**。整个回路是：电池正极出发 → 万用表 → MOS 管的 D → MOS 管的 S → 电池负极。

打开电源，先把稳压电源输出调到 0V。我们慢慢往上调。

- 调到 **1V**，电流一直是 0。再调到 1.9V、2V，还是没有电流。
- 把电池开关打开，继续往上调：1.8、1.9……这时候能看到有 **10mA** 了。

> **提示**：这个 MOS 管我之前测其实在 1.5V 左右就开通了，但万用表精度比较低，20A 挡位下最小采样精度是 10mA，所以要等到 1.9V 才看得见那个 10mA。

然后再慢慢把电压增大：1.91，就一点点往上涨。随着电压越来越高，D-S 之间的电流就越来越大、越来越大。

最终我们看到：**$V_{GS}$ 从 1.9V 变到 2.7V，电流就从 10mA 变成了 170mA。**

到 4.5V 左右的时候，它就已经开始进入完全饱和导通的状态了。再往上拧，$R_{DS(on)}$ 还会更小，但规律是一样的：随着 $V_{GS}$ 电压上升，$I_D$ 电流越来越高、越来越高。

这里再强调一遍：MOS 管不是一个理想开关。理想开关按下去就饱和导通了，断开就断开了；但 MOS 管**开了并不一定代表完全开通**，它一定要让 $V_{GS}$ 达到某一定值，才能处于完全把内部沟道打开的状态，这时候才能够流过最大值的电流。

### 耐压：D-S 能扛几百伏，G-S 却只有 ±20V

最后一个知识点，MOS 管的最大耐压。

MOS 管有最大耐压，也是因为它并不是一个理想的开关。理想开关断开之后可以承受无穷大的电压，但 MOS 管不是理想开关，所以即使断开了，它能承受的电压也是有限的。

> **结论**：所有的半导体所组成的器件，耐压都是有限的。

这是什么意思呢？来看这个电路：接一个电源进来（这里要给它加多一个小电阻限制一下电流），再加一个控制电源。正常来说，当开关处于断开的时候，MOS 管 D-S 之间也是一个断开的状态。断开之后，这边的电压比如说是 12V，就会完完全全地叠加在 D-S 之间，所以这时候 MOS 管承受的电压就等于 12V。

#### 选型余量怎么留

比如这里面有一个 100V 的电源，在挑 MOS 管的时候，至少要挑一个 **150V 以上耐压**的 MOS 管。

具体挑多少伏要看余量。一般来说，**耐压和电流的余量至少要挑到 1.2 倍以上**。如果对成本要求相对没那么高，挑的余量可以高一点，挑个两倍甚至三倍都可以；如果对成本要求比较高，就尽量靠近最大的工作电压，但**至少要留 1.2 倍以上**。

#### 实测 2N7000 的两个耐压

我手上这颗 MOS 管是 2N7000。D-S 之间的耐压是 60V，最大耐压等于 60V，那就意味着 D-S 之间的电压尽量不要超过 60V。

测耐压很简单，直接搞两个电源接上去就行了。正常来说我们应该在 G-S 之间加一个电阻，这样才能保证它一定不能导通，但这里我们直接接就行了。

**先测 $V_{DS}$**：从 0V 往上加，3V、慢慢加。因为稳压电源最大输出就是 60V，而 D-S 耐压正好是 60V，按道理加到最大也不会有事。一直加到 60V——**电源已经加到 60V 了，它现在也没事，不会出现电流突然变得很大的情况**，说明它这时候其实还没击穿。

所以可以看到：虽然写的是 60V 的耐压，实际上是能够承受 60V 以上的。一般来说厂家也会留一定的余量，不会说按 60V 就刚好 60V 就会炸，不至于。

**再测 $V_{GS}$**，这是我们要重点关注的地方。**大部分 MOS 管 G-S 之间的耐压都是 $\pm 20\text{V}$ 或 $\pm 30\text{V}$**，当然有一些特殊工艺的 G-S 耐压会高很多。

同样地在 G-S 之间加一个电压，一样来调。一般来说在 20V 以下都不会有事的：调到 20V，还没击穿；再往上调，还没击穿。**在 29.6V 的时候，可以看到这里已经有一个 1mA 的电流了。** 实际上可能还不止 1mA——这说明这时候它的 $V_{GS}$ 已经开始击穿了。当然它可能**早就**已经开始击穿了，只是稳压电源显示不出那个小电流而已，实际上可能在 22V 左右就已经开始击穿了。

如果继续再调大电压，会发现 $V_{GS}$ 之间的漏电流会越来越大：32V 的时候变成 4mA 了，再大一点 7mA，再大一点 11mA。

**但是如果在这个时候及时把电压撤下来**，你会看到电流又变成 0 了，所以这时候它还没有损坏。这时候用万用表去测它的 G-S，它其实还是正常工作的——因为现在 G-S 之间有一个 7.2V 的电压，所以可以再测一下它的 D-S，是会响的，说明 MOS 管还是正常的。

**但如果继续加**：现在 30V，电流慢慢变大，11mA，再加 15mA、20mA、19mA、24mA、30mA、34mA、**41mA**——突然之间看到它没有炸，但是电流突然之间没有了。

这个时候我们就说，这个 MOS 管已经损坏了，它已经完全击穿了。击穿之后它没有短路，而是处于一个**断路**的状态。这时候肯定就坏掉了，G-S 肯定就不能够去控制 D-S 两端的电压了。比如把电压再降下来变成 10V，再来测一下它的 D-S，是不会响的了。

所以大家一定要注意：**选 MOS 管的时候，不要只看它 D-S 的耐压很高。**有一些 MOS 管 D-S 能够达到几百伏甚至上千伏，但是 D-S 耐压再高，G-S 之间的耐压不一定很高。

G-S 两端的耐压跟 D-S 两端的耐压是不一样的，不要看到 D-S 两端能耐个一两百伏，就以为 G-S 两端也能承受这么高。

> **易错点**：G-S 之间的电压千万不要大于额定的标称值（常见 $\pm 20\text{V}$ 或 $\pm 30\text{V}$）。设计时宁可加一颗 G-S 下拉电阻保证它可靠关断，也不要让 G 极悬空——悬空时任何一点干扰电压都可能击穿栅氧。
