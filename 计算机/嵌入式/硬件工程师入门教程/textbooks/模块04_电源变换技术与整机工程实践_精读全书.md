## 恒流源的输出边界、高端反馈与直流稳压电源
> 对应块：BLK20 | 覆盖分集：P91-P95 | 块标题（分集名）：《87.恒流源电路的设计注意事项2》

上一节我们把恒流源电路设计注意事项的第一条讲完了：电路里那个输出的最高电压，是被运放的最大输出电压卡死的——运放拿 12V 供电，它最多也就只能把 12V 吐出来，所以负载端的电压最高也就只能高到 11V 附近，再往上是被三极管的 $V_B$ 死死限制住的。这一节我们把第二条边界条件补上。

这一条更狠，而且很多人在仿真里栽过跟头才反应过来：**卡死恒流值的，往往不是电压，而是运放能吐出的电流。**

### 限流的三极管，把电流需求算给运放看

三极管是电流控制电流型器件，我们前面就说过：集电极电流由基极电流决定，$I_C = \beta \times I_B$。而在这个恒流源里，负载电流几乎全部是从 $I_C$ 过来的。

那么问题就来了。我现在想让输出 1A，假设 $\beta = 100$，那 $I_B$ 至少得有 10mA。这个好说。可我要是想输出 10A 呢？$I_C$ 要到 10A，$I_B$ 就得是 $0.1A$，也就是 **100mA**。

> **易错点**：这一条就是很多人算完觉得"这电路没问题啊"、一上电就发现根本不工作的根因。基极电流是放大电流之后的量，恒流值越大，它对运放输出电流的要求是成倍往上翻的。

而实际上大部分运放根本给不了 100mA。常见运放的最大输出电流也就 50mA 上下，有些专门做信号放大的，最大的输出电流可能只有十几毫安。所以这一条必须记死：**运放的最大输出电压会限制恒流源能带的最大负载，运放的最大输出电流会限制恒流源能输出的恒流值**。两个天花板，各管一头。

拿 LM358 仿真一下，这道墙就看得见了。我们把前面那个理想运放换成 LM358，用 24V 供电，先验证电路能不能正常工作。20V 那一档的负载，仿真出来的电流确实是 1A，没问题。既然 1A 能达到，那按正常逻辑 10A 应该也能达到对吧？

于是我把负载电阻往下调十倍，想让它给出 10A。结果一点仿真，发现问题了：**输出电流根本没有 10A，只有 2A。**

我们直接拿探头去量运放的输出电流，一看只有 **19.3mA**。这时候输出已经饱和了，说明负载取得太重，我再把负载改小一点，改成 1Ω 再看——电流确实上来了，**6 安多**，但离 10A 还差着一截。

关键在于：这时候运放的输出电压**并没有饱和**，只有 9V 多，理论上它完全能到 20 多伏。所以这一次，**卡住恒流源的不是运放的输出电压，是它的输出电流**。

一量，运放输出电流已经等于 **40.6mA**——这就是 LM358 的最大输出电流，它不能再大了。

> **结论**：运放输出不了这么大的电流，它就把 $I_C$ 限死了。整个恒流源最后只停在 6A 附近，再怎么调负载电阻也没有用。

### 拆掉这堵墙的两条路

问题定位清楚了，解决思路就两条：要么让运放能吐更多电流，要么在中间加一级电流放大。

#### 换一颗吐得动电流的运放

最直接的办法就是把 LM358 换回理想运放。这里顺带把理想运放的模型参数也调一下，输出电阻改成 1Ω，电源改成 24V。

再仿真，**电流老老实实到了 10A**。这时候顺手量一下运放输出的 $I_B$，正好是 **101mA**。跟我们刚才纸上算的"10A、$\beta = 100$，所以要 100mA"几乎一模一样。

你看，公式是准的，LM358 给不了只是它自己弱。

#### 或者加一颗三极管，让它替你扛电流

第二条路更实用——**既然运放输出不够电流，那就利用三极管放大电流的特性。**

做法就是加一颗三极管，构成我们经常说的**达林顿管**：先用运放去控制第一颗三极管，再用第一颗三极管的集电极电流去驱动第二颗三极管的基极。

这样一来，原本需要从运放抽出来的 100mA，先经过一颗三极管放大 $\beta$ 倍之后，后一颗只需要 1mA 出头就能满足要求了。所有的电流压力，全部由三极管替运放承担。

仿真验证：保持原来的 LM358 不动，只加这一颗三极管，**电流做到了 4A**，而这时候运放输出的电流**连 1mA 都不需要**。

> **提示**：零基础的同学看到这儿可能会有点想法——"既然我学到这儿了，那有些东西就该用起来"。达林顿管就是最典型的例子，教科书上只告诉你它是什么，但真正能把一个运放驱动不动的电路救回来的，往往就是它。

到这里，恒流源电路的设计注意事项就齐了：一条看输出电压，一条看输出电流，一条靠达林顿管兜底。

好，接下来我们换个方向，开始讲**高端反馈的恒流源电路**。前面那些恒流源，反馈线都是老老实实接回运放反相端的。这一种不一样。

### 反馈线接到了同相端

这一版电路的特别之处就在于它的反馈端——不接反相端，接的是 **V 正（同相端）**。

```text
              +12V
               │
              1Ω   采样/负载电阻
               │
      ┌────────●─────────┐
      │        │ VR      │   ← 高端采样点
      │        C         │
      │    ┌───┴───┐     │
      │    │ NPN   │     │
      │    └───┬───┘     │
      │        E         │
      │        │         │
      └────────┼─────────┘
               │
              GND

   运放：  V+ ← VR   （高端反馈接到同相端）
           V- ← Vref
           Vout ─→ NPN 基极
```

很多同学一看到这种接法就懵了——反馈怎么能接到同相端？那不成了正反馈了吗？

我们前面讲虚短虚断的时候就说过：**并不是所有运放的负反馈都一定要接到反相端**，有一些负反馈是会接到同相端的。这里就是一个活生生的例子。

> **易错点**：拿到一个电路，如果实在判断不出来到底是正反馈还是负反馈，就别猜。用那条万能的分析方法硬推。

那条方法我们再说一遍：**当 $V_+$ 大于 $V_-$ 时，运放输出 $V_{out}$ 往上走；当 $V_+$ 小于等于 $V_-$ 时，$V_{out}$ 往下走。**

只要把这两条工作特性刻在脑子里，不管是正反馈还是负反馈，都能推出一个稳定状态：

- 负反馈推到最后，一定是 $V_+ = V_-$（也就是虚短）；
- 正反馈推到最后，$V_+$ 肯定不可能等于 $V_-$，那运放输出只可能等于 $V_{CC}$ 或者 GND，输出直接怼到轨。

这一个电路，我们用这个方法完整推一遍。

#### 上电瞬间：Vref 还没来，输出被顶到 6V

**第一步，先假设所有节点都是 0V。** 上电之前，每一点都是 0，运放输出也是 0。

**第二步，啪一下 12V 接进来，Vref 还没进。** 这时候 VR 这个点就是 12V。

**第三步，判断方向。** 此时 $V_-$（Vref）还是 0，$V_+$（VR）是 12V，所以 $V_+ > V_-$，运放输出 $V_{out}$ 往上走。

输出一路往上走，走到 **0.6V** 的时候，三极管导通了。一导通就有电流从这一路下来，VR 这个点的电压就开始往下掉。

**但它掉不下去多少。** 这是本段最关键的一步：

运放就算一路走走到 0.8V，三极管已经完全饱和导通，假设饱和压降是 0.3V——那 VR 也只能低到 0.5V 附近。可实际仿真里你看到的是 **6V 左右**，也就是 12V 经两个电阻分压出来的那个值。原因是这一路里串着采样电阻，回路电流大，压降就大。

所以结论很清楚：**如果 Vref 一直不接进来，稳态就是 VR 稳定在 6V 左右，回路里始终挂着一个很大的电流。** 仿真里这个电流实测约 **5.63A**。

#### Vref 接进来之后：环路自己把节点顶到 11V

现在我们把 Vref 接进来，比如从 0V 啪一下变成 11V。

上一拍的稳态是 VR ≈ 6V，Vref = 11V，于是 **$V_- > V_+$**，运放输出往下掉。

输出往下掉 → 三极管的 $I_B$ 减小 → 回路电流 $I_C$ 减小（因为 $I_C = \beta \cdot I_B$）→ 采样电阻上的压降减小 → VR 上升。

把 VR 这个电压记作 $V_R$，那么

$$V_R = 12\text{V} - 1\Omega \times I_C$$

$I_C$ 在减小，$V_R$ 自然就往上走。VR 一路升，升到 **11V** 的时候，$V_+$ 和 $V_-$ 又相等了。

可它们一旦相等，按前面那条特性，$V_{out}$ 就要往下掉那么一点点；一掉，VR 就冲过 11V 变成 11.001，$V_+$ 又反超 $V_-$，输出又往上抬那么一点点。就这么来来回回、自我调节，最终 VR 停在 11V。

> **结论**：这是一个标准的负反馈收敛过程，最后自然收敛到虚短状态，$V_+ \approx V_- \approx 11V$。

有了虚短，输出电流的公式就非常简单：

$$I_C = \frac{12\text{V} - 11\text{V}}{1\Omega} = 1\text{A}$$

#### 仿真里看到的两个关键现象

我们在电路里加一个下拉电阻和一个开关，用开关来模拟"Vref 有没有被接进来"，然后用示波器同时盯三个点：Vref、VR、运放输出。三个通道的刻度都设成 5V/div，起点设 0。

**开关断开（Vref = 0）：** VR 稳定在 6V 多，电流约 5.63A，运放输出顶到最大值约 12V。这时候运放输出电压很大，实际电路里还要额外加一个电阻做限流，虽然仿真是理想状态，但这一条不能省。

**开关闭合的一瞬间：** 橙色的 Vref 信号线啪一下从 0 跳到 11V → 运放发现 $V_- > V_+$，绿色输出线开始往下压 → 白色的 VR 线慢慢往上升 → 升到 11V 的时候稳住。电流随之从 6A 降到 1A。

这就是我们刚才在纸上推的那一幕，一个字都不差。

**顺带提一句：** 三个通道里有两条出现了正弦波——这正是下一节要解决的问题。

### 闭环为什么会自己振荡

上一节结尾那个正弦波，其实一点都不神秘。

按道理，电路稳定之后 $V_{out}$ 就应该恒定不变了，为什么它会振？根因就一句话：**我们这个运放的控制速度，比反馈速度快太多了。反馈跟不上运放，它就振。**

书上的结论更正式一些：运放的增益大于 1、反馈的相位延迟达到 180° 时，就会出现振荡。

> **提示**：这句话已经把解题思路给全了。振荡 = 环路增益太大 + 相位滞后。所以解法必然落在两头：**要么让运放慢下来，要么让反馈快起来。** 我们从这两个维度各走一条路。

#### 第一条路：把运放跑慢

回路里加一个电容，作用就是把运放的带宽压下来，这个电容叫**积分电容**。有了它，运放输出电压的变化速度被压低，反馈就追得上了。

仿真一加，果然不振了。

换一种思路更直接：我们在选运放的时候，看它的增益带宽积（GBW）。100MHz 的运放在这个电路里会振；换成 0.1MHz，就不振了。换成 1MHz 的话呢？前面还会振一点点，但最终能稳住——这个现象特别典型，说明环路的相位裕度不够，靠着系统的阻尼慢慢收敛。

> **结论**：只有当运放带宽高到 100MHz 这个量级、速度非常快的时候，它才会在这个反馈结构下激发出振荡。

#### 第二条路：把反馈拉快

另一头我们改不动运放，只能去改反馈路径。

先看反馈到底是怎么跑回来的：VR 这个点之所以能从 6V 慢慢升到 11V，靠的是运放输出下降 → $I_B$ 减小 → $I_C$ 减小 → 采样电阻压降减小。**所以反馈速度，实际上是被三极管的关断速度决定的。** 三极管关得越快，VR 涨得越快。

这里有两个可动手的地方：

**换三极管型号。** 相同工艺下，电流额定值小的三极管开关速度通常更快。我们复制一份原理图，只换一颗管子、其它全不动，跑仿真对比——上面那份（原型号）在振，下面这份（换过的）不振。

**加快反馈路径。** 在反馈线上串一个分压电阻，再在这个电阻上并一个电容，构成反馈补偿。光加电容是不够的，必须配一个分压电阻，反馈电容才能真正加速电压的反馈。

这里有个细节：加了分压电阻之后，反馈量会产生两倍放大，所以原边这一侧的电压要相应减掉一半。

仿真结果：问题**还没解决**。原因也很实在——这一侧三极管的开关速度本身就不够高，光调反馈网络怎么调都不够。所以还得回到第一条路，把运放带宽适当压一点，比如加个 10pF。

再跑：稳定了，VR 不振了，电流回到约 1A。控制环路彻底稳住。

> **易错点**：单靠反馈补偿救不回来时，正确的做法不是继续硬调反馈网络，而是老老实实把运放带宽压下来。反馈网络能改的幅度有限，运放的速度才是矛盾的源头。

### 负载要接地的场合：换成 P 管的高端反馈

前面那个高端反馈电路，输出还是从三极管的**集电极**出去的。有些场合负载必须接地，输出根本没法接在中间，那就得把 N 管换成 **P 管**。

```text
              +12V
               │
              1Ω   采样/负载电阻
               │
      ┌────────●─────────┐
      │        │ VR      │   ← 以发射极作为反馈点
      │        E         │
      │    ┌───┴───┐     │
      │    │ PNP   │     │
      │    └───┬───┘     │
      │        C         │
      │        │         │
      └────────┼─────────┘
               │
              GND

   运放：  V- ← VR   （反馈接回反相端）
           V+ ← Vref
           Vout ─→ PNP 基极
```

换了 P 管之后，反馈逻辑也跟着反过来了：

**发射极作为反馈点，是没有反向作用的，所以这个负反馈只要接回运放的反相端就够了。** 也就是说，Vref 接 V+，VR 接 V-。

我们还是用那两条工作特性推一遍。这次两边同时上电，不用一點一点分析了。

#### 为什么发射极那一端是被人"拉"上去的

**上电瞬间，三极管还没开通。** 这时候 V+ 那端（Vref）是 11V，VR 这端因为没电流，停在 12V。于是 $V_- > V_+$，运放输出往下走——可它一开始本来就是 0V，往下也走不了哪儿去。

**但三极管会导通。** 因为基极被拉低，发射极在 12V 这一侧，电流立刻灌下来，VR 从 12V 开始往下掉。

这里有个很容易被忽略的现象：**VR 往下掉的同时，运放输出也在往上走。** 原因是运放内部有输出阻抗，它不可能一边输出停在 0V、一边让三极管去承受整整 12V 的压差——那不合理。所以 VR 下降的这段时间里，运放输出被"顶"着往上抬。

于是出现一个很有意思的追赶：VR 从 12V 掉到 11.9V 的过程中，运放输出可能已经蹿到 8V 了，但 $V_-$ 依然大于 $V_+$，VR 继续往下走，运放继续往上走。

**关键的一拍在这里。** 一直走到 VR 下降穿过 11V 的时候，运放输出那边却被三极管的大电流"拉"到了 **10.3V**，停住了。

> **提示**：这个 10.3V 是被 $V_{BE}$ 钳位的结果，不是运放主动往上推的。想明白这一点：$V_-$ 一直大于 $V_+$，运放的输出方向是被往下压的，它怎么可能主动往上走？真正把它拉上去的是基极电流从三极管灌进运放输出引脚的那股力。$11 - 0.7 = 10.3$，钳位点就是这么来的。

VR 停在 11V，Vref 也是 11V，$V_+ = V_-$，虚短成立，环路锁死。

之后的过程和 N 管版一模一样，只是极性反过来：输出稍微往下走一点点 → $V_{BE}$ 增大 → $I_C$ 增大 → 采样电阻压降增大 → VR 往下掉一点点 → $V_+$ 又反超 → 输出再往上抬一点点。最终停在一个平衡点上。

#### 上电瞬间那一下脉冲电流

仿真里我们除了示波器，还加了电流探头。看到的现象是：**刚上电那一瞬间，运放的电流是负的**——电流从 12V 经 1Ω、再经三极管灌回运放那一端，运放在拼命吸收它。

这时候峰值能到 **-2A 左右**。随着 VR 慢慢上升，运放主动介入控制，这个电流就被压下来了，后面变得非常非常小。

> **注意**：这个脉冲只在两边同时上电、两边一开始都是高压的时候才会出现。如果 VR 那一路是缓慢上升的，就不会出现三极管的竞争，也就不会有这个大脉冲。但脉冲电流再大，它的上限也就是运放能灌的那点电流。**实际电路里这里一定要再加一个限流电阻**，把它压住。

知道它是一个负反馈之后，输出电流公式又回到老样子：

$$I_C = \frac{12\text{V} - V_{ref}}{1\Omega}$$

$V_{ref} = 11\text{V}$，代进去就是 **1A**。

### 直流稳压电源：先把公式算出来

从这里开始，我们正式进入电源的内容。

直流稳压电源我们打算讲两种方案：**带反馈的**和**不带反馈的**。带反馈的方案，本质上就是一个运放——所以只要前面那些运放的原理都搞定了，分析这一系列直流稳压电源就非常简单。

先看输出电压 $V_{out}$ 是怎么被 $V_{ref}$ 控住的：

```text
              +12V
               │
              （负载）
               │
      ┌────────●─────────┐  Vout
      │        │         │
      │        C         │
      │    ┌───┴───┐     │
      │    │ NPN   │     │
      │    └───┬───┘     │
      │        E         │
      │        │         │
      │   运放输出经电阻   │
      │      接到基极     │
      │        │         │
      │       1k          │
      │        │         │
      │        ●  V-     │
      │        │         │
      │       1k          │
      │        │         │
      └────────┼─────────┘
               │
              GND

   运放：  V+ ← Vref      V- ← 分压点
```

这个回路里明显有一条负反馈路径，所以可以直接用虚短虚断来分析。

**虚短：** $V_+ = V_- = V_{ref}$。

**虚断：** 运放输入不吸电流，所以分压支路可以化简成一个干净的分压器——Vout 下来一个 1k，再下来一个 1k 到地，中间那个点就是 $V_-$。

**分压公式：**

$$V_- = V_{out} \times \frac{1\text{k}}{2\text{k}} = \frac{V_{out}}{2}$$

两边一合：

$$V_{out} = 2 \times V_- = 2 \times V_{ref}$$

$V_{ref} = 1.25\text{V}$，输出就是 **2.5V**。

用虚短虚断推，就是这么简单的一个过程。

### 再从本质走一遍：输出是怎么停在 2.5V 的

不过很多同学更喜欢从本质角度去理解电路到底在干什么，所以我们再演示一次，用运放工作特性来看这个 2.5V 是怎么来的。

还是那两条：$V_+ > V_-$ 输出往上走，$V_+ \le V_-$ 输出往下走。

**起点：** 假设刚开始上电，几个点都是 0V。12V 接进来，$V_{ref}$ 立刻变成 1.25V。这时候 $V_+ = 1.25$，$V_- = 0$，所以运放发现 $V_+$ 大，输出往上走。

我们跟着它一步一步走：

| 运放输出 | 输出节点（减 $V_{BE}$） | 分压后 $V_-$ | 谁大 |
| --- | --- | --- | --- |
| 0.6V | 刚好开始导通，节点仍为 0 | 0 | $V_+$ |
| 1.0V | 0.4V | 0.2V | $V_+$ |
| 2.0V | 1.4V | 0.7V | $V_+$ |
| 3.1V | 2.5V | 1.25V | 相等 |

这里要注意，基极到 $V_{out}$ 之间还有限流电阻，上表是忽略电阻压降的理想推演。

一行一行看下来，规律非常清楚：**只要 $V_-$ 还追不上 $V_{ref} = 1.25V$，输出就一直往上走。**

- 输出走到 0.6V，三极管开始导通，这时输出节点还维持在 0；
- 走到 1V，输出节点 = 1 − 0.6 = 0.4V；
- 走到 2V，输出节点 = 1.4V，经两个 1k 分压得到 0.7V；
- 走到 **3.1V**，输出节点 = 3.1 − 0.6 = **2.5V**，分压下去正好是 **1.25V**。

此刻 $V_+ = V_-$，运放输出就想往下走了。可它一往下走到 3.0999V，输出节点就变成 2.4999999V，分压后比 1.25V 少了那么一丁点，运放立刻又发现 $V_+$ 大于 $V_-$，输出再往上抬一点点——如此往复，最终平衡。

> **结论**：输出稳定在 **2.5V**。

仿真验证也是这个画面：一上电，白色的 $V_{ref}$ 稳定在 1.25V，而输出侧会出现一个**过冲**，最高冲到 3V 多。过冲的原因是运放输出电压变化得太快——上电那一瞬间因为 $V_+ > V_-$，它一瞬间就冲到了一个比较高的电压。之后它从 3V 多开始慢慢往下压，一点一点降，最终降到 2.5V 就稳住了，后面一直平。

这个过冲在真实电路里是要留意的：负载如果对过冲敏感，就得在设计时把启动过程考虑进去。

### 从最小电路到真实产品

理论到这里就打通了。往后你在设计里真正要做的事情，无非是基于这一张框图，一点一点把外部器件展开、把参数算实、拿实际理论值去调整。你画着画着就会发现，原来那个最简单的小电路，慢慢就长成了你手里那个完整的东西。

> **提示**：设计的路径永远是同一条——**先把最基础的原理吃透，再用实际案例去拓展，把知识点一个个用起来。** 恒流源是这样，直流稳压电源也是这样，后面所有的电路都是这个套路。

直流稳压电源我们一共讲两种方案：带反馈的（也就是上面这个运放方案）和不带反馈的，上面这一路先把最核心的推导吃透。顺带说一句，带反馈这一版对应的实物电路，在弟子计划的直流稳压电源那一块是有的——理论你搞定了，剩下的就是在实际案例里把知识点一个个用起来，这一部分我们会放到弟子班的项目里来讲。

## 从线性稳压的效率困境，到 Buck 拓扑是怎么想出来的
> 对应块：BLK21 | 覆盖分集：P96-P101 | 块标题（分集名）：《92.直流稳压电源工作原理_下》

### 不带反馈的直流稳压电源

刚刚说的直流稳压电源是带反馈的。还有一种相对来说比较简单粗暴的，就是不带反馈的直流稳压电源。

不带反馈的直流稳压电源就不需要用运放了，只需要加一个稳压管，再加一个三极管，再加两个电阻和电容，就可以实现直流稳压电源。它的原理是怎么实现的呢？这里面我们简单来讲解一下。

它的核心就两句话：第一，三极管只要导通，$V_{BE}$ 压降就约等于 $0.6\ \text{V}$ 或 $0.7\ \text{V}$，我们在这里就假设等于 $0.6\ \text{V}$；既然 $V_{BE}$ 是一个近乎固定的数，那么把基极电压 $V_B$ 控制住了，输出端的 $V_E$ 就等于被控制住了。第二，基极电压怎么控制？加一颗稳压管就行了——稳压管有一个很重要的特点：**只要稳压管导通了，它两端的电压基本上就是一个恒定值**。

```text
   12 V ──[R1]──┬──► Q1 基极 (NPN)
                 │        │
                 │        └──► 发射极 ──┬──► Vout ≈ 5 V ──┬──► 负载
                 │                     │                  │
              [DZ 5.6V]             [C1] ────────────────┘
                 │
                GND
```

举个具体的数：假设用一个 $5.6\ \text{V}$ 的稳压管，输入 $12\ \text{V}$。$12\ \text{V}$ 经过电阻 $R1$，稳压管肯定会击穿，击穿之后这个节点电压就变成 $5.6\ \text{V}$ 了。基极等于 $5.6\ \text{V}$，发射极就等于 $5.6\ \text{V} - 0.6\ \text{V} = 5\ \text{V}$。就这样，输出被钉在 $5\ \text{V}$ 上。这就是不带反馈的直流稳压电源的工作原理。

> **定义**：所谓"不带反馈"，指的是这条电压链路上没有任何东西去"回头看"输出端的实际电压，它是一条纯粹开环的通路。

那它不好的点在哪里？三极管的 $V_{CE}$ 不是等于它饱和状态的 $0.3\ \text{V}$，这时候它等于电源电压 $12\ \text{V}$ 减去输出电压 $5\ \text{V}$，就等于 $7\ \text{V}$。意味着这个直流稳压电源的调整管会承受一个 $7\ \text{V}$ 的电压。假设输出的负载等于一个 $5\ \Omega$ 的负载，这时候回路流过的电流就等于 $1\ \text{A}$。

这时候三极管所承载的功耗是非常大的。它的功耗等于 $7\ \text{V} \times 1\ \text{A} = 7\ \text{W}$。

| 能量去向 | 数值 | 是否有用于 |
| --- | --- | --- |
| 电源输入 | $12\ \text{V} \times 1\ \text{A} = 12\ \text{W}$ | —— |
| 负载上拿到 | $5\ \text{V} \times 1\ \text{A} = 5\ \text{W}$ | 有用功 |
| 三极管上发热 | $7\ \text{V} \times 1\ \text{A} = 7\ \text{W}$ | 全部是有害功 |

因为电源输出的功耗实际上是等于 $12\ \text{W}$，$5\ \text{W}$ 是放在了输出对应的负载上面，这一部分是有用的能量；剩下 $7\ \text{W}$ 全部都压在三极管上面。所以为什么说线性稳压电源它的工作效率很低，就是因为三极管主动地把电源输出多余的这部分能量全部都承载掉了，全部变成了热。

### 带反馈与不带反馈，差在输出稳不稳

刚刚讲解了带反馈型的 LDO，还有一个不带反馈型的 LDO。带反馈和不带反馈到底有什么区别呢？接下来就一起来讲一下。

这两个电路，最大的区别在于**稳定性**。这里的稳定性不是指瞬态稳定，指的是**输出点**的稳不稳。

我们直接上仿真来看。让它们输出都是等于 $5\ \text{V}$。第一步先看两端输出的电压是不是都是 $5\ \text{V}$——带反馈的这边输出确实是 $5\ \text{V}$；不带反馈的这边，不是等于 $5\ \text{V}$，但约等于 $5\ \text{V}$。我们在输出点各挂一个示波器，点一下开始仿真，等输出稳定下来之后就会看到：通道 A（带反馈的）是一个很标准的 $5\ \text{V}$；不带反馈的那条，电压等于 $5.2\ \text{V}$，就不是等于 $5\ \text{V}$ 了。

这个原因主要有两个。第一，稳压管会有对应的偏差：稳压管写着一个 $5.6\ \text{V}$，但实际稳压出来的结果有可能等于 $5.5\ \text{V}$，也有可能等于 $5.7\ \text{V}$。第二，三极管的 $V_{BE}$ 导通压降本身就是有区别的，而且它会跟着工作电流变：

| 三极管工作电流 | $V_{BE}$ 压降 |
| --- | --- |
| $1\ \text{mA}$ | 约 $0.5\ \text{V}$ |
| $5\ \text{mA}$ | 约 $0.6\ \text{V}$ |
| $10\ \text{mA}$ | 约 $0.7\ \text{V}$ |

所以理论上我们想要它输出 $5\ \text{V}$，实际输出就变成了 $5.2\ \text{V}$。电流不一样的时候三极管的导通压降也是不一样的。这时候把这两个开关闭合，一闭合之后继续来看：带反馈的输出电压依旧还是等于 $5\ \text{V}$，通道 A 还是等于 $5\ \text{V}$；但是不带反馈的输出就由刚刚的 $5.2\ \text{V}$ 变成了一个 $5.083\ \text{V}$。

> **结论**：带反馈和不带反馈，在不同的工作条件下，输出稳定性的差别是会被放大的。稳压管和 $V_{BE}$ 这些"看起来差不多"的偏差，在开环状态下没有任何东西去纠正它们。

如果希望输出更加稳定，电路里就**必须**让它变成一个负反馈系统，因为负反馈系统是可以实时去自我调节的。这个区别用一个比喻就讲透了：**不带反馈相当于是开环状态，开环状态就相当于一个瞎子**——自己觉得后面就是 $5\ \text{V}$，但实际上是不是 $5\ \text{V}$ 它并不知道。带反馈的话，相当于控制大脑里面想着"输出要等于 $5\ \text{V}$"，然后实际是不是 $5\ \text{V}$，是有**一只眼睛**可以去观测的：输出小了就把基极抬高一点，输出大了就把它调小一点。

我们把这个"眼睛"具体怎么转的过程完整走一遍。这里有一个开关，带一个比较大的负载，输出用一个 $5\ \text{V}$ 给 $1\ \text{k}\Omega$ 供电，电流很小，就等于 $5\ \text{mA}$，所以流过三极管的电流 $I_C$ 也就约等于 $5\ \text{mA}$。假设 $I_C$ 等于 $5\ \text{mA}$ 时 $V_{BE}$ 等于 $0.5\ \text{V}$，等于 $500\ \text{mA}$ 时 $V_{BE}$ 等于 $0.8\ \text{V}$（$V_{BE}$ 随 $I_C$、$I_B$ 变，当然还跟温度相关）。

开关闭合之前输出已经等于 $5\ \text{V}$，是个稳态。此时运放会自动把自己的输出电压调到 $5.5\ \text{V}$ 左右。刚上电的时候运放"+"端是 $0$、"−"端是 $2.5\ \text{V}$，运放发现 $V_+$ 比 $V_-$ 大，输出就从 $0$ 慢慢往上升；升到 $0.5\ \text{V}$ 时三极管开通导通；继续升到 $1.5\ \text{V}$ 时，输出电压此时是 $1\ \text{V}$，$1\ \text{V}$ 反馈回到分压点就变成 $0.5\ \text{V}$，它还会继续往上升；当刚好升到 $5.5\ \text{V}$ 时，输出就等于 $5\ \text{V}$，此时分压点刚好是 $2.5\ \text{V}$，于是自动形成一个稳态。

突然之间给它挂一个 $10\ \Omega$ 的负载进来，电流"啪"一下从 $5\ \text{mA}$ 变成约 $500\ \text{mA}$。$V_{BE}$ 立刻就变成 $0.8\ \text{V}$ 了，开关闭合一瞬间输出电压会往下掉，比如从 $5\ \text{V}$ 掉到 $4.5\ \text{V}$。运放发现 $V_-$ 比 $V_+$ 小了，于是输出电压自动往上调一点，调到 $5.6\ \text{V}$。可 $500\ \text{mA}$ 时 $V_{BE}$ 已经等于 $0.8\ \text{V}$ 了，所以 $5.6\ \text{V}$ 的基极电压对应输出只能到 $4.8\ \text{V}$。运放是知道的：$4.8\ \text{V}$ 分压过来这里也就只有 $2.4\ \text{V}$，还是 $V_+$ 比 $V_-$ 小，于是再往上调一点，调到 $5.8\ \text{V}$，此时输出刚好又等于 $5\ \text{V}$，分压点又回到 $2.5\ \text{V}$，又形成稳态了。

| 时刻 | $I_C$ | 运放输出 $V_B$ | 输出 $V_{out}$ | 分压点 | 运放动作 |
| --- | --- | --- | --- | --- | --- |
| 稳态 | $5\ \text{mA}$ | $5.5\ \text{V}$ | $5.0\ \text{V}$ | $2.5\ \text{V}$ | 平衡 |
| 接入 $10\ \Omega$ | $5\ \text{mA} \to 500\ \text{mA}$ | $5.6\ \text{V}$ | 掉到 $4.5\ \text{V}$ | $< 2.5\ \text{V}$ | $V_- < V_+$，上调 |
| 第一次修正 | $500\ \text{mA}$ | $5.6\ \text{V}$ | $4.8\ \text{V}$ | $2.4\ \text{V}$ | 仍不够，再上调 |
| 第二次修正 | $500\ \text{mA}$ | $5.8\ \text{V}$ | $5.0\ \text{V}$ | $2.5\ \text{V}$ | 重新稳态 |

所以带反馈就有这样的好处：**可以实时去监测输出到底够不够**。够了就停，不够就增加一点；如果太大了，就让输出减小一点点。

而不带反馈就不具备这种实时调节的能力。这里我们就把稳压管当成一个理想稳压管，它一直就等于 $5.6\ \text{V}$。带载一开始是 $1\ \text{k}$，压降是 $0.5\ \text{V}$，那它在默认状态下就是一个 $5.1\ \text{V}$ 的输出。突然之间加一个 $10\ \Omega$ 的负载进来，电流从 $5\ \text{mA}$ 变成 $500\ \text{mA}$，$V_{BE}$ 从 $0.5$ 变成 $0.8$，所以输出这一块就会从 $5.1\ \text{V}$ 往下降，降成 $5.6 - 0.8 = 4.8\ \text{V}$。

> **提示**：这个 $4.9$ 和 $4.8$ 的差别，正是初学者容易自己算懵的地方——稳压管钉死的是**基极**，不是输出，输出永远等于"稳压管电压减去当时的 $V_{BE}$"，$V_{BE}$ 一变，输出就跟着掉。

但是这个 $4.8\ \text{V}$ 降完之后，稳压管它是**不知道**的。它就像个瞎子一样，或者像一个很悠闲的躺平的工作人员一样：反正我就觉得按了个 $5.6$ 在这里，就天天喝茶，我也不管你后级到底是等于多少，反正我是已经觉得这里你的输出就等于 $5\ \text{V}$ 了。所以这种开环状态的输出肯定是没有这么稳定的。

### 最原始的开关电源：一个开关、一颗电阻、一颗电容

开关电源有很多种类型，有 Buck、Boost，还有反激，还有 Buck-Boost，对不对？所有开关电源里面，只要它是有开关特性的，我们都可以把它称之为开关电源。今天先来把降压型，也就是 Buck 的工作原理讲透。

可能很多同学看 Buck 已经很熟悉了。但我们最原始的一个开关电源，实际上是不长这样的。我们从一个最原始的模型一步一步地来，看 Buck 的电路模型是怎么来的。

最原始的模型是这样：这里有一个 $12\ \text{V}$，下来之后接一个开关，然后这个开关下来，只要加一个电阻，再加一个电容——这个电路就是一个最简单开关电源的拓扑结构。

```text
   Vin = 12 V
      │
    ┌─┴─┐
    │ S │  ← 开关（"控制电路"决定它什么时候通断）
    └─┬─┘
      │
    ┌─┴─┐
    │ R │  ← 限流，同时会白白耗能
    └─┬─┘
      ├───────────┐
      │           │
     GND       ┌─┴─┐
              │ C │  ← 电容 ≈ 电池，电压慢慢爬
              └─┬─┘
                │
              Vout（拿万用表盯着）
```

它是怎么工作的？我们一般这里会有一个控制电路，那控制电路我们现在先不管，**我就假设现在我们人就是那一个控制电路**。如果通过人去控制这个电路来达到降压效果，其实是很简单的：在输出端加一个万用表。当开关一闭合的时候，我们前面讲电容的时候跟大家讲过，电容有点像一个电池，用一个直流电源给它充电，它的电压会慢慢慢慢最终充到等于电源电压。

如果我把这个开关一闭合就一直闭合，我们会看到输出电压从 $0$ 最终充到 $12\ \text{V}$。但我们想要的是降压效果，不能让它到 $12\ \text{V}$。比如说现在想降到 $5\ \text{V}$，那怎么办呢？很简单，我们盯着万用表看：假设上电之前这里是 $0$，我看到输出小于 $5\ \text{V}$，那我就把开关闭合；一闭合之后，输出电压一样会慢慢往上升；当它上升到 $5\ \text{V}$ 的时候，我就把开关断开。断开之后，它的输出是不是维持在 $5\ \text{V}$ 不变了？

然后如果我们在里面给它带一个负载，就会看到：我开关一闭合，闭合到 $5\ \text{V}$ 时断开，一断开电压就往下掉；假设掉到 $4.9\ \text{V}$ 时，我发现它又比 $5\ \text{V}$ 小了，那我就再把开关闭合；一闭合它又会往上冲，冲到 $5.1\ \text{V}$ 左右我又断开。只要这样来回往复不停地切换开关，最终输出电压就会不停地在 $5\ \text{V}$ 上面来回抖动。

```text
Vout
12 V ┤        ─────────────────────  不做任何控制，一口气充到 Vin
     │
 5 V ┤    ╭─╮   ╭─╮   ╭─╮         带负载来回切换，抖在 5 V 上
     │   ╱   ╲ ╱   ╲ ╱   ╲
 0   ┼──╯     ─       ─     ─
     └─────────────────────────── t
```

我们用仿真软件一起看一下：拿一个 $12\ \text{V}$，拿一个开关，再拿一个电阻，然后再拿一个电容，电阻可以取得小一点，两端都接 GND，示波器测这一点的输出电压，再把仿真精度提高。不做任何控制、开关闭合就一路充，最终肯定冲到 $12\ \text{V}$。现在想降压，重新做一次控制：开关闭合，电压慢慢升，升到 $3$ 点多，等于 $5\ \text{V}$ 的时候把开关断开，这时它就维持在 $5\ \text{V}$ 附近不变了——这就是降压功能。

再假设加一个 $100\ \Omega$ 的负载：重新闭合，输出电压慢慢升，升到约 $5\ \text{V}$ 的时候断开，断开它往下掉，再闭合；升到 $5\ \text{V}$ 再断开。来回往复地重复控制，输出就约等于 $5\ \text{V}$。

> **结论**：这就是开关电源最核心的一个控制思维——**我通过一个开关，可以让输出端的能量分批地到达后级**，这样子我就可以控制输出电压的最大值了。这和线性稳压"把多余的电压压在三极管上烧掉"是完全相反的思路。

### 把电阻换成电感

按刚刚讲的，这已经是一个最简单的开关电源模型了。但为什么我们现在看到的开关电源不长成这样，而要用成后面那种样子？主要的原因只有一个：**开关电源的效率可以做得很高，我们研发一个开关电源出来，主要就是为了研发出一种高效率的降压电路。**

用这一种开关电源的结构，降压功能确实是可以实现的，但这里有个电阻。这个电阻会对转换效率产生非常大的影响——我们所有的电源在给后级提供能量的时候，是不是肯定会经过这个电阻？既然有电阻，它就肯定会耗能。虽然换成这种开关结构确实可以降压了，但因为这个电阻的存在，耗能会非常高，这就脱离了我们设计开关电源的初衷了。

所以很多同学会想：既然电阻耗能，那我把它去掉不就可以了？**从一个理想的状态下，这样子是没有问题的**，但实际上你把电阻去掉是不可能实现降压功能的。为什么？因为当你把电阻去掉之后，开关一闭合，$12\ \text{V}$ 给后级电容充电的这个回路上，它的充电电阻 $R$ 就变得非常非常非常小。

我们前面讲电容的时候说过，充放电跟充电时间常数 $\tau$ 有关：

$$\tau = R \times C$$

这里的 $R$ 非常非常非常小，就意味着电容的充电速度非常非常快。于是就出现了一个问题：**开关一闭合，电压"唰"一下就从 $0$ 冲到 $12\ \text{V}$ 去了**。你可能就眼睁睁地看着输出电压从 $0$ 飞到 $12\ \text{V}$，都还来不及把开关断开，它就已经冲到 $12\ \text{V}$ 了——那你还怎么控制降压的效果呢？

仿真里看得很清楚：把电阻改成 $0\ \Omega$，一闭合瞬间输出就已经冲到 $12\ \text{V}$ 了，我哪有时间来把这开关断开。

> **易错点**：电阻在这里的作用不是"用来耗能"，而是**给控制电路争取反应时间**。电阻就是控制电路的时间预算，一去掉，时间预算就没了。

那么我们从中可以得到一个什么道理呢？如果把电阻去掉，理论上效率确实可以做得非常高，但是它对我们控制电路的速度要求就非常高，要求它非常非常非常快才行。而我们几乎所有的控制电路都不可能满足这个条件。所以我们不能单纯地说"把电阻去掉就完事了"。

那怎么去解决呢？很简单——**把这个电阻换成电感就可以了**。

为什么换成电感就可以？核心的思想是，电感跟电阻有一个非常不同的特点：**电感它是不耗能的**。前面讲电感的时候说过，电感和电容都是储能器件，理想状态下它们都不耗能。电感不耗能，就解决了刚刚说电阻有损耗的问题。

另外电感还有一个非常大的好处：**电感的电流 $I$ 是不突变的**。

我们先捋一下一开始加电阻的目的是什么。电阻在里面会限制我们电流的充电速度，有了电阻之后，我们去控制开关对个人的要求就非常低了——随随便便一个速度快那么一点点的控制电路都可以完成控制。但是加电阻的坏处就是效率很低。

换成电感之后，第一个好处：电感同样可以限制电流；电流被限制了，是不是意味着电容电压的变化速度也会被限制？同时，电感还不耗能。所以加了电感之后，它既解决了电阻耗能的问题，又保持了电阻"抑制电容充电速度"的这个效果。人在外面控制这个开关，一下子就变得非常简单了。这个把电阻换成电感的替换，我觉得是非常非常巧妙的一个特点。

### 续流二极管：给电感留一条不断流的路

换完之后，这个电路又出现了一个新问题。什么问题呢？就是因为电感的电流 $I$ 不突变。它确实解决了电容电压突变的问题，但**电流不突变这件事本身，会带来新的麻烦**。

我们把整个过程重新演示一遍。刚上电时输出是 $0$，我们通过万用表发现输出是 $0$，于是把开关闭合。$12\ \text{V}$ 给输出电容充电，电压越来越高越来越高。同时注意电感的电流波形，它也是从 $0\ \text{A}$ 慢慢往上升的。

现在问题来了：当我们输出升到约 $5\ \text{V}$ 时，我们要断开开关。假设开关断开的一瞬间，电感的电流等于 $1\ \text{A}$ 左右。这时候你开关"啪"一下断开——电感一开始的电流回路没有了，因为开关断开了嘛。**没有这个回路，就相当于电感上电流回路的电阻发生了突变。**

前面讲电感的时候说过，电感的回路电阻是一定不能发生突变的。如果发生突变，会感生出一个非常大的电压。这个很大的电压很轻松地就能把我们这个开关给击穿。所以我们是不能直接用这个电路的——**因为电感在工作过程中会感生出一个很大的电压，而这个感生电压就是因为开关断开、电感回路电阻发生突变导致的。**

那怎么解决呢？很简单，在这里给它加一个续流的二极管。加了之后它就可以完美地解决我们刚刚说的问题。

过程是这样的：一样假设刚上电时输出是 $0$，我们把开关闭合，输出电压越来越高，电感的电流也越来越高。升到 $5\ \text{V}$ 时把开关断开，电感因为电流不能突变，就要把它的能量释放掉。释放的时候它发现原来的支路走不通了，但它会发现这个回路还有一个新的支路——于是它就可以通过这个支路进行续流。这样子它就还有一个完整的续流回路，所以就**不会**产生刚刚说的那个高压。

> **定义**：这个二极管就叫**续流二极管**，它唯一的作用就是给电感提供一条"电流不会断掉"的回路。

我们可以从另一个角度把这件事说得更狠一点：如果不加这个寄生二极管，开关断开的一瞬间，电感会强制性地把它的能量释放出去，而它释放的过程其实是**对我们这个开关的寄生电容充电**。这个寄生电容的容值非常非常小，所以当电感上的能量转移到它上面的时候，电容两端就会产生一个很高的电压。这个很高的电压如果说你这个开关不是一个理想开关，比如说你是一个 MOS 管，它很轻松地就可以把你这个 MOS 管给击穿。

仿真里能直接看到这个尖峰。我们把电阻换成电感之后重新仿真，开关闭合，输出电压也是慢慢往上升的，而且上升得越来越快。当它上升到 $5\ \text{V}$ 时把开关断开——注意，我们刚才看的只是输出电容两端的电压，所以确实没有看到高压。**但如果把示波器移到开关两端去观察，就完全不一样了。**

我们重新来仿真：把开关闭合，橙色的曲线越来越高越来越高，我假设在 $5\ \text{V}$ 时把开关断开。看这里，把幅值刻度提高——现在已经提高到 $5000\ \text{V}$ 每格了，这一个尖峰是直接超过了 $5000\ \text{V}$ 的，还超了很多，大概 $1.2$ 格左右，也就是接近 $6000\ \text{V}$。

```text
V_sw（开关两端电压）
   ↑
   │   ╷  尖峰 ≈ 1.2 格 × 5000 V/格 ≈ 6000 V
   │   │
12 V┤───┘ └─────────────────  常态就是 Vin 的量级
   │
 0 ┼───────────────────────── t
       开关断开的那一瞬间
```

所以我们就会发现，在开关断开的一瞬间会产生一个非常高的尖峰电压。实际电路中可能不会这么高，但搞个几百伏出来还是一个很简单的问题——如果你这里是一个 MOS 管或者三极管，你说它坏不坏？

那我们假如在这里给它加一个二极管呢？直接用一个理想二极管在这里就行了。再重新仿真：点一下仿真，开关闭合，可以看到橙色的越来越高，到 $5\ \text{V}$ 时断开。断开之后我们发现，它这个开关两端的电压**也会上升**——因为这时 SW 节点被续流二极管拉到了输入电压那一侧——但是这时候刻度才 $5\ \text{V}$ 每格，还有没有那个尖峰？没有了。

所以加这个二极管就可以非常完美地解决我们刚刚说的尖峰问题。

到这里，我们就可以得到一个完整的 Buck 开关电源拓扑结构。把"小人"删掉，把万用表删掉，把负载删掉，就得到了这样一张图：

                      │
                   ┌──┴──┐
                   │ Cin │   输入电容
                   └──┬──┘
                      │
        ┌─────────────┴─────────────┐
        │          SWITCH           │  ← VIN → SW，集成在芯片内
        └─────────────┬─────────────┘
                      │

### 降压型开关电源的一个完整周期

最后我们简单梳理一下降压型开关电源的具体工作原理。

电路中实际是由开关电源控制芯片进行控制的。控制芯片外接两颗反馈电阻，将采样信号反馈给芯片，芯片内部的驱动电路去控制开关管——开关管可能是 MOS 管，也可能是三极管。

电路刚上电时，控制芯片开始工作，它首先通过分压电阻检测输出电压。假设设定的输出目标值是 $5\ \text{V}$，芯片就会去判断当前输出电压是否达到了 $5\ \text{V}$。如果检测到输出小于 $5\ \text{V}$，芯片就会让开关导通闭合，或者说让驱动 MOS 管的 PWM 占空比变大。占空比增大之后，输入 $12\ \text{V}$ 给后级回路提供的能量越来越多，输出电压就会逐步上升。当输出电压上升到 $5\ \text{V}$ 左右时，系统达到平衡状态，控制芯片输出的占空比会进行微调，最终让整个电路维持在动态平衡状态。

在整个过程中要分清两种状态下的电流路径：

```text
开关导通（能量向后级输送）
  Vin ──► 开关 ──┬──────────────► 负载
                  │                  ▲
                  └──► Cout 充电储能 ─┘

开关断开（电感 + 电容接力）
  Vin   断开
   │
  SW ●──► D ──► 续流回路：L → Cout → 负载 → GND
   │
   └────► L ────► Cout ────► 负载 ────► GND
   （电感储能释放完毕后，由 Cout 持续给负载供能）
```

当开关导通闭合时，电源的能量流向后级，电流路径分为两条：**一路给电容充电储能，一路给负载供电**。当系统达到平衡、开关断开的一瞬间，电感通过续流二极管构成回路，进行续流放电。电感储能释放完毕后，由输出滤波电容持续给负载提供能量。

这就是降压型开关电源基本的工作原理。

回头再看一眼开头那个 $7\ \text{W}$：线性稳压里多出来的电压是被三极管"主动承载掉"的；而开关电源导通的时候，多出来的电压根本没有被"压"在任何器件上，能量是被分批送到后级的。**同样是一个 12 V 降到 5 V，差别只在于多出来的那部分是被烧掉，还是根本不烧——这正是我们当初一定要研发出一个开关电源的原因。**

## 让电感去搬运电荷：Boost 升压、电荷泵，以及第一台纯硬件循迹小车
> 对应块：BLK22 | 覆盖分集：P102-P108 | 块标题（分集名）：《98.BOOST的工作原理》

Buck 刚搞定，紧接着就往下走，讲 Boost。

Boost 这个结构，很多人一眼看过去觉得很熟悉，对不对？但我们先别急着盯着框图看——我们先得知道，这玩意儿到底是怎么来的。

### 一个开关、一个电容，升不了压

一个电源要实现升压，如果你不加任何辅助器件，只靠电容或者电阻，是升不上去的。

你想象一下：这里有个 5V，这 5V 电路里我只放一个开关，再加一个电容，能升压吗？不能。因为开关一闭合，输出端顶多也就等于一个 5V。除非你在那儿堆好几个开关、好几个电容，靠电容的自举去升压——理论上能，但那个过程就相当复杂了。

所以要想升压，必须充分利用电感一个很重要的特点：

> **定义**：电感上的电流不能突变，但它两端的电压可以突变。

就这一条，就够了。

我们在电路里放一个电感，再加一个开关。当开关一闭合，电流开始流过电感；这时候如果把开关**突然**断开，电感两端就会产生一个比电源高很多的电压。既然它能自己把自己顶上去，那升压还不是顺手的事？

关键问题来了：**我怎么才能把电感的能量收下来？**

很简单，后级再加一个储能器件——比如一个电容。我们把整个过程走一遍。刚上电的时候，输出是 0V，电源也当作是 0V。这时候开关一闭合，5V 就给电感蓄能；蓄满了，"啪"一下把开关断开。断开的一瞬间，电感电流是从左往右走的，开关没了，它照样得从左往右走——于是这股电流就一股脑灌到后级去。

这里有个很神奇的现象。如果不加电感，你这个电容最多只能充到 5V。但加了电感之后，电感在释放自己能量的过程中，它**根本不管你后级现在是 5V 还是 10V**。只要它身上还有能量——比如开关闭合的时候已经给电感充到了 1A——开关一断开，它就会把这一整个 1A 的电流，强制性地全部倒到你后级去。

那后级电容的电压按什么算？$V = \frac{Q}{C}$。电感强制性地把一大堆电荷放到后级电容上，$Q$ 上升了，$C$ 又不变，那 $V$ 是不是肯定往上走？所以我们最终这个电容每被充一次，就会上升一个台阶。

```text
输出电压
  │            ┌───┐        ┌───┐        ┌───┐
  │            │   │        │   │        │   │
  │      ┌───┐ │   │  ┌───┐ │   │  ┌───┐ │   │
  │      │   │ │   │  │   │ │   │  │   │ │   │
  └──────┴───┘─┴───┘──┴───┘─┴───┘──┴───┘─┴───┘──→ 时间
         断    合     断    合     断    合
```

这张图就是 Boost 的全部秘密：开关闭合一步、断开一步，输出就往上爬一格。

### 那个二极管为什么非加不可

台阶是有了，但新的问题马上冒出来。

你想啊，电感每次蓄能都得把开关闭合。可这一闭合，我们发现——这个电容辛辛苦苦在上一周存下来的能量，又被释放掉了。那你这不成了白干吗？每给电感充一次能，下次给电感充能的时候，它又顺手把电容的能量放掉一次，这肯定不合理。

所以我们必须保证：**开关闭合的时候，这个电容不能被释放能量。**

怎么办？在这儿多加一个二极管。

加了之后，事情就顺了：开关闭合时，电源给电感蓄能；蓄满了断开，电感强制给后级充电，输出上升一个台阶；等下一次开关闭合，因为输出点被拉回 0V 了，二极管就处在反向截止状态，不会再往后级倒能量。

至此，一个升压开关电源最基本的拓扑结构就齐了——电容、二极管、开关，再加一个电感。

```text
        S               D
Vin ──o/ o──── L ──────|>|────┬──── Vout
 │                            │
 │                            C
 │                            │
GND                           GND
```

读图：开关闭合时，电流从 Vin 经 S、L 走到地，电感蓄能；二极管此时反偏截止，输出电容靠 Vin 侧维持电压。开关断开的瞬间，电感电流方向来不及改变，只能继续左→右，于是通过二极管灌进输出电容，把它抬高一个台阶。

### 在仿真里看它一格一格往上爬

光讲不如看，我们直接仿真跑一遍。

先把负载去掉，电源加上，顺便把电感电流这条波形改成红色，时间轴调小一点、仿真精度提高一点、电感量也加大一点，然后点开始。

刚上电的一瞬间，我们就会看到输出电压变高——因为电源会往后级充电。这里要注意一个细节：**仿真里必须加负载**。不加载荷的话，一上电它就会一路冲到很高的电压去，那就没意思了。加上负载重新跑：刚上电时电源给后级充电，充满之后，输出稳定在 12V 左右。

然后我把开关闭合——你看，电感电流开始升高。断开——你看，输出电压又上升一个台阶。因为我刚才断开的时间拖得太长了，所以升得非常猛。快一点断开给你看：闭合、断开、闭合、断开、闭合、断开，不停地按这个开关，输出是不是**一个台阶一个台阶慢慢往上爬**？

再往前走一步。可以在回路里加一个 $1\ \Omega$ 的电阻，把电流限制一下。等输出电压先稳住，现在稳住了对不对？我闭合、断开——升一个台阶。再闭合、再断开——又升一个台阶。

那如果我想要输出变成 10V 呢？不停地这么控制就好了。你看现在已经等于 10V 了，我再闭合、再断开。等它输出等于 10V 之后，它又慢慢慢慢放电，放到 10V 以下，我再闭合、再断开，它又保持在 10V 左右。

所以结论很清楚：**只要不停地控制这个开关，输出就会一直维持在约 10V。** 我们这是非常巧妙地利用了电感电流不能突变的特性，把升压给做出来了。

### 电感的饱和电流，一定要比理论峰值大

开关电源选电感的时候，有一条必须记住：

> **结论**：饱和电流一定要大于电路中理论电流的最大值。

比如说我们算出来电感的峰值电流是 10A，那饱和电流一般至少取 1.2 倍，也就是 12A；取成 1.5 倍那就更稳了。

那要是你取的时候没取够呢？比如你取了个 1A，会出现什么问题？这就意味着电感在工作过程中会**饱和**。

饱和是很严重的问题：电感一旦饱和，就不能当成电感来看待了，**你只能把它当成一根导线**。

为什么这么讲？回忆一下电感的特性——它能抑制电流的上升，对不对？它有个公式：

$$V = L \frac{\mathrm{d}i}{\mathrm{d}t}$$

把这个式子换一下，我们就知道：

$$\frac{\Delta i}{\Delta t} = \frac{V}{L}$$

（严格说前面还有个负号，我们把它去掉不管。）从这个公式就能看到：假如电感处于正常工作状态，电感两端的电压 $V$ 不变、电感量 $L$ 也不变，那么它上面的电流变化率就是一定的。

举个具体的数：我这里加一个 5V，开关一闭合，电感两端电压就等于 5V。如果电感是 $10\ \mu\text{H}$，那电流变化率就是 $\frac{5}{10\ \mu\text{H}}$，也就是 $0.5\ \text{A}/\mu\text{s}$。

我们还是仿真来看。等输出满了，我把开关闭合——你看，这里就有波形了。有了波形我们来测一下：测 $1\ \mu\text{s}$ 的时间，这 $1\ \mu\text{s}$ 过去，波形上是不是就掉了 500mV？500mV 对应的就是 0.5A。所以结论就出来了：**只要电感没饱和，它两端的电压就能通过这个公式算出电流的变化率。**

但反过来——如果电感饱和了，它那个抑制效果、缓慢变化的效果就**完全无效**了。它变成一根导线，电流"唰"一下上升得非常非常快。

那会出什么事？开关很容易被烧掉；这个电感发热会非常严重；同时你的电源也有可能被直接拉死。

> **易错点**：选开关电源电感时，饱和电流必须留足余量。饱和不是"精度差一点"，而是电感直接退化成导线，电流失去限制。

### 电荷泵：三个开关、一个电容搞定升压

电荷泵这种电源，既能做升压，也能产生负压。它的工作原理其实更简单。

还是假设有个 5V 电源，后级我想要 10V，怎么办？我们用两个电容（准确说是一个储电容加一组开关）来实现。

先加两个开关，给一个电容充电。A、B 两个开关闭合，这个电容就被充到 5V。充完之后把这两个开关断开。接着，我在电容底端再加多一个开关 C。

C 一闭合，如果以其中一点作为参考点，这一点是 5V。刚才说的 A、B 闭合时，我们已经把这个电容充到了 5V。现在 C 一闭合，底端变成了 5V——而电容两端的电压**不能突变**，那顶端的电压是不是就变成 10V 了？

顶端变成 10V 之后，如果在这一边直接带一个负载，比如带到 GND，这个负载是不是就得到 10V 了？三个开关加一个电容，升压过程就搞定了。

但是，**这个升压结果不能直接用**。

问题在于：电容是不是需要持续充电？它要持续充电，就得把 C 断开、把 A、B 合上。而 A、B 一闭合，负载上的电压就从 10V 掉到了 5V。等 C 再次闭合，才又回到 10V。

这就有个很扯淡的问题：我们负载本来要求的额定工作电压是 10V，结果在电容充电的过程中它电压会往下掉。往下掉肯定就不正常了——我们总不能跟负载说"电容在充电的时候你先别工作，等我充满了你再继续"，这不可能。

> **提示**：凡是用"电容两端电压不能突变"造出来的电压，中间都必然夹着一次切换动作。凡是切换，就是电压塌陷的来源。

解决办法也很简单：**加一个二极管，再加一个电容**，然后再去给负载供电。

这个电路的作用，和我们前面讲的 Boost 续流二极管非常相似。有了它之后：A、B 闭合，电容充到 5V；A、B 断开，C 闭合，这里出现 10V，电源就通过这条路径给输出电容充电。经过多个周期，它每个周期高一点、高一点、高一点，最终上升到一个 10V 左右的电压。

当然，这里会有一个二极管压降——比如它实际上升到 9.7V 就停住了。

升到 9.7V 之后，假如这时候带载，一带载，当电容在储能的时候，电压会往下掉一点点。只要电容储能的速度足够快，是不是在每一个开关周期里，都会给电容提供一部分能量？掉下去一点点，很快又上来；掉下去一点点，很快又上来。

我们也仿真看看：把电感都删掉，只需要几个开关；电容加大到 100 微法；先不加二极管，直接带一个 100 欧姆的负载，拿示波器看这一点的电压。

一点仿真：还没开始充电的时候，输出等于零。开始充电，这里变成 5V；然后再切换，它变成 10V，慢慢往下掉。我再充电，它又变 5V；我再释放，又变 10V，又慢慢往下降。

这就清楚地看到：它确实能升到 10V，但它就是在开关充电的时候往下掉。所以我们给它加一个二极管，再加一个电容。

这时候再仿真：先开关几次，把电压充到 9 点多伏。只要不停地开关，你就可以看到输出约等于 9V 多，一直在跳变。这就是自举升压——电荷泵升压的基本工作原理。

### 电荷泵换个接法，还能造出负压

我们来看一下如何用电荷泵产生负压。还是假设一个 5V 电源，先用两个开关（还是叫 A 和 B）给电容充电。

A、B 一闭合，电容就充到一个**上正下负**的 5V。充完之后一样把这两个开关断开。

升压的时候，我们是加一个 C 开关到电容的**底端**；现在想产生负压，反过来——只需要在 GND 那一支加多一个开关，接到电容的**顶端**就可以了。

A、B 闭合的时候，电容上充到的是上正下负 5V，相当于上极板比下极板高 5V。突然之间 C 这个开关"啪"闭合了，是不是意味着**下极板这一点**的电位就变成零了？它变成零，而这一点比零还要小 5V——那上极板是不是就变成 $-5\text{V}$ 了？

所以负压也就这么出来了。

产生负压之后，跟升压一样，**不能直接给负载供电**，因为开关在切换的过程中，电位会发生变化。解决办法也一样：在这儿加一个二极管，再加一个电容，然后在这儿给负载供电。

这样我们就能得到一个约等于 $-5\text{V}$ 的电压去给负载供电了。仿真验证：把开关切换一下，二极管换方向，地挪到上面，然后测这一点的电压。点仿真，再切一下开关，就出现一个负压；不停地切，你就能看到一个负 4 点多伏的电压。

> **结论**：电荷泵的升压与负压，是同一个电路的两种接法。A、B 负责给储电容充上固定的 5V 压差，第三个开关负责把其中一端"顶"到 5V（得正压）或"钉"到 GND（得负压），二极管 + 输出电容负责把切换时的塌陷挡在负载之外。

### 学到这里，就得动手了

同学们你好。看到这一节，说明你已经把前面那些基础元器件、以及常见的电路原理都过了一遍。

但这里我要说一句实在话：**学电路设计，如果你只是停留在理论学习阶段而不去动手，实际上是很难把知识点掌握好的。** 而且只要你不动手，你会慢慢发现前面学到的东西正在一点点被遗忘。所以我们必须趁热打铁，进入理论实操阶段。

我们接下来的第一个实战项目，就是**纯硬件循迹小车**。

循迹小车，学过程序的同学应该非常熟悉——基本上是每一个学嵌入式软件的同学必做的项目。因为看我们这门课的同学基本上都是学硬件的，而且考虑到大家可能对单片机不了解，所以我们第一个项目就做一个**不需要单片机编程**的循迹小车。

在这个项目里，我们会手把手带你从循迹小车的工作原理，一直带到原理图设计。设计原理图的时候，自然就会涉及对应参数的计算、元器件的选型、整个原理图的绘制；最后到 PCB 设计，我们都会完整过一遍。

（PCB 库这些资料，需要的同学直接联系助教，或者私信拿就行。）

那有没有更难的开源项目？有。大家可以去主页切到粉丝视角，往下滑，里面有我以前更新过的全国大学生电子设计大赛电赛特训营——每一个特训营，对应的就是一个实战项目。讲法是一样的：原理分析 → 原理图设计 → PCB 设计 → 实物调试，从 0 到 1 完整过一遍。

以最新一期电赛特训营为例，一共四集：第一集做原理分析（比如线缆长度测试这个项目，第一节课就讲原理分析）；分析结束，第二集开始画电路图，手把手算参数、绘原理图，并且**用仿真软件辅助验证设计方案是否合理**；画完原理图，第三步带大家画 PCB；第四步开始用实物调试——直接拿样机调参数，实时演示不同参数下波形是什么效果，同时说明波形异常了该怎么解决。

这些项目，如果你还是一名在校大学生，我建议有时间尽量都去做一遍。做完之后，对你后面参加竞赛、学校的项目，甚至出去实习，都会非常有帮助。

再说说更进阶的方向。进阶课程里还有无刷电机、分立的 Boost、分立的 Buck，难度都非常大；比如反激开关电源，我们做了两个版本——一个是用 UC3842 实现的，一个是全用分立元器件搭出来的。

这里经常有同学问：现在做电路设计，集成芯片已经非常多了，为什么还要用分立元器件去搭芯片的内部框架？

原因很简单：**用分立器件去搭芯片内部框架，更重要的是让我们深入了解芯片内部的工作原理。** 你做了这些内容，以后再用芯片，会发现一眼看过去就知道它内部的工作方案是什么。这样你在设计电路的时候用芯片就会更灵活；出了问题，排查方向也极其明确，因为你一眼就知道它可能是哪里出了问题。

而且用分立元器件搭开关电源，也不只是为了理解内部原理这么简单——更重要的是要讲**开关电源控制环路的设计方法**。我们常说开关电源是一个负反馈系统，其中就涉及环路控制的补偿问题。用这些分立器件，我们就可以非常直观地讲解它的环路控制过程；通过里面的一些零极点的补偿，也能非常直观地看到每一个补偿器件在电路中到底起了什么作用。这里面涉及到的知识点，是非常深入的。

除了开关电源，还有直流稳压电源、负载仪，还有微流控医疗这一类的项目——微流控这些东西，基本上只有研究生阶段才会接触到。

废话不多说，趁热打铁，我们立刻开始第一个实战项目。在这里也提前预祝大家，尽早进阶成为一名高级硬件工程师。

### 纯硬件循迹小车：靠差速拐弯

先来看一下这台小车的基本样子。它后面有一块场地，我们把小车打开，往场地上一扔——循迹小车自然而然就会跟着那条线一直跑。顾名思义，这就是循迹。

它的原理其实很简单，我们直接拿实物来看。

**核心就是一个差速原理。** 板子底部有两对红外，每一对里，一个是用 LED 发射红外光的，一个是用红外接收管接收红外光的。两对红外一起发射、一起接收，起到的作用就一件事：**检测黑线**。

我们拿一个镊子当成一根黑线来演示。

当小车循着黑线走的时候，两边的红外发射管所对应的区域都是**白色区域**。白色可以反射所有光谱的光，所以此时红外光从下面对准纸面射出去，因为纸面是白的，就反射回来，被红外接收管接收到。接收管一收到，自然而然就产生一个控制信号，去控制电机转动。因为两个红外发射管打出去的都是白区，两个接收管都有信号，所以两个车轮一起转，小车就一直往前走。

它一直走，走到拐弯处。比如走到这里，底部的黑线碰到了左边这个红外发射管。因为是黑色，**黑色可以吸收所有的光**，左边发射管发出去的红外光就反射不回来了。左边的发射管一旦进入黑色区域，左边的接收管就收不到信号。这时候左轮就停。

左边一停，右边的发射管还没进入黑色区域，右边的接收管照样收得到红外，右轮继续转。一转动，左边不转右边转，这是不是就有了差速？一差速就实现拐弯，一拐就拐到线对应的方向上去。拐到一定角度之后，左边的红外管又会脱离黑色区域，是不是又可以继续前进了？这样就实现了循迹。

> **易错点**：这里两个红外管天然是互补的一对——只要有一只进黑区，两只的输出就不一样，小车就能分辨出"线往哪边偏"。所以传感器不需要做任何调制或算法，纯粹靠"白反射、黑吸收"这条物理规律就够了。

一句话总结：循迹小车就是用红外光识别黑线，然后根据检测结果去控制两个车轮是否要转动。所以它的工作原理并不难。

### 动手第一课：从空白工程到电机驱动原理图

整个项目分四个步骤：第一步，简单说一下工作原理（刚刚已经讲完了）；第二步，进入纯硬件循迹小车的原理图设计，会手把手根据刚刚说的原理，一步一步把整个完整电路画出来；第三步，简单带大家做一下 PCB 设计，把板子做出来；第四步，完成对应的实物调试。

讲完原理，接下来就进入电路设计阶段。原有的项目我们就不管了，重新新建一个项目，一步一步把对应的电路画出来。

#### 先把工程、原理图和库准备好

先新建一个项目。在 AD 里是这样操作的：点"文件"→"新建"，这里有一个"项目"，点一下。在这里可以命个名，小车就命名为 `car`；下面对应的是路径，自己新建一个路径就可以了。选择文件夹之后，点击新建。

点击新建之后，上面的项目树里就多了一个新的项目文件夹。这个文件夹只是一个框架——接着我们要先给它添加一个原理图：点击 `Car-1` 右键 → "添加新的到工程" → 在这里添加一个原理图。

添加原理图之后，在里面还不能直接画，还要给它添加一些**原理图封装**进来。原理图封装简单来说，就像原理图里的小工具：把整张原理图看成一栋房子，画房子的时候上面有很多小零件，这些小零件是要有一个库的，就叫**原理图库**。所以第一步要先把原理图库添加进来：这里面直接点右键，下面有一个"添加已有文档到工程"。

进来之后，这里面已经提前画好了一些 PCB 的原理图库和 PCB 库。如果需要，找助教或者直接找我就行。

添加进来之后，原理图也要保存一下——新建的原理图还没有保存，在这里把它保存好。保存完，就可以开始画电路了。

#### 把电机驱动电路摆上去

按照刚刚说的，小车的目的很单纯：这里有一个红外管，用它去检测小车到底到了黑线区域没有——到了就让电机停，没到就让电机动。所以整个循迹小车的工作逻辑就两步：**检测黑线**，然后**根据黑线去控制电机**。

根据这两部分，就可以一步一步画原理图了。我们先把电机的控制电路画出来。

电机控制电路的原理很简单：因为我们这个小车里，电机是**单向工作**的，不需要双方向工作，所以控制一个电机旋转，只需要控制它是否接电就行了——拿一个开关去控制电机的电流，开关闭合电机动，不闭合电机不动。在电路里，三极管和 MOS 管都可以，这里我们用三极管举例：画一个三极管，再搞一个电机，这就是最简单的电机控制电路。

先把三极管画上去。三极管用一个 NPN 的就行，NPN 里有个比较经典的型号就是 **8050**，所以直接把 8050 拉下来。操作是：点右键 →"组件"→ 选择对应的原理图库，选我们自己的库；在这里直接搜索 `SS`，就会出现很多 SS 相关的元器件，其中 `SS8050` 对应的就是一个 8050 的三极管。

三极管底部是有封装信息的。点开之后你会发现，有一些元器件里面挂了很多个封装。

这里要做一个选择：**因为板子是直接贴在车子的结构上面的，所以不能用插件的元器件，要用贴片型的。** 贴片型是什么意思？它在焊接的时候是不需要穿孔的。插件元器件简单来说就是有引脚的，焊接的时候要像 LED 一样插过去焊。如果这里所有元器件都用插件，就相当于板子不能平放在车子的表面上了——它会被插件的针给顶起来。所以我们直接选贴片式的封装。

放下来之后，上面是不是要控制一个电机？电机在这里不用画在原理图上——因为电机是要通过两根线焊接在板子上的，板子上只需要给它留两个孔，去焊电机的两根电源线就可以了。

所以在画原理图的时候，给它加两个洞就行。这两个洞是什么？就是**排针**。排针在原理图里一般就是 `Header`，`Header 2` 就代表这里有两个洞。往下划能看到它的封装就是两个洞，这时候直接把它拉下来就行了——看到这个东西，你就知道它是用来接电机的。

电机上面直接接电源：点右键 →"放置电源端口"，比如电源命名成 `Vin`，然后把 `Vin` 这里连起来；三极管的底部放一个 `GND` 端口。

这样放完，一个最简单的电机开关控制电路就画好了。

```text
              Motor
        ┌────(     )────┐
        │               │
        │               │
   Vin ─┴──────┐        │
               │        │
             C │      [Header 2]
               │        │
               └────┬───┘
                    │ E
              Q1    │
          (NPN 8050)│
                    │
                   GND
```

读图：`Motor` 是要焊在 `Header 2` 两根线上的实物，原理图上并不画它，只留两个孔；三极管 `Q1`（NPN 8050）串在电机回路里当开关用——基极给电流通路打开，电机转；基极不给电，电机停。它就是"单方向电机只需要控制是否接电"这句话在原理图上的样子。

## 一颗红外管、一只比较器，把小车按在黑线上
> 对应块：BLK23 | 覆盖分集：P109-P114 | 块标题（分集名）：《104.纯硬件寻迹小车_黑线检测原理》

开关电路画完之后，接下来的活就很明确了：一是画电机的控制电路，二是画检测黑线的电路。这两件事看上去一个管输出、一个管输入，中间隔着十万八千里，实际上它们共用同一个关键器件——红外接收二极管。整个纯硬件循迹小车的思路，就这么一根线串起来了。

我们不从电路图开始，先把这个器件的脾气摸清楚。因为后面所有的电阻取值、阈值设定，都建立在它的脾气上。

### 红外接收二极管是一个受光强控制的电流源

红外接收二极管，大家可以简单把它理解成一个**跟光的强度有关的电流源**。

它平时没有接收到任何红外光的时候，反向电流非常非常小，小到你完全可以先忽略掉；当它接收到红外光的时候，就可以认为它反向导通了，会有一个反向的光电流。

> **易错点**：它虽然长得是个二极管，但工作的时候是**反着接**的。普通二极管顺着用，红外接收二极管反过来用。这一点画原理图的时候一定要盯住，接反了整条链路都不成立。

关键规律只有一条：**接收到的红外光越强，流过它的反向电流就越大**。

现在给它接一个电阻：电阻上端接 5V，下端接 GND，中间的这个点我们称之为 $V_R$。

$$V_R = 5\text{V} - I_R \times R$$

推导一下就很有意思。没有红外光的时候，$I_R$ 约等于 0（实际是纳安、皮安或者微安级别的微弱电流，看具体型号，这里直接忽略），压降就是 0，于是 $V_R = 5\text{V}$。一旦接收到红外光，$I_R$ 变大，$5\text{V}$ 减去一个不为零的压降，$V_R$ 必然掉下来。

所以规律是：**红外光越强，$V_R$ 越低。**

> **结论**：电压和光强是一个反比关系。这个"反"字是后面所有电路的出发点。

### 黑白两色在电压上被拉成了两个点

我们把实物摆上来讲。一对红外管，一颗是发射管，一颗是接收管。小车走到某处时，发射管的红外光正好打在黑色胶纸上——黑色把所有光都吸收掉了，于是走到这个位置时接收管收不到红外光；在其它位置，接收管一直是有光的。

带着这个物理图像，我们再用公式算一遍。取 $R = 1\text{k}\Omega$：

**白色区域**（收到了红外光），假设 $I_R = 1\text{mA}$：

$$V_R = 5\text{V} - 1\text{mA} \times 1\text{k}\Omega = 5\text{V} - 1\text{V} = 4\text{V}$$

**黑色区域**（光被吸收，电流极小），假设 $I_R = 1\mu\text{A}$：

$$V_R = 5\text{V} - 1\mu\text{A} \times 1\text{k}\Omega = 5\text{V} - 1\text{mV} = 4.999\text{V}$$

差别出来了：白线约 4V，黑线约 4.999V。一个模拟量变成了两个可分辨的档位，这就是我们能判断"车有没有压线"的全部依据。

顺带一提，白线区域那个 4V 是可以调的。从公式一眼就能看出来，$R$ 取得越大，白线时掉下去的压降越多，$V_R$ 就越低。所以**调电阻 $R$ 就是在调灵敏度**。

```text
            5V
             │
          [R] 1kΩ     ← 调 R 就是调灵敏度
             │
   V_R ──────┼──────────► 送比较器反相端
             │
        ┌────┴────┐
        │ 红外接收 │  ← 反接使用
        │  二极管  │
        └────┬────┘
             │
            GND
```

读图：这是一个典型的"光强变电压"转换级。光照越强，电流越大，$R$ 上的压降越大，取样点电压越低。

### 加一颗比较器，把模拟量变成开关量

知道了电压区别，接下来就是用它去控制电机。这件事只需要加一个比较器进来。

怎么接法？参考电压 $V_+$ 接一个 4.5V，红外电路的信号 $V_R$ 直接接到反相端 $V_-$。

```text
   红外信号 V_R ────────► (−)
                          │  ┌──────────┐
   滑动变阻器中点 ──────► (+) │  LM393   │ ───► V_out
                          │  │  比较器  │
                          └──└──────────┘
```

行为就很清楚了：

- **黑色区域**：$V_- = 5\text{V}$，$V_+ = 4.5\text{V}$，$V_- > V_+$，输出**低电平**；
- **白色区域**：$V_- = 4\text{V}$，$V_+ = 4.5\text{V}$，$V_- < V_+$，输出**高电平**。

| 区域 | 光照 | $I_R$ | $V_R$ | $V_-$ 与 $V_+$ | $V_{out}$ | 三极管 | 电机 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 白线 | 收到红外光 | $1\text{mA}$ | $4\text{V}$ | $V_- < V_+$ | 高电平 | 导通 | 转 |
| 黑线 | 光被吸收 | $1\mu\text{A}$ | $4.999\text{V}$ | $V_- > V_+$ | 低电平 | 截止 | 停 |

把 $V_{out}$ 接到三极管的基极，逻辑就连上了：黑线时输出低，三极管不导通，电机不转，处于停止状态；白线时输出高，基极有电流，电机转起来。

> **结论**：**红外停在黑线上，电机停；停在白线上，电机走。**

这就是前面推导的完整链路：

```text
 红外接收管 ──► 取样电阻 ──► 比较器 ──► 三极管 ──► 电机
   (光强)       (变电压)    (变开关量)   (变电流)
```

### 回到实物上，这个逻辑就是循迹

我们前面演示的实物，用的就是这套逻辑。车跟着黑线走的时候，两边的红外接收管都在收光，于是两个电机一起往前走。走着走着走到某处，左边的接收管突然收不到红外了——因为进了黑色区域，黑色把这一侧发射管打出来的红外光全吸走了。于是左边轮子停，右边还在转，车就拐过去了。一拐弯，循迹不就实现了。

到这里，"检测黑线"和"控制电机"这两件看似不相干的事，被一根逻辑线拧在了一起。

按照这个逻辑，我们可以得到一个非常简单的检测黑线并控制电机的基本逻辑图。它就是我们设计电路的**系统框图**——框图是设计电路的核心思维，接下来要做的事，就是把这个框图逐个方框地画进原理图里。

### 从框图到原理图：一步一步画

往原理图里落地的顺序，是从左往右。

**第一步，画红外接收二极管。** 它属于光敏二极管，直接用光敏二极管的封装来画。点这里之后往下滑，会看到底部一堆封装，里面有红外光敏二极管 HWQ 黑色，插件型的。但你刚才点到的是贴片的，不能用，所以要换成有两个洞的那个——那个才是适合我们项目的。选对了再拖出来，得到的才是一颗插件型的红外接收二极管。

**接上取样电阻。** 选 RES，贴片电阻底部同样一大堆封装。初学者建议直接用 **0805**，焊盘大，好焊接。

**定电压。** $V_{in}$ 先按 5V 来，连上去，底部接 GND。记住刚才那条：红外接收二极管一定反着接。

**第二步，画比较器。** 常见的比较器型号是 LM393，所以要把运放的型号换成 LM393。

这里有个要点值得停下来：为什么 LM358 可以直接改名成 LM393 用？原因是**这两颗芯片的封装可以共用**。实物上买来的这颗八个引脚的芯片就是 LM393；买一颗 LM358 回来，芯片的引脚定义一模一样。所以直接改型号是安全的。

**第三步，接供电和两路输入。** LM393 也需要供电，给它接 5V 和 VCC。红外接收二极管的信号按前面推导的接**反相端**。$V_+$ 接参考电压——这里必须接一个**滑动变阻器**，一端接 5V，一端接 GND，中间抽出来，拧动就能在 0~5V 之间连续调整。

> **易错点**：为什么不能直接用两个电阻分压出一个 4.5V？前面分析的时候我们"假设"白线区反向电流是 1mA，但实际上它到底是不是 1mA，你根本不知道。你要是图省事搞一个 500Ω、一个 4.5kΩ 分出个漂亮的 4.5V，装上去就会发现没用——因为实际电流可能根本不是 1mA，阈值一开始就偏了。
>
> **结论**：画电路不能理所当然。一顿分析分析得再有味道，落到板子上都必须保证阈值是**可调**的。

到这里，检测电路和黑线判断电路就画好了。接下来用比较器去驱动后级的电机部分。

### LM393 是 OC 输出，必须加上拉电阻

前面基础课程里讲过这个知识点，这里再强调一次：比较器有的是 OC 输出，有的是 OD 输出，有的是推挽输出，**LM393 是 OC 输出**。

OC 是什么概念，就是输出端内部挂了一个三极管到地，没有上拉到电源。用它的时候**必须加一个上拉电阻**，不然 OUT 上根本不存在任何高电平。

加上拉电阻之后，再预留一个基极电阻，方便后面调试，然后接到三极管的基极。这样就实现了用 LM393 控制三极管导通。

> **提示**：画原理图时，按住键盘的 **Shift** 再用鼠标左键点击元器件一拉，就能拉出一个新的。电阻能这么拉，三极管也能这么拉。这个快捷键在后面复制整块电路的时候还要再用一次。

到这里，黑线检测加电机控制的最初步电路就完成了。

### 电机这一侧：续流二极管是保命的

最初的电路只是能跑，真要上板子，得改。先看电机这一部分。

前面课程里说过，电机本质是一个**电感模型**。既然是电感模型，就有一个很严重的问题：**当回路中的阻抗发生突变时，会产生很高的感应电动势。**

具体到什么程度？三极管一开始导通、又突然断开的时候，电机两端会产生一个高压。高压几千伏可能产生不了，但产生一两百伏、或者几十到一百伏左右，是很轻松的事。所以必须给电机加一个**续流回路**，把电流的突变过程接住。

续流回路怎么加？**直接加一个二极管就行了。**

```text
          +5V ──────────────┐
                            │
                          ┌─┴─┐
   V_out ──[R_B]─────────┤ Q │  M（电机）
                          └─┬─┘──┬──┐
                            │    │  │
                            └─|◄─┘  │
                               D     │
                          (续流二极管)
```

读图：Q 导通时电流从 5V 经 Q 流向电机；Q 突然截止时，电机电感上的电流不能突变，会自己产生一个上正下负的感应电动势，此时二极管 D 导通，给电流提供了另一条回路，电压被钳位在二极管导通压降附近，MOSFET 两端就不会被击穿。

这个二极管的选型**一定要上心**。因为在开关断开的一瞬间，电机的电流会全部流过它。当然，流过只是一瞬间的事，但既然有电流流过，**它的导通电流就必须大于电机的正常工作电流**。

买的那种 TT 电机，工作电流大约 500mA，负载重一点会更大，但正常行驶就是 500mA 左右。而且 500mA 瞬间就流完了。所以——**直接选一个普通的 1N4007 之类的二极管就够了**。

如果你的电机是大功率电机，最大电流能到 10A，那续流二极管就必须换成相对大功率的型号。这一条没有中间地带。

### 基极电阻要算，不能随手取 1k

二极管搞定，往下就是三极管。三极管要控制电机工作，流过它的电流也就是电机的工作电流，所以它也得扛得住这么大电流。SS8050 查一下资料就知道它最大的导通电流 $I_C$ 是够的，只是我们这种封装小、散热差，工作时可能发热到五六十度，不过这种小项目也就无所谓了。

接下来是这两个电阻的取值。这里我要专门停一下，因为网上大神老爱说"这个电阻随便取个 1k、10k 就行了"。

这话在负载电流很小的时候没错。几毫安、十几毫安那种，随便取 1k、取 10k、甚至取 50k，问题都不大。但你要是去驱动电机这种电流稍微大一点的负载，就**一定要把 $R_B$ 算清楚**。

为什么？回到讲三极管时那个公式：

$$I_B \times \beta = I_C$$

这个公式只在三极管工作于**放大区**时才成立。而我们这里三极管是做开关用的，要让它进入**饱和导通**状态，条件是：

$$\beta \times I_B > I_C$$

只要满足这个不等式，它就是一个确定的饱和态。注意是"大于"，不是"等于"——这条不等式就是后面所有计算的出发点。

算一下：$I_C$ 约等于电机电流 500mA，这是已知的。假设三极管电流放大倍数 $\beta = 100$，那么：

$$I_B = \frac{500\text{mA}}{100} = 5\text{mA}$$

得到 5mA，再算总电阻 $R_{\text{总}}$。因为这里是两个电阻串联，要从 5V 里减去三极管导通压降 $V_{BE} = 0.7\text{V}$，再除以回路电流：

$$R_{\text{总}} = \frac{5\text{V} - 0.7\text{V}}{5\text{mA}} = \frac{4.3\text{V}}{5\text{mA}} = 0.86\text{k}\Omega$$

这就是这两个电阻的总阻值。

### 为什么这个电阻不能取 0Ω

算出来是 0.86kΩ，那就该在这两个电阻里分配。有一个同学一定会想：那我干脆一个取 0Ω，一个取 820Ω，行不行？

答案是**不行**。我们回到 LM393 的内部结构上来想这件事。

前面说过 LM393 是 OC 输出。它的输出内部其实就相当于一个三极管，输出低电平时就是内部这个三极管导通了，把输出点拉到地。

如果你把这两个电阻中的一个直接取成 0Ω，会发生什么？相当于这个回路被那个内部三极管**直接短路**了。5V 通过上拉电阻直接灌进 LM393 内部的三极管里，LM393 可能就直接烧掉。

所以正确的分配是：**一个取 0Ω，一个取 820Ω**。这样在我这里输出低电平的时候，流过来的电流约等于 5mA 稍多一点。对 LM393 来说这压根不算事——一般来说，比较器也好运放也好，输出电流和吸收电流都能达到五六十毫安，吸收 5mA 一般不会有问题。而且输出断开的时候，电流就从这个路径走了，它也照样正常工作。

> **易错点**：这里千万不要图省事把这两个电阻**直接短接**。这一条支路最好**预留一个电阻**在电路里，哪怕值取成 0，它在原理图上也是一颗实打实的器件，后期要留位置调试的。

至于为什么非要预留这一颗——因为 820Ω 是按 $\beta = 100$ 算出来的，可实际上很多三极管的电流放大倍数比 100 大得多，可能是 200，甚至 300。

所以正确做法是：初步算出一个值，焊上去之后**必须实测**。测到已经完全饱和导通了，就尝试把电阻再放大一点点，再测一下是不是还饱和；还饱和就继续放大。因为对整个电路来说，**电阻越大，静态功耗越小**。算出来只是起点，后期还要进一步调整。

这两个电阻取完，上拉电阻初步取 1k，滑动变阻器初步取 10k，就可以了。

### 电源不是理想电源：每一处都要电容

画完功能，剩下最后一件事是电源。

VCC 这里是要加电容的，尤其是电机这一路。电机工作过程中会有比较大的电流，而且直流有刷电机在工作的时候还会产生一些高频噪声。所以我们**首先在这一部分给它并联上一个小电容**，用来改善直流有刷电机工作过程中产生的高脉冲噪声。

$V_{in}$ 那一部分也要加电容：先加一个**储能电容**，直接用电解电容做；然后再加一个 **100nF**，专门滤除高频噪声。

```text
   VIN ──┬────────────── 送往取样电阻与 LM393 供电
         │
        ─┴─  储能电容（电解）
         │
        ─┴─  100nF（滤高频）
         │
        GND
```

这里有两种画法都行：一种是老老实实在这一侧把电容都画上；另一种是直接拉一根线连过去，效果完全一样，看个人怎么方便。

对应的，芯片那边的 5V 也要加电容，比较器供电的 5V 要滤波，共用的那一侧 GND 同样要。

> **结论**：**所有的元器件在实际工作时，电源都不是理想电源，它一定带噪声。** 所以设计电路一定要有意识：凡是电源引脚，一律考虑加电容做滤波。这不是可选项，是基本功。

甚至那个电阻上面也可以并一个很小的电容，比如 **100pF**，用来滤除红外接收二极管接收到的一些高频噪声。

到这一步，一个相对比较完善的电机驱动电路就出来了。

### 这个电容为什么能压住电机的噪声

这里单独解释一下，因为很多人觉得"电容就是拿来储能用的"，其实它在这个位置干的是两件事。

第一件事，是**时间差**。实际安装的时候，6V 的电源可能要经过一段很长的走线才接到电池。当开关突然闭合的时候，外部给这一边提供电流实际上是有一定时间差的，它需要反应时间。

怎么办？画 PCB 的时候，**把电容放在电机的安装端口旁边**。这样电容就能在开关闭合一瞬间优先给电机提供一定的能量，把它顶上去。

第二件事，电机产生感应电动势或者噪声的时候，这个近在咫尺的电容又能立刻把这些噪声压下来。

所以这一个电容，既能在瞬态提供大电流防止电压跌落，又能滤掉电机产生的高频干扰。

### 一颗双通道比较器，两个电机

最后还有一个收尾的动作。我们这个实物里有两部分——两个电机都要独立控制，所以得把刚才整块电路复制一份。

怎么做？全选，按住键盘的 Shift，一拉，就搞定了。

> **提示**：对于模块化的电路，或者说一模一样重复的电路，你只需要把其中一部分画完，然后直接 copy 过来就行，没必要手画第二遍。

复制过来之后有一个**必须注意**的地方：LM393 是**双通道**的比较器。

买一颗比较器回来数引脚，1、2、3、4、5、6、7、8，一共八个。其中 **1、2、3 对应其中一个比较器的三个引脚，5、6、7 又是另一个比较器的三个引脚，4 和 8 是电源引脚**。

也就是说，你买一颗比较器回来，它里面就已经**包含了两颗比较器**。

```text
        ┌──────────────────────────────┐
        │           LM393              │
        │                              │
        │  1 ──┐                ┌── 6  │
        │  2 ──┼── 比较器 A ────┼── 5  │  比较器 B
        │  3 ──┘                └── 7  │
        │                              │
        │  4 ────── 电源引脚 ───── 8   │
        └──────────────────────────────┘
```

读图：所以你复制出来的那份电路，根本不需要再买第二颗芯片——它和原来的那一路**就在同一颗芯片上**。我们这台实物上有两个电机，要用两个比较器，但我们只有一颗芯片，原因就在这儿。

既然两个通道是共用电源的，那么复制过来那一路多画的 5V 就可以删掉了。

但这里有个陷阱：**删 5V 的时候，不要把上拉电阻也一起删掉**。上拉电阻是每一路都必须的。

这样，第二个电机的驱动就完成了。到这里，控制电机以及检测黑线的整体电路，就算彻底画完了。

### 画完这一堆电路，还剩 20% 是电源

接收部分画完了，比较器画完了，电机驱动也画完了。我们这么往原理图上一看，会发现整个电路已经完成了 80%，对不对？

剩下的 20% 是什么？就是我们这里的电源。

在这张图里往上看，电源主要有两路：一路 5V，一路 6V。当然我们这里还可以再加多一个 3.3V。为什么要故意多加一个？因为我们等一下要跟大家讲一些例子，我就故意多用几个电源吧。比如说我们这里面的这一个 5V，我们把它删掉，让红外接收管这里用一个 3.3V。

实际上红外接收管这里用一个 5V 也是可以的，但我故意不用——我们这个课程毕竟还是针对完全零基础的同学，该用的东西都尽量跟大家用一下，这样子大家能学到的东西也更多。所以我们在这里就故意再创造一个 3.3V 出来。

大家自己实际画的时候，可以不加这个 3.3V，没关系的，我在这里只是为了跟大家演示一下这些芯片怎么用而已。

这些电路搞定之后，接下来就要把电源画出来。我们画的是三路：输入 6V，往下产生 5V，再由 5V 产生 3.3V。

```text
   电池盒（4 节 5 号电池串联，自带开关）
              │
              │  6V 输入（未稳压）
              ▼
        ┌─────────────┐
        │  6V →  5V   │  分立线性稳压：稳压管 + 三极管
        └──────┬──────┘
               │ 5V
               ▼
        ┌─────────────┐
        │  5V →  3.3V │  1117-3.3
        └──────┬──────┘
               │ 3.3V
               ▼
   信号处理电路：比较器、10k 分压、红外接收管……
```

电源方案我们在前面的课程里也跟大家讲过，常见的降压方案包括开关电源和线性稳压电源，对不对？在我们的电路里面，输入是 6V，出来的 5V 和 3.3V 都是给这些信号处理电路供电的，所以我们在这里就没有必要用开关电源了。这里我们直接用 LDO 就行。

### 一颗 LM7805 为什么摆上去就翻车

我们有一些同学可能想着：这里 6V 过来，那我直接就用一个常见的 LM7805，对吧？

LM7805 就是一个非常非常经典的线性稳压芯片，可以直接把输入电压降成一个 5V。但是用在这里有一个坑，这个坑我必须专门拿出来讲一遍：

> **易错点**：所有线性稳压芯片都有一个关键参数，叫**最小压差**，也叫最小稳压压差（英文参数名 `Dropout Voltage`）。忽略它，电路画得再漂亮也是错的。

这个最小稳压压差是什么意思？意思是，你的 LM7805 想要输出一个 5V，前提条件是你的输入一定要大于它的最小稳压压差。常见的普通稳压芯片，最小压差有可能是 0.3V，也有可能是 0.7V，也有可能等于 1.4V，有的甚至更高。

具体去哪儿查？去查你选的那颗线性稳压芯片的数据手册，看它的 `Dropout Voltage` 这一项。（这里不方便放数据手册，大家自己去找一份查一下就行。）像我们这些 AMS1117 的 -3.3、-5.0 等型号，它们的最小稳压压差通常来说都是会大于 1V 的。

> **结论**：6V 的电池输入进来，它可能就得不到一个 5V 的电压了。

我们把它列成表算一遍就很直观。假设最小压差分别取下面几个值，看输出 5V 需要的最低输入是多少，再看 6V 灌进去实际能出多少：

| 芯片最小压差 | 输出 5V 所需的最低输入 | 6V 电池灌进来的实际输出 |
| --- | --- | --- |
| 0.3V（低压差型） | 5.3V | 5.0V，可用 |
| 0.7V | 5.7V | 5.0V，可用 |
| 1.2V | 6.2V | 4.8V，差一口气 |
| 1.5V | 6.5V | 4.8V，不够 |

道理就是这么简单：假设它的最小压差等于 1.5V，那就意味着要想输出 5V，你的最小输入电压应该要达到 6.5V；如果是 1.2V，那要想输出 5V，最小输入电压应该是 6.2V。否则的话，你这里输入一个 6V 进来，它的输出会只有 4.8V，对不对？

所以这里的对策只有两条路：要么你去选那种最小稳压压差比较小的比如说只有 0.3V、0.5V 的芯片，但选那一种的话价格一般会比较高一点点；既然选不到，我就干脆不选它了。怎么办呢？我们就可以尝试用分立元器件去搭。

我们在前面不是跟大家讲过分立的线性稳压电源的模型吗？我们在这里可以跟大家简单画一下。

### 用稳压管和三极管搭一个 5V

就是下面这样子：

```text
      6V 输入
        │
        ├──── R（限流电阻）────┬────────────┐
        │                      │            │  B
        │                    ┌─┴─┐          │
        │                    │DZ │ 5.6V     │   │
        │                    └┬─┘          │   ▼
        │                     │        ┌────┴────┐
        │                     └────────┤   Q1    │
        │                              │  (NPN)  │
        │                              └────┬────┘
       GND ────────────────────────────────┤  C
                                               │
                                               └──────→ 5V 输出
   Q1 发射极 E 接地；集电极 C 就是 5V 输出端
```

原理就这么一句话：稳压管一旦导通，它两端的电压就被钉死在 5.6V；三极管工作在放大区与饱和区的临界点，也就是预饱和区，是一个跟随器（射极跟随器），输出比基极低一个 $V_{be}$。所以我们让这一点变成 5.6V，减去一个三极管的 $V_{be}$ 的压降，这里是不是就得到一个约等于 5V 左右的电压了，对不对？

所以我们利用这种分立的线性稳压电源，就可以得到一个很简单的 5V 电压了。

具体的器件选择：稳压管大家注意，稳压管是 Z 开头的——Zener 二极管对应的是 Z 开头，你用得多了自然而然就知道了。我们拉过来选一个 5.6V 的稳压管就行了，然后接个地；对应地，我们这里输出就会变成一个 5V 左右的电压了。

得到 5V 之后，再过来我就可以用一个很经典的降压芯片 1117-3.3，这时候我们是不是就可以把 5V 转换成一个 3.3V 了？这一个就是我们对应的电路方案。

> **提示**：这个分立线性稳压的电路，我建议初学者、没有做过任何电路的同学最好去做一下；如果你以前做过电路的话，就没有必要去做，这个电路你做不做都可以。

### 降到 3.3V：交给 1117-3.3

1117-3.3 的用法很简单，端口是很明显的：一个是 IN，两个是 OUT，一个是 GND。

```text
   5V ──┬──────── IN ─────┐
         │                  │
      [ 10μF ]        ┌────┴────┐
         │            │         │
         │            │ 1117-   │
         │            │  3.3    ├── OUT ──┬──→ 3.3V ──┬── [ C ]
         │            │         │              │       │
         │            │         ├── OUT ─┘    [ C ]   GND
         │            │         │              │
         │            └────┬────┘             GND
       GND ─────────────────┴──→ GND
```

两个 OUT 其实只要接其中一个就可以了，不一定两个都接，当然你也可以两个都接。

我们这里面的输入端都要接电容，所以在这里要加几个电容。输入端挂电容是为了什么？是为了让芯片在负载突变的时候还有电可放，不然输出会跟着抖。输出端再挂电容，就是储能兼滤波。

### 把电源电路画到原理图上

接下来我们一起把这个电源电路画出来。

首先先画我们 6V 的输入电压。因为 6V 的电池模型买回来之后，我们看到它是自带有一个开关的，这就意味着电池插进来之后，电池的电压只要插到板子上就好。所以我们也是一样的，在这里要预留两个接口去插我们的输入电压 6V。

6V 进来之后，按照我们刚刚说的，我们就要用分立元器件去产生 5V 的电压：先画 6V 的输入电压接口，然后加一个电阻，然后再加一个稳压管，稳压管是 Z 开头的，我们选一个 5.6V 的，然后接个地——这样输出就会变成一个 5V 左右的电压了。

5V 过来之后，我们还要再加多一个降压芯片，就是 1117-3.3V，拉过来，这里接到 GND。

剩下的电容，我给你算清楚：6V 输入进来，这里我们接一个小电容就可以了，没有必要接大电容，当然这个电容可以取成一个 10μF；这里也接一个 10μF 的电容。然后这一个点的话，我们最好也加一个电容做一下滤波。再输出过来就是到我们 5V 了，5V 这里肯定也要加一些储能电容的，这里接 100nF 就可以了。

剩下的我们只需要把它连起来就搞定了，所以这个电源画起来是很简单的。输出也是一样，搞两个电容挂上去就可以了。这里面的这一个你也可以接上，也可以不接，都可以。

这样的话，我们就可以把这个电源也画好了。整一个电路就全部画完了。

画完之后，在**工具**菜单点击**标注**，选择**静态标注原理图**。点击之后，系统就会自动把里面对应的原理图元器件进行统一编号。

### 电阻取 82Ω 是怎么算出来的

另外，这里面电阻的取值需要计算一下。

首先，稳压管这一点的电压是 5.6V，输入电压是 6V。要想让稳压管稳定工作，我们要计算流过电阻上面的电流 $I$。因为稳压管只要导通，电压就是 5.6V，所以电阻两端的电压差可以认为是恒定的 0.4V。重点就是要评估流过该电阻的电流。

流过电阻的电流主要由两部分组成：第一部分是流过稳压管的电流，第二部分是流过基极的电流 $I_b$。

**第一部分，稳压管的电流。** 稳压管的工作电流，一般来说，当反向导通电流达到 0.5mA 左右时，就已经开始具有相对稳定的电压了。往上的电流范围其实很宽，最大可能达到 20mA 甚至 50mA，这与稳压管的封装和额定功率有关，不同型号的稳压管最大导通电流是不一样的。通常在选取稳压管的稳压电流时，一般取在 1mA 到 10mA 之间即可。简单来说，在正常工作过程中让它流过 1mA 到 10mA 左右的电流就能满足要求。这里可以取一个折中值，按 5mA 左右进行计算。

**第二部分，基极电流。** 流向基极的电流 $I_b$，由于此时三极管工作在放大区与饱和区的临界点，即预饱和区，可以通过公式：

$$I_c = \beta \times I_b$$

来计算 $I_b$。其中 $I_c$ 对应的是后级电路的工作电流。

后级的工作电流实际上非常小，主要包含供给 10k 分压电阻以及比较器的电流。10k 电阻上大约流过 0.5mA 电流，加上其他分支，大概几毫安。就算把所有杂七杂八的功耗都算上，后级电路电流大约在 10mA 左右，上下两路加起来，后级电路最多按 20mA 估算。实际上根本达不到 20mA，这里只是做粗略预估。

> **易错点**：估的时候要往大了估，宁可算出来的电流大一点，也别留余量不够的风险。

如果后级电路最大 $I_c$ 撑死按 20mA 计算：

$$I_c = 20\text{mA}$$

将 20mA 除以 $\beta$（取 100 倍）：

$$I_b = \frac{20\text{mA}}{100} = 0.2\text{mA}$$

可以看到流入基极的 $I_b$ 电流非常小，基本可以忽略不计。因此流过电阻的总电流大致取 5mA 左右即可。

现在电流评估为 5mA，压降为 0.4V，计算 $R_5$ 电阻的阻值：

$$R_5 = \frac{0.4\text{V}}{5\text{mA}} = 0.08\text{k}\Omega = 80\Omega$$

实际取标称阻值 82Ω 左右即可。标称值这一跳大家记住：算出来 80Ω，E24 系列里最接近的是 82Ω，直接往上取。

该电阻流过的电流仅为 5mA 左右，功率很小，封装选择 0805 即可满足要求。到这里，稳压部分的完整电路就确定好了。

> **结论**：一条链路记下来就是——压差 0.4V，电流 5mA，80Ω 取 82Ω，0805 封装。

### 完善原理图：下拉电阻、两个发射管、两颗指示灯

上一节课已经把纯硬件循迹小车的大部分电路初步绘制完成，实际上电路还有一些细节需要更改。

之前已经画完了接收部分、比较器以及电机驱动部分。但是我们回头看一下，电机驱动部分还缺少一个细节。

#### 基极加下拉电阻

三极管基极应该增加一个下拉电阻，用于增强电路工作的稳定性。所以我们在三极管基极位置增加一个下拉电阻。

这一条几乎不用解释，你只要记住：**驱动三极管的基极，永远要有一个把电平拉回默认态的通路**。悬空的基极就是一个天线，什么噪声都往里灌。

#### 补上两个红外发射管

添加下拉电阻后，还需要补上两个红外发射管。

参考实物可知，上面总共有四个光电管，其中两个是红外接收管，两个是红外发射管。所以我们在原有电路基础上，还需要补充两个红外发射管。

这里有一个选型细节：红外发射管的封装要选择**直插封装**，不要选成贴片封装。因为我们采用的是直插方式安装，所以要选择直插元器件封装。供电可以选择 5V 或 3.3V，区别不大，这里我们直接接 5V 供电。

因为总共使用两个红外发射管，所以底部对应的位置同样需要再加一个红外发射管。

#### 加两颗 LED 指示灯

另外，我们可以在电路中增加两个 LED 作为指示灯。当红外接收管接收到红外信号，输出端输出高电平时，LED 点亮，这样能够直观反映电机的工作状态，也方便后续电路的调试。

> **提示**：调试的时候没有指示灯，你得一路拿示波器去点每一个引脚；有指示灯，一眼就知道哪一路已经"看见线"了。这两个灯省下的调试时间，是画这两个灯花的时间的好几倍。

指示灯 LED 选用贴片 0805 封装，限流电阻修改为 1k。底部通道同样增加一颗 LED 指示灯及 1k 限流电阻。

修改完成后，重新对原理图执行一次**工具 → 标注 → 静态标注原理图**，完成整个原理图的最终整理。

### 原理图封装自己画：先加库，先对栅格

原理图完善之后，接下来就要准备绘制 PCB 了。在正式开始 Layout 之前，我们先把原理图封装与 PCB 封装的绘制方法讲掉。对于刚开始学习的同学，可能没有现成的原理图库与 PCB 库，所有器件都需要自行绘制。

首先演示如何绘制原理图库。以 LM393 为例。

**第一步，是在工程中添加原理图库。** 点击工程，选择**添加新的原理图库（Schematic Library）**。添加后，工程列表中就会生成一个新的原理图库文件。

**第二步，调栅格。** 新建的原理图库初始为空白状态，进入编辑界面后，第一步务必要先调整格点（Grid）：点击"视图"，找到"栅格"，设置栅格尺寸，一般习惯设置为 50mil。

这一步非常关键，切记不要随意调整成 20mil 或 30mil。

> **结论**：原理图库元器件引脚的格点，必须与原理图界面中的格点保持一致，或者呈整数倍关系。

为什么这么强调？因为如果原理图库元器件引脚的格点与原理图界面中的格点不一致，在原理图中放置该器件时就会导致引脚无法对齐格点，连线就无法拉成直线。你辛辛苦苦画完了封装，放到原理图里一看，线是斜的，全都歪着。

设置好格点后，开始绘制原理图符号。绘制原理图符号可以直接参考数据手册：打开 LM393 的芯片手册，查看其引脚功能介绍。

### 画引脚：白点朝外，编号对上

点**放置**、点**管脚**。（当然你也可以直接在文字那一栏里点，直接放置管脚。）

点了管脚之后，首先一定要注意——把管脚放大之后就发现，它右边这里是有几个小白点的，对不对？

**这个小白点一定要往外放。** 为什么要往外放呢？因为只有这个小白点它才能够连接我们外部的信号线的。如果说你是把我们白点这样子放的话，等一下画出来这个原理图，我们在外面连这一根线的时候，你会发现它是连不上的。

```text
   对：白点朝外 —— 热点 ● 落在符号外面，信号线直接接得上

            ┌────┐
     ──────┤    ├●─────      ← 热点在右侧，连线拉得直
            └────┘

   错：白点朝内 —— 热点 ● 被压在符号身体里，外部的线根本碰不到它

            ┌────┐
     ──────┤  ●─┤─────      ← 线看着接上了，其实根本没接
            └────┘
```

放到外面之后，接下来我们要编辑引脚信息。

这里面的第一个对应的是我们的引脚编号，这个引脚编号是要跟你的 PCB 封装对应起来的，所以一般来说这个编号我们就是按照这里的引脚编号来设置——比如说你现在画的是第一个引脚，那你在这一就写 1。

然后这里面第二个，它不是有一个 Name（名称）吗？你的 1 脚对应的就是 1OUT，所以在这里就写一个 OUT1 就可以了。

这样的话我们第一个引脚就画好了。当然这第一个引脚的话它还有一些信息，比如说这里面还有引脚的长度，一般你就设个 100mil 就可以了。

第一个引脚画完，我们紧接着就画第二个。画出一个引脚之后，你按 **Tab** 键，它就会把我们这里面的一个编辑信息跳出来。然后这里面第一个因为我们这里画的是第二个引脚了，所以我们这一栏里就写 2；然后这个 Name 的话你就按照我们这里面的数据手册，你看第二个引脚它对应的是 1IN−，对不对？就意味着它是第一个运放的反相输入端，所以我们在这一样的给它写一个名称。

然后 3 也是一样，这里面就变成是 1IN+ 了。第四个的话对应的是 GND，所以我们在这里就写一个 GND 的编号。到第五个，第五个的话就是变成是 IN2+。

这个因为我以前画得比较多，所以我在这里就不需要说去看那个原理图了，我在这里就直接画完，然后等一下再跟大家去对就好了，好吧？因为一点一点跟大家对的话这里要花太多时间，我们在这里快速跟大家过一下就好了。

把八个引脚的对应关系理清楚，画起来就很快：

| 引脚编号 | 名称 | 功能 | 归属部件 |
| --- | --- | --- | --- |
| 1 | 1OUT | 比较器 1 输出 | Part A |
| 2 | 1IN− | 比较器 1 反相输入端 | Part A |
| 3 | 1IN+ | 比较器 1 同相输入端 | Part A |
| 4 | GND | 地 | Part A |
| 5 | 2IN+ | 比较器 2 同相输入端 | Part B |
| 6 | 2IN− | 比较器 2 反相输入端 | Part B |
| 7 | 2OUT | 比较器 2 输出 | Part B |
| 8 | VCC | 电源 | Part A |

### 补个外形，再把引脚名字显示出来

八个引脚画完之后，我们一般来说还要给它加多一个——你看，会加一个外形在里面，所以我们在里面还要再给它放置一个矩形。

放置矩形的时候，我们一般要把它变成透明。

变成透明之后，我们在这里看一下：像我们这个 LDO，你看它里面的话是有文字的，对不对？但我们现在看的话它只有数字没有文字，怎么调出来呢？

这个很简单。我们先把这个引脚先全选，全选之后点一下这个信息窗，然后我们看到这里面 Name 这里，它的这个眼睛是被擦掉的，那你再点一下，它就会显示了。

显示之后，我们就会发现全部乱了对不对？这时候不要慌——把这里面的引脚全部选择，选择之后你把它拉出来，然后再把这个框拉长一点点。

那这样的话我们就可以画完我们这个原理图封装了。

> **易错点**：符号本体只是给人看的，电气连接全靠引脚热点。所以框的大小以"不碰到引脚名字"为准，宁可大一点也别挤成一团。

### Design ID、标号和描述

画完之后，我们这里面的原理图封装的名称也要改一下。

设计 ID（Design ID）你可以直接设成 LM393。然后这里面的标号（Designator），一般我们这些芯片的话都是以 U 开头，然后你再打个问号就可以了，也就是 U?。这里面的话你也一样可以写成 LM393。底部这里面还有一个描述（Description），你就把它打成"比较器"就可以了，这个打中文是没有关系的。

那这样的话我们就画完了这一个封装，然后我们在这里就保存一下。好，那这个时候的话我们就得到了第一个属于我们自己画出来的一个原理图封装了。

### 单个部件画出来为什么难用

但是我们在这一看，这个原理图封装实际上它画得还不是一个特别好用的原理图封装。为什么呢？因为它用起来是很费劲的。

你看我们在这一拉出来之后，正常来说我们画一个比较器，你看这个比较器这样子看着就很舒服，对不对？但是你要用这一个芯片去画的话，那就很恶心了。

你这一个东西这样子看，用这一种芯片去画的话其实也是能用的，但是你画出来那个电路是非常难去检查的——你会发现那个线绕来绕去绕来绕去，它就没有像我们上面的这种看起来那么顺眼。

```text
   单个部件画出来的 LM393：能用，但线全绕在芯片周围

     1OUT ──┐   ┌── 3IN+
     1IN- ──┤   ├── GND
     1IN+ ──┤ ▓ ├── 2IN+
     VCC  ──┤   ├── 2IN-
     GND  ──┘   └── 2OUT

   两个部件画出来的 LM393：每个比较器独立，连线一路直着走

        ┌───┐             ┌───┐
  1OUT ─┤ △ ├─── 1IN+ 2OUT┤ △ ├── 2IN-
  1IN- ─┤   ├─── VCC  2IN+─┤   ├── VCC
        └───┘             └───┘
```

所以说的话我们一般来说，像这一种比较器或者说一些复杂一点的这些芯片，我们通常的话要把它画成多个部件。

### 新部件：把 LM393 拆成 Part A 和 Part B

那我们在这一画成多个部件要怎么去画呢？

很简单，我们只需要在这里选择它，然后**工具**，点击一下**"新部件"**。注意，是**新部件**，不是**新器件**——这两个挨得很近，点错了就变成另一个器件了。

点了新部件之后，我们就会发现它这里就会有分成 Part A 和 Part B。

我们这里面的这个芯片它其实就是有两个部件的：在原来那个原理图库文件里，我们点一下之后，你会发现它底部这里是有两个部件去给你选的，对不对？那它是怎么画出来的？就是在库文件里选中它，点工具，点新部件，这时候我们的这个芯片就会变成两个部分，然后这两个部分我们就可以把它分成两个运放或者比较器来画了，对不对？

那我们在这里面的话一样的跟大家简单的演示一下，比如我们在这一快速地画一下。

**先画 Part A。** 首先放第一个引脚进来，第一个引脚对应的就是 1OUT；第二个对应的就是 1IN−；第三个就是 1IN+。

在这里面其实我们不需要去画它那个 OUT1、OUT2、OUT3 了，因为它是分成两个部件，对不对？在这里大家画不画都可以。

然后的话我们一般来说我个人习惯，是画成那个 Part B 了，这里我们剪切到这个 Part A 这里来吧。

Part A 的话我们就画第一个，一般来说我个人是习惯在第一个部件那里，我会把电源还有地的引脚就画在上面——所以我们在这一可以把它的电源还有 GND 的引脚画上去。一般来说它的 VCC 是 8 引脚，所以我们在这里把它的 VCC 给放上来，然后 GND 也放一下，GND 的话一般就是第四个引脚。

> **提示**：运放的话很多时候不是叫 GND，一般是叫 VSS。因为我们有一些运放是可以双电源供电的，包括比较器也是一样。

好，然后我们这样子画完之后，接下来要放一个三角形，对不对？所以我们在这一就要点一下**放置**，然后点一下**多边形**。

好，然后这时候的话我们可以把它的线改成 Small，然后它这里面的填充改成透明状的。把它的这个 Pin 放上去就好了。

### 三角形和引脚差那么一点点怎么办

这个 Pin 的话我们一般来说我们是希望它跟它接一起嘛，对不对？要么你就把我们这里的三角形往后挪一点点，要么你就把你的 Pin 脚变长一点点。比如说我把这个 Pin 脚改成 120，或者 150 吧。

变长一点点之后，它还有一点点伸不上去，这时候要注意。

有一些同学可能就想着：我能不能把它的网格变成 10mil 或者啥的？你可以变成 10mil，比如说我把它变成一个 10，这个时候的话我们就可以把它这样子拉下来，你看拉得很精确对不对？

**但是我不建议大家这样子去做。** 因为你这样子做的话，有时候我们在画原理图的时候，我们原理图的格点它有可能是等于一个 100 或者 50，这时候如果你有这样的一个区别的话，它容易出现对不齐的一个问题。

那这时候怎么办呢？有一个比较笨的办法，就是你可以在这里面放置多一条线——就是你在这里放置多一条线，这样子拉下来，你看这样子看上去的话是不是就接在一起了？对吧？

```text
   ✗ 把库里的栅格改成 10mil 硬凑

     ▓▓▓▓
     ▓  ▓
     ▓  ●──   ← 这里落在 10mil 格点上，10 的倍数
     ▓▓▓▓        在原理图 50mil 格点下就没法落位

   ✓ 补一小段线把差值吃掉

     ▓▓▓▓
     ▓  ▓
     ▓  │
     ▓  ●   ← 主体仍锁在 50mil，多出来一小段用线补
     ▓▓▓▓
```

好，然后的话我们在这一一样可以把它的输入引脚的名称给显示出来。

这个 1 引脚是 OUT 的，3 引脚，还有这个 2 引脚，我们刚刚的栅格单位还没换回来——所以这一步做完记得把栅格换回 50mil。

这个 OUT 的话我们可以把它这个名称给关掉；这个负号我们就写成一个负就可以了；3 的话我们就写成这个正。

好，那这样的话我们就画完了第一个 Part 的部分。

**再画第二个 Part。** 第二个 Part 的话也是一样的，就是我们一样的直接放我们这个引脚，然后也是一样放这个 V+、V−。

第一个的话正的话就第 5 引脚嘛，然后 Name 就是正。然后第六个引脚，它就是负。然后第七个引脚，它的这个名称就是 OUT2。

好，然后的话也是一样的，我们就画这个三角形就行了，再把这个三角形给画下来——就是放置这个多边形，然后这样画这个三角形出来。有点不对称。

然后一样的，我们把它的这个线改成 Small，然后放下来。之后我们这个 5 脚还有 6 脚，它的这个名称一样要把它给调出来。

> **易错点**：这两个部件的三角形，面积大小我们要调成一样的，不然等一下你画的时候就发现是很别扭的。

那这样的话，我们就可以得到分成两个部件的原理图封装。

然后我们在这里去画原理图的时候，这个时候我们去选择它的这个，就画我们这个原理图的时候，你看它这里面就会分成有两个部件，对吧？然后你这里就这样拉出来，你看，它就是其中第一个，对不对？然后你拉第二个，就选第二个 Part，你这样子拉出来，它就是第二个，对吧？

那这样子的话，我们是不是就可以实现之前画的这种形式去画我们这个原理图了，对不对？

## 手绘一个 SOP-8 封装，顺便把关键器件钉在正确的位置上
> 对应块：BLK25 | 覆盖分集：P120-P123 | 块标题（分集名）：《115.绘制PCB封装》

### 先给原理图封装认领 PCB 封装

上一节我们把原理图封装画完了。接下来要干的事只有一件：给这个符号底下挂上一个 PCB 封装。在器件库里点 Add，把刚才选中的 LM358 那个封装加进来——就是一个 SOP 封装。

加进来之后，你选中其中一个引脚，比如 1 脚，它就会亮起来。这个动作很关键：你正好可以借这个机会，把你画的原理图封装到底有没有画错整个对一遍。

> **易错点**：从嘉立创下载下来的封装，千万不要太相信它百分之百是对的。我们有很多同学都被坑过。下载进来之后，一定要先检查一遍。

怎么个点法呢？打开原理图库，一个引脚一个引脚地点过去。以这个比较器为例：

| Part | 引脚 | 对应信号 | 点下去的表现 |
| --- | --- | --- | --- |
| A | 1 | OUT | 亮 |
| A | 2 | IN− | 亮 |
| A | 3 | IN+ | 亮 |
| A | 4 | GND | 亮 |
| A | 8 | VCC | 亮 |
| B | 5 / 6 / 7 | — | 点一下，5、6、7 都亮 |

这一轮全对上了，说明符号这块没问题。这个"对着亮"的检查方式，值得养成习惯。

不过话说回来，PCB 封装我们还是要会自己画。各大厂家给芯片都配好了对应的封装，下载确实省事，可作为一个新手，画原理图封装和画 PCB 封装是一个基本技能，我们一定要学会。前面那个 PCB 封装虽然是直接添加进来的，它到底是怎么画出来的，我们也要搞明白。

### 从零画一个 SOP-8

#### 建库、起名、打开格点

第一步是建 PCB 库：在项目上右键，新建 PCB Library，点保存。工程里就多出一个 PCB Library 2，里面空空如也，所以还是得在这个基础上画。

打开这个文件，先给它命个名。我们现在画的是 SOP-8 封装，直接命名成 SOP-8 就行，也可以写成 SOIC-8，这些都是很常见的名称。当然你也可以在后面加个器件型号，比如 SOP-8_LM393，这样等一下找起来更加容易。描述那些字段其实都可以不填。

进来之后，先点一下字母 G，在栅格属性里点"设为默认"，点适用，这时候画面上就出来一些格点，方便我们观察位置。

#### 第一个焊盘：层和编号

放 → 焊盘，画面上就多了一个焊盘出来。然后先按一下 Tab。

Tab 之后弹出焊盘属性，这里有两件事必须先想清楚。

第一是层。我们画的这个 LM393 是贴片封装，所以引脚必须选贴片型的焊盘，Layer 就选 Top Layer，这一层选完，焊盘立刻变成贴片的样子。如果画的是过孔型的焊盘——就是一个中间有洞的——那就选 Multi-Layer。

| 焊盘类型 | Layer 选什么 | 长相 |
| --- | --- | --- |
| 贴片型（SMD） | Top Layer | 贴在板面上，没有洞 |
| 过孔型（插件） | Multi-Layer | 中间有洞，穿过整个板 |

> **易错点**：Top Layer 和 Multi-Layer 这一栏，决定了你画出来的是贴片封装还是插件封装，选错了整个封装就废了。

第二是编号。这是第一个引脚，所以数字要改成 1。

> **结论**：这个数字不是随便一个编号，它就是你这个 PCB 封装的引脚编号，会跟你原理图库里的第一个引脚一一对应起来。千万别乱标，标错了等一下你就会发现原理图和 PCB 之间的封装对不上。这件事等下我专门演示给你看。

#### 焊盘的长和宽怎么算

尺寸这一步是很烦的事情，我自己都非常烦，但没办法，大家都要自己去算。

我自己的习惯是先新建一个小表格，按表格来算。以一个焊盘为例，它分长和宽两个方向。

长怎么来呢？一般就按最大值算。手册上标的是 5.6 和 5.2 这种上下限，我们要的是它每一边单独属于这个焊盘的那一段：

$$
\text{焊盘长} = \frac{8.2 - 5.6}{2} = 1.3\ \text{mm}
$$

算出来，每一侧边框到焊盘边缘的实际长度就是 1.3 毫米。不过我一般会把它放长一点点，直接取 2 毫米——留一点空间，方便你焊接。

宽是可以直接读的，手册写的是 0.51，这里直接取 0.5 毫米就行了，不用较真到这个 0.01。

形状我一般选圆形的。当然你也可以选方形的，方形的没有那么好看，所以我比较喜欢圆的。

于是这个标准焊盘就出来了：圆形，2 毫米 × 0.5 毫米。

#### 其余焊盘：坐标法和格点法

一个焊盘画好了，剩下的就好办。Ctrl+C，点一下这个中点，Ctrl+V，就放下来了。

接下来有一个很关键的点：焊盘与焊盘之间是有间距的，而这个间距要按封装信息来调。1 脚到 2 脚是多少？手册已经给了，1.27 毫米。

填法有两种。

第一种是直接打坐标。以 1 脚的中心点为基准，2 脚在它往下 1.27 毫米的地方，那你就把 2 号焊盘的编号设成 2，Y 直接写 -1.27。这时候两个焊盘的距离肯定就是 1.27 了。

第二种方式是直接编辑格点。按 G，打开栅格属性，去掉"步进的链接"，然后 Y 方向的步进写成 1.27，X 方向直接写 8.2。这样鼠标走一格就是 1.27。

```
    按 G → 栅格属性 → 去掉「步进的链接」

      X 步进 = 8.2      ← 1 脚跨到 4 脚，芯片的体长
      Y 步进 = 1.27     ← 相邻两脚之间的节距
```

有了这个格点，放置第三个焊盘就非常爽了：往下一格是 1.27，3、4；然后往左走，一走就是 8.2 左右，5、6、7、8。几下就可以把这几个焊盘全部放好。

当然我这里演示的只是焊盘比较少的画法。如果你要画那种很多个焊盘的，还有别的快捷方式，我就不跟大家演示了，大家自行去百度一下。

焊盘摆好之后要检查。怎么检查？按 Ctrl+M，量一下它们的距离，应该是 8.2。

> **定义**：这里的 8.2 是焊盘与焊盘之间的中心距离，不是边缘到边缘。中心距意味着什么？意味着你的芯片直接放上去的时候，芯片的边缘刚好卡在你这两个中心点中间。你能看到每一边都多出来一半焊盘，那是专门留给你焊接的，这样焊起来就简单很多。

如果说你想把封装体积压缩一点，可以适当地把焊盘减小一点点。

#### 丝印框和第一脚标记

引脚位置画好了，接下来还要再画封装外部的信息。这里可以看到外面还有一个小框。

这个小框你就大概地画一下就行，一般而言我都是大概地画，只要把框的信息、大小画得合适就可以了。

先把栅格调小一点点：按 Q 把单位重新换回 mil，步进填 10 mil 一格，这样就回到了一个相对比较细的格点状态。

然后放置丝印信息的时候，是要切到 Top Overlay 层的，大家一定要注意。切到丝印层，放 → 线条，沿着外面把这个框画下来就好了。

还有一个细节：要标出第一引脚。我一般会把 1 脚这一侧的线再画长一点点，多画一格，然后在这个位置放一个小圆圈，用它来表示这是第一引脚。

好，这样一个最简单的 PCB 封装就画完了。

当然，一个标准的 PCB 封装实际上还要添加很多信息，比如封装的高度信息，同时可能还要再画一些机械层在上面，还有各种各样的约束层。这些细节我就不一步步演示了，最标准的画法大家自己去百度一下——百度上有很多非常专业的文档，照着画就行。

当然你按照我这样子画出来，也不是说不能用，其实这个封装也是可以用的。

#### 存回去，再点一遍

接下来保存。我先把这个标号设成 10，先保存。

保存完了，我们做一件验证的事：把刚刚这一个给删掉，然后添加一下刚刚这里面的封装。它就添加进来了。

然后点 5、6、7，再点 Part A 的 1、2、3、4、8——引脚都是能对应起来的。

但是！我一点 1，1 引脚没有亮。

> **易错点**：其实就是因为我们刚刚看到引脚没有写成是 1 的标号，所以它是对应不起来的。所以这一点大家一定一定要注意——你在画 PCB 封装的时候，引脚的标号一定不能够随便乱取。

改回来，点保存，再回去。

这时候我们要**刷新一下预览**。因为我们这一边画好、保存了之后，这一边是要刷新一下才更新得过来的，不刷新它是过不来的。

刷新了预览之后，再点一下 1，你看，这时候它就亮了。

反过来的验证我也做了：我把引脚标号改回 10，这时候已经保存了，一般来说保存之后数据就已经更新过去了；但如果不去刷新预览，点这个 1 它还是会对过去。右键刷新预览之后，再点 1，就没有了。

由此引出最后一条，也是最容易搞混的一条：

> **结论**：原理图里的引脚位置，是可以随便改的。比如我把 1 脚放到这里来，实际上它依然会一一对应我们这里的 PCB 封装位置——只要引脚标号跟 PCB 上面的标号是对上的，原理图上引脚画在哪里都无所谓。但是 PCB 上面的引脚位置，你就一定、一定不能够乱改，因为它的焊盘跟你的实物是一一对应、是死的。

### 原理图更新成 PCB

原理图封装和 PCB 封装都画好了，我们紧接着往下一步：把原理图变成一个 PCB。

第一步是给项目工程添加一个 PCB 文件。点完之后工程里就会多出一个 PCB 文件，然后 Ctrl+S 保存，命名成 card。

得到 PCB 文件之后，大家一定要注意：在生成 PCB 的时候，直接选中文档原理图，点设计 → 更新 PCB 文档。这时候会弹出一个窗口出来。

弹窗里的顺序千万别搞反：

```
    设计 → 更新 PCB 文档（Design → Update PCB Document）
             ↓
      ┌────────────────────────┐
      │  ① 验证变更 Validate    │  ← 先检查，不改板子
      │  ② 仅显示错误 Show Errs │  ← 有错就筛出来看
      │  ③ 执行变更 Execute     │  ← 确认干净了再执行
      └────────────────────────┘
             ↓
       PCB 里冒出一堆元器件
```

先点"验证变更"，它会进行第一步检查，看有没有错误。如果有错误，你可以点"仅显示错误"筛出来，里面就会有显示；如果没有错误，这一栏就是空白的。确认干净了，再点"执行变更"。

执行完，PCB 文件里就会有一堆元器件出来。

错误长什么样？我给大家演示一下。比如我们选的这一个运放、这个比较器，它是有封装的。我假设把它的封装给删掉：点删除，点 Yes，原理图里这个 LM393 就没有封装了。

这时候去更新，先验证。你看，它就报错了——会告诉你 U1 缺少了什么东西。

> **结论**：只要你的元器件出了问题，不管是少封装，还是有其他一些短路什么的，它其实都会报一个对应的错误出来。

新手碰到这些错误往往不知道怎么排查。有个很简单的办法：把它的报错复制过来，到百度上去搜。搜完之后一般都会找到答案，因为这些错误都是非常非常常见的错误，90% 的错误你都是可以解决的。

如果说你解决不了，你可以问一下我们几位老师，他们在这些东西上是非常非常有经验的。当然，你报了我们硬件班的话，你也可以来问我们。

那找到问题之后怎么办？很简单，把这个封装再添加回去就好了。刚刚删掉的那个封装名称好像是叫 MSOP8，就添加回来，保存，然后再更新一次、验证一下。

这次没有错误，直接点执行变更，它就更新过来了。PCB 上就有了——这一个就是我们刚刚最新更新出来的一个封装。

### 边框：先量实物，再画线

原理图封装和 PCB 封装都齐了，接下来我们正式开始画 PCB 了。第一步不是布局，是先给这块板子画一个边框。

这一步很简单，但要根据你的实际结构来画。我们这一个 PCB 是直接放在小车上面的，所以照着结构图画就行了。

小车的长，我们这里是量出来的——这个长等于 10 厘米。宽的话，你买了一个新的模型回来，可以先在你的框上面画一条线，这样一量，就得到是 65 毫米。

长宽信息知道了，下面就好办。

画边框一般就要用机械层。所以第一步，把层切换到 Mechanical 1 层；然后点放置 → 线条。

放置的时候不要一根线一根线硬拉。你可以先随便画一条，然后把单位切换成毫米（按 Q）。双击这条线，在属性里有一个"长度"，把它改成 100 毫米。

宽的那条，对应的是我们刚量的 65。同样画一条线，长度改成 65 就行了。

（这里有个小细节：刚画的时候那几条线对不齐，其实还是格点的问题，把格点改成 10 mil 就顺了。改完格点，把线剪切、复制、粘贴到对应的位置，四边很快就齐了。）

四边齐了之后，全选，然后点设计 → 把板子形状按照这个对象定义。这样我们就得到了一个 100 毫米 × 65 毫米的边框。

### 安装孔：三个孔的坐标

边框是有了，但还有一个要点：我们要先根据实物上的安装位置，把安装孔定下来。

你看这台车，这儿要拧一个螺丝，这儿也要拧一个，这儿也要拧一个，一共三个。

孔位在哪儿、离边界多远，靠眼睛看是看不出来的。这里我用一个很土的办法：因为我这块板子底部已经焊好了，我就不拆了——你在画之前完全可以自己先拿一支笔，在实物上画一个边框，画完之后，你的洞离你的框边多少距离，就是能量出来的。

我们这里量一下：从这一条边过去，大概等于 8 毫米左右；从这一条边界过去，大概等于 15 毫米左右。这样子你就可以得到第一个安装孔的具体位置。

知道了位置，怎么才能精确地把这个孔定位过去呢？跟前面一样——你要充分利用坐标。

#### 孔位与原点

第一步，设原点。我们把原点设在你板子的左上角这个角上。

第二步，放孔。放置 → 焊盘（一般放焊盘；过孔是要连线的）。

第三步，改属性。层选择 Multi-Layer，它就变成一个穿孔的插件焊盘了。

第四步，填尺寸。要装一个 3 毫米的螺丝，就把它设置成 3.5 × 3.5。

> **注意**：这里要分清两个数——上面设的是焊盘大小，下面还有一个钻孔（Drill）大小。我们要的就是 M3 的螺丝孔，是整块钻穿，所以焊盘填 3.5，钻孔也直接填 3.5。看 3D 图，它就是一个完完整整的 3.5 × 3.5 的洞。

顺便说一下，你这里的焊盘边界其实是可以小于钻孔的——你设成 2，钻孔也填 2，也是没问题的，钻出来的效果一样，都是同一个 3.5 的孔。反正在这里我们只是做一个安装孔而已，不需要外围那一圈铜。

第五步，定坐标。刚刚量出来：离左边这条线 7 毫米（量的时候大概是 8），从上边这条线往下走 15 毫米。那么 X 就填 7，Y 填 -15。第一个孔位的位置就出来了。

第二个孔位也是一样的。直接复制过去就行。

如果你懒得去算坐标，其实有一个很笨的办法。孔位跟这一边的孔位肯定是对称的，所以你可以把这一边又设置成一个原点。设完之后，这一边的孔位离你这一边也是 7 毫米，离上面也是 15 毫米。于是 X 变成 -7，Y 还是 -15。

你看，这样两个孔是不是就左右对称了？一定要充分地去利用这个坐标。

中间还有一个孔位，因为你一开始已经在实物上画过框了，框到洞的距离你是知道的。所以要么直接测量——这个洞距离那个洞多少，那个洞距离这个洞多少——只要找到一个参考点去算就行了。

我这里简单测了一下，中间这个孔的坐标距离大概等于 13。往上走就是 13，所以我直接打坐标：先复制一个下来，X 就是 50（因为左右两边对称，板宽 100，50 就是正中间），Y 就是 -13。

```text
    ┌───────────────────────────────┐  ← 上边界
    │  ● 孔1: X= 7, Y=-15           │
    │                               │
    │                               │
    │            ● 孔3: X=50, Y=-13 │
    │                               │
    │                               │
    │  ● 孔2: X=-7, Y=-15           │
    └───────────────────────────────┘  ← 下边界
       原点设在左上角；板宽 100，X=50 即中线
       两个孔到左边界的距离由“重新设原点”直接镜像得到
```

三个安装坐标，再加一个边框，OK。

#### 锁定，并让孔边上的铜让开

搞定之后，我们一般要把它们给锁定：全选，然后点属性，把"锁"给上。之后你再想移动它，它会警告你要不要移这个东西，点"否"就行了。这样我们就得到了初步的安装信息。

我们再回头看刚才的边框——你会发现每个孔旁边都多了一个圈圈。这个圈不是画着好看的，它的作用是把孔旁边的铜去掉。

实现办法是加一层 Keepout Layer，在这一层上再放一个圆上去，这样孔旁边就不会铺铜了。这一边也一样，放置一个圆弧上去。当然这里其实也可以直接复制。

看一眼 3D 图，这时候就能看到边框上有三个洞了。

到这里，Layout 的第一阶段就完了：把边框以及关键器件做一个定位。

### 布局：先把关键器件钉住

接下来就可以正式开始 Layout 了。Layout 的第一步是要先去做布局，而布局是有顺序的——首先第一步，要把那些关键器件的位置给放好。

什么叫关键器件？看一下实物图就明白了：机械结构在这一里是有几个洞的，这儿也是有几个洞的，底部这里也是。焊线的接口还有 LED 的位置，是不是一定要按照洞的位置去放的？所以我们画 PCB 的第一步，就是先把这些关键的位置放好。

#### LED：位置由结构决定

我们需要先把 LED 的位置确定下来。怎么确定？也是拿一把尺子，按照原来规划的那个点去量距离，直接去量就行了。量了之后就可以得到它对应的坐标，然后按照我们刚刚说的坐标法，一步一步地把 LED 放到这个位置来。

这里一个 LED，这儿一个，这儿一个，这儿一个，一共四个。

选择这四个之后，有一个快捷方式：按一下 I，在列表里面点一下 L。这时候画一个框，就可以把选择的这四个元器件选出来。

> **提示**：如果嫌一个一个点太慢，工具菜单里还有一个交叉选择模式（Cross Select Mode）。打开之后，只要在原理图里选择对应的器件，PCB 里就会被同步选上。做 Layout 的时候这个功能非常方便。

具体放到哪呢？有时候你也不知道它放左边合适还是右边合适。这时候怎么办？可以先把 LM393 挪出来看——挪开之后就会发现，LM393 明显有一根飞线飞到这里来，这里又是有飞线飞到那一边的。明显它要放到右边。

放置也是有讲究的：

> **结论**：发射端的 LED 一定要靠中间去放。

为什么？因为小车在走的过程中，中间是黑线，所以我们肯定要让发射管靠近黑线，这样灵敏度才更高。所以发射的那一颗 LED、还有这一颗，都要靠近中间去放。

对应的坐标自己设置就好了，按照测出来的长度、边框的长度以及孔的位置，对好了标上去。

接收端也是一样，要按照对应的编号对好位置。我们可以把它们做一下简单的对齐，左右对应的轴大家自己去设置好就行了。这样就可以把 LED 给放好了，这里我就不跟大家一点一点去测了。

#### 接口：电机口和电源口

LED 放好之后，输入接口也要对齐。

为什么呢？看一下实物——电机的两根线要从这个位置拉出来，所以电机的输出口也是一样要按照车子的位置去拉出来。

这里也是拿尺子去测。测出来之后，就可以知道电机应该在哪一个点拉两根线出来，比如这一点和这一点。然后一样按 I 和 L，这里就会出来两个。测出来之后大概就放在这一个位置——因为对应的是安装孔，高度是差不多的。

最后还有一个电源输入端口。电源输入端口是要放在这边的角落的，所以电源口也要放到这个位置来。

放完之后，我们就可以得到一个初步的大体结构了。

#### 锁住

有了大体结构之后，要把现有的比较重要的点位锁定：这几个 LED、电机口，还有电源输入孔。选择之后点属性，把"锁"给锁上，这样它们就固定住了。

这时候我们得到的就是初步的电路信息。第一阶段就完了，就是把边框以及关键器件做了一个定位。做好定位之后，下一步就要开始做布局。

## 元器件布局与铺铜：让电流走它该走的路
> 对应块：BLK26 | 覆盖分集：P124-P127 | 块标题（分集名）：《119.元器件布局》

很多同学摆完板子会很得意：元件排排坐，对齐得严严实实，走线也拉得挺漂亮，看着就专业。我见过这样的板子——为了"看起来对称"，还在另一侧硬凑了一个三极管出来。

然后一上电，性能像鬼一样。

问题不在于它摆得难看，而在于它摆得**好看但不对**。所以 layout 的第一件事，从来不是拉线，而是把电流路径摆对。这一讲我们从收尾布局一路走到铺铜和设计规则检查，把整条流程走完一遍。

### 动手之前：把网络藏起来，把丝印压到最小

有了初步布局之后，第一步是把板子里所有的网络全部隐藏。隐藏之后，先把丝印调一下——这一步很多人是等到最后才想起来做，那就晚了。

操作是：点中丝印 → 查找相似对象 → 直接点应用；然后把文字高度调成 0.1，位置设到中间，类型直接选面板上给的那个类型。点完你会发现丝印不见了，这是对的——丝印现在只是被压小了，藏在焊盘底下，等打板前再调回来。

丝印消失之后，这里常常会多出一条线来。这条线好像删不掉，是不是 bug？不用管它，把对象移一下它就没了，纯粹是渲染上的小毛病。

> **结论**：布局阶段先把丝印压到最小。它属于最后一步的事，现在只需要它别碍事。

### 电机这块：电容必须贴着端子

关键内容搞定，开始做布局。布局是分成一个一个模块来布的，先把电机这一部分布了。

先说清楚为什么布局要这么较真。这个项目其实很简单，说句不好听的，就算直接用自动布线，这块板子出来也能用。但自动布线能出板子，不等于布得好——**布局决定了你后面走线到底好不好走，也决定了这块板子的工作质量**。

#### 两个电容：储能就得挨着电源

第一件事，是一定要知道电机这一块的电流流向。

因为板上加了两个电容，这两个电容可以简单认为就是电机的储能电容，所以它们一定要放在电机旁边。

你千万不要说："我这里输入是 6V，我把电容放到这一边来，其实也不会报错。"它确实不会报错。为什么？因为这个电容跟 6V 接在一起，你那一侧也是 6V，飞线那根线本来就是跟 6V 端子接在一起的，所以电气规则完全通得过。

但是——我们画原理图和画 PCB 的时候，**一定要有一条很清晰的电流路径**。这个电容的作用就是给电机储能，那它的位置就必须靠近端子。

具体分开说：小电容放在端子旁边，大电容可以稍微远离一点点。因为小电容靠得越近，滤波效果越好。

#### 滤波电容：要在噪声跑掉之前抓住它

除了储能电容，还有续流二极管和滤噪声的电容。续流二极管可以放远一点点，然后再到三极管；但**滤除噪声的电容必须靠近端子**。

为什么？因为这个滤波电容干的事就是滤掉电机产生的噪声，那当然是希望噪声一出来就被我滤掉。你要是把它放到远处，拉两根线过去，电气上确实连在一起了，但噪声早就跑到其他地方去了。拉那么远，你这个电容加在这里还不如不加。

所以电机旁边的这个电容，一定要放在电机旁边，大家一定注意，不能随便乱放。

#### 三极管：把电流路径摆顺

再看三极管，它的电流流向一定要盯住。

```text
   6V ──▶[储能电容]──▶● 端子 ──▶ 电机 ──▶ 三极管 C（集电极）
                                       │
                                       ▼ E（发射极）
                                      GND ──▶ 电容负极
```

读图：电流从 6V 出来，经过储能电容到达端子，进电机；从电机另一端回来，进了三极管的集电极，再从发射极回到 GND，最后回到电容的负极。整条路径就是这么一个圈。

所以 layout 的时候一定要按真实的电流路径去规划，不要为了好看把三极管怼到别处去。

> **易错点**：有些同学总喜欢"我为了好看，把三极管怼到那边去"，那边也放一个，搞得特别对称，看着好像很帅。这样摆出来，工作起来性能像鬼一样。这块板子的信号频率不高、电流也不大，你就算随便搞其实都还行——但原则不能丢：**先保证电路的工作质量，再去保证美观**。

### 下拉电阻太大了？换个封装再摆

摆电机这块的时候，我们看到这个下拉电阻的封装明显偏大，可以改一下。

怎么改：点中这个电阻 → 查找相似对象 → 把匹配到的电阻全选上 → 把封装改成 0603-1 → 确定 → 保存。回到 PCB 这边点"更新"。

更新过去之后，封装就变小了。更新完你会看到元件全部变成绿色，多半是因为原理图里多了一个 class 而 PCB 端没有对应，把那个 class 删掉就行了。

放进去之后，这个电路是不是就报绿了？实际上这个可以忽略。实在看不惯，你可以把它挪过去一点点，也可以去改规则。

这个报绿跟**装配**有关，就是器件与器件之间的距离。在规则里跟装配相关的这一项里面，有一个最小水平距离，把它改成 0，点应用，就不报了。

它刚才为什么会报？因为电解电容画 PCB 封装的时候，已经把它的长宽信息标在里面了。当你的电阻放到它的这个范围以内时，它就会报绿。刚才我们调的最小水平距离是 0.254，一放进来它就发现你已经放进另一个器件的封装范围里了，所以报错。

**但是这一个信息我建议大家不要改成 0。** 你改成 0 之后，后面万一真的两个器件有干涉，它是不会报错的，你根本不知道。最好的做法是：要么专门针对这两个设一条规则，要么你就把它挪远一点点，这样就不会报错了。我建议大家挪远一点点就可以了。

### 发射接收这块：原理很简单，摆法有讲究

发射和接收这一部分的原理其实很简单，没有什么需要特别注意的。这里是一个比较器，不是运放，所以摆这些器件的时候，尽量把这一部分靠近比较器去摆就好了。

#### 储能电容跟着 VCC 和 GND 走

重点是这个电容，它是比较器芯片的储能电容，在这里面要靠近它来放。放这边也行、放那边也行，尽量让它到 VCC 和 GND 的路径最短。

> **提示**：这里为什么这么随便？因为它只是个比较器，输出一个高低电平而已，速度太低了。跟运放做线性放大完全是两回事，运放的补偿电容可不敢这么放。

#### 可调电阻：挪到空旷的地方去

这里有两个接收端的可调电阻。放到芯片旁边其实也没什么影响，但我建议大家把它们挪到空旷的一侧。

原因很朴素：这个电阻是用来调光敏接收二极管灵敏度的。既然是调的，就意味着真正工作过程中你可能要去焊它。既然要焊，那就放到空旷的地方去比较好焊。

你要是把它怼到这两个芯片中间，新手下烙铁头的时候——现在看我们这个教程的基本上都是新手嘛——手抖一下又焊到这颗芯片，手抖一下把两个引脚短路了，抖来抖去抖来抖去，好不容易把这两个引脚给弄开了，然后那一边已经弄得面目全非，一不小心这个焊盘又掉了。

所以说，你这两个经常要焊的东西，就放到空旷的地方。按我自己的实物，我就没有放到那里，我就直接放到这里来了，因为我对我的焊功还是有点自信的。

### 原理图是边画边改出来的

这 100Ω 的电阻，就跟着你的发射端放在旁边就行了。然后发射端这里最好也给它加一个电容，在这儿做一个滤波。

这里要特别注意一个观念：**你在画 PCB 的时候，是要根据实际情况实时去调节电路的。** 比如你看到这里少了个电容，加个电容能增加稳定性，那你就直接在 PCB 这边加一下就行了。

我们画原理图，不是一画好就锁死了，非得一路布完 PCB 才 OK。你要实时去调，因为很多时候我们在 layout 的过程中会实时发现这个原理图有一点点问题。

改完原理图之后，一定要点"静态标注原理图"。**千万不要点强制标注**，一强制标注，你这里面的编号就全部乱了，前面做的那些工作全白做了。一定选静态标注，选完保存，然后再更新原理图。

更新过去之后，我们这边就会多一个电容，就这样子放上来就行。

然后这里还有一个电容。按理来说，这个 5V 这里，这个电阻也要给它加一个电容，就是你在这里再并联多一个电容，这样子这个电阻两端的稳定性也会更好，所以也可以再加多一个电容。

画电路就是这样子，你不要指望一上来就把原理图画得非常完美，不一定。你就是一边画、一边调。我个人画原理图是很随性的，甚至有时候走线的时候发现走不通了，我还要去改原理图，把那个原理图改成非常好走的那种状态——只要你不影响性能就行了。

画完之后别忘了验证。刚才我们忘记标号了，这边有错误，点一下验证，它会明确告诉你：这两个器件的标号都是 C?。我们把标注标好之后再重新更新。

更新好之后，把对应的电容放到该放的位置上，把这个东西往前往前一靠，这一部分的布局就布好了。

电源那块布局也是一样的，我就不一一跟大家布了，大家按刚才说的规则来摆就行：保证电流路径非常顺畅。

> **结论**：很多同学搞得这边放一个、那边放一个，摆得漂漂亮亮、齐齐整整，很有"艺术感"，走线也好看，但工作起来性能非常差。**layout 的时候先保证电路的工作质量，再去保证美观。**

### 走线之前：先把规则设好

接下来就是 layout。在真正拉线之前，**要先把规则设好**——规则没设就开始拉，拉到一半发现线宽不对，全得重来。

点 Design（设计）→ Rules（规则），往下拉 Routing，里面有一个很重要的点就是 Width，对应线宽。

#### Width：线宽

点进去之后，一般默认的线宽全部都是 0.254 mm：最小宽度 0.254，首选宽度 0.254，最大宽度也是 0.254。

0.254 这个值一般都要去做一些更改：电源线可能要让它走大一点点；信号线就按最小去走，一般也没什么问题；要做阻抗匹配的线，则要设定对应的宽度。这里就根据实际情况来设置。

我们这个电路的规则非常简单，就演示一下普通的过程：最小宽度就用 0.254 不改了，拿它走信号线；首选宽度 0.254；最大宽度设成 0.5，这个 0.5 等一下用来连电源线。点应用。

接下来就可以连线了。点连线工具（Interactive Routing），点一下旁边就亮了，线宽可以通过这里改。按了连线工具之后，先点一下目标，然后按 **Tab 键**——所有的信息修改都是按 Tab 键的。

这里面会出来一大堆信息：走线的过孔大小可以在这里设置，走线的宽度也可以设置，走 45 度夹角、弯角还是直角也在这里选。因为这里只是驱动一个 LED，所以用 0.254 就行了，连起来。下面电源线一般要让它变大一点点，按一下 Tab，变成 0.5，连起来。

> **提示**：电源线其实不一定要 0.5，用 0.254 也没什么问题。一般 10 mil 的线大约可以过 1 A 左右的电流，电机的电流才几百毫安，所以搞个 0.254 就行了。

在拉线的过程中位置可以微调一下，走线会更顺一点点。这些都是边拉边调的。

#### Net Class：给电源单独开一条规则

有时候你希望所有的电源线都变成比如 0.3、0.7，这时候可以专门针对电源设一条规则。

怎么设：在规则窗口里点击 Classes（Net Classes），添加一个类，New Class，改名改成 VCC，把 3.3V、5V、6V 添加进来，就变成了一个统一的 VCC 类，点击确定。

然后回到 Rules → Width，添加一条新规则，命名成 Width_VCC。点进去选择"规则是针对谁的"，选 Net Class，选 VCC 这个类；把最小宽度设成 0.35，优选宽度 0.35，最大宽度也设成 0.35。点应用。

这时候它就会报错——因为检测到现有的这根走线不等于 0.35 了。没关系，利用刚刚说的规则，给特定的网络设置合适的值。以后拉这些专用的网络就非常方便了，不需要重复去设置：一拉出来这根线肯定是 0.35 的，因为规则已经设定好了。6V 也一样。去拉其它线的时候，它还是按优选 0.254 走，但如果需要在 0.254 到 0.5 之间灵活变化，也可以在这里临时调。

#### 过孔：Tab 一定要在放下之前按

还有一个点：走线过程中有时候需要过层换到第二层，怎么打呢？走过来之后点一下，按住 Ctrl + Shift，滑一下鼠标，这时候就会多出一个过孔来。

想设置过孔信息的话，**大家一定要注意：不要点左键放下之后再设置**，因为过孔一旦放下去就来不及了，**一定要在没放之前按 Tab 键**。这时候你会看到过孔的直径，还有过孔的孔径是多大。

一般对于信号线来说，可以打最小的过孔，宽度乘个 2 倍就行了。但一般不会打这么小，会比板厂的最小工艺要大那么一点点。不同板厂、不同工艺下最小过孔是有规则的，这一点大家可以自己去各大板厂查一下。比如板厂说最便宜的那种两层板，最小过孔写的是 0.3，这时候尽量调大一点点，比如调成 0.35，就不去挑战它的工艺了。

所以一般都会把信号线的过孔调到 0.35 mm 左右。过孔旁边有铜（焊盘），一般焊盘直径设成两倍或者两倍多一点点，比如 0.75；设成 1 也是可以的，这样就得到一个比较小的过孔。

> **注意**：过孔放置之后还有一个很重要的信息——**到底要不要盖油**。如果不盖油，打回来的板子如果孔比较大，会发现是镂空的，照一下灯就发现板子到处都是洞。避免的方法就是把这个勾勾上，做出来的时候会强制把过孔盖油，孔里面给填充好，整个板子就不是镂空的状态了。这一点很多新手都会忽略。

### 铺铜

线拉得差不多之后，第五个步骤是铺铜。这里同样简单给大家说一下。

#### 铺一整片 GND

点 Place Polygon Pour（铺铜）工具，点完之后先按 **Tab**。第一步先选层，比如选 Top Layer；然后选 Net，铺铜一般就铺 GND，所以点 GND。

再往下走，这里一般选择 **Pour Over All Same Net**。这是什么意思？比如你有一根 GND 的走线，铺铜铺过去的时候会直接把 GND 的线也一起铺上去。如果选 Don't Pour Over Same Net，不把相同网络直接铺过去，那到时候这里走一根 GND 线，铺过去会发现这根线跟铺铜是不连在一起的。一般都是直接铺过去。

下面这两个勾直接勾上，特别是第一个 Remove Dead Copper——把死铜自己删掉。什么叫死铜呢？铺了这个铜之后，这块铜跟外部没有任何连接关系，这种就叫死铜。

全部设置完之后，选好区域，把这个区域选上，就能看到它铺了一层红色的铜。

这里你会看到有两个镂空的区域。为什么？因为这里有一根走线、那里也有一根走线，它们会把这个区域的铜跟外部的铜隔开，所以这个区域就叫死铜，它会自动把它删掉。如果把这个勾取消、不自动删除死铜，这时候再重新铺一次，这块铜是不会被删掉的。

#### 底层照抄顶层

顶层铺了铜，底层是不是也要铺？操作是一模一样的，或者用一个快捷方式：先选中这个铜，按 Ctrl 点一下，再 Ctrl+V 粘贴；粘贴完之后先选中其中一块铜，把 Top Layer 改成 Bottom Layer，然后在右键选"所有铜重铺"，这样上下就都铺上铜了。

#### 十字连接还是直接连接

上下铺了铜之后，这里还有一个要点：刚铺的这个铜是 GND 铜，你会在规则里发现它的 GND 网络是一个**十字型**的连接方式。

有些同学就想着不要十字连接，就想让它直接铺过去，那怎么办呢？去规则里设置：Rules → Plane，里面有一个铺铜的连接方式 Polygon Connect Style，点进去一般会看到两种方式——第一个是 Relief Connect（十字连接），第二个是 Direct Connect（直接铺过去）。想让它直接铺过去就选第二个，点应用、点确定，再"所有铜重铺"，就全部直接铺过去了。

| 连接方式 | 铜的样子 | 什么时候用 |
| --- | --- | --- |
| Relief Connect 十字连接 | 焊盘四周留出间隙，铜从四个方向伸过来搭上 | 常规推荐，尤其小信号、小电流的器件 |
| Direct Connect 直接连接 | 铜直接盖在焊盘上 | 大电流或对散热有要求的场合 |

但**一般不建议直接铺过去**，因为直接铺过去之后，引脚在焊接的时候实际上是不好焊的。

为什么？直接铺一层铜过去之后，引脚的散热是非常好的。这时候其他引脚在焊接的时候都很好焊，唯独这个引脚——比如大家都用 330 度，其他引脚一怼上去就焊好了，焊这个引脚的时候会发现 330 度锡熔得很慢。其他引脚一怼就融了，这个引脚可能要怼个两秒钟。

所以对于这些小信号、小电流的器件，建议铺铜还是用十字连接，散热效果差一些，就比较好焊。这里用十字连接其实对性能没有什么变化，因为这只是一个小功率的电路而已。

#### 高级设置：焊盘走十字，过孔走直连

变成十字连接之后又有一个问题：这里会发现，地过孔也变成十字连接了。一般对于地过孔来说，直接铺上去就好了，不要十字连接。

这个问题也要在规则里解决。点进 Polygon Connect Style，把左下角点成"高级（Advanced）"，它就会把我们常见的三种连接方式都独立出来，让你自己分别设置：

- **通孔焊盘**：插件型焊盘，想让它十字连接就设成十字；
- **SMD 焊盘**：贴片型焊盘，这里设成十字连接；
- **过孔**：走线用的过孔，我们希望它直接铺过去，就选直接铺过去。

点应用，再"所有铜重铺"，就会发现引脚还是十字，但过孔已经全部直接铺过去了。这就是我们平时最常见的铺铜规则和操作。

#### 缝合孔：给地回流降阻抗

铺铜这里还有一点：**一般要给板子多打一些过孔**，让它地的回流路径阻抗更小。

为什么？顶面和底面都铺了一层铜之后，顶层和底层的地是要靠过孔连在一起的，那过孔当然希望到处都打一点。

最笨的一种方式，是点放置过孔工具，然后把它的网络设置成 GND，再这样一点一点地打。这是最笨的方法。

快捷一点的办法是：点开工具栏里的"缝合孔/屏蔽"，选"给网络添加缝合孔"，然后点约束区域，把要打孔的区域整个框起来。

约束区域搞定之后，这里的**网格可以调大一点，调成 10 毫米**就行——因为我们这个电路的电流什么的都很小，不要把孔打得太密了。网格设成 10 mm 之后，这里的网络要选成 GND。还有一个很重要的，**强制性盖油的勾一定要打上**，然后点击确定。

确定之后，它就会自动地在这片区域里打了很多个过孔。像刚刚这里因为没有识别到、没打到，我们再手工加两个上去，这样过孔就全打完了。

#### Keep-Out 与死铜

我们在板上可以看到，这个位置加了 Keep-Out Layer 之后，里面还有过孔，这里还铺了铜，怎么办？

把死铜勾上，勾选自动去除死铜，然后再重新铺一次。去掉之后就会发现这些孤立的铜块没有了。

这样就得到了一个完整的结果：**layout 完了、铜铺上去之后，所有的 GND 都会自动连接起来。**

### 整套流程复盘

我们再重新过一遍：

Layout 第一步是画边框。边框画完之后，下一步是**关键器件的定位**。关键器件定位定好之后，开始做**布局**——布局就决定了后面走线到底好不好，所以布局一定要按原理图里面最小的电流回流路径来放。我们这个项目涉及到的信号非常慢、电流也很小，说实话随便搞都可以。

布局搞定之后就去**走线**。走线按照刚才说的线宽规则把规则弄好，然后一点一点连起来。连起来之后准备**铺铜**：点铺铜工具，里面的设置一定要设置好——网络要选好、在哪一层、铺铜的类型、要不要把相同网络直接铺过去、要不要移除死铜等等。设置好之后画好区域，铜就铺好了。

铺好之后还有一些规则要收拾：铺铜连接方式是很多新手都会用到的；线宽规则可以在这里设置；各个走线之间的间距也在这里设置。这一条规则是非常非常常用的——走线与其他走线之间的距离、焊盘与焊盘之间的距离、走线与焊盘之间的距离，都在这个表格里面去调。

### 加丝印、导 Logo、再把丝印调回来

最后还要做一些小细节。

**加丝印**：比如我们这个"青林计划"工程里的小车，标签要怎么打？第一步把当前层调到丝印层 Top Overlay，点到这个层之后，点文字工具，按 Tab，然后在这里打字就行了。

打完字之后还有一点要注意：**字体要选择宋体之类的，才能够正常显示文字**。不然的话你选其他英文字体，中文是显示不出来的。把文字打进来，对应这些标签就有了。

**加 Logo**：比如我这里就喜欢加我自己"电子芯吧客"的 Logo。导 Logo 需要一个专门的工具，这个工具买了我们课程的同学可以直接跟我们或者跟助教要；当然你直接去百度搜"AD 怎么导入 Logo"，或者"导入 Logo 脚本 小工具"，一大堆，都行。

**调丝印**：这是最后一个点，也是很多新手会忘的。我们刚才铺铜的时候按键盘上的 3 就自动切换到 3D，按 2 就切回 2D。我们刚才已经把丝印调得非常非常小了，所以现在第一步要把丝印调回正常状态。

一般来说 Text（文字高度）调成 1 毫米，打出来就已经看得很清楚了。先把其中一个器件的丝印调回正常状态——点中它，查找相似对象，点应用，把 Text Height 全部改成 1 毫米；再把它的位置调到器件的顶部，选 Center Above。这样一点之后，这里所有的丝印就全部调到器件的顶部了。

调到顶部之后可以直接切到 3D 层来看（当然不切也行，看个人习惯），把层切到 Top Layer，然后就可以直接挪了。看得到的地方就不用管；明显看不到的，就把它挪到能看清的位置。像 U2、C10 这些，我们就这样一点一点慢慢挪，调完之后就变成这个完整的效果了——丝印就全部都看得见了。

### 设计规则检查：哪些警告能看，哪些不能

丝印调好之后就可以去打板了。打板之前还要做一个检查：点工具栏里的"设计规则检查（DRC）"，然后运行。

运行完回到板子上，左边会出现一个报告窗口，里面有很多报错。**但这些报错其实大部分只是警告。**

比如 Silk To Solder Mask，意思是你的丝印和阻焊层太近了。它建议你不要让丝印跟阻焊直接贴在一起。实际上你不管它也可以的，没有问题。像这一类的警告，你可以直接忽略。

**但是有一些警告是不能忽略的：**

- **没有连接（Un-Routed Net）**：这一根线没有连上，这是非常非常严重的，必须解决；
- **短路（Short Circuit）**：一定要去注意；
- **线与线之间的距离（Clearance）**：这个也要注意。

后面那一些其实没什么关系，比如丝印到丝印之间的距离，只要你看得到其实就没什么关系。

其他那些规则，大家直接去百度一下，看一下它什么意思、怎么解决。你把这个警告复制到百度上一粘贴，大把答案，按照百度上面得到的答案自己去解决就行了。

解决完就可以去打板了。现在打板的地方太多了：立创、华秋、捷配，还有各种各样很多很多。它们现在打板的方式其实都很简单——你把这个 PCB 文件变成一个压缩文件，拖到打板的界面上，然后按照它的默认一直填信息下来就可以了，没有什么难度。打板回来之后，把元器件买回来焊上去，慢慢调就行了。

这样，整个 PCB 就搞定了。
