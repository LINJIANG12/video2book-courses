# 汇编语言：`jmp` 指令详解与转移机制

---

### [00:00] `jmp` 指令概述与转移分类

在这一节中，我们将系统介绍 `jmp` 指令。

`jmp` 为无条件转移指令。既然涉及到转移，就必然涉及到修改指令指针寄存器 $\text{IP}$ 的值；在某些情况下，还会同时修改代码段寄存器 $\text{CS}$ 的值，以此实现段间转移。

在使用 `jmp` 指令时，需要给出两种类型的信息：
1. **转移的目标地址**：指示程序转移的目的地；
2. **转移的距离（转移范围）**：转移的距离体现在以下三个方面：
   * **段间转移（远转移，Far Jump）**：不仅改变 $\text{IP}$，还会改变 $\text{CS}$，转移范围跨越不同的代码段；
   * **段内短转移（Short Jump）**：$\text{CS}$ 保持不变，仅修改 $\text{IP}$。使用关键字 `short`，属于 8 位位移转移，$\text{IP}$ 的修改范围为 $[-128, 127]$ 字节；
   * **段内近转移（Near Jump）**：$\text{CS}$ 保持不变，仅修改 $\text{IP}$。使用操作符 `near ptr`，属于 16 位位移转移，$\text{IP}$ 的修改范围为 $[-32768, 32767]$ 字节。

其中，短转移和近转移后接的都是标号，两者的本质区别在于**相对位移量的大小**不同。负数表示向前转移（当前指令的前方/上方），正数表示向后转移（当前指令的后方）。

### [01:34] 依据位移转移的原理分析

在深入理解 `jmp` 指令之前，必须明确一点：**段内转移指令通常是根据“相对位移”进行转移的，而不是在机器指令中直接给出绝对物理地址。**

在常见的指令中，如果包含立即数（常数），该常数会直接编码在机器指令中。例如：

```assembly
mov ax, 0123H
mov ax, [0123H]
push [0123H]
```

通过 Debug 的 `U` 命令反汇编这三条指令后会发现：
* 第一条指令编译后的机器码为 `B8 23 01`，其低字节在前、高字节在后，包含立即数 `0123H`；
* 第二条指定内存地址的指令机器码中，依然包含 `0123H` 的痕迹；
* 第三条压栈指令同样在机器码中包含 `0123H`。

这说明常规指令中的立即数会直接体现在机器码中。

### [03:06] `jmp short` 指令的机器码与执行机制

接下来观察段内短转移指令 `jmp short`。分析如下汇编代码段：

```assembly
    jmp short s
    add ax, 1
s:  inc ax
```

当使用 `U` 命令查看该段代码的机器码时：
* 汇编指令显示为：`jmp 0008`，即转移到偏移地址为 `0008H` 的指令处（对应 `inc ax`）；
* 观察其机器码，发现仅有 2 个字节：`EB 03`。

在机器码中并未出现目标地址 `08`，取而代之的是 `03`。这个 `03` 代表相对位移量：
$$\text{当前下一条指令的偏移地址 } 0005\text{H} + \text{位移量 } 0003\text{H} = \text{目标地址 } 0008\text{H}$$

机器指令中包含的是相对偏移量，而不是绝对目标地址。

### [05:00] 段内转移的 CPU 执行过程分析

以另一段包含 `jmp short s` 的代码为例：
* 假设 `jmp short s` 编译后的反汇编显示目标为 `000AH`；
* 对应的机器码为 `EB 05`。

执行过程如下：
1. 当 $\text{IP} = 0003\text{H}$ 时，CPU 将 `jmp` 指令的机器码（2 字节，`EB 05`）读取到指令缓冲队列；
2. 读取后，$\text{IP}$ 自动增加所读取指令的长度（2 字节），变为 $0005\text{H}$，此时 $\text{CS:IP}$ 指向本应顺序执行的下一条指令；
3. CPU 执行指令缓冲队列中的 `jmp` 指令，取出机器码中的相对位移量 `05`，并与当前的 $\text{IP}$ 相加：
   $$\text{新 IP} = \text{当前 IP } (0005\text{H}) + \text{位移量 } (05\text{H}) = 000AH$$
4. $\text{CS:IP}$ 随即指向目标地址 `000AH` 处的 `inc ax` 指令，转移完成。

机器指令中保存的是相对目标标号的**位移量**，而非目标地址。

### [07:55] `jmp short` 与 `jmp near ptr` 的位移计算与规范

段内转移包含两类：
* **短转移**：`jmp short 标号`
* **近转移**：`jmp near ptr 标号`

#### 位移计算公式
`jmp short` 的功能为：$(\text{IP}) = (\text{IP}) + 8\text{ 位位移}$。其中 8 位位移的计算公式为：
$$\text{8 位位移} = \text{标号处的地址} - \text{jmp 指令后第一个字节的地址}$$

因为 CPU 在读取完 `jmp` 指令后，$\text{IP}$ 已经自动递增指向了下一条指令的首地址，所以位移量正好等于标号地址减去 `jmp` 指令下一条指令的起始地址。8 位位移在机器码中以**补码**形式存放，由编译器在编译阶段自动计算得出。

`jmp near ptr 标号` 的功能为：$(\text{IP}) = (\text{IP}) + 16\text{ 位位移}$，位移计算方式完全一致，但位移扩展为 16 位补码，范围为 $[-32768, 32767]$。

### [09:50] 短转移超界错误示例

如果在程序中人为制造位移超出 8 位范围的情况：

```assembly
    jmp short s
    db 128 dup (0)
s:  mov ax, 0ffffh
```

分析：
* `jmp short` 允许的最大正向偏移量为 $127$ 字节；
* 中间定义了 128 个字节的数据，相对位移必然超过 $127$；
* 在编译时，汇编编译器会直接报错：`jump out of range by ... byte(s)`（跳转相对位移超出单字节表示范围）。

段内转移的位移不可超界；若超出范围，编译器会拒绝通过。

### [11:07] 段间转移：`jmp far ptr`（远转移）

远转移指令格式为：
```assembly
jmp far ptr 标号
```

与短转移/近转移不同，**远转移指明的是目的地的绝对地址**，在机器指令中直接包含目标标号的代码段地址 $\text{CS}$ 和偏移地址 $\text{IP}$。

代码示例：
```assembly
    jmp far ptr s
    db 256 dup (0)
s:  add ax, 1
```

编译并查看机器码：
* 目标转移指令位于 `076A:010B`；
* `jmp far ptr s` 的机器码为：`EA 0B 01 6A 07`；
  * `EA` 为操作码；
  * `0B 01` 为偏移地址 `010BH`（低地址存低位）；
  * `6A 07` 为段地址 `076AH`（高地址存高位）。

机器码中直接写入了跳转目标的完整物理分段信息，执行时直接装载：
$$\text{CS} = 076A\text{H}, \quad \text{IP} = 010B\text{H}$$

### [13:14] 段内近转移示例：`jmp near ptr`

近转移使用 16 位相对位移，范围为 $[-32768, 32767]$。

代码示例：
```assembly
    jmp near ptr s
    db 256 dup (0)
s:  add ax, 1
```

编译后：
* 汇编反汇编结果显示转移目标为 `0109H`；
* 对应的机器码为：`E9 00 01`；
  * 偏移值按小端读取为 `0100H`（即十进制 256 字节）；
  * 当前下一条指令地址为 `0009H`，加上位移量：
    $$0009\text{H} + 0100\text{H} = 0109\text{H}$$

机器码中存储的依然是 16 位相对位移，而非绝对地址。

---

### [14:58] 转移地址在寄存器中的 `jmp` 指令

转移地址也可以存放在 16 位寄存器中：
```assembly
jmp 16位寄存器
```

指令功能为：$(\text{IP}) = (\text{16位寄存器内容})$。例如：
```assembly
mov ax, 0
mov bx, ax
jmp bx
```
编译后，`jmp bx` 的机器码仅包含操作码，不包含固定的转移目标地址。执行后，$\text{IP}$ 被赋值为 $\text{BX}$ 中的值（即 `0000H`）。这种方式允许程序在运行期间动态计算跳转目的地址，灵活性极高。

### [16:25] 转移地址在内存中的 `jmp` 指令

转移地址还可以存放在内存单元中，分为段内转移和段间转移两种情况。

#### 1. 段内转移：`jmp word ptr 内存单元地址`
CPU 从指定的内存单元处读取一个字（16 位）作为目的偏移地址放入 $\text{IP}$。

```assembly
mov ax, 0123H
mov ds:[0], ax
jmp word ptr ds:[0]
; 或使用寄存器间接寻址：
jmp word ptr [bx]
```
执行后：
$$(\text{IP}) = ((\text{DS}) \times 16 + 0) = 0123\text{H}$$

---

### [18:28] 段间转移：`jmp dword ptr 内存单元地址`

#### 2. 段间转移：`jmp dword ptr 内存单元地址`
CPU 从指定的内存单元处读取两个字（双字，32 位）：
* **低地址字**：存放目标偏移地址 $\text{IP}$；
* **高地址字**：存放目标段地址 $\text{CS}$。

代码示例 1：
```assembly
mov ax, 0123H
mov ds:[0], ax
mov word ptr ds:[2], 0
jmp dword ptr ds:[0]
```
执行后：
* 高位字为 `0000H`，装入 $\text{CS}$；
* 低位字为 `0123H`，装入 $\text{IP}$；
* 程序转移至 `0000:0123` 执行。

代码示例 2：
```assembly
mov ax, 0123H
mov [bx], ax
mov word ptr [bx+2], 0
jmp dword ptr [bx]
```
执行后：
$$\text{CS} = 0000\text{H}, \quad \text{IP} = 0123\text{H}$$

### [20:26] `jmp` 指令总结

| 指令类型 | 指令格式 | 机器码记录内容 | 修改寄存器 | 范围 / 说明 |
| :--- | :--- | :--- | :--- | :--- |
| **段内短转移** | `jmp short 标号` | 8 位相对位移 | $\text{IP}$ | 范围 $[-128, 127]$ 字节 |
| **段内近转移** | `jmp near ptr 标号` | 16 位相对位移 | $\text{IP}$ | 范围 $[-32768, 32767]$ 字节 |
| **段间远转移** | `jmp far ptr 标号` | 目标标号的 $\text{CS}$ 和 $\text{IP}$ | $\text{CS}, \text{IP}$ | 直接写入目标绝对地址 |
| **寄存器间接转移** | `jmp 16位寄存器` | 寄存器操作码 | $\text{IP}$ | $(\text{IP}) = (\text{Reg})$，段内近转移 |
| **内存段内转移** | `jmp word ptr 内存单元` | 内存寻址码 | $\text{IP}$ | 从内存读取 1 个字送入 $\text{IP}$ |
| **内存段间转移** | `jmp dword ptr 内存单元` | 内存寻址码 | $\text{CS}, \text{IP}$ | 高地址字送入 $\text{CS}$，低地址字送入 $\text{IP}$ |

---

### [22:48] 语法限制强调

在编写汇编源程序（`.asm` 文件）时，**严禁直接使用立即数指定段地址与偏移地址进行跳转**，例如以下语法是非法的：

```assembly
; 错误语法！汇编编译器无法识别该指令
jmp 076A:010B
```

汇编语言编译器不支持此种立即数段间跳转格式。此类形式仅允许在 Debug 调试环境中通过交互指令使用。在源程序中若需实现段间转移，必须采用 `jmp far ptr 标号` 或 `jmp dword ptr 内存单元` 的方式。
