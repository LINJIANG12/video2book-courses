在这一节课，我们去介绍一下在转移指令当中经常要用到的一个操作符 `offset`。

`offset` 的作用是取得标号的偏移地址。这如何去解释呢？
`offset` 后边的格式总是 `offset` 后面加一个标号。而作为标号来讲，我们曾经用过，比如说这一段指令：`start` 和 `s` 都是标号。于是我们可以看到：

```assembly
offset start
offset s
```

也就是说，这样一个操作符后边加的都是标号。

[00:31]
那么这个标号将来转换成什么呢？对于这个来讲，它会把它转换成 0。为什么呢？我们可以看到 `codesegment`，对这个段来讲，一开始就是这条指令，所以 `start` 作为偏移地址来讲它就是 0。

而且 `s` 它是 3，为什么呢？前面这条指令是一个 3 字节的指令，所以 `s` 的偏移地址是 3。所以在这里边经过编译以后就是这个样子的。

[00:58]
接下来我们看，如果把它放在源程序里边，经过编译以后，我们通过 Debug 把它调到内存里边，通过 `u` 命令去打开，那么的确在里边可以看到：在这得到的就是 0 和 3。

而现在我们观察到，对第一条指令 `mov ax, 0` 来讲，它最终的机器码是这个位置。所以对 `s`（也就是在这里边出现的这个 `s`），它的偏移地址的确可以看到就是 3，所以在这里边这个是没有问题的。

[01:26]
因此，我们在掌握这个指令以后就知道了：如果在程序里边，我们需要知道某一条指令它的偏移地址到底在哪，我们可以在这条指令前面加一个标号，然后在需要的地方 `offset` 后面加标号，这就可以了，这是它的用法。

[01:45]
对于这个用法，我们现在做一个小练习。这个小练习是这样的：我们要在一段程序段里面添加两条指令。要干什么呢？干的事情很简单，用的技术也简单，但是它起的作用绝对吸引人——它能够把该程序在运行过程里边（注意：在运行过程里边），把某一处的一条指令复制到另外一处。注意到在运行的时候把某一处的一个指令复制到另外一个，想想这大概是很多病毒在干的事了。接下来我们看一下这段程序。

[02:18]
在这段程序里边，我们读一下：
当代码段开始以后，我们把 `bx` 放到 `ax` 里边；然后现在我们要把 `s`，也就是这个偏移地址放到 `si` 当中，这是一个寄存器；把 `s0` 的偏移地址放到 `di`。`s0` 在哪呢？在这。而 `s0` 后面跟了两条指令，这两条指令我们经常叫空指令（`nop`），它每一个指令占有一个字节，起到一个占位作用。因此在这有两个字节，而这两个字节现在是空的。

好，现在我们就要把这一块去填空。这块填什么呢？要把 `s` 处（也就是这个位置上）的这一条指令，我们希望填到 `s0` 所代表的这块空间。接下来看这的两条指令该如何去写。

[03:12]
要写这两条指令，我们现在做一个分析。
我们首先要知道，`s` 处和 `s0` 处的指令，它所在的内存单元地址是多少。因为在这里边提到了 `s` 和 `s0`，而且内存单元的地址我们在程序里边已经看到，它们分别是：

$$\text{CS}:\text{offset } s$$

这是它的偏移地址；以及：

$$\text{CS}:\text{offset } s_0$$

这是我们 `s` 和 `s0` 这两条指令所在的内存单元地址，包括段地址，包括偏移地址。而现在我们可以看到就是在这一段里面进行操作，所以 `cs` 两个都是相同的，我们可以忽略一下。

[03:56]
然后我们要把 `s` 处的这一条指令复制到 `s0` 处，它其实干的是这样的事情：就是把 $\text{CS}:\text{offset } s$ 地方的这条指令，复制到 $\text{CS}:\text{offset } s_0$ 的这个位置上去，我们要做的就是这个事情。

那么这个地址如何去表示呢？段地址已经在 `cs` 里面，而偏移地址已经送到了 `si` 和 `di` 里面了：送到 `si`（这是源地址），送到 `di`（这是目标地址）。现在其实我们要去做的事情就显然了。

[04:34]
我们可以把在 `s` 处的这一条指令看成是数据。注意，指令和数据其实都是二进制表示的，我们希望把它用成指令就是指令，希望把它看成数据就是数据。

我们现在要看一下，其实就是把在这个偏移地址上的数据复制到这儿，我们把它当指令去看的。现在要复制的这个数据有多长呢？

[05:01]
我们知道对于这个代码来讲，它是一个两字节的代码。所以在这儿要填入的指令，只需要把偏移地址保存在 `si` 位置上的两个字节，能够把它复制到偏移地址为 `di` 的这两个字节处就可以了。其实这个问题就很好解决了。

[05:24]
如何解决呢？我们把 `si` 作为偏移地址、`cs` 作为段地址的这一块的一个字（两字节数据）放到 `ax` 里边，然后把 `ax` 里面的内容放到以 `cs` 为段地址、`di` 为偏移地址的这么一个位置上：

```assembly
mov ax, cs:[si]
mov cs:[di], ax
```

现在其实从这个地址里面取出的就是它的机器码，所以这样的话完成了这个工作。

[05:54]
我们通过填写两条指令，该程序在运行的过程里面，把 `s` 处的一条指令复制到了 `s0` 处，于是这个任务就完成了。
