### 基址变址寻址方式：`[bx+si]` 与 `[bx+di]`

#### [00:00] 寻址方式引入与基本概念
在有了 SI 和 DI 寄存器以后，我们对内存的寻址方式进一步丰富了。在这一节，我们介绍 `[bx+si]` 和 `[bx+di]` 的这种寻址方式。

首先我们可以看到，这种方式指定的地址格式为：`[bx+si]`，也可以是 `[bx+di]`。它表示的是一个内存单元，该内存单元的偏移地址就是 BX 的内容和 SI 的内容相加。

也就是说，用示意图去看，一段内存可以先确定它的段地址；段地址确定后，再加上 BX 的内容去确定一个基准位置，这个位置表示为 `[bx]`，加上方括号表示取出它里面的内容。

如果再加上 SI，指定的就是在此基础上进一步偏移的空间。在偏移量为 BX 的基础上再加上 SI，空间又偏移了 SI 这么多。

因此在汇编语言中，我们经常把 BX 称为**基址**（基即基础），SI 称为**变址**，这种寻址方式被称为**基址变址寻址**。我们用 BX 代表基数定在基准位置（BX 本身也是可变的）；若希望灵活访问后续的内存单元，通过改变 SI 的值进行累加即可，因此这种方式更加灵活。

---

#### [01:26] 指令含义与寻址规则
我们来看这样一条指令的含义，逐层剖析：

```assembly
mov ax, [bx+si]
```

1. **操作对象与字长**：该指令将一个内存单元的内容送入 AX 寄存器。此处的传送操作关注的是一个**字单元**（两个字节），因为目标操作数是 16 位寄存器 AX。
2. **偏移地址（EA）**：偏移地址由 BX 中的数值加上 SI 中的数值共同决定：
   $$EA = (bx) + (si)$$
3. **段地址（SA）**：在没有段超越前缀的情况下，SI 和 DI 默认的段地址存放在数据段寄存器 **DS** 当中。

---

#### [02:11] 数学化描述与等价写法
对于指令 `mov ax, [bx+si]`，其数学化描述如下：

$$ (ax) = ((ds) \times 16 + (bx) + (si)) $$

即先将段地址 DS 左移 4 位（乘以 16），再加上 BX，再加上 SI，确定物理地址后，取出该内存字单元的内容送入 AX 寄存器中。

这种形式还有另一种等价的书写格式：

```assembly
mov ax, [bx][si]
```

遇到这种写法时，需要明确其含义与 `mov ax, [bx+si]` 完全相同。

#### [02:46] 案例分析与寄存器变化推导
我们来看一个具体案例，分析程序执行后各寄存器（AX、BX、CX、SI、DI）的内容变化。

程序代码如下：

```assembly
mov ax, 2000H
mov ds, ax
mov bx, 1000H
mov si, 0
mov ax, [bx+si]
inc si
mov cx, [bx+si]
inc si
mov di, si
mov ax, [bx+di]
```

执行过程分析：

1. `mov ax, 2000H` / `mov ds, ax`：设置数据段寄存器 $DS = 2000\text{H}$。
2. `mov bx, 1000H`：设置基址寄存器 $BX = 1000\text{H}$。此时对应的数据段基地址为 `2000:1000`。
3. `mov si, 0`：变址寄存器 $SI = 0$。
4. `mov ax, [bx+si]`：
   - 偏移地址为 $1000\text{H} + 0 = 1000\text{H}$。
   - 读取 `2000:1000` 处的字单元，低字节为 `1000H` 处的内容，高字节为 `1001H` 处的内容。
   - 读取后：$AX = 00\text{BEH}$。
5. `inc si`：SI 自增 1，$SI = 1$。
6. `mov cx, [bx+si]`：
   - 偏移地址为 $1000\text{H} + 1 = 1001\text{H}$。
   - 读取 `2000:1001` 处的字单元。
   - 读取后：$CX = 0600\text{H}$。
7. `inc si`：SI 再次自增 1，$SI = 2$。
8. `mov di, si`：将 SI 的值送入 DI，此时 $DI = 2$。
9. `mov ax, [bx+di]`：
   - 偏移地址为 $1000\text{H} + 2 = 1002\text{H}$。
   - 读取 `2000:1002` 处的字单元。
   - 读取后：$AX = 0006\text{H}$。

#### [04:44] 运行结果与验证
在 Debug 环境下修改内存数据并运行该段程序，执行完毕后各寄存器的状态如下：

- $AX = 0006\text{H}$
- $BX = 1000\text{H}$
- $CX = 0600\text{H}$
- $SI = 0002\text{H}$
- $DI = 0002\text{H}$
- $DS = 2000\text{H}$
