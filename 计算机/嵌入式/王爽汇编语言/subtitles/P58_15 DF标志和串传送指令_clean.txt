# 方向标志位与串传送指令

### [00:00] 引入：字符串复制问题与传统实现方式

在这节中，我们介绍方向标志位和串传送指令。

现在我们首先解决一个以前曾经解决过的问题：我们要把 `data` 段当中的第一个字符串复制到后边紧接着的 16 个字节上去，这个字符串一共占了 16 个字节。在做这个事情的时候，我们原来是这样编写程序的：

首先取得该段的段地址放入 `DS` 当中；然后，要复制的源字符串在起始位置，所以我们把源地址寄存器 `SI` 赋为 0；而将要复制到的目标位置在偏移 16 处，所以把目标地址寄存器 `DI` 赋为 16。

接着设置一个循环，在循环的过程中完成复制。在这里我们循环 8 次，每一次不是按照字节进行复制，而是按照字（Word）来进行复制：把 `SI` 所指向的那个字取出来，放到 `DI` 的位置上去；然后把 `SI` 和 `DI` 分别加 2，再去循环。当 8 次循环完成之后，正好完成了这 16 个字节的复制。

```assembly
mov ax, data
mov ds, ax
mov si, 0
mov di, 16

mov cx, 8
s:  mov ax, [si]
    mov [di], ax
    add si, 2
    add di, 2
    loop s
```

这个程序充分体现了源地址寄存器（`SI`）和目标地址寄存器（`DI`）配合进行数据复制。我们希望把这样的程序写得更加简洁。怎样才能更简洁呢？我们引入标志寄存器中的 DF 位（方向标志位）以及串传送指令。

---

### [01:37] 方向标志位 DF（Direction Flag）

DF 是方向标志位（Direction Flag），它保存在整个标志寄存器中编号为 10 的位上。

对于这个标志位来说，它与串处理指令密切相关。DF 控制每次操作后 `SI` 和 `DI` 的增减：
- 当 $\text{DF} = 0$ 时，每次操作后 `SI` 和 `DI` 递增（根据操作单位加 1 或加 2）；
- 当 $\text{DF} = 1$ 时，每次操作后 `SI` 和 `DI` 递减（根据操作单位减 1 或减 2）。

---

### [02:13] 串传送指令：MOVSB 与 MOVSW

配合串传送指令来看它的具体工作方式。

第一个串传送指令是 `MOVSB`。这条指令很好理解：`MOV` 表示移动，`S` 代表串（String），`B` 代表字节（Byte），所以它是以字节为单位传送一个串。

`MOVSB` 的传送规则如下：
1. 将数据段（段地址为 `DS`、偏移地址为 `SI`）中的一个字节取出；
2. 传送并写入到附加段（段地址为 `ES`、偏移地址为 `DI`）所指向的位置：
   $$((ES) \times 16 + (DI)) = ((DS) \times 16 + (SI))$$
3. 传送完成后，修改 `SI` 和 `DI` 的值：
   - 若 $\text{DF} = 0$，则 `SI` 和 `DI` 递增，即：
     $$(SI) = (SI) + 1, \quad (DI) = (DI) + 1$$
   - 若 $\text{DF} = 1$，则 `SI` 和 `DI` 递减，即：
     $$(SI) = (SI) - 1, \quad (DI) = (DI) - 1$$

---

### [03:26] 字传送指令 MOVSW

另一个串传送指令是 `MOVSW`，即以字（Word）为单位传送一个串。

它将数据段 `DS:SI` 所指向的一个字单元取出，传送到附加段 `ES:DI` 的位置上去。传送完成后，同样根据 DF 的值自动调整 `SI` 和 `DI`：
- 若 $\text{DF} = 0$，则 $(SI) = (SI) + 2, (DI) = (DI) + 2$；
- 若 $\text{DF} = 1$，则 $(SI) = (SI) - 2, (DI) = (DI) - 2$。

---

### [04:01] DF 标志位的设置指令：CLD 与 STD

方向标志位与串传送指令是密切配合的，因此 DF 是 0 还是 1 非常关键。在 8086 汇编语言中，提供了两条专门设置 DF 位的指令：

1. **`CLD`（Clear Direction Flag）**：
   - 作用：将标志寄存器的 DF 位置 0（$\text{DF} = 0$）。
   - 助记符解析：`CL` 代表 Clear（清除），`D` 代表 Direction（方向）。
2. **`STD`（Set Direction Flag）**：
   - 作用：将标志寄存器的 DF 位置 1（$\text{DF} = 1$）。
   - 助记符解析：`ST` 代表 Set（置位），`D` 代表 Direction（方向）。

---

### [04:54] 使用方向标志位与串传送指令优化程序

接下来看刚才的例子，如何利用方向标志位与串传送指令去完成复制。

我们要把第一个字符串复制到紧随其后的位置上去，程序结构如下：
1. 设置相关寄存器：将 `data` 段地址分别赋值给 `DS` 和 `ES`（串传送指令的目的操作数默认使用附加段 `ES`，这里源和目标在同一个段，因此 `ES` 与 `DS` 相同）；
2. 设置源地址偏移 `SI = 0`，目标地址偏移 `DI = 16`；
3. 执行 `CLD` 指令清除 DF，确保 $\text{DF} = 0$，保证后续操作中 `SI` 和 `DI` 能够自动递增（这一步设置非常重要，必须保证）；
4. 设置循环计数器 `CX = 16`，通过循环执行 16 次 `MOVSB`：

```assembly
mov ax, data
mov ds, ax
mov es, ax
mov si, 0
mov di, 16

cld
mov cx, 16
s:  movsb
    loop s
```

执行时，每一次循环执行 `MOVSB`，自动把 `DS:SI` 的一个字节复制到 `ES:DI`，并使 `SI` 和 `DI` 自动加 1。

经过这样的改造，串传送指令节省了编写手动调整 `SI` 和 `DI` 代码的时间。对于该程序，完全也可以将循环次数设为 8（`mov cx, 8`），将 `MOVSB` 改为 `MOVSW`，同样可以完成这 16 个字节的传送。

### [07:34] 重复前缀指令 REP 及其应用

汇编语言中还提供了一条让程序更简洁的指令——`REP`（Repeat，重复前缀指令）。它通常与串传送指令搭配使用。

它的功能是根据 `CX` 的值重复执行后面的串传送指令，例如：
```assembly
rep movsb
```
它完全等价于：
```assembly
s:  movsb
    loop s
```
重复执行多少次由 `CX` 的值决定。执行指令之前必须先给 `CX` 设置初值。

同理，`rep movsw` 完全等价于：
```assembly
s:  movsw
    loop s
```

引入 `REP` 以后，前面的复制程序可以写得更加紧凑、简洁：

```assembly
mov ax, data
mov ds, ax
mov es, ax
mov si, 0
mov di, 16

cld
mov cx, 8
rep movsw
```

在计算机处理成片数据传送的场景中，这类需求非常频繁，因此汇编语言专门提供了这些成套的串传送指令。

### [09:30] 综合应用实例：逆向传送 ROM 中的数据

**任务需求**：使用串传送指令将 `F000H` 段最后 16 个字符复制到 `data` 段当中。

#### 1. 地址与逻辑分析
- `F000H` 段最后 16 个字符的物理地址范围为：`F000:FFF0H` 到 `F000:FFFFH`，共 16 个字节；
- 需求要求从后往前倒着复制（逆向传送）：即不是从第一个字符开始复制，而是从最后一个字符 `FFFFH` 开始往前复制；
- 源地址：段地址为 `F000H`，起始偏移地址 `SI = 0FFFFH`；
- 目标地址：段地址为 `data`（赋给 `ES`），目标段空间大小为 16 字节，从后向前存放，所以起始偏移地址 `DI = 15`；
- 传输次数：一共 16 个字符，设置 `CX = 16`；
- 增减方向：因为是倒序复制，需要 `SI` 和 `DI` 每次操作后自动减小，所以使用 `STD` 指令将 DF 置为 1；
- 传送指令：以字节为单位，执行 `REP MOVSB`。

#### 2. 程序实现代码

```assembly
mov ax, 0f000h
mov ds, ax
mov si, 0ffffh

mov ax, data
mov es, ax
mov di, 15

mov cx, 16
std
rep movsb
```

#### 3. 调试与结果验证
将程序编译链接后载入 Debug 跟踪观察：
1. 先查看 `F000:FFF0` 到 `F000:FFFF` 内存区域的值，这是 ROM 中固化存储的数据；
2. 程序刚载入内存时，`data` 数据区全为 0；
3. 使用 Debug 的 `g` 命令执行程序，一直运行到串传送结束；
4. 再次查看 `data` 数据区，发现原来全为 0 的区域已经变成了与 `F000:FFF0`～`F000:FFFF` 完全一模一样的内容，成功实现了逆向复制。

### [13:04] 总结

本节主要介绍了：
1. **方向标志位 DF**：控制串操作中地址指针（`SI`、`DI`）的增减方向；
2. **串传送指令**：`MOVSB`（字节传送）与 `MOVSW`（字传送）；
3. **标志位设置指令**：`CLD`（清零，递增）与 `STD`（置位，递减）；
4. **重复前缀指令**：`REP`，配合 `CX` 自动重复执行串操作。

利用这些指令，能够高效地构建批量、成片数据传送的汇编程序。
