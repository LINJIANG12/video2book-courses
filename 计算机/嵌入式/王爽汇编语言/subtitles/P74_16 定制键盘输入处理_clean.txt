# 汇编语言：定制键盘输入处理与中断例程接管

---

### [00:00] 一、PC 键盘输入处理过程回顾

本节介绍定制键盘输入处理的相关技术。首先回顾 PC 键盘的常规输入处理过程：

1. **第一步**：键盘产生扫描码。
2. **第二步**：键盘将扫描码送入端口 `60H`。
3. **第三步**：引发 9 号中断（`int 9`）。
4. **第四步**：CPU 响应并执行 9 号中断例程，完成键盘输入的处理。

前三个步骤完全由硬件系统自动完成，无需软件进行干预。当引发 9 号中断后，CPU 转去执行 `int 9` 中断例程，此时处理键盘输入通常有两种途径：
* **常规处理**：直接使用系统（BIOS/DOS）提供的 `int 9` 中断例程完成标准的字符读取与缓存。
* **定制处理**：在某些特殊场合，系统对键盘输入（如按下某个特定按键）有定制化的响应要求。此时应按照实际开发需求，自行编写中断例程来定制处理键盘输入。

本节所介绍的定制键盘输入处理技术，同样可以拓展到其他外部硬件设备的处理中，用于满足各种个性化、特殊功能的需求。

### [01:14] 二、定制需求与总体设计策略

通过一个典型示例来分析具体技术实现。

**任务目标**：
* 在屏幕中央依次显示字符 `'A'` 到 `'Z'`，并保持人眼清晰可见的显示时间。
* 在字符显示过程中，若按下 `ESC` 键，则改变当前显示字符的颜色属性。

**总体设计策略**：
1. **尽可能忽略底层硬件细节**：从应用程序编程的角度考虑，不必重新设计专用的键盘硬件控制逻辑。
2. **充分复用已有 BIOS 历程**：充分利用 BIOS 预先提供的 `int 9` 中断例程来处理繁琐的硬件细节，避免推翻并重写整个驱动，降低开发代价。
3. **改写与挂接中断例程**：在自定义的 `int 9` 中断例程中，仅对特定需求（按下 `ESC` 键改变颜色）进行拦截处理；对于其他按键，依然调用原 BIOS 的 `int 9` 中断例程，最大化保留原有系统的输入处理规则。

### [02:36] 三、字符显示与延时子程序设计

首先解决在屏幕中央依次显示 `'A'` 到 `'Z'` 的问题。

显存文本模式的显示原理：
* 屏幕一共有 25 行，每行 80 个字符，每个字符占 2 个字节（字符 ASCII 码和属性字节），即一行占 160 个字节。
* 屏幕中心位置选定在第 12 行、第 40 列。
* 显存偏移地址计算公式：
  $$\text{Offset} = 12 \times 160 + 40 \times 2 = 1920 + 80 = 2000$$

将字符放入显存对应的单元即可完成显示。字符从 `'A'` 开始递增，每显示一个字符就与 `'Z'` 进行比较，循环执行直到显示完 `'Z'`。

```assembly
    mov ah, 'A'
s:  mov es:[160*12 + 40*2], ah
    call delay
    inc ah
    cmp ah, 'Z'
    jna s
```

**引入延时机制**：
如果直接运行上述代码，由于计算机运算速度极快，人眼根本无法看清中间字符的变化，屏幕上会瞬间停留在 `'Z'`。因此，在每显示一个字符后，必须让 CPU 执行一段空循环进行延时，保持该字符显示一段时间。

在汇编中设计一个通用的双重循环延时子程序 `delay`，利用 `DX:AX` 构造 32 位计数器：

```assembly
delay:
    push ax
    push dx
    mov dx, 10h
    mov ax, 0
s1: 
    sub ax, 1
    sbb dx, 0
    cmp ax, 0
    jne s1
    cmp dx, 0
    jne s1
    pop dx
    pop ax
    ret
```

* 逻辑解析：`AX` 每次减 1，`DX` 带借位减 0（`sbb dx, 0`）。只有当 `AX` 减到 0 产生借位时，`DX` 才会减 1。内外层嵌套循环执行极多次，使 CPU 消耗一定的时间，从而达到延时效果。

### [07:04] 四、拦截 ESC 键与颜色控制策略

核心任务是截获 `ESC` 按键。在标准应用程序中，`ESC` 键通常用于取消或退出操作；而本程序要求按下 `ESC` 键时改变显示字符的颜色。

* 键盘产生输入后，会将扫描码送入 `60H` 端口，并触发 9 号中断。
* CPU 转入执行 9 号中断例程。
* 自定义中断例程需要从端口 `60H` 读取该扫描码（使用 `in al, 60h`）。
* 对比扫描码是否为 `ESC` 键（`ESC` 键的按下扫描码为 `01H`）：
  * **如果是其他按键**：保持原有功能不变，直接转去调用原 BIOS 的 `int 9` 中断例程。
  * **如果是 ESC 键**：执行自定义逻辑，修改屏幕中心位置字符的属性字节，实现变色。

### [08:21] 五、中断向量表的保存与重置

要让 CPU 执行自定义的 9 号中断例程，必须修改中断向量表（IVT）。

中断向量表位于内存 `0000:0000` 处（`ES = 0`）：
* 9 号中断向量的偏移地址位于 `0000:[9*4]`（即 `0024H`）。
* 9 号中断向量的段地址位于 `0000:[9*4 + 2]`（即 `0026H`）。

**处理步骤**：
1. **保存原中断入口地址**：在当前程序的数据段中开辟空间，将原 `int 9` 的偏移地址（IP）和段地址（CS）分别保存到 `ds:[0]` 和 `ds:[2]` 中，供后续模拟调用与程序退出时恢复使用。
2. **设置新中断入口地址**：将自定义中断例程 `int9` 的偏移地址和段地址填入中断向量表的 `es:[9*4]` 与 `es:[9*4+2]` 中。

**代码实现（巧用入栈出栈实现数据转移）**：

```assembly
    mov ax, 0
    mov es, ax

    ; 保存原 int 9 中断向量到数据段 ds:[0] 和 ds:[2]
    push es:[9*4]
    pop ds:[0]
    push es:[9*4+2]
    pop ds:[2]

    ; 设置新的 int 9 中断向量
    mov word ptr es:[9*4], offset int9
    mov es:[9*4+2], cs
```

### [12:40] 六、模拟调用原中断例程的机制

在自定义的 `int 9` 中断例程中，为了兼顾其他常规按键的正常处理，必须调用原 BIOS 的 `int 9` 例程。

正常触发中断时，CPU 硬件会自动完成以下动作：
1. 标志寄存器（FLAGS）入栈；
2. 将标志寄存器中的 `IF`（中断允许标志）和 `TF`（陷阱标志）置 0；
3. 当前代码段 `CS` 及指令指针 `IP` 入栈；
4. 跳转到中断例程入口执行。

由于要在子程序内部通过代码去“模拟”这一硬件中断触发过程，必须手动执行上述步骤：

1. **标志寄存器入栈**：执行 `pushf`。
2. **将 IF 和 TF 置 0**：
   * `IF` 位于标志寄存器的第 9 位，`TF` 位于第 8 位。
   * 通过将标志寄存器出栈到通用寄存器（如 `AX` 或 `BX`），将其高 8 位与 `11111100B` 进行逻辑与（`AND`）操作，使第 8、9 位强制归零，其余位保持不变，再出栈回标志寄存器：
   ```assembly
   pushf
   pop bx
   and bh, 11111100b   ; 第8、9位置0
   push bx
   popf
   ```
3. **远过程调用原中断例程**：
   ```assembly
   call dword ptr ds:[0]
   ```
   * 使用 `dword ptr` 取出双字（高字为 `CS`，低字为 `IP`）。
   * 该调用将当前 `CS` 和 `IP` 压栈后发生跳转。原例程执行完毕后以 `iret` 指令返回，刚好能平衡 `pushf` 与 `call` 压入的参数，实现完美模拟。

### [15:48] 七、完整程序框架设计

程序整体结构包含数据段、栈段和代码段。

**核心流程架构**：
1. 保存原 `int 9` 中断向量至 `ds:[0]`、`ds:[2]`。
2. 将新的中断例程 `int9` 地址写入中断向量表。
3. 主循环：在屏幕中心依次输出 `'A'` 到 `'Z'`，并调用 `delay` 延时。
4. 恢复中断向量：将 `ds:[0]`、`ds:[2]` 保存的原中断入口地址重新写回中断向量表 `es:[9*4]` 和 `es:[9*4+2]`。
5. 退出程序返回 DOS。

> **规范要求**：修改系统中断向量后，在程序结束前必须严格将原中断向量恢复，否则程序退出后，键盘后续的中断响应将指向无效地址，导致系统崩溃。

#### 自定义中断例程 `int9` 实现细节：

```assembly
int9:
    push ax
    push bx
    push es

    in al, 60h                      ; 从键盘端口读取扫描码

    ; 模拟中断调用原 BIOS int 9 例程
    pushf
    pushf
    pop bx
    and bh, 11111100b
    push bx
    popf
    call dword ptr ds:[0]

    ; 判断是否为 ESC 键
    cmp al, 1                       ; ESC 的按下扫描码为 01H
    jne int9ret

    ; 修改屏幕中心位置字符的显示属性
    mov ax, 0b800h
    mov es, ax
    inc byte ptr es:[160*12 + 40*2 + 1] ; 将属性字节加 1 改变颜色

int9ret:
    pop es
    pop bx
    pop ax
    iret
```

* **属性字节说明**：显存单元中偶数地址存放字符 ASCII 码，奇数地址存放属性字节（控制前景色、背景色、闪烁等）。对 `es:[160*12 + 40*2 + 1]` 执行 `inc` 操作，其颜色属性数值发生改变，使得屏幕字符颜色发生变化。
