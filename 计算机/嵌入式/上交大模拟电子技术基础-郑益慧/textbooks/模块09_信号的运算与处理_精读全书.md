## 看不见的电流：基本运算电路的分析原则与设计思路
> 对应块：BLK36 | 覆盖分集：P37 | 块标题（分集名）：《36-基本运算电路（1）_4K》

### 这一章真正在教什么

说真话，整个第七章——信号的运算和处理——如果真的给你们足够的时间，讲到今天这一章我本来可以不讲了。

为什么？因为基本的分析原则，我已经非常深入地告诉你们了。剩下的事，就是你们拿这套分析原则，再加上基本电路理论里学过的知识去解决问题。这个过程，我们称之为知识的整合、知识的运用。

> **提示**：我现在一点点给你们讲这个东西，就有点把你们看得太低了。我在这里重要的不是讲这个题怎么解，而是要讲一种电路的**设计思路**。当然，考试还是在考这题怎么解——题怎么解，你们肯定都能解决。

那要先学会设计，就得先学会分析别人的电路，对不对？分析了之后，从分析出来的现象里提升出来，从感性认识提升到理性认识，然后再去设计。所以我们在分析每一个电路的时候，脑子里一定要存这样一个念想：它怎么实现这个功能的？它靠怎样一个思路去设计出这样一个电路？它在运作的过程当中，到底靠什么样的原理、什么样的定理、什么样的思想去完成它所实现的功能？如果换了我来做这件事，我该怎么设计？

> **结论**：这是我们真正关心的东西——不是答案，是路径。

那为什么第七章要和第八章分开？因为第七章这一整套集成运放的电路，基本上是**让集成运放工作在线性工作区**。什么叫工作在线性工作区？我们加的整个反馈是一个负反馈。既然是负反馈，线性工作区就成立。

另外提醒一句记号约定：下面所有 $u_I$、$u_N$、$u_O$、$u_P$，如果没有特别指出，通通指的是**对地电压**。

### 虚短与虚断：两条必须形成习惯的规则

整个这一章的分析原则，第一个就是要抓住**虚短和虚断**。

**虚短**给到我们的是：

$$u_P = u_N$$

它有前提——深度负反馈，使运放工作在线性工作区，才有这样一个关系。

**虚断**是任何时候都有的。因为集成运放的差模输入电阻非常非常大，所以虚断一直成立，也就是说从总的输入电流 $I_I$ 来看是等于零的。集成运放按这个来写就是：

$$i_N = i_P = 0$$

所以在分析集成运放的时候，有两件事你们一定要形成习惯。

第一，视那两根输入线于不见。这根线，还有这根线——这是一个**心理障碍**。真的是心理障碍。什么意思？你永远会认为，在你没熟练之前，那根线上是有电流的。你就得不停地、强迫地告诉自己：这根线是没有电流的，它是断路的。很多时候都是老师提醒了一手，“啊，原来这块是没电流的”，都是这样一个道理。

所以你是视它不见。看到吧，一旦视它不见，这块就变成什么样了？视它不见容易，成天跟念经似的“视它不见”，容易；但“视它不见”背后的含义要深刻理解。你把这根线视而不见了，这根线就相当于一根串联的线了——这儿的电流和这儿的电流就是同一个了。一系列的东西都出来了，是这样一个关系。

> **易错点**：“视它不见”不是一句咒语，它是有后果的。这根线一旦视而不见，它就从“一条可能有电流的支路”变成了“一条串联导线”，于是同一条串联路径上的电流处处相等——后面所有电流相等、电流可算的结论，都是从这一步来的。

第二，你脑子里一定一直要有 $u_N = u_P$ 这个概念，而且要非常清晰。

那么对一个这样的电路，在很多分析的时候我们经常用什么？大家可以看到，这儿也有输入量，这儿也有输入量；这个 $u_O$ 本身也相当于一个独立信号源一样的东西。所以当反馈网络一加进来，$u_O$ 本身也像一个独立信号源。所以我们在分析的时候，经常用一个东西叫**叠加原理**，用一个叠加的概念，一个个来分析。

### 叠加原理，和一个 KCL 陷阱

这里要特别小心。有的同学把那两个输入线视而不见之后，**会扩展过头**，扩展出一个错误概念。

我问一个问题：在输出端挂一个负载电阻 $R_L$ 到地，这里面有没有电流？

```text
                              R_F
              ┌──────────────────/\/\/──────────────┐
              │                                     │
                ┌───────────────────────────────┐
                │                               │
u_M ──────────┼─┤ (-)                           │
                │                               ├───┬── u_O
                │                               │
                │                               │   R_L
                │                               │
                └───────────────────────────────┘
              └────────────────────────┘            │
                              GND                   GND
```

这绝对是有电流的。这没电流就出事了——到处都没电流，四路进不去，这里没电流，这里也就没电流，这块变成什么了？这输出是有电流的。

有的同学就说了：这个鬼东西好像不符合 KCL 嘛。你在这儿画一个圈，说“郑老师讲过这俩没电流，根据 KCL，这块就应该是没电流的”。这是真理。

不对。为什么它上面有电流？难道 KCL 错了吗？

> **易错点**：KCL 没错，错的是“把运放当成一个纯符号”。运放要工作，它的能量从哪儿来的？有外加的直流电源。

这个运放仅仅是个符号。你拿一个芯片过来看，同相端、反相端、输出端——芯片可查到了，这个 2 管脚是什么、3 管脚是什么、4 管脚是什么，然后把这三个管脚一连，怎么不好用啊？你根本没给人家电源。还有一个 $V_{CC}$ 呢，对不对？有的是双电源的，有的是单电源的，你要给它接好，它才能工作。

你们拿 Protel 去做仿真，用得比较多的是 Multisim，会发现这块都会给你甩出两个小电源线出来，让你去接直流电源。所以你刚才画了那么一个圈，实际上你是把直流电源那根线给切了。直流电源是有电流给它的。

所以我们这种原理图和实际电路之间，脑子里要建立一个关系：那玩意是要有电源驱动的。就如同你们上学期学了那么多门电路，我不知道你们做了数电的实验没有，也是芯片。好比说与非门，你铿铿铿一测，好，按照电路图接，输入 1、输入 2，然后输出应该是：

$$Y = \overline{A \cdot B}$$

啥非也没有，什么东西都看不到。为什么？你还是没接电源。

### 反相比例电路：一条最普适的算法

好，上来第一个电路——**反相比例电路**。

```text
                                FB network
                    ┌───────────────────────────┐
                    │                           │
                    │                           │
                    │                           │
u_I ───R────────────┼       (-)
       │            │                           ├──── ┬── u_O
       │            └───────────────────────────┘     │
       └─────────── ┘                                 R_L
                            (+)                       │
                             │
                            GND
```

你们马上就能看到，这是什么？很清楚，它做了一个**电压并联负反馈**，那肯定工作在线性工作区。那马上我们就得到一个条件：算这种东西闭着眼就行——虚短、虚断、叠加原理，完事了。用叠加的时候就叠加，不用叠加就不叠加。

**第一步：给出一个最普适的想法。**

最简单，你要建立 $u_O$ 和 $u_I$ 之间的关系。你能运用的等式是什么？是 $u_P = u_N$。那最普适性的想法是什么？**我用 $u_O$ 和 $u_I$ 把 $u_P$ 表示出来，用 $u_O$ 和 $u_I$ 把 $u_N$ 表示出来**。由于 $u_N = u_P$，所以 $u_O$ 和 $u_I$ 之间的关系就可以得到。别管什么电路，按这种想法都可以解决。

当然，也有比它简单的做法。好比说这个，如果按我们那个想法来做也还可以，但稍微有点麻烦。

**第二步：求 $u_P$。**

首先我的 $u_P$ 是等于 0 的，同不同意？有同学说那还有个 $R'$，你看人家还写了个 $i_P$。$i_P$ 是虚断的，非常非常小，所以 $R'$ 上是没有电流的。这是理想状态，$R'$ 上没有电流，因此这个 $u_P$ 等于 0。先这样放着。

**第三步：求 $u_N$，用叠加原理。**

$u_I$ 和 $u_O$ 都可以看成一个独立源，$u_N$ 是在 $u_I$ 和 $u_O$ 的共同作用下产生的。那我就用叠加原理。

$u_I$ 单独作用（把 $u_O$ 置零）时，它给 $u_N$ 贡献的是：

$$\frac{R_F}{R + R_F} \cdot u_I$$

$u_O$ 单独作用（把 $u_I$ 置零）时，它给 $u_N$ 贡献的是：

$$\frac{R}{R + R_F} \cdot u_O$$

两式联立，右边等于 $u_P$，而 $u_P = 0$：

$$\frac{R_F}{R + R_F} u_I + \frac{R}{R + R_F} u_O = 0$$

所以：

$$u_O = -\frac{R_F}{R} u_I$$

没错吧？实现的是一个**反相比例**，就是 $y = -kx$ 这样一个关系。

### 走另一条路：虚地、虚短和电流的传递

上面那种是最普遍的做法。但我们还可以走另一条路，而且这条路的好处一眼就看得到：**哪个点先能确定下来，我就先确定它**。

上面我们已经把 $u_P = 0$ 拿出来了。那么既然 $u_P = u_N$，$u_N$ 也等于 0。$u_N$ 等于 0，$N$ 那点就是**虚地**——一个虚拟的地。因为他把同相端的地电位传递给反相端了，它是一个虚地。

> **定义**：虚短在反相比例电路里具体化出来，就是“虚地”——同相端接地时，反相端电位被虚短拉到 0，但那里并没有真正接地，也不会有电流流进运放。

有了虚地，$i_R$ 是不是就可以计算出来了？

$$i_R = \frac{u_I - u_N}{R} = \frac{u_I}{R}$$

注意，这是个很重要的想法：$i_R$ 和 $u_I$ 成比例。这个比例是谁的特性决定的？**是电阻的特性。**电阻两端的电压和电流成比例。你想，我在做比例运算，我选取了虚地的概念，我又选取了一个电阻——那么这个电阻就实现了一个概念：输入电压和输入电流成比例。

接下来，由于虚断的概念：

$$i_F = i_R$$

目前这两者是完全相等的。再往前，$u_O$ 和 $i_F$ 之间的关系：

$$\frac{u_N - u_O}{R_F} = i_F$$

所以直接就出来了：

$$u_O = u_N - R_F i_F = -R_F \cdot i_F$$

（提醒一句：下标要大写，$i_F$ 不是 $i_f$。这个写法是有含义的。）

现在你们告诉我，这个式子又代表什么含义？我反馈这条路径上，网络上加的是一个**电阻**，你发现了吧？从而使得我反馈电流和输出电压之间是一个比例关系。

> **结论**：比例运算是怎么做成的？
> 我的 $u_I$ 通过元件 $R$ 和 $i_R$ 成比例；我的 $u_O$ 通过元件 $R_F$ 和 $i_F$ 成比例；而这两个电流因为虚断是相等的传递关系。通过这样一个传递，$u_O$ 和 $u_I$ 就成比例了。这里有两个关键性的元件、两个电阻，它体现的都是一个**比例**的概念。

这里有一个**技术路径**值得单独拎出来说：$u_I$ 和 $u_O$ 搭不到一块直接去，中间肯定得找个东西来传递。传递的量是**电流**。那么我就需要找两个元件，使得 $u_I$ 和那个电流成比例，使得 $u_O$ 和那个电流成比例，这时候比例运算就完成了。

到这一步你们多少已经理解了吧？这个“设计思路”的概念我讲得已经非常多了，但你们目前还不是非常理解——因为我讲得再多，你们也得自己过一遍。

两种分析方法现在你们都学会了。一种是最普遍性的；还有一种，它的优点是：我先看 $u_P$ 和 $u_N$ 哪个能确定下来就先确定它。现在 $u_P = 0$ 很清楚，所以 $u_N = 0$，然后运算就变得非常简单——我先求 $i_R$，$i_R$ 又等于 $i_F$，我一段一段地去算。

### 输入电阻到底算不算那个 $R$

现在来看这个电路的一个特点，注意，这是一个**并联负反馈**，而并联负反馈的输入电阻非常小。

我们来真正算它的输入电阻。电阻 $R$ 实际上是**在反馈环之外**的：如果我画这样一个反馈，这块相当于做了一个反馈，结果我在反馈之外接了一个电阻 $R$。如果我真的算输入电阻的话，应该在这个端口上算。

```text
                              R_F
            ┌───────────────────/\/\/───────────────┐
            │                                       │
                ┌───────────────────────────────┐
                │                               │
u_I ───R────┼───┤ (-)                           │
                │                               │
                │                               │
                │                               ├───┼── u_O
                │                               │
                │                               │
                │                               │
             ┌──┤ (+)                           │
             │  └───────────────────────────────┘
             │
            GND
```

我整个后面这个反馈网络的输入电阻是从这看进去的。从这里看进去等于多少？这块是有电流的，但这里有电压吗？电压是 0。所以这块的等效电阻是什么？**0**。

和我们所学的并联负反馈、深度并联负反馈的概念是不是非常相符？它会把输入电阻降得非常非常小。现在我们可以看到，从 $R$ 之后往里看，等效电阻是 0。

那么对于这个电路，**总的**输入电阻是多少？那个 0 加上串联的一个 $R$，所以：

$$R_i = R$$

如果我完全用输入电阻的概念从这里往里做，$R_i$ 等于什么？$R_i = \dfrac{u_I}{i_R}$，它依然等于 $R$。我这样写，是不想让你们造成一个错觉。

> **易错点**：书上直接求出来的 $R_i = R$，你们脑子里很容易冒出一个想法：“这不还是有这么一个电阻吗？$R$ 等于 1 kΩ、2 kΩ 的话，输入电阻还蛮大的，那跟我并联不就是矛盾了吗？”并不矛盾——**那个 $R$ 是游离在反馈环之外的**；在真正并联负反馈的那个电路里，它的输入电阻是 0。

### 设计上的困境：R 大了，RF 也躲不掉

对于这样一个电路，接下来实际上它是有它的问题的。

有的时候虽然说我的前端需要是电流源，但实际中我确实要拿电压源的信号，所以它加了这么一个 $R$，以待于提高输入阻抗。那就来了一个问题：我如果想输入阻抗大一点，$R$ 就得大；$R$ 大的话，我想让比例系数再大一点，你会发现 $R_F$ 要更大。这个事情就麻烦了。

> **结论**：$R_F$ 过大的时候，这个东西有的时候分压不是那么想分就分的。讲场效应管放大电路的时候我说过，前端为什么有上面那个 10 MΩ 的、下面又有两个电阻，为什么不直接用两个 10 MΩ 的去分压？**电阻大的时候抗干扰能力都很差，扰动就比较大**——电阻越大，里面电流越小，只要受一点点干扰，表现出来的电压差异就很大。所以我们不会用非常大的电阻去做分压、去做比例，它不稳定。

那么我既要输入电阻稍微大一点，又不想用一个很大的 $R_F$，还想得到一个比较大的放大倍数——我的要求都很过分。我该怎么做呢？

思路从这里拎出来就很清楚了：$u_O$ 是和 $i_F$ 成比例的，目前的问题是 $i_F$ 等于 $i_R$，它俩被绑定死了。**如果我能想个主意，让我的 $i_F$ 比 $i_R$ 大，我不就成功了吗？**我就可以得到比较好的 $u_O$。

这个主意倒实际上不太容易想。它的想法是什么呢？现在 $i_R$ 就是等于 $i_F$，如果我在这儿弄一个电流上去，让最终输出的 $i_F$ 等于这个电流加上 $i_R$，我的 $i_F$ 就会增大。

所以人们就想了这样一个主意：把反馈电阻**分开**。

```text
               R_2               R_3                R_4
          ┌────/\/\/───────────────────────────/\/\/──────────┐
          │           │           │                           │
          │           ├───────────┬                           │
                      ●   ┌─────────────────────────────┐
                          │       │                     │
                          │       │                     │
u_I ──────┼───────────────┤ (-)   │                     │
          │               │       │                     ├─────┼── u_O
          │               │      GND                    │     │
          │               │                             │     │
          │               │                             │     │
          │               │                             │     │
          │               │                             │     │
          └───────────────┘─────────────────────────────┘    GND
         GND

```

$M$ 这块肯定是个负电位，所以它一定会引起一个向上的电流 $i_3$。这个时候 $i_F$ 这里叫 $i_4$ 了：

$$i_4 = i_2 + i_3, \qquad i_2 = i_1$$

使得我的 $i_4$ 加大。本来如果没有它的话，我的 $u_O$ 就等于 $-(R_2 + R_4)\cdot i_2$；现在有了它之后，我起码 $R_4$ 上的压降提升了——提升了 $i_3 \cdot R_4$。所以你如果理解它的设计概念，这些东西都非常好理解。这个电路叫 **T 型**的——上面看，是一个 T 啊。

### T 型电路：从“我想要什么”倒推的解题思路

对于这样一个电路，有多少同学会求？你们思路是什么？

分析这个电路的思路是什么？$u_+ = u_-$，就是 $u_P = u_N$。这是一个关键点。但接下来——我们在分析问题的时候脑子要非常清楚。

> **提示**：我从小就知道要证明一个等式就两边凑。实际上那是一个**不正确的、但很功利**的做法。人家其实是希望你用很正常的思路这样过去。后来我发现，这才是**工程问题**的解决思路：工程问题就是我知道这样一个结果、我要达到这样的目标；达到这个目标，我要求前一个要达到什么、要具备什么样的条件；要具备这个条件，我前面再具备什么条件；最后推出我的技术路线来。推到最前面那个条件一定是可以解决的，否则你就没有解了。

那么我们就这么倒推下去。我要知道 $u_O$，就必须知道 $i_4$，并且要知道 $u_M$。$i_4$ 我要求谁提供？一个是 $i_2$，一个是 $i_3$。而 $i_3$ 又由谁来提供？我必须知道 $u_M$。也就是说，推到现在，我需要什么条件呢？$u_M$ 和 $i_2$，就可以了吧？

那 $u_M$ 又怎么能知道呢？我只要知道 $i_2$ 就知道了。最根本的，我只要知道 $i_2$，就知道了一切。而 $i_2$ 我知不知道呢？$i_2$ 是等于 $i_1$ 的。

所以反过来该怎么求，看清楚：

```text
                    i_1 = i_2               i_3             i_4

u_I ──/\/\/────●──────R_2───────────────●M  ──────────R_4─────●─── u_O
               │                        │
              (N)                       R_3
               │                        │
               │                        GND
            u_N = 0




```

**先求出 $i_1$，然后求出 $i_2$，由 $i_2$ 推出 $u_M$，由 $u_M$ 推出 $i_3$，由 $i_3$ 和 $i_2$ 推出 $i_4$，由 $u_M$ 和 $i_4$ 推出 $u_O$。**

我就不算了，算得太没意义了，非常重要的是解决问题的一个思路——你想得到什么，你必须有什么。

否则这样一个题，我就跟你们说，我这样扔这儿，估计我们班三分之一同学可能算不出来。因为当你脑子不清晰的时候，你都不知道该从哪儿下手。

我一直说解题包括工程问题都很有意思，和看病什么乱七八糟都一样，特别有快感：一点点剥、剥、剥，剥到最后咔解开了。包括原来 Windows 的游戏，玩那个扫雷，一点点算、算、算。我挺喜欢这样一个东西的，就像抽丝一样地去做一个诊断、去一个判断。算出来你们就会知道：原来如此，原来如此。

### 同相比例电路：把负号换成正号

我现在整个来讲这是一个反相比例放大电路，$y = -kx$。

至此我们弄出了一个东西：我能实现 $y = -kx$。我们先把数学表达式都写出来。现在我需要 $y = kx$（$k > 0$），我该怎么办？

> **结论**：从反相端进去的，出来就是一个负的比例；从同相端进去，出来就是一个正的比例。

这个我可真教过你们。刚才从反相端进去的，现在应该走**同相端**。就这么回事。

同样的思路，你想想设计思路应该怎么走：就这么一个运放，整个交给我们了。

那么我的反馈该怎么引？能不能这样引个反馈啊——这是**正反馈**。所以我要想引负反馈的话，我必须引到这边来。是这个含义吧？那么这里直接接地还不行，**我必须通过一个电阻接地**。

```text
                              R_F
        ┌─────────────────────/\/\/─────────────────┐
        │                                           │
                ┌───────────────────────────────┐
        │       │                               │   │
                │                               │
        ┼───────┤ (-)                           │
        │       │                               │
                │                               ├───┼── u_O
       R│       │                               │
       GND      │                               │
u_I ────────────┤ (+)                           │
                └───────────────────────────────┘

```

我们来看，它做的事情是不是和刚才是一样的？你发现什么呢？我这里是 $u_I$；$u_P = u_N$ 使得我的 $u_I$ 被引到这儿来了——$u_P$ 等于 $u_I$ 了。看，我通过一个**虚短**，神奇地把 $u_I$ 引到这儿来了。我一引到这儿来，跟刚才那个思路就一模一样了：$u_I$ 使得这里有个电流，这个电流和 $u_I$ 成比例；然后 $u_O$ 和这个电流成比例。两个电流联立之后，$u_I$ 和 $u_O$ 就成比例了。

看，书上那张图跟我画的多像。$R'$ 是这个，$R$ 是这个，$R_F$ 是这个。完全重复的是一样的东西。我的 $i_R$ 等于 $u_N / R$，而 $u_N$ 就是 $u_I$，所以 $i_R = u_I / R$；然后等于 $i_F$。整个的 $u_O$ 就等于：

$$u_O = u_N + i_F R_F = \left(1 + \frac{R_F}{R}\right) u_I$$

我实现了 $y = kx$。

### 同相比例的三个特点

现在我们起码脑子里有一个概念了。来看一看这种同相比例放大电路的好处是什么。

**第一，它的输入电阻非常大。**你发现它是什么反馈？这是什么组态？什么？这都不敢说啊。**电压串联负反馈**，它的输入电阻应该是无穷。在这里的确可以看到它的输入电阻非常非常大，几乎断路。所以这个 $u_P$ 是等于 $u_I$ 的，$u_N$ 也等于 $u_I$。

你会发现这种同相比例运算电路非常适合于**去取电压信号**。它接到前端信号源上的话，自己相当于是一个断路。

**第二，它和刚才那个电路有一个区别。**大家虽然都是虚短，刚才那种电压并联负反馈的电路，它的 $u_P = u_N$ 是等于 0 的；这种的 $u_P = u_N$ 是等于 $u_I$ 的。也就是说，它这里**存在着共模信号**。

我们对集成运放的整个结构应该比较清楚了：前端是个差放的输入形式，对不对？那么共模进去的话，被我完全抑制——是这么说，它还是有共模的，你们知道吧。

**第三这就对运放的选取提出了一个条件。**如果你用的是那种电压并联负反馈的电路，运放对这种抗共模的要求不高；但是如果你用的是串联负反馈的电路，它就要求你拥有比较好的**共模抑制**。

| 对比项 | 反相比例电路 | 同相比例电路 |
| --- | --- | --- |
| 反馈组态 | 电压并联负反馈 | 电压串联负反馈 |
| 反馈网络自身的输入电阻 | 0（深度降低） | 很大（近似无穷） |
| 电路总输入电阻 | $R$（那个 $R$ 游离在反馈环外） | 几乎断路 |
| 输入端电位 | $u_P = u_N = 0$（虚地） | $u_P = u_N = u_I$ |
| 比例关系 | $u_O = -\dfrac{R_F}{R}u_I$ | $u_O = \left(1+\dfrac{R_F}{R}\right)u_I$ |
| 能否取电压信号 | 需串 $R$ 提高输入阻抗 | 天然适合，输入端近似断路 |
| 对运放的要求 | 抗共模要求不高 | 要求有较好的共模抑制比 |

三个电路到这里就讲完了。最后再说一句学习的节奏：**第一个电路是抱着学习的态度来看怎么分析；第二个电路就要会自己分析；第三种之后，脑子里就该想它是怎么弄出来的；再往下，就该想自己能不能弄出来了。**

好，我们休息一下，下一堂课我们的速度就要上去了。

## 运算电路的一条主线：从平衡电阻到对数指数
> 对应块：BLK37 | 覆盖分集：P38 | 块标题（分集名）：《37-基本运算电路（2）_4K》

### 平衡电阻之问：我为什么憋了一路没讲

有一件事，我一直憋着没说。

从第一次讲反相比例运算电路开始，电路图上就画着那个 $R_1'$，我一次都没解释过。我一直在等，等有人举手问一句：**为什么这里要有一个 $R_1'$？**

书上有答案。但书上不会告诉你，这答案本来就是个问题。今天到下课之前我把它提出来——你们谁回答？

先摆一个事实：**没有 $R_1'$，这个电路一样活。** 你想想，没有 $R_1'$ 的话，$u_i$ 不正好直接给了 $u_P$ 吗？有了 $R_1'$，不也是 $u_i$ 给 $u_P$ 吗？两种接法，信号路径上看起来没区别。那为什么还要多这一个电阻？

要回答它，得先把那个"近似"掀开。

我们一直说运放的输入电流近似为零。这话没错，但它约掉的那一笔，是实实在在存在的——**偏置电流**。你们读过运放的指标吧？有可能读了，有可能忘了，有可能压根没读。好几种选择，反正它存在，很小，非常小，但存在。

那它在哪儿起作用？**静态的时候。** 什么叫静态？置零。把信号源置零，把所有的交流都置零，剩下来的就是它。

```text
   Static analysis: sources zeroed, R and R_F both land on ground

        +--/\/\/--+
        |         |
   ---->+--->     +-------->   to the rest of the circuit
        |         |
        +----+----+
             |
        u_N = I_B * (R || R_F)     current -> drop -> u_N lifts up


   Non-inverting side, with no R_1'

   ---------------+
                  +---   no resistor: current flows, but no drop
   ---------------+
   u_P = 0


        u_N != u_P    ==>   static error
```

偏置电流是从运放内部**流出来**的，两个输入端都有。

先看流出来的电流都一样的情况——先不说两路流出电流本身就有差异。电流从反相端流出来，能去哪儿？置零之后，$R$ 和 $R_F$ 都落地了，所以反相端对外呈现的就是 $R$ 并 $R_F$。电流从这里流过去，就在上面压出一个压降，$u_N$ 被抬起来了。

同相端呢？如果没有 $R_1'$，那里直接连着地。虽然同样有电流流出，可它没有电阻，没有压降，电位还是零。

于是 $u_N$ 和 $u_P$ 之间就出现了一个差值。这个差值对后面的电路运算来说就是一个**静态误差**——不太好。

> **定义**：$R_1' = R \parallel R_F$，称为**平衡电阻**。它让同相端与反相端的接入电阻相同，偏置电流在两侧产生的压降相同，把那个静态差值抵掉。

```text
   With  R_1' = R || R_F  inserted

        inverting side:    I_B  ->  (R || R_F)  ->  u_N = I_B * (R || R_F)
        non-inverting:     I_B  ->   R_1'        ->  u_P = I_B * R_1'

        R_1' = R || R_F   ==>   u_N = u_P   ==>   balanced
```

> **易错点**：算平衡电阻，必须回到**静态（置零）**状态去算，不能拿交流通路那套直觉去套。反相端之所以是 $R \parallel R_F$，正是因为置零之后 $R_F$ 那一头也落地了——这一步最容易漏。

所以我在设计的时候，一直要考虑 $R_1'$ 的存在。

### 电压跟随器：$u_o = u_i$ 的那一下

同相这一块讲完了，接下来可就快了。

看这两个电路——我现在问你：$u_o$ 和 $u_i$ 什么关系？**快告诉我。**

$u_o = u_i$。

这两个电路的传递函数**一样**。这就真见点本事了，能飞快地说出 $u_o = u_i$ 我就服你。

```text
                        ┌────────────┐
    u_i ────────────────┤ +          │
                        │            ├──── u_o
    GND ────────────────┤ −          │
                        └────────────┘
```

怎么来的？链条很短，三步：

1. $u_o$ 就是 $u_N$。这敢肯定吧？输出那一路不取负载电流，线上就没有压降。
2. $u_N = u_P$，虚短。
3. $u_P = u_i$，同一路过来的。

三步接起来，$u_o = u_i$。**这就是电压跟随器。** 先不要求你记，后面它会自己跑出来。

### 求和电路：从反相比例里"长"出来

好，下一个问题：**加减运算。**

前面比例已经做出来了，那么加法呢？加法叫什么？**求和。** 所以第一个要看的就是求和电路——反相求和。

别急着看答案，先想思路：你手里有一张反相比例运算电路的图，怎么从它上面"长"出一个反相求和来？

这里有个特别好的概念，我再强调一遍：**在这种集成运放的电路里，用的是同一个概念——两边的电流是相等的。**

顺着这句话往下想：$u_{i1}$ 和一个电流成比例，$u_{i2}$ 和一个电流成比例，$u_{i3}$ 和一个电流成比例。如果这三个电流的和，正好等于反馈那一路的电流——那不就求和了吗？

```text
                         ┌────[R_F]───────────┐
                         │                    │
   u_i1 ──[R1]──┐        │                    │
   u_i2 ──[R2]──┼────────┴─────────┤ −        │
   u_i3 ──[R3]──┘                  │          ├──── u_o
                                   └────┬─────┘
                                        │
   GND ───[R']───┬─────────────────┤ +
                 │
   GND ──────────┴───────────────────────
```

看见了没有？跟我想象中一模一样。你这个家伙贡献一个电流 $i_1$，我再并上一个，它贡献第二个电流 $i_2$，再并上一个，贡献第三个电流 $i_3$。总反馈电流 $i_F$ 等于前面这些电流的和：

$$i_F = i_1 + i_2 + i_3$$

> **结论**：KCL 在这里就是求和关系。整个设计过程的核心，就是这一句。

$i_F$ 通过 $R_F$ 和谁成比例？和 $u_o$。再把 $u_{i1}$ 与 $i_1$ 的比例关系换过来，答案就出来了：

$$u_o = -\left(\frac{R_F}{R_1}u_{i1} + \frac{R_F}{R_2}u_{i2} + \frac{R_F}{R_3}u_{i3}\right)$$

$$y = -(k_1x_1 + k_2x_2 + k_3x_3)$$

看到了吗？**求和**。这就是反相求和电路。平衡电阻呢？**上面四个电阻并联**——$R_1'$、$R_1$、$R_2$、$R_3$。

#### 同相求和：思路一致，只是换个端

同相应该怎么做？把这一堆挪到**同相端**去。思想还是一致的。

同相求和的关键，你可以这样看：我的这几个 $R$，让 $i_1$、$i_2$、$i_3$ 在同相端汇成 $i_4$；$i_4$ 决定 $u_P$；$P$ 就是 $N$；$N$ 和 $u_o$ 成比例。

那 $u_{i1}$、$u_{i2}$、$u_{i3}$ 和 $u_P$ 的关系怎么算？用什么算法？**叠加原理**——它单独作用，那两家伙接地；它单独作用，那两接地。算出比例关系来。

> **提示**：叠加原理的标准套路是"其余置零"：交流信号源置零（短路），不作用的电压源置零（接地）。置零这件事，我们在讲平衡电阻的时候刚用过。

### 加减与差分比例电路

加减到这里就水到渠成了。既然是叠加原理，那我只要**同相端和反相端都参与叠加**，就会出现加减。

具体怎么定符号，我现在不算了——真算还真有点麻烦，反正慢慢算。我只问一个定性的问题：在最终那个 $u_o$ 里面，$u_{I1}$、$u_{I2}$、$u_{I3}$、$u_{I4}$ 这四个量，谁是正号，谁是负号？

$u_{I1}$、$u_{I2}$ 是负号；$u_{I3}$、$u_{I4}$ 是正号。也就是说，$u_{I3}$、$u_{I4}$ 去减去 $u_{I1}$、$u_{I2}$——就是这样一种关系。

如果把输入搞少一点，这就是它的算法。反正都是叠加原理。把输入减到最少，$u_{I1}$ 和 $u_{I2}$ 一个减法，减法就是**差分**。这个差分电路，你们觉得好不好？

如果要真做到一个绝对干净的差分，就得做成图中所示：整个电阻都匹配，两个 $R$ 一样，两个 $R_F$ 一样，这样算出来是 $u_{I2} - u_{I1}$ 这样一种关系。

好不好？好在哪？不好在哪？不好在**输入电阻**。

$u_{I1}$ 的输入电阻还算比较大，对不对？但 $u_{I2}$ 就麻烦了。因为 $R_F$ 的存在，$u_{I2}$ 的输入特性被破坏了。把 $u_{I1}$ 那边置零，问你：$u_{I2}$ 的输入电阻是多少？

$R + R_F$。后面是短路的，相当于 $R$ 和 $R_F$ 直接串起来，不大。**如果没有 $R_F$ 的话，它一下就变得很大。**

> **易错点**：差分电路里"输入电阻大"这句话，是只对 $u_{I1}$ 说的。别把两侧当成一回事。

所以真用差分的时候，就得有个解决方案：我希望这两个输入的输入电阻都非常大。有没有主意？最简单的方案——前端用**两个电压跟随器**。同意不同意？输入电阻都可以变大了。这是最简单的解决方案。

当然，真用起来没那么麻烦。你看人家给的这个方案：这儿用一个**同相比例**，使得这一块的输入电阻非常大，然后这里直接输入——就这样做出了一个**高输入电阻的差分比例运算电路**。

### 微积分：手里有什么元件，就能造什么电路

好。到这里，比例、加法、减法都实现了。下面该什么呢？**微积分。**

先别急着算。先想一想，前面这些电路最关键的一点是什么？

刚才无论加法、减法、比例——它们最关键的一点，都是**比例**。加法、减法里用的无非还是比例，还是 $k_1x_1$ 那一套，只不过把比例再用 KCL、用叠加原理，给它变成了加减。所以它们全都建立在比例的基础上。

那为什么它们是比例？因为我选的那个元件，电压和电流之间的关系就成比例关系——**电阻**。

现在要做微积分了。你脑子里应该已经有想法了：**如果我能找到一个元件，它的 $u$ 和 $i$ 之间的关系是微积分关系呢？** 好比说

$$i = K\frac{\mathrm{d}u}{\mathrm{d}t}$$

我找到这样一个元件，整个电路我就可以设计了。

怎么设计？让我的 $u_i$ 和这个 $i$ 成比例，让我的 $u_o$ 和它的 $u$ 成比例，那我实现的是什么运算？**积分**。反过来，反之，就实现**微分**。

问题来了：你怎么让 $u_i$ 和这个 $i$ 成比例？很简单，用刚才那种电路传过去。我只要让 $u_i$ 在这，这块放一个电阻——电阻不就是比例关系吗？——然后就生成一个 $i$。这 $i$ 就成比例了。然后我把这个元件放在那，这个电流就流到元件里去了，这个元件两端的电压自然是 $u_o$。

想法简单吗？换句话说：**我手里有什么元件，我就能造出什么电路来。** 现在你们能明白什么叫实现积分、实现微分了吧？只要手里有电压和电流之间关系成微积分关系的元件，你就能用集成运放去实现。

这 $K$ 是什么呀？$C$。**电容。**

#### 积分电路：真正的三角波是这么来的

还记得吗？在基本电路里面，我们也讲过微积分电路。当我们讲完高通、低通这些东西的时候，后面肯定有一个用 $RC$ 构成的微积分电路。

但那种微积分是一种**近似**的。充电、放电是这个形状，虽然近似于三角，但它是有弧度的，波形是这样的。

现在我们要做**真正的积分**了。它应该长成这个样子，充电、放电就应该这个样子——直线。

换句话说，为什么我们都是同样用电容，为什么我们能做到这一点？因为我给它的是**恒流充电、恒流放电**。这是它厉害的地方。它电容上的充电电流是谁决定的？是由 $u_i$ 和 $R$ 决定的。

那么你脑子里构想一下，积分电路应该长什么样？想好了啊，我们要揭谜底了。

```text
                 └─[ C ]────────────────┐
                      ┌─────────────┐   │
         ┬────────────┤ +           │   │
         │            │             ├───┴── u_o
   u_i ─[R]──────┴────┤ −           │
         │            └─────────────┘
         │
       [ R' ]
         │
   GND ──┴──────────────────────────────
```

$u_i$ 和这个 $i_R$ 成比例——所谓 $u_i$ 和 $i_R$ 成比例，就是和 $i_C$ 成比例。然后电容 $C$ 上的电压等于 $-u_o$。这样一来，$u_o$ 就等于 $u_i$ 的一个积分，其实是等于 $\frac{u_i}{R}$ 的一个积分：

$$u_o = -\frac{1}{RC}\int u_i\,\mathrm{d}t$$

> **提示**：如果这个积分是定积分，里面可能有初始值——电容上本来存着电荷。初始电压是积分的常数项，实际工作里别忘了它。

#### $R_F$ 在这里干的是保护

那下面就有一个问题：**为什么还要加这个 $R_F$？**

$R_F$ 在干什么？它在**保护**。

那个电容如果一个劲地往里冲，会怎么样？会饱和的。冲啊冲啊冲啊冲，**总有一天它是冲不进去的**。什么时候冲不进去了呢？我输出的 $u_o$ 饱和了。到了输出 $u_o$ 饱和的时候，电容两端的电压就再也涨不上去，这时候它冲不进去了。

但是真的到饱和了，对我电路是不利的，对运放是不利的。为什么？它一旦进入饱和之后，你要给它一个退饱和的过程，**会影响它的速度**。

所以一般说来，我不会让它进入。要保证速度的话，我不会让它进入饱和区。这时候加上 $R_F$ 是什么作用？当超过一定值的时候，$R_F$ 就起作用了，让 $u_o$ 不会超出 $-\frac{R_F}{R}u_i$，不会超出这一点。所以它起这样一个保护作用。

> **结论**：积分电路里的 $R_F$ 不是用来"改善性能"的，是用来兜底的。去掉它，$u_o$ 会一路冲到饱和，而且退不出来。

我们可以看到它这个非常漂亮的波形：我用一个方波来充电的话，如果输入是个方波，它就会变成这样。如果输入是这样的话。当然，这个不会无穷无尽地下去——我如果就是一个直流 $u_i$ 的话，它不会无穷无尽下去，它会饱和的。**注意一点啊。**

```text
   u_i  (square in)                 u_o  (triangle out)

     +---+    +---+    +---+            /\        /\        /\
     |   |    |   |    |   |           /  \      /  \      /  \
   --+---+----+---+----+---+--- t      /    \    /    \    /    \
                                   /      \  /      \  /      \
                                  /        \/        \/        \
                                        t

     + step  ->  - ramp ;  constant current  ->  straight lines
```

这一块很有意思。有意思在哪，我问你们？**第一点，我们从它们身上看到了真正的积分。**

然后你们又发现哪个有意思的东西能看懂吗？——**反相**。对，因为我们在反相端输入。

它有个很关键的地方：上面是方波，下面是三角波。你们都没有感受到啊——它实现了**波形变换**。太明显了。

这是一个思想，到后面你会知道的。**第八章用的就是这玩意儿**，懂我的意思吗？第八章里用的就是这玩意儿。你们要觉得这个简单，后面一切 OK 了，知道吧？

然后在这里非常关键的一点：这个充电时间、放电时间都是**线性**的。我很容易算出来。充电时间、放电时间能不能算出来？都能算出来。电容的电压，和充电电流之间是什么关系？

$$\Delta q = \Delta u \cdot C = I \cdot \Delta t$$

**充电电流是恒定的**，这一点注意。你的 $\Delta t$ 是求得出来的，$\Delta u$ 对应的 $t$ 是求得出来的。如果你知道 $\Delta u$：

$$\Delta t = \frac{\Delta u \cdot C}{I}$$

> **易错点**：别把电容搞糊涂。$q = Cu$，这是电容的定义式，不是"大概差不多"。

#### 微分电路：一个急性子，得防它咬人

好，微分电路。微分电路该长什么样？

这回，$u_I$ 要和那个 $u_C$ 成比例了吧？那 $u_I$ 怎么和 $u_C$ 成比例？把电容取代谁的位置？**刚才 $R$ 的位置。** 然后让我的 $I$ 和谁成比例？和 $u_o$ 吧。那谁取代谁的位置？原来那个 $C$ 的位置，变成**电阻**。

```text
                 └─[ R ]────────────────┐
                      ┌─────────────┐   │
         ┬────────────┤ +           │   │
         │            │             ├───┴── u_o
   u_i ─[C]──────┴────┤ −           │
         │            └─────────────┘
         │
       [ R' ]
         │
   GND ──┴──────────────────────────────
```

看到了吧？微分电路。好推多了。

但是有一点要提醒大家注意：**这并不是一个非常好玩的东西。**

我说最简单一点。积分没问题。积分是个**慢**性质——积分是个稳定环节，它滞后，它慢。你看电容这样积分，数字积分是什么？我算前面的平均值，从历史数据当中算平均值，慢慢算，它总归是滞后的那个东西，它是个稳定的。

微分呢？微分是什么？**急性的，快速动作。** 它是加速系统。

什么意思？看着一点趋势，它就当大的东西了。你本来稍微有那么一点苗头，它就认为你垂直 90 度上升了；你稍微往这儿歪一点点，它就认为你瞬间下降了。

有点像股市。你如果去看当日的曲线，你在看每分钟的曲线，每分钟的曲线你看，"欻！"这样往下走了——你如果用微分去看它啊，大跌。但是你如果慢慢积分的话，你看，虽然上下震荡，它最后是上行的。微分是把前面那一点点东西放大成大的东西，积分是把前面的数据都积起来。

> **易错点**：$u_I$ 如果是一个阶跃，在阶跃的那一瞬间，$i_C$ 趋向于无穷。确确实实理论上的阶跃，$i_C$ 应该是一个**冲击**。

当然不会出现这种理想的东西。但我完全可以做到接近：一合闸，这个电容上的电流特别大。特别大，它电流逃哪儿去了？没地方逃，全给 $i_R$。

这时候 $i_R$ 会怎么样？轰一下，变成一个非常大的电压，一下子就把这个运放干饱和了，而且干到**深度饱和**，搞不好还让它**闭锁**掉——从饱和里出不来了，被打晕掉了。除非你把电给断了，它才出来，它内部可能就闭锁了。

所以这种现象你不能让它出现，知道吧？否则你合闸就完蛋了。

这时候就要给它一个保护电路。人们怎么保护？我最简单一点：**我让 $R$ 上的电压不过大。** 有没有办法？咱们第一章学的绝对不是吃素的——**稳压二极管**。对。

在这个 $R$ 的两端并一个稳压二极管，电压就被控制住了。然后再加一个电容，并联在同一个 $R$ 上——那个电容干什么用的？**相位补偿**，相位补偿用的。这是一个滞后环节，防止这个家伙进入自激振荡。

```text
   All of these sit in parallel with the feedback R:

        +-----[ R ]-----+
        |               |
        +-----|>|-------+   ZD  clamps the voltage on R
        |     ZD        |
        +-----||--------+   Cφ  phase compensation, a lag link
              Cφ
```

保护做得很周全。好，那么这是个微分电路。

### 对数与指数：给我一个支点

我问你们，**对数、指数**，你们现在觉得有没有希望啊？该怎么做啊？

要说这个，我要搬出一句话来：**给我一个支点，我能撬动地球。** 谁说的？阿基米德。

用在电路上是一模一样的：你给我一个元件，只要它的电压和电流是**指数关系**，我就能给你做出指数、对数电路来。没错吧？

我们有没有这个元件？有——**二极管**，或者 PN 结。二极管的电流和它的电压之间，是不是一个指数关系啊？如你们所愿。

> **易错点**：不要以为真能做出这么好的一个指数电路，这个还是有要求的。

#### 二极管够用，但有两个硬约束

第一，如果你放二极管在这儿，$u_I$ 能不能小于 0 啊？小于 0 你就死掉了。这回真不开玩笑——这玩意儿不能倒着流。一定是 $u_I > 0$。

第二，$i_R$ 实际上要做到这样一个对数运算，它的**区间很小很小**。为什么？因为 $U_{BE}$ 本身就没有很大的变化区间。$U_{BE}$ 有很大变化区间吗？不要以为对数什么都实现了，"啊我能实现几十伏的对数"，瞎扯。除非你再进行放大。

#### 三极管把动态范围撑开

那么二极管有的时候——就是说输入电压的动态范围实际上不够大——那么我们就经常用什么来取代它呢？**三极管**。

看，三极管这里：如果我这个 $\alpha$ 近似于 1 的话，那么 $i_C$ 就是这儿，$i_C$ 就是我这个 $i_0$。

那 $i_C$ 实际上就是 $i_E$ 了，对不对？$i_E$ 和 $u_{BE}$ 之间什么关系？**指数关系。**

而 $u_{BE}$——同学们看看，这不就是 $u_{BE}$ 吗？$u_{BE}$ 就是谁啊？**负的 $u_o$。**

所以：$u_o$ 和这个 $i_E$ 成**对数**关系。然后 $i_E$ 和 $i_C$ 相等，$i_C$ 又等于 $i_R$，$i_R$ 又和 $u_I$ 是比例关系。所以 $u_o$ 和 $u_I$ 是对数关系。

**指数就更简单了**：把这个放前面。看到吗？具体怎么做我不管，你看得出来就行。

现在你们看到这是一种构成形式。

#### 反函数：把积分器接进反馈

那么另外一种构成形式，非常优秀的构成形式在哪呢？

看到了吗？这叫**反函数**，或者叫**逆函数**。

你们觉得夸张吗？我现在问你们啊——**你不要看底下那个鬼东西**，就看上面这一块。我问你，这是什么电路？**积分电路。**

看到了吗？很简单的一个积分电路。现在它接成反馈之后，同学们你看到什么呢？

我的输出 $u_o$ 和我的 $u_I$ 成比例。没错吧？很清楚的比例吧？能看出来了吧？因为 $i_1$ 是等于 $i_2$ 的。

而我的 $u_o$ 和谁成比例呢？我的 $u_o$ 就是这儿的 $u_I$，就是积分的那个 $u_I$。$u_o$ 是 $u_I$。然后我对面那个 $u_I$ 是那个 $u_{o2}$。那我新的这个 $u_o$ 和 $u_I$ 之间的关系，是不是正好倒过来了？

**就把积分变成了微分。**

这是常用的一种方法啊。同学们看，**反函数**：输出、输入一个，用反馈来做一个大调个儿。

## 从元器件函数到反函数：运算电路的设计思路与模拟乘法器
> 对应块：BLK38 | 覆盖分集：P39 | 块标题（分集名）：《38-运算电路设计思路与模拟乘法器的应用_4K》

### 解题很简单，设计才是真本事

上节课我们学习了运放电路。实际上我一再说，解题是很简单的事情，对吧？你只要掌握了虚短、虚断，剩下就不是问题。剩下再有问题的，就是说我就推到基本电路理论的概念上了。再有问题真就是基本电路理论，不是模拟电子技术。

你们觉得这一部分应该说是比较好理解。我希望你们上节课学到什么，听得懂吧？我讲的书上没有这种思想——是什么？这些电路是怎么样构成的，对不对？那么构成的思路是什么，这个很重要。实际上一个电路你都会去设计了的话，分析就不在话下。

> **结论**：会设计就不会怕分析。这一讲真正要拿走的不是"某类电路怎么算"，而是"面对一个我手上还没有的功能，我凭什么想到它应该长成那个样子"。分析是别人把电路摆在你面前你顺着算；设计是你面对一句功能描述从零把电路画出来——后者难得多，因为连"从哪儿下手"都没人告诉你。

---

### 第一种思路：手里有个元件，它的端口关系就是设计的依据

按电路分好多好多组，从大的一块，我详细地讲了一种，然后快速地带过了最后一种，总共两种。

第一种思路是我们找到一个元器件，对不对？找到一个元器件。这个元器件两端的电压和当中通过的电流之间的函数关系，是我们设计电路的一个依据。也就是说，我们整体上来说，我找到了元器件，好比说总共用了三种元器件。

| 元器件 | 两端电压与其中电流的关系 | 性质 |
| --- | --- | --- |
| 电阻 | $U = I \times R$ | 乘积关系 |
| 电容 | $i = C\dfrac{\mathrm{d}u}{\mathrm{d}t}$ | 微积分关系 |
| PN 结 | $i \approx I_S\left(e^{u/U_T}-1\right)$ | 指数关系（只能约等于） |

PN 结这一条要注意措辞：它是一个指数关系，只能说约等于，后面它得有一个 $-1$，然后也是约等。所以它从一开始就不是一条能随手拿到精确值的直线式子——而这恰恰是它好用的原因。正因为有那个近似指数，我们才拿它做对数和指数运算。

#### 用虚短虚断把元件塞进运放：电流是传递的媒介

有了这些关系之后呢？我们用"虚短"这个概念，虚短和虚断的概念。一个运放，我用虚短和虚断的概念，就可以构造出什么呢？好比说我这里就可以构造进去元器件。反正这块是个元器件——**不能把它看成一个电阻的概念，这是个元器件**。

```text
             ┌────────────────────────┐
   u_I  ────►│      ┌──────────┐      │────► u_O
             │  ───►│ 元器件盒 │───►  │
             │      └──────────┘      │
             │      i    =    i'      │
             └────────────────────────┘
```

它的基本概念大家可以看到：这里的电流和这里的电流是相等的，对不对？我用电流进行传递。是这样一个概念吧？我用电流进行传递。

这句话是第一种思路的枢纽：虚断保证电流不被运放"漏"走，所以电流必须被顶进元件；虚短保证反馈端的电位被钳住。于是元件在中间当的是一台"电压—电流"翻译机，进来的是电流，出去的是电压。

#### 同一条规则，四种结果

如果用的是**电阻**这个元器件，我输入端的电压和这个电流成正比、输出端的电压和这个电压成正比的话，那么我构成的是一个**线性关系**，对不对？

在**电容**这块就更清楚了。如果我输入端的电压和电流成正比、输出端的电压和电容电压成正比的话，我构成什么关系？**积分关系**。这里是和 $U_o$ 成正比，这里和 $U_i$ 成正比，就有积分关系。倒过来就怎么样啊？**微分关系**。看到吧？

**PN 结**这边同样道理。我 $U_i$ 和 $I$ 成正比的话，我 $U_o$ 和这个 $U$ 成正比的话，我是什么关系？**对数关系**。**指数关系**是 $U_o$ 和它成正比，对不对？$U_I$ 和它成正比，这是指数关系。看到吧？很清楚，它的构成思路非常清晰。

所以电阻给出比例、电容给出积分与微分、PN 结给出对数与指数——这六种看起来毫不相干的功能，用的是**同一张拼装图纸**。加减则不同质：它没换元器件，换的是"电流往哪几个方向汇合"。一个用器件特性，一个只用电路定律，两类合起来才是完整的运算能力。

#### 加减从哪里来：KCL 与叠加定理

至于加减什么乱七八糟的这些东西是什么呢？实际上利用的是 KCL 和叠加定理。

**加**是什么？KCL 就是这个电流等于前端这些电流之和，你不断地往上加元件，对不对？如果构成加减的话那怎么样呢？两个输入端都进，对不对？这边提供同相，这边提供反相，就加减。

这一条和上面三条是不同性质的：加减靠的是电路定律，跟换不换元器件无关。

> **结论**：第一种思路可以浓缩成一句话——**只要找到一个元器件，它满足某种函数关系，我这种函数关系就可以利用集成运放引进来使用。** 有了这种思想以后，你就知道任何函数关系只要能落到某个元器件的端口特性上，就能被集成运放引进来使用。

### 第二种思路：把现成的电路塞进反馈，换来它的反函数

那么除了这种关系，我最后讲了什么东西？是不是讲了它？这也是一个很妙的方法，非常非常棒。

如果我们**已经知道输入和输出之间的关系**——假设我已经拿到一个集成运放的电路，实现的关系是什么呢？这个 $U_o'$ 和这个 $U_i'$ 成某一个函数关系。在有了这个函数之后，这么一个大框框就出来了。

#### 端口掉个儿

如果我用这个东西去做反馈通路——我用它去做反馈通路，看到吧？如果我用它去做反馈通路，我构成这样一个电路。

```text
      ┌────────────────────────────────┐
      │        ┌────────────┐           │
      │        │  原功能块   │           │
   u_o├───────►│ u_i'  F(·) ├─────┐     │
      │        └────────────┘     │     │
      │          ┌──────────┐   ┌─┼─────┼──► 新电路输出

       u_i  ◄─────────┴──（与 u_o' 成比例）─┘
```

读这张图：原来的功能块一个端子都没动，$u_i'$ 进去、$u_o'$ 出来，中间的函数关系还是那个函数关系。变的是**接到谁**——功能块的输入端改由新的输出 $u_o$ 按比例驱动，功能块的输出端又反过来按比例驱动新的输入 $u_i$。两个端子，掉了个个儿。

如果我能建立这样一个关系：让我的 $U_o$ 和 $U_i'$ 成正比，让我的 $U_i$ 和 $U_o'$ 成正比，我会得到什么？我就会把 $U_o$ 带到 $U_i'$ 这边来，把 $U_i$ 带到 $U_o$ 这边来，然后最后形成的关系就变成——新的 $U_o$ 和 $U_i$ 的关系，是一个**反函数关系**。

> **结论**：给你一个函数，你就能构建出一个反函数。原来是给你一个元件，你就能造出这个元件的函数关系，根据元件的函数关系能完成实现运放的这样一个运算；现在反过来，有了函数本身，用同一个电路就能造出反函数。

这跟戴维宁定理、诺顿定理是同一个味道——**都不新增元件，只重新安排已有东西的连接顺序**。指数电路和对数电路正好是这么一对。

#### 从反函数想到对偶：知一必有其二

这样的话，同学们注意，这样你们就有本事了。你们有没有隐隐约约当中感觉到，这中间有一种对偶的关系？

咱们数电里面学过对偶规则，对不对？讲对偶的时候，你难道认为对偶就是这个、这个就完事了吗？你们对偶现在一点都没有感觉吗？那不叫对偶，那叫卡诺图。

它的对偶式是什么呢？会发现我们在数电里面整个学了那些基本规则、学了一大堆公式，这一大堆公式正好是一半一半：这边是这边的公式，这边是这边的对偶式。

这是一个对偶的规则，这是一个对偶的表达。对偶的表达实际上，我认为这些东西都可以扩展。**对偶最关键一点是什么呢？有这一个，必有其对偶的一个关系。换句话说，你知一，有一，就知二。**

在数电里面，由于对偶规则的存在，你证明了一个等式，它的对偶等式必然成立——必然成立。就是这样一个规则。它给我们一个非常方便的用法，就是**知一到二**，从一到二这样一个关系。这是我们最常用的。

> **提示**：我刚才那个好像它不全是对偶，绝对不是。你可以把它简单地看成是用了类似的"知其一、必有其二"的思路，但它**不全是对偶**。这两个东西不一样，别把它们混为一谈。

同样的事情在电路里也有。好比说我们戴维宁定理和诺顿定理——你证明了电压源的那个东西，它就有电流源的那个关系存在，看到吗？建立在这样一个**等效互换**的基础上。所以很多时候我们有这样一个对偶的关系；很多地方你努力仔细去看，它的对偶的关系都存在，你会发现一个类似于普遍的规律。

### 乘除：一笔我早就许诺过的账

那么统统来看，我们现在已经实现了加、减、比例、积分、微分，对不对？现在我问你，我曾经还许诺过什么？乘除，对不对？乘除这样的运算。

就现在的形势，你们能不能构建出乘法电路来？乘法电路，能不能构建乘法电路？你们现在有没有本事构建乘法电路？会不会构建？怎么构建？有没有想法？

我相信你们每个人的反应都是这样的——都很"矜持"，我就自个儿说。那什么？怎么讲？没法做啊。

#### 手里的牌

其实乘除这个事，我在讲对数的时候已经跟大家说明过了。我怎么推导对数的反函数？从那个波特图开始。对数会化加减为什么？为乘除，马上就知道了。

那这是什么呢？我先做加减，做加减作为一个反过去做一个什么？做一个指数，就会变成什么呢？乘除，变成一个乘除电路。

所以我的最基本思想是：如果我算 $u_{I1} \times u_{I2}$ 的话，我手里肯定没有直接的这个乘除电路，对不对？我手里只有加减电路，我手里有指数对数电路，也没说错吧？那么我就用指数、对数和加减去算乘除。

#### 化乘除为加减，再变回来

那么我首先把它求一个什么？把这个乘除求什么？我给它做对数运算，对不对？把它变成什么呢？一个是 $\log u_{I1}$，一个是 $\log u_{I2}$。我这里如果中间放的是**加法**的话，这一加，它就会变成什么？

$$\log(u_{I1} \times u_{I2}) = \log u_{I1} + \log u_{I2}$$

然后我再求个指数的话，得出来的结果就是 $u_{I1} \times u_{I2}$。如果这里是**减法**的话，就变成什么？就变成除法：

$$\log\frac{u_{I1}}{u_{I2}} = \log u_{I1} - \log u_{I2}$$

一句话概括这个套路：**取对数把乘法变成加法，加完之后再取指数还原。** 对数电路存在的全部理由就在这一行里——它的本质是"把尺度换成另一种，让乘法变加法"。中间那一级甚至不需要是真正的乘法器，一个反相求和就够了。

#### 电路框图

那么现在这个结构，你们脑子里能不能出现？跟我们想法一点都没有什么相异的地方，看到吗？两个对数，引出求和了，反相求和，对不对？然后接着来了什么？来了指数。就把那个三极管移到这儿、移到这儿、移到这儿——就是一个是指数、一个是对数，这样一个电路。很简单的。

```text
  u_I1 ──►[ 对数 ]──┐
                    ├──►[ 反相求和 ]──►[ 指数 ]──► u_O
  u_I2 ──►[ 对数 ]──┘

        求和级换成减法：  u_O = u_I1 / u_I2
```

读图：两个对数级分别把 $u_{I1}$、$u_{I2}$ 换成它们的对数，中间的求和级完成相加或相减，最后一级指数把它还原回乘或除的量级。

请注意这三个模块的名字——**对数、求和、指数**，正是前面第一种思路里已经用过的老朋友。乘除电路没有引入任何新的器件特性，它只是把已经有的三种能力重新排了一次队。

> **提示**：这仍然只是一种**思想**。真正在做这个电路的时候，我们当然也可以做，做成一个集成的模拟乘法器。

### 模拟乘法器：先认符号，再读端口等效

对于模拟乘法器，我们仅仅是简介。具体的内部构成电路呢，我们不过多地去研究。有了我们模拟电路的基础，前面一二三章的基础，这部分内容同学们如果自己想知道的话，可以深入一下，是不是？如果你不想要知道的话——**你要会用**。

**第一，电路与符号。** 那么我们来看看，它的电路与符号。这个符号认识了吧？给了一个大乘号，看到吗？$u_X$、$u_Y$、$u_O$。

**第二，等效电路。** 什么意思？同学们能读得懂这个等效电路吗？它表明的是端口的、两个端口的关系吧？一个是输入端口，对不对？一个是输出端口的等效关系，对不对？它是个**端口等效**。

```text
        Δu_X                                 Δu_O
      ┌──/\/\/──┐                     ┌─────────────┐
      │   R_i   │                     │      R_o    │
  ────┤         │                ┌────┤     /\/\/    ├──►
   u_X┤         │                │    └──────┬──────┘
      └─────────┘                │           │
                                 │   ▷ u_o   │
                                 │  受控电压源 │
                                 │  K·Δu_X·Δu_Y│
                                 └───────────┘
```

在这个输入端口上怎么样？$u_X$，这个 $\Delta u_X$，它相当于有个输入电阻什么？$R_i$，对不对？然后输出是一个**戴维宁模型**——戴维宁等效的戴维宁模型。

其中里面的电压源**并不是独立电压源**。如果是独立电压源，我们就没戏了，对不对？$U_i$ 和 $U_o$ 没有任何关系了。所以一定是一个**受控源**。

> **结论**：这个受控电压源所表明的，恰恰就是我们需要的乘法关系。所以这模型一定是这样的，猜都猜得到。

这一条值得停下来体会：受控源不是画图的人随手加上去的记号，它是"输出必须依赖输入"这件事在电路语言里的唯一合法写法。任何带运算功能的器件，它的等效模型里都必须有受控源——运放如此，模拟乘法器也如此。然后当然电压源有一个内阻 $R_o$。

#### 理想的模拟乘法器应该是什么样

下一个问题我就提给你们了：你们心目中的理想的这样一个器件，就说你说了算，如果你用起来方便的话，它的理想条件是什么？你来说一说理想条件，你愿意怎么用起来？

好，同学们看——**输入电阻无穷大**，对吧？非常好。然后呢？**输出电阻很小**，对不对？就是 $r_o$ 趋向于 0。是不是有感觉了？因为这样用起来，我们目标就是要真正实现 $\Delta u_O = K \cdot \Delta u_X \cdot \Delta u_Y$。所以，你想的这两点都很重要。

那么这里面还有一个值，有影响的概念上：我们刚才说这个 $r_{i1}$、$r_{i2}$ 最好是趋向于无穷，$r_o$ 最好是趋向于 0。然后这个 $K$ 值，其实这个 $K$ 值如果在实际情况下它并不是一成不变的，对不对？所以我希望它怎么样？**一成不变**。看温度一变就变得很大，那东西就没得玩了。所以 $K$ 值要趋向于恒定，这是我需要的。

然后另外呢，你们学过了运放的那些参数吧？**失调电压、失调电流**，这些东西统统为零。那些干扰、噪声统统为零。实际上电路很难做到，我们只能努力地向那个方向去争取，做就是了。

> **结论**：构成这样一个理想的模拟乘法器之后，如果真到了理想，最终就什么关系？放心大胆地用，$\Delta u_O = K \cdot \Delta u_X \cdot \Delta u_Y$。

把理想条件列全，其实就是一句话：**除了乘法的增益，其他一切副作用都消失。** 这也解释了为什么"理想"两个字在推导中如此重要——理想条件下画出来的电路是骨架，真实器件只是往这个骨架上贴误差。

#### 三类乘法器：象限与输入约束

那么这样的一个乘法器的话，我们在用的时候，大家想一想，在做电路的时候，这里面肯定会用到有些电路会有反馈或者这些东西。所以有的时候它会对输入极性……包括我在做的时候用那个元器件，它会限制我输入的极性的组合。

大家可以看到，我现在 $\Delta u_X$、$\Delta u_Y$ 有几种组合方式？第一种是两个都是正的；第二种是一正一负，一正一负有两种组合方式，要么 $X$ 正，要么是 $Y$ 正；第三种是两个都是负的。有四种组合方式。四种组合方式我可以给它分成正好是**四个象限**，第一象限、第二象限、第三象限、第四象限。

一般说来，我们这种模拟乘法器可以有**三类状态**：一个是第一象限，一个是两象限，一个是四象限。

> **结论**：模拟乘法器并不是都一样。有的模拟乘法器对输入是有约束的。好比说如果单象限，只允许工作在第一象限，它对输入的约束就是那两个值要是全都是正的——你要用其他的它就不工作了。当然四象限用起来最方便，对不对？没有任何约束。

### 应用一：平方、三次方、四次方

在这样一个条件下，使用模拟乘法器，使用起来就很简单。

#### 平方运算

第一个电路，**平方运算**。都不用说，简单的一塌糊涂，真的简单的一塌糊涂。

平方运算。我问你，怎么接？就刚才那模拟乘法器怎么接能变成平方运算？把两个输入端怎么？**短接在一起**，然后给同一个信号。结束了，平方运算，看到吗？

```text
        ┌──────────────┐
  u_I ──┤              ├──► u_O = K·u_I²
        │   模拟乘法器  │
  u_I ──┤              │
        └──────────────┘
```

这是整讲里唯一一个"想都不用想"的电路——因为 $u_X = u_Y$ 时，$K u_X u_Y = K u_I^2$，乘法器自己就完成了平方。

#### 三次方和四次方：级联

然后三次和四次方呢？脑子里想想应该长成什么样。三次和四次方怎么长成啊？**一级能解决问题吗？不能吧？得两级**，对不对？两级应该怎么解决？

那么这样一个电路，他说再加一级，看到吗？再加一级。如果**四次方**的话呢？直接连——把上一级的输出接到下一级的两个输入端。如果是**三次方**的话怎么弄呢？就是把这个拆开，其中一个端子接到上一级去。

```text
  平方级 ──► 平方级          ⇒  u_I⁴

  平方级 ──┬──► ×(u_I) 级     ⇒  u_I³
            └── 一路直接取自输入
```

所以四级幂就是两级平方级串起来，三级幂则是"平方级 + 与原始信号相乘"。差别只在一根线接到哪里，但**结构上的迁移思路是同一个**：想 $n$ 次方，就把指数拆成几个小的、能用乘法器实现的指数，再串起来。

### 现实：乘法器是有误差的，级数不能太多

那么这里我要给大家提醒一点，什么呢？实际上模拟乘法器它是有误差的，**越乘越是有误差**。

我们刚才上来先讨论理想，对不对？有了理想的概念之后，我们再讨论现实，往往就简单。现实是什么呢？每一级它都有运算的误差，它并不是真的完全等于遵循这样一种关系，看到没？$K$ 会动，还有失调电流、失调电压造成的影响，还有输入、输出电阻的影响。这些误差因素前面列理想条件时全都出现过——**它们不会互相抵消，只会一级一级往下传。**

接下来我有一个问题就提出来了：那么我这样的话，我的 $n$ 次方怎么弄？不用非常大，$n = 10$。10 次方怎么弄？

没关系，但是提出这个思路肯定是有定论的。用**指数电路**来解决问题。如果我们用乘方电路的话，要好几级。用模拟乘法器的话，**大家记住，最好不要超过三级**。超过三级的话，它的误差一步一步地被放大，最后就根本表现不出那种乘方关系。

> **易错点**：三级不是精度损失的起点，而是"乘方关系还算不算得出来"的终点。四级乘方电路在理论纸上永远成立，在实际元件上只是一堆误差的乘积——误差自己也在一级一级地相乘，其增长速度比信号本身还快。

### 应用二：$n$ 次方——用指数电路把级数压到两级

所以现在就又想到了指数和对数。我说指数对数是很好的一个东西，它随便什么东西都可以算。**乘法电路实际上算不了 $a^x$ 这种**，完全用乘法器的话，很难去算 $a$ 的 $x$ 次方。但是你要用指数和对数的话就没有问题。

所以整个构成的思路就如同：如果我要算这个 $u_i$ 的十次方的话，我先把它怎么样？先把这个家伙做一个**对数**，对不对？先把这个 $u_i$ 做对数，然后用一个乘法把它乘起来——也就是说，10 乘以它。乘法完了之后呢？再去做**指数**。

```text
  u_I ──►[ 对数 ]──►[ ×10 ]──►[ 指数 ]──► u_O = u_I¹⁰
```

你多少次方都没有问题了，当然只要在我们的限度之内。

看到了吧？就是说这种想法：**先把 $u_i$ 做一个对数，然后把 $n$ 次方给它乘上去，然后再做一个指数。**

请和前面那个乘除电路对照着看——它们是同一个模板：

| 需要实现的运算 | 前段 | 中段 | 后段 |
| --- | --- | --- | --- |
| $u_{I1} \times u_{I2}$ | 两个对数 | 求和（加） | 指数 |
| $u_{I1} / u_{I2}$ | 两个对数 | 求和（减） | 指数 |
| $u_I^{\,n}$ | 一个对数 | 比例（$\times n$） | 指数 |

三行的骨架都是"**换尺度 → 在新尺度里做最简单的线性运算 → 换回来**"。这就是这节课唯一需要反复念的一句口诀。

> **结论**：同学们注意啊，我一再强调一点，你学的是一种**思想**。看到吗？就是这种电路的构成思想。

### 应用三：除法电路——照葫芦画瓢的迁移

下面提出一个问题啊，我来看你们到底感受到了什么。

**不要看书**，我先问你：除法你们怎么去算？怎么样构成除法电路？也就是说我怎么能构成，好比说 $u_o$ 等于什么 $u_{i2}$ 除以 $u_{i1}$，对不对？前面最多有个 $k$。我怎么来实现这样一个东西？我怎么实现这个东西？有没有想法？怎么实现这样一个电路？

我们手里有除法器吗？**我们手里没有除法器，我们手里有什么？乘法器。**

乘法和除法是什么函数关系？**反函数的关系**，对不对？我们实现不了这个……但是我们能实现什么东西。这个东西我们现在有本事实现它吧？注意啊，我说用是什么**迁移性的东西**用过来。

#### 第一步：先照着目标关系摆位置

那用反函数我们去构造它的话，现在脑子里你们在想：如果给我一个电路，我用反函数去构造它的话，我该如何构造？

你看它的思想是什么？$u_I$ 和上面反函数的 $u_{O2}$ 是成比例关系的，对不对？然后我这边的 $u_O$ 是和那里的输入 $u_I$ 成比例关系。那么我把乘法器往这一画，画大号：

```text
        ┌──────────────────┐
  u_i1 ─┤  u_X          u_Y├──────────► u_O(乘)
  u_i2 ─┤   模拟乘法器      │             │
        └──────────┬───────┘             │
                   └──── 回接成 K·u_O(乘) ┘
```

读图要说清楚：这个是乘法器的输出，这是乘法器的两个输入。$u_{i2}$ 就是那个**被除数**，$u_{i1}$ 就是**除数**。我输出的 $u_O$ 应该是乘法器的一个输入，从这里读出来了吧，是我乘法器的一个输入，另外一个输入就进去了。总结起来就是：**我被除数是乘法器输出的一个比例关系**。

> **结论**：这样我们就可以构成除法电路。你发现这两个东西简直是惊人的相似，看到吗？**这就叫迁移**——这种思想迁移到解决这个问题来。我觉得这还是小迁移，这简直就是**照葫芦画瓢**似的这样一个迁移方式。

#### 第二步：把照葫芦画瓢真的做出来——然后发现它有问题

那么这里面实际上拿过来真的就这么能用了吗？绝有的时候我们开始做一做，就会发现：呦，它有问题的。

仿照我们现在的思路都是：这里默认了一点是什么？**这个反馈肯定是负反馈**，对不对？——这不一定。现在关键点：刚才那个积分电路肯定是没有问题的，它本身肯定会构成负反馈。这个假定不一定。**这个乘法器到底能不能构成负反馈？**

所以，你构成这样一个电路，你马上接着想：**它的使用条件是什么？**

看到吧？你要给订人家的标准使用手册。不是说你给人家产一个汽车，说这玩意儿能当飞机用，连翅膀都没有。这个东西有**使用条件**的，对不对？就是说你不能说正常汽车往水里开一样，当潜艇去吧，开着开着淹死了。

#### 第三步：按负反馈逐条分析，推导使用条件

在这个使用的时候我们来看，分析一下这个东西，按负反馈来分析，对不对？一个瞬时的正进去吧，然后这是瞬时的负出来。你希望——现在我们只能提希望，对不对——你希望这里出什么呢？瞬时的负。

**它可没答应。** 它仅仅答应你这块出来的是 $k$ 倍的……不对，$k$ 倍的 $u_{I1} \cdot u_O$，没错吧？

关键点在哪？$k$ 倍的 $u_{I1} \cdot u_O$，你要保证它是**大于零**的。它如果小于零你不就死定了嘛。$k$ 倍的这个东西如果一旦小于零的话，你出来的就成正了，这时候你**变成正反馈了**，轰的一声就上去了。

一般来说，你选中了乘法器之后，$K$ 就定了：

- 如果 $K > 0$，那么要求这个 $u_{i1}$ 就限定了，$u_{i1}$ 就一定是一个**大于零**的东西；
- 如果 $K$ 是小于零的，$u_{i1}$ 就是一个小于零的东西。

就是这样一种概念。**所以它是有条件的，别什么东西都拿来用。**

> **结论**：除法电路能构造出来，但它的成立是以"某个输入量必须保持特定符号"为代价的。这个符号条件不是细节，而是负反馈能否成立的前提——一旦破坏，环路立刻从负反馈翻成正反馈，运放一路冲到饱和。

### 平方通吃正负，所以只能靠 K 锁定极性

$K$ 必须小于零。这里就小于零。

为什么是这个要求？因为这里面是平方，对不对？平方的话不管你正负它通吃：

$$
u_I > 0 \Rightarrow u_I^2 \ge 0, \qquad u_I < 0 \Rightarrow u_I^2 \ge 0
$$

你看，$u_I$ 无论取正取负，平方之后一律被拉到正半轴上去，符号信息被彻底吃掉了。既然输入自己的正负号指望不上，那这个电路到底是走负反馈还是走正反馈，就只剩下 $K$ 这一个开关能把关。所以我才要求 $K$ 必须小于零，才能满足这样一个需求。

> **定义**：开方（平方根）电路要面对的，是一个「平方之后已经丢失符号」的输入。反馈极性没法再靠输入符号自动纠正，只能靠乘法系数 $K$ 的符号一次性锁死。$K<0$ 是这套结构能工作的前提，不是可以临场调整的参数。

### K 大于零的代价：它和 u_I 被绑死了

好比说，在 $K>0$ 的情况下，我突然输入这里是正的。当然 $K$ 肯定乘法器一旦选定，$K$ 就选定了，对不对？现在假设我选定了一个 $K>0$ 的乘法器，同学们看到了吗？

### 从二极管温度计说起：为什么需要它

做信号预处理的放大电路，一个预处理用的放大电路。实际上就是在我们电子信息系统里面，做信号的一个预处理。叫做仪表用放大器，仪表放大器。

这里实际上跟大家讨论一个问题。还记得吗？我跟你们讲二极管的时候，我说二极管整个特性曲线哪块都是个宝贝，对不对？正向、反向等等都可以。好比说它正常使用的时候，实际上二极管正向和反向都可以说是一个很好的**温度传感器**，对不对？

记得吧？我说用二极管可以做什么？电子温度计，对不对？

好，今天课文就告诉你们，这个电子温度计你们现在可以去做，可以用二极管去做一个电子温度计。

怎么去做？二极管它的一个特性就是：我这个正向导通的电压会随温度变化，一度好比说 **10 mV** 等等，有这样一个情况。它可以有这样的变化，我们根据二极管的特性去测。

我只要把这个电压变化测出来，代表的就是温度。整个的思路是什么呢？由于二极管两端的电压变化是和温度成一个线性关系，那我只要能够测出来二极管两端电压的细微变化，我就能知道温度。我把这个电压转化成数字、数字化，就是我们温度计显示的数字化。就是这样的关系，很简单的关系。

那么我们这里要用到的技术是什么呢？第一，我要能够把二极管两端的电压变化测量出来，对不对？然后我们要把它怎么样呢？把这个电压再转化成什么？数据量。

#### 难点一：这个传感器的内阻一直在变

那么我要读二极管的这个东西，实际上同学们就发现有一个问题存在。你看二极管如果说你把它当做一个传感器的话，我们知道二极管的电阻，你看它的特性曲线了吧？

说实话，它的这个电阻无时无刻不在变，是不是在变？充分有这感觉吧？它特点这很清楚，对不对？咱们当时就讨论过，为啥咱们说微变的动态电阻咱们可以认为在静态工作点附近不变？是因为动态范围太小了，对不对？我就认为那块是什么？是一根线段。

如果这个静态工作点在那……整个曲线在动的话，那我们知道，二极管两端的等效电阻就是什么？应该是它的**电压比上电流**，是不是？所以，它这个阻值也会变化。

换句话说，我们经常在传感器——因为我们仪表用的放大器等等，它对应的都是这种传感器。很多传感器我跟大家说，它是一个类似于**电压源性质**的，就是它可以输出电压为主的这样一个传感器。

但是，它的特点是什么呢？

第一，电压的信号特别小，**微弱**。上来直接就一百伏，那何妨呢，事情变得很好办。很微弱，这是第一点。

第二点，它的**内阻会怎么样呢？会动**，知道吧，不是那么固定的。输出不同电压的时候，它的内阻它会这样来回变，讨厌。

#### 难点二：输入输出方式决定了必须高输入电阻

这样的话，我们就需要干什么事情？我们就需要把后端的采样的放大电路、后端的运算放大电路里面，要求我们**输入电阻尽可能地大**。

大到类似于断路的状态的话就挺好。你随便前面内阻变，对不对？你怎么变，不大可能会影响你的输出电压，看到了吧？所以这是很重要的原因。

第二点，实际上我们在输出的时候，同学们知道这个输出电压我们都用**差分的方式来输出**，用差分的方式来输出，就是传感器输出的时候。它这种输出的话是**带有共模的**。

差分是什么概念？一个端子 1 V，另一个端子 1.01 V，它有效的其实是什么？

$$
1.01\text{ V} - 1\text{ V} = 0.01\text{ V} = 10\text{ mV}
$$

微伏。不对，是 10 mV。换句话说，甚至可能差模的信号比共模信号还要小得多。这就要求我们后面的组成的仪表用放大器**共模抑制比**要比较高，要不断地提高它的共模抑制比。

> **结论**：仪表用放大器的三个刚需由此而来——**放大微弱信号、大输入电阻、抗干扰（共模抑制比好）**。这三条不是设计者的偏好，是传感器的物理性质逼出来的。

在讲第六章负反馈放大电路的时候，我们讲到了负反馈放大电路的**稳定性**。我说，有朝一日这个负反馈如果产生足够的相移，它将变成一个正反馈；正反馈将产生一种**自激振荡**——你不用给它任何输入信号，它自己逐步地把自己的信号加强。这样就会容易产生饱和，会影响放大电路的工作性能。这个时候自激振荡是非常不好的一种东西。

### 振荡是怎么起得来、稳得住的

#### 星星之火：合闸瞬间那"振"一下

我们来看这样一个框图。大家看，现在这个方框图跟我们讲负反馈的时候有什么区别？

```text
   （a）负反馈：第六章、第七章 —— 拼命想让反馈变"负"
        x_i ─►( Σ )─► x_i' ─►[ A ]─► x_o ─►[ F ]─► x_f ─┐
                 ▲                                           │
                 └──────────────────( − )────────────────────┘

   （b）正反馈：第八章，波形发生 —— 就想让反馈变"正"
       x_i' ─►( Σ )─► x_i' ─►[ A ]─► x_o ─►[ F ]─► x_f ──┐
                 ▲                                           │
                 └──────────────────( + )────────────────────┘
```

差别就在**比较环节的符号变正了**。我们讲负反馈的时候，是想避免它变正，想避免出现那个 180 度的相移；现在在这个电路里面，我就是想让它变正，就是正的。换句话说，没有相移的时候它就应该是个正的，也就是做成一个正反馈——因为它要发生波形，它要做正弦波的发生。

那么对于这样一个电路来讲，大家看：如果我这输出 $x_o$ 产生了一个 $x_f$，然后我的 $x_f$ 又能提供给 $x_i'$，然后 $x_i'$ 又产生 $x_o$——如果能形成这样一个闭环，看到吧？也就是说我输出的 $x_f$ 正好能提供给净输入量，形成这样一个循环，那么我的 $x_o$ 的输出就可以保证了。这样我就能产生一个波形了，能够发生一个波形了，也就是一个正弦信号就可以发生了。

```text
        x_i' ──►[ A ]──► x_o ──►[ F ]──► x_f
          ▲                              │
          └────────────( + )─────────────┘

   自己产生的 x_f 又回到自己的输入端，并且与 x_i' 同相，
   只要 |AF| ≥ 1，这个环就能一直转下去 —— 这就是"闭环"。
```

现在大家可能多少还有一点一头雾水的感觉。如果说你第六章弄得非常明白，其实这里非常简单；第六章没弄明白，我们把这里弄明白了就变得更明白了。就这个概念，是相辅相成的。

**那这个"闭环"到底是个什么感觉？我给你们做一个比喻。** 好比说假设开始的时候 $x_i$ 不是零。我 $x_i$ 是某一个赫兹的，好比说是 $f = f_0$ 的这样一个正弦波信号。$x_i$ 输给 $x_i'$ 了，然后 $x_i'$ 就产生了 $x_o$，$x_o$ 产生 $x_f$。

这个时候我把 $x_i$ 撤掉。就像点火了，点火了，点火了我撤掉了。撤掉了之后呢，这个 $x_f$ 提供给 $x_i'$，这个时候它是一个**正反馈**——注意啊，是个正反馈。回来之后正好 $x_i' = x_f$。然后整个这个，我让它的 $AF = 1$。

$AF = 1$ 什么概念啊？我 $x_i'$ 产生的 $x_o$，再产生的 $x_f$，正好又等于我的 $x_i'$。它就像**永动机**一样不断地这样坚持下去——自己产生了输出，输出又产生了输入，输入又产生了输出，转着玩。

但绝对不是永动机的概念。你想，为什么它不是永动机呢？永动机是自己个儿玩玩玩，它不输出；你现在 $x_o$ 还是输出的。它有外接电源，它有能量的提供者，能量提供者被隐藏了，所以说它能这样一圈一圈地转着玩，而且 $x_o$ 能不断地输出。也就是说 $x_i'$ 就起了一个什么功能呢？**点火。**

特别像汽车的启动马达。以前的那个车是拿手摇的，电影里见过吧，铿铿铿摇两下，呼呼呼起来了。现在不是了，里面有个小的直流电机，一点火那电机欻一转，就给它点起来了。一样，$x_i$ 去点火了。

那接下来就变成一个很有意思的事情出现了。你想啊，我要造一个 $1\ \text{kHz}$ 的正弦波，我就得拿一个 $1\ \text{kHz}$ 的正弦波源去点火。是这个概念吗？按我刚才说这个逻辑，是这个概念吧？我得搞一个东西点完火，点完火之后你可以点下一台去，拿这个 $1\ \text{kHz}$ 你看可以复制出一百台，不断地点火。

你们 $1\ \text{kHz}$ 那个源从哪来的？然后就变成了以前老年人，像我的外公逗我玩的时候，小的时候就问我：先有鸡还是先有蛋？先有蛋还是先有鸡？当然这个问题，反正不管，目前可以用进化论来解释。而这里就说：事先有 $1\ \text{kHz}$ 的那个正弦波电源呢，还是先有那个输出？

那就不是波形发生器了。换句话说，我要问你们，你们用过函数发生器吗？功率函数发生器，用过吧？可以调输出频率的，可以调，你看你这一调就行了。那按这个说法的话，得准备一堆电源给它点火去。**肯定不是这个样子的。**

现在已经给你一个思路了，就是说你有一个小的电源你就能把它点动起来。再往下想是：你不去从外界拿一个电源，你有没有本事做出一个东西来，让它就像你们用的那个东西，可以调节的，输出频率、幅值都可以调节的？有没有这个想法呢？有没有这个办法呢？

#### 选频：只让 10 kHz 越转越大

> **提示**：这里说的"博爱型电路"，就是指放大倍数对所有频率一视同仁、不挑频的电路。既然要挑出正弦波，那就绝不能做成博爱型。

最起始的 $x_i'$ 来源于谁？这是我心中的疑问：最开始的 $x_i'$ 哪儿来？

如果是做一个波形发生器，我肯定不能用其他电源来点火，肯定不能干这事的，干这个事就麻烦了，那就不叫波形发生器了。那关键肯定还是有**星星之火**。那个东西在哪儿呢？

以前给你们讲过这句话，还是在讲稳定性的时候说过：什么呢？你随便把这个东西，只要把这个电路一合、一关闭的瞬间，在 $x_i'$ 上就会有一个**杂乱无章的信号**出现，肯定会有个振动会出现。不管怎么样，反正振一下。

振一下，就这么一个波形出来，也就什么都有了。

同学们知道，把这个波形做傅里叶变换，只要这个连续波形，它肯定能够分解成各种频率的正弦信号的叠加——各种频率、各种幅值，丰富极了，从 $0\ \text{Hz}$ 都有。为什么呢？它有直流分量，直流分量就是 $0\ \text{Hz}$。只不过里面都有大的有小的而已，可能都是甚至微伏的这样一些信号。

**不怕。** 有这样一个东西之后，然后我就开始设计电路。我设计电路的思路是什么呢？好比说你要产生 $10\ \text{kHz}$ 的正弦波，你怎么做？你就要把 $10\ \text{kHz}$ 那个信号从这一大堆信号里给选出来。

不仅选出来，而且是什么呢？**只有这一个 $10\ \text{kHz}$ 的信号能使这个 $AF$ 大于 1，其他信号 $AF$ 都小于 1。**

接下来的事情奇迹就发生了：$10\ \text{kHz}$ 的信号一圈、一圈、一圈、一圈被放大；其他的信号一圈、一圈怎么样呢？衰减。最后 $x_o$ 就输出了一个 $10\ \text{kHz}$ 的正弦波信号。

很关键的一点，大家可以看到，它有一个**选频**，然后这个选频使得我的 $AF$ 是大于 1 的。它的过程就是这样——你不要怕它小。

看看起振的过程：

```text
   幅值
    ↑
    │                                     ╱ ─ ─ ─ ─ ─  不加节制：飞快奔着饱和去
    │                              ╱─────╯
    │                         ╱────╯
    │                    ╱────╯       稳幅电路一旦起作用，
    │              ╱────╯              幅值就被钳在 ─ ─ ─ 这条线上
    │         ╱────╯                      （此时 |AF| 已经回到 1）
    │    ╱────╯
    │───╯   起点：合闸那一下的杂散噪声，微伏级
    └──────────────────────────────────────────────────► 时间

        「转一圈」的含义：x_i' → x_o → x_f → x_i'，完整走一圈
```

开始是很小很小的，转一圈大一点，转一圈大一点，唰就下去了。用不了多一会儿，非常大了——**就出事了**。

你们说是不是出事了？如果不加以节制、不加以控制的话，就出事情了，奔着饱和就去了，飞快地奔着饱和就去了。

#### 稳幅：让 AF 重新回到 1

这时候你肯定不能让它去饱和吧？这时候你要怎么办呢？你一定要让它幅值开始稳定。

幅值怎么样稳定？**让那个 $AF$ 等于 1**，让 $AF$ 去等于 1。也就是说转一转、转一转，你还有个使命是什么呢？让这个 $AF$ 要转到一定程度上让 $AF = 1$。这时候就出现稳定的输出，稳定的输出。

> **结论**：起振靠"放大"，维持平衡靠"不变"。前一阶段要求 $|AF| > 1$，后一阶段要求 $|AF| = 1$。稳幅电路干的就是把这台"越转越大的永动机"用手轻轻摁住在某个幅值上。

### 振荡条件：一个式子拆开是两句话

#### 幅值条件：|AF| = 1 是"维持"，起振阶段要 > 1

刚才我把这件事限定的是什么呢？$AF = 1$。

如果我开始的时候 $AF$ 就不等于 1，还记得我们那个稳定裕度那个时候吗？在讲稳定裕度的时候，我非常希望 $AF$ 怎么样？稳定裕度的时候，我非常希望 $AF$ 是**小于 1** 的，它不震。现在我的目标让它什么？**震！** 让它震的话就怎么样呢？就**大于 1**。

所以同学们注意，从起振的角度来说，就是它要从最微小的信号放大出来，所以起振的条件应该是 $|AF| > 1$，它才能慢慢壮大。而 $|AF| = 1$ 是**维持平衡**的振荡条件。

#### 相位平衡条件：180° 是个大坑

我现在问同学们，还有一种可能：我说 $10\ \text{kHz}$ 的信号 $AF$ 是大于 1，你们认为就能起振了吗？就能起振了吗？

假设我告诉你，$\varphi_a + \varphi_f$ 假设我等于的是 180 度，能起振吗？同学们，能不能起振？

先别急，把参数含义读清楚：

> **定义**：$\varphi_a + \varphi_f$ 是 $x_f$ 和 $x_i'$ 之间的**相位差**；$|AF|$ 是 $x_f$ 和 $x_i'$ 的**模的大小之比**。每一个参数的含义都要读懂。

如果 $AF$ 大于 1，但是**如果**出现这个情况——$\varphi_a + \varphi_f = 180^\circ$——同学们看看，事情就糟糕了。它由**正反馈一跃而变为负反馈**，奔着稳定就去了。

为什么？看这个框图：它转了一圈之后，这个 $x_f$ 和输入是**反相**的，反馈量削弱了净输入量。这就是我们什么框图？负反馈框图。它是负反馈，它不可能起振。

那什么时候能够起振呢？是 $\varphi_a + \varphi_f$ 应该等于 **360 度**，或者说用弧度表示的话是 $2n\pi$，即 0 度、360 度、720 度这些。换句话说，转回来相位是相同的，$x_i'$ 和 $x_f$ 相位是相同的——只有这样它才能不断地加强。

所以整个振荡的产生条件有两个。如果总地写起来，只要这一个：

$$\dot{A}\dot{F} = 1$$

它代表的含义就是能维持这种振荡，代表的含义是 $x_i' = x_f$。再解读开的话，它由两个条件构成：一个是 $|AF| = 1$，这个叫**幅值条件**；一个是 $\varphi_a + \varphi_f = 2n\pi$，这个叫**相位平衡条件**。

相位平衡条件如果我们去判别它的话，其实很简单：**这个电路当中是否存在正反馈**。如果这个相位平衡条件成立的话，也就说明电路当中存在的是正反馈这样一个概念。

### 正弦波振荡电路的组成与判别

基于这样一个想法的话，我问同学们，这样一个正弦波振荡电路，它的基本组成应该是什么？

#### 四个部分，以及它们之间的"共用"

- **首先必须有放大电路**，这是它的核心；
- **第二，反馈应不应该有？** 什么反馈？**正反馈**，它一定要有正反馈。
- 我刚才说了，你怎么把 $10\ \text{kHz}$ 弄出来？**一定要有选频电路**；
- 选完频之后，不能让它一味地去放大吧？**应该稳定它的幅值，所以有稳幅电路**。

这是一个正反馈放大电路的基本组成。

总体来说，一个正弦波振荡电路从构成上来说，有 RC 振荡，有 LC 振荡，还有石英晶体振荡。石英晶体振荡在以后的电路当中用的是比较多的，也就是晶振。但基本原理都是比较类似的。

这里有一个关键点必须提醒：放大电路**可不一定是个开环的**。这个 $A$ 不是开环放大电路，很有可能就是一个比例放大电路，放大一个 10 倍的、15 倍的这样一个电路。它也可以是一个**带有负反馈的放大电路**，有稳定的电压放大倍数。

> **提示**：这里容易搞错。$A$ 这个方框指的是"提供稳定电压放大倍数这个功能的那一块电路"，它可以是一个集成运放，可以是分立元件搭的，也可以是一个带负反馈的稳定比例放大电路。**不要一看到 $A$ 就条件反射地想成运放开环增益。**

所以判别的时候，第一，**组成电路齐全吗**？看各部分是不是都有。

注意，你觉得这一定得有四个电路吗？**有的时候是共用的**，好比说正反馈和选频这两个电路，既能完成正反馈，又能完成选频，往往是这样结合在一起的。因为最后选完了频，选频结束的要求就是让 $|AF| > 1$、$\varphi_a + \varphi_f = 2n\pi$，一般就是这样选。

#### 选频为什么都靠谐振：品质因数的脾气

一般选频都用什么选呢？你们在电路当中学过吧，一般用什么选频选得比较准？**用电路的谐振，谐振选频。**

你们比较熟悉的是 LC，LC 谐振能选频。LC 有并联也有串联谐振，谐振选频是最常用的。而且**谐振电路品质因数越高越尖，选择性越强，越好**。

大家去调的时候就知道了。大家做过基电实验，好比说 RLC 串联谐振，如果品质因数很高的时候，没经过计算，那实验永远也做不出来。你去手动扫频那就死了，稍微手一激动，毫伏表上什么感觉都没有，过去了；只有在谐振点上指针一下子上去，稍微一过马上就摔跌下来，没到它都不往上摆。这就叫选频。

如果品质因数差一点，你还能看到它慢慢起来了然后又下去了，也不会那么慢，再差都不会那么慢，可只要到谐振了。

所以只有真的认认真真做了那个实验，你才知道人家选频的厉害——因为你根本就找不到谐振点。你得先算出来大约在哪儿，然后你在旁边一点一点地微调，突然成功了，看它上去了，这样才行。所以谐振选频是比较灵敏的这样一种情况。

#### 判别的四步

综合起来，如果给我们一个电路，我们能否判别它起振、能否产生正弦波的这种振荡？按四步走：

| 步骤 | 检查什么 | 具体问法 |
| --- | --- | --- |
| 第一 | 组成是否齐全 | 放大、正反馈选频、稳幅这几块在不在 |
| 第二 | 功能是否齐全 | 放大电路能否正常工作、放大倍数是否稳定 |
| 第三 | 是否存在正反馈 | 忙活一圈是负反馈还是正反馈 |
| 第四 | 能否起振 | 起振幅值条件 $|AF| > 1$ 是否成立 |

第三步具体说：**判断正反馈存在与否，实际上我们称作正弦波振荡电路的相位平衡条件。** 如果这个电路忙活了一圈，就是稳定放大倍数了，全是负反馈，没用的。有没有正反馈存在？

相位平衡条件怎么判断？判断相位条件实际上特别简单，就是**判断反馈的极性**。

这是一个方框图，我从输入端拉一个信号 $u_f$ 进去，过来，看到 $u_f$ 是不是正反馈。如果是正反馈的话，就说明相位平衡条件、相位条件是满足的。

第四步：能不能起振。这就回到 $|AF| > 1$ 上去了。

在这一节里面，我们实际上要掌握这两点：第一，后面我会学一个 RC 电路，**RC 电路要整个会分析**；后面的 LC 电路，同学们需要掌握的就是**学会用相位条件去判别它是否具备起振条件**，换句话说，就是判别这样一个电路是否存在正反馈。

### RC 桥式正弦波振荡电路：同相比例放大器 + 串并联 RC 选频网络

说了这一大堆，这实际上都是一个原则，非常抽象。我们来看一个电路：RC 桥式正弦波振荡电路。

#### 把电路割开看：右边那块就是 A

这一眼看过去，同学们来看，觉得电路复杂吗？我们来看。

我问你，这一块如果把这儿给割开，这样一个电路，如果把这个还是接地，这是什么电路？长得好看点：$u_I$ 进来，这里是 $u_O$，这是 $R_f$，这是 $R_1$。我问同学们，这是什么电路？**同相比例**，应该认识吧？带有负反馈的同相比例，放大系数是

$$1 + \frac{R_f}{R_1}$$

没错吧？就这样一个东西。

这个东西就是谁？我在这儿并行的画，就是那个 $A$。那个 $u_O$ 就是我期待的输出 $x_o$。

现在这块准备进去的就是，如果人为地加 $u_I$ 的话，那就正是一个同相比例放大电路。我现在需要的是什么？**我现在需要的是让这个 $u_O$ 给它提供输入。**

想办法。$u_O$ 不是拉过来了吗？目标是经过这样一个 $F$，然后给这块提供给它。如果这是电路设计的话，我就这样一个想法。

然后注意一点：这个 $F$ 我肯定保证这里是**正反馈**，你看正、正，回了一个正反馈。但关键一点是什么呢？我这个 $F$ 还要保证一点，**我要能把频率选择出来**。

$u_O$ 这块可能有一大堆频率的东西。注意，在一开始的时候这个 $u_O$ 并不代表着是某一个固定频率的 $u_O$，我要选择。换句话说，**我选择谁反馈回去？我选择谁反馈。** 因此，这个 $F$ 既是一个**反馈网络**，又是一个**选频网络**。

```text
   串并联 RC 选频网络（就是那个 F）

              u_o
               │
      ┌────────┴─────────┐
      │   R       C      │     ← 串联支路
      └───┬───────||─────┘
          │               │
          ●───────────────┘
          │      u_f
      ┌───┴───┐
      │  R  ║ C│                ← 并联支路
      └───┬───┘
          │
         GND

   u_f = U_F 接到放大电路 A 的同相（+）输入端
```

现在用的是什么电路？**RC 的串并联电路来做选频。**

那么我们来看，什么时候这个 $U_F$ 实际上比 $U_o$ 最大？而且不仅是最大，而且还要怎么样？**相位差是 0，同相。** 要做到同相位。

两点啊，一个是这个时候 $U_F$ 最大，然后还得同相位。那我就成功了，这个电路就可以了。

#### 定性：高频像高通、低频像低通，交集就是带通

你们有的同学刚才我听有个疑问：RC 怎么能谐振？正常概念的话就是，RC 怎么能去选频？换句话说，RC 的话最多是个做高通或者做一个低通，怎么能选频？在我们概念当中应该是 LC 去选频。

你们去看那两个图，它代表的是它的一个**电路构成的理念**。第一个图代表什么含义？那是高通电路吧？下面是一个低通电路。也就是说**在不同频段，这个电路在高频段和低频段的时候，会表现出不同的特性**。

上面那部分选择的是什么呢？高通没错。但这个等效是在什么频段？**低频段。**

在低频段的时候，$\omega$ 很小，容抗 $\dfrac{1}{\omega C}$ 很大。容抗很大，所以这两个**串联**就剩的是谁？**电容**；这两个**并联**就剩的是谁？**电阻**。

（到了高频段正好反过来：容抗很小，串联支路里电阻占主导，并联支路里电容把电阻短路。）

这一部分和这一部分对频率的选择是不一样的。上面那部分和下面这部分对频率的选择是不一样的，然后它来产生了一个**交集**。中间那个交集就怎么样呢？**就把频率给选出来了。** 这是最定性的分析方法。

> **提示**：RC 并不是不能选频。把"只对高频响应"的环节和"只对低频响应"的环节串成一条支路、并联成另一条支路，两者的响应区间只重叠一小段，重叠的那一段就天然成为**带通**。再把这个带通做得很窄、特别窄，就变成选频了。这都是电路设计的一个大思路。

#### 定量：U_F / U_o 的最大值 1/3，出现在 ω₀ = 1/(RC)

定量的话，最简单定量，你们最喜欢干的事情是定量。这个是 $U_F$ 比上 $U_o$：

$$\frac{U_F}{U_o} = \frac{R \parallel \dfrac{1}{j\omega C}}{\left(R + \dfrac{1}{j\omega C}\right) + \left(R \parallel \dfrac{1}{j\omega C}\right)}$$

上面那部分 $R \parallel \dfrac{1}{j\omega C}$，再加上 $R + \dfrac{1}{j\omega C}$，然后这里又是 $R \parallel \dfrac{1}{j\omega C}$。每个人都能把这个算出来。算完之后，这个东西等于什么？

$$\frac{U_F}{U_o} = \frac{1}{3 + j\left(\omega RC - \dfrac{1}{\omega RC}\right)}$$

问同学们，这个东西什么时候最大呀？**虚部为 0。** 只要虚部不为 0，它肯定就不是最大。看到它选出频率了吗？什么时候虚部为 0？$\omega RC = 1$，就是

$$\omega_0 = \frac{1}{RC}$$

的时候。这个时候它最大。最大多少？

$$\left.\frac{U_F}{U_o}\right|_{\max} = \frac{1}{3}$$

看到吧？频率选出来了吧？

其他任何一个频率拉过来，我都会有虚部的存在。这个时候 $\varphi_A + \varphi_F$ 都不会等于 $2n\pi$，都会有一个相位差。**一旦有相位差，就不会构成正反馈**——它转、转、转，这个相位总归是不会完全一样的。

所以，只有对于频率 $\omega_0 = \dfrac{1}{RC}$ 的这样一个信号，它会**完全实现一个正反馈**，而且这个时候它也最大。这时候它也最大。

一旦做到这一点的话，这里就活了。大家可以看到，$U_o$ 是可以含有一大堆杂的，我还是那个概念，$U_o$ 出了一大堆。所以这个 $U_o$ 相当于一大堆什么呢？**一大堆信号源的串联**，各种各样的频率信号源的串联。

但是谁过去谁不过去：其他那些也能过去，但是**越转怎么样？越小**；只有 $\omega_0 = \dfrac{1}{RC}$ 的那个，**越转越大**。

但是为了让它越转越大，你得做一点什么？让它得**大于 3**。

> **结论**：这个 $F$ 在 $\omega_0$ 处最大只能给出 $\dfrac{1}{3}$，因此要满足起振条件 $|AF| > 1$，放大电路那一级的电压放大倍数必须**大于 3**。取 $\omega_0 = \dfrac{1}{RC}$ 定出振荡频率，靠串并联 RC 网络在"带通峰"上同时给出最大增益和零相移，靠稳幅电路把起振后的 $|AF|$ 拉回 1——三件事凑齐，一个正弦波振荡电路就成了。
