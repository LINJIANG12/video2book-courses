## 单级不够用的时候：多级放大电路怎么拼、怎么算
> 对应块：BLK18 | 覆盖分集：P18 | 块标题（分集名）：《18-多级放大电路的构成与动态分析_4K》

### 给我一个需求，我用单级做不出来

到上节课为止，放大电路基本的构成原则、基本的分析方法、基本的概念，我们都应该已经清楚了。可真正拿电路的时候，常常卡在同一个地方：**一个单级放大电路够用吗？**

我先给你们一个需求，很简单，你们自己判断能不能做。

前端是一个电压型的信号源，注意，是电压型的，而且它的**内阻不能忽略**——它是有内阻的，我这个 $U_S$ 是有待于放大的。输出端接一个 $R_L$。这个 $R_L$ 是什么量级？大约是 $\text{k}\Omega$ 级的，在 $\text{k}\Omega$ 上下、或者几 $\text{k}\Omega$ 这样来回变化的一个负载。负载是会变的。**在负载变化的前提下，我要求输出电压近似维持不变。** 第三，尽可能放大，电压、电流、功率都尽可能放大。

```text
  +----------+        +--------------+        +---------+
  |  us, Rs  |--ui--->|   amplifier  |--uo--->|   RL   |
  +----------+        +--------------+        +---------+
   |                 |                 |
  voltage-type      Ri : large       Ro : small
  source            Ro : small       RL : k-ohm
  Rs matters        Au, Ai : large   RL varies
                                     uo ~ constant
```

读图：左边是一个带内阻 $R_s$ 的电压源，中间是被要求的那块放大电路，右边是会变的 $\text{k}\Omega$ 级负载；两条要求压在中间这块上——进去的 $R_i$ 要大，出来的 $R_o$ 要小，而且电压电流都要放大；右边那一条说的是，$R_L$ 怎么折腾，$u_o$ 基本不许动。

把需求翻译到对放大电路的要求上，就三句话。第一，$R_i$ 尽可能大——$R_i$ 越大，我这里拿到的 $U_i$ 越大；顺带一提，$R_i$ 大也意味着从 $U_S$ 那里取走的电流小，$U_S$ 输出的功率反而小，两头都占。第二，$R_o$ 非常小——只有 $R_o$ 小，$R_L$ 变化引起的输出电压变化才小，因为越小的 $R_o$ 越接近理想电压源。第三，不管 $A_{uu}$ 还是 $A_{iu}$，电压和电流都得放大。

> **结论**：$R_i$ 大、$R_o$ 小、还有增益——这就是放大电路最经典的一组矛盾。

那咱们学过的哪个单级电路能同时做到？我们把两个最熟的一个一个拎出来对。

| 单级电路 | $R_i$ | $R_o$ | 电压增益 | 电流增益 |
| --- | --- | --- | --- | --- |
| 射极输出器（共用集） | 大 | 小 | 基本不放大，$A_u \approx 1$ | 放大 |
| 共射放大电路 | 小 | 大 | 放大 | 放大 |

射极输出器做到的是输入电阻大、输出电阻小，这两条全中，可它就是不能放大电压——我这里明明要求放大电压。共射放大电路好，电压能放得很大，电流也放大，可它输入电阻小、输出电阻大，两头都不合格。

> **易错点**：射极输出器"电流放大、电压不放大"这一点是常考的判断题。它不是"什么都不放大"，$A_u$ 接近 1 但严格小于 1，同时电流放大倍数大、输入输出电阻都理想。

既然没有任何一个单级电路能干成这件事，那就让它们**组合起来用**。随便给你拼一个看：

```text
  +------------+    +------------+    +------------+
  |  stage 1   |    |  stage 2   |    |  stage 3   |
  |  common    |--->|  common    |--->|  common    |
  |  collector |    |  emitter   |    |  collector |
  +------------+    +------------+    +------------+
       CC               CE               CC
     Ri : big        Au : big          Ro : small
     Ai : big        Ro : small        Au ~ 1
     Au ~ 1          Ri : small       Ai : big
```

读图：级联顺序是共集—共射—共集。

第一级放共集，放这儿是为了 $R_i$ 大：进来的时候 $U_i$ 大，电流也放大了，而且送到后级去的功率已经放大了一截，虽然电压没放大——不要紧，后面有共射。中间放共射。为什么放共射它输入电阻不大也没关系？因为第一级是共集，**它的输出电阻小**，等于给这个输入电阻不算大的共射配了一个低内阻的驱动源，所以共射的集电极电压照样稳定，电压和电流在这里一起放大。输出端为什么不能直接出去？它 $R_o$ 大，负载一变输出就晃。所以最后再接一级共集：它输入电阻大，把前面共射的输出好好取过来；它输出电阻小，把 $u_o$ 稳住；电流再放大一次。

当然这只是一个随手举的例子，实际设计不会照抄。真正重要的是结论：**这种需求单级完不成，必须把若干单级合成一个整体——这就是多级放大电路。**

### 看图的本钱：把电路读成模块

说到看图，我提一个要求，这个要求比会算重要。

现在给你一张直接耦合的图，里面是三个极管、四个电阻、一堆线。如果你看着它还是"一个三极管、一个三极管、一个电阻"这样看——**危险**。我希望你一眼看过去就知道：这是一级电路，这是一级电路，第一个是共射，后面那个也是共射。**读图要读成模块。**

怎么判断一个人读图的水平？看他对基本模块熟不熟。就跟你们天天学的英语一样：最低级是 b-o-o-k，一个字母一个字母地拼，知道它是 book；再高一级，你看过去它就是个词；再高，一眼扫过去是个词组；再厉害，一眼过去就是个从句——阅读速度当然越来越快。**你要是读电路还是一个电阻一个电阻地看，那说明你还停在拼字母那一级。**

模块会越组合越大。共射加共射、再加共集，再往上是一眼能认出"这是运放的图"，再往上是一眼能认出"这是电源的图"。好比一台电视机拆开：这块是电源，这块是驱动器，这块是滤波电路——几大模块先在脑子里分开，然后进到某个模块里再往下分。这个道理不是电路特有的，是所有系统都一样的。

> **提示**：如果你一眼看过去满眼全是电阻和电容，那不是电路太复杂，是你还不够熟。**读图能力 = 对基本电路的熟悉程度**，没有第二条捷径。

### 级与级之间怎么连：耦合方式

我以前给大家讲过什么叫耦合——放大电路和放大电路之间，信号是怎么过去的，这就是信号的耦合方式。通俗点说，就是**这些级和级之间是怎么联的，信号怎么过去的**。一共就这么几种。

#### 直接耦合：最常用，也最麻烦

这是最常用的一种。第一级、第二级，一根线直接连上，中间什么都不放。

看完这张图，我希望你回头再问一句：以后看多级电路，知道怎么办了吗？回头看第一节那个"读成模块"。

接下来是真正麻烦的地方。**这样直接连起来的电路，能用吗？**

看着很合理，实际上很不合理。分开看都对——第一级合理，第二级合理，合在一起不合理。你说 $T_2$ 的基极电位是多少？大约 $0.7\text{V}$。那 $T_1$ 的集电极也就得是 $0.7\text{V}$，没做错吧？问题就在这儿：**$T_1$ 的基极和集电极电位几乎相同了，这个管子必将奔向饱和。** 基极只要有一点动态信号进去，它又往饱和区去了。你根本没法保证它的集电结有足够的反偏，它贴着饱和区的边缘在运行。大信号出不来，出了也是削顶的。

```text
        +Vcc
          |
         RC          <-- idea: use the drop on RC to raise VC1
          |
   +------+------+
   |             |
  T1            T2      VC1 = VB2 ~ 0.7V
  CE1           CE2     T1 sits on the edge of saturation
   |             |
  GND           GND
```

怎么让它合理？很明确：**必须把 $T_1$ 管子的集电极电位提高。** 那我们就来看这一串"想主意"的过程，这段思路比结论值钱得多。

**第一步：加电阻。** 加个电阻肯定能把电位顶上去，因为电阻上有压降嘛。问题是什么？静态是解决了，动态代价太大——这个电阻要加多大才能把 $T_1$ 拉出饱和？电阻一大，后面的输出就被它分走了，增益下降。加得越大增益掉得越厉害。

**第二步：改用二极管。** 我要一个"静态能顶电位、动态又不挡路"的元件，二极管正好。放一个二极管，抬 $0.7\text{V}$；动态的时候二极管的电阻不大，曲线比较垂直，动态电阻比较小，所以加了动态信号它也不怎么挡。**问题是它不好。** 加一个不过瘾，我还想再高，那就得加俩；加俩，动态电阻不就又大了吗？

**第三步：改用稳压二极管。** 我想要多少伏就多少伏，而且稳压管反向击穿区的动态电阻也比较小。看上去这回总行了。

```text
   need: raise VC1
       |
       +-- (a) add RC  : static OK, but gain drops (R must be big)
       |
       +-- (b) add D   : +0.7V, small dynamic r
       |                 one D is not enough ...
       |                 two D -> dynamic r adds up
       |
       +-- (c) add DZ  : any voltage you like, small dynamic r
       |                 BUT needs a minimum Iz -> add R to feed it
       |
       +-- (d) NPN + PNP : levels match for free, Vcc untouched
```

读图：四条思路按时间顺序排列，前三条都是"在 $T_1$ 上面挂一个能顶电位的元件"，一条比一条聪明，第三条还补上了限流电阻 $R$ 来提供最小稳压电流 $I_Z$——每一步都有意义，缺一个 $R$ 稳压管就进不了稳压区，电流不够它就在拐弯的地方待着。第四条干脆不挂了。

而这第四条才是最漂亮的。**那如果后一级不用 NPN，改用 PNP 呢？** 一个 NPN，一个 PNP，两个管子天然互补，各级都找到了自己合适的静态工作点。我的 $V_{CC}$ 不用调，什么都不用改，两级共射就能好好地协调在一起。

```text
   +----------+                 +----------+
   |  NPN CE  |-----------------|  PNP CE  |
   |  stage 1 |                 |  stage 2 |
   +----------+                 +----------+
        the two stages match each other at DC,
        the supply Vcc stays where it was
```

读图：NPN 的共射后面直接接 PNP 的共射，电平天然对齐，供电电压一点不用往上抬。而且做 $h$ 参数等效的时候，这一个电路和前面那一个作用**完全一样**——从动态角度看，它们是同一个东西。

> **结论**：直接耦合的级间电平匹配，本质上是"让前一级输出电压范围能塞进后一级输入电压范围"的问题。管型互补是比堆稳压管优雅得多的解法。

然后说说它的优缺点。**缺点一大堆**，真的。

第一个，也是最要命的：**调试非常困难**。为什么？$T_1$ 的静态工作点一变，$T_2$ 就跟着变——两级联动。前一级 Q 点发生漂移，后一级不但跟着漂，还把这个漂移**放大**得更厉害。所以不管从调试角度还是从 Q 点稳定性角度，这个电路的毛病都非常大。

**但如果全是缺点，它就没有存在的道理了。** 我一直跟你们说，缺点再多的东西，里面一定有优点。

第一，**低频特性好**。阻容耦合的低频会变差，因为容抗越来越大；直接耦合没有这个问题，信号频率放到多低都行，**放到直流都没事**。

第二，**易于集成**。它没有任何外加元件，就是几根导线直接连着，所以可以做成集成放大电路。我上节课提过阻容耦合能不能集成——集成不了，因为大电容你集成不出来。想要集成，就只剩这一条路。**这个电路必用，因为我们确实有大量的集成电路存在。**

#### 阻容耦合：各级静态独立，考试最好下手

阻容耦合就是：前一级输出和后一级输入之间，用一个**电容**连过去。$u_i$ 通过 $C_1$ 进第一级，第一级的输出通过 $C_2$ 进 $T_2$ 那一级。

```text
  +---------+  C1   +---------+  C2   +---------+  C3   +-------+
  | stage 1 |---||--| stage 2 |---||--| stage 3 |---||--|  RL   |
  +---------+      +---------+      +---------+      +-------+

  C1 blocks DC from stage 2
  C2 blocks DC from stage 3
  C3 shorts R4 away when AC is present
```

读图：三个单级用 $C_1$、$C_2$ 隔开，负载再经 $C_3$ 接入；直流上各级被电容彻底分开，动态上电容容抗很小、相当于导线。

这张图好看在哪？**泾渭分明**，太清楚了。第一级是共射还是共集还是共集，静态稳不稳，一眼就看出来；第二级是射极输出器还是共射，一眼就看出来。

好处也太明显了。对着缺点说：

**第一，静态工作点非常好调。** 你去画它的直流通路，会发现各管各的，每一级都是独立的，互不干扰。这是阻容耦合最实在的一个优点。

**第二，稳 $Q$ 点可以肆无忌惮地做。** 你看图上那个 $R_4$，就可以随便往上加，让静态工作点更稳。为什么敢这么干？因为我加了 $C_3$ 之后，**动态的时候 $R_4$ 就消失了**——静态靠 $R_4$ 稳住，动态靠 $C_3$ 把它短路掉。两头都顾上了。

缺点呢？如果信号频率低就出事。**频率比较低的时候，它的缺点暴露无遗。** 放个直流根本过不去；$u_i$ 频率一低，整个电压放大倍数就大幅下降，因为电容过不去。所以它适合频率比较高的情况——注意，也不是越高越好，高到高频截止区又是另一回事；是在中频区这一段，它表现得很好，因为那时候容抗很低。同样，它也**不能集成**。

> **结论**：这种电路常见于分立元件放大电路。而**真要考试，最简单的电路就是阻容耦合的**。为什么？因为你分析静态的时候非常开心——每级单独分析，各级互不干涉。给直接耦合？那一级和一级连在一起，那就要命了。

#### 变压器耦合：会变阻抗，才敢带扬声器

变压器耦合是真耦合，不是"连一根线"那种。它靠变压器把信号传过去。

这里有个概念要说清楚：**对前一级来说，后一级无外乎就是一个 $R_L$。** 图上第二级没画电路，画了个 $R_L$，就是这个意思——你完全可以把它画成一个共射的输入电阻或者一个射极输出器的输入电阻，就那么一个东西。搞清楚了这一点，你就知道变压器接在哪儿了。

```text
  +----------+       1 : 2        +----------+
  |  amp     |------(  )||( )----| speaker  |
  |  Ro=32ohm|        xfmr        | RL = 8ohm|
  +----------+                     +----------+

  direct   : load looks like  8 ohm        -> mismatch, ~1/5 power
  with xfmr: load looks like 8 x n^2
                      = 8 x 4 = 32 ohm     -> max power
```

读图：左边功放输出电阻 $32\ \Omega$，右边扬声器 $8\ \Omega$，中间是变比 2 的变压器。

好处第一个还是老一套：直流信号传不过去，所以各管各的。第二个才是它独有的——**变压器能完成阻抗变换**，这在基本电路里学过，用处非常大。

举个数得过来的例子。我的扬声器是 $8\ \Omega$，我的功放输出电阻是 $32\ \Omega$。要达到最大输出功率，负载阻值必须和内阻相等。你要是不用变压器，我这儿怎么接都有问题：$8\ \Omega$ 直接接上去，得到的电压和功率只有五分之一，哪怕我这边功率已经放大了也白搭。有同学说那我在功放输出端串一个 $24\ \Omega$ 行不行？从功放那头看是 $32\ \Omega$ 匹配了，可到 $8\ \Omega$ 那块又更小了。**两头总有一头不匹配。**

换成变压器就干净了：变比取 2，阻抗就翻 4 倍，$8 \times 4 = 32\ \Omega$。从功放看过去，负载正好是 $32\ \Omega$，功率最大。

#### 光电耦合：把信号换成光再送出去

光电耦合我不细说，就是用光耦器件。里面怎么工作呢？很明白：这一面把信号变成光，那一面用光电三极管接住——**而且这还是一个达林顿结构，光电复合管结构**。中间那段光还可以用光纤来传输。

它的好处很实在。**第一，长距离传输的时候干扰极小**——外面的电磁场对光几乎没有影响，抗干扰能力强。这在实际工程里太有用了：很多强功率控制柜、功率柜里，驱动信号要送过去驱动大功率管子。放一根导线过去？死了。告诉你，那边全是大电流，磁场干扰一下，你那个信号过去就完全变形了。**拉一根光纤过去，用光耦，问题就解决了**，整个传递过程不受干扰。

**第二，绝缘。** 假设那边是个一百来万伏的高压，你要把信号取出来怎么办？用分压器？分下来你就危险了。用光耦取，取完之后整个器件是绝缘的。

> **提示**：光耦最大的用处其实是抗干扰，次才是高压隔离。这两件事它做起来毫不费力，因为它的物理通道根本不是电。

四种方式摆在一起，优缺点摊开看：

| 耦合方式 | 直流与静态工作点 | 低频特性 | 它自己的看家本领 |
| --- | --- | --- | --- |
| 直接耦合 | 两级联动，Q 点难调，漂移还会被后级放大 | 好，频率放到直流都行 | 没有任何外加元件，所以易于集成 |
| 阻容耦合 | 各级完全独立，好调，还能加 $R_4$ 稳 Q 点 | 差，频率一低放大倍数就大幅下降 | 分立元件电路常用；静态分析最省心 |
| 变压器耦合 | 直流传不过去，各管各的 | — | 能做阻抗变换，$8\ \Omega$ 配 $32\ \Omega$ |
| 光电耦合 | — | — | 抗干扰强，还能高压隔离，可用光纤远传 |

表里留空的那几格不是我省事，是这几条我确实没讲——**表格只能填讲过的，猜不得。**

### 多级放大电路怎么分析：拆回一级一级

这几种耦合方式一凑，多级放大电路就构成了。构成之后马上要面对动态分析。

阻容耦合的静态分析没什么好说的——每级是自己的，都是单级。所以我们专门说动态分析怎么下手。现在摆一个多级放大电路在我面前，一级一级往上堆：$u_s$、$R_s$，第一级、第二级、第三级，最后一个 $R_L$，中间当然还可以继续加。**一级一级"砰砰"地叠上去。**

> **提示**：整个道理是通的——**用你已经掌握的知识去解决未知问题**。多级再复杂，本质上也就是若干个单级。

先把框图拉出来：

```text
  us,Rs -->[ Au1 ]-->[ Au2 ]-->[ Au3 ]--> ... -->[ Aun ]--> RL
               |           |           |
              Ri          Ri2         Ri3
        whole Ri = what you see looking into stage 1 from the left
```

读图：一条纯级联链，每级是电压增益方块，方块下面标着该级从自己左边看进去的输入电阻；整条链的 $R_i$ 就是从第一级左边看进去看到的那个东西。

#### 总增益是相乘，但每一级都得"连着"才算

我唯一要知道的，是 $u_o$ 比上 $u_i$。那它等于什么？等于 $A_{u1} \times A_{u2} \times A_{u3}$。

**但注意，这个 $A_{u1}$、$A_{u2}$、$A_{u3}$ 是什么条件下算出来的？是在连在一起的条件下算出来的。** 这句话是这一节的关键。

看个例子。我现在把 $A_{u2}$ 这个方块单独拎出来研究：如果它后面什么都不接，开路，单独算它的电压增益，得到一个 $A_{u2}'$。我问你们，$A_{u2}'$ 和 $A_{u2}$ 相等吗？很多同学说不等。**不等，为什么？** 因为你把人家的负载给弄没了。

$Au2$ 原来的负载是谁？就是 $A_{u3}$ 后面那一堆。那我把后面那一堆换成什么？换成"从这一级看进去的一个等效电阻 $R_{i3}$"。

```text
  WRONG:  [Au1] -->[ Au2 ] -->[ Au3 ]        gives Au2'
           (Au3 lifted away = open circuit)

  RIGHT:  [Au1] -->[ Au2 ] -->[ Ri3 ]        gives Au2
           (a real Ri3 is exactly the same to Au2)
```

读图：上半图把第三级整个拎走，第二级后面开路，算出来的 $A_{u2}'$ 不是真实的 $A_{u2}$；下半图把第三级换成它的输入电阻 $R_{i3}$——对第二级来说这两者**完全等价**，这回算出来的就是真的 $A_{u2}$。

> **易错点**：算多级的各级增益，**绝不能把某一级拎出来单独算**。你能拎走的只能是后级电路的**等效输入电阻**，不是后级电路本身。

#### 顺着算：把后一级折成一只电阻

这样一改，问题就被打回原形了——**每一个单级放大电路的求解**。

$Au_3$：直接就着它算，完事。

$Au_2$：先从左边往 $A_{u3}$ 里面看进去，求出 $R_{i3}$，把后三级换成一个 $R_{i3}$，然后按单级算出 $A_{u2}$。

$Au_1$：在刚才那个电路的基础上，从左边往里看，求出 $R_{i2}$，把后面那一大坨换成一个 $R_{i2}$，然后按单级算出 $A_{u1}$。

```text
  Au3  ->  Ri3  ->  Au2  ->  Ri2  ->  Au1  ->  Ri
   ^                   ^                   ^
   |                   |                   |
  known single     after Ri3 replaces   after Ri2 replaces
  stage            the later stages     the later stages

  Au = Au1 * Au2 * Au3 * ... * Aun
  Ri = look into stage 1 from the far left
```

读图：一条从右往左的化简链——先拿到最末级的增益，用它算出末级的输入电阻，用这个电阻替换掉后级，再算倒数第二级……一路推到第一级；整条链的等效输入电阻 $R_i$ 就是从最左端看进第一级得到的那个值。

三个都出来了，$A_u$ 就出来了。整条链的 $R_i$ 也出来了——从最左边直接看进去。

> **结论**：顺着算的通法只有一条，就是**"从后往前，把后一级电路折叠成它的输入电阻"**。每折叠一次，问题就退回一个你已经会做的单级问题。

#### 倒着算：求输出电阻

$R_o$ 的思路是什么？**反过来。**

最终目标是什么？最终目标就是：把所有这些电路对 $R_L$ 而言，等效成"一个 $R_o$ 加一个信号源 $U_o'$"。

```text
  forward :  Au3 -> Ri3 -> Au2 -> Ri2 -> Au1 -> Ri
  backward:  Ro1 -> Ro2 -> Ro -> (seen by RL as  Ro , Uo' )

  step 1:  Ro1  -- look back into stage 1 from its output side
  step 2:  stage 1 becomes  ( Ro1 , Uo1' )  = the source of stage 2
  step 3:  Ro2  -- use that source, single-stage Ro method
  step 4:  stage 2 becomes  ( Ro2 , Uo2' )  = the source of stage 3
  step 5:  Ro   -- the pair that RL actually sees
```

读图：上半是刚才那条向右的化简链，下半是它的镜像——把第一级化成"输出电阻 + 等效源"，这个等效源就是第二级的信号源，再用标准单级方法求第二级的输出电阻，如此往复，最后 $R_L$ 面前只留下一个 $R_o$ 和一个 $U_o'$。

一步一步来。第一级拉出来，从它的输出端看进去算出一个 $R_{o1}$——注意是对着"后面那一堆"算的，算完之后这一级就塌缩成"一个 $R_{o1}$ 加一个 $U_{o1}'"。$R_{o1}$ 一到手，前面那些都不用看了：$R_{o2}$ 怎么求？就用这个等效源来求，每一个都是标准的单级 $R_o$ 求法。求出 $R_{o2}$，这一级再塌缩成 "$R_{o2}$ 加 $U_{o2}'"。最后一路倒出来，就是总的 $R_o$。

所以整个多级放大电路的动态分析，说白了就是一句话：**一个单级放大电路的解法，不停地重复。**

> **易错点**：整个过程里你唯一能犯、也最常犯的错，就是把其中某一级"咔嚓"一把拎出来单独算。你这么一拎，就割裂了事物的联系。联系在哪儿？就在这些等效电阻里——$R_{i3}$、$R_{i2}$ 是正向的联系，$R_{o1}$、$R_{o2}$ 是反向的联系。**每一级都必须放回它的系统里去看。**

#### 交流通路怎么画：在中间开一刀，留 A、B 两个口

最后说个实操的。拿到一个多级放大电路，第一步是画交流通路。教你一个**永远不会画错**的办法，比你凭感觉画稳得多。

```text
                 A              B
            -----+-------||-----+------  <-- the cut goes here
            |                       |
     left part                 right part
     drawn alone,              drawn alone,
     labeled A and B           labeled A and B
     h-parameter model ...     h-parameter model ...
            |                       |
            +-------- snap --------+   <-- glue back at A-B
```

读图：在两级之间的耦合电容处把电路一刀切开，左边和右边各自当作一个独立的单级放大电路画交流通路，画的时候端口上务必把 A、B 两个标记都带上，h 参数等效也照画；两张图画完，在 A、B 端口处"啪"地合起来，就是完整的交流通路。

关键是**切口两边都必须带着 A、B**。因为人家在那儿是要缝合的，你合的时候得知道对哪儿。哪怕你两边都完整画到 h 参数等效了，最后也是在 AB 端口那儿合。

合上之后你在想什么？你就想明白了：**在 AB 这个端口处合起来的这一坨，对前面那一级来说是什么？** 就是它的 $R_L$——$R_{i2}$。而 $R_{i2}$ 一旦算出来，后面那一大坨就可以扔掉，把它换成一只 $R_{i2}$ 接在前一级上，前一级的 $A_{u1}$ 就出来了。

对照着看：**框图上觉得简单的东西，画到真实电路上也一点都不难。** $A_{u2}$ 就用后面那块的电路直接算；后面那块还能算出 $R_{i2}$；$R_{i2}$ 一到手，后面这玩意就不要了，往前一级输出一接，$A_{u1}$ 就出来了。整体 $A_u = A_{u1} \times A_{u2}$，整体 $R_i$ 从最左端看进去，$R_o$ 反过来倒。

这块我真不想再给你们做一遍了。确实就是单级放大电路在重复——关键还是你们对 $R_i$、$R_o$ 的认识够不够、牢不牢。

## 拼起来的三级放大电路，和它为什么怕频率
> 对应块：BLK23 | 覆盖分集：P23 | 块标题（分集名）：《23-直接耦合多级放大电路与放大电路频率响应的基》

### 复合管收尾，以及一条回头看很清楚的演进链

刚刚我们分析了输出级，而且我给你们留了最后一个问题：怎么让我最外层的两个管子是一样的，然后还变成一个 NPN、一个 PNP？这就是我们刚刚学过的内容——用复合管。

复合管的做法是：一个用 NPN 当主管，另一个用 PNP 当主管，最外面全用 NPN 就可以了。

```text
   NPN 复合管                      PNP 复合管

   ┌───┐                          ┌───┐
   │T1 │ NPN（主管）              │T1 │ PNP（主管）
   └───┘                          └───┘
      │ C                            │ C
      │                              │
   ┌──▼───┐                       ┌──▼──┐
   │ T2   │ NPN（输出管）          │ T2  │ NPN（输出管）
   └──┬───┘                       └─────┘
      │ E                            │ E
      ▼                              ▼
     ───                            ───

   最外面两个复合管：结构完全相同，
   极性相反 → 对称性极佳，β 更大
```

看到了吗？这两个管子现在是一样的，它完成了非常好的对称性。但是这个管子是 NPN 复合起来的，另一个是 PNP 复合起来的。用了复合管，既加强了它的对称性，又进一步提高了它的放大性能。

> **提示**：复合管的电流放大倍数约等于两级 β 的乘积（$\beta_{\text{总}} \approx \beta_1 \beta_2$）——这就是"进一步提高放大性能"的来源，也是我们敢用它来构成准对称输出级的前提。

那么我们已经什么都学了：输入级也学了，中间的级也学了，输出级也学了。把它们组合起来——这就是我们所需要的**多级放大电路**。而且它是一个**直接耦合的多级放大电路**。

顺便说一句，我们这个黑板还是蛮大的，刚才哪位同学教我了，说"你省着点用这黑板"。

#### 回看输出级：一步步推过来的

你们现在看到它是一个很复杂的电路，我要你们觉得有成就感。成就感在哪？咱们就是从最简单的射极输出器开始推的：

```text
   射极输出器
        │  做成互补对称
        ▼
   最简单的互补对称输出级
        │  加两个二极管，消除交越失真
        ▼
   二极管消除交越失真
        │  换成一个倍增电路
        ▼
   倍增电路消除交越失真
        │  两个非对称的互补管子 → 用复合管取代
        ▼
   准对称复合管输出级（5 个管子）
```

你看我说了这么一大套：从最开始那么小一个东西、一个管子的东西，现在咱们变成了五个管子的，是不是这样一步一步来的？每一步都有它改动的道理和改动的理由存在。实际上每一步的更改都是我们费尽了心机的，都是这么回事。

### 九个管子，三级：每一级各自解决什么

你们现在能不能迅速地分出来？这么乱七八糟竟然有九个管子——你们要感觉你们在进步，现在这里竟然有九个管子。没学模电的时候，你知道这是什么？满篇是箭头，好像是个流程图。你们现在知道它分三级了。

```text
   直流电源（把电压源转化为电流源）给各级提供直流偏置

   输入 ──► [ 差放 T1,T2 ] ──► [ 共射 T3,T4 ] ──► [ 互补对称输出级 ] ──► u_o
              第一级             第二级                第三级
             （输入级）      （T3,T4 为复合管）      （复合管 + 甲乙类）
                                  ▲
                                  │ 集电极负载 = 电流源 I2
                                  │ 交流时内阻极大，捏合为一点
```

这个电路用的还是电压源吗？不是了。它的直流电源不再是我们所想象的电压源——它把这个电压源转化为一种电流源，这是有道理的。

上节课我们曾经接触过最简单的一个电流源，还记得吧？在谁身上的？差放。差放的 $R_E$ 电阻最后用了一个电流源给取代了，长尾式用一个电流源取代了。这里，它的直流同样是用电流源来做。

#### 输入级：差放，温漂和干扰一起解决

第一级是什么？T1、T2 的一个差放。

输入级有非常好的消除温漂的作用。除此之外还有什么？消除干扰——对不对？因为差放它是具备这样一个功能的，消除干扰。所以这是输入端所做的。

#### 中间级：共射加电流源负载，把放大倍数顶上去

第二级是一个**共射放大电路**。这一点非常重要。

T3、T4 构成了一个复合管，你期望得到更大的 $\beta$；然后这里做了一个共射放大电路。

现在一个关键点来了：这个共射放大电路的 $R_C$ 电阻是谁？

基本上这一部分电路，它提供的是一个纯的直流的静态偏置，有点类似一个电源、类似一个直流的电压源。所以一般在动态分析的时候，我们可以在动态的时候把它看成一个点。因此它真正的负载在这儿——$I_2$ 这个电流源。

一旦是 $I_2$ 这个电流源，电流源的内阻怎么样？非常非常大。就代表着我这个 $R_C$ 电阻很大；$R_C$ 电阻很大，这个中间共射放大电路的放大倍数就很大。所以它用电流源当负载，是为了进一步地增大它的放大倍数——电流源有很大的内阻，会起到这样一个效果。

#### 输出级：低输出电阻、小功耗，以及翻倍的不失真输出电压

第三级就是我们熟悉的输出级。特别需要我们再欣赏我们这个输出级——非常可爱的输出级。

它有三件事：

1. 因为是射极输出器的结构，所以满足了**输出电阻低**；
2. 用的是**甲乙类**的这么一个工作状态，所以**功耗小**；
3. 第三点是什么，帮我想想。由于用了甲乙类工作状态，它实际上可以极大地——原来我的最大不失真输出电压是什么？是我那整个活动区的一半，对不对？现在变成了什么？全部都给它了，**放大了一倍**。

> **结论**：最大不失真输出电压翻倍，意味着对管子的要求降低了一倍。

但代价就不是降低一倍的问题了，同学们。同样功率的甲类功放和甲乙类功放，代价完全不同，代价完全不同，价格差得太远。

不过现在基本上甲乙类功放能够做到和甲类功放、就是所谓的纯甲类功放几乎同等的水平，声音乱七八糟这些东西都会做得非常非常好。

### 交流通路怎么画：两个关键简化

对于这样一个电路，如果我们真的还没到功放这个档次——它的电压还不是超大的时候，我们还可以用微变等效或者用 $H$ 参数等效来分析。

第一处简化前面已经说了：像 $I_2$ 这一块，做动态的时候被捏合为一个点，因为它近似于给这里提供直流偏置，相当于一个类似直流的电源。

现在我提一个问题，你们注意一点。如果真的画动态等效电路，画交流通路，我问你们：**这两套管子会同时存在吗？**

```text
   交流通路（微变等效 / H 参数）

   输入 ──► [ 差放 ] ──► [ 共射 T3,T4 ] ──► [ 一只互补管 ] ──► u_o
                          │                  ▲
                          │  集电极          接输出点
                          ▼
                    ×   ← 电流源 I2：交流断路，捏合为一点

   互补输出级只保留一套管子：
   正半周一套工作、负半周另一套工作，
   两者作用完全一样，否则两半周就不对称了
```

答案是：一套。

这两个东西实际上起同样的作用，一个给正半周，一个是给负半周。所以在某一个瞬间，它肯定只有一个在工作；而且它工作的时候肯定工作的效果是一样的，否则这两个半周就会不对称，对不对？

所以在我们画交流通路的时候，肯定只留一套管子——要么留上面那套，要么留下面那套。就留一套。它导通的时候另一套是截止的，因此就相当于输出点要么和它连、要么和它连，就这样得到了一个等效电路。

再补充一点：中间级这里有集电极吧？这个集电极它现在这块是不接地的，这块是断路了，因为它是电流源。它直接连到后面管子的基极上——直接连到后面的一个基极上。然后后面的管子接着用复合管的方式把这些东西画出来。这样一个交流的等效电路，整个直接耦合放大电路的分析就这。

### 分离元件电路到此为止

至此，分离元件电路我们基本上都掌握了：共射、共集、共基三种基本的放大电路，以及它们的复合电路、特殊的输入级差放，以及互补对称的输出级。把它们组合在一起，就是我们所需要的直接耦合的多级放大电路——这样一个过程。

可是为什么这个东西跟频率有关？这个电路怎么会和频率有关？信号的频率怎么能影响到电路的输出？

#### 三个我们至今也没完全想明白的疑问

我们来看，接触了多少和频率相关、到现在我们都不明白的事情。

**第一个**，我们曾经学过，当频率非常高的时候，$\beta$ 会下降。有一个特殊的频率叫 $f_T$，它是指当把 $f_T$ 的信号加进去，电流放大倍数 $\beta$ 衰减到 1。我们不知道为什么。

**第二个**，咱们学共基放大电路的时候，共基放大电路的好处就是频率响应特别好，通频带很宽。为什么？

**第三个**，阻容耦合的放大电路，这个我们直接就知道原因：阻容耦合的放大电路对低频信号反应非常差，效果非常差，它是挑频率的。如果放一个直流上去，根本就不会放大——直流过不了耦合电容。所以这也和频率相关。

那像今天这样一个直接耦合的电路，跟频率相不相关？低频肯定没事，放直流或者缓慢变化的信号肯定能放大，都没有问题。但是另外一种信号就有问题了——当我高频、频率变得特别特别高的时候，一切都发生变化了。$\beta$ 降低了，$\beta$ 降低肯定会影响到它的放大倍数。

#### 结电容：高频下 β 下降的根源

这是因为什么呢？大家还记得吗？PN 结是有结电容的。所以这些管子上，每个 PN 结上都有它的结电容，也就是说它的极间是有电容存在的。

这个极间电容平时非常非常小，皮法级。电容这个参数大家一定要清楚：1000 微法那才是大电容、相当大的电容了；皮法级的电容平时在我们那点小频率下，对于它来说相当于断路，因为

$$X_C = \frac{1}{\omega C}$$

电容很小，容抗很大，相当于断路。但是当我的频率孜孜不倦地不断往上升的时候，它就有效果了——这个容抗就可以被计算了。这时候它就会影响到输出，影响了输出的幅值，影响了 $\beta$。

### 那张图为什么长成这个样子

这个图我让你们自己看的，还记得吧？在第二章里留的阅读内容，放大电路的一个频率指标。我说当时给你们这个图，实际上只是让你们在死记硬背。

#### 低频端为什么咔嚓下来：耦合电容在惹祸

低频那块为什么咔嚓下来了？什么对低频是敏感的？电容。哪个电容？阻容耦合——阻容耦合里的耦合电容对低频是有抑制的。所以对于阻容式耦合电路来说，它有这么一个低频段的特性。

#### 高频端为什么咔嚓下来：极间电容在惹祸

另外一段谁都跑不了，不管你用直接耦合还是阻容耦合。到了中频段以后，耦合电容的作用几乎就被忽略了——频率越高，耦合电容越相当于短路掉，越相当于没有。但是极间电容这时候就跳起来作怪了，就会产生高频段的这样一个响应。

实际上跳来跳去，无外乎都是电容和电阻惹的祸。**低频的时候耦合电容在惹祸，高频的时候极间电容在惹祸。**

那么我问一个最基本的概念：电阻和电容成什么样的组合，会出现这两种情况？RC 电路的这两种特性你们学过吗？——RC 组成的高通电路和低通电路。

### RC 高通与低通：整个频率响应的分析都靠它

频率响应的概述，5.1.1 必要性我已经给大家讲完了。我们来看这样一个基本概念，这是你们学过的内容。在整个的频率响应当中，我们将反复应用这个最简单的概念。

```text
   RC 高通电路                      RC 低通电路

   ui o──C──┬──R──⏚               ui o──┬──R──C──⏚
            │                           │
            o uo                        o uo
            │                           │
            ⏝                           ⏝

   C 串、R 并 → 低频被 C 挡住        R 串、C 并 → 高频被 C 短路掉
   f < f_L 时衰减                    f > f_H 时衰减
```

#### 高通电路与下限截止频率

先看上面都写着的高通电路——RC 高通电路，它是滤波器。

它为什么称是"高通"？它有它的传输特性。

> **定义**：什么叫**传输**？输出和输入之间的关系；这里就是输出电压和输入电压之间的关系，这个比值就叫传输特性。

$$A_u = \frac{\dot{U}_o}{\dot{U}_i}$$

前提告诉你，我再严密一点，$U_o$ 开路——要不然负载很复杂，很难算。先说开路的问题。

$$A_u = \frac{R}{R + \frac{1}{j\omega C}}$$

而 $\frac{1}{j\omega C}$ 就等于 $-j \cdot \frac{1}{\omega C}$，这样这样一个东西。

得到这样一个东西之后，我就会做出这样的幅频特性和相频特性。幅频特性是谁和谁之间的关系？$A_u$ 和 $f$ 的关系。

**那么下限截止频率是怎么定义出来的？** 注意，我是在跟你们复习、给你们定位这个事情，可不是在讲。定义是：当幅值衰减到**最大值的 $\frac{1}{\sqrt{2}}$** 的时候，所对应的那个频率，就是下限截止频率。0.707，对不对？$\frac{1}{\sqrt{2}}$ 就是 0.707。

这个数怎么算出来的？把上面归一化成 1，$A_u$ 就成了

$$A_u = \frac{1}{1 + \frac{1}{j\omega RC}}$$

什么时候它才等于 $\frac{1}{\sqrt{2}}$？$1-j$ 的 $\frac{1}{\sqrt{2}}$，它的幅值，没错吧？所以条件就是

$$\omega_L RC = 1 \quad\Rightarrow\quad \omega_L = \frac{1}{RC}, \qquad f_L = \frac{\omega_L}{2\pi} = \frac{1}{2\pi RC}$$

那如果我把 $f_L$ 往这里一带，$A_u$ 的这个表达式就会变成它的标准形式：上面是 $j\frac{f}{f_L}$，底下是 $1 + j\frac{f}{f_L}$。

$$A_u = \frac{j\frac{f}{f_L}}{1 + j\frac{f}{f_L}}$$

这是高通电路的一个标准形式，这个形式你们要记住。

> **易错点**：别搞混了——高通电路，它有的是**下限**截止频率。因为它是高通，底下有个限制，只要比这个下限频率高的，都可以过去。

为什么称之为高通电路？很清楚，在它的幅频特性上，频率越高它的幅值越大。当它大于下限截止频率之后，我们认为它的整个信号都能通过。

在 $f_L$ 的时候，它的相移是 $45^\circ$。这 $45^\circ$ 代表什么含义？$u_o$ 超前于 $u_i$，还是 $u_i$ 超前于 $u_o$？

$A_u = \frac{\dot{U}_o}{\dot{U}_i} = A_u \angle \varphi$，$\angle \varphi$ 就是那个 $\varphi$；这个家伙等于 $\frac{\dot{U}_o}{\dot{U}_i}$，谁在前面？$u_o$ 超前于 $u_i$。

> **提示**：我把这里 $45^\circ$ 当作一个**时间**的概念。为什么能把 $45^\circ$ 当作时间的概念？因为我们的坐标可以是 $\omega t$——$\omega t$ 使得我们可以用弧度或者度数来代替时间，这是学正弦交流电路当中最基本的概念。所谓 $u_o$ 超前 $u_i$，就是我的 $u_o$ 比 $u_i$ 提前 $45^\circ$ 达到正峰值。

#### 低通电路与上限截止频率

那低通长什么样？低通电路的 $A_u$ 我不给你们再推了，没有推的必要。低通电路的 $A_u$ 最后等于：

$$A_u = \frac{1}{1 + j\frac{f}{f_H}}$$

大家注意这两个有什么区别？上面那个叫高通，那个形式叫低通。$f_H$ 是**上限**截止频率，同样它也是等于 $\frac{1}{2\pi RC}$。而且我们可以看到，随着频率的增加，这家伙在衰减。

所以你可以预知：**耦合电容引起的电路是一个高通电路；极间电容引起的电路肯定是一个低通电路。** 你们脑子里首先就有这个概念。

相频特性那边，在 $f_H$ 的时候，这个家伙等于 $-45^\circ$，含义是 $u_o$ **滞后**于 $u_i$。

```text
   高通与低通，一句话对照

   高通：低频被挡 → 底部留一个台阶 → 记「下限」 f_L → u_o 超前
   低通：高频被挡 → 顶部压下来     → 记「上限」 f_H → u_o 滞后

   共性：  f_c = 1 / (2*pi*R*C)，定义为幅值降到 1/sqrt(2) 的那一点
```

| 对照项 | RC 高通电路 | RC 低通电路 |
|---|---|---|
| 标准形式 | $A_u = \dfrac{j f/f_L}{1 + j f/f_L}$ | $A_u = \dfrac{1}{1 + j f/f_H}$ |
| 截止频率 | 下限 $f_L = \dfrac{1}{2\pi RC}$ | 上限 $f_H = \dfrac{1}{2\pi RC}$ |
| 幅频走向 | 频率越高幅值越大 | 频率越高幅值越小 |
| 截止点相移 | $+45^\circ$ | $-45^\circ$ |
| 相位关系 | $u_o$ 超前 $u_i$ | $u_o$ 滞后 $u_i$ |
| 在放大电路里对应谁惹祸 | 耦合电容 | 极间电容 |

> **结论**：对低通电路，$u_o$ 是滞后的；对高通电路，$u_o$ 是超前的。它们都会引起相对应的相移。

### 线性坐标画不下去，于是有了波特图

下面这个问题：实际上这样画是很不负责任的。那个 $f$ 那么一画，很不负责任。我提一个问题出来，你把刻度给我画出来——如果用线性坐标，频率响应我可以从 $1\ \text{Hz}$ 算起（咱们少说嘛，就 $1\ \text{Hz}$，甚至还可以零点几赫兹，就算你 $1\ \text{Hz}$ 便宜点吧）。

上面呢？轻轻松松几十千赫兹，再轻轻松松几十兆，几百兆。我们现在总线一个多吉赫兹，$1\ \text{GHz}$。$2\ \text{G}$ 是总线频率吗？$2\ \text{G}$ 是 CPU 频率，总线频率是 1066 好像是。

那么画呀：$1\ \text{Hz}$ 后面一个 $1\ \text{GHz}$，给我拿一条直线画出来。而且 $1\ \text{Hz}$ 得可测量，懂我的意思吧？你别把 $1\ \text{Hz}$ 给弄成没了呀，你得拿电子显微镜看 $1\ \text{Hz}$。弄这么小一个，然后绕地球好几周，总算把那 $1\ \text{G}$ 画出来。

怎么办？**对数坐标。**

一旦有了对数，$1\ \text{Hz}$、$10\ \text{Hz}$、$100\ \text{Hz}$、$1000\ \text{Hz}$，每增加 10 倍，它的格数是一样的。你们不说嘛，从秦始皇到现在没几格，5000 年。很短的一个长度就可以把 $1\ \text{GHz}$ 实现出来了。

对数发明出来我是太佩服人家了。我学对数的时候觉得这东西真讨厌，什么上啊下啊上；后来我觉得，真是好东西啊，没有它怎么过呀。

幅值也一样。好的集成放大器可以达到上千万倍的放大倍数，一样的道理——那也用个对数。看到吧？不是单对数了，是**双对数**。

```text
   线性频率轴：绕地球好几周才画得完 1 Hz → 1 GHz

   1 Hz |······················································| 1 GHz
        ↑ 每 10 倍要挤在同一条直线上，越往右越密，最后根本分辨不了

   对数频率轴：每一格就是一个十倍频

   1 Hz |--+----+----+----+----+----+----+----+----+----+| 1 GHz
        1   10  100  1k   10k 100k  1M  10M 100M  1G
        ↑ 每增加 10 倍，格数完全一样
```

用了双对数还有什么好处？咱们算总 $A_u$ 的时候，不就是各级乘起来吗？$A_{u1} \times A_{u2} \times A_{u3} \times A_{u4}$，它变成什么了？一到对数里面就变成加了。**乘除变加减**，太神奇了——你不用的话，你根本就体会不到。

你知道还有什么？以前没有计算器的时候用什么？叫对数的计算尺。

举一个例子，你们要知道对数给人类社会带来的这么一个进步。$a^x$，如果 $x$ 是 2，在座各位全会算；$x$ 是 3.14 呢？怎么弄？不会再算了吧？有了对数，一气解决了：$\log a$ 可以在那个尺上查出来，乘完了之后再做个反对数，就算出来了。

让我们的天文学也一样——地球到月亮觉得挺远的，然后地球到太阳、银河系，银河系外面的东西，天文学的东西不能想，越想越头疼，现在都可以表示出来了。

所以我们就把对数移植到这儿来，用双对数坐标系来分析我们的频率特性。这种频率特性我们称之为**波特图**。

### 先把高通、低通这两条曲线摆正

上节课留给大家回顾过两个电路：一个是高通，一个是低通。它们的传输特性我一起摆在这儿。

这里我要先把一件最容易搞混的事说死，因为每年都有人栽在这儿：

> **易错点**：看着下标 $f_H$ 就以为它是高通电路的参数——错。$f_H$ 是**低通**电路的上限截止频率；$f_L$ 才是**高通**电路的下限截止频率。这两个下标跟电路的归属是**交叉**的，一混全盘皆输。

公式里那个 $C$ 大家都认识，就是电容。可我要问的是那个 $R$。

以后你们碰到的电路绝不会像黑板上画得这么干净：电容还是那一个电容，可周围可能堆着一大堆电阻，还带着内阻的信号源。这时候公式还能不能用？能用。但这个 $R$ 到底是哪一个 $R$？

答案是——**从电容两端看进去，把其余电路做一次戴维宁等效，得到的那个等效内阻**。

这就是我一直强调戴维宁定理的原因。基电里"等效"这两个字你要是没真正吃透，后面所有的分析都会别别扭扭。上面那条干净的 RC 曲线和你的真实电路之间，隔着的就是"等效"这一层。

### 分贝到底是个什么刻度

有了分频的概念之后我们来看，波特图到底怎么画。肯定是照着公式画——但先别急，我们先把纵坐标这个刻度弄明白。

纵坐标写的是 $20\lg|A_u|$，这就是**分贝**。我们平时看到的"多少分贝的噪声""多少 dB 的增益"，用的都是这一套。

那么我问你们一个特别基础的问题：**0 dB 代表什么意思？**

0 dB 代表**不放大**，代表**没有增益**，该多少就是多少。dB 是正的就代表放大了，dB 是负的就代表衰减——注意用词，是"衰减"，这两个字很专业，也是我们一直在用的词。

所以以后你看到某个频段的增益是零点几、十几、几十，别再去跟零点几较劲了，dB 那一栏清清楚楚：零以上的是增益、是加大；零以下的是衰减。**就这么简单，但很多人就是绕不过这个弯。**

### 高通电路的波特图：三个区段

好，现在正式画。高通电路幅频特性的 dB 表达式是这样来的：把传递函数求模，上面取模很清楚是 $f/f_L$，分母是 $\sqrt{1+(f/f_L)^2}$，于是

$$
20\lg|A_u| = 20\lg\frac{f}{f_L} - 20\lg\sqrt{1+\left(\frac{f}{f_L}\right)^2}
$$

先说一句：**写公式不是目的，公式代表的是它的物理含义。** 你如果只是把这个式子念一遍，那不算本事。真正要会答的是——它凭什么就能画成那个样子？

答案就是分三个区段去看。我们先定性、再近似，这是工程上惯用的打法。有时候太拘泥于逐点详细计算，某些东西你反而很难看明白。

```text
20lg|Au|
     |                                      ____________  0 dB
     |                     _____/
     |                _____/
     |           _____/
     |      ___/
     +--------.---------------------------------------------> f
     |      /
     |    /
     |  /
     |/
     +--+-----+---------------------------------------------
      0.1fL  fL
```

读图：拐点（图中那个圆点）就落在 $f_L$ 上，高度是 **−3 dB**，也就是 $|A_u|$ 降到了原来的 $1/\sqrt2$；拐点右边是一条水平的 0 dB 线，左边是一条以 $f_L$ 为拐点、以 $0.1f_L$ 为终点的斜线，斜率就是每十倍频 20 dB；横轴上 0.1 倍频和 10 倍频这两个位置，分别对应相频特性的两个转折点。

#### 转折点上：$f = f_L$

这是最特殊的一种情况，不用近似：电路的传输比正好降到原来的 $\frac{1}{\sqrt2}$。取 dB 就是

$$20\lg\frac{1}{\sqrt2} = -10\lg 2 \approx -3\ \text{dB}$$

所以转折点的高度就是 **−3 dB**。与此同时这个点上的**相角正好是 +45°**，这是高通的标志。低通在同一位置则是 −45°。

#### 平台段：$f \gg f_L$

分子分母对 $f$ 的依赖几乎是同一个东西，两项大刀阔斧地抵消掉，剩下 $\lg 1 = 0$，也就是 **0 dB**。

这说明什么？当频率远远高于下限截止频率时，高通电路**没有衰减**。滤波电路不会去放大——除非是谐振的，谐振不在这里讨论。

#### 斜线段：$f \ll f_L$

这时候分母里那个根号里的 1 远远压过 $\left(\frac{f}{f_L}\right)^2$，根号里只剩 1，分母就是 1，于是只剩分子那一项 $20\lg\frac{f}{f_L}$ 单独存在。画到图上就是一根直线。

这根直线的含义非常具体：

| $f$ 相对 $f_L$ 的变化 | 传输比的变化 | dB 的变化 |
| --- | --- | --- |
| 降为原来的 $1/10$ | 衰减为 $1/10$ | 下降 $20\ \text{dB}$ |
| 降为原来的 $1/100$ | 衰减为 $1/100$ | 下降 $40\ \text{dB}$ |

所以这根线叫**每十倍频 20 dB** 的衰减线。这里藏着一个特别有用的反推：

> **结论**：只要看到"每十倍频 20 dB"的斜率，就知道这里是一级高通；如果斜率是每十倍频 40 dB，那就是两级。

为什么 40 dB 对应两级？上节课讲过，对数电路把原来的**乘法变成了加减**。级数翻倍，在幅频相乘的意义下就相当于乘以一个平方；取对数之后，平方不就变成加倍了吗。所以你只要扫一眼波特图的斜率，这个放大电路里有几级高通衰减、几级低通衰减，非常清晰——这是波特图最好用的一点。

#### 从三段到一根折线：工程近似

如果真按精确公式逐点画，那条曲线在 $f_L$ 附近应该是一段圆滑的过渡曲线（也就是图上本该有的虚线部分），太麻烦了。而且实际上我们几乎不会真的去画那一段——**要想滤掉某个波，你的工作点离截止频率本来就差得很远**，根本不会贴着 $f_L$ 去设计。

所以真正做的时候，我们就把它大刀阔斧地近似掉：

- 转折点取在 $f_L$；
- 右边的 10 倍 $f_L$、左边的 0.1 倍 $f_L$，分别对应相频特性上已经达到稳定的位置（10 倍处相角为 $0^\circ$，0.1 倍处为 $90^\circ$）。

于是画一张高通波特图的动作分解开来就三步：

1. **先找 $f_L$**：$f_L = \dfrac{1}{2\pi RC}$，其中 $R$ 是从电容 $C$ 两端看进去的等效电阻——这是关键中的关键；
2. **在 $f_L$ 上立拐点，高度 −3 dB**；
3. **左边画每十倍频 20 dB 的斜线，右边画水平线**，顺手把 $0.1f_L$、$10f_L$ 标出来。

完事了。很简单，但**一定要理解这些背后的含义**，不然换个电路你就不会了。低通电路完全一样，只是左右翻过来。

### 拿到一个放大电路，全频域怎么扫

有了上面这套东西，我们就能真正拿它干活了。

因为一个放大电路既有高频特性、又有中频特性、还有低频特性，这三段必须**联合**起来看。我问你们一个终极的问题：

> 现在给你一个阻容耦合的单管晶体管放大电路，让你画出它从低频一直扫到高频的**全频域波特图**，你该怎么下手？

我们先老老实实地清点一下手里的工具。就目前学的这些知识，你能分析出哪几段？

**能做出来的有两段。** 一是中频段——前面学的那一大堆东西全都是中频段的：既不考虑前面阻容耦合电容的影响，也不考虑后面极间电容和分布电容的影响，不用去考虑它，直接算。其次是把阻容耦合的等效高通电路单独拿出来分析，把高通那一段给补上。

**做不出来的是高频段。** 为什么？因为你们手里**没有模型**。极间电容该怎么算？它应该加在哪个节点上？值是多少？连分布电容都不考虑、只考虑极间电容，你也不知道它该安在哪儿。

假如这些值都直接给我了，我敢说你们肯定能搞定——无外乎又是一个低通电路而已。所以问题不在低通电路，问题在模型。

那么全频域分析的完整路线就很清楚了：

```text
                     full band
                        |
        +---------------+---------------+
        |               |               |
   [ midband ]     [ low band ]   [ high band ]
     can do          can do          blocked
   caps ignored    R-C coupling      no model
        |               |               |
        +---------------+---------------+
                        |
                        v
        the key : fetch the transistor's
             high-frequency model
                   ( hybrid  pi model )
```

读图：三条支路分别对应全频域波特图的三段。中间那段我们前面就做完了；右边那段卡住了，卡住的原因就写在图下面——**先得把晶体管的高频等效模型拿到手**。

所以关键点是要去抓**等效模型**。前辈们在这件事上做了很大一番努力，给了我们一个非常好的东西——它就是我们下面要拆的那个模型。

### 混合 $\pi$ 模型：从 $h$ 参数一步步拆出来

这个模型叫作**混合 $\pi$ 模型**，它是考虑了**发射结电容和集电结电容**这两样极间结电容之后得到的模型。

在动手之前我先把话撂在这儿：

> **提示**：我**不喜欢**噔一下就把那个完整图形甩给你。你一看就会说：哎哟，如此复杂之图形，让我不知道该如何应对。放心，我不这么干。咱们一步一步搭，搭完你自己再看那张图，它一点都不复杂。

#### 第一步：先把电阻拆开，找到 $b'$

我们从最熟悉的那个东西出发——$h$ 参数等效模型。这个模型大家闭着眼睛都能画出来。

模型里那个 $r_{be}$，是谁和谁的合成？是 $r_{bb'}$ 和 $r_{b'e}$。

$$r_{be} = r_{bb'} + (1+\beta)\frac{U_T}{I_{EQ}}$$

其中 $r_{bb'}$ 是基区的体电阻，一般在 $100 \sim 300\ \Omega$。基区掺杂浓度极低，所以它的体电阻是不能忽略的；集电区和发射区的体电阻非常小，一般情况下我们**忽略不计**。

现在看这个模型里还缺什么。缺两个电容：集电结那块一个，发射结这块一个。

要把电容加上去，就必须找到 $b'$ 这个点——因为电容的一端就接在 $b'$ 上。$b'$ 找不到，电容就加不上去，对不对？

怎么找？**把 $r_{be}$ 拆开。** 上面是 $r_{bb'}$，下面就是 $r_{b'e}$。这一步你们每个人都会拆，不用我多讲。

#### 第二步：再把电容和电阻添上去

拆开 $r_{be}$ 之后，往上添东西就有章法了。我们用基电里整理电路最常用的那种**节点法**——一个元器件往两个节点中间添，还有什么难的？

- $b'$ 到 $e$ 之间，除了 $r_{b'e}$，再添一个电容——这就是 $C_{b'e}$，在这张图里它的名字叫 **$C_\pi$**；
- $b'$ 到 $c$ 之间，添一个 $r_{b'c}$（集电结电阻），再添一个电容 $C_{b'c}$，它的名字叫 **$C_\mu$**；
- $c$ 到 $e$ 之间，原来 $h$ 参数里本来就带着 $r_{ce}$，这一块不用动。

添完了。两个长得一样了吧？

```text
          r_bb'         r_b'e   C_pi    g_m*U_b'e  r_b'c    C_mu
   b o +--/\/\/---+-------+-------+---------+--------+------||--+-o c
       |          |       |       |         |        |          |
       |          |       |       |         v        |          |
       |          |       |       |     ( dep. )     |          |
       |          |       |       |         |        |          |
       |          |     /\/\/     |         |        |          |
       |          |       |       |         |        |          |
       |          |       |     ----        |        |          |
       |          |       |       |         |        |          |
       |          |       |       |         |      /\/\/        |
       |          |       |       |         |        |          |
   e o +----------+-------+-------+---------+--------+---/\/\/--+-
```

读图：从基极 $b$ 进来先串 $r_{bb'}$ 到内部节点 $b'$；从 $b'$ 到发射极 $e$ 之间并着四条支路——$r_{b'e}$、$C_\pi$、受控电流源 $g_m U_{b'e}$、$r_{b'c}$；从 $b'$ 到集电极 $c$ 之间是电容 $C_\mu$；最后 $c$ 到 $e$ 之间跨着 $r_{ce}$。

这里补一句：$r_{ce}$ 是个**非常大**的电阻，几十千欧的量级。但它跟后面负载 $R_L$ 比起来，一般算大的了——所以在 $h$ 参数模型里我们通常干脆不画它，画了也没意义。可在 $\pi$ 模型里我们把它保留，因为接下来要用它说话。

#### 第三步：电流方向和跨导 $g_m$

还有一个关键点我一直没写——**电流方向**。

对，这个必须标出来。受控源和它的控制电路之间的电流方向，一定要标清楚，这是画模型的规矩。

那为什么我一开始没标？因为这里有说法。原来那个受控源写的是 $\beta I_b$，现在还能叫 $\beta I_b$ 吗？这个 $I_b$ 已经非彼 $I_b$ 了。原来那个 $I_b$ 是从 $r_{bb'}$ 一路流到 $r_{b'e}$ 的同一个电流；现在不是了——中间插了 $b'$ 这个节点。

于是控制量换成了电压：支路两端那个电压是 $U_{b'e}$，受控电流是 $g_m U_{b'e}$。这里引入了一个新参数——**跨导** $g_m$。

$g_m$ 的量纲是电导，它的定义式下面自然会推出来。

### 这个模型为什么敢从高频通吃到底

模型搭完了，现在要说它的来路。

#### 外特性等效和物理模型是两回事

我们说过的等效模型其实有好几种。一种是**外特性等效**——在某些特定条件下才成立的等效。我们的 $h$ 参数实际上就是一个外特性的等效，我是**从外特性出发**把它推出来的。

> $h$ 参数的使用条件：中频区域，或者更宽一点说，**中低频区域**。

而 $\pi$ 模型更接近另一种——**物理模型的等效**。

> **结论**：物理模型的等效在**任何区域**都可以使用。所以 $\pi$ 模型这个等效是"通吃"的——从高频到低频它都成立。

那我就追问你一个非常要命的问题：

> **在中低频段，我用 $h$ 参数模型和用 $\pi$ 模型分析同一个电路，得到的结果一样吗？**

答案是**一样**。

为什么？因为 $h$ 参数本来就是这个电路在中低频段的等效模型，拿它去分析中低频肯定没错；而 $\pi$ 模型是通吃型的，中低频自然也在它的射程之内。两个都对同一个对象建模，结果当然必须一致。

这条结论非常重要，因为它给了我们一把钥匙：**在中低频时两者等效，所以可以用 $h$ 参数去求 $\pi$ 模型的参数。**

#### 把模型弄残，它就退回 $h$ 参数

我们把这个事情**做实**，不然口说无凭。

在中低频段，$C_\pi$ 和 $C_\mu$ 这两个家伙等于无穷大，直接开路——它们本来就不该存在，我们现在非要把完整的模型**弄成不完整的、弄残它**。

接着处理 $r_{b'c}$。它是集电结的电阻，而集电结是**反偏**的。反偏电阻一般有多大？锗管的小一些，大约 $100\ \text{k}\Omega$；硅管大约 $500\ \text{k}\Omega$。这么大的电阻，并联在电路里几乎相当于断路——干掉。

它一干掉，$r_{ce}$ 也就跟着显形了。$r_{ce}$ 几十千欧，跟后面那个 $R_L$ 一比更大——也干掉。

现在你再看这张图，它马上恢复成什么模型了？**就是 $h$ 参数模型。**

所以在中低频范围内，$\pi$ 模型退化以后和 $h$ 模型一模一样，起完全相同的作用。记住这一点，很重要。

### 单向化：把碍事的 $C_\mu$ 拆成两个电容

不过 $\pi$ 模型毕竟还略显复杂，我们还得继续简化。这里有一个**非常讨厌**的东西，你猜是哪个？

就是 $C_\mu$。它横跨在 $b'$ 和 $c$ 之间，一头在这头在那，怎么画怎么尴尬。你要去分析高通电路、低通电路，它就在那儿横着，非常麻烦。

所以我们必须对它做一件事：**单向化**。

#### 端口等效，算出 $C_\mu'$

先解释一下什么叫单向化，它其实就是我们用得极熟的**戴维南等效**。

具体说：把 $b'$ 到 $c$ 这一整块（$C_\mu$ 和受控源那一支的耦合）**扣一个黑盒子**，然后从两个端口各自往里看——

- 从 $b'$ 端看进去，等效出一个电容来，记作 $C_\mu'$；
- 从 $c$ 端看进去，等效出一个电容来，记作 $C_\mu''$。

一旦这么一等效，跨接的 $C_\mu$ 就被劈成了两个分别接地的并联电容。问题一下就简单了：这边一个电容，那边一个电容，各管各的。

```text
              b'                        c
              o--------- C_mu ----------o
              |                         |
            C_mu'                     C_mu''
              |                         |
              o----------- e -----------o
```

（读图：横跨 $b'$ 与 $c$ 的 $C_\mu$ 被等效成两个各自对 $e$ 的并联电容，这就是"单向化"。）

怎么算？我给你们算一个 $C_\mu'$，$C_\mu''$ 你们同理推。

**第一步，端口条件。** 不管等效成什么，总归是从端口特性来的：换过去以后，端口上的电压 $U_{b'e}$ 和流过端口的电流 $I_{C\mu}$ 都必须**保持不变**。电压除以电流，就是容抗：

$$X_{C\mu'} = \frac{U_{b'e}}{I_{C\mu}}$$

**第二步，算 $I_{C\mu}$。** 它流过 $C_\mu$，所以就是 $C_\mu$ 两端的电压除以它的容抗：

$$I_{C\mu} = \frac{U_{b'e} - U_{ce}}{-jX_{C\mu}} = j\omega C_\mu\left(U_{b'e} - U_{ce}\right)$$

**第三步，消掉讨厌的项。** 代回去你会发现 $U_{ce}$ 消不掉。没关系，设一个参数 $K$ 把它带走：

$$K = \frac{U_{ce}}{U_{b'e}}$$

这个 $K$ 有点类似电压放大倍数的味道——它和电压放大倍数是相关的。

$$X_{C\mu'} = \frac{U_{b'e}}{j\omega C_\mu(U_{b'e} - U_{ce})} = \frac{1}{j\omega C_\mu(1 - K)} = \frac{1}{j\omega C_\mu'}$$

$$\boxed{\;C_\mu' = (1 - K)\,C_\mu\;}$$

到这里就有了。

#### 这个 $C_\mu'$ 是可变的

推导完了，但真正要紧的是下面这句话，我再强调一遍：

> **易错点**：$C_\mu'$ **不是定死的一个常数**，它是**随电路状态变化**的量。根据 $U_{ce}$ 和 $U_{b'e}$ 的比值不同，在电路的不同工作状态下，它会表现出不同的值来。一定要把这句话记牢。

顺着还能问一句：一般情况下，$C_\mu'$ 比 $C_\mu$ 大还是小？

**大。** 为什么？因为 $K$ 一般是负的——$U_{ce}$ 一般是负的嘛。所以 $1 - K > 1$，等效电容自然变大。

至于 $C_\mu''$，这里有个很好的消息要告诉大家：**$C_\mu''$ 的容抗非常大**，比起 $R_L$ 来说又可以忽略不计了。所以它直接被扔掉。

#### 简化之后的样子

最终简化出来的图形是这样的：

```text
          r_bb'          C_pi'         g_m*U_b'e r_b'e
   b o +--/\/\/---+-------+-------+-------+-------+--------+-o c
       |          |       |       |       |       |        |
       |          |       |       |       v       |        |
       |          |       |       |   ( dep. )    |        |
       |          |       |       |       |       |        |
       |          |       |       |       |     /\/\/      |
       |          |       |       |       |       |        |
       |          |       |     ----      |       |        |
       |          |       |       |       |       |        |
   e o +----------+-------+-------+-------+-------+--------+-
```

读图：$C_\mu$ 没有了，跨接耦合被打断；原来那个电容的位置上换成了一个更大的等效电容

$$C_\pi' = C_\pi + C_\mu'$$

再把 $C_\mu'$ 状态相关的性质默念一遍。**一定要在脑子里深深地打上这个烙印。**

### 哪些参数查手册，哪些还得自己求

最后我们收个尾：这个模型建起来了，模型里这一堆参数，哪些是我们已经知道的，哪些还得自己想办法？

**手册上直接能查到的有三个：**

| 参数 | 手册上的对应 | 说明 |
| --- | --- | --- |
| $r_{bb'}$ | $r_{bb'}$ | 基区体电阻，$100 \sim 300\ \Omega$ |
| $C_\mu$ | $C_{ob}$ | 输出电容，指的就是 $b$、$c$ 之间的这个电容 |
| $f_T$ | $f_T$ | 特征频率 |

**还剩下三个得靠我们自己求：**

$$C_\pi, \qquad g_m, \qquad r_{b'e}$$

怎么求？这里先按住，我们下一段接着往下走。

最后再把整条线串一遍，你就知道今天这四十分钟到底干了什么：

- **低频段**——阻容耦合等效成高通电路，用上一节的波特图画法解决；
- **中频段**——前面那一大套常规分析直接算，不用考虑任何电容；
- **高频段**——靠今天搭出来的这个混合 $\pi$ 模型，把它等效成一个低通电路，再用同样的波特图画法解决；

## β 从哪儿开始掉下来，以及单管放大电路怎么分频段算清楚
> 对应块：BLK25 | 覆盖分集：P25 | 块标题（分集名）：《25-晶体管电流放大倍数β的频率响应与单管放大电》

手册里能查到的参数，我们都能查到。刚才我给了大家一个兴奋点，你们把头全抬起来了——目标已经达成，那就该把注意力收回来，回到正题上。

收回来之后一看，手册里查不到、必须靠公式推的东西还剩三个：$r_{b'e}$、$g_m$、$C_\pi$。$\pi$ 参数等效模型里就缺这么几块，其余的都有了。这一讲要干的事，就是把这三块补齐。

而且补的过程不枯燥。解决 $C_\pi$ 的那一步，会顺手把我们心里攒了很久的两个疑问一起解决掉：$f_T$ 到底是个什么量，以及共基放大电路的频响凭什么那么好。这两个疑问，我都留在后面兑现。

### $r_{b'e}$：静态工作点直接给

$r_{b'e}$ 在座的各位都会，用不着我讲。它由静态工作点推出来：

$$r_{b'e} = (1 + \beta_0)\frac{U_T}{I_{EQ}}$$

搞定一个。

### $g_m$：用 h 参数和 π 参数在低频等价这件事推出来

现在我问你们，$g_m$ 有没有办法搞定？提示过你们了——我把它从模型里"弄掉"了，那一块变成了 $C_\pi'$。有想法吗？$g_m$ 怎么求？用什么方法？

用 $\beta$！用 $\beta I_B$ 相等。关键词出来了：**用 h 参数等效模型和 $\pi$ 参数等效模型在低频段是同样效果**。因为低频段里那个"谁"呀，是 $\beta_0$；所以在低频段，$\beta_0$ 这个东西就被我们毫不留情地干掉了。

思路一打开就收不住了。现在来看，如果改用 $g_m$ 来算，$I_C$ 和 $I_B$ 之间是什么关系？

- $I_C$ 是什么？是 $g_m \cdot U_{b'e}$；
- $I_B$ 是什么？是 $\dfrac{U_{b'e}}{r_{b'e}}$。

你们千万别含糊。为什么？因为 $\beta$ 那套模型里的那个东西被拿掉之后你就随便了；那个东西**没拿掉**的时候还蛮讨厌的，知道吧？那东西一拿掉，这两端的电流不就串上了吗？

于是

$$\frac{I_C}{I_B} = g_m \cdot r_{b'e} = \beta_0$$

$$g_m = \frac{\beta_0}{r_{b'e}}$$

再往下深究一步：静态的时候 $r_{b'e}$ 又等于 $(1+\beta_0)\dfrac{U_T}{I_{EQ}}$，代进去，如果 $\beta_0$ 比较大的话，这个家伙就约等于 $\dfrac{I_{EQ}}{U_T}$ 了。也可以说它就是 $\dfrac{I_{EQ}}{U_T}$ 再乘一个 $\dfrac{\beta_0}{1+\beta_0}$。

> **提示**：算出最后那个表达式是什么，其实无关紧要。我不希望你们去背它——清楚吧？一背，脑子最后就错乱了。我希望你们记住的是**怎么推出来**：低频段 h 参数和 $\pi$ 参数等效，按这个思想一推，$g_m = \beta_0/r_{b'e}$ 就自己掉出来了。这个思想比公式值钱。

现在还欠一个账，$C_\pi$。这个家伙到底怎么求？解决它的过程当中，我们会发现很多好玩的东西。

### β 不再是一个数：它为什么会有频响

先把这个疑问摆出来：$f_T$ 是什么？肯定和 $f_T$ 相关，可怎么研究？

逻辑要清楚。$f_T$ 是个什么量？当频率不断上升的时候，电流放大倍数会怎么样？会下降。随着不断下降，当频率上升到 $f_T$ 的时候，$\beta$ 最终下降到 1。所以想知道 $f_T$ 到底是多大，必须研究一个关系——$\beta$ 和频率的关系，也就是 $\beta$ 的频响。

至于 $\beta$ 为什么会有频响，把模型画出来就明白了。这里面有 $C_\pi'$，看到吧？从定义上说，$\dot\beta = \dfrac{\dot I_C}{\dot I_B}$，另外还有一个 $U_{CE}$。当时咱们分析的时候，$U_{CE}$ 是什么？还是直流。算 $\beta$ 的时候，$U_{CE}$ 是常数。

那么问题来了——**为什么现在我在这个 $\beta$ 上面加了个向量符号？** 什么道理？

原来我们一直把 $\beta$ 当成一个像标量一样的数。现在跟低频段不一样了：低频段我用 $\beta_0$ 来表示，注意到没有？这一个 $\beta$ 因为 $C_\pi'$ 的存在，$I_B$ 现在由**两个电流**组成——一个电阻电流，一个电容电流。所以 $I_B$ 和 $U_{b'e}$ 必然不会同相位了；而 $g_m U_{b'e}$ 那一支和 $U_{b'e}$ 是同相位的。它俩的比值随着频率增长，一定会有大小的变化，也会有相位的变化。所以 $\beta$ 一定是一个向量。

再看 $U_{CE}$。在这种分析里，$U_{CE}$ 是一个不变的量。这代表什么含义？$U_{CE}$ 不变，在交流等效当中，C 和 E 之间相当于什么？有没有电压？没有。这回很干脆，非常好——因为 CE 之间没有任何电压的变化，说明它没有交流含量。那么画交流通路的时候，CE 之间相当于**短路**。

条件齐了，表达式马上就出来：

$$\dot\beta = \frac{g_m \dot U_{b'e}}{\dfrac{\dot U_{b'e}}{\dfrac{1}{r_{b'e}} + j\omega C_\pi'}} = \frac{g_m}{\dfrac{1}{r_{b'e}} + j\omega C_\pi'}$$

并联我就干脆直接用并联来表示了，是不是？

### 这是低通还是高通：别套公式，把 ω 带进去

现在我问你一个问题。这样一个电路，它是高通还是低通？不知道了？很简单，稍微想一下——你不用去跟刚才那个东西较劲，**你就把 $\omega$ 往这里带**：让 $\omega$ 变成无穷大，你看这家伙是变大了还是变小了？变小了。$\omega = 0$ 的时候呢？变大了。那就是低通嘛。

> **易错点**：活学活用，千万别套公式，一套公式死定了，我跟你讲。判断高通低通，把 $\omega$ 的两个极端值代进去看大小，秒出结果。

低通就好办了。上下同乘一个 $r_{b'e}$：

$$\dot\beta = \frac{g_m \cdot r_{b'e}}{1 + j\omega r_{b'e} C_\pi'} = \frac{\beta_0}{1 + j\omega r_{b'e} C_\pi'}$$

上面那个 $g_m \cdot r_{b'e}$ 是谁呀？$\beta_0$。看到了吧，这回更靠谱了——一个漂亮的、和 $\beta_0$ 相关的低通。

那低通的上限截止频率是多少？马上就出来了：

$$f_\beta = \frac{1}{2\pi r_{b'e} C_\pi'}$$

$f_\beta$ 求出来，波特图就出来了。因为是直接耦合，低频段没有问题；从 $f_\beta$ 开始啪地下来；相频特性每个十倍频程走 45°，10 倍频和 0.1 倍频对应的地方就是 $-3\text{dB}$ 那两个点。

然后注意这块——这块高度是 $20\lg \beta_0$。**谁蹦出来了？** 看到了吧？很重要的一个东西跳出来了。谁啊？$f_T$。

$f_T$ 的时候 $\beta$ 等于 1，所以在幅频特性上它就是一个**过零点**。

### $f_T = \beta_0 f_\beta$，以及由此把 $C_\pi'$ 倒推出来

$f_\beta$ 和谁紧紧绑定了？$C_\pi'$。所以我现在只要再建立 $f_\beta$ 和 $f_T$ 之间的关系，就可以从 $f_T$ 反推出 $C_\pi'$ 了。看到吗？这非常重要。

怎么建立？$f = f_T$ 的时候 $\beta$ 等于 1，把 $f_\beta$ 代进去，这个低通电路的参数就变成：

$$\dot\beta = \frac{\beta_0}{1 + j\frac{f}{f_\beta}}$$

什么时候这个家伙约等于 1？当 $\beta_0$ 比 1 大很多的时候，它的模就是 $\beta_0$；要让整个式子的模压到 1，就相当于 $\dfrac{f}{f_\beta}$ 要约等于 $\beta_0$。而这个 $f$ 就是 $f_T$，所以

$$f_T = \beta_0 f_\beta$$

> **提示**：这一步**不必跑到波特图上去拉直线推**，直接在这块代数式子里看就能看出来。看到没有？它的模是 $\beta_0$，模压到 1 就要求 $f/f_\beta \approx \beta_0$。

把 $f_\beta$ 再带回来，$C_\pi'$ 就进去了，我们终于知道 $C_\pi'$ 和 $f_T$ 之间是什么关系了——$C_\pi'$ 可以用 $f_T$ 推出来，没问题了吧？

那还差最后一步：$C_\pi'$ 里面装的到底是什么？

$$C_\pi' = C_\pi + C_\mu' = C_\pi + (1 - K)C_\mu$$

$K$ 是什么？$K = \dfrac{U_{ce}}{U_{b'e}}$。那我现在问你，$U_{ce}$ 等于多少？在这里等于多少？0——它已经短接了嘛。所以 $K = 0$。于是

$$C_\pi' = C_\pi + C_\mu$$

你用不着去测算什么别的了。再把 $C_{ob}$ 往里一带，$C_\pi$ 就可求了。

到这一步，$f_T$ 是个什么东西，你们清楚了吧？

### 共基的频响为什么好：$\alpha$ 与 $f_\alpha$

第四个东西，$\alpha$。大家都知道它是共基的电流放大倍数：

$$\alpha = \frac{\beta}{1 + \beta}$$

把它带进上一节那个 $\beta$ 的表达式里去，自己算。算完必然出现这样一个东西：

$$\dot\alpha = \frac{\beta_0}{1 + \beta_0 + j\frac{f}{f_\beta}}$$

自己推着玩去。我现在给你们东西了——你们给我求 $f_\alpha$。

$f_\alpha$ 是什么？定义是这样的：$\alpha$ 等于 $\dfrac{\alpha_0}{\sqrt{2}}$ 的时候。很好，你定义出来了——这就是共基电流放大倍数的**上限截止频率**。

那么算出来是多少？这块的分母要变成 1，等于上下同除一个 $1 + \beta_0$，那个 $f_\beta$ 就变成了 $f_\beta (1 + \beta_0)$，所以

$$f_\alpha = f_\beta (1 + \beta_0)$$

现在你们能看到什么了？用共基电流放大倍数的时候，共基电路的电流频率响应，其上限截止频率比共射的要**大 $1 + \beta_0$ 倍**。说明它什么？频带更宽了，宽了好多倍。

> **结论**：这就是为什么共基电路的频响好——它的频带比共射的宽了 $1 + \beta_0$ 倍。现在这个解释你们总算能自己说出来了。

好归好，它付出代价了。我说什么事都要付出代价，对不对？你们看到它付出代价了吗？什么？大点声。是电压的问题吗？不是，是放大倍数的问题。电流放大倍数也减小了 $1 + \beta_0$ 倍。你们脑子里要有这个概念：频带是宽了，但是增益小了。体积好像还没变，压扁了，拍拍扁——本来是高的，拍下来然后变宽了。就这个概念。

到这里，我们通过这一套分析知道了怎么求 $C_\pi$，知道了 $f_T$ 是什么含义，也知道了共基放大电路频响好的道理。

**举一反三**：场效应管的高频等效模型，思路和晶体管是一样的。它也有个 GS 的电容，这电容同样要做单向化处理，整个分析方法一模一样，所以我就不重复叙述了。

### 拿真枪实弹的干：阻容耦合共射电路的三频段分析

下面拿一个真家伙来干。晶体管放大电路，就分析这个——阻容耦合的一个共射。为了让你们感觉它还比较简单，我把前面那个耦合电容去掉了；因为再加上它，相当于两级高通。我现在留一级高通、一级低通这么一个概念。

问题是：对于这样一个电路，我们该怎么分析？问题已经抛给你们了。这是单管共射的频响，这个思路我其实已经给你们分析过了，但你们多少还有点手足无措的感觉，是不是？

给它分成三个频段：**低频段、中频段、高频段**。

- **中频段**：耦合电容导通掉，极间电容断路掉。这就是我们前面所学的方法，分析一二三章那个电路，绝对没有问题；
- **低频段**：耦合电容蹦出来了；极间电容在中频段都断路了，低频段更是断路；
- **高频段**：耦合电容短路掉，极间电容构成低通电路来分析。

很清晰。波特图出来之后长什么样，你们肯定能想到：首先得找准基准——中频段在哪儿。这部分是要抓住的。

### 第一步：把 $\pi$ 模型画出来

整个分析的步骤是这样的：

**第一，做 $\pi$ 参数等效，也就是画 $\pi$ 模型。** 而在 $\pi$ 模型的条件里，要求的正是 $r_{b'e}$、$g_m$ 和 $C_\pi$ 这三个参数。$r_{b'e}$ 和 $g_m$ 由谁求出来？由**直流通路**，求出 $I_{EQ}$，再把它们弄出来。$C_\pi$ 还不全是，它要用 $f_T$ 来求。至此所有参数准备完毕，$\pi$ 等效模型就出来了。

> **结论**：静态决定了动态。如果我们做这种电路分析时没有用到任何和静态相关的参数，那肯定错了——你们脑子里这个认识到现在应该非常清晰了。

那这个模型是怎么画出来的？应该怎么样一个步骤？先画什么通路？画交流通路。很棒，交流通路。交流通路得到之后，把那里的三极管拎出来做 $\pi$ 模型：三极管拎出来，先把 b、c、e 三点找到，然后中间凭空再给它生出一个点来——$b'$。

和我们用 h 参数稍微有一点不同的是，h 参数里是没有那个 $b'$ 的。现在我生出这样 $b'$ 一点，然后 b 和 $b'$ 之间连的是 $r_{bb'}$，$b'$ 和 e 之间连的是 $r_{b'e}$ 和 $C_\pi$，c 和 e 之间连的是一个受控电流源，受控值是 $g_m \times U_{b'e}$。

```text
        b            b'                c
        ●────r_bb'───●                 ●
        │            │                 │
        │            ├───r_b'e───┤     │
        │            │                 │
        │            ├────C_π────┤     │
        │            │                 │
        │            └─[g_m U_b'e]──┤  │
        │                              │
        ───────────────────────────────●
                                       e
```

读图：三端 b、c、e 引出来，b 到 $b'$ 之间是基区体电阻 $r_{bb'}$；$b'$ 到 e 之间并着 $r_{b'e}$ 和 $C_\pi$；c 到 e 之间是受控电流源 $g_m U_{b'e}$，方向由 c 指向 e。

这样的一个电路拎出来，实际上无论高频段、低频段还是中频段，我用的都是它。

### 中频段：$A_{usm}$ 到底比的是谁

先对中频下手。把中间那个电容定住：该断的断，该短的短。

中频段的 $A_{usm}$ 是个什么参数？$A_{usm} = \dfrac{U_o}{U_s}$。注意，是 $\dfrac{U_o}{U_s}$——因为现在放的是一个**电压型信号源**，要比的不是 $U_i$，比的是 $U_s$。

会算吗？拆成两半：

$$A_{usm} = \frac{U_o}{U_i} \times \frac{U_i}{U_s}$$

其中 $\dfrac{U_i}{U_s}$ 是什么关系？就是 $\dfrac{R_i}{R_s + R_i}$——我只要求出等效输入电阻 $R_i$ 就完事了。

另一半 $\dfrac{U_o}{U_i}$ 更容易，因为它们共同用的参数是 $U_{b'e}$：

$$U_i = \frac{r_{bb'} + r_{b'e}}{r_{b'e}} \cdot U_{b'e}, \qquad U_o = -g_m U_{b'e}\,(R_C \parallel R_L)$$

这是有载的，带着负载；如果不带负载，就把 $R_L$ 去掉。

### 低频段：$f_L$ 和那个耦合电容

低频段的模型长什么样？在这个电路的基础上加上谁？加上后面那个 $C$。

实际上，在这整个分析里我就可以对前端这一大堆电路做戴维南等效。这个戴维南等效的 $U_o'$ 就是这里的开路电压，也就是我刚才所说的空载电压；前端的输出电阻就是 $R_C$，然后这块是 $R_L$。简单了吧？所谓分析低频段，就是在中频的基础上再分析这么一个小电路——有难度吗？

```text
   U_o' ──┬─── R_C ───┬──── R_L ─── 地
          │           │
          └───── C ───┘
```

读图：把耦合电容 $C$ 单独拎出来看，从它两端看进去，电阻就是 $R_C$ 与 $R_L$ 串联，所以时间常数直接由这个串联和给出。

现在我问你，求这个电路的截止频率叫什么？低频段嘛——它是一个高通电路，高通电路有**下限截止频率** $f_L$。它的大小等于多少？

$$f_L = \frac{1}{2\pi (R_C + R_L) C}$$

带进去就完事了——相当于在中频的基础上再乘一个低频因子：

$$A_{us}(\text{低频}) = A_{usm} \cdot \frac{j\frac{f}{f_L}}{1 + j\frac{f}{f_L}}$$

### 高频段：$f_H$ 和从 $C_\pi'$ 看进去的内阻

同样的道理，高频段就是把 $C_\pi'$ 这个东西加进来分析。做法还是戴维南等效——把前面这个电路等效掉，做出一个低通来。

它的截止频率告诉我什么？$f_H$ 等于什么？

$$f_H = \frac{1}{2\pi R C_\pi'}$$

其中 $R$ 是什么？是从 $C_\pi'$ 两端看进去、前端的戴维南等效内阻。那应该是多少呢？

$$R = r_{b'e} \parallel \left(r_{bb'} + (R_S \parallel R_B)\right)$$

清楚吧？$f_H$ 就出来了。然后在我中频的基础上乘上高频因子：

$$A_{us}(\text{高频}) = A_{usm} \cdot \frac{1}{1 + j\frac{f}{f_H}}$$

### 总图：三个因子一乘，波特图就出来了

把低频和中频、高频的因子合起来，中间这段基准就是 $A_{usm}$：

$$A_{us} = A_{usm} \cdot \frac{j\frac{f}{f_L}}{1 + j\frac{f}{f_L}} \cdot \frac{1}{1 + j\frac{f}{f_H}}$$

这边是 $f_L$，那边是 $f_H$，中间夹着中频段的水平段——波特图就出来了。

### 本讲提到的题目

**题目**：把 h 参数等效模型完整地推到 $\pi$ 参数等效模型，并从中推出 $C_\pi'$，以及 $f_T$、$f_\beta$、$f_\alpha$ 三者之间的关系。要求不看讲义，独立推到位。

**解析**：这道题不需要另外给数值，前面几节的推导就是它的完整答案，读者可回溯查找——

- $g_m = \dfrac{\beta_0}{r_{b'e}}$ 来自 h 参数与 $\pi$ 参数在低频段的等价，即 $\dfrac{I_C}{I_B} = g_m r_{b'e} = \beta_0$；
- $r_{b'e} = (1+\beta_0)\dfrac{U_T}{I_{EQ}}$ 由静态工作点给出，代回去可进一步得到 $g_m \approx \dfrac{I_{EQ}}{U_T}$；
- 在 $U_{CE}$ 为常数（交流通路中 CE 短路）的条件下，$\dot\beta = \dfrac{g_m}{\dfrac{1}{r_{b'e}} + j\omega C_\pi'} = \dfrac{\beta_0}{1 + j\omega r_{b'e}C_\pi'}$，判断为低通，于是 $f_\beta = \dfrac{1}{2\pi r_{b'e}C_\pi'}$；
- 由幅频特性过零点条件 $\left|\dot\beta\right| = 1$ 得 $f_T = \beta_0 f_\beta$，代回即可由 $f_T$ 反求 $C_\pi'$；
- 再由 $K = \dfrac{U_{ce}}{U_{b'e}} = 0$ 得 $C_\pi' = C_\pi + C_\mu$，配合 $C_{ob}$ 求出 $C_\pi$；
- 最后 $\alpha = \dfrac{\beta}{1+\beta}$ 代入即得 $\dot\alpha = \dfrac{\beta_0}{1 + \beta_0 + j\frac{f}{f_\beta}}$，由 $\left|\dot\alpha\right| = \dfrac{\alpha_0}{\sqrt{2}}$ 得 $f_\alpha = (1+\beta_0) f_\beta$，这同时解释了共基电路频带更宽、但电流增益更小的原因。

### 思路不是顺着推，是倒着推

中频、高频、低频分别讨论。**好。** 中频的话先 h 参数等效求出 $r_{be}$，然后中频就出来了。低频的话加上那个 $C$ 就可以了。然后高频的话再用 $\pi$ 参数等效，根据那个 $\beta_0$、$r_{bb'}$、$r_{b'e}$ 求出它的 $g_{\text{m}}$，再从 $g_{\text{m}}$ 求出 $C_{\mu}'$，再求出 $C_{\pi}'$。

非常清晰。如果都这样，我就满意了，真的是这样。

但比这个答案更值钱的是下面这句：**整个的分析思路，实际上我们在解决一个工程问题的时候，思路往往是倒推的。**

什么意思？往往我要获得这个结果，我就必须获得什么，最后形成一条技术路线。

我要获得一个完整的等效，我肯定要把它的中频、高频、低频都求出来。那么总的来讲，我就需要一个电路作为分析基础。我需要知道是哪一个电路呢？是 $\pi$ 参数的等效电路。因为 h 参数在中频和低频是和 $\pi$ 是一样的，h 参数求中频没有问题；但 $\pi$ 参数等效电路是整个频域通吃的，所以我只要知道那一个。

知道了 $\pi$ 参数等效电路，等效电路我们画得出来，那么只需要求哪几个参数呢？$g_{\text{m}}$、$r_{b'e}$，还有——$C_{\pi}$。这里是 $C_{\pi}$。

**为什么这里必须是 $C_{\pi}$ 而不是 $C_{\pi}'$？** 记住这一点，等一下就明白。

要得到 $C_{\pi}$ 之后，我们才可以求 $C_{\pi}'$。$C_{\pi}'$ 是一个单向化的电容，把电容做单向化等效之后的这样一个电容。那么注意，$C_{\pi}'$ 在各个情况下是不一样的，因为它和什么相关？和 $K$。$K$ 是什么？$u_{ce}$ 比上 $u_{be}$。在不同的时候，$u_{ce}$ 比 $u_{be}$ 是不同的。

那这些参数实际上是从哪儿来的呢？是从**直流**。所以我要分析直流，一步一步反推。要分析直流，因为有了直流我才能求出谁来？求出 $r_{b'e}$ 和 $g_{\text{m}}$——$r_{b'e}$ 和 $g_{\text{m}}$ 是从直流来的。

所以反过来说，这道题整个的思路就是：先是一个直流。直流求出我们的 $I_{EQ}$，求出 $I_{EQ}$ 之后，$r_{b'e}$ 就知道了，$g_{\text{m}}$ 就知道了。这是第一步。接下来解决下一个参数，$C_{\pi}$，我们用 $f_T$ 来求。

整条路线就长这样：

```text
               目标：压放倍数 A_us + 相频特性
                              │
          │                   │                   │
          ▼                   ▼                   ▼
     中频 A_usm           下限 f_L            上限 f_H
    h 等效 → r_be      耦合电容 → 高通     高频电容 → 低通
                              │
                              ▼
               三者共用同一个全频域适用的基础
                              │
                              ▼
                     混合 π 参数等效电路
                              │
          │             │           │           │
          ▼             ▼           ▼           ▼
         g_m          r_b'e        C_π        C_μ'
          │             │           │           │
          └── ① 直流 I_EQ ─┘        │           │
                            ② 由 f_T 反推 C_π   │
                                    ▼           ▼
                       ③ 取中频 K = u_ce/u_b'e  │
                                    │           │
                                    └─────────────┘
                                             ▼
                    C_π' = C_π + C_μ'  →  放回高频段分析
```

读图：顶上三个是要求的东西，往下每一层都是"为了得到它，必须先得到什么"。注意三个参数的来源互不相同——$g_{\text{m}}$ 和 $r_{b'e}$ 来自直流工作点，$C_{\pi}$ 来自 $f_T$，$C_{\mu}'$ 来自 $K$。三者凑齐，才能拼出高频段真正要用的那个 $C_{\pi}'$。

### $C_{\pi}'$ 里的那个 $K$：最容易翻车的一环

#### 用 $f_T$ 反推 $C_{\pi}$ 时，$K$ 为什么等于 0

去死背书上的公式，真的是没有什么太大意义。$C_{\pi}'$ 大家都知道等于：

$$C_{\pi}' = C_{\pi} + C_{\mu}'$$

这个 $C_{\mu}'$ 是什么？它的含义是什么？含义就是把 $b$、$c$ 间的电容**单向化**，单向化到输入端那边去，于是就出现了 $C_{\mu}'$。刚才我所说的就是它和 $K$ 相关。

所以大家注意一点，这里有一个关键。我从 $f_T$ 推 $C_{\pi}$ 的时候，$f_T$ 直接和谁相关？直接和 $C_{\pi}'$ 相关。但是这个时候的 $C_{\pi}'$ 等于什么？等于 $C_{\pi}$ 加上 $C_{\mu}$。

**有没有疑问？为什么？为什么这时候 $C_{\mu}'$ 是等于 $C_{\mu}$ 的？**

这个时候你一定要知道：$f_{\beta}$ 是一个什么参数？$f_{\beta}$ 是一个什么参数？它是指向谁的？它表明谁和谁之间的关系？它表明谁和谁之间的关系？是什么？大点声。**$\beta$ 和频率的关系。**

那么 $\beta$ 的定义很清楚：$\beta$ 它等于 $I_c$ 比 $I_b$，对不对？$\Delta I_c$ 比 $\Delta I_b$。那么前提是什么呢？我保持 $U_{CE}$ 不变。也就是说，此时动态的 $u_{ce}$ 是 0。

**这就是 $K$ 为什么等于 0 的道理。** $K = 0$，所以 $C_{\mu}' = C_{\mu}$，所以 $C_{\pi}' = C_{\pi} + C_{\mu}$。

> **提示**：所以你在用 $f_T$ 去求 $C_{\pi}$ 的时候，是这样一个道理。上次课我们都讲了，这一次我认为这是一个很轻易混淆的问题，给你们再提出来。

#### 高频段真正要用的 $C_{\pi}'$，为什么只能近似

真正在算高频的时候，$C_{\pi}'$ 依然是等于 $C_{\pi} + C_{\mu}'$。我现在问你们一个问题。

$f_T$ 求这个 $C_{\pi}$ 的时候，这个 $C_{\mu}$，我问大家，是我们手册上查的哪一个参数？$C_{ob}$。

那么在高频段，我问大家一个问题：在高频段的时候，我通过 $f_T$ 是不是已经把 $C_{\pi}'$ 求出来了？没错吧？然后我通过 $C_{\pi}'$ 又求出 $C_{\pi}$。我费了这么大劲。我现在问大家一个问题：**我通过 $f_T$ 求出的这个 $C_{\pi}'$ 这个值，能不能直接用于高频段的分析当中？就是高频段的分析当中的这个 $C_{\pi}'$，是不是就是这个 $C_{\pi}'$？是不是？**

有没有同意是的？有没有同意不是的？

这是最难抉择的，没有人表态。刚才我看着有几位同学说不是的。

**的确不是。** 因为你们注意听，我前面都给你们打下伏笔了：$C_{\pi}'$ 和 $K$ 是相关的。

你用 $f_T$ 再求这个 $C_{\pi}'$ 的时候，我目标实际上就是为了求 $C_{\pi}$。$C_{\pi}$ 是个固定值，$C_{\mu}$ 是个固定值，但 $C_{\pi}'$ 不是固定值。$C_{\mu}$ 切实存在的，就是那个 $C_{ob}$；$C_{\pi}$ 也是存在的。但是 $C_{\pi}'$ 是等效出来的——**等效是跟环境相关的，跟条件相关的。**

所以这也是为什么我们一定要把 $C_{\pi}$ 求出来。整个这个过程求的是谁？求的是 $C_{\pi}$，不是求的这个 $C_{\pi}'$。$C_{\pi}'$ 是个中间的过程，是此时的 $C_{\pi}'$。求的是此时的 $C_{\pi}'$，然后从而推出了 $C_{\pi}$。

推出了这个 $C_{\pi}$ 之后，我才能推出在高频段的时候 $C_{\pi}'$ 到底等于多少。这时候我需要求什么？实际上要求高频段的时候：

$$K = \frac{u_{ce}}{u_{b'e}}$$

我需要知道它，这才能行。

但是你到真正工程当中在做的时候，你发现这个东西又矛盾了。什么呢？你如果真的要这样求，这样求这个 $K$，真的用高频段的 $K$ 去带这里的话，非常困难。所以我们就怎么办？我用中频段求出来的，虽然跟这个有误差，我用中频段求出来的这个值去带这个 $C_{\mu}'$。

所以我整个做的这个过程，最费劲的就是这儿：**高频段的 $C_{\pi}'$ 的求法。我觉得整个的难点就在这里，你要理解了的话就没有难点了。**

通过 $f_T$ 求出 $C_{\pi}$，中频段求出一个 $K$ 来，从而推出近似的高频段的 $C_{\pi}'$，然后把这个 $C_{\pi}'$ 放到高频去分析。到这儿，所有的参数就求解完毕。

> **结论**：所有参数的来路是一条清晰的链——先把直流算出来，再把 $f_T$ 用上，最后用中频段的 $K$ 折算。

| 参数 | 来源 | 关键说明 |
| --- | --- | --- |
| $I_{EQ}$ | 直流静态分析 | 一切动态参数的源头 |
| $r_{b'e}$、$g_{\text{m}}$ | 由 $I_{EQ}$ 得 | 两个都从直流来 |
| $C_{\pi}$ | 由 $f_T$ 反推 | 此步 $K = 0$，故 $C_{\mu}' = C_{\mu} = C_{ob}$ |
| $C_{\mu}'$、$C_{\pi}'$ | 由中频段的 $K$ 折算 | $K$ 取中频值，是近似而非精确 |

### 参数齐了，只剩 $A_{usm}$ 和两个频率

下面整个做的过程就没什么好算的了，$A_{us\text{m}}$，把中频段这个求出来。

然后再做哪两个事情呢？你不要再去求了，用不着再去求高频段的 $A_{us\text{h}}$ 和低频段的 $A_{us\text{l}}$ 了，你只要去求两个东西。

因为你看，像这种单管放大电路的这样一个东西，最后求出来是这个样子。没错吧？**这不就是它的波特图、幅频特性吗？** 刚才求的 $A_{us\text{m}}$ 是什么？是不是中间这根线？

你把整个这根线画出来，现在还需要知道两个事情就完事了。哪两个事情？还要再去求那整个的放大倍数吗？不用。一个叫 $f_H$，一个叫 $f_L$。

你脑子要清楚，这块就可以非常清晰了。一个是我要求它的上限截止频率，一个要求下限截止频率。我只要把这两个频率求出来就完事了。

```text
A/dB
     ↑
A_m   ┤───────────────────────╭─────────────────────────────╮
      │ +20 dB/dec         ╱                                   ╲ −20 dB/dec
      │                 ╱                                         ╲
      │              ╱                                               ╲
      └───────────────────────┬─────────────────────────────┬──────────→ lg f
                             f_L                           f_H
```

读图：中间那条水平线就是刚求出来的 $A_{us\text{m}}$；低频段以每十倍频 $+20$ dB 的斜率爬上来，交点就是 $f_L$；高频段以每十倍频 $-20$ dB 落下去，交点就是 $f_H$。整根线现在只缺这两个横坐标。

而这两个频率的求法非常简单，就是我们所谓的高通电路和低通电路的截止频率，都是 $\frac{1}{2\pi RC}$。**关键点在谁？在 $R$。**

你看把这个事情一点一点地剥开，到最后又变成求这个电容两端看进去等效的那个 $R$ 了——又要用我们的戴维南定理了。

多复杂的问题。但你会发现，它全是由我们这些最基本的概念构成的，还是由我们这些基本概念的理解构成的。

中频段不用说了：中频段的时候电容全去掉，$C_{b'e}$ 相当于断路，那个耦合电容相当于短路。中频段你们非常熟悉。

#### 求 $f_L$：把前端整个电路做戴维南等效

$f_L$ 实际上就是哪里？就是这个电容算出来的等效。把前端整个电路相当于做什么？把前端整个电路做戴维南等效。

其实你等效来等效去，你无外乎要求前端的输出电阻，对不对？这个 $R_C$ 是最关键的，剩下这我都不用看。**听明白这意思吧？这我都不用看，我其实不关心，我只要知道你截止频率就完事了。** 这是我的 $R_C$，这是我的 $R_L$。

因此截止频率是什么？$f_L$ 是什么？

$$f_L = \frac{1}{2\pi (R_L + R_C) C}$$

看到了吧？一个结束了。你波特图那块低频就可以画出来了。

#### 求 $f_H$：从 $C_{b'e}$ 两端看进去

$f_H$ 呢？我们来看高频段。高频段从这个电容 $C_{b'e}$ 两端看进去，前端应该是：

$$f_H = \frac{1}{2\pi \left[ r_{b'e} \parallel \left( r_{bb'} + R_S \parallel R_B \right) \right] C_{b'e}}$$

咱们先把 $C_{b'e}$ 写好吧。这个电阻告诉我，是多少？应该是谁？$r_{b'e}$。然后怎么样？$r_{b'e}$ 并上 $r_{bb'}$ 串上 $R_S$ 并 $R_B$。


读图：从 $b'$ 往发射极方向看，是 $r_{b'e}$ 这一条路；往基极方向绕出去，是 $r_{bb'}$ 串上信号源内阻与偏置电阻的并联 $R_S \parallel R_B$ 这一条路。两条路并联，并联结果就是电容 $C_{b'e}$ 所看到的负载。

### 本讲提到的题目

**题目**：给定一个单管共射放大电路的全部参数——$\beta_0$、电路中各电阻值、各电容值、电源 $V_{CC}$——求它的幅频特性和相频特性。

**解析**：不要顺着推，要倒着推。整条路线就是开头那张图。

第一步，解直流工作点得 $I_{EQ}$，据此得 $r_{b'e}$ 和 $g_{\text{m}}$。

第二步，用 $f_T$ 反推 $C_{\pi}$。这一步里 $C_{\pi}' = C_{\pi} + C_{\mu}$，因为 $f_{\beta}$ 的定义前提是保持 $U_{CE}$ 不变，即动态 $u_{ce} = 0$，故 $K = 0$，$C_{\mu}' = C_{\mu}$。

第三步，取中频段的 $K = u_{ce}/u_{b'e}$，折算出高频段的 $C_{\pi}' = C_{\pi} + C_{\mu}'$（近似）。

第四步，算中频增益 $A_{us\text{m}}$，用 h 参数等效求 $r_{be}$。

第五步，求 $f_L$：把前端整个电路作戴维南等效，$f_L = \frac{1}{2\pi (R_L + R_C) C}$。

第六步，求 $f_H$：从 $C_{b'e}$ 两端看进去，$f_H = \frac{1}{2\pi \left[ r_{b'e} \parallel \left( r_{bb'} + R_S \parallel R_B \right) \right] C_{b'e}}$。

第七步，画波特图：中频平台取 $A_{us\text{m}}$，两侧以每十倍频 $\mp 20$ dB 下降，交点即 $f_L$、$f_H$；通频带 $f_{BW} = f_H - f_L$。相频特性以 $180^\circ$ 为基准，高频最终落在 $90^\circ$。

最后可以用增益带宽积做个自检：$A_{us\text{m}} \times f_{BW} \approx \frac{1}{2\pi (r_{bb'} + R_S) C_{\mu}}$，其中 $C_{\mu}$ 就是手册上的 $C_{ob}$。如果算出来的乘积跟这个对不上，说明中间某一步的等效电阻取错了。

> **注意**：这题真正容易翻车的地方不在计算，在于你用 $f_T$ 反推出的那个 $C_{\pi}'$，是**中间过程**，不是高频段分析要用的那个 $C_{\pi}'$。两个数不相等，因为 $C_{\mu}'$ 依赖 $K$，而 $K$ 依赖工作点。

## 多级放大电路的截止频率，与集成运放的起点
> 对应块：BLK27 | 覆盖分集：P27 | 块标题（分集名）：《27-多级放大电路的频率响应（2）与集成运放的电》

### 截止频率不是各级简单叠加

先问一个老问题：**截止频率的含义到底是什么？**

单级放大电路的时候这件事很清楚——放大倍数降为原来的 $0.707$，也就是 $\frac{1}{\sqrt{2}}$ 的那一会儿，对应的频率就叫截止频率。多级放大电路也是这同一个定义，**没有任何特殊之处**。

> **定义**：截止频率是放大倍数降为原来的 $\frac{1}{\sqrt{2}}$ 时所对应的频率。无论单级还是多级，都以这一句话为准。

可一到多级，就有人习惯性地想把各级的数据往上凑：两级就是两个 $f_{L1}$、$f_{H1}$ 凑一凑，串起来就完事。我先把这个想法否掉。

我们把多级放大电路看成一个整体。它作为一个整体，放大倍数降为原来的 $\frac{1}{\sqrt{2}}$ 时对应的那个频率，才是这个多级放大电路的截止频率。就这一句。我一直强调，基本概念清楚，后面就不会有误差。

看看硬凑会出什么问题。两个单级，截止频率分别是 $f_{L1}$ 和 $f_{H1}$（每一级还有一个自己的 $f_{L2}$、$f_{H2}$），波特图一乘，两级连乘的波特图就是这样的：

```text
  单级1 的通频带：  [---------f_L1------------f_H1---------]
  单级2 的通频带：  [---------f_L2------------f_H2---------]
  两级总的通频带：  [-----------f_L----------f_H-----------]

  频率由低到高：   f_L1 < f_L < f_H < f_H1
                   （f_L 比任一单级的下限都高，f_H 比任一单级的上限都低）
```

现在注意一个致命细节：如果硬把 $f_{L1}$ 和 $f_{H1}$ 当成两级放大电路的截止频率，那一点对应的是**下降 6 dB**，而正常一个截止频率只该对应 3 dB。两级一叠加，幅值下降翻倍，6 dB 就出来了。

而且不只是 6 dB。相移也翻倍：单级在截止频率上是 $45^\circ$ 相移，两级叠上去就是 $90^\circ$。

> **结论**：真正的截止频率，是两级总波特图上 3 dB 线所对应的那个频率。

所以你们发现了一件事没？**两级串起来的通频带，比任何单一级都窄**，下限往上抬、上限往下压，两边往中间缩。

### 从定义把 $f_L$ 和 $f_H$ 推出来

既然如此，严格按定义推。多级放大电路的低频段表达式就是把每一级连乘：

$$A_u = \prod_{i=1}^{k} \frac{A_{umi}}{\sqrt{1 + \left(\dfrac{f_{Li}}{f}\right)^2}}$$

这里 $A_{umi}$ 是第 $i$ 级的中频电压放大倍数，整个 $A_u$ 就是这些模的连乘。

现在让它降为中频值的 $\frac{1}{\sqrt{2}}$，也就是连乘的那一堆根号整体等于 $\sqrt{2}$：

$$\prod_{i=1}^{k} \sqrt{1 + \left(\frac{f_{Li}}{f}\right)^2} = \sqrt{2}$$

两边平方，把这个连乘打开：

$$\prod_{i=1}^{k}\left(1 + \left(\frac{f_{Li}}{f}\right)^2\right) = 2$$

打开之后是 $1 + \sum\left(\frac{f_{Li}}{f}\right)^2$ 加上一些高次交叉项——比如 $\frac{f_{L1}}{f}\cdot\frac{f_{L2}}{f}$ 这种两两相乘的项。两级的时候每一项都带 $\frac{1}{f^2}$，$f$ 又是下限截止频率那一带的频率，所以这些交叉项量级很小，直接略掉：

$$1 + \sum_{i=1}^{k} \left(\frac{f_{Li}}{f}\right)^2 \approx 2$$

于是 $\sum f_{Li}^2 / f^2 \approx 1$，把 $f$ 倒回去，这个 $f$ 就是总的下限截止频率：

$$f_L \approx \sqrt{\sum_{i=1}^{k} f_{Li}^2}$$

就是**方均根**——平方和再开根号。

高频段完全一个套路，方向反过来：

$$\frac{1}{f_H^2} \approx \sum_{i=1}^{k} \frac{1}{f_{Hi}^2}$$

> **提示**：刚才那个“略去高次项”当然会带来偏差，所以我们给它加一个修正系数。$f_L$ 这一侧的修正是

$$f_L = 1.1 \sqrt{\sum_{i=1}^{k} f_{Li}^2}$$

$f_H$ 那一侧同样带一个修正系数，这里先只给概念，数值关系记着就行。

这条推导要两头都要：既要有概念上的理解，也要有自己动手推的过程。我给了你起点和终点，中间那步展开，是留给你们的。

### 平方和告诉你：谁是关键

公式一摆出来，能读出好几层东西。

**第一层，定性的。** 级数越多，$f_L$ 越大，往右移；$f_H$ 越小，往左移。也就是说，**级数越多，通频带越窄**。这个结论很好记，但别只记结论，要能从公式里一眼看出来。

**第二层，权重。** 注意这是个**平方和**。我打个比方：两级，一个 $f_{L1}$ 是 100，另一个 $f_{L2}$ 是 5——当然实际不会差这么离谱，但意思你们听着。最后算出来是多少？$\sqrt{100^2 + 5^2} = \sqrt{10025} \approx 100$。**还是 100**，5 那一个几乎没进账。

> **结论**：多级耦合电路里，只要有某一个 $f_{Li}$ 遥遥领先于其他所有级，它就是权重最大的那一个，几乎决定一切。

这就是工程估算里最值钱的一条：**千万别傻乎乎一档一档去调**。有经验的，一眼扫过去就知道哪个是“干坏事干最大的”——先消灭它、先调整它，整个电路的面貌就改了。每一级都去拧一遍，那多麻烦。$f_H$ 是完全一样的道理，哪个 $f_{Hi}$ 决定性最大，心里要随时有数。

**第三层，回到电路。** 把上一节讲的那套“$f_L$ 怎么更大更小、$f_H$ 怎么更大更小”对上号，你就对整个多级放大电路有感觉了。一眼看过去就该知道：哪个耦合电容对下限截止频率影响最大？必然是那个时间常数 $RC$ **乘起来最小**的那个——它最先滚下坡，把下限拖上来。哪个对上限截止频率影响最大？必然是 $RC$ **乘起来最大**的那个。

这一层最要紧。**我需要的是整体的感觉。** 有了感觉，细节问题你很快就能想明白。反过来，从一堆细节里去找整体的感觉，那可太麻烦了。所谓感觉，就是大概念；大概念清晰了，剩下的都在它的指导下完成。

### 分立元件这一段，到此为止

到这里，分立元件放大电路就全部交代完毕了。

我们回头看一眼这条线：从**中频段的单级放大电路**出发，到**多级放大电路**，再把频段从中间扩展到**所有频段**——低频、高频全走了一遍。这会给你们以后做任何方向打下一个概貌性的底子：做高频的、做电力电子强电的、做集成电路的，都用得上。

### 从电子管到集成电路

好，重头戏来了。

半导体材料发展到今天，取代了电子管。但真正带来革命性进步的，不是“它导通了”，而是**它可以集成**。电子管没法集成——你把一个电子管封装起来就这么大，封装是什么概念？要把它弄结实，再把引线引出去，里面真正的电子管占的体积其实很小，可是外壳就那么大。十个电子管封装起来还是那么大。

而一旦能集成，**上亿个元器件可以集成在一块芯片上**，上亿个三极管、场效应管堆在一块片子上，片子也不过那么大点。换句话说——我本来造了一个体育场那么大的房子，你一个人住进去；现在这房子里可以装成千上万的人。

模拟电子技术里对集成电路的讨论，重点就落在一个元器件上：**集成运算放大器**。

> **注意**：这一章的重点**不是**运放怎么用，而是**它的电路是什么**。它是介于集成器件和分立器件之间的东西——我们用分立器件的原理，去构造集成器件。

### 集成运放到底能干什么

先说它的本事，你们看看厉不厉害。

它可以实现模拟信号的**比例运算、加法、减法、乘法、除法、积分、微分、指数、对数**。这一堆运算，一个器件全包。

而且注意，它**是直接模拟对模拟的**。它没有把模拟信号先变成 AD，丢给 DSP 或单片机处理一下，再 DA 出来。现在很多架构确实是基于嵌入式的——确实方便，编译简单，抗干扰也强，AD 接口和 DA 接口做好了，剩下全交给程序。但它有它的问题：**速度没那么快**。纯模拟电路、硬件电路的好处就是快。

它还能**产生波形**：正弦波、三角波、方波都可以。

还能做**波形的整形**，这件事很重要。数字信号传输可靠性高，是因为用方波代表 1 和 0；但实际长距离传输中还是会出现一部分失真，这时候就需要整形，集成运放能把波形整得很好。

> **提示**：整形能做到什么程度？跟上升时延和下降时延有关——波形的上升沿、下降沿那个斜度，越陡越好。运放不光能给你整形，还能把边沿变得更陡。这就是提高速度。

还能做**有源滤波**，有源滤波的损失很小。还能做**有源的整流**，其中**小信号整流极其重要**。

为什么小信号整流要单拎出来说？我们平常用二极管整流，靠的是二极管的单向导电性，把交流“咔嚓咔嚓”先把下面腰斩，这是半波；再把下面那半翻上去，这是全波。但前提是什么？**输入信号幅值必须大到能把那个 0.7 V 的门槛干掉**，否则你还整什么流？交流幅值要是直接小于 0.7 V，整出来全是 0，只剩直流。

那如果我给你 20 mV 这样的信号，要求你整成直流，怎么办？用二极管是过不去的。**集成运放给了你一条技术路线——有源整流。**

还有什么？555。你们学数电的时候 555 总归学了吧？555 电路里最主要的结构，就是**用运放构成的比较器**；那 $\frac{1}{3}$、$\frac{2}{3}$ 的分压一摆，就可以构成施密特触发器——那是个非常好的东西，用起来很顺手。

又能算——你看比例、加法、减法这些。我当时觉得这玩意儿真挺神奇，学的时候还觉得它没那么神奇，后来越想越觉得这东西不错。

### 它本质上，只是一个高增益放大器

说了这么一大堆，本质上它是什么？**本质上就是一个放大器。** 什么定语？**集成的、高增益的**——一定是高增益的放大器。

所以这一章要解决的问题就两条：怎么把它做成集成的，怎么在它的放大电路里实现高增益。

先看它的符号：

```text
                   u_O
                    ▲
               ┌────┴─────┐
               │   ╱      │
  u_P ────────►│P(+)      │
  u_N ────────►│N(−)   A  │
               └──────────┘
```

**输入信号是什么？是 $u_P - u_N$，差模信号。** 这一点一看就知道：集成运放的输入端肯定是一个差分放大电路。

再看它的电压传输特性：

```text
   u_O
    ↑
+14V├─────────╮       ╭─────────  饱和
    │          ╲     ╱
    │           ╲   ╱
    │            ╲ ╱
  0 ├─────────────╳──────────────────────►  u_P − u_N
    │            ╱ ╲
    │           ╱   ╲
    │          ╱     ╲
−14V├─────────╯       ╰─────────  饱和
                  ↑
        中间这条缝就是线性区，只有十几微伏宽
```

现在讲重点。这条曲线中间那个线性区，**非常窄**，窄到很多人看一眼就忘了。两侧是什么？**饱和了。** 要不饱和那不就坏了。

有人高兴了：“一百万倍！拿来，这边加 1 V，那边不就是一百万 V？瞧我的，我要去电人了。” 可能吗？**可能吗？** 你看它的电源，正负 15 V。它里面是晶体管或者场效应管做的，输出电压能高过 $V_{CC}$、$V_{DD}$ 吗？高不过去。你给它捅个 1 V 进去，人家说：“咔，我到顶了，14 点几伏。”这已经很给你面子了，它自己还得损耗一点呢。这就叫饱和。

所以这个加号的一百万倍——$A_{od} = 10^6$ ——只能在**线性区**里起作用：

$$u_O = A_{od}\,(u_P - u_N) \qquad (\text{线性区内})$$

你加 2 μV 进去，它给你输出 2 V，这时 $A_{od}$ 才真的算数。但你不能指望着加 1 V 进去它出 100 万 V。

那线性区到底有多宽？电源正负 15 V，输出到 14 点几伏，$10^6$ 的增益一除——**你的 $u_P - u_N$ 只能在正负十几微伏之间游走。** 十几微伏什么概念？你把一个电路往那儿一摆，什么都不放、什么都不动，它的两个输入端就会感应出十几微伏的差。**想把两个电压做得只差十几微伏，在我们看来就可以认为它们相等了。**

> **易错点**：所以一个高增益运放，拿过来通上电就是饱和的，**除非你把它做成闭环**。神奇的功能全都是闭环挣来的——这就是我们下一章（第六章）负反馈要解决的问题；等到第七、第八章，才正式开始使用它。第六章不是白放在那儿的。

顺带把命名说清楚：为什么一个叫同相端、一个叫反相端？$u_N = 0$ 时，$u_O$ 与 $u_P$ 同相；$u_P = 0$ 时，$u_O$ 与 $u_N$ 反相。一个起正的作用，一个起负的作用，名字就是这么来的。

### 运放电路的骨架

整体概念已经有了，它得有这么几级：

```text
        +---------+     +---------+     +---------+
   u_P -|         |     |         |     |         |----> u_O
        |  输入级 |---->| 中间级  |---->|  输出级 |
   u_N -| (差放)  |     | (共射)  |     | (互补)  |
        +---------+     +---------+     +---------+
              |                              |
              +---------- 偏置电路 ----------+
                         （提供静态电流）
```

输入级是差放，中间级是主要实现电压放大的，输出级就是互补对称那一套——这些你们都学过。中间再配一个偏置电路，提供各级的静态电流。

但**一旦涉及集成电路，就有它自己的硬约束**。

第一条：**能不能用阻容耦合？不能。** 阻容耦合的电容没法集成，做不了那么大的电容。所以只能直接耦合。

第二条：中间级要拿到比较大的电压放大倍数，用共射。**我希望 $R_C$ 尽可能大**——只给 1 kΩ 的 $R_C$，你死定了，$I_C R_C$ 那么小，上哪搞那么大的放大倍数。可你说“我来个大的，十兆”——你的 $I_C$ 是毫安级的，毫安级配十兆欧？算算要多少电压？你整个芯片组跑高压，然后机箱上贴一张“内有高压，勿触”。

> **结论**：电阻要大，电压还不能高。有解决方案吗？**电流源。** 电流源既能提供 $I_C$，它本身在动态的时候内阻又非常大——既不对直流电源提出过分的要求，又满足了“我要大电阻”的需求。

### 这一章唯一没学过的东西：电流源

这么一看，集成运放里其他的东西你们都学过。**唯一一个没学过的，就是怎么造这个集成电路里的电流源。**

它在集成运放里有两大作用：

| 作用 | 说明 |
| --- | :--- |
| 当电源用 | 提供电路所需要的静态电流 |
| 当负载用 | 取代 $R_C$，甚至取代 $R_E$——长尾式差分放大电路尾巴上挂的就是一个恒流源 |

长尾式差放里那个恒流源，其实我们已经见过一次了，但那个电流源比较难控制。我们现在要的是：**电流源的电流必须可控、必须可调**，这样才能真正用好它。

### 镜像电流源：最简单的那一个

先看基本电流源里的镜像。它的设计思路非常巧妙，最后我要你们做到**所有这些电路都会画**。

注意底下这块——**这是个对管，两个管子特性一模一样**。既然特性一模一样，我问你们：$I_{B1}$ 和 $I_{B0}$ 什么关系？相等。

为什么相等？给一个充足的理由：**$U_{BE1}$ 和 $U_{BE0}$ 绝对相等**。既然结压相等，两只管的 $I_B$ 就相等；$\beta$ 一样，$I_{C}$ 也就相等。$I_{B0} = I_{B1}$，$I_{C0} = I_{C1}$。**这就是“镜像”这个名字的来由。**

连接关系是这样的：

```text
  V_CC ──[R]──●──┬──(T0 的 C 与 B 短接，E 接地)
                 │
                 └──(T1 的 B)
                      T1 的 E 接地
                      T1 的 C ──► I_C1（电流源输出端）
```

注意 $I_{C1}$ 这一支我只画了输出端，上面那半张电路我没画——**这就是电流源和别处的接入点**。哪块电路需要这个电流源，把这个端接上去就行，那边会自己给它提供直流电压。**如果是用长尾式的差分放大电路，这个 $I_{C1}$ 就接在 $R_E$ 那一块**，因为上级会有电源给它供电。

那么问题来了：**谁是调节 $I_{C1}$ 的基准？** 很清楚了，是参考电流 $I_R$。

对参考支路用基尔霍夫电流定律：

$$I_R = I_{C1} + 2I_B = \frac{\beta + 2}{\beta} \times I_{C1}$$

$\beta \gg 2$ 的时候，$\frac{\beta+2}{\beta}$ 几乎就是 1，所以 $I_R \approx I_{C1}$。而 $I_R$ 又由电阻决定：

$$I_R = \frac{V_{CC} - U_{BE0}}{R}$$

所以我只要**调 $R$ 的大小，就能控制 $I_{C1}$**。跟我们最早那个别扭的电流源比，这已经是巨大的进步了——**我可以任意地控制 $I_{C1}$。**

在镜像的基础上，还能派生出**比例电流源**和**微电流源**。怎么派生的、这些电流源在后面怎么用，下节课讲。
