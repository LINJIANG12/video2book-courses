### 放大到底是什么

在说放大电路怎么构成之前，我们首先得知道"放大"是什么。不知道放大电路是干什么的，那怎么可能构成一个放大电路呢？

#### 放大的是功率

最简单的放大电路，大家现在正在用：扩音机。我这块麦克风到那个扬声器。

我们的声音给了话筒，话筒实际上就是一个**传感器**，它的功能是把声波信号变成电信号。这个电信号非常非常微弱。如果说把这根线直接接在那个扬声器上，什么都听不到。你使劲喊，那边最多是"嘶嘶嘶"，你能喊出那么点震动来都不错了。

那我们为什么能听到大的声音？因为放大电路在起作用。我们这里进来的是一个毫伏级的很小功率的信号，经过放大电路，放大成一个功率比较大的信号，这个大功率信号去推动扬声器——电流推动线圈，线圈让喇叭的振子震动，震动再重新发出声音。

所以它的真实目标是什么？

> **定义**：放大，是把一个很小功率的电信号，变成一个大功率的电信号。

这里我要专门强调一下，放大，你们脑子里千万别把"放大"就想成一个东西——我放大电压，那叫放大。不是。**我放大的是功率。**

功率包含两部分内容：一部分是电压，一部分是我们讲电流。我这里进来的是小电压、小电流的非常小的信号，从这出去是大电压、大电流的大功率信号。这个过程才叫做放大。

#### 能量从哪来：核心元件在干什么

那么第二个问题：这个功率的放大是凭空长出来的吗？

不是。它实际上是一种**能量在控制之下的一种转换**。它把电能转换成我们放大的这种声波震动的能量。放大电路一定是外接有供电电源的，这个供电电源提供了输出信号的功率、提供了输出信号的能量，一定是这样的。

所以从本质上来说，它是一种**能量的控制**，同时还伴随着**能量的转换**。

那么，构成一个放大电路，放大必须有一个核心元件，这个核心元件起控制作用。**没有它，这个放大电路就组成不了**——这是必要条件。

这个核心元件就是我们的三极管、场效应管这类**有源元件**。它的功能是什么？用一个小信号的输入，控制一个输出的大信号。但这种信号的能量是谁给的呢？是外界的电源给它的。它自己能起到这个作用。

最形象的体现在哪里？在晶体三极管里面，是 $I_B$ 对 $I_C$ 的控制——电流放大。$I_C$ 是 $I_B$ 的几十倍到几百倍，让它工作在放大状态下，它就可以干这样一件事。在场效应晶体管里面呢？是 $u_{GS}$ 对 $i_D$ 的控制。

你看，我说得再远一点，它都是输出那部分和输入这部分成比例，它可控。

```text
      输入侧（很小的信号）              输出侧（很大的信号，能量来自电源）
   ┌──────────────────────┐       ┌──────────────────────────┐
   │   u_i  →  u_BE       │       │          E_C             │
   │           │          │       │          │               │
   │           ▼          │       │          ▼               │
   │          i_B         │──────▶│         i_C              │
   └──────────────────────┘  控制 └────────────┬─────────────┘
                                                  │ 流过 R_C 产生压降
                                                  ▼
                                                 u_o
```

图上就是那条控制链：小信号进去，经过有源元件，出来的是大信号，而大信号的能量全部是电源给的。

#### 前提是不失真，测试靠正弦波

那么对于一个放大电路，我放大的前提是什么？前提条件就三个字：**不失真**。换成两个字就是：保真。

这个我们前面已经讨论过了。如果失真了，这就没有意义了——一定得我这块声音大体什么样，你从那儿还能听出这是我的声音，扬声器出来还是我的声音，没有发生大的畸变。

那我怎么知道它保不保真、特性怎么样？要测试。测试信号用什么？**正弦波**。

为什么用正弦波？你们这学期开始学信号系统了吗？没开始学吧？应该开始学了吧——不要骗我，大家都能见得到，你们现在并行上什么课我还是知道的。（笑）

你们要是学了信号系统就知道为什么可以：用正弦波做测试信号，是因为我们这种声波、以及我有待放大的这种交流波形，我总归可以把它分解为多个频率的正弦波的叠加。当我用正弦波来扫频、来测试的时候，在多大的频率范围内我能扫过去，就说明多大的频率的信号可以通过这个放大电路。

所以简单地总结一下放大的概念，你要形成这样一串东西：

```text
   小功率信号  ──放大──▶  大功率信号          ← 目标
        │                      ▲
        │                      └── 能量来自外部直流电源
        ▼
   必须有一个"能量控制元件"（有源元件）      ← 必要条件
        │
   全过程必须保真、不失真                ← 前提条件
        │
   用一系列不同频率的正弦信号扫频测试        ← 测量手段
```

### 目标、现有条件与技术路线

现在我们就可以正式讨论：放大电路的组成，怎样来构建。

#### 第一步：把管子摆进放大区

构建放大电路的**目标**刚才已经清晰了：把小功率信号——小到小电压、小电流，可能就几个毫伏、几十个毫伏，电平其实很小——变成大功率信号。

有了目标，我手里能有的条件、或者说必须有的条件，我觉得两点必须有。注意，小信号是你已经有的，它就放在那儿等着你去把它弄大；现在你要想弄大它，首先手里得有两样东西：

1. **元件**，也就是刚才说的有源元件——你的三极管；
2. **能量**，也就是电源。

其他的东西就视需要往里拉，是需要往里拉的。

这跟我们写很多申请书、proposal 是一个套路：你的工作目标是什么、指导思想是什么，然后你手里已有的现有条件是什么，然后在现有条件下面你需要的技术路线是什么。

那技术路线是什么？我现在已经把实验室整个扔给你了，你已经知道晶体三极管和场效应管的工作特点。我们不同时讲两个东西，先说晶体三极管，学会举一反三，场效应管以此类推。

从这个技术路线上说，第一点：这个晶体管不是要放大吗？我一定要把它弄在放大状态下——这是我必须做的第一件事情。拿过一个三极管，所谓放大，我就让它工作在放大状态下。

一旦工作在放大状态下，我们就可以得到一点：$i_b$ 可以去控制 $i_c$。

#### 第二步：让小信号推动 $i_B$

那我接着问你们一点：**谁控制 $i_b$？**

你们如果学得很清楚的话，是谁？你们跳得很快——小信号。实际上我们有个输入特性曲线吧？输入特性曲线是谁和谁的关系？是 $i_b$ 和 $u_{BE}$ 的关系。它这里定义得非常清楚：$u_{BE}$ 变化引起 $i_b$ 变化。你当然反过来说是一回事，但实际上真的从源泉上来讲，还是 $u_{BE}$——$u_{BE}$ 变化了，发射结才变化。

好，小信号要去控制 $i_b$。但在电路构成上，我要让这个 $i_b$ 跟着我的小信号变，那实际上是怎么让 $i_b$ 跟这个小信号变呢？这里还有一个东西：你要控制这个 $u_{BE}$。**这个构成非常关键。**

那么现在我们来实际搭一搭。我们把三极管放上去了，三极管在这儿。目标之一就是让我的小信号能够控制 $i_b$。这样控制行不行？$u_i$ 进来了，它能不能控制这个 $i_b$？

看得很清楚，$u_i$ 的变化就是我 $u_{BE}$ 的变化。这能达到我的诉求吗？

**不能。**很多同学都说不能。

为什么？**要加直流电源。不加直流电源，这个 $u_i$ 根本产生不了 $i_b$。**

刚才我说了，这个 $u_i$ 都是很小的，有可能几毫伏到几十毫伏。这里的开启电压是多少？600 到 700 毫伏。我们拿毫伏比毫伏——你根本就开启不了这里。你如果直接这么放，你这块摆动，这里是什么？$i_b$ 还是零，$i_b$ 还是零。

> **易错点**：把交流信号"骑"在直流偏置上，靠的是直流偏置先把二极管正偏打开。如果只有交流本身，发射结在正半周导通、在负半周截止，电路根本没法对称工作。

这个问题我们前面讨论过吧？我刚刚上课还说什么呢——我怎么把一个交流的小电压信号让它在二极管上产生交流电流？是不是同样的问题？**那个发射结本身就是一个二极管**，同样的问题移植过来。

那我的做法是什么？你们很清楚这个做法。我在这里要加一个直流源 $E_B$，我先把它"打通"。我这么打通行不行？我现在这么放行不行？缺什么？缺电阻——非常棒。为什么？因为你如果直接放，这就烧了，一定得有**限流的电阻**。

这个时候我再把 $u_i$ 放上去，我们就知道了：我一定会得到一个变化的 $i_b$。这个变化**来源于骑在什么上？骑在直流上**——直流给抬高了，然后它在高的上面这样变化。

#### 第三步：把放大的 $I_C$ 取出来

下一个目标是什么呢？我们要把这块能输出大的交流 $i_c$。那我就要把它弄在什么状态下？放大。

我问同学们，放大状态下好不好把它弄出来？我现在这个发射结已经正偏了，我所需要的就是**集电结反偏**。集电结反偏。

那这个事情简单了吧？我只要在这边保证我的集电结在反偏，然后这里就会出现一个 $i_c$ 电流，这个 $i_c$ 就是对 $i_b$ 的一个放大。

但这 $i_c$ 的功率，大家看看是谁提供的？是不是都从这儿出来的？它发出的功率，量级上就是电源电压乘以 $i_c$——它的能量全部来自电源。所以你看得很清楚：现在这 $i_b$ 去控制 $i_c$，实际上在控制谁？**在控制 $E_C$ 输出多大的电流。**

到这里我前面两个条件都具备了：第一，让三极管工作在放大状态——用一个 $E_B$ 和 $R_B$ 把发射结正向导通，再加一个 $E_C$ 让集电结反偏；第二，让我的 $u_i$ 从这儿加进去，骑在这个直流上加进去，它的变化就能引起 $i_b$ 的变化。为什么呢？因为 $i_b$ 已经被提高了，一定有个静态工作点，那它的变化就能引起 $i_b$ 的变化；而 $i_b$ 的变化在放大条件下会原样放大成 $i_c$——大的 $i_c$ 有了。

**但还有一个问题：我怎么把它输出出来？**

你现在如果想输出一个电压，我从这儿输出给一个负载 $R_L$，假设这有个 $R_L$，我输出出来。同学们看，我得到了这个交流 $i_c$ 了吗？我得到这个交流了吗？

这里的电压是什么？我问大家，这两端电压是多少？$E_C$。换句话说，你有一个大的交流 $i_c$，但是你死活没辙，你拿不到。你如果这么输出，你得到的还是一个直流。

怎么办？有两个办法：

- 一种是让这个电流直接流进我的负载——换句话说，你可以把 $R_L$ 放在 $i_c$ 的通路里；
- 另一种是把这种交流电流**变成电压信号**输出出来：让这个电流流经一个电阻，这个信号就取出来了。

所以我的解决方案是：我这里加一个 $R_C$。现在同学们知道这个 $R_C$ 的作用了吗？当 $i_c$ 流过 $R_C$ 的时候，$R_C$ 上的压降就是什么？跟 $i_c$ 长得是一样的。这个时候再从它两端把电压取出来，这个电压就是个交流的，就是 $u_i$ 的一个放大。

这样原理简单吗？你们现在能不能画出这个图形来？

```text
                    +E_C
                      │
                     R_C
                      │
        ┌─────────────┼────────┬── u_o
        │             │        │
       R_B            C        │
        │             │        │
       +E_B           │        │
        │             │        │
        ├──────┬──────┤        │
        │      │      │        │
        │     ─┤├─    │        │   ← 耦合电容：把 u_i 骑到直流上
        │      │      │        │
        │    (∽) u_i  │        │
        │      │      │        │
        ├──────┴──────┤        │
        │   ┌───────┐ │        │
        └───┤   T   ├─┤        │
            └────┬──┘
                 │
                 └── 地
```

图上就是这个基本共射放大电路：一个三极管为核心，发射结正偏、集电结反偏让它工作在放大区；$E_B$ 经 $R_B$ 提供直流偏置并限流，$u_i$ 耦合进来骑在直流上；$R_C$ 把放大的交流电流变成交流电压输出。

现在不用我再解释这里面每一个元件都在干什么了吧？跟前面那个图是不是一样？看看，是不是一样。

#### 换个角度看这张图：设计的眼光

所以你们如果直接看这张图，得一个个想这个东西干什么、那个东西干什么。但是当你去构建这么一个东西的时候，你就知道每个东西应该是干什么。

我希望你们在学习整本书的时候用这样一种思路：这个电路如果换作你去设计，我就给你需求——因为你前面的知识都知道——给你这个需求，你怎么去设计这个电路？如果你按这种思想去学这本书、去学模拟电子技术的话，你肯定跟别人不是一个层次的。所以这些图我也希望你们都能**信手拈来就可以画出来**。

#### 交流是骑在直流上的

再来看这个电路工作的时候是什么样子。我的 $u_i$ 就是一个小交流，这没问题。

大家可以看到：当我直流 $V_{BB}$ 加上去之后，这块就会有直流的 $I_B$，对不对？直流的 $I_B$ 就起来了。当我把 $u_i$ 往上一加，这个 $u_i$ 的变动就引起了 $u_{BE}$ 的变动，然后就引起了一个交流 $i_b$ 的变动。

为什么你的 $u_i$ 不能直接产生 $i_b$ 呢？因为 $u_i$ 如果直接产生，$i_b$ 就会变成有负的。$i_b$ 是没有负的，因为二极管是什么？单向导电的。

所以我们把 $i_b$ 拆开看，逻辑是这样的：

```text
   i_B = 直流分量 I_BQ  +  交流分量 i_b

   i_B
    ▲
    │       ╭──╮        ╭──╮
    │      ╱    ╲      ╱    ╲
I_BQ├─────╱──────╲────╱──────╲──────  ← 直流分量（静态工作点）
    │    ╱                ╲
    │   ╱                  ╲
    └───────────────────────────────▶ t

   单独把交流分量 i_b 拿出来看：

    ▲         ╭─╮      ╭─╮
    │        ╱   ╲    ╱   ╲
    │       ╱     ╲  ╱     ╲
    │      ╱       ╲╱       ╲
    └──────────────────────────▶ t     ← 这才是"有正有负"的交流
```

所谓交流，它的正半周只不过是我正向流动的 $i_b$ 电流在**增大**；它的负半周是我正向流动的 $i_b$ 电流在**减小**。但是它一直都是朝一个方向流动的。所以它的交流概念是这样的：**它架在一个直流上面，它都是往一个方向流的**。只不过在交流的正半周它流动的值更大，在负半周我流动的值变小。把那个直流一抽掉，它就变成中间是一个纯交流。

就这样一个很简单的道理。

所以当这边流过来的时候，$i_c$ 就会出现一个交流；$i_c$ 出现一个交流，这个 $u_{CE}$ 就变成这样一个波形——等一下我们会看到。然后把这个直流一拿掉，$u_o$ 实际上就变成了一个纯的交流波形。

### 一套电源就够了吗

现在我先跟大家约定一个记号，你们以后要适应这一点。你们基电都学完了，你们来看这个符号代表什么含义：这个节点上的电位是正的 $V_{CC}$。它相当于这个点和地之间有一个 $V_{CC}$ 的电源，所以以后电路就简化成这样。

那现在我问同学们：这个电路能不能工作？非常清楚，**不能工作**。

为什么不能？因为这里没有一个合理的静态工作点。你的 $u_i$ 加上去，在输入回路上没有提供任何一个直流，你 $u_i$ 加上去根本不可能让我的 $I_B$ 产生变化，也不可能产生 $I_B$ 这个电流——尤其当你 $u_i$ 很小的时候。

那我们接下来分析一点什么呢？实际上，我们这种电路在真正用的时候不会这样用。你想，这一个电源、这一个电源，这俩电源还不一样——我一个放大电路里面要提供两套电源系统，这我很累。

**我能不能用一套电源系统去解决这个问题？能不能？**

我无外乎要求的就是能达到一个发射结正偏、集电结反偏。用一套电源系统，你来看。

我这里画是这样画的：这个 $E_B$ 我也让它等于 $E_C$ 这么大的电源，看清楚啊，也是 $E_C$ 这么大的电源。我能不能让这里的电位比这里的电位低？我现在不考虑外面的输出，先不管外面的输出。我能不能让这里的电位比这里的电位低？我怎么调节？可以——我调节 $R_C$ 和 $R_B$ 这两个电阻的阻值。我让基极这一路的压降大于集电极那一路的压降，那我这里的电位就比这里的电位要低。技术上可以实现吗？可以。

因此这个电路我马上就可以变成这样：$V_{CC}$ 一路下来，跟刚才一样，只不过把它掰上去了。可以看到实际上还是两套电源，这边一套、那边一套，一个意思。

但这样的话有一个问题是什么呢？这个交流信号它是**浮地的**，它没接地，任何一边都没有接地。这对它的传输、对干扰都不好。

我还得让这个信号有一面是接地的。那怎么样呢？我的信号只能从这边进来，我的交流从这边进来，叠加到直流上去。

那我现在问同学们，我这样画对不对？交流这样加进去，能叠加上去吗？这么画对不对？

**不对。**

为什么？那一点还是 $u_i$——那两点之间的电位还是 $u_i$。你们电路学得非常好。

你可以预测到，这个电流几乎不从直流源那边走，都从你这个小信号这儿走。因为你 $u_i$ 这块电压小，我不会把这块击穿的，我不会让这块开通的——电流全部从你的小信号源走。

这就麻烦了。

> **易错点**：信号源的输出电阻很小。交流信号若直接并到偏置节点上，节点电位就等于 $u_i$，直流偏置被信号源短路掉了。必须靠一个电阻把两者"隔开"。

那怎么办呢？我让这里的电位和这里不能直接通嘛，无外乎就这个意思。我有一个方法：我这儿加一个电阻。

一旦加一个电阻，你们都学过**叠加定理**，对不对？对于它来讲，这时候这个节点上的电位实际上是由两个东西叠加出来的，而不是直接等于 $u_i$ 了——这里是有两个叠加的：一个是 $E_C$（现在是 $V_{CC}$）单独作用，第二个是 $u_i$ 单独作用。这样的话，我就可以在这里产生一个交直流叠加的电位。

看着啊，这还是基电里的东西，基本电路里的。

而且 $E_C$ 成天画在这里，累不累？然后就变成了——我以后不叫 $E_C$ 了，叫 $V_{CC}$。

这样出来的一个电路，就叫做**直接耦合的共射放大电路**。你们很棒啊——注意啊，这个电阻必须得有。

到这里，直接耦合的共射放大电路你们应该很轻松地画出来了，而且每个元器件的作用你们也应该知道。

### 直接耦合，以及它甩下的两个问题

为什么叫"直接耦合"？大家可以看到，它的输入、它的输出都是直接加到这个放大电路上，也都从这个放大电路上直接出来，没有通过任何滤波、什么这些手段。电路之间信号的这种传递，我们叫做**信号的耦合**。这个叫耦合。所以直接耦合就说明什么呢？我的输入信号、输出信号和放大电路之间的这种传递，不经过任何其他东西，一根线连上就完事。

那么直接耦合这里面有两个东西我们要考虑：

第一点，我这里输进去的这个 $u_i$，实际上它的效率并不高——它要在这儿先分压之后才给晶体管，是两个电阻进行分压（$R_B$ 和信号源的内阻各分走一部分）。

第二点，输出的时候，我这块输出给 $R_L$ 的那个上面这个电压，它是**带着直流的**，不是一个纯交流的，是带着直流的。

那么我们就考虑什么呢？我如果做一个电路的话，我这边就是一个纯的交流进去，那边一个纯的交流出来，我应该怎么办？这里进去是个纯交流，那我出来一个纯交流——怎么弄？

直接耦合这两个问题不解决，它就只能是一个"分析起来很漂亮的电路"，还不能直接拿到信号链里去用。怎么办——这里进去是个纯交流，那边出来一个纯交流，那怎么弄？

这个问题先记着，下一讲我们接着往下走。先休息一下。

### 电容耦合：让直流和交流分道扬镳

我刚才抛的问题是：假如我输入是一个纯交流，我输出也是一个纯交流，那我这个电路到底该怎么搭？

思路一点都不复杂——那一小块，换成一个电容，事情就变得很轻松了。

电容干什么用？直流能不能通过电容？直流在电容那里达到稳态的时候是截止的，或者说断开的。对电容来说，直流就是断路。那么我这一路换上电容以后，我那个小的交流信号在这里还能影响这里的开通吗？不能了——在直流状态下，它就是这样一个路径：它可以让我的发射极导通。

而交流往这一放的时候，这个交流可以越过电容。所以这一段上的信号就是直流加上交流，它通过电容这样一个耦合，就很舒服。

```text
   u_i       C1                                 C2          u_o
  (~)-------||-----+-------------+-------------||-------[ R_L ]--- GND
                   |             |
                [ R_b ]       [ R_C ]
                   |             |
                   +---- V_CC ----+
```

前一个电容进去，后一个电容出来。但出去的时候有个细节你们要注意：输出用一个电容隔出去，前一段的波形如果我画一个标准的 $u_{CE}$，它是带着直流电平的那条曲线；可经过电容之后，到输出的 $u_o$ 会变成什么样？直流那部分没了，$u_o$ 就是把交流那一段直接拿过来。

> **易错点**：$u_o$ 不是等于 $u_{CE}$，$u_o$ 是从 $u_{CE}$ 里"取"出来的——因为输出端串了隔直电容。

为什么没了？我不管里面电路怎么样，从前端做一次戴维宁等效，前端就等效成一个小交流信号源、一个直流电源、一个内阻串在一起的形式。这里加上我的电容，这里加上我的 $R_L$，输出就是 $R_L$ 上的电压。在这个电路里可以非常清楚地用叠加定理来算——纯线性的。直流电源单独作用的时候，$u_o$ 上有输出吗？没有；交流源单独作用的时候，$u_o$ 上才有输出。所以直流成分就这样被滤掉了。

> **结论**：这一级本身就是高通滤波器，滤掉直流，得到一个纯的 $u_o$。

这种耦合方式靠电容来做，所以称为阻容耦合——电阻电容耦合的放大电路。

对阻容耦合放大电路来说，两个电容的作用非常清晰，就是八个字：**通交流，隔直流**。直流作用下这两个电容相当于断路；交流作用下，用阻容耦合的时候我们要求这个交流信号频率足够高，高到电容的容抗非常小——对这样频率的信号，电容相当于短路。

> **提示**：电容也有讲究。你在图上看到的那种带正负号的电容，一般是容量比较大的电解电容。打开电路板，你们真的应该见过——小圆柱式的，灰的或者别的颜色，大的小的都有，焊在板上，有的很小，那就是电解电容，电容量比较大。**电解电容是有正负极的，焊反了它是能爆的**，用的时候务必看清楚。

### 阻容耦合放大电路是怎么把信号放大的

放大电路构成到这一步，我们就好好理解理解它的工作原理。我们拿阻容耦合为例。

#### 先摆静态：功放开机了，我还没说话

先让 $u_i = 0$。这其实就是我们一直在用的分析思路：当有多个输入的时候，让它简单化，先让一个起作用，再考虑把另一个加上去。

打个比方，功放开机了，我嘴巴没说话，就是这个状态。

那开机之后它是什么状态？就是让三极管工作在放大状态下。直流过来的时候，你们注意：电容 $C_1$ 相当于断路，电容 $C_2$ 相当于断路，**只有中间这个电路在直流作用下**。那很明显，中间这个电路一定有一个开启的直流 $U_{BE}$。

直流 $U_{BE}$ 作用之后呢？根据输入特性曲线，这个 $U_{BE}$ 就对应一个 $I_B$，于是有了直流 $I_B$。再看输出特性曲线——每一个直流 $I_B$ 值都会有一条输出特性曲线与之对应。输出特性曲线是谁和谁的关系？$i_C$ 和 $u_{CE}$。

> **结论**：输出特性曲线是一个**曲线族**，因为针对不同的 $I_B$ 就有一条对应的输出特性曲线。而后面我们总说 $i_C$ 和 $I_B$ 成比例，依据就在这里——针对同一个 $I_B$，只要工作在线性放大区，$i_C$ 几乎是不随 $u_{CE}$ 变化的，相对是固定的。这些曲线要深深地在你们脑子里，得不断训练自己。

这样我就得到一个放大的直流 $I_C$。当然要注意，这么画不是说它就比 $I_B$ 大这么一点点，很可能这里单位都不一样。

$I_C$ 出来了，自然就有一个 $U_{CE}$。这里有同学问过我接点的电位：发射极 E 这块没加什么东西，它的电位就是 0；但集电极 C 不是——C 和 E 之间可不是短路的。

> **易错点**：什么情况下 C 和 E 之间才近似短路？**双正偏**——发射结和集电结都是正偏，那才是饱和状态。这时候 C-E 之间的压降降到最小，像一个开关闭合。而在正常放大状态下，$U_{CE}$ 确实是有电压的，而且它在自动调节变化。

正是这种自动调节，保证了我的 $I_C$ 和我的 $I_B$ 成比例。还记得我们推 $I_{C\max}$ 怎么推的吗？$I_C$ 之所以能不断变大，是因为谁在变小？$U_{CE}$ 在不断变小。所以你看，$U_{CE}$ 是一个可变化值，它由外电路来定。

如果真的较真从图形上看，输出特性曲线略微上倾——$I_C$ 增大的时候，$U_{CE}$ 其实也要涨一点点。

反过来，$U_{CE}$ 本身也有个直流值：$U_{CE} = V_{CC} - I_C R_C$。为什么这儿要专门分析 $U_{CE}$？因为你的 $u_o$ 就是从 $u_{CE}$ 里出来的。

到这儿直流这条线就非常清楚了：直流 $U_{BE}$ 产生直流 $I_B$，直流 $I_B$ 产生直流 $I_C$，直流 $I_C$ 产生直流 $U_{CE}$。万事俱备，它准备好给你放大了。

#### 再看动态：信号进来以后

现在把 $u_i$ 放进去，$u_i 
eq 0$。它的变化通过 $C_1$ 过去，直接架在 $u_{BE}$ 上。

我把这个逻辑说得清清楚楚，你们记牢：

```text
   (1)      (2)      (3)         (4)          (5)         (6)
   u_i ---> u_BE ---> i_B ------> i_C ------> u_CE -----> u_o
    |         |        |           |            |           |
```

(1) 输入交流，(2) 加在 $u_{BE}$ 上，(3) 这一步是输入特性曲线的功劳，(4) 是输出特性曲线，(5) 是 $R_C$——由 $u_{CE} = V_{CC} - i_C R_C$ 可知方向与 $i_C$ 相反，(6) 经 $C_2$ 隔直输出。

$u_i$ 的变化引起 $u_{BE}$ 的变化，$u_{BE}$ 的变化引起 $i_B$ 的变化——因为根据输入特性曲线，$u_{BE}$ 变了 $i_B$ 就变。

这里我要额外强调一句：$i_B$ 即使交流上去了，它的小值仍然大于 0，其实 $i_B$ 一直保持着正向流动，只是正向流动变大、变小了。**这就是直流加交流的好处**——交流的负半周，对总电流来说依然是正的。

变化的 $i_B$ 产生了变化的 $i_C$。这里就出现一个关键点：变化的 $i_C$ 要让 $u_{CE}$ 产生变化，这个变化落在哪儿？在 $R_C$ 上。可是方向对不对？反了。因为

$$u_{CE} = V_{CC} - i_C R_C$$

于是我们输出了 $u_o$。成功了——我把一个小的 $u_i$，变成了一个大的 $u_o$ 出去了。

而且不仅是一个大的 $u_o$，注意，这个大的 $u_o$ 还带着一个输出电流 $i_C$：**一个大 $u_o$ 加一个大 $i_C$**。而我输入的是什么？**一个小 $u_i$ 加一个小 $i_B$**。这就是放大。

熟练到这个程度——直流链路和交流链路都能从头到尾自己串起来——你们才算把这个原理搞清楚了。

### 输入电阻 Ri：信号源眼里的放大电路

现在我们拿到了一个放大电路。要更好地用它，就得分析它的性能和指标：怎么来说一个放大电路是好，它的性能当然要有指标。

先看输入端。对前面这一大堆放大电路（包括后面的负载一起），我们可以用戴维宁定理等效出一个示意图来。

```text
   u_s                                           u_i
  (~)----[ R_s ]----+------[ R_i ]---------------+
   |                |                            |
   +----------------+----------------------------+
```

这是从信号源这一端看放大电路：信号源是一个电压源加内阻 $R_s$，放大电路在输入端口上被等效成 $R_i$，$u_i$ 就是 $R_i$ 上分到的电压。

> **结论**：对整个放大电路来说，前端的信号源总归可以看成一个电压源和一个内阻串联，或者一个电流源和一个内阻并联，出现在输入端口上。反过来看，对于信号源而言，后面这一大堆放大电路，从这个端口看进去终究可以等效成为一个电阻——这个电阻就叫 $R_i$，也叫放大电路的**输入电阻**。

请注意这个思路的分量：等效成一个 $R_i$。对于信号源来说，它才不管你后面是什么电路，你就是一个电阻，就是它的负载。

那 $R_i$ 是干什么用的？它决定信号源到底给你的放大电路输入了多大的信号。放大电路真正得到的信号，就是 $R_i$ 和 $R_s$ 对 $u_s$ 的一个分压：

$$u_i = \frac{R_i}{R_i + R_s}\, u_s$$

于是问题来了：如果我前端的信号源是**电压型**信号源，这个 $R_i$ 是越大越好还是越小越好？$u_s$ 是信号源自己的电动势，是不变的。你要放大，就希望输入到你端口的 $u_i$ 越大越好；$R_i$ 越大分得的电压越大——第一点，从信号获得上说，$R_i$ 越大越好。

第二点，你们还得考虑一个问题：这个 $u_s$ 画出来，我心里都是非常胆战心惊的。理想电源的概念是什么？功率无穷。它能做到吗？做不到，很有限。就因为它太有限了，所以我才要给它放大。

那你现在是不是得减小对它的功率负荷？别让它输出太大功率。因为一旦我对它的要求超过它能输出的，它一定会想个办法对付你——它一定得失真，它得畸变。

所以 $R_i$ 的第二个理由来了：$u_s$ 是不变的，要减小输出功率就得减小输出电流；电流小了，是不是 $R_i$ 越大越好？

两个方面都指向同一个结论。

> **结论**：信号源是电压型的时候，$R_i$ 越大越好。

所以 $R_i$ 是不是评判放大电路的一个重要指标？$R_i$ 的定义就是：从输入端口看进去，放大电路的等效电阻。

### 输出电阻 Ro：负载眼里的放大电路

再看输出端。

对于 $R_L$ 来讲，我前面这一大堆电路构成一个**单口网络**。单口网络总归可以等效成一个电源和一个内阻串联的形式：电源是这块的开路电压，内阻是从这儿看进去的前端等效电阻。

```text
   U_oo
   +--------[ R_o ]---------+----[ R_L ]---- u_o
   |                        |          |
   +-------( ~ )------------+----------+
```

这是从输出端看：整个放大电路对 $R_L$ 而言是一个**单口网络**，等效成电源加内阻串联——电源是开路输出电压 $U_{oo}$，内阻就是输出电阻 $R_o$。

这个内阻，就是**输出电阻** $R_o$。

那好，我问你们：如果你希望输出的是一个稳定的电压——换句话说，$R_L$ 变化的时候 $u_o$ 尽量保持恒定、变化尽量小——你希望前面的放大电路近似一个电压源。这时候你要 $R_o$ 大呢还是小呢？

很好，$R_o$ 小。$R_o$ 越小，电压变化越小。

> **注意**：但我们现在有一个很重要的问题——我们习惯了电压源，对电流源的认识其实是不够的。

我再给你提一个问题：如果参数需求变了，我要求 $R_L$ 变化的时候，输出的 $i_o$ 几乎不变。这时候我要求前面近似一个什么源？电流源。那你告诉我，这个时候 $R_o$ 是大好还是小好？

$R_o$ 大。

> **提示**：为什么？这里我不展开，你们自己回去推一推。用电流源去推，用分压的道理去推，都可以。我很理解你们——你们对电流源的认识确实没有对电压源认识得那么好，所以更要自己动动手推一遍。

所以 $R_o$ 是不是也是一个重要参数？

### 两级一串，Ri 和 Ro 才开始要紧

刚才这种输入电阻、输出电阻的概念，在**多个放大电路级联**的时候，就更要紧了。

为什么还要再接一级？以后你们肯定知道：一级放大电路可能完成不了那么大的放大，我需要再接一级继续放大。

这么一接，连接处就变成了一个核心点。对于第一级放大电路来讲，我怎么看第二级放大电路？第二级就等效成一个 $R_{i2}$。而且这个 $R_{i2}$ 就是第一级放大电路的负载——第一级的负载 $R_L$，就是第二级的输入电阻。

> **结论**：**前一级的负载 = 后一级的输入电阻。**

这句话你们要理解透。你后面是不是还接了一级、还有多少级，他不管；你只要能给我等效出一个输入电阻来，我实际上只关心你这个输入电阻。

这特别像什么？火车车头。你让一个车头去拉一大堆货车，车头其实不知道后面拉了多少节，它只拉了第一节。但实际上这第一节已经等效了后面那五六十节的力量。那么车头就知道我拽了这么大一个重量往前跑——你给的是我这个等效值。所以这个 $R_i$ 对于车头来说就是它的负载，你把这个断开车头就空了。

同样的道理，对于后面那个放大电路来讲，它不关心前面的信号源是不是"在这儿"的问题了，而是把整个前级当成一个大信号源：等效出来就是**前级的输出电阻加上前级的开路输出电压**。

```text
  u_s            Stage 1        Stage 2       R_o2    R_L
  (~)-[ R_s ]-+-----------+--+-----------+--[     ]--[   ]--- u_o
              |           |  |           |
             Ri1         Ro1 Ri2        Ro2
```

图里那个级间的 `Ri2`，就是第 1 级的负载 $R_L$。对第 2 级来说，它看到的前级是 $(R_{o1}, U_{oo1})$；对第 1 级来说，它带的是 $Ri2$。

对这一节车厢来讲，谁是它的动力源？它直接看到的就是车头。但对第一节车厢来说，谁是它的动力源？是车头和它俩加起来。它可不管这车头是不是真的在拽，而是把两者整个变成一个车头的一体——这跟我刚才说的电源是一回事：我不管你这块是信号源还是放大电路，我从这儿往回看，前端总归等效成一个电源和一个内阻串联的形式。

所以两级、多级连在一起的时候，这种输入电阻、输出电阻以及电源等效的概念，就更为重要、更为清晰。这个大家要加强理解。

### 放大倍数有四种组合

从这个示意图上我们已经能看得很清楚，一个放大电路的这么几个重要参数是什么。

第一个是**放大倍数**。

放大倍数有四种。放大不只是电压放大电压：电压可以放大成电流，电流可以放大成电流，电流也可以变成放大的电压。所以组合出四种：

| 放大倍数 | 含义 |
| :--- | :--- |
| $A_{uu}$ | 输出电压 $u_o$ 与输入电压 $u_i$ 之比 |
| $A_{ui}$ | 输出电压 $u_o$ 与输入电流 $i_i$ 之比 |
| $A_{iu}$ | 输出电流 $i_o$ 与输入电压 $u_i$ 之比 |
| $A_{ii}$ | 输出电流 $i_o$ 与输入电流 $i_i$ 之比 |

> **结论**：其中我们最常求的是 $A_{uu}$。

第二个参数是刚才那个**输入电阻** $R_i$，第三个是**输出电阻** $R_o$。

### 通频带：低频和高频两头都在偷偷衰减

刚才还提到一个重要参数：**频率指标，通频带**。

放大电路里是有东西存在的。刚才那个阻容式放大电路就有问题：当信号源频率很低的时候会发生什么？容抗变得很大，这个信号就不容易进去。信号源那边信号不容易出来，信号是不是就衰减了？随着频率减小，不断衰减。到了频率是直流的时候，它没办法放大——这是一个问题。

```text
   A_u
   ^
   |         _______________
   |       /                 \
   |     /                     \
   |___/                         \___
   +--------------------------------> f
   f_L                            f_H
```

第二个问题来自三极管本身。我让你们回去看过三极管的参数吧？那里还有一个**特征频率**。它表征的是：当频率不断升高的时候，我的电流放大倍数会不断减小。

> **结论**：为什么不断减小？因为都有**结电容**的存在。随着频率不断增高，结电容上的容抗不断减小，电流可以被旁路掉，所以电流放大倍数越来越小，输出信号也就越来越小。

低频衰减、高频衰减，只有中间这一块还在放大——这一块就叫**通频带**。

这个东西很重要。说了半天，你要研究一个放大电路，就得知道你这个放大电路定义的通频带在哪。

我打个比方。我们做这个电路，把通频带定义在 $1\text{ MHz}$ 附近——从 $900\text{ kHz}$ 到 $1100\text{ kHz}$。你看，够宽了吧？$200\text{ kHz}$ 的通频带。但是你拿上去，能听到声吗？

听不到。

为什么？声音的频率主要是在 $20\text{ Hz}$ 到 $40\text{ kHz}$ 之间。以前玩过那个扫频的程序，能把声音扫出来，但每个人耳朵不一样：有人十几赫兹就能听到，有人二十几、三十几才听到；再往上高频就听不到了。反正我觉得到三四十千赫兹就"很那个什么了"。音乐家的耳朵跟我这种估计也不大一样——每个人的频率响应都不相同。

但是你总归得把你的功放的通频带定在该定的地方吧？也就是说，你在设计一个放大电路的时候，首先要关心的是——**它工作频率在哪，你想放大什么**。你想放大的东西不同，通频带当然不同。

> **易错点**：别那么贪心，说"我的通频带全适应"。那是要付出代价的。

### 失真、最大输出电压与效率

除了上面几个，还有这几个指标。

**非线性失真**。这个参数我先不讲，你们可以自己去看看。

**最大不失真输出电压**。很简单的一个定义：你的输出电压如果再大，它就开始失真了。

**最大输出功率与效率**。最大输出功率是指——在保证信号不失真的前提下，你能在负载上输出的最大功率是多少；而输出这个最大功率的时候，你注意你在做一个功放，功放是要讲究效率的：输出功率和输入功率相比，效率是多少？

> **结论**：**这两个指标的前提都是"信号不失真"。**

效率为什么这么重要？我举个数：如果效率是 20%，那基本上你做的这个东西没人要。为什么会是 20%？因为另外那 80% 全在发热。说简单点，你做了一个 $1000\text{ W}$ 的功放搬回去用，你会发现它的主要功能是电炉、是电暖气——因为有 $800\text{ W}$ 在发热。

所以这个指标也非常重要。

### 接下来这几章围绕哪几个指标转

简单把这些指标介绍一下。后面我们会围绕几个主要指标来分析电路。

这一章我们主要关心的是**放大倍数、输入电阻、输出电阻**这三个。为什么是这三个？知道了放大倍数，我就能基本上知道这个电路把信号放大成什么样；知道了输入电阻和输出电阻，我就能知道它适用于什么样的信号、什么样的连接状态——什么输入电阻配什么信号源。

而当我们讲到**功率放大电路**的时候，还会关心它的效率；当我们讲到**高频放大电路**的时候，就会关心它的通频带。

> **承前启后**：上一节讲完「放大电路的性能指标」，下一节接着讲「先直流，后交流：放大电路的分析方法」。

## 先直流，后交流：放大电路的分析方法
> 对应块：BLK12 | 覆盖分集：P12 | 块标题（分集名）：《12-放大电路的分析方法_4K》

上一节我们把放大电路的性能指标过了一遍，也说清楚了在这一章里我们到底关心什么：放大系数、输入电阻、输出电阻。

那么问题就来了——这些东西怎么分析？

说白了，电压放大倍数这件事，本质上就是一句话：我能不能算出交流的 $u_o$ 和交流的 $u_i$ 之间的关系？把这个关系算出来，放大倍数就在里面了。至于直流，直流你放大了那么多，跟我实际上没有什么关系，直流只是**提供了一个工作点**在那儿。

那么这是不是就意味着，我上来了就可以不管直流，直接直奔交流的大小而去？能不能说这句话？

不能。我们回想一下二极管是怎么分析的：对一个二极管电路，交流的 $u_D$ 产生一个交流的 $i_D$，这没问题。可我问你们，这个交流的 $u_D$ 和交流的 $i_D$ 之间的关系，跟 Q 点在哪里有没有联系？

非常清楚有联系。Q 点在这里和 Q 点在那里，对于**相同的** $\Delta u_D$，你会得到**不同的** $\Delta i_D$。

> **注意**：这个结论有一个前提条件——$\Delta u_D$ 必须在比较小的范围内。变化量小的时候，这一段曲线才可以近似看成折线、近似看成一段直线。

三极管的输入特性曲线跟二极管长得一模一样，所以立刻就能想到：我那个变化的 $u_{BE}$ 和变化的 $i_B$ 之间的关系，必然受直流点在哪儿的支配。

好比说，我把直流点从底下往上提一点。从这张图上一眼就能看出来：对于**相同变化**的 $u_{BE}$，我可以得到一个**比较大**的 $i_B$ 变化。整个电路我什么都没改，只改了一件事——让 Q 点在输入特性曲线上往上移了那么一点。结果就是：我加了同样的交流信号，$u_{BE}$ 产生同样的变化，可是这个同样的变化因为 Q 点挪了位置，产生了不同的 $\Delta i_B$。$\Delta i_B$ 变大，$\Delta i_C$ 跟着变大，$R_C$ 上的压降跟着变大，而 $R_C$ 上的压降直接决定 $u_{CE}$，所以 $u_o$ 就变大了。

> **结论**：要分析动态，必须先知道我在哪个点上动态；分析动态之前，必须先分析静态。
>
> 所以放大电路的分析原则只有一句：**先直流，后交流**。

这两步各自对应一个电路，这就是所谓的两个通路：**直流通路**和**交流通路**。

---

### 直流通路：把交流按掉，看静态

直流通路是什么？就是我这个放大电路中**直流所流经**的那条通路。

怎么画？记住几点就够了：

- 输入信号 $u_i$，我既然只研究直流，那就把交流给它置零——所谓置零，就是接地；
- 如果前面给的是信号源 $u_s$ 并且给了内阻，也一样置零；如果人家干脆直接给 $u_i$，你就把 $u_i$ 置零。反正不管哪种写法，**信号源一律置零**。直接给 $u_i$，其实近似默认了前端是个电压源；
- 电容相当于断路，电感相当于短路。

拿这个阻容耦合共射放大电路来说：

```text
                              +V_CC
                                │
             ┌──────────────────┼──────────────┐
             │                  │              │
            R_B1                 │             R_C
             │                  │              │
u_i ─[C_i]────┤                  │              │
             ●────── B ─────────┤              │
            R_B2                 │              ├── C ─[C_o]─┬── u_o
             │                  │              │            │
             │                 ───            ───           │
             │                  E              E            │
             │                  │              │            │
            GND                GND            GND          GND
```

$u_i$ 置零（接地），$C_i$、$C_o$ 断路，剩下的就是直流通路：

```text
                              +V_CC
                                │
              ┌─────────────────┼────────────────┐
              │                 │                │
             R_B1                │               R_C
              │                 │                │
              ├──── B ──────────┼────────────────C
             R_B2                │                │
              │                 │                │
             GND                GND              GND
```

读这张图：中间那一块就是直流走的路，$R_{B1}$、$R_{B2}$、$R_C$ 都还在，两只耦合电容被打开了。

直流通路最大的用处是：**静态上的一切错误，在这张图上一下子就能看出来**。

还记得最早我们画过的那一版错的电路吗？当时你们给的答案是"这块还是 $u_i$"。现在不用争了，直接用直流通路判断：你一旦把 $u_i$ 置零，直流通路立刻画出来，而画出来一看就明白了——那个版本 $R_{B1}$ 是直接接到地上的；而现在这个版本，$R_{B1}$ 上面明明坐着一个电阻接到 $V_{CC}$。**电路合不合理，画一次直流通路就判完了。**

顺便把直流通路上要算的东西交代清楚，免得后面糊涂。在输入特性曲线上，我求的是 $U_{BE}$ 和 $I_B$；在输出特性曲线上，我求的是 $U_{CE}$ 和 $I_C$。直流的时候，先有直流 $U_{BE}$、直流 $I_B$，然后直流 $I_C$、直流 $U_{CE}$。

---

### 交流通路：把直流按掉，看动态

交流通路就是我交流信号所流经的那条通路。

先说清楚一件事：这个说法是**近似**的。因为三极管是非线性元件，叠加定理是给线性电路用的，不能拿它硬往上套。后面我们会把三极管等效成线性元件，那时候才能名正言顺。

在"近似当成线性"的前提下，交流通路有两条处理规则：

**第一条，直流源置零。** 这跟叠加定理有点像，但我过一会儿会告诉你为什么必须置零、为什么置零来分析才是对的。道理很直白：交流信号流过直流电源的时候，这个直流电压源就相当于一个短路的东西，信号直接过去。

**第二条，电容短路。** 为什么？一般用阻容耦合放大电路的时候，我们对信号源的要求是频率足够高。频率足够高的时候，这个通交隔直的耦合电容容抗就变得非常小，可以近似当作短路。

照着这两条，上一张电路的交流通路是：

```text
   u_i ────── B ────────────────── C ──── u_o
              │                     │
              R_B                   R_C
              │                     │
             GND                   GND
```

画的时候有三个动作，我把它们拆开说：

1. **置零就是接地。** 我教一年级小学生都能教会这块——凡是带加号的 $V_{CC}$，他们都知道那叫 $V_{CC}$，都能读出来。现在要干的事就是把它接地。
2. **两条竖线可以并一根。** 同一根导线上的两个竖条本来就等电位，接到这儿和接到那儿是一样，可以直接连起来、擦掉一个。$R_{B1}$、$R_{B2}$ 那两条竖线并起来就是图里的 $R_B$；$R_C$ 那两条竖线同理，合并成一根。
3. **电容直接用导线连过去。**

> **易错点**：每届学生到最后画交流通路，都会给我弄出一个直流源来。直流源放在那儿，电容又被干掉了，画出一个"四不像"，那就大错特错了。
>
> **交流通路的第一件事，就是把直流源置零。**

两个通路合起来对照，规则其实很整齐：

| 处理对象 | 直流通路（静态） | 交流通路（动态） |
| --- | --- | --- |
| 信号源 $u_i$（或 $u_s$） | 置零（接地） | 保留 |
| 直流电源 $V_{CC}$、$V_{BB}$ | 保留 | 置零（接地） |
| 耦合电容 $C_i$、$C_o$ | 断路 | 短路 |
| 关心的量 | $U_{BEQ}$、$I_{BQ}$、$I_{CQ}$、$U_{CEQ}$ | $\Delta u_{BE}$、$\Delta i_B$、$\Delta i_C$、$\Delta u_{CE}$ |

---

### 图解法：在特性曲线上找 Q 点、叠 Δ

现在我们真正动手分析一个放大电路是怎么工作的。就从最简单的基本共射放大电路开始。

我要分析的是什么？我放进去的交流 $u_i$，就相当于一个 $\Delta u_i$；我要看它和输出端的 $\Delta u_o$ 之间是什么关系——把这个关系算出来，就是放大倍数。

怎么算？**图解法。** 你们电路课上学过非线性电路的分析吧？非线性电路就是用图解法做的。

图解法要用的工具我有两张：一张是输入特性曲线，横轴 $u_{BE}$、纵轴 $i_B$；另一张是输出特性曲线，横轴 $u_{CE}$、纵轴 $i_C$。

这两套曲线是三极管特有的。三极管要工作，它的工作点必然**同时**落在输入特性曲线上，也落在输出特性曲线上。

那么图解法到底是找什么？找 Q 点。怎么找？

道理和二极管一模一样，一个约束来自两头：

- 一个是**外面**给的：输入回路把它限死了一条线，这叫工作线；
- 一个是**里面**的：三极管自己的输入特性曲线。

它只有**同时满足**这两条，才能生存。两条线的交点，就是它真正工作的地方。

#### 输入回路：先定 Q 点，再叠加 Δu_i

直流情况下，还是那套办法：**先把 $\Delta u_i$ 置零**，我暂时不考虑它，只看 $V_{BB}$ 的时候，Q 点在哪儿。

只看 $V_{BB}$，$i_B$ 和 $u_{BE}$ 是什么关系？

$$ i_B = \frac{V_{BB} - u_{BE}}{R_B} $$

这是一条直线，你完全能画出来：横截距是 $V_{BB}$，纵截距是 $\dfrac{V_{BB}}{R_B}$。它和输入特性曲线的交点，就是 Q 点，我们叫它**静态工作点**。

Q 点找出来了，就可以往上加东西了。把 $\Delta u_i$ 加上去。因为 $\Delta u_i$ 加进去之后工作线是**平移**的，所以你会得到一条和原来平行的线：

```text
   i_B
    ▲
    │                 ╲  L(+Δu_i)
    │      ●P2 ───┤   与 L0 平行、横移 Δu_i
    │     ╱
    │    ╱   输入特性曲线
    │   ╱
    │    ●Q ──────┤   L0 ：i_B = (V_BB − u_BE)/R_B
    │   ╱
    │  ╱
    │●P1 ─────────┤   L(−Δu_i)
    └─┬───┬───┬────────────────────────────▶ u_BE
      P1  Q   P2
       ←── Δu_BE ──→
```

读图的顺序是这样的：中间那条 $L_0$ 是 $\Delta u_i = 0$ 的工作线，它和输入特性曲线的交点就是 Q；上面、下面两条是加上 $\pm\Delta u_i$ 之后的工作线。它们与输入特性曲线的交点 $P_1$、$P_2$ 之间，横向读出 $\Delta u_{BE}$，沿曲线纵向读出 $\Delta i_B$。Q 点本身对应的横坐标是 $U_{BEQ}$，纵坐标是 $I_{BQ}$。

> **易错点**：整个图解法里，对静态点的要求最"苛刻"的一点就在这儿。Q 点在这个位置和挪到那个位置，**相同的** $\Delta u_{BE}$ 会给出**不同的** $\Delta i_B$。所以 Q 点定错了，后面全错。

#### 输出回路：把 Δi_B 搬过去，读出 A_u

输入这边算完了，接着在输出回路做同样的事——从输出回路写一个 $u_{CE}$ 和 $i_C$ 的方程：

$$ i_C = \frac{V_{CC} - u_{CE}}{R_C} $$

截距一个 $V_{CC}$，一个 $\dfrac{V_{CC}}{R_C}$。别让它跑出坐标范围。

现在去输出特性曲线上找 Q 点：找 $i_B = I_{BQ}$ 的那一条曲线，它和输出工作线的交点就是输出侧的 Q 点。别让它出界。

然后把刚才那个 $\Delta i_B$ 搬过来：

```text
   i_C
    ▲
    │      ●B ──────┐   L′ ：把 L 上移 Δi_C = β·Δi_B
    │      │         │
    │      ●A ──────┘   A ：落在 i_B = I_BQ 那根输出特性曲线上
    │     ╱
    │   ╱
    │ ╱
    │●Q′ ─────────────   Q′ ：输出 Q 点 = 输出工作线 L ∩ 输出特性曲线
    └───────┬────────────────────────────▶ u_CE
            A′
    ←─── Δu_CE ───→
```

做法是从 $Q'$ 竖直上移一个 $\Delta i_C = \beta\Delta i_B$，落到 $i_B = I_{BQ}$ 那根输出特性曲线上的 $A$ 点；再从 $A$ 水平向左走回到输出工作线上，得到 $B$ 点。$A$、$B$ 之间的竖直距离就是 $\Delta i_C$，水平距离就是 $\Delta u_{CE}$。

最后一步：把 $\Delta u_{CE}$ 和前面的 $\Delta u_i$ 一比，放大倍数就出来了。整个图解法到此为止。

顺带解决一个你们一定会问的问题：**为什么我拿一个 $\Delta u_i$ 就能代替 $u_i$ 的变化？**

因为 $u_i$ 的变化无外乎就是 $\Delta u_i$、就是它的峰峰值。我这样一个交流信号，相对于直流工作点来看，不外乎就是这么大的一个 $\Delta$ 量。所以完全作图法，用 $\Delta u_i$ 来画就够了。

> **结论**：图解法的全部要害就两步——**先确定 Q 点**，再**在 Q 点上叠加 $\Delta$**。$\Delta u_i$ → $\Delta u_{BE}$ → $\Delta i_B$，然后搬到输出侧得到 $\Delta i_C$、$\Delta u_{CE}$。

### 既然不能一直画图，就让三极管线性化

我总归不能一直用图解法。你们想想，如果每一个电路都要这样一张一张画下去，这课就没法上了。图解法最重要的地方，在于它帮我们把**工作原理**分析清楚了。

那接下来我为什么不能直接用别的办法——比如说，用线性电路的方法来求解这个电路？

因为这里头有一个非线性元件：三极管。我能不能把三极管线性化？这是一个非常值得想一想的问题。

我们把整个三极管拆开来看。求这个电路的 $u_o$，关键在哪儿？$u_i$ 过来，最后在这儿产生一个 $i_B$；然后这个 $i_B$ 在这儿直接就是一个 $i_C$，被放大了。$i_C$ 和 $i_B$ 之间的关系很清楚：

$$ i_C = \beta i_B $$

这一段是线性的。再往输出看，$u_o$ 说白了就是 $R_C$ 两端的东西：

$$ u_o = -i_C \cdot R_C $$

这一段也是线性的。也就是说，$i_B$ 这一段的电流关系、$R_C$ 上取输出这一段，我都可以用线性的东西来替代。

**关键点在于**：$i_B$ 和 $u_{BE}$ 之间的关系，或者说 $i_B$ 和 $u_i$ 之间的关系，总体来讲它肯定不是线性的。大范围地看，$i_B$ 这样变化、$u_{BE}$ 这样变化，它俩不成直线。

那哪儿是线性的？你这个 $\Delta$ 是不是？交流这一部分是线性的。当交流的 $u_{BE}$ 比较小的时候，交流 $i_B$ 和交流 $u_{BE}$ 之间就可以看成一段直线段了，它俩之间就出现了一个线性关系。

那我就厉害了——只要我知道这个 $\Delta$ 和那个 $\Delta$ 之间的线性关系，整个电路就变简单了。

#### 输入端：动态电阻 r_be

定义这样一个电阻，**动态电阻**：

$$ r_{be} = \frac{\Delta u_{BE}}{\Delta i_B} $$

这个电阻值实际上就是**过 Q 点那条切线的斜率的倒数**，它描述的就是 $\Delta i_B$ 和 $\Delta u_{BE}$ 之间的关系。

然后我就用这个东西去替代输入这个端口——我把这个端口不再看成一个二极管了，这一整块全扔掉，换成一个 $r_{be}$。放二极管和放 $r_{be}$，在交流的意义上是一样的。

这个等效对三极管意味着什么？就是我 $u_i$ 和 $i_B$ 之间的关系被线性化了。$r_{be}$ 这块本身实际是那根曲线，只是因为变化量小的时候这一段是线性的，所以才能这么换。

> **提示**：这里极其容易掉坑。两条曲线上随便点一点、比一比，得到的比值都不一样。可是在 Q 点附近，$\Delta u_{BE}$ 和 $\Delta i_B$ 的比值是**固定**的。
>
> 所以前提是**纯交流**。$\Delta i_B$ 和 $\Delta u_{BE}$ 的关系可以等效成 $r_{be}$；$u_{BE}$ 和 $i_B$ 的关系**绝对不能**这么说。

一旦静态点定下来了，对于 Q 点附近的 $\Delta u_{BE}$ 和 $\Delta i_B$，放二极管和放 $r_{be}$ 得到的关系近乎等效。我把这个三极管整个封进一个黑匣子里——这就是等效的概念。

#### 输出端：流控电流源 βi_b

输出这面其实它什么也不关心。它只要求一件事：我这块输出的电流，实际就是 $\beta$ 倍的 $\Delta i_B$。

进从这个端口进去的是 $\Delta i_B$，出来的是 $\beta$ 倍的 $\Delta i_B$——那这个模型用什么来替代？我们学过，受控源。加一个受控电流源，大小就是 $\beta$ 倍的 $\Delta i_B$，用它替代三极管来分析这种交流小信号，没有毛病。

于是三极管就变成了这样一个东西：$b$ 和 $e$ 之间一个电阻，$c$ 和 $e$ 之间一个流控电流源。

#### 四个带 I_B 的写法，一个都不能混

这一步我一下写出四个 $I_B$ 来，现在就开始注意符号，一个都不能混：

| 写法 | 含义 |
| --- | --- |
| $I_B$ | 纯直流 |
| $i_B$ | 瞬时值，既含直流又含交流 |
| $i_b$ | 仅含交流（小写字母、小写下脚标） |
| $\dot{I}_b$ | 交流分量的正弦相量 |

我问你们一句：**直流有相量吗？** 没有。既然直流没有相量，那我在这里标定的，就统统是纯交流。

到这里，整个电路已经线性化了，下面所有的问题都变得异常简单。

### 等效到底凭什么成立：坐标原点搬到了 Q 点

这一段我想把它讲透，因为它撑起了整个交流分析。

我们动用 $r_{be}$ 这个关键点，说白了就是这么回事：**我把我的坐标原点，从原来那个地方，搬到了 Q 点这儿。**

为什么可以搬？因为对于 $\Delta$ 来说，我把直流给拿掉了。原来的坐标系里，直流的 $u_{BE}$ 是从原点开始往上数的；现在原点一搬到 Q 点，直流就没了，只剩下 $\Delta u_{BE}$ 在动。这时候再看这一小段曲线，它就是一个线性电阻——因为在新的原点附近，这一段就是直的。

所以答案也就清楚了：

- 交流通路为什么必须把直流电源置零？**因为只有直流置零了，这个坐标原点才真的搬到 Q 点上去。**
- 而交流信号"单独作用"这件事，其实是不现实的。它一定是在直流的肩膀上做这件事情——交流骑在直流上面。
- 但我们可以近似地认为：先有直流，再让交流单独作用。因为这样确实能等效出来。

> **结论**：**没有直流绝对不行。** 所以等效的第一步必须是先直流。

整个分析思路到这里就闭合了：第一，用直流通路定出 Q 点、并检查它合不合理；第二，在这个 Q 点上求出切线斜率的倒数，得到 $r_{be}$；第三，画交流通路，把三极管换成微变等效电路；第四，整个电路线性化，可以求解。

### r_be 怎么算：直流决定动态

$r_{be}$ 这个量，前面说了就是切线斜率的倒数。二极管那边的动态电阻我们是可以推出来的，去求导就完了。三极管这边有一点不同：它这个等效出来的 $r_{be}$，**由于有 $I_C$ 的影响，所以相当于加了一个 $(1+\beta)$ 倍**。

所以它的表达式是：

$$ r_{be} = r_{bb'} + (1+\beta)\frac{U_T}{I_{EQ}} $$

这里面 $I_{EQ}$ 是什么？实际上就是 $I_B$ 的体现，也就是静态工作点。

看到没有，这个公式非常清晰地体现了一件事：**我的直流决定了你动态的参数。** 静态工作点定了，就决定了 $r_{be}$ 的大小。

至于 $r_{bb'}$ 是什么，它是基区的体电阻。基区自己有个电阻，原因是基区的掺杂浓度很低，所以它能表现出一个体电阻，大概是 100 到 300 欧。

所以直流里我们要做的两件事是：先确定静态工作点；再通过这个静态工作点，把输入特性曲线上的 $r_{be}$ 找出来。拿到 $r_{be}$ 之后，马上就可以转去关心交流通路了。

### 从 U_BEQ 走到 A_u：完整走一遍

光讲道理不够，我们拿一个具体电路从头走到尾。

#### 静态：直流通路加估算模型

先画直流通路——这一步我相信每一位同学都能做到，就是 $R_B$、$R_C$、$V_{CC}$ 这一块。

估算模型这块，一般题里会直接给你 $U_{BEQ}$，也就是开启电压。为什么能这么做？因为**这块估算模型实际上就是二极管的直流估算模型**——相当于这里有一个开启电压。理解了这个，后面就顺理成章了。

由它求 $I_{BQ}$：

$$ I_{BQ} = \frac{V_{CC} - U_{BEQ}}{R_B} $$

其他的迎刃而解：

$$ I_C = \beta I_{BQ} $$

$$ I_{EQ} = (1+\beta) I_{BQ} $$

静态一出来，$r_{be}$ 就直接求出来了。记住，$r_{be}$ 是**动态**的时候才用的。

#### 判别工作状态：放大、饱和还是截止

到交流之前，有一个问题要先解决：这个管子到底工作在放大状态、饱和状态，还是截止状态？

判断步骤是这样的：放大和饱和这两块都是**开通**的，区别不大；截止是**反偏**的。所以先判是不是截止，然后区分放大还是饱和。对这个电路来说，第二步很简单：

先求这个电路最大的 $I_C$ 值：

$$ I_{C\max} = \frac{V_{CC} - U_{CES}}{R_C} $$

然后从输入回路里求出 $I_B$ 来，拿 $\beta I_B$ 和 $I_{C\max}$ 比大小：

| 比较结果 | 工作状态 | $I_C$ | $U_{CE}$ |
| --- | --- | --- | --- |
| $\beta I_B > I_{C\max}$ | 一定饱和 | $I_C = I_{C\max}$ | 非常小 |
| $\beta I_B < I_{C\max}$ | 放大 | $I_C = \beta I_B$ | 正常 |

道理也很直白：后面的电路能提供的 $I_C$ 是有上限的。当 $\beta I_B$ 大过这个上限，说明它"要不到那么多电流"，只能被拽到上限，那就是饱和，此时 $U_{CE}$ 非常小；反过来说，当 $\beta I_B$ 小于这个上限，说明后面的电流还是供得起 $\beta I_B$ 的，那就老老实实按 $\beta I_B$ 走，工作在放大状态。

#### 动态：三个参数都是基电的老办法

有了 $r_{be}$，就可以关心交流参数了，整个过程非常简单。

第一步是画交流通路，这一步每位同学现在都会了。第二步叫做**等效电路**——也叫微变等效电路。**从交流通路变成微变等效，这是一个关键点。**

这一步极其简单，因为现在只考虑纯交流。找 $b$、找 $c$、找 $e$，找到没有？然后：

- $b$ 和 $e$ 之间，接一个电阻 $r_{be}$。你别嫌这一步简单，先看清楚；
- $c$ 和 $e$ 之间，接一个**流控电流源**，大小是 $\beta i_b$。

于是这个微变等效电路就出来了。下面的问题立刻变得异常简单。

放大倍数：

$$ A_u = \frac{U_o}{U_i} $$

从这个电路上就能求出来，因为 $U_o$ 等于 $-\beta i_b$ 乘 $R_C$，而 $U_i$ 等于 $i_b$ 乘 $r_{be}$：

$$ A_u = -\beta \frac{R_C}{r_{be}} $$

$i_b$ 一消掉，$A_u$ 就出来了。

输入电阻 $R_i$，就是从输入端往里看进去。你用戴维南等效也好，用随便什么办法也好，把它求出来。输出电阻 $R_o$，就是从输出端往里看进去。

这一步做完，你要求的那几个参数，**统统都是基本电路的内容**。

> **提示**：你应该重复地去看基本电路里哪一部分，才能把这块掌握好——**戴维南等效电路**。你想一想，哪一块不是一个戴维南等效电路？都是这个道理。

所以回去看书上的 2.1、2.2、2.3 这三节。等你先把这个思路立住了，再去看书上那些东西，它就变得简单了。否则你从那一大篇东西里推来推去、推来推去，它只不过就是在讨论一个数学推导的问题。

### 起点不一样，放大效果就不一样

这张图你们应该不陌生：它反映的是一个共射放大电路，我们怎么从波形、从图形去分析它的放大过程。

从这张图看得很清楚：我要分析动态，首先要找到 $Q$ 点。为什么？因为 $Q$ 点不一样，什么会不一样？$Q$ 点在这里和 $Q$ 点在这里，对于**相同变化的 $u_{be}$** 来讲，$i_b$ 的变化一样吗？不一样，很明显不一样。这种变化不一样，必然会影响到后面的动态性能，也就是放大的效果肯定会不同。

所以在做任何放大电路的分析时，最终要分析的都是动态性能：输入了多大信号会输出多大信号，输入电阻是多少、输出电阻是多少，都是针对交流信号而言的。但动态信号的分析恰恰是基于这个电路静态在哪里。静态起点不一样，动态反映的效果就不同。

一旦静态确定下来，我就可以在静态上面把动态加上去：$u_{be}$、$i_b$，这里是 $i_c$、$u_{ce}$。现在你们应该已经知道这几个符号的含义了，我把话挑明再说一遍——这一串量每个的含义都不一样：

- $I_B$：**直流**，静态值；
- $i_B$：**瞬时值**，直流和交流都存在的那个实际的瞬时量；
- $i_b$：**交流分量**，就是 $i_B$ 上面震荡的那一块；
- $\dot{I}_b$：正弦交流量的**相量**；
- $I_b$：这个正弦交流量的**有效值**。

如果用一个坐标来画：那根实线是大的 $I_B$，直流；另一根线是 $i_B$；而这里面如果把这个直流去掉，剩下的交流就是 $i_b$。

我们研究动态，先静态后动态，先静态的是什么？就是这个 $I_B$。我找到 $I_B$，也就是说知道我这个交流的 $i_b$ 会在这个直流 $I_B$ 的**哪里上下动**，这很重要。看到没有？然后我把交流的 $i_b$ 放上去。其实我到最后分析的时候，只分析这个交流的响应；但为了分析动态响应，你得先找到直流。

### 感性地推一把：斜率的倒数就是 $r_{be}$

上节课我们根据那个图形，很容易就想到一点：这里无外乎等效为什么？这里一个变化量 $\Delta u_{be}$ 和 $\Delta i_b$ 之间到底是什么关系？有了这个 $\Delta$ 的关系，我很容易清楚 $\Delta i_c$ 大约等于 $\beta$ 倍的 $\Delta i_b$——这个我们从开始学的时候就知道。

由此我们得到了哪个等效？我把中间这个东西给它括起来，用另外一个电路等效出来，让它在**这种 $\Delta$ 的条件下**成立。

> **易错点**：注意我说啥，$\Delta$ 的条件下！绝对不是 $U_{BE}$ 对 $I_B$ 的条件下。如果是 $U_{BE}$ 对 $I_B$ 的条件，你绝对不能那么等效。$U_{BE}$ 对 $I_B$ 实际上是那个点在坐标系里面；而我现在关注的是这个交流的 $u_{be}$ 和交流的 $i_b$ 之间的关系，我关心的是 $\Delta u_{be}$ 和 $\Delta i_b$ 之间的关系。所以我这里换成了 $\Delta$。

一旦换成 $\Delta$，我就可以发现：这边用一个 $r_{be}$ 来替代，$\Delta u_{be}$ 和 $\Delta i_b$ 之间的关系就可以得以表述。这个 $r_{be}$ 是谁呢？我的前提条件是 $u_{be}$ 的 $\Delta$ 变化**很小**。当它变化很小的时候，这段线近似于直线段。所以只要我能求出这个直线段的斜率——就是 $\Delta u_{be}$ 和 $\Delta i_b$ 之间的比值——我这块就不用看了，我就相当于一个 $r_{be}$ 电阻。用数学的方法精确一点描述的话，就是**过 $Q$ 点切线斜率的倒数**。

那么这个 $r_{be}$ 怎么用来替代输出侧？一旦 $\Delta i_b$ 知道了，很明显这边可以用一个**流控电流源**来替代，这大家都能理解，流控电流源上的电流就是 $\beta$ 倍的 $\Delta i_b$；然后这里是 $\Delta u_{ce}$。

这个过程非常感性，但你可以看到一条链子摆在那儿：**我静态 $Q$ 点不同，谁不同？$r_{be}$ 就不同。** 所以静态影响动态参数，在这儿反映得非常确定——你的 $Q$ 点不同，$r_{be}$ 就不同；$r_{be}$ 不同，对于相同的 $\Delta u_{be}$ 来讲，就会有不同的 $\Delta i_b$；有不同的 $\Delta i_b$ 就会有不同的 $\Delta i_c$；有不同的 $\Delta i_c$ 就会有不同的 $\Delta u_o$。

所以同一个管子放在那里，你给它不同的静态工作点，输入了相同的待放大信号，你会得到不同的放大输出。**相同的管子、相同的输入信号，静态工作点不同，输出就不同。** 这几个界限你们听清楚了吧？

所以你们一定要深深地理解为什么要求解静态。而且求解静态，从图解法上可以很清楚地看出静态在哪里、它影响动态表现在哪里；同时在我们这种等效里面，你们也可以清楚地看到它静态是对哪个动态参数进行影响。

这是我们对上节课所讲东西的回顾。现在你们已经做题了，再回顾一遍，感受又不一样了。接下来我这里毕竟是一种非常感性的说法，看着那个图自然就想到这点——我很喜欢这样想问题，先直观地想一想。但实际上，我们可以建立严谨一些的数学模型。

### 把三极管看成双口网络

数学模型来说，又要用到你们电路的知识了。对于这个端口来讲，我如果把它封起来，同学们说，这是什么网络？双口网络。对吧？双口网络的话，我就可以做**混合参数的模型**。

实际上我无外乎来写出什么呢？这块的输入端是 $U_{BE}$ 和 $I_B$；输出端是 $U_{CE}$ 和 $I_C$。

我现在问你们，$U_{BE}$ 是谁的函数？首先它是 $I_B$ 的函数——$U_{BE}$ 和 $I_B$ 的关系，不就是这根线吗？或者你反过来说 $I_B$ 是 $U_{BE}$ 的函数，也一样。

那么除了受 $I_B$ 的影响，这根线还受谁的影响？$U_{CE}$。还记得吧？$U_{CE}$ 不同，我是不是让你们回去自己查过——为什么 $U_{CE} \geq 1\text{ V}$ 之后，这根线几乎就不动了？否则它是一个**曲线族**：对于不同的 $U_{CE}$，就有一根 $U_{BE}$ 和 $I_B$ 之间相对应的曲线。这给你们复习一遍，哪块没去看，你们赶紧去看。

所以 $U_{BE}$ 和 $I_B$ 的函数关系绝对不是一个单一的，还有 $U_{CE}$。这是一个函数，这是输入端口的函数关系。

输出端口能不能得到？$I_C$ 我现在问你们跟谁有关。首先看得很清楚，它和 $I_B$ 有关；另外，输出特性曲线本身就表明 $I_C$ 和 $U_{CE}$ 之间的关系。所以我为什么这么写呢？这样同学们可以看到，我这个端口特性的**自变量都是谁？是 $I_B$ 和 $U_{CE}$**。

好，这个端口特性我可以写出来。这样描述出来之后，我现在要求的是什么？我实际上要求的是**变化量**——$\Delta U_{BE}$ 和 $\Delta I_B$、$\Delta U_{CE}$、$\Delta I_C$ 它们之间的关系。直流求完了，交流也放上去了，我想求的就是这个函数关系里面，各量变化一点点的时候它们之间是什么关系。

这个模型它表明的是这些曲线上现实的这样一种情况。而我们要做的动态参数等效电路，就是当我把这块单独拿出来看这个动态信号的时候，我要研究的正是 $\Delta U_{BE}$ 与 $\Delta I_B$、$\Delta U_{CE}$ 与 $\Delta I_C$ 的关系。

这个关系我可以从这个方程推出来，肯定可以。我一旦求出这个关系，是不是就往我这个感性的结果上推了？这是我们前面推出来的结果，现在要重新用数学的方法推一遍。

### 对端口特性做全微分

该怎么推？什么是 $\Delta$？我已经在提醒了，这块是要写 $\Delta$ 的关系了。你现在本来是一个函数关系，现在要知道它们 $\Delta$ 之间的关系，看用什么求？什么是 $\Delta$？什么能很好地表现 $\Delta$？是**微分**。

我做这个东西的全微分，$\Delta$ 就出来了。$\Delta$ 是当它趋向于 0 的时候的那个微分。

$$\text{d}U_{BE} = \left.\frac{\partial U_{BE}}{\partial I_B}\right|_{U_{CE}} \text{d}I_B + \left.\frac{\partial U_{BE}}{\partial U_{CE}}\right|_{I_B} \text{d}U_{CE}$$

$$\text{d}I_C = \left.\frac{\partial I_C}{\partial I_B}\right|_{U_{CE}} \text{d}I_B + \left.\frac{\partial I_C}{\partial U_{CE}}\right|_{I_B} \text{d}U_{CE}$$

> **提示**：第二项下面的下标别漏了。写 $\frac{\partial U_{BE}}{\partial U_{CE}}$，含义是**$I_B$ 保持为常数**、只对 $U_{CE}$ 求偏导，后面那个才是 $U_{CE}$ 的变化量。这两个偏导是在两个不同的"冻结条件"下算出来的，不能混。

数学里的东西同学们还要记住一些。

这个数学还是需要的啊。我感觉数学功底好非常重要，我自己数学功底就不够好。数学功底好，到后面你做科学研究的时候可以很上层次，你可以把里面都抽象出来——因为一门科学它发展成熟了，必然数学模型建立得很好。这个层面的数学，我估计跟你们水平差不多。

同学们，这样写出来我理解你们，你们看着会头晕。但你脑子里反过来看，把这些东西都看成 $\Delta$，它会变成什么样？这一串值我用四个东西来取代：

$$\Delta U_{BE} = h_{11e}\,\Delta I_B + h_{12e}\,\Delta U_{CE}$$

$$\Delta I_C = h_{21e}\,\Delta I_B + h_{22e}\,\Delta U_{CE}$$

实际上我就是这四个东西，我让它变成四个**混合参数**。

所以如果你仅仅是推数学，你注意，你仅仅推数学你会觉得"哎呀这个思路是很清晰的"，但它背后的**物理含义不清晰**。数学是这么推出来的，所以推出来的数学公式我们一定要知道它的物理意义。

### 从方程反构出电路

这四个量很清楚吧？是 $\Delta U_{BE}$、$\Delta I_C$、$\Delta U_{CE}$、$\Delta I_B$ 这四个 $\Delta$ 之间的关系。既然很清楚，那我就可以重构了。

端口是 $\Delta U_{BE}$ 和 $\Delta I_B$。$\Delta U_{BE}$ 到底等于什么？等于 $h_{11e}\cdot\Delta I_B$，再加上 $h_{12e}\cdot\Delta U_{CE}$。这也是一个电压——**电压等于两个东西相加。电压什么时候相加？串联。**

所以第一个可以画成一个阻抗，它的名字是 $h_{11e}$；后面这一段是一个**压控电压源**，它的压控参数是 $h_{12e}$，控制量是 $\Delta U_{CE}$。

当这块是 $\Delta$ 的时候，你画一个三极管也好，画一个这个东西也好，完全等效——从公式上它俩完全是等效的。

输出端这边，$\Delta I_C$ 现在是两部分。**电流怎么能成相加？并联。** 所以这块和那块是并联。那这是个电流源，很明显这是一个**流控的电流源**，它的电流就是 $h_{21e}\cdot\Delta I_B$。剩下那个是什么？**电导**，它的名字是 $h_{22}$，因为这里的输出是 $\Delta U_{CE}$。

```text
            b                             c
   ┌────────┬────────┐           ┌────────┬────────┐
   │        │        │           │        │        │
   │[ h11 ]          │           │  (h21) │        │
   │        │        │           │        │        │
   │        ( h12 ) │           │         1/h22   │
   │        │        │           │        │        │
   └────────┴────────┘           └────────┴────────┘
            │                             │
            └─────────────────────────────┴
                              │
                       发射极 e（公共参考端）
```

读图：左边输入回路里，$h_{11}$ 与压控电压源 $h_{12}$ **串联**在 b–e 之间；右边输出回路里，流控电流源 $h_{21}$ 与 $1/h_{22}$ **并联**在 c–e 之间；两个回路的下端都接发射极 $e$，这就是"混合"二字的由来——因为这几个参数的**量纲都不一样**。你们电路里学过，混合参数。画图的时候 $h_{22}$ 这一块是用阻抗形式写的，它写成 $\frac{1}{h_{22}}$ 了。

为了跟书上统一，我们把这个 $e$ 去掉，都是混合参数。

换句话说，我就可以把上面的三极管模型拿出来了：当它是**低频小信号**作用时，它的等效模型就是这个样子。这就是它的等效模型，我完全用数学推出来的。

### 四个 h 参数分别是什么

这几个参数写出来对应什么，你们能对得上吧？

| 参数 | 对应的是哪个量 | 量级与处理 |
| --- | --- | --- |
| $h_{11}$ | $Q$ 点处 $\Delta U_{BE}$ 与 $\Delta I_B$ 的关系，也就是那根线的斜率倒数 | 就是前面那个 $r_{be}$ |
| $h_{12}$ | $U_{CE}$ 的波动引起 $U_{BE}$ 的改变量，即那个压控电压源 | $U_{CE} > 1\text{ V}$ 后曲线几乎重合，约 $0.01$ 这样一个范围，可以忽略 |
| $h_{21}$ | $I_C$ 对 $I_B$ 的关系，即那个流控电流源 | 就是我们的 $\beta$ |
| $h_{22}$ | 输出特性曲线的上翘程度，是个电导 | $=\dfrac{1}{r_{ce}}$，是 $10^{-5}$ 或比这还小，可以忽略 |

$h_{11}$ 就是我们前面非常感性讲的那个 $r_{be}$，没错。

再说 $h_{12}$：它说明的是 $U_{CE}$ 的波动对输入的改变值。这个值当 $U_{CE} > 1\text{ V}$ 之后你们知道几乎重合了，这个时候 $h_{12}$ 非常小。小到什么程度呢？$0.01$ 这样一个范围。所以那个压控的电压源我们几乎可以忽略。

再说 $h_{22}$：大家可以看到，实际上这根线我上来的时候就跟大家讲过，它**并不是水平的**，它是微微有些上翘的，但上翘的斜度比较小。$h_{22}$ 越小，说明这根线越平。$\frac{1}{h_{22}}$ 那块画在那里，我们叫做等效电阻 $r_{ce}$，就是 c、e 之间的等效电阻。这个电阻有多大呢？百千欧、百千欧以上。也就是说，当后段你接的负载电阻不是非常非常大、大到能和它相媲美的程度的时候，我们几乎可以认为 $r_{ce}$ 是断路的。

### 简化 h 参数，就是微变等效电路

这两个忽略下来——$h_{12}$ 忽略、$h_{22}$ 忽略——我们就得到**简化的 h 参数**。那么你们就知道，这个简化的 h 参数实际上就是上节课我跟你说的那个**微变等效电路**。

> **结论**：为什么能到简化 h 参数、这里面的含义是什么，至此我给你们都讲明白了。上节课我们是从图形上非常感性地认为它就应该这么等效；这节课把里面的误差——$h$ 参数带来的误差——都考虑进来了。

其实这里的误差就是：当时我们上节课在推的时候，**没有考虑 $U_{CE}$ 对输入曲线的影响**。现在你一旦考虑影响，那就是 $h_{12}$；但我们发现这个影响当 $U_{CE} > 1\text{ V}$ 之后非常小。所以输入端一旦忽略它，输入端的模型就和我们上节课直接从图形上感性推出来的一样。

这就是为什么"感性"能行——不是感性碰巧对了，而是被忽略的那两项确实小到可以忽略。今天我们是用数学把它们算出来、证明它们可以忽略的。

### $r_{be}$ 是怎么算出来的

由此我们整个得到了：如果用简化的 h 参数等效模型来分析一个放大电路，整个的分析方法就出来了：

1. **求解静态**——先把 $Q$ 点定下来；
2. **求解 $r_{be}$**——静态定下来之后，$r_{be}$ 才有意义；
3. **画出微变等效电路**，然后按基本电路的方法求 $A_u$、$R_i$、$R_o$。

这个 $r_{be}$ 怎么求解？在图上看得很清楚：$r_{be}$ 就是这两点之间的电阻。它由什么构成？有个 $r_{bb'}$——你现在知道 $r_{bb'}$ 是什么了吧？是**基区里面的体电阻**。这个体电阻我们在手册上可以查得，注意，是在手册上可以查得。

发射区同样有一个体电阻 $r_{e'}$，但这个体电阻非常非常小。为什么非常小？它的**掺杂浓度非常高**，掺杂浓度高的话电阻就小，忽略不计。

实际上我们要求的是谁呢？是 $r_{b'e'}$。这个实际上就是发射结的 PN 结电阻。这个 PN 结电阻的求解方法，我们在讲二极管的时候说过吧？是 $\frac{U_T}{I_D}$。$U_T$ 是什么？温度当量。你们要忘了回去推去。

那么这里的 $I_D$ 实际上是谁？**注意，不是 $I_B$。** 这个 PN 结所流过的电流是 $I_E$。因此这个 $r_{b'e'}$ 实际上是和 $I_{EQ}$ 相关——这就是为什么我们公式里直接推出来是 $I_{EQ}$。

但同学们看到，如果在 $I_{EQ}$ 的条件下推出 $r_{b'e'}$ 的话，那这里的等效电阻是什么？$r_{be}$ 这个等效电阻是**端口电压比上端口电流**。这个端口电流是多少？是 $I_B$；端口电压是 $U_{be}$。那么我这个等效电阻实际上不是 $r_{b'e'}$，是 $r_{be}$。

> **提示**：输入电阻非常明确的一个表示方式就是端口电压比上端口电流。戴维南定理里我们这种输入电阻的求法也是这样，怎么明确地求出来？很简单，$U_{be}$ 你用 $I_b$ 表示出来就好了。

$U_{be}$ 在 $I_b$ 上怎么表示？$U_{be}$ 等于 $I_b$ 乘以 $r_{bb'}$，再加上 $I_e$ 乘以 $r_{b'e'}$，发射极那一项的体电阻忽略的话：

$$U_{be} = I_b \cdot r_{bb'} + I_e \cdot r_{b'e}$$

所以这个东西是什么？是 $(1+\beta)I_b$ 吧？所以：

$$r_{be} = r_{bb'} + (1+\beta)\,r_{b'e'}$$

而 $r_{b'e'}$ 又等于 $\dfrac{U_T}{I_{EQ}}$。它是 PN 结的等效电阻，PN 结的**动态**等效电阻，一定是动态的。

那么问题就来了：所以同学们可以看到，有的同学我估计你们在做题当中有没有这个疑问——这不是吃饱了撑的吗？这块是 $(1+\beta)$ 倍，你干脆写个 $U_T/I_{BQ}$ 不就完事了吗？因为 $I_{BQ}$ 和 $I_{EQ}$ 之间的关系正是 $1+\beta$ 倍，对不对？你为什么不用这个公式，这么来得更省事吗？

是不是这样直接比的道理？不是。这样写是它的**物理意义**在这儿：这个东西就是那个发射结的动态等效电阻，看到没有？这个 $(1+\beta)$ 是因为你**前端的电阻等效模型**是这样的。你最后消掉是这么回事，但物理意义是另一回事。所以你们自己推一遍就知道这个东西为什么是这样。

> **提示**：做题的时候用哪个写法都行，但推导和理解的时候要记住——$r_{bb'}$ 是基区体电阻（查手册），$(1+\beta)r_{b'e'}$ 是发射结动态电阻折算到基极端口的结果。两项的物理来源完全不同，不是同一个东西的两种算法。

这样，我们整个的 h 参数等效模型应该非常清楚地知道了。在下面的两节课当中，我们将应用这种模型一个一个地去分析这些问题，实际上都是基本电路的问题了——想办法把它变成基本电路的问题。

## 共射放大电路的动态分析：从静态工作点到 h 参数模型与三个端口参数

### 先把要什么理清楚：我现在是在倒着分析需求

"先静态、后动态"，这个模型到这一步应该已经比较清楚了——不敢说非常清楚，但应该比较清楚。剩下的问题只有一个：不间断地拿它去解题。

这个模型要是真懂了还解不出来，那出问题的地方就不是模拟电子技术了，是基本电路理论。

来看一个实际的共射放大电路。信号源是电压型的 $u_s$，带一个内阻 $R_s$，接进来；电路输出一个 $u_o$。

已知量给全了：$R_b$、$R_c$、$R_s$、$V_{CC}$、$R_L$，静态估算模型里的 $U_{BEQ}$，还有手册上肯定给得出的 $r_{bb'}$。给出 $U_{BEQ}$ 相当于在二极管里直接给了开启电压。

要求解的只有三样：

> **结论**：$A_{us} = u_o/u_s$、输入电阻 $R_i$（从信号源那个端口看进去）、输出电阻 $R_o$（从负载那个端口看进去）。

上来要的都是动态量，但动态不是凭空能算的。想拿到 h 参数等效模型，关键是要 $r_{be}$；要 $r_{be}$，又必须先有静态工作点。所以我这是**倒着**在分析需求。

> **结论**：正着做题，顺序就是——先静态，再交流通路，再 h 参数等效，然后 $A_u$、$R_i$、$A_{us}$、$R_o$。

### 静态：直流通路里用电位分析法一个一个走

交流输入为零、$u_s$ 置零，耦合电容在直流通路里全部断路。拎出来就是中间那一块：$R_b$、$R_c$ 和三极管。目标是 $I_{BQ}$、$I_{EQ}$，以及整个静态工作点。

#### 一个元件一个元件地走，永远不会错

用电位分析法。以发射极为零电位点，从 $V_{CC}$ 这一头出发，一个元件一个元件往上倒：

- 基极电位比发射极高 $U_{BEQ}$；
- 从基极再往 $V_{CC}$ 那头，又升了 $I_{BQ} R_b$；
- 而 $V_{CC}$ 那一头就是 $V_{CC}$。

于是

$$V_{CC} = U_{BEQ} + I_{BQ} R_b \qquad\Rightarrow\qquad I_{BQ} = \frac{V_{CC} - U_{BEQ}}{R_b}$$

有了 $I_{BQ}$，$I_{EQ}$ 顺手就出来了；再要 $I_{CQ} = \beta I_{BQ}$、$U_{CEQ}$，也都是简单的事。$U_{CEQ}$ 同样用电位分析法：$c$ 点电位比 $e$ 点高 $U_{CEQ}$，从 $c$ 点再往上到 $V_{CC}$ 那头还要升 $I_{CQ} R_c$。

$$V_{CC} = U_{CEQ} + I_{CQ} R_c$$

电位分析法到今天我仍然觉得它很好用。原因是：人想东西最容易错的地方，是把一整堆东西当成一个整体一起看——一看"这一大堆"，就错了。一个元件一个元件地分析，永远不会错，因为一个元件很简单，$u = i \cdot r$，或者"一个元件两端的电压就是它两端的电位差"，概念干净，不给犯错留空间。

#### 加一个 $R_e$ 看看：最容易翻车的地方

我再把这个电路"异化"一下，假设发射极那一路还挂了一个 $R_e$。现在求 $I_{BQ}$，会不会？

电位分析法一点都不会错。$I_{EQ} R_e$ 是从 $e$ 点往基极方向降的，$U_{BEQ}$ 是 b、e 之间的，$I_{BQ} R_b$ 是从 b 往 $V_{CC}$ 升的：

$$V_{CC} = I_{EQ} R_e + U_{BEQ} + I_{BQ} R_b$$

这里 $I_{EQ} = (1+\beta) I_{BQ}$，是**发射极**电流。

> **易错点**：$R_e$ 上的压降要乘 $I_{EQ}$，不是 $I_{BQ}$。很多同学一眼看到电路里多了个电阻，就顺手把它当串联电阻处理，$R_e \times I_{BQ}$ 直接写了上去——这是把"整体一起想"的毛病犯在了最典型的位置上。

#### $r_{be}$：静态分析真正的落脚点

$$r_{be} = r_{bb'} + (1+\beta)\frac{U_T}{I_{EQ}}$$

后面那一项就是 PN 结上的动态等效电阻。$r_{be}$ 一到手，直流的使命就算到头了。

顺便交代一句，直流其实有两个使命：一是判断三极管到底工作在不在放大状态（本题因为没给具体参数，就默认它工作在放大区），二是定出静态工作点，从而推出 $r_{be}$。第二个使命的结果，就是递给动态分析的唯一一张门票。

### 原点往哪儿搬：为什么这时候才敢用 $r_{be}$

我不止一次强调过：**你凭什么能用 $r_{be}$**？

因为用 $r_{be}$ 相当于把坐标的原点提到了静态工作点那里去。提到那儿，这一段才是真正一根过原点的直线——线性电阻的定义本来就是一根过原点的直线吗。原点不提上去，就谈不上 $r_{be}$。

所以用 $r_{be}$ 的时候，脑子里一定要清楚：原点被虚拟地搬到了静态工作点上，所有直流都被置零了。

> **注意**：直流其实还在，只是被抽象掉了。这个矛盾必须想通。想不通的同学就会来问："郑老师，为什么交流的时候 $i_b$ 是个负的电流？怎么会有个负电流在交流的时候？"

答案是：交流时的 $i_b$ 并不是一个负的电流。把直流加回去看，那一段仍然是正向的，只是正向在**减小**。之所以把它抽象成纯交流，纯粹是为了能用 $r_{be}$ 做等效而已。

#### 交流通路怎么来：两件事

- **第一件**：把所有的直流置零——就是刚才说的原点平移；
- **第二件**：耦合电容在交流通路里相当于短路。

做完这两件事，交流通路就出来了。

> **易错点**：交流通路里绝不允许 $r_{be}$ 和 $V_{CC}$ 同时出现。"我总算把 $r_{be}$ 学了，$V_{CC}$ 我也没忘"——但放在一起就是错的。$V_{CC}$ 是直流偏置，$r_{be}$ 是在直流已被扣掉之后的线性切片，原点没搬上去，这两个东西同时在场，$r_{be}$ 就不成立。

画法还是上节课交代的那几步：**先接地，再整理**。接地这一步处理掉 $R_b$ 和 $R_c$，它们就可以"翻下来"，交流通路就整理干净了。

### 从交流通路到 h 参数等效：其实只加两个元件

简化 h 参数等效怎么来？极其简单，记住这几步，以后永远不会画错：

1. 基极找得到吧？
2. 集电极找得到吧？
3. 发射极找得到吧——只不过它现在相当于接地了。

把这三个点擦掉、重新画，然后只加两个元件：

- **b 与 e 之间**：$r_{be}$；
- **c 与 e 之间**：一个流控电流源，受 $i_b$ 控制，大小是 $\beta i_b$，也就是 $i_c$。

```text
              c
              o
              |
        +-----+-----+
        |           |
        |  [ x ib ] |     ic = beta * ib
        |           |
        +-----+-----+
              |
              o-----------------------+
              |                       |
            b o------[ r_be ]--------o e  (= 0, ground)
                                      |
  -----------------------------------o--------  ground
```

就这样，一个非线性的东西，在低频小信号条件下，变成了一个线性等效。

> **注意**：这里所有的符号都换成小写——小写 $i$、小写 $b$。因为这里是一个**纯交流量**，直流已经被拿掉了。

### $A_u$：公式里每一项都解释得出来

模型有了，剩下的求解就变得很简单。把整个电路按功能圈成三块：左边是信号源，中间是放大电路本体，右边是负载。

```text
   +--------------+          +------------------+        +-------+
   |   us      Rs |          |                  |        |       |
   |   (~)    ( /\/\ ) ------->|   放大电路       |------->|  RL   |
   |              |   Ui     |   (Ri, Ro)       |   Uo   |       |
   +--------------+          +------------------+        +-------+
        信号源                    本体                      负载
```

> **定义**：$A_u = U_o / U_i$，只针对中间那块**固定的**放大电路。左右两边会变，中间这块做好之后一般不再动。

这一步我特意把 $U_i$ 圈出来、换个颜色，就是为了强调：先算本体的放大倍数，不去管外面那两个会变的家伙。

$U_o$ 能不能用 $i_c$ 表示？能：

$$U_o = i_c (R_L \parallel R_c) \quad\text{（带负号）}$$

$U_i$ 呢？

$$U_i = i_b r_{be}$$

注意这里为什么都用 $i_b$ 当参数——数学里的参数方程都用 $i_b$，因为 $i_c = \beta i_b$。合起来：

$$A_u = \frac{U_o}{U_i} = -\frac{\beta (R_L \parallel R_c)}{r_{be}}$$

现在看这个放大倍数里的每一项，**每一项都解释得出来物理含义**：

| 因子里的一项 | 对应放大过程的哪一步 |
| --- | --- |
| $r_{be}$ | 动态 $u_{be}$ 变成动态 $i_b$：多大的动态 $u_{be}$ 能产生多大的动态 $i_b$ |
| $\beta$ | 动态 $i_b$ 变成动态 $i_c$ |
| $R_c$ | 动态 $i_c$ 变成动态输出量：上面挂多大的 $R_c$（开环、空载时） |
| $R_L$ | 接上负载以后负载对输出的影响 |

那为什么前面带一个负号？

> **结论**：共射是**反相**的。输出 $U_o$ 本质上是 $V_{CC} - u_{ce}$，正好倒了一个相。而 $u_{ce} = V_{CC} - i_c R_c$，所以 $u_{ce}$ 里 $i_c$ 是反着走的，$U_o$ 就带着这个负号。

我记得第一堂课第一次讲放大电路的时候，就问过大家这个问题：$U_o$ 到底是这样的还是那样的。现在这个负号的来龙去脉，就在那一问里。

### 输入电阻 $R_i$：火车头和后面那一串车厢

$A_u$ 和 $r_{be}$ 之间的关系有了，$U_o$ 和 $U_i$ 之间的关系也有了。那么只要知道 $U_s$ 和 $U_i$ 之间的关系，$U_o$ 和 $U_s$ 的关系就出来了——**把电路拆开看**。

拆开之后，面对前面那个信号源，我接放大电路和接一个等效电阻 $R_i$ 是**一回事**。盒子里面放什么，对我这个等效电阻来说没有区别。

> **定义**：输入电阻 $R_i$ 的含义就在这里——从输入端口看进去，后面那一大堆东西等效成的那个电阻。

这个电路很简单，一眼能看到：

$$R_i = R_b \parallel r_{be}$$

#### 一个问题：算 $R_i$ 的时候，考不考虑 $R_L$？

要**考虑**。

因为到这儿输入回路就断开了，$R_L$ 那条路看似不涉及——但它是一节车厢啊。还记得我给你们讲过的那个火车头的图吗：火车头拽着后面一串车厢。$R_L$ 是不是其中的一节车厢？是。你往上挂，它是不是得算进去？它一样要从这个放大电路这里获取信号。

我后面还要再接一级放大电路，对于前一级来说，那个后级也要算到它的 $R_i$ 里去，这不是很明显的吗。

> **结论**：输入电阻指的是整个后面那一大堆的等效。后面挂的东西不一样，输入电阻就不一样。我的火车头，后面空载和后面挂两车煤，对前面来说当然不是一回事——不能说这也算等效，然后不算后面那两车煤。

#### $A_{us}$：把源电压也算进来

一旦 $R_L$ 定下来，$U_i$ 和 $U_s$ 的关系就非常清晰——就是一个分压：

$$\frac{U_i}{U_s} = \frac{R_i}{R_i + R_s}$$

于是

$$A_{us} = \frac{U_o}{U_s} = \frac{U_o}{U_i}\cdot\frac{U_i}{U_s} = A_u \cdot \frac{R_i}{R_i + R_s}$$

### 同样是放大 100 倍，输出却差了三倍

从这个式子里能读出一个很实际的结论。

两个放大电路，哪怕中间用的晶体管一模一样、放大倍数都测出来是 100 倍，但输入电阻一个 $2\,\text{k}\Omega$、一个 $100\,\text{k}\Omega$，接在同一个电压型信号源后面，结果会差得很远。

给一组具体数感受一下：信号源 $U_s = 20\,\text{mV}$，内阻 $R_s = 1\,\text{k}\Omega$，两个电路的 $A_u$ 都是 100 倍。

```text
        Rs = 1 kΩ              Rs = 1 kΩ
   us ---/\/\---+----------+---/\/\-----------+
   20 mV        |          |                 |
                Ri = 2 kΩ  |        Ri = 100 kΩ
                Au = 100   |        Au = 100
                |          |                 |
                +----------+                 |
                |                             |
                Ui = 20mV * 2/3 = 6.67 mV     |
                Ui ~ 20 mV                     |
                v                             v
               Uo1 = 0.667 V                 Uo2 = 2 V
```

算一下就明白了：

- 输入电阻 $2\,\text{k}\Omega$ 的那个：分到的 $U_i = \dfrac{2}{2+1}\times 20\,\text{mV} = 6.67\,\text{mV}$，放大 100 倍得 $0.667\,\text{V}$；
- 输入电阻 $100\,\text{k}\Omega$ 的那个：$R_i \gg R_s$，$U_i \approx 20\,\text{mV}$，几乎把整个信号源电压都拿了，放大 100 倍得 $2\,\text{V}$。

放大倍数一模一样，输出差了整整三倍。

> **结论**：对电压型信号源来说，输入电阻越大越好。你要的是信号源上那个电压，输入电阻越大，分过去的电压损失越小，后面放大出来的幅度才越大。

### 输出电阻 $R_o$：想稳压还是想稳流

前面那一大堆电路，对于负载 $R_L$ 来说，无外乎可以等效成一个电压源和一个内阻串联的形式——戴维南定理。

> **定义**：这个串联内阻就是输出电阻 $R_o$。求法有两条：一是把前端的独立源置零后，从这个端口看进去的等效电阻；二是端口电压比上端口电流（或者开路电压比短路电流）。一旦里面出现受控源，就必须走后一条路，不能只做电阻串并联。

这个电路里算起来很轻松。把独立电压源置零——**独立源可以置零，受控源不能**——置零之后 $i_b = 0$，受控源特别忠诚，$i_b$ 一为零它马上等于零，等于断路。这回从输出端看进去，剩下的就是 $R_c$：

$$R_o = R_c$$

#### $R_o$ 小和 $R_o$ 大，各像什么源

把前端等效成"一个 $U$ 串一个 $R_o$"，后面挂 $R_L$。两个量分别看：

$$U_o = \frac{R_L}{R_L + R_o}\,U \qquad\qquad I_o = \frac{U}{R_L + R_o}$$

- **$R_o$ 很小**（≪ $R_L$）：$R_L$ 怎么变，$U_o$ 都几乎不变。这时候输出近似一个**电压源**，而且是越稳定越好；
- **$R_o$ 很大**（≫ $R_L$）：$R_L$ 怎么变，$I_o$ 都几乎不变。这时候输出近似一个**电流源**，前提是内阻足够大。

> **结论**：$R_c$ 越小越能稳定输出电压；$R_c$ 越大越能稳定输出电流。上节课留的那个问题——为什么 $R_o$ 大时近似电流源、小的时候近似电压源——不用去推什么模型，从等效概念上看一眼就够了：$R_o$ 大时 $R_L$ 的变化对 $I_o$ 影响很小，$R_o$ 小时 $R_L$ 的变化对 $U_o$ 影响很小。

但这里必须多说一句：

> **易错点**：并不存在"输出电阻越小越好"或者"越大越好"这种说法。目标输出电压信号，$R_o$ 越小越好；目标输出稳定电流信号，$R_o$ 越大越好。看你要干什么用。

事物都是有两面性的。鸦片是毒品，同时也是药品；砒霜是毒品，据说砷里面还有能美容的东西（这一点我不敢说一定对，多少听说过）。关键看你要拿它干什么。工程上也一样——不是造出一个"什么都能用"的设备，而是要非常清楚自己的目标是什么。

### 温度一动，Q 点就跟着漂

这一段转到下一个话题：**静态工作点稳定的放大电路**，以及 Q 点稳定的必要性（必要性到这儿大家应该已经很清楚了）。

先看这个图给出的：晶体管在不同环境温度下的输出特性曲线族。随着温度升高，整族曲线会往上走。

温度升高会带来这些变化，每一条都往同一个方向推：

- $\beta$ 上升；
- $I_{CEO}$（穿透电流）上升——反向电流本来就是少子的事，温度升高必然上去；
- 合成结果：Q 点上升。

同样的道理，温度下降，Q 点就下降。

#### Q 点下滑：尾巴被砍，输出波形掉了头

本来 Q 点好好待在放大区的中间，温度一降，Q 点滑到边界以下，直接进截止区了。

$i_c$ 的**尾巴**被砍平；因为共射是反相的，$u_o$ 上看到的就是**头部**被砍平。拿示波器一看，啪——波形没了头。这叫**截止失真**。

#### Q 点上冲：$I_C$ 撞在负载线上，头部被削

$Q$ 点本来在这儿，非要把它推上去。推的时候 $I_B$ 那一头没事，把 $I_B$ 拉到更高；$I_B$ 原来是在两根输出特性曲线之间动的，那么 $I_C$ 还能长成那个样子吗？不能。

$I_C$ 同时受两个东西约束：

> **定义**：第一，$I_C$ 一定在输出特性曲线围起来的那一大片区域里；第二，$I_C$ 一定在负载线上。所以 $I_C$ 只能在**负载线与输出特性曲线区域的交点**那里取得最大值 $I_{C\max}$。

现在 $I_B$ 要求过分了，能提供的最大 $I_C$ 就是 $I_{C\max}$，再上不去——$I_C$ 的**头部**被削平；因为反相，$u_o$ 的**底部**被削平。这是**饱和失真**。

所以结论很清楚：静态工作点一动，两种失真都可能发生；而温度能推动静态工作点移动，所以温度就能引起这种失真。必须想办法克服它——这就是下一段要讲的 Q 点稳定电路。

### 本讲提到的题目

#### 题目一：为什么 $R_o$ 大时近似电流源输出，$R_o$ 小时近似电压源输出

这是上节课留下的问题，本节用等效概念直接解答。

**解答**：把输出侧对负载等效成 $U$ 串 $R_o$，带负载 $R_L$：

$$U_o = \frac{R_L}{R_L + R_o}U,\qquad I_o = \frac{U}{R_L + R_o}$$

$R_o$ 很小时，分压比 $R_L/(R_L+R_o) \approx 1$，$R_L$ 变化对 $U_o$ 影响极小，输出近似电压源；$R_o$ 很大时，$U/(R_L+R_o) \approx U/R_o$，$R_L$ 变化对 $I_o$ 影响极小，输出近似电流源。详见正文"输出电阻"一节。

#### 题目二：两个放大电路，源电压增益谁大

某电压型信号源 $U_s = 20\,\text{mV}$，内阻 $R_s = 1\,\text{k}\Omega$。两个放大电路从 $U_i$ 到 $U_o$ 的放大倍数都是 100 倍，输入电阻分别是 $2\,\text{k}\Omega$ 和 $100\,\text{k}\Omega$。问：谁的 $U_o$ 大？

**解答**：用 $A_{us} = A_u \cdot \dfrac{R_i}{R_i + R_s}$。

- 第一个：$\dfrac{2}{2+1} = \dfrac{2}{3}$，$U_i = 6.67\,\text{mV}$，$U_{o1} = 0.667\,\text{V}$；
- 第二个：$\dfrac{100}{100+1} \approx 1$，$U_i \approx 20\,\text{mV}$，$U_{o2} = 2\,\text{V}$。

**答案**：输入电阻大的那个输出大，$U_{o2}$ 约为 $U_{o1}$ 的三倍。放大倍数相同不等于源电压增益相同——这一点正是"输入电阻"这个概念的物理分量。

> 另：$R_i$、$R_o$ 的求法一定要练熟。求 $R_i$ 时别漏了 $R_L$；电路里一旦有受控源，求 $R_o$ 就不能只做串并联，必须用端口电压与端口电流的关系，或者开路电压比短路电流。
