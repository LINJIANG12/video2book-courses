## 钉住 Q 点：温度、反馈，与那个"什么都不放大"的电路
> 对应块：BLK15 | 覆盖分集：P15 | 块标题（分集名）：《15-Q点稳定的放大电路和基本共集放大电路_4K》

上一讲我们把静态工作点这个概念彻底铺开了，今天要接着往下走一步：既然 Q 点会跑，那**谁在让它跑**？跑掉了**怎么办**？

### 谁在让 Q 点跑：温度、电源与老化

先回答第一个问题。请你自问自答：什么东西对 Q 点有影响？

第一个，一开口就能答上来——温度，而且影响非常大。除此之外还有两样：

**电源波动**。$V_{CC}$ 那块电源要是自己抖了，Q 点当然跟着抖。这一条好办，换个稳一点的电源，让它的波动足够小，小到可以忽略，基本就"干掉"了。

**元器件老化**。这是很多同学容易掉以轻心的一条：你别以为电阻一贴到板子上就一成不变，它会用、会老化，参数会慢慢漂。一样会推动 Q 点移动。这一条也好办：出厂之前先把这些元器件做一轮老化。汽车前 5000 公里叫走合，过了走合期，后面十几万公里性能就基本稳了；元器件完全一样，前面那一小段让它先"走合"掉，后面就能安安稳稳用很长时间。调好静态工作点再出厂，参数就锁住了。

三样里面，前两样都能用"外部手段"摆平。剩下温度怎么办？

> **易错点**：温度这一条，你想靠外部条件解决是想不通的。想想机房——我们宿舍没空调，计算机房有空调，因为半导体材料怕温度。可你不可能抱着一台半导体收音机过日子，夏天给它吹风扇、拿冰块，冬天抱在怀里焐着。**你绝对不能祈求于"温度不变"，只能从电路的结构上去控制它。**

那好，控制温度影响，从哪儿下手？

### 稳定 Q 点的思路：造一股反向的力量

先把目标钉死：我要稳定的是什么？**$I_C$**。温度一变，$I_C$ 不变——这就是全部目标。

可是现实是，温度一变，$I_C$ 就在变。躲不掉。那思路就得换一下：

温度上升的时候，$I_C$ 要跟着上升，这是"被推着走"的力量。那我能不能**另外造一股力量，把它往下拉**？什么东西能抑制 $I_C$ 的变化？——$I_B$。那又是什么东西控制 $I_B$ 的变化？——$U_{BE}$。

链条一展开，事情就这么简单了：

```text
   温度 ↑
      │
      ▼
    I_C ↑ ──▶ I_E ↑ ──▶ U_E ↑ ──▶ U_BE ↓ ──▶ I_B ↓ ──┐
    ▲                                                      │
    └────────────────── 拉回来，抵消掉 ────────────────────┘
```

读图：这一串箭头里，**只有第一个是温度亲手推的**，后面每一个箭头都是由 $I_C$ 自己引发的。$I_C$ 涨 → 发射极电位 $U_E$ 涨 → $U_{BE}$ 被压低 → 基极电流 $I_B$ 变小 → 反过来把 $I_C$ 拽回来。

> **定义**：输出量的变化被引回输入端，从而改变输入、进而影响输出——这种状态叫**反馈**。这里要的是负反馈。
>
> 我们现在只看到一点皮毛，后面会专门用一整块来讨论反馈。

### 关键的那一步：在发射极底下加一个电阻

回到最熟悉的基本共射放大电路，对着它发愁：

- $I_C$ 上升了？随它去，我有什么办法。
- $E$ 点电位？它是固定死的，$E$ 点就是接地点，动不了。
- $B$ 点？有可能变一点，没用。

"你们现在有没有点思路？我得让我的 $E$ 点能动。发射极的电位，我得让它能随 $I_C$ 变化而变化。"

怎么让它能动？——**加电阻**。

"在哪儿加？别看书。在接地点和 E 之间，在发射极下面。"

就这么轻描淡写的一下，后果可不轻。跟着我一步步走：

1. 温度升高 → $I_C$ 要升高；
2. $I_C$ 升，$I_E$ 就跟它是"如影随形"的——**只差一个 $I_B$，几乎是模子刻出来的**；
3. $I_E$ 上升 → $U_E$ 的电位上升，而且**这个上升量远远大于其他量的变化量**；
4. $U_E$ 升 → $U_{BE}$ 被拉低；
5. $U_{BE}$ 降 → $I_B$ 降；
6. $I_B$ 降 → $I_C$ 被拉回来。

结果是：$I_C$ 是上升了，但只上升了半步。**本来它要蹿上去十步，现在连半步都没上去**，因为剩下的九步半被 $U_{BE}$ 的下降抵消掉了。这颗晶体管稳得离谱。

这就是 $R_E$ 的作用。而 $R_E$ 干的这件事，用刚才那个词讲，就是**反馈**：$I_C$ 是输出量，$U_{BE}$ 属于输入环节，$R_E$ 在两者之间拉了一条纽带，把输出绕一圈又引回了输入。

### 把 $U_B$ 也钉住

这里一定有人要问：你这块大刀阔斧地就说 $U_{BE}$ 下降了，凭什么？**你凭什么说 $U_B$ 不变？**

$U_B$ 是变的，只是变得小。所以还得在前端再动一刀。

"我为了让 $U_B$ 趋于稳定，在前端还可以加电路。加什么电路？这个你们肯定熟悉——**分压式的稳压电路**。"

工程上怎么做？分压下支路那个支路本来就流着 $I_{B2}$。做法一句话：

> **做法**：让 $I_{B2}$ **远远大于** $I_B$。

这样跑过去的电流和基极电流差着好几个数量级，基极电位就近似等于两个电阻的分压值，与 $I_B$ 的波动几乎无关。$U_B$ 趋于稳定，而 $U_E$ 继续老老实实跟着 $I_C$ 跑，两头一稳，Q 点就稳住了。

```text
                       +Vcc
                         │      │
                        Rb1     Rc
                         │      │
   ui ── C1 ──●─────────┤      │
              │         │      │
             Rb2     ┌──┴───┐  │
              │      │  Q1  │  │
             GND     │B   C  ├─┴──Co──RL──GND
                     └─┬─┬──┘
                      RE│E
                      │ │
                     ┌──┴──┐
                    RE    CE
                      │    │
                      └─┬──┘
                        │
                       GND
```

读图：信号从左侧经耦合电容 $C_1$ 进基极，$R_{b1}$、$R_{b2}$ 分压给基极供电；集电极经 $R_C$ 接 $V_{CC}$，并从 $C$ 端经耦合电容 $C_o$ 把信号送出去；发射极经 $R_E$ 落到负端，$C_E$ 跨接在 $R_E$ 两端（这是后面要还的一笔账）。

> **结论**：判断一个电路是不是 Q 点稳定电路，**看它的直流通路就够了**。分压电阻 + 发射极电阻这一段，就是它的全部。

### 直接耦合版本：分压电阻直接落地

现在麻烦来了。我们看到的是阻容耦合。如果把它换成**直接耦合**呢？

有人会说："反正你教过我，把电容短路掉不就行了？"——对，工程上麻烦就麻烦在这儿。阻容耦合版本在画直流通路时，耦合电容是断开的；直接耦合版本不能这么断开，画出来是"死定了"的：分压下电阻 $R_{b2}$ 会直接接地，等于和 $R_{b1}$ 并起来，整个偏置网络被短掉一截，电路根本不成型。

所以直接耦合版本的 $R_{b2}$ 就是老老实实从基极节点拉到地：

```text
                       +Vcc
                         │      │
                        Rb1     Rc
                         │      │
        ┌────────────────┤      │
        │                │      │
        │             ┌──┴───┐  │
        │             │  Q1  │  │
        ├─────────────┤B   C  ├─┴──Co──RL──GND
        │             └─┬─┬──┘
       Rb2          RE   │E
        │              │ │
        │             CE  │
        │              │ │
        └───────┬──────┴─┘
                │
               GND
```

读图：和前一图相比，只是 $R_{b2}$ 不再经过任何耦合环节，直接接到底；负载 $R_L$ 也在直流上接地（分析时若挂负载要注意这一点，嫌麻烦就当空载处理，简单一点）。

就这一点"讨厌"，带来了真正麻烦的分析过程。

### 求 $I_{EQ}$：戴维南定理 + 电位法

这个电路你再去求 $I_{EQ}$，倒还真是有难度。

"会不会求？你们的心理障碍在哪儿，我很清楚，都是过来人。"——别怕，它实际上很简单。表面上就三样东西：$U_{BEQ}$、$I_B$、$I_C$ 和 $U_{CE}$，没什么大不了的。**关键点只有一处**：$R_{b2}$ 的存在。要是没有 $R_{b2}$，这件事就太简单了；有也无所谓——

**做这个端口的等效。戴维南定理到哪都用啊。**

对基极这个端口向电路内部看等效：开路电压就是分压值，等效电阻是 $R_{b1}$ 并上 $R_{b2}$。

```text
   对基极端口作等效                       等效结果

        Vcc                                      Vcc'
         │                                         │
        Rb1                                       Rb'
         │                                         │
         ├──────────● B                            ├───● B
         │          │                              │
        Rb2         │                             GND
         │          │
        GND
```

所以 $R_{b1}$、$R_{b2}$ 这一坨，可以整体换成一个"$V_{CC}'$ 串 $R_b'$"：

$$V_{CC}' = V_{CC}\cdot\frac{R_{b2}}{R_{b1}+R_{b2}},\qquad R_b' = R_{b1}\parallel R_{b2}$$

电路马上恢复成熟悉的样子，后面的事情就变得很愉快：**电位分析法**。从电源正极出发，沿外电路绕一圈回到负极：

```text
   Vcc' ── Rb' ──● B ──(BE 结, UBEQ≈0.7V)──● E ── RE ── GND
        ▲                                             │
        └─────────────────────────────────────────────┘

   回路方程： Vcc' = IBQ·Rb' + UBEQ + IEQ·RE
```

$$V_{CC}' = I_{BQ}R_b' + U_{BEQ} + I_{EQ}R_E$$

注意 $R_b'$ 是 $R_{b1}\parallel R_{b2}$。$I_{EQ}$、$I_{BQ}$ 一解出来，$r_{be}$ 就出来了；$r_{be}$ 一出来，后面就是老一套。

> **提示**：这一段是整块内容里最需要动手的。电路基础的东西该复习还得复习——戴维南等效、电位法，这两件武器哪个电路都能用，趁这一讲再练一遍手。

### 交流通路与 $A_u$：$R_E$ 带来的两难

交流通路要画快，镜像翻下来就是了。$R_E$、$r_{be}$、$R_C$、$R_L$、受控源，该有的都有：

```text
              Ui                            Uo
               │                             │
     b ●───────┴────[ r_be ]────┬──────● e   │
                                │      │     │
                          ( ↑ β·Ib )   │     │
                                │      │     │
                                └──────● c ──┴──[ RC ∥ RL ]── GND
                                       │
                                      [ RE ]
                                       │
                                      GND
```

读图：受控电流源 $\beta I_b$ 从 $e$ 流向 $c$，把集电极电流从发射极"抽"上来。

输出那一端简单，$U_o = -\beta I_b(R_C\parallel R_L)$。

输入那一端可就有意思了。$U_i$ 是什么？还是电位分析法——就是这两点之间的**电位差**。怎么算？从某处升到某处，再从某处升到某处：

$$U_i = (1+\beta)I_b R_E + I_b r_{be}$$

上面那支路上的电流是什么？是 $(1+\beta)I_b$。于是

$$A_u=\frac{U_o}{U_i}=\frac{-\beta I_b (R_C\parallel R_L)}{I_b r_{be}+(1+\beta)I_b R_E}=\frac{-\beta (R_C\parallel R_L)}{r_{be}+(1+\beta)R_E}$$

写出来之后，好玩的地方来了——**一个矛盾横在面前**。

| | 对直流（稳 Q 点） | 对交流（要电压增益） |
|---|---|---|
| $R_E$ 大 | 杠杆长，$I_C$ 变一点点 $U_E$ 就啪地上去，稳得牢 | 分母 $(1+\beta)R_E$ 变大，增益掉下来 |
| $R_E$ 小 | 不灵敏，稳不住 | 增益大 |

数一数就明白有多难受：$R_C$ 一般都是 $3\text{k}$ 这个量级，再并一个 $R_L$ 只会比 $3\text{k}$ 更小；而 $R_E$ 想"实在点、好用点"，也得好几千欧。分子分母一摆，**比值小于 1**。这电压还放大什么？没法弄了。

"能提出问题，肯定就得有办法，要不然问题就开放式的了。"

在动手段之前，先拿它练手。$R_E$ 还在的情况下，输入电阻怎么算？$R_i = R_i' \parallel R_{b1}\parallel R_{b2}$，而 $R_i'$ 就是在这里放个 $U$、写个 $I$ 的关系：

$$R_i' = r_{be}+(1+\beta)R_E$$

**有失必有得**：输入电阻确实变大了——原来只有 $r_{be}$，现在成了 $r_{be}+(1+\beta)R_E$。但这个"得"我们并不想要。

### 消灭 $R_E$：并一个电容的巧劲，和集成的死结

口号很明确：**消灭 $R_E$**。

怎么消灭？想想电容是干什么的——**在交流的时候它相当于一根短路**。那么在 $R_E$ 两端并一个 $C_E$，会发生一个奇迹：

- 直流的时候：$R_E$ 还在，稳 Q 点的功能一点不损失；
- 交流的时候：$C_E$ 短路，$R_E$ 被彻底旁路，交流通路里它直接消失。

回到原电路图上，就是 $R_E$ 两端并了个 $C_E$。这样一来，画交流通路时电路**重新恢复成基本共射的样子**，矛盾一举瓦解。

> **结论**：阻容耦合有它的好处——直流靠 $R_E$，交流靠 $C_E$ 把 $R_E$ 短路掉，两套需求各得其所。

**但是**——这么大的好处，代价是什么？

代价是：**这个电路集成不了。** 一个这样的电路里就含有三个电容；一个集成电路里有多少个电路？成千万上亿个。集成完才那么大一个芯片，几千万个电容往哪儿放？芯片上鼓个包？鼓也鼓不过来，而且达不到所需的电容量。

所以：**要集成，只能直接耦合，电容全没有。**

于是问题又绕回来了：

> 如果用的是直接耦合，就**不许**加那个电容了。可我又必须保留 $R_E$。能不能设计出一种电路来，让 $R_E$ 在直流下顶用，在交流下自动消失？

答案当然有。我先把它的功能直接告诉你——因为答案我心里有数：

**直流情况下，$R_E$ 的功能被 double 了，加倍了。** 你放一个 $10\text{k}$ 的 $R_E$，它当 $20\text{k}$ 用。
**交流情况下，这个 $10\text{k}$ 的 $R_E$ 消失了**，而且谁也没给它加电容。

这种电路叫什么？叫**差分放大电路**。

第三章我们正式学它。静态的时候（直接耦合，$R_E$ 真拿不掉）$R_E$ 当两倍用；动态的时候等效出来 $R_E$ 就没有了。非常巧妙。

"我每次看到这个电路都觉得，思想非常值得学习、精妙。"——说句老实话，如果让我从无到有地去设计这样一个电路，我评估了一下自己，我觉得蛮难的。除非脑子里已经有了"差分"这个概念。而且现在脑子里概念多，设计点什么就容易得多，拎一个出来就能用。

**这里先留一个扣子。**

> **提示**：除了刚才讲的这些，还有别的 Q 点稳定电路。那些我不讲，你们回去自己看，看明白它。

### 基本共集电极放大电路

我们一路讲下来，其实在讲"基本共射放大电路"——所以才叫它**基本共射**：输入从 $b$ 取，输出从 $c$ 取，共用的是发射极。

现在我做一点点改动：**输出改从 $e$ 取。**

要从 $e$ 取输出，那 $e$ 上就必须带一个电阻 $R_E$，好在它天生就在。而且——**我根本不用去消灭 $R_E$**，因为它本身就是被我拿来用的。

这就叫**共集电极放大电路**：输入是 $b$，输出是 $e$，共用的是 $c$。

```text
                     Vcc
                      │        │
                     RB        RC
                      │        │
    ui ── C1 ────●────┤        │
                  │    │  Q1    │
                 GND  B       C├──────── GND
                      │        │
                      E        │
                      │        │
                     RE        │
                      │        │
   uo ────────────●───┤        │
                  │   │        │
                 RL   │        │
                  │   │        │
                 GND ─┴────────┘
```

读图：和共射相比，输出改从 $E$ 端经 $R_E$ 上取（$R_L$ 跨接在 $R_E$ 两端），集电极不再接负载，而是经 $R_C$ 接 $V_{CC}$——对交流来说它就是地。

静态我不重复了，拿过来分析动态。

#### 微变等效：先把图"拧一下"

难点在画交流通路。集电极在图上方，可它对交流来说是地；你要把它接地，那个"绳子没解套"的图形就死活接不上。

怎么解套？**把整个图拧一下**——这一端冲上去，集电极端就直接接地了，那个尖尖的部分接的正是 $R_E$。翻成这样之后，一切就都 OK 了。

> **易错点**：翻过来以后 $c$ 和 $e$ 的上下位置和共射不一样了，别奇怪。$b$–$e$ 之间是 $r_{be}$；$c$–$e$ 之间本来是 $r_{ce}$，我们照惯例忽略不画，受控源就长成那个向上的样子。

```text
              Ui                            Uo
               │                             │
     b ●───────┴────[ r_be ]────┬──────● e ──┴──[ RE ∥ RL ]── GND
                                │      │
                          ( ↑ β·Ib )   │
                                │      │
                                └──────● c ──── GND（交流接地）
```

读图：受控源 $\beta I_b$ 从 $e$ 流向 $c$；对交流而言 $c$ 就是地，所以它等价于从 $e$ 往地"抽"电流——电流全从 $R_E$（与 $R_L$ 并联后的等效）上过去了。

#### 电压增益：小于 1，趋向于 1

$A_u = U_o/U_i$。上面那一坨 $U_o$ 简单，就等于 $(1+\beta)I_b\cdot R_E$。

$U_i$ 呢？**千万别奇怪，$U_i$ 就是 $U_o$ 再加上一个电压**——也就是说它比 $U_o$ 还大一点点：

$$A_u=\frac{(1+\beta)I_b R_E}{(1+\beta)I_b R_E+I_b r_{be}}=\frac{(1+\beta)R_E}{(1+\beta)R_E+r_{be}}$$

算出来确实小于 1，但**趋向于 1**，实际算出来都是 0.98、0.99。为什么？因为 $(1+\beta)R_E$ 远远大于 $r_{be}$。

#### 放大的是功率，不是电压

有人要问了：这个电路是不是吃饱了撑的？放大半天，放大了半天，结果发现——**它没在放大**。不但没放大，还略微缩小一点。它干了件什么事呢？**跟随**。

我几乎跟你同相位，同大小。你怎么样我就怎么样，所以这个家伙又叫**射极输出器**，又叫**射极跟随器**。

可它真的没放大吗？还记得我给你们讲什么叫"放大"吗？**仅仅电压放大就是放大吗？放大是功率。**

它的电流从 $I_b$ 变成了 $I_e$——电流实实在在放大了，功率也就实在放大了。用那个比方来说：本来我是一个很微弱、很小的电功率信号，虽然我的电压没有变大，但实际上**我的身子骨变强了**，我的功率变大了。看着跟你长得一样，内在已经跟你不一样了。

**它有用。**

#### 输入电阻：把 $R_L$ 也算进来

$h$ 参数等效里那一大坨东西就是输入电阻。$R_L$ 已经画进去了，怎么求？

"千万别傻到这个程度从入口放端口电压，那明显可以跨过去。" 在这一处放 $R_i'$，然后

$$R_i = R_i' \parallel R_B$$

$R_i'$ 就是这一处放个 $U$、那个是 $I$ 的关系。$U$ 等于什么呢？

$$U = (1+\beta)I\cdot(R_E\parallel R_L) + I\cdot r_{be}$$

$$R_i' = r_{be}+(1+\beta)(R_E\parallel R_L)$$

这里有两件事值得停一下：

**第一**，$R_L$ 是 $R_i$ 的一部分。这不是想当然。写推导的时候我顺手就写了个 $R_E$，底下立刻有人喊："那个错啦，你那个！"——好，很好，**能挑出我讲错的地方，说明你在认真思考**。要是我讲错一点，底下异口同声地喊"错啦"，那我才要担心。改过来，$R_E$ 那边要并上 $R_L$。

**第二**，这个 $R_i$ 比基本共射放大电路大得多。基本共射那边光看 $R_i'$ 就只有 $r_{be}$。

> **结论**：$R_i = \bigl[r_{be}+(1+\beta)(R_E\parallel R_L)\bigr]\parallel R_B$。基本共射的输入电阻小，射极输出器的输入电阻大——所以**射极输出器可以放在第一级，去抢电压型信号源的信号**。共射接不了的场合，它可以接。

#### 输出电阻：从 $R_C$ 变成几十欧

算 $R_o$ 时先把独立源置零：$U_i$ 短路。这一短路，$r_{be}$ 短掉、受控源也短掉，$R_E$ 与 $R_L$ 并联的那一支则保留。放个 $U_i$ 求 $I$，就能得到

$$R_o' = \frac{r_{be}}{1+\beta}$$

道理很直白：如果我这里放进去的电流是 $I$，那么流过 $r_{be}$ 的电流就是 $I/(1+\beta)$。

> **易错点**：$R_o$ 里**永远不要把 $R_L$ 加进去**。$R_o$ 是站在 $R_L$ 那边往前面看的结果，你不能把自己也包含进去。

$$R_o=\frac{r_{be}}{1+\beta}\parallel R_E$$

现在做一下对比。基本共射的 $R_o$ 是谁？是 $R_C$——$3\text{k}$、几 $\text{k}$ 的量。而这里，你们都求过 $r_{be}$，做过题的话它大概 $1\text{k}$ 上下，配一个几十倍的 $\beta$，$r_{be}/(1+\beta)$ 就变成**几十欧**。

这是个非常小的输出电阻，也就是说**它输出电压的稳定性将非常好**。

| | 基本共射 | 共集（射极输出器） |
|---|---|---|
| 输出取自 | 集电极 $c$ | 发射极 $e$ |
| $A_u$ | 负值，$\left|\cdot\right|$ 通常远大于 1 | 正值，小于 1 但非常接近 1 |
| $R_i$ | 小（$R_i'$ 就是 $r_{be}$ 量级） | 大，$R_i' = r_{be}+(1+\beta)(R_E\parallel R_L)$ |
| $R_o$ | $R_C$，几 $\text{k}\Omega$ | $\frac{r_{be}}{1+\beta}\parallel R_E$，几十 $\Omega$ |

到此你可以看明白了：**射极输出器极其有用**。它放大了功率，加大了输入电阻，减小了输出电阻——这是一个非常关键的电路。

至于**基本共基**到底是个什么样子，用我教你的这套方法，一样去分析就行。

## 共基放大电路与场效应管放大电路的构成原则
> 对应块：BLK16 | 覆盖分集：P16 | 块标题（分集名）：《16-基本共基放大电路与场效应管放大电路的构成原》

### 背下来的电路是死的，原则才是活的

刚才上课前和几位同学聊了聊，得到的信息是：单管放大电路这块，大家基本都能处理。画出直流通路、求解静态工作点，这两步都能做；交流通路也能画出来。但一问到"画成简化 h 参数等效电路"这一步，痕迹就明显了——是背的痕迹。好比说共射放大电路啪一下就画成那个样子，射极输出器啪一下就画成那个样子，习惯性地就背过来了。

我不希望你们是这样的。

我希望的是什么呢？你拿到一个电路，画出交流通路之后，只需要把三极管用简化 h 参数模型（也就是微变等效模型）替换掉，其他的电路部分不动，这样得到的就是简化 h 参数等效电路。

为什么呢？因为一旦你这样做，电路本身怎么变你都不怕。背一个电路，那个电路是死的，是死的，知道吧？但是要掌握一个原则，原则是通用的。你只要把这个放大电路做出交流通路，把交流通路里的三极管用它的微变等效模型、简化 h 参数模型一取代掉，这个电路马上变成一个线性电路，你就可以求解了，再去求 $A_u$、$R_i$、$R_o$。任何电路、任何含有三极管的电路，只要还在小信号、低频小信号模型下，你都可以用这个方法去分析、去解决。

我一直希望同学们掌握的是一个原则。其实很多东西，这个原则都非常重要。我们回想以前解决的所谓复杂问题，最终都可以还原成一种、或者分解成一些原则的组合。

这也是金庸武侠小说的意思：最后什么叫无招胜有招？有招，就是你有形的东西——背一个电路、背一个电路，这叫有招，一说到这个电路咱们就背下来了。但是当你掌握的是这个原则、是这种电路组成的原则或者解决的原则的时候，你不再需要任何招式了，看到什么东西，你都可以根据脑子里的这些原则把它解决开。他练的也就是练一些基本原则。

这是我要强调的这部分。

> **结论**：一套分析流程（画交流通路 → 用微变等效模型替换非线性器件 → 线性求解）之所以值得掌握，是因为它通用；而某个具体电路的长相不通用。所以先把流程变成肌肉记忆，电路只是流程的一次应用。

顺便再问一句：为什么我们要先求静态、再求动态？这句话我会不断一直重复下去，这是我们分析电路的基本原则。

有了这些原则，实际上这节课的很多部分我应该是一带而过的。

### 为什么叫共射、共集、共基

到目前为止，我们学了基本上两种类型的放大电路，都是从组合开始做的、从设计开始做的。一个是共射放大电路，从基本共射放大电路到静态工作点稳定的共射放大电路，一步步给它推过来的；在这个基础上我们又学了基本共集电极放大电路，也就是射极输出器。现在有了共射的、共集电极的，那肯定还有一个共基极。

什么是共射？为什么把那个叫共射？大家看，这是一个共射放大电路，对不对？我把 $R_e$ 用个 $C_e$ 给它旁路掉，这样让它在交流的时候可以获取比较大的放大倍数。之所以叫它共射放大电路：我的输入信号是从基极进的，我输出从集电极出，所以它们共用的是发射极。

那共集电极放大电路呢？它输出不从这了，输出从这出来。输入还是在基极，输出在发射极，所以共用的是集电极——它有一个没用到的。

还有一个：交流通路里，输入从发射极进去，输出从集电极出来，共用的是基极。

你们发现一个特点没有？这个输入信号不是在基极就是在发射极，输入信号不会从集电极进去。

为什么？这和我们整个放大的原理是相关的。怎么放大的？是外界信号的变化引起了 $u_{be}$ 的变化，$u_{be}$ 变化引起 $i_b$ 变化，$i_b$ 变化引起 $i_c$ 变化，$i_c$ 然后出去。如果你从集电极上来的话，没戏。只有从发射极和基极进去，b 或者 e 的变化能引起 $u_{be}$ 的变化，才会使得这个 PN 结这块的电压发生变化，信号才能按照这样一个流程被放大。

这就是为什么我们把信号这样加。所以你们脑子里很清楚了：共射应该基极进、集电极出；共集电极基极进、发射极出；共基呢，因为已经共基了，你不可能从基极进，那发射极进、集电极出。

### 基本共基放大电路的组成

我就以这个为例，再跟大家讲一下。在这个 PPT 的原图上，这就是我们基本共基放大电路的图形。

```text
                   V_BB                        V_CC
                    |                           |
                    |                        R_c |
                    |                           |
       +------------+-----------+       +-------+------+
       |            |           |       |       |      |
       |            b           c       |       |    C_2
       |       +----+----+      +-------+       |      |
       |       |   NPN   |      |               |      |
       |       +----+----+      |              R_L     |
       |            e           |               |      |
      R_e            |           |               |      |
       |            |           |               |      |
      C_1            |           |               |      |
       |            |           |               |      |
  u_i--+------------+-----------+---------------+------+-- GND
```

大家可以看到，$V_{BB}$ 给了输入回路一个好的静态工作点，让它导通；$V_{CC}$ 的作用同样会使得我的集电结反偏。一个正偏、一个反偏，这是我们正常要求的放大。你看组成原则是不是一样的？还记得我给你们推基本共射放大电路的时候，我是把一个三极管放在那一步一步把放大电路给它弄出来的，上来的原则就让这个三极管发射结是正偏的、集电结是反偏的。所以你看你组成共基的时候也是同样的道理。

但是这个共基放大电路看起来很有意思，其实我们可以预计一点。这个电路会不会放大电流？输入电流是什么？是 $I_e$。输出电流是什么？是 $I_c$。它不会放大电流，很清楚——电流几乎是不变的。

但是这个电路会放大什么呢？我们就可以分析一下。

### 从交流通路到简化 h 参数等效电路

交流通路的画法无须我再说了，直流源统统置零。这个交流通路任何一位同学都可以画出来。然后我们来看由交流通路变成简化 h 参数电路。

所谓简化 h 参数电路，实际上是在小信号、在低频小信号作用下，三极管等效成一个什么东西。从等效的原则上说：如果是一个低频小信号，把这个三极管放在一个盒子里，它应该和这样东西等效。

```text
            +----------+
      b  +--|   r_be   |--+  e
            |          |
      c  +--|  β·I_b   |--+  e
            |  ↓ 电流  |      (受控源在 c-e 之间，方向 c -> e)
            +----------+
```

$b$ 到 $e$ 之间连的是那个电阻 $r_{be}$；这是 $\beta$ 倍的 $I_b$，这是个流控电流源。

注意，$r_{be}$ 这个参数是和直流静态相关的。静态工作点不同，$r_{be}$ 不一样。这也是为什么我们要先求静态的一个原因——静态会影响动态。

> **为什么要等效成线性元件**：三极管本身是个非线性的东西，但是低频小信号的时候，信号很小，工作在特性曲线上一小段，这一小段曲线可以折线化，近似为一个直线。在这种条件下，我们就可以用线性元件把它等效出来，这样整个电路就可以用线性电路的方法来求解。用线性元件去取代非线性元件，有利于我们电路的分析。

一旦取代下来，事情就很简单了。从端口上来讲，我把它擦掉。$b$ 和 $e$ 之间连的是那个电阻 $r_{be}$；$c$ 和 $e$ 之间连一个 $\beta$ 倍 $I_b$ 的流控电流源。

这里我要特别提醒一下——你们有可能真的做的时候会出现这种错误：习惯了一串一串，$b$-$e$ 连完顺手就往下画，根本不看。看到吗？还有谁和谁连？$c$ 和 $e$。一般原则，我刚才自己都差点这么画一笔。

> **易错点**：口诀不能替代判断。$r_{be}$ 在 $b$-$e$ 之间、受控电流源在 $c$-$e$ 之间，这两件事要每次都重新看一眼端口标号，而不是顺着上一笔的惯性往下画。

电流源的方向要看好。我从 $b$ 指向 $e$，那这个电流源就是从 $c$ 指向 $e$；我也可以反过来画，道理是一样的——只要表明的是一种方向之间的逻辑关系就可以了，看清楚，方向要跟着变。

你们回去可以试一下画 PNP 的电路。你会发现 PNP 和 NPN 在直流通路上是不一样的，直流通路上正负不一样；但是当把它们都画成简化 h 参数等效电路之后，你会发现它们是一样的。为什么？因为这个模型是一模一样的。不管你用的是 NPN 管子还是 PNP 管子，画到简化 h 参数这一层，它们一定一样。

把这个电路稍事整理一下：这里是 $r_{be}$，这里是 $I_b$，那么这个是什么？是 $I_e$——就得到了这个等效电路。

```text
   输入回路 (I_b，I_e = (1+β)I_b)        输出回路
     +------ r_be ------+          +---- R_c ∥ R_L ----+
     |                  |          |                    |
  b  *                  |       +--+---+  β·I_b ↓       |
     |               (1+β)I_b ↓    |   c |-------+       |
  e  *-------------+-----+---+      +---+---+       |       |
     |             |     e|                   |       |
    R_e            |      |                  R_L      |
     |             |      |                   |       |
     |             |      |                   |       |
  u_i+------------- +------+-------------------+-------+
                                                             GND
```

下面的工作就是求解它了。整个求解过程完全——这个电路整个描述出来是什么？是一个**含有受控电源的线性电路**。

而且这个电路可爱到什么程度：虽然画的是交流通路，里面却没有任何容抗和感抗。没让你们分析高频，没有电容、没有电感，换句话说相位几乎没有什么变化。虽然我们在复数域求解，但实际上用的还是实数域。所以这是最简单的交流电路——电阻形式的交流电路。

### 电压放大倍数：$R_e$ 越小越像共射

$A_u$ 我相信很多同学现在都会了，用参数方程的形式。$U_o$ 等于什么？很好，$\beta$ 倍的 $I_b$ 乘以 $R_c$；如果接负载的话就 $R_c \parallel R_l$。我这块再接一个负载，让它更完整一点，就是 $R_c \parallel R_l$。

然后 $U_i$ 等于什么？用电位分析法，一部分加另一部分：$I_b r_{be}$ 加上 $I_e R_e$，其中 $I_e$ 是 $(1+\beta) I_b$。

$$
U_o = \beta I_b (R_c \parallel R_l)
$$

$$
U_i = I_b r_{be} + (1+\beta) I_b R_e = I_b\big[r_{be} + (1+\beta) R_e\big]
$$

一消掉，同学们可以看到，如果这个时候注意，$R_e$ 比较大的话，这个电路真的是一无是处。$R_e$ 如果比较大，大到和 $R_c$ 相媲美，那这个电路很值得讨论了：什么？第一，电流没放大；第二，电压也没放大。当然它还有其他好处，等下说。

所以一般来看，在这种电路里 $R_e$ 是非常小的，其实几乎就是我们信号源的内阻——它是一个非常小的值。因此这个放大倍数在这样算下来的时候，就有点近似于共射：

$$
A_u=\frac{\beta (R_c \parallel R_l)}{r_{be}+(1+\beta) R_e}\;\approx\;\frac{\beta (R_c \parallel R_l)}{r_{be}}
$$

如果 $R_e$ 趋向于零，不就是我们共射的那种形式吗？所以在做共基放大电路的时候，这个 $R_e$ 电阻我们要做得小一些。

> **对比**：共基不放大电流（$I_e$ 进、$I_c$ 出），但只要 $R_e$ 足够小，它的电压增益就能和共射相当。所以共基的胜负手在发射极电阻上——做大了，电压增益也跟着塌下来。

### 通频带：共基藏起来的优势

它最好的一个特性我们在这儿还真没法展开，到第五章的时候我们就看到：它有非常好的频率特性。

大家还记得通频带的概念吧？因为我们三极管里面有这种极间的电容，当频率高的时候，它放大倍数就下去了。

我还要跟同学们讲：我们要做功放的话，通频带得定在哪儿——你想做什么频率的，通频带就得定在哪。一般老说，你要想通用的放大，除非你有选择性，否则通频带越宽越好；通频带越宽，应用范围越宽。

它（共用基）的通频带的宽度是共射和射极输出器的 $1+\beta$ 倍，宽度可以放大近 $\beta$ 倍。至于为什么，我留这么一个问题，到第五章我们就可以看到。现在告诉你们一个结论。

### 输入电阻与输出电阻：看的是哪个端口

我相信非常多的同学，绝绝大部分同学，$A_u$ 这部分一点问题没有。但是对哪儿有问题呢？求 $R_i$、$R_o$。

$R_o$ 是从这儿看进去的，还是从那儿看进去的？是从这里看的叫 $R_o$。第二个，非常好。

为什么这块看进去是 $R_o$？因为 $R_o$ 相当于把前端放大电路做戴维南等效，等效的戴维南内阻。这时候你如果把 $R_L$ 也放进去的话，谁是负载？前端既然等效为电源，后面有个负载，你把 $R_L$ 都弄进去了，谁当负载？没负载了。所以你之所以求 $R_o$，是要看前面的内阻是什么。

而对于 $R_i$ 来讲，它是从这儿看进去的，是后端整个放大电路的等效电阻。

这种等效电阻的求法非常明确，因为它是含有受控源的。所以在戴维南等效当中我们用什么样的方法来求呢？端口加电压和电流。端口加一个 $U$、一块一个 $I$，求出 $U$、$I$ 的关系，就是 $R_i$。一定要非常熟练。

> **为什么必须是这个方法**：我把这个电阻封在箱子里，它肯定是个电阻。如果这里是个 $U$、这块是个 $I$，那么这家伙的阻值自然就等于 $\frac{U}{I}$。因此一般来看我当然不会去算 $\frac{U}{I}$；我能够推出来的是什么呢？用 $I$ 表示出 $U$ 来——$I$ 乘以一个什么玩意儿最后等于 $U$，括号里的东西就是 $R$。

无论输入电阻、输出电阻都是一回事，都是在端口，只不过端口不同。大家注意，我们在算戴维南定理的时候，对相同的电路，从不同的端口看进去，它的等效是不一样的：从不同的地方看进去是不一样的，从不同的地方做等效都是不一样的。所以这就是为什么输入电阻是从输入端口进去的，它是一个值；输出电阻是从输出端口看进去的，它是另外一个值，不一样。

#### 电流等效：看电流倍数就知道电阻被"升"还是被"降"

你们以后用熟练了，我跟你讲最后到什么程度？看它的电路都不用看交流通路什么乱七八糟，看着那个电路你就知道它输入电阻是什么了。因为啥？这就是一个电流等效的概念：入端的电流如果是 $I$，后面的电流如果出现 $\beta I$，这个电阻就被"升"了 $\beta$ 倍；如果后面的电流变成了 $\frac{1}{\beta} I$，这个电阻就被"降"了 $\beta$ 倍。它等效出来就是这么回事，完全按电压等效的。

所以从这儿来看：入端电流是 $I$，那么流过 $r_{be}$ 的电流就是 $\frac{1}{1+\beta} I$，受控源那边的电流是 $\frac{\beta}{1+\beta} I$，两者合成的正是 $I$。加上 $R_e$ 上的压降：

$$
U = I \times R_e + \frac{I}{1+\beta} \times r_{be}
$$

$$
R_i = R_e + \frac{1}{1+\beta} r_{be}
$$

可以看到这家伙的输入电阻很小。我们原来那个 $r_{be}$ 大约是 $1\ \text{k}\Omega$ 左右的一个值，被减小到几十欧姆，$R_e$ 本身又小，所以它输入电阻比较小——这是它的特点。

#### 求 $R_o$：先别急着说受控源为零

射极输出器的 $R_o$ 应该没什么问题。对于这种电路，很多同学我估计在 $r_o$ 的求解上是有困难的，看到这块有这么一个东西就发懵。

求 $R_o$ 的时候它应该怎么样？短接。$R_l$ 短接。

然后这里一旦短接的时候，同学们注意：我现在没法说这家伙是不是零。我根本没法去说它是不是零。你能马上说、能肯定这块是零吗？你不能肯定这是零，因为这个电源存在。

这就像静态工作点稳定放大电路，$R_e$ 电阻如果没有置零的话，它就会等效出类似于这样的一个电路。这个时刻，它中间有关联。

那你就得推它到底是不是零。到底是不是零？能不能推？就这个电路到底是不是零？

我问同学们，如果它不是零，就代表谁不是零？就是 $I_b$ 肯定不是零。我问你们，$I_b$ 可能不是零吗？来看这个回路——这是个回路吧？由这个回路我会得到什么？KVL 很清楚，我马上就可以得到：

$$
I_b \cdot r_{be} + (1+\beta) I_b \cdot R_e = 0 \;\Longrightarrow\; I_b = 0
$$

所以在这里 $I_b = 0$，那么受控电流源就是 0。看到吗，这里很清楚，它变成 0。它是 0 的话，$R_o$ 就是什么？

$$
R_o = R_c
$$

如果这部分还是不清楚，你们真的要回基电，再把基本电路理论的这部分知识稍微复习一下。

### 举一反三：MOS 管也有三种电路

共射、共集电极、共基都看到了。我不只希望你们看到，我希望你们做到什么？举一反三。

你们现在知道了共射放大电路怎么构成的，共集电极怎么构成，共基怎么构成——这是我们晶体三极管。我们还有一种管子，场效应管，MOS 管。

MOS 管同样我们来推理，它一定也有三种电路。共射的对偶啊，特别像我们数电里的对偶——数电和基电里都有。这是一个很相通的一个道理。

> **对偶规则你们没学过？** 数电里，一个等式相等，它的对偶式也相等。白学了，上学期学的。你们学了反演规则也不知道？就是把那个"非"、大"非"打开——$\overline{A \cdot B} = \overline{A} + \overline{B}$，这叫反演。当时我们学数电的时候，这边一堆规则、那边一堆规则，什么 1、0 规则呀，那些乱七八糟的东西，你会发现你学了比如说 20 个等式，实际上只需要知道其中的 10 个。因为另外 10 个是这 10 个的对偶式、对偶等式，你只要用对偶规则啪一翻它，学一个就当两个。这是相通性。

所以你们学东西的时候，我不知道你们在学什么——我特别希望你们学到本质的东西，学到一些通用性的原则。这种通用性的原则在以后你在科学研究或者工作的时候，会实际指导你，让你做事情事半功倍。你知道这个东西存在，必然有存在的另外一个东西。

就如同数学我们怎么用一样。冥王星、海王星，它的发现是数学推出来的：根据这个万有引力什么哗哗哗数学一计算，发现这轨道不对，旁边一定有个东西，然后后来发现，而且在那个点上都推出那个点。数学的妙用，很多规律都是在这个数学的规矩之中。

那一样的道理，我们现在晶体三极管这么用，MOS 管就可以这么用。所以这边有共射，那边就有什么？共源。源极和射极是什么呢？是差不多一样的东西——源极是载流子的源泉，射极也是载流子的源泉。当然了，对于 MOS 管来讲，它如果中间的衬底没接的话，D 和 S 是可以换的。

它有共源。对应我们的射极输出器，它有源极输出器，也就是共漏放大电路。同样它还有共栅放大电路，肯定有。

### 场效应管放大电路的构成原则

它的构成原则是什么？也要让那个场效应管工作在放大状态。场效应管的放大状态是什么？恒流。非常好，恒流。

所以我说的概念什么意思？我把三个晶体管电路分析得如此之详细，那场效应管的放大电路你们能不能自己构成、自己分析？它的分析思路该是什么？

首先一点，我把一个场效应管拎过来的话，我要让它构成放大电路，我得怎么样？得让它工作在恒流区。不同的电路、不同的管子，保证它工作在恒流区，我的手段是不一样的。

- **增强型 MOS 管**：我的手段是给它加一个偏置，让它导通。$U_{GS}$ 要大于开启电压 $U_{GS(th)}$——光大于开启电压不行吧？还得加一个大的 $U_{DS}$ 梆上去，才能让它进入恒流区。一个让它导通，一个让它恒流，这是它两大条件。
- **耗尽型场效应管**：你不用操心它的导通问题了，你只需要加一个大的 $U_{DS}$。
- **结型场效应管**：你也不用操心它的导通问题，但是你要操心一个问题——N 沟道的要让它工作在 $U_{GS} < 0$ 的区域。千万别让它到大于 0，一旦大于 0，PN 结就导通了。

> **易错点**：N 沟道结型场效应管的 $U_{GS}$ 必须为负。一旦 $U_{GS} > 0$，栅源之间的 PN 结正向导通，器件就不再工作在可控的恒流区，$I_D$ 对 $U_{GS}$ 的控制关系彻底失效。

说明结型管在你们脑子里面的印象非常非常浅，这也是让我非常失望的地方。为什么呢？结型管我的确没仔细给你们讲。你们完全如果依靠我这样讲的话，我就开始怀疑我讲课的态度。

我讲课为什么把一个东西讲得特别细？因为特别细之后，我希望你去推、去看懂其他的——通过一个来看懂其他。因为我们的确没有很好的配套的其他措施，能让你们把所有的东西都弄得非常非常懂。我可以上课的时候很开心，把所有的点点一遍，然后你们自己回去看，再给你配上非常好的导师——那种不可能。所以只能靠我这样给你们讲。

但是我留给你们自己看的那个东西，我是真希望你们去把它弄懂的。不是说那个不重要，而是：因为我给你们讲了 MOS 管，MOS 管的工作原理可以反推到那面去，反推到 JFET 上、结型管。你们肯定能看懂结型管。

所以对于结型场效应管来说，我除了关注加大的 $U_{DS}$ 之外，很关注一点：就是我如何保护我的 $U_{GS}$，特别是 N 型的，不让它到正区。

这些原则，就构成了我们这个放大电路的基本的组成原则。

### 从 $r_{be}$ 到 $g_m$

有了这个组成原则之外，你们马上脑子里就会知道一点什么呢？我基于的是 $U_{GS}$ 对 $I_D$ 的控制——转移特性，$U_{GS}$ 对 $I_D$ 的控制。我 $U_{GS}$ 变化引起 $I_D$ 的变化，$I_D$ 的变化然后输出出去。

所以你的输入点一定会使 $U_{GS}$ 变化，然后变成 $I_D$ 变化，然后出去。

那么同样的道理：我的静态点落在转移特性的不同地方，在那个曲线的不同的地方，我 $U_{GS}$ 和 $I_D$ 之间的关系就不一样。

> **这一点跟 $r_{be}$ 的道理很像**。静态工作点不同，$r_{be}$ 不一样，所以在共射电路里我们必须先求静态。场效应管里一模一样，只是不叫 $r_{be}$ 了，它叫 $g_m$。

所以你会导出一个 $g_m$ 的参数模型。这个 $g_m$ 值和我的静态值相关，然后这个 $g_m$ 的参数模型就可以把我那个放大电路线性化，然后你们去求解。

这就是整个的场效应管放大电路的构成、分析及等效方式。

### 复合管：让一对互补管在输出端变成同一种

#### 一对管子的难题：NPN 和 PNP 配不出对子

为什么有复合管？其实你们要玩过一点东西的话，这个问题就容易回答。

刚才上课之前我和王老师在交流，他问我这节课是不是可以讲到差放。差放他也玩过，搭这个电路也玩过——只要做功放，用差放的电路，效果比较好。但一个困难点是什么呢？找对管特别难。

差放在分立元件的时候，真正把它用起来很难；而在集成元件里对管非常容易做，因为在同样的环境里"啪"一下就做出来了，性能一样。但你真的去找两个分立的三极管，让它们特性一样，很难。

> **易错点**：分立器件靠"挑"，集成器件靠"造"。同一片硅片上挨着做出来的两个管子，温度、掺杂、工艺全都一致，所以天然配对；分立元件是从一整批料里挑两个最接近的，天生就差一截。

后面我马上会给你们讲功率输出的管子。功率输出管子里面，它要求后面有一对管来输出：一个 NPN 的，一个 PNP 的。这两个管子怎么连上？它输出。而且它要求是——这个 NPN 和 PNP 的管子特性基本相同。

小功率的时候，这件事还好办，还真能找到差不多相同的 NPN 和 PNP。可它俩结构不一样，NPN 和 PNP 明显它里面内部结构就不一样，你让它特性相同，其实是蛮难的一件事。小功率的时候还容易，到大功率太难了，你找这样一对管子太难了。

那么什么能找到一样的呢？俩都是 NPN 的。功率大的时候，两个都是 NPN 的还能找到极其相近的大功率管。

所以我做功放、推到对管的时候，注意啊，我有两个很无理的要求：

第一个要求，我要求这两个管子必须**一个是 NPN，一个是 PNP**。听懂了吧？让你做这两个管。第二个要求，这个 NPN 和 PNP，实际上从输出端我来看的话，**我还希望它俩是一样的，就都是 NPN**。

没听明白？肯定没听明白。我的需求是什么呢？一个是 NPN，一个是 PNP，对不对？这两点，两个管子特性近似一致，对吧？但是我告诉你们，当大功率的时候，特性近似一致，这两个管子几乎不可能一个是 NPN、一个 PNP。这两个管子只能都是 PNP 或者都是 NPN。矛盾就出来了吧？

于是问题就变成了：**我有没有一种办法，让这个管子整个看上去一个是 NPN、一个 PNP，但是从它的输出端那边一看，两个都是 NPN？**

这就提到了复合管。复合管它可以干这件事。

复合管还有别的很多好处：可以把功率做得更大、放大倍数做得更大，因为整个放大倍数是两个管子电流放大倍数的乘积。

看这个管子是怎么复合的：一个 NPN 叠上一个 NPN；一个 PNP 叠上一个 PNP；还有一个是一个 PNP 叠上一个 NPN。他们每个都画一个那个玩意儿，这是什么意思啊？它可以等效为它。看到奇迹了吗？它可以等效为它。

#### 构成原则：通路要走通，前面那个管子说了算

为什么能等效成 NPN 管？这很明显，这个跟 NPN 的基极是一样的，对不对？这是我们的发射极，一样这样打通，只不过打通两个发射结，两个发射结这样一样是正偏的；集电极这样过来。所以它等效为这样一个情况。

而另外一个电路，第一级是什么？PNP，对不对？你看，一做 PNP 的时候，它用这里的集电极给下面供电了，对不对？

所以这里就透出一个复合管的**组成原则：一定要有合理的电流路径**。

如果你胆敢把这个东西连接成这个样子——第一个是 NPN，你看我也发射极这么连嘛——这管子能工作吗？它要求电流往这流，对不对？你要想把整个打通的话，向上的通路你要把它干掉，向下的通路你也要把它干掉，对不对？

所以你要有合理的电流路径。这个是不是提供了合理的电流路径？一旦这么提供，我这个管子真的要工作的话，从外围来看，那我怎么工作？我首先把这个 PN 结打通。所以从这块如果我们来看等效来说的话，这相当于一个 PN 结打通到基极，跟这边是这样等效的。然后这个还是集电极，集电极出去，然后这个电流加大。所以这里整个反映的还是一个集电极。因此这个等效出来是一个什么东西啊？从整个管子的使用上来说，它要把这个正向打通来使用，因此它是 NPN。

我为什么直接这块能写成 $g_m u_{gs}$？我没写 $r_{ds}$。我没写 $r_{ds}$，其实我在忽略什么东西？我就认为在恒流区的时候，对不对？实际上我在认为什么？在恒流区的时候，我那根线是平的、水平的。也就是说，对于相同的 $U_{GS}$，我的 $I_D$ 是不变的，是基于这样一个假设，知道吧？

但是现实情况是什么？现实它是这根线怎么样？有倾斜度的。看到吗？这个倾斜度用什么表示出来？$r_{ds}$。

但是同学们可以看到，这个倾斜度怎么样？很小。也就是说，我们的 $r_{ds}$ 怎么样？我们的 $r_{ds}$ 很大。倾斜度很小，我们的 $r_{ds}$ 很大，所以往往这个 $r_{ds}$ 我们就忽略，在做这个等效的时候。

但是当我后面负载 $R_L$ 大到几十 k 到上百 k 的时候，$r_{ds}$ 又重新提出这个东西，因为跟它的量级相同了。

所以在这里面的话，我们的模型如果是简化模型的话，低频小信号的简化模型的话，就是中间这部分。

### 从静态到动态的完整分析流程

这样一来，我整个电路的分析方式还是什么？分析方式是什么？**静态。**

第一步，静态求出 $I_D$ 来，看到吗？我静态求出 $I_{DQ}$。怎么求啊？场效应管有个好处：$I_D$ 和 $U_{GS}$ 之间那个转移特性有个方程。

对于耗尽型场效应管以及结型场效应管来说，负半轴那部分以 $I_{DSS}$ 为界限：

$$I_D = I_{DSS}\left(\frac{U_{GS}}{U_{GS(off)}} - 1\right)^2$$

而对于增强型的场效应管，这块有个 $I_{D0}$——它怎么定义的？这底下是两倍的 $U_{GS(th)}$。它的方程就变成什么呢？方程一样，就是：

$$I_D = I_{D0}\left(\frac{U_{GS}}{U_{GS(th)}} - 1\right)^2$$

所以这两个方程，根据这两个方程再根据你的电路，你就可以推出 $I_D$ 等于多少。因为 $U_{GS(th)}$ 或者 $U_{GS(off)}$ 都会告诉大家，就可以推出来。

第二步，$I_D$ 一旦出来，$g_m$ 就出来了。$g_m$ 不就是把那个方程求导吗？刚才我念叨的那个方程求导，对不对？那个方程求导，然后出来，把 $g_m$ 求出来。

第三步，开做它的交流通路。做出交流通路之后，把这个东西用什么取代掉？用那个模型取代掉，对不对？你就可以求 $A_u$、$R_i$、$R_o$ 了。就这个过程。
