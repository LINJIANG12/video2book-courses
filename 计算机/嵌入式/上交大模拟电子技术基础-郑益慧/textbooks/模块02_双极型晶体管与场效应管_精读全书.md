## 三极管的结构与放大原理：小电流凭什么能牵动大电流
> 对应块：BLK06 | 覆盖分集：P06 | 块标题（分集名）：《06-双极晶体管的结构与放大原理_4K》

上节课留的作业还挂着：稳压二极管的参数，还有发光二极管，这两块请自己阅读，今天不再重复。

不过有一件事得先说清楚——**二极管只是我们半导体器件"开张"的第一篇**。实际上人们一直在孜孜不倦地追求一点什么呢？**用半导体材料去代替电子管**。

那电子管靠什么被"代替"？靠它能**放大**的那个作用。所以真正把这个作用顶上来、扛下来的，是**双极型晶体管**。

> **结论**：半导体器件走到双极型晶体管这一步，才算真正解决了"放大"这个悬在半空的问题。

它的名字里藏了两条信息，都要抓住：

- **"双极"**（Bipolar）——这种晶体管里面的导电离子有**两种极性**，空穴和自由电子**都参与导电**，所以叫双极晶体管；
- **"三极管"**——它有三个电极引出来，所以我们平常叫它半导体三极管，简称三极管。

BJT 就是 Bipolar Junction Transistor。下面我们就顺着这个顺序来：先看它长什么样，再说它到底是怎么把电流放大的。

### 三层三明治：从结构到符号

#### 三个区域，各干各的活

先看外形——"三极管"这个名字真不是白来的，外壳上三个电极明明白白摆在那儿：一个、两个，还有底下那个大平面，三个。

一般来说，它的形式是：**在一块硅片上，也就是半导体基材上，做出三个不同的掺杂区域**。原理图看过去就非常清楚了：

```text
     发射区           基区              集电区
   ┌──────────┐     ┌────────┐      ┌────────────┐
   │   N 型    │     │  P 型  │      │    N 型    │
   │ 掺杂最高 │     │  极薄  │      │  面积最大  │
   └────┬─────┘     └───┬────┘      └──────┬─────┘
        │               │                  │
        ╎  发射结       ╎  集电结          ╎
        │               │                  │
   ─────┴───────────────┴──────────────────┴──────
     E                B                    C
```

读图：一层 N、一层 P、再一层 N 的**夹心"三明治"**。因为是 N、P、N 交界面，所以**在两个交界面处必然各形成一个 PN 结**——P 和 N 放在一起它就成 PN 结嘛，自然就是两个。

三个区域形成之后，名字就好起了：

| 区域 | 引出的电极 | 字母 | 名字来源 | 本职工作 |
| --- | --- | --- | --- | --- |
| 发射区 | 发射极 | E | emit，发射 | **发射**载流子 |
| 基区 | 基极 | B | base，基 | **控制** |
| 集电区 | 集电极 | C | collect，收集 | **收集**载流子 |

> **提示**：光看这张示意图，你一定会冒出一个疑问——**凭什么叫发射区、凭什么叫集电区？倒过来用不一样吗？那个东西仿佛是对称的。** 可实际上，发射区和集电区在功能上是**截然不同**的：发射区是载流子的"**弹药库和源泉**"，它往外发；集电区干的活是收集；基区则是一个**控制区域**。

正因为分工不同，**三个区域在工艺上的做法也完全不一样**：

- **发射区掺杂浓度是所有区域当中最高的**。它要往外发射载流子，那它就得有丰富的载流子供它发射；
- **集电区不能掺杂浓度过高，但面积要大**。你可以想象：你把一个仓库弄出来，然后说我要往里装东西，结果第一你面积小，第二你把里面塞满了东西——它还能收集东西吗？不能。所以要**面积大，而且里面近似于空**；
- **基区掺杂浓度低，而且非常薄**。为什么要做得这么薄？等一下讲到载流子在管子里怎么走，你们就明白了——**它宽了，载流子就过不来了**。

#### 在一块硅片上怎么造出来

芯片剖面图画的就是这么回事。注意它**没按比例**画——真按比例来画，中间那层就细得看不见了：

```text
      ①  整块硅片掺杂成 N 型区
   ┌──────────────────────────────────┐
   │           N 型衬区               │
   │  ┌────────────────────────────┐  │
   │  │     P 型基区（很薄）       │  │
   │  │  ┌──────────────────────┐  │  │
   │  │  │ 高浓度 N 型发射区     │  │  │
   └──┴──┴──────────────────────┴──┴──┘
      ②  上面敷硼，把这一块做成 P 型
                    ③  再做一层高浓度磷
```

所以尺寸上，发射区和基区是**几微米**量级，集电区是**几百微米**量级，差着两个数量级还多；掺杂浓度上，上面那个小的 N（发射区）比下面那个大的 N（集电区）**高得多**。

谁小谁大，一目了然：**上面那个小的 N 就是发射区**，连出发射极，它来发射载流子；底下那个大的是收集用的；中间那一层就是基区。

#### 三个极、两个结，以及符号怎么读

三个区域、三种掺杂，自然引出三根电极：**发射极 E、基极 B、集电极 C**。

有了三区，就有了两结。这两结的命名规则有点意思——**从来不用"基区"的名字，因为两个结里都有基区参与**。那到底怎么命名？看它靠近谁：

- 靠近**发射区**的那一侧，也就是基区和发射区之间形成的结，叫**发射结**；
- 基区和集电区之间的那个结，叫**集电结**。

符号就是这么来的：

```text
          NPN 型                            PPN 型

            C                                  C
            │                                  │
            │                                  │
         ┌──┤                               ┌──┤
     B ──┤  │                           B ──┤  │
         └──┤                               └──┤
            │                                  │
            ▼   发射结箭头朝外                  ▲   发射结箭头朝内
            │                                  │
            E                                  E
```

**怎么一眼判型？** 抓住那条箭头——**箭头的方向就是发射结导通的方向**。PN 结正向导通是从 P 指向 N，所以这条箭头就画在发射结上，顺着它你就能认出谁是 P、谁是 N：

- **NPN 型**：基区在符号上是 P（中间那层），发射区在下面、是 N。箭头由基区指向发射区，也就是**指向管外**；夹心结构外面两层自然是 N，N-P-N；
- **PNP 型**：**箭头反过来**——发射区是 P，基区是 N，集电区当然是 P，P-N-P。箭头由发射区指向基区，也就是**指向管内**。

> **提示**：两种符号**唯一的差异就是这个箭头是反过来的**，非常好记。看到箭头朝外（朝发射极）是 NPN，看到箭头朝内（朝基极）是 PNP。

### 放大现象：$I_C$ 是 $I_B$ 的 $\beta$ 倍

三极管最重要的作用是什么？是它的**电流放大作用**。这件事电子管同样有，电子管同样有电流放大作用——但真正把电子管替下来的，是半导体器件。

先看现象。如果基极进来一个输入电流 $I_B$，那么在一定工作条件下，集电极和发射极之间就会流过一个电流 $I_C$。这时候你会惊喜地发现：

$$\frac{I_C}{I_B} \approx \text{一个近似不变的常数}$$

这个常数叫**电流放大倍数**，记作 $\beta$。

也就是说：**$I_C$ 是跟着 $I_B$ 变的，是 $I_B$ 的放大。** 这个放大作用我们到现在都在用，放大的基本原理也一直在用。

打个比方：好比放大倍数是 100 倍，那么 $I_B$ 是 $10\ \mu\text{A}$，那家伙就是 $1\ \text{mA}$；$I_B$ 是 $20\ \mu\text{A}$，它就是 $2\ \text{mA}$，$I_C$ 就跟着变成两毫安。**相当于把那个东西整个放大了。**

#### 放大的是电流，不是能量

最常见的应用就是我们现在正在用的这个：**话筒**。

我说话，声音让麦克风的颤板振动，**变成电信号**，这个电信号非常非常微弱；然后调制、载波，发出去——因为它是无线的嘛，它得过去，发过去。那一头的过程先不考虑，我们只看小信号进了功率放大器这一段。功率放大器里分很多种，我说的是甲乙类功放：它做的事情就是把这个小信号变成基极电流 $I_B$，然后在集电极那块变成放大的电流出来，最后变成放大的功率出来。

**但这一切都是有外部条件的。** 什么呢？我们学到现在，学了这么多乱七八糟的转换，只有一条要死死记住：**能量在转换过程当中不会凭空冒出来，它从一种转到另一种。**

所以你得到的那个被放大的声能，它究竟是从哪来的？三极管一定有一个**外部支持的电源**。

> **结论**：**你以为的那个大 $I_C$，不是它自己变出来的。** 它是用 $I_B$ 去控制电源，让电源的电流变成那样——这个大 $I_C$ 是它控制电源得来的。

这玩意儿特别像什么呢？特别像咱们**操作一个机器人**。现在好的仿生手都带手套了：你这么一"咔"一抓，那头的机械手也跟着你"咔"一抓；你这么一捏，人家那面把好几辆汽车"咔"就捏碎了。

**是你捏的吗？** 是你控制的。你控制了什么？**你控制了那个机械手的能量**，它跟着你这个动作走。三极管也一样——**它控制了其他电源的能量**。

所以严格说，这种控制作用就是它的电流放大作用：**说是电流放大，实际上它控制了一个能量，让那个能量跟着它变、跟着它走。** 就是这个道理。

#### 放大的真谛：绝对不能失真

那么从"放大"这个角度再往深里说：**三极管是一个控制的核心元件**，它的机理是通过**控制一个能量的新的变化**来实现这种放大的。

那放大的根本真谛是什么呢？

> **结论**：**放大绝对不能失真。**

最好懂的一个例子就在眼前：你们从扬声器里听到的声音，和我本人的声音应该**比较接近**。要是不接近到什么程度呢——**我在这说，那面传出来的是唐老鸭的声音，那就失真了**。再失真过分一点，全是啸叫，那好了，我也不用说话了，直接放啸叫。

所以放大的这种基本要求是：**要保真**。

### 基本共射放大电路：放大成立的条件

刚才我是一再强调：**三极管要想放大，它是具备一定条件的**——在一定条件下，$I_B$ 和 $I_C$ 才能成比例。什么条件呢？我们用一个典型的研究电路来看：**基本共射放大电路**。

先说明一下：在这里我**不对这个电路进行过多的评价**。等到第二章，我会和你们一起从三极管的特性出发，把这个电路构架出来。这里我是**以实验的角度**来谈这个问题——你想看到我想研究这个实验，三极管到底怎么接，你先不管它为什么那么接。

```text
          V_BB                            V_CC
            │                               │
           R_B                              │
            │      ┌────────┐               │
            ├──── B┤        │          C ───┤
            │      │  NPN   ├───────────────┤
            │      │        │               │
            └──── E┤        │               │
                   └────────┘               │
                        │                    │
                        └────────────────────┘
```

一节电池 $V_{BB}$ 通过 $R_B$ 送进基极，作用非常明显：**使我的发射结导通**；另一边 $V_{CC}$ 加在集电极和发射极之间。

#### 为什么基极回路非串 $R_B$ 不可

那我先问同学们一个很直接的问题：**我不加 $R_B$ 行不行？**

我的发射结导通大概只需要 $0.6\ \text{V}$，那我这块 $V_{BB}$ 弄个 $1\ \text{V}$，直接"啪"扔上去，$R_B$ 不要，行不行？

**行不行？——不行。为什么？**

> **结论**：**会导至电源短路。**

这跟稳压二极管那节的情形非常像。你把 $1\ \text{V}$ 直接加在这个 PN 结的两端，含义是什么？**PN 结两端的电压将达到 1 V**。可它还是那个二极管——它很"忠实"，两端的电压和电流之间的关系**一定得符合它那根伏安特性曲线**：

```text
   I
   │                ╱
   │               ╱   ← 一旦导通，电流急剧上升
   │              ╱
   │  ───────────╱
   │
   └──────────────────── U_BE
          ↑
        0.6 V      导通点大致在这个位置
```

你现在硬把 $1\ \text{V}$ 加上去，就得**跑到这根曲线上去找对应的电流**。而电流在哪？在楼上呢——**它到不了**。电流"唰"就上去了，相当于电源在源源不断地灌电流。当然一般情况下电源比较"坚强"，那么结果就是：**三极管坏，这个发射结坏。**

所以 $R_B$ 往这一放，它是干什么的呢？——**$R_B$ 是一个限流电阻。** 在这个电路里它非常明显的一个作用就是**限流**。你再想让电流往上升就升不上去了，最大的电流值是多少？你随便估一下，最多就是

$$I_{B,\max} = \frac{V_{BB}}{R_B}$$

不管那面 PN 结的压降有多小，最大就是 $V_{BB} / R_B$。所以这个东西比较有用。

#### 正偏与反偏：两个必须记住的新词

再看另一面。集电极和发射极之间加了一个 $V_{CC}$。$V_{CC}$ 和 $V_{BB}$ 之间的关系是什么？

> **结论**：**$V_{CC}$ 肯定比 $V_{BB}$ 大。** 图上你看看个头——这边一节电池，那边两节，很形象。

那就说明什么呢？**说明我的发射结在这时候正向导通。** 我们把这种情况叫做**正向偏置**。

> **定义**：以后我们说一个 PN 结"正向偏置"，就说明这个 PN 结正向导通——我们给它加了一个直流让它正向导通了。**正向偏置简称正偏。**

与它对应的一个名词叫作什么？**反向偏置，简称反偏。** 反偏是什么意思？就是**这个 PN 结截止**，反偏即截止。这两个名词今天给大家介绍清楚。

#### 为什么集电结只能是反偏

在这个电路里，**两个 PN 结的待遇是不一样的**：

- **发射结正偏**；
- **集电结必然反偏**。

为什么？——**因为 $V_{CC}$ 比 $V_{BB}$ 大**。这是 NPN 型：现在我的 N 的电位比你 P 的电位要高。你要想正偏的话，必须是 **P 比 N 高**才对。我现在是这样一个状况，所以集电结只能反偏。

> **结论**：**发射结正偏、集电结反偏**——这就是三极管工作在放大状态的条件。

在这个电路的条件下，大家可以看到：我这里的 $I_B$ 电流和那边的 $I_C$ 电流，**它们成比例**了，$I_C$ 是一个放大的电流。那么 $I_C$ 这个放大的电流，能量来源于谁？

**来源于 $V_{CC}$。** $V_{CC}$ 给它这个能量——**并不是它自己无中生有能够产出来的，它是控制了 $V_{CC}$ 这个电源。**

### 管子内部的电流：三步走

上面说的是外部现象。现在我们进到管子里面去，看电流到底是怎么走的——这也就是我们所谓的**晶体管内部载流子的运动**。

> **提示**：为了把机理讲清楚，我把交流信号去掉，纯用直流来分析这个工作状态。其实这个工作情况大部分你们自己都能分析出来，我先问你们第一个问题。

已知条件：发射结正偏了，集电结反偏了。**发射结正偏，能产生什么后果？**

#### 发射结正偏：扩散运动恢复，$I_{EP}$ 被扔掉

它还是像一个 PN 结、像一个二极管一样的东西。二极管正向导通的时候，是什么在做主？——**扩散运动。**（二极管截止的时候是漂移运动打头，中间设计了一道堤坝，扩散过不去了；正偏就是把这道堤坝给消灭了，于是扩散运动开始正常工作了。）

那么后果就很清楚了。**两边都在动：**

- 发射区是**载流子的聚集区、是它的源泉**，掺杂浓度高，所以里面大量的**自由电子**会向基区扩散，形成 $I_{EN}$；
- 同时基区里的多子是**空穴**，也会向发射区扩散，形成 $I_{EP}$。

于是形成两个电流。**但这两个电流一比，差距实在太大了。**

> **结论**：**$I_{EP}$ 相对 $I_{EN}$ 近似于可以忽略。**

为什么？因为两个区域的掺杂浓度极其悬殊——发射区掺杂浓度非常高，自由电子的数目非常多；基区掺杂浓度很低，空穴的数目很少。这两个压根就不成比例。所以虽然形式上形成两个电流，但两个电流一合，**几乎整个电流都是 $I_{EN}$**。（当然严格说是 $I_{EP} + I_{EN}$，但后面那个跟它比，近似于可以忽略。）

还有一点要记住：**过去的数量跟什么相关？跟 PN 结上所加的正向电压。** 正向电压越大，过去的速度越快——过去的东西越多。这在二极管里我们就分析过了。

#### 基区：一边往前扩散，一边被复合掉一小部分

**第二步很关键了。**

这批电子过去了，在基区里该怎么办？我们一步步想："啪"，它越境了，到基区去了。**刚到基区的时候**，它的大部队肯定都在基区和发射区之间的发射结那一侧集结——你能想象出来吧，推着推着就过去了。

**它就在那儿停着不动了吗？** 它必然继续往前**扩散**。因为**基区靠结那侧的边缘浓度特别高**，浓度梯度在那儿摆着，它就往浓度低的方向扩散，也就是**朝集电结跑**。

而且这时候的基区很奇怪：它本来的自由电子是**少子**，可现在扩散过来的**非平衡少子**，竟然比它原来的多子（空穴）还多得多，远远大于它。所以现在基区里当家的是扩散过来的非平衡少子。

在朝集电结跑的过程当中，在基区里必然发生一件事——**复合**。因为毕竟这里是空穴的地盘。

这里我们用一个比喻：**这特别像一条河，河里面有鳄鱼，然后迁徙的马鹿、驯鹿往河里跳。** 河要是不够长、鳄鱼要是不够多，那动物就迁徙不过去。

> **结论**：**如果基区足够宽、基区的掺杂浓度足够高，那么所有扩散过来的自由电子都将被在基区里消灭，只有极少数能逃到集电结那边。**

而我们做基区时的原则是什么？——**薄，且掺杂浓度低。** 现在能明白这一点了吧？**我要让绝大多数都顺利地通过去。**

在这个通过的过程当中，**基区的宽度和基区的掺杂浓度决定了什么？——决定了复合的百分比。** 这实际上是个概率问题：你往前走一步，被"咬"一次的可能就大一分；这个宽度和这个掺杂浓度，就大体把"复合的百分比"给定死了。

好比说：100 个里面复合了 2 个。那么你在这条"河"的另外一边就能看到——**100 个过来，98 个顺利地冲到这儿了，有 2 个在这复合了。**

**但这里有一点必须想明白：** 我这个基区**整个的掺杂浓度实际上是不变的**。条件不变的情况下，你这边复合掉两个，我这块**很容易再产生两个空穴**——你在这儿复合掉两个电子，我这块马上就会抽走两个电子，于是**两个新的空穴就产生了**。

> **提示**：**这边复合，这边产生。** 所以你最终看到的现象就是：好像有 98 个自由电子跑到那儿去了、2 个自由电子从这边出去了——实际上那 2 个是在中途被复合掉的，只不过在中途**又被重新产生**了。对外面的人来说，效果就等于两个自由电子往这边跑、98 个往那儿跑。

现在同学们脑子里应该渐渐有一点概念了吧——**由于这个比例是固定的，所以 $I_B$ 和 $I_C$ 就渐渐地成比例了。** 在上面这个例子里，比例是 49:1。

**但是还有一个关键点在哪？** 我们现在在基区里，能记住它做哪几个工作吗？

- **第一**，继续扩散——向哪扩散？**向集电结**扩散；
- **第二**，去干**复合**这件事；
- **第三**，在基极那块，它还会**产生**（补上被复合掉的那些空穴）。

那么这个"复合比例近似固定"，除了基区结构不变要固定，还有一个条件——**扩散的推进速度必须近似不变。**

道理还是那条河：**如果你这个小动物能够以简直是"脚不沾地"的速度，"唰"一下就蹚过去了，它被鳄鱼咬着的概率就比较小；它要是在里面游个一天、慢慢地往前走，那就死定了。** 所以推进的速度得大致是恒定的。

**什么维持这种恒定？** ——**扩散速度**，而扩散速度跟**浓度梯度**相关。

所以问题就来了：你推到集电结旁边的这些自由电子，**一定要被快速地移走**，否则它们自然会在那儿聚集。前面积累了，后面还在往前推——**前面浓度不断提高，扩散速度就减慢。** 这才是"第三步"要解决的问题。

#### 集电结反偏：像抽水机一样把电子抽走

现在我们看**第三个关键点**——**集电区收集自由电子**。

先想一想：集电结反偏是什么意思？——**这里电位高，那里电位低。** 也就是说，**电场方向是向下的，向下有一个很大的电场。**

而过来的是什么？——**自由电子。**

> **结论**：**这个电场就像一个抽水机一样，把过来的自由电子"噌噌噌"全拉过来，收集到它的集电区里去。**

这就保证了两件很要紧的事：一是基区里靠近集电结那一侧的电子被及时抽走，**浓度梯度能够维持正常**；二是**扩散的推进速度能够保持住**。

**那为什么反偏在这里这么重要？** 我们反过来想一遍就明白了——

> **易错点**：**一旦这个反偏没有了，就比较麻烦了。** 反偏没有了，推进速度就保证不了，$I_B$ 和 $I_C$ 之间的比例关系就保证不了。它变成一种"自由交通"的状态：集电结也是正偏了，自由电子就靠浓度推动从这头跑到那头，整个半导体**跟个大导体似的**，跟一个整个 PN 结导通的导体一样，**里面没有任何控制在里面**——你说不准在基区的速度是什么。

你就会看到一种特别典型的现象：**$I_C$ 电流几乎都不长了，而 $I_B$ 电流却还可以不断增长。**

为什么？因为**越慢复合得越多**。前面已经没有任何一个力量去抽它了——本来集电结反偏就是在抽它，抽力没有了，那就"过来吧"。你看看这个规律多好：这样过来了，对不对，这块吸走；过来了，吸走。**然后吸力没有了，那就过来吧。**

到这里，基区里的活、集电区的活都讲完了。顺带说清楚另一件事：**在收集的过程当中，它也没白干。** 集电结反偏，反偏本身就会加大一个什么运动？——**漂移运动。** 当然绝大部分漂移都发生在集电区里，不过在那儿这都不叫漂移了，**这就叫收集。** 另外集电区自己的少子（电子和空穴）**自个儿在那儿玩漂移**，它们形成的电流，就是我们下面要说的 $I_{CBO}$。

---

### 几个电流参数和两个放大系数

上面的图景里，符号已经不少了，我们一个一个对上号：

| 符号 | 含义 | 地位 |
| --- | --- | --- |
| $I_{EN}$ | 发射区自由电子注入基区的电流 | 由 $I_B$ 支配，做**主流** |
| $I_{EP}$ | 基区空穴注入发射区的电流 | 与 $I_{EN}$ 差距太大，**近似忽略** |
| $I_{BN}$ | 扩散进基区后被复合掉的那部分电流 | 由 $I_C$ 支配 |
| $I_{CN}$ | 到达集电结并被集电极收集的电流 | **与 $I_{BN}$ 成比例** |
| $I_{CBO}$ | 集电结的反向饱和电流 | 相当一个 PN 结的反向饱和电流，**很小** |

实际上最后真正成比例的是 $I_{CN}$ 和 $I_{BN}$——两个过去、两个复合，就这个意思。这边成比例，那边都是一个小干扰因素。

#### $I_{CBO}$ 与 $I_{CEO}$：一个小，一个穿透

$I_{CBO}$ 我们刚才说了，**它就相当于一个 PN 结的反向饱和电流**。这个电流很小，小到跟别的东西不好比。

还有一个更有意思的，叫 **$I_{CEO}$**——**穿透电流**（不是首席执行官啊）。

它怎么定义？——**基极开路的时候，c 和 e 之间的电流。**

想一想就很清楚：我这块没电流，**当 $I_B = 0$ 的时候，正常情况下我这块应该断开，$I_C$ 应该等于 0**。但是它还有一个小小的电流 $I_{CEO}$ 从这头穿过来，所以它叫**穿透电流**。

#### $I_B$ 的 KCL 与直流放大系数 $\bar{\beta}$

现在回头看 $I_B$。$I_B$ 实际上等于好几个东西——你在这张图上做一个 **KCL** 就看得出来：

$$I_B = I_{EP} + I_{BN} - I_{CBO} - I_{CEO}$$

> **提示**：**别把 KCL 学成只能用在"一个点"上。** 割集形式的 KCL 一样能用——只要是闭合曲面都可以用 KCL。你围着基区做一圈割集，上面这一串就出来了。

这里面**起主流的是 $I_{BN}$**。好，有了这些，我们就可以得到放大系数了。

**第一个：共射的直流放大系数 $\bar{\beta}$**。

$$\bar{\beta} = \frac{I_{CN}}{I_{BN}}$$

把它换成端电流，就是

$$\bar{\beta} = \frac{I_C - I_{CBO}}{I_B + I_{CBO}} \approx \frac{I_C}{I_B}$$

同学们注意，我这里**约了两个东西**：一是丢掉了 $I_{CBO}$、$I_{CEO}$ 这些小项；二是**还约掉了一个 $I_{EP}$**——$I_{EP}$ 直接就被扔了。刚才分析的时候它跟 $I_{EN}$ 差距实在太大了，根本没法比。

#### 交流 $\beta$ 与共基的 $\alpha$

还有第二个放大系数，叫 $\beta$，是**变化量**之比：

$$\beta = \frac{\Delta I_C}{\Delta I_B}$$

这个叫**交流电流放大系数**。

> **易错点**：**直流 $\bar{\beta}$ 和交流 $\beta$ 这俩不是一个东西**，从意义上说一个是直流的，一个是动态的交流的；而且它们**数值确实有点不一样**。只不过在绝大多数情况下这两个是近似的，所以我们这门书到最后干脆合二为一了——开始还分 $\bar{\beta}$、$\beta$，后面全用 $\beta$。记住这一条就够了。

除了共射的电流放大系数，还有**共基**的，叫 $\alpha$ 和 $\bar{\alpha}$。

共射是什么意思？——**共用发射极**。我们比的是 $I_C$ 和 $I_B$，**而发射极就在那儿摆着，没参与**，所以叫共射。

共基呢？——**我这个基极不用**（或者说作公共端），然后谁和谁比？**$I_C$ 和 $I_E$ 比。** 这就是共基电流放大系数：

$$\bar{\alpha} \approx \frac{I_C}{I_E}$$

这俩之间可以互相倒换的：

$$\bar{\alpha} = \frac{\bar{\beta}}{1 + \bar{\beta}}$$

同样道理，它也有交流的 $\alpha$，也是近似相等的这样一对情况。

---

现在同学们脑子里可以有一个基本概念了，我们捋一遍：

1. **三极管可以实现电流放大**，它放大的是电流；
2. **靠基区那玩意儿实现**——就是那层"薄且掺杂浓度低"的基区，它决定了绝大多数载流子能不能穿过去；
3. **在什么条件下实现**——**发射结正偏、集电结反偏**；
4. 实现之后有**两个参数**出来：**共射电流放大系数 $\beta$** 和**共基电流放大系数 $\alpha$**，两者之间可以互倒。

不过有个非线性的因素现在就必须记住：**当我们 $I_B$ 等于 0 的时候，$I_C$ 并不等于 0。** 这个 $I_C$ 叫 $I_{CEO}$，叫**穿透电流**。所以正常工作时 $I_C = \beta I_B$，但那只是个近似式。

至于这些参数到底对三极管有什么影响、以及对三极管整个特性的分析，我们**将在下次课里一起来讨论**。今天一定要理解好三极管这个最基本的基本概念。

## 三极管的共射特性曲线：两个端口、三个工作区与温度的影响
> 对应块：BLK07 | 覆盖分集：P07 | 块标题（分集名）：《07-BJT特性曲线共射_4K》

我们来认识一下三极管的特性。

先把名字交代清楚：以后我们说的"晶体三极管"，有个标准名称叫**双极型晶体管**，简称 **BJT**。真要用它，就得看它的特性曲线。这一讲我们盯住的是共射接法下的那一条——共射特性曲线。

---

### 三个极，一条伏安特性曲线哪里够用

原来我们说特性曲线，其实是很简单一个事情。电源画的是**外特性曲线**；电阻是什么？伏安特性曲线；刚学的晶体二极管呢？也是一条伏安特性曲线。

两个极的东西好办：我两边加一个电压，中间出一个电流，伏安关系，一条线画完，齐了。

三极管不行。它三个极——本来两个极的东西我两边一加电压、中间一个电流就够了，现在这三个极就跟什么相关了？跟**我这个电路到底是什么结构**相关。这个三极管接成什么样子，我怎么用它。所以"三极管特性"不是一条线能办完的事。

现在用得最多的是**共射放大电路**，那我们就从共射来看。

所谓共射，我共用了什么？发射极。一旦共用发射极，三极管就天然劈成了**两个端口**：

```text
        V_BB                      V_CC
          │                         │
          │                         │
         R_B                       R_C
          │                         │
          ├──── B   ┌──────┐   C ───┘
          │          │ NPN  ├────────┐
          │          └──────┘        │
          └──── E ───────────────────┤
          │                           │
          ▽                           ▽
         共用的发射极              回到参考电位

  输入端口 B–E ：I_B = (V_BB − U_BE) / R_B
  输出端口 C–E ：I_C = (V_CC − U_CE) / R_C
```

一个端口是基极和发射极之间，上面跑的是 $I_{\text{B}}$；另一个端口是集电极和发射极之间，上面跑的是 $I_{\text{C}}$。两个电流，就有了两条曲线——端口特性总归是电压与电流的关系嘛。第一个端口的曲线叫**输入特性**，$I_{\text{B}}$ 与 $U_{\text{BE}}$ 的关系；第二个端口的曲线叫**输出特性**，$I_{\text{C}}$ 与 $U_{\text{CE}}$ 的关系。

那么当初讲基本共射放大电路的时候，我们说它有输入回路和输出回路。为什么这么叫？我给大家举个例子。

对放大电路来说，目标是什么？**用小信号去控制大能量、大功率**。那么哪个是小信号？是控制量。要用三极管构成放大电路，很明显就是我的输入信号要去控制 $I_{\text{B}}$。输入信号变化 → 控制 $I_{\text{B}}$ 变化 → 由于放大作用，$I_{\text{B}}$ 的变化控制 $I_{\text{C}}$ 的变化 → $I_{\text{C}}$ 是个比较大的东西，再把 $I_{\text{C}}$ 变成能量的、功率的输出。

所以，$I_{\text{B}}$ 这边这个环节是输入回路，$I_{\text{C}}$ 那环节是输出回路。就这个道理。

顺带说一句，研究输入特性是干什么用的？它是个端口——以后你的输入信号就加在这上边，从这儿进去；你的输出信号从另一个口取出来，比如控制音箱那一套东西，从那儿出来。所以我研究输入特性，就是为输入信号研究的。

---

### 输入特性：基极电流受发射结电压支配

从这个端口上看，输入特性就是 $I_{\text{B}}$ 和 $U_{\text{BE}}$ 之间的关系。

不过还有一个控制量你别忘了：C 和 E 之间还有个电压 $U_{\text{CE}}$——那边有 $V_{\text{BB}}$，这边有 $V_{\text{CC}}$。所以这里摆着三个东西：$I_{\text{B}}$、$U_{\text{BE}}$、$U_{\text{CE}}$。

> **易错点**：研究变量之间的关系，**千万别三个变量一起变**，那样永远研究不明白。一个函数两个变量，你总得先把其中一个固定成定值。所以研究输入特性的时候，$U_{\text{CE}}$ 一定等于一个常数。

#### 形状你其实早就会了

其实都不用研究。我问你，这个特性曲线应该长什么样？它不明显就是 PN 结那样吗？$I_{\text{B}}$ 对 $U_{\text{BE}}$，就长这样。PN 结大家记住了吧？那它就应该长这样。

真正要看的，是**它为什么是一组**。

图上每条曲线都标了数：这条是 $U_{\text{CE}} = 0.5\ \text{V}$，那条是 $U_{\text{CE}} = 0$，还有一条标的是 $U_{\text{CE}} \geq 1\ \text{V}$。如果我把这个 $U_{\text{CE}}$ 从 0 画到 1 V 画全了，这一块就被画黑了。所以输入特性曲线首先是一个**曲线族**：每一个 $U_{\text{CE}}$ 对应一条 $I_{\text{B}}$ 和 $U_{\text{BE}}$ 之间的关系。

#### 这一族曲线有两大特点

**第一**，$U_{\text{CE}}$ 越小，这个曲线越往左移动；$U_{\text{CE}}$ 越大，它越往右移动。

**第二**，当 $U_{\text{CE}}$ 大于 1 V 之后，它几乎就不动了。换句话说，$U_{\text{CE}}$ 大过 1 V 之后，后面这一大段全都重合了。

为什么？这个"为什么"你们回去一看就明白——想一想**集电结是干什么用的**。$U_{\text{CE}} = 0\ \text{V}$ 和 $U_{\text{CE}} = 1\ \text{V}$ 这两种情况，对集电结来说有什么区别？想明白了这两句就都通了。

#### 这一族曲线到底在讲什么

> **结论**：输入特性曲线说明了一件很关键的事——基极电流 $I_{\text{B}}$ 的大小受发射结电压 $U_{\text{BE}}$ 控制。$U_{\text{BE}}$ 变化，$I_{\text{B}}$ 就变化，变化的关系就是这条输入特性曲线。

脑子里有这么一个概念就够了：我 $U_{\text{BE}}$ 能够控制什么？$I_{\text{B}}$。是这样吗？好。

#### 别把公式停在公式上

这里插一段，不是这一讲的内容，但你们迟早要用得上，而且比这一讲更值钱。

我们以前很习惯背公式。最简单的一个相量关系：

$$\dot{U} = \dot{I}Z$$

每位同学都会写。但你用语言把这个公式**内部的含义**描述出来，它才有实用价值。就像电容：

$$C = \frac{\Delta q}{\Delta u}$$

就这么一个东西，但它代表的含义一展开，你就知道哪里有电容、什么样东西才该是电容。

> **易错点**：如果现在学公式还停留在"公式、公式推导"上，那就有问题了。我们电学的公式、物理的公式，后面都拖着物理意义。

你把 $\dot{U} = \dot{I}Z$ 这么一写，能分析出多少个属性来？$U$、$I$ 同频——不同频你根本写不成相量；它描述的是流经这个阻抗 $Z$ 的电流和阻抗两端电压的关系；再往下说，大小是它的大小乘以阻抗的模，相位上它超前于电流一个阻抗角。这么多含义，还可以继续往下挖。

所以当我们对一个事物真正了解的时候，习惯不是"我背下一个公式"或者"我画了一张图"，而是——我能不能把这个式子、这张图**到底在讲什么物理**说出来。我们回到输入特性上来：我这里写了这样一个关系、画了这样一张图，它描述的关键点就是 $U_{\text{BE}}$ 是发射结的电压，$I_{\text{B}}$ 受它控制。你能讲出来，你才真的看懂了。

---

### 输出特性：集电极电流与集射电压的那一族曲线

输出特性从定义上讲，就是 $I_{\text{C}}$ 和 $U_{\text{CE}}$ 之间的关系。

但这里要留个心眼：真的只是 $I_{\text{C}}$ 和 $U_{\text{CE}}$ 的关系吗？它还受谁影响？$I_{\text{B}}$。所以做这件事的时候，$I_{\text{B}}$ 得等于常数。

#### 曲线的形状是从哪来的

可以预想它也是一个曲线族：每一个 $I_{\text{B}}$ 就有一条 $I_{\text{C}}$ 与 $U_{\text{CE}}$ 的对应曲线。

再往下想一层。$I_{\text{C}}$ 和 $I_{\text{B}}$ 简单来看是什么关系？成比例。**成比例的前提是什么？发射结正偏、集电结反偏。**

为什么必须有这个前提？你只要有 $I_{\text{B}}$，就说明发射结是正偏的。发射结不正偏、集电结反偏的情况下那是截止状态，PN 结不通；就算有那么一个 $I_{\text{B}}$，它也只是个反向电流的概念。

那反偏不反偏跟什么相关？跟 $U_{\text{CE}}$ 相关。$U_{\text{CE}}$ 越大，它越向集电结反偏发展；$U_{\text{CE}}$ 很小的时候它根本不是反偏的。$U_{\text{CE}}$ 刚才说等于 0——C 和 E 电位相等，而基极电位在这儿比它高，说不定集电结就正偏了。

所以脑子里就该有这么一条：**当我 $U_{\text{CE}}$ 足够大的时候，只要 $I_{\text{B}}$ 不变，$I_{\text{C}}$ 应该是几乎不变的**——这条曲线后面应该是平的；前面呢，随着 $U_{\text{CE}}$ 增大，电流还要往上涨。所以输出特性曲线长这样：

```text
     I_C
      │    ───────────────────────────────────  I_B = I_B3
      │        ╭───────────────────────╯
      │    ───╭╯          ╭────────────────────  I_B = I_B2
      │      ╭╯      ╭───╯
      │    ──╯    ╭──╯        ╭────────────────  I_B = I_B1
      │         ╭──╯      ╭───╯
      │        ╭─╯    ╭───╯
      │   ╭────╯    ╭──╯
      │──╯   ╭─────╯························  I_B = 0
      └───────────────────────────────────────► U_CE
       ╰饱和区╯  ╰──────── 放大区 ─────────╯

   读图：每条曲线过拐点之后压平，那一段就是放大区；
   左侧挤在一起的陡峭段是饱和区；最底下那条贴着轴的虚线是 I_B = 0。
```

解读一下。$I_{\text{B}} = I_{\text{B1}}$ 那条，$I_{\text{C}}$ 和 $U_{\text{CE}}$ 是这个关系：过了这个拐点之后，$U_{\text{CE}}$ 大于这个值，就说明我的集电结已经反偏了；反偏之后只要 $I_{\text{B}} = I_{\text{B1}}$ 不变，$I_{\text{C}}$ 就是一个固定值。$I_{\text{B2}}$、$I_{\text{B3}}$、$I_{\text{B4}}$ 完全同理。

所以这一大片平坦的区域就是**放大区**。如果我把曲线都画满——$I_{\text{B}}$ 从 $I_{\text{B0}}$ 一路画上去——这个放大区就被曲线覆盖成黑的了。记住，它**也是一个曲线族**。

#### 截止区：关不干净的那一点电流

放大区下面还有两个很有意思的区域。

先看 $I_{\text{B}} = 0$ 这条线。你会发现它不是零——上面有一股很小很小的电流。这是哪个电流？上节课刚提到过：$I_{\text{CEO}}$，**穿透电流**。它的数值我给过你们了，为什么等于那么多，你们回去看。

这条线所在的位置，就是**截止区**。

> **结论**：穿透电流越小越好。越小，说明我这截止区截止得越干净。你看这儿几乎等于零了——$I_{\text{C}}$ 就是 C 和 E 之间的连通关系，它几乎为零，就相当于 C 和 E 是断开的。

至于工作状态本身，截止区的特点是**双结都反偏**。其中最主要的一个反偏是谁呢？一般我们去控制**发射结反偏**。因为发射结一旦反偏，就相当于把水源给关了；水关了，C 和 E 相当于断路，相当于一个开关断开了。

这个区好不好创造？好创造。我只要控制基极的电位，让我基极电位小于发射极电位，就可以把它控制在截止区。

#### 饱和区：双结正偏，基极电流说了不算

饱和区的特点就多了。

**第一**，$I_{\text{B}}$ 和 $I_{\text{C}}$ 不成比例。也就是说，在这个区域里 $I_{\text{C}}$ 根本不受 $I_{\text{B}}$ 控制。

**第二**，$U_{\text{CE}}$ 非常小，小到集电结处于正偏状态。

回过头来看，**集电结正偏代表什么含义**？发射结正偏了、集电结也正偏了，这个玩意儿是个什么东西？类似于是一个电阻的导体，你自由地通过。

那么问题来了：这里电流的大小根本不是 $I_{\text{B}}$ 说了算。谁说了算的？几乎就是 $V_{\text{CC}}$ 比上 $R_{\text{C}}$。

我最多有一个饱和压降，C 和 E 之间有个很低的压降——硅管约 0.3 V，锗管约 0.1 V。这种状态下，相当于 C 和 E 两个电极之间是个开关的**闭合**。

#### 把基极电流一直加大，饱和是怎么来的

我们换一个角度来理解饱和区。

假设我把 $I_{\text{B}}$ 不断地加大。原来是正常放大状态，$I_{\text{B}}$ 不断加大的时候 $I_{\text{C}}$ 肯定也跟着长，因为放大状态下它俩成比例，对吧？没毛病。

那我问你们：$I_{\text{C}}$ 能无限度地跟着 $I_{\text{B}}$ 一直玩下去吗？

我们先姑且不论 $I_{\text{C}}$ 会不会烧掉——先不考虑烧不烧的问题，单从**这个电路上**看，$I_{\text{C}}$ 会一直往下长吗？$I_{\text{C}}$ 有没有极值？极值是什么？

它绝对不会超过 $V_{\text{CC}}$ 比上 $R_{\text{C}}$ 的。

为什么？因为在这里，$I_{\text{C}}$ 就是这么来的：

$$I_{\text{C}} = \frac{V_{\text{CC}} - U_{\text{CE}}}{R_{\text{C}}}$$

$V_{\text{CC}}$ 是定值，$R_{\text{C}}$ 是定值，$I_{\text{C}}$ 要往上涨，唯一能动的就是 $U_{\text{CE}}$ 在**不断减小**。哪怕我把 $U_{\text{CE}}$ 缩到 0，$I_{\text{C}}$ 也只能是 $V_{\text{CC}} / R_{\text{C}}$，不可能再大了。到顶了，就叫**饱和**。

```text
   I_C
    │                    ┄┄┄┄┄ I_Cmax ┄┄┄┄┄┄┄┄┄┄
    │              ╭────── ─ ─ ─ ─ ─ ─ ─ ─ ─ ─
    │           ╭──╯   饱和：I_C 到顶，不再上升
    │        ╭──╯
    │      ╱  放大段：I_C ≈ β·I_B
    │    ╱
    │  ╱┆
    │╱ ┆  虚线段是这条直线往原点方向的线性外推，
    └┴──┆──────────────────────────────► I_B
    I_B0┆

   斜率就是 β；走到 I_Cmax 就压平。再往右加 I_B，
   I_C 上不去，而 I_B 自己还照 PN 结的规律继续涨——这就是饱和。
```

所以你们现在能理解"饱和"这个概念了吗？如果你 $U_{\text{CE}}$ 足够大，从外电路来看，就说明 $I_{\text{C}}$ 还有上涨的前途；$U_{\text{CE}}$ 缩到不能缩的时候，就说明它饱和了。

换到内部来看是什么状态？双结全正偏了。集电结、发射结我都全正偏，你自由交通吧——这时候**我 $I_{\text{B}}$ 说了不算了**，外面的电路来决定你当中通过的电流。

再往机理里钻一层。集电结正偏了，我收集电子的功能怎么样？没有了，就是一个自由扩散。所以这时候 $I_{\text{B}}$ 和 $I_{\text{C}}$ 之间没有关系：$I_{\text{C}}$ 跑 $I_{\text{C}}$ 的，$I_{\text{B}}$ 跑 $I_{\text{B}}$ 的——$I_{\text{B}}$ 只和它自己那个端口的电压相关。

而正常放大时呢？集电结反偏，不断地收集电子；外界表现就是 $U_{\text{CE}}$ 比较大，是一个比较大的值。

所以从外特性上来讲，饱和也是一个过程：$I_{\text{B}}$ 不断地长，$I_{\text{C}}$ 跟着长；最后 $I_{\text{C}}$ 从外电路来看有个极值，不能再长了，$I_{\text{C}}$ 就饱和了。

#### 三步一比，判工作状态

现在我给你一个晶体三极管的电路，你能不能判断出这颗三极管的工作状态？有没有思路？

**第一步，算 $I_{\text{B}}$。** 看一下：$V_{\text{BB}}$ 减去 $U_{\text{BE}}$，除以 $R_{\text{B}}$。

$$I_{\text{B}} = \frac{V_{\text{BB}} - U_{\text{BE}}}{R_{\text{B}}}$$

其中 $U_{\text{BE}}$ 几乎可以近似为一个定值，上下可能有 0.1、0.2 这样的波动——这跟我们处理二极管是一模一样的。所以饱和的时候 $I_{\text{B}}$ 也不用重新算，它还是按 PN 结那么算。

**第二步，算 $I_{\text{Cmax}}$，也就是外电路规定的 $I_{\text{C}}$ 最大值。** 如果给你 $U_{\text{CES}}$，那么：

$$I_{\text{Cmax}} = \frac{V_{\text{CC}} - U_{\text{CES}}}{R_{\text{C}}}$$

$U_{\text{CES}}$，大写的 S，是饱和电压，$U_{\text{CE}}$ 能够达到的最小压降——它是一个近似定值，锗管 0.1 V，硅管约 0.3 V，非常小。

**第三步，拿 $\beta I_{\text{B}}$ 去和 $I_{\text{Cmax}}$ 比。**

| 比较结果 | 含义 | 结论 |
| --- | --- | --- |
| $\beta I_{\text{B}} < I_{\text{Cmax}}$ | $I_{\text{C}}$ 跟得上你 | 工作在**放大区** |
| $\beta I_{\text{B}} \ge I_{\text{Cmax}}$ | $I_{\text{C}}$ 涨到头了 | 工作在**饱和区**，$I_{\text{C}} = I_{\text{Cmax}}$ |

道理就是一句：$\beta I_{\text{B}}$ 要是大了，说明我完了，我只能饱和。

当然还有另一个更快的办法：**你一旦判断出发射结是反偏的，它就处于截止。**

### 三个区对照，以及电子开关

| 工作区 | 发射结 | 集电结 | $U_{\text{CE}}$ | $I_{\text{C}}$ 与 $I_{\text{B}}$ | 电流由谁决定 | 对外等效 |
| --- | --- | --- | --- | --- | --- | --- |
| 放大区 | 正偏 | 反偏 | 较大 | 成比例，$I_{\text{C}} \approx \beta I_{\text{B}}$ | $I_{\text{B}}$ | 受控放大 |
| 截止区 | 反偏 | 反偏 | — | 不成比例 | 极小，约 $I_{\text{CEO}}$ | C–E 断开 |
| 饱和区 | 正偏 | 正偏 | 很小，约 $U_{\text{CES}}$ | 不成比例 | $V_{\text{CC}} / R_{\text{C}}$ | C–E 闭合 |

看清了这三个区域，剩下的事情就顺理成章了。

截止和饱和之间能来回跳。$I_{\text{B}}$ 要么特别低、要么特别高——我基极电位要么特别低（截止），要么特别高（高到肯定大于集电极电位，那就是饱和）。这样我就能让它在两者之间来回跳变，实现**电子开关**的作用。

这时候就可以把电路扩展出去了。我们计算机的控制板输出的信号，好比说可以是方波、可以是矩形波：

- 低电平过来的时候，C–E 之间是断开的；
- 高电平过来的时候，C–E 之间相当于是饱和的（闭合）。

你外边愿意接灯也好、接什么东西也好，这边编程过来的一个信号就能控制那头的通断。不再是过去那种机械的控制方式了。

> **注意**：当然，你直接用 C 和 E 去输出的时候，功率感觉不大——你不能直接连接大的负载，想控制灯这类东西可能不行，要再加一级。上节课给你们讲过一个东西叫**继电器**：你用这个信号去控制继电器的线圈，再用继电器的主触点去给负载供电。一级不够，还可以再扩大一级。当然能做的事情很多。

> **结论**：晶体三极管最主要的就是这两大功能——**放大功能**和**开关功能**。

### 极限参数：设计之外还有一道边界

三极管还有主要参数，除了我们一直在说的 $\beta$ 之类的常规参数，还有**极限参数**。

极限参数是什么？就是在什么样的电流下、什么样的电压下，这个管子是不会坏的。这是我们买管子的重要指标。

> **结论**：极限参数越大，那玩意儿肯定越贵——容量大嘛，就越贵。

我们设计电路的时候算这个，谁都有这个过程。最开始设计是"功能能实现"就挺好了，从来不会去想这个电阻该是多少瓦的、那个稳压二极管该是多少瓦的，一开始都不知道会想。直到那玩意儿拿过来一用，发现不对啊——**这玩意儿烧**。这才回头去算电阻功率。

原来咱们一算，算出来是几欧姆。其实几欧姆这玩意儿多可怕呀：1 欧姆的电阻配 1 伏的电源，你试试？那就代表 1 瓦，电阻要 1 瓦。上个 2 伏的电源，那就是 4 瓦——4 瓦的电阻已经很大了。再往上发展，它就该变成电阻丝了，就是电热炉那玩意儿，水泥电阻。

所以这些东西脑子里都要有个概念：**极限参数是有用的**。但是我不给你们讲了——能看懂。参数自己去看，这块自己去看，弄懂。我再讲实在是没有意义。

> **提示**：极限参数这块我留给你们当作业，自己看教材弄懂。

但有一点我得说清楚：这个参数肯定有用。说真话，**我们买东西受不受骗，就在这儿了**。

### 温度：整族曲线一起动

对于三极管来说，温度对它必然是有影响的。

#### 输入特性左移，正向压降微降

看输入特性：**温度升高，曲线左移**。

这句话反过来读就更有味道：在相同的 $I_{\text{B}}$ 电流下，温度升高会让我的发射结正向压降**降低**。

降多少？PN 结的时候研究过——每升高 1 度，正向压降小 2 到 2.5 毫伏。三极管是一样的：**2 到 2.5 毫伏，每升高 1 度，正向压降将降低 2 到 2.5 毫伏**。

```text
   I_B
    │      ╱╱╱  高温（同一 I_B 下，U_BE 更小）
    │     ╱╱╱
    │    ╱╱╱        ╱╱╱  低温（同一 I_B 下，U_BE 更大）
    │   ╱╱╱       ╱╱╱
    │  ╱╱╱      ╱╱╱
    │ ╱╱╱     ╱╱╱
    │╱╱╱    ╱╱╱
    └────────────────────────► U_BE
```

#### 反向电流的暴涨：ICBO 每 10 度翻一倍

正向这边的影响其实还是比较小的，2 到 2.5 毫伏，量级上就那么大——硅管这儿大约是 600 毫伏，每上升一度才动 2 到 2.5 毫伏，你可以想象它多小。

**但你去比它的反向特性，他就懵了。** 这里还有一个 $I_{\text{CBO}}$，就是集电结反偏时的反向饱和电流：$I_{\text{CBO}}$ **每升高 10 度翻一倍**。

> **易错点**：这两个温度系数量级完全不同，别记混。正向压降是每度零点几毫伏；$I_{\text{CBO}}$ 是每 10 度翻一倍。

#### 输出特性整族上移：穿透电流与放大倍数一起长

看输出特性：温度升高，相应的 $I_{\text{C}}$ 都往上长。

这个很容易理解：你本来 $I_{\text{CEO}}$ 穿透电流就会增大，这里这一块非线性的就会增大，然后继续往上增大；而且 $\beta$ 也会增大。

> **结论**：所以真正受温度影响的主要就是两个量——一个是 $I_{\text{CEO}}$ 穿透电流，一个是 $\beta$ 放大倍数。**温度越高，$\beta$ 就开始增大。**

还有一个细节，我们一直在说一个理想的状态。你看那根曲线——它会怎么样？微微上倾的，往上走的。

什么意思？$U_{\text{CE}}$ 增大，实际上 $I_{\text{C}}$ 最后还是要增大一点，只是增大的幅度非常小。但这个特性是真实存在的，它是斜的。

只不过我们很多计算现在都用近似来看：近似看的话就是 $I_{\text{C}}$ 和 $I_{\text{B}}$ 成比例。实际上 $I_{\text{B}}$ 还是会随着 $U_{\text{CE}}$ 微微上升，但在考虑放大作用的时候，我们可以先把它忽略不计。

### 光电三极管与光电耦合器

除了温度的影响之外，晶体三极管还有别的门类——光电三极管。

光电三极管是什么？实际上从它的内部来看，它是一个**光电二极管再加上一个晶体三管的电流放大**。所以功能上比光电二极管更强大一些。它的电流和光照成比例——说白了，它就是一个光电传感器。

#### 两边电气上彻底绝缘

这个地方再发展发展，我们可以把它发展成**光电耦合器**：这块放一个发光二极管，然后把发光二极管和它封到一起去。这边电流过来，电流的大小控制发光二极管的光照亮度；光照亮度又传到那边，控制那边的电流。

> **提示**：同学们会不会觉得这是吃饱了撑的？为什么那个电流不直接过来？

你想到一点吗？**这边和那边电气上完全绝缘，没有任何关系。**

最简单的例子：我要测量 50 万伏高压上的信号，我用这种方式、用光电耦合的思想，两边的电气就是绝缘的。

#### 再往前一步：光缆与光纤

还有这种思想再往下扩充：中间这个光不是直接放在一起的，光是通过**光缆、光纤**去传输的。这样我这两个器件之间的距离、信号的传递，就可以变成用光信号来传递——不是用电信号传递。

> **结论**：光信号传递的特点是**受干扰非常小**。

你用电信号敢传那么远吗？像海底的光缆那么长，基本传不过去——"死得差不多"。电信号传不过去，光信号就没问题：把它先变成光，通过光纤过去，再进来。

别小看这么一个小小的东西。把它拓展出去，就是我们身边很多很多正在应用的事情。所以我一直说，模拟电子技术是咱们学工科的人都应该学的一个东西——它是很多东西的拓展。这玩意儿你懂了，往外一拓展，原理一下就明白了。

## 让栅极几乎不耗电：MOS 管从耗尽层走到恒流区
> 对应块：BLK08 | 覆盖分集：P08 | 块标题（分集名）：《08-MOS管的工作原理_4K》

上节课我们把晶体三极管整个的特性都给大家分析了一遍，后面第二章会讲它的使用。今天换一个主角。

晶体三极管的出现，实际上是我们固体电子技术、或者说固体半导体电子技术的开端。但真的现在在集成电路里用得非常非常多的是什么东西呢？是场效应管，是另外一种东西。

场效应管实际上最早比晶体三极管晚了一两年出来，但是真正做出 MOS 场效应管的话要晚了十年，上世纪 60 年代才出来。可是它的出现，又使得我们的电子技术产生了一次非常大的进步。

### 集成电路真正的瓶颈不是速度，是功率

场效应管最大的好处是什么？它不费电，它消耗的功率特别小。

为什么功率这么重要？因为一旦消耗的功率大，当你出现大规模集成的时候，你的功率就是你的瓶颈。集成度越高，散热越难。

想一想看，我们最早芯片那么小的时候，我给大家讲过 386 那个芯片——386 那么小的时候，旁边的小风扇就这么小。你现在看 CPU 上的芯片，加一个大散热片，上面堆叠了那么大一个大风扇，干嘛？给它散热。

所以功率消耗的问题变成了我们这种集成电路的一个瓶颈。而场效应管的出现，为这种瓶颈的解决起了很大的作用。当然到最后还会碰到瓶颈，集成度会越来越高，但是到目前为止，它把这个问题解决得很好。

而且场效应管这种管子真的是蛮可爱的一个东西。无论从原理和应用上，狭隘一点说，在某些方面上它的确比晶体三极管要强。

### 靠电场控制，还是靠分配电流

FET 的全称叫场效应晶体管，Field Effect Transistor。它跟三极管最根本的区别在于：它的基本原理是靠**电场效应**来控制这个管子。

晶体三极管靠什么？靠分配电流。我要让 $I_C$ 上面有电流输出的话，我一定要牺牲一部分我 $I_B$ 的电流。$I_B$ 是控制用的电流——注意，是"电流"。

打个比方。你要控制一个机械手，一种方式是我得使劲推到那边，那个家伙也动了，虽然它动的力量比我大，但我毕竟得花挺大劲；还有一种控制方式是什么呢？拿个手指头拨一下，那东西就过去了，然后那边也起同样的作用。

你喜欢哪个？第一个很有质感是吧？但是真到你俩都干 8 个小时活的时候，一天下来你就觉得——除非你想锻炼身体、锻炼肌肉。

而 $I_B$ 恰恰就是我要付出功率的地方。因为你有电流了，我那块一定是有电压的，所以我在控制上要付出比较大的功率。

而电场效应一个好处是什么呢？几乎是没电流的。没电流的话，几乎是没有功率付出的。也就是说，我从控制的回路上来讲，消耗的功率非常非常小。这是它这种管子的一个非常大的好处。

而且它的输入电阻非常高，因为它没有电流。输入电阻高有什么用？意味着信号源几乎不用出力就能把这个管子推动起来，这在级联的时候意义非常大。

温度稳定性上，它也占便宜。

| 对比项 | 晶体三极管 | 场效应晶体管 |
| --- | --- | --- |
| 导电的载流子 | 多子和少子都在导电（双极型） | 只有多子参与导电 |
| 输入端要付出的功率 | 要，有 $I_B$ 就得付功率 | 几乎不取电流，几乎不付功率 |
| 输入电阻 | 相对较低 | 非常高 |
| 温度稳定性 | 有少子参与，受温度影响比较大 | 好得多 |

你们回忆一下我给你们解释过的"双极型"：里面同时有两种粒子在导电，对不对？自由电子和空穴，多子和少子都在导电。那么这种管子受温度的影响会比较大——有少子的参与，受温度影响是比较大的。

而场效应晶体管只有一种粒子，多子在参与导电。那同学们就明白了，它的温度稳定性要好得多。

### 两大类：结型与绝缘栅型

从大的方面来说，场效应管分两种：一个是结型场效应管，还有一种我们叫绝缘栅型场效应管。

我以绝缘栅型为主给你们讲解原理，然后把结型的原理带一下。绝缘栅型使用是比较多的，倒不是说结型不用。而且从很大的程度上，绝缘栅型是可以替代结型的很多特性的。我把绝缘栅型的原理和使用方式讲完，结型我们一带就听明白了，就会举一反三。

我们书上把结型讲得很长，那我把绝缘栅给大家讲一讲。

绝缘栅管子实际上产生得比较晚，是 1962 年造出来的——就我刚才说的，几乎比晶体三极管晚了 10 年。

这个管子另外一个名字，叫做金属-氧化物-半导体场效应晶体管，全称 MOSFET，或者简称为 MOS 管。在它的基础上，人们又造出了 CMOS 电路。不知道有多少同学知道 CMOS？你们用电脑对不对？如果是台式机的话，BIOS 的设置里面有个叫 CMOS 设置，它那里面就是 CMOS 电路。因为 CMOS 电路可以用作存储等等一大堆的东西，它耗电量特别小。所以你就可以看到这种东西对我们现在电子技术的推动。

### N 沟道增强型 MOS 管的结构

我们以 N 沟道增强型 MOS 管来介绍它的基本工作原理，先看它的结构。

一个 P 型的、掺杂浓度比较低的 P 型大半导体。我说"大"，实际上它很小，相对这几个东西它大一点。然后在这上面扩散了一个 N 型区，在这里又扩散了一个 N 型区。

在这块 P 型半导体上接一个电极。我们把这个大的 P 型半导体叫做**衬底**，在衬底上接的电极叫 **B**。然后我在其中一个 N 区上接一个电极出来，叫做 **S**；另一个 N 区上接一个电极，叫做 **D**。

这一层是什么呢？二氧化硅。大家知道，就玻璃那玩意儿，对不对？绝缘的。这层二氧化硅特别薄，非常非常薄。然后在二氧化硅上趴了一个基板，这个基板接出一个极 **G**，这个 G 叫做**栅极**。

```text
                       │  G  栅极（控制极）
        ┌──────────────┬─────────────┬───────────┐
        │      二氧化硅 SiO2          极薄、绝缘          │
        └──────────────┴─────────────┴───────────┘
        │              │             │           │
        ┌──────────────┬─────────────┬───────────┐
        │            n+            n+            │
        │            S 源           D 漏           │
        │                反型层（沟道）                 │
        └──────────────┴─────────────┴───────────┘
        │              │             │           │
        ┌──────────────┬─────────────┬───────────┐
        │                 P 型衬底（电极 B）            │
        └────────────────────────────────────────┘
```

读图：栅极 G 坐在极薄的二氧化硅绝缘层上，S 和 D 是两个 N 型区，衬底是 P 型半导体并引出电极 B，S 与 D 之间那层是沟道所在的区域。

现在能知道它为什么叫**绝缘栅**了吧？因为栅极跟谁都绝缘的，都做绝了。D、S，随便什么玩意儿，它就孤零零地趴在二氧化硅上，跟谁都绝缘。跟谁都绝缘，你控制是控制这个栅极 G，G 上不可能有电流，G 上没电流。那肯定省电啊。

这里的名字也都可以跟晶体三极管马上对应起来：

| MOS 管 | 晶体三极管 | 作用 |
| --- | --- | --- |
| G（栅极） | B（基极） | 控制极 |
| S（源极） | E（发射极） | 载流子的源泉、发源地 |
| D（漏极） | C（集电极） | 载流子的漏出处 |

但你们注意：**原理是不一样的**。名字像不等于原理像，这一点后面讲原理的时候会反复看到。

### 一个死局：源漏之间隔着二氧化硅

现在看工作原理。

先提一个要求。三极管其实有两大作用，一个开关作用，一个放大作用。那我想要让 MOS 管跟它有同样的作用的话，我要 MOS 管有放大作用，那我肯定要我的栅极去控制某一个输出量。你要不控制电压，要不控制电流，总归是一个东西要控制才能放大。就像 $I_B$ 控制 $I_C$ 似的。

那么从工作原理我们来看一看。

其实你乍一看这个结构的时候——同学们看啊，你看这儿的时候没法用。因为什么？很明显，既然已经定义了这是 S，这是 D，对不对？其实脑子里就很清楚，我 S 和 D 之间一定得有电流，对不对？

可能吗现在？这是二氧化硅啊？这要是二氧化硅，我们同学们咱们太有才了，那彻底死了。你想想，把一个漏极整个包在二氧化硅里面，那那就不是绝缘栅了，整个绝缘体了，各个地方都绝缘。

这块我一直提醒你们注意：有 P 和有 N 交界的地方就一定有什么？有 PN 结，对不对？所以这两个东西都是 PN 结。

没法玩了。这个事情。你 S 这块出来的这个东西，能到 D 吗？要跨越千山万路啊。

你看看，其实如果我们用水池子来形容的话，人家这块是个小水塘，这块是个小水塘，里面都有那个自由电子，是那种载流子，在小水塘里。但是这小水塘之间过不来——你这个水没有那个渠，看到吗？没有那个可以通的那个渠，过不来。而且这一道堤坝，中间这块你还过不去。这块你的自由电子想倒这里来的话，就是一个死。因为人家那是什？P 区。

那造出来是废物了？你怎能让它有用？你想想你怎么能让它有用？它不一般的有用，它还得有很大的用处。

原理很简单的。

在讲原理之前，先说一个构造上的细节。绝缘栅型这种管子有两种构造。一种呢，我们看到外面还是三个极、三个电极，这三个电极它怎么出来的呢？实际上是在出厂的时候，我就会把这个源极和这个衬底接在一起。那么这块就形成一个极。还有一种呢，如果是外面有四个极的话，那就是衬底是单独的。

一旦衬底是单独的，同学们，**D 和 S 你可以互换，D 和 S 没区别**。不像我们 C 和 E 之间区别很大，对不对？如果把 B 拎出来的话，那么 D 和 S 可以互换。但是连在一起的话，我们习惯上把和 B 连在一起的那个都叫做 S，源极。

你看，我这样连上之后，我的 D 和 S 之间……所以我在做工作原理分析的时候呢，同学们可以看得很清楚。

### 一次只动一个变量

这里插一个分析方法，它比这一节任何结论都重要。

我要加的电压有好几个地方可以加：栅源可以加，D 和 S 之间也可以加。如果一起加就麻烦了，事情就变复杂了。

当我有多个变量控制一个东西的时候，我比较简单的方法是什么？**一个一个来看，一个一个来看，然后再谈它们的耦合问题。**

所以我 $U_{DS}$ 我先让它等于 0，然后我加一个 $U_{GS}$ 上去。

> **提示**：记住这个"一个一个来"的习惯。你后面分析四端管子、分析多电源电路，凡是变量超过一个的，都可以先固定其余变量、只扫一个，画出它的"特性曲线"，最后再把几条曲线放到同一张图上比较。今天 MOS 管的曲线就是这么来的。

### 栅压把死局救回来：耗尽层、反型层、可变电阻区

我 $U_{GS}$ 加上去，$U_{GS} > 0$，开始加。

同学们看，第一步，当你开始加 $U_{GS}$ 的时候，你会发现一个现象，情况变得越来越糟。什么呢？人家为什么把这个 PN 结都画在这儿了？你开始一加电压的话，从上向下的电场会把附近的空穴怎么样？在电场力的作用下全踢走，都踢走。

使得这里就变成了一个什么呢？几乎没有载流子的**耗尽层**。看到吗？我的耗尽层变大了。

你如果就加到这儿你结束了的话，那事情就 over 了，没故事了。形象点，这出现了黎明前的黑暗。

你接着再往下加电压，再大，把这个 $U_{GS}$ 再往上升，你会发现什么？这底下它有少子啊，这区域很大，它的少子是什么？自由电子。这时候它干的工作是有两样了：一个是把空穴全踢跑了；第二件事是把这个自由电子怎么样？吸上去了。

我每次看到这我都觉得这很可爱。这自由电子上去了，我们就形成了一个什么呢？沟道。自由电子形成了沟道，像把这两个水塘之间挖出了一个渠。

如果用我们中国的神话故事来讲的话，我特别形象地想牛郎织女——那些喜鹊被吸引上去了，搭成了一个鹊桥，然后这块就导通了。你管它是鹊桥也好，是沟道也好，总之它构成了一个**反型层**，看到吗？使得它们之间导通了。这个沟渠挖出来了。

```text
U_GS 还没加够                                         U_GS 继续加大                             
                                                                                                
               │  G  栅极                                            │  G  栅极                 
    ┌──────────┬─────────┬───────────┐                    ┌──────────┬─────────┬───────────┐    
    │     二氧化硅 SiO2                  │                │     二氧化硅 SiO2                  │
    └──────────┴─────────┴───────────┘                    └──────────┴─────────┴───────────┘    
    │          │         │           │                    │          │         │           │    
    ┌──────────┬─────────┬───────────┐                    ┌──────────┬─────────┬───────────┐    
    │        n+        n+            │                    │        n+        n+            │    
    │        ~  ~  ~    耗尽层          │                 │        =========  反型层          │ 
    └──────────┴─────────┴───────────┘                    └──────────┴─────────┴───────────┘    
    │          │         │           │                    │          │         │           │    
    ┌──────────┬─────────┬───────────┐                    ┌──────────┬─────────┬───────────┐    
    │            P 型衬底 B             │                 │            P 型衬底 B             │ 
    └────────────────────────────────┘                    └────────────────────────────────┘    

空穴被电场踢走，只剩耗尽层，            自由电子被吸到氧化层下面，
源漏之间仍然不导通                      形成 N 型沟道，开始导通   
```

读图：左图栅压还小，栅极电场只把沟道区的空穴驱走，留下耗尽层，源漏之间并不导通；右图栅压继续加大，耗尽层里的自由电子被吸到氧化层下面，源漏之间出现一条电子通道，这就是反型层。

所以这个沟道里面的多子是谁？自由电子，对不对？这个沟道的名字叫什么？是什么型沟道？N 型沟道。现在同学们能知道它为什么叫 N 沟道了吧？它把这种自由电子吸上去，所以形成了 N 沟道。

那么什么时候沟道开始形成呢？这时候有一个电压我们叫做 $U_{GS(th)}$，这个叫**开启电压**。th 就是 threshold，阈值，对吧？当我的 $U_{GS}$ 大于 $U_{GS(th)}$ 的时候，我的沟道开始形成。

$$
U_{GS} > U_{GS(th)} \quad \Longrightarrow \quad \text{沟道形成，D、S 之间导通}
$$

反过来很清楚：在 $U_{GS}$ 小于 $U_{GS(th)}$ 的时候，没有沟道，还是在绝缘的状态下，D、S 之间还是没有电流。

#### 沟道宽度，就是一个被电压捏住的电阻

这个沟道一旦形成，有件很可爱的东西出现了。

如果这个时候我的 $U_{GS}$ 不变，我问你们沟道的宽度会不会变？沟道宽度是不是几乎也就不变啊？沟道的宽度和什么相关啊？实际上就 $U_{GS}$ 大小，对不对？你 $U_{GS}$ 越高，沟道越宽；$U_{GS}$ 越小，沟道越窄。是这样吧？

那么这个沟道的宽窄决定了什么？你觉得是什么？是不是电阻啊？对啊，是不是电阻啊？

所以你沟道越宽，D 和 S 之间的电阻怎么样？越小；沟道越窄，D 和 S 之间的电阻怎么样？越大；你沟道不变，D 和 S 之间的电阻怎么样？不变。

看没看到？你得到了什么？D 和 S 之间得到了一个**可以用电压控制的可变电阻器**。

是不是啊？这以前也没玩过吧？你得到了这样一个东西。于是 $U_{GS}$ 决定了谁呀？它决定了 $R_{DS}$。

当你 $U_{GS}$ 不变的时候，我的 $R_{DS}$ 也不变，表现为一个固定的电阻；$U_{GS}$ 变，我 $R_{DS}$ 也变。所以在 $U_{DS}$ 还没加的这个状态下，我的 D 和 S 之间、或者说我这个场效应管就像一个可变电阻区、可变电阻器一样，它是一个电压控制的可变电阻器。

### 再加漏压：预夹断与恒流区

既然它已经变成一个阻值的东西了，下一部分就是显而易见非常简单的事情了。问你们怎么让 D 和 S 之间有电流啊？怎么呢？有电压就有电流。你不是一个电阻吗？我在电阻两端加上一个电压，自然就有电流了。

所以第二步，我们让 $U_{DS}$ 不再等于 0 了，而且让它逐渐上升，前提是我让 $U_{GS} > U_{GS(th)}$ 并且保持不变。

那么你们猜这样会什么样呢？当然我加电路肯定是这样加了。这个电路，如果让我来画曲线的话，我可以很清楚地画出来——我们就在猜，猜这个曲线。

这块是我的 $U_{DS}$，这里是 $I_D$，$I_D$ 就是 $I_{DS}$。

我最开始的时候一定是这样，这同学们能理解吧？为什么这样？因为这时候 $R_{DS}$ 是一个电阻啊，我在电阻两端加电压，那电阻两端的电压和电阻通过的电流自然是一根直线。

我会往上涨，这时候它表现为一个固定的电阻。这个电阻的大小跟谁相关？也就是说这个斜率跟谁相关？$U_{GS}$。非常棒。它是对应某一个固定的 $U_{GS}$，我给它起名 1，对吧？$U_{GS1}$。

接着往上涨，涨成什么样呢？随着 $U_{DS}$ 的增大，这块开始变倾斜了。为什么？

我问你们，沟道的宽度是和 $U_{GS}$ 相关，对不对？咱们直接说的是 $U_{GS}$，但实际上是哪两点之间的电压？没错吧？这个电压越大，这个东西越宽，没错吧？现在同学们来看，这点的电位和这的电位还相等吗？不相等。这里比这高，高了多少？$U_{DS}$。

所以同学们可以看到，我这两点之间的电压差还是原来的电压差 $U_{GS}$，对不对？而这两点的电压差已经变成什么了？$U_{GS} - U_{DS}$。后面这块已经变成 $U_{GS} - U_{DS}$，电压差变小。随着 $U_{DS}$ 的不断加大，这块的电压差不断减小，这块会越来越窄。但是在它没有封死之前，这块的阻值几乎还是保持不变。

这个情况在什么时候出现？它减去它等于什么？也就是说那两点之间的电压差变成了 $U_{GS(th)}$。

$$
U_{GS} - U_{DS} = U_{GS(th)}
$$

看到吧？这样的话，我们就说出现了一个叫什么呢？**预夹断**。

#### 预夹断为什么不会真夹断

我问你们，它会不会真夹断？真的说断了，没电流了？**不会的。**

一旦断了没电流了，那这块就没压降了；没电流没压降了，它马上这个缝隙又给打开。所以它是一个自动的平衡状态。这里并没有真的夹断，而这里看着我们画的是断了，实际上这里留了一个小缝，一个缝隙，非常小的一个缝隙。**它是关不断的**，除非你一开始就关断的，知道吧？这里是关不断的，它已经关不段了，只是说变成一个很小的缝隙。

```text
U_DS 很小                                   U_DS 增大                                     出现预夹断                              
              │  G  栅极                                  │  G  栅极                                    │  G  栅极                
    ┌─────────┬───────┬────────┐                ┌─────────┬───────┬────────┐                  ┌─────────┬───────┬────────┐        
    │     二氧化硅                 │            │     二氧化硅                 │              │     二氧化硅                 │    
    └─────────┴───────┴────────┘                └─────────┴───────┴────────┘                  └─────────┴───────┴────────┘        
    │         │       │        │                │         │       │        │                  │         │       │        │        
    ┌─────────┬───────┬────────┐                ┌─────────┬───────┬────────┐                  ┌─────────┬───────┬────────┐        
    │       n+      n+         │                │       n+      n+         │                  │       n+      n+         │        
    │       =========          │                │       ======             │                  │       ==== .             │        
    │          沟道均匀            │            │          靠漏极端变窄          │            │          缝隙向源极端伸长        │
    └─────────┴───────┴────────┘                └─────────┴───────┴────────┘                  └─────────┴───────┴────────┘        
    │         │       │        │                │         │       │        │                  │         │       │        │        
    ┌─────────┬───────┬────────┐                ┌─────────┬───────┬────────┐                  ┌─────────┬───────┬────────┐        
    │            P 型衬底 B       │             │            P 型衬底 B       │               │            P 型衬底 B       │     
    └──────────────────────────┘                └──────────────────────────┘                  └──────────────────────────┘        

两端压差 = U_GS            靠漏极端压差                   压差降到 U_GS(th)
沟道均匀，R_DS 不变        = U_GS - U_DS，沟道变窄        这一端沟道失效   
```

读图：$U_{DS}$ 很小时沟道均匀；$U_{DS}$ 增大，靠漏极那一端的压差降到 $U_{GS} - U_{DS}$，这一端先变窄；压差降到 $U_{GS(th)}$ 时这一端先失效，这就是预夹断。

这个时候很有意思的现象就出现了。你再加大这个 $U_{DS}$，你会发现这个缝隙会变长。这个缝隙变长换来的代价是什么呢？$R_{DS}$ 电阻变大。显而易见，你缝隙越长，$R_{DS}$ 电阻越大。然后你得到了一个很有意思的东西，是什么呢？这个时候你会发现 $I_D$ 几乎不变了。

开始预夹断了，然后预夹断之后它怎么样呢？我就画得有点太理想了，实际上它还是会往上稍微倾斜一点，同学们。但是几乎这块不变了。

近似地出现了一个什么东西呢？**恒流**。因为你增加的电压都去抵抗那个增加的电阻了。

这里可以再补一句机理，它恰恰是你在前面那个"自动平衡"里埋下的伏笔：电流一小，它和那个缝隙之间的关系就会发生变化——自由电子在这个窄缝里高速通过，所以缝隙的电阻阻值会增大。这个增大正好和电压的增大抵消，出现这块近似一个恒流。它实际上在自己的平衡里自动地平衡。

#### 一族曲线：$I_D$ 只听 $U_{GS}$ 的话

所以这个区域以预夹断点为分界，它出现了两个部分。

第一个部分电阻是不变的——注意，是针对 $U_{GS1}$ 不变而言的。而 $U_{GS}$ 变的话，这个电阻就变，所以这个区域是一个**可变电阻区**。

而这个区域是一个什么区域？**恒流区域**。这个恒流区域就有意思了。解释出来的话，一旦进入恒流区域，这里的电流 $I_D$ 只听谁的话？只和 $U_{GS}$ 相关。

我如果再画一个，我给你们个条件：$U_{GS2} > U_{GS1}$，这块应该表现成什么样？这个线是在上面还是在下面？**上面。**

为什么？因为 $U_{GS2} > U_{GS1}$ 的话，我 $R_{DS}$ 电阻就小——沟道宽，我电阻就小。电阻小的话，我的斜率就大，相同的电压下电流就高。

那么你再看这里，然后再有一个小一点的 $U_{GS3}$。你把这些东西放在一起，你就会发现什么呢？你的 $I_D$ 只和这个 $U_{GS}$ 相关。

```text
     I_D
     ↑
     │
     │
     │               ###########################################   U_GS2
     │             ###
     │            ##
     │          ###
     │         ##    +++++++++++++++++++++++++++++++++++++++++++   U_GS1
     │        ##   +++
     │       ##  +++
     │     ###++++    ..........................................   U_GS3
     │    ##+++   .....
     │  ##+++......
     │ #+.....
     │....
     └──────────────────────────────────────────────────────────→  U_DS

     每条曲线对应一个固定的 U_GS。从原点到预夹断点是一段直线，
     对应可变电阻区；预夹断之后曲线几乎水平，那就是恒流区。
```

读图：三条曲线分别对应 $U_{GS2} > U_{GS1} > U_{GS3}$，栅压越大曲线越高、饱和电流越大；每条曲线自己的直线段是可变电阻区，水平段是恒流区。

说明什么？说明在这种恒流区，你得到了这样一个向往已久的特性：**栅极和源极之间的电压能够控制 $I_D$ 的电流**，换句话说，$I_D$ 电流和栅极、源极之间的电压成比例。

> **易错点**：千万别在可变电阻区里就说"$U_{GS}$ 和 $I_D$ 成比例"。在那个区域里它们成比例吗？不是的，不是一个单一的比例关系，$U_{GS}$ 和 $U_{DS}$ 共同决定了 $I_D$。而在恒流区里，只有 $U_{GS}$ 自己在决定 $I_D$。这就是为什么放大一定要工作在恒流区。

我们把这种控制关系拉出来的话，就近似于我的 $I_B$ 和 $I_C$ 的关系。这是我要用场效应管做放大的那个状态。

### 三个工作区域

所以场效应管的应用、它的工作状态很简单：

如果你的 $U_{GS}$ 没有大于 $U_{GS(th)}$，大家什么也不用谈，**截止**——D、S 之间是截止，沟道没有形成。

后面就出现两个了。当你的 $U_{GS} > U_{GS(th)}$ 了，如果你的 $U_{DS}$ 不过分、不很大的话，没有出现预夹断的话，这个时候 D 和 S 之间表现为一个电阻。这个电阻的大小由谁决定呢？由 $U_{GS}$ 决定。这个区域叫做**可变电阻区**，也就是说在这个区域里面你可以得到一个压控的可变电阻器。

但是，当你的 $U_{DS}$ 足够大，让它出现了预夹断之后，事情并没有变坏，而是你进入了另一个境界：这个时候你的 $U_{GS}$ 可以控制 $I_D$ 了。

> **结论**：$U_{GS}$ 什么时候能控制 $I_D$？预夹断之后进入恒流区，**这是前提条件，不是什么时候都可以控制的**。

| 工作区域 | 判据 | 管子表现 | 我们拿它做什么 |
| --- | --- | --- | --- |
| 截止区 | $U_{GS} \le U_{GS(th)}$ | 沟道没形成，D、S 之间没有电流 | 开关的断开态 |
| 可变电阻区 | $U_{GS} > U_{GS(th)}$，且 $U_{GS} - U_{DS} > U_{GS(th)}$ | 表现为一个由 $U_{GS}$ 决定的电阻 $R_{DS}$ | 压控可变电阻 |
| 恒流区 | $U_{GS} - U_{DS} \le U_{GS(th)}$ | $I_D$ 几乎只由 $U_{GS}$ 决定 | 放大 |

你可以用这个区域去放大了；可以用这个区域去有可变电阻；可以让它导通；可以让它截止。这就是场效应管。

那么整个的这个场效应管，我们称之为绝缘栅型的、N 沟道增强型场效应管。

"N 沟道"现在同学们知道了。**增强型**什么意思？我一定得有 $U_{GS} > U_{GS(th)}$ 这个增强的过程，它才能导通。这是它和结型不同的地方——结型是天生导通的。

### 回头看符号：名字里的每一段都有出处

现在回头看一下它的符号，能不能理解？

这是增强型的符号，很形象吧？栅极是绝缘的，看到吗？栅极跟谁都不搭界，自己漂在这儿。漏极、源极中间想拉一个沟道出来，看到吗？这沟道天生是什么？**天生是断的**。你需要增强了之后，它才能形成。然后这是衬底 B。

这个箭头是什么含义？大家注意，我们这个箭头的指向都指的是 **PN 结方向**。你去想想，三极管里是不是 B 和 E 之间那个箭头也是指 PN 结方向？

我沟道是 N 型，对不对？我的衬底是什么？P 型。PN。一看这箭头往这……这叫什么沟道？N 沟道。懂了吧？

所以全读出来的话：N 沟道、这块由于天生是断的所以需要增强、增强型、绝缘栅型场效应管。

那另外那个符号上的 P、N 呢？说明沟道是 P 型的，对吧？所以它是一个 P 沟道增强型 MOS 管。

```text
                        │  G  栅极（此时不加电压）
        ┌───────────────┬──────────────┬───────────┐
        │      二氧化硅里固定正电荷                + + + +   │
        └───────────────┴──────────────┴───────────┘
        │               │              │           │
        ┌───────────────┬──────────────┬───────────┐
        │             n+             n+            │
        │             S 源            D 漏           │
        │                 正电荷     正电荷              │
        │                天生就有的 N 型沟道               │
        └───────────────┴──────────────┴───────────┘
        │               │              │           │
        ┌───────────────┬──────────────┬───────────┐
        │                  P 型衬底（电极 B）             │
        └──────────────────────────────────────────┘
```

读图：两个符号的区别只在漏、源之间那条线——增强型画虚线，表示沟道天生断开；耗尽型画实线，表示沟道天生就存在。栅极那一竖永远是断开的，这就是"绝缘栅"。

### 能不能天生导通：耗尽型 MOS 管

那我刚才提到了一个问题——我说它天生是断的，我得给它加点外力，把 $U_{GS}$ 让它大于 $U_{GS(th)}$ 了，它才能形成沟道，天生沟道是没有的。

我能不能做成一种天生沟道就有的呢？

因为结型你不用加电压，它一样导通，它就导通，**天生就能导通**——这是结型它自己能做到的。

那我绝缘栅能不能做到这一点呢？这回答当然是肯定的：**N 沟道的耗尽型 MOS 管**。当然也会有 P 沟道的耗尽型 MOS 管。

它会怎么样呢？它的基本原理我给你们画。

还是二氧化硅这一层，只不过我在这层二氧化硅里干了一件什么事呢？我让二氧化硅里面天生就固定一大堆正电荷，让它天生带正电。

带正电强到什么程度呢？带正电不就有电场吗，对不对？强大到**我这个沟道天生产生**。

```text
增强型：沟道天生断开              耗尽型：沟道天生存在
      │  G                              │  G          
┌──────┬────────┐                 ┌──────┬────────┐   
D ─ · · · · · ─ S                 D ─────────────── S 
└──────┴────────┘                 └──────┴────────┘   
      │  B                              │  B          

源漏之间是虚线，要靠 U_GS                 源漏之间是实线，不用增强
增强，超过 U_GS(th) 才有沟道              天生就有沟道            
```

读图：二氧化硅内部预先埋设的固定正电荷形成内建电场，把沟道区的自由电子吸引上来，于是源漏之间天生就有一条 N 型沟道，栅压都还没加。

那就是让我这里天生有沟道。天生有沟道的话，这是我的 G，这是我的 S，这是我的 D，这是我的衬底 B。

当然这种东西拿过来你就可以用了，D、S 直接加上电压就可以工作。

$U_{GS}$ 加正向电压，这沟道会变大；$U_{GS}$ 加反向电压，沟道会变小。你加到什么时候这沟道没有呢？那么有一个参数叫做 $U_{GS(off)}$，$U_{GS(off)}$。我们把这个电压叫做什么？**夹断电压**。也就是说要加到某一个负电压值的时候，它才能真正关断，我让它关断。

$$
U_{GS} < U_{GS(off)} \quad \Longrightarrow \quad \text{沟道夹断，管子真正关断}
$$

那么在这个 $U_{GS}$，也就是说只要我的 $U_{GS}$ 大于这个 $U_{GS(off)}$，我这个场效应管都可以用，一直属于开通的在用，它都没截止。也就是说，$U_{GS}$ **既可以是正的，也可以是负的**。

其他的用法跟增强型一样：把增强型的 $U_{GS(th)}$ 换成耗尽型的 $U_{GS(off)}$，三个工作区域的判据照旧，只是管子的默认状态从"天生断开"变成了"天生导通"。

那么耗尽型的场效应管，同学们可以看到它的符号——跟增强型有什么区别？**天生沟道就形成了**，所以画成实线。

### 先说一段题外话：当日事当日毕

今天早上我开车过来的时候特别困，因为我起得早。我们有一个老师习惯每天早上六点钟起床，我就学他，结果就有点麻烦——晚上睡不着。倒不是焦虑，就是晚上那一段时间工作效率特别高，过了九点钟以后思路越转越快，一写东西就忘了时间，一写就写到十一点、十二点，停不下来了。

但我当学生的时候，生活非常规律。大一那会儿我每天晚上跑到教室自修到十点钟回寝室，十点半上床睡觉，第二天早上六点半就起来了，睡七个半到八个小时，那个效率反而不低。

所以我只是跟你们谈一个效率问题、工作效率问题。大家要**高效率地学习**，而不是去拼时间——拼时间是没有意义的。什么叫高效率？我总结了这么两条。

第一条，最短的时间完成最多的事情。

第二条，**千万不要积攒工作**。工作一旦压下来就麻烦了。我手上的事情如果全要拿出来做，够三到五个人做的。你要是有一点点积累，越攒越多，那是个恶性循环。一旦积攒到最后，人会进入一种什么状态？叫作**死猪不怕开水烫**——到那个时候就比较麻烦了。

我最怕的就是这个：出去开会，除非万不得已，后面的旅游我从来不参加，会议一结束马上返回。因为我太怕了——后面旅游玩一天，我得用两三天去补这后面的时间，补我落下的那些工作。而那些工作不是说你落了就可以落了。

所以高效率就是两句话：最短时间干最多的事；当日事、当日毕。宁可今天我稍微多花一点时间，但今天的事情今天干完，这样我是最高效的。学习上完全一样：今天不懂的事情，我这周一定要搞明白。否则积攒下来，结果就是这一门课你越来越憎恨它，到最后你变成想办法能过就不错了。我整个大学期间很少出现这种状态，基本上都是搞定的，到最后考试的时候，我能处于一种给人答疑的状态。

然后再讲一个学习的体会，我一直觉得：把一个事情**看懂**，你还不如说把它**说懂**。你觉得你看懂了，不用给任何人讲，自己给自己讲一遍、说出来，你会发现你又不懂了。等你把自己都讲懂了，再去给第三者讲——如果你能把别人讲懂，那才叫真厉害。而且你给别人讲的时候，往往会发现，原来我这里还是不懂。

我大学期间愿意给别的同学解答问题，就是这个原因。我发现我从中受益匪浅：我以为我都学懂了，实际上给别人讲的时候发现我不懂了；当我把他讲糊涂的时候，我自己就懂了；讲到他能懂，我再给他讲一遍，他也就懂了。这个层次跟你自己看书那个层次，真的不在一个层面上。

所以牛津和剑桥的教育最核心的一点，就是用它的导师制去推动学生和学生之间、学生和老师之间的讨论。导师制是分组的，讨论之前你不能跑去瞎掰，所以这一组学生自己会先把这个讨论到有深度，再去跟老师讨论。我们也可以这么做。

> **结论**：当日事当日毕，看懂不如说懂，说懂不如讲懂。剩下的时间干什么？干什么都行，就别攒着。

好，正题开始。

### 结型场效应管的结构

结型场效应管的结构很有意思。你说它是三明治吧，它也不是三明治。

你看这块示意：一块 N 型，中间是一块 N 型——看到了吧？然后我在这两面各掺杂了两个高浓度的 P，这儿一个 P，这儿一个 P。掺杂两个高浓度的 P 区，在 N 的两面各接一个：一头接 S，另一头接 D。然后我把这两个 P 接在一起，一起给 G，也就是栅极。栅极控制了这两个 P 区。

```text
                  G
        ┌─────────┴─────────┐
        │                   │
    ┌───┴────┐         ┌────┴───┐
    │   │ P+ │         │ P+ │   │
D ──┤   └────┘ N 沟道  ┌────┘   ├── S
    │                           │
    └───────────────────────────┘
```

读图：中间那一整块 N 型衬底，就是源极与漏极之间的导电沟道；它上下两面各扩散一个高浓度的 P 区（P+ 表示高浓度 P 掺杂），两个 P 区并在一起向上引出栅极 G；N 型衬底左右两端分别引出漏极 D 和源极 S。

这时候自然而然就形成 PN 结了，对不对？如果我栅源之间现在加的是零电压，你看一下，是不是跟我们那个耗尽型的一样——**天生就有沟道**？中间这个 N 是导通的，D 和 S 之间就可以导通。

那我怎么控制它呢？我在 $U_{GS}$ 之间加反压。这不就是 P 对着 N 吗？我加的 $U_{GS}$ 是负值，使它反偏。反偏越厉害，耗尽层越宽；耗尽层一宽，夹在中间的沟道就变窄了。

是不是跟我们那个很像？我们那个是**加大**，把沟道拽宽；而我现在是**加反压**，把沟道变小。跟耗尽型很像：耗尽型天生就有一个沟道，你加反压沟道就会变小，加到某一个程度的反压就会出现**夹断**。

夹断很容易理解吧？结型场效应管的基本工作原理就是加反压，让这个沟道越来越小。

> **结论**：只要你 $U_{GS}$ 不变，沟道就不变；固定为某一个 $U_{GS}$，沟道就固定住了。夹断电压叫 $U_{GS(off)}$。注意，这个是**真夹断**，不是预夹断——夹断以后中间就不导电了。

你会发现它跟耗尽型 MOS 管非常接近，对吧？人家那个真的是由自由电子构成的沟道，加反压它会变小；它这个是用 PN 结来夹，加反压去夹，很有意思。

```text
      U_GS = 0           U_GS < 0          U_GS = U_GS(off)
   ┌────────────┐     ┌────────────┐     ┌────────────┐
   │            │     │▓▓▓      ▓▓▓│     │▓▓▓▓▓▓▓▓▓▓▓▓│
   │   沟道     │     │   沟道     │     │  （夹断）  │
   └────────────┘     └────────────┘     └────────────┘
    D          S       D          S       D          S
```

读图：俯视看漏源之间那条通道。`▓` 表示 PN 结反偏挤出来的耗尽区，那里已经没有自由载流子；中间空白的地方才是还剩下的导电沟道。左格零栅压时整条都是沟道，往右 $U_{GS}$ 越来越负，两侧耗尽区越来越宽，沟道越来越窄，最右格沟道完全消失，就是夹断。

### 接上漏源电压：可变电阻区和恒流区

那它到底该怎么工作？想一想，$D$ 和 $S$ 之间加上电压，工作原理跟前面一样——沟道不是在那儿吗？我 $D$ 和 $S$ 一加电压，上面那个 PN 结会变厚，对不对？加得越大，上面变得越厚。加到最后怎么样？**预夹断**了吧。

所以它一样也会分成这样的区域。在预夹断之前，它是一个固定的电阻，也就是**可变电阻区**：我 $U_{GS}$ 不变，电阻就不变；你 $U_{GS}$ 变，电阻就变。$U_{GS}$ 不变的时候电阻不变，$U_{DS}$ 和 $I_D$ 之间成正比：

$$I_D = \frac{U_{DS}}{R_{DS}}$$

当我出现预夹断之后怎么样？我 $I_D$ 电流就不变了，$I_D$ 电流出现恒流了。这时候 $I_D$ 电流只和谁相关？只和 $U_{GS}$ 相关，对不对？这就是**恒流区**，也出现了。

一切一切，除了它是一个结型的原理之外，它这个沟道的大小、恒流的出现、可变电阻区，都跟谁一样？耗尽型。

> **结论**：结型场效应管与耗尽型 MOS 管在特性上几乎同构，唯一的差别在栅压的取值范围上——这一点下一节专门讲。

### 与耗尽型 MOS 管的唯一本质差别

我现在问同学们，其实表里已经给出来了，你们看到了吗？它对 $U_{GS}$ 做了一个规定：它可以大于 $U_{GS(off)}$，但是**不能大于 0**。

我当时讲绝缘栅型耗尽型 MOS 管的时候，我给你们规定它不能大于 0 了吗？我说的是：大于 0 就让它那沟道再变宽点而已。它为什么不能大于 0？告诉我——**大于 0 怎么样？PN 结导通了**。非常棒。

大于 0，PN 结就导通了。这一导通你不死定了？这东西还玩什么？这是 P，这是 N，你所谓大于 0 就是这里比这里高、这里比这里高，你这 PN 结就不存在了，直接导通。导通了它就不是结型场效应管了，双结导通，没有沟道这些东西了。所以它要想用，一定得怎么样？**反偏**，让那 PN 结反向截止。

而且 PN 结一旦反偏，大家想一想：绝缘栅 MOS 管的时候，栅源的电阻是很大的，因为它是绝缘的（二氧化硅），$R_{GS}$ 几乎趋向于无穷。结型这里呢？它反偏的时候，$U_{GS}$ 是处于反偏状态，PN 结的电阻依然非常高，只不过是没绝缘栅那么高，但也很高很高。注意啊，它最多有一点点反偏的漏电流、反偏的饱和电流而已；绝缘栅的就更狠，根本几乎没有电流。

所以结型管子跟耗尽型绝缘栅场效应管在实用上有什么区别呢？它不能工作在 $U_{GS}>0$。千万注意，这是它俩本质上的一个区别。

那这样一说，同学们是不是觉得结型肯定能被绝缘栅型完全取代？其实也不尽然，它们各有特点。结型这种管子，输入电阻确实没有绝缘栅型的高，而且不能用于 $U_{GS}>0$ 的区域——当然这是说 N 沟道的，N 沟道；P 沟道就正好反过来，反正你不能让 PN 结导通。

但它有它的好处。它是有一点点漏电流，但这个管子不大容易坏。而绝缘栅的那个管子很娇贵。娇贵在哪？你看它那层二氧化硅，它是绝缘的，对不对？它**特别薄**。如果你没有很好地保护栅极，它的感应电荷就可以把它击穿。因为那电容很小，有一点点电量就会产生很高的电压。它是个小电容，相当于——电容很小，有一点点电荷聚集、寄居在那里，就会有一个很高的电压。其实电压不用很高，因为那层太薄了，太薄的话，不用很高的电压就会产生很强的电场，就会把那块击穿，它就坏了。所以绝缘栅管子很容易坏。

当然有很多保护措施，所以也不存在谁完全替代谁的问题。

> **易错点**：从特性曲线上看，结型场效应管的 $U_{GS}$ **不能跨越正负**（N 沟道全为负、P 沟道全为正），而耗尽型 MOS 管的 $U_{GS}$ 是可以跨越正负的。这是判断一颗管子最直接的一条线索。

### 画不出输入特性，那就画转移特性

那么我们来看一看场效应管的特性曲线。

> **定义**：**转移特性**指在 $U_{DS}$ 取某个定值（且大到使管子工作在恒流区）时，$I_D$ 与 $U_{GS}$ 之间的关系曲线。

场效应管的特性曲线，从举一反三的角度来说肯定也是两根，因为它有三个极：漏极、源极、栅极。但它又不能完全模拟三极管——晶体三极管是有输入特性的，那一块会有特性。这个家伙有没有特性？没有。栅极这端口压根没电流，出不了特性，看到了吗？

所以我们用的叫**转移特性**：它不是对这个有控制吗？我就画恒流区条件下 $U_{GS}$ 和 $I_D$ 之间的关系。

```text
   I_D
    │                          ● I_D0（U_GS = 2U_GS(th)）
    │                      ／
    │                  ／
    │              ／
    │          ／
    │      ／
    │  ／
  0 └──────────────────────────── U_GS
    U_GS(th)
```

读图：横轴 $U_{GS}$、纵轴 $I_D$。$U_{GS}$ 必须超过开启电压 $U_{GS(th)}$ 之后曲线才起来，起来以后就是 N 沟道增强型 $I_D$ 与 $U_{GS}$ 的关系；曲线上特意标出的那一点是 $I_{D0}$，它取在 $U_{GS}=2U_{GS(th)}$ 上。

很明显这是一个 N 沟道增强型的特性。可以看得很清楚，为什么？因为 $U_{GS}$ 大于 $U_{GS(th)}$ 之后它才导通，对不对？看到了吧？导通之后，这就是它和 $I_D$ 之间的关系。

其中 $I_{D0}$ 是当 $U_{GS}$ 等于两倍 $U_{GS(th)}$ 的时候所对应的这样一个点。为什么非要给出这个点，等一下看。

那么我问同学们，这根曲线得出来有没有条件？第一个条件：**场效应管一定工作在恒流区**，换句话说 $U_{DS}$ 要足够大。不在恒流区的时候，$U_{GS}$ 和 $I_D$ 之间有这种对应关系吗？没有。那时候 $I_D$ 实际上受两个东西控制：一个是 $U_{GS}$ 所决定的 $R_{DS}$ 的电阻；还有一个是 $U_{DS}$ 的大小。因为 $U_{DS}$ 比上 $R_{DS}$ 才是 $I_D$。

> **提示**：所以这根转移特性曲线最大的前提，就是从恒流区取出来的；而且 $U_{DS}$ 得是一个恒定值，$U_{DS}$ 一变，这条曲线也跟着变。

既然给出了 $I_{D0}$，我们就可以把 $I_{D0}$ 和 $U_{GS(th)}$ 之间的这一段曲线写出一个方程来。这个 $I_D$ 和 $U_{GS}$ 之间的关系可以写成一个方程，叫做**电流方程**：

$$I_D = I_{D0}\left(\frac{U_{GS}}{U_{GS(th)}} - 1\right)^2$$

注意这条方程只管 $U_{GS}\geq U_{GS(th)}$ 那一段，也就是曲线上已经起来的那一段。

那耗尽型呢？同学们注意看耗尽型的转移特性：它可以既到这面，又可以到那面，因为它天生有沟道，$U_{GS}=0$ 就已经导通了。这一段里面 $I_D$ 和 $U_{GS}$ 的关系跟上面一样，只不过把 $I_{D0}$ 换成 $I_{DSS}$——**饱和漏极电流**，也就是 $U_{GS}=0$ 时对应的那个 $I_D$。这一段的方程和上面那一段是同样的方程。

### 输出特性上的几个区域

输出特性曲线我们来看。

> **定义**：场效应管的输出特性是一族 $I_D$–$U_{DS}$ 曲线，每条曲线对应一个固定的 $U_{GS}$，与三极管的输出特性是同一个路子。

在这里可以很清楚地看到：恒流区，这同学们都理解，对吧？然后这是什么？可变电阻区、预夹断区；底下是夹断区。这个特性应该比较熟悉了吧？我们一条一条画出来的，对不对？

- **可变电阻区**：$U_{GS}$ 固定时导通电阻固定，可以当作一个**压控电阻**来用。
- **恒流区**：用来做放大。想让它放大，就得把工作点放在恒流区。
- **夹断区**：可以作为开关，相当于断路。
- **击穿区**：这是结型特有的——$U_{DS}$ 再继续大的话，它会把 PN 结击穿，所以结型管子的曲线上后面还跟着一段击穿区。

### 四类管子怎么从曲线上认出来

那么这是 N 沟道增强型。我们来看另外几个，问同学们，这是什么？先看这里，写着 $U_{GS}$ 吧，它最大的是 $U_{GS}=0$，然后 $U_{GS}$ 都是负的，然后 $I_D$ 是正的。首先一点，这是一个 N 沟道的东西，$I_D$ 是正的。然后它是一个**结型管**——如果是绝缘栅的耗尽型管，$U_{GS}$ 会有正的、可以出现正值；但它这个 $U_{GS}$ 全是负的，所以这是一个结型管。当然 $U_{DS}$ 电压再继续大的话，它会把 PN 结击穿，所以它还有个击穿区。

所以这几张放在一起看，几种管子就这样分：

| 器件 | $I_D$ | $U_{GS}$ 的范围 | 认它的判据 |
| --- | --- | --- | --- |
| N 沟道结型 | 正 | 全为负 | PN 结不能导通，$U_{GS}$ 只能取负；后段还有击穿区 |
| P 沟道结型 | 负 | 全为正 | 同理反向，$I_D$ 是负的 |
| N 沟道增强型 MOS | 正 | 必须 $U_{GS}>U_{GS(th)}$ | 天生断开，超过开启电压才成沟道 |
| P 沟道增强型 MOS | 负 | 反向对称，$U_{GS(th)}$ 取负 | 同上反向 |
| N 沟道耗尽型 MOS | 正 | 可跨越正负 | 天生有沟道，$U_{GS}=0$ 处为 $I_{DSS}$ |
| P 沟道耗尽型 MOS | 负 | 可跨越正负 | 同上反向 |

现在你能分出这几种管子的区别了吧？

先说大的区别：**结型和绝缘栅型**。结型的区域很明显，要么 $U_{GS}$ 全正，要么 $U_{GS}$ 全负；而绝缘栅型有两种：一种耗尽型，$U_{GS}$ 会跨越正负；一种增强型，一定得大于一个开启电压，它是**开启**的，它不是夹断的。

增强型是开启的，它的阈值是开启电压，得大于它——它天生是断的嘛，得大于某一个值之后它才能形成沟道。而**结型和耗尽型天生有沟道**，我们得反着加电压让它去夹断。

### 要做放大，思路该怎么搭

我问你们：真的构成一个放大电路，你会怎么去做？你的思路是什么？下节课我们就用它来构成放大电路。我给你一个信号，很显然就是把这个信号放大，对不对？你要怎么样？

对于三极管，你的思路是什么？对于场效应管，你的思路又是什么？

```text
三极管：  小信号 → I_B  变 → （放在放大区）→ I_C 变 → 输出
场效应管：小信号 → U_GS 变 → （放在恒流区）→ I_D 变 → 输出
```

对于三极管：这个小信号进来，我一定能够引起谁的变化？我让它去影响 $I_B$。我把电路构成这样，让这个小信号能够让我的 $I_B$ 变化——我就快成功了。因为让 $I_B$ 变化并不需要花很多力气；只要三极管工作在放大状态下，这个变化的 $I_B$ 就会变成一个变化的 $I_C$。注意，这个变化的 $I_B$ 和你前面的小信号长得一样，然后一个放大的 $I_C$ 出现了，它跟你那个信号长得一样，但强大了，把这种 $I_C$ 输出，你就得到了放大。前提是把这玩意儿放在放大状态下。思路很清楚：**$I_B$ 对 $I_C$ 的控制**，也就是三极管的电流放大原理。

场效应管呢？第一步，**先把场效应管弄在恒流区里**。弄到恒流区之后，你的思想是什么？转移特性体现的是什么？$U_{GS}$ 对 $I_D$ 的控制。好，那我就让我这个小信号去影响 $U_{GS}$。小信号变化，$U_{GS}$ 变化；$U_{GS}$ 变化，我就产生了一个 $I_D$ 的变化；再把 $I_D$ 输出出去。

> **结论**：你为什么能得到比较大的 $I_D$？因为外面有直流电源。你为什么能得到比较大的 $I_C$？$V_{CC}$ 搁那儿挺着呢。你不过是用小的 $I_B$ 去控制了一个大的直流电源所提供的功率、控制它的功率输出而已。

### 场效应管的主要参数

#### 直流参数

直流参数有三个最常用的：

- **开启电压 $U_{GS(th)}$**：这是增强型 MOS 管的参数；
- **夹断电压 $U_{GS(off)}$**：这个有两种可能，一种结型，一种耗尽型——凡是天生就有沟道的管子都用它；
- **饱和漏极电流 $I_{DSS}$**：耗尽型和结型在 $U_{GS}=0$ 时对应的 $I_D$；
- **直流输入电阻 $R_{GS(DC)}$**：MOS 管的值是多少呢？大于 $10^9\ \Omega$，1000 兆以上。这个数量级才叫绝缘——我们拿摇表去测一个东西绝不绝缘，大于 500 兆欧就认为绝缘了，它比这还高。

#### 交流参数

第一个交流参数，我们称之为**跨导**，或者**低频跨导**，记作 $g_m$：

$$g_m = \left.\frac{\Delta I_D}{\Delta U_{GS}}\right|_{U_{DS} = \text{常数}}$$

我问你们，一旦这样表示出来什么意思？$\Delta I_D$ 比上 $\Delta U_{GS}$，就是转移特性曲线上某一点的**切线斜率**，看到了吧？

为什么会有这种写法？想想我们当时分析二极管是怎么做的。当我分析小的交流信号的时候，这小交流信号一定是在静态的某一点上做震荡，对不对？在直流的某一点上震荡。那我想知道这个小交流信号之间的关系，只要知道这一点上的斜率就够了，对吧？

所以动态值都是一个思路：直流上找到一点，交流信号加上去。交流信号加上去以后，你不能再像求直流电阻那样去求了，而是在这一点的 $\Delta$ 和 $\Delta$ 之间的关系，而 $\Delta$ 与 $\Delta$ 之间的关系就是这一点切线的斜率，这就是它的动态等效电阻。在这里我们把它叫做**电导**，因为它是电流比上电压。你们注意，你们学习一定要学到它的思路——所有的东西都很类似，它都是那一个思路出来的。

第二个交流参数是**极间电容**。这个很容易理解：有三个电容，每一个极与极之间都有电容，这些等效出来的电容大约都是**皮法级**的。出现高频的时候这些会出事情——高频下它就相当于极间电容导通了。

还有一些**极限参数**，就是我使用这个场效应管的时候要注意的，也就是选择管子的时候要注意的。这部分我不在这儿念了，同学们自己回去看教材 1.3.4 晶体管的主要参数；另外 1.3.5 温度对晶体管特性的影响和参数的影响、1.3.6 光电三极管，这两节也都比较容易看懂。
