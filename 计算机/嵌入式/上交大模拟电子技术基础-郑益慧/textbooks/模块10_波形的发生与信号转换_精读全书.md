## 正弦波振荡电路：稳幅、LC 选频与石英晶体
> 对应块：BLK41 | 覆盖分集：P42 | 块标题（分集名）：《41-LC正弦波震荡电路_4K》

前面一路算下来的结论摆在这里——环路增益要大于 1，振荡才起得来。这个结论说起来只有一句话，后面却全是坑。这一讲就顺着这个坑往下挖：稳幅怎么办、频率怎么选、反馈怎么接上去，最后讲到频率越高为什么必须靠晶振。

这一块其实特别有意思。你们可以用仿真软件自己搭一搭、玩一玩。等你真把波形跑出来的那一下，是会兴奋的。

### 起振的门槛：AF 大于 3，以及为什么必须有稳幅

先把这个结论落到实处。反馈网络在这里是有衰减的，它把信号压成了 $\frac{1}{3}$，所以要整体凑出 $AF > 1$，上面的放大倍数就必须大于 3。

> **结论**：桥式（文氏桥）反馈的衰减是 $\frac{1}{3}$，因此要求 $A_F = 1 + \dfrac{R_F}{R_1} > 3$，也就是 $R_F > 2R_1$。

大于 3 很简单，没错。可问题在于哪？你们想一想，它能一直大下去吗？一直大下去就是走向饱和。也就是说，你必须得有一个稳幅的环节，必须得有这样一个稳幅的东西。

这样一摆，桥式振荡电路就出来了：放大电路加上选频网络，两个桥臂，合起来构成整个电路的频率特性。

那么我们下面要解决的关键点就是：**我怎样能够让信号足够大的时候，$AF$ 变小，让它重新等于 1？有没有办法？**

思路一下就打开了。要动谁？要么让 $R_1$ 可变，要么让 $R_F$ 可变。如果我能让 $R_F$ 随着信号的加大而减小——那就成了。

### 稳幅怎么做：让 RF 的阻值跟温度反着走

顺着这条思路再往下追一层：信号加大是什么意思？信号加大，$R_F$ 上的电流就增大；$R_F$ 上的电流增大，说明 $R_F$ 上的发热在加大。那么好办——**让 $R_F$ 的阻值和温度成一个反比**。你挑这么一个元件，让它的阻值随温度反着变，稳幅就成功了。

而且这种稳幅是自动的，它本身还带有反馈作用。你们看这个链条：温度越高，阻值越小；阻值小，放大倍数下来，幅值就变小；要是变得过小了，温度降下来，$R_F$ 阻值又会变大，幅值重新上去。这是一个自动的稳定过程。

> **定义**：稳幅环节 = 一个阻值与温度成反比、且随信号增大而减小的元件，做在放大器的反馈电阻上。

现在你们脑子里想想有什么元器件？这大概是最"可爱"的一类元器件了。我学了这么多年，你们也学了这么多节课了，我们仿佛已经对模拟电子技术很熟悉了——但这种元件偏偏就是 Semiconductor 的地盘：**半导体器件的阻值和温度关系非常大。**

那这里还有一个特别容易搞错的地方：为什么不用一个二极管？为什么偏偏要一正一反两个二极管？

信号是交流的，两边都会跑，有正有负。你要是只弄一个，它在正半周导通、负半周截止，出来直接就被整流了——整流都整流不行了，振荡就死了。所以必须是 $D_1$、$D_2$ 反向并联：随着温度的升高，$D_1$、$D_2$ 的电阻下降，两个半周都照顾到，这样才能做到稳幅。

> **易错点**：稳幅二极管必须反向并联。单个二极管只能整流半个周期，会把振荡信号掐死。

### RC 振荡卡在 1 MHz：R 和 C 都不能太小

说完稳幅，回头把 RC 这条路的天花板也摸清楚。RC 电路有它的好处——频率比较稳定。但你们想一想，如果我要把频率往上升：$\omega_0 = \dfrac{1}{RC}$，要产生频率很高的正弦波，办法无外乎就是**要么减小 $R$，要么减小 $C$**。

哪条路都走不通，我们一条一条看。

**想减小 $R$？** 这里是运放。运放是有输出电阻的，只不过和我们外接的负载比起来，它非常非常小，可以忽略不计。但当你把频率真的升得很高、$R$ 小到可以和运放的输出电阻相提并论的时候，事情就变了——你这里还是这个 $R$ 吗？这个 $R$ 上要并上输出电阻了，选频特性都会被改变。

**想把 $C$ 弄小？** 也不行。运放芯片内部有极间电容，当你小到和它可以匹配的时候，你那个 $C$ 也保不住了。

所以结论很清楚：

> **结论**：RC 振荡电路的使用条件是 $R$ 和 $C$ 都不能太小，都要比运放内部的输出电阻、极间电容大得多，只有这样才能忽略芯片内部参数的影响。

那它大约适用于多少频率呢。一般来说，1 MHz。1 MHz，你们觉得不小了吧？挺大的了。可你们想想我们计算机的主频现在多大？早就是 GHz 了。笔记本上现在的主流主频，一个是 1033，一个是 1333，兆赫兹；你所说的 3.0 那种，几年前的那个，我可以向你保证，那不是主频，那是 CPU 运算的频率速度，是从主板主频倍频上来的。

> **提示**：主频和 CPU 频率是两个概念，别混。主板给的是基准时钟，CPU 的标称频率是倍频上来的。

那么问题就来了：**高频的东西怎么弄？** 我要产生 1 MHz 以上的东西，用什么？答案就是 LC 和晶振。

### LC 并联谐振：大阻抗，天然就是选频网络

先说 LC。并联谐振的时候，它表现出什么特性？开路。如果真的是纯的 LC——理想电感、理想电容——当然不会出现理想情况，但实际上当它谐振的时候，表现为阻抗非常非常大。

> **定义**：LC 并联谐振时呈**开路特性**，即阻抗达到极大值。

这一条特性一出来，LC 立刻就有了两个身份。

**第一个身份是阻波器。** 我们把 LC 并联电路串到某一条电路里面去，它可以把这个频率的波形全截掉、阻止掉。比如本来有一个波形往外输出，过来以后，你在上面串一个 LC，跟它谐振的那个频率就过不来了，被它整个阻断。

**第二个身份更有用——它可以直接当 $R_C$。**

> **易错点**：这是最容易搞混的地方。同一件事有两个视角：把它看成信号通路里的元件，它是**阻波器**（串联在通路里，阻断该频率）；把它看成负载，它在谐振时是**大阻抗**，正好替代 $R_C$。

放大电路里我们希望 $R_C$ 很大，这是最基本的要求。那么现在我用这个 LC 并联电路去取代 $R_C$ 的位置，会得到什么结果？

- 谐振的那个频率：LC 在这里变成一个很大很大的阻抗，等于一个巨大的 $R_C$，信号被放得非常大；
- 不谐振的频率：阻抗很小，增益很小。

非常漂亮。往 $R_C$ 上一放，直接就完成选频，而且它把那个 $A$ 做得很大。

> **结论**：LC 并联网络取代 $R_C$，在谐振点提供极大负载阻抗、在其余频率压低增益，等于一步同时完成了选频和放大，这是 LC 振荡电路最漂亮的地方。

所以你在用这些电路的时候，脑子里要这么想：LC 并联谐振是一个大阻抗的阻波器，但它提供的是大阻抗——而放大电路里我们恰恰希望 $R_C$ 大。用它去取代 $R_C$，就是一个很漂亮的电路。没有难点吧？

那么接下来这一步，你要自己动脑筋了。我从这儿输出一个被极大放大的信号，这个信号只属于 LC 谐振的那一个频率；我把这个信号通过某一个正反馈网络引回到 $u_i$——我就成功了。

怎么引回去？办法有的是。

```text
                    +----------------------+
             +----->|   放大电路 A         |-----> uo
             |      |  LC 选频网络 (R_C)   |
             |      +----------+-----------+
             |                 |
             |                 |  f = f0 : Z_LC 极大
             |                 v
             |      +---------+-------------+
             |      |  正反馈网络            |
             |      |  transformer / tap     |
             |      +---------+-------------+
             |                 |
             +-----------------+
                 共用接地端, 一条线就回来了
```

### 同一套元件，三种反馈画法

整个设计思路其实非常清晰，一步一步自己就能画出来：

第一步，共射放大电路——这个对你们没有难点；
第二步，把共射放大电路里的 $R_C$ 换成 LC——没有难点；
第三步，画变压器——这个真有难点吗？画变压器最没难点了，这边一个线圈、那边一个线圈，又没让你真的去绕变压器。

三步做完，变压器反馈式振荡电路就成了。

#### 变压器反馈式：先把同名端搞清楚

不过我刚才说"成功了"，你们脑子里还要绷着一根弦：**你拉回来的到底是正反馈还是负反馈？** 你要是拉回一个负反馈，那就没戏唱了。你要保证拉回来的信号能够驱动、替代原来的输入信号——这个肯定是对的——但极性必须对。

靠什么来保证极性？变压器上有个东西叫**同名端**。

> **定义**：同名端 = 具有**相同瞬时极性**的端子。某一瞬间它的电位比另一个端子高，那么另一侧对应的那个端子，一定也比它对应的那个端子高。

同名端可非常重要的。你们电路当中学过变压器吗？没事，忘了不要紧，我现在就帮你们回忆起来。

这里有个特别容易掉进去的坑。最可怕的同名端理解是什么？"那个瞬时正极性，那个就是瞬时正极性"——谁告诉你的？你太有才了。

什么意思？如果同学们都喜欢模仿我的话，我就成功了。我仿佛又回到了上世纪五四时期，能被模仿那是一种荣幸，总比被遗忘强。下次接着模仿，回去站在寝室里模仿一遍，把我讲的课模仿一遍，就成功了。

好，说正经的。同名端表示的是一个**瞬时的相对极性**。也就是说，某一瞬间，同名端比另外一个端子高的话，那另外一个同名端肯定比另外一个端子电位高。它讲的是电位相互的高低关系，**根本没有"瞬时正""瞬时负"这回事**。

我给你举一个最简单的例子：一个变压器，这儿是接地的。就说某一瞬间，对地它是正极性——你能说它这一瞬间就是"正极性"吗？不能。你只能说它是负极性。因为它是零，那么另一侧对应的那个端子既然比它高，在那一瞬间就只能是负极性。它传递的一定是一个相对极性，是相对的这样一个电位概念。

同名端我就简单给你这么解释，听懂了吗？

好，现在用反馈的道理来看相位。**相位条件判断，这个是一定要会的。** 这里回来，如果这块接回来，是不是一个正反馈？谐振的时候，整个这个东西就是一个纯电阻，相当于看一个纯的 RC。瞬时的正、向下电流，使得这里的电位差是上正下负——上面比下面电位高。这样传递过来，引回去的就是一个瞬时的正，**满足正反馈的相位平衡条件**。

这样画太麻烦了，我们把它简化。当我们共用接地端的时候，实际上只要一条线回来就可以了。这就是变压器反馈式振荡电路。

#### 电感反馈式：抽头抽到哪儿，是个真问题

变压器反馈式有它的好处——频率范围大，振荡得也真稳定。但它的问题也很明显：变压器耦合里面必然是有气隙的，它靠磁耦合实现。怎么样呢？它一定有漏磁。漏磁就让信号有损失，耦合不紧密，信号就会有损失。

为了耦合得更加紧密一点，反馈式就变成电感的了。

最简单的一种做法：直接从电感上抽头反馈，不用绕第二个绕组了。

```text
            VCC
             |
        +----+----+
        |         |
       [L]       [C]
        |         |
        +----+----+---- tap ------> 输出 (谐振点被放大)
             |
             |  抽头在这里: 瞬时上正下负
             |
             +------------------> 正反馈回 ui

        注意: 不是从 L/C 的正中间抽回 ui, 那样是负反馈
              抽到发射极也行, 但必须先把 C_e 拿掉
```

你们看它整体的概念是什么？看清楚，瞬时一个正、向下电流。这家伙谐振的时候是个纯电阻，使得上正下负。这个电感肯定不是说平均分压，它肯定是要分压的。在这个电感上是上正下负；在纯交流电路里 $V_{CC}$ 相当于接地。所以这里是一个瞬时的正极性，把它拉回来——正反馈成立。

现在我问你们一个问题：**刚才为什么不从中间这个抽头拉回来？**

从中间抽头拉回到输入端行不行？行不行？为什么？——负反馈了。可不可以呢？我不拉到这儿，我抽到发射极去，行不行？行。但是你一定要做一个动作：**$C_e$ 得干掉**。把 $C_e$ 拿掉，否则你白抽了。因为发射极经 $C_e$ 接地，你等于把抽头抽到接地点去了。

所以结论是：中间那个抽头，你真要接到前面那个输入端上去，得到的只能是负反馈；接到发射极，必须先干掉 $C_e$。**抽头抽在哪儿，是个真问题**——这就是电感反馈式的电路要解决的问题。

它有它自己的好处：振幅比较大，调节的范围也比较大。

> **易错点**：电感反馈式输出里容易带高次谐波。

为什么？因为电流当中如果含有高次谐波，这个高次谐波在电感上将得到充分的体现。频率越高，电感的感抗越大，所以它对高次谐波非常敏感。于是从这个电路出来的信号，上面就容易含有高次谐波。这就是电感这个方案的问题。

#### 电容反馈式：两只电容，还有换位思考

那什么出来不容易有高次谐波？电容。

按同一把尺子往下推就明白了：电感的感抗随频率升高而增大，所以它挡不住高次谐波；电容的容抗随频率升高而减小，高次谐波到了电容这里反而被它短接掉了。

所以就有电容反馈式。电容要抽头，怎么抽？用两个电容。就这么简单——反应还是快。

```text
            VCC
             |
        +----+----+
        |         |
       [C1]      [C2]
        |         |
        +----+----+
             |
             +---- tap ------> 输出 (高次谐波少)
             |
             +-------------> 正反馈回 ui

        两个电容是耦合在反馈支路上的: 改 C 会连带改分压比
        所以不动变比, 另外加 C3 去调谐振频率
```

为什么要这么接？还是要保证反馈是正反馈。想尽一切办法。

这里我提醒你们一句：你们现在看着它，都觉得这个电路很简单嘛，一看就懂。稍微一变形——电容稍微往别的地方一翻，拧一下劲儿——你就不认识它了。

我们对电路的认识经常是这样，不光你们，我也经常会这样，这是肯定的。摆得很规矩的一个电路非常容易认，稍微变一下形就不容易认。为什么呢？最简单一点，你给我一个电路的原理图，我很容易读懂一个大图。但你给我一块印制电路板，我真的就只能猜个大概。看它上面主要的芯片是什么，我缕不出它的线来；一会儿两层板还好，上面顶一个孔、下面一个孔，然后两边看看还能对出来；四层板啥都看不到。然后如果说是单面板更容易，线都在一面，但那样也不大容易看，为了布线方便，它会把电路的形状变得很大。

所以你们要有那个本事：这个电路变形了也认识。你们要有这个本事。

好，回到这个电路。瞬时的一个正、向下电流。这个向下的电流引起的电流是这样流动的；然后这里是从下向上的电流。它使得**下正上负、下正上负、下正上负**——这里是接地点，所以把正电位给拉回来了。这就构成了一个电容的正反馈。

那电容反馈式这么大的一个问题是什么？

刚才 LC 从 L 反馈，我调节电容 $C$ 就可以得到不同的频率。电容 $C$ 很容易调节——如果你以前拆过老收音机，拨台的那个东西就是可变电容，它通过改变电容的面积、交叉的面积来改变电容大小。电容很好改变。

但这块出事了。这里是**两个电容**：如果你再通过改变电容去改变频率，冒的风险非常大。为什么？因为你两个电容一起改了，整个反馈都会受影响。

对比一下刚才的 LC：LC 我只改 $C$，$L$ 没动，所以**分压比不会变**。

> **易错点**：LC 振荡里改 $C$ 不影响分压比；电容反馈式里两个电容是耦合在反馈支路上的，同时改变它们会连分压比一起改掉，反馈量就不对了。

那有同学说，那我改变电感呗？改变电感挺困难的，花代价非常大。这种小电感根本不值得改；值得改的都是很大的电力电抗器，在里面改变它饱和、不饱和，来改变电感值。这块不值得改。

所以这个电路如果真的还要调节怎么办？**再加一个 $C_3$**。看到没有——不去调这个变比，这块的变比千万别动，我加一个 $C_3$ 去调节谐振的频率。

那么这就是电容反馈式振荡电路的概念。书上还有其他一些简单的内容。

> **结论**：8.1.3 这一节，从来没有要求我们推 $AF$ 大小的运算。这里不用去推。为什么？因为我一直给你们分析的是"是不是存在正反馈"，就是**相位条件**——会用相位条件判断有没有起振的可能性，这是对这一节的要求。

### 石英晶体谐振器：把一块会振动的石英片等效成电路

下面简单介绍一下晶振，石英晶体谐振器。这个必须得了解，它能做很多事情。

我们来看这个东西。中间看到的是石英晶体的晶片——割出来这样一个晶片，然后在这上下各敷了一层银，上下再夹上管脚，这就是它的符号。

人们发现它有个很好的特性。前辈们是真聪明，我越看这块就越觉得他们聪明——他们发现这个东西之后，能做那么多事情。

一加直流电，晶体能变形；这是真的，加电它会变形。那如果给它加交流电呢？晶体就会振动。它变形来回变嘛，那不就变成振动了吗？

光振动还不算，这个振动反过来还能产生电。这就是**压电效应**：它振动还能产生电。

> **定义**：压电效应 = 石英晶体加电会变形（机械振动），而振动又能反过来产生电。

你发现它和什么特别类似？你们能不能再对偶出一个东西来？它和磁感应很像。你要有这个感觉：电生磁的时候，有电，然后生磁场；交变电场一出现，就出现交变磁场；交变磁场一出现，又产生交变电场。它这个感觉就是：交变电场产生晶体振动，晶体振动又产生交变电场。

所以有用晶振做变压器的——你可以把它做成一个小的变压器。当然了，晶振最主要的功能还是在正弦波振荡电路里。

#### 等效电路：压电、滞后、发热

它等效出来应该是什么样？这是它的等效电路，你要明白它。

```text
      +------+------ C0 -------+------+
      |      |                 |      |
  o---+      |                 |      +---o
             +-- L -- C -- R ---+
      +------+-----------------+------+
```

这个等效电路是一步一步推出来的，我们跟着走一遍。

**$C_0$ 是什么？是它的静态电容。** 什么叫静态电容？大家知道，上下敷了银，中间是石英晶片——这不就是个典型的电容吗？两个极板、中间一个介质。它不动的时候，就是那个 $C_0$。$C_0$ 大约是几十个皮法的量级。

**$L$ 等效的是什么？** 它等效出来就是"电生振动、振动又生电"这样一个感觉，是一个电感。**它是一个滞后的环节。** 为什么可以比电磁感应？因为表述电磁感应的元器件就是电感。

它非常类似：先有电的变化，然后才有机械振动；机械振动之后再产生电——这不就是滞后的吗？所以它表现为一个电感。

**动态电容 $C$ 从哪来？** 它振动的时候，这种小的位移，是不是相当于改变了电容介质之间的厚度？对。这就产生了一个动态的小电容。它很小，非常非常小——大约零点几个皮法，而 $C_0$ 是几十个皮法。

**$R$ 从哪来？** 晶体这样摩擦会发热。发热是什么概念？是耗能，是电阻的特性。所以 $R$ 就是损耗。它的特性就是这么一步一步被等效出来的。

#### 中间一段感性，两边都是容性

现在看它的频率特性。低频段的时候，它会表现成什么样？我们把整个通路捋一遍。

$L$ 和 $C$ 在这条支路上，频率往上走的时候会发生**串联谐振**，谐振点是 $\omega_s = \dfrac{1}{\sqrt{LC}}$，这个 $f_s$ 就是它。

当 $f = f_s$ 的时候，这条支路发生串联谐振。串联谐振的时候，这条支路的等效阻抗是什么？是 $R$——最小值。

> **提示**：这个 $R$ 本身还不算足够小。但在 $f_s$ 下，$C_0$ 的容抗 $\dfrac{1}{\omega C_0}$ 远远大于 $R$。一个很小的电阻 $R$ 和一个非常大的容抗并联，并联以后等效出来是什么？还是电阻 $R$。

所以在 $f_s$ 的时候，整个晶振相当于一个纯电阻。

那在此之前呢？都呈容性。我问你们：$LC$ 串联谐振，当频率低于谐振点的时候，电路表现为容性还是感性？——**容性**。再往高频走，$\omega L$ 越大，就呈**感性**，大于谐振点就是感性。所以在低频段，总电抗 $X$ 小于 0，这是容性的；过了 $f_s$ 之后就是感性的。

有同学问，这是什么东西啊？这又怎么了？这怎么会变得如此之奇怪？

不错呀，你过了之后这块是感性。随着频率继续往上一走，这个感性会和 $C_0$ 再发生一个谐振——**并联谐振**，在 $f_p$ 这个点。一旦过了并联谐振点，又继续呈容性。

所以它非常特殊：**在中间这一段的时候，它才表现为感性，两边都是容性。**

```text
    X
    ^
    |           .-------.
    |          /         \
    |         /           \
 ---+---------+-------------+---------------> f
    |        f_s           f_p
    |       /               \
    |______/                 \______

    f < f_s : 容性   |   f_s < f < f_p : 感性   |   f > f_p : 容性
```

#### 串联型用 fs，并联型用 fp

根据它这样一个条件，我们做成两种电路：一个是并联谐振晶振，一个是串联谐振晶振。

串联谐振晶振用的是哪个频率点？它用的是 $LC$ 的**串联**谐振点 $f_s$。

你们脑子一定要清楚的。我就给你们定性地分析：这里——并联谐振晶振那里——能用并联谐振点启动吗？

> **结论**：并联型晶振不能用 $f_p$。$f_p$ 是并联谐振点，此时晶振相当于断了，信号过不去——这就是刚才讲的 LC 并联谐振的概念：一旦并联谐振，这块就是一个阻波的作用、是断的。你的反馈信号还能过去吗？过不去。正反馈还能形成吗？形成不了。

但是如果用的是串联谐振点 $f_s$ 呢？阻抗这时候是最小的，你的信号正好能从那儿过去。

所以晶振的两种电路——并联型和串联型——用的频率点实际上是有些不同的，这两个频率靠得比较近。

这样，大体就把正弦波发生电路给大家介绍完了。这一节课还是有些需要你们理解的，不是那么轻松愉快。下一节课是比较轻松愉快的，是一气呵成的：从电压比较器一直推到波形发生电路，一步一步往上加东西就推出来了。

## 把运放接成比较器：过零、一般单限与迟滞
> 对应块：BLK42 | 覆盖分集：P43 | 块标题（分集名）：《42-电压比较器（1）_4K》

上节课我们把正弦波振荡电路怎么做讲完了。这一节课和下一节课的内容非常连贯，一气呵成：先讨论集成运放如何构成一个电压比较器，各种各样的电压比较器；然后从其中一个比较器入手，去设计方波发生电路；在方波发生电路的基础上设计三角波发生电路；在三角波发生电路的基础上，再设计锯齿波发生电路。

所以这两次课结束之后，我希望你们练出来的是什么本事呢？拿过一个集成运放，咔咔咔连几笔，变成一个电压比较器；再连几笔，变成一个方波发生电路；再连几笔，变成一个三角波发生电路；再连几笔，变成一个锯齿波发生电路。

这种思路才是非常重要的，而不是简单地去分析一个电路。你们去看那些电路图，它们哪个不是别人连几笔连出来的？分析电路只能让你看懂别人已经连好的东西，只有设计才让你握有从零开始的那支笔。所以今天我们一路都是"设计"，不是"分析"。

### 开环与正反馈：没有线性区的传输特性

既然谈到电压比较器，第一个问题就是：集成运放在这里到底工作在哪一个状态？上一节课我就跟大家提过，集成运放在这一章里面最大程度地被应用在正反馈或者开环这样一个状态下。

同学们可以看，这一个是开环状态，这一个是正反馈状态。无论哪一种状态，运放整个的电压传输特性都是这个样子：它几乎没有什么线性区，没有线性区，直接就饱和，两边直接饱和。也就是说，当我的 $u_P > u_N$ 的时候，同相端比反相端高，输出马上就是正饱和；当同相端比反相端低的时候，输出就是负饱和。

> **定义**：电压比较器的基本原理就是比较同相端和反相端之间的电位。谁的电位高，我就做出相应的输出。

各种各样的电压比较器，都是在这个内核的外围进行拓展得到的。所以后面不管出现多复杂的比较器，你都要能把它剥回这句话：它比较的永远是同相端和反相端这两个电位。

那么问题来了：正反馈在这里到底起什么作用？为什么有的时候要加正反馈？

> **结论**：正反馈起加速作用。

大家想想，开环的时候输出是这样"刷"地爬上去到饱和的；有了正反馈，它自己不断加强自己，唰一下就到了，比别人快。所以在整个电压比较器里，我们利用的就是这两种状态。

顺便把电压比较器的任务也说明白：它完成的是两个电压之间的比较，一个输入电压和一个参考电压之间的比较。参考电压是定死的，是我自己去定的；变的是输入电压。

### 三步求出一条电压传输特性

我现在扔给你一个电压比较器，你不管我是怎么做的，我又提那个方盒子的概念：这是一个输入 $u_I$，这是输出 $u_O$。如果你要用这个电压比较器，你必须知道它什么特性？电压传输特性。什么样的 $u_I$ 进去，会出来什么样的 $u_O$。

所以我们研究一个电压比较器、设计一个电压比较器，依据都是它的传输特性。手里拿一个比较器的图，我能分析出它的传输特性，我才能用它；反过来，给我一条传输特性，我去设计一个比较器。

那么这条传输特性由哪几件事决定？我给你倒过来数。

#### 先定高、低输出电平

在开环和正反馈条件下，运放的输出基本上没有什么线性区可言：要么输出一个高电平 $U_{OH}$，要么输出一个低电平 $U_{OL}$，总归是在两边跳。

它是什么含义呢？同相端电位比反相端高，输出一个 $U_{OH}$；同相端电位比反相端低，输出一个 $U_{OL}$。也就是说，我一看到输出的电平，就知道前面比较的结果了——我是通过电平来反映比较结果的。

#### 再定阈值：线性区被压缩到"相等的一瞬间"

第二步，跳变发生在 $u_I$ 等于多少的时候？这个临界值我们称为阈值电压 $U_T$，它是发生跳变时的 $u_I$。

这里有一个疑问我要当场提出来：有同学会问，$u_I$ 不就是那个东西吗？$u_I$ 不就是同相端、反相端的某一个输入吗？——不是。这里 $u_I$ 是外面接有电路的输入量，是 $u_I$ 的变化引起了同相端和反相端之间大小的变化。

那么跳变的临界点到底是什么？

> **结论**：是线性工作区。只不过在比较器里，线性工作区变得极短，短到什么程度呢？短到只有同相端和反相端相等的那一瞬间。

往这边偏一点，同相端就比反相端高；往那边偏一点，同相端就比反相端低。所以跃变的阈值一定是 $u_P = u_N$ 的时候，那个对应的 $u_I$。

```text
      u_I  ──────────►
                       │
   u_P - u_N ──────────┼────────►  正
                       │        ╱
                    U_T│      ╱
                       │    ╱
                       └────────────►  负
              线性区被压成"相等的一瞬间"
```

所以阈值电压怎么求？求使 $u_P = u_N$ 的那个 $u_I$，也就是 $U_T$。

#### 最后定跃变方向

我知道了 $U_{OH}$、$U_{OL}$，也知道阈值了 $U_T$，能不能把整条传输特性画出来？

不能。而且这个"不能"如果出一道判断题，你会得满分。我反过来问你为什么不行。

看这两条曲线：$U_T$ 都等于 0，$U_{OH}$ 和 $U_{OL}$ 也都一样，但是这两张图一样吗？

```text
   u_O                              u_O
U_OH ┤────────┐                U_OH ┤        ┌────────
    │        │                     │        │
    │        ↓                     ↑        │
U_OL └         └───────         U_OL └────────┘
    │        │        │             │        │        │
    └────────┴────────┴──→ u_I     └────────┴────────┴──→ u_I
              0                              0
         U_T = 0，向下跌变             U_T = 0，向上跃变
```

不一样。这叫跃变方向不一样：一个随着 $u_I$ 增长是上升跃变，一个是下降跃变。

所以完整的一条电压传输特性，需要三样东西：高、低输出电平 $U_{OH}$、$U_{OL}$；阈值 $U_T$；以及跃变方向。有了这三点，一条电压传输特性肯定就出来了。

### 四种比较器的传输特性

大体上常用的电压比较器有这么几种。看这几条曲线，长得都不一样，长得最复杂的那条留到最后讲。

#### 单限比较器

最简单的一种，我们都认识。整个传输特性上只有一个阈值，而且无论 $u_I$ 上升还是下降，都是过同一个阈值来跃变的。这叫单限电压比较器。

#### 双限比较器之一：两个阈值，原路返回

第二条曲线有两个阈值 $U_{T1}$、$U_{T2}$。但它的特点是：不管我是上升还是下降，过这两个阈值的时候跳变是一样的。我过 $U_{T1}$ 是从上往下跳，回来的时候同样是从下往上跳，会按原路返回。整个上升轨迹和下降轨迹是重合的。曲线上连虚线的往返箭头都不用画，因为它就是原路。

两个阈值，这叫双限。

#### 双限比较器之二：按一个方向走，两次跃变

第三条曲线也是两个阈值。这回它就没有虚线轨迹了，因为往返不重合。按同一个方向走——比如 $u_I$ 单调增——会产生两次跃变：一次跳下来，另一次又跳上去了。两次跃变、两个阈值，而且必须按同一个方向走。

这才是双限电压比较器真正的判据：两次跃变，两个阈值，按同一个方向走。

#### 迟滞比较器：回来时不走原路

第四条曲线是这一讲我最想给你们看的东西。它也有两个阈值。

$u_I$ 单调增长的时候，增长到 $U_{T1}$，发生跃变吗？不跃变！要到 $U_{T2}$ 才啪地跳下来，而且只跃变一次。只要 $u_I$ 是单调增的，我只会出现一次跃变。

然后奇妙的地方来了：回来的时候，$u_I$ 开始减小，它不会在 $U_{T2}$ 往回跳，它要一直降到 $U_{T1}$ 才嘣地跳上来，也只有一次跃变。

你看清这一点了吗？从单个方向看，它每次只有一个跳的机会，从这个道理上说，它类似于一个单限比较器。但它又明明有两个阈值。

> **结论**：它仿佛带着一段迟滞的历史，就像磁滞回线、像有剩磁的那种感觉——回来的时候不沿原路返回，要过一段距离才修正回来。这种比较器就叫迟滞比较器。

这四种比较器应该都能设计出来。我先扔在这儿，你们脑子里先存这样一个想法。

### 设计一个过零比较器

我给你们最简单的一种：过零比较器。既然过零，参考电压就该是 0。

#### 起点：参考电压接同相端

所谓过零比较，我的参考电压是 0，我这个参考电压接在哪？同相端还是反相端？从那条传输特性来看，我应该接同相端。猜一个——同相，对不对？

有人不敢同意。那么 $u_I$ 就从反相端进去。至于要不要加保护、要不要加电阻，那再说。

电路有了，传输特性我们一起分析，还是那三步。

第一步，输出高低电平是什么？正负 $U_{oM}$，因为饱和嘛。

第二步，阈值是什么？$U_T$ 就是使 $u_P = u_N$ 的那个 $u_I$。同相端接的是 0，所以 $u_P = u_N = 0$ 时，反相端上的 $u_I$ 也只能是 0，于是 $U_T = 0$。

第三步，跃变方向。$u_I < U_T$ 也就是 $u_I$ 为负的时候，$u_N$ 低，输出高电平；$u_I > U_T$ 也就是 $u_I$ 为正的时候，输出低电平。所以是向下跃变。

三步合起来，这条传输特性就出来了。

#### 给输入端加保护：限流电阻 + 稳压管

需求还在提高。有的时候做过零比较器，如果我的输入端不是那么坚强，我不能让它承受很大的差模电压——$u_P$ 和 $u_N$ 之间的电位差不能太大。怎么保护？能不能保护它？

用稳压。一种是用稳压二极管，正反向都可以搞定，简单。如果再省一点，就加两只正反二极管。为什么两只普通二极管也行？因为只要它的输入比二极管开启电压小个几十毫伏，输出就已经饱和了。

我问你们，我这个电路对不对？有同学画出来了，概念是真的挺扎实——少了限流电阻。这个应该前面加什么？限流电阻。

一个限流电阻，加上并联在两个输入端之间的双向限幅（稳压管，或者两只正反二极管），输入端就护住了。图越画越小，对不对？

#### 让输出不再是 ±U_oM：双向稳压管限幅

我还不满足。你是把前端保护了，可我现在对输出有要求：我不想输出正负 $U_{oM}$，这玩意不是我控制的，还得看运放高不高兴。我想输出一个固定的电压，那我输出端加什么环节？

稳压。直接上双向稳压二极管。

但是同学们，到这一步我心里其实是有一点点犹豫的，用的时候要注意。看，输出端肯定要接 $R_L$，对吧？我的 $R_L$ 是有要求的：你要想让那个稳压二极管启动，$R_L$ 必须比较大，要比这里的这个 $R$ 大得多，我才能保证稳压管被击穿。否则 $R_L$ 很小，分压特别小，稳压管根本击不穿，它就根本没在工作。

这也是让我头疼的一个问题。

#### 把双向稳压管挪进反馈通路

那能不能设计一个电路，让它照样稳压，而我对 $R_L$ 不那么挑剔？

一种稳压方式就是这样了。我们把这两个二极管先擦了——这个不是接地吗？和接地直接稳压。我的思路是什么？我把这里构成一个反馈通路，这就是负反馈。一旦形成负反馈，这个点就是接地点，这一点就变成虚地。

所以要换一个说法：只要这里形成负反馈，这个点就被钉在虚地上了，$R_L$ 从这个点到地，无论 $R_L$ 怎么变，这个点的电位都不动，输出自然就被钳住了。

我们来看这个电路怎么工作。

```text
 上电：双向稳压管截止 → 输出稍微一正 → 奔着负饱和去
                              │
                     两端电位差 > U_Z
                              ▼
        ┌─────── 负反馈一旦建立 ────────┐
        │  反相端 = 虚地(0)，输出被钳住  │
        │  R_L 怎么变，输出仍是 -U_Z   │
        └───────────────────────────────┘
                              │
  u_I 缓慢趋近 0 → [R] 上电流趋近 0 → 稳压管截止 → 退回开环
                              │
  u_I 转负的一瞬间 → 输出冲向正饱和 → 反向击穿 → 输出 = +U_Z
```

最初的时候还没输出，双向稳压管截止。只要输出稍微大于零一点点，它马上奔着负饱和去了。它能不能到负饱和？不能。当输出端和反馈端的电位差大于双向稳压管的击穿电压时，啪，击穿。

一旦击穿，就形成了负反馈。这个点成为虚地，输出就被钳在 $-U_Z$。这时候你 $R_L$ 再变化，它还是 $-U_Z$。

然后我们看它怎么退出来。刚才那一路是正的，慢慢往零变。随着电位不断减小，输入电阻上的电流不断减小——电流就是 $u_I$ 除以这个电阻——不断向零逼近。直到有一天 $u_I = 0$ 的那一瞬间，电阻上的电流是零。稳压管中通过的电流是零，意味着它重新恢复到截止状态。这个电路又重新变成开环。

在它变向负向的一瞬间，输出马上向正方向增长，增长到两端电位差大于击穿电压时，出现这个方向的击穿，输出变成 $+U_Z$，从而实现稳压。

它的好处还远远不止这一点：它的转换速度比刚才那个开环的快得多。为什么？开环的时候，集成运放一定工作在饱和状态，它把运放干到饱和了，只不过饱和输出之后我用一个稳压管去稳压。而这个电路里，集成运放工作在线性状态，它在两个状态之间转换的时候，根本不用"退饱和"这个过程，所以速度非常快，啪就回来了。

> **结论**：这个电路还是一个非常漂亮的电路。它比那个把稳压管挂在输出上的方案好，好在不挑 $R_L$，还快。

到这里你们应该能一口气画出来了吧：过零比较器加上输入保护，加上输出限幅，再加上反馈。这就是过零比较器。

### 一般单限比较器：把阈值从 0 挪走

我们不能总是单限比较器，不可能就一个阈值、就一个 0 吧？我们把它拓展到一般的单限比较器。

#### 怎么把阈值挪离零点

我给你们出一个题：怎么改变 $U_T$？我现在的 $U_T$ 是 0，怎么让它不是 0，让它受我操控？你们有多少办法？

最简单的办法，加一个参考电压 $U_{REF}$。

如果我还想让这一端保持接地，还有没有办法让 $U_T$ 不是 0？有——让 $u_I$ 和另一个参考电压进行叠加。叠加以后 $u_I$ 受到影响了，$U_T$ 自然就挪走了。

所以方法非常多。我们就用叠加的办法来做。

#### 三步把传输特性算出来

第一步，输出电平。它加了双向稳压管，所以 $u_O$ 就是 $\pm U_Z$。

第二步，阈值怎么求？还是老规矩，$u_P = u_N$ 的那一瞬间。由于 $u_P = 0$（接地），所以 $u_N$ 必须等于 0。而 $u_N$ 是什么？是 $u_I$ 和 $U_{REF}$ 的叠加。用叠加定理分开算：

$$u_{\text{N}} = \frac{R_2}{R_1 + R_2}\,U_{\text{REF}} + \frac{R_1}{R_1 + R_2}\,u_{\text{I}}$$

令它等于零，两边乘掉分母，把 $u_I$ 解出来：

$$U_{\text{T}} = -\frac{R_2}{R_1}\,U_{\text{REF}}$$

于是阈值就被 $U_{REF}$ 和两个电阻的比值控制住了。想往哪边挪就往哪边挪，想多大就多大。

第三步，跃变方向。当 $u_I < U_T$ 时，$u_N$ 是负的，输出是正的；当 $u_I > U_T$ 时，$u_N$ 是正的，输出变成负的。所以它是从上向下跳变。

三个点一凑，这就是一般单限电压比较器。

> **结论**：加参考电压只是把 $U_T$ 从 0 挪走了，跃变方向仍然是向下，输出仍然只有两个电平。改变的只是"在哪儿跳"。

### 单限比较器的用武之地：PWM

这样一个比较器有什么作用？它当然可以用来比电压。真的拿它去比电压，我们来看这个电路。

先看最简单的那个过零比较器。如果我的输入 $u_I$ 进来的是一个三角波，输出会变成什么样？变成一个方波，或者矩形波。大家看到没有，在这个情况下占空比是 50%。

那我怎么调占空比？用刚才那个过零比较器行不行？不行。因为过零比较器的阈值是死的，是 0，它没法调。应该用一般单限比较器。把三角波接进一般单限比较器的输入，调它的 $U_{REF}$，你调阈值的高低，就能调方波的占空比。

> **结论**：电压比较器最常见的用武之地，是脉宽调制电路 PWM。做法就是拿这个电压比较器去和一个三角波比，调它的阈值，触发出去的脉宽就不一样了。

```text
   三角波 u_I ──┐
                 ├──►[ 单限比较器，阈值 U_T ] ──► u_O 方波
   U_REF ────────┘                            ▲
                                               │
                        调 U_T  ⇒  调脉宽  ⇒  调 IGBT 的导通时间
```

IGBT 你就简单地想成一个三极管：我让它开通，或者让它处于一个开关状态。高电平的时候让这个开关闭合，低电平的时候让开关断开。这样我就可以调节三极管闭合和断开的时间，就能得到我想要的波形。

所以这是一条很完整的链条：单限比较器就够用了；调 $U_T$ 就调占空比；占空比变了，输出量就变了。

再看平均输出电压。如果我把整个轴线，也就是阈值，往下拉，拉到负的位置，你能看到平均输出电压会减小；如果我把它拉到零，输出就变成零到十伏的方波了。这就是调制。

### 迟滞比较器：从单限改过来

说到迟滞比较器，我今天给你们一个不算高的要求：我假设 $U_{T1}$ 和 $U_{T2}$ 的绝对值是相等的，是对零对称的，也就是 $U_{T1} = -U_{T2}$。我给你这样一个滞回比较器的要求，你们能设计出电路来吗？

这个要求真的不过分，我告诉你们。

#### 它本质上是从单限改过来的

我们先想清楚道理。再怎么是滞回比较器，我刚才跟你们分析过它的原则：如果仅从一个方向上看，单调增的时候它就是一个单限。没错吧？单调减的时候也是一个单限。

所以脑子里第一个概念是：这家伙应该是从单限电压比较器改过来的。

那区别在哪里？区别在阈值：单调增的阈值和单调减的阈值是不同的。

我们把这句话再翻译一遍。$u_I$ 什么方向？单调增、单调减。看到这个图上，这是什么意思？意思就是我 $U_O$ 是高电平的时候，它的跃变阈值，和 $U_O$ 是低电平的时候的跃变阈值，不一样。

再解释一步。$U_O$ 是高电平输出的时候，它向低电平跃变的阈值只有一个，对不对？是一个单限的东西；低电平向上跃变的也只有一个，只不过它俩值不相同。

> **结论**：跃变的阈值受 $U_O$ 影响。

#### 让 $U_O$ 反过来影响参考电压

那脑子里就要想了：单限电压比较器的参考电压，是受谁影响的？

是受 $U_O$ 影响。

听懂我的意思了吧？那我就让我的 $U_O$ 回过来，去影响这个参考电压。不同的 $U_O$，有不同的参考电压，我的一切就成功了。

这一步的设计要点在于：这里要形成的是正反馈，不能是负反馈。正反馈才是"我的输出抬高一点，阈值也跟着抬高一点"，正是迟滞所要求的。

至于具体怎么连——这个电路怎么做，你们应该能做出来。方法和一般单限比较器相比只多了一件事：参考电压那一路不再是接死的 $U_{REF}$，而是要接 $U_O$ 的一份反馈。

至此，比较器这一块我们算是搭起了骨架：从最简单的过零比较器出发，加保护、加限幅、加反馈，就得到了一个完整好用的电路；把阈值从 0 挪走，得到一般单限比较器，顺带解决占空比可调和 PWM 的问题；再让阈值受 $U_O$ 影响，就是迟滞比较器。下一节课，我们就从方波发生电路开始，一路往三角波、锯齿波推下去。

### 本讲提到的题目

课上有两处题目，都是当场抛出、当场带做的，这里还原。

#### 设计一个过零比较器

**题干**：给定传输特性——横轴 $u_I$，纵轴 $u_O$，跃变点在 0，输出为 $+U_{oM}$ 和 $-U_{oM}$。要求设计出这个电路。

**答案**：一个运放，参考电压 0 接同相端，$u_I$ 接反相端。

**解析**（依据正文"三步求出一条电压传输特性"）：输出电平是 $\pm U_{oM}$，因为运放工作在饱和状态；阈值 $U_T = 0$，因为阈值就是使 $u_P = u_N$ 的那个 $u_I$，而此时 $u_P = 0$；跃变方向向下，因为 $u_I < U_T$ 时输出高、$u_I > U_T$ 时输出低。

#### 设计对称滞回比较器

**题干**：给定传输特性，两个阈值对零对称，$U_{T1} = -U_{T2}$。要求设计出电路。

**答案**：在一般单限比较器的基础上，把参考电压改接为 $U_O$ 的正反馈。

**解析**（依据正文"迟滞比较器：从单限改过来"）：单调增时它只有一个跳变点，等效于单限；单调减时也只有一次跃变，但阈值不同。所以阈值必须受 $U_O$ 影响。把 $U_O$ 引回参考电压支路，形成正反馈，不同的 $U_O$ 对应不同的阈值，就得到 $U_{T1}$ 与 $U_{T2}$ 一正一负的两个值。

## 滞回比较器与矩形波、三角波发生电路
> 对应块：BLK43 | 覆盖分集：P44 | 块标题（分集名）：《43-电压比较器（2）_4K》

### 把输出引回输入：滞回比较器是这么来的

有了前面单限比较器打底，再看滞回比较器，其实一下子就变得非常简单了——一句话：把输出的影响引回到输入端。

为什么要引回？单限比较器那条门限线是死的，输入电压只要在它附近晃一晃，输出就跟着翻跟头。现实里从传感器、从传输线、从上一级放大器出来的信号，焉能没有一点毛刺。所以真正好用的比较器，必须对这种毛刺有"脾气"。

最简单的引回方式，就是把输出原样接回去。这么接当然成，而且它确实就是滞回比较器。但你立刻会发现它怪在哪里：输出是 $+U_Z$ 的时候，输入门限就是 $+U_Z$；输出翻成 $-U_Z$，门限就成了 $-U_Z$。一点调节能力都没有，门限被输出自己锁死了。这个我不喜欢。

要想让它有得调，就得让输出先做个分压再引回来。$R_1$、$R_2$ 一摆上去，回馈节点上拿到的就是输出的一部分，调节余地立刻就有了：

```text
   u_I ─────►(−)┌───────────┐────► u_o
                │  运放 A   │
   u_P ─────►(+)└───────────┘
                │           │
               R1          R2
                │           │
               GND         u_o
```

读图：输入 $u_I$ 进反相端，输出 $u_O$ 经 $R_2$ 回来、再经 $R_1$ 落到地，中途那个节点就是 $u_P$（同名输入端）。电路就这么多东西，没有第二个秘密。

> **定义**：这种把输出引回输入、且引回到**同相端**的比较器，叫滞回比较器；引回反相端就不是它了。

### 两个门限 $U_{T1}$、$U_{T2}$ 是怎么算出来的

分析它的特性，我们的办法很固定：**先假定输出停在哪一档，再回头问这时候输入门限是多少**。

当 $u_O = +U_Z$ 时，分压节点上的电压是

$$u_P = \frac{R_1}{R_1 + R_2} U_Z$$

而输出停在这个高电平的条件，按定义就是输入电压 $u_I$ 从高的方向压下来、压到 $u_P$ 为止（此时 $u_N = u_P$）。所以这一档对应的门限：

$$U_{T1} = \frac{R_1}{R_1 + R_2} U_Z$$

换到另一种情况。当 $u_O = -U_Z$ 时，

$$u_P = -\frac{R_1}{R_1 + R_2} U_Z$$

对应的门限就是

$$U_{T2} = -\frac{R_1}{R_1 + R_2} U_Z$$

两个都拿到了，那么回差电压自然也就出来了：

$$U_H = U_{T1} - U_{T2} = \frac{2R_1}{R_1 + R_2} U_Z$$

> **结论**：滞回比较器的门限**不是电路里某条固定的线，而是跟着输出走的**。输出是哪一档，两个门限就整体挪到哪一档去。$U_{T1}$ 和 $U_{T2}$ 关于零点中心对称，中点就是零。

后面为了说话省事，我一律把 $U_{T1}$ 简写成 $+U_T$，把 $U_{T2}$ 简写成 $-U_T$，你们心里知道这是两个东西就行。

### 阈值"蹦来蹦去"的奇妙过程

门限跟着输出跑，这件事画到坐标上就非常有意思了：

```text
      u_o
       ↑
  +U_Z │        ┌────────────┐
       │        │            │
  U_T1 ├────────●            │
       │        │            │
     0 ┼────────┼────────────┼────────→ u_I
       │        │            │
  U_T2 │        │            ●
       │        │            │
  -U_Z │        └────────────┘
                ↑            ↑
               跳变         跳变
```

读图：横轴是输入电压，纵轴是输出。$u_I$ 往大的方向走，走到 $U_{T1}$（左边那条竖线），输出由 $-U_Z$ 啪地跳到 $+U_Z$；然后 $u_I$ 再怎么往回退，它都不动，一直保持高电平，直到退到 $U_T2$（右边那条竖线），才啪地跳回 $-U_Z$。

现在跟着我走一遍整个过程，注意看那个门限本身是怎么蹦的。

$u_I$ 从左边过来，一直加大，加大到 $U_{T1}$，超过一点点。这时候输入端（反相端）就大于 $u_P$ 了，输出跳变。跳变的那一瞬间，这颗运放"改头换面"了：$u_O$ 一变成 $-U_Z$，分压节点立刻跟着变成 $U_{T2}$，**门限从 $U_{T1}$ 一下子蹦到 $U_{T2}$**。

然后你往回走，走到 $U_{T1}$ 那一带，它连动都不动。为啥？$U_{T2} < U_{T1}$，你现在这个位置根本还没到它的触发点，它当然不理你。

一直等 $u_I$ 减到小于 $-U_T$（也就是 $U_{T2}$），此时输入端低于 $u_P$，砰，又跳上去，跳回 $+U_Z$；门限又从 $U_{T2}$ 蹦回 $U_{T1}$。你再想回去，没门了。

结果就是：**同样一个 $u_I$ 数值，落在 $[U_{T2}, U_{T1}]$ 这个区间里，输出既可能是高电平也可能是低电平**，取决于你是从哪个方向进来的。这就是所谓滞回区域。

这个区域留给我们很多想象空间。说句话，这玩意儿有点像手续费——你买入，想用同样的价格再卖回去？不行，得付出点钱。回差电压就是这个味道。

### 滞回比较器的两个特点

整个滞回电路，特点就两条。

#### 回差电压：一点容忍度

第一条，它有回差电压。这个回差电压是一个**容忍**——它就是容忍度。

单限比较器没有容忍这回事，就一条杠，过来跳上去，回来跳下去，死死的。滞回不一样：过去，回来到这儿，我不认为你真的要悔改了；直到你再冲过去一段。它给你一段容忍区，你回来也给你一段容忍区。

> **易错点**：容忍区不是"迟钝"，是"缓冲"。输出进到滞回区里不动，是它记住了上一次的状态，不是因为它反应慢。

这一段容忍区域，为我们消除干扰打下了非常好的基础，后面讲整形的时候你会看到它到底值多少钱。

#### 正反馈：让跳变更快

第二条，用的是什么反馈？正反馈。

正反馈是一个**加速**的过程。我比着描述一下：如果开环，输出从高往低是这样慢慢、线性地降下去的；正反馈时，只要比门限大一点点就开始降，这一降引起门限那边也往更狠的方向降，于是差距从"一点点"变成"两点点"，再继续变成"很多点"，速度比开环快得多。

我们看图的时候画的那些竖直跳变，都是把时间轴缩到很夸张之后的简化。真把时间不断缩小，缩到纳秒级，你会看到那条沿开始倾斜了——总归是有个跳的过程。但你一加上正反馈，它马上又变回垂直的了，因为下降时间被压缩了。

> **结论**：一个脉冲的上升沿和下降沿代表着你的传输速度和转换速度，沿越陡速度越快。正反馈能把沿变陡，这正是数字电路里非常关心的问题。

### 让回差中心搬家：非对称的门限

到这里滞回比较器就算讲完了。但我这点很讨厌——你看到这个方框了吗？我凭什么它就长成这样、两头是对称的？我就不要对称。我想让 $U_{T1}$ 和 $U_{T2}$ 不对称，随便走，这个大方框我想让它挪到哪儿就挪到哪儿。有没有办法？

先想清楚它**为什么**对称：因为分压电阻的下端接地，它对零点对称。零点嘛，于是正的时候门限就是正的 $\frac{R_1}{R_1+R_2}\cdot U_Z$，负的时候就是负的。

那我干一件事就把它改掉：**这块不接零了，我加一个参考电压**。这一换，它肯定就以我那个参考电压为中心点对称了。

$$U_{T1} = U_{REF} + \frac{R_1}{R_1 + R_2}\left(U_Z - U_{REF}\right),\qquad U_{T2} = U_{REF} + \frac{R_1}{R_1 + R_2}\left(-U_Z - U_{REF}\right)$$

于是

$$\frac{U_{T1} + U_{T2}}{2} = U_{REF}$$

方框中心挪走了，回差宽度一点没变。这些思想都很简单的，真的很简单。

> **提示**：电路图是设计出来的，不是看出来的。你突然盯着这样一个图看，是没感觉的；你必须知道这个东西是怎么一点一点从上面那个想法弄出来的。这个过程本身比结论值钱。

### 拿它去整形：把被干扰的"1"救回来

有了回差和正反馈，滞回比较器就有了一个非常好的应用。我们来看。

给你提一个问题。屏幕上这个可爱的锯齿小波形，画的不是山。我如果在传输一个数字信号，假设我传的是个"1"——没错，就是这个"1"——它可不像我画得这么干净。真实传输过程中，这条平线会被各种干扰搞成"山峦叠嶂"的样子，有高有低，大体的形状还是那个样子。

我现在要做两件事：第一，恢复它原来的面貌；第二，让它变得更陡。本来它可能就长得歪歪扭扭，然后咔咔咔被一通干扰。

> **易错点**：如果只用单限比较器，能不能做到？做不到。单限比较器咔嚓往上一卡，本来一个"1"就变成了 `1010`；本来人家是连续几个"1"，你一卡、有高有低，出来的就是 `1010` 这样一串东西。

把滞回往上一加，情况完全变了：这些干扰**全被容忍了，全被吃掉了**。因为在回差里面，输出根本不会跟着你的干扰跑；你过来一下我回去了，你过来一下我又回去了，来回来回的，人家就在那儿玩。只有你真的过分了、超过了干扰的限度、真该跳变的时候，它才跳。

所以只要你调一个合适的回差电压，把 $U_T$ 调到比干扰幅度大一点，干扰就被全部滤除。

第二点，正反馈让波形变得更陡峭。两条加起来，它就是一个非常棒的整形电路。

### 双限比较器

双限电压比较器我不讲，你们自己看一眼就明白了，懂我意思吗？简单的一塌糊涂的一个电路。

就是弄两个运放，用两个运放提供两个门限，一个上限一个下限。

它关键的点在哪里？就在这两个二极管的应用上。

为什么非得有这两个二极管？因为如果没有：一个输出高电平，一个输出低电平，它俩直接短路了，就是输出端短路嘛，然后比它俩谁更坚强，干掉其中一个，另外一个留下来。肯定得烧掉一个喽。所以人家就弄俩二极管上去。

> **提示**：这就是我脑子里总在假想的画面。聪明一点的前辈，一看就知道要串两颗二极管。真去干这事，少两颗二极管就烧俩运放。除了这个，这个电路就没啥别的了。

### 几种波形之间怎么互相变出来

屏幕上给了这么多种波形：第一个，方波或者矩形波；第二个，三角波；第三个，锯齿波；还有一个长得类似冲击的东西——它其实就是把方波滞回一下、微分一下的产物。

它们之间是相辅相成的，转换方式都很直白：

| 你手里的波形 | 处理方式 | 你拿到的波形 |
| --- | --- | --- |
| 方波 | 积分 | 三角波 |
| 三角波 | 陡峭的上升段 + 水平的保持段 | 锯齿波（真锯齿波） |
| 三角波 | 把倾斜的那一面不断缩小 | 近似锯齿波 |
| 方波 | 微分 | 冲击类波形 |
| 正弦波 | 过零比较器 | 方波 |
| 方波 | 积分 | 三角波 |
| 正弦波 | 一般单限比较器，占空比可调的矩形波 | 占空比可调的矩形波，再积分 |

所以你们现在起码应该有本事说"我能弄出方波了"。那你们有没有本事弄出三角波？

很简单：前面有个正弦波发生电路，取一个正弦波，过零比较器一卡，方波就出来了；再积分，三角波。这是一套思路。

要占空比可调的怎么办？正弦波进一般单限比较器，得到占空比可调的矩形波；再积分，当我把这个占空比调得很变态的时候，就可以变成锯齿波。

你们已经有这个本事了。但我们现在不从正弦波发生电路入手——拿到运放，我们用运放给它攒一个方波出来。

### 矩形波发生电路

把这个方波的问题放在刚才那个滞回比较器上想。这个家伙在 $\pm U_Z$ 上来回跳变。想让它变成方波，唯一的办法就是让它**自动地跳**：过段时间跳一下，再过段时间跳一下；保持高电平一段时间跳到低电平，保持低电平一段时间又跳回来，方波不就出来了？

问题是，怎么让它这样自己跳着玩？

> **问题**：当输出停在 $+U_Z$ 的时候，怎么让它站不住、自动跳到 $-U_Z$？

很简单：我让 $+U_Z$ 去影响输入端，让这个点的电位不断上升；终究有一个时刻它会大于门限，然后这里就跳变成 $-U_Z$。然后我让 $-U_Z$ 去影响这里，当它变成 $-U_Z$ 的时候，这里的电压不断减小，直到有一天小于 $-U_T$，我又重新跳变到 $+U_Z$；然后 $+U_Z$ 再对它影响，不断让它增长。

让它有一定的时间，我利用谁？利用电容去充放电。充电放电是有时间常数的。

所以最简单的电路就这样出来了：

```text
             u_o
              │
              ├──────────────► 运放输出端
              │
              ├──── R2 ────┐
              │            │
              │           u_P ──► 同相端(＋)
              │            │
              │           R1
              │            │
              │           GND
              │
              R
              │
              ● u_C ─────────► 反相端(－)
              │
              C
              │
             GND
```

读图：从 $u_O$ 出来一条 $R$–$C$ 的充放电支路，$C$ 上端即 $u_C$ 送反相端；另一条从 $u_O$ 经 $R_2$、$R_1$ 分压得到 $u_P = \pm U_T$ 送同相端。电容充到 $+U_T$ 就翻转，放到 $-U_T$ 再翻转，周而复始。

> **易错点**：换成单限比较器，说死了都玩不成。单限的话你刚过来马上就回去了——电容电压稍微往回退一点，就又变 $+U_Z$ 了，再往回一点变哒哒哒哒，可能抖；频率根本没办法控制，就靠回路那一点点传输延迟在瞎折腾。滞回的好处就是你过来了，想回去还得经过一个历程，而这个历程正好就是方波的脉宽。只有滞回比较器才提供得出这个回差电压。

工作过程我们捋一遍。当输出停在 $+U_Z$ 时，同相端是 $+U_T$。$u_O$ 通过 $R$ 给 $C$ 充电，从 $-U_T$（也可以从零）开始往上长；长到 $u_C$ 等于 $+U_T$ 的时候，它就准备开始跳变了，一旦超过一点点，这里立刻变成 $-U_Z$。

它跳变成 $-U_Z$ 的那一瞬间，同相端也跟着变成 $-U_T$——这一点非常关键。这时电容开始往外放电，一直放到 $u_C$ 接近 $-U_T$、继续减小，砰，这里又变成 $+U_Z$。然后再充电、再放电。充电回路和放电回路是同一个回路，所以时间常数是一样的，出来就是方波。

电容上的电压就是从 $-U_T$ 冲到 $+U_T$，然后从 $+U_T$ 放回 $-U_T$，方波由此出去。

### $T_k$ 是怎么求出来的

那么 $T_k$ 和 $T$ 会不会求？$T_k$ 就是充电（或者放电）走完半程的时间，我们把它算出来。

最简单的 $RC$ 电路，一个 $R$、一个 $C$，注意这个 $u_C$ 的电源是谁？电源就是 $u_O$。

用三要素法：

$$u_C(t) = u_C(\infty) + \left[u_C(0_+) - u_C(\infty)\right] e^{-\frac{t}{\tau}}$$

这个方程已经把两件事说清楚了：当 $t \to \infty$ 时两边相等（那是稳态值）；把 $t = 0_+$ 代进去，两边也都是 $u_C(0_+)$（那是起始值）。

现在填数。

$u_C(\infty)$ 是多少？稳态值是什么？是电容充满之后的那个电压，也就是电源电压 $u_O$ 停在 $+U_Z$ 时的 $+U_Z$。它不是 $+U_T$——要是稳态值是 $+U_T$ 的话那就死定了，一辈子都到不了，因为充到 $+U_T$ 的时候它早就翻转跑人了。

$u_C(0_+) = -U_T$，这是起始点。

时间常数 $\tau = RC$。

所以充电段有

$$u_C(t) = U_Z + \left(-U_T - U_Z\right) e^{-\frac{t}{RC}}$$

而在 $t = T_k$ 的那一刻，$u_C$ 正好等于 $+U_T$：

$$U_T = U_Z + \left(-U_T - U_Z\right) e^{-\frac{T_k}{RC}}$$

$$e^{-\frac{T_k}{RC}} = -\frac{U_T - U_Z}{U_T + U_Z} = \frac{U_Z - U_T}{U_Z + U_T}$$

$$T_k = RC \ln\frac{U_Z + U_T}{U_Z - U_T}$$

放电段同理。由于充电回路和放电回路是同一条回路，$\tau$ 一样，起点和终点又是关于原点对称的两个值，所以放电时间也是 $T_k$，周期就是

$$T = 2T_k = 2RC \ln\frac{U_Z + U_T}{U_Z - U_T}$$

> **提示**：$T_k$ 这个东西必须会求。它就是暂态过程里最入门的那点知识，加上高数里最入门的一阶常系数非齐次微分方程。你们基电要是这块不踏实，回去翻基电的书补一下最入门的部分；不过我这样讲一遍，你们总归会了吧。

### 占空比可调的矩形波发生电路

现在提更高的要求。刚才那个方波，我要改变占空比，别老是一半一半，行不行？

思路你们应该马上就能想到。刚才我为什么说它占空比不可调？因为**充电的回路和放电的回路是同一个回路**。所以要改，就得让这俩回路不一样。

在基电的时候，我肯定不要求你们有这个想法；但在模拟电子技术里，你们能不能实现？用什么？**二极管**。二极管最重要的一个特点，它能规定一个电流的流动方向。

最简单的一个想法：把回路分成两路，一路冲过去，一路放回来。充电时走 $R_3$ 和 $C$，放电时走 $R_4$ 和 $C$。

我不满足在哪儿呢？这些东西全定死了。我最好弄个钮，可调。你们现在很清楚加什么？加**电位器**。加一个电位器，就可调了。而且既然加了电位器，我这两个电阻就可以省了——电位器本身就能提供 $R_3$ 和 $R_4$。

占空比可调：其实就改变了 $R_3$ 和 $R_4$ 之间的比值，通过调节这个接触点，你可以得到各种各样的占空比。

下面还有一个思路，看你们能不能画到这儿了：回去画着玩、推着玩，推那些参数。

### 三角波发生电路，以及一次"南辕北辙"

百尺竿头再进一步。现在手里是方波了，后面接个什么？**积分**。接个积分器，后面三角波就做完了。

三角波一出来，你回想一下刚才那个波形：其实人家三角波比它长得还可爱。前面那个 $u_C$ 还不是直线的，是指数的；这个三角波的两边是实打实的直线段。

你脑子里立刻就有个想法：这个三角波能不能把前面那个 $RC$ 充放电回路**取代**掉？进一步简化，我就不用那个充电回路了。做两套东西多烦。

那我的目标就是：把输出的影响直接引回来，"大笔一挥"。我们在不断的探索中进步。

可是这样一做，我们发现**犯了一个致命性的错误**。

为什么？因为你这样一回来，比较就出问题了。想清楚它的极性：当输出是高电平的时候，那颗电容的电压是在**疯长**（因为 $+U_Z$ 在给它充电）。我现在不接充电回路了，我改接积分器——积分器是反相的，$u_O$ 是高电平时，积分器输出是在**下降**的。

完了，背道而驰，南辕北辙。方向反了，差距不但不收敛，反而越分越大，电路根本锁不住。

有同学说：我后面再加一个反相器。这一次你又成功了，加个反相器咔回来，这边就能用了。对，能用，但你不累吗？

不用。**你为什么非得一棵树上吊死？** 我可以越过它直奔该去的地方，我提供给它不就完事了吗？

```text
   u_o ────► 积分器 ────► 三角波 u_o' ──────► 反相端(－)
   u_o ────► R2 ────● ─────────────────────────► 同相端(＋)
                   │
                   R1
                   │
                  GND
```

读图：输出 $u_O$ 一路送去积分器，积分器出来的三角波送反相端；另一路直接从 $u_O$ 出来，经 $R_2$、$R_1$ 分压（$R_1$ 下端接地）送到同相端，形成 $\pm U_T$ 的门限。极性一正，比较就顺了。

这就是三角波发生电路。

这里面的思想你们要记住：**接到这儿不行，我有很多种改进方法**。我后面加个反相器，一样接到那儿还好用；如果想省一个，就直接拉到同相端，那个反相器就省了。你们回去拿正反正反转一圈，看一看这个波形是怎么形成的——这个过程本身比电路图重要。

## 推出来的锯齿波：从单限比较器一路推到波形变换
> 对应块：BLK44 | 覆盖分集：P45 | 块标题（分集名）：《44-锯齿波发生电路与波形转换电路_4K》

上节课我留的要求是，请大家从一个集成运放出发，一直推到三角波、推到锯齿波。推了吗？推了。

可是我发现一个问题：大家推的过程好像没什么问题，可真拿到这个电路去做分析的时候，又想不通了。有没有这种情况？觉得这个东西又想不通了。

好，想得通想不通先不管，我们还是一起来走一遍这个思路，把这个波形推出来。

### 一根回线，把单限比较器变成滞回比较器

我们从集成运放开始。第一个台阶是单限的、带限幅的电压比较器——很简单，每位同学都画得出来：输入跟一个阈值比，比过了就 $+U_Z$，比不过就 $-U_Z$。

要在单限的基础上做出滞回，道理只有一句：**滞回比较器的阈值和输出有关**。既然阈值跟输出有关，那我一定得把输出量引回到阈值控制端去。就这么一根线引回来，电路就成了滞回比较器——说白了就是正反馈。

```text
  单限比较器 ──（把输出 u_o 引进阈值控制端）──► 滞回比较器
   阈值由外部给定                              阈值随输出跳变
   固定不变                                    才有回差
```

### 输出一跳，阈值就跳：方波是怎么来的

有了滞回比较器的回差，我就可以做方波了——利用这个回差，让电容 $C$ 通过电阻充放电。

这个电路的原理你们懂不懂？方程我们求过。但我还是走一遍。一启动，反正你别管它怎么样，零状态下，这里假设要不比它高一点，要不比它低一点；总归输出不是 $+U_Z$ 就是 $-U_Z$，这里是饱和输出。

假设我这里输出 $+U_Z$。很明显一个道理，它通过 $R_1$ 给电容 $C$ 充电。这时候这块就是 $+U_T$，阈值就变成了 $+U_T$，然后电容电压不断上升。长到比 $+U_T$ 大的一瞬间，这里变成 $-U_Z$。而这里**一旦变成 $-U_Z$，阈值马上变成 $-U_T$**。

> **易错点**：这一点是滞回比较器能构成方波发生电路非常关键的地方——**输出一跳，阈值就跳**。否则你要阈值不跳的话非常麻烦：电容 $C$ 稍微一放电，它又过阈值了，电路根本稳不住。滞回提供的这个回差电压，正是给电容 $C$ 去放电用的。

阈值变成 $-U_T$ 之后，电容 $C$ 开始通过 $R_1$ 放电，降到 $-U_T$ 的时候输出又跳回 $+U_Z$，阈值同时跳回 $+U_T$。你看，跳来跳去这样跳，周而复始地跳变下去。

而这个充电和放电的时间，就决定了方波的周期和频率。

所以这个东西有两条基本原则：

> **结论**：一，阈值必须能够来回跳变，也就是一种滞回的结构；二，这里的输出电压必须是一个**随时间变化**的电压，要有时间充电、有时间放电。把完成一次回差电压的充电时间和放电时间加起来，就是方波的周期。

### 方波后面挂积分器，麻烦出在反相上

进而我们知道，一旦这里是方波，那我很容易用一个积分电路就会把它变成三角波——这是我们最初的构想。

但是这里做了一个变化。我这个东西经过一个积分电路，它变成三角波；而这里，研究这里，这里的波形原来是什么样呢？它是一个充放电的斜坡波形。

那么无外乎我刚才讲的道理：从 $-U_T$ 到 $+U_T$ 有个时间，$+U_T$ 到 $-U_T$ 的变化也有个时间。只要能满足这样的输入要求，我就可以做出方波发生电路。

那么很明显一点，我这个是可以取代它的。如果我真的要取代它，那我把它去掉。但是我们发现有一点问题在哪里呢？**这里和这里正好是一个反相**。反相的情况下，我就不能把它直接拉到这儿了——拉到这儿它就没办法了，它就变化不了了。我不能拉到这个端，但是我可以把它叠加到哪里去呢？同相端。那么我这个就可以拉过来接上去，那我这边就可以接地了。

好，那你现在可以算阈值了。你们这种会算阈值吗？

### 两个阈值，以及两个跃变方向

先提醒一句定义：阈值是什么？$u_P = u_N$ 的时候，$u_I$ 的值。

那我问你们，这个时候这个电路的阈值，我说的是谁的电压？是左面这个，是 $u_o$。谁是 $u_I$？$u_o$。就是说这个 $u_o$ 是那个 $u_I$。

注意啊，阈值一定是有两个，而且滞回的阈值和输出相关。我们来定义这些电阻：这个算一个 $R_2$，$R_2$、$R_1$、$R_3$。

看这张图，同相端接了两路——$u_o$ 经 $R_2$ 进来，$u_{o1}$ 经 $R_1$ 进来，两路在这里相遇；反相端经 $R_3$ 接地。所以按叠加原理，同相端电位是两项之和：

$$u_P = u_o \cdot \frac{R_1}{R_1 + R_2} + u_{o1} \cdot \frac{R_2}{R_1 + R_2}$$

（$u_o$ 单独作用时它贡献 $u_o \cdot \frac{R_1}{R_1+R_2}$，$u_{o1}$ 置零时另一项自然为 0，就是叠加原理。）

反相端是零，所以阈值条件就是 $u_P = u_N = 0$。

当 $u_{o1} = +U_Z$ 时：

$$0 = \frac{u_o R_1 + U_Z R_2}{R_1 + R_2} \quad\Longrightarrow\quad u_o = -\frac{R_2}{R_1} U_Z$$

这就是 $U_{T-}$。

当 $u_{o1} = -U_Z$ 时：

$$u_o = +\frac{R_2}{R_1} U_Z = U_{T+}$$

| $u_{o1}$ | 阈值（$u_o$ 的跳变点） | 这时候 $u_o$ 在干什么 | 越过去之后 $u_{o1}$ |
| :--- | :--- | :--- | :--- |
| $+U_Z$ | $U_{T-} = -\dfrac{R_2}{R_1}U_Z$ | 往下降 | **负跃变**到 $-U_Z$ |
| $-U_Z$ | $U_{T+} = +\dfrac{R_2}{R_1}U_Z$ | 往上升 | **正跃变**到 $+U_Z$ |

> **易错点**：符号别记反。$u_{o1}$ 是 $+U_Z$ 的时候，阈值是**负**的 $U_{T-}$；$u_{o1}$ 是 $-U_Z$ 的时候，阈值是**正**的 $U_{T+}$。

那 $U_{T-}$ 的含义到底是什么？我们把 $U_{T-}$ 这一行展开：这时候 $u_{o1}$ 是 $+U_Z$，$u_{o1}$ 那一项是正的贡献。$u_o$ 减、减、减、减、减，$u_o$ 越减，这个电位就越小。减到小于 $U_{T-}$ 的时候，这块就小于零了。一旦这里小于零，啪，这里就跃变为 $-U_Z$。$U_{T-}$ 就是那个临界值。

所以整个电路，真的是对前面那个知识的深入理解和应用。你一定要深入理解滞回比较器那两个阈值到底是什么、跃变方向是什么。我让你们画传输特性，无外乎就这几点：输出的幅值、阈值、跃变的阈值、跃变的方向。你把这些搞清楚，这个电路看似复杂，其实一点都不复杂。

### 从 +UZ 起步，把一个周期走完

有了这个基础，我们来分析这个电路。你们拿过来总想不明白的，其实就是启动的瞬间。别管它，零状态开始启动。

$u_{o1}$ 总归会上来就定一个状态——要么 $+U_Z$，要么 $-U_Z$，因为这两者不可能在瞬间相等，只要有一点差值，这块就饱和（正反馈嘛）。是随机的，你们挑一个，我们从 $+U_Z$ 开始。

这一瞬间，$u_o$ 目前还是零。$u_{o1}$ 是 $+U_Z$，那么这一块目前是什么？明显就是正。所以肯定保证我的 $+U_Z$ 是维持的。

然后我们一切开始了。**它开始充电。**

很可爱，这里充电——同学们，你不用去算三要素法了，它没有三要素法那个概念了，这里是一个**线性充电**。你要算这个时间简直简单死了：电量除以电流，$\Delta q / i$ 就是 $t$。而 $\Delta q$ 是什么？$\Delta q = \Delta u \cdot C$。

> **定义**：电容本身表明的是这么一种关系——它两端**电量变化值**和**电压变化值**之间的关系。换句话说，电容量越大，在同样的电压变化范围内，电量变化越大，充电的电量就越大。这就是电容值所表征的东西。
> 电感、电容、电阻这些元件的基本物理意义，一定要搞得非常清楚：它到底表征什么。这些概念你一旦延伸开，"分布电容""极间电容""势垒结电容"就都很好理解了。

你有了这个电容的概念，就很清楚了：这个块再加一个 $R_4$，充电电流是多少？

$$i_C = \frac{u_{o1}}{R_4} = \frac{U_Z}{R_4}$$

注意它是个常数——所以才是线性充电。方向是那样冲的，冲进积分节点，那么 $u_o$ 就往负的方向走。怎么叫负增长？开始下降。

下降到 $U_{T-}$，这里变成零了；继续下降，这里就变成了负值；这块出现负跃变，$u_{o1} = -U_Z$。

一旦这里是 $-U_Z$，马上一切从头再来：$i_C$ 电流就变成了往这边充电，方向反了，变成放电了。那这里就会从 $U_{T-}$ 开始长。

**注意，两个关键点同时存在。** 由于 $u_{o1}$ 的影响，使得这里从 $U_{T-}$ 往上长；又由于 $u_{o1}$ 自己也跳成了 $-U_Z$，这一项的贡献使这里变得更负了——$-U_Z$ 加上 $U_{T-}$ 使得这里一直小于零，从而保证这里稳稳地是 $-U_Z$。

然后它从 $U_{T-}$ 开始长，长到由于这里变成 $-U_Z$ 了，我要想这里重新达到零，$u_o$ 必须达到 $U_{T+}$。

```text
       u_o1
  +UZ   ┌──────────────┐                ┌─────────
        │              │                │
  ──────┘              └────────────────┘
        └──────────────────────────────────────→ t

       u_o
  UT+   ●                               ●
            ╲                         ╱
                 ╲               ╱
  UT−                  ●
        └──────────────────────────────────────→ t
```

长到 $U_{T+}$ 之后，这块就变成零；再往上涨一点点，它就变成正了。一旦变成正，这家伙会跳成 $+U_Z$。它一旦跳成 $+U_Z$，这块的值唰地一下往上跃，本来在零那块一下跃到一个正值，使得这里更能维持这个 $+U_Z$。那你这里的表现就是，$u_{o1}$ 变成 $+U_Z$；而 $u_o$ 从 $U_{T+}$ 继续下降，奔 $U_{T-}$ 去。然后下降，周而复始地进行下去。

这就是 $u_o$ 和 $u_{o1}$。

### 周期：这次真的不用解方程

这个宽度求不求得出？最简单：$\Delta u$ 是什么？

$$\Delta q = \left(U_{T+} - U_{T-}\right) \cdot C$$

再除以我的 $i_C$，这就是这里的 $T$：

$$T = \frac{\left(U_{T+} - U_{T-}\right) C}{i_C} = \frac{\dfrac{2R_2}{R_1}U_Z \cdot C}{U_Z / R_4} = 2\,\frac{R_2}{R_1} R_4 C$$

$$f = \frac{1}{T} = \frac{R_1}{2 R_2 R_4 C}$$

三角波发生电路的计算真的比我们前面最简单的方波容易得多。那个东西毕竟还要指数、对数这样去算，因为它是个近似量；而这个家伙很好。

所以这是这样一个分析过程，真的是一个很简单的东西。但你们要掌握基本原则。

### 看书不要为书所左右：公式要学到第几层

很重要的一点，同学们：**你们看书不要为书所左右**。我现在发现你们很多同学有这个问题——看了书，然后把我讲的忘了。书仅仅是参考，最重要的是你对这个知识的理解。

一个知识你如果理解透了，一个定理、一个定义你真的理解透了是什么概念？咱们不从严谨的概念上说，我形象地说：你换十遍对它的解释，听懂了吗？哪怕你把它比喻成流星，比喻成什么东西，只要你比喻得对，用比拟的手法，只要比拟得对，说明了它其中的含义，神似。你能说出十种神似的解释，这叫你理解透了。如果说你背得一字都不差，那叫你背完了，你还是什么都不懂。

公式同样的道理，也有几个层次：

> **结论**：
> 第一，公式根本就不会，啥都不会——这叫**没学**；
> 第二，公式背下来了，背得滚瓜烂熟——这叫**死记硬背**；
> 第三，公式你推出来了——这叫你有**严密的逻辑**；
> 第四，公式你不仅推出来了，还能用语言把它从物理意义的角度上解释出来——这才叫**学懂**。

就好比电容这个公式：

$$i_C = C \frac{\mathrm{d}u_C}{\mathrm{d}t}$$

它说的是电容两端电压和电流的关系。什么物理意义？如果你脑海里印着的不是简单背一个公式的概念，而是非常深刻的电容的定义——我刚才给大家解释过的——那就不一样了。如果你把数学公式学到死到这个程度，那就麻烦了，清楚吧？

任何一个东西都是这样，不光在电学里面。否则的话，你会发现所有的科学都近似相等：离开它的物理和现实层意义，完全抽象出来，那叫数学。你去推经济学模型、去推咱们信工里变压器的模型，两个矩阵是一样的，都用的是矩阵理论；你再看控制系统，那也是。如果光背公式，最后你怎么回事都不知道。

### 让占空比可变，顺手把三角波拧成锯齿波

接着，这个家伙怎么能变成占空比可变？充电电流和放电电流只要不一样——$\Delta q / i$ 里，$i$ 不一样，不就变成不一样了吗？

在哪弄？同学们知道，就在这儿：做一个充电的路径规则，做一个放电的路径规则，然后这里弄一个电阻。画得很难看，但是很实用。充电一个 $i_C$，放电另一个 $i_C$，肯定就可以随意调节了，这个电路就随意调节。

这样当我调到一个极限的时候，把其中一个边压得很小，它就会变成近似锯齿波。

```text
  u_o1 方波输出
        │
        ├─ R_a ──► 充电路径（u_o1 = +UZ 期间，u_o 下降）
        │
        └─ R_b ──► 放电路径（u_o1 = −UZ 期间，u_o 上升）

   R_a 小 → i_C 大 → 这段陡、这段快、占空比小
   R_b 大 → i_C 小 → 这段缓、这段长、占空比大
                                  ──► 占空比可调的锯齿波
```

这里我画成这样，问你们：上下两个电阻，哪个大？上面的大还是下面的大？

有人说上面，有人说下面。

正确的答案是**下面的大**。为什么？因为上面那一路要陡、要快。

而要陡、要快，就要电流大；电流要大的话，电阻就得小。

> **易错点**：我为什么问"哪个电阻大"，这里其实是设了一个思维陷阱。前面两步——要陡、要快；要电流大——你们全懂，电流要大都答得出来。这个问题就卡在你敢不敢把结论往回推一步：**电阻越小，电流越大**。想通了这一步，上面那一路（$+U_Z$ 那一路）电阻小，下面那一路电阻大，一下子就清楚了。

> **结论**：电阻越小，充放电电流越大，波形越陡、这段耗时越短；电阻越大，电流越小，波形越缓、这段耗时越长。

到这里锯齿波就出来了。

整个这样一个电路，你们现在在脑子里想想，还有任何难点吗？每一步是不是都会了？从单限电压比较器到滞回比较器的推法，然后到矩形波发生器，再到三角波——应该没问题了吧？

```text
   单限比较器
       │  输出引回阈值端（正反馈）
       ▼
   滞回比较器 ──＋回差──▶ 配 R、C 充放电 ──▶ 方波发生电路
       ▲                                             │
       │                                          积分器
       │                                             ▼
       └────── u_o 反相，改接同相端 ◀──────── 三角波发生电路
                                                      │
                                          充放电分两条路走
                                                      ▼
                                            占空比可变 ──▶ 锯齿波
```

我心里多少还有些不安，你们需要自己推。我跟你讲，看我推的时候可顺溜了，顺理成章就下去了，自己推是另外一回事。好了，不能过多纠缠于此。

### 波形变换：用一个开关把半周翻个个儿

除了这些波形发生电路之外，实际上还可以进行波形的转换、波形变换。

锯齿波发生电路其实还有另外一种方法。这种方法的思想属于一种波形的变换——它把三角波变成了很标准的锯齿波。我总想把它当做一种波形变换的例子来说，而不只是从三角波变成正弦波等等，这也是一个波形变换。

它的思想是什么？其实就是把这半周翻个个儿。

那整个电路的构成思路就很清楚：前端肯定是一个三角波发生电路，后面是一个变换电路。这个变换电路是，当我处于前半周的时候，让我这个变换电路的放大倍数是 $+1$；到后半周的时候让放大倍数是 $-1$。如果能做到这一点，就 OK 了。

用怎样一个电路来产生呢？肯定得做一个开关，换句话说，电路里肯定得有开关。这里加了一个开关，开关是通过其他信号来触发的——好比说当我这里是低电平的时候开关断开，高电平的时候开关闭合。

#### 开关断开时：接成差分，放大倍数是 +1

当这个开关断开的时候，你会发现这个放大倍数是多少呢？

输入进来先被两个 $\frac{1}{2}R$ 分一次：这里是 $\frac{1}{2}u_i$，那儿也是 $\frac{1}{2}u_i$。反相那侧 $\frac{1}{2}u_i$ 经 $R$ 过来的电流是

$$i = \frac{\frac{1}{2}u_i}{R}$$

它流进反馈网络，让反馈电阻上的电位差也等于 $\frac{1}{2}u_i$；而同相端本身就是 $\frac{1}{2}u_i$。这里的电位比那边高 $\frac{1}{2}u_i$，那边又是 $\frac{1}{2}u_i$，因此输出是 $u_i$。

所以开关断开的时候，放大倍数是 $+1$。

#### 开关闭合时：退化成反相比例，放大倍数是 −1

开关闭合，你们注意：这个 $u_i$ 就没用了，对这没影响了——这里就是 0，经两个电阻接地。

开关这样一闭合，它就变成一个纯粹的反相比例，所以这块就是 $-1$。

所以你看它整个的构成思路，用这个开关起了个什么作用？控制它是一个反相比例呢，还是一个类似于差分的东西。它用差分构成了 $+1$；用反相比例构成了 $-1$。因此开关就起这样一个作用：$+1$、$-1$。

> **提示**：这个电路我很喜欢，有时候我就这样讲——它特别像下象棋下盲棋那种感觉，让你们的思路、想象力增强一点。

#### 这个开关由谁来控制：三角波自己

进而的思路是什么？你看，我这开关靠啥控制呢？我的开关就靠这个波形来控制。

我高电平怎么来？都从我三角波来。我三角波怎么能变成这样一个波形？三角波现在反过来要变方波了。我怎么能变方波？我用微分电路。

所以微分电路我弄了这样一个，为什么要弄成这样一个高低电平的东西？最简单一点，三极管这种东西如果用高低电平的话，就可以当做一个开关用——三极管的开关作用。那不就成功了吗？就完全做出了一个自动的电子开关，你就可以用它进行这样一个波形的变换。

```text
   ┌──────────────┐   三角波   ┌────────────────────┐   锯齿波
   │ 三角波发生电路 ├──────────►│ 开关切换 +1 / −1  ├───►
   └──────────────┘            └────────────────────┘
          ▲                             ▲
          │ 微分                         │ 方波 → 三极管当开关
          ▼                             │
     ┌────────┐                          │
     │ 方波   ├──────────────────────────┘
     └────────┘
```

### 三角波怎么变成正弦波

书上谈了两个波形变换，但我一直觉得它们仅仅是一个概念——都是怎么从三角波变成正弦波。记得前面讲三角波发生的时候我就说过，正弦波发生器同样可以把它变成方波、变成三角波，道理完全一样。所以现在反过来走一遍：从三角波一样可以变出正弦波。

这一块对你们来说应该不难。有人在学信号，信号作业本都交到我这儿了——三角波你们肯定熟，给它做一次傅里叶级数展开，展开式里会出现像 $\frac{1}{9}\cos(3\omega t)$ 这样的系数，展开完你就发现：这个三角波无非是由 1、3、5、7、9 这样一串奇次谐波叠加出来的波形。不是什么"高频电路"，就是多个正弦波拼出来的。

#### 谐波视角：三角波是一串正弦波的叠加

```text
   三角波 = 1 次 + 3 次 + 5 次 + 7 次 + 9 次 + ...
              │       │       │       │       │
    50 Hz ────┼───150 ┼───250 ┼───350 ┼───450 ┼────→ 频率轴 / Hz
              │       │       │       │       │
              ▼       ▼       ▼       ▼       ▼
   低通 f_c = 100 Hz：只留下 50 Hz 基波，其余全部滤掉
                    → 输出就是一个干净的 50 Hz 正弦波
```

好比说三角波是 50 Hz 的，我要得到 50 Hz 的正弦波。50 赫兹往下一个频率是多少？150，三倍，对不对？那我低通的截止频率只要设在 100 Hz，后面的东西就全干掉，剩下的正好是 50 Hz 的正弦波。滤波法就是这么把基波挑出来的。

反过来玩一下更好玩。信号这东西你不真的动手叠加一遍是不会有体感的：我先弄一个正弦波，然后加一个三次谐波，你会看到它的脑袋被打出一个窝来，跟骆驼似的；再加一个五次谐波，波形就变成那个样子；一直加到九次、十一次，你看到的几乎就是一个方波了。

我当时感触比较深的一点是，我反过来做了一遍——我是怎么把一个正弦波看成方波的。就按傅里叶那一套，一点一点往上加谐波，加到几次近似于方波为止。这东西你们计算机上全都能做，仿真一下就完事了。你们现在信号与系统正在学，认真再推什么公式我肯定不如你们，FFT 都是现成的；但我有一点是知道的——我知道那个东西该什么时候用。

#### 滤波法的死穴：滤波器一动就不能动

用滤波法的麻烦在于：它对三角波的频率变化是有**限制**的。按正常想法，我多少赫兹的三角波进去，就应该出来多少赫兹的正弦波，对不对？可你一旦把滤波器截止频率定死了，你就不敢乱动了。

举个最简单的例子。假设滤波器截止频率就取 100 Hz，为了保证 50 Hz 的正弦波出来。现在偏偏发信号了，发出来的三角波频率从 40 Hz 变到 150 Hz——你死定了，150 Hz 的三角波一个也出不来，输出被全滤掉，什么都没有了。

反过来，有人说那我干脆把截止频率设到 150 Hz，行不行？也不行。你这么设，做 50 Hz 波形的时候 150 Hz 的谐波还在里面，混进去了。

| 截止频率 | 输入 50 Hz 三角波 | 输入 150 Hz 三角波 |
| --- | --- | --- |
| $f_c = 100\ \mathrm{Hz}$ | 正确输出 50 Hz 正弦 | 全被滤掉，没有输出 |
| $f_c = 150\ \mathrm{Hz}$ | 50 Hz 与 150 Hz 一起出来，混了 | 正确输出 150 Hz 正弦 |

> **结论**：截止频率定死之后，可用的输入频率范围就被卡在一个很窄的窗口里。频率变化要大，只有两条路——把滤波器做成自适应的，让它的特性跟着基频走；或者干脆换一种不依赖截止频率的变换方法。

方法都想得出来，至于代价值不值得那么花，那是另一回事了。

#### 折线法：每一段换一套放大倍数

频率变化大的时候，用的是一种近似法——折线法。三角波本来就是折线，正好顺着它办：把三角波一段一段"咔咔咔咔"地折线化，每一段用**不同的放大倍数**。为什么放大倍数要一段一变？因为正弦的形状就是变比一段比一段大、越往后越接近无穷大的东西，按等比的方式往上抬，折出来的就是一条像正弦的曲线。

怎么做到"每一段换一套放大倍数"？靠二极管。二极管导通的条件是电压超过它的开通门限，所以当输入幅值跨过一个门限时，某条支路就自动接通、某个比例就自动切进去。这就是最简单的原理：**在不同的幅值下自动选择不同的通路，就产生了不同的比例**，相当于自动完成了一件事——不用你去调，放进来多大它自己选。

具体到那个电路，前面已经拆过一级，我就不一节一节分析了。抓住这句话就行。

> **易错点**：这一节没有一个电路是要你背下来的。波形变换是概念，电路是概念的产物，记住"变比分段递增"和"用二极管按幅值自动选通路"这两条，剩下的可以自己配。

### 电压和电流之间互相变身

#### 最简单的电压-电流转换

这一章的最后一部分是信号转换，第一个电路最简单：电压电流之间的转换。

怎么把一个电压变成一个电流？我起码要做一个电流负反馈，对不对？当然方法不止一种，也可以用电压-电流串联负反馈，但这里用的是**电流并联负反馈**。

关键在哪？大家看——肯定是电流反馈，$R_L$ 就接在这里。这时候：

$$i_L = i_I = \frac{u_I}{R}$$

$R_L$ 上的电流就等于 $R$ 上的电流，就等于输入电压除以 $R$。一个电压到电流的转换，做完了。

#### 让 R_L 接地：正反馈和负反馈正好对消

这个电路的问题在于：$R_L$ 这个负载上不着天、下不着地，它悬在那儿，没有接地点。一般情况下我们不这么用。

所以要给它加接地。这正是第六章第七节讲"放大电路中的一些正反馈应用"时提到过的电路——它的原型不是这样，原型这里是个电阻；现在把 $R_L$ 接上去之后，$R_L$ 接地了，实现的效果是：$I_O$ 和 $R_L$ 无关。

它的思想其实很简单：

```text
        u_i ──────▶ [ A1 负反馈放大 ] ── u_o1 ──┐
                                                    ├─▶ 经 R0 注入/泄放补偿电流
        u_i ──────▶ [ A2 跟随器   ] ── u_o2 ──┘

        补偿电流 = (u_o1 − u_o2) / R0 ，只由 u_i 决定
        而流进 R_L 的 i_o 恰恰就是这个电流  ──▶  i_o 与 R_L 解耦
```

先做定性分析，这一段最好懂。假设 $R_L$ 变小。如果下面这个电路不存在，$R_L$ 变化必然引起电流变化——$R_L$ 一变小，$i_o$ 必然变大。而 $i_o$ 一变大，某一点的电位是下降的。注意 $R_0$ 摆在这个位置，$R_0$ 是很重要的一个东西，没有 $R_0$ 这个电路就别谈了。这个电位下降就代表 $u_{o1}$ 减小，$u_{o1}$ 减小就把 $i_o$ 的增长抑制住了，最终把 $R_L$ 变化所产生的 $i_o$ 变化扭转回来。

```text
   假设 R_L 变小：

   ①  没加下面那一级时：  R_L 变小 ──▶ i_o 变大（这是必然的）
   ②  下面那一级检测到它：i_o 变大 ──▶ u_o1 下降 ──▶ 经 R0 把变化拉回
   ③  两者作用方向正好相反 ──▶ i_o 的变化被抵消，负载与输出解耦
```

下面那个电路是正反馈，上面是负反馈、局部也是负反馈——这个负反馈和这个正反馈对 $i_o$ 的影响正好抵消，它做的事情就是这一件。定性上很好理解，定量上也很容易分析出来。

我们正式推一下。抓住这几点：

- 上下两个放大电路都处于负反馈状态，所以都有虚短的概念；
- 虚短意味着 $u_{o2}$ 等于中间那一点的电位——$u_{o2}$ 就是一个跟随器的输出；
- $u_{o1}$ 和 $u_i$ 相关，$u_{o2}$ 又可以由 $u_{o1}$ 推出来，所以最后必然得到 $u_{o2} - u_{o1}$ 只是一个和 $u_i$ 相关的量；
- 于是 $R_0$ 上的电流 $(u_{o1} - u_{o2})/R_0$ 只和 $u_i$ 相关。而 $R_0$ 上的电流你会"奇迹般"地发现它就是 $i_o$——因为虚断。

两个东西在抵消，对 $i_o$ 的影响在抵消，用方程就能证明。这样就做成了一个电压和电流的转换。

当然，同样也可以实现电流-电压的转换，那一讲非常清晰，是典型的电压并联负反馈，肯定能实现电流和电压的转换。

> **提示**：这些电路我觉得不是很值得特别提的东西——结构一眼看过去，你推就能推出来。真碰到没推出来的，五个指头数得过来。

### 整流：0.7 V 带来的麻烦

当时在学习的过程当中看到精密整流电路的时候，我觉得运放真的是非常有用。

#### 半波、全波，和那个"馒头波"

什么是整流？把交流变成直流。最简单的整流电路有两种。一种是半波整流：把正弦波的负向部分统统消灭，输出只剩正半瓣，这就是半波整流。还有一种是全波整流：把负的那半瓣翻上去拉到正半边，输出变成像馒头一样的形状——像蒸了一锅馒头一样。

```text
    输入正弦              半波整流              全波整流
    ~~~~~~~              ~~~~~~~               ~~   ~~
   /       \            /       \             /   \ /   \
  /         \          /         \           /     V     \
 /           \        /           \         /     / \     \
─────────────────  ─────────────────       ───────────────────
                          ↑ 负半周被切掉      ↑ 负半周翻上去
```

这样变换之后再加上电容滤波，就能变成直流，这是最简单的把交流变直流的方法。而且注意，变换之后整个的平均值已经上来了——一般说半波整流最后得到的直流电压，比全波的还要低一些，这主要跟后面的 RC 滤波电路有关，到底怎么滤波我们后面再讲。

电路怎么得到？最简单的半波整流就是一个二极管串一个负载电阻 $R_L$。二极管的作用在这里体现得淋漓尽致：只有正向的时候过去，负向的时候被截止；负半周这块没电流，这里没电流也就没有电压，于是输出就是那个只有正半瓣的波。

全波整流可以用四个二极管：给它们构成一条正向通路，再构成一条负向通路，正负半周各走各的路。正半周的时候电流是这样走的，负半周的时候电流还能是这样走——创造出两条路径来，把同一个负载驱动起来，这个想法其实挺有意思的。

#### 当二极管的压降吃掉整个信号

问题是：在电力电子里用这种整流，根本不考虑二极管，为什么？那边都是好几百伏，几十伏、好几百伏，二极管那 0.7 V 跟它无关，对不对？

但有的时候就麻烦了。有的时候我们采样的信号源很微弱，比方说交流信号总共就几十个毫伏，可怜得很。你非得给它做个整流，可你找不到开通电压只有 1 mV 或者几十微伏的二极管。0.7 V 的二极管往那一放，你不用整了——人家直接告诉你我就是零。几十毫伏往那一加，出都出不来，你还整流什么？

> **易错点**：二极管的 0.7 V 开通电压在强电场合可以忽略，但在弱信号场合它可能就是整个信号本身。判断一个整流电路能不能用，先看信号幅值和二极管开通电压的量级关系。

这时候怎么办？有难度了吧？有了运放，我们就可以欣赏一下了。

#### 精密半波整流：让运放去跨过 0.7 V

先不看那个二极管，这一块实际上还是一个整流电路，只是把运放构架进去了。整个工作的思路是这样的。

当我这里是正的时候，$u_I > 0$，正半周，这个运放输出是负的。一旦输出为负，二极管必然打通。如果不打通，它就没有反馈——不打通就没有反馈，运放会一路狂奔，马上肯定能让你打通。两个二极管都不导通的话，这里就是开环，开环几乎是不可以的；一旦开环，输出就是负饱和，负饱和肯定能把这个二极管给干通。一通，这里就形成了负反馈，电流就是这样流的，然后 $R_f$ 和 $R$ 做成 1:1 比例。

```text
   正半周：u_i > 0 ──▶ 运放输出为负 ──▶ D2 导通 ──▶ 反馈闭合（负反馈）
                  ┌──────────────────────────────────────────┐
   u_i ──(+)──▶ [ 运放 ] ──▶ D2 ──▶ R_f ──▶ u_o = −u_i        │
              (−) ▲                                      │
                   └──────────────────────────────────────┘

   负半周：u_i < 0 ──▶ 运放输出为正 ──▶ D1 导通、D2 截止
                  ──▶ R_f 上无电流 ──▶ 两端电位拉平 ──▶ u_o = 0
```

先把 D1 跳过去不管，从 $u_i$ 反着看：这个电路在正半周做的是一个负向的 1:1 反相。

然后看这里小于零的时候，运放输出变成正的。这里一旦变成正的，D1 就导通，而 D2 是截止的，过不去——这里是正的，那里是负的，D2 根本过不去。只能通过 D1 过去，D1 过去、D2 过不去，那么 $R_f$ 上就没有电流。$R_f$ 上没有电流，就代表这里的电位和那里的电位是相等的，拉平了。

> **定义**：精密整流的本质，是巧妙地既利用了二极管单向导电的特性，又把二极管的压降用有源器件去克服掉——集成运放在克服它的压降。这一步是普通二极管整流永远做不到的。

#### 全波整流不必多给一条通路

下面这个电路还要妙，它做全波整流。我们要想把负的那半瓣补成馒头，就要多造一条通路；这一版没有这么干，我们是把这做得更复杂吗？没有。它用的是**波形叠加**的方法。

什么叫波形叠加？你不是已经得到了负半周的整流结果吗——想一下：我如果把这个整流波的幅值放大一倍，再加上上面那个正弦波形，叠加起来会变成什么？两倍减这一，还是它自己，但它就出来了，是全波。

```text
        u_i ──────────────( ×1 )─────────▶┐
                                             ├──▶ 差放求和 ──▶ u_o = |u_i|
        u_o1（半波整流输出）─( ×2 )──────▶┘
                          放大两倍：差放反馈电阻取 2R

   u_i > 0 时：u_o1 = u_i   ──▶  u_o = 2u_i − u_i = u_i
   u_i < 0 时：u_o1 = 0     ──▶  u_o = 2×0  − u_i = −u_i
   两条曲线一拼，全波整流就成了
```

所以我们能不能做这样一个电路？很简单。我那边的正弦波是差放的一个输入端，我的整流波是差放的另一个输入端——整流波形放大两倍，正弦波形按一倍，然后叠加，这就出来了。这就是后面这个电路。我这里是放大两倍，$2R$；我那边 $u_I$ 过来就是一倍，然后 $u_{o1}$ 过来是做两倍的叠加，在这里一叠加，就会得到这样的波形。这就做成了全波整流。

精密整流电路值得你们欣赏，它整个的思想都非常非常好。

### 压频转换：把电压"数"出来

还有一个电路叫做压频转换，电压频率转换。这个电路我给你们提过吗？我在讲温度计的时候提过：我说把一个电压做压频转换，然后再做一个计数，就可以把它变成数字量。

#### 电荷平衡式：充电时间和电压挂钩

电压和频率到底怎样转换？思路很简单。第一种方法是电荷平衡式。

这里放一个滞回比较器，一个积分器。$u_I < 0$，我就要把这个电压转换成频率。充电，充电时间和我的 $u_I$ 是不是相关？没错，这个时间跟 $u_I$ 直接相关。$u_I$ 的绝对值越大，充电时间越短还是越长？短。

看细节：$u_I$ 越大，$i_1$ 电流越大；$i_1$ 越大，充电到同样那个 $u_{T2}$ 的时间就越短。所以就建立起这样一个关系——$u_I$ 实际上和充电时间直接相关。

#### 波形上的两个时间

一旦充到 $u_{T2}$，滞回比较器马上输出高电平。高电平控制下面的开关闭合，这块是个大电流，瞬间就把它重新充回 $u_{T1}$。这个时间非常非常短，在整个周期里面可以忽略不计。

```text
        一个完整周期 T = 充电 T1 + 放电 ΔT

        ├──────────── 充电 T1 ────────────┤├─ ΔT ─┤
                  小电流 i1 = |u_i| / R         大电流，瞬间回拉
                  充到 u_T+ 所花的时间            ΔT 短到可忽略
```

但是它毕竟代表着频率的输出，每次都有高电平输出。真正决定这个频率的值，这个 $T$ 几乎是由 $T_1$ 来决定的；$T_1$ 又由这里的电压决定。所以电压越大，$T_1$ 越小，频率越高；电压越小，$T_1$ 越长，频率低下来。是不是把电压变成了一个频率？这就是一个压频转换电路。

> **提示**：看波形不要比电路，先比波形。这个电路和那个电路哪个不一样？好像一样——其实充电路径和放电路径不是同一条路径，充电路径的时间常数要比放电路径大得多，这就是概念本身。

具体到电路里：当 $u_{o1}$ 是 $+U_Z$ 的时候，通过二极管——甚至连限流都可以不要了，当然不可能，用一个很小的限流电阻，就给它充电了。然后把这一块改了，不用 $U_Z$ 去控制，改放我们的 $u_I$。

整个过程是这样的：$u_I < 0$，假设负多少伏，负的 $u_I$ 加到电容上就开始充电。这个长高的过程就是积累 $T_1$ 的过程。长到刚才所说的 $u_{T+}$ 的时候，这块就开始过零了；一旦变成正的，这块马上跳成正 $U_Z$，大电流灌进去了。注意它当然也有电流，但是这两个电流比起来一定是不可比的，这时候几乎是大电流把那个小电流淹没了，瞬间就把它又充回到 $u_{T-}$，然后这里又重新变成 $-U_Z$，然后这个断掉，它又慢慢地去积分。

这就是电荷平衡式。只不过书上画出来长的是这个样子，你们现在还得有这个本事：人家把两个运放调了个个儿，其实就是我那个图，只不过把后面那个拉到前面去了、前面的拉到后面去了，你们还得有本事认出来。这种电路结构很简单——一个滞回比较器加一个积分器，无外乎谁摆在前面的问题。

#### 复位式：换个更省事的开关

除了电荷平衡式，还有一个复位式的，思想也很简单：它们都需要电压比较器，只不过那个是滞回比较器，这个是普通电压比较器；用一个高电平把这个开关关掉，实际上就做电容短路放电。

更简单的电路结构是弄个三极管。低电平充电：当输入大于零，$u_{o1}$ 开始减小，减小到这里输出负的 $U_Z$；这里一变负的 $U_Z$ 就短路，马上把电容放成零；一放成零，这里又变成 $-U_Z$，然后它又关断，接着又开始充电，辛辛苦苦地积那个 $T_1$。积到一定程度又放掉，然后再积，波形就出来了。这就是压频转换。

### 功率放大电路：课程还剩的两件事

对于第九章来讲，第九章第一节我已经完全讲过了。在第三章的时候我讲过功率放大电路，你会发现推导过程一模一样——我是把第九章移到了第三章去讲，只不过当时没跟同学们讨论功率的计算问题。9.2 这一节就是功率的计算问题，这一节你们完全有能力自己推，是一个非常简单的功率计算，没有必要我来给你们推。

所有这些结束之后，第一章到第八章的所有内容到现在就完整了。做完了这些之后，实际上我们在做模拟电路里面还有两个问题要解决，其他的我们就不再关注了。

第一个问题是：放大电路一级一级地构成了，前面我要做一个功率输出。这一点我在别的场合已经讲过一点——理想运放里面，最后一级是一个输出，我讲过一些。这里涉及到的就是，我怎样把这样一个信号作为功率输出出去？前面都放大放大放大，放大的电压信号都比较大了，但是我到最后怎么去推、怎么输出出去、怎么去推动其他负载，这很重要。

第二个问题是：电路里都有直流电源，这直流电源到底是由谁提供的？怎样提供的？怎样构造一个直流电源？在剩下的时间里，我们将讨论这两个问题。

#### 大信号：h 参数在这里失效

先看功率放大电路。什么是功率放大电路？实际上就是前面什么东西都做好了，最后差的一块：给负载提供足够大的信号功率。

一般规律来说，这种功率放大电路的特点是什么？电压的幅值已经放大到我们足够用了，基本上电压幅值已经够用了，但我最终要输出一个大功率，怎么办？继续加大它的电流，继续加大它的功率。

所以分析它的思路跟我们前面的不一样。前面我们能用 $h$ 参数等效——为什么？因为信号小，而且我还专门挑最好用的中间那一段。现在不行了：电压信号很大，你不能再用 $h$ 参数等效的思路去分析它，一般规律来说应该用图解法。

而且它的特点还在于：信号比较大，我用了特性曲线的很长一段，必然会有非线性的部分。也就是说这种功率放大电路一定会伴随着非线性失真。

> **结论**：大信号电路有两条规矩——分析用图解法，不用小信号等效电路；必然存在非线性失真，所以必须给非线性失真单独设立一个指标。

#### 功放的四把尺子

有了非线性失真，我们就需要一些衡量的、或者是评价的指标。

第一个，最大输出功率 $P_{om}$——指负载可以获得的最大交流功率。最典型的功率放大电路在哪里？在扬声器的前级推动，藏在桌子里的那个功放。只要家里有音响，包括家庭影院什么的，它一定有一个功放。功放是一种音源的功放，是对声音的功率放大。它有个 input 的地方，DVD、唱机什么信号输进去；后面 output 的地方，把音箱挂上，推动它。至于推 5.1 声道什么那是另一回事，但它是一个功率的放大。还有过去老的功放你摸过没有——一摸它是很沉、很重的，那个东西很重。$P_{om}$ 就是扬声器上所能得到的最大的交流输出功率。注意 $P_{om}$ 是一个最大值，换句话说就是我这边使劲喊，它能拉到的最大输出功率，我不可能用一个平均值来算。$P_{om}$ 越大，功放就越好。

```text
   input  (DVD / 唱机 / 信号源)
      │
      ▼
   ┌──────────────────────────────────────┐
   │            功 放                     │   很沉、很重
   │   内部：多级电压放大 + 末级大电流驱动  │   指标：P_om、η、THD
   └──────────────────────────────────────┘
      │
      ▼
   output ──▶ 音箱（负载）
```

第二，效率 $\eta$。既然谈到功率了，功放一定要谈效率：

$$\eta = \frac{P_{om}}{P_{DC}}$$

有同学有这个疑问：不是直流啊，我们家那功放插的是交流电源。插了交流电源之后一定要把它变成直流来供电——这是第十章的内容。它有个电源变换器，把交流电变成直流电，再给整个系统供电。所以对于功放来说，它相当于一个直流输入，$P_{DC}$ 是直流输入的总功率。实际上对于一个单管放大电路来说，它的直流就是 $V_{CC}$ 乘以输出电流；如果忽略 $I_B$，就是 $V_{CC}$ 乘以 $I_C$。

| 指标 | 含义 | 越好还是越差 |
| --- | --- | --- |
| $P_{om}$ 最大输出功率 | 负载上能获得的最大交流功率 | 越大越好 |
| $\eta$ 效率 | $P_{om} / P_{DC}$，直流输入中有多少变成了有用输出 | 越高越好 |
| THD 总谐波失真 | 非线性产生谐波的总量 | 越低越好 |
| 晶体管极限参数 | 最大电流、最大耗散功率、最大击穿电压 | 越大余量越安全 |

第三，晶体管的极限值。这个电路里面的各种器件、这里的晶体管，对它的考验都用到了它的极限值。选晶体管的时候一定要考虑它的极限值：最大的电流、最大的耗散功率、最大的击穿电压等等。因为过来的全是大信号，所以这个时候我们对晶体管的考虑都是一些极限值的考虑。

第四，THD，总的谐波含量。刚才不是说过吗，它有非线性的东西在，它就会产生谐波，这个谐波含量越低越好。

所以总体来讲，如果我设计一个功放，我的第一目标是：**在不失真的条件下，让效率越高越好**。后面的几个设计电路都是跟着这一个条件往下走的。
