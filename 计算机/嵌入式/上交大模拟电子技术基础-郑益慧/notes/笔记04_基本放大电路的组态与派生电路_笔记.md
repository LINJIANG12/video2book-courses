# 基本放大电路的组态与派生电路

## Q 点漂移的三条来源

* **推动 Q 点移动的因素**

    * 温度：对静态工作点影响非常大。

    * 电源波动：$V_{CC}$ 自身抖动，Q 点跟着抖动。

    * 元器件老化：电阻贴到板子上不是一成不变，会用会老化，参数慢慢漂移，同样推动 Q 点移动。

* **三种手段的分工**

    * 电源波动：换成稳压电源，把波动压到足够小即可视为消除。

    * 元器件老化：出厂前先做一轮老化，把参数漂移的那一段"走合"掉，静态工作点在老化之后锁定。

    * 温度：外部条件无法解决，只能从电路结构上控制。

    * > **易错点**：温度这一条想靠外部条件摆平是行不通的。半导体材料怕热——机房和宿舍的差别就在空调；不可能夏天给晶体管吹风扇、拿冰块，冬天抱在怀里焐着。**绝不能祈求于"温度不变"**。

## 负反馈稳定 Q 点的因果链

* **稳定的最终目标**

    * 只要温度变化时 $I_C$ 不变，稳定任务即告完成。

* **反向抑制链**

    * 温度升高直接推动的只有第一环 $I_C\uparrow$，后面每一环都由 $I_C$ 自己引发。

    ```text
       温度 ↑
          │
          ▼
        I_C ↑ ──▶ I_E ↑ ──▶ U_E ↑ ──▶ U_BE ↓ ──▶ I_B ↓ ──┐
        ▲                                                      │
        └────────────────── 拉回来，抵消掉 ────────────────────┘
    ```

* **反馈（Feedback）**

    * > **定义**：输出量的变化被引回输入端，从而改变输入量、进而影响输出量，这种状态叫反馈；稳定 Q 点需要的是负反馈。

## 发射极电阻的接入

* **出发点**

    * 输入取自 $b$、输出取自 $c$ 时，$E$ 点直接接地、电位锁死，$I_C$ 上升时无从下手。

    * 要让 $E$ 点电位能随 $I_C}$ 变化，唯一办法是在接地点与发射极之间串入一个电阻 $R_E$。

* **$R_E$ 产生抑制的五步**

    * 温度升高 → $I_C$ 升高。

    * $I_C$ 升，$I_E$ 如影随形，只差一个 $I_B$，两者几乎模子刻出来。

    * $I_E$ 升 → $U_E$ 上升，且上升量远大于其他量的变化量。

    * $U_E$ 升 → $U_{BE}$ 被拉低 → $I_B$ 降 → $I_C$ 被拉回。

    * 净效果：$I_C$ 仍有上升，但原本十步的蹿升被 $U_{BE}$ 的下降抵消掉九步半。

* **本质**

    * $I_C$ 是输出量，$U_{BE}$ 属于输入环节，$R_E$ 在两者之间建立纽带，把输出绕一圈引回输入，作用就是反馈。

## 分压式偏置与 $U_B$ 的稳定

* **$U_B$ 也会变**

    * $U_{BE}$ 下降的结论以 $U_B$ 不变为前提，而 $U_B$ 实际是变的，只是变化量小。

    * 解决办法在前端再加一级电路：分压式稳压电路。

* **分压支路的取法**

    * > **做法**：让分压下支路的电流 $I_{B2}$ 远远大于基极电流 $I_B$。

    * 二者差着好几个数量级时，基极电位近似等于两个电阻的分压值，与 $I_B$ 的波动几乎无关。

    * $U_B$ 稳住、$U_E$ 继续跟着 $I_C$ 跑，两头一稳，Q 点即稳定。

* **分压式 Q 点稳定共射电路**

    ```text
                         +Vcc
                           │      │
                          Rb1     Rc
                           │      │
         ui ── C1 ──●──────┤      │
                      │     │      │
                     Rb2  ┌──┴───┐ │
                           │  Q1  │ │
             GND         B │      │ C├──Co──RL──GND
                          └──┬─┬──┘
                             RE│E
                             │ │
                            ┌──┴──┐
                           RE    CE
                             │    │
                             └─┬──┘
                               │
                              GND
    ```

    * 信号经 $C_1$ 进基极，$R_{b1}$、$R_{b2}$ 分压供电；集电极经 $R_C$ 接 $V_{CC}$，并从 $C$ 端经 $C_o$ 送出；发射极经 $R_E$ 落到负端，$C_E$ 跨接在 $R_E$ 两端。

    * > **结论**：判断一个电路是不是 Q 点稳定电路，看直流通路就够——分压电阻加发射极电阻这一段就是全部。

* **直接耦合版本**

    * 直接耦合时 $R_{b2}$ 从基极节点直接拉到地，负载 $R_L$ 在直流上同样接地，分析时嫌麻烦可当空载处理。

    * > **易错点**：不能把阻容耦合的"耦合电容短路即成直接耦合"照搬。直接耦合画直流通路时 $R_{b2}$ 直接接地，会与 $R_{b1}$ 并联把整个偏置网络短掉一截，电路根本不成型。

## 静态工作点的求解：戴维南等效加电位法

* **等效对象**

    * 对基极端口向电路内部作戴维南等效：开路电压是分压值，等效电阻是 $R_{b1}$ 并 $R_{b2}$。

    $$V_{CC}' = V_{CC}\cdot\frac{R_{b2}}{R_{b1}+R_{b2}},\qquad R_b' = R_{b1}\parallel R_{b2}$$

* **回路方程**

    * $R_{b1}$、$R_{b2}$ 整体换成"$V_{CC}'$ 串 $R_b'$"后，电路恢复成熟悉形状，按电位分析法从电源正极绕一圈回负极。

    ```text
       Vcc' ── Rb' ──● B ──(BE 结, UBEQ≈0.7V)──● E ── RE ── GND
            ▲                                             │
            └─────────────────────────────────────────────┘

       回路方程： Vcc' = IBQ·Rb' + UBEQ + IEQ·RE
    ```

    $$V_{CC}' = I_{BQ}R_b' + U_{BEQ} + I_{EQ}R_E$$

    * 解出 $I_{EQ}$、$I_{BQ}$ 后 $r_{be}$ 随之确定，后面是常规动态分析。

    * > **提示**：戴维南等效与电位法是通用武器，任何含源网络都用得上，是这一段最需要动手的部分。

## 交流通路与电压增益

* **交流通路画法**

    * 直流源全部置零，把原图镜像翻下来即得；受控源 $\beta I_b$ 从 $e$ 流向 $c$。

    ```text
              Ui                            Uo
               │                             │
         b ●───┴────[ r_be ]────┬──────● e   │
                                │      │     │
                          ( ↑ β·Ib )   │     │
                                │      │     │
                                └──────● c ──┴──[ RC ∥ RL ]── GND
                                       │
                                      [ RE ]
                                       │
                                      GND
    ```

* **电压增益**

    * 输出端：$U_o = -\beta I_b(R_C\parallel R_L)$。

    * 输入端按电位分析法一段一段相加，$R_E$ 上流过的是 $(1+\beta)I_b$：

    $$U_i = (1+\beta)I_b R_E + I_b r_{be}$$

    $$A_u=\frac{U_o}{U_i}=\frac{-\beta (R_C\parallel R_L)}{r_{be}+(1+\beta)R_E}$$

* **输入电阻**

    * $R_i' = r_{be}+(1+\beta)R_E$，$R_i = R_i'\parallel R_{b1}\parallel R_{b2}$。

* **$R_E$ 带来的两难**

    | | 对直流（稳 Q 点） | 对交流（要电压增益） |
    |---|---|---|
    | $R_E$ 大 | 杠杆长，$I_C$ 稍变 $U_E$ 就上去，稳得牢 | 分母 $(1+\beta)R_E$ 变大，增益掉下来 |
    | $R_E$ 小 | 不灵敏，稳不住 | 增益大 |

    * $R_C$ 一般在 $3\text{k}$ 量级，再并 $R_L$ 只会更小；$R_E$ 想稳得住也得好几千欧，分子分母一摆，比值小于 1，电压增益无法使用。

## 旁路电容与集成的死结

* **在 $R_E$ 两端并 $C_E$**

    * 电容对交流相当于短路：直流时 $R_E$ 保留、稳 Q 点功能一点不损失；交流时 $C_E$ 把 $R_E$ 彻底旁路，交流通路重新变成基本共射的样子，矛盾瓦解。

    * > **结论**：阻容耦合的好处是直流靠 $R_E$、交流靠 $C_E$ 短路，两套需求各得其所。

* **集成带来的限制**

    * 一个这样的电路就含三个电容，集成电路里成千万上亿个电路，芯片面积和鼓包高度都容不下这么多电容。

    * 要集成只能直接耦合，电容一个也用不上，于是必须保留 $R_E$，形成矛盾。

* **矛盾的一种解法**

    * 需要一种电路让 $R_E$ 直流下顶用、交流下自动消失。

    * 直流情况下 $R_E$ 的功能被加倍：放一个 $10\text{k}$ 的 $R_E$，它当 $20\text{k}$ 用。

    * 交流情况下这个 $10\text{k}$ 的 $R_E$ 消失，且没有给任何电容。

    * 这种电路叫差分放大电路。

## 共集电极放大电路

* **构成**

    * 输出从 $e$ 取，输入仍在 $b$，共用的是 $c$；$e$ 上必须带电阻 $R_E$ 才好取输出，而 $R_E$ 本身就是被拿来用的，无需消灭。

    * 集电极不再接负载，经 $R_C$ 接 $V_{CC}$，对交流而言就是地；$R_L$ 跨接在 $R_E$ 两端。

    ```text
                       Vcc
                        │        │
                       RB        RC
                        │        │
      ui ── C1 ────●────┤        │
                      │    │  Q1    │
                     GND  B       C├──────── GND
                        │        │
                        E        │
                        │        │
                       RE        │
                        │        │
     uo ────────────●───┤        │
                      │   │        │
                     RL   │        │
                      │   │        │
                     GND ─┴────────┘
    ```

* **微变等效画法**

    * 难点在于集电极在图上方却对交流是地，画法接不上；解法是把整张图翻转，让集电极端直接接地，尖尖处接的正是 $R_E$。

    ```text
              Ui                            Uo
               │                             │
         b ●───┴────[ r_be ]────┬──────● e ──┴──[ RE ∥ RL ]── GND
                                │      │
                          ( ↑ β·Ib )   │
                                │      │
                                └──────● c ──── GND（交流接地）
    ```

    * $c$ 与 $e$ 之间本来还有 $r_{ce}$，按惯例忽略不画；受控源仍从 $e$ 指向 $c$。

    * > **易错点**：翻转后 $c$ 和 $e$ 的上下位置与共射不同，不必怀疑画错。

* **电压增益**

    * $U_o$ 就是 $(1+\beta)I_b$ 流过 $R_E\parallel R_L$ 的压降；$U_i$ 比 $U_o$ 还多一个 $I_b r_{be}$：

    $$A_u=\frac{(1+\beta)I_b R_E}{(1+\beta)I_b R_E+I_b r_{be}}=\frac{(1+\beta)R_E}{(1+\beta)R_E+r_{be}}$$

    * 结果小于 1 但趋向于 1，实际常为 0.98、0.99，原因是 $(1+\beta)R_E$ 远大于 $r_{be}$。

* **放大的是功率**

    * 电压略微缩小，电流由 $I_b$ 变为 $I_e$ 实实在在放大，功率随之放大；输出与输入几乎同相位同大小，故称射极输出器或射极跟随器。

* **输入电阻**

    * 不能从入口放端口电压，$U_i$ 显然可从负载跨过；应在管子处放 $R_i'$：

    $$U = (1+\beta)I\cdot(R_E\parallel R_L) + I\cdot r_{be}$$

    $$R_i' = r_{be}+(1+\beta)(R_E\parallel R_L),\qquad R_i = R_i'\parallel R_B$$

    * $R_L$ 是 $R_i$ 的一部分：写 $R_E$ 而漏掉并联的 $R_L$ 是常见笔误。

* **输出电阻**

    * 独立源置零（$U_i$ 短路）后 $r_{be}$ 与受控源一并消失，$R_E$ 与 $R_L$ 并联支路保留：

    $$R_o' = \frac{r_{be}}{1+\beta},\qquad R_o=\frac{r_{be}}{1+\beta}\parallel R_E$$

    * 道理很直白：放进电流 $I$，流过 $r_{be}$ 的只有 $I/(1+\beta)$。

    * > **易错点**：$R_o$ 里永远不加 $R_L$。$R_o$ 是站在 $R_L$ 那边往回看的结果，不能把自己包含进去。

* **与基本共射的对比**

    | | 基本共射 | 共集（射极输出器） |
    |---|---|---|
    | 输出取自 | 集电极 $c$ | 发射极 $e$ |
    | $A_u$ | 负值，绝对值通常远大于 1 | 正值，小于 1 但非常接近 1 |
    | $R_i$ | 小，$R_i'$ 就是 $r_{be}$ 量级 | 大，$R_i' = r_{be}+(1+\beta)(R_E\parallel R_L)$ |
    | $R_o$ | $R_C$，几 $\text{k}\Omega$ | $\frac{r_{be}}{1+\beta}\parallel R_E$，几十 $\Omega$ |

    * > **结论**：射极输出器放大功率、加大输入电阻、减小输出电阻（输出电压稳定性极好），因此可以放在第一级去抢电压型信号源的信号。

## 放大的统一原则与分析通则

* **为什么不背电路**

    * 背一个电路，那个电路是死的；掌握一个原则则通用。

    * 拿到电路画出交流通路后，只把三极管用简化 $h$ 参数模型（微变等效模型）替换掉，其余部分不动，所得即是简化 $h$ 参数等效电路。

    * 替换之后电路变成线性电路，任何含三极管的电路只要还在小信号、低频小信号模型下都能用这套方法求 $A_u$、$R_i$、$R_o$。

* **先静态后动态**

    * $r_{be}$ 是与直流静态相关的参数，静态工作点不同则 $r_{be}$ 不同；静态影响动态，所以必须先求静态。

* **简化 $h$ 参数模型的端口**

    ```text
                +----------+
          b  +--|   r_be   |--+  e
                |          |
          c  +--|  β·I_b   |--+  e
                |  ↓ 电流  |      (受控源在 c-e 之间，方向 c -> e)
                +----------+
    ```

    * $b$–$e$ 之间是电阻 $r_{be}$；$c$–$e$ 之间是 $\beta$ 倍 $I_b$ 的流控电流源。

    * 电流源方向可反画，只要表明 $c$–$e$ 之间的逻辑关系即可；沿 $b\to e$ 方向理解则电流源画 $c\to e$，反之亦然。

    * NPN 与 PNP 的直流通路正负不同，但换成简化 $h$ 参数等效电路后完全一样，因为模型本身一模一样。

    * > **易错点**：口诀不能替代判断。$r_{be}$ 在 $b$–$e$、受控源在 $c$–$e$，每次都要重看端口标号，而不是顺着上一笔的惯性往下画。

* **为什么要等效成线性元件**

    * 三极管本身非线性，但低频小信号时信号很小，工作在特性曲线上一小段，这一小段可折线化近似为直线，于是能用线性元件取代，使整个电路可用线性方法求解。

* **输入输出电阻的求法**

    * 二者都是在端口加一个 $U$、标一个 $I$，求出 $U$、$I$ 的关系即可；通常不直接算 $\frac{U}{I}$，而是用 $I$ 表示 $U$，括号里的系数就是电阻。

    * $R_o$ 是把前端放大电路做戴维南等效后的戴维南内阻，所以不能把后级负载 $R_L$ 放进去；$R_i$ 是从输入端口看进去、包含后级整个放大电路的等效电阻。

    * 同一电路从不同端口看进去的等效值不同，所以输入电阻和输出电阻是两个不一样的数。

    * 电流等效的快速判据：入端电流为 $I$，后面出现 $\beta I$ 则该电阻被"升"了 $\beta$ 倍，后面出现 $\frac{1}{\beta}I$ 则被"降"了 $\beta$ 倍——熟练后看原电路即可判断，不必先画交流通路。

## 组态的命名与信号入口

* **三种组态的划分**

    * 共射：输入从 $b$ 进、输出从 $c$ 出，共用发射极。

    * 共集电极：输入从 $b$ 进、输出从 $e$ 出，共用集电极。

    * 共基：交流通路里输入从 $e$ 进、输出从 $c$ 出，共用基极。

* **信号为什么不从集电极进**

    * 放大的物理链条是 $u_{be}$ 变化引起 $i_b$ 变化、$i_b$ 变化引起 $i_c$ 变化、$i_c$ 输出出去。

    * 从集电极进来无法引起 $u_{be}$ 变化，只有从 $b$ 或 $e$ 进才能改变 PN 结电压，信号才按上述链条被放大。

* **并存的两种类型**

    * 共射与共集电极都是从组合、从设计起步逐级推出来的，共基是同一套原则的第三次应用。

## 基本共基放大电路

* **组成**

    * $V_{BB}$ 给输入回路一个合适的静态工作点使发射结导通（正偏），$V_{CC}$ 使集电结反偏，与推基本共射时的出发点完全一致。

    ```text
                       V_BB                        V_CC
                        │                           │
                        │                        R_c │
                        │                           │
           +------------+-----------+       +-------+------+
           │            │           │       │       │      C_2
           │            b           c       │       │      │
           │       +----+----+      +-------+      R_L
           │       |   NPN   |      |               │
           │       +----+----+      |               │
           │            e           |               │
          R_e            │           │               │
           │            │           │               │
          C_1            │           │               │
           │            │           │               │
      u_i--+------------+-----------+---------------+------+-- GND
    ```

* **不放大电流**

    * 输入电流是 $I_e$，输出电流是 $I_c$，两者几乎不变，电流没有放大。

* **电压增益**

    * $U_o = \beta I_b (R_c\parallel R_l)$；$U_i$ 用电位分析法分段相加，$I_e = (1+\beta)I_b$：

    $$U_i = I_b\big[r_{be} + (1+\beta) R_e\big]$$

    $$A_u=\frac{\beta (R_c \parallel R_l)}{r_{be}+(1+\beta) R_e}\;\approx\;\frac{\beta (R_c \parallel R_l)}{r_{be}}$$

    * $R_e$ 一般很小、几乎等于信号源内阻，此时电压增益与共射相当；所以做共基时 $R_e$ 要刻意做小。

    * > **易错点**：$R_e$ 做大会让共基一无是处——电流没放大，电压增益也塌下来，因为 $R_e$ 大到与 $R_c$ 相当时分母被 $(1+\beta)R_e$ 主导。

* **通频带**

    * 共基的通频带宽度是共射和射极输出器的 $1+\beta$ 倍，宽度可放大近 $\beta$ 倍；原因是最好的一个特性，长文点到为止未展开。

* **输入电阻**

    * 入端电流为 $I$，则流过 $r_{be}$ 的为 $\frac{1}{1+\beta}I$，受控源处为 $\frac{\beta}{1+\beta}I$，两者合成恰为 $I$；再加上 $R_e$ 的压降：

    $$U = I \times R_e + \frac{I}{1+\beta} \times r_{be},\qquad R_i = R_e + \frac{1}{1+\beta} r_{be}$$

    * 原本约 $1\ \text{k}\Omega$ 的 $r_{be}$ 被降到几十欧，加上本身很小的 $R_e$，输入电阻很小，这是共基的特点。

* **输出电阻**

    * 求 $R_o$ 先短接 $R_l$，此时不能直接断言受控源为零，因为它是受控源；把回路列 KVL：

    $$I_b \cdot r_{be} + (1+\beta) I_b \cdot R_e = 0 \;\Longrightarrow\; I_b = 0$$

    * $I_b$ 为零则受控源为零，于是：

    $$R_o = R_c$$

    * > **易错点**：遇到含受控源的电阻求解，置零与否必须靠列回路方程证明，不能凭感觉；端口电阻法只有一条，就是加 $U$ 加 $I$。

## 直流负载线与交流负载线

* **斜率的来源**

    * 直流分析中负载管看见的负载只有 $R_C$；交流通路中负载管的负载变成 $R_C\parallel R_L$。

    * 两条线的斜率正是由这两个不同的等效负载决定。

* **重合条件**

## 场效应管放大电路的构成原则

* **三种接法的对偶**

    | | 共源 | 源极输出器（共漏） | 共栅 |
    |---|---|---|---|
    | 输入 | $G$ | $G$ | $S$ |
    | 输出 | $D$ | $S$ | $D$ |
    | 交流公共端 | $S$ | $D$ | $G$ |

    * 对应关系：共源的 $R_D$ 对应三极管侧的 $R_C$，栅极还有分压电阻 $R_G$；源极输出器的 $R_S$ 对应 $R_E$。

    * 源极与射极同义，都是载流子的源泉；MOS 管若衬底未接，$D$ 与 $S$ 可以互换。

    * 这与数电的对偶规则是同一个道理：一个等式成立，其对偶式也成立，学一个可当两个。

* **进入放大状态的核心要求**

    * 场效应管的放大状态是恒流，所有接法都必须保证管子工作在恒流区。

    * 增强型 MOS 管：加偏置让其导通，$U_{GS} > U_{GS(th)}$；光大于开启电压不够，还要加大 $U_{DS}$ 才能进入恒流区。一管导通、一管恒流是两大条件。

    * 耗尽型场效应管：导通问题不必操心，只需加大 $U_{DS}$。

    * 结型场效应管：导通问题也不必操心，但要保证 N 沟道工作在 $U_{GS} < 0$ 的区域。

    * > **易错点**：N 沟道结型场效应管的 $U_{GS}$ 必须为负。一旦 $U_{GS} > 0$，栅源之间 PN 结正向导通，器件不再工作于可控的恒流区，$I_D$ 对 $U_{GS}$ 的控制关系彻底失效。

* **基本共源电路的构成动作**

    ```text
          VDD  ──┬──►  给一个足够大的 UDS，让管子待在恒流区
                 │
                RD ──►  iD 流过 RD 的压降，就是我要的 uo
                 │
                 D
               ┌─┴─┐
         ui ──►│ G │  G 上再叠加 VGG 提供的静态 UGS
               ├─┬─┤
               │ S │
               └─┬─┘
                 │
                RS ──►  稳定静态工作点
                 │
                GND

       VGG ──► RG ──► G ：让 UGS > UGS(th)，沟道建立
                          （RG 上没有电流，也就没有压降）
    ```

    * $V_{GG}$ 加 $R_G$ 负责开通并形成沟道，$V_{DD}$ 加 $R_D$ 负责把管子压在大 $u_{DS}$ 的恒流区，$u_i$ 从栅极进来，最后由 $R_D$ 把电流变回电压。

    * $R_S$ 的基本作用与三极管侧的 $R_E$ 相同，是稳定静态工作点。

* **栅极绝缘带来的直接性**

    * 输入端取不到电流关系：$i_G = 0$，绝缘栅没有任何电流，也没有分压。

    * 因此 $u_i$ 怎么振荡，$u_{GS}$ 就怎么跟着动；静态时 $R_G$ 上无压降，静态 $U_{GS}$ 就是 $V_{GG}$。

* **转移特性曲线**

    * $i_D$ 与 $u_{GS}$ 的关系只能在恒流区得到，因为只有恒流区两者才一一对应。

    * 不在恒流区时 $i_D$ 同时受 $u_{GS}$（决定沟道电阻 $R_{DS}$）和 $u_{DS}$（经 $\frac{u_{DS}}{R_{DS}}$）两个量控制。

    * > **提示**：这与三极管的 $u_{BE}$–$i_B$ 曲线不同——后者是 PN 结特性，从不需要限定工作区。

## 跨导与小信号等效模型

* **$g_m$ 的来历**

    * Q 点落在转移特性的不同位置，$U_{GS}$ 与 $I_D$ 的关系就不同，要求的方法是取该点切线的斜率：

    $$g_m = \frac{\Delta I_D}{\Delta U_{GS}}$$

    * 它表明 $U_{GS}$ 的变化量与 $I_D$ 的变化量之间的关系，代表的都是低频交流量。

    * 这与 $r_{be}$ 的道理完全一样：静态工作点不同参数不同，所以场效应管也必须先求静态。

    * > **提示**：做等效时直流已被拿掉，等于把坐标原点移到 Q 点、只留纯交流，$g_m$ 才是纯交流意义下的跨导；信号一大曲线不再是直线，小信号模型失效。

* **简化等效模型**

    ```text
              G
              ○
              ┊   i_g = 0：绝缘栅，交流通路里彻底断开
              ┊
              ┊   Δu_gs（纯交流，不是直流）
              ┴─────────────┐
                            │
                            ▼
       D  ○───────────┌───┴───┐
                       │ gm·ugs│    压控电流源
                       └───────┘    大小 = gm · Δu_gs，方向 D → S
                            │
                            ▼
       S  ○─────────────────────►  交流地
    ```

    * $G$ 一路彻底断开什么都不用研究；$D$–$S$ 之间挂一个受 $u_{gs}$ 控制的电流源，大小为 $g_m\cdot\Delta u_{gs}$。

    * 模型比三极管简单：三极管那侧要有两个电阻，场效应管这边是断路，断路最好分析。

* **$r_{ds}$ 的取舍**

    * $r_{ds}$ 与三极管的 $r_{ce}$ 同源，都用双口网络推出，表征恒流区特性曲线实际的倾斜度。

    * 倾斜很小意味着 $r_{ds}$ 很大，做低频小信号简化等效时通常忽略，此时近似认为恒流区内同一 $U_{GS}$ 下 $I_D$ 不变。

    * 当外接负载 $R_L$ 大到几十 $\text{k}$ 到上百 $\text{k}$ 时，$r_{ds}$ 与其量级相同，必须重新计入。

## 场效应管放大电路的分析流程

* **第一步：静态求 $I_D$**

    * 耗尽型与结型场效应管，以 $I_{DSS}$ 为界限的负半轴方程：

    $$I_D = I_{DSS}\left(\frac{U_{GS}}{U_{GS(off)}} - 1\right)^2$$

    * 增强型场效应管，$I_{D0}$ 定义在 $2U_{GS(th)}$ 处，方程形式相同：

    $$I_D = I_{D0}\left(\frac{U_{GS}}{U_{GS(th)}} - 1\right)^2$$

* **第二步：由 $I_D$ 求 $g_m$**

    * $g_m$ 就是上述方程对 $U_{GS}$ 求导的结果。

* **第三步：交流通路替换**

    * 画出交流通路，把管子换成小信号模型，即可求 $A_u$、$R_i$、$R_o$。

    * 三极管怎么做，场效应管就怎么做，整个分析思路一致。

## 复合管

* **动机：互补对管难配**

    * 功放输出级要求后面一对管子输出，一个 NPN、一个 PNP，且两者特性基本相同。

    * NPN 与 PNP 内部结构本就不同，要求特性一致很难；小功率尚可，大功率几乎不可能凑出一对。

    * 能凑齐的是两个同型管，功率大时两个同型的大功率管可以极其相近，于是产生矛盾：既要一 NPN 一 PNP，又希望从输出端看两者一样。

    * > **易错点**：分立器件靠"挑"，集成器件靠"造"。同一片硅片上挨着做出来的两个管子温度、掺杂、工艺全一致，天然配对；分立元件是从一整批料里挑两个最接近的，天生差一截。

* **构成原则**

    * 一定要有合理的电流路径：向下的通路与向上的通路都要被"打通"，否则管子无法工作。

    * 判断 NPN 还是 PNP 看哪边是发射结——用发射结来确定类型，而不是按图上的箭头印象。

    * > **结论**：在通路合理的前提下，前面那个管子是什么，等效出来的功能就是谁。前面是 NPN，后面接 NPN 或 PNP 都等效为 NPN；前面是 PNP，后面接 NPN 或 PNP 都等效为 PNP。

    | 前级（驱动管） | 后级（功率管） | 等效出来的类型 | 真正出大电流的管 |
    | --- | --- | --- | --- |
    | NPN | NPN | NPN | NPN |
    | NPN | PNP | NPN | PNP |
    | PNP | NPN | PNP | NPN |
    | PNP | PNP | PNP | PNP |

    * 第一行与第三行配成一对，对外正好一个 NPN 一个 PNP 互补，真正推到外面的两只管全是 NPN。

    * 其他好处：功率可以做得更大；整个放大倍数是两级管电流放大倍数的乘积。

* **两种典型接法**

    ```text
      组合①   前 NPN + 后 NPN（达林顿管）

       B1 ────[ Q1 : NPN ]──── E1 ────[ Q2 : NPN ]──── E2 ── 地
                   │                       │
                  C1                      C2
                  └────────────┬──────────┘
                               │
                            C(out)
    ```

    ```text
      组合③   前 PNP + 后 NPN（等效 PNP，出大电流的是 NPN）

       B1 ────[ Q1 : PNP ]──── E1 ────[ Q2 : NPN ]──── E2 ── 地
                   │                       │
                  C1                      C2
                  └────────────┬──────────┘
                               │
                            C(out)
    ```

    * 这两张图看的是连接关系，不是信号流；$E_2$ 是参考端，在共射电路里就是接地点。

    * 组合③的接法与①完全一样，只把前面那只换成 PNP，它改用自己的集电极给后级供电。

* **电流放大倍数**

    * 最外围那级真正做功率推动的管子，其发射极电流就是下一级的基极电流，输出电流与 $I_{B1}$ 的关系约为：

    $$\beta_1 \times \beta_2$$

    * 电流分工清楚：第一个管子的功率要求明显小一些，第二个管子才是真正的功率管。

* **极数与命名**

    * 这种结构叫达林顿结构（达林顿管）。

    * > **易错点**：复合管仍然是三个极，不要以为变成四个；第一级的发射极去驱动第二级的基极。

* **接进电路后的节点识别**

    * $B_1$——最左边的输入基极。

    * $E_1$ 与 $B_2$——第一级发射极和第二级基极是同一个节点。

    * $C_1$ 与 $C_2$——两个集电极也是同一节点，即输出端。

    * $E_2$——真正的发射极，共射电路里就是接地点。

    * 认清 B、C、E 之后逐管做 $h$ 参数替换：$B_1$-$E_1$ 之间是 $r_{be1}$、电流是 $I_{b1}$，$C_1$-$E_1$ 之间是 $\beta_1$ 倍 $I_{b1}$ 的电流源；$B_2$-$E_2$ 之间是 $r_{be2}$、电流是 $I_{b2}$，$C_2$-$E_2$ 之间是 $\beta_2$ 倍 $I_{b2}$ 的电流源。

    ```text
       B1 ──┬──[ r_be1 ]──┬── E1 = B2 ──┬──[ r_be2 ]──┬── E2 ── 地
            │    I_b1 →   │             │    I_b2 →   │
            └─────────────┴─────────────┴─────────────┘
       C1 ──► 电流源 β1·I_b1 （C1 → E1）──┐
                                           ├──► C(out)
       C2 ──► 电流源 β2·I_b2 （C2 → E2）──┘
    ```

    * 由此得两级电流关系：

    $$I_{B2} = (1+\beta_1)\,I_{B1}, \qquad I_{C2} = \beta_2 I_{B2} = \beta_2 (1+\beta_1)\,I_{B1}$$

    * > **易错点**：这类电路的正确做法是按原则一步步变出来，而不是背下来；电路稍加整理就变好看，背下来的形状一改就全错。

## 派生放大电路

* **共射-共基放大电路**

    * 连接方式：前级接成共射，后级接成共基，两个集电极连在一起，信号从 $E_2$ 取出。

    ```text
      共射 - 共基

       u_i ──► B Q1
                │
                E ──────► B Q2
                │            │
                C ──────► C Q2
                         │
                         E ──► u_o
    ```

    * 电流由共射放大、共基不再放大；电压两级都放大；并利用共基的通频带宽进一步拓宽本级通频带。

* **共集-共集放大电路**

    ```text
      共集 - 共集（两级射极跟随器）

       u_i ──► B Q1
                │
                E ──────► B Q2 ──────► E2 ──► u_o
                │                     │
                C                     C ───► 交流地（V_DD）
    ```

    * 两级都是射极输出器，信号从 $B_1$ 进、从 $E_2$ 出，两个集电极都接电源。

    * 射极输出前端输入电阻大，可从电压型信号源取得更大的 $u_i$，同时减小信号源需提供的输出功率，特别适合共集放在第一级抢电压型信号源的信号。

* **派生电路的动机**

    * 共射、共集、共基单一使用时效果未必最好，需要把不同电路的特性组合在一起才有意义。

    * 画这类电路的 $h$ 参数等效仍用同一条通则，说明电路形状无法靠背诵穷尽。
