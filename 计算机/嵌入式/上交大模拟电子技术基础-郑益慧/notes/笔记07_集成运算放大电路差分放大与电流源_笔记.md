# 集成运算放大电路：差分放大与电流源

## 直接耦合与零点漂移

* **零点漂移（zero drift）**
    * > **定义**：直接耦合多级放大电路在输入被短接置零时，输出并不停在零点或某个稳定直流电平上，而是像波浪一样随时间漂移的现象。

    * 期望状态：动态输入被掐掉后，输出的那部分 $U_o$ 应该是一个稳定的直流。

    * 形象说法：零点不在零点的位置上，随波逐流，像波浪一样漂，仿佛前面还挂着一个动态信号。

    * 本质就是静态工作点在漂移；讲静态工作点稳定电路时已经指出静态工作点会动。

      ```text
      u_o
       ^
       |  ·····························  期望：输出停住不动，
       |                                    稳定在某一个直流电平
       |      ~~~~~~~~~~~~            ~~~~~~
       |    ~~         ~~          ~~         实际：零点不在零点的位置上，
       |  ~~             ~~      ~~                随波逐流，像波浪一样漂
       |                     ~~
       +------------------------------------------► t
      ```

* **温漂（temperature drift）**
    * > **定义**：由温度引起的零点漂移。

    * 静态工作点漂移的原因有温度、电源电压、元器件等；其他原因可以克服，温度是目前没法克服、必须忍受的一项。

    * 温漂是直接耦合放大电路的一个重要指标。

* **直接耦合（direct coupling）成为必选项的两条来路**
    * 传感器送来的物理量（空调里的温度传感器）变化很缓慢，用阻容式耦合时耦合电容容抗很大，信号过不去；变压器耦合对缓慢变化的信号同样不现实。

    * 集成电路工艺本身用的就是直接耦合，这是工艺发展的必然结果。

    * 直接耦合的缺点：各级静态工作点紧密相关，很难调；致命问题是太容易受干扰。

    * 既然必须用，问题就变成直接耦合放大电路要克服哪些困难、怎样克服。

* **发射极电阻抑制温漂的作用链**
    * 在基本共射电路的发射极上加 $R_e$ 引入负反馈，机理是找一个跟温漂起反作用的量。

    * 温度影响下若 $I_c$ 意图上升，则 $U_E \approx I_c R_e$（严格说是 $I_E R_E$，比它还大一点）。

    * $U_E$ 上升使 $U_{be} = U_b - U_E$ 下降，$U_{be}$ 下降使 $I_b$ 下降，$I_c$ 上升的趋势被摁住。

    * $R_e$ 越大，同样的电流变化引起的 $U_E$ 变化越大；$I_c$ 本来想上升三四毫安，$R_e$ 小时被压到只上升一毫安，$R_e$ 很大时可以压到几十个微安。

    * > **易错点**：直接耦合电路里不能再指望用旁路电容把 $R_e$ 短路掉。交流通路里 $R_e$ 一直在，电压放大倍数必须为它付出代价。

* **$R_e$ 的两难**
    * 带 $R_e$ 的基本共射电路电压放大倍数为 $A_u = -\dfrac{\beta\,(R_c \parallel R_L)}{r_{be} + (1+\beta)R_e}$，分母里相当于多了一个 $(1+\beta)$ 倍的 $R_e$。

    * 当 $R_e$ 与 $R_c$ 可以相提并论时，放大倍数不再是几十倍上百倍，而是变成 1 甚至小于 1。

    * 这正是负反馈的作用——负反馈本身的作用就是减小放大倍数。

    * 一个希望 $R_e$ 大（抑制温漂），一个希望 $R_e$ 小（放大倍数），矛盾全部聚焦在 $R_e$ 上。

* **旁路电容这条路的终结**
    * 抑制温漂的其他办法：继续改进电路稳定静态工作点、加温度敏感器件（如二极管），这些属于自行阅读的内容。

    * 阻容式耦合时可以大胆并一个旁路电容，交流通路里 $R_e$ 被电容短路掉；直接耦合不允许这么干。

    * 突破口在于：能否让 $R_e$ 在直流与干扰下起作用，而在有用的输入信号进来时等效为消失。

## 共用发射极电阻的由来

* **镜像电路：让零点跟着一起漂**
    * 思路是引入一个可变电源：你这边零点怎么波动，我这边就怎么波动，总归和你保持固定的相对关系，两条很近的船一起上、一起下，一减就没了。

    * 关键不是做一个负电源，而是这个电源必须自动地、实时地跟着零点漂；凡是需要人来拨的方案都等于没方案。

    * 实现方式不是做一个模拟电路，而是做一个完全镜像的电路——两边参数完全对称，输出就跟着一起动。

      ```text
            实际电路                       镜像电路
              +V_CC                          +V_CC
                │                              │
               R_C                            R_C
                │                              │
               Q1                             Q2
                │                              │
            ┌───┴───┐                      ┌───┴───┐
            │       │                      │       │
           GND     R_L                    GND     R_L
                     │                             │
                    GND                           GND

        u_o 在漂                  参数完全对称时，u_o' 跟着一起动
      ──────────────────────────────────────────────────
        两条很近的船放在水波上：一起上，一起下
      ```

* **长尾式（tail）的构成**
    * 两个 $R_e$ 可以共用成一个，公共发射极那一支叫尾巴，形状像风筝的大尾巴，故称长尾。

    * 静态时支路电流为 $I_{E1}$、$I_{E2}$，完全对称时流过公共电阻的是 $2I_E$。

    * 对任何单边端口而言，电流只走过一路 $I_E$，电压变化却是 $2I_E \cdot R_E$，因此等效电阻相当于两倍 $R_E$。

    * 不用共用电阻的坏处：漂移波浪会变大，单颗管子可能进入饱和区或截止区，一旦离开线性区就失真。

      ```text
                            +V_CC
                          /        \
                        R_C        R_C
                        /            \
                       Q1            Q2
                        \            /
                         \          /
                          \        /
                           \      /
                            \    /
                  I_E1 +  I_E2   (完全对称时 = 2 I_E)
                              │
                             R_E
                              │
                             GND
      ```

* **基极偏置从 $V_{BB}$ 共用到 $-V_{EE}$**
    * 两个 $V_{BB}$ 也可以合并共用一个电源，电路结构进一步简化。

    * 让输入信号骑在一个直流偏置电源上并不希望——希望输入端接地，这样干扰小。

    * 接地之后，原来的地就变成一个很好的负电源；因为接在发射极上，符号相应改成 $-V_{EE}$。

      ```text
                         +V_CC
                        /      \
                      R_C      R_C
                        /          \
                 u_I1 ─┤B        B├─ u_I2      两个 V_BB → 共用一个
                        Q1 \      / Q2
                            \    /
                      I_E1 \  / I_E2
                              \/
                             R_E
                              │
                      -V_EE（原 V_BB 的地）
      ```

* **镜像电路的死局与破解**
    * > **易错点**：完全对称的镜像电路，两端同相输入时输出恒为零。它对称得越彻底，作为放大器越没用。

    * 破解办法是让两个输入反相：$u_{i2} = -u_{i1}$，一个往上一个往下沉。

    * 另一种等效说法：把一端取零，等效成一个正的 $\frac{1}{2}u_{I1}$ 和一个负的 $\frac{1}{2}u_{I1}$，两者之差仍为 $u_{I1}$。

* **差模信号让 $R_E$ 消失**
    * $u_{i1}$ 产生动态 $i_{e1}$，$u_{i2}$ 产生动态 $i_{e2}$，两者方向相反，公共电阻上的动态电流 $i_e = i_{e1} + i_{e2} = 0$。

    * 动态电流为零意味着 $R_E$ 上的动态压降为零，等效为消失；该点电位就是接地点电位。

    * 一对大小相等、方向相反的信号进来，一方面在集电极获得放大输出，另一方面把 $R_E$ 等效掉。

      ```text
       i_e1 向下              i_e2 反向（向上）
            │                        │
            ▼                        ▲
           Q1                       Q2
            │                        │
            └──────── R_E ───────────┘

          i_e = i_e1 + i_e2 = 0
          →  R_E 上动态压降 = 0·R_E = 0
          →  R_E 在交流通路中等效为"消失"
      ```

* **交流信号骑在直流上**
    * > **提示**：所谓动态电流"反向"流动，并不是电流真的反向，而是正向的直流工作点往回退了一点（比如从 10 mA 退到 9 mA，看起来就像倒着流了 1 mA）。

    * 这一层概念清楚之后，后面所有交流通路分析就都顺了；动态信号一律用小写，静态一律用大写。

## 共模信号与差模信号

* **共模信号（common-mode signal）**
    * > **定义**：$u_{I1} = u_{I2}$，两个输入大小相等、方向相同。

    * 在差分放大电路里，共模信号代表的是干扰信号：温度引起的温漂、外界电磁干扰都表现为共模。

    * 温漂之所以等效成共模，是因为集成电路中两个管子可以做得非常近，所感受的温度变化相同，两处产生的温漂相同。

    * 电磁干扰进来同样等效出 $u_{I1}$ 就必然等效出 $u_{I2}$，不可能一个有一个没有，因此也是共模。

* **差模信号（differential-mode signal）**
    * > **定义**：大小相等、方向相反的一对信号，即 $u_{I2} = -u_{I1}$。

    * 差模是要放大的有用信号。

    * 一个带干扰的实际输入必然能分解成两部分：一部分共模干扰、一部分差模有用信号。

      ```text
          共模（u_I1 = u_I2）              差模（u_I2 = -u_I1）
              ↓      ↓                       ↓      ↑
             Q1     Q2                      Q1     Q2
              ↓      ↓                       ↓      ↑
           ────  R_E  ────                 ──── R_E ────
           i_e = 2 i_E                    i_e = 0
        → 等效 2 R_E，强烈负反馈        → R_E 等效消失
      ```

* **$R_E$ 的两大作用**
    * 共模进来时，从单边看过去 $R_E$ 表现出两倍 $R_E$ 的作用，形成强烈负反馈，共模放大倍数是在减小而非放大。

    * $R_E$ 本身已经很大，再乘两倍，放大倍数会缩小为原来的百分之几、千分之几。

    * 差模进来时动态电流为零，$R_E$ 在交流通路中等效消失，这是长尾式电路最关键的一点。

    * 没有 $R_E$ 时，单边对干扰信号毫无抑制，完全靠两边相减；有 $R_E$ 时第一关就把干扰干掉，之后用不用相减都不重要。

    * 输出方式与相减的关系：只有双端（相减）输出才能体现"$R_E$ 消失、两边抵消"；从单个端子对地输出时两边的相减关系消失，但仅凭一个 $R_E$ 也已经把干扰干掉到 99% 甚至 99.9%。

      | | 共模信号 | 差模信号 |
      | :--- | :--- | :--- |
      | 定义 | $u_{I1} = u_{I2}$，大小相等、方向相同 | $u_{I2} = -u_{I1}$，大小相等、方向相反 |
      | 在这里的身份 | 干扰：温漂、电磁干扰 | 要放大的有用信号 |
      | 公共尾电阻 $R_E$ | 相当于 $2R_E$，强烈抑制 | 动态电流为零，等效消失 |
      | 双端输出时的放大倍数 | $0$（相减后为零） | 与基本共射级基本相等 |

## 差模交流通路与等效电路

* **差模下两个发射极电位相等**
    * 差模状态下两路电流一路往里折、一路往外折，方向正好抵消，公共点电位一动不动。

    * $R_e$ 消失不是被"忽略"，而是在差模这一半里真的不起作用；看到交流通路里 $R_E$ 整个不见了不必慌。

    * 交流通路的起点动作：电源全部接地，$R_L$ 照常接着，$R_e$ 在差模这一半里先去掉。

* **把电路"掰"成左进右出**
    * 差模交流通路原始形状是两头对称、输出夹在两个集电极中间，读起来别扭。

    * 解法是把右半支绕发射极公共节点转 180 度，转过来后发射极那一点交流接地，两路 $R_b$ 在左边做输入、两路 $R_c$ 在右边做输出。

      ```text
         差模交流通路（掰之前：两头对称，输出夹在中间）

            u_i2                        u_i1
              │                           │
             R_b                         R_b
              │                           │
           ┌──┴──┐ B1               B2 ┌──┴──┐
              │E                         E│
              ├───────────┬───────────────┤
              │           │               │
             R_c         ⏚              R_c
              │           │               │
              o───────────┴───────────────o
                          ↑
                   u_o 跨接在这两点之间
      ```

    * 掰过之后顺手捡到一个便宜：原来 $u_o$ 接在两个集电极之间、中间挂 $R_L$；两端电位一正一负、关于中点对称，接地点电位正好落在 $R_L$ 正中间，$R_L$ 被等分成两个 $\frac{1}{2}R_L$。

      ```text
         差模等效电路（掰之后：左进右出）

            u_i2                               C1
              │                                  │
             R_b                                R_c
              │                                  │
             B1                                  o    +½u_o
              │E                                 │
              ├──────────────────────────────────┤
             B2           │                      │
              │E          │                     R_c
             R_b          │                      o    −½u_o
              │           │                      │
             u_i1          ⏚                    ½R_L
                                                 │
                                                 ⏚
      ```

* **h 参数等效的口诀**
    * 先标出 $B_1$、$E_1$、$C_1$ 与 $B_2$、$E_2$、$C_2$。

    * 口诀只有两句：$B$ 与 $E$ 之间是 $r_{be}$；$C$ 与 $E$ 之间是流控电流源。

      ```text
         单个管子的 h 参数模型

              B            C
              │            │
              ├─ r_be ─E ──┤
              │            │
              └───▶│───────┘
                   β·i_b（流控电流源，C → E）
      ```

    * 差模下把两个输入整体记成一个 $u_{id}$：上面是 $\frac{1}{2}u_{id}$、下面是 $-\frac{1}{2}u_{id}$，所以 $I_{b1}$ 与 $I_{b2}$ 大小相等、方向相反。

## 双入双出的差模分析

* **$u_o$ 是两倍**
    * $u_o = u_{o1} - u_{o2}$，上面一路是 $\beta$ 倍 $I_{b1}$ 造成的、符号为负，即 $u_o = -2\beta I_{b1}\left(R_c \parallel \frac{1}{2}R_L\right)$。

    * > **易错点**：上面是 $\frac{1}{2}u_o$、下面是 $-\frac{1}{2}u_o$，整体正好是单边电压的两倍。算一半就交卷是最常见的错。

* **$u_{id}$ 也是两倍，但要写成减法**
    * 给两个节点分别标号 $u_1$（上）、$u_2$（下），则 $u_{id} = u_1 - u_2$。

    * $u_1 = I_{b1}(R_b + r_{be1})$，$u_2 = I_{b2}(R_b + r_{be2})$。

    * 电路完全对称给出 $r_{be1} = r_{be2}$ 且 $I_{b1} = -I_{b2}$，负负得正，后面的串全部加起来，得 $u_{id} = 2I_{b1}(R_b + r_{be1})$。

* **放大倍数结论**
    * 双入双出时 $A_{ud} = \dfrac{u_o}{u_{id}} = -\dfrac{\beta\left(R_c \parallel \frac{1}{2}R_L\right)}{R_b + r_{be}}$。

    * 它与基本共射放大电路的放大倍数近乎相等，损失非常小，代价只是电路复杂了一倍。

* **电压传输特性**
    * 中间是一段线性关系，斜率就是那个负的放大倍数；再往两边走进入饱和。

      ```text
         电压传输特性

          u_o
           │  _____
           │      ╲
           │       ╲                    _________
           │        ╲                 ╱
           │         ╲              ╱
         ──┼──────────╲────────────╱──────────────→ u_id
           │           ╲          ╱
           │            ╲        ╱
           │             ╲      ╱
           │              ╲____╱
      ```

## 四种输入输出组合

* **组合清单**
    * 差分放大电路只有四种接法，由输入端单/双与输出端单/双排列组合而成。

    * 之所以出现单端输出，是因为实际电路中 $u_o$ 经常从一个集电极和地之间取；只要有一端接地，它就带上了防干扰功能。

      | 组合 | 输入 | 输出 | 共模的下场 |
      | :--- | :--- | :--- | :--- |
      | 双入双出 | $u_{i1} = -u_{i2}$ | 接在两个集电极之间 | 完美相减，$A_{uc} = 0$ |
      | 双入单出 | $u_{i1} = -u_{i2}$ | 一个集电极对地 | 不再相减，靠 $2R_e$ 强压，$A_{uc}$ 很小但不为零 |
      | 单入双出 | $u_i$ 与"地" | 接在两个集电极之间 | 差模之外还要背一对共模 |
      | 单入单出 | $u_i$ 与"地" | 一个集电极对地 | 在双入单出的基础上再叠一对共模 |

    * 共模信号双入双出时两个管子支路完全一样，输出一相减就没了，$u_o = 0$，$A_{uc} = 0$，理想得不能再理想。

* **单端输入的拆分方法**
    * 所谓单端输入，就是把 $u_{i2}$ 弄成 0，判据是"哪个端子没接地"。

    * 把零拆开看：$u_{i1} = \frac{1}{2}u_i + \frac{1}{2}u_i$ 是两个相等的量，构成一对共模；$u_{i2} = 0 = -\frac{1}{2}u_i + \frac{1}{2}u_i$ 是一正一负，构成一对差模。

      ```text
         实际接法：u_i1 = u_i ，u_i2 = 0

         拆开看：
         u_i1 = u_i   =   ½u_i   +   ½u_i     ← 两个相等，是一对共模
         u_i2 = 0     =  −½u_i   +   ½u_i     ← 一正一负，是一对差模
         ─────────────────────────────────────────────
         等价于：双端输入、双端输出电路
               + 一对幅度为 ½u_i 的共模信号
      ```

    * 单端输入相当于一对共模信号加上一对差模信号；单入双出等于双入双出再加一对共模，单入单出等于双入单出再加一对共模。

    * 那个"看起来是 0"的端子一直在贡献共模信号，不能当成没有；差模那一半里共模被减掉，靠的正是它的存在。

## 双入单出的分析

* **静态：$R_L$ 挪走，对称性没坏**
    * 双入单出与双入双出的唯一区别是 $R_L$ 从两个集电极之间挪到其中一个集电极与地之间。

    * 从输出端口做戴维南等效，得到的不是 $R_c$ 而是 $R_c' \parallel R_L$，由 $R_c'$ 和 $V_{CC}'$ 一起把这一小段整个替掉。

    * 因此 $U_{CQ1} \ne U_{CQ2}$，但 $I_E$ 不变：两个相同的管子、相同的 $U_E$、基极经一样的 $R_b$ 接地，所以 $U_{BE}$ 一样，$I_b$ 一样，$I_E$ 一样，动态 $r_{be}$ 也一样，即 $I_{e1} = I_{e2}$、$r_{be1} = r_{be2}$。

    * > **易错点**：别以为上面那一段动了底下对称性就破坏了。真把它当破坏了，这道题做不下去——静态是为动态打底的，动态时对称性依然成立。

* **共模支路**
    * $I_{e1} = I_{e2}$，对单边而言共模电流流过 $R_e$ 的效果相当于两倍 $R_e$，共模通路剩下的是一个熟悉的共射放大电路。

    * $A_{uc} = -\dfrac{\beta (R_c \parallel R_L)}{R_b + r_{be} + 2(1+\beta)R_e}$，写成 $(1+\beta)\cdot 2R_e$ 与 $2(1+\beta)R_e$ 是同一个逻辑关系。

    * 数量级估算：$R_e$ 可做到几十千欧而 $R_c$ 只有几千欧，两者差约十倍，分母上再乘 2，共模放大倍数的绝对值大约只有百分之几，比 5% 还小。

    * $R_e$ 还能继续调大、压得更小，压到后来单端输出这边的干扰已经快没了。

    * > **易错点**：等效时可以在这一侧不画另一半，但绝不是"咔嚓一剪子"把它剪掉。它的作用要留着，只是换成等效形式留在另一边——这和求多级放大电路第一级放大倍数时把后面各级等效成输入电阻 $R_L$ 是一个道理。

* **差模支路**
    * 差模下唯一变化是 $R_L$ 不再被折半，直接就是 $R_L$；输出是单边一路，输入 $u_{id}$ 是完整的差模。

    * $A_{ud} = -\dfrac{\beta (R_c \parallel R_L)}{2(R_b + r_{be})}$。

    * 这个值就是基本共射放大电路放大倍数的 $\frac{1}{2}$，不是"约等于"而是精确的 $\frac{1}{2}$：底下那一半是两倍的东西顶上来，输入是完整的两倍差模而输出只取一倍。

* **输入输出分解**
    * 含干扰的输入写成 $u_i = u_{ic} + u_{id}$，输出写成 $u_o = u_{od} + u_{oc}$。

    * 分析套路：静态动态分开，动态里面共模放大倍数与差模放大倍数分开算，最后相加。

## 用恒流源替代大电阻

* **$R_e$ 太大带来的困境**
    * $R_e$ 越大恒流特性越好，但 $V_{EE}$ 被逼得越来越大；$V_{EE}$ 不够大就提供不了足够的直流偏置，而提供大电源是很麻烦的事。

    * 改进办法是用一只恒流源把整个公共发射极支路换掉，$I_{C3}$ 可以做大而 $V_{EE}$ 不必很大。

      ```text
         改进前：R_e 直接接在两管的公共发射极上
         （R_e 越大 → 恒流特性越好，但 V_EE 被逼得越来越大）

             V_EE
               │
            ┌──┴──┐  R_e
            └──┬──┘
               │
          E1 ──┴── E2

         改进后：用一只恒流源把这一支整个换掉
         （I_C3 可以做大 → V_EE 不必很大；等效电阻是 r_ce，很大）

             V_EE
               │
       ┌─────┴──────────┐
       │  R_1  R_2  R_3  │   调它们定出 I_E3
       │       T_3      │
       └─────┬──────────┘
             │  I_C3 ≈ I_E3（对上面而言就是一个电流源）
        E1 ──┴── E2
      ```

* **受控源思路**
    * 线索来自加 $R_L$ 的那一步：一边有 $R_L$ 一边没有，结论却是 $I_{C1}$ 与 $I_{C2}$ 一样大，因为 $I_{E1}$ 与 $I_{E2}$ 一样大。

    * $I_C$ 受下面控制，既然如此就做不出恒流源还做不出受控源：$I_{E3}$ 只受自己那一小块电路控制，调节 $R_1$、$R_2$、$R_3$ 就能把 $I_{E3}$ 做成不同值，让 $I_{C3}$ 接在公共支路上。

    * 好处是电源电压不必太高也能提供一份较大的 $I_{C3}$；恒定电流一旦提供出来，交流下这一支的等效电阻是 $r_{ce}$，非常大，正好就是一直想要的那份 $R_e$。

    * 这就叫具有恒流源的差分放大电路；再往前一步把管子换成 MOS 管，输入电阻又变大了。

## 电流源在集成运放中的位置

* **电流源（current source）的三条性质**
    * > **定义**：输出电流为固定值，且这个电流是它本身的属性；输出电压为任意值，由外部电路和电流值共同决定；内阻为无穷大。

    * 因为内阻无穷大，电流源在电路中可以当作一个极大的电阻使用。

* **两条最要紧的理由**
    * 静态方面：集成运放里提供静态工作点若靠极大的 $R_C$，这种大电阻在集成电路里很难造；造出来之后有一点电流就要求极高电压，对系统不利。用电流源可以在小电压下给出所需静态电流。

    * 动态方面：希望电压放大倍数高就要求 $R_C$ 很大，希望差放有非常好的共模抑制比和抗干扰能力就要求 $R_e$ 非常大——两者都要靠电流源来替代。

* **集成性的逻辑**
    * 集成电路用掩模批量制造，多十个或少一万个晶体管都不增加太多复杂工序；而做同样的电阻却不容易。

    * 所以不去做电阻，改用晶体管电路来替代，电流源提高的是整个电路的集成性。

    * 分立元件电路里这个矛盾很尖锐：要大电阻就得配高直流电压源，想用小电源还得有大电阻的效益。

    * > **例外**：只在乎速度而不顾功耗时可以使用大功耗电路，代表是射极耦合的 ECL，速度极快，可用于通信电路的交换机。

* **识别电流源的三种多路结构**
    * 一个 $I_R$ 控制一批电流源，理由是集成放大电路里需要多处直流偏置和负载。

      | 结构 | 比例怎么定 | 好处 |
      | :--- | :--- | :--- |
      | 并联多个镜像电流源 | 每一路的 $R$ 自己定 | 结构直观、灵活 |
      | 多集电极三极管 | 每个集电极面积做得不一样 | 连电阻都没了，比例在版图里就定好 |
      | 多 MOS 管 | 同一个 $V_{GS}$、不同的宽长比 | 无需偏置电阻，集成最彻底 |

    * 多集电极管的思路：集电极区域越大得到的电流越大，生产时按比例做好，比例就定下来了，不再需要电阻。

    * MOS 管导通后有导通电阻，与 $V_{GS}$ 有关；$V_{GS}$ 实际控制导电沟道宽度，越宽电阻越小，长度越长电阻越大，因此同一 $V_{GS}$ 下各管宽长比不同，$I_{D1}$、$I_{D2}$、$I_{D3}$ 与各自宽长比成正比。

    * 多个电流源电路里每个都由同一个 $I_R$ 控制，一眼认出种类是必须练出的火眼金睛。

## 镜像电流源

* **镜像电流源（current mirror）**
    * > **定义**：用两个特性完全一样的对管构成，控制管决定电流，被控管复制这份电流。

    * 原理链条：$U_{BE0} = U_{BE1}$ 势必造成 $I_{B0} = I_{B1}$，也就造成 $I_{C0} = I_{C1}$，完全是两个管子在照镜子。

    * 电阻 $R$ 所在的 $T_0$ 是控制管，$I_C1$ 受 $I_R$ 控制，构成受控电流源。

      ```text
                     V_CC
                      │
                      R
                      │
             ┌────────┼────────────────┐
             │        │                │
          ┌──┴──┐     │             ┌──┴──┐
          │  T0 │─────┴─────────────│  T1 │
          └──┬──┘   基极相连        └──┬──┘
             │                         │
            GND                       GND
                                       C
                                       ↓ I_C1
      ```

* **数值关系**
    * 找一条通路算参考电流：$I_R = \dfrac{V_{CC} - U_{BE0}}{R}$，其中 $U_{BE0}$ 一般为零点几伏。

    * $I_R$ 与 $I_{C0}$ 的关系为 $I_{C0} = \dfrac{\beta}{\beta + 2} I_R$。

    * 实际希望 $\beta$ 大一些；$\beta \gg 2$ 时 $I_{C0} \approx I_R$，控制了 $I_R$ 就近似控制了 $I_{C0}$。

    * > **易错点**：$\beta$ 本身是不稳定的量，不能带 $\beta$ 当作精确结果。用 $\beta \gg 2$ 正是因为此时 $\beta$ 的变化率对 $I_C$ 与 $I_R$ 关系的影响已经非常小。

## 比例电流源

* **大电流的麻烦出在电阻上**
    * 镜像电流源里 $I_R$ 与 $I_{C1}$ 相等，要多大输出就得多大的参考电流——"榜样的力量"。

    * $I_R$ 一大，电阻上的功耗就是 $P = I_R^2 R$，带来两大麻烦：真的消耗电功率效率低，以及发热导致芯片散热困难。

    * 集成电路的瓶颈一是输入功率问题，二是散热问题，所以要尽可能把功耗降下来。

* **比例电流源（ratioed current mirror）的结构与推导**
    * 在两个管子的发射极各塞一个电阻，结构与镜像电流源基本一样，只是多了 $R_{e0}$ 和 $R_{e1}$。

    * 从公共基极到地列 KVL：$I_{E0} R_{e0} + U_{BE0} = I_{E1} R_{e1} + U_{BE1}$。

    * PN 结中电流变化很大时两端电压变化很小，所以 $U_{BE0} \approx U_{BE1}$，得 $I_{E0} R_{e0} \approx I_{E1} R_{e1}$；比例关系再传递到集电极：$I_{C0} R_{e0} \approx I_{C1} R_{e1}$。

    * 最终实现对 $I_{C1}$ 的比例控制：$I_{C1} = \dfrac{R_{e0}}{R_{e1}} I_{C0}$；参考电流为 $I_R = I_{C0} + I_{B0} + I_{B1}$。

    * $\beta$ 很大时 $I_{B0}$、$I_{B1}$ 可忽略，$I_{C0} \approx I_R$，于是可以只用很小的 $I_R$ 控制较大的 $I_{C1}$，既省功率又得到大电流。

      ```text
                     V_CC
                      │
                      R
                      │
             ┌────────┼────────────────┐
             │        │                │
          ┌──┴──┐     │             ┌──┴──┐
          │  T0 │─────┴─────────────│  T1 │
          └──┬──┘   U_BE0 = U_BE1   └──┬──┘
             │                         │
           R_e0                       R_e1
             │                         │
            GND                       GND
                                       C
                                       ↓ I_C1
      ```

* **边界条件**
    * $I_{C1}$ 与本支路的 $R_{e1}$ 接的电阻越大越小，即与 $R_{e1}$ 成反比、与 $R_{e0}$ 成正比。

    * 比例电流源只能做成反比关系而不能任意缩小，要做几十微安的电流源必须另想办法。

## 微电流源

* **微电流源（small current source）的构成**
    * 在比例电流源中要让 $I_{C1}$ 变小，应让 $R_{e0}$ 尽可能小、$R_{e1}$ 尽可能大，极限是把 $R_{e0}$ 短路掉令 $R_{e0} = 0$。

    * > **易错点**：是短路掉 $R_{e0}$，不是把 $R_{e0}$ 断开或去掉。因为 $I_{C1}$ 与 $R_{e0}$ 成正比，$R_{e0}$ 变小 $I_{C1}$ 才变小。

      ```text
                     V_CC
                      │
                      R
                      │
             ┌────────┼────────────────┐
             │        │                │
          ┌──┴──┐     │             ┌──┴──┐
          │  T0 │─────┴─────────────│  T1 │
          └──┬──┘   U_BE0 = U_BE1   └──┬──┘
             │                         │
            ───  ← R_e0 被短路掉      R_e1
             │                         │
            GND                       GND
                                       C
                                       ↓ I_C1
      ```

* **定标原理**
    * $R_{e0}$ 短路后列式得 $U_{BE0} = U_{BE1} + I_{E1} R_{e1}$，即 $I_{E1} = \dfrac{U_{BE0} - U_{BE1}}{R_{e1}}$。

    * $U_{BE0}$ 与 $U_{BE1}$ 本来相差无几，因此两者之差极小，$R_{e1}$ 越大电流越微小。

    * > **提示**：微电流源的本质是靠两个 $U_{BE}$ 之间极其微小的差值来定标电流。

    * 由 $I_E \approx I_S e^{U/U_T}$ 得 $U_{BE} = U_T \ln \dfrac{I_E}{I_S}$，$U_T$ 是常温下 26 mV，两式相减把 $I_S$ 消掉：$U_{BE0} - U_{BE1} = U_T \ln \dfrac{I_{E0}}{I_{E1}}$。

    * $\beta$ 很大时 $I_R \approx I_{C1} \approx I_{E0}$，于是 $I_{E1} = \dfrac{U_T}{R_{e1}} \ln \dfrac{I_R}{I_{E1}}$ 且 $I_{E1} \approx I_{C1}$；这是一个关于 $I_{E1}$ 的隐方程，工程上不去解它。

## 改进型电流源

* **误差的来源**
    * $\beta$ 不够大时误差是 $\dfrac{\beta}{\beta + 2}$；$\beta$ 只有 5 或 10 时误差约 20%，工程上不能接受。

* **再补一级放大**
    * 想法是让下面分出去的电流变小而流进放大级的电流不小，在中间插一个放大电路，靠它把驱动电流压到原来的 $\frac{1}{\beta}$。

    * 加了放大级相当于又乘了一个 $\beta$：本来要输出约 0.2 倍的 $I_C$，加上这一级后输出约为 2% 的 $I_C$，性能明显变好。

    * 那一级通常用射极输出器形式的电流源实现。

      ```text
                V_CC
                 │
          ┌──────┴──────┐
          │             │
         T0             T1      ← 原来的对管
          │B───────────B│
          └───┬─────┬───┘
              │     │
              │  ┌──▼───────┐
              │  │  放大级   │  ← 中间插入的一级
              │  │  (≈β 倍)  │     驱动电流约为原来的 1/β
              │  └──┬────────┘
              │     │E
              │  ┌··┴··┐        ← R_E2（虚线：可加可不加）
              │  ·     ·
              │  └─────┘
              │
             GND
      ```

* **$R_{E2}$ 的补偿作用**
    * 没有 $R_{E2}$ 时，$I_{E2}$ 只提供 $I_{B0}$ 和 $I_{B1}$，电流很小；工作在很小电流区时管子的电流放大倍数会变小，并不是很理想的 $\beta$。

    * 加一个 $R_{E2}$ 给它提供一点点电流，把 $\beta$ 顶上去越过一个类似阈值的区域；$\beta$ 上去之后即使提供的电流不多，总体仍然合算。

    * 它的作用就是让这个 $\beta$ 真的变大，使 $I_R$ 更接近于 $I_C$。

## 威尔逊电流源

* **威尔逊电流源（Wilson current source）的结构**
    * 由 $T_0$、$T_1$、$T_2$ 三管构成，$T_0$ 的集电极与基极、$T_1$ 的基极、$T_2$ 的基极接在同一点，$T_1$ 是输出管。

    * $T_0$ 与 $T_1$ 仍是镜像结构，所以 $I_{C1} = I_{C0}$。

      ```text
                        V_CC
                         │
                         C
                       ┌─┴─┐
                       │T1 │  输出管
                       └┬─┘
                        │E
                        └──────┬──────┬──────────┐
                               │      │          │
                            ┌──┴──┐   │       ┌──┴──┐
                            │ T0  │   │       │ T2  │
                            └──┬──┘   │       └──┬──┘
                            ┌──┴──┐  │          │E
                            │  C  │  │          R
                            └─────┘  │          │
                                      │         GND
                                      │
         节点说明：T0 的 C、B 与 T1 的 B、T2 的 B 全部接在同一点
      ```

* **第一个好处：$\beta$ 的影响被压到 $\beta^2$ 项上**
    * $I_{E2} = I_C + 2I_B = \dfrac{\beta + 2}{\beta} I_C$，而 $I_{C2} = \dfrac{\beta}{\beta + 1} I_{E2}$。

    * $I_R = I_{C0} + I_{B2}$，其中 $I_{C0} = I_C$、$I_{B2} = \dfrac{1}{\beta + 1} I_{E2}$，代入并用 $I_{E2} = \dfrac{\beta+1}{\beta} I_{C2}$ 整理得 $I_{C2} = \left(1 - \dfrac{2}{\beta^2 + 2\beta + 2}\right) I_R$。

    * 加一层之后出现高次项 $\beta^2$：$\beta = 10$ 时分母里已有一百，几乎可以认为 $I_{C2} = I_R$。

* **第二个好处：射极电阻被整个翻过来**
    * 把这个电路倒过来看，就是静态工作点稳定放大电路，其中射极的 $R_E$ 被换成了一个内阻极大的电流源。

      ```text
         静态工作点稳定电路            倒过来看
         ┌─────────────┐              ┌───────────────────┐
         │      R_E    │     ══►     │  电流源（r_o 极大）│
         │  ┌──┴──┐    │              │        ┌──┴──┐   │
         │  │ T1  │    │              │        │ T1  │   │
         │  └┬─┬──┘    │              │        └┬─┬──┘   │
         └──┴─┴────────┘              └──────────┴─┴─────┘
          稳定 I_C，靠负反馈            这就是威尔逊的"射极电阻"
      ```

    * 在这种条件下 $I_C$ 的温度稳定性非常高，用的是那条负反馈通路；它本质上就是从最简单的电路一级级变形而来的。

## 电流源作负载的共发放大电路

* **有源负载的含义**
    * 把共射电路集电极上的 $R_C$ 拿掉换成电流源，就得到有源负载的共射放大电路。

    * 交流通路里集电极这一侧的负载是电流源的小信号输出电阻 $r_{ce2}$，它非常大，原来的 $R_C$ 只有几十千欧量级，倍数一下子被顶上去。

    * 顶到 $r_{ce2}$ 足够大的区间之后，决定权不在管子身上而交给后一级的 $R_L$。

* **"一仆二主"的矛盾**
    * 放大管的 $I_{C1}$ 一边受 $I_B$ 控制，一边又受镜像电流源的 $I_{R2}$ 控制，它的要求和电流源的要求必须匹配才能存在。

    * 图上输入标成大写的 $U_I$ 而不是小写带点的 $u_i$，说明那里本应是一个直流源加一个信号源。

      ```text
                           V_CC
                            │
                        ┌───┴───┐
                        │ 镜像   │   r_ce2 极大
                        │ 电流源 │  ──► 相当于 R_C
                        │ (含 R) │
                        └───┬───┘
                            │
                            │   ← I_C 从这里来
                    ┌───────┴───────┐
                    │ B         C   │
         U_I ──────►│      T1       ├───→ 输出
                    │   （共射）    │
                    │ E             │
                    └───────┬───────┘
                            │
                           GND
      ```

* **h 参数等效里出现的 $r_{ce}$**
    * 负载电流源对前端而言等效为它的集电极输出电阻 $r_{ce2}$，位置正好处在原 $R_C$ 的地方。

    * 因为负载管的动态电阻也参与了，$r_{ce1}$ 就不能再忽略——原来 $R_C$ 小而 $r_{ce1}$ 大可以视为开路，现在两者可以媲美，全部显形。

      ```text
                    β·i_b （流控电流源）
                         ↑
                         │
       输出端 o_c ──────┼──────────────►
                         │
               ┌─────────┴─────────┐
               │                   │
            r_ce1               r_ce2
         （放大管自身的）    （负载管，原 R_C 的位置）
               │                   │
               └─────────┬─────────┘
                         │
                    输入公共端 e
      ```

    * > **定义**：$r_{ce}$ 代表 $u_{CE}$ 的变化对 $i_C$ 的影响——输出特性曲线的上翘。$u_{CE}$ 对 $i_C$ 有影响但很小，所以 $r_{ce}$ 的值很大。

    * 平时画 h 参数等效时忽略它，现在不忽略：在 $c$ 与 $e$ 之间除了流控电流源还要接一个电阻，其他都一样。

    * 负载那两只管子不必再做微变等效——动态信号是从放大管基极进来的，根本过不来，负载只提供静态直流；唯一参与的是 $r_{ce2}$ 的等效。

## 镜像负载差分放大电路

* **电流的 KCL 写法**
    * 输出电流按 KCL 写是 $I_o = I_{C4} - I_{C2}$。

    * 底部电流源是直流恒流源、尾电流被平分；镜像支路的参考管接的是 $T_1$ 那一侧，恒流的一半给了 $T_1$ 和 $T_3$ 这一对，$T_4$ 再把 $T_3$ 镜像一份过来，故 $I_{C1} \approx I_{C3} \approx I_{C4}$，代回得 $I_o = 0$，静态账做平。

    * > **易错点**：凭什么 $I_{C4}$ 与 $I_{C1}$ 相等而不是与 $I_{C2}$ 相等——因为参考管是 $T_1$，镜像支路是从 $T_1$ 那一侧引出来的。静态时 $I_{C2} = I_{C1}$ 是尾电流平分的结果，不是镜像关系。

* **差模进来：输出电流直接翻倍**
    * 动态信号一律写成 $\Delta$。差模下 $\Delta I_{C2} = -\Delta I_{C1}$。

    * 镜像是 $T_3$ 传 $T_4$、参考一路来自 $T_1$，所以 $\Delta I_{C4} = \Delta I_{C3} = \Delta I_{C1}$。

    * 代回 KCL 得 $\Delta I_o = \Delta I_{C4} - \Delta I_{C2} = \Delta I_{C1} - (-\Delta I_{C1}) = 2\Delta I_{C1}$。

    * 没有镜像电流源时单端输出拿到的就是 $\Delta I_{C1}$ 这一份；有了镜像电流源电流直接加倍，后级输出也跟着加倍。

* **共模进来：输出纹丝不动**
    * 共模下 $\Delta I_{C1} = \Delta I_{C2}$；倒推回去 $T_1$ 到 $T_3$ 是控制与被控、$T_3$ 到 $T_4$ 是镜像，得 $\Delta I_{C4} = \Delta I_{C1}$。

    * 于是 $\Delta I_o = \Delta I_{C1} - \Delta I_{C1} = 0$，没有输出。

    * 这与双端输出那套是异曲同工：一个靠相减，一个靠镜像，双端输出相减免疫共模的好处在这里又拿到一次。

    * 底下还有一层：共模信号进到底部那个电流源时已经被打得体无完肤，上面这只镜像再一夹，两下一夹共模就干净了。

## 集成运算放大器的整体电路

* **输出那一段**
    * 互补对称输出级，带克服交越的倍增电路，右边那几只是起保护作用的。

    * 中间那只电容是相位补偿用的，为什么能补相位先不用管；真把它去掉玩出事就明白了。

* **输入与中间那一段**
    * 从输入往里数：先是差分输入级，心里先认定"这是差放输入"，外貌就基本有数了。

    * 再往里是复合管结构，横过来看是共基——从射极输入、集电极输出、基极共用，这就是复合管。

    * 中间那个共射放大电路上面本该有 $R_C$，现在用刚讲过的镜像电流源顶掉；同一张图换个地方，形状一点没改。

    * 底下那一只倒真的是电流源，一个比例电流源，提供静态工作电流。

         u_id

              ┌──────────────┐

## 反馈的必要性

* **集成运放开环就饱和**
    * 集成运放本质上是一个放大倍数高到非常容易饱和的电压放大电路；开环状态下往里塞一点电压就饱和，饱和了就没法用。

    * 唯一办法是让它工作在线性区，条件就是加入反馈——这是学反馈的第一个理由。

    * 反馈不只让电路能用，还能改进放大的稳定性与频率响应：反馈一加，开环那个巨大而不可控的放大倍数就被牢牢约束住。

* **深度负反馈让 $A_{uf}$ 与 $A_u$ 脱钩**
    * 多级放大电路分析到三级就快崩溃：每一级都要算、算完还要级联、频率响应还要一级一级往下乘。

    * 深度反馈条件下的闭环放大倍数 $A_{uf}$ 竟然和基本放大电路的 $A_u$ 无关，几乎只由反馈网络内部的元件决定。

    * 因此只要把 $A_u$ 做到很大就够了，具体是五千还是五万一点关系都没有，分析多级电路时一眼就能看出放大倍数。

* **反馈带来的两个新问题**
    * 信号之间的转换：传感器出来的电压信号长距离传输时受干扰极大，转成电流信号输出更抗干扰；反馈能实现电压与电流之间的相互转换和放大。

    * 啸叫：各处单看都对的电路，系统一启动就"呜呜"叫，是因为没有把负反馈和高频电路放在一起考虑而发生了自激振荡。

    * 自激振荡不总是坏事：波形发生电路就是一个正反馈的自激振荡过程，正负反馈都有用武之地。

## 反馈的定义与分类

* **反馈（feedback）的定义**
    * > **定义**：输出量的一部分或全部被引回到输入端，去影响输入量。

    * 反馈信号只与输出量相关，相当于输出量的一个函数，与输入量、与信号源都没有关系。

    * 没有反馈的系统是广播式的：我看不见自己的输出量，只能按自己的模式一路讲下去；有反馈就能从听众的反应里得到信息并调整讲法。

      ```text
         开环:一条道走到黑

              u_i             u_d                u_o
         ──────────────► ⊕ ──────────► [ 基本放大电路 A ] ──────────►
                        ⊖
                         ↑
                    这就是净输入量


         加反馈:信息在一个圈里转

              u_i                    u_d                u_o
         ──────────────► ⊕ ─────────────────► [ 基本放大电路 A ] ──────────►
                        ⊖  ▲                                              │
                            │ u_f                                          │
                            └──────────────── [ 反馈网络 F ] ◄───────────────┘
      ```

    * 框图读法：开环时净输入量 $u_d$ 就等于输入量 $u_i$；接上反馈后输出量送进反馈网络，网络输出反馈量 $u_f$ 回到输入端与输入量在 $\oplus$ 处叠加得到净输入量 $u_d$。

* **正反馈与负反馈**
    * 正反馈：向上扰动转一圈回来后增强了净输入量，推波助澜继续往上推。

    * 负反馈：本来向上的欲望转一圈回来被减小，把净输入量的增量往下压。

    * > **易错点**：判断看的一定是**增量**而不是绝对值。没有绝对的正也没有绝对的负——输入本身是负信号时，往下再添一个负增量、继续往下推，这仍然是正反馈；把往下的趋势往上托才是负反馈。

      ```text
         扰动出现 → 电流想涨 → 发射极电位被顶起 → 净输入被压回去

         u_i 端输入增大
              │
              ▼
         i_B 增大 ─────► i_C 增大(这是输出量)
                            │
                            ▼
                    i_C 流过 R_e
                            │
                            ▼
                    R_e 上产生压降 u_E 增大
                            │
                            ▼
                    u_BE = u_B − u_E 减小
                            │
                            ▼
                      i_B 被压回来,想涨的趋势被拉下来  ⇒  负反馈
      ```

    * $R_e$ 就是最熟悉的负反馈例子：输出量 $i_C$ 流过 $R_e$ 经反馈网络变成 $u_E$ 的增长，$u_E$ 正是净输入量 $u_{BE}$ 里的一头。

* **直流反馈与交流反馈**
    * > **定义**：反馈信号是直流的叫直流反馈，是交流的叫交流反馈。

    * 判断方法：直流通路里存在的反馈就是直流反馈，交流通路里存在的反馈就是交流反馈。

      | 电路 | 直流通路里有反馈吗 | 交流通路里有反馈吗 | 结论 |
      | :--- | :--- | :--- | :--- |
      | 只有 $R_e$ 直流反馈的那种 | 有 | 没有，$R_e$ 在交流通路里被短路了 | 只有直流反馈 |
      | 交直流都有反馈的那种 | 有 | 有 | 交直流反馈 |

    * 交流反馈一旦存在，由于 $R_e$ 这道负反馈的存在，放大倍数会迅速减小——但它肯定会给回报。

    * 基本分类是交流正反馈、交流负反馈、直流正反馈、直流负反馈；一般直流里面不加正反馈。
