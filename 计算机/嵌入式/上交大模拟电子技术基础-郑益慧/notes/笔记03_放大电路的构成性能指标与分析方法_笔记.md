# 放大电路的构成、性能指标与分析方法

## 放大的本质

### 功率、能量与控制元件

   * **放大**

       * > **定义**：把一个很小功率的电信号变成一个大功率的电信号；放大的是功率，不是单独的电压。

       * 功率由电压和电流两部分组成，真正的放大标志是输出侧同时出现大电压和大电流。

       * 典型场景是扩音机：话筒作为传感器把声波变成极微弱的电信号，这根线直接接扬声器只会听到嘶嘶声，必须经放大电路变成大功率信号去推动扬声器线圈。

       * 信号的电平可以只有几毫伏到几十毫伏，属于很小的量级。

   * **能量控制与能量转换**

       * > **定义**：放大是能量在控制之下的一种转换，输入的小信号只提供控制量，输出信号的能量全部来自外接直流电源。

       * 放大电路一定外接供电电源，输出信号的功率和能量都由它提供。

       * 没有电源，输出的大功率信号不可能凭空出现。

   * **有源元件**

       * > **定义**：构成放大电路不可缺少的核心控制元件，功能是用小信号输入控制大信号输出。

       * 晶体三极管上体现为 $I_B$ 对 $I_C$ 的控制，$I_C$ 是 $I_B$ 的几十倍到几百倍，前提是让它工作在放大状态。

       * 场效应晶体管上体现为 $u_{GS}$ 对 $i_D$ 的控制；进入恒流区前它可以当压控电阻用，也可以截止。

       * 共性是输出部分与输入部分成比例且可控；去掉有源元件放大电路就组不成，这是必要条件。

### 前提条件与测试手段

   * **不失真（保真）**

       * > **定义**：放大的前提是输出波形与输入信号对应、形状大体不变，即不失真。

       * 一旦失真放大就没有意义：送进去的声音大体什么样，扬声器里还应当听得出是这个声音，没有大的畸变。

       * 失真的量化指标是非线性失真。

   * **正弦波测试与扫频**

       * > **定义**：判断放大电路特性是否保真所用的测试信号是正弦波，做的是扫频测试。

       * 依据是任何待放大的交流波形都可以分解为多个频率正弦波的叠加。

       * 用正弦波从低频扫到高频，能扫过去的频率范围就说明该频率的信号可以通过这个放大电路。

       * 因此设计放大电路时首先要问的是：它工作频率在哪、想放大什么；想放大的东西不同，通频带当然不同。

```text
   小功率信号  ──放大──▶  大功率信号          ← 目标
        │                      ▲
        │                      └── 能量来自外部直流电源
        ▼
   必须有一个"能量控制元件"（有源元件）      ← 必要条件
        │
   全过程必须保真、不失真                ← 前提条件
        │
   用一系列不同频率的正弦信号扫频测试        ← 测量手段
```

## 基本放大电路的构成

### 三步搭出直接耦合共射放大电路

   * **第一步：把管子摆进放大区**

       * 目标是把小功率信号变成大功率信号，动手时手里必须先有元件（有源三极管）和能量（电源）两样。

       * 第一个动作是让晶体管工作在放大状态：发射结正向偏置、集电结反向偏置。

       * 一旦进入放大状态就得到 $i_B$ 可以控制 $i_C$，这是后面所有步骤的前提。

       * 技术路线是先讲透晶体三极管再举一反三到场效应管。

   * **第二步：让小信号推动 $i_B$**

       * 输入特性曲线定义的是 $u_{BE}$ 变化引起 $i_B$ 变化，所以真正控制 $i_B$ 的是 $u_{BE}$ 而不是小信号本身。

       * 把 $u_i$ 直接加到 $u_{BE}$ 上行不通：输入只有几毫伏到几十毫伏，而开启电压是 $600\sim700\,\mathrm{mV}$，拿毫伏比毫伏根本开启不了，$i_B$ 仍然是零。

       * 做法是加一个直流电源先把发射结打通，再串一个电阻限流；直接加直流电源而不串电阻会烧管子。

       * 加上 $R_B$ 之后靠叠加定理，基极电位由直流源和 $u_i$ 两个源共同决定，$u_i$ 骑在直流偏置上引起变化的 $i_B$。

       * > **易错点**：把交流信号直接并到偏置节点上靠的是直流偏置先把二极管正偏打开。只有交流本身时，发射结在正半周导通、负半周截止，电路根本没法对称工作。

   * **第三步：把放大的 $i_C$ 取出来**

       * 有了大的交流 $i_C$ 还拿不到电压：若直接从集电极对地输出，两端电位仍然等于电源电压，输出还是直流。

       * 解决办法有两个：让电流直接流进负载 $R_L$，或者让电流流经电阻把电流信号变成电压信号。

       * 加上集电极电阻 $R_C$ 后，$i_C$ 在其上产生的压降与 $i_C$ 成正比，从两端取出的就是被放大的交流电压。

       * $i_C$ 对 $i_B$ 的控制实质是控制电源向集电极送出多大的电流，$i_C$ 的功率量级就是电源电压乘 $i_C$。

### 直接耦合的记号约定与遗留问题

   * **电源记号 $V_{CC}$**

       * 节点电位为正的电源记号写作 $V_{CC}$，相当于该点与地之间接了一个 $V_{CC}$ 的电源，画图时可以直接简化为该点接 $V_{CC}$。

   * **直接耦合共射放大电路**

       * > **定义**：输入、输出与放大电路之间不经过任何滤波或中介元件、一根线直接连上的耦合方式称为直接耦合，由此得到的电路是直接耦合共射放大电路。

       * 让基极一路的压降大于集电极一路的压降，就可以把两套不同大小的电源合并成一套 $V_{CC}$，技术上靠调节 $R_B$ 和 $R_C$ 的阻值实现。

       * 这样合并后交流信号仍是浮地的，两边都不接地，对信号传输和抗干扰都不利。

       * 信号必须有一面接地，所以交流只能从基极一侧进来；把 $u_i$ 直接并到偏置节点上则直流偏置会被信号源短路掉，必须靠电阻把两者隔开。

       * > **易错点**：信号源输出电阻很小，交流信号若直接并到偏置节点，节点电位就等于 $u_i$，电流几乎全部从小信号源流走。必须靠一个电阻把直流偏置和信号源隔开。

   * **直接耦合甩下的两个问题**

       * 输入端效率不高：$u_i$ 要先经 $R_B$ 与信号源内阻分压后才送到晶体管，真正进入晶体管的部分被分走了一部分。

       * 输出端不是纯交流：送给负载 $R_L$ 的输出电压带着直流分量，不是纯交流信号。

       * 这两个问题不解决，直接耦合电路只能作为分析对象，还不能直接接进信号链。

### 交流骑在直流上

   * **$i_B$ 的直流与交流分量**

       * > **定义**：基极电流由静态工作点提供的直流分量与信号引起的交流分量叠加而成，即 $i_B = I_{BQ} + i_b$。

       * 直流偏置把基极电位抬高到开启电压之上并确定一个静态工作点，$u_i$ 的变化才可能引起 $i_B$ 的变化。

       * $i_B$ 出现交流后 $i_C$ 跟着出现交流，$u_{CE}$ 就成为带直流电平的曲线，再把直流拿掉，输出才成为纯交流波形。

   * **交流分量的单向性**

       * 交流分量的正半周只是正向流动的 $i_B$ 在增大，负半周是它在减小，电流始终朝同一个方向流动，不存在负电流。

       * $i_B$ 即使有了交流分量，其小值仍大于 0，交流的负半周对总电流而言依然是正的；这正是直流加交流的好处。

       * 直流分量抽掉之后，剩下的才是有正有负的纯交流。

## 阻容耦合与工作原理

### 电容耦合的作用

   * **阻容耦合（电容耦合）**

       * > **定义**：用耦合电容把交流信号从前后级之间传递、同时隔断直流的耦合方式称为阻容耦合。

       * 两个耦合电容的作用可以概括为通交流、隔直流。

       * 直流在电容上达到稳态时相当于断路，交流则可以越过电容；用阻容耦合时要求信号频率足够高，使电容容抗非常小、对该频率相当于短路。

       * 前一个耦合电容输入、后一个耦合电容输出；经过输出电容后，输出的 $u_o$ 只是从 $u_{CE}$ 中取出的交流部分。

       * > **易错点**：$u_o$ 不等于 $u_{CE}$。输出端串了隔直电容，直流被滤掉，$u_o$ 只是 $u_{CE}$ 的交流分量，这一级本身就相当于一个高通滤波器。

   * **电解电容**

       * 电路图上带正负号的电容一般是容量较大的电解电容，实际是灰的或其他颜色的小圆柱件，焊在电路板上，有大有小。

       * > **易错点**：电解电容有正负极，焊反了会爆，使用前必须看清极性。

### 直流链路

   * **静态工作状态**

       * 分析时先令 $u_i = 0$，相当于让多个输入中的一个先不起作用、另一个先作用。

       * 此时两个耦合电容都断路，只有中间电路受直流作用，中间必然存在一个开启的直流 $U_{BE}$。

       * 由输入特性曲线，$U_{BE}$ 对应一个直流 $I_B$；由输出特性曲线，$I_{BQ}$ 对应一条输出特性曲线，从而得到直流 $I_C$，再得到直流 $U_{CE}$。

   * **输出特性曲线族**

       * > **定义**：输出特性曲线是 $i_C$ 与 $u_{CE}$ 的关系，对应不同的 $I_B$ 各有一条，因此是一族曲线。

       * 针对同一个 $I_B$，只要工作在线性放大区，$i_C$ 几乎不随 $u_{CE}$ 变化而相对固定；这正是 $i_C$ 与 $I_B$ 成比例的依据。

       * $U_{CE}$ 是一个由外电路决定的可变化量：$I_C$ 能不断变大是因为 $U_{CE}$ 在不断变小；曲线实际上略微上倾，$I_C$ 增大时 $U_{CE}$ 也会涨一点点。

       * $U_{CE}$ 与 $I_C$ 的关系为 $U_{CE} = V_{CC} - I_C R_C$，专门分析 $U_{CE}$ 是因为输出电压就是从它里面取出来的。

   * **集电极与发射极何时近似短路**

       * > **易错点**：发射极电位为 0，但集电极与发射极之间并不短路。只有在发射结和集电结双正偏的饱和状态下，$U_{CE}$ 才降到最小、两者近似短路；正常放大状态下 $U_{CE}$ 有电压且在自动调节变化。

### 动态链路

   * **信号传递的六个环节**

       * $u_i$ 越过输入耦合电容直接架在 $u_{BE}$ 上，$u_{BE}$ 的变化经输入特性曲线引起 $i_B$ 的变化，$i_B$ 的变化经输出特性曲线引起 $i_C$ 的变化。

       * $i_C$ 的变化落在集电极电阻上，由 $u_{CE} = V_{CC} - i_C R_C$ 可知压降方向与 $i_C$ 相反，$u_{CE}$ 随之变化。

       * $u_{CE}$ 的变化经输出耦合电容隔直后成为输出 $u_o$。

   * **放大的完整标志**

       * 输出不仅是一个大的交流电压，还带着一个大的输出电流；输入则是小电压加小电流。

       * 一个大 $u_o$ 加一个大 $i_C$，对应一个小 $u_i$ 加一个小 $i_B$，这才构成完整的放大。

## 放大电路的性能指标

### 放大倍数与输入电阻

   * **放大倍数**

       * > **定义**：放大倍数描述输出量与输入量之间的比例关系；放大不只是电压放大电压，电压可以放大成电流、电流可以放大成电流，电流也可以变成放大的电压。

| 放大倍数 | 含义 |
| :--- | :--- |
| $A_{uu}$ | 输出电压 $u_o$ 与输入电压 $u_i$ 之比 |
| $A_{ui}$ | 输出电压 $u_o$ 与输入电流 $i_i$ 之比 |
| $A_{iu}$ | 输出电流 $i_o$ 与输入电压 $u_i$ 之比 |
| $A_{ii}$ | 输出电流 $i_o$ 与输入电流 $i_i$ 之比 |

       * 四种之中最常求的是 $A_{uu}$，它的实质就是算出交流 $u_o$ 与交流 $u_i$ 之间的关系。

       * 知道放大倍数就基本知道这个电路把信号放大成什么样，是本部分最先要分析的指标。

   * **输入电阻 $R_i$**

       * > **定义**：从输入端口看进去，整个放大电路等效成的那个电阻称为输入电阻。

       * 对信号源而言，后面接的放大电路就是一个电阻，就是它的负载；信号源总可以看成电压源加内阻串联，或电流源加内阻并联出现在输入端口上。

       * 放大电路真正得到的输入信号是 $R_i$ 与 $R_s$ 对 $u_s$ 的分压：$u_i = \dfrac{R_i}{R_i + R_s}u_s$。

       * 信号源是电压型时 $R_i$ 越大越好：其一，$u_s$ 固定，$R_i$ 越大分得的输入电压越大；其二，信号源输出功率有限，要减小功率负荷就得减小输出电流，电流越小也要求 $R_i$ 越大。

       * 知道输入电阻才能判断该电路适合配什么样的信号源。

### 输出电阻与级联等效

   * **输出电阻 $R_o$**

       * > **定义**：从输出端口看进去，整个放大电路对负载呈现的内阻称为输出电阻，它等于输出端单口网络等效电源的串联内阻。

       * 输出单口网络等效成电源加内阻串联，电源是开路输出电压 $U_{oo}$，内阻就是 $R_o$。

       * 希望输出稳定电压、$R_L$ 变化时 $u_o$ 尽量不变，需要电路近似电压源，此时 $R_o$ 越小越好。

       * 希望输出稳定电流、$R_L$ 变化时 $i_o$ 几乎不变，需要电路近似电流源，此时 $R_o$ 越大越好。

       * > **易错点**：不存在输出电阻越小越好或越大越好的说法，取决于要用稳定电压还是稳定电流；工程上不是造一个什么都能用的设备，而是要看清自己的目标。

   * **级联时的等效关系**

       * 多级放大电路级联时，连接处成为核心：第一级看第二级，第二级就等效成一个 $R_{i2}$，它同时就是第一级的负载 $R_L$。

       * 第一级只关心后级等效出的输入电阻，不管后面还接了多少级。

       * 比喻成火车车头拉货车：车头只知道被拽的等效重量，断开这个等效负载车头就空了。

   * **后级看到的前级**

       * 后一级不关心前级信号源在不在那个位置，而是把整个前级当成一个大信号源，等效为前级的输出电阻加上前级的开路输出电压。

       * 由此前端无论是信号源还是放大电路，从端口往回看总归等效成一个电源加内阻串联。

       * 多级连接时输入电阻、输出电阻和电源等效的概念更清晰、更重要。

### 通频带与输出能力

   * **通频带（频率响应）**

       * > **定义**：低频衰减与高频衰减之间仍能放大的一段频率范围称为通频带。

       * 低频端的衰减来自耦合电容：频率越低容抗越大，信号越不容易通过；到直流时无法放大。

       * 高频端的衰减来自三极管本身：存在特征频率，频率升高时电流放大倍数不断减小。

       * 电流放大倍数随频率减小的原因是结电容：频率升高时结电容容抗减小，电流被旁路掉，输出信号随之变小。

       * 声音频率主要在 $20\,\mathrm{Hz}$ 到 $40\,\mathrm{kHz}$ 之间，而每个人的频率响应不相同。

       * > **易错点**：不要追求通频带全适应，那是要付出代价的。

   * **非线性失真**

       * 由非线性引起的波形畸变指标，是描述放大电路保真程度的参数。

   * **最大不失真输出电压**

       * > **定义**：输出电压再继续增大就开始失真之前的那个输出电压值。

   * **最大输出功率与效率**

       * 最大输出功率指在保证信号不失真的前提下能在负载上输出的最大功率。

       * 效率是输出功率与输入功率之比，功放尤其看重这一指标。

       * 效率若只有 20%，剩下 80% 全部变成发热：做一个 $1000\,\mathrm{W}$ 的功放，$800\,\mathrm{W}$ 在发热，它的主要功能会变成电炉或电暖气。

       * 最大输出功率与效率这两个指标的前提都是信号不失真。

   * **不同电路类型关心的指标**

       * 一般放大电路分析主要围绕放大倍数、输入电阻、输出电阻三个指标展开。

       * 功率放大电路还要关心效率，高频放大电路还要关心通频带。

## 分析方法：先直流后交流

### 分析原则与两个通路

   * **先直流后交流**

       * > **结论**：要分析动态必须先知道在哪个点上做动态分析，而分析动态之前必须先分析静态。

       * 依据：Q 点在输入特性曲线的不同位置，对相同的 $\Delta u_{BE}$ 会得到不同的 $\Delta i_B$；$\Delta i_B$ 变大则 $\Delta i_C$、$R_C$ 上压降和 $u_o$ 跟着变大。

       * 这个结论有前提条件：$\Delta u_{BE}$ 必须处在比较小的范围内，这样一段曲线才能近似看成直线段。

       * 直流本身不提供任何放大倍数，它只是提供了一个工作点。

   * **直流通路**

       * > **定义**：直流通路是放大电路中直流所流经的那条通路。

   * **交流通路**

       * > **定义**：交流通路是交流信号所流经的那条通路。

       * 这是一个近似说法：三极管是非线性元件，叠加定理只适用于线性电路，等效成线性元件之后才能名正言顺地使用。

### 直流通路的画法与用途

   * **画法规则**

       * 只研究直流时把输入信号置零，置零就是接地；前面给的是信号源 $u_s$ 就把 $u_s$ 置零，直接给 $u_i$ 就把 $u_i$ 置零，反正信号源一律置零。

       * 直接给 $u_i$ 相当于近似默认前端是一个电压源。

       * 电容相当于断路，电感相当于短路。

   * **用途**

       * 直流通路最大的用处是静态上的一切错误在图上一下子就能看出来。

       * 判断依据：把输入信号置零后画出直流通路，基极电阻的一端若直接接地就不合理，若经一个电阻接到 $V_{CC}$ 才合理；电路合不合理，画一次直流通路就判完了。

       * 直流通路上要算的量：输入特性曲线上求 $U_{BE}$ 和 $I_B$，输出特性曲线上求 $U_{CE}$ 和 $I_C$，顺序是先 $U_{BE}$、$I_B$，再 $I_C$、$U_{CE}$。

```text
                              +V_CC
                                │
             ┌──────────────────┼──────────────┐
             │                  │              │
            R_B1                 │             R_C
             │                  │              │
u_i ─[C_i]────┤                  │              │
             ●────── B ─────────┤              │
            R_B2                 │      C ─[C_o]─┬── u_o
             │                  │              │
            GND                GND            GND
```

### 交流通路的画法

   * **两条处理规则**

       * 第一条，直流电源置零：交流信号流过直流电源时相当于经过一个短路，信号直接过去。

       * 第二条，电容短路：阻容耦合电路要求信号频率足够高，耦合电容容抗很小，可近似当作短路。

   * **三个具体动作**

       * 置零就是接地：凡是带加号的 $V_{CC}$ 都要接地处理。

       * 同一根导线上的两条竖线等电位，可以并成一根；基极上下两个电阻的竖线并起来就是 $R_B$，集电极电阻同理。

       * 耦合电容直接用导线连过去。

       * > **易错点**：交流通路的第一件事就是把直流源置零，置零之后却仍把直流源留着、电容又干掉了，画出一个四不像的电路。

```text
   u_i ────── B ────────────────── C ──── u_o
              │                     │
             R_B                   R_C
              │                     │
             GND                   GND
```

   * **两个通路的对照**

| 处理对象 | 直流通路（静态） | 交流通路（动态） |
| --- | --- | --- |
| 信号源 $u_i$（或 $u_s$） | 置零（接地） | 保留 |
| 直流电源 $V_{CC}$、$V_{BB}$ | 保留 | 置零（接地） |
| 耦合电容 $C_i$、$C_o$ | 断路 | 短路 |
| 关心的量 | $U_{BEQ}$、$I_{BQ}$、$I_{CQ}$、$U_{CEQ}$ | $\Delta u_{BE}$、$\Delta i_B$、$\Delta i_C$、$\Delta u_{CE}$ |

### 图解法

   * **输入回路定 $Q$ 点**

       * 先把 $\Delta u_i$ 置零，只看直流电源时，输入回路的负载线为 $i_B = \dfrac{V_{BB} - u_{BE}}{R_B}$，横截距是 $V_{BB}$，纵截距是 $\dfrac{V_{BB}}{R_B}$。

       * 负载线与输入特性曲线的交点就是静态工作点 $Q$，横坐标是 $U_{BEQ}$，纵坐标是 $I_{BQ}$。

       * 加进 $\Delta u_i$ 之后负载线平移，得到与原线平行的两条线，与输入特性曲线的交点为 $P_1$、$P_2$；横向读出 $\Delta u_{BE}$，沿曲线纵向读出 $\Delta i_B$。

       * > **易错点**：对静态点最苛刻的要求就在这里，$Q$ 点位置一变，相同的 $\Delta u_{BE}$ 就给出不同的 $\Delta i_B$，$Q$ 点定错后面全错。

   * **输出回路读出放大倍数**

       * 输出回路的负载线为 $i_C = \dfrac{V_{CC} - u_{CE}}{R_C}$，横截距 $V_{CC}$、纵截距 $\dfrac{V_{CC}}{R_C}$，两条截距都不能跑出坐标范围。

       * 在输出特性曲线上找 $i_B = I_{BQ}$ 的那一条曲线，它与输出负载线的交点就是输出侧 $Q$ 点。

       * 从 $Q$ 竖直上移 $\Delta i_C = \beta\Delta i_B$ 落到该输出特性曲线上的 $A$ 点，再从 $A$ 水平左走回到负载线上的 $B$ 点，竖直距离是 $\Delta i_C$，水平距离是 $\Delta u_{CE}$。

       * 把 $\Delta u_{CE}$ 与 $\Delta u_i$ 一比，放大倍数就出来了。

   * **为什么能用 $\Delta u_i$ 代替 $u_i$**

       * 相对于直流工作点，一个交流信号的变化量无外乎就是它的峰峰值，完全作图法用 $\Delta u_i$ 画就够了。

       * 图解法的全部要害只有两步：先确定 $Q$ 点，再在 $Q$ 点上叠加 $\Delta$，即 $\Delta u_i \to \Delta u_{BE} \to \Delta i_B$，再搬到输出侧得到 $\Delta i_C$、$\Delta u_{CE}$。

       * 图解法的价值在于把工作原理分析清楚，不能对每个电路都靠一张张图画下去。

### 三极管的线性化

   * **动态电阻 $r_{be}$**

       * > **定义**：输入端的动态电阻 $r_{be} = \dfrac{\Delta u_{BE}}{\Delta i_B}$，即输入特性曲线上过 $Q$ 点那条切线斜率的倒数。

       * 用它替换输入端整块二极管，只在交流的意义上等效。

       * > **提示**：两条曲线上随便取点比出的比值都不一样，只有在 $Q$ 点附近 $\Delta u_{BE}$ 与 $\Delta i_B$ 的比值才是固定的，因此前提必须是纯交流。

       * > **易错点**：$u_{BE}$ 与 $i_B$ 的关系绝对不能用 $r_{be}$ 去等效；$r_{be}$ 描述的是变化量之间的关系。

   * **输出端用受控电流源**

       * 输出端只要求一件事：输出电流就是 $\beta$ 倍的输入电流 $\Delta i_B$，因此用一个流控电流源替代三极管。

       * 线性化之后整个三极管变成 $b$ 与 $e$ 之间一个电阻、$c$ 与 $e$ 之间一个流控电流源，电路被封进一个黑匣子里，这就是等效的概念。

   * **四种带 $I_B$ 的写法**

| 写法 | 含义 |
| --- | --- |
| $I_B$ | 纯直流 |
| $i_B$ | 瞬时值，既含直流又含交流 |
| $i_b$ | 仅含交流分量 |
| $\dot{I}_b$ | 交流分量的正弦相量 |

       * 直流没有相量，所以在交流等效模型中标定的量统统是纯交流。

   * **等效成立的原因：原点搬到 $Q$ 点**

       * > **结论**：用 $r_{be}$ 等效相当于把坐标原点从原来的位置搬到了 $Q$ 点，原点附近的这一小段曲线才成为一根过原点的直线。

       * 这解释了交流通路为什么必须把直流电源置零：只有直流置零，原点才真的搬到 $Q$ 点上。

       * 交流信号单独作用其实不现实，它一定是在直流的肩膀上工作，即交流骑在直流上；只是近似认为先有直流再让交流单独作用才能等效。

       * 没有直流绝对不行，所以等效的第一步必须是先直流。

   * **$r_{be}$ 的表达式**

       * > **定义**：$r_{be} = r_{bb'} + (1+\beta)\dfrac{U_T}{I_{EQ}}$。

       * 后一项是发射结 PN 结的动态等效电阻，$U_T$ 是温度当量；$I_{EQ}$ 是静态工作点中的发射极电流。

       * $r_{bb'}$ 是基区的体电阻，因为基区掺杂浓度很低，大约 $100\sim300\,\Omega$。

       * 公式清楚地体现了直流决定动态参数：静态工作点定下来就决定了 $r_{be}$ 的大小。

### 完整分析流程

   * **静态求解**

       * 先画直流通路，再用二极管的直流估算模型求静态工作点；估算模型相当于在发射结处放了一个开启电压 $U_{BEQ}$。

       * $I_{BQ} = \dfrac{V_{CC} - U_{BEQ}}{R_B}$，$I_C = \beta I_{BQ}$，$I_{EQ} = (1+\beta)I_{BQ}$。

       * 静态量算出后，$r_{be}$ 就直接求出来了；$r_{be}$ 只在动态分析时才使用。

   * **工作状态判别**

       * 放大与饱和都是开通的，截止是反偏的，所以先判是不是截止，再区分放大还是饱和。

       * 先求电路能提供的最大集电极电流 $I_{C\max} = \dfrac{V_{CC} - U_{CES}}{R_C}$，再从输入回路求出 $I_B$，拿 $\beta I_B$ 与 $I_{C\max}$ 比大小。

| 比较结果 | 工作状态 | $I_C$ | $U_{CE}$ |
| --- | --- | --- | --- |
| $\beta I_B > I_{C\max}$ | 一定饱和 | $I_C = I_{C\max}$ | 非常小 |
| $\beta I_B < I_{C\max}$ | 放大 | $I_C = \beta I_B$ | 正常 |

       * 道理是后级能提供的电流有上限：$\beta I_B$ 超过上限说明要不到那么多电流，只能被拽到上限，那就是饱和；小于上限说明电流供得起，按 $\beta I_B$ 走即工作在放大状态。

   * **动态求解**

       * 画交流通路，再把交流通路换成微变等效电路，这是整个流程的关键点。

       * 微变等效只需找到 $b$、$c$、$e$ 三个点，然后在 $b$ 与 $e$ 之间接 $r_{be}$、在 $c$ 与 $e$ 之间接流控电流源 $\beta i_b$。

       * 不带负载时放大倍数为 $A_u = -\beta\dfrac{R_C}{r_{be}}$，其中 $U_o = -i_C R_C$、$U_i = i_b r_{be}$，消掉 $i_b$ 就得到 $A_u$。

       * 输入电阻从输入端往里看，输出电阻从输出端往里看；求出这几个参数后剩下的统统是基本电路的内容，最常用的手段是戴维南等效电路。

## $h$ 参数等效模型

### 双口网络与全微分

   * **把三极管看成双口网络**

       * 把三极管端口封起来就是双口网络，可以对它做混合参数模型。

       * 输入端是 $U_{BE}$ 和 $I_B$，输出端是 $U_{CE}$ 和 $I_C$；两个端口特性的自变量都是 $I_B$ 和 $U_{CE}$。

       * $U_{BE}$ 与 $I_B$ 的关系还受 $U_{CE}$ 影响：当 $U_{CE} \geq 1\,\mathrm{V}$ 之后这条线几乎不动，否则它是一族曲线，对不同 $U_{CE}$ 各有一根。

       * $I_C$ 既与 $I_B$ 有关，也与 $U_{CE}$ 有关，后者直接由输出特性曲线表明。

   * **对端口特性做全微分**

       * > **提示**：要对函数关系求变化量之间的关系就做全微分，$\Delta$ 就是变化量趋近于 0 时的微分。

$$\mathrm{d}U_{BE} = \left.\frac{\partial U_{BE}}{\partial I_B}\right|_{U_{CE}} \mathrm{d}I_B + \left.\frac{\partial U_{BE}}{\partial U_{CE}}\right|_{I_B} \mathrm{d}U_{CE}$$

$$\mathrm{d}I_C = \left.\frac{\partial I_C}{\partial I_B}\right|_{U_{CE}} \mathrm{d}I_B + \left.\frac{\partial I_C}{\partial U_{CE}}\right|_{I_B} \mathrm{d}U_{CE}$$

       * > **提示**：第二项后面的下标不能漏，$\dfrac{\partial U_{BE}}{\partial U_{CE}}$ 的含义是 $I_B$ 保持常数、只对 $U_{CE}$ 求偏导。两项偏导是在两种不同的冻结条件下算出来的，不能混。

   * **换成四个混合参数**

       * 把四个偏导分别用四个混合参数取代，端口方程变成

$$\Delta U_{BE} = h_{11e}\,\Delta I_B + h_{12e}\,\Delta U_{CE}$$

$$\Delta I_C = h_{21e}\,\Delta I_B + h_{22e}\,\Delta U_{CE}$$

       * 只推数学会认为思路清晰，但推出来的公式必须知道它的物理意义。

### 四个 $h$ 参数与等效电路

   * **从方程反构电路**

       * 输入端 $\Delta U_{BE}$ 是两部分相加，电压相加对应串联，所以 $h_{11e}$ 画成阻抗、$h_{12e}$ 画成压控电压源（控制量是 $\Delta U_{CE}$），两者串联在 $b$–$e$ 之间。

       * 输出端 $\Delta I_C$ 也是两部分相加，电流相加对应并联，所以 $h_{21e}$ 是流控电流源（控制量是 $\Delta I_B$）、$h_{22e}$ 是电导，两者并联在 $c$–$e$ 之间，画图时电导用阻抗 $\dfrac{1}{h_{22}}$ 的形式写出。

       * 两个回路的下端都接发射极 $e$；这就是混合二字的由来，因为这几个参数的量纲都不一样。

```text
            b                             c
   ┌────────┬────────┐           ┌────────┬────────┐
   │        │        │           │        │        │
   │[ h11 ]          │           │  (h21) │        │
   │        │        │           │        │        │
   │        ( h12 ) │           │         1/h22   │
   │        │        │           │        │        │
   └────────┴────────┘           └────────┴────────┘
            │                             │
            └─────────────────────────────┴
                              │
                       发射极 e（公共参考端）
```

   * **四个参数对应的物理量**

| 参数 | 对应的是哪个量 | 量级与处理 |
| --- | --- | --- |
| $h_{11}$ | $Q$ 点处 $\Delta U_{BE}$ 与 $\Delta I_B$ 的关系，即那根线的斜率倒数 | 就是 $r_{be}$ |
| $h_{12}$ | $U_{CE}$ 波动引起 $U_{BE}$ 的改变量，即压控电压源 | $U_{CE} > 1\,\mathrm{V}$ 后曲线几乎重合，在 $0.01$ 这样量级，可以忽略 |
| $h_{21}$ | $I_C$ 对 $I_B$ 的关系，即流控电流源 | 就是 $\beta$ |
| $h_{22}$ | 输出特性曲线的上翘程度，是个电导 | $=\dfrac{1}{r_{ce}}$，是 $10^{-5}$ 或比这还小，可以忽略 |

       * $h_{22}$ 越小说明输出特性曲线越平；等效电阻 $r_{ce}$ 在百千欧、百千欧以上，后级负载电阻没有大到能和它相媲美时，几乎可以认为 $r_{ce}$ 是断路的。

### 简化 $h$ 参数与微变等效电路

   * **简化 $h$ 参数**

       * > **结论**：忽略 $h_{12}$ 与 $h_{22}$ 两个小量后得到的简化 $h$ 参数模型，就是微变等效电路。

       * 直接从图形上感性推出的模型没有考虑 $U_{CE}$ 对输入曲线的影响，这一项正是 $h_{12}$；它小到可以忽略，才使输入端模型与感性推导结果一致。

       * 感性的等效之所以成立，不是碰巧对，而是被忽略的两项确实小到可以忽略；$h$ 参数模型把这项误差明确地算了出来。

   * **$r_{be}$ 的构成与计算**

       * $r_{be}$ 由两部分构成：基区体电阻 $r_{bb'}$，以及折算到基极端口的发射结动态电阻。

       * 发射区也有体电阻 $r_{e'}$，但因掺杂浓度非常高而非常小，可忽略不计。

       * 发射结的 PN 结动态电阻按 $\dfrac{U_T}{I_D}$ 求，代入这里流过结的电流是 $I_E$ 而不是 $I_B$，所以结果是 $r_{b'e'} = \dfrac{U_T}{I_{EQ}}$。

       * 由 $U_{be} = I_b r_{bb'} + I_e r_{b'e'}$ 与 $I_e = (1+\beta)I_b$ 得 $r_{be} = r_{bb'} + (1+\beta)\dfrac{U_T}{I_{EQ}}$。

       * > **提示**：做题时写成 $U_T/I_{BQ}$ 也能得到同样结果，但推导和理解时要记住，$r_{bb'}$ 是手册可查的基区体电阻，$(1+\beta)r_{b'e'}$ 是发射结动态电阻折算到基极端口的结果，两项物理来源完全不同。

   * **分析步骤总结**

       * 先求解静态、定下 $Q$ 点；再求 $r_{be}$；然后画微变等效电路；最后按基本电路方法求 $A_u$、$R_i$、$R_o$。

## 基本共射放大电路的动态分析

### 已知量与求解顺序

   * **已知量与待求量**

       * > **结论**：一个实际的共射放大电路只要求三样：源电压增益 $A_{us} = u_o/u_s$、输入电阻 $R_i$、输出电阻 $R_o$。

       * 已知量包括 $R_b$、$R_c$、$R_s$、$V_{CC}$、$R_L$、估算模型中的 $U_{BEQ}$ 以及手册可查的 $r_{bb'}$；给出 $U_{BEQ}$ 相当于在二极管里直接给出了开启电压。

       * 信号源是电压型的 $u_s$ 带内阻 $R_s$ 接进来，电路输出 $u_o$。

   * **求解顺序**

       * 这些量都是动态量，而动态不能凭空算出来：要 $h$ 参数模型先要有 $r_{be}$，要有 $r_{be}$ 又必须先有静态工作点，所以这是倒着在分析需求。

       * 正着做题的顺序就是先静态，再交流通路，再 $h$ 参数等效，然后依次求 $A_u$、$R_i$、$A_{us}$、$R_o$。

### 静态求解

   * **电位分析法**

       * > **定义**：从指定的零电位点出发，一个元件一个元件地累加电位差来求静态电流的方法称为电位分析法。

       * 取发射极为零电位点，从 $V_{CC}$ 那一头发起：基极电位比发射极高 $U_{BEQ}$，从基极往 $V_{CC}$ 那头又升了 $I_{BQ}R_b$，于是 $V_{CC} = U_{BEQ} + I_{BQ}R_b$，解得 $I_{BQ} = \dfrac{V_{CC} - U_{BEQ}}{R_b}$。

       * 有了 $I_{BQ}$ 就得到 $I_{EQ}$、$I_{CQ} = \beta I_{BQ}$；$U_{CEQ}$ 同样用电位分析法，$c$ 点电位比 $e$ 点高 $U_{CEQ}$，再往上到 $V_{CC}$ 要升 $I_{CQ}R_c$，即 $V_{CC} = U_{CEQ} + I_{CQ}R_c$。

       * 之所以好用，是因为人最容易错的地方是把一整堆东西当成整体一起看；一个元件一个元件分析永远不会错，因为一个元件就是 $u = i \cdot r$ 或两端电位差，概念干净，不给犯错留空间。

   * **发射极串电阻时**

       * 增加发射极电阻后，电压关系变为 $V_{CC} = I_{EQ}R_e + U_{BEQ} + I_{BQ}R_b$，其中 $I_{EQ} = (1+\beta)I_{BQ}$。

       * > **易错点**：⚠️ $R_e$ 上的压降要乘发射极电流 $I_{EQ}$，不是 $I_{BQ}$；看到电路里多了电阻就顺手当串联电阻处理，是把整体一起想的毛病犯在最典型的位置上。

   * **直流的两个使命**

       * 第一是判断三极管到底工作在不在放大状态，第二是定出静态工作点从而推出 $r_{be}$。

       * 第二个使命的结果就是递给动态分析的唯一一张门票；$r_{be}$ 一到手，直流的使命就算到头了。

### 交流通路与等效模型

   * **敢用 $r_{be}$ 的理由**

       * > **提示**：用 $r_{be}$ 相当于把坐标原点提到了静态工作点，那里才是一根真正过原点的直线；线性电阻的定义本来就是一根过原点的直线，原点不搬上去就谈不上 $r_{be}$。

       * > **注意**：直流其实还在，只是被抽象掉了。交流时的 $i_b$ 并不是一个负的电流，把直流加回去看，那一段仍然是正向的，只是正向在减小；抽象成纯交流纯粹是为了能用 $r_{be}$ 做等效。

   * **交流通路的两件事**

       * 第一件，把所有直流置零，即上面说的原点平移。

       * 第二件，耦合电容在交流通路里相当于短路。

       * 画法是先接地再整理：接地这一步处理掉基极电阻和集电极电阻，它们就可以翻下来，交流通路随之整理干净。

       * > **易错点**：⚠️ 交流通路里绝不允许 $r_{be}$ 和 $V_{CC}$ 同时出现；$V_{CC}$ 是直流偏置，$r_{be}$ 是直流被扣掉之后的线性切片，原点没搬上去，两者同时在场时 $r_{be}$ 不成立。

   * **微变等效只加两个元件**

       * 步骤是找出基极、集电极、发射极三个点（此时发射极相当于接地），擦掉重画，然后只加两个元件。

       * $b$ 与 $e$ 之间接 $r_{be}$；$c$ 与 $e$ 之间接受 $i_b$ 控制的流控电流源，大小为 $\beta i_b$，即 $i_c$。

       * 这样一个非线性元件在低频小信号条件下就变成了线性等效；所有符号换成小写，因为这里全是纯交流量、直流已被拿掉。

```text
              c
              o
              |
        +-----+-----+
        |           |
        |  [ x ib ] |     ic = beta * ib
        |           |
        +-----+-----+
              |
              o-----------------------+
              |                       |
            b o------[ r_be ]--------o e  (= 0, ground)
                                      |
  -----------------------------------o--------  ground
```

### 电压放大倍数

   * **$A_u$ 的定义与范围**

       * > **定义**：$A_u = \dfrac{U_o}{U_i}$，只针对中间那块固定的放大电路本体，左右两边会变、本体做好后一般不再动。

   * **表达式与每一项的含义**

       * $U_o = i_c (R_L \parallel R_c)$（带负号），$U_i = i_b r_{be}$，全部以 $i_b$ 为参数是因为 $i_c = \beta i_b$，合起来得

$$A_u = \frac{U_o}{U_i} = -\frac{\beta (R_L \parallel R_c)}{r_{be}}$$

| 因子里的一项 | 对应放大过程的哪一步 |
| --- | --- |
| $r_{be}$ | 动态 $u_{be}$ 变成动态 $i_b$：多大的动态 $u_{be}$ 能产生多大的动态 $i_b$ |
| $\beta$ | 动态 $i_b$ 变成动态 $i_c$ |
| $R_c$ | 动态 $i_c$ 变成动态输出量：上面挂多大的 $R_c$（开环、空载时） |
| $R_L$ | 接上负载以后负载对输出的影响 |

   * **负号的来源**

       * > **结论**：共射电路是反相的，输出 $U_o$ 本质上是 $V_{CC} - u_{ce}$，正好倒了一个相；而 $u_{ce} = V_{CC} - i_c R_c$，$u_{ce}$ 里 $i_c$ 是反着走的，所以 $U_o$ 带这个负号。

### 输入电阻与源电压增益

   * **$R_i$ 的求法**

       * > **定义**：输入电阻 $R_i$ 是从输入端口看进去，后面那一大堆东西等效成的那个电阻；接放大电路和接一个等效电阻对信号源是一回事，盒子里装什么对等效电阻没有区别。

       * 基本共射电路一眼可看出 $R_i = R_b \parallel r_{be}$。

       * 求 $R_i$ 时要考虑 $R_L$：到输入回路虽然断开，但 $R_L$ 是后面那一串车厢中的一节，往上挂就必须算进去，它同样要从这个放大电路获取信号。

       * 输入电阻指的是整个后面那一大堆的等效，后面挂的东西不一样，输入电阻就不一样。

   * **$A_{us}$**

       * $R_L$ 定下来后 $U_i$ 与 $U_s$ 就是一次分压：$\dfrac{U_i}{U_s} = \dfrac{R_i}{R_i + R_s}$，于是 $A_{us} = A_u \cdot \dfrac{R_i}{R_i + R_s}$。

   * **放大倍数相同不等于源电压增益相同**

       * 举例：信号源 $U_s = 20\,\mathrm{mV}$、内阻 $R_s = 1\,\mathrm{k}\Omega$，两个电路的 $A_u$ 都是 100 倍。

       * $R_i = 2\,\mathrm{k}\Omega$ 的那个分到 $U_i = \dfrac{2}{2+1}\times 20\,\mathrm{mV} = 6.67\,\mathrm{mV}$，放大后 $U_{o1} = 0.667\,\mathrm{V}$。

       * $R_i = 100\,\mathrm{k}\Omega$ 的那个 $R_i \gg R_s$，$U_i \approx 20\,\mathrm{mV}$ 几乎拿走整个信号源电压，放大后 $U_{o2} = 2\,\mathrm{V}$。

       * > **结论**：放大倍数一模一样，输出却差了整整三倍；对电压型信号源来说输入电阻越大越好，分过去的电压损失越小，后面放大出来的幅度才越大。

### 输出电阻

   * **$R_o$ 的定义与求法**

       * > **定义**：输出电阻 $R_o$ 是放大电路对负载等效成的电源串联内阻。

       * 求法有两条：一是把前端独立源置零后从端口看进去的等效电阻；二是端口电压比端口电流，或开路电压比短路电流。

       * 电路中一旦出现受控源，就必须走第二条路，不能只做电阻串并联。

   * **基本共射电路中 $R_o = R_c$**

       * 独立电压源可以置零，受控源不能置零；置零之后 $i_b = 0$，受控电流源随之等于零、相当于断路，从输出端看进去剩下 $R_c$。

   * **$R_o$ 大小决定输出像什么源**

       * 把输出侧等效成 $U$ 串 $R_o$ 再挂 $R_L$，有 $U_o = \dfrac{R_L}{R_L + R_o}U$ 与 $I_o = \dfrac{U}{R_L + R_o}$。

       * $R_o \ll R_L$ 时分压比近似 1，$R_L$ 怎么变 $U_o$ 都几乎不变，输出近似电压源。

       * $R_o \gg R_L$ 时 $I_o \approx U/R_o$，$R_L$ 怎么变 $I_o$ 都几乎不变，输出近似电流源。

## 静态工作点稳定与温度漂移

### 温度推动 Q 点移动

   * **温度对晶体管参数的影响**

       * 随环境温度升高，整族输出特性曲线整体上移，晶体管的 $Q$ 点随之上升。

       * 三条变化都指向同一方向：$\beta$ 上升；穿透电流 $I_{CEO}$ 上升（反向电流本质是少子的事，温度升高必然上去）；合成结果是 $Q$ 点上升。

       * 温度下降则 $Q$ 点下降。

   * **两种失真的产生**

       * 静态工作点一动，两种失真都可能发生；温度能推动静态工作点移动，所以温度就能引起失真。

### 截止失真与饱和失真

   * **截止失真**

       * $Q$ 点本来在放大区中间，温度一降滑到边界以下直接进入截止区。

       * $i_C$ 的尾巴被砍平；因为共射反相，$u_o$ 上看到的是头部被砍平，示波器上看波形没了头。

   * **饱和失真**

       * $Q$ 点被推高时 $I_B$ 那一头没事，把 $I_B$ 拉到更高，但 $I_C$ 同时受两个约束。

       * > **定义**：$I_C$ 一定在输出特性曲线围起来的区域内，也一定在负载线上，所以它只能在负载线与输出特性曲线区域的交点处取得最大值 $I_{C\max}$。

       * $I_B$ 要求过分时能提供的最大 $I_C$ 就是 $I_{C\max}$，$I_C$ 的头部被削平；因为反相，$u_o$ 的底部被削平。

       * 两种失真共同说明必须想办法让静态工作点稳定，这就是静态工作点稳定电路要解决的问题。
