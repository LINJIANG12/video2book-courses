# 放大电路的频率响应

## 波特图的坐标刻度与截止频率约定

   * **分贝刻度**

       * > **定义**：波特图纵坐标写 $20\lg|A_u|$，这套刻度就叫分贝。

       * 0 dB 代表不放大、代表没有增益，该多少就是多少。

       * dB 为正代表放大，为负代表衰减；说"负"时用词是"衰减"。

   * **上下限截止频率的下标**

       * > **定义**：$f_H$ 是低通电路的上限截止频率，$f_L$ 是高通电路的下限截止频率。

       * > **易错点**：⚠️ 看着下标 $f_H$ 就以为它属于高通电路，是错的；这两个下标跟电路的归属是交叉的，一混全盘皆输。

   * **公式中的等效电阻 $R$**

       * > **定义**：高通、低通公式里的 $R$，是从电容 $C$ 两端看进去、把它余下的电路做一次戴维宁等效后得到的那个等效内阻。

       * 实际电路里电容周围常堆着一大堆电阻，还带着内阻的信号源，公式照样能用，只是要按这个等效内阻代入。

## 高通电路波特图的三个区段

   * **dB 表达式**

$$20\lg|A_u| = 20\lg\frac{f}{f_L} - 20\lg\sqrt{1+\left(\frac{f}{f_L}\right)^2}$$

       * 做法是先定性、再近似，按区段去看；拘泥于逐点详细计算反而很难看明白。

   * **转折点 $f = f_L$**

       * > **定义**：这一处不用近似，传输比正好降到原来的 $\frac{1}{\sqrt2}$，取 dB 即 $20\lg\frac{1}{\sqrt2} = -10\lg 2 \approx -3\ \text{dB}$。

       * 该点上的相角正好是 $+45^\circ$，这是高通的标志；低通在同一位置是 $-45^\circ$。

   * **平台段 $f \gg f_L$**

       * 分子分母对 $f$ 的依赖几乎是同一个东西，两项大刀阔斧地抵消，剩下 $\lg 1 = 0$，即 0 dB。

       * 说明频率远高于下限截止频率时高通电路没有衰减；滤波电路不会去放大，谐振的情形不在此处讨论。

   * **斜线段 $f \ll f_L$**

       * 分母根号里的 1 远远压过 $\left(\frac{f}{f_L}\right)^2$，分母就是 1，只剩分子那一项 $20\lg\frac{f}{f_L}$，画出来是一根直线。

| $f$ 相对 $f_L$ 的变化 | 传输比的变化 | dB 的变化 |
| :--- | :--- | :--- |
| 降为原来的 $1/10$ | 衰减为 $1/10$ | 下降 $20\ \text{dB}$ |
| 降为原来的 $1/100$ | 衰减为 $1/100$ | 下降 $40\ \text{dB}$ |

       * 这根线叫每十倍频 20 dB 的衰减线。

       * 反推用法：看到"每十倍频 20 dB"的斜率就是一级高通，斜率是每十倍频 40 dB 就是两级。

       * 40 dB 对应两级，是因为对数把乘法变成加减，级数翻倍在幅频相乘的意义下相当于乘一个平方，取对数后平方就变成加倍。

```text
20lg|Au|
     |                                      ____________  0 dB
     |                     _____/
     |                _____/
     |           _____/
     |      ___/
     +--------.---------------------------------------------> f
     |      /
     |    /
     |  /
     |/
     +--+-----+---------------------------------------------
      0.1fL  fL
```

   * **拐点读图**

       * 拐点落在 $f_L$ 上，高度是 −3 dB，也就是 $|A_u|$ 降到原来的 $1/\sqrt2$。

       * 拐点右边是一条水平的 0 dB 线，左边是以 $f_L$ 为拐点、$0.1f_L$ 为终点的斜线，斜率每十倍频 20 dB。

       * 横轴上 0.1 倍频与 10 倍频两个位置，恰好对应相频特性的两个转折点。

### 工程近似与三步动作

   * **近似规则**

       * 精确曲线在 $f_L$ 附近本该是一段圆滑的过渡曲线，实际上几乎不会去画它——要想滤掉某个波，工作点离截止频率本来就差得很远，不会贴着 $f_L$ 设计。

       * 转折点取在 $f_L$；右边的 $10$ 倍 $f_L$ 与左边的 $0.1$ 倍 $f_L$，分别对应相频特性上已经达到稳定的位置。

   * **三步画法**

       * 先找 $f_L = \dfrac{1}{2\pi RC}$，其中 $R$ 是从电容 $C$ 两端看进去的等效电阻——这是关键中的关键。

       * 在 $f_L$ 上立拐点，高度 −3 dB。

       * 左边画每十倍频 20 dB 的斜线，右边画水平线，顺手标出 $0.1f_L$ 与 $10f_L$。

   * **低通与相频位置**

       * 低通电路的画法完全一样，只是左右翻过来。

       * 相频特性上 $10$ 倍处相角为 $0^\circ$，$0.1$ 倍处为 $90^\circ$。

   * **高低通的判别方法**

       * > **易错点**：⚠️ 活学活用，千万别套公式判断高频还是低通；把 $\omega$ 的两个极端值代进去看大小，秒出结果。

       * $\omega \to \infty$ 时传输比变小、$\omega = 0$ 时变大，就是低通。

## 全频域分析的三段分工

   * **中频段**

       * > **定义**：既不考虑阻容耦合电容的影响，也不考虑极间电容和分布电容的影响，直接算。

       * 前面那一大套常规分析全部属于中频段。

   * **低频段**

       * 把阻容耦合电路单独拿出来等效成高通电路，用高通那一段的波特图画法补上。

   * **高频段**

       * > **定义**：这一段眼下做不出来，原因是手里没有模型。

       * 极间电容该加在哪个节点上、值是多少都无从谈起，连分布电容都不考虑、只考虑极间电容时也不知道该安在哪儿。

       * 问题不在低通电路本身，而在于模型；只要极间电容的值和位置直接给出来，它同样是一个低通电路。

```text
                     full band
                        |
        +---------------+---------------+
        |               |               |
   [ midband ]     [ low band ]   [ high band ]
     can do          can do          blocked
   caps ignored    R-C coupling      no model
        |               |               |
        +---------------+---------------+
                        |
                        v
        the key : fetch the transistor's
             high-frequency model
                   ( hybrid  pi model )
```

   * **三段必须联合起来看**

       * 一个放大电路既有高频、中频、低频特性，三段合起来才是全频域波特图。

       * 突破口是拿到高频等效模型，前辈们给出的工具就是混合 $\pi$ 模型。

## 混合 π 模型的搭建

   * **混合 π 模型（hybrid $\pi$ model）**

       * > **定义**：考虑了发射结电容和集电结电容这两样极间结电容之后得到的晶体管模型。

   * **第一步：拆电阻找到 $b'$ 点**

       * $h$ 参数等效模型里的 $r_{be}$ 是 $r_{bb'}$ 与 $r_{b'e}$ 的合成：

$$r_{be} = r_{bb'} + (1+\beta)\frac{U_T}{I_{EQ}}$$

       * $r_{bb'}$ 是基区体电阻，一般在 $100 \sim 300\ \Omega$；基区掺杂浓度极低，这个体电阻不能忽略。

       * 集电区和发射区的体电阻非常小，一般情况下忽略不计。

       * 电容的一端要接在 $b'$ 上，$b'$ 找不到电容就加不上；把 $r_{be}$ 拆开，上面是 $r_{bb'}$，下面就是 $r_{b'e}$。

   * **第二步：往节点之间添电容**

       * $b'$ 到 $e$ 之间：除 $r_{b'e}$ 外再添一个电容 $C_{b'e}$，在这张图里叫 $C_\pi$。

       * $b'$ 到 $c$ 之间：添一个集电结电阻 $r_{b'c}$，再添一个电容 $C_{b'c}$，它叫 $C_\mu$。

       * $c$ 到 $e$ 之间：$h$ 参数里本来就带着 $r_{ce}$，这一块不动。

```text
          r_bb'         r_b'e   C_pi    g_m*U_b'e  r_b'c    C_mu
   b o +--/\/\/---+-------+-------+---------+--------+------||--+-o c
       |          |       |       |         |        |          |
       |          |       |       |         v        |          |
       |          |       |       |     ( dep. )     |          |
       |          |       |       |         |        |          |
       |          |     /\/\/     |         |        |          |
       |          |       |       |         |        |          |
       |          |     ----        |         |        |          |
       |          |       |       |         |        |          |
       |          |       |       |         |      /\/\/        |
       |          |       |       |         |        |          |
   e o +----------+-------+-------+---------+--------+---/\/\/--+-
```

   * **第三步：标电流方向与跨导**

       * 受控源与它的控制电路之间的电流方向必须标清楚，这是画模型的规矩。

       * 中间插入了 $b'$ 节点，原来那个 $I_b$ 已非彼 $I_b$，所以受控电流不能再写成 $\beta I_b$，控制量换成电压 $U_{b'e}$。

       * 受控电流为 $g_m U_{b'e}$，这里引入的新参数叫跨导 $g_m$，量纲是电导。

   * **模型里 $r_{ce}$ 的去留**

       * $r_{ce}$ 是非常大的电阻，几十千欧量级；在 $h$ 参数模型里通常干脆不画它，画了也没意义。

       * $\pi$ 模型里把它保留，因为接下来要用它说话。

## 外特性等效与物理模型等效

   * **两类等效模型**

       * > **定义**：外特性等效是在某些特定条件下才成立的等效，$h$ 参数就是从外特性出发推出来的一种。

       * > **提示**：$h$ 参数的使用条件是中频区域，或者更宽一点说是中低频区域。

       * $\pi$ 模型更接近物理模型的等效。

   * **π 模型通吃全频域**

       * > **结论**：物理模型的等效在任何区域都可以使用，所以 $\pi$ 模型从高频到低频都成立。

       * 在中低频段用 $h$ 参数和用 $\pi$ 模型分析同一个电路，结果一样：前者本来就是该电路在中低频段的等效，后者射程覆盖中低频。

       * 这条结论给出了钥匙：中低频两者等效，所以可以用 $h$ 参数去求 $\pi$ 模型的参数。

   * **把模型弄残就退回 $h$ 参数**

       * 中低频段 $C_\pi$ 和 $C_\mu$ 直接开路。

       * $r_{b'c}$ 是反偏的集电结电阻，锗管大约 $100\ \text{k}\Omega$、硅管大约 $500\ \text{k}\Omega$，并联在电路里几乎相当于断路，干掉。

       * $r_{b'c}$ 一干掉，$r_{ce}$ 也跟着显形，它几十千欧比后面的 $R_L$ 还大，也干掉。

       * 处理完之后图形恢复成 $h$ 参数模型，二者在中低频范围内起完全相同的作用。

## $C_\mu$ 的单向化

   * **单向化**

       * > **定义**：单向化就是一次戴维南等效——把 $b'$ 到 $c$ 这一整块（$C_\mu$ 与受控源那一支的耦合）扣一个黑盒子，再从两个端口各自往里看。

       * 从 $b'$ 端看进去等效出一个电容 $C_\mu'$；从 $c$ 端看进去等效出一个电容 $C_\mu''$。

       * 一旦这样等效，横接的 $C_\mu$ 就被劈成两个各自对 $e$ 的并联电容，各管各的，高通低通都能直接分析。

```text
              b'                        c
              o--------- C_mu ----------o
              |                         |
            C_mu'                     C_mu''
              |                         |
              o----------- e -----------o
```

   * **端口等效条件**

       * 换过去以后，端口上的电压 $U_{b'e}$ 和流过端口的电流 $I_{C\mu}$ 都必须保持不变。

       * 电压除以电流就是容抗：$X_{C\mu'} = \frac{U_{b'e}}{I_{C\mu}}$。

   * **三步算出 $C_\mu'$**

       * 第一步算流过 $C_\mu$ 的电流：

$$I_{C\mu} = \frac{U_{b'e} - U_{ce}}{-jX_{C\mu}} = j\omega C_\mu\left(U_{b'e} - U_{ce}\right)$$

       * 第二步消去消不掉的 $U_{ce}$，设 $K = \frac{U_{ce}}{U_{b'e}}$，它和电压放大倍数是相关的。

       * 第三步代回容抗：

$$X_{C\mu'} = \frac{1}{j\omega C_\mu(1 - K)} = \frac{1}{j\omega C_\mu'} \;\Longrightarrow\; C_\mu' = (1 - K)\,C_\mu$$

   * **$C_\mu'$ 的大小与去留**

       * > **易错点**：$C_\mu'$ 不是定死的常数，它是随电路状态变化的量；按 $U_{ce}$ 与 $U_{b'e}$ 比值的不同，在不同工作状态下表现出不同的值。

       * 一般情况下 $C_\mu'$ 比 $C_\mu$ 大，因为 $K$ 一般是负的（$U_{ce}$ 一般为负），于是 $1 - K > 1$。

       * $C_\mu''$ 的容抗非常大，比起 $R_L$ 可以忽略不计，直接被扔掉。

   * **简化后的形状**

       * 跨接的 $C_\mu$ 没有了，原来那个电容的位置上换成一个更大的等效电容：

$$C_\pi' = C_\pi + C_\mu'$$

```text
          r_bb'          C_pi'         g_m*U_b'e r_b'e
   b o +--/\/\/---+-------+-------+-------+-------+--------+-o c
       |          |       |       |       |       |        |
       |          |       |       |       v       |        |
       |          |       |       |   ( dep. )    |        |
       |          |       |       |       |       |        |
       |          |       |       |       |     /\/\/      |
       |          |       |       |       |       |        |
       |          |     ----      |       |       |        |
       |          |       |       |       |       |        |
   e o +----------+-------+-------+-------+-------+--------+-
```

## 模型参数的来路

   * **手册能查到的三个**

| 参数 | 手册上的对应 | 说明 |
| :--- | :--- | :--- |
| $r_{bb'}$ | $r_{bb'}$ | 基区体电阻，$100 \sim 300\ \Omega$ |
| $C_\mu$ | $C_{ob}$ | 输出电容，指的就是 $b$、$c$ 之间的这个电容 |
| $f_T$ | $f_T$ | 特征频率 |

   * **必须自己求的三个**

       * $$C_\pi, \qquad g_m, \qquad r_{b'e}$$

   * **$r_{b'e}$**

$$r_{b'e} = (1 + \beta_0)\frac{U_T}{I_{EQ}}$$

       * 它由静态工作点直接给出。

   * **$g_m$**

       * > **定义**：靠 $h$ 参数模型与 $\pi$ 参数模型在低频段等效这件事推出来。

       * 低频段里 $I_B$ 已由 $r_{b'e}$ 决定，于是 $I_C = g_m U_{b'e}$、$I_B = \dfrac{U_{b'e}}{r_{b'e}}$，两端电流串上了：

$$\frac{I_C}{I_B} = g_m \cdot r_{b'e} = \beta_0 \;\Longrightarrow\; g_m = \frac{\beta_0}{r_{b'e}}$$

       * 把 $r_{b'e}$ 代进去，在 $\beta_0$ 比较大时 $g_m \approx \dfrac{I_{EQ}}{U_T}$，也可以写成 $\dfrac{I_{EQ}}{U_T}$ 再乘 $\dfrac{\beta_0}{1+\beta_0}$。

       * > **提示**：最后那个表达式是什么其实无关紧要，不要去背；该记住的是怎么推出来——低频段两种模型等效，一推 $g_m = \beta_0/r_{b'e}$ 自己就掉出来了。

## β 的频率响应与 $f_T$

   * **β 为什么会成为向量**

       * > **定义**：$\dot\beta = \dfrac{\dot I_C}{\dot I_B}$，算它时 $U_{CE}$ 是常数，保持不变。

       * $U_{CE}$ 不变意味着 $c$ 与 $e$ 之间没有电压变化、没有交流含量，画交流通路时 $c$ 与 $e$ 之间相当于短路。

       * 因为 $C_\pi'$ 的存在，$I_B$ 由电阻电流和电容电流两个组成，与 $U_{b'e}$ 不再同相；而 $g_m U_{b'e}$ 那一支与 $U_{b'e}$ 同相。

       * 两者的比值随频率增长必然同时有大小变化和相位变化，所以 $\beta$ 必须是向量；低频段用不带向量的 $\beta_0$ 表示。

   * **传输函数与 $f_\beta$**

$$\dot\beta = \frac{g_m \dot U_{b'e}}{\dfrac{\dot U_{b'e}}{\dfrac{1}{r_{b'e}} + j\omega C_\pi'}} = \frac{g_m}{\dfrac{1}{r_{b'e}} + j\omega C_\pi'}$$

$$\dot\beta = \frac{g_m \cdot r_{b'e}}{1 + j\omega r_{b'e} C_\pi'} = \frac{\beta_0}{1 + j\omega r_{b'e} C_\pi'}$$

       * 上限截止频率：$f_\beta = \dfrac{1}{2\pi r_{b'e} C_\pi'}$。

       * 因为是直接耦合，低频段没有问题；从 $f_\beta$ 开始下降，相频特性每个十倍频程走 $45^\circ$，10 倍频和 0.1 倍频处就是 −3 dB 的那两个点。

       * 幅频特性的高度是 $20\lg \beta_0$。

   * **特征频率 $f_T$**

       * > **定义**：$f_T$ 是 $\beta$ 下降到 1 时的频率，在 $\beta$ 的幅频特性上就是一个过零点。

       * 由 $f = f_T$ 时 $\beta$ 约等于 1：模在 $\beta_0$ 远大于 1 时约等于 $\beta_0$，要把整个式子的模压到 1 就要求 $\dfrac{f}{f_\beta} \approx \beta_0$，于是

$$f_T = \beta_0 f_\beta$$

       * > **提示**：这一步不必跑到波特图上拉直线推，直接在代数式子里看就能出来。

       * 把 $f_\beta$ 带回来就能由 $f_T$ 反求 $C_\pi'$，这是手册给的 $f_T$ 唯一实际的用处。

### 由 $f_T$ 反推 $C_\pi$

   * **$K = 0$ 的来由**

       * $f_\beta$ 表明的是 $\beta$ 与频率的关系，而 $\beta$ 的定义前提是保持 $U_{CE}$ 不变，即动态 $u_{ce} = 0$。

       * 于是用 $f_T$ 反推时 $K = \dfrac{U_{ce}}{U_{b'e}} = 0$，$C_\mu' = C_\mu$：

$$C_\pi' = C_\pi + C_\mu' = C_\pi + C_\mu$$

       * 把手册上的 $C_{ob}$ 往里一带，$C_\pi$ 就可求了。

   * **高频段的 $C_\pi'$ 只能用中频值折算**

       * > **注意**：用 $f_T$ 反推出的那个 $C_\pi'$ 是中间过程，不是高频段分析要用的那个 $C_\pi'$，两个数不相等。

       * $C_\pi$ 与 $C_\mu$ 是固定值，$C_\pi'$ 是等效出来的，等效跟环境和条件相关；$C_\mu'$ 依赖 $K$，$K = \dfrac{u_{ce}}{u_{b'e}}$ 依赖工作点。

       * 真正算高频段时要用高频段的 $K = \dfrac{u_{ce}}{u_{b'e}}$，但真去求它非常困难，所以用中频段求出来的值去折算，是近似而非精确。

       * > **结论**：整个参数求解链是清晰的——先算直流，再用 $f_T$，最后用中频段的 $K$ 折算。

| 参数 | 来源 | 关键说明 |
| :--- | :--- | :--- |
| $I_{EQ}$ | 直流静态分析 | 一切动态参数的源头 |
| $r_{b'e}$、$g_{\text{m}}$ | 由 $I_{EQ}$ 得 | 两个都从直流来 |
| $C_{\pi}$ | 由 $f_T$ 反推 | 此步 $K = 0$，故 $C_{\mu}' = C_{\mu} = C_{ob}$ |
| $C_{\mu}'$、$C_{\pi}'$ | 由中频段的 $K$ 折算 | $K$ 取中频值，是近似而非精确 |

## 共基电路的频响

   * **电流放大倍数 α**

       * $\alpha = \dfrac{\beta}{1 + \beta}$，代入 $\dot\beta$ 的表达式可得：

$$\dot\alpha = \frac{\beta_0}{1 + \beta_0 + j\frac{f}{f_\beta}}$$

   * **上限截止频率 $f_\alpha$**

       * > **定义**：$f_\alpha$ 是 $\alpha$ 降为 $\dfrac{\alpha_0}{\sqrt2}$ 时的频率，即共基电流放大倍数的上限截止频率。

       * 分母要变成 1，等于上下同除一个 $1 + \beta_0$，原来的 $f_\beta$ 就变成 $f_\beta(1+\beta_0)$：

$$f_\alpha = f_\beta (1 + \beta_0)$$

       * > **结论**：共基电路的电流频率响应上限截止频率比共射大 $1 + \beta_0$ 倍，这就是它频响好的原因。

       * 代价在放大倍数上：电流放大倍数也减小了 $1 + \beta_0$ 倍，频带宽了、增益小了。

   * **迁移到场效应管**

       * 场效应管的高频等效模型思路与晶体管一样，它也有个 GS 电容，这电容同样要做单向化处理，整个分析方法一模一样。

## 单管共射放大电路的三频段分析

   * **分析路线是倒着推的**

       * > **结论**：解决工程问题时思路往往是倒推的——要获得这个结果，就必须先获得什么，最后连成一条技术路线。

       * 目标是幅频特性和相频特性，就必须要中频 $A_{usm}$、下限 $f_L$、上限 $f_H$；三者共用同一个全频域适用的基础，就是混合 $\pi$ 参数等效电路。

       * 参数里必须是 $C_\pi$ 而不是 $C_\pi'$，因为只有先定住 $C_\pi$ 才能在具体工作点下求 $C_\pi'$。

       * $g_m$ 与 $r_{b'e}$ 从直流来，$C_\pi$ 从 $f_T$ 来，$C_\mu'$ 从 $K$ 来。

```text
               目标：压放倍数 A_us + 相频特性
                              │
          │                   │                   │
          ▼                   ▼                   ▼
     中频 A_usm           下限 f_L            上限 f_H
    h 等效 → r_be      耦合电容 → 高通     高频电容 → 低通
                              │
                              ▼
               三者共用同一个全频域适用的基础
                              │
                              ▼
                     混合 π 参数等效电路
                              │
          │             │           │           │
          ▼             ▼           ▼           ▼
         g_m          r_b'e        C_π        C_μ'
          │             │           │           │
          └── ① 直流 I_EQ ─┘        │           │
                            ② 由 f_T 反推 C_π   │
                                    ▼           ▼
                       ③ 取中频 K = u_ce/u_b'e  │
                                    │           │
                                    └─────────────┘
                                             ▼
                    C_π' = C_π + C_μ'  →  放回高频段分析
```

   * **第一步：画出 π 模型**

       * 先画交流通路，再把里面的三极管拎出来做 $\pi$ 模型。

       * 先找到 $b$、$c$、$e$ 三点，然后凭空再给它生出一点 $b'$；$b$ 与 $b'$ 之间是 $r_{bb'}$，$b'$ 与 $e$ 之间是 $r_{b'e}$ 和 $C_\pi$，$c$ 与 $e$ 之间是受控电流源 $g_m \times U_{b'e}$。

       * $r_{b'e}$ 和 $g_m$ 由直流通路求出的 $I_{EQ}$ 得到，$C_\pi$ 由 $f_T$ 求。

```text
        b            b'                c
        ●────r_bb'───●                 ●
        │            │                 │
        │            ├───r_b'e───┤     │
        │            │                 │
        │            ├────C_π────┤     │
        │            │                 │
        │            └─[g_m U_b'e]──┤  │
        │                              │
        ───────────────────────────────●
                                       e
```

       * > **结论**：静态决定了动态；如果电路分析里没用到任何与静态相关的参数，那肯定错了。

       * 这个电路无论高频段、低频段还是中频段都用它。

### 中频段

   * **基准增益的定义**

       * > **定义**：$A_{usm} = \dfrac{U_o}{U_s}$，比的是信号源电压 $U_s$ 而不是 $U_i$，因为放的是电压型信号源。

$$A_{usm} = \frac{U_o}{U_i} \times \frac{U_i}{U_s}$$

   * **输入侧分压**

       * $\dfrac{U_i}{U_s} = \dfrac{R_i}{R_s + R_i}$，只要求出等效输入电阻 $R_i$。

   * **输出侧**

       * 两端共用 $U_{b'e}$，有载时：

$$U_i = \frac{r_{bb'} + r_{b'e}}{r_{b'e}} \cdot U_{b'e}, \qquad U_o = -g_m U_{b'e}\,(R_C \parallel R_L)$$

       * 不带负载时把 $R_L$ 去掉。

### 低频段与高频段

   * **低频段：加上耦合电容**

       * 对前端这一大堆电路作戴维南等效，$U_o'$ 就是空载电压，前端输出电阻就是 $R_C$，另一块是 $R_L$。

       * 从耦合电容两端看进去，电阻就是 $R_C$ 与 $R_L$ 串联：

$$f_L = \frac{1}{2\pi (R_C + R_L) C}$$

       * 相当于在中频基准上再乘一个低频因子：

$$A_{us}(\text{低频}) = A_{usm} \cdot \frac{j\frac{f}{f_L}}{1 + j\frac{f}{f_L}}$$

```text
   U_o' ──┬─── R_C ───┬──── R_L ─── 地
          │           │
          └───── C ───┘
```

   * **高频段：加上 $C_\pi'$**

       * 同样做戴维南等效，把前端等效掉做出一个低通：

$$f_H = \frac{1}{2\pi R C_\pi'}, \qquad R = r_{b'e} \parallel \left(r_{bb'} + (R_S \parallel R_B)\right)$$

       * 相当于在中频基准上再乘一个高频因子：

$$A_{us}(\text{高频}) = A_{usm} \cdot \frac{1}{1 + j\frac{f}{f_H}}$$

   * **三因子相乘**

$$A_{us} = A_{usm} \cdot \frac{j\frac{f}{f_L}}{1 + j\frac{f}{f_L}} \cdot \frac{1}{1 + j\frac{f}{f_H}}$$

       * 这边是 $f_L$，那边是 $f_H$，中间夹着中频段的水平段，波特图就出来了。

## 单管放大电路的波特图与相频特性

   * **幅频特性**

       * 中间那条水平线就是刚求出来的 $A_{usm}$；低频段以每十倍频 $+20$ dB 的斜率爬上来，交点是 $f_L$；高频段以每十倍频 $-20$ dB 落下去，交点是 $f_H$。

       * 整根线只缺 $f_L$ 与 $f_H$ 两个横坐标。

```text
A/dB
     ↑
A_m   ┤───────────────────────╭─────────────────────────────╮
      │ +20 dB/dec         ╱                                   ╲ −20 dB/dec
      │                 ╱                                         ╲
      │              ╱                                               ╲
      └───────────────────────┬─────────────────────────────┬──────────→ lg f
                             f_L                           f_H
```

   * **通频带**

       * > **定义**：$f_H - f_L$ 称为通频带。

       * 两个频率求出来之后，幅频特性和相频特性就定了：$10f_L$ 处是没有衰减的时候，$0.1f_L$ 倍处是衰减完毕。

   * **相频特性以 180° 为基准**

       * 高通造成 $0^\circ \sim +90^\circ$ 的相移，低通造成 $0^\circ \sim -90^\circ$ 的相移。

       * 这是共射放大电路，输出和输入差 $180^\circ$，所以整条相频曲线以 $180^\circ$ 为基准上下对称。

       * 相角从 $0^\circ$ 抬到 $180^\circ$ 的上升沿对应低频段耦合电容的影响，$180^\circ$ 平台是中频段，再往高频走相角落到 $90^\circ$ 并稳住，这就是共射电路高频段的最终相移。

```text
φ/°
     ↑
180   ┬─────────────────────────────────────╭───────────────────╮
      │                           ╱                                   ╲
      │                 ╱                                                   ╲────┘
      │              ╱                                                      ╲────┘───→ 90°
0     ┼              ╱──────────────────────────────────────────────────────────────────→ lg f
      └─────────────────┬─────────┬─────────┬───────────────────┬───────────┬────────────
                     0.1f_L      f_L      10f_L                f_H        10f_H
```

## 通频带的展宽方向与增益带宽积

   * **两个频率的方向**

       * 通频带越宽越好，意味着 $f_L$ 越小越好、$f_H$ 越大越好。

       * 低频耦合电容往里看进去的等效电阻越大越好；高频那边希望电阻越小越好。

       * 直接耦合把低频段的虚线拉平，是低频特性最好的做法。

   * **增益带宽积（gain-bandwidth product）**

       * > **定义**：$A_{usm} \times f_{BW} \approx \dfrac{1}{2\pi (r_{bb'} + R_S) C_{\mu}}$，其中 $C_{\mu}$ 就是手册上的 $C_{ob}$。

       * > **结论**：晶体管一旦选定，右边这些值就都定死了，这个积不再变；想把带宽拉宽，代价必然是中频放大倍数降低。

       * 共基电路带宽增大了 $1+\beta_0$ 倍，电流放大倍数就降低了 $1+\beta_0$ 倍，乘积是固定的，这不是偶然现象。

       * 提高的办法只有一个：把 $C_{ob}$ 选小，即用输出电容较小的管子。

       * > **易错点**：选元器件时参数比外观重要得多；只按外壳长相判断贵贱，恰恰是最容易吃亏的做法。

## 多级放大电路的叠加

   * **一个管子配两个耦合电容**

       * 整个放大电路只有一个晶体管却有两个耦合电容，相当于一级高通加一级低通。

       * > **结论**：高频段仍然是每十倍频 20 dB，低频段会出现每十倍频 40 dB，因为多了一级高通。

       * 用电压放大倍数算是乘法，在波特图里却是加法。

```text
A/dB
     ↑
A_m   ┤───────────────────────────╭───────────────────────────╮
      │ +40 dB/dec              ╱                                ╲ −20 dB/dec
      │                       ╱                                     ╲
      │                     ╱                                          ╲
      └───────────────────────────┬───────────────────────────┬──────────→ lg f
                                 f_L                         f_H
```

   * **斜率与级数**

       * 高频段出现每十倍频 40 dB 代表两级，出现 60 dB 代表三级。

       * 单级单管的高频段最大相移是 $-90^\circ$，两级是 $-180^\circ$，三级是 $-270^\circ$。

       * 相位角相加是因为向量相乘时幅值相乘、相位相加；取了对数之后幅频的相乘也变成相加。

| | 一级 | 两级 | 三级 |
| :--- | :--- | :--- | :--- |
| 高频段每十倍频下降 | 20 dB | 40 dB | 60 dB |
| 高频段最大相移 | $-90^\circ$ | $-180^\circ$ | $-270^\circ$ |
| 中频压放倍数 | $A_1$ | $A_1 A_2 = A_1^2$ | $A_1 A_2 A_3$ |
| 中频增益的 dB 值 | $20\lg A_1$ | $2 \times 20\lg A_1$ | $3 \times 20\lg A_1$ |

   * **总原则**

       * > **结论**：多级放大电路总的相移和总的增益，是各级放大电路相移与增益之和。

       * 电压放大倍数是各级之积、乘积，取对数后就变成和，两种说法是同一件事。

       * 有了这条原则，多级放大电路的分析就只剩一级一级算出来最后乘起来。

## 多级放大电路的截止频率

   * **截止频率的定义**

       * > **定义**：截止频率是放大倍数降为原来的 $\frac{1}{\sqrt{2}}$ 时所对应的频率，单级与多级都以此为准。

       * 多级必须把整体看成一个整体，而不是把各级的数据往上凑。

   * **硬凑会出什么问题**

       * 把两个单级的 $f_{L1}$、$f_{H1}$ 当成两级放大电路的截止频率，那一点对应的是下降 6 dB，而正常一个截止频率只该对应 3 dB。

       * 相移也翻倍：单级在截止频率上是 $45^\circ$，两级叠上去就是 $90^\circ$。

       * 真正的截止频率是总波特图上 3 dB 线所对应的那个频率。

```text
  单级1 的通频带：  [---------f_L1------------f_H1---------]
  单级2 的通频带：  [---------f_L2------------f_H2---------]
  两级总的通频带：  [-----------f_L----------f_H-----------]

  频率由低到高：   f_L1 < f_L < f_H < f_H1
                   （f_L 比任一单级的下限都高，f_H 比任一单级的上限都低）
```

   * **两级串起来的通频带比任何单级都窄**，下限往上抬、上限往下压，两边往中间缩。

### 由定义推出 $f_L$ 与 $f_H$

   * **低频段连乘**

$$A_u = \prod_{i=1}^{k} \frac{A_{umi}}{\sqrt{1 + \left(\dfrac{f_{Li}}{f}\right)^2}}$$

       * 让它降为中频值的 $\frac{1}{\sqrt2}$，连乘的根号整体等于 $\sqrt2$，两边平方并打开连乘：

$$\prod_{i=1}^{k}\left(1 + \left(\frac{f_{Li}}{f}\right)^2\right) = 2$$

   * **略去高次交叉项**

       * 展开后是 $1 + \sum\left(\frac{f_{Li}}{f}\right)^2$ 加上两两相乘的交叉项；两级时每一项都带 $\frac{1}{f^2}$，而 $f$ 又在下限截止频率那一带，量级很小，直接略掉：

$$1 + \sum_{i=1}^{k} \left(\frac{f_{Li}}{f}\right)^2 \approx 2$$

       * 于是 $\sum f_{Li}^2 / f^2 \approx 1$，把 $f$ 倒回去就是总的下限截止频率：

$$f_L \approx \sqrt{\sum_{i=1}^{k} f_{Li}^2}$$

   * **修正系数**

       * > **提示**：略去高次项会带来偏差，所以要加修正系数，$f_L$ 这一侧为

$$f_L = 1.1 \sqrt{\sum_{i=1}^{k} f_{Li}^2}$$

       * $f_H$ 那一侧同样带一个修正系数，这里只给概念，数值关系记着就行。

   * **高频段方向反过来**

$$\frac{1}{f_H^2} \approx \sum_{i=1}^{k} \frac{1}{f_{Hi}^2}$$

### 平方和给出的三层结论

   * **定性**

       * 级数越多 $f_L$ 越大往右移、$f_H$ 越小往左移，即级数越多通频带越窄。

   * **权重**

       * 公式是平方和，某一个 $f_{Li}$ 只要遥遥领先于其他所有级，它就是权重最大的那一个。

       * 例：两级一个 $f_{L1}$ 是 100、另一个 $f_{L2}$ 是 5，$\sqrt{100^2 + 5^2} = \sqrt{10025} \approx 100$，5 那一个几乎没进账。

       * > **结论**：工程估算里千万别一档一档去调；一眼扫过去找出权重最大的那一级，先消灭它、先调整它，整个电路的面貌就改了。

       * $f_H$ 完全同理，要随时清楚哪个 $f_{Hi}$ 决定性最大。

   * **回到电路**

       * 对下限截止频率影响最大的耦合电容，必然是时间常数 $RC$ 乘起来最小的那一个，它最先滚下坡把下限拖上来。

       * 对上限截止频率影响最大的，必然是 $RC$ 乘起来最大的那一个。

## 从分立元件到集成运放

   * **能集成才是革命**

       * 半导体材料取代电子管不是关键，关键是它可以集成；电子管没法集成，封装起来就这么大，十个封装起来还是那么大。

       * 一旦能集成，上亿个元器件可以堆在一块芯片上，片子也不过那么大点。

   * **集成运放的定位**

       * > **注意**：这一章的重点不是运放怎么用，而是它的电路是什么；它是介于集成器件和分立器件之间的东西，用分立器件的原理去构造集成器件。

       * 输入信号是 $u_P - u_N$ 这个差模信号，说明它的输入端肯定是差分放大电路。

   * **本质是集成的、高增益的放大器**

$$u_O = A_{od}\,(u_P - u_N) \qquad (\text{线性区内})$$

       * > **定义**：传输特性中间那条线性区非常窄，电源正负 15 V、输出到十几伏时，$A_{od} = 10^6$ 对应的 $u_P - u_N$ 只能在正负十几微伏之间游走。

       * 十几微伏什么概念——一个电路往那儿一摆、什么都不动，两个输入端就会感应出十几微伏的差；把两个电压做得只差十几微伏，在看来就可以认为它们相等了。

       * 两端是饱和区，内部是晶体管或场效应管做的，输出电压高不过 $V_{CC}$、$V_{DD}$。

       * > **易错点**：高增益运放通上电就是饱和的，除非把它做成闭环；神奇的功能全都是闭环挣来的。

       * 同相端与反相端的命名：$u_N = 0$ 时 $u_O$ 与 $u_P$ 同相，$u_P = 0$ 时 $u_O$ 与 $u_N$ 反相，一个起正的作用一个起负的作用。

   * **运放电路的骨架**

       * 输入级是差放，中间级是主要实现电压放大的（用共射），输出级是互补对称那一套，中间配一个偏置电路提供各级静态电流。

       * 集成带来的硬约束：阻容耦合用不了，因为耦合电容没法集成；中间级希望 $R_C$ 尽可能大，但毫安级电流配十兆欧电阻所需电压高得离谱。

       * > **结论**：电阻要大、电压还不能高，办法是电流源——它既提供 $I_C$，动态内阻又非常大。

### 电流源

   * **两大作用**

| 作用 | 说明 |
| :--- | :--- |
| 当电源用 | 提供电路所需要的静态电流 |
| 当负载用 | 取代 $R_C$，甚至取代 $R_E$——长尾式差分放大电路尾巴上挂的就是一个恒流源 |

   * **镜像电流源**

       * > **定义**：用两个特性一模一样的对管构成的电流源；因为 $U_{BE1}$ 与 $U_{BE0}$ 绝对相等，$I_B$ 相等、$\beta$ 一样则 $I_C$ 也相等，"镜像"由此得名。

```text
  V_CC ──[R]──●──┬──(T0 的 C 与 B 短接，E 接地)
                 │
                 └──(T1 的 B)
                      T1 的 E 接地
                      T1 的 C ──► I_C1（电流源输出端）
```

       * $I_{C1}$ 这一支只画输出端，哪块电路需要这个电流源就把这个端接上去，那边会自己提供直流电压；用在长尾式差放时它就接在 $R_E$ 那一块。

       * 调节 $I_{C1}$ 的基准是参考电流 $I_R$。对参考支路用基尔霍夫电流定律：

$$I_R = I_{C1} + 2I_B = \frac{\beta + 2}{\beta} \times I_{C1}$$

       * $\beta \gg 2$ 时 $\dfrac{\beta+2}{\beta}$ 几乎就是 1，故 $I_R \approx I_{C1}$；而 $I_R$ 由电阻决定：

$$I_R = \frac{V_{CC} - U_{BE0}}{R}$$

       * 所以调 $R$ 的大小就能控制 $I_{C1}$，电流必须可控、必须可调才能真正用好它。

       * 在镜像的基础上还能派生出比例电流源和微电流源。
