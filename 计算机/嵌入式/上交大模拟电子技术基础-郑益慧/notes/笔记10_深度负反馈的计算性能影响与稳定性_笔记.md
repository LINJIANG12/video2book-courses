# 深度负反馈的计算、性能影响与稳定性

## 深度负反馈的实质

* **深度负反馈（deep negative feedback）**

    * > **定义**：在开环增益 $A$ 足够大的条件下，净输入量可以被忽略，闭环放大倍数就直接等于反馈系数的倒数。

    * 核心结论是 $A_f \approx \frac{1}{F}$。

    * 这一句话把求解方案彻底换掉了：以前要列联立方程组把 $A$、$F$ 一起拉进去磨，现在只需求出 $F$，别的都可以先撂下。

    * 深度负反馈的实质就是忽略了净输入量。

    * 把 $A$ 约掉得到 $\frac{1}{F}$ 这件事反过来说，就是 $A$ 变化 10%、变化 20% 对整个电路没有影响，开环增益自己的动荡不会再引起闭环增益的动荡。

* **反馈网络（feedback network）**

    * > **定义**：体现反馈量和输出量之间关系的那个网络。

    * 之所以非要把反馈网络从电路里揪出来，唯一的目的就是求 $F$；$F$ 一到手 $A_f$ 就白送。

    * 反馈量的定义：仅仅是输出量的函数，也就是在输出量单独作用下所产生的反馈量。

## 用虚短走另一条路

* **虚短（virtual short circuit）**

    * 忽略净输入量 $U_i'$ 相当于 $U_p = U_n$，这就是从实质出发的分析。

    * 由 $U_p = U_i$ 推出 $U_n = U_i$；再由输入端电流为零的虚断，得到 $U_n$ 与 $U_o$ 之间的比例关系。

    * 用虚短推出的结果与先求 $F$ 再取倒数的结果完全相同。

    * > **结论**：两条路殊途同归，因为出发点是同一个——深度负反馈与虚短都在讲忽略净输入量，最基本的理论相同，结果不可能不一样。

## 深度负反馈的求解步骤

* **求解四步**

    * 第一步 判别组态，找到反馈网络；组态一定，反馈网络自然就找出来了。

    * 第二步 求 $F$，也就是反馈系数。

    * 第三步 求 $A_f$；在深度负反馈条件下这一步已经不能称之为一步，$A_f$ 无非就是 $\frac{1}{F}$。

    * 第四步 把 $A_f$ 换算成习惯的电压放大倍数 $A_{uuf}$。

    * 前两步是真正的功夫活，后两步几乎是白捡的。

    * 最终的闭环放大系数和 $A$ 无关、和环路增益无关、也和三极管无关，全部由电阻决定。

    * $A$ 与 $F$ 唯一要做的事情就是齐心合力把 $A$ 弄大，$A$ 弄大之后它们就功成身退。

    * 用不用做小信号等效完全取决于有没有负反馈概念：差分放大后面再加一级共射（第二级是静态工作点稳定的共射、输出从集电极取出）的电路，不加负反馈时要算第二级输入电阻当第一级负载、画 $h$ 参数等效，非常难求；加了深度负反馈就变成最基础的电路分析。

## 组态判别

* **置零判据**

    * > **提示**：判断电压取样还是电流取样最省事的办法，是把输出交流置零（短路输出端）。

    * 反馈信号跟着一起消失的，是电压取样。

    * 反馈信号仍然赖着不走的，是电流取样。

    * 两个级联三极管的电流并联例子中，把下一级的 $U_o$ 置零后，$T_2$ 的电流依然存在，$T_2$ 电流存在则发射极上的负依然存在，所以判为电流取样。

* **极性判别**

    * 输入端瞬时正、电流向下，反馈必然是负反馈；先判正负再判电压取样还是电流取样。

    * 反馈的正负号一旦搞错，负反馈会瞬间变成正反馈，系统不是变稳，而是变疯。

## 电压串联负反馈的计算

* **反馈系数**

    * 取样量是输出电压，反馈量取自电阻分压网络中 $R_1$ 上的压降。

    * $$F_{uu} = \frac{U_f}{U_o} = \frac{R_1}{R_1 + R_2}$$

    * > **易错点**：取反馈信号的那个节点是断开的，不能当成通路去分压；多级放大电路里引入这样的电压反馈，反馈电流照样会往上一级串。

* **闭环增益**

    * $$A_{uuf} = \frac{R_1 + R_2}{R_1} = \frac{U_o}{U_i}$$

    * 这个式子等价于 $U_o = \frac{R_1+R_2}{R_1}U_i$，即输出对输入实现了一个比例放大，运算是 $y = kx$，且 $k$ 大于 0、大于 1。

    * 电压串联最友好，因为它一反就是 $A_{uuf}$。

* **静态工作点稳定的共射电路**

    * 把输出交流置零后反馈信号消失，所以是电压取样；输入端正、正且电流向下，是负反馈，判为电压串联。

    * $$F_{uu} = \frac{R_2}{R_2 + R_4}$$

    * $$A_{uuf} = \frac{R_2 + R_4}{R_2} = 1 + \frac{R_4}{R_2}$$

    * 熟练之后几乎一眼就能看出最终结果，复杂电路塌缩成两个电阻之比。

## 电流串联负反馈的计算

* **反馈系数**

    * $U_f$ 取自采样电阻 $R$ 上的压降，不是取自 $U_o$。

    * > **易错点**：$U_o$ 是输出管那一块的电压，$U_f$ 是采样电阻 $R$ 上的压降，是两个不同的东西，不能因为都跟输出有关就当成一回事。

    * 反馈网络就是一只采样电阻：$F = \frac{U_f}{I_o}$。

    * 该处为虚断，电流畅通无阻流过采样电阻，所以 $F = R$。

* **闭环增益**

    * $$A_{iuf} = \frac{I_o}{U_i} = \frac{1}{R}$$

    * 由此得到的运算关系是 $I_o = \frac{U_i}{R}$，把一个电压转换成电流。

    * 换回电压放大倍数：$A_{uuf} = \frac{U_o}{U_i} = \frac{R_L}{R}$，即 $U_o = \frac{R_L}{R}U_i$。

    * 用虚短复算：$U_p = U_n$、$U_p = U_i$ 得 $U_n = U_i$，于是 $U_f = U_i$，立刻得到 $I_o = \frac{U_i}{R}$。

### 它到底是电压源还是电流源

* **电压源型输出电阻的判据**

    * 电压负反馈稳定的是输出电压，让输出电压更近似一个电压源；电流负反馈稳定的是输出电流，让输出电流更近似一个电流源。

    * 两种组态推出的都是 $U_o$ 与 $U_i$ 的比例关系，但电压源的 $U_o$ 与负载 $R_L$ 无关，电流源的 $I_o$ 与负载无关。

    * 电流串联中 $I_o$ 与 $R_L$ 一点关系都没有，$I_o$ 才是真正的电流源；而 $U_o$ 因为等于 $I_oR_L$ 而随 $R_L$ 变化。

    * 负反馈把放大电路的输出关系函数化了，用公式而不是印象就能判断它像什么源。

## 电压并联负反馈的计算

* **反馈系数**

    * $$F = \frac{I_f}{U_o}$$

    * 把净输入电流 $I_i'$ 置零后，这两端的压降为零，相当于接地点，反馈电流只由 $U_o$ 决定。

    * $$I_f = -\frac{U_o}{R_F}$$

    * $$A_{uif} = \frac{U_o}{I_i} = -R_F$

* **换算成源电压增益**

    * 前端接的是 $R_s$，天然是电流源型信号源，要求电压放大倍数就得先做源电压、源电流等效互换。

    * 深度负反馈下 $I_i'$ 为零，两端压降为零，故 $U_s = I_iR_s$。

    * $$A_{usf} = \frac{U_o}{U_s} = -\frac{R_F}{R_s}$$

    * > **结论**：电流源和电压源可以等效互换，没有理想的电流源也没有理想的电压源；$R_s$ 稍大一点可以看成电流源，$R_s$ 稍小一点就看成电压型信号源。

## 电流并联负反馈的计算

* **反馈系数**

    * $$F_{ii} = \frac{I_f}{I_o}$$

    * 图中没标出 $I_o$，需要自己设一个参考电流 $I_o$，再按 $I_o$ 单独作用、前端接地来算 $I_f$。

    * > **易错点**：必须先把 $I_o$ 设出来。设在这里是允许的，只不过折算回去时要一路折算上去，比较麻烦；先在这里算最省事。

    * $I_o$ 单独作用时前端的影响去掉、相当于接地，两个电阻并联后对 $I_o$ 分流。

    * $$F_{ii} = \frac{I_f}{I_o} = \frac{R_{e2}}{R_{e2} + R_f}$$

* **两级 PNP 联袂电路的极性判别**

    * 输入端一个正进去，第一级的向下瞬时电流使第一级集电极输出为负；第二级是 PNP 管，基极为负产生向下电流，使发射极也为负。

    * 这个负引回到同一个端子上，反馈量与输入量并联，故为并联负反馈。

* **闭环增益**

    * 输出电压 $U_o = I_o(R_{c2} \parallel R_L)$，源电压 $U_s = I_fR_s$。

    * 由 $I_f = \frac{R_{e2}}{R_{e2}+R_f}I_o$ 反解得 $I_o = I_f\left(1 + \frac{R_f}{R_{e2}}\right)$。

    * $$A_{usf} = \frac{U_o}{U_s} = \left(1 + \frac{R_f}{R_{e2}}\right)\cdot\frac{R_{c2} \parallel R_L}{R_s}$$

## 虚短分析 T 型反馈网络

* **T 型网络的走法**

    * 求 $I_i$ 时先找能确定的量：$U_p = U_n = 0$，因为这里找不到 $U_i$。

    * 有虚断则 $I_i = I_f$。

    * 输出电流 $I_o = \frac{U_o}{R_L}$ 在 $I_f$ 支路与 $R_2$ 上分流，$R_1$、$R_2$ 相当于并联。

    * $$I_f = -\frac{R_2}{R_1 + R_2}I_o$$

    * 负号来自方向相反：$I_o$ 向下、$I_f$ 与之反向。

## 实际电路试刀：两级差放加共射

* **两级差放加共射的电流串联**

    * 输入端正、正且电流向下，是负反馈；把输出交流置零后电流依然存在、取样还在，所以判为电流串联。

    * $U_f$ 与 $I_o$ 之间用两步算：先分流，再乘 $R_1$。

    * $$F_{ui} = \frac{R_3}{R_1 + R_2 + R_3}\cdot R_1$$

    * $$A_{iuf} = \frac{R_1 + R_2 + R_3}{R_1R_3}$$

    * 要电压放大倍数时再乘 $R_L$：$A_{uuf} = \frac{I_o}{U_i}R_L$。

    * 看似复杂的问题三下两下就出来，用的全是电路分析。

## 负反馈对性能的影响总表

* **反馈深度（feedback depth）**

    * > **定义**：$1+AF$，其中 $AF$ 是环路放大倍数。

    * 负反馈带来的全部性能影响都挂在同一个量 $1+AF$ 上，不是 $AF$，也不是单独的 $A$ 或 $F$。

    * | 性能 | 无反馈时 | 加负反馈后 |
    | :--- | :--- | :--- |
    | 放大倍数 | $A$ | $\dfrac{A}{1+AF}$，降为原来的 $\dfrac{1}{1+AF}$ |
    | 稳定度（相对变化率） | $\dfrac{dA}{A}$ | 改善 $1+AF$ 倍 |
    | 上限截止频率 | $f_H$ | $f_{Hf}=(1+AF)f_H$，展宽 $1+AF$ 倍 |
    | 输入电阻 | $R_i$ | 串联 $(1+AF)R_i$；并联 $\dfrac{R_i}{1+AF}$ |
    | 输出电阻 | $R_o$ | 电压反馈 $\dfrac{R_o}{1+AF}$；电流反馈 $(1+AF)R_o$ |
    | 非线性失真 | 由 $A$ 自己决定 | 闭环可削弱 |

## 稳定度

* **相对变化率的推导**

    * 分析这类问题先定性、再定量，定性在前就不会出方向性错误。

    * 中频段闭环放大倍数为 $A_f = \frac{A}{1+AF}$。

    * $\Delta A$ 与 $\Delta A_f$ 基数不同，不能直接比，只有相对变化率比出来才谈得上稳定度。

    * 对 $A_f$ 求微分：$dA_f = \frac{(1+AF)dA - AF\,dA}{(1+AF)^2}$。

    * 两边同除各自的基数并把 $A$、$1+AF$ 消掉：$\frac{dA_f}{A_f} = \frac{1}{1+AF}\cdot\frac{dA}{A}$。

* **稳定度的结论**

    * 闭环放大倍数的相对变化是开环相对变化的 $\frac{1}{1+AF}$，即稳定度提高了 $1+AF$ 倍。

    * 反馈深度为 1 万倍时，开环 $A$ 变化 20%，闭环稳定后变化率是十万分之二。

    * > **易错点**：稳定度提升从来不是免费的。反馈深度做到 1 万倍，代价就是放大倍数同时降为原来的 $\frac{1}{1+AF}$。

## 输入电阻

* **串联负反馈增大输入电阻**

    * 抓住端口等效定义 $R_{if} = \frac{U_i}{I_i}$，把分子分母都表达出来。

    * 串联时 $U_i = U_i' + U_f$，且 $U_f = AF\cdot U_i'$，其中 $AF$ 是环路放大倍数，把中间那一段环路整个绕了回去。

    * $$R_{if}=\frac{U_i'+AF U_i'}{I_i}=(1+AF)\frac{U_i'}{I_i}=(1+AF)R_i$$

* **并联负反馈减小输入电阻**

    * 并联时反馈电流并到输入节点，$U_i$ 不变，而 $I_i = (1+AF)I_i'$。

    * $$R_{if}=\frac{U_i}{(1+AF)I_i'}=\frac{1}{1+AF}R_i$$

* **输入电阻变化的量级**

    * 原输入电阻只有 $3\,\text{k}\Omega$ 时，引入反馈深度 100 倍的串联负反馈后闭环输入电阻变成 303 倍、约 $303\,\text{k}\Omega$，大体就是 $300\,\text{k}\Omega$。

    * 同样条件下并联负反馈让输入电阻掉到 $30\,\Omega$ 左右。

    * 串联负反馈就是拼命把输入电阻往上撑，让信号源分到的电压多、源轻松；并联负反馈就是给信号源一个小输入电阻，减轻它的压力。

* **偏置电阻的归属**

    * 多级放大电路前面常挂偏置电阻 $R_b$，必须看清反馈环是从哪儿开始绕的。

    * 反馈环若绕在 $R_b$ 之后，$1+AF$ 这个倍数与 $R_b$ 毫无关系，$R_b$ 不属于 $R_i$。

    * > **易错点**：从输入端口整体看进去，$R_b$ 与闭环输入电阻 $R_{if}$ 是并联关系；这个并联是端口概念，从定义出发就能推出，与 $(1+AF)R_i$ 不冲突。

## 输出电阻

* **求输出电阻的置零对象**

    * 算输出电阻要把独立源置零，求 $R_{of}$ 时置零的不是输出电压而是输入信号源。

    * 输入源置零后 $U_i'$ 不再是外加激励，而等于反馈信号取负：$U_i' = -U_f = -F U_o$。

    * 把前端做戴维南等效，等效成一个电压源加一个 $R_o$，输入支路里的信号源消失，只剩一条从 $U_o$ 出发绕一圈回到 $U_o$ 的环路。

* **反馈网络的负载效应**

    * 反馈网络接在输出端，它本身就是输出的一路负载；老实分析就要连反馈网络一起求出基本放大电路，这套方法在本课程里不展开。

    * 采用的处理办法是：把反馈网络视作内阻无穷大，只取电压、不取电流，负载效应就被规避掉，模型才干净。

    * 戴维南等效给出的那个 $R_o$，按已经包含负载效应的说法来对待。

* **电压负反馈减小输出电阻**

    * 从环路直接写出 $U_o = -AFU_o + R_oI_o$，其中输出电压等于 $-AFU_o$ 与 $R_oI_o$ 两个电压相加。

    * $$R_{of}=\frac{U_o}{I_o}=\frac{R_o}{1+AF}$$

    * 输出电阻原本 $3\,\text{k}\Omega$ 的电路，加反馈深度 1000 倍的电压负反馈后输出电阻变成 $3\,\Omega$；集成运放输出电阻本来就小，再加一道电压负反馈就更像电压源。

* **电流负反馈增大输出电阻**

    * 电流负反馈与电压负反馈完全对称：$R_{of} = (1+AF)R_o$。

    * 想当电流源输出电阻就得大，这个结果符合直觉。

* **手性的定性判断**

    * 电压负反馈要把放大电路当电压源用，电压源输出电阻很小，所以电压负反馈让输出电阻变小。

    * 电流负反馈要把放大电路当电流源用，电流源输出电阻很大，所以电流负反馈让输出电阻变大。

## 带宽

* **上限频率的展宽**

    * 直接耦合放大电路只有高频段展宽这一说，把开环增益换成 $A_H$、上限截止频率记成 $f_H$，这是低通电路的高频响应。

    * $$A_{Hf}=\frac{A_H}{1+A_HF}$$

    * 解得闭环的上限截止频率 $f_{Hf} = (1+AF)f_H$，即展宽了 $1+AF$ 倍。

    * > **结论**：这一条不用死记，它是放大倍数下降的推论——增益带宽积这个定值还在，想带宽就拿增益换，一分不给。

* **代价清单**

    * | 你想要的 | 代价 |
    | :--- | :--- |
    | 稳定度提高 $1+AF$ 倍 | 放大倍数降为 $\frac{1}{1+AF}$ |
    | 带宽展宽 $1+AF$ 倍 | 放大倍数降为 $\frac{1}{1+AF}$ |
    | 输入电阻变大（串联） | 输出电阻变小（电压反馈） |

## 非线性失真

* **失真的成因**

    * 晶体管输入特性在静态工作点上下并不对称，上半周斜率大、下半周斜率小，同样的 $\Delta u_{BE}$ 上半周 $i_B$ 涨得多。

    * 说"变化很小"的前提是只在静态工作点附近取一小段、这一小段近似线性；信号一大，$u_{BE}$ 变化范围变大，整段跨到明显非线性区域，映射非线性则输出非线性。

    * 开环系统遇到这种情况只能认了。

* **闭环如何把歪的掰回来**

    * 晶体管真正的输入端子是 B 和 E，从电压角度看净输入量就是 $u_{BE}$，反馈只要对 $u_{BE}$ 产生影响就能解决问题。

    * 既然 $A$ 对上半部分放大能力强、对下半部分弱，就在输入端预先加一个反向变形的信号：上面给小一点、下面给大一点，与原信号叠加后把 $A$ 自身带来的畸变抵消掉。

    * 这种大小分布不均会减小 $i_B$ 大小分布的不均。

    * > **注意**：不可能全部消掉，但会大大削弱。

    * > **提示**：此时净输入量已经被压小，要达到同样的净输入量，输入信号的能量就必须加大；减小失真的手段是对输入信号能量有要求的，不是白拿的。

* **负反馈不能纠正的失真**

    * > **易错点**：负反馈能减小的是放大电路自身进入饱和区或非线性区所引起的失真，绝不是指"前端输入一个畸变波形、输出一个不畸变波形"。

    * 前一种情况是救场，后一种情况是捣乱。

    * 输入本身就是"头大身小"的失真波形时，系统认为它本来就是正确的；把它纠正过来说明系统自己畸变了。

    * 放大就是进来什么出去就是什么，不能电梯进去一个老太太、开门出来一个美女。

## 按需求设计电路的一般原则

* **从照着分析到按需求设计**

    * 以前是老师摆出电路去分析、去算、去验证，现在是有需求了由你来搭电路。

    * 电压型传感器要传得远，就得把电压型变成电流型，因为电流信号在长线传输时比电压信号抗干扰能力强得多，应该加电流串联负反馈。

    * 要稳定放大电路的静态工作点，针对性答案是加直流负反馈；深度负反馈当然不算错，但静态工作点是直流量，要稳的是直流量，对交流量恰恰希望放得开，不要因为稳直流把交流也压死。

    * 信号源是电流型信号源时应引入并联负反馈，与电流不电流无关，与后面是电流并联还是电压并联也无关；因为要解决的是"从哪取信号"，反馈信号取回来以后并到输入端还是串到输入端由取样位置决定。

    * 信号源是电流型、又要求后端有好的带负载能力（以电压源面貌输出）时，应加电压并联负反馈；"并联电压负反馈"与"电压并联负反馈"是同一个东西。

    * 两种门电路之间有电位差需要电平转换时，接口电路属于能设计出来的范围。

### NPN 与 PNP 的 h 参数

* **导电极性的等效性**

    * 不考虑其他问题时画 $h$ 参数等效电路，NPN 管与 PNP 管是一模一样的。

    * 两者的直流偏置不同，但放大状态下不都是发射结正偏、集电结反偏吗；不指定电位高低、只说 PN 结的正偏反偏，它们是一样的。

    * $h$ 参数等效电路一样，无外乎受控源那两个反一个方向。

## 两级放大电路的反馈拼图

* **题目结构**

    * 第一级是差放，第二级是共射放大电路（射极在上面），图上标出各接线端子，另有一根待接入的电阻 $R_F$ 和几根待连的导线。

    * 按三条不同设计指标分别接线，难度不在题目而在把线路接对。

* **减小取源电流并增强带负载能力**

    * "减小从信号源所取的电流"就是输入电阻要大，断路后一点电流都不从源索取；"增强带负载能力"就是以电压源面貌输出。

    * 对应电压串联负反馈。

    * 电压反馈的取样点应取自输出电压——输出电压一旦置零反馈点就为零，这是最有效的保障；$R_F$ 一端接 3（输入信号所在端子），另一端接 8（只有接在 8 上，前端接地后反馈信号才真的消失）。

    * 剩下几根线里，第一级与第二级之间的联系作用不小，连错就变成正反馈；倒着推极性：输入瞬时正、回来也要正，要让该处为正就得电流向下，于是 6 为负；4 和 5 中输出负的是 4，所以 4 接 6。

    * 接法：9 接 3，10 接 8，4 接 6，$R_F$ 接在 3 与 8 之间。

* **输入电流转换成稳定线性关系的输出电流**

    * "稳定线性关系"就是要求闭环放大倍数稳定，从电流变电流对应电流并联负反馈。

    * 既然是电流反馈，10 就不能接 8，改接 7；$R_F$ 接在 7 与 2 之间。

    * 极性复核：1 进去瞬时正，2 回来要瞬时负，要 7 为负就得电流向下，于是 6 为瞬时负，仍然是 4 接 6。

* **输入电流转换成稳定输出电压**

    * 对应电压并联负反馈，$R_F$ 接在 2 与 8 之间。

    * 2 要求是负，那 8 就要求是负；8 变负则电流向上，6 就是正，因此改由 5 接 6。

* **判据归纳**

    * | 要求 | 反馈组态 | 接法 |
    | :--- | :--- | :--- |
    | 少取电流 + 增强带负载能力 | 电压串联负反馈 | 9 接 3，10 接 8，4 接 6，$R_F$ 接在 3 与 8 之间 |
    | 输入电流 → 稳定线性输出电流 | 电流并联负反馈 | 10 改接 7，7 接 2，$R_F$ 接在 7 与 2 之间，4 仍接 6 |
    | 输入电流 → 稳定输出电压 | 电压并联负反馈 | $R_F$ 接在 2 与 8 之间，5 接 6 |

    * 4 接 6 还是 5 接 6，靠倒着推极性逐点验证：正输入进去，算到第一级哪个输出是负，再把它接到第二级的哪个端子上，反馈回来才是负的。

    * 差放的两个端子是对抗的：1 增加时这边电流增加、那边电流往上增加；3 增加时它让这边也加一个增加的电流去对抗那边的增加，两者增加方向正好相反。

    * > **易错点**：不要把"什么都认为可以忽略"当成习惯，什么都可以忽略正是最容易出事的地方。

## 自激振荡的成因

* **自激振荡（self-oscillation）**

    * > **定义**：自己给自己激励、自己振荡着玩，不需要外界信号。

    * 典型现象是没加负反馈时电路正常，一加负反馈就上电即饱和、一充电就饱和。

    * 中频段的负反馈关系是 $X_i' = X_i - X_f$，其中 $X_f = A\cdot F\cdot X_o$；中频段时相移近似为零，这个关系成立。

    * 但电路工作在高频区域时，$A$ 和 $F$ 不可能像中频段那样没有相移。

* **相移的来源**

    * 高频段每多一个三极管就多一级低通电路的相移，只要有一个三极管就有一级。

    * 低频段的级数与三极管数量无关，取决于耦合电容的个数：一级放大电路挂三个耦合电容，低频段就相当于三级高通电路；四个三极管只有一个耦合电容，低频段就只有一级。

    * 直接耦合放大电路没有耦合电容，有几级放大电路、几个三极管就有几级高频段响应。

    * 设 $\dot{A}$ 的相移为 $\varphi_A$、$\dot{F}$ 的相移为 $\varphi_F$，中频段 $\varphi_A + \varphi_F = 0^\circ$；当某个频率 $f$ 使 $\varphi_A + \varphi_F = 180^\circ$ 时，这个频率上就变成了正反馈。

    * > **提示**：输入信号 $\dot{X}_i$ 是外加信号、根本没有在放大电路里走，不受相移影响，只有反馈信号受影响。

    * > **注意**：正反馈还不等于自激振荡，自激振荡还要满足幅值条件。

## 起振条件与平衡条件

* **相位条件**

    * 存在某一个频率，使得 $\varphi_A + \varphi_F = 180^\circ$。

* **幅值条件**

    * 该频率下 $|AF| \geq 1$；起振要 $>1$，平衡时 $=1$。

    * $|AF|=1$ 时危害不大，转一圈回来还是原样，既不再大也不再小，处于平衡。

    * $|AF|<1$ 时转一圈小一圈，迅速衰减，振荡停止。

    * $|AF|>1$ 时飞快发散：取 $|AF|=2$，转一圈从 1 变 2，再转一圈从 2 变 4；$1\,\text{K}=2^{10}$、$1\,\text{G}=2^{30}$，让信号转 30 圈在模拟电路里是纳秒级的事，按上音量的一瞬间就叫起来。

* **平衡条件的写法**

    * 两条合起来写成 $AF = -1$。

    * > **注意**：这个条件强调的是**在某一个频率下**，不是所有频率。

    * 扩音设备的啸叫是纯正反馈过程，发生在中频段；而自激振荡是在某一个频率段突然出现，对某一个频率相位正好移了 180 度，且该频率对应的 $|AF| \geq 1$。

* **出事的概率**

    * 只要电路里存在这样的频率，出事概率几乎是 100%；合上电源时电路板里就已经有了那个频率。

    * 任意输入信号做傅里叶变换，想要什么频率就有什么频率，只是在你的频段里非常微小、连微伏都不到；微伏到 $1\,\text{G}$ 差了一兆倍，转 30 圈就放大完了，而放大到 15 V 就已经饱和，用不着 30 圈。

    * 所以设计电路时必须知道它在什么时候会产生自激振荡、有没有这个风险。

## 稳定性判据

* **幅频特性与相频特性**

    * 判断放大电路稳定性最好的着手点是幅频特性和相频特性。

    * 横轴是频率，纵轴是 $20\lg|AF|$；$f_c$ 是幅频特性过 0 dB 的点，$f_0$ 是相频特性上相位恰好到达 $-180^\circ$ 的频率。

    * $f_0$ 落在 $f_c$ 左边：相位已经转过 180 度时环路增益还大于 1，会自激。

    * $f_0$ 落在 $f_c$ 右边：相位转够 180 度时增益早已掉到 1 以下，越转越小，振不起来。

* **判断步骤**

    * 第一步 找有没有一个频率点使相移达到 $-180^\circ$；没有就是安全的。

    * 第二步 若有，再看该点所对应的 $|AF|$；$|AF| \geq 1$ 基本就牺牲了，$|AF|$ 比 1 小得多则非常安全。

## 级数与起振风险

* **直耦电路的级数判据**

    * 单级放大电路加入负反馈不会自激振荡，最大相移只有 $-90^\circ$，达不到 $180^\circ$。

    * 两级有可能相移到 $-180^\circ$，而且 $A$ 比较大、$AF$ 可能大于 1；但低通电路到达 $-90^\circ$ 时频率已经极高、输出端近似短路、传递函数趋于 0，放大倍数已由 $A$ 下降为 0，所以即使凑到 $-180^\circ$ 也满足不了 $AF=1$，两级也不会起振。

    * 三级最大相移 $-270^\circ$，比较宽裕，每级贡献 $-60^\circ$ 就能到 $180^\circ$。

    * 四级更轻松，每级来个 $45^\circ$ 就够了。

    * | 级数 | 最大相移 | 会不会自激振荡 |
    | :--- | :--- | :--- |
    | 单级 | $-90^\circ$ | 不会 |
    | 两级 | 理论上能到 $-180^\circ$ | 不会（到达时增益已降为 0） |
    | 三级 | $-270^\circ$ | 有可能 |
    | 四级 | 每级来 $45^\circ$ 就够 | 很可能 |

    * > **提示**：级数越多越危险；多弄几级放大倍数做得更大反而更危险，恰恰因为放大倍数大正是起振的幅值条件。

## 稳定裕度

* **稳定裕度（stability margin）**

    * > **定义**：$G_M$ 是 $-180^\circ$ 点与 0 dB 线之间的裕度，$\varphi_M$ 是同样含义下的相位裕度，两者都是稳定性的裕度。

    * 相频特性可以到 $-270^\circ$ 的那条曲线：当 $\varphi_A + \varphi_F$ 等于 $-180^\circ$ 时所对应的 $20\lg|AF|$ 若大于 0（即 $|AF|>1$），就完全可以起振。

    * 有 $-180^\circ$ 点但该点对应放大倍数小于 0 dB（即小于 1）的那条曲线：越转越小，不能起振。

## 消除自激振荡

* **补偿的基本想法**

    * 方法原则非常清晰：总归是在电路里加点东西让这张图变形，要么让 $f_0$ 跑到另一边，要么让过零点 $f_c$ 跑到另一边，两者结果一样。

    * 让 $f_{H3}$ 这个点往前移：再加一个作用在高频段的电容，把这一块的上限截止频率前移，让它在到达 $-180^\circ$ 之前就衰减为 0。

    * 这就是简单滞后补偿。

    * 补偿只作定性了解，不要求定量。

    * > **易错点**：这里加的是让高频段提前下折用的电容，别跟低频段那几个耦合电容混了；还是那笔账——高频数三极管，低频数耦合电容。
