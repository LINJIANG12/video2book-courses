# 功率放大电路与互补输出级

## 多级放大电路的级间分工

* **多级放大电路的最终目标**

    * > **定义**：多级放大电路要输出足够大的功率信号。

    * 共射放大电路既放大电流又放大电压，是理想的中间级。

    * 差分放大电路一般作为多级放大电路的输入级，抑制温漂、抑制干扰；前端若用场效应管，输入电阻还能很大。

    * > **结论**：共射输出后的信号已经很大，再往下用前面那些电路就有点捉襟见肘，因此需要一级专门做功率输出的输出级。

    * 本节讲直接耦合的互补输出级，是这套级联里"临门一脚"的一级。

* **电流源当负载**

    * > **定义**：把恒流源接在集电极位置，替代电阻 $R_C$。

    * 电流源内阻非常大，用它当负载就能提供很高的电压放大倍数。

    * > **结论**：直流源当负载、当 $R_e$ 电阻、当 $R_c$ 电阻，用途就是提供静态工作点。

    * 集成版电路从上到下依次是：具有恒流源的长尾式差分放大电路（单端输出的 NPN 共射）、电流源充当 $R_C$ 的共射级、互补对称输出级。

    * > **注意**：作交流通路时，电源相当于短路；偏置支路那几点只差一个直流电位，估算时可认为交流电位一致，捏成一个点，它们仅作为直流偏置存在。

## 输出级的需求单

* **输出级的四项要求**

    * 若把整个多级放大电路定义为对负载而言的电压源，输出级必须满足四条要求。

    * 输出电阻 $R_o$ 要小。

    * 到了最后一级输出电压已经很大，最大不失真输出电压 $U_{om}$ 要尽可能大。

    * 输出功率还要进一步放大，效率 $\eta$ 尽可能高。

    * > **结论**：由"$R_o$ 小"这一条就能推出，输出级最合适的电路是射极输出器（共集放大电路），它带负载时 $R_L$ 的变化对输出电压影响很小。

    * > **易错点**：做工程问题必须先说清需求。对电路连用在哪儿、用给谁都不清楚，就是大炮打蚊子甚至驴唇不对马嘴。

* **共集输出级的隐藏代价**

    * 共集解决了输出电阻小的问题，但到输出级已经不只是一个信号放大的问题，输出电流有明确的功率需求，效率问题随之出现。

    * 即使不考虑功率，输出级对管子的要求也极高：希望管子耐压越高越好、电流越大越好、范围越大越好，而这类管子代价很高。

    * > **结论**：用共集直接做音频功放，它一开机就端在那里发热。

    * 为了提高电平利用率，必须快速说话、扯着嗓子喊，把交流值做大，效率才上得去。

## 功率的账：电源交出去的钱去了哪里

* **效率（efficiency，$\eta$）**

    * > **定义**：$\eta$ 是最大交流输出功率 $P_{om}$ 与电源输入的直流功率之比；直流给它的是总功率，变成有效交流输出的是有用功率，其余部分全部转化为热。

    * 判定方法：只要 $P_{om}$ 与直流输入功率都算出来，直接相除。

* **电源交出的功率**

    * > **定义**：一个电源所发出的电功率等于电源电动势乘以输出电流。

    * 直流电源提供的功率为 $P_{DC}=V_{CC}\times (I_C+I_B)$。

    * 若 $I_B$ 远小于 $I_C$，则 $P_{DC}\approx V_{CC}\times I_{CQ}$。

    * > **结论**：有交流输出也好、没有交流输出也好，直流电源所发出的功率不变——交流的平均值还是零，作积分后仍是 $V_{CC}\times I_{CQ}$。

    * 静态时这功率的去处只有两处：管子的耗散 $U_{CEQ}\times I_{CQ}$，以及 $R_E$ 上的损耗，全都是热。

    * 加上交流后，电源交出的平均功率数值不变，但其中有一块 $u_o\times I_L$ 被"挖"出来变成了声音，相应地发热那部分就少了。

    * 把 $Q$ 点越往下移，静态功耗越小；移到截止区，只剩穿透电流。

* **发热的最大来源**

    * > **易错点**：整个电路里发热最大的其实是晶体管本身，不是电阻。电阻只承担一部分功率，而管压降 $V_{CE}$ 与管电流是同时存在的，乘积才是管子的耗散。

    * 由此得到提高效率的手段：让管子的开通时间变小。

* **甲类功放的现象判据**

    * 甲类波形全部落在工作区内，正负半周都在，一个失真都没有，这是甲类工作状态的由来；波形要摆成上顶天、下踩地就必须加直流把它抬起来，而这个抬升的直流不管用不用都在耗电。

    * 现象一：一开机家里就不需要电暖气，很快烫得不敢摸。

    * 现象二：把音乐推进去、交流输出越大，温度反而下降、反而更凉一些。

    * > **答**：因为甲类的直流电源功率一开机就不变，用不用都不变；不用时全部直流功率变成热，开始输出后有一部分转成声音，发热自然减少。

    * 网上流传的自制 $50\ \mathrm{W}\times 2$ 功放，冬天开机后 30 平米房间一小时内升温 10 度。

    * 判别方法：开机就发热，把音频推进去后热度减小。

    * 追求它的理由是失真小、高保真；不真用的理由是功率代价太高，市面上号称甲类的多是鱼目混珠。

    * 真正的甲类功放还有一个体征：里面有个很大的变压器，很沉。

## 工作状态：按导通角划分

* **工作状态分类**

    * > **定义**：工作状态按三极管导通角度划分：甲类导通 $360^\circ$，乙类导通 $180^\circ$，甲乙类导通大于 $180^\circ$ 小于 $360^\circ$，丙类导通小于 $180^\circ$，另有丁类。

    * 导通 $180^\circ$ 的含义是一半时间导通、一半时间截止。

    * > **提示**：正弦情况下角度与时间一致，横坐标以 $\omega t$ 代替时间、以相位代替时间。

    * 甲类失真最小，静态功耗很大，开机就在发热；乙类静态几乎不耗电，代价是交越失真；甲乙类居中，兼有甲类的低失真与乙类的高效率。

    * 甲乙类还分偏乙类和偏甲类两种，区别只在静态工作点抬高得多还是少；偏乙类的那种效率与纯乙类差不多。

    * 波形对比：

    ```text
              甲 类              甲 乙 类               乙 类

           ####              ####
          ######            ####           ######
          #    #           ######           #    #  死 区
         #      #          ##    ##          #      #
         #      #          #      #          #      #
        #        #        o#        #         #        #
        #        ##         #        ##         #        #
      ·o··········#··········#·       ·#··········#··········#·       ·o··········############·
    0              #        ##     0              #        ##     0
                   #        #                    #        #
                    #      #                     #      #
                    #      #                     ##    ##
                     #    #                      ######
                     ######                       ####

         Q 顶 在 正 中 间         Q 略 微 抬 高 一 点          Q 降 到 截 止 点
    ```

    * 读图：甲类的静态点被顶在正中间，波形上下对称、幅度最大；甲乙类的静态点从截止点往上抬了一丁点，整条波形跟着抬起来，两边仍然完整；乙类的静态点落到截止点，只有正半周能过去，而且因为要克服死区，连正半周的起始一段也是趴着的。

    * 按开通时间画的阶梯：

    ```text
        一个周期

    甲   ████████████████████████████   开通 360°
    甲乙 ████████████████░░░░░░░░░░░   开通 > 180°（略微超过半周）
    乙   ██████████████░░░░░░░░░░░░░   开通 180°（恰好半周）
    丁   ░░░░░░░████████░░░░████████░   开通 < 180°（窄脉冲开关）
    ```

    * 从甲类一路降静态功耗的路径：甲类（波形完整、静态功耗最大）→ 甲乙类（静态点略抬高）→ 乙类（静态点压到截止区，只剩半个波形）。

    * > **易错点**：乙类这种失真还是有谱的——起码照照镜子还知道另外一面，它一半是对的；有的失真连原型都找不到，那才是真的畸变。

* **甲类的低失真代价**

    * 甲类的低失真是用大静态电流换来的：一旦开机，无论说不说话，直流平均功率都一样，等于开机就开始计费。

    * 因为交流是对称的，$I_C$ 的平均值不变，所以电源输出功率不变。

    * 提高甲类效率的办法只有一个：以最大的嗓音、最快的速度不停地输出，否则没有交流输出时效率就是零。

    * 甲类功放不开声时实质是一台很好的电暖气，封在箱子里散热不够，温度会一路上去。

    * > **结论**：市面确有甲类功放这个概念，但代价特别高、对管子的要求全都不一样，鱼目混珠的非常多。

* **丁类（D 类）功放**

    * 开通角小于 $180^\circ$ 的叫 D 类，也叫丁类，因为名字更贴切——它其实是数字功放。

    * 第一代数字功放用的是 PWM 技术（脉宽调制，pulse width modulation）：管子不再线性放大，而是当开关啪啪开关形成一组脉冲波形，滤波之后还原成正弦波。

    * > **结论**：用上脉宽调制后效率大大提升，功放可以做得非常小。

## 互补输出级的组成与拓扑

* **互补对称**

    * 思路是"一半补一半"：既然乙类丢了一半波形，就再做一个电路产生另外一半，把两半对起来。

    * > **结论**：NPN 接正半周、PNP 接负半周，两只管子上下互补，这就是互补输出级最基本的样子。

    * NPN 与 PNP 是一回事，仅仅在静态的时候不同。

    * 两个半周各自干活：正半周打通上面那只，相当于上面那个射极输出器在工作；负半周打通下面那只，输出在负向，两个半周合起来是完整的。

    * > **注意**：这两条通路从不同时用。画交流通路时要么画上面半周、要么画下面半周，只画其一即可。

    * 复合管电路的分析同此：正半周上面那个复合管动，负半周下面那个复合管动。

* **OCL（Output Capacitor-Less，无输出电容器电路）**

    * 把下半边不接地，改接负电源：正半周由 $+V_{CC}$ 提供能量，负半周由 $-V_{CC}$ 提供能量，输出点直接接负载。

    * > **提示**：这里的 L 指的是 -less，去掉的是输出耦合电容。

    * 两只管子的基极并在一起接输入信号，发射极并在一起形成输出中点，中点大约是零点。

    * 由于有负载 $R_L$ 存在，发射极回路里那个起限流作用的电阻几乎可以不要了。

    * > **结论**：集成时没法用电容，所以双电源的 OCL 形式是集成实现的选择。

    * 好处是输入信号不用再骑在某个直流电平上，直接就是纯交流。

    ```text
                    +V_CC
                      │
                 ┌────┴────┐
                 │  T1 NPN │  正半周它导通
                 └────┬────┘
                      │  (E)
       u_s ──●─────────●───────────► u_o ──► R_L ──► GND
            │ (B)   中点 ≈ 0 V
       u_s ──●─────────●
                      │  (E)
                 ┌────┴────┐
                 │  T2 PNP │  负半周它导通
                 └────┬────┘
                      │
                    -V_CC
    ```

* **OTL（Output Transformer-Less，无输出变压器电路）**

    * 最初是用变压器实现互补输出的，变压器笨重；后来用电容代替，电容器很小，于是有了 OTL。

    * > **提示**：OTL 的 L 指的是 -less，里面放的是电容。

    * 负半周时前面那个电源供不上能，所以必须加入一个电容：正半周时电容被充电，负半周时靠电容放电度过。

    * > **结论**：两个管子对称、静态平衡时，电容上的电压正好是 $\frac{1}{2}V_{CC}$；交流信号是骑在这个 $\frac{1}{2}V_{CC}$ 基准上的交流。

    * > **易错点**：单电源供电时输入信号不是纯交流，它骑在 $\frac{1}{2}V_{CC}$ 这个直流电平上。

    * 正半周时 $V_{CC}$ 对电容充电，同时产生输出电压，直到把电容充到 $\frac{1}{2}V_{CC}$；负半周时靠电容放电撑过去。

    * > **结论**：这个电容一定得大，储电量不够就撑不完负半周。

    * 缺点是这个大电容也讨厌，于是想到：电容在这里起的作用不就是个电源吗，那就再弄个电源——这就催生了 OCL。

    ```text
                +V_CC
                  │
           ┌──────│──────┐
    ui ├──────┤     T1      │  NPN：正半周导通
       │      │             │
       │      └──────│──────┘                       C              R_L
       │             │
       │             ├───────────────────────────────│───────────────│
       │                                             │               │
       │      ┌─────────────┐                        │               │
       └──────┤     T2      │  PNP：负半周导通        │               │
              │             │                        │               │
              └──────│──────┘                        │               │
                     │                               │               │ GND
                   GND                               ┴───────────────┘
    ```

    * 读图：两只管子的发射极并联在同一个输出点上。正半周 NPN 把电流推进输出点，经耦合电容送到 $R_L$，同时把电容充上电；负半周电容放电，放出来的电流经 $R_L$、PNP 回到地，PNP 这才真正开始工作。

* **BTL 电路**

    * 无输出电容器电路如果还要再往下想，就会提出现在能不能只用单电源。

    * > **结论**：用一套电源 $V_{CC}$ 就能做，就是 BTL 电路。

    * 正半周时让 $T_1$、$T_4$ 导通，电流从左向右流过负载；负半周时让 $T_2$、$T_3$ 导通，电流从右向左，于是负载上得到完整的正弦电流。

    * 负载上的电压是电源电压减去两个管子的压降：$u_L = V_{CC} - U_{CES1} - U_{CES2}$。

    ```text
                 +V_CC
                   │
            ┌──────┴──────┐
            │             │
       T_1 ─┤             ├── T_4
            │    ┌──┐    │
       T_3 ─┤    │RL│    ├── T_2
            │    └──┘    │
            └──────┬──────┘
                   │
                  GND
    ```

* **变压器耦合与乙类推挽式**

    * > **结论**：甲类功放一定会有变压器存在，因为换掉 $R_C$ 之后所有能量都来源于 $R_L$，所有功率都给了负载。

    * 直流这一路反而更简单：直流时变压器相当于短路，$U_{CEQ}$ 恒等于 $V_{CC}$；$I_{CQ}$ 完全受 $I_{BQ}$ 控制，$I_{CQ}=\beta I_{BQ}$，所以直流负载线与交流负载线交于一点，这个交点就是 $Q$ 点。

    * 交流这一路才体现变压器的价值：调变比就等于调 $R_L$ 等效过来的电阻，等效电阻等于变比的平方，也就等于在调交流负载线的斜率。

    * > **结论**：变压器耦合不仅把所有功率都给了 $R_L$，还通过阻抗变换把输出幅值调高了将近一倍以上；调成 $45^\circ$ 后交流负载线交于 $2V_{CC}$，整个交流动态幅值就是 $V_{CC}$。

    * 变压器耦合的问题是直流时一直在耗功率，于是把直流负载线降下来——用乙类，就出现了乙类推挽式功放。

    * > **定义**：推挽式由两只特性相同的晶体管分别承担输出信号的正、负半周，轮流工作，一个"推"出去、一个"拉"回来。

    * 正半周时副边两个线圈同为上正下负，$T_1$ 导通、$T_2$ 截止，在 $R_L$ 上感应出正半周；负半周两边反过来，$T_1$ 截止、$T_2$ 导通，感应出负半周，两个波形合起来就是乙类推挽式功放。

    * 好处是平时不加输入时两管都不工作；问题是交越失真一定会出现。

    * 坏处更明显：抬起来就知道太沉了，而且会消耗大量硅钢片与铜线等有色金属。

    ```text
       ωt         0°──────────────180°──────────────360°
                  │     正 半 周     │     负 半 周      │

       T_1        ██████████████████████░░░░░░░░░░░░░░
       T_2        ░░░░░░░░░░░░░░░░░░░░████████████████

       u_o        ▁▂▃▄▅▆▇█████████████▇▆▅▄▃▂▁▔▃▂▁
                  ←── 正半周 ──→←──── 负半周 ────→
    ```

* **负载线**

    * > **定义**：加交流后可见两条线，直流负载线与交流负载线。

    * 阻容耦合时交流负载线与直流负载线不是同一条线，因为斜率不一样：直流负载线斜率 $-\dfrac{1}{R_C}$，交流负载线斜率 $-\dfrac{1}{R_C \parallel R_L}$。

    * 直流负载线只考虑直流，负载被耦合电容隔开；交流时 $R_C$ 与 $R_L$ 并联。

    * 最大输出时 $U_o$ 从饱和压降 $U_{CES}$ 一直摆到 $V_{CC}$，这段是最大的，交流负载线围出的那块三角面积就是 $R_C$ 与 $R_L$ 合起来消耗的交流功率。

    * > **易错点**：那块三角面积是 $R_C$ 和 $R_L$ 两者合起来消耗的功率，不是负载 $R_L$ 单拿的份额。

    * 想提高 $R_L$ 上的功率只剩一条路——把 $R_C$ 去掉，让所有功率都给到 $R_L$；但真把 $R_C$ 拿掉就没有输出电压了。

    * 讲变压器耦合正反馈电路时出现过没有 $R_C$ 的形式，那里是用变压器取代 $R_C$ 的位置。

## 交越失真及其消除

* **交越失真（crossover distortion）**

    * > **定义**：互补输出级在过零点附近出现的非线性畸变，波形表现为一段"平台"，这段既不是正半周也不是负半周。

    * 成因是三极管发射结有开启电压：过零点附近 $T_1$、$T_2$ 都还在截止，输入信号要自己牺牲掉几百毫伏去克服死区才能把它们打开。

    * 乙类做得太绝，把直流一点都没留，所以死区必然存在、必然出现交越失真。

    * 电流波形上的表现：正半周时 $i_{C1}$ 不断上升、$i_{C2}$ 不断下降直到零；负半周反之；纯乙类时会出现很长一段 $i_L$ 为零的状态。

    * > **易错点**：画图时那个"高一点点"是夸张的，真实死区电压没有那么高，但交越失真的存在是实打实的。

* **消除办法：让直流替输入信号买单**

    * 基本思路是把乙类抬出截止区，变成甲乙类，让两个管子都微微导通。

    * > **结论**：托举器件要有同样的温度特性，所以固定电源不行；两个发射结各需 $0.6\ \mathrm{V}$ 时，需要两个 PN 结约 $1.2\ \mathrm{V}$ 托起来。

    * 上稳压管是个好主意，但稳压管离散性特别大，而且反向特性与正向特性稍有不同。

    * 所以两个二极管是更容易想到的方案：导通这两个 PN 结补上发射结的压降，两管微微导通，交越处就不会断路，波形变得平滑。

    * 一旦托起来，工作状态就是甲乙类——还有偏乙类的甲乙类和偏甲类的甲乙类，看静态工作点高一点还是低一点。

* **二极管偏置的致命细节**

    * 画完两个二极管只是画了个饼，它们根本没导通，还得给这条支路加直流。

    * > **易错点**：限流电阻不是多余的。去掉它以后，两个二极管会被两倍的 $V_{CC}$ 直接灌死。

    * 交流分析时，这个偏置支路提供的是一个直流静态，因此可近似看成电源，交流时可认为近似短路、几点交流电位相同；但这些阻值相对都比较小，算出来也行。

    * > **注意**：一定要接点地气，二极管才打得通；光串上两个二极管而没有直流回路是不行的。

* **V_BE 倍增电路**

    * 对两个二极管方案的评价是"略显稚嫩"：它是死的，每个二极管正向导通压降都有些许不同，选到哪个就是哪个，不能调节。

    * > **结论**：用三极管的发射结作基准做倍压电路，跟发射结的特性特别近似；有温度影响时大家要变一起变，而且输出电压可以是基准的若干倍，从而可以调节。

    * 电路条件：支路电流 $I_1$ 近似等于 $I_2$，即电流源提供的 $I$ 要远远大于基极电流——这与静态工作点稳定放大电路的条件相同。

    * > **定义**：倍增电路把 $R_2$、$R_3$ 串在两个基极 $b_1$、$b_2$ 之间，恒流源保证两支路电流近似相等，于是两电阻压降可以相加得到 $U_{b_1b_2}$：

    $$U_{b_1 b_2} = \frac{R_2 + R_3}{R_3}\, U_{BE}$$

    * $U_{BE}$ 是发射结的导通电压，是一个随温度变化的量。

    * 通过选取不同的 $R_2$、$R_3$ 就能得到不同的倍压，这就是"可调"。

    * 最常见的实际形式是：两只管子、两个电阻、二极管，再加一个电流源；常见偏置支路是 $R_1$、$R_2$、$D_1$、$D_2$、$R_3$ 串在 $+V_{CC}$ 与 $-V_{CC}$ 之间。

    * > **提示**：交流通路里说"$R_3$ 上就是 $U_{BE}$"、"$R_2$、$R_3$ 流过同一电流"，靠的都是 $I_R \gg I_B$ 这个前提——基极电流小到可以忽略，从基极注入的电流才几乎全部流过发射结。

    * 去掉限流电阻不行：上下两个结都会出现正向偏置，等于提供一个很可观的通路，等同于短路。

* **OCL 偏置支路的两个要点**

    * 用 $R_2$、$D_1$、$D_2$ 构成偏置支路，让两个发射极微微导通，两管合起来都是甲乙类工作状态，交接处两管同时微导通，电流波形在那儿平滑交接。

    * 第一，$R_2$ 是个很小的电阻，作用是微调——调 $R_2$ 可以让 $E$ 点最终保持零电位。

    * 第二，$R_2$、$D_1$、$D_2$ 上任何一个虚焊都非常危险。

    * > **易错点**：任一元件虚焊，这条路径上出现断点，$V_{CC}$ 就经 $R_1$ 走下来、再经 $R_3$ 打通；这两个电阻并不很大，一旦打通相当于短路，两个管子会很快发热而且容易烧毁。正常连着时基极电位受对面控制，不会出现这种危险。

## 复合管

* **复合管（compound / Darlington 型连接）**

    * > **定义**：把两只管子叠在一起，输入电流先进内层管，内层管的发射极电流再去驱动外层管，输出电流被逐级放大。

    * 复合管的电流放大能力约等于各级 $\beta$ 的连乘。

    * 存在的原因是 NPN 与 PNP 在大功率时很难对称：外面看要求对称，功能上又要求上面是 NPN、下面一定是 PPN。

    * > **结论**：复合管让最外层（真正承受大电流的那一对）可以做成同型管——上、下都是 NPN，而整体对外仍呈现互补的极性关系。

    * 从外面看它是对称的，但实际分析时仍然是正半周上面这个动、负半周下面这个动。

## 输出功率、效率与管子的选择

* **最大输出功率 $P_{om}$**

    * > **定义**：$P_{om}$ 是最大的交流输出功率。

    * 最大的不失真幅值是从饱和压降 $U_{CES}$ 到 $V_{CC}$ 那一段，所以幅值是 $V_{CC}-U_{CES}$；若按有效值则再除以一个 $\sqrt{2}$。

    $$P_{om}=\frac{(V_{CC}-U_{CES})^2}{2R_L}$$

    * > **提示**：这个公式里的 $U_{om}$ 指的是有效值，所以时域表达式里还要再乘一个 $\sqrt{2}$ 才是幅值。

* **电源平均功率 $P_V$**

    * 求效率前必须先得到 $V_{CC}$ 电源的平均功率，电源的瞬时功率为 $p(t)=V_{CC}\times i_C(t)$。

    * $i_C(t)$ 就是 $i_L(t)$，每一时刻都是导通的那只管子在供流。

    $$i_C(t)=\frac{\sqrt{2}\,U_{om}}{R_L}\sin(\omega t)$$

    * > **注意**：这只是半个周波，所以平均功率按半周来算，积分区间 $0$ 到 $\pi$，系数是 $\frac{1}{\pi}$：

    $$P_V=\frac{1}{\pi}\int_0^{\pi}V_{CC}\cdot\frac{\sqrt{2}\,U_{om}}{R_L}\sin(\omega t)\;\mathrm{d}(\omega t)$$

* **效率**

    * > **定义**：$\eta$ 是最大交流输出功率与电源输入的平均功率之比。

    * > **易错点**：这已经是甲乙类工作状态了，不能用甲类的式子替代。甲类只需静态电流乘 $V_{CC}$，甲乙类不是这样。

    * 最终算出的效率约为：

    $$\eta\approx\frac{\pi}{4}\times\frac{V_{CC}-U_{CES}}{V_{CC}}$$

    * > **结论**：这个数接近 1，$\eta$ 大约是 $78.5\%$——乙类、甲乙类功放的效率可以达到 $78.5\%$。

    * 作为对照，甲类功放的直流输入功率是 $P_{DC}=V_{CC}\times (I_{CQ}+I_{BQ})\approx V_{CC}I_{CQ}$（矩形面积），输出功率是负载线上那块三角面积，把 $Q$ 点坐标代进去即可求。

* **管子的耐压**

    * 选管子只考虑两件事：能承受的压降和最大耗散功率。

    * 管压降按峰峰值分析：导通时最大值是 $V_{CC}-U_{CES}$，而要承受的最大管压降为：

    $$u_{CE\max}=2\left(V_{CC}-U_{CES}\right)$$

    * > **结论**：选管子时 C-E 之间的击穿电压一定要耐受这个值之上。

* **最大耗散功率**

    * > **结论**：所谓最大耗散，就是管子上最大耗散功率，它既不出现在 $i_C$ 最大的时候，也不出现在 $u_{CE}$ 最大的时候。

    * 原因是 $u_{CE}$ 最大时 $i_C$ 最小，$i_C$ 最大时 $u_{CE}$ 最小，峰值必然落在两者此消彼长的中间位置。

    * 求法：把单管在一个半周内的两个量都写成 $\omega t$ 的函数——导通期间电流是 $i_C=I_{om}\sin\omega t$，管压降是 $u_{CE}=V_{CC}-U_{CES}-U_L$，两者相乘得到瞬时耗散表达式，再求极值。
