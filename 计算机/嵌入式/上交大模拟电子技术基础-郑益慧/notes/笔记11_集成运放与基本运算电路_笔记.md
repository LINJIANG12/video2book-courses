# 集成运放与基本运算电路

## 虚短与虚断

* **虚短（virtual short）**

    * > **定义**：运放处于线性工作区时，同相端与反相端电位相等，即 $u_P = u_N$。

    * 成立前提是深度负反馈把运放压在线性工作区内；没有负反馈就没有虚短。
    * 记号 $u_I$、$u_N$、$u_O$、$u_P$ 默认都指对地电压。
    * 反相比例电路里同相端接地时，虚短具体化为「虚地」：反相端电位被拉到 0，但那里并未真正接地，也没有电流流进运放。

* **虚断（virtual open）**

    * > **定义**：集成运放差模输入电阻极大，从输入端看进去的输入电流 $I_I$ 视为零，$i_N = i_P = 0$。

    * 虚断任何时候都成立，不依赖线性工作区这一条件。
    * 虚断成立的前提不是「输入电流近似为零」这句话本身，而是它约掉的那一笔实实在在存在的**偏置电流**。

* **视输入线于不见**

    * > **结论**：把两根输入线当成断路后，它们不再是有电流的支路，而变成串联导线；同一串联路径上电流处处相等，后面「两支路电流相等」的结论都从这一步来。

    * 这是一道心理障碍，反复自我提醒才能形成习惯。

* **运放的电源与 KCL 陷阱**

    * 在输出端挂负载电阻 $R_L$ 到地，电路中一定有电流。
    * 把运放当成一个纯符号去套 KCL，会得出「输出端也无电流」的错误结论。
    * 错因是忽略了芯片的电源管脚：芯片的引脚必须接上外加直流电源才能工作，双电源、单电源的接法各不相同。
    * 仿真工具（如 Multisim）会给运放甩出两根小电源线要求外接直流电源，就是提醒这一点。
    * 原理图与实际电路之间必须建立「要有电源驱动」的对应关系，和非门不接电源就测不出 $Y = \overline{A \cdot B}$ 是同一回事。

* **线性工作区的来源**

    * 负反馈使运放工作在线性工作区，这是判定一组集成运放电路能用虚短分析的前提。
    * 分析每一张电路图时要同时追问：它靠什么原理、什么定理完成这个功能，换了自己会怎么设计。

## 反相比例电路

* **最普适的分析法：两点分别表示**

    * > **结论**：不管什么电路，都可以用 $u_O$ 和 $u_I$ 把 $u_P$ 表示出来、再把 $u_N$ 表示出来，由 $u_N = u_P$ 解出 $u_O$ 与 $u_I$ 的关系。

    * 电路本质是电压并联负反馈，必然工作在线性工作区，可以直接套虚短、虚断、叠加原理。
    * $u_P = 0$：即使同相端对地串了 $R'$，因 $i_P$ 极小，$R'$ 上没有电流，压降为零。
    * 用 $u_I$ 与 $u_O$ 作两个独立源叠加求 $u_N$：$u_I$ 单独作用贡献 $\dfrac{R_F}{R + R_F}u_I$，$u_O$ 单独作用贡献 $\dfrac{R}{R + R_F}u_O$。
    * 两式相加等于 $u_P = 0$，解得 $u_O = -\dfrac{R_F}{R}u_I$，实现 $y = -kx$。

* **虚地法：先定能定的点，再传电流**

    * $u_P = 0$ 先定下来，由虚短得 $u_N = 0$，$N$ 点即虚地。
    * $i_R = \dfrac{u_I - u_N}{R} = \dfrac{u_I}{R}$，输入电压与输入电流的比例由**电阻的特性**决定。
    * 虚断使 $i_F = i_R$，反馈电流与输出电压的比例同样由电阻 $R_F$ 决定：$u_O = u_N - R_F i_F = -R_F i_F$。
    * > **结论**：比例运算靠两个电阻各完成一次「电压—电流比例」转换，再用虚断把两个电流串接传递，$u_O$ 与 $u_I$ 自然成比例。

    * 技术路径：$u_I$ 与 $u_O$ 无法直接相比，中间必须找一个传递量，选的是**电流**；需要两个元件分别把 $u_I$、$u_O$ 与该电流绑定成比例。

* **输入电阻的计算**

    * 从反馈网络向里看，有电流但电压为零，等效输入电阻为 0，与深度电压并联负反馈把输入电阻压到极小的结论相符。
    * 电路总输入电阻 $R_i = R$，也可用 $R_i = \dfrac{u_I}{i_R}$ 直接算得。

    * > **易错点**：看到 $R_i = R$ 容易认为「并联负反馈输入电阻应当很小」与结果矛盾。那个 $R$ 是**游离在反馈环之外**的；真正处在并联负反馈里的那部分，其等效输入电阻是 0。

* **设计上的困境**

    * 前端信号源常常只能提供电流，实际又必须经 $R$ 转成电压以提高输入阻抗。
    * 想要输入阻抗大就得加大 $R$；比例系数再要大，$R_F$ 就必须更大，两者被绑死。
    * > **结论**：电阻越大，内部电流越小，受一点点干扰就表现为很大的电压差异，所以不会用非常大的电阻去做分压、去做比例，稳定性太差。

    * 破局思路：$u_O$ 与 $i_F$ 成比例，问题在于 $i_F$ 被 $i_R$ 绑定死了；只要能让 $i_F$ 比 $i_R$ 大，就能得到更好的 $u_O$。

## T 型反相比例电路

* **做法：把反馈电阻分开**

    * 把单一反馈电阻 $R_F$ 拆成 $R_2$、$R_3$、$R_4$ 三段，$R_3$ 从反馈中点 $M$ 接地，形成 T 字形。
    * $M$ 点必然是负电位，因此必然引起一个向上的电流 $i_3$。
    * 电流关系为 $i_4 = i_2 + i_3$，其中 $i_2 = i_1$。
    * 效果：没有 $i_3$ 时 $u_O = -(R_2 + R_4)\cdot i_2$；加入后 $R_4$ 上的压降至少提升 $i_3 R_4$。

* **倒推式工程思路**

    * > **结论**：工程问题的解法是「我知道要达到什么结果，为了达到它要求前面具备什么条件，再往前又需要什么条件」，一路推到最前面的条件一定是可解决的，否则无解。

    * 推理链：要 $u_O$ 就必须知道 $i_4$ 与 $u_M$；$i_4$ 由 $i_2$ 和 $i_3$ 提供，而 $i_3$ 必须靠 $u_M$；$u_M$ 只由 $i_2$ 决定；$i_2 = i_1$。
    * 因此只要知道 $i_1$ 就知道了一切。
    * 求解顺序：$i_1$ → $i_2$ → $u_M$ → $i_3$ → 由 $i_3$ 与 $i_2$ 得 $i_4$ → 由 $u_M$ 与 $i_4$ 得 $u_O$。

## 同相比例电路与电压跟随器

* **同相比例电路**

    * > **结论**：从反相端进去得到负比例，从同相端进去得到正比例。

    * 反馈必须引到反相端才是负反馈；同相端不能直接接地，必须通过一个电阻 $R$ 接地，否则就退回了反相形式。
    * 虚短把 $u_I$ 「引」到 $u_P$ 上，于是 $u_P = u_N = u_I$。
    * $i_R = \dfrac{u_N}{R} = \dfrac{u_I}{R}$，等于 $i_F$，$u_O = u_N + i_F R_F = \left(1 + \dfrac{R_F}{R}\right)u_I$，实现 $y = kx$（$k>0$）。

* **同相比例的三个特点**

    * 输入电阻非常大：属于电压串联负反馈，输入端近似断路，因此特别适合直接取电压信号。
    * 输入端存在共模信号：$u_P = u_N = u_I$，不再是零；运放前端是差分输入结构，共模分量会被抑制但并未消失。
    * 对运放提出额外条件：电压并联负反馈的电路对抗共模要求不高，电压串联负反馈的电路要求运放有较好的共模抑制。

* **反相与同相比例的对照**

    | 对比项 | 反相比例电路 | 同相比例电路 |
    | :--- | :--- | :--- |
    | 反馈组态 | 电压并联负反馈 | 电压串联负反馈 |
    | 反馈网络自身输入电阻 | 0（被深度降低） | 很大，近似无穷 |
    | 电路总输入电阻 | $R$（$R$ 游离在反馈环外） | 几乎断路 |
    | 输入端电位 | $u_P = u_N = 0$（虚地） | $u_P = u_N = u_I$ |
    | 比例关系 | $u_O = -\dfrac{R_F}{R}u_I$ | $u_O = \left(1+\dfrac{R_F}{R}\right)u_I$ |
    | 取电压信号 | 需串 $R$ 提高输入阻抗 | 天然适合，输入端近似断路 |
    | 对运放的要求 | 抗共模要求不高 | 要求有较好的共模抑制 |

    * 两种电路的反馈网络输入电阻之所以一个为 0、一个近似无穷，直接由反馈组态决定。
    * 选择哪一个取决于前端信号源能否提供电流、是否需要大输入阻抗与低干扰。

* **电压跟随器（voltage follower）**

    * > **定义**：传递函数为 $u_O = u_I$ 的电路。

    * 推导链条只有三步：输出端不取负载电流，线上无压降，$u_O = u_N$；虚短给 $u_N = u_P$；同一路过来给 $u_P = u_I$。
    * 两种画法的跟随器传递函数完全一样，差别只在同相端是否串电阻。

## 平衡电阻

* **平衡电阻（balancing resistor）**

    * > **定义**：$R_1' = R \parallel R_F$，称为平衡电阻，使同相端与反相端的接入电阻相同，靠偏置电流在两侧产生相同压降，把静态差值抵掉。

    * 起因是**偏置电流**：它从运放内部流出来，两个输入端都有，虽然极小但确实存在。
    * 偏置电流只在**静态（置零）**条件下起作用：信号源置零、交流置零之后剩下的量。
    * 置零后 $R$ 与 $R_F$ 都落地，反相端对外呈现 $R \parallel R_F$，偏置电流在这个等效电阻上压出压降，把 $u_N$ 抬高。
    * 同相端若没有 $R_1'$，虽同样有电流流出，但没有电阻就没有压降，$u_P$ 仍为零。
    * 两侧压降不等就产生 $u_N \ne u_P$ 的**静态误差**，对后续运算是有害的。
    * 装上 $R_1'$ 后：反相侧 $u_N = I_B (R \parallel R_F)$，同相侧 $u_P = I_B R_1'$，取 $R_1' = R \parallel R_F$ 即有 $u_N = u_P$。

    * > **易错点**：算平衡电阻必须回到**静态置零**状态去算。反相端之所以是 $R \parallel R_F$，正是因为置零之后 $R_F$ 那一头也落地了，这一步最容易漏；拿交流通路那套直觉去套必然算错。

    * 没有 $R_1'$ 电路一样能工作，只是留下静态误差。

## 求和、加减与差分电路

* **反相求和电路**

    * > **结论**：在这种集成运放电路里，用的是同一个概念——两边的电流相等；把多路电流汇到反馈支路，KCL 本身就写出了求和关系。

    * 三个输入各经 $R_1$、$R_2$、$R_3$ 并到反相端，分别贡献 $i_1$、$i_2$、$i_3$。
    * $i_F = i_1 + i_2 + i_3$，再由 $R_F$ 把总电流换算成输出电压。
    * $u_O = -\left(\dfrac{R_F}{R_1}u_{i1} + \dfrac{R_F}{R_2}u_{i2} + \dfrac{R_F}{R_3}u_{i3}\right)$，即 $y = -(k_1x_1 + k_2x_2 + k_3x_3)$。
    * 平衡电阻为四个电阻的并联：$R_1' \parallel R_1 \parallel R_2 \parallel R_3$。

* **同相求和电路**

    * 把这一堆输入电阻整体挪到同相端，思想不变。
    * 电流路径：各支路电流 $i_1$、$i_2$、$i_3$ 在同相端汇成 $i_4$，$i_4$ 决定 $u_P$，再由 $u_P = u_N$ 落到反相端，$u_N$ 与 $u_O$ 成比例。
    * $u_{i1}$、$u_{i2}$、$u_{i3}$ 与 $u_P$ 的关系用**叠加原理**算。

* **叠加原理的标准套路**

    * 其余置零：交流信号源置零相当于短路，不作用的电压源置零相当于接地。
    * 置零这个操作与平衡电阻的推导用的是同一件事。

* **加减法与差分比例电路**

    * 同相端和反相端都参与叠加，就自然得到加减运算。
    * 符号判定：接在反相端的 $u_{I1}$、$u_{I2}$ 取负号，接在同相端的 $u_{I3}$、$u_{I4}$ 取正号，即 $u_{I3}$、$u_{I4}$ 减去 $u_{I1}$、$u_{I2}$。
    * 把输入减到最少、只剩 $u_{I1}$ 与 $u_{I2}$ 一个减法，就是差分；做成绝对干净的差分需整个电阻网络匹配（两个 $R$ 相同、两个 $R_F$ 相同），输出为 $u_{I2} - u_{I1}$。
    * 该差分电路的短板是输入电阻：$u_{I1}$ 侧输入电阻较大，$u_{I2}$ 侧因 $R_F$ 的存在被破坏，把 $u_{I1}$ 侧置零后其等效为 $R + R_F$，不大。

    * > **易错点**：「差分电路输入电阻大」这句话只对 $u_{I1}$ 那一侧成立，不能把两侧当成一回事。

    * 解决方案一（最简单）：前端用两个电压跟随器，把两侧输入电阻都做大。
    * 解决方案二：用一级同相比例放大先把该侧输入电阻做大，再直接输入，构成高输入电阻的差分比例运算电路。

## 积分与微分电路

* **从元件特性推电路的方法**

    * 比例、加法、减法最关键的都是比例，因为所选元件（电阻）的电压与电流本来就成比例。
    * 做微积分只需找到一个满足 $i = K\dfrac{\mathrm{d}u}{\mathrm{d}t}$ 的元件，再让 $u_I$ 与该电流成比例、$u_O$ 与该元件上的电压成比例，就得到积分；两者关系对调就是微分。
    * 这个 $K$ 就是电容 $C$。
    * > **结论**：手里有什么元件，就能造出什么电路——只要找到电压与电流呈某种函数关系的元件，就能用集成运放把该函数关系引进来。

* **积分电路**

    * > **定义**：反相端输入经 $R$ 到地，输出经电容 $C$ 反馈到输出，构成真正的积分器，$u_O = -\dfrac{1}{RC}\int u_i\,\mathrm{d}t$。

    * 电容上的电压等于 $-u_O$，充电电流由 $u_i$ 与 $R$ 决定，故充放电电流恒定。
    * 正是恒流充放电使波形成为**真正的直线**，区别于基本电路中靠 $RC$ 直接充放电、带有弧度的近似积分。
    * 定积分含初始值项：电容上原有电荷对应的初始电压就是积分的常数项，实际工作中不能忽略。
    * 方波输入得到三角波输出，同时实现了**波形变换**；由于从反相端输入，输出与输入反相。

* **积分电路中的 $R_F$**

    * > **结论**：这里的 $R_F$ 不是用来改善性能的，是用来兜底保护运放的。

    * 去掉 $R_F$ 时 $u_O$ 会一路冲到饱和，而且进入饱和后需要退饱和过程，会影响响应速度。
    * 加上 $R_F$ 后 $u_O$ 不会超出 $-\dfrac{R_F}{R}u_i$ 这个界限，从而不让运放进入饱和区。
    * 直流输入时 $u_O$ 不会无限增长，最终仍会饱和，但加了 $R_F$ 后不会被推到深度饱和。

* **充放电时间的计算**

    * 依据电容定义式 $\Delta q = \Delta u \cdot C = I \cdot \Delta t$。
    * 充电电流恒定，$\Delta t = \dfrac{\Delta u \cdot C}{I}$，线性充放电使时间可以精确算出。

    * > **易错点**：$q = Cu$ 是电容的定义式，不是「大概差不多」的近似关系，不能随便当近似用。

* **微分电路**

    * 构成：把积分电路中的 $R$ 与 $C$ 位置对调——反相端输入经电容，原反馈电阻改为电阻。
    * 本质是急性子、快速动作的环节，把前面一点点的趋势放大成大的变化；积分则是稳定的滞后环节，从历史数据里取平均。
    * > **易错点**：若 $u_I$ 是理想阶跃，阶跃瞬间 $i_C$ 趋向无穷，理论上是一个冲击电流。

    * 实际后果：合闸瞬间电容电流特别大，全部电流灌进反馈电阻，电阻上电压骤增，把运放打到**深度饱和**，严重时内部**闭锁**，从饱和里出不来，除非断电。
    * 保护措施一：在反馈电阻两端并一个**稳压二极管**，把电阻上的电压钳住。
    * 保护措施二：再在同一个电阻上并一个电容作**相位补偿**，它是滞后环节，防止电路进入自激振荡。

## 对数与指数放大电路

* **元件的指数关系**

    * > **结论**：给我一个电压与电流呈指数关系的元件，就能做出指数与对数电路——这个元件就是二极管或 PN 结。

    * PN 结的端口关系为 $i \approx I_S\left(e^{u/U_T} - 1\right)$，只能取近似，不能当成能随手算出精确值的式子。

* **二极管实现对数的两条硬约束**

    * 输入 $u_I$ 必须大于零：二极管不能倒着流，$u_I < 0$ 直接失效。
    * 可用的输入电压**区间很小**：
    * > **易错点**：$U_{BE}$ 本身没有很大的变化区间，不要以为对数电路能实现几十伏量程的对数运算；确需大范围必须再做放大。

* **三极管撑开动态范围**

    * 当 $\alpha$ 近似为 1 时 $i_C \approx i_0$，而 $i_C$ 就是 $i_E$，$i_E$ 与 $u_{BE}$ 呈指数关系。
    * $u_{BE}$ 就是负的 $u_O$，于是 $u_O$ 与 $i_E$ 成对数关系。
    * $i_E = i_C = i_R$，而 $i_R$ 与 $u_I$ 成比例，所以 $u_O$ 与 $u_I$ 成对数关系。
    * 指数电路的做法是把这个关系元件挪到输入一侧。

* **反函数构成法**

    * > **定义**：把一个已有的功能块整体接进反馈通路，使它的输入与输出端口掉个个儿，得到的正是原函数的反函数。

    * 例：把积分电路接进反馈，输出 $u_O$ 与外输入 $u_I$ 成比例（$i_1 = i_2$），而积分器的输入就是 $u_O$，外输入对应原积分器的输出，于是**积分变成了微分**。
    * 这是一类非常常用的方法：用反馈对已实现的功能做一次大调个儿。

## 运算电路的设计思路

* **第一种思路：元件端口函数关系**

    * 找到一个元器件，把它两端电压与其中电流的函数关系当作设计依据，再用虚短、虚断把这个元件塞进运放回路。

    | 元器件 | 两端电压与其中电流的关系 | 性质 |
    | :--- | :--- | :--- |
    | 电阻 | $U = I \times R$ | 乘积关系 |
    | 电容 | $i = C\dfrac{\mathrm{d}u}{\mathrm{d}t}$ | 微积分关系 |
    | PN 结 | $i \approx I_S\left(e^{u/U_T}-1\right)$ | 指数关系（只能约等于） |

    * 枢纽在于**电流是传递的媒介**：虚断保证电流不被运放漏走，所以电流必须被顶进元件；虚短保证反馈端电位被钳住。
    * 元件在中间充当一台「电压—电流」翻译机：进来的是电流，出去的是电压。

* **同一条拼装图纸，四种结果**

    * 输入端电压与电流成正比、输出端电压与元件电压成正比时，用电阻得到**比例**关系。
    * 输入端电压与电流成正比、输出端电压与电容电压成正比时得到**积分**；两者对调得到**微分**。
    * 用 PN 结时，$u_I$ 与电流成正比、$u_O$ 与元件电压成正比得到**对数**；若 $u_O$ 与电流成正比则得到**指数**。

* **加减运算的来源不同**

    * 加减来自 **KCL 与叠加定理**，与换不换元器件无关。
    * 加法是不断往上并联输入元件，让电流累加；同相端提供一路、反相端提供一路，就构成加减。
    * > **结论**：只要找到一个元器件满足某种函数关系，这种函数关系就能利用集成运放引进来使用；任何函数关系只要能落到某个元器件的端口特性上，就能被引进来。

* **第二种思路：端口掉个儿换来反函数**

    * 已有功能块 $F$ 满足 $u_O' = F(u_I')$；把它接进反馈后，功能块输入端改由新输出按比例驱动，功能块输出端反过来驱动新输入。
    * 令新 $u_O$ 与 $u_I'$ 成正比、新 $u_I$ 与 $u_O'$ 成正比，得到的就是原函数的**反函数**。
    * > **结论**：给一个函数就能构建出它的反函数；原来是从元件造函数，现在是有了函数本身用同一个电路造反函数。

    * 这一手法与戴维宁定理、诺顿定理同味道：不新增元件，只重新安排已有东西的连接顺序。

* **对偶与迁移**

    * 对偶最关键的一点是知一必有其二：证明了一个等式，其对偶等式必然成立，于是「知一到二」成为最常用的用法。
    * 电路里同样存在这种关系，例如证明电压源形式的结论后，电流源形式的对偶关系同样成立。
    * > **提示**：上面那种「端口掉个儿」的做法可以看成借用了「知其一必有其二」的思路，但它**不全是对偶**，两者不能混为一谈。

    * 学习方法上，从无到有一步步把电路画出来，比背电路更能加深理解：电路能一步步构建下来，才算深刻理解了它的含义。

## 模拟乘法器

* **符号与等效电路**

    * 符号是一个大乘号，端口为 $u_X$、$u_Y$、$u_O$。
    * 等效电路表达的是**端口等效**：输入端对应输入电阻 $R_i$，输出端是戴维宁等效模型。
    * 输出端的电压源是**受控电压源**，值为 $K \cdot \Delta u_X \cdot \Delta u_Y$，并带内阻 $R_o$。
    * 必须是受控源而不是独立电压源：若为独立源，$u_I$ 与 $u_O$ 就失去了关系。

* **理想模拟乘法器的条件**

    * 输入电阻无穷大，输出电阻 $r_o \to 0$。
    * 系数 $K$ 恒定不随温度变化。
    * 失调电压、失调电流以及一切干扰与噪声统统为零。
    * 满足这些条件后可直接放心使用 $\Delta u_O = K \cdot \Delta u_X \cdot \Delta u_Y$。

    * > **结论**：理想条件可以浓缩成一句话——除了乘法的增益，其他一切副作用都消失；理想条件下画出的电路是骨架，真实器件只是在骨架上贴误差。

* **象限与输入约束**

    * $\Delta u_X$、$\Delta u_Y$ 的符号组合共四种：两个正、一正一负（两种）、两个负，对应四个象限。
    * 模拟乘法器据此分为**单象限（第一象限）、两象限、四象限**三类。
    * > **结论**：模拟乘法器并非都一样，有些对输入极性有硬约束；单象限器件只允许两个输入全为正，四象限用起来最方便、没有任何约束。

* **平方与高次幂的级联**

    * 平方运算：把乘法器的两个输入端短接在一起并送入同一信号，得 $u_O = K u_I^2$。
    * 四次方：两级平方级直接串接，把上一级输出接到下一级的两个输入端。
    * 三次方：平方级的输出一路接乘法级，另一路取自原始输入。
    * 迁移思路是同一个：想 $n$ 次方，就把指数拆成几个能用乘法器实现的小指数，再串起来。

* **级数上限**

    * 模拟乘法器每一级都有误差：$K$ 会漂移，还有失调电流、失调电压、输入与输出电阻的影响。
    * 这些误差不会互相抵消，只会一级一级往下传，而且**误差自己也在逐级相乘**。
    * > **结论**：用模拟乘法器实现 $n$ 次方时级数**最好不超过三级**。三级不是精度损失的起点，而是「乘方关系还算不算得出来」的终点；四级乘方在纸面上永远成立，在实际元件上只是一堆误差的乘积，其增长速度比信号本身还快。

* **换尺度法实现乘除与 $n$ 次方**

    * 乘法器算不了 $a^x$ 这类运算，对数与指数可以。
    * 乘法：取对数把乘法变成加法，加完再取指数还原；中间一级甚至不需要真正的乘法器，一个反相求和就够。
    * 除法：取对数后相减，再取指数。

    | 需要实现的运算 | 前段 | 中段 | 后段 |
    | :--- | :--- | :--- | :--- |
    | $u_{I1} \times u_{I2}$ | 两个对数 | 求和（加） | 指数 |
    | $u_{I1} / u_{I2}$ | 两个对数 | 求和（减） | 指数 |
    | $u_{I}^{\,n}$ | 一个对数 | 比例（$\times n$） | 指数 |

    * 三行骨架都是「换尺度 → 在新尺度里做最简单的线性运算 → 换回来」。

    ```text
      u_I1 ──►[ 对数 ]──┐
                        ├──►[ 反相求和 ]──►[ 指数 ]──► u_O
      u_I2 ──►[ 对数 ]──┘

        求和级换成减法：  u_O = u_I1 / u_I2

      n 次方：  u_I ──►[ 对数 ]──►[ ×n ]──►[ 指数 ]──► u_O
    ```

    * > **结论**：乘除与 $n$ 次方电路没有引入任何新的器件特性，只是把已经有的对数、求和、指数三种能力重新排了一次队；学到的是构成电路的思想。

* **除法电路及其使用条件**

    * 手里没有除法器但有乘法器，乘除互为反函数，因此把乘法器按反函数接法插入反馈即可。
    * 接法：$u_{i2}$ 是被除数，送入乘法器一个输入；$u_{i1}$ 是除数；乘法器的输出 $u_O$ 本身就是它的一个输入，按比例回接。
    * 照葫芦画瓢搬过来后必须马上检查使用条件：这个乘法器回路**究竟能不能构成负反馈**。
    * 环路增益为 $K u_{I1} u_O$，必须保证它**大于零**；一旦小于零，环路立刻由负反馈翻成正反馈，运放一路冲到饱和。

    | 乘法器系数 | 使用条件 |
    | :--- | :--- |
    | $K > 0$ | $u_{i1}$ 必须恒为大于零 |
    | $K < 0$ | $u_{i1}$ 必须恒为小于零 |

    * > **结论**：除法电路的成立以「某个输入量必须保持特定符号」为代价；符号条件不是细节，而是负反馈能否成立的前提。

* **开方电路与极性锁定**

    * 开方电路没有现成电路，但有平方电路：把平方电路的两个输入端接到一起即可，不再外接 $u_i$，另一个输入取 $-u_O$。
    * > **定义**：平方根电路面对的是一个「平方之后已经丢失符号」的输入——$u_I$ 取正取负，$u_I^2$ 一律被拉到正半轴；反馈极性无法再靠输入符号自动纠正，只能靠乘法系数 $K$ 的符号一次性锁死。

    * 在原接法下必须 $K < 0$。
    * 若改用**串联反馈**，把反馈网络接到同相端，则可以改用 $K > 0$。
    * 若 $K > 0$ 而不改装接法，就必须约束 $u_I < 0$，此时 $K$ 与 $u_I$ 的符号被绑死，$K$ 一变 $u_I$ 就必须跟着变。

    * > **易错点**：选 $K>0$ 的乘法器又用原接法时，一个宽度 0.1 秒的正尖峰窜进来就会让这一级正反馈深度饱和并自锁。饱和时输出可达 15 V，此后即使输入回一个 $-1$ V 也拉不回负区，因为所需幅度已经超出正常输出范围——这不是稳态偏差，是没有回程。

    * 保护方案：在输出回路上串**二极管**，只让正的输出出去，负的被钳到 0，输出永远进不了饱和。

    ```text
      开方电路画完
        │
        ▼
      对输入有没有要求？
        │
        ├─ K < 0 ─────► 原接法成立，u_I 正负都收
        │
        ├─ K > 0 ─────► 改接法：反馈网络接到同相端（串联反馈）
        │
        └─ K > 0，不改接法
            └─ 必须约束 u_I < 0
                │
                ▼
      0.1 秒的正尖峰窜进来 → 正反馈深度饱和 → 自锁
                │  ✗ 靠加负的输入拉不回来
                ▼
      保护：在输出回路上串二极管 → 负的被钳到 0
      → 输出永远进不了饱和
    ```

    * 除方电路用同一个方法重复构造，设计时同样要保证负反馈成立。
    * 系统设计中 $K$ 的符号、$u_I$ 的符号、反馈网络的接点这三件事必须一起定下来并写清楚交给用户。

## 有源滤波器与仪表用放大器

* **有源滤波器**

    * 建立基础同样是虚短、虚断，把基本电路中的滤波电路加载到集成运放上构成。
    * 思想仍来自基本电路中的高通、低通、带通、带阻等滤波原理。
    * 分析时可以使用基电中的**拉普拉斯变换**。

* **二极管温度计引出的需求**

    * 二极管正向导通电压随温度变化，每 1℃ 约 10 mV，因此二极管的正向与反向特性都可以当作良好的温度传感器。
    * 思路：测出二极管两端电压的细微变化就知道温度，再把电压数字化，就是温度计的显示值。

* **传感器的三个物理特点**

    * 信号特别微弱。
    * 内阻一直在变：二极管两端的等效电阻就是其电压与电流之比，输出不同电压时阻值来回变化。
    * 输出用**差分方式**给出，因而带有共模分量。
    * 差分量可能远小于共模量：一个端子 1 V、另一个 1.01 V，有效值只有 $1.01 - 1 = 0.01$ V 即 10 mV。

    * > **结论**：仪表用放大器的三个刚需由此而来——放大微弱信号、大输入电阻、抗干扰（共模抑制比好）。这三条不是设计偏好，而是传感器的物理性质逼出来的。

* **三运放结构**

    * 同相端那一路**直接采**，反相端那一路先经过一个电压跟随器再采，于是两个输入端都获得大输入电阻。
    * 后面接一级差分放大输出 $u_{O1} - u_{O2}$，共模抑制全部由这一段完成。

    * 没有中间的 $R_2$ 时：$u_{O1} - u_{O2} = u_{I1} - u_{I2}$，本质只是两个跟随器，输入差模完全没被放大。
    * 有 $R_2$ 时：$u_A = u_{I1}$、$u_B = u_{I2}$，$R_1$、$R_2$、$R_1$ 三个电阻上流的是**同一个电流** $I = \dfrac{u_A - u_B}{R_2}$，由此得 $u_{O1} - u_{O2} = \left(1 + \dfrac{2R_1}{R_2}\right)(u_{I1} - u_{I2})$。
    * 共模输入时 $u_A = u_B = u_{iC}$，$R_2$ 与两个 $R_1$ 上都没有电流，整块电位相同，于是 $u_{O1} = u_{O2} = u_{iC}$。

    | 情形 | $R_2$ 上有无电流 | 差模 $u_{O1}-u_{O2}$ | 共模 $u_{O1}, u_{O2}$ |
    | :--- | :--- | :--- | :--- |
    | 差模输入 $u_{I1}\ne u_{I2}$ | 有，$I=\dfrac{u_A-u_B}{R_2}$ | $\left(1+\dfrac{2R_1}{R_2}\right)(u_{I1}-u_{I2})$，被放大 | 随输入 |
    | 共模输入 $u_{I1}=u_{I2}=u_{iC}$ | 无 | 为 0 | $u_{O1}=u_{O2}=u_{iC}$，未被放大 |

    * $R_2$ 在这里是画龙点睛而不是画蛇添足：差模被放大，共模一点没动。
    * > **易错点**：只学会解题意义不大，懂它**为什么**这样设计才有价值；看到一个好电路应记住它、在自己的设计中把它复用进去。

* **集成仪表放大器**

    * 芯片上出现的四个电容是最简单的**相位补偿**手段，用于抗自激振荡；先把它们扔掉不看，电路立刻还原成两个跟随器加上 $R_2$。
    * 带叉的那一端**绝不是输入端**，用它做输入端绝对得不到高输入电阻，输入必须从另一端进。
    * 芯片给了若干电阻供外部选接，不同接法对应不同差模增益。

    | $R_2$ 的接法 | 差模增益 |
    | :--- | :--- |
    | 6 与 7 直接相连 | 1 |
    | 2 连到 7 | 10 |
    | 3 连到 7 | 100 |
    | 4 的接法 | 1000 |

    * 板上还有去耦电容与输入级调整端，都是可以在外部调节的部分；倍数由用户自己按接法设定。

* **落到实物：电桥加仪表放大器加数字输出**

    * 仪表放大器取一个后先调零，量程从 $-50^\circ\text{C}$ 到 $+150^\circ\text{C}$、以 10 mV 对应 1℃ 时，信号范围为 $-0.5$ V 到 $+1.5$ V，再设定 10 倍放大倍数。
    * 调零用电桥上的 $RW$，在 0℃ 标定输出为 0；温度变化后输出正负变化。
    * 调比例这一级用**电压跟随器**：它不直接跟随输出，而是准确取到分压，因此对分压比没有影响。
    * 电压转数字有两条路：压频转换后接计数器，或直接用 A/D 转换。

    ```text
      二极管（10 mV/℃）
        │
        ▼
      电桥 ──► 仪表放大器（放大 10 倍，调零）
        │
        ▼
      跟随器级（调比例，不影响分压）
        │
        ├──► 压频转换 ──► 计数器 ──► 数字读出
        │
        └──► A/D 转换  ─────────────► 数字读出
    ```

## 正反馈与正弦波振荡电路

* **负反馈与正反馈两种工作环境**

    * 运放电路那一章的内容（运放及其运算放大、仪表用放大器、电荷转换器、有源滤波等）共同特点是运放工作在**负反馈**环境下。
    * 波形发生与转换中，运放工作在**开环或正反馈**条件下才能产生波形。

* **自激振荡的两副面孔**

    * 在负反馈放大电路的稳定性讨论中，负反馈若产生足够相移就会变成正反馈，正反馈产生自激振荡——不给任何输入信号它自己把信号加强，容易产生饱和、影响放大电路性能，那时它非常不好。
    * 在波形发生电路中，自激振荡成为波形发生的基础。

    * 框图上的差别只在**比较环节的符号变正**：正反馈版本把 $x_o$ 产生的 $x_f$ 送回净输入量 $x_i'$，形成闭环，只要 $|AF| \ge 1$ 这个环就能一直转下去。
    * 其中 $x_i'$ 起的是**点火**作用，类似汽车的启动马达；它不是永动机，因为 $x_o$ 仍有输出、电路有外接电源。
    * 若靠外部电源点火就谈不上波形发生器——函数发生器可以任意调频，不靠一堆电源。

* **起振：星星之火与选频**

    * 电路合闸瞬间，$x_i'$ 上必然出现一个杂乱无章的信号，反正会振一下，这就是起点。
    * 该连续波形做傅里叶变换后可分解成各种频率正弦信号的叠加，从 0 Hz 起都有，只是幅值有的大有的小。
    * 设计电路的思路是把目标频率（例如 10 kHz）从这一堆信号里选出来，并且**只有这一个频率使 $|AF| > 1$，其他频率的 $|AF| < 1$**。
    * 于是目标频率一圈圈被放大，其他频率一圈圈衰减，最后输出就是单一频率的正弦波。
    * 不加节制时它会飞快地奔着饱和区去，所以必须加稳幅电路把 $|AF|$ 拉回 1。

    * > **结论**：起振靠放大、维持平衡靠不变；前一阶段要求 $|AF| > 1$，后一阶段要求 $|AF| = 1$。

* **振荡条件：一个式子拆成两句话**

    * 总条件为 $\dot{A}\dot{F} = 1$，含义是 $x_i' = x_f$，即能维持这种振荡。

    | 条件 | 表达式 | 含义 |
    | :--- | :--- | :--- |
    | 幅值条件 | $\lvert AF\rvert = 1$ | 维持平衡；起振阶段要求 $\lvert AF\rvert > 1$ |
    | 相位平衡条件 | $\varphi_a + \varphi_f = 2n\pi$ | 环路中存在正反馈 |

    * $\varphi_a + \varphi_f$ 是 $x_f$ 与 $x_i'$ 之间的**相位差**；$|AF|$ 是 $x_f$ 与 $x_i'$ 的**模的大小之比**。
    * 稳定性讨论中希望 $|AF| < 1$（不振荡），现在为了让它振荡反而要 $|AF| > 1$。
    * 若 $\varphi_a + \varphi_f = 180^\circ$，转一圈回来 $x_f$ 与输入反相，反馈量削弱净输入量，环路由正反馈一跃而变为负反馈，不可能起振。
    * 能起振时 $\varphi_a + \varphi_f = 2n\pi$，即 0°、360°、720°……转回来相位相同。
    * 相位平衡条件的判别方法就是**判断电路中是否存在正反馈**。

* **正弦波振荡电路的组成**

    * 四个部分：放大电路（核心）、正反馈、选频电路、稳幅电路。
    * 各部分有时**共用**，例如正反馈与选频两个功能常结合在同一网络里。
    * 构成形式有 RC 振荡、LC 振荡和石英晶体振荡（晶振），基本原理类似。

    * > **提示**：框图中的 $A$ 不一定是开环放大电路，它指「提供稳定电压放大倍数这个功能的那一块」，可以是一个集成运放、分立元件电路，甚至是一个带负反馈的 10 倍、15 倍稳定比例放大电路。

* **选频靠谐振**

    * 选频一般用电路的**谐振**，LC 谐振有并联与串联两种，是最常用的手段。
    * 谐振电路品质因数越高，特性越尖、选择性越强。
    * 做 RLC 串联谐振实验时，品质因数很高则手动扫频几乎做不出来：只在谐振点指针骤然上冲、稍过一点马上摔跌；品质因数差一点时还能看到缓缓升起再落下。

* **判别起振的四步**

    | 步骤 | 检查什么 | 具体问法 |
    | :--- | :--- | :--- |
    | 第一 | 组成是否齐全 | 放大、正反馈选频、稳幅这几块在不在 |
    | 第二 | 功能是否齐全 | 放大电路能否正常工作、放大倍数是否稳定 |
    | 第三 | 是否存在正反馈 | 绕一圈是负反馈还是正反馈 |
    | 第四 | 能否起振 | 起振幅值条件 $\lvert AF\rvert > 1$ 是否成立 |

    * 第三步实质就是相位平衡条件：判断相位条件只要判断反馈极性。
    * RC 电路要求整个会分析；LC 电路只要求会用相位条件判别是否存在正反馈。

* **RC 桥式正弦波振荡电路**

    * 把电路割开看，右半部分就是一个带负反馈的**同相比例放大电路**，放大倍数为 $1 + \dfrac{R_f}{R_1}$，它就是框图里的 $A$。
    * 左半部分是**串并联 RC 选频网络**，它同时是反馈网络 $F$ 和选频网络，保证正反馈并且能把频率选出来。
    * $u_F$ 接在放大电路的同相（+）输入端，网络要求在某一频率上 $U_F$ 最大且与 $u_O$ 同相。

    * 定性理解：低频段容抗 $\dfrac{1}{\omega C}$ 很大，串联支路里只剩电容、并联支路里只剩电阻，整体表现为高通；高频段正好反过来，表现为低通。
    * 两段响应区间只重叠一小段，这个**交集**就是被选出的频段，因而天然成为带通；把带通做得很窄就成了选频。

    * 定量结果：

    $$\frac{U_F}{U_o} = \frac{R \parallel \dfrac{1}{j\omega C}}{\left(R + \dfrac{1}{j\omega C}\right) + \left(R \parallel \dfrac{1}{j\omega C}\right)}$$

    $$\frac{U_F}{U_o} = \frac{1}{3 + j\left(\omega RC - \dfrac{1}{\omega RC}\right)}$$

    * 该比值最大时虚部为零，得 $\omega_0 = \dfrac{1}{RC}$，此时 $\left.\dfrac{U_F}{U_o}\right|_{\max} = \dfrac{1}{3}$。
    * 其他频率都带虚部、都有相位差，$\varphi_A + \varphi_F \ne 2n\pi$，不构成正反馈。
    * > **结论**：$F$ 在 $\omega_0$ 处最多只能给出 $\dfrac{1}{3}$，因此要满足起振条件 $|AF| > 1$，放大电路那一级的电压放大倍数必须**大于 3**。

    ```text
       串并联 RC 选频网络（就是那个 F）

                u_o
                 │
            ┌────┴─────┐
            │   R   C  │     ← 串联支路
            └──┬─────||─┘
               │         │
               ●─────────┘
               │    u_f
           ┌───┴───┐
           │  R  ║ C│        ← 并联支路
           └───┬───┘
               │
              GND

       低频段：容抗大 → 串联剩电容、并联剩电阻 → 像高通
       高频段：容抗小 → 串联剩电阻、并联剩电容 → 像低通
       两段交集即为带通，ω₀ = 1/(RC) 处 U_F/U_o = 1/3 且相移为 0
    ```

    * 三件事凑齐即成正弦波振荡电路：取 $\omega_0 = \dfrac{1}{RC}$ 定出振荡频率，靠串并联 RC 网络在带通峰上同时给出最大增益与零相移，靠稳幅电路把起振后的 $|AF|$ 拉回 1。
