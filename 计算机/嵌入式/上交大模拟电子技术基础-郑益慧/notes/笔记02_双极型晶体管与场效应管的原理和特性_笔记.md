# 双极型晶体管与场效应管的原理和特性

## 双极型晶体管的结构

### 三个掺杂区域

* **双极型晶体管（Bipolar Junction Transistor，BJT）**

    * > **定义**：在一块半导体基材上做出三个不同掺杂区域、有三个电极引出的有源器件，因空穴和自由电子两种极性的载流子都参与导电而得名。

    * 名字里藏着两条信息：**"双极"**指多子和少子都参与导电；**"三极管"**指三个电极引出，所以又叫半导体三极管。
    * 半导体器件真正把"放大"这个悬在半空的问题顶下来，靠的就是它。

* **NPN 型的三层夹心结构**

    * 在一块硅片上依次做出 N 型发射区、P 型基区、N 型集电区。
    * N、P、N 两个交界面处必然各形成一个 PN 结。

    ```text
         发射区           基区              集电区
       ┌──────────┐     ┌────────┐      ┌────────────┐
       │   N 型    │     │  P 型  │      │    N 型    │
       │ 掺杂最高 │     │  极薄  │      │  面积最大  │
       └────┬─────┘     └───┬────┘      └──────┬─────┘
            │               │                  │
            ╎  发射结       ╎  集电结          ╎
            │               │                  │
       ─────┴───────────────┴──────────────────┴──────
         E                B                    C
    ```

* **三个区的分工**

    | 区域 | 引出的电极 | 字母 | 名字来源 | 本职工作 |
    | :--- | :--- | :--- | :--- | :--- |
    | 发射区 | 发射极 | E | emit，发射 | 发射载流子 |
    | 基区 | 基极 | B | base，基 | 控制 |
    | 集电区 | 集电极 | C | collect，收集 | 收集载流子 |

    * > **提示**：看上去三明治结构是对称的，倒过来用一样吗？不一样。发射区是载流子的"弹药库和源泉"，往外发；集电区干的是收集；基区是控制区域。功能截然不同。

* **三个区的工艺差异**

    * 发射区掺杂浓度是所有区域中最高的，它要往外发射载流子，得有丰富的载流子供它发射。
    * 集电区掺杂浓度不能过高，但面积要大——仓库太小、里面塞满东西，就没法收集了，所以要面积大且里面近似于空。
    * 基区掺杂浓度低且非常薄，薄是为了让绝大多数载流子能穿过去。

* **尺寸与浓度的数量级**

    * 发射区和基区是几微米量级，集电区是几百微米量级，差着两个数量级还多。
    * 掺杂浓度上，上面那个小的 N（发射区）比下面那个大的 N（集电区）高得多。

    ```text
        ①  整块硅片掺杂成 N 型区
     ┌──────────────────────────────────┐
     │           N 型衬区               │
     │  ┌────────────────────────────┐  │
     │  │     P 型基区（很薄）       │  │
     │  │  ┌──────────────────────┐  │  │
     │  │  │ 高浓度 N 型发射区     │  │  │
     └──┴──┴──────────────────────┴──┴──┘
        ②  上面敷硼，把这一块做成 P 型
                      ③  再做一层高浓度磷
    ```

### 两个结与符号判型

* **发射结**

    * > **定义**：基区与发射区之间形成的那个 PN 结，靠近发射区一侧，故按它靠近谁命名。

* **集电结**

    * > **定义**：基区与集电区之间形成的那个 PN 结。

    * 两个结的命名**从来不用"基区"**，因为两个结里都有基区参与。

* **符号判型：看发射结箭头**

    * > **结论**：箭头的方向就是发射结导通的方向；PN 结正向导通是从 P 指向 N，顺着箭头就能认出谁是 P、谁是 N。

    * **NPN 型**：基区在符号上是 P，发射区在下面、是 N，箭头由基区指向发射区即指向管外；外面两层自然是 N。
    * **PNP 型**：箭头反过来，发射区是 P、基区是 N、集电区是 P，箭头由发射区指向基区即指向管内。

    ```text
              NPN 型                            PPN 型

                C                                  C
                │                                  │
             ┌──┤                               ┌──┤
         B ──┤  │                           B ──┤  │
             └──┤                               └──┤
                │                                  │
                ▼   发射结箭头朝外                  ▲   发射结箭头朝内
                │                                  │
                E                                  E
    ```

    * > **提示**：两种符号唯一的差异就是箭头反过来。看到箭头朝外（朝发射极）是 NPN，看到箭头朝内（朝基极）是 PNP。

## 电流放大与能量来源

### 放大现象

* **电流放大倍数（$\beta$）**

    * > **定义**：在一定工作条件下，集电极电流与基极电流之比近似为一个不变的常数，这个常数叫电流放大倍数。

    $$\frac{I_C}{I_B} \approx \text{一个近似不变的常数}$$

    * 也就是说 $I_C$ 跟着 $I_B$ 变，是 $I_B$ 的放大。放大倍数为 100 时，$I_B = 10\ \mu\text{A}$ 对应 $I_C = 1\ \text{mA}$，$I_B = 20\ \mu\text{A}$ 对应 $I_C = 2\ \text{mA}$。

* **放大绝对不能失真**

    * 三极管是控制的核心元件，机理是通过控制一个能量的新变化来实现放大。
    * 放大的根本要求是保真：扬声器里传出的声音要和本人声音接近，传成唐老鸭的声音就是失真，全是啸叫就更是失真。

### 放大的是控制，不是能量

* **能量守恒视角**

    * 能量在转换过程中不会凭空冒出来，它只从一种转到另一种。
    * 被放大的那个大 $I_C$ 不是器件自己变出来的，它是用 $I_B$ 去控制电源，让电源的电流变成那样得来的。
    * 典型场合是话筒：麦克风把声音变成微弱电信号，经调制载波送出，小信号在甲乙类功放里变成基极电流 $I_B$，再在集电极变成放大的电流和功率。

* > **易错点**：把"电流放大"理解成器件自身把电流变大了。严格说它是控制了一个外部电源的能量，让那个能量跟着 $I_B$ 走。

## 放大的条件与偏置

### 正偏与反偏

* **正向偏置（正偏）**

    * > **定义**：给 PN 结加一个直流电压使它正向导通，就叫这个 PN 结正向偏置，简称正偏。

* **反向偏置（反偏）**

    * > **定义**：加反向电压使这个 PN 结截止，就叫反向偏置，简称反偏。

* **两个结的待遇不一样**

    * 在 NPN 型基本共射电路里，因为 $V_{CC}$ 肯定比 $V_{BB}$ 大，N 的电位高于 P，发射结正偏，集电结必然反偏。
    * 反过来讲，NPN 型要让集电结正偏必须是 P 比 N 高，现在的状况做不到。

### 基本共射放大电路

* **电路构成**

    * $V_{BB}$ 通过 $R_B$ 送进基极，作用是使发射结导通；$V_{CC}$ 加在集电极和发射极之间。

    ```text
              V_BB                            V_CC
                │                               │
               R_B                              │
                │      ┌────────┐               │
                ├──── B┤        │          C ───┤
                │      │  NPN   ├───────────────┤
                │      │        │               │
                └──── E┤        │               │
                       └────────┘               │
                            │                    │
                            └────────────────────┘
    ```

* **$R_B$ 是限流电阻**

    * 发射结导通大概只需 $0.6\ \text{V}$，若把 $1\ \text{V}$ 的 $V_{BB}$ 直接扔上去而不串 $R_B$，PN 结两端电压就达到 1 V，必须沿伏安特性曲线去找对应电流，那电流已到曲线的陡升段，结果是电源被灌电流、三极管损坏。
    * 串上 $R_B$ 后基极电流有上限：

    $$I_{B,\max} = \frac{V_{BB}}{R_B}$$

    * 不管发射结压降多小，最大就是 $V_{BB} / R_B$。

> **结论**：**发射结正偏、集电结反偏**——这就是三极管工作在放大状态的条件。

## 管内载流子运动三步

### 发射结正偏：扩散恢复

* 正偏的实质是把阻碍扩散的那道堤坝消灭掉，于是扩散运动开始正常工作。
* 发射区掺杂浓度高，是载流子的聚集区和源泉，大量自由电子向基区扩散形成 $I_{EN}$。
* 基区的多子是空穴，也向发射区扩散形成 $I_{EP}$。
* 两个电流一比差距太大：$I_{EP}$ 相对 $I_{EN}$ 近似于可以忽略，几乎整个电流都是 $I_{EN}$。
* 过去的数量与 PN 结上所加的正向电压相关：正向电压越大，过去的速度越快、过去的量越多。

### 基区：一面扩散，一面复合

* 刚越过发射结的电子大部队集结在基区靠发射结那一侧，但会继续向浓度低的方向即朝集电结扩散，因为那里浓度梯度摆着。
* 此时基区里扩散过来的非平衡少子比它原来的多子（空穴）还多得多，远大于它，基区里当家的是非平衡少子。
* 向集电结跑的过程中必然发生复合，因为这里是空穴的地盘。
* 基区的宽度和掺杂浓度决定了复合的百分比，这实质是个概率问题。100 个过来复合 2 个，河的另一侧就看到 98 个顺利冲过来、2 个被复合掉了。
* 基区整个掺杂浓度实际不变，你这边复合掉两个电子，基极马上抽走两个电子产生两个新的空穴：**这边复合，这边产生**。对外看效果等同于 2 个自由电子往基极方向跑、98 个往集电极方向跑。
* 基区在放大过程中干三件事：继续向集电结扩散、发生复合、在基极补充产生被复合掉的空穴。
* 复合比例近似固定还要求扩散推进速度近似不变，扩散速度跟浓度梯度相关，所以推到集电结旁边的电子必须被快速移走。

> **结论**：**如果基区足够宽、掺杂浓度足够高，所有扩散过来的自由电子都会被消灭，只有极少数能逃到集电结那边。** 而做基区的原则恰恰是薄且掺杂浓度低。

### 集电区：像抽水机一样抽走电子

* 集电结反偏意味着高电位到低电位，电场向下，而过来的是自由电子。
* 这个电场就像抽水机，把过来的自由电子迅速拉过来收集进集电区。
* 这样保证了两件事：基区里靠近集电结一侧的电子被及时抽走，浓度梯度维持正常；扩散的推进速度保持住。
* 集电结反偏本身会加大漂移运动，绝大部分漂移发生在集电区里，在那儿这不叫漂移而叫收集；集电区自己的少子自个儿在那儿玩漂移，形成的电流就是 $I_{CBO}$。

> **易错点**：**一旦反偏没有了就麻烦了。** 推进速度保证不了，$I_B$ 和 $I_C$ 的比例关系就保证不了，整个半导体跟个大导体似的、跟一个整体导通的 PN 结一样，里面没有任何控制，你会看到 $I_C$ 几乎不长了而 $I_B$ 还能不断增长——因为越慢复合得越多。

## 电流参数与放大系数

### 五个电流分量

| 符号 | 含义 | 地位 |
| :--- | :--- | :--- |
| $I_{EN}$ | 发射区自由电子注入基区的电流 | 由 $I_B$ 支配，做主流 |
| $I_{EP}$ | 基区空穴注入发射区的电流 | 与 $I_{EN}$ 差距太大，近似忽略 |
| $I_{BN}$ | 扩散进基区后被复合掉的那部分电流 | 由 $I_C$ 支配 |
| $I_{CN}$ | 到达集电结并被集电极收集的电流 | 与 $I_{BN}$ 成比例 |
| $I_{CBO}$ | 集电结的反向饱和电流 | 相当于一个 PN 结的反向饱和电流，很小 |

* 真正成比例的是 $I_{CN}$ 和 $I_{BN}$，其余都是小干扰因素。

### $I_{CBO}$ 与 $I_{CEO}$

* $I_{CBO}$ 相当于一个 PN 结的反向饱和电流，很小。
* **穿透电流 $I_{CEO}$** 是基极开路时 c 与 e 之间的电流。$I_B = 0$ 时正常应当 $I_C = 0$，但仍有一股小电流从这头穿过来，所以叫穿透电流。

### $I_B$ 的 KCL 与共射直流放大系数

* 围着基区做一圈割集做 KCL：

$$I_B = I_{EP} + I_{BN} - I_{CBO} - I_{CEO}$$

    * > **提示**：KCL 不只用在"一个点"上，割集形式的 KCL 一样能用，只要是闭合曲面都可以围着它列式。

* **共射直流放大系数 $\bar{\beta}$**

$$\bar{\beta} = \frac{I_{CN}}{I_{BN}} = \frac{I_C - I_{CBO}}{I_B + I_{CBO}} \approx \frac{I_C}{I_B}$$

    * 这里约掉了 $I_{CBO}$、$I_{CEO}$ 这些小项，还约掉了 $I_{EP}$——它跟 $I_{EN}$ 差距太大没法比。

* **交流电流放大系数 $\beta$**

$$\beta = \frac{\Delta I_C}{\Delta I_B}$$

    * > **易错点**：**直流 $\bar{\beta}$ 和交流 $\beta$ 不是一个东西**，一个讲直流、一个讲动态交流，数值也确实有点不一样。绝大多数情况下二者近似，所以后面干脆合二为一，全部用 $\beta$。

### 共基放大系数

* **共射（common emitter）**：共用发射极，比的是 $I_C$ 与 $I_B$，发射极在那儿摆着没参与。
* **共基（common base）**：基极作公共端，比的是 $I_C$ 与 $I_E$。
* **共基电流放大系数**

$$\bar{\alpha} \approx \frac{I_C}{I_E} = \frac{\bar{\beta}}{1 + \bar{\beta}}$$

    * 同样道理它也有交流的 $\alpha$，也是一对近似相等的情况。
    * 正常工作时 $I_C = \beta I_B$ 只是近似式，$I_B = 0$ 时 $I_C$ 并不为 0，而是 $I_{CEO}$。

## 共射特性曲线

### 两个端口

* 共用发射极之后，三极管天然劈成两个端口。

    ```text
            V_BB                      V_CC
              │                         │
             R_B                       R_C
              │                         │
              ├──── B   ┌──────┐   C ───┘
              │          │ NPN  ├────────┐
              │          └──────┘        │
              └──── E ───────────────────┤
              │                           │
              ▽                           ▽
             共用的发射极              回到参考电位

      输入端口 B–E ：I_B = (V_BB − U_BE) / R_B
      输出端口 C–E ：I_C = (V_CC − U_CE) / R_C
    ```

    * 输入端口上跑的是 $I_B$、$I_B$ 与 $U_{BE}$ 的关系叫**输入特性**；输出端口上跑的是 $I_C$、$I_C$ 与 $U_{CE}$ 的关系叫**输出特性**。
    * $I_B$ 这个环节是输入回路、$I_C$ 那个环节是输出回路：输入信号控制 $I_B$，$I_B$ 的变化控制 $I_C$ 的变化，再把 $I_C$ 变成能量的、功率的输出。
    * 研究输入特性是因为输入信号就加在这个端口上。

> **易错点**：研究变量之间的关系，**千万别三个变量一起变**。一个函数两个变量，总得先把其中一个固定成定值，所以研究输入特性时 $U_{CE}$ 一定取常数。

### 输入特性

* **形状就是 PN 结的伏安特性**

    * $I_B$ 对 $U_{BE}$ 就是 PN 结那样的曲线形状，它首先是一个曲线族，每条曲线对应一个 $U_{CE}$。
    * $U_{CE}$ 越小曲线越往左移，$U_{CE}$ 越大越往右移。
    * 当 $U_{CE}$ 大于 1 V 之后几乎不动，后面一大段全都重合——因为 $U_{CE} = 0$ 与 $U_{CE} = 1\ \text{V}$ 对集电结来说是两种状态，集电结就是用来把电子抽走的。

* **输入特性说明的事**

    * > **结论**：基极电流 $I_B$ 的大小受发射结电压 $U_{BE}$ 控制，$U_{BE}$ 变化 $I_B$ 就按这条曲线变化。

* **公式要读出物理意义**

    * 只会写不会讲没有实用价值：$\dot{U} = \dot{I}Z$ 意味着 $U$、$I$ 同频（不同频写不成相量），描述流经阻抗 $Z$ 的电流与阻抗两端电压的关系，大小上电压幅值是电流幅值乘阻抗的模，相位上电压超前电流一个阻抗角。
    * $C = \dfrac{\Delta q}{\Delta u}$ 一展开就知道哪里有电容、什么样的东西才该是电容。

    > **易错点**：学公式停留在"公式、公式推导"上就有问题了。电学的、物理的公式后面都拖着物理意义，要能把这个式子到底在讲什么物理说出来。

### 输出特性曲线族

* **定义与前提**

    * 输出特性是 $I_C$ 与 $U_{CE}$ 的关系，但它还受 $I_B$ 影响，所以做这件事时 $I_B$ 得等于常数。
    * 成比例的前提是发射结正偏、集电结反偏；有 $I_B$ 就说明发射结正偏，$U_{CE}$ 越大越向集电结反偏发展，$U_{CE}$ 很小的时候集电结根本不是反偏的，甚至可能正偏。
    * 所以 $U_{CE}$ 足够大时，$I_B$ 不变则 $I_C$ 几乎不变，曲线后面是平的；前面随 $U_{CE}$ 增大电流还要上涨。

    ```text
         I_C
          │    ───────────────────────────────────  I_B = I_B3
          │        ╭───────────────────────╯
          │    ───╭╯          ╭────────────────────  I_B = I_B2
          │      ╭╯      ╭───╯
          │    ──╯    ╭──╯        ╭────────────────  I_B = I_B1
          │         ╭──╯      ╭───╯
          │        ╭─╯    ╭───╯
          │   ╭────╯    ╭──╯
          │──╯   ╭─────╯························  I_B = 0
          └───────────────────────────────────────► U_CE
           ╰饱和区╯  ╰──────── 放大区 ─────────╯

       每条曲线过拐点之后压平，那一段就是放大区；
       左侧挤在一起的陡峭段是饱和区；最底下那条贴着轴的虚线是 I_B = 0。
    ```

    * 把 $I_B$ 从 $I_{B0}$ 一路画上去，放大区就被曲线覆盖成一片黑，记住输出特性**也是一个曲线族**。

### 三个工作区

* **放大区**

    * 发射结正偏、集电结反偏，$U_{CE}$ 较大，$I_C$ 与 $I_B$ 成比例，电流由 $I_B$ 决定，对外等效为受控放大。

* **截止区**

    * 特点是双结都反偏，其中控制的主要是发射结反偏，发射结一反偏相当于把水源关了，C 与 E 相当于断路。
    * 这条区上还有一股很小的电流，就是穿透电流 $I_{CEO}$。穿透电流越小越好，越小说明截止得越干净，$I_C$ 几乎为零就相当于 C 与 E 断开。
    * 创造方法：控制基极电位，让基极电位小于发射极电位。

* **饱和区**

    * 特点是双结正偏，$U_{CE}$ 非常小到集电结处于正偏状态，$I_B$ 与 $I_C$ 不成比例，$I_C$ 不受 $I_B$ 控制。
    * 集电结正偏意味着发射结、集电结都正偏，管子类似一个电阻导体，电流大小几乎由 $V_{CC} / R_C$ 决定。
    * 饱和压降 $U_{CES}$ 是个近似定值：硅管约 0.3 V，锗管约 0.1 V，相当于 C 与 E 之间开关的闭合。

* **三个区对照**

    | 工作区 | 发射结 | 集电结 | $U_{CE}$ | $I_C$ 与 $I_B$ | 电流由谁决定 | 对外等效 |
    | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
    | 放大区 | 正偏 | 反偏 | 较大 | 成比例，$I_C \approx \beta I_B$ | $I_B$ | 受控放大 |
    | 截止区 | 反偏 | 反偏 | — | 不成比例 | 极小，约 $I_{CEO}$ | C–E 断开 |
    | 饱和区 | 正偏 | 正偏 | 很小，约 $U_{CES}$ | 不成比例 | $V_{CC} / R_C$ | C–E 闭合 |

### 饱和的来历与状态判断

* **把 $I_B$ 一直加大**

    * 放大区内 $I_C$ 跟着 $I_B$ 一起长，但外电路给 $I_C$ 定了上限：

$$I_{C,\max} = \frac{V_{CC} - U_{CE}}{R_C}$$

    * $V_{CC}$、$R_C$ 是定值，$I_C$ 唯一能动的就是 $U_{CE}$ 在不断减小；哪怕 $U_{CE}$ 缩到 0，$I_C$ 也只能是 $V_{CC} / R_C$，到顶了就叫饱和。
    * 再往右加 $I_B$，$I_C$ 上不去而 $I_B$ 自己还照 PN 结的规律继续涨，这就是饱和——$I_B$ 说了不算，外面的电路决定通过电流。
    * 往机理里钻一层：集电结正偏后收集电子的功能没有了，只剩自由扩散，$I_B$ 和 $I_C$ 之间没有关系，$I_B$ 只和它自己那个端口的电压相关。

    ```text
       I_C
        │                    ┄┄┄┄┄ I_Cmax ┄┄┄┄┄┄┄┄┄┄
        │              ╭────── ─ ─ ─ ─ ─ ─ ─ ─ ─ ─
        │           ╭──╯   饱和：I_C 到顶，不再上升
        │        ╭──╯
        │      ╱  放大段：I_C ≈ β·I_B
        │    ╱
        │  ╱┆
        │╱ ┆  虚线段是这条直线往原点方向的线性外推，
        └┴──┆──────────────────────────────► I_B
        I_B0┆

       斜率就是 β；走到 I_Cmax 就压平。再往右加 I_B，
       I_C 上不去，而 I_B 自己还照 PN 结的规律继续涨——这就是饱和。
    ```

* **三步一比判工作状态**

    * 第一步算基极电流：$I_{B} = \dfrac{V_{BB} - U_{BE}}{R_{B}}$，其中 $U_{BE}$ 可近似为定值、上下有 0.1、0.2 这样的波动，与处理二极管一模一样，饱和时也不用重算。
    * 第二步算外电路规定的最大值：$I_{Cmax} = \dfrac{V_{CC} - U_{CES}}{R_{C}}$。
    * 第三步拿 $\beta I_{B}$ 去和 $I_{Cmax}$ 比。

    | 比较结果 | 含义 | 结论 |
    | :--- | :--- | :--- |
    | $\beta I_{B} < I_{Cmax}$ | $I_C$ 跟得上 | 工作在放大区 |
    | $\beta I_{B} \ge I_{Cmax}$ | $I_C$ 涨到头了 | 工作在饱和区，$I_C = I_{Cmax}$ |

    * 更快的一条捷径：一旦判断出发射结反偏，它就处于截止。

### 电子开关与光电器件

* **电子开关**

    * 让基极电位特别低就走截止、特别高（高到肯定大于集电极电位）就走饱和，管子就能在断开与闭合之间来回跳变。
    * 控制板输出的方波、矩形波过来，低电平时 C–E 断开，高电平时 C–E 相当于饱和闭合，外边接灯或接负载都行，取代了过去的机械控制方式。

    > **注意**：直接用 C 和 E 输出功率不大，不能直接接大负载，想控制灯这类东西要再加一级，可以用继电器——先控制继电器线圈，再用主触点给负载供电；一级不够还能再扩大一级。

* **光电三极管**

    * 内部是一个光电二极管加上一个晶体三管的电流放大，电流和光照成比例，功能比光电二极管更强。

* **光电耦合器**

    * 一边放一个发光二极管和它封在一起，电流的大小控制发光亮度，光照亮度又控制那边的电流。
    * 两边电气上完全绝缘、没有任何关系，例如测量 50 万伏高压上的信号就靠这种绝缘。
    * 再往前一步，中间换成光缆、光纤传输，光信号传递受干扰非常小——海底那么长的电信号基本传不过去，光信号就没问题。

### 极限参数与温度影响

* **极限参数**

    * 是指在什么样的电流下、什么样的电压下管子不会坏，是买管子的重要指标。
    * 极限参数越大容量越大，肯定越贵；设计电路时要回头算电阻功率，几欧姆的电阻其实很可怕：1 欧姆配 1 伏就是 1 W，2 伏就是 4 W，再往上就该变成电阻丝了。

* **温度对输入特性的影响**

    * 温度升高输入特性曲线左移；反过来读就是相同 $I_B$ 下温度升高会让发射结正向压降降低。
    * 数值上每升高 1 度、正向压降小 2 到 2.5 毫伏。硅管 $U_{BE}$ 约 600 毫伏，每度才动 2 到 2.5 毫伏，可见影响多小。

    ```text
       I_B
        │      ╱╱╱  高温（同一 I_B 下，U_BE 更小）
        │     ╱╱╱
        │    ╱╱╱        ╱╱╱  低温（同一 I_B 下，U_BE 更大）
        │   ╱╱╱       ╱╱╱
        │  ╱╱╱      ╱╱╱
        │ ╱╱╱     ╱╱╱
        │╱╱╱    ╱╱╱
        └────────────────────────► U_BE
    ```

* **温度对反向电流的影响**

    * $I_{CBO}$ 每升高 10 度翻一倍。

    > **易错点**：**这两个温度系数量级完全不同，别记混。** 正向压降是每度 2 到 2.5 毫伏；$I_{CBO}$ 是每 10 度翻一倍。

* **温度对输出特性的影响**

    * 温度升高整族曲线的 $I_C$ 都往上长，因为 $I_{CEO}$ 穿透电流会增大、$\beta$ 也会增大，真正受温度影响的主要就是这两个量。
    * 曲线并非理想水平，微微上倾：$U_{CE}$ 增大时 $I_C$ 还是要增大一点，只是幅度非常小，这个特性是真实存在、它是斜的；只是多数计算用近似看成 $I_C$ 与 $I_B$ 成比例。

## 场效应管的总论

### 与三极管的根本区别

* **场效应晶体管（Field Effect Transistor，FET）**

    * > **定义**：靠电场效应控制管子工作的晶体管，与三极管靠分配电流控制根本不同。

    * 三极管要 $I_C$ 有输出就必须牺牲一部分 $I_B$，而 $I_B$ 是要付出功率的地方——有电流就一定有电压，控制回路上要付出较大功率。
    * 电场效应几乎不取电流、几乎不付功率，输入电阻非常高，意味着信号源几乎不用出力就能把管子推动起来，级联时意义很大。

    | 对比项 | 晶体三极管 | 场效应晶体管 |
    | :--- | :--- | :--- |
    | 导电的载流子 | 多子和少子都在导电（双极型） | 只有多子参与导电 |
    | 输入端要付出的功率 | 要，有 $I_B$ 就得付功率 | 几乎不取电流，几乎不付功率 |
    | 输入电阻 | 相对较低 | 非常高 |
    | 温度稳定性 | 有少子参与，受温度影响比较大 | 好得多 |

* **功率是集成电路真正的瓶颈**

    * 场效应管最大的好处是不费电、消耗功率特别小。
    * 消耗功率一大，大规模集成时功率就成了瓶颈，集成度越高散热越难——早年的 386 旁边只要一个小风扇，现在 CPU 上要加大散热片、堆一个大风扇。
    * MOS 场效应管比晶体三极管晚了一两年提出，真正做出来晚了十年，是 1962 年，它的出现使电子技术产生了一次非常大的进步。

### 两大类

* **结型场效应管**

    * 一大类，靠 PN 结本身的反偏来控制沟道。

* **绝缘栅型场效应管**

    * 另一大类，栅极与谁都绝缘，制造于 1962 年。
    * 全称金属-氧化物-半导体场效应晶体管（MOSFET），简称 MOS 管；在它的基础上又造出了 CMOS 电路，BIOS 设置里的 CMOS 设置就是 CMOS 电路，它可以做存储一大堆东西且耗电量特别小。
    * 绝缘栅型使用得比较多，在很大的程度上可以替代结型的很多特性。

## N 沟道增强型 MOS 管

### 结构与命名对应

* **分层结构**

    * 一块掺杂浓度比较低的 P 型半导体作**衬底**，衬底上引出电极 **B**；衬底上扩散两个 N 型区，一个接电极 **S**（源极），另一个接电极 **D**（漏极）。
    * 两个 N 区上面是一层极薄的二氧化硅（绝缘体，就玻璃那玩意儿），二氧化硅上的基板引出 **G**（栅极）。
    * S 与 D 之间那层是沟道所在的区域。

    ```text
                            │  G  栅极（控制极）
             ┌──────────────┬─────────────┬───────────┐
             │      二氧化硅 SiO2          极薄、绝缘          │
             └──────────────┴─────────────┴───────────┘
             │              │             │           │
             ┌──────────────┬─────────────┬───────────┐
             │            n+            n+            │
             │            S 源           D 漏           │
             │                反型层（沟道）                 │
             └──────────────┴─────────────┴───────────┘
             │              │             │           │
             ┌──────────────┬─────────────┬───────────┐
             │                 P 型衬底（电极 B）            │
             └────────────────────────────────────────┘
    ```

    * 栅极孤零零趴在二氧化硅上跟谁都绝缘，G 上不可能有电流，所以省电——这就是"绝缘栅"的由来。

* **与三极管的电极对应**

    | MOS 管 | 晶体三极管 | 作用 |
    | :--- | :--- | :--- |
    | G（栅极） | B（基极） | 控制极 |
    | S（源极） | E（发射极） | 载流子的源泉、发源地 |
    | D（漏极） | C（集电极） | 载流子的漏出处 |

    * 名字像不等于原理像，这一点在原理部分会反复看到。

* **三极还是四极**

    * 绝缘栅型有两种构造：出厂时把源极和衬底接在一起，就形成三极；如果外面是四个极，衬底就是单独的。
    * 衬底单独时 D 和 S 可以互换、没有区别，不像 C 和 E 之间区别很大；连在一起时习惯上把和 B 连在一起的那个叫做源极 S。

### 耗尽层、反型层与开启电压

* **第一步：只加 $U_{GS}$**

    * 分析方法上多个变量不要一起动，先固定其余变量只扫一个，画出它的特性曲线，最后再把几条曲线放到同一张图上比较。
    * 所以先让 $U_{DS} = 0$，再加 $U_{GS} > 0$。

* **加栅压先变糟：耗尽层**

    * 自上而下的电场把附近的空穴全踢走，使这里变成几乎没有载流子的**耗尽层**，耗尽层变大。
    * 只加到这一步源漏之间仍然不导通。

* **继续加大栅压：反型层**

    * 底下区域很大、少子是自由电子，电场一方面把空穴全踢跑，另一方面把自由电子吸上去。
    * 自由电子聚起来就形成了沟道，像在两个水塘之间挖出一条渠——这道渠就是**反型层**，使得源漏之间导通；沟道里的多子是自由电子，所以是 **N 沟道**。

    ```text
    U_GS 还没加够                                         U_GS 继续加大

                   │  G  栅极                                            │  G  栅极
        ┌──────────┬─────────┬───────────┐                    ┌──────────┬─────────┬───────────┐
        │     二氧化硅 SiO2                  │                │     二氧化硅 SiO2                  │
        └──────────┴─────────┴───────────┘                    └──────────┴─────────┴───────────┘
        │          │         │           │                    │          │         │           │
        ┌──────────┬─────────┬───────────┐                    ┌──────────┬─────────┬───────────┐
        │        n+        n+            │                    │        n+        n+            │
        │        ~  ~  ~    耗尽层          │                 │        =========  反型层          │
        └──────────┴─────────┴───────────┘                    └──────────┴─────────┴───────────┘
        │          │         │           │                    │          │         │           │
        ┌──────────┬─────────┬───────────┐                    ┌──────────┬─────────┬───────────┐
        │            P 型衬底 B             │                 │            P 型衬底 B             │
        └────────────────────────────────┘                    └────────────────────────────────┘

    空穴被电场踢走，只剩耗尽层，            自由电子被吸到氧化层下面，
    源漏之间仍然不导通                      形成 N 型沟道，开始导通
    ```

* **开启电压 $U_{GS(th)}$**

    * > **定义**：沟道开始形成时对应的栅源电压，th 即 threshold（阈值）。

$$U_{GS} > U_{GS(th)} \quad \Longrightarrow \quad \text{沟道形成，D、S 之间导通}$$

    * $U_{GS}$ 小于 $U_{GS(th)}$ 时没有沟道，仍在绝缘状态，源漏之间没有电流。

* **沟道宽度就是被电压捏住的电阻**

    * $U_{GS}$ 越大沟道越宽、越小越窄，宽度实际上就由 $U_{GS}$ 决定。
    * 沟道越宽源漏之间的电阻越小、越窄越大、宽度不变则电阻不变，于是得到一个**可以用电压控制的可变电阻器**。
    * $U_{GS}$ 决定 $R_{DS}$：$U_{GS}$ 不变时表现为固定电阻，$U_{GS}$ 变时 $R_{DS}$ 也变；在 $U_{DS}$ 还没加的状态下，管子就是一个压控可变电阻器。

### 预夹断与恒流区

* **加上 $U_{DS}$**

    * 既然已经是阻值的东西，在电阻两端加电压自然就有电流：$I_D$ 就是 $I_{DS}$。
    * $U_{DS}$ 最小时表现为固定电阻，曲线是直线，斜率对应固定的 $U_{GS}$，记作 $U_{GS1}$。

* **沟道为什么先从靠漏极端变窄**

    * 决定沟道宽度的严格说是栅极与沟道某一点之间的电压，不是简单的 $U_{GS}$。
    * $U_{DS}$ 增大后，靠漏极那端与栅极的电压差变成 $U_{GS} - U_{DS}$，电压差变小这一端越来越窄，但在封死之前 $R_{DS}$ 几乎保持不变。
    * 当这电压差降到 $U_{GS(th)}$ 时：

$$U_{GS} - U_{DS} = U_{GS(th)}$$

    * 这就叫**预夹断**。

    ```text
    U_DS 很小                                   U_DS 增大                                     出现预夹断
                  │  G  栅极                                  │  G  栅极                                    │  G  栅极
        ┌─────────┬───────┬────────┐                ┌─────────┬───────┬────────┐                  ┌─────────┬───────┬────────┐
        │     二氧化硅                 │            │     二氧化硅                 │              │     二氧化硅                 │
        └─────────┴───────┴────────┘                └─────────┴───────┴────────┘                  └─────────┴───────┴────────┘
        │         │       │        │                │         │       │        │                  │         │       │        │
        ┌─────────┬───────┬────────┐                ┌─────────┬───────┬────────┐                  ┌─────────┬───────┬────────┐
        │       n+      n+         │                │       n+      n+         │                  │       n+      n+         │
        │       =========          │                │       ======             │                  │       ==== .             │
        │          沟道均匀            │            │          靠漏极端变窄          │            │          缝隙向源极端伸长        │
        └─────────┴───────┴────────┘                └─────────┴───────┴────────┘                  └─────────┴───────┴────────┘
        │         │       │        │                │         │       │        │                  │         │       │        │
        ┌─────────┬───────┬────────┐                ┌─────────┬───────┬────────┐                  ┌─────────┬───────┬────────┐
        │            P 型衬底 B       │             │            P 型衬底 B       │               │            P 型衬底 B       │
        └──────────────────────────┘                └──────────────────────────┘                  └──────────────────────────┘

    两端压差 = U_GS            靠漏极端压差                   压差降到 U_GS(th)
    沟道均匀，R_DS 不变        = U_GS - U_DS，沟道变窄        这一端沟道失效
    ```

* **预夹断为什么不会真夹断**

    * 它不会真的断掉：一旦断了没电流，这块就没压降了；没电流没压降，缝隙马上又打开，所以它是一个自动平衡的状态。
    * 这里并没有真的夹断，画着像断了实际上只留了一个非常小的缝隙，是关不断的。

* **恒流区**

    * 再加大 $U_{DS}$，缝隙会变长，代价是 $R_{DS}$ 变大，而 $I_D$ 几乎不变——增加的电压都去抵抗增加的电阻了，于是近似出现恒流。
    * 机理上还能再补一句：电流一小，缝隙与电流的关系就变化，自由电子在窄缝里高速通过使缝隙电阻增大，这个增大正好与电压的增大抵消，形成自动平衡。
    * 这时电流 $I_D$ 只和 $U_{GS}$ 相关；$U_{GS2} > U_{GS1}$ 时 $R_{DS}$ 更小、斜率更大，曲线在上面；$U_{GS3}$ 更小则曲线在下面。

    ```text
         I_D
         ↑
         │
         │
         │               ###########################################   U_GS2
         │             ###
         │            ##
         │          ###
         │         ##    +++++++++++++++++++++++++++++++++++++++++++   U_GS1
         │        ##   +++
         │       ##  +++
         │     ###++++    ..........................................   U_GS3
         │    ##+++   .....
         │  ##+++......
         │ #+.....
         │....
         └──────────────────────────────────────────────────────────→  U_DS

         每条曲线对应一个固定的 U_GS。从原点到预夹断点是一段直线，
         对应可变电阻区；预夹断之后曲线几乎水平，那就是恒流区。
    ```

    * > **易错点**：**别在可变电阻区里就说"$U_{GS}$ 和 $I_D$ 成比例"。** 那个区域里不是单一比例关系，$U_{GS}$ 和 $U_{DS}$ 共同决定 $I_D$；只有恒流区里 $U_{GS}$ 自己在决定 $I_D$。这就是为什么放大一定要工作在恒流区。

### 三个工作区域

* **判据与表现**

    | 工作区域 | 判据 | 管子表现 | 我们拿它做什么 |
    | :--- | :--- | :--- | :--- |
    | 截止区 | $U_{GS} \le U_{GS(th)}$ | 沟道没形成，D、S 之间没有电流 | 开关的断开态 |
    | 可变电阻区 | $U_{GS} > U_{GS(th)}$，且 $U_{GS} - U_{DS} > U_{GS(th)}$ | 表现为由 $U_{GS}$ 决定的电阻 $R_{DS}$ | 压控可变电阻 |
    | 恒流区 | $U_{GS} - U_{DS} \le U_{GS(th)}$ | $I_D$ 几乎只由 $U_{GS}$ 决定 | 放大 |

    * 电阻不变是对某个固定 $U_{GS1}$ 而言的，$U_{GS}$ 一变这个电阻就变，所以这一段是可变电阻区。

* **增强型这个命名的出处**

    * "N 沟道"是因为它把自由电子吸上去形成 N 沟道。
    * "增强型"指一定得有 $U_{GS} > U_{GS(th)}$ 这个增强过程才能导通——这是它和结型不同的地方，结型是天生导通的。

* **看符号读名字**

    * 增强型符号漏、源之间画虚线，表示沟道天生断开、需要增强；栅极那一竖永远是断开的，这就是绝缘栅。
    * 符号上标 P 就说明沟道是 P 型的，是 P 沟道增强型 MOS 管。
    * 符号里的箭头指向的是 **PN 结方向**：沟道是 N 型、衬底是 P 型，一看箭头就知道是 N 沟道；三极管里 B 与 E 之间的箭头也是指 PN 结方向。

### 耗尽型 MOS 管

* **让栅压还没加就有沟道**

    * 结型不用加电压一样导通、天生就能导通，绝缘栅也能做到，办法就是在二氧化硅里预先埋设固定正电荷。
    * 二氧化硅里天生固定一大堆正电荷、天然带正电，带正电就有电场，强大到让沟道天生产生。

    ```text
    增强型：沟道天生断开              耗尽型：沟道天生存在
          │  G                              │  G
    ┌──────┬────────┐                 ┌──────┬────────┐
    D ─ · · · · · ─ S                 D ─────────────── S
    └──────┴────────┘                 └──────┴────────┘
          │  B                              │  B

    源漏之间是虚线，要靠 U_GS                 源漏之间是实线，不用增强
    增强，超过 U_GS(th) 才有沟道              天生就有沟道
    ```

* **夹断电压 $U_{GS(off)}$**

    * $U_{GS}$ 加正向电压沟道变大，加反向电压沟道变小；加到某一个负电压时沟道才真正没有，这个电压叫**夹断电压**。

$$U_{GS} < U_{GS(off)} \quad \Longrightarrow \quad \text{沟道夹断，管子真正关断}$$

    * 只要 $U_{GS}$ 大于 $U_{GS(off)}$ 管子就一直属于开通可用，没截止，所以 $U_{GS}$ **既可以是正的也可以是负的**。
    * 其他用法与增强型一样：把 $U_{GS(th)}$ 换成 $U_{GS(off)}$，三个工作区域的判据照旧，只是默认状态从"天生断开"变成"天生导通"；符号上源漏之间画实线。

## 结型场效应管

### 结构与工作原理

* **结构**

    * 中间是一整块 N 型衬底（它本身就是源极与漏极之间的导电沟道），在 N 的两面各扩散一个高浓度 P 区（P+ 表示高浓度 P 掺杂），一头接 S、一头接 D，两个 P 接在一起向上引出栅极 G。

    ```text
                      G
            ┌─────────┴─────────┐
            │                   │
        ┌───┴────┐         ┌────┴───┐
        │   │ P+ │         │ P+ │   │
    D ──┤   └────┘ N 沟道  ┌────┘   ├── S
        │                           │
        └───────────────────────────┘
    ```

* **加反压把沟道夹窄**

    * 栅源之间为零电压时中间这个 N 是导通的，源漏之间就能导通，天生就有沟道。
    * 在 $U_{GS}$ 上加负值使 PN 结反偏，反偏越厉害耗尽层越宽，夹在中间的沟道就越窄，加到某个程度的反压就会出现**夹断**。
    * 与耗尽型 MOS 管很接近：那个是由自由电子构成的沟道、加反压变小，这个是用 PN 结来夹。

    ```text
          U_GS = 0           U_GS < 0          U_GS = U_GS(off)
       ┌────────────┐     ┌────────────┐     ┌────────────┐
       │            │     │▓▓▓      ▓▓▓│     │▓▓▓▓▓▓▓▓▓▓▓▓│
       │   沟道     │     │   沟道     │     │  （夹断）  │
       └────────────┘     └────────────┘     └────────────┘
        D          S       D          S       D          S
    ```

* **真夹断而不是预夹断**

    * > **结论**：只要你 $U_{GS}$ 不变沟道就不变，固定为某一个 $U_{GS}$ 沟道就固定住了；夹断电压叫 $U_{GS(off)}$。**这个是真夹断，不是预夹断——夹断以后中间就不导电了。**

* **接上漏源电压**

    * 预夹断之前是**可变电阻区**：$U_{GS}$ 不变电阻就不变、$U_{GS}$ 变电阻就变，$U_{DS}$ 与 $I_D$ 成正比 $I_D = \dfrac{U_{DS}}{R_{DS}}$。
    * 出现预夹断之后 $I_D$ 电流不再变化而出现恒流，这时 $I_D$ 只和 $U_{GS}$ 相关，这就是**恒流区**。
    * 除结型原理之外，沟道大小、恒流的出现、可变电阻区都与耗尽型完全一样。

### 与耗尽型 MOS 管的唯一本质差别

* **栅压取值范围**

    * 结型场效应管规定 $U_{GS}$ 可以大于 $U_{GS(off)}$ 但**不能大于 0**。
    * 原因是 $U_{GS} > 0$ 就使 PN 结直接导通，结型管子就不存在了、双结导通、没有沟道这些东西，所以它一定要反偏让 PN 结反向截止。
    * 结型反偏时 $R_{GS}$ 依然非常高，只不过比绝缘栅低一些，它最多有一点点反偏的漏电流、反偏的饱和电流；绝缘栅的更狠，根本几乎没有电流。

    > **易错点**：**从特性曲线看，结型场效应管的 $U_{GS}$ 不能跨越正负**（N 沟道全为负、P 沟道全为正），**而耗尽型 MOS 管的 $U_{GS}$ 是可以跨越正负的**。这是判断一颗管子最直接的一条线索。

* **谁也替代不了谁**

    * 结型输入电阻没有绝缘栅型高，也不能用于 $U_{GS} > 0$ 的区域（N 沟道如此，P 沟道正好反过来），但它有一点漏电流、不大容易坏。
    * 绝缘栅管的二氧化硅特别薄，栅极没有很好保护时感应电荷就能把它击穿：那电容很小，有一点点电量就会产生很高的电压，电压不用很高就会产生很强的电场把薄层击穿，所以绝缘栅管子很娇贵。
    * 绝缘栅有很多保护措施，所以也不存在谁完全替代谁的问题。

## 场效应管的特性曲线与参数

### 转移特性

* **转移特性（transfer characteristic）**

    * > **定义**：在 $U_{DS}$ 取某个定值（且大到使管子工作在恒流区）时，$I_D$ 与 $U_{GS}$ 之间的关系曲线。

    * 场效应管有三个极本该有两根曲线，但栅极这个端口压根没有电流，出不了输入特性，所以用的是转移特性。
    * $I_{D0}$ 是当 $U_{GS}$ 等于两倍 $U_{GS(th)}$ 时所对应的点。

    ```text
       I_D
        │                          ● I_D0（U_GS = 2U_GS(th)）
        │                      ／
        │                  ／
        │              ／
        │          ／
        │      ／
        │  ／
      0 └──────────────────────────── U_GS
        U_GS(th)
    ```

* **成立的前提**

    * 场效应管一定工作在恒流区、$U_{DS}$ 要足够大，否则 $I_D$ 实际受两个东西控制：由 $U_{GS}$ 决定的 $R_{DS}$ 和 $U_{DS}$ 本身的大小，因为 $I_D = U_{DS} / R_{DS}$。
    * $U_{DS}$ 必须是恒定值，$U_{DS}$ 一变这条曲线也跟着变。

    > **提示**：这根转移特性曲线最大的前提就是从恒流区取出来的。

* **耗尽型的转移特性**

    * 耗尽型可以既到这面又到那面，因为它天生有沟道、$U_{GS} = 0$ 就已经导通；这一段里 $I_D$ 与 $U_{GS}$ 的关系跟上面一样，只是把 $I_{D0}$ 换成 $I_{DSS}$。

### 电流方程

* **电流方程**

$$I_D = I_{D0}\left(\frac{U_{GS}}{U_{GS(th)}} - 1\right)^2$$

    * 只管 $U_{GS} \geq U_{GS(th)}$ 那一段，也就是曲线上已经起来的那一段。
    * 耗尽型那一段用同一个方程，把 $I_{D0}$ 换成 $U_{GS} = 0$ 时对应的饱和漏极电流 $I_{DSS}$。

### 输出特性的几个区域

* **输出特性定义**

    * > **定义**：一族 $I_D$–$U_{DS}$ 曲线，每条曲线对应一个固定的 $U_{GS}$，与三极管的输出特性是同一个路子。

* **四个区域**

    * **可变电阻区**：$U_{GS}$ 固定时导通电阻固定，可以当作一个压控电阻来用。
    * **恒流区**：用来做放大，想让它放大就得把工作点放在恒流区。
    * **夹断区**：可以作为开关，相当于断路。
    * **击穿区**：这是结型特有的，$U_{DS}$ 再继续大会把 PN 结击穿，所以结型管子的曲线上后面还跟着一段击穿区。

### 四类管子怎么从曲线上认出来

* **辨认判据**

    | 器件 | $I_D$ | $U_{GS}$ 的范围 | 认它的判据 |
    | :--- | :--- | :--- | :--- |
    | N 沟道结型 | 正 | 全为负 | PN 结不能导通，$U_{GS}$ 只能取负；后段还有击穿区 |
    | P 沟道结型 | 负 | 全为正 | 同理反向，$I_D$ 是负的 |
    | N 沟道增强型 MOS | 正 | 必须 $U_{GS}>U_{GS(th)}$ | 天生断开，超过开启电压才成沟道 |
    | P 沟道增强型 MOS | 负 | 反向对称，$U_{GS(th)}$ 取负 | 同上反向 |
    | N 沟道耗尽型 MOS | 正 | 可跨越正负 | 天生有沟道，$U_{GS}=0$ 处为 $I_{DSS}$ |
    | P 沟道耗尽型 MOS | 负 | 可跨越正负 | 同上反向 |

* **大区别怎么分**

    * 结型的区域很明显，要么 $U_{GS}$ 全正、要么全负。
    * 绝缘栅型有两种：耗尽型 $U_{GS}$ 会跨越正负；增强型一定得大于一个开启电压，是"开启"的、不是夹断的。
    * 增强型天生是断的，阈值是开启电压；结型和耗尽型天生有沟道，得反着加电压让它夹断。

### 直流与交流参数

* **直流参数**

    * **开启电压 $U_{GS(th)}$**：增强型 MOS 管的参数。
    * **夹断电压 $U_{GS(off)}$**：结型和耗尽型两种天生有沟道的管子都用它。
    * **饱和漏极电流 $I_{DSS}$**：耗尽型和结型在 $U_{GS} = 0$ 时对应的 $I_D$。
    * **直流输入电阻 $R_{GS(DC)}$**：MOS 管的值大于 $10^9\ \Omega$（1000 兆以上）。这个数量级才叫绝缘，拿摇表测绝缘时大于 500 兆欧就认为绝缘了，它比这还高。

* **跨导（低频跨导，$g_m$）**

    * > **定义**：在 $U_{DS}$ 取常数时，$I_D$ 的变化量与 $U_{GS}$ 变化量之比。

$$g_m = \left.\frac{\Delta I_D}{\Delta U_{GS}}\right|_{U_{DS} = \text{常数}}$$

    * 它就是转移特性曲线上某一点的**切线斜率**。
    * 这样写的道理：小交流信号一定是在静态的某一点上做震荡，想知道小信号之间的关系只要知道这一点上的斜率就够了；交流信号不能再像求直流电阻那样求，而要看这一点上 $\Delta$ 与 $\Delta$ 之间的关系，这就是动态等效，在场效应管里因为它是电流比电压所以叫电导。

* **极间电容**

    * 有三个电容，每两个极之间都有电容，等效出来的电容大约都是皮法级。
    * 出现高频时这些会出事情——高频下它就相当于极间电容导通了。

### 构成放大电路的思路

* **三极管的思路**

    * 小信号进来后设法让它影响 $I_B$，让 $I_B$ 变化并不需要花很多力气，只要管子工作在放大区，这个变化的 $I_B$ 就变成同样形状的、强大的 $I_C$ 输出出来。

    ```text
    三极管：  小信号 → I_B  变 → （放在放大区）→ I_C 变 → 输出
    场效应管：小信号 → U_GS 变 → （放在恒流区）→ I_D 变 → 输出
    ```

* **场效应管的思路**

    * 第一步先把管子弄在恒流区里，转移特性体现的正是 $U_{GS}$ 对 $I_D$ 的控制。
    * 让小信号去影响 $U_{GS}$，$U_{GS}$ 变化就产生 $I_D$ 的变化，再把 $I_D$ 输出出去。

* **大电流从哪里来**

    * 你能得到比较大的 $I_D$ 是因为外面有直流电源，能得到比较大的 $I_C$ 是因为 $V_{CC}$ 搁在那儿；本质上都是用小的控制量去控制一个大的直流电源所提供的功率输出。
