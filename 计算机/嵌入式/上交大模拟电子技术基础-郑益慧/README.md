# 上海交通大学：模拟电子技术基础（郑益慧）

上海交通大学郑益慧老师的《模拟电子技术基础》，按国内模电主流教材的章节顺序完整讲授。课程从半导体二极管与 PN 结的物理基础出发，经双极型晶体管与场效应管，进入放大电路的构成、性能指标与分析方法，再依次讲基本放大电路的组态、多级放大与频率响应、集成运算放大电路、功率放大、反馈、信号的运算与处理、波形发生与信号转换，最后收在直流电源上，是典型的「器件—放大—反馈—应用」四段式模电主线。

- **原视频**：https://www.bilibili.com/video/BV1Gt411b7Zq — Bilibili，BV1Gt411b7Zq
- **52 集**，已产出 11 册模块全书、13 篇复习笔记、49 份逐字稿

## 怎么学

- **器件打底** → 模块 01、02 讲 PN 结、双极管与场效应管，后面每一册的分析方法都建立在器件特性曲线上，这两册必须先啃透
- **放大电路的分析范式** → 模块 03、04 建立「先算静态工作点、再用小信号模型求增益与输入输出电阻」的通用套路，共射/共集/共基三种组态的差异就在这套范式里比较
- **频率与集成运放** → 模块 05、06 把多级放大、频率响应与集成运放串起来，运放的两条理想化结论（虚短、虚断）是全课使用频率最高的工具
- **反馈是分水岭** → 模块 08 的负反馈四类型判断与深度负反馈计算，决定了后面几册的电路为什么能那样设计，务必按笔记 09、10 的分类逐条对照着过
- **应用与收尾** → 模块 09~11 讲信号运算、波形发生与直流电源，配合 `notes/` 里 13 篇按考点切分的笔记，考前直接按题型速查
