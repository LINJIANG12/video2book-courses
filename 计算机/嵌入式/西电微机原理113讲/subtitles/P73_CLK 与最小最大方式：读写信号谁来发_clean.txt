### 时钟周期与总线周期

[04:17] 任何 CPU 工作的速度，都是以时钟的一个周期作为最小节拍来运行的。

对于 8086 CPU 而言，CPU 执行一条指令时，如果该指令需要对外部存储器进行读/写，或者从外部 I/O 端口进行读/写，就必须要用到外部总线。CPU 执行这类指令占用外部总线的时间，称为**总线周期**。

[04:59] 一个基本的总线周期同样是以 CLK 周期来衡量的。

课堂板书绘制的时钟波形是非常理想的方波，实际产生的时钟如果用示波器去测波形，并没有这么规整。8086 CPU 是以时钟的下降沿同步工作的。

- 第一个时钟周期称为 $T_1$ 状态；
- 随后依次为 $T_2$、$T_3$、$T_4$ 状态。

在正常情况下，CPU 执行一条总线读写指令要花费这么长时间。这段时间就称为一个**基本的总线周期**（包含 $T_1, T_2, T_3, T_4$）。

[06:24] 有基本的总线周期，就有非基本的总线周期。非基本的总线周期是指在 $T_3$ 结束后并不直接进入 $T_4$，而是在 $T_3$ 之后插入等待周期 $T_w$，这种总线周期即为带等待周期的总线周期。

# 8086 微处理器总线复用时序与总线控制

### 多处理器系统与总线控制权 [00:00]

在微处理器之外，系统中是否还存在其他的处理器？两个及以上处理器构成的系统，就是多处理器系统。但在多处理器系统当中，系统总线只有一组，包括数据总线、地址总线和控制总线，它们只有一组。

那么在多处理器系统当中，哪个处理器在工作？哪个处理器负责管理总线？这就存在一个问题：当 CPU 以外（即微处理器以外）的外部处理器需要工作并使用总线时，外部处理器必须先向微处理器 CPU 请求总线使用权、发出总线请求申请。

只有当 CPU 将总线让出来之后，外部处理器才能接管总线，进而对挂载在总线上的存储器和 I/O 接口进行读写和管理。

CPU 将总线让出来，具体指的是 CPU 的所有输出引脚都呈现第三态（高阻态），与外部电路隔离，从而把总线控制权出让。当然，CPU 将总线让给外部处理器时，CPU 会通过应答信号通知外部处理器：总线已经让出。也就是说，外部处理器向 CPU 提出申请：“我想使用总线”；CPU 将总线让出后做出回答，请求与回答构成了一对握手信号。

* **工作时钟上限**：第一代 8086 微处理器的最高主频限制为 **$5\text{ MHz}$**。
* **IBM PC 选频考量（$4.77\text{ MHz}$ 的物理成因）**：
  在初代 IBM PC 中，主处理器采用与 8086 同代的准 16 位处理器 8088。其标准系统时钟未采用满额的 $5\text{ MHz}$，而是设定为约 **$4.77\text{ MHz}$**。
  * **设计依据**：讲师经推算指出，该特定频率直接受制于**串行异步通信**的波特率发生需求。在当时的时钟分频硬件条件下，只有在 $4.77\text{ MHz}$ 工作频率下进行分频，串行通信在接收/发送每一帧（Frame）数据时，各采样点累计下来的**每帧积累误差最小**，从而保证串行通信的可靠性。
* **代际架构演进**：
  * **8086-2**：工艺改进版，工作频率提升至 **$8\text{ MHz}$**。
  * **80186 的历史断档**：80186 推出时正值国内改革开放初期（约 1980~1981 年）。因当时国内技术引进存在滞后周期，在消化吸收 8086/8088 后直接跨越引进 80286，导致 **80186 在国内工控及微机领域出现断档**。
  * **80286**：基准主频 $8\text{ MHz}$。主板引入硬件 **Turbo 键（加速键）**，按下后可将运行频率倍频切换至 **$16\text{ MHz}$**。
  * **80386**：工作主频跃升至 **$33\text{ MHz}$**。
  * **80486**：主频达到 $66\text{ MHz}$，最高达到 **$80\text{ MHz}$**（最低工作频率达到 80MHz 等不同规格）。
  * **奔腾系列（586 级）**：586 命名为奔腾（Pentium 1 即为 586），其后延续为奔腾 2、奔腾 3、奔腾 4。
  * **架构拐点**：奔腾 4 之后未出现“奔腾 5”，而是转向多核架构（双核、四核，目前实验室及国内自主研发处于 8 核研究阶段）。

### 2.2 总线周期（Bus Cycle）时序原理与状态划分

#### 2.2.1 最小时间基准与触发沿
* **节拍基准**：CPU 内部及外部所有操作均以时钟输入引脚 CLK 的一个周期作为最小物理工作节拍，称为 **$T$ 状态（$T$ 周期）**。
* **同步触发机制**：对于 8086 CPU 而言，内部逻辑与外部总线操作严格以 **CLK 的下降沿（Falling Edge）** 作为同步基准触发采样与状态转换。

#### 2.2.2 总线周期分类与 TW 边界
当 8086 CPU 执行一条涉及访问外部存储器（读/写）或外部 I/O 端口（输入/输出）的指令时，必须占用外部总线，这一完整的外部操作过程定义为一个**总线周期（Bus Cycle）**。

```text
CLK  ──┐    ┌───┐    ┌───┐    ┌───┐    ┌───┐    ┌───
       │    │   │    │   │    │   │    │   │    │   
       └────┘   └────┘   └────┘   └────┘   └────┘   
       ^        ^        ^        ^        ^
       │  T1    │  T2    │  T3    │ (TW)   │  T4    │
       下降沿   下降沿   下降沿   下降沿   下降沿   下降沿
```

* **基本总线周期**：标准无等待操作由 **4 个连续的时钟周期** 构成，依次定义为 **$T_1$ 状态、$T_2$ 状态、$T_3$ 状态、$T_4$ 状态**。
* **非基本总线周期（带等待周期的总线周期）**：
  * **触发条件**：外设或存储器响应速度较慢，未能在预定时间内准备好数据。
  * **插入边界**：在 **$T_3$ 状态结束之后，严禁直接跳入 $T_4$ 状态**，而必须在 $T_3$ 与 $T_4$ 之间插入一个或多个 **$T_W$（Wait State，等待状态）** 周期，直至数据就绪再进入 $T_4$ 完成周期收尾。

### 2.3 工作模式选择引脚（$\text{MN}/\overline{\text{MX}}$）及其架构影响

8086 CPU 通过外部硬件连线决定其运行模式，该控制引脚为 **$\text{MN}/\overline{\text{MX}}$**（第 33 引脚）：
* **高电平（$+5\text{V}$ / 逻辑 1）**：CPU 锁定工作于**最小方式（Minimum Mode）**。
* **低电平（接地 $\text{GND}$ / 逻辑 0）**：CPU 锁定工作于**最大方式（Maximum Mode）**。

#### 模式差异 1：引脚 24~31 的双重语义重构
依据教材图 5.5，当 $\text{MN}/\overline{\text{MX}}$ 状态改变时，第 24 脚至第 31 脚的功能定义发生完全置换：
* **最小方式下**：引脚直接映射为单处理器系统所需的控制输出信号（如第 29 脚为 $\overline{\text{WR}}$，写控制信号）。
* **最大方式下**：引脚功能变更为右侧括号内定义的多处理器协调与状态信号（第 24~31 脚功能重构，其中 26、27、28 脚转变为状态输出引脚 $\overline{S_0}, \overline{S_1}, \overline{S_2}$）。

### 2.4 读写控制总线生成架构：直出架构 vs. 8288 译码架构

#### 2.4.1 最小方式：CPU 硬件引脚直接驱动
在最小方式下，微处理器直接驱动外设总线：
* **写控制信号 $\overline{\text{WR}}$（第 29 引脚）**：当 CPU 对外部存储器或 I/O 端口执行写入操作时，该引脚直接由 CPU 内部逻辑拉低至**低电平有效**。
* **读控制信号 $\overline{\text{RD}}$（第 32 引脚）**：执行读操作时，直接由引脚输出**低电平有效**信号。

#### 2.4.2 最大方式：多处理器仲裁与 8288 总线控制器译码
在多处理器系统中（CPU 数量 $\ge 2$），系统全局仅存在**唯一一组共享物理总线**（数据总线、地址总线、控制总线）。
* **总线使用权仲裁协议**：
  * 主 CPU 默认拥有总线主导权。外部从处理器若需访问总线，必须预先向微处理器发出总线占用申请。
  * 主 CPU 在让出总线时，通过握手协议向申请者发出应答通知，并**强制将其自身的所有输出引脚切换至“高阻态”（第三态，浮空隔离）**，在电气层面脱离总线连接。
* **8288 总线控制器介入推导**：
  因 CPU 部分引脚重构为状态输出，外部读写控制信号不再由 8086 CPU 引脚直出，必须由外挂专用芯片 **8288 总线控制器** 辅助生成：
  1. 8086 的第 28、27、26 引脚分别定义为 **$\overline{S_2}, \overline{S_1}, \overline{S_0}$** 状态输出端，与 8288 的输入端对应相连。
  2. CPU 依据当前执行的操作，在这三根状态线上输出 3 位二进制状态码（从 `000` 到 `111` 共 8 类状态组合）。
  3. 8288 内部译码电路对状态码进行硬件译码，并在其专用输出管脚上生成对应的低电平有效控制脉冲。

#### 8288 译码映射关系（依据教材表 5.4）：
* **存储器读操作**：
  * 8086 输出状态码 $\overline{S_2}\overline{S_1}\overline{S_0} = \mathbf{101}$。
  * 8288 译码激活输出端 **$\overline{\text{MRDC}}$**（Memory Read Command，存储器读命令，低电平有效）。工程及系统总线上常记作 **$\overline{\text{MEMR}}$**。
* **存储器写操作**：
  * 8086 输出状态码 $\overline{S_2}\overline{S_1}\overline{S_0} = \mathbf{110}$。
  * 8288 译码激活输出端 **$\overline{\text{MWTC}}$**（Memory Write Command，存储器写命令，低电平有效）。工程上常记作 **$\overline{\text{MEMW}}$**。
* **I/O 端口读操作（如执行 `IN` 指令）**：
  * 8086 输出状态码 $\overline{S_2}\overline{S_1}\overline{S_0} = \mathbf{001}$。
  * 8288 译码激活输出端 **$\overline{\text{IORC}}$**（I/O Read Command，低电平有效）。工程上常记作 **$\overline{\text{IOR}}$**。
* **I/O 端口写操作（如执行 `OUT` 指令）**：
  * 8288 译码激活输出端 **$\overline{\text{IOWC}}$**。工程上常记作 **$\overline{\text{IOW}}$**。

### 2.5 引脚分时复用与系统地址总线形成电路设计

#### 2.5.1 分时复用引脚的时序切分机理
8086 为节约芯片管脚，大量采用了分时复用（Time-Multiplexed）机制：
* **$\text{AD}_0 \sim \text{AD}_{15}$（第 16~2 脚及第 39 脚，共 16 根）**：
  * **$T_1$ 状态**：引脚作为地址总线使用，输出 20 位物理地址中的低 16 位地址信息 **$A_0 \sim A_{15}$**（地址包）。
  * **$T_2 \sim T_4$ 状态**：引脚转变为双向数据总线，用于传输 16 位数据 **$D_0 \sim D_{15}$**（若与 8 位外设交互，则依据偶地址/奇地址使用 $D_0 \sim D_7$ 或 $D_8 \sim D_{15}$）。
  * **$T_1$ 态之前**：引脚电平为未定义的浮动状态（虚线表示）。
* **$A_{16}/\overline{S_3} \sim A_{19}/\overline{S_6}$（共 4 根）**：
  * **$T_1$ 状态**：引脚输出 20 位物理地址中的高 4 位地址信息 **$A_{16} \sim A_{19}$**。
  * **$T_2 \sim T_4$ 状态**：引脚转变为 CPU 内部状态输出线 **$S_3 \sim S_6$**。

#### 2.5.2 状态位 $S_3 \sim S_6$ 的物理语义（$T_2 \sim T_4$ 期间）
* **$S_6$**：恒定输出低电平（固定为 0，无实际功能）。
* **$S_5$**：程序状态字（PSW）中**中断允许标志位（$\text{IF}$）的状态镜像**。若当前 $\text{IF}=1$，则 $S_5$ 输出高电平；若 $\text{IF}=0$，则输出低电平。
* **$S_4, S_3$ 组合编码**：指示当前总线周期所访问的内存单元所对应的**段寄存器类型**（教材表 5.1，如组合为 `00` 时指向附加段寄存器 `ES`）。*(讲师明确标定：此概念属“了解”级，考试绝不涉及)*。

#### 2.5.3 地址锁存控制信号（ALE）的电气行为
为从复用线上剥离出稳定可靠的系统地址，CPU 必须提供一个用于捕获 $T_1$ 态地址的时序标尺信号——**$\text{ALE}$（Address Latch Enable，地址锁存使能）**：
* **稳态**：平时维持低电平。
* **触发机制**：总线周期开始时，在 **$T_1$ 状态内跃升为高电平**，允许外部锁存器采样；在 **$T_1$ 周期即将结束的瞬间，产生陡峭的下降沿（Falling Edge）**。

#### 2.5.4 74LS373 构建系统地址总线硬件工程实现（重中之重）
* **核心需求推导**：
  * 8086 物理地址线宽为 20 位（$A_0 \sim A_{19}$）。
  * 单片 74LS373 为 8 位三态锁存器，锁存容量为 8 位。
  * 锁存器数量计算：$20 \div 8 = 2.5 \implies$ **必须采用 3 片 74LS373**（2 片提供 16 位，容量不足）。

```text
               +------------------- 8086 CPU -------------------+
               |                                                |
               |   ALE ───────────────────────────┐             |
               |                                  │             |
               |   AD0 ~ AD7 ──────────┐          │             |
               |                       │          │             |
               |   AD8 ~ AD15 ─────────┼──────┐   │             |
               |                       │      │   │             |
               |   A16/S3 ~ A19/S6 ────┼──────┼───┼─────────┐   |
               +───────────────────────┼──────┼───┼─────────┼───+
                                       │      │   │         │
             ┌─────────────────────────┘      │   │         │
             │                                │   │         │
             ▼                                │   │         │
       +-----------+                          │   │         │
       | 74LS373(1)|                          ▼   │         │
       |    低位   |                    +-----------+       │
AD0~7 ─┤D0~7   Q0~7├── A0~A7     AD8~15 ┤D0~7   Q0~7├── A8~15
       |           |                    | 74LS373(2)|       │
       |  G    OE# |                    |    中位   |       │
       +--▲-----▲--+                    +--▲-----▲--+       │
          │     │                          │     │          ▼
          │     │     ┌────────────────────┴─────┼──── +-----------+
          │     │     │                          │     | 74LS373(3)|
          │     └─────┼──────────────────────────┴─────┤    高位   |
          │           │                          ┌─────┤D0~3   Q0~3├── A16~A19
          │           │                          │     | (D4~7 悬空|
          │           │                          │     |   未说明) |
          │           ▼                          │     |  G    OE# |
          │          GND (恒定输出使能)          │     +--▲-----▲--+
          └──────────────────────────────────────┴────────┼─────┘
                                                          │
                                     ALE ─────────────────┘
```

* **电路引脚级接线规范**：
  1. **输出使能端（$\overline{\text{OE}}$）控制**：将 3 片 74LS373 的 $\overline{\text{OE}}$（Output Enable）引脚并联，直接**焊接接地（GND）**，强制使其内部三态门恒定导通，保持锁存数据的持续输出。
  2. **锁存使能端（$G$）控制**：将 3 片 74LS373 的选通端 $G$（Gate）并联，统一连接至 8086 CPU 的 **$\text{ALE}$ 引脚**。
  3. **数据输入与地址输出映射**：
     * **低位片（74LS373 #1）**：输入端 $D_0 \sim D_7$ 连接 CPU 的 $\text{AD}_0 \sim \text{AD}_7$；输出端 $Q_0 \sim Q_7$ 形成系统低位地址线 **$A_0 \sim A_7$**。
     * **中位片（74LS373 #2）**：输入端 $D_0 \sim D_7$ 连接 CPU 的 $\text{AD}_8 \sim \text{AD}_{15}$；输出端 $Q_0 \sim Q_7$ 形成系统中位地址线 **$A_8 \sim A_{15}$**。
     * **高位片（74LS373 #3）**：仅使用其低 4 位输入端 $D_0 \sim D_3$，连接 CPU 的 $A_{16}/\overline{S_3} \sim A_{19}/\overline{S_6}$；低 4 位输出端 $Q_0 \sim Q_3$ 形成系统高位地址线 **$A_{16} \sim A_{19}$**。*(注：该片未使用的 $D_4 \sim D_7$ 端处理视频中讲师未说明)*。
* **物理锁存过程时序追溯**：
  * 在 $T_1$ 期间，$\text{ALE}$ 处于高电平时，$G$ 端有效，74LS373 输出端 $Q$ 跟随输入端 $D$ 实时变动，20 位物理地址信息穿透锁存器。
  * 当 $T_1$ 即将结束、$\text{ALE}$ 由高电平跳变为低电平（下降沿）的瞬间，当前输入端上的 $A_0 \sim A_{19}$ 瞬间被**硬件冻结并锁存在 74LS373 内部寄存单元**。
  * 步入 $T_2 \sim T_4$ 状态后，尽管 CPU 的复用引脚电平翻转变为数据信号或状态信号，系统总线侧的 $A_0 \sim A_{19}$ 依然由 373 的 $Q$ 端持续稳定锁存输出，为外部存储器/外设提供了贯穿整个总线周期的稳定物理寻址信号。

## 3. 核心技术方案横向对比矩阵

### 3.1 8086 最小工作模式 vs. 最大工作模式

| 维度 | 最小工作模式 (Minimum Mode) | 最大工作模式 (Maximum Mode) |
| :--- | :--- | :--- |
| **硬件模式控制（$\text{MN}/\overline{\text{MX}}$）** | 接 $+5\text{V}$（逻辑 1 / 高电平） | 接 $\text{GND}$（逻辑 0 / 低电平） |
| **适用系统拓扑架构** | 单处理器系统（独立单微处理器） | 多处理器系统（$\ge 2$ 个处理器并行协同） |
| **引脚 24~31 功能特征** | 直接提供基本控制信号（如第 29 脚输出 $\overline{\text{WR}}$） | 功能完全重构，提供状态码输出与多机握手信号 |
| **控制总线驱动源** | **8086 CPU 引脚直接输出驱动** | **外接专用 8288 总线控制器译码驱动** |
| **读/写控制信号产生机制** | CPU 依据总线周期内部直接置位 $\overline{\text{RD}}, \overline{\text{WR}}$ | CPU 经 26~28 脚输出 $\overline{S_2},\overline{S_1},\overline{S_0}$ 状态码，8288 译码产生控制信号 |
| **总线争用与让出机制** | 无需复杂仲裁（仅单 CPU 独占） | 支持从处理器请求总线；CPU 让出总线时引脚呈现**高阻态（第三态）**并握手应答 |
| **典型控制信号名称** | $\overline{\text{RD}}$、$\overline{\text{WR}}$ | $\overline{\text{MRDC}}$ ($\overline{\text{MEMR}}$)、$\overline{\text{MWTC}}$ ($\overline{\text{MEMW}}$)、$\overline{\text{IORC}}$ ($\overline{\text{IOR}}$)、$\overline{\text{IOWC}}$ ($\overline{\text{IOW}}$) |

### 3.2 基本总线周期 vs. 带等待状态（$T_W$）的总线周期

| 对比维度 | 基本总线周期 (Basic Bus Cycle) | 带等待状态的总线周期 (With Wait States) |
| :--- | :--- | :--- |
| **时钟周期（$T$ 状态）数量** | 固定为 **4 个** 时钟周期（$T_1, T_2, T_3, T_4$） | **$> 4$ 个** 时钟周期（$T_1, T_2, T_3, n \times T_W, T_4$） |
| **插入时机与边界** | 无插入状态，各状态严格时序递进 | **在 $T_3$ 之后、$T_4$ 之前** 插入 $T_W$ 等待周期 |
| **触发物理成因** | 外部设备/存储器响应速率满足 CPU 时序节拍要求 | 外部设备/存储器存取时间较慢，无法在 $T_3$ 结束前完成数据交换 |
| **总线信号维持期** | 数据总线在 $T_2 \sim T_4$ 维持有效 | 数据与总线控制信号顺延跨越整个 $T_W$ 周期直至 $T_4$ |

## 4. 实战工程反模式、避坑清单与考点边界

### 4.1 常见工程反模式与避坑清单

* **反模式 1：在 $T_2 \sim T_4$ 态直接从 $\text{AD}_0 \sim \text{AD}_{15}$ 读取外部寻址地址**
  * **后果**：系统崩溃。进入 $T_2$ 后引脚逻辑状态已彻底蜕变为数据总线，此时直连获取的为内存数据而非地址代码。
  * **防御设计**：必须严格依赖 $\text{ALE}$ 下降沿通过硬件锁存器（74LS373）在 $T_1$ 结束瞬间将地址固化，后续总线寻址只能从 373 的输出端（$Q$ 端）引出。
* **反模式 2：系统地址总线形成电路中 74LS373 选型片数不足（仅用 2 片）**
  * **后果**：低估 8086 的 1MB 寻址空间需求。2 片 74LS373 仅能锁存 16 位地址（$64\text{ KB}$ 寻址），缺失高 4 位段寻址物理线。
  * **防御设计**：尽管高位片仅消耗 4 个锁存通道，亦必须配备第 3 片 74LS373 负责锁存 $A_{16} \sim A_{19}$，确保完整的 20 位物理地址总线。
* **反模式 3：74LS373 输出使能端（$\overline{\text{OE}}$）浮空或受不当控制逻辑干预**
  * **后果**：74LS373 输出端呈现高阻态，系统地址总线信号断路，外部存储芯片无法被选通。
  * **防御设计**：在地址总线形成专职电路中，3 片 74LS373 的 $\overline{\text{OE}}$ 必须牢固**接地（GND）**，强制使输出三态门常开。
* **反模式 4：最大方式下误认为 CPU 引脚可直出 $\overline{\text{RD}} / \overline{\text{WR}}$**
  * **后果**：控制线无信号。最大方式下对应引脚已被改构为状态输出或总线应答，直连外设将无法产生任何读写选通。
  * **防御设计**：最大方式下必须在系统板上配置 8288 总线控制器，并由 8288 译码产生标准的总线读写命令（$\overline{\text{MRDC}}, \overline{\text{MWTC}}, \overline{\text{IORC}}, \overline{\text{IOWC}}$）。
