## 核心原理深度推导

### 1. 双重循环模型与比较次数边界推导

在无序序列的排序任务中，设待排序元素总数为 $n$。本课讲授的起泡排序在物理结构上呈现“自顶向下两两比较、极值沉底”的执行过程：

#### （1）内循环（Inner Loop）的动态缩减性
- **第 1 趟内循环**：
  - 参与排序的元素个数为 $n$。
  - 两两相邻单元比较次数为 $n - 1$ 次。
  - 比较结果：单趟将序列中的绝对极值（讲师板书示例中为“最小值 $54$”）通过连续比较与交换，沉降至缓冲区最底部。
- **第 2 趟内循环**：
  - 底部已固化 $1$ 个极值，剩余未排序元素个数为 $n - 1$。
  - 两两相邻单元比较次数为 $(n - 1) - 1 = n - 2$ 次。
  - 比较结果：找到次极值（板书示例为 $67$）并沉降至已固化极值之上。
- **第 $k$ 趟内循环**：
  - 剩余未排序元素个数为 $n - k + 1$。
  - 内循环比较次数为 $(n - k + 1) - 1 = n - k$ 次。
- **边界条件（最终趟）**：
  - 剩余未排序元素仅剩 $2$ 个时，内循环比较次数为 $2 - 1 = 1$ 次。

#### （2）外循环（Outer Loop）的上限推导
- 每执行一趟内循环，必然且仅能固化一个极值到其最终物理位置。
- 当经过 $n - 1$ 趟内循环后，已固化 $n - 1$ 个元素的位置。
- 根据排他性边界条件，序列中仅剩的最后 $1$ 个元素必然已在正确的全局有序位置上，无需再进行自身比较。
- **结论**：外循环最大执行次数（最坏情况轮数）严格满足：
  $$\text{Outer\_Loops}_{\max} = n - 1$$

### 2. 讲师板书实例：5 个数据完整执行轨迹追踪

讲师以 $n = 5$ 的整数数据集合为例，演示“从低到高”排序（物理呈现为将小数值逐步交换沉降至缓冲区底部，大数值上浮）：

```text
【初始乱序状态及前序状态】
经第 1 趟循环后：经 4 次比较，最小值 54 已沉至最底部。
剩余 4 个未排好序的元素参与第 2 趟。

【第 2 趟排序推导：剩余 4 个数，需比较 4 - 1 = 3 次】
• 比较 1：相邻单元比较，上方单元数值低于下方单元，触发交换，70 沉降至下一单元。
• 比较 2：70 与其下一单元比较，70 数值高、对方数值低，保持现状不交换。
• 比较 3：67 与 80 比较，80 高、67 低，触发交换，67 沉降至底部缓冲区（位于 54 上方）。
• 固化结果：次小数 67 就位，底部已排定区间为 [67, 54]。

【第 3 趟排序推导：剩余 3 个数，需比较 3 - 1 = 2 次】
• 比较 1：两两比较，上方单元数值高于下方单元，不交换。
• 比较 2：70 与下一个单元（80）比较，80 顶上去，70 沉下来，触发交换。
• 固化结果：次次小数 70 沉底就位，底部已排定区间为 [70, 67, 54]。

【第 4 趟排序推导：剩余 2 个数，需比较 2 - 1 = 1 次】
• 比较 1：两两比较，两单元无需交换。
• 固化结果：次小数沉降就位，全局全序达成。
• 最终排定序列：[..., 70, 67, 54] 整体有序。
```

### 3. 工程性能优化：自适应“交换标志位（Flag）”机制

#### （1）工程缺陷溯源（反模式）
在固定执行 $n - 1$ 趟外循环的传统设计中，若输入数据为“原本有序”或“在第 $m$ 趟（$m < n-1$）已提前完全有序”，CPU 仍会机械执行剩余 $(n - 1 - m)$ 趟外循环，进行大量无交换的冗余访存与比较操作，导致执行效率严重劣化。

#### （2）数学判据与防御性重构
- **全序判据定理**：在某一趟内循环中，若历经该趟所有两两相邻元素比较后，**未发生任何一次数据交换**，则可充分且必要地判定当前未排序列已呈现单调有序。
- **寄存器级实现方案**：
  引入通用寄存器 `BL` 作为状态交换标志位：
  1. **初始化**：在每一趟内循环启动前，显式置零：
     $$\text{BL} \leftarrow 0$$
  2. **脏标记（Dirty Flag）触发**：在单趟内循环比较中，一旦满足交换条件并执行了数据对调，立即将 `BL` 写入状态标记：
     $$\text{BL} \leftarrow -1 \quad (\text{机器码表示为 } \text{0FFH})$$
  3. **外循环决策点检测**：单趟内循环完成退出后、进入下一趟外循环之前，执行基准比对：
     $$\text{CMP } \text{BL}, 0$$
     - 若 $\text{BL} = 0$：表明整趟比较内未发生任何对调，全序已成立，直接执行跳转指令提前终止排序（Break Outer Loop）。
     - 若 $\text{BL} \neq 0$：表明本轮仍有无序逆序对被调整，重置外层环境，进入下一趟循环。

### 4. 汇编程序架构与寄存器分配推导

讲师在设计程序流程图时，确立了以下寄存器初始化与映射规范：

1. **图形化元标准**：
   - **开始框图元**：必须严格规范使用**椭圆框**（Oval），禁止错用矩形处理框。
2. **循环计数器拓扑配置**：
   - **外层循环计数器**：分配寄存器 `CH`。
     $$\text{CH} \leftarrow n - 1$$
   - **内层循环计数器**：分配寄存器 `CL`。
     - 每趟内循环前，通过 `CH` 动态赋值：
       $$\text{CL} \leftarrow \text{CH}$$
     - 依据：每完成一趟外循环，`CH` 递减 $1$，使得后续内循环次数 `CL` 动态递减，天然契合剩余元素减少的数学边界。
3. **数据缓冲区基址寻址**：
   - **基址指针**：分配源变址寄存器 `SI`。
   - 装载待排序数据缓冲区的首地址偏移量（`offset BUFFER`），作为后续两两取数比较的寻址基准。
4. **存储单元定义**：
   - 连续存储区域命名为 `BUFFER`（讲师以 `BUFFER 1` 单元开始示意寻址空间）。

### 2. 忽略数据预有序状态的空转缺陷（架构反模式）
- **错误表现**：硬编码执行 $n-1$ 趟外循环，缺失状态感知能力。
- **讲师警示**：“如果这个时刻序都排好了，那再做这几遍是不是白做了？再要数据效率就低了！”
- **防御方案**：引入 `BL` 作为 Dirty Flag。内循环前清零，发生对调置 `0FFH`，内循环结束检测为 0 立即 break。

### 3. 内外循环计数器解耦失当（时序反模式）
- **错误表现**：内循环比较次数写死为固定值，或者未利用外循环寄存器联动。
- **防御方案**：必须利用外循环控制变量更新内循环初值（`CL = CH`），确保每固化一个极值，内循环的比较范围边界收缩 1 位。

## 1. 知识拓扑框架

```text
x86 汇编冒泡排序（降序 / 由高到低）
│
├── [1] 初始化阶段 (外层进入)
│   ├── 外层循环计数器配置：CH = N - 1（视频示例 N=6, CH=5）
│   └── 外层循环入口 [标号 D]
│       ├── 内层循环计数器重置：CL = CH（动态缩减比较轮次）
│       ├── 指针/首地址初始化：SI = OFFSET BUFFER1 (或 LEA SI, BUFFER1)
│       └── 交换标志清零：BL = 0（默认本轮有序）
│
├── [2] 内层核心比较与交换体 [标号 C]
│   ├── 取当前基准数：AL = [SI]
│   ├── 相邻单元比较：CMP AL, [SI+1]
│   ├── 排序方向判定（降序规则）：
│   │   ├── 若 AL >= [SI+1] (JAE) ──> 分支跳过：不交换，直接跳转至参数调整
│   │   └── 若 AL < [SI+1] ────────> 触发交换：
│   │       ├── XCHG AL, [SI+1] （原子置换下个单元）
│   │       ├── MOV [SI], AL    （写回当前单元）
│   │       └── MOV BL, -1      （置换标志改写，标记本轮发生逆序）
│   └── 步进与参数调整 [标号 A]
│       └── 指针自增推进：SI = SI + 1 (INC SI)
│
├── [3] 循环控制与双重终止判定
│   ├── 内层轮次判决 [标号 B]
│   │   ├── CL = CL - 1 (DEC CL)
│   │   ├── CL == 0 ?
│   │   │   ├── NO ──> 跳转回标号 C（继续本轮相邻对比较）
│   │   │   └── YES ─> 本轮内层遍历结束，进入外层状态核验
│   │
│   └── 外层状态核验与提前退出
│       ├── 交换标志判定：BL == 0 ?
│       │   ├── YES ──> [提前退出] 全程无逆序，排序已完全成立
│       │   └── NO ───> 发生过交换，序列仍不稳定：
│       │       ├── CH = CH - 1 (DEC CH)
│       │       └── CH == 0 ?
│       │           ├── YES ──> [自然退出] 最大轮次耗尽，排序完成
│       │           └── NO ───> 跳转回标号 D（重置 CL/SI/BL，开启新一轮）

```

## 2. 核心原理深度推导与板书架构演进

### 2.1 算法物理目标与数学约束
* **排序目标**：降序排列（由高至低，High to Low）。
* **有序条件**：对于任意有效地址索引 $i$（对应首地址偏移行量），满足：
  $$\text{BUFFER1}[i] \ge \text{BUFFER1}[i+1]$$
* **逆序触发条件**：若 $\text{BUFFER1}[i] < \text{BUFFER1}[i+1]$，则破坏降序定义，必须就地发生数值置换（Swap）。

---

### 2.2 寄存器架构映射与职责分配
讲师在板书中对 8086 通用寄存器进行了严格的分工解耦：

| 寄存器 | 硬件位宽 | 逻辑角色 | 物理功能与状态机演进 |
| :--- | :--- | :--- | :--- |
| **CH** | 8-bit | 外层循环计数器 | 记录剩余的最大大轮次。初值设为 $N - 1$；每完成一轮内循环且未提前终止时减 1。 |
| **CL** | 8-bit | 内层循环计数器 | 记录当前轮次中剩余的相邻两两比较次数。每轮外循环开始时由 `CH` 同步复制（`CL = CH`），每比对一组减 1，减至 0 为止。 |
| **SI** | 16-bit | 源变址/寻址指针 | 充当动态“手指”（移动指针），承载被比对元素的有效基地址，利用变址寻址方式（`[SI]` 与相对寻址 `[SI+1]`）访问相邻单元。 |
| **AL** | 8-bit | 数据操作/累加器 | 暂存当前变址单元的数值，参与 `CMP` 算术标志位影响及参与双单元 `XCHG` 数据中转。 |
| **BL** | 8-bit | 交换状态标志位 | 标志序列是否已经排好。每轮内循环前强制置 `0`；一旦发生两数交换则置为 `-1`（即十六进制 `0FFH`）。 |

---

### 2.3 状态机流转与边界推导逻辑

#### 步骤一：初始化流水线（外层循环装载）
1. **外层总轮次建立**：将待排数组长度 $N$ 的递减基准赋给 `CH`：
   $$\text{CH} \leftarrow N - 1$$
   *注：视频中讲师以 $N = 6$ 为例，明确指出此时外层次数 $N - 1 = 5$。*
2. **标号 D（新一轮外循环入口）**：
   * 同步内循环计数器：$\text{CL} \leftarrow \text{CH}$。此设计的边界意义在于：每一轮外循环都会将当前未排序区间的最大/最小值“下沉/上浮”至边界，下一轮无需重复核验已就位元素，比较次数随 `CH` 动态递减。
   * 指针复位：$\text{SI} \leftarrow \text{OFFSET BUFFER1}$（使用 `LEA SI, BUFFER1` 将数组首地址装入 SI）。
   * 状态旗标初始化：$\text{BL} \leftarrow 0$。

#### 步骤二：内层两两比对状态机（标号 C）
1. **数据提取**：将当前单元内容载入累加器：
   $$\text{AL} \leftarrow [\text{SI}]$$
2. **状态判定**：执行指令比较：
   $$\text{CMP AL}, [\text{SI}+1]$$
   执行算术减法：$[\text{SI}] - [\text{SI}+1]$，仅改变标志寄存器（CF、ZF、SF 等），不破坏 `AL`。
3. **条件转移抉择（降序逻辑）**：
   * **条件成立（无须交换）**：若当前数据 **高于或等于** 下一单元内容（$\text{AL} \ge [\text{SI}+1]$），执行无符号数条件转移指令 `JAE`（Jump if Above or Equal）。
     * 执行路径：直接跃过交换代码块，跳至指针步进段。此时 `BL` 保持原始状态不变。
   * **条件不成立（触发逆序交换）**：即 $\text{AL} < [\text{SI}+1]$，控制流穿透至交换指令组：
     * **指令 1**：`XCHG AL, [SI+1]`
       * *效应*：下一单元的值进入 `AL`；原当前单元的值被安全写入下一单元。
     * **指令 2**：`MOV [SI], AL`
       * *效应*：将换入 `AL` 的较小值写入当前变址单元 `[SI]`。
       * *结果证明*：通过仅有的一组寄存器 `AL` 配合 `XCHG` + `MOV`，以两条指令在内存与寄存器间彻底实现相邻单元原地（In-Place）交换。
     * **指令 3**：`MOV BL, -1`
       * *效应*：明确记录“本轮发生了倒序置换”，撤销提前收敛的前提。

## 5. 反模式与踩坑清单

在讲师的现场构建和强调中，暴露了以下几种汇编级算法实现的工程反模式：

### 5.1 标志位未在外层内部及时复位（State Leakage 反模式）
* **反模式表现**：将 `MOV BL, 0` 放置在标号 `D` 外部（即与外层 `MOV CH, N-1` 放在一起初始化）。
* **物理后果**：一旦第一轮循环触发了交换（`BL` 被覆写为 `-1`），在后续的所有外层轮次中，`BL` 将永久保持 `-1`。
* **危害**：算法彻底失去**自适应提前退出（Early Exit）**能力，即使数组在第 2 轮已完全有序，仍将被迫跑满全部 $N-1$ 轮，造成总线与 CPU 算力的空耗。

---

### 5.2 内存到内存直接搬运的语法陷阱（Direct Memory-to-Memory Trap）
* **反模式表现**：试图直接使用类似 `CMP [SI], [SI+1]` 或在置换时使用 `MOV [SI], [SI+1]`。
* **硬件底线**：x86 CISC 体系架构严苛禁止在一条常规数据处理指令中同时出现两个存储器操作数（Double Memory Operands Exception）。
* **防御机制**：必须严格遵循讲师演示的标准模式：
  1. 引入寄存器暂存（`MOV AL, [SI]`）；
  2. 借助 `XCHG` 将寄存器与第二个内存操作数原子互换；
  3. 通过 `MOV` 将寄存器值回填至第一个内存操作数。

---

### 5.3 比较规则与跳转指令的符号语义不匹配（Signed/Unsigned Mismatch）
* **反模式表现**：本例明确要求降序且讲师选用了 `JAE` 指令。如果将其错误编写为 `JGE`（Jump if Greater or Equal），或者颠倒判定方向。
* **逻辑缺陷**：
  * `JAE` 依赖 $CF=0$（无符号数比对）；
  * `JGE` 依赖 $SF=OF$（带符号数比对）。
  * 若被排数据涉及首位为 1 的字节（如 `80H` ~ `FFH`），符号位判断错误会导致排序逻辑全部紊乱。

---

### 5.4 忽视内层计数与外层联动的硬编码（Inner Loop Decoupling）
* **反模式表现**：每一轮内循环均将 `CL` 简单粗暴地重设为常量 $N-1$。
* **计算冗余**：冒泡排序的关键性质在于：第 $k$ 轮外循环结束后，末端的 $k$ 个元素已经绝对就位。内层循环必须使用 `MOV CL, CH` 实现“每过一轮少比一次”。若硬编码固定长度，时间复杂度将退化为恒定的 $O(N^2)$ 无效操作。

## 二、核心原理深度推导

### 1. 冒泡排序的物理模型与循环次数推导

讲师在黑板上以缓冲区中的具体数值序列为例，推导降序（由高到低）冒泡排序的数学本质。

* **排序目标**：将连续存储区中的 $N$ 个无序无符号/带符号数按照**由高到低**排列。
* **物理模型（下沉模型）**：
  * 指针从数据缓冲区首地址出发，自上而下对相邻的两个数据单元进行两两比较。
  * 若“上方数据”小于“下方数据”，则交换位置；若“上方数据”大于等于“下方数据”，则不交换。
  * 在第一轮比较完成后，整个数据集中**最小的一个数**将被推移至缓冲区的最底部（最高物理地址单元）。
* **循环次数与边界条件的递推证明**：
  * **第 1 轮内循环**：对全部 $N$ 个数据进行两两比较，比较总次数为 $N - 1$ 次。最小数沉底。
  * **第 2 轮内循环**：最底部的数已有序，剩余未排好序的数只有 $N - 1$ 个，两两比较次数为 $(N - 1) - 1 = N - 2$ 次。次小数沉底。
  * **第 $i$ 轮内循环**：未排序数据为 $N - (i - 1)$ 个，两两比较次数为 $N - i$ 次。
  * **外循环轮数**：当排好 $N - 1$ 个数后，最后仅剩 1 个数，其位置自然确定，无需再比。因此外循环的总执行轮次固定为 $N - 1$ 次。

---

### 2. 提前退出优化机制（标志位状态机）

#### 传统模式的性能缺陷
若原始序列已部分有序或完全有序，外循环依然强制执行满 $N - 1$ 次，后续各轮比较中不会发生任何数据交换，产生纯粹的无效 CPU 空转。

#### 标志位优化原理
* 引入一个专用的“交换标志位”（讲师黑板板书使用通用寄存器 `BL`）。
* **初始状态**：在每一轮外循环开始、进入内循环之前，执行 `MOV BL, 0`，对交换标志清零。
* **状态置位**：在内循环的两两比较中，只要发生了一次相邻单元的数据交换，立即置标志位为有效值：`MOV BL, -1`（注：讲师在板书中说明赋为 `-1` 即全 `1`，亦表示逻辑真）。
* **轮次结束判决**：当一轮内循环执行完毕后，在进入外循环计数递减前，执行 `CMP BL, 0`：
  * 若 $BL = 0$：表明在整整一轮内循环的比对中，**未发生过任何两两交换**。依据数学定理，此时整个序列已经完全满足由高到低的排序要求，程序应立即提前退出排序循环，直接转入结束出口。
  * 若 $BL \neq 0$：表明该轮次仍有无序项被调换，序列尚不稳定，继续进入外循环递减步骤，启动下一轮排序。

```text
      │           ┌──────────────┐                  │
      │           │ CH <- CH - 1 │                  │
      │           └──────┬───────┘                  │
      │                  ▼                          │
      │           /──────────────\                  │
      │          /     CH == 0    \    NO           │
      └─────────<     (外循环完?)  >────────────────┘
                 \                /
                  \──────────────/
                         │ YES
                         ▼
                  ┌──────────────┐
                  │ 退出到 EXIT  │◄─────────────────┘
                  └──────────────┘
```

### 4. 8086 汇编架构实现与指令逐行演进

#### 寄存器工程规划分配
* `CH`：外循环计数器。初始化为 $N - 1$。
* `CL`：内循环计数器。每一轮外循环开始时，直接继承当前 `CH` 的剩余值（动态从 $N-1$ 递减到 $1$）。
* `SI`：源变址寄存器。作为指向数据缓冲区的物理偏移指针。
* `BL`：标志寄存器。用作交换标记（`0` 表示无交换，`-1` 表示发生交换）。
* `AL`：累加器低字节。用于暂存当前指针所指的数据，并参与比较运算。

#### 讲师完整板书程序推导与逐行解析

```assembly
; =========================================================================
; 程序功能：带交换标志优化的冒泡排序法（降序：由高到低）
; 假定：数据区首地址为 BUFFER1，数据个数为 N
; =========================================================================

        MOV     CH, N - 1           ; 1. 初始化外循环计数器：N 个数共需比对 N-1 轮
NEXT2:                              ; 外循环入口标号
        MOV     CL, CH              ; 2. 内循环计数器初始化：当前轮次的比对次数等于 CH 的值
        LEA     SI, BUFFER1         ; 3. 数组首地址偏移赋给指针 SI (板书等效: MOV SI, OFFSET BUFFER1)
        MOV     BL, 0               ; 4. 交换标志位清零

NEXT1:                              ; 内循环入口标号
        MOV     AL, [SI]            ; 5. 取出当前前驱单元的内容至累加器 AL
        CMP     AL, [SI+1]          ; 6. 将前驱单元与后继单元 [SI+1] 进行数值比较
        JAE     NOCHANGE            ; 7. 分支转移：若 AL >= [SI+1]，符合由高到低顺序，不交换，跳过

        ; --- 发生逆序，执行相邻单元数据交换 ---
        XCHG    AL, [SI+1]          ; 8. 核心技巧：将 AL 中的较小数与 [SI+1] 中的较大数进行交换
        MOV     [SI], AL            ; 9. 将交换出来的较大数（现存于 AL）写回前驱单元 [SI]
        MOV     BL, -1              ; 10. 置位交换标志，说明本轮内循环发生了数据位置调整

NOCHANGE:                           ; 不交换或交换完成汇合点标号
        INC     SI                  ; 11. 数据指针下移一个单元，准备比对下一对相邻数
        DEC     CL                  ; 12. 内循环计数器减 1
        JNZ     NEXT1               ; 13. 若 CL 尚未减到 0，则继续内循环相邻单元比对

        ; --- 一轮内循环结束，进行标志位与外循环判决 ---
        CMP     BL, 0               ; 14. 检测试验交换标志位
        JE      EXIT                ; 15. 若 BL == 0，说明本轮完全无交换，已提前排序完毕，跳出

        DEC     CH                  ; 16. 外循环计数器减 1
        JNZ     NEXT2               ; 17. 若 CH 尚未减到 0，说明未达到最大轮次，进入下一轮外循环

EXIT:                               ; 退出标号
        MOV     AH, 4CH             ; 18. 返回 DOS 系统功能调用
        INT     21H                 ; 19. 引发 21H 中断，终止当前进程
```

## 三、对比矩阵：标准双重循环 vs 标志位优化冒泡

| 比较维度 | 标准双重循环冒泡排序 | 带标志位（BL）优化冒泡排序 |
| :--- | :--- | :--- |
| **外循环终止条件** | 仅依赖 `CH` 严格减至 `0`（强制打满 $N - 1$ 轮） | 满足 `BL == 0`（无交换）**或** `CH` 减至 `0` |
| **最好时间复杂度** | $\Theta(N^2)$（即便初始有序，仍强行执行所有比对） | $\Theta(N)$（首轮比较未触发交换，直接 `JE EXIT` 提前终止） |
| **最坏时间复杂度** | $\Theta(N^2)$（完全逆序，两两必交换） | $\Theta(N^2)$（完全逆序，优化分支不生效，正常打满） |
| **指令控制开销** | 无额外标志位检测，每轮循环开销小 | 每轮内外循环交界处增加 `CMP BL, 0` 和 `JE EXIT` 开销 |
| **寄存器开销** | 占用 `CH`, `CL`, `SI`, `AL` | 额外占用一个专用通用寄存器（板书占用 `BL`） |
| **适用场景** | 数据高度离散、逆序严重，或对代码尺寸极度苛刻的场景 | 实际工程环境、数据大致有序或部分有序的高性能需求场景 |

## 四、反模式与踩坑清单

### 1. 软件工程反模式
* **反模式 1：无差别盲目循环（硬跑全部轮次）**
  * *问题*：未设置状态监测机制。若数据仅有微调即可有序，程序仍机械地进行全部 $N-1$ 轮遍历，浪费总线带宽与 CPU 周期。
  * *防御方案*：设立标志寄存器（如 `BL`），在循环体内建立**被动触发变更机制**，每轮内循环结束后对标志进行守卫判断。

* **反模式 2：双内存操作数指令越界**
  * *问题*：在执行交换时，直觉性地写出 `XCHG [SI], [SI+1]`。8086 指令系统严格禁止源操作数和目的操作数同时为内存寻址单元。
  * *防御方案*：板书示范的标准写法：先将 `[SI]` 装入寄存器 `AL`，再通过 `XCHG AL, [SI+1]` 配合 `MOV [SI], AL` 完成两步原子化内存级数据对调。

### 2. 汇编工程坑点
* **坑点 1：指针与内循环初始化的嵌套层级错位**
  * *现象*：将 `LEA SI, BUFFER1` 或 `MOV CL, CH` 错误地置于 `NEXT2` 标号之上（外循环外部）。
  * *后果*：导致第 2 轮外循环开始时，`SI` 未能复位回到数组起始点，而继续向下溢出越界寻址；或者 `CL` 保持第 1 轮结束时的 `0`，内循环直接失效或发生越界计数。
  * *防御方案*：在外循环标号 `NEXT2:` 内部的第一时间，必须严格完成三重重置：`CL <- CH`、`SI <- OFFSET BUFFER1`、`BL <- 0`。

* **坑点 2：分支跳转条件与排序方向反转**
  * *现象*：本算法目标是由高到低（降序）。在 `CMP AL, [SI+1]` 后，若误用 `JBE`（低于或等于则跳转），会导致最终排序结果变为由低到高（升序）。
  * *防御方案*：严格复核转移条件：`AL` 存放前驱单元内容，若降序排列，当前驱高于等于后继时无需改变顺序，故使用 `JAE NOCHANGE`。

### 3. 应试与考核重点（讲师课堂实战指要）
* **题型 A：读程序分析功能题**
  * 讲师明确指出，考卷常给出一整段排序汇编代码，不写任何注释，要求考生根据循环结构、`CMP` 比较对象及跳转指令判定：
    1. 排序算法（识别出为气泡排序法）；
    2. 排列方向（由高到低还是由低到高）；
    3. 参与排序的数据个数（分析 `MOV CH, N-1` 处的常数或符号常量）。
* **题型 B：关键指令横线挖空填空题**
  * 常见挖空陷阱：
    * 交换数据时的寄存器匹配指令（`XCHG AL, [SI+1]` 后的 `MOV [SI], AL`）；
    * 内外循环步进与跳转（`DEC CL` 配 `JNZ NEXT1`，`DEC CH` 配 `JNZ NEXT2`）；
    * 交换标志的条件跳转（`CMP BL, 0` 后的 `JE EXIT`）。
