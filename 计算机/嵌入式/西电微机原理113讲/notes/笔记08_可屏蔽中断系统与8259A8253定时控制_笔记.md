# 可屏蔽中断系统与8259A、8253定时控制

## 中断系统基本概念

### 中断过程与分类

* **中断（Interrupt）**
    * > **定义**：CPU 执行当前指令期间收到中断请求，待当前指令执行完后暂停主程序，保护现场，转去执行中断服务程序，处理结束再恢复现场并返回断点。
    * 中断必须发生在指令边界，不能在一条指令尚未执行完时直接丢弃该指令的执行过程。
    * 中断的两个核心动作是保护断点与现场，以及服务结束后恢复现场并返回断点。

* **中断源（Interrupt Source）**
    * > **定义**：向 CPU 提出中断请求的设备、事件或 CPU 内部单元。
    * 位于 CPU 内部的中断源产生内部中断，位于 CPU 外部的中断源产生外部中断。

* **8086 外部请求输入**
    * `NMI` 接收非可屏蔽中断请求，外部设备以上升沿提出，请求不能由中断屏蔽寄存器屏蔽。
    * `INTR` 接收可屏蔽中断请求，以高电平提出，只有 CPU 的 `IF=1` 且 8259A 未屏蔽该路时才可能得到响应。

    | 输入 | 请求性质 | 有效方式 | 屏蔽能力 |
    | :--- | :--- | :--- | :--- |
    | `NMI` | 非可屏蔽中断 | 上升沿 | 不受可屏蔽中断屏蔽字控制 |
    | `INTR` | 可屏蔽中断 | 高电平 | 受 CPU 的 `IF` 和 8259A 的 IMR 共同控制 |

    * > **易错点**：`NMI` 的上升沿与 `INTR` 的高电平是两种不同的请求方式，不能混用。

### 中断源识别与优先权

* **8086 的中断类型号**
    * > **定义**：8086 用 8 位中断类型号识别中断源，取值为 `0～255`，因此最多管理 256 级中断。
    * 内部固定类型号包括除法错 `0`、单步 `1`、非屏蔽中断 `2`、断点 `3`、溢出 `4`。
    * 执行 `INT n` 时，指令中的 `n` 就是软件中断的类型号。
    * 通过 `INTR` 进来的外部可屏蔽中断，其类型号由外部 8259A 在中断响应时送出。

* **软件查询识别**
    * 8051 一类没有中断类型号的系统可把多个请求合并到 `INT0` 或 `INT1`，进入服务程序后再依次查询各输入状态。
    * 哪个输入先被检测为有效，哪个请求就获得更高优先权，因此软件查询顺序同时决定优先权。

* **8086 中断优先权**
    * 内部中断除 `NMI` 外，优先权高于外部中断。
    * `NMI` 的优先权高于 `INTR` 上的可屏蔽中断。
    * 内部硬件优先级由 8086 固定，单步中断优先级最低。
    * 一片 8259A 管理八路可屏蔽中断，片内八路的优先级由初始化方式决定。

    * > **易错点**：8086 的固定优先级规则与 8259A 的片内优先级规则是两套独立机制，不能混为一条优先级链。

## 中断向量与中断服务

### 中断向量和向量表

* **中断向量（Interrupt Vector）**
    * > **定义**：中断服务程序的入口地址，由 16 位偏移地址 `IP` 和 16 位段地址 `CS` 组成，共 32 位。
    * 8086 中断向量表位于 1 MB 存储空间最低的 `00000H～003FFH`，共 1024 字节。
    * 每个中断向量占 4 字节，类型号为 $n$ 的向量表项起始物理地址为 $4n$。
    * 表项前两字节存 `IP`，后两字节存 `CS`；物理地址 $4n$ 取 `IP`，$4n+2$ 取 `CS`。

    | 类型号 $n$ | 存放 `IP` 的地址 | 存放 `CS` 的地址 |
    | :---: | :---: | :---: |
    | `0` | `00000H～00001H` | `00002H～00003H` |
    | `1` | `00004H～00005H` | `00006H～00007H` |
    | `n` | $4n～4n+1$ | $4n+2～4n+3$ |
    | `255` | `03FCH～03FDH` | `03FEH～03FFH` |

* **中断服务程序（Interrupt Service Routine，ISR）**
    * > **定义**：专门为提出请求的中断源或事件服务的程序。
    * 服务程序会使用的通用寄存器仍需由软件保护；CPU 自动压入的是返回所需的 `PSW`、`CS` 和 `IP`。

* **中断嵌套（Interrupt Nesting）**
    * > **定义**：执行某一中断服务程序时，允许更高优先级请求再次中断当前服务；高优先级服务结束后再返回原服务程序。
    * CPU 响应中断后自动清 `IF`，若需要外部可屏蔽中断嵌套，应在服务程序开始处执行 `STI` 重新开中断。

* **`IRET` 返回顺序**
    * CPU 响应中断时按 `PSW`、`CS`、`IP` 的顺序压栈。
    * `IRET` 按 `IP`、`CS`、`PSW` 的顺序出栈，恢复断点和标志后继续执行原程序。

    * > **易错点**：保护断点与现场属于同一个压栈过程，不能拆成两个响应步骤重复计数。

## 外部可屏蔽中断响应过程

### 五步响应链

* **响应前提**
    * 外部可屏蔽中断只有在 CPU 的 `IF=1` 时才进入响应过程。
    * 对 8259A 管理的请求，还必须先通过 IMR 屏蔽检查。

* **保护断点和现场**
    * CPU 依次把 `PSW`、`CS`、`IP` 压入堆栈，保存返回断点和进入中断前的标志状态。

* **取得类型号**
    * 外部可屏蔽中断在响应期间从 8259A 取得类型号 $n$。
    * 内部中断和 `NMI` 的类型号固定，不执行从 8259A 取类型号这一步。

* **关闭单步和可屏蔽中断**
    * CPU 清除 `IF` 与 `TF`，使服务期间不再接受新的可屏蔽请求，也避免每执行一条指令就再次陷入单步中断。
    * 若允许高优先级外部中断嵌套，应在受控位置重新执行 `STI`。

* **定位向量并转入服务程序**
    * CPU 计算 $n\times4$，从该地址取 `IP`，从 $n\times4+2$ 取 `CS`。
    * 把 `CS:IP` 指向服务程序入口，开始执行中断服务代码。

    ```text
    INTR 请求且 IF=1
        → 压入 PSW、CS、IP
        → 从 8259A 取得类型号 n
        → 清 IF、TF
        → 定位 n×4
        → 取得 IP、CS，转入服务程序
    ```

* **非 INTR 请求的差异**
    * 内部中断与 `NMI` 只需删去“从 8259A 取得类型号”这一步，其余压栈、清 `IF` 和 `TF`、查向量与返回过程相同。

## 8259A 的结构与引脚

### 引脚和端口选择

* **可编程中断控制器 8259A（Programmable Interrupt Controller，PIC）**
    * 8259A 采用 28 引脚双列直插式封装，负责管理 8086 外部可屏蔽中断。
    * 一片 8259A 有八路请求输入 `IR0～IR7`，因此最多直接接收八个外部中断源。

    | 引脚组 | 信号 | 作用 |
    | :--- | :--- | :--- |
    | 请求输入 | `IR0～IR7` | 接收八路外部中断请求 |
    | 数据总线 | `D0～D7` | 双向传送命令字、计数无关的状态及中断类型号；未选中时呈高阻态 |
    | 控制 | `WR`、`RD`、`CS`、`A0` | 完成写控制、读控制、片选和片内寻址 |
    | CPU 中断接口 | `INT`、`INTA` | 向 CPU 发出请求并接收 CPU 的响应脉冲 |
    | 级联 | `CAS0～CAS2` | 主片输出级联代码，从片输入并比较 |
    | 主从及缓冲 | `SP/EN` | 非级联主片接高电平、从片接地；缓冲方式下作为缓冲使能输出 |

* **两级寻址**
    * 8259A 内部部件多于端口数，先由 `A0=0` 或 `A0=1` 选择端口组，再由命令字特征位确定具体命令或寄存器。
    * 不能只用“偶地址写命令、奇地址读状态”概括全部访问，必须把 `A0` 与命令字内容结合起来。

* **数据总线连接**
    * 8086 系统的外部数据总线为 `D0～D15` 时，8259A 的 `D0～D7` 应接系统总线的 `D8～D15`。
    * 8088 只有 8 位外部数据总线时，8259A 的 `D0～D7` 直接接系统的 `D0～D7`。

    * > **易错点**：8086 在第二个 `INTA` 期间从高八位数据线读取类型号，8259A 若接到低八位 `D0～D7` 会接线错误。

### `SP/EN` 与级联线

* **非缓冲方式**
    * 8259A 的 `D0～D7` 与系统相应数据线直接相连。
    * `SP/EN` 作为输入：单片工作或级联主片接 $+5\ \mathrm{V}$，从片接地。
    * 主从身份同时决定 `CAS0～CAS2` 的方向：主片输出，从片输入。

* **缓冲方式**
    * 8259A 的 `SP/EN` 改为输出，控制 CPU 与系统总线之间的双向数据缓冲器。
    * CPU 执行 `IN` 或 `OUT` 时，8259A 通过该引脚使缓冲器工作。

* **级联信号**
    * 从片把 `IR0～IR7` 的请求汇总到自己的 `INT`，再把该输出接到主片某一路 `IR`。
    * CPU 响应后，主片在 `CAS2～CAS0` 输出级联代码，选中请求来自哪一路从片。
    * 从片比较级联代码与初始化身份，相符后才把对应中断类型号送上数据总线。

## 8259A 内部寄存器与请求通路

### `IRR`、`IMR`、`ISR`

* **三个八位寄存器**
    * `IR0～IR7` 分别对应三个寄存器的八个位。

    | 寄存器 | 名称 | 位为 `1` 的含义 | 位为 `0` 的含义 |
    | :--- | :--- | :--- | :--- |
    | `IRR` | 中断请求寄存器 | 对应请求已经到达并被锁存 | 对应请求未记录 |
    | `IMR` | 中断屏蔽寄存器 | 对应请求被屏蔽 | 对应请求放行 |
    | `ISR` | 中断服务寄存器 | 8259A 已选中该级进入服务 | 该级未被选入服务 |

    * > **易错点**：`IRR` 记“谁来过”，`IMR` 记“谁被挡住”，`ISR` 记“谁已被 8259A 选中”；三个位的 `1` 含义不同。
    * `ISR` 置位只表示 8259A 已选中该级并向 CPU 请求，不表示 CPU 已执行完服务程序。

* **请求处理链**

    ```text
    IR0～IR7
        ↓
    IRR 锁存有效请求
        ↓
    IMR：1 屏蔽，0 放行
        ↓
    中断优先权分析器选择最高一级并置 ISR
        ↓
    INT → CPU 的 INTR
    ```

* **运行中改变屏蔽**
    * 初始化完成后仍可通过 `OCW1` 改写 IMR。
    * 只放行 `IR1` 时，应令 `D1=0`，其余七位为 `1`。

### 外部请求的两道门

* **IMR 门**
    * 即使 CPU 已开中断，只要 IMR 对应位为 `1`，该请求就不能参加有效的优先权分析。
    * 被 IMR 屏蔽的请求不能越过 8259A 到达 CPU。

* **IF 门**
    * 即使 8259A 已经通过 `INT` 发出请求，只要 CPU 的 `IF=0`，CPU 就暂不进入响应过程。
    * 请求仍保存在 IRR 中；以后执行 `STI` 使 `IF=1`，保留的请求仍可得到响应。

* **门控结论**
    * `IF` 决定 CPU 能不能响应可屏蔽中断，IMR 决定 8259A 放不放行对应请求。
    * `IF=0` 不会让 IRR 中已经记录的请求凭空消失。

    * > **易错点**：“8259A 已发 `INT`”不等于 CPU 一定立即响应；IMR 和 `IF` 两道门都通过才具备响应条件。

### 两次 `INTA`

* **单片响应**
    * 第一个 `INTA` 负脉冲表示 CPU 已接受 8259A 的请求。
    * 第二个 `INTA` 期间，8259A 把被选请求对应的中断类型号送到 `D0～D7`。
    * CPU 自动读取类型号 $n$，再通过 $4n$ 定位中断向量。

* **级联响应**
    * 两个 `INTA` 脉冲都送到主片和从片。
    * 第二个 `INTA` 到来后，主片先在 `CAS2～CAS0` 输出级联代码。
    * 命中级联代码的从片送出类型号，不能由主片替从片计算后代替送出。

* **两级总线的类型号读取**
    * 8086 通过系统总线高八位 `D8～D15` 自动读取 8259A 送出的类型号。
    * 8088 通过 8 位 `D0～D7` 读取。

    ```text
    第二个 INTA
        ├─ 主片请求：本片送出类型号
        └─ 从片请求：主片先送 CAS2～CAS0
                       → 命中的从片送出类型号
    ```

## 级联与中断结束

### 主片、从片级联

* **主从身份**
    * 主片 `SP/EN` 接高电平，从片 `SP/EN` 接地。
    * 主片的 `CAS0～CAS2` 是输出，从片对应三根线是输入。
    * 从片不能直接向 CPU 的 `INTR` 请求，必须经主片某一路 `IR` 汇总。

* **两片级联的常用连接**
    * 从片 `INT` 接主片 `IR2`。
    * 主片仍接 `IR0、IR1、IR3～IR7` 七路外设，从片接自己的 `IR0～IR7` 八路，共形成 15 路外部可屏蔽中断。
    * 主片级联代码按 `CAS2、CAS1、CAS0` 读取；接在主片 `IR2` 时对应 `010`。

    ```text
    外设 → 从片 IR0～IR7 → 从片 INT
                            ↓
                       主片 IR2 → 主片 INT → CPU INTR

    主片 CAS2～CAS0 → 从片 CAS2～CAS0
    ```

* **级联优先级**
    * 从片内部先按自己的固定优先级选择一路请求。
    * 对主片而言，从片的八路请求整体以主片 `IR2` 的身份参与主片优先级分析，不能把从片八路拆散后插入主片各路之间。

* **PC 的 15 路外部中断**
    * 主片类型号 `08H～0FH` 对应 `IRQ0～IRQ7`。
    * 从片类型号 `70H～77H` 对应 `IRQ8～IRQ15`。
    * 主片 `IR2` 已用于级联，因此 16 个编号中少一路，实际可用 15 路。

    ```text
    IRQ0 > IRQ1 > 从片整组 IRQ8～IRQ15 > IRQ3 > IRQ4 > IRQ5 > IRQ6 > IRQ7
    ```

### 自动结束与非自动结束

* **自动结束**
    * 8259A 在第二个 `INTA` 期间送出类型号，同时清 ISR 中正在服务的一位。
    * 对 8259A 而言，类型号送出即认为该级结束。

* **非自动结束**
    * 第二个 `INTA` 只送出类型号，ISR 服务位继续保持为 `1`。
    * 服务程序完成后、执行 `IRET` 前，先向 8259A 发送 EOI；8259A 收到后清 ISR 对应位，CPU 再执行 `IRET`。

    ```text
    服务程序完成
        → 向 OCW2 写 EOI
        → 清 ISR 服务位
        → 执行 IRET
    ```

* **时间关系**
    * IRR 置位表示请求已经到达。
    * ISR 置位表示 8259A 已选中该级。
    * EOI 清 ISR 才表示服务程序确认该级结束。

    * > **易错点**：类型号送出不等于 EOI；非自动结束方式必须先 EOI、后 `IRET`。

## 8259A 初始化命令字

### 初始化顺序与端口

* **初始化命令字（Initialization Command Word，ICW）**
    * 初始化顺序固定为 `ICW1 → ICW2 → ICW3 → ICW4`，单片工作跳过 `ICW3`。
    * `ICW1` 依靠 `A0=0` 与数据特征识别；`ICW2～ICW4` 写到 `A0=1` 的端口，并依靠紧邻的写入顺序区分。
    * 初始化命令之间不能插入无关写入，否则会破坏命令识别顺序。

    | 命令字 | 端口条件 | 主要作用 |
    | :--- | :--- | :--- |
    | `ICW1` | `A0=0` | 建立初始化序列，选择单片或级联、请求有效方式 |
    | `ICW2` | `A0=1` | 设置本片 `IR0` 的类型号基址 |
    | `ICW3` | `A0=1` | 级联时说明从片接到主片的位置及从片自身标识 |
    | `ICW4` | `A0=1` | 选择嵌套、缓冲和中断结束方式 |

* **PC 端口配对**
    * 主片偶地址端口 `20H` 与奇地址端口 `21H` 配对。
    * 从片偶地址端口 `A0H` 与奇地址端口 `A1H` 配对。
    * `A0=0` 端口用于 `ICW1` 及常用 `OCW2`、`OCW3`；`A0=1` 端口用于 `ICW2～ICW4` 和 `OCW1`。

### `ICW1`

* **请求有效方式**
    * `D3=0` 时，`IR0～IR7` 按上升沿接收请求。
    * `D3=1` 时，按高电平接收请求。
    * PC 常用配置取上升沿方式。

* **8086 系统取值**
    * `D4=1` 是 `ICW1` 的识别特征。
    * `D0=1` 是固定标志位。
    * 8086 不使用 8085 时代的相关设置，相关位不按旧系统格式写入。
    * PC 两片级联初始化时，主片和从片的 `ICW1` 均使用 `11H`。

* **初始化边界**
    * 从片也必须写 `ICW1`，不能只初始化主片。
    * 只要选择级联，就必须继续写 `ICW3`。

    * > **易错点**：把 8259A 用于 8086 时不能照搬 8085 的中断向量间隔设置；旧系统的相关位不适用。

### `ICW2`

* **类型号基址**
    * `ICW2` 设置本片 `IR0` 的中断类型号基址，`IR1～IR7` 的类型号依次加一。
    * 8086 方式只写类型号高五位 `D7～D3`，`D2～D0` 写 `0`。
    * 给主片写 `ICW2=08H` 时，八路类型号为 `08H～0FH`。
    * 给从片写 `ICW2=70H` 时，八路类型号为 `70H～77H`。

    * > **易错点**：`ICW2` 给出的是八个类型号共同的高五位和最低三位为 `0` 的基址，不是直接把全部 `0～255` 类型号写入一片 8259A。

### `ICW3`

* **主片 `ICW3`**
    * 某位为 `1` 表示主片对应编号的 `IR` 输入接有从片 `INT` 输出。
    * 从片接主片 `IR2` 时，主片写 `04H`。

* **从片 `ICW3`**
    * 某位为 `1` 表示从片自身的身份编号，即它的 `INT` 输出接到主片哪一路。
    * 从片接主片 `IR2` 时，从片写 `02H`。

    | 命令字 | 主片写入值 | 从片写入值 | 含义 |
    | :--- | :---: | :---: | :--- |
    | `ICW3` | `04H` | `02H` | 从片 `INT` 接主片 `IR2` |

    * > **易错点**：主片 `04H` 描述“从片接到我的哪一路”，从片 `02H` 描述“我以哪个身份接到主片”；二者不能都写成 `04H`。

### `ICW4`

* **位字段**
    * `D4=0` 选择正常嵌套，`D4=1` 选择特殊嵌套。
    * `D3=0` 选择非缓冲方式；缓冲方式还涉及主从区分。
    * `D1=0` 选择非自动结束，`D1=1` 选择自动结束。
    * `D0=1` 是 `ICW4` 的识别标志位。

* **常用配置**
    * PC 常用正常嵌套、非缓冲、非自动结束，主片和从片的 `ICW4` 都为 `01H`。
    * 单片系统虽然跳过 `ICW3`，仍必须写 `ICW4`。

    | 初始化命令字 | 主片 | 从片 | 作用 |
    | :--- | :---: | :---: | :--- |
    | `ICW1` | `11H` | `11H` | 上升沿、级联初始化 |
    | `ICW2` | `08H` | `70H` | 各自类型号基址 |
    | `ICW3` | `04H` | `02H` | 从片接主片 `IR2` |
    | `ICW4` | `01H` | `01H` | 正常嵌套、非缓冲、非自动结束 |

    * > **易错点**：`ICW1～ICW4` 是一组有先后依赖的配置，不是四个互不相关的字节。

## 8259A 操作命令字

### `OCW1`、`OCW2`、`OCW3`

* **操作命令字（Operation Command Word，OCW）**
    * `ICW` 建立初始工作方式，`OCW` 在初始化后改变运行状态。

    | 命令字 | 端口条件 | 作用 | 常用场景 |
    | :--- | :--- | :--- | :--- |
    | `OCW1` | `A0=1` | 改写 IMR | 动态屏蔽或放行某几路请求 |
    | `OCW2` | `A0=0` | 发出 EOI | 非自动结束方式通知服务完成 |
    | `OCW3` | `A0=0` | 改变屏蔽方式 | 正常全嵌套、非自动结束时通常不用 |

* **`OCW1` 的极性**
    * 对应位写 `1` 屏蔽该路请求，写 `0` 放行该路请求。
    * 可从同一奇地址端口读出当前 IMR，端口相同但读、写方向对应的寄存器不同。

* **`OCW2` 的 EOI**
    * 正常嵌套方式下，主片从 `20H`、从片从 `A0H` 写 `20H`，发出 EOI。
    * `OCW2` 还可用于在结束中断时指定后续优先权，但此处要求掌握的常规用法是非自动结束 EOI。

    ```asm
    ; 主片 EOI
    MOV AL, 20H
    OUT 20H, AL

    ; 从片 EOI
    MOV AL, 20H
    OUT A0H, AL
    ```

* **`OCW3` 的边界**
    * `OCW1` 决定“哪一路被屏蔽”，`OCW3` 改变“屏蔽方式本身”。
    * 长文未展开 `OCW3` 的完整位组合，常用正常嵌套和非自动结束配置不依赖它。

### 固定优先级与循环优先级

* **固定优先级**
    * 正常全嵌套方式下，`IR0` 最高，依次降低到 `IR7` 最低。
    * 正在服务 `IR0` 时，只有更高一级请求可能打断；同级请求不能打断自身。

* **循环优先级**
    * 某一级被响应后，原最低级升为最高，已响应级退到最低，其余顺序循环轮转。
    * 例如原来 `IR0` 最高，响应后 `IR1` 成为最高；原来 `IR1` 最高，响应后 `IR2` 成为最高。

* **特殊嵌套**
    * `ICW4` 选择特殊嵌套时，可再通过操作命令指定优先权。
    * 常规 PC 配置采用正常嵌套，不展开特殊嵌套的完整命令组合。

## 8086 中断输入程序

### 数据结构与程序流程

* **缓冲区、指针和屏蔽字**
    * 输入缓冲区保存设备数据；示例定义 `IN_BUFF DB 100 DUP (?)`，可连续保存 100 个字节。
    * 写指针 `IN_POINT` 保存下一次写入位置的偏移地址，每处理一次中断后加一。
    * `IMR_SAVE` 保存原中断屏蔽字，退出前恢复，避免破坏其他中断的屏蔽状态。

    ```asm
    IN_BUFF   DB 100 DUP (?)
    IN_POINT  DW ?
    IMR_SAVE  DB ?
    ```

* **初始化顺序**
    * 建立中断向量，保存并局部修改 IMR，准备写指针，最后进入主循环等待结束键。
    * 设备数据通过中断进入服务程序，不等待用户按下回车后才交付 CPU。

* **缓冲区边界**
    * 该示例没有加入越界判断，默认在 100 个数据写满前已经复位或按下回车。
    * 若实际数据量可能超过 100 个，软件必须增加指针边界判断。

### 建立中断向量

* **类型号为 `0BH` 的向量位置**
    * 物理地址 $4\times0BH=002CH$ 存服务程序入口偏移地址。
    * 物理地址 `002EH` 存服务程序入口段地址。

* **手工写向量表**
    * 先执行 `CLI`，防止向量尚未完整建立时被中断。
    * 保存原 `DS`，令 `DS=0` 定位中断向量表，先写 `IP` 再写 `CS`，恢复 `DS` 后再执行 `STI`。

    ```asm
    CLI
    PUSH DS
    MOV AX, 0000H
    MOV DS, AX
    MOV BX, 4*0BH
    MOV AX, OFFSET INT_TYPE
    MOV WORD PTR [BX], AX
    MOV AX, SEG INT_TYPE
    MOV WORD PTR [BX+2], AX
    POP DS
    STI
    ```

    * > **易错点**：`[BX+2]` 存入口段地址；不能把完整入口误当成一次连续写入的一个地址单元。

* **DOS `25H` 功能调用**
    * 调用前按功能要求准备服务程序入口的段地址和偏移地址。
    * `AH=25H` 表示建立向量功能，`AL=0BH` 表示向量类型号。

    ```asm
    MOV AH, 25H
    MOV AL, 0BH
    INT 21H
    ```

### 只放行当前中断

* **读出、修改、写回 IMR**
    * 从主片奇地址端口 `21H` 读出原 IMR，保存到 `IMR_SAVE`。
    * 当前使用类型号 `0BH`，对应第 3 位；执行 `AND AL,0F7H` 只把该位清零，其余位保持原值。
    * 修改后的字节写回 `21H`，使该路请求放行。

    ```asm
    IN  AL, 21H
    MOV IMR_SAVE, AL
    AND AL, 0F7H
    OUT 21H, AL
    ```

    * `0F7H=11110111B`，与运算只清第 3 位；IMR 中 `0` 表示放行。
    * 同一端口从 CPU 读出时得到 IMR，向 CPU 写出时是新的 `OCW1`。

* **恢复原屏蔽状态**
    * 退出前把 `IMR_SAVE` 装回 `AL` 并写回 `21H`，完成“读出—修改—恢复”闭环。

    ```asm
    MOV AL, IMR_SAVE
    OUT 21H, AL
    ```

    * > **易错点**：`AND AL,0F7H` 是把第 3 位清 `0` 以放行中断，不是把它置 `1`；保存原值用于恢复其他七路原有状态。

### 主程序与中断服务程序

* **写指针初始化**
    * `IN_POINT` 装入的是 `IN_BUFF` 的偏移地址，不是 `IN_POINT` 变量自身的地址。

    ```asm
    MOV AX, OFFSET IN_BUFF
    MOV IN_POINT, AX
    ```

* **主循环等待回车**
    * `AH=06H`、`DL=0FFH` 时读取控制台字符；`AL` 中得到 `0DH` 表示回车。
    * 主循环持续轮询期间 CPU 仍在执行指令，设备中断可以在任意时刻打断该循环。

    ```asm
    MOV AH, 06H
    MOV DL, 0FFH
    WAIT_KEY:
    INT 21H
    CMP AL, 0DH
    JNE WAIT_KEY
    ```

* **服务程序的数据通路**
    * 保护服务程序会修改且主程序仍需使用的寄存器。
    * 从 `IN_POINT` 取当前写入位置，从设备数据端口 `240H` 读入一个字节，写入 `[BX]`，再把指针加一并保存。

    ```asm
    MOV BX, IN_POINT
    MOV DX, 240H
    IN  AL, DX
    MOV  [BX], AL
    INC  BX
    MOV  IN_POINT, BX
    ```

* **逐次中断的数据流**

    ```text
    IN_POINT = OFFSET IN_BUFF
        → IN_BUFF[0] ← 设备数据 0
        → IN_POINT 加一
        → IN_BUFF[1] ← 设备数据 1
        → IN_POINT 加一
        → IN_BUFF[2] ← 设备数据 2
    ```

    * 每次中断只读一个数据、更新一次指针，然后返回主程序。
    * 设备端口的读操作还会清除相应设备状态，使下一次中断读取下一份数据，而不是重复读旧数据。

* **返回与退出**
    * 非自动结束方式下，服务程序结束前先向 8259A 发 EOI，再执行 `IRET`。
    * 主程序收到回车后恢复原 IMR，再通过 DOS `4CH` 功能退出。

    ```asm
    MOV AL, IMR_SAVE
    OUT 21H, AL
    MOV AH, 4CH
    INT 21H
    ```

## 8253 的结构与编程基础

### 引脚和三个计数器

* **可编程定时计数器 8253（Programmable Interval Timer，PIT）**
    * 8253 采用 24 引脚双列直插式封装，内部有三个相互独立的 16 位计数器。
    * 三个计数器分别拥有自己的计数初值、计数状态和工作方式，每一路均对应一组 `CLK`、`GATE`、`OUT`。

    | 类别 | 引脚 | 作用 |
    | :--- | :--- | :--- |
    | 系统总线 | `D0～D7` | 传送方式字、计数初值和读回数据 |
    | 系统总线 | `A1、A0` | 选择三个计数器端口或方式控制端口 |
    | 系统总线 | `CS#、RD#、WR#` | 完成片选、读控制和写控制 |
    | 外部设备 | `CLK0～CLK2` | 提供各计数器的外部计数时钟 |
    | 外部设备 | `GATE0～GATE2` | 门控、允许计数或硬件触发 |
    | 外部设备 | `OUT0～OUT2` | 输出定时结束、分频、方波或单脉冲波形 |

* **三个控制信号**
    * `CLK` 的下降沿作为有效计数边沿。
    * `GATE` 在不同工作方式下可能表示电平允许，也可能表示上升沿硬件触发，不能统一理解为高电平使能。
    * `OUT` 不只表示溢出，还可能是单脉冲、周期分频或方波。

* **级联与计数宽度**
    * 前一级 `OUT` 可接后一级 `CLK`，用多个 16 位计数器扩大分频系数和定时长度。
    * 单个 16 位计数器范围为 `0～65535`；需要更大数值时必须级联。
    * 方式字可选择只访问低 8 位、只访问高 8 位或完整 16 位。

* **8253 与 8254**
    * 8253 的时钟上限按本课规格为 `2 MHz`；8254 的上限更高，材料中出现 `5 MHz` 与 `8 MHz` 两种口径，实际应以具体型号手册为准。
    * 在 8253 允许的时钟范围内，两者外部引脚兼容。
    * 8254 增加状态寄存器，可锁存并读回工作方式、`OUT` 电平和计数状态；8253 只能按计数锁存方式取得当前计数值，不能用 8254 的状态读回命令。

    * > **易错点**：8253 没有 `RESET` 引脚；系统复位不会像复位普通寄存器那样自动把已经初始化的 8253 工作状态清零。

### 端口选择

* **`A1A0` 端口映射**

    | `A1A0` | 写操作 | 读操作 |
    | :--- | :--- | :--- |
    | `00` | 写计数器 0 的初值 | 读计数器 0 的当前值 |
    | `01` | 写计数器 1 的初值 | 读计数器 1 的当前值 |
    | `10` | 写计数器 2 的初值 | 读计数器 2 的当前值 |
    | `11` | 写方式控制字 | 8253 不适用该状态读回方式；8254 可读回锁存状态 |

* **地址选择边界**
    * 三个计数器各有初值端口，但共用一个方式控制端口。
    * 向 `A1A0=11` 写数据时，方式字最高两位再决定设置计数器 0、1 还是 2。
    * 控制端口地址只是端口编号，不表示存在“计数器 3”；8253 只有计数器 0、1、2。

### 方式控制字

* **方式控制字四组字段**

    | 位 | 名称 | 含义 |
    | :--- | :--- | :--- |
    | `D7D6` | `SC1SC0` | `00` 选计数器 0，`01` 选计数器 1，`10` 选计数器 2 |
    | `D5D4` | `RW1RW0` | `00` 锁存命令，`01` 低 8 位，`10` 高 8 位，`11` 先低后高 |
    | `D3D2D1` | `M2M1M0` | 选择方式 0～方式 5 |
    | `D0` | `BCD` | `0` 为二进制计数，`1` 为 BCD 计数 |

* **工作方式编码**

    | `D3D2D1` | 方式 |
    | :--- | :--- |
    | `000` 或 `001` | 方式 0 |
    | `010` 或 `011` | 方式 2 |
    | `100` | 方式 4 |
    | `101` | 方式 5 |
    | `110` 或 `111` | 不使用 |

* **读写格式**
    * `01` 只写低 8 位，`10` 只写高 8 位，`11` 完整写 16 位。
    * 完整 16 位必须先写低字节，再写高字节。
    * `00` 不是普通数据写入，而是锁存命令；方式字段不决定另一种工作方式。

* **二进制与 BCD**
    * `D0=0` 时按二进制递减，初值按普通二进制解释。
    * `D0=1` 时按 BCD 计数。

    * > **易错点**：方式字必须先写，计数初值后写；完整 16 位初值的两个字节也不能颠倒。

### `CR`、`CE` 与 `OL`

* **计数初值寄存器（Count Register，CR）**
    * 保存 CPU 写入的 16 位初值，不等同于正在执行减一运算的计数器。

* **计数执行部件（Counting Element，CE）**
    * 写初值后的第一个有效 `CLK` 下降沿把完整初值从 `CR` 装入 `CE`。
    * 装载条件满足后，`CE` 按有效时钟边沿递减，递减规律由工作方式决定。

* **输出锁存器（Output Latch，OL）**
    * `CE` 的计数值同步送到 `OL`，CPU 读数时不能假设它一直稳定。
    * 读取正在运行的计数器时，先发锁存命令使 `OL` 停止跟随 `CE`，再按所设字节宽度读出。
    * 完整 16 位读完后锁存解除，`OL` 重新跟随 `CE`。

    ```text
    写方式字
        → 写初值：低字节在前、高字节在后
        → 第一个有效 CLK 下降沿：CR 装入 CE
        → CE 递减，OL 跟随 CE
        → 发锁存命令
        → 读取稳定的低字节和高字节
        → 读完解除锁存
    ```

* **初值装入边界**
    * 方式 0、1、2、4、5 中，`CE` 按一个计数单位递减。
    * 方式 3 中，`CE` 按两个计数单位递减以形成方波，奇数初值还要经过奇偶处理。

## 8253 的六种工作方式

### 方式总览

* **六种方式**

    | 方式 | 名称 | 启动或触发来源 | 输出重点 |
    | :--- | :--- | :--- | :--- |
    | 方式 0 | 计数到终止中断 | 写入方式字和初值后在允许条件下计数 | 到零时 `OUT` 由低变高 |
    | 方式 1 | 硬件触发单脉冲形成 | `GATE` 上升沿 | 形成宽度可编程的低脉冲 |
    | 方式 2 | 分频器 | 初值装入后连续计数 | 周期性窄脉冲并自动重装 |
    | 方式 3 | 方波发生器 | 初值装入后连续计数 | 周期性方波 |
    | 方式 4 | 软件触发选通信号产生 | 软件写入启动 | 形成选通脉冲 |
    | 方式 5 | 硬件触发选通信号产生 | `GATE` 上升沿 | 形成选通脉冲 |

* **选择线索**
    * 看到“计数到零产生一次信号”优先考虑方式 0。
    * 看到“外部事件到来后形成一次单脉冲”优先考虑方式 1。
    * 看到“输入时钟分频、周期性窄脉冲”优先考虑方式 2。
    * 看到“连续方波或稳定节拍”优先考虑方式 3。
    * 方式 4 与方式 5 都产生选通信号，核心区别是软件触发和硬件触发。

## 方式 0：计数到终止中断

### 初始化和 `OUT0` 生命周期

* **方式零控制字**
    * 计数器 0、8 位、二进制、方式 0 的控制字为 `00110000B=30H`。
    * 假设端口为 `300H～303H`，方式控制端口为 `303H`，计数器 0 端口为 `300H`。

    ```asm
    MOV DX, 303H
    MOV AL, 30H
    OUT DX, AL

    MOV DX, 300H
    MOV AL, 05H
    OUT DX, AL
    ```

* **装载过程**
    * 写入方式 0 后，`OUT0` 立即进入低电平。
    * 完整初值写入后，在 `GATE0=1` 条件下，第一个有效 `CLK0` 下降沿把初值装入 `CE`。
    * 初值 `0005H` 时，`CE` 依次为 `0005H → 0004H → 0003H → 0002H → 0001H → 0000H`。

* **终止状态**
    * `CE` 减到 `0000H` 的时刻，`OUT0` 从低电平变高并保持。
    * 定时宽度为 $T_{\mathrm{OUT}}=N\times T_{\mathrm{CLK0}}$。
    * `OUT0` 上升沿是本轮计数完成的标志，可作为状态，也可接入 8259A 产生定时中断。

* **到零后继续递减**
    * `OUT0` 变高后，`CE` 不会停止，下一时钟到来时继续变为 `FFFFH`、`FFFEH` 等。
    * 方式 0 不在到零时自动装回原初值；`OUT0` 变高后要开始下一轮，软件必须重新写初值。

    * > **易错点**：`CE=0000H` 只表示本轮终止，不表示 8253 停机；等待 `OUT0` 自动恢复低电平不会得到下一轮定时。

### `GATE0` 与周期重装

* **允许与暂停**
    * `GATE0=1` 时，每个有效 `CLK0` 下降沿使 `CE` 减一。
    * `GATE0=0` 时计数暂停，当前 `CE` 值保留。
    * `GATE0` 重新变高后从保留值继续，不必重新装载初值。

* **终止前重装与终止后重装**
    * 尚未到零时重写 `CR`，下一个有效下降沿把新初值装入 `CE`，本轮尚未完成的定时被新初值替代。
    * 已经到零后重写 `CR`，用于启动下一轮定时。
    * `GATE0` 恢复高电平是继续原计数；重写 `CR` 是替换或开始一轮新计数。

    * > **易错点**：暂停后恢复和重新开始不是同一动作；前者保留当前 `CE`，后者需要新的初值。

### 判断计数到零

* **直接读零的困难**
    * CPU 按自身指令时序运行，`CE` 按外部时钟异步运行，读取和比较时 `CE` 可能已经继续变化。
    * 16 位值分两次读取，若低字节读完后 `CE` 再减一，拼接结果可能从未真实存在过。

* **锁存读取**
    * 先向方式控制端口写锁存命令，再从所选计数器端口按低字节、高字节顺序读取。
    * 锁存只保证两次读取属于同一快照，不能保证锁存命令发出的瞬间恰好捕获 `0000H`。

* **用回绕判断**
    * 未越过零时，读回的无符号值不大于原初值。
    * 越过零后进入 `FFFFH` 区间，无符号值大于原初值，因此比较回绕比等待稍纵即逝的零更可靠。

    ```asm
    WAIT_ZERO:
        MOV  DX, 303H
        MOV  AL, 00H
        OUT  DX, AL           ; 锁存计数器 0

        MOV  DX, 300H
        IN   AL, DX           ; 先读低字节
        MOV  AH, AL
        IN   AL, DX           ; 再从同一计数器端口读高字节
        XCHG AH, AL           ; AX 得到完整 16 位计数值

        CMP  AX, INITIAL
        JBE  WAIT_ZERO
    ```

    * > **易错点**：一次锁存读只能稳定“低字节—高字节”的组合，不能消除锁存命令发出前 `CE` 可能已经越过零点的时间竞争。

### 定时唤醒与看门狗

* **定时中断**
    * 方式 0 的 `OUT0` 上升沿接入 8259A，请求到来后 CPU 进入服务程序完成到期处理。
    * 软件在计数器到零前重装初值，即可获得连续、可控的周期过程。

* **看门狗**
    * 正常运行时，程序在规定位置重装计数器初值，相当于“喂看门狗”。
    * 应选择满足 $N_{\mathrm{WDT}}T_{\mathrm{CLK0}}>T_{\mathrm{normal}}$ 的计数值，并留出余量。
    * 程序受干扰走飞后不再重装，`CE` 最终到零并产生异常信号。
    - 简单系统可在服务程序中无条件跳回主程序流程。
    - 较长系统可把程序分段，在各段入口重装并保存段入口地址，超时后按走失段选择恢复位置。

    * > **结论**：方式 0 用“正常程序持续重装、走飞后停止重装”的差别判断程序是否仍在正常执行。

## 方式 1：硬件触发单脉冲形成

### 触发和计数过程

* **方式一控制字**
    * 计数器 0、只写低 8 位、二进制、方式 1 的控制字为 `00100000B=20H`。
    * 初值 `04H` 写入后，计数器等待 `GATE0` 上升沿，不立即开始计数。

    ```asm
    MOV DX, 303H
    MOV AL, 20H
    OUT DX, AL

    MOV DX, 300H
    MOV AL, 04H
    OUT DX, AL
    ```

* **硬件触发**
    * 初始化方式 1 后，`OUT0` 保持高电平。
    - `GATE0` 上升沿到来时，`OUT0` 转为低电平。
    - 随后有效 `CLK0` 边沿把初值装入 `CE` 并开始递减。
    - `CE` 数完 $N$ 个时钟后到达零，`OUT0` 回到高电平，单脉冲结束。

* **脉冲宽度**
    * $W_{\mathrm{pulse}}=N\times T_{\mathrm{CLK0}}$。
    * 硬件决定何时开始，软件通过初值决定低脉冲持续多久。

* **再次触发**
    * 一次脉冲尚未结束时若 `GATE0` 再出现上升沿，初值重新装入，计数从头开始。
    * 方式一的再次触发会重启本轮计数，不是忽略新触发。

    ```text
    GATE0 上升沿
        → OUT0 变低
        → 装入初值 N
        → N 个计数边沿后 CE 到零
        → OUT0 恢复高电平
    ```

* **与方式 0 的边界**
    * 方式 0 初始化后 `OUT` 为低，由写入新初值推动重装和下一轮。
    * 方式 1 初始化后 `OUT` 为高，由 `GATE` 上升沿推动重装和再次触发。

    | 比较项 | 方式 0 | 方式 1 |
    | :--- | :--- | :--- |
    | 初始化后 `OUT` | 低 | 高 |
    | 启动动作 | 写入初值 | `GATE` 上升沿 |
    | 结束动作 | `CE` 到零，`OUT` 保持高 | `CE` 到零，`OUT` 回高结束单脉冲 |
    | 下一轮来源 | 重新写初值 | 下一次 `GATE` 上升沿 |
    | 典型用途 | 定时、周期重装、看门狗 | 硬件触发延时和可编程单脉冲 |

## 方式 2：脉冲发生器与分频

### 计数、自动重装和周期

* **方式二控制字**
    * 计数器 1、完整 16 位、二进制、方式 2 的控制字为 `01110100B=74H`。

    ```asm
    MOV DX, 303H
    MOV AL, 74H
    OUT DX, AL
    ```

* **初值为 6 的动作**
    * `GATE` 保持高电平，CE 从 6 开始按有效下降沿递减。
    - 前四个下降沿使 `CE` 依次为 `5、4、3、2`，`OUT` 仍为高。
    - 第五个下降沿使 `CE` 由 2 变 1，`OUT` 变低。
    - 第六个下降沿使 `CE` 由 1 变 0，`OUT` 回高，CR 中的初值自动重新装入 CE。

* **自动重装**
    * 方式 2 在计数到零后自动把 CR 初值重新装入 CE，不需要软件每个周期重写。
    * `OUT` 的低电平只保持一个时钟周期，完整输出波形周期性重复。

* **稳态周期**
    * 从装入初值到第一次由高变低经历 $N-1$ 个下降沿，第 $N$ 个下降沿补上最后一个低电平时钟。
    * 稳态输出周期为 $T_{\mathrm{OUT}}=(N+1)T_{\mathrm{CLK}}$。

    * > **易错点**：方式 2 稳态周期不是 $NT_{\mathrm{CLK}}$，必须计入“到零时自动重装”带来的一个时钟。

* **初值用途**
    * 改变初值即可改变分频周期，输入脉冲频率为 $f_{\mathrm{CLK}}$ 时，稳态输出频率对应 $1/[(N+1)T_{\mathrm{CLK}}]$。

### `GATE` 控制

* **连续工作**
    * `GATE` 保持高电平时允许计数和接受初值，是分频器最常见的接法。
    * 固定连续工作时把对应 `GATE` 接高电平即可。

* **暂停与重新触发**
    * `GATE` 变低时停止计数，当前值保留。
    * `GATE` 由低变高形成重新触发上升沿，允许装载时初值重新进入 CE。

* **软件控制 GATE**
    * 需要由程序决定启停时，可把 I/O 输出端口某一位接到 `GATE`。
    * 不能只写控制字和初值而忽略外部 `GATE` 的实际电平。

## 方式 3：方波发生器

### 控制字与偶数初值

* **方式三控制字**
    * 计数器 0、完整 16 位、二进制、方式 3 的控制字为 `00110110B=36H`。
    - `D7D6=00` 选择计数器 0。
    - `D5D4=11` 表示先低字节、后高字节。
    - `D3D2D1=011` 选择方式 3。
    - `D0=0` 选择二进制。

    ```asm
    MOV AL, 36H
    OUT 83H, AL
    ```

* **偶数初值 $N=2k$**
    * CE 按 2 递减，序列为 $N\rightarrow N-2\rightarrow\cdots\rightarrow0$。
    * CE 到零时 `OUT` 变低，保持一个时钟后 CR 自动重装，`OUT` 再变高。
    * 高、低电平宽度均为 $kT_{\mathrm{CLK}}$，完整周期为 $NT_{\mathrm{CLK}}$，占空比为 $1/2$。

    $$
    T_{\mathrm{高}}=kT_{\mathrm{CLK}},\qquad
    T_{\mathrm{低}}=kT_{\mathrm{CLK}},\qquad
    T_{\mathrm{OUT}}=NT_{\mathrm{CLK}}
    $$

* **示例 $N=6$**
    * CE 依次为 `6、4、2、0`。
    * `OUT` 高电平和低电平各保持 3 个输入时钟。

    * > **易错点**：方式 3 不能按一次减一推算高、低宽度；它在多数时钟内按减二推进。

### 奇数初值

* **奇数初值 $N=2k+1$**
    * 装入 CE 时先把奇数初值按 $N-1=2k$ 处理，完成正半周。
    - `OUT` 变低后，CR 中的奇数初值再减一，以偶数 $2k$ 重新装入 CE。
    - 随后完成相同的负半周。

* **高、低宽度**
    * 高电平宽度为 $(k+1)T_{\mathrm{CLK}}$。
    * 低电平宽度为 $kT_{\mathrm{CLK}}$。
    * 完整周期仍为 $NT_{\mathrm{CLK}}$，但高低比不为 `1`。

    $$
    T_{\mathrm{高}}=(k+1)T_{\mathrm{CLK}},\qquad
    T_{\mathrm{低}}=kT_{\mathrm{CLK}},\qquad
    T_{\mathrm{OUT}}=NT_{\mathrm{CLK}}
    $$

* **示例 $N=5$**
    - 每次实际装入 CE 的偶数值是 4。
    - 正半周为 $4\rightarrow2\rightarrow0$。
    - `OUT` 变低并保持一个时钟后，再以 4 装入 CE 完成负半周。
    - 完整周期为 5 个时钟，高电平比低电平多 1 个时钟。

* **占空比结论**
    * 偶数初值产生对称方波。
    * 奇数初值产生周期仍为 $NT_{\mathrm{CLK}}$ 的非对称方波。
    * CPU 不必参与每个边沿，8253 在每轮结束后自动重装。

### `GATE` 接法

* **连续方波**
    * `GATE` 为高电平时允许计数并持续产生方波。
    * 固定连续工作时把 `GATE` 接高电平。

* **暂停与恢复**
    * `GATE` 变低停止计数。
    * `GATE` 由低变高时形成触发上升沿，使初值重新装入并恢复计数。
    * 仅执行初始化而把 `GATE` 悬空或接低，不能保证得到要求的连续方波。

    * > **提示**：软件决定启停时，把 `GATE` 接到 I/O 输出口某一位；固定工作时直接接高电平。

## 方式 4、方式 5 与选通触发

* **方式 4：软件触发选通信号产生**
    * 初始化并写入初值后，由软件写入动作启动后续的触发计数。
    * 核心名称是“软件触发”，重点是触发动作来自软件而不是 `GATE` 上升沿。

* **方式 5：硬件触发选通信号产生**
    * 写入方式字和初值后，还要等待 `GATE` 由低变高的上升沿。
    * 每次硬件信号作为一次触发输入，结构与方式 1 的硬件启动思想相近。

* **触发来源边界**
    * 方式 4 与方式 5 的主要区别是“软件启动”和“硬件启动”。
    * `GATE` 的高电平允许作用和上升沿触发作用不能混为一个概念。

* **波形信息边界**
    * 长文没有展开方式 4、方式 5 的完整 `OUT` 波形、全部边沿次序和全部暂停恢复细节。
    * 已知内容仅包括名称、触发来源以及与方式 1 相近的选通触发结构。

## 8253 与系统总线接口

### 总线连接

* **端口和地址选择**
    * 8253 共有四个端口：一个方式控制端口、三个计数器端口。
    - `A1A0=00` 选择计数器 0。
    - `A1A0=01` 选择计数器 1。
    - `A1A0=10` 选择计数器 2。
    - `A1A0=11` 选择控制端口。
    * 四个端口地址不必连续，由系统地址译码决定。

* **数据总线**
    * 8088 使用 `D0～D7`，8253 的 `D0～D7` 直接对应。
    * 8086 外部总线为 16 位时，应按系统实际接口完整考虑 `D0～D15` 的连接，不能只接低位就认为接口完成。

* **读、写和译码信号**
    * 8253 的 `RD#`、`WR#` 分别连接系统读、写控制。
    * `CS#` 由系统地址译码和 I/O 控制条件共同产生。
    * PC 总线接口还要考虑 `AEN`，区分处理器访问与 I/O 访问。
    * 必须核对 `M/IO`、`IO/M` 的命名和有效电平，不能只凭符号方向猜测。

* **外部计数信号**
    * 外部 `CLK` 向指定计数器提供计数节拍。
    * `GATE` 决定是否允许计数或是否形成硬件触发。
    * `CLK`、`GATE` 与 CPU 系统总线不是同一类控制信号，初始化正确也不能代替外部接线。

    * > **易错点**：端口地址由 `A1A0` 选择；例如控制端口为 `83H` 时，`OUT 83H,AL` 是写控制字，不是给“计数器 3”写初值。

## 8253 级联与定时应用

### 级联规则

* **硬件级联**
    * 前一级 `OUT` 接后一级 `CLK`。
    - 计数器 0 的 `OUT0` 可接计数器 1 的 `CLK1`。
    - 计数器 1 的 `OUT1` 可接计数器 2 的 `CLK2`。
    * 后一级按前一级输出翻转或到达边沿的节拍继续计数。

* **软件初始化**
    * 每一级都要分别写自己的方式控制字和计数初值。
    * 每一级对应的 `GATE` 都要满足工作条件，连续定时通常全部接高电平。

* **应用目的**
    * 16 位计数器不能装入所需大数时，用级联拆分计数值。
    * 方式 2 可产生中间分频节拍，方式 3 可在末级产生最终方波。

### 织布机每百米下刀打包

* **事件与计数脉冲**
    * 织布机每织 1 米向计数器 0 输入一个脉冲。
    * 每累计 100 米，计数器 0 的 `OUT0` 向织布机发出一次下刀、打包命令。

* **方式与初值**
    * 计数器 0 使用方式 2，对每米脉冲进行 100 分频。
    * 初值应写 100，不能写 99。
    * 计数器 0、方式 2、完整 16 位、二进制的控制字为 `00110100B=34H`。
    * `GATE0` 接高电平，织布机每米脉冲接 `CLK0`，`OUT0` 接控制命令输入端。

* **端口与程序**
    * 端口范围为 `80H～83H` 时，计数器 0 端口为 `80H`，控制端口为 `83H`。
    * 初值 100 的低、高字节都为 `64H`，但必须连续写两次。

    ```asm
    PORT_0    EQU 80H
    PORT_CTRL EQU 83H

            MOV     AL, 34H
            OUT     PORT_CTRL, AL

            MOV     AL, 64H
            OUT     PORT_0, AL
            OUT     PORT_0, AL
    ```

* **接线边界**
    * 程序完成后，8253 每收到 100 个“每米脉冲”输出一次控制命令。
    * `GATE0` 若为低电平或悬空，就不能保证持续有效计数。

### 周期信号与时间间隔

* **周期拆分**
    * `1 MHz` 时钟的周期为 $1\ \mu s$。
    * `0.1 s` 对应 100000 个输入时钟，单个 16 位计数器装不下 100000。
    * 采用 `100000=1000\times100`，把总计数拆到两个通道。

* **级联配置**
    * 计数器 1 用方式 2、初值 1000，`OUT1` 接计数器 2 的 `CLK2`。
    * 计数器 2 用方式 3、初值 100，从 `OUT2` 输出最终方波。
    * `GATE1`、`GATE2` 均接高电平。

    ```text
    1 MHz → CLK1 → 计数器1（方式2，N=1000）
                         │ OUT1
                         ↓
                       CLK2 → 计数器2（方式3，N=100）→ OUT2
    ```

* **方式字**
    * 计数器 1 的方式 2、完整 16 位、二进制控制字为 `74H`。
    * 计数器 2 的方式 3、完整 16 位、二进制控制字为 `36H`。

    ```asm
    PORT_1    EQU 81H
    PORT_2    EQU 82H
    PORT_CTRL EQU 83H

            MOV     AL, 74H
            OUT     PORT_CTRL, AL
            MOV     AX, 1000
            OUT     PORT_1, AL
            XCHG    AL, AH
            OUT     PORT_1, AL

            MOV     AL, 36H
            OUT     PORT_CTRL, AL
            MOV     AX, 100
            OUT     PORT_2, AL
            XCHG    AL, AH
            OUT     PORT_2, AL
    ```

* **理想值与真实节拍**
    * 若按 1000 个输入时钟直接作为前级周期，理想计算为 $1000\times100\times1\ \mu s=0.1\ s$。
    * 方式 2 的真实稳态周期为 $(1000+1)\times1\ \mu s$，所以末级实际周期为 $100\times1001\ \mu s=0.1001\ s$。
    * 题目若严格要求准确周期，应按前级方式 2 的真实节拍重新选择初值，并在答案中写明采用的计算口径。

    * > **易错点**：把 100000 简单拆成 `1000×100` 只得到理想十进制拆分；严格计算必须带入方式 2 稳态周期的 `+1` 个时钟。

## 8253 应用题的确定顺序

* **先确定输入节拍**
    * 明确每路 `CLK` 来自固定时钟、前级 `OUT` 还是设备事件脉冲。
    * 设备每米一脉冲与固定 1 MHz 时钟的物理含义不同，不能互换。

* **再确定工作方式**
    * 一次到零通知选方式 0，硬件触发单脉冲选方式 1。
    * 分频和周期窄脉冲选方式 2，连续方波选方式 3。
    * 软件或硬件选通分别对应方式 4、方式 5。

* **再确定计数宽度和初值**
    * 初值不超过 255 时可只访问低 8 位；更大数值按 16 位先低后高写入。
    * 16 位初值不能一次通过 8 位数据总线送出，也不能先写高字节。

* **最后检查外部接线**
    * 连续工作通常把 `GATE` 接高电平；需要硬件触发时接入对应事件。
    * 级联必须把前级 `OUT` 接到后级 `CLK`，并逐级检查控制字、初值和 GATE。

* **最后核算输出周期**
    * 方式 0 和方式 1 的定时或脉冲宽度按 $NT_{\mathrm{CLK}}$。
    * 方式 2 的稳态周期按 $(N+1)T_{\mathrm{CLK}}$。
    * 方式 3 的完整周期按 $NT_{\mathrm{CLK}}$，奇数初值的高电平比低电平多一个时钟。

    * > **结论**：先看“时钟来源—工作方式—计数宽度—初值—输出连接—GATE”，再算波形；漏掉任何一项，程序和接线都可能与预期不一致。
