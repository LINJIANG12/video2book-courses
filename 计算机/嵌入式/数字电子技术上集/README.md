# 数字电子技术·上集（55 讲）

一门零基础、保姆级的数字电子技术（数字逻辑电路）入门课：从二进制、码制这些最底层的表示方法讲起，经逻辑代数的基本定律与卡诺图化简，进入半导体开关特性、TTL/CMOS 集成门电路的电气特性，最后落到组合逻辑电路的分析设计与加法器、比较器、编码器、译码器、数据选择器等常用中规模器件。每一步都从「为什么」讲起，不跳步、不堆结论，适合从零开始建立数电的完整基础。

- **全 55 集**（上集），已产出 4 册模块全书、6 篇复习笔记、39 份逐字稿

## 怎么学

- **先过逻辑代数这一关** → 笔记 01-02 把数制码制、定律规则与卡诺图化简收成速查表，这是后面一切章节的语言，卡诺图要练到看到变量圈就出表达式
- **门电路抓电气特性** → 笔记 03-04 讲清「为什么与门的输出是这个电平」：三极管/MOS 管的开关状态、TTL 与 CMOS 的电压传输特性、线与与开路门，是考试与电路调试的共同基础
- **组合逻辑按「分析-设计」两条路走** → 笔记 05-06 把分析（给电路求功能）与设计（给需求搭电路）的固定步骤配齐，再落到加法器、比较器、编码器、译码器、数据选择器的级联与扩展
- **上集范围** → 本课覆盖逻辑代数、门电路与组合逻辑；触发器与时序逻辑在「下集」，本页不涉及
