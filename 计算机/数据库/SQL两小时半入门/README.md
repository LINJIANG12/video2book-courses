# SQL两小时半入门（1 集）

一门零基础速成课：不是完整的数据库原理课，而是把「建库建表 → 增删改查 → 多表关系与 JOIN → 高级查询与外键约束 → Python 数据库操作」这条完整动手链路压缩进一堂课。讲法偏演示与操作，全程强调边看边敲；B 站虽只发布 1 集，但内容切成 P01上 / P01中1 / P01下 三个知识块，分别覆盖关系型数据库基础与 MySQL 入门实操、SQL 核心数据操作与多表关系建模、SQL 进阶查询/外键约束与 Python 数据库操作实战。同仓的《MySQL数据库入门到大牛》（199 讲）是完整的工具与工程实战课，《数据库系统原理》（28 讲）是原理理论课；这门课是「只想在两小时内跑通 SQL 全流程」时的最短路径。

- **原视频**：[【SQL数据库】SQL两小时半快速入门到精通](https://www.bilibili.com/video/BV1yw4m1S7Be/) — Bilibili，BV1yw4m1S7Be
- **全 1 集**（约 2.8 小时），已产出 1 册模块全书、1 篇复习笔记、3 份逐字稿

## 怎么学

- **零基础直接跟敲即可**：课程默认你没有数据库基础，从建库建表一路演示到 Python 连库，按顺序边看边建一个自己的练习库，比只读文字更快形成手感。
- **面试前速查就翻模块全书**：两小时半的课信息密度很高，模块全书把「建库建表 → 增删改查 → JOIN 多表 → 高级查询/外键 → Python 操作」的语法与命令按动手链路整理好，面试前一天过一遍就能捡回手感。
- **一定要边看边实操**：这门课是操作演示型，JOIN、外键、Python 数据库连接光看容易忘，跟着敲一遍比反复看视频有效得多。
- **三个知识块可独立查阅**：B 站虽然只有 1 集，但 P01上（关系型数据库基础与 MySQL 入门）、P01中1（核心数据操作与多表关系）、P01下（进阶查询/外键与 Python）切得清楚，想补哪一段直接定位。
- **想系统学就转 MySQL 大课**：这 2.8 小时只求跑通全流程、不求讲透原理与工程细节；需要完整工具链、性能与工程实践，回到同仓《MySQL数据库入门到大牛》（199 讲）。
- **课后回顾用那篇全景笔记**：笔记按语法点与实操链路组织，适合课后快速回顾和查具体命令，不用重刷视频。
