# 尚硅谷：5 天上手 MySQL 实战

尚硅谷韦峰老师的 MySQL 快速入门实践课，基于 MySQL 8.2 与 SQLyog 13 打造。课程以实战为主线，从数据库概念、安装配置一路讲到多表查询、约束与事务，适合零基础在短时间内建立可用的 MySQL 能力。

- **原视频**：https://www.bilibili.com/video/BV1Cm421373b — Bilibili，BV1Cm421373b
- **106 集**，已产出 4 册模块全书、8 篇复习笔记、21 份逐字稿

## 怎么学

- **先建环境** → 模块 01 讲课程介绍与概念澄清，先把学习目标对齐
- **吃透 SQL** → 模块 02~04 覆盖安装、建库建表、数据维护与多表查询
- **数据完整性** → 模块 03 系统讲解约束与建模，是后续所有查询的地基
- **工程收尾** → 模块 04 以事务概念收官，配合 `notes/` 里的笔记做速查
