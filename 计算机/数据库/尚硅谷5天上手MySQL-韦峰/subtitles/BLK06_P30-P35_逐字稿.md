但是它具体包含哪些操作呢？接下来我们来一一介绍一下。首先在 DML 环节，我会分为两个小章节进行讲解。第一个小章节就是老样子，先介绍一下 DML 这个语言，以及也会介绍一个行是最基本的操纵单位，大家心里边先有个概念。第二，我会去讲一下这个 DML 语言的语法和实战，一共就两个小章节。首先我们先进入到第一个小章节，数据操纵语言的一个概述和介绍。

首先数据操纵语言的作用是啥呢？我给大家解释一下，它的作用主要有三个，分别是插入数据、更新数据和删除数据。其实兄弟们，我也不用给它兜圈子，大家应该知道，数据库无非就是对数据进行存储和一些操作的一个工具。它的操作主要分为四个方向，分别是增、删、改、查。而 DML 这个方向的语言，它把查给剔开了，剩下的是增、删、改，就是我们的 DML 语言。

那你说为什么把查给剔出去呢？因为查询跟它们仨有些不同点。查询它不会改变原有的数据，也就是说你不管对表怎么查，数据不会丢，也不会多，也不会少。但是这三个哥们儿它们会真正地影响表数据，所以它把它们给分开了。

那完毕以后，我们接下来再做一个细化介绍。数据操纵语言它也叫操作语言，操纵、操作都一样。这里边它取的单词是什么呢？Data Manipulation Language 的缩写，叫 DML。它内部主要有三个操作，分别是插入、删除和修改数据这三个操作。

但是大家要了解一点，就是 DML 这个语言它不会影响库表结构，也就是说你不管怎么删数据，别怕，你删不了表，也删不了库，它只是对内部的数据进行影响。当然，你也不能把数据都删了，那不是删库跑路了吗？对不对？但是大家要知道一点，它们会真正地影响库中的数据，所以你删了数据，那它真的就没了，这一块大家要知道。

它内部有三个关键字，分别是 INSERT、UPDATE 以及 DELETE，分别对应的是插入、更新和删除。大家一定要把这三个关键字记住，一会儿我会围绕这三个关键字把这三个动作给大家讲一遍。那到这儿我们就对 DML 做了一个基本介绍。

那除此以外，我还想再给大家做一个拓展。删除的时候我要删除哪些呢？修改我要修改哪些呢？插入我是怎么插入呢？其实在大家对数据操纵的时候有一个最基本单位，我们都要围绕基本单位进行插入、删除和更新。接下来我们来看一看这个基本单位是什么，咱们理解一下。

首先数据库中操纵的最基本单位是行。之前我们在介绍关系型数据库的时候一定提过，关系型数据库一共有四个单位，分别是库、表、行、列。列是最小的单位，对吧？库是最大的单位，但是行是最基本的单位。也就是说我们真正删除的时候也是以行为单位，删除哪一行数据或删除哪些行数据。修改也是修改哪一行的哪个数据。插入也是插入一行数据、一行数据插入。所以大家记住，行是操纵的最基本单位。

接下来给大家解释一下，举个例子，假如说我们这儿有一个表，表中呢有若干的列。接下来假如说我想要插入数据怎么办呢？我是先选中一行，往行中去插入对应的数据。所以大家记住，你插入的数据就是一插入就是一行。行与行之间当然互不干扰了，对吧？第二，假如说我想修改数据怎么办呢？也一样，你先去锁定一行或者是若干行也可以，当然锁定哪些行之后是有条件准备的。锁定行以后是改变行中的某些列。大家一定要找准这种感觉，行是最基本单位。完毕以后，最后我想删除数据，也同样道理，怎么删除呢？就是选中一行，把这一行的数据给它删除了，就可以了。所以到这儿我们需要明白一个事儿，不管我们是插入、删除和修改，我们最基本的单位都是什么呢？都是行。

讲完数据库操纵语言的概念以后，接下来我们来一一去实战增、删、改相关的语法。我们进入到第二小节。首先第二小节我们先讲的第一个语法就是插入数据。

插入数据我将情况分为三种情况。第一种情况就是插入一行中的所有列；第二种情况就是插入一行，但是不插入所有列，指定列插入；第三是同时插入多行数据。那我们一一说。

在讲它之前，大家在脑海里边儿先回忆一个事情，就是增删改查最基本单位是行，所以你要插入的时候是一行。第一种插入方式就是一行中的所有列，那语法就是：

```sql
INSERT INTO 表名 VALUES (值1, 值2, ...);
```

INTO 和 INSERT 它是好基友，不分家。第二是要插入指定的表名。VALUES 代表你要插入一行中的值，而后边的一个括号就代表一行。那一行中有几个列，就在里边写几个值，中间用逗号隔开就可以了。这就是为表中的一行插入数据。

例如你看，这我们有一个表，里边是有三列，假如第一列是名字，第二列是年龄，第三是性别。那你就围绕第一个写的时候，值 1 就应该是名字这个字符串，第二就是年龄这个数值，第三再写个逗号隔开，再写个性别这个字符串就可以了。

那如果要是全列插入，它其实有优点，优点就是语法更简洁，表名加 VALUES 就可以了，不需要指定插入一行中的列。但它的缺点就是你得记住你当初这个数据库中一共有哪些列，且 VALUES 的值的顺序要跟你数据库中表的列的顺序要一致。大家思考个问题，如果一个表中有 50 列、60 列，你能记得住吗？如果记不住，那我就不推荐第一种方案，大家理解吧？所以大家注意，你在插入的时候，这个 VALUE 值也要跟当初的列的顺序一致。

如果你记不住这种怎么办呢？推荐使用第二种方案，叫指定列插入。这种语法其实就是可以写：

```sql
INSERT INTO 表名 (列名1, 列名2, ...) VALUES (值1, 值2, ...);
```

只怪在后边多了一个括号。这个括号的位置指定你要插入哪些列。最后在写 VALUES 的时候，VALUES 后边的这个值就按照你前期指定列名的顺序进行插入就可以了，就不按照原表的列名进行插入。当然，这些列也可以是一个表中的全部列，例如说这边指定三列也是可以的，但这边也同样可以指定两列、一列也是可以的，顺序也可以自己随意指定，大家理解吗？这样就相当于会更加灵活，且在前面是有体现你要按照哪个顺序去填值的。这就是我们推荐的第二种方案，指定我们对应的列进行插入，这样容易正确，容易避免错误，对不对？

除此以外，有的时候假如说我想一次插入多行数据怎么办呢？就是上面两种语法都一样，加个变异。加什么变异呢？就是我们说了一个括号就代表一行数据，你可以逗号隔开，再写一行数据，逗号隔开，再写一行数据。就可以写多个括号，里边放多对 VALUE 值就可以了。但还是那句话，VALUE 值的类型和它对应的顺序要跟我们表中的列名，或者你指定的列名和类型要一一对应。这个大家能理解了吗？

讲完以后有两个小结。第一，注意在写 VALUES 的时候这儿有个特别，除了 VALUES 也可以写成 VALUE 这个关键字，也是可以的。这个关键字可以换成 VALUE 或者 VALUES，但是 VALUES 是标准的语法，所以我们推荐用 VALUES。第二，如果大家在插入数据的时候是字符串还是日期类型，别忘了在外面加一个单引号，代表它是字符，就可以了。这就是我们的插入语法，大家可以先去把视频暂停，把这记一下。

接下来我们来介绍一下数据操纵语言的另外一个方向，叫修改语句。修改主要分为两个方向：

第一是全表修改，指的是修改表中所有行的数据。举个例子，将学生表所有人的年龄都加一岁，这边没有任何条件，不需要筛选任何行。

第二种叫条件修改，这里边会在上面基础加一个 `WHERE` 关键字。它指的就是来筛选符合条件的行。举个例子，去更新一下身高大于 1.60 的学生的年龄信息。前面是不是有一个条件，要身高大于某某值，才去修改。第二种就说不是全表，只是修改符合条件的行。

我们来看两个语法。

第一个，全表修改。它的关键字是 `UPDATE`，后面紧跟的是表名 table_name。除此之外还有一个关键字叫 `SET`，大家一定要记住。`SET` 代表的是你要把这行的哪些列等于哪个值。这写法就是：
```sql
UPDATE 表名 SET 列名 = 新值, 列名 = 新值;
```
如果你一次想改行中的多个列，用逗号隔开，就是列名等于值、逗号隔开、列名等于值就可以了。这就是我们的全表修改，它会把表中的所有行都按照你的 `SET` 列名等于新值全部修改掉。

第二种修改叫条件修改。它只不过在第一种的基础上加了一个 `WHERE` 关键字。`WHERE` 关键字本次我们只是初步先体验一下，我们在查询的时候再着重去讲 `WHERE` 关键字。它指的是对表中的行进行筛选，筛选到符合的行以后，再去修改行中对应的列。这就是两种修改方式。

接下来我们在原有的学生表中准备一些数据。准备好数据后，下方我们有四个对应的练习，打开客户端把这个练习实践一下，来强化对 `UPDATE` 语法的理解。

首先对修改语法进行一下总结。修改语法无非就两点：

第一是全表，表中所有的行都改，它的语法就是：
```sql
UPDATE 表名 SET 列名 = 新值, 列名 = 新值;
```
第二是条件修改，其实就是在全表修改的基础上加一个行筛选，它后边取一个关键字叫 `WHERE`，可以写一些条件：
```sql
UPDATE 表名 SET 列名 = 新值 WHERE 条件;
```
它只会修改符合 `WHERE` 条件的这些行。

注意一下，第一点强调一下，如果不添加 `WHERE`，代表的是修改一个表中的所有行的数据，把所有行的这些列数据都改了；反之，只修改符合 `WHERE` 条件的。第二点，如果修改多个列，`SET` 的后边要写列名等于值，逗号隔开，再写列名等于值，它们之间用逗号隔开就可以了。这就是修改语法，没有什么难的。

接下来下方我们来做个练习。首先我们已经有了一个表，把数据给它插入进去。

修改有四个练习，我们一个个来做。

第一个，将学号为 8 的学生的姓名改成黄六。这是全表修改还是条件修改呢？很明显，这有一个条件叫学号为，那应该怎么做呢？
```sql
UPDATE students SET stu_name = '黄六' WHERE stu_id = 8;
```
前面是一个 `UPDATE` 关键字，改表 students，把学生的姓名改为黄六。姓名这个列叫 stu_name，等于黄六。黄六是字符串，直接加引号。条件加个 `WHERE`，`WHERE` 这儿叫“为”，说白了是不是就等于的意思，列名 stu_id 等于 8。这就相当于学号等于 8、学号为 8 的改成黄六。执行完以后，学号为 8 的就改成黄六了。它的语法相当于先找到符合条件的行，即这一行，再把里面的列改成黄六，后面的执行顺序会早于前面的修改。

第二个，将年龄小于 20 的学生的身高加 2.0，在原有基础上加 2.0。这是什么意思？我们这里边会有学生的年龄这个条件，将年龄小于 20 的，假如说 19 的，把它们的身高都加 2 这个数值。这个要怎么写呢？
```sql
UPDATE students SET stu_height = stu_height + 2 WHERE stu_age < 20;
```
`WHERE` 条件是 `stu_age < 20`。身高怎么改大家注意，这两个是符合条件的，这两行符合条件，但它改的值是不一样的。它们一个是 1.65，一个是 1.85，改后一个值是 1.67，一个是 1.87。`SET` 后面这个值一旦你写了以后，相当于它们俩都会变成同一个值，而不是两个相对的值。它的写法是在取到原有的值基础之上加 2，即 `stu_height + 2`。这个的语法指的是在取到原有的值的基础之上加 2。你是 165.8，加完以后变成 167.8；如果你是 185.5，加完就变成 187.5。可以利用原值去做。

但是注意，不能怎么写呢？有人说我学过 Java，Java 里面可以写 `+= 2`，这个语法是不支持的。Java 跟 SQL 语句的标准语法还是有区别的。它的支持语法只支持取到你原来的列，在右侧原有的列的值上去加。能加大家也注意，也能减，也能乘，也能除，就是可以使用原列进行运算。

执行完以后它影响了两行，1.67、1.87 就搞定了。

接下来下方，将学号为 11 的学生的生日修改为 2003-07-10，且年龄改为 21。这代表改两个列且有条件：
```sql
UPDATE students SET stu_birthday = '2003-07-10', stu_age = 21 WHERE stu_id = 11;
```
时间是一个特殊格式字符串，写上就可以了。这是一个列修改，还有一个列用逗号隔开，`stu_age = 21`。学号为 11 的是孙八，我们执行一下。刷新，孙八变成 21，变成 7 月 10 号了。

下方，将所有的学生的年龄增加一岁。过年了，数据库当中所有学生的年龄要增加一岁，是不是在原有基础上增加一岁？其实语法并不难：
```sql
UPDATE students SET stu_age = stu_age + 1;
```
这是取到原值，在右侧加 1 以后赋给新的列名。最终的条件是所有，没条件，那就不用写了。这代表找到每一行，把每一行的所有的年龄都改一下。刷新一下数据，大家是不是都增加了一岁。

这就是我们要给大家介绍的修改语法，大家也把这个做一下练习就可以了。

接下来我们来讲一下 DML 的最后一个操作，就是删除了。网上经常有人开玩笑就是删库跑路，那个删库其实……

删除库中的表结构是库表结构层面的操作，而我们这里的删除指的是删除表中的相关数据。

它的删除一共分为两种：第一种是全表删除，即把一个表中的所有数据删除掉。说到这里，有些同学可能会回想起来，之前在讲表的操作时也讲过清空表数据。其实它们两个动作的效果是类似的，都会把表中的所有数据删掉。但是 `DELETE` 这种删除的语法相较于清空表的 `TRUNCATE` 语法会更轻一些，它只删除当前表的数据，但不会删除表相关的记录，例如自增的最大 ID 值等等。第二种就是条件删除，在删除的时候先选中符合条件的行。最基本的数据库操作单位是行，选中行以后再进行删除。在开发中，99% 的需求其实全是条件删除。

这两种语法分别为：
全表删除所有行：
```sql
DELETE FROM 表名;
```
条件删除，只删除符合条件的行：
```sql
DELETE FROM 表名 WHERE 条件;
```

在正式练习之前，我们先把 DML 的核心内容做个梳理。整个 DML 语法学完后，大家需要掌握三个小目标：
第一，掌握语法的关键字和作用，分别是 `INSERT`、`UPDATE` 和 `DELETE`，要把基本的语法结构掌握好。
第二，一定要理解数据库操作的最基本单位是行。无论是插入、修改还是删除，针对的都是整行，理解了这点才不会在操作时感到困惑。
第三，掌握具体的三种语法细节：如何进行全表插入、如何指定列插入、如何插入多行数据；更新时如何在原有的列上进行修改、如何指定多列更新；删除时如何按条件清除等。

接下来我们在客户端中进行实操演练。

删除语法主要分为两种：
第一种是全表删除。语法是 `DELETE FROM 表名;`，代表删除一个表中的所有数据。
第二种是条件删除。语法是 `DELETE FROM 表名 WHERE 条件;`，只有符合条件的这些行才会被删除。

需要注意，在实际开发中很少使用全表删除，绝大多数情况下使用的都是条件删除。另外，`DELETE` 删除和之前讲的清空表 `TRUNCATE` 删除之间有明确区别：两者都会删除表中的全部数据，但 `TRUNCATE` 删除的程度更重一些，它不仅删除表数据，而且会重置数据库自增 ID 的最大记录值。如果单纯删除数据，通常使用 `DELETE`；如果项目推倒重来、要上新项目，需要将原有数据完全清空，才会使用 `TRUNCATE`。而业务运行过程中因逻辑需要删除某条数据，则必须使用 `DELETE`。

接下来我们完成几个练习：

第一，删除年龄大于 23 岁的学员：
```sql
DELETE FROM students WHERE stu_age > 23;
```
这里的条件写法，无论在删除、修改还是后续的查询中都是通用的。具体的复杂条件写法，后续在查询章节会详细展开。

第二，删除身高高于两米且学号大于 10 的学员。这里包含两个条件，需要使用且关系：
```sql
DELETE FROM students WHERE stu_height > 200 AND id > 10;
```
在 SQL 中，条件之间的逻辑关系可以使用关键字 `AND`、`OR` 等来连接。两个条件都必须符合时，使用 `AND`。

第三，删除身高大于两米或者学号大于 10 的学员：
```sql
DELETE FROM students WHERE stu_height > 200 OR id > 10;
```
中间是或者的关系，使用关键字 `OR` 即可。

第四，把表中的数据全删掉：
```sql
DELETE FROM students;
```
后面不加任何条件，执行后即可清空表中所有行的数据。打开表数据刷新验证，表中数据已被清空。以上就是删除的相关操作，到这里所有的 DML 操作就讲解完毕了。

首先来看第一小节：DQL 的概述和作用。

DQL 全称为 Data Query Language，即数据查询语言，顾名思义主要用于执行数据的查询操作。它将查询与 DML 中的删除、保存和修改区分开来，单独进行梳理。DQL 与 DDL、DML 有一个共同点：都不会改变库表本身的物理结构。在此基础上，DQL 还有一个特性：它不会修改原有的表数据。无论如何对表执行查询，原有的数据记录都不会发生改变，它只是在原有表数据的基础之上查出一个虚拟结果。当执行一条查询语句时，数据库会生成一个临时的虚拟表展示给用户，对底层的原有物理表没有任何影响。这就是查询语句的核心意义。

其内部最核心的关键字是 `SELECT`，代表选择与查询，用于从原有表中筛选出所需的数据结构。

在查询的分类上，主要分为单表查询和多表查询两类。所谓单表，即查询结果来自于单张真实的数据库表，通过查询语法最终生成一张虚拟表，这就是单表查询。

单表查询需要学习的内容包括：
作为开篇关键字的 `SELECT` 语法；用于按行筛选数据的 `WHERE` 条件语句；用于结果运算的各种运算符；用于丰富查询结果的内置函数；以及用于对结果进行分组、排序的高级操作。

而多表查询并不是颠覆单表查询的语法，它是在单表查询的基础之上扩展了部分语法。其执行过程是：查询结果来源于多张真实表，第一步先使用多表合并语法，将多张表的数据合并成一张虚拟的中间表；合并完毕后，再正常套用单表的查询语句与语法，最终生成目标虚拟表。因此，只要学好单表查询，后续多表查询只需额外掌握合并语法即可顺理成章地掌握。

接下来进入第二小节，讲解单表查询的基本语法。单表的基本语法常见于五种场景：

第一种场景是非表查询。查询语句通常是对原有物理表进行数据筛选并生成虚拟表，但也有特殊场景：查询时不指定具体表，直接快速输出一个结果，类似于 Java 中的控制台打印输出。
例如：
```sql
SELECT 1;
```
该语句直接输出数值 1。
又如：
```sql
SELECT 9 % 2;
```
该语句直接计算 9 取模 2 的运算结果。
还可以调用内置函数：
```sql
SELECT version();
```
`version()` 是数据库提供的一个函数，用于获取当前 MySQL 的版本号。加上 `SELECT` 后，就相当于把该函数的执行结果打印输出，类似于 Java 中的 `System.out.println` 输出函数返回值到控制台。非表查询通常用于快速输出表达式的运算结果或函数的返回值，后面不需要接 `FROM 表名`。

第二种场景是指定表查询。语法结构为：
```sql
SELECT 列名1, 列名2, ... FROM 表名;
```
`FROM` 后面指定需要参照查询的目标表，`SELECT` 后面跟上需要从该表中获取的具体列名。多列之间使用英文逗号分隔。

例如，学生表中有多个字段，但本次查询只需要展示两列或一列，最终虚拟表的结果就只包含指定的列。在书写列名时，也可以采用 `表名.列名` 的格式。这种写法在多表查询中极为常用，用于避免多张表中存在同名字段时产生歧义。如果在单表中使用，直接写列名即可，数据库默认会从当前表中定位该字段。

如果需要获取表中的所有字段，可以写成 `表名.*`，也可以直接使用通配符 `*`：
```sql
SELECT * FROM 表名;
```
星号通配符代表获取后方指定表中的所有列。如果是单表就获取单表的所有列，如果是多表则获取多表的所有列。各字段在虚拟表中的排列顺序与查询中书写的顺序保持一致。

第三种场景是在查询时为列起别名。在 `SELECT` 关键字与 `FROM` 关键字之间配置列名，而在表名之前……

可以放很多列名。如果查到一个列以后，想给这个列去起一个别名，那这个怎么起呢？你可以用一个关键字叫 AS，就是列名 AS 别名。最终查到的结果，在虚拟表中会以别名作为基准去显示虚拟表的结果。

除此之外还可以怎么起呢？在中间加空格也可以，就是列名空格别名也可以，就可以省略 AS，中间用空格。但是别写逗号，如果写逗号以后代表的就是多个列。

为什么起别名呢？说一个场景，举个例子。假如说我们有一个 student 这个表，它里面有个叫 student_id 这个列，还有一个叫 student_name 这个列。我们要基于它查到一个中间的虚拟表。查出虚拟表以后，最终假如说我用 Java 语言去开发，要把这个虚拟表存到 Java 中的一个类上。Java 中类在命名的时候就不能叫下划线了。假如我有一个 Student 类，它内部有 studentId，我们用的是驼峰式命名，还有 studentName。后期我想让它自动映射，如果你想把数据库中的数据结果映射到实体类，它有要求，要求列名跟实体类的属性名是一致的。

现在不一致怎么办呢？其实我们在查询的时候，中间会生成一个叫虚拟结果表。我们可以在虚拟结果表给它起别名。例如说第一个 student_id，可以写 AS 起个别名叫 studentId。这样查到的表里的列名就叫 studentId 了。同样下方也可以给 name 起个别名，就是 student_name 空格也可以，叫 stuName。这样我们后期可以快速映射到 Java 中的实体类上。原因就是列名不等于实体类的属性名，你需要给它起个别名，让虚拟结果跟它映射上，方便我们把数据映射到实体类上。大家先记住起别名的语法，后期这个场景我们在开发中再去用就可以了。起别名的语法就是 AS 或者直接加空格，不要加逗号就可以了。这是第三种场景。

第四种场景是去重复。它有一个关键字叫 DISTINCT。这个关键字可以对我们查询的这些列的值进行去重复。这边可以写一个列，或者逗号隔开写多个列。如果写多个列，它就对多列的综合结果去重复。

举个例子，单列的时候，假如我有一个学生表 student。学生表里面有一个年龄 age 字段，年龄的值有 1、1，假如都是 1 岁，2 岁、2 岁，3 岁、3 岁，4 岁。如果我想查询这个表：

```sql
SELECT age FROM student;
```

这代表把表中所有行都拿到，拿到 student 的 age 列。最终查的虚拟结果里面有 1、1、2、2、3、3、4，会拿到对应的 6 个结果。如果不想拿这么多，就想拿一共有几种年龄，重复的只出现一遍就可以了，只需要在前面加上一个 DISTINCT 关键字就可以了。如果是单列，会对单列结果进行去重，最终拿到的结果只有 1、2、3、4。

DISTINCT 后面可以写多列，比如写 age，再写一个其他列比如性别 sex。它是怎么去重呢？它会用两列的综合结果去重。比如这里有个 1-男，年龄是 1，性别是男；还有一个 1-女，女学生。在查的时候就会把它俩作为一个综合，一男、一女，这两项不是重复的，最终结果会查到 1-男，也会查到 1-女。因为它是以两列的综合结果看是否重复才去做去重。同样可以再写逗号写多个列，按照几列的综合结果去重就可以了。DISTINCT 是对结果进行去重的，必须加在 SELECT 的后边、列名的前方，后面可以加一个列或者多个列。

最后一种场景叫查询常数。查询常数指的是我们自己造一个数据，伪装一个列放到结果中。我们在查询的时候，可以在这个位置去写列名，列名指的是去表中找到这些列名。另外还可以写常量值，比如写 `'尚硅谷' AS 某一列`。这里边是没有“尚硅谷”这一列的，它就是一个常量值，每次查询结果的时候都会多一列，里面值就叫“尚硅谷”，相当于人造出来的一个常数列、固定值。

假如我们有一个员工表，里面有员工 ID，有员工的 name。想查所有的员工信息：

```sql
SELECT * FROM 员工表;
```

它就会把所有员工的 ID 和 name 这两列都拿到。这些员工全是我们尚硅谷的，想在查出的结果里再加一列表示它的公司，值全都是“尚硅谷”这个字符串。“尚硅谷”字符串就相当于一个常数，在写的时候就可以这么做：

```sql
SELECT *, '尚硅谷' AS 公司 FROM 员工表;
```

这样每一个行中都有一个常数列，叫“公司”，值等于“尚硅谷”。

到这里为止，我们介绍了 SQL 语句的基本语句，在不加条件时代表拿到一个表中的所有行的数据。这里边讲了几种场景：
第一种是非表查询，怎么去快速输出一个运算值或者函数值；
第二种是指定表查询的时候，怎么去指定一个表，表中的列怎么指定，可以逗号隔开，或者在多表的时候写“表名.列名”，或者写“表名.*”，或者写“*”；
第三种是在查询列的时候给这些列起别名，为了后期方便跟 Java 进行映射；
第四种讲了去重语句，加了一个 DISTINCT，必须加在前方；
最后还介绍了常数。
