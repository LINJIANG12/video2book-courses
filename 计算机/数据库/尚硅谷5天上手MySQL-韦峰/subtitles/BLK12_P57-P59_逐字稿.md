首先先进入到第一个小节：约束的概述和分类。

先提一下约束。约束这个词大家在生活中经常会有，举个例子，小时候学校会约束你不能去网吧、不能去游戏厅，其实你的家长也会约束。如果去了游戏厅或网吧被家长抓住会怎么办？难免来一顿男女混合双打。约束指的是对某些行为的一种限制，但是这些限制并不一定是坏事，它可能是对我们有一个保护等一些作用。

数据库的约束是什么意思呢？数据库的约束是一个表级别的一种规定，它是对表中的数据的一种限制语法，这叫约束。注意它是来限制数据的。

为什么突然间要限制数据？举个例子，假如说我们有一个学生表，学生表里面有一个手机号列，我要求学生在填写的时候必须要填写手机号。你要怎么去限制呢？这时候就可以在手机号这列加一个非空约束。除此之外其实还有很多，例如填身份证号不能重复，要唯一约束等等。这些都属于约束。

约束的作用是来保证表中数据的一个准确性、可靠性和正确性。你不要去相信录入数据的人，你更应该去相信约束给你带来的保障。如果他不符合我们的约束，最终在插入或修改的时候会报错。

约束添加的时机一共有两种：第一种就是在我们创建表的时候可以添加，在 `CREATE TABLE` 的时候添加；第二种如果表创建完毕以后，我们后续也可以利用 DDL 里面的 `ALTER TABLE`，修改表的时候去添加相关的约束，也是可以的。通过本章的学习，能让大家在创建表结构的时候，表会更加合理和清晰。

约束的分类一共分为三类：第一类叫列或者域级别的约束；第二是实体或者行级别的约束；第三是引用参照，一般叫做引用约束，或者是多表级别的约束。一共是三个分类，这几个分类只是为了方便大家去记忆这些约束，相当于给大家分一个子类。

第一，什么叫列和域级别的约束？这一类约束只对当前的列有效果。举个例子，像我们刚刚说的手机号不能唯空，这就是一个列级别的约束。它不需要去关注其他的行、其他的列，只需要关注我自己是否符合这个约束，这叫列级别的约束。

具体列级别的约束都有什么呢？大家记三个：
第一个是非空约束 `NOT NULL`，要求就是某一列不为空；
第二个是默认值约束 `DEFAULT`。举个例子，在某一列可以给它一个默认值约束，如果在插入数据的时候你不指定或者指定空，它都会走默认值；
最后还有一个检查约束 `CHECK`。

这个约束并不是列级别的，它是表级别的，但是放在这个位置说也比较好理解。CHECK 指的是检查某一列是否符合我们的一个规则。举个例子，假如说我们有个 age 这一列，插入的数据的年龄要求大于 18 岁，这时候就可以用 CHECK 约束在里面写一个规则，要求大于 18 岁，否则无法插入。CHECK 约束相当于是一种自定义约束，它可以写任何的规则。大家先这么记，它是列级别的约束。列级别的约束再强调一下，只针对当前列有效，它不需要关注其它列。

第一说了，第二我们来说说实体和行。什么叫实体和行呢？之前我们也介绍过。MySQL 是一种关系型数据库，每个表代表一种大的类别，相当于我们之前 Java 中的 Class 的概念。而表中有个行的概念，行是操作的最基本单位，一行就代表一个实体。一行数据对应的相当于就是我们用 Java 语言来说的一个对象。

所谓的行级约束是什么意思呢？此类约束需要对比同一个表中其它行的数据才能有效，或者才能得出结果。之前列级别的约束只能以单列就知道它行不行，而行级别不行，它得对比其它行，才能判定出它对应是否达到这个效果。

举个例子，第一个，例如主键约束。这个主键约束先给大家提一嘴，它代表不为空且这个值要唯一。大家思考一个问题，假如说我们有一个表，表里面有很多行，第一行有一个属性值叫 id，在这个行上面加了一个主键约束，那就要求这一行里面写数值的时候，这要写 1，这儿就不能再写 1 了。如果要写 1 就重复了，它要求不能重复且不能为 NULL。那这一列到底能不能插入，是不是要对比其它行？对比其它行这个列，才能知道当前能不能插入。所以这个时候，这类约束就叫做行约束，或者叫实体级别约束，它需要参照其它行才能得出结果，这就是主键约束。

下边还有一个唯一约束，叫 UNIQUE。它跟主键约束的不同点就是，主键约束是唯一且不为空，而唯一约束指的是它可以为空。举个例子，刚刚的手机号如果添非空约束并不好，假如没有手机号，但换句话说，如果有手机的话，学生之间的手机号不应该重复。我建议手机号在加约束的时候可以加一个 UNIQUE 唯一约束，可以没有手机号不写，但如果要写了，这一列里面的手机号之间就不能重复，这就叫做唯一约束，所以它也是一个行级约束。

完毕以后下边会有个自增长约束，后面我们会讲，它对应的是主键类型，它的数值假如第一个是 1，第二个它就自动在原来的基础涨 1，变成 2、3，它会参照之前的一个值进行递增涨，所以这也是一个行级约束。先记大概有哪些约束，大概它的分类就可以了，这就是我们的行级或者实体约束。

最后还有一类约束，叫引用约束，其实它也叫外键约束等。这类约束有个特点，它需要对比的不仅是不同行了，它需要对比其它表才能得到效果，所以这类约束也叫多表约束。这些约束的类型对比范围是逐渐增大的。

怎么才能说对比多表才有效果呢？举个例子，假如说我们有一个学生表，还有一个分数表。分数表里面要引用学生表的一个名字，或者引用学生表的一个学号。这个引用学号能不能瞎写？学生表里面有学号，还有一个姓名，学号是 1 号、2 号；而分数表里面有分数、学科，还有学生的学号。分数是 99 分，学科是 Java 的，这儿写个 1 号学生；20 分是 MySQL 的，是 2 号学生。那这个学号的值能瞎写吗？不能，我们是不是要参照它是哪个学生的分数？这里面相当于引出了多表之间的关系。假如想要写个 3，都没这个学生怎么能写 3 呢？所以这时候我们可以对这一列加一个参照约束，或者叫引用约束，叫 FOREIGN KEY。加了以后，这一列的值必须要参照另外一个表的某一列的值。这个约束是来限制多表之间的，限制跟另外一个表之间的数据是否匹配，所以这类约束叫多表级别的约束。

到这儿为止，我们一共是有三大类：前面两个都属于同一个表内的约束，第一个指的是对单个列的一种限制，有三个：非空、默认值和 CHECK；第二个是同一个表中不同行之间的一种约束限制，也有三个，分别是主键约束、UNIQUE 约束以及自增长约束；第三个是我们说的多表级的约束，它里面只有一个，指的是某一列必须参照另外一个表的某一列，否则不能瞎写，否则就报错。一共我们要学的约束是 $3+3+1$，一共是 7 种。

我们会学约束的三个方向：第一，我们需要理解每个约束的作用；第二，我们要学会如何去添加这类约束，完善我们的表结构；第三，要学会如何去删除这类约束。

接下来进入到具体的约束类别讲解。首先进入到第二章节，专门讲一讲列和域级别的三个约束，分别是非空、默认值和检查约束。

首先讲一下非空约束。非空约束的作用其实很简单，就是来限定某一个字段或者多个字段的值不能为 NULL，这就是非空约束。表里面有两列，一个是 age 和 name，假如说这两列的值不能为 NULL，就需要给这两列加上非空约束。非空约束的关键字叫 `NOT NULL`。

在说添加非空约束之前，先说几个非空约束的特点：
第一，所有的类型都可以加非空约束，包括数值类型。如果有数值类型的列，不添加非空约束也可以放空值 NULL，加非空约束以后就变成不能为 NULL 了。
第二，非空约束是加在列上的，在创建表过程中或修改表过程中，就可以在列的后边直接追加非空约束。
第三，可以多次使用，一个表中可以有 $N$ 个列加非空约束，并不是只有一个。
最后，关于空的判定：空字符串不算空，数值的 0 也不算空，只有真的 `NULL` 才算空。

非空约束添加的方式有两种：第一种是在创建表的时候添加；第二种是在建表以后修改添加。

第一种在创建表的时候，只需要在字段、类型后面加个 `NOT NULL` 就可以了，代表当前这个列是非空的。如果有多个列，继续再加就行了。

第二种是在修改表，在 `ALTER TABLE` 后面写 `MODIFY`，修改某个表中的字段还有原类型，最后再加上 `NOT NULL`。`MODIFY` 可以修改字段的一个类型，如果类型不变，只要加 `NOT NULL`，就相当于对原有的字段添加一个非空约束。

删除也很简单，可以通过后续修改表给它变为空。第一种就是 `ALTER TABLE 表名 MODIFY 列名 数据类型 NULL`，把 NOT 去掉，就可以为空；或者 `ALTER TABLE 表名 MODIFY 列名 数据类型`，后边不写 NULL，啥也不写，如果一个列不写，默认是允许为空的，这时候相当于也是允许为空。

总结一下：
1. 语法：在列后边加 `NOT NULL`。
2. 作用：限制某一个列或者多个列的值不能为 NULL。
3. 注意事项：
   - 所有类型的列都可以添加非空约束；
   - 非空约束只能添加到列上；
   - 一个表中可以有多个列是非空的；
   - 非空的判定问题：空字符串不算空，0 不算空，只有 NULL 算空。

添加的方案有两种：
1. 可以在创建表的时候添加；
2. 在创建表以后修改添加。
最后是删除非空约束。

来创建一个表叫 emp1，里面有一个 name 和 age，把 name 这一列在创建表时加非空，age 在后期修改表再加非空约束。

```sql
CREATE TABLE emp1 (
    ename VARCHAR(20) NOT NULL,
    eage INT
);
```

执行创建表语句。建好以后怎么看有没有非空约束呢？可以用关键字查看表结构：

```sql
DESC emp1;
```

用 DESC 能看表结构，第一个 Null 属性是 NO，不能为空；第二个是 YES，可以为空。

怎么在创建表以后修改呢？用的是 ALTER 关键字：

```sql
ALTER TABLE emp1 MODIFY eage INT NOT NULL;
```

这就加上非空了。再执行 `DESC emp1;` 看一下表，这个位置也不能为空了。
