那怎么解决这个方案呢？我再给大家介绍一个函数叫 `IFNULL`，咱们碰到就说。`IFNULL` 是 SQL 语句中提供的函数，第一个要写你的列，第二写一个为空的时候你给予的默认值：
```sql
IFNULL(列名, 默认值)
```
啥意思？第一个你放个列名，第二你给空给它一个默认值，它如果是空你想给它什么值。那这里边大家想个问题，如果他这个奖金占比为空，我给的值是不是应该是0？那这样它就会跟0运算，它就得0，就不会出现空了，能理解吗？所以大家注意，可以用 `IFNULL` 去解这个问题。

那这个怎么做呢？咱们把它稍微变一下，大家看着，还是同样这个 SQL 语句，咱复制一遍拿过来。这个位置，月薪一定不为空就不用管；这个他的奖金是不是可能为 `NULL`？这块可能为 `NULL`，那怎么办呢？你可以这么运算：
```sql
IFNULL(commission_pct, 0)
```
奖金咱们给它括起来，括了以后，当它等于空的时候这个值等于0。但这个值是你自己设置的，但现在它只要占比为空，那就相当于给0。除了这以外大家举个例子，假如说我们公司这规定，如果你指定的奖金占比你就有，如果没指定的没关系，我们会有一个基础的，大家都是0.05。谁都有奖金占比，如果为空没指定的就是0.05，那这你就写成0.05。还有某种场景，举例假如说我们有一个年终奖字段，假如说这有个年终奖字段，每个公司大家都有年终奖。如果写了年终奖的值就是你写的值，如果没写大家都是1000。我写空的，那是1000。那怎么办呢？就 `IFNULL(年终奖, 1000)`，是不是就可以了？所以这个值是自己指定的。当它为空就等于0，0跟你工资乘是不是就等于0了？
