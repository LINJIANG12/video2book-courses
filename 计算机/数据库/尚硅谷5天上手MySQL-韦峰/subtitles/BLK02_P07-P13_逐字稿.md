介绍完 SQL 语句的作用和概念以后，接下来我们来介绍一下应该如何去学习 SQL 语句，也就是 SQL 语句内部到底是如何分类的，我们应该怎么学。

其实就好比学 Java 一样，Java 分为 Java SE、Java ME 和 Java EE。我们知道应该先学习 Java SE，再学 Java ME 或者 EE。当你了解了这个语言的分类和每个类别的特点以后，就知道应该如何按顺序去学习。

其实 SQL 语句也同样道理。SQL 语句内部的命令是非常庞大的，很多很多，用东北话说就是老鼻子多了。如果说你上来直接去搞，基本你是搞得很乱，而且一头雾水。SQL 语句内部是有分类的，我们应该按照正确的每个类别的作用的顺序去学习 SQL 语句。

SQL 语句大概会分为以下几个类别：
第一，叫数据定义语句；
第二，叫做数据操纵语句；
第三，叫数据查询语句；
第四，叫数据控制语句；
第五，叫事务控制语句。

它是有五个不同类别，类别里边都有对应功能的 SQL 语句。这到底是什么，我们应该怎么学这些类别，这边给大家介绍一下。

首先先说第一个。大家想象一个问题，你想对数据库进行操作，你的第一步应该先干什么？有人说我要插入数据，或者我要查询数据、修改数据、删除数据。这四个动作，增、删、改、查，一定是你最终要做的目标，但一定不是你最初的目标。你想想，你要对数据进行插入，前期关系型数据库内部是有容器的，是需要你提前规定好的库、表、行、列。那你是不是要先把这些容器先创建好，学生表、分数表是不是要创建好？所以第一步我认为，我们应该做的事情是先完成 MySQL 或者是数据库相关的容器的创建、修改和删除的工作。这里边当然包含库的创建、表的创建，还有列的修改等等相关的动作。这一类的语句就叫做数据定义语句，简称为 DDL。DDL 里边包含的是关于容器的创建、删除和修改相关的指令和命令，这是我们在学习的时候第一步要学习的事情。

DDL 掌握了以后，容器是没有问题了。容器没问题以后，接下来你要干什么？有人说我查询，那也不太合适，只有容器没有数据也不行。第二个我们要讲的就是数据操纵语句，简称为 DML。它包含了对数据的添加、修改以及删除这三个动作。DML 不会影响我们的表和库等相关的结构，它只是对表中数据进行增、删、改相关的动作。

有了表也有了数据，接下来你就可以大大方方地进行查询、展示了。第三个我们基本要学的就是 DQL，叫数据查询语句。这里边它只包含一个功能叫查询，会根据你的表去查询到结果。但大家记住，查询语句不管你怎么查，你查出花来，你也不会影响表中的数据，更不会影响整个表结构。大家不要看查询语句只有一个查询功能，但它是最复杂的。因为你查询的条件、单表、多表非常多样化，所以查询语句是最复杂的，它也是我们本门课程的重点核心。如果想对数据库操作，前三个 DDL、DML 以及 DQL，这是基础和重点，必须要掌握。

这三个搞定以后，其实还有两个，这就包含我们所说的数据控制和事务控制。这两个大家现在也不用了解，后面我们会讲，它指的就是对数据库的一个高级维护。相当于失败以后会做回滚，还有一个就是创建一些账号，可以对数据库访问权限进行控制等等相关的动作，这其实就是一些扩展和拔高了。上面是基础，下方是扩展和拔高，大家理解它内部的 SQL 语句分类就可以了。

大家了解完以后，我也大致给大家说一下学习顺序。第一步，我们是不是先学 DDL，你要保证对表、容器能进行操作。第二步我们要学 DML，你要保证能把数据插到数据库中，修改和删除，对数据能做修改和操作。第三我们要学 DQL，DQL 指的是对数据查询，虽然它只有一个，但是它是重点和核心，它也是最复杂的。在下方就是扩展 TCL 和 DCL 这两个，它俩谁先谁后倒没有任何顺序了。这就是我们整个 SQL 语句的分类，以及我们应该如何学习。

在正式学习 SQL 语句之前，我们先去讲几个关于 SQL 语句的基本操作。这里边主要包含：第一，我们要知道在什么位置去编写或输入 SQL 语句；第二，一些基本的 SQL 指令，包括连接、退出和版本号查询以及注释等等。

这几个我们基本带大家去操作一番。首先把这个退出，我们来截一下这个图。对于这个图，我们来给大家演示一遍。如果说你想跟我们的 MySQL 进行沟通，第一步你一定要保证一个点：打开右键“管理”，点开“服务”，找到“服务”，搜一下“MySQL”服务，要确保 MySQL 的服务是正在启动状态。启动好了以后，第二步我们要打开 cmd，咱们的黑窗口“命令提示符”这个应用，Mac 打开终端。打开了以后，我们就可以通过这个应用去连接到对应的 MySQL 服务，连接到以后也可以在这个位置向 MySQL 去传递 SQL 指令。现在的黑窗口就相当于是我们编辑 SQL 指令的一个编辑区和编辑工具，这样去理解就可以了。

第二步我们来说说连接。怎么去连接？我们要找 MySQL 这个软件，这里边需要输入一些核心参数。

第一个我们要先写的就是 `mysql`，这是固定的，相当于调用 MySQL 的可执行文件。后边要跟的是空格，第一个跟的是 `-u`，指的是你要登录的账号用户名是什么。现在我们只有一个超级管理员，所以这儿我们一会儿写都是 `root`。用户名可以紧贴着 `u` 后边，也可以写个空格再写 `root`，都可以。

第二要写个 `-p`。`p` 指的是你登录对应账号的密码。这里边 root 的密码我们在刚刚已经设置了。如果你忘了，去看一看我们的常见的问题解决方案文档，那里边教你怎么去修改密码。但是大家注意，这个密码必须要紧贴着 `-p`，不能像账号一样能写空格，它必须要紧贴着。

除此之外还有一个 `-h`。`-h` 指的就是连接 MySQL 这个服务所在电脑主机的 IP 地址。因为 MySQL 连接软件也没说非得装到当前的电脑中，也可以装到其他电脑中，只要通过 IP 地址就可以进行连接。

再下边还有一个 `-P`（大写 P）。找到 IP 地址以后，想找到一个软件我们应该知道，还得知道它所在端口号。大写 P 就写这个软件 MySQL 软件的端口号，默认的就是 3306。我们在当初在安装的时候，如果你没改它就是 3306。

但是这里边的 `-h` 和 `-P`，它俩可以省略。什么场景下可以省略呢？如果这个软件装在了和 cmd 这个黑窗口是同一台电脑中，并且端口号你没改，是 3306，那这两个就不用写，它默认就找本机 3306 这个软件。所以这两个你可以改，也可以不改。

在下方最后其实还可以写一个数据库名。如果你写数据库名，指的是我直接连接到某一个库；如果你不写数据库名，相当于是连接到所有库，最终你可以选择使用哪个库，所以数据库名可以省略，这也可以写，可以不写的。

这里边必须写的只有 `-u` 和 `-p`，剩下的这三个都是可以省略的。

现在我给大家演示一下怎么连接。第一种方案，打开窗口以后输入：
```bash
mysql -uroot -proot
```
注意空格。`-u` 我们账号是 `root`，`-p` 必须紧贴着，我的密码也是 `root`。当然这个账号其实可以贴也可以不贴，而密码必须紧贴着 `-p`。到这为止其实基本的就已经满足了，我回车，这样是不是就可以连接上了？这是第一种连接方法。

还有第二种连接方法，我直接给它保留下记录。第二种，我可以输入一些 IP 地址和端口号。怎么写呢？
```bash
mysql -u root -p root -h 127.0.0.1 -P 3306
```
这回我给它空格。下边 `-p` 还是 `root`，再下方可以写 `-h`，我们在本机 `127.0.0.1`，当然你这儿也可以加空格，这都没问题。再下方 `-P 3306`，我也加空格。这样也可以指定，回车。但其实你这么指定的效果跟你上方不指定效果是一样的，因为默认就连接本地和 3306。这就是相当于我们对数据库的连接。

当然还有一些场景，后边你还可以写一个库名，假如这里边有库叫 `mysql`，那这个时候你就直接连接到 `mysql` 这个库了，这是一个库名。退出。

但是这么写都有一个弊端。因为我们账号你写出来去体现也行，但密码如果直接在这儿写上，在开发中你周围有同事，你刚跟你同事闹点矛盾，同事一眼撇到你的密码了，记住你的密码了，那他有没有可能趁你上厕所登录你的数据库删库并且跑路呢？当然他删你库，你跑路。所以说我们这个密码不建议明着写。

那怎么做呢？可以这么做：写个 `mysql -u root -p`，我只写上 `-p`。后边其他写不写跟这个没关系。这回你 `p` 后边不写密码，当然你也可以继续有 `-h 127.0.0.1`，这样写是没问题的，只是 `p` 后边不写密码。如果你不写密码，当你按回车的时候它会提示你，让你去输密码。这个时候你再输入的密码就是隐式密码了。所以我建议大家在连接的时候，`p` 后边不要写密码，回车以后再输密码，这回我们就可以进行连接了。这就是我们如何使用命令行去连接到 MySQL。

连接完毕以后注意，前面就会变成 `mysql>`，在这个中就可以写我们所谓的 SQL 命令了。后期我们学的所有 SQL 命令都可以在此处进行编写。

现在我们先讲一个最基本的命令，例如说查看我们 MySQL 的版本。查版本有一个 SQL 指令叫：
```sql
select version();
```
这里边要这么写：`select version();`。这就是一个指令，是固定的，查看 MySQL 版本。但是大家注意，我不加分号，我直接回车，我回车了很多遍，它也不执行。MySQL 中是以分号判定你这个语句是否结束的。如果你不加分号，它认为你没结束，你可以继续再写，它会追加到之前的命令中。但如果你想结束去执行，你必须要加分号。所以大家注意，千万别忘了分号，而且这个分号大家仔细看，应该是英文的分号。紧接着下边一回车，这就查到了版本了。就在这里就可以写我们后边的所谓的 SQL 指令了。

但是你不能瞎写，如果你瞎写，加个分号，英文的分号，它说我不识别这个指令，这不是一个正确的 SQL 指令。当然如果说你想写描述的话语，这叫注释。不执行的一个注释咋办呢？这个位置也给大家体现了。如果你想加注释，有三种方案：
第一是 `#`，加单行注释；
还有就是 `-- ` 加注释，但是注意 `-- ` 后边必须加空格，否则它也不识别，这也是注释；
除此之外还可以加 `/* */` 多行注释就可以了。

举例了，假如我想加个注释，写个 `#`，写什么呢？写“SQL 指令”，就一回车，它也是成功的，它不会真正执行，它代表是一个注释的含义。但这几种大家都可以去试试。

到这为止我们知道怎么连接，在哪个位置怎么写 SQL 语句了。如果想退出连接怎么办呢？很自然，有个退出命令：`exit`。退出命令稍微有点特殊，它可以不用加分号，就直接执行了，因为最后一个关键字了，也没有其他的命令了，所以它可以省略分号。回车，说了个 `Bye`，这就已经相当于是退出了 MySQL 的一个连接。
