第一个为 `ABS`，它代表是取绝对值的，这个大家一看就应该没问题。
第二个函数指的是你给它传一个值，它能判断它到底是个正值还是负值。如果要是正值返回是一，负值返回就是负一，零就返回零，是干这个事的。
`PI` 就取圆周率的值，3.1415926 的值。
`CEIL` 是向上舍入。你给它一个浮点类型，它最终返回的是个整数类型，但这个整数类型是向上舍入的。假如你给它一个 32.3，那它返回的就是 33。当然如果你给它一个负的 32.3，那它先取到的就是负的 32。注意是向上舍入，而不是负的 33，这个大家要知道。
而 `FLOOR` 是向下舍入，也是给它一个浮点类型，它相当于地板这个单词的含义，是向下舍入。假如你给它一个 32.3，它会取到 32。
再下方这几个是取其中的最小值，这是取其中的一个最大值。如果你有多个值，可以用它取最小值和最大值。
`MOD` 咱们之前用过，它也会封装成一个函数，它就是取模的。之前我们用过 `MOD` 关键字，它取模是一样的效果。
`RAND` 这个是取随机数的，它是取 0 到 1 之间的随机数，是干这个事的。而 `RAND` 用法还可以中间传一个 $x$。但注意，这个 $x$ 跟我们其他语言可能有些不同。我们像 Java 中也可以传一个 $x$，但是它会生成一个 0 到 $x$ 之间的随机数，而 SQL 中的 $x$ 不是，这个 $x$ 指的是一个种子。如果说你调用了两次 `RAND` 的方法，它的 $x$ 值相同，那它最终产生的随机数也是相同的。能理解吗？就是说它是一种作弊手段。我举个例子，假如说我们公司年会要抽奖，抽奖我们公司管理层有两个副总裁，两个副总裁抽获奖的概率要相同，你不能搞随机数。既然可以随机数，他俩要相同，那怎么办呢？你就可以给他们俩在 `RAND` 的时候填相同的 $x$ 值。只要填相同的 $x$ 值，那它算出来的随机数值就是相同的。能理解吧？是干这个事的。这是一种作弊手段，就非随机了，说白了你给它固定了，大家都一样了。
完毕以后，下方我们有个叫 `ROUND`，这个跟 `CEIL` 和 `FLOOR` 有点类似。如果说你单纯放一个浮点类型，它也会取到一个整数类型，但跟上方两者不同的一点是啥？因为一个它是向上取，一个是向下取，它会四舍五入。假如说你给它一个 35.4，那它会变成 35；如果你给它 35.6，它就会变成 36。它会根据后边小数位四舍五入向上去取，是这样。
再下面 `ROUND` 还可以放一个 $y$，前面浮点类型，后面放一个 $y$。这个 $y$ 指的是你要保留的小数位是几位。而它是怎么保留小数位呢？它同样后边也是四舍五入向上进行取位，能理解吧？
下边 `TRUNCATE`，其实这个跟 `ROUND` 作用是一模一样的，也是放一个浮点类型，$y$ 代表小数位，但它唯一的区别就是它不是四舍五入，它是直接截取。它不管你后边小数位是啥，它只截到那个对应的位行了，后边它不会向上进行四舍五入取位。

提完以后各位下方我们来说一说最后一个啊，叫 STR_TO_DATE。它只是把非标准的时间转成这个标准的时间格式。我举个例子，假如说就是前端要根据时间查询数据，但前端传的时间怎么传呢？传的是 2024 它写个年，完了呢，完了是写了个啥？写了一个叫假如说 04月，完了呢，多少呢？20日，它传了这个时间。大家注意啊，我们在数据库里面做对比的时候，这个时间能不能做对比呢？是比不了的。因为在数据库里面对比它得要求它是标准的时间，怎么写呢？你要这么写，2024-04-20，这个是可以直接对比的，那这是对比不了的。那你想传过来一个非标准的时间，又想对比怎么办呢？第一步你就先得用谁呢？用我们叫 STR_TO_DATE 这种格式，先把它转成什么呢？一个标准时间。大家理解吧？转了以后呢最终你再做对比就可以了，是干这个事的。

那接下来我们来看看怎么转啊。这个写法也很简单。STR_TO_DATE，第一个呢就是我们放的是非标准时间，你把它就直接给粘过来就行了。来，粘过来，它是一个字符串，前端传的，好。那既然转成一个标准时间，怎么转？大家看啊，逗号，这个标准时间的格式就要跟你非标准的时间那个一样、一致。它写法就是年月日，那你怎么写？你就写 % 大写的 Y，完了呢这写个年，完 % 什么呢？大写的 Y，怎么小写 Y，大写是 4 位的是吧？后边 %m，后边再写个啥？月。% 完了啥？日是什么？各位我们说是不是 d 呀？日，就可以了。也就是说这个格式要跟它一模一样，这样的话它才知道，哦，原来你是这种时间格式，那就会把你这个字符串转成一个标准时间。那我们来输出一下看看啊。来，一走。

大家发现输出是不是变成了杠啊？为什么？因为它会把你的时间按照你的格式转成一个标准时间，转了以后标准时间输出呢就是一个杠，就可以了。

```sql
SELECT STR_TO_DATE('2024年04月20日', '%Y年%m月%d日');
```

好嘞，那这节课我们介绍了三个时间格式化，我们再强调一下。DATE_FORMAT 和 TIME_FORMAT 它是把时间转成你指定格式的一个时间字符串，而下方各位 STR_TO_DATE 它指的是把一个非标准的时间，如果你想要做对比的话，按照你的非标准的时间指定的格式它转成一个标准的时间字符串，标准的时间，大家这样去理解。好嘞，那这边注意啊，4 位的年就是大写的 %Y，两位的月小写的 %m，两位的日小写的 %d，时间呢是大写的 %H 24 小时啊，咱们的分是 %i，小写 i，秒是...


秒是小写的 `%s` 或大写的 `%S` 都可以，那就完成转换了。这一节课我们先讲到这。

刚刚我们已经把时间函数都介绍完毕了。因为时间函数比较多，接下来我们专门针对时间函数来做一个小练习。这里一共有五个练习题，老样子，我们跳到对应的终端，一一去实现一下。

打开我们的终端。首先我们针对的还是对应的员工表。员工表里面其实有一个叫生日的字段。我们来看一看通过这个字段做一些关于时间的查询。

第一个，查询今天过生日的员工信息。

今天过生日是什么意思呢？今天的日期是 04-20，就是 2024 年 4 月 20 日，这是我们今天的日期。今天过生日代表他的生日后两位跟我对得上，就是他的生日也是 04-20。年份肯定是对不上了，年份一过去就不会复返了。只要这两位对上就可以了。这个我们可以怎么实现呢？也就是他是 4 月 20 日的生日就可以了。我们是不是可以把这个做时间提取出来做对比呢？我们写一下：

```sql
SELECT * FROM t_emp
WHERE DAY(birthday) = DAY(NOW())
  AND MONTH(birthday) = MONTH(NOW());
```

`DAY` 代表对应你的时间提取出它对应的日期，就是 20 日；然后等于我们的 `DAY` 提取 `NOW` 就行了。`NOW` 是获取当前时间，也提取出当前时间是第几日。且月呢，提取 `birthday`，等于 `MONTH(NOW())` 就可以了。这样就可以了，提取出你的月份和日一对比，没有就没有，这是一种做法。

还可以怎么做呢？其实我们还可以用格式化去做。我们不用写这两个去对比这么麻烦：

```sql
SELECT * FROM t_emp
WHERE DATE_FORMAT(birthday, '%m-%d') = DATE_FORMAT(NOW(), '%m-%d');
```

只提月和日，月是 `%m`，日是 `%d`，提取出来了；等于 `DATE_FORMAT(NOW(), '%m-%d')`，提现在时间的月和日，是不是就可以了？做时间格式化，这也是可以的。两种方案都是可以的，没问题。

再往下，查询本月过生日的员工信息。这个相对来说就比较简单，只提一个月就够了。把日去掉，只考虑当前月份和生日月份只要相同就代表是本月过生日：

```sql
SELECT * FROM t_emp
WHERE MONTH(birthday) = MONTH(NOW());
```

走一下，有几个，这几个都是 4 月份过生日的，这样就搞定了。

再下方，查询下月过生日的员工信息。下月份，就是当前 `MONTH` 提出 4，当你的 `birthday` 提出等于 5 的时候就可以了。能不能这么做？在这加 1：

```sql
SELECT * FROM t_emp
WHERE MONTH(birthday) = MONTH(NOW()) + 1;
```

走一下，是不是就算出 5 月份过生日的了？这个做法就是相当于把当前提取出的一个月时间加 1，就等于下个月的。可以这么做。

还可以怎么做呢？其实还有一种就是能不能把当前时间再加一个月？当前时间再加一个月去算，也行，但是不太合理。我给大家演示一下那个函数，有一个时间运算的函数：

```sql
SELECT * FROM t_emp
WHERE MONTH(birthday) = MONTH(DATE_ADD(NOW(), INTERVAL 1 MONTH));
```

这是获取当前时间，给它加上一个月，获取下个月的时间；获取完了以后，最终做提取运算，走一下，也能算出 5。这就演示一下这个可以进行加运算，但我觉得第一个会更方便一些。

再下方，查询员工姓名、工资和年龄，保留小数点一位。

首先姓名有，工资是有，年龄没有。但它有什么呢？是不是有一个生日？如果要有生日，生日的时间和现在时间它们间隔的天数除以 365，是不是就等于它的年龄？然后只要保留一位小数点就可以了。我们怎么做呢？

```sql
SELECT
  ename,
  salary,
  DATEDIFF(NOW(), birthday) / 365 AS age
FROM t_emp;
```

算两个时间的间隔天数用 `DATEDIFF`，算两个时间的间隔天数，当前时间是大时间，后面是对应的 `birthday`。算出来它的间隔天数以后除以 365，这就是年龄。

算完以后，它得出的值有四位小数点。想保留一位怎么办？还记得吗？可以用 `TRUNCATE` 或者四舍五入 `ROUND` 都可以。假如说我想用个四舍五入：

```sql
SELECT
  ename,
  salary,
  ROUND(DATEDIFF(NOW(), birthday) / 365, 1) AS age
FROM t_emp;
```

括号把它括起来，括完以后算出的值，后面逗号写 1，那它就会四舍五入变成 43.6。走一下，就完事了。这就相当于把我们学的都套起来了。

最后，查询年龄在谁和谁之间的员工信息。其实这个年龄我们都会算了，查询在谁和谁之间的员工信息，这个东西可以放在我们的列上，也可以放在 `WHERE` 条件后边，都是可以的：

```sql
SELECT * FROM t_emp
WHERE DATEDIFF(NOW(), birthday) / 365 BETWEEN 25 AND 35;
```

它的年龄应该大于等于 25、小于等于 35，大体上我们是不是可以用 `BETWEEN AND`？正常写，这边就写 `BETWEEN 25 AND 35`。这样就完事了，这就算出它的值是在 25 到 35 之间的。搞定了。

这就是我们说的时间函数。到这时间函数介绍完了，我们简单做个总结。

常见的时间函数分为四大类：第一类是要知道如何获取当前时间；第二类是会提取，提取年月日、时分秒、周几，或者是一年中的第几周，一般它都是英文名函数就可以了；再下方是时间运算，这边主要记一个 `DATE_ADD` 或者 `ADDDATE` 就行，它是完成一个时间节点加减运算的。其实不用记 `SUB`，因为直接用负号就是减了。除此还要记一个时间间隔，`DATEDIFF` 算两个时间间隔的天数，`TIMEDIFF` 等等；第四块是时间格式化，`DATE_FORMAT` 还有 `TIME_FORMAT`，指的是把一个标准的时间类型去按你的时间格式化字符串，格式成一个你想要的时间字符串格式去展示。这里的做法你要记住：年是大写的 `%Y`（四位的年）；月是小写的 `%m`；日是小写的 `%d`；小时是大写的 `%H`；分钟是小写的 `%i`；秒是 `%s` 或者 `%S`。下方的 `STR_TO_DATE`，它是把一个非标准的时间字符串，你写出它非标准的格式，去转成一个标准的时间，用于做对比的。

这就是我们的时间函数。练习我们就练到这了，这节课先到这。
