接下来我们来介绍一下比较运算符。我们来一一介绍一下，咱们看一下左侧。

比较运算符比较多，我们来一一说一说。首先第一个、第二、第三、第四这都简单，就是大于、大于等于、小于、小于等于，大家都能看懂。接下来第五个叫不等于。不等于一共有两种写法：第一种是一个小于号加一个大于号，第二种是一个感叹号和等于号。注意，这里面的第一种写法 `<>` 是一种标准的写法，也就是说所有的标准关系型数据库中它都支持第一种；而第二种是为了迎合其他语言的一种写法，很多语言都是用感叹号加上等于号表示不等于的，这是一种 MySQL 的迎合支持，也就是说现在这种写法在 MySQL 中暂时也是可以用的。两种在 MySQL 中都可以用，但是推荐使用第一种。

下方这个是等于，大家注意，这个等于比较号是一个等于号，不是两个等于号。下方这个也是等于，但这种等于能进行空的一个判断。第一种等于不能作为空值判断，第二种等于是可以作为空值判断的，一会我们来说具体的场景。

下方除了它可以做空值判断，如果想做一个列是否为空的判断或者是否不为空的判断，SQL 语句中提供了两种：一个叫 `IS NULL`，代表说某一列是否为空；还有一个 `IS NOT NULL`，某一列不为空。空值的判断我们应该选择的等于应该是用 `IS NULL`，如果是判断非空就应该是 `IS NOT NULL`。

完毕以后下方有一个 `BETWEEN AND`，这个大家应该能理解，指的是你的值在给定的两个区间，假如说这写个 1 和 5，你的值应该在 1 和 5 区间，1、2、3、4、5 都是可以的。下方 `NOT BETWEEN AND` 就是不在此区间。

下方 `IN` 也是一个范围，但这个范围是给定的值中。`IN` 里面可以放多个值，例如说我可以放 1，逗号隔开 5，那它指的就是你的值是 1 或者是 5；而 `BETWEEN AND` 的 1 和 5 指的是 1、2、3、4、5 都行，但是 `IN` 指的是两个值这个区间就可以了。`NOT IN` 大家应该知道，就是不在这个两值、不在你给定的值区间就可以了。

下边有一个 `LIKE` 还有一个 `NOT LIKE`。这里我简单介绍一下，一会细说。这里面的 `LIKE` 和 `NOT LIKE` 它指的是一个模糊查询。什么叫模糊查询？假如说我想查询一下姓张的学员，我只知道这个字符的其中一部分，不知道完整的值，那你可以用 `LIKE` 这种进行查询。第一个 `LIKE` 是模糊查询，第二是 `NOT LIKE`，就是不姓张的同学。一会我们来做演示。

大体来说有以下几种，需要注意的就是空值的处理要用 `IS NULL` 或者 `IS NOT NULL`。这里边等于是一个等于号。而下方有一个安全等于，也是我刚才说漏了，它也是一种例如方言、MySQL 支持的，而标准 SQL 语句中是没有这种安全等于的。这个跟等于的效果是一样的，在 SQL 语句中、在 MySQL 中，同时它能进行空的判断，能判断空的判断，是这样的。也就是说我们不推荐使用它，难道空判断用谁？空判断是不是用下边这两个做空判断就可以了？这大家知道一下也可以了。还有一个不等于推荐使用第一种。一共是有这么多。

除此之外我们需要注意的事情有几个：第一，大家在做比较运算符的时候结果能得到的是 1、0、NULL。这边 1 就代表是 TRUE，0 就代表是 FALSE 的含义，NULL 当然也是代表 FALSE 的含义，是这样的。这是一个。下方如果说我们这有个等于，写个字符串 `'1'` 等于数值的 `1`，这个结果也是为 TRUE 的。如果它碰见字符串，它会自动进行转成这个数值进行对比。所以说这种等于的时候它不需要考虑类型，大家大概知道一下。

大家听我说，这个结果它也是 TRUE 的。也就是说这个安全等于它能进行空的比较，而你如果在这直接写一个等于号，它就会归为 FALSE，它不能做空的比较。所以说安全等于是做空的比较。那这个位置它还可以怎么写？可以写：

我们说了，注意，一个等于号是不能做空比较的，它的返回结果也是个 NULL，说白了 NULL 在我们数据库看来就是 FALSE。还有：

大家看见了吗？那这个值是为 TRUE 的。大家看，那这个是为啥？因为双方都是字符串，字符串的比较就不会转成数值，只有一方为数值的时候，它才会转成数值。

在不在他们之间？在吧。1 和 3 代表是 1、2、3 都可以的，所以说 2 在此区间，返回第一个是 1。

这个值也是对的。如果你要比较的是字符串，它就会转成 ASCII 编码。b 的 ASCII 编码肯定在小写的 a 和 c 之间，所以这个值也是对的。

下边：

这个值也是对的。它的比较记住，`BETWEEN AND` 它两边是闭区间，左闭右闭，两边都可以构得到的，这大家知道一下。

下方第五种，这就是最后有一个叫模糊查询，我给大家介绍。

模糊查询的时候它主要用来做字符串的一个模糊匹配。就像我说的，假如说查询姓张的学生的姓名，手机号 138 开头的手机号，你只知道一部分，那就可以了。这个怎么做？咱们看这，它在匹配的时候有两个通配符，你先记一下：一个叫百分号 `%`，一个是下划线 `_`。

百分号代表的是匹配任意多个字符。如果写了百分号，这个位置可以有 1 到 $n$ 个字符我都算对的。如果说你写下划线，代表是只能匹配任意一个字符。有人说我不太懂啥意思，没关系，我们看一下下边的实例你就懂了。看第一个：

```sql
SELECT 'aaa' LIKE '%';
```

也就是说 `'aaa'` 某值是不是等于你给定的一个值？百分号代表说匹配任意个字符串，3 个 a 不就是任意一个字符串吗？第一个结果是 TRUE，百分号是任意字符串。如果还看不懂，继续看：

```sql
SELECT 'aaa' LIKE '_';
```

这个结果就为 FALSE，0。为什么？下划线、一个下划线代表的就是任意匹配一个字符，你三个字符我肯定匹配不了，对不对？

下方来看这个：

```sql
SELECT 'aaa' LIKE '___';
```

注意，这里边是三个下划线，有三个下划线对应三个字符，其实这个结果也是 1，代表我正好匹配你三个字符的一个字符串，是什么都行，我都能匹配上，这个是 1。

继续看：

```sql
SELECT 'abc' LIKE '_a%';
```

那这个值是 TRUE 还是 FALSE 呢？答案是 FALSE。为什么？大家看，这里边第一位它代表有下划线，就代表说它第一位有一个字符，是啥不用管，第一位你是 a、b、c、d、e、f、g 都行，第一位其实这儿是没问题的。但是下划线写完以后，第二位它直接写了个 a，a 就代表一个固定值，它要求第二位是 a 开头的、叫 a 的，但它第二位是 b，那这个就为 FALSE 了。第二位只要是 a，你后边再有啥它不管，是这个含义，所以这个为 FALSE。

下方来看这：

```sql
SELECT 'abc' LIKE 'a__';
```

这里边是两个下划线，那这个值是 TRUE。为什么？代表第一个 a 跟我具体的 a 匹配到了，下边有两个下划线代表啥？匹配任意你字符中的两个字符就可以了，那你愿是 bc 还有 fg、sb 都可以，所以这个是没问题的。

下方：

```sql
SELECT 'abc' LIKE '%c';
```

注意，它指的是最后一位是 c，前边是啥无所谓。所以这个也是匹配的，结果它也是 1，所以是 0、1、1。

大家注意，像我说的，假如说我想匹配一个姓张的学员信息，怎么办？假如有一列叫 name：

```sql
name LIKE '张%';
```

姓张是以“张”开头，后边叫张三、张麻子、张巴拉巴拉，小明心啥都行，后边你写一个百分号就行了。这就叫做姓张的，后边是两位张、三位张都行。那假如说我想匹配一个只能叫张三、张四、张五，两位张，第一位姓张，第二位只能是一位，那写个：

```sql
name LIKE '张_';
```

这代表就两位姓张的。

还有假如说我想找一个学生，这个学生第二位姓啥不管，但是它的第二位是“伟”，那怎么办？你写的时候就是第一位是啥不管写个下划线，代表第一位是任意值，第二位是“伟”，那就写个“伟”：

```sql
name LIKE '_伟';
```

但是第三位如果你要不写的话，就代表它是两位、第二位是伟。那如果再写个百分号代表啥意思？第一位是啥不用管，第二位是伟，后边是啥随便，有没有都行，可以匹配 0 到 $n$，是这样的。这就是模糊查询。

介绍完毕以后我们来介绍一下最后一种特殊情况。有些时候写我们可以用一些特殊语法，但是大家听我说，这个你了解就行了，不推荐。如果你想一次对比多个列，你就踏踏实实写，用逻辑符号去加就行了，不推荐这么写，但你知道一下。

第一种写法就是：

```sql
(a, b) = (x, y)
```

这个代表是：

```sql
a = x AND b = y
```

相当于语法是这种写法，两个值必须得相等，且是“且”的关系。如果第一种记不好，你就正常这么写就可以了。

第二就是安全等于：

```sql
(a, b) <=> (x, y)
```

它的效果是一样的。也就是第一个是 `a <=> x`，第二是 `b <=> y`。安全等于只不过它能做空判断，等于不能做空判断，是这样。

最后：

```sql
(a, b) <> (x, y)
```

它等同于什么呢？是：

```sql
a <> x OR b <> y
```

大家记住，等于的时候中间相当于“且”的关系，而不等于的时候它们中间其实等于的效果是“或”的关系。这就是特殊情况。

刚才我们写了列的一个比较符运算，一共有这些场景我们碰得最多：

第一个，等于对比。有谁？一个等于，还有一个啥？安全等于 `<=>`。大家记住，区别就是：第一个等于是不能做空判断，也就是说你有一个空值，用等于空，它返回的值也是 FALSE。而第二个等于，它除了做普通值判断，它还能做空判断，假如说 `NULL <=> NULL`，它的返回结果是 TRUE，是这样的。这个大家一定要知道，它是可以做这个。但是我们要知道一点，这个安全等于是方言，所谓的方言就是 MySQL 支持，但是其他的标准语法可能不支持。如果说你真的想做等于判断，大家记住，我们推荐用什么呢？`IS NULL`。这是普通话，就是标准语言，任何的标准关系数据库都是支持的。

第二个叫不等于对比，我们说有两种：第一种 `<>`，还有 `!=`。第一个也是标准语法，而下方也是 MySQL 的一个方言。MySQL 支持，但是有些数据库可能也支持，但不代表所有的标准数据库都支持，这是这种。

再下方大于、等于、小于，这我就不用记了，就是 `>`、`>=`、`<`、`<=`。

空值处理我们说了两种：如果是空，`IS NULL`；还有什么呢？`IS NOT NULL`，非空。

咱们的区间处理，咱们有个叫 `BETWEEN AND`。前面是小值，后边是什么值？还有一个大值。当然其实还可以加啥？前面加个 NOT，不在区间内，`NOT BETWEEN AND`。假如说我这写个 1、5，代表它的值可以是 1、2、3、4、5 都是可以的。

第二个有个范围对比，它是 `IN`，还有一个什么呢？`NOT IN`。这里边 `IN` 的它的范围就是这里边可以写多值，假如说 $x, y, z$，那代表就是你是 $x$ 或者 $y$ 或者 $z$ 都是可以的。其实它的效果等于谁呢？假如我们前面有个列名是 $k$，它其实等于：

```sql
k = x OR k = y OR k = z
```

是这样。而 `NOT IN` 指的是不在这个区间范围内，任意一个值都不行。那这个我们就搞定了。

搞定后下方我们讲了一个模糊匹配，就是咱们的一个 `LIKE`，还有一个 `NOT LIKE`。当如果你在判断的时候它的值你不知道准确值，你只知道部分值，你就可以用模糊匹配。模糊匹配的时候前面你正常是 $k$ 假如说，我们给它举个例子，一个 $k$ `LIKE`，后面如果你知道的值你就直接写。假如说我想找到姓赵的，那第一个知道我就写个“赵”。后边“赵”啥不用管，那你可以加百分号，代表匹配任意一个字符。第二假如说我取到第二个名字是“伟”的，怎么办呢？就我们说的 $k$ `LIKE`，第一个是任意字符写个下划线，第二个是“伟”，那写个“伟”就可以了。第三个你不用管写个百分号代表它是任意；如果你不写百分号就是它是两位。这就是我们说的这些比较符号。大家要去掌握这些比较符号，那这节课我们先说到这，下节课没关系，我们来做一套练习。

接下来我们进入到课程的3.5章节，来讲讲逻辑运算符，如何利用逻辑运算符将多个条件进行拼接。

在标准SQL语句中它提供了以下四种逻辑运算符，大家可能大概也熟悉：
第一种就是逻辑且的关系：`AND`，或者是写两个 `&` 符号；
第二种就是 `NOT`，反转的关系，或者写一个感叹号 `!`，代表把你的一个对应的条件结果进行反转；
接下方是 `OR`，叫逻辑或的关系，大家应该知道，双方只要任意一方为 `TRUE`，它结果就为 `TRUE`，是这样的；
还有一个就是异或：`XOR`，异或它指的就是双方有一方为 `TRUE`、一方为 `FALSE` 的时候，这才能结果为 `TRUE`，反之都为 `FALSE`。

一共三种关系大家应该很眼熟吧。接下来我会给大家去演示一下这三种关系如何将多个条件拼接成一个结果。但在拼接的时候我要给大家提前说一点，如果大家用非0的数据，非0非空的数据结果就为 `TRUE`，也就是说我们默认把它的值会当成 `TRUE`；如果说你用0或者空，那这俩值它会当为所谓的 `FALSE`。

我们接下来用这个去演示一下 `AND`、`NOT` 以及 `OR` 或者是异或之间的关系。大家看，这有几个相关示例，我们一个一个看：

首先第一个就是 `NOT 10`。大家看，这里的10不管是10、20、30或者是250等等，它都是一个叫非0且非空的一个值，那这个值结果就是 `TRUE` 的含义。如果说你用了 `NOT` 的话，相当于把 `TRUE` 进行反转，它的结果就是为 `FALSE`。`FALSE` 在我们的数据库中展示的值就是0，大家能理解吧？好，大家要知晓一下。

第二个我们看：`NOT 0`。这个写反是0，0或者空都可以，它代表的结果是 `FALSE`。`NOT` 相当于把 `FALSE` 反转，它的结果为 `TRUE`，`TRUE` 在我们数据库表达的值是1，所以这个是1。

第二就是 `1 AND 1`，其实或者 `10 AND 10` 都是一样的效果。1和1它代表就是 `TRUE` 的意思，只要是非0非空就为 `TRUE`。那两个 `TRUE` 用 `AND` 拼接，大家应该知道结果是不是也是 `TRUE`？所以这个值是1。

那 `1 AND 0`，大家注意，0是 `FALSE` 的含义，也就是说 `1 AND 0` 任意 `AND` 要求双方都为 `TRUE` 结果才为 `TRUE`，否则就为 `FALSE`，那这个就是为 `FALSE` 是不是0？

`1 OR 1`，两个 `TRUE` 获直接是不是结果为1？

`1 OR 0`，0为 `FALSE` 嘛，就 `TRUE` 或 `FALSE`，只要一方为 `TRUE`，`OR` 就为 `TRUE`，所以结果为 `TRUE`。

这里边 `0 OR 0`，就是 `FALSE OR FALSE`，那结果就是0，大家一定要理解。

接下方是异或，异或指的是双方一方为 `TRUE`、一方为 `FALSE`。你看，这 `1 XOR 1`，它最终的结果是多少呢？它的结果就是0。因为1和1都为 `TRUE`，异或它现在就是0了，就为 `FALSE` 了。还有一个就是 `1 XOR 0`，这个时候我们要知晓一下，`1 XOR 0` 的话，那它结果就为 `TRUE` 了，因为一方为 `TRUE`，一方为 `FALSE`，是吧？

接下来大家注意，这些逻辑符号除了将两个条件能拼到一起，其实也可以将多个条件拼到一起。这儿演示了三个条件，大家看：

```text

```

它的结果为多少呢？首先第一个 `1 XOR 1`，它们在顺序运算，它的值为0，对吧？因为两个为 `TRUE` 嘛，它俩为0。为0以后再去异或最后一个1，那就正好一 `TRUE` 一 `FALSE`，那结果这个为1的，对吧？大家知晓。

接下边这儿还有一个就是 `NOT 1`，那应该知道，1为 `TRUE`，`NOT` 相当于反转呗，那这个结果为0。大家能理解吗？这个相当于就是把多个条件拼到一起。

虽然我们在这儿演示的是用 `TRUE`、`FALSE` 直接写值，当然你在真正去比较的时候，这可以是前面可以是一个比较条件，后边可以是一个比较条件，它们最终的结果是 `TRUE` 或 `FALSE`，最终用我们这些逻辑运算符把它们连到一起。大家能理解吗？这样就搞定了。

所以说逻辑运算符的主要作用就是将多个条件结果进行综合连到一起进行运算。

接下来我们进入到查询的第四章节，单行和多行函数的一个介绍。在讲第四章节之前，我们可以简单去回忆一下，我们之前也用过了一些相关的函数，例如说对空值的处理 `IFNULL`，还有对 `SET` 这种数据的一个判断查询 `FIND_IN_SET` 等等这些函数。那 SQL 语句中的函数跟我们其它语言的函数也都是同样作用，它相当于就是对某项功能的一个封装，我们直接可以利用函数去解决我们一些相关的问题。那么接下来我们主要来介绍一下在 SQL 语句中有哪些函数，以及它们之间的一个区别。好，我们一一来做一下介绍，进入到第四章节。

首先我们还是先去理解一下，函数的作用就是你向函数可以输入一些相关的参数，最终函数执行完毕以后，会给我们返回一个相关的结果，那这就是函数，它是一个某一个功能点的一个集合。而在 SQL 语句中它函数分为两类，一类叫内置函数，说白了就是它提供好的一些函数，我们拿来直接用就可以了，就是 `IFNULL` 等等；还一类就是它也允许自定义函数，但是本门课程我们只讲内置函数，自定义函数我们是不提的。

好，完毕以后大家注意，那函数到底分为哪些类别，要怎么去记呢？大家注意，函数方法会非常多，而整个 SQL 语句大致将函数分为两大类，一类叫单行函数，一类叫多行函数。大家看，有这么多种函数，常用的函数有这么多种，例如说我们有数值函数，就专门对算术运算的，日期函数、流程函数、时间函数，以及信息函数或者聚合函数或者字符串处理函数等等。但这些函数我们统一会分为两大类，一类叫单行函数，一类叫多行函数。大家注意，除了聚合函数，剩下的都是单行函数。

那有人说，什么叫单行，什么叫多行呢？这个单行和多行，它指的是函数作用的这个位置。也就是说，单行函数是对单行数据进行生效的。也就是说，我们查了一条数据，这个数据里边有某个字段需要处理，OK，你就可以用单行函数去处理。例如说假如说我查一个数据，同时我想展示一下当前查询的时间，那你就可以利用单行函数的时间函数叫 `NOW()`，可以获取当前时间，它会把这个作用到你单行的数据上，最终结果也可以放在你的单行结果中，是这样的，就是在单行进行生效的。

而多行函数顾名思义，兄弟们，它的作用范围是什么呢？是多行。也就是说，它的范围指的是对我们多行数据进行一个统计，最终生成一个结果。它是一种统计性函数，例如说聚合函数里边包含叫平均数统计，或者最大数的一个计算，最小数的一个计算。那它是通过单行拿不到的，它需要统计你的所有符合条件的行一起做最终的一个运算。所以说函数通过它的生效范围和作用范围分为两类，一类叫单行函数，一类叫多行函数。

那有人说它到底还有没有什么其它区别呢？有，后面我们会讲，多行函数也就是聚合函数，一般它单独使用，或者它配合我们分组去使用，是这样的。好，那这个大家先了解一下我们函数的介绍以及函数的分类。那这节课我们先说到这。
