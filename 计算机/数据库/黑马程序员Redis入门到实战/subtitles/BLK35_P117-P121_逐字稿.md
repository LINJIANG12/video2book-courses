[听音转录 · P118 高级篇-多级缓存-06-Lua语法-初识Lua]
> 来源：**听音转录**——非平台字幕，由讲师原声转录

同学们，到目前为止，我们已经实现了整个多级缓存框架中的多个部分了。其中 Nginx 反向代理我们已经做好了，还有我们的数据库也准备了，这里的 Tomcat 服务也准备好了，并且上一节课我们还实现了 Tomcat 内部的进程缓存。

所以接下来要做的，其实就是 Nginx 的业务集群，然后在它里面实现本地缓存；本地缓存未命中查 Redis，Redis 未命中查 Tomcat 这样的业务了。而这一部分业务因为是在 Nginx 的业务集群里实现的，所以等于要通过 Nginx 来做业务编码，而不再是利用 Tomcat 做编码了。

那么以前我们利用 Tomcat 做编码，其实是用 Java 语言去写业务逻辑，对吧？那在 Nginx 内部，它用什么去写业务逻辑呢？它就要用到一种新的语言，那这个语言叫做 Lua。

所以你可以理解成以前我们是用 Tomcat 结合 Java 来开发，那今天我们要行的事情就是用 Nginx 结合 Lua 来开发。那么 Nginx 对应于 Tomcat 都属于是一个 Web 服务，而 Java 和 Lua 就是开发的语言。这么来讲，大家应该能明白 Lua 到底是什么的了吧？它就是一个开发的语言。所以我们这一章主要就是来学习一下 Lua 它的一门语法。

那我们会先带大家简单了解一下 Lua 的语法，看下它的基本用法是什么样子的。而后就是学习一个语言的基本流程了，什么变量、循环、条件控制、函数等等这些基本的语法知识。这里我们学习的并不是完整的 Lua 的语法，只是 Lua 中最常用的、在我们后边会用到的一些知识。

那下边我们就进入这一章的第一小节：初识 Lua。

首先我们来看一下 Lua 这门语言。它是一个轻量小巧的脚本语言。脚本语言咱们也不是第一次接触了，以前我们学习 JS 是不是也是脚本语言？还有现在比较流行的 Python，是吧？那这样的语言，它一般的特点就是比较小巧，比较轻量级。而 Lua 它底层是用 C 语言编写的，并以源代码形式开放的。那它设计的目的是为了嵌入应用程序当中。基本上大多数用 C 语言开发的程序，只要它开放了对应的接口，都可以基于 Lua 进行一个嵌入。

因此，Lua 经常被用在游戏开发当中。比如说之前比较流行的魔兽世界，在它里面就可以用 Lua 去编写一些插件，实现一些拓展功能。而我们的 Nginx 它也是用 C 语言编写的，它也开放了一些接口，因此它就允许你基于 Lua 进行一些拓展，那你就能够去实现一些业务功能了。

那么这个是 Lua 的官方网站，提前我已经打开了。我们打开浏览器看一眼。

在这里边大家如果要学习 Lua，你可以看这里的 Documentation，就是文档。当然如果你是第一次使用 Lua，还是需要去做一些安装的，它需要有一个运行环境。那么这里有个 Get Started，它会教你怎样去安装。如果是 Mac 就按照上面这种是吧。那如果说是咱们的 Linux 系统，我们就可以用源码安装，下载、解压，然后编译安装就可以了，还是比较简单的。

那我们需不需要去安装呢？我们不需要。因为在我们的 CentOS 系统里面已经自带了这个 Lua 了，所以我们可以直接去用。

好，那我们再回到 PPT。那怎么去使用 Lua 做一些开发呢？下边我们就来一个快速入门。

在这里它告诉我们了，需要在你的 Linux 虚拟机里面任意目录下先新建一个文件 `hello.lua`，这就像咱们 Java 文件一样嘛。然后你去对这个文件做一个修改。修改的时候其实在里面添加了这么一行内容：
```lua
print("Hello World")
```
这不就是一个典型的 Hello World 快速入门嘛。以前我们 Java 里面是写什么呢？`System.out.println` 是吧，那这里是直接 `print`，说明 Lua 的语言更加的简单。然后这里边是一个字符串 `"Hello World"`，那它的字符串可以用双引号，也可以用单引号，这一点跟我们的 JS 里面非常的像。

好了，那写完以后你保存，怎么去运行这个 Lua 文件呢？它不需要编译，可以直接运行，通过 `lua hello.lua` 就能直接运行这个 Lua 文件了。

好，那下边我们就按照这个来做一下。我们打开 shell 控制台。在这里我们先去新建一个文件，我们直接来个 vi 吧，就叫 `hello.lua`。

在这里边我们就用那个 `print` 去打印。打印的时候我们讲单引号也可以，双引号也可以。
```lua
print('Hello World')
```
好，这里我用了单引号，那这其实就是调了个函数嘛。好，写完了。注意啊，这里不需要加分号。

好，保存。那这个时候我们用 `lua hello.lua` 去运行。可以看到在控制台成功打印出了 Hello World 这样一句话。

那么我们这个 Lua 的快速入门就讲完了。那我们这节课就先到这里。
