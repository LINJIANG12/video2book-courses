# 黑马程序员：Redis 入门到实战

黑马程序员的 Redis 课程，175 集走的是「先会用、再懂原理、最后做架构」的顺序。前段用黑马点评这个中型项目把缓存的基本功练扎实：短信登录与登录态、商户查询缓存与三大缓存问题、优惠券秒杀与超卖控制、分布式锁、秒杀异步化与 Redis 消息队列，再到探店关注 Feed 流与 GEO 地理搜索；后段回头补原理与架构：持久化与主从复制、分片集群与槽位路由、多级缓存与缓存同步、键值设计与批处理等最佳实践，最后下沉到底层数据结构与内存编码、网络模型与 IO 多路复用、单线程模型与 RESP 协议、内存回收与淘汰策略。

- **原视频**：https://www.bilibili.com/video/BV1cr4y1671t — Bilibili，BV1cr4y1671t
- **175 集**，已产出 10 册模块全书、16 篇复习笔记、53 份逐字稿

## 怎么学

- **先把基本功练扎实** → 模块 01、02 与笔记 01~03 讲安装部署、常用命令、Java 客户端，以及缓存的更新策略与穿透/击穿/雪崩三大问题；这三条是后面所有实战的地基
- **秒杀是本课主线战场** → 模块 03、04 与笔记 04~06 覆盖库存扣减与超卖控制、分布式锁的原理与陷阱（含 Redisson）、秒杀异步化与消息队列；笔记 05 专门讲锁的陷阱，建议反复看
- **社交场景练复杂数据结构** → 模块 05 与笔记 07、08 用探店、关注关系与 Feed 流，顺带把 GEO、BitMap、HyperLogLog 这些特殊结构用起来，这一段很贴近真实业务
- **原理与架构部分** → 模块 06、07 与笔记 09~11 讲持久化、主从复制、分片集群的槽位路由与故障倒换、多级缓存；这是面试里区分「用过 Redis」和「懂 Redis」的地方
- **下沉到源码级** → 模块 09、10 与笔记 13~16 讲底层数据结构与内存编码、网络模型与 IO 多路复用、单线程模型与 RESP、内存回收与淘汰策略；建议对照 Redis 源码看，理解会比死记深刻
- **收尾是最佳实践** → 模块 08 与笔记 12 讲键值设计、批处理与服务端调优，可以直接当上线前的 checklist 用
