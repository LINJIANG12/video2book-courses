## 高级光线传播与外观建模
> 对应块：BLK27 | 覆盖分集：P18上 | 块标题（分集名）：《Lecture 18 Advanced Topi》

这门课很快就要结束了，剩下来的几节课相对轻松愉快。这节课讲的东西虽然叫 advanced topics——高级的光线传播和材质——但其实挺容易，因为我们只会说一些大概的内容。叫它们"高级"，并不是说它们一定比路径追踪难，只是这些话题在基础图形学入门里就不再多说了，大家是有办法自己掌握的，所以我们管它叫"提高"。这一讲我会以最主要的思想为主，把大概思路说清楚就差不多了，不会抠各种技术细节，基本上不涉及什么数学——大家就当听一个"十万个为什么"。

内容分两块。先讲高级的光线传播：无偏方法的代表是双向路径追踪和 Metropolis 光线传播；有偏方法的代表是光子映射，以及把光子映射和双向路径追踪结合起来的 VCM；最后提一个思路完全不同的实时辐射度算法，它相当于把间接光表示成很多很小的光源。然后进入第二个话题：更复杂的外观建模，讲散射介质、头发这些不定义在物体表面上的材质。

### 有偏、无偏与一致：先把判据立好

先说这一部分里最重要的一件事：什么是有偏（biased）、什么是无偏（unbiased）。做光线追踪，不管用什么方法，本质上都是在用蒙特卡洛方法做估计，而蒙特卡洛的估计是有性质可言的：如果不管用多少个样本，估计出来的结果，它的期望永远都是我们要的那个真实值，那这个方法就叫无偏的。

回忆一下路径追踪是怎么解积分的：可以用不同数量的样本，但不管用多少个，得出来的估计值的期望，永远都是那个真实的定积分的值——这就是无偏的估计。

那什么是有偏？所有其他情况都是有偏的：估计出来的值，它的期望和最后要的值不一样，就叫有偏。

有偏里面还有一种特殊情况：虽然取多少个样本，最后得到的结果都是有偏的，但在极限的定义下——样本足够多、多到无穷多——得到的期望值会收到正确值。这种情况当然还是有偏的，但我们管它叫一致的（consistent）。

> **定义**：无偏 = 无论用多少样本，估计的期望恒等于真值；有偏 = 期望与真值不一致的一切情况；一致 = 虽然有偏，但样本趋于无穷时会收敛到真值。

这几个概念现在听着肯定还有点抽象，没有关系，马上找一个例子看就明白了。它们反映在渲染里到底是怎么回事，我们说到光子映射的时候回头再看这一眼。

### 双向路径追踪：两头各走一半

双向路径追踪（BDPT），顾名思义。之前的路径追踪是从哪儿开始打路径的？还记得吧——利用光路可逆性，我们从相机出发产生一条路径，最后连接相机和光源。双向路径追踪把这个概念拓展一下：它会生成两个不同的半路径（sub-path）——从光源打出一系列 light sub-path，也就是从光源出发的半路径；再从摄像机出发生成另外一系列半路径。双向路径追踪做的事情，就是把这两组半路径的端点连起来，形成一条完整的路径。

```text
light sub-path :  L -----> x1 -----> x2   <- endpoint
                                   |
                                   |  connect the two endpoints
                                   v
camera sub-path:  C -----> y1 -----> y2   <- endpoint
```

读图：光源一侧与相机一侧各自独立产生半路径，把两个端点连接起来，就得到一条完整光路。

思想非常简单，对不对？但实现起来是非常非常困难的。不过在有些条件下，它的效果非常好。

看一组对比：同一个场景，左边用（单向的）路径追踪，右边用双向路径追踪，两边都是每像素 32 个样本——但右边的双向路径追踪效果这么好，左边的单向路径追踪效果这么差。为什么呢？

对这个场景做一点分析，就能看出它有一个很明显的、能和其他场景区分开的性质：光源往上一个角落打，整个场景其实都是被间接光照亮的——光从光源出发打到天花板，再弹到别处，最后弹到大家眼睛里。这种情况下做路径追踪：从摄像机出发，打到墙上某个点，这里是一个漫反射表面，那下一次弹射它可能被弹到哪儿去？弹到别处去，它就接收不到这么强的光；只有弹射恰好落到那一个能量集中的小区域时，这条路径才带着可观的能量。问题就出在这里——路径追踪里碰到的第一个 BSDF 是 diffuse，导致你控制不了后续弹射能不能到达能量集中的区域，大量路径就这么浪费了。

双向路径追踪反着来就舒服了：从光源出发先打一条光线，它肯定都集中在被光源直射的那一小块区域；从相机出发再打出一堆光线，把它们光路的端点连起来，就会发现基本找到的都是很合理的路径。也就是说，当光线传播在光源那一半边比较容易算的时候，BDPT 的效果就会很好——把它适合的情况说明白就好。

> **提示**：千万不要小看 BDPT，实现它的难度非常不容易，想做对挺难。如果你能把 BDPT 做对，基本上来说自己开发一个渲染器应该没有任何问题。

另外，BDPT 相对来说比较慢：虽然对比图两边都是每像素 32 个样本，但两者的运行速度肯定不一样，BDPT 要慢一些，甚至其实会慢很多。好处坏处都说清楚了。

### Metropolis 光线传播：一条种子路径带出一窝

BDPT 说完了，再说另外一个无偏的估计方法：Metropolis 光线传播（Metropolis light transport，MLT）。我见过一个很扯的翻译：有人把 Metropolis 按字面意思翻成"大都市"，管它叫"大都市光线传播"——和这毫无关系，它是按人名命名的。

#### 马尔可夫链：在旧样本旁边找新样本

它的思想是借用统计学上一个采样工具，这个工具能帮你采样，名字叫马尔可夫链（Markov chain）。马尔可夫链说白了非常简单：我当前有一个样本，它可以根据当前这个样本，生成一个跟它靠近的下一个样本。就这个意思。

想象一下这和普通蒙特卡洛有多不一样。还记得之前的积分吗？在 $[a, b]$ 之间按均等概率选一个点，每次选的和上一次选的毫无关系。马尔可夫链的方法是：当前有一个样本，我在它周围生成一个新样本，然后用这些样本来估计函数的值。

它有一个非常好的性质：给定足够的时间，马尔可夫链蒙特卡洛可以生成一系列样本，让样本的分布以任意函数的形状为 PDF。之前说过，蒙特卡洛方法可以用任意的 PDF 来采样一个函数，但我们并没有说用什么样的 PDF 最合适。现在可以告诉大家：当你采样的 PDF 和被积函数 $f(x)$ 形状一致的时候，得到的 variance 是最小的。而马尔可夫链的办法，能让你对任何未知的函数，都生成一批分布与被积函数形状一致的样本——这就非常好了。

跳回渲染。既然一个样本可以变出更多的样本，反映在"产生路径"这件事上就是：已经有一条路径的情况下，可以产生它周围更多跟它相似的路径。也就是说，它是一个局部的方法——给你任何一条路径，它可以生成和这条路径相似的路径。

比如画面里已经找到了一条蓝色的光路（path），现在对这条路径做一些微小的扰动：把它上面各个顶点的位置稍微动一动，就可以形成一条新的路径。这就跟马尔可夫链的做法完全一样——给你一个样本，在它周围找出一个新样本。这样不断在一条 path 周围产生新的 path，最后就可以把所有的 path 都找出来。这就是 Metropolis 的方法。

#### 越难的光路越吃香

在很多情况下，MLT 的效果是不错的。把它和刚刚说过的双向路径追踪放在一起对比：半开着一扇门的场景——光线完全只能从门挡住之后剩下的那一小块区域进来，也就是说只有那一小块被直接照亮，其他所有东西都是间接被照亮，是不是很像双向路径追踪擅长的那个场景？这种情况就相对比较难，而越难的场景，MLT 做得越好。为什么？你只要能找到其中一条路径作为种子，它就有办法在周围不断找到更多。

还有一个更神奇的例子，大家夏天去游泳池是一定可以看到的：池底那些波纹形状的亮纹。这叫 caustics——光线经过聚焦打在游泳池底，然后被你看见。想象一下：光线要穿过凹凸不平的水面，水面上有浪，穿过表面时有一些光就像过棱镜一样，被聚焦到一系列的地方；水面正好有办法把光聚焦成一系列的线，所以池底看上去是一道一道的。

这种情况渲染起来非常困难。分析一下：假设游泳池底是 diffuse 的，那么光要被你看见，路径得先经过 specular 的水面——水面肯定是 specular 的，而且是折射的 specular——再到 diffuse 的水底，再经过 specular 的水面出去。从眼睛或摄像机出发：先经过 specular（水面），然后 diffuse（水底），再 specular（水面），最后到光源，这种路径简写叫 SDS（specular diffuse specular path）。为什么路径追踪解这种路径非常非常难？当你的路径打到水底、产生 diffuse 弹射的时候，你根本不知道它该往哪儿弹；只有弹到很少的一部分位置，才能再穿过水面上的正确位置、和光源连成一条有效的光路。所以 SDS 路径非常难找。但 MLT 只要能找到一些，它就有办法在周围找到更多，效果就会很好。

#### 它的代价：收敛未知、画面偏"脏"

任何一个方法不可能只有好处。MLT 的坏处是什么呢？

第一，很难在理论上分析它收敛的速度。如果用路径追踪，渲染多长时间之后它大概会收敛，心里是有一个估计的——因为简单的蒙特卡洛方法可以分析 variance：把样本数量提高一倍，variance 能不能降低一倍，是有这么一系列关系的。Metropolis 里很难估计这么一个关系，所以你不知道它什么时候收敛、什么时候变成没有噪声。那把图放在那儿渲一天，一天够不够？不知道，就会出现这种情况。

第二，它所有操作都是局部的。这意味着每个像素自己做自己的，一点关系也没有。这样一来，有一些像素收敛得快、有一些像素收敛得慢，得到的结果就是图像看上去比较"脏"：上面有一道一道的东西，金属那一块有各种各样的点，各个墙缝基本都不太能看。

第三，由这两条自然得出另一个结论：你根本不知道一张图什么时候收敛，那更不可能拿它作为渲染动画的方法。用它渲动画会出现很严重的问题：上一帧跟这一帧各自有一些地方收敛了、有些地方没收敛，看上去图像就抖得非常厉害。所以它当然有它的问题——好处坏处都说清楚，这就是 Metropolis 光线传播。

### 光子映射：有偏但一致的两步法

下面再提另外一个方法：光子映射（photon mapping）。刚才说了，这是一个有偏的估计。那它能干什么？它特别特别适合渲染所谓的 caustics，也很适合刚才说的那种非常困难的 SDS 路径——光线穿过一个 specular、再达到 diffuse、再达到 specular，这种是非常非常困难的。

caustics 是什么？无非就是一系列光经过聚焦之后产生的图案。大家猜：左上角应该有一个光源，打到这么一个复杂的物体上，经过折射出来之后，很多光会聚焦在某些地方（至于有颜色没颜色，涉及到色彩，这个问题不大）。比如这里一个类似戒指的东西：如果有光从右上方打到它的内壁，内壁就会把光反射到地板上，形成一个环形的亮形状。这非常常见，大家平常在餐馆吃饭就能直接看到。所谓 caustics，就是由于光线的聚焦产生的一系列非常强的图案。

> **提示**：我始终对国内的这个翻译耿耿于怀——caustics 翻译成"焦散"是不合适的，这里只有"聚焦"，并没有任何"发散"的概念在里面。所以我们就直接念 caustics。

#### 两步完全分开的做法

光子映射的做法是两步，完全分开的两步。光子映射的实现方法太多了，这里给大家提其中一种简单做法。

第一步，从光源出发。光源无时无刻不在往外辐射光子——认为是光线还是光子，问题不大，道理和正常的光线传播一样。光子往各个方向打，碰到物体该反射反射、该折射折射，直到光子达到一个 diffuse 的物体上，它就停下来。当然，这是其中一种简单做法。这一步做完之后，把所有光子整理起来，我就知道所有光子都在哪里了。

第二步，真正从眼睛或者摄像机出发，往各个不同的方向打各种各样的路径——也就是之前说的从 camera 出发的 sub-path。同样该反射反射、该折射折射，直到它们达到 diffuse 的物体上停下来。第一步已经把所有光子都记录在 diffuse 物体上了，第二步的弹射点也停在 diffuse 物体上——现在就可以把这两步合起来，做一个计算：局部的密度估计（local density estimation）。

```text
Step 1 (from light):   L ~~> photon ~~> ... ~~> hits DIFFUSE  -> stop & record
Step 2 (from camera):  C ~~> ray    ~~> ... ~~> hits DIFFUSE  -> stop
Merge :  at each shading point, local density estimation
         find nearest N photons -> density = N / covered area
```

读图：两步各自独立进行，最终靠"着色点周围的局部密度估计"把两边的信息合在一起。

#### 局部密度估计：找最近的 N 个光子

密度估计是建立在一个观察上的：一开始打的一堆光子已经分布在物体表面了，第二趟又有一堆从相机出发的光线打在物体表面上。那我看到物体表面哪儿应该亮、哪儿不应该亮？当然是光子分布越集中的地方越亮，光子分布越不集中的地方就越不亮。

具体做法是：对于任何一个着色点，取它周围最近的 $N$ 个光子。所有光子分布在物体各个表面上、位置都知道，"给你一个点，找它周围最近的 $N$ 个光子"是一个经典的 nearest neighbor 问题，非常好解，可以迅速定位到任何一个点周围的光子。找到了之后怎么办？看这 $N$ 个光子在着色点周围占了多大的面积——比如找到 5 个光子，这 5 个光子会占据着色点周围的一块区域，这块面积有多大可以算出来。有了数量、有了面积，光子的密度就是：数量 $N$ 除以它们所占的面积。

这样一来，用一个确定的 $N$，就能算出每个着色点应该看到什么。但这里可想而知，$N$ 取多少是个问题：用很少的光子数量（比如周围只取 2 个光子），就会得到一张很有噪声的图；任何一个着色点都找 200 个光子，得到的结果会好一些，但是会糊、会比较模糊。

刚才有同学把这个总结成：光子映射是在 variance 和 bias 中间做一个妥协——要么更多的 variance（噪声），要么更多的 bias（模糊）。对，就是这么回事，就看大家对哪一边的接受程度稍微高一些、稍微低一些。

顺带回答另一个问题：密度估计里那块"面积"到底怎么算？这块其实是挺 hack 的一个做法：把找到的这堆光子覆盖的范围，和着色点所在的那个面求一个交集，交出来的那块相交面的面积，就认为是覆盖面积。这方面的估计有很多各种各样不同的方法，但都是各种各样的近似。

#### 为什么有偏，又为什么一致

现在来分析为什么光子映射是一个有偏的方法。做密度估计时我们真正想算的密度，应该是：在当前这个点周围取一个微小的面积 $\mathrm{d}A$，看里面有多少个光子。但我们不是这么算的——我们是先给它一定的光子数，再算它们实际覆盖的面积。正常情况下这两个挺接近，但绝对不是一回事：光子的数量毕竟是有限的，周围覆盖的面积也是有限的，所以这个对密度的估计其实是一个"不对"的估计——只有当 $\mathrm{d}A$ 无限小时，它才是正确的估计。

对应到渲染里就很好理解了：得到的结果，只要和正确结果相比有任何一点的模糊，它就是有偏的。

那什么时候能对？转念一想：刚才说了，实际覆盖的面积足够小的情况下，它就越来越接近真实的 $\mathrm{d}A$。那什么时候覆盖面积会变小？这样想：如果我打出 1 亿个光子，现在改成打出 1000 亿个光子，有更多的光子被辐射出去；我在任何一个着色点周围还是找同样数量的光子——原本找 100 个，现在还是找 100 个——这 100 个一定集中得非常厉害，所以一定会覆盖一个更小的区域，因为你总共的光子数量多了。区域更小，就更接近真实的 $\mathrm{d}A$。当有足够多的光子时，这么做最后能够得到正确的结果——这就是为什么说它是 consistent：光子打出去足够多的情况下，你就会得到正确的结果；但只要光子打出来的不是无限多，结果就一定不是完全正确的，多少都会有一点糊。所以说光子映射是有偏的方法，但是一致的方法。

> **结论**：渲染里说"有偏"，就是结果相比正确结果有一点模糊；说"一致"，就是虽然有模糊，但样本足够多就能收敛到不模糊的正确结果。

#### 固定面积数光子为什么不行

之前肯定有同学在想这个问题：局部密度估计，为什么非要"取固定的 $N$ 个光子、看它们覆盖多大"，能不能反过来——在这个着色点周围取一个固定的面积，比如一平方厘米，数里面有多少个光子？

从理论上来说，你这样做也可以，但是这样得到的结果永远都是有偏的，而且是不一致的。为什么？不管用多少亿个光子，你周围确定了一个大小的范围，这个范围里面你只会找到越来越多的光子；你这样计算出来的密度，对应的 $\mathrm{d}A$ 永远不会自己变小——范围是你自己规定的。它永远不会和真实的微小面积相同，所以它就不再是一个 consistent 的方法了。这就是为什么光子映射会选择"取临近的固定 $N$ 个光子"。

### VCM：把双向路径追踪和光子映射拼起来

顺理成章再提另外一个概念：VCM（vertex connection and merging）。它的推导、理论什么都很复杂，但它的想法非常简单：它是一个结合体，把双向路径追踪和光子映射结合起来。

回想 BDPT 是怎么做的：两边各生成一条 sub-path，把端点连起来。但有的路径满足这么一个性质：两条 sub-path 的最后端点非常接近、落在同一个面上。在同一面上，就不可能再让 $x_2$ 弹一次光、弹到旁边的 $x_2^*$ 上去——它们在同一个局部的面里面。这种路径不要浪费，VCM 的思想就是：这种情况下，把其中一半过来的当作"光子"看待——这和光子映射就非常相似了——然后用光子映射把这两条 sub-path 的贡献合并在一块。两套方法结合起来，自然就可以得到更好的结果。

VCM 应用得挺广泛：在电影行业里，有很多电影就是用这种方法来做的。

### 实时辐射度：被照亮的点就是新光源

再提一个和之前的方法都完全不一样的方法：实时辐射度算法（instant radiosity，IR）。有时候人们管这种方法叫 many-light——很多光源的方法，听上去很土，但它确实就是这么回事。

思想很简单。之前分析光线传播的时候说过：我们其实并不太区分光线到底是反射来的，还是自己发出来的——不管怎么样都是光线、都是 radiance。实时辐射度就一直利用这种思想：已经被照亮的那些地方，都可以认为它们是光源，用它们再去照亮别人。

做法：一开始先从光源打出很多所谓的 light sub-path——你会发现这种"双向"的思想到处都是。光路停在某些地方之后，就把停住的那些地方当成新的光源，画面上形成的那一片绿色小点就是新光源。当我看到某一个着色点的时候，就用所有这些新光源去照亮它。这些新生成的虚拟点光源叫 VPL（virtual point lights）。注意：这是直接光照——这些 VPL 对着色点的直接光照；而每个 VPL 本身，是之前真正的光源经过了若干次弹射之后的结果。所以就相当于我用直接光照的方法，得到了间接光照的结果——非常好。

总结起来：先去生成这一系列 VPL，再去看这个场景的时候，用这些 VPL 当光源去照亮你的着色点。简单吧？思想很简单，而且实际应用起来非常快。

顺带说一句，many-light rendering 是一个很活跃的研究领域，不一定非得是 VPL 这种形态：比如在一个盒子里，左边是一堆小光源，右边也是一堆小光源，用它们来照亮中间的一系列物体，还是非常有意思的。

但它也有问题。第一，有些地方会莫名其妙地发光：窄的缝隙、接缝这些地方会出问题。至于为什么会出问题，不再多说，简单提一句：这和之前推 light sampling 时那个距离平方反比有关系——把对立体角的采样改成对面积的采样时，产生了一个"$A \cos\theta / d^2$"这样的因子（面积乘以 $\cos\theta$、除以两点之间距离的平方）；两点之间距离一旦极近，就等于除以一个极接近零的数，得到的结果就非常大，就会出现这种情况。第二，VPL 不能做 glossy 的物体——稍微带一点光泽反射的材质就处理不了。

### 没有完美的方法

到这里，常用的光线传播方法就简单给大家梳理了一遍，大概就是现在常用的这些。把它们放在一起看：

我看有同学问：有没有无偏的例子？有——之前的路径追踪就是，BDPT 也是，MLT 也是。

那有没有完美的方法？真的没有，目前来说完全没有——目前真的没有什么好办法可以把所有问题都解决。多说一句工业界现在在用什么办法：很多做动画、电影的非常厉害的公司，到现在还在用路径追踪。它虽然听上去没有其他东西这么高端，但它是最可靠的一个。

### 外观建模：材质不止是表面

进入第二个话题：更复杂的外观建模（appearance modeling）。之前说过，外观就是材质；对于表面模型来说，材质就是 BRDF。这里给大家提一些比课上内容更深刻一些的东西。

会提到一些非表面的模型：散射介质（什么叫散射介质，待会儿看）、头发和动物毛发，还有一粒一粒的沙子这种东西——这些材质都和表面无关。表面模型自己也有一些稍微复杂的情况：像半透明、布料，以及细节非常多的复杂模型。最后还会提到所谓程序化生成的模型。

### 散射介质：定义在空间中的材质

先从非表面模型开始。散射介质，或者叫参与介质（participating media）——我自己更愿意把它翻译成"散射介质"。很好理解：像雾啊、云啊这些材质，显然不是定义在一个表面上的，它们定义在空间中，是这么一个概念。

#### 散射与吸收：光在介质里的两件事

怎么理解散射介质？想象你有一根光线穿进了云。光在行进的过程中，会有几件事发生。

第一，散射。云里面有各种各样的晶体、小的冰晶，它们会把你的光线随机地打到其他方向上去：从左到右过来，打到了一个小冰晶，就会被分散到各个方向去，这是非常有可能的。同样地，在传播过程中，你也可能接收到从其他方向散射过来的光——这是一一对应的：你可以往外散，也可以接收到别人往外散的光对这个点的影响。

第二，吸收。在传播过程中，有一些能量就逐渐逐渐没了。想想乌云：光线传播传不过去、穿不过去，就相当于各种东西都被吸收了。

> **结论**：光线在散射介质中传播，最重要的就是两件事：被吸收、被散射。

那散射怎么描述？类比物体的表面就好懂了。物体表面是不是 diffuse、光线怎么反射，由 BRDF 决定；同样道理，参与介质在任何一个点都会发生散射、往各个不同的方向散，怎么散由一个函数来定义，叫做相位函数（phase function）。它规定一束光打到这个点之后，是主要往背后散，还是主要向前散——这些就是规定不同的散射方法。这很像 BRDF：BRDF 决定光线如何反射，相位函数决定光线如何散射，道理就在这儿。

#### 参与介质怎么渲染

参与介质其实很好渲染。假设你已经在参与介质中间的某个地方，往某一个方向走：能走多远，由介质的吸收能力决定——如果是乌云这种很"黑"的东西，走不远就得停；薄雾这种就能穿得更远。停下来之后，就考虑把光线往哪个新的方向再打——这就是散射。这样一路下去，就好像光在物体表面做各种弹射一样，只不过在介质里，中间这些点任何一个地方都可能改变方向。不管怎样，找到一条 path 之后怎么办？和之前一样：把各个弹射（散射）的地方和光源相连，计算整条路径的贡献。说白了就是这个意思。

中间当然有很多数学计算，但我们这里考虑的就不再是渲染方程了——渲染方程只告诉我们光线如何与物体表面作用，不告诉我们怎么和体积作用，自然有别的方程来做好这件事。但思想是一样的：产生不同的 path 就是了。

#### 应用：雾、烟与巧克力

散射介质得到了非常广泛的应用。《超能陆战队》里那个东西方结合的城市 San Fransokyo——旧金山和东京的结合体——有很多场景发生在夜里，各种各样的雾的渲染。游戏里也是，各种各样的烟、雾（至于那是哪个游戏，我当场也想不起来了，大家自己考证）。所以实时渲染里也有很多很多研究，琢磨怎么很快地把散射介质的效果渲染出来——这很难，但人们很聪明，有各种各样的办法。

这里大家看到另外一种散射介质，可能会愣一下：这怎么能是散射介质呢？不是云、烟、雾才算吗——这是一块融化的巧克力。它背后有一个重要的事实：很多材质，你觉得它可能是一个表面的东西，但实际上不是——光线是有可能进到物体里面的，只是进得多还是少。像云，光线可以进去很多；有些东西比较厚，光进去不久就会消失掉。

给大家看一个实验，很简单：我用手挡住了摄像头，大家却还能看到光线穿了过来——哟喂，闪瞎了。大家自己也可以拿手挡住闪光灯试试，就会发现光线的穿透力很强，完全可以穿透人的皮肤，再从其他地方出来（这一点后面还会说到）。所以对于巧克力这种材质来说，它肯定还是一种散射介质，只不过光线进到材质里不久就会消失掉。

### 头发：光学发生在曲线上

另一种同样不定义在物体表面上的材质：头发。头发是一根一根的；如果说它梳理得比较平整，说它在一个表面上还行，但正常情况下不能这么假设——很多头发都是飘出来的，一根一根的。所以要描述头发的光学属性，我们要考虑光线和一根曲线如何作用，而不再是和一个面如何作用。

人的头发很神奇：它会有高光，高光看起来很碎，但大家看到，其实有两种不同类型的高光：一种是无色的高光，稍微发白一点；另一种是有色的高光。

这两种高光是怎么形成的？我们分析一下这个问题。从一开始有人研究头发起，人们就广泛地采用某一个简单的模型：把头发看成一根圆柱，一束光打到一个圆柱上，它会往四面八方散射。对头发来说，把它考虑成会散射出一个圆锥来：光从一个方向过来，如果它是一个表面，它会往某个确定的方向去；但它现在不是表面，是一个圆柱，所以会产生一个漏斗形的散射——沿圆锥的这些方向都会散射出去；同时还有一些光线被散射到四面八方去。这就好像是 diffuse 和 specular 两个加起来。

## 更真实的材质：从头发模型到程序化外观
> 对应块：BLK28 | 覆盖分集：P18下 | 块标题（分集名）：《Lecture 18 Advanced Topi》

### 头发渲染：Marschner 模型

把头发当成一根圆柱、按之前那套思路做出来，得到的模型叫 Kajiya-Kay 模型。但它看上去就不怎么好——因为它显然不是真的，看上去就好像我们之前做的 Blinn-Phong 模型。它不对，自然就会有人来研究：真实的头发到底和光线如何作用？

这里就是一个得到广泛应用的模型：Marschner 模型。它考虑的事情是：光打到一根圆柱上，肯定有一部分会被直接反射掉——没问题；也有一部分会穿进去，穿到头发里面发生折射，再穿出去。把这些传播方式分开记：直接反射记作 R；穿进去再穿出来，一根光线要穿透一根头发得穿两次，所以会产生 TT 这种传播方式；还有一种，光线进到头发里面、在头发的内壁上发生一次反射——第一次穿透之后发生一次内部反射，然后再发生第二次穿透——这就是 TRT。通过这种方式，我们可以定义各种各样不同的光线传播。

那我们怎么样描述一个材质？之前就说得很清楚：描述材质，就是描述它和光线怎么样作用。Marschner 模型的做法，是把头发当成一个玻璃圆柱——头发当然可以扭曲，但局部我们认为它是直的。它有两个结构：外层叫 cuticle（表皮），里面叫 cortex（皮质，中文名我一时想不起来）。

它认为头发内部有色素——这也不是"认为"，实际上就是这么回事，头发内部当然有色素。如果有光线穿进头发，在传播的过程中会被部分吸收，然后再传出去。人的头发是黑的，那就是色素多；金发呢，就是里面吸收少，光直接传出去了。所以它可以解释很多问题：把头发理解成这么一个玻璃柱，光经过的时候有能量损失、产生颜色，非常合理。

> **定义**：Marschner 模型考虑光线与头发圆柱的三种作用：R（表面直接反射）、TT（穿进去直接穿出来）、TRT（穿进去、内壁反射一次、再穿出来）。综合考虑这三者，就能得到非常好的渲染结果。

Marschner 模型以及它之后的这些模型，能够得到非常好的渲染效果。这里多给大家提一句——肯定有同学已经想到这么一个问题了：我定义的是光线如何和一根圆柱作用，那我只能算光线和一根头发怎么作用。如果光线和多根头发作用呢？可想而知：光线打到一根头发里出来，再打到第二根头发再出来，再打到第三根、第四根，直到第一百根，最后出来被你看见——真的有这么一个过程。如果光线和一根头发的一次作用叫单次散射，那么这个就叫多次散射。多次可以多到没边儿，多到一百次没有任何问题。这就是为什么头发渲染这么困难：它要求的计算量实在太大，真的得模拟光线在一根一根头发之间弹射，最后出来是什么。但不管怎么样，只要和一根头发的作用我知道怎么做，再根据光线传播，自然而然就可以把最后的结果算出来。计算量确实是真的大——这就是头发渲染非常难的原因。

应用上，各种游戏里都能看到头发模型的身影，比如《最终幻想15》：各种人物不同的头发——灰白的、黑色的、染成各种颜色的都有；最终幻想系列一直是这么一个风格，头发是特别认真来做的。动画电影里也有，比如《疯狂动物城》——那么多根毛发，每一根都是一根一根做出来的；一些卡通风格的应用里也能见到它。

### 动物毛发：双层圆柱模型

顺着人的头发，自然会想到另一个问题：人的头发模型，能不能用来描述动物的毛发？之前就有人试过——把人的头发模型应用在动物上，会发现不对：怎么渲染出来看着一点也不像，不是我们想要的那种效果。这就说明，人的头发模型不足以描述光线如何与动物毛发作用。

这到底是怎么回事？我们可以看一看生物上的结构。研究人和动物的毛发，会发现一些共同点：毛发如果切开，会发现它有三个结构。第一层，外面的表皮叫 cuticle；第二层，里面的 cortex——还记得吧，人的头发之前就有这个部分，它能够吸收光；第三层最内层很神奇，叫做髓质（medulla）。髓质的内部结构非常复杂，光线进去之后，就好像进入了散射介质一样，直接被打到四面八方去。

```text
+-----------------------------------+
| cuticle : outer layer             |
|  +-----------------------------+  |
|  | cortex : pigment absorbs    |  |
|  |  +-----------------------+  |  |
|  |  | medulla : scatters    |  |  |
|  |  +-----------------------+  |  |
|  +-----------------------------+  |
+-----------------------------------+
```

从外到内三层：表皮 cuticle、皮质 cortex（含色素、吸收光）、髓质 medulla（内部结构复杂，像散射介质一样把光打散）。人和动物都有这三层——但一看又发现了一个区别：对动物来说，它中间的髓质大得可怕，和人相比完全不一样。髓质特别大，也就意味着光线进去之后更容易发生散射。这就发现了一个之前的模型没能描述的东西。

那髓质的作用到底有没有那么大？这么一看，一目了然——当然这是一个所谓先有鸡还是先有蛋的问题：模型已经做出来了，看结果自然一目了然。看来模拟髓质是有必要的：之前的玻璃柱模型忽略髓质是不对的，所以我们要引入这么一个东西。同样道理放在人的头发上也成立：人的头发髓质这么小——直径大概只有头发直径的 10% 到 15%——但它的作用就很大：有没有髓质，明显一处亮很多、一处暗很多。

> **提示**：人的头发里，髓质直径只占头发直径的约 10%~15%，作用却很大；动物毛发的髓质则大得可怕，光线进去后散射强得多——这就是用人的头发模型画不像动物毛发的根源。

所以就有人提出了双层的圆柱模型——这就是我发明的动物毛发模型。它做的事情，就是把髓质精准地描述出来：真的用两个圆柱，中间是髓质，来模拟光线和这个双层圆柱的作用。光线打到表面上，还是可以被弹走；光线在穿过结构的过程中，有可能没打到髓质，或者打到了但没有发生散射——这是有概率的，所以还是有可能跟之前一样，有 R、TT 和 TRT。同样道理，也会有一部分光在穿过双层模型的过程中，在中间穿过髓质的时候被散射到各个方向去，这是 TS；TRT 的两次穿透也都有可能被散射，形成 TRTS。

这样，我们就可以用五个不同的分量来描述毛发——之前 Blinn-Phong 有三个分量，头发模型有三个，现在在头发模型上再加两个散射的结果：

| 分量 | 光线路径 | 物理含义 |
| :---: | :---: | :--- |
| R | 反射 | 打在毛发表面，直接弹走 |
| TT | 穿透 ×2 | 折射进入，直接从另一侧穿出 |
| TRT | 穿透—反射—穿透 | 进入后在内壁反射一次，再穿出 |
| TS | 穿透—散射 | 穿过中间髓质时被散射到四面八方 |
| TRTS | 穿透—反射—穿透—散射 | 与 TRT 同路径，但两次穿透都可能被散射 |

散射的结果对总贡献确实不少，所以不能忽略——之前看着假，就是因为这个。

来看例子。这是仓鼠（hamster），由 60 万根毛发组成——所以看到的根本不是什么表面，真的是一根一根的曲线描述出来的。渲染了多久呢？每一帧渲染了将近 40 分钟，把各帧联系起来，就看到一个转动的仓鼠模型——动物毛发的表现力非常不错。

双层圆柱模型得到了广泛的应用。比如《猩球崛起》这部电影，里面所有猿的毛发都是用这个双层圆柱模型做的，做得非常好，所以被 2018 年的奥斯卡拿去当了最佳视觉效果奖的提名；到了 2019 年，又有一部电影应用了这项技术——《狮子王》，同样拿了奥斯卡最佳视效的提名。大家会发现一个问题：为什么大家用了我的模型之后，都只能拿提名、拿不到最终的奖？我也很纳闷这个事情。话又说回来，奥斯卡的视觉效果奖又不是光看制作难度——特效那些东西都要考虑。所以从这个角度上说，我自然很希望自己能拿一次奥斯卡，当然拿的也不算我的，算是电影公司的。

这套东西背后是一套科学的研究方案：之前的一个头发模型不行，那它肯定有能被改进的地方——结构决定性质嘛。所以需要看一些生物方面的文献调研，再把它总结成图形学的模型。大家会更加体会到，图形学好像什么都涉及：咱们之前一直在说数学、物理、统计，现在又来个生物——各种东西都有，是的，没有问题。

### 颗粒材质：granular material

再多说一种模型，叫做 granular 材质。granular 这个词我词穷，实在没办法翻译——后来有同学帮我翻译成"颗粒材质"，我觉得挺合适，就叫颗粒吧。

颗粒就是一粒一粒的：香料、盐、糖，一个一个的晶体，每个都很像——整个就是由一堆这样的小东西形成的。注意，这可不是表面模型，是一堆小东西形成的这么一种材质，所以它会非常麻烦，计算量非常非常大。但人们可以做一些简化：比如一个沙子堆成的城堡，认为它的每一个单元上，由好多不同的石子构成，各自成分占百分之多少——拿这个去渲染。比如一个沙丘的模型：离得非常近的情况下，可以看到一粒一粒的；离得很远的情况下，看到的就是一个沙丘。当然，生成这么一张图花的时间是非常非常厉害的。

所以到现在来说，granular 材质并没有得到非常好的解决。

顺带看一个例子：皮克斯不只做长篇动画，还有一些短片，其中有一部叫 Piper（《鹬》，就是"鹬蚌相争"的那个鹬）。这个短片涉及的东西很多，其中大家可以看到沙子——这可不就是 granular material 嘛。皮克斯就是在不断地通过这些短片来炫技，非常非常厉害。

### 半透明材质与次表面散射（BSSRDF）

说完非表面的模型，我们回到表面相关的材质，重新提回散射介质这个现象，提一个东西：玉石。玉石是一类材质的典型代表，这类材质叫做半透明材质。

这里又是一个我对翻译非常不满意的词汇。translucent 绝对不应该翻译成"半透明"——半透明应该是 semi-transparent。translucent 和半透明其实有区别：它不是说光线沿一个方向传播过去、中间没被吸收这么简单，它本身还涉及散射——它说明的是，光线可以从某个地方进入这个表面，再从另一个地方出这个表面。中文的词汇不太合理，那我们还是管它叫"半透明"吧，translucent，大家知道这么回事就行：不是沿着一个方向传播过去没被吸收，而是可以被导到其他方向上去。

玉石就是其中一种：光可以从一个地方进来，从另外一个地方钻出去。海里的水母也是这么一个道理：光线进入它头部里面，在内部发生一些散射，然后再从另外一些地方钻出去。这类物体大家平常都很喜欢，看起来比较好看。反映在物理上，就是我刚才说的：光线从一个点进入了某个表面，在底下发生了大量的散射，从另外一个点钻出去。常见的物体里，牛奶就有很明显的这种现象；人的耳朵也是——背后有光进来，会穿过人的耳朵出来。大家还可以自己试一试：用手指按住手机的光源，会看到手指发红——光从这一面钻进手指，从另外一面钻出去。

> **定义**：次表面散射（subsurface scattering，SSS）：光线从表面某一点进入，在表面下方发生大量散射，再从表面上另一点离开的现象。

次表面散射可以理解成对 BRDF 概念的一个延伸。为什么？平常说 BRDF，是光线打到了这个点、并且又从这个点出来——比如 diffuse 物体，光线进来之后往各个不同方向去——所有的作用都发生在一个点上。BSSRDF 则把概念延伸：从一个点、以任意方向进来，往任意方向出去，而且可以从任意其他的地方出去。它规定了：光线从哪个点进来、从哪个方向进来、哪一点出去、从哪个方向出去。名字上也看得出来，就是在 BRDF 中间加了一个 subsurface scattering。

```text
BRDF  :  light in at x  -> out at the same point x
BSSRDF:  light in at xi -> out at any other point xo on the surface
```

进光点和出光点可以是表面上不同的两个点——这就是 BSSRDF 相对 BRDF 多出来的那件事。

延伸了之后，渲染方程也要改一改。原本是对各个方向进行积分；现在考虑这个着色点：如果这个表面有次表面散射性质，那么打到其他点的光，也有可能贡献到这个点、并且朝研究方向去。也就是说，我不能只考虑从各个方向进来的光，还得考虑从各个方向进到其他点的光——所以要对方向进行积分，也要对面积进行积分：

$$L_o(x_o,\omega_o)=\int_A\int_\Omega S(x_i,\omega_i,x_o,\omega_o)\,L_i(x_i,\omega_i)\cos\theta_i\,d\omega_i\,dA$$

相比 BRDF 的渲染方程，这里多了一层对入射位置 $x_i$ 在表面 $A$ 上取的面积分。

当然，这么算起来很复杂。人们就发现了一个近似的好办法。大家可以自己试一试：把手机摁在手心上，打开闪光灯——会发现闪光灯周围产生了一片往外走的光源，就好像你的手心底下有一个光源在发光一样。这就是基本思想：半透明介质就好像这么一个原理——一根光线打到了一个物体上，就好像这个物体底下出现了一个光源，会从底下照亮打光点周围的一片。这非常好用。当然，为了物理上的真实，大家推出来说：一个光源不够，上方还得对应有一个光源——相当于是有两个光源，用这两个光源去照亮周围着色面，这一块就很像次表面散射得出来的结果。这个方法叫 dipole（偶极子）近似，就是这两个光源嘛。用它来近似次表面散射的效果，得出来的结果不错。

```text
            incoming light
                  |
                  v
   ---------------x-------------------  <- surface
                  |
           ~ [ light ] ~   <- a "lamp" seems buried under x
```

一根光线打进来，就好像在入射点底下藏了一盏灯，把周围一片着色点从底下照亮；为了物理真实，再在上方对称地配一盏，两盏一起用——这就是 dipole（偶极子）近似。

看效果。这是一个雕塑：假设渲染全是 BRDF、没有次表面散射，看上去就是石膏这种效果；如果有次表面散射，效果就完全不一样，看上去就像大理石了。哪里看得最明显？鼻子这儿。只看 BRDF：鼻子背后有光，正面照不到光的地方就完全是阴影；换成 BSSRDF，光线就可以钻出去，得到所谓"珠圆玉润"的效果。这里的渲染正是用 dipole 这么一个估计来近似的。

同样的另一个例子：用 BRDF 渲染人脸，得到的结果看起来很干；用 BSSRDF 加入次表面散射渲染同一张人脸，结果好太多了——已经很像真实的人脸了。为什么说它真实了些？因为实际的情况下，光线就是能进入人的皮肤，在一个局部散射出去。人的皮肤真的就应该有次表面散射的性质，所以加入之后自然效果会好。

科研上，次表面散射也有各种各样的应用。比如我当年老师徐昆老师的作品：次表面散射材质的编辑——可以动态地改，改得更像石头，或者改得更像玉石，颜色也可以变，或者更像蜡烛，这些都是可以调的，挺有意思。

BSSRDF 现在研究得非常不错，有很多人喜欢，我自己也很喜欢。它厉害到了一定境界：有三幅著名的渲染图——我直接告诉大家吧，这三幅图都是假的，都是渲染来的，没有一张是真实的照片。用了次表面散射之后，可以得到非常非常真实的皮肤，效果非常好。这里还推荐一个网站（地址在课件上），收集了十个渲染得最真实的人物模型，可以看看艺术家有多厉害、次表面散射到底有多强大。当然即便如此，有同学可能会说，看上去确实还差那么一点点。那这个就留个后话吧。

### 布料：先弄懂它怎么织出来

说完次表面散射，再来说另一个跟表面相关的材质：布料（cloth）。为了理解布料，得先理解它的制作原理。布料是一系列缠绕的纤维构成的——这样说没问题，但它的缠绕有几个不同的层级，涉及到很多概念。

纤维（fiber）是最原始的概念：一根羊毛，就是最基础的纤维；化纤也是一个道理。不同的纤维经过第一次缠绕，可以缠绕成不同的股（ply）；不同的股再经过缠绕，会形成线（yarn）——每一根线的颜色，本身就是由很多股绕出来的，而线本身又涉及到各种各样不同的缠绕。有了线之后，要么被"织"，要么被"编"——这两个词中文反正都叫"织"：一种是机器织的，一根压一根，像桌布这类东西的做法；另一种是手工织的，跟织毛衣一个道理。道理是一样的，没什么问题。

```text
fiber(纤维) --twist--> ply(股) --twist--> yarn(线) --weave/knit--> cloth(布料)
```

一条链读下来：纤维绕成股，股绕成线，线再被机器织或手工编，才成为布。

布既然是缠绕而成的，要算它的表面模型就会非常头疼：它肯定和针织、纺织的方式有关——比如隔多少根让另外一根去压着一根，这种织法、你织出来的形状，会决定最后的结果。根据这些编织的图案，就可以推断出这个布最后看起来会怎么样。

#### 当成表面：从织法推 BRDF

如果认为布料就是一个物体表面，那可以通过各种各样不同的编织图案，推算出它到底应该是什么样子——自然而然就得到一个 BRDF 模型。有同学会说，BRDF 模型肯定有问题吧？如果布本身真的是在一个平面上，认为它在表面上，没问题——咱们之前见过。但我之前提到过有个材质叫天鹅绒：它所有的纤维都是往外一根一根分布的，根本就不是一个平面，怎么能拿 BRDF 来表示它？其实并不合理。

#### 当成体积：像渲染云一样

一个更准确的做法，是把织物认为是空间中分布的体积。既然是空间中的体积，就可以把它划分成超级细小的格子——比如一条围巾、或者沙发的布，就是把空间分成了非常非常小的格子，每个格子里大概知道纤维的朝向分布、复杂程度这些性质。然后把这些性质转换成光线的吸收和散射——就好像在渲染云一样，把布料的性质转换成对云雾这种散射介质的渲染：不再把布料当成一个面，而是当成一个体积，体积中间任何一个微小的块都知道它的性质。可想而知，计算量很夸张——生成一幅图要花好多好多个小时，但能得到相对准确的结果，肯定比认为它在一个平面上要对。

#### 当成纤维：一根一根渲染

还有一个做法。布料本身就是纤维，我知道它是怎么缠绕的，那最暴力的做法：把每一根纤维都渲染出来，不就完了吗？每一根线上有很多股，每一股上有很多纤维——把每一根 fiber 都渲染出来，把它当成人的头发，和人头发的渲染一模一样。得到的结果自然非常真实，但计算量也同样非常非常惊人。

三种做法放到一起看：

| 做法 | 把布料当成 | 怎么算 | 代价与效果 |
| :--- | :--- | :--- | :--- |
| 表面 | 物体表面 | 从织法与编织图案推出 BRDF | 最便宜；平布可以，天鹅绒这类不成立 |
| 体积 | 散射介质 | 空间切成细小格子，每格记录纤维朝向等性质，转成吸收与散射，像渲染云 | 一幅图要花好多小时；相对准确 |
| 纤维 | 一根根纤维 | 每根 fiber 当头发渲染 | 最真实；计算量惊人 |

这三种方法——当成散射介质、当成实际的纤维、当成物体表面——直到今天都有人用。考虑到各种各样不同的应用场合：要更准确的结果，那就去多花点时间。渲染中间有很多这样的 trade off：想要更好的结果，行，没问题，多花点计算量、多花点时间。

布料的例子也很多。演示过的那个布料，显然不是当物体表面算的，它本身会非常复杂。还有一部电影——迪士尼的《圆梦巨人》（Big Friendly Giant），讲一些巨人的故事，他们身上穿的亚麻衣服做得非常真实。这里多说一句：它用的就是 BRDF 模型，最简单的模型，但其实效果也不错。布料会被应用在各个方面。

### 材质里的细节：完美的反而不真实

下面说一种复杂的材质——有细节的材质。这一段我就随意说一说，作为扩展视野，大家想随时撤就随时撤，没什么问题。

先看例子。现在这些渲染器渲染出来的结果，看上去非常不错，但其实还显得并不是多么真实。为什么不真实？因为很多情况下得出的结果过于完美。比如这个车子——现实生活中哪有这么完美的一块？任何车子、再新的自行车，上面都有各种各样的划痕。这个鼠标看上去完完全全是整板一块，得到的结果非常完美——反而这样就不对了，因为真实情况下不会有这种情况。

看真实的世界：车子上面会有高光，高光周围有类似蜘蛛网结构的东西——这就是划痕。划痕发生在哪儿？发生在空气中各种灰尘颗粒和车外层那层清漆之间——还没到车的油漆部分——所以强光照射下一定可以看到这个效果：一个高光，加上划痕形成的效果，共同构成这个样子。真实世界反倒是不完美的，但我们的描述方法能得到很完美的结果——这就是问题所在。

微表面模型（microfacet model）我们之前说过它非常强大，结果非常完美——但完美的结果反而不真实，之前那个摩托车就是这样。什么是稍微真实一点的？加入各种各样实际可能产生的不完美。比如划痕：有划痕的情况下，物体旋转起来，可以看到高光还是高光，但还能看到各个不同的划痕。甚至还可以模拟各向异性材质——还记得吧，沿着一个方向去刷金属的表面，一条一条刷出来的划痕都在，你能看到很明显的高光，随着视角变化可以看到不同的划痕。这就是细节模型能够带来的真实感——这就是我们为什么要研究它。

顺便说一句，这是我的作品，算代表作——博士那几年我的几个贡献之一；和它并列的还有 real-time ray tracing，差不多就这么几项。

微表面模型咱们之前提过：它最重要的是微表面的法线分布（NDF）。但我们之前只说到这儿——实际上，大家描述这个分布，用的是一些非常简单的模型，比如正态分布、高斯之类。用这种分布去描述法线分布，得到的结果自然是一个看上去并没有什么细节的结果，因为法线分布本身就没有体现出各种各样不同的变化。但我们要的是什么？法线分布基本符合统计规律，又有自带的细节。如果能把这些考虑进去，自然而然就可以得到好一点的结果。

比如这只蜗牛：在蜗牛壳上贴了一张非常大的法线贴图——之前讲纹理映射的时候说过，可以定义每一个点上不同的法线。这张法线贴图用了多大？200k×200k。大家自己算一算这是什么概念——超级大的一张法线贴图。贴上去之后，每一个小面可以产生一个高光，所有高光合在一块，就会变成这么一个大的高光。从远到近看过去，可以看到每一个高光是什么样的——确实，一个大的高光是由很多高光形成的。

同样可以换另外一种法线分布的模型：比如模拟车漆。很多人愿意在车漆里加亮片——亮片非常非常小，但它们会形成各自不同的方向，方向不同就有不同的反光，得出来的效果就是那样的，非常真实。

虽然我们可以定义各种各样不同的细节，但要渲染出来非常困难。真的用 path tracing 来做：花两个小时还得不到要的结果；那多久可以得到？我算了一下，需要大概将近一个月——渲染一个月才能得到这么一个结果。大家可以想象这是一个多么困难的渲染问题。

它到底困难在哪儿？根本原因在于：我们认为每一个微表面是一个镜面。想象一个针孔摄像机和一个点光源：从摄像机打一根光线过去，打到什么样的表面，就知道它的法线、知道它镜面反射的方向——但很难很难通过反射的方式，让这根反射光线打到光源上去。光源打过来也一样：打到微表面，知道怎么反射，但它就是反射不到摄像机上去。

所以怎么做？考虑一个像素——它会覆盖很多微表面。如果我们能把一个像素覆盖的小范围内的微表面法线分布算出来，就可以用它替代原本光滑的分布，用在微表面模型里。这个思路大家应该听懂都没有问题。

```text
   one pixel covers many microfacets
   +---------+
   |  /| |\  |     collect the normals inside the pixel footprint
   | / | | \ |
   +---------+
         |
         v
   aggregated NDF over this footprint
         |
         v
   plug into the microfacet model
       (replace the original smooth NDF)
```

把一个像素覆盖范围内的所有微表面法线聚合出来，替换微表面模型里原本那条光滑的统计分布——这就是处理细节的思路。

一个像素覆盖多大的范围，会得到各种各样神奇的法线分布。一个像素覆盖了非常多的微表面，这些微表面自然而然就会显示出统计学的规律——看上去挺圆的，很像高斯分布；覆盖的范围小，它就会显示出一些很独特的性质，法线分布看上去就很有特点。而且不同类型的法线贴图，会引起不同的法线分布：比如刷过的表面，很显然会得到一系列各向异性的分布；比如离散的亮片，每一个亮片都是离散的法线，那我就得到很多离散的点。非常有意思。所以我们只要能把它算出来就行了——怎么算这里不展开，给大家看一看得出的结果就好。

这是一个杯子（Blender 的例子）：水杯有一个金属的表面，这里是磨过的，那里是朝另一个方向磨的，跟橘子皮一样。这些都算进去之后，得到的结果就能把这些细节都反映出来。同样大家可以看到，任何宏观的东西，都一定是由这些微观的东西构成的——一系列点形成了线状的高光。

之前给大家说过：远和近、微观和宏观是相对的——就像看卫星图拍地球一样。从远处看一个海面，海面的波纹就是很细节的东西，可以通过这种方式描述出来；每一帧用一个不同的细节，就可以得出海面上波光粼粼的效果。这个方法在游戏中也稍微得到了一些应用——像《古墓丽影》重启三部曲的第二部（我记得是），雪地上会有一些发光的点。这是实时渲染中的一些应用。

### 细节再小下去：波动光学

这些细节就算这么解决了吗？答案是不对。为什么？当你引入这些细节的时候，如果大家还在用几何光学来解释，就不对了。大家之前学过物理：当物体非常小——小到和光线的波长相当的时候——就不能再假设光线的传播是沿着一条直线了，必须假设光是一个波，因为会发生各种现象：衍射、干涉。这种现象在这种微小的细节上就会发生。

有很多人研究过这个问题，我也研究过。这个问题反映在什么上？比如你在一个小黑屋里——真得小黑屋，其他光源都得关掉——只用一个点光源，比如你手机的光，去照亮一个金属片：金属原本是一个颜色，但你却会在这个上面看到各种各样不同的颜色。同样，比如拍 MacBook 的背后：通常拍出来是白的；但如果只用一个光源、放大了拍，拍出来一张图，放大看，其实根本不是白的，是各种各样不同颜色的点。

这反映什么问题？用白光来照射一个物体，它反射出来就应该是白的；如果不是白的，一定有波动光学发生了。所以我们就把波动光学给解出来了。波动光学的公式我完全不想提——我的天，完全是劝退的东西，太复杂了：要在复数域上做各种各样的积分，非常麻烦。大家就看一点：波动光学得出的 BRDF，跟几何光学得出的 BRDF 挺像，但又有自己的特点——不连续。为什么不连续？大家学过物理，知道光会发生干涉：干涉会引起有些地方加强、有些地方减弱，就会形成一条一条不连续的效果。

拿它去渲染：真的把波动光学的 BRDF 放进渲染里，得到的图是渲染出来的，不是照片。放大的过程中放大、放大、再放大，就会发现真的是这样——没有什么表面是白的，基本都是各种各样不同颜色的形状。是不是非常神奇？生活中也有：去餐馆吃饭，各种各样使用过程中产生的划痕——关键是肉眼可见的，可以看到中间是彩色的。真实生活中是一定可以看得到的。

有同学课后问：波动光学的渲染能讲吗？不能，真不能——波动光学讲完要死人的。感兴趣的话，访问一下我的个人主页，随便点开一篇我的波动光学的文章看一眼，你觉得能看下去，我就给你讲；复杂的光线传播嘛，倒是没问题，可以讲。

### 程序化外观：不生成，随用随取

最后一个话题：程序化生成的表面——或者说材质，或者说外观。程序化生成是什么意思？就是我用一定的方式来指导它的生成，而不需要真正去生成它，我可以动态地去查询它。

比如我可以定义各种各样不同的花纹：这个花瓶，花瓶打在地上摔碎了，我还可以看到花瓶内部的花纹到底是什么样的。这就可以定义一个所谓三维的纹理。但大家知道，存储量在三维的情况下瞬间就上去了：存一张图还行，存一个三维的体积、在各个地方都存这么细节的东西，那是不可能的。怎么办？不存，什么时候需要用、什么时候去查。就好像我有一个空间中的函数 $f(x,y,z)$：给任何 $x,y,z$，立刻可以得到它的 $f$ 值，就可以了。而事实上就是有的——有那么一些函数，叫做噪声函数（noise 函数）。这些函数允许你得到一些很神奇的效果，比如看起来像木头纹理的 noise——而且我说清楚，它是定义在空间中的。也就是说，刚才那个木头的纹理，如果把木头砍成两半，切面上长什么样，也都知道——用三维空间中的噪声函数就可以得到这些结果。

那为什么叫 procedural？就是随用随取的意思。其实翻译成"程序化生成"也不太合理——procedural 更多的意思是：我不生成，需要用的时候，我去找就好了。

举个例子，游戏里很多应用，比如车子上的锈。我可以生成一系列噪声，然后对噪声做一些操作：锈肯定有些地方有、有些地方没有。如果认为噪声函数的值是 0 到 1，那我就认为噪声值大于 0.8 的地方是锈（记作 1），小于 0.8 就是 0——把它二值化。对噪声函数可以做任意的操作，这种后期处理只要处理得当，就可以得到任意不同的效果。

噪声函数目前应用最广泛的叫 Perlin noise，之后还会有各种各样神奇的噪声函数。它们的共同点就是这样：你不用管它是怎么得到的，它允许你给空间中任何 $x,y,z$，返回给你一个值，就这么回事。

噪声函数非常有用。比如生成地形：这么复杂的地形，山上各种各样不同的细节，噪声函数就可以做，没有问题。水面也是一样：不同位置有不同的高度；至于水面到底应该用一种什么样的噪声来表现，这个都有人研究。还有工作台的木头：木头有各种各样的纹理，它肯定是三维的——它是生长产生的嘛。Autodesk 就做了一个工作：可以生成三维的木头，并且你不用真的生成，可以直接去查询这个三维木头中间的任何一个部分——木头可以任意切割，都能得到内部的东西。它就是控制这个函数应该长什么样，来模拟树的年轮、树里面负责传导的纤维这些真实的物理结构，把真实的物理和程序化生成结合在一块，可以得到非常真实的结果。要说程序化材质最新的东西，这个木头可能算是一个集大成者。它有一个例子是吉他：吉他上这些纹理完全没有预先定义，直接去查询它产生的三维木头对应的函数，就可以得到，非常厉害。

课后有同学问：程序化材质是不是老方法？并不是——一直都有人研究，到现在还是一个很火的话题。另外有一个软件专门做程序化材质，叫 Houdini，在工业界得到了很大的应用；只不过它的程序化材质是真的先程序化生成、然后你再拿去用，和我们这里"不用生成、直接去查询"的理解并不太一样。

今天这节课说的不少，就说到这儿。之后的安排咱们之前说过：很快会有一个关于模拟仿真的课，结束之后回来——有可能是暑假——我要么给大家讲实时渲染，要么把今天讲的这些高级内容一块一块拓展讲清楚。今天这些算是复杂一点的话题，大家随便听一听就好。另外多说一句：今天这节课的课件，绝大部分是我在伯克利当助教时做的那节课的——那节课也是我讲的——今天拿过来，又加了一些新的东西。

## 相机与镜头：从针孔成像到曝光三要素
> 对应块：BLK29 | 覆盖分集：P19上 | 块标题（分集名）：《Lecture 19 Cameras, Lens》

### 从成像说起：合成与捕捉

今天开始一个相对独立的新话题。这门课走到现在，主线上的几大块是：光栅化成像、几何、光线追踪（以及更高级的路径追踪），后面还会讲到模拟与仿真。而最近这几周，我们要说一些独立的话题：这一讲是相机、镜头和光场；下一讲是颜色与感知——我们到底怎么会看到各种各样不同的颜色？光谱是什么东西？我们所看到的到底是什么？把这些杂七杂八的事情弄完，之后就可以进入模拟与仿真。

为什么要专门讲这些？因为这些都是图形学的重要组成部分，后面涉及到各个方面的时候，我们会默认大家知道这些事情——可是这些知识从哪学呢？基本上还是得从光学课上来。所以趁这几周，把它们补上。

咱们从成像说起。计算机图形学有两种成像方法：一种是光栅化成像（画出软阴影那种效果），一种是光线追踪成像（还有各种高级话题）。但这两种成像本质上都是合成（synthesis）：画出来的这些东西，在自然界中其实并不存在。合成之外，还有另一条成像的路——捕捉（capture）：真实世界中存在的东西，把它变成照片。这个理解非常朴素，但很对。而最简单的捕捉成像工具，就是相机：拿个相机随便往一个地方拍张照，那就是成像。成像作为图形学中的重要组成部分，肯定要专门说一说。

肯定有同学关心：现在还有人研究别的成像技术吗？怎么更好地捕捉各种各样的光？有，而且大家做得非常积极。比如有地方在研究光的传播——光是有传播时间的，光以光速传播，那我能不能限制在某个极其微小的时间内，看这一小段时间里我能看到的光是什么样？这样你就能看到光线真正在空间中传播的过程。这个方向叫瞬态成像（transient imaging），有兴趣可以了解一下；整个"成像"这个范畴的研究，更多归在计算摄影学（computational photography）里。各个方向怎么区分，第一节课咱们简单说过。

回到图形学的话题上：既然说捕捉，今天就从相机开始。相机背后到底是什么？这就是本讲要讲清楚的事。

### 相机里都有什么

把一台相机沿轴线剖开，你会看到：最前面是一组镜头——很多不同的透镜组叠在一块；中间是机身；最后是感光元件。这台精密仪器里的各个部件到底各自干什么，今天把它们的原理都讲清楚。

提到相机，我们容易想到的是带一个大镜头的那种。但在很古老的时候，最早研究相机，是从一个最简单的现象开始的——小孔成像。

### 小孔成像：最早的起点

小孔成像是什么意思？看一个人。这个人之所以能被我们看到，是因为他在往四面八方反射光线——任何一个部分都在往任何一个方向反射光。现在在他前面放一块纸板，中间钻一个孔。光线是直线传播的：比如帽子上反射的光，往水平方向走就会被纸板挡住；它往哪儿反射才不会被挡住？只有正好对着洞的方向，这条光线才能钻过洞去。

如果把这个孔看成一个理想的点，那么物体上所有有反射光的点，都各有一条光线穿过这个洞，于是在纸板的另一侧，自然形成一个和原来上下颠倒的像。在右边放一个传感器、或者用胶片记录下来，就可以得到一张照片。

```text
  *                     *
   \                   /
    \                 /
     \               /
      \             /
       \           /
        \         /
         \       /
          \     /
           \   /
            \ /
             o
            / \
           /   \
          /     \
         /       \
        /         \
       /           \
      /             \
     /               \
    /                 \
   /                   \
  *                     *
```

读图：左上、左下两个 `*` 是物体上的点（顶端与底端），中间的 `o` 是纸板上只开的小孔，右侧两个 `*` 是它们投在成像面上的像——顶端的光穿过小孔落在成像面下部，底端的光落在上部，整个像上下颠倒。

这个道理很简单。公元前人们就已经发现了小孔成像的原理：高塔反射的光，经过一个小小的针孔，投影到幕布上。而且小孔成像有真正对应的相机，就叫针孔相机（pinhole camera）。当然，平常见得最多的还是带镜头的相机，今天都会说。

### 快门与传感器

先把相机的几个部件说清楚。把镜头从相机上拧下来，正对着镜头的位置上有一个部件，负责控制光能不能进到机身里去，这就是快门（shutter）。快门能控制光在多少分之一秒内进入相机。

光进来之后怎么办？肯定要被捕捉并记录下来。能捕捉光、并且能把东西记下来的部件，叫传感器（sensor）。那传感器上任何一个点——把它理解成一个像素——记录的到底是什么？记录的是 irradiance。这一点，用学过的辐射度量学就能解释清楚。

先做个思想实验：如果一台相机既没有镜头、也没有针孔，直接把感光元件放在人的面前，还能拍出照来吗？不可能。人在往任何方向反射光，传感器上的任何一个点，都可能收集到来自不同方向的光；而这个点作为传感器，它又不区分光从哪个方向来——于是它把来自各个方向的能量全部综合到这一个点上。用辐射度量学的话说：它收集的是 irradiance，收集不了 radiance。所有方向的光糊在一块，拍出来自然全都是糊的。

> **关键**：传感器上任何一个点记录的是 irradiance（不区分方向的能量总和），不是 radiance。相机必须靠小孔或镜头，替每个传感器点筛选光的来向。

顺带一提，现在已经有人在研究方向性的传感器：不同方向来的光可以分开记录，非常厉害，科技还在发展。但目前咱们还是这么认为：传感器记录不了 radiance，只能记录 irradiance。

### 针孔相机：一张处处锐利的照片

针孔相机不是只能在纸板上做思想实验，它直到今天真的可以拿来拍照。找一块硬纸板，中间留一个能透光的小孔，对着某个场景拍一张，把结果记录在胶片上——还真就能拍出来，效果相当不错。

不过针孔相机拍出来的照片有个鲜明特点：没有深度可言。任何地方都不会是虚的，无论前景、后景还是中间，处处都是锐利的，看不到任何虚化的地方。虚化到底怎么回事？之后会说——那是因为镜头的存在。

这里顺便把渲染的事说清楚：我们做光线追踪的时候，用的就是针孔摄像机的模型。所以正如针孔相机拍不出虚化，光线追踪也渲染不出"不同地方有不同模糊"的景深效果。反过来，如果能模拟光线如何与镜头作用，就可以做出带景深的渲染——这门课之后会说。

### 视场角：能看到多大的范围

接下来逐个介绍概念，从最简单的开始：视场（field of view，FOV）。视场说的就是我能看到多大的范围。所谓广角镜头，意味着能拍更广的角度，也就是视场更大；而 iPhone 上那种普通相机，视场就相对比较窄。那什么因素决定视场？按说在相机设计的时候就应该能定下来——答案是可以的，咱们从小孔成像来理解。

#### 从小孔模型算出 FOV

小孔成像很容易算出视场是多少，因为它有一个简单的相似三角形关系。从某一个小孔往世界看，会形成一个角度；把这个角度反向延长，就落到传感器上。设计时我们希望把整块传感器都用上：从传感器的上边缘连一条线到小孔，打到景物的一侧；下边缘连到小孔，打到另一侧——中间的区域都认为能看见，这样认为肯定没问题。

记传感器的高度为 $h$（视场有水平和垂直两种定义，正常情况以垂直为例，说垂直方向上的可视角度是多大——跟之前定义投影是一回事）。再定义传感器到小孔之间的距离为 $f$，把它叫做焦距。当然，对小孔来说本来不存在焦距这个概念，没关系，先这么定义。

于是视场角太好算了：把整个视场角 $\theta$ 取一半，这一半角度的正切就是 $\frac{h}{2}$ 除以 $f$：

$$\tan\frac{\theta}{2}=\frac{h/2}{f}\qquad\Longrightarrow\qquad FOV=2\arctan\frac{h}{2f}$$

如果让传感器离小孔更近，焦距 $f$ 变小，对应的视场就变大。所以通过相机的内部设计，就能推断出它对应的视场有多大——很简单。

#### 35mm 胶片基准与等效焦距

可回头一想：视场和什么有关系？从刚才的推导看，既和传感器大小有关系，又和焦距有关系。两个变量搅在一起，视场就没法用一个数说清楚。所以人们通常以 35mm 格式的胶片为基准：假定传感器都是 35mm 胶片这么大，然后通过定义焦距，来定义视场。

这就是为什么在市场上买单反镜头的时候，会看到"焦距"这个概念：17mm 对应的就是广角镜头——焦距短，在相同的传感器大小下，得出的视野自然就大。

这里有一个常见疑问：手机会告诉你，它的相机焦距是 28mm。可手机总共才多厚？厚度不到 1cm，怎么可能装下 28mm 的焦距来成像？这就是定义在起作用：标称的焦距指的是等效焦距——如果传感器是 35mm 胶片那么大，焦距相当于多少。手机的实际传感器小得多，实际焦距也就小很多。以后再看手机的参数，就明白是怎么回事了。

不同视场的镜头自然拍出不同的效果。在同一位置用不同的视场各拍一张：视场越窄，看到的东西其实越远。

#### 传感器大小：视场的第二个变量

刚才一直在说焦距，前提是传感器大小不变。如果真的能改变传感器的大小呢？用一个大一点的传感器和一个小一点的传感器，小传感器自然对应小的视场、小的可视角度，道理很直接。所以视场由两个因素共同决定；平常定义的时候，人们固定传感器大小，用焦距来衡量。把这个弄明白就行。

顺带分清两个平时混用的概念：传感器（sensor）和胶片（film）。平常认为它们是一回事——传感器上各个点与最后呈现的图像一一对应，传感器接收到的图像就是最后呈现的图像，不区分没什么关系。但如果搞渲染、用渲染器，这两个概念是要分开的：sensor 负责记录每个像素最后收到的 irradiance 到底多大；film 则由你决定把这些值存成什么样的图片格式。目前咱们还是把它们混淆使用。

传感器当然有不同的大小。正常的大相机有大传感器，就可以有更大的分辨率。各相机的价格各不相同——买相机的经验之谈：机身越大越好，镜头越大越长越好，价钱也照着往上走。你会发现，学图形学可不只是要学会数学、物理，还有生物等各种各样的学科——还得有点家底，才能研究明白相机是怎么回事。

手机对应的传感器就相对较小。这正是手机可以用一个非常短的焦距、还能达到一定可视角度的原因：小传感器把焦距也变小，就可以达到相同的视场。视场、焦距、传感器大小这三者的关系非常简单明了。

### 曝光：进光量乘以时间

下一个话题：曝光（exposure）。定义从公式开始看：

$$H=T\times E$$

exposure 等于 irradiance 乘以 time。怎么理解？很简单：对着一个明亮的场景拍一张照，得出来的结果看起来就亮一些；对着一个比较暗的场景，但快门按下的时间很长、曝光时间很长，你也可以得到一张比较亮的照片。两个道理：进了多少光，让它进来多长时间，把两者累积起来，就得到曝光度。

> **定义**：曝光 $H=T\times E$，即曝光度 = irradiance × 时间。它记录的是一段时间内累积的总能量，而不是单位时间的功率。

这里可以联系辐射度量学：辐射度量学里我们一直在说单位时间——单位时间有光到达某一个表面，单位时间又辐射出去，考虑单位时间就好了。照相可不是考虑单位时间，它考虑的是整段时间：快门留的时间长，更多的光进来、被传感器捕捉到，结果自然更亮。

曝光的两个因素在相机里都有体现："时间"体现为快门；"进了多少光"——相同时间内能接收多少 irradiance——由光圈大小决定。光圈说白了就是挡光用的：光圈开得大，更多的光直接进来，相同曝光时间内接收到的 irradiance 就多。相机的这些部件都可以单独控制，共同决定最后的曝光度。

### 光圈、快门、ISO：影响亮度的三要素

那相机里到底有哪些因素，影响最后照片拍出来亮还是不亮？归纳起来是三个：光圈的大小、快门的时间、ISO 增益。一个一个说。

先说光圈。相机是精密仪器，光圈的大小是可以控制的：最大肯定只能开到跟镜头一般大，然后可以继续变小。控制它的数字叫 f-stop，也叫 f 数，马上细说。

光圈其实是一个仿生学设计——它在仿照人的瞳孔。人的瞳孔可以动态调节大小：在相对暗的环境下，瞳孔会自动放大，单位时间接收更多光，你就可以看清楚更多东西；在非常亮的环境下，瞳孔会缩小，不让更多的光进来灼伤你的视网膜。光圈就是这么个意思：一个挡光的东西，它当然会影响曝光度。

再说快门。更专业的说法叫 shutter speed——快门有一个"速度"，你可以理解成快门开放的时间。关系是：shutter speed 越快，意味着快门开放的时间越短，更少的光会进来。把这个关系搞明白。

第三个是 ISO 增益，有时也被说成感光度。最简单的理解：ISO 是一个后期处理——感光元件感知到了某个量级的光，比如算出来是 0.1，那就把所有的值乘个十，乘到 1 上去。传感器接收到多少就是多少，只不过后期给它乘上某一个数。这个乘法可以发生在各个不同的地方：可以发生在硬件上，比如传感器本身，通过调节它的灵敏度来提高 ISO；也可以在相机生成照片之后，在照片的数字信号上去调。ISO 的具体实现不讲，大家简单认为"最后接收到多少能量，就乘上一个数"就行。而且它是线性的：ISO 200 一定是 ISO 100 的两倍。

| 因素 | 控制什么 | 对亮度的影响 | 伴随的副作用 |
| :--- | :--- | :--- | :--- |
| 光圈（f 数） | 镜头进光口开口的大小 | f 数越小光圈越大，单位时间进光越多 | 光圈大时画面部分区域发虚 |
| 快门（shutter speed） | 快门开放时间的长短 | 开放时间越长，累积进光越多 | 时间长会把物体的移动记下来，产生运动模糊 |
| ISO（增益） | 对感光结果整体乘的系数 | 系数越大照片越亮 | 同时放大噪声，高 ISO 噪声明显 |

### 把三要素放到一张图上看

这几个因素都会影响最后的图像亮度，那它们各自带来什么效果？把不同光圈、快门、ISO 取值下拍到的照片排成一张对照图，现象非常生动。

先看光圈这一组：外面一圈是黑色的遮挡物，中间那块才是实际的光圈大小。光圈用 f 数表示：f 后面跟着一个数，这个数越大，光圈其实越小。

> **易错点**：f 数越大，光圈越小。F32 对应的是最小的光圈，F1.4 才是大光圈，别把方向记反。

顺带说一句，这类图里 "5,6"、"1,4" 的写法是欧洲写法——把小数点写成逗号，分别是 5.6 和 1.4 的意思。

再看快门：shutter speed 通常用分数表示，非常好理解——就是快门开放多长时间。1/1000 的意思是开放 1/1000 秒，也就是 1ms；开放 2ms，得到的就是另一张图。

ISO 也可以调，不同的 ISO 可以认为就是简单地线性往上乘：ISO 200 就是把 ISO 100 那张图上的值乘一个 2。

这张图里还能看到两个现象。改光圈大小的时候，照片的感觉不太一样：光圈用得大，照片在一定的区域内就会很虚；光圈用得小，整张图看上去都很锐利——这是为什么？再看快门那一组：快门开的时间短，能看到一个正常跑步的人；快门开的时间非常长，怎么就看到一团模糊的东西了？这些都可以用今天学的东西来解释——先把最简单的 ISO 说明白。

### ISO 与噪声：放大信号也放大噪声

ISO 说白了就是一个后期处理：往一张比较暗的图上乘一个数。对应到信号领域想一下：任何一个信号本身肯定有噪声。你对整个信号乘以一个很大的数，信号确实放大了，但噪声的程度同样被放大了。

这就是为什么：在一个很暗的房间里，用很小的光圈、或者很短的快门时间，拍出来一张很暗的图；然后用相当大的 ISO 把它拉亮——它是变亮了，但同时冒出另一个问题：结果看上去非常 noisy。因为它就是直接往上乘，什么也不管。

所以正常情况下，大家不愿意通过调 ISO 来把图拉亮；在一定的小范围内调没有问题，调到非常大，一定会出现噪声问题——原因就是简单放大信号会同时放大噪声。

那为什么信号里会有噪声？这个问题其实很深。咱们现在最简单的理解：把光看成光子——之前讲 photon mapping 的时候就是这么认为的，实际的光线传播也可以把光线当成光子。如果快门时间不够，进到感光元件的光子数就少；光子数少，看上去的结果就是 noisy。这么理解是对的，只不过真要把这件事解释清楚不容易，先这么认为。

ISO 会带来噪声，不是我瞎说的。控制其他变量，让拍出来的画面一张比一张暗，再用 ISO 把亮度调回一样：ISO 100 的时候，结果挺好；ISO 12800 的时候，噪声就非常非常明显了。所以 ISO 确实能提升曝光度，但同样会造成噪声的放大。

### F 数：光圈大小的度量

回到光圈。描述光圈大小的数叫 f 数（f-number），也叫 f-stop，这两个是一回事——更专业的相机领域有人会区分，咱们不区分。f 数有两种写法：一种是 f 后面直接跟一个数（比如 F32），另一种是 f 后面打一个杠、再跟一个数。不管怎么写，我们关心的就是那个数 $N$，这个 $N$ 就是 f 数。要用单反认真拍各种照片，这个东西是肯定要学的。

f 数是什么？先给大家一个非正式的理解，正式的解答课的最后会给出：假设光圈是圆的，f 数就是这个圆的直径分之一——1 除以直径：

$$N=\frac{1}{D}$$

其中 $D$ 是光圈的直径。所以 $N$ 越大，直径越小——刚才看到了，F32 对应的就是最小的光圈。

调光圈，显然可以调出固定时间段内进入相机的能量大小，所以直接就能调出各种不同的曝光度。光圈还有更多的东西，后面再说。

### 快门是怎么工作的

那快门到底是怎么控制的？真实单反相机里的机械快门是这样工作的：一开始快门是关闭的，前面有一面镜子一样的东西；拍摄时，镜子先升上去，然后快门突然一下打开，再把它关上——这就是平常真正的相机里"给多长时间让光过去"的实际过程。

但注意一个细节：我说快门"突然"打开，其实它是有一个过程的。对任何相机来说，快门都不可能在某个瞬间"唰"地完全打开——总得有一个过程，有的地方已经打开了、有的地方还没打开，再快也得有这么一个过程。有同学会问：这个过程会造成什么影响？这就要说到快门的曝光时间对结果的真正影响了。

### 运动模糊：快门时间的另一面

快门的曝光时间当然可以起到调节曝光度的作用，但我们更关心它除了这个作用，还会产生什么。

回看对照图里那个跑步的人：快门时间长，相当于让光进来更长的时间，为什么人就模糊了？这个现象叫运动模糊（motion blur）。正常情况下，有东西在运动——握手、或者高速运动的物体——就容易出现运动模糊。

道理很好理解：它和快门打开的时间有关。在快门打开的这段时间内，物体已经发生了一些运动。光以光速传播，传感器把这段时间里的光都忠实地记录下来：快门刚开时物体在这儿，快门准备关闭时它已经到了那儿，中间的过程全都被记录下来。传感器在这一段时间里起的是平均的作用——看到的就是模糊。

两个规律：曝光时间越长，同样速度的物体在曝光期间移动的范围更长，运动模糊就更严重——这就是为什么更长的曝光时间造成更严重的运动模糊；反过来，快门时间不动，物体运动越快，越容易出现运动模糊。

手抖也是同样的道理。拍照为什么要用手臂架稳、或者上三脚架？就是为了减小在短时间曝光内产生的运动模糊。

那用更短的曝光时间——更快的 shutter speed——运动模糊就会减轻。但曝光度肯定也降低了：要达到相同的亮度，你肯定要么调 ISO，要么还得调光圈。

最后一个问题：运动模糊一定是坏事吗？不一定。玩过赛车类游戏的同学有体会：为了体现赛车的速度，要是没有运动模糊，你会觉得这个车特别慢。人们在长久以来用眼睛感知世界的过程中，自然而然形成了这么一个感觉：有运动模糊的，一定是快的。对比两类照片：一类有明显的动感，看起来是很快的运动；另一类甚至有可能是摆拍。运动模糊不总是要消灭的东西——它本身也是画面语言的一部分。

## 从运动模糊到景深：薄透镜成像
> 对应块：BLK30 | 覆盖分集：P19下 | 块标题（分集名）：《Lecture 19 Cameras, Lens》

### 先把运动模糊讲完：在时间上采样

先把快门这个话题收个尾。上一节结束时的问题还挂着：如果我不让照片有运动模糊，那意味着什么？

可以这么想：我要拍一段视频，在每一帧里都用非常短的快门，那么任何一个时刻物体运动到了哪个位置，我都记录下来了。可物体的运动本身是连续的——所以这相当于我在不同的帧、也就是不同的时间点上，对物体所在的位置做了一次采样。

这个事情就和之前讲的反走样非常像。平常我们用像素的中心去采样"这个点在不在三角形内"，采样的对象是三角形这样的空间信号；像素与像素之间有间隔，采出来的结果就会走样，而做反走样的时候，我们会引入一定的模糊。时间上的采样是同一个道理，只不过这次是在时间上采：如果画面里带着运动模糊，反倒起到了反走样的效果。所以分析快门速度这件事，要从两个方面看：一个是人的感知，一个就是时间上的采样。

快门本身还有个细节值得说清楚。电子控制的快门，你可以真的认为它在任何时刻都是全域同步打开的；但机械快门不一样——它有一个打开的过程，再快也有过程。如果物体的运动比这个过程还快、或者跟它差不多，就一定会出问题。这个问题叫 rolling shutter（卷帘快门）：快门是以某种方式渐渐打开的，于是图像上不同的位置，记录到的可能是不同时刻进来的光。对超级高速运动的东西——比如螺旋桨——就会造成扭曲：图像不同位置记录的是不同时候的桨叶，可不就扭了嘛。问题的根源就在快门打开这件事本身有一个时间过程。

### 快门、光圈、ISO：一套曝光里的权衡

快门说到这里，就可以和光圈放在一块考虑了。快门打开的时间短，进光就少，怎么办？提高光圈的大小——用更小的 f 数。把快门、光圈，再加上 ISO 一起考虑，就能配出曝光相同的组合。课程里有一张经典的表，上下对应的几行基本可以达到相同的曝光度、相同的亮度。

道理拿 f 数从 4 到 8 这一行就能讲清楚。f 数说的是直径分之一：从 f/4 到 f/8，直径相当于变成了原来的一半，光圈的面积就成了原来的 1/4。进的光只有 1/4，那你就应该用四倍的曝光时间去补偿——所以 f/4 配 1/60 秒，和 f/8 配 1/15 秒，曝光度基本是一样的。

| 光圈（f 数） | 快门时间 | 说明 |
| :---: | :---: | :--- |
| f/4 | 1/60 s | 直径大、面积大，进光多，快门可以短 |
| f/8 | 1/15 s | 直径减半、面积变为 1/4，曝光时间乘四来补偿 |

但要问一句：这两张照片拍出来是不是就一模一样了？并不是。大光圈会带来景深的问题（后面专门分析），快门时间又会影响运动模糊。所以这两个因素正常情况下都需要权衡：你想要景深，就顾不上运动模糊；想控制运动模糊，就得在景深上让步。把快门、光圈、ISO 全都放在一块，至少能保证配出一套曝光度相同的照片，这是没有问题的。

这套配合用到一定境界，就能拍出非常有意思的照片。

一个是高速摄影（high speed photography）。所谓高速摄影，就是每秒钟拍更多的帧，然后按正常帧数播放。每秒要拍更多张，就意味着每张照片分到的快门时间非常少——也就是非常快的快门速度。可每张又都得看得见、得有正常的曝光度，怎么办？刚才说过了：用更大的光圈，或者更高的 ISO。ISO 大家一般不喜欢，因为它会让结果变得有噪声，所以就用更大的光圈。子弹穿过苹果、穿过三个气球的那种照片，把运动员抛网球、接网球的整套动作拍得清清楚楚的照片，都是这么来的。

另一个反过来，是超低速：给照片特别特别长的曝光时间，配非常小的光圈，让它慢慢拍。这样拍出来的就是长曝光的作品，摄影界俗称"拉丝"——看上去就像有丝一样。飞机着陆或起飞的轨迹能拉出丝，海面上运动的什么东西能拉出丝，甚至有一幅作品拍的是一根电线杆下面各种飞虫飞来飞去的轨迹——不知道谁想出来的，不过看起来非常有趣。你看到的那些丝，其实就是运动模糊：打开快门的这段时间里，物体发生了剧烈的运动，你把它整个记了下来，就变成这么一个情况。

### 真正的主角：透镜

接下来进入相对困难一点的话题。相机这么多的部件里，除了光圈、快门，最重要的就是镜头了。

真实的镜头非常复杂。不管什么相机——手机的也好、别的也好，比如 iPhone 的相机——都是很多层不同的透镜叠成一个透镜组，背后才是感光元件。就目前来说，不会有相机拿单片透镜来成像，大家用的都是透镜组。而且有的透镜形状（比如一面凸、一面平的那种）根本没办法把平行光聚到一点：按说透镜该把平行光汇聚到一个点上，它就是聚不到一块儿去，不满足理想成像该有的形状——这就造成了所谓的 aberration（像差）。

真实的透镜这么复杂，我们就要用一个简单的方法来描述它，这就是理想化的薄透镜（thin lens）。

> **定义**：薄透镜（thin lens）是理想化模型：透镜自身的厚度忽略不计；平行于光轴的平行光会被它汇聚到一点。

### 理想薄透镜的四条约定

第一条：平行于透镜（垂直入射）的平行光打进来，都会被汇聚到一个点上，这个点叫焦点；焦点到透镜中心的距离，叫焦距 $f$。第二条：光路是可逆的——如果光线先穿过了焦点、再被透镜折射，出去之后会变成一束平行光。这两条是以前物理课都讲过的，我们先默认没问题：平行光一定汇聚过焦点，过焦点一定会变平行光。

第三条是我们这个模型里比较独特的一个假设：假设这片薄薄的透镜可以任意改变它的焦距。你可能会想，一片设计好了的透镜，焦距肯定是固定的，改不了。单片确实改不了；但现在的相机用的是透镜组，通过各种各样不同的组合，组出来的整体效果，就好像是一片能改变焦距的薄透镜一样。现在这些相机的设计都非常精巧，能做到这件事，所以现实中你完全可以认为"我可以改变透镜的焦距"。我们也把它作为基本假设：透镜的焦距可以动态改变。顺带回答一个常见的疑问：这些公式今天还有用吗？有。现实中各种透镜组的设计仍然要用这些公式；而且组里不只是凸透镜，还有凹透镜、一面平的凹透镜，各种放到一块——正因为能组合，才能动态地改变焦距。

第四条：任何一条光，只要穿过透镜的中心，方向就不会变，直着往前走。这是由对称性保证的。

### 物距、像距与薄透镜公式

有了薄透镜，就可以说成像了。基本配置：左边放一个物体，经过透镜之后，成像到右边。这里定义两个距离——物距 $z_o$，物体到透镜的垂直距离；像距 $z_i$，成的像到透镜的垂直距离。加上之前定义的焦距 $f$，透镜成像满足这么一个规律：

$$\frac{1}{f} = \frac{1}{z_o} + \frac{1}{z_i}$$

它说的是：对一片固定焦距的透镜，物距要是变了，像距一定得跟着变。这非常有道理。

先给大家吃颗定心丸：相机里涉及各种各样的公式，但推起来真的不难，关键就是把各个部件到底是什么意思说明白。这个式子的推导就是典型，用纯几何就能做。从物体的顶点引两条特殊的光路：一条平行于光轴入射，折射后穿过焦点；一条先穿过（前）焦点，折射后变成平行光。只看这两条光就够了，它们各自给出一组相似三角形。

第一条光路（过焦点变平行）在物侧给出：物高 $h$ 比上物体到前焦点的距离 $(z_o - f)$，等于这条光在透镜上截出的高度 $a$ 比上焦距 $f$。这束光出透镜后平行于光轴、高度不再变，而它最终必须汇聚到像点上，所以 $a$ 正好等于像高 $h'$。整理成比值：

$$\frac{h}{h'} = \frac{z_o - f}{f}$$

第二条光路（平行光过焦点）在像侧给出：这束光在透镜上的高度正好是 $h$，出射后穿过焦点、打到像点上；透镜到焦点的距离是 $f$，焦点到像的距离是 $(z_i - f)$，于是：

$$\frac{h}{h'} = \frac{f}{z_i - f}$$

$h$、$h'$ 都是未知的，但两个式子给出的是同一个比值 $h/h'$，让它们相等、交叉相乘：

$$(z_o - f)(z_i - f) = f^2$$

展开，左边的 $z_o z_i - (z_o + z_i)f + f^2$ 与右边的 $f^2$ 一抵消，剩下 $z_o z_i = f(z_o + z_i)$，两边同除以 $z_o z_i f$，就是薄透镜公式。因为整个推导靠的全是相似三角形，这个式子又叫高斯薄透镜定理，平时就直接叫薄透镜公式。

```text
     object (height h)                lens             image (h', inverted)
        ^                               |                     v
 -------+-------------------------------+---------------------+------> axis
        |<----------- z_o ----------->|<------ z_i ------>|
        
        f : distance from focal point to lens center
```

读图：物体在透镜前 $z_o$ 处，像成在透镜后 $z_i$ 处且倒立；推导用的两条特殊光路，一条平行入射过后焦点，一条过焦点出射平行。

课堂上我还准备了一个很好用的交互演示（从链接就能直接打开）：调物距，相机那一侧必须跟着动；调另一边也一样；调焦距，物距像距的关系又会整体变。三者的联动，动手拖一下就非常清楚。

> **易错点**：成像位置和焦点完全是两回事。焦点的性质只有一条——平行光会过焦点、过焦点的光会变平行。而成像位置由透镜公式决定：物距和焦距定了，像距就算出来了；把感光元件正好放在那个位置，物距那个平面的像才清晰地投到胶片上。理解的时候，就想象透镜左边画一个三角形、右边再画一个三角形。

### 模糊圈：一个点为什么会糊成一圈

通过薄透镜可以解释好多好多问题，根本不需要动用真实的透镜组。先解释第一个：defocus blur（散焦模糊），也就是景深问题的根源。为此要引入一个概念：circle of confusion（模糊圈），简称 CoC。

先说对焦平面（focal plane）：远处某一个平面上所有的光，经过透镜之后都会聚焦到右边某一个平面上——我就把左边这个平面叫对焦平面，右边那个是成像看上去最锐利的成像平面。随便拍一张照片，总有一个地方是完美的、不模糊的，其他地方都会模糊。那如果物体不在对焦平面上，会发生什么？

物体上随便取一个点，它穿过透镜之后，用透镜公式一算——$1/f = 1/z_o + 1/z_i$——它应该聚焦在像距 $z_i$ 的位置。可你的成像平面不在那儿，离它有一段距离。光线不会在聚焦点停下来，它继续往前传播；继续传播就意味着：原来左边的一个点，等被感光元件（sensor）接收到的时候，就不再是一个点了，而成了一片——在二维的图上看是一条线段；实际三维情况里透镜是圆的，这个点落到 sensor 上就是一个圆。这个圆就叫 circle of confusion。

为什么叫"confusion"（混乱）？因为在这个圆的范围之内，你区分不了光到底是从哪个点来的：相邻的两个点，各自都会在 sensor 上投影出一个圆，两个圆叠在一块，你就不知道这个点到底在哪了。这名字起得很对。

> **定义**：CoC（circle of confusion，模糊圈）——一个物点没有正好聚焦到感光平面上时，在 sensor 上形成的一个圆斑。

那 CoC 有多大？它和几个因素都有关系，首先就是光圈（aperture）的大小。看几何：聚焦的光锥和 sensor 相交，形成两组相似三角形，于是

$$\frac{\text{CoC}}{A} = \frac{z_i - z_s}{z_i} \quad\Longrightarrow\quad \text{CoC} = A \cdot \frac{z_i - z_s}{z_i}$$

其中 $A$ 是光圈直径；$z_i$ 是这个点的像距——物距和焦距都知道，像距自然算得出来；$z_s$ 是成像平面到透镜的距离。两个距离一减就是 $d' = z_i - z_s$（取距离差，sensor 在焦点之前还是之后都一样）。把 $A$ 挪到等式右边，结论就出来了：

> **结论**：CoC 的大小与光圈直径 $A$ 成正比。光圈的 f 数是 1.4，那就是大光圈，自然要期待更模糊的效果；小光圈就基本看不出模糊。

准备这门课的时候，我还专门查了一下 CoC 到底该怎么翻译，想给大家一个中文说法，结果碰上一件不得不分享的事：我拿去 Google 翻译，它把 circle of confusion 翻译成了"混乱的圈子"。当时弹幕马上有人接了一句"贵圈真乱"，简直了。所以说 AI 距离统治世界还有段距离，还得再努力。大家当个笑话看，但意思没翻错：一个点成像过来，在 sensor 上变成了一个圈。

### F 数的正式定义

之前我们一直把 f 数随口说成"直径分之一"，严格讲这不对。F 数（f-number）有明确的定义：

$$N = \frac{f}{A}$$

焦距除以光圈直径。它确实跟"直径分之一"有关系，但还跟焦距有关系。相机上标的那些数——1.4、2、2.8 这些——经常写成 f/1.4 的样子，也有直接写成 F1.4 的，我们关心这个数本身就行。这个定义把三样东西联系到了一块：f 数、光圈的实际大小、焦距。

有了 $N = f/A$，立刻能把 CoC 和 f 数挂上钩：光圈直径 $A = f/N$，代回 CoC 的式子，

$$\text{CoC} = \frac{f}{N} \cdot \frac{z_i - z_s}{z_i}$$

CoC 与 $N$ 成反比。所以想拍出更清楚的照片，自然要用小光圈——就是这么个道理。

> **提示**：f 数也可以理解成"透镜的大小"。实际上你是用不同的东西去挡这枚透镜，相当于在动态地改变透镜的通光大小；曝光补偿和曝光时间、光圈大小的关系，就归结为快门、光圈、ISO 这三个因素各自的折算。

### 用薄透镜模型做渲染

透镜怎么弯折光线我们都会算了，那自然而然就可以用薄透镜来渲染。想想平时我们做光栅化也好、光线追踪也好，光线是怎么产生的？从相机往任何一个像素中心连一条线——这其实默认了小孔成像（针孔摄像机）模型，相机就是一个点。但我们完全可以渲染出薄透镜模型：模拟一片薄透镜，给它焦距，规定好感光元件离透镜多远，然后实际去做光线追踪。

设定方案是这样的：

1. 先确定 sensor（感光元件，即成像平面）本身的大小——它在空间中占多大一块区域；
2. 定义透镜本身的属性：焦距和光圈大小。注意到现在还没跟场景发生任何关系，而且从此就没有"相机位置"这个东西了——没有那个小点了；
3. 把透镜真正放进场景：规定它离场景中某个你想着重拍摄的平面有多远，这个距离就是物距 $z_o$；
4. 物距 $z_o$ 和焦距 $f$ 都知道了，用薄透镜公式一算，像距 $z_i$ 就出来了——sensor 与透镜的距离也就定了。

然后就可以真正做光线追踪了，做法很简单：

1. 在感光元件上选一个点 $x''$；
2. 在透镜上再选一个点——透镜本身是个圆盘，上面任何一点都可以；
3. 把这两个点连成一条线。这条线穿过透镜之后会往哪儿去？透镜公式直接告诉你折射后的方向：它一定会打到对焦平面上对应的位置 $x'''$，这一点是确定的；
4. 于是这条光线最终会被记录到 sensor 的 $x''$ 上——只需要考虑 $x''$ 到场景这一段光路携带的 radiance，算出来记到 $x''$ 上就行了。

```text
    scene (in focus)               lens                  sensor
        |                    focal length f               |
        |                      aperture A                 |
        |                          |                      |
  x'''  + . . . . . . . . . . . . o . . . . . . . . . .  +  x''
        |<---------- z_o --------->|<-------- z_i ------->|

  pick x'' on the sensor and any point on the lens; connect and
  extend the ray: it must hit x''' on the focal plane
```

读图：sensor 上的 $x''$ 与透镜上任一点的连线，延长后必达对焦平面上的共轭点 $x'''$；这条光路的 radiance 就记到 $x''$ 上。说白了，整个事情就是利用透镜公式算一算折射光线的方向。

### 景深：清晰的那一段范围

有了 defocus blur，就可以正式定义景深（depth of field）了。先看两张照片，一张大光圈、一张小光圈：大光圈对应大的 CoC，一个点会变成更大的圆，所以更模糊。但不管哪张照片，总有一些地方是不模糊的——就是对焦平面上。也就是说，光圈的大小影响的是模糊的范围：对焦平面附近多远还算清晰，这个范围跟着光圈变。我们就来研究这个范围。

景深的定义：实际场景中有一段深度范围，这一段的光经过透镜之后，会在成像平面附近形成一小段区域，这段区域内 CoC 都足够小——这段场景深度就叫景深。

为什么 CoC"足够小"就算清晰？可以这样想：成像平面上有各种各样的像素，一个像素再怎么说也不是一个点，它是有大小的。当 CoC 的大小跟像素差不多、甚至比像素还小，最后得到的结果就可以认为是锐利的。所以不止成像平面本身，它附近一个很微小的范围内，成像出来的结果都可以接受为清晰——这就是"CoC 足够小的一段范围"的意思。

定量上怎么算？给场景深度记号：景深的最远一处叫 $D_f$，最近一处叫 $D_n$，对焦平面的深度叫 $D_s$（大写 $D$）。从最近、最远这两个深度各引光线穿过透镜，看它们在成像平面附近各自形成的 CoC，用相似三角形把这几个深度、焦距、光圈和可接受的 CoC 大小联系起来——分析全在透镜右边进行。这里不做推导，其实想推导超级简单，别看图上的量多；最后解出来的就是景深

$$\text{DoF} = D_f - D_n$$

课堂的演示里还有几条很能说明问题的性质：

- 调 sensor 离透镜的距离（也就是调对焦位置）：sensor 离透镜近的时候，景深变大；离得太远，景深变小。
- 改焦距：用大的焦距，会看到更浅的景深——只有一小段是清晰的，其他地方都模糊。
- 改 F 数（也就是改光圈大小）：光圈越小，景深越大。这条非常能解释问题：光圈越小，透镜就越接近一个小孔；接近小孔的话，各处都应该清晰，清晰的范围自然就大。
- 调可接受的 CoC：如果我认为 CoC 不超过某个大小都还能接受、都算清晰，那容忍的 CoC 越大，对应的景深就越深。

> **结论**：景深就是成像清晰的一段场景深度范围。光圈越小越接近小孔成像，景深越大；焦距越长，景深越浅。

### 番茄还是西红柿：光场的名字

幻灯片上光场这个词，我写了两个：一个叫 light field，一个叫 Lumigraph。这两个指的完全是同一个东西，就好像番茄和西红柿。这是历史遗留问题：两个不同的组各自发明——或者说发现——了光场这么一个东西，各自给这个描述光线的东西命了名，到现在还争论不休，到底哪一个先发明、光场到底应该叫什么。从中文翻译来看，大家认可更多的是"光场"这个叫法。这桩公案我们不多考虑，课里统一用 light field 的概念。

### 一块幕布：你看到的到底是什么

光场到底是怎么回事？首先得从"我们看到的是这个世界"说起。这件事非常复杂，但我们设定一个简单的场景：我们坐在这个屋子里，看这个屋子，以及透过屋子看到外面一棵树——这是我们看到世界的过程。如果我把我看到的东西画下来，这就是一幅图：窗户、窗外的树、墙壁各处的东西，都没有问题。

那我现在问这么一个问题：如果我把这个房间整个砍掉，或者说在房间中间加上一块幕布，而这块幕布非常好，能够严格模拟你之前看到的这些光线——从某个点打到某个点、它的强度是多少——并让它显示的正是你刚才所能看到的那幅图。那么你坐在这里看这块幕布，绝对不会体会到任何和真实世界的区别，就好像你还坐在真正的屋里往前看。

由这个思想实验能想到两件事。第一，这就是**虚拟现实的原理**：戴上头戴式设备，成像平面就在眼前，但它让你认为呈现的是整个世界。也就是说，如果把所有信息都完整地记录在一个平面上，并且能被人看到，那就严格意义上和人看到真实场景一模一样。第二，稍微题外一点，这种应用其实在科幻电影里已经出现了——《碟中谍》，我不记得是第几部了，中间在克里姆林宫里发生的那场戏，严格意义上用的就是这种技术，这里不多说，大家回去自行查一查。

所以大家看到的是什么？就是从各个方向进来的光线。其实你根本看不到这条光线从多远来、从什么地方进——我们不关心这些。我们只关心：人眼从某个方向看向某个方向，能看到什么。就这一件事。

### 全光函数：七个维度装下整个视觉世界

人到底可以看到什么东西，可以用一个函数来描述，这就是所谓**全光函数**（plenoptic function）。全光函数是什么？就是我们所能看到的所有东西。为什么是这么回事？咱们从最简单的全光函数开始，一步一步把它说明白。

第一步，假设我站在一个场景里，位置固定，可以往四面八方看。任何一个方向都可以用它的极坐标 $(\theta,\varphi)$ 表示，那我就可以定义一个函数：往任意一个方向上看，我能看到一个什么值。这个函数自然就是 $\theta$ 和 $\varphi$ 的函数，最后的结果是一个数：

$$P(\theta,\varphi)$$

这样我就能表示"我在某个地方、往所有方向看，可以看到什么"。

第二步，把这个函数稍微改进一点：引入**波长** $\lambda$。所谓波长，其实就是引入各种不同的颜色——大家知道，颜色基本上就是因为光有各种不同的波长。往某个方向看，能看到某个波长的光，把每个方向、每个波长的信息都记录下来，我才算看到了一个彩色的世界：$P(\theta,\varphi,\lambda)$。

第三步，我们不是想得到我们能看到的**所有**东西嘛，那继续扩展一个**时间** $t$。大家可以想到，这就是电影：往各个不同方向看的信息都是彩色的，并且在不同时间显示的东西不一样——$P(\theta,\varphi,\lambda,t)$，这可不就是电影吗？

第四步，再进一步。刚才这个人的位置不是一直固定着吗？现在考虑让他——或者说摄像机——在三维空间中任意移动，位置用 $(V_x,V_y,V_z)$ 表示。加了它之后，我看到的这就是一个所谓**全息电影**：我不止可以看到这个世界，还可以改变自己的位置，从另外一个角度来看这个世界。

| 逐步加入的量 | 函数形式 | 对应的概念 |
| :--- | :--- | :--- |
| 方向（二维） | $P(\theta,\varphi)$ | 站定后环顾四周能看到的一切 |
| 波长 | $P(\theta,\varphi,\lambda)$ | 彩色的世界 |
| 时间 | $P(\theta,\varphi,\lambda,t)$ | 电影 |
| 位置（三维） | $P(\theta,\varphi,\lambda,t,V_x,V_y,V_z)$ | 全息电影 |

大家觉得这个事情是不是很神奇？我们可以看到这么丰富的世界，其实拿**七个维度**就可以衡量了：任何时刻、任何位置、任何方向看到的东西——整个一个视觉的世界，就是这个七维函数。当然，之后还可以再改进、再加入点什么，那是有可能的。另外注意，全光函数本身不一定是离散的——画成一个个离散的点只是示意图，方向也应该是连续的。

到此为止，这个七维函数就是我们所说的全光函数。整个世界都可以拿它来表示，而光场的概念，就从这里开始。

### 光场：二维位置加二维方向

所谓光场，就是从全光函数中提取出来的一部分信息：平常在一个点往一个方向看，记录的是来自各个方向的光的信息；光场相当于是记录了稍微多了那么一点点的信息——**光场其实就是全光函数的一个小部分**。

要定义光场，先回顾一下光线的定义。很早之前我们就说过，一条光线得有个起点、有个方向：起点是 $(V_x,V_y,V_z)$，方向是 $(\theta,\varphi)$。那这样定义是不是最好的？不一定。定义一条光线有各种各样不同的方式——比如方向已知（连正负都知道），那我任意取两点，两点确定一条直线，也能定义这么一条光线。

但不管怎么定义，可以得出一个关键结论：要描述一条光线，其实我只需要**二维的位置和二维的方向**。这怎么理解？看物体的表面：三维世界中，三维物体的表面本身是嵌在一个二维的空间里的——纹理映射早就讲过，用两个数 $(u,v)$ 就可以表示表面上的任何一个位置。方向也一样，空间中任何一个方向都可以用 $(\theta,\varphi)$ 两个数表示。两个数表示位置、两个数表示方向，这就是光场。

再从"看"的角度把它串一遍。任何一个物体都可以被放在某一个盒子里；我看向这个物体，无非是从任何位置、任何方向看它。反过来利用光路的可逆性：要想描述这个物体所能被看到的所有情况，只要把它的表面在任何一个位置、往任何一个方向过去的光线都记录下来，那我从任何一个位置看向这个物体它长什么样，我就都知道了——因为你的观测点加上表面上的点，两点确定一条光线，方向也有了，去查询我们记录的这个函数就行。这个函数记录的是物体表面不同位置往各个不同方向的发光情况，可以理解成一个黑盒：它往各个方向去的光照情况是什么样的，把信息记录下来，这就是要的光场。

> **定义**：光场就是在任何一个位置、往任何一个方向去的光的强度。它是四维的——二维的位置加二维的方向，是全光函数的一小部分。

这里其实不必纠结光场一定定义在"物体表面"上。就像开头那块幕布：到底是一块幕布还是整个物体的几何，我们并不关心，只关心到达观测点的某一条光线带的能量是多少。所以我不需要知道这个光场表示的是什么东西，把它当成一个黑盒：只要在它的盒子表面任何一个位置、任何一个方向过去的光线都能查到，光场就记录下来了；盒子里面是什么，没有记录，没有问题。

光场的好处立刻就出来了：我从任意一个位置往这个物体上看，无非是确定往各个点、各个方向看的光线，然后从这个四维的光场里查出对应光线的强度，也就是我能看到什么。所以有了光场，我们可以得到这个物体的**任意观测**——从任意一个位置看向它，我都知道。

### 两个平面参数化：u–v 与 s–t

还可以更简单。取一个平面，平面右边是一些发光的物体，它们发出各种各样的光穿过这个平面。平面右边的东西全都可以忽略，我只需要知道平面左边是什么：平面上一个点，加上一个方向——平面情形下一个数就够了，三维情形两个数 $(\theta,\varphi)$。于是自然有这样一个想法：**对于任何一个光场，是不是可以用两个平面来定义？**

可以。取两个相互平行的平面，各自任取一个点——每个点都是二维的——这两点一连，我就知道对应的是哪一条光线，把这条光线的值记下来就行。我只需要找到所有的 $uv$、所有的 $st$ 的组合，就可以描述所有不同位置、不同方向出来的光线。这就是通常大家用到的经典参数化方法：$uv$ 和 $st$。说白了，光场本质上就是一个四维函数，这只取决于我们如何描述它。

```text
      s–t 平面（近，光线穿过它）            u–v 平面（远，相当于"眼睛"）
        ┌───────────┐                       ┌───────────┐
        │         s ●│──────────────────────│● u        │
        └───────────┘                       └───────────┘
                 两个平面各取一点，一连 = 一条光线
     光场 = 所有 (u, v, s, t) 组合对应光线的强度，恰好四个自由度
```

这组 $u,v,s,t$ 有两种理解方式。一种是容易的：固定 $u,v$ 上的一个点，看遍所有的 $s,t$——这就好像一个针孔摄像机从那个点看向整个世界，会看到一张完整的图、一个完整的物体。把 $u,v$ 的位置换一换，就相当于换了个机位，从另外一个角度拍这个世界。

另一种相对困难：反过来，固定 $s,t$ 上的一个点，往 $u,v$ 平面上看，看到的是**同一个物体点在不同方向上的样子**。这块不太好理解，先给一个感觉上的说法：就好像你盯着同一个点，从不同的角度去看，会看到类似"高光在变"的那种效果。再给一个更技术的说法：相机拍了一张图，一个像素上存的是什么？是 irradiance，咱们上节课说过。而固定 $s,t$ 遍历 $u,v$，恰恰可以把像素上的 irradiance **展开成 radiance**——你可以看到打到任何一个像素上、不同方向的光分别是什么。这里一时想不通没有关系，等说到光场相机，会把这件事情讲得更清楚。

| 固定哪一组 | 遍历哪一组 | 看到什么 | 直觉 |
| :--- | :--- | :--- | :--- |
| $u,v$ | $s,t$ | 一张完整的图 | 相当于一个针孔相机放在该处拍的照片；换 $u,v$ 就是换机位 |
| $s,t$ | $u,v$ | 同一点来自各方向的光 | 盯着同一点换角度看，高光会变；把该像素的 irradiance 展开成 radiance |

顺着第一种理解，真有人这么做了：斯坦福做了一个摄像机阵列，由上百台相机组成。每个相机在一个位置上，对应一个 $u,v$；它拍出来的一张照片是二维的，对应一组 $s,t$。二维乘二维，这就是四维的光场——把所有这些图组织在一块，就是整个光场。当然，一个摄像机阵列是要花很多银子的，大家可以算一算这个概念。

### 把像素拆开：从复眼到微透镜

为什么我们要费劲讲第二种理解？因为在自然界里，就有生物在这么成像——比如苍蝇。苍蝇的眼睛我们管它叫**复眼**，它的成像原理其实就是在成像一个光场。

怎么理解？还是从刚才的角度出发，盯着一张正常拍出来的照片看。照片上的任何一个像素，记录的是所谓 irradiance——它不区分光来自哪个方向，把各方向来的光都平均在一块。这也是上节课提到过的：为什么相机一定要有镜头，不能把感光元件直接放在面前？因为任何一个感光元件、任何一个像素，都会把所有不同方向上来的光记录下来、平均起来。

那如果我有办法把这些方向**分开**呢？光打到这个像素的时候，不立刻记录它，而是把这个像素变成一枚小透镜，让它的作用是把来自各个方向的光分到不同的位置上去；实际的感光元件放在透镜背后、底下。经过这么一步分光操作，打到原本这个像素上的、各个方向的光，就被分别记录在了不同的位置上：红光在这里、绿光在这里、蓝光在这里。也就是说，我记录的不再是一个像素平均下来的 irradiance，而是它往这个世界各个不同方向看到的 radiance。

```text
          各方向来的光（红 / 绿 / 蓝）
            \      |      /
             \     |     /
              \    |    /
           ┌─────────┐                ┌─────────┐
           │  像素   │                │ 微透镜  │
           └─────────┘                └─────────┘
                │                    ↓     ↓     ↓
         全部平均成一个值           蓝    绿    红
        （记录的是 irradiance）（分散到透镜后面不同的位置上，
                                  一格对应一个方向）
```

而这正是**光场相机的基本原理**。再回过头总结一遍：我看着一个像素，其实相当于看着穿过这个像素的不同方向的光——光场相机做的事情，就是把这些方向拆开、分别记录。

### 光场相机：先拍照，后对焦

光场的原理说清楚了，利用它就可以做一个真正的相机出来。这里要提 UC Berkeley 的 Ren Ng 老师——这个姓写作 Ng，写法很奇怪，读法也特别，其实对应中文的"吴"姓。他创立了一家公司，做的就是 Lytro 光场相机，算是世界上首创，真正让光场相机进入了消费者的层级。它的原理就是我们刚才说的微透镜：把一个像素替换成一个透镜，让透镜把来自不同方向的光分开，然后再记录下来。

它最重要、最重要的功能，是支持**后期的重新聚焦**。什么叫后期重新聚焦？就是你拿到相机，先随便拍一张照，聚焦的事之后再考虑——不光可以动态调节各种虚拟的焦距，连光圈的大小也可以后期来改。"先拍照、再调聚焦"，这就非常好：有时候你想拍一张重要的照片，结果调各种参数给调坏了，拍出来一张比较糊的照片；对光场相机来说不存在这个道理——直接拍，拍完了动态调。

Lytro 出过两代：一代是非常小的手持设备，二代就和一台真正的相机差不多大了。这两个实体我都是见过的，而且也拍过照，就在伯克利这块。顺带说个小事情：我的毕业典礼，就是 Ren Ng 老师帮我拨的穗。有同学可能要问，为什么不是你老板来帮你拨穗？这是另外一个问题，咱们先不说。

实际用 Lytro 拍出来的效果是这样的：可以先拍一张很糊的照片，然后动态调焦距。一开始，聚焦平面在这个人的脸上；继续把聚焦平面前推，头部这一块变清晰了；再推，聚焦平面到了椅子这一块，椅子清楚了，后面的人自然就变虚了；还可以继续，聚焦平面不断地往近处拉近。确实可以做后期对焦。

原理我们再过一遍。普通相机里，成像平面上任何一个像素，会接收到来自于各个不同方向的光，平均起来，这就是 irradiance。光场相机做的，就是把这些原本的像素换成微透镜，把感光元件往后挪一点点，让不同方向的光经过透镜之后正好分散在一片区域上，再把它记录下来。所以光场相机和普通相机的区别，说白了就是：**原本我记录一个像素，现在我要记录一块像素。**

光场相机直接拍出来的最原始的图是什么？原本的一个像素，现在变成了一个圆。至于为什么设计成圆、不是方块，无所谓——任何一个圆的内部，如果把它平均起来，就是以前普通相机得到的结果；而圆内部的各个像素在干的活，是记录各个不同的方向。

> **提示**：有同学问，小孔不是也可以把光分开吗？没有那么容易。小孔成像是一个非常理想化的情况，实际用透镜只会比这更复杂——透镜阵列怎么设计，咱们之后再说。

从这个微透镜阵列往左边看：不同的透镜对应不同的位置，每个透镜又可以接收到不同方向上来的光并把它存起来——不同的位置、各自往不同的方向，这可不就是一个光场吗？所以光场相机的原理，说白了就是：**一个像素原本记录的 irradiance 被拆开了。**

那么一个很现实的问题来了：拍出来那张跟复眼看到的图一样的原始图，怎么还原成一张普通的照片？很简单。每个微透镜下面有各条不同的光线，我在每个透镜下面都选同一条——比如都选最底下这一条，也就是所有光线都从这个方向进来——把选出的结果记录在对应的一个像素上。这样每个透镜就对应一个值，可不就得到一张照片了吗？这就像把相机放在某一个位置、往某个方向看。更进一步：如果每个透镜选的都是中间这条光线，就好像把相机放在正中间往前看；如果选的都是上面这条光线，得到的就相当于相机在上面拍的结果。

通过这种方式我们做到了什么？**有了光场，就可以虚拟地移动摄像机的位置。**大家想一想，以前这是不可能的事情：你拍了一张照片之后想把镜头挪一下位置，那得依赖计算机视觉重新去算；而光场相机可以严格地做到——取不同方向的光线，其实就相当于移动摄像机的位置。

重新聚焦利用的是完完全全一样的道理，具体的动态重新聚焦算法这里不展开。为什么可以这么做？因为你拥有整个光场。想象把焦平面移得非常远或者非常近，移动的过程中对应的光线应该如何变化；算出来之后，就按需从四维的光场里去查询：对不同的透镜，我要查的光线可能不在同一个位置——没有关系，算出来该查哪个方向，就去查询这个方向。这跟虚拟移动相机位置在理论上是一模一样的，中间无非需要一些计算，算出我到底应该去哪些方向取值。

总结起来：为什么"移动摄像机位置""动态聚焦"这些功能可以得以实现？正是因为光场相机记录了**整个光场**的信息，而整个光场，就是所有进到这个相机里面的信息。

### 代价：分辨率与成本

有同学问：光场相机是不是完美的，能解决所有问题？答案是它自己有问题，而且非常明显——**分辨率不足**。

大家想象一下：原本成像平面在这里，现在成像平面在后面，它记录的是什么呢？每一个小块——比如认为是 $10\times10$ 的一小块像素——记录的是原本普通相机一个像素的信息。如果用相同的胶片，那我原本一个像素记录一个像素的信息，现在得用 100 个像素记录一个像素的信息，因为我把不同的方向分开了。也就是说，胶片的分辨率现在变成了所谓**空间上的分辨率乘以方向上的分辨率**：方向上既然要记录得多，照片本身记录的分辨率就肯定低。所以它对胶片的分辨率要求非常高。

自然而然，它还会造成另外一个问题：**高成本**。一方面，要让光场相机达到跟以前一样的空间分辨率，就得用超级大的实际胶片分辨率；另一方面，微透镜这些透镜的原理很简单，实现起来绝对没有这么简单——它是一个超级精密的仪器，中间的设计有各种各样的问题。这就造成了光场相机的高成本，这是目前来说没有办法避免的问题。当然，我也希望科技进步，到时候能解决这个问题。

再从中体会一下取舍：如果需要记录更精密的方向信息，比如 $10\times10$ 不够、要记录 $100\times100$，那位置信息就丢失得更多——留给记录像素的数量就更少了。回想复眼那张图：一个圆圈特别大，你能记录的圆圈数就少。所以大家再次可以体会到，整个计算机图形学就是关于**各个方面的权衡**：你提升了这一块，另外一块可能就要受影响；而最重要的目标，是让很多方面都能同步得到提升——这也是大家做进步的思路。

好，关于光场这一块差不多到这里。回头看，$u,v,s,t$ 这套理解里，反过来的那种（固定 $s,t$）稍微麻烦一点；但对应到光场相机上，把一个像素的 irradiance 拆成各个方向的 radiance 之后，这块就不难了。光场说完，接下来就轮到这一讲的正题——颜色。

## 颜色与感知：你看到的从来不是光谱本身
> 对应块：BLK32 | 覆盖分集：P20下 | 块标题（分集名）：《Lecture 20 Color and Per》

先把光场那边收个尾。光场就理解成一种"分布在空间中的场"：空间中任何一个点、往任何一个方向，都可以记录一条光线的强度——这和我们熟悉的磁力场、引力场完全是一个概念。有同学问的"反过来该怎么理解"（就是 UV 和 ST 倒过来的那个问题），它跟微透镜阵列是完全一个道理，大家把它理解成复眼就没有问题；这一块回去通过光场相机那一节自行过一遍，应该不难。时间所限，接下来先说颜色——毕竟这边还有很多内容，如果顺利说完，再回头看看有没有时间多解释一下。

### 从牛顿的棱镜说起：颜色是混合出来的

颜色到底是什么？早期牛顿做过一个实验：一束白光穿过一个棱镜，会被分解成各种不同的颜色，形成彩虹一样的色带。这个实验其实还有后续：把这些已经分解开的颜色再合到一块儿去，又会形成白色。

也就是说，通过牛顿的这个实验我们发现：颜色本质上是一个混合出来的结果——它应该由很多不同的基本颜色混合而成，最后形成某一种颜色。这是怎么回事？这正是这一讲要研究的话题。

这个实验还顺带回答了一个"为什么"：光线为什么会被棱镜折射成不同的颜色？因为不同的波长对应不同的折射率。而给你任何一种光，它一定对应某一种光谱——所谓光谱，就是这个光线的能量在不同波长上的分布。这是最基本的物理知识。

光谱是一个很长的范围，但我们平常关心的、特别是图形学里关心的，是可见光的光谱：分布在波长约 400nm 到 700nm 之间，大概就是这么一个范围。在这个范围内我们可以看到，其他范围内看不到——那就是紫外线和红外线。

### 光谱与谱功率密度（SPD）

说到光谱，有一个稍微更准确一点的定义，叫谱功率密度（spectral power distribution，SPD）。说白了就是：这个光在不同波长上，强度分别是多少。之前定义辐射度量学的时候，我们一直没提波长的事情，提的都是"光本身会怎么样"；但其实不同的波长，它的表现是不一样的。有了 SPD，就可以描述光在任何一个波长上的分布是多少。

看两个例子。蓝天上某一个地方的 SPD：你会发现它更多的能量集中在高频那一端——小波长就意味着高频，这是同一个意思——所以看出来就是蓝颜色。阳光则是另外一种 SPD，形状完全不同。各种各样不同的光，自然对应各种各样不同的 SPD：日光和 LED 灯就不一样。要描述一个光线的强度在各个波长上的分布，就得引入这么一条曲线，这就是 SPD。

SPD 有一个性质：线性。非常简单，生活中就接触过。比如我有一种能记录光强度的东西，用某一种光照亮它，得到某一种分布；用另一种光照亮它，得到另一种分布；那两种光同时照亮它，得到的分布就是它们对应的两个 SPD 之和。想象一下开了很多盏灯，它就会越来越亮，对不对，就是这回事。

有同学问到这里的 SPD 是不是信号里定义的那个 SPD，以及这个可加性为什么会成立、跟干涉有没有关系——这个事情相对深入一些，我自己也没有考证过，就不再多回答了。差不多就是：大家发现了一个原理，然后咱们用它就好了。

### 颜色是人的感知

我们最终要回答的问题是"颜色"，而不是"光线的光谱"。先把结论放在这里：颜色其实是人的感知，它跟人有关，并不是物理上某种客观存在的东西；它和实际的光的分布并不一样。这听起来是不是有点玄？下面就来解释。

#### 人眼就是一台摄像机

既然颜色是感知，那人怎么感知的？那接下来要讲的东西可想而知——人的眼睛。人的眼睛就是一台摄像机：有瞳孔，瞳孔可调节大小，就是光圈；有晶状体，晶状体就是透镜，怎么调节焦距？靠肌肉来拽它，把它拽成各种不同的形状；而感知发生的地方在视网膜——贴在眼球内壁上的那一块，可以理解成图像。人眼希望看到的东西都呈现在视网膜上，就这么一个意思。

| 眼睛的结构 | 对应摄像机 |
| :--- | :--- |
| 瞳孔（大小可调） | 光圈 |
| 晶状体（靠肌肉牵引变形来调焦） | 透镜 |
| 视网膜 | 胶片 / 感光面 |

#### 棒状细胞、锥形细胞与三种锥形细胞

视网膜是光线最终到达的地方。为什么光线到了，你就知道自己看到东西了？因为视网膜上有感光细胞。把视网膜上的细胞可视化出来，内壁上有很多"跟毛一样"的东西，这些"毛"分成两个种类。

一种称作棒状细胞，看上去就是棒状的，可以用来感知光的强度，但是它不感知颜色——基本上只用这些棒状细胞，你就可以得到一幅灰度的图。另一种叫锥形细胞，数量少很多，但是可以用来感知颜色。所以为了研究颜色是怎么回事，我们应该去研究锥形细胞（关于具体的生物学译名，就简单这么翻译一下）。

有意思的是，锥形细胞内部又分成三种不同的锥形细胞。为什么这么分？因为三种细胞对三种类型的波长的响应各不相同：S 型细胞对小波长（也就是高频率）的光感知得更灵敏；M 型感知中间波长那一系列的光；L 型感知长波。描述"给它不同的光，它会有多强烈的反应"的，就是所谓的响应曲线（response curve）——它就是细胞的感知能力。

还有一件非常违背自然规律、但是千真万确的事情：不同的人眼睛里，这三种细胞的分布非常非常不一样。把 12 个不同的人眼睛里这三种锥形细胞的分布画出来（12 幅图对应 12 个人），一眼就能看出它们的分布绝对不一样，数量上也有严重的个体差异——比如左下角这个人，他有很多感知绿色的锥形细胞；右上角那个人，则有很多对红色更敏感的感知细胞。每个人之间差异非常大。这再次印证了那个结论：颜色是人感知的结果，这里就算是一个证明。

### 看到的不是光谱，而是三个数

现在把前面两件事拼起来。我们定义了光在不同波长上的分布（SPD），又知道某一种细胞对某一个波长的响应是多少，那么感知的结果是什么？把这两个函数对应位置相乘起来，再积分起来：给定某一个波长，我知道光线的强度是多少，乘上感知曲线在这个波长上的感应强度，把每一个波长都考虑进去——这可不就是最后的结果嘛。

记光谱为 $S(\lambda)$，三种锥形细胞的响应曲线为 $\bar s$、$\bar m$、$\bar l$，那么三个感知结果就是：

$$S=\int S(\lambda)\,\bar s(\lambda)\,\mathrm{d}\lambda,\qquad M=\int S(\lambda)\,\bar m(\lambda)\,\mathrm{d}\lambda,\qquad L=\int S(\lambda)\,\bar l(\lambda)\,\mathrm{d}\lambda$$

三种不同的细胞，自然就感应出三个结果，对应 S、M、L——这就是人们如何感知不同的颜色。

```text
        光源的 SPD：S(λ)
              │
              │  与三种锥形细胞的响应曲线
              │  逐波长相乘，再对波长积分
              ▼
        ( S , M , L )   ← 眼睛真正"看见"的，只有这三个数
              │
              ▼
        大脑："我看到了一个什么样的颜色"
```

读图说明：从上到下是感知链路——光谱经过眼睛反映到视网膜上，被三种不同的细胞感知成三个数，这三个数送到脑袋里，你就认为看到了某种颜色。

这立刻反映出一个问题：给定任何一种光线，它有什么样的 SPD 都没关系，通过"响应曲线 × 光谱再积分"这种计算方式，人们看到的是三个数。积分结束之后得到的结果就是一个数，光谱本身已经被积分掉了。你真正感知到的颜色，就是 S、M、L 这三个数，而绝对不是光线本身的 SPD。有同学反映"每个人眼中世界不一样"——确实就是这么回事，因为每个人眼睛里三种细胞的分布各不相同。这就是原理。

> **结论**：你看到的不是光谱，而是 S、M、L 三个数；光谱本身在积分里已经被"消耗"掉了，人们看不到光谱。

### 同色异谱：不同光谱，同一个颜色

大家自然会问这么一个问题：既然我们看到的不是光线的光谱，而是光谱和各种曲线积分出来的结果，那会不会有一种情况——两种光线，它们的光谱不相同，可是被我们看到的结果却是相同的？完全有可能。这种现象就叫做同色异谱：不同的信号进来，经过积分之后，得到三个数却是相同的。

而同色异谱现象非常重要：正是利用这个现象，我们才能够给人们呈现各种各样不同的颜色。这个过程就叫颜色匹配（color matching）：我想通过不同的调和方式，用各种各样不同的光谱，得到某一种颜色，使得这种颜色跟我看到的另外一种颜色一样——我并不需要两种光的光谱一样，我只需要它们的颜色一样，就这么一个意思。

实际测过一些例子：几束光的光谱（SPD）各不相同，通过那三条曲线积分之后，得到三个完全相同的结果——这就是同色异谱。它的一个重要应用是：一张照片拍了一个太阳，我希望在显示器上把这种东西显示出来，应该用什么样的颜色？我就可以通过不同的调节方式，使人看上去这两个颜色长得一样；至于混合出来的光谱和之前的光谱长得完全不一样，没有关系。

### 加色系统：计算机里的颜色混合

同色异谱意味着我们可以重新匹配任何一个颜色：用不同的颜色混合得到它。那么为了做混合，首先得说颜色应该如何混合。

在我们的计算机成像系统里，这种成像系统叫做加色系统。什么叫加色系统？很好理解：我有几种不同的所谓原色——以最常见的 RGB 三种颜色为例——让它们各自乘上某一个强度，然后混合起来，就可以得到一种颜色；我就用它们各自混合的系数（也就是强度），R、G、B 这三个数，来表示这种颜色。

为什么叫"加色"？在计算机里，如果把 R、G、B 三个值都调到 255（最高），得到的是什么颜色？白色。在真实世界里也是一样：把这些不同的光照到同一个位置上面，各个光混合了之后会变强——比如 RGB 三个颜色混合之后会变成白色。这和我们画画就不一样：调和各种各样不同的颜料，它会越调越黑，最后变黑，那种叫减色系统。我们这里用的都是加色系统。

加色系统就允许我们通过线性组合这些基本颜色，来匹配任何给定的颜色。

### 颜色匹配实验与负系数

怎么做？太简单了。给你任何一个颜色，我希望用三种不同的颜色混合匹配出相同的颜色。从上往下看这个实验：左边是给定的颜色，右边是我混合出来的颜色，只要把右边混合出来的颜色调得跟左边一样就可以。右边的每一种原色都有一个系数，就是它的强度。调着调着——诶，这时候不匹配；这还不匹配；诶，这时候匹配了——这就说明：用多强的第一种颜色、多强的第二种颜色、多强的第三种颜色混合起来，就可以得到左边的颜色。这部分自然实验就可以解决；对于任意一个颜色，我都可以通过类似的方法解决。

但是有一些情况很奇怪：左边这个颜色，右边怎么混都混不出来。怎么办？有人发现还可以这么做：往左边给定的、我需要匹配的颜色上，加一个颜色。左边加一个颜色，就相当于对应右边减去这个颜色——而右边减，顶多是减到零。这用的就是刚才 SPD 那个线性的性质。

所以说，通过几种不同的颜色混合得到一种颜色时，这几个系数其实可能是负的——没有问题，就可以理解成另外一边加上。

> **易错点**：负系数不代表存在"负强度的光"。实验上它对应"把这种颜色加到待匹配的那一侧"，数学上才等价于另一侧取负。

### CIE RGB 与颜色匹配函数

通过这种方式，人们就发明了一个所谓 CIE RGB 的系统——这就渐渐开始有点像我们正常用颜色空间去表示了。CIE 是一个组织（这个名字是法语的，不是英语），他们定义了这套 RGB 系统。它要干什么？做颜色的匹配。

给你的任何一个颜色，是单波长的颜色——某种激光。它的 SPD 不是一般的 SPD，而是一个单一的、所谓的 delta 函数（你就可以理解成某一种曲线，没有什么关系）。用来匹配的三种原色也是单色光，它们在频谱上的分布非常非常集中，几乎就在同一个波长上。目标颜色和这三种基础颜色各自是什么样的 SPD 我们都不用管，只需要考虑：如何用这三种光，混合出某一个波长上对应的那个颜色。

于是他们对每一个波长都做了实验，把结果画成三条曲线。读图的方法是：这幅图跟响应函数没关系，它是在做颜色匹配——对每一个波长取一根竖线，比如取在 450nm 处，这就是我要匹配的颜色；匹配它需要这么多的蓝色、这么多的绿色，和这么多负的红色，把它们混合起来，得到这个颜色。对每一个波长、每一个不同的颜色都做一遍实验，就可以测出这么一个形状——这就叫颜色匹配函数：对于不同的波长，我需要用多少的这些原始的光，组合起来。

做完会发现确实有负的：红色那条曲线很明显有一块是负的，其他地方看起来比较正常。负的没关系，刚才说过，肯定是可以的。

有了匹配函数，如果现在给你任何一种实际的光的光谱，需要多少 R、多少 G、多少 B？那就把每一个波长上需要多少红、绿、蓝都考虑进去，自然而然就是另外一个积分，积出来三个数：

$$R=\int S(\lambda)\,\bar r(\lambda)\,\mathrm{d}\lambda,\qquad G=\int S(\lambda)\,\bar g(\lambda)\,\mathrm{d}\lambda,\qquad B=\int S(\lambda)\,\bar b(\lambda)\,\mathrm{d}\lambda$$

这三条匹配曲线分别告诉你这三个数。这个形式和之前"感知"那个积分形式非常像，但是它们的意思并不一样，这个要理解清楚。

> **易错点**：锥形细胞响应的积分和颜色匹配的积分形式相同、含义不同：前者回答"人感觉到了什么"，后者回答"要用多少 R/G/B 才能匹配出它"。

不管怎么样：给你任何一个颜色，你都可以用这么多红、这么多绿、这么多蓝来表示，这就是我们的 RGB 系统——通过 RGB 不同的调和，我们可以调出各种各样实际的颜色。这就是颜色匹配函数的一个应用。

### sRGB 与 CIE XYZ

RGB 是一个广泛使用的标准系统，不过它的名字其实应该叫标准 RGB（standard RGB），也就是 sRGB——这应该是更正规的名字。sRGB 广泛应用于各种各样的成像设备，比如我们电脑的显示器。它是怎么做的：先找某一台机器，把它的 RGB 做好之后，行，后来的制造就按照这台机器的方法来制造，就是这么个意思。

sRGB 用了很多，但是 RGB 这个颜色空间所能形成的色域是有限的——这都是什么意思，马上就说。

在说色域之前，先说另外一个系统。这个系统虽然咱们不常用，但在科学上应用更广泛，叫 CIE XYZ——还是那个组织。XYZ 系统同样定义颜色匹配函数，但它和 RGB 系统是反过来的：它不是实验测出来的颜色匹配系统，而是人造的一套——自己先定义好这几种不同的曲线，它是虚拟的，不存在。这些曲线告诉你的事情还是一样：对任何一个波长，比如还是看 450nm，需要很少的 Y、稍微多一点的 X、很多的 Z，就这么一个意思。

由于它的设计——覆盖正常地从 400 到 700（左边稍微多那么一点点，问题不大），分布又挺对称——用这三条小写 x、y、z 颜色匹配函数匹配出来的颜色，其大写 Y 这个数（类似于 RGB 里 G 那个数）一定程度上就可以表示这个颜色的亮度。再看设计细节：X 这条"红色"曲线其实有两个峰值，但是它没有负数；所有这些函数都覆盖在整个可见光的范围内。

X、Y、Z 对应三种不同的匹配函数，我们可以用这三个数来表示某种颜色；特别的，大写 Y 本身表示的就是亮度。它跟 RGB 的区别，仅仅在于匹配函数的问题。

### 可视化 XYZ：色域

有人问：能不能把 XYZ 系统能表示的所有颜色都显示出来？这是一个好想法。但大写 X、Y、Z 本身是三维的，可视化一个三维的东西不好办。怎么办？只显示其中两维。

第一步，对任何大写 X、Y、Z 先做归一化。注意这里的归一化是让三个数加起来等于 1——跟之前做向量归一化不一样，那次是平方加起来等于 1，这次就是直接相加：

$$x=\frac{X}{X+Y+Z},\qquad y=\frac{Y}{X+Y+Z},\qquad z=\frac{Z}{X+Y+Z}$$

归一化之后得到三个小写的 x、y、z，加起来等于 1，所以我只需要显示前面两个维度——x 和 y——就可以了，z 是多少自然知道。显示的时候，小写 x 放在水平轴，小写 y 放在竖直轴。

但小写 x、y 归根结底还是由大写 X、Y、Z 三个数决定的——颜色其实还是三个变量，怎么办？既然大写 Y 表示的是亮度，那我就把亮度固定成某一个数（把 Y 当作常数来看），让大写 X 和 Z 发生变化；这样小写 x 和 y 就都是大写 X 和 Z 的函数，就可以做这么一个可视化。这么显示是有道理的：你改变大写 Y，其实也只不过改变亮度而已，还是可以一目了然地看清楚各种各样不同的颜色。

显示出来是一个扇面形的形状，有一条边界。大家看到的东西就叫做色域（gamut）。

> **定义**：色域就是"一个颜色空间可以表示的所有颜色"，也就是刚才那个形状围起来的这一块。

从这张图上可以看出很多事情。中心这个地方是白色的颜色：白色是由各种各样的颜色混合起来的，所以我们说白色是最不纯的颜色——一定记得我们用的是加色系统，白色是混合得最多的、最不纯的。而纯的颜色都在哪儿？都在这个形状的边界上，那是最纯的、单色的这么一种感觉。

有同学会问：难道不同的颜色空间，表示颜色的范围是不一样的吗？答案是确实如此。看色域这张图就看得出来：sRGB 仅仅能够表示里面一个很小的三角形，表示不了 XYZ 这么大的色域；也有各种各样神奇的其他颜色空间，它们能够表示的颜色也各不相同。

### HSV：给艺术家准备的拾色器

还有其他各种各样不同的空间。对 Photoshop 比较熟的同学肯定会知道一个颜色空间叫 HSV；就算你没听说过，在生活中也肯定已经广泛使用过了——就是所谓颜色拾取器（color picker），就这么个东西。

它允许你选各种各样不同的色调（hue），然后选各种各样不同的饱和度（saturation），还有一个 brightness，有时候叫 value（所以叫 HSV）；也有人叫 HSL，那个 L 是 lightness，其实就是 HSV，问题不大。

| 分量 | 名字 | 直观理解 |
| :--- | :--- | :--- |
| H | 色调（hue） | 不同类型的颜色：要红色、蓝色，还是要什么颜色 |
| S | 饱和度（saturation） | 更接近白色，还是更接近颜色本身的纯色 |
| V | 明度（value / brightness） | 从黑色一直到某种颜色 |

HSV 是给艺术家们定义的，非常好理解，从色条上看清清楚楚：色调就是不同类型的颜色，什么红色、蓝色，要什么颜色；饱和度说的是更接近白色、还是更接近颜色本身的纯色——之前不是说了吗，白色算是最不纯的，颜色本身算是最纯的，越饱和就越接近单一颜色，越不饱和就意味着越接近混合出来的白色；value 最好理解，就是亮度，从黑色一直到某种颜色。主要就是：通过色调选不同的颜色，通过饱和度决定偏白还是偏颜色，通过亮度决定偏黑还是偏颜色。所以它适合艺术家去调，选某种颜色很方便。

### Lab 空间：建立在互补色上的感知空间

还有一种空间也是 CIE 的——大家会发现 CIE 在颜色界是有统治地位的——叫 Lab 空间，跟实验室没关系。Lab 也是一个跟感知有关的空间：刚才 HSV 跟感知有关，是因为一目了然可以看到什么颜色；Lab 的"感知"，体现在它的轴是怎么安排的。

它有三个轴：一个 L 轴，一个 a 轴（负 a 到正 a），一个和它垂直的 b 轴（负 b 到正 b）。L 永远是最简单的，表示的都是亮度：0 就是黑，100 就是白。a 轴表示的是红和绿这两个颜色，b 轴表示的是蓝和黄。

关键在于：在 Lab 这个空间内，任何一个轴上表示的颜色，它的极限两端都是互补色。什么叫互补色？白色的"反义词"是黑色——白跟黑互补，这好理解；不好理解的是：红色凭什么跟绿色互补？黄色为什么跟蓝色（紫色）这些是互补的？这些是根据实验得到的事情——人的大脑对这些互补色本身是有一个定义的，我们马上就会看到。

从什么地方可以看出来？你平常会想到浅色的绿、深绿，黄绿、蓝绿，这些都好想；可是大家绝对不会想到有一种"偏红的绿色"——这个很困难。为什么？因为红色跟绿色差得太远了，它们两个完全成了一对互补色。这跟人脑有关系，就这么一个意思。

### 视觉暂留实验：人脑会自动补上互补色

可以从一个非常简单的例子，通过人眼的视觉暂留来验证这么一个互补色。视觉暂留的意思是：你看一幅图，看时间长了之后突然切换到另一幅图，你会看到这幅图的互补色。

第一个实验：先显示一幅完全是互补色的图，大家盯着中心那个点看——中间有个点——看个十秒钟，然后切换到下面一幅图上来。怎么样，有没有看到？应该是没有问题的。这就是说，人脑会自动地把互补色给补上，就这么一个道理。

第二个例子：忍者神龟。第一幅图的忍者神龟显然也是用互补色画的；下一幅图显示的是一个灰度的忍者神龟。这是为了干什么？大家可以想象：一开始先看第一张图，看了之后会看到它的互补色，并且你同时又会看到灰度图——所以相当于是把互补色加到了灰度图上。我们知道，偏红的颜色过来之后就正好是偏绿，而忍者神龟本来就是绿的。盯着中间这个点开始计时，数到十——怎么样？我是看到了，哈哈，还是不错的。

不管怎么样，人脑自动是可以达到互补色的效果的。互补色有道理，这就说明刚才的 Lab 空间有道理：它有三对轴，一个轴上两个端点完全互补，这么个意思。

### 颜色是相对的：两个例子

颜色还有很多很神奇的东西：颜色很多都是相对的。回到那句话——颜色本身是感知。你看到的颜色到底有多强，是你自己觉得是这么回事，它和实际情况可能有相悖的效果。

第一个例子，棋盘阴影。一张非常简单的渲染图：地板上有棋盘格，有一个 A，有一个 B。问题非常简单：A 和 B 哪一个更亮？大家会觉得这个问题太简单了——A 显然更暗，A 非常暗，是深灰色；B 是浅灰色。本来就是这么回事嘛。但事实上并不是这么回事。把左边挡住，再把右边挡住，A 还是比 B 要暗；那再把上面挡住、下面挡住，再把中间（圆柱）消掉，只盯着 A 和 B 看——大家会发现：A 和 B 其实颜色一模一样。所以从原来那幅图直接切换到这幅图，你会看到 A 跟 B 绝对是一样的颜色。

第二个例子，同样的道理。两个黄色的叉，哪一个更亮？大家会觉得左边这个黄色的叉显然要比右边这个黄色的叉亮。但如果简单地做一个水平的、纯色的条，把这两个连接起来，就会发现：两个颜色其实完全一样。

这就说明：整个颜色完全是一个人脑感知的道理——咱们又回到之前所说的"颜色是感知"这么一个事情上来。

### 减色系统与 CMYK

最后还有一件事没说：减色系统。它在生活中应用得更加广泛——各种各样的印刷、打印这些事情，用的都是减色系统。减色系统是什么意思？给你不同的颜色，混合在一块儿，会越混越黑。

一个典型的减色系统叫做 CMYK 系统：C 是蓝绿色（cyan），M 是品红色（magenta），Y 是黄颜色（yellow），K 是黑色。为什么用这套系统？因为 C、M、Y 可以通过混合得到各种各样不同的颜色——打印上，我通过混合各种各样不同的墨水，越混越黑，可以调出各种各样不同的颜色。这现在肯定很好理解。

那我问这么一个问题：混合 C、M、Y 本来就可以得到 K（黑色），那我为什么还要黑色？为什么这套系统不叫 CM 系统，为什么叫 CMYK，为什么它一定要带上这个黑色自己？我觉得大家完全可以回答这个问题。我直接告诉大家：这是因为印刷上是要考虑成本的——这是一个实际的系统。正常情况下，打印有很多东西本来就应该以黑色居多，黑色会得到很广泛的应用；而黑色这个墨水好造、便宜，C、M、Y 这三种带颜色的墨水不容易造——用它们混合出来得到黑色就很亏，成本非常高。所以平常带上一格黑色，需要用黑的直接用，省得浪费彩色墨水。这就是便宜，就这么一个道理。

| | 加色系统 | 减色系统 |
| :--- | :--- | :--- |
| 混合的对象 | 光 | 颜料、墨水 |
| 混合的结果 | 越混越亮；RGB 全开是白色 | 越混越黑，最后变黑 |
| 典型场景 | 计算机成像、显示器 | 画画、印刷、打印 |

### 没来得及讲的，与几个问答

今天的内容基本上就是这样。最后回答了几个问题，挑有内容的说一下。

大作业框架需要自己写吗？可以自己写，也可以去拿别人的，问题不大；用别人的记得写清楚，比如在文档里写一写用到了谁的东西就好。

有两块东西这门课没有提。一个是 HDR（high dynamic range，高动态范围图像）：颜色亮过了白色，还能不能更亮？像这种东西没有提。另一个是伽马校正。之前做 path tracing 的时候问过这么一个问题：你算出来的最后是 pixel radiance，radiance 最后要变成颜色，是不是简单做一个线性的变换就可以得到？并不是——因为你本身的颜色显示在显示器上，它是非线性的，你必须先把它校正过来，使得这两部分非线性抵消了之后还是线性。这个部分叫做伽马校正，不过我们也没有提，基本上来说不提应该问题不大。

还有几个问答。怎么发现、造一个新的颜色空间？挺难的，这个我并不知道。一个典型的想法是：你造了之后得有人用，它得有自己独特的性质——比如 XYZ 理论性质非常好、色域非常大；RGB 好用，平常红绿蓝很直观；HSV 比较好调颜色，随便选颜色比较容易。做这种东西需要考虑很多，当然，你也可以造一个虚拟的，就像 XYZ 一样。D65、D50 这些就不再多提了：仅仅相当于有不同的光源，D65 是某一种灯，具有某一种特定的光谱性质，仅此而已。sRGB 广泛应用是因为什么？好问题，我还真不知道，只知道大家都在广泛应用这个东西。
