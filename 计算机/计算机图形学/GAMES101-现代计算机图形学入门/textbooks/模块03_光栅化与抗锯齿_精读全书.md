## 光栅化：把三角形画到屏幕上
> 对应块：BLK06 | 覆盖分集：P05 | 块标题（分集名）：《Lecture 05 Rasterization》

### 从变换到光栅化：这节课要解决什么

不知道大家有没有注意过，这门课每一页 PPT 的封面上都有同样四张图，课程主页上放的也是这四张——它们分别对应这门课要讲的四个主要部分。咱们现在进入的第一块，就是左下角那两辆汽车加阴影的图：光栅化成像，也就是各种实时应用生成图像时所着重使用的方法。前几节课我们花了点时间把变换讲完，变换是基础；应用这些变换，最终就能把三维中的场景画到屏幕上。从这节课开始，就说这个事情——今天讲三角形的光栅化。先说一句：相比上节课，这节课太简单了，我相信大家听下来一定都能听明白。

简单回顾上节课的内容。视图变换利用的是相机和物体之间的相对运动关系：把相机从任意位置移到一个"经典位置"——原点、看向 $-z$、向上方向为 $y$——其他所有物体都和相机一样移动。这样，把模型变换、视图变换都应用在所有模型上之后，所有物体就都处于标准位置的相机注视之下；接下来要把它们投影成一张"照片"，从三维投影到二维。投影有两类：正交投影直接忽略深度信息，可以理解成相机放在无限远；透视投影则可以达到近大远小的效果。我们还着重推导了正交投影矩阵，以及透视投影如何先变换成正交投影、再投影过去。

站高一层来看：无论哪种投影，做完 MVP（model、view、projection）之后，场景里所有的物体都会被变到 $[-1,1]^3$ 这个经典立方体里。那下一步是什么？下一步就是把这个立方体画在屏幕上——这一步就叫光栅化（Rasterization）。这就是今天的主题；如果时间富余，再往前赶一点，把下节课的遮挡与可见性也说一说，因为下节课内容相对比较多。

### 用垂直可视角度和宽高比定义视锥

先把上节课的收尾补齐。正交投影如何定义三维空间中的一个长方体？用 $x$ 轴的覆盖（左和右）、$y$ 轴的覆盖（下和上）、$z$ 轴的覆盖（远和近）这六个数。透视投影要做的，是把一个视锥（frustum）——就是那个近大远小的形状——变成一个长方体。其中远和近这两个数，用透视投影和正交投影表示都是一样的，$n$ 和 $f$ 认为已知、不用管。那剩下的部分——这个视锥——怎么定义？

引入两个新概念。第一个是宽高比（aspect ratio），就是宽度除以高度。说一块屏幕是 4:3 的——早期的屏幕，或者现在的 iPad——或者说 16:9，指的就是这个信息；摄像机摆好、往一个方向看，它试图看到的那个区域的宽高比，我们就把它定下来。第二个是可视角度（field of view），表示你可以看到的角度范围：从相机连出两条线，分别连到近平面上边的中点和下边的中点，这两条线所夹的角度，就叫垂直可视角度（fovY）。

这两个量和相机的直觉对得上。拍近距离的物体要用广角相机——所谓广角，就是可视角度比较大，反映在视锥上就是它张得比较开，一开始从零迅速就可以张到一个非常大的范围；垂直可视角度比较小，相当于开口比较小，透视投影的效果就越不明显、越像正交投影，但这样一来你可以很容易地拍到远处的物体。

顺带一提，打游戏时经常涉及到的是水平可视角度——两者可以相互转化：知道宽高比和垂直可视角度，自然可以推出水平可视角度，也就是从相机连两根线、分别连向左边和右边的中点所形成的角度。

有了这两个概念，就可以把它们转化到之前定义正交投影长方体的那套概念上。从侧面看过去，相机的视野是一个三角形：相机往 $-z$ 方向看，到近平面的距离是 $|n|$；垂直可视角度是上下两条边线的总夹角，所以这个三角形张开的半角是 $fovY/2$。三角函数关系立刻就出来了。

```text
             y = +t
              |
             /|
            / |
           /  |
          /   |          近平面到相机的距离 = |n|
  camera -+---+-------->  视线方向
          \   |
           \  |
            \ |
             \|
              |
             y = -t
```

读图：右侧竖线段是近平面，上下端点分别为 $y=+t$ 与 $y=-t$；斜线与水平视线方向的夹角即半角 $fovY/2$。

$$\tan\frac{fovY}{2} = \frac{t}{|n|}$$

知道可视角度，自然就知道近平面高度的一半，也就是 top 是多少：近平面最高点对应的 $y$ 值就是算出来的 $t$，最低点对应的 $y$ 就是 $-t$，所以 $b = -t$。水平方向同理：知道高度 $t$ 和宽高比，水平方向的宽度就是 $t$ 乘以宽高比，也就是 $r = \text{aspect}\cdot t$、$l = -r$。这些概念都是可以相互转化的。

所以正常情况下，定义一个视锥很简单：只需要定义一个垂直的可视角度、一个宽高比，其他的这些都可以自动转化到我们定义正交投影的"远近左右上下"那几个概念上去。

> **结论**：定义视锥只需要两个量——垂直可视角度 fovY 与宽高比 aspect；$l,r,b,t$ 全部可以从它们和 $|n|$ 推出来。

### 屏幕：像素阵列与光栅成像

下一步要把东西画在屏幕上，那得先把"屏幕"这个概念定义好。对图形学来说，屏幕被抽象地认为是一个二维数组，数组中的每一个元素是一个像素。这其实好理解：大家都说屏幕分辨率是多少——比如 1920×1080，就表示有这么多个像素，并且这么多像素形成了一个二维数组。1280×720 我们管它叫 720p，1920×1080 叫 1080p，当然还有更高的 2K、4K——这些表示的都是像素的多少，也就是分辨率。

屏幕是一种典型的光栅成像设备。Raster 这个词来自德语，意思就是屏幕。所以"光栅化"（Rasterization）是什么意思呢？就是把东西画在屏幕上——把名词变成动词，这个过程就叫光栅化，以后我们就这么说。

> **定义**：光栅化（Rasterization）＝ 把东西画在屏幕上的过程。

多提一句像素。像素的名字来自 picture element，缩写成 pixel。像素其实挺复杂的，但在这门课里，我们把它认为是一个一个的小方块，每一个方块内部的颜色都不会有变化——要么整个方块是红色，要么整个方块是完全相同的白色或者黑色——就是说像素已经是最小的单位了，里面不会有任何的变化。当然这是不对的哈，到课程最后大家就会看到，像素远远比这要复杂；但作为一个抽象，咱们这么理解没有问题。

一个像素可以表示不同的颜色。如果认为它表示灰度——从黑到白——可以划分成若干等级，正常情况下大家把它划分成 256 个等级：等级 0 完全是黑的，等级 255 完全是白的。同样道理，也可以用三个不同的数字，分别表示红、绿、蓝三种颜色的强度等级，组合在一块就可以形成各种各样不同的颜色。所以我们认为一个像素内的颜色都可以用 RGB 三个值来表示，并且一个像素内颜色不会发生任何差异。

### 屏幕空间：给像素建坐标系

接下来把屏幕的空间定义一下。所谓屏幕空间，就是在屏幕上建立一个坐标系。大家如果看虎书，它自己有一套定义方案；咱们也有自己的一套：假设屏幕的左下角是原点——屏幕空间的原点——向右是 $x$，向上是 $y$。这样，屏幕中间任何一个点都可以用 $(x,y)$ 来表示。

有几条规定。这些规定是平常这么用、约定俗成的，并没有什么特殊的意义。首先，像素的坐标（或者说下标、index）都写成 $(x,y)$ 的形式，用整数来描述；一块宽 width、高 height 的屏幕，所有像素从 $(0,0)$ 一直到 $(\text{width}-1,\ \text{height}-1)$——从零开始数，宽度自然就是 width 个像素，高度也是一样。

其次，虽然我们用整数坐标描述像素，但像素的中心不在整数点上：坐标为 $(2,1)$ 的像素，实际的中心在 $(2.5, 1.5)$。对任何一个像素来说，它的中心都准确地落在 $(x+0.5,\ y+0.5)$ 上。既然每个像素在 $x$、$y$ 上都覆盖宽度 1，那整个屏幕覆盖的范围就是从 $(0,0)$ 到 $(\text{width},\ \text{height})$。这么一定义，屏幕空间就非常清楚了。

```text
  y
  ^
3 +---+---+---+---+
  |   |   |   |   |
2 +---+---+---+---+
  |   |   | o |   |      o = 像素 (2,1) 的中心，在 (2.5, 1.5)
1 +---+---+---+---+
  |   |   |   |   |
0 +---+---+---+---+---> x
  0   1   2   3   4
```

读图：方格是一个个像素，原点在左下角；标出的像素整数坐标是 $(2,1)$，覆盖 $x\in[2,3]$、$y\in[1,2]$，中心在 $(2.5,1.5)$。

> **易错点**：像素 $(x,y)$ 用整数编号，但它的中心在 $(x+0.5,\ y+0.5)$——后面整个采样过程都建立在这半格偏移上。

### 视口变换：从标准正方形到整个屏幕

屏幕空间清楚了，现在要干什么？还记得吗——我们手里有一个 $[-1,1]^3$ 的立方体，要把它转化到屏幕上，也就是做一个从 $[-1,1]^3$ 到 $[0,\text{width}]\times[0,\text{height}]$ 的变换。

这里有个小问题：立方体是三维的，还有一个 $z$ 呢？很简单，暂时先不管它——$z$ 自然而然之后有它的用途，很快就会说到。只盯着 $x$ 和 $y$ 看：原本 $[-1,1]^2$ 占据一个边长为 2 的正方形，要把它拉到 $[0,\text{width}]\times[0,\text{height}]$，分两步。

第一步是缩放。$[-1,1]$ 的宽度是 2、高度也是 2，把宽度和高度都先除以 2、再乘以对应的 width 或 height，这个正方形就变成屏幕大小了。第二步是平移。缩放完之后，中心还停在原点；但屏幕空间的原点定义在左下角——比如一块 4×3 的屏幕，它的中心应该落在 $(\text{width}/2,\ \text{height}/2)$ 那个位置——所以要把中心从 $(0,0)$ 平移过去。

这两步可以合并成一个简单的变换，称为视口变换（viewport transform）：把 $[-1,1]^2$ 变成整个屏幕空间。

$$M_{\text{viewport}}=\begin{pmatrix}\dfrac{w}{2}&0&0&\dfrac{w}{2}\\ 0&\dfrac{h}{2}&0&\dfrac{h}{2}\\ 0&0&1&0\\ 0&0&0&1\end{pmatrix}$$

其中 $w$、$h$ 分别是屏幕的宽和高。矩阵左上角的 3×3 是个对角阵：宽度方向乘 $w/2$、高度方向乘 $h/2$；$z$ 方向那一项写的是 1——$z$ 确实没有经过任何改变。

做完视口变换，之前不管你是用宽高比加可视角度定义的视锥，还是用三组对边位置定义的正交投影长方体，反正都已经变到 $[-1,1]^3$，现在又把 $x,y$ 变到了屏幕上。也就是说，我们已经可以得到一张二维的、场景的"虚拟照片"了。

### 光栅化：把多边形打散成像素

但先别急。别忘了，这个结果仍然是空间中描述的一堆三角形的信息；我们要把它变成真正的图，也就是说要把它打散成像素。

看一个例子。《少年派的奇幻漂流》里那只老虎是假的，但做得栩栩如生——这就是图形学的贡献。老虎身上有各种各样的多边形，这些多边形经过变换、经过各种操作，会形成屏幕空间中的多边形；但这还不够，还要把多边形进一步打碎，打成像素，显示在一个个像素上——告诉我每一个像素的值都应该是什么。这一步过程，就是我们所说的光栅化：把屏幕空间中的多边形真正画在屏幕上。

顺带一说，能拿来"绘画"的机器可不只是屏幕。有一类类似机械臂的结构，绑上一支笔，按照编程好的位置控制它的移动，可以真实地在任何地方画画；制造过程中用激光切割金属，相当于在金属上面进行绘制，这些也都是控制好的。咱们在屏幕上画，是同一个道理。在介绍屏幕上绘制之前，先看看各种不同的光栅显示设备都是什么东西。

### 显示设备巡礼：从示波器到电子墨水屏

#### 示波器与阴极射线管

最简单、也非常常见的一类光栅显示设备是示波器——做过物理实验的话应该都见过，上面可以形成各种各样不同的曲线，正常情况下都是绿的。这东西很神奇。有一段挺有名的演示，就是在试图用示波器画一个蘑菇：用到各种各样的正弦波和余弦波，还把声音作为一种噪声的输入（那个噪音是真的）。演示里是这么说的：先在水平偏转通道上放一个正弦波，再在垂直偏转通道上放一个余弦波，两者加起来，就是一个漂亮的圆。

示波器本身当然是一个成像设备，它的成像原理和早期显示器的成像原理一模一样：阴极射线管（cathode ray tube，CRT）。电子发射端产生很多电子，穿过显示设备时发生偏转、偏到不同的位置上，打在屏幕的某一个位置。如果这个过程进行得足够快，你就不会看到一个个电子打上去，而是看到它们连成的形状；每个点都可以这么操作，看过去自然就是一整块屏幕。这就是非常早期的屏幕，CRT 屏幕就是阴极射线管的缩写叫法。这屏幕非常伤眼睛——很多电子打过来，示波器基本一个原理，大概就是这么个道理。

#### 逐行扫描与隔行扫描

早期的电视也好、电脑显示器也好，是怎么把一个一个的点打在屏幕上、形成一整张完整的画的？靠所谓扫描：可以控制电子打在哪一个位置——从屏幕左上角开始画一道线，换一行再画一道线，都是水平线；从上往下一直画过来，这些线画得足够密集，基本就可以覆盖整个屏幕。

人们是很聪明的，当然也很懒的——懒惰是进步之源。为了画得快一点，人们发现：对每一张图，其实可以只画一半。什么叫画一半？隔一行画一条线。当前这幅图（当前这个时刻）画第一、三、五、七行这些奇数行；到了下一个时刻、下一张图，再画第二、四、六、八行这些偶数行。这个技术就叫做隔行扫描。

好处很简单：画每一张图的工作量都减少了一半。那放在一块儿看呢？人眼本身能够感知动画，是因为人眼有一定的视觉暂留效应——每两幅画之间相隔的时间非常短，短暂的视觉会停留在之前画过的东西上，所以每一次看到的其实都相当于一幅完整的画面，也不会发现中间其实缺了行。这是一个聪明的做法。隔行扫描的思想直到现在还在一些视频压缩里起作用：相隔的两帧之间，这一帧只记录奇数行，下一帧只记录偶数行，放的时候反正大家看不到。当然这里还是有一个问题：隔行扫描会造成严重的画面撕裂，特别是高速运动的画面——比如体育比赛，人物移动的时候会发生交叉的鬼影现象。

#### 显存与帧缓冲

现在的显示设备，我们只需要知道它们的原理就可以了：给我一个显示器，我怎么知道它要显示什么？答案是内存中的一块区域——显卡里的内存我们管它叫显存。把这块区域映射到屏幕上，这就是现在屏幕显示的方式。之后还会讲到：可以生成不同的图像、存在显存中的不同区域，然后告诉显示器到底显示哪一幅图。总之这里大家明白一件事就好：显示的图像其实就是内存中的一块区域。

顺便补充一个冷知识：红白机上那个国内俗称"小蜜蜂"的游戏，其实有真名，叫 Space Invaders，太空侵略者。

#### 液晶显示器（LCD）

现在大家都在什么样的设备上显示？主流是平板显示设备，主要是 LCD。两个例子可以感受一下分辨率的两端：计算器是一个超级低分辨率的 LCD 显示器，可以看到一个一个的格子；手机则是非常高分辨率的显示器。现在人们还发明了分辨率更高的显示设备，高到什么地步？高到屏幕的分辨率已经超出了人的视网膜的分辨率——这种屏幕我们就管它叫视网膜屏幕。除了 LCD，还有 OLED 等各种各样不同的显示设备，这里着重说 LCD。

LCD 就是液晶显示器，顾名思义，它利用液晶的原理来控制一个像素到底显示什么。它的结构里，一个像素有两组以不同方向排布的偏振光栅（偏振片）。理解它需要一点大学物理里的光学知识——光是有波动性的；光经过一个偏振片，只会留下在偏振片所规定方向上振动的那些能量，也就是说，通过偏振片之后，光的振动方向就和偏振片的方向一致了。

想象一下：光先通过右边这张竖直的偏振片，自然只剩下竖直的振动；它再想通过左边那张水平的偏振片——竖直的振动过水平偏振片，那可就什么都没有了。那怎么让光过去？液晶显示的原理，就是通过液晶的扭曲，把光的振动方向渐渐地调过来：光通过右边的偏振片之后仍然是竖直的，经过液晶的扭曲被扭成了水平的，然后它就可以从水平的偏振片出去了——这就是为什么你能看到这个像素在发光。这当然需要知道一些光的波动性，不难。

#### LED 与电子墨水屏

还有一种广泛使用的显示设备叫 LED，缩写完全不同：light emitting diode，发光二极管。发光二极管很好理解：要么发光，要么不发光。一块板由各种各样不同的发光二极管阵列构成，有一些可以发蓝光、有一些可以发红光，颜色都是预先定义好的——这就是 LED 显示设备。

还有一种显示设备，买过电子墨水屏（比如亚马逊的 Kindle）的就会知道：它里面有黑色和白色两种墨水，经过不同的通电电压或者模式，它可以发生翻转——黑的在上面还是白的在上面。通过控制这些不同的像素到底黑的还是白的在上面，就可以控制你到底看得见看不见字。这就是电子墨水屏的原理。当然它有一个严重的问题：刷新率很低——要改变一次每个像素黑色和白色的朝向，它要花一定的时间，而且是肉眼可见的时间。这就是为什么用 Kindle 会发现翻页非常的慢：它得刷新一遍；用它看动画更是不可能。当然它的好处就是看起来非常自然。

| 设备 | 成像原理 | 特点与短板 |
| :--- | :--- | :--- |
| CRT 阴极射线管 | 电子束偏转后打在屏幕上，足够快就连成图像 | 早期电视与显示器，非常伤眼睛 |
| LCD 液晶 | 液晶扭曲光的偏振方向，决定光能否穿过两组偏振片 | 现在的主流平板显示设备 |
| LED | 发光二极管阵列，亮或不亮，颜色预先定义 | 结构直观 |
| 电子墨水屏 | 电压翻转黑白墨水的朝向 | 看着自然，但刷新率低、翻页慢、看不了动画 |

### 为什么用三角形

好，回到课题上来：怎么样在这些成像设备上面画东西。还是那个假设——屏幕上由各种各样不同的像素构成，每一个像素是一个内部颜色不会发生变化的小方块。从这里开始，我们已经知道怎么把三维空间中的一系列多边形（或者多边形的顶点）变换到屏幕空间上去了，下一步就是把多边形实际拆成不同的像素。

刚才看到的老虎是靠不同的四边形组成的，我们现在的例子是靠三角形组成的。三角形当然可以表示三维空间中的形状，同样也可以表示二维空间中的图形——一个很复杂的图形，其实也是由很多不同的三角形构成的。也就是说，三角形的表示能力其实很强。这就是为什么我们认为三角形会在图形学中得到广泛应用：它有很多不错的性质。

- **最基础的多边形**。没有比三角形边更少的多边形了，再少就退化成线段了；而任何其他多边形，都可以拆成三角形。三角形算是所有多边形中的基础。
- **内部一定是平面的**。给定三个点连成三角形，它一定得是平面的。四边形就不行：沿着它的某一条对角线一折，这个四边形就不再是平面的了；三角形不可能这样，除非你把它折成两个三角形。
- **内外定义得非常清晰**。多边形会带来各种神奇的问题：里面有洞怎么办？不是凸多边形怎么办？三角形不存在这些问题；而且可以通过向量的叉积，判断一个点是不是在三角形内——这节课很快就要用到这个知识。
- **顶点属性可以在内部渐变**。只要定义三角形三个顶点各自的属性，那么在形成的三角形内部，就可以根据任何一个点与三个顶点的位置关系，把这个点的属性"猜"出来，得到从三角形一个顶点到另一个顶点的逐渐变化——这就是之后要讲的重心坐标插值方法。

三角形优势很大，那咱们现在就盯着三角形来看。空间中的三角形——不管原来 $x,y,z$ 是什么——经过一系列变换：MVP 变换做完，再经过视口变换，只看它的 $x$ 和 $y$，我们就能拿到每一个顶点在屏幕空间下的坐标。顺带说明：有些示意图把坐标原点放在左上角，那并不是我们定义的屏幕空间，但这没有关系。

现在要把这个三角形变成真正的像素。麻烦来了：一个像素内部不可能有颜色变化。那一个正好被三角形盖住大概一半的像素，到底应该怎么算——它到底是亮还是不亮？三角形内部的这些像素自然应该全红，像这些判断应当如何去做？这就是光栅化中最重要的一个概念：判断一个像素和三角形的位置关系——更确切地说，我们考虑像素的中心点与三角形的位置关系。

### 采样：把函数离散化

这里给大家介绍做光栅化最简单的做法：通过采样的方法。

采样是什么概念？给你一个连续的函数，我在不同的地方去问：这个函数的值是多少？这就是采样，很简单嘛。比如说 $f(x)=\sin x$，我给 $x=1$、$x=2$、$x=3$、一直到 $x=100$，问这些点上对应的 $f(x)$ 都是多少。稍微正规一点的定义：采样其实就是把一个函数给离散化的过程。

采样是图形学里非常重要的概念，我们会涉及到各种不同的采样。咱们这里说的采样，是利用像素的中心对屏幕空间进行采样：屏幕空间定义是 $[0,\text{width}]\times[0,\text{height}]$ 这么一整个区域，用像素中心采样，就相当于要算出我们需要的、定义在屏幕空间上的某一个函数，在不同的像素中心它的值是多少。之后我们还会采样时间、采样位置、采样物体表面的反射性质——各种各样的东西都可以采样。三维空间也是：医学中的 CT、核磁共振成像，得到的成像结果本身是三维的——病人体内任何一个位置的组织密度是多少，这些信息都能拿到；要把它显示出来，同样涉及到采样。这就是采样的重要性。

回到我们要做的工作上：我们要采样什么呢？给你一个三角形，我要在像素的中心判断这个中心是不是在三角形内。这本身就是一个函数：定义一个 inside 函数，给定一个三角形和屏幕空间中任意一点的坐标 $(x,y)$——这个坐标不一定是整数，可以是任何实数——这个点要么在三角形里，要么不在；根据它在不在，我们定义这个函数取 1 或者 0。

我们采样的对象，就是屏幕空间中定义的这个 inside 函数：在不同的像素中心，确定这个函数的值到底是 1 还是 0。简单吧，我们要做的就是这件事情。

### 光栅化循环：在像素中心做采样

那如何去进行这么一个采样？沿用之前采样在代码上的定义，只不过把它变成二维的形式：

```cpp
for (int x = 0; x < width; ++x)
    for (int y = 0; y < height; ++y)
        image[x][y] = inside(tri, x + 0.5, y + 0.5);
```

两个 for 循环做的事情，就是把整个屏幕上所有的像素都考虑一遍。回到最开始的定义：每一个像素的坐标是整数 $x,y$，它实际的中心在 $(x+0.5,\ y+0.5)$；判断这个中心是不是在三角形里，就通过 `inside(triangle, x + 0.5, y + 0.5)` 这个函数——在内得到 1，不在得到 0。相当于让像素 $(x,y)$ 的值要么等于 0、要么等于 1；当然之后我们可以给它不同的颜色。这就是最最简单的、通过采样的方法来进行光栅化的过程。

小回顾：像素原本是整形的 index，中心在 $(x+0.5,\ y+0.5)$ 上；现在我们又定义了一个函数，表示 $(x,y)$ 这个点是不是在三角形内。那么重中之重来了：这个函数具体在图形学中应该怎么样去实现？

### 叉积判据：点在三角形内吗

这个问题其实前面讲向量叉积的时候已经提到过了。有一个三角形 $p_0p_1p_2$，要判断点 $q$ 是不是在三角形内，怎么办？做叉积。

比如看边 $p_1p_2$：建立从 $p_1$ 到 $p_2$ 的向量，去叉乘从 $p_1$ 到 $q$ 的向量，即 $\vec{p_1p_2}\times\vec{p_1q}$——这个叉积（用右手定则判断朝向）就能告诉我们 $q$ 点在 $p_1p_2$ 的左侧还是右侧。

```text
              p1
             /  \
            /    \
           /      \
          /   q    \
         /          \
        p0 -------- p2
```

读图：对三角形的每条边，都做"边向量 × 边起点指向 $q$ 的向量"这个叉积，用结果的 $z$ 分量符号判断 $q$ 在边的哪一侧。

具体算一遍：$\vec{p_1p_2}\times\vec{p_1q}$ 得到的向量朝外、朝屏幕外，也就是 $z$ 值为正——告诉我们 $q$ 在 $p_1p_2$ 的左侧。同样道理，$\vec{p_0p_1}\times\vec{p_0q}$ 得到的结果仍然是 $q$ 在 $p_0p_1$ 的左侧。只不过轮到第三条边：$\vec{p_2p_0}\times\vec{p_2q}$ 得到的是朝里的一个向量，说明 $q$ 在 $p_2p_0$ 的右侧——这就说明 $q$ 点不在三角形内。反过来，$q$ 若真在内部，它一定同时处在 $p_0p_1$、$p_1p_2$、$p_2p_0$ 这三条边的同一侧。

总结一下：考虑一个三角形，把顶点按某种顺序安排好，比如 $p_0p_1p_2$（或者 $a,b,c$），然后不断地重复它——$abc$、$abc$、$abc$——这样顺序就不会错，我们会依次找到 $ab$、$bc$、$ca$，而不是 $ac$。按这么一个循环的顺序去判断，叉乘得到的结果要么 $z$ 全是正的、要么 $z$ 全是负的，只有在这两种情况下，才判定 $q$ 在三角形 $p_0p_1p_2$ 里面。

> **易错点**：三条边必须按循环边序取（$p_0p_1$、$p_1p_2$、$p_2p_0$），不要漏掉首尾相接的那条边。另外，如果三角形的顶点是顺时针安排的——比如把 $p_1$ 和 $p_2$ 互换一下位置——那三个"在左还是在右"的测试就得全是"在右"，才能说明 $q$ 在三角形内。

这里还有同学会问一个问题：如果有一点正好碰巧落在三角形的边界上，这可怎么办？同学们在实际写的时候经常遇到这样的问题。对这种问题，通常要么不做处理，要么特殊处理。在这门课上，咱们不做处理——自己定义一个标准、自己把它说通就可以了：比如两个三角形共享一条边时，边界上的点到底算在三角形一、三角形二，还是两者都算？如果你认为这个点只要在某一条边上、就算在三角形内，那得到的结果就是它既在一上、也在二上；你认为在边界上不算，那也没有关系。

> **提示**：一些图形学 API（比如 OpenGL 和 DirectX）对此有着非常严格的规定：点落在三角形的上边和左边，就认为在三角形内；落在右边和下边，就算不在。这个规矩相对复杂一些，没有必要特别去掌握它，大家只要知道这是一个"要么自己规定、要么不严格处理"的事情就行。

### 包围盒：只遍历三角形附近的像素

再想想刚才那个二重循环：$x$ 从 0 到最大、$y$ 从 0 到最大——考虑一个三角形的光栅化时，把屏幕上所有的像素都给走一遍，是不是没必要？一个三角形其实只能覆盖一个相对较小的区域：离它很远的那几列像素根本就不在这个区域里，更不可能碰到这个三角形，所以对这些像素根本就不用看，三角形根本不可能填充到它们上面。

更严格一点说，这个区域是由水平的边和竖直的边围成的：三个顶点的所有 $x$ 取最小和最大，所有的 $y$ 取最小和最大，自然就得到一个方形的区域。像素如果本来就不在这个区域里面，自然就没有必要对它做光栅化——三角形一定不可能覆盖到它；只有这个区域内的像素，才需要做刚才的循环：$x$ 从 $x_{\min}$ 一直循环到 $x_{\max}$，$y$ 也同样操作，就不用所有的 $x$ 都从 0 到 width、把整个屏幕上的点走一遍。

这个包围盒其实还有名字，叫 axis-aligned bounding box（轴对齐包围盒），平常缩写成 AABB，之后还会给大家提到。

```text
      ymax +---------+
           |   /\    |
           |  /  \   |
           | /    \  |
           |/_______\|
      ymin +---------+
           |         |
      +----+----+----+----> x
           ^         ^
         xmin      xmax
```

读图：包围盒由三个顶点 $x$ 的最小/最大、$y$ 的最小/最大围成；盒外的像素不必再做采样。

还可以更省：对三角形所覆盖的区域，每一行都找它对应的最左和最右——这样一来，连一个像素都不会多考虑。当然，这个事情说起来容易，做起来其实不太容易。而且要问一句：这么一个方法，适用于光栅化什么样的三角形？什么时候会出现"三角形其实没覆盖多少像素、包围盒倒覆盖了不少像素"的情况？自然是三角形挺窄长、又旋转过来（旋转 45 度）的时候——正好倒霉。对于这种情况来说，就挺适合用刚才说的这种逐行找左右的方法。所以针对不同的情况，自然有不同的处理方法。

### 真实屏幕的像素：条纹与拜耳排列

这套理论非常简单——说白了就是每个可能的像素，检测一下是不是在三角形内。那实际屏幕上的光栅化是什么样？看一眼真实的屏幕：拿两个显示同一个画面的手机来对比，一台 iPhone，一台三星 Galaxy。

一看你就会发现不对：一个像素根本就不是一个小的方块。iPhone 上，一个像素其实是由三个不同的条组成的——红、绿、蓝 RGB 三个不同的条放在一块，变成一个像素，这是像素内部的结构。Galaxy 更有意思：同样是红绿蓝三个颜色，但这三个颜色形成了某一种图案，叫 Bayer 图案（拜耳排列）——你很难找出一个方块，把它圈起来说"这就是一个像素"。

这里还有一个特点，正好有时间多说一句。仔细注意的话，可以看到一个现象：绿色的点其实要比红色和蓝色的都要多。直接盯着某一块区域看，其实不容易看清，给大家提供一个方法：只看红颜色的点，估计一下它的密度——以这台 Galaxy 为例——你会发现红点的密度和蓝点的密度基本上是一样的；但如果只看绿颜色的点，很明显会感觉到这些绿色的点密度比红色和蓝色都要高。这是怎么回事？因为人眼本质上对绿色这个颜色最为敏感，所以在绿色上多一些像素是有好处的。同样的道理，很多相机其实也是这么设计的：不同的感光元件里，涉及绿色的感光元件就放得多一些——用 Bayer 图案的形式把这些元件以不同的密度组织起来，绿色上就有更多的感光元件，可以得到在绿色上更好的还原，从而人眼看上去会更舒服。

其他成像设备上还有更复杂的图案，比如彩色打印机：把打印结果放大了看，那些图案的分布非常非常奇怪——斜着的这样一条蓝色分布、这样的红色分布，还有黄颜色的。在打印的过程中，大家有时候会更多地关注比如如何去最省墨；而且其实我们之后会在颜色这一章专门给大家说：打印是一个减色系统——往上加的颜色越多，最后得到的结果越黑；我们平常提到的屏幕正好反过来，是加色的——RGB 的值越高，表示它越亮、越靠近白色。

回到咱们这门课上：我们仍然认为屏幕上每一个像素是内部颜色不变的小方块，这么理解没有问题。

### 锯齿：走样问题登场

这节课就差不多了。最后看一个问题：对屏幕中间这些不同像素的中心点，我们都可以判断是否在三角形内；在三角形内，就把它填成三角形对应的颜色。又知道像素是一个小方块——那么把所有像素中心点的判断结果点亮出来（红色表示在三角形内，白色表示在三角形外），你实际看到的应该是这么一幅图：一个由小方块拼出来的三角形，边缘全是台阶。

这一看就不太对。大家想要的是那个平滑的三角形，可是得到的是这么一个形状。你要说它不是三角形吧，也不能这么说——它基本的形状跟三角形一致；但很明显可以看到一样东西：锯齿。

锯齿就是光栅化图形学里一直在致力于解决的一个严重问题。原因其实从刚才的描述里已经可以看出来：像素本身自己有一定的大小；并且——用下节课将要讲的内容来说——我们的采样率对于这个信号来说是不够高的，所以产生了信号的走样问题。所谓走样，叫做 aliasing，在我们的光栅化图形学上就体现在锯齿上。

> **结论**：锯齿就是走样（aliasing）在光栅化上的体现；成因是像素有大小，而采样率对信号来说不够高。

接下来自然而然的一步工作，就是抗锯齿或者反走样——这是图形学中的一个重大技术，下节课给大家说。下节课还会着重分析：在频率上如何去解释走样问题、从采样的方法上看它到底是怎么回事。这两节课对比着看，大家就会知道：这节课这么简单的一个话题，为什么我们一定要通过"采样"这么一个概念去分析它、把它转化成一个理论上的问题。

先预告一句：下节课绝对不容易，特别是对于没接触过信号处理的同学，可能会相对较难；但希望下节课咱们把这个事情说清楚——联系这节课的内容，大家就知道采样到底是怎么回事，以及走样的基本成因和解决办法。

## 从锯齿到频域：反走样的采样理论

上节课我们把三角形送上了屏幕：经过 MVP 变换和视口变换，把 $[-1,1]^3$ 这个空间映射到屏幕空间。当所有三角形都已经在屏幕上时，把东西真正画出来的过程，就叫光栅化；而光栅化最重要的思想，是利用**像素的中心**，对三角形的可见性函数进行采样。这个解释当时听着有点绕，但我上节课说过：学完这节课你就会明白为什么一定要这么理解——因为只有这么说，才能方便地解释走样的成因，以及解决办法。

### 上节课的遗留问题：锯齿从哪儿来

先把上一节末尾的问题摆出来。一个三角形，定义在屏幕空间里，本质上是一个连续的信号，或者说连续的函数：给定任何一个点——浮点坐标也行——我们都能测试这个点是否在三角形内。光栅化的做法，就是拿每个像素的中心去做这个测试：中心在三角形内，记一个红点；在三角形外，记一个白点。然后把对应的像素涂上颜色——红的表示三角形覆盖了这个像素，白的表示没覆盖。

按这个流程画出来的结果，是一个"类似三角形"的图案。可我们希望看到的三角形应该长什么样，大家心里有数。两个一对比，中间的差异非常明显：能看到很明显的锯齿效果。

> **定义**：锯齿是俗称，它的学名叫**走样**（aliasing）。走样出现在各种场合——三角形的尖角放大了看，全是密密麻麻的锯齿。我们要做的对抗工作，就叫**反走样**（antialiasing）。

那怎么把锯齿干掉？先别急着给方案。咱们从采样理论开始，把"锯齿到底是怎么回事"想明白——这就是为什么这节课要和信号处理扯上关系；弄明白了原理，再看图形学里大家实际是怎么做反走样的。

### 采样无处不在：光栅化、照片与视频

上一节提过一个观点：采样在图形学中广泛存在。

光栅化本身就是采样——在屏幕空间里，用一系列离散的点（也就是像素的中心）对"是否在三角形内"这个函数进行采样。

采样也不只发生在光栅化里。任何一张拍出来的照片，放大了看都是一个一个的格子，这是我们表示图像的基本方法。图像有分辨率，也就是说它由多少个不同的格子组成，每个格子就是一个像素。一张照片，本质上是所有到达感光元件平面的光学信息，被离散成图像上一系列像素的过程——所以照片同样是采样。

还有一种有意思的情况：采样不但可以发生在不同的位置，还可以发生在不同的时间。什么叫视频，或者动画？把一系列的图按一定的时间间隔放出来，就形成了动画。动画实际上是在时间中进行的采样——你们从来没见过任何连续意义上的动画。把动画拆开看，它定义在一帧一帧上：一帧就是一幅图，每秒放出比如 24 帧图像，连在一起，大家就觉得这是一个光滑的过渡过程。但实际上，你看到的每一幅图、每一帧，都取自一个特定的时间点，在时间中并不连续。比如把每一帧叠在一块儿看，网球选手击球、发球的过程里，球拍和球的位置都是明显离散的。

所以说：采样广泛存在，而采样所产生的问题也同样广泛存在。

### 三种典型的采样瑕疵

图形学里有个词叫 **artifact**，专门表示错误、不准确、一切我们不希望看到的结果——凡是看上去不太对的东西，都管它叫 artifact。中文有翻译叫"瑕疵"，但比较别扭，所以后面我直接叫它 artifact。这就好比 frustum，中文叫"视锥"，听着也还是别扭——有些词，留着原文最省事。

> **定义**：artifact = 图形学里一切错误、不准确、我们不希望看到的结果。

第一种 artifact 咱们已经见过了：锯齿，长得像楼梯。这是在空间里采样产生的问题。

第二种叫**摩尔纹**（Moiré）。看一个实验：把一幅图的奇数行、奇数列全部去掉，剩下的像素重新拼成一张小图，再按原来的大小显示出来。效果很奇怪：衬衫上原本方向明确的纹理，完全扭曲了；领带上原本一个个的格子，变成了一条一条的怪纹。日常生活里也能见到它：拿手机去拍显示器的屏幕，屏幕上会出现一圈圈扭曲的纹路。这些同样是采样带来的问题，之后都会说到。

第三种看一个动画：一张纸片上画着各种条纹，把它转起来。纸片明明在顺时针旋转，但你会看到在某些位置上，有些条纹像是逆时针在转。生活中也常见：高速行驶的汽车，车轮看起来像在倒转。这个例子是什么采样出的问题？是**人眼在时间中的采样**——和视频一个道理，人眼在时间轴上采样，速度跟不上运动本身，就会出现这种情况。

| 瑕疵 | 采样发生的维度 | 典型场景 |
| :--------------------- | :------- | :------------------------------------- |
| 锯齿（Jaggies） | 空间 | 三角形边界画出楼梯状 |
| 摩尔纹（Moiré） | 空间 | 去掉奇数行列再放大；手机拍显示器屏幕 |
| 车轮效应（Wagon wheel） | 时间 | 条纹纸片顺时针转却像逆时针；高速车轮倒转 |

前两种说的是在空间中、不同位置上采样产生的问题，第三种说的是时间上的采样，但本质上都一样——都是采样带来的问题。

> **结论**：走样的根因，是**信号的变化太快了，以至于采样的速度跟不上它**。这种情况下采样就会产生 artifact，我们把这个 artifact 命名为走样。

那"信号变化太快"到底是什么意思？这就需要通过频率来分析了。频率分析本身完全可以撑起一门课，这里咱们快速普及它背后的结论。

### 先给结论：采样之前，先做一次模糊

怎么反走样？我先给大家一个结果，再回头分析为什么。

关键操作就一步：**在采样之前，先对信号做一次模糊**，也就是滤波（filtering）。

回到三角形的例子。之前为什么会走样？我们用像素中心去采样三角形，每个采样点要么完全在三角形内，要么完全在外，所以像素要么红、要么白，画出来就是锯齿。现在加一道工序：先拿到三角形，对它做一次模糊操作，把它变成一个模糊的三角形；然后再用像素中心去采样——采样的是这个模糊的三角形，它该是什么颜色就取什么颜色。有的点采到模糊三角形的边界，变成粉红色；离边界远一点就偏白，离边界近一点就偏红。

这么做之后，效果相当不错：即使放大了看，也没有之前那么严重的锯齿。换句话说，**对原始信号先做模糊（滤波），再去采样，就能抗锯齿**——这就是反走样。实际画面的对比也是如此：不做任何处理时走样严重，先滤波、再采样之后，结果就真实得多了。

那有同学会问：能不能反过来？先采样，采样完不是得到一个走样的结果吗，然后再做一次模糊、一次滤波，行不行？

答案是不行。先采样、再滤波，得到的不是我们想要的结果。这个操作有名字，英文叫 sample then filter，产物叫 **blurred aliasing**（模糊的走样）：它其实还是走样，只不过是走样了之后又被模糊了一道，跟反走样完全是两回事。

```text
正确的顺序（先滤波，再采样）：
  原始信号 ──模糊/滤波──> 模糊后的信号 ──像素中心采样──> 边界平滑的结果

错误的顺序（先采样，再滤波）：
  原始信号 ──像素中心采样──> 已经走样的结果 ──模糊/滤波──> blurred aliasing
```

读图：同样的两个操作，顺序一换，一个是反走样，一个只是把走样的结果糊了一遍。

> **易错点**：模糊和采样的先后顺序不能换。先滤波再采样才是反走样；先采样再滤波，只是 blurred aliasing。

那为什么采样速度跟不上信号变化的速度，就会产生走样？为什么先采样、再模糊，就达不到反走样的效果？要弄清楚这些，我们就需要频域方面的知识了。

### 用频率刻画"变化有多快"

frequency 是频率，frequency domain 就是频域。频域分析从最简单的东西看起——没有什么信号会比正弦波、余弦波更简单了。$\cos x$ 和 $\sin x$ 的区别，无非是一个相对另一个左右平移了一点；而把 $x$ 前面的系数考虑进去，有意思的事情就来了。

比如 $\cos(2\pi x)$ 和 $\cos(4\pi x)$：调整 $x$ 前面的系数，就能得到各种不同的余弦波，它们的区别在于**频率不同**。

> **定义**：把余弦写成 $\cos(2\pi f x)$，$f$ 就是它的频率。$f=1$ 对应 $\cos(2\pi x)$；$f=2$ 对应 $\cos(4\pi x)$，变化明显比 $f=1$ 快。频率 $f$ 刻画了余弦波变化的快慢。

对一个函数还可以定义它的**周期**：每隔多少，函数会重复自己一次。周期是频率的倒数：

$$T = \frac{1}{f}$$

$f=1$ 的余弦波每隔 1 重复一次；$f=2$ 的那个每隔 0.5 就重复一次。

为什么要介绍这些不同频率的正弦、余弦波？这就要请大家回忆微积分里的一个东西：函数展开。展开的方法有很多——什么泰勒展开之类的——其中有一种，叫**傅里叶级数展开**。

### 傅里叶级数与傅里叶变换

傅里叶级数展开说的是：**任何一个周期函数，都可以写成一系列正弦函数和余弦函数的线性组合，外加一个常数项**。

看一个例子就明白了。假设要描述的是一个"跟城墙一样"的函数：突然凸出来一块，突然又没了，周期性地重复——这就是一个周期性重复的 box 函数。怎么用余弦去近似它？一步步来。

先用常数项 $A/2$（$A$ 就是 box 的高度），作用是把函数的中心往上提；再加一项频率最低的余弦——中心提上去、再叠上这一个 cos，出来的结果就算是一个近似了。然后继续引入更多的项：比如再乘上诸如 $\frac{2}{3\pi}$ 这种算出来的系数，加上频率更高一些的余弦，几项线性组合下来，近似就更准确了。再往上加项，就越来越像；加到无限多项，它就无限接近这个周期函数。这里是一个特殊情况：只有余弦、没有正弦。

这说明什么？不同的正弦、余弦函数有着不同的频率——比如各项的角频率 $\omega$、$3\omega$、$5\omega$、$7\omega$ 各不相同，本身就代表不同的频率。所以傅里叶级数展开告诉我们：**任何一个函数，都可以分解成频率从低到高排列的各个成分**。常数项 $A/2$ 跟 cos 根本没关系，它是最"低"的成分；接着是变化很缓慢的低频余弦；再往后加的项，频率一项比一项高。

由此引出一个和它紧密相连、但并不是一回事的概念——**傅里叶变换**（Fourier transform）。给定任何一个函数，让它经过一个相当复杂的操作，变成另外一个函数；这个复杂操作大家完全没必要去看，只需要知道：小写的 $f(x)$ 经过变换变成大写的 $F(x)$，一个函数变成了另一个函数；而且大写的 $F(x)$ 还能通过**逆变换**变回原来的 $f(x)$。能变过去、也能变回来——这就是傅里叶变换和逆傅里叶变换。

> **定义**：傅里叶变换把一个函数变成一段段不同频率的成分，并把各个频率上的内容显示出来。

### 同一种采样，看穿走样

有了频率的框架，看一组实验，体会"采样"和"函数频率"之间的关系。

取五个不同的函数 $f_1$ 到 $f_5$，从上到下频率从低到高。我们用**完全相同**的采样方法——每隔同样长的一段采一个点——对它们逐个采样，然后把采样点连起来，看能不能恢复出原来的函数：

- $f_1$：采样点连起来，基本上能大概看出原来的函数长什么样；
- $f_2$：也能这么做，问题不大；
- $f_3$：到这里就已经发现不太对了。采样点连起来，恢复得相当勉强，尤其后半段，恢复出来的函数和原来的 $f_3$ 越离越远；
- $f_5$：那就差得不行了。凭这些采样点能恢复出来的东西，和实际的 $f_5$ 完全比不了。

道理很直白：函数本身有频率，采样也有频率。采样间隔很小，就是采样很密、采样频率很高，自然能恢复出频率很高的函数；可如果函数本身频率很高——像 $f_5$ 变化那么快——采样频率却很低，那就跟不上它的变化，原始信号就恢复不出来了。采样好不好，和函数自身的频率非常有关系。

再进一步，把走样正式定义出来。先看一个变化挺剧烈的函数，采样间隔我们自己说了算、随便选——采出来的点不太行，连起来恢复成另一根线，出问题了。现在换一个问法：假如有两个函数，一个频率低、一个频率高，截然不同——注意，其中那根对不上的线不是刚才恢复出来的产物，它本身是另一个真实存在的函数。用同一种采样方法去采这两个函数，会得到什么？

得到的采样点是**完全相同**的：同一串空心采样点，拿去描述这一个函数是这些点，拿去描述那一个函数还是这些点。而这两个函数原本的频率差得太多，我们却无法通过采样结果把它们区分开。

> **定义**：走样（aliasing）——**同一种采样方法，采样两种不同频率的函数，得出来的结果无法区分**。

到这儿，走样就在频率分析上被严格定义好了；傅里叶变换也定义过了。接下来就可以真正动手，分析一些函数——比如一张图像——到底拥有什么样的频率。

### 滤波：在频域抹掉一段频率

滤波（filtering）从频率的角度看，非常简单：

> **定义**：滤波，就是把某个特定频段的内容抹掉、删掉，看对应的信号会发生什么变化。滤波 = 去掉一系列频率。

傅里叶变换可以把一个函数从时域变到频域——这正是它的作用。拿一张人像照片试试：对它做傅里叶变换，图像就从图像的空间被变到了频率的空间。图像本身当然不含任何时间信息，但我们把空间上不同的位置也叫作"时域"——这只是个名字而已。

#### 频谱怎么读：中心低频，亮度即信息量

得到的频域图像（频谱）这么读：

```text
+--------------+--------------+
|              |              |
|      H       |      H       |     H    = 高频区域
|              |              |
|--------------*--------------|     *    = 中心：最低频，自然图像上最亮
|              |              |     向外 = 频率越来越高
|      H       |      H       |     亮度 = 该频率上信息的多少
|              |              |
+--------------+--------------+
```

这张人像的频谱显示：图像的大多数信息集中在低频上——中心比较亮。高频信息有没有？有，比如外围那些亮度不为零的地方；但相比低频少太多了。对自然的图片来说基本都是这样。真想验证的话，自己写个傅里叶变换的程序非常简单——不用手写，很多库直接提供——随便找一张图变换一下，你会发现低频信息集中在中间、非常多，高频信息在外围、非常少。

那频谱里为什么有水平和竖直两道特别明显的亮线？简单说一句：我们分析一个信号时，会把它当作周期性重复的信号。一张图哪是周期重复的？不是。那我们就认为它在水平方向上叠了无限多张、竖直方向上也挨个放了无限多张——右边界之后接着重复左边的内容。可很少有图像的右边界和左边界完全一致，于是拼接的地方会发生剧烈的信号变化，产生极其高的高频。这就是那两条线的来历。为了分析图像内部的事情，忽略这两条线。

这种"信号在各个不同频率上长什么样"的表示，就叫**频谱**。

#### 高通滤波：剩下的全是边界

第一个滤波实验：把频谱上低频的信号完完全全抹掉，只留下高频，再用逆傅里叶变换变回图像——会发现高频信息在图像上是有意义的：它表示的是图像**内容的边界**。注意，不是图像四边的那个边框，是内容上的边界：比如这个人衣服的轮廓和背景差得很多，这些边界都被提取了出来。

我们只做了一件事——抹掉低频。这种滤波有名字，叫**高通滤波**：应用这种滤波器，只有高频信号能通过，所以叫"高通"。别搞错：高通滤波器意味着最后只剩下高频。

为什么高频就对应内容的边界？想一个问题：不通过任何数学，什么叫边界？其实想得明白——图像上某个地方，左边跟右边（或者上边跟下边）突然发生突变、差得很多，我们就认为这里是边界。比如那件衣服：下边是衣服的颜色，上边是模糊的背景，沿着这条边，信号发生了非常剧烈的变化。而剧烈变化的信号，可不就是信号本身蕴含的高频信息吗？所以让高频通过，自然就把这些边界找了出来。这是有道理的。

#### 低通滤波：抹掉边界，就是模糊

反过来做第二组实验：只留下低频信息，把所有高频信息全抹掉，再变回图像——得到一张**相对模糊**的图。基本还能看清是个人，但绝大部分细节，比如衣服上的褶皱，就再也看不见了。

这就是对信号应用了**低通滤波器**：只让低频通过，高频都被筛掉、去掉。从刚才建立的角度分析：高频意味着边界；边界被去掉了，就再也看不着边界了——图像看起来自然就模糊了，不再有原本边界的概念。有道理吧？

有同学可能会问：这个模糊图像的频谱里，看起来像水波纹一圈一圈的东西是什么？这个稍微复杂一点，待会儿讲到 box filter 的时候再说——它是一个不完美的低通滤波产生的问题，这里先忽略它。

#### 带通滤波：只留中间一圈

第三个实验更有趣。这次把高频去掉、低频也去掉，只留下中间某一段频率——不算特别高，但也不是低频。变回图像，会提取到一些**不那么明显**的边界特征。这也有道理：最明显的边界特征对应最高的频率，外面一圈已经被去掉了；大面积相同的色块是低频，也被去掉了；剩下的自然就是这种中间状态的信息。

同样道理，如果把保留的圈往外扩，留下频率更高的外面一圈，看到的结果就更偏高频的边界特征。这一切都是可以想明白的。

到这里，我们通过频率上的分析，把"不同的频率"和"信号的变化"联系起来了。这一块内容，图形学里正常不会讲得特别多；真想多学，有一门课叫**数字图像处理**，专门教怎么用各种滤波方法对图像做操作——当然那是经典的做法。平常我们很少做频域操作，但不管怎样，这个分析是很有道理的，把它弄明白就好。

滤波，我们刚才是从"去掉一段特定的频率"这个角度来理解的；它还可以从另外一个角度来分析——咱们接着往下看。

> **承前启后**：上一节讲完「从锯齿到频域：反走样的采样理论」，下一节接着讲「频率视角下的采样与抗锯齿」。

## 频率视角下的采样与抗锯齿
> 对应块：BLK08 | 覆盖分集：P06下 | 块标题（分集名）：《Lecture 06 Rasterization》

先把上一节末尾留下的那串等式捡起来：**滤波等于平均，又等于卷积**。一句话里挤了三个概念，得一个一个接上。"平均"最好理解：低通滤波器只留下低频信号，图像看起来就像被模糊了一样，而模糊本身就是一种平均操作。

那卷积（convolution）是什么东西？它听上去像某种奇怪的运算，凭什么和滤波扯上关系？如果你接触过信号系统，这个词再常见不过；没接触过也不要紧——从图形学的角度，我们有一套简化了的定义，足够把这件事说明白。而且说明白之后你会发现，"先模糊、再采样"的反走样做法为什么成立，也就水到渠成了。

### 卷积：一个滑动的窗口

设有一个信号——一维数组也好，二维图像也好——再拿一个滤波器（filter），把它想象成一个窗口：这个窗口可以在信号上左右滑动，窗口有大小（比如三格），每一格上面都写着一个数。

所谓卷积操作就是：窗口滑到某个位置时，把它盖住的几个数与窗口上对应的几个数一一相乘、再相加（也就是做点乘），把结果写回窗口中心那个格子。

```text
信号（一维数组）：            ...  1   3   5   3  ...
滤波器（窗口，可左右滑动）：    [ 1/4 | 1/2 | 1/4 ]

第 1 步：窗口对齐，盖住信号上的 1、3、5
         1*(1/4) + 3*(1/2) + 5*(1/4) = 3   -> 结果写回窗口中心那个格子

第 2 步：窗口向右移动一格，这次盖住 3、5、3
         3*(1/4) + 5*(1/2) + 3*(1/4) = 4   -> 结果写回新的中心格子

窗口一路滑过去，每个位置都得到一个"周围一圈的加权平均"
```

读图：滤波器像一个三格宽的窗口在信号上滑动，每停一处就把盖住的数与窗口上的系数点乘求和，写回窗口中心。

说白了，这就是在原始信号的任何一个位置，取它周围一圈数做一次加权平均；任何一个位置的数都变成了周围若干数的平均，一路算下来，就得到一条写满平均值的新信号。卷积作用在一个信号上，用某种滤波器对它做这样的操作、得到一个结果——整个过程就叫卷积操作。

> **定义**：这是图形学上简化了的卷积定义，不是数学上的严格定义（严格的数学定义要到信号系统课里去见）。对图形学来说，记住"卷积 = 信号在任何一个位置对它周围区域做一次加权平均"就够用了。

### 卷积定理：时域卷积，频域乘积

卷积有一条定理。这个东西其实是可以证明的，但证明是信号处理课的事情，这里直接下结论：

> **结论**：时域上对两个信号做卷积，等价于在频域上把两个信号各自的频谱做乘积；反过来，时域上的乘积对应频域上的卷积。卷积和乘积这两个操作，联系就是这么近。

有了它，做卷积就有了两条等价的路：可以直接拿一幅图，用某个滤波器对它做卷积操作；也可以先把这幅图变换到频域，把卷积用的滤波器也变换到频域，把两者相乘得到频域上的结果，再做逆傅里叶变换变回时域。两条路做出来的东西一样。

拿一幅真实的图来验证。想对一幅图做平均（也就是模糊）：用一个 $3 \times 3$ 的窗口——数学上我们管它叫卷积核——对任何一个像素，取它周围 $3 \times 3$ 共九个数求一下平均，再写回这个像素本身。任何一个像素都变成了周围九个像素的平均，得到的结果可想而知，就是一幅模糊了的图像。

现在走频域那条路。把图傅里叶变换到频域，得到它的频谱；把那个 $3 \times 3$ 的卷积核也变换到频域——它会变成一幅几乎全黑、只有中心留下一块白的图（细看中心之外还有些环状的纹路，这里先不深究），总之绝大部分能量集中在中心低频这一块。把两个频谱乘起来，等于只让原图留下最低频的内容；而上一节分析过，把低频内容逆傅里叶变换回去，得到的就是这幅图像对应的模糊图像。结果对上了——这就验证了卷积定理是对的。

这个定理乍一听不好接受很正常，它本来该是信号处理课上花好几个课时讲的内容，我们在这里直接用了它的结论。没关系，刚才这个例子已经把"为什么有道理"解释清楚了。

顺带把卷积核上那个 $1/9$ 说明白。九个格子全是 1、再统统乘 $1/9$，是为了让卷积之后图像整体的颜色值不发生变化：你想，如果系数全是 1，任何一个像素都会变成周围九个像素之和，那图像岂不是越滤波越明亮了？这可不对。所以要做归一化，把所有系数变成 $1/9$，这样卷积就不会引起整幅图亮度的变化，就这么个目的。

也正因为这个卷积核放到频域上只留下低频的部分，这个盒子形状的滤波器（box filter）就是我们所说的**低通滤波器**。

### 盒子越大，频域上越小

盒子滤波器显然有大小。把时域上那个小小的方块盒子傅里叶变换到频域，会得到某个形状的频谱。那么问题来了：如果盒子在时域上变大了，它在频域上应该如何变化？变小又会怎样？可以先想一想。

答案是：**盒子在时域上变大，它在频域上反而变小**。这听起来违反直觉，但完全正确，可以这样理解：

为了模糊一张图，我们用 $3 \times 3$ 的卷积核；如果换成 $21 \times 21$、$63 \times 63$ 这么大的盒子，对任何像素都取周围那么大一块区域再平均起来，得到的结果肯定越来越模糊——越大的盒子越模糊。再想两个极端：用一个比图像还要大的超级大盒子，所有像素全被加起来，各处结果基本都一样；用一个比一个像素还小的超级小盒子，那不等于是完全没做滤波吗？——它对应频域上的范围就会超级大，把所有的频率都留了下来。

反过来，用一个大的盒子，就只能留下更低的频率，结果就变得更模糊。所以这个关系非常有道理。

> **结论**：时域上的盒子越大，频域上盖住的范围越小，滤波结果越模糊；盒子越小（小过像素），相当于没滤波，所有频率都保留。

### 采样，就是复制频谱

滤波和卷积说清楚了，现在从频率的角度看另一头：什么是采样。

还是结论先行：**采样，其实就是在重复频域上的内容**。为什么这么说？一步步推。

有一个连续函数 $a$，假设它的频谱（傅里叶变换的结果）记作 $b$。什么叫采样？把连续函数变成一系列离散的点——只留下某些位置上的函数值。这件事等价于：拿 $a$ 去乘另一个函数 $c$，$c$ 只在一系列固定间隔的位置上有值，其他地方一概为零。$c$ 画出来是一根根竖着的箭头，这种"只在那个位置有值、别处没有值"的函数有名字，叫**冲击函数**。$a$ 乘上这一排冲击函数，得到的 $e$ 就是一系列离散的点——这正是采样留下来的结果。

时域上做了乘积，那频域上会发生什么？卷积定理出场：时域乘积对应频域卷积。而一排冲击函数经过傅里叶变换，还是一排冲击函数，只是间隔不一样了，记作 $d$。于是把 $a$、$c$ 各自的频谱 $b$、$d$ 在频域上卷积起来，得到 $f$。神奇的现象出现了：原始函数明明只是被采了样，它的频谱却被**复制粘贴**了很多份。

> **结论**：采样 = 重复原始信号的频谱。时域上乘一排冲击函数（留下离散点），等价于频域上把频谱按固定间隔复制粘贴。

### 采样不够快：频谱混叠，走样出现

既然采样就是复制频谱，那复制得多密，就由采样间隔决定。这里时域和频域又表现出一种相反的关系：**采样越稀疏（采样点之间的距离越大），频谱拷贝之间反而越密集**。

如果采样率不足、采得不够快，一份份频谱拷贝就会挤到一块儿，原始频谱和相邻的拷贝叠在一起、混在一起。这种频谱在复制（搬移）过程中发生混合的情况，就叫混叠——它就是走样产生的原因。

```text
采样足够快（采样点密）：  [谱]········[谱]········[谱]········   拷贝间隔大，互不干扰
采样不够快（采样点稀）：  [谱]····[谱]····[谱]····               拷贝挤在一起，相互混叠 -> 走样
```

读图：采样点越稀疏，频谱拷贝被搬移的间隔越小；相邻拷贝一旦叠在一起，混叠（走样）就发生了。

> **定义**：从频率的角度说，走样（aliasing）就是采样后频谱的各份拷贝相互混叠。

这个解释拿回光栅化上一验证就对上了：还是那个三角形，如果像素非常小、非常密，相当于对这个信号采样得很密集，走样现象就会少很多；如果每个像素都很大、像素中心间隔很大，相当于稀疏采样，走样就很严重。道理就在这儿。

### 反走样：先模糊，再采样

明白了走样在频率上是怎么回事，就可以谈反走样了。有两种思路。

第一种：增加采样率。这是终极解决办法。一台古老的 $640 \times 480$ 显示器，一个像素非常大，光栅化出来的三角形锯齿一眼就能看见；换成分辨率几千乘几千的视网膜（Retina）显示器，像素变小、像素间隔变小——意味着采样频率变高，频域上频谱拷贝的间隔变大，就不容易出现混叠。但这不是反走样要做的事情：反走样是在同一块屏幕上完成的，你不可能靠打开某个抗锯齿选项就让分辨率涨上去，这受物理限制。

第二种，就是最开始给反走样下的那个操作定义：先模糊，再采样。前面这一大串频率分析都是铺垫，现在可以回答"它为什么有道理"了。把这句话翻译成频率的语言：

- 什么叫模糊？模糊就是低通滤波，把信号的高频信息先拿掉；
- 高频被砍掉之后，频谱变窄了；
- 这时再用原本那个稀疏的采样率去采样——频谱拷贝之间不再重叠，混叠不发生了。

拿图来看：原始频谱是一个梯形，按原来的稀疏采样率直接复制粘贴，相邻拷贝会混叠；先把超出某个范围的高频统统砍掉不要，剩下的频谱覆盖的面变小了，再按原本的间隔复制粘贴，就不混叠了。先模糊、再采样，就是这么回事。

> **结论**：反走样 = 先去掉高频（模糊、低通滤波），再采样。模糊让频谱变窄，随后的稀疏采样不再混叠。

### 把三角形变模糊：按覆盖率求平均

方案定了，剩下的问题只有一个：到底怎么才能把一个三角形变模糊？采样我们本来就会，所有难度都集中在滤波这一步。

办法：用一个一定大小的低通滤波器对它做卷积。卷积就是平均——任何一个位置，取它周围一块区域，把这块区域的结果平均起来。

取什么样的块？最简单的块就是一个像素：像素自己正好是一个小方块，而这个小方块就是一个 box filter，就是低通滤波器，起的作用正是模糊。

原本的三角形是个二值函数：一个点要么在三角形内，要么在三角形外。现在拿每个像素对应的这个小 box 对它做卷积、求平均——像素内部被三角形覆盖了多少比例的面积，这个像素就取多大比例的三角形颜色。对任何一个像素，三角形要么完全不覆盖它，要么完全覆盖，要么覆盖一部分：覆盖 $1/8$，像素就是 $1/8$ 的三角形色加 $7/8$ 的背景色（87.5% 的白）；覆盖一半，就是一半对一半；完全覆盖，就是全黑。把每个像素的值都这样平均出来，三角形就被模糊了。

可这事儿说着容易做着难：怎么把三角形在某个像素内部覆盖的精确区域算出来？这不容易，计算量也不小。所以人们研究出了一种近似方法。

### MSAA：用更多采样点近似覆盖率

这个近似方法叫 MSAA（Multisample Antialiasing，多重采样抗锯齿）：用更多的采样点来做反走样。注意它是对反走样的**近似**，并不能严格意义上解决走样问题。

它怎么工作？原本一个像素只用一个点判断在不在三角形内；现在把一个像素划分成许多小的采样点（比如 $4 \times 4$ 十六个），每个小点各自判断是否在三角形内，再把判断结果平均起来——这就是三角形对这个大像素覆盖区域的近似。采样点越密，近似越准：$100 \times 100$ 个点可以得到相对准确的结果；$4 \times 4$ 不太准，但没关系，效果已经挺好。

用最简单的 $2 \times 2$ 四个点走一遍。某个像素的四个点全在三角形外，覆盖率是 0，像素保持背景色；挨个判下去，走到某个像素，四个点里三个在内、一个在外，覆盖率就是 75%，像素写成 75% 的三角形颜色；再往边上，某个像素只有一个点被"感知到"在三角形内，覆盖率 25%，这个像素就写成 25% 的红色。每个像素都这样处理，抗锯齿的效果就出来了；和不做抗锯齿的图一比，效果相当明显。

讲到这里必须停下来，把两件事澄清清楚。

第一，MSAA 近似的是反走样的第一步——模糊。每个像素内部求完平均、知道了覆盖率之后，像素里已经是同一个颜色，第二步采样变得无比简单：在格子中间采出来的就是这种颜色。也就是说，采样这一步其实隐含在了整个过程里；你非要认为后面真的还有一步独立的采样，也没什么关系。

> **易错点**：MSAA 绝对不是靠提升分辨率来解决走样问题的。屏幕上该多少像素还是多少像素，加的那些采样点只是为了近似一个合理的三角形覆盖率，并没有真的提高屏幕的分辨率。按这个角度理解反走样才是正确的。

### 没有免费的午餐：代价与工业界的变通

MSAA 效果不错，但 no free lunch——没有免费的午餐。为了做到抗锯齿，我们到底牺牲了什么？很显然：计算量。用更多的点去测试是否在三角形内，计算量必然增大，而且增大多少说得明白：$4 \times 4$ 就是 16 倍，$2 \times 2$ 就是 4 倍。

但人们都很贪婪：谁也不想用那么多采样点只换这么一点效果，都希望只用很少一点采样点，也能达到 $4 \times 4$ 规则网格的效果。事实证明这是可以的：工业界并不把像素规则地划分成 $4 \times 4$、再取这些子像素的中心，而是用一些更有效的图案来分布这些采样点，而且有一些点还会被相邻的不同像素复用。

这反过来又印证了前面的强调：这些点不是用来提高分辨率的，仅仅是为了检测三角形的覆盖而已。所以打游戏的时候开 4 倍 MSAA，帧率并不会掉到原来的四分之一——道理就在这儿，很多样本被复用了。至于具体什么样的分布图案能达到最好的覆盖效果（会涉及一些随机数、样本分布的技巧），等到光线追踪那一块再讲。

### 另外两条路线：FXAA 与 TAA

只讲一种抗锯齿，显然代表不了现代图形学的发展。抗锯齿方案特别特别多，除了 MSAA 之外，按个人意见最重要的两种是 FXAA 和 TAA，它们都得到了工业界的广泛应用。

FXAA（Fast Approximate Antialiasing，快速近似抗锯齿）：它和增加采样数没有任何关系，是一种**图像的后期处理**——先拿到一幅有锯齿的图，然后通过一些图像匹配的方法把这些锯齿的边界找到，再把它们换成没有锯齿的边界。简单吧，就这么一个操作，而且非常快。要注意，这可不是"对有锯齿的图做模糊"：一开始就强调过，先采样得到锯齿、再回头去模糊，是不对的（有兴趣的话可以从频率的角度自己分析一下为什么）。

TAA（Temporal Antialiasing）：最近几年才刚刚兴起的一种抗锯齿方法，非常简单高效。T 是 temporal，意思就是与时间相关。它的思想是**复用上一帧的结果**：假设场景是静止的，相邻两帧显示的东西一样，但相邻两帧可以用像素内部不同位置上的点去感知三角形——于是不同帧里，边界有时出现、有时不出现。把上一帧每个像素的值拿到这一帧继续发挥作用，效果上相当于把 MSAA 对应的那些样本分布到了时间上，而在当前这一帧，没有引入任何额外的操作。这是个非常聪明的做法。那运动的物体怎么办？等讲到实时光线追踪再说，那边的核心思想和 TAA 是一样的。

顺带说个工业界的习惯：temporal 这个词本身还有"暂时性"的意思，为了避免误会，美国的同行们倾向于不按整词念，而是按字母把它念成 TAA。

三种方法放到一起看：

| 方法 | 核心思路 | 特点 |
| :--- | :--- | :--- |
| MSAA | 像素内加采样点，近似三角形覆盖率 | 近似的是"先模糊"这一步，代价是计算量 |
| FXAA | 后期处理：找到锯齿边界并替换 | 与采样无关，非常快 |
| TAA | 复用上一帧结果，把样本分布到时间上 | 当前帧零额外操作 |

### 顺带一提：超分辨率与 DLSS

提到抗锯齿这个概念，一定还得提另外一个和它很相似的概念：super resolution，中文叫超分辨率。两件事不是一回事，但本质是相似的。

超分辨率是说：给你一张 $512 \times 512$ 的图，要把它拉大到 $1024 \times 1024$——直接拉大，看的全是锯齿。想拉大、又不想看到锯齿，说白了是什么？其实存在一幅 1k 乘 1k 的高分辨率图，只是你的采样率不够，采到的结果只有 $512 \times 512$；你想把这幅高分辨率的图恢复出来。从这个角度看，超分辨率和抗锯齿（比如 MSAA 做的事情）非常相似：**都是在解决样本不足的问题**。

这里介绍一种做法，叫 DLSS。把小图拉大之后，肯定有些细节缺失，缺失怎么办？猜出来就好了。猜出来怎么猜？什么技术适合"猜"这种事？——给它足够多的经验性的东西，让它学会在任何一个局部应该如何把细节补上去，这正是深度学习擅长的事情。

到这里，抗锯齿这块就完全说明白了。这一讲内容相对较深、也较多，课后值得多花点时间回头再看几遍，也欢迎踊跃讨论。深度测试，以及"谁挡住谁"的遮挡问题，这一系列事情这节课还没来得及讲，留到下节课。
