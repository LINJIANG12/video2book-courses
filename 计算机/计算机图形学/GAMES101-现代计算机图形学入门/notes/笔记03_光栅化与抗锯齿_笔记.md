# 光栅化与抗锯齿

## 视锥的两个定义量

* **垂直可视角度（field of view，fovY）**

    * > **定义**：从相机连出两条线，分别连到近平面上边中点与下边中点，这两条线所夹的角度。

    * 广角相机就是可视角度比较大：反映在视锥上张得比较开，透视投影效果明显，适合拍近距离的物体。

    * fovY 比较小相当于开口小：透视投影效果越不明显、越像正交投影，但可以很容易地拍到远处的物体。

    * 打游戏经常涉及的是水平可视角度：从相机连两根线、分别连向近平面左边与右边的中点所形成的角度；知道宽高比与 fovY 就能把它推出来。

* **宽高比（aspect ratio）**

    * > **定义**：宽度除以高度。

    * 说一块屏幕是 4:3（早期屏幕、iPad）或 16:9，指的就是这个信息；摄像机摆好、朝一个方向看，试图看到的那个区域的宽高比就此定下。

* 与正交投影长方体六参数的转化

    * 透视投影要处理的是视锥（frustum）——那个近大远小的形状，要把它变成长方体；远、近两个数与正交投影的表示相同（$n$、$f$ 认为已知、不用管），视锥的其余部分由 fovY 与宽高比定义。

    * 从侧面看，相机视野是一个三角形：到近平面的距离为 $|n|$，上下两条边线的总夹角是 fovY，三角形张开的半角是 $fovY/2$，三角函数关系立即给出 $\tan\frac{fovY}{2}=\frac{t}{|n|}$。

    * 近平面最高点对应的 $y$ 值就是 $t$，最低点对应 $-t$，故 $b=-t$；知道高度 $t$ 与宽高比，水平方向的宽度就是 $t$ 乘以宽高比，故 $r=\text{aspect}\cdot t$、$l=-r$。

    * 正常情况下定义一个视锥很简单：只需一个垂直可视角度、一个宽高比，其余量全部自动转化到正交投影"左右上下远近"那套概念上。

## 屏幕与像素

* **像素（picture element，pixel）**

    * > **定义**：屏幕被抽象地认为是一个二维数组，数组中的每一个元素是一个像素。

    * 分辨率表示的就是像素的多少：1920×1080 叫 1080p，1280×720 叫 720p，更高的还有 2K、4K。

    * 基础抽象：每个像素是内部颜色不会发生变化的小方块——要么整个方块是红色，要么是完全相同的白色或黑色；真实像素远比这复杂，但作为抽象没有问题。

    * 颜色表示：认为灰度可划分成 256 个等级，等级 0 完全是黑的、等级 255 完全是白的；也可以用红、绿、蓝三个强度值组合出各种各样不同的颜色（RGB）。

* **光栅化（Rasterization）**

    * > **定义**：把东西画在屏幕上的过程。

    * Raster 这个词来自德语，意思就是屏幕；把名词变成动词，这个过程就叫光栅化。屏幕是一种典型的光栅成像设备。

* **屏幕空间**

    * > **定义**：在屏幕上建立的坐标系：屏幕左下角为原点，向右为 $x$，向上为 $y$。

    * 像素的坐标（下标）写成整数形式 $(x,y)$：宽 width、高 height 的屏幕，像素从 $(0,0)$ 一直编到 $(\text{width}-1,\ \text{height}-1)$——从零开始数；这些规定是约定俗成，并没有什么特殊的意义。

    * 像素中心不在整数点上：坐标 $(2,1)$ 的像素实际中心在 $(2.5,1.5)$；任何一个像素的中心都准确地落在 $(x+0.5,\ y+0.5)$ 上。

    * 每个像素在 $x$、$y$ 方向都覆盖宽度 1，整个屏幕覆盖的范围就是从 $(0,0)$ 到 $(\text{width},\text{height})$。

    * > ⚠️ **易错点**：像素 $(x,y)$ 用整数编号，但它的中心在 $(x+0.5,\ y+0.5)$——整个采样过程都建立在这半格偏移上。

* 像素中心图示

    ```text
      y
      ^
    3 +---+---+---+---+
      |   |   |   |   |
    2 +---+---+---+---+
      |   |   | o |   |    o = 像素 (2,1) 的中心，位于 (2.5, 1.5)
    1 +---+---+---+---+
      |   |   |   |   |
    0 +---+---+---+---+---> x
      0   1   2   3   4
    ```

## 视口变换

* MVP（model、view、projection）变换做完之后，场景里所有物体都会被变到 $[-1,1]^3$ 这个经典立方体里；下一步就是把这个立方体画在屏幕上。

* **视口变换（viewport transform）**

    * > **定义**：把 $[-1,1]^2$ 变成整个屏幕空间 $[0,\text{width}]\times[0,\text{height}]$ 的变换。

    * 分两步：先缩放——宽度和高度各除以 2、再分别乘以 width 与 height，边长为 2 的正方形就变成屏幕大小；再平移——缩放完中心还停在原点，而屏幕空间的原点定义在左下角，要把中心平移到 $(\text{width}/2,\ \text{height}/2)$。

    * 矩阵形式（$w$、$h$ 分别是屏幕的宽和高）：

$$M_{\text{viewport}}=\begin{pmatrix}\dfrac{w}{2}&0&0&\dfrac{w}{2}\\ 0&\dfrac{h}{2}&0&\dfrac{h}{2}\\ 0&0&1&0\\ 0&0&0&1\end{pmatrix}$$

    * 左上角的 3×3 是对角阵：宽度方向乘 $w/2$、高度方向乘 $h/2$；$z$ 方向那一项写的是 1——$z$ 没有经过任何改变（暂时先不管它，之后自然有它的用途）。

    * 做完视口变换，不管原本是用宽高比加可视角度定义的视锥，还是用三组对边位置定义的正交投影长方体，反正都已经变到 $[-1,1]^3$，现在又把 $x,y$ 变到了屏幕上——已经可以得到一张二维的、场景的"虚拟照片"。

## 显示设备

* **阴极射线管（cathode ray tube，CRT）**

    * > **定义**：靠电子束成像的显示设备：电子发射端产生很多电子，穿过显示设备时发生偏转、偏到不同的位置上，打在屏幕的某一个位置；这个过程进行得足够快，就不会看到一个个电子，而是看到它们连成的形状。

    * 示波器与早期显示器的成像原理一模一样：在水平偏转通道放一个正弦波、垂直偏转通道放一个余弦波，两者加起来就是一个漂亮的圆。

    * 这种屏幕非常伤眼睛——很多电子打过来。

* 逐行扫描与隔行扫描

    * 逐行扫描：控制电子从屏幕左上角开始画一道道水平线、换一行再画一道，从上往下画得足够密集，基本就可以覆盖整个屏幕。

    * **隔行扫描**：对每一张图只画一半——当前这个时刻画第一、三、五、七行这些奇数行，下一个时刻再画第二、四、六、八行这些偶数行，每张图的工作量减少一半。

    * 看不出缺行靠人眼的视觉暂留效应：每两幅画之间相隔的时间非常短，短暂的视觉停留在之前画过的东西上，每一次看到的都相当于一幅完整的画面。

    * 隔行扫描的思想直到现在还在一些视频压缩里起作用：相隔的两帧之间，这一帧只记录奇数行、下一帧只记录偶数行。

    * 代价：隔行扫描会造成严重的画面撕裂，特别是高速运动的画面——比如体育比赛，人物移动时会发生交叉的鬼影现象。

* 显存与屏幕显示

    * 显示器要显示什么，由内存中的一块区域决定：显卡里的内存叫显存，把这块区域映射到屏幕上，这就是现在屏幕显示的方式——显示的图像其实就是内存中的一块区域。

* **液晶显示器（LCD）**

    * 现在的主流是平板显示设备，主要是 LCD（此外还有 OLED 等各种各样不同的显示设备）；分辨率的两端：计算器是超级低分辨率的 LCD，可以看到一个一个的格子，手机则是非常高分辨率的显示器。

    * **视网膜屏幕**：分辨率高到已经超出了人的视网膜分辨率的屏幕。

    * 成像原理：一个像素有两组以不同方向排布的偏振光栅（偏振片）；光经过一个偏振片，只会留下在偏振片所规定方向上振动的能量。

    * 竖直振动的光过水平偏振片就什么都没有了；液晶显示的原理是通过液晶的扭曲，把光的振动方向渐渐地调过来（竖直扭成水平），光才能从第二张偏振片出去——这就是像素在发光的原理。

* **发光二极管（light emitting diode，LED）**

    * 一块板由发光二极管阵列构成：要么发光、要么不发光；有一些发蓝光、有一些发红光，颜色都是预先定义好的。

* **电子墨水屏**

    * 里面有黑色和白色两种墨水，经过不同的通电电压或模式发生翻转——黑的在上面还是白的在上面，以此控制到底看得见看不见字。

    * 短板：刷新率很低——改变一次每个像素黑色和白色的朝向要花肉眼可见的时间，翻页非常慢、看动画更不可能；好处是看起来非常自然。

## 三角形作为光栅化基本单元

* 三角形的表示能力很强：它当然可以表示三维空间中的形状，同样可以表示二维空间中的图形——一个很复杂的图形，其实是由很多不同的三角形构成的。

* 四条好性质

    * 最基础的多边形：没有比三角形边更少的多边形了，再少就退化成线段；而任何其他多边形，都可以拆成三角形。

    * 内部一定是平面的：给定三个点连成三角形，它一定得是平面的；四边形就不行，沿着某一条对角线一折就不再是平面的，三角形不可能这样。

    * 内外定义得非常清晰：多边形会带来各种神奇的问题——里面有洞怎么办、不是凸多边形怎么办——三角形不存在这些问题，而且可以通过向量的叉积判断一个点是不是在三角形内。

    * 顶点属性可以在内部渐变：只要定义三个顶点各自的属性，三角形内部任何一个点的属性就可以根据它与三个顶点的位置关系"猜"出来，得到从三角形一个顶点到另一个顶点的逐渐变化——这就是重心坐标插值方法。

* 光栅化要解决的核心问题

    * 一个像素内部不可能有颜色变化，那一个正好被三角形盖住大概一半的像素到底应该怎么算——是亮还是不亮？这归结为判断像素和三角形的位置关系，更确切地说是判断像素的中心点与三角形的位置关系。

## 光栅化的采样实现

* **采样**

    * > **定义**：给一个连续的函数，在不同的地方去问这个函数的值是多少——采样其实就是把一个函数给离散化的过程。

    * 采样在图形学里非常重要、涉及各种不同的采样：之后还会采样时间、采样位置、采样物体表面的反射性质；医学中的 CT、核磁共振得到的成像结果本身是三维的，要显示出来同样涉及采样。

    * 光栅化中的采样：利用像素的中心对屏幕空间进行采样——算出定义在屏幕空间上的某一个函数，在不同的像素中心它的值是多少。

* **`inside` 函数**

    * > **定义**：给定一个三角形和屏幕空间中任意一点的坐标 $(x,y)$——这个坐标不一定是整数、可以是任何实数——点在三角形里取 1、不在取 0。

    * 采样的对象就是屏幕空间中定义的这个 `inside` 函数：在不同的像素中心，确定这个函数的值到底是 1 还是 0。

* 光栅化循环

    * 两个 for 循环做的事情，就是把整个屏幕上所有的像素都考虑一遍，判断每个像素中心是否在三角形内：

    ```cpp
    for (int x = 0; x < width; ++x)
        for (int y = 0; y < height; ++y)
            image[x][y] = inside(tri, x + 0.5, y + 0.5);
    ```

    * 在内得到 1、不在得到 0，相当于让像素 $(x,y)$ 的值要么等于 0、要么等于 1，之后可以给它不同的颜色——这就是最简单的、通过采样进行光栅化的过程。

## 点在三角形内的判定

* 叉积判据

    * 机理：对三角形的每条边，做"边向量 × 边起点指向 $q$ 的向量"这个叉积（如 $\vec{p_1p_2}\times\vec{p_1q}$），用结果的 $z$ 分量符号（右手定则判断朝向）判断 $q$ 点在这条边的左侧还是右侧。

    * 判定规则：$q$ 若真在三角形内部，它一定同时处在 $p_0p_1$、$p_1p_2$、$p_2p_0$ 这三条边的同一侧——三个叉积的 $z$ 要么全是正的、要么全是负的，只有这两种情况判定在内。

    * 反例走一遍：$\vec{p_1p_2}\times\vec{p_1q}$ 得到的向量朝外、$z$ 值为正，$q$ 在 $p_1p_2$ 左侧；$\vec{p_0p_1}\times\vec{p_0q}$ 仍是左侧；但 $\vec{p_2p_0}\times\vec{p_2q}$ 得到的是朝里的向量，$q$ 在 $p_2p_0$ 的右侧——不同侧，$q$ 不在三角形内。

* 边序与顶点顺序

    * 顶点按某种循环顺序安排好，比如 $p_0p_1p_2$（或者 $a,b,c$），然后不断地重复它——$abc$、$abc$、$abc$——这样顺序就不会错，会依次找到 $ab$、$bc$、$ca$，而不是 $ac$。

    * 如果三角形的顶点是顺时针安排的——比如把 $p_1$ 和 $p_2$ 互换一下位置——那三个"在左还是在右"的测试就得全是"在右"，才能说明 $q$ 在三角形内。

    * > ⚠️ **易错点**：三条边必须按循环边序取（$p_0p_1$、$p_1p_2$、$p_2p_0$），不要漏掉首尾相接的那条边。

* 边界上的点

    * 如果有一点正好落在三角形的边界上，通常要么不做处理、要么特殊处理；这里不做处理——自己定义一个标准、自己把它说通即可：共享一条边的两个三角形，边界上的点算在三角形一、三角形二还是两者都算，由你规定。

    * > **提示**：一些图形学 API（如 OpenGL 和 DirectX）对此有非常严格的规定：点落在三角形的上边和左边，就认为在三角形内；落在右边和下边，就算不在。这个规矩相对复杂，没有必要特别去掌握。

## 包围盒加速

* **轴对齐包围盒（axis-aligned bounding box，AABB）**

    * > **定义**：由三角形三个顶点的所有 $x$ 取最小和最大、所有 $y$ 取最小和最大，围成的一个由水平边与竖直边构成的方形区域。

    * 加速规则：包围盒外的像素根本不可能碰到这个三角形，自然没有必要对它做光栅化；二重循环只需 $x$ 从 $x_{\min}$ 循环到 $x_{\max}$、$y$ 同样操作，不用把整屏的像素从 0 走到最大。

* 逐行找左右

    * 还可以更省：对三角形所覆盖的区域，每一行都找它对应的最左和最右——连一个像素都不会多考虑；当然说起来容易、做起来不太容易。

    * 适用场景：三角形挺窄长、又旋转过来（旋转 45 度）的时候，会出现"三角形没覆盖多少像素、包围盒倒覆盖了不少像素"的情况，正好倒霉——这时适合逐行法；不同的情况有不同的处理方法。

* 包围盒图示

    ```text
      ymax +---------+
           |   /\    |
           |  /  \   |
           | /    \  |
           |/_______\|
      ymin +---------+
           |         |
      +----+----+----+----> x
           ^         ^
         xmin      xmax
    ```

## 真实屏幕的像素结构

* 像素内部的真实结构

    * 拿两台显示同一个画面的手机对比就会发现：一个像素根本就不是一个小的方块。

    * iPhone：一个像素其实是由三个不同的条组成的——红、绿、蓝 RGB 三个不同的条放在一块，变成一个像素。

    * 三星 Galaxy：同样是红绿蓝三个颜色，但这三个颜色形成了某一种图案，叫 **Bayer 图案（拜耳排列）**——很难找出一个方块，把它圈起来说"这就是一个像素"。

* 绿色点更多的原因

    * 实测密度：Galaxy 上红点的密度和蓝点的密度基本一样，但绿点的密度明显比红色和蓝色都要高——因为人眼本质上对绿色这个颜色最为敏感，在绿色上多一些像素是有好处的。

    * 相机同理：很多相机的感光元件里，涉及绿色的感光元件就放得多一些——用 Bayer 图案的形式把这些元件以不同密度组织起来，得到在绿色上更好的还原，人眼看上去更舒服。

* 加色系统与减色系统

    * 屏幕：加色系统——RGB 的值越高，表示越亮、越靠近白色。

    * 彩色打印：减色系统——往上加的颜色越多，最后得到的结果越黑；把打印结果放大看，图案分布非常奇怪（斜着的蓝色、红色、黄色分布），打印过程中还会关注如何最省墨。

* 尽管真实结构如此，仍然认为屏幕上每一个像素是内部颜色不变的小方块，这么理解没有问题。

## 锯齿与走样

* **走样（aliasing）**

    * > **定义**：锯齿是俗称，它的学名叫走样；在光栅化图形学上就体现在锯齿上——三角形的尖角放大了看，全是密密麻麻的锯齿。

    * 成因：像素本身有大小；并且采样率对于这个信号来说是不够高的，所以产生了信号的走样问题。

    * 直接按"中心在内就整格填色"画出来的结果：一个由小方块拼出来的"类似三角形"——基本形状与三角形一致，但边缘全是台阶。

* **瑕疵（artifact）**

    * > **定义**：图形学里专门用它表示错误、不准确、一切不希望看到的结果——凡是看上去不太对的东西都叫 artifact。

* 采样无处不在

    * 光栅化是采样：在屏幕空间里，用一系列离散的点（像素的中心）对"是否在三角形内"这个函数进行采样。

    * 照片是采样：一张照片本质上是所有到达感光元件平面的光学信息，被离散成图像上一系列像素的过程；放大了看都是一个一个的格子。

    * 视频与动画是时间中的采样：把一系列的图按一定的时间间隔放出来（比如每秒 24 帧）就形成动画；每一帧都取自一个特定的时间点，在时间中并不连续——从来不存在连续意义上的动画。

* 三种典型的采样瑕疵

| 瑕疵 | 采样维度 | 典型场景 |
| :--- | :--- | :--- |
| 锯齿（jaggies） | 空间 | 三角形边界画出楼梯状 |
| 摩尔纹（Moiré） | 空间 | 去掉奇数行、奇数列再拼图放大；手机拍显示器屏幕 |
| 车轮效应（wagon wheel effect） | 时间 | 条纹纸片顺时针转却像逆时针转；高速行驶的车轮看起来倒转 |

    * 摩尔纹实验：把一幅图的奇数行、奇数列全部去掉，剩下的像素重新拼成一张小图、再按原来的大小显示出来——衬衫上原本方向明确的纹理完全扭曲，领带上一个个的格子变成一条条怪纹。

    * 车轮效应是**人眼在时间中的采样**出的问题：人眼在时间轴上采样，速度跟不上运动本身——和视频一个道理。

* 走样的根因

    * 信号的变化太快了，以至于采样的速度跟不上它——这种情况下采样就会产生 artifact，把这个 artifact 命名为走样。

## 反走样的操作定义

* **反走样（antialiasing）**

    * > **定义**：对抗走样的工作；关键操作就一步——在采样之前，先对信号做一次模糊，也就是滤波（filtering）。

    * 做法：先拿到三角形，对它做一次模糊操作，把它变成一个模糊的三角形；然后再用像素中心去采样这个模糊后的信号——有的点采到边界，变成粉红色；离边界远一点就偏白，近一点就偏红。

    * 效果：即使放大了看，也没有之前那么严重的锯齿——对原始信号先做模糊（滤波）再去采样，就能抗锯齿。

* 模糊与采样的顺序不能换

    * 正确顺序（先滤波，再采样）：原始信号 → 模糊/滤波 → 像素中心采样 → 边界平滑的结果。

    * 错误顺序（先采样，再滤波）：原始信号 → 像素中心采样 → 已经走样的结果 → 模糊/滤波——产物叫 **blurred aliasing（模糊的走样）**：它其实还是走样，只不过是走样了之后又被模糊了一道，跟反走样完全是两回事。

    * > ⚠️ **易错点**：模糊和采样的先后顺序不能换——先滤波再采样才是反走样；先采样再滤波，得到的不是想要的结果，只是 blurred aliasing。

## 频率与傅里叶变换

* **频率（frequency）与周期（period）**

    * 把余弦写成 $\cos(2\pi f x)$，$f$ 就是它的频率：$f=1$ 对应 $\cos(2\pi x)$，$f=2$ 对应 $\cos(4\pi x)$，变化明显比 $f=1$ 快——频率 $f$ 刻画了余弦波变化的快慢。

    * **周期**：每隔多少函数会重复自己一次，是频率的倒数 $T=\frac{1}{f}$——$f=1$ 的余弦波每隔 1 重复一次，$f=2$ 的那个每隔 0.5 就重复一次。

* **傅里叶级数展开**

    * > **定义**：任何一个周期函数，都可以写成一系列正弦函数和余弦函数的线性组合，外加一个常数项。

    * 例子（周期重复的 box 函数，像城墙一样突然凸出来一块、突然又没了）：先用常数项 $A/2$（$A$ 是 box 的高度）把函数的中心往上提；再叠上频率最低的余弦，出来就算一个近似；继续引入算出来的系数（如 $\frac{2}{3\pi}$）、加上频率更高的余弦，近似就更准确；加到无限多项，就无限接近这个周期函数（此例只有余弦、没有正弦）。

    * 各项的角频率 $\omega$、$3\omega$、$5\omega$、$7\omega$ 各不相同，本身就代表不同的频率——傅里叶级数展开说明：任何一个函数，都可以分解成频率从低到高排列的各个成分。

* **傅里叶变换（Fourier transform）**

    * > **定义**：把一个函数变成一段段不同频率的成分，并把各个频率上的内容显示出来。

    * 小写的 $f(x)$ 经过一个相当复杂的操作变成大写的 $F(x)$，一个函数变成了另一个函数；大写的 $F(x)$ 还能通过**逆变换**变回原来的 $f(x)$——能变过去、也能变回来。

* 采样效果与函数频率的关系

    * 用完全相同的采样方法（每隔同样长的一段采一个点）对五个频率从低到高的函数 $f_1$ 到 $f_5$ 逐个采样：$f_1$、$f_2$ 把采样点连起来基本能恢复出原来的函数；$f_3$ 恢复得相当勉强，尤其后半段越离越远；$f_5$ 凭这些采样点能恢复出来的东西与实际完全比不了。

    * 道理：采样间隔很小就是采样很密、采样频率很高，自然能恢复出频率很高的函数；函数本身频率很高而采样频率很低，就跟不上它的变化，原始信号恢复不出来——采样好不好，与函数自身的频率非常有关系。

* 走样的频率定义

    * 用同一种采样方法去采两个频率截然不同、真实存在的函数，得到的采样点是**完全相同**的——同一串采样点拿去描述哪个函数都行，无法通过采样结果把它们区分开。

    * > **定义**：走样（aliasing）——同一种采样方法，采样两种不同频率的函数，得出来的结果无法区分。

## 频谱与滤波

* **频域（frequency domain）**

    * 傅里叶变换可以把一个函数从时域变到频域；图像本身不含任何时间信息，但把空间上不同的位置也叫作"时域"——这只是个名字而已。

* **频谱**

    * > **定义**：这种"信号在各个不同频率上长什么样"的表示，就叫频谱。

    * 读法：中心是最低频，从中心向外频率越来越高，亮度表示该频率上信息的多少。

    * 自然图像的普遍规律：大多数信息集中在低频上（中心比较亮）；高频信息有，但相比低频少太多。

    * 频谱里水平和竖直两道特别明显的亮线：分析一个信号时会把它当作周期性重复的——图像在水平、竖直方向都叠了无限多张，可很少有图像的右边界和左边界完全一致，拼接的地方发生剧烈的信号变化、产生极其高的高频；为了分析图像内部的事情，忽略这两条线。

* 频谱读法图示

    ```text
    +--------------+--------------+
    |              |              |
    |      H       |      H       |
    |--------------*--------------|
    |              |              |
    |      H       |      H       |
    |              |              |
    +--------------+--------------+

    H = 高频区域
    * = 中心：最低频，自然图像上最亮
    向外 = 频率越来越高
    亮度 = 该频率上信息的多少
    ```

* **滤波（filtering）**

    * > **定义**：把某个特定频段的内容抹掉、删掉，看对应的信号会发生什么变化——滤波就是去掉一系列频率。

* **高通滤波**

    * 操作：把频谱上低频的信号完完全全抹掉、只留下高频，再用逆傅里叶变换变回图像；别搞错，高通滤波器意味着最后只剩下高频。

    * 结果：提取出图像内容的边界（比如衣服的轮廓和背景差得很多的地方）——不是图像四边的那个边框，是内容上的边界。

    * 原理：边界就是图像上某个地方左边跟右边（或上边跟下边）突然发生突变、差得很多；剧烈变化的信号就是信号本身蕴含的高频信息，让高频通过自然就把边界找了出来。

* **低通滤波**

    * 操作：只留下低频信息，把所有高频信息全抹掉，再变回图像。

    * 结果：得到一张**相对模糊**的图——基本还能看清是个人，但绝大部分细节（比如衣服上的褶皱）就再也看不见了；边界被去掉了，图像看起来就不再有原本边界的概念。

* **带通滤波**

    * 操作：高频去掉、低频也去掉，只留下中间某一段频率——不算特别高，但也不是低频。

    * 结果：提取到一些**不那么明显**的边界特征——最明显的边界特征对应最高的频率（外面一圈已被去掉），大面积相同的色块是低频（也被去掉），剩下的自然就是中间状态的信息。

    * 把保留的圈往外扩、留下频率更高的外面一圈，看到的结果就更偏高频的边界特征。

## 卷积与卷积定理

* **卷积（convolution）**

    * > **定义**（图形学简化版）：信号在任何一个位置，对它周围区域做一次加权平均。

    * 机理：把滤波器（filter）想象成一个可以在信号上滑动的窗口，窗口有大小、每一格上面写着一个数；窗口滑到某个位置时，把它盖住的几个数与窗口上对应的几个数一一相乘、再相加（也就是做点乘），把结果写回窗口中心那个格子。

    * 一维算例：三格窗口 $[\frac{1}{4},\frac{1}{2},\frac{1}{4}]$ 对准信号上的 $1,3,5$，得 $1\cdot\frac{1}{4}+3\cdot\frac{1}{2}+5\cdot\frac{1}{4}=3$，写回中心那个格子；窗口向右移动一格、盖住 $3,5,3$，得 $4$；窗口一路滑过去，每个位置都得到一个"周围一圈的加权平均"。

    * 这是简化了的定义，不是数学上的严格定义（严格的要到信号系统课里见）；对图形学来说，记住"卷积 = 信号在任何一个位置对它周围区域做一次加权平均"就够用了。

* **卷积定理**

    * > **定义**：时域上对两个信号做卷积，等价于在频域上把两个信号各自的频谱做乘积；反过来，时域上的乘积对应频域上的卷积。

    * 由此做卷积有两条等价的路：直接拿一幅图、用某个滤波器对它做卷积操作；或先把图变换到频域、把卷积用的滤波器也变换到频域，两者相乘得到频域结果，再做逆傅里叶变换变回时域——两条路做出来的东西一样。

    * 验证（$3\times3$ 平均 = 模糊）：用 $3\times3$ 卷积核对任何一个像素取周围九个数求平均、写回这个像素，得到的就是一幅模糊的图像；把这个核变换到频域，它会变成一幅几乎全黑、只有中心留下一块白的图（绝大部分能量集中在中心低频；细看中心之外还有环状纹路，是不完美的低通滤波产生的问题）——两个频谱乘起来等于只让原图留下最低频，逆变换回去正是模糊图像，结果对上了。

* 卷积核的归一化

    * 九个格子全是 1、再统统乘 $\frac{1}{9}$：如果系数全是 1，任何一个像素都会变成周围九个像素之和，图像岂不是越滤波越明亮；做归一化之后，卷积就不会引起整幅图亮度的变化。

* box filter 就是低通滤波器

    * 盒子形状的滤波器放到频域上只留下低频的部分——这个 box filter 就是我们所说的低通滤波器。

* 盒子大小与频域范围

    * 规律：**盒子在时域上变大，它在频域上反而变小**——听起来违反直觉，但完全正确。

    * 把 $3\times3$ 换成 $21\times21$、$63\times63$ 的大盒子，对任何像素取周围一大块区域再平均，结果肯定越来越模糊——越大的盒子越模糊。

    * 两个极端：用一个比图像还要大的超级大盒子，所有像素全被加起来，各处结果基本都一样；用一个比一个像素还小的超级小盒子，那等于完全没做滤波——它对应频域上的范围就会超级大，把所有的频率都留了下来。

## 采样的频域本质

* **冲击函数**

    * > **定义**：只在那个位置有值、别处没有值的函数，画出来是一根根竖着的箭头。

* 采样 = 重复原始信号的频谱

    * 推导：有一个连续函数 $a$，它的频谱（傅里叶变换的结果）记作 $b$；"把连续函数变成一系列离散的点"（只留下某些位置上的函数值）等价于拿 $a$ 去乘另一个函数 $c$——$c$ 只在一系列固定间隔的位置上有值、其他地方一概为零，即一排冲击函数；乘出来的 $e$ 就是一系列离散的点，正是采样留下来的结果。

    * 时域上做了乘积，频域上对应卷积（卷积定理）：一排冲击函数经过傅里叶变换，还是一排冲击函数，只是间隔不一样了（记作 $d$）；把 $a$、$c$ 各自的频谱 $b$、$d$ 在频域上卷积起来得到 $f$——原始函数明明只是被采了样，它的频谱却被**复制粘贴**了很多份。

* 采样密度与混叠

    * 时域和频域的相反关系：**采样越稀疏（采样点之间的距离越大），频谱拷贝之间反而越密集**——复制得多密，由采样间隔决定。

    * 采样率不足、采得不够快时，一份份频谱拷贝就会挤到一块儿，原始频谱和相邻的拷贝叠在一起、混在一起——这种频谱在复制（搬移）过程中发生混合的情况就叫**混叠**，它就是走样产生的原因。

    * > **定义**：从频率的角度说，走样（aliasing）就是采样后频谱的各份拷贝相互混叠。

* 频谱拷贝密度图示

    ```text
    采样足够快（点密）：  [谱]········[谱]········[谱]········
    采样不够快（点稀）：  [谱]····[谱]····[谱]····
                          相邻拷贝挤在一起、相互混叠 -> 走样
    ```

* 拿回光栅化验证

    * 像素非常小、非常密，相当于对这个信号采样得很密集，走样现象就会少很多；每个像素都很大、像素中心间隔很大，相当于稀疏采样，走样就很严重。

## 反走样的频率解释

* 两条思路

    * 思路一：增加采样率——这是终极解决办法。一台古老的 $640\times480$ 显示器，一个像素非常大，锯齿一眼就能看见；换成分辨率几千乘几千的视网膜（Retina）显示器，像素变小、像素间隔变小——意味着采样频率变高，频域上频谱拷贝的间隔变大，就不容易出现混叠。但这不是反走样要做的事情：反走样是在同一块屏幕上完成的，不可能靠打开某个抗锯齿选项就让分辨率涨上去，受物理限制。

    * 思路二：先模糊，再采样——把操作定义翻译成频率的语言：模糊就是低通滤波，把信号的高频信息先拿掉；高频被砍掉之后，频谱变窄了；这时再用原本那个稀疏的采样率去采样，频谱拷贝之间不再重叠，混叠不发生。

    * 图景：原始频谱是一个梯形，按原来的稀疏采样率直接复制粘贴，相邻拷贝会混叠；先把超出某个范围的高频统统砍掉不要，剩下的频谱覆盖的面变小了，再按原本的间隔复制粘贴，就不混叠了。

* 把三角形变模糊：按覆盖率求平均

    * 方案定了之后，所有难度都集中在滤波这一步：用一个一定大小的低通滤波器对三角形做卷积，而卷积就是平均——任何一个位置取它周围一块区域、把这块区域的结果平均起来。

    * 取什么样的块？最简单的块就是一个像素：像素自己正好是一个小方块，而这个小方块就是一个 box filter、低通滤波器，起的作用正是模糊。

    * 原本的三角形是个二值函数（一个点要么在三角形内、要么在外）；拿每个像素对应的小 box 对它做卷积求平均——像素内部被三角形覆盖了多少比例的面积，这个像素就取多大比例的三角形颜色：覆盖 $\frac{1}{8}$，像素就是 $\frac{1}{8}$ 的三角形色加 $\frac{7}{8}$ 的背景色（87.5% 的白）；覆盖一半，就是一半对一半；完全覆盖，就是全黑。

    * 困难：怎么把三角形在某个像素内部覆盖的精确区域算出来？不容易，计算量也不小——所以人们研究出了一种近似方法。

## MSAA 与其他抗锯齿方案

* **多重采样抗锯齿（Multisample Antialiasing，MSAA）**

    * > **定义**：用更多的采样点来做反走样的近似方法——注意它是对反走样的**近似**，并不能严格意义上解决走样问题。

    * 机理：原本一个像素只用一个点判断在不在三角形内；现在把一个像素划分成许多小的采样点（比如 $4\times4$ 十六个），每个小点各自判断是否在三角形内，再把判断结果平均起来——这就是三角形对这个大像素覆盖区域的近似。

    * 覆盖率数值例（最简单的 $2\times2$ 四个点）：某像素四个点全在三角形外，覆盖率是 0，像素保持背景色；四点里三个在内、一个在外，覆盖率是 75%，像素写成 75% 的三角形颜色；只有一个点被"感知到"在三角形内，覆盖率 25%，这个像素就写成 25% 的红色。

    * 采样点越密近似越准：$100\times100$ 个点可以得到相对准确的结果；$4\times4$ 不太准，但没关系，效果已经挺好。

    * MSAA 近似的是反走样的第一步——模糊：每个像素内部求完平均、知道了覆盖率之后，像素里已经是同一个颜色，第二步采样变得无比简单（在格子中间采出来的就是这种颜色）；采样这一步其实隐含在了整个过程里。

    * > ⚠️ **易错点**：MSAA 绝对不是靠提升分辨率来解决走样问题的——屏幕上该多少像素还是多少像素，加的那些采样点只是为了近似一个合理的三角形覆盖率，并没有真的提高屏幕的分辨率。

* 代价与工业界的变通

    * no free lunch（没有免费的午餐）：为了抗锯齿牺牲的是计算量——用更多的点去测试是否在三角形内，$4\times4$ 就是 16 倍、$2\times2$ 就是 4 倍。

    * 变通：工业界并不把像素规则地划分成 $4\times4$、再取这些子像素的中心，而是用一些更有效的图案来分布这些采样点，而且有一些点还会被相邻的不同像素复用。

    * 因此打游戏的时候开 4 倍 MSAA，帧率并不会掉到原来的四分之一——很多样本被复用了；这反过来印证这些点不是用来提高分辨率的，仅仅是为了检测三角形的覆盖。

    * 至于什么样的分布图案能达到最好的覆盖效果（会涉及一些随机数、样本分布的技巧），在光线追踪那一块展开。

* **快速近似抗锯齿（Fast Approximate Antialiasing，FXAA）**

    * > **定义**：一种**图像的后期处理**——先拿到一幅有锯齿的图，然后通过一些图像匹配的方法把这些锯齿的边界找到，再把它们换成没有锯齿的边界。

    * 它和增加采样数没有任何关系；非常快。

    * > **注意**：FXAA 不是"对有锯齿的图做模糊"——先采样得到锯齿、再回头去模糊是不对的（有兴趣可以从频率的角度自己分析为什么）。

* **时间抗锯齿（Temporal Antialiasing，TAA）**

    * 最近几年才刚刚兴起的一种抗锯齿方法，非常简单高效；T 是 temporal，意思就是与时间相关。

    * 思想：**复用上一帧的结果**——假设场景是静止的，相邻两帧显示的东西一样，但相邻两帧可以用像素内部不同位置上的点去感知三角形，于是不同帧里边界有时出现、有时不出现；把上一帧每个像素的值拿到这一帧继续发挥作用。

    * 效果上相当于把 MSAA 对应的那些样本分布到了时间上，而在当前这一帧没有引入任何额外的操作——非常聪明的做法。

    * 运动的物体怎么办：实时光线追踪那边的核心思想和 TAA 一样（此处未展开）。

    * 工业界习惯：temporal 这个词本身还有"暂时性"的意思，为了避免误会，美国的同行们倾向于不按整词念，而是按字母把它念成 T-A-A。

* 三种抗锯齿方案对比

| 方法 | 核心思路 | 特点 |
| :--- | :--- | :--- |
| MSAA | 像素内加采样点，近似三角形覆盖率 | 近似的是"先模糊"这一步，代价是计算量 |
| FXAA | 后期处理：找到锯齿边界并替换 | 与采样无关，非常快 |
| TAA | 复用上一帧结果，把样本分布到时间上 | 当前帧零额外操作 |

* **超分辨率（super resolution）与 DLSS**

    * 超分辨率：给你一张 $512\times512$ 的图，要把它拉大到 $1024\times1024$——直接拉大，看的全是锯齿；本质是其实存在一幅 1k×1k 的高分辨率图，只是你的采样率不够、采到的结果只有 $512\times512$，想把这幅高分辨率的图恢复出来。

    * 从这个角度看，超分辨率和抗锯齿（比如 MSAA 做的事情）非常相似：**都是在解决样本不足的问题**。

    * DLSS：把小图拉大之后肯定有些细节缺失，缺失怎么办——猜出来就好了；给它足够多的经验性的东西，让它学会在任何一个局部应该如何把细节补上去，这正是深度学习擅长的事情。
