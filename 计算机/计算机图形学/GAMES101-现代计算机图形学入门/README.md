# GAMES101：现代计算机图形学入门（闫令琪）（23 讲）

闫令琪老师的 GAMES101 是中文图形学入门的标准课：从线性代数与变换讲起，经光栅化、着色与纹理、几何表示，到光线追踪、路径追踪、材质、相机与颜色，最后收在动画与物理仿真。课程沿着渲染管线本身的顺序展开，概念与实现并重。23 集整编为 9 册模块全书与 13 篇主题笔记。

## 怎么学
- **按「变换 → 光栅化 → 着色 → 几何 → 光追」主线走**，这正是渲染管线的顺序。
- **每讲配套的编程作业要真做**：变换、光栅化、路径追踪三次作业是理解的关键。
- **矩阵与投影自己推一遍**：MVP、正交/透视投影、视图变换，推导比记公式可靠。
- **光追部分抓住渲染方程**：Whitted → 路径追踪 → 重要性采样，一条线下来。
- **材质与颜色别跳**：BRDF、微表面、伽马与色彩空间，决定最终画面质感。
- **动画部分当扩展**：关键帧、质点弹簧、运动学，为 GAMES103/105 铺路。
