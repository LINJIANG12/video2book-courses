# 物理动画概述与数学基础

## 图形学与图形学管线

* **图形学**

    * > **定义**：构造一个 3D 虚拟世界，并把它以 2D 的形式呈现出来。

    * 三大方向：几何——怎么样构造这个 3D 世界；渲染——怎么样把 3D 世界转化成 2D 呈现出来（今天大部分显示设备都基于 2D 图片、基于像素）；动画——怎么样让 3D 世界运动起来，静态世界不真实，真实世界里物体都有运动。

    * 与计算机视觉是两个完全相反的方向：图形学从 3D 到 2D，计算机视觉从 2D 图像去理解影像中的 3D 场景；两者都围绕 3D 与 2D 之间的关系做文章，所以论文有相当一部分重复。构造 3D 世界有时也会用到视觉的东西，例如从真实影像出发做三维重建。

    * 典型应用：娱乐（游戏、电影特效、数字人等轻娱乐产品）、CAD 与 CAE（机械、建筑、艺术设计、时尚）、电商与智能制造（数字化商品展示、下单后反向制造实物）、元宇宙与 VR/AR/MR——要构造虚拟世界就离不开图形学。

* **图形学管线（pipeline）**

    * 理想情况下的实时管线：几何构造出 3D 虚拟世界 → 动画让世界里的物体动起来 → 渲染把 3D 虚拟世界转化为 2D 图片 → 显示设备把图片呈现出来。

    ```text
    ┌────────────┐    ┌────────────┐    ┌────────────┐    ┌────────────┐
    │    几何    │ -> │    动画    │ -> │    渲染    │ -> │    显示    │
    │ 构造3D世界 │    │让世界动起来│    │  3D转成2D  │    │ 呈现给用户 │
    └────────────┘    └────────────┘    └────────────┘    └────────────┘
    ```

    * 几何一般来说不需要实时：完全可以离线操作，借助辅助工具、甚至计算机视觉算法把 3D 世界构造出来。

    * 动画跟渲染必须是实时的：需要玩家的操作能够马上对虚拟世界产生影响，让用户或玩家立刻看到这些操作带来的效果。

## 帧率与实时的折中

* **帧率（frame rate）**

    * > **定义**：显示设备以多快的速度去展示这些渲染出来的帧。

    * 典型值：传统电影 24 帧——对肉眼来说基本上已看不出不连续的效果；游戏 30 帧、60 帧都有；交互性强的竞技类游戏可到 160 帧；图形学里一般来说标准的帧率是 30 帧每秒。

    * 帧率高低主要取决于交互：游戏是强交互应用，玩家的操作要很快在游戏里体现，交互性强的游戏只有 30 帧就会有延迟、卡顿；电影没有交互，帧率要求就比较低。帧率跟交互有关系，跟用户体验也有关系。

* **实时做不到时的三种形态**

    * 根源是计算量与硬件计算能力有限：想要非常真实、逼真的效果，硬件可能撑不住这样的计算量。按交互需求折中——交互要求越高，需要实时跑的环节就越多；完全没有交互就可以全部离线，花几周甚至几个月的计算时间去换更逼真的效果。

| 应用形态 | 动画 | 渲染 | 典型场景 |
| :--- | :--- | :--- | :--- |
| 全实时 | 实时模拟 | 实时渲染 | 需要交互的游戏 |
| 动画离线、渲染实时 | 事先录制、回放 | 实时 | 游戏过场动画、电商商品展示 |
| 全离线 | 离线 | 离线 | 数字电影 |

## 几何的三种表达

* **网格（mesh）**

    * > **定义**：用顶点加多边形（多面体）元素来描述物体的几何表达方式，如 Stanford bunny 的表面由三角形描述。

    * 两部分构成：覆盖在物体身上的顶点，加上由这些点构成的多边形／多面体元素；元素取决于内容——三角形最常见，四边形在 Maya 这类设计软件里常用（比较符合大众设计习惯），做软体、弹性体模拟时元素是四面体。

    * 三角形是整个图形学的基础：整个图形学的硬件、GPU 显卡，整套都是基于三角形渲染框架的。

* **围绕网格的经典问题**

    * remeshing（重新剖分网格）：调整三角形网格、让三角形有比较好的质量——不希望出现很窄、很细的三角形，希望大部分三角形比较正、接近 60° 的正三角形。

    * 简化：硬件没有办法支持很多三角形时，减少三角形数量，同时不希望 mesh 的形状发生很大改变；反过来的操作是细分——增加三角形。

    * 优化：对 mesh 做平滑、计算 mesh 上面的 flow 等。

    * volume mesh（体积网格，如四面体网格）处理起来的难度比三角形网格大非常多——这也是做四面体网格、做有限元分析是一个难点的原因。

* **结构化与非结构化网格（structured / unstructured mesh）**

    * structured mesh 有一定规律性：方方正正的格子、基于六边形的 mesh、对球形按足球的形状做特殊分解等。

    * unstructured mesh 没有什么规律、比较"乱七八糟"；最大的好处是通用，对结构没有什么要求。

    * structured 的规律可以被一些模拟算法、几何算法利用来做简化、优化；volume mesh 同样分 structured 与 unstructured 两种。

* **点云**

    * > **定义**：用一大堆点把物体描述出来的表达方式，不需要考虑三角形、不需要考虑三角形之间的连通关系。

    * 最大的好处是简单，因此通常以"原始数据"的身份出现——用 3D 扫描仪扫一个物体，得到的原始数据往往就是一大堆点云。

    * 三个核心问题：怎么从点云构造出 mesh——直接给一坨点没有办法用硬件做渲染；怎么对点云重新采样——点云往往有的地方疏、有的地方密，要让稀疏程度一致；怎么找近邻——给一个点，知道它周围有哪些点，很多算法都要用到近邻查询。

* **格子（grid）**

    * > **定义**：把三维空间划分成很多小方块、小格子，每一个块叫一个 cell，每个 cell 里储存了一定物理量的表达方式。

    * 最常见于医学和科学实验的原始数据：如 CT、大气的流体模拟。

    * 主要问题是内存消耗会很大：三维空间划分得非常细就需要大量内存；可以用 octree（八叉树）之类的结构减少内存占用，但总的来说内存始终是一个问题。

    * 渲染有两条路：把它转化成 mesh 再渲染；或者直接对 volume 的 grid 做渲染——volumetric rendering，本身是图形学里的一个研究课题。

    * > **提示**：mesh 和 grid 怎么区分？mesh 是定义在物体上的——三角形或多边形组成的网格，贴着物体走；grid 是定义在整个 3D 场景上的——把空间细分成一个一个小格子的体系。记住这一句就够用了。

## 渲染与材质获取

* **真实感与非真实感渲染（photorealistic / non-photorealistic rendering）**

    * 渲染分成两个大内容；大家比较熟知的是 photorealistic rendering——non-photorealistic rendering 这个领域近几年衰败得特别厉害、做研究的人特别少，但游戏、设计软件、绘画软件里仍有很多地方用到它的技术。

    * photorealistic rendering 主要有两种类型：基于光线追踪、基于传统渲染管线；做了光线追踪（如 NVIDIA RTX 的开关对比）之后，可以产生更好的折射、反射效果。

* **材质获取**

    * 光是有渲染引擎是没有用的，还需要有材质；怎么扫描材质、怎么把做出来的效果弄得跟真实的一模一样，是蛮大的挑战，研究得相对较少。例：用扫描仪扫描皮革，再用扫出来的数据做渲染，效果非常逼真。

* **light stage 与人体渲染**

    * light stage：把一个房间布满各种各样的灯光和摄像头，利用不同的灯光、摄像头不同的位置，捕捉人体在不同角度、不同照明情况下的效果，把一个人的整个渲染外观捕捉出来。

    * 最大的问题是构造 BRDF；对人体还有一个更大的挑战：人体皮肤不是 BRDF，而是 BSSRDF——光打到皮肤上之后会进去，然后从另外的地方出来，不是一个简单的在表面做反射的模型，这就是人体渲染特别难、特别有挑战性的原因。

    * 人对自身是很了解的：看到一个人渲染得特别不像，第一时间就能看出来；对相对来说没那么了解的东西（比如很多长得特别一样的猫狗），容忍程度就会高一点。

## 动画的本质与时间步长

* **计算机动画**

    * > **定义**：动画本质上就是在每一个时间点上更新物体的状态——设定时间点 $t_0, t_1, t_2, \ldots, t_n$，每个时间点上把物体状态更新一遍，动画就做出来了。

    * 需要更新什么状态取决于动画内容：位置、姿势、速度；也可以更新外观——如变色龙、火焰的颜色；还可以更新密度——如烟雾动画。

    ```text
    t0 --dt--> t1 --dt--> t2 --dt--> ... --dt--> tn
    |          |          |                     |
    更新状态    更新状态    更新状态          更新状态
    ```

    * 讨论物理模拟时主要讨论的就是一个问题：怎么在一个时间步长里面更新这些状态。

* **步长（time step，$\Delta t$）**

    * > **定义**：相邻两个时间点之间的间隔，记作 $\Delta t$。

    * 步长可以跟帧率一致，但不要求必须一模一样：步长完全可以取得更小一点，此时渲染一帧可能需要模拟更多个时间步——取决于引擎怎么设计。

    * > **提示**：时间步长和帧率是两码事——模拟按 $\Delta t$ 一步一步推进、渲染按帧出画面，二者不必严格对齐。

* **角色动画与物理动画（character animation / physics based animation）**

    * 动画分为两类：基于人体的 character animation（角色动画）；基于物理的 physics based animation——利用物理去求解、把动画效果做出来。

    * 现实的图形学应用里两者不分家：人要穿衣服、要跟整个环境有交互，既需要人的动画也需要物理的动画。例：虚拟数字人由真人演员动作捕捉、经游戏引擎实时驱动，既有人体的模拟、人体的动画，也有物理模拟的动画。

## 物理模拟的四大对象

* **四大模拟对象**

    * 刚体（rigid body）；衣服跟头发——比较窄、比较细的物体归为一类；弹性体，也就是软体（soft body）；流体——液体和气体一般来说当作一类流体来处理。

    * 针对四大类，配上三种表达方式 mesh、particle、grid，就有三种相对应的模拟技术。

* **mesh 是主阵地**

    * 刚体、头发、衣服、弹性体一般来说都用 mesh：这些物体整个形态比较固定，不会发生剧烈的撕裂或断裂，基本上是一个整体；弹性体形变会比较大一点，但它还是一个整体。

    * 这些 mesh 模拟的例子基本都不是实时的——差不多要一秒以上才能算一帧。

* **例外：粒子与格子**

    * 刚体的破裂可以按 meshless（无网格）方式、用粒子去模拟：没有 mesh，意味着物体碎裂的时候不需要去处理 mesh，这是最大的好处。

    * 衣服、头发也有人用 grid 或类似 MPM 的 hybrid 方式去模拟，主要原因是要减少碰撞处理、把碰撞简化；但总的来说是比较实验性质的、不是通用的处理方式——带来好处的同时局限性也很强，比如计算量可能很大、处理细节处理得不好。

* **对象与表达的对应**

| 模拟对象 | 首选表达 | 理由与备注 |
| :--- | :--- | :--- |
| 刚体 | mesh | 形态固定；碎裂可用粒子（meshless），省掉 mesh 处理 |
| 衣服、头发 | mesh | 也有 grid/MPM 类 hybrid 的实验性做法，目的是简化碰撞 |
| 弹性体（软体） | mesh | 形变大，但仍是一个整体 |
| 流体（液体、气体） | particle、grid | 烟走粒子法+网格法；水滴与波 mesh 可实时、grid 更逼真；水花复杂多变，以 particle/grid 为主 |
| 雪、粘滞物体 | hybrid（MPM） | 既有 particle 属性又有 grid 属性 |

## 流体模拟的方法选择

* **烟**

    * 一般用粒子法跟网格法；实时引擎计算量有限，3D 的烟比较复杂做不了，2D 的烟模拟可行。

* **水滴与表面波**

    * 水滴跟水波基本还是一个整体、不会那么容易分裂出来，所以可以用 mesh 来模拟波、模拟水滴，而且基本上可拿来做实时的模拟；grid 可以拿来做比较真实、逼真的模拟——取决于需求。

    * 把小波（wavelet）引入水面模拟，可以实时地模拟水面波：不只有大的浪花，很细的波纹也可以实时模拟出来，而且这个波能跟物体交互。

    * 流体主要就是解 Navier–Stokes 方程，所以对波而言，正常的反射、折射、衍射都会有。

* **水花**

    * 非常多变、非常复杂，模拟起来相对不容易做到实时；基于 mesh 做水花可以做，但更多是实验性质的；大家采用的主要是基于 particle 和基于 grid 的方式。

    * SPH 模拟水花的效果很好；实时引擎（如 Unity）局限性强，光靠它做不了这种效果，需要 OpenGL 或类似的其他图形引擎。

## Hybrid 方法与耦合

* **混合方法（hybrid）与 MPM（Material Point Method）**

    * hybrid（混合）方法把这些方法结合在一起；比较典型的就是 MPM——particle 跟 grid 相结合的方法，目的是既有 particle 的优点、也有 grid 的优点。

    * MPM 最常见的例子是做雪、做各种粘滞物体：粘滞物体最大的特点是既有一些 particle 属性、也有一些 grid 属性，所以用 hybrid 最常见、最通用；血、沙子也适合用 MPM 模拟。

    * 反过来，做刚体、做衣服、做弹性体，用 hybrid 可能就不合适，用 mesh 是更好的选择。

    * MPM 是一个比较小众的 hybrid 算法：它不是单一的方法，本质上是把粒子法跟网格法合在一起；懂了粒子法、也懂了网格法之后，再去学 MPM 相对来说会容易很多。

* **耦合（coupling）**

    * 场景里可能既有刚体、也有衣服、也有弹性体、也有流体，怎么模拟这几种不同的物质之间的交互——水落在衣服上、水落在弹性体上、衣服穿在人身上而人又是一个弹性体等——是这个方向研究得比较重要的一个课题。

## 刚体、软体与形变

* **刚体与软体的边界**

    * 硬的东西就是认为它没有形变：做刚体模拟时假设刚体是无形变的；任何有形变、可以观察到形变的，都把它认为是软体——关键就看它有没有形变。

    * 例：简单的游戏里，轮子只是车辆的一个附件、只做一个滚动，可以把它认为是刚体；要单独模拟一个轮胎——让它从天上掉下来、产生弹性的效果——就可能需要把它做成弹性体。

* **形变三阶段**

    * 第一阶段弹性形变（elastic），第二阶段塑性形变（plastic），最后是破碎（fracture）——严格意义上讲，这三个阶段都是形变。

    * 塑性可以认为是弹性的一个延伸；塑性形变（plastic deformation）的例子：一堆橡皮车撞在一起，撞完之后发生永久形变、被撞成各种奇奇怪怪的形状。

* **游戏引擎里的 fracture**

    * 游戏里的 fracture 效果——一面墙被打碎、一辆坦克给炸飞——一般都是通过预计算来处理的，不是模拟出来的。

    * fracture 实时模拟难做的原因之一：一大块工作是关于 remeshing 的，而 Unity 处理 remeshing 会比较复杂。

* **软体与约束类方法**

    * 软体主要讲弹性体：重点是有限元（FEM）跟超弹性模型（hyperelastic model），在这个基础上再扩展一些数值方法上的内容；碰撞处理跟碰撞检测会专门拿出时间来讲。

    * PBD（Position Based Dynamics）事实上可以归成一种类型：constraint-based approach，基于约束的方法；同类技术还有 Projective Dynamics，以及基于拉格朗日算子的 constrained dynamics。

## 矢量基础

* **矢量（vector）**

    * > **定义**：有方向的含义、也有大小的含义的量；三维矢量写作 $\mathbb{R}^3$——$\mathbb{R}$ 表示实数空间、上标 3 表示三维空间，由它在三个坐标轴上的投影 $p_x, p_y, p_z$ 表示。

    * 原点是一个比较特殊的矢量：$(0,0,0)$，三个方向投影都是零，相当于一个初始点。

    * 3D 矢量可以描述点、速度、力，还有一些线——所有跟线有关的表达都可以用矢量来描述。

* **书写约定：用字体区分，不用箭头**

    * 手写时矢量上面放一个箭头；但印刷体、论文里一般不这么写——每个矢量都带箭头的话整个论文里到处是箭头，特别乱。

    * 论文里用字体区分：矢量一般用黑体（bold），标量一般用斜体；为了区分矢量和矩阵，还用大写跟小写来区分。读论文要特别注意字体。

    * 同形不同义的例子：投影点用黑体大写 $\mathbf{s}$（矢量，是个位置），投影距离用斜体小写 $s$（标量，表示大小）——两个 $s$ 长得一样，字体不同、含义不同。

* **右手系统与左手系统（right-handed system）**

    * 右手系统判定：右手四个手指从 $x$ 转到 $y$，大拇指指向的方向就是 $z$ 的方向；图形学研究一般来说用右手坐标系，OpenGL 一般也是右手系统。

    * 左手系统也很常见：Unity 是左手的，DirectX 也是左手的；不要默认好像都是右手或都是左手——不同系统用的坐标系不一样。

    * 屏幕空间参考：右手方向是 $x$、头顶方向是 $y$ 时，$z$ 朝着屏幕外（朝着我们）是右手系统，朝着屏幕里面是左手系统。

    * 左手系统的好处：空间物体都在屏幕后面，用左手系统这些物体的 $x, y, z$ 坐标都是正值；右手系统则物体落在负的 $z$ 方向上。右手、左手都可以，就是个约定。

| 坐标系 | 判定方法 | 常见于 |
| :--- | :--- | :--- |
| 右手系 | 右手四指从 $x$ 转向 $y$，拇指指向 $z$ | 图形学研究、OpenGL |
| 左手系 | 同样的规则改用左手判定 | Unity、DirectX |

* **状态向量（stack vector）**

    * > **定义**：把一堆向量按顺序叠（stack）在一起形成的大向量，专门拿来描述物体的状态；它没有什么几何含义，承载的是状态。

    * 例：一道由 11 个顶点构成的闪电，把 11 个点的位置 $\mathbf{x}_0, \mathbf{x}_1, \ldots, \mathbf{x}_{10}$ 排成一列，这个大向量就描述了物体的形状；做动画要修改某些点的位置，就相应更改大向量里的值。每个 $\mathbf{x}_i$ 都是一个三维向量，合在一起是一个 33 维的向量。

* **向量加减法**

    * 对每一个元素做加减法：$\mathbf{p} \pm \mathbf{q} = (p_x \pm q_x,\ p_y \pm q_y,\ p_z \pm q_z)$；$\mathbf{p} + \mathbf{q} = \mathbf{q} + \mathbf{p}$，交换位置结果肯定一样。

    * 几何含义：$\mathbf{p}+\mathbf{q}$ 是先从原点出发沿 $\mathbf{p}$ 往前走、走完之后再沿 $\mathbf{q}$ 往前走的叠加（先 $\mathbf{q}$ 后 $\mathbf{p}$ 也能达到同样结果）；$\mathbf{p}-\mathbf{q}$ 得到的是 $\mathbf{p}$ 跟 $\mathbf{q}$ 之间相对的位移关系。

## 直线、射线与线性插值

* **粒子运动与直线方程**

    * 粒子沿 $\mathbf{v}$ 方向往前运动（$\mathbf{v}$ 可认为是速度）：$\mathbf{p}(t) = \mathbf{p} + t\,\mathbf{v}$——位置等于原始位置加上速度乘以时间；$t > 0$ 粒子往前运动，$t < 0$ 表示倒推回去、之前时刻的位置。

    * 两个点定一条线：过 $\mathbf{p}$、$\mathbf{q}$ 的线，方向就是 $\mathbf{q}-\mathbf{p}$，轨迹公式 $\mathbf{p}(t) = \mathbf{p} + t(\mathbf{q}-\mathbf{p})$——描述粒子运动的公式拿来描述一条线。

    * 同一个公式按 $t$ 的取值范围定义不同的几何体：加条件 $0 \le t \le 1$ 得到线段；要求 $t \ge 0$ 得到从 $P$ 出发的一条射线；对 $t$ 不做任何约束（取任意实数）得到一整条完整的线。

    ```text
        t<0             0<=t<=1              t>1
    --------+===============+---------------------->
            P               Q
    ```

* **线性插值（interpolation）**

    * 公式换一种写法：$\mathbf{p}(t) = (1-t)\,\mathbf{p} + t\,\mathbf{q}$——本质上是对 $\mathbf{p}$ 跟 $\mathbf{q}$ 做线性混合，$1-t$ 是 $\mathbf{p}$ 的权重、$t$ 是 $\mathbf{q}$ 的权重。

    * 概念：给两个点、给一个权重，利用线性混合的方式得到中间的结果；$1-t$ 和 $t$ 就是插值的权重。

## 范数与单位向量

* **范数（norm）**

    * > **定义**：矢量"大小"的度量——给一个矢量，怎么去计算这个矢量的大小。

    * 最常见的是 2-范数，也叫 euclidean norm：$\|\mathbf{p}\|_2 = \sqrt{p_x^2 + p_y^2 + p_z^2}$——分量平方、求和、开根号，处处是 2，所以叫 2-norm；很多时候大家直接把下标 2 去掉，默认就是它。

    * 用途举例：两点的相对位置用矢量 $\mathbf{q}-\mathbf{p}$ 描述，这个矢量的 norm 就是两点之间的距离。

| 名称 | 定义 | 备注 |
| :--- | :--- | :--- |
| 2-范数（欧氏范数） | $\sqrt{p_x^2+p_y^2+p_z^2}$ | 最常见，下标 2 常省略 |
| p-范数 | $(\lvert p_x\rvert^p+\lvert p_y\rvert^p+\lvert p_z\rvert^p)^{1/p}$ | 阶数 $p$ 任取，按取值不同得到各种范数 |
| 1-范数 | $\lvert p_x\rvert+\lvert p_y\rvert+\lvert p_z\rvert$ | 又名曼哈顿距离（Manhattan distance） |
| ∞-范数 | $p\to\infty$ 时的极限 | 等于各分量的最大值 |

    * 1-范数在数学里还有另外一个名字：曼哈顿距离——做某些游戏开发时可能会用到，利用坐标系之间的差求和来算距离，而不是直接算欧氏距离。

* **单位向量（unit vector）与归一化（normalization）**

    * 单位向量：norm 为 1 的向量。

    * 归一化：把向量除以它自己的 norm——结果的 norm 等于 $\|\mathbf{p}\|/\|\mathbf{p}\| = 1$，自然得到单位向量。

## 点乘

* **点乘（dot product）**

    * > **定义**：两向量各分量对应相乘再求和，得到一个标量：$\mathbf{p} \cdot \mathbf{q} = p_xq_x + p_yq_y + p_zq_z$；数学里一般叫内积，做几何运算时常叫点乘。

    * 几何含义：$\mathbf{p} \cdot \mathbf{q} = \|\mathbf{p}\|\,\|\mathbf{q}\|\cos\theta$——两个向量的长度相乘，再乘上它们夹角的余弦。

    * 论文写法一：尖括号 $\langle \mathbf{p}, \mathbf{q} \rangle$——其实是一个意思，就是做内积、做点乘。

    * 论文写法二：$\mathbf{p}^T\mathbf{q}$——把 $\mathbf{p}$ 转置（transpose）成横着的向量再做矩阵乘法，结果跟点乘一模一样；好处是可以把所有东西都写成矩阵跟向量的乘法，不需要额外定义点乘。读 paper 时看到两个向量中间夹一个 transpose，实际上就是在做点乘。

* **运算性质**

    * 交换律：$\mathbf{p}\cdot\mathbf{q} = \mathbf{q}\cdot\mathbf{p}$；分配律：$\mathbf{p}\cdot(\mathbf{q}+\mathbf{r}) = \mathbf{p}\cdot\mathbf{q} + \mathbf{p}\cdot\mathbf{r}$——从定义出发就能得到。

    * 关键恒等式：$\mathbf{p}\cdot\mathbf{p} = \|\mathbf{p}\|_2^2$——向量对自己做点乘等于 2-范数的平方；想做关于矢量的积分、微分计算时，一般都是利用这个式子去写，而不用 norm 的定义去写。

    * 垂直判定：两个非零向量点乘为零，当且仅当它们互相垂直（正交）——点乘等于零意味着 $\cos\theta = 0$，即 $\theta = 90°$ 或 $270°$；要判定两个方向是不是垂直，做一次点乘、看看结果是不是等于零就行。

## 点乘的应用

* **点到直线的投影**

    * 场景：一个点 $\mathbf{q}$，一条线——过任意一点 $\mathbf{o}$（不一定是原点）、方向为 $\mathbf{v}$；求 $\mathbf{q}$ 在这条线上的投影点，以及投影点到 $\mathbf{o}$ 的距离。

    * 投影距离：$s = \|\mathbf{q}-\mathbf{o}\|\cos\theta$——斜边 $\|\mathbf{q}-\mathbf{o}\|$ 乘以夹角余弦等于底边；上下同乘 $\|\mathbf{v}\|$ 凑成点乘定义，得 $s = (\mathbf{q}-\mathbf{o})\cdot\mathbf{v}\,/\,\|\mathbf{v}\| = (\mathbf{q}-\mathbf{o})\cdot\hat{\mathbf{v}}$，其中 $\hat{\mathbf{v}} = \mathbf{v}/\|\mathbf{v}\|$ 是 normalize 过的方向。

    * 投影点：$\mathbf{s} = \mathbf{o} + s\,\hat{\mathbf{v}}$——从 $\mathbf{o}$ 出发沿方向走投影距离；距离乘以方向就等于投影点的位置。

    ```text
            Q
            +
            |
            |
     O -----+------------------------>  v
            S
    ```

    * 读图：从 $Q$ 往直线作垂线，垂足 $S$ 就是投影点，$O$ 到 $S$ 的长度就是标量 $s$。

* **用点加法向量定义平面**

    * 平面用两个元素定义：平面中的一个点 $\mathbf{c}$，加垂直于平面的方向 $\mathbf{n}$——这种向量就叫做 normal，是这个平面的法向量，且 $\mathbf{n}$ 是单位向量。

    * 位置判定：对任意点 $\mathbf{p}$ 算 $(\mathbf{p}-\mathbf{c})\cdot\mathbf{n}$——大于 0，$\mathbf{p}-\mathbf{c}$ 跟 $\mathbf{n}$ 在同一个半平面上，$\mathbf{p}$ 在平面上面；等于 0，$\mathbf{p}-\mathbf{c}$ 跟法向量垂直，$\mathbf{p}$ 刚好位于平面上；小于 0，$\mathbf{p}$ 在平面下面。

* **有符号距离（signed distance）**

    * $(\mathbf{p}-\mathbf{c})\cdot\mathbf{n}$ 本质上就是 $\mathbf{p}$ 到这个平面的距离（法向上的投影），但它可正可负：绝对值表示传统意义上的距离，符号表示到这个曲面的位置关系。

    * 用途：以后可以利用这个符号做碰撞检测——东西跑到物体里面去了，符号就会变负。

* **点在盒内的判定**

    * 盒子由六个面构成；每个面都用"面上一点 $\mathbf{c}_i$ + 法向量 $\mathbf{n}_i$"来描述，对给定的点 $\mathbf{p}$ 把六个面各算一遍：$(\mathbf{p}-\mathbf{c}_i)\cdot\mathbf{n}_i$，$i = 1, \ldots, 6$。

    * 判定：把六个法向量统一约定成朝内（或统一朝外），点在盒子里面当且仅当六个符号全部一致——点在每一个面的同一侧；任何一个面的符号表明点在这一面的外侧，就立即判定它在盒子外面；点恰好落在某个面上时，对应那个面的值正好为零。

## 点与球的碰撞求交

* **碰撞方程**

    * 场景：点从 $\mathbf{p}$ 出发、沿速度 $\mathbf{v}$ 往前走（$\mathbf{p}(t) = \mathbf{p} + t\mathbf{v}$），前方悬着球心 $\mathbf{c}$、半径 $r$ 的静止球——它撞不撞、什么时候撞。

    * 假设碰撞会发生：$\mathbf{p}(t)$ 到 $\mathbf{c}$ 的距离等于半径，$\|\mathbf{p}(t)-\mathbf{c}\| = r$；两边平方、用"自己点自己等于范数平方"写开，得 $(\mathbf{p}-\mathbf{c}+t\mathbf{v})\cdot(\mathbf{p}-\mathbf{c}+t\mathbf{v}) = r^2$。

    * 用分配率把它彻底展开（套路跟 $(a+b)^2 = a^2 + 2ab + b^2$ 一模一样——平方展开、交叉项带个 2），得到关于 $t$ 的一元二次方程：

      $$(\mathbf{v}\cdot\mathbf{v})\,t^2 + 2t\,(\mathbf{p}-\mathbf{c})\cdot\mathbf{v} + (\mathbf{p}-\mathbf{c})\cdot(\mathbf{p}-\mathbf{c}) - r^2 = 0$$

    * 整个方程里唯一的未知量就是 $t$——$\mathbf{v},\mathbf{c},\mathbf{r},\mathbf{p}$ 全是已知的，把那些点乘老老实实算出来，就得到一个标准的一元二次方程。

* **根的情况与碰撞状态**

| 根的情况 | 几何含义 |
| :--- | :--- |
| 无实根 | 动点与球没有碰撞 |
| 恰好一个根 | 动点刚好擦着球面掠过（相切），发生一次碰撞 |
| 两个根 | 最常见：动点先穿入球面，继续往前走又穿出球面（进去一次、出来一次，正好两个交点） |

* **挑根规则**

    * 解出根之后在实根中取大于零且最小的那个：要求大于零，因为碰撞必须发生在前进方向上——是往前撞上的，不是背后已经过去的事；要求最小，因为要找的是第一个发生碰撞的时刻——要近处这个点，不是远处那个点。

## 叉乘

* **叉乘（cross product）**

    * > **定义**：对夹角为 $\theta$ 的向量 $\mathbf{p}$、$\mathbf{q}$，$\mathbf{r} = \mathbf{p}\times\mathbf{q}$ 是一个向量：与 $\mathbf{p}$、$\mathbf{q}$ 都垂直（$\mathbf{r}\cdot\mathbf{p} = 0$、$\mathbf{r}\cdot\mathbf{q} = 0$），大小为 $\|\mathbf{r}\| = \|\mathbf{p}\|\,\|\mathbf{q}\|\sin\theta$。

    * 与点乘的根本区别：点乘乘出来的是一个标量、带 $\cos\theta$；叉乘乘出来的是一个新的向量、带 $\sin\theta$。

| | 点乘 | 叉乘 |
| :--- | :--- | :--- |
| 结果 | 标量 | 新的向量 |
| 夹角进入公式的方式 | $\cos\theta$ | $\sin\theta$ |

    * 反交换：$\mathbf{p}\times\mathbf{q} = -(\mathbf{q}\times\mathbf{p})$——把 $\mathbf{p}$、$\mathbf{q}$ 交换后每一行都变号。

    * > ⚠️ **易错点**：叉乘不满足交换律，交换顺序结果反号；书写时前后顺序不能随手调换。

    * 分配律：叉乘同样满足分配率，跟正常的乘法一样。

    * 平行判定：两个非零向量的叉乘等于零向量 $\mathbf{0}$，唯一可能是 $\sin\theta = 0$，即 $\theta = 0°$ 或 $180°$——两向量平行，同方向反方向都算；叉乘可以当平行判定器用。

    * > ⚠️ **易错点**：这里说的"零"是黑体的零向量 $\mathbf{0}$，不是数字 0——叉乘的结果是向量，等式两边都得是向量；后面三点共线、平行判据的右边都是零向量。

## 三角形的法向、面积与内外判定

### 法向与面积

* **三角形法向量**

    * 顶点 $\mathbf{x}_0, \mathbf{x}_1, \mathbf{x}_2$，特地从 $\mathbf{x}_0$ 出发选两条边：$\mathbf{x}_{10} = \mathbf{x}_1 - \mathbf{x}_0$、$\mathbf{x}_{20} = \mathbf{x}_2 - \mathbf{x}_0$。

    * 法向量 = 先叉乘、再 normalize：$n = \mathbf{x}_{10}\times\mathbf{x}_{20}\,/\,\|\mathbf{x}_{10}\times\mathbf{x}_{20}\|$——叉乘算出来的东西跟两条边向量都垂直，但正常想要的法向必须是单位向量，所以要除以它自己的大小。

* **三角形面积**

    * 底乘高除以二：$A = \frac{1}{2}\|\mathbf{x}_{10}\|\,\|\mathbf{x}_{20}\|\sin\theta$——底是 $\|\mathbf{x}_{10}\|$，$\mathbf{x}_{20}$ 这条边当斜边，斜边长度乘以夹角 $\sin\theta$ 正好是高。

    * 这个东西跟叉乘的大小是同一个东西：$A = \frac{1}{2}\|\mathbf{x}_{10}\times\mathbf{x}_{20}\|$——一次叉乘一石二鸟：方向（normalize 之后）给出法向量，大小除以二给出面积。

* **拓扑顺序**

    * 用顶点定义三角形时，不光需要顶点的位置信息，顶点的顺序同样重要：把 $x_1$、$x_2$ 的角色对调，再用右手法则比划，法向就翻到另一边去了。

    * > ⚠️ **易错点**：顺序一换、法向就反向；这个顺序通常叫做三角形的拓扑顺序（拓扑关系），使用三角形时要时刻留意。

### 内外判定与带符号面积

* **点在三角形内的判定**

    * 单看一条边：假设 $p$ 在边的内侧，$p$ 和 $x_0$、$x_1$ 构成的小三角形，用右手定则（$p \to x_0 \to x_1$）比划出的法向 $(\mathbf{x}_0-\mathbf{p})\times(\mathbf{x}_1-\mathbf{p})$，跟大三角形自己的法向同方向；$p$ 跑到外侧，同样的公式、同样的右手定则，法向就相反。

    * 三条边各查一遍：三个子三角形法向 $(\mathbf{x}_0-\mathbf{p})\times(\mathbf{x}_1-\mathbf{p})$、$(\mathbf{x}_1-\mathbf{p})\times(\mathbf{x}_2-\mathbf{p})$、$(\mathbf{x}_2-\mathbf{p})\times(\mathbf{x}_0-\mathbf{p})$ 分别与大三角形法向 $n$ 做点乘，三个都同方向 $\iff$ $p$ 在三角形里面；只要有一个反向，$p$ 就在三角形外面。

    * 前提一：判定不取决于 $n$ 朝哪边——把 $x_0,x_1,x_2$ 顺序整体反转，$n$ 跟着反向、三个子三角形法向也跟着反向，点乘照样全部同号；只要遵循同样的顶点顺序，公式就成立。

    * 前提二：整套推导假设 $p$ 与三角形共面，这是一个很重要的前提假设。

* **带符号面积（signed area）**

    * 把三个子法向与 $n$ 的点乘除以二，得到三个小三角形的面积——子三角形法向是叉乘结果、$n$ 是单位向量，同方向时点乘出来就是叉乘的大小，反方向时添个负号；这个面积可正可负，所以叫带符号面积：

      $$a_0=\frac{1}{2}\,n\cdot\big((\mathbf{x}_1-\mathbf{p})\times(\mathbf{x}_2-\mathbf{p})\big),\qquad a_1=\frac{1}{2}\,n\cdot\big((\mathbf{x}_2-\mathbf{p})\times(\mathbf{x}_0-\mathbf{p})\big),\qquad a_2=\frac{1}{2}\,n\cdot\big((\mathbf{x}_0-\mathbf{p})\times(\mathbf{x}_1-\mathbf{p})\big)$$

    * 每个 $a_i$ 对应"不含顶点 $\mathbf{x}_i$ 的那个小三角形"——$a_2$ 由 $x_0,x_1$ 与 $p$ 算出，$a_1$ 由 $x_0,x_2$ 与 $p$ 算出，$a_0$ 由 $x_1,x_2$ 与 $p$ 算出。

    * 恒等式：不管 $p$ 在哪儿，$a_0+a_1+a_2 = A$（大三角形的面积）恒成立；$p$ 在内部时三个全正，$p$ 在外部时有的变负、有的甚至比 $A$ 还大，但总和始终等于 $A$。

* **三点共线判定**

    * 给三个点 $\mathbf{x}_0,\mathbf{x}_1,\mathbf{x}_2$：三点共线 $\iff$ 从同一点出发的两条边向量平行 $\iff$ 叉乘等于零向量——计算 $\mathbf{x}_{10}\times\mathbf{x}_{20}$，结果是零向量 $\mathbf{0}$ 就共线，否则不共线（平行时 $\theta = 0°$ 或 $180°$，$\sin\theta = 0$）。

## 重心坐标与三角形插值

* **重心坐标（barycentric weights）**

    * > **定义**：$b_i = a_i / A$——三个带符号面积分别除以总面积；因为 $a_0+a_1+a_2 = A$，所以 $b_0+b_1+b_2 = 1$；三个权重分别"挂"在顶点 $\mathbf{x}_0,\mathbf{x}_1,\mathbf{x}_2$ 上。

    * 与内外判定的关系：$p$ 在三角形内部时三个权重都是大于零的值；$p$ 在外部时这套权重同样成立、只是有的权重会是负的——"权重全正"和"点乘全同号"是同一件事的两种说法，用正负号就能判断点在不在三角形里。

* **重心插值（barycentric interpolation）**

    * $\mathbf{p} = b_0\,\mathbf{x}_0 + b_1\,\mathbf{x}_1 + b_2\,\mathbf{x}_2$——把权重搁到三个顶点的位置上，插出 $p$ 点的位置；跟线段插值同一思想，作用对象从两个点换成三个顶点，图形学里用得非常常见。

    * 典型应用 Gouraud shading：三个顶点各自算出颜色，三角形内部像素 $p$ 的颜色由三个顶点颜色做一次重心插值得到。

    * 历史原因：二三十年前计算机硬件能力弱，显卡没办法对每一个像素做颜色计算，只能算三角形顶点的颜色，然后靠插值把内部铺满——插值的计算量比颜色计算小得多；现在显卡算力已经很强，完全可以对每个像素算颜色、甚至做光线追踪，这种着色方式已经很少见到了。

    * 实践细节：即便在当时，实践中通常也不直接对每个像素算 barycentric weight（麻烦、计算量稍大），常用扫描线算法（scanline conversion）——把同一行两端的像素先算出来，中间像素在这两点之间做线性插值，用几个线性插值拼出三角形内部的插值。

## 四面体的体积与重心坐标

* **四面体体积公式**

    * 四个顶点 $\mathbf{x}_0,\mathbf{x}_1,\mathbf{x}_2,\mathbf{x}_3$，从 $\mathbf{x}_0$ 出发三条边 $\mathbf{x}_{10},\mathbf{x}_{20},\mathbf{x}_{30}$；体积 = 底面积 × 高 ÷ 3。

    * $$V = \frac{1}{6}\,\mathbf{x}_{30}\cdot(\mathbf{x}_{10}\times\mathbf{x}_{20}) = \frac{1}{6}\,(\mathbf{x}_3-\mathbf{x}_0)\cdot\big((\mathbf{x}_1-\mathbf{x}_0)\times(\mathbf{x}_2-\mathbf{x}_0)\big)$$

    * 推导：底面 $x_0x_1x_2$ 本身是三角形，面积 $= \|\mathbf{x}_{10}\times\mathbf{x}_{20}\|/2$；高是 $\mathbf{x}_3$ 到底面的距离，即 $\mathbf{x}_{30}$ 在底面法向（$\mathbf{x}_{10}\times\mathbf{x}_{20}$ 的方向）上的投影；相乘时两处 $\|\mathbf{x}_{10}\times\mathbf{x}_{20}\|$ 正好抵消，$\frac{1}{2}\times\frac{1}{3} = \frac{1}{6}$。

    * 行列式形式：把四个顶点当成四个向量，写成一个 $4\times4$ 的行列式——第一列 $\mathbf{x}_1$、第二列 $\mathbf{x}_2$、第三列 $\mathbf{x}_3$、最后是 $\mathbf{x}_0$，每列最下面添一个 1（四个三维向量、底下加个 1，高度就成了四）；它跟点乘叉乘那坨相等，$\frac{1}{6}$ 照样保留；以后看到这种行列式形式，要知道它其实就是在计算四面体的体积。

    * 行列式的值跟顺序有关：两行（或两列）一交换，值就变号；所以尽量遵循约定的顺序去写，如果算出行列式的值是负的，有可能就是顺序出了问题。

* **可正可负可零的体积**

    * 符号由 $\mathbf{x}_3$ 相对底面法向的侧向决定：$\mathbf{x}_3$ 跟底面 $x_0x_1x_2$ 的法向在同侧，算出来是正体积——一个正常的四面体；在法向的另一侧，体积就是负的——叫被反转的四面体（inverted tetrahedron），意味着四面体翻过来了、凹了个面；正常情况下默认四面体是正体积的。

    * 零体积：四个点落在同一个平面上（共面）。

* **四面体的重心坐标**

    * 用点 $p$ 把四面体分成四个小四面体——四个面各跟 $p$ 构成一个小四面体，小体积都用同一体积公式算（把相应的顶点换成 $p$）。

    * 内部判定：四个小四面体的体积都为正 $\iff$ $p$ 在四面体里面；同时四个小体积加起来等于整个四面体的体积。

    * 插值：每个小体积除以总体积得到四个 barycentric weight，挂到四个顶点上：$\mathbf{p} = b_0\,\mathbf{x}_0 + b_1\,\mathbf{x}_1 + b_2\,\mathbf{x}_2 + b_3\,\mathbf{x}_3$——本质上是三角形插值的"高级版"，多了一个点，带来从面积到体积的转换、多了一些计算，但概念完全一样。

## 点与三角形的碰撞

* **两步判定**

    * 三角形静止，点从 $\mathbf{p}$ 出发、沿速度 $\mathbf{v}$ 的方向运动；判定分两步：第一步，先求这个点什么时候跟三角形所在的平面碰撞——三角形落在一个平面上，先找到与这个平面相碰的时刻；第二步，再看碰撞点是否真的落在三角形里面。

    * 第一步的方程：碰撞时刻动点位置 $\mathbf{p}_t = \mathbf{p} + t\mathbf{v}$ 落在三角形平面内，则 $\mathbf{x}_0,\mathbf{x}_1,\mathbf{x}_2,\mathbf{p}_t$ 四点共面——它们构成的四面体体积为零（常数 $\frac{1}{6}$ 不影响零判定）：

      $$\big((\mathbf{x}_1-\mathbf{x}_0)\times(\mathbf{x}_2-\mathbf{x}_0)\big)\cdot\big(\mathbf{p}-\mathbf{x}_0 + t\,\mathbf{v}\big) = 0$$

    * 把 $\mathbf{p}_t - \mathbf{x}_0 = (\mathbf{p}-\mathbf{x}_0) + t\mathbf{v}$ 代进去、用分配率整理，得到关于 $t$ 的一次方程——比撞球那会儿的二次方程还省事——碰撞时刻直接解出：

      $$t = -\,\frac{n\cdot(\mathbf{p}-\mathbf{x}_0)}{n\cdot\mathbf{v}},\qquad n = (\mathbf{x}_1-\mathbf{x}_0)\times(\mathbf{x}_2-\mathbf{x}_0)$$

    * 分子衡量的是出发点 $\mathbf{p}$ 相对三角形平面的带符号"高度"，分母是速度在法向方向上的分量——一除，撞到平面的时刻就出来了。

    * "体积为零"在这里扮演的角色，跟撞球问题里"距离等于半径"完全一样：都是把"发生碰撞"翻译成一个能解的方程。

* **射线与三角形求交的整体流程**

    * 参数 $t$ 一到手，射线与平面相交的点 $\mathbf{p}_t$ 也就算出来了，但事情只完成了一半：平面是无限延展的，三角形只是其中一小块，交点有可能落在三角形外面。

    * 整体归拢成两个部分：①利用体积公式，算出点与面相交的位置，得到交点 $\mathbf{p}_t$；②检测这个相交的点是否落在三角形内侧（用重心坐标权重那套内外检测）。

* **运算顺序**

    * 点乘只能跟另一个向量做，所以 $(\mathbf{x}_1\times\mathbf{x}_2)\cdot\mathbf{x}_3$ 这种"先叉乘、再点乘"的分组是默认存在的；不写括号只是书写习惯，含义不会丢。

## 矩阵

* **矩阵**

    * > **定义**：把矢量（一堆实数）用行跟列叠在一起的数组；图形学里用得比较多的是 $3\times3$ 矩阵——相当于三个矢量叠在一起构成的矩阵；图形学里通常只考虑实数矩阵。

* **四种特殊矩阵**

    * 转置（transpose）：沿着对角线把上跟下的元素换位置——$(0,1)$ 跟 $(1,0)$ 换、$(0,2)$ 跟 $(2,0)$ 换，以此类推。

    * 对称矩阵：一个矩阵转置之后跟原来一模一样，即沿对角轴上下两两相等。

    * 对角矩阵：只有对角上有值，非对角的地方全是零。

    * 单位矩阵（identity matrix）：对角上全是一的特殊对角矩阵；$\mathbf{I}$ 乘一个向量，等于这个向量乘了跟没乘一样；跟矩阵相乘，也是乘了等于没乘。

* **乘法的规律**

    * 顺序不能换：$AB \neq BA$——矩阵乘法跟顺序有关，不能像数的乘法那样随便交换。

    * 结合律成立：$(AB)\mathbf{x} = A(B\mathbf{x})$——可以先对 $AB$ 做乘法，也可以先对 $B\mathbf{x}$ 做乘法，最后乘出来是一样的。

    * 转置要倒序：$(AB)^T = B^TA^T$——可以分别对 $A$、$B$ 做转置，但要把前后顺序倒一倒。

* **两个对称化套路**

    * $AA^T$：用"转置要倒序"的规矩一验，$(AA^T)^T = (A^T)^TA^T = AA^T$，转置等于它自己——所以乘完之后就是对称矩阵。

    * $A + A^T$：它的转置显然等于它自己，同样是一个对称矩阵；不太常见，但有时候也有人用。

* **逆矩阵（inverse）**

    * 定义：如果一个矩阵 $A$ 有逆，$A$ 乘以它的逆等于单位矩阵，而且左乘、右乘都可以；一个矩阵如果有逆，它是唯一的。

    * 乘积的逆倒序：$(AB)^{-1} = B^{-1}A^{-1}$——可以分别对 $A$、$B$ 求逆，顺序要倒一倒，跟转置那一条有点像。

    * 不是所有矩阵都有逆：全零矩阵不管怎么构造一个矩阵跟它乘，乘出来最后都是零，永远不可能等于 identity——不可逆。

## 正交矩阵与旋转、缩放

* **正交矩阵（orthogonal matrix）**

    * > **定义**：一个矩阵由正交的单位向量构成——比如 $3\times3$ 矩阵 $A$ 的三个列 $\mathbf{a}_0,\mathbf{a}_1,\mathbf{a}_2$ 都是正交的单位向量：$\mathbf{a}_i\cdot\mathbf{a}_j$ 在 $i = j$ 时等于 1、$i \neq j$ 时等于 0。

    * "单位"是说每个向量点乘它自己等于一；"正交"是说不同的向量互相点乘等于零（垂直）。

    * 关键性质：$A$ 乘它自己的转置等于单位矩阵——对角线上是 $\mathbf{a}_0\cdot\mathbf{a}_0$ 这些，全是一；非对角线上全是零——正是 identity；所以正交矩阵的转置就等于它自己的逆。

    * 实际价值：通常情况下算矩阵的逆会很麻烦，但对正交矩阵而言，想要逆，直接对它做个转置就行了——这是正交矩阵很好的一个优点。

* **旋转矩阵**

    * 旋转可以用正交矩阵去描述；理解方式：三维物体（如一个立方体）自带一个局部空间（local space）——自己的前后左右上下就是它的坐标轴，初始时跟 $x,y,z$ 重合；用旋转矩阵 $A$ 转动之后，局部轴分别指向世界空间（world space）里的三个新方向 $\mathbf{u},\mathbf{v},\mathbf{w}$。

    * 矩阵与局部轴的关系：$A\mathbf{x} = \mathbf{u}$、$A\mathbf{y} = \mathbf{v}$、$A\mathbf{z} = \mathbf{w}$；而 $\mathbf{x},\mathbf{y},\mathbf{z}$ 三个单位向量拼起来正好是单位矩阵，所以三条合起来写就是 $A = [\,\mathbf{u}\;\mathbf{v}\;\mathbf{w}\,]$——旋转矩阵直接等于这三个列向量拼成的矩阵。

    * > **提示**：旋转矩阵本质上就是这个物体的局部坐标系在世界空间中的状态——拿到旋转矩阵，就等于把物体的局部坐标从矩阵里"抠"了出来。

    * $\mathbf{u},\mathbf{v},\mathbf{w}$ 是一个坐标系——三个单位正交的向量，彼此垂直、又都是单位长度，所以 $A$ 必然是一个正交矩阵。

* **缩放矩阵（scaling matrix）**

    * 缩放用对角矩阵描述：沿 $x,y,z$ 做缩放时，对角线上的值分别是三个方向的缩放量 $d_x, d_y, d_z$。

    * 一句话归拢：旋转用正交矩阵描述，缩放用对角矩阵描述。

## 矩阵分解：SVD 与特征值分解

* **奇异值分解（singular value decomposition，SVD）**

    * > **定义**：矩阵 $A$ 可以写成三个部分的乘积 $A = UDV^T$——中间的 $D$ 是一个对角矩阵，对角上的值叫奇异值（singular value）；两边的 $U$、$V$ 都是正交矩阵。

    * > ⚠️ **易错点**：对角元是奇异值，不是特征值——这两个词都会出现，别搞混。

    * 直观理解：不管什么样的线性形变，都可以用三个操作去描述——旋转、缩放、旋转：先用 $V^T$ 把方块转到一个特定的位置上，接着由 $D$ 做缩放，最后用 $U$ 把它转到想要的方向上去，整个线性变换就完成了。

    ```text
          V^T 旋转                D 缩放                 U 旋转
     原方块 ────────────→ 转到特定位置 ────────────→ 沿轴拉伸 ────────────→ 转到最终朝向
    ```

    * 为什么中间要垫一个旋转：缩放矩阵是对角的，做缩放的时候只能沿 $x$、$y$ 这些轴拉；想沿某个斜着的方向缩放怎么办——例：想让方块沿对角方向缩放，先把它转 45 度、让它的对角跟 $xyz$ 重叠，这时候再做缩放，就是对角方向上的缩放了；缩完之后再转回去。

    * SVD 的核心是中间那个 scaling：不管什么样的线性变换，本质上都是缩放——只不过是沿任意方向的缩放；二维如此，四面体（三维）的情形一模一样，换成三维的旋转、缩放、旋转来实现就行。

    * 所有的矩阵都可以做 SVD。

* **特征值分解（eigenvalue decomposition）**

    * 图形学里只考虑对称矩阵的特征值分解：$A = UDU^{-1}$——对称的时候，SVD 左边跟右边就一模一样了；写 $U^{-1}$ 还是写 $U^T$ 无所谓，$U$ 是正交矩阵，它的逆跟它的转置本质上是一回事情。

    * 教科书定义式：$A\mathbf{u}_i = d_i\mathbf{u}_i$——矩阵 $A$ 乘以一个特征向量，等于这个特征向量乘以某个特征值；$\mathbf{u}_i$ 叫特征向量，$d_i$ 叫特征值；它跟分解式是一回事情，一个是分解的写法、一个是跟特征值打交道时更常见的写法。

    * 推导要点：$U^T$ 乘 $\mathbf{u}_i$（正交矩阵的转置去乘它自己的一列）得到一堆零加一个一；接着乘对角矩阵 $D$，把原来 1 的位置换成 $d_i$、其余还是零；最后左乘 $U$，就得到 $d_i\mathbf{u}_i$——特征向量被抠出来了。

    * 非对称的矩阵其实也可以做特征值分解，但分解出来的特征值、特征向量有可能是虚数；图形学里通常不考虑虚数，所以通常只考虑对称矩阵。

* **两种分解对比**

| | 奇异值分解（SVD） | 特征值分解（图形学口径） |
| :--- | :--- | :--- |
| 分解形式 | $A = UDV^T$ | $A = UDU^T$（或 $U^{-1}$） |
| 两侧因子 | 正交阵 $U$、$V$，一般不同 | 同一个正交阵 $U$ |
| 对角元的名字 | 奇异值 | 特征值 |
| 适用范围 | 所有矩阵都可以做 | 图形学里只取对称矩阵 |

## 对称正定矩阵

* **对称正定（SPD）**

    * > **定义**：对称矩阵 $A$ 对任何非零向量 $\mathbf{x}$ 都满足 $\mathbf{x}^TA\mathbf{x} > 0$，就叫正定；把大于号换成 $\geq$（乘出来可能等于零），就叫半正定；前提是矩阵得对称。

    * 重要性：它跟处理线性问题、解线性系统的时候特别有关系，是矩阵一个很关键的定性。

* **直觉链：从数到对角阵到一般对称阵**

    * 从一个数想起：正数 $d$ 左右夹住非零向量，本质就是 $d\,|\mathbf{v}|^2$——向量的大小（magnitude）肯定是正的，$d$ 又是正的，所以乘出来肯定大于零。

    * 对角阵：把一堆正实数 $d_0, d_1, d_2, \ldots$ 摆成对角矩阵 $D$，展开 $\mathbf{v}^TD\mathbf{v} = d_0v_0^2 + d_1v_1^2 + d_2v_2^2 + \cdots$——一堆平方项天然非负，前面的系数又都是正的，加起来肯定大于零；对角元全为正的对角矩阵，必然是正定的。

    * 一般对称阵：构造 $A = UDU^T$（就是对称矩阵的特征值分解，$D$ 分解出来的对角元就是特征值）；在 $\mathbf{x}^TA\mathbf{x}$ 前后各插 $U^T$、$U$（正交矩阵乘自己的转置等于单位矩阵，插进去的是 identity、不影响等式），令 $\mathbf{y} = U^T\mathbf{x}$，得 $\mathbf{x}^TA\mathbf{x} = \mathbf{y}^TD\mathbf{y}$——$U^T$ 做的是旋转，一个非零的向量旋转一下怎么都不可能变成零向量，于是问题回到对角阵情形，必然大于零。

    * 等价结论：对称矩阵特征值分解出来的特征值全是正的，它必然是正定的；而且这两件事是一回事情、等价——正定，等价于特征值全正。整条直觉链：数的平方必然大于零 → 对角元全正的对角阵夹非零向量必然大于零 → 前后各乘一个正交矩阵（做个旋转）不影响正定性。

* **实用判定：对角占优**

    * 实际中不会通过特征值分解来玩正定性：利用数值计算做特征值分解一般来说很慢、计算量非常大，通常不会直接去做这个计算。

    * 对角占优：对角上的值大于同一行非对角元素的和；对角占优的矩阵一定是正定的。例：对角元为 4、5、9 的矩阵逐行检查——第一行 $4 > 3+0$，第二行 $5 > 1+3$，第三行 $9 > 0+8$，行行过关，所以它是正定的。

    * 不要求行、列两边同时满足——只要每一行都满足（或者每一列都满足）就够了。

    * > **注意**：对角占优能推出正定，反方向不成立——正定的矩阵未必对角占优；这只是个充分条件：检查过关，可以放心下"正定"的结论；检查不过关，并不代表矩阵不正定，只是这条捷径给不出答案。

* **正定与可逆性**

    * SPD 矩阵必然是可逆的：$A^{-1} = (UDU^T)^{-1} = UD^{-1}U^T$——$U$ 是正交矩阵，它的逆就是它自己的转置；$D$ 是对角矩阵、对角上的元素都是正的，逐个取倒数就行；串起来，$A^{-1}$ 一定存在。

    * 使用场景：后面讨论有限元的时候，还有跟矩阵的 Hessian——也就是矩阵的二阶导——打交道的时候，都会碰到这些概念。
