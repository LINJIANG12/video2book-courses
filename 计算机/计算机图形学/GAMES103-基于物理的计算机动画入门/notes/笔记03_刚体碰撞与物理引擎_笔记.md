# 刚体碰撞与物理引擎

## 旋转动力学：力矩与惯量张量

### 线性运动与旋转运动的对应

   * **旋转更新链**

       * 平移靠力、旋转靠力矩：线性侧的每个步骤在旋转侧都有对应物，整套流程平行成立。

       * 流程同线性一致：先按模型算出各点的力，对力矩求和得总力矩，再依次更新角速度与姿态。

| 线性运动 | 旋转运动 |
| :--- | :--- |
| 力 $f$：造成物体平移运动的趋势 | 力矩 $\tau$：造成物体旋转的趋势 |
| 对力求和得总力 | 对力矩求和得总力矩 |
| 除以质量 $m$（常数） | 除以惯量张量 $I$（矩阵） |
| 更新速度 | 更新角速度 |
| 更新位置 | 更新姿态（四元数） |

### 力矩（torque，$\tau$）

   * **力矩（torque，$\tau$）**

       * > **定义**：造成物体旋转趋势的量；旋转轴决定旋转方式，力矩大小决定这种趋势的猛烈程度。

       * 计算公式：$\tau_i = (R\,\bar{r}_i) \times f_i$——力与"质心到作用点"向量的叉积（cross product），方向与这两个向量都垂直。

       * 大小三要素：力越大、作用点离质心越远（杠杆原理）、两向量夹角越接近 $90°$（正比于 $\sin\theta$），力矩越大；朝质心方向推不产生任何旋转。

       * $R$ 是描述当前姿态的旋转矩阵（引擎内部用四元数 quaternion 描述姿态，两者可换算），随时间变化；$\bar{r}_i$ 是 reference 状态下质心到作用点的向量，固定不变；$R$ 由之前的运动造成，与当前力 $f$ 无关。

### 惯量张量（inertia tensor，$I$）

   * **惯量张量（inertia tensor，$I$）**

       * > **定义**：物体对旋转趋势的抵抗，角色相当于线性运动中的质量，但它是一个随姿态变化的矩阵而非常数。

       * 抵抗随方向变化：同样大小的力矩，质量集中在旋转轴上时抵抗小、转得猛；质量远离旋转轴时抵抗大、转得弱——质量则与力的方向毫无关系、永远是常数，这是旋转与线性的本质差异。

       * reference 状态下的计算：$I_{\text{ref}} = \sum_i m_i \left( (\bar{r}_i^{\,T}\bar{r}_i)\,\mathbf{1} - \bar{r}_i\,\bar{r}_i^{\,T} \right)$——每个采样点"向量长度平方乘单位阵，减去向量自身的外积"，乘质量后全点求和。

       * > **易错点** ⚠️：惯量张量不是常数——它随力矩方向与物体当前姿态变化；姿态一变，点的向量变成 $R\bar{r}_i$，惯量就跟着变。

       * 当前姿态免重算：$I = R\,I_{\text{ref}}\,R^T$。推导两步：$R^TR$ 抵消为单位阵（旋转矩阵的转置就是它的逆）；实数倍的单位阵左右乘 $R$、$R^T$ 不变，随后把 $R$、$R^T$ 提到括号外。$I_{\text{ref}}$ 事先算好当常数，用时左右各乘一次矩阵即可，点很多时省下大量计算。

       * 角速度更新：$\Delta\omega = I^{-1}\tau$，对应线性侧"力除以质量"；随后按新角速度更新四元数（四个值，但不是真的四维向量）。

## 符号距离函数与距离场组合

### 符号距离函数（signed distance function，SDF）

   * **符号距离函数（signed distance function，SDF）**

       * > **定义**：对每个点 $x$ 给出它到某个面的带符号距离：值为正在外侧，为负在内侧，等于零恰好落在面上；取零值的曲面也称 zero surface。

       * 用途：碰撞检测只看正负号——$\phi(x)<0$ 即发生碰撞；符号管内外、大小管深浅。

       * 平面：$f(x) = (x-p) \cdot n$，$p$ 为面内一点、$n$ 为法向（normal）；$n$ 指向的一侧约定为外面。

       * 球：$f(x) = \lVert x-c\rVert - r$，到圆心的距离减半径，差值本身就是到球面的距离。

       * 圆柱：到中心轴的距离减半径；点到轴的距离用勾股定理——斜边 $\lVert x-p\rVert$、底边 $(x-p)\cdot m$（$m$ 为轴向），垂线段 $d_\perp=\sqrt{\lVert x-p\rVert^2-\big((x-p)\cdot m\big)^2}$，故 $\phi(x)=d_\perp-r$。

       * > **易错点**：公式记号要分清——斜体一般是标量，黑体一般是矢量或矩阵，混用会误导人。

### 用布尔运算组合距离场

   * **相交（intersection）**

       * > **定义**：各组成面全部包住点才算内部（AND 逻辑），组合距离函数取最大值 $\phi(x)=\max\{\phi_0(x),\,\phi_1(x),\,\phi_2(x)\}$。

       * 内侧用 max 可靠：内部各函数值全为负，最大者最接近零、对应的正是最近的曲面，即到轮廓的真实距离。

       * 外侧的组合函数可能与各 $\phi_i$ 都毫无关系，但检测只看正负号，不影响碰撞判断。

       * 典型拆解：扇形 = 一个球面（二维即圆）与两个平面相交；正方形 = 四条边；立方体 = 六个面；圆锥 = 锥面 + 底面。

   * **并集（union）**

       * > **定义**：点落进任一组成部分即算内部（OR 逻辑），组合函数取最小值 $\phi(x)=\min\{\phi_0(x),\,\phi_1(x)\}$。

       * 外侧用 min 可放心；内侧只是近似——点在两球相交区域中心附近时，两个函数值都很小，但到实际表面可能很远。

       * 并集也可以当成两个独立物体分别做碰撞处理，本质上等价。

| 对比项 | 相交（AND） | 并集（OR） |
| :--- | :--- | :--- |
| 内侧判定 | 所有 $\phi_i<0$ 同时成立 | 至少一个 $\phi_i<0$ |
| 组合方式 | $\max\{\phi_0,\phi_1,\dots\}$ | $\min\{\phi_0,\phi_1,\dots\}$ |
| 可靠的一侧 | 内侧：max 是到最近面的真实距离 | 外侧：min 可放心用 |
| 不可靠的一侧 | 外侧：可能与各 $\phi_i$ 都无关，检测只看符号 | 内侧：只是近似，越深入偏差可能越大 |

## 点碰撞响应：Penalty 与 Impulse

### Penalty 方法

   * **Penalty 方法**

       * > **定义**：检测到碰撞后给点施加一个把它推出物体的力；力加入正常模拟流程，效果到下一时刻才起作用（滞后）。

       * 弹性 penalty：力像弹簧、大小与陷入深度成正比，$f=-k\,\phi(x)\,n$；内侧 $\phi$ 为负，加负号让力的大小等于穿透深度；$k$ 是 penalty 强度（碰撞强度），本质是弹簧的弹性系数。

       * 力的方向取距离函数的 gradient（梯度）：梯度指向函数值增大最快的方向，沿它推能最快把点推出去，所以梯度方向就是表面法向。

       * 缓冲层：检测条件从 $\phi(x)<0$ 改成 $\phi(x)<\varepsilon$、力改为 $f=k\,(\varepsilon-\phi(x))\,n$——给表面加一层厚度 $\varepsilon$，点尚未穿透、只是靠近时就加力推出；实操中一般都用这个套路。

       * $k$ 的两难：太小推不动，物体会一直往里走、陷得足够深力积累够大才被推出来；太大则一步之内力过大，点直接飞出屏幕。

       * > **易错点**：大 $k$ 引起 overshooting（过冲）——本质是不稳定问题；对碰撞而言隐式积分更好，但实际常用较简单的显式方法处理碰撞，所以不稳定存在。

       * 对数障碍函数（log barrier function）：把常数强度换成随距离放大的 $\rho/\phi(x)$，$f=\frac{\rho}{\phi(x)}\,n$；对应能量 $-\rho\log\phi(x)$（log 求导变分之一）。点越靠近表面力越大，试图同时避免"力不足"与"力过大"。

       * log barrier 的两个问题：$\phi\to 0$ 时力趋于无穷大，仍会 overshooting；一旦穿透 $\phi<0$，力反向朝里、物体越陷越深——它假设穿透永不发生，必须用小步长保证，带来额外成本。

       * 参数 $\rho$ 一般是常数、不太调，与力的衰减速度有关、与力的大小关系不强；改进方向是给 log barrier 再加一层 buffer，限定其无限大的影响力。

       * 得与失：容易实现（算个力加进正常模拟即可）；摩擦较难做，难以保证物体完全没有穿透、完美停下。

### Impulse 方法

   * **Impulse 方法（冲量法）**

       * > **定义**：碰撞检测到之后立刻更新速度与位置，不让碰撞效果拖到下一时刻。

       * 位置更新：把点沿法向移回表面上距离最近的点，$x'=x+\big|\phi(x)\big|\,n$；取绝对值是因为内侧距离为负，$n$ 即梯度方向。

       * 速度前置检测：$v\cdot n<0$ 才处理——速度若已朝外（与法向同侧）说明正离开表面，不用管。

       * 速度拆解：法向分量 $v_n=(v\cdot n)\,n$（点乘得标量，再乘 $n$ 还原成矢量），切向分量 $v_t=v-v_n$。

       * 速度合成：$v'=-\mu\,v_n+a\,v_t$——$\mu$ 是反弹系数（弹性系数），限 $0$ 到 $1$ 之间，否则反弹后速度比原来大；$a$ 是摩擦造成的切向衰减系数。

```text
碰前速度 v (满足 v·n < 0, 还在往里走)
    |
    +---> 法向分量  v_n = (v·n)·n  --乘 -μ-->  反弹: 方向反转
    |
    +---> 切向分量  v_t = v - v_n  --乘 a--->  摩擦: 按比例衰减

碰后速度  v' = -μ·v_n + a·v_t
```

   * **摩擦系数 $a$：由库伦定律推出**

       * 库伦定律：切方向速度的改变量，等于法方向速度的改变量乘以某个摩擦系数。

       * 两边改变量：切向 $(1-a)\lvert v_t\rvert$，法向 $(1+\mu)\lvert v_n\rvert$（一进一出）；要求 $a$ 尽量小、顶到库伦界限时两边相等，解得 $a=1-\mu_f\,(1+\mu)\,\frac{\lvert v_n\rvert}{\lvert v_t\rvert}$。

       * $a$ 的下界是 $0$：摩擦力再强也只能让切向速度归零、不能使其反转，故 $a=\max\left\{0,\;1-\mu_f\,(1+\mu)\,\frac{\lvert v_n\rvert}{\lvert v_t\rvert}\right\}$。

       * 两种摩擦形态：取库伦值为动摩擦——物体还在滑动、切向速度被衰减但没停；取 $0$ 为静摩擦——切向速度直接归零、物体停下来。

   * **两种方法的取舍**

| 对比项 | Penalty | Impulse |
| :--- | :--- | :--- |
| 起效时机 | 力到下一时刻才起作用，效果滞后 | 检测到碰撞立刻更新位置和速度 |
| 碰撞的表达 | 施加一个弹簧行为的力 | 直接修改速度（和位置） |
| 摩擦与停止 | 难以精确控制，易残留轻微穿透 | 能精确控制摩擦、反弹和停下 |
| 实现与适用 | 实现简单，衣服、弹性体用得多 | 刚体用得多；有些情况处理麻烦 |

       * impulse 的优势是能精确控制摩擦、反弹与物体停下来的状态（想要静摩擦、必然停下就能做到）；penalty 仍常被使用，因为它更简单。

       * 适用习惯：衣服、弹性体一般 penalty 更多；刚体用 impulse 挺多；$\mu$ 等参数一般由用户自定义。

       * 真实物理世界的碰撞本质上也是 penalty——源于分子间的互斥；真实摩擦由表面不平整造成，建模时用各种数学模型近似。

       * 撞击是否导致局部变形取决于对象：弹性体有可能，刚体不会。

## 刚体碰撞的冲量法

### 检测与碰撞点运动量

   * **刚体的四个状态变量**

       * 刚体模拟状态里只有四个变量：质心位置 $x$、质心速度 $v$、旋转姿势 $q$（四元数）、角速度 $\omega$。

       * 表面点位置：$x_i=x+R\,r_i$；碰撞检测把每个表面点的位置算出来，逐点代入 $\phi(x_i)<0$ 判定（平面的 $\phi$ 由法向与面上点直接定义）。这是较朴素的检测方式，多边形、多面体的更高级检测另有专门方法。

       * 碰撞点速度：$v_i=v+\omega\times r_i$——旋转在该点产生的速度与旋转轴、质心到点的向量都垂直（右手定则），故取叉积。

       * > **易错点** ⚠️：碰撞点的位置 $x_i$、速度 $v_i$ 都是从四个状态变量导出的量，不是独立状态——直接修改它们没有意义，要改必须改回 $x$、$v$、$q$、$\omega$。

       * 简化设定：只施加速度冲量、不修改 $x$ 和 $q$——对刚体直接改位置与姿势较麻烦，位置修正是非线性问题，一般交给约束类方法处理。

### 冲量推导：从质点到刚体

   * **冲量（impulse，$J$）**

       * > **定义**：一个未知的三维向量；冲量除以质量等于速度的改变量（牛顿定律）。

       * 施加冲量后：$v'=v+\frac{J}{m}$，$\omega'=\omega+I^{-1}(r\times J)$——把力矩公式里的力 $F$ 换成冲量 $J$（$J=F\cdot t$，$t$ 为标量），严格说是"力矩乘时间"在极短时间内的作用。

       * 碰撞点新速度照旧合成 $v_i'=v'+\omega'\times r$；代入展开后，原来 $v+\omega\times r$ 恰是该点老速度 $v_i$，真正变化只剩 $\Delta v_i=v_i'-v_i=\frac{J}{m}-r\times\big(I^{-1}(r\times J)\big)$。

   * **叉乘矩阵（cross product matrix，$r^{*}$）**

       * > **定义**：把叉乘写成矩阵乘法 $r\times q=r^{*}\,q$，其中 $r^{*}=\begin{bmatrix} 0 & -r_z & r_y \\ r_z & 0 & -r_x \\ -r_y & r_x & 0 \end{bmatrix}$，与叉乘逐分量相等。

       * 用途：叉乘没法跟其他量合并运算，矩阵化后整个表达式变成纯矩阵乘法；$\frac{J}{m}$ 一项同步矩阵化为 $\frac{1}{m}E$。

       * > **注意**：$E$ 是 $3\times3$ 单位阵，别与惯量张量 $I$ 混淆。

   * **K 矩阵与冲量反解**

       * 冲量与点速度变化是线性关系：$\Delta v_i=\Big(\frac{1}{m}E-r^{*}I^{-1}r^{*}\Big)J=K\,J$；$K$ 里的质量、惯量张量、力臂全是已知量，唯一不知道的只有 $J$。

       * 想要的速度变化可先算：用质点冲量那套方法算出目标速度 $v_i^{*}$，则 $\Delta v_i=v_i^{*}-v_i$，冲量直接反解 $J=K^{-1}\big(v_i^{*}-v_i\big)$。

       * 推导的动机：$v_i$ 由 $v$ 和 $\omega$ 拼出来、没法直接改，只能借道冲量去改 $v$、$\omega$；质点情形可以直接改 $v_i$，刚体必须走这个间接过程。

### 完整算法与落地细节

```text
对每一个顶点:
    ① 算出顶点位置
    ② 用 SDF(signed distance function) 检测有没有碰撞
        ├─ 没有 → 这个点处理完毕
        └─ 有碰撞
            ③ 算出碰撞点的速度 v_i
            ④ 判断这一点是不是还想继续往下掉 / 继续穿透
                ├─ 已经想离开物体表面 → OK, 不用管
                └─ 还在往下掉
                    ⑤ 质点冲量法算目标速度 v*
                      (法向/切向分解, 得到新的法向速度和切向速度, 合成 v*)
                    ⑥ 算 K 矩阵, 解出冲量 J = K^(-1)·(v* − v_i)
                    ⑦ 用 J 更新刚体: v ← v + J/m
                                  ω ← ω + I^(-1)·(r × J)
```

   * **流水线要点**

       * ⑤算出的 $v^{*}$ 只是中间变量——它不存在于模拟状态，绕过 $v$、$\omega$ 直接改 $v^{*}$ 等于什么都没做；正确路径是借 $K$ 把 $v^{*}-v_i$ 换算成冲量 $J$，再用 $J$ 这个真实物理量更新 $v$、$\omega$。

       * > **易错点**：$v^{*}$ 是"想要"的速度，直接更新它毫无意义；模拟状态里真正存在的是 $v$ 和 $\omega$，点的速度每一时刻都由它们算出。

   * **多点碰撞**

       * 好多点同时碰撞时，取它们位置的平均值做一次碰撞处理；不建议让所有点各自处理，可能导致冲量过大。

       * 性能不用担心：遍历这么多点只是为了做检测，整套冲量公式只针对单个点计算——这正是取平均的原因。

   * **抖动（oscillation）**

       * 成因：重力始终让速度带一个往下走的分量，冲量又永远把它反弹一下，物体贴在平面上反复震荡、停不下来。

       * 实用 hack：发现物体开始静止时，尽量把反弹的那个量调小，衰减抖动；不做也不影响正确性，从美观角度可做。

   * **两个留白**

       * 位置更新：对位置做冲量式修正是非线性问题，交给约束类方法处理。

       * 多物体接触：三个物体就有三个接触点、三个互相影响的 impulse，构成一个系统，问题更复杂。

## Shape Matching：无物理的刚体模拟

### 优化问题与求解

   * **Shape Matching**

       * > **定义**：不含任何物理、纯基于图形学与优化的刚体模拟思路——先把每个点当自由粒子模拟，再把它们重新"拧"回一个刚体状态。

       * 第一步粒子模拟：每个点有自己的力、质量、速度，各自运动、各自碰撞摩擦——质点那套方法全部可用，得到自由模拟后的位置 $y_i$。

       * 第二步聚回刚体：约束后的位置应为 $x_i'=c+R\,r_i$（$c$ 质心、$R$ 旋转矩阵、$r_i$ reference 状态下的位置），希望每个点拉回后尽量贴近 $y_i$，得优化问题 $\min_{c,\,R}\ \sum_i \big\| c+R\,r_i-y_i \big\|^2$；$y_i$ 已知，未知量是 $c$ 与 $R$。

       * 放宽：先让 $R$ 当任意矩阵 $A$，问题简化为 $\min_{c,\,A}\ \sum_i \big\| c+A\,r_i-y_i \big\|^2$。

       * 解 $c$：对 $c$ 求导置零，利用 reference 状态下质心在原点（$\sum_i r_i=0$）消去中间项，得 $c=\frac{1}{n}\sum_i y_i$——约束前后的中心是同一个点，即所有顶点位置的平均。

       * 解 $A$：对 $A$ 求导置零（对矩阵求导与对向量求导同理，不熟可按 $x$、$y$、$z$ 分量展开硬推），得 $A=\Big[\sum_i (y_i-c)\,r_i^{\mathsf T}\Big]\Big[\sum_i r_i\,r_i^{\mathsf T}\Big]^{-1}$。

### 极分解与完整流程

   * **极分解（polar decomposition）**

       * > **定义**：把任意矩阵拆成"旋转 × 对称形变"的乘积 $A=RS$；取旋转部分 $R$ 即刚体旋转。

       * SVD 视角：$A=U\Sigma V^{\mathsf T}=\big(UV^{\mathsf T}\big)\big(V\Sigma V^{\mathsf T}\big)$——$UV^{\mathsf T}$ 是全局旋转（本地坐标系到世界坐标系），$V\Sigma V^{\mathsf T}$ 是本地形变（先转过去、缩放、再转回来的"斜方向缩放"）。

       * 刚体不应有本地形变：直接扔掉形变部分 $S$、保留旋转部分；极分解的结果是唯一的（unique）。

       * $3\times3$ 矩阵的快速极分解有现成算法（出自一篇专门论文），模拟框架里一般直接提供该函数，调用即可。

   * **完整流程**

       * 各点独立模拟得 $y_i$ → 按公式算 $c$ 与 $A$ → 极分解抠出 $R$ → 新位置 $x_i'=c+R\,r_i$ → 速度按"新位置减老位置除以 $\Delta t$"反推 → 再对位置做更新。

       * 每个点速度不同、形状先散开，正是算法设计：先让它随便变，再算出刚体的质心与旋转、把形状约束回去。做软体时慢慢恢复目标形状，做刚体时瞬间恢复。

### 优缺点与适用场景

   * **优点**

       * 容易实现：没有力矩、角速度这些物理概念，对没学过大学物理的人友好。

       * 与基于点的模型容易结合：衣服模拟、其他粒子模型的模拟、粒子法的流体模拟都能直接搭在一起。

   * **缺点与适用**

       * 难以严格保证约束（如摩擦）：约束一个时可能破坏前面已满足的约束，需要迭代反复进行约束——摩擦处理不如基于物理的接触好，物体停下来时会略带轻微滑动。

       * 适用场景：碰撞、摩擦这类精度要求不高时——衣服上的扣子、皮带这类接触不频繁或不要求精确的刚体。

       * 该方法出自 shape matching 最早的论文之一：原本用于形变体，论文里也提出可拿来做刚体模拟。

## 布料的弹簧建模

### 布料与模拟路线

   * **布料（cloth）**

       * > **定义**：二维的面在三维中展开的状态；对照地，头发是一维的线在三维中展开——头发另有自身旋转、类螺旋线模型等特殊性，通用讨论聚焦布料。

       * 模拟路线：先物理仿真（由能量、力模型推导模拟方式），再约束方法（PBD 及其延伸、constraints dynamics），最后专门处理碰撞——布料的碰撞最难，能处理好它，做其他模拟的碰撞相对都容易。

### 弹簧的能量与力

   * **理想弹簧（胡克定律）**

       * > **定义**：弹簧的力试图把弹簧恢复到原长，且这个力与拉伸的长度成正比。

       * 一维：能量 $E=\frac{1}{2}k(x-l)^2$（$k$ 弹性系数、$x-l$ 形变量）；力是能量对位置的导数取负，$F=-\frac{\mathrm{d}E}{\mathrm{d}x}=-k(x-l)$。

       * 连接顶点 $i$、$j$ 的弹簧：$E=\frac{1}{2}k\big(\lVert x_i-x_j\rVert-l\big)^2$；$F_i=-k\big(\lVert x_i-x_j\rVert-l\big)\frac{x_i-x_j}{\lVert x_i-x_j\rVert}$，且 $F_j=-F_i$——两个顶点连同弹簧看成系统时总力为零（作用力与反作用力）。

       * 多根弹簧叠加：能量直接相加 $E=e_0+e_1+e_2+e_3$；总力为 $F(x)=-\big(\frac{\partial E}{\partial x}\big)^{T}$（梯度的定义）。

### 网格上的弹簧布局

   * **结构化网格的三类弹簧**

       * 横竖弹簧：描述面料横向、纵向的形变。

       * 对角弹簧：防止面料在斜 45 度方向上被拉伸，45 度与 135 度两个方向都要有。

       * 弯曲弹簧（bending spring）：对每个点，跨过相邻的另一个点、与另一侧的那个点连一根弹簧——防止面料沿某条线自由翻折；面料偏挺还是偏软，很大程度上就从弯曲造成的褶皱判断。

       * 对角弹簧的简化：错开布置，每个格子只放 45 度或 135 度其中一根——两个方向都兼顾、弹簧数量还更少；一律同一方向会让模拟产生偏向性（该方向抵抗强、另一方向几乎没有抵抗）。

   * **三角网格（非结构化）**

       * 衣服版型常是不规则形状，用非结构化三角网格描述：每条边都认为是一根拉伸弹簧。

       * 弯曲抵抗：对每条内部边，把它所对的两个顶点连接成一根弯曲弹簧——面料想沿这条内部边弯时会有东西拉着；内部边很多，弯曲弹簧也随之很多。

       * > **注意**：弹簧的弯曲模型并不很合适，弯曲还会带来 locking 问题（长文未展开细节，另有别的弯曲模型）。

### 从网格数据构造弹簧

   * **网格的原始表示**

       * 两个数组：顶点位置列表（每个是一个 3D 向量）+ 三角形顶点索引列表（按序号到顶点列表里查位置）。

       * 陷阱：不能直接把每个三角形的三条边都当弹簧——内部边被两个三角形共享，会在同一位置装上两根重复弹簧。

   * **抠边算法**

       * 构造 triple：前两个数是边的顶点索引、第三个数是三角形编号；每个三角形生成三个 triple（一条原始边一个）。

       * 按顶点对排序：内部边的顶点对重复出现两次，排序后必然落到相邻位置。

       * 从头到尾扫描一遍，顶点对相同的剔除一份——剩下的边列表无重复，直接当拉伸弹簧。

       * 弯曲弹簧的来源：刚才重复出现过的边就是内部边；查内部边相邻的两个三角形、找到各自对着这条边的顶点，把这两个顶点连起来即可。也可以改存三角形的相邻关系，两种存法皆可。

### 显式积分与 overshooting

   * **显式积分（explicit integration）流程**

       * 标准粒子系统：$v_{\text{new}}=v+\frac{F}{m}\Delta t$，$x_{\text{new}}=x+v_{\text{new}}\,\Delta t$；比刚体模拟还简单——没有旋转，每个点只有位置，弹簧只是力里面多出的一类。

       * 弹簧的数据组织：一个二维数组存（弹簧编号，连接的两个顶点索引）；另一个列表存每根弹簧的原始长度，由预计算得到（假设初始位置无形变、把初始长度存下来）。

       * 算力分两遍：第一遍遍历每根弹簧、把力按作用力与反作用力分别累加进力的数组；第二遍再用力的数组更新每个顶点——两件事分开写才不易误导。

```text
# 第一遍：先把所有弹簧的力算出来，集中存进力的数组
for 每根弹簧 e:
    i, j = spring_vertex[e]        # 这根弹簧连接的两个顶点
    l0    = rest_length[e]         # 预计算好的原始长度
    f     = -k * (||x[i] - x[j]|| - l0) * normalize(x[i] - x[j])
    force[i] += f                  # 力分别加到 i 和 j 上
    force[j] -= f                  # 作用力与反作用力：方向相反

# 第二遍：再用算好的力更新每一个顶点
for 每个顶点 i:
    v[i] += (force[i] / m) * dt
    x[i] += v[i] * dt
```

   * **数值不稳定（numerical instability）与 overshooting**

       * 机理：$k$ 很大时弹力很大，顶点一步被推过头、冲到另一侧更远的位置；下一步算出的力比原来更大、推得更远，如此反复放大，最终飞出整个模拟空间——与碰撞里的 overshooting 本质相同。

       * > **易错点** ⚠️：overshooting 出现在两种情形——刚度 $k$ 很大，或时间步长 $\Delta t$ 很大；固定 $k$ 时步长一大，一步顶出去的位移就大。

       * 对策与代价：把 $\Delta t$ 调小可行，但模拟很在乎效率、步长太小性能代价高——这就是早年多用显式积分、后来隐式积分流行起来的原因。

       * 隐式积分的形态：$v_1=v_0+\Delta t\,\frac{F(x_1,\,v_1)}{m}$，$x_1=x_0+\Delta t\,v_1$——力要用未知的新状态 $x_1$、$v_1$ 计算，事先无法直接求出。

## 隐式积分化为优化问题

### 消元与受力假设

   * **消元**

       * 困境：位置更新式里写着未来时刻的速度 $v_1$，速度更新式里写着未来的力（力又作用在未来的 $x_1$ 上），两个未知量互相咬着、谁也没法先算。

       * 消掉 $v_1$：把速度式代入位置式，得 $x_1=x_0+\Delta t\,v_0+\Delta t^2 M^{-1}f_1$；速度反推是平凡的 $v_1=\frac{x_1-x_0}{\Delta t}$——真正的问题全压在前一条上。

   * **只与位置有关的力（holonomic）**

       * > **定义**：只跟位置有关系、与速度无关的力，称为 holonomic 的力。

       * 例子：重力算一个（它连顶点的位置都不依赖，是常数）；弹簧力算一个（只跟弹簧两端顶点的位置相关）。

       * 有了该假设 $f_1$ 写成 $f(x_1)$，方程变成只含 $x_1$ 的非线性方程组；力一旦非线性，线性代数的消元手段失效，需要专门的办法。

### 优化表述及等价性

   * **优化形式**

       * $x_1=\underset{x_1}{\arg\min}\ E(x_1)$，其中 $E(x_1)=\frac{1}{2\Delta t^2}\bigl\|x_1-x_0-\Delta t\,v_0\bigr\|_M^2+E_{\text{elastic}}(x_1)$；$\|u\|_M^2=u^TMu$，$E_{\text{elastic}}$ 是力所对应的能量（弹簧有弹簧能量、重力有重力势能）。

       * 对象是全体顶点：$n$ 个顶点摞成一个 $3n$ 维大向量；$M$ 是质量矩阵（mass matrix），一般是对角阵、对角线上放各顶点的质量，$M\in\mathbb{R}^{3n\times3n}$——整个式子是 $3n$ 个方程构成的方程组。

       * 能量的可得性：只有保守（conservative）力才能用能量形式描述，摩擦力等非保守力不行；能量也不用先算力再积分——每种力的能量形式直接写出。

   * **等价性与意义**

       * 依据"最小值点处梯度为零"：对二次型求梯度 $\nabla\big[\frac{1}{2\Delta t^2}u^TMu\big]=\frac{1}{\Delta t^2}Mu$；对能量求梯度得负的力 $\nabla E_{\text{elastic}}(x_1)=-f(x_1)$。

       * 令梯度为零、两边乘 $\Delta t^2$、左乘 $M^{-1}$，恰好还原消元得到的方程——方程组表述与优化表述完全等价，只是同一问题的两种写法。

       * > **易错点** ⚠️：克服 overshooting 的是隐式积分本身，不是"改写成优化"这个动作；消元、改写、牛顿法这一套解决的是"隐式积分到底怎么算出来"。

       * 化成优化的好处：优化问题有大量现成数值方法可直接借用；且不限于弹簧系统——任何想做隐式积分的 dynamics 模拟都适用，有限元也用它。优化可能出现多解（解到局部极值）的隐患，由极值判定处理。

       * 数学定位：解方程组是优化问题的特例；"用牛顿法求根"与"做优化"是一回事——本质上都是对一阶导数求根。走数值路线不依赖反函数、只要能对它求导；早期模拟论文按解方程组处理，近年优化框架更广阔、方法选择更多样。

## 牛顿法

### 一维牛顿法

   * **Newton–Raphson method（牛顿法）**

       * > **定义**：最早为解非线性优化问题而生的迭代法——对导数做一阶泰勒展开并令其为零，沿当前切线跳一步，逐步逼近函数的谷底（$f'(x)=0$ 处）。

       * 迭代式：在 $x_k$ 附近 $f'(x)\approx f'(x_k)+f''(x_k)(x-x_k)$，令近似为零解得 $\Delta x=-\frac{f'(x_k)}{f''(x_k)}$，更新 $x_{k+1}=x_k+\Delta x$，如此反复。

       * 前提是函数连续：不连续则连导数都求不出来；数学上广义的 Lipschitz continuous 就够，不必严格一阶、二阶连续。

       * 不保证一定收敛；后续给牛顿法加条件约束能保证收敛。"隐式积分能克服 overshooting"的证明属数值积分课程内容——本质是证明误差长期看是衰减的。

### 极值判定与解的唯一性

   * **导数为零不一定是最小值**

       * 一阶导为零的点既可以是最大值也可以是最小值（两处切线都平），且这样的点可能有多个；用二阶导数判定：大于零开口向上是最小值，小于零开口向下是最大值。

       * 满足极小条件的点可能只是局部极小（local minimal）而非全局最小；局部极小没有特别好的通用处理方式，实际中常用随机扰动等各种办法对付。

       * > **结论**：二阶导数处处大于零的连续函数不存在最大值（最大值处二阶导小于零），也不可能有两个最小值（中间必夹一个最大值，矛盾）——有且仅有一个最小值。这个条件在后面的模拟里会被利用。

### 向量版：梯度与海森矩阵

   * **向量版牛顿法**

       * 变量是 $3n$ 维顶点位置大向量：一阶导数换成梯度 $\nabla f$（向量），二阶导数换成海森矩阵（Hessian）$\nabla^2 f$；"除以二阶导数"升级为解线性方程组（乘矩阵的逆）。

       * 迭代式：$\Delta x=-\big[\nabla^2 f(x_k)\big]^{-1}\nabla f(x_k)$，把 $\Delta x$ 加到顶点位置上，如此反复迭代。

       * 此处的目标函数就是隐式积分推出来的那个 $E(x)=\frac{1}{2\Delta t^2}\bigl\|x-x_0-\Delta t\,v_0\bigr\|_M^2+E_{\text{elastic}}(x)$；迭代出 $x_1$ 后用 $v_1=\frac{x_1-x_0}{\Delta t}$ 把速度收回来。

```text
隐式积分方程组                                消元
  x1 = x0 + Δt·v1          ──────────►   x1 = x0 + Δt·v0 + Δt²·M⁻¹·f(x1)
  v1 = v0 + Δt·M⁻¹·f1                    （只含 x1 的非线性方程组）
                                               │
                                           等价改写
                                               ▼
       x1 = argmin [ 1/(2Δt²)·‖x1 - x0 - Δt·v0‖²_M + E(x1) ]
                                               │
                                           牛顿法迭代
                                               ▼
                                   x1 ──► v1 = (x1 - x0)/Δt
```

## 牛顿迭代的工程实现

### 一个时间步的流程

   * **目标函数的两块结构**

       * 梯度两块：$\nabla E(x)=\frac{1}{\Delta t^{2}}M\big(x-x_0-\Delta t\,v_0\big)-f(x)$——惯性项的导数，加"负的弹力"（势能对 $x$ 求导得负的力）。

       * 海塞两块：$H(x)=\frac{1}{\Delta t^{2}}M+\frac{\partial^{2}E_{\text{elastic}}}{\partial x^{2}}$——$\frac{1}{\Delta t^2}M$ 加弹性势能的二阶导。

       * 惯性项的含义：$x_0+\Delta t\,v_0$ 是该时间步内顶点靠惯性本来该到的位置。

   * **一个时间步四件事**

       * 初始化：给牛顿迭代一个初始猜测——一般直接用原来的位置，或用原位置加速度的改变量 $x_0+\Delta t\,v_0$，依具体算法而定。

       * 解线性方程 $H\,\Delta x=-\nabla E(x)$，得位置的更新改变量；随后更新位置 $x\leftarrow x+\Delta x$。

       * 更新速度：$v\leftarrow\frac{x-x_0}{\Delta t}$（新位置与老位置的差除以 $\Delta t$）。

   * **只做一次牛顿法的隐患**

       * 早期论文假设面对非线性方程组，做线性化后把线性方程组解掉——等价于只做一次牛顿迭代；这样做可能出现模拟问题、不稳定。

       * 代表文献：Baraff 与 Witkin 的《Large Steps in Cloth Simulation》是最早用隐式积分做衣服模拟的经典论文——不用弹簧系统（另一套模型），对非线性方程做线性化（论文自己也说明等价于一次牛顿迭代）；做衣服模拟项目必读。

       * 站在优化高度的价值：弹簧系统换成有限元只是换能量换力，计算核心都是非线性优化——高层次的统一框架有助于解释模拟现象；对刚体这么做不常见，弹性体有限元、衣服模拟更多。

       * 边界：双方都是粒子模型的多场耦合（布掉在软体上）可用这套；布与流体结合则不行，需要专门耦合模型"分别求解、中间加耦合步"。扩展玩法：衣服吸水拧干——顶点上像海绵一样存水，受力时把水挤出来。

       * 与线性化的关系：对隐式积分做泰勒展开线性化与这里的优化等价（等价到要解的那个线性方程）；实际写模拟可直接构造优化、不必先推一遍方程；其他隐式积分也能套类似套路，欧拉隐式的方程最简单。

### 弹簧系统的海塞矩阵

   * **分块结构**

       * 整体是 $3n\times3n$ 矩阵（每个顶点是三维向量、占三行三列，顶点按 0、1、2 依次每三行三列往下排）；每根连接 $i$、$j$ 的弹簧贡献四个 $3\times3$ 小块，摆在 $i$ 的三行三列、$j$ 的三行三列及 $i$、$j$ 交叉的位置上；多根弹簧的小块重叠叠加。

```text
            顶点0          顶点1          顶点2
          ┌──────────────┬──────────────┬──────────────┐
  顶点0   │  H00(边01)   │  H01(边01)   │  H02(边02)   │
          │ +H00(边02)   │              │              │
          ├──────────────┼──────────────┼──────────────┤
  顶点1   │  H10(边01)   │  H11(边01)   │      0       │
          ├──────────────┼──────────────┼──────────────┤
  顶点2   │  H20(边02)   │      0       │  H22(边02)   │
          └──────────────┴──────────────┴──────────────┘
```

       * 组装方式：每根弹簧用公式算出一个 $3\times3$ 小块，按摆放规则加进大矩阵；例如左上角那一块同时收了边 (0,1) 和边 (0,2) 两根弹簧的对角贡献。

   * **单根弹簧的 $3\times3$ 小块**

       * 记 $x_{ij}=x_i-x_j$（两端点位置差）、$\hat{x}_{ij}$ 为其单位方向向量：$H_{ij}=k\,\hat{x}_{ij}\hat{x}_{ij}^{T}+k\Big(1-\frac{l_0}{\lVert x_{ij}\rVert}\Big)\Big(I-\hat{x}_{ij}\hat{x}_{ij}^{T}\Big)$。

       * 半正定的证明：任取向量 $v$ 算 $v^{T}H_{ij}v$——第一部分是平方 $k(\hat{x}_{ij}^{T}v)^2\ge0$，第二部分由柯西不等式保证 $\ge0$；两部分均非负。严格说法是半正定（semi-positive definite），而非通常说的对称正定。

       * 压缩风险：弹簧被压缩（$\lVert x_{ij}\rVert<l_0$）时系数 $1-\frac{l_0}{\lVert x_{ij}\rVert}$ 变负，海塞小块可能不正定；拉伸时一定正定。说"可能"，是因为整个系统矩阵里还有质量矩阵等其他项兜底，不能断定它一定不正定。

       * 系统整体的正定性由每一个小块决定，逐块检查即可。

       * 顶点质量可以各不相同：一般按面积给每个三角形算质量，再把三角形的质量三等分、分布到三个顶点上。

### 正定性与压缩问题

   * **正定为什么重要**

       * 海塞是目标函数的二阶导数；矩阵正定对应实数函数"二阶导恒正"，此时函数存在唯一的极小解——对弹簧系统是非常重要的一点。

       * $\Delta t$ 越小，惯性项 $\frac{1}{\Delta t^2}M$ 越大、系统越正定、模拟越稳定——与显式积分"步长小更稳定"是同一回事。

       * > **易错点** ⚠️：正定是"存在唯一解"的充分条件而非必要条件——不能严格说不正定就一定没有唯一解；但正定时系统稳定得多，压缩时更容易出问题。

       * 压缩出问题的直观图像：弹簧被挤压会蜷起来，往上翘或往下翘都有可能——两种状态都满足能量最小化、是不同的局部极小，事先不知道往哪边翘；这个问题三维出现、一维不出现（一维弹簧能量的二阶导就是 $k>0$）。

       * 解析解的边界：一维弹簧是简谐振动、有解析解可对照；二维三维一般没有解析解。

       * 弹簧模型的先天局限：只考虑两个端点的相对位置、假设弹簧永远是一条直线，不考虑弹簧自身的弯曲——单纯用这种弹簧模型，对弯曲的模拟存在很大问题。

   * **不正定的粗暴修法**

       * 为什么在意正定：不少线性求解算法要求矩阵必须正定——这是算法稳定性的考量，不是数学模型稳定性的考量；即使不正定，只要能解出一个结果，模拟总还是有一个结果。

       * 直接删项：压缩时把弹性海塞那一项抹掉，剩下的 $\frac{1}{\Delta t^{2}}M$ 一定正定，问题解决；更精细的方法见《Stable but Responsive Cloth》论文，里面列举了矩阵不正定时的多种调整手段。

### 线性方程求解器

   * **Jacobi 迭代（雅可比迭代）**

       * 解 $A\,\Delta x=b$：给 $\Delta x$ 初值 → 算残差 $r=b-A\Delta x$ → 更新 $\Delta x\leftarrow\Delta x+\alpha\,D^{-1}r$（$D$ 是取 $A$ 对角线元素组成的矩阵），多次迭代下去。

       * 教科书版取 $\alpha=1$、要求矩阵对角占优；矩阵没法保证对角占优时，带一个 $\alpha$ 能让方法在更多条件下收敛，推荐带 $\alpha$。

       * 牛顿迭代里解线性方程用什么方法都可以，Jacobi 只是举例；方程一般不会无解——弹性海塞单独看是奇异的（半正定、可能有零奇异值），加上质量矩阵那一项后大概率可逆：没有零奇异值就可逆，方程就有解。

   * **直接法与迭代法**

| 对比项 | 直接法 | 迭代法 |
| :--- | :--- | :--- |
| 对矩阵 $A$ 的要求 | 约束小，基本都能操作 | 有收敛问题 |
| 常见平台 | 一般在 CPU 上 | GPU、CPU 都能做 |
| 精确解 | 直接给出 | 想要精确解会比较慢 |
| 实现难度 | 通常依赖现成数学库 | 实现起来比较容易 |
| 内存开销 | 大，限制可解规模 | 小很多，能支撑更大规模 |

       * 选择经验：自己动手写推荐迭代法；有现成数学库（如很强大的 Intel MKL）建议直接法；GPU 上两者皆可用，直接法会稍慢一点。

       * 共轭梯度（conjugate gradient，CG）的效果取决于预条件子（preconditioner）：没有预条件子时效率并不高；GPU 上预条件子的选择比较有限，CPU 上一般用 ILU（incomplete LU 分解）。

       * 实操经验：矩阵很大时谱（spectrum）根本没法算，不用谱去衡量矩阵；调参很多时候就是试错——不收敛就把系数调小一点再看，只要不断地调，总能找到一组合适的参数让它收敛。

       * 隐式积分天然比显式复杂，但追求高性能、顶点数量多的模拟就需要它。
