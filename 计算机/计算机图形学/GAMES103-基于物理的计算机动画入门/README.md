# GAMES103：基于物理的计算机动画入门（12 讲）

GAMES103 讲基于物理的动画：数学基础与数值积分、刚体动力学与碰撞、约束系统与弹簧质点、有限元与碰撞处理、流体模拟（欧拉与粒子视角），最后一讲用高度场做水面（Shallow Wave）。课程从「状态 + 方程 + 求解」的通用框架出发，落到布料、头发、刚体与流体几个典型场景。12 集整编为 5 册、8 篇主题笔记。

## 怎么学
- **数值积分先过关**：显式/隐式欧拉与稳定性，后面所有仿真都靠它。
- **刚体部分抓「状态 + 方程 + 求解」三段式**，碰撞响应单独练。
- **约束系统对比拉格朗日乘子与 PBD**，理解各自适用场景。
- **有限元抓住「形变能 → 力」的推导**，不用背矩阵。
- **流体两视角对照学**：欧拉网格 vs SPH 粒子，最后用高度场水面收束。
