### 预备知识：门槛已经降到最低

上这门课需要准备什么样的知识？我个人是想把这个课的要求降到最低的：有一些基本的数学知识——比如线性代数、微积分——再加上一些基本的编程能力，相对而言就够了。有其他储备的知识更好，但基本上标准就设在基础编程知识和基础数学知识这一块上。

这个标准不是随便定的。我之前在学校教书的时候，有一个相对应的类似课程，主要面对大三大四的同学，基本上假设他们之前没有上过图形学、对图形学没有什么了解，把这门课当作图形学的第一节课、一个入门的机会。所以这门课在难度设置、预备知识上也是这么一个标准。当然，研一研二的同学如果对物理模拟比较感兴趣，也完全可以上这个课。

具体展开。线性代数在图形学里用得比较多，肯定是少不了的：主要是矢量、矩阵、线性系统，还有特征值分解这些基本概念。你可能不会手工去做 SVD，但是你需要了解 SVD 是个什么样的事情。微积分的话，基本的求导要会。求导有个链式法则——当你有好多个函数、这个函数又是另一个函数的函数的函数的时候，链式法则会帮助你求导——大家还记不记得？类似这样，求导、积分这些概念要有一些了解，包括怎么样手工做一些简单的计算。梯度、泰勒展开这些，最好也稍微有一些概念上的了解。

编程方面，我个人觉得，学一门计算机的课，如果说不做作业，这个就是毫无意义的事情，对不对？你就其实只是听听而已，没有办法很深入地去掌握这个东西。所以我们的作业是编程作业：用 C#，在 Unity 里做，因为 Unity 的脚本本身就是 C#。如果你会 C、C++、C# 或者 Java，其实都很接近，都可以拿来写这个代码。拿我自己举例：我之前没有接触过 C#，但是我会 C、会 C++，写这个脚本是完全没有问题的。

图形学基础呢？有同学问要不要先上 GAMES101。其实并不是特别需要。你最好稍微懂一些简单的图形学概念——比如旋转、做一些简单的 transformation，渲染大概是这么回事儿，你可能需要了解一下——但是很复杂的图形学知识其实是不需要的。

至于那些看起来门槛很高的物理、数学——数值算法、数值线性代数、数值偏微分方程、有限元分析、流体力学等等——我估计很多同学之前会觉得，要做物理模拟就必须先懂这些。确实，要做深是需要懂的。但如果你之前不具备，也不要紧：我们这门课本身就是在帮大家学习这方面的知识，课程内容会覆盖这些数学的计算方法、流体力学的知识，然后学习怎么样利用这些东西去做动画的开发。会了更好；不会这些很高级的物理、数学概念也没有关系，我们会具体提到。

还有一点希望大家能做到：主动地学习。课程能够涵盖的东西毕竟只是一个子集，如果你要很深入地理解很多东西，肯定需要课后去阅读、课后做更多的实验和操作。希望大家有自学的精神，这个蛮重要。

### Unity 与硬件：把顾虑都放下

关于 Unity 的问题比较集中，我一次说清楚。

没接触过 Unity、完全没有经验，没有问题。我选 Unity 就是因为它上手其实很容易：花一天时间——可能两天都不用——把一些简单的教程看一下就可以了。对比一下最早的情况：还没有 Unity 的时候，我们最早上课用的是 OpenGL。OpenGL 上手起来就会难一点，需要花更多的时间去学习它的机制。有了 Unity 之后，上手相对来说容易很多了。

为什么用 Unity 而不是 Unreal？因为我们的作业不是凭空让你做的：我会给你一个小 demo，你要根据这个小 demo 去写脚本、再去扩展。原始代码和场景都是用 Unity 写的。如果你自己有能力、愿意花时间把它移植到 Unreal 上，也可以，但是工作量会比较大；用 Unity 的话，你只需要完成脚本的编写工作就可以了。

Unity 版本没有什么太大的要求，只要不是很老的版本都可以。我自己作业里的一些代码就是用老版本写的，也完全可以运行。个人版、学生版都是可以的，是一样的，而且对个人是免费的。Mac 也可以，Windows 也可以；Linux 我记得好像会有一些问题，他们没有支持——不过应该也没有什么同学在 Linux 上跑，我自己用的也是 Mac。

显卡的要求其实很低：大部分计算都是基于 CPU 的，没有什么 GPU 的要求。我们做的这些例子、demo 也比较简单，不会用几十万、几百万个点的模型。一台笔记本，只要不是十年旧的那种特别老的，大部分情况下都没有什么太大的问题。这一点大家不用担心。

渲染也不用管：Unity 本身就有一个渲染引擎，直接拿它自带的那个用就可以了。至于怎么用 Unity 交作业，讲作业的时候会跟大家具体讲，到时候看公告。

Unity 的主页大家可以去把引擎下载下来；另外有 Unity 的论坛，涉及「怎么样使用 Unity」这类比较通用的问题，可以在论坛上得到一些解答。

最后有一点需要强调：我们用 Unity 主要是把它当作学习的工具，本身并不是学怎么用 Unity——这个区分还是有点重要的。我希望大家把更多的时间花在写脚本、阅读知识、掌握知识上，跟 Unity 纯引擎相关的东西会尽量少一点。比如 Unity 自身也有物理引擎，但我们大部分时间都不会使用它——我们写的脚本，其实就是替代了它原有的物理引擎。

### 十二周的课程规划与四次作业

既然大家问了这么多，我干脆把 schedule 这一页给大家看一下。总共 12 周，大概是这样走的：

- 第一周，也就是今天：一个简介介绍的形式。
- 第二周：主要讨论数学。数学挺重要的，我们会把需要的一些基本概念过一遍，同时举一些例子——比如怎么去计算四面体、怎么去计算投影等等；还有 vector calculus，大家可能有听说过，我们也会有例子，比如给你一个弹簧，怎么样去算这个弹簧的能量、以及推导出来的一些矩阵、stiffness matrix 之类。我们会用比较简单的例子，给大家看数学是怎么应用在图形学的具体问题上的。
- 第三周开始线下课：我们首先花两周——第三周和第四周——来讨论刚体，包括刚体的动力学、刚体的接触，也就是刚体的碰撞、刚体的摩擦。这个完了之后就有第一次作业，我们会用刚体做一个作业。
- 第五、六、七周：三周的时间来讨论衣服的模拟，同时引入 PBD（Position Based Dynamics）、Projective Dynamics，还有 Constrained Dynamics 这一套，把衣服这一块给大家吃透。同样还有作业：基于 PBD 的，还有基于弹簧系统的。
- 之后讨论 soft body dynamics：会讲弹性体，也会讲有限元。针对软体有一个比较简单的小作业——给大家一个小的软体，在地上弹弹弹，做这么一个效果。
- 第十、十一、十二周：讲流体。会讲表面波；然后讲网格法，就是不可压的流体动力学——Navier-Stokes 方程——怎么样用网格法去解它；然后讲粒子法，怎么样用 particle-based 的方法去解流体。

总共是四次作业，每次作业针对一个方向。

这里我想说一下物理模拟的一个特别大的好处：每一个方向其实都是相对比较独立的。它不像有的学科——尤其是数学——可能你第一天听不懂，后面就完全更听不懂了，前后是有关系的。我们每天讲的内容基本上是一个独立的章节：你刚体没学好，或者刚体的课没来得及听，没有关系，后面讲弹性体的时候你还是可以继续跟得上。不用担心前面 miss 掉了之后，后面就没有办法跟上——反正后面可以补上，后面的课也可以继续听下去。这个我觉得是一个好处。

顺带回答两个关于课程内容边界的问题。有同学问，会不会介绍当今游戏引擎里基于物理的动画？我们不会具体介绍游戏引擎里面的物理引擎本身，但是会介绍这些物理引擎所用的算法——比如现在物理引擎里很多时候用到的 PBD，我们会介绍这个算法、它的优缺点，以及它跟其他一些类似算法的比较。还有同学问 MPM。MPM 我们不会讲，因为它是一个比较小众的 hybrid 算法：它不是一个单一的方法，本质上是把几个方法合在一起——把粒子法跟网格法合在一起。我们这个课主要介绍基础的、比较大众的算法，粒子法、网格法都会涉及到；你懂了粒子法、也懂了网格法之后，以后在高级课程或者其他课程里自己去学 MPM，相对来说就会容易很多。

### 什么是图形学

首先，图形学你可以简单地认为：怎么样去构造一个 3D 的虚拟世界，然后把这个 3D 虚拟世界通过 2D 的形式呈现给大家。所以图形学涉及到很多关于 3D 虚拟世界的东西：怎么样去构造这个虚拟世界、怎么样去运行这个 3D 虚拟世界、怎么样渲染——怎么样把这个 3D 的世界转化成 2D。

> **定义**：图形学，简单说就是构造一个 3D 虚拟世界，并把它以 2D 的形式呈现出来。

有同学可能会把图形学跟计算机视觉混淆在一起，或者理不清它们的关系。其实你可以把计算机视觉跟图形学认为是两个完全相反的方向：图形学是从 3D 到 2D——从 3D 的虚拟世界到 2D 的图像；而计算机视觉是给你 2D 的图像、给你影像，你怎么样去理解这个影像中的 3D 场景——它可以认为是反方向的一个操作。

> **提示**：图形学和计算机视觉都是围绕着 3D 跟 2D 之间的关系在做文章，但方向刚好相反——一个从 3D 到 2D，一个从 2D 回到 3D。这就是为什么大家看这两个方向的论文，会发现有相当一部分重复。

当然，图形学有的时候会用到 vision 所需要的东西。比如我们想要构造 3D 虚拟世界的时候，可以从真实的影像出发，去做三维重建这些东西。但我希望大家能够比较深刻地理解到：这两个东西刚好是一个相反的关系。

图形学大概有三个比较典型的方向。一个是几何：关于怎么样构造这个 3D 的世界。然后是渲染：怎么样呈现这个 3D 世界——光是有个 3D 世界不行，对吧？我必须要显示这个 3D 世界，而我们今天大部分的显示设备都是基于 2D 图片、基于像素的形式的，所以怎么样把这个 3D 转化成 2D，这是渲染。最后是动画：怎么样把这个 3D 世界运行起来。因为我不希望是一个静态的世界——真实的世界里物体都是有运动的——所以我也希望在这个 3D 世界里面，把这个世界运动起来。

这里我用了 bunny 这个例子，因为在图形学里面，bunny 是一个比较知名的模型，叫做 Stanford bunny，大家一般来说都喜欢用它来做 demo。

### 图形学的管线：从几何到显示

那么图形学大概是一个什么样的 pipeline、什么样的流程？刚才讲到有几何、动画、渲染三个部分，理想情况下，它们串成一条实时的管线：

```text
┌────────────┐    ┌────────────┐    ┌────────────┐    ┌────────────┐
│    几何    │ -> │    动画    │ -> │    渲染    │ -> │    显示    │
│            │    │            │    │            │    │            │
│ 构造3D世界 │    │让世界动起来│    │  3D转成2D  │    │ 呈现给用户 │
└────────────┘    └────────────┘    └────────────┘    └────────────┘
```

读图：几何排第一，负责把 3D 虚拟世界构造出来、创造出来；动画让虚拟世界里的物体——比如一些圆柱、一些笑脸——动起来；渲染把 3D 的虚拟世界转化为 2D 的图片；最后把这些图片发送到显示设备里，通过显示设备展示出来。这是一个理想情况下的实时的图形学管线。

几何实际上一般来说不需要实时。为什么？因为构造这个 3D 虚拟世界，我完全可以离线地操作嘛：我可以通过一些辅助工具，甚至通过计算机视觉的一些算法，离线地把这个 3D 世界创造出来，这都没有关系。但是动画跟渲染必须是实时的。因为如果说你这个虚拟世界需要跟用户有交互——玩家像游戏里的玩家做一些操作——我需要这些玩家的操作能够对我的虚拟世界产生影响，那么我的动画跟渲染就必须是实时的，必须能够让用户或者玩家马上看到这些操作所带来的效果。

#### 帧率与交互

这里其实有个概念就叫帧率（frame rate）：显示设备以多快的速度去展示这些渲染出来的帧。

> **定义**：帧率（frame rate）——显示设备以多快的速度去展示渲染出来的帧。比较典型的帧率有 24 帧、30 帧、60 帧。

先考大家一个问题：传统电影一般来说帧率是多少，有知道的吗？——对，24 帧。那游戏一般来说是多少帧？其实都有：30 帧的也有，60 帧的也有。区别主要在于什么？其实主要在于交互。游戏是强交互的一个应用：如果玩家做出一些操作，你希望玩家的操作能够很快地在游戏里面体现，那么帧率就要相对来说高一点——尤其是一些比较竞技类的游戏，比如 160 帧，相对来说就高很多。而电影没有交互，帧率要求就会比较低：24 帧对于我们的肉眼来说，基本上已经看不出不连续的效果了。但如果交互性比较强的游戏只有 30 帧，其实就会有一些延迟、有一些卡顿。

我们图形学里面一般来说标准的帧率是 30 帧每秒。这里就是给大家一个基本概念：帧率跟交互有关系，跟用户的体验也有关系。

#### 实时做不到怎么办

刚才讲的是实时的动画、实时的渲染。但事实上，实时这件事情相对来说是比较难的。为什么？因为我们的计算量、硬件的计算能力是有限的：如果你想要做一个非常真实、逼真的效果，硬件可能就没有办法支撑这样的计算量了。

那么这种情况下怎么办？也不是说图形学就没有相对应的应用了——也是有的，只不过应用会比较窄一点。比如我可以把动画作为离线的部分，把渲染作为实时的部分：换句话说，我不需要实时地去模拟动画、不需要做交互，我可以把动画事先给录下来，然后回放，把这个渲染的效果实时地展现给大家，就够了。这种形式一般来说在游戏里的过场动画里面比较常见——因为过场动画不需要交互嘛，它可以完全就是一个渲染的展示。还有一些电商商品的网上展示，很多也是采用这样的形式：只做实时的渲染，不做实时的动画。

我们甚至可以搞得更极端一点：完全做成一个数字电影。做成电影的话，从几何到动画到渲染就全部都是离线的方式了——我可以离线地把这些渲染效果、动画效果生成好，然后把它录制到电影里面，做一个回放就可以了。这就是电影跟实时图形学应用的差别：电影不需要实时、不需要实时交互，所以它采用的模拟也好、动画也好、渲染也好，计算量相对来说都可以大一点——可以花好几周甚至好几个月的时间去做渲染、去做模拟，这都没有关系。

| 应用形态 | 动画 | 渲染 | 典型场景 |
| :--- | :--- | :--- | :--- |
| 全实时 | 实时模拟 | 实时渲染 | 需要交互的游戏 |
| 动画离线、渲染实时 | 事先录制、回放 | 实时 | 游戏过场动画、电商商品展示 |
| 全离线 | 离线 | 离线 | 数字电影 |

三种形态的差别就在交互上：交互要求越高，需要实时跑的环节就越多；完全没有交互，就可以全部离线，用充足的计算时间去换更逼真的效果。

### 几何表达：从网格说起

接下来，我想跟大家讲一下刚才讲的这三个方向——几何、动画、渲染——它们里面大概有些什么样的内容、有哪些问题。首先第一个是几何。

几何是关于怎么样去描述这个 3D 世界的。那怎么样去描述 3D 世界？通常有三种表达方式。第一种表达方式是网格（mesh）。

#### 网格由什么构成

拿那只 Stanford bunny 来说：这个兔子是通过一些三角形来描述的。兔子表面这个 mesh 由两部分构成：一个部分是顶点，就是覆盖在兔子身上的这些顶点；另一个部分是由这些多边形元素或者多面体元素所构成的，比较常见的一般是三角形。多边形——比如四边形——在一些设计软件里面，比如 Maya，用得会比较多一点，因为它比较符合大众的设计习惯。而如果以后我们做软体、包括弹性体的一些模拟的时候，会用到四面体的网格，在这种情况下我们的元素就是四面体。所以元素取决于你的内容是什么。

> **结论**：三角形可以认为是整个图形学的基础——包括我们整个图形学的硬件、GPU 显卡，整套都是基于三角形渲染框架的。如果大家对硬件有一些了解，可能都知道，三角形是一个很基础的元素。

#### 围绕网格的经典问题

mesh 是一个很基础的表达方式，所以关于 mesh 的问题其实有很多。

首先是怎么样去构造这个 mesh，能够让三角形有比较好的质量。我们不希望出现很窄的三角形、很细的三角形，我们希望大部分三角形看起来都比较正——都是接近 60 度的正三角形。怎么样去调整这个三角形网格、让三角形看起来比较正一点？这个就叫 remeshing。

然后是简化：有的时候我们的硬件没有办法支持很多很多三角形，我们希望可以减少三角形的数量，同时又不希望 mesh 的形状发生很大的改变，那么就需要做简化。反过来的操作是细分：怎么样去增加三角形。

还有怎么样对 mesh 做优化：可以做平滑，可以计算 mesh 上面的 flow，等等等等。

最后还有一个比较有挑战性的：怎么样处理 volume mesh。所谓 volume mesh，就是类似四面体网格这样的 mesh。它比三角形网格处理起来的难度要大非常多——这个也是为什么做四面体网格、做有限元分析是一个难点。总的来说，volume mesh 相对来说处理起来会比较难。

#### 结构化与非结构化网格

mesh 有两种比较常见的类型。一种叫做 structured mesh：这种 mesh 是有一定规律性的。比如它是一个方方正正的格子——当然不见得一定是一个横平竖直的格子，它有可能是基于六边形搞出来的 mesh，或者是基于某些特殊形状的：比如对一个球形，可以按足球的形状做一些特殊的分解，等等等等。总之你这个 mesh 是有一定规律的。第二种 mesh 是 unstructured mesh：它是没有什么规律的，你可以认为是一个比较「乱七八糟」的 mesh。

相对应地，volume mesh 也一样有 structured volume mesh 和 unstructured volume mesh 两种。

我为什么要提这个区分呢？因为对于 structured 跟 unstructured mesh，其实会有不同的计算方式。structured mesh 有一个很大的特点：它有 structure。那么有一些模拟算法、有一些几何算法，就可以利用这个 structure 做一些文章——做一些简化、做一些优化，等等等等。我们这个课看看情况，有可能会提到一些针对 structured 做简化优化的东西。当然，unstructured 最大的好处就是它比较通用：它对结构没有什么要求，所以通用性会更强一点。

网格讲完了，再看几何的第二种表达方式：点云。说白了，点云就是很多点。三种表达方式，这里刚讲到第二种。

## 从点云到流体：物理动画的全景图
> 对应块：BLK02 | 覆盖分集：P01下 | 块标题（分集名）：《Lecture 01 Intro to Phys》

### 点云与格子

点云这种表达方式，最大的好处就俩字：简单。你不需要考虑三角形，不需要考虑三角形之间的连通关系，只需要用一大堆点把物体描述出来就行了。也正因为简单，点云通常是以"原始数据"的身份出现的——比如用 3D 扫描仪扫一个物体，得到的原始数据往往就是一大堆点云。

但简单归简单，围绕点云有一串对应的问题要解决。第一个问题：怎么从点云里构造出 mesh？直接给一坨点，是没有办法渲染的——更准确地说，是没有办法用硬件做渲染的——所以得先把 mesh 构造出来，才能拿去做渲染。第二个问题：怎么对点云采样？点云往往有的地方疏、有的地方密，怎么重新采样，让它的稀疏程度一致，这也是个问题。第三个问题：怎么找近邻？给一个点，你怎么知道它周围有哪些点？很多算法里都要用到近邻查询，等等等等。

最后一种表达方式就是 grid。grid 本质上是一个三维的格子：把空间划分成很多小方块、小格子，每一个块叫一个 cell，每个 cell 里储存了一定的物理量。这种格子式的表达，最常见于医学和科学实验的原始数据——比如做 CT，比如做大气的一些流体模拟，很多原始数据就是基于这种格子来组织的。

grid 的问题也很直接：内存消耗会很大。要想把一个三维空间划分得非常细，就需要大量的内存。有一些解决方案，比如用 octree（八叉树）之类的结构来减少内存占用，但总的来说，内存始终是一个问题。渲染上则有两条路：一种是把它转化成 mesh 再渲染；另一种是直接对这个 volume 的 grid 做渲染，叫做 volumetric rendering——这本身也是图形学里的一个研究课题。当然，围绕 grid 还会延伸出各种各样的问题，跟动画相关的那些，我们后面也会谈到。

> **提示**：mesh 和 grid 怎么区分？mesh 是定义在物体上的——三角形或者多边形组成的网格，贴着物体走；grid 是定义在整个 3D 场景上的——把空间细分成一个一个小格子的体系。记住这一句就够用了。

### 渲染：真实感与非真实感

渲染分成两个大的内容：一个叫 non-photorealistic rendering，非真实感渲染；另一个叫 photorealistic rendering，真实感渲染。大家比较熟知的应该是 photorealistic rendering。为什么？因为 non-photorealistic rendering 这个领域最近几年衰败得特别厉害，做这方面研究的人特别少，整个领域大部分以 photorealistic rendering 为主。但也不能说非真实感渲染就没有用了——包括游戏也好，还有一些设计软件、绘画软件也好，其实有很多地方用到了 non-photorealistic rendering 的技术。当然，我们这门课不是关于渲染的，这里就不具体展开了。

photorealistic rendering 主要有两种类型：一种基于光线追踪，另一种基于传统的渲染管线。这个不知道也没关系，反正我们这课也不是关于渲染的。这里直接看一个对比效果：用 NVIDIA 的 RTX 做的演示，左边没开 RTX，右边开了 RTX——也就是右边做了光线追踪。可以看到，做了光线追踪之后，可以产生更好的折射、反射效果。

### 材质获取与人体的渲染

渲染里有一块，我个人觉得挺重要、但研究得相对较少的：材质的获取。因为光是有渲染引擎是没有用的，你还需要有材质。怎么去扫描材质，怎么把做出来的效果弄得跟真实的一模一样，这其实是一个蛮大的挑战。比如有人搞的扫描仪，扫描皮革，再用扫出来的数据做渲染——效果非常逼真。

关于扫描，还有一个很重要的对象：人。因为人不是一个平面，你没有办法把它当一个平面的材质那样去扫——人体是有曲面的皮肤，是一个曲面上的物体。所以图形学、尤其是电影领域，就搞出了一种叫 light stage 的技术：把一个房间布满各种各样的灯光，还有各种各样的摄像头，利用不同的灯光、摄像头不同的位置，捕捉人体在不同角度、不同照明情况下的效果，把一个人的整个渲染外观捕捉出来。

这里最大的问题，就是你怎么构造 BRDF。而且对人体来说，还有一个更大的挑战：人体皮肤不是 BRDF，而是 BSSRDF。也就是说，光打到皮肤上之后会进去，然后从另外的地方出来——它不是一个简单的在表面做反射的模型。如果你上过涉及半透明材质的高级渲染课，可能会了解这方面的东西。这就是为什么人体的渲染会特别难、特别有挑战性。

再加上一条：人其实对人自身是很了解的。如果你看到一个人渲染得特别不像，你第一时间就能看出来。但对相对来说没那么了解的东西，你的容忍程度就会高一点。举个例子：认人是相对容易的，张三李四王五，一看他的脸，你可能就认出来了；但是猫猫狗狗，有很多长得特别一样，你就没有办法判断出来——为什么？因为你没有每天都在观察这些猫狗。就一个道理：人对自身比较了解的东西，能够辨识出真假；对相对来说没那么了解的东西，容忍度就会高一点。

### 角色动画与物理动画

动画分为两类：一类是基于人体的动画，叫做 character animation（角色动画）；另一类是基于物理的动画，physics based animation。我们这门课主要就是后者——关于怎么样利用物理去求解，然后把动画效果给它做出来。当然，在现实的图形学应用里面，这两者是不分家的：人要穿衣服嘛，人要跟整个环境有交互嘛，所以你既需要人的动画，也需要物理的动画，这就是为什么这两者都相对比较重要的原因。

这里看一个 UE（Unreal Engine）前几年发布的虚拟数字人的效果。视频里这位虚拟人自我介绍：拥有 state of the art 的实时图形，眼睛、皮肤、头发的细节达到了前所未有的水平；而且她"不只是一堆漂亮的像素"（more than just a collection of fancy pixels）——她由一位真人演员通过动作捕捉、经由 Unreal Engine 实时驱动，最后还招呼大家到 Vicon 展台当面看她。从这个 demo 里你可以看到：它既有人体的模拟、人体的动画，同时也有物理模拟的动画——这两个是需要相结合的。

### 图形学能拿来干什么

一个主要的应用就是娱乐行业：拿来做游戏，拿来做电影特效，还有很多轻娱乐的产品——比如抖音、MetaHuman、数字人，还有各种社交媒体里面，其实都有图形学应用的需求。所以娱乐是一个比较重要的行业。

然后图形学可以拿来做设计，也就是计算机辅助设计（CAD）跟计算机辅助工程（CAE）。比如机械领域，需要大量的图形学辅助工具；建筑行业、艺术设计、时尚等等一系列领域，都需要用到图形学技术。这里可以看一个我们凌迪科技做的 CAD 软件 Style3D Studio：用户通过一些 2D 的版片，把一件 3D 的虚拟服装制造出来；右边是渲染出来的效果图——一件利用真实服装制造工艺设计出来的虚拟数字服装。

图形学对电子商务、跨境电商，也有很重要的作用，关键词是智能制造：怎么样把数字化的产品作为商品推销出去、销售出去，让消费者能够看到数字化的产品、下单，我们再通过智能制造把这个实物制造出来。这是最近一段时间特别火的一个概念，而计算机图形学在智能制造里面起到了非常重要的作用。

社交媒体上的例子就是网红直播带货，这个大家多少都了解一些。网红带货里带货最多的是什么？服装跟化妆品。那么服装怎么样把数字的服装跟制造相结合，把整个服装的产业链带动起来，图形学也在其中起到非常重要的作用。

近一段时间比较火的，还有元宇宙，还有 VR、AR，所谓 MR 这些概念。图形学在里面起到非常关键的作用——因为要构造一个虚拟的世界，你就离不开计算机图形学技术。这里看一个我们最近做的 AR 效果：左边的模特是真的，但左边这个衣服是假的（虚拟的）；右边是真实照片的对比图。牛仔裤的例子也一样——上衣跟裤子都是虚拟的，右边是照片。可以看到，目前我们做到几乎是以假乱真的效果了。AR 未来一个很自然的应用，就是虚拟样衣，或者虚拟模特。

### 动画的本质：按时间点更新状态

接下来想讲清楚：什么是计算机动画，什么是基于物理的计算机动画。先看一个基于物理的动画例子——这里面对人体也做了建模，我们是有人体模型的。注意，这个不是实时的：实时其实很难做到，我们实际上是一个离线的过程。

那动画大概是一个什么样的操作？我们的最终目的，是想把这些物体给动起来。我们会设定时间点 $t_0, t_1, t_2, \ldots, t_n$，每一个时间点上，我都需要得到这些物体的状态。所以动画本质上就是：我需要在每一个时间点去更新这些物体的状态；当我完成这个更新之后，动画就做出来了。

```text
t0 --dt--> t1 --dt--> t2 --dt--> ... --dt--> tn
|          |          |                     |
更新状态    更新状态    更新状态          更新状态
```

从 $t_0$ 到 $t_n$ 设定一串时间点（省略号表示中间更多时间点），在每个时间点上更新一遍物体的状态，动画就出来了；相邻两个时间点的间隔，就是下面要说的步长。

> **定义**：动画本质上就是在每个时间点上更新物体的状态。

那么，有什么样的状态需要更新？取决于你动画的内容是什么。可以更新它的位置、更新它的姿势、更新它的速度；也可以更新它的外观是什么样子的——举个比较极端的例子，变色龙；比如模拟一个火焰，火焰的颜色会发生改变；还可以更新密度，比如做一个烟雾的动画效果，就要更新烟的密度，等等等等。不同的动画，需要更新的状态不一样。

两个时刻之间的间隔，我们叫做步长（time step），记作 $\Delta t$。步长可以跟你的帧率一致，但也不要求必须跟帧率一模一样——时间步长完全可以取得更小一点，这种情况下渲染一帧，可能就需要模拟更多个时间步。这都没有关系，取决于你的引擎是怎么样设计的。

> **提示**：时间步长和帧率是两码事。模拟按 $\Delta t$ 一步一步推进，渲染按帧出画面；二者不必严格对齐，一帧里面可以包含多个模拟步，这纯粹是引擎设计的选择。

所以，我们很多时候讨论物理模拟，主要讨论的就是一个问题：怎么在一个时间步长里面更新这些状态。这就是我们要研究的东西。

### 物理模拟的四大对象与三种表达

整个物理模拟大概可以分成四个方向。从左到右分别是：刚体（rigid body）；衣服跟头发——我把它归为一类，就是那种比较窄的、或者比较细的物体；然后是弹性体，也就是软体（soft body）；最后是流体，流体包括液体和气体，我们一般来说把液体和气体当作一类流体来处理。针对这四大类，配上刚才讲到过的三种表达方式——mesh、particle、grid——我们就有三种相对应的模拟技术。

#### mesh 是主阵地

对于刚体、头发、衣服还有弹性体而言，一般来说我们都是用 mesh。为什么？因为一般来说，这些物体的整个形态都是比较固定的，不会发生剧烈的撕裂或者断裂这种现象——这种现象相对会比较少，它们基本上都是一个整体。就算是弹性体，它的形变会比较大一点，但它还是一个整体。所以一般来说，我们都会用 mesh 来做这些模拟。

可以看几个对应的例子。一个是在 YouTube 上用 Blender 做的刚体模拟：很多方块最后掉到地上，堆成一团的效果。另一个是我们前几年做的 fracture（体破碎）模拟：它本质上也是刚体模拟，但我们专门处理了怎么模拟它破碎掉；还有弹性体的破碎效果——一个果冻被拉扯了之后，断成两段。关于衣服，这是我们今年 SIGGRAPH 的一篇 paper，讲怎么模拟高分辨率的衣服，是一个羽绒服的效果。还有我们前几年的一篇 SIGGRAPH Asia，做弹性体，展示了不同的弹性体模型，从左到右各有各的名字。另外还有一篇别人做的 SIGGRAPH paper，展示塑性形变（plastic deformation）：你可以认为是一堆橡皮车撞在一起，撞完之后发生永久形变，被撞成各种奇奇怪怪的形状。

这些例子基本上都是用 mesh 来做的，因为 mesh 在处理这种形态比较固定的物体上，有很大的好处。但要注意：这些都不是实时的——差不多要一秒以上才能算一帧，这几个例子没有一个是实时的。

#### 凡事都有例外

不是所有这些内容都是用 mesh 做的。也有人研究用别的方法，比如用 particle 或者 grid 去模拟。比如刚体的破裂，有人用 meshless（无网格）的方式、也就是用粒子的方式去模拟。用粒子最大的好处就是没有 mesh；没有 mesh，就意味着当这个物体碎裂的时候，你不需要去处理 mesh——因为它根本就没有 mesh，这是最大的一个好处。这是一篇 2005 年的 paper，到现在已经有十六年了，讲的就是在没有 mesh 的情况下，怎么用粒子模拟物体 fracture 的效果。

也有人用 grid 的方式，包括类似 MPM 这种 hybrid 的方式，去模拟衣服或者头发。为什么要这么做？主要原因是想减少碰撞的处理，把碰撞处理这一块给它简化一下。但总的来说，这方面的研究是比较实验性质的，不是一个通用的处理方式——在你用这些技术带来好处的同时，也会有很强的局限性，比如计算量可能会很大，比如处理细节的时候处理得不好。所以我们通常把它当成一种比较实验性的做法。（MPM，Material Point Method，是一个 hybrid 方法，等会儿就会讲到。）

### 流体：形态不同，方法不同

讲完刚体和弹性体，接下来讲流体。流体这个东西很神奇，为什么？因为流体的很多类型，展示的方式是很不一样的——从烟、水滴跟表面波，到水花，形式都不太一样。所以我们研究流体，用到的方式方法也不一样。

#### 烟

就烟而言，一般来说用粒子法跟网格法会比较多一点。看两个效果。一个是火焰：看起来像粒子，但我个人觉得应该是用 Blender 做的、用网格法（grid）来模拟的。另一个烟的效果更有意思：有人把一个人作为烟的 source，人走路的时候，烟就从人身上被吹下来，产生这些效果。

咱们这个课因为是用 Unity 做的，计算量会有一定的限制，做不了这么复杂的模拟。3D 会比较复杂，但是我们可以做 2D 的烟的模拟，这个是可以的。

#### 水滴与表面波

为什么要把水滴跟表面波单独拿出来讲？因为水滴跟水波有一个很大的特性：它们基本上还是一个整体，不会那么容易地分裂出来。所以大家就研究，可不可以用 mesh 来模拟波、模拟水滴？可以，而且有一个很大的好处——基本上可以拿来做实时的模拟。而 grid 可以拿来做比较真实、比较逼真的模拟。取决于你的需求是什么。

SIGGRAPH 2018 有一篇 paper，把小波（wavelet）引入到了水面模拟之中，可以实时地模拟水面波的效果：不只是有大的浪花，同时还有很细的波纹，都是可以实时模拟出来的。而且它跟物体有交互——这个波不是单纯的波，是能够跟物体交互的。

顺带回答一个常见疑问：流体我们主要就是解 Navier–Stokes 方程，所以对于波而言，正常的反射、折射、衍射都会有。

#### 水花

最后是水花。水花这个东西大的问题是什么？它非常多变、非常复杂，所以模拟起来相对就没那么容易做到实时。基于 mesh 做的水花可以做，但更多是实验性质的；大家采用的，主要还是基于 particle 和基于 grid 的方式来模拟。

看一个我个人觉得蛮好的效果：2012 年的一篇 SIGGRAPH paper，用 SPH 模拟出来的水花效果。我们这门课最后的时候，也会讨论这个技术——怎么用 SPH 的方式来模拟流体。

有同学问，这种水花效果 Unity 做得了吗？做不了。Unity 是一个实时引擎，局限性很强，光靠 Unity 是做不了的；想做类似这种效果，可能需要用到 OpenGL 或者类似的其他渲染引擎、图形学引擎。我们能做的，是 2D 烟的效果；后面我们会布置一个波的作业，类似刚才那种波浪的效果，但会比它稍微差一点。

### hybrid 方法与耦合

讲完四大类物质和三种方法，还有两类东西刚才没有讨论到。

第一类，是把这些方法结合在一起的 hybrid（混合）方法。比较典型的、大家可能听说过的，就是 MPM——particle 跟 grid 相结合的方法。为什么要做这个事情？主要原因是想让这个方法既有 particle 的优点，也有 grid 的优点。MPM 大家看到的最多的例子就是做雪，还有做各种粘滞的物体。粘滞的物体最大的特点，就是它既有一些 particle 的属性，也有一些 grid 的属性，所以用这种 hybrid 的方法是最常见、最通用的。反过来，比如说你要做刚体、做衣服、做弹性体，那么用 hybrid 的方法可能就不合适，用 mesh 的方法会是更好的选择。

给大家看过一个 MPM 比较早期的 paper——模拟血的效果。沙子也是可以用 MPM 这种方法来模拟的，比较合适。

第二类，是耦合（coupling），这是这个方向里研究得比较重要的一个问题：你的场景里面可能既有刚体，也有衣服，也有弹性体，也有流体，那么你怎么去模拟这几种不同的物质之间的交互？比如水落在衣服上，或者水落在弹性体上，或者衣服穿在人身上、而人又是一个弹性体，等等等等。这是大家研究得比较多的一个课题。

把四大对象、三种表达还有 hybrid 的对应关系归拢成一张表：

| 模拟对象 | 首选表达 | 理由与备注 |
| :--- | :--- | :--- |
| 刚体 | mesh | 形态固定；碎裂可用粒子（meshless），省掉 mesh 处理 |
| 衣服、头发 | mesh | 也有 grid／MPM 类 hybrid 的实验性做法，目的是简化碰撞 |
| 弹性体（软体） | mesh | 形变大，但仍是一个整体 |
| 流体（液体、气体） | particle、grid | 烟走粒子法＋网格法；水滴与波 mesh 可实时、grid 更逼真；水花复杂多变，以 particle／grid 为主 |
| 雪、粘滞物体 | hybrid（MPM） | 既有 particle 属性又有 grid 属性 |

### 这门课要学什么

看了这么多演示，最后说一下这门课会上到一些什么东西——幻灯片上框出来的，就是这学期要上的内容。

刚体这一块，主要上刚体动力学（rigid body dynamics）跟 contact（接触）。刚体的 fracture 我们就略过了，原因有两个：一是 fracture 有一大块是关于 remeshing（重新剖分网格）的，而 Unity 在处理 remeshing 的时候会比较复杂；二是游戏引擎里面的 fracture 通常是预计算的，不是模拟出来的——它通过一些预处理的方式来完成。你在游戏里见过 fracture 的效果吧？一面墙被打碎掉、一辆坦克给炸飞掉，这类效果在游戏里一般都是通过预计算来处理的。所以我们就不讲 fracture 了，因为 Unity 没办法支持实时的 fracture 模拟。

衣服跟头发：主要讲 cloth（衣服）。头发这一块暂时不讲——头发涉及的内容其实也挺多，包括头发的摩擦、自摩擦，还有一些发型模拟的效果，但我们暂时先略过。

软体这一块主要讲弹性体：会重点讲有限元（FEM），会讲超弹性模型（hyperelastic model），在这个基础上再扩展一些数值方法上的内容。碰撞处理跟碰撞检测也会讲，我们会专门拿出一天的时间来讲碰撞。塑性（plasticity）可以认为是弹性的一个延伸，但坦白地说，我自己以前也没有做过 plastic，可能我讲也不是很合适，所以我就偷个懒，这一块先不讲。

PBD 事实上可以把它归成一种类型，叫做 constraint-based approach，基于约束的方法。围绕这个东西，我们会讲 PBD，会讲 Projective Dynamics，还有一种技术叫 constrained dynamics，它是基于拉格朗日算子的——各种各样利用约束来做模拟的方式，我们都会涉及到。

流体的话，主要集中在 particle 跟 grid 这一块——哦，漏了一点，我们也会讲波。整个课大概三天时间：第一天讲 mesh，第二天讲 grid，第三天讲 particle，三天讲不同的内容。

有同学问：硬和软的边界在哪里？硬的东西，其实就是你认为它是没有形变的——做刚体模拟的时候，我们就假设刚体是无形变的；而任何有形变、可以观察到形变的，我们其实都可以把它认为是软体。关键就看它有没有形变。比如你做一个简单的游戏，轮子只是车辆的一个附件、只是做一个滚动，那你可以把它认为是刚体，它没有形变；但如果你要单独模拟一个轮胎——比如让它从天上掉下来，会产生一个弹性的效果——那你可能就需要把它做成一个弹性体。

形变其实是有三个阶段的：第一个阶段是弹性形变（elastic），第二个阶段是塑性形变（plastic），最后是破碎（fracture）。所以严格意义上讲，这三个阶段都是形变。

### 开场：这一讲要补哪些数学

今天主要讲跟物理模拟相关的一些数学问题。这些数学问题大致可以分成三类。第一类是基础知识，就是大家高中或者大学本科上数学课时已经比较了解的内容——我猜大家上数学课有的时候逃课，或者种种原因，有些东西忘掉了，这里帮大家把概念巩固一下。第二类是图形学里要用到、但有的同学可能不太了解的知识，如果在这方面欠缺的话，课后需要读一些参考资料稍微了解一下。第三类是大家在读书、读文献的过程中才会碰到的东西，这里只给一个 introduction，帮助大家有个初步的了解，后面的课程里还会把这些知识传递给大家。

今天的课分成三块：一个是矢量，另一个是矩阵，最后讲一些跟矢量、矩阵相关的微积分。这一篇先走完第一块——矢量。

### 矢量是什么

矢量（vector）这个概念，相信大家在中学里就已经学过了。最常见、日常用得最多的描述方式，是把矢量看成二维或者三维空间中的一个几何体：它有方向的含义，同时也有大小的含义。

具体一点：假如空间中有一个坐标系 $x, y, z$，我可以定义一个矢量，是从原点出发到某一个点 $P$ 的。这个矢量描述的，就是从原点到 $P$ 的这么一个相对关系。它在每一个坐标轴上的投影分别是 $p_x$、$p_y$、$p_z$，三个方向、三个值，就把这个矢量表示出来了。因为它在三维空间里，我们把它写作 $\mathbb{R}^3$：$\mathbb{R}$ 表示实数空间，上标 3 表示它是一个三维空间。

原点是一个比较特殊的矢量：它是 $(0,0,0)$，在三个方向上的投影都是零，相当于一个初始点。

### 手写的箭头与印刷的字体

一般在印象里、手写的时候，矢量上面都会放一个箭头，大家基本都是这么写的。但这种写法在印刷体、论文里一般来说不是很常见。为什么不常见？因为如果每个矢量都给它写个箭头，整个论文里就到处都是箭头，特别乱。

所以通常在论文里，我们用字体来区分矢量和标量：矢量一般用黑体（bold）表示，标量一般用斜体表示。看到一个字母，先看它的字体是什么——如果是斜体字，一般来说意思就是标量；如果是黑体字，一般来说就是矢量。另外，为了区分矢量和矩阵，我们还用大写跟小写来区分，这个等会儿后面会讲。总之，在论文里要特别注意这个字体：我们一般是用字体去区分的，而不是用那个小箭头去区分的。

本文也遵守这个约定：矢量一律写黑体（如 $\mathbf{p}$、$\mathbf{v}$），标量一律写斜体（如 $t$、$s$）。

### 右手系还是左手系

刚才那个坐标系有一个特点：它其实有两种类型。

如果大家记得右手定则是什么的话：把右手四个手指从 $x$ 转到 $y$，大拇指指向的方向就是 $z$ 的方向——这就叫右手系统（right-handed system）。在图形学里做研究，一般来说都是用右手坐标系来定义的；OpenGL 一般也是右手系统。

那么左手系统有没有呢？其实也很常见。比如 Unity 就是左手的，DirectX——微软的一个图形引擎——也是左手的。所以在图形学里面，左手跟右手的系统其实都有。大家有的时候要比较留意一下，不要默认地就觉得好像都是右手、或者都是左手，不同系统用的坐标系是不一样的。

| 坐标系 | 判定方法 | 常见于 |
| :--- | :--- | :--- |
| 右手系 | 右手四指从 $x$ 转向 $y$，拇指指向 $z$ | 图形学研究、OpenGL |
| 左手系 | 同样的规则改用左手判定 | Unity、DirectX |

设定坐标系的时候，可以参考屏幕空间。观察我们自己的屏幕：右手方向是 $x$ 方向，头顶方向是 $y$ 方向，那么 $z$ 方向就有两个选择了——朝着屏幕外、朝着我们的是右手系统；朝着屏幕里面的是左手系统。

左手系统其实有个好处。想象一下：我们空间中的物体、三维虚拟空间里的那些东西，是不是都在屏幕后面？都在屏幕后面的话，用左手系统就意味着这些物体的 $x, y, z$ 坐标都是正值——所有值都是正的，这是它的一个好处。如果用右手系统，物体就等于落在负的 $z$ 方向上。所以不是说不能那样定义，右手、左手都可以，这就是个约定，大家参考一下、留意一下就行。

### 没有几何含义的向量：stack vector

刚才说矢量是三维空间里描述方向的几何体，但在有的时候，我们其实并不需要这个矢量一定有什么几何的含义——它完全可以就是一堆数字组合起来的结果。

举个例子。假如我要描述一个物体，比如一道闪电：这道闪电由 11 个顶点构成，编号 0 到 10。我可以把这 11 个点的位置排成一列，$\mathbf{x}_0, \mathbf{x}_1, \dots, \mathbf{x}_{10}$——这整一个大向量，其实就可以描述这个物体的形状了。那么当我做动画的时候，如果说要修改某些点的位置，我就相应地更改这些点在这个大向量里的值，物体的状态就这么描述了。

这种情况下，这个向量是一个 33 维空间里的大向量（11 个点、每点 3 个坐标），就不再是三维空间里的一个向量了。它其实也并没有什么几何的含义——33 维空间是个什么几何含义？我不知道。但是我把这些点全都合在一起，确实可以描述这个物体的状态，可以拿来当一个矢量的表示用。这种情况下，我们把它叫做 stack vector：这些向量其实是叠（stack）在一起的，没有什么几何含义，但我拿来用它描述物体的状态。

> **定义**：把一堆向量按顺序叠成一个大向量、专门用来记录物体状态的表示，就是 stack vector。它不承载几何含义，承载的是状态。

课上有同学问：$\mathbf{x}_0$、$\mathbf{x}_1$ 是不是也是向量？——是。每一个 $\mathbf{x}_i$ 都是一个三维向量，把这 11 个三维向量合在一起，就是一个 33 维的向量。

### 向量的加减法

有了向量的定义，接下来可以进一步定义一些数学运算。先看加减法，中学里都学过：矢量的加减法，其实就是对每一个元素做加减法：

$$\mathbf{p} \pm \mathbf{q} = (p_x \pm q_x,\ p_y \pm q_y,\ p_z \pm q_z)$$

$\mathbf{p} + \mathbf{q} = \mathbf{q} + \mathbf{p}$ 这个大家也知道，把两个向量交换一下位置，结果肯定是一样的。

那几何上是个什么含义呢？有一个 $\mathbf{p}$ 向量、一个 $\mathbf{q}$ 向量，$\mathbf{p} + \mathbf{q}$ 就等于：我先从原点出发，沿着 $\mathbf{p}$ 的方向往前走，走完之后，再沿着 $\mathbf{q}$ 的方向往前走，两个叠加在一起，就得到了 $\mathbf{p} + \mathbf{q}$。同样地，如果先沿着 $\mathbf{q}$ 走、再沿着 $\mathbf{p}$ 走，最终也可以达到同样的结果。

减法类似：$\mathbf{p} - \mathbf{q}$ 就是 $\mathbf{p}$ 跟 $\mathbf{q}$ 之间的这么一个相对位置，得到的是一个相对的位移关系。

### 从粒子运动到线段、射线与直线

有了加减法这些定义之后，可以拿矢量来做什么？我们一般来说，可以用这些 3D 矢量来描述点、速度、力，还有一些线——所有跟线有关的表达，都可以用矢量来描述。

举个简单的例子。我现在有一个点 $\mathbf{p}$，把它看成一个小粒子；这个粒子沿着 $\mathbf{v}$ 的方向往前运动，$\mathbf{v}$ 可以认为是它的速度。怎么去描述这个粒子的运动呢？我可以把运动的轨迹写成一个公式：

$$\mathbf{p}(t) = \mathbf{p} + t\,\mathbf{v}$$

也就是位置等于原始位置加上速度乘以时间。这个公式把位置写成了关于时间的函数：$t > 0$ 的时候，意味着粒子在往前运动；$t < 0$ 的时刻，就表示倒推回去，在之前的时刻这个粒子是什么样的位置。整个公式，实际上就是在描述一个粒子沿着这个速度往前运动。

因为这个东西本质上就是一条线，所以我们可以利用同样的公式来定义一条线。假如这里有两个点，一个是 $\mathbf{p}$ 点，一个是 $\mathbf{q}$ 点，那么方向是什么？就是 $\mathbf{q} - \mathbf{p}$。粒子的运动轨迹就变成了：

$$\mathbf{p}(t) = \mathbf{p} + t\,(\mathbf{q} - \mathbf{p})$$

原来是描述粒子运动的公式，我现在把它拿来描述一条线了。天然地，它就有三个部分构成：

```text
        t<0             0<=t<=1              t>1
    --------+===============+---------------------->
            P               Q
```

$t < 0$ 是 $P$ 前面的那一段；$t$ 在 0 跟 1 之间，得到的是 $P$ 跟 $Q$ 之间的这一段；$t > 1$ 的时候，得到的是 $Q$ 以外的那一段。

所以同样一个公式，根据 $t$ 的不同取值范围，可以拿来定义不同的几何体：想要定义一个**线段**，就用这个公式再加一个条件，要求 $t$ 在 0 跟 1 之间；想要得到一个**射线**，就要求 $t \ge 0$，得到的就是从 $P$ 出发的一条射线；想要得到**一整条完整的线**，那对 $t$ 就不做任何约束，直接用这个公式、$t$ 可以取任意的实数。

还有一种比较常见的写法，是把公式稍微做一下变化：

$$\mathbf{p}(t) = (1-t)\,\mathbf{p} + t\,\mathbf{q}$$

这样一看就会发现，它本质上就是对 $\mathbf{p}$ 跟 $\mathbf{q}$ 做了一个混合：混合的量是多少呢？是通过 $1-t$ 跟 $t$ 来决定的——$1-t$ 就是 $\mathbf{p}$ 的权重，$t$ 就是 $\mathbf{q}$ 的权重。也就是说，根据 $t$ 计算出一组权重值，利用这组权重对两个点做一个线性的混合，可以得到中间的结果。这个东西就叫做插值（interpolation），$1-t$ 和 $t$ 就是插值的权重。概念很简单：给两个点，给一个权重，利用线性混合的方式得到中间的一个结果。

### 矢量的大小：范数

加法、减法讲完了，接下来讲一个也是比较重要的概念：矢量的大小，数学里面叫做范数（norm）。它的意思就是说，给一个矢量，怎么去计算这个矢量的大小。

最常见、见得比较多的，是 euclidean norm，也就是所谓的 2-norm：

$$\|\mathbf{p}\|_2 = \sqrt{p_x^2 + p_y^2 + p_z^2}$$

为什么叫 2-norm？大家留意一下——因为这里都是二嘛：平方、平方、平方，然后最后开根号，所以叫 2-norm。

相对应地，可以任意取一个阶数 $p$：各分量做 $p$ 次方、求和，最后开 $p$ 次根号，这个就叫 p-norm。根据 $p$ 的不同取值，有各种 norm 的写法。比如 1-norm 就是各分量绝对值的和，它在数学里其实还有另外一个名字，叫曼哈顿距离（Manhattan distance）。做某些游戏开发的时候可能会用到它——利用坐标系之间的差求和来算距离，而不是直接算欧氏距离。还有一种叫 infinity norm（∞-范数）：假如 $p$ 趋向于无穷大，会发生什么？这时候算出来的值，实际上就是各分量的最大值。这也是一种比较常见的 norm。

| 名称 | 定义 | 备注 |
| :--- | :--- | :--- |
| 2-范数（欧氏范数） | $\sqrt{p_x^2+p_y^2+p_z^2}$ | 最常见；很多时候大家不写下标 2，默认就是 2-范数 |
| p-范数 | $\bigl(|p_x|^p+|p_y|^p+|p_z|^p\bigr)^{1/p}$ | 阶数 $p$ 任取，按取值不同得到各种范数 |
| 1-范数 | $\lvert p_x\rvert+\lvert p_y\rvert+\lvert p_z\rvert$ | 又名曼哈顿距离 |
| ∞-范数 | $p\to\infty$ 时的极限 | 等于各分量的最大值 |

当然最常见的还是 2-norm，很多时候大家直接把这个下标 2 去掉，默认就是它。

norm 有什么用呢？比如可以拿来计算两个点之间的距离：两点的相对位置可以用矢量 $\mathbf{q} - \mathbf{p}$ 来描述，那么这个矢量的 norm，也就是两点之间的距离。

如果一个向量的 norm 为 1，我们就把它叫做单位向量（unit vector）。如果一个向量想把它变成单位向量，怎么做呢？把它除以它的 norm 就可以了。为什么？因为除完之后，它的 norm 就等于 norm 除以 norm，自然也就得到 1 了：

$$\left\|\frac{\mathbf{p}}{\|\mathbf{p}\|}\right\| = \frac{\|\mathbf{p}\|}{\|\mathbf{p}\|} = 1$$

这就是一个很简单的操作，叫做 normalization——把向量变成单位向量的方式。

### 点乘：定义、写法与几何含义

加法、减法、范数都讲了，接下来我们讲乘法。先讲一种乘法，叫做点乘（dot product），或者叫内积——数学里面一般叫内积，但我们做几何运算的时候，有的时候大家就喜欢叫点乘。

点乘是什么意思呢？给两个向量 $\mathbf{p}$ 和 $\mathbf{q}$，分别对它们的 $x$、$y$、$z$ 做乘法，做完乘法以后把它们加起来，得到的是一个标量：

$$\mathbf{p} \cdot \mathbf{q} = p_x q_x + p_y q_y + p_z q_z$$

读 paper 的时候会发现，它一般不用这个点的方式写，而是用尖括号的形式：$\langle \mathbf{p}, \mathbf{q} \rangle$——其实是一个意思，就是做内积、做点乘。

还有一种写法也比较常见：$\mathbf{p}^T \mathbf{q}$（p transpose q）。什么意思呢？把 $\mathbf{p}$ 当作是一个矩阵，转置（transpose）实际上就是把 $\mathbf{p}$ 从一个竖着的向量变成了一个横着的向量，然后再做乘法。做矩阵乘法的结果，跟做点乘是一模一样的。虽然我们现在还没讲到矩阵，但这种写法其实就是想利用矩阵乘法的形式来写点乘。它的好处在于什么？在于我们可以把所有的东西都写成矩阵跟向量的乘法，而不需要额外去定义点乘或者是其他乘法。以后大家读 paper、或者我们后续的课程里，看到两个向量中间夹一个 transpose，实际上就是在做点乘。

那几何上它是什么意思呢？假如我有两个向量，分别知道它们的大小（长度），写作 $\|\mathbf{p}\|$ 跟 $\|\mathbf{q}\|$；同时还有一个夹角 $\theta$，是 $\mathbf{p}$ 跟 $\mathbf{q}$ 之间的夹角。那么点乘就等于：

$$\mathbf{p} \cdot \mathbf{q} = \|\mathbf{p}\|\,\|\mathbf{q}\|\cos\theta$$

这就是点乘在几何上的含义：两个向量的长度相乘，再乘上它们夹角的余弦。

根据定义，点乘有一些特征。$\mathbf{p}\cdot\mathbf{q} = \mathbf{q}\cdot\mathbf{p}$，这个从定义上蛮容易理解：标量乘法 $a \times b = b \times a$ 嘛，把 $\mathbf{p}$、$\mathbf{q}$ 交换一下位置，结果肯定是一样的。它也满足分配律：$\mathbf{p}\cdot(\mathbf{q}+\mathbf{r}) = \mathbf{p}\cdot\mathbf{q} + \mathbf{p}\cdot\mathbf{r}$，跟正常的乘法分配率一样，从定义出发就可以得到，没有什么特别奇怪的。

还有一条是比较有意思的——怎么去写 norm：

> **结论**：向量对它自己做点乘，等于它 2-范数的平方：$\mathbf{p}\cdot\mathbf{p} = \|\mathbf{p}\|_2^2$。

为什么？$\mathbf{p}\cdot\mathbf{p}$ 展开就是 $p_x^2 + p_y^2 + p_z^2$，正是 2-norm 的平方。所以很多时候，大家想做一些关于矢量的积分、微分计算的时候，一般都是利用这个式子去写，而不用 norm 的定义去写——利用点乘、利用矩阵乘法的这种写法，就可以做微积分的计算了。回头我会给大家看一个例子。

最后一点是关于 $\theta$ 的。假如 $\mathbf{p}$ 跟 $\mathbf{q}$ 的点乘是零，也就意味着 $\cos\theta = 0$——因为假设 $\mathbf{p}$ 跟 $\mathbf{q}$ 都不是零向量，两个都不是零向量的话，点乘等于零的唯一原因就是 $\cos\theta = 0$。那 $\cos\theta$ 什么时候等于零？肯定是 $\theta = 90°$ 或者 $270°$ 的时候。两个向量的夹角是 90 度，意味着什么？它们必须是垂直的。

> **结论**：两个非零向量点乘为零，当且仅当它们互相垂直（正交）。要判定两个方向是不是垂直，做一次点乘、看看结果是不是等于零就行了。

### 点乘能做什么：投影、平面与碰撞

接下来，我们可以利用点乘来搞些事情了。

#### 点到直线的投影

假如有这么个场景：一个点 $\mathbf{q}$，还有一条线——这条线通过一个点 $\mathbf{o}$（不一定是原点，可以是任意的点）和一个方向 $\mathbf{v}$。用这两个元素、按照刚才的线性公式，就可以描述这条线。现在想知道两件事：$\mathbf{q}$ 在这条线上的投影是哪个点；同时，投影点到原来这个点的距离是多少。

注意一下记号：投影点用黑体大写的 $\mathbf{s}$（矢量，是个位置），投影距离用斜体小写的 $s$（标量，表示大小）。刚才讲的"用字体区分含义"，在这里就派上用场了——两个 $s$ 长得一样，但字体不同，含义不同。

```text
            Q
            +
            |
            |
     O -----+------------------------>  v
            S
```

读图：从 $Q$ 往直线作垂线，垂足 $S$ 就是投影点，$O$ 到 $S$ 的长度就是标量 $s$。

先来计算这个标量 $s$。如果 $\mathbf{q}$ 的投影是 $\mathbf{s}$，那么 $\mathbf{q}$ 到 $\mathbf{s}$ 的这条连线，跟原来这条直线肯定是垂直的。所以 $s$ 就是矢量 $\mathbf{q}-\mathbf{o}$ 在这条线方向上的投影：已知 $\|\mathbf{q}-\mathbf{o}\|$（斜边），再乘以 $\cos\theta$——$\theta$ 是这两条方向的夹角——就得到 $s$ 了。这就是它的定义嘛：斜边乘以 $\cos$ 等于底边：

$$s = \|\mathbf{q}-\mathbf{o}\|\cos\theta$$

接下来做个小变形：把这个式子上下同乘以 $\|\mathbf{v}\|$——分子分母同乘一个数，是不影响结果的：

$$s = \frac{\|\mathbf{q}-\mathbf{o}\|\,\|\mathbf{v}\|\cos\theta}{\|\mathbf{v}\|}$$

那分子是什么？两个矢量的大小的乘积，再乘以这两个矢量夹角的余弦——完美的、典型的点乘定义。所以我们得到：

$$s = \frac{(\mathbf{q}-\mathbf{o})\cdot\mathbf{v}}{\|\mathbf{v}\|}$$

而 $\mathbf{v} / \|\mathbf{v}\|$ 是什么？正是 normalization——把 $\mathbf{v}$ 变成单位向量。所以 $s$ 同样等于 $\mathbf{q}-\mathbf{o}$ 点乘 normalize 过以后的 $\mathbf{v}$：

$$s = (\mathbf{q}-\mathbf{o})\cdot\hat{\mathbf{v}}, \qquad \hat{\mathbf{v}} = \frac{\mathbf{v}}{\|\mathbf{v}\|}$$

换句话说：把 $\mathbf{v}$ 先 normalize 一下，然后跟 $\mathbf{q}-\mathbf{o}$ 做一次点乘，就得到投影距离 $s$ 了。

有了投影距离，大的 $\mathbf{s}$ 就好求了。从 $\mathbf{o}$ 出发，按照线的定义，沿着方向往前走，走多少？走 $s$：

$$\mathbf{s} = \mathbf{o} + s\,\hat{\mathbf{v}}$$

距离乘以方向，就等于投影点的位置。这就是利用点乘来计算一个点到一条线的投影的方式。

#### 用法向量定义平面与有向距离

接着用点乘来定义一个平面。假如有一个平面，平面中有个点，叫做 $\mathbf{c}$ 点；然后给平面一个方向——垂直于平面的方向，记作 $\mathbf{n}$，同时 $\mathbf{n}$ 是一个单位向量。这种向量就叫做 normal，就是这个平面的法向量。平面上一个点，加上一个法向量，利用这两个向量就可以定义一个平面。

怎么定义呢？搞一个公式：随便给你一个点 $\mathbf{p}$，用

$$(\mathbf{p}-\mathbf{c})\cdot\mathbf{n}$$

来判定这个 $\mathbf{p}$ 点跟这个平面处在一个什么样的关系上——它是在平面的上面、刚好位于平面、还是在平面的下面，一共三种不同的位置。

怎么得到这三种位置呢？很简单。$\mathbf{p}-\mathbf{c}$ 是从 $c$ 点出发到 $p$ 点的向量，把它跟法向量做一个点乘，就得到一个距离——就是刚才讲的那个投影距离。注意这个投影距离不是永远为正的，它可正可负，而它的符号就告诉了我们 $\mathbf{p}$ 点跟平面的关系：

- $(\mathbf{p}-\mathbf{c})\cdot\mathbf{n} > 0$：$\mathbf{p}-\mathbf{c}$ 跟 $\mathbf{n}$ 在同一个半平面上、同一个方向上，$\mathbf{p}$ 在平面上面；
- $(\mathbf{p}-\mathbf{c})\cdot\mathbf{n} = 0$：$\mathbf{p}-\mathbf{c}$ 跟法向量是垂直的关系，$\mathbf{p}$ 刚好位于平面上；
- $(\mathbf{p}-\mathbf{c})\cdot\mathbf{n} < 0$：$\mathbf{p}-\mathbf{c}$ 跟 $\mathbf{n}$ 不在同一个半平面上，$\mathbf{p}$ 在平面下面。

根据这个点乘的符号大于零、等于零还是小于零，就可以做一个位置上的判定。

还有一点比较重要：这个值本质上就是 $\mathbf{p}$ 到这个平面的距离——它在法向上的投影，就是到平面的距离。但这个距离跟我们平常所说的距离不一样：平常的距离不可能是负的值，这里它是可正可负的。它的绝对值表示的是传统意义上的距离，而它的符号表示了到这个曲面的一个位置关系。所以这个东西叫做 signed distance，有符号的距离。

以后我们可以利用这个符号做碰撞检测。为什么？假如我跟一个物体发生碰撞，我这个东西跑到物体里面去了，符号就会变负，所以可以利用它来做检测。讲碰撞处理的时候会展开讲。这里大家可以先留意一下：它是个距离，但不只是一个单纯的距离——它还有符号，而符号可以拿来做位置的判定。

#### 点与球的碰撞：把范数写成点乘

再给大家举一个利用点乘的例子：做一个点跟球的碰撞。假如有一个点 $\mathbf{p}$，它朝着某个方向运动，$\mathbf{v}$ 就是它的速度、运动方向；它的轨迹前面讲过，就是那个线性公式 $\mathbf{p}(t) = \mathbf{p} + t\,\mathbf{v}$。球呢，简单起见假设它不运动，球的圆心是 $\mathbf{c}$，半径是 $r$。那么我想知道：有没有发生碰撞？什么时候发生碰撞？该怎么做？

可以利用一个公式。我假设会发生碰撞——假如碰撞会发生，会有一个什么样的现象呢？就是 $\mathbf{p}(t)$，这个点在 $t$ 时刻的位置，到 $\mathbf{c}$ 的距离等于半径：

$$\|\mathbf{p}(t) - \mathbf{c}\| = r$$

然后两边都搞个平方，它们也是相等的。所以假如碰撞发生了，下面这个必然成立：

$$\|\mathbf{p}(t) - \mathbf{c}\|^2 = r^2$$

那么 2-norm 的平方是什么？就是点乘。这正是前面那条"自己点自己等于范数平方"的用武之地：把 $\|\mathbf{p}(t)-\mathbf{c}\|^2$ 写成 $(\mathbf{p}(t)-\mathbf{c})\cdot(\mathbf{p}(t)-\mathbf{c})$，再代入 $\mathbf{p}(t) = \mathbf{p} + t\,\mathbf{v}$，等式就变成了一个关于 $t$ 的普通代数方程——解出 $t$，就回答了"什么时候发生碰撞"。

课上留了一个小小的课后作业，大家可以回头想一想：

> 假如我不是一个面，而是一个盒子——一个盒子由六个面构成——那你怎么判断一个点是不是在这个盒子的里面？

**解析**：工具就是正文里的 signed distance。盒子的每一个面都可以用"面上一点 $\mathbf{c}_i$ + 法向量 $\mathbf{n}_i$"来描述，对给定的点 $\mathbf{p}$，把六个面各算一遍：

$$(\mathbf{p}-\mathbf{c}_i)\cdot\mathbf{n}_i, \qquad i = 1, 2, \dots, 6$$

每个值都是一个有符号距离，符号表明 $\mathbf{p}$ 在这个面的哪一侧。把六个法向量统一约定成朝内（或统一朝外），那么：点在盒子里面，当且仅当六个符号全部一致——即点在每一个面的同一侧；只要有任何一个面的符号表明点在这一面的外侧，就可以立即判定它在盒子外面。点恰好落在某个面上时，对应那个面的值正好为零。

## 向量乘法实战：从光线求交到重心坐标
> 对应块：BLK04 | 覆盖分集：P02中1 | 块标题（分集名）：《Lecture 02 Math Backgrou》

先摆一个问题：一个点从 $p$ 出发、沿速度 $v$ 往前走，前方悬着一个球心在 $c$、半径为 $r$ 的球——它撞不撞？什么时候撞？这是物理动画里最基础的一类判断，而解开它的钥匙就是向量乘法。这一篇我们把点乘和叉乘彻底用起来：先用点乘把撞球的时刻解出来；然后引入叉乘，用它算三角形的法向与面积、判断点在不在三角形里、构造重心坐标插值；再升级到四面体的体积与重心坐标；最后回头做一个"点撞三角形"的完整碰撞例子。

### 用点乘解出碰撞时刻

动点在时刻 $t$ 的位置是 $p + tv$。撞上球，等价于它与球心的距离等于半径。把"距离等于 $r$"平方、用点乘把长度平方写开，整个碰撞条件就变成：

$$\left(p - c + t\,v\right)\cdot\left(p - c + t\,v\right) = r^2$$

接下来用点乘的分配率把它彻底展开。展开的套路跟 $(a+b)^2 = a^2 + 2ab + b^2$ 一模一样——平方展开、交叉项带个 2：

$$(v\cdot v)\,t^2 \;+\; 2\,t\,(p-c)\cdot v \;+\; (p-c)\cdot(p-c) \;-\; r^2 \;=\; 0$$

这个式子告诉我们一件关键的事：$t$ 是一个一元二次方程的根。整个方程里唯一的未知量就是 $t$——$v$、$c$、$r$、$p$ 全是已知的，把那些点乘老老实实算出来，就得到一个标准的一元二次方程。

一元二次方程的根有三种可能，每种对应一种碰撞状态：

| 根的情况 | 几何含义 |
| :--- | :--- |
| 无实根 | 动点与球没有碰撞 |
| 恰好一个根 | 动点刚好擦着球面掠过（相切），发生一次碰撞 |
| 两个根 | 最常见：动点先穿入球面，继续往前走又穿出球面 |

为什么会有两个根？因为点继续往前走走走，会再次跟球面碰上——进去一次、出来一次，正好两个交点。

解出根之后还要挑：检查哪个根**大于零、同时也是最小**的，它就是我们要的解。为什么要求大于零？因为碰撞必须发生在前进方向上——是往前撞上的，不是背后已经过去的事。为什么要最小？因为我们要找的是**第一个**发生碰撞的时刻——要的是近处这个点，不是远处那个点。

> **结论**：动点与球的求交归结为解一个关于 $t$ 的一元二次方程；在实根中取"大于零且最小"的那个，就是第一次碰撞的时刻。

### 叉乘：另一种向量乘法

讲完点乘，再来讲矢量跟矢量的另一种乘法：cross product，叉乘。

它的代数定义相信大家以前上数学课都学过，我就不重复了；这里更要紧的是**几何定义**。

> **定义**：对夹角为 $\theta$ 的向量 $p$、$q$，叉乘 $r = p\times q$ 是一个**向量**——注意，点乘乘出来的是一个标量，叉乘乘出来的是一个新的向量，这是两者的根本区别。它满足两条性质：
>
> 1. $r$ 与 $p$、$q$ 都垂直，即 $r\cdot p = 0$、$r\cdot q = 0$——点乘等于零就意味着垂直；
> 2. $r$ 的大小为 $\|r\| = \|p\|\,\|q\|\sin\theta$。

可以看到它跟点乘稍微有点像，但又不一样——点乘带 $\cos\theta$，叉乘带 $\sin\theta$，小小的区别：

| | 点乘 | 叉乘 |
| :--- | :--- | :--- |
| 结果 | 标量 | 新的向量 |
| 夹角进入公式的方式 | $\cos\theta$ | $\sin\theta$ |

第二个有意思的点：**叉乘跟顺序有关**。把 $p$、$q$ 的顺序倒一倒，得到的是相反的值。为什么？从定义出发看每一行就明白了——比如其中一行是 $p_y q_z - p_z q_y$，把 $p$、$q$ 交换后每一行都变号。所以：

$$p \times q = -\,(q \times p)$$

> **易错点**：叉乘不满足交换律，交换顺序结果反号。书写时前后顺序不能随手调换。

另外，叉乘同样满足分配率，这一点跟正常的乘法是一样的。

那么，叉乘等于零意味着什么？注意，这里说的"零"是**黑体的零** $\mathbf{0}$——它是零向量，不是数字 0；叉乘的结果是向量，等式两边都得是向量。两个**非零**向量的叉乘等于零向量，唯一可能是 $\sin\theta = 0$，也就是 $\theta = 0°$ 或 $180°$——$p$、$q$ 平行，同方向或反方向都算。

> **提示**：叉乘可以当平行判定器用：两个非零向量的叉乘等于零向量 $\iff$ 两向量平行。记住这一条，后面到处能用上。

### 一石二鸟：三角形的法向与面积

有了叉乘，举第一个例子：计算一个三角形的**法向量**和**面积**。

三维空间里有一个三角形，三个顶点 $x_0$、$x_1$、$x_2$。特地从 $x_0$ 出发选两条边：$x_{10} = x_1 - x_0$ 和 $x_{20} = x_2 - x_0$，就用这两个向量来表示这两条边。

先算法向。想要一个方向，它跟两条边向量都垂直——这正是叉乘的拿手好戏：$x_{10}\times x_{20}$ 算出来的东西就跟这两个向量都垂直。但这还不够，因为正常情况下我们想要的法向必须是一个**单位向量**，所以叉乘完还要 normalize 一下、除以它自己的大小：

$$n \;=\; \frac{x_{10}\times x_{20}}{\left\|x_{10}\times x_{20}\right\|}$$

这就是计算三角形法向量的完整套路：先叉乘，再做 normalization。

再算面积。三角形面积等于底乘高除以二——学过初中几何都知道。底就是 $\|x_{10}\|$，底边向量的长度。高呢？可以用另一条边找出来：$x_{20}$ 这条边相当于直角三角形的斜边，斜边长度乘以夹角的 $\sin\theta$，正好就是三角形的高：

$$A \;=\; \frac{1}{2}\,\|x_{10}\|\,\|x_{20}\|\sin\theta$$

然后就会发现一个很有意思的现象：这个东西跟叉乘的大小**是同一个东西**——两个矢量的叉乘大小，就等于它们的大小乘积乘以 $\sin\theta$。所以：

$$A \;=\; \frac{1}{2}\,\left\|x_{10}\times x_{20}\right\|$$

一次叉乘，一石二鸟：它的**方向**给出法向量（normalize 之后），它的**大小**除以二给出面积。三角形的面积和法向量同时到手。

还有一个要点：结果跟**顶点顺序**有关。按 $x_0 \to x_1 \to x_2$ 的顺序用右手法则，法向朝一边；如果把顶点的标号换一换（比如把 $x_1$、$x_2$ 的角色对调），再用右手法则比划，法向就翻到另一边去了。

> **易错点**：用顶点定义三角形时，不光需要顶点的位置信息，顶点的**顺序**同样重要——顺序一换，法向就反向。这个顺序通常叫做三角形的**拓扑顺序**（拓扑关系），使用三角形时要时刻留意。

顺手留一个小小的课后思考题：给三个点，怎么判断它们在不在同一条线上？用刚才讨论过的东西想一想——文末揭晓。

### 判断点在不在三角形里

继续讨论三角形，这次搞稍微深入一点：给定一个三角形，怎么判断一个点是在三角形里面还是外面。

做判定之前，先只看一条边，比如底边 $x_{01}$（从 $x_0$ 指向 $x_1$ 的边）。这条边把空间分成两个部分：内侧和外侧。

假设点 $p$ 在这条边的**内侧**。那么 $p$ 和 $x_0$、$x_1$ 构成一个小三角形，由 $x_0 - p$、$x_1 - p$ 这几条边向量撑起来。用叉乘算这个小三角形的法向：$(x_0-p)\times(x_1-p)$。用右手定则比划一下——从 $p$ 出发，到 $x_0$，再到 $x_1$——大拇指指的方向，跟大三角形自己的法向是**同方向**的。

再假设 $p$ 跑到这条边的**外侧**去了。还是同样的公式、同样的右手定则（$p \to x_0 \to x_1$），这次大拇指指的就是另一边——子三角形的法向跟大三角形的法向**相反**。

这个事情就好办了。既然有这个特性，那就把三条边各查一遍：$p$ 把大三角形分成三个小三角形（底下一个、左边一个、右边一个），逐个算子三角形的法向：

$$(x_0-p)\times(x_1-p), \qquad (x_1-p)\times(x_2-p), \qquad (x_2-p)\times(x_0-p)$$

把这三个法向分别与大三角形的法向 $n$ 做点乘，看是不是都同方向。三个都同向，说明 $p$ 在三条边的内侧，也就是在三角形里面；只要有一个反向，$p$ 就在三角形外面。这是一个非常方便的内外检测方法。

> **结论**：$p$ 在三角形内 $\iff$ 三个子三角形法向 $(x_0-p)\times(x_1-p)$、$(x_1-p)\times(x_2-p)$、$(x_2-p)\times(x_0-p)$ 与 $n$ 的点乘全部同号。

两个自然的疑问，值得一问一答：

- 这个判定取决于 $n$ 朝哪边吗？**不取决于**。如果把 $x_0,x_1,x_2$ 的顺序整体反转，$n$ 跟着反向，三个子三角形法向也跟着反向，点乘照样全部同号。只要遵循**同样的顶点顺序**，公式就是成立的。
- 四个点要在同一个平面上吗？**要**。整套推导假设 $p$ 与三角形共面，这是一个很重要的前提假设。

### 点乘值背后的带符号面积

刚才只用了点乘结果的**正负号**；光有正负号还不够，我们还想看看这个值本身到底有什么含义。

把它除以二看看。子三角形的法向本质上是叉乘的结果，$n$ 又是一个单位向量，那么两者只有两种关系：同方向时，点乘出来的就是叉乘的大小；反方向时，点乘出来的就是叉乘大小前面添个负号。

而"叉乘大小除以二"恰好是面积——前面刚证的。所以除以二之后，得到的就是三个小三角形的**面积**，记作 $a_0$、$a_1$、$a_2$：每个 $a_i$ 对应"不含顶点 $x_i$ 的那个小三角形"——$a_2$ 由 $x_0,x_1$ 与 $p$ 算出，$a_1$ 由 $x_0,x_2$ 与 $p$ 算出，$a_0$ 由 $x_1,x_2$ 与 $p$ 算出：

$$a_0=\frac{1}{2}\,n\cdot\big((x_1-p)\times(x_2-p)\big),\qquad
a_1=\frac{1}{2}\,n\cdot\big((x_2-p)\times(x_0-p)\big),\qquad
a_2=\frac{1}{2}\,n\cdot\big((x_0-p)\times(x_1-p)\big)$$

注意，这个面积**不是**我们通常意义上的面积——通常说面积都是正的，而它实际上带符号：$p$ 在内部时三个都是正面积；$p$ 跑到外面去，由 $p$ 和顶点构成的某些小三角形就翻出**负面积**。这种可正可负的面积，叫做 **signed area**（带符号面积）。

> **结论**：不管 $p$ 在哪儿，$a_0+a_1+a_2=A$（大三角形的面积）恒成立。$p$ 在内部时三者全正；$p$ 在外部时有的变负、有的甚至比 $A$ 还大，但总和始终等于 $A$。

### 重心坐标与三角形插值

把三个带符号面积分别除以总面积 $A$，得到三个权重：

$$b_0=\frac{a_0}{A},\qquad b_1=\frac{a_1}{A},\qquad b_2=\frac{a_2}{A}$$

因为 $a_0+a_1+a_2=A$，所以 $b_0+b_1+b_2=1$。这组数就是 **barycentric 权重**（重心坐标）。

> **定义**：$b_i = a_i / A$ 称为点 $p$ 在三角形上的重心坐标（barycentric weights），满足 $b_0+b_1+b_2=1$；三个权重分别"挂"在顶点 $x_0,x_1,x_2$ 上。

这个权重有什么作用？就像我们前面对线段做插值一样，现在可以对三角形也做插值——把权重搁到三个顶点的位置上，就能得到 $p$ 点的位置：

$$p \;=\; b_0\,x_0 + b_1\,x_1 + b_2\,x_2$$

这就是所谓的 **barycentric interpolation**（重心插值），在图形学里用得非常常见。比如做渲染的时候：一个三角形，三个顶点各自算出颜色，想要三角形内部像素 $p$ 的颜色怎么办？分别计算三个顶点上的颜色，然后对这三个颜色做一次重心插值，中间点的颜色就出来了。这个套路叫做 **Gouraud shading**——分别计算顶点的颜色，再利用三角形顶点的颜色来决定三角形内部像素的颜色。

为什么早年要做这个事情？因为二三十年前计算机硬件的能力很弱，不像我们现在有 GPU、什么 GTX，各种非常强大——那时候的显卡没办法对每一个像素做颜色计算，只能算三角形顶点的颜色，然后靠插值把内部铺满，因为插值的计算量比颜色计算小得多。这是传统图形引擎、图形硬件里很常见的套路。现在这种着色方式已经很少见到了：显卡的算力已经很强，完全可以对每个像素算颜色，甚至光线追踪都可以做。

不过即使在当时，实践中大家通常也**不直接**对每个像素去算 barycentric weight——逐像素算起来比较麻烦，计算量也稍大。通常的做法是**扫描线算法**（scanline conversion）：把同一行上的像素放在一起算——把这一行两端的像素先算出来，中间的像素在这两点之间做线性插值，也就是用几个线性插值拼出三角形内部的插值。上图形学课时如果教科书比较老，尤其老版教科书，可能会讲到它，这里就不展开了。要传达的意思就一句：给你一个三角形，利用 barycentric weight 可以拿来做各种各样的插值。

还有一个值得问一问的点：这套权重成立，需要 $p$ 在三角形内部吗？**不需要**。$p$ 在三角形外部时它同样成立，只是那时有的权重会是负的；$p$ 在内部时三个权重才都是大于零的值。这恰好跟前面的内外判定对上了——"权重全正"和"点乘全同号"是同一件事的两种说法，用正负号就能判断点在不在三角形里。

### 四面体的体积公式

现在搞得更高级一点：四面体。它由四个顶点 $x_0,x_1,x_2,x_3$ 构成，有四个面；跟三角形相比多了一个点，边也就变成了三条：$x_{10}$、$x_{20}$、$x_{30}$，都从 $x_0$ 出发。

前面说半天三角形的面积，现在就来讨论四面体的体积。公式是：体积等于底面积乘以高除以三。

底面积是现成的：底面 $x_0x_1x_2$ 本身就是个三角形，面积 $= \|x_{10}\times x_{20}\|/2$，前面刚讲过。高呢？是 $x_3$ 到底面的距离，也就是 $x_{30}$ 在底面法向上的投影；底面的法向就是用 $x_{10}\times x_{20}$ 算出来的那个方向，所以拿 $x_{30}$ 跟这个单位法向做个点乘，高就得到了。

把底面积和高乘起来，有意思的事情发生了：底面积里带着的 $\|x_{10}\times x_{20}\|$ 在分子上，高里的那一个在分母上，俩正好**抵消掉了**；剩下的 $\frac{1}{2}$ 乘上前面的 $\frac{1}{3}$，得到 $\frac{1}{6}$：

$$V \;=\; \frac{1}{6}\; x_{30}\cdot\big(x_{10}\times x_{20}\big) \;=\; \frac{1}{6}\,(x_3-x_0)\cdot\big((x_1-x_0)\times(x_2-x_0)\big)$$

这就是计算四面体体积的公式。

有的时候你还会看到另一种写法：把四个顶点当成四个向量，写成一个 $4\times4$ 的行列式——第一列是 $x_1$，第二列是 $x_2$，第三列是 $x_3$，最后是 $x_0$，每列最下面添一个 $1$。为什么是 $4\times4$？因为有四个向量，每个都是三维的，底下加个 $1$，高度就成了四：

$$V=\frac{1}{6}\begin{vmatrix}
x_{1} & x_{2} & x_{3} & x_{0}\\
y_{1} & y_{2} & y_{3} & y_{0}\\
z_{1} & z_{2} & z_{3} & z_{0}\\
1 & 1 & 1 & 1
\end{vmatrix}$$

这里 $x_i, y_i, z_i$ 表示顶点 $x_i$ 的三个坐标分量。为什么这个行列式跟上面点乘叉乘那坨相等，这里不展开——自己动手推一遍会发现两个是一模一样的，$\frac{1}{6}$ 照样保留。提这一笔的目的只是：以后看到这种行列式形式，要知道它其实就是在计算四面体的体积。

### 可正可负可零的体积

这个体积公式跟前面三角形面积公式有一个相像的地方，值得注意：它们都**带符号**。算三角形面积时可以是正面积也可以是负面积；四面体的体积同样可正可负。

体积是负的是什么状况？拿底面 $x_0x_1x_2$ 算出一个法向：如果 $x_3$ 跟这个法向在**同侧**，算出来的就是**正体积**——一个正常的四面体；如果 $x_3$ 在法向的**另一侧**，体积就是负的，这时也把它叫做一个**被反转了的四面体**（inverted tetrahedron）——正常情况下我们都默认四面体是正体积的，体积变负就意味着这个四面体翻过来了、凹了个面。

还有一种情况是**零体积**：四个点落在同一个平面上，也就是共面，体积为零。

> **结论**：体积可正、可负、可为零；符号由 $x_3$ 相对底面法向的侧向决定。负体积对应"被反转的四面体"，零体积对应四点共面。

### 四面体的重心坐标

有了可正可负的体积，就可以跟三角形一样，搞一套 barycentric weight。

用点 $p$ 把四面体分成四个小四面体——四面体有四个面，每个面跟 $p$ 构成一个小四面体，小四面体的体积都用刚才那个公式算（把相应的顶点换成 $p$）。

判定方式跟三角形一模一样：$p$ 什么时候在四面体里面？必然是**四个小四面体的体积都为正**的时候。

同时我们也知道，四个小体积加起来等于整个四面体的体积。所以把每个小体积除以总体积，就得到四个插值权重（barycentric weight）；把权重挂到四个顶点上，就能插值出 $p$ 的位置：

$$p \;=\; b_0\,x_0+b_1\,x_1+b_2\,x_2+b_3\,x_3$$

本质上跟三角形是一回事情：多了一个点，带来的是从面积到体积的转换、多了一些计算，但概念完全一样。你可以把它认为是一个"高级版"的三角形插值，只不过作用到了四面体上。

### 再战碰撞：点与三角形

最后用这套工具再举一个碰撞的例子：一个点跟一个三角形碰撞。假设三角形是静止的，点从 $p$ 出发、沿着速度 $v$ 的方向运动，想知道有没有发生碰撞。

判定分两步做：第一步，先求这个点什么时候跟三角形所在的**平面**碰撞——三角形落在一个平面上，先找到与这个平面相碰的时刻；第二步，再看碰撞点是否真的落在三角形里面。

第一步这样解：设碰撞时刻动点的位置为 $p_t = p + tv$。如果 $p_t$ 落在三角形的平面内，那么 $x_0,x_1,x_2,p_t$ 四点共面——它们构成的四面体体积为零。把体积公式写出来（常数 $\frac{1}{6}$ 不影响零判定），要求体积等于零：

$$\big((x_1-x_0)\times(x_2-x_0)\big)\cdot\big(p_t-x_0\big) \;=\; 0$$

把 $p_t - x_0 = (p-x_0) + t\,v$ 代进去，再用分配率整理一下。注意整理完是一个关于 $t$ 的**一次**方程——比撞球那会儿的二次方程还省事——碰撞时刻直接就解出来了：

$$t \;=\; -\,\frac{n\cdot(p-x_0)}{n\cdot v},\qquad n=(x_1-x_0)\times(x_2-x_0)$$

分子衡量的是出发点 $p$ 相对三角形平面的带符号"高度"，分母是速度在法向方向上的分量——一除，撞到平面的时刻就出来了。"体积为零"在这里扮演的角色，跟开头撞球问题里"距离等于半径"完全一样：都是把"发生碰撞"翻译成一个能解的方程。

### 本讲提到的题目

**课后思考题**（讲完三角形的法向与面积后顺手留下的）：给三个点 $x_0,x_1,x_2$，怎么判断它们是不是在同一条线上？提示是可以利用刚才讨论过的东西。

**解析**：三点共线 $\iff$ 从同一点出发的两条边向量平行，即 $x_{10}=x_1-x_0$ 与 $x_{20}=x_2-x_0$ 平行。而叉乘那一节刚讲过：两个非零向量平行 $\iff$ 它们的叉乘等于**零向量**——叉乘的大小带着 $\sin\theta$，平行时 $\theta=0°$ 或 $180°$，$\sin\theta=0$。

**答案**：计算 $x_{10}\times x_{20}$，结果是零向量 $\mathbf 0$ 就三点共线，否则不共线。（注意判据右边是黑体的零向量，不是数字 $0$。）

### 交点有了，还差一步：它落在三角形里吗

参数 $t$ 一到手，射线与平面相交的点 $\mathbf{p}_t$ 也就算出来了。但到这里事情只完成了一半——为什么这么说？因为这个相交点有可能落在三角形里面，也有可能落在三角形外面：平面是无限延展的，三角形只是其中一小块。所以接下来还要进一步检查：$\mathbf{p}_t$ 到底是不是落在三角形内部？

检查用的还是前面讲三角形内外检测时的那套套路：利用 barycentric weight（重心坐标权重），也就是三角形各块子面积之间的比例关系来判断。具体做法这里就不再重复一遍了，记得有这么一套检测方法就行。

于是，"射线与三角形求交"这件事整体上就归拢成两个部分：

1. 利用体积公式，算出点与面相交的位置，得到交点 $\mathbf{p}_t$；
2. 检测这个相交的点是否落在三角形内侧。

讲到这儿，正好回应一个同学当场提出的问题，它戳中的正是公式书写里容易犯嘀咕的地方：式子里 $\mathbf{x}_1$、$\mathbf{x}_2$、$\mathbf{x}_3$ 几个向量混在一起乘，括号要不要加？要加，只是我这里没有写出来——因为点乘只能跟另一个向量做，所以 $(\mathbf{x}_1 \times \mathbf{x}_2) \cdot \mathbf{x}_3$ 这种"先叉乘、再点乘"的分组是默认存在的，不写括号只是书写习惯，含义不会丢。

顺带再提醒一句：这一项你可以把它当作行列式来看。行列式的值跟顺序有关——两行（或两列）一交换，值就变号。所以尽量遵循约定的顺序去写；如果算出行列式的值是负的，有可能就是顺序出了问题。

### 矩阵：把向量按行列叠起来

接下来讲矩阵。今天时间不太充裕，我把这一块给大家过一遍，可能会留点尾巴下次接着讲——忘光了也没关系，这里就是提个醒，而且矩阵跟行列式是有关系的。

矩阵这个东西，其实就是把矢量叠在一起：我有一堆实数值，用行跟列把它们分别描述出来。图形学里用得比较多的可能就是 $3 \times 3$ 矩阵——相当于三个矢量叠在一起构成的这么一个矩阵。另外，图形学里通常只考虑实数矩阵：虚数也许有吧，但反正我是没怎么见过，实数占绝对多数。

#### 转置、对称、对角、单位

学过线性代数的，这几个定义应该都有概念，起码眼熟；没学过的建议回头稍微补一补。快速过一遍：

- **转置（transpose）**：沿着对角线，把上跟下的元素换位置——$(0,1)$ 跟 $(1,0)$ 换，$(0,2)$ 跟 $(2,0)$ 换，以此类推。
- **对称矩阵**：一个矩阵转置之后跟原来一模一样，也就是沿对角轴上下两两相等，就叫对称矩阵。
- **对角矩阵**：只有对角上有值，非对角的地方全是零。
- **单位矩阵（identity matrix）**：一种特殊的对角矩阵——对角上全是一。

#### 乘法的规矩与两个对称化套路

矩阵跟矩阵之间、矩阵跟向量之间都可以做乘法。具体怎么乘这里不细讲、不展开了——写来写去一大堆公式，大家也记不住；不太记得怎么乘的，一定要回头补补课，确保自己会做矩阵乘法和矩阵–向量乘法。真正要特别留意的是乘法的几条规律：

- **顺序不能换**：$AB \neq BA$。矩阵乘法跟顺序有关，不能像数的乘法那样随便交换，这个需要特别注意。
- **结合律成立**：$(AB)\mathbf{x} = A(B\mathbf{x})$。可以先对 $AB$ 做乘法，也可以先对 $B\mathbf{x}$ 做乘法，最后乘出来是一样的——想按什么样的组合去做乘法，没关系。
- **转置要倒序**：$(AB)^T = B^T A^T$。可以分别对 $A$、$B$ 做转置，但要把前后顺序倒一倒——这是个蛮重要的点。

单位矩阵的角色也顺带一提：$\mathbf{I}$ 乘一个向量，等于这个向量乘了跟没乘一样；跟矩阵相乘，也是乘了等于没乘。这就是 identity 的特点。

再给两个把不对称矩阵变成对称矩阵的套路，蛮有意思。第一个：让 $A$ 乘以它自己的转置。用刚才"转置要倒序"的规矩一验，$(AA^T)^T = (A^T)^T A^T = AA^T$，转置等于它自己——所以乘完之后这玩意儿就对称了。第二个套路不太常见，但有时候也有人用：$A + A^T$，它的转置显然等于它自己，同样是一个对称矩阵。

#### 逆矩阵：不是谁都有

还有一个东西叫逆矩阵（inverse）。如果一个矩阵 $A$ 有逆，那么 $A$ 乘以它的逆等于单位矩阵；而且左乘、右乘都可以——乘在左边、乘在右边都能得到 identity，这就是逆的定义。一个矩阵如果有逆，它是唯一的。

乘积的逆跟转置那一条有点像：可以分别对 $A$、$B$ 求逆，只不过顺序要倒一倒，$(AB)^{-1} = B^{-1}A^{-1}$。

但不是所有矩阵都有逆。例子很直观：全零矩阵。你不管怎么去构造一个矩阵跟它乘，乘出来最后都是零——零乘以任何数都等于零——永远不可能等于 identity。所以说它是不可逆的，没有逆。学过线性代数或者有一定基础的话，这些应该都比较了解，就不展开了。

### 正交矩阵：转置就是逆

接下来这个跟图形学相关的点，可能稍微重要一点，叫做正交矩阵（orthogonal matrix）。定义：一个矩阵由正交的单位向量构成——比如一个 $3 \times 3$ 矩阵 $A$，它的三个列 $\mathbf{a}_0$、$\mathbf{a}_1$、$\mathbf{a}_2$ 都是正交的单位向量。

"单位正交"意味着什么？**单位**，是说每个向量点乘它自己等于一；**正交**，是说不同的向量互相点乘等于零——因为它俩垂直。合起来就是：$i$ 跟 $j$ 相等的时候，乘出来是一；不相同的时候，做点乘（转置相乘）出来是零：

$$\mathbf{a}_i \cdot \mathbf{a}_j = \begin{cases} 1, & i = j \\ 0, & i \neq j \end{cases}$$

用这个定义，会发现一个有意思的现象：把正交矩阵跟它自己的转置相乘，会发生什么？$A^T$ 的三行分别是 $\mathbf{a}_0^T$、$\mathbf{a}_1^T$、$\mathbf{a}_2^T$，$A$ 的三列是 $\mathbf{a}_0$、$\mathbf{a}_1$、$\mathbf{a}_2$，乘出来：对角线上是 $\mathbf{a}_0 \cdot \mathbf{a}_0$、$\mathbf{a}_1 \cdot \mathbf{a}_1$、$\mathbf{a}_2 \cdot \mathbf{a}_2$，全是一；非对角线上是 $\mathbf{a}_0 \cdot \mathbf{a}_1$ 这些，全是零。对角全一、非对角全零——按咱们之前的定义，这正是单位矩阵。

> **结论**：正交矩阵乘它自己的转置等于单位矩阵，也就是说，它的转置就等于它自己的逆。通常情况下算矩阵的逆会很麻烦，但对正交矩阵而言，想要逆，直接对它做个转置就行了——这是正交矩阵很好的一个优点。

### 旋转与缩放：两个最基本的图形学矩阵

矩阵在图形学里很重要，为什么重要？因为图形学里有一类特殊的东西跟它直接相关——旋转。旋转可以用正交矩阵去描述。

这件事我喜欢通过这种方式去理解：三维空间里有一个物体，比如一个立方体，这是它初始的状态——它自带一个局部空间（local space），自己的前后左右上下就是它的坐标轴，这个时候局部空间跟 $x$、$y$、$z$ 是重合的。现在通过某一个旋转矩阵 $A$ 把立方体转一下，得到一个新的状态：它的前后左右上下不再跟 $xyz$ 重合，而是分别指向三个新的方向 $u$、$v$、$w$——这就是它新的局部坐标系在世界空间（world space）里的状态。

那 $A$ 跟这些方向有什么关系？$A$ 是做旋转的，把原来的 $x$ 方向转过去，得到的就是 $u$：$A\mathbf{x} = \mathbf{u}$；同样，$A\mathbf{y} = \mathbf{v}$，$A\mathbf{z} = \mathbf{w}$。而 $\mathbf{x}$ 就是 $(1,0,0)^T$，$\mathbf{y}$ 是 $(0,1,0)^T$，$\mathbf{z}$ 是 $(0,0,1)^T$，三个拼起来正好是单位矩阵，所以这三条合起来写就是 $A = [\,\mathbf{u}\;\mathbf{v}\;\mathbf{w}\,]$——乘不乘那个 $\mathbf{I}$ 反正无所谓，于是 $A$ 就直接等于这三个列向量拼成的矩阵。

$\mathbf{u}$、$\mathbf{v}$、$\mathbf{w}$ 是什么？是一个坐标系——三个单位正交的向量，彼此垂直、又都是单位长度。所以 $A$ 必然是一个正交矩阵。反过来看就明白了：**旋转矩阵本质上就是这个物体的局部坐标系在世界空间中的状态**。拿到旋转矩阵，就等于把物体的局部坐标从矩阵里"抠"了出来。上过基础图形学课的话，这个概念应该不陌生；没听过这种解释的话，就当收获一个新视角。

旋转相关的形变之外，还有一类形变叫放大缩小——缩放矩阵（scaling matrix）。同样一个立方体，现在要沿着 $x$、$y$、$z$ 做缩放，怎么做？定义一个矩阵 $D$，让对角线上的值分别是三个方向的缩放量：

$$D = \begin{pmatrix} d_x & 0 & 0 \\ 0 & d_y & 0 \\ 0 & 0 & d_z \end{pmatrix}$$

$d_x$ 就是 $x$ 方向的缩放量，$d_y$ 是 $y$ 方向的，$d_z$ 是 $z$ 方向的。所以缩放矩阵就跟对角矩阵有关。

一句话归拢：旋转用正交矩阵描述，缩放用对角矩阵描述。有一点图形学基础的话，这些应该都学过。

### 奇异值分解：转一下、缩一下、再转一下

接下来讨论下一个东西——特征值分解。是不是听着觉得特别慌？我以前学线性代数的时候，听到特征值什么的，反正就觉得特别头大。其实这个东西特别有意思，它在图形学里有一个非常直观的解释。不过先从跟它直接相关、也更一般的概念讲起：奇异值分解（singular value decomposition，SVD）。

假如我有一个矩阵 $A$，"分解"是什么意思？就是这个矩阵可以写成三个部分的乘积：

$$A = U\, D\, V^T$$

中间的 $D$ 是一个对角矩阵，对角上的值叫**奇异值**（singular value）——注意，是奇异值，不是特征值，这两个词这一讲都会出现，别搞混；两边的 $U$、$V$ 都是正交矩阵。

我当年光在数学课上看这个式子，是有点懵的：这玩意儿到底有啥意思？可以这么理解。假如你有一个物体——比如一个方块——通过某一个矩阵的线性变换，它形变成一个新的形状。奇异值分解本质上就说了一件事情：**不管什么样的线性形变，都可以用三个操作去描述——旋转、缩放、旋转**。

```text
          V^T 旋转                D 缩放                 U 旋转
 原方块 ────────────→ 转到特定位置 ────────────→ 沿轴拉伸 ────────────→ 转到最终朝向
```

读图：先用 $V^T$ 把方块转到一个特定的位置上，接着由 $D$ 做缩放，最后用 $U$ 把它转到想要的方向上去——整个线性变换就完成了。

为什么中间要垫一个旋转？因为缩放矩阵是对角的，做缩放的时候必须沿着坐标轴缩，只能沿 $x$、$y$ 这些轴拉。想沿某个斜着的方向缩放怎么办？那就先做一个旋转（$V^T$），把物体转到轴对齐的位置上，然后再缩放。举个最简单的例子：想让方块沿对角方向缩放，就先把它转 45 度，让它的对角跟 $xyz$ 重叠，这时候再做缩放，不就是对角方向上做缩放了吗？缩完之后，最后一个旋转把它转到我想要的位置上去。

所以奇异值分解的核心是中间那个 scaling：**不管什么样的线性变换，本质上都是缩放**——只不过是沿任意方向的缩放。先调整朝向，做缩放，缩放完之后再转到想要的方向上，整个线性过程就完成了。这里画的是二维的例子；四面体（三维）的情形一模一样，换成三维的旋转、三维的缩放、三维的旋转来实现就行。

顺带回答一个常见的疑问：所有的 $A$ 都可以做奇异值分解吗？是的，所有的矩阵都可以做 SVD。

### 特征值分解：对称矩阵的特例

跟奇异值分解相关的另一个，叫做特征值分解（eigenvalue decomposition）。刚才是奇异值分解，现在讲特征值分解。图形学里我们会把问题考虑得稍微简单一点点——简单在哪里？简单在我们**只考虑对称矩阵的特征值分解**。

对称矩阵的特征值分解长这样：

$$A = U\, D\, U^{-1}$$

把它想象成奇异值分解的一个特例：SVD 左边右边是 $U$ 跟 $V$ 两个正交阵，当矩阵对称的时候，左边跟右边就一模一样了。至于这里写 $U^{-1}$ 还是写 $U^T$，无所谓——$U$ 是正交矩阵，它的逆跟它的转置本质上是一回事情，所以式子里写转置、写逆，没有区别。

数学书上它的定义会稍微有点不一样。教科书的写法是：把正交矩阵 $U$ 写成一列列的向量 $\mathbf{u}_0$、$\mathbf{u}_1$、$\mathbf{u}_2$，那么

$$A\,\mathbf{u}_i = d_i\,\mathbf{u}_i$$

矩阵 $A$ 乘以一个特征向量，等于这个特征向量乘以某个特征值。这个式子从分解式里怎么出来的？推一遍：

$$A\,\mathbf{u}_i = U\, D\, U^T \mathbf{u}_i$$

$U^T$ 乘 $\mathbf{u}_i$ 得到什么？$U$ 是正交矩阵，$\mathbf{u}_i$ 是它自己的第 $i$ 列，一个正交矩阵的转置去乘它自己的一列，得到的不就是一堆零加一个一吗——上下全是零，第 $i$ 个位置是一。接着乘对角矩阵 $D$：对角阵乘这种"一堆零加一个一"的向量，就是把原来 1 的位置换成 $d_i$，其余还是零。最后左乘 $U$，等于就是 $d_i$ 乘以 $\mathbf{u}_i$——特征向量被抠出来了。

这里的 $d_i$ 就叫**特征值**（不叫奇异值了），$\mathbf{u}_i$ 叫**特征向量**。$A = UDU^T$ 这个分解式跟 $A\mathbf{u}_i = d_i\mathbf{u}_i$ 这个定义式，其实是一回事情，只不过一个是分解的写法、一个是跟特征值打交道时更常见的写法。

补充两点。第一，我这里说的是对称矩阵——非对称的矩阵其实也可以做特征值分解，但它分解出来的特征值、特征向量有可能是虚数；图形学里通常不考虑虚数，所以我们就不考虑了，通常只考虑对称矩阵。第二，$A\mathbf{u}_i = d_i\mathbf{u}_i$ 这种教科书式写法在图形学里用得到的地方不是特别多，大家听一听就完了；觉得特别懵也没什么关系，记住这两个定义是一样的就行。

把两种分解并排放在一起，区别一目了然：

|  | 奇异值分解（SVD） | 特征值分解（图形学口径） |
| :--- | :--- | :--- |
| 分解形式 | $A = U D V^T$ | $A = U D U^T$（或 $U^{-1}$） |
| 两侧因子 | 正交阵 $U$、$V$，一般不同 | 同一个正交阵 $U$ |
| 对角元的名字 | 奇异值 | 特征值 |
| 适用范围 | 所有矩阵都可以做 | 图形学里只取对称矩阵 |

### 正定：矩阵版的"正数"

跟特征值相关的，还有一个概念叫做**对称正定**（SPD）。为什么它重要？因为它跟我们处理线性问题、解线性系统的时候特别有关系——是矩阵一个很关键的定性。

先看定义。给任何一个非零的向量 $\mathbf{x}$，把它左右夹着矩阵乘一遍，乘出来是一个实数：

$$\mathbf{x}^T A\, \mathbf{x} > 0$$

不管什么向量，只要非零，乘出来的这个实数肯定大于零——那这个矩阵就叫做**正定**的。要是它有可能等于零，也就是对一切非零向量都有 $\mathbf{x}^T A\mathbf{x} \geq 0$，那就叫**半正定**。当然，前提是矩阵得对称。

> **定义**：对称矩阵 $A$ 正定，是指对任何非零向量 $\mathbf{x}$ 都有 $\mathbf{x}^T A\mathbf{x} > 0$；把大于号换成 $\geq$，就是半正定。

教科书的定义就这两行，大家懵不懵？反正我以前中学、大学里学线性代数的时候，还是挺懵的。接下来给大家一个直观的感觉：这玩意儿到底是个什么东西，"正定"到底在说什么。

先从一个数想起。我有一个实数，是个大于零的正数 $d$。把它放在中间，左右乘上同一个非零向量，是不是肯定大于零？为什么？因为它本质上就是 $d$ 乘上向量大小的平方：$d\,|\mathbf{v}|^2$。向量的大小（magnitude）肯定是正的，$d$ 又是正的，所以这玩意儿肯定是正的。

那 $d$ 是一个数，不是一个矩阵，怎么跟矩阵联系在一起？假如说我不是一个实数，而是有一堆实数 $d_0, d_1, d_2, \dots$，把这些实数搞成一个对角矩阵 $D$，左右都乘上向量，会发生什么？把这个式子展开：

$$\mathbf{v}^T D\, \mathbf{v} = d_0 v_0^2 + d_1 v_1^2 + d_2 v_2^2 + \cdots$$

一堆平方项，平方天然非负，前面的 $d_i$ 又都是正的，所以加起来肯定大于零——一堆正的数加起来，不可能是负的值。所以说：**对角元全为正的对角矩阵，必然是正定的**，满足前面 SPD 的定义。

再往下走一步。毕竟很多矩阵不是对角矩阵，奇奇怪怪的，怎么把这个结论跟各种奇奇怪怪的矩阵联系在一起？可以这么想：还是一堆正实数 $d_0, d_1, d_2$ 摆成对角阵 $D$，另外再有一个正交矩阵 $U$（就是前面说的那种），构造

$$A = U\, D\, U^T$$

——这不就是刚才讲的对称矩阵特征值分解嘛，$D$ 分解出来的对角元就是特征值。如果这些特征值都是正的，$A$ 正定吗？看：给 $\mathbf{x}^T A\mathbf{x}$ 前后各乘上 $U$、$U^T$，这不会影响这个等式，因为插进去的东西是 identity——$U$ 是正交矩阵，正交矩阵乘它自己的转置等于单位矩阵。插入之后，把中间的 $D$ 拆成两半，分别跟前后结合，$U^T$ 跟 $U$ 各自抵消，最终中间就是个 $D$，两边得到：

$$\mathbf{x}^T A\, \mathbf{x} = \mathbf{x}^T U\, D\, U^T \mathbf{x} = (U^T\mathbf{x})^T\, D\, (U^T\mathbf{x})$$

记 $\mathbf{y} = U^T\mathbf{x}$。$\mathbf{x}$ 是非零向量，而 $U^T$ 做的是旋转——一个非零的向量，给它旋转一下，怎么都不可能变成零向量——所以 $\mathbf{y}$ 也必然非零。于是问题就回到了刚才对角矩阵的情形：对角元全正的对角阵夹一个非零向量，必然大于零。

这就说清了一件事：**对称矩阵特征值分解出来的特征值全是正的，它必然是正定的**；而且这两件事是一回事情、是等价的——正定，等价于特征值全正。整条直觉链合起来就是：什么叫"正"？对一个数来说，非零数的平方必然大于零；类推一步，对角元全正的对角阵夹住非零向量，必然大于零；再类推，给这个全正对角阵前后各乘一个正交矩阵——做个旋转，不影响正定性——还是正定。这就是正定矩阵的全貌。

### 别硬算：正定的实用判定与可逆性

听起来挺有意思，但我们实际中是不会去通过特征值分解来玩正定性的。为什么？因为利用数值计算做特征值分解，一般来说很慢、计算量非常大，通常不会直接去做这个计算。那怎么判定？可以用一些别的法则，比如：**如果一个矩阵是对角占优的，那么它一定是正定的**。

什么叫做对角占优？对角上的值，大于同一行非对角元素的和。举个对角元为 4、5、9 的矩阵：

$$\begin{pmatrix} 4 & 3 & 0 \\ 1 & 5 & 3 \\ 0 & 8 & 9 \end{pmatrix}$$

逐行检查：第一行，$4 > 3 + 0$；第二行，$5 > 1 + 3$；第三行，$9 > 0 + 8$。行行过关，所以它是一个对角占优矩阵，进而它是正定的。这里不要求行、列两边同时满足——只要每一行都满足（或者每一列都满足）就够了。

> **注意**：对角占优能推出正定，反方向不成立——正定的矩阵未必对角占优。所以这只是个充分条件：检查过关，可以放心下"正定"的结论；检查不过关，并不代表矩阵不正定，只是这条捷径给不出答案。

正定还带来一个直接的好处：**SPD 矩阵必然是可逆的**。为什么？看它的逆：

$$A^{-1} = (U\, D\, U^T)^{-1} = U\, D^{-1}\, U^T$$

$U$ 是正交矩阵，它的逆就是它自己的转置；$D$ 是对角矩阵，对角上的元素都是正的，逐个取倒数就行，所以它也是可逆的。串起来，$A^{-1}$ 一定存在——一个 SPD 矩阵必然可逆。

这些概念会在什么情况下用到？后面讨论有限元的时候，还有跟矩阵的 Hessian——也就是矩阵的二阶导——打交道的时候，都会碰到。这里把这些概念先给大家过一遍，有个印象就行：现在很懵也不要紧，到时候再回来回忆一下；如果对概念完全没有感觉，也可以把这一段翻出来再看一看。
