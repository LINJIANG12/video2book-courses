大家好。今天是 GAMES002 课程的倒数第二节课，我们根据大纲的安排来讲一下三维处理的工具。

关于三维处理工具，指的是图形学中遇到的一些专门用来做几何处理、渲染和做重建的软件。我们今天的内容大概可以分成这三个部分来推进。首先，我们会介绍基本的几何处理软件，包括 CloudCompare、MeshLab 等比较知名的软件；其次，我们会介绍如何通过调库的方式来做几何处理，比如使用 Open3D 代码库；第二部分我们将介绍渲染工具，这里会有常见的 Blender 或者 KeyShot 这样的渲染工具；第三部分我们将介绍几何重建工具，包括最常用的 COLMAP 和商用软件 ContextCapture。这就是我们今天的全部内容，最后会有一次作业布置。

首先我们来讲几何处理软件 CloudCompare。这个软件从名字上大家就可以看出来，其实是用来做点云处理的。它也支持一些额外的功能，比如做网格处理，但它最主要的功能是对 3D 点云做几何处理，包括点云的变换、过滤等，都可以用 CloudCompare 这个软件。

这个软件是一个开源软件，可以在网上找到它的 C++ 源码。如果你要写一个 C++ 程序，是可以直接调用它的一些函数的。同时它作为一个软件，本身自带图形化界面，提供了一些很方便的功能。比如它有一系列插件，在给出点云后能够估计法向，或者做点云过滤（如剔除异常点）以及点云分割。插件在 CloudCompare 里非常通用，它有一系列标准插件，也可以实现自定义插件。这一系列插件组成了 CloudCompare 的扩展功能。它的基础功能是点云的显示和查看。它是一个 3D 查看界面，最基础的功能是显示点云、显示坐标轴、显示比例尺。在界面的左侧和上方有很多按钮，用来做点云编辑或点云处理。具体的功能大家可以查看 CloudCompare 的主页。它基于 OpenGL 做渲染，底层调用了 C++ 的处理库，应该是 PCL 处理库。

刚才的 CloudCompare 基本上只能做点云的处理和渲染。但实际上我们平时更通用的一种数据格式是三角网格，即 MeshLab 名字里的 Mesh。MeshLab 比 CloudCompare 更加通用一些，它不仅可以做点云的处理，也支持对三角网格进行处理。它的功能主要集中在对网格的处理上。它本身也是一个开源软件，用 C++ 编写。

除了图形化界面以外，MeshLab 提供了 Python API。在 Python 代码里调用 MeshLab 的 API 即可实现想要的功能，不需要在图形化界面上手动操作。MeshLab 支持各种网格算法，包括网格简化、凸包计算等。这些功能可以在 MeshLab 的主页上查阅官方文档。

网格在 MeshLab 界面中可以直接显示，比如 Stanford Bunny 模型。在界面中可以显示出网格的顶点，三角面片也可以以 wireframe 的形式显示出来。MeshLab 能够提供的一个重要功能是直接在界面中编辑 3D 数据，比如选取网格并做进一步操作（如剔除或其他变换）。通过选取的特征功能，界面中显示的红色三角面片即为被选中的部分。MeshLab 作为三维可视化查看软件，最主要的功能就是能够直接在上面编辑 3D 数据。虽然通过代码很难直接实现某些交互操作，但配合带有图形界面的软件可以直观地完成网格编辑。

MeshLab 的 Python 绑定工具叫做 PyMeshLab，能够很方便地通过 pip 或者 conda 安装。安装后即可直接调用 MeshLab 内置的函数，比如载入网格（load mesh）、计算凸包以及保存当前的网格。这一系列编辑操作都可以通过 Python 函数调用的形式来完成。PyMeshLab 的文档中列出了其支持的所有 API 和功能。

PyMeshLab 有一个特殊功能，即可以定义过滤器。首先生成一个 MeshSet，接着可以在上面做一系列操作，例如对坐标做拉普拉斯平滑，最终把这一系列操作通过 `save_filter_script` 保存成本地文件。该文件中记录了所有执行的操作。下次想要复刻同样的操作时，直接载入该文件即可对输入的网格执行同样的一系列操作。它提供了一个方便的定制脚本功能。综合来说，MeshLab 兼顾了图形化界面与编程化管理方式。可以先在图形化界面中进行验证，后续通过脚本化操作批量处理几何单元。

除了上述两个软件，还有一个非常方便的几何处理工具——Open3D。严格来说它不能算作几何处理软件，因为它本身没有图形化交互界面，而是一套代码库。它比 MeshLab 更加通用，涵盖了 3D 几何处理的各个方面。

Open3D 本身是用 C++ 编写的代码库，但提供了 Python 绑定，从 Python 调用非常容易。它支持各种 3D 算法，包括点云处理、网格处理，以及射线求交等计算几何算法。它的官方文档写得非常清楚。Open3D 具有一系列可视化函数。之前的几何处理工具是通过软件打开可视化界面并在其中操作，而 Open3D 是通过调用代码生成图形化窗口，在窗口中查看结果。在平时使用的过程中，通常会结合使用 MeshLab 和 Open3D。MeshLab 本质上是一个软件，在 Python 代码中调用相对较重；而 Open3D 作为代码库，提供了方便的 API，适合嵌入代码中完成点云处理或网格简化等操作。

它的官方文档提供了许多 Python 示例，展示了 Open3D 可以实现的功能。针对每个功能都有对应的 `.py` 文件及示例代码，可以参考学习。例如处理相机、处理相机轨迹、点云与网格处理（位于 geometry 模块）、点云和网格数据的读取与保存（位于 io 模块），以及常用的可视化功能。

总体而言，几何处理工具基本可以分为两类：一类注重可视化（如 MeshLab），方便在开发初期快速验证正确性与方法可用性；确定方法可用后，则可以通过 Open3D 这类库将几何处理逻辑整合到代码中。

介绍完几何处理工具后，来看一下渲染工具。这里最主要的是 Blender。Blender 在渲染中是非常重要的工具，几乎所有内容都可以在 Blender 中完成渲染。Blender 本身是一个开源软件，使用 Python 编写，提供了图形化界面以及 Python API。其图形化界面是一个非常复杂的系统，支持各种功能。相比于偏向轻量开源工具的 MeshLab，Blender 在渲染工具中属于工业级的渲染工具，上手难度比 MeshLab 高很多。由于支持的功能非常多、系统复杂，需要花费较多时间来学习其使用方法。官方提供了中文手册，可以在上面找到官方教程。

此外，网上有非常丰富的 Blender 教程。在学术使用上，GitHub 上有专门做学术渲染的库，例如 BlenderToolbox 提供了丰富的示例脚本。此外，知乎、YouTube 以及 B站上也有许多博主制作了优质的教程。由于 Blender 工具非常复杂，大家可以根据自己的需求检索相应的教程。

除了 Blender 以外，还有其他渲染工具。例如非常著名的 Houdini，主要用于电影特效和游戏特效制作，门槛相对更高。另外还有 KeyShot，与偏向光栅化渲染的 Blender 不同，KeyShot 更注重真实感渲染，采用光线追踪算法，是一款重量级的商业软件，主要提供基于光线追踪的真实感渲染。除此之外，还有 UE4、Unity 这样集成了渲染模块的综合引擎工具。

最后介绍几何重建工具。三维重建是指从一系列照片中恢复出 3D 模型的算法。3D 模型的数据获取来源主要有两种：一种是通过 CAD 手工建模或艺术家创作；另一种是通过算法从真实世界中恢复，包括雷达扫描或基于图像的重建。我们这里介绍的重建工具主要指从图像中恢复物体的三维模型。最常见的使用场景是对物体或场景拍摄一系列照片，随后将照片输入算法，算法自动生成所拍摄场景的三维模型。

首先介绍重建中最重要的工具之一——COLMAP。COLMAP 源自一篇学术论文所附带的工具。它支持的功能包括位姿估计（确定每张图片拍摄时的相机姿态），这是后续重建的基础。在确定相机姿态后，COLMAP 支持渐进式重建：第一阶段是稀疏重建，根据相机姿态估算三维物体所在的位置，确认物体表面特征点的位置，最终输出稀疏点云；由于稀疏点云难以直接用于高质量可视化，因此需要进一步进行稠密重建，利用泊松重建等方法将位姿和稀疏点云转化为稠密点云或网格模型。

COLMAP 是一个开源软件，可以在 GitHub 上找到 C++ 源码。它依赖 CUDA 运行，并提供了简单的图形化界面与 Python API。它的界面相比 Blender 而言更为简洁。在典型流程中，围绕物体拍摄多张图像，COLMAP 最终重建出物体的三维模型，并确定所有拍摄照片对应的相机位姿（在界面中以红色锥体表示）。重建出的模型可以导入 MeshLab 等工具中进行查看与渲染。

除了主要用于学术研究的开源工具 COLMAP 之外，在商业领域还有一个更重量级的工具——ContextCapture。与 COLMAP 相比，ContextCapture 是一款闭源的商业付费软件。它更擅长处理户外大场景，例如无人机航拍生成的结果。它针对工业级应用设计，提供了更专业的位姿估计和重建算法，并支持图形化界面与 Python API。
