# GAMES002：图形学研发基础工具（9 讲）

GAMES002 讲图形学研发绕不开的工具链：Linux 与 shell、Windows 的 CMD 和 PowerShell、SSH 远程开发与 tmux、Git/GitHub 版本管理、C++ 的编译构建与包管理（make/CMake/conda）、编辑器与 Markdown/LaTeX 写作，以及个人网站搭建和三维处理、仿真渲染软件的使用。环境配置是图形学的隐形门槛，这门课把它拆成一条条可执行的操作。9 集整编为 4 册、8 篇主题笔记。

## 怎么学
- **边看边敲**：命令行、Git、编译构建都必须在自己的机器上复现一遍，光看会忘。
- **先 Linux 后 Windows**：shell 基础打好，再看 PowerShell 的对象管道会快很多。
- **Git 按「提交—分支—撤销—远程协作」顺序练**，别只背命令。
- **CMake 与包管理按项目学**：拿一个最小 C++ 工程走通 configure/build/install。
- **编辑器与写作工具按需取用**：Markdown 速查 + LaTeX 公式，够写笔记与报告即可。
- **三维/渲染软件部分当操作手册**：跟着课里的流程走一遍资产导入与渲染。
