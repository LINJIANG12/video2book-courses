# GAMES301：曲面参数化（15 讲）

GAMES301 讲曲面参数化：从参数化导论与离散网格基础出发，讲无翻转方法体系、全局单射与 Atlas、参数化网格生成与光滑映射、调和映射与高质量形变、共形参数化与锥奇异点，最后到曲面对应、高阶网格与产业应用。核心问题只有一个：怎样把曲面摊平到平面，同时不翻转、不重叠、少扭曲。15 集整编为 4 册、7 篇主题笔记。

## 怎么学
- **先明确目标**：把曲面摊平到平面，同时不翻转、不重叠、少扭曲。
- **无翻转方法按「约束 → 求解」梳理**。
- **单射与 Atlas 是全局化的关键**。
- **调和/共形部分抓住能量与奇异点**。
- **产业应用部分对照 UV 展开流程**。
