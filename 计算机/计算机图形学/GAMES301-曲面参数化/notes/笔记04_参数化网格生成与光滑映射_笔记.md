# 参数化网格生成与光滑映射

## 网格生成与重新网格化

* **网格生成（meshing）**

    * > **定义**：用一些多边形或者多面体，通过边和点把它们连起来，用来近似一个数字模型的几何。

    * 典型形态：先对飞机表面做四边形化，让表面上每个元素都是四边形；再对机体外部的空气区域做网格化，最外层用四面体，贴着表面的那一层是边界层网格。

    * 生成的网格接入有限元分析、流体力学等物理仿真，算出物理量，用来判断最初设计的形状是否合理、性能是否达标。

    * 是连接 CAD 与 CAE 的桥梁：CAD 模型最常见的表示是 NURBS 曲面片或各种基本体元，片与片之间离散拼合；做 CAE 之前必须网格化，而这个网格化过程缓慢，效率与鲁棒性都需要提升。

    * CAD/CAE 一体化想用统一的模型或数据表示同时完成设计与分析、从而免去网格化，但迄今没有方法能完全做到。

    * 闭环还要反向走一遍：用物理分析结果修改 CAD 模型，目前多靠人工；用神经网络与可微（differentiable）技术把 CAE 结果反过来 deform CAD 是一个研究趋势。

* **重新网格化（remeshing）**

    * > **定义**：给定一个三维网格作为输入，计算另一个网格，使输出的每个元素（element）满足一定的质量准则，同时输出网格对输入曲面的近似程度足够好——比如两者之间的 Hausdorff 距离受控、比较小或者有界。

    * 输入网格质量可能很差、满足不了质量要求；输出要满足质量要求，同时两者距离控制在可接受范围内。

    * 输入不限于三角形网格；它相当于对一个已有的网格模型做进一步的质量提升。

* **坏网格的两种来路**

    * 三维扫描：重建一般用 marching cubes 出网格，往往先出一张很密的网格再做简化，简化时可能根本没考虑质量，结果就比较糟。

    * CAD 模型：从一片片 NURBS 曲面片做三角化或其他网格化时质量可能没做好；CAD 网格化流程的第一步往往就是先生成粗糙的三角化，再做优化把质量提上来。

## 网格类型与质量准则

* **四种基本网格**

    * 表面网格：三角形网格（每个单元是三角形）、四边形网格（每个单元是四边形）。

    * 体网格：四面体网格、六面体网格——体网格不光有表面，还有内部。

    * 动画与游戏常用四边形网格，因为其边的走向可以跟特征走向保持一致，做动作时动作的捕捉比较好。

    * 有限元偏爱六面体与四面体，因为可以在上面构造高精度的基（基函数），分析精度更高。

    * 这个偏好不是绝对的：三角形、四面体上同样可以构造高阶基，也可以把几何本身变成高阶几何（高阶网格），每个单元上的精度同样能提上来。

    * 用哪种网格由应用驱动；某些应用里两类网格存在竞争（battle），只能在质量指标与计算代价之间取舍，不能说哪一种一定比另一种好。

    * 有限元的最终评判标准只有一条：物理仿真的结果是否准确。

* **质量准则的五个维度**

    * 元素正则性：三角形越接近正三角形越好，四边形越接近正方形越好。

    * 尺寸场（size field）：有些地方元素要大一点，有些地方要小一点。

    * 朝向（orientation）：网格要有明确的走向信息，比如四边形网格整体的走向。

    * 对齐（alignment）：网格边要跟特征线（feature）对齐。

    * 拓扑：出现非流形等不好的拓扑结构时，要做 repair。

* **各向同性（isotropic）与各向异性（anisotropic）**

    * 各向同性：每个三角形元素都接近正三角形，也就是都接近正则（regular）三角形。

    * 各向异性：带圆角过渡的立方体上，圆角处曲率大，用尺寸小的近正三角形；中间平坦处用大一点的正三角形；侧面沿轴向是狭长的三角形——元素跟着曲率做自适应。

    * 各向异性的朝向在工程里由 PDE 决定，而不只是跟曲率主方向对齐。

    * 各向异性最常用于流体仿真（CFD）：水、空气、喷气的模拟；网格符合流体流动与变化的方向时，仿真精度显著提升。

* **采样密度：均匀与自适应**

    * 均匀（uniform）：所有三角形大小一样。

    * 自适应：在曲率高、曲面变化快的地方（如眼睛一圈）加密，曲率低的地方少放。

    * 目的是在三角形总数不爆炸与逼近程度更好之间取得平衡。

* **特征对齐与规则顶点**

    * CAD 模型一般有 sharp feature：两侧法向产生剧烈变化的棱边；机械与工业零件本来就有这些棱棱角角。

    * 一条 sharp feature 上，左右两侧的三角形应该有一条边正好压在 feature 上；若中间那条边偏离开 feature 斜着走，这一段 feature 就没被保持住。

    * 三角形网格的内部顶点度为 6 称 regular，四边形网格的内部顶点度为 4 称 regular，其余称 irregular。

    * 对一张粗糙的三角形网格做细分得到的网格称半规则（semi-regular）网格；所有点的度都是 6 的完全规则三角形网格很少见，大部分点的度是 6 的称高度规则（highly regular）网格。

## 参数化路线的流水线

* **经典方法版图**

    * Delaunay refinement（德劳内细化）与泊松盘采样（Poisson disk sampling）。

    * advancing front（推进波前法）：工程里使用非常广泛、局部控制力强，但研究价值没那么高。

    * 局部操作（local operations）：edge flip（也叫 swap、交换边）、collapse、split、smoothing 四个操作，提升质量显著，但过于局部，很容易陷入局部最小。

    * 基于参数化的方法。

    * 基于优化的方法，门类下方法很多。

    * 基于场（field）的方法：近年比较热门，与参数化方法在内容上有交叉。

* **三步流水线**

    * (1) 计算参数化：用一个映射 $f$ 把曲面摊到平面；(2) 在参数域里做重新网格化或网格生成；(3) lift：用 $f$ 的逆映射把结果拉回原始曲面。

    * 第三步相对容易，主要的困难在中间那一步。

```text
输入网格 (3D)
    |
    | (1) 参数化 f：曲面 -> 平面
    v
2D 参数域
    |
    | (2) 在参数域里做网格生成 / 重网格化
    v
2D 新网格
    |
    | (3) lift：用 f 的逆映回原始曲面
    v
输出网格 (3D)
```

* **搬到平面上做的理由**

    * 参数化到平面以后，在参数域里做 meshing 或 remeshing 变得简单——参数化把网格生成这个问题变简单了，这才是使用参数化路线的内在动力。

    * 参数化本质上是一个映射：把输入定义域映到另一个域，在那个域里网格化简单，做完再变回原始网格。

    * 方法论上等价于"把难解的原始问题转化成一个相对简单的等价问题，求解后再返回来"。

    * 输出既可以是各向同性的生成，也可以是带尺寸场的自适应版本：曲率高的地方点放得多一点。

## 切割与接缝约束

* **闭网格的切割（cut）**

    * 输入是开网格（带边界的曲面片）时可以直接参数化；输入是闭网格（比如一个球）时，要先做 cut 把网格切开，切完再参数化。

    * 对参数化的要求是低扭曲（low distortion）：保角（conformal）也好、等距（isometric）也好，这样在 2D 平面上做的三角化返回来时还能保持形状。

* **割缝（seam）的可拼合约束**

    * 沿曲面做的一条割缝参数化到 2D 上后，原始网格上的一个顶点会被拆成参数域上的两个、三个甚至几个顶点。

    * lift 回来时，割缝处必须还能合上、拼得起来，这需要在参数化里加入额外约束。

    * 这是参数化用于网格化时最麻烦的一处约束：它决定 cut 要怎么切、映射要满足什么条件。

## 各向同性重网格化

* **三维直接操作的失败：狗耳朵**

    * 狗的两只耳朵上下靠得非常近，属于极端的扁平结构、很小的特征。

    * 直接在三维里用 collapse、split 改善质量时，判断依据是三维欧氏距离：耳朵上下两点的欧氏距离很近，边小于目标边长就被 collapse，一路做下去耳朵慢慢被吃掉，尾巴和耳朵最后都不在了。

    * > **易错点**：细窄结构（贴得很近的耳朵、尾巴、薄壁）上下两侧的点三维直线距离很近；按三维欧氏距离去判断"这条边该不该 collapse"，就会把结构本身吃掉。

* **参数域为什么能救回结构**

    * 先把网格参数化到 2D 平面，且这个参数化要接近等距（isometric）嵌入，然后在 2D 平面上做各向同性网格生成。

    * 接近等距意味着在 2D 平面上算两点的距离，近似等价于在原曲面上算测地距离（geodesic distance）。

    * 于是三维里直线距离很近的耳朵上下两点，在 2D 上距离其实比较长，不会被 collapse 掉；lift 回来耳朵在、尾巴也在，尾巴处还留着不少三角形。

* **cut 边界的两步处理**

    * 切开得到的 cut 边界，在 2D 重网格化过程中保持不动。

    * 原始网格切出的边界不能保证各向同性，每段边长并不一样；所以在切割之后、参数化之前，先对边界做一轮 split 与 collapse，把位置调一调，让每条边长都差不多。

    * 这样边界在参数化之前就已经比较均匀，后续在 2D 里得到的也是均匀的边界。

* **四步完整流程**

    * (1) 切割：把网格切成与圆盘同胚，切割边界先做 split / collapse 使每段边长接近。

    * (2) 参数化：低扭曲，接近保角或等距。

    * (3) 在参数域里做各向同性 remeshing，cut 边界保持不动。

    * (4) 把 2D 均匀三角网格投影回原始曲面（lift）。

    * 这四步分别解决拓扑、几何、平面内的网格生成与回投，就是一个简单的基于参数化的各向同性网格生成。

## 各向异性度量场

* **度量场（metric field）**

    * 输入有两样：一个定义域，以及定义域上每一点的一个对称正定（symmetric positive definite，SPD）矩阵 $M$，也就是度量或距离矩阵。

    * 目标：网格里每个三角形的三条边在这个新距离下长度尽量相等，相当于"度量意义下的正三角形"。

    * $M$ 描述该点元素的朝向与大小——某个位置的元素该多大、该朝哪个方向，由该位置的度量场决定。

    * > **注意**：凡是说"边长"，指的都是新度量下的距离，不再是欧氏距离。

* **度量的三条性质**

    * 非负性：$d(x,y)\ge 0$，并且 $d(x,y)=0$ 当且仅当 $x=y$。

    * 对称性：$d(x,y)=d(y,x)$。

    * 三角不等式：$d(x,z)\le d(x,y)+d(y,z)$。

    * 欧氏距离 $d(x,y)=\lVert x-y\rVert_2=\sqrt{\langle x-y,\;x-y\rangle}$ 满足全部三条：它本质是范数故非负，$x-y=0$ 时才为零，三角不等式由 $\lVert (x-y)+(y-z)\rVert\le\lVert x-y\rVert+\lVert y-z\rVert$ 得到。

    * 定义度量的常见造法是在线性空间里用内积去定义；也存在别的方式，各向异性用的正是"换一个内积"这一招。

* **用 SPD 矩阵重定义内积**

    * 新内积 $\langle x,y\rangle_M=x^{T}My$；新范数 $\lVert x\rVert_M=\sqrt{x^{T}Mx}$；距离 $d(x,y)=\lVert x-y\rVert_M$。

    * 三层是一条链，度量 $M$ 的作用点在最底层的内积上，范数与距离全部跟着变。

    * $d(x,y)=1$ 即 $(x-y)^{T}M(x-y)=1$，在二维是一个椭圆、在三维是一个椭球——每个点上画的小椭圆就是这个点把"单位距离"捏成的形状。

* **特征分解：把各向异性拉直成各向同性**

    * $M$ 对称正定，可做特征值分解；把特征值开根号塞进一个新矩阵 $\Phi$（相当于"取一半"），得 $M=\Phi^{T}\Phi$。

    * 代回距离得 $d(x,y)=\sqrt{(x-y)^{T}\Phi^{T}\Phi(x-y)}=\lVert\Phi(x-y)\rVert_2$；令 $x'=\Phi x$、$y'=\Phi y$，则 $d(x,y)=\lVert x'-y'\rVert_2$。

    * 含义：$\Phi$ 把各向异性网格空间映到各向同性网格空间，各向异性网格生成就变成"在 $\Phi$ 映射下三角形最好是正三角形"。

    * 各向异性网格生成难、各向同性网格生成简单，于是设法用参数化或映射把前者转成后者。

* **两条现成的路**

    * 保角映射（conformal mapping）：依据共形映射理论里的一致化定理（uniformization）——任何一个曲面，给定一个黎曼度量，都可以做保角转化；各向异性网格做保角映射后在 2D 平面上就是各向同性网格。

    * 高维等距嵌入（high-dimensional isometric embedding）：依据嵌入定理——任何一个黎曼流形都能被等距地嵌入到某一个高维欧氏空间里，三维的可以嵌到八维、二维定义域可以嵌到三维。

    * 嵌入之后所有距离与形状计算都变成各向同性的，可以直接用欧氏距离做 remeshing。

    * 嵌入一般不白给，需要优化，优化里有两项能量：嵌入（embedding）能量——低维里由度量定义的距离要与高维嵌入中对应两点的距离尽量一样，这是"等距"的来历；光滑（smooth）能量——希望高维嵌入出来的空间比较光滑，便于后续 remeshing。

    * 流程是：2D 定义域加各向异性度量场，经变形/嵌入优化进入高维欧氏空间，在高维里做各向同性网格生成，再映射回 2D 得到各向异性网格。

## 四边形网格生成

* **度、奇异点与半规则网格**

    * 度（valence）：一个顶点周围连了多少条边；所有顶点度都是 4 的网格是最理想的规则（regular）网格。

    * 奇异点：度不是 4 的顶点。

    * 半规则（semi-regular）网格：大部分顶点度是 4，只有少部分非 4；把一个粗糙（coarse）的四边形网格做细分得到的就是这种网格。

    * 一般的目标就是生成半规则网格。

* **把参数化钉在整数格点上**

    * 做法：把奇异点用一条线连到边界、沿这条线切开，再把区域参数化到 2D 平面；参数化要让角点、边界都落在整数格点上。

    * 原因：平面上铺一个规则网格，每个格子天然是一个规整的四边形，再把这些四边形映射回原始网格就得到四边形网格。

    * 于是"在参数域里铺格子"与"映射回去"都变得非常简单，唯一的难点全部集中到参数化：怎么算出让角点与边都落在格点上的参数化。

* **割缝两侧的 90 度旋转**

    * 割缝在参数域里会变成两份 copy，上面一份、下面一份。

    * 两侧要成垂直 90 度的关系：映射回曲面时两侧边界本来是同一条线、要重合，一侧缺掉的空白要靠另一侧对应的格子补过来；转 90 度后两条边构成旋转关系，空白被对面的格子填上，拼起来才是一个完整的格子。

    * 参数化之后对应两段的长度也要对得上，否则那个地方填不满，最终的四边形化就会出洞。

    * 不一定是 90 度，也可能是 180 度，总而言之必须是 90 度的整数倍。

* **场到网格的流水线**

    * 先做一个场，再做参数化；参数化做完直接画等参线：一个方向的线一种颜色、另一个方向的线另一种颜色，它们就是格子线。

    * 这个参数化可以看成一个 texture map（纹理映射）：把 grid 当作纹理贴到网格上完全对得上，它本身还不是四边形网格，但格线对上后很容易生成四边形网格。

    * 跨过割缝线的颜色会变（红接蓝），因为两份 copy 按 90 度旋转约束拼合，两个方向的格子线正好互换。

* **同时要满足的一组约束**

    * 平移的量必须是整数：一侧格线标号是 1、另一侧是 4，就要平移 3，格点才能对上、线才能对齐。

    * 封闭网格上更常见：原始网格上的同一条线在参数域里拆成两条、可能隔得很远，没有奇异点把它们挨在一起，旋转完还得平移过去。

    * 这套流程已被研究约 15 年，有一两个方法鲁棒性非常好，大部分例子都能跑出来，但要让参数化同时满足这组约束仍然很难做。

| 约束 | 具体要求 |
| :--- | :--- |
| 无翻转 | 参数化过程中不能出现翻转 |
| 奇异点 | 要落在整数格点上 |
| 割缝 | 两侧满足 90 度整数倍的旋转，再加一个整数的平移 |

## 六面体网格与高阶网格

* **PolyCube 参数域**

    * PolyCube 是一个轴对齐的参数域，横平竖直，也可以看成 grid map——格子在上面已经打好了。

    * 可以把它想象成乐高玩具，或由立方体堆积而成的体素化定义域；参数域体素化后做六面体化相对容易：直接把体素堆上去，再映射回定义域，就得到比较好的六面体网格。

    * 核心问题只有一个：怎么把输入的网格（四面体网格或三角形网格）映射到 PolyCube 结构上。

* **到 PolyCube 映射的三个条件**

    * 算出来的边界法向要跟轴对齐。

    * 法向的方向只有六个：正负 $x$、正负 $y$、正负 $z$。

    * 映射的扭曲要比较低。

    * 这些条件凑在一起并不好做；该方向从 2008、2009 年左右起经过十几年研究，重要成果出得比较少、做的人不多，但确实有一些模型能做得比较好，不少 CAD 模型能跑出全六面体的结果。

* **高阶网格（high-order mesh）**

    * 元素不再是传统意义上的三角形、四面体：每条边不再是直的而是弯的，每个四面体变成一个多项式表示的四面体，内部接线也都是弯的线。

    * 元素由贝塞尔（Bézier）映射定义：每个四面体由一个额外的 Bézier map 给出，是一个多项式定义出来的形状。

    * 好处一：对边界的保真更好，弯曲的单元能把弯曲的真实边界表达得更贴。

    * 好处二：有限元里元素变成 Bézier map，上面的基函数变成高阶基，精度更高，计算量也更大。

    * 希望 Bézier map 在整个元素上都没有翻转；但它是连续变化的映射、定义在整个三角形或四面体上而不是常数，要保证整个元素上所有点都不翻转，判断条件跟线性情形不一样。

    * 生成方法最常见的是：先生成一个粗糙的线性网格，再把线性网格变形为高阶网格，变形过程就是计算映射或者几何优化。

## 分片线性映射的光滑性缺陷

* **基函数表示与帽函数**

    * 定义在三角网格上的映射写成基函数的线性组合 $f(x)=\sum_{j=1}^{n}y_j b_j(x)$，$y_j$ 是第 $j$ 个顶点映射后的目标坐标（真正要求的量），组合权重正是这些目标坐标。

    * 基函数取值规则：在第 $j$ 个顶点上取 1，在所有其他顶点上取 0；代入 $x=x_1$ 时右边只剩 $j=1$ 那一项，得到 $f(x_1)=y_1$，即插值性质。

    * 把第 $j$ 个顶点抬到高度 1、它周围一邻域的三角形跟着抬起，得到的连续函数就是帽函数（hat function），在每个三角形上都是线性的。

    * 一维版本是分片线性的帐篷函数：只在 $x_j$ 处取 1，向两边线性衰减到 0。

* **两处不光滑**

    * 基函数不光滑：峰的左右各是一段直线、斜率不同，峰顶处导数不存在；回到三角网格上，它在每个三角片上是线性函数，跨过一条边斜率就换了。

    * 雅可比不连续：三角形内部映射把三个顶点映到另外三个顶点，唯一确定为 $f(x)=Ax+b$，$A$ 就是雅可比，且在每一片内部是常量。

    * 相邻片之间 $A$ 不连续的原因：顶点是自由度，相邻面片的顶点位置可以任意取，没有任何机制约束两边的 $A$ 必须一样。

    * 视觉证据：把分片线性映射用纹理映射可视化，相邻三角形之间纹理小格子的大小与走向在一条边两侧差别很大——映射连续、导数不连续。

* **两条提高光滑度的路**

    * 加密网格：网格足够密时映射看起来没有明显不连续，但计算复杂度大幅飙升；做非线性优化要迭代解线性方程组，网格变大后每个方程组至少 $O(n\log n)$ 量级，代价非常高。

    * 直接构造光滑基函数，让映射本身就是光滑的。

| 方法 | 一句话定位 |
| :--- | :--- |
| 径向基函数（RBF） | 最简单的一类光滑基函数，只依赖到某个中心点的距离 |
| 广义重心坐标 | 三角形重心坐标推广到一般多边形 |
| 调和映射 | 由广义重心坐标引出，因为是调和的，数学上可以认为是最光滑的映射 |
| 基于样条的映射 | CAGD 里发展起来的分片多项式映射，每一片是多项式，比线性光滑得多 |

## 径向基函数

* **径向基函数（radial basis function，RBF）**

    * 基函数只依赖到某个参数点 $p_i$ 的距离：$b_i(x)=\varphi(\lVert x-p_i\rVert)$；以 $p_i$ 为中心的各个圆上取值都一样，所以叫径向基函数。

    * 映射仍是基函数的线性组合 $f(x)=\sum_i a_i b_i(x)$，$a_i$ 是系数。

    * 最早用于图像变形（image warping）：用户指定把图像里的一些点拖到新位置，旧图到新图就是一个二维映射 $f$；把它作用到每个像素得到新坐标，再把对应颜色值复制过去。

    * $\varphi$ 的候选形式：距离的倒数（$x=p_i$ 时距离为零会除零，一般加小量 $\varepsilon$ 写成 $1/(r+\varepsilon)$）、指数函数、距离平方的倒数；变形应用里一般取倒数或倒数的平方。

    * 偏爱递减形式的原因：控制点必须精确满足用户指定的目标，离开控制点后映射应越来越趋向恒等映射，即每个基函数的影响范围递减——$r=0$ 处最大，$r$ 越大越小。

    * 在几何与网格领域可用于网格变形、网格重建。

    * 主要问题：基函数虽然很光滑（距离的倒数可无限次求导），却张不成最简单的多项式函数，特别是线性函数——随便撒一批 $p_i$ 得到一组基函数，其线性组合永远生成不出线性函数。

## 三角形重心坐标

* **重心坐标（barycentric coordinates）**

    * 平面上任意点可以写成三个基点的线性组合；三个基点 $A$、$B$、$C$ 的坐标分别记为 $(1,0,0)$、$(0,1,0)$、$(0,0,1)$，类比欧式坐标里的单位向量。

    * 用三个数表示平面上的点比欧式坐标多一个自由度，存在冗余；加约束 $a+b+c=1$ 后表示唯一。

    * 质心性质：$v=\frac{aA+bB+cC}{a+b+c}$——把 $a,b,c$ 当作分配到三个基点上的质量，质量的质心正好是该点的欧式坐标；权重不归一化也行，分母除一下即可。

    * $(a,b,c)$ 不要求为正，所以这是三个顶点的一个仿射组合。

    * 唯一性由 Möbius 在 19 世纪证明：质心关系按 $x$、$y$ 分量分别成立，给出关于三个权重的两个方程，三个未知数只剩一个整体缩放自由度，再加上"和为一"就把它钉死。

* **面积公式与三条性质**

    * $w_i=\operatorname{Area}(v,\,v_{i+1},\,v_{i+2})$，下标关于 3 取模；归一化就是拿小三角形面积除以大三角形 $\operatorname{Area}(v_1,v_2,v_3)$。

    * "面积"取的是带符号面积，与定向有关：$v,v_{i+1},v_{i+2}$ 逆时针取正、顺时针取负，这样公式在三角形外也成立。

    * > **易错点**：重心坐标里的"面积"是带符号面积，定向决定正负——"面积永远非负"的直觉在这里不成立。

    * 归一性：三个坐标加起来等于一。

    * 重现性：以当前点的重心坐标为系数对 $v_1,v_2,v_3$ 做线性组合，得到的正是当前点。

    * 非负性：$v$ 在三角形内部时三个坐标都非负；点一旦跑到三角形外，非负性就不成立。

    * 用重心坐标在三角形上插值顶点值，得到的映射就是线性映射，也正是分片线性映射。

## 广义重心坐标

* **广义重心坐标（generalized barycentric coordinates）**

    * 质心性质必须保留：$v=\frac{\sum_i w_i v_i}{\sum_i w_i}$，$w_i$ 同样不要求归一化；拿来插值时把 $w_i$ 除以总和以获得归一性。

    * 由质心性质与归一化直接得到两条基本性质：归一性（所有坐标加起来等于一）与重现性（以坐标为权重对顶点做线性组合得到当前点）。

    * 关键性质：能重现线性函数——把某个线性函数在顶点上的值以重心坐标为权重做插值，插值函数还原成那个线性函数；插值只需要顶点处的值，但得到的函数在整个多边形内部都有定义。

    * 与 RBF 的对照：RBF 怎么组合都张不出线性函数，广义重心坐标天生就能重现它。

* **均值坐标（mean value coordinates，MVC）**

    * 最早的经典广义重心坐标，由 Floater 在 1997 年提出。

    * $w_i=\dfrac{\tan(\alpha_{i-1}/2)+\tan(\alpha_i/2)}{\lVert v-v_i\rVert}$：$v$ 连向 $v_i$ 的边两侧张出两个角 $\alpha_{i-1}$ 与 $\alpha_i$，取半角、求正切、相加，再除以 $v$ 与 $v_i$ 的距离。

    * 满足质心性质，并具有难得的非负性：对星型多边形，当点落在多边形的核（kernel）里——即该点能看到多边形所有顶点、$v$ 到每个 $v_i$ 的连线完全落在多边形内部——权重非负。

    * 很多其他广义重心坐标没有非负性；多边形若只是更一般的简单多边形（不一定是星型），连均值坐标也会失去非负性。

    * 用于参数化时更省事：它自带质心性质、$v$ 是顶点的归一化加权组合，正好满足 Tutte 参数化的要求；权重与几何相关，得到形状相关、对形状敏感的参数化。

    * 来源是中值插值：调和函数的中值性质里，插值的权重函数 $w$ 就是距离的倒数 $1/\lVert x-v\rVert$。

* **离散调和坐标（cotangent 权重，cot weights）**

    * 构造与均值坐标类似，也看 $v$ 与 $v_i$ 相关的两个三角形，但换一组角：取 $v_i$ 所在那条边对面的两个三角形内角 $\beta_i$ 与 $\gamma_{i-1}$，求余切相加，$w_i=\cot\beta_i+\cot\gamma_{i-1}$。

    * 与均值坐标并列为两种最经典的解析形式广义重心坐标；这类解析坐标常见的有九种，实际还有更多。

* **调和坐标（harmonic coordinates）**

    * 每个坐标分量 $\lambda_i$ 作为一个函数满足拉普拉斯方程 $\Delta\lambda_i=0$，边界条件是狄拉克函数：$\lambda_i(v_j)=1$ 当 $i=j$，否则为 0。

    * 二维拉普拉斯算子 $\Delta\lambda_i=\frac{\partial^2\lambda_i}{\partial x^2}+\frac{\partial^2\lambda_i}{\partial y^2}$。

    * 好处一：满足拉普拉斯方程，所以是 $C^\infty$，无穷阶连续可导。

    * 好处二：连续情形下有非负性——边界值是 0 和 1，解出来的坐标在多边形内部取值永远介于 0 与 1 之间。

    * 离散情况下拉普拉斯方程一般用有限元求解，取值可能变化：负得不多（数值比较小），但确实可能出现小于零的值。

    * 有三维版本：拉普拉斯换成关于 $x$、$y$、$z$ 的三个二阶偏导之和，可用三维调和坐标做三维形状变形。

* **局部与非局部**

    * 大多数基于计算的重心坐标是非局部的：调和坐标在内部所有点上都大于零，可能非常接近零但就是非零。

    * 局部重心坐标（2014 年提出）反过来要求基函数的影响有范围：当前点与某个边界顶点离得很远时，该顶点对应的坐标取值为零。

    * 其他基于计算的三类：最大熵坐标、移动最小二乘、局部重心坐标。

* **典型应用**

    * 插值：在多边形上给定函数值，通过广义重心坐标插值到整个平面；三维同理，可以插值到整个空间。

    * 网格（形状）动画：把几个网格所有顶点的坐标拿来做插值，得到中间的插值形状。

    * 渲染里的法向插值：顶点法向经重心坐标插值得到三角形内部任意一点的法向，法向场变光滑，低分辨率网格也能渲染出光滑曲面。

    * 图像 warping：把图像平面上的点用重心坐标表示，多边形变形后用原来的重心坐标对新顶点插值，得到每个点的新坐标；边界甚至可以是两个多边形。

    * 向量场：多边形上给定一些方向，插值到全平面，得到每点都定义了一个方向的场。

* **用广义重心坐标构造光滑映射**

    * 多边形内部任意点 $v$ 有重心坐标 $\lambda_i$，由质心性质 $\sum_i\lambda_i c_i=v$。

    * 把多边形编辑成顶点 $c_i'$ 的新多边形，直接沿用原来的 $\lambda_i$ 作权重：$f(v)=\sum_i\lambda_i c_i'$，对每个内部点都这么做就定义了一个映射。

    * 这个映射变形相当自然、没有分片映射那种纹理断裂——它是光滑的。

    * 光滑的原因：$\lambda_i$ 有解析表达式，是关于 $v$ 的欧式坐标的连续函数，不是分片线性或更低阶的形式。

    * 构造框架与前面一致：$f$ 仍是基函数的线性组合，只是基函数换成了广义重心坐标函数。

## 复重心坐标与调和映射

* **复重心坐标（柯西复重心坐标）**

    * 把参与线性组合的实数坐标 $b$ 换成复数 $c$：$c$ 是复平面上的数据对，被组合的对象也是复平面上的数据，线性组合变成复数的加权组合。

    * 用它同样可以构造光滑映射，效果与实重心坐标的变形一致，差别只是 $c_i$ 与 $b_i$ 的表达式不同。

    * 这样构造出的映射 $f$ 是全纯的（holomorphic）。

* **全纯映射（holomorphic map）**

    * > **定义**：对 $f$ 关于 $c$ 的共轭求导，若导数为零（$\partial f/\partial\bar c=0$），这个映射就叫全纯映射。

    * 全纯与保角基本等价，唯一差别是全纯映射可能有零点——$f$ 关于 $c$ 的导数可以在某些点取到零。

    * > **易错点**：全纯跟保角基本等价，但不完全是一回事——差别就在零点上。

    * 全纯映射就是调和映射，但反过来不一定成立；有了这块积木，可以通过组合得到所有的调和映射。

* **调和映射（harmonic map）**

    * 二维映射写成 $u$ 分量与 $v$ 分量，各是关于 $x$、$y$ 的函数；"调和"即两个分量分别满足拉普拉斯方程 $\Delta u=0$、$\Delta v=0$。

    * 给定边界条件后拉普拉斯方程有唯一解，可以从边界把内部所有点都推出来。

    * 数学上是最光滑的一类映射，无穷阶可导，可以求任意阶导数。

    * > **提示**：不是拉普拉斯算子本身无穷光滑，而是这类偏微分方程的解——调和函数、调和映射——无穷阶可导。

    * 极值原理：$u$、$v$ 的极大值与极小值都在边界上达到；内部点可能跑到边界像之外，但绝不能跑得太远。

    * 唯一性的用处：把要求放到边界上，在一定条件下内部就自动满足这些要求。

* **全纯加反全纯的分解**

    * 二维调和映射都能写成两个映射之和（简单相加，不是复合）：$f=\phi+\bar\psi$。

    * $\phi$ 与 $\psi$ 都是全纯映射，都可以由柯西复重心坐标得到；反全纯映射 $\bar\psi$ 就是 $\psi$ 关于 $x$ 轴做镜面翻转。

    * 构造方式：用复重心坐标得到一个全纯映射 $\phi$，再构造另一个全纯映射 $\psi$ 并取共轭得到 $\bar\psi$，两者相加就是调和映射。

    * 由此可以解析地构造出所有调和映射，完全不必去解拉普拉斯方程——后者的形式比较难优化。

    * 调和映射与一组二维系数一一对应：给定任意一组系数得到唯一一个调和映射，给定任意一个调和映射可唯一反解出系数。

    * 导数也有解析式：$\dfrac{\partial f}{\partial c}=\phi'(c)$，$\dfrac{\partial f}{\partial\bar c}=\overline{\psi'(c)}$。

## 样条基与张量积曲面

* **贝塞尔曲线（Bézier curve）**

    * $x(t)=\sum_{i=0}^{n}B_i^{n}(t)\,b_i$，其中 $B_i^{n}(t)=\binom{n}{i}t^{i}(1-t)^{n-i}$，$b_i$ 是控制顶点，连起来是控制多边形。

    * 曲线只插值控制多边形的两个端点，其他控制点只被靠近而不被插到。

    * 曲线在两个端点的导数就是控制多边形的第一条边与最后一条边，即在这两端相切。

    * 是多项式形式，顶点越多曲线次数越高；六七十年代在 CAD 领域（汽车、飞机、航空）用于曲线曲面设计。

* **伯恩斯坦基（Bernstein basis）的优缺点**

    * 缺点一：次数高时计算不稳定、复杂度高。

    * 缺点二：支撑不局部——每个基函数在整个区间上取值都非负，只在端点上（对某些基函数）取零，没有局部支撑区域。

    * 缺点三：不插值，只有两个端点插值。

    * 优点一：基函数是多项式，所以光滑。

    * 优点二：支撑是"伪局部"的——移动一个控制顶点，曲线上靠近该顶点处变化大，越远受影响越小。

    * 优点三：归一性，所有基函数加起来等于一。

    * 优点四：非负性（$t\in[0,1]$），所以曲线永远落在控制顶点的凸包内。

* **样条基的递归构造**

    * 一阶基函数在指定支撑区域（如 $[t_i,t_{i+1})$）取 1、其他区域取 0，是一个分片常值函数。

    * 递归：$N_i^{k}(t)=\dfrac{t-t_i}{t_{i+k-1}-t_i}N_i^{k-1}(t)+\dfrac{t_{i+k}-t}{t_{i+k}-t_{i+1}}N_{i+1}^{k-1}(t)$。

    * 权重函数很简单：第一个基函数在支撑区域内是从 0 到 1 线性递增，第二个是从 1 到 0 递减。

    * 两个分片常数这样组合就得到分片线性，递推一次多项式次数升高一次。

    * 实际使用时 B 样条的阶数不会取太高，四阶是最常见的。

| 阶数 | 分片多项式次数 | 节点处连续性 |
| :--- | :--- | :--- |
| 一阶 | 常值 | — |
| 二阶 | 一次（线性） | $C^0$（帽子函数） |
| 三阶 | 二次 | $C^1$ |
| 四阶 | 三次 | $C^2$ |

* **局部支撑（紧支撑）**

    * > **定义**：每个基函数都是一个分片多项式，在自己的支撑区域内是分片多项式并取非零值，支撑区域外直接为零。

    * 每个基函数长得都一样，都可以由另一个平移得到，各有自己的支撑区域。

    * 移动一个控制顶点（德布尔点，de Boor 点），曲线只有局部变化，右边那一部分完全不动——曲线编辑里一条关键性质。

* **张量积曲面**

    * 维度的差别在定义域参数个数：曲线一个参数 $t$，曲面两个参数 $u$、$v$，空间三个参数 $u$、$v$、$w$。

    * 张量积是排列组合：$u$ 方向一组基函数、$v$ 方向一组基函数，所有可能的组合都拿出来；四阶基函数有 4 个，张量积后得 $4\times4=16$ 个二维基函数。

    * $f(u,v)=\sum_i\sum_j B_i(u)B_j(v)P_{ij}$；求和顺序可交换，所以张量积曲面可以看成"曲线的曲线"。

    * 每一片的参数域是一个格子，每一片与正方形同胚、就是一个四边形，整个曲面是四边形网格的 layout；曲线基函数的非负性、归一性可以平凡推广到曲面。

    * 两片拼接要满足连续性条件：沿共享边界的方向（$v$ 方向）自然满足一阶连续，跨过边界的方向（$x$ 方向）不一定，需要把 $C^1$ 条件放进控制点的构造里——比如让某个控制点正好落在相邻两个控制点的中间。

* **全自由度曲面**

    * 每一片是一个贝塞尔三角形（de Casteljau 算法的三角形形式），也有一个控制多边形（三维就是三角网格）。

    * 参数域是任意拓扑的平面三角网格，每一片是一个三角片，比张量积的规整格子更自由，但构造稍微麻烦。

    * 构造方式：在三条边上分别做 de Casteljau（重复割角），最后缩成一个三角形时做插值，此时用重心坐标插值成一个点，即曲面上的一个点。

| | 张量积曲面 | 全自由度曲面 |
| :--- | :--- | :--- |
| 每一片 | 与正方形同胚的四边形 | 贝塞尔三角形（三角片） |
| 参数域 | 规整格子 | 任意拓扑的平面三角网格 |
| 特点 | 构造直接，曲线性质平凡推广 | 参数域拓扑更自由，构造稍麻烦 |

## 光滑映射的无翻转判正

* **SD 能量**

    * > **定义**：SD 能量是映射的扭曲能量；用它的原因是能量里内置了一个障碍函数——雅可比行列式的倒数，映射奇异时行列式为零、倒数变成无穷大。

    * 在三角网格上是每一片能量值做面积加权的和，权重就是这一片的面积。

    * 加面积权重的原因：能量本质是积分形式，每一点都有能量；分片线性映射的雅可比在三角形内部是常数，每片内部每点能量一模一样，所以每片的积分退化为"面积 × 任意一点的扭曲"。

    * 优化用内点法：每次沿能量梯度或其他二次下降方向走一条连续路径，保证能量下降；映射一旦奇异能量爆掉，所以连续优化中每一点都非奇异；初始无翻转则全程无翻转。

    * 分片线性下约束是有限的：三角片内每点雅可比相同，每片只需一个约束——行列式大于零。

* **推广到光滑映射的两个差别**

    * 两处差别把直接推广堵死：一是积分不能再退化成逐片求和，二是无翻转约束从有限个变成无穷多个，都不可能直接交给计算机求解。

    * 做法是在定义域上采样：积分变成有限和，采样点足够多就足够精确；无穷多约束也换成有限点上的非线性约束（雅可比大于零）。

    * 这样优化下来只能保证采样点上不翻转，采样点之外的映射结果没有保证，可能翻转。

| | 分片线性映射 | 光滑映射 |
| :--- | :--- | :--- |
| 能量 | 三角形内雅可比是常数，积分退化为"面积 × 单点扭曲"，逐片求和 | 任意两个点多近雅可比都不同，积分无法变成求和 |
| 无翻转约束 | 每片一个约束（行列式 > 0），有限个 | 定义要求每一点都不翻转，约束有无穷多个 |

* **Lipschitz 连续性判正**

    * 前提：映射本身光滑连续，雅可比函数也连续，进一步是 Lipschitz 连续的。

    * $L$ 是 Lipschitz 常数，刻画雅可比函数在球内的最大变化率（梯度模长的上界）；从 $p$ 走到球面，最大变化量只可能是 $L$ 乘半径 $r$。

    * 条件加强：把 $J(p)>0$ 加强为 $J(p)>L\cdot r$。

    * 球内任意 $q$：$J(q)\ge J(p)-L\lVert p-q\rVert\ge J(p)-Lr>0$，最坏情形在球面上也成立。

    * 当所有采样点都满足 $J>Lr$，且以它们为心、半径 $r$ 的球覆盖整个定义域（$r$ 足够大、采样点足够密）时，全域任意点的雅可比都大于零。

    * **结论**：利用光滑映射的连续性，把采样点上的约束从"雅可比大于零"加强为"大于某个正值 $L\cdot r$"，采样点之外的雅可比就都被兜住了。

* **凸组合与细分判正**

    * 依据伯恩斯坦基的凸包性质：$B_i^{n}$ 加起来等于一，且 $0<t<1$ 时非负，这组权重具有凸组合性质。

    * 把雅可比这个关于 $u$、$v$ 的多项式写成贝塞尔形式：$J(u,v)=\sum_i B_i(u,v)J_i$，$J_i$ 是采样点（控制点）上的雅可比。

    * 采样点上雅可比非负、权重又是凸组合，当前点的雅可比就是采样点雅可比的凸组合，同样非负——这是充分条件。

    * 若某些采样点上的 $J_i$ 小于零，条件不成立，此时无法判断该点雅可比是否真的大于零（它可能实际仍大于零）。

    * 补救手段是对曲线或曲面做细分：线性组合表示更加紧致，原来取负值的控制值细分后可能变成非负，判断随之更精确；判断失败就细分、再判断，越分越准。
