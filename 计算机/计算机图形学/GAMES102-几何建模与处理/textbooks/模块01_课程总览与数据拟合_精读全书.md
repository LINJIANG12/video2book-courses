### 图像与图形

#### 图像：离散的像素阵列

我们来看一个问题：图片是什么？照片是什么？实际上，照片就是我们的三维世界投影到我们——比如说眼睛的——视网膜上面的成像。视网膜上成的其实是倒像，但我们的大脑会把倒立的像解释成正立，这是大脑的解释。

相机是机械版的眼睛，道理一样：基于世界中的物体，成的是倒像；底片上有跟我们感光细胞一样的东西——感光元件。这些元件能接受通过透镜汇聚到这一点的光，呈现相应的颜色。于是自然界的场景，就通过透镜呈现在了相机的胶片或者底片上面。

关键在这里：感光元件是一个个有物理大小的元件，无论它做得多小，总是占有空间体积。所以我们的存储图像都是离散方式。你看起来这张图片是连续的一个区域，但事实上它是由好多好多小的感光元件组成的像素所组成的，每个像素有红、绿、蓝三个分量——这就是颜色的来源。

所以图像——或者叫数字图像——本质上在计算机里存储的时候，基本都是这种离散存储，这也叫光栅显示图像。我们的显示器、手机屏幕都是这种光栅化的；只不过像素小到很小的时候，人眼分辨不出来，我们就分不清它是离散的还是连续的空间了。

> **定义**：分辨率——图像 $n$ 行 $m$ 列的像素规模（$n\times m$），指的就是这张图像像素的多少。举例：1000×1000 的图像有 100 万个像素，属于百万像素级。

图像的表达非常简单，就是线性的：虽然存的是取整之后的值，取整也是线性——把矩阵拉直就成了一列。

#### 图形：有数学表达的几何对象

那「图形」又是什么？我自己理解的图像和图形的区别是这样的：图形的实质，就是**具有数学表达的几何对象**。一个点、一条线、一个线段、一个多边形、一条曲线，都叫图形；还有一个区域——带填充的等等。如果里面的填充颜色设置得很好，你甚至可以做出像那只老虎一样非常真实、非常漂亮的矢量图。

图形有的时候也叫**矢量**，在有些领域就叫矢量。比如说「图像的矢量化」，就是把它变成一片一片的区域，每个区域由数学表达的边界所表示。

#### 光栅化：从图形到像素

我们处理的图形——平面上的线、多边形、三角形等等——要显示在电脑上面，就一定要把它转化成像素所表达的，这一步就叫**光栅化**。大家在 101 的时候都学过：比如一条直线，怎么用像素去填充、来表达这条直线。像素很小的时候，你看不出里面有明显的锯齿；这个锯齿叫**走样**——闫老师在 101 里讲过走样的原理以及怎么消除，这里不展开。还有三角形：给它里面的一些点，判断哪些点填充、哪些点不填充，这也是光栅化里很重要的一块；再往外就是一般的多边形。

事实上，我们电脑中存储的文字、字母等等，都是矢量。所以文字放大以后都非常清晰。为什么？把它放大以后，我们重新计算、填充里面的像素——里面的像素不是存储起来的，是**实时算出来的**。我们存储的只是这些多边形的顶点：放大时顶点重新算一遍，里面的填充区域重新变化，又重新做一遍光栅化。所以无论怎么放大，它的边界看起来都非常光滑。这就是矢量。

```text
          光栅化：判断哪些像素被填充
  图形 ─────────────────────────────▶ 图像
  点、线、多边形的坐标             n × m 个像素的点阵
  （连续，有数学表达）             （离散，RGB 三分量）

  放大图形：重算顶点坐标 → 重新光栅化 → 边界始终光滑
  放大图像：不做插值 / 上采样 → 模糊
```

读图：图形与图像之间隔着一道「光栅化」；两者放大之后的行为完全不同——这正是矢量文字怎么放大都不糊的原因。

| 对比 | 图像（光栅图像） | 图形（矢量） |
| :--- | :--- | :--- |
| 存的是什么 | 一个个像素组成的离散点阵，每个像素有红绿蓝三个分量 | 点、线、多边形等几何对象的坐标与数学表达 |
| 放大之后 | 不做特殊的插值、外推或上采样，图像看起来就很模糊 | 坐标重新计算、填充区域重新光栅化，始终保持高分辨率的效果 |
| 本质 | 离散 | 连续、有数学表达 |

所以矢量图形有的时候也被叫做「无穷分辨率的图像」——这是一种叫法。但我更偏向于叫它图形：图像是离散的，图形是连续的、有数学表达的。

### 渲染：光的计算科学

照片可以把影像存储起来；但如果人类要去**创造**这样的影像，怎么办？人类很早以前就知道用不同的彩笔去绘画，画出我们想象的世界：小孩子画卡通型的；大师画非常表意性质的；还有一种艺术家，能画出跟照片一样的写实型的画——他们对自然界的光照理解非常好。比如三幅写实作品：一个水果、一只豹子、一张人脸——你如果不说它是画出来的，大家都会认为是照片。这种才华需要很多年的训练：就说那张人脸，光源在哪里、哪里是阴影、头发在里面怎么交互，主要是靠自己的脑袋去想象的，甚至没有一个参照物，就能把这么真实的东西画出来。但这肯定不是常规的做法——我要画一组动画，这样画根本不可行。所以我们能不能通过**计算**的方法，创造出这种照片一样的东西？这是很多年前大家就在追求的。

要做这个事情，就要去理解成像的原理。镜头成像有几个主要元素：成像平面，还有外界的物体。如果没有光源，你什么都成不了像——一片黑暗。加了一个光源以后，物体上的这一点通过透镜达到成像平面上那一点，就能把它呈现起来。所以，一个物体的颜色能不能被看到、能不能被感光元件感受到，一定要有光源的存在：光源与它发生作用，它的材质反射出来的光线汇聚到那一点，才能形成这一点的像素颜色。这就是图形学做渲染的基本物理原理。

学过 101 的同学都清楚：**渲染就是光的计算科学**。比如一个局部光源，照到这里，眼睛在这：反射出来的光线就跟夹角相关——夹角越大，看到的光就越弱，因为它是按一定的分布散开的，就是那个 $\cos\theta$ 的关系。要更真实一点：光源不仅在这一点反射到人眼，还有多次弹射、折射，甚至其他一些光学现象——这就是我们的光照方程，这是渲染的核心，就是要解这个方程。左边这个其实是右边那个方程的简化版本：它里面假设 BRDF 是一个常值，各个方向都一样。真正要绘得很好——像实际场景那样，给定一个模型，通过光源的渲染计算，就能呈现出非常逼真的效果——里面是大量的计算。

但要做这个事情，少不了原材料：

- **场景模型**：这就是我们的几何，也是这个课要重点讲的；
- **光源设置**：怎么打这个光，能让画面看起来比较和谐；
- **纹理**：模型上面的纹理怎么样；
- **材质（BRDF）**：光源与模型发生作用以后，反射出来光的强度都跟材质相关，所以材质的设置非常非常重要。材质设置不好，再怎么样的算法，绘制出来都不好看——就像艺术家给它们涂色一样：木头的材质跟沙发布的材质，就是不一样。

事实上在很多领域、特别是游戏的场景创建里，都有一批人叫做美工（美术），还有技术美术（TA），在里面做创建。场景这些素材——几何好、纹理漂亮、材质说得对——才能形成一个真实场景。所以做渲染的人都关注怎么写这个方程，但前面这些要素没有，你怎么画都画不好。这里面难度还是非常大的，后面会再展开。

```text
几何模型 + 光源设置 + 纹理 + 材质（BRDF）
              │
              ▼
      渲染：求解光照方程
（BRDF 取常值即是它的简化版本）
              │
              ▼
          逼真的图像
```

读图：渲染的输入是四类素材，缺一样都画不好；渲染本身是求解方程的计算过程。

假设材质都设好了，再通过强大的算力，就可以绘制出非常逼真的图像：《狮子王》里那些渲染出来的动物；《阿丽塔》这个电影，里面用了大量的几何去表达、材质去表达，物体绘制得非常逼真。

### 仿真：解方程的运动计算

一个物体——世界里的静态物体，还有动态物体，特别是流体、软体——怎么去表现这个运动物体呢？这就是运动的科学，里面做的是运动的计算。说到底，这里面就是在解各种各样的方程：刚才渲染是在解积分方程，仿真是在解偏微分方程（PDE）。所以 PDE 的数值解法就很重要。

流体那块，胡渊鸣的 201 课程也讲了：解 Navier-Stokes 方程（N-S 方程），就是流体的方程。它有不同的解法：从欧拉的观点、拉格朗日的观点，解法是不一样的；当然也可以结合——就是最近流行的 MPM 方法。对于窗帘、布料这类东西，可以用弹簧质点系统去解；当然还有有限元（FEM）等等，也可以给不同的物体做仿真运动计算。还有刚体运动，就是牛顿第二定律；还有一些其他的量的变化，这里不展开。总之你要做仿真，就是在解各种各样的运动与力学方程、流体方程、波动方程等等。

在电影里，像《冰雪奇缘》的雪的变化、《海洋奇缘》的水的变化，都做得越来越逼真——这靠的是非常强大的算力，能够生成这么大一部的电影：通过物理仿真，再通过渲染，就能生成这么多三维的虚拟电影。国内近几年也发展起来了：《流浪地球》是去年的大片，还有《白蛇缘起》、《哪吒之魔童降世》，大家应该都看过，里面都是纯三维的东西。每个人物、每个故事都不一样，你可以按照你的想象去创造里面的世界——实际上，导演在里面就是创造了一个真实的平行世界。

### 虚拟世界的畅想

有部电影大家如果看过应该都非常熟：任何一个人戴上头盔、启动程序，马上就到了另外一个世界。当然它是一个畅想——人身上还要绑好多触觉传感器、运动传感器。进去以后看到的世界是另外一个，里面的触觉感觉也有讲究：如果那个世界的物理规律跟地球一样，你就没有异样感；如果跟地球不一样，是月球那样的吸引力，你就会觉得比较轻——不过这是另外一个事情。

进去以后，那个世界有一套规则——那个世界叫「绿洲」，绿洲背后有个 boss 定义了这个世界的运营方式。你可以在里面跟其他的虚拟人——每个虚拟人对应一个真实的人——进行社交活动：可以接触、可以谈话、可以赛车。主角进去以后就可以在里面赛车，赛车里的车有真实的力反馈，有速度、有力的作用，跟在现实世界里的感觉一样。当然你还可以在大街上跟一批人汇聚——影片最后那个片段，就是大家一起去打坏人的场景。

这个电影如果没看过，值得去看一看。它展示了我们 VR——虚拟现实——的未来：如果哪一天各个支撑技术都能到位，触觉、力学这些都到位，那么我们每个人都有能力去创造自己的虚拟世界。

### 数据从哪来：建模是瓶颈

刚才讲完了这个世界我们可以用各种技术去创作，但有一个问题大家有没有想过：**数据从哪来**？有一张图把做数据的过程画得很清楚：你要造一个这样的模型，要去建模；要去把它做 UV 展开——UV 展开后面我们会讲，叫参数化；UV 展开以后，要去生成法线贴图、偏移（位移）贴图，还有一些材质贴图等等。要做这么多东西，才有可能创作出这么逼真的渲染效果。

如果你只是做渲染或者仿真，你可能觉得数据是已知的、不用你去创造，已经有——当然没问题。但是这个数据来源是非常非常困难的。201 可以说：哎，我们用美术，靠美术去堆、去画、去调——美术就会疯掉。所以我们这个课的目的，就是来讲这些数据怎么构建，怎么让自己有这个能力——无论是通过工具也好，还是通过程序也好——来做这个事情。

我们来看一张摆了很多模型的图。左上角这个模型大家一看就能感觉到：一些方块、一些球、柱、锥等等——比较简单的几何，一看马上就能想出它的数学表达。但左下角，工业界要造一辆汽车、造飞机，它的曲面要非常非常光滑，光用一些点是表达不了的，需要有连续的数学表达——这个就是后面我们会讲的样条。还有一些动画里面，我们可能不需要这么光滑，但里面有很多细节，可以通过一些规则去细分，再加上雕刻去建模——这就是细分与雕刻，ZBrush 这类软件的应用。当然你要做得更加逼真，还有 translucent（半透明材质）、毛发，还有金属表面的脏污、锈迹等等。要去刻画这些东西，建模就要更加精准：材质怎么获取、毛发怎么表达、铁锈怎么表达——涉及的建模手段和表达方式还有很多。

> **结论**：到现在为止，渲染可以很真实了，仿真也可以骗过眼睛了，但是建模——我们把它叫做**几何内容的生成**——仍然是图形学的一个瓶颈之一。

我们这个课讲最左边的几个建模手段，下面的十几周我会给大家做一些介绍，希望大家能够有所了解；右边这些高级建模，未来有机会我们再来详细讲。

### 数学是一种语言

现在开始讲我们的内容。今天第一个内容是**函数拟合**——我们先讲这种「连续精准建模」。可能很多游戏界、工业界的朋友，更多接触的是离散建模；我想先把建模这一块让大家有个概念、有个基础，后面讲离散就容易接触了。

我也看到很多同学注册时留言：数学方面能不能考虑他们的基础。所以我会尽量把数学概念讲清楚，从一点点数学开始讲——一点都不讲，是没法表达后面那些概念的。数学大家千万不要怕：不是说科班出身的同学数学才好，不是这样。**数学实际上是一种语言**：我要表达一个量，我就用 $x$、$y$、$z$、$a$、$b$、$c$——它就是一个符号，符号表达一个规律，这就是数学表达；还有各种更复杂的方程等等。

数学的历史今天不能展开，但可以提一下：数学来源于生活——从古代的结绳计数到丈量土地，就有了数和形的概念；后面欧几里得又把几何的东西抽象出来，形成了五条公理的几何理论框架。聪明的人善于把观察到的各种规律变成公理，然后用公理无限地推演——这就是数学的发展过程。

数学真的非常有用，特别是做科研来讲：没有好的数学思维，做不深。所以我这个课也希望给大家建立一些数学思维和数学建模能力。当然这可能达不到我在科大给本科生上课的那个难度，我会尽量讲得通俗，大家尽量跟一下。

数学的产生刚才基本提了：来源于实际目的——结绳计数、土地丈量；后面有些出名的人，就把它变成了一个逻辑游戏。平面几何就是从里面抽出了五到七条公理——欧几里得这个家伙把它写成了《几何原本》：只要这几条公理大家认同，你就可以无限地演绎、繁衍、推理，产生各种各样的性质。如果公理有一条是不对的，或者把它变一下，就变成了另外一门学科：比如平面几何，把「两条平行线不相交」改成「相交于一点」，那就变成了另外一门几何。所以数学就变成一个这么纯粹的理论学科：纯数学不考虑它的应用，只把它当成一个逻辑体系——你也可以把它看成逻辑上的游戏。像我本人虽然数学出身，但也不是纯数学研究工作者，我更希望把数学用到我们的工程问题上。纯数学有很多定理、新命题、猜想，非常深刻，但不一定有实际用处——当然，可能若干年后会发生用处。

应用这一侧，要善于把实际问题转换成一个数学模型。这个模型是什么？用一些符号表达问题的一些变量，然后是用优化模型，还是方程模型，还是统计模型等等。模型有了，你才能对这个问题进行刻画；后面才是真正把模型去求解——有可能是优化，有可能是解方程，有可能是解一个概率问题或者统计问题。最后，代码是实现你算法的东西。

```text
实际问题 ──▶ 数学模型 ──▶ 模型求解 ──▶ 代码实现
        用符号表达变量    优化 / 解方程 /
        选模型：优化？    解概率统计问题
        方程？统计？
```

读图：代码在链条的最末端——它实现算法、验证想法，但真正的主干是从实际问题到数学模型的建模。

代码实际上在整个研究里面是最不重要的——但是没有它，你有想法也无法验证，没用。所以代码是必须的，但更重要的是这个过程：**从问题到模型，怎么去建模**。后面课程中碰到一些东西，我会引导大家来做这方面的练习。

数学还有一个东西：要善于**抽象**——数学符号本身就是从事件中抽象出来的。幼儿园做加法，不能太抽象，老师一定问：两个苹果加三个苹果等于几个苹果——苹果很具体。小学呢，苹果可以扔掉了：$2+3$。到中学：$2x+3x=5x$，$x$ 可以是苹果，也可以是人，也可以是一个虚拟的东西；再往上，它有函数的性质了，怎么就成了微分方程了……东西越来越抽象、越来越高深。

### 集合与线性空间

要开始讲拟合了，前面这些铺垫，我给大家回忆一下。数学科班的同学都会学到这些，可能非数学专业的不一定学，但这些都是基本概念，大家不用担心。

#### 集合：讨论问题的边界

首先是**集合**：一些具有同样性质的对象。比如我有一些数字构成集合 $A$，当然可以。集合可能有无穷多个元素，比如自然数集、有理数集等等。我们讨论一些东西的时候，都会限制在特定的集合上讨论：比如讨论人的性质，会局限在「人」这个群体里讨论；讨论向量的性质，会限定在 $n$ 维向量里讨论，不会把不同维的向量放在一块。所以集合，就是具有同样性质的一些对象聚成的一堆。

集合有可数与不可数之分：有限集就是个数说得清的；无限集才分可数与不可数。可数的意思是：它能跟自然数一一对应。比较「个数」的大小，只要能跟 $\mathbb{N}$ 一一对应起来，它们的个数就是一样的。比如整数跟自然数就是一样「大」的，都属于可数集——虽然看起来自然数集好像是整数集的一个子集。因为它们两个可以建立一一对应：我把自然数 1 对应整数 $1$，自然数 2 对应整数 $-1$，就像这样交错下去就对应起来了——无穷之后的部分我们不用管它。还有一种不可数集，比如实数。另外集合还有一些运算——并、交、差——大家稍微看一下就行。

> **易错点**：整数集「包含」自然数集，直觉上整数「更多」，但无穷集合比大小不靠包含关系，靠能否一一对应——能对应就一样多。整数与自然数都能跟 $\mathbb{N}$ 一一对应，所以同为可数集；实数集则不可数。

#### 线性结构：把无穷多个元素变成 n 个实数

集合里的元素之间如果没有任何运算，这个集合就比较难构建一些关系：$A$ 里的元素跟 $B$ 里的元素之间到底是什么关系，不知道。所以要引入元素之间的运算：两个元素相加还在这个集合里面，元素放大多少倍还在这个集合里面，那这个集合就具有非常好的性质，叫**线性结构**。它要满足这些律：交换律 $a+b=b+a$、结合律等等——这就是大一微积分就学过的线性空间。

具有这种性质的集合有非常好的结构。什么意思？里面的每个元素不用一个个去列举了——所有元素都能写成

$$v=\alpha_1 v_1+\alpha_2 v_2+\cdots+\alpha_n v_n$$

这样的形式，$v_i$ 就是里面的若干个**基**（basis）；线性无关的基向量的个数叫做**维数**。这样的话，这个空间实际上很简单：它所有元素都表达成一些 $v_i$ 的组合，$\alpha_i$ 是实数，就是它的系数——每个元素对应一个 $n$ 维向量，只要 $n$ 个实数就表达了其中的一个元素。而这个 $n$ 维（向量空间）又同构于 $n$ 维的欧氏空间。所以我们看到的一维实数、二维平面、三维空间——这叫欧氏空间——还有更高维的空间，都是这样的结构。

有了这个结构，我们讨论这么无穷多的东西，就把它变成有限的、$n$ 个实数的性质了。这是一个特别重要的概念——为什么我们要学线性空间、学线性代数，就是这个原因。

### 映射与函数

#### 映射：对应关系的规矩

**映射**：有两个集合 $A$ 和 $B$，如果 $A$ 中任何一个元素，在 $B$ 中都有一个像跟它对应，那这个就叫映射，$f$ 就叫做映射法则。如果一个 $a$ 对应两个像（$b_1$、$b_2$），那就不是映射——只能一个 $a$ 对一个 $b$。那能不能多个 $a$ 对一个 $b$ 呢？可以。有没有映射不满的（有的 $b$ 没被映到）？也可以。

| 类型 | 条件 | 直观说法 |
| :--- | :--- | :--- |
| 单射 | 每个像都不一样 | 不同的原像映到不同的像 |
| 满射 | 映满了 | $B$ 中每个元素都被映到 |
| 双射 | 既单又满 | 一一对应，也叫一一映射 |

这里还有几个概念：一个叫**定义域**，一个叫**值域**——$A$ 就是定义域，$f$ 在上面起作用；$B$ 就是值域。$A$ 里的元素叫**原像**，$B$ 里对应的叫**像**。

#### 函数：实数到实数的映射

当两个集合 $A$ 和 $B$ 都是实数的时候，这就是我们初中就接触过的**函数**：$x$ 在这、$y$ 在这，$y=f(x)$ 就表达了一个实数映到另外一个实数，这就是函数的概念，也叫**变换**。映射、函数、变换，在不同的上下文里可以混着用；但「函数」在这里特定指实数 $\mathbb{R}$ 到实数的一个变换。

#### 函数的图像：人为升维的可视化

那函数怎么可视化呢？这是挺麻烦的事情。为什么？$x$ 是一根实轴，$y$ 也是一根实轴，这边的点运到那边去、那边的点运到这边来，来来回回的，就不好画了。人们就定义：对这样的一元函数，把它人为地升维成二维——把 $x$ 放这里，把 $y=f(x)$ 放到那里，这样平面上就有了一个点 $(x, f(x))$。$x$ 走完整个定义域以后，它所形成的像就变成一条曲线——这叫**函数的图像**。大家先记住这一点：我们对函数的可视化，是人为地把它升维成了两维；这实际上就是我们初中就会画的东西，叫函数的图像，而不是函数「本身」的可视化。对高维的函数，我们就不这么做了——下周会讲。

### 函数空间：把「找函数」变成「找系数」

哪些函数是我们要研究的？我们初中就学会了很多函数：幂函数、三角函数等等，学过它们的很多性质。你要去研究函数，也需要有一个特定的范围——这个就是**函数集合**。函数跟向量一样：如果你现在有一些基函数 $f_i(x)$，只要让它们构成一个线性空间，就能够表达由这些函数线性组合构成的类——也叫**函数类**（不叫函数组；不同学科里叫法稍微有点区别），意思就是一个函数的集合。

我要研究问题，一定得先定义我在哪个集合里面去找我要的东西。如果你不给我定义，说「你去找个函数」——世界上函数千千万、无穷多，我怎么找？所以我希望在某一类里面去找。这样，就把「求函数」变成了跟刚才一样的「找 $n$ 个系数」的事情：求函数，就是在这个线性空间里，把这 $n$ 个系数定出来就可以了。比如你现在在多项式空间，就去找这 $n$ 个组合系数；在三角函数空间，就去找 $\cos$、$\sin$ 的组合系数。

所以我们研究问题，一定得先限制我们在哪研究，最好是这个空间有结构——这样我就把要找的东西变成了一个量：这个量虽然是一个 $n$ 维向量，但它毕竟是 $n$ 个实数可以表达的。当然，选函数空间也不是随便选的：随便选的话，函数表达能力不够。比如我只选三次函数——三次多项式就只有一个拐点，再复杂一点的形状它就表达不了了。怎么选一个既有好结构、表达能力又够用的函数空间，正是函数拟合里要仔细斟酌的头一个问题。

## 从函数空间到最小二乘：数据拟合的完整方法论
> 对应块：BLK02 | 覆盖分集：P01下 | 块标题（分集名）：《课程介绍》

三次函数就只有一个拐点，变不出多少别的形状——函数的表达能力就不够。所以基函数 $g$ 也要足够丰富，要能靠近我想要的东西：假如我要的那个函数很复杂，你仅仅拿三次函数这一个"类"去拟合，肯定拟合不好。

所以选函数空间的时候，有一条硬要求：**这个空间里面必须存在一个函数，能够很好地逼近我要的那个真实规律**。那个真实的函数长什么样？我不知道——正因为不知道，才更要求"能逼近"。这就要进到泛函分析里，去研究函数空间的一些性质了。

### 函数空间要装得下你要逼近的函数

"逼近"这个词要落到实处，就得先能度量"近不近"。所以首先要定义：什么叫一个函数逼近另一个函数——中间要引出**度量**。这里就引出函数的内积：内积可以诱导范数，范数就可以诱导距离。有了两个函数之间的距离，你就可以去度量这个函数跟那个函数像不像、哪个才是最好的逼近，等等这些性质。

还有一个性质叫**完备性**。什么叫完备性？就是说这个函数空间，$n$ 取大一点，表达能力就强——比如当 $n$ 趋向于正无穷的时候，空间里就什么都有了。这就是大名鼎鼎的**万能逼近定理**，也叫 Weierstrass 定理，大一数学分析里就非常有名的一个定理：一个区间上的连续函数，无论什么函数——你告诉我也好、不告诉我也罢——都可以用多项式来逼近它。只不过后面写的是一个级数：级数的项数可能很多；如果项数给定，那就是在这个大小固定的空间里，找一个最逼近的。

> **定义**：完备性保证"你要找的函数，在这个空间里找得到"。所以选函数空间时必须考虑完备性——因为我要保证能找到我要的函数。

同样的道理，凡是周期函数，都可以用三角函数去逼近。所以基函数选什么、空间够不够用，是动手之前就要想清楚的第一件事。

这里冒出来的"赋范空间"这类名词，是纯数学概念，大家不用太着急，我们先不管它，接着往下看。

### 一个 sin x，撑起一个函数空间

傅里叶级数是所有工科同学都学过的：**任何一个周期函数，都可以写成 cos 和 sin 的组合**——函数无论多复杂，只要是周期函数就行。傅里叶级数有两种等价的写法，可以互相推出，说的都是同一件事：一个（可能很复杂的）周期函数 $f(x)$，能被一组 sin、cos 表达出来。

把这件事再抽象一步。级数里的每一项，变量是 $t$，前面乘一个因子，再加一个平移——基本单元可以写成

$$g(t)=\sin(\alpha t+\beta)$$

$\alpha$、$\beta$ 一变，sin 就衍生出一整个家族。用这一个函数的各种变换，我也可以张成一个空间，而这个空间就可以逼近任何一个（周期）函数。

$\alpha$ 和 $\beta$ 各管一件事。$\alpha$ 是**伸缩**——沿 $x$ 方向把函数挤一挤、拉一拉：$\alpha$ 小，曲线就比较宽；$\alpha$ 大就比较窄，比如 $\alpha$ 取 2，波形就明显挤窄了。$\beta$ 是**平移**——让 $\sin x$ 往左往右挪。

这里有一个很奇怪也很有意思的现象：我用一个函数 $\sin x$，靠它自身的伸缩（挤一点、拉一点）加左右平移，就能够很有效地表达一个非常复杂的函数——这个函数可以任意复杂，当然这里局限在周期函数。这里我先卖一个关子：后面会有一个东西，跟它非常非常类似。

还可以再进一步：通过**复合**，把一个任务拆成一串函数接力。复合的意思是，$f_k$ 里面装的是 $f_{k-1}$，一层套一层，不断把上一级的计算结果喂给下一级，最后一路套到 $f_1(f_0(x))$：

```text
x ──f0──▶ f0(x) ──f1──▶ f1(f0(x)) ──▶ …… ──fk──▶ fk(fk-1( … f1(f0(x)) … ))
```

读图：每一级只做一件简单的事，把上一级的输出当作自己的输入；链条拉长，通过复合就能构造出任意复杂的函数——表达能力更强，但代价是要做很多个基础函数的复合。

### 找函数的三部曲

那么下面一个问题就是：怎么去求满足我要求的这个函数？在后面的建模过程中，我会讲一些案例——很多实际问题，最后都是在找一个函数：PDE（偏微分方程）求解，求的也是一个函数，只不过这个函数用 PDE 来表达；优化问题呢，也只是对这个函数的某些性质做度量——差别只在变量不一样、维度不一样。

怎么找？都有这么三部曲——这是我个人归纳的，大家记住：

1. **在哪找**：你是在哪个函数空间里找——就是刚才讲的那个空间；
2. **找哪个**：哪个是最好的？相对于你要的东西，你希望它满足什么性质——这就是定义"好坏"；这个度量好坏的东西，也可以把它叫做 loss function，**损失函数**；
3. **怎么找**：空间定好了、好坏也定好了，剩下就是求解，或者叫**优化**——当然，优化方法越快越好。

| 三部曲 | 回答的问题 | 深度学习里对应的说法 |
| :------- | :----------------------- | :----------------- |
| 在哪找 | 在哪个函数空间里找     | 模型             |
| 找哪个 | 哪个叫好，怎么度量好坏 | 策略（损失函数） |
| 怎么找 | 怎么把它解出来         | 算法（优化）     |

深度学习常说的模型、策略、算法，跟这三步是一回事；神经网络本质上也就是这三步——它是用网络来表达一个函数集合（函数空间）。今天的课基本上都是在讲函数：你要去找这个函数——在哪找，好坏怎么度量，最后怎么求解它。

### 从逆向工程说起：只有采样点，没有方程

我们回到几十年前。假设拿到一张船型的设计图——注意，只有图纸，没有方程。但造船的话，一定要有它的方程、一定要有它的函数。怎么办？

在没有很多数字化技术的情况下，早年的做法是：把别人的产品拿来，琢磨怎么去**反求**它的方程、反求它的函数。方程我不知道，但点我可以描——在上面多描点。描完这些点之后，怎么用函数把它拟合出来，也就是用函数去逼近它——我就认为，我的函数就代表了这些采样点反映的规律。制造里面我们需要的是光滑函数；后期我们可能会直接讲离散的处理，但前面这部分，还是假定我们一定要有一个（光滑的）表达，才能做后面的应用。

很多年前，逆向工程是中国一个非常大的应用：很多零件——包括一些拿不到设计资料的——我们都没有它的函数方程，但要制造，就一定要把它们输到电脑里面去，用这些方程、函数。办法就是在表面上描点，用三维扫描仪扫出一堆离散点；这些点只是外表面的一些测量点。那怎么造出它的模型？就要去求出一个光滑函数——就这个问题。三部曲的三个问题全在这里面了，下面一个一个来回答。

### 在哪找：选基函数，搭函数空间

先把问题摆清楚——数据拟合：给定了平面上的若干个点 $x_0,\ x_i,\ \dots,\ x_n$，这些点你可以看成从船型上采来的，也可以是从机器零件上采来的。我们要找一个函数 $y=f(x)$ 去反映这些规律：规律可能是一条直线，船的外表面轮廓可能是这样，机械零件可能是那样。这就是拟合问题——拟合也叫回归。我们这里先限制在一维，因为函数是最简单的；高维的问题，下节课我再给大家解释。

第一步，在哪找：你是想用多项式去拟合这条船型线呢，还是想用其他的函数、三角函数去拟合？如果你发现数据是有规律的、可能有周期的，那三角函数可能就比较合适。选定一组基本函数——叫 $g$ 函数，也就是**基函数**，可能是幂函数，也可能是其他函数——那么 $f(x)$ 就表达成这些基函数的带系数组合：

$$f(x)=\sum_{i=0}^{n}a_i\,g_i(x)$$

只要把这些系数求解出来，这个函数就找到了。

### 找哪个：插值与逼近

空间假定选定了——就用幂函数的组合，在 n 次多项式这个空间里找一个去逼近数据。第二个问题：度量"哪个叫好"。

**先说插值。** 假设我要求很严格：这些点都是很精确的，我需要你这个函数一定要经过我这些点——这个问题就叫**插值**：函数得经过所有点，误差是零，因为这个函数满足所有这些点的关系。把每个点代到基函数组合里面，就形成了一个关于系数 $\alpha=(a_0,\dots,a_n)$ 的线性方程组

$$A\alpha=b$$

这就是大一学过的**拉格朗日插值**：有 $n+1$ 个点，用次数不超过 $n$ 的多项式去插值，插值多项式**存在且唯一**。道理也直白：自由度是零——未知数个数等于方程个数，$n+1$ 个未知数配 $n+1$ 个方程，一定有解，解还可以写成拉格朗日插值函数的形式。

但这里面有个问题：有些问题是**病态**的——矩阵 $A$ 的条件数过高，求解非常不稳定，数值上就有误差。什么叫条件数？大致可以理解为矩阵 $A$ 最大与最小奇异值之比：这个比例比较大，意思是矩阵在某个方向上特别特别"窄"，这时候就容易病态。这是数值解法里的问题，我这里不展开，以后有机会再解释。

**再说逼近。** 还有另外一个目标：我不需要插值，我要**靠近**。这些点虽然是从实物上采来的，但可能有设备的误差、存储的误差，数据并不一定精确，只是大致对。数据只是大致对，你还要求曲线一定插值过每个点，就不很合理了。允许它有一定误差怎么办？我说，曲线只要靠近它就行：两个值不要求严格相等，但希望误差尽量小——希望它们之差在某个度量下（比如取平方再全部加起来）是最小的：

$$\min_{a_0,\dots,a_n}\ \sum_{i}\big(f(x_i)-y_i\big)^2$$

变量仍然是那些系数——求 $n+1$ 个系数，使得误差平方和最小的那个函数在哪里，这就叫**逼近问题**。

当然你会问：能不能不用平方，用绝对值？可以，这也是一种误差——它度量的是点到曲线的这样一个距离。那我用更好的距离呢？比如点到曲线的垂直距离，平方和最小，行不行？也可以，没问题。这些都是你的目标、你的度量，度量这个函数的好坏。但为什么我们不采用绝对值、不采用点到曲线的垂距，偏爱平方？因为"怎么找"这一步：**平方好优化**。求最小值，只要对这个目标函数关于这些系数求导、找驻点；平方一求导就变成线性了，让求解非常快。绝对值、垂距这类度量就不好优化——等于你自己设了一个坎、挖了一个坑，让自己为难。当然，某些特定应用里平方就是不行、一定要用绝对值，那没法子，只能硬着头皮去解这个不光滑的问题。这种平方度量，我们有时把它叫做平方范数，也就是二范数。

> **易错点**：度量不是随便挑的——它决定第三步好不好解。"好"的目标函数，是求导之后能让问题变线性的目标。

|  | 插值 | 逼近 |
| :--------- | :------------------------- | :----------------------------- |
| 数据前提 | 点精确可信             | 点可能有测量、存储误差   |
| 误差要求 | 必须为零，过所有点     | 允许误差，越小越好       |
| 求解方式 | 解线性方程组（拉格朗日） | 最小化误差平方和（最小二乘） |
| 需要提防 | 方程组病态             | 欠拟合、过拟合           |

### 怎么找：最小二乘法

插值和逼近两个目标都讲完了，数据模型出来了，最后一句就是：对每个点，它的误差和达到极小，怎么去求？要求一个函数的极小值——现在这个目标是关于系数 $a_0,\dots,a_n$ 的函数，里面变量是系数。求最小，大家学过：求它的**驻点**。驻点什么意思？这个函数对每个变量的（偏）导数都要等于零——这个等于零、那个等于零，$n+1$ 个方程就出来了。$n+1$ 个方程、$n+1$ 个系数，同样得到一个线性方程组——它有个特定的名字，叫**法方程**。

这一整套方法就叫做**最小二乘法**："二乘"就是二范数——误差的二范数最小，就是这个值最小。做法就是去求它的梯度，令梯度为零得到方程——这是大家经常用的，最小二乘法非常非常普遍。到这里，这个问题就解掉了：逼近问题我也可以找到一个函数了。

拟合也叫**回归**。实际应用中，逼近型用得比插值型多，为什么呢？我们总是认为数据中有一些概率上的误差；插值的话自由度不够高（被点钉死），逼近的话函数空间可以给得更多。

### 次数怎么选：欠拟合与过拟合

还有一个现实问题：点很多怎么办？假设有一万个点，你用 9999 次的多项式去拟合就不合适——所以我们一般不用那么高次，系数少一点，误差让它体现在数据上就好。反过来，可能只有十个点，你一定要用十次多项式去插值、去逼近，这时候就会产生很多问题。

怎么选多项式、选几次，是非常非常纠结的：没有应用背景、没有先验知识，随便去试，往往是解不好的。这里面就出现两种典型毛病：

- 系数选少了，表达能力不够——这就是**欠拟合**；
- 点很少，却用了一个非常复杂的函数——比如本来是个逼近问题，你非要每个点都插过去——这就是**过拟合**。

### 过拟合长什么样：误差很小，预测离谱

红点是我采样的，我希望求出一条光滑曲线给我（绿色的那种）；结果求出来的函数（蓝色的）呢，确实误差也很小——但它非常震荡：虽然在红色这些点上拟合得很好，可它在非采样的那些点上的预测极其离谱。

什么原因？因为你度量的只是那些观察点（采样点）的误差，但这个函数本身的行为不好。为什么说它"强"？它次数很高嘛，能力很强——但这个不是我想要的。这种情况经常发生，所以大家用的时候，一定要好好思考你的应用背景。后面我们会引出神经网络——用的时候没注意这些，往往就是过拟合，还以为很好："你说这个误差很小啊，为什么预测很差？"就是这个问题。

实际过程中大家会这样搞：把数据集里随机抽取 10% 拎出来，不参与拟合；用 90% 去拟合，然后用 10% 去做验证，来认证这个函数到底拟得好不好。这样能降低过拟合的概率，但不完全保险。

再把两个词说明白：用线性（二次）函数去拟合，是**欠拟合**——拟合能力不够、表达能力不够，你的函数空间太小了，里面只有线性函数；点很少、却给了一个非常复杂的函数，是**过拟合**——用户看起来误差很小，等于零，没有误差，但函数并不可靠。

那什么时候才是一个比较好的函数呢？人们想了好多办法，比如交叉验证——像我刚说的，随机拿一部分数据出来做测试，能很大概率减少过拟合。但从理论上讲，这事没法避免：除非数据分布我是预先知道的，那我有办法避免；可实际过程中你根本不知道数据实际是什么样的行为，所以只要函数空间选得不好，什么事情都可能发生。神经网络里，一个神经网络就是一个函数空间，权重定义了所有函数的形式——没办法，只能不断尝试、不断做验证，这个我把它叫做**调参**。

> **易错点**：误差很小（甚至等于零）≠ 函数可靠。你优化的只是采样点上的误差，函数在采样点之外的行为，目标函数根本没管。

### 对抗过拟合：数据、模型与正则项

举个采样不均的例子：真实的规律你不知道，某一段你采了很多点，另一段只采了几个——你让模型尽量去拟合，它会给你拟合出很诡异的曲线，稀疏区间的预测肯定不准。那怎么办？几个方向：

- **增加数据**：采样多一点；
- **数据增强**：数据不够，自己去造；
- **简化模型**：函数空间别给太大；
- **加正则项**：给函数（的系数）加限制。

今天时间有限，前几个先不详细展开，后面讲几个重要的正则项。

### 岭回归：让系数小一点

第一个正则项叫**岭回归**：拟合一些点，得到误差最小的一个拟合之后，对这些系数——就是刚才的 $a_0,\dots,a_n$——我希望它的模（范数）也很小。目标变成：

$$\min\ \sum_{i}\big(f(x_i)-y_i\big)^2+\lambda\,\|w\|_2^2,\qquad w=(a_0,a_1,\dots,a_n)$$

中间这个 $\lambda$，表示两项的重要性比例：除了拟合误差，我还希望系数的模小一点。原来的回归模型只有前面（拟合）那一部分，现在对系数加了限制，整个回归问题就变得更加稳定。

### 稀疏正则：让优化替你挑基函数

还有一种情形：具体去选哪些函数，我确实没把握；但我知道这个现象里面有一批函数都跟目标有点类似、都可能有用。那就把这批函数全拿来——这时候函数集可能是过冗余的，甚至可能是线性相关的，这叫**过完备**——不像刚才讲的函数空间那样要求基函数线性无关。怎么办？策略是：取很多函数 $g_i(x)$，不保证它们线性无关；对系数 $w=(a_0,\dots,a_n)$ 用 **L0 范数**——它数的就是向量里非零元素的个数——希望这一项也尽量小：

$$\min\ \sum_{i}\big(f(x_i)-y_i\big)^2+\lambda\,\|w\|_0$$

我再讲一遍：L0 范数表示向量的非零元素个数，这个值越小，非零元素越少，也就是零越多。假设解出来只有三项是非零的，是不是就意味着：只要用这三个基函数来刻画我要的东西就可以了？某个系数等于零，实际上就是对应的 g 函数没有被采用。所以，虽然你给了我很多基函数，我通过这样一个优化，自动在里面选出部分的基函数来组合我要的东西——根据不同的数据，选择我要用的函数。

上面这种带 $\lambda$ 加权的无约束写法，跟写成约束形式是等价的：任何一个 $\beta$ 都存在一个 $\mu$，使得两个问题的解相同——这是优化理论的内容，中间我不展开，只讲思想。

为什么要有这一手？因为选函数是非常痛苦的事情：选少了表达不够，欠拟合；选多了，过拟合；应用中总是出问题。那就换个思路——对要的函数加一些限制，使得我能不用在乎那些函数怎么选择，让优化过程把函数选得更精准。

### 压缩感知：稀疏性的高光时刻

说到稀疏优化，就要提一下压缩感知——听众里可能也有同学了解过。它在大概 2010 到 2020 年那十年非常热，研究非常火；现在没什么人去研究了，但事实上里面还是有很多有意思的东西。

问题是这样的：我有一个信号 $x$，维度很高，但我知道它是**稀疏**的——只有少量的元素非零。这样的信号要直接记录，需要很长的存储。简单一点，我通过一个采样矩阵对它做线性乘法（相当于点乘），只存储一个短的 $y=\Phi x$。问题来了：已知 $y$、已知采样矩阵，我能不能恢复出 $x$？从数学上讲，不可能——方程个数少于未知数个数，显然有无穷多个解。

但是！这无穷多个解里面，有一个最稀疏的解，而**最稀疏的解是唯一的**——这个证明非常强，是我们著名的华人数学家陶哲轩与合作者证明的：只要知道这个信号是稀疏的，通过这样一个方法，你就能够用很少的存储量去存储这个稀疏信号，然后通过这样一个优化，就能够反解出 $x$；并且可以证明，以概率 1 能够得到真解。什么叫概率 1？就是不保证每一次都解对，但很大概率是真解——解 1000 次，可能有 999 次都是真解。概率上为什么有这些讲究？因为中间的测量矩阵里有一些随机的量，这里不展开。

你看，L0 范数刻画的不就是稀疏吗——一个向量只有少部分元素非零。所以稀疏优化跟压缩感知是相关联的；压缩感知也确实很成功地用在 CT、MRI 这类信号采集上。细节不展开。

### 函数之外：非函数曲线与分段技巧

今天把函数拟合讲完了。这样讲，对一些从来没接触过的同学有没有难度，我不知道，但我已经尽自己可能把它讲得比较通俗了。函数没问题之后，还有一类东西不是函数型的：像一条打圈的曲线，一个 $x$ 对应若干个 $y$——它显然就不是函数，用函数就没法表达。怎么办？下周我们就来讲这种复杂的曲线；再往后还有曲面，怎么表达、怎么拟合，一路讲下去。

今天先留几个思考：一是这种非函数型的曲线怎么拟合；二是维数可以往高维走；三是复杂度很高的时候，要考虑不同的形式，甚至把大问题变小问题——把一个复杂的函数曲线变成**分段**：这一段用一个函数，下一段用另一条曲线，一段一段去拟合。这都是技巧，但要保证它们之间的**光滑性**——这里有些约束，是建模领域非常重要的东西。

### 曲线怎么画：光栅化

还有另外一个问题：你拟合出了曲线，怎么把它画出来？这就是**光栅化**——计算机里任何曲线，最后都要变成像素。一般曲线变像素比较麻烦，所以平面上我们只对直线段提供基本的光栅化函数，也就是直线光栅化——我们的库、框架里面都提供了。圆、椭圆这种特殊曲线有特殊算法去光栅化；其他的曲线没有一般的方法。那怎么办？只能在曲线上取点：比如红色这条是你求出的函数，你在上面取若干点——取越密，点越多——然后依次连成线段，把这些线段依次画出来（靠图形 API；我们给的这个框架里面，也有画直线的基本接口）。

```text
连续函数 y=f(x) ──密集取点──▶ 离散点列 ──依次连线──▶ 折线段 ──光栅化──▶ 屏幕像素
```

读图：计算机里画曲线，本质上都是先把它离散成多边形（一串线段），再靠线段的光栅化画出来。这也是为什么 GAMES101 课上做渲染都用三角网格：我给的是一个连续函数表达的曲面，也必须把它离散成一个点、一个三角片，才能画出来。光滑函数在工程中表达能力非常强，但绘制的时候还是得把它离散出来。平面上画线段；空间中画三角形——三角形投影到屏幕上还是三角形，拿去光栅化，就画出来了。

### 课程规划：先连续，后离散

最后简单讲讲后面的计划。前面一部分（大概三分之一到一半不到）讲**连续的曲线曲面**——为什么？这是业界标准：汽车、飞机这些行业，工业界用的就是非均匀有理 B 样条（NURBS）这类建模；很多软件里都有，3ds Max、Maya，特别是专业软件 Rhino（犀牛）就是用 NURBS 建模，非常强大，可以建出非常光滑的曲面。像汽车为什么一定要光滑？如果是面片，反光跳出来就很不光滑；所以工业界都用这种连续的样条函数来表达曲面。

后面留三分之二（或者更少一点）的时间讲**离散曲面**。离散曲面不具有方程——是把方程离散成三角面片；只要面片足够多，就足够逼近那个曲面，我就可以对它进行研究。后面的内容也比较多：重建、去噪、变形编辑等等，偏向离散型曲面。所以这门课，前一半不到是连续，后面是离散；离散部分的数据结构大家也要有一点了解，我尽量照顾到更多同学。

## 从散点到函数：插值、逼近与基函数的选择

### 先把一维函数这一步走扎实

晚上好，各位。这是 GAMES102 的第二次课，任务是把"数据拟合"这一整块讲完。上周我们开了个头：花了大概半小时把大家学过的基本内容回顾了一遍，解释了函数映射——它在不同场景里其实是同一个东西：给一个 $x$，输出一个 $y$。现在我们把这个范围先钉死：$x$ 和 $y$ 都是实数，也就是初中学的那种函数。高中都还没学向量呢，所以我们就从最入门的形式做起。

同学们先不要着急去啃张量、向量和多维函数。$x$ 将来可以是向量，甚至是一个矩阵、一个张量——一张图片就可以看成一个矩阵——映射函数推广到高维是一点问题都没有的。但那是以后的事：先把一维情形里面的门道搞明白，后面的一切都好过渡。

给了一些 $(x, y)$ 的对子，怎么找一个函数去拟合它？三个步骤：第一，什么叫做"好"的函数？第二，在哪个范围里找？——你告诉我一个池子、一个集合、一个函数空间，我到那里去找，把"找函数"变成"找一串系数"；第三，怎么找？——去求目标函数的梯度。上周有些同学第一次接触，反馈说结果很怪异、很困惑，讨论得还很激烈——这很正常。今天再完整过一遍，理解会深一层；后面我会越讲越快，今天这一遍就是照顾第一次接触、背景不那么相关的同学。

另外，为了答疑解惑：课件不在视频网站上，而是放在课程主页上，大家可以去下载。建议同学们跟着把里面的推导自己推一遍。

### 为什么要给散点找一个函数

动机是这样的：背后的规律可能要用一个非常复杂的函数才能表示，但我不知道它的表达形式，只能观察到一些采样点——离散点，也叫数据点。

那把这些点拟合成一个函数，有什么好处？

第一是压缩存储。假设有 100 万个数据，但拟合出来的函数可能只用 1000 个系数就存储下来了——你不用去存那 100 万个数据，只要存 1000 个系数就可以了。这就是压缩。

第二是预测。有了函数，采样点之间那些中间值，代进去就能知道对应的输出；来了一个新的观测 $x$，也能预测对应的 $y$ 是多少。

顺带说一句，机器学习里说的是另一套语言：他们把这叫"编码"——把数据信息编到一个函数里面去；那个函数，他们叫"网络"。名词不一样，事情是同一件。

### 什么叫"好函数"：从分段线性说起

给定了这些点，能通过它们的函数有无穷多个——你要多少个就有多少个。当然，有些函数好一点，有些函数不好。那什么叫好、什么叫坏？不同的应用对它的要求不一样。

最简单、最暴力的一种：假设知道点的顺序，把它们依次用直线段连起来。这确实是个函数——每一段都是直线，整体是一个分段线性函数；它经过了所有样本点，误差全是零。

但这个函数好不好？大家一看就知道：不好，因为它不够光滑。在每一个数据点处，它只有 C0 连续——左边导数是一个方向，右边导数是另一个方向，左右导数不相等，所以连 C1 都没有，节点处根本不可导。

所以在实际应用中一般不会用这种函数，只有在精度要求不高的场合才会用到：它只有 C0，并且不可求导，而不可导会给后面很多处理带来困难。当然，你非要拿它做数值计算也可以——用差分去做数值微分，那就属于离散的那一套。这门课后半部分的网格处理，研究的正是这种对象：不追求光滑，曲线是分片线性的，曲面是分片三角形的——这是最通用、也最简单的表达。这种分片对象有它的限制：一个点的导数怎么求？能不能用周围两个点的导数来估计？这就涉及数值微分、数值积分的计算，放到后面去讲。

从我们这门课今天的主线来说，分段线性函数虽然也能算出一个结果，但不够好。我们追求的是一种非常光滑的函数——把函数的性质提上去，这就叫光滑插值。

### 噪声与离群点：插值的软肋

光滑插值有一个绕不开的问题：如果数据里还带噪声（英文叫 noise），或者带一些离群点（outlier），事情就麻烦了。离群点是怎么来的？一个随机的现象：由于外界的误差、仪器的误差，这个点并不落在我们要的那个函数上。这样的数据实际上非常不可靠，本不应该进入我的数据集。

麻烦在哪里？我只是拿回来很多数据——100 万条里到底哪些是噪声、哪些是离群点，我并不知道。于是插值只能对所有数据"完全负责"：误差确实是零了，但那些值本身很不可靠，在这些点附近做的预测就极其不准确——曲线本来应该平顺地过去，却被个别坏点拽歪了。

所以，完全尊重原始数据去做插值，并不是一个非常好的想法——除非你能保证采样点非常精确，或者仪器足够可靠。

更常见的选择是拟合：允许每一点的误差不为零，只要小一点。这样对噪声和离群点就能部分抵抗。

三种函数摆在一起看：黑色的是分段线性，绿色的是插值，红色的是拟合。就这个数据集来讲，三个都还可以——误差有大有小，光滑性有好有坏。哪个绝对好？说不上，看你的应用。

| 函数类型 | 数据点上的误差 | 光滑性 | 抗噪声能力 | 适用场合 |
| :--- | :--- | :--- | :--- | :--- |
| 分段线性连接 | 恒为零 | 只有 C0，节点处不可导 | 无（完全忠于数据） | 精度要求不高的场合 |
| 光滑插值 | 恒为零 | 高 | 无，坏点会把曲线拽歪 | 采样点精确可靠、仪器可信 |
| 拟合（逼近） | 允许非零，但要小 | 高 | 能部分抵抗噪声与离群点 | 数据带噪声的大多数实际场景 |

### 没有唯一答案：领域背景是刚需

选哪个函数是一个非常痛苦的过程，因为你根本不知道这个数据是什么样子——除非你有先验，知道数据的性质和分布。

所以，求拟合函数绝对没有唯一的方法，它根据你的应用、你的意图、你的背景来定。求拟合函数的时候一定要有领域背景，也就是对问题本身的领域要有了解。比如我们后面会讲到曲线曲面的拟合：我知道它是二维平面上的一条曲线、三维空间中的一个曲面，知道它的维数是多少，函数就可以照着这个去设计。但如果对数据的性质、意义一点都不清楚——假设来的是个 100 万维的数据，它到底多少维、服从什么样的分布，你两眼一抹黑——这个事情就很难做。那怎么办？只能试，不断地调。这就是所谓的调参，是个蛮痛苦的过程，后面我会再展开。

### 三部曲：在哪找、什么叫好、怎么找

把方法论收拢一下，整个拟合就三步，大家就全清楚了：

```text
散点 (xi, yi)
   │
   │ ① 在哪找：限定一个函数空间
   │    f(x) = λ0φ0(x) + λ1φ1(x) + … + λnφn(x)
   │    基函数张成的线性空间，找函数变成找系数 λ
   ▼
目标函数 E(λ) = 误差项（数据项） + 正则项
   │
   │ ② 什么叫好：既要贴近数据，又要约束系数或函数本身
   ▼
③ 怎么找：对每个 λj 求偏导并令其为零
   │    → 线性方程组 → 解出 λ
   ▼
拟合函数 f(x)
```

图读下来就是一条流水线：先圈定搜索范围，再定义"好"的标准，最后用求导把问题变成能解的方程组。

#### 在哪找：函数空间与基函数

函数千千万，你总得限定我一个范围、一个形式。一般的做法，是把函数写成一组基函数（basis function）所张成的线性空间里的元素，这样"找函数"就变成了"求系数"——系数求到了，函数就求到了。

那这个空间选得好不好，是另一个必须考虑的问题。假设这个空间只有线性函数的表达，那它就太小了，根本没法表达非常复杂的函数——它只是所有函数可能性里很小的一个子集。所以人们会想办法把张成的空间做得尽可能大：空间大，你大概率能找到数据所表现的规律；否则概率很小，甚至最后得到一个非常差的函数。基函数怎么选，就是今天要搞明白的事。

#### 什么叫好：误差项加正则项

"哪个最好"，就靠目标函数来定义。目标函数通常不止一项：第一项叫误差项，也叫数据项（data term）——所求函数离每个采样点 $(x_i, y_i)$ 的靠近程度必须保证，因为这些点是从采样来的。

但光有这一项往往还不够——比如碰到变量比方程多的情形，解有无穷多，怎么办？我们还要加约束，通常加在系数上——对系数加约束，相当于对函数加约束。比如岭回归对系数的模（L2 范数）加约束；稀疏优化（Lasso）对系数的 L1 范数加约束。

你说，我对 $f$ 本身加约束行不行？可以。比如我希望 $f$ 的二阶导数的平方在整个区域上的积分不要太大，把它当作正则项放上去，完全没问题。为什么这条管用？二阶导数是曲率，它的平方积起来小，函数就不会发生很大的震荡，不会像蛇一样游来游去——这个积分衡量的正是函数的光滑性。再比如，我可以把 $f$ 的弧长作为一个限制，希望弧长尽量短——弧长就是导数的积分，这就是经常看到的 TV 模型（Total Variation）。你甚至可以提出统计的、规划的模型去描述 $f$——当然也可以。有一大批研究工作者就在这里面定义 model，这是个实实在在的研究方向。

#### 怎么找：求导变方程组

有了目标函数，怎么求解？如果它是平方的形式，非常好解：一求导就变成线性方程组——第一次作业里大家已经体会过了。但如果目标函数非常复杂、非线性，优化就比较难。所以在这门课里我们用的形式都比较简单：误差是平方的，正则项也是平方的，一求导就是一个方程组。

还有一种情况要处理：如果变量数多于方程数（线性代数学过），解空间是无穷的，而且这个解空间的维数等于未知数个数 $n$ 减去系数矩阵的秩。这时就要靠正则项在无穷解空间里做筛选——在里面找一个最稀疏的解、模最小的解——这样你的系统才能得到一个合理的解。这就是整个过程。

### 多项式插值：范德蒙德方程组

现在把细节重新理一遍。假设有一些点 $(x_i, y_i)$，我要用 $n$ 次多项式去插值：把"过每个点"的条件逐个带进去，就得到一个 $(n+1)\times(n+1)$ 的方程组，未知数是 $n+1$ 个系数：

$$p_n(x)=a_0+a_1x+a_2x^2+\cdots+a_nx^n,\qquad p_n(x_i)=y_i$$

$$\begin{pmatrix}1 & x_0 & \cdots & x_0^{n}\\ 1 & x_1 & \cdots & x_1^{n}\\ \vdots & \vdots & & \vdots\\ 1 & x_n & \cdots & x_n^{n} \end{pmatrix}\begin{pmatrix}a_0\\ a_1\\ \vdots\\ a_n\end{pmatrix}=\begin{pmatrix}y_0\\ y_1\\ \vdots\\ y_n\end{pmatrix}$$

这个系数矩阵就是范德蒙德（Vandermonde）矩阵——大一就学过。可以证明，在这个问题里它的行列式非零：基函数换一换，只不过系数不一样，但"行列式非零"这件事是能证明的。所以方程组的解存在而且唯一。

### 两个偷懒技巧：拉格朗日与牛顿

直接面对这个方程组，每次都要重新求解，比较麻烦。数学上有两个技巧，可以让你偷懒。

#### 拉格朗日：把基函数预先算好

思路是这样的：$(x_0, y_0)$ 这些 $x$ 是固定的，变的是 $y$——那能不能预先求出一组函数，以后 $y$ 一来、一变，我一下子就能把函数表达出来，不用再去解方程组？这是可能的。

看这组函数的性质：$l_k(x)$ 只在自己对应的那个点上等于 1，在其余点上全是 0。以三个插值点为例：

```text
          x0    x1    x2
l0(x)  =  1     0     0
l1(x)  =  0     1     0
l2(x)  =  0     0     1
```

每个基函数"只在一点为一、其余为零"，把它们一组合，$f(x)=\sum_i y_i\,l_i(x)$，插值条件就自动满足了——每个 $y_i$ 只被 $l_i$ 在 $x_i$ 处"接住"。那这些 $l_i$ 怎么求？也不神秘：把"在自己点等于 1、在别的点等于 0"当条件带进去，解的还是刚才那个方程组——只不过只解这一次：预先求出来、存起来，以后数据来了，一组合结果就出来了。这就是大一学的拉格朗日插值。

#### 牛顿：用差商递推

另一个需要偷懒的场景：既然是求一个多项式去拟合数据，那如果能得到一个多项式，与你要的那个多项式在零阶、一阶、二阶……导数上都一样，基本上就可以证明它们两个是同一个多项式。于是就用差商的办法去构造：一阶差商、二阶差商，一直到 $n$ 阶差商，用这些差商把基组合起来——这就是数值分析里学的牛顿插值多项式。

两个技巧的共同思想是：预计算、预存储。把 $l_0$ 到 $l_n$ 预先算出来，或者把差分表预先算出来，用的时候直接代入组合，就得到函数，不需要再求方程组。但天下没有免费的午餐——你肯定要在前面做一些预计算、预存储，用起来才快。做计算机的要清楚：在计算机里，时间和空间永远是矛盾——你存得多，到时算得就快；你不存什么东西、什么都现算，时间开销就大。这就是拿空间换时间；如果空间还换得起，这是合理的。

### 范德蒙德矩阵的两大毛病：稠密与病态

那这套插值求解有什么问题？先说清楚：这些问题不是只插值存在——它们是通用的，你也可以把它们理解成在整个拟合、乃至机器学习里都存在的问题。

第一个问题：范德蒙德矩阵是稠密的——它处处元素都非零。对比另一类矩阵：虽然规模很大，但非零元素很少，那叫稀疏矩阵。稀疏矩阵的方程求解有非常好的迭代方法，速度很快；稠密矩阵就享受不到这个便宜。这里顺带推荐一个非常有名的数学库——Eigen，我建议大家都要去学会用它：里面解方程组的函数都有，直接拿过来用就行了，没必要自己写——自己写还写不过这些库，人家经过了大量验证，效率也有保证。

#### 病态：小扰动，大变化

第二个问题：它可能是病态的。什么叫病态？就是这个解不好求——对输入的微小扰动极其敏感。举个非常简单的 $2\times 2$ 的例子：两个变量，解出来是 $(1,1)$，代回去验证没问题。现在把某个系数稍微做个扰动——假设由于计算精度或者采样，产生了 $10^{-3}$ 量级的误差——你看，这两个方程组看起来几乎一模一样，解出来的结果却完全变了，跟原来的 $(1,1)$ 完全不一样。对右端项做小扰动也一样：0.333 变成 0.334，其余都不动，解又大变。

也就是说，无论对系数矩阵还是对右端项做一点小扰动，对解的影响都非常大。直觉上这是一个连续的系统：系数变一点点，解也应该跟着变一点点。但这里的变化被放大了——说明这个系统在这个地方的"导数"非常大，爬得非常快，所以一点点扰动它就变很多。矩阵的这种性质就叫病态。

病态在数学上用什么刻画？条件数——这个矩阵的最大奇异值与最小奇异值之比。这两个值相差非常非常大，条件数就大。它其实相当于这个矩阵在各个方向上的比例：最大奇异值跟最小奇异值比得比较大，说明有一个方向被"丢掉"了，矩阵里有很强的线性相关性——系统趋近于有无穷多个解，解的可能性很大，一点点扰动就可能让你跳到解空间里的另外一个解上去。

所以在数值分析里，我们要控制住条件数；条件数太大，这个系统就不稳定。你如果不去关心、傻乎乎地把它求出来、把这个解当成你的解，往往会造成很大的问题。做实际求解的时候，这些都是非常重要的，不能够啥也不管就直接算。

### 次数越高越病态：龙格现象

多项式插值为什么容易病态？可以证明——这里不是数学课，我就不证了——范德蒙德矩阵的条件数随着插值点个数的增长是指数型增长的，长得非常快。插值点越多，意味着多项式的系数越多、次数越高；次数越高，条件数就越差，而且是指数级地差下去。这就是为什么次数开得很高去做插值，就容易病态。

这里只做定性的描述；要定量的话，你们要去数学书里看一看，里面有严格的推导和证明。我们只讲原理，照顾大多数背景的学员。

病态体现到曲线上，就是那个大家已经很熟悉的现象——龙格现象：不稳定、抖动。作业里很多同学放了类似的图：同样九个数据点，低次的（蓝色）还好，绿色（次数高一些）开始抖动，红色（次数最高）抖得最厉害——次数越高，抖动越厉害。数据点上的误差是零，但这个函数并不好。

所以结论是：多项式插值不稳定。原因有两个：次数高，基函数不好。数学上，多项式空间是能拟合所有（连续）函数的——魏尔斯特拉斯定理保证了这一点——但用这组基函数去求解，它不稳定，而且导致龙格现象。

那有没有更好的基函数？人们会想：我不想用这种单调疯长的基函数，有没有可能用"稍微有抖动"的基函数，同样张成整个多项式空间？有——这样的基是存在的。不过这里先卖个关子，具体放到后面去讲。

### 幂函数基的先天缺陷：疯长的函数

作业里大家已经发现：次数一高就容易过拟合。回头看幂函数基本身——$1, x, x^2, x^3, \dots, x^{10}$——随着次数升高，函数增长非常快：$x$ 的十次方是一条陡峭上升的曲线。数值上，这种疯长的函数是不好的。

那怎么办？经验是：这个函数的各次项要有正有负去抵消，这样加起来才不会全是大值。反过来说，如果每一项都是很大的数，靠"大数减大数"去凑出结果，精度很快就没了。举个具体的数：如果 $x=0.1$，次数一高，$x^{10}$ 就是 $10^{-10}$，在计算机里这个量级可能连底数都保不住，直接被丢掉了。

怎么求一个多项式的值最好？初中——我记得我是在初中竞赛的时候学过——秦九韶算法。把 $a_0 + a_1x + a_2x^2+\cdots$ 改成由里向外的嵌套乘法：先取最里面的系数，乘 $x$，再加系数，再乘 $x$，再加系数……一层一层套出来，至少可以把精度控制住。

所以，多项式的幂函数基，实际上不是好方法。

### 出路之一：正交多项式

那怎么办？数学上准备好了很多正交多项式。看它们的图像：一整族带震荡的曲线，浅蓝的带两个震荡，别的带三个震荡。它们关键的性质是正交——两两的内积等于零：相乘再求和，正好相互抵消。用这样的基，性质就好得多。

大一学过：给了一组多项式（或者一般的一组基），怎么去获得它的正交基——回忆一下，大一里学的那些题都是有用的。我比较着急的一点是：当年的那些课没有讲为什么要做这些变换、原理是什么。如果能带着今天这些应用问题去学大一的数学，我相信很多同学对数学的感受不会那么糟糕，甚至可能会热爱上它。

所以这一讲里讲的所有东西都不是新的，都是原来的东西。我也不是知识的创造者，只是知识的搬运工——把大一的知识翻出来，用到实际问题中，告诉大家怎么去求解。

### 退一步海阔天空：最小二乘逼近

插值讲完了，它的问题摆在那里：数据有噪声或者离群点时，完全忠于数据反而坏事；次数一高还容易产生龙格现象。

那我就退一步：不要求经过每个点，只要逼近这个函数。为什么可以退？你看这些点，看起来像线性关系，虽然每个点离直线有一定距离——那可能就是噪声。既然点本身未必可信，就没必要让曲线硬凑过去。

做法跟插值是一样的三部曲：找一个函数空间、一组基函数，在张成的空间里找一个函数，让它与数据整体上距离最佳。逼近的目标函数，一般就取"所求函数代进去的值与目标值的平方和"：

$$E(\lambda_0,\lambda_1,\dots,\lambda_n)=\sum_{i}\Big(\sum_{j}\lambda_j\,\phi_j(x_i)-y_i\Big)^{2}$$

注意，这个函数的变量是谁？是那些 $\lambda_0$ 到 $\lambda_n$——基函数的系数。要求它的极小值，就是对每个变量求偏导并令其为零：$\partial E/\partial \lambda_j = 0$。这样就化成了关于 $\lambda$ 的方程组。

具体展开我就不一步一步写了，稍微有一点线性代数知识就能推：式子一求导，就可以整理成矩阵形式，系数矩阵反映了怎么去求 $\lambda$ 的解。整个目标函数是个二次型，一求导就变成线性方程组；求解上同样涉及矩阵求逆这类操作——所以前面讲的那些稳定性问题，在这里同样存在。

### 魏尔斯特拉斯定理：多项式无处不在

既然幂函数基这么不好，为什么大家还是喜欢用多项式？因为有一个非常强的定理给它撑腰——魏尔斯特拉斯（Weierstrass）逼近定理：无论你给我一个什么样的函数——这个函数是未知的——我总能找到一个 $n$ 次多项式，在给定区间上与你靠得足够近：你给我一个 $\varepsilon$，要多小有多小，比如 $10^{-6}$、$10^{-8}$ 的误差，我总可以找到一个 $p_n$ 满足；只不过这个次数 $n$ 可能很高。

这就是数学的思维：我告诉你"存在"。怎么找？我不管，反正它存在。用直白的语言讲：整个函数空间非常大，但多项式在里面处处都在——你问 $f(x)$ 在哪里，我总有附近的一个多项式存在，可以跟它靠得比较近。这就叫稠密。

一个类比：实数轴上，无论你给我哪个实数——它是无理数也好、什么数也好——我总存在一个有理数靠得足够近，要多近有多近。这说明有理数在实数上处处都有。多项式函数在整个函数空间里也是这样：无处不在，只不过次数可能很高而已。

> **提示**：这里的"稠密"说的是逼近意义上的"无处不在"——任何连续函数附近总有多项式；它和前面说矩阵元素"处处非零"的"稠密"不是一回事。

一个细节：这个定理是限定在一个区间上的。一般我们讨论问题都会把区间规范化到 $[0,1]$——$[a,b]$ 和 $[0,1]$ 之间就差一个系数（线性变换）。

为什么有了这些毛病大家还是觉得多项式不错？因为它表达能力很强：无论 $x$ 在哪里，总存在多项式靠近它；只要 $n$ 足够大，用这个空间去找函数，至少有概率表达出我要的东西。只不过 $n$ 要多大，事先不知道。到了实际过程中就变成自己去调：$n=100$ 不够？上 1000；1000 不够？上 10000……但不可能这样搞——这样搞代价太大，因为次数太高。

### 伯恩斯坦多项式：把存在性变成构造

证明不讲，我只告诉大家：有一位数学家叫伯恩斯坦（Bernstein），他用构造性的办法证明了这个定理——构造出一列多项式，然后证明在给定条件下，这列多项式一致收敛到 $f$，从而把"存在"落到了"怎么造"上。这个构造长这样（$x$ 限制在 $[0,1]$）：

$$B_n(f)(x)=\sum_{j=0}^{n} f\!\left(\frac{j}{n}\right)\binom{n}{j}x^{\,j}(1-x)^{\,n-j}$$

$j$ 从 0 到 $n$，共 $n+1$ 项；$\binom{n}{j}$ 是二项式系数，就是从 $n$ 个元素里拿 $j$ 个的组合数；基函数是 $x^j(1-x)^{n-j}$，组合的系数就是函数在均匀分点 $j/n$ 上的取值。

把这族基函数画出来看：一次的、二次的、三次的、四次的（黑、绿、黄、红各一组）——它跟 $x, x^2, x^3, x^4$ 那些图长得完全不一样，但它仍然是线性无关的，并且同样组成多项式空间——是这个空间的一组基。后面我们会花更多时间来讲，这里先一带而过。

这里头有一个非常重要的认识：同一个函数空间，可以用不同的基；基与基之间的变换，就是矩阵。矩阵的本质，是在不同的基函数之间做线性变换的描述。我不太赞成现在流行的那种教法：给你一个叫矩阵的东西，列出一堆性质，搞半天不知道它有啥用。矩阵实际上非常有用——把矩阵理解为"信息在不同基函数之间做线性变换的描述"，用这样一个理解去掌握它。后面有时间我再展开一点。

### 伯恩斯坦基的好性质

我们这个学科里，有一门课叫《计算机辅助几何设计》，专门在讲这类多项式的性质。伯恩斯坦基到底好在哪？

#### 权性：基函数天生是一组权重

首先，每个基函数在 $[0,1]$ 上都大于零；而且对固定的任何 $x\in[0,1]$，所有基函数在这一点的值加起来恰好等于 1——在图上任意竖着切一刀，那一列函数值加起来都是 1。

$n$ 个数都不小于零，加起来又等于一，这意味着什么？这就是一组权！用它们做线性组合，就是一个加权平均。具有"作为权的性质"的基函数非常好：基是正的，计算就很稳定。

此外它还有凸包性，有递归性，还可以细分——后面要讲的 Bézier 曲线（贝塞尔曲线）的那些性质，它这里都有，因为 Bézier 曲线就是用 Bernstein 基表达的。

#### 高次也不龙格：还有"造基"的传统

再回看那张高次的图：用了 500 次的多项式，都没有发生龙格现象——原因还是出在基函数上。这族基函数长成一座座"山包"：第一个靠在左边，第二个往右翘一点，像波浪一样慢慢依次隆起，到最后一个函数与第一个镜像相对；无论多少次，都是这样的形状，并且左右对称。5 次、20 次的整族图像也是这个样子，不会疯长。

当然，在我们这个学科里面，还有不同的学者构造了很多种不同的基函数，大多以人名命名——专门有人研究这个东西，对各种各样的基函数非常熟。这里给大家指一条"科研路径"：只要你觉得某个函数作为基函数有一些好性质，把它证明出来，并且它对曲线设计、函数表达有一些好的特征，那它就有可能成为一个新的基函数，你就可以写篇论文——早年的很多文章就有这样一个特点。

### 两个观点看曲线：代数与几何

关于伯恩斯坦基函数，还有两个观点——从不同观点去考虑，对后面理解"曲线怎么设计、怎么看好"很有用。

先摆一个事实：蓝色点是从一个函数上采样出来的；把它们依次用线段连起来，就是那条蓝色折线。现在取这些采样点的函数值当系数，用 Bernstein 基去组合，就得到一条红色的曲线——这就是伯恩斯坦多项式：给这组函数值，不断这样组合，就得到一条曲线。

这可以被证明：当 $n$ 足够大、在函数上采样足够密时，构成的这个红色函数 $p_n(x)$ 一致收敛到 $f(x)$。一致收敛的意思是"处处都差不多"——红线会越来越贴近原函数。所以用伯恩斯坦多项式做逼近是有保证的：你毕竟在逼近你要的东西。

代数观点：那串系数就是一串函数值——$y$ 值的集合。Bernstein 基因为"处处非负、总和为一"，拿它对这串函数值做的就是加权，得到其中"一个点"的值——这是一个纯粹的代数过程。

几何观点：把这些基函数看成一些"对象"，把系数换成平面上的点——控制顶点；用系数去组合这些基函数，就变成一条新的曲线。两个观点在后面做设计的时候合流到"控制顶点"上：我把这个顶点调一调、拖到这里来，曲线就跟着变成这个样子——这样就可以用交互的手段去做曲线的设计。交互式建模里"拖控制点改曲线"的做法，来源就在这里。

### 尾声：高斯函数与 RBF

最后回应一下上周有同学关心的 RBF。RBF 实际上是在高维里用得比较多；在低维、一维的情形，它就是大家都熟的高斯函数：

$$G(x)=\exp\!\left(-\frac{(x-\mu)^{2}}{2\sigma^{2}}\right)$$

参数上，$\mu$ 叫均值——就是分布的期望值；$\sigma$ 是方差（标准差）。这个函数涨起来再落下去，比较好记的名字叫"帽子函数"——像一顶帽子。它处处都不为零：在很远的地方函数值只是很小，但不是零。

把 $\mu$ 取 0、$\sigma$ 取 1，得到 $G(0,1;x)$——这就是标准化：均值在零，是沿着坐标轴左右对称的一个函数。$\mu$ 和 $\sigma$ 的分工很清楚：$\mu$ 不为零，决定帽子的位置；$\sigma$ 不为一，决定它的胖瘦——是宽还是窄。图里蓝色的那条 $\mu=0$，所以峰正好立在 $y$ 轴上；$\sigma=0.2$ 比较小，所以又窄又高。

这顶"帽子"怎么拿来做拟合，RBF 在高维里怎么展开，后面接着讲。

### 高斯基函数的两个旋钮

先把高斯基函数这顶"帽子"的两个旋钮拧清楚——后面整节课的戏，都围着这两个参数转。$\sigma=1$ 的时候，它就是图上红色那条，明显变得比较胖。前面还乘的那个系数不是可有可无的装饰：它是归一化因子，作用是让曲线下的面积积分等于 1。这也回答了"为什么这些帽子有高有矮"——面积被固定住了，$\sigma$ 越小，帽子就必须长得越尖越高。面积积分等于 1 之后，这个函数在形式上就成了一个概率密度函数——但我们先别管概率，你不要去管概率，它就是一个普通的函数，这么用就行了。

$$g(x)=\frac{1}{\sigma\sqrt{2\pi}}\,\exp\!\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)$$

两个参数各管一件事。$\mu$ 管它在哪：绿色那条 $\mu=-2$，整顶帽子就往左偏了两格。$\sigma$ 管胖瘦：绿色那条 $\sigma=0.5$，稍微胖一点点，但没有红字的胖，因为红字的 $\sigma$ 是 1。所以这样一个函数有两个参数：一个表示它在哪（就是均值），一个表示它胖还是瘦。

$\sigma$ 还有一个极端情形要心里有数：如果 $\sigma$ 很小，设成 0.01，这个函数涨起来就像脉冲一样，很尖很尖锐——因为 $\sigma$ 很小，就一个值凸出来，很高。所以 $\sigma$ 不能太小。

> **提示**：$\mu$ 定位置（均值），$\sigma$ 定胖瘦（宽度），记住这一条就够，别被"概率函数"的名头带跑。

### RBF 拟合：把帽子摆到数据点上

不管 $\mu$、$\sigma$ 取什么值，这样构造出来的这些基函数彼此都是线性无关的。线性无关，自然就可以张成一个空间、组合表达很多函数——所谓的 RBF 插值就是这个道理。

具体实施有不同做法，我讲一个比较通用的做法：给了一批数据点，我就在这里面放一个基函数，这里放一个基函数，这里再放一个基函数，把这些基函数加权加起来，定义为我的 $f(x)$；另外放一个系数 $b_0$，它在这里只是让整条曲线上下移动。这样组合出来的东西，在高斯混合模型（GMM）里也能见到同款形式。

求解跟前面完全一样：还是去求极值，得到关于各个系数的方程组。有时候 $b_0$ 会显得多余，那这时候可以给它一些先验，比如在这里加一个二次的惩罚项，或者对系数之和做点约束——目的只是让问题规整（归一化）好解。RBF 拟合就是这样。

高维中也顺理成章。这些点照样往上放基函数，只不过这时函数不再是一维那条曲线，而是像一个草帽一样的曲面——把这个函数进行一个旋转，就变成二维的、三维的，道理一模一样。

这里是同学们作业中真实出现的东西。上一周我们还没讲这块，大家作业里普遍出现了同一个现象，不知道是什么原因；现在原因就清楚了嘛：因为你的 $\sigma$ 设得很小，每个基函数都很尖锐、很瘦。虽然它完成了插值，但这个函数不够好——每个基函数都这么瘦，用这些积木也只能长成这个样子，还不够丰满。把 $\sigma$ 放大到十，胖一点，就好多了。可以看到变化。另一位同学的作业也是同一个病根：$\sigma$ 这个设子不够好，太小了。

### 把 σ 和 μ 变成待求的变量

这里就有一个困惑：$\sigma$ 到底取多少？只能凭经验——你如果希望这个函数稍微胖一点，$\sigma$ 就取大一点。那怎么办？有没有可能让 $\sigma$ 和 $\mu$ 也变成变量？如果能自动把 $\sigma$、$\mu$ 都求出来，那就太好了，我就不用拿 1、0.1、10 一个个去试。

想想现状有多"死"。这些方法里基函数中心是被定死的——$\mu$ 放在哪里？就放在数据点上。方差呢？哪个点该胖、哪个该瘦，你怎么知道取哪些不一样？没办法预先知道。而且基函数也不一定非得放在这里，说不定放在别处更好。你凭什么说 $\sigma$ 等于 10 好、$\sigma$ 等于 1 好？不同的数据都有不同的特性；我的数据是啥类型，你能够很智能、很自动地告诉我 $\sigma$ 是多少最好，这样才省心。

所以我们把这个 problem 来 formulate 一下。做个变形：把 $\sigma$ 吸收进去，把一般的高斯写成"标准高斯套一个仿射变换"的形式：

$$g_{0,1}(a x+b)=\exp\!\left(-\tfrac{(a x+b)^2}{2}\right)=\exp\!\left(-\tfrac{\bigl(x-(-b/a)\bigr)^2}{2(1/a)^2}\right)$$

其中 $g_{0,1}$ 就是那个标准高斯。对一下账就清楚了：$a$ 是伸缩因子，就是 $\sigma$ 的倒数；$b$ 管沿 $x$ 轴平移，峰顶落在 $x=-b/a$ 处，等价于 $\mu=-b/a$、$\sigma=1/a$。也就是说，任何一个一般的高斯函数，都是由我一个标准基函数通过这样的变换生成的：让它沿着 $x$ 轴左移右移，再变胖变瘦。一个函数经过这一族变换，可以产生出一系列新的函数；这些函数再去组合，就能组合出我要的目标函数。

这里我讲慢一点，这里很重要——因为这个东西一旦写好之后，现在这十年大家很赶时髦的一个东西（神经网络）就出来了。我以前是直接把 $\sigma$ 写成固定常数，没有把它写在变量里；现在把它当做一个变量：$a_i$ 和 $b_i$ 就跟每个基函数的 $\sigma$、中心相关，都是未知数，都拿去求。这些函数照样线性无关，就可以张成一个空间、表达很多函数；目标函数就长这个样子，这个函数就是我要求的。既然你定义好了这样一个空间、这个函数形式，你再去用刚才说的拟合也好、插值也好去求解就行了。这样就把 $a_i$、$b_i$——也就是 $\sigma$ 和 $\mu$——做成了变量，可以同时去优化中心跟每个基函数的方差。

对比一下参数地位的变化：

|                 | 以前的 RBF 拟合         | 变量化之后                       |
| :-------------- | :---------------------- | :------------------------------- |
| 中心 $\mu_i$    | 定死在数据点上          | 变量，交给优化                   |
| 宽度 $\sigma_i$ | 凭经验手调              | 变量，交给优化                   |
| 待求量          | 只有组合系数（线性问题） | 系数与 $a_i,b_i$ 一起求（非线性） |

这个思想在理论上是站得住的。数学上可以证明：只要 $a$ 和 $b$ 足够多，这种形式的函数所产生的函数空间，同样可以逼近任意连续函数——跟多项式的 Weierstrass 逼近定理一个道理，关键是足够多、次数够高。直观理解：你这个函数无论长成啥样，我总可以在上面布局一些这种帽子函数，用它们的组合去逼近，只是要足够多。所以 RBF 在计算数学里是一个很大的领域，人们研究了很长时间，就因为它本身有这样稠密性的保证。

### 换个画法：这就是一张神经网络

我们再把这个函数形式变一下，画成一张图。每个位置用的都是同样的东西——标准高斯 $g_{0,1}$：

```text
  x --+
      +---(a1,b1)---> [ g01 ] ---w1---+
  1 --+                               |
      +---(a2,b2)---> [ g01 ] ---w2---+--->( sum )---> f(x)
      |                               |        ^
      |                               |        |
      +---(an,bn)---> [ g01 ] ---wn---+       w0
```

读法：输入端是 $x$ 和常数 $1$ 两个入口；每条边带一对权 $(a_i,b_i)$，它算的就是 $a_i x + b_i$（$x$ 乘 $a_i$，1 乘 $b_i$）；中间节点统一过激活 $g_{0,1}$；输出端再用 $w_i$ 加权求和。整个函数就是：

$$f(x)=\sum_{i=1}^{n} w_i\, g_{0,1}(a_i x+b_i)+w_0$$

那个 $w_0$ 是什么？就是它的一个平移。

这里藏着一个非常大的技巧，叫齐次坐标（homogeneous coordinates）。把 $x$ 看成二维的 $(x,1)$，平移就变成"乘在 1 上的权"，"乘线性加平移"这个仿射变换就统一成了矩阵相乘。所以 $a_i x+b_i$ 这些变换，你既可以把它看作对输入做了一个仿射变换，也可以干脆写成矩阵乘法——升一维，平移就归队了。

神经网络把中间这个 $g_{0,1}$ 美其名曰叫激活函数：$a_1 x+b_1$ 算出来把它带进去——所谓"激活"其实就是带进去再算出来，它那边语言叫激活，这里并没有什么真的被激活。每一条线上的权就叫这个网络的权系数，也叫网络参数。

回忆一下我们从上节课一路碰到过的困难：基函数个数 $n$ 不知道取多少——现在它对应的就是这里中间的节点个数；要放多少个节点、节点数怎么调，要调的变量就是这些网络参数。所以这就是一个神经网络，只不过这个网络比较特殊：我用的激活函数是一个高斯函数而已。这个网络也就叫做 RBF 网络，是数学里面一个比较经典的网络。理解这个以后，你再去理解神经网络是非常简单的。

神经元是什么？一个输入——我这里输入全是一维的，就是一个实数；以后维数高一点也可以，只不过多几条线，不管它。一维的 $x$ 跟一个常数 1，这里有两个圈；除了这个激活函数，出来就得到一个值；输出这边要几个，就把同样结构的东西两个三个给它组合、再接上来，就形成一个网络。所以一个神经网络是什么？就是一个函数。只不过激活函数我这里用高斯；你用别的函数可不可以？可以——只要你这个函数经过平移加上伸缩之后彼此线性无关，都可以张成函数空间。至于张出来的空间能不能覆盖你要表达的那类函数，那是这个函数自己的性质，所以我们才要去找那些合适的函数来当激活函数。用高斯函数的，就叫 RBF 网络。

### 非线性来了：全局极小为什么难

把 $a_i$、$b_i$ 变成变量，代价立刻出现。RBF 网络的优化不是很容易：误差项要对 $a_i$、$b_i$ 求导，而它们出现在指数里面，导数就变成一个高度非线性的表达。大家都知道数学这么多年发展，大家觉得它很厉害——不厉害。一旦碰到一般的非线性函数，我们数学上没辙：这个函数再复杂，函数值我能算、导数我也能求，但是你要求它的全局极小值，那就很难求了。

这里我稍微补一补优化的知识。什么叫凸的？这函数长成一只碗这个样子，凸的——这当然好找了：随便放一个点，一求导，下降下降下降走人；导数为零就表示它稳定；换另外一个初值，直接迭代也总能走到那儿。但如果函数不是凸的，运气不好，一路"跌跌跌"只能找到这样一个局部极小的解。所以现在数学上也只能保证找到局部极小，全局最优解没任何办法能保证——除非你运气太好，或者说你这个问题太特殊，知道你的初值就在好解附近，那能找到一个很好的解。但是往往你没那么的运气好。所以说为什么全局极小这个问题很难做、只能做到局部极小。

> **易错点**：初值选取极其重要。也不是随便什么初值都行，一定要根据你的问题和经验来。一般问题里找到全局极小确实很难，但是找到一个不那么差的解还是有可能的——前提是你要对这个问题做分析，用很好的初值。你不能两眼一抹黑，什么变量全用初始值为零去做，那根本就是在随机地找极小值，这是不对的。一定要找这个问题本身的物理意义，用有物理意义所对应的数值，那是最好的，因为至少有道理。

### 换个激活函数：万能逼近

用 RBF 这个函数解释完了什么叫神经网络，反过来看，神经网络也就没什么神秘：它就是一个函数，只不过是用一个激活函数去张成一个函数空间——一个函数通过一些构造，组合出一个函数空间。激活函数当然可以换，这几年用得比较多的就是 ReLU 这类函数。这里稍微说一下我的看法：这套东西的数学本质是在做逼近，只不过他们把它解释成"神经元"之类的抽象，我觉得那是很不严谨的；数学上它就是函数逼近，不必神化。

常用的这些激活函数都是递增的。递增有一个好处：靠平移、伸缩，同样能从它生成一整族函数；这一族函数彼此互补——你大的地方我可能小，我小的地方你很大——铺得开，所以它张成的空间就能够完备了。这就是所谓的万能逼近（universal approximation）：网络只要节点足够多，就有很强的逼近能力——你给我数据，我就可以来逼近你。

### 多变量与向量值：把函数搞明白就都不难

如果输入是高维的，就像刚才那个图一样，出现了好多 $x$——$x_1$ 到 $x_m$。那怎么组合？也挺简单：每个分量跟对应的权做点积——$x_1,\dots,x_m$ 连同那个常数 1，跟这组权相乘再求和，然后照样过那个单变量的激活函数。多维的点，还是通过这样的单变量函数去张成函数，我这里还是讲函数形式。

那我一定要问：如果 $y$ 也多个怎么办？这不可怕——$y_1$、$y_2$、$y_3$，每个 $y$ 都是同样的结构。输出很多维的叫向量值函数，后面下课就会讲。理解非常简单，你们不要觉得难，只不过就是你要把它分解。为什么我现在还是强调"我们在讲函数"？把函数搞明白了，多变量只不过是变量多了；多输出只不过是 $y$ 变成 $y_1,y_2,y_3$，每个 $y$ 都是一样的东西，怎么做都一样——网络共享基函数、共享权，性质就可以一样了。你只要研究一维就行了嘛，所以没什么难的。没必要自己给自己找麻烦：万一你拿多项式那套去硬搞向量值，你不制造麻烦吗？共享一下就好了，技术不一样而已。所以很容易，大家不要慌、不要着急，我们先把函数形式讲明白。

多变量、多元、向量值这些词，下周我会再剖析。这里先说一句要紧的：这方面你要是没理解，后面一上矩阵、张量就蒙了。矩阵和张量就是那些东西的一个表达方式，是用来表达的——它不是凭空产生的一个什么 $n\times n$ 的表，每个东西叫元素，里面有什么列变换、行变换——这应该从线性变换的角度上讲。

### 一层接一层：深度网络就是函数的复合

"层"是什么意思？把上面那套组合成一层，这一层我就可以给它变成一个矩阵形式，就可以给它接起来；接完之后它就是一个新的维数的输出，那我也可以继续接——这又是网络，可以再接网络。你这里接 100 层，就是 100 层的网络。从本质上来讲，这就是一个函数，只不过函数相互复合了；复合的时候你没有把它表达成嵌套的样子，就表达成了矩阵。所以它整个过程已经基本上全是一个线性变换——矩阵相乘——中间夹着激活。

那这个激活函数可以每一层选得不一样吗？当然可以，但不利于你去优化呀，所以一般人们就统一用同一个。

要留意规模。有些网络为了减少规模——规模就是这些网络中的权——你想想：这一层有 100 个节点，下一层有 100 个，交叉相乘 $100\times 100$，一层就是 1 万个变量了，这就是一层的节点个数带来的。变量一下子膨胀。变量膨胀是什么意思呢？它的表达能力就比较强。所以说用"深"的就会比"宽"的要来的好一点。

本质上你把它理解成函数，网络的这些玩法就很容易理解。为什么要去调参？就是调这些函数空间：结构就是空间，里面的参数个数就是它的自由度。为了减少自由度，就要对这些参数进行共享——参数共享了，变量就少了。

### 三部曲没变：神经网络的能与不能

网络里面有大量的参数，就是这里面的权。给一批采样点，把参数记作 $\theta$，你要求出这个 $\theta$。解出来以后，你这个网络就出来了；网络出来了，函数就出来了——就是去拟合、逼近目标函数。是不是跟我们一直做的三部曲一模一样？

```text
 选函数空间(结构+激活函数) --> 定误差/损失(+正则项) --> 优化求参数 theta
```

它为什么 work？就是我刚才讲的：只要足够深、节点足够多，数据也足够多，就可以逼近所有函数，跟那个 Weierstrass 定理一样的。

那请问你会碰到什么问题？网络结构怎么选？不好选吧。误差怎么定？也靠经验，没有标准答案怎么办？只能靠自己去建模。如果是非线性的话，就不好优化，你老老实实用那些迭代方法去搞。同样的问题、同样的挑战，一个都躲不掉。所以大家也不用自己去实现这种优化器：像神经网络的 backpropagation（BP），其实就是梯度下降法，只不过它把多层的优化变成一层一层地做，减少规模。

我们再一起回顾一下走到哪了。有些问题端到端挺难搞，那就在中间搞一些映射：先做映射，再做映射，再做映射——映射串起来叫级联；有的地方这个映射不够，就用特殊的映射过来再过来，搞些花招。要把每个映射都变成一个网络，为什么？因为它统一了所有的函数表达——就一个函数形式，表达所有东西。我们在以前的话，要去想到底用多项式、还是高斯、还是三角函数，这是根据人的感觉经验相关、跟问题相关；它这里很暴力：用一个函数全包。

比如图像处理里，我希望周边给像素平均一下——像素跟周围取平均，先抹掉一些噪声——这个操作就是一种特殊的运算，叫卷积；卷积完以后再去降维。所以所有这些，不管它怎么变换——卷积也好、不同的网络也好——在我们眼里都是函数，只不过函数变换里面有一些地方是有意义的，你的任务就是怎么去设计这串函数。

```text
 input ---> [映射1: 网络] ---> [映射2: 卷积] ---> [映射3: 网络] ---> output
```

网络加得很大，容易造成过拟合；那就要网络简化——剪枝——或者在损失函数上加各种各样的惩罚项、正则项。中间如果有一些所谓的特征，你知道它的几何意义，那就针对它再加一个惩罚项，或者叫做正则项；最后的误差就是损失加正则项。所以你可以看到，任何一篇文章拿来都在做这个事情。网络就是靠调嘛——有的说得出道理，有的真的说不出道理，就是指望采样样本足够多，把这个现象拟合住。

调参是不是纯碰运气？你看那张经典的图：同样是求解最小值，不同颜色是不同方法——有的很快冲到底，有的在上面摆一摆、晃一晃才下来。所以你去调参数要有耐心，当然也要有直觉：有直觉跟没直觉，调出来是不一样的。

### 回看作业：上周的困惑都有答案了

现在再来看作业里的那些现象。你们上周的那些困惑、那些迷惑、那些不安，今天基本都能找到答案了：$\sigma$ 取多少、曲线为什么一会儿瘦一会儿胖，前面已经讲明白了——只不过你现在是"调"出来的。已经有同学发现 $\sigma$ 靠经验取不好取，干脆把它当成参数去调，还做了个 UI——挺好，经验靠不住，就把它变成可调的变量。

有同学用多项式插值，出现了龙格现象——原因刚才解释了：次数一高，范德蒙行列式对应的条件数急剧上升，导致数值不稳定，所以拿高次幂基做插值不是个好的技术，你要用正交基才比较稳定。

有同学用了岭回归，$\lambda$ 取 0.01、0.1 这些值，可以看到正则由强到弱的变化。当然也提醒一句：大家没有必要什么都自己写，求解器可以直接调 MATLAB 这类现成工具，谁家的库都可以去调。只要能解决问题，这个就是好工具——没规定啥都要自己写，不要重复造轮子，我们要解决我们自己的问题。

我这里给大家演示一份比较好的报告。这位同学没有用真名，ID 叫 lxt，正好像个方程组：L 乘 x 等于 t。来看它的作业视频，写得非常好：点一个点，就能够马上算出那个插值函数；他现在用的是多项式拟合，左上角一切换成高斯，就发现 $\sigma$ 不对，先调到 28、再调到 36，不断调，后来调到 40；又大概试了一下样条（spline），参数可以自己设；又用了岭回归，这次调的是 $\lambda$。他做了一个非常好的 UI 界面，把所有方法都放在一块儿来看性质，还可以实时地增加交互点——你看这函数有好有坏。这样调有什么好处呢？我能看到结果。

但如果你是 100 维、1 万维、100 万的数据，再来调啥呀？你能看到的就是那个 loss function 的值。图里绿色、红色、蓝色的看着风险差不多，可是显然蓝色的比红色要好——光盯着 loss 你分不出来，两眼一抹黑，啥也不知道，那你就只能继续去调；有的可能调一个礼拜都调不出来。为什么？如果你懂它的本质、懂这个函数空间往哪个方向走，这些问题你才调得出来。

### 样条的初衷：从全局函数到局部控制

答疑时有同学问样条。给个启发，你自己想：我们到目前为止用的所有函数都是全局函数——动一个点，整条函数都要跟着动。能不能把它变成局部的：这个点的地方数据摆一摆，别的地方不受影响——这样是不是会更好一点？这就是我们做样条、讲样条的初衷。

课后很多同学说，终于明白神经网络在干嘛了。对，它就在做这个事情：函数逼近。只不过那个领域的人把神经网络变成了一个抽象，从那个角度上看，我个人觉得它是非常不严谨的；数学上它就是个逼近的工具，只不过这个空间的表达能力非常大而已。

### 本讲提到的题目

第二次作业已经发布，是第一次作业的延伸，练的就是本讲的神经网络（RBF 网络）：

- 核心任务：让 $\mu$ 和 $\sigma$ 也变成待优化的变量（做法见"把 σ 和 μ 变成待求的变量"一节），再跟前面固定参数的方法做个比较。
- RBF 网络因为是非线性的，所以要做到优化：能写一些简单优化器的可以自己写；用成熟软件里现成的优化去拟合同样没有问题——两条路都可以拿来跟我们的方法做比较。
- 走得快的同学再往前走一点：用神经网络框架去做。框架本身就是一个非常好的优化器——把网络设计好、数据给进去、把 loss function 定义好，它就帮你优化。推荐大家咬咬牙学一学课程推荐的框架，后面设计网络会更方便；虽然它对 Windows、VS2019 这些环境有些要求，机器实在不匹配的话，用其他框架也没问题，现阶段可以先尝试一下。
- 截止时间仍然是礼拜六晚上（按东八区）。第一梯队没跟上的同学可以继续补交，课程会一直开放；我们都有参考代码和参考文档，你们可以朝着这些目标去逼近。

解析：这道作业的全部依据都在正文里——固定 $\sigma$、$\mu$ 时，拟合是线性的、好解；把它们变成 $a_i$、$b_i$ 之后，问题变成了非线性优化，所以正文才强调初值要按物理意义来取、优化只能保证局部极小。让"参数定死"与"参数交给优化器"两条路线同台比较，正好体会本讲最核心的那个思想。
