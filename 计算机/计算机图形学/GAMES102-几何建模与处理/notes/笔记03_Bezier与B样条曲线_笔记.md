# Bezier与B样条曲线

## 重建与设计

* **重建（reconstruction）**

    * > **定义**：对象已经存在，采集采样点、猜测其函数形式与基函数类型，再用理论方法把外形拟合出来；扫描建模属于这一类。

    * 背景是逆向工程：不知道产品曲面（如发动机叶片、铸造成型的机械零件）的表达就没法制造，于是购买实物、在其表面采点勾勒轮廓来仿造；这只是外形模仿，性能是另一回事。

    * 落到数学上就是拟合：函数（单变量曲线）可看成参数化、多元情形的特例，而实际造型要处理的是参数形式的对象，从表面采到的点出发把形状做出来。

* **设计（design）**

    * > **定义**：对象只存在于设计师头脑中，从一个简单形状（如圆）出发靠交互编辑把它"做"出来；设计师可能参考他人，更多凭自己的设计美学与工程经验。

    * 对工具的要求：交互式、直观性非常好——用少量的点就能控制曲线，$t$ 从 0 变到 1，曲线一个点一个点出来形成光滑曲线；前提是基函数非常好、非常直观。

* **同一表达式的两种观点**

    * 代数观点：基函数固定，从函数集合（函数池子）里找系数——二次函数 $f(t)=at^2+bt+c$ 用"好函数"的度量把 $a,b,c$ 求出来，就是拟合。

    * 几何观点：顶点由用户直接给定，把基函数看成组合这些顶点的权系数；基函数的特性决定曲线的特性。

    * 参数形式下 $x(t),y(t)$ 各有一组系数，联立起来基函数前的系数恰好是空间中的一个点（一个分量管 $x$、一个分量管 $y$），能表达的范围比单值函数广一点。

    * 幂函数基的麻烦：没有几何意义，曲线跟顶点"没什么关系"；拖动一个系数点，曲线可能一下子变得很大、完全变成另一个样子，交互毫无直观。

    * 做设计时基函数的选择决定交互直观性——幂基不直观，就要换成有几何意义的基。

## Bernstein基

* **伯恩斯坦基（Bernstein 基）**

    * > **定义**：$B_i^n(t) = \binom{n}{i}\,t^i\,(1-t)^{n-i}$，$i = 0, 1, \dots, n$；两个幂的次数之和为 $n$，整体是 $t$ 的 $n$ 次多项式，$\binom{n}{i}$ 是组合系数（旧写法 $C_n^i$，即"从 $n$ 个里拿 $i$ 个"）。

    * 记号：上标 $n$ 表示次数、下标 $i$ 表示第几个；$n$ 次共有 $n+1$ 个基函数，与幂基 $1,t,\dots,t^n$ 的个数一样。

    * 与幂基张成同一个不高于 $n$ 次多项式的空间：任一 Bernstein 基函数都能写成幂基的组合，幂基也能由 Bernstein 基表达；两个基维数相同，转化矩阵可逆。

    * 历史：Bernstein 基在数学上已存在几百年；上世纪五六十年代法国雷诺公司的工程师 Bézier 把它用于汽车设计，人们为纪念这个发现把曲线命名为贝塞尔曲线，但基函数仍叫 Bernstein 基。

    * 低阶形态（限定在 $[0,1]$ 上）：0 次是常值函数 $1$；1 次是 $1-t$、$t$ 两条直线；2 次三条；3 次四条（$b_0,b_1,b_2,b_3$）。

* **二次形式的直观性**

    * $$P(t) = (1-t)^2\,p_0 + 2t(1-t)\,p_1 + t^2\,p_2$$

    * 三个基函数仍是二次的，但顶点系数与曲线高度相关——一头、一尾、一中间刚好就是这三个点；控制多边形什么样子，曲线就体现成什么样子，高次同理。

    * 中间的点往哪儿拖，曲线就往哪儿多翘一点；很容易用一个程序做起来。

## 贝塞尔曲线的定义

* **控制顶点与控制多边形（control polygon）**

    * > **定义**：给定 $n+1$ 个点 $p_0,\dots,p_n$，它们控制着曲线的形状，叫控制顶点；按顺序连成的折线叫控制多边形；用 Bernstein 基组合控制顶点得到的光滑曲线就是贝塞尔曲线。

    $$P(t) = \sum_{i=0}^{n} p_i\,B_i^n(t), \qquad t \in [0,1]$$

    * 几何读法：取定一个 $t$（$0, 0.1, 0.2,\dots$），$n+1$ 个基函数值生成 $n+1$ 个权，由这些点组合出一个点；$t$ 从 0 到 1 连续变化，这些点拼成一条曲线——曲线上任何一点都是这组点在某个 $t$ 时刻的加权组合。

    * 曲线的性质来源于基函数的性质：顶点是用户看得到、用来交互的东西，基函数对曲线形态起关键作用；在这个形式之上构造其他基函数（如让曲线更贴近控制多边形）的工作都循同一道理。

* **三次曲线形态对照**

    * 控制多边形的样子基本决定曲线表现：

    | 控制多边形的样子 | 曲线的表现 |
    | :--- | :--- |
    | 平顺排布的四个点 | 一条光顺的曲线段 |
    | 多边形中间折了一下 | 曲线随之可能出现拐点 |
    | 四个控制顶点共线 | 曲线退化为 $p_0$ 到 $p_3$ 的这条线段 |
    | $p_0p_1$ 与 $p_2p_3$ 交叉排布 | 曲线可能出现自交 |

* **推广**

    * 复杂形状用多段拼接生成：如瓶子轮廓侧面算一段、顶面算一段，段与段之间做到 $C^0$ 光滑衔接。

    * 单参数下三维只是 $x(t),y(t),z(t)$ 三个分量，形式仍是 $\sum p_i b_i(t)$，$p_i$ 是空间中的点，性质照样可以讨论；四维、五维中的单参数对象本质上都是一维的，定义的都是曲线。

## 贝塞尔曲线的性质

### 基函数层面的性质

* **对称性与最大值位置**

    * 第 $i$ 个与第 $n-i$ 个基函数完全一样，关于区间中点对称——因为 $t$ 与 $1-t$ 刚好关于中点对称。

    * 最大值位置：第 0 个在 $t=0$，第 $n$ 个在 $t=1$，中间第 $i$ 个在 $t=i/n$，沿参数轴分布比较均匀。

* **正性与权性**

    * 正性：所有基函数在 $[0,1]$ 上都在零之上（非负），从表达式直接就能看出来。

    * 权（weight）：任取 $t\in[0,1]$，$n+1$ 个基函数值之和恒等于 1；权和为 1 叫归一性——权性是凸包性的直接前提。

* **递推式**

    * $$B_i^n(t) = (1-t)\,B_i^{n-1}(t) + t\,B_{i-1}^{n-1}(t)$$

    * $n$ 阶基函数由两个相邻的 $n-1$ 阶基函数加权而来：提升过程带着变量 $t$，次数一定会提高一阶；正性保持，光滑性也提高（乘 $t$ 以后再求导，导数的项会多一些）。

    * 用途：算东西时可以让计算量降下来；也是 de Casteljau 算法的出发点。

### 曲线层面的性质

* **凸包性（convex hull property）**

    * 正性 + 权性 ⇒ 曲线上的点是控制顶点非常规整的、归一化的加权平均（凸组合）；无论控制多边形怎么分布、次数多高，曲线永远落在控制多边形的凸包之内。

* **端点插值**

    * $t=0$ 时除第 0 个基函数等于 1 外其余全为 0，$t=1$ 时只有最后一个基函数等于 1——无论次数多高，起点必是 $p_0$、终点必是 $p_n$，曲线"手握"一头一尾两个点。

    * 实际用得最多的是两条：端点插值，以及切线要沿着"手握"的那两条边。

* **端点导数的几何意义（三次为例）**

    * 一阶导：$f'(0)=3\,(p_1-p_0)$、$f'(1)=3\,(p_3-p_2)$——端点切线方向与第一条边、最后一条边完全重合，大小是邻边长度的三倍。

    * 二阶导：$f''(0)=6\,(p_2-2p_1+p_0)$，而 $p_2-2p_1+p_0=2\left(\frac{p_0+p_2}{2}-p_1\right)$，方向由 $p_1$ 指向 $p_0,p_2$ 的中点；终点处 $f''(1)=6\,(p_3-2p_2+p_1)$，方向由 $p_2$ 指向 $p_1,p_3$ 的中点。

## 升阶与降阶

* **升阶**

    * 做法：每条边上按比例加一个顶点——本来四个顶点定义一条三次曲线，每边多出一个点后得到五个新顶点，它们定义的四次曲线与原来四个点生成的三次曲线一模一样。

    * 升阶只增加控制顶点的个数、曲线保持不变；同样地不断递归，可以升到五阶、六阶、七阶、八阶。

    * 本质次数：由低阶升阶上来的曲线，真正的次数就是那个低阶的次数——"五个顶点定义的四次曲线"本质是三阶。

* **降阶**

    * 动机：曲线表面次比较高，为节省存储希望次数越低越好，所以有很多人去做降阶；具体方法长文未说明。

## de Casteljau算法

* **de Casteljau 算法**

    * > **定义**：把基函数递推式中的基函数换成顶点，得到纯粹关于顶点的组合：任取 $t\in[0,1]$（如 $1/3$、$1/2$），把相邻两顶点按 $(1-t):t$ 线性组合得新一列点，对新点列重复同样操作，三次曲线做三轮，最后剩下的唯一点一定是曲线在当前 $t$ 处的位置。

    * 递推图（每个新点 = $(1-t)\times$ 左点 $+\ t\times$ 右点）：

    ```text
    p0        p1        p2        p3        (第0层：控制顶点)
       \       /  \      /  \      /
        p01       p12       p23           (第1层：两两组合)
           \      /   \      /
            p012      p123                 (第2层)
                \    /
                p0123                       (第3层)  <== 曲线在 t 处的点 P(t)
    ```

    * 整个算法每一步都是线性组合：算起来非常快，数值上非常稳定（线性组合不会造成太多误差积累），时间开销与空间占用都不大。

* **剖分性质**

    * 求得的点把曲线分成两段：左段是一条三次贝塞尔曲线，控制顶点为三角形左下边缘那一串 $p_0,p_{01},p_{012},p_{0123}$；右段控制顶点为 $p_{0123},p_{123},p_{23},p_3$——不仅求到了曲线上的一个点，还把左右两段贝塞尔曲线的控制顶点都求出来了。

    * 剖分的比例跟 $t$ 绑定：$t$ 取 $1/2$ 就按 1/2 剖，取 $1/3$ 剖分过程始终用 $1/3$，取 $2/3$ 得到的是另一番剖分。

* **切线性质**

    * 最后那条边（$p_{012}$ 到 $p_{123}$ 的连线）跟曲线在这个点相切，就是曲线在该点的切线；$t=1/2$ 时这个点恰好是这条边的中点，两边等长——这个连续性直接就有了。

* **边界与延伸**

    * 一次给定一个 $t$ 只能算一个点：画曲线要写循环采样，步长取 0.1 得十个点连起来，步长取 0.01 得一百个点、画得更密；历史上还有研究"一次同时算 n 个点"的算法。

    * 深入研究的两个用处：把曲线离散成多边形（采点画图本来就在做这件事）、求多项式的根等。

## 分段贝塞尔曲线的拼接

* **分段插值的构成**

    * 给 $k$ 个数据点生成中间插值的分段样条：每两个相邻点之间用一条三次贝塞尔曲线——一头一尾取数据点，中间两个控制点待定；下一段照此办理。

    * 每段的中间点受两重约束：段与段在公共点处要保证一定的光滑性，待定点须满足拼接条件。

### 拼接连续性条件

* **$C^0$**

    * 只要公共点固定、两边共用同一个点，两条曲线一定在这里拼牢——非常自然就满足。

* **$C^1$**

    * 条件：两侧待定控制点与公共点三点共线，且公共点是两个待定控制点的中点（两条邻边等长）。

    * 原因：贝塞尔曲线在端点的切线是相邻边的三倍（三次的情形），两边切线的"三倍"可以约掉，所以共线保证方向相同之外，还必须两条邻边等长。

* **$G^1$（几何连续）**

    * 只需三点共线、切线方向一样，长度可以不一样——条件比 $C^1$ 弱，但设计上多出自由度；从 $C^1$ 改成 $G^1$ 是很容易的改法。

* **$C^2$**

    * 用二阶导数的"中点"几何意义也能推出来：推导中会看到两个三角形相似、甚至全等（那两条边本来就一样）；判断条件时相邻的三点都要拿来做考虑，变量就多一些。

    * 具体的 $C^2$ 条件长文未说明，可带走的方法是"把几何意义找到"。

### 平行1/6构造

* **构造方法**

    * 设数据点 $p_1,p_2,p_3,p_4$，构造 $p_2$ 到 $p_3$ 这一段，两个待定控制点完全由相邻数据点的弦方向定出：

    $$b_1 = p_2 + \frac{1}{6}\,(p_3 - p_1), \qquad b_2 = p_3 - \frac{1}{6}\,(p_4 - p_2)$$

    * $b_1$ 从 $p_2$ 出发、方向平行于 $p_1$ 到 $p_3$ 的弦、长度取该弦长的 $1/6$；$b_2$ 从 $p_3$ 回退、方向平行于 $p_2$ 到 $p_4$、长度也取 $1/6$——不需要解任何方程组。

* **性质与优势**

    * 公共点两侧控制点的偏移量恰好相等，中点条件自动满足，天然达到 $C^1$；对照拼接条件还可以自己注意离 $C^2$ 还差什么——可以证明它甚至有可能达到 $C^2$。

    * 最好的地方是局部性：每一段都由相邻的四个点决定，很远的点跟这段曲线没有关系；对比解全局（global）方程组的整体做法——顶点稍微动一下，整个方程组要重新求解，不利于设计。

    * 插值构造中"曲线开头第一、第二个控制点怎么定"可以随意——中间的点受约束，一头一尾跟样条一样留有自由度，切线方向自己调。

## 样条的概念

* **样条（spline）**

    * 词源：绘图时用一根弹性木条压过各个点，弯出来的形状就叫样条；它天然具有分段三次的特性，所以现在把分段多项式曲线——包括分段贝塞尔曲线——都叫做样条。

    * 概念可以放得很宽：一条曲线里有些是光滑段、有些是直线段、有些甚至只有 $C^0$ 连续，都可以把它看成样条；甚至一个多边形也是样条——多边形就是一次的分段多项式。

    * > **易错点**：分段构造拼出来的"样条"与整体意义下的样条（整体光滑、$C^2$ 连续）不是同一个概念；分段贝塞尔要满足 $C^2$ 比较难，$C^2$ 需要一个全局的方法。

## 全局性问题与局部性

* **Bezier 的全局性**

    * > **定义**：基函数族在 $[0,1]$ 区间内部处处不取零——每个基函数都从头到尾全程参与；注意是 $[0,1]$ 之内全局，不是整个实数轴（原来定义在 $a,b$ 之间的问题也可以规范化到 $[0,1]$）。

    * 后果：中间任何一个控制顶点哪怕只做一点小小的改动，这个改动就会通过基函数传遍整条曲线——离得远的部分动得比较小，但它毕竟在动，整条曲线都在变。

    * 同一现象在神经网络拟合里早就碰到：sigmoid 也好、RBF 也好用的同样是全局基函数，网络一旦有新数据更新就得整个重新拟合；要是能用局部基函数，更新就不必全局做，只需更新一部分。

* **局部性目标**

    * 设计要求"改哪儿动哪儿"：别的部分已经设计好、只想局部修改这一块时，没理由让很大一片甚至全局跟着动；真正的局部性是这一块修改时，旁边那两段保证没有任何修改——因为它们是局部定义的。

    * 数学家更深的问题：分段表达不必一段一段写六个函数，能不能用一个自带分段性质的函数统一表达？——必须从基函数的局部支撑性质入手来构造，正性、权性这些也得保住；这套理论 60 年代就有了，后来被用到工程设计中去。

## B样条的构造蓝图

* **基本样条（B-spline）**

    * B 是 Basic 的简写——基本样条；数学里的 B 样条与那根木头样条干的是同一件事，所以也叫样条。

    * 在计算机领域，样条 50 年代就开始用了；到 70 年代，它变成计算几何里一个非常标准的曲线设计方法。

* **构造蓝图**

    * 灵感来自 Bernstein 递推式：两个低阶基函数，一个乘上 $1-t$、一个乘上 $t$，线性组合起来次数就升一阶，而且每升一阶光滑性还跟着提高。

    * 照葫芦画瓢造"局部"：在每个局部位置定义基函数，让一个基函数沿着节点一次次平移，再通过这样的乘法逐级升阶；平移过程中基函数的形状跟节点之间的距离有关系。

    * 与神经网络对照：相当于把 RBF 那样的"激活函数"平移一下（铺到各个位置）、伸缩一下（宽度由节点决定），它跟它组合出一个个新基函数。

    * 因为基函数有局部性，所以曲线具有"局部可控"的性质——改哪儿，动哪儿。

* **节点向量（knot vector）与 de Boor 顶点**

    * > **定义**：节点向量是一串从小到大排的参数值 $t_0 \le t_1 \le \cdots$，它给每个控制顶点配上位置参数（这个点配 $t_0$、那个点配 $t_i$）；基函数就按节点向量来定义——每个基函数定义在相邻的几个节点上，只不过是一个个平移过去。

    * 控制顶点也可以叫 de Boor 顶点；参数化简单一点用均匀参数化，复杂一点可以用弦长参数化或者向心参数化。

    * 均匀节点（uniform）：每个控制顶点对应的参数间隔一样，实际上就是均匀参数化；也可以用弧长来定节点，节点值可以是 $-1,0,1,2,3$ 这样一串数。

## 从分段常数到帽子函数

* **递推构造**

    * 最底下这层是分段常数（0 次）：在某个节点区间内取 1，出了这个区间就是 0，画出来是一段段水平直线。

    * 取相邻的两个分段常数，一个乘 $1-t$、一个乘 $t$，加起来——得到一个先爬坡再下坡的帽子函数；接着再取两个相邻的帽子函数同样组合出 2 次的；二次再这么乘变成 3 次……一路递推上去。

    * 光滑性一步步变好：分段常数在节点处有跳跃；帽子函数已经是 $C^0$ 连续；再升一阶，就成了光滑的函数。

    * 形状：所有 B 样条基函数长得都像帽子，有点像高斯函数但不完全是高斯；只不过阶数越高，跨度越大。

* **支撑跨度规律**

    * 每升一阶，基函数的支撑跨度就多一个节点区间——原因藏在乘法里，每升一阶就多"吃"进一个节点区间，紧支集一步步扩大：

    | 阶数 $k$ | 次数 | 非零（支撑）区间 | 跨越的节点区间数 |
    | :---: | :---: | :---: | :---: |
    | 1 | 0 次 | $[t_i,\ t_{i+1}]$ | 1 |
    | 2 | 1 次 | $[t_i,\ t_{i+2}]$ | 2 |
    | 3 | 2 次 | $[t_i,\ t_{i+3}]$ | 3 |
    | 4 | 3 次 | $[t_i,\ t_{i+4}]$ | 4 |

* **递归定义**

    * B 样条的定义方式有好几种（比如通过差商来定义），通行的递归定义以分段常数为起点，高阶基函数由两个低一阶的相邻基函数线性组合而成（组合系数可以由权性反推）：

    $$N_{i,1}(t)=\begin{cases}1, & t_i \le t < t_{i+1}\\ 0, & \text{其他}\end{cases}$$

    $$N_{i,k}(t)=\frac{t-t_i}{t_{i+k-1}-t_i}\,N_{i,k-1}(t)+\frac{t_{i+k}-t}{t_{i+k}-t_{i+1}}\,N_{i+1,k-1}(t)$$

    * 节点等距时，它就退化成均匀节点的帽子；非均匀节点（节点不必等距）把 $t_0,t_1,\dots,t_n,\dots,t_{n+k}$ 这一串统称节点向量，定义方式完全一样。

    * 组合系数记忆规律：分母里出现的下标，一定能在分子里找到同伴——第一个系数分母下标是 $i$ 与 $i+k-1$，分子 $t-t_i$ 正好跟其中一个对上；第二个系数分母下标是 $i+1$ 与 $i+k$，分子 $t_{i+k}-t$ 又跟其中一个对上。

    * > **易错点**：$N_{i,k}$ 里 $k$ 是"阶数"，对应的多项式次数是 $k-1$；第一个下标 $i$ 表示从哪个节点起步——两套数字别搅在一起。

## B样条基函数的性质

* **局部支撑与紧支集**

    * > **定义**：基函数只在一段有限区间上非零、其余处处为零，这段非零区间就叫它的紧支集。

    * $N_{i,k}$ 的非零区间是 $[t_i,\ t_{i+k}]$；此外无论 $t < t_i$ 还是 $t > t_{i+k}$，取值都是零——由递推式可证每个基函数都局部支撑，这正是构造它的初衷。

* **权性**

    * 在参数轴上任取一点，会有若干个基函数（它们是一个个往右平移的）"经过"它；把这些非零值全部相加，一定等于 1——无论点取在哪里。

    * 递归公式里那两个组合系数，就是由权性倒推出来的。

* **光滑性**

    * 在节点拼接处，$k$ 阶基函数具有 $C^{k-2}$ 的连续性；整条曲线段与段在公共节点处拼接，拼接处同样具有 $C^{k-2}$ 的连续性（五阶就是 $C^3$）。

## B样条曲线

* **定义与凸包**

    * $$P(t)=\sum_{i=0}^{n} d_i\,N_{i,k}(t)$$

    * 顶点 $d_i$ 叫控制顶点，也叫 de Boor 顶点；形式跟 Bezier 一模一样——还是"基函数乘上顶点再求和"；与 RBF 对比：RBF 逼近一个点靠的是全局的高斯基函数叠加，这里换成了局部支撑的 B 样条基。

    * 因为基函数非负而且和为一（权性），曲线上每个点都是相邻控制顶点的加权平均，落在它们围出的范围里——跟 Bezier 一样的凸包性质。

* **分段结构与滑动窗口**

    * 每一段曲线由相邻的 $k$ 个控制顶点定义（五阶就是相邻 5 个，四阶（三次）就是相邻 4 个）；控制多边形是一条，但这条曲线本质上是分段的。

    * 窗口示意（每段只由窗口里的那几个顶点加权决定，窗口每往右平移一个顶点，就多出一段）：

    ```text
    控制顶点:   d0   d1   d2   d3   d4   d5   d6
    第一段:   [ d0   d1   d2   d3   d4 ]
    第二段:        [ d1   d2   d3   d4   d5 ]
    第三段:             [ d2   d3   d4   d5   d6 ]
    ```

    * 六个顶点 $d_0\sim d_5$ 就能连出首尾相接的两段：$d_0\sim d_4$ 定第一段、$d_1\sim d_5$ 定第二段；如果还有 $d_6$，$d_2\sim d_6$ 定第三段。

    * 每段是 $k-1$ 次的多项式曲线；一条分段多项式曲线由此被表达成一个统一的、非常漂亮的形式——"分段"从此有了统一的写法。

* **局部修改的威力**

    * 把一个控制顶点拖走，曲线跟着变形，但远处的那些段一模一样、纹丝不动——理论上保证绝对不动，因为它已经远离了这个顶点的影响区间。

    * 受影响的段数由阶数决定；用户要修改哪一段，就去拖那附近的顶点；而且不管怎么拖，它仍然是一条整体曲线。

    * 迁移到神经网络：把 sigmoid 这种全局基函数换成局部基，网络拟合好之后源头来了新数据，只需更新新数据所对应的附近那几个基函数，不用整个网络重新训练——性质现成，但到高维还会遇到很多困难，目前仍是一个 open problem。

## 重节点

* **连续性降阶（reduced continuity）**

    * 节点向量里那串参数是可以重合的；一旦有节点重合，曲线在该处的光滑性就降一阶，再重合、再降。

    * > **定义**：节点重数为 $l$ 时，该处连续性降为 $C^{k-l-1}$（$k$ 为阶数），这就是连续性降阶；要控制曲线在某处的光滑性，拧"节点重数"这个旋钮就行。

    * 五阶实例：简单节点处是 $C^3$，两重降为 $C^2$，三重降到 $C^1$，四重就只剩 $C^0$。

    * 设计用法：某一处只要低阶连续、甚至要一个尖点（$C^0$、不光滑），就把对应节点的重数提上去——三次曲线把节点重数设成三重，那里就是 $C^0$ 尖点；让 $t_3=t_4$ 两个节点重叠，拼接点的光滑性就变了。

    * 合起来的设计能力：一条曲线能同时装下大部分光滑段、一个尖点和一段直线段——只要每一段都是多项式，它就是样条；光滑的、分段光滑的、连续但不光滑的都能灵活地融进同一条曲线。

* **端点插值与 Bernstein 退化**

    * 拿四个点构造一段三次曲线时，首末那两个点并不被曲线插值（曲线不正好经过它们）。

    * 把端点节点的重数设成 $k$ 重，重数一高，端部基函数就退化为 Bernstein 基，曲线就插值端点了；反过来，端点节点不重合，端点就不插值——端点的行为全靠重节点来调。

* **与Bezier的统一**

    * 只要一个节点区间两端的节点重数都达到 $k-1$，这一段就是一段 Bezier 曲线——样条本质上就是分段的 Bezier，靠节点向量的重数就能把它"捏"出来。

## B样条的能力边界

* **插值要反解控制多边形**

    * 给定一批数据点、想让 B 样条曲线插值它们时，控制顶点是未知的，要反解出来，涉及解方程、未知量很多；好消息是规模不再跟着整条曲线走，而是分段的——每一段解一个方程，规模就不算特别大。

* **表达不了圆**

    * 用 Bezier 表达不了圆弧：拿多边形去逼近终究是逼近，多项式曲线表达不出精确的圆弧（证明并不难）；B 样条同样表达不了圆，或者退一步的一段圆弧。

    * 出路是"有理"——要除上一个分母；有理事实上是射影几何的语言：从仿射空间到射影空间，与"平移变成齐次坐标"是同一类概念，换到那个空间里圆就可以精确表达了。

    * 非均匀有理 B 样条（NURBS）就是工业的标准：工业界设计飞机、轮船的曲面甚至设计字体统一都用它——因为它既能表达圆，又能表达直线，还能表达多项式曲线。

* **调控手段**

    * 可以调控制顶点，可以调节点向量（含重数）；将来学有理 B 样条，还可以调权函数，权对曲线同样有影响——3d max、Maya 这些软件里碰到的许多参数，对应的正是它们。

* **其余工具**

    * 其他性质跟 Bezier 一样丰富：有导数递推、基函数递推，还有几何方法、作图法。

    * 节点插入算法：不断往节点向量里插节点，形式上也是一个递推；要真正搞明白甚至写程序，还得看不少东西。
