# GAMES102：几何建模与处理（15 讲）

GAMES102 讲几何建模与处理：从数据拟合与三次样条出发，到 Bezier/B 样条/NURBS、细分与隐式曲线，再进入离散微分几何与微分坐标，最后覆盖曲面去噪、参数化、几何映射与曲面重建。课程把「表示—分析—处理」这条几何处理主线走完。15 集整编为 6 册、11 篇主题笔记。

## 怎么学
- **拟合 → 样条 → Bezier/B 样条 → NURBS 是第一条主线**，按顺序学。
- **多动手画曲线**：de Casteljau、基函数、控制点的影响，画一遍比看十遍强。
- **离散微分几何是分水岭**：拉普拉斯算子、微分坐标，后面的去噪、形变、参数化全靠它。
- **几何处理四件套连着看**：去噪 → 参数化 → 映射/优化 → 重建。
- **每册的关键推导自己走一遍**：最小二乘、能量最小化、泊松方程。
