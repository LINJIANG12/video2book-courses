# GAMES104：现代游戏引擎——从入门到实践（37 讲）

GAMES104 是王希的现代游戏引擎课：从引擎导论与分层架构、游戏世界构建、渲染实践与光材质数学、渲染管线与后处理、动画、物理、粒子与音效、工具链、Gameplay、网络架构，到面向数据编程（ECS）、动态全局光照 Lumen 与 GPU 驱动几何管线（Nanite），并附 Piccolo 引擎源码解读与番外。37 集整编为 14 册、20 篇主题笔记。

- **原视频**：[GAMES104-现代游戏引擎：从入门到实践](https://www.bilibili.com/video/BV1oU4y1R7Km/) — Bilibili，BV1oU4y1R7Km
- **全 37 集**，已产出 14 册模块全书、20 篇复习笔记、60 份逐字稿
- 全 60 块已完整成稿

## 怎么学
- **先看架构分层与世界构建**，建立「引擎由哪些系统组成」的地图。
- **渲染四册（光材质/管线/地形大气云/前沿）按管线顺序读**。
- **动画、物理、粒子音效按子系统各取所需**。
- **Gameplay 与网络两段偏工程**，配合自己熟悉的引擎对照看。
- **ECS 与 Lumen/Nanite 是当代引擎的关键演进**，值得反复读。
- **Piccolo 源码解读配合代码看**，把前面的架构落到真实工程。
