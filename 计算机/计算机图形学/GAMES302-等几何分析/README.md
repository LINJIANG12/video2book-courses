# GAMES302：等几何分析（12 讲）

GAMES302 讲等几何分析（IGA）：从 CAE 与样条建模基础、有限元与计算域参数化，到等几何求解泊松/线弹性/超弹性、形状优化与拓扑优化，再到体细分建模-仿真-优化一体化框架与深度学习等几何分析。核心思想是让几何表示与分析基函数统一，省掉网格化这一环。12 集整编为 4 册、6 篇主题笔记。

- **原视频**：[GAMES302-等几何分析](https://www.bilibili.com/video/BV1dM4y117PS/) — Bilibili，BV1dM4y117PS
- **全 12 集**，已产出 4 册模块全书、6 篇复习笔记、22 份逐字稿
- 全 22 块已完整成稿

## 怎么学
- **先懂有限元再看 IGA**：区别在「用样条基代替拉格朗日基」。
- **样条建模基础要打牢**：B 样条/NURBS/细分。
- **参数化质量决定求解质量**，计算域参数化单独练。
- **优化部分对照形状导数与拓扑优化**。
- **一体化框架与深度学习部分当前沿看**。
