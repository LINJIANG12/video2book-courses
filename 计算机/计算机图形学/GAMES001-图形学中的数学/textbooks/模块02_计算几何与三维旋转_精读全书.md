## 计算几何：点线面的表示与位置判定
> 对应块：BLK06 | 覆盖分集：P03上 | 块标题（分集名）：《计算几何》

今天我们进入一个比较轻松愉快的话题——计算几何。这一讲从头到尾不会出现代码，只讲算法，以及一些最基础的解析几何知识；内容也不会再像前两节课那样需要将近两个小时，现在应该可以准时下课——我希望如此。

### 从 OI 到图形学：计算几何是什么

有过信息学竞赛（OI）或者大学生程序设计竞赛经验的同学，对计算几何应该都不陌生。图形学当中的计算几何，和 OI 里的计算几何之间有一定的关系，也有一定的区别，但区别并不是很大。最主要的区别在于：图形学的计算几何在三维问题上会比 OI 有更多的要求，而二维计算几何仍然是三维计算几何的基础。所以今天的思路是：拿 OI 中的计算几何，去解决图形学所关心的问题——OI 里那些比较偏门的算法不讲，同时扩充一些三维的知识，核心放在「如何把二维的计算几何拓展到三维」这个问题上。

先把这门学问的身份说清楚：计算几何从本质上说不是数学——虽然它被放在「图形学中的数学」这门课里，但它其实是计算机科学下的一个研究分支；甚至更进一步说，它就是图形学的一个研究分支。只是它所用到的东西，是直接接触到数学的。

计算几何的历史到现在并不特别久，大概也就 50 多年。它关心的是那些解决几何问题的算法——三角剖分、凸包、扫描线，这些都属于计算几何。相比于别的算法，它的特点主要在于：它需要处理实数而不是整数，并且需要关心向量。当然，这个向量和我们线性代数基础里讲的那种高维向量不同，它主要指的是低维向量——关心的是低维向量，而不是标量。

> **结论**：为什么需要计算几何这样一个研究分支？主要是我们希望在计算机中，降低解决几何问题的**复杂度**和**数值误差**。

今天主要关心第一部分，也就是如何降低在计算机中解决几何问题的复杂度。数值误差的部分，会有别的更专业的课程去讲解，而且它也超出了「图形学中的数学」这个范畴。

### 坐标系与左右手系

要表示点、线、面这些最基本的几何体，首先要确定坐标系。坐标系由**原点**和**坐标轴**构成。原点的选取理论上是任意的，所以真正要关心的点在于如何选取坐标轴。按照线性代数基础课里讲的内容，我们希望选出来的坐标轴尽量是**单位正交**的——因为单位正交的基底下，内积会非常好算。把单位正交基底构成的坐标轴叫做笛卡尔坐标；三维的笛卡尔坐标，就是 X、Y、Z 这三个轴。

这里有个实用的小窍门：一般情况下，XYZ 三个轴正好和 RGB 三种颜色对应。所以当你看到一个图形学应用没有标谁是 X、谁是 Y、谁是 Z，但给你画了红线、绿线、蓝线，那么颜色就确定了这套软件的 XYZ 是怎样排布的。

下面以列举的形式，给出常用图形学软件的坐标系约定：

| 代表软件 | 竖直轴 | 手性 | 轴向细节 |
| :--- | :--- | :--- | :--- |
| Houdini、Maya | Y 轴 | 右手系 | X 指向屏幕右侧，Y 指向屏幕上方，Z 垂直屏幕朝外 |
| Unity3D | Y 轴 | 左手系 | 与上一种唯一的区别：Z 垂直屏幕朝内 |
| Blender | Z 轴 | 右手系 | Z 指向屏幕上方，Y 垂直屏幕朝内 |
| Unreal | Z 轴 | 左手系 | Z 轴竖直 |

这四种坐标系都有极具代表性的图形应用——Houdini、Unity、Blender、Unreal，它们竟然全都不一样。所以大家在使用这些图形学软件的时候，一定要先搞清楚它们的坐标轴到底是按照什么方向选取的。

更底层的 API 也有类似的情况：一般情况下我们默认 OpenGL 是右手系，D3D 是左手系。但这并不是说 API 内部规定了这些，而是它们官方实现的一些库做了如上的假设，所以我们一般这么认为。

至于到底什么叫右手系、什么叫左手系——用握拳的方法来辨别。左手握拳，让除拇指以外的四指从 X 方向往 Y 方向转，此时拇指的朝向就是 Z 轴方向；右手同理：右手握拳、四指从 X 往 Y 转，拇指指向的方向就是 Z 轴方向。这就是左手系和右手系的确定方式。除此以外还有用三个手指的做法，但至少我个人握起来不是非常舒服，所以我比较推荐这种握拳确定法。

### 点、向量与直线的表示

确定了坐标系，就可以定义点了。一般情况下，点可以和向量等同使用，因为它可以看成从原点到这个点的位置向量。不过在很多图形学使用的 API 或者第三方库里，会把点和矢量的概念区分开，定义两种不同的数据结构：一种叫 point，一种叫 vector。此时它们会对运算做严格的规定：

| 运算 | 结果 |
| :--- | :--- |
| point − point | vector |
| point + point | 未定义 |
| point ± vector | point |
| vector ± point | 未定义 |

使用这些库的时候，要提前看一下它是否采用了这样的规定。

有了点，就可以定义线。无论二维还是三维，直线或射线都可以定义为：从一个点出发，沿着某个方向向量，并且有一个参数 $t$——如此用参数方程来规定：

$$\boldsymbol{X} = \boldsymbol{P} + t\,\boldsymbol{D}$$

直线和射线唯一的区别在于 $t$ 的取值范围：直线取 $(-\infty, +\infty)$，射线取 $[0, +\infty)$。

> **易错点**：对直线来说，$\boldsymbol{P}$ 可以是它上面的任何一个点；对射线来说，$\boldsymbol{P}$ 必须是射线发射的端点。

线段就是有两个端点的所谓「直线」，定义方法也是类似的。设两个端点为 $\boldsymbol{P}_1$、$\boldsymbol{P}_2$，很容易写出它的参数方程：

$$\boldsymbol{X} = \boldsymbol{P}_1 + t\,(\boldsymbol{P}_2 - \boldsymbol{P}_1) = (1-t)\,\boldsymbol{P}_1 + t\,\boldsymbol{P}_2$$

合并一下同类项，就得到右边的形式，$\boldsymbol{P}_1$、$\boldsymbol{P}_2$ 分别是现在的两个端点。这些表示对二维和三维都是成立的。

### 平面、半空间与三角面片

面是一个三维的量，不存在二维的对应物。无穷大的平面用**隐式方程**来表示——注意，这里没有参数：

$$(\boldsymbol{X} - \boldsymbol{P}) \cdot \boldsymbol{N} = 0$$

在平面上任取一点 $\boldsymbol{P}$：某一个点 $\boldsymbol{X}$，如果它与 $\boldsymbol{P}$ 相减得到的差向量，点乘平面的法向量 $\boldsymbol{N}$ 等于零，那么这个点就一定在平面上。这一点很容易证明，因为平面的法向量会垂直于平面内所有的线向量。

如此又可以定义**半平面**。所谓半平面，它其实不是平面，而是一半的空间：

$$(\boldsymbol{X} - \boldsymbol{P}) \cdot \boldsymbol{N} \le 0$$

指的是这个平面以下的所有空间。

> **易错点**：到了半空间，法向量的正负就有意义了。如果把法向量取负号，它指代的就是原来的上半部分空间。

类似的，既然直线可以限缩到线段上，平面也可以限缩到三角面片内。设三角面有三个顶点 $\boldsymbol{P}_1$、$\boldsymbol{P}_2$、$\boldsymbol{P}_3$，可以类似地把它写成参数方程的形式：

$$\boldsymbol{X} = \boldsymbol{P}_1 + u\,(\boldsymbol{P}_2 - \boldsymbol{P}_1) + v\,(\boldsymbol{P}_3 - \boldsymbol{P}_1) = (1-u-v)\,\boldsymbol{P}_1 + u\,\boldsymbol{P}_2 + v\,\boldsymbol{P}_3$$

这个方程的形式不太对称，看起来不是特别好看，可能也不太明白为什么一定得这么取。其实上面这个过程，可以看成是以下几条操作的合并：我们想把 $\boldsymbol{X}$ 限制在 $\boldsymbol{P}_1\boldsymbol{P}_2\boldsymbol{P}_3$ 三个顶点决定的三角形之内，相当于先在 $\boldsymbol{P}_1$ 和 $\boldsymbol{P}_2$ 之间找一个点，这个点显然满足线段的参数方程：

$$\boldsymbol{X}' = (1-t')\,\boldsymbol{P}_1 + t'\,\boldsymbol{P}_2$$

再在这个点 $\boldsymbol{X}'$ 和 $\boldsymbol{P}_3$ 之间找一个点——这个点就是 $\boldsymbol{X}$，它满足的也是线段的参数方程：

$$\boldsymbol{X} = (1-t)\,\boldsymbol{X}' + t\,\boldsymbol{P}_3 = (1-t)(1-t')\,\boldsymbol{P}_1 + (1-t)\,t'\,\boldsymbol{P}_2 + t\,\boldsymbol{P}_3$$

```text
             P3
            /  \
           /    \
          /  X   \       X 取在 X' 与 P3 的连线上
         /   |    \
        /    |     \    X' 取在 P1 与 P2 的连线上
       /     |      \
      P1----X'-------P2
```

两次线段插值复合起来，$\boldsymbol{X}$ 就扫遍了整个三角形。如果我们令 $u = (1-t)(1-t')$、$v = (1-t)\,t'$、$w = t$，最终就得到：

$$\boldsymbol{X} = u\,\boldsymbol{P}_1 + v\,\boldsymbol{P}_2 + w\,\boldsymbol{P}_3$$

很容易验证 $u + v + w = 1$。也就是说，通过这样的方式，我们可以构造出一个在 $\boldsymbol{P}_1\boldsymbol{P}_2\boldsymbol{P}_3$ 这个三角形内的点，并且使得每一个顶点的权重相加的和等于一。而且由于以上过程用的都是 $(1-t')$ 和 $t'$ 这种成对的系数，$u, v, w$ 也必然都是 0 和 1 之间的量——不可能是小于 0 或者大于 1 的数。

### 点与直线的距离和投影

定义了点线面之后，还要看点线面之间的关系。先交代一个课件里的约定：在本次课件中，如果标题上没有标明是 2D 还是 3D，基本上就意味着它对二维和三维都是通用的。我们为什么要如此定义直线、如此定义平面、如此定义点？就在于用这套方法去计算距离的公式，对维度是无关的——不管在二维还是三维下，都可以用同样的方法去计算。

先看点与直线的距离。给定一点 $\boldsymbol{P}$，给定一条直线的参数方程 $\boldsymbol{X} = \boldsymbol{O} + t\boldsymbol{D}$，那么这个点到这条直线的距离，可以用

$$d = \frac{\left| (\boldsymbol{P} - \boldsymbol{O}) \times \boldsymbol{D} \right|}{|\boldsymbol{D}|}$$

来确定。这个事情是为什么呢？把几何画出来：$\boldsymbol{P} - \boldsymbol{O}$ 就是连接 $\boldsymbol{O}$ 与 $\boldsymbol{P}$ 的那条边，它和 $\boldsymbol{D}$ 张成一个三角形——叉乘得到的，其实是这个三角形面积的二倍；再除以 $\boldsymbol{D}$ 的模长（底边长），得到的就是这个三角形沿 $\boldsymbol{D}$ 这条边的高。而这条高根据定义，就是 $\boldsymbol{P}$ 点到这条直线的距离。

类似的，既然已经知道距离可以这么算了，也可以算点在直线上的投影。要怎么去做？相当于在直线上找一个点，使它和 $\boldsymbol{P}$ 点之间的差向量，和 $\boldsymbol{D}$ 这个向量正好垂直。设这个点为 $\boldsymbol{O} + t\boldsymbol{D}$，要满足的条件就是：

$$(\boldsymbol{P} - \boldsymbol{O} - t\,\boldsymbol{D}) \cdot \boldsymbol{D} = 0$$

把这个条件展开，得到一个关于 $t$ 的一次方程；再整理一下解出 $t$，把 $t$ 带回到直线的方程里面，就可以得到直线外一点在直线上投影的位置坐标。

那么如何计算点与射线的距离呢？其实和之前是一样的：先确定这个 $t$ 是什么。如果 $t \ge 0$，它就是到直线的距离；如果 $t < 0$——射线的端点在这里，而我们取到的最小值点在那边——那么它的最近距离，就直接取它与射线端点的距离。

### 二维的线线关系：绕序与跨立测试

接下来看线与线的位置关系，主要在二维当中确定。首先是共端点的射线（或者线段）的绕序。假设射线一、二的端点都为 $\boldsymbol{O}$，方向向量分别为 $\boldsymbol{D}_1$、$\boldsymbol{D}_2$；或者设线段一的端点是 $\boldsymbol{OP}_1$、线段二的端点是 $\boldsymbol{OP}_2$——不管这两种定义里的哪一种，都会得到同样的判定：直接拿 $\boldsymbol{D}_1$ 去叉乘 $\boldsymbol{D}_2$。

> **提示**：这里的叉乘是限缩在二维下的叉乘：$\boldsymbol{D}_1 \times \boldsymbol{D}_2 = x_1 y_2 - x_2 y_1$，得到的是一个实数。上节课讲过，放在这里再提示一下。

| $\boldsymbol{D}_1 \times \boldsymbol{D}_2$ | 含义 |
| :--- | :--- |
| 大于零 | 射线二在射线一的左边（逆时针转角小于 180°） |
| 小于零 | 射线二在射线一的右边（顺时针转角小于 180°） |
| 等于零 | 射线二与射线一重合，或者反方向 |

等于零时，如何判定是重合还是反方向呢？这时候就需要通过点乘来进一步判断：重合得到的点乘值大于零，而反方向得到的点乘值小于零。

再看直线与直线的交点（二维）。两条直线的参数方程分别是 $\boldsymbol{X}_1 = \boldsymbol{O}_1 + t_1\boldsymbol{D}_1$、$\boldsymbol{X}_2 = \boldsymbol{O}_2 + t_2\boldsymbol{D}_2$。任取直线二上参数为 $t_2$ 的点 $\boldsymbol{O}_2 + t_2\boldsymbol{D}_2$：它也落在直线一上，等价于它和直线一的端点 $\boldsymbol{O}_1$ 之间的差向量，与 $\boldsymbol{D}_1$ 是平行的。用二维叉乘把「平行」写出来，就是：

$$(\boldsymbol{O}_2 + t_2\,\boldsymbol{D}_2 - \boldsymbol{O}_1) \times \boldsymbol{D}_1 = 0$$

把这个式子展开，它是一个关于 $t_2$ 的线性方程，稍微化简就能解出 $t_2$；然后直接取 $\boldsymbol{P} = \boldsymbol{O}_2 + t_2\boldsymbol{D}_2$，就能算出这两条直线的交点位置。可以看到，这个计算方式还是比较简洁的。

另外，有时候我们需要判断两条线段之间是不是相交。除了求出交点、再判断它有没有交点之外，还有没有别的做法呢？借助二维计算几何的算法，我们有**跨立测试**这样一种手段。取线段一的端点是 $\boldsymbol{P}_1$ 和 $\boldsymbol{Q}_1$，线段二的端点是 $\boldsymbol{P}_2$ 和 $\boldsymbol{Q}_2$。第一个条件要求：$\boldsymbol{P}_1\boldsymbol{Q}_1$ 所对应的向量 $\boldsymbol{Q}_1 - \boldsymbol{P}_1$，要夹在 $\boldsymbol{P}_1\boldsymbol{P}_2$ 和 $\boldsymbol{P}_1\boldsymbol{Q}_2$ 这两个向量之间——代数上，就是 $(\boldsymbol{Q}_1-\boldsymbol{P}_1)\times(\boldsymbol{P}_2-\boldsymbol{P}_1)$ 与 $(\boldsymbol{Q}_1-\boldsymbol{P}_1)\times(\boldsymbol{Q}_2-\boldsymbol{P}_1)$ 这两个叉乘异号。第二个条件与之对称：$\boldsymbol{Q}_2 - \boldsymbol{P}_2$ 这个向量，要夹在 $\boldsymbol{P}_2\boldsymbol{P}_1$ 和 $\boldsymbol{P}_2\boldsymbol{Q}_1$ 这两个向量之间。如果这两个条件都能满足，那么这两个线段一定是有交点的；如果满足不了，就一定没有交点。而如果叉乘取到了等号，其实说明交点是在端点处发生的，我们才会取等号。

注意，这里面我们并没有做任何的除法运算，直接通过这几次叉乘就判断了两个线段是不是相交，避免了很多「先求出交点、再讨论大于零小于零」这样的情况。

### 三维异面直线的距离

会算了二维直线之间的这些关系，再来看三维的线与线之间的位置关系。首先是异面直线之间的距离。还是一样，先给出两条直线的参数方程：$\boldsymbol{X}_1 = \boldsymbol{O}_1 + t_1\boldsymbol{D}_1$，$\boldsymbol{X}_2 = \boldsymbol{O}_2 + t_2\boldsymbol{D}_2$。

计算两条异面直线距离的**法一**：求两条直线的公垂线，并且把向量投影到公垂线所决定的方向上。这个事情是什么样的逻辑呢？比如有一条异面直线 B、一条异面直线 A：先求这两条直线的公垂线，也就是求出法向量 $\boldsymbol{N}$，这个法向量会决定一个平面的朝向；然后在 B 和 A 上各任取一个点，它们俩之间的向量投影到 $\boldsymbol{N}$ 上，得到的必然就是 B 和 A 之间的最近距离。

**法二**：联立方程。索性把 $t_1$、$t_2$ 都当做未知数，写出两点之间模长的表达式，然后对这个表达式分别关于 $t_1$、$t_2$ 求偏导、令其为零——这是第二种求法，本质上就是把距离变成一个优化问题，去求极值。

既然已知异面直线之间距离的计算方式，就可以去讨论异面线段之间距离的计算方式了。做法也是一样的：把两条线段投影到同一个平面内，然后去做跨立测试。如果投影后在同平面内是相交的，那么跟上面一样，最近距离仍然可以用法一（公垂线投影）去求；如果不是相交的，那么它的最近距离就发生在端点处，这时候还要再重新讨论一下。或者，如果你觉得刚刚这个方法太麻烦了的话，也可以直接把它转换成一个优化问题，求极值。

### 点与平面的距离：为什么用向量形式

讲过了线与线的位置关系，就可以去看点与面的位置关系了。给出要求解的点和平面的定义：平面方程跟刚刚一样，$(\boldsymbol{X}-\boldsymbol{P})\cdot\boldsymbol{N}=0$；平面外有一点 $\boldsymbol{X}$。现在要求 $\boldsymbol{X}$ 到平面的距离。它就等于：在平面上任取一个点 $\boldsymbol{P}$，将平面外这一点和平面上这一点做差，求得一个向量，再求这个向量在法向上的投影：

$$d = \frac{\left| (\boldsymbol{X} - \boldsymbol{P}) \cdot \boldsymbol{N} \right|}{|\boldsymbol{N}|}$$

这个距离不受 $\boldsymbol{P}$ 点选取的影响。为什么？取平面上别的任何一个点，它和 $\boldsymbol{P}$ 点之间的差，只会是一个与法向垂直的向量——因为任何在平面内的向量都垂直于法向。所以就算取另外一点 $\boldsymbol{P}'$，$\boldsymbol{P}'-\boldsymbol{P}$ 与 $\boldsymbol{N}$ 点乘之后都会消掉。

如果上过高等数学课，应该都接触过高数课上给出的点与面距离的计算方式：平面是 $Ax+By+Cz+D=0$，距离是

$$d = \frac{|Ax+By+Cz+D|}{\sqrt{A^2+B^2+C^2}}$$

我们上面给出的用点乘表达的形式，其实和这个形式是等价的。为什么等价？只要把 $\boldsymbol{X}-\boldsymbol{P}$ 点乘 $\boldsymbol{N}$ 的操作，全部拆开成分量形式去计算就可以了：设 $\boldsymbol{X}$ 的三个坐标分别是 $x, y, z$，$\boldsymbol{P}$ 的三个坐标分别是 $P_x, P_y, P_z$，法向量 $\boldsymbol{N}=(A,B,C)$，把点乘展开计算，就会把它整理成 $Ax+By+Cz+D$ 的形式——并且会发现，这个计算式和上面高数里那个计算式是完全一样的、完全一致的。

那么我们为什么还要用向量这种方式去计算点与面的距离呢？因为这种方式是**自动适用于二维**的。二维的直线如果定义成 $Ax+By+C=0$，那么二维直线外一点到直线的距离应该是：

$$d = \frac{|Ax+By+C|}{\sqrt{A^2+B^2}}$$

这跟三维的形式完全一致。我们完全可以用同一个式子，既去求二维中点与线的距离，也去求三维中点与面的距离。所以我们在计算几何当中，倾向于用向量的形式表达，而不是用这种完全展开的解析形式表达。

从另一个角度说：我们定义平面的方式是一种**隐式的表示**，而定义直线的方式是一种**参数的表示**。其实直线也可以用隐式的方式去表达——某一点与直线上某个端点的差向量，和直线朝向的叉乘等于零，也可以用一个隐式方程表达。但我们一般会选择：直线用带参数 $t$ 的参数表达来表示，而三维的平面用隐式的 $\boldsymbol{X}-\boldsymbol{P}$ 点乘 $\boldsymbol{N}$ 等于零来表示。原因在于：对直线来说，参数的选取是很直接的——只要取它的方向向量、取方向向量的步长就可以；而对平面来说，如果要给它参数表达，还需要先取平面上任意的两个切向量，然后用这两个切向量在平面上构建一个坐标轴——这个过程相对来说不是唯一确定的，所以我们一般不这么做。当然，用参数表达的例子我们也已经看到了：刚刚讲的三角形的表达，其实是一种参数表达——因为三角形的三个顶点，刚好给出了一组切向量的表达方式。

### 多边形的周长与面积

讲完了点线面之间的关系，以及它们距离的求法以后，来看多边形——有了点线面，我们就可以去定义多边形了。多边形的两个重要参数，一个是周长，一个是面积。

首先最好算的肯定是周长：只需要去遍历多边形的每条边，计算模长求和，就可以算出这个多边形的周长了。

那么多边形的面积要怎么算呢？这里我们假定多边形是用**逆时针序**给出的，并且把不是逆时针序（顺时针序）的三角形面积记作负值。三角形是最简单的多边形，它怎么算？上节课已经说过了——叉乘的定义，正好可以用来算二维三角形的面积：

$$A_{123} = \frac{1}{2}\,(\boldsymbol{P}_2 - \boldsymbol{P}_1) \times (\boldsymbol{P}_3 - \boldsymbol{P}_1)$$

有没有别的计算方式呢？还给出了另一种方式——这种计算方式看起来貌似比第一种要繁琐很多。做法是：在平面内任取一个点 $\boldsymbol{P}_0$，先去计算三角形 012 的面积，再去计算三角形 023 的面积，然后减掉三角形 013 的面积（也就是加上 031 的面积），用这样的方式去得到三角形 123 的面积。把逆时针序的面积记正、非逆时针序记负的话，就可以把三角形的面积写作：

$$A_{123} = A_{012} + A_{023} + A_{031}$$

发现了什么？除了 0 一直在这个位置不变以外，后面是 12、23、31——正好是以逆时针序，遍历了三角形的每一对顶点。

再来看凸多边形。比如一个凸四边形 1234，想求它的面积：最简单的求法是先去求三角形 123 的面积，再加上三角形 134 的面积，把这两部分的面积相加，就能得到整个凸多边形的面积。但和上面一样，我们也可以任取平面内一点 $\boldsymbol{P}_0$，把这个多边形的面积表示成 012 的面积 + 023 的面积 + 034 的面积 + 041 的面积——041 实际上是减去 014 的面积。规律就出来了：我们可以把任何一个多边形的面积写成

$$A = \sum_{i} A_{0ij}$$

这里的 $ij$ 按逆时针序遍历这个多边形的每一对相邻顶点。

我们为什么要这样去算多边形的面积呢？因为我们并不能保证这个多边形是一个凸多边形。对一个凹多边形来说，按照前一种（从固定顶点做扇形剖分的）方法，是求不出来正确的面积的。这时候与其想怎么去把它剖成三角形，不如直接在平面内随便取一个点，然后按照刚刚所说的 $A_{0ij}$ 这个方法去算——这个求面积的方法，无论对于凸多边形还是凹多边形，都是适用的。

### 点与凸多边形：面积法与绕序法

刚刚给出了求多边形面积的方法，从中能发现一个规律，用它来处理点和凸多边形的位置关系。还是刚才四边形的例子：如果取的参考点 $\boldsymbol{P}_0$ 在多边形外，按逆时针序去计算 012、023、034、041 这些三角形的面积，然后给它们都取绝对值再相加（也就是说，认为 $A_{041} = A_{014}$，把那个「负」的三角形也按正面积算），会发现这些三角形面积相加，是大于等于整个多边形的面积的。相反，如果参考点取的是在多边形内部，再用它和每个顶点按绕序的三角形面积相加，它是正好等于这个凸多边形面积的。

于是就有了判定办法：记 $A$ 为带符号面积求和的结果——按前一节的结论，它就是多边形的面积；记 $A'$ 为求和过程中把每一项都取了绝对值之后的结果。

> **结论**：$A' = A$，参考点一定在多边形内；$A' \neq A$（更大），参考点一定在多边形外——因为只有取在外面的时候，才会出现有的三角形面积是负数这样的情况。

对于凸多边形来说，除了面积法以外，还有**绕序法**。在多边形内部取一点 $\boldsymbol{P}_0$：对这个点来说，每一条边其实都在这个点的右边——或者说，这个点在每一个多边形的边所对应线段的左边。比如 $(\boldsymbol{P}_2-\boldsymbol{P}_1)\times(\boldsymbol{P}_0-\boldsymbol{P}_1) > 0$，它在往左转；同样的，$(\boldsymbol{P}_3-\boldsymbol{P}_2)\times(\boldsymbol{P}_0-\boldsymbol{P}_2) > 0$，$(\boldsymbol{P}_4-\boldsymbol{P}_3)\times(\boldsymbol{P}_0-\boldsymbol{P}_3) > 0$，每条边都是一样。$\boldsymbol{P}_0$ 在每一条边对应向量的左边，它就一定在多边形内部；但凡 $\boldsymbol{P}_0$ 不在某一条边的左边，它就不在这个凸多边形的内部。

上面的判断关系，很容易拓展到三维里面。对多面体来说——这就不是面积了，是体积——体积怎么算？把 $A_{0ij}$ 改成 $V_{0ijk}$，把有向三角形改成有向的四面体就可以了。而点与凸多面体的位置关系也一样：如果这个点在凸多面体的每一个面的「左边」——就像我们之前定义过半平面的概念，如果它在每一个凸多面体的半空间的同一个方向——那它一定就在这个凸多面体的内部，否则它就在凸多面体的外部。

### 点与任意多边形的位置关系

解决了点与凸多边形的位置关系以后，再来看点与任意多边形的位置关系。这个时候，解法就不是那么自然了，需要一些比较精巧的经验。一般而言，考察点与任意多边形的位置关系有两种算法：一种是光线投射算法，一种是回转数算法——看这两个名字，就非常图形学。

#### 光线投射法

光线投射算法基于**若尔当曲线定理**：

> **定义**：若尔当曲线定理——任何一条简单闭曲线可以将平面分成两部分。连接同一部分任意两点的弧，与该曲线不相交，或者相交偶数次；连接不同部分两点的弧，与该曲线相交奇数次。

怎么理解？可以画一个圆代表平面，任何一条简单闭曲线，把圆的里面分成了两部分。连接同一部分任意两点的弧：要么不穿过这条闭曲线，要么和它相交两次，或者绕出来再绕回来再绕过去——反正相交一定都是偶数次；而如果起始点在一部分、终止点在另一部分，那么它和闭曲线相交的次数一定是奇数次。

用在这个问题上：把多边形取成定理里那条简单闭曲线，从判断点出发随便发一条射线，把这条射线当做定理定义里的「弧」。那么这条射线每与多边形相交一次，都会改变一次内外关系；而无穷远点一定在多边形外——因为多边形是一个有限大的图形。于是得到结论：

> **结论**：射线与多边形的交点个数是奇数，点就在多边形内；交点个数是偶数，点就在多边形外。

跟着数一遍：从要判断的点出发随便发一条射线，与多边形相交一次，我们认为它是在里面；又碰到一次，认为在外面；里面、外面、里面、外面——最后这条射线只和多边形相交了偶数次，所以我们就说初始点是在多边形的外面。

这里我们需要思考一些特殊情况：如果该射线与顶点（或边）重合了，该怎么办？比如要判断一个四边形里面的 $\boldsymbol{Y}$ 点：如果取的射线正好与 X 轴平行，它就会撞到顶点 $\boldsymbol{C}$——撞到 $\boldsymbol{C}$ 这个点，到底算相交一次还是算相交两次？这个问题就很难处理。

最简单的解决方案：取射线的时候不要沿 X 轴，把射线的夹角取成 $\pi$ 的无理数倍，这样它重合的概率就几乎为零了。

或者，有一个更加健壮的算法：规定射线上的点以及射线上方的点算「上方」，否则算「下方」；当发出的射线与多边形的某条边相遇时，只有这条边的两个端点分别在上方和下方，我们才算相交。

用这个规则验证 $\boldsymbol{Y}$ 点：往右发的射线正好穿过顶点 $\boldsymbol{C}$。按规则，$\boldsymbol{C}$ 在射线上、算上方；$\boldsymbol{D}$ 在射线上方，$\boldsymbol{B}$ 在下方。于是边 CD 的两个端点都在上方——我们不认为这条射线与 CD 这条边相交；而边 CB 分别在上方和下方——我们认为这条射线与 CB 相交。最终判断的相交次数是 1，因为相交次数是奇数，所以我们说 $\boldsymbol{Y}$ 在多边形内。

再看这个规则对 $\boldsymbol{X}$ 点的情况是不是也成立：$\boldsymbol{X}$ 往右发一条射线，会正好打到顶点 $\boldsymbol{D}$。按规则，$\boldsymbol{D}$ 在射线上、算上方，$\boldsymbol{A}$ 点在射线下方，$\boldsymbol{C}$ 点也在下方。于是这条射线和 AD 相交（一上一下），和 DC 也相交（一上一下），它和整个多边形的相交次数是 2——偶数，所以我们判断 $\boldsymbol{X}$ 在多边形外。这个算法就规避掉了射线与顶点、边重合所带来的数值上的问题。

#### 回转数法

除了光线投射法外，还有回转数法：用曲线绕过某一点的次数，来判断这个点是在多边形内还是多边形外。多边形内的点，多边形绕过该点的次数是 1；多边形外的点，多边形绕过该点的次数是 0。

这个事情怎么看呢？比如一个三角形，沿着三角形的边走一圈，正好绕过了内部的这个点一次；而如果判断点在多边形外，多边形逆时针绕一圈，对这个点来说绕了零圈。

如何去计算回转数呢？回转数等于回转角 $\theta$ 除以 $2\pi$。回转角的计算方式：对多边形上的每一条边，从判断点看这条边的两个端点，得到两个方向向量，求它们之间的夹角 $\theta_i$——这个夹角是带符号的，逆时针方向扫过记正、顺时针记负。把每一个 $\theta_i$ 相加，就是回转角 $\theta$。

三角形内部的点：$\theta_1 + \theta_2 + \theta_3$ 加起来正好等于 $2\pi$，所以回转数是 1，在多边形内。多边形外的点：先考察的第一条边给出了正的 $\theta_1$，$\theta_2$ 也是正的；再看 $\theta_3$ 的时候，它变成负的了，$\theta_4$、$\theta_5$ 也是负的——它们相加，正好抵掉了 $\theta_1$、$\theta_2$ 这两个正值，最终得到的结果就是 0，$0 \div 2\pi = 0$，回转数为零，在多边形外。

## 图形学中的计算几何：距离、凸包、最小覆盖与反演变换
> 对应块：BLK07 | 覆盖分集：P03下 | 块标题（分集名）：《计算几何》

### 回转数：点在多边形内的最后一环

判断一个点在不在多边形内，最后一步就是把回转数算出来：把这一点相对多边形各段边界的绕行贡献累加起来，再除以 2。这里累加结果除以 2 得到 0——回转数是零，所以这个点在多边形外。

一般我们在算回转数的时候，会先定义回转数的方向：逆时针绕一圈才认为是 1；如果是顺时针绕一圈，就记作 −1。回转数可以取不同的值，也存在回转数绝对值大于 1 的情况——比如绕中间某个点转了两圈，回转数就是 2。

> **易错点**：我们考察的对象是多边形。一个简单的多边形不可能自己和自己相交，所以对多边形来说，它对任何一个点的回转数只可能是 1 或者 0（把方向算上，就是 ±1 或 0）。不要把一般曲线那种"绕很多圈"的情形套到多边形头上。

有了判断点是不是在多边形内的算法之后，我们再来看点到三角形的距离该怎么算。

### 点到三角形的距离

这是一个很经典的问题。比如在图形学当中，我们有一个 mesh，它是由三角形面片组成的；现在要求一个点到这个 mesh 的距离——那我们其实就相当于对这个 mesh 上的每一个 face，求这个点到这个 face 的距离，然后再求它的最小值。所以，点到三角形的距离这个问题，对图形学来说是很重要的一个计算几何应用。

跟之前一样，我们先看二维情形。

#### 二维：先比顶点，再比投影

平面当中有一个三角形（顶点记作 $V_0$、$V_1$、$V_2$），还有三角形外一点 $P$。

- 如果点在三角形内，那么距离显然是 0；
- 如果点在三角形外：我们先把最近距离设为 $P$ 到三个顶点 $V_0$、$V_1$、$V_2$ 距离的最小值；然后，把 $P$ 逐条边做投影。

投影这一步要看投影点落在哪里。比如把 $P$ 投影到 $V_0V_2$ 所在的这条边上，我们发现投影点落在 $V_0V_2$ 的延长线上——那这个候选就不需要了；再把 $P$ 投影到 $V_1V_2$ 这条边呢，诶，投影点没有落在延长线上，它就在 $V_1$、$V_2$ 之间——这个时候，我们就用这个点到这条边的距离，去更新刚刚求得的最小值。

做完这两步（顶点候选加上有效的投影候选），得到的距离就是点到三角形的最近距离。

#### 三维：只多一步投影

那能不能把刚刚这个过程拓展到三维呢？其实很简单。考察空间里的一点 $P$，想计算它到三角形 $V_0V_1V_2$ 的距离：我们先把它投影到三角形所在的平面。

- 投影点落在三角形内：那么距离就是点到平面的距离；
- 投影点落在三角形外：那这个距离就相当于"点到平面的距离"再接上"投影点到三角形的距离"，用勾股定理算一下就能得到：

$$d=\sqrt{h^2+d_{\mathrm{proj}}^2}$$

其中 $h$ 是 $P$ 到三角形所在平面的距离，$d_{\mathrm{proj}}$ 是投影点到三角形的（二维）最近距离。所以三维情形和二维情形几乎一样，就是只多了一个投影的过程。

#### 不想分类讨论？转成优化问题

当然，上面这个方法是不可避免会有一些讨论的：我们需要去讨论二维情况下、点到各边的投影点在不在延长线上——这个问题是回避不了的。那么有没有一些不需要讨论的方式呢？还是一样的思路：利用三角形的参数表达，把它转化为优化问题。

三角形中任何一个内部的点，都满足

$$X=uV_0+vV_1+wV_2,\qquad u+v+w=1,\ u,v,w\ge 0,$$

这样会给出三角形中任何一个点的表达式。把三角形内的这个参数点和三角形外那一点做差，我们就会得到一个优化函数：现在要做的，就是在 $u+v+w=1$ 且它们都大于等于零这个约束的情况下，去求上面这个优化函数的最小值。这样，它就变成一个优化问题了。至于优化问题如何去求解，是我们这个学期课程后面的内容。

### 两个三角形之间的距离

还是从图形学出发：刚刚我们给出了一个点到一个 mesh 的距离；而现在我有两个 mesh，想求这两个 mesh 之间的距离，该怎么办？这可以拆成"两个三角形之间的距离"来算。

#### 二维：最近距离必取在顶点上

二维的两个三角形，它们之间的距离应该怎么算？既然已经给出了点到三角形的具体表示方式，我们其实可以把一个三角形的三个顶点，分别对另一个三角形求一遍最近距离；然后再倒过来，用另一边的三个顶点对这个三角形求一次最近距离；最后把这 6 个值取最小——就是这两个二维三角形的最近距离。

在这个过程中，我们用到了一个定理：**二维中两个三角形的最近距离，必然在其中一个三角形的顶点上取到**。这个定理的证明我们在这里不给出，但它可以很直观地理解。

如果你不相信这个定理的话，还有另一种求两个三角形距离的方式：用 18 组"点-边"距离的最小值来决定。除了求点到三角形（面）的距离，你还可以用任何一个三角形的某个顶点，和另一个三角形的三条边分别求一次最小值——3 个顶点乘 3 条边再乘两个方向，正好 18 组。不过，这好像还是要建立在那条定理的基础上：这一切都建立在"二维当中任何两个三角形的距离，其中一个三角形必然要取在顶点上"这条性质上。

#### 三维：点面之外还要补边边

三维当中跟二维是类似的：我们可以取 6 组"点-面"距离的最小值——每个三角形的 3 个顶点，分别对另一个三角形面片求一次。但是注意，三维就没有二维那个"或者"了：在二维当中，这个取法是完备的，你取完点-三角形就已经找到了最近距离，一定能保证找到；但在三维，你取 6 组点-面，不一定能把最近距离找到，因为你还要去考察 9 组"边-边"的情况。

看个反例就明白了：两个三角形一上一下错开摆着，它们的最近距离取在上面三角形的一条边和下面三角形的一条边之间——并不取在任何一个顶点上。

> **结论**：三维中两个三角形的最近距离 = min（6 组点-面距离的最小值，9 组边-边距离的最小值），两种情况都要算。

### 从距离到碰撞检测：DCD 与 CCD

刚刚我们说的 mesh 到 mesh 的距离有什么用呢？在 CG 当中，它最主要的作用在碰撞检测上。碰撞检测里面，我们一般会将碰撞检测分为两种。

第一种叫**离散碰撞检测**（Discrete Collision Detection），简称 DCD。它在字面上就是说，我们要求两个三角形网格之间的距离——也就是说，它的最基本算法刚刚已经给出了。

第二种叫**连续碰撞检测**（Continuous Collision Detection），简称 CCD。这里三角形网格上的每一个顶点不仅有位置，还有速度。现在我想知道：这两个三角形经过多长时间会接触？这要怎么去算呢？

还是一样，我们要去考察那 6 组点-面和 9 组边-边，去计算它们都到什么时候会共面。我们可以把这个共面的方程列出来，去判断它们什么时候会共面；每一个共面的方程，都会对应一个关于时间 $t$ 的一元三次方程，解出这个时间 $t$ 以后，再判断共面的那一刻是否真的发生了接触。这个算法还是相对来说在实现上比较困难，感兴趣的同学可以去参考 GAMES103 的课程，文末参考资料里还会再提到。

### 德洛内三角剖分与它的对偶

讲完了三角形之间的距离，我们还要提一下德洛内（Delaunay）三角剖分的概念。这是一个定义在二维上的内容。

#### 两条定义性质：空圆性与最大最小角

三角剖分是说：我们要将点集连接为三角网格，使得各个三角形的边互不相交。比如给定很多顶点、只有顶点，我们要把这些顶点连起来，连成一个三角网格，并且这些边之间不交叉——它是一个简单的网格。

所谓德洛内三角剖分，是说它是以满足以下性质的三角剖分：

1. **空圆性**：任意三角形的外接圆内都没有别的点；
2. **规则化（最大化最小角）**：在所有的三角剖分中，德洛内三角剖分所得的三角形，内角的最小值是最大的——把每个剖分中所有三角形的最小内角取 min，德洛内的这个 min 是最大的。这是可以证明的。

#### 结果唯一、改动局部、外层凸

德洛内三角剖分还有一些其他的性质：

- **结果唯一**：就是不论你用什么算法求得，三角剖分一定是一样的；
- **局部性**：我们对它增删改顶点，都只会影响局部——新加一个顶点，它顶多会把原来的剖分局部翻转一下，不会影响到别的位置；
- **外层是凸的**：三角剖分的最外层一定会形成一个凸多边形——它给出的是最外层为凸多边形的这样一种剖分方式。

#### 对偶图：沃罗诺伊图

三角剖分有一种对偶图，它的对偶图叫沃罗诺伊（Voronoi）图。Voronoi 图的目的，是将平面划分为若干个由"最近的控制点"决定的区域：我们保证平面内的任何一个点，它所属的区域都是离它最近的那个控制点；对平面中的每一点都这样操作，得到的就是 Voronoi 图。

很容易可以证明，Voronoi 图就是德洛内三角剖分的对偶图。怎么做呢？其实就是在三角剖分的每一条边上，取它的中垂线；这些中垂线会自然地相交，它们相交的结果，就会形成 Voronoi 图。

求三角剖分的算法比较繁琐，而且已经超出了这门课的数学范畴——它本身就是计算几何的一部分，大家可以去看 GAMES 系列的其他课程。这里就稍微带过一下三角剖分的概念。

### 凸包与包围盒家族

在三角剖分以外，我们来看凸包。

#### 什么是二维凸包

首先看二维的凸包。二维凸包的定义是：在平面上能包含给定点的最小的凸多边形，我们叫它凸包。比如五个点构成一个点集，我们想用一个最小的凸多边形把它包起来——有一种包法是不对的，因为它不是凸的；另一种包法是一个凸多边形，这才是凸包。

#### 放宽版本：AABB、OBB 与固定方向凸包

其实在图形学当中，我们往往会用一些比凸包稍微放宽一点的结构。

**轴对齐包围盒**（AABB）的定义和凸包非常相似：它也要包含给定点，只不过不是"最小的凸多边形"，而是与坐标轴平行的矩形。把包含整个点集的、与坐标轴平行的矩形画出来，是最外面的那个框；而包含这些点的凸包要小一圈。显然可以证明，这个凸包一定在轴对齐包围盒之内——所以，轴对齐包围盒是凸包最粗糙的近似。

有没有稍微厉害一点的？**方向包围盒**（OBB）也是要求矩形，但是放宽了"轴对齐"这个限制——矩形可以斜着取。当然，斜着取的取法不一定最优，示意一下而已；但这样一个矩形说不定就比轴对齐的矩形要小。所以 OBB 的定义方式是：包含给定点的最小的矩形——这个最小的矩形不一定要与坐标轴平行。

除了这两种包围盒以外，还有**固定方向凸包**。固定方向凸包和正常的凸包最大的区别在于：我们要求凸包的各个边（或者面），它的法向只能在给定的集合当中选取。那么从这个角度说，轴对齐包围盒岂不就是一种固定方向的凸包？对——我们要求这个凸包的各条边只能取横平竖直的那几种，用这几种边组合得到的"凸包"，就是轴对齐包围盒。然后如果我们放宽一点限制，比如说允许斜 45 度的边，用这样的边拼出来的图形，就是更广义的固定方向凸包——它就会比轴对齐包围盒更接近我们真正的凸包。

| 包围结构 | 约束 | 和真凸包的关系 |
| :--- | :--- | :--- |
| 凸包 | 无——最小的凸多边形 | 本尊，最精确的表示 |
| AABB | 矩形，且与坐标轴平行 | 最粗糙的近似（凸包必在其内） |
| OBB | 矩形，方向不限 | 放宽轴向限制，通常比 AABB 更小 |
| 固定方向凸包 | 边/面的法向只能从给定集合中选 | 法向集合越丰富越贴近真凸包；AABB 是它的特例 |

### 二维凸包怎么求：Graham 扫描

当然啦，在二维当中，其实去求准确的凸包并不是一个非常困难的事情。

对一个二维点集观察一下，会发现两条性质。第一，点集中纵坐标最小的点一定在凸包上——为什么？因为它底下没有别的点了，凸包要包含所有点，正好过它是最优的。第二，在凸包上逆时针走，所经过的边一定都是左拐——但这都不需要特别去记，因为这都是凸包的定义：我们要它是一个简单的凸多边形嘛。

根据这两条性质，我们就可以建立 Graham 扫描法：

1. 既然已知凸包上必然存在那个纵坐标最小的点 $P_0$，我们就把这个纵坐标最小的点 $P_0$ 先压入栈中；
2. 把别的所有的点，按照相对 $P_0$ 的极角排序——$A$、$B$、$C$、$D$ 这样，$P_0$ 转到 $A$、$A$ 转到 $B$、$B$ 转到 $C$，极角逐渐增大；
3. 维护一个栈：先将 $P_0$ 和 $A$ 压入栈中，然后依次考察排好序的点，看"栈顶两点连向新点"的转向：

   - 考察 $B$：从 $P_0A$ 转到 $AB$ 是左转，符合凸包的性质，所以直接把 $B$ 入栈；
   - 考察 $C$：现在栈顶是 $B$ 点，栈的第二个元素是 $A$ 点——从 $AB$ 到 $BC$ 是左转吗？也是左转，所以把 $C$ 压入栈中；
   - 考察 $D$：从 $BC$ 到 $CD$ 是左转吗？不是左转，这时候是右转——右转就弹出栈顶 $C$；然后再去判断从 $AB$ 到 $BD$ 是不是左转，是左转，把 $D$ 压入栈中；

4. 重复上述过程，直到遍历完所有的点，栈里剩下的就一定是一个凸包。

```text
入栈 P0, A               -> 栈 [P0, A]
考察 B: P0A->AB 是左转    -> 入栈 B    栈 [P0, A, B]
考察 C: AB->BC 是左转     -> 入栈 C    栈 [P0, A, B, C]
考察 D: BC->CD 是右转     -> 弹出 C    栈 [P0, A, B]
考察 D: AB->BD 是左转     -> 入栈 D    栈 [P0, A, B, D]
遍历结束：凸包就是栈里的点 [P0, A, B, D]
```

读图：每一行是一次考察——栈顶两个点连向新点的方向若是左转就入栈，若是右转就弹出栈顶重判，直到恢复左转为止。

这个算法的复杂度是 $O(n\log n)$，它的主要时间代价其实在极角排序这一步。也就是说，只要排序能够做得更快，这个复杂度还能再降——这个方法的效率是比较高的。

### 三维凸包

然后我们再来看三维。三维就没有那么好的性质了，因为三维不存在一个极角序。那么我们怎么去构造三维凸包呢？

#### 增量法：把新点当成光源

一个最简单的算法是增量法：我们要求 $n$ 个点的凸包，先假定我们已知 $n-1$ 个点的凸包，然后考察一个新点。

新点在不在凸包内怎么判断？这个我们之前已经说过了——它只要在每一个面的左侧，它就在凸包内。如果新点在凸包内，那么凸包是不变的。

如果新点不在凸包内怎么办？以该点为光源，从这个点向四面八方发射光线，那么它一定会在凸包上形成一个明暗分界线，并且这条明暗分界线一定是由凸包的棱组成的——凸包有很多小面片，这些面片要么能被这个光源照到，要么不能被照到。怎么办呢？把亮面全部删除，然后连接光源（新点）和分界线，就得到了加入这个新点之后的凸包。

这个算法的复杂度可以证明是 $O(n^2)$ 量级的。因为每次考察一个新点的时候，我要考察它是不是在每一个面的左边，然后还要遍历每条边、再去考察每条边能不能被这个光源照到——所以这个复杂度不可避免地会比较高。

#### 多点共面：随机扰动

那如何处理多点共面的情况呢？其实没有什么特别好的办法，一般大家的处理方式，都是对输入的点进行一些随机扰动，去避免点共面。

#### 暴力法与快速凸包法

三维凸包还有一些其他的算法。比如**暴力法**：我有个点集，点集里面有 $n$ 个点，那么这 $n$ 个点会构成 $\binom{n}{3}$ 个三角形，对吧；而凸包上的三角形，一定是由这 $\binom{n}{3}$ 个三角形中的一些组成的——所以我只需要去遍历这 $\binom{n}{3}$ 个候选三角形，判断它在不在凸包上就可以了。怎么判断它在不在凸包上呢？只要其余所有的点都在这个三角形的左侧——要么就是这个三角形的顶点，要么在它的左边——它就在凸包上。这样去遍历每一个候选三角形、判断它在不在凸包上，就能找到三维凸包。很自然，这个算法的复杂度是四次方量级的：$\binom{n}{3}$ 个候选面，每个还要对全部 $n$ 个点判一次侧。

还有**快速凸包法**（QuickHull）。它其实和增量法在逻辑上是完全一致的，只不过每次选择的这个点不是随便取，而是挑成离当前凸包最远的那个点——以这样的方式，我们能保证三维凸包构造的复杂度尽量低。不过，这个快速凸包法的实现并没有那么容易；现在的一些开源计算几何库，一般都会有快速凸包法，也包括前面的三角剖分，大家可以直接调这些库去完成计算。

### 平面最近点对：留给 kd 树与分治

讲完凸包以后，我们再回到 2D 上，看平面最近点对的问题。这个问题今天不打算细讲：它在图形学当中有应用，但大家可能更喜欢去写 kd 树，对吧——kd 树不仅能适用于二维，也适用于三维，而且不仅能找最近点对，还能去找别的一些东西。最重要的是，平面最近点对是一道分治的经典例题，大家在大学的算法课上应该也学过。所以我们今天就跳过这一部分，直接来看最小圆覆盖。

### 最小圆覆盖

刚刚我们有了凸包，又从凸包放宽出了 AABB、OBB，还有固定方向凸包。那么如果我不用矩形，能不能用圆去覆盖——求包围该点集的最小的圆呢？也是可以求的。

#### 最小圆只有三种可能

首先还是一样：凸包一定在最小覆盖圆内。而最小覆盖圆只有三种可能：

1. 圆心在某一点处、半径为零——点集里只有一个点时，最小覆盖圆就是圆心在它、半径为零的这个圆；
2. 圆心在两点的中点处，直径是两点的距离；
3. 圆心由三个点所决定——就是这三点构成的三角形的外接圆，半径是这个外接圆的半径。

只有这三种情况。可以感性理解一下：如果一开始求出来的覆盖圆是最外层的大圆，那么这个圆显然不是最小——我们可以不断地缩小半径，直到圆碰到点集当中的某一个点；接上中间某个点之后，发现旁边都是空白，就把圆心再移动一下，使得正好有三个点落在这个圆上——那么这个得到的就是一个最小覆盖圆。对于其他的情况，比如最终得到的最小圆，是以某两个点的连线为直径的这样一个圆，圆心就在这条连线的中点处。以上就是最小覆盖圆所有的情况。

#### 三层循环，期望却是线性

那么最小覆盖圆是不是也可以增量构造呢？其实可以，和凸包一样去做增量构造。给定了 $n-1$ 个点的最小覆盖圆，那么第 $n$ 个点要么在上述圆内，要么这个新的覆盖圆一定要过这个点。这也很容易理解，对吗？新加一个点在覆盖圆内，那我们就什么都不用做；新加的点在覆盖圆外，那么覆盖圆一定要过这个点——因为没有比它更靠外的点了。

最小圆覆盖的算法是什么样的呢？其实是相当暴力的一个做法：三层循环。

```text
C <- 以 P1 为圆心、半径为 0 的圆
for i = 2 .. n:
    if Pi 在 C 内: 直接进入下一次循环
    # 走到这里，说明 Pi 一定在最终的最小圆上
    C <- 以 Pi 为圆心、半径为 0 的圆
    for j = 1 .. i-1:
        if Pj 在 C 内: 直接进入下一次循环
        # Pj 一定在最终的圆上
        C <- 以 PiPj 为直径的圆      # 它一定同时包含 Pi 和 Pj
        for k = 1 .. j-1:
            if Pk 在 C 内: 什么都不做
            # Pk 一定在最终的圆上
            C <- 过 Pi、Pj、Pk 三点的三角形外接圆
```

直接这么暴力三重循环就完事了，而且能保证最后找到的这个圆一定是最优的最小覆盖圆。

这个方法的时间复杂度并不是 $O(n^3)$，而是 $O(n)$——这是很神奇的地方。为什么呢？因为我们刚刚已经说过了，最小覆盖圆只有三种不同的情况：要么是一个点、半径为零；要么是两个点，半径是它们俩的距离除以二；要么是三个点，三个点直接确定一个外接圆。所以说明什么？说明这个最小圆并不是可以任意取的——如果暴力去计算的话，我们其实只需要判断 $\binom{n}{1}+\binom{n}{2}+\binom{n}{3}$ 种情况，也就是只需要三个特定的点，就能够确定这个最小覆盖圆。

那每次考察，要不要进入下一层循环？进入下一层循环，只可能在于我们当前构造的最小覆盖圆必须过某个点——比如必须过 $P_i$，或者是必须过 $P_j$，或者是必须过 $P_k$。它们的概率都只有 $3/i$ 或者 $3/j$。为什么呢？因为三个点就可以确定这个最小覆盖圆；如果我说这个最小覆盖圆一定要过 $P_j$，那岂不是说 $P_j$ 就在那三个（决定圆的）点之内吗？也就是它每次进入下一层循环的概率，就是当前这批点的大小分之三。算一下：满打满算 $O(n^3)$ 量级的结构，乘上 $3/n$、再乘上 $3/n$，最终得到的复杂度是 $9n$——所以它的期望时间复杂度是线性的，而并不是 $n^3$ 的算法。

> **提示**：这个复杂度的证明，可能稍微对大家来说不是那么直观。如果理解不了，没有关系——大家只要知道：最小圆覆盖可以用三层循环、以期望 $O(n)$ 的时间复杂度解决，就完事了。这就是所谓的随机增量法。

#### 拓展到最小球覆盖

这个最小圆覆盖是可以直接拓展到最小球覆盖上的，把二维拓展到三维。其实只是把三种情况变成了四种情况：除了刚刚所说的三种情况以外，多了一个"四点确定球面"的情况。现在一共四种情况：

1. 第一种还是一个点：它为球心，半径为零；
2. 第二种是两个点：两点的中点是球心，半径是这两点距离的一半；
3. 第三个情况是以这三个点的外接圆为球的大圆，以外接圆的半径为球的半径；
4. 第四种情况就是由四个点所确定的球面，就是最小球覆盖。

而且，因为进入下一层循环的概率仍然是这么多、没有变，所以随机增量法的期望复杂度仍然不变——它仍然是线性的，我们可以在期望线性的复杂度内构建最小球覆盖。但是，求最小球覆盖最大的困难、难点，并不是这个复杂度高，而是求外接球的过程并不像求外接圆那么容易——事实上，求外接圆本身也不是很容易，而求外接球就更难算了。

所以我们还可以采用**模拟退火法**：直接去随机圆心（球心）的位置——如果球心是给定的，那么半径就是它到点集里每一个点的距离的最大值；然后我们去随机化、优化这个圆（球心）的取值，以这种方式来求最小圆覆盖或者最小球覆盖。

#### 用在哪里：包围体与碰撞检测

最小球覆盖（或者说最小圆覆盖）有什么用呢？它其实和我们之前所说的三角形和三角形之间的距离是有关系的。比如我们在做碰撞检测，或者是光线渲染求光线相交的时候，都要先判断一个点、或者一条射线和某个三角形是不是相交——但这个过程会很麻烦，对吧。所以我们需要一个数据结构，去先粗糙地判断一下：它跟"一大片三角形"是不是相交的？如果它跟这一大片三角形不相交，这一片三角形我就都不用看了。

那么对于这一大片三角形，我需要一个数据结构来表示它。怎么表示？最精确的表示方法，就是求这一大片三角形的凸包；稍微弱一点的取法，就是 AABB 或者 OBB，也或者是求球覆盖。

实际用下来是这样的：做光线追踪的时候，我们主要用的是 AABB；做实时碰撞检测的时候，我们用的是球覆盖——因为对球去做碰撞检测是最容易的。也就是说，我们现在不把这个三角形看成三角形——之前求三角形相不相交、距离是什么的那些算法太复杂了——而是把这一片三角形看成一个球，直接去判断这两个球是不是相交的；如果这两个球相交，我们就认为这两个 mesh 碰撞了（当然，一个 mesh 可能还会有很多很多个球，不只是一个球）；如果这些球都没有相交，我们就认为这两个 mesh 没有碰撞。至于这个球具体怎么确定，就可以用我们这里说的圆覆盖或者球覆盖算法来决定。

### 反演变换

最后，我们来看一下反演变换。先说清楚：这个是做一个知识的科普，并没有要求大家去掌握。

#### 反演点：共线与距离乘积

所谓反演，是定义在点上的。给定了某一个反演中心 $O$——它是一个点，和一个反演半径 $R$——它是一个实数，这其实就给定了一个圆（在二维中）。空间（平面）当中的每一个点，关于这个圆都会有一个反演点，比如 $P$ 和它的反演点 $P'$。

一点和它的反演点之间，会满足下面两条性质：

1. 第一点，它们三点是共线的；
2. 第二点，它们到圆心的距离相乘，等于半径的平方：$OP\cdot OP'=R^2$。

那么很显然，一个圆 $O$ 内的点，它的反演点一定在圆 $O$ 外；一个圆 $O$ 外的点，反演点一定在圆 $O$ 内，对吧——因为它们俩相乘等于 $R^2$ 嘛：$D_1$ 小于 $R$，那么 $D_2$ 一定大于 $R$，才能保证 $D_1\cdot D_2=R^2$。

#### 过圆心的圆，反演成直线

反演最重要的应用是什么呢？一个过反演圆心 $O$ 的圆，它的反演是一条不过圆心 $O$ 的直线；倒过来也是一样的——给一条不过点 $O$ 的直线，它反演之后一定是一个过点 $O$ 的圆。

可以稍加证明一下。我们先写出这个过点 $O$ 的圆的表达式：

$$(x-x_0)^2+(y-y_0)^2=a^2,$$

圆心我们设为 $(x_0,y_0)$。既然说这个圆过原点 $O$，那就是说 $x=0$、$y=0$ 的时候它在圆上，也就是 $x_0^2+y_0^2=a^2$。代回展开，圆方程就化简成

$$x^2+y^2-2x_0x-2y_0y=0.$$

反演关系是：$(x,y)$ 会被反演成 $(x',y')$，坐标由

$$x'=\frac{R^2x}{x^2+y^2},\qquad y'=\frac{R^2y}{x^2+y^2}$$

给出。把以上式子联立——把反演关系代回化简后的圆方程，整理掉分母——就能得到一条直线方程：

$$x_0x'+y_0y'=\frac{R^2}{2},$$

这就是反演结果那条直线对应的方程，注意它不过原点。

#### 应用：把公切圆问题变成公切线问题

那么这个东西有什么用吗？比如我们想求：过两圆外一点、与两圆都相切的所有的圆——过这个点画一个圆，要求这个圆和这两个圆都是相切的，这有几种画法？我们想求这个问题怎么办？

其实我们知道，就可以以这个点为圆心、以任意大小的半径去做反演。那么，所有的过这个点的圆都会变成直线，而所有不过这个点的圆还是一个圆——于是两个已知的圆（不过该点）还是两个圆，最终我们就把问题变成两个圆求公切线的问题。这比两个圆直接去求公切圆要简单多了。这就是一个反演变换的直接应用。

#### 直观理解：关于球的镜像

其实，反演变换在图形学当中的用处可能没有那么大。但是如果我们换一个视角去想，反演的意义它是什么呢？我们平时说镜像，镜像就是关于平面的：中间的平面某一侧的一个点，经过镜像会得到另一侧的那个点；而反演呢，就是圆内的某一个点 $P$，它经过圆——作为一个某种镜像——得到了一个点 $P'$。所以反演的意义，它其实就是几何图形关于球的镜像，而不是关于平面的镜像。

我们后面再讲到微分方程求解的时候，会说到格林函数法，也就是镜像法。这个方法其实还在很大程度上和反演变换之间有共同之处，到时候大家再来体会。

## 三维旋转的表示：从特殊正交群到罗德里格公式
> 对应块：BLK08 | 覆盖分集：P04上 | 块标题（分集名）：《旋转变换》

### 从太空里的一把扳手说起

旋转这个东西，大家在线性代数基础那一讲里其实已经接触过了。一个非常简单的例子：绕 $x$ 轴旋转 $30^\circ$，模型上有个点 $P$，经过旋转变换之后变到 $P'$，$P'$ 和 $P$ 之间的关系可以写成一个矩阵乘法

$$P' = R\,P$$

中间这个矩阵就是旋转矩阵，矩阵元素里 $\cos$、$\sin$ 与角度的关系之前已经介绍过，比如

$$R_x(\theta) =
\begin{pmatrix}
1 & 0 & 0 \\
0 & \cos\theta & -\sin\theta \\
0 & \sin\theta & \cos\theta
\end{pmatrix}$$

这个应该没什么问题。那么下面给大家看一个现象，这个现象非常有意思：NASA 在空间站里实拍过这样一段素材——有一个 T 字形的扳手，把它拿出来转一下，它会有一些非常有意思的运动。看这把扳手的旋转，它跟我们刚才描述的那种简单旋转有本质区别：这是一个非常复杂的、**没有定轴的旋转**。

有同学已经马上认出来了：这是中间轴定理，说明物理基础非常不错。不过我们今天不讲物理。如何去 model 这样的旋转，其实就是我们今天讨论的主要问题：如何去表示它，如何去分析旋转本身。

### 刚体约束：旋转矩阵必是正交矩阵

那我们就从旋转矩阵出发。我们说旋转是一个线性变换，那一个一般的旋转应该满足什么样的要求呢？假设给定一个任意的三维线性变换

$$P' = A\,P$$

旋转有个特性：物体发生旋转是一个**刚性**的变化，物体上任意两点之间的距离不应该发生改变。换算成公式就是：$P'$ 和 $Q'$ 之间的距离，在发生旋转之后，应该和 $P$、$Q$ 之间的距离是一样的：

$$\|P' - Q'\| = \|P - Q\|$$

把模长变成两个向量的点乘，可以写成下面这个式子：

$$(P'-Q')^T(P'-Q') = (P-Q)^T\,A^TA\,(P-Q)$$

这个式子应该对任意的点 $P$ 和点 $Q$ 都成立——我在模型上随便选两个点，它都得是对的。而 $A^TA$ 是一个对称矩阵，一共只有 6 个未知数；但 $P-Q$ 是无穷多对的。要让这个等式对无穷多对点都成立，唯一的条件就是

$$A^TA = I$$

也就是说，$A$ 是一个正交矩阵。

> **结论**："旋转保距"这条刚性约束落到矩阵上，就是 $A^TA = I$——旋转矩阵必是正交矩阵。

那我们可以干些什么事呢？可以随机采样一些正交矩阵，把它们作用到模型上——你会看到生成的这些变化，看起来真的就是各种各样的、自由的旋转。

### 镜像反例：正交矩阵不全是旋转

但是，不是所有的正交矩阵表示的都是旋转。

举个例子：这里有一只兔子，把它沿着 $y$ 轴这么转；底下还有一只兔子，它跟上面那只是有本质区别的——下面这只兔子无论怎么转，你都不可能把它转到上面那只的样子。大家可以在脑子里想象一下：这只兔子转一圈，是不会出现那种姿态的。但它们明明是同一只兔子，唯一的区别是：两只兔子实际上是一个**镜像**的关系，它们之间有一个反射。

用线性变换写出来的话：把兔子的 $z$ 轴乘一个 $-1$，这个矩阵 $A=\mathrm{diag}(1,\,1,\,-1)$ 就是一个反射变换。反射变换同样是一个正交矩阵——你可以验证 $AA^T$ 是一个单位矩阵——但是它永远无法通过旋转得到。

> **结论**：能够表示旋转的矩阵，是**行列式为 $+1$** 的正交矩阵。行列式等于全部特征值之积：一旦像镜像这样带出一个 $-1$ 的特征值，就代表有反射的成分，这种矩阵是永远转不出来的。这一点必须强调。

所有行列式为 $+1$ 的 $n$ 维正交矩阵的集合，就称为**特殊正交群**（Special Orthogonal Group），记作 $SO(n)$。大家可能在不同地方看到过 $SO(n)$ 代表旋转变换，它的含义其实就是字面意思：O 代表这个矩阵是正交矩阵（Orthogonal），Special 代表行列式为 $+1$、把反射排除在外，里面的 $n$ 代表维数。所以二维旋转矩阵的集合就是 $SO(2)$，三维旋转矩阵的集合就是 $SO(3)$。

### 把旋转当成一个群

我们说旋转矩阵是一个群——特殊正交群——那它自然就要满足群的一些特征。我们没必要在数学上非常严格地定义群是什么东西，但大家可以有个基本的概念：群里的这些元素进行运算的时候，得到的元素最终还是在这个群里的，也就是**对运算是封闭的**。

反映到旋转上，有这么几条：

- **封闭性**：任意两个旋转矩阵相乘，得到的结果依然是一个旋转。这也很容易理解：两个正交矩阵相乘，一定还是一个正交矩阵，而且行列式还是 $+1$。
- **结合律**：任意交换结合的顺序都可以——可以先 $R_0$ 乘 $R_1$、再整体乘 $R_2$，也可以 $R_0$ 去乘 $R_1$ 和 $R_2$ 的整体，结果一样。
- **可逆性**：对任意一个代表旋转变换的 $R$，它的逆变换就是 $R^T$。这一点是由旋转矩阵的正交性保证的：左边的模型通过 $R$ 旋转变到右边之后，就可以通过 $R^T$ 把它从右边变回左边。

但是旋转有一个比较奇怪的地方——这里注意，我们强调的是**三维**旋转。在二维里面，你先转 $10^\circ$ 再转 $20^\circ$，和先转 $20^\circ$ 再转 $10^\circ$，结果是一样的。三维里面由于旋转还有**旋转轴**的概念，就不一样了。举一个非常直观的例子：一个模型，先沿 $x$ 轴转 $90^\circ$，它会变成某个样子；再沿 $y$ 轴转 $90^\circ$，它会变成头朝上、四只脚朝右的朝向。而对于同样的模型，先沿 $y$ 轴转 $90^\circ$，它会先改成一个朝向；再沿 $x$ 轴转 $90^\circ$，它就会躺下——这个时候你会发现它的四只脚是朝左的。所以说，**三维旋转不满足交换律**。

### 表示旋转为什么是个重要课题

现在我们知道旋转到底是个什么东西了——它是行列式为 $+1$ 的正交矩阵。接下来的问题就是：我们如何去**表示**一个三维的旋转？

这个东西对于图形学来说是一个非常重要的课题，举一些例子。

比如游戏里面，我们要操作鼠标去移动镜头。鼠标在屏幕上的移动轨迹是一个二维的东西，只有 $x$ 方向和 $y$ 方向的位移；但是旋转矩阵是个 $3\times 3$ 的东西。那鼠标的这个操作，是如何映射到最后的旋转矩阵的变化上的？也就是说，如何通过鼠标去控制相机的朝向？

再比如角色动画里的**关键帧动画**。对于一个完整的人体运动序列来说，它里面有非常非常多的帧，但艺术家在创作的时候，往往只会指定中间的几帧关键帧——要求人物必须在这个时刻达到这个动作——中间的所有动作其实都是通过插值得到的。而对人体角色而言，各个关节之间差的就是一个旋转变换。那么如何在这些关键帧的关节旋转之中，插值出角色中间的旋转？

以及再比如，回到开头展示的那把 T 字形扳手。物理上去描述一个物体旋转、建立方程的时候，使用的其实是角速度、角动量；但最终我们是要回到物体的坐标上、回到旋转矩阵本身，才能把这个物体渲染出来。假如要模拟这样一个东西，角速度与刚体旋转之间的关系到底是什么？这也是值得研究的。

再比如说，现在神经网络是一个非常强大的工具。如果用神经网络去解决一些跟三维旋转有关的任务——比如估计一个物体的位姿，或者生成一些角色的动作——那就不可避免地需要网络去输出一些旋转矩阵。那么这个网络如何去输出这些矩阵？

这些问题合在一起，本质上就是：**我要研究如何在计算机里表示旋转本身，把这件事参数化，再用参数化之后的旋转去完成我想要的任务。**

### 数一数旋转的自由度

在讲各种表示之前，我们先需要弄清楚旋转的自由度是多少。因为只有知道自由度的个数，我才知道应该用多少个参数去对旋转进行描述。

二维情况非常简单：一个角度就可以描述。$\theta$ 的正负决定往哪个方向转，大小代表旋转的角度。

三维情况呢？如果根据旋转本身的定义来说：对于一个旋转，我首先要定义一个旋转轴——绕哪根轴进行旋转。旋转轴 $u$ 是一个三维向量，但我们会给这个三维向量加一个约束：$u$ 的模长应该是 1。因为 $u$ 本身只有它的方向有用，大小其实没有用——真正描述旋转大小的是角度 $\theta$，那是额外的一个参数。所以三维旋转的自由度是

$$(3 - 1) + 1 = 3$$

可以换一个角度去理解这个问题。旋转矩阵满足 $R^TR = I$，那把这个条件写开，到底对应几个方程？关键在于：$R^TR$ 本身一定是一个对称的矩阵，所以不相干的自由度里，只有对角元素和非对角元素（对称只算一份）是独立的。

以二维为例：$R$ 是 $2\times 2$ 的矩阵，一共 4 个自由度；$R^TR = I$ 对应的其实只有三个方程——对角元素 2 个（应该等于 1）加上非对角元素 1 个（应该等于 0），$2 + 1 = 3$。所以剩下的自由度是 $4 - 3 = 1$。

对于三维而言，故事是类似的：$R$ 是 $3\times 3$ 的矩阵，9 个自由度；$R^TR = I$ 对应对角线 3 个方程，剩下 6 个位置由于是对称矩阵只有 3 个独立，$3 + 3 = 6$ 个方程。$9 - 6 = 3$，三个自由度。

跟刚才按定义算的结果一样：二维旋转 1 个自由度，三维旋转 3 个自由度。

|  | 二维旋转 | 三维旋转 |
| :--- | :--- | :--- |
| 按定义数 | 一个角度 | 单位轴（$3-1$）＋角度（$+1$） |
| 按矩阵数 | $4-3=1$ | $9-6=3$ |

### 流形：旋转全体长什么样

介绍完自由度，可以引入一个稍微抽象一点的概念——**流形**（manifold）。今天肯定不会在数学上严格定义流形是什么东西，引入它只是为了给大家一个直观上的想象：我们研究的旋转，在空间中到底是一个怎样的分布。

流形是什么东西呢？举两个简单的例子。先看一个圆：我们称它是一个**二维空间中的一维流形**。为什么是二维空间？因为它是在平面上画的。为什么是一维流形？因为对这个圆来说，不考虑它的里面、只考虑圆的边界，它在局部的地方处处都近似于一个线段——而线段是一个一维的东西。

再看克莱因瓶：我们称它是**三维空间中的二维流形**。还是一样，它是三维空间里的，因为它被画成了一个三维的模型；但你凑得非常近去看它的每个局部，它其实还是一个平面——它本质上不是一个有实体的三维东西，本质上还是由平面这种曲面组合成的东西。

> **定义**：流形的直观含义——局部看是低维的东西（线段、平面），但整体上没办法把它展开摊平。比如圆，它没有办法展开成一维的一条线，因为它是首尾相接的，只有在二维空间里才能把它画出来。这就是流形。

为什么介绍流形这个概念？其实它跟刚才的自由度是联系起来的，能让我们看清"所有的旋转"在空间中是怎样分布的。

二维情况下，每一个旋转都是一个 $2\times 2$ 的矩阵。那么想象整个空间是一个**四维空间**，空间中的每一个点代表一个矩阵——我在这空间里随机踩一个点，这个点拿出来就是一个 $2\times 2$ 的矩阵，表示一个任意的线性变换。那么旋转是什么？所有的旋转在这个空间中会构成一条**一维流形**——因为二维旋转的自由度是 1，能动的只有一个自由度，就是角度。所以所有的旋转在这个空间中会组合成一条曲线。这条曲线长什么样子，我们暂时不用管，就认为它是一条曲线；在曲线上任意采样一个点，它都是一个旋转变换；并且曲线上相邻、接近的点，表示的旋转变换也是接近的——它是连续的。

三维旋转的情况会复杂一些：旋转是 $3\times 3$ 的矩阵，所以是**九维的空间**；自由度是 3，对应一个**三维流形**。我觉得应该没有同学能够想象出来，一个九维空间中的三维流形对应的是什么东西——我们能想到的可能只有一维流形、二维流形、最多三维流形，九维空间中的就有点难了。

那么现在可以对旋转给出一个更精确的描述：旋转首先是一个群（特殊正交群），同时所有的旋转又组合成一个流形。**既是群、又是流形**的东西，我们就称之为**李群**。大家可能在其他的地方——比如一些机器人的教材里——看到用李群、李代数去描述、推导旋转的概念，其实就是从这里来的。

### 流形视角的三个直观

引入流形这个概念，是为了对很多事情有直观上的理解。

#### 旋转插值为什么难

比如刚才提到的关键帧动画里会有旋转的插值。旋转插值这个事情为什么难？

如果直接拿 $3\times 3$ 的旋转矩阵去表示旋转、直接在矩阵里做线性插值，它会出问题。问题是什么？线性插出来的中间矩阵 $R_T$ 不一定还在流形上。假设流形是一个类似甜甜圈的东西——现在不管它的形状是什么，反正它一定是个曲面——随便选两个点做线性插值，中间插出来的点就不一定落在这个流形上。于是这个点代表的就不一定是一个旋转变换。所以直接做线性插值，插出来一定会是奇怪的东西：模型可能会先变小、再被拉伸，然后才慢慢回到右边 $R_1$ 的状态。

那我真正要做的是什么？在流形**里面**找到一条合理的路径，在这个路径上选一个点进行插值——最终要找的是这样一个点：它在流形上，同时在 $R_0$ 和 $R_1$ 连接的曲线上。并且大家可以想象，这条曲线应该越短越好：路径短，代表两个状态之间走的差别最小，这时插值过去才是最合理的动作。

这就是用流形视角去看旋转插值得到的结论。

#### 角速度住在切空间里

流形视角还有助于我们理解角速度的概念。

在正常的欧几里得空间里，有一条轨迹、一个点在这条轨迹上运动。求每个点的速度，只需要把位移 $X$ 拿出来对时间求个导数，对应的就是速度——位移是一个三维的向量，速度也是一个三维的向量，很整齐。

但是对于旋转来说：旋转是一个 $3\times 3$ 的矩阵，对它直接求导，求出来的也会是一个 $3\times 3$ 的东西。可是角速度 $\omega$——大家如果有了解的话——应该是一个三维的矢量，不是一个 $3\times 3$ 的矩阵。所以角速度和"对矩阵求导"之间，肯定不是一个直接相等的关系。

那么什么东西是三维的？我们刚才说了：旋转组成的流形是三维的。在流形上任意一点取它的**切空间**，切空间实际上是三维的东西。角速度与旋转之间的关系就是：**角速度是切空间上的一个矢量**——它本身是三维的；而旋转矩阵是流形上的点，住在九维里面。

#### 表示旋转就是给流形做参数化

今天要讲的旋转的表示问题，对应的其实是一个**流形的参数化**问题。

我有一个任意的流形，比如长得奇奇怪怪的，要给它贴上贴图——如果学过 GAMES101 就知道，每个点有 UV 坐标，UV 坐标是一个二维的东西，但整个模型是三维的东西。任务就是把这个三维的模型映射到二维空间里去，其实就是给模型做参数化——这就是对流形进行参数化的步骤。

对旋转而言：旋转本身是个 $3\times 3$ 的矩阵，我们要为它寻找不同的表达方法，本质上同样是给它找参数化——最终让这个问题对应一个**自由度为 3** 的东西，而不是一个 $3\times 3$ 的矩阵。所以我们今天介绍的各种各样的方法——欧拉角也好、轴角也好、四元数也好——本质上都是在用不同的方法，对旋转这个流形进行参数化的过程。

### 欧拉角：把一个旋转拆成三次绕轴

接下来进入比较细节的东西。旋转的第一种表示：**欧拉角**。

刚才说了，旋转是三个自由度的东西，那自然可以想到：把这个旋转分解到各个轴上，用绕各个轴旋转的角度来表达整个的旋转。这个表示方法就是欧拉角。

看一个分解成三步的例子：有一个球要对它进行旋转。第一步，先沿 $z$ 轴把它转 $\alpha$ 角；转完之后，再沿 $x$ 轴——也就是转过 $\alpha$ 之后模型上的那根新 $x$ 轴——转一个 $\beta$ 角，这个时候 $z$ 轴就会有一个偏移；最后再沿 $z$ 轴转一个 $\gamma$ 角，完成三次旋转。这三次旋转对应三个参变量 $\alpha$、$\beta$、$\gamma$，对应一个自由度为 3 的东西，理论上它就可以表示任意一个旋转。

#### 先分清两套坐标系

在推导欧拉角之前，我们先回顾一个东西：**旋转与坐标变换的关系**。

刚才所有介绍旋转矩阵的地方，我们都是固定在所谓的**世界坐标系**下考虑的：有一个固定不动的坐标系，然后看模型里面的点会怎么动。比如旋转前模型上有个点 $P$，旋转之后，它在世界坐标系下会变到 $P'_W$——W 就是 world，世界坐标系。

同时我还有另外一种观测方法：有一个坐标系固定绑在模型上没有动。对于模型上任意一点，由于整个旋转变换是一个刚性的变化，这个点相对于这个局部坐标系的坐标，在旋转前后是不应该发生变化的——也就是说 $P'_L$ 在整个旋转过程中保持不变，还是之前的坐标 $P$。

```text
同一个点 P，两种观测：

  世界坐标系（固定不动）：  P  --R-->  P'_W = R * P    （坐标变了）
  模型局部坐标系（跟随）：  P  --R-->  P'_L = P         （坐标没变）
```

读图：同一个旋转，站在"地面"上看，点的坐标被 $R$ 改写；坐在模型上看，点根本没动。

只在世界坐标系下考虑的话，我们有旋转关系 $P'_W = R\,P$，这个 $R$ 就是之前一直用的旋转矩阵。而 $P$ 其实等于 $P'_L$，所以也可以把它写成

$$P'_W = R\,P'_L$$

注意：等式左右两边表述的都是**旋转之后**的状态，它们唯一的区别是，对于同一个点 $P$，我选择了不同的坐标系——左边的 $P'_W$ 是世界坐标系下的表示，右边的 $P'_L$ 是局部坐标系下的表示。这两个表述根本上是同一点，只是中间会插一个旋转矩阵。

所以这个式子代表的就是：同一个点，换一个坐标系，它的坐标变换应该是什么。做渲染的时候就会用到它——比如要知道模型上任意一个三角形旋转之后在世界坐标系下在什么位置，乘一个旋转矩阵就可以了。

#### 一路代换推出公式

有了这个理解之后，我们就可以去推导欧拉角本身的公式了。刚才介绍的旋转顺序是：先沿 $z$ 轴转 $\alpha$，然后再沿 $x$ 轴转 $\beta$，最后再沿 $z$ 轴转 $\gamma$。三个基本旋转分别记作 $R_1$、$R_2$、$R_3$，我们来推坐标转换关系。

模型上固定的这个点，它在世界坐标系的位置，应该等于 $R_1$ 乘以它在"第一次旋转转完之后的那个坐标系"里的坐标 $x_{L1}$——这两个坐标系之间差的只有第一个 $\alpha$ 角对应的旋转 $R_1$：

$$x_W = R_1\,x_{L1}$$

而 $x_{L1}$ 是第一次旋转之后那个坐标系里的坐标，还可以进一步变到下一步的坐标系——转完 $\beta$ 角之后的坐标系——里，多出一个 $R_2$：

$$x_{L1} = R_2\,x_{L2}$$

最后一步 $\gamma$ 旋转一样的拆法。到这一步，$x_{L3}$ 就是绑定在旋转模型上的那个局部坐标系——模型本身的坐标系——下的坐标了：

```text
x_W  = R1 * x_L1
x_L1 = R2 * x_L2
x_L2 = R3 * x_L3
--------------------------------  一路代入
x_W  = (R1 * R2 * R3) * x_L3
```

读图：三行都是坐标变换关系，逐行把中间坐标代进去，就得到世界坐标与模型局部坐标之间的总变换。

这个 $R_1R_2R_3$ 就是欧拉角代表的旋转矩阵，把它拿出来写开：

$$R = R_z(\alpha)\,R_x(\beta)\,R_z(\gamma)$$

到这里拿到的是 ZXZ 这种顺序下的欧拉角。每一个基本旋转矩阵看它的局部：$R_z(\alpha)$ 其实就是单纯的一个绕 $z$ 轴的旋转矩阵，$z$ 轴是没有变的，唯一变动的是 $x$、$y$ 里那个 $2\times 2$ 的旋转矩阵；$R_x(\beta)$ 一样，$x$ 轴没动，$y$ 和 $z$ 在转；$R_z(\gamma)$ 同理：

$$R_z(\alpha) =
\begin{pmatrix}
\cos\alpha & -\sin\alpha & 0 \\
\sin\alpha & \cos\alpha & 0 \\
0 & 0 & 1
\end{pmatrix}
\qquad
R_x(\beta) =
\begin{pmatrix}
1 & 0 & 0 \\
0 & \cos\beta & -\sin\beta \\
0 & \sin\beta & \cos\beta
\end{pmatrix}$$

这就是欧拉角的三个分量：先建立每一个矩阵，再把三个矩阵乘起来，得到最终的矩阵。

课上弹幕里有同学问左乘和右乘的问题，这里说一下：我们这地方的 $x$ 都是**列向量**，所以要乘的话一般都是乘在左边。至于为什么 $R_2$、$R_3$ 看起来是"插在中间"——因为这里推的是**坐标的关系**：$x_{L1}$ 拆开成了 $R_2 x_{L2}$，$x_{L2}$ 又拆开成 $R_3 x_{L3}$，一路推下来，它自然就是这样一个嵌套相乘的关系，$R$ 都是乘在左边的。关于左乘右乘，待会还会有一个概念跟这个东西有关——这里先埋个伏笔。

#### 轴的顺序有很多种

为什么特意强调"ZXZ 这种顺序下"？因为欧拉角实际上有非常多的选择方法。

我们只说了旋转本身是三个自由度，并没有说你非得按照刚才这个顺序来——非得先 $z$ 转、然后 $x$ 转、然后再 $z$ 转。你可以自由选择：比如先 $x$ 转、然后再 $z$ 转、再 $x$ 转；或者先 $x$ 转、再绕 $y$ 转、再绕 $z$ 转。你想一想，这几个字母的组合方式有很多很多种。只要不是"沿 $x$ 轴转完之后接着再沿 $x$ 轴转"——那就重复了，两次就合成一次了——这种情况除外，其他所有的组合都是符合要求的，都可以表示所有的旋转。

但注意：每一种顺序，最后得到的旋转矩阵都是不一样的，形式都不一样。为什么？就是刚才提到的，旋转群**不满足交换律**——先沿 $x$ 轴转再沿 $z$ 轴转，和先沿 $z$ 轴转再沿 $x$ 轴转，结果完全不一样。所以每一种选择的方式，都会对应不同的结果。去维基百科或者其他资料上查，它会把不同组合方式对应的旋转矩阵列出来，方便大家查表使用。

#### 内旋与外旋

除了不同轴的组合顺序之外，欧拉角还有一个比较烦人的东西：**内旋和外旋**的区别。

刚才给大家介绍的这种旋转方式，对应的是**内旋**：每次旋转都是绕"之前旋转之后的那个坐标系"的轴转。回头看刚才的分解过程：第一次转完之后，接下来是沿着转过来的新轴去转；最后一次绕 $z$ 轴转的时候，绕的也不是最开始那根 $z$ 轴，而是跟着模型一起转过来的那根 $z$ 轴。这个东西就称为内旋。

与之对应的就是**外旋**：每一次旋转沿的轴，都是最外面固定的那个世界坐标系的轴。先沿世界系的 $z$ 轴转，这时 $x$、$y$ 的角度会发生一些偏移；然后再转的时候，我不沿转完之后转过来的轴转，而是沿着世界坐标系本来的 $y$ 轴转；$x$ 轴也一样，还是沿着本身那个固定坐标系的 $x$ 轴去转。这个东西叫外旋。

|  | 内旋 | 外旋 |
| :--- | :--- | :--- |
| 每一步绕哪根轴 | 上一步转完之后、跟着模型更新的那根轴 | 始终是最外面固定的世界坐标系的轴 |

内旋和外旋之间是有联系的，大家可以想象一下联系是什么。课上已经有同学提到了：它跟这三个矩阵旋转的**相乘顺序**有关——对，确实是有关的。这个东西我们就把它留成一个作业，大家可以回去尝试推一推：用刚才介绍的坐标变换、照着推欧拉角公式的方法，看一看内旋和外旋的旋转矩阵到底对应一个什么样的关系。

顺便兑现刚才的伏笔：推导欧拉角时说的"待会还有一个概念会跟左乘右乘有关"，说的就是它——内旋与外旋，正对应基本旋转矩阵不同的相乘方式。

总的来说，欧拉角这个东西虽然很直观——我就是绕三根轴各转一下——但是由于它有非常多的顺序选择、以及内旋外旋的规范，所以用的时候一定要谨慎：不同软件里面规定的顺序可能就完全不一样。

### 相机怎么转：航空业的三个角

回到刚才提出的问题：游戏里面我们需要移动鼠标去控制相机的转动。这个时候有一个通用的规范，是从航空业那边来的——他们对这三个角有具体的含义。

可以想象一架飞机：

| 角 | 绕哪根轴 | 含义 |
| :--- | :--- | :--- |
| roll（横滚） | 机体本身的轴 | 机身翻滚，不改变航向 |
| yaw（航向） | 垂直于机身的竖直方向 | 飞机往哪边飞的航向角 |
| pitch（俯仰） | 水平方向上的另一根轴 | 机头往上飞还是往下飞 |

对于我们游戏里的相机来说，你可以把它想象成一架飞机，无非就是控制机头朝哪个地方。那么其实需要调节的，就是它的**航向角**和**俯仰角**。大家去看一些代码就会发现，这两个角度的叫法一个叫 pitch，一个叫 yaw。一般来说我们不需要 roll——你也不希望相机翻来翻去，人看着会比较晕。

刚才提到不同软件的规范是不一样的。比如 Blender 的界面里就有非常多的不同旋转方式：XYZ、XZY、YXZ 这些之类的东西。Blender 是开源免费的，可以去玩一玩，看看不同角度选择的效果。它做得比较好的地方是：如果你去改变它的这个选择，它会自动帮你把角度换算过来——比如设置是 X60、Y20、Z0，把 XYZ 换成 YXZ 之后，这三个角度值是会改变的，但物体的朝向不会改变：同一个朝向，不同顺序下三个角度的数值不一样。

### 万向锁：被锁死的那个方向

欧拉角的优势大家也看到了：非常直观。但它有一个非常致命的问题，称之为**万向锁**（gimbal lock）。

万向锁代表什么含义？看这样一种情况：当航向的那个环和俯仰的那个环——它们俩平行的时候，你去转横滚的环、以及转最外面的航向环，对于飞机来说，转动的方式都是一样的：都对应飞机的一个横滚动作。

把这一帧单独拿出来看，你就会发现：这个飞机做不了沿某根轴的旋转——是哪个轴呢？航向。也就是说，在这个配置（configuration）下，不管你怎么转，飞机都改变不了它的航向。

这个现象就称为万向锁。它表示：虽然我是用三个参数去表达一个三维流形，但在这个点上是一个**奇点**——明明有三个参数，但这三个参数在这个点上只能控制两个方向，还有一个方向被 lock 住了。这个东西就非常不好：如果我要做的事情，比如我就是希望在这个点附近它是连续的、还需要做一些别的操作，那这个问题就比较严重。所以万向锁是欧拉角一个非常严重的问题。

> **易错点**：万向锁不是参数变少了——参数还是三个——而是参数化在这个点上退化了：转其中两个环得到的是同一个动作，有一个方向（这里是航向）无论怎么转都到不了。

### 轴角表示与旋转向量

接下来看另外一个表示：**轴角表示**。

轴角表示其实它就是旋转的一个定义：给定一个旋转轴，给定一个转动的角度 $\theta$，它就可以定义一个旋转。刚才也给大家算过了：虽然它是"一个向量加一个标量"，实际对应的自由度是三个。

还可以把它换一个写法，写成**旋转向量**的形式：把 $\theta$ 角乘到旋转轴上，也就是 $\theta u$。这个时候它就是一个三维向量——这个向量的**模长表示的就是旋转角度，方向对应的就是旋转轴**。所以我就可以用一个三维的向量，表示一个完整的旋转。

### 罗德里格旋转公式

接下来需要推一个东西：轴角表示下，给你 $u$ 和 $\theta$，对应的旋转矩阵到底是什么？

推导的核心思路：把要旋转的这个向量 $v$ 分解到两个方向上——第一个方向是跟旋转轴平行的方向 $v_\parallel$，第二个是垂直于旋转轴的平面上的分量 $v_\perp$——然后分别看这两个方向经过旋转之后会怎么动。

在平行分量上，$v_\parallel$ 很自然：它不会动。核心是垂直方向的分量，从原来的 $v_\perp$ 变到了一个新的方向。把公式写出来就是：

$$v' = v_\parallel + \cos\theta\, v_\perp + \sin\theta\, (u \times v_\perp)$$

平行分量不动，可以直接写开：把 $v$ 投影到 $u$ 上，再乘以 $u$ 的方向，也就是 $v_\parallel = (v^Tu)\,u$。后面"旋转之后的垂直分量"那一项 $\cos\theta\,v_\perp + \sin\theta\,(u\times v_\perp)$，对应的其实是一个**二维的旋转公式**：一个 $\cos\theta$、一个 $\sin\theta$；$v_\perp$ 是原本的方向，而 $u\times v_\perp$ 是旋转轴叉乘它得到的那个 $w$ 方向——跟这两个东西都垂直。在垂直于轴的平面里，以"原方向＋垂直方向"为基转 $\theta$ 角，正是二维旋转的样子。

接下来把这一堆公式搞到一起。$v_\perp$ 可以写成 $v - v_\parallel$；三重叉积有"点乘减去本身"的展开式：

$$u \times (u \times v) = (v^Tu)\,u - v$$

代入整理，再把 $v$ 提出来：第一项就是一个 identity matrix；$u\times(u\times v)$ 这一项，可以用叉乘的矩阵表达——把 $u$ 外面加一个方括号写成矩阵形式 $[u]_\times$，叉两次就是这个矩阵的平方；$\sin\theta\,u\times v$ 那一项，就是拿 $[u]_\times$ 去乘 $v$。最后就可以把旋转矩阵单独拿出来，它是一个关于 $u$ 和 $\theta$ 的方程：

$$R(u,\theta) = I + \sin\theta\,[u]_\times + (1-\cos\theta)\,[u]_\times^2$$

这个公式称为**罗德里格旋转公式**（Rodrigues' rotation formula）。其中 $[u]_\times$ 是把叉乘写成矩阵的形式，满足 $[u]_\times v = u\times v$：

$$[u]_\times =
\begin{pmatrix}
0 & -u_z & u_y \\
u_z & 0 & -u_x \\
-u_y & u_x & 0
\end{pmatrix}$$

推导讲到这里，只是给大家介绍一个逻辑，想推的同学可以回去自己推一下。关于这个公式本身——它还挺重要的——大家要能看懂。

### 反方向：从矩阵反解轴与角

有了这个旋转矩阵的表达之后，我们只解决了一个方向：有了 $u$ 和 $\theta$ 之后，怎么得到旋转矩阵 $R$。反过来还有一个方向：我有一个旋转矩阵 $R$，怎么得到它的旋转轴 $u$ 和旋转角度 $\theta$？

可以从旋转公式本身推一些性质出来。比如考虑旋转矩阵的 **trace**（迹）。三项的迹都可以算：

- identity matrix 的 trace 是 3；
- $[u]_\times^2$ 的 trace：把 $[u]_\times$ 的公式带进去，注意到 $u$ 的模长是 1，可以自然算出来，它是 $-2$；
- $[u]_\times$ 本身的 trace 是 0——它是一个反对称矩阵，对角线全是零。

三个东西带进去之后，可以得到

$$\mathrm{tr}(R) = 1 + 2\cos\theta$$

这个东西非常好的地方在于：它跟 $u$ 没有关系了。所以我就可以单独把角度拿出来，得到 $\theta$ 与旋转矩阵 $R$ 的关系：

$$\theta = \arccos\frac{\mathrm{tr}(R) - 1}{2}$$

有了 $\theta$ 之后，旋转轴 $u$ 怎么算呢？我们先推一个东西：$[u]_\times^2$ 的具体形式。把 $[u]_\times^2$ 乘以一个任意的向量 $v$，展开就是 $u\times(u\times v)$，利用三重叉积的展开写成矩阵形式——由于 $v$ 是任意选择的，两边的 $v$ 可以直接约掉，得到

$$[u]_\times^2 = uu^T - I$$

你会发现：$[u]_\times$ 本身是一个反对称矩阵，但它平方之后是一个**对称矩阵**——$uu^T$ 是对称的，$I$ 也是对称的。

再观察罗德里格公式里的三项：$I$ 是对称矩阵，$uu^T$ 是对称矩阵，只有最后一项 $\sin\theta\,[u]_\times$ 是反对称矩阵。那可以干一件事：把 $R$ 减去 $R^T$——前面两项由于是对称矩阵，直接消掉，只剩下最后一项反对称项：

$$R - R^T = 2\sin\theta\,[u]_\times$$

$\theta$ 我们之前已经推出来了，把 $\sin\theta$ 除过去，右边就只剩下 $[u]_\times$，从这个反对称矩阵的元素里就能把旋转轴 $u$ 读出来。这样两个方向都能推了：既可以从 $(u,\theta)$ 得到 $R$，也可以从 $R$ 反解出旋转轴和旋转角度。

顺便补一个等价形式：把 $[u]_\times^2 = uu^T - I$ 代回罗德里格公式，就得到文献里同样常见的一个写法

$$R = \cos\theta\,I + (1-\cos\theta)\,uu^T + \sin\theta\,[u]_\times$$

### 指数形式：把旋转向量放进指数

同时，旋转矩阵还有一个非常神奇的形式：**指数形式**。

刚才说 $R$ 与 $u$、$\theta$ 的关系是罗德里格公式给出来的。其实可以把它写成这样一个指数形式——把一个 $3\times 3$ 的矩阵放到指数上：

$$R = \exp\big(\theta\,[u]_\times\big) = \exp\big([\theta u]_\times\big)$$

把 $\theta$ 乘进去，利用最开始定义的旋转向量 $\theta u$，就得到后面这个式子。这个式子非常干净：旋转向量和旋转矩阵 $R$ 之间的关系，就是一个指数关系。

那这个指数是哪里来的？对一个任意的 $3\times 3$ 矩阵算它的指数，利用的是指数的展开形式——泰勒级数：

$$e^X = I + X + \frac{1}{2!}X^2 + \frac{1}{3!}X^3 + \cdots$$

里面的每一项都可以计算。刚才算过 $[u]_\times^2 = uu^T - I$，把它再乘一个 $[u]_\times$：$[u]_\times$ 乘以 $u$ 应该是零——因为 $u\times u$ 本身是零——所以实际上只会剩下

$$[u]_\times^3 = -[u]_\times$$

一样地可以得到四次方、五次方。到五次方它就会有一个**回归**：$[u]_\times^5 = [u]_\times$。所以这个式子不需要无限地推下去——它本身是一个 1、2、3、4 一循环的东西。

把循环利用起来，放进展开式里：所有 $[u]_\times$ 这一项、以及 $[u]_\times^2$ 这一项，把前面的系数分别合到一起：

$$e^{\theta[u]_\times} = I + \Big(\theta - \frac{\theta^3}{3!} + \frac{\theta^5}{5!} - \cdots\Big)[u]_\times + \Big(\frac{\theta^2}{2!} - \frac{\theta^4}{4!} + \cdots\Big)[u]_\times^2$$

这组系数大家应该就比较眼熟了：前面一个系数对应的是 $\sin\theta$ 的展开，后面一个系数对应的是 $1-\cos\theta$ 的展开。于是我又把它从一个级数变成一个紧的（compact）形式——而这个形式正好就是罗德里格旋转公式。所以说，指数形式也是从旋转向量到旋转矩阵的一种正确的表达方式。

这么巧的东西，它当然不是一个纯粹的巧合。它其实反映的是一个更本质的东西：**从李代数到李群的指数映射关系**。这个我们今天肯定不会讲到，大家如果有兴趣可以去研究一下，非常有意思：它描述的是——从切空间上拿一个向量出来，然后往前走；走的时候对应的其实是在球面上、在那个曲面上、在流形上走；最后积分积出来一个指数形式。今天不涉及，只是把它拿出来给大家看一下：有这么一个东西存在。

### 用轴角做旋转插值

有了轴角表示之后，可以研究一个问题：怎么去插值一个旋转？可以利用刚才推出的轴角表示与旋转矩阵的关系，分成这么几步进行。初始状态 $t=0$ 的时候是 $R_0$，$t=1$ 的时候是 $R_1$，要插中间 $t$ 时刻的状态：

```text
R0 (t=0),  R1 (t=1)
   |
   |  ΔR = R1 * R0^T            -- 相对旋转（R0^T 即 R0 的逆）
   v
(u, Δθ)                        -- 轴角反解：轴 + 相对角度
   |
   |  固定轴 u 不动，只插角度：θ_T = t * Δθ
   v
ΔR_T = R(u, θ_T)               -- 再用一次罗德里格公式
   |
   v
R_T = ΔR_T * R0                -- 合成最终的旋转矩阵
```

读图：先把两个端点之间的"旋转差"算出来，在"轴固定、只有角度在变"的这条线上做插值，最后再合成回去。

具体来说：先算一个相对旋转矩阵 $\Delta R = R_1 R_0^T$——$R_0^T$ 其实也就是 $R_0$ 的逆——它反映的就是从 $R_0$ 到 $R_1$ 的一个相对旋转。然后可以把这个相对旋转通过轴角表示，转化成一个转动角度 $\Delta\theta$ 和相对旋转的轴 $u$。接下来要插值的时候，我就可以固定这个旋转轴不动，只插值它的旋转角度：$\theta_T = t\,\Delta\theta$。然后用这个 $\theta_T$ 和中间的相对旋转轴这两个东西，再用一次罗德里格公式，得到中间的旋转 $\Delta R_T$；再把这个 $\Delta R_T$ 乘到 $R_0$ 之上，就可以得到最终的旋转矩阵 $R_T$。

这样插出来，中间的状态都是对的。但是有一件事情是错的：直接拿**旋转向量**做线性插值，插出来的结果是不对的。

举个例子：左边的旋转向量代表绕 $(1,0,0)$ 这个轴转了 $\dfrac{3\pi}{2}$，末状态是绕 $y$ 轴转 $\dfrac{3\pi}{2}$。两个旋转向量，如果直接拿去做线性插值，插出来会是一个非常诡异的结果：中间状态确实都是旋转，但它走的不是最短路径——看起来绕来绕去，绕了很多圈之后才回到右边的状态。

但是如果你直接去算它的相对旋转，然后再用相对旋转的角度做线性插值，插出来的就直接是对的——因为那是绕一根固定的轴、直接做的一个旋转。

> **易错点**：可以插的是"相对旋转的角度"，不是"旋转向量"本身。旋转向量的模长就是角度，对它做线性插值会走出绕远路的轨迹。

## 四元数与角速度：三维旋转表达的下半场
> 对应块：BLK09 | 覆盖分集：P04下 | 块标题（分集名）：《旋转变换》

先把上一部分的尾巴收干净。拿旋转向量做插值有一个一定要注意的点：**不能用旋转向量直接插值**——要做插值，得用相对旋转。

> **易错点**：旋转向量不能直接拿来做插值；插值要走"相对旋转"那条路。

那么介绍完旋转向量之后，最后再介绍一种方法：**四元数**。这是一个相当重要的概念——以后你们用一些库的时候会发现，里面的旋转向量、旋转矩阵，大概率是拿四元数来存的。它同时也是一个相对来说比较难的东西。不过，有了前面旋转向量这些基础打底，理解四元数其实没有那么难，我尽量用一种相对直观的方式给大家介绍。

### 从哈密顿的桥说起

四元数的发明历史本身就很有说头。主角是哈密顿勋爵。他脑子里一直转着一个问题：如何表达三维的旋转——用一个什么样的"数"去表达它（说"数据结构"都不对，就是要找一个数）。这个问题他想了很久很久。

然后某一天，他走到一座桥上的时候，突然灵光一现。那座桥的墙上至今留着 flash of genius——天才的灵光一现——他在那一刻顿悟了四元数应该长什么样，然后立马回家把这个东西推完，推完发现它就是对的。这座桥也因此成了一个景点：数学圈里有个传统，没什么思路的时候，去桥上走一走，说不定就灵光乍现、哈密顿勋爵灵魂附体，把问题想出来了。

当然，这个故事还有半截不能丢：那道灵光，是建立在他本身思考这个问题很久的基础上的。没有前面长年累月的琢磨，桥走得再勤也走不出四元数。

那么在介绍四元数之前，我们可以先从二维旋转入手——因为二维旋转早就有自己的代数了，就是复数。

### 复数：二维旋转的另一种写法

复数应该是大家都理解的东西：在实数轴之外加一根虚轴，用它张成复平面——而这个复平面上正好自带一些旋转的结构。我们来回顾一下二维旋转的矩阵表达和复数表达之间的对应关系。

对二维旋转来说，我可以用一个旋转矩阵来表达它；同时，平面上的点 $(x,y)$ 也可以写成一个复数 $z = x + \mathrm{i}y$。变换之后的 $z'$ 和变换之前的 $z$ 之间，就差了一次复数相乘：

$$z' = c\,z, \qquad c = \cos\theta + \mathrm{i}\sin\theta$$

这个复数相乘是从哪里来的？把两个复数的乘法展开就清楚了。设 $c = a + b\,\mathrm{i}$，那么

$$c\,z = (a + b\,\mathrm{i})(x + \mathrm{i}y) = (ax - by) + (ay + bx)\,\mathrm{i}$$

实部是 $ax - by$，虚部是 $ay + bx$。现在换到矩阵这边：拿一个形如下面的矩阵去乘 $(x,y)$，

$$\begin{pmatrix} a & -b \\ b & a \end{pmatrix}\begin{pmatrix} x \\ y \end{pmatrix} = \begin{pmatrix} ax - by \\ ay + bx \end{pmatrix}$$

得到的两个分量，正好对应复数乘完之后的实部和虚部。换句话说，**复数的乘法可以写成矩阵形式**：给 $c$ 加个方括号记作 $[c]$，它对应的就是复数本身的矩阵表达，复数相乘 $cz$ 对应矩阵相乘 $[c][z]$。特别地，当 $c = \cos\theta + \mathrm{i}\sin\theta$ 时，$[c]$ 恰好就是二维旋转矩阵。

可以验证一下。取纯虚复数 $\mathrm{i}$，它有这样一个循环关系：

$$\mathrm{i}^2 = -1, \qquad \mathrm{i}^3 = -\mathrm{i}, \qquad \mathrm{i}^4 = 1$$

把 $\mathrm{i}$ 的矩阵形式写出来：实部是零，所以对角线是零；虚部是一，所以非对角线一个 $-1$、一个 $1$：

$$[\mathrm{i}] = \begin{pmatrix} 0 & -1 \\ 1 & 0 \end{pmatrix}$$

拿这个矩阵自己乘一次，乘出来对角线上是 $-1$、非对角线是零——实部 $-1$、虚部 $0$，代表的复数正是 $-1$，也就是 $\mathrm{i}^2$；接着再乘，会变成 $-\mathrm{i}$ 对应的矩阵；乘到第四次，回到单位矩阵，单位矩阵就是 $1$。循环关系在矩阵这边原样复现，对应关系成立。

复数还有一个特别的东西：它可以写成指数形式。这个公式大家都知道，就是欧拉公式——$e^{\mathrm{i}\pi} + 1 = 0$ 说的就是它。一般地，$e^{\mathrm{i}\theta} = \cos\theta + \mathrm{i}\sin\theta$。复数有指数形式，那么矩阵这边同样也会有：把这个矩阵写到指数里面来，就得到一个级数。把这个级数展开，跟上一部分推三维旋转罗德里格斯公式时处理指数的套路一模一样——把对应的项提到一起，看一下前面的系数，就会发现一个是 $\cos\theta$、一个是 $\sin\theta$；收拢起来再看：

$$e^{\theta[\mathrm{i}]} = \cos\theta\,I + \sin\theta\,[\mathrm{i}]$$

得到的正是最开始那个二维旋转矩阵。

> **结论**：复数和矩阵是两套语言，描述的是同一个概念——都可以用来表示二维旋转。

### 四元数：定义与乘法

那么四元数是什么？它就是我们引入的、与三维旋转矩阵相对应的、用来表示三维旋转的一个代数。可以这么想：复数是"适用于旋转的虚数"——二维旋转有虚数（复数）表达，那三维旋转就可以有一些对应的四元数表达。

四元数跟复数有点像，只不过除了 $\mathrm{i}$ 之外，它还有 $\mathrm{j}$ 和 $\mathrm{k}$——三个都是"类似虚数的东西"。复数对应的是复平面，四元数对应的则是一个四维空间：它有四根轴，分别是实数轴、$\mathrm{i}$ 的轴、$\mathrm{j}$ 的轴和 $\mathrm{k}$ 的轴。$\mathrm{i}$、$\mathrm{j}$、$\mathrm{k}$ 可以称为类似"基石"的东西，它们之间满足这样一个相乘的关系：

$$\mathrm{i}^2 = \mathrm{j}^2 = \mathrm{k}^2 = \mathrm{i}\mathrm{j}\mathrm{k} = -1$$

这就是四元数最开始的定义：定义这么一个数，它满足这样的运算规则。

> **定义**：四元数 $q = a + b\,\mathrm{i} + c\,\mathrm{j} + d\,\mathrm{k}$，三个虚单位满足 $\mathrm{i}^2 = \mathrm{j}^2 = \mathrm{k}^2 = \mathrm{i}\mathrm{j}\mathrm{k} = -1$。

由此就可以推导四元数的乘法。取两个四元数，它们一共八个系数：

$$q_1 = a + b\,\mathrm{i} + c\,\mathrm{j} + d\,\mathrm{k}, \qquad q_2 = e + f\,\mathrm{i} + g\,\mathrm{j} + h\,\mathrm{k}$$

把乘积逐项摊开来看：比如 $b\mathrm{i}$ 乘 $f\mathrm{i}$，等于 $bf\,\mathrm{i}^2 = -bf$，落回一个实数。那 $\mathrm{j}$ 乘 $\mathrm{k}$ 怎么办？从刚才的定义里推：$\mathrm{i}^2 = \mathrm{i}\mathrm{j}\mathrm{k}$，两边同时约掉一个 $\mathrm{i}$，就得到 $\mathrm{j}\mathrm{k} = \mathrm{i}$。它就有这样的相乘关系；同理 $\mathrm{i}\mathrm{j} = \mathrm{k}$、$\mathrm{k}\mathrm{i} = \mathrm{j}$，而反序相乘要变号：$\mathrm{j}\mathrm{i} = -\mathrm{k}$、$\mathrm{k}\mathrm{j} = -\mathrm{i}$、$\mathrm{i}\mathrm{k} = -\mathrm{j}$。

全部乘出来之后，两个四元数的乘积还是一个四元数：一个实部，加上 $\mathrm{i}$、$\mathrm{j}$、$\mathrm{k}$ 各自对应的虚部，只是前面的系数都比较长。为了计算简便，旁边放一张乘法表，随查随用——比如 $1\times 1 = 1$，$\mathrm{i}\times\mathrm{i} = -1$：

| $\otimes$ | $1$ | $\mathrm{i}$ | $\mathrm{j}$ | $\mathrm{k}$ |
| :---: | :---: | :---: | :---: | :---: |
| $1$ | $1$ | $\mathrm{i}$ | $\mathrm{j}$ | $\mathrm{k}$ |
| $\mathrm{i}$ | $\mathrm{i}$ | $-1$ | $\mathrm{k}$ | $-\mathrm{j}$ |
| $\mathrm{j}$ | $\mathrm{j}$ | $-\mathrm{k}$ | $-1$ | $\mathrm{i}$ |
| $\mathrm{k}$ | $\mathrm{k}$ | $\mathrm{j}$ | $-\mathrm{i}$ | $-1$ |

读表方式：行是左因子、列是右因子——$\mathrm{i}$ 行 $\mathrm{j}$ 列的 $k$ 就是 $\mathrm{i}\mathrm{j} = \mathrm{k}$；对角线上三个 $-1$ 是三个虚单位的平方；交换顺序的位置（如 $\mathrm{j}\mathrm{i}$）差一个负号。

除了查表，还可以把乘法写成矩阵形式，跟刚才复数那边一模一样的思路：把第一个四元数写成一个 $4\times 4$ 矩阵，把第二个四元数写成一个四维列向量，做一次矩阵乘法，乘出来的四个分量就是乘积四元数的四个系数。也就是说，查表也行、矩阵乘也行，两条路算的是同一个乘法。

### 标量加向量：四元数的顺手写法

四元数乘法其实还有另外一种写法。四元数虽然有四个分量，但我可以选择把它写成一个**标量**加上一个**类似矢量的东西**：$a$ 是标量；剩下那部分 $\mathbf{v} = b\,\mathrm{i} + c\,\mathrm{j} + d\,\mathrm{k}$ 当作一个三维矢量——它有三个维度，每个维度上有一块基石（$\mathrm{i}$、$\mathrm{j}$、$\mathrm{k}$）。于是四个参数的东西就写成了

$$q = a + \mathbf{v}$$

这样写有什么好处？两个四元数相乘，可以简便地写成下面这个紧凑形式。设 $q_1 = a + \mathbf{v}$、$q_2 = e + \mathbf{u}$，则

$$q_1\,q_2 = \Big(ae - \mathbf{v}\cdot\mathbf{u},\;\; a\mathbf{v} + e\mathbf{u} + \mathbf{v}\times\mathbf{u}\Big)$$

这个形式怎么来的？回到上一节把八个系数摊开的那个结果，逐项去看：$ae$ 对应的就是两个标量部分的乘法；$-bf - cg - dh$，其实就是把两组虚部系数当成两个普通的三维向量做点乘、再取负，也就是 $-\mathbf{v}\cdot\mathbf{u}$——这两项你可以把它们理解成正常的向量运算，已经不是四元数的事了；剩下带 $\mathrm{i}\mathrm{j}$、$\mathrm{j}\mathrm{k}$ 的交叉项收拢起来，正好是 $\mathbf{v}\times\mathbf{u}$。

为什么四元数跟旋转有关系？这个地方其实就已经能体现出来：公式里有一个 $\mathbf{v}\times\mathbf{u}$，出现了**叉乘**的结构——而旋转矩阵里面也有叉乘。后面我们就会利用这个东西，把四元数和旋转矩阵建立起联系。

同时，通过这个公式大家还可以发现：四元数的乘法**不满足交换律**。$q_1 q_2$ 和 $q_2 q_1$ 是不一样的——因为这里有一个叉乘，叉乘一旦交换顺序就会变一个符号。

还有一个特殊角色：如果一个四元数的实部是零（$a = 0$），我们称它为**纯四元数**，或者叫纯虚四元数，都可以。这时它的乘法就会有一些简化：两个标量都是零，乘出来的实部就只剩一个负的点乘，虚部就只剩一个叉乘：

$$(0,\mathbf{v})(0,\mathbf{u}) = \big(-\mathbf{v}\cdot\mathbf{u},\;\; \mathbf{v}\times\mathbf{u}\big)$$

所以纯四元数的乘法，本身就是一个能反映"向量之间做点乘、叉乘"这些操作的机器。

矩阵形式也可以用标量加向量的方式简化。把上一节那个 $4\times 4$ 矩阵重新排一下：对角线上的 $a$ 挪出来，$\mathbf{v}$ 的三个分量放到边上，剩下的那一块对应的就是一个**叉乘矩阵**的形式——把 $\mathbf{v}$ 拿出来写成叉乘矩阵（记作 $\mathbf{v}^{\times}$，满足 $\mathbf{v}^{\times}\mathbf{u} = \mathbf{v}\times\mathbf{u}$）：

$$[q] = \begin{pmatrix} a & -\mathbf{v}^{\top} \\ \mathbf{v} & aI + \mathbf{v}^{\times} \end{pmatrix}$$

它跟分量形式的写法一模一样，只是换了一种摆放。

到这里，四元数其实一共介绍了三种表示：第一种是最开始定义它的**分量表示**，第二种是**向量表示**（标量加矢量），第三种是**矩阵表示**。这三种表示写的都是同一个四元数。

### 共轭、模长与逆

接下来可以分别在这三种表示下，定义四元数的**共轭**。就像虚数的共轭一样：把对应的虚单位 $\mathrm{i}$、$\mathrm{j}$、$\mathrm{k}$ 前面的正号统统变成负号。分量形式下，$q = a + b\,\mathrm{i} + c\,\mathrm{j} + d\,\mathrm{k}$ 的共轭就是

$$q^{*} = a - b\,\mathrm{i} - c\,\mathrm{j} - d\,\mathrm{k}$$

定义共轭有一个直接的好处：$q$ 乘以 $q^{*}$，乘出来是一个**纯实数**——后面那些虚的部分全部相互抵消了。大家可以用最开始那张乘法表回去自己推一推，会发现 $\mathrm{i}$、$\mathrm{j}$、$\mathrm{k}$ 前面的系数全都是零，只剩下最开头的实数 $a^2 + b^2 + c^2 + d^2$。

向量形式下看这个过程最省力。$q = (a, \mathbf{v})$，它的共轭就是在 $\mathbf{v}$ 前面加一个负号，即 $(a, -\mathbf{v})$。套上乘法公式：实部等于"前面两个标量相乘，减去后面两个矢量点乘"，也就是 $a\cdot a - \mathbf{v}\cdot(-\mathbf{v}) = a^2 + \mathbf{v}\cdot\mathbf{v}$；虚部这边，$a\mathbf{v}$ 和 $e\mathbf{u}$ 那两项对应过来是 $a\mathbf{v} - a\mathbf{v}$，正好抵消，而叉乘那一项是 $\mathbf{v}\times(-\mathbf{v})$，天生是零。所以乘出来就是一个纯实数。矩阵形式下也一样：两个矩阵做分块乘法，乘出来是一个纯对角的形式——这个纯对角矩阵不是别的什么，正是那个纯实数对应的矩阵。三种表示都可以推到同样的结果。

这个纯实数太有用了，我们直接给它一个名字：它就是 $q$ 这个四元数**模长的平方**——把四个参数拿出来各自平方、再求和：

$$|q|^2 = a^2 + b^2 + c^2 + d^2$$

利用共轭，就可以定义四元数的**逆**：

$$q^{-1} = \frac{q^{*}}{|q|^2}$$

为什么它可以长成这个形式？左边乘一个 $q$ 验证一下：$q\cdot\dfrac{q^{*}}{|q|^2} = \dfrac{q\,q^{*}}{|q|^2} = 1$，所以 $q\,q^{-1} = 1$，它就是逆。特别地，如果 $q$ 是一个**单位四元数**——模长为一——那么直接有 $q^{-1} = q^{*}$：单位四元数的逆就是它的共轭。这一条马上就要用到。

### 组合旋转、双倍覆盖与指数形式

四元数用来表示旋转，也会有一些对应的性质。

**多次旋转，一路乘过去。** 旋转是满足结合律的——它是一个乘法群，满足群的结构；四元数也一样。对多次旋转来说，其实不需要把每一步都老老实实写成三明治：把单次旋转的四元数拿出来，一路给它乘过去，就可以得到最终旋转对应的那个四元数。为什么呢？一步一步来就明白了：第一次旋转 $\mathbf{v}_1 = q_1\,\mathbf{v}\,q_1^{*}$；第二次旋转在 $\mathbf{v}_1$ 的基础上再转 $q_2$，$\mathbf{v}_2 = q_2\,\mathbf{v}_1\,q_2^{*}$；把 $\mathbf{v}_1$ 代进去：

$$\mathbf{v}_2 = q_2\,q_1\,\mathbf{v}\,q_1^{*}\,q_2^{*} = (q_2\,q_1)\,\mathbf{v}\,(q_2\,q_1)^{*}$$

最后一步利用了共轭的一条公式：$q_1^{*}\,q_2^{*} = (q_2\,q_1)^{*}$——共轭会把乘积顺序倒过来，大家可以推一推。你看后面这个形式，它其实就是直接做了一次 $q_2\,q_1$ 对应的旋转。所以连续旋转的复合，就是四元数按顺序相乘。

**$q$ 和 $-q$ 表示相同的旋转。** 这点可能比较奇怪：给 $q$ 加一个负号，怎么还是同一个旋转？从公式上看很直接：三明治里 $q$ 出现了两次，加负号之后 $-1\times(-1) = 1$，负号自己消掉了。所以 $q$ 和 $-q$ 表示的其实是相同的旋转。这一条记住，后面讲插值的时候它会回来找我们。

**指数形式。** 四元数同样有指数形式，而且跟之前矩阵的指数形式是一一对应起来的：刚才在二维情况里说过，二维矩阵有指数形式，二维复数也有指数形式；前面又推了三维矩阵（罗德里格斯公式）有指数形式；那么对应的，四元数也有它的指数形式：

$$q = \cos\frac{\theta}{2} + \sin\frac{\theta}{2}\,\mathbf{u} = e^{\frac{\theta}{2}\,\mathbf{u}}$$

其中指数里的 $\mathbf{u}$ 是一个表示旋转轴的纯四元数。这样一来，旋转矩阵可以写成指数形式，旋转向量可以，四元数也可以——整条线都配齐了。不过这个指数形式只是给大家看一看，基本上没啥用：实际要算的话，还是得回到前面定义的那些公式里去。

### 三明治公式：四元数如何转动一个向量

有了共轭和逆，接下来就可以看四元数和旋转之间的关系到底是什么。

假设三维空间中有一个向量 $\mathbf{v}$，我要对它进行旋转。首先把 $\mathbf{v}$ 写成纯四元数的形式——实部直接置零。然后考虑一个任意的四元数 $q = (s, \mathbf{t})$，先拿它直接乘到 $\mathbf{v}$ 上，看看 $qv$ 乘出来是什么。套用标量加向量的乘法公式：

$$qv = \Big(-\mathbf{t}\cdot\mathbf{v},\;\; s\,\mathbf{v} + \mathbf{t}\times\mathbf{v}\Big)$$

先忽略实部、只看虚部，就会发现一些很有意思的东西。对照前面推出来的罗德里格斯公式：

$$\mathbf{v}' = \cos\theta\,\mathbf{v} + \sin\theta\,(\mathbf{u}\times\mathbf{v}) + (1-\cos\theta)(\mathbf{u}\cdot\mathbf{v})\,\mathbf{u}$$

虚部里有一项 $s\,\mathbf{v}$，$s$ 是个标量，罗德里格斯公式里有一项 $\cos\theta\,\mathbf{v}$；虚部里还有一项 $\mathbf{t}\times\mathbf{v}$，是向量叉乘的形式，罗德里格斯公式里也有一项 $\sin\theta\,(\mathbf{u}\times\mathbf{v})$。那么如果对应起来，定义 $s = \cos\theta$、$\mathbf{t} = \sin\theta\,\mathbf{u}$，拿这个四元数乘到 $\mathbf{v}$ 上，虚部看起来就比较接近旋转变换的形式了。但是它差了中间那一项——罗德里格斯公式里的 $(1-\cos\theta)(\mathbf{u}\cdot\mathbf{v})\,\mathbf{u}$ 没有出现；另外还多出来一个实部 $-\mathbf{t}\cdot\mathbf{v}$，这个实部具体是什么含义，我们其实并不清楚。

那么四元数与旋转之间的对应关系到底是什么？这里我就不去讲背后到底是为什么了——这个东西讲起来其实挺难，我自己其实也没有完全弄明白。但我们可以直接去推这个结果：假设我告诉你，$q$ 还是取这个形式，但不直接把 $q$ 乘到 $\mathbf{v}$ 上，而是**后面再乘一个 $q$ 的逆**，它会有一些很好的结果。

先确认 $q = (\cos\theta,\ \sin\theta\,\mathbf{u})$ 是不是单位四元数——应该是的：$\cos^2\theta + \sin^2\theta = 1$。所以它的逆就是它的共轭：$q^{*} = (\cos\theta,\ -\sin\theta\,\mathbf{u})$。下面看 $qvq^{*}$ 推出来是什么样子。为了推导简便，把 $\cos\theta$、$\sin\theta$ 简写成 $c$ 和 $s$，然后用标量加向量的乘法公式一步步展开。

先看实部。展开后的实部里，有一块带着 $\mathbf{u}\cdot(\mathbf{v}\times\mathbf{u})$ 这种结构——而 $\mathbf{v}\times\mathbf{u}$ 一定垂直于 $\mathbf{u}$，再去点乘 $\mathbf{u}$，结果一定是零，所以这部分是零；剩下的是 $cs(\mathbf{v}\cdot\mathbf{u}) - sc(\mathbf{v}\cdot\mathbf{u})$，自然也是零。实部干干净净归零。

再看虚部。把里面带叉乘的项用三重叉乘展开的公式打开，跟前面几项合在一起，可以收拢成下面这个形式：

$$(c^2 - s^2)\,\mathbf{v} + 2sc\,(\mathbf{u}\times\mathbf{v}) + 2s^2\,(\mathbf{u}\cdot\mathbf{v})\,\mathbf{u}$$

这个形式非常妙，看前面各自的系数：$c^2 - s^2$，也就是 $\cos^2\theta - \sin^2\theta$，这其实就是二倍角公式，对应 $\cos 2\theta$；$2sc$ 就是 $2\sin\theta\cos\theta$，是 $\sin 2\theta$；两倍的 $s^2$ 也一样，用倍角公式一换就是 $1 - \cos 2\theta$。于是整个式子变成

$$\cos 2\theta\,\mathbf{v} + \sin 2\theta\,(\mathbf{u}\times\mathbf{v}) + (1 - \cos 2\theta)(\mathbf{u}\cdot\mathbf{v})\,\mathbf{u}$$

这跟罗德里格斯公式就**完全一样**了——只不过罗德里格斯公式里都是 $\cos\theta$、$\sin\theta$，这里推出来的是 $\cos 2\theta$、$\sin 2\theta$、$1-\cos 2\theta$，除此之外其他一模一样。所以说 $qvq^{*}$ 这个形式对应的就是旋转，并且它对应的不是转 $\theta$，而是转了**两倍的 $\theta$**。

利用这个结果，四元数与旋转的对应关系就写出来了：对空间中任意一个三维向量 $\mathbf{v}$，先把它写成实部置零的四元数；$q$ 取单位四元数，实部是 $\cos\frac{\theta}{2}$，虚部是 $\sin\frac{\theta}{2}\,\mathbf{u}$，$\mathbf{u}$ 是对应的旋转轴；然后利用四元数乘法把这三者乘起来：

$$\mathbf{v}' = q\,\mathbf{v}\,q^{*}, \qquad q = \Big(\cos\tfrac{\theta}{2},\ \sin\tfrac{\theta}{2}\,\mathbf{u}\Big)$$

得到的就是旋转之后的向量。

> **结论**：三维中的旋转与四元数之间满足 $\mathbf{v}' = q\,\mathbf{v}\,q^{*}$，其中 $q$ 的实部是 $\cos\frac{\theta}{2}$、虚部是 $\sin\frac{\theta}{2}\,\mathbf{u}$。非常妙的有两点：一是**三明治乘法**的结构——$\mathbf{v}$ 要夹在两个 $q$ 的中间；二是 $q$ 里装的不是 $\theta$，而是**二分之 $\theta$**。

至于为什么会有这样的旋转关系，大家可以去看 3Blue1Brown 的四元数视频，它有非常好的可视化解释；网上还有一位作者的四元数入门教程也非常好。想详细了解里面的门道，可以去看这些资料；但如果你只是想用的话，把这个公式记住就可以——这其实是四元数最核心的一个公式，能理解就挺好的。

这里也顺手把自由度对上：$q$ 的自由度是三，和前面一致。$q$ 虽然有四个分量，但我们要求它是单位四元数，加了一个约束，所以自由度是三。具体推导的过程，大家可以下去自己推一下试试。

### 在四维球面上插值

有了四元数之后，我们对旋转流形本身就会有一个非常直观的了解。前面说过，旋转矩阵的自由度是三，它对应九维空间中的一个三维流形；而如果采用四维的四元数去表达——四元数本身活在四维空间里，因为它有四个参量——同时，能够表示旋转的四元数一定是单位四元数。这意思就是：四维空间里，只要一个四元数是单位四元数，它就代表一个旋转。所有单位四元数在四维空间中组合起来，对应的就是一个"球的表面"——说球体不太准确，是球面。所以用四元数去观察旋转，它对应的就是四维空间中的一个三维流形。

于是我们回到那个熟悉的旋转插值问题，它现在会有一个非常直观的理解：**在一个球面上插值**。球面上有两个点 $q_0$ 和 $q_1$，代表两个旋转 $R_0$ 和 $R_1$；要在球面上做插值，自然就是要在球面上找一段弧，沿着这段弧做插值。我们确实可以这么做——先看第一种插值方法。

#### NLERP：先线性插值，再归一化

做法是：对两个四元数 $q_0$ 和 $q_1$ 先做线性插值；插完之后它就不是单位四元数了，那就直接做一次归一化（normalization）。归一化之后，这个点一定落在弧线上，于是插值就完成了：

$$\mathrm{NLERP}(q_0, q_1, t) = \frac{(1-t)\,q_0 + t\,q_1}{\big\|(1-t)\,q_0 + t\,q_1\big\|}$$

但这么做出来的插值，动起来有一个很明显的问题：**开始转得慢，中间一下转得特别快，到末尾的地方又慢了**。这是为什么呢？

#### 为什么会先慢后快

把球面上这段弧所在的截面单独拿出来，它是一个圆。NLERP 做的事，其实是在 $q_0$ 和 $q_1$ 连成的那条线上匀速地动——这条线是圆的一条**弦**；然后做一次归一化，把点投到弧上。问题就在这儿：弦上是匀速的，但投影到弧上之后，扫过的弧长不是一个匀速的过程，而是一个先慢后快的过程。

```text
              *  *  *  *  *
           *                 *
         *                     *
        *        t = 0.5         *
        *   t = 0.25   t = 0.75   *     <- 弦上四等分的点，投到弧上：
        *                          *       中间那段弧明显更长
         *                       *
           *                   *
              *  *  *  *  *

   q0 ●--------------●--------------●--------------● q1
     t=0           t=0.25         t=0.5          t=1

   弦上匀速 lerp -> 归一化投影到弧上 -> 扫弧先慢、中间快、末尾慢
```

取几个点观察：取弦上的四等分点 $0.25$、$0.5$、$0.75$，看它们对应到弧上的位置——虽然弦上是四等分的，但对应到弧上，中间这段会特别长。弧上的速度不是一个匀速，而这个弧上速度的不匀，导致的就是最终旋转速度的不匀。

这还可以推得更确切。取 $q_0 = (1, 0)$ 固定不动，$q_1 = \big(\cos\frac{\theta}{2},\ \sin\frac{\theta}{2}\,\mathbf{u}\big)$，它代表一个转 $\theta$ 角的旋转。算一下 $q_0$ 和 $q_1$ 这两个**四维向量**的夹角 $\varphi$：算两个向量的夹角，先算点乘，再除以两个向量的模长。两个都是单位四元数，分母是一；分子用点乘公式一算，会发现它等于 $\cos\frac{\theta}{2}$：

$$\cos\varphi = \frac{q_0\cdot q_1}{|q_0|\,|q_1|} = \cos\frac{\theta}{2} \quad\Longrightarrow\quad \varphi = \frac{\theta}{2}$$

这个式子代表什么含义？物体从初始姿态转到目标姿态、转过 $\theta$ 角，对应的四元数在球面上扫过的角度是 $\frac{\theta}{2}$——两者之间是成比例的关系。所以只要四元数在球面上扫弧的角速度不是一个匀速，实际扫过的 $\theta$ 角也就不是一个匀速——实际的旋转就不是一个匀速旋转，导致的结果就是先转得慢、再转快、再转得慢这么一个很明显的加速减速过程。这个过程是我们不希望的。

#### SLERP：按匀角速度扫弧

解决方法也很简单：让这个角度均匀变化就可以了。这就对应另一种插值方法——SLERP（Spherical Linear Interpolation，球面线性插值）。它代表的含义是：插值出来的这个点，在空间中以一个**匀速的角速度**扫过这段弧——具体说，$t$ 时刻它与 $q_0$ 的夹角是 $t\theta$，与 $q_1$ 的夹角是 $(1-t)\theta$。

把这个条件落实下来，会对应出一个公式。它也长成"两个系数的加权组合"，只是这两个系数不再简单是 $t$ 和 $1-t$，而是需要计算 $\sin$ 值的东西：

$$\mathrm{SLERP}(q_0, q_1, t) = \frac{\sin\big((1-t)\,\theta\big)}{\sin\theta}\,q_0 + \frac{\sin(t\,\theta)}{\sin\theta}\,q_1$$

其中 $\theta$ 代表的是两个四元数之间的实际夹角（单位四元数点乘一下就能拿到）。SLERP 插值的结果比 NLERP 要好很多：它就是一个匀速转动的东西。所以如果你希望插值结果是匀速转动的，那尽可能还是用 SLERP。

这个公式本身的推导我这里就不推了——作业里面应该有道题，就是大家可以去尝试推一下这个公式到底是什么样子；上网找的话也肯定能找到很多推导，感兴趣的话可以自己推一推试试。它具体的思路是：把插值四元数写成 $q_0$、$q_1$ 的两个系数的线性组合，算它跟 $q_0$ 的点乘、和跟 $q_1$ 的点乘，让它满足上面那个夹角关系，建立两个方程，然后把这两个系数解出来。

但也有一点值得说的：虽然 SLERP 能够保证角速度是稳定的，但它计算起来会比 NLERP 要慢。其实很明显：SLERP 需要算 $\sin\theta$，而 NLERP 只需要做一次简单的线性插值，所以 NLERP 会比 SLERP 快很多。那么什么情况下两者的结果是相近的？如果你的插值两帧之间的角度变化不是特别大——两个点很近——其实 NLERP 和 SLERP 看不出明显差别，NLERP 也不会露出明显的 artifact。所以角度变化不大时，用 NLERP 可能也看不出问题；但如果你要它百分之百准确、要它的稳定性，可以用 SLERP。同时 SLERP 也是有需要注意的地方：比如 $\theta$ 角度特别小的时候，$\sin\theta$ 可能就特别小，这时候你需要处理一些数值上的问题。

> **提示**：NLERP 快但转速不匀，SLERP 匀速但更贵、小角度还有数值坑——帧间夹角小用 NLERP 足够，追求稳定就用 SLERP 并处理小角度情形。

四元数为什么大家用得多？其实也正是因为插值这件事大家会经常用。

#### 长弧还是短弧：q 与 −q 的坑

前面介绍过一条性质：$q$ 和 $-q$ 表达的是相同的旋转。那么在 $q_0$ 和 $q_1$ 之间插值的时候，就会发现其实有两种选择：从 $q_0$ 到 $q_1$ 走一段很长的弧过去；也可以从 $q_0$ 到 $-q_1$ 走一段很短的弧。因为 $q_1$ 和 $-q_1$ 表示的其实是同一个旋转，所以短弧和长弧都是这两个旋转之间的插值。区别是什么呢？长弧反映的是往角度距离相差比较大的方向转——绕了一大圈再回到那个角度；短弧走的就是最短角，走的距离会短一点。

所以进行四元数插值的时候，需要注意这一点：**如果发现要插值的两个四元数之间的夹角大于 $\frac{\pi}{2}$——大于 90 度——就可以把其中一个取反**，走短弧来完成插值。

> **易错点**：两个四元数夹角超过 90 度时，先把其中一个变成 $-q$ 再插值，否则插值动画会绕一大圈走长弧。

### 三种旋转表示的取舍

总结来说，本模块主要介绍了旋转的三种表示方法：第一种欧拉角，第二种轴角，第三种四元数。

对**欧拉角**来说，总体上它操作很直观，意义也很直观，但是它的规范非常复杂；同时它最大的问题是有万向锁。并且如果你要用欧拉角进行插值——可想而知，效果应该不会特别好，因为它走的路径基本不会是一个最短路径。

对**轴角**来说，其实它就是旋转本身的定义。它也可以进行插值，而且插值的结果——如果你使用对的插值方法，就是前面介绍的那个相对旋转的插值方法——和四元数的插值结果是等价的。这其实也是我们作业题的一部分，大家可以推一下为什么等价。不过轴角相比四元数来说，用得还是相对少一点，为什么？因为它需要大量的矩阵运算；而四元数的话，旋转之间做运算，只需要在四元数本身上做运算，会更方便一些，计算效率也会更高。

**四元数**的性质就非常好：它计算效率很高，同时组合起来方便、查找起来方便、采样也方便。它唯一的问题就是理解起来会稍微有点麻烦——它不是特别直观。它最直观的理解方式，反而是把四元数转换成轴角，用轴角去理解这个旋转。

| 表示方法 | 优势 | 短板与注意 |
| :--- | :--- | :--- |
| 欧拉角 | 操作直观、意义直观 | 规范非常复杂；有万向锁；插值路径基本不是最短路径 |
| 轴角 | 就是旋转本身的定义；用相对旋转法插值，结果与四元数插值等价 | 需要大量矩阵运算，用得比四元数少 |
| 四元数 | 计算效率高；组合、查找、采样都方便 | 不直观——最直观的理解方式是转回轴角去看 |

这就是一般比较常用的几种旋转表示方法，不同情况下根据情况使用就可以。

### 神经网络需要怎样的旋转表达

本模块开始的时候提过一个问题是：神经网络可能要输出旋转——不管是做回归也好、做预测也好、还是做生成——那么对一个神经网络来说，适合的旋转表达应该是什么？

问题在于：前面介绍的欧拉角、轴角、四元数，其实都不一定适合。它们有一些通用的问题，最大的通用问题是**多义性**。以欧拉角为例，相差 $2\pi$（360 度）的角度表示的是相同的旋转：转 10 度和转 370 度，代表的是相同的含义。这时如果让网络去输出这个角度，它有可能输出 10 度给你，也有可能输出 370 度给你——这两个结果最后的 loss 值可能都是一样的，因为你的目标只跟最终的旋转有关。这个时候网络面对的就是多义性：相当于有很多个不同的极小值（minimum）结果，优化方向被模糊了，就可能出现一些优化上的问题。

轴角来说是一样的：沿 $\mathbf{z}$ 轴转 $\theta$ 角表示的旋转，和绕 $-\mathbf{z}$ 轴转 $-\theta$ 角是一样的。四元数的话，$q$ 和 $-q$ 的结果相同。所以这三种表示方法在表达旋转的时候，都不可避免地出现了多义性的问题，而它可能就会影响到网络的优化。

那如果做一个操作——比如强制规定欧拉角里所有的角度范围都是 $0$ 到 $2\pi$——行不行？这时也会出现问题。明明在零点附近，一个正的角度、一个负的角度，表示的旋转其实是相邻的：往正方向转一点和往负方向转一点，是很接近的结果。但强制把角度限制到 $[0, 2\pi)$ 之后，正的那个方向还好说，负的那个方向立马会跳到 $2\pi$ 附近——原来是 +10 度和 −10 度两个相近的东西，限域之后就变成 +10 度和 350 度。这是一个**不连续**的现象，而不连续对网络优化来说是非常难以处理的。

所以之前介绍的这些旋转表示方法，对神经网络来说可能都不是最优的。这个问题本身也是一个研究方向：有研究者提出了更适合神经网络的旋转表达，非常经典的就是 **6D 旋转表达**。

我们说旋转本身的自由度是三维的，但可以让网络输出一个 6D 的向量——它实际上代表两个三维向量 $\mathbf{a}_1$ 和 $\mathbf{a}_2$。拿到之后干什么呢？对 $\mathbf{a}_1$、$\mathbf{a}_2$ 做**施密特正交化**（Gram–Schmidt）：

```text
   a1, a2 --> b1 = normalize(a1)                    （固定第一个方向）
          --> b2 = normalize( a2 - (a2*b1)*b1 )     （减掉 a2 在 b1 上的投影，留下垂直分量）
          --> b3 = b1 x b2                          （叉乘补出第三个方向）
          --> R  = [b1  b2  b3]                     （拼成矩阵：正交、det = +1，即一个旋转）
```

固定 $\mathbf{a}_1$，把它归一化，作为第一个方向 $\mathbf{b}_1$；然后让 $\mathbf{b}_2$ 和 $\mathbf{b}_1$ 正交——从 $\mathbf{a}_2$ 里面减去它在 $\mathbf{b}_1$ 上投影的部分，剩下与 $\mathbf{b}_1$ 垂直的部分；$\mathbf{b}_3$ 就是把 $\mathbf{b}_1$ 和 $\mathbf{b}_2$ 叉乘起来。这样的话就能保证 $\mathbf{b}_1$、$\mathbf{b}_2$、$\mathbf{b}_3$ 都是单位向量，并且相互垂直。于是把三个拼起来组合成一个矩阵 $R$，并且能保证它是一个正交矩阵、行列式为 $+1$——那它表示的就是一个旋转。

很显然，6D 旋转表达是**冗余**的：旋转本质上就是三维的，所以很多的输出其实对应的是同一个旋转。那它的好处是什么？好处是它**连续**：虽然有冗余，但冗余的那一片基本上都是连续的——是把一个连续区域里的一片六维向量映射到了同一个旋转上。这种连续性对网络来说正是它非常喜欢的。所以 6D 旋转在某些特定的任务上，就会表现得比之前的四元数也好、轴角也好更好一些。

但这也不是绝对的，具体要看你用神经网络的时候到底是什么结构。也有例外：比如 3D Gaussian Splatting 那篇工作，大家如果读过的话会发现，它里面的旋转表达用的其实就是四元数——虽然它不是神经网络，但它也是一个优化问题，而它里面优化用的表达还是四元数。

同时除了 6D 之外，还有 **9D 表达**：再加三个维度，除了能建模旋转，还能建模旋转的**不确定度**。这就是研究上的问题了，大家如果对这个方向感兴趣，可以去看一看这些论文。一般来说，如果你直接拿来用，可以先试试 6D——6D 一般还可以。

### 角速度与旋转矩阵

介绍完旋转表达，这部分就基本介绍完了，还剩下最后一个问题：**角速度与旋转之间的关系到底是什么**。这个东西会用在什么地方呢？如果你要做模拟——比如模拟一个刚体——那你建立的方程都是角速度的方程；如何利用角速度去更新刚体最终的旋转，就必须知道角速度与旋转矩阵之间的关系。接下来就看一下这个关系。

#### 从速度的定义出发

先从一个非常具体的情况开始推。比如这样一个 T 字形的扳手，它上面固定了一个局部坐标系，坐标系里有一个点，这个点在局部坐标系下的局部坐标是 $\mathbf{x}_L$；它对应的也有一个全局坐标 $\mathbf{x}_W$——这个点在全局世界坐标系里的坐标。两者满足这样一个关系：

$$\mathbf{x}_W = R\,\mathbf{x}_L$$

这个我们在前面就已经推过了，大家应该还记得——就是讲欧拉角的时候推过的、不同坐标系之间的坐标转换。

那如果我现在考虑这个点在旋转之中速度到底是多少呢？$\mathbf{x}_W$ 上面加一点，代表它对时间求导。第一种看法直接来自角速度本身的定义：纯旋转的情况下，一个点的速度等于角速度叉乘上它相对观察点（原点）的位置：

$$\dot{\mathbf{x}}_W = \boldsymbol{\omega}\times\mathbf{x}_W = \boldsymbol{\omega}^{\times}\,\mathbf{x}_W = \boldsymbol{\omega}^{\times}\,R\,\mathbf{x}_L$$

叉乘可以写成叉乘矩阵 $\boldsymbol{\omega}^{\times}$ 的形式（还是之前那个叉乘矩阵），再把 $\mathbf{x}_W = R\mathbf{x}_L$ 代进去——这就是世界坐标系下这个点的速度表达式。

还有另外一种推法：直接从 $\mathbf{x}_W = R\,\mathbf{x}_L$ 这个形式出发，对时间求导。乘法求导公式：

$$\dot{\mathbf{x}}_W = \dot{R}\,\mathbf{x}_L + R\,\dot{\mathbf{x}}_L$$

但是 $\mathbf{x}_L$ 是局部坐标系下的坐标——这个点是随着刚体一起动的，它在局部坐标系下是一个固定的值，所以 $\dot{\mathbf{x}}_L = 0$，式子就只剩下：

$$\dot{\mathbf{x}}_W = \dot{R}\,\mathbf{x}_L$$

把这两个式子和前面的速度表达式结合在一起看：

$$\dot{R}\,\mathbf{x}_L = \boldsymbol{\omega}^{\times}\,R\,\mathbf{x}_L$$

$\mathbf{x}_L$ 是刚体上任意一点的局部坐标，可以取任意向量，所以立马得到下面这个关系：

> **结论**：旋转矩阵求导，等于一个角速度的叉乘矩阵乘以这个旋转矩阵本身：$\dot{R} = \boldsymbol{\omega}^{\times}\,R$。这就是旋转矩阵的导数与角速度之间的关系——或者说，我们建立的角速度与旋转矩阵之间的关系。

#### 从约束出发：流形与切空间的视角

我们也可以从另外一个视角去想这个问题。最开始我们就说过，旋转是一个流形——三维流形，而角速度其实反映的是它切空间的情况。怎么看这个事情呢？

还是回到旋转矩阵：把它看作九维空间中的一个三维流形。旋转矩阵的转置乘以旋转矩阵本身是一个单位矩阵，这是约束。把这个约束对时间求导：左边按乘法求导展开之后是两项，注意到其中一项其实就是另一项转个置——把转置搞进去，两项互为转置；右边单位矩阵对时间求导是零。两项加起来等于零，这个式子告诉我们：$\dot{R}\,R^{\top}$ 的转置加上它本身等于零。**一个矩阵的转置加上它本身等于零，那么这个矩阵就是一个反对称矩阵。**

而反对称的 $3\times 3$ 矩阵一定就是长成叉乘矩阵这个样子的：

$$\boldsymbol{\omega}^{\times} = \begin{pmatrix} 0 & -\omega_3 & \omega_2 \\ \omega_3 & 0 & -\omega_1 \\ -\omega_2 & \omega_1 & 0 \end{pmatrix}$$

这个形式其实可以理解成对 $\boldsymbol{\omega}$ 的一个定义：先不管它的物理意义是什么，反正它是一个反对称矩阵，一定是长成这个样子，我就给它定义成这样。定义完之后，把这个式子两边乘一个 $R$，就可以得到：

$$\dot{R} = \boldsymbol{\omega}^{\times}\,R$$

我们从不同的视角导出了相同的公式，并且可以立马知道这里 $\boldsymbol{\omega}$ 的具体物理含义——其实就是这个刚体的角速度。

> **提示**：这里涉及对矩阵求导，前面讲线性代数的时候专门讲过矩阵求导应该怎么求。另外，如果你不做模拟（simulation），这一部分其实不是特别需要了解——一般只有模拟的情况才会对时间求导。

### 左乘还是右乘：世界系与局部系

关于角速度还想再多说一点。刚才推的这个角速度，其实是定义在**世界坐标系**下的角速度。但我们有的时候也会用到另外一种定义：把这个角速度分解到**局部坐标系**下去看。这时它会变成另外一种形式，推一下这个形式长什么样。

把 $\boldsymbol{\omega}^{\times}\,R$ 后面再乘一个任意的三维向量 $\mathbf{u}$——$\mathbf{u}$ 是任意的，不管它是什么。把这个式子展开，它对应的就是 $\boldsymbol{\omega}\times(R\,\mathbf{u})$。然后给 $\boldsymbol{\omega}$ 前面乘一个 $R\,R^{\top}$——因为 $R$ 本身是一个正交矩阵，$R\,R^{\top}$ 就是单位矩阵，乘了等于没乘——写成这个样子：

$$(R\,R^{\top}\boldsymbol{\omega})\times(R\,\mathbf{u})$$

写成这个样子你就可以看到：叉乘的两个向量，左边都挂着一个旋转矩阵 $R$，我就可以把这个 $R$ 提出来。为什么可以提？你想：两个向量先各自旋转 $R$ 角度、再叉乘，和我先把它们叉乘起来、再整体旋转 $R$ 角度，出来的结果应该是一样的。所以

$$(R\,R^{\top}\boldsymbol{\omega})\times(R\,\mathbf{u}) = R\,\big[(R^{\top}\boldsymbol{\omega})\times\mathbf{u}\big] = R\,(R^{\top}\boldsymbol{\omega})^{\times}\,\mathbf{u}$$

由于 $\mathbf{u}$ 是任意选的，所以两边就相等：

$$\boldsymbol{\omega}^{\times}\,R = R\,(R^{\top}\boldsymbol{\omega})^{\times}$$

那这个 $R^{\top}\boldsymbol{\omega}$ 是什么？它其实就是角速度通过一个坐标变换、变换到局部坐标系下的结果。之前推过：一个向量从局部坐标系变换到世界坐标系，中间差一个旋转矩阵 $R$；那么反过来，把一个向量从世界坐标系转换到局部坐标系，只需要在前面乘个转置。记 $\boldsymbol{\omega}' = R^{\top}\boldsymbol{\omega}$ 为局部坐标系下的角速度，于是

$$\dot{R} = \boldsymbol{\omega}^{\times}\,R = R\,\boldsymbol{\omega}'^{\times}$$

> **结论**：对同一个旋转矩阵求导，既可以写成 $\boldsymbol{\omega}^{\times}\,R$——$\boldsymbol{\omega}$ 乘在**左边**，是世界坐标系下的角速度；又可以写成 $R\,\boldsymbol{\omega}'^{\times}$——$\boldsymbol{\omega}'$ 乘在**右边**，是局部坐标系下的角速度。

所以这要具体看：你算出来的是哪个角速度，就把它按对应的位置更新到 $R$ 上。

### 四元数的导数与角速度

推完了角速度与旋转矩阵的关系，最后来看一下四元数与角速度的关系——因为很有可能你最后表示旋转用的就是一个四元数。那么角速度与四元数之间的关系是什么？

可以用刚才类似的推法去推一遍。这个推导可能有一些繁琐，我大概过一遍。还是一样，从三明治出发：

$$\mathbf{x}_W = q\,\mathbf{x}_L\,q^{*}$$

两边同时对时间求导。因为 $\mathbf{x}_L$ 是一个固定的向量（点固连在刚体上），它求导出来是零，所以只剩两项：

$$\dot{\mathbf{x}}_W = \dot{q}\,\mathbf{x}_L\,q^{*} + q\,\mathbf{x}_L\,\dot{q}^{*}$$

后面这一项可以用四元数共轭的公式改写：由于 $\mathbf{x}_L$ 是纯四元数、共轭等于它的相反数，改写之后第二项变成带负号的共轭形式。这样一看，最后的结果等于"一个四元数减去它自己的共轭"——而任何一个四元数减它自己的共轭，实部归零、虚部翻倍，结果就等于两倍的虚部。这也正合适：速度本来就应该是一个纯四元数。这是一种推法。

然后还可以从角速度的方式去理解它：$\dot{\mathbf{x}}_W$ 应该等于一个角速度叉乘 $\mathbf{x}_W$。用四元数写的话可以写成四元数乘积的形式——上一节说过，纯四元数乘积的虚部正好是叉乘。而且这里可以认为 $\boldsymbol{\omega}$ 是定义在局部坐标系下的：那只需要先把 $\boldsymbol{\omega}$ 和 $\mathbf{x}_L$ 在局部坐标系下叉乘完（纯四元数乘积），然后再转到世界坐标系——三明治一裹就行。这两种推导方法写的都是同一个 $\dot{\mathbf{x}}_W$，把两种方法等起来，就可以推出四元数求导与角速度的关系：

> **结论**：$\dot{q} = \dfrac{1}{2}\,\boldsymbol{\omega}\,q = \dfrac{1}{2}\,q\,\boldsymbol{\omega}'$。$\boldsymbol{\omega}$ 是世界坐标系下的角速度、乘在左边；$\boldsymbol{\omega}'$ 是局部坐标系下的角速度、乘在右边——和矩阵那边一模一样的分工。多出来的 $\tfrac{1}{2}$ 也不奇怪：四元数里存的是半角，一求导自然掉出来一半。

当然这个推导，大家如果有兴趣的话可以推，如果没兴趣的话，直接记公式就可以。

到这里，旋转就基本上讲完了。这一讲列了一些参考资料，都是讲得很好的资料，有兴趣可以去翻一翻——包括刘老师的 GAMES105（人体动画方向）课程，里面专门有一讲讲线性代数和旋转表达，值得一看。

### 本讲提到的题目

讲的过程中留了几个练习和作业，汇总在这里。

**用乘法表验证 $q\,q^{*}$ 是纯实数（课上口头练习）。** 拿最开始那张乘法表回去推一遍 $q\,q^{*}$，验证 $\mathrm{i}$、$\mathrm{j}$、$\mathrm{k}$ 前面的系数全都是零，只剩下 $a^2 + b^2 + c^2 + d^2$。解析线索在"共轭、模长与逆"一节：用标量加向量的形式最快——实部是 $a\cdot a - \mathbf{v}\cdot(-\mathbf{v}) = a^2 + |\mathbf{v}|^2$；虚部里 $a\mathbf{v}$ 与 $a(-\mathbf{v})$ 相互抵消、$\mathbf{v}\times(-\mathbf{v}) = \mathbf{0}$，天然为零。

**推导 SLERP 公式（作业题）。** 推出球面线性插值公式，说明两个系数为什么是 $\frac{\sin((1-t)\theta)}{\sin\theta}$ 和 $\frac{\sin(t\theta)}{\sin\theta}$。当场给的思路：把插值四元数写成 $q_0$、$q_1$ 的两个系数的线性组合；算它与 $q_0$ 的点乘、与 $q_1$ 的点乘；要求它在 $t$ 时刻与 $q_0$ 的夹角为 $t\theta$、与 $q_1$ 的夹角为 $(1-t)\theta$；让点乘结果满足这个夹角关系，建立两个方程，把两个系数解出来。"为什么会先慢后快"一节里 $\varphi = \theta/2$ 的点乘计算就是同样的手法，可以照着推。

**证明轴角插值与四元数插值等价（作业题）。** 轴角用相对旋转法做插值（本模块前面介绍的方法），推出它与四元数插值结果等价。正文线索在"三种旋转表示的取舍"一节（轴角插值用对方法时与四元数等价）和"在四维球面上插值"一节（四元数侧的夹角对应关系 $\varphi = \theta/2$），从两边旋转角的对应关系入手即可。
