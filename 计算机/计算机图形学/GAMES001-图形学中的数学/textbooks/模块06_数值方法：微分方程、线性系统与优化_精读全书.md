## 微分方程：连续数学的最后一课
> 对应块：BLK22 | 覆盖分集：P12 | 块标题（分集名）：《微分方程》

### 这节课的位置：从数学走向计算机

如果去看课程大纲，会看到我们已经讲过场论、讲过微分几何，今天讲微分方程——这是连续数学部分的最后一节课。这节课之后，我们就会进入离散的部分：去讲线性求解器、最优化，以及机器学习。可以简单地这么理解：以上这些内容更偏数学，接下来的内容更偏计算机，而今天这节课，就是要起到承上启下的作用。

图形学当中的微分方程其实相当多，从常微分方程到偏微分方程，各种各样的方程都是图形学需要去求解的。所以这节课带有总结的性质，但先把丑话说在前面：它肯定是挂一漏万的——我不可能在一节课里把图形学涉及的所有微分方程知识都讲到，有些地方会讲得比较快。大家之后用到微分方程的相关内容时，应该根据今天讲的内容去查阅资料、更详细地学习。我们的路线是从最简单的微分方程出发，一步一步走到比较复杂的微分方程。

### 微分方程是什么，有哪几类解法

> **定义**：微分方程表示的是未知函数、未知函数的导数（一阶导、二阶导、各种阶的导数）与自变量之间的关系的方程。求解微分方程，就是从这个方程里把未知函数解出来。

如果你修过两学期的高等数学，应该都接触过微分方程；如果你修的是三学期的数学分析，大一可能还没学到这一块，那这节课正好带你过一遍。

最基础的分类，是常微分方程和偏微分方程。所谓常微分方程，就是未知函数是一元函数，里面涉及的导数全是全导数——如果你看到的式子里导数符号都是 d，那它就是个常微分方程。如果未知函数是多元函数，涉及的导数就都是偏导数——符号是 ∂——那它就是个偏微分方程。

| 对比项 | 常微分方程 | 偏微分方程 |
| :--- | :--- | :--- |
| 未知函数 | 一元函数 | 多元函数 |
| 涉及的导数 | 全导数 | 偏导数 |
| 认出的符号 | $d$ | $\partial$ |

微分方程有很多种求解方法，今天我们大体上讲四种：

- **通解法**：一些非常简单的、特定形式的微分方程存在通解——满足这个形式的方程的所有解都给你找齐了，你只需要代值，就能确定它的解究竟是什么。
- **分离变量法**：求解微分方程当中非常重要的手段，它在常微分方程和偏微分方程当中的表现形式有所不同，一会儿会分别讲到。它是一种分析的手段，数学家、物理学家也会去用。
- **格林函数法**：我个人认为它更多可以用在数值当中——它是从数学到计算机的桥梁，计算机当中很多时候求解方程需要利用格林函数。
- **数值法**：数值法求解微分方程，本身就是计算机图形学研究的核心之一——如果你发明了一种更好的数值方法去求解微分方程，是可以投稿计算机图形学相关论文的。

### 分离变量：从最简单的方程开始

先看常微分方程里的分离变量。它的标准形式是等式左端为 $\psi(y)\,\mathrm{d}y$、右端为 $\varphi(x)\,\mathrm{d}x$。对等式两边同时做积分：左边积出 $\psi(y)\,\mathrm{d}y$ 的原函数，右边积出 $\varphi(x)\,\mathrm{d}x$ 的原函数——中间一定要补上一个常数 $C$，加减一个常数是不会影响方程的解的。

来看一道例题：求方程

$$x(1+y^2)\,\mathrm{d}x - y(1+x^2)\,\mathrm{d}y = 0$$

的通解。首先我们发现，想把它整理成标准形式，需要在等式两边同时除以 $(1+y^2)$ 和 $(1+x^2)$，这时左式变成

$$\frac{y}{1+y^2}\,\mathrm{d}y = \frac{x}{1+x^2}\,\mathrm{d}x$$

等式两边就都可以积分了：左端积分是 $\frac{1}{2}\ln(1+y^2)$，右端积分是 $\frac{1}{2}\ln(1+x^2)$，当然还差一个常数：

$$\frac{1}{2}\ln(1+y^2) = \frac{1}{2}\ln(1+x^2) + C_1$$

这个常数我们可以处理得巧一点：令 $C_1 = \frac{1}{2}\ln C$。注意到 $\ln C$ 的取值是 $-\infty$ 到 $+\infty$，所以 $\frac{1}{2}\ln C$ 和上面随便的某个常数 $C_1$ 是等价的。整理一下得到 $\ln(1+y^2) = \ln\bigl[C\,(1+x^2)\bigr]$，两边同时取 $e$ 的指数幂，左边变成 $1+y^2$，右边变成 $C(1+x^2)$；再移一下项：

$$y^2 = C\,(1+x^2) - 1$$

这就是求出的解。当然你想把它写成 $y$ 是 $x$ 的函数的形式也没有关系，可以写成 $y = \pm\sqrt{C(1+x^2)-1}$，都是可以的。这是最简单的求解微分方程的办法。

### 一阶线性方程：齐次与非齐次

接下来是稍微复杂一点的情形：一阶线性微分方程。它有标准形式：

$$\frac{\mathrm{d}y}{\mathrm{d}x} + p(x)\,y = q(x)$$

如果等式右端恒等于零，这样的方程我们称它为齐次的；右端不等于零，就称它为非齐次的。

先看线性齐次方程的解法。它长这个形式，是很容易分离变量的：利用一阶导数具有线性性，等式两边先乘以 $\mathrm{d}x$、再除以 $y$，得到

$$\frac{\mathrm{d}y}{y} = -p(x)\,\mathrm{d}x$$

等式两端做积分，左边变成 $\ln|y|$，右边变成 $-\int p(x)\,\mathrm{d}x + C$；再求 $e$ 的指数幂，就得到

$$y = C\,e^{-\int p(x)\,\mathrm{d}x}, \qquad C = \pm e^{C_1}$$

就是分离变量，然后做积分，就可以了。这个方程在图形学当中是有应用的：最典型的应用就是体渲染当中，求解光线在具有透射率的体介质中散射时，辐照度的衰减量。

再看线性非齐次方程。它跟刚才齐次方程的唯一区别，就是等式右端现在有一个函数 $q(x)$，不再是零了。如何求解？我们使用待定系数法：注意到齐次解前面是一个常数 $C$，现在我们令它变成一个函数 $C(x)$，即假设

$$y = C(x)\,e^{-\int p(x)\,\mathrm{d}x}$$

然后把这个假设代回方程。先求 $y$ 对 $x$ 的导数（这是一个简单的求导练习，大家可以自己做一下）：

$$y' = C'(x)\,e^{-\int p(x)\,\mathrm{d}x} - p(x)\,C(x)\,e^{-\int p(x)\,\mathrm{d}x}$$

代入 $y' + p(x)y = q(x)$ 展开，含 $p(x)C(x)$ 的两项正好抵消，整理就得到 $C'(x) = q(x)\,e^{\int p(x)\,\mathrm{d}x}$；两边积分，$C'(x)$ 的积分就是 $C(x)$：

$$C(x) = \int q(x)\,e^{\int p(x)\,\mathrm{d}x}\,\mathrm{d}x + C$$

代回去整理，$y$ 最后等于：

$$y = C\,e^{-\int p(x)\,\mathrm{d}x} + e^{-\int p(x)\,\mathrm{d}x}\int q(x)\,e^{\int p(x)\,\mathrm{d}x}\,\mathrm{d}x$$

我们会发现，它和齐次方程的解相比只是多了一项：把多出来的这项去掉，剩下的就是该非齐次方程所对应的齐次方程（把右端变成零）的通解；反过来，去掉带 $C$ 的那一项、只留下多出来的这一项，它就是这个非齐次方程的特解——在这个地方加不加 $C$ 其实是不影响结果的。

> **结论**：非齐次方程的通解 = 齐次方程的通解 + 非齐次方程的特解。

那什么叫通解、什么叫特解？这就可以有另一种理解方式了。给大家一个简单的记忆方法：凡是在解的表达式里含有某一个不确定常数 $C$ 的，它就是通解；没有这个不确定常数 $C$ 的，它就是特解。

### 伯努利方程：变量代换

刚才看到的都是一阶的线性微分方程，现在看一阶的非线性微分方程，最简单的例子是伯努利方程：

$$\frac{\mathrm{d}y}{\mathrm{d}x} + p(x)\,y = q(x)\,y^n$$

它和刚刚的式子最大的差别，是等式右端不仅有 $q(x)$ 这一项，还要乘以 $y^n$。这时我们要求 $n \neq 0$ 且 $n \neq 1$。为什么呢？如果 $n = 0$，它会退化成一阶线性非齐次方程；如果 $n = 1$，它其实就成了一阶线性齐次方程——都回到了刚才的情形。

怎么求解伯努利方程？简单的做法是变量代换。把等式左右两端都除以 $y^n$：左边变成 $y^{-n}\,\dfrac{\mathrm{d}y}{\mathrm{d}x}$，中间变成 $y^{1-n}$，右边就没有 $y^n$ 了。这时候我们发现一个关键事实：对 $y^{1-n}$ 关于 $x$ 求导，会得到

$$\frac{\mathrm{d}\bigl(y^{1-n}\bigr)}{\mathrm{d}x} = (1-n)\,y^{-n}\,\frac{\mathrm{d}y}{\mathrm{d}x}$$

比方程里已有的 $y^{-n}y'$ 只多了一个系数。把这个系数约掉，原方程就可以改写成以 $y^{1-n}$ 为未知函数的形式，别的都没有变。于是令 $z = y^{1-n}$，再在等式两边同时乘以 $(1-n)$，就得到

$$\frac{\mathrm{d}z}{\mathrm{d}x} + (1-n)\,p(x)\,z = (1-n)\,q(x)$$

这正是一个一阶线性非齐次微分方程。把刚刚推出来的通解表达式代下来，就得到伯努利方程的解。这就是变量代换法。

到这里，我们已经展示了求解微分方程的几种手段：一个是分离变量法，一个是待定系数法，一个是变量代换法。

### 可降阶的高阶方程

刚才都是一阶的微分方程，现在看高阶的。高阶微分方程最简单的情形，就是可以降阶的高阶微分方程。

第一种：$y^{(n)} = f(x)$。怎么求 $y$ 本身？只要做 $n$ 次不定积分，就可以求得通解。

第二种：$y'' = f(x,\,y')$，二阶导数等于 $x$ 和一阶导数的函数。可以设 $p = y'$，那么 $p' = y''$，方程就变成 $p' = f(x,\,p)$——一个关于 $p$ 的一阶方程。假设这个一阶方程有通解 $p = \varphi(x,\,C_1)$，那么直接对这个通解再做一次积分，就得到 $y$。

第三种：$y'' = f(y,\,y')$，右端是 $y$ 和一阶导数的函数。同样设 $p = y'$，但这时候 $p$ 得看成 $y$ 的函数，于是二阶导要写成 $y'' = p\,\dfrac{\mathrm{d}p}{\mathrm{d}y}$，方程变成 $p\,\dfrac{\mathrm{d}p}{\mathrm{d}y} = f(y,\,p)$。在这个式子里解得一阶导数 $y' = p = \varphi(y,\,C_1)$，再做一次积分，就得到原函数。

### 二阶线性方程：通解的结构

高阶微分方程里面，最重要的是二阶微分方程：它很具有典型性，并且二阶常微分方程在扩展到二阶偏微分方程以后，应用也非常广泛。

二阶线性常微分方程的标准形式是：

$$y'' + p(x)\,y' + q(x)\,y = f(x)$$

一样的规矩：等式右端恒等于零，方程叫齐次的；不等于零，叫非齐次的。我们先看齐次方程——齐次方程总是更好解的。这里给出一个定理：

> **定理**：如果二阶线性齐次方程有两个线性无关的解 $y_1(x)$ 和 $y_2(x)$，那么 $y = C_1 y_1(x) + C_2 y_2(x)$ 就是方程的通解。

换句话说，对于二阶线性齐次方程，只要你能找到两个线性无关的特解——满足这个方程的任意两个函数，只要它们线性无关——这两个函数的线性组合就得到了方程所有的解。这个定理可以拓展到 $n$ 阶线性齐次方程：当最高阶导数是 $n$ 阶的时候，你只要能找到 $n$ 个线性无关的解，就可以组合出它所有的解。

那对于二阶线性非齐次方程来说呢？刚才已经说过了：如果你能找到对应齐次方程的通解，再加上这个非齐次方程的一个特解，你就找到了非齐次方程的通解。

### 常系数齐次方程与特征方程

来看一个具体的例子：二阶常系数齐次线性微分方程。"常系数"是说方程里的 $p$ 和 $q$ 是固定的常数，不再是 $x$ 的函数。这里的解法我们依然用待定系数法——先猜一个解：假设 $y = e^{rx}$ 是方程的解。

为什么这么猜？因为我们发现 $e^{x}$ 这个函数不管求多少次导数，它都会保留 $e$ 的因子，这个性质我们觉得很好——求导不会把函数的形式搞乱。把 $y = e^{rx}$ 代入 $y'' + py' + qy = 0$，会得到

$$(r^2 + pr + q)\,e^{rx} = 0$$

因为 $e^{rx}$ 不可能等于零，所以只可能是

$$r^2 + pr + q = 0$$

这个方程就叫做特征方程。用一元二次方程的求根公式解出特征根 $r_1$ 和 $r_2$，接下来就看判别式 $p^2 - 4q$ 了。

判别式大于零：我们得到两个线性无关的特解 $y_1 = e^{r_1 x}$、$y_2 = e^{r_2 x}$，那我们就已经找到解了，通解是 $y = C_1 e^{r_1 x} + C_2 e^{r_2 x}$。

判别式等于零：只找到一个特解 $y_1 = e^{-\frac{p}{2}x}$（此时重根 $r = -\frac{p}{2}$）。还想找到另一个特解，怎么找？我们依然猜：设 $y_2 = u(x)\,e^{-\frac{p}{2}x}$，把这个 $y_2$ 代入原方程、整理一下，会得到另一个特解

$$y_2 = x\,e^{-\frac{p}{2}x}$$

这样通解就都找齐了：$y = (C_1 + C_2 x)\,e^{-\frac{p}{2}x}$。

判别式小于零：这时方程没有实根，会解得两个复根。这两个复根一定是共轭的，记 $r_{1,2} = \alpha \pm i\beta$。利用欧拉公式 $e^{ix} = \cos x + i\sin x$，我们可以消掉虚部，得到两个实值的特解：

$$y_1 = e^{\alpha x}\cos\beta x, \qquad y_2 = e^{\alpha x}\sin\beta x$$

这样又找到了方程的所有通解。

上述论证过程也可以向高阶的常系数——注意，是常系数——齐次线性微分方程去扩展，方法是一样的：去解一个特征方程

$$r^n + p_1 r^{n-1} + \cdots + p_{n-1}\,r + p_n = 0$$

特征方程的每一个 $k$ 重实根 $r$，对应一个通解项：

$$(C_1 + C_2 x + \cdots + C_k x^{k-1})\,e^{rx}$$

每一个 $k$ 重的共轭复根 $\alpha \pm i\beta$，也对应一个通解项：

$$e^{\alpha x}\Bigl[(C_1 + C_2 x + \cdots + C_k x^{k-1})\cos\beta x + (D_1 + D_2 x + \cdots + D_k x^{k-1})\sin\beta x\Bigr]$$

前面乘的多项式，是因为 $k$ 重所造成的；拆出的 $\cos$、$\sin$ 两支，是因为有复根所造成的。

### 常系数非齐次方程：特解的设定

刚刚我们相当于给出了二阶常系数齐次线性微分方程的解法，现在要看二阶常系数非齐次线性微分方程该怎么做——也就是等式右端现在开始有一个函数 $f(x)$ 了。右端常见两种形状，特解也照着这个形状去设。

第一种情形：$f(x) = e^{\lambda x} P_m(x)$，其中 $P_m(x)$ 是最高 $m$ 次的多项式。这时方程有一个形如下面的特解 $y^*$：

$$y^* = x^k\,Q_m(x)\,e^{\lambda x}$$

其中 $Q_m(x)$ 是某个 $m$ 次的多项式（系数待定），而 $x^k$ 里 $k$ 的取值由 $\lambda$ 是不是特征方程的根来决定：$\lambda$ 不是特征方程的根，$k = 0$；是特征方程的单根，$k = 1$；是特征方程的重根，$k = 2$。

第二种情形：$f(x) = e^{\lambda x}\bigl[P_l(x)\cos\omega x + Q_n(x)\sin\omega x\bigr]$，$P_l$、$Q_n$ 分别是最高 $l$ 次、$n$ 次的多项式。这时我们认为特解长这样：

$$y^* = x^k\,e^{\lambda x}\bigl[R_m^{(1)}(x)\cos\omega x + R_m^{(2)}(x)\sin\omega x\bigr]$$

其中多项式的最高次数取 $l$ 和 $n$ 的最大值。$k$ 的决定方式也是一样的：看 $\lambda + i\omega$ 是不是特征方程的根——不是，$k = 0$；是，$k = 1$。

到这里，常微分方程相关的内容就讲完了。其实这些就是高数上的内容，相当于带大家回顾了一遍。接下来我们就要走入偏微分方程——这部分相对来说，会超出计算机专业要掌握的数学基础课的水平。

### 偏微分方程的分类：双曲、抛物、椭圆

首先看二元二阶的线性偏微分方程。令未知函数是 $u$，假设 $A$、$B$、$C$、$D$、$E$、$F$ 都是自变量 $x$ 和 $y$ 的函数，标准形式可以写作：

$$A\,\frac{\partial^2 u}{\partial x^2} + 2B\,\frac{\partial^2 u}{\partial x\,\partial y} + C\,\frac{\partial^2 u}{\partial y^2} + D\,\frac{\partial u}{\partial x} + E\,\frac{\partial u}{\partial y} + F\,u = f$$

如何对它分类？我们直接给出结论：主要看判别式

$$\Delta = B^2 - AC$$

大家可能会提问：为什么不是 $B^2 - 4AC$？那是因为 4 这个量已经被提前放进 $2B$ 里了——注意混合导数项的系数写的是 $2B$。

- 对任意的 $x$、$y$，$\Delta$ 都大于零：称方程是双曲型偏微分方程；
- 对任意的 $x$、$y$，$\Delta$ 都等于零：称方程是抛物型偏微分方程；
- 对任意的 $x$、$y$，$\Delta$ 都小于零：称方程是椭圆形偏微分方程。

为什么会这样起名？其实，如果把上面方程里的二阶项不是偏导数、而是函数值本身——比如是 $x^2$、$y^2$、$xy$ 这样的量——那它就是圆锥曲线的标准形式。所以这里的命名就是根据圆锥曲线来的：判别式的符号决定一条圆锥曲线是双曲线、抛物线还是椭圆，同样也决定偏微分方程是双曲型、抛物型还是椭圆型。

如果是多元二阶怎么办呢？判断方法是：先列出它的标准形式

$$\sum_{i,j} a_{ij}\,\frac{\partial^2 u}{\partial x_i\,\partial x_j} + \sum_i b_i\,\frac{\partial u}{\partial x_i} + cu = f$$

把系数 $a_{ij}$ 构建成一个二次型，然后把这个二次型做标准化，就可以按照标准化后系数的符号去判断偏微分方程的类型——比如系数是不是都等于零、是不是都大于零，类似这样来判断。

### 物理中的几个典型方程

有哪些典型的二阶偏微分方程呢？看物理上几种非常典型的例子，它们正好对应刚才的三种类型。

波动方程是双曲型的典型例子。它有两个自变量：$t$ 是时间，$x$ 是位置，描述的是一维的振动：

$$\frac{\partial^2 u}{\partial t^2} - a^2\,\frac{\partial^2 u}{\partial x^2} = 0$$

这个方程是齐次的，右端项等于零。如果方程非齐次——也就是说这个振动时刻在被施加激励、施加外力——它就叫受迫振动：在齐次方程的基础上加一个源项就是了。这个方程还可以拓展到三维：一维的波动是二元（$x$、$t$）二阶偏微分方程，三维的波动其实就是把 $\frac{\partial^2 u}{\partial x^2}$ 换成拉普拉斯算子 $\Delta$，它已经是一个四元（$x$、$y$、$z$、$t$）二阶偏微分方程了。

抛物型的最典型例子是热传导方程：

$$\frac{\partial u}{\partial t} - a^2\,\Delta u = 0$$

可以观察一下它和波动方程的区别，主要区别就在于关于时间 $t$ 的这一项是几阶偏导：波动方程关于 $t$ 的偏导是二阶的，而热传导方程关于 $t$ 的偏导是一阶的。这个方程同样可以改成非齐次，在等式右端加上非齐次的源项，它表达的意思是：所考虑的区域当中有热源，这些热源会往外辐射热量。

椭圆型的最典型例子是拉普拉斯方程 $\Delta u = 0$（一维就是 $\frac{\partial^2 u}{\partial x^2} = 0$，三维就是 $\Delta u = 0$）。它其实可以看成刚才热传导方程的一个稳定问题：假如我们不停地传热、传热，传到最后不可能停不下来，空间最终会形成一个稳定的热的分布——也就是说 $\frac{\partial u}{\partial t}$ 这一项干掉了，剩下的就是拉普拉斯方程。如果给它加上源项，这个方程就叫泊松方程——空间中有源。源可能是什么呢？可能是一个热源，也有可能是电场方程中的电荷，一会儿我们就具体来看静电场写成泊松方程的形式。

还有一个是亥姆霍兹方程。如果在波动方程当中，我们假设解 $u(x,y,z,t)$ 长这样的形式：

$$u(x,y,z,t) = V(x,y,z)\,e^{-i\omega t}$$

代入波动方程，它就会变成

$$\Delta V + k^2\,V = 0$$

这就是亥姆霍兹方程。

### 分离变量法解波动方程

有了这些典型方程，怎么去求解偏微分方程呢？又要回到分离变量法。以波动方程为例：

$$\frac{\partial^2 u}{\partial t^2} - a^2\,\frac{\partial^2 u}{\partial x^2} = 0$$

给定初始条件：$t = 0$ 时 $u = f(x)$，且 $\frac{\partial u}{\partial t} = \cos x$。

开始分离变量。在偏微分方程当中，分离变量有的时候就是在拆解：我们假设 $u(x,t)$ 的 $x$ 和 $t$ 是可分离的，等于一个关于 $x$ 的函数和一个关于 $t$ 的函数相乘：

$$u(x,t) = X(x)\,T(t)$$

把这个假设代入波动方程，会得到

$$X\,T'' - a^2\,X''\,T = 0$$

做分离，等式两端同除以 $a^2\,X\,T$，就变成

$$\frac{T''}{a^2\,T} = \frac{X''}{X}$$

可以看到，等式左端只和 $t$ 有关，等式右端只和 $x$ 有关，而这两个事情还得时时刻刻相等——那这件事成立，当且仅当等式两端都等于同一个常数。我们就设这个常数为 $-\lambda$。可能有同学会问：这里为什么有负号？主要是因为这个解我其实已经知道正确答案是什么了：你可以猜它等于 $+\lambda$，但那样的话你会解出矛盾，所以这里只能假设它是 $-\lambda$。

假设是 $-\lambda$，等式左端就写成

$$T'' + \lambda a^2\,T = 0$$

变成了一个二阶线性齐次常微分方程，它有通解

$$T(t) = A\sin\bigl(\sqrt{\lambda}\,a\,t\bigr) + B\cos\bigl(\sqrt{\lambda}\,a\,t\bigr)$$

类似地，等式右端解出来是

$$X(x) = C\sin\bigl(\sqrt{\lambda}\,x\bigr) + D\cos\bigl(\sqrt{\lambda}\,x\bigr)$$

好，现在再加上边界条件来定解——刚刚解出来的式子里，大 $A$、大 $B$、大 $C$、大 $D$ 都是未知量。我们假设这个波动有边界条件：你可以看成绳子在震动的时候，我给它捏住两端，在任意时刻，$x = 0$ 和 $x = L$ 的位置都不发生震动、这两个点的位移不会发生改变。那么定解条件就是

$$X(0) = 0, \qquad X(L) = 0$$

这意味着什么呢？$X(0) = C\sin 0 + D\cos 0 = D$，它得等于零；还意味着 $X(L) = C\sin\bigl(\sqrt{\lambda}\,L\bigr) = 0$。后一个式子是什么意思？就是说 $\sqrt{\lambda}\,L$ 要等于 $\pi$ 的整数倍，即

$$\lambda_n = \frac{n^2\pi^2}{L^2}, \qquad n = 0, 1, 2, \dots$$

于是我们把 $n$ 作为一个参量，得到取第 $n$ 个参量时的分离变量解：

$$u_n(x,t) = \sin\frac{n\pi x}{L}\left(A_n \sin\frac{n\pi a t}{L} + B_n \cos\frac{n\pi a t}{L}\right)$$

然后我们不加证明地给出一个定理：对于任何满足这个波动方程的解，它都可以写成上述分离变量解的线性组合。那么上面还有一些未决定的系数——$A_n$ 和 $B_n$。它们由谁决定？由初始条件 $u = f(x)$ 和 $\frac{\partial u}{\partial t} = \cos x$ 来决定：只需要把 $t = 0$ 代入，同时使用傅里叶展开，就能确定 $A_n$ 和 $B_n$。

所以，分离变量法背后蕴含的思想就是傅里叶展开——它其实相当于说，我们给一个偏微分方程，给出了它的傅里叶展开形式下的解。

### 球谐函数：球坐标下的拉普拉斯方程

有了分离变量法这个求解偏微分方程的手段以后，我们就可以定义球谐函数了。本系列课程的前几节课大家已经接触过球谐函数，这里就稍微详细地说明一下它是怎么来的。

球谐函数其实就来自拉普拉斯方程，但我们是在球坐标系下给出拉普拉斯方程。在直角坐标系下，拉普拉斯算子的形式很简单；但在球坐标系下就比较麻烦了，因为球坐标系的三个参量里，$\theta$ 和 $\phi$ 并不对称。我们不纠缠球坐标下拉普拉斯方程的具体形式，直接对它做分离变量：假设解 $u(r,\theta,\phi)$ 等于一个关于 $r$ 的函数乘以一个关于 $\theta$ 和 $\phi$ 的函数——关于 $r$ 的函数用大 $R$ 表示，关于 $\theta$ 和 $\phi$ 的函数用大 $Y$ 表示：

$$u(r,\theta,\phi) = R(r)\,Y(\theta,\phi)$$

分离变量的结果跟之前一样：等式一端只和 $r$ 有关，另一端只和 $\theta$、$\phi$ 有关，它们俩要时刻相等，只可能等于同一个常数，我们设这个常数等于 $-\alpha$。

顺便把名字定下来：第一次分离变量以后得到的、仅和 $\theta$ 和 $\phi$ 有关的这个方程，就叫做球谐函数方程；把这个方程解出来，得到的函数 $Y$ 就叫做球谐函数。

现在考察中间这一项——$Y(\theta,\phi)$ 满足的还是一个偏微分方程。又得了个偏微分方程，还是不会解呀。不会解怎么办呢？遇事不决，继续分离变量：把 $Y(\theta,\phi)$ 分解成 $\Theta(\theta)$ 乘以 $\Phi(\phi)$，再做一次分离变量。

这一次分离完，$\Phi$ 那一项的导数里只和 $\phi$ 有关，$\Theta$ 那一项的导数里只和 $\theta$ 有关，但还剩一个 $\sin^2\theta$ 消不掉。既然等式一边带着 $\sin^2\theta$、另一边不带，两边又要时刻相等，那它们只能等于一个"常数除以 $\sin^2\theta$"形式的量——道理是这样的：给等式两边同时乘以 $\sin^2\theta$，就可以消掉其中一端所有跟 $\sin^2\theta$ 有关的量，所以另一端必然也带着一个 $\frac{\beta}{\sin^2\theta}$，这里的 $\beta$ 就是又一个分离常数。

先把容易的 $\phi$ 这边解掉。把与 $\phi$ 有关的量归到一起，它就变成了一个线性的齐次二阶常微分方程，可以解出两个特解：

$$\Phi_1(\phi) = \cos\bigl(\sqrt{\beta}\,\phi\bigr), \qquad \Phi_2(\phi) = \sin\bigl(\sqrt{\beta}\,\phi\bigr)$$

由于我们知道球坐标里的 $\phi$ 以 $0 \sim 2\pi$ 为一个周期——$\phi = 0$ 和 $\phi = 2\pi$ 是一回事——所以用周期性边界条件 $\Phi(0) = \Phi(2\pi)$，可以得到：$\beta$ 一定等于 $m^2$，这里的 $m$ 取遍自然数，因为只有这样才能满足 $\Phi(0) = \Phi(2\pi)$。

再来看 $\theta$ 这边。$\theta$ 的方程整理完之后，令 $x = \cos\theta$，会惊奇地发现：这个方程可以写成一个只和 $x$ 及未知函数有关、没有三角函数的形式。这个方程还可以继续考察：当 $x$ 取到 $\pm 1$ 的时候，这个方程其实是发散的，因为方程里有一项 $\frac{m^2}{1-x^2}$，$x = \pm 1$ 时分母是零。我们根据自然边界条件以及解的展开，可以解得：为了使解有界，$\alpha$ 一定可以写成

$$\alpha = l\,(l+1)$$

的形式，这里的 $l$ 取遍非负整数。

总之，球坐标系下拉普拉斯方程的分离变量解一共三块。径向方程——只和 $r$ 有关的部分——是一个二阶线性齐次微分方程，解出来是

$$R(r) = A\,r^l + B\,r^{-(l+1)}$$

$\phi$ 方向刚刚已经解过了：$\Phi_1 = \cos m\phi$，$\Phi_2 = \sin m\phi$。

### 连带勒让德方程与球谐函数

最后是跟 $\theta$ 有关的量。把 $\alpha = l(l+1)$ 和 $\beta = m^2$ 都带进去——也就是说，两个分离常数都定下来了——得到的这个方程，我们称为连带勒让德方程，这里的 $l$ 和 $m$ 都是我们人为指定的非负整数。这个方程解出来的多项式，称为连带勒让德多项式。

刚才说过，$Y = \Theta\,\Phi$，现在把两者乘在一起。在复数域下，我们往往还要求球谐函数是归一化的。所谓归一化，就是在整个立体角内做积分——因为在球坐标系中不看 $r$ 的话，$\theta$ 和 $\phi$ 相当于取遍整个单位球面。如果要求这个积分满足归一化条件（积分结果等于 $\delta_{kl}\,\delta_{mn}$ 这样的形式），可以解得

$$Y_l^m = N_{lm}\,P_l^m(\cos\theta)\,e^{im\phi}$$

也就是一个归一化系数，乘以连带勒让德多项式，再乘以 $e^{im\phi}$。这是复数域的球谐函数。

实际当中往往需要的是实数域的球谐函数，这需要根据 $m > 0$、$m < 0$、$m = 0$ 去做一个讨论。注意到我们刚才求解的过程当中，其实认为 $m$ 一定是大于等于零的；但我们解 $\phi$ 方程时得到过两个特解，一个 $\cos m\phi$、一个 $\sin m\phi$。这时候我们发现，不如把 $m < 0$ 的情况也给利用起来：$m \geq 0$ 的时候取 $\cos$ 这一支，$m < 0$ 的时候取 $\sin$ 这一支。这样去做，就得到了实数域归一化球谐函数的表达式：按 $m$ 的符号讨论，球谐函数分别有三种形式——$m > 0$ 时配 $\cos m\phi$，$m < 0$ 时配 $\sin|m|\phi$，$m = 0$ 时只剩勒让德多项式那一项。

所以，所谓的球谐函数是什么？它是连带勒让德多项式，乘以归一化系数，再乘以一个三角函数。

### 勒让德多项式

既然叫"连带"勒让德函数，那必然还存在不带"连带"的勒让德函数、存在勒让德方程。勒让德方程就是连带勒让德方程在 $m$ 取零的时候的特殊情况。它对应的物理图像是什么？是解出来的结果与 $\phi$ 无关：不管 $\phi$ 怎么变，得到的结果都相同——也就是说，解绕极轴旋转是对称的。这种情况下，连带勒让德方程就退化成勒让德方程（少了 $\frac{m^2}{1-x^2}$ 那一项），它解出来的解记作 $P_l(x)$（把 $P_l^0$ 的上标零省略掉），称为 $l$ 阶的勒让德多项式。

勒让德多项式要怎么计算呢？首先它有一个级数表达，级数表达可以直接带值算，因为它完全是一个多项式，多项式的系数可以直接用阶乘去计算。或者可以写成微分的形式——对 $(x^2 - 1)^l$ 求 $l$ 阶导数：

$$P_l(x) = \frac{1}{2^l\,l!}\,\frac{\mathrm{d}^l}{\mathrm{d}x^l}\left(x^2 - 1\right)^l$$

这是它的微分表示。

勒让德多项式有一些很好的性质。第一个性质：它有 $l$ 个零点，并且这些零点都是实的，而且都在 $-1$ 到 $1$ 之间；同时，勒让德多项式要么是奇函数、要么是偶函数，跟 $l$ 有关——$l$ 是奇数时是奇函数，$l$ 是偶数时是偶函数。第二个性质是勒让德多项式具有正交性：当 $n$ 和 $l$ 不同的时候，把两个勒让德多项式相乘、并在 $-1$ 到 $1$ 上做积分，积出来是零；如果两者阶数相同，积出来是 $\frac{2}{2l+1}$：

$$\int_{-1}^{1} P_n(x)\,P_l(x)\,\mathrm{d}x =
\begin{cases}
0, & n \neq l \\[4pt]
\dfrac{2}{2l+1}, & n = l
\end{cases}$$

知道如何计算勒让德多项式，你就会知道如何去计算球谐函数。

### 球谐函数在图形学中的应用

球谐函数有什么作用？在图形学当中，球谐函数最重要的作用就是作为基底，去展开一个球面函数。比如我们在做渲染的时候，会用一个球形的天空盒来表达环境光，表达所渲染物体周围的环境光照长什么样。但是如果你要存一个环境球的贴图，就需要非常大的存储空间，而且使用的时候你得做插值、做寻址，这些都是很大的计算量。

如果用球谐函数去展开，只用比较低阶的 $l$、比较低阶的 $m$，只取这些项，那它其实就只剩若干个系数了——因为球谐函数本身是固定的，展开的每一项前面只和系数有关。任何一个球面函数都可以用球谐函数去展开，所以我们只需要记前几项的展开系数，就可以近似地表达一个环境光照贴图了；想用这个环境光照的时候，直接在球谐函数上算一下值就可以了。这样你既不需要存储一个非常巨大的环境光贴图，效果也已经非常好了。

### 格林函数法：从点电荷说起

刚刚说的就是分离变量法在求解偏微分方程中的应用，接下来看格林函数法。要讲格林函数法，干脆先来看这样一个问题：给定空间中的电荷密度分布，求电场强度。

首先用场论那一节的知识。电场的高斯定理的积分形式是：在空间中任意划分一个区域，对这个区域的表面做电场强度的面积分，它等于区域内包含的电荷总量除以一个物理常量——这个物理常量叫真空介电常数，记作 $\varepsilon_0$：

$$\oint_{\partial V} \mathbf{E} \cdot \mathrm{d}\mathbf{A} = \frac{Q}{\varepsilon_0}$$

用高斯定理的微分形式，又可以把它写成电场强度的散度等于电荷密度除以 $\varepsilon_0$：

$$
abla \cdot \mathbf{E} = \frac{\rho}{\varepsilon_0}$$

其中 $\rho$ 就是电荷密度。这两个形式是等价的，只不过第一个是积分形式，第二个是微分形式。

积分形式还好说：如果空间中有一个点电荷，你只要把这个点电荷包起来、去算这个面积分就可以了。但考虑这样一个问题：如果是微分形式呢？在点电荷附近会发生什么？电荷密度会变成无穷大——因为物理中我们认为点电荷是没有体积的，它聚焦在空间当中的一个点上，这个点却带有一个有限大的电荷，也就是说，这时候电荷密度是发散的。

但事实上，我们已经知道空间中有一个点电荷时，电场强度的分布长什么样了。其实高中的时候我们就给出来了：在空间 $\mathbf{r_0}$ 处存在一个大小为 $Q$ 的点电荷，那么空间中的场强等于一个系数 $k$ 乘以电荷大小 $Q$、再乘以 $\mathbf{r} - \mathbf{r_0}$ 这个矢量、除以 $|\mathbf{r} - \mathbf{r_0}|$ 的三次方；或者写成大家更熟悉的形式

$$\mathbf{E}(\mathbf{r}) = \frac{kQ}{|\mathbf{r} - \mathbf{r_0}|^2}$$

方向由 $\mathbf{r} - \mathbf{r_0}$ 这个矢量决定。在大学的物理里面，我们又给出了空间某一点处大小为 $Q$ 的点电荷的电势，它可以由 $k$ 乘上 $Q$、再除以 $\mathbf{r}$ 到 $\mathbf{r_0}$ 的距离来计算。

所以这说明什么？点电荷处的电荷密度在无穷大的情况下，我们是知道电场分布的解的。于是这启发了我们去定义一个东西——狄拉克函数（狄拉克 $\delta$ 函数）。所谓狄拉克函数，在三维当中就是：当 $\mathbf{r} \neq 0$ 时，$\delta(\mathbf{r})$ 取零；当 $\mathbf{r} = 0$ 时，$\delta(\mathbf{r})$ 取无穷。但光这样不够，还要补充一个积分定义：在空间当中对 $\delta$ 做一个体积分，如果取的区域包含原点，体积分结果为一；如果取的区域不包含原点，积分为零。

有了狄拉克函数，我们就可以定义点电荷的密度了。直接说"密度等于无穷"这件事是没法定义的——无穷是一个概念，无穷可以有好多阶、有更高阶的无穷；但现在有了狄拉克函数之后，我们知道点电荷的密度就是

$$\rho = Q\,\delta(\mathbf{r} - \mathbf{r_0})$$

把它代回散度形式：$
abla \cdot \mathbf{E} = Q\,\delta(\mathbf{r} - \mathbf{r_0})/\varepsilon_0$。或者，我们令 $\mathbf{E}$ 等于某一个标量势 $\phi$ 的负梯度，就会写成

$$\Delta\phi = -\frac{Q\,\delta(\mathbf{r} - \mathbf{r_0})}{\varepsilon_0}$$

这个方程是什么？它是一个泊松方程。也就是说，泊松方程在等式右端是一个 $\delta$ 函数情况下的解，我们是知道的。这个"知道"是怎么知道的？是人类在做实验的时候，在电场这个特殊的情形下，已经把这个解找到了。

### 基本解与叠加原理

把上面的发现形式化表达一下：把右端的 $Q/\varepsilon_0$ 换成一个纯粹的 $\delta$ 函数，考虑方程

$$\Delta u = -\,\delta(\mathbf{r} - \mathbf{r_0})$$

它的解是

$$u = \frac{1}{4\pi}\,\frac{1}{|\mathbf{r} - \mathbf{r_0}|}$$

如果我们在等式右端乘上 $Q/\varepsilon_0$——也就是电势所满足的泊松方程——解就等于 $\phi = \dfrac{1}{4\pi\varepsilon_0}\cdot\dfrac{Q}{|\mathbf{r} - \mathbf{r_0}|}$。这说明什么？前面我们是用一个 $k$ 来表达的，高中物理里那前面就是一个 $k$——也就是说，$\dfrac{1}{4\pi\varepsilon_0}$ 就是这个 $k$。

我们称 $u = \dfrac{1}{4\pi}\,\dfrac{1}{|\mathbf{r} - \mathbf{r_0}|}$ 为泊松方程在无穷远边界条件下的格林函数解，或者把它称为泊松方程的基本解。这里要注意：格林函数解是要指定边界条件的，而基本解不需要指定边界条件——基本解里蕴含了你取无穷远的边界条件。什么叫无穷远的边界条件？就是当 $|\mathbf{r}|$ 趋向于无穷的时候，这个函数的值等于零。

那么由叠加原理，我们就可以求得无穷远边界条件下 $\Delta u = f$ 的解——就相当于给定电荷密度分布求电势：刚才给定了空间中有一个点电荷去求电势，现在改成电荷密度分布求电势，那就做一个体积分：

$$u(\mathbf{r}) = \frac{1}{4\pi}\int \frac{f(\mathbf{r}')}{|\mathbf{r} - \mathbf{r}'|}\,\mathrm{d}V'$$

它相当于说什么？比如这里有一个导体，导体上均匀带电，你考察它的每一小段 $\mathrm{d}V$：这一小段的电荷密度就是 $Q/V$，你用库仑定律算一下这一小段贡献的电势，然后给它做积分——其实就是格林函数解的意思。

### 镜像法：非无穷远边界的格林函数

刚才给出的都是无穷远边界条件下的格林函数解，现在来看非无穷远边界条件下格林函数解长什么样。还是举静电学当中的例子：空间中有一个无穷大的平面，满足电势为零；在平面的左端有一个点电荷。形式化一下：泊松方程，外加一个边界条件——在 $x = 0$ 处 $\phi = 0$。

这个方程的格林函数解可以直接给出来：

$$G = \frac{1}{4\pi\varepsilon_0}\left(\frac{Q}{|\mathbf{r} - \mathbf{r_0}|} - \frac{Q}{|\mathbf{r} - \mathbf{r_0}'|}\right)$$

可以看到，它相当于在源点 $\mathbf{r_0}$ 当中，把 $x$ 分量做了一个反号，得到镜像点 $\mathbf{r_0}'$。它等同于：电荷本身产生的电势，加上右侧镜像位置的异号电荷产生的电势。就是说，左边比如有一个正电荷，由于边界条件是这个无穷大的平面电势为零，它就会在右端产生一个镜像电荷：设左边带电量是 $+Q$，镜像位置那个就是 $-Q$——带电量与左边的电荷相反，并且距离与它是镜面关系。

类似地，如果左端不是一个点电荷，而是一个电荷分布，我们就可以用这个镜像法的格林函数解，加上叠加原理去求解这个方程。

还有一点要注意：刚才给出的所有这些格林函数——无穷远的也好、非无穷远的也好——它们都是三维的。在二维的情况下，泊松方程 $\Delta u = -\delta(\mathbf{r} - \mathbf{r_0})$ 在无穷远边界条件下的解，不是刚刚说的 $\dfrac{1}{4\pi|\mathbf{r} - \mathbf{r_0}|}$，而是对数形式

$$\frac{1}{2\pi}\,\ln\frac{1}{|\mathbf{r} - \mathbf{r_0}|}$$

要注意这个区别。

### 格林恒等式与边界元法

格林不仅提出了用格林函数法求解偏微分方程，同时还证明了三个以他名字命名的恒等式。设定是：区域 $V$ 内有连续可微的标量函数场 $\phi$ 和 $\psi$。第一恒等式给出了 $\phi$ 和 $\psi$ 满足的一个体积分关系，等于在这个区域的面上做的一个特定的面积分；第二恒等式也是类似的，一个体积分等于一个面积分。前两个恒等式的作用，是把两个定义在某个区域上的标量函数场联系起来，找到它们俩之间的关系。

格林第三恒等式，相对来说对我们更重要一些。假设 $G(\mathbf{r}, \mathbf{r_0})$ 是泊松方程的基本解，而 $\psi$ 在所考察的区域内满足拉普拉斯方程，那么这时我们会得到 $\psi$ 的一个表达式：$\psi$ 等于在所取区域的边界上做的一个面积分。这个面积分只和四样东西有关：$\psi$ 本身、$\psi$ 在区域边界面上沿外法线方向的偏导数、泊松方程的基本解，以及基本解的偏导数。

它相当于说什么？我在空间当中任取一个区域，如果我知道这个区域边界上的值、以及这些边界上的偏导数，我就能得到——估算出——区域内部任何一个位置的 $\psi$ 是多少，它就相当于对这个区域边界做一个积分。那么这个方程，就构成了边界元法的基础。今天我们不会展开讲边界元，因为偏微分方程的离散化本身也是图形学研究的内容之一。

### 数值解法一瞥

最后我们简要地看一下，微分方程要用什么样的方法去做数值解。

#### 常微分方程：欧拉法与龙格-库塔

常微分方程的数值解，最简单的形式是

$$y' = f(x, y), \qquad y(x_0) = y_0$$

欧拉法说，第 $i+1$ 个时间步的 $y$ 等于第 $i$ 个时间步的 $y$，加上 $f(x_i, y_i)$ 乘以 $h$：

$$y_{i+1} = y_i + f(x_i,\,y_i)\,h$$

其中 $h$ 就是步长，$h = x_{i+1} - x_i$。这个方法只有一阶精度，可以通过一些手段去提升它的精度，由此会产生高阶方法，我们称之为龙格-库塔法。关于常微分方程数值解的详细内容，大家可以去参见 GAMES 系列的相关课程。

#### 偏微分方程：有限差分与点迭代

关于偏微分方程，我们还是以二维拉普拉斯方程为例。假设空间中有一些格点，这些格点之间都是均匀分布的，格点上存储了函数 $u$ 的值。中心格点记作 $(i,j)$，它的四个邻居分别是 $(i+1,j)$、$(i,j+1)$、$(i-1,j)$、$(i,j-1)$，并且我们假设每个格子的边长都是 $\Delta x$——它们都是正方形。

```text
            u(i,j+1)
                |
u(i-1,j) --- u(i,j) --- u(i+1,j)
                |
            u(i,j-1)
```

计算拉普拉斯算子时用到的五个格点：中心点，加上它的上、下、左、右四个邻居。

如果我们用有限差分去计算拉普拉斯算子，它等于什么？有限差分是说，可以用

$$\frac{u_{i+1,j} - u_{i,j}}{\Delta x}$$

去近似估算这个位置的 $u$ 的一阶偏导数；类似地，用 $u_{i,j+1} - u_{i,j}$、$u_{i,j} - u_{i-1,j}$、$u_{i,j} - u_{i,j-1}$ 这些差分，去算另外几个位置的一阶偏导数。这些一阶偏导数在一起，再求一次一阶偏导数，是不是就得到原来 $u$ 的二阶偏导数了？也就是说，把它们相减、再做一次有限差分的计算，最后简化，就得到中心这一点的拉普拉斯算子：它等于所有相邻格点的 $u$ 值相加、再减去四倍中心点的值，除以 $\Delta x^2$：

$$\Delta u \approx \frac{u_{i+1,j} + u_{i-1,j} + u_{i,j+1} + u_{i,j-1} - 4\,u_{i,j}}{\Delta x^2}$$

拉普拉斯方程是说，每个格点处拉普拉斯算子作用后的结果都等于零。令这个东西等于零，$\Delta x^2$ 就跟方程无关了、可以约掉，那么

$$u_{i,j} = \frac{u_{i+1,j} + u_{i-1,j} + u_{i,j+1} + u_{i,j-1}}{4}$$

也就是每一点的值，等于它所有周围邻居相加再除以四。

这东西怎么解呢？可以用迭代法去求解。首先是雅可比迭代：在每个时间步内，用上一时刻它周围四个格点的值的平均，来更新 $u_{i,j}$。这个方法的收敛效率要稍微慢一些。如何提升呢？其实非常简单，就得到了高斯-赛德尔迭代：高斯-赛德尔迭代是说，可以直接写 for 循环去扫——一半的值用这一次的结果（已经更新过的邻居，用新值），一半的值用上一次的结果（还没有更新过的邻居，用旧值），给它们求平均，得到 $u_{i,j}^{n+1}$。

那什么时候我们知道方程解完了呢？可以去估算 $\sum_{i,j}\bigl|u_{i,j}^{n+1} - u_{i,j}^{n}\bigr|$：取绝对值、求和，当这个东西小于你给定的某一个 `tolerance` 之后，就让算法停止。这样，你就给出了求解二维拉普拉斯方程的一个最简单的数值解法——这也是我们今天的编程作业。

上述解法在分类上，称之为有限差分离散化下的点迭代法：一个离散化的方式，加上一个求解的方式。

### 承上启下：方程变成了线性系统

上面看到，除了有限差分法以外，还有有限体积法、有限元法、边界元法等其他离散化方式，这些可以参见 GAMES 系列的其他课程；而线性系统的求解，除了上面给出的点迭代法以外，还有共轭梯度法、多重网格法等等——这些就是下一节课的内容，下一节课要讲线性系统。

今天这节课之所以说是承上启下，就在于我们巧妙地把一个二维的拉普拉斯方程转换成了另一种形式：它的自变量都是格点处的值，它们之间满足一些恒等式的关系——这就是一个线性系统。一些离散的值，这些离散的值之间要满足一个巨大的矩阵方程。也就是说，我们通过空间离散化的方式，把一个偏微分方程转化成了一个线性系统。那么这个线性系统具体要怎么求解？欢迎大家来到下一次课。作业之后，助教会在群里发布。

## 求解线性系统：从高斯消元到不动点迭代
> 对应块：BLK23 | 覆盖分集：P13上 | 块标题（分集名）：《线性系统》

这一讲要解决的问题本身非常简单：给定矩阵 $A$ 和右端项 $b$，把矩阵方程 $Ax = b$ 的解求出来。但这个问题在图形学中非常重要，它会出现在各个地方：几何处理里做隐式拉普拉斯平滑（implicit Laplacian smoothing），涉及解方程；物理模拟更不用说，每一个时间步内一般都要解一个规模很大的线性方程组；全局渲染里也有，像 radiosity 这类基于辐射度的算法同样需要解方程。所以，如何针对不同的问题选择合适的矩阵求解器，让它解得又稳定、又快、又好，就是我们这一讲要讨论的中心问题。

### 高斯消元：从一个 3×3 的例子说起

最直接的思路当然就是直接求解，也就是大家在线性代数里都接触过的高斯消元法。我们拿一个 $3 \times 3$ 的矩阵方程 $Ax = b$，把整个过程走一遍。

第一步，用第一行对角线上的 $2$ 当主元，去消掉第二行、第三行在第一列的 $3$ 和 $2$。具体做法是把第一行乘以 $\frac{3}{2}$ 加到第二行上：$2 \times \frac{3}{2} + (-3) = 0$，第一列的这个元素就变成零了；同一行里其他位置的元素也同步更新，比如某一列上，第一行的 $8$ 乘以 $\frac{3}{2}$、加上第二行原来的 $-11$，就变成了 $1$。同样的把戏用在第三行上，第一行乘个倍数加过去，第三行第一列的 $2$ 也被消掉了。这样得到的新矩阵方程与原方程完全等价，但形状已经更好解了——它的第一列在主元以下已经全是零。

接着看第二行：它现在的主元是 $0.5$。把第二行乘以 $-4$（即 $0.5 \times (-4) = -2$）加到第三行上，第三行的那个 $2$ 就被消掉了。做到这里，系数矩阵变成了上三角矩阵。

上三角方程有天生的求解顺序：先解最后一行，直接得到 $x_2$；代回倒数第二行，解出 $x_1$；再代回第一行，解出 $x_0$。这样就把所有未知数都求出来了。

这个"往回代"的过程，其实也可以看成是一个逆向的高斯消元：把最后一行乘个倍数加到第二行、再乘个倍数加到第一行，然后把第二行也乘个倍数加到第一行，把上三角部分的 $1$、$-1$、$0.5$ 这几个非零元一个个消掉。消完之后，方程变成对角矩阵，连代都不用代，解直接就摆在那儿了：

$$x_0 = 2, \qquad x_1 = 3, \qquad x_2 = 1.$$

这就是高斯消元法求解矩阵方程最基础的完整过程：正向消元，把矩阵压成上三角；回代，把解一个个抠出来。

### 行变换的矩阵身份：LU 分解

刚才的消元过程可以换一个角度来看。我们干的事情，本质上就是不断重复"某一行乘以某个常数，加到另一行上"，用这种方式消掉矩阵里的一些变量。关键在于：每一次行变换，都等价于在左边乘上一个矩阵。

拿第一步验证一下。把第一行乘以 $1.5$（也就是 $\frac{3}{2}$）加到第二行上，等价于把原矩阵分解成两个矩阵的乘积：左边是一个下三角矩阵，对角线全是 $1$，只在左下方那一个位置有个 $-1.5$；右边就是变换之后的矩阵。怎么验证？把那个 $-1.5$ "乘回去"就行：它位于第二行第一列，作用到右边的矩阵上，效果就是把右矩阵的第一行乘以 $-1.5$ 加到第二行上——正好把第二行恢复成原来的值。

既然每一步行变换都等价于左乘一个矩阵，那一路消元下来，就是有一堆矩阵一直在左边乘。而这些矩阵都是下三角的，下三角矩阵连乘还是下三角矩阵——所以整个消元过程积累下来，等于左乘了一个总的下三角矩阵。

于是，高斯消元的全过程可以写成这样一个矩阵分解的形式：

$$A = LU,$$

其中 $L$ 是下三角矩阵（对角线全是 $1$），$U$ 是上三角矩阵。$L$ 里对角线以下那些数是什么？正是我们每次做高斯消元时用的那些倍数取负。回头数一数：我们用了 $\frac{3}{2}$、$-1$、$-4$，那么 $L$ 里出现的就是 $-\frac{3}{2}$、$1$、$4$。换句话说，这个下三角矩阵记录的，正是我们对原矩阵做过的那一系列行变换。

### 从分解到算法：两步求解与原地存储

写成 $A = LU$ 之后，就能看清高斯消元为什么能帮我们解方程。把 $Ax = b$ 拆成 $LUx = b$：先解 $L$ 的方程——把 $Ux$ 整体当作一个未知向量，解 $Ly = b$；解出来之后，再把刚才的解当作新的右手项，解 $Ux = y$。一个方程被换成了两步方程。

而这两步都是三角方程，可以直接顺着解：对下三角的 $L$，先解第一行，把结果代入第二行再解第二行，再代入第三行；对上三角的 $U$ 就倒过来，先解最后一行，代入回第二行，再代入回第一行。所以一旦把 $A$ 分解成一个下三角矩阵和一个上三角矩阵，原方程通过这样两遍扫描就能解出来。这就是高斯消元法更形式化的表达；把它转化成算法，就是所谓的 LU 分解算法。

这个算法还利用了一点：它并没有把 $L$ 和 $U$ 另外存成两个矩阵，而是就存在 $A$ 自己里面——输入是 $A$，算法跑完输出还是 $A$，只不过输出的 $A$ 矩阵，下三角部分对应的就是 $L$，上三角部分对应的就是 $U$。这就是所谓的 in place（原地）操作：

```text
分解完成后的 A（原地存储）：
[ u11  u12  u13 ]
[ l21  u22  u23 ]
[ l31  l32  u33 ]
```

读图：同一个数组里，严格下三角存的是 $L$，对角线连同上三角存的是 $U$；$L$ 的对角线全是 $1$，不必占存储。

至于复杂度，也非常容易看出来：算法里有三个嵌套的 for 循环，所以复杂度就是 $O(n^3)$，跟矩阵维数的立方成正比——相对来说是相当高的。当然，也可以为它设计对应的并行算法，进一步提高速度。

### 主元不能是零：部分选主元

LU 分解还有一个小地方需要注意。设想消元进行到中间某一步，该用第二行去消第三行了，却发现第二行的主元不是 $0.5$ 而是 $0$。这是完全可能发生的：你拿第一行去消第二行的时候，不光把第一个元素消掉了，还顺手把第二个元素也消掉了。

这时候如果还按算法照章办事，第二行的 $0$ 就要作分母，直接出现除零操作，数值上立刻就不稳定了。

> **易错点**：消元中途主元变零不是"倒霉"，而是正常现象；不设防的 LU 分解在这里会直接除零崩溃。

所以为了让 LU 分解算法更稳定，一般的做法是在"选哪一行去消哪一行"这个环节上做文章：每次都选绝对值最大的那一行来当主元。比如在刚才的例子里，就不用 $0.5$ 去消 $2$，而是反过来用 $2$ 去消 $0.5$。这样一来，只要整个矩阵是满秩的，就能保证算法过程中不会除以一个小量而导致数值不稳定。这种方法一般称为列主元高斯消去法，或者部分选主元高斯消去法，简写 GEPP（Gaussian Elimination with Partial Pivoting）。

### 对称半正定的捷径：Cholesky 分解

对于对称半正定的矩阵，上面这套流程有一个更为简单、也非常常用的版本：Cholesky 分解（Cholesky decomposition），也称为 LLᵀ 分解。它干的事情是把 $A$ 分解成

$$A = LL^{\top},$$

其中 $L$ 是下三角矩阵，$L^{\top}$ 自然就是上三角矩阵——依然还是"下三角乘上三角"，只不过这两个因子现在互为转置。正因为 $A$ 是对称半正定的，下三角部分和上三角部分才会恰好是这么一个转置关系。

利用这个关系，可以简化 LU 分解的算法。怎么简化？把 $L$ 里的元素都当作待求的未知数，把 $LL^{\top}$ 乘开、令其等于 $A$，然后一个一个把 $L_{11}$、$L_{21}$、$L_{22}$ 这些值解出来。求解顺序是现成的：

- $L_{11}^2 = A_{11}$：乘开的矩阵在 $(1,1)$ 位置只剩这一项，它只跟 $L_{11}$ 有关，所以 $L_{11} = \sqrt{A_{11}}$，直接解出；
- 有了 $L_{11}$，代入 $(2,1)$ 位置的式子，得 $L_{21} = A_{21} / L_{11}$；
- $L_{21}$ 有了，再代入 $(2,2)$ 位置的式子，得 $L_{22} = \sqrt{A_{22} - L_{21}^2}$。

就这么一路带下去，整个 $L$ 里的各个系数就都求出来了。

相比 LU 分解，好处在哪？由于 $A$ 是对称的，只需要知道一个 $L$ 就够了，不需要同时知道 $L$ 和 $U$，相应的计算量可以减小一半。它的算法跟 LU 分解长得很像，但注意它同样有三重 for 循环，所以复杂度也是 $O(n^3)$。对于对称半正定的矩阵来说，Cholesky 分解（LLᵀ 分解）是一个非常常用的算法。

### 直接法的天花板

到这里，我们有了两种直接求解矩阵方程的方法，摆在一起看：

| 方法 | 分解形式 | 适用矩阵 | 特点 |
| :--- | :--- | :--- | :--- |
| LU 分解（高斯消元） | $A = LU$ | 任意矩阵 | 通用；需选主元保证鲁棒性 |
| Cholesky 分解（LLᵀ） | $A = LL^{\top}$ | 对称半正定 | 只求一个 $L$，速度更快 |

LU 分解直接对应高斯消元，可以求解任意的矩阵方程，只不过为了保证算法的鲁棒性，需要在选主元上做文章，避免出现除零。LLᵀ 分解只适用于对称半正定的情况，但相应的速度会比 LU 分解更快一点。

这两种算法的时间复杂度都是 $O(n^3)$，所以一般来说只适用于求解小的矩阵方程。多小呢？矩阵大小在 $100$ 到 $1000$、也就是 1000 以下这个量级，用 LU 分解、LLᵀ 分解一般是能够解得很快的。再往上走，立方复杂度会让这两种直接求解方法的速度大大减慢。

而在图形学中，我们经常需要在 mesh 上解方程，或者给一个场景构建方程，矩阵的规模会非常大：比如这样一个 mesh，轻轻松松就有超过 10 万个顶点，建出来的矩阵方程就是 10 万 × 10 万的。这时候再用 LU 分解、LLᵀ 分解，就会非常非常慢——可能需要几十分钟甚至几个小时。这样的速度显然是不可接受的。

所以对于更大规模的矩阵方程，我们一般来说使用的是迭代求解的方法。

### 迭代法的通用框架

迭代方法的整个流程是一个大框架。先有一个初始猜测 $x_0$：如果完全没有任何信息，可以直接把 $x_0$ 置成零；如果有一些信息——比如大概知道 $Ax = b$ 的解可能是多少——就把所能拿到的那个值作为初始值。然后反复执行某一个步骤，从 $x_k$ 推到 $x_{k+1}$，不断迭代下去。我们期望迭代到一定步数时，把 $x_k$ 放进矩阵方程里检查，残差（residual）

$$r = b - Ax$$

的模长足够小了，就认为迭代可以终止，得到的解差不多就是一个精确解。

```text
初始解 x0（没信息就置零；有先验就猜个近的）
  │
  ▼  反复执行同一个更新步骤
xk  ──▶  xk+1  ──▶  xk+2  ──▶ ...
  │
  ▼
每步算残差 r = b − A·xk，看 ‖r‖ 是否够小
  │
  ├─ 够小（如 < 1e-6）→ 停止，xk 就是近似解
  └─ 不够            → 回到上面，继续迭代
```

这个框图就是迭代法的骨架：一个不断重复的更新步骤，加上一个"残差够小就停"的出口。

阈值怎么选？比如可以把残差的上界选成 $10^{-6}$——这已经达到 float 的数值精度了，再往下迭代也没有意义。但很多情况我们甚至不需要达到这么小，$10^{-3}$、$10^{-4}$ 就够了。

跟直接求解相比，迭代法还有这么几个好处：

- 随时可以把迭代停下来，拿到一个差不多的解。直接法必须等算法全部跑完，才能拿到非常准确的解；而很多时候我们并不需要非常非常精确的解，差不多就行了。
- 如果初始猜测给得非常好，迭代次数会大大减小，不需要迭代多少步就能逼近真实解。
- 对很多特定问题——比如矩阵是稀疏矩阵，或者是对称正定矩阵——有专门的迭代算法去解这类矩阵方程，速度明显优于直接求解。
- 某些时候，$Ax = b$ 的 $A$ 并没有显式存下来，我们只拿到一个接口：输入 $x$，返回 $Ax$；至于 $A$ 到底长什么样，是个黑盒。很多迭代方法恰恰只用这样一个接口，这时迭代法就比直接求解更有优势——直接法连矩阵本身都拿不到，无从分解起。

给一个数量级的体感：一个弹性体模型，一共 20 万个节点，对应的矩阵方程就是 60 万维的（每个节点 3 个自由度），这个矩阵是非常大的。但只要迭代求解器设计得好，几十毫秒内就可以把它解得差不多；直接求解的话，可能就需要几十分钟甚至更长的时间。迭代算法设计得好，速度是非常可观的。

### 不动点迭代：从卡西欧计算器说起

这一讲要介绍的第一类迭代方法，叫不动点迭代。先从一个非常简单的例子说起：如果你玩过卡西欧计算器，可以试试这样一个操作——随便给一个初值，比如 $x = 0$，然后不断地执行 cos Ans：每一次都把上一次 cos Ans 的结果再放进 cos 里，一直往下算，也就是一直按等号。你会发现，这个值最后会收敛到某一个特定的值上。

这个值是什么？它反映的其实就是方程 $x = \cos x$ 的解。画成图就是：一条直线 $y = x$，一条曲线 $y = \cos x$。从 $x_0 = 0$ 出发，算一次得 $1$，再算变成 $0.54$，再算变成 $0.85$……一直这么算下去，这个序列就会慢慢收敛到两条曲线的交点上，而收敛到的这个解，正是 $x - \cos x = 0$ 这个方程的解。整个过程就称为不动点迭代。为什么这么叫？原因非常直观：这个点在迭代的过程中，最后会收敛到真正的解上——它就不动了。

换到 $Ax = b$ 这个矩阵方程上，不动点迭代可以这么写。假设把 $A$ 拆成两个矩阵的差：

$$A = M - N.$$

那么 $Ax = b$ 可以改写成 $Mx - Nx = b$；把 $Nx$ 移到右边，两边同时乘一个 $M^{-1}$，就变成

$$x = M^{-1}Nx + M^{-1}b.$$

这个方程跟 $Ax = b$ 是等价的，但左右两边同时出现了 $x$——这正是不动点的形状。于是可以照抄计算器上那套操作：每有一个 $x_k$，就把它代入方程的右边，输出的结果记为 $x_{k+1}$；下一步再把 $x_{k+1}$ 代进去，得到的结果变成 $x_{k+2}$。如此往复进行，迭代就走起来了。

这个迭代过程可以验证：如果它收敛了——也就是 $x_k$ 趋向某一个固定的值 $x^*$——把它带回去，一定会有 $(M - N)x^* = b$，也就是 $Ax^* = b$。所以说，只要它收敛，收敛到的值一定是 $Ax = b$ 的解。

> **结论**：不动点迭代一旦收敛，极限必为原方程的解；真正要担心的是"能不能收敛"。

那么这里显然有几个问题。第一，$M^{-1}$ 这个矩阵要怎么去算？$M$ 是我们任意取的一个矩阵，$M$ 的逆——或者说以 $M$ 为系数的那一步求解——到底好不好算？其次，这个不动点迭代的收敛效率到底会有多快？以及，它到底能不能保证收敛？有没有可能迭代下去 $x$ 越变越大，最后直接炸掉？

### 雅可比迭代：拿对角线当 M

最简单的不动点迭代例子是雅可比迭代（Jacobi iteration）。它选 $M$ 的方式非常直接：直接取 $M$ 为 $A$ 的对角部分 $D$，把剩下的非对角部分取个反，扔到 $N$ 里去。也就是

$$M = D, \qquad N = D - A,$$

$N$ 的对角线全是 $0$、非对角线是 $-a_{ij}$，正好满足 $M - N = A$。代回不动点形式，迭代就是

$$x_{k+1} = D^{-1}(Nx_k + b).$$

实际迭代的时候：比如 $x$ 从零开始，每次先算 $Nx_k + b$ 拿到一个向量，然后左乘 $D^{-1}$——因为 $D$ 是对角矩阵，它的逆是非常好求的东西，对角线逐个取倒数就行——把结果塞回 $x_{k+1}$ 里去。所以雅可比迭代是一个非常简单的迭代算法。

拿一个具体的 $3 \times 3$ 矩阵看它收敛的情况：随着迭代数的增大，整个矩阵方程的残差——也就是 $b - Ax_k$ 的模长——在不断减小：初始是个很大的值，然后不断减小，减到零就意味着 $b = Ax_k$，最后就收敛了。这个例子确实可以收敛，不过即便是 $3 \times 3$ 这么小的方程，雅可比迭代也需要跑十几步差不多才能收敛。

换一种情况：把刚才讲 LU 分解时用的那个 $A$ 矩阵拿过来，套进雅可比迭代——问题来了，整个东西不收敛。残差随着迭代数的增大在不断变大，而且这个变大的过程会一直持续，不会到后面某个地方减下来。也就是说，对这样一个矩阵，雅可比迭代失败了，它永远不可能达到这个矩阵的真实解。

所以，不动点迭代虽然非常简单，但在某些情况下是可能失败的。具体是哪些情况会失败？我们就希望有一个准则，能够告诉我们到底什么情况下不动点迭代是可以收敛的。

### 什么时候收敛：看迭代矩阵的特征值

我们来分析一下。把不动点迭代的形式写出来，然后做一步改写：既然 $M - N = A$，就有 $N = M - A$；把它代进 $x_{k+1} = M^{-1}(Nx_k + b)$，整理之后，形式里就只剩 $M$ 和 $A$：

$$x_{k+1} = M^{-1}\big((M - A)x_k + b\big) = x_k + M^{-1}(b - Ax_k).$$

接着定义两个贯穿下面的量。**误差**（error）反映每步迭代值与真实解之间的差距：

$$e_k = x^* - x_k.$$

**残差**（residual）反映方程当前还差多少没有被满足：

$$r_k = b - Ax_k.$$

残差和误差是两个不同的概念，它们之间的关系把 $b = Ax^*$ 代进去就能看出来：

$$r_k = b - Ax_k = Ax^* - Ax_k = A(x^* - x_k) = Ae_k.$$

也就是说，残差和误差之间就差一个 $A$ 矩阵。把这个关系带回到迭代式里——后面那个 $b - Ax_k$ 其实就是残差 $r_k$——就得到

$$x_{k+1} = x_k + M^{-1}Ae_k.$$

那么下一步的误差呢？$e_{k+1} = x^* - x_{k+1}$，代进去整理，就得到

$$e_{k+1} = e_k - M^{-1}Ae_k = (I - M^{-1}A)\,e_k = M^{-1}Ne_k.$$

这个推导告诉我们：每迭代一步，误差就被左乘一次矩阵

$$T = I - M^{-1}A = M^{-1}N,$$

给它起个名字，叫迭代矩阵。误差的演化完全由它决定。

对 $T$ 做特征值分解，把它对角化成 $T = Q\Lambda Q^{-1}$。$T$ 不一定是对称矩阵，所以特征值 $\lambda$ 可以是复数（带辐角），不过没关系，我们只关心它的模长。把误差向量 $e_k$ 在特征向量这组基底下展开，那么每迭代一步、乘一次 $T$，相当于给每个特征分量各自乘上对应的特征值一次；迭代 $k$ 步之后，每个分量乘的就是 $\lambda_i^k$。

于是收敛条件就水落石出了：只要 $T$ 的所有特征值的模长都小于 $1$，$e_k$ 的每个分量就都在每步乘一个小于 $1$ 的常数，不断迭代下去，$e_k$ 一定能收敛到零。

> **结论**：不动点迭代收敛的充分且必要条件，是迭代矩阵 $T = M^{-1}N$ 的所有特征值的模长都小于 $1$。

为什么是充要的？反过来看：只要 $T$ 里有一个特征值的模长大于 $1$，那一维的误差分量就会每步被放大。最简单的情况，设 $T$ 是对角矩阵、某个对角元是 $2$，那一维的误差每步乘 $2$：$2$、$4$、$8$、$16$……不断乘下去，最后就炸掉了，迭代不可能收敛。

另外，特征值越小，对应分量的误差收敛得越快——因为每步乘的那个数更小。极端情况是什么？$M$ 直接取 $A$ 本身。这时 $T = I - A^{-1}A = 0$，零矩阵的特征值全是 $0$，一步就能把所有的误差降到零。代价是什么？迭代的时候你还是得处理 $A^{-1}$ 这个东西——可它正是我们处理不了的、想绕开的东西。我们做迭代法的目的，本来就是为了不直接面对 $A^{-1}$。

所以在选择 $M$ 的时候，准则就清楚了：让 $M$ 尽可能地去接近、近似 $A$（把 $T$ 的特征值往小压），同时 $M^{-1}$ 又必须是一个能方便求解的东西。雅可比迭代取 $M$ 为 $A$ 的对角阵，就是用对角线去近似 $A$——对角矩阵的逆好求到极致，这就是它的立足点。

不过，这个特征值判据在实际应用里是不好用的：总不能把 $T$ 求出来，再对它做一遍特征值分解，看每个特征值是不是小于 $1$——有这功夫，迭代可能早就自己收敛了。所以它只是一个理论上的判断。实际应用的时候，我们有一些简化的判断标准。

### 实用的充分条件：对角占优

对雅可比迭代这种特殊的不动点迭代，有一个现成的结论：如果 $A$ 是对角占优矩阵，那么雅可比迭代一定能够保证收敛。什么叫对角占优？对 $A$ 的每一行而言，对角元素的绝对值大于该行其余所有非对角元素的绝对值之和：

$$\left| a_{ii} \right| > \sum_{j \neq i} \left| a_{ij} \right| \quad \text{对每一行都成立}.$$

> **易错点**：对角占优是充分条件，但不是必要条件——不满足它也可能收敛，满足它则一定收敛。

正因为这个条件非常简单，它才特别实用：建矩阵的时候扫一眼、逐行查一查，就能预判雅可比迭代收不收敛。回头看刚才的两个例子：第一个矩阵显然是对角占优的，所以它收敛了；第二个矩阵不是对角占优的，所以它就发散了。

### 发散了还有救：松弛法

那对非对角占优的矩阵，是不是就完全没办法用雅可比迭代去解了？也不是完全没有办法，可以使用松弛的方法。松弛是什么意思？非常简单：在做雅可比迭代时，给每次更新的步长乘一个常数 $\omega$：

$$x_{k+1} = x_k + \omega\, D^{-1}(b - Ax_k).$$

刚才我们所有的迭代其实都默认 $\omega = 1$——右边求出来直接加到 $x_k$ 上；现在是先乘一个 $\omega$ 再加。$\omega$ 的取值还挺自由的，大于 $1$ 甚至都可以。但如果你面对的情况是不收敛，$\omega$ 一般就取一个小的值，尽量小。

还是刚才那个发散的例子：取 $\omega = 0.5$，每次更新的步长打对折，最后它其实还是会收敛的——只不过迭代数相比那些 $\omega = 1$ 就能收敛的情况会稍微久一点，但它能处理原本会发散的情况。

所以经验是：如果发现迭代发散了，可以试一试用松弛法，乘上这样一个 $\omega$ 因子。

### 雅可比迭代的得与失

总的来说，雅可比迭代是一个每一步代价都很低的迭代算法：每一步里只需要算一个对角矩阵的逆——逐个元素取倒数，非常好算；而且由于 $M$ 是对角矩阵，各维互相独立，非常利于并行操作。

但它需要的迭代步数还是挺多的：刚才展示的 $3 \times 3$ 矩阵的情况，就需要十几步甚至几十步才能收敛。单步便宜、步数偏多，这笔账正是挑选迭代求解器时最核心的权衡之一。

## 线性系统求解：从不动点迭代到共轭梯度
> 对应块：BLK24 | 覆盖分集：P13下 | 块标题（分集名）：《线性系统》

### 雅可比迭代的快与慢

上一部分我们把解 $A\mathbf{x} = \mathbf{b}$ 写成了不动点迭代的形式，迭代矩阵是 $T = I - M^{-1}A$；雅可比迭代取 $M$ 为对角阵 $D$，此时 $T = I - D^{-1}A$。现在把账算一算：如果矩阵是几万维的，迭代步数很可能也得是几万、几十万这个量级——所以总的来说，它依然不快。但好就好在，它非常简单。

而且在某些情况下，雅可比迭代收敛得非常快。什么情况？比如 $A$ 本身就是一个对角矩阵，那雅可比迭代一步就可以收敛，因为这时

$$T = I - D^{-1}A = 0$$

迭代矩阵直接就是零矩阵。反过来说，$A$ 越是对角占优——对角元相对越大——用对角矩阵去近似 $A$ 的效果就越好，迭代矩阵 $T$ 就越接近零矩阵，收敛速度也就越快。

> **结论**：雅可比迭代快不快，看 $A$ 有多"像对角矩阵"：越对角占优收敛越快，极端情况（$A$ 本身就是对角阵）一步收敛。

### 高斯–赛德尔迭代：把 M 选得更像 A

雅可比迭代显然不是唯一的不动点迭代方法，经常和它放在一起提的，是高斯–赛德尔迭代（Gauss–Seidel iteration）。它跟雅可比迭代最大的区别，就在 $M$ 矩阵的选取上：雅可比迭代把 $M$ 取成对角矩阵；高斯–赛德尔迭代则把 $M$ 取成 $A$ 的对角部分加上下三角部分——取"对角加上三角"也没有本质区别，只是个约定。

这时 $M$ 是一个下三角矩阵。$M^{-1}$ 怎么求？注意每步迭代真正要算的是 $M^{-1}$ 乘一个向量，也就是解方程 $M\mathbf{x} = \mathbf{v}$。这正好就是高斯消元法的那套原理：从第一行开始，解出一个未知量就代入下一行，不断地求、不断地代入，就把 $M^{-1}\mathbf{v}$ 算出来了。所以对下三角矩阵来说，"逆矩阵乘一个向量"这个操作是很好算的。

而且，由于这里的 $M$ 比雅可比那个纯对角的 $M$ 多装了整个下三角，它明显更"像" $A$。于是可以想象，$T = I - M^{-1}A$ 这个迭代矩阵也更接近零矩阵——所以一般来说，高斯–赛德尔迭代需要的迭代次数比雅可比要少不少，收敛更快。

对应的代价呢？每一步的成本更高。雅可比迭代的 $M$ 是对角矩阵，各分量互不相干，可以直接并行地求；而这里的 $M$ 是下三角矩阵，只能一行一行串行地解。当然，在某些情况下——比如矩阵是稀疏的——也可以通过重排的方式得到一个并行版本的高斯–赛德尔迭代，那个版本具体长什么样子，有兴趣可以去查一查。

### 收敛条件：两条互不重叠的充分条件

高斯–赛德尔迭代的收敛也有一个充分但不必要的条件：$A$ 是对称正定矩阵。它并不要求 $A$ 对角占优。所谓"充分不必要"，就是满足条件一定收敛；不满足的话未必不收敛，只是没有这层保证。

要注意，这两类矩阵互不包含：不是所有对称正定矩阵都对角占优，也不是所有对角占优的矩阵都对称正定。但两条判据分工很清楚。

> **结论**：雅可比迭代收敛的充分不必要条件是 $A$ 对角占优；高斯–赛德尔迭代收敛的充分不必要条件是 $A$ 对称正定。

### 两个算法只差一件事：用没用上本轮的新值

真把高斯–赛德尔的算法写出来跟雅可比一对比，会发现改动非常小。唯一的改动在取值上：雅可比迭代在更新 $\mathbf{x}_{k+1}$ 时，用到的始终都是上一轮 $\mathbf{x}_k$ 的信息；高斯–赛德尔迭代由于用的是下三角矩阵 $M$，更新 $\mathbf{x}_{k+1}$ 时会同时用上本轮已经更新出来的那部分分量。比如更新第二个分量 $x_2$ 时，用的就是刚刚更新过的 $x_1$ 的值；而雅可比迭代更新 $x_2$ 时，只会用到上一轮还没更新的 $x_1$。

就这一条区别，导致两个算法在收敛性质上的差距——一般来说，高斯–赛德尔会比雅可比更快。

### 不动点迭代小结：简单，但都不快

到这里，把两种最基础的不动点迭代方法做个总结。它们的共同优势是实现非常简单；共同短板是收敛速度都不快——高斯–赛德尔会比雅可比快一点，但没有优化的话也照样跑得比较慢。两者各有各的收敛判别标准，具体用哪一种更好，要具体矩阵具体分析。

| 对比项 | 雅可比迭代 | 高斯–赛德尔迭代 |
| :--- | :--- | :--- |
| $M$ 的取法 | $A$ 的对角部分 | $A$ 的对角 + 下三角部分 |
| $M$ 与 $A$ 的相似程度 | 较远 | 更像 $A$ |
| 迭代矩阵 $T = I - M^{-1}A$ | 离零矩阵较远 | 更接近零矩阵 |
| 每步成本 | 低，可并行 | 高，逐行串行 |
| 总体迭代次数 | 多 | 明显更少 |
| 收敛充分条件 | 对角占优 | 对称正定 |
| 更新 $\mathbf{x}_{k+1}$ 时的取值 | 只用上一轮的 $\mathbf{x}_k$ | 顺带用本轮已更新的分量 |

### 两条改进出路：松弛与多重网格

如果出现了不收敛的情况，可以尝试用松弛的方法——给迭代配上一个松弛系数——来让雅可比或高斯–赛德尔收敛；实际使用中，一般也就是靠调节松弛系数，来平衡不动点迭代的稳定性和收敛速度。

另一条出路来自对收敛特性的仔细分析：如果仔细分析不动点迭代的收敛特性，其实可以分析出来哪些误差分量收敛得快、哪些误差分量收敛得慢。有了这个信息，就可以去构建多层的网格——或者说，不断用小规模的矩阵去近似 $A$，让误差在不同层之间传递，在不同层上用不动点迭代去求解。这个思想就是多重网格求解器的基本思想。

一般来说，多重网格算法是求解矩阵方程的最优方法，非常非常快。但它要求我们对矩阵的结构有一些分析：先分清楚这个矩阵的特性是什么——也就是不动点迭代作用到它上面时，哪些误差分量收敛得快、哪些收敛得慢。有了这些信息，才能构造出多重网格求解器来加速求解。这个部分今天就不展开了，有兴趣可以自行查查资料。

### 子空间方法：最多 N 步的承诺

到目前为止，我们介绍了两类解矩阵方程的方法：直接求解（LU 分解、LLT 分解），和不动点迭代（雅可比、高斯–赛德尔）。下面要介绍第三种迭代求解方法，称为子空间方法。

子空间方法的数学理论比较复杂，不像不动点迭代那么直观，我尽量用简单的语言把它的基本思想讲清楚。

出发点是：可以把 $A\mathbf{x} = \mathbf{b}$ 看成一个优化问题——去优化残差，让 $A\mathbf{x} - \mathbf{b}$ 越小越好。整个优化空间是 $\mathbb{R}^N$，设 $\mathbb{R}^N$ 上有一组基 $\mathbf{e}_1, \dots, \mathbf{e}_N$。子空间迭代的基本思想是：在第 $M$ 步，只考虑由 $\mathbf{e}_1$ 到 $\mathbf{e}_M$ 张成的 $M$ 维子空间上的优化问题的解——也就是限制 $\mathbf{x}$ 只能由这 $M$ 个向量的线性组合构成，只考虑在这个子空间上如何让残差最小。

这样一来，每一步迭代考虑的优化问题的维度，就不再是整个优化空间，而是一个子空间。并且，如果 $\mathbf{e}_1$ 到 $\mathbf{e}_N$ 这组基的构造方式满足某些数学特性，那么从 $\mathbf{x}_{M-1}$（前 $M-1$ 个向量张成的子空间上的解）更新到 $\mathbf{x}_M$（$M$ 维子空间上的解）的代价其实很低。每一步的代价都低，这个迭代就能进行下去。

同时，子空间迭代保证：最多只需要 $N$ 步，就一定达到最终的解。为什么？因为第 $N$ 步时，我们求的解是 $\mathbf{e}_1$ 到 $\mathbf{e}_N$ 这 $N$ 个向量张成的 $N$ 维子空间上的残差最小化解，而这个子空间就是原来的整个空间 $\mathbb{R}^N$——已经是全空间上的最优了。

> **结论**：子空间迭代最多 $N$ 步保证拿到最终解。相比之下，雅可比和高斯–赛德尔可能要迭代很多很多步——一个 $3 \times 3$ 的小矩阵，不动点迭代都可能要十几步；而子空间迭代最多三步，就保证把解求出来。

### Krylov 子空间：这组基怎么构造

最常用、也最成功的子空间迭代方法，是基于 Krylov 子空间的方法。Krylov（克雷洛夫）应该是前苏联或者俄罗斯的数学家，由他提出的这个子空间具体长这样：

$$\mathcal{K}_R = \operatorname{span}\{\mathbf{b},\ A\mathbf{b},\ A^2\mathbf{b},\ \dots,\ A^{R-1}\mathbf{b}\}$$

数学含义是：整个子空间由 $\mathbf{b}$、$A\mathbf{b}$、一直到 $A^{R-1}\mathbf{b}$ 这 $R$ 个向量张成，所以是一个 $R$ 维子空间。这 $R$ 个向量之间不一定是正交的——可以把它们作为基，但这是一组不正交的基。

并且它满足一个嵌套关系：

$$\mathcal{K}_1 \subset \mathcal{K}_2 \subset \mathcal{K}_3 \subset \cdots \subset \mathcal{K}_N = \mathbb{R}^N$$

这很显然：$\mathcal{K}_2$ 相比 $\mathcal{K}_1$ 只是多了 $A\mathbf{b}$ 这一个基向量，$\mathcal{K}_3$ 相比 $\mathcal{K}_2$ 只多了一个 $A^2\mathbf{b}$，就这样一层层嵌套下去。到 $\mathcal{K}_N$——也就是 $\mathbf{b}, A\mathbf{b}, \dots, A^{N-1}\mathbf{b}$ 这 $N$ 个向量张成的空间——就是全空间 $\mathbb{R}^N$。之后的 $\mathcal{K}_{N+1}$、$\mathcal{K}_{N+2}$，虽然向量个数变多了，但空间的维度不再增加，因为这 $N+1$、$N+2$ 个向量之间已经存在线性关系了。

用 Krylov 子空间做子空间迭代，就是说在第 $M$ 步，我们在 $\mathcal{K}_M$ 中寻找让残差最优的 $\mathbf{x}_M$。这就是 Krylov 子空间迭代方法最基本的描述。

下面看一个具体的例子，也是最常用的 Krylov 子空间迭代方法：共轭梯度法（Conjugate Gradient method，CG）。它所解决的问题是：对于对称正定矩阵 $A$，求解 $A\mathbf{x} = \mathbf{b}$。

### 共轭梯度法（CG）

#### 把解方程变成最小化一个二次型

对 CG 来说，第一步是把 $A\mathbf{x} = \mathbf{b}$ 这个矩阵方程转化成一个优化问题：

$$f(\mathbf{x}) = \frac{1}{2}\,\mathbf{x}^\top A\,\mathbf{x} - \mathbf{b}^\top \mathbf{x}$$

这个形式取到最小值的时候，对应的就是它的梯度等于零。梯度是什么？把这个形式对 $\mathbf{x}$ 求导，结果就是 $A\mathbf{x} - \mathbf{b}$——刚好是负的残差。所以这个形式取到最小，就是残差等于零，也就是 $A\mathbf{x} = \mathbf{b}$。并且由于 $A$ 对称正定，可以保证整个 $f(\mathbf{x})$ 是一个正的二次型，有唯一的最小值。因此，解决这个最小化问题就等价于解 $A\mathbf{x} = \mathbf{b}$。

#### 子空间内取到最优的条件：残差垂直于子空间

刚才说，子空间迭代在第 $M$ 步要让 $\mathbf{x}_M$ 在 $\mathcal{K}_M$ 中把 $f(\mathbf{x})$ 最小化。那这个最小化什么时候取到呢？这就是个几何知识了：当梯度——也就是 $-\mathbf{r}_M$——正交于当前子空间时，就能保证这个解在 $\mathcal{K}_M$ 中最小化了 $f(\mathbf{x})$。

为什么？要继续减小 $f$，我一定是沿着负梯度 $-\mathbf{r}_M$ 这个方向移动，才能让它更小；而现在 $-\mathbf{r}_M$ 跟当前子空间是垂直的，所以在子空间里无论怎么移动，都没有办法让残差进一步变小——已经降到底了。

所以，在每一步迭代中，我们都需要让 $\mathbf{r}_M$ 和当前的子空间 $\mathcal{K}_M$ 正交。只要满足了这个条件，就能知道 $\mathbf{x}_M$ 是在 $\mathcal{K}_M$ 中最小化了 $f(\mathbf{x})$，整个子空间迭代算法就成立了。

#### 共轭方向：把每一步压成一维优化

CG 的核心思想是：如果我们能构造出 Krylov 子空间的一系列共轭的基 $\mathbf{p}_1, \dots, \mathbf{p}_M$——它们张成的空间就是 $\mathcal{K}_M$，并且两两之间满足共轭关系

$$\mathbf{p}_i^\top A\,\mathbf{p}_j = 0, \quad i \neq j$$

那么在迭代的每一步，已知 $\mathbf{x}_{M-1}$ 求 $\mathbf{x}_M$ 的过程，就是在 $\mathbf{p}_M$ 方向上最小化 $f$ 的过程，写成数学形式就是

$$\mathbf{x}_M = \mathbf{x}_{M-1} + \alpha_M\,\mathbf{p}_M$$

其中 $\alpha_M$ 是一个标量，$\mathbf{p}_M$ 是已知的向量方向。要求一个标量 $\alpha_M$ 使 $f$ 最小——这是一个一维的优化问题，非常好解。

这就是共轭梯度下降算法的核心。大家先不用去想 $\mathbf{p}_1$ 到 $\mathbf{p}_M$ 到底是怎么来的、为什么 $\mathbf{x}_{M-1}$ 和 $\mathbf{x}_M$ 之间是这样一个关系，先记住这个结论：只要有了这一系列共轭基，每一步迭代只需要解一个一维的优化问题，就可以从 $\mathbf{x}_{M-1}$ 更新到 $\mathbf{x}_M$。

#### 归纳证明：每一步的残差都垂直于当前子空间

下一个问题是：为什么这样的算法就能保证我们要的性质——$\mathbf{x}_M$ 对应的梯度 $\mathbf{r}_M$ 正交于 $\mathcal{K}_M$？用归纳法来证。

最开始，我们在由 $\mathbf{p}_1$ 构成的一维子空间上直接解这个优化问题——一维的，可以直接解。解完之后能保证 $\mathbf{r}_1$ 垂直于 $\mathcal{K}_1$：就是在这个一维问题上解到了最优，残差（也就是梯度）自然垂直于当前子空间。

然后假设在第 $M-1$ 步保证了 $\mathbf{r}_{M-1}$ 和 $\mathcal{K}_{M-1}$ 垂直，来看 $\mathbf{r}_M$ 和 $\mathcal{K}_M$ 的关系。先把 $\mathbf{r}_M$ 写出来，把更新关系代进去展开：

$$\mathbf{r}_M = \mathbf{b} - A\mathbf{x}_M = \mathbf{b} - A(\mathbf{x}_{M-1} + \alpha_M \mathbf{p}_M) = \mathbf{r}_{M-1} - \alpha_M A\,\mathbf{p}_M$$

（其中 $\mathbf{b} - A\mathbf{x}_{M-1}$ 这一项就是 $\mathbf{r}_{M-1}$。）要证 $\mathbf{r}_M \perp \mathcal{K}_M$，靠两个结论：

第一，这步是在 $\mathbf{p}_M$ 方向上做了搜索，并且在这一维上最小化了 $f$、满足了最小化条件。那么一定有 $\mathbf{r}_M \perp \mathbf{p}_M$——$\mathbf{p}_M$ 是额外增加的那一维方向，在这个方向上取到了最小，剩下的残差一定跟这个方向垂直。

第二，由共轭关系，对所有的 $i < M$ 有 $\mathbf{p}_i^\top A\,\mathbf{p}_M = 0$。注意这里中间隔着一个 $A$ 矩阵，所以正确的读法是：$A\mathbf{p}_M$ 与每一个 $\mathbf{p}_i$ 都正交，也就是

$$A\,\mathbf{p}_M \perp \mathcal{K}_{M-1}$$

> **易错点**：共轭关系 $\mathbf{p}_i^\top A\,\mathbf{p}_j = 0$ 里隔着一个 $A$，它说的是"$A\mathbf{p}_j$ 与 $\mathbf{p}_i$ 正交"，而不是"$\mathbf{p}_i$ 与 $\mathbf{p}_j$ 正交"。推导 $A\mathbf{p}_M \perp \mathcal{K}_{M-1}$ 用的正是这一点——把中间的 $A$ 丢了就会推错。

于是看 $\mathbf{r}_M = \mathbf{r}_{M-1} - \alpha_M A\mathbf{p}_M$：$\mathbf{r}_{M-1} \perp \mathcal{K}_{M-1}$ 是归纳假设，$A\mathbf{p}_M \perp \mathcal{K}_{M-1}$ 刚由共轭关系得到，两项都垂直于 $\mathcal{K}_{M-1}$，所以 $\mathbf{r}_M$ 自然和 $\mathcal{K}_{M-1}$ 垂直。再加上第一个结论 $\mathbf{r}_M \perp \mathbf{p}_M$，而 $\mathcal{K}_M$ 就是由 $\mathcal{K}_{M-1}$ 和 $\mathbf{p}_M$ 组成的，所以 $\mathbf{r}_M \perp \mathcal{K}_M$。归纳完成。

换言之，只要能构造出一系列共轭基 $\mathbf{p}_1$ 到 $\mathbf{p}_N$，CG 算法就能进行下去：每一步都保证了梯度 $\mathbf{r}_M$ 与当前子空间垂直，也就是每一步都在当前子空间取到了最优；并且每一步更新只需要考虑 $\mathbf{p}_M$ 方向上的一个一维优化问题。这就是共轭梯度算法的基本想法。当然，这里还没有涉及如何去构造 $\mathbf{p}$——今天不展开，直接把算法的具体形式告诉大家。

#### 算法本体：写出来非常短

这样的算法写出来会非常简单。前面一部分求 $\alpha_k$ 的过程，描述的就是刚才说的"在 $\mathbf{p}_k$ 方向上解一维优化问题"：

$$\mathbf{x}_k = \mathbf{x}_{k-1} + \alpha_k\,\mathbf{p}_k$$

$\alpha_k$ 是需要优化的量，由这个一维优化的极值条件直接算出。拿到 $\alpha_k$ 之后，下一步就去构造 $\mathbf{p}_{k+1}$，作为下一个搜索方向——这个方向要跟前面所有的 $\mathbf{p}_1$ 到 $\mathbf{p}_k$ 相互共轭。怎么构造？写出来也非常简单：算一个 $\beta_k$，然后

$$\mathbf{p}_{k+1} = \mathbf{r}_{k+1} + \beta_k\,\mathbf{p}_k$$

也是一步更新的东西。$\beta_k$ 怎么算，涉及 Krylov 子空间的一些独特性质，今天就不展开讲了。

```text
共轭梯度法（CG）每一轮迭代只做两件事：
  ① 一维优化：xk = xk-1 + αk·pk      （αk 让 f 沿 pk 方向取到最小）
  ② 方向更新：pk+1 = rk+1 + βk·pk    （βk 让 pk+1 与 p1…pk 全部 A-共轭）
```

总体来说，共轭梯度算法还是一个写起来非常简单的东西，并且效率非常高。至于 $\alpha_k$、$\beta_k$ 具体是怎么算的，属于更细节的数学推导，有兴趣可以去了解一下；没兴趣的话，会用就可以了。很多时候大家只需要用就行——大概的思想就是刚才说的子空间迭代的思想，这部分稍微了解一下即可。

#### 收敛上界：条件数说了算

共轭梯度算法是一个非常快的收敛算法：它能保证 $N$ 步之内收敛到最终解。而且一般来说，我们不需要真的让它迭代 $N$ 步——远小于 $N$ 的步数，误差基本就能收敛到阈值以下。对常见的几万维矩阵来说，几千步就可以让 CG 收敛得差不多了。

并且 CG 有一个收敛速度的上界：

$$\frac{\|\mathbf{x}_k - \mathbf{x}^*\|}{\|\mathbf{x}_0 - \mathbf{x}^*\|} \le \left(\frac{\sqrt{\kappa}-1}{\sqrt{\kappa}+1}\right)^k$$

其中 $\mathbf{x}^*$ 是真实解，$\mathbf{x}_k$ 是迭代到第 $k$ 步的解，左边就是第 $k$ 步的误差与初始误差之比；指数上的底数是一个常数，其中的 $\kappa$ 是矩阵的条件数，定义为 $A$ 的最大特征值与最小特征值的模长之比，一定有 $\kappa \ge 1$。

这个形式说明什么？如果 $A$ 的条件数非常大——比如上千——底数就会非常接近 $1$，相当于每步误差只乘一个 $0.99$，收敛就会很慢。反过来，条件数越接近 $1$，底数就越小、越接近零，整个收敛就越快——相当于每步都乘 $0.1$、$0.001$、$0.0001$ 这样往下降。

> **结论**：CG 的收敛速度主要取决于矩阵的条件数。我们希望条件数尽可能接近 $1$，这样 CG 收敛得非常快。

#### 预处理：把条件数压下来

为了让 CG 的条件数变小，有一种方法叫预处理（preconditioning）。

思路是：尽可能去找 $A^{-1}$ 的一个近似矩阵，写成 $M = P^\top P$，然后转而求解等价变换后的矩阵方程 $PAP^\top \mathbf{y} = P\mathbf{b}$（解出 $\mathbf{y}$ 后，$\mathbf{x} = P^\top \mathbf{y}$）——它跟 $A\mathbf{x} = \mathbf{b}$ 显然等价，而 $PAP^\top$ 这个矩阵的条件数一定比原来单独的 $A$ 要小。为什么？极端情况下，如果 $M$ 就是 $A^{-1}$，那么变换后矩阵的条件数就应该是 $1$。所以只要能找到 $A^{-1}$ 的近似 $M$，转而去解变换后的方程，CG 收敛就会非常快。

那 $M$ 怎么选呢？思路跟不动点迭代里选 $M$ 有些类似：

- 把 $M$ 选成 $A$ 的对角矩阵——对应的 CG 就叫雅可比预条件 CG（对角预条件 CG，DPCG）；
- 用 LLT 分解（也就是 Cholesky 分解）的简化形式——不完全 Cholesky 分解——对应的 CG 就叫不完全 Cholesky 预条件 CG（ICPCG，incomplete Cholesky preconditioned CG）。

ICPCG 的收敛速度比不做预处理快非常多。预处理是一个非常强大的技术，ICPCG 也是求解对称正定矩阵方程时非常常用的求解器：一旦你的方程是对称正定的，可以试一试 ICPCG，它的收敛速度一般很快——对一个几万维的矩阵，甚至只需要几十步，就能收敛到不错的程度。

#### 对称不保证正定、一般矩阵怎么办

CG 只适用于对称正定的矩阵方程。而 Krylov 子空间方法本身还有其他形式，适用于更宽泛的情况，常用的有：

- 求解的是对称、但不一定正定的矩阵：可以考虑 MINRES（minimal residual method）求解器；
- 求解的是更一般的、甚至都不对称的矩阵：也有对应的 Krylov 子空间求解器，比如 GMRES、BiCG、BiCGSTAB，它们都能求解一般的非对称矩阵方程。

只不过，如果拿 GMRES 或者 MINRES 去解对称正定的方程，速度会比 CG 慢一些。所以为了速度，先看一看你的矩阵到底是什么样的矩阵：对称正定，CG 就是最优的；只是对称，MINRES 最合适；一般情况，再考虑 GMRES、BiCGSTAB 之类的求解器。

### 三类求解器，怎么选

最后总结一下今天介绍的这三类求解器。

如果矩阵规模比较小——比如小于一千维——通常直接求解是最快的方法，比如 LU 分解；LLT 分解则只适用于矩阵对称正定的情况。矩阵规模大了之后，直接求解受复杂度限制会非常慢，这时迭代求解器就更有优势。

迭代求解器分两类。第一类是不动点迭代，比如雅可比迭代和高斯–赛德尔迭代：实现非常简单，但收敛速度不一定快，一般来说需要调节松弛系数，去平衡不动点迭代的稳定性和收敛速度；它还可以被改进为多重网格方法——今天没有展开，但要知道多重网格的速度非常快。第二类是 Krylov 子空间方法：收敛速度一般很快，而且要对不同的矩阵使用相对应的方法——对称正定用 CG，对称矩阵用 MINRES，一般矩阵用 GMRES、BiCG 之类的算法；并且如果能对矩阵做预处理，还能大大提高这些 Krylov 子空间迭代方法的收敛速度，比如前面介绍的 DPCG、ICPCG。

| 矩阵情况 | 该用什么 |
| :--- | :--- |
| 规模小（一千维以内） | 直接法：LU；对称正定用 LLT（Cholesky） |
| 规模大、图省事 | 不动点迭代：Jacobi / 高斯–赛德尔，调松弛系数，可升级为多重网格 |
| 对称正定 | CG（配预处理更快：DPCG、ICPCG） |
| 对称，不保证正定 | MINRES |
| 一般（非对称） | GMRES、BiCG、BiCGSTAB |

可以看到，解决 $A\mathbf{x} = \mathbf{b}$ 这个问题，其实没有一个通用的、最优的 solver，更多时候还是得根据自己的实际情况，去选择合适的求解器。今天提到的这些求解器，在 NumPy、SciPy、MATLAB 这些库里都有内置的实现，函数名一般也非常直观：LU 一般就直接叫 `lu`，LLT 可能叫 `cholesky`，CG、MINRES 一般就直接叫 `cg`、`minres`。以后用这些软件的时候，结合自己矩阵的特性，去选最合理、最快的方案就行。

## 优化基础：从梯度下降到 BFGS
> 对应块：BLK27 | 覆盖分集：P15上 | 块标题（分集名）：《优化基础》

优化本身是一个涵盖内容非常多、同时也非常难的大学科。这一讲只有一个多小时，注定没办法介绍得特别详细、特别具体。所以我的计划是：尽可能用一些比较简单的例子，把优化里面比较重要的一些概念引出来；至于之后更高级的优化算法，大家可以顺着这些教材自己去深入学习。今天这一篇，就是一个相对来说非常非常入门的介绍，肯定也不可能面面俱到——我们还是以一些比较简单的例子作为切入点，看看优化里面会有哪些大家经常用到的概念、算法之类的东西。

### 一个优化问题长什么样

一个优化问题，一般来说可以写成下面这个比较通用的样子：

$$\min_{x}\ f(x)\qquad \text{s.t.}\ \ C(x)$$

其中 $x$ 是我们待优化的变量，可以是连续的，也可以是离散的；$f(x)$ 是优化目标，同样可以是离散的、连续的，可以是可导的或者不可导的，各种各样的都可以。除了目标之外，$x$ 还要满足一定的约束条件，用 $C$ 来表示。$C$ 里面就可以包含各种各样的东西：有等式的约束，有不等式的约束，也可以是一个子空间或者某个取值范围。

面对这么一个通用形式，怎么去设计算法优化这样一个问题？这要根据问题的具体形式去决定。所以我们先来看最简单的情况：无约束优化问题——没有约束，然后再做一些额外的假设，比如假设 $f(x)$ 是一个连续可微的函数，$x$ 是一个连续的 $n$ 维向量。这也是我们平常在很多时候最能接触到的优化问题。接下来梯度下降、牛顿法、BFGS 这一整条线，都搭在这个最简单的问题上。

### 三个例子：最小二乘、贴图与弹性体

先看三个例子。它们来自三个不同的领域，最后却都落到同一件事上：最小化 $f(x)$。

#### 最小二乘拟合

第一个例子是之前介绍过的最小二乘法。给定数据集里的 $N$ 个点 $(x_0,y_0)$、$(x_1,y_1)$，一直到 $(x_{N-1},y_{N-1})$，我们希望拟合出一个曲线或者直线来近似整个数据集。假设 $y$ 和 $x$ 之间满足这样一个函数关系：

$$f(x)=\sum_{j=0}^{K-1} a_j\, g_j(x)$$

其中 $g_0$ 到 $g_{K-1}$ 是我们给定的基本函数，可以是常数项、线性项、二次项 $x^2$、三次项，或者 $x$ 乘 $y$ 这样的交叉项；$a_0$ 到 $a_{K-1}$ 就是它们的组合系数。那我们要优化的就是这组系数 $a$：把系数带进去、把各个 $x$ 带进去，得到的函数值和数据集里的 $y$ 之间的差距要尽可能小，也就是最小化所有点上误差的平方和。大家最熟悉的，就是用一次函数做拟合的那个最小二乘。

这个优化目标可以写成更紧凑的形式：把所有这些基本函数在 $x_0$ 到 $x_{N-1}$ 处的函数值排成一个大矩阵 $G$，同时把 $y$ 排列在一起，那个对 $i$ 求和的目标就可以写成矩阵乘法的形式：

$$\min_{a}\ \big\lVert y - G\,a \big\rVert^2$$

它还可以进一步展开：

$$\big\lVert y - G\,a \big\rVert^2 \;=\; a^\top G^\top G\, a \;-\; 2\, y^\top G\, a \;+\; y^\top y$$

注意看：这是一个针对参数 $a$ 的、关于 $a$ 二次的优化目标——$a$ 是一个向量，中间那个矩阵就是 $G^\top G$。

#### 网格参数化：给曲面贴图

第二个例子来自几何，是曲面参数化问题。比如我们有一个用 mesh 表示的球，要为球上的每个顶点定义一个二维纹理坐标，也就是 UV 坐标。UV 坐标是什么？可以拿地图来理解：地图是一个二维的东西，有 $x$、$y$ 坐标，对应的就是这里的 $U$ 和 $V$。只要球上每一个点都有一个 UV 坐标，我就可以对应地把地图贴到球上来——那它就是一个地球。所以，UV 坐标定义了三维曲面到二维贴图的一个映射关系。

那么问题是：假设我有一个任意的三维 mesh，比如一张人脸，要怎么确定它里面每个顶点上的 UV 坐标，使得贴图贴到人脸上之后，它的 distortion（拉伸形变）是最小的？相当于我现在有一张"脸皮"，要给它绷到这个人脸的模型上，我希望定义出的 UV 坐标能尽可能让这张脸皮的拉伸形变最小——这样贴图贴上去才尽可能均匀，不会出现一些比较错误的 artifact。

最简单的做法称之为弹簧模型。它怎么定义呢？假设每个顶点上都有一个 UV 坐标 $(u_i, v_i)$，然后去看 mesh 上的每条边：希望每条边对应的两个顶点，它们之间 UV 坐标的差值尽可能小。遍历整个 mesh 的所有边，每条边上算一个两端顶点 UV 坐标差的平方，把所有这些差值加起来，希望这个总和尽可能小：

$$\min_{\{(u_i,v_i)\}}\ \sum_{(i,j)\in\mathcal{E}} \big\lVert (u_i, v_i) - (u_j, v_j) \big\rVert^2$$

通过这种方法求出来的 UV，可以近似认为它会尽可能均匀地分布到整个 mesh 上。这同样对应一个无约束的优化问题。

#### 隐式欧拉与弹性体模拟

第三个例子来自物理模拟：弹性体的模拟。如果我们使用隐式欧拉法进行时间积分，那么在每个时间步内，弹性体模拟等价于优化下面这样一个增量能量：

$$\min_{x}\ E_{\text{inertia}}(x) + E_{\text{elastic}}(x)$$

这个增量能量有两项：第一项叫 inertia 项，也就是惯性项；第二项 $E_{\text{elastic}}$ 是整个弹性体的总弹性势能。可以证明：只要你优化这样一个增量能量，求出来的最小值点 $x$，就是下一个时间步整个弹性体的位置。大家在 GAMES103、GAMES201 这样的物理模拟课里面，可能会见到这样一个优化问题的形式。

上面列举的这几个例子，最后要解决的都是同一件事：最小化 $f(x)$。

### 线搜索：每一步只定两件事

对这样的优化问题应该怎么求解？大家应该或多或少都有一些了解。最简单的就是梯度下降法：想象下山，每次沿着梯度的方向往前走一段距离，一直这样走，理想情况下就可能跑到最优点上。这一类优化方法有一个通用的名字，叫线搜索方法。它写出来是一个非常简单的形式：

$$x_{k+1} = x_k + \alpha_k\, p_k$$

其中 $p_k$ 表示下降方向，$\alpha_k$ 表示下降步长。也就是说，每一步迭代我需要确定两个量：你沿哪个方向走、走多远的距离。一直这样迭代下去，希望最终能够收敛到全局最优点上。

这一类方法里大家最熟悉、应用也最广泛的就是梯度下降法。它直接把每一步的搜索方向选成函数的负梯度：

$$p_k = -
abla f(x_k)$$

这同时也是函数下降最快的方向。

那么在这个方向上要走多远呢？可以把它变成一个一维的优化问题：固定 $p_k$，唯一不知道的就是 $\alpha_k$，然后在这个方向上进行搜索，确定一个 $\alpha_k$ 让函数值最小。这是一个很合理的策略。但直接去解这样一个一维优化问题，同样也是不容易的——可能还要在这个一维问题上再套一个子迭代去优化 $\alpha_k$，时间就比较长了。

### Armijo 条件：不求最优，只求够降

实际中，我们用一个近似的条件去代替"最小化 $\alpha_k$"这个优化任务，这就是非常常见的 Armijo 条件。它写成什么样子呢？其实不需要 $\alpha_k$ 让函数值取到最小，而是只需要找到一个 $\alpha_k$，满足下面这样一个不等式就可以：

$$f(x_k + \alpha_k\, p_k)\ \le\ f(x_k) + c_1\,\alpha_k\,
abla f(x_k)^\top p_k$$

就是说：沿 $p_k$ 走了 $\alpha_k$ 这么长到达的位置，它对应的函数值，要小于等于原来出发点的函数值再加上后面那一小坨东西。其中 $c_1$ 是一个我们可以给定的常数，取在 $0$ 到 $1$ 之间；对一般的问题可以把它取到非常小，比如 $10^{-4}$，取 $0.1$、$0.5$ 这些也都有，要根据具体问题来确定。

这个 Armijo 条件具体对应一个什么东西？用切线的视角非常好理解。看后面那一项 $c_1\alpha_k
abla f(x_k)^\top p_k$：如果 $c_1 = 1$，那么 $\alpha_k p_k$ 点乘上 $f$ 的梯度——也就是把 $f(x)$ 在 $x_k$ 处做局部线性展开，可以找到它的一条切线，这条切线就是一个一次函数：$f(x_k) + \alpha_k\,
abla f(x_k)^\top p_k$。如果 $c_1 < 1$，那就是改变了这条切线的斜率，把它的斜率变小了一点。Armijo 条件要求：走到的那个点的函数值，要低于这条减小了斜率的切线——直观地说，就是 $f(x)$ 在中间这一段的取值要落在这条弱化切线的下面。

换句话说，$\alpha_k$ 不能取得过大：比如 $\alpha_k$ 取到某个太远的位置，那个点就跑到弱化切线上面去了，下降得就不够多；一个合理的 $\alpha_k$ 只能落在中间的某一段里，保证函数下降得比这条弱化的切线还要快。只要满足了这个条件，就能保证 $f$ 以某个速率往下降，最终这个算法就能保证收敛。

那么这个条件要如何达到？一般来说最简单的做法：从 $\alpha_k$ 等于一个比较大的初始值开始，比如从 $1$ 开始。走一步，发现函数值比弱化的切线还要高？那就说明 $\alpha$ 太大了、跑得太远了，应该减小——直接把 $\alpha$ 乘以某一个值，比如乘以 $1/2$ 取一半。取半之后发现这个点正好落到了弱化切线的下面，那这个时候这个 $\alpha$ 就是可以接受的，直接停止。如果乘了 $1/2$ 之后条件依然不满足，就接着往下减——一直减到 $\alpha$ 趋向于零，条件一定是能满足的：只要离出发点足够近，函数在这个点局部就近似是一条切线，上述条件必然能满足。

所以 Armijo 条件只要 $\alpha$ 取得足够小，一定是能达到的。但 $\alpha$ 取太小的话，每次只跑一个非常短的距离，收敛就很慢了。所以我们应该从一个尽可能大的初始值开始（比如 $\alpha = 1$），逐步减小 $\alpha$，直到它第一次让 Armijo 条件满足的时候就停下来，走对应的这个步长。

把这套东西写成算法，就是最简单的梯度下降法：每一步先确定下降方向——函数的负梯度；然后通过线搜索，让步长满足我们给定的 Armijo 条件，来保证整个函数值是下降的；再让 $x$ 沿这个方向走这么远，就可以进行到下一步了。

那么梯度下降法是不是一个好的算法呢？它确实是一个好方法。但是可以注意到：梯度下降法只利用了优化目标 $f(x)$ 的一阶信息，也就是它的梯度信息。

### 牛顿法：把曲率信息用起来

有没有可能使用函数局部的二阶信息——也就是曲率信息——来获得更快的收敛速度？对应的方法就是牛顿法。

牛顿法与梯度下降法最大的区别在于：迭代到 $x_k$ 这个位置时，要在 $x_k$ 的附近给函数做二阶展开。展开出来有两项：第一项跟刚才一样是梯度项，后面多了一个二次项：

$$f(x_k + p)\ \approx\ f(x_k) + 
abla f(x_k)^\top p + \frac{1}{2}\, p^\top 
abla^2 f(x_k)\, p$$

其中 $
abla^2 f(x_k)$ 就是 $f$ 的二阶导数。我们希望选择的下降方向 $p$，能够最小化函数在 $x_k$ 附近这个二阶展开的形式，把它作为优化方向，而不是直接使用它的梯度方向。那这个展开式的最小值应该在什么时候取到？直接对它求一次导、让它的梯度等于零，自然就可以得到最小点出在什么位置：

$$
abla f(x_k) + 
abla^2 f(x_k)\, p = 0\qquad\Longrightarrow\qquad p_k = -\big(
abla^2 f(x_k)\big)^{-1}\, 
abla f(x_k)$$

这个方向不再是像梯度下降里面那样直接等于函数本身的负梯度，而是在负梯度前面乘了二阶导的逆这样一个矩阵。

这个二阶导是一个矩阵——这一点大家应该能看出来：对 $f$ 求一阶导，得到的是一个 $n$ 维向量；再求一次导，向量里的每一个值都要再求一次二阶导，一次出来就是一个 $n\times n$ 的矩阵。这个矩阵有一个名字，叫海森矩阵（Hessian）。也就是说，对牛顿法而言，下降方向是在负梯度前面乘以一个海森矩阵的逆来得到的。

> **定义**：海森矩阵 $
abla^2 f(x)$ 是梯度再求一次导得到的 $n\times n$ 矩阵；牛顿法的下降方向是 $p_k=-\big(
abla^2 f(x_k)\big)^{-1}
abla f(x_k)$。

#### 海森矩阵不正定，函数值可能不降反升

如果这个海森矩阵不是一个正定的矩阵，可能会发生什么？我们从 $x_k$ 这个起点出发沿 $p_k$ 走，去观察 $f$ 的函数值变化了多少。用一阶近似，变化量应该是它本身的梯度点乘上走的距离；把 $p_k$ 这个等式带进去，就会发现变化量等于后面这一坨东西：

$$
abla f(x_k)^\top p_k \;=\; -\,
abla f(x_k)^\top\, \big(
abla^2 f(x_k)\big)^{-1}\, 
abla f(x_k)$$

后面这坨东西是什么？可以看到，它是负的"某个向量，乘以海森矩阵的逆，再乘以这个向量"——一个二次型的形式。那么如果中间的海森矩阵不正定，万一梯度方向非常的不幸，正好对应海森矩阵某一个负特征值的特征向量，整个后面这坨东西就有可能出现一个正的值。这个时候意味着：沿 $p_k$ 的方向走，函数值不一定是下降的，有可能是上升的。这是一个很反直觉、也非常坏的结果——我希望它往下跑，结果跑着跑着函数值还往上升了，最后可能就解炸了。

对比一下梯度下降法：它前面没有乘海森矩阵——或者说你可以认为前面乘的是一个单位阵，单位阵一定是正定的，所以往前走一步，函数值大概率一定是下降的。牛顿迭代前面乘了一个矩阵的逆，这个矩阵不正定的话，函数值就有可能上升。

所以说，使用牛顿迭代的时候，$p_k$ 不能简单地照上面那样写，我们要检查一下海森矩阵。如果发现它不正定，可以用一些额外的处理：海森矩阵的具体形式一般你是知道的，可以把它投影回一个正定的矩阵，这种方法就称为投影牛顿法；或者在这种时候就退回梯度下降法，让它直接沿着梯度往下走。

另外，确定了下降方向之后，还要像刚才一样进行线搜索：走的步长 $\alpha_k$ 依然要满足 Armijo 条件，来保证整个算法是下降的。

#### 快，但每一步更贵

牛顿迭代跟梯度下降最大的不同，就是计算下降方向时前面要乘一个海森矩阵的逆——也就是要解一个矩阵方程。花了这么多额外的时间，理论上我们应该期待它有更好的收敛效率，对不对？是不是这样呢？可以想象：牛顿迭代使用了函数局部的二阶信息，用的信息更多了，所以它的下降应该是更快的。

比如给一个例子：一个二维的优化问题，$f(x)$ 的 landscape 长成某个样子，我要从一个点优化到另一个点。这个时候分别使用牛顿迭代和梯度下降：牛顿迭代往往只需要非常少的几步——两三步——一般就可以达到一个很好的收敛效果。梯度下降则有一个很明显的问题：它可能出现震荡。虽然沿着梯度方向往前走、步长满足 Armijo 条件、函数值确实在下降，但我依然可能跑过了——因为我局部只有它的梯度信息，不知道应该走多远；跑过了之后再跑回来，只有这样慢慢地震荡之后，它才会收敛。牛顿法就不会有这个问题：我已经近似知道函数局部的二阶信息是什么，就可以更有目的性地去控制步长，保证不会出现这种震荡的情况。总的来说，牛顿的下降要比梯度下降快很多——这合理，因为我利用了除一阶信息之外的二阶信息。

但与之相应的就是：牛顿下降每一步都需要解一个矩阵方程来得到下降方向，每一步的开销变大了。这个时候，如果这个矩阵方程实现得不好，最后的收敛效率反而可能比梯度下降慢很多。这就是牛顿下降的问题。

### 拟牛顿法：给海森矩阵找个便宜替身

解决这个问题的方法，叫拟牛顿法。它与牛顿法最大的区别是什么？就是其实不需要严格地去解海森矩阵的那个矩阵方程来得到下降方向，而是可以近似地找到一个更简单的矩阵 $B_k$，去近似整个系统的海森矩阵，然后用 $B_k$ 代替海森矩阵得到下降方向：

$$p_k = -B_k^{-1}\,
abla f(x_k)$$

再像牛顿法一样迭代收敛。这么做的逻辑很顺：如果 $B_k$ 选得好，首先它近似于海森矩阵，那么收敛效率应该近似于牛顿法；同时 $B_k$ 又比海森矩阵更容易计算，每个迭代步里解它的方程就会比牛顿法快一些。所以我们期待：拟牛顿法最终的实现效率，应该要比牛顿法更快。就这么一个简单的思想。

比如，我们可以把梯度下降也看成一种拟牛顿法：它使用的近似海森矩阵就是单位矩阵——直接把一个单位矩阵的逆乘在梯度前面，相当于直接把负梯度作为下降方向。由于单位矩阵虽然计算很简单，但它离真正的海森矩阵比较远，所以可以期待梯度下降算法的收敛效率，要比真正的牛顿下降慢一些。

那对这个方法进行一个最直接的改进是什么？可以把海森矩阵的对角项拿出来，构造一个对角矩阵作为 $B_k$。这个时候，它的计算效率就更接近于梯度下降法——不需要再去解矩阵方程了——但收敛速度可以期待要比梯度下降法更快。这就是拟牛顿法的基本思想。

### BFGS：工业求解器的默认选项

接下来介绍拟牛顿法里几个比较经典的算法，重点要介绍的是 BFGS——到现在来说非常通用的一个方法。大家如果去使用各种各样的工业软件或者一些数值求解器，会发现它们会把 BFGS 或者 L-BFGS 作为默认的优化算法在使用。

BFGS 这个名字的来源是什么？它其实是四个老哥的名字——四位提出者的名字从左到右分别以 B、F、G、S 开头。他们四个人在上个世纪提出了这个算法，就把算法叫成了 BFGS。

#### 核心思想：每步维护一个近似矩阵

BFGS 是一种拟牛顿法。它在实现拟牛顿思想时的想法是：在每一步迭代的时候，额外去更新维护一个矩阵 $B_k$，用来近似整个系统真正的海森矩阵。在迭代最开始的时候，把 $B_0$ 初始化成一个单位矩阵——或者初始化成初始值位置上真正的海森矩阵——都可以。然后在每一次迭代的过程中，设计一种更新的方法，把 $B_k$ 加上一个增量 $\Delta B_k$，更新到 $B_{k+1}$，用 $B_{k+1}$ 作为下一步的海森矩阵近似，然后一直这么做下去。

那么自然有个问题：这个 $\Delta B_k$ 要具体怎么构造？

#### 割线条件：近似必须对得上梯度差

BFGS 算法在构造 $\Delta B_k$ 的时候，要求它满足一个关系：$B_{k+1}$ 应该是 $x_{k+1}$ 处海森矩阵的一个近似。那我们就可以把 $f(x)$ 在 $x_{k+1}$ 附近做二阶展开，就应该有下面这样一个关系成立：$x_{k+1}$ 处的梯度减去 $x_k$ 处的梯度，应该等于 $B_{k+1}$ 乘以（$x_{k+1}$ 减去 $x_k$）：

$$
abla f(x_{k+1}) - 
abla f(x_k) \;=\; B_{k+1}\,\big(x_{k+1} - x_k\big)$$

为什么？因为 $B_{k+1}$ 是我要近似的那个二阶导，二阶导乘以一个 $\Delta x$，理论上就应该对应的是梯度的差。所以我们就用这样一个简单的关系，来作为 $\Delta B_k$ 要满足的条件。

把这个关系简写一下：把 $x_{k+1}$ 处的梯度减去 $x_k$ 处的梯度记成 $y_k$，把 $x_{k+1}$ 减去 $x_k$ 记成 $s_k$。那么只要 $B_{k+1}$ 满足

$$y_k = B_{k+1}\, s_k$$

我就可以近似认为 $B_{k+1}$ 就是海森矩阵的一个近似，就可以把 $B_{k+1}$ 用到牛顿法中间的计算上去了。

> **定义**：割线条件 $y_k = B_{k+1} s_k$，其中 $s_k = x_{k+1}-x_k$ 是两步位置之差，$y_k = 
abla f(x_{k+1})-
abla f(x_k)$ 是两点梯度之差。

#### 秩二更新：反推出更新公式

具体要怎么得到 $\Delta B_k$？BFGS 进一步假设 $\Delta B_k$ 是一个秩为二的更新，它可以写成

$$\Delta B_k = a\, u u^\top + b\, v v^\top$$

其中 $u$、$v$ 是两个向量，$a$、$b$ 是两个常数。相当于假设 $\Delta B_k$ 满足这样一个形式，然后反求这些向量和标量，让 $\Delta B_k$ 代进去之后满足 $y_k = B_{k+1} s_k$ 这个条件。

把 $\Delta B_k$ 的具体形式带进去，挪一挪项，就可以得到下面这个关系：

$$a\,\big(u^\top s_k\big)\, u \;+\; b\,\big(v^\top s_k\big)\, v \;=\; y_k - B_k s_k$$

观察一下这个等式：右边 $y_k - B_k s_k$ 是我已知的东西；左边是待求的系数——$a(u^\top s_k)$ 其实是一个标量，乘上向量 $u$；$b(v^\top s_k)$ 也是一个标量，乘上向量 $v$。两个"标量乘向量"的结果相加，等于右边那个已知的向量。

那么一个最直接的取法就是：

$$a\,\big(u^\top s_k\big) = 1,\quad u = y_k; \qquad b\,\big(v^\top s_k\big) = -1,\quad v = B_k s_k$$

只要满足这几个式子，就可以保证 $B_{k+1} s_k = y_k$。由这几个式子，我们可以直接解出 $a$、$b$、$u$、$v$ 分别等于多少；再反代回 $\Delta B_k$，就得到 $\Delta B_k$ 的具体形式：

$$\Delta B_k \;=\; \frac{y_k\, y_k^\top}{y_k^\top s_k} \;-\; \frac{B_k s_k\, s_k^\top B_k}{s_k^\top B_k s_k}$$

于是

$$B_{k+1} \;=\; B_k \;+\; \frac{y_k\, y_k^\top}{y_k^\top s_k} \;-\; \frac{B_k s_k\, s_k^\top B_k}{s_k^\top B_k s_k}$$

这个形式就是 BFGS 算法最核心的形式：我如何去更新 $B_k$，使它始终保持是系统海森矩阵的一个近似。实际跑起来，每一步拿 $B_k$ 算完下降方向之后，还要把 $y_k$、$s_k$ 都算出来往里带，把 $B_k$ 更新到 $B_{k+1}$，再把它作为下一步的海森矩阵近似。

#### 逆矩阵有显式形式

$B_{k+1}$ 这个形式虽然看起来复杂，但它可以使用 SMW 公式写出显式的逆矩阵。原因是更新里后面的那两项虽然看起来复杂，其实都是秩为一的矩阵，利用这个定理就可以写出它逆矩阵的显式形式：

$$B_{k+1}^{-1} \;=\; \Big(I - \rho_k\, s_k y_k^\top\Big)\, B_k^{-1}\, \Big(I - \rho_k\, y_k s_k^\top\Big) \;+\; \rho_k\, s_k s_k^\top, \qquad \rho_k = \frac{1}{y_k^\top s_k}$$

也就是说，BFGS 算法里面近似的这个海森矩阵 $B$，它的逆矩阵是一个好求的东西——这一条在后面的整个流程里非常有用。

#### 正定性为什么能保住

在牛顿法里我们刚才说过：如果整个海森矩阵不是一个正定矩阵，那么算法是有可能不收敛的——只要矩阵不正定，这一步的下降方向就有可能导致函数值上升。BFGS 好就好在：按上面的形式一直更新下去，$B_k$、$B_{k+1}$ 这些矩阵一般来说都能保证是正定的。

怎么证明？把刚才这个形式做一个变换，变换成下面这个等价形式（两者是等价的，大家可以检查一下）：

$$B_{k+1}^{-1} \;=\; \Big(I - \rho_k\, y_k s_k^\top\Big)^{\top} B_k^{-1}\, \Big(I - \rho_k\, y_k s_k^\top\Big) \;+\; \rho_k\, s_k s_k^\top$$

改写成这个形式之后就会发现：前面一部分一定是一个正定矩阵——只要 $B_k^{-1}$ 是正定矩阵，这种"两边同乘再转置"的合同结构就保持正定；而后面一部分是一个秩一的项，只要常数 $s_k^\top y_k$ 是一个大于零的值，$\rho_k\, s_k s_k^\top$ 就是一个正的贡献。换句话说：只要我在迭代过程中能够保证 $s_k^\top y_k$ 一直都大于零，那么 BFGS 算法生成的这一系列近似海森矩阵就一定是正定的，就能保证 BFGS 算法一直是朝着目标减小的方向进行的。而 $B_0$ 初始化成单位阵时，$B_0^{-1}$ 就是单位阵，天然正定，这样归纳下去，整条链上的近似矩阵都是正定的。

那么 $s_k^\top y_k > 0$ 是不是永远成立？这不是算法本身保证的，而是由优化问题的具体形式来保证的。回去看一下 $s_k$ 和 $y_k$ 是什么：$s_k$ 是两个迭代点的差，$y_k$ 是这两个点处的梯度差。只要你的问题长得还比较好，$y_k^\top s_k$ 一般来说就是一个正的值，BFGS 就是能够收敛的；反之，如果这一点不能一直保证，那么 BFGS 算法也有可能不收敛——要具体情况具体分析。

> **提示**：$s_k^\top y_k$ 衡量的是沿 $s_k$ 这一步走过去，函数曲率的正负。它是否成立取决于问题本身，而 BFGS 的全部收敛保证都建立在它之上。

把 BFGS 的整体流程串起来：下降方向跟牛顿法一样，是需要解一个矩阵方程得出来的，只不过这个矩阵方程由近似的海森矩阵给出；这个近似海森矩阵通过 BFGS 的更新公式迭代维护，它的逆矩阵还是显式可以给出来的东西。所以总体来说，BFGS 算法的速度要比牛顿法相对来说快一些。

到这里，这一讲出现的几种方法可以放在一张表里对照着看：

| 方法 | 用到的信息 | 每一步的开销 | 收敛表现 |
|:---|:---|:---|:---|
| 梯度下降 | 一阶：负梯度 | 最便宜 | 可能震荡，收敛慢 |
| 牛顿法 | 二阶：海森矩阵的逆 | 要解矩阵方程，最贵 | 往往两三步就收敛，但不正定时可能"解炸" |
| 对角拟牛顿 | 海森的对角近似 | 不用解矩阵方程 | 期待比梯度下降快 |
| BFGS | 秩二更新维护的近似海森 | 解方程，但逆有显式形式 | 总体比牛顿法快，正定性有保证 |

### 内存瓶颈与 L-BFGS

BFGS 虽然已经比牛顿法更好了，但它还是有一个问题：我们需要一个 $N\times N$ 的空间，来储存这个稠密的矩阵 $B_k$（或者 $B_k^{-1}$）——要把这个矩阵存出来，然后还要不断地去更新它。当问题的规模比较大的时候，比如像之前介绍过的那种有几百万个节点的非常大的 mesh，$N\times N$ 就是一个很大很大的空间了。这个时候 BFGS 算法不管是计算上还是储存上，效率都会降下来。

为了解决这个问题，大家就想出了 BFGS 的另外一个改进，叫 L-BFGS。这个 L 表示的意思就是 limited——约束了内存的 BFGS 算法。

到这里，这一讲的主线就走完了：从"定方向、定步长"的线搜索框架出发，方向先取负梯度（梯度下降），再修正为海森矩阵的逆乘负梯度（牛顿法），最后落到用一个不断更新、更好算的矩阵去近似海森（拟牛顿法，代表是 BFGS）；步长则统一交给 Armijo 条件把关，保证每一步真的在下降。问题规模大到存不下稠密矩阵时，就轮到约束内存的 L-BFGS 登场了。

## 优化方法：从 L-BFGS 到带约束优化
> 对应块：BLK28 | 覆盖分集：P15下 | 块标题（分集名）：《优化基础》

### L-BFGS：只留最近 M 步的曲率

BFGS 有一个绕不开的负担：它从第 0 步开始，一直追踪海森矩阵（Hessian）近似的每一次更新——迭代走得越远，攒下的信息越多，最后摊成一个 $n \times n$ 的稠密矩阵。那具体怎么把这个负担卸下来呢？想法非常简单：**L-BFGS 只保留最近 $M$ 次迭代的更新 $\Delta B_k$**。

BFGS 的每一步更新本身就是一个秩二修正，$M$ 步攒起来，对应的就是一个秩为 $2M$ 的矩阵。要表示它，不必存下 $n \times n$ 个数，只需要存 $2M$ 个长度为 $n$ 的向量——也就是 $2M \times n$ 个变量。由于限制了"最近只保留 $M$ 次迭代"，整个计算和存储的开销就重新回到了 $O(n)$ 的线性水平：不再需要直接储存 $n \times n$ 的矩阵，只需要存这 $2M$ 个向量。

这其实和我们之前介绍过的用 SVD 压缩矩阵是同一个想法：SVD 说的是，取矩阵最大的前若干个奇异值和奇异向量，就可以表示这个矩阵的大部分信息；对 L-BFGS 而言，就是用最近 $M$ 次迭代更新攒出来的这个秩 $2M$ 的低秩矩阵，去近似真正的海森矩阵。用这种方法，计算和存储的开销就都降下来了。

当然，这样做要牺牲一些 BFGS 的收敛速度。但总体来说，问题规模越大，这笔交换越划算——省掉的是整个 $n \times n$ 的存储与计算。也正因为这样，**L-BFGS 是很多数值工业软件的默认优化算法**：它能够比较好地平衡"总共需要多少次迭代"和"每次迭代花多少开销"这一对矛盾。

> **提示**：$M$ 是 L-BFGS 的记忆长度——取得越大，低秩近似越接近完整的 BFGS，需要的存储也相应变多。

### 回望不动点迭代：它其实也是拟牛顿法

再回头补一笔前面留下的伏笔。我们介绍过用不动点迭代——Jacobi、Gauss-Seidel 这些——去求解矩阵方程。现在回过头看会发现：**解方程的不动点迭代，其实也是一种拟牛顿法**。

怎么看呢？假设 $A$ 正定，那么"求解 $Ax = b$"可以等价地写成下面这个最优化问题，这个最小化问题的解就是原方程的解：

$$\min_x \ \frac{1}{2}\,x^\top A x - b^\top x$$

看看它的梯度：等于 $Ax - b$；它的二阶导数，也就是海森矩阵，其实就是 $A$ 本身。而 Jacobi、Gauss-Seidel 这类不动点迭代的更新公式，改写一下就是

$$x_{k+1} = x_k + M^{-1}\,(b - A x_k)$$

一眼就能认出来：$b - Ax_k$ 其实就是目标函数的负梯度，而 $M^{-1}$ 扮演的正是拟牛顿法里近似海森矩阵的那个角色。如果 $M$ 直接取 $A$，那么只需要一步迭代就可以收敛——但代价是 $A^{-1}$ 本身是一个很难算的东西。如果用一些更简单的矩阵，比如单位矩阵、或者下三角矩阵，来近似这个海森矩阵，就可以去平衡整个算法的收敛和它的计算速度。所以说，不动点迭代也可以看成是一种拟牛顿法。

到这里，无约束优化比较核心的几种方法就都介绍完了：梯度下降法、牛顿法，以及拟牛顿法。其中要特别注意的就是 BFGS 和 L-BFGS——这是大家实际中最常用的几种算法。下面就来看：如果优化问题是一个带约束的优化问题，我们应该选择什么样的方法去求解。

### 约束从哪里来

带约束的优化问题，相比无约束的问题多的就是一个"约束"，而这个约束可以分为**等式约束**和**不等式约束**两类。

在图形学中，约束非常常见。做模拟的时候，我们当然希望两个物体之间不能发生穿透——写成约束，就是两个物体之间的最短距离 $d \ge 0$，这是不等式约束；如果有关节，比如人手上有一个关节，我们会希望人手的两个部分在这个关节处的位置是一样的——这是等式约束；同时关节的角度也有一些限制，不能弯得过小、也不能弯得过大——又是不等式约束；再比如路径规划里的约束，就是等式约束。所以说带约束的优化问题，在图形学中是一个非常常见的问题。

为了讨论简单，这一讲只考虑**等式约束**，先不管不等式。问题写成：最小化目标函数 $f(x)$，同时希望 $x$ 满足一组条件

$$\min_x \ f(x) \qquad \text{s.t.} \quad g(x) = 0$$

$g$ 的每个分量代表一条等式约束。

### 最优条件：梯度要与约束垂直

第一个问题：这个优化问题达到最优的时候，应该满足什么样的条件？

用一个二维的例子来切入。假设最小化 $f(x, y)$，只有一个约束 $g(x, y) = 0$。所有可行的 $(x, y)$，对应的是二元函数 $g$ 的零等值线——这些点只能在 $g(x,y)=0$ 这条线上滑动。那么什么时候 $f(x,y)$ 可以取到最小呢？

答案：$f$ 本身的梯度，应该垂直于这条等值线。为什么呢？反过来看：假如我们在另外一个点上，$f$ 的梯度和这条曲线不垂直，那就意味着在这个点上、沿曲线的某一个方向往前走一点，有可能使 $f$ 继续下降——那它就一定不是最小值点。所以如果你是最小值点，那么 $f$ 在这个点的梯度一定要跟曲线的切线垂直。

而 $g$ 的梯度本身就是垂直于零等值线的。垂直于同一条线的两个方向彼此平行，于是：**在最优点上，$f$ 的梯度应该和 $g$ 的梯度平行**。写成数学，就是存在一个实数 $\lambda$，满足

$$
abla f = \lambda \, 
abla g$$

二维情形里可行集是一条零等值线；换到高维，$g(x) = 0$（$x$ 是高维向量）就不再是一条线，而可能是等值面、等值体——一个高维的流形。但垂直关系依然满足：$f$ 在这个点上的梯度，一定要跟约束流形本身垂直。

把条件整理出来，就是两条：

> **结论**：等式约束优化问题的最优点 $x^\star$ 满足——
>
> 1. $x^\star$ 满足所有约束：$g(x^\star) = 0$；
> 2. 存在一组 $\lambda$，使得 $
abla f = \sum_i \lambda_i 
abla g_i$，即 $
abla f$ 是诸 $
abla g_i$ 的线性组合。
>
> 只要这两条同时满足，$x^\star$ 就是原优化问题的最优点。

### 拉格朗日函数：两个条件并成一个

这个最优形式看起来依然比较复杂。这里引入一个非常重要的概念——**拉格朗日函数**，用它把刚才推出的最优条件简化。

> **定义**：对上面的优化问题，定义拉格朗日函数 $L(x, \lambda) = f(x) - \sum_i \lambda_i\, g_i(x)$。它同时是 $x$ 和一组 $\lambda$ 的函数；$\lambda_i$ 称为拉格朗日乘子，个数正好等于约束的条数，每个约束前面乘一个。

定义了这个函数之后，刚才说的最优解条件，其实可以简单地写为

$$
abla L = 0$$

为什么呢？我们可以来算一算 $L$ 的梯度具体是什么。把 $L$ 对 $\lambda_i$ 求导：整个式子里出现 $\lambda_i$ 的地方只有后面那一项，求出来就是 $-g_i$；令它等于零，就代表 $g_i = 0$——也就是 $x$ 要满足我们列出来的约束，这正对应第一条。把 $L$ 对 $x$ 求梯度，得到

$$
abla f - \sum_i \lambda_i 
abla g_i = 0$$

这个条件刚好就对应着刚才推出来的第二条。所以前面推出的两个条件，可以被简单地写成"拉格朗日函数的梯度等于零"这一个条件，看起来就简洁多了。

### 为什么不能直接最小化 L：一场 min-max 博弈

那这个结论是不是意味着：我们直接去最小化这个拉格朗日函数，就可以得到原问题的解呢？**这个是不对的。**

观察拉格朗日函数的形式：后面是 $-\lambda_i g_i(x)$ 这一项。如果随便取一个 $x$，让某个 $g_i(x) 
e 0$，这个 $\lambda_i$ 就可以去选一个很大的值。比如 $g_i(x) > 0$，$\lambda_i$ 就可以选成正无穷，这时 $L$ 就是一个负无穷的值。所以如果直接去最小化 $L$，最小化的结果一定是 $-\infty$，最小化 $L$ 就没有意义了。

> **易错点**："$
abla L = 0$ 是最优条件"不等于"最小化 $L$ 就能得到解"。只要 $x$ 违反约束，$L$ 就能被乘子压到负无穷，直接最小化 $L$ 无界、无意义；$
abla L = 0$ 刻画的是下面这个博弈的平衡点。

那 $
abla L = 0$ 这个条件到底是怎么来的呢？这里可以引入另一个重要的概念：**min-max 问题**。与原来这个带约束优化问题等价的拉格朗日函数优化问题，其实不是一个单纯的最小化或者最大化问题，而是

$$\min_x \ \max_\lambda \ L(x, \lambda)$$

对 $x$ 取最小，然后对 $\lambda$ 取最大。这个问题非常有意思，可以怎么想象它呢？想象有 $x$ 和 $\lambda$ 两组玩家在博弈：$x$ 希望这个 $L$ 取最小，$\lambda$ 希望这个 $L$ 取最大。

看这两个玩家怎么过招：如果 $x$ 一不小心取到了一个 $g_i(x) 
e 0$ 的点，那么 $\lambda_i$ 就一定能够取到正无穷或者负无穷，使得 $L$ 趋向于正无穷——$\lambda$ 的目的就是要最大化 $L$，现在 $L$ 被顶到了正无穷，$x$ 就输了。所以 $x$ 想要最小化 $L$、想要赢，就一定要让 $g_i(x)$ 等于零：只要它等于零，后面那一项不管 $\lambda_i$ 取多大都永远是零，$\lambda$ 无计可施。这时 $x$ 的任务就变成了：尽可能最小化 $f(x)$。

所以这场博弈的结论是：博弈到最后平衡点上的那个解，就是原来带约束优化问题的解——$x$ 既要让 $g(x) = 0$，同时要最小化 $f(x)$。而且既然是 min-max 问题，达到平衡点的时候，$L$ 关于 $x$ 的梯度以及关于 $\lambda$ 的梯度自然都应该是零——这正好对应前面列举的最优点条件。

于是，最开始那个带约束的优化问题，到这一步就被我们变成了 min-max 的形式。但也正因为它是 min-max，我们没有办法直接套用前面介绍的那些无约束优化方法去优化它。想迭代地求解这个 min-max 问题，最终还是要回到"最优点满足什么性质"上来：找到一组 $x$ 和 $\lambda$，让它们满足那两个条件。

### 用牛顿法直接解最优条件

这样的条件怎么迭代求解呢？可以使用牛顿法。

最开始介绍牛顿法的时候，说它是优化 $f(x)$ 的一个二阶方法。换一个角度看：优化 $f(x)$，其实也就是解一个"$f(x)$ 的梯度等于零"的方程。所以牛顿法可以应用到解一般的方程上来：如果我直接有一个方程 $p(x) = 0$，用牛顿法去解它，就是在迭代的每一步把这个函数做一阶展开

$$p(x_k + \Delta x) \approx p(x_k) + 
abla p(x_k)\,\Delta x = 0$$

然后看这个一阶展开对应的近似解是多少，把它作为更新的步长：

$$\Delta x = -\big(
abla p(x_k)\big)^{-1} p(x_k)$$

在图上看，牛顿法解方程的过程是：从 $x_0$ 开始，在 $x_0$ 附近画出方程曲线的切线，找到切线在 $x$ 轴上的交点，把这个交点作为下一步更新的位置；一直这么进行下去，最终就可以收敛到方程真正的解。而由于这是对 $p$ 做一阶近似——假设 $p$ 是某个优化问题 $f$ 的梯度，那么对 $p$ 做一阶展开，其实就是对 $f$ 做二阶展开——所以它确实就是牛顿法。

现在用这个工具去求解拉格朗日函数的平衡点满足的方程。把 $\lambda$ 写成一个矢量（维度等于约束的个数），拉格朗日函数就是 $L = f(x) - \lambda^\top g(x)$，最优条件是两条：

$$g(x) = 0, \qquad 
abla f(x) - J(x)^\top \lambda = 0$$

其中 $J(x)$ 是约束函数 $g$ 对 $x$ 的雅可比矩阵。在迭代的第 $k$ 步，把这两个方程在 $(x_k, \lambda_k)$ 附近做线性展开、令它等于零，跟刚才解方程的过程一样；再把展开出来的两个式子写成一个大的矩阵方程：

$$\begin{bmatrix} H_k & -J_k^\top \\ J_k & 0 \end{bmatrix} \begin{bmatrix} \Delta x_k \\ \Delta \lambda_k \end{bmatrix} = \begin{bmatrix} -(
abla f_k - J_k^\top \lambda_k) \\ -g(x_k) \end{bmatrix}$$

其中 $H_k$ 是拉格朗日函数对 $x$ 的海森矩阵。可以看到：这个方程的左边是一个对称的矩阵，但这个对称矩阵的右下角有一部分是零；同时整个方程也不一定是正定的——一般来说它是一个**不定方程**。解这个矩阵方程，就得到 $\Delta x_k$ 和 $\Delta \lambda_k$，把它们作为更新方向去更新 $x_k$ 和 $\lambda_k$，直到最终收敛到我们想要的平衡点上来。

不定方程带来一个现实问题：能使用的求解器，就是上一节介绍的那一类，比如像 LU 分解这样的一些形式。正定的矩阵方程有一些很快的求解器可以解它；但如果是不定的，解下来可能就比较慢。所以用牛顿法直接求解这个最优条件，因为实现上的原因，一般来说不会是一个特别快的方法。

### 对偶问题：换个顺序解同一个问题

那么我们还有一个做法，称为把原问题转化成对应的**对偶问题**来优化。对偶问题一般来说有着比原问题更好的形式，以及更快的求解器。

对偶问题从哪里来呢？最简单的理解方法，就是从刚才介绍的 min-max 形式出发，把两个操作的顺序调个头：原来是 $x$ 先手、$\lambda$ 见招拆招，现在让 $\lambda$ 先手、$x$ 后手。写出来就是

$$\max_\lambda \ \min_x \ L(x, \lambda)$$

这个调换了顺序的问题，就是原问题的**对偶问题**。这也很合理——$x$ 和 $\lambda$ 本来就是博弈的两队玩家，一个想最小化 $L$、一个想最大化 $L$，先后手对调，游戏还是那个游戏，只是换了出牌顺序。

#### 弱对偶与强对偶

那么对偶问题和原问题的关系到底是什么呢？一般来说，对于一个任意的函数 $L$，我们总有下面的**弱对偶关系**成立：把 min-max 的顺序交换之后，最优点的值一定是小于等于原来这个值的，

$$\max_\lambda \min_x \ L \ \le \ \min_x \max_\lambda \ L$$

而如果 $L$ 还满足一些额外的性质——比如目标函数 $f$ 和约束 $g$ 都是**凸**的——那么下面的**强对偶关系**就成立了：对偶问题的最优值和原问题是相等的。

说到这里就涉及到凸函数的概念了。它是优化中一个非常重要的概念，甚至衍生出优化里一个专门的研究方向——**凸优化**。这一讲是实践课程，没有时间给大家延伸理论，我们可以牺牲一些理论上的严谨程度：假设大部分见到的函数都近似是凸的，或者可以通过某种手段把它转化成对应的凸函数，这样就可以默认强对偶条件一定成立。而事实情况也是如此：大部分大家接触到的优化问题，做这样一个对偶转换，一般来说都是可以转化过去的。至于到底哪些问题严格满足强对偶条件，我们这里就不去纠结了。

#### 对偶函数：把约束藏进一个最小化里

强对偶关系成立意味着什么呢？意味着原问题可以变成去求解对应的对偶问题，这个对偶问题的解和原问题的解是一样的。那么对偶问题可以写成什么样子呢？我们可以定义一个新的函数

$$G(\lambda) = \min_x \ L(x, \lambda)$$

它就是拉格朗日函数对 $x$ 取最小值，称为**对偶函数**；对应地，$G(\lambda)$ 的优化问题也就称为对偶问题。如果我们能给出 $G(\lambda)$ 的具体形式，那我们就不用去解原来那个带约束的优化问题，而是可以直接求解一个**无约束**的优化问题 $\max_\lambda G(\lambda)$；如果强对偶关系成立，那么这个无约束优化问题最终的解应该和原问题的解是一样的。而且它相比原问题是个无约束问题，解起来就更容易了。

#### 动手算一个：圆上最小化 x+y

给一个具体的例子，看看对偶问题到底是什么。约束取一个二维的 $g(x, y) = x^2 + y^2 - 1 = 0$——可行点只能在单位圆上运动；目标函数取 $f(x, y) = x + y$，我们希望在圆上最小化它。$f$ 的等值面画出来是一条一条的直线。先在脑子里想一下：它应该在什么时候取到最小？直觉上应该在 $x = y$ 这条对角线方向上、圆的左下边缘那个点附近。

下面用对偶的方法正规地解一遍。写出对应的拉格朗日函数：

$$L = x + y - \lambda\,(x^2 + y^2 - 1)$$

然后求对偶函数 $G(\lambda) = \min_{x,y} L$。分两种情况：

当 $\lambda \ge 0$ 的时候，$L$ 关于 $x$ 和 $y$ 是一个开口向下的二次函数——往远处走，$-\lambda(x^2 + y^2)$ 会把函数值压向负无穷。于是这个"最小值"可以取到负无穷，$G(\lambda) = -\infty$。

当 $\lambda < 0$ 的时候，$L$ 关于 $x, y$ 是一个开口向上的二次函数，最小值有指望了。令梯度为零：$\partial L / \partial x = 1 - 2\lambda x = 0$，得到 $x = y = \dfrac{1}{2\lambda}$（此时是负数）。代回去，可以算出

$$G(\lambda) = \lambda + \frac{1}{2\lambda}$$

所以这个对偶函数是可以直接求出来的：$\lambda < 0$ 时它画在图上是一条双曲线形状的曲线，$\lambda \ge 0$ 时恒为 $-\infty$。那么要问：$G(\lambda)$ 什么时候可以取到最大？显然就在 $\lambda < 0$ 这条双曲线的顶点上。解析地算：$\dfrac{dG}{d\lambda} = 1 - \dfrac{1}{2\lambda^2} = 0$，得到 $\lambda = -\sqrt{1/2}$ 时取到最大值。这时 $x$ 和 $y$ 对应的值也就可以求出来：$x = y = \dfrac{1}{2\lambda} = -\dfrac{\sqrt{2}}{2}$。

回到几何图上一对照：这确实就是原问题的最优解——$x = y$ 那条线上、圆的左下方向的那个点。所以我们就用这个例子展示了：原来这样一个带约束的优化问题，在转化成对应的对偶问题之后，还可以变成一个无约束的优化问题，我们直接得到无约束优化的解，再对应回原问题的解。这就是面对带约束优化时非常重要的一个概念：**对偶问题**。

### 对偶上升法：交替更新 x 与 λ

有了对偶这个基本想法之后，我们就可以去设计对应的优化算法，也就是**对偶上升法**。它利用对偶问题的形式，交替地更新 $x_k$ 和 $\lambda_k$。算法每一步分两步走。

第一步，固定 $\lambda_k$，把它当成一个固定的值，然后去单独优化 $x$ 的部分：

$$x_{k+1} = \arg\min_x \ L(x, \lambda_k)$$

这一步相当于什么？相当于去计算 $G(\lambda_k)$ 的值是多少——因为 $G(\lambda_k)$ 对应的正是"给定 $\lambda_k$ 时，$L$ 取到最小值的那个点"。

第二步，有了 $G(\lambda)$ 之后，用**梯度上升**的方法去更新 $\lambda_k$——因为我们要最大化 $G$。那就需要把对偶函数 $G$ 对 $\lambda$ 求梯度，加到 $\lambda_k$ 上。这个梯度等于多少呢？注意到对偶函数可以写成

$$G(\lambda) = L\big(x^*(\lambda),\ \lambda\big)$$

其中 $x^*(\lambda)$ 也是 $\lambda$ 的一个函数，表示给定一个 $\lambda$ 之后，$L$ 取到最小值时的那个 $x$。由于 $x^*$ 是这个 $\lambda$ 对应的 $L$ 的最小值点，它应该满足 $L$ 对 $x^*$ 的导数为零。于是用链式法则计算 $G$ 对 $\lambda$ 的梯度：

$$
abla_\lambda G = 
abla_x L \cdot \frac{\partial x^*}{\partial \lambda} + \frac{\partial L}{\partial \lambda}$$

第一项里 $L$ 对 $x$ 的梯度在 $x^*$ 处是零，整项消失，只剩下最后一项 $L$ 直接对 $\lambda$ 求梯度。而 $L = f - \lambda^\top g$，对 $\lambda$ 求梯度就是 $-g$。所以对偶函数在 $\lambda$ 这个点的梯度，应该等于 $-g(x^*)$。代入梯度上升的公式，我们就得到 $\lambda$ 本身的更新公式：

$$\lambda_{k+1} = \lambda_k - \alpha_k \, g(x_{k+1})$$

到这里，对偶上升法的算法流程就推齐了：每次迭代分两步，第一步更新 $x_k$ 到 $x_{k+1}$，第二步再用更新过的 $x_{k+1}$ 去更新 $\lambda_k$。

可以发现，它相比于牛顿法来说看起来更简单：它相当于把我们刚才那个带约束的优化问题，变成了**两个无约束的优化问题**。第二个（$\lambda$ 的更新）使用梯度上升法去解；第一个关于 $x$ 的优化问题，也可以用梯度法去解。这样整体就相当于一个一阶的方法——可以在完全不知道 $L$ 的二阶信息的情况下，优化 $x$ 和 $\lambda$。

### 罚函数法：最简单的近似方案

除了牛顿法和对偶上升法，还有一个非常直接的方法去求解带等式约束的优化问题：**罚函数法**。

罚函数法的想法非常简单：把约束函数作为一个罚函数、作为一个惩罚，直接加到目标函数里：

$$\min_x \ f(x) + \mu \,\| g(x) \|^2$$

其中 $\mu$ 是我们给定的约束强度，$\mu$ 越大代表这个约束越强。直接对这个问题做无约束优化的时候，可以想象：后面这一项要尽可能小，就是 $g(x)$ 要尽可能接近于零；而 $g(x)$ 接近于零的时候，就相当于是只在优化前面的 $f(x)$ 这一项。

所以罚函数法**只能近似地**求解到最优点：近似地让约束满足，$f$ 也是近似最优。但它的好处是形式非常简单。除了"解是近似的"这一点之外，$\mu$ 本身也是一个很大的问题：我们需要去调节 $\mu$ 的值，来让整个算法的效果比较好。$\mu$ 取得比较大之后，算法就可能比较难收敛——因为后面挂着一项很大的二次项；$\mu$ 很小呢，代表这个约束很"软"，$g(x)$ 可能就离零偏差得比较远。所以我们一定要选择一个合适的 $\mu$，使得 $x$ 同时满足约束、并且尽可能最小化 $f(x)$。总的说来，罚函数法是一个简单的近似方法：在精度要求不是很高的地方，我们可以使用它。

### 不等式约束：能忽略时就忽略

前面讨论的都是等式约束的情况。最后简单展示一下：如果我们遇到了不等式约束，处理它的基本思想是怎样的。

不等式约束与等式约束最大的区别在哪呢？在于：**如果最优点被包含在了不等式约束的范围里面，那么这个不等式约束其实可以当它不存在**。它唯一发挥作用的地方，恰恰是在不等式约束变成等式约束的那条线上——边界上。如果最优点（没有约束时的自由解）没有被包含在不等式约束的区域内，那么我们只需要在这个不等式约束的边界上进行搜索，找到的最优点就是整个问题的最优点。所以不等式约束的处理思路非常直接：自由解落在不等式范围内，这条约束当它不存在就可以；自由解落在外面，就把这条不等式约束当成等式约束一样处理。

那么它引入的困难，恰恰就在于**判断**：到底哪些约束是要考虑在内的、哪些约束是可以忽略掉的。这样一个"选择"问题，其实是一个策略问题——哪些东西应该保留、哪些应该扔掉——它不再是一个连续的优化问题，而是一个**离散的优化问题**。这一点导致不等式约束处理起来，要比等式约束更麻烦一些。

那不等式约束的拉格朗日函数长什么样呢？对一个通用形式的带不等式约束的优化问题（比如 $\min f(x)$，约束为 $h(x) = 0$ 与 $g(x) \le 0$），我们依然可以定义它对应的拉格朗日函数；只不过相比于等式约束，min-max 问题里多了一个带取值范围限制的乘子：

$$\min_x \ \max_{\lambda,\ \mu \ge 0} \ \left[\, f(x) + \lambda^\top h(x) + \mu^\top g(x) \,\right]$$

它与等式约束情形最大的区别，就在于中间 $\mu$ 的这一项：$\mu$ 的取值被限制在大于等于零。为什么会出现这样一个结果呢？还是用博弈来看。等式约束的情形，是 $x$ 和 $\lambda$ 两个人在玩游戏：$x$ 希望 $L$ 取最小，$\lambda$ 希望 $L$ 取最大，最后平衡的结果就是 $x$ 必须让等式约束 $h(x) = 0$ 才能让自己获胜。把 $\mu$ 和不等式约束考虑进来、限制 $\mu$ 只能取大于等于零的值之后：如果 $x$ 取到 $g(x) > 0$ 的点，$\mu$ 就可以取一个正值，把 $L$ 顶到正无穷——$x$ 就输了。所以 $x$ 想赢的话，一定要让 $g(x) \le 0$。而只要 $g(x) < 0$，$\mu$ 的最优反应只能是取 $\mu = 0$，让这一项乘起来等于零——它没有办法通过取一个负的值把整个函数顶上去，因为 $\mu$ 被限制在非负。所以说，只要限制了 $\mu \ge 0$ 让它参与博弈，博弈的平衡点就是：$x$ 满足 $h(x) = 0$ 的限制、同时满足 $g(x) \le 0$ 的限制，在这两个限制的基础上让 $f$ 取到最小化。

有了这个 min-max 形式之后，同样可以导出对应的最优化条件——称之为 **KKT 条件**——也可以找到它对应的对偶问题、对偶优化算法。由于今天的时间限制，这里就不展开了。

> **提示**：本讲等式部分把拉格朗日函数写成 $f - \lambda^\top g$，不等式部分写成 $f + \lambda^\top h + \mu^\top g$。两种写法在教材里都常见：等式约束的乘子 $\lambda$ 没有取值限制，整体变号等价于把 $\lambda$ 换成 $-\lambda$，符号约定不影响结论；不等式约束的乘子 $\mu \ge 0$ 有方向性，符号必须和"违反约束时能被顶到正无穷"这套博弈逻辑配套。读别的书时先认一下符号约定，再认结论。

### 方法地图与这一讲没讲到的

回顾一下这一讲一起看的这些方法。我们其实主要关注的就是两类问题：第一类是无约束的优化问题，第二类是带等式约束的优化问题。把整个方法版图画出来：

```text
优化问题
├─ 无约束优化
│   ├─ 梯度下降法：一阶，只用梯度
│   ├─ 牛顿法：二阶，收敛效率更高，但每步要解矩阵方程求下降方向
│   └─ 拟牛顿法：用更简单的矩阵近似海森矩阵，让求逆变方便
│       ├─ BFGS
│       └─ L-BFGS：只留最近 M 步更新，存储回到 O(n)，工业软件默认
└─ 带等式约束优化
    ├─ 牛顿法解最优条件：仍是二阶方法；方程不定，求解器受限，一般不快
    ├─ 对偶上升法：转成无约束对偶问题，交替更新 x 与 λ（一阶）
    └─ 罚函数法：把约束当惩罚加进目标；近似满足，需要调 μ
```

一句话读图：两个主枝对应两类问题；带约束那一枝的三条路线，分别是"直接解条件""转到对偶"与"近似处理"三种取舍。

逐条串一遍。无约束这一支：梯度下降法只使用优化问题的一阶信息；牛顿法使用了二阶信息，相对来说收敛效率更高，但它的问题在于迭代的每一步都需要通过求解一个矩阵方程来获得下降方向，这一步比较耗时；拟牛顿法解决这个问题的办法，就是用一个更简单的矩阵去近似牛顿法里的海森矩阵，让它更方便地求出逆矩阵来——常见的就是 BFGS 和 L-BFGS，也是大家最常用的算法。

带等式约束这一支：我们首先建立了拉格朗日函数与对偶的概念，讨论了等式约束优化问题在什么条件下取到最优；直接求解这个最优条件可以使用牛顿法，它依然是一个二阶方法，但写出来的方程是一个不定方程，求解时需要注意使用合理的求解器；对偶上升法则把等式约束问题转换成对应的对偶问题——一个无约束优化问题——交替迭代地更新 $x$ 和拉格朗日乘子 $\lambda$，让它收敛到最终的平衡解。

当然，今天没涉及到的东西还有非常多：无约束问题里如果函数不可导怎么办；问题空间是离散的组合优化该怎么办；等式约束换成不等式约束之后的完整处理（KKT 条件、对偶算法）；以及问题是非凸的该怎么办。这些问题今天都没有涉及，所以今天的介绍只能算一个简单的入门。不过，今天介绍的这几种算法，恰恰是我们应用中碰到的问题里用得最广泛的方法；以后涉及到更难的问题、或者需要更快的优化算法的时候，再进一步深入学习优化相关的知识就好——那一般来说是一整个学期的课程，内容分量非常大，感兴趣的话值得系统地啃下去。
