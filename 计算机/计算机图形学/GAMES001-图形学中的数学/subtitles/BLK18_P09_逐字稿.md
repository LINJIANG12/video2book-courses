好的。今天这节课我们主要是从两个方面去讲一下概率论在图形学当中的应用。第一个部分是噪声，第二个部分是蒙特卡洛积分法。这两个部分其实是有一定的相关性的，我们之后会看到这两部分的相关性在什么地方。我们首先从噪声开始去讲一下噪声和我们上节课所说的那些概率论相关的知识到底有什么关系。

首先，大家可能会很奇怪，噪声这个“声”字，听起来应该是某一种物理学当中声学的概念，那它和概率之间是如何建立联系的呢？我们干脆就先从声音的角度出发去看声音里面所谓的噪声是什么。

首先我们说声音是有颜色的。声音的颜色是来源于光的颜色。因为我们平常大家所说的颜色都是指光的颜色，而光的颜色从本质上看，它其实是人眼对于不同波长的光的混合的感觉。

注意这里我用的词是“不同波长的光的混合”，而不是不同波长。因为大家都知道，比如说日光我们看起来它是白色的，但其实它是红橙黄绿青蓝紫各种波长的光的混合。所以我们并不说一个颜色只能对应于一种频谱，而是每一种频谱在人眼中都会形成一种颜色，但是不同的频谱有可能对应于相同的颜色。

举一个例子，比如说赤橙黄绿青蓝紫当中已经有黄这一个光线了，我们都知道是钠黄光，大概是由钠原子激发所发出来的光，它本身就是黄色。但是我们又知道红色色光和绿色色光混合在一起会形成黄色色光。所以同样是黄色，它的来源可能有很多种。

好，简要说了下什么是颜色之后，我们会发现所谓声音，它和光一样，它也是一种波。只不过光是电磁波，而声音是机械波。那么有波就有波长，有波长就有颜色。如果我们能做一下这样的类比的话，那么我们可以说声音也是具有颜色的。

既然我们刚刚已经说白光是不同波长的光的混合，那么白声呢？或者我们中间加一个“噪”字，因为类似这样的声音其实很难被人发出，或者自然界当中以一种音乐的方式给出的，所以我们称它为噪声。那么白噪声是什么呢？一样的，它就是在一定频域范围内所有频率的声音的均匀混合，它就叫白噪声。因为我们知道所有频率的光的均匀混合会形成白光，所以所有频率的声音的均匀混合就会形成白噪声。

两个比较常见的白噪声的例子，比如电视机没有信号的时候会听见沙沙的声音，这是白噪声；或者在海边我们去听海浪拍打岩石的声音，这也是白噪声。我们可以看到它的频谱图在不同的频段上，它的强度大概都是相同的，大致是相同的，这种声音我们就称之为白噪声。

从白噪声出发，我们自然可以形成粉噪声和蓝噪声。因为红橙黄绿青蓝紫，“粉”显然是偏向于左侧，左侧是低频的，对吧？所以低频强、高频弱，我们称它为粉噪声；而如果低频弱、高频强，若是这样的话，我们就称它为蓝噪声。这种噪声我们都称之为蓝噪声。都是类比于光线当中的。

好。那么广义的噪声，它广泛地存在于图像和视频当中。视频大家都还好理解，因为视频中也有声音，那么图像当中为什么也有噪声呢？这里又经过了一次类比。原来我们是光波，然后变成了声波，这个过程它是怎么又到图像当中去的呢？这个概念是在 CV 或者 CG 的领域当中，我们常常用噪声这个词来指代一种具有一定随机性的扰动，或者我们称之为某种随机分布，这样的噪声也就是基于这种随机分布生成的。因为不同的随机分布会使频域中有不同的特点，因此这个噪声具有颜色。

所以这里的逻辑是这样来的：它首先是从光学当中不同波长的波具有不同的颜色，然后到声学当中不同波长的声音也具有颜色，最后到我们的 CG 里面，我们在说图像、视频的时候，其中的误差也可能会具有颜色。这个时候我们说的这个波，或者说我们说的这个频谱它要从哪来呢？

比如说我们给了一张数字图像，一张 $M \times N$ 像素的数字图像，我记 $f(x, y)$ 表示坐标为 $(x, y)$ 处的像素的强度。然后我们可以对整个图像去做二维的傅里叶展开。展开完以后，我们称 $|F(u, v)|^2$ 这个东西叫做功率谱。

什么是功率谱？就是现在 $F$ 的自变量 $u, v$，或者 $P$ 的自变量 $u, v$，它本身都是某种和谱、和频谱相对应的这样一个参量。这大家概念性地理解一下就可以了，因为我们并不需要真的去掌握说如何对一个数字图像去做傅里叶分析。

好，这时候我们来看一个很经典的问题，叫图像的量化。

因为我们知道现在的显示技术当中，RGB 一般在红色通道、绿色通道、蓝色通道，每个通道都有 0 到 255 这 256 种颜色，总共形成的颜色的数量就是 $256^3$。这个数字是相当大了，所以我们一般都已经把这么多种颜色给看成是连续的了，颜色空间我们一般都把它当成是连续的。

但是假如我们的显示设备支持不了这么好的显示的手段，我们显示设备只能在 R 通道上要么取 255、要么取 0；在 G 通道上也是要么取 255、要么取 0；在 B 通道也是要么取 255、要么取 0。那么我们现在给你一个原图，原图是连续的一个照片，然后我们希望在某一个只能显示 0 或者 255 的这样一台显示设备上将原图给显示出来，怎么显示出来的结果是最接近原图的？我们现在就来讨论一下这个问题。

下面我们给出的 A 是原图。而 B 呢，B 是直接进行量化。什么叫直接进行量化？就是我们每拿到一个 RGB 值，比如说 126，我们就比一下，看它比 127 是大还是小。如果我们看它是小于等于 127，我们就置为 0；如果过来一个 128，128 是大于 127 的，我们就给 1。我们就这样把整个的 0 到 255 这 256 种颜色里面的前 128 种算成 0，后 128 种算成 1，也就是 255。

如果我们去做这样的操作，我们就会得到 B 图。可以发现 B 图相对于 A 图其实丢失了非常多的细节。

而我们现在要讨论的东西就是我们如何通过某种方法达到 C 的效果。我们可以看到 C 它也是一个只支持显示 0 或 255 的这样一个显示手段，但它显示出来的结果要比 B 更加接近于原图。而使得 A 原图能转化为 C 这样效果的图的算法，就是和今天我们要说的这个主题噪声是息息相关的。接下来我们来看一下它是怎么联系起来的。

我们先把问题给 formulate 一下。给定一张灰度图，刚刚我们其实给了一个 RGB 的图，这个问题会相对难一些，现在我们给定一张灰度图。每个像素的亮度值，我们刚刚说说 0 到 255 这 256 种，现在我们干脆给它加强一下，就是 0 到 1 范围内的实数。0 就是最暗的，1 就是最亮的。现在我们要把它显示在一台老式的显示设备上。在这台老式的显示设备上，每个像素要么取 0，要么取 1。那么如何才能让显示的图像在视觉上尽可能地接近原图呢？

刚刚我们讨论的上一页当中给出的 B 的图片，它其实就是朴素方案。我们把亮度小于等于 0.5 的像素都给显示成黑色，否则我们就把它显示成白色。

一种简单的解决方案是有序抖动法。所谓有序抖动法我们可以这样去看：假如我们显示器的分辨率是高于图像的，举个例子，原图的像素是 $100 \times 100$，而我们显示器的分辨率是 $300 \times 300$，而显示器的每个像素只有 0 或 1 这两种。这个时候我们怎么办？我们可以用 $3 \times 3$ 的显示像素来表示一个图像的像素，对吧？既然我们的显示能力就是 0 或者 1，那我们可以把某一小块放在一起，那它就有更多种的显示能力了。比如说我们现在下面给出了从 0 到 9 这不同的色块，我们用每个色块来表示图像当中的一个像素。

怎么表示呢？如果图片当中发来一个原图的像素是 0.5，对应到显示器的像素是一个 $3 \times 3$ 的，对吗？我们是不是说这 $3 \times 3$ 的像素中只要有大概一半的像素被填满，从远处看它就比较接近于一个 0.5 亮度的像素的这样一个效果？我们来比一下。这个显示是 0，对吧，全黑是 0。这个显示是 1/9，这个是 2/9、3/9、4/9。我们发现这两种组合在视觉上都比较接近于 0.5 这个效果，对吗？所以如果拿来一个 0.5，我们就给它要么是这个、要么是这个就好。

然后以此类推，后面是 $\frac{6}{9}$、$\frac{7}{9}$、$\frac{8}{9}$，一直到 1。

每当我们拿到一个实数——因为每个像素它的亮度值都是一个 0 到 1 之间的实数——每当我们拿到一个实数，我们就看它更接近于下面哪一种，然后我们取这一个 $3 \times 3$ 的色块，用它来表示原图的像素就可以。

这个方法听起来很巧妙对吧？但是它虽然巧妙，它需要显示器的分辨率是高于图像的，需要宽和高都是原图的 3 倍。如果宽和高不是原图的 3 倍怎么办呢？

我们可以先看一下刚刚我们所说的处理方案，如果我们要把它形式地写下来大概是什么样的。它是说，我们有这样一个矩阵，这个矩阵是写成这样。因为我们可以看到，最先填上颜色的是中间这个，所以它标成 0；然后第二个填上颜色的是最左边这个，所以它标成 1；然后第三个，我这样写可能更清楚一些：这是 0，这是 1，这是 2，这是 3，对吧？然后以此类推，我们这样填下去，就会得到这个矩阵。

所以它的意思是说，如果原图像素的亮度值是大于等于 $M_{i,j} / 9$ 的，那么相应显示的 $3 \times 3$ 像素的第 $i$ 行第 $j$ 列的亮度值取 1，否则取 0。

因为当我们拿到一个色块的时候，它都对应于一个原图的像素，比如 $C_{i,j}$。然后我们就看这个 $C_{i,j}$ 和这个 $M_{i,j}$ 之间的关系，如果它是大于等于 $M_{i,j} / 9$ 的，那么我们就给它亮度值取 1，否则取 0。

刚刚我们做的都是显示的像素比原图的像素要高的情况。如果显示的分辨率和原图的分辨率是一致的呢？怎么办呢？

我们能不能这样做：不管三七二十一，我们把原图也做一个 $3 \times 3$ 的划分。比如说，原图是一个有 $6 \times 6$ 像素的图片。这是原图，我们现在把原图给分成四块，每块都是一个 $3 \times 3$ 的阵列，对吧？我们把每块的 $3 \times 3$ 阵列直接给它拉到刚刚我们说的解决方案里，直接去比较它在 $3 \times 3$ 阵列当中的第几行第几列，然后去比较底下这个，来决定这里是填白还是填黑。

这个方案相当于对原图增加了一个以 $3 \times 3$ 为周期的噪声，最后再进行二值化处理。对吧？因为我们看原图像素的亮度值大于等于 $M_{i,j} / 9$ ，如果它是大于等于这个数的话，我们就置 1，否则置 0。而我们原来是看原图像素的亮度值是不是大于等于 0.5，对吧？我们只不过是把 0.5 变成了 $M_{i,j} / 9$。

而这里的 $M_{i,j} / 9$ 是从上面这个矩阵来的，它看起来是完全没有规律的，就是 0, 1, 2, 3 的填法看起来完全没有规律、完全随机。所以它最后就相当于我们先对原图增加了一个以 $3 \times 3$ 为周期的噪声，然后再进行二值化处理，对吧？

我们可以给大家看一下刚刚我们这么做的效果。首先最左侧依然是原图。然后直接按 0.5 进行二值化处理会得到第二个效果。这个效果也很艺术对吧，但是它丢失了非常多的细节，我们现在根本看不清人物的面部特征。

如果我们按有序抖动，就是刚刚我们说的按 $3 \times 3$ 的阵列，然后都依次加上一个对应的数再做二值化处理，我们就会得到第三幅图。这幅图的效果是不是我们已经能够看清一点面部的特征了？

如果我们不是用有序抖动法，而是在图片的每一个像素上都随机地增加一个值，之后再去作二值化处理，我们会得到这幅图，随机抖动的结果。这个结果看起来非常像电视没有信号时候的雪花点。所以其实这个就是白噪声，我们一会儿会看它为什么是白噪声。

最后一个看起来效果最好的，是用蓝噪声的方法去进行抖动之后得到的结果。

现在我们用数学的形式来表述一下我们刚才到底干了什么。

比如我们刚刚在这里提到的 C 图，也就是随机抖动法，它在数学上看是什么样的呢？

我们先比较一下不对它进行抖动，直接去做：给定一个像素，它是小于 0.5 就置 0，大于 0.5 就置 1。如果直接做这样的操作，原图的某一个像素是小于 0.5 的——原图某一个像素的大小我们记它为 $c$，$c$ 是小于 0.5 的——那么不管这个 $c$ 出现在图片上的任何一个地方，也不管我哪一次去做量化，我都会把这个 $c$ 直接置为 0，对吧？它是一个确定性的过程，这个 $c$ 一定会变成 0。

所以说，对于一个 $c < 0.5$ 的像素，它直接二值化后期望的亮度就是 0，因为它永远不可能产生 1。所以从 0 到 0.49999，它都会变成 0，而且是确定地会变成 0。

但是如果我们先把这个 $c$ 加上一个在 $[-0.5, 0.5]$ 上的随机数，也就是说现在把 $c$ 变成了 $c + u$，而 $u$ 是一个在 $[-0.5, 0.5]$ 上的随机数。如果是这样的话，我们再来看这个像素得到的期望是什么。

我们这时候看 $E[\bar{c}]$，它等于……我们现在来看 $u$ 至多为多少的时候，仍然是会得到 0 的结果呢？显然，$u$ 在 $[-0.5, 0.5 - c]$ 这个区间内，都会得到 0。对吧？因为我们就看 $c + u \le 0.5$ 这个式子的解是什么就可以了，解出来是 $u \le 0.5 - c$。

剩下的情况就是返回的结果为 1 的，也就是从 $0.5 - c$ 一直到 0.5。这个时候，令 $\bar{c}$ 的结果返回是 1。

总之，由于这又是一个在 $[-0.5, 0.5]$ 上的均匀分布，它的概率密度函数都是取 1，所以直接把这个积分算出来就会得到期望。这个数学期望等于多少呢？它就等于 $c$。

很神奇对吧？我们只要在上面先盖上一个随机数，再取直接二值化处理的数学期望，就会发现期望等于它本身。

然后我们可以看到，我们一般一张图片都有几百万、几千万个像素。在像素点这么多的情况下，有一些像素取成了 0，有一些像素取成了 1。但在随机意义下，一个同样大小的，比如说在随机意义下一个亮度为 0.3 的像素——因为它可能会在图片当中很多个地方都是亮度为 0.3——在随机意义下，它们这些像素做二值化处理之后的期望仍然是 0.3。

因此我们只做了一个抖动，之后再进行二值化，反而能够看见原来我们看不见的颜色了。

好，没有问题的话，我们就接着往下说。

上述我们叠加的分布是均匀分布。因为叠加的是均匀分布的随机数，我们可以对它做傅里叶分析，它产生的频谱在各个频率上的强度大概是相同的。也就是说我们产生了一个白噪声，相当于在原图上加了一个白噪声，之后再进行抖动。

回到刚刚这个图，我们可以看到，这个白噪声得到的效果，你不能说它不好，比起直接二值化的结果还是多反映了一些细节，使得能够看见一些细节了。但是它也模糊掉了一些，使图像整体变得非常模糊。所以我们需要去考察有没有什么方案来解决一下在上面产生了这么多白噪声的问题。

人眼是对低频信号敏感，对高频信号是不敏感的。而蓝噪声的高频信号是强的，低频信号是弱的。从人的观感上来说，它是最符合人的需求的。

但是蓝噪声产生的算法相对来说就没有那么简单了。因为蓝噪声对于空间频率是有要求的。我们刚刚看图片的傅里叶分析，看到它的频率是空间频率，对吧？是按照图像的像素出现在空间哪块位置有关的。既然蓝噪声是对空间频率有要求的，因此不可能每个像素独立地去随机。每个像素独立地去随机，随机出来的东西对空间频率一定也是无关的。所以，我们不能每个像素独立去随机。

也就是说，如果我们想生成一个满足蓝噪声的分布，它需要一些特定的算法。这个就超出了 GAMES101 课程的框架了。大家感兴趣的话可以自己去看一下图形学当中那些如何去生成蓝噪声的算法。

总之，生成的内容可以看成是一张灰度的图像，然后我们可以用这个灰度的图像去抖动，抖动完以后再进行量化，然后就能生成上一页看到的那个比较好的结果。当然这个灰度图像有别于传统的灰度图像，因为它可能去复制。

此外，既然蓝噪声对人来说是最符合人的需求的，所以它也更适用于去做模拟渲染等任务当中的采样。从某种意义上说，蓝噪声生成的序列就是我们后面会说到的低差异序列。

这个概念的时候就有所了解。那个时候我们是用蒙特卡洛积分来求解不规则图形的面积的，对吧？

如何求解不规则图形的面积？我们先在矩形的区域内去撒 $N$ 个点，然后我们记落在图形内的数目是 $K$。这里的绿点就是落在图形内的。然后从概率上来说，这个图形的面积就等于 $\frac{K}{N}$ 乘上矩形区域的面积。

因为根据伯努利大数定律，当 $N$ 趋向于无穷时，$A_{\text{shape}}$ 就是趋于真值的。这可以从我们上一节课所说的内容当中去证明。

那么我们把求不规则图形面积的蒙特卡洛积分给它形式化一下，我们可以用它来求解一个从 $a$ 到 $b$ 区间上的定积分。

求解这一段上的定积分，我们最简单的做法是矩形法，对吧？所谓矩形法就是我们先把 $a$ 到 $b$ 这一段给它分成 $N$ 段，然后我们在每一段取一个值，用这个值去乘以这一段的长度，也就是 $\frac{b - a}{N}$。在这里，这个就不要了。

这个是个确定性的算法，因为我们在每一段当中要取哪一个值都是确定的。这里它取的值就是 $a + \frac{b - a}{N}i$。

那么蒙特卡洛解法是什么意思？就是我们现在仍然是在 $[a, b]$ 上取一些值，然后用这些值去乘以区间的长度。但是这些值是用某个分布产生的一个随机数序列。

如果这个分布是均匀分布的话，解决方案就是我们直接去用 $f(X_i)$。也就是我们先在 $[a, b]$ 这个区间上随便取一个点，然后看一下这个点的值是什么，然后用这个值去乘以 $b - a$。我们就假设这个值它就是整个区间上每个值都等于这个。那这个当然不对，我们就再取一次，我们会得到 $f(X_2) \cdot (b - a)$，然后再取再取，一直取到 $f(X_N) \cdot (b - a)$。然后我们看得到了 $N$ 个值对吧？这 $N$ 个值很有可能不一样，那我们怎么办呢？我们把它平均一下，所以我们再除以 $N$。这样就实现了一个最简单的在一个区间上去求定积分的蒙特卡洛算法。

然后我们就会想，刚刚这个都是均匀分布对吧？那如果我们产生的 $[a, b]$ 上的随机数它不是一个均匀分布呢？它是任意的一个分布呢？那其实也很简单。刚刚均匀分布，$[a, b]$ 上的均匀分布，它的概率密度函数是什么？是 $\frac{1}{b - a}$ 对吧？它写在哪呢？写在这儿。相当于我们把这个概率密度函数给除掉了。现在我们把这个概率密度函数给它放回去。

我们把它放在这个地方，它就是 $f(X_i)$ 除以概率密度函数，我们写成 $\text{pdf}$，这是个缩写。写成这个东西，然后一直算一直算，算出 $N$ 个出来，仍然一样，加和求平均。这样我们就得到了一个任意分布的蒙特卡洛积分。

好，现在我们来证明一下这个任意分布的蒙特卡洛积分它为什么是对的。

也就是说我们要看这个东西的数学期望等于多少。因为我们的 $X_1$ 一直到 $X_N$ 都是在同一个概率分布下去取的，所以它的数学期望是——也就是说 $\frac{1}{N}$ 的这个过程完全可以不要，我们直接就是在求这个东西的数学期望。

这个东西的数学期望是什么呢？我们用数学期望的定义，就是在 $[a, b]$ 上，这个是取这个随机变量，随机变量是 $\frac{f(x)}{p(x)}$，然后取得这个随机变量的概率是 $p(x)$。我们发现这个分母和这个因子直接抵消了对吧？它们俩相乘，剩下就只剩 $f(x)$，也就正好变成这个东西。这个东西是什么？就是我们要取的积分 $I$。

我们再来看这个东西的方差。这个东西的方差，类似地我们先把 $\frac{1}{N}$ 给提出来。为什么我们提的是 $\frac{1}{N}$ 不是 $\frac{1}{N^2}$？这是方差的性质，我们可以在之前的上一节课课程当中去找到。我们先把 $\frac{1}{N}$ 提出来，然后里面变成了分子是 $f(X_i)$，分母是 $p(X_i)$。然后我们再看这个方差的表达式。

方差我们回忆一下，方差的表达式是 $E[X^2] - (E[X])^2$ 对吧？$E[X^2]$ 是什么？$E[X^2]$ 是 $\frac{f^2(X_i)}{p^2(X_i)} \cdot p(X_i)$，也就是这个，对它积分。再减去 $(E[X])^2$。刚刚 $E[X]$ 我们已经求出来是 $I$ 了，所以 $(E[X])^2$ 就是减 $I^2$。

这个东西等于什么我不知道，但是我们发现它是正比于 $\frac{1}{N}$ 的。这说明什么呢？说明蒙特卡洛积分法的收敛速率是 $\frac{1}{\sqrt{N}}$ 的。因为这里求的是方差，而收敛速率我们一般看的是什么？看的是误差，或者说是标准差，也就是 $\sigma$。$\sigma$ 是 $\frac{1}{\sqrt{N}}$ 这个级别的。

也就是说，如果我们希望将蒙特卡洛积分的误差降低两倍的话，我们需要干什么？我们需要增加四倍的采样量。也就是四倍的采样会怎么样呢？会得到二分之一的误差。

这个收敛速率相对来说还是有一点慢的，对吧？那怎么去提升呢？因为我们发现其实蒙特卡洛积分因为它是随机算法，这个随机算法希望它能够很快地接近真值，只要它方差小就可以了，只要它方差小就可以很快地接近真值。

所以我们刚刚既然发现我们总是取得某一个随机数，然后取它的这个函数值，再除以这一点的概率密度值的话，那么决定这个收敛性的，除了 $\frac{1}{N}$，就只剩 $p(x)$ 了对吧？因为别的都是已知量，$f^2(x)$ 或者积分的结果 $I^2$ 都是不能变的，所以我们唯一能变的就是这个 $p(x)$。

怎么取呢？一个直观的猜测是，$f(x)$ 比较大的地方我们就大概率去取，$f(x)$ 比较小的地方我们就小概率去取，对吧？

是不是这样呢？当然是这样。这里有个定理，这个定理也就是佐证了我们要讲的蒙特卡洛积分的另一个很重要的特质，就是重要性采样这个算法。这个定理是说：当 $f(x)$ 与 $p(x)$ 是形状相同的时候，蒙特卡洛积分的方差直接为零。

我们来证明一下这件事。什么叫形状相同？也就是说 $p(x)$ 永远等于 $f(x)$ 的 $k$ 倍，$k$ 是一个常数。那么由于从 $a$ 到 $b$ 这个区间内 $p(x)$ 它的积分、概率密度函数的积分是 1，因为总概率是 1，我们会得到 $k$ 就等于 $\frac{1}{I}$。因为我们可以把这里用 $k \cdot f(x)$ 给它代进去，我们代进去就会推导出 $k = \frac{1}{I}$。

好，现在我们再来看这个东西的方差。蒙特卡洛积分算法的方差是什么呢？展开得到这个式子。左边的 $\frac{f^2(x)}{p(x)}$ 变成了什么？变成了 $\frac{f(x)}{k}$。$k$ 是什么？$k$ 是 $\frac{1}{I}$，所以它就变成了 $I \cdot \int_a^b f(x) dx$。这是什么呀？这就是 $I^2$ 对吧？那么 $I^2 - I^2$，方差是不是为零？

也就是说，结论是 $\frac{f(x)}{p(x)}$ 越平稳——什么叫平稳呢？就是它最好是一条水平线——越平稳，蒙特卡洛积分的方差就越小，也就是说它的收敛速率越快。

我们来考虑这个结论带来的两个问题。

第一个问题：方差为零意味着什么？方差为零意味着我们只需要采样一次就能算出这个积分的结果，对不对？这件事情它合理吗？为什么我们只采样一次它就能算出这个积分的结果呀？为什么方差可以为零？

因为我们刚刚要求了 $f(x)$ 与 $p(x)$ 形状相同。你既然要求了它形状相同，你的 $p(x)$ 和 $f(x)$ 之间就是一个正比例关系。而根据这个正比例关系呢，你其实是知道这个 $k$ 值，你必须算出这个 $k$ 值。换句话说，我们必须知道，我们必须令这个东西等于 1，因为这样它才是一个合理的概率密度函数。我们在计算这个东西的时候，你是不是自然地把积分给算出来了呀？因为 $p(x)$ 又同时等于 $k \cdot f(x)$。如果你都能够知道某一个点的 $p(x)$ 等于什么了，你一定做了这个归一化，也就是说你一定已经把这个 $k$ 算出来了。你把这个 $k$ 算出来了，就意味着你一定已经把 $I$ 算出来了。也就是说，但凡你存在一个和 $f(x)$ 形状相同的 $p(x)$，都意味着你已经把积分算出来了。这个东西是你已知的东西了，所以方差可以为零。

问题二：为什么要求 $f(x)$ 在积分区间上是非负的？如果有负数怎么办？刚刚我们在讨论这个问题的时候，我们设了 $f(x)$ 在 $[a, b]$ 上总是大于等于 0。为什么我们要求它是非负的？

因为看我们刚刚在推导的过程当中，我们是要求 $p(x)$ 永远和 $f(x)$ 之间差的是一个正比例关系。如果你的这个 $k$ 是取负值会怎么样？或者说如果你的 $f(x)$ 是取一个负值会怎么样？就会出现某一个点取这个点的概率是负的，对吧？会出现这种情况。所以如果有负数的话，重要性采样的这个定理，上面我们这个定理它是不成立的。

所以有负数是个 open problem。有一些 SIGGRAPH 的文章就去讨论说，一些特定的渲染场景里面我们会出现负数，这个时候该怎么办这个问题。有一些文章就是在研究这个。

好，我们今天当然就从最基本的开始讲了。那么刚刚我们证明的这个定理，它是说这个形状完全相同的时候方差为零。我们刚刚也说，这意味这你其实已经把积分算出来了。但绝大部分情况下你其实是算不出来这个积分的，或者说你都算出来这个积分了，你还要做蒙特卡洛积分干嘛呢？

所以我们来举一个最简单的例子。比如说我们在 $[0, 2\pi]$ 上去积分 $\sin x$，是右边这幅图的红线，这红线是个 $\sin x$。然后现在我们有两个不同的概率密度函数：第一个是在 $[0, \frac{\pi}{2}]$ 上面的均匀分布，也就是说 $\text{pdf}_1$ 是 $\frac{2}{\pi}$；第二个曲线呢是在 $[0, \frac{\pi}{2}]$ 上满足 $\text{pdf}(x) = \frac{8x}{\pi^2}$ 的这样一个曲线。这曲线是右边的蓝色的线，就这个。

那么用这两个概率密度函数，谁去做蒙特卡洛积分的时候收敛速度更快呢？我们就肉眼判断一下。因为我们是要把 $f(x)$ 和 $\text{pdf}(x)$ 相除的，所以这个 $\text{pdf}(x)$ 肯定是和 $f(x)$ 越接近越好。也就是说，显然是用蓝色的这个概率密度函数去做这个重要性采样要更好。

好。最后我们再来看一下蒙特卡洛积分当中的拟蒙特卡洛法。

为什么说是拟蒙特卡洛法呢？因为蒙特卡洛法是建立在纯随机的基础上的，而纯随机的采样非常容易产生聚集。比如说在右边的这个图上，我们是求一个一维的积分，然后我们要撒 6 个点。我们看撒的这 6 个点非常不均匀，这 6 个点 3 个都……这 6 个都在一个很偏很高的位置，都在这个 2 附近。但实际上这个整个函数有非常小的值，但我们就是正好没有采样到。

所以为了解决这个问题，我们在实践当中常常去采用这个分层采样法。什么是分层采样法？就是我们先划分一个区间，再在每个区间内去做随机。比如说右边右下角这个图，我们先把上面这个函数给它划分划分成若干个区间，这个区间、这个区间、这个区间。然后我们在每个区间内随机取一点，每个区间内随机取一点。

这东西是不是有点像回归到我们一开始说去估算定积分的这个矩形法？它是有稍微有一点像，但它现在的唯一区别就是我们原来在每个矩形的时候，我们可能都取这个矩形的中点的值。但现在我们可以看到我们不一定要取这段的中点，我们可以取在比较歪的地方。也就是说我们在每个区间内随机取一个点。也就是说它兼具了我们刚刚说的这个矩形法和蒙特卡洛法的优点。我们相当于把这两个东西给 bind 起来，所以我们叫它拟蒙特卡洛法。

或者呢，我们又把用这样的方式去做出来的这种分层采样的结果称之为低差异序列。

什么叫低差异序列呢？差异就是对刚刚我们说的聚集的反义词。低差异序列是说，我们去算下列两个量之差的最大值。首先我们在要积分的区间内任取一个子区间，这个子区间和总区间长度它会有一个比值；然后我们看该子区间内采样数和总采样数之间它也有一个比值。我们把这两个比值相减，我们希望这两个值相减的差，它的最大值尽量的小。

这个说法非常的拗口，但是总之一句话，就是它在逻辑上会产生一个更近似于分层采样的结果，而不是一个纯随机的结果。因为分层采样能保证在每一个区间内它至少都会产生……每一个划分的区间内它都至少产生一个点，而纯随机的方法完全不保证这一点。

在整个 20 世纪当中，大家在研究随机性算法的时候已经发现了很多这样的低差异序列。以一维为例，最简单的就是这个 van der Corput 序列，我们叫它 VC 序列吧。这个 VC 序列它是怎么做呢？它其实非常的简单。比如说我们在十进制之下数数，先算 1, 2, 3, 4 一直到 9 对吧。这是个位数，个位数比它大的这个进制的底数是 10，所以我们就 $\frac{1}{10}$, $\frac{2}{10}$ 这样一直到 $\frac{9}{10}$，也就是 0.1 一直到 0.2, 0.3 一直到 0.9。然后区别从 10 开始。我们数数数到 10，比 10 大的这个十进制之下底数是 100。这时候我们把 10 的分子和分母颠倒一下，变成 01，然后 01 除以 100 等于 0.01。然后我们再数 11，因为 11 的个位和十位是一样的，所以它还是产生 0.11。我们再看 12，12 我们把个位跟十位颠倒，变成 21，然后 $\frac{21}{100}$ 等于 0.21。以此类推，一直到 100。我们数数数到 100，100 比它大的十进制底数是 1000。我们把 100 颠倒变成 001，001 除以 1000 是 0.001。然后类似的 0.101，0.201。这个产生的 VC 序列就是一个低差异序列，在数学上可以证明它的差异会有一个上界。

而且这个算法是可以迭代地往下box去做的。就是我们产生前 100 个序列，长度为 101 的 VC 序列是长度为 100 的 VC 序列直接在后面补一个数。这个性质也非常的方便。

好。那么刚刚我们给出了一个一维的低差异序列，现在我们想看高维的低差异序列该怎么产生呢？我们把 $k$ 进制之下的一维的 VC 序列记为 $g(k, i)$。因为我们刚刚给的其实是一个十进制的 VC 序列的产生方法，就是这个数数的方法。$k$ 进制是一样的呀，$k$ 进制是一样的。就比如说三进制，你就是 $\frac{1}{3}$, $\frac{2}{3}$，然后就是 $\frac{0}{3}$, $\frac{1}{3}$, $\frac{2}{3}$, $\frac{3}{9}$ 这种往下走。

我们记 $k$ 进制之下的一维 VC 序列是 $g(k, i)$，然后我们就可以去制造一个高维的 Halton 序列。Halton 序列是怎么做呢？我们找出 $n$ 个这样的进制，找出 $n$ 个进制，从 $b_1$ 一直到 $b_n$，要求这个进制的底数都是互质的。比如说我们取质数的序列：2, 3, 5, 7 往下走。我们要求它们是互质的。

然后我每次产生，比如说这个 $x$ 方向它就是 $g(b_1, i)$，$y$ 方向就是 $g(b_2, i)$，然后 $z$ 方向就是 $g(b_3, i)$。这样我们就会产生一个三维空间当中的一个点，然后这个点它的每一个维度都是一个 VC 序列，它整个这些点的序列被称作为 Halton 序列。以二维为例，我们产生的 Halton 序列大概就长这样。长这样。我们发现它很少聚集对吧，它不是那种白噪声的那种感觉，它没有很多点堆在一起这种情况。

用这个方法去采样而不是用纯随机的方法去采样，所产生的这个蒙特卡洛算法的收敛速率是以 $\frac{1}{N}$ 作为底数，而不是我们刚刚说的 $\frac{1}{\sqrt{N}}$。快了很多，对吧。

然后类似的我们可以去造这个 Hammersley 序列。它唯一的区别在于，刚刚我们是每一个维度都是一个一维的 VC 序列，现在我们把第一个维度不让它随机，第一个维度干脆就定义成 $\frac{i}{N}$，然后第二个维度让它随机，从第二个维度往后让它随机。这个叫 Hammersley 序列。但它相较于 Halton 序列不方便的地方在于我们需要提前给订这个总采样数。它不能迭代地往上去扔点，它必须提前去决定这个采样数的数目。

用这个方式制造的二维的序列长这个样子。我们可以看到它比 Halton 序列确实还要差异更小一些，对吧。可以看到它这个聚集更少一些，而且更均匀一些，这个是 Hammersley 序列。

然后它的收敛速率仍然是 $\frac{1}{N}$ 做底数，然后分子分子的这个次幂它比它降了一下，都是 $\log N$，分子都是一个 $\log N$ 的一个多少次幂。然后 Halton 序列的这个次幂是 $n$，而 Hammersley 这个次幂是 $n-1$。这个 $n$ 是维度嘛，比如说在三维下这里就是 3，这里就是 2。也就是说 Hammersley 序列要稍微优于 Halton 序列。但是因为他要提前给订采样数，所以有时候会造成一定的困扰。

在图形学当中，大家可以去看那些渲染的框架，比如说 PBRT，比如说这个 Mitsuba，他们在真正的实现这个渲染算法的时候，基本上用的都是用 Halton 序列产生的随机数，而不是一个真正的在一个空间内去分布上去取随机数。它的优势就在于此。

好。最后我们来看一个问题，就是如何产生一个随机数。当然我们并不是说我们需要从这个数论的原理上去跟大家讲怎么产生一个 0-1 上的均匀分布的伪随机数生成器啊，这个也不是图形学的内容。我们假设我们已知计算机可以在数论基础上去实现一个 0 到 1 上的均匀分布的伪随机数生成器。现在我们希望解决的问题是：我们拿到这么样一个随机数生成器，我们怎么在一个单位球面上进行随机均匀采样？

这问题还蛮重要的对吧。因为我们比如说去做这个路径追踪、光线追踪、path tracing 的时候，你是不是有个入射角、一个出射角？我们得采样你的入射角，或者采样你的出射角对吧？你采样入射角、出射角都是在一个半球面上采样。我们希望这个采样尽量地均匀，也就是我们必须面临一个怎么在单位球面上进行随机均匀采样的问题。

这里我们给出了这种四种做法，其中每种做法都各有自己的优势。我们简要来看一下这四种做法分别是怎么去做的。

第一种做法最简单，是拒绝采样法。也就是说我们比如说我们要生成一个二维的圆的圆周上的随机数，我们先怎么做呢？我们生成这个矩形内的随机数。这个矩形内的随机数就是一个 $[-1, +1]$，然后平方这个之内的二维的一个坐标，它上面每个点的坐标我们都可以把它看成是由两个随机数组组成，然后 $u_1$ 你直接均匀分布随机数生成器生成，$u_2$ 你也这么生成，就完事了。

我们这样就可以生成一个在矩形内的随机点了。但在矩形内的随机点有的在圆内，有的在圆外对吧。你在圆内的概率是什么？你在圆内的概率是 $\pi r^2$ 或者说就是 $\pi$、$\frac{\pi}{4}$。比较大，这个数值比较大，应该已经在接近于 80% 左右。就 80% 你这样产生的随机数都在圆内。但是也有可能它在圆外。如果它在圆外，我们就直接扔掉，我们不要这个随机点。

否则呢，我们就相当于先生成了一个在圆内的随机点对吧，而且是均匀的。否则我们再把生成的这些随机点给一个个全部都投影到从圆心开始投影到这个面上，投影到周长上。这样做我们可以保证最后会生成一个在单位圆上的均匀随机采样。

但是这个方法有一定的弊端，就是你生成这个随机点的过程，并且不在其内就丢弃这个过程会浪费很多的计算资源。而且如果你的运气非常差的话，你可能一个能用的都没有，你产生的所有点都被你丢掉了。

所以有没有一些确定性的方案呢？就是我们能不能不用这个拒绝采样这个方法？也可以。

其实大家最容易想到的可能是这个三角函数变换法。这个方法是说，比如说这个方法对三维的特化是这样：三维的球面上的值我们一般是用这个球坐标来表示。球坐标会有两个角对吧，两个角，一个 $\theta$ 一个 $\phi$。

然后我们想看的是什么？我们想看的是我们变 $\theta$ 会增加多少面积，变 $\phi$ 又会增加多少面积。这个大家学过高等数学都知道，这个面积微元是什么？是 $r^2 \sin\theta\,d\theta\,d\phi$。

换句话说，对于 $\phi$ 来说是个均匀的。也就是不管你的 $\phi$ 取多少，也就是我们假设 $\theta$ 不变去改变 $\phi$ 的话，不管 $\phi$ 在哪里，它的概率密度函数都是一样的。也就是因为你的 $\phi$ 可以取 0 到 $2\pi$，而 $u_2$ 生成的是一个 0-1 之上的随机数，我们直接对它乘以 $2\pi$ 就会得到 $\phi$。好，这个问题就解决了。

我们关键是要看这个 $\theta$。这个 $\theta$ 它是一个什么？它是一个 0 到 $\pi$ 之间的数。我们看在 $\phi$ 不变的情况下，去改变 $\theta$ 它会改变多少面积。也就是我们可以这样去看，我们从 0 去积分，积分到某一个 $\theta$。我们可以去算这么一个积分。这积分等于什么呢？它等于……

$-\cos\theta$，然后一个取 $\theta_0$，一个取 $0$。这是什么呢？这是 $1 - \cos\theta_0$。

也就是说你的面积，你从球坐标的顶开始一直往下算，你产生的这个圆周的面积相对于 $\theta$ 的变化率是这个，是 $1 - \cos\theta_0$。

也就是说我们的理想情况应该是这个东西它是一个随机数。这个分布函数，这个累积的面积分布函数它是一个随机数。当然前面其实还应该有一个系数。

为什么有这个系数？因为从 $0$ 到 $\pi$ 去做这个积分，如果我们要把它变成分布函数的话，就是从 $0$ 到 $\pi$ 去做这个积分，积出来的数值是 $2$，对吧？我们要给它归一化，所以前面还要乘一个 $\frac{1}{2}$。

也就是说我们希望这个东西它是一个分布函数，所以我们要令这个东西等于一个随机数。变换一下就会变成 $1 - \cos\theta = 2u_1$。也就是 $\theta$ 要等于什么？$\theta = \arccos(1 - 2u_1)$，就是这个东西，$\theta = \arccos(1 - 2u_1)$。

这样我们也实现了一个在球面上的随机均匀采样，是利用这个分布函数来推导的。

然后第三种方案相对来说就比较巧妙了，它是利用了我们上节课说到的高斯分布的一个性质。

高斯分布有一个非常好的性质，就是我们产生一个二维的高斯分布，它在任何一个方向上去看它都是一个高斯分布。也就是如果我们有一个随机变量，这个随机变量我们叫它 $v$ 吧，$v_1$ 和 $v_2$ 都是满足高斯分布的话，我们把这个随机变量去点乘任何一个方向向量，它也依然是一个高斯分布。

所以我们可以做的事情就是，我们先在每个方向上都去生成一个 $n$ 维的高斯分布。比如 $v_1, v_2$，三维里面就 $v_1, v_2, v_3$，这是个高斯分布。然后它在每个方向上都是一个相同的高斯分布，所以我们可以把这个高维的高斯分布给它投影到一个球面上，它依然也是均匀的。

这个方法很巧妙，但是它唯一的问题在于生成高斯分布本身并没有那么容易，它需要用 Box-Muller 变换。也就是说我们先要从一个均匀的分布开始去得到一个二维的高斯分布，然后再从二维的高斯分布出发去得到一个任意维的高斯分布。大家可能会奇怪为什么从均匀分布开始要先得到一个二维的高斯分布？因为高斯分布的分布函数是一个超越函数，它是没办法积出来的。所以为了简便计算，我们一般会选择一个二维的高斯分布，因为这时候它的累积分步函数不再是一个超越函数了。有关 Box-Muller 变换的内容大家可以课后去了解一下。但总之，这个方案就是我们可以先生成二维的高斯分布，再把二维高斯分布变成任意维的高斯分布。

生成二维高斯分布的方法我们这里也直接给出了，就是我们先拿到一个 $0$ 到 $1$ 上的随机变量，$u_1, u_2$ 分别都是 $0$ 到 $1$ 上的随机变量，然后 $-2\ln(1 - u_1)\cos(2\pi u_2)$ 会得到第一个满足高斯分布的随机变量，然后乘以 $\sin$ 会得到第二个满足高斯分布的随机变量。

最后一种在球面上进行随机均匀采样的方法看起来比较麻烦，但实际上实现起来的效率甚至比前面的某些方法还要高。它的做法大体上来说是我们先用一个拒绝采样去产生一个圆盘，就是刚刚我们说的在矩形当中我们先用拒绝采样去产生一个圆盘，再用这个圆盘给它进行变换得到一个球。

这个过程的好处是它从头到尾不涉及三角函数运算。我们可以看到这个方法有 $\arccos$，这个方法有 $\cos$ 和 $\sin$，而基于圆盘的这个方法，圆盘到球的方法它从头到尾不会产生任何的三角函数运算，所以它速度反而很快。

这件事情大家可能会问：那你既然都已经用了拒绝采样，你为什么不直接让它在球面上生成一个 $-1$ 到正 $1$，这里写 $3$，然后再把它投影到球面上，而你非要先把它生成到圆盘，然后再把圆盘给映射成一个球呢？

这个问题就在于我们刚刚给出的，在一个正方形内去拒绝采样产生一个圆内的概率是 $80\%$ 左右，而如果是一个球内呢，它会变成这个概率。

也就是在这个地方的分母上乘了 $2$，但在分子上乘了 $\frac{4}{3}$。我们知道 $\frac{4}{3}$ 是小于 $2$ 的，也就是说总共我们把这个概率乘了个 $\frac{2}{3}$。现在我们直接在一个正方体内产生一个随机数，它在球内的概率只有 $80\% \times \frac{2}{3}$。

所以这个概率已经快不足一半了，对吧？已经快不足一半了。所以我们先产生一个圆盘，它的好处在于用拒绝采样扔掉的点会比直接产生球内的随机数要少得多。

以上就是关于如何在单位球面上进行随机均匀采样的几种不同的思路。这些思路其实实现的细节二、三当中已经给出了，直接照抄这个式子就可以了。第四种映射的方法受限于它写很长，大家可以自己去看一下。
