# GAMES001：图形学中的数学（16 讲）

GAMES001 是图形学的数学总览课，用 16 讲讲清图形学真正用到的数学：线性代数与矩阵分解、计算几何、三维旋转、SVD/PCA、插值拟合、傅里叶与球谐、概率论、场论与微分几何、数值方法与拓扑。它的定位是索引课——不追求把每门数学从头证到尾，而是告诉你每块数学在图形学的哪个环节用到、关键概念与结论是什么。16 集整编为 6 册模块全书与 14 篇主题复习笔记。

## 怎么学
- **当索引书用**：先通读一遍建立地图，之后遇到具体问题再回来查对应专题。
- **线性代数与矩阵分解是底盘**：向量、矩阵与线性映射 → 矩阵范数、矩阵求导与张量，两册连起来看。
- **旋转与四元数必须动手推**：旋转矩阵、欧拉角、罗德里格公式、四元数，光看结论容易在正负号上翻车。
- **傅里叶与球谐按「换一组基」理解**：先抓基变换与卷积定理，再看球谐在环境光照里的用途。
- **概率与蒙特卡洛连起来学**：概率基础 → 噪声与蒙特卡洛积分，这是渲染采样与降噪的语言。
- **最后的拓扑当视野扩展**：从七桥问题到庞加莱猜想，理解「连续形变下什么不变」。
