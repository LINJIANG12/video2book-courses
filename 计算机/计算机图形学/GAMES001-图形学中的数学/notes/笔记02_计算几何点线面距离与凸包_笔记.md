# 计算几何：点线面、距离与凸包

## 计算几何的定位

* **计算几何（Computational Geometry）**

    * > **定义**：研究用算法解决几何问题的学问，是计算机科学下的一个研究分支，更进一步说是图形学的一个研究分支；用到的工具直接接触数学。

    * 历史：至今约 50 多年；三角剖分、凸包、扫描线都属于计算几何。

    * 特点：相比别的算法，它需要处理实数而不是整数，并且需要关心向量——关心的是低维向量，而不是线性代数基础里那种高维向量或标量。

    * 与竞赛（OI）计算几何的关系：二维计算几何仍然是三维计算几何的基础，二维算法基本通用；图形学在三维问题上要求更多，核心问题是如何把二维计算几何拓展到三维。

    * 研究目标：降低在计算机中解决几何问题的复杂度与数值误差；数值误差超出该课程范畴，由更专业的课程处理。

## 坐标系与左右手系

* **坐标系**

    * > **定义**：由原点和坐标轴构成；原点的选取理论上是任意的，真正要关心的是坐标轴的选取。

    * 坐标轴希望尽量取单位正交——单位正交的基底下内积非常好算；单位正交基底构成的坐标轴叫笛卡尔坐标，三维笛卡尔坐标就是 X、Y、Z 三个轴。

* **轴色对应**

    * 一般情况下 XYZ 三个轴正好和 RGB 三种颜色对应；软件没标谁是 X、Y、Z 但画了红绿蓝线时，颜色就确定了这套软件的 XYZ 排布。

* **常用软件的坐标系约定**

| 代表软件 | 竖直轴 | 手性 | 轴向细节 |
| :--- | :--- | :--- | :--- |
| Houdini、Maya | Y 轴 | 右手系 | X 指向屏幕右侧，Y 指向屏幕上方，Z 垂直屏幕朝外 |
| Unity3D | Y 轴 | 左手系 | 与上一种唯一的区别：Z 垂直屏幕朝内 |
| Blender | Z 轴 | 右手系 | Z 指向屏幕上方，Y 垂直屏幕朝内 |
| Unreal | Z 轴 | 左手系 | Z 轴竖直 |

* **手性约定**

    * 使用图形学软件前一定要先搞清楚它的坐标轴按什么方向选取——四种主流软件的坐标系全都不一样。

    * 一般默认 OpenGL 是右手系、D3D 是左手系；这并不是 API 内部规定，而是它们官方实现的库做了这样的假设。

* **握拳判定法**

    * 左手握拳，除拇指外四指从 X 方向往 Y 方向转，拇指的朝向就是 Z 轴方向；右手同理。

    * 也有用三根手指的判定做法，但推荐握拳确定法。

## 点、向量与直线的表示

* **点与向量（point / vector）**

    * > **定义**：点可以和向量等同使用——点可以看成从原点到这个点的位置向量。

    * 许多图形学 API 与第三方库把点和矢量分成 point、vector 两种数据结构，并对运算做严格规定；使用前要提前看库是否采用了这样的规定。

| 运算 | 结果 |
| :--- | :--- |
| point − point | vector |
| point + point | 未定义 |
| point ± vector | point |
| vector ± point | 未定义 |

* **直线与射线**

    * > **定义**：从一个点出发、沿着某个方向向量、带一个参数 $t$ 的轨迹，用参数方程 $\boldsymbol{X}=\boldsymbol{P}+t\,\boldsymbol{D}$ 规定；二维三维通用。

    * 直线和射线的唯一区别在 $t$ 的取值范围：直线取 $(-\infty,+\infty)$，射线取 $[0,+\infty)$。

    * > **易错点**：⚠️ 对直线来说，$\boldsymbol{P}$ 可以是它上面的任何一个点；对射线来说，$\boldsymbol{P}$ 必须是射线发射的端点。

* **线段**

    * 设两个端点 $\boldsymbol{P}_1$、$\boldsymbol{P}_2$，参数方程为 $\boldsymbol{X}=\boldsymbol{P}_1+t(\boldsymbol{P}_2-\boldsymbol{P}_1)=(1-t)\boldsymbol{P}_1+t\boldsymbol{P}_2$；这些表示对二维和三维都成立。

## 平面、半空间与三角面片

* **平面的隐式方程**

    * > **定义**：$(\boldsymbol{X}-\boldsymbol{P})\cdot\boldsymbol{N}=0$，其中 $\boldsymbol{P}$ 为平面上任一点、$\boldsymbol{N}$ 为法向量；无穷大的平面用隐式方程表示，没有参数。

    * 面是一个三维的量，不存在二维的对应物。

    * 判定方式：点 $\boldsymbol{X}$ 与 $\boldsymbol{P}$ 的差向量点乘法向量 $\boldsymbol{N}$ 等于零，$\boldsymbol{X}$ 就一定在平面上——法向量垂直于平面内所有的线向量。

* **半平面与半空间**

    * > **定义**：$(\boldsymbol{X}-\boldsymbol{P})\cdot\boldsymbol{N}\le 0$ 指该平面以下的所有空间；它其实不是平面，而是一半的空间。

    * > **易错点**：⚠️ 到了半空间，法向量的正负就有意义了：把法向量取负号，它指代的就是原来的上半部分空间。

* **三角面片的参数方程**

    * 设三个顶点 $\boldsymbol{P}_1$、$\boldsymbol{P}_2$、$\boldsymbol{P}_3$：

    $$\boldsymbol{X}=\boldsymbol{P}_1+u(\boldsymbol{P}_2-\boldsymbol{P}_1)+v(\boldsymbol{P}_3-\boldsymbol{P}_1)=(1-u-v)\boldsymbol{P}_1+u\boldsymbol{P}_2+v\boldsymbol{P}_3$$

    * 推导：先在 $\boldsymbol{P}_1$ 与 $\boldsymbol{P}_2$ 之间取点 $\boldsymbol{X}'$（满足线段参数方程），再在 $\boldsymbol{X}'$ 与 $\boldsymbol{P}_3$ 之间取点 $\boldsymbol{X}$（同样满足线段参数方程）；两次线段插值复合起来，$\boldsymbol{X}$ 就扫遍了整个三角形。

    * 令 $u=(1-t)(1-t')$、$v=(1-t)t'$、$w=t$，得 $\boldsymbol{X}=u\boldsymbol{P}_1+v\boldsymbol{P}_2+w\boldsymbol{P}_3$，满足 $u+v+w=1$；由于系数都是 $(1-t')$ 与 $t'$ 这种成对出现，$u,v,w$ 必然都是 0 和 1 之间的量。

## 点与直线的距离和投影

* **维度通用性**

    * 这套定义点、线、面的方法，使距离计算公式与维度无关——二维三维都可以用同样的方法计算，不注明维度即两者通用。

* **点到直线的距离**

    * 给定直线参数方程 $\boldsymbol{X}=\boldsymbol{O}+t\boldsymbol{D}$ 与点 $\boldsymbol{P}$，距离为：

    $$d=\frac{\left|(\boldsymbol{P}-\boldsymbol{O})\times\boldsymbol{D}\right|}{|\boldsymbol{D}|}$$

    * 机理：$\boldsymbol{P}-\boldsymbol{O}$ 与 $\boldsymbol{D}$ 张成一个三角形，叉乘得到的其实是这个三角形面积的二倍；再除以底边长 $|\boldsymbol{D}|$，得到沿 $\boldsymbol{D}$ 这条边的高，即 $\boldsymbol{P}$ 到直线的距离。

* **点到直线的投影**

    * 做法：在直线上找一个点，使它与 $\boldsymbol{P}$ 的差向量和方向向量 $\boldsymbol{D}$ 垂直，即 $(\boldsymbol{P}-\boldsymbol{O}-t\boldsymbol{D})\cdot\boldsymbol{D}=0$。

    * 展开得到关于 $t$ 的一次方程，解出 $t$ 带回直线方程，即得投影点的位置坐标。

* **点到射线的距离**

    * 先确定投影参数 $t$：$t\ge 0$ 时就是到直线的距离；$t< 0$ 时最小值点在射线端点之外，最近距离直接取该点与射线端点的距离。

## 点与平面的距离

* **点到平面的距离**

    * 平面 $(\boldsymbol{X}-\boldsymbol{P})\cdot\boldsymbol{N}=0$ 外一点 $\boldsymbol{X}$ 的距离：

    $$d=\frac{\left|(\boldsymbol{X}-\boldsymbol{P})\cdot\boldsymbol{N}\right|}{|\boldsymbol{N}|}$$

    * 即在平面上任取一点 $\boldsymbol{P}$，把平面外这一点与 $\boldsymbol{P}$ 的差向量投影到法向上。

    * 结果不受 $\boldsymbol{P}$ 选取的影响：取平面上别的任何一点 $\boldsymbol{P}'$，$\boldsymbol{P}'-\boldsymbol{P}$ 是与法向垂直的向量（平面内所有向量都垂直于法向），点乘后都会消掉。

    * 与高数公式 $d=\dfrac{|Ax+By+Cz+D|}{\sqrt{A^2+B^2+C^2}}$ 等价：把点乘全部拆开成分量计算，$\boldsymbol{N}=(A,B,C)$，就整理成 $Ax+By+Cz+D$ 的形式，两者完全一致。

* **为什么用向量形式**

    * 向量形式自动适用于二维：二维直线 $Ax+By+C=0$ 外一点到直线的距离 $d=\dfrac{|Ax+By+C|}{\sqrt{A^2+B^2}}$，与三维形式完全一致——同一个式子既求二维点线距离，也求三维点面距离。

    * 因此计算几何倾向用向量的形式表达，而不是完全展开的解析形式。

* **参数表示与隐式表示的选择**

    * 一般选择：直线用带参数 $t$ 的参数表示——取方向向量与步长很直接；三维平面用隐式的 $(\boldsymbol{X}-\boldsymbol{P})\cdot\boldsymbol{N}=0$ 表示。

    * 平面要参数化得先取平面上任意两个切向量、再构建坐标轴，过程不是唯一确定的，一般不这么做；直线其实也能隐式表示（差向量与直线朝向叉乘等于零），但一般不用。

    * 三角形的表达式是参数表达的例子——三个顶点刚好给出一组切向量的表达方式。

## 二维线线关系

* **共端点射线（线段）的绕序**

    * 两条射线端点同为 $\boldsymbol{O}$、方向向量 $\boldsymbol{D}_1$、$\boldsymbol{D}_2$（线段则取 $\boldsymbol{OP}_1$、$\boldsymbol{OP}_2$），两种定义得到同样的判定：直接拿 $\boldsymbol{D}_1$ 叉乘 $\boldsymbol{D}_2$。

    * > **提示**：这里的叉乘限缩在二维：$\boldsymbol{D}_1\times\boldsymbol{D}_2=x_1y_2-x_2y_1$，得到的是一个实数。

    * 判定表：

| $\boldsymbol{D}_1\times\boldsymbol{D}_2$ | 含义 |
| :--- | :--- |
| 大于零 | 射线二在射线一的左边（逆时针转角小于 180°） |
| 小于零 | 射线二在射线一的右边（顺时针转角小于 180°） |
| 等于零 | 射线二与射线一重合，或者反方向 |

* **叉乘为零时的细分**

    * 用点乘进一步判断：重合得到的点乘值大于零，反方向得到的点乘值小于零。

* **二维直线与直线的交点**

    * 两直线 $\boldsymbol{X}_1=\boldsymbol{O}_1+t_1\boldsymbol{D}_1$、$\boldsymbol{X}_2=\boldsymbol{O}_2+t_2\boldsymbol{D}_2$：直线二上参数为 $t_2$ 的点落在直线一上，等价于它与 $\boldsymbol{O}_1$ 的差向量与 $\boldsymbol{D}_1$ 平行，即 $(\boldsymbol{O}_2+t_2\boldsymbol{D}_2-\boldsymbol{O}_1)\times\boldsymbol{D}_1=0$。

    * 展开是关于 $t_2$ 的线性方程，解出 $t_2$ 后取 $\boldsymbol{P}=\boldsymbol{O}_2+t_2\boldsymbol{D}_2$，即得交点位置。

* **跨立测试**

    * 用途：判断两条线段是否相交，全程只做叉乘、不做任何除法，避免「先求出交点、再讨论大于零小于零」。

    * 设线段一端点 $\boldsymbol{P}_1$、$\boldsymbol{Q}_1$，线段二端点 $\boldsymbol{P}_2$、$\boldsymbol{Q}_2$。条件一：$(\boldsymbol{Q}_1-\boldsymbol{P}_1)\times(\boldsymbol{P}_2-\boldsymbol{P}_1)$ 与 $(\boldsymbol{Q}_1-\boldsymbol{P}_1)\times(\boldsymbol{Q}_2-\boldsymbol{P}_1)$ 异号——即 $\boldsymbol{Q}_1-\boldsymbol{P}_1$ 夹在 $\boldsymbol{P}_1\boldsymbol{P}_2$ 与 $\boldsymbol{P}_1\boldsymbol{Q}_2$ 之间。

    * 条件二与之对称：$\boldsymbol{Q}_2-\boldsymbol{P}_2$ 要夹在 $\boldsymbol{P}_2\boldsymbol{P}_1$ 与 $\boldsymbol{P}_2\boldsymbol{Q}_1$ 之间。

    * 判定：两个条件都满足则两线段必有交点，满足不了则必无交点；叉乘取到等号说明交点是在端点处发生的。

## 三维异面直线的距离

* **法一：公垂线投影**

    * 先求两条异面直线的公垂线，得到法向量 $\boldsymbol{N}$（它决定一个平面的朝向）；在两条直线上各任取一点，两点间向量投影到 $\boldsymbol{N}$ 上，得到的就是两直线的最近距离。

* **法二：优化求极值**

    * 把 $t_1$、$t_2$ 都当未知数，写出两点之间模长的表达式，分别关于 $t_1$、$t_2$ 求偏导、令其为零——把距离变成优化问题求极值。

* **异面线段的距离**

    * 把两条线段投影到同一个平面内做跨立测试：投影后在同平面内相交，最近距离仍用法一（公垂线投影）求；不相交，最近距离就发生在端点处，需要重新讨论。

    * 觉得麻烦也可以直接转成优化问题求极值。

## 多边形的周长与面积

* **周长**

    * 遍历多边形的每条边，计算模长求和。

* **带符号面积的约定**

    * 假定多边形是用逆时针序给出的；把不是逆时针序（顺时针序）的三角形面积记作负值。

* **三角形面积**

    * 叉乘法：$A_{123}=\dfrac{1}{2}(\boldsymbol{P}_2-\boldsymbol{P}_1)\times(\boldsymbol{P}_3-\boldsymbol{P}_1)$——叉乘的定义正好可以用来算二维三角形的面积。

    * 任取参考点法：在平面内任取一点 $\boldsymbol{P}_0$，先算 012 的面积、再算 023 的面积、减掉 013 的面积（即加上 031 的面积）：$A_{123}=A_{012}+A_{023}+A_{031}$；除 0 不变外，下标 12、23、31 正好按逆时针序遍历三角形的每一对顶点。

* **任意多边形的面积**

    * $A=\sum_i A_{0ij}$：任取平面内一点 $\boldsymbol{P}_0$，$ij$ 按逆时针序遍历多边形的每一对相邻顶点；凸四边形即 $A_{012}+A_{023}+A_{034}+A_{041}$（其中 $A_{041}$ 实际是减去 $A_{014}$）。

    * 适用范围：凸、凹多边形都适用——凹多边形用从固定顶点做扇形剖分的方法求不出正确面积，而 $A_{0ij}$ 方法不会出错。

## 点与凸多边形

* **面积法**

    * 记 $A$ 为带符号面积求和的结果（即多边形面积），$A'$ 为求和过程中每一项都取绝对值后的结果。

    * 判定：$A'=A$，参考点一定在多边形内；$A'\ne A$（更大），参考点一定在多边形外——只有参考点取在外面时，才会出现有的三角形面积是负数的情况。

* **绕序法**

    * 在多边形内取一点 $\boldsymbol{P}_0$：$\boldsymbol{P}_0$ 在每一条边对应向量的左边，如 $(\boldsymbol{P}_2-\boldsymbol{P}_1)\times(\boldsymbol{P}_0-\boldsymbol{P}_1)>0$、$(\boldsymbol{P}_3-\boldsymbol{P}_2)\times(\boldsymbol{P}_0-\boldsymbol{P}_2)>0$ 对每条边都成立，则 $\boldsymbol{P}_0$ 一定在凸多边形内部；但凡在某一条边的左边不成立，它就不在内部。

* **拓展到三维**

    * 多面体体积：把 $A_{0ij}$ 换成 $V_{0ijk}$，把有向三角形换成有向的四面体。

    * 点与凸多面体：点在凸多面体每一个面的「左边」（落在每一个半空间的同一方向）就在内部，否则在外部。

## 点与任意多边形

### 光线投射法

* **理论基础：若尔当曲线定理**

    * > **定义**：任何一条简单闭曲线可以将平面分成两部分；连接同一部分任意两点的弧，与该曲线不相交，或者相交偶数次；连接不同部分两点的弧，与该曲线相交奇数次。

* **判定规则**

    * 把多边形取成定理里的简单闭曲线，从判断点出发随便发一条射线当作「弧」；无穷远点一定在多边形外，因为多边形是有限大的图形。

    * 射线与多边形的交点个数是奇数，点就在多边形内；交点个数是偶数，点就在多边形外——射线每与多边形相交一次，内外关系就改变一次。

* **射线撞顶点的处理**

    * 特殊情况：射线正好撞到顶点（或与边重合）时，算相交一次还是两次很难处理。

    * 简单解法：取射线时不要沿 X 轴，把射线夹角取成 $\pi$ 的无理数倍，与顶点重合的概率就几乎为零。

    * 健壮解法：规定射线上的点以及射线上方的点算「上方」，否则算「下方」；射线与某条边相遇时，只有这条边的两个端点分别在上方和下方，才算相交。

    * 规则效果：射线穿过顶点时该顶点算上方——与顶点相连的入边、出边各有一端在上一端在下，各计相交一次合计 2（判在外）；若一条相邻边两端都在上方则不计，只剩另一条计入合计 1（判在内），从而规避掉数值上的歧义。

### 回转数法

* **回转数**

    * > **定义**：用曲线绕过某一点的次数判断内外：回转数等于回转角 $\theta$ 除以 $2\pi$；多边形内的点绕过次数是 1，多边形外的点是 0。

    * 回转角的计算：对多边形上每一条边，从判断点看这条边的两个端点得到两个方向向量，求它们之间带符号的夹角 $\theta_i$——逆时针扫过记正、顺时针记负；把每个 $\theta_i$ 相加就是回转角 $\theta$。

    * 内点例：三角形内部点三边夹角之和正好等于 $2\pi$，回转数为 1；外点例：先出现正的 $\theta_1$、$\theta_2$，后面的负夹角正好抵掉，总和为 0，回转数为零。

* **取值范围**

    * 方向约定：逆时针绕一圈记 1，顺时针绕一圈记 −1；回转数绝对值可以大于 1——绕某个点转两圈回转数就是 2。

    * > **易错点**：⚠️ 考察的对象是多边形——简单多边形不可能自己和自己相交，所以多边形对任何一个点的回转数只可能是 1 或 0（把方向算上就是 ±1 或 0）；不要把一般曲线「绕很多圈」的情形套到多边形头上。

## 点到三角形的距离

* **应用背景**

    * 求点到 mesh（由三角形面片组成）的距离，相当于对 mesh 上每一个 face 求点到该 face 的距离再取最小值；这是图形学很重要的计算几何应用。

* **二维算法**

    * 点在三角形内，距离显然是 0。

    * 点在三角形外：先把最近距离设为 $\boldsymbol{P}$ 到三个顶点距离的最小值；再把 $\boldsymbol{P}$ 逐条边投影——投影点落在边的延长线上则这个候选舍弃，落在两端点之间则用这个点到这条边的距离更新最小值；顶点候选加有效投影候选做完即得最近距离。

* **三维算法**

    * 先把 $\boldsymbol{P}$ 投影到三角形所在的平面：投影点落在三角形内，距离就是点到平面的距离。

    * 投影点落在三角形外，距离用勾股定理：$d=\sqrt{h^2+d_{\mathrm{proj}}^2}$，其中 $h$ 是 $\boldsymbol{P}$ 到三角形所在平面的距离，$d_{\mathrm{proj}}$ 是投影点到三角形的二维最近距离——和二维几乎一样，只多了一个投影过程。

* **免分类讨论：转成优化问题**

    * 利用三角形的参数表达 $\boldsymbol{X}=u\boldsymbol{V}_0+v\boldsymbol{V}_1+w\boldsymbol{V}_2$（$u+v+w=1$，$u,v,w\ge 0$），把三角形内的参数点与三角形外那一点做差得到优化函数，在该约束下求最小值，回避「投影点在不在延长线上」的讨论。

    * 优化问题如何求解，是课程后面的内容。

## 两个三角形之间的距离

* **问题来源**

    * 求两个 mesh 之间的距离，可以拆成「两个三角形之间的距离」来算。

* **二维**

    * 定理：二维中两个三角形的最近距离，必然在其中一个三角形的顶点上取到。

    * 算法：把一个三角形的三个顶点分别对另一个三角形求一遍最近距离，再倒过来用另一边三个顶点求一次，6 个值取最小即两三角形的最近距离。

    * 另一种求法：18 组「点-边」距离取最小——任一三角形的某个顶点与另一个三角形的三条边各求一次最小值，3 个顶点 × 3 条边 × 两个方向正好 18 组；同样建立在上述顶点定理的基础上。

* **三维**

    * 取 6 组「点-面」距离（每个三角形的 3 个顶点分别对另一三角形面片求一次）不一定能找到最近距离：反例是两个三角形一上一下错开摆，最近距离取在上面三角形的一条边与下面三角形的一条边之间，不取在任何顶点上。

    * > **注意**：三维中两个三角形的最近距离 = min（6 组点-面距离的最小值，9 组边-边距离的最小值），两种情况都要算。

## 离散与连续碰撞检测

* **离散碰撞检测（Discrete Collision Detection，DCD）**

    * > **定义**：直接求两个三角形网格之间的距离——它的最基本算法就是前面的 mesh 距离计算；mesh 到 mesh 的距离在计算机图形学中最主要的作用就在碰撞检测上。

* **连续碰撞检测（Continuous Collision Detection，CCD）**

    * > **定义**：三角形网格上每个顶点不仅有位置还有速度，要求两个三角形经过多长时间会接触。

    * 做法：同样考察 6 组点-面和 9 组边-边，列出共面方程判断它们什么时候共面；每一个共面方程都对应一个关于时间 $t$ 的一元三次方程，解出 $t$ 后再判断共面的那一刻是否真的发生了接触。

    * 实现上比较困难。

## 德洛内三角剖分与沃罗诺伊图

* **三角剖分**

    * > **定义**：将点集连接为三角网格，使得各个三角形的边互不相交——一个简单的网格。

* **德洛内（Delaunay）三角剖分**

    * > **定义**：满足以下性质的三角剖分：空圆性——任意三角形的外接圆内都没有别的点；规则化（最大化最小角）——所有三角剖分中，德洛内剖分所得三角形内角的最小值是最大的。

    * 结果唯一：不论用什么算法求得，三角剖分一定是一样的。

    * 局部性：增删改顶点都只影响局部——新加一个顶点，顶多把原来的剖分局部翻转一下，不会影响别的位置。

    * 外层是凸的：三角剖分的最外层一定会形成一个凸多边形。

    * 它是定义在二维上的内容；求三角剖分的算法比较繁琐、超出数学范畴，属计算几何专门内容。

* **沃罗诺伊（Voronoi）图**

    * > **定义**：将平面划分为若干由「最近的控制点」决定的区域——保证平面内任何一个点，所属区域都是离它最近的那个控制点。

    * 对偶关系：在三角剖分的每一条边上取中垂线，这些中垂线自然相交，相交结果就形成 Voronoi 图——很容易证明 Voronoi 图就是德洛内三角剖分的对偶图。

## 凸包与包围盒

* **二维凸包**

    * > **定义**：平面上能包含给定点的最小的凸多边形。

* **轴对齐包围盒（AABB）**

    * > **定义**：包含整个点集的、与坐标轴平行的矩形。

    * 凸包一定在 AABB 之内（凸包比外面的框小一圈）——AABB 是凸包最粗糙的近似。

* **方向包围盒（OBB）**

    * > **定义**：包含给定点的最小的矩形，放宽了「轴对齐」限制——矩形可以斜着取。

    * 斜着取的取法不一定最优，但通常比轴对齐的矩形要小。

* **固定方向凸包**

    * > **定义**：要求凸包的各个边（或面）的法向只能在给定的集合当中选取。

    * AABB 就是固定方向凸包的特例（边只能取横平竖直那几种）；放宽到允许斜 45 度的边等更广的法向集合，拼出的结果就比 AABB 更接近真正的凸包。

* **四种包围结构对比**

| 包围结构 | 约束 | 和真凸包的关系 |
| :--- | :--- | :--- |
| 凸包 | 无——最小的凸多边形 | 本尊，最精确的表示 |
| AABB | 矩形，且与坐标轴平行 | 最粗糙的近似（凸包必在其内） |
| OBB | 矩形，方向不限 | 放宽轴向限制，通常比 AABB 更小 |
| 固定方向凸包 | 边/面的法向只能从给定集合中选 | 法向集合越丰富越贴近真凸包；AABB 是它的特例 |

## Graham 扫描

* **二维点集的两条性质**

    * 点集中纵坐标最小的点一定在凸包上——它底下没有别的点了，凸包要包含所有点，正好过它是最优的。

    * 在凸包上逆时针走，所经过的边一定都是左拐——这是凸包是简单凸多边形的直接体现。

* **算法步骤**

    * 把纵坐标最小的点 $\boldsymbol{P}_0$ 压入栈中。

    * 把其余所有点按照相对 $\boldsymbol{P}_0$ 的极角排序（极角逐渐增大）。

    * 先将 $\boldsymbol{P}_0$ 和排序后第一个点压入栈，然后依次考察排好序的点：栈顶两点连向新点若是左转（符合凸包性质）就入栈；若是右转就弹出栈顶、重新判断，直到恢复左转为止。

    * 重复直到遍历完所有点，栈里剩下的就一定是一个凸包。

    * 过程示例：

    ```text
    入栈 P0, A               -> 栈 [P0, A]
    考察 B: P0A->AB 是左转    -> 入栈 B    栈 [P0, A, B]
    考察 C: AB->BC 是左转     -> 入栈 C    栈 [P0, A, B, C]
    考察 D: BC->CD 是右转     -> 弹出 C    栈 [P0, A, B]
    考察 D: AB->BD 是左转     -> 入栈 D    栈 [P0, A, B, D]
    遍历结束：凸包就是栈里的点 [P0, A, B, D]
    ```

* **复杂度**

    * $O(n\log n)$，主要时间代价在极角排序这一步——只要排序能做得更快，这个复杂度还能再降，效率是比较高的。

## 三维凸包

* **难点**

    * 三维不存在极角序，没有二维那么好的性质。

* **增量法**

    * 思路：先假定已知 $n-1$ 个点的凸包，再考察一个新点——新点只要在每一个面的左侧就在凸包内，凸包不变。

    * 新点不在凸包内：以该点为光源向四面八方发射光线，在凸包上形成一条明暗分界线，且这条分界线一定由凸包的棱组成；把能被照到的亮面全部删除，再连接光源（新点）与分界线，就得到加入新点后的凸包。

    * 复杂度是 $O(n^2)$ 量级：每次考察新点要判断它在不在每一个面的左侧，还要遍历每条边、考察能不能被光源照到，复杂度不可避免地高。

* **多点共面**

    * 没有什么特别好的处理办法，一般大家对输入点做随机扰动来避免共面。

* **暴力法**

    * $n$ 个点构成 $\binom{n}{3}$ 个候选三角形，凸包上的三角形一定由其中一些组成；遍历候选，只要其余所有的点都在这个三角形的左侧（要么是它的顶点、要么在它左边），它就在凸包上。

    * 复杂度是四次方量级：$\binom{n}{3}$ 个候选面，每个还要对全部 $n$ 个点判一次侧。

* **快速凸包法（QuickHull）**

    * 逻辑与增量法完全一致，只是每次选的点不是随便取，而是挑离当前凸包最远的那个点，以此保证三维凸包构造的复杂度尽量低。

    * 实现并没有那么容易；开源计算几何库一般都有快速凸包法（也包括三角剖分），可以直接调库。

## 平面最近点对

* **平面最近点对**

    * 在图形学中有应用；常用 kd 树求解——kd 树不仅能适用于二维，也适用于三维，而且除了最近点对还能找别的东西。

    * 它也是分治算法的一道经典例题。

## 最小圆覆盖

### 最小覆盖圆的三种形态

* **最小覆盖圆**

    * > **定义**：包围该点集的最小的圆；凸包一定在最小覆盖圆内。

* **只有三种可能**

    * 圆心在某一点处、半径为零——点集里只有一个点时，最小覆盖圆就是它。

    * 圆心在两点的中点处，直径是两点的距离。

    * 圆心由三个点决定——这三点构成的三角形的外接圆，半径是外接圆的半径。

    * 感性理解：从最外层的大圆不断缩小半径，直到圆碰到点集中的某一个点；再移动圆心使正好有三个点落在圆上，得到的就是最小覆盖圆；两点情形即以连线为直径的圆。

### 随机增量算法

* **增量关系**

    * 给定 $n-1$ 个点的最小覆盖圆，第 $n$ 个点要么在圆内（什么都不用做），要么最终的新覆盖圆一定要过这个点——因为没有比它更靠外的点。

* **三层循环算法**

    * 相当暴力的做法，能保证最后找到的圆一定是最优的最小覆盖圆：

    ```text
    C <- 以 P1 为圆心、半径为 0 的圆
    for i = 2 .. n:
        if Pi 在 C 内: 直接进入下一次循环
        # 走到这里，说明 Pi 一定在最终的最小圆上
        C <- 以 Pi 为圆心、半径为 0 的圆
        for j = 1 .. i-1:
            if Pj 在 C 内: 直接进入下一次循环
            # Pj 一定在最终的圆上
            C <- 以 PiPj 为直径的圆      # 它一定同时包含 Pi 和 Pj
            for k = 1 .. j-1:
                if Pk 在 C 内: 什么都不做
                # Pk 一定在最终的圆上
                C <- 过 Pi、Pj、Pk 三点的三角形外接圆
    ```

* **期望复杂度 O(n)**

    * 最小覆盖圆不是可以任意取的：三个特定的点就能确定它，暴力计算只需要判断 $\binom{n}{1}+\binom{n}{2}+\binom{n}{3}$ 种情况。

    * 进入下一层循环，只发生在当前构造的最小覆盖圆必须过某个点时（必须过 $P_i$、$P_j$ 或 $P_k$），概率是当前这批点的大小分之三（$3/i$、$3/j$）；满打满算 $O(n^3)$ 量级的结构乘上 $3/n$ 再乘上 $3/n$，最终约是 $9n$。

    * 所以期望时间复杂度是线性的 $O(n)$，并不是 $O(n^3)$；这套做法就是随机增量法。

    * > **提示**：这个复杂度证明不太直观也没关系，记住结论：最小圆覆盖可以用三层循环、以期望 $O(n)$ 的时间复杂度解决。

### 最小球覆盖

* **最小球覆盖**

    * 把二维拓展到三维，三种情况变成四种：单点为球心、半径为零；两点中点为球心、半径为两点距离的一半；三点的外接圆作为球的大圆、以外接圆半径为球的半径；由四个点确定球面。

    * 进入下一层循环的概率没有变，随机增量法的期望复杂度仍然是线性，可在期望线性复杂度内构建最小球覆盖。

    * 最大的难点不是复杂度，而是求外接球的过程——求外接圆本身就不容易，求外接球更难算。

* **模拟退火法**

    * 直接随机化（优化）圆心（球心）的位置：球心给定时，半径就是它到点集里每一个点距离的最大值；以此求最小圆覆盖或最小球覆盖。

### 包围体应用

* **为什么需要包围结构**

    * 判断一个点或一条射线与某个三角形是否相交很麻烦，需要数据结构先粗糙地判断它跟「一大片三角形」是否相交——不相交，这一片三角形就都不用看了。

    * 表示一大片三角形：最精确是求这片三角形的凸包；稍微弱一点的取法是 AABB、OBB，或者求球覆盖。

* **实践选择**

    * 做光线追踪时主要用 AABB；做实时碰撞检测时用球覆盖——对球做碰撞检测最容易。

    * 碰撞判定：不把三角形看成三角形，而是把一片三角形看成一个球，两个球相交就认为两个 mesh 碰撞了，这些球都不相交就认为没碰撞；一个 mesh 可能由很多个球组成，球的具体形状就用圆覆盖或球覆盖算法确定。

## 反演变换

### 反演点

* **反演**

    * > **定义**：给定反演中心 $\boldsymbol{O}$（一个点）和反演半径 $R$（一个实数），就给定了二维中的一个圆；空间（平面）当中的每一个点，关于这个圆都有一个反演点。

    * 点 $\boldsymbol{P}$ 与它的反演点 $\boldsymbol{P}'$ 满足两条性质：$\boldsymbol{O}$、$\boldsymbol{P}$、$\boldsymbol{P}'$ 三点共线；到圆心的距离相乘等于半径的平方，即 $OP\cdot OP'=R^2$。

* **内外互换**

    * 圆 $\boldsymbol{O}$ 内的点的反演点一定在圆外，圆外的点的反演点一定在圆内——$D_1<R$ 时必须 $D_2>R$，才能保证 $D_1\cdot D_2=R^2$。

### 过圆心的圆反演成直线

* **互反关系**

    * 一个过反演圆心 $\boldsymbol{O}$ 的圆，它的反演是一条不过圆心 $\boldsymbol{O}$ 的直线；反过来，给一条不过点 $\boldsymbol{O}$ 的直线，它反演之后一定是一个过点 $\boldsymbol{O}$ 的圆。

* **推导要点**

    * 过原点的圆 $(x-x_0)^2+(y-y_0)^2=a^2$（圆心 $(x_0,y_0)$），由 $x=0,y=0$ 在圆上得 $x_0^2+y_0^2=a^2$，代回化简为 $x^2+y^2-2x_0x-2y_0y=0$。

    * 反演坐标公式：$(x,y)$ 被反演成 $(x',y')$，其中 $x'=\dfrac{R^2x}{x^2+y^2}$，$y'=\dfrac{R^2y}{x^2+y^2}$。

    * 把反演关系代回化简后的圆方程、整理掉分母，得到一条直线方程 $x_0x'+y_0y'=\dfrac{R^2}{2}$——注意它不过原点。

### 应用与几何直观

* **公切圆问题变公切线问题**

    * 问题：求过两圆外一点、与两圆都相切的所有的圆。

    * 做法：以这个点为反演中心、以任意大小的半径做反演——所有过这个点的圆都会变成直线，所有不过这个点的圆还是一个圆（两个已知圆仍是两个圆），问题就变成两个圆求公切线，比两个圆直接求公切圆简单得多。

* **直观理解：关于球的镜像**

    * 平时说的镜像是关于平面的：平面某一侧的点经镜像得到另一侧的点；反演则是圆内的点 $\boldsymbol{P}$ 经圆得到 $\boldsymbol{P}'$——反演的意义是几何图形关于球的镜像，而不是关于平面的镜像。

    * 反演变换在图形学当中的用处可能没有那么大；微分方程求解里的格林函数法（镜像法）与反演变换在很大程度上有共同之处。
