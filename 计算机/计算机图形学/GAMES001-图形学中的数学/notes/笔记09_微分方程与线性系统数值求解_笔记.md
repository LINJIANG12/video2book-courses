# 微分方程与线性系统数值求解

## 微分方程的定义与解法总览

   * **微分方程**

       * > **定义**：表示未知函数、未知函数的导数（一阶导、二阶导、各阶导数）与自变量之间关系的方程；求解微分方程，就是从这个方程里把未知函数解出来。

       * 位置：图形学中从常微分方程到偏微分方程都有大量需要求解的方程；它是连续数学部分（场论、微分几何之后）的最后一环，之后进入离散部分（线性求解器、最优化、机器学习），起承上启下作用。

       * 性质边界：内容带有总结性质、挂一漏万，之后用到时应据此框架查阅资料、更详细地学习。

   * **常微分方程与偏微分方程**

       * 常微分方程：未知函数是一元函数，涉及的导数全是全导数——式子里导数符号都是 $d$。

       * 偏微分方程：未知函数是多元函数，涉及的导数都是偏导数——符号是 $\partial$。

| 对比项 | 常微分方程 | 偏微分方程 |
| :--- | :--- | :--- |
| 未知函数 | 一元函数 | 多元函数 |
| 涉及的导数 | 全导数 | 偏导数 |
| 认出的符号 | $d$ | $\partial$ |

   * **四类求解方法**

       * 通解法：一些非常简单、特定形式的方程存在通解——满足该形式的方程的所有解已找齐，代值就能确定解究竟是什么。

       * 分离变量法：求解微分方程的重要分析手段，在常微分方程与偏微分方程中的表现形式有所不同，数学家、物理学家也会使用。

       * 格林函数法：更多用在数值当中——是从数学到计算机的桥梁，计算机求解方程很多时候需要利用格林函数。

       * 数值法：数值求解微分方程本身就是计算机图形学研究的核心之一——发明更好的数值方法可以投稿图形学论文。

## 一阶常微分方程

   * **分离变量法**

       * 标准形式：等式左端为 $\psi(y)\,\mathrm{d}y$、右端为 $\varphi(x)\,\mathrm{d}x$，对等式两边同时积分，各自积出原函数。

       * 规则：中间一定要补上一个常数 $C$——加减一个常数不会影响方程的解。

       * 例题：$x(1+y^2)\,\mathrm{d}x - y(1+x^2)\,\mathrm{d}y = 0$，两边同除 $(1+y^2)$ 与 $(1+x^2)$ 化为 $\frac{y}{1+y^2}\,\mathrm{d}y = \frac{x}{1+x^2}\,\mathrm{d}x$，积分得 $\frac{1}{2}\ln(1+y^2) = \frac{1}{2}\ln(1+x^2) + C_1$；令 $C_1 = \frac{1}{2}\ln C$（$\ln C$ 取值 $-\infty$ 到 $+\infty$，与任意常数等价），整理得 $y^2 = C(1+x^2) - 1$，也可写成 $y = \pm\sqrt{C(1+x^2)-1}$。

   * **一阶线性微分方程**

       * 标准形式：$\dfrac{\mathrm{d}y}{\mathrm{d}x} + p(x)\,y = q(x)$；右端恒等于零称齐次，不等于零称非齐次。

       * 齐次解法：利用一阶导数的线性性分离变量，两边乘 $\mathrm{d}x$ 再除以 $y$ 得 $\dfrac{\mathrm{d}y}{y} = -p(x)\,\mathrm{d}x$，积分、取指数得 $y = C\,e^{-\int p(x)\,\mathrm{d}x}$（$C = \pm e^{C_1}$）。

       * 齐次方程的图形学应用：体渲染中求解光线在具有透射率的体介质中散射时，辐照度的衰减量。

       * 非齐次解法（待定系数法）：把齐次解里的常数 $C$ 换成待定函数，设 $y = C(x)\,e^{-\int p(x)\,\mathrm{d}x}$，代回方程后含 $p(x)C(x)$ 的两项正好抵消，解出 $C(x) = \int q(x)\,e^{\int p(x)\,\mathrm{d}x}\,\mathrm{d}x + C$。

       * 通解结果：$y = C\,e^{-\int p(x)\,\mathrm{d}x} + e^{-\int p(x)\,\mathrm{d}x}\int q(x)\,e^{\int p(x)\,\mathrm{d}x}\,\mathrm{d}x$——去掉多出的一项即对应齐次方程的通解，只留多出的一项即非齐次方程的特解（那一项加不加 $C$ 不影响结果）。

       * **结论**：非齐次方程的通解 = 齐次方程的通解 + 非齐次方程的特解。

       * 通解与特解的记忆方式：解的表达式里含有不确定常数 $C$ 的是通解，不含 $C$ 的是特解。

   * **伯努利方程**

       * 形式：$\dfrac{\mathrm{d}y}{\mathrm{d}x} + p(x)\,y = q(x)\,y^n$，与线性方程的差别在右端多乘 $y^n$；要求 $n \neq 0$ 且 $n \neq 1$——$n=0$ 退化成一阶线性非齐次方程，$n=1$ 成为一阶线性齐次方程。

       * 解法（变量代换）：两边除以 $y^n$，利用 $\dfrac{\mathrm{d}(y^{1-n})}{\mathrm{d}x} = (1-n)\,y^{-n}\,\dfrac{\mathrm{d}y}{\mathrm{d}x}$ 只比已有的 $y^{-n}y'$ 多一个系数；令 $z = y^{1-n}$、两边同乘 $(1-n)$，化为 $\dfrac{\mathrm{d}z}{\mathrm{d}x} + (1-n)\,p(x)\,z = (1-n)\,q(x)$——正是一阶线性非齐次方程，代通解表达式即得。

       * 阶段总结：一阶方程的三个手段——分离变量法、待定系数法、变量代换法。

## 高阶常微分方程

   * **可降阶的三种类型**

       * $y^{(n)} = f(x)$：只要做 $n$ 次不定积分，就求得通解。

       * $y'' = f(x,\,y')$：设 $p = y'$，则 $p' = y''$，方程变成一阶方程 $p' = f(x, p)$；解出 $p = \varphi(x, C_1)$ 后再积分一次得 $y$。

       * $y'' = f(y,\,y')$：同样设 $p = y'$，但 $p$ 要看成 $y$ 的函数，二阶导写成 $y'' = p\,\dfrac{\mathrm{d}p}{\mathrm{d}y}$，方程变成 $p\,\dfrac{\mathrm{d}p}{\mathrm{d}y} = f(y, p)$；解出 $y' = p = \varphi(y, C_1)$ 后再积分一次得原函数。

   * **二阶线性方程通解的结构**

       * 标准形式：$y'' + p(x)\,y' + q(x)\,y = f(x)$；右端恒为零为齐次，否则为非齐次；齐次方程总是更好解。

       * **定理**：二阶线性齐次方程若有两个线性无关的解 $y_1(x)$、$y_2(x)$，则 $y = C_1 y_1(x) + C_2 y_2(x)$ 就是通解——两个线性无关特解的线性组合给出方程所有的解。

       * 推广：$n$ 阶线性齐次方程只要找到 $n$ 个线性无关的解，就可以组合出它所有的解。

       * 非齐次情形：找到对应齐次方程的通解，再加上非齐次方程的一个特解，就是非齐次方程的通解。

       * 地位：高阶微分方程里最重要的是二阶方程——很具典型性，扩展到二阶偏微分方程后应用也非常广泛。

   * **常系数齐次方程与特征方程**

       * 「常系数」指 $p$、$q$ 是固定常数而非 $x$ 的函数；解法用待定系数法猜 $y = e^{rx}$——因为 $e^x$ 求多少次导都保留 $e$ 的因子，求导不会把函数形式搞乱。

       * 特征方程：代入 $y'' + py' + qy = 0$ 得 $(r^2 + pr + q)\,e^{rx} = 0$，因 $e^{rx}$ 不可能为零，得 $r^2 + pr + q = 0$；用求根公式解出特征根 $r_1$、$r_2$，看判别式 $p^2 - 4q$。

       * 判别式大于零：两个线性无关特解 $y_1 = e^{r_1 x}$、$y_2 = e^{r_2 x}$，通解 $y = C_1 e^{r_1 x} + C_2 e^{r_2 x}$。

       * 判别式等于零：重根 $r = -\frac{p}{2}$ 只给一个特解 $y_1 = e^{-\frac{p}{2}x}$；再设 $y_2 = u(x)\,e^{-\frac{p}{2}x}$ 代入原方程整理，得另一个特解 $y_2 = x\,e^{-\frac{p}{2}x}$，通解 $y = (C_1 + C_2 x)\,e^{-\frac{p}{2}x}$。

       * 判别式小于零：没有实根，两个复根一定共轭，记 $r_{1,2} = \alpha \pm i\beta$；用欧拉公式 $e^{ix} = \cos x + i\sin x$ 消掉虚部，得两个实值特解 $y_1 = e^{\alpha x}\cos\beta x$、$y_2 = e^{\alpha x}\sin\beta x$。

       * 高阶扩展（注意是常系数）：解特征方程 $r^n + p_1 r^{n-1} + \cdots + p_{n-1}\,r + p_n = 0$；每个 $k$ 重实根 $r$ 对应通解项 $(C_1 + C_2 x + \cdots + C_k x^{k-1})\,e^{rx}$；每个 $k$ 重共轭复根 $\alpha \pm i\beta$ 对应通解项 $e^{\alpha x}\left[(C_1 + \cdots + C_k x^{k-1})\cos\beta x + (D_1 + \cdots + D_k x^{k-1})\sin\beta x\right]$——前面乘的多项式是 $k$ 重造成的，拆出 $\cos$、$\sin$ 两支是复根造成的。

   * **常系数非齐次方程的特解设定**

       * 右端 $f(x) = e^{\lambda x} P_m(x)$（$P_m$ 为最高 $m$ 次多项式）时，设特解 $y^* = x^k\,Q_m(x)\,e^{\lambda x}$，$Q_m(x)$ 是系数待定的 $m$ 次多项式。

       * $k$ 的取值规则：$\lambda$ 不是特征方程的根取 $k=0$，是单根取 $k=1$，是重根取 $k=2$。

       * 右端 $f(x) = e^{\lambda x}\left[P_l(x)\cos\omega x + Q_n(x)\sin\omega x\right]$ 时，设 $y^* = x^k\,e^{\lambda x}\left[R_m^{(1)}(x)\cos\omega x + R_m^{(2)}(x)\sin\omega x\right]$，多项式最高次数取 $l$ 与 $n$ 的最大值；$k$ 看 $\lambda + i\omega$ 是不是特征方程的根——不是取 $k=0$，是取 $k=1$。

## 偏微分方程的分类

   * **二元二阶线性偏微分方程**

       * 标准形式：$A\,\dfrac{\partial^2 u}{\partial x^2} + 2B\,\dfrac{\partial^2 u}{\partial x\,\partial y} + C\,\dfrac{\partial^2 u}{\partial y^2} + D\,\dfrac{\partial u}{\partial x} + E\,\dfrac{\partial u}{\partial y} + F\,u = f$，其中 $A,\dots,F$ 都是自变量 $x$、$y$ 的函数。

       * 分类判据：看判别式 $\Delta = B^2 - AC$——不是 $B^2 - 4AC$，因为 $4$ 已被提前放进混合导数项的系数 $2B$ 里。

       * 三型划分：对任意 $x$、$y$ 恒有 $\Delta > 0$ 为双曲型；恒等于零为抛物型；恒小于零为椭圆形。

       * 命名由来：把二阶偏导项换成 $x^2$、$y^2$、$xy$ 这类函数值，方程就是圆锥曲线的标准形式；判别式符号决定圆锥曲线是双曲线、抛物线还是椭圆，同样决定偏微分方程的类型。

   * **多元二阶的判断方法**

       * 列出标准形式 $\sum_{i,j} a_{ij}\,\dfrac{\partial^2 u}{\partial x_i\,\partial x_j} + \sum_i b_i\,\dfrac{\partial u}{\partial x_i} + cu = f$，把系数 $a_{ij}$ 构建成二次型并做标准化，按标准化后系数的符号判断类型（是否都等于零、是否都大于零等）。

## 物理中的典型偏微分方程

   * **波动方程（双曲型）**

       * $\dfrac{\partial^2 u}{\partial t^2} - a^2\,\dfrac{\partial^2 u}{\partial x^2} = 0$：两个自变量 $t$（时间）、$x$（位置），描述一维振动；方程齐次（右端项为零）。

       * 非齐次版本：右端加一个源项即受迫振动——振动时刻被施加激励、施加外力。

       * 三维拓展：把 $\dfrac{\partial^2 u}{\partial x^2}$ 换成拉普拉斯算子 $\Delta$，成为四元（$x$、$y$、$z$、$t$）二阶偏微分方程。

   * **热传导方程（抛物型）**

       * $\dfrac{\partial u}{\partial t} - a^2\,\Delta u = 0$；与波动方程的主要区别在关于 $t$ 的偏导阶数——波动方程是二阶，热传导方程是一阶。

       * 非齐次版本：右端加源项，表示所考虑区域中有热源往外辐射热量。

   * **拉普拉斯方程与泊松方程（椭圆型）**

       * 拉普拉斯方程 $\Delta u = 0$（一维即 $\dfrac{\partial^2 u}{\partial x^2} = 0$）：可看成热传导方程的稳定问题——不停传热最终形成稳定的热分布，$\dfrac{\partial u}{\partial t}$ 项消失。

       * 泊松方程：拉普拉斯方程加上源项——空间中有源；源可以是热源，也可以是电场方程中的电荷。

   * **亥姆霍兹方程**

       * 来源：在波动方程中假设解 $u(x,y,z,t) = V(x,y,z)\,e^{-i\omega t}$，代入即得 $\Delta V + k^2\,V = 0$。

## 分离变量法解波动方程

   * **分离过程**

       * 假设：$u(x,t) = X(x)\,T(t)$——$x$ 和 $t$ 可分离，等于一个关于 $x$ 的函数乘一个关于 $t$ 的函数。

       * 代入波动方程得 $X\,T'' - a^2\,X''\,T = 0$，两端同除 $a^2 X T$ 得 $\dfrac{T''}{a^2 T} = \dfrac{X''}{X}$：左端只与 $t$ 有关、右端只与 $x$ 有关，又要时刻相等，当且仅当两端等于同一个常数，设为 $-\lambda$。

       * > **易错点**：⚠️ 分离常数只能设成 $-\lambda$——猜成 $+\lambda$ 会解出矛盾。

       * $t$ 端：变成二阶线性齐次常微分方程 $T'' + \lambda a^2 T = 0$，通解 $T(t) = A\sin(\sqrt{\lambda}\,a\,t) + B\cos(\sqrt{\lambda}\,a\,t)$；$x$ 端类似，$X(x) = C\sin(\sqrt{\lambda}\,x) + D\cos(\sqrt{\lambda}\,x)$。

   * **边界条件定解**

       * 设定：绳子两端捏住，任意时刻 $x = 0$ 和 $x = L$ 处不发生震动、位移不变，即 $X(0) = 0$、$X(L) = 0$。

       * $X(0) = C\sin 0 + D\cos 0 = D$ 得 $D = 0$；$X(L) = C\sin(\sqrt{\lambda}\,L) = 0$ 要求 $\sqrt{\lambda}\,L$ 等于 $\pi$ 的整数倍，即 $\lambda_n = \dfrac{n^2\pi^2}{L^2}$，$n = 0, 1, 2, \dots$。

       * 第 $n$ 个分离变量解：$u_n(x,t) = \sin\dfrac{n\pi x}{L}\left(A_n \sin\dfrac{n\pi a t}{L} + B_n \cos\dfrac{n\pi a t}{L}\right)$。

       * **定理**：任何满足该波动方程的解都可写成上述分离变量解的线性组合；未定系数 $A_n$、$B_n$ 由初始条件 $u = f(x)$ 与 $\dfrac{\partial u}{\partial t} = \cos x$ 决定——把 $t = 0$ 代入并使用傅里叶展开即可确定。

       * **结论**：分离变量法背后蕴含的思想是傅里叶展开——相当于给偏微分方程给出傅里叶展开形式下的解。

## 球谐函数与勒让德多项式

   * **球坐标下拉普拉斯方程的分离变量**

       * 第一次分离：设 $u(r,\theta,\phi) = R(r)\,Y(\theta,\phi)$，等式一端只与 $r$ 有关、另一端只与 $\theta$、$\phi$ 有关，时刻相等只能等于同一常数，设为 $-\alpha$；仅与 $\theta$、$\phi$ 有关的方程叫球谐函数方程，解出的函数 $Y$ 叫球谐函数。

       * 第二次分离：$Y(\theta,\phi)$ 仍是偏微分方程，继续设 $Y = \Theta(\theta)\,\Phi(\phi)$；分离后剩一个消不掉的 $\sin^2\theta$，两边只能等于「常数除以 $\sin^2\theta$」形式的量（两边同乘 $\sin^2\theta$ 可消掉一端的 $\sin^2\theta$，另一端必然带着 $\dfrac{\beta}{\sin^2\theta}$），$\beta$ 是又一个分离常数。

       * $\phi$ 方向：归拢后是线性齐次二阶常微分方程，解得 $\Phi_1(\phi) = \cos(\sqrt{\beta}\,\phi)$、$\Phi_2(\phi) = \sin(\sqrt{\beta}\,\phi)$；球坐标里 $\phi$ 以 $0 \sim 2\pi$ 为周期（$\phi = 0$ 与 $\phi = 2\pi$ 是一回事），周期性边界条件 $\Phi(0) = \Phi(2\pi)$ 要求 $\beta = m^2$，$m$ 取遍自然数。

       * $\theta$ 方向：令 $x = \cos\theta$，方程化为只与 $x$ 及未知函数有关、无三角函数的形式；$x$ 取 $\pm 1$ 时方程因 $\dfrac{m^2}{1-x^2}$ 分母为零而发散，根据自然边界条件与解的展开，为使解有界要求 $\alpha = l\,(l+1)$，$l$ 取遍非负整数。

       * 径向方程：只与 $r$ 有关的二阶线性齐次微分方程，解为 $R(r) = A\,r^l + B\,r^{-(l+1)}$。

   * **连带勒让德方程与球谐函数的构成**

       * 连带勒让德方程：把 $\alpha = l(l+1)$、$\beta = m^2$ 都代入 $\theta$ 方程所得（$l$、$m$ 为人为指定的非负整数）；解出的多项式称为连带勒让德多项式。

       * 复数域归一化球谐函数：$Y_l^m = N_{lm}\,P_l^m(\cos\theta)\,e^{im\phi}$——归一化系数乘连带勒让德多项式再乘 $e^{im\phi}$。

       * 归一化含义：在整个立体角内做积分（不看 $r$ 时 $\theta$、$\phi$ 取遍整个单位球面），要求积分结果满足 $\delta_{kl}\,\delta_{mn}$ 这样的形式。

       * 实数域球谐函数：求解时默认 $m \geq 0$，但 $\phi$ 方程本有 $\cos m\phi$、$\sin m\phi$ 两支特解，把 $m < 0$ 利用起来——$m > 0$ 取 $\cos$ 支，$m < 0$ 取 $\sin|m|\phi$ 支，$m = 0$ 只剩勒让德多项式一项。

       * 一句话本质：球谐函数 = 连带勒让德多项式 × 归一化系数 × 三角函数。

   * **勒让德多项式**

       * 来源：勒让德方程是连带勒让德方程在 $m$ 取零时的特例，对应解与 $\phi$ 无关（绕极轴旋转对称）的情形，少了 $\dfrac{m^2}{1-x^2}$ 那一项；其解 $P_l(x)$（$P_l^0$ 省略上标零）称为 $l$ 阶勒让德多项式。

       * 计算：级数表达可直接带值算——完全是一个多项式，系数可以直接用阶乘计算；微分表示 $P_l(x) = \dfrac{1}{2^l\,l!}\,\dfrac{\mathrm{d}^l}{\mathrm{d}x^l}\left(x^2 - 1\right)^l$。

       * 零点与奇偶性：有 $l$ 个零点，全为实数且都在 $-1$ 到 $1$ 之间；$l$ 是奇数时为奇函数，$l$ 是偶数时为偶函数。

       * 正交性：$\int_{-1}^{1} P_n(x)\,P_l(x)\,\mathrm{d}x = 0$（$n \neq l$ 时），$= \dfrac{2}{2l+1}$（$n = l$ 时）。

       * 衔接：知道如何计算勒让德多项式，就知道如何计算球谐函数。

   * **球谐函数在图形学中的应用**

       * 作用：作为基底展开球面函数——任何球面函数都可以用球谐函数展开。

       * 动机：渲染中用球形天空盒表达环境光；直接存环境球贴图需要非常大的存储空间，使用时还要做插值、寻址，计算量很大。

       * 收益：用较低阶的 $l$、$m$ 展开后只剩若干个系数（球谐函数本身固定，每项只与系数有关）；只记前几项的展开系数就能近似表达环境光照贴图，使用时直接在球谐函数上算值——既不需要存储巨大的环境光贴图，效果也已经非常好。

## 格林函数法

   * **从点电荷问题引入**

       * 电场高斯定理：积分形式 $\oint_{\partial V} \mathbf{E} \cdot \mathrm{d}\mathbf{A} = \dfrac{Q}{\varepsilon_0}$（区域表面的电场强度面积分等于区域内电荷总量除以真空介电常数 $\varepsilon_0$）；微分形式 $\nabla \cdot \mathbf{E} = \dfrac{\rho}{\varepsilon_0}$（$\rho$ 为电荷密度）；两形式等价。

       * 微分形式在点电荷处失效：点电荷没有体积、聚焦在空间一点却带有限电荷，附近电荷密度发散——直接说「密度等于无穷」没法定义（无穷可以有好多阶、更高阶的无穷）。

       * 而点电荷的场是已知的：$\mathbf{r_0}$ 处大小为 $Q$ 的点电荷，场强 $\mathbf{E}(\mathbf{r}) = \dfrac{kQ}{|\mathbf{r} - \mathbf{r_0}|^2}$（方向由 $\mathbf{r} - \mathbf{r_0}$ 决定）；电势等于 $k$ 乘 $Q$ 再除以到 $\mathbf{r_0}$ 的距离。

       * 狄拉克函数（狄拉克 $\delta$ 函数）：三维中 $\mathbf{r} \neq 0$ 时 $\delta(\mathbf{r})$ 取零、$\mathbf{r} = 0$ 时取无穷；补充积分定义——对 $\delta$ 做体积分，取的区域包含原点结果为一，不包含则为零。

       * 点电荷密度：$\rho = Q\,\delta(\mathbf{r} - \mathbf{r_0})$；令 $\mathbf{E}$ 等于标量势 $\phi$ 的负梯度，得 $\Delta\phi = -\dfrac{Q\,\delta(\mathbf{r} - \mathbf{r_0})}{\varepsilon_0}$——右端为 $\delta$ 函数的泊松方程，其解人类在电场实验中已经找到。

   * **基本解与叠加原理**

       * 基本解：把右端换成纯 $\delta$ 函数，$\Delta u = -\delta(\mathbf{r} - \mathbf{r_0})$ 的解是 $u = \dfrac{1}{4\pi}\,\dfrac{1}{|\mathbf{r} - \mathbf{r_0}|}$——称为泊松方程在无穷远边界条件下的格林函数解，也称基本解。

       * 边界条件辨析：格林函数解要指定边界条件；基本解不需要——它蕴含了无穷远边界条件（$|\mathbf{r}|$ 趋向无穷时函数值等于零）。

       * 系数对应：电势泊松方程（右端乘 $Q/\varepsilon_0$）的解 $\phi = \dfrac{1}{4\pi\varepsilon_0}\cdot\dfrac{Q}{|\mathbf{r} - \mathbf{r_0}|}$——高中物理里的系数 $k$ 就是 $\dfrac{1}{4\pi\varepsilon_0}$。

       * 叠加原理求一般右端：无穷远边界条件下 $\Delta u = f$ 的解为体积分 $u(\mathbf{r}) = \dfrac{1}{4\pi}\int \dfrac{f(\mathbf{r}')}{|\mathbf{r} - \mathbf{r}'|}\,\mathrm{d}V'$——相当于对均匀带电导体的每一小段用库仑定律算电势贡献再积分。

   * **镜像法（非无穷远边界）**

       * 设定：空间中有无穷大平面满足电势为零，平面左端有电荷——泊松方程加边界条件「$x = 0$ 处 $\phi = 0$」。

       * 格林函数解：$G = \dfrac{1}{4\pi\varepsilon_0}\left(\dfrac{Q}{|\mathbf{r} - \mathbf{r_0}|} - \dfrac{Q}{|\mathbf{r} - \mathbf{r_0}'|}\right)$——把源点 $\mathbf{r_0}$ 的 $x$ 分量反号得到镜像点 $\mathbf{r_0}'$，等同于源电荷加上镜像位置的异号电荷（左边 $+Q$ 则镜像 $-Q$，带电量相反、距离镜面对称）。

       * 推广：左端不是点电荷而是电荷分布时，用镜像法格林函数解配合叠加原理求解。

       * > **易错点**：⚠️ 上述格林函数（无穷远的、非无穷远的）都是三维的；二维泊松方程 $\Delta u = -\delta(\mathbf{r} - \mathbf{r_0})$ 在无穷远边界条件下的解是对数形式 $\dfrac{1}{2\pi}\,\ln\dfrac{1}{|\mathbf{r} - \mathbf{r_0}|}$，不是 $\dfrac{1}{4\pi|\mathbf{r} - \mathbf{r_0}|}$，两者不能混用。

   * **格林恒等式与边界元法**

       * 第一、第二恒等式：把两个定义在某区域上的标量函数场（$\phi$、$\psi$ 连续可微）通过一个体积分等于一个面积分的关系联系起来。

       * 第三恒等式（更重要）：设 $G(\mathbf{r}, \mathbf{r_0})$ 是泊松方程的基本解、$\psi$ 在区域内满足拉普拉斯方程，则 $\psi$ 等于区域边界上的一个面积分，只与四样东西有关——$\psi$ 本身、$\psi$ 沿边界外法线方向的偏导数、泊松方程的基本解、基本解的偏导数。

       * 意义：知道区域边界上的值与偏导数，就能估算区域内部任何位置的 $\psi$——这个方程构成边界元法的基础；偏微分方程的离散化本身也是图形学研究的内容之一。

## 偏微分方程的数值解法

   * **常微分方程的数值解：欧拉法与龙格–库塔**

       * 最简形式：$y' = f(x, y)$，$y(x_0) = y_0$。

       * 欧拉法：$y_{i+1} = y_i + f(x_i,\,y_i)\,h$，其中 $h = x_{i+1} - x_i$ 为步长；只有一阶精度。

       * 龙格–库塔法：通过一些手段提升欧拉法精度所产生的高阶方法。

   * **有限差分逼近拉普拉斯算子**

       * 设定：二维拉普拉斯方程，均匀正方形格点，格点上存函数 $u$ 的值；中心 $(i,j)$，四邻居 $(i\pm1,j)$、$(i,j\pm1)$，每格边长 $\Delta x$。

```text
            u(i,j+1)
                |
u(i-1,j) --- u(i,j) --- u(i+1,j)
                |
            u(i,j-1)
```

       * 差分原理：用 $\dfrac{u_{i+1,j} - u_{i,j}}{\Delta x}$ 等估算一阶偏导数，一阶偏导再差分一次得二阶偏导，整理得五点格式 $\Delta u \approx \dfrac{u_{i+1,j} + u_{i-1,j} + u_{i,j+1} + u_{i,j-1} - 4\,u_{i,j}}{\Delta x^2}$。

       * 拉普拉斯方程代入：令每格点 $\Delta u = 0$，$\Delta x^2$ 与方程无关可约去，得 $u_{i,j} = \dfrac{u_{i+1,j} + u_{i-1,j} + u_{i,j+1} + u_{i,j-1}}{4}$——每点的值等于周围邻居相加再除以四。

   * **点迭代求解**

       * 雅可比迭代：每个时间步用上一时刻周围四个格点值的平均更新 $u_{i,j}$；收敛效率要稍微慢一些。

       * 高斯–赛德尔迭代：直接写 for 循环扫——一半的值用这一次的结果（已更新过的邻居用新值），一半用上一次的结果（未更新的邻居用旧值），求平均得到 $u_{i,j}^{n+1}$。

       * 终止条件：估算 $\sum_{i,j}\left|u_{i,j}^{n+1} - u_{i,j}^{n}\right|$（取绝对值求和），小于给定的 `tolerance` 后让算法停止。

       * 分类：这套解法称为有限差分离散化下的点迭代法——一个离散化的方式加上一个求解的方式。

   * **从偏微分方程到线性系统**

       * 离散化方式不止有限差分，还有有限体积法、有限元法、边界元法等。

       * 转化关系：通过空间离散化，偏微分方程变成线性系统——自变量是格点处的值，它们之间满足恒等式关系；一些离散的值要满足一个巨大的矩阵方程。

       * 求解衔接：线性系统除点迭代法外，还有共轭梯度法、多重网格法等求解方法。

## 线性系统与高斯消元

   * **问题背景**

       * 问题本身：给定矩阵 $A$ 和右端项 $b$，求矩阵方程 $Ax = b$ 的解。

       * 图形学中的出现位置：几何处理的隐式拉普拉斯平滑（implicit Laplacian smoothing）要解方程；物理模拟每个时间步内一般要解一个规模很大的线性方程组；全局渲染中 radiosity 这类基于辐射度的算法同样要解方程。

       * 中心问题：针对不同的问题选择合适的矩阵求解器，让它解得又稳定、又快、又好。

   * **高斯消元**

       * 正向消元：用每行对角线上的主元乘倍数加到下方各行，把主元以下消成零，系数矩阵压成上三角矩阵；得到的方程与原方程完全等价但形状更好解。

       * 回代：上三角方程有天生的求解顺序——先解最后一行直接得最后一个未知数，代回倒数第二行、再代回第一行，逐个抠出全部解。

       * 回代的另一视角：逆向的高斯消元——把最后一行乘倍数加到上面的行、逐个消掉上三角非零元，最终变成对角矩阵，连代都不用代，解直接摆在方程上。

   * **LU 分解**

       * > **定义**：高斯消元的矩阵分解形式 $A = LU$，其中 $L$ 是对角线全为 $1$ 的下三角矩阵，$U$ 是上三角矩阵。

       * 机理：每一次「某一行乘以某个常数加到另一行」的行变换都等价于在左边乘上一个矩阵，且这些矩阵都是下三角的；下三角矩阵连乘还是下三角，整个消元积累下来等于左乘一个总的下三角矩阵。

       * $L$ 的含义：对角线以下的数正是每次消元所用倍数取负——用了 $\frac{3}{2}$、$-1$、$-4$，$L$ 里就是 $-\frac{3}{2}$、$1$、$4$；$L$ 记录了对原矩阵做过的全部行变换。

       * 两步求解：$Ax = b$ 拆成 $LUx = b$，先把 $Ux$ 整体当未知向量解 $Ly = b$（下三角，从第一行顺解、逐行代入），再把 $y$ 当新右手项解 $Ux = y$（上三角，从最后一行倒解）——一个方程换成两遍扫描的三角方程。

       * 原地存储：$L$、$U$ 不另存成两个矩阵，就存在 $A$ 自己里——输入是 $A$，算法跑完输出还是 $A$，严格下三角部分对应 $L$，对角线连同上三角对应 $U$；$L$ 的对角线全 $1$，不必占存储。

```text
分解完成后的 A（原地存储）：
[ u11  u12  u13 ]
[ l21  u22  u23 ]
[ l31  l32  u33 ]
```

       * 复杂度：三个嵌套的 for 循环，$O(n^3)$，与矩阵维数的立方成正比，相对较高；也可以设计对应的并行算法进一步提高速度。

   * **部分选主元（GEPP）**

       * 风险场景：消元进行到中途，该用某行主元去消下方时发现主元是 $0$——拿第一行消第二行时可能顺手把第二个元素也消掉；此时按算法照章办事，$0$ 作分母直接除零，数值上立刻不稳定。

       * > **易错点**：⚠️ 消元中途主元变零不是「倒霉」，而是正常现象；不设防的 LU 分解在这里会直接除零崩溃。

       * 对策：每次都选绝对值最大的那一行来当主元（如不用 $0.5$ 去消 $2$，反过来用 $2$ 去消 $0.5$）——只要矩阵满秩，就能保证过程中不会除以一个小量导致数值不稳定；称为列主元高斯消去法或部分选主元高斯消去法，简写 GEPP（Gaussian Elimination with Partial Pivoting）。

## Cholesky分解与直接法的天花板

   * **Cholesky 分解（Cholesky decomposition，LLᵀ 分解）**

       * > **定义**：对称半正定矩阵的分解 $A = LL^{\top}$——$L$ 是下三角矩阵，$L^{\top}$ 是上三角矩阵，仍是「下三角乘上三角」，只是两个因子互为转置；正因为 $A$ 对称半正定才有这个转置关系。

       * 求解顺序现成：$(1,1)$ 位置只剩 $L_{11}^2 = A_{11}$，得 $L_{11} = \sqrt{A_{11}}$；代入 $(2,1)$ 位置的式子得 $L_{21} = A_{21}/L_{11}$；代入 $(2,2)$ 得 $L_{22} = \sqrt{A_{22} - L_{21}^2}$；就这么一路带下去，整个 $L$ 的系数都求出来。

       * 相比 LU 的好处：$A$ 对称，只需知道一个 $L$，不需要同时知道 $L$ 和 $U$，计算量减小一半；算法跟 LU 分解长得很像，但同样有三重 for 循环，复杂度也是 $O(n^3)$；对称半正定情形非常常用。

   * **两种直接法对比**

| 方法 | 分解形式 | 适用矩阵 | 特点 |
| :--- | :--- | :--- | :--- |
| LU 分解（高斯消元） | $A = LU$ | 任意矩阵 | 通用；需选主元保证鲁棒性 |
| Cholesky 分解（LLᵀ） | $A = LL^{\top}$ | 对称半正定 | 只求一个 $L$，速度更快 |

   * **直接法的天花板**

       * 适用规模：两种算法都是 $O(n^3)$，一般来说只适用于小矩阵方程——矩阵在 $100$ 到 $1000$、即 1000 以下量级解得很快；再往上走，立方复杂度让速度大大减慢。

       * 图形学现状：经常在 mesh 上解方程或给场景构建方程，轻轻松松超过 10 万个顶点，建出的矩阵方程就是 10 万 × 10 万；LU、LLᵀ 可能要几十分钟甚至几个小时——不可接受。

       * 结论：更大规模的矩阵方程一般使用迭代求解的方法。

## 迭代求解的通用框架

   * **框架流程**

       * 初始猜测 $x_0$：完全没信息就置成零；有先验信息（大概知道解可能是多少）就把拿到的值作为初始值。

       * 迭代主体：反复执行某一个步骤，从 $x_k$ 推到 $x_{k+1}$；迭代到一定步数把 $x_k$ 放进方程检查，残差（residual）$r = b - Ax$ 的模长足够小就认为可以终止，得到的解差不多是精确解。

       * 阈值：$10^{-6}$ 已达 float 的数值精度，再往下迭代没有意义；很多情况甚至不需要这么小，$10^{-3}$、$10^{-4}$ 就够。

```text
初始解 x0（没信息就置零；有先验就猜个近的）
  │
  ▼  反复执行同一个更新步骤
xk  ──▶  xk+1  ──▶  xk+2  ──▶ ...
  │
  ▼
每步算残差 r = b − A·xk，看 ‖r‖ 是否够小
  │
  ├─ 够小（如 < 1e-6）→ 停止，xk 就是近似解
  └─ 不够            → 回到上面，继续迭代
```

   * **迭代法相对直接法的优势**

       * 随时可停：随时把迭代停下来拿到一个差不多的解——直接法必须等算法全部跑完才有准确解，而很多场景并不需要非常非常精确。

       * 初始值敏感（正面）：初始猜测给得非常好时，迭代次数会大大减小。

       * 专用算法：对很多特定问题——矩阵是稀疏矩阵或对称正定矩阵——有专门的迭代算法，速度明显优于直接求解。

       * 黑盒友好：有时 $A$ 并没有显式存下来，只拿到一个「输入 $x$ 返回 $Ax$」的接口，$A$ 长什么样是黑盒；很多迭代方法恰恰只用这个接口——直接法连矩阵本身都拿不到，无从分解起。

       * 数量级体感：20 万节点的弹性体对应 60 万维方程（每个节点 3 个自由度）；迭代求解器设计得好，几十毫秒内可以解得差不多；直接求解可能要几十分钟甚至更长。

## 不动点迭代

   * **基本思想**

       * 直观例子（卡西欧计算器）：随便给初值 $x = 0$，不断执行 cos Ans——每次把上一次的结果再放进 cos——序列最后收敛到某个特定值；这个值就是方程 $x = \cos x$ 的解（直线 $y = x$ 与曲线 $y = \cos x$ 的交点）。

       * 得名：这个点在迭代过程中最后收敛到真正的解上——它就不动了，故称不动点迭代。

       * 矩阵形式：把 $A$ 拆成两个矩阵的差 $A = M - N$，则 $Ax = b$ 改写为 $Mx - Nx = b$，把 $Nx$ 移到右边、两边同乘 $M^{-1}$，得 $x = M^{-1}Nx + M^{-1}b$——与原方程等价，但左右两边同时出现 $x$，正是不动点的形状。

       * 迭代操作：每有 $x_k$ 就代入方程右边，输出记 $x_{k+1}$，如此往复；若迭代收敛（$x_k$ 趋向某个固定值 $x^*$），代回必有 $(M - N)x^* = b$，即 $Ax^* = b$。

       * **结论**：不动点迭代一旦收敛，极限必为原方程的解；真正要担心的是「能不能收敛」。

       * 三个待解决问题：$M^{-1}$ 要怎么算（$M$ 任意取的，以 $M$ 为系数的那步求解好不好算）、收敛效率多快、能否保证收敛（会不会越迭代越大直接炸掉）。

## 雅可比迭代

   * **定义与迭代式**

       * > **定义**：最简单的不动点迭代（Jacobi iteration）——$M$ 直接取 $A$ 的对角部分 $D$，剩下的非对角部分取反扔进 $N$：$M = D$，$N = D - A$（$N$ 对角线全 $0$、非对角线为 $-a_{ij}$，满足 $M - N = A$）。

       * 迭代式：$x_{k+1} = D^{-1}(Nx_k + b)$——先算 $Nx_k + b$ 拿到向量，再左乘 $D^{-1}$（对角矩阵的逆对角线逐个取倒数即可），结果塞回 $x_{k+1}$；非常简单的迭代算法。

       * 收敛实例：某个 $3\times3$ 矩阵方程的残差（$b - Ax_k$ 的模长）随迭代不断减小，最后收敛——但即便这么小的方程也要跑十几步差不多才能收敛。

       * 发散反例：把高斯消元例子里的那个 $A$ 套进雅可比迭代——残差随迭代不断变大且持续下去，永远达不到矩阵的真实解，迭代失败。

   * **快慢取决于 $A$ 有多「像对角矩阵」**

       * 极端快的情况：$A$ 本身就是对角矩阵时，$T = I - D^{-1}A = 0$，一步就收敛。

       * 一般规律：$A$ 越对角占优——对角元相对越大——用对角矩阵近似 $A$ 的效果越好，迭代矩阵 $T$ 越接近零矩阵，收敛越快。

       * 总账：矩阵几万维时迭代步数很可能也是几万、几十万量级——总的来说依然不快，好在非常简单。

## 收敛判据与松弛法

   * **误差与残差**

       * 误差（error）：$e_k = x^* - x_k$，反映每步迭代值与真实解之间的差距。

       * 残差（residual）：$r_k = b - Ax_k$，反映方程当前还差多少没有被满足——两者是不同概念。

       * 关系：$r_k = b - Ax_k = Ax^* - Ax_k = A(x^* - x_k) = Ae_k$——残差和误差之间就差一个 $A$ 矩阵。

   * **迭代矩阵与特征值判据**

       * 迭代式改写：利用 $N = M - A$，得 $x_{k+1} = x_k + M^{-1}(b - Ax_k)$，形式里只剩 $M$ 和 $A$。

       * 误差演化：$e_{k+1} = e_k - M^{-1}Ae_k = (I - M^{-1}A)\,e_k = M^{-1}Ne_k$——每迭代一步，误差被左乘一次迭代矩阵 $T = I - M^{-1}A = M^{-1}N$，误差的演化完全由它决定。

       * 特征值分析：$T$ 不一定对称，特征值可以是复数（带辐角），只关心模长；把误差向量在特征向量基底下展开，每迭代一步每个特征分量各自乘一次对应特征值，$k$ 步后乘的是 $\lambda_i^k$。

       * **结论**：不动点迭代收敛的充分且必要条件，是迭代矩阵 $T = M^{-1}N$ 的所有特征值的模长都小于 $1$。

       * 充要的原因：只要 $T$ 里有一个特征值模长大于 $1$（最简单如对角阵某个对角元是 $2$），那一维误差每步乘 $2$、$4$、$8$、$16$……不断放大炸掉，不可能收敛；特征值越小对应分量收敛越快（每步乘的数更小）。

       * 极端情况：$M$ 直接取 $A$ 本身，$T = I - A^{-1}A = 0$，零矩阵特征值全 $0$，一步把所有误差降到零——但代价是迭代时要处理 $A^{-1}$，而做迭代法的目的本来就是为了不直接面对 $A^{-1}$。

       * 选 $M$ 的准则：让 $M$ 尽可能接近、近似 $A$（把 $T$ 的特征值往小压），同时 $M^{-1}$ 必须是方便求解的东西；雅可比取对角阵就是用对角线近似 $A$，对角矩阵的逆好求到极致。

       * > **注意**：特征值判据在实际应用里不好用——总不能把 $T$ 求出来再做一遍特征值分解，有这功夫迭代可能早自己收敛了；它只是理论判断，实际用简化判据。

   * **对角占优（实用充分条件）**

       * > **定义**：对 $A$ 的每一行而言，对角元素的绝对值大于该行其余所有非对角元素的绝对值之和：$\left| a_{ii} \right| > \sum_{j \neq i} \left| a_{ij} \right|$ 对每一行都成立。

       * > **易错点**：⚠️ 对角占优是充分条件，但不是必要条件——不满足它也可能收敛，满足它则一定收敛。

       * 实用性：条件非常简单，建矩阵时扫一眼、逐行查一查就能预判雅可比迭代收不收敛；前述收敛实例正是对角占优，发散反例正是非对角占优。

   * **松弛法**

       * 做法：给每次更新的步长乘一个常数 $\omega$：$x_{k+1} = x_k + \omega\,D^{-1}(b - Ax_k)$——之前的迭代默认 $\omega = 1$（右边求出来直接加），现在是先乘 $\omega$ 再加。

       * 取值：$\omega$ 挺自由，大于 $1$ 甚至都可以；面对不收敛的情况一般取尽量小的值。

       * 效果：前述发散例子取 $\omega = 0.5$（每次更新步长打对折）最后仍会收敛——只是迭代数比 $\omega = 1$ 就能收敛的情况稍多。

       * 经验：发现迭代发散了，可以试一试用松弛法乘 $\omega$ 因子。

## 高斯–赛德尔迭代

   * **$M$ 的选取与求解**

       * 取法：$M$ 取 $A$ 的对角部分加上下三角部分（取「对角加上三角」也没有本质区别，只是约定），$M$ 是一个下三角矩阵。

       * $M^{-1}$ 的算法：每步真正要算的是 $M^{-1}$ 乘一个向量，即解 $M\mathbf{x} = \mathbf{v}$——正是高斯消元那套原理：从第一行解出一个未知量就代入下一行，不断求、不断代入；对下三角矩阵来说「逆矩阵乘一个向量」很好算。

       * 收敛优势：$M$ 比纯对角多装了整个下三角，明显更「像」$A$，迭代矩阵 $T = I - M^{-1}A$ 更接近零矩阵——一般来说迭代次数比雅可比少不少，收敛更快。

       * 代价：每步成本更高——雅可比的 $M$ 是对角阵、各维互不相干可直接并行；这里的 $M$ 是下三角阵，只能一行一行串行解；矩阵稀疏时可以通过重排得到并行版本的高斯–赛德尔迭代。

   * **收敛条件**

       * 充分不必要条件：$A$ 是对称正定矩阵——并不要求 $A$ 对角占优；满足则一定收敛，不满足未必不收敛，只是没有这层保证。

       * 两类矩阵互不包含：不是所有对称正定矩阵都对角占优，也不是所有对角占优的矩阵都对称正定；两条判据分工很清楚。

       * **结论**：雅可比迭代收敛的充分不必要条件是 $A$ 对角占优；高斯–赛德尔迭代收敛的充分不必要条件是 $A$ 对称正定。

   * **与雅可比的唯一算法区别**

       * 取值差异：雅可比更新 $\mathbf{x}_{k+1}$ 时用到的始终是上一轮 $\mathbf{x}_k$ 的信息；高斯–赛德尔因用下三角 $M$，更新 $\mathbf{x}_{k+1}$ 时会同时用上本轮已经更新出来的那部分分量——更新第二个分量 $x_2$ 时用的是刚更新过的 $x_1$，而雅可比只会用上一轮还没更新的 $x_1$。

       * 影响：就这一条区别，导致两个算法收敛性质上的差距——一般来说高斯–赛德尔比雅可比更快。

   * **两算法对比**

| 对比项 | 雅可比迭代 | 高斯–赛德尔迭代 |
| :--- | :--- | :--- |
| $M$ 的取法 | $A$ 的对角部分 | $A$ 的对角 + 下三角部分 |
| $M$ 与 $A$ 的相似程度 | 较远 | 更像 $A$ |
| 迭代矩阵 $T = I - M^{-1}A$ | 离零矩阵较远 | 更接近零矩阵 |
| 每步成本 | 低，可并行 | 高，逐行串行 |
| 总体迭代次数 | 多 | 明显更少 |
| 收敛充分条件 | 对角占优 | 对称正定 |
| 更新 $\mathbf{x}_{k+1}$ 时的取值 | 只用上一轮的 $\mathbf{x}_k$ | 顺带用本轮已更新的分量 |

## 不动点迭代的总结与出路

   * **共同优势与短板**

       * 共同优势：实现非常简单。

       * 共同短板：收敛速度都不快——高斯–赛德尔比雅可比快一点，但没有优化的话照样跑得比较慢；具体用哪一种更好，要具体矩阵具体分析。

       * 核心权衡：雅可比单步便宜（只算对角矩阵的逆、逐元素取倒数）且各维独立利于并行，但需要的迭代步数多——$3\times3$ 小矩阵都要十几步甚至几十步；单步便宜、步数偏多，正是挑选迭代求解器时最核心的权衡之一。

   * **两条改进出路**

       * 出路一·松弛：出现不收敛的情况时，给迭代配上松弛系数让雅可比或高斯–赛德尔收敛；实际使用中一般就是靠调节松弛系数，平衡不动点迭代的稳定性和收敛速度。

       * 出路二·多重网格：仔细分析不动点迭代的收敛特性，找出哪些误差分量收敛得快、哪些慢；据此构建多层网格（不断用小规模的矩阵近似 $A$），让误差在不同层之间传递、在不同层上用不动点迭代求解——多重网格求解器的基本思想。

       * 多重网格的定位：一般是求解矩阵方程的最优方法，非常非常快；但要求先对矩阵结构做分析（分清矩阵的特性），才能构造出来。

## 子空间方法与Krylov子空间

   * **子空间迭代的基本思想**

       * 出发点：把 $A\mathbf{x} = \mathbf{b}$ 看成优化问题——优化残差，让 $A\mathbf{x} - \mathbf{b}$ 越小越好；整个优化空间是 $\mathbb{R}^N$，设其上有一组基 $\mathbf{e}_1, \dots, \mathbf{e}_N$。

       * 限制：第 $M$ 步只考虑由 $\mathbf{e}_1$ 到 $\mathbf{e}_M$ 张成的 $M$ 维子空间上的优化问题解——$\mathbf{x}$ 只能由这 $M$ 个向量的线性组合构成，只考虑子空间内如何让残差最小。

       * 低成本更新：若这组基的构造方式满足某些数学特性，从 $\mathbf{x}_{M-1}$（前 $M-1$ 个向量张成子空间上的解）更新到 $\mathbf{x}_M$ 的代价其实很低；每步代价都低，迭代就能进行下去。

       * **结论**：子空间迭代最多只需 $N$ 步就一定达到最终的解——第 $N$ 步求的是 $\mathbf{e}_1$ 到 $\mathbf{e}_N$ 张成的 $N$ 维子空间上的残差最小化解，而这个子空间就是全空间 $\mathbb{R}^N$；对比：$3\times3$ 的小矩阵不动点迭代都可能要十几步，子空间迭代最多三步。

   * **Krylov 子空间**

       * > **定义**：$\mathcal{K}_R = \operatorname{span}\{\mathbf{b},\ A\mathbf{b},\ A^2\mathbf{b},\ \dots,\ A^{R-1}\mathbf{b}\}$——由 $\mathbf{b}$、$A\mathbf{b}$ 一直到 $A^{R-1}\mathbf{b}$ 这 $R$ 个向量张成的 $R$ 维子空间（Krylov，克雷洛夫，前苏联或俄罗斯数学家）。

       * 基的性质：这 $R$ 个向量之间不一定正交——可以把它们作为基，但这是一组不正交的基。

       * 嵌套关系：$\mathcal{K}_1 \subset \mathcal{K}_2 \subset \mathcal{K}_3 \subset \cdots \subset \mathcal{K}_N = \mathbb{R}^N$——$\mathcal{K}_2$ 比 $\mathcal{K}_1$ 只多 $A\mathbf{b}$ 一个基向量，层层嵌套；$\mathcal{K}_{N+1}$、$\mathcal{K}_{N+2}$ 向量个数变多但维度不再增加（向量之间已存在线性关系）。

       * 迭代含义：用 Krylov 子空间做子空间迭代，就是第 $M$ 步在 $\mathcal{K}_M$ 中寻找让残差最优的 $\mathbf{x}_M$；最常用、也最成功的具体方法是共轭梯度法（Conjugate Gradient method，CG），解决对称正定矩阵 $A$ 的 $A\mathbf{x} = \mathbf{b}$。

## 共轭梯度法

   * **把解方程变成最小化二次型**

       * 转化：$f(\mathbf{x}) = \dfrac{1}{2}\,\mathbf{x}^\top A\,\mathbf{x} - \mathbf{b}^\top \mathbf{x}$；对 $\mathbf{x}$ 求导得梯度 $A\mathbf{x} - \mathbf{b}$——刚好是负的残差。

       * 等价性：$f$ 取到最小 ⇔ 梯度等于零 ⇔ 残差等于零 ⇔ $A\mathbf{x} = \mathbf{b}$；且 $A$ 对称正定保证 $f$ 是正的二次型、有唯一最小值——解决最小化问题就等价于解方程。

   * **子空间内最优的条件**

       * 几何条件：当梯度（即 $-\mathbf{r}_M$）正交于当前子空间时，$\mathbf{x}_M$ 就在 $\mathcal{K}_M$ 中最小化了 $f$。

       * 理由：要继续减小 $f$，一定沿负梯度 $-\mathbf{r}_M$ 方向移动才能更小；而 $-\mathbf{r}_M$ 与当前子空间垂直，子空间里无论怎么移动都无法让残差进一步变小——已经降到底了。

       * 迭代要求：每步迭代都让 $\mathbf{r}_M$ 和当前子空间 $\mathcal{K}_M$ 正交；满足即知 $\mathbf{x}_M$ 在 $\mathcal{K}_M$ 中取到最优，子空间迭代算法成立。

   * **共轭方向：每步压成一维优化**

       * 核心思想：构造 Krylov 子空间的一系列共轭的基 $\mathbf{p}_1, \dots, \mathbf{p}_M$——它们张成的空间就是 $\mathcal{K}_M$，且两两满足共轭关系 $\mathbf{p}_i^\top A\,\mathbf{p}_j = 0\ (i \neq j)$。

       * 更新公式：$\mathbf{x}_M = \mathbf{x}_{M-1} + \alpha_M\,\mathbf{p}_M$——已知 $\mathbf{x}_{M-1}$ 求 $\mathbf{x}_M$ 就是在 $\mathbf{p}_M$ 方向上最小化 $f$；$\alpha_M$ 是标量、$\mathbf{p}_M$ 是已知向量，求一个标量使 $f$ 最小是一维优化问题，非常好解。

   * **归纳证明：每步残差垂直于当前子空间**

       * 初始步：在 $\mathbf{p}_1$ 构成的一维子空间上直接解优化问题（一维可以直接解），解到最优则 $\mathbf{r}_1$ 垂直于 $\mathcal{K}_1$。

       * 归纳假设：第 $M-1$ 步保证 $\mathbf{r}_{M-1} \perp \mathcal{K}_{M-1}$；把更新关系代进残差展开，$\mathbf{r}_M = \mathbf{b} - A\mathbf{x}_M = \mathbf{b} - A(\mathbf{x}_{M-1} + \alpha_M \mathbf{p}_M) = \mathbf{r}_{M-1} - \alpha_M A\,\mathbf{p}_M$。

       * 结论一：这步在 $\mathbf{p}_M$ 方向上搜索并取到一维最小，$\mathbf{p}_M$ 是额外增加的那一维方向，剩下的残差一定与它垂直——$\mathbf{r}_M \perp \mathbf{p}_M$。

       * 结论二：由共轭关系，对所有 $i < M$ 有 $\mathbf{p}_i^\top A\,\mathbf{p}_M = 0$，即 $A\,\mathbf{p}_M \perp \mathcal{K}_{M-1}$。

       * 合并：$\mathbf{r}_{M-1} \perp \mathcal{K}_{M-1}$（归纳假设）、$A\mathbf{p}_M \perp \mathcal{K}_{M-1}$（共轭关系），两项都垂直于 $\mathcal{K}_{M-1}$，故 $\mathbf{r}_M \perp \mathcal{K}_{M-1}$；再加上 $\mathbf{r}_M \perp \mathbf{p}_M$，而 $\mathcal{K}_M$ 由 $\mathcal{K}_{M-1}$ 和 $\mathbf{p}_M$ 组成，所以 $\mathbf{r}_M \perp \mathcal{K}_M$，归纳完成。

       * > **易错点**：⚠️ 共轭关系 $\mathbf{p}_i^\top A\,\mathbf{p}_j = 0$ 里隔着一个 $A$，说的是「$A\mathbf{p}_j$ 与 $\mathbf{p}_i$ 正交」，而不是「$\mathbf{p}_i$ 与 $\mathbf{p}_j$ 正交」；推导 $A\mathbf{p}_M \perp \mathcal{K}_{M-1}$ 用的正是这一点——把中间的 $A$ 丢了就会推错。

   * **算法本体**

       * 每轮只做两件事：求 $\alpha_k$ 描述的就是「在 $\mathbf{p}_k$ 方向上解一维优化问题」；拿到 $\alpha_k$ 后构造下一个搜索方向 $\mathbf{p}_{k+1}$——要跟前面所有 $\mathbf{p}_1$ 到 $\mathbf{p}_k$ 相互共轭。

```text
共轭梯度法（CG）每一轮迭代只做两件事：
  ① 一维优化：xk = xk-1 + αk·pk      （αk 让 f 沿 pk 方向取到最小）
  ② 方向更新：pk+1 = rk+1 + βk·pk    （βk 让 pk+1 与 p1…pk 全部 A-共轭）
```

       * 细节边界：$\alpha_k$ 由一维优化的极值条件直接算出；$\beta_k$ 怎么算涉及 Krylov 子空间的独特性质，$\mathbf{p}$ 系列怎么构造也未展开——算法写出来非常短、效率非常高，会用即可。

   * **收敛上界：条件数说了算**

       * 步数保证：CG 能保证 $N$ 步之内收敛到最终解；一般不需要真迭代 $N$ 步——远小于 $N$ 的步数误差基本就能收敛到阈值以下，几万维的矩阵几千步就可以收敛得差不多。

       * 上界公式：$\dfrac{\|\mathbf{x}_k - \mathbf{x}^*\|}{\|\mathbf{x}_0 - \mathbf{x}^*\|} \le \left(\dfrac{\sqrt{\kappa}-1}{\sqrt{\kappa}+1}\right)^k$，其中 $\mathbf{x}^*$ 是真实解，左边是第 $k$ 步误差与初始误差之比。

       * 条件数：$\kappa$ 是矩阵的条件数——$A$ 的最大特征值与最小特征值的模长之比，一定有 $\kappa \ge 1$。

       * 读法：条件数非常大（比如上千）时底数非常接近 $1$，相当于每步误差只乘一个 $0.99$，收敛很慢；条件数越接近 $1$ 底数越小，相当于每步乘 $0.1$、$0.001$、$0.0001$ 往下降，收敛越快。

       * **结论**：CG 的收敛速度主要取决于矩阵的条件数——希望条件数尽可能接近 $1$，这样 CG 收敛得非常快。

## 预处理与求解器选择

   * **预处理（preconditioning）**

       * > **定义**：为了把 CG 的条件数变小，找 $A^{-1}$ 的一个近似矩阵、写成 $M = P^\top P$，转而求解等价变换后的矩阵方程 $PAP^\top \mathbf{y} = P\mathbf{b}$（解出 $\mathbf{y}$ 后 $\mathbf{x} = P^\top \mathbf{y}$）。

       * 原理：$PAP^\top$ 的条件数一定比原来单独的 $A$ 小——极端情况 $M$ 就是 $A^{-1}$ 时，变换后矩阵的条件数为 $1$；只要 $M$ 是 $A^{-1}$ 的不错近似，转而解变换后的方程，CG 收敛就非常快。

       * $M$ 的选法（与不动点迭代选 $M$ 思路类似）：$M$ 选成 $A$ 的对角矩阵——对应的 CG 叫雅可比预条件 CG（对角预条件 CG，DPCG）；用 LLᵀ 分解（Cholesky 分解）的简化形式——不完全 Cholesky 分解——对应的 CG 叫不完全 Cholesky 预条件 CG（ICPCG，incomplete Cholesky preconditioned CG）。

       * 效果：ICPCG 的收敛速度比不做预处理快非常多，是求解对称正定矩阵方程非常常用的求解器——几万维的矩阵甚至只需几十步就能收敛到不错的程度；方程对称正定时可以试一试。

   * **对称不正定与一般矩阵的 Krylov 求解器**

       * 适用边界：CG 只适用于对称正定的矩阵方程；Krylov 子空间方法还有其他形式，适用于更宽泛的情况。

       * 对称但不一定正定：可以考虑 MINRES（minimal residual method）求解器。

       * 一般甚至不对称的矩阵：有对应的 Krylov 子空间求解器——GMRES、BiCG、BiCGSTAB，都能求解一般的非对称矩阵方程。

       * 速度提醒：拿 GMRES 或 MINRES 去解对称正定的方程，速度会比 CG 慢一些——为了速度先看矩阵是什么矩阵。

   * **三类求解器怎么选**

| 矩阵情况 | 该用什么 |
| :--- | :--- |
| 规模小（一千维以内） | 直接法：LU；对称正定用 LLᵀ（Cholesky） |
| 规模大、图省事 | 不动点迭代：Jacobi / 高斯–赛德尔，调松弛系数，可升级为多重网格 |
| 对称正定 | CG（配预处理更快：DPCG、ICPCG） |
| 对称，不保证正定 | MINRES |
| 一般（非对称） | GMRES、BiCG、BiCGSTAB |

       * 选型逻辑：矩阵规模小（如小于一千维）直接求解通常最快；规模大了直接法受 $O(n^3)$ 复杂度限制非常慢，迭代求解器更有优势。

       * 不动点迭代的定位：实现非常简单但收敛速度不一定快，一般需调节松弛系数平衡稳定性与收敛速度；还可改进为多重网格方法——速度非常快。

       * Krylov 子空间方法的定位：收敛速度一般很快，但要对不同矩阵使用相对应的方法（对称正定用 CG，对称用 MINRES，一般矩阵用 GMRES、BiCG 等）；预处理还能大大提高收敛速度。

       * 总原则：解 $A\mathbf{x} = \mathbf{b}$ 没有通用的、最优的 solver，按实际情况选合适的求解器；NumPy、SciPy、MATLAB 都有内置实现，函数名直观——LU 一般叫 `lu`，LLᵀ 可能叫 `cholesky`，CG、MINRES 一般直接叫 `cg`、`minres`。
