## 怎么学
- **先补三维旋转与运动学**：FK/IK 是后面所有角色控制的基础。
- **关键帧与曲线插值动手做**：理解切线、缓入缓出。
- **动作匹配（Motion Matching）抓住特征与检索**，这是数据驱动动画的核心。
- **蒙皮部分对照线性混合蒙皮与对偶四元数**。
- **物理仿真与强化学习控制连着看**：仿真角色怎么被「驱动」起来。
