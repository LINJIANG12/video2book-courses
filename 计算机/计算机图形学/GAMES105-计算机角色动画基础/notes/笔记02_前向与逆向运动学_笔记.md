# 前向与逆向运动学

## 运动学与角色抽象

* **运动学（kinematics）**

    * > **定义**：研究物体运动的学科，前提是不考虑物体的质量、力这些"外来的"性质；一旦把质量与力考虑进来，就进入动力学（dynamics）的领域。

* **骨骼（bone / link）**

    * > **定义**：构成角色的刚性部件；整个身体抽象成若干骨骼的组合，每两块骨骼之间由一个关节连接，这是最常用的角色抽象。

    * 身体本身是刚性的，只会沿着关节进行旋转；"软"角色（非刚性）也存在，把刚性这套描述加以扩展同样能实现想要的效果。

    * 角色不限于人：机器人（双足机器人、机械臂）也算角色，角色动画与机器人领域在这方面共享非常大的一块技术。

    * 对动画而言，骨骼本身的形状与参数大多不被特别关注，真正关心的只有两件事：关节的位置，以及关节的旋转带给角色姿态的改变。

* **关节（joint）**

    * > **定义**：连接两块骨骼的部件，保证它们在旋转的过程中不会分开。

    * 创建一个姿势 = 旋转某一个、每一个关节，把肢体摆动到某个状态。

    * "旋转中不脱开"不会自动满足：必须非常准确地计算每个关节在一次旋转后带来的影响——旋转之后它的位置和朝向各是多少，这个计算过程就是前向运动学要做的事。

## 关节类型与自由度

* **关节类型**

    * 每个关节以什么方式旋转，由关节和骨骼的具体结构、形状共同确定；对很精确的人体模型，关节种类可以多到每个关节都不同，角色动画通常建得简单一些，只考虑几种常用的关节表示方式。

* **自由度（degree of freedom，DOF）**

    * > **定义**：唯一、准确描述一个物理系统当前状态所需的参数个数；直观理解是物体能在多少个独立方向上移动。

    * 任何一个三维旋转都可以分解成沿坐标轴旋转的组合（如欧拉角表示），所以数自由度时不用单列"绕任意轴旋转"。

| 情形 | 能动的独立方式 | 自由度 |
| :--- | :--- | :---: |
| 自由立方体 | 沿 x/y/z 平移 + 绕 x/y/z 旋转 | 6 |
| 立方体放在平面上 | 沿 x/z 平移 + 绕竖直方向（y）旋转 | 3 |
| 立方体穿在轴上 | 沿轴滑动 + 绕轴旋转 | 2 |

* **铰链关节（hinge joint，revolute joint）**

    * > **定义**：单自由度旋转关节，有一条确定的旋转轴，只能沿这条轴进行旋转。

    * 人体对应：手肘、膝盖——只能朝一个方向旋转，反着转就出问题了（多半是骨折了）。

* **球窝关节（ball joint / ball-socket joint）**

    * > **定义**：三自由度关节——"碗"形结构包住一根骨头，没有确定的旋转轴，可在整个范围内任意旋转。

    * 人体对应：髋关节、肩关节。

* **万向节（universal joint）**

    * > **定义**：两自由度关节，两段肢体分别绕两根（可以是互相垂直的）轴进行旋转。

    * 机械里用得挺多，可用来做传动、转向；人体上手腕差不多就是万向节的抽象。

* **关节自由度上限**

    * 关节有一条最基本的性质：保证两个物体不会分开——相当于限制了物体不能发生位移方向的移动；只考虑旋转的情况下，关节的自由度通常最多为 3。

* **关节极限（joint limit / angle limit）**

    * 膝盖不能往反方向旋转，旋转范围大约是 0 到七八十度；球关节同样有极限，且很多时候取决于身体柔韧性——抬腿 90 度到头与抬到 150 度以上都存在。

    * 做角色动作生成时，关节极限是经常需要考虑的问题。

| 关节类型 | 自由度 | 旋转方式 | 人体中的例子 |
| :--- | :---: | :--- | :--- |
| 铰链（hinge / revolute） | 1 | 绕一条确定的轴转 | 手肘、膝盖 |
| 球窝（ball / ball-socket） | 3 | 无固定轴，范围内任意转 | 髋、肩 |
| 万向节（universal） | 2 | 绕两根轴分别转 | 手腕（近似） |

## 前向运动学的链式求解

* **前向运动学（forward kinematics，FK）**

    * > **定义**：给出每个关节的旋转，从根到末端逐级更新每个关节坐标系的位置与朝向——本质是一系列坐标变换的组合，非常简单。

* **单链与坐标系约定**

    * 以机械臂为例：一条链上若干个关节按 0 到 4 编号；每个关节上绑一个坐标系，原点刚好落在关节的旋转点上，这个坐标系在世界坐标系里的方向就定义为该关节的朝向。

    * 初始时所有关节坐标系与世界坐标系平行重合，朝向为单位旋转；相邻关节之间的距离 $l_i$ 等价于"关节 $i{+}1$ 的原点在关节 $i$ 局部坐标系下的坐标"。

* **朝向递推**

    * 记第 $i$ 个关节坐标系的朝向为 $q_i$、关节自身旋转为 $r_i$（都用旋转矩阵表示）；每转一个关节，它后面所有子关节的朝向都会跟着变——转关节 4 时 $q_4 = r_4$，再转关节 3 时 $q_4 = r_3\,r_4$，依次往前：

        $$q_i = q_{i-1}\,r_i \qquad\Longrightarrow\qquad q_4 = r_0\,r_1\,r_2\,r_3\,r_4$$

    * > **易错点** ⚠️：新转上去的父关节乘在左边——父在前、子在后，次序不能颠倒。

    * 正用：已知父关节朝向与当前关节旋转，直接算出当前关节朝向；反用：给父关节朝向求逆再乘上当前朝向，$r_i = q_{i-1}^{-1}\,q_i$，反解出关节的旋转。

    * 相对旋转：把从某个关节到当前关节这一路上所有关节的旋转乘起来，就是这两个关节之间的相对旋转。

* **位置递推**

    * 骨骼是刚性的：转动关节 1 会带动后面所有关节一起旋转，但"关节 1 在关节 0 坐标系里的局部表示 $l_0$"不会变化；从局部走到世界只是一次坐标转换（关节 0 在原点或任意位置 $p_0$ 都成立）：

        $$p_i = q_{i-1}\,l_{i-1} + p_{i-1}, \qquad x_{\mathrm{world}} = q_4\,x_0 + p_4$$

    * 链末端挂点 $x_0$（在第 4 关节系下的局部坐标）反推它在第 3 关节系下的表示：把 $q_4 = q_3\,r_4$、$p_4 = p_3 + q_3\,l_3$ 代入展开，得 $r_4\,x_0 + l_3$；继续往前推，每个局部坐标系下的表示都能算出来。

* **从梢到根的逆向换算**

    * 把一个点依次转换到父节点的局部坐标系里，每步用同一组数据——当前坐标系在父坐标系里的局部表示：原点的局部坐标是相邻关节距离，朝向的局部表示刚好是关节自身旋转：

        $$x^{(i-1)} = r_i\,x^{(i)} + l_{i-1}$$

    * 迭代不必从根开始：只想算末端点在中间某一个关节（如关节 1）局部系下的坐标，就从那一环开始迭代；只关心位置、不关心朝向时，直接做逆向迭代即可完成整套换算。

* **树形结构与根节点**

    * 真实角色建模成由多个链条连接到同一个根节点构成的树形结构，有且只有一个根节点；从根到手、从根到腿各是一条链。

    ```text
              ○ 根节点（有且只有一个，通常放在腰上）
             / | \
            /  |  \
       根→手的链 ··· 根→腿的链
    ```

    * 根节点通常放在腰的位置——它带来的是整个角色的朝向和位置的信息，整体朝向总是由根节点决定。

    * 根节点选在不同关节（如腰 vs 右脚），用同样方式旋转右腿关节时整个角色的旋转方式就变了——但两种情况下的姿态本质完全相同，只是整个身体的朝向会跟着变。

## 姿势参数化与动作文件

* **姿势的参数化**

    * 角色建成树形结构后，一个姿势 = 根节点的位置和朝向（6 个自由度）+ 树形结构里每个关节的旋转；整个角色的自由度 = 6 + 每个关节自由度的总和。

    * 参数个数随关节类型而不同：铰链关节（如指关节）表示旋转只需 1 个参数——沿旋转轴的转角；球关节至少需要 3 个参数。

* **关节列表的排序要求**

    * 为计算方便要求：一个关节在列表中的顺序必须比它后面所有的子关节都靠前；这样从根出发遍历一遍关节列表，整棵树的位置与朝向更新就完成了——这就是数据结构里"树"的一种实际实现方式。

* **可伸缩关节的扩展**

    * 前向推导假设关节刚性（不伸长、不拉伸）；机器人经常有线性关节（沿某个方向移动）、平面约束关节（在一个水平面上移动），只需在内部关节的旋转参数之外再加上它自己的平移作为参数，即可支持可变形关节。

* **BVH 动作文件**

    * 一个动作由很多姿态构成，姿态序列放进文件；常用格式有 BVH、ASF、AMC 以及更复杂一点的 FBX，其中 BVH 因很多开源动作捕捉库基本都提供而使用非常广泛。

    * BVH 分两部分：开头定义角色——在每个关节旋转等于零的零位姿势（T-pose）下，每个关节和它父关节之间的相对位置关系；接下来描述在定义好的角色之上每个关节的旋转应该是多少——每行一个姿势，100 个姿势就有 100 行。

    * BVH 用欧拉角表示关节旋转，而欧拉角有旋转顺序问题，所以骨骼定义里会额外声明欧拉角的顺序（如 ZYX，三个轴的旋转矩阵按这个固定次序相乘）；顺序不同，同样的三个角度摆出来的姿势不一样。

    * 文件下面的动作数据每一行代表一个姿势，每行的参数刚好按声明好的轴顺序排列。

## 逆向运动学的问题定义

* **逆运动学（inverse kinematics，IK）**

    * > **定义**：与前向运动学相反——直接指定末端点的位置和朝向，让 IK 算法自动计算出每一个关节的旋转应该是多少。

    * 实际应用比 FK 更广泛：做角色绑定（rigging）时通常会建立若干个 IK 控制器，动画师主要通过这些 IK 控制器来改变角色姿势。

    * 不直接调关节角度的原因：靠欧拉角把姿势摆到某个状态非常困难——每个轴大概转成什么样心里有数，但组合起来稍微调一调就不知道跑哪儿去了，很难有直观的方式说"我就想要转到某一个角度"；IK 更简单、结果也更直观。

* **前向问题与逆向问题**

    * IK 是更通用、更广泛的"逆向问题"的特例。前向问题：已知系统参数（如每个关节的旋转）计算某个属性（如某个关节点的位置）；软体已知刚度、材料系数，通过前向仿真得到外力下的形变过程也是前向问题——函数形式确定后只要计算函数值就得到解，比较容易。

    * 目标属性的维度通常远小于参数的维度：整条链的旋转自由度通常较大，而只控制一个末端点只有三维。

    * 逆向问题：已知目标属性想要达到的值，反算系统参数使属性达到该值——等于要求解一个高度非线性、非常复杂的函数的根，通常比前向问题难很多。

    * 这个函数通常不是单射：会有很多不同的参数组合完成同样的目标，如何选择组合达到想要的效果是另一个难点。

* **解的存在性与多解**

    * 目标点超出整个机械臂的总长 → 没有解；目标点贴着根部那一圈 → 也没有解，不管怎么选关节角末端都到不了里面那一圈。

    * 中间部分的任何一个点，都至少有两种以上的方式能够到达——IK 很多情况下是多解问题。

    * 多解在身体上非常直观：同一个目标点，肘可以朝上也可以朝下，两套姿势都对。

## 两关节 IK 的解析求解

* **两关节 IK（two-link IK）**

    * > **定义**：两个关节、两段肢体的最简 IK 问题；人的胳膊和腿就是两关节连着两段肢体构成的链，想让手伸到前面碰到一个物体，很多时候解一个两关节 IK 就可以。

    * 单独讲它还有一层原因：足够简单，可以用很容易的方法算出解来。

* **几何作图法**

    * 以关节 0 为圆心、关节 0 到 1 的杆长为半径画一段圆弧；再以目标点 x 为圆心、关节 1 到 2 的杆长为半径画一段圆弧；两个圆弧的交点肯定就是关节 1 应该在的位置，然后根据这些相对关系把每个关节的旋转算出来。

* **两步旋转法**

    * 第一步：旋转关节 1，使得 0 到 2 的距离等于 0 到 x 的距离——三角形两条边（两段杆长）与第三边（0 到 x 的距离）已知，用余弦公式算出两段杆在关节 1 处的夹角 $\beta$，关节 1 该转多少也就定了：

        $$\cos\beta = \frac{|01|^2 + |12|^2 - |0x|^2}{2\,|01|\,|12|}$$

    * 第二步：此时 0 到 2 的距离已等于 0 到 x 的距离，再旋转关节 0，把向量 02 转到 0x 的位置使 2 跟 x 重合——旋转轴取 02 和 0x 的叉乘，旋转角由这两个向量的点乘给出。

    * 附加旋转：三维里在 0 到 x 这条连线周围的旋转都满足条件，所以可以沿 0x 再做一次额外旋转把中间关节转到需要的位置——如手或脚伸到某位置后，沿髋到脚踝的连线再加一个旋转，把膝盖转到比较舒服的朝向。

## 一般 IK 的优化形式与迭代框架

* **IK 写成优化问题**

    * 一般 IK 的定义：希望末端点的位置移动到目标位置 $x^{*}$，同时末端点的朝向达到期望朝向；修改朝向相对容易、修改位置才难，所以先把朝向放到一边，只考虑位置。

    * 把每个关节的旋转参数化（欧拉角、轴角表示、四元数等），记这组参数为 $\theta$，末端点位置写成函数 $f(\theta)$；求根问题 $x^{*} - f(\theta) = 0$ 可以等价转换成最小化二次目标：

        $$E(\theta) = \left\| x^{*} - f(\theta) \right\|^2$$

    * $f(\theta)$ 跟目标点重合时，优化问题取得极值（最优值刚好等于零）；这个目标函数高度非线性——以两个参数为例，等值面一圈套一圈，越往里目标函数值越小。

* **迭代求解框架**

    * 从初始姿势（初始参数点）出发循环：找一个最有希望改进目标函数值的方向 → 沿这个方向移动一个合适的距离（步长）→ 把参数更新到新的位置 → 判断是否足够接近最优点，不够就重复。

    * 出口有两个：足够接近最优点时停止、返回当前值；或迭代到一定次数后强制停止、返回当前值——它可以认为是（近似的）最优值，也可以认为这个问题没有解。

    * 保底机制必需：目标函数是非线性的，换不同的算法很可能迭代很多次还是没足够接近。

    * 不管哪种迭代方法，关键问题就两个：怎么找一个比较好的方向更新参数、怎么找一个比较合适的距离更新参数——各 IK 算法就是对这两个问题的不同回答。

## 循环坐标下降（CCD）

* **坐标下降（coordinate descent）**

    * > **定义**：把参数对应的坐标轴方向当作更新方向，每次沿一个坐标轴做一次查找，取"更新之后这个点在该坐标轴方向上对应的目标值最小"的点，再换另一个坐标轴同样下降。

    * 收敛依据：每次更新都保证新坐标点的目标函数值比之前的小——每一步函数值总是在不增的（不一定真减少，但至少不增加），不断交替下去最终得到局部最优点。

* **循环坐标下降（cyclic coordinate descent，CCD）**

    * 参数多时最简单的选法：循环地、依次地用每一个轴下降——第一次沿第一个轴、第二次沿第二个轴……第十次沿第十个轴，第十一次循环回第一个轴；用它解 IK 的优化问题，得到的就是 CCD IK。

    * 机械臂上的具体操作：旋转某个关节，转到"该关节与末端点的连线"跟"该关节与目标点的连线"重合，就完成了一次坐标下降。

    * 几何解释：该关节旋转参数在取值范围内逐点取值，末端点扫出一个圆周（圆心是关节）；圆周上离目标最近的点肯定是"目标点跟圆心的连线"与圆周的交点——这一步旋转刚好把末端点转到那里，等价于沿该参数轴做了一次下降。

* **向量对齐旋转**

    * CCD 每一步都是那个出现好多次的老问题——把一个向量旋转到跟另一个向量重合：设 $r$ 为关节指向末端点的向量、$v$ 为关节指向目标点的向量，旋转轴 $\omega = r \times v$（叉乘），转角满足 $\cos\theta = \dfrac{r \cdot v}{\lVert r\rVert\,\lVert v\rVert}$（点乘）。

* **CCD 循环与代价**

    * 按某一个顺序依次循环旋转每一个关节（从末端侧的关节 3 开始也行，从第 0 个关节开始也行），每次旋转都使末端点的位置跟"对应关节到目标点的连线"重合；一轮做完回到起始关节继续，直到末端点足够接近目标。

    ```text
    一次 CCD 循环（此例从末端侧的关节 3 开始，顺序也可以反过来）：

      旋转关节 3：让「关节3 → 末端点」与「关节3 → 目标点」两条连线重合
          ↓
      旋转关节 2：让「关节2 → 末端点」与「关节2 → 目标点」重合
          ↓
      旋转关节 1、关节 0：同理
          ↓
      末端点还没足够接近目标 ──► 回到关节 3，进入下一轮
    ```

    * 每次旋转就是一次叉乘加一次点乘：CCD 整体计算量非常小，实现非常容易，实际跑起来也非常快。

* **CCD 的特点**

    * 总是"第一次移动的那个关节"动得比其他关节多一点。

    * 完全基于坐标方向做更新、本质上不考虑目标函数的性质：某些特定情况下收敛速度比较慢——可能需要很多次迭代才能得到解，甚至迭代很多次都没有解。

    * 末端点从一个位置逐渐向另一个位置移动、过程中不断求解 CCD 时，解出来的姿势可能在不断抖动——输出姿势可能不是一个稳定的状态。

    * 旋转顺序是实现上的一个自由度：按 3→2→1→0 或反过来 0→1→2→3 循环都能得到 IK 的解；按链条本身的性质选——人伸手够物体时肩膀的移动范围比手小，就应该先旋转肩膀、再旋转手肘，依次循环。

## 梯度下降与雅可比转置法

* **梯度（gradient）**

    * > **定义**：标量目标函数对参数的每一个分量分别求导、把导数值写成的列向量，代表函数在该点增长最快的方向。

        $$\nabla E(\theta)=\Big(\frac{\partial E}{\partial\theta_1},\ \frac{\partial E}{\partial\theta_2},\ \cdots,\ \frac{\partial E}{\partial\theta_n}\Big)^{T}$$

    * 梯度下降总结成一句话：每次迭代把当前参数值沿梯度方向的反方向移动一小段距离——本质上想让函数变小，就沿增长最快的反方向走。

    * > **易错点** ⚠️：步长不能贪大——太大一步就会越过、错过极值点；非常大甚至会在极值点两侧反复横跳，最终还是落不到极值点上；函数性质再差一点，一次走得太远可能跑到非常不好的地方，整个优化直接崩溃。通常选相对小一点的步长保证收敛。

* **雅可比转置法（Jacobian Transpose）**

    * 对 IK 目标函数算梯度，具体等于：前向运动学函数对每一个旋转参数的导数，乘上当前位置跟目标位置的距离差——导数部分通常写成矩阵，就是雅可比矩阵。

    * 这种更新方式就叫雅可比转置法，它本质上等价于梯度下降——两个是等价的方法。

## 雅可比矩阵的计算

* **雅可比矩阵（Jacobian）**

    * > **定义**：前向运动学函数 $f$ 输出三维末端点 $(f_x, f_y, f_z)$，对这个问题雅可比矩阵就是 $3\times n$ 的矩阵（$n$ 为全部参数的数量），第 $i$ 列是 $f_x, f_y, f_z$ 分别对第 $i$ 个参数 $\theta_i$ 求导得到的三个数：

        $$J_{:i}=\frac{\partial f}{\partial\theta_i}=\Big(\frac{\partial f_x}{\partial\theta_i},\ \frac{\partial f_y}{\partial\theta_i},\ \frac{\partial f_z}{\partial\theta_i}\Big)^{T}$$

* **自动微分**

    * 用 PyTorch、TensorFlow 这类方便的框架把前向运动学实现一遍，然后利用框架自带的自动求导功能直接把梯度（雅可比矩阵）算出来。

    * 非常简单、也可以说非常偷懒，但对一些很复杂的系统反而是效率更高的方法——如 Simulink 把模型设计好后可以自动生成 C++ 代码，而这个代码刚好就能计算雅可比矩阵的值；实际上一直都是用这一类工具实现的。

* **有限差分**

    * 没有自动微分工具时的万能兜底：先用当前参数做一遍前向运动学得到末端点位置；给 $\theta_1$ 加上一个很小的偏移再做一遍得到新位置；两次函数值之差除以偏移量就是导数的近似——两点连线之差刚好给出雅可比这一列的所有值（三个分量一次全出来）：

        $$\frac{\partial f}{\partial\theta_1}\approx\frac{f(\theta+\varepsilon\,e_1)-f(\theta)}{\varepsilon}$$

    * 需要依次对每一个关节、每一个参数都做一遍前向运动学与差分计算，才能把矩阵每一列逐渐填起来——整个计算量相对来说比较大。

* **解析解：铰链关节**

    * 所有关节都是 hinge（单自由度、沿某确定轴旋转）、关节 $i$ 的旋转轴在世界坐标系下为 $a_i$ 时：由罗德里格旋转公式（Rodrigues），末端点沿轴转极小角度 $\mathrm{d}\theta$ 的位移差不多沿 $a_i \times r$ 的方向；把位移差除以旋转角度并让角度趋于零取极限，即得这一列偏导——全局坐标系下的旋转轴，叉乘上"关节指向末端点"的向量：

        $$\frac{\partial f}{\partial\theta_i}=a_i\times r_i,\qquad r_i=p_{\text{末端}}-p_{J_i}$$

    * 对每个关节如法炮制——用关节自己的、在全局坐标系下表示的旋转轴，叉乘上该关节到末端点位置的向量——逐次计算就能完成雅可比矩阵每一列。

* **解析解：球关节（欧拉角）**

    * 球关节三个自由度、旋转轴不固定；把旋转参数表示成欧拉角 $R_x\,R_y\,R_z$，等价于三个 hinge 关节重合在同一个位置（关节中心）、分别绕自己的轴旋转——欧拉角有三个参数，对应雅可比的三列：

        $$\frac{\partial f}{\partial\theta_x}=a_x\times r,\qquad \frac{\partial f}{\partial\theta_y}=a_y\times r,\qquad \frac{\partial f}{\partial\theta_z}=a_z\times r$$

    * 麻烦在于叉乘要求坐标轴是世界坐标系下的向量表示，而欧拉角的三个轴是一层套一层的局部轴：$a_x = R_{\text{父}}\hat{x}$（乘父关节朝向）；$y$ 的旋转发生在 $x$ 旋转的内部、是局部进行的，$a_y = R_{\text{父}}R_x\,\hat{y}$；$z$ 是最后一个轴，要带上前面所有的旋转，$a_z = R_{\text{父}}R_xR_y\,\hat{z}$。

    * > **易错点** ⚠️：跟铰链关节不一样——不能简单地拿 $\hat{x}$、$\hat{y}$、$\hat{z}$ 三个轴直接去叉乘 $r$；必须分别把三个轴变换到世界坐标系，排在后面的轴会受到前面轴旋转的影响。

    * 欧拉角还有其他表示方式：如顺序 $R_x\,R_y\,R_x$（最后又沿 $x$ 转一次），三个坐标轴的计算类似——把第三个 $x$ 轴做坐标变换，换算到它实际所在的新位置。

## 高斯牛顿法与雅可比伪逆

### 二次问题的闭式解

* **一阶最优条件**

    * 梯度代表函数变化最快的方向；某点梯度为零 → 在这个位置不管怎么移动函数值都不发生变化 → 局部极值点（不一定是最小点）。$\nabla E = 0$ 就是极值点的一阶最优条件。

* **二次规划的闭式解**

    * 最简单的例子是二次规划（quadratic programming）：目标函数 $E(\theta)=\frac{1}{2}\theta^{T}A\theta+b^{T}\theta$，对 $A$ 的基本要求是正定——$A$ 是对称阵，且对任何非零 $\theta$，二次型 $\theta^{T}A\theta$ 都要严格大于零。

    * > **提示**：严格大于零才叫正定；允许等于零（$\theta^{T}A\theta\ge 0$）是更弱的条件，叫半正定，两者别混。

    * 梯度 $\nabla E = A\theta + b$，叠加上一阶最优条件得 $A\theta + b = 0$，解得极值点 $\theta^{*} = -A^{-1}b$。

### 泰勒展开与法方程

* **非线性问题的二次近似**

    * IK 的目标函数没有这么良性——前向运动学 $f$ 是非线性函数；在当前点 $\theta^{0}$ 附近对 $f$ 做一阶泰勒展开 $f(\theta)\approx f(\theta^{0})+J\,(\theta-\theta^{0})$，代入目标函数（记 $\Delta\theta=\theta-\theta^{0}$，$\delta$ 为目标点位置跟当前末端点位置之差），目标函数（近似地）变成二次形式：

        $$E\approx\lVert J\,\Delta\theta-\delta\rVert^{2}$$

* **法方程与更新式**

    * 根据一阶最优条件对近似目标函数求梯度并令其为零：$J^{T}(J\Delta\theta-\delta)=0$，即 $J^{T}J\,\Delta\theta=J^{T}\delta$；如果 $J^{T}J$ 可逆，得到参数更新方式：

        $$\Delta\theta=(J^{T}J)^{-1}J^{T}\,\delta$$

    * 沿这个方向更新可以很快找到这一步近似下的最优解；从优化的角度讲这套方法对应高斯牛顿法（Gauss–Newton），通常比简单的梯度下降（雅可比转置方法）快一点。

### 伪逆的两种形状

* **矮胖矩阵：单点 IK 欠约束**

    * 单末端点的雅可比是 $3\times n$ 的矮胖矩阵：矩阵可逆必须满秩，而 $J$ 本身只有行满秩、没有列满秩，乘起来的矩阵秩不会比原来更大，所以 $J^{T}J$ 虽是更大的 $n\times n$ 矩阵，必然不满秩、不可逆。

    * 反过来算 $J\,J^{T}$，得到 $3\times3$ 矩阵，有可能可逆；把法方程两边都乘上 $J$，在它可逆的假设下约掉，得到等价结论 $J\,(\theta-\theta^{0})=\delta$；$J$ 不是方阵不能直接求逆，用伪逆（pseudo-inverse）：

        $$\Delta\theta=J^{+}\,\delta=J^{T}\,(JJ^{T})^{-1}\,\delta$$

    * 因为用了雅可比的伪逆，这个方法通常叫雅可比伪逆方法（Jacobian Inverse）；矮胖矩阵对应单点的、欠约束的 IK 问题（目标少、参数多，解不唯一）。

* **高瘦矩阵：多目标 IK 过约束**

    * 多点 IK 例子：还是机械臂，让末端点到一个位置、第三个关节到另一个位置、第二个关节再到一个位置，且每个关节都是 hinge；四个关节、三个目标点——$f$ 输出三个点的位置（九维向量），参数空间只有四维，雅可比是 $9\times4$ 的**高瘦**矩阵。

    * 此时 $J^{T}J$ 是 $4\times4$ 的，大概就是一个可逆的状态，可以用 $(J^{T}J)^{-1}J^{T}\delta$ 来更新。

    * > **定义**：矮胖 $J$ ↔ 欠约束（目标少、参数多，解不唯一）；高瘦 $J$ ↔ 过约束（目标多、参数少，一般够不到所有目标，只能找最接近的解）。

* **线性化只在附近有效**

    * 这整套算法本质上是把高度非线性的函数线性化了，而线性化通常只在当前点附近才有效，离得很远线性化误差会非常大；实际使用时可在求出的更新方向上再加一个学习率（learning rate），避免一下走得太远、导致解崩溃。

* **求逆的风险**

    * 高斯牛顿每一步都要计算一个矩阵的逆（$JJ^{T}$ 或 $J^{T}J$）：无法保证它一定可逆；甚至它可能可逆但**接近于不可逆**——这种情况下求逆没有意义，或求出一个数值都非常巨大的矩阵，对应一个非常大的移动，给整个优化带来很不稳定的效果。

## 阻尼最小二乘与 Levenberg–Marquardt

* **阻尼最小二乘（damped least squares，DLS）**

    * 为了解决"逆不可靠"的问题，在求逆之前往括号里加上一个阻尼项（damping），保证括号里这个内部矩阵一定可逆：

        $$\Delta\theta=J^{T}\,(JJ^{T}+\lambda I)^{-1}\,\delta$$

    * 可以很简单地推导、很容易地证明：有阻尼项存在时，矮胖写法和高瘦写法两种伪逆形式算出来的结果是相同的。

* **Levenberg–Marquardt（LM）**

    * 加阻尼项的方法的另外一个名字；LM 还有另一种形式——最后所加的那一项不是单位阵，而是 $JJ^{T}$ 这样的形式。

    * 它本身也是很常用的优化方法：首先避免了高斯牛顿法在中间矩阵不可逆的情况下所带来的不稳定问题。

* **阻尼大小的两极**

    * 阻尼项调得非常非常大的时候，这个方法实际上就等价于梯度下降法——所以它可以看成梯度下降的一个改进：阻尼小，接近高斯牛顿，步子迈得快；阻尼大，退回最稳的一阶方法，一小步一小步地挪。

* **阻尼即正则**

    * 加阻尼项等价于在目标函数后面加了一个约束项、一个正则项（regularization）：要求每个关节用尽可能少的旋转来实现末端移动到目标点，解出来的姿态实际体现的就是这个效果。

* **给关节配重**

    * 前述方式每个关节权重相同——尽可能让每个关节用相同的移动实现 IK；实际上可以给每个关节不同的权重：不想让 root 关节（髋）移动很多、想让手部或胳膊多动一点，就给 root 很大的权重 $w_0$、给中间关节（如第二个关节）很小的权重 $w_2$。

    * 效果：第零个关节尽可能少动，尽可能多地用第二个关节的旋转来完成 IK——以此在某种程度上控制旋转过程中的实际效果。

## 全身角色 IK 与方法对照

* **多目标全身 IK**

    * 实际的完整角色是树形结构——多条链条放在一起；在它上面做 IK 通常比较复杂：可能同时需要这只手移动到一个位置、另一条胳膊移动到另一个位置、另一只脚移动到某一个位置。

    * 同样写成优化问题：整体目标由若干子问题构成，每个子问题是一个前向运动学函数减掉对应目标点的位置取平方距离——三个目标就是三项平方距离加在一起，最后再添一个正则项：

        $$E(\theta)=\sum_{i}\lVert f_i(\theta)-t_i\rVert^{2}+\text{正则项}$$

    * 可以往里加其他约束（想让某个关节用得多一点、或基本不动——写出类似带权重的优化函数）；然后计算雅可比矩阵，用雅可比伪逆、雅可比转置这样的方式算出整个角色姿态的变化；$\theta$ 是整个姿态的参数化方式，包括每个关节的旋转。

* **一次一个约束与根节点选择**

    * 实际使用中通常不必一次考虑所有约束——很可能一次只考虑一个约束（如先只让胳膊移动到某个点）；这时选一个根节点和一个末端节点，而根节点选在哪里，效果完全不一样。

    * 根节点选在腰：胳膊移动手的过程中会同时带动整个上半身，形成"向前伸"的效果——不加其他约束时解想要每个关节用差不多相同的旋转，相当于整个身体向 IK 目标的方向倾过去。

    * 根节点选在脚：同样的 IK 目标会用到整条链上所有的关节——相当于整个身体都会向前倾斜去实现目标位置。

    * 根节点选在肩膀：只想让胳膊发生旋转、不想让其他身体部分旋转时用——只有胳膊发生移动来实现 IK 目标。

* **启发式方法**

    * 除基于优化的方法外还有一类启发式方法：先不去考虑优化函数的具体性质，通过设想——拍脑袋拍出一些想法——也可以实现对 IK 问题的求解；CCD 如果不考虑它跟优化问题的联系，每一步的优化过程其实就是一个启发式的过程。

    * **FABRIK**：2011 年一篇论文提出的非常常用的启发式方法，现在很多常见的物理引擎和游戏引擎其实也都支持。

* **优化解法与 IK 算法的对应**

| 优化问题的解法 | 对应的 IK 算法 |
| :--- | :--- |
| 循环坐标下降法 | CCD IK |
| 梯度下降法 | 雅可比转置（Jacobian Transpose）方法 |
| 高斯牛顿法 / Levenberg–Marquardt | 雅可比伪逆（Jacobian Inverse）方法 |

* **方法脾气对照**

| 方法 | 每步的计算 | 收敛与稳定性 | 要留意的坑 |
| :--- | :--- | :--- | :--- |
| CCD | 一次叉乘 + 一次点乘，非常小 | 实现容易，跑得快 | 不看目标函数性质，可能收敛慢甚至无解；跟踪时姿势抖动；第一个转的关节动得多 |
| 雅可比转置 | 每轮重算雅可比 | 迭代次数通常比 CCD 少 | 本质是一阶方法，收敛不够快；总计算量比 CCD 大很多 |
| 高斯牛顿 / 伪逆 | 每轮重算雅可比，还要矩阵求逆 | 收敛更快 | 矩阵可能不可逆或接近不可逆，一步迈太大解就不稳 |
| DLS / LM | 求逆前加阻尼项 | 阻尼保证可逆，稳定 | 阻尼很大时退化为梯度下降 |
