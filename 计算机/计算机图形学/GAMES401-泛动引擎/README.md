# GAMES401：泛动引擎（11 讲）

GAMES401 讲泛动引擎（PeriDyno）：从引擎架构与 GPU 并行基础、图形学常用几何工具、刚体动力学并行编程，到 SPH 与近场动力学仿真、插件体系与 Vulkan 通用计算、工程 CAE 连续介质力学与有限元、CAE 软件集成与工程实践。课程把「仿真内核 + 软件工程」怎么结合讲成一条工程路线。11 集整编为 4 册、7 篇主题笔记。

- **原视频**：[GAMES401-泛动引擎](https://www.bilibili.com/video/BV15M4y1U76M/) — Bilibili，BV15M4y1U76M
- **全 11 集**，已产出 4 册模块全书、7 篇复习笔记、22 份逐字稿
- 全 22 块已完整成稿

## 怎么学
- **先看引擎架构与 GPU 并行基础**，理解数据布局与 kernel 组织。
- **几何工具（求交、距离、包围盒）是仿真基础设施**。
- **SPH 与近场动力学对照学**：核函数与邻域搜索是重点。
- **插件体系与 Vulkan 计算偏工程**，对照代码看接口设计。
- **CAE 集成部分理解「仿真内核 + 软件工程」如何结合**。
