刚才讲其实它的基础是两个：一个是矢量代数，另外一个是张量分析相关的一些内容。这两部分之前王华民老师应该已经涉及过了，包括每一个运算它到底代表什么直观的、从几何上怎么去解释，王老师课里面应该也提过了，这里我就不展开讲了。

大家需要注意一点，所有在这里边看到的线性代数里面的东西，最好能跟几何的直观联系起来，这样有助于你去理解。直接看符号的话很抽象，比如 $a + b$，但如果用几何直观去理解，可能就是两个向量求和，算出它的一个对角线；求差的话就是两个向量的端点一减。类似用这种形式去辅助理解会比较容易一些。

后面的还有像点积，当然还有叉积，还有三重积。这些一定要记得符号代表什么意思。初学者可能有些不一定很熟，比如叉乘，实际代表的是计算出的一个新的方向，沿着跟这两个 $A$、$B$ 都垂直的方向。像后面三重积的话，比较常见的是算平行六面体的体积，会很常见地用这样的一个公式。

当然这里满足还有一些额外的定律，比如交换律或者结合律等等。每一个运算符号可能会不太一样的，有些符号其实是不符合交换律的。比如前三个实际上都是符合交换律的，但是最后两个实际上都不符合交换律，这些在计算的时候一定要注意。这个是矢量代数最常见的这么几个运算。后面讲距离计算包括相交运算的时候，也会用到这几个符号。

还有一个就是大家看仿真的 paper 里面会涉及到大量的张量概念。这个张量直观地怎么去理解呢？张量实际上是一个通用的叫法，如果按照以往初中或者高中学的，张量其实分 0 阶张量、1 阶张量或者是 2 阶张量。

0 阶张量实际上就是我们常说的标量。通常看论文里面标这个符号的话，一般就用小写的字母，像 $a, b, c, d$ 都是小写的斜体，代表的一般是 0 阶张量。

1 阶张量的话其实所谓的就是矢量，一般用粗体的小写字母代表 1 阶张量，它其实也就是一个矢量。

2 阶张量其实就是我们所谓的矩阵，其实就是几乘几，是一个二维的形式，所以它实际上就是一个矩阵。

当然还有更高阶的，比如 3 阶的、4 阶的。像 3 阶、4 阶上去之后，主要会在以后讲到弹性的时候用到。像应力应变张量实际上都是 2 阶张量，实际上是一个矩阵；但是应力跟应变之间的关系，实际上会用一个 4 阶的张量去表示它们的线性关系。

几阶张量实际上就是往某个维度上再增加一维。比如 0 阶张量其实是没有维度；1 阶张量增加一个维度，比如它有一个列也好或者行也好，不同约定可能不一样，增加一个维度其实就是 1 阶张量；到 2 阶的话再增加一个维度就是 2 阶；3 阶的话沿着纵向再增加一个，其实就变成一个体。本质上张量是这么一个概念。

这里边其实还有一个非常重要的东西，我们常见的论文里面一般会以第一行我写的用标量去标，好处是整个形式看起来会非常简洁。但是这种形式在做实现或者做仿真计算的时候，不太适合用来做计算。因为整个这个东西实际上你……

比如你用 CUDA 写实验也好，用 C++ 实验也好，实际上你要知道它里面具体每一项，实际上是项与项之间的一个计算。针对这种，如果你是想实现更方便的话，一般来所会用这种叫爱因斯坦标记法。这个标记法主要是在做实现的时候，因为它主要是用下标来标的，这样的话每一个，比如你写一个 for 循环，这样的话你比如 $i$ 到底是针对的是哪一个下标，$j$ 针对的是哪一个下标，这样的话可以比较清楚，你实现的时候也比较方便。

所以整个后面我会讲一些运算的时候，也会对应地讲一下爱因斯坦标记法，看看它整个是怎么用的。

这里边张量的代数运算，我主要目的列在这还是为了帮大家有一个感性的认识。因为这个东西每个展开比较多，所以我把这个符号先列在这，后面如果碰到某些符号的话，不至于说不知道这个符号是做什么事情的。你有一个概念，反映出来这应该张量里面哪一个运算或者是哪一部分来的，这样的话你可以进一步去比如找相应的书，看看到底应该是什么概念。

这里边典型的你可以发现它主要包含张量的和差。张量和差这里边，因为 $A$、$B$ 我实际上都是以二阶张量为例来举例的，所以你会发现相当于是其实都是一个二维的，所以它的下标的话其实主要就是 $i$、$j$ 两个指标。所以这里边你可以看到，比如两个张量求和或者求差的话，实际上就是对应的一个元素，比如 $A_{ij}$ 这个元素，然后加上或者减去对应的 $B_{ij}$ 的元素。

这里一定要注意，这里的 $i$、$j$ 实际上是一个显式指标，这个跟后面讲到有一个 $k$ 这个哑指标是不一样的。显式指标代表什么意思呢？就是这个 $i$、$j$ 实际上是固定的。你相当于比如说你算左边这个张量，那你这样的话你要去算 $ij$ 这个，后面这两个指标一定要跟前面，就是你公式左边那个 $ij$ 指标是一样的，这个是不能变的。

对应的其实你可以看到后面，比如标量跟张量相乘的话也是一样的，就相当于本意就是标量乘上一个张量，等效于标量跟张量里面的每一个元素相乘，也就是它们这个 $ij$ 指标是对上的。

这里边其实有一个比较特殊的，就是这里边有个点积的这么一个概念，张量里面比较特殊。其实你如果以前学过线性代数，学过矩阵运算的话，其实你发现这就是一个矩阵运算。当然张量因为它是一个更广义的范畴，所以从张量里面怎么去定义这个东西。实际上就是你如果按比如 $A \cdot B$ 这么一算的话，实际上就是你要去算它 $ij$ 下标所对应的一个元素，你会发现它实际上相当于是要把 $A$ 对应的元素，它有一个 $i$，$i$ 是固定的，但这里边会有一个 $k$，这个叫哑指标。这个哑指标就是要变的，这个跟你张量的维数是有关系的。比如一个 $3 \times 3$ 的张量，那这里的 $k$ 实际上是必须得从 0 到 1、2，相当于是三个元素。然后对应的后面的比如 $B$ 也是一样的，就是你要 0、1、2。

所以这里边你会发现，比如我们算一个 $ij$ 的元素的话，实际上这里边会有相当于三项要把它加起来。当然 $i$、$j$ 不变，$i$、$j$ 跟左边是一样的，后面的话这个 $k$ 必须是从 0 到 2 这么一个概念，所以它实际上是一个哑指标。也就是说你后面如果出现的某个下标在前面没有的话，那这个必须得遍历所有的元素，这个元素的个数跟你实际上张量每个方向的维度是相关的。

后面还有一些典型的比如像转置。转置的话实际上就是你放下标换个方向，$i$ 跟 $j$ 变成 $j$ 跟 $i$。当然还有一个缩并，后面两个比较奇怪的符号，其实就是一个冒号的符号，这个叫缩并。缩并什么概念呢？其实如果是两个二阶张量的缩并，缩并完了之后实际上就变成一个标量。所以相当于 $i$ 跟 $j$ 所有的都加起来。因为左边实际上是没有下标的，如果左边没有下标的话，这个 $i$、$j$ 在后面实际上就是一个哑指标，所以相当于需要把所有的元素对应地相乘之后然后再相加。

当然还有一个叫并矢。并矢比如我们在做计算 shape tensor，或者我们根据粒子法然后根据邻域去计算它的一个形状，这个会比较有用。相当于比如两个向量，你怎么合成？其实 $A$ 跟 $B$ 实际上是一个一阶的张量，一阶张量你怎么变成一个二阶张量？这样的话就需要相当于从 $A$ 里面对应地取第 $i$ 个元素，从 $B$ 里面去取第 $j$ 个元素，这两个乘起来之后组成一个二阶张量，就相当于把一个低维的张量生成一个高维的张量。

后面的话主要就是讲三维空间里面的一些基本几何图元，以及我们怎么基于这些几何图元去做距离计算或者是……

三阶张量也会有转置的概念。我看直播里有问。三阶张量实际上什么概念？三阶张量的话其实跟这概念是一样的。比如这里边当然它的下标只是说 $i, j, k$，但是它转置的概念是跟这个一样的。比如你可以对 $i, j$ 转置，那这样的话就是把 $i, j$ 两个符号对调一下；当然你也可以跟 $j$ 跟 $k$ 转置，那这样的话实际上就是 $i, k, j$，相当于 $k$ 跟 $j$ 两个符号对调一下。所以转置的概念实际上就是你把两个下标互换，这个不是二阶张量特有的，不管三阶、四阶、五阶其实都存在转置的概念。这里边有些运算实际上是可以拓展到高维，当然有些可能比较特殊，有些到高维不一定能行。

下面的话我们就来看看三维空间里面一些常见的几何图元。主要包含的就是像点，点的话比如粒子法里面其实就是一个 particle，你就可以理解为一个点。当然还有比如线性的结构，线性主要是包含直线、射线或者线段。当然还有像平面的结构，平面主要包含无穷大的平面，还有比如三角形。三角形是因为图形里面用得非常多，所以这里主要以三角形去讲。其实还有四边形，四边形的话你也可以理解为是两个三角形拼成一个四边形。当然还有一种体的结构，像球、胶囊。这些其实都比较简单，因为整个运算还是相对比较容易，可以用这些基本的几何图元去搭一些更复杂的结构。当然体的话还有四面体，后面还包括 AABB 以及 OBB。

我们后面来看一下，后面我整个过的时候都会包含三种形式：一个就是它的几何表示，它当然就是一个点；还有一个就是我们现在代码里面怎么去定义这么一个东西，比如定义一个点，实际上三维空间里面就对应一个 $(x, y, z)$ 的三维坐标；它当然还有一个参数化的形式，参数化的形式其实就是 $(x, y, z)$，点其实就很容易了。

这里面你会发现为什么这里面要单独定义一个点的结构？因为三维的，比如用很多 vector 它其实也是三维的，但这里为什么要额外定义一个点呢？大家学过 C++ 的话你发现，因为 C++ 主要还是以封装、面向对象的一个概念，点里面包含的运算跟我们传统的三维向量还是不太一样的，所以这里实际上额外定义了一个叫点的结构，这样的话可以用来额外地去实现一些距离计算的功能。

接下来就是一些线性结构，比如像直线。直线的话它其实就……

你可以相当于定义一个原点。当然这个原点其实在哪一个位置无所谓，你定义往前一点往后一点，其实不影响整个定义。除了原点之外，实际上还有一个就是直线的一个方向。当然你可以朝这边，也可以朝这边。如果这个方向不一样的话，它对应的一个参数坐标可能就不太一样。

这样的话实际上整个直线，它的参数化的一个形式就是原点加上一个 $t$，然后乘上它的一个方向的一个向量。这个 $t$ 对于直线的话，因为它是无穷，它不是有限的，它实际上是无论是哪一端，比如向上也好向下也好，它实际上都可以延伸到无穷远之处。所以你发现它的参数坐标实际上就是从负无穷到正无穷。对应到代码的实现的话，你发现它实际上主要是两个东西，一个就是对应的原点，还有一个方向。这个 $t$ 实际上是隐含在里面的，因为 $t$ 是整个在计算的过程中会去计算，你是不需要把这个东西存下来的。

后面比如看射线的话，其实整个结构非常像，这里唯一不一样的是射线因为它只有一半。也就是说它的参数形式的话，你可以看它相当于是它的 $t$ 必须是大于等于 0，然后相当于可以到正无穷，但是不能到负无穷。当然这个是约定，如果非要搞成负无穷当然也没问题，但是一般大家都比较容易接受的实际上是按照正无穷的这个形式。看它内部的结构，就是它的算法的定义，其实你发现跟那个完全一模一样，就是相当于有一个原点，然后有方向。也就是说其实包括这个 $t$ 因为也是这样，你在结构上可以通过结构来判定它到底是什么类型，所以你也不需要隐式地去把这个 $t$ 给定义在里头。所以你需要的数据类型实际上只需要两个三维的矢量。

接下来还有就是线段。线段的话其实跟那个稍微有点不太一样。当然也有种方式是线段实际上你也可以按前面参数化的形式，比如定义一个原点，然后定义一个方向，然后它是 0 到 1，你可以这么去定义。但是线段的话，更简单的一种方式实际上就定义它的两个端点，左端点跟右端点，它相当于是包含了两个三维的一个坐标。它的参数形式实际上是中间任何一个点都是用它的两个端点插值插出来的。中间一个点，两个权重，左边那个权重就 $v_0$ 对应的一个 $1-t$ 这么一个权重，然后 $v_1$ 对应的一个 $t$ 的一个权重。这两个权重加起来始终是等于 1 的。也就是说它的 $t$ 的范围一直是处在左端点跟右端点限制的这么一个范围内，它是不能超出范围的。所以这是线段的一个定义。

总体来说你发现这三个结构非常的相似，唯一不一样的，你如果从参数化的形式去看的话，它主要是体现在 $t$ 的一个范围。像直线的话其实就是 $t$ 从负无穷到正无穷，然后射线的话就是从 0 到正无穷，如果是线段的话，完全就是从 0 到 1 的这么一个定义。

后面就是有一个平面的一个定义。你发现它最核心的主要两个东西，一个是你定义一个原点，这样的话相当于你有个参照的标准。有了这个原点之后，你额外要知道整个平面的一个方向，它是朝哪个方向。有了这个之后，你可以计算出平面上任意一个点。因为平面它有个性质，它任意一个点跟原点形成的这么一个向量，它实际上跟法向是垂直的。所以实际上它任意一个点都可以表示成：

$$(x - o) \cdot n = 0$$

因为在向量线性代数里面，点乘等于 0 的话代表它俩的方向是垂直的。所以它任意一点都要符合这么一个公式。进一步的话你发现这个东西如果展开之后，你把这个两两相乘，其实这个东西就变成了我们以前常见的解析几何里面学的平面的表达形式，就是：

$$Ax + By + Cz + D = 0$$

这么一个公式。在这里面你发现其实就 $A$、$B$、$C$ 这几个参数，你把它单独拎出来的话，实际上就代表整个平面的一个法线方向。它整个算法的话，你发现实际上只需要两个，一个是它的原点，第二个就是法向。也就是说这个 $x$ 的任意一个点其实都是隐含在，因为你定义它的基本数据结构是不需要把 $x$ 定义出来的，相当于在计算的时候，你可以隐式地去算它到底是什么每一个点。这个在后面讲包括计算距离，像 GJK 的时候都会去讲这个东西。

还有一个就是三角形。这个三角形你发现图形学里面用得非常的常见。因为整个图形学包括渲染什么其实都是，最最核心的其实就是三角形。这里面三角形的话最主要你可以发现它其实就是三个顶点。但这里边一定要注意的一个地方就是，三角形的三个顶点它是有方向的。一般来说通常我们约定的是它是一个逆时针的一个方向。这个东西不能搞错，因为如果搞错的话就会导致比如后面你做碰撞检测，很有可能会导致你正反面搞错之后，可能会导致它整个计算的时候会发生穿透，就有这么一个问题。因为这样的话正常比如一个体表面，你需要通过它的表面方向来判定它到底是哪一面是朝外哪一面是朝里。所以一般来说你需要通过三角形的顶点的顺序来判定。如果所有表面的所有三角形的定义都是统一的，比如都按顺时针或者都按逆时针，那这样的话你实际上是可以很容易地去判定到底是哪一面是朝里哪一面朝外。但如果你是乱序的，比如有一些是逆时针有些是顺时针的话，这个很容易会导致你后面整个计算的时候非常容易出错。所以一般来说我们就假设所有的三角形，其实这里不光三角形，比如四边形或者其他的多边形等等，一般来说也是这么一个约定，就是按照逆时针的方向去定义它的一个顶点顺序。

在这里边这样定义完了之后，三角形里面它任意一个点实际上都可以表示成参数化的一个形式。主要是可以通过它的两条边，比如 $v_1 - v_0$ 然后 $v_2 - v_0$ 这两条边，你可以去计算它内部的任何一个点。它这里边就包含两个参数坐标，就是 $s$、$t$。$s$、$t$ 一定要符合三角形下面的一个约束：首先 $s$、$t$ 这两个加起来是等于 1，同时 $s$、$t$ 这两个必须是属于 0 到 1 这么一个范围。同时你发现如果按这么定义的话，按照你的右手法则你可以去算一下，$e_0$ 跟 $e_1$ 这两个右手法则一算法线的话，实际上正好是朝外的，也就是说你可以指示你到底是哪一面是相当于一个体的一个外部。代码的话你发现就很简单了，就是一个三个顶点的数组。

后面就是有球。球的话主要是需要定义它的一个中心点，然后它对应的一个半径。球的内部的每一点实际上就符合你的整个距离要小于 $r$ 的一个平方。看代码的话其实就是一个中心点加一个半径。

最后其实就是有两个比如做碰撞检测或者做那个的时候非常常用的两个结构，一个叫 AABB 结构。这个在后面讲刚体的时候会用到。主要原因还是为什么用这个结构呢？主要还是因为其实从它的定义可以看出，它其实就是需要两个顶点。也就是它整个计算其实是非常方便的。这样的话可以用这个 AABB 结构来加速比如碰撞过程中，你想跟邻域做一个查找，预先你把不太可能发生碰撞的一些物体，可以用这个 AABB 的结构给它剔除掉。

当然 AABB 的好处就是，它实际上整个计算比较简单。不好的地方可能就是说它整个从包围盒的角度来讲可能没有那么紧致。所以还会有一种比较常见的，就是叫 OBB。OBB 的话实际上就代表了，实际上你发现其实就是把 AABB 转了一个方向。所以你会发现以它的中心点实际上就会有一个新的坐标系。这个标架实际上就定义了一个新的标架。也就是说，比如你的物体可能是沿着某一个朝向的，它可能不一定是沿着标准的 $x, y, z$ 这么一个方向。那这样的话你实际上就可以用这个 OBB，可以定义一个更紧致的包围盒。

所以它这里边就包含几个东西：一个当然就是你中心点的一个位置，这个跟 AABB 是一样的；还有一个就是你会发现这里边就必须得定义三个轴。当然这个 $u, v, w$ 必须是垂直的，同时一般来说实际上是单位向量，也就是你会发现这 $u, v, w$ 这三个向量组在一起的话，实际上就变成一个类似于旋转矩阵。也就是说你相对于 AABB 旋转了什么样的一个角度之后，就变成了这个 OBB。所以你会发现 $u, v, w$ 最后可以张成一个，这个新的标架实际就是一个旋转矩阵。当然还有一个就是对应它的长度，一般来说这个定义的是它的一半，也就是以它的中心点分别到它的各个面的一个距离。所以你会发现这个的话它主要包含主要有四个三维向量，差不多这么一个结构。

首先我们来看一下距离的计算。距离因为主要是类型比较多，这里边比较常用的主要还是点到其他的一些图元的距离计算。这次课的话主要会讲点到点的距离计算，点到线条结构（包含直线、射线、线段）的距离计算，另外还有点到平面跟三角。因为这个其实就是前面包含讲的所有三维图元，所以这里边主要还是讲点到前面那些图元的距离计算。

接下来我们就看一下，首先是点到点。这一部分应该都很简单了，大家应该以前都学过，相当于两个点之间的一个距离，实际上就是一个向量，相当于两个向量相减，减完之后你算一个模。这部分其实不需要讲太多东西。

后面的话主要讲一下点到一个线性结构的距离。前面讲不论是直线也好、射线也好，或者是线段也好，在它的定义上实际上是可以统一起来的。比如如果是直线的话，从参数坐标的角度来讲，实际上它是从负无穷到正无穷；如果射线的话实际上就是 $t \ge 0$；线段的话就是 0 到 1。所以从这个特点上来讲，你的点不论是算到射线也好，或者直线也好，或者线段也好，整个计算上实际上是可以统一的。

这里边我们的一个思路怎么做呢？你先不管它是直线也好或者射线也好，先不管这个 $t$ 到底是一个什么范围，假设统一地先去计算点 $P$ 到线性结构上的一个投影点。根据这个投影点算完之后，实际上可以根据下面的公式，用 $P$ 减去 $V_0$ 这么一个线段，然后点乘 $V_1$ 减去 $V_0$ 这么一个线段，可以计算它参数坐标 $t$。接下来就可以根据这个参数坐标进一步地去判定：如果是直线的话，任意的参数坐标 $t$ 实际上都是符合要求的；但是如果现在是射线，如果你出现 $t < 0$，实际上可以把你的 $t$ 给它截断，截断到 0。直观上怎么理解呢？实际上就是比如说这个点 $P$ 投到了超出 $V_0$ 的这个部分之后，离它最近的点实际上就是 $V_0$，所以相当于需要把这个最近点做一下截断。对于线段其实也一样的，线段的话如果超出了一个上界，这样的话实际上需要把它约束到 $V_1$ 的位置。所以基于这样的一个思想，整个计算的过程实际上就比较简单了。

你会发现整个计算方式是一样的，相当于你首先计算原点，然后包含它的一个方向。方向的话比如 $V_1$ 减去 $V_0$。整个实现的话，这里边你可以不做归一化。不做归一化的话，因为如果做归一化会有一个额外的开根号操作，这个操作实际上整个计算开销也是蛮大的。更方便的一种做法其实可以不做，算方向的时候不用去算它实际的单位向量，直接就用 $V_1 - V_0$。然后你在底下再除上 $V_1 - V_0$ 之后，这样的话就可以避免开根号的这一步计算。因为开根号消耗的代价比加、减实际上还是要复杂很多。所以这样的话这里边实际上就不存在开根号的操作。

整个第一步实际上都是在算参数坐标 $t$。这个 $t$ 算完之后，后面就会根据你是到直线的距离还是到射线的距离，相当于对它进一步地去做截断。比如这里是直线的话，不需要做任何截断，投影过来的那个点实际上就代表它的投影点。这样的话直接算一下点 $P$ 跟投影点的距离，实际上就代表了点 $P$ 到直线的距离。

当然这里边如果是射线的话，前面就讲了，因为射线要求它的 $t$ 必须得大于等于 0 的。所以对于射线的话要额外增加一个判断：如果你 $t < 0$ 了，需要把你的 $t$ 截断到 0。直观上怎么理解呢？实际上就是把你的位置，比如点 $P$ 投到了 $V_0$ 的外侧，这样的话把投影点移到 $V_0$，也就是 $V_0$ 是你的一个投影点；如果是 $V_0$ 内侧的话，还是标准的一个投影点。相当约束完了之后，再进一步地去算它的距离。从图上来看的话，如果点 $P$ 是处在 $V_0$ 的外侧，离它最近的距离实际上就是从 $P$ 到 $V_0$ 的距离；再往里的话其实就是到投影点的距离。进一步地去算点 $P$ 到

但是这里边有一个需要注意的地方，你会发现我们这个实现的话，它返回的距离实际上是带符号的。带符号会有一个什么好处呢？因为比如正常定义一个平面，如果一个刚体掉下来之后，实际上不希望除了判定它们是不是已经发生碰撞了或者是不是已经穿透了，还要判定一个东西，就是要判定哪一面是它的正面，哪一面是它的反面。

所以这样的话实际上就可以通过距离去判定。假设定义 $n$ 的方向是它的一个正向的距离，也就是说这个时候如果返回的是一个正向的距离，背面的话返回一个负向的距离，这样的话可以很容易地通过正负号来判定到底它处在哪一面。所以代码里边额外增加了一个符号的判定，实际上返回的叫作一个有向距离，它不是纯粹的一个绝对距离。因为绝对距离的话实际上是相当于 0 到正无穷的量，但是有向距离实际上就变成了一个负无穷到正无穷。也就是说下面那部分，处在它的负平面的话，所有的距离定义都是负的。这个时候实际上可以通过它的符号跟它的距离来避免它发生穿透，在后面整个计算的时候会更加方便。

接下来我们看一下点到三角形的一个距离判定。这个就是要复杂一些，因为整个三角形实际上是有界的，相当于它有三条边去限制它到底是处在哪个范围里。这样的话后面去算的话就一定要注意，因为它的整个投影点有可能投影到三角形的外头，所以需要根据它投影在哪个区域，然后去截断，就跟前面的线段一样类似的，需要判定它到底截断到边还是截断到点等等，这个需要去做判定。

这里边整个计算的话，实际上就演变成了类似一个优化的过程。因为实际上整个 $p$ 到三角形的距离，实际上就相当于可以理解为什么意思呢？比如在 $v_0, v_1, v_2$ 里边可以找一个点，然后那个点离 $p$ 的距离是最近的。这个过程本质上其实是一个约束优化的过程。因为任意一个点实际上可以用它的参数坐标，就是 $x(t)$ 的参数坐标表示，然后它减去 $p$ 的距离的平方。当然一般为什么这里要平方，还是一样的问题，就是我们不希望去开根号，降低整个计算的复杂度。

整个算距离的过程等效于这么一个距离平方求极小值的问题。这里边展开之后，实际上就变成了一个二次的、有两个未知量的方程，需要去求它的极值。如果学过最优化的同学，求这个极值的过程等效于对 $Q$ 针对 $s, t$ 算它的偏导数。也就是说它的偏导数，比如针对 $s$ 算一个偏导数，针对 $t$ 算一个偏导数，然后所有的偏导数完了之后，极值的那个地方一定是导数等于 0。导数等于 0 的地方才有可能取到极值。

当然导数等于 0 的地方不一定说一定能取到极值，因为像有些复杂的问题它可能有鞍点，那些地方可能导数也等于 0，但实际上它不是极值。但是对于这个问题，因为这是一个二次优化的问题，它导数等于 0 的地方肯定是它的极值，这点是没问题的。所以前面求极值的问题等效于对它做求导数之后，解这么一个二元一次线性方程组。

这个方程就很简单了，其实就是本科里面学的线代里的知识。相当于其实有两个方程、两个未知量，这个东西一般赖说是存在唯一解的。但这里边解完之后，本质上是相当于这么一个形式。是不是存在解，其实还有一些其他的因素在里头，后面会讲。因为比如这里还得看 $ac - b^2$ 到底是不是等于 0。$ac - b^2$ 到底等于 0 是什么概念？可以看一下前面 $a, c$ 这两个什么意思。$a$ 代表它的 $e_0$，$c$ 代表的是 $e_1$。所以这里 $ac - b^2$ 如果等于 0 的话，实际上就等效于 $e_0$ 跟 $e_1$ 实际上是共线的。那这个时候说明输入的这个三角形——

我们现在考虑这个问题的时候，先假设的实际上是一个无约束的问题。现在这里不要去考虑 $s, t$ 是有范围的。因为范围我们在后面会进一步根据范围去确定它到底最近的是点还是在边上。解这个问题的时候，我们假设就是一个无约束的，所以这里边实际上任意点都是可导的。导完之后实际上即使去解这个问题的时候，其实也是一个无约束的问题，所以它的 $s, t$ 假设范围就是负无穷到正无穷。根据这个公式算出来的时候，它也有可能就超出，比如这里边 $s, t$ 等于 1 它有可能不满足，甚至 $s, t$ 的范围也是超出 0 到 1。这个做完之后，我们在后面才会进一步根据这个值去判定到底它是处在哪个范围。

因为前半部分相当于假设它是无约束的，落点实际上是不可控的，有可能外头，有可能里头。但是这样的话对于前面的计算是方便的，因为无约束的话，整个等效于一个二元二次方程。所以只要输入的三角形是不存在退化的问题——因为如果输入就无效，那是另外一回事，这个时候你要退化成点到边的距离计算。

这个其实跟前面算平面是类似的，但是这里边必须要有 $s, t$ 这两个参数坐标，因为平面里面不存在 $s, t$ 的这两个参数坐标。三角形特有的这两个参数坐标算出来之后，后面我们才会进一步去判定它到底是属于哪一个、离它最近的到底是落在三角形里还是落在外头。我们需要根据 $s, t$ 的值去判定它到底是在哪个区域。所以把 $s, t$ 这两个参数假设把它拉平，实际上可以把任意的一个平面——

实际上划分成了几个区域，0 到 6 差不多是七个范围。这样的话，实际上我们可以通过 $s, t$ 的值去判定落点到底在哪个范围。你会发现在不同的范围，离它最近的一个点是不一样的。比如如果落点是在 0 这个区域，那离它最近的一个值肯定是在内部的。

现在我们换一个，如果它的落点是落在了 1 这个范围，那实际上跟内部点不可能是最近的，最近的点肯定是在沿着这条边上，肯定有一个点离它是最近。所以划分这个范围之后，你可以进一步去确定到底这个点离三角形的哪一部分最近，然后进一步去算它的一个距离。

这里边有这么一个判定的条件。什么意思呢？因为 $s+t$ 正常要求是等于 1 的，这个时候你可以根据它的范围。因为这条斜线代表的实际上就是 $s+t=1$ 的一条线，如果 $\le 1$ 的话，它只可能是在比如下面那个区域，也就是只可能是 0、3、4 这四个区域里边，对应地去选一个区域，然后再进一步去判定。当然如果下面有 else，对应的是如果 $s+t > 1$ 的话，那也就是只可能是在 1、2、6 这三个区域里边去选。

进一步的，0、3、4、5 这里边怎么判定呢？还要首先根据 $s$，如果 $s < 0$，那 $s < 0$ 对应的可能就只有 3 跟 4 这两个区域。这两个区域拎出来之后，我们再进一步根据 $t$，如果 $t < 0$，那对应的应该是 4 这个区域。如果已经选到 4 这个区域了，你会发现离这个点最近的肯定是这个角点，这个是没问题的。当然如果这个时候落在区域 5，那离它最近的肯定是这条边。所以就需要根据这些不同的情况，最终去算点到三角形面片最近的一个点。
