点跟球讲完之后还比较简单。接下来主要讲一下点跟胶囊体。胶囊体本质上还是相当于对球体的一个拓展，也就是把原先球体的中心点变成了一条中心线。

所以在这里你会发现，点到胶囊体的距离计算其实可以退化成点到线段（比如这里 $v_0 v_1$ 线段）的距离。因为线段前面已经介绍过了，你可以很方便地算出 $P$ 到线段上任意一点的距离，比如最近点的距离。点到线段算完之后，再减去半径 $r$，实际上就代表了点到胶囊体的距离。胶囊体之所以大家用得多，本质上是因为它退化成了点到线段的距离，计算量比较少，比较容易；同时形状也很适合用来表示人体这种长条性的结构，所以在很多游戏引擎里用得会比较多。

下面主要讲一下点到四面体的距离计算。其实跟前面的问题类似，和三角形的问题一样，离它最近的点有可能发生在内部——如果点在内部，距离其实就是零；但还有可能最近的点发生在某一条边上，或者是在某一个面上，当然也有可能是在某一个顶点。所以这几种情况都有可能发生。

去解决这个问题，如果要写 CUDA 的算法，前面我们也讲过，尽可能要减少分支结构。因为分支结构对 CUDA 这种并行计算语言不太友好，所以在计算的时候看有没有可能尽可能降低分支判断。如果前面分别独立去算，可能就会存在问题，比如先判定到底是离边最近还是离面最近，就会导致有大量的分支判断，在 CUDA 或者 GPU 运算的时候很多线程可能是占不满的。所以最好是把分支判断降下来。

这里边怎么去做呢？一个比较理想的方式是，因为整个四面体包含四个面，我们可以通过这四个面去判定点到底处在哪一个部分。如果判定下来点都处在面的负面（即法向的反方向），就可以断定点处在四面体的内部。内部计算很简单，只需要跟四个三角形分别做一下距离计算，找出最近的距离，就代表了它跟体表面最近的距离。

如果它处在某些面的外侧，只需要针对外侧的面来处理。比如有两个面，判定的时候点处在第一个面的外侧，同时也处在第二个面的外侧，那后面两个面实际上就不需要去算了，只需要针对这两个面算一下到点的距离，找出最近的点。这样一方面把计算量降下来，另一方面也减少了分支判断的过程。

当然这个代码可能没有做到最简，为了写得简单，实际上做了一些冗余计算，直接对四个面分别做了一遍距离计算，然后找一个最近的。这样也能实现，唯一的缺点就是计算多了几步。如果事先把负面的三角形剔除掉，就可以进一步降低整个计算的开销。因为整个逻辑是一个循环，分支结构相对来说比较少，对于 CUDA、GPU 来说还是比较友好的计算。

后面主要是 AABB。AABB 跟四面体的计算是类似的，但其实 AABB 更简单。为什么更简单呢？因为它其实不需要去算点到平面的距离，完全可以通过坐标轴，根据 $X$ 坐标或者 $Y$ 坐标就可以判定它到底属于哪一面。所以计算思路跟四面体是一样的，但在计算上只需要分别对 $X$、$Y$、$Z$ 三个轴判断一下，整个计算会更加方便。这部分我就不展开讲了，有兴趣可以直接去看源代码里的实现。

OBB 跟 AABB 是一样的，本质上相当于旋转了一定方向的 AABB。实际去做点到 OBB 距离计算的时候，一般可以先把它转回来，因为在 AABB 上算非常快。可以先做一个变换矩阵 $T$，$T$ 包含几个部分：一个是 $\mathbf{u}, \mathbf{v}, \mathbf{w}$ 三个方向向量，还有一个是平移。这个 $T$ 实际上是一个齐次坐标下的变换矩阵，相当于把它转换成标准的 AABB，在这个坐标系下算完距离或者相交测试之后，再转回到 OBB 所处的坐标架。这样整个效率上会比较高。

OBB 后面在做碰撞检测时会用到。有人问“变换点会不会更快一点？”——变换点是什么意思？这里边本质上就是变换点，把顶点分别乘上旋转矩阵，顶点坐标实际上就变到了标准坐标系下，本质上就是顶点的变换。

前面讲完之后，接下来讲相交测试。相交测试主要在碰撞检测场景里用得比较多，刚体模拟里会有大量的碰撞检测。一个物体穿透到另一个物体之后，需要判定它们相交的时刻以及相交的点。复杂的碰撞检测很多时候都可以简化成点跟物体的碰撞。因为整个过程在时间上是动态的，从这个时刻到下一个时刻，即使是一个点，实际上也连成了一条线段。这个时候要检测连续运动的线段上是不是存在某一个时刻跟别的物体发生碰撞，等效于线形结构跟其它几何结构（比如平面或球）的相交问题。所以之所以要讲线形结构跟基本几何图元的相交，主要是因为把时间维度加上去之后，很多问题都可以退化成线形结构跟几何图元的相交问题。

下面看一下线形结构跟平面相交应该怎么去计算。前面已经讲过，直线是一个参数方程：

$$O + tD$$

平面方程是：

$$Ax + By + Cz + D = 0$$

如果它们之间存在交点，意味着存在某一个值 $t$，算出来的位置与平面方程相满足。

比如这个时候有一个平面坐标，正好跟平面上的某一个点是重合的，对于某一个点来说，它实际上同时符合直线的参数坐标方程以及平面的参数坐标方程。两个同时成立的话，这两个东西实际上是等效的，对于这个点如果是交点上来讲，它们这两个东西应该是等效的。

这个时候可以把直线的参数坐标替到平面坐标里头。比如直线的话，它表示成 $O + tD$，当然这个 $t$ 我们现在假设还不清楚，但是可以替换到这里边，展开之后其实就是 $x, y, z$。我们可以根据平面坐标的形式，进一步把 $t$ 的值给算出来，这样的话就可以计算出它参数坐标 $t$ 的值。

当然这个值其实会有一些问题，还是前面讲到的。对应的是它的代码，根据前面那个公式，就是 $n \cdot O$ 加上 $d$ 然后除以 $n \cdot D$，这个你可以对一下。

这里边的一个问题就是，因为 $D$ 的方向有可能是跟平面平行的。这个时候你会发现底下那个值，算底下的参数坐标，就是平面的法向乘上直线的方向，这两个乘起来之后，如果直线跟平面是平行的话，这两个乘起来是 0。所以在代码实现的时候特别需要注意的一个地方就是，除以 0 要特殊处理一下，不然的话有可能会导致整个计算直接被 0 除，整个结果可能是不对的，有可能会直接报 NaN 类似这种错误。

代码里边它其实有个特殊的处理，当然这个处理怎么实现其实都可以。如果它出现无效的值，比如像我们这里就返回 0，假设判定它暂且不发生碰撞。但这个东西其实也有歧义，如果直线一开始直接就是处在平面的内部，这个时候去判定它到底是属于相交还是不相交的状态，实际上是有歧义的。所以这个取决于具体的应用，比如有些应用可以假设它处在一个不发生碰撞的阶段，当然也有些应用可能是需要对于那种情况处在发生碰撞的阶段，有可能需要根据具体应用去调整极端情况的一些测试。

接下来的话，比如线性结构跟球的相交也是存在多种情况。最左边那个相当于存在两个交点，中间那个其实存在一个交点，包括最右边那个其实就可能是没有交点了。

线性结构跟球也是一样的，存在两个交点、一个交点甚至没有交点。直观地去理解的话很容易，如果是两个交点，中心点跟直线的距离如果小于它的半径，那肯定就存在两个交点；一个交点的话，正好等于它的半径，实际上就正好是一个交点；如果是大于它的半径，实际上就是没有交点。

但因为我们在去做碰撞检测的时候，不光是需要判定整个是不是相交，还有一个是因为我们需要去找它的触点，所以需要精确地把这个位置给算出来。这里就需要依赖整个参数坐标的一些计算，参数形式的一个计算。跟前面其实类似，相当于有一个直线的参数形式，它有一个对应的参数坐标 $t$，同时也有一个球面的参数坐标，就是它的中心点。因为这个相交计算一般只需要去求球的表面，内部的不用管，一般只需要去找整个线性结构跟球面表面的碰撞检测情况，相当于去找出那两个点。

这里我们用的本质上是一个球面坐标的形式。可以把直线的公式替换到球面坐标，替换好之后逐步展开，一步一步展开之后，最后就变成等效于一个一元二次方程。

这个一元二次方程跟以前学到的 $a \cdot t^2 + 2bt + c = 0$ 的形式是一样的，无非就是 $a, 2b, c$ 每一个需要定义它具体的值到底是多少。如果把它分别列开的话，$a$ 对应的是 1，然后 $b$ 后面对应的是后面那个，$b$ 应该是没有 $t$ 的，因为 $a, b, c$ 都是常量，$t$ 应该是不需要的，然后后面 $c$ 也是这么一个表达的形式。

这里边本质上也是一个一元二次方程，如果从一元二次方程去判定它有几个交点，其实就很容易了。以前学一元二次方程的时候，公式是不是存在根或者存在几个根，实际上是有判定条件的，就相当于 $b^2 - 4ac$ 它的值到底是什么样子。

比如它大于 0 的时候，这个时候正好有两个根。因为 $t_0$ 跟 $t_1$ 如果独立写开的话，相当于 $b^2 - 4ac$ 如果大于 0，减去后面那项跟加上后面那项实际上是不一样的，所以正好有两个值。对于如果是 $b^2 - 4ac = 0$ 的话，正好相当于 $t_0$ 跟 $t_1$ 重合了，这个时候等效于正好有一个交点。最后还有没有解的时候，没有解的时候实际上就是直线远离球面的时候，这样的话 $b^2 - 4ac < 0$。因为我们现在算的其实都是实根，如果刨开实根，虚根的话其实都有两个解，但是因为虚根在几何上面没有意义，所以我们这里算的都是实根。$b^2 - 4ac < 0$ 的时候不存在解，也就是不存在交点。

接下来我们来看一下线性结构跟三角形。三角形比如用来做布料模拟，用得会非常的多。做布料模拟的时候，我们需要去判定一个顶点跟一个三角面片或者跟一个边是不是有可能发生穿透了，所以就需要依赖线性结构跟三角面片相交的碰撞检测算法。

直线的坐标其实是一样的。这里前面可能忘了提了，这里虽然只讲了直线，线性结构后面如果是进一步比如射线的话，实际上可以根据 $t_0, t_1$ 到底处在哪个范围，跟前面计算点到直线或者点到射线的距离一样，相当于根据 $t_0, t_1$ 的范围进一步去截断到底属于哪种情况。因为如果是射线的话，原点处在球的内部，往外打出来的话实际上也只有一个交点，这样的话是因为 $t_0$ 的坐标实际上是小于 0……

你需要把这个 $t_0$ 给它剔掉，因为小于 0 的话在射线里面它实际上是不成立的。所以你可以根据 $t_0, t_1$ 的一个范围进一步地去截断到底比如你像射线或直线跟这个球到底是不是包含这个交点。

后面实际上也是一样的，普遍我讲的话可能都直接都按直线去讲了，然后射线跟线段的话，都需要按照这个 $t$ 的范围去进一步地截断一下。

这里边三角形的一个参数坐标公式的话，实际上就可以表示成，前面是 $s, t$，然后这里边主要为了表示方便的话做了一个替换，就是分 $u, v, w$。当然这个 $w$ 后面实际上是可以表示成，因为 $u, v, w$ 这三个值加起来肯定是等于 1 的，所以这个 $w$ 实际上可以表示成 $1 - u - v$ 这么一个形式。

所以这两个公式在相交点它是符合下面这么一个定义的，也就是说你这个 $O$ 加上某一个未知量的 $t$ 乘上一个 $D$ 之后，它的那个位置正好是处在平面上的某一个点。当然我们现在不知道这里边这个 $u, v, w$ 到底是多少，一定存在某一个 $u, v, w$ 这么一个值，正好这样的话平面上的点跟直线上的点正好是重叠的。所以这个公式其实就代表这么一个意思，直线上点跟右面平面上的那个点，也就是三角形上的一个点应该是重叠。

这个公式你再进一步地往下转的话，实际上你会发现它应该就变成一个线性方程组。这里边你会发现它有几个未知量，一个是它的 $t$ 它是未知的，第二个是它的 $u, v$，这两个实际上未知的。展开之后你会发现这里边整个线性方程组它其实包含三个未知量，那同时它实际上正好是三个方程。

这个东西实际上正好三个未知量跟三个方程的话，理想情况下它是应该存在唯一解的。当然这个也跟现代里面的基础有关系，你会发现它实际上就是等效于后面 $Ax = b$。但是我们线代里面其实学过，这个方程为可解的唯一条件，它必须是这个 $A$ 是满秩的，相当于是不奇异的，这个才是可解的，不然的话它这个东西可能是包含无穷解。

如果先假设它可解的话，那这样的话实际上最后如果用线代里的知识、线性代数里边的知识的话，实际上就可以转换成类似这样一个形式。当然后面那三项的话实际上可能需要自己推导一下，这里边可能没有那么直观。

这里边唯一需要注意的一个地方就是这个 $D$，这个 $D$ 实际上你会发现其实就是前面的三重积，相当于它包含几部分：一个就是线段的方向，还有就是两个东西，就是 $V_2 - V_0$，$V_1 - V_0$，就是它两条边。

这个东西前面讲了这个三重积代表一个什么意思呢？实际上就代表它的一个体积，就是相当于这三条边，比如 $D$ 跟 $V_0, V_1$，这三条边张成的这么一个体积。

所以你会发现如果这个体积它不等于 0 的话，那这里边这个 $t, u, v$ 这个实际上都是可解的，也就是它存在一个唯一的解。

但是有可能什么情况呢？也有可能这个东西 $D$ 有可能是等于 0。那这个是什么情况它会等于 0 呢？我们后面看一下，其实比较复杂。

比如第一种情况，你发现比如这个线段它的那个方向正好跟平面实际上是平行的，那这个时候你会发现用这三个量算出来的体积是等于 0。所以这个时候你会发现它实际上这个东西是不可解的，也就是这个时候其实就是没有交点。因为这个东西它实际上如果是在上头的话，它不可能跟平面、就跟这个三角形相交。

但是其实还是有一样的一个问题，就是如果某些情况，比如你这个线段或者这个直线一开始就跟三角形所处的平面处在一个平面上，那这个时候就会存在一个问题，就是你这个时候到底判定它到底相交还是不相交？这个东西需要根据具体问题去具体分析。

因为如果是这里有个问题，打个比方，你一开始就假定判定相交了，比如你是布料仿真的一个问题，那你这个时候如果直接就判定它相交了，那这个时候因为有个什么问题呢？你其实你并不知道你的布料的那一层到底处在哪一层，你相当于你的正面你可能不清楚。所以这样的话你这个时候如果相交了，你很难去处理到底应该是往上推还是往下推。所以这个时候其实就会存在一定的奇异。这个当然就是你需要额外地借助别的信息来帮助你去判定，这个点应该是比如发生碰撞之后是往上还是往下。

当然还有一种情况就是你假设比如我现在这个直线跟这个三角形平面处在一个平面里面，我假定它就不碰撞，那这个时候呢它也有可能是没有力，然后你可以借助别的那个点，然后相当于把它给它分离开，然后进一步地在后面比如它一定程度脱离之后，然后再进一步去判定它到底后面应该怎么去计算。所以对于这样两种情况的话，反正就具体的问题的时候你相当于需要注意一些这种极端的一些情况。

当然还有些其他的情况就是，这个射线的那个方向，比如这个直线的方向它跟这个平面也不是说平行的，但是有可能你进来之后你的三角形可能这个质量不太好，这个时候有可能会出现一个什么问题，就是你的两个边实际上就重合了。那这种也很常见，因为你布料模拟的时候你很难保证如果你弹性力不够的话，可能你三角形可能就坍塌了。那这种时候其实你发现它这个东西也是等于 0，所以这种情况也需要额外地去做一定的一个特殊处理。当然这个最极端情况就比如像这种，比如你两条边可能也重合，你方向也是平行的等等，就这种的话那就更难处理了。
