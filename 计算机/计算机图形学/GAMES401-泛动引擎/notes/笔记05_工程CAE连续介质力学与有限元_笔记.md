# 工程CAE连续介质力学与有限元

## CAE 与物理仿真的分野

### 评判维度

* **计算精度**

    * > **定义**：比的是同一件事——计算机模拟出来的物理现象，与物理实验实测到的数据能对上多少。

    * 碰撞中某个零部件瘪了多少、位移了多远，就是评判精度最直接的抓手。

    * CAE 落在工业与工程场景，精度要求被提得很高，整体高于物理仿真；物理仿真服务于观感，够像就行。

* **计算效率**

    * 物理仿真必须实时：车已经撞毁、玻璃已经碎开，画面必须当场出来，慢半拍就不叫游戏。

    * CAE 做不到也不打算实时：车头接触刚性墙到形变结束可能只有一秒甚至零点几秒，计算机要算几个小时；早些年一个工况算几天是常事。

* **结果数据量**

    * 物理仿真只需产出给图形渲染用的画面，把现象显示出来就完成任务。

    * CAE 要指导工程设计、支撑优化设计，必须留下变形全过程每一处的数据——吸能盒怎么瘪的，每个位置的位移、受力、能量，一个都不能丢。

    * 于是短短一秒的仿真配上几小时甚至几天的计算，产出的是数 TB 乃至上百 TB 的数据。

* **后处理**

    * CAE 独有的一道工序：把海量结果数据变成人能读的云图、流线图、矢量图、曲线。

* **维度对照**

    | 维度 | 物理仿真 | CAE 仿真 |
    | :--- | :--- | :--- |
    | 计算精度 | 服务于观感，够像就行 | 与物理实验实测对齐，要求很高 |
    | 计算效率 | 必须实时 | 一秒的过程算几小时到几天 |
    | 结果数据 | 实时渲染的画面 | 全过程的场数据，数 TB 级 |
    | 后处理 | 基本不需要 | 云图、曲线等专门环节 |
    | 几何与材料 | 简化模型 | 真实几何建模加真实材料本构 |

### 建模分工

* **几何与材料**

    * 物理仿真的几何模型多是 OBJ 这类格式，材料用简化模型；CAE 用 UG、SolidWorks、CATIA 等工业三维软件建真实几何，并接真实材料本构。

    * CAE 只关注物理场景里的某一个个体：公路上两车相撞，真正要分析计算的只是那辆车。

* **CAE 的定位**

    * > **定义**：CAE 是用计算机辅助求解实际工程问题的一套方法，作用是预测和优化产品的设计与制造性能。

    * 名称前省了「工业」「工程」两个字，落点在工业与工程，所以它的判据是能否对齐真实物理现象，而不是画面是否好看。

    * 相比物理仿真，CAE 精度要求更高、效率一定更慢，因为它要算的东西多得多：整个几何模型要真实建模，材料的本质要真实表征；此外还多出结果数据与后处理两个概念。

## CAE 的工程链路

### 主链与关键节点

* **完整链路**

    ```text
        几何模型
           │
           ▼
        网格模型（离散）
           │
           ▼
        载荷与边界条件
           │
           ▼
        求解器（固体 / 声学 / 热学 / 光学 / 电磁 / CFD）
           │
           ▼
        结果数据
           │
           ▼
        后处理（云图 / 流线图 / 矢量图 / 曲线）
    ```

    * 前四步是前处理加求解，后两步是结果数据与后处理；载荷与边界条件必须插在求解之前，它决定模型怎么被驱动。

* **几何建模**

    * 从实际工程对象出发，建立一个只包含待分析个体的几何模型，这是整条链路的入口。

* **边界条件与载荷**

    * 整条链路里最关键的一步：告诉求解器哪些地方受约束、哪些部件能动。

    * 空间里六个自由度——$x$、$y$、$z$ 三个平动，绕 $x$、$y$、$z$ 三个转动——哪些放开、哪些锁死，再由施加的力或速度把车推起来。

    * 约束交代不清，算出来的结果就没有意义；缺了这一步，再好的网格也只是一个静态的壳。

* **求解与数据**

    * 求解器按物理场分家：固体力学、声学、热学、光学、电磁学，加上 CFD 流体力学，问题不同用的求解器不同。

    * 结果数据不是拿来看的，是指导实际产品研发的：工程师基于它们做大量分析、提改进方案。

* **三个基本阶段**

    * 整个 CAE 分析就是三部分：前处理（几何建模、网格剖分、施加载荷与边界条件）、求解、后处理。

### 替代实验与流程改造

* **可替代的三类实验**

    * 汽车研发要对车身做抗弯刚度、抗扭刚度、碰撞三类实验；这里的车身指去掉发动机、底盘、轮胎这些驱动系统后剩下的那副车壳。

    * CAE 分别以抗弯刚度计算、抗扭刚度计算、碰撞仿真替代，算完得到的是一张带物理量的云图，一眼能看出受扭时哪些地方刚度偏差。

* **替代的经济前提**

    * 计算精度做到物理实验的 80% 到 90%，就足以指导研发。

    * 拿计算机模拟一场碰撞与真拿一台车去撞，结论对得上，研发周期短了，成本也降了，这是企业愿意上 CAE 的理由。

* **设计流程的改造**

    ```text
        传统流程
        产品规划 → 产品设计 → 产品研制 → 实验验证 → 生产
                         ↑                    │
                         └──── 不合格则改设计 ──┘

        引入 CAE 之后
        产品规划 → 产品设计 → CAE 验证与优化 → 产品研制 → 实验验证 → 生产
    ```

    * CAE 插在「设计完成」与「研制样件」之间：设计一完成就在计算机里验证和优化，发现问题直接改模型，不必每改一处就做一次样件、做一次物理实验。

    * 传统主线的毛病是设计出来的产品不一定一次达标，刚度、强度、模态、疲劳稳定性任一项不过关都得靠实验暴露，再回头改设计、再试制、再实验。

* **全数字化开发**

    * 换来的是更短的开发时间、更优的方案、更可靠的质量、更低的成本。

    * 已有企业能用全数字化模型加 CAE 完成车型开发，样件与物理实验可以完全不做；CAE 的定位正从「辅助设计工具」变成融入正向研发流程、引导设计的一环。

## 汽车上的分析谱系

### 分析类型清单

* **谱系全表**

    | 分析类型 | 它回答的问题 |
    | :--- | :--- |
    | 环境舒适性 | 空调吹着舒不舒服、隔音好不好、减震降噪行不行 |
    | 安全性 | 撞的时候车里的人保不保得住 |
    | 人机工程 | 坐姿、方向盘、档把、按钮顺不顺手，会不会和动作轨迹干涉 |
    | 结构刚度与强度 | 够不够硬、够不够稳 |
    | 模态 | 结构怎么振动，噪声从哪来 |
    | 响应与疲劳 | 跑几万公里之后会不会裂 |
    | 温度场 | 发动机热不热、散热够不够、零部件是否在可靠温度区间 |
    | 振动噪声 | 车厢空腔里哪吵哪静 |
    | 空气动力学 | 风阻系数多大，能耗能降多少 |
    | 碰撞与冲击 | 侧碰之后车损成什么样 |
    | 工艺分析 | 这块钢板冲压会不会裂、会不会起皱 |
    | 可靠性 | 整套结构在长期使用中稳不稳 |
    | 多学科优化 | 算出来的数据怎么反哺结构设计 |

* **刚度与强度**

    * 最传统的一条：刚度通俗讲就是够不够硬，强度就是够不够稳。

* **模态**

    * 属于动力学分析，解决结构振动与噪声问题；坐在车里隔音降噪的能力怎么样，看的就是这一层。

* **响应与疲劳**

    * 响应分析对应到虚拟实验里的疲劳问题：跑完几万公里之后各项性能指标怎么变化，哪些结构件长期处在振动中、会不会开裂。

### 专项分析

* **虚拟实验**

    * 感觉像在虚拟场景里开着车在路上跑，但游戏里那种跑多数停在物理仿真层面，把简单变形与画面现象表达出来就够了。

    * CAE 的虚拟实验要给出跑完几万公里后各项性能指标的变化，最典型的是疲劳程度。

    * 整条道路的数据要先拿进来，而且不只是路面图像，路面坑坑洼洼的实际特征都要进模型，评出来的疲劳结果才可信。

* **冲压成型**

    * 车身漂亮的外形起点是一整块平钢板，靠两个带造型的模具对压，钢板跟着模具型面变形压出车身。

    * 分析结果一片绿说明当前工艺设计得好，整车特征都加工得出来；出现别的颜色尤其是红色就说明有问题——红色处可能因变形太大而开裂，也可能钢板挤到一起起了皱。

* **风阻**

    * 关系到燃油经济性与电动车能耗，要把能耗压下去就得尽量降低风阻系数，这是 CFD 流体分析的活。

    * 方法上，物理仿真常用 SPH 这类方法做流体；工业 CAE 里用得更多的是 FEM、FVM，边界元 BEM 也占一席之地。

* **振动噪声**

    * 关注空腔内部的声场分布：运行过程中每个位置的噪声怎么分布、哪里小哪里大，据此指导设计。

* **多学科优化设计**

    * CAE 领域里的另一类软件：把各类分析得到的数据反哺回结构优化设计，让前面的计算真正落到结构上。

* **多体动力学与自动驾驶**

    * 自动驾驶仿真主要落在多体动力学：用 ADAMS 这类软件把汽车主要传动部件建成多体动力学模型，模拟转向、侧倾与稳定性——快速转弯、快速行驶时结构反应灵不灵敏，高速过弯会不会侧翻。

    * 再往自动驾驶那层走是多领域协作：布置 V2X 传感器或用图像识别判断前方障碍物，把障碍物信息变成信号喂进动力学模型，再由模型驱动汽车执行操作指令。

## 离散与单元

### 单元与网格

* **单元（element）**

    * 等价于物理仿真里的 mesh、网格、片元——把模型切成的那一小片，在有限元里就叫单元。

    * > **提示**：物理仿真说 mesh，有限元说 element，指的是同一个东西在两个语境下的名字，都是连续体被切出来的那一小块。

    * 有限元这个名字说白了就是「有限个元素」，数量有限的单元。

* **单元类型**

    | 单元类型 | 对应的形状或对象 |
    | :--- | :--- |
    | 一维单元 | 杆单元、梁单元 |
    | 平面单元 | 三角形、四边形 |
    | 实体单元 | 四面体、六面体、三棱柱、四棱柱 |
    | 板壳单元 | 板、壳这类薄壁构件 |
    | 特殊单元 | 刚体单元、弹簧单元 |

* **特殊单元**

    * 刚体单元把整个模型当成一个刚体，假定它不变形。

    * 弹簧单元是给弹簧仿真准备的专门单元，直接引进模型里参与计算；这两类在通用单元之外各管一摊。

### 离散化

* **离散的含义**

    * > **定义**：离散是把原来的连续体切开，用数量有限的单元去逼近它。

    * 足球是现成的例子：球面本来是连续圆面，画满黑白格子之后，连续表面就被离散成一个个小块；算圆周率用的也是这个思路。

    * 一个原本整体的刚体模型，用四面体单元去切，切成很多小区域，用这些小特征去近似完整的特征。

* **离散为什么必要**

    * 真实零件是连续体，上面有无穷多个点、无穷多个未知量，没法直接算。

    * 不管这个面多么复杂，都可以用一些或大或小、或多或少的三角形把几何区域铺满、离散掉——这是它最大的用处：能处理非常复杂的几何问题。

* **近似的本性**

    * 离散后的模型与原模型之间是近似关系，不是一对一完全吻合；边界上最明显——用直线去拟合曲边，误差一定存在。

    * 有限元是一种近似求解技术，交给你的是近似解，不是真值。

* **标准构件的好处**

    * 原来用各种曲线、曲面都很难描述的区域，被换成若干个相对规则的标准构件。

    * 每次计算只需在这个标准构件上建立力学方程、做求解，不必直接面对那个复杂形状。

### 节点与自由度

* **节点**

    * 每一条线段是一个单元，单元与单元之间靠红色的点连接，那个点叫节点。

    * 节点是整个模型的着力点：它能承受载荷，也有自由度——空间里 $x$、$y$、$z$ 三个平动，加绕三个轴的转动，一共六个。

    * 真实系统受到的力，最终都要落到节点上去；整个系统的运动是通过节点被牵引出来的。

* **规模的计算**

    * 自由度 = 节点数 × 每个节点的自由度数。

    * 有多少节点、每个节点放开几个自由度，决定这个模型最终要解多大规模的一个方程组。

    * > **易错点**：算模型自由度时，是节点数乘以每个节点的自由度数，不是节点数本身。两个节点、每节点六个自由度，得到的是十二个自由度。

* **一维情形**

    * 一条线段按几何离散切成若干段线段，段与段之间就是节点，整条线的行为由这些节点串起来描述。

### 单元分析与组装

* **单元内部闭环**

    ```text
        节点位移
           │  形函数插值
           ▼
        单元内部各点位移
           │  几何关系
           ▼
        单元应变
           │  材料本构
           ▼
        单元应力
           │  等效分配到节点
           ▼
        节点力
           │
           ▼
        新的节点位移
    ```

    * 它是一个循环，不是单向流程；节点力又推动下一轮的节点位移。

* **每一步的依据**

    * 一个三角形三个节点各自产生位移，整个三角形形状必然改变——形状改变就是应变。

    * 三个角点一动，内部每一点动多少，靠插值函数算出来；有了应变，本构模型告诉你这种材料会因此产生多大应力。

    * 应力分布在单元内部，要送回节点，才能和外部的载荷、约束放进同一套方程里。

* **组装**

    * 假设离散出十个单元，就有十份单元上的力学方程，解完之后要把它们拼起来。

    * 具体做法是从单元刚度矩阵组装出整体刚度矩阵；一个大三角形剖成四个单元，每个单独算完再全部拼回一个整体。

    * > **提示**：有限元的全部套路就是六个字——先离散，再组装。

## 有限元的性质

### 方法与普适性

* **有限元方法（Finite Element Method，FEM）**

    * > **定义**：用数学近似的方法对真实的物理系统进行模拟，是求解数学物理方程的一种基本计算方法；它从固体力学起步，随后扩展到流体、热、电磁等领域。

    * 两个关键词：一是「近似」，求出来的不是精确解而是工程数值解；二是「通用」，能解决非常复杂的工程问题，适用面极广。

    * 代价就是精度不是百分之百——有限元给出的答案永远带着近似的前提。

* **普适性与精度的交换**

    * 工程数值方法要满足实际工程需要，就必须有很高的普适性：什么形状、什么材料、什么工况都能算。

    * 普适性和精度是要交换的，为了普适必然牺牲一部分精度。

    * 用一套工程算法去搭流程算 $1+1$，算出来可能不是 $2$ 而是 $1.9999$，差了万分之一；这点误差在工程上完全可用，能指导研发、满足需要就没有问题。

    * > **提示**：不要因为「$1.9999$ 不是 $2$」就否定有限元。工程仿真追求误差可控、结论可用，不是数学上的恒等；真正该警惕的是误差大到改变了设计决策。

* **理想化模型**

    * > **定义**：有限元模型是对真实系统做理想化之后得到的数学抽象。

### 三步骤与标准化

* **分析的三段**

    * 结构离散化：把连续体切开，切出单元与节点。

    * 单元分析：每一小块内部怎么用节点位移插值出整个单元的变形。

    * 整体分析：把所有单元按节点拼回一个整体，组装成方程组再求解。

* **标准化与规范化**

    * 标准化：任何复杂问题都先做标准化的分解，分解成一个个标准单元，然后在单元上建模、在单元上计算。

    * 规范化：整个分析路线固定、程式化，不因人而异。

    * 用有限种类的标准件构造任意复杂对象：杆、梁、三角形与四边形壳、四面体与六面体实体，种类有限、翻来覆去就这些，组合起来可以逼近任何形状。

* **为什么能写成程序**

    * 正因为规范，它才能被写成程序——这是有限元在众多数值方法里脱颖而出、发展得这么快的重要原因。

    * 它可以做成标准程序，再拆成一个个模块（前处理、求解、各种单元、本构计算），最后拼成一个软件，非常符合增量式软件架构与模块化编程的思路。

* **完整流程**

    ```text
        真实系统（连续体，未知量无限多）
                │ ① 几何建模（CAD）
                ▼
            CAD 几何模型
                │ ② 网格划分：三角形 / 四边形 / 四面体 / 六面体
                ▼
          有限元模型（有限个单元 + 节点 + 自由度）
                │ ③ 单元级建模与计算
                ▼
           单元方程 ──► 组装成整体方程组
                │ ④ 施加边界条件与载荷，求解
                ▼
           节点位移 ──► 单元应变、应力
                │ ⑤ 后处理显示
                ▼
           工程评价：强度 / 刚度 / 稳定性
    ```

### 精度与效率

* **两者的绑定**

    * CAE 用的是工程数值分析算法，得到的解本身就是近似解；很多问题基本实现了从 0 到 1，但理论上仍有不成熟之处，很多场景精度还是有限。

    * 计算效率和精度成正比：精度要往上提，计算时间就得跟着涨。

    * 只用两个单元去逼近一条曲边，误差必然大；要减小误差就把网格尺寸变小、多加节点多连线，结果更贴近真实模型。

    * 但离散完每个单元都要计算，增加十个单元就要多算十次单元的时间量——精度上去了，效率必然下来。

* **各分析类型的水平**

    | 分析类型 | 精度 | 效率 |
    | :--- | :--- | :--- |
    | 静刚度、静强度 | 90% 以上 | 较快 |
    | 模态 | — | 快 |
    | 疲劳、裂纹 | 约 75% | — |
    | 流体、碰撞 | — | 慢 |

    * 空着的地方表示这一类没有给出具体数字；这组数据可作参考，方向是明确的：静力学类精度高、疲劳裂纹类只到 75% 左右、模态快、流体与碰撞慢。

    * 实际工程分析并不要求一定达到百分之百或 90%，有时候 70%、80% 在特定过程中就能满足要求。

* **认识框架**

    * 该在心里挂上三个问号：CAE 有没有理论上的缺陷；它能不能、又是如何模拟出完全真实的情况；该怎么正确认识 CAE、又该怎么正确使用 CAE 软件。

    * > **提示**：看一个 CAE 结果先问两件事——它算的是哪一类问题，我要求它准到什么程度。脱离这两点谈「准不准」没有意义。

## 求解器的构成

### 七块骨架

* **七个组成**

    ```text
                            ┌─ 数值算法与单元计算理论
                            ├─ 材料本构模型
           一个求解器 ──────┼─ 接触算法
                            ├─ 非线性迭代技术
                            ├─ 连接与约束关系
                            ├─ 边界与载荷条件加载
                            └─ 方程组求解 + 并行计算
    ```

    * 这七块合起来才是一个能算的求解器。

* **连接与约束**

    * 负责把上万个零件按零件—部件—整机的层次连起来：一整辆车不能当成一个整体去建，得分开建再连。

* **数值算法与单元计算理论**

    * CAE 分析里的第一大块；图形学里用得很多的 SPH、MPM 这一类方法在这里也有一席之地。

    * 另一条思路是 CAD/CAE 一体化：能不能直接基于 CAD 模型做 CAE 分析，对应的答案就是等几何分析 IGA，以及边界元 BEM 这一类方法。

### 单元算法与本构

* **单元类型是算法不是形状**

    * 同样是三角形单元、几何形状都是三角形，计算理论可以不一样：一阶三角形的平面应力单元、二阶三角形的平面应力单元、平面应变单元、二阶的平面应变单元，同样一个三角形有很多种计算方法。

    * > **易错点**：在有限元软件里提到「单元」，指的不是形状，而是单元计算的方法。形状只决定它长什么样，阶次与平面应力、平面应变的假设决定它怎么算。

    * 选哪种要看实际工况、应用场景和对计算精度的要求，同一个几何体对应多种计算方法属于正常。

* **材料本构模型**

    * > **定义**：材料本构模型描述的是应力和应变之间的行为关系——给定一个应变，材料回给你多大的应力，全靠它来表征。

    * 它要回答的问题很朴素：这个零件是钢的、铁的、铝的，还是布料、木头、水泥？同样的受力，不同材料给出的反应完全不同。

    * 和物理仿真高度一致：线弹性、超弹性、弹塑性，物理仿真里有的这一套这里都有；区别在于 CAE 会把精度更高的本构模型接进整个分析流程。

* **本构的实验标定**

    * 开发本构要用标准 benchmark 测试：单轴拉伸实验在物理实验机上做完，得到材料拉伸过程中的应力—应变曲线。

    * 再用开发出的本构模型去模拟同样的单轴拉伸，也得到一条应力—应变曲线；两条曲线一对比，就知道仿真数据与实验数据是否吻合，从而验证本构模型开发得对不对。

### 接触与优化

* **接触算法的地位**

    * 接触在 CAE 里非常重要，在物理仿真里也非常重要——要模拟真实的物理系统，接触必不可少，但两者的接触有差异。

* **罚函数法**

    * 一开始先容许穿透，通过穿透量获取接触力；有了接触力再对物体施加接触反力，产生反向运动，把它们分开。

    * 物理仿真里的刚体、粒子法也采用类似思想：先算两个点之间的距离，再由距离算力。

    * 差别在于 CAE 接触对数值稳定性要求非常高：接触反力产生之后，最终要和内力、外力形成一个合力；这个合力一旦不稳，整个求解就崩了。

* **拓扑优化**

    * 看一个连杆零件：随着优化过程，有些地方的材料被去掉了。

    * 原因是反复计算后可以发现，有些地方产生的位移非常小，说明这部分材料对整个零件的刚度、强度影响不大，可以去掉。

    * 达到的目的是轻量化：零件质量降下来，重量越轻成本也越低，这是 CAE 一个非常典型的应用。

* **四边形与三角形的取舍**

    * 四边形单元的计算精度远高于三角形，一般软件里都是这样；但四边形网格剖分困难，三维里对应的六面体更是如此。

    * 三角形可以自动剖分，于是有了另一条思路：把三角形的计算精度提上去，用高精度三角形替代工程中的四边形，既降低前处理的时间与难度，又尽量不牺牲精度。

### 隐式与显式

* **隐式分析**

    * 线性分析部分支持静强度分析、模态分析，此外还有屈曲分析、惯性释放分析、疲劳分析、随机振动分析。

    * 隐式求解的计算效率其实比较好——把方程组解出来就很快。

* **显式分析**

    * 主要算汽车碰撞那类涉及非常大材料变形的问题；考虑数值稳定性，一般要采用类似中心差分的思想做显式求解。

    * 典型算例：两个管的碰撞、整个模型的挤压过程、子弹打穿一块平板，以及构件受冲击破坏、冲压成型、零部件受冲击力后的变形。

    * 显式里的接触计算比隐式更稳定一些，涉及点面接触、面面接触、单面接触，还有非常复杂的自接触，此外还要处理连接约束。

    * 显式是一个迭代计算的过程：算一个汽车碰撞问题可能要涉及数十万次反复计算迭代，计算时间可能要几天，或者至少一二十个小时。

### 方程组与并行

* **一切归结为解方程**

    * 任何 CAE 分析最后都会归结为解 $Ax=b$，通过求解得到想要的未知量 $x$。

    * 方程组求解常占整个 CAE 分析计算时间的 80% 以上，因此非常有必要开发高稳定性、高精度的方程组求解器。

    * 高铁、工程机械、船舶这些领域都有典型应用；它不是可有可无的工具，而是决定整套分析能不能算完、算得准不准的主干。

* **并行的必要性**

    * 显式求解必须用并行计算提高效率，这也是为什么它离不开并行。

    * 底层数据采用 CPU/GPU 混合方式管理，数据既可以直接在 CPU 上用，也可以在 GPU 上用，这种框架非常适合做 CAE 里的 GPU 并行算法开发。

* **GPU 的收益**

    * 手机掉到地上损坏程度怎么评估，就是用 CAE 的显式有限元分析模块模拟这个过程，非常耗时。

    * 用一块 A100 加速，计算速度可以比商业软件跑 96 核 CPU 还快 1.6 倍。

## CAE 软件

### 产业格局

* **起源**

    * 最早的 CAE 软件由美国 NASA 提出，最初是为辅助自己的飞行器、飞机设计研发而做的内部工具，后来逐步演化成国际上大名鼎鼎的 NASTRAN。

    * 今天的仿真软件覆盖面非常宽：电池分析、结构优化、多体动力学、机械传动、冲压仿真这些工艺仿真，每个领域都有各自的软件，也都有行业里领头的产品。

* **市场份额**

    * 现在大概 95% 的 CAE 软件是国外的商业软件，国产的还处在快速发展和起步当中。

    * 工业软件是卡脖子问题，CAE 软件是国内目前比较缺的一类工业软件。

* **巨头的成长路径**

    * 国际上基本被西门子、Altair、MSC、达索、ESI 几家工业软件巨头垄断。

    * 它们的成长路径像大鱼吃小鱼：不断并购各种小的 CAE 软件公司，把功能点补进来、把实力壮大起来。

    * 原因是 CAE 涉及的功能点太多，靠自己一个个做太慢，并购是最快的补充方式。

* **国产厂商**

    * 由湖南大学成果转化成立的迈曦软件，以及十沣、索辰，还有几家起步更早的传统厂商，都是国内比较有代表性的公司与产品。

### 学科交叉与卡点

* **六大学科支撑**

    * 数学：各种数学计算方法、工程中的数值分析方法、有限元计算。

    * 网格：网格剖分。

    * 求解：大规模线性方程组的求解。

    * 物理：材料、本构等物理学知识。

    * 计算机：并行计算、图形学。

    * 工程：理解汽车碰撞的实际工况和真实场景。

    * 少一样都做不成，这也是 CAE 软件难做的根源：它是复杂的学科交叉，中间有一道很大的技术鸿沟。

* **产业跨度**

    * 覆盖面从深海到太空，从民用到军工，从小型民企到大型央企。

    * 问题跨度也大：可能拿它算一个纳米级的器件，也可能算一艘千米级的航母；共性技术是一样的，差别在细节。

* **三个卡点**

    * 技术积累相对薄弱：以前有国外软件可用的时候，研究更多集中在算法层面，真正落地到软件产品层面的工作做得相对少。

    * 场景迭代不足：习惯用国外软件就不愿意用国产，国产没人用则产品迭代不足，越迭代不足越不好用，形成循环。

    * 人才储备匮乏：无论是高校做 CAE 软件人才培养，还是企业招 CAD 开发人员，都能感觉到人才非常匮乏。

### 软件骨架

* **三段架构**

    ```text
                ┌──────────────┐
                │    前处理    │  CAD 建模 / 模型接口 / 网格剖分
                └──────┬───────┘
                       │
                ┌──────▼───────┐
                │    求解器    │  隐式 / 显式 / 多体动力学
                └──────┬───────┘
                       │
                ┌──────▼───────┐
                │    后处理    │  云图 / 动画渲染
                └──────────────┘

        支撑：云计算 · 并行计算 · 数学计算库 · 材料与单元库
    ```

    * 数据从几何与网格进来，经过求解器，最后以云图和动画出来；底下那一层是所有模块共用的支撑。

    * 最核心的几块是前处理模块、求解器模块、材料与单元库、并行计算模块。

* **几何前处理**

    * 首先把构建好的整体模型（一艘船、一辆坦克）通过几何接口导入，现在很多软件也支持点、线、面的简单建模。

    * 建模能力比不上 CAD，但不可或缺：一是导入 CAD 模型后难免要做几何修补，比如某个孔作用不大就生成一个面把它补上。

    * 二是很多场景需要全自动分析——从几何分析、网格剖分、计算求解到后处理全部自动完成，这要求几何建模有足够多软构件、能做参数驱动的几何建模。

* **网格模块**

    * 要能生成三角形、四边形、四面体、六面体这些网格。

    * 生成完还要能调：网格密度要能改，网格要能拉伸，不需要的网格要能删，本来四个网格要能合并成一个。

* **求解器与后处理**

    * 求解器按应用场景分：通用结构的隐式求解器、显式动力学求解器、多体动力学求解器等。

    * 后处理要有强有力的渲染模块支撑——分析结果最后要变成漂亮的动画和云图，靠的就是它。

* **支撑技术**

    * 云计算：CAE 计算很耗资源，普通用户要靠云端算力。

    * 并行计算：计算量大。

    * 数学计算库：像 BLAS 这类基础线性代数库，以及各种稀疏矩阵求解库。

### 三条效率战线

* **使用效率**

    * 要解决的是 CAE 模型和 CAD 模型相分离的问题：做分析先要把 CAD 模型转成 CAE 模型，这个转换本身就很花时间。

    * 工程设计的梦想是 CAD 与 CAE 无缝集成，直接基于 CAD 模型做 CAE 分析；现在有不少商业软件在做，也有学者在研究这条路。

* **计算效率**

    * 就是并行计算：用 GPU、用超算，或者用 CPU 加 GPU 的异构平台，把整个 CAE 仿真的计算效率提上去。

* **迭代效率**

    * 产品设计完用 CAE 分析、分析完改进设计再分析，这个循环里迭代效率非常重要。

    * 一个车门改来改去可能只是增加了一个孔，按以前的做法整个模型要全部重算；如果要迭代 100 次，这个车门就要重复算 100 次。

    * 提高的办法叫重分析：只改了这一部分，就只对这一部分周边做分析，其他地方不重新分析，每次迭代的计算量大幅降低。

* **其他方向**

    * 更多、更好的单元算法来提高计算精度，这涉及 CAE 非常核心的计算理论。

    * 多物理场耦合，比如力与热的耦合分析，也是未来 CAE 软件要解决的关键问题。

## 弹性力学的研究对象

### 胡克定律与弹塑性

* **胡克定律**

    * 弹性体的变形与外力成正比：$F=k\,\Delta x$，其中 $F$ 是施加的力，$\Delta x$ 是伸长量，$k$ 是弹性系数，代表这个弹性体的变形能力。

    * 力和变形量之间是线性关系，画出来就是一条过原点的斜直线；但这条直线只在一定范围内成立。

* **弹性变形阶段**

    * 力与变形成正比。

    * 关键是外力去掉之后变形可以回到原来的样子，弹簧恢复原状。

* **塑性变形阶段**

    * 力与位移不再是线性关系，可能是一条抖动得很「随机」的曲线。

    * 更重要的特征是卸载回不去：力撤掉了，变形留在那里保持着现在的样子，回不到原样。

    * > **提示**：判弹性还是塑性，不只看「力与变形是不是成正比」，还要看「卸载后能不能恢复」。前者是过程特征，后者是本质特征。

* **先讲弹性的理由**

    * 弹性这一段最简单、最规整，是整个理论体系的入口；塑性的账要难算得多。

### 力与研究分工

* **力的两个效应**

    * 力是物体间的一种相互的机械作用，作用的结果是使物体的形状或者运动状态发生改变。

    * 运动状态改变是运动效应，归理论力学研究；形状改变是变形效应，归材料力学、弹性力学研究。

    * 力有三个要素：大小、方向、作用点；它是有方向的量，是矢量，单位是牛顿。

* **学科分野**

    * 理论力学、材料力学、结构力学、弹性力学：同样是「力」，在不同假设、不同研究对象下采用的研究方法不同。

* **三类研究对象**

    | 结构类型 | 几何特征 | 典型例子 | 用什么力学研究 |
    | :--- | :--- | :--- | :--- |
    | 杆件结构 | 长度远大于横截面尺寸 | 简化成杆单元的梯子 | 材料力学 |
    | 薄壁结构 | 两个方向尺寸远大于厚度，平的叫板、曲的叫壳 | 平板、各种壳体 | 弹性力学 |
    | 实体结构 | 三个方向尺寸基本相当 | 地基、水坝、挡土墙、变速箱箱体 | 弹性力学 |

### 杆件的基本变形

* **轴向拉伸与压缩**

    * 外力沿着杆的轴向；拉伸时轴向伸长，同时垂直于轴向的横向却在缩小，杆变窄了。

    * 受压时轴向缩短，横向反而变宽——这个「一伸一缩、一缩一伸」的横向效应后面会反复出现。

* **平面弯曲**

    * 杆受到弯曲会随约束方式、支撑点的不同，产生连续的弯曲变形。

    * 实际工况往往不是单一外力而是组合受力，比如既有弯曲、中间又受一个集中力，就会出现叠加起来的变形形态。

* **剪切**

    * 物体受到两个相对的力，表面上就产生剪切力。

    * 材料拉伸试验里试件最终沿 45 度方向断裂，就是剪切力在起作用。

* **扭转**

    * 绕着一个轴施加扭矩，杆件被拧转。

    * 这几种基本变形加上它们的组合，就是杆件力学分析的全部「字母表」。

### 强度、刚度与稳定性

* **强度**

    * 构件抵抗破坏的能力：一个钩子挂上很重的东西会不会断，不断说明强度够。

* **刚度**

    * 构件抵抗变形的能力：一个支架断不掉，但会不会被压矮、被压变形；变形太大就是刚度不够。

    * > **提示**：强度管「断不断」，刚度管「变不变形」。强度是有多硬，刚度是撑得有多稳；这里的「稳」说的是不变形，与下面单独定义的稳定性不是一回事。

* **稳定性**

    * 构件保持原有平衡状态的能力：受到外力加载时，它能不能始终维持原来那个平衡状态。

    * 这个概念提得相对少一些，但在细长压杆、薄壳这类问题上是主角。

* **常用分析**

    * 有限元分析里最常做的还是刚度和强度这两类计算，此外还有模态分析。

### 研究任务与工程意义

* **弹性力学的定义**

    * 研究弹性体在外界因素（外力的作用、温度的变化、边界的约束等）的影响下，其内部所产生的应力、形变和位移。

* **弹性体的性质**

    * 弹性体是只有弹性性质的一种理想物体：变形与力成正比，外力撤销之后变形能够恢复。

    * 应力和应变之间存在一一对应的关系，且作用去除之后能回到原来的状态。

* **研究对象**

    * 板、壳这样的薄壁结构归它管；土木里的地基、水坝、挡土墙这样的实体结构也归它管。

    * 工程里就更多了：发动机的机壳、变速箱的箱体、各种汽车的车身，都是实体结构。

    * 用杆单元把楼梯简化成几根杆是杆件层面的简化；弹性力学会做更精密的处理，不会只当一维单元，而可能用二维、三维单元分析。

* **三项研究任务**

    * 分析结构物和构件在弹性阶段的应力和位移。

    * 校核它是否具有所需的强度、刚度和稳定性。

    * 寻求或改进计算方法，采取最优方案去解决安全与经济的矛盾。

    * 分析完发现刚度、强度不够，就要根据仿真结果改进结构，把强度和刚度提上去——「改进计算方法」说的就是这件事。

* **安全与经济的矛盾**

    * 军工产品不追求轻量化与燃油经济性、是小批量生产，完全可以把结构做得非常扎实，凭工人经验就够，不太需要 CAE。

    * 民用产品既要安全也要经济性，这个矛盾靠经验拍脑袋解决不了，只能靠计算去找那个最优点；这是计算机仿真在工程界立足的理由。

### 与材料力学的分野

* **两者对照**

    | 对比项 | 材料力学 | 弹性力学 |
    | :--- | :--- | :--- |
    | 研究对象 | 杆状结构 | 实体结构、薄壁结构 |
    | 研究范围 | 弹性阶段，还延伸到塑性阶段、疲劳等问题 | 主要研究弹性阶段 |
    | 研究方法 | 对应力分布或变形状态做近似假设 | 从基本假设出发，做精确分析 |
    | 结果精度 | 往往是近似的、初等的，只能在特定条件下使用 | 更精确，还可以用来校核材料力学的结果 |

* **材料力学的做法**

    * 先对应力分布或变形状态做一些近似的假设，然后推公式；得到的结果往往是近似的、初等的，只能在一定的条件下使用。

    * 典型形态是教材里那张表——列一堆常用结构受某种载荷的情形，直接代入经验公式就能算出近似结果，够用，但它是在「套表」。

* **弹性力学的做法**

    * 从基本假设出发，对物体的应力和变形做精确的分析，结果更精确。

    * 也正因为更准确，它有时反而被用来校核材料力学算出来的结果。

## 五个基本假设

### 假设的由来

* **为什么要假设**

    * 希望用数学工具研究弹性力学，而真实材料在微观上并不连续，真实变形过程也复杂得没法直接写方程。

    * 必须先做理想化，把问题「修剪」成数学能处理的样子。

* **假设的地位**

    * > **提示**：这五条后面会被反复引用，凡是讲到「为什么这里可以这样算」，答案基本都落回这五条上。

### 连续性假设

* **内容**

    * 从宏观上看，物体是连续的；在整个物体内部，物理量——应力、应变、位移——都可以表示成坐标的连续函数，比如正应力 $\sigma_x$ 是坐标 $x$ 的连续函数。

* **为什么需要**

    * 只有这样，推导时才能用连续和极限的概念，才能用微积分、用微分。

    * 如果材料是不连续的，函数就不可导、极限也求不了，方程根本立不起来。

### 完全弹性假设

* **内容**

    * 物体产生变形之后，把外力去除，物体能够完全恢复原形。

    * 它带来一个很强的推论：在温度不变的前提下，物体在任何一个时刻的形状完全取决于该时刻所受的外力，与过去所受的历史无关——材料没有「记忆」。

* **两个层次**

    * 线弹性阶段与完全弹性阶段，对应的两个材料参数是比例极限和弹性极限。

    * 最要紧的意义：它使得描述应力应变关系的本构方程是一个线性方程，为后面用数学工具做计算和推导带来极大便利。

* **适用范围**

    * 脆性材料只要应力没有超过比例极限、还处在下面那段线弹性阶段，就可以近似当成完全弹性体来分析。

    * 塑性材料只要应力没有超过屈服极限、还在线性阶段，同样可以用弹性力学研究；一旦超过屈服极限进入塑性变形阶段，就得换塑性力学。

### 均匀性假设

* **内容**

    * 整个物体由同一种材料构成，比如汽车里的一个变速箱箱体由同一种金属材料做成。

    * 这保证了物体各个部分具有相同的物理性质，弹性常数（弹性模量、泊松比）不会随着位置、坐标而改变。

* **两个好处**

    * 写程序时非常直观：刚度矩阵之类的矩阵可以做模块化的表达。

    * 更根本的好处是：因为整个物体是同一种材料，所以可以取物体中任意的一小部分来分析，再把结果用到整个物体上去——只算某一个单元就敢把结果推广到整体，答案就在这条假设上。

### 各向同性假设

* **内容**

    * 分析对象上的每一个点，在不同的方向上都具有相同的物理性质和机械性质。

    * 材料在 $x$、$y$、$z$ 各个方向上表现一致，弹性模量和泊松比这些弹性常数不随方向而改变。

* **与均匀性的区别**

    * > **易错点**：均匀性假设的是材料参数不随坐标变化，各向同性假设的是弹性常数不随方向变化。一个管「走到哪都一样」，一个管「朝哪看都一样」。

### 小变形假设

* **内容**

    * 物体受力之后，所有点的位移都小于物体的原有尺寸。

    * 以悬臂梁为例：受力后原来在 $A$ 点的位置变到 $A'$ 点，这个变形要夸张地画出来才看得清，实际工程里的位移量相对原尺寸很小。

* **第一个好处**

    * 建立平衡方程时可以直接用变形之前的尺寸近似代替变形之后的尺寸，而不产生显著的误差。

    * 偏差确实存在——尺寸本来变长了，为了简化还用原来的长度算；但这个偏差可以接受。

* **第二个好处**

    * 考虑物体变形时，应变和转角的平方项、乘积项这些高阶项（如 $x^2$、$x\cdot y$）都可以忽略不计。

    * 高阶项一扔，弹性力学里的微分方程就变成了线性方程，可以直接求解。

### 线性化与叠加

* **线性化的合力**

    ```text
        连续性假设   ┐
        完全弹性假设 ├──► 本构方程是线性的
        均匀性假设   ┤
        各向同性假设 ┤
        小变形假设   ┘──► 几何方程、平衡方程线性化
                            │
                            ▼
                  弹性力学问题 → 线性问题
                            │
                            ├──► 求解：解线性方程组即可
                            └──► 叠加原理：多组载荷的效应可直接相加
    ```

    * 完全弹性假设保证本构方程线性，小变形假设保证其余微分方程线性，整个体系一起线性化。

* **叠加原理**

    * 在线弹性和小变形的条件下，作用在物体上的几组载荷所产生的应力和变形的总效应，等于单独每组载荷作用效应之和。

    * 例：物体同时受外部施加的力 $P$、内部的体力 $Q$、边界上一段非均匀分布的载荷，可拆成三个问题分别算再累加，得到原来那个复杂受力情况下的总效应。

    * 它是线性体系送的一份大礼，后面会反复用到。

## 外力、内力与应力

### 外力

* **外力的定义**

    * 其他物体对研究对象的作用力：研究对象之外的、别的物体给它的力，都算外力。

* **体力**

    * 分布在物体体积内的力，比如重力、惯性力、电磁力；用单位体积内的力来度量，是矢量，方向沿着力的方向。

    * 按三个坐标方向分解后，合力是三个分量的平方和再开根号：$F=\sqrt{F_x^2+F_y^2+F_z^2}$，方向以沿坐标正向为正。

* **面力**

    * 分布在物体表面的力，比如流体压力这一类作用在表面上的分布力。

    * 用单位面积上所受到的力来度量，同样按三个方向平方累加再开根号，以指向外法向为正。

* **集度性质**

    * > **易错点**：体力和面力都是「集度」，表示的是单位体积、单位面积上的作用力，不是总的合力。

    * 所以在考虑平衡条件、做求和的时候，必须乘以相应的体积或者面积，得到的才是合力。

### 内力与应力

* **内力**

    * 物体本身不同部分之间相互作用的力：想象把一个物体切开，截面两边相互作用的那个力就是内力。

* **应力**

    * 截面上单位截面积上的内力：$\sigma=\dfrac{F}{A}$，力学里一般用 $\sigma$ 表示。

    * 内力作用在截面的法向（垂直于表面）时称为正应力；作用在平行于表面的方向上时是剪应力，用 $\tau$ 表示。

* **多出的作用面**

    * 力有三要素——大小、方向、作用点；应力除了这三样还有一个非常重要的东西：作用面。

    * 因为它定义在单位面积上，离开面积就无从谈起；直接后果是同一个点、不同的截面，应力不同。

* **同点不同面**

    * 一根杆两端都受大小相等、方向相反的力 $N$，中间那个截面上两侧的力互相抵消、合力为零，那里的应力就是零。

    * 只有一端受力时，分析垂直于轴线的截面，正应力是 $\sigma=\dfrac{N}{A}$。

    * 若分析的是过一个点 $P$ 的斜截面，结果又不一样：虽然都过 $P$，方向不同应力就不同，斜截面上还要分解成垂直于斜面的正应力与平行于斜面的剪应力。

## 一点的应力状态

### 六面体取法

* **取法**

    * 在 $P$ 点取出一个无穷小的平行六面体，三条棱分别沿三个坐标轴，长度记作 $dx$、$dy$、$dz$，用六个表面上的应力分量来表示 $P$ 点的应力。

    * 实际分析时就是在实体结构里取出一个小小的六面体，分析包含 $P$ 点的这个微小正六面体。

* **为什么六面体够用**

    * 因为它可以取得任意小，一直小到趋近于 $P$ 点；此时六个面上的应力就趋近于过 $P$ 点、法向分别沿三个坐标轴的那三组平面上的应力。

    * 任意一个斜截面上的力，都可以由这三组平面上的应力通过平衡关系投影出来——底账就是这么记的。

    * 六个面成三对，每一对的两个面外法向相反、互相平行；所谓分析 $P$ 点的应力状态，就是把这三对面上的应力都写出来。

### 下标与正负号

* **正应力下标**

    * $\sigma_i$ 的下标 $i$ 是作用面的外法向，同时也是力的方向——正应力垂直于面，两者天然同向。

    * $\sigma_y$ 完整写出来是 $\sigma_{yy}$，作用面外法向与力的方向都是 $y$，两个下标相同；两个下标相同的分量只写一个下标，这个简写约定就是 **Voigt 记号**。

* **切应力下标**

    * $\tau_{ij}$ 的第一个下标 $i$ 是作用面的外法向，第二个下标 $j$ 是力的指向。

    * $\tau_{yx}$ 是「作用在外法向为 $y$ 的面上、指向 $x$ 的切应力」；$i$、$j$ 各取 $x$、$y$、$z$，组合起来正好六种。

    | 切应力分量 | 作用面的外法向 | 力的指向 |
    | :--- | :--- | :--- |
    | $\tau_{xy}$ | $x$ | $y$ |
    | $\tau_{xz}$ | $x$ | $z$ |
    | $\tau_{yx}$ | $y$ | $x$ |
    | $\tau_{yz}$ | $y$ | $z$ |
    | $\tau_{zx}$ | $z$ | $x$ |
    | $\tau_{zy}$ | $z$ | $y$ |

* **正负号规定**

    * 外法线沿坐标轴正方向的面叫正面，正面上应力沿坐标轴正方向为正、沿负方向为负；外法线沿坐标轴负方向的面叫负面，负面上的正负正好相反。

    * 一句话概括：应力的指向与所在面的外法向同号为正。

* **与材料力学的符号分歧**

    * > **易错点**：材料力学对剪应力的正负号另有规定——按剪应力对截面内任意一点的矩是顺时针还是逆时针来定，与弹性力学这套「按面法向和力指向」的规则不是一回事。

    * 两套体系的符号不能混着用，看不同教材的图时先确认它用的是哪一套。

### 切应力互等与六分量

* **切应力互等**

    * > **定义**：在受力物体相互垂直的两个表面上，切应力必然成对存在，大小相等，且两者都垂直于这两个平面的交线，方向同时指向交线或同时背离交线。

    * 写成式子就是 $\tau_{ij}=\tau_{ji}$；绝不会出现一个指向交线、另一个背离的画法。

* **两个学科的画法差异**

    * 弹性力学取「大小相等、图上方向同向」的画法，材料力学取「大小相等、图上方向相反」的画法。

    * 这不是物理上打架，而是两边取正号的规定不同，导致同一个物理量画出来的箭头方向相反。

* **六个独立分量**

    * 三个正应力 $\sigma_x$、$\sigma_y$、$\sigma_z$，三个切应力 $\tau_{xy}$、$\tau_{yz}$、$\tau_{zx}$。

    * 没有 $\tau_{yx}$ 和 $\tau_{zy}$，因为它们分别和 $\tau_{xy}$、$\tau_{yz}$ 相等，写出来是重复的。

    * > **提示**：这六个量在 $P$ 点已知，就能求出过该点任何斜面上的正应力和切应力；六个分量完全确定了 $P$ 点的应力状态，它们被称为该点的应力分量。

* **坐标函数与列阵**

    * 弹性体里应力各处不同，这些分量并不是常量而是坐标的函数：$\sigma_x(x,y,z)$、$\tau_{xy}(x,y,z)$ 依此类推；在取出的微元体上可以把它们当常量处理。

    * 工程计算里习惯排成一个列阵，三个正应力在前、三个切应力在后：$\{\sigma\}=[\sigma_x,\ \sigma_y,\ \sigma_z,\ \tau_{xy},\ \tau_{yz},\ \tau_{zx}]^{T}$。

    * 后面的几何方程、物理方程都用这个列阵表示，记住排列顺序，矩阵推导时不会错位。

## 位移、应变与平面问题

### 位移与应变

* **位移**

    * 物体里任意一点 $A$ 的位置变化在三个坐标轴上各有分量，记作 $u$、$v$、$w$——沿 $x$ 是 $u$，沿 $y$ 是 $v$，沿 $z$ 是 $w$。

* **两类位移**

    * 与形状有关的位移：物体真的变了形，原来的形状变成另一个形状。

    * 与形状无关的位移：刚体位移。物体整体从这儿挪到那儿，$A$ 变成 $A'$，确实有了位移，但形状一点没变——刚体发生不了形变，它只有位置的改变。

* **正应变**

    * 任意线段变形后的长度变化量除以它原来的长度：$\varepsilon=\dfrac{\Delta L}{L}$。

    * 沿三个坐标轴各有一个分量，记作 $\varepsilon_x$、$\varepsilon_y$、$\varepsilon_z$；伸长为正，缩短为负。

* **剪应变**

    * 原来成直角的两个线段，受力后夹角不再是 $90^{\circ}$，改变量记作 $\gamma$。

    * 沿 $x$ 的线段转过 $\alpha$，沿 $y$ 的线段转过 $\beta$，两条边一起贡献了这个直角的改变量，所以 $\gamma_{xy}=\alpha+\beta$；同样有三个分量 $\gamma_{xy}$、$\gamma_{yz}$、$\gamma_{zx}$。

    * > **提示**：正应变描述「拉长压短」，剪应变描述「直角被掰歪」，两者合起来才能完整刻画一个微元的形状变化；只给正应变，你不知道这个方块是被斜着搓过的。

### 平面应力问题

* **几何特征**

    * 等厚的薄板：一个方向上的尺度远远小于另外两个方向的尺度，就是前面说过的薄壁结构。

* **载荷与约束要求**

    * 体力作用于体内，平行于板的正中面，而且沿板的厚度方向不变化。

    * 面力只作用在板的边上，同样平行于中面、沿厚度不变；约束也只作用于板边，平行于中面、沿厚度不变。

* **为零的量**

    * 外力和约束全部平行于板的平面作用，厚度方向既没有载荷也不随厚度变化，于是垂直于板面的正应力与 $z$ 面上两个切应力全为零：$\sigma_z=0$、$\tau_{zx}=0$、$\tau_{zy}=0$。

    * 关键在它不只在某一个面上成立：因为沿厚度什么都不变，中面上为零的量整个板厚之内都为零，不必逐点验证。

* **保留的未知量**

    * 六个分量划掉三个，剩下 $\sigma_x$、$\sigma_y$、$\tau_{xy}$（而 $\tau_{yx}=\tau_{xy}$）。

    * 所谓平面应力问题，就是「只剩下 $xy$ 面内的两个正应力加一个切应力」的问题。

### 平面应变问题

* **几何特征**

    * 一个很长的等截面柱体，沿 $z$ 方向拉得很长，横截面的形状和面积沿长度不变。

    * 载荷条件照着几何来：体力作用于体内、平行于横截面；面力、约束同样平行于横截面。

* **为什么没有 $z$ 向位移**

    * 因为它很长，任意取一个横截面，两侧的材料是对称的，这个截面就可以看成一个对称面。

    * 对称面上的点不能有垂直于该面的位移，否则对称性就被破坏了，于是 $w=0$、$\varepsilon_z=0$、$\gamma_{yz}=\gamma_{zx}=0$。

* **名字的由来**

    * 位移只有面内的 $u$、$v$，所以它也被叫作平面位移问题；因为应变跟着位移走，习惯上的名字是平面应变问题——应变只发生在面内。

* **易错点**

    * > **易错点**：$\sigma_z$ 在这里并不等于零。$z$ 方向虽然没有位移，但两侧的材料把它夹住了，它照样受力。

    * 平面应力是「厚度方向自由、应力为零」，平面应变是「厚度方向被约束、应变为零」，这两句话不能混。

### 两种简化的对照

* **简化价值**

    * 实体结构（发动机缸体）只能按空间问题分析，三个方向的位移、应变、应力都不能丢；薄壁件、薄板可简化为平面问题。

    * 应变和应力各有六个分量，简化之后只分析面内的那几个，未知量立刻少一大截，手算也好、编程也好都轻得多。

* **对照表**

    | 对比项 | 平面应力问题 | 平面应变问题 |
    | :--- | :--- | :--- |
    | 结构特征 | 等厚薄板 | 很长的等截面柱体 |
    | 几何条件 | 厚度远小于另两个方向 | 长度远大于截面尺寸 |
    | 载荷与约束 | 平行于中面，沿厚度不变 | 平行于横截面 |
    | 为零的量 | $\sigma_z$、$\tau_{zx}$、$\tau_{zy}$ | $\varepsilon_z$、$\gamma_{yz}$、$\gamma_{zx}$（$w=0$） |
    | 保留的未知量 | $\sigma_x$、$\sigma_y$、$\tau_{xy}$ | $\sigma_x$、$\sigma_y$、$\tau_{xy}$、$\sigma_z$ |
    | 典型对象 | 板类薄壁结构 | 长柱体类结构 |

    * 两种做法的方向正好相反：一个在应力上归零，另一个在应变上归零。

## 三类方程与边界条件

### 方程链条

* **三类方程的分工**

    * 平衡方程管应力与外力，几何方程管应变与位移，物理方程管应力与应变。

    * 它们首尾相接，正好把「位移→应变→应力→外力」这一圈连起来，再配上边界条件才能解；缺哪一段这个闭环都断，方程组也就不封闭。

* **链条全图**

    ```text
                  位移 u、v、w
                        │ 几何方程（微分关系）
                        ▼
                  应变 ε、γ
                        │ 物理方程（代数关系，材料参数 E、μ）
                        ▼
                  应力 σ、τ
                        │ 平衡方程（微分关系 + 边界条件）
                        ▼
                位移场与应力场的解
    ```

### 平衡方程

* **取微元**

    * 平衡方程表示物体内任何一点微分体的平衡条件：取边长 $dx$、$dy$、$dz$ 的微元，每个表面上都作用着它自己的正应力和切应力。

* **应力的增量**

    * 设背面（外法向 $-x$）上的正应力是 $\sigma_x$，沿 $x$ 走到正面（外法向 $+x$）、走过 $dx$ 之后应力有了一个增量：$\sigma_x \to \sigma_x+\dfrac{\partial \sigma_x}{\partial x}dx$。

    * 这一步能写出来靠两条假设：连续性假设让应力可以用连续函数表示，所以才能谈增量；小变形假设让面积和力臂都按 $dx$、$dy$、$dz$ 算，不必回头修正。

* **$x$ 向合力**

    | 力的来源 | 应力或体力 | 作用的面积／体积 |
    | :--- | :--- | :--- |
    | 背面（外法向 $-x$）的正应力 | $\sigma_x$ | $dy\,dz$ |
    | 正面（外法向 $+x$）的正应力 | $\sigma_x+\dfrac{\partial\sigma_x}{\partial x}dx$ | $dy\,dz$ |
    | 底面（外法向 $-y$）的切应力 | $\tau_{yx}$ | $dx\,dz$ |
    | 顶面（外法向 $+y$）的切应力 | $\tau_{yx}+\dfrac{\partial\tau_{yx}}{\partial y}dy$ | $dx\,dz$ |
    | 体力 | $f_x$ | $dx\,dy\,dz$ |

    * 正应力沿 $x$ 作用，所在面的面积是 $dy\,dz$；切应力 $\tau_{yx}$ 躺在法向为 $y$ 的上下底面，作用面积是 $dx\,dz$。

    * 相对的两个面外法向相反，同一个方向上的分量在两边一正一负，所以这四个应力项是相减之后再相加，而不是简单叠加。

* **平衡微分方程**

    * 令合力为零、约去公共的微元体积，$x$ 向得 $\dfrac{\partial\sigma_x}{\partial x}+\dfrac{\partial\tau_{yx}}{\partial y}+f_x=0$。

    * 同法列 $y$ 向得 $\dfrac{\partial\tau_{xy}}{\partial x}+\dfrac{\partial\sigma_y}{\partial y}+f_y=0$。

* **力矩条件与切应力互等**

    * 绕 $z$ 轴对微元中心点取矩：正应力都通过中心点，体力也通过中心点，力臂为零不产生力矩，真正产生力矩的只有成对的切应力。

    * 令合力矩为零，再用小变形假设把微小的增量项去掉，就得到 $\tau_{xy}=\tau_{yx}$——这是切应力互等在微分形式下的来历，与从物理上「成对出现、同指向」直接给出殊途同归。

* **三套力学的比较**

    * 材料力学、理论力学、弹性力学里都有平衡方程，只是表达方式与研究目标不同。

    * 三者之中，弹性力学的平衡条件最严格。

### 斜截面上的应力

* **三角形微元**

    * 把微元从六面体换成三角形：包含 $x$ 面、$y$ 面和斜的 $n$ 面，两个直角边分别贴在 $x$ 面与 $y$ 面上，斜边就是要求的那个截面。

    * 用方向余弦——法线 $n$ 与 $x$、$y$ 轴夹角的余弦，记作 $l$、$m$——配合斜边长度，用投影关系把各面上的力换算到同一条斜边上。

* **计算式**

    * 斜面上的力乘斜边面积，与 $\sigma_x$ 乘 $x$ 面投影面积、$\tau_{xy}$ 乘 $y$ 面投影面积、体力乘体积一起构成平衡条件。

    * 写开就是 $p_x=\sigma_x l+\tau_{yx}m$、$p_y=\tau_{xy}l+\sigma_y m$，其中 $p_x$、$p_y$ 是斜面上那个力 $p$ 沿 $x$、$y$ 的分量。

    * 正应力是 $p$ 在法向的投影，切应力是 $p$ 在切向的投影：$\sigma_n=p_x l+p_y m$、$\tau_n=p_y l-p_x m$。

    * 手法没有新东西，仍旧是取微元、列平衡、投影，只是几何形状从六面体缩成了三角形。

### 几何方程

* **位移的增量**

    * 取微元，$P$、$A$、$B$ 三点构成直角，$PA$ 沿 $x$ 长 $dx$、$PB$ 沿 $y$ 长 $dy$；变形后 $P$ 移到 $P'$，$x$ 向位移 $u$、$y$ 向位移 $v$。

    * $A$ 也移动，但它离 $P$ 有 $dx$，位移里还要多加一份由位置差带来的增量：$u_A=u+\dfrac{\partial u}{\partial x}dx$、$v_A=v+\dfrac{\partial v}{\partial x}dx$。

* **正应变**

    * $PA$ 这条线段的正应变是变形后长度减原长再除以原长：$\varepsilon_x=\dfrac{\left[dx+\dfrac{\partial u}{\partial x}dx\right]-dx}{dx}=\dfrac{\partial u}{\partial x}$。

    * 同理沿 $y$ 的 $PB$ 给出 $\varepsilon_y=\dfrac{\partial v}{\partial y}$。

* **剪应变**

    * 原来 $\angle APB=90^{\circ}$，变形后 $PA$ 转过 $\alpha$、$PB$ 转过 $\beta$，两者共同把直角掰歪了 $\alpha+\beta$。

    * 两角都不大用正切算：$\tan\alpha=\dfrac{\frac{\partial v}{\partial x}dx}{dx+\frac{\partial u}{\partial x}dx}\approx\dfrac{\partial v}{\partial x}$，$\tan\beta\approx\dfrac{\partial u}{\partial y}$。

    * 分母里那个 $\dfrac{\partial u}{\partial x}dx$ 相对 $dx$ 是小量可略去；小变形假设下变形量很小，正切值等于角度值本身，两边一加得 $\gamma_{xy}=\dfrac{\partial u}{\partial y}+\dfrac{\partial v}{\partial x}$。

* **平面问题的三式**

    * $\varepsilon_x=\dfrac{\partial u}{\partial x}$、$\varepsilon_y=\dfrac{\partial v}{\partial y}$、$\gamma_{xy}=\dfrac{\partial u}{\partial y}+\dfrac{\partial v}{\partial x}$。

    * 它是一组纯几何的、运动学的关系，跟材料是什么、受多大的力都没有关系。

* **方向性**

    * > **提示**：几何方程不是位移与形变之间的充分必要关系。位移确定，形变完全确定；形变确定，却定不出全部位移。

    * 原因就是前面分过的两类位移：整体平移、转动这类刚体位移不改变任何线段长度与夹角，应变里根本不含它的信息。

    * 给了一组应变，你可以把形状画出来，却不知道这块东西整体搁在空间的哪个位置、朝哪个方向；补上边界条件，位置和姿态才被钉死。

### 物理方程

* **叠加的推导**

    * 物理方程也叫本构方程，讲应力与应变之间的关系，描述材料本身的变形性质；最简单的物理方程是胡克定律，推广到三维应力状态就是广义胡克定律。

    * $x$ 方向的应变由三个正应力共同造成：$\sigma_x$ 使其伸长 $\dfrac{\sigma_x}{E}$，$\sigma_y$ 与 $\sigma_z$ 各使其横向收缩 $-\mu\dfrac{\sigma_y}{E}$、$-\mu\dfrac{\sigma_z}{E}$。

* **正应变三式**

    * 三项叠加：$\varepsilon_x=\dfrac{1}{E}\left[\sigma_x-\mu\left(\sigma_y+\sigma_z\right)\right]$，$\varepsilon_y$、$\varepsilon_z$ 把下标轮换即可。

    * 后面两项带负号的原因是泊松效应：一个方向受拉，另外两个方向就会缩，横向变形与纵向变形反号。

* **剪应变三式**

    * 三个剪应变与切应力之间只差一个系数，形式上更简单：$\gamma_{xy}=\dfrac{\tau_{xy}}{G}$、$\gamma_{yz}=\dfrac{\tau_{yz}}{G}$、$\gamma_{zx}=\dfrac{\tau_{zx}}{G}$。

    * $E$ 是弹性模量，$\mu$ 是泊松比，$G$ 是剪切模量；六个式子合在一起就是完整的本构方程。

* **参数的实际含义**

    * > **提示**：做有限元分析、给材料模型填参数时，填的就是 $E$ 和 $\mu$——因为本构方程里材料的全部信息都装在这两个数里。

### 弹性矩阵与柔度矩阵

* **矩阵形式**

    * $\{\sigma\}=[D]\{\varepsilon\}$、$\{\varepsilon\}=[C]\{\sigma\}$；$[D]$ 叫弹性矩阵，$[C]$ 叫柔度矩阵，两者互为逆矩阵。

* **$[D]$ 的性质**

    * 元素只由 $E$ 和 $\mu$ 决定，与坐标无关——材料是连续的，物体内哪一处的材料性质都一样。

    * 也与位移无关、跟变形状态无关，纯粹是材料属性的载体。

* **形式不变的价值**

    * 换到平面应力或平面应变问题，$[D]$ 里的元素会不一样，但 $\{\sigma\}=[D]\{\varepsilon\}$ 这个总体形式一字不改。

    * 这是有限元程序好写的根本原因之一：模块是同一个，只是喂进去的弹性矩阵不同，程序主体不用动。

* **另一种写法**

    * 除了用 $E$、$\mu$ 表示，也可以改用拉梅系数 $\lambda$ 与 $G$ 表达，得到等价的另一种形式，矩阵里的系数写法会跟着变。

### 边界条件

* **约定与三类限制**

    * 研究对象以外的其他物体称为外界；研究对象与外界接触的那个面称为边界。

    * 边界对研究对象的限制包含三方面：边界的形状、边界上所受的外力、边界给出的位移约束。

* **两类边界**

    * 力边界 $S_\sigma$：边界上的面力已知；位移边界 $S_u$：边界上的位移已知。

    * 判断一个问题怎么提，先问一句：这个边界上给的是力，还是给的是位移？

* **补上几何方程的缺口**

    * 形变定不出刚体位移这个缺口，正是靠位移边界补上的。

    * 没有它，方程组的解可以整体平移、转动，有无穷多组。

* **进入求解的方式**

    * 把边界上的应力和应变做分解计算，再融进方程里去。

    * 所以在有限元求解程序里，专门有一块模块负责力边界和位移边界的处理。

* **体系闭合**

    * 一点处的应力状态由六个分量刻画，变形由位移与应变刻画，内部靠平衡、几何、物理三类方程联系，外部靠力边界与位移边界收口。

    * 有限元后面要做的，无非是把这套连续的表达离散到一个个单元上，再把它变成能算的线性代数。
