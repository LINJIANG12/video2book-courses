# 基于物理的实时着色

## PBR 与实时材质现状

* **基于物理的渲染（physically based rendering，PBR）**

    * > **定义**：模拟一切与光相关的物理过程的渲染体系；渲染内部的任何话题其实都在 PBR 范围之内——材质（光与表面、体积等 matter 怎么互动，即 light-matter interaction）、光照传输、相机成像皆是。

    * 实时领域平常一说 PBR，默认指的就是材质这一块；概念虽大，在不引起歧义的场合把 PBR 材质直接叫成 PBR 就行。

    * 实时材质落后离线渲染两点：**丰富程度**——离线渲染器本身就支持好几十种材质、artist 能调出大概几百种，实时只敢用研究得比较透彻、跑得又快的少数材质；**质量与准确度**——为了能快速渲染必须牺牲很大一部分质量，典型是头发（根数多、光线在每根头发之间的运动无法模拟，实时只能忽略一些准确度换速度）。

    * > **注意**：实时渲染中提到的所谓 physically based 基本都不是 physically based——分析（材质怎么样和光线作用）是物理的，但实时做了大量简化，很多地方已经不再基于物理；大家仍这么叫，区分概念即可。

    * 实时 PBR 材质最重要的事情是 performance：在保证速度的前提下尽可能提升质量，物理严格性是第一个被牺牲的东西。

    * 实时做材质的本质：把离线渲染那边用熟的理论拿过来，想出各种聪明的 implementation hacks 把开销降到实时；超快猛地把问题解决掉的好 hack 绝对不是坏事。

* **表面材质与体积材质**

    * 实时 PBR 材质分两类：定义在**物体表面**上的——微表面模型（基于物理地描述微表面的法线分布、怎么理解宏观表面与微观表面）与迪士尼 principled BRDF（按迪士尼的一套原则设计）；定义在**体积（volume）**上的——云、烟、雾，光线会进入体积里面去作用，实时里比表面更困难（表面现在做得已经相当不错）。

    * 迪士尼 principled BRDF 发明出来是给离线渲染（迪士尼自家渲染器）用的，但非常轻量级——计算量小、实现容易、能表示的材质种类特别多、效果不错，于是实时渲染也大量在用；注意它本来就不是 PBR——是从 artist 的角度、为艺术家用起来方便而设计的 BRDF，正好印证"实时用了复杂材质不见得真是 PBR"。

    * 体积材质更关注两个概念：single scattering（光线在体积中作用一次）与 multiple scattering（作用多次）的分离考虑方法。

    * 头发是体积类绕不开的例子：古墓丽影重启三部曲引入了一套真正可以一根一根渲染头发的人物系统（戏称"海飞丝系统"），到今天也不是所有游戏、所有人物都能支持这么做；头发这块现在做得已经不错。

    * 承前：屏幕空间全局光照收尾之后，材质成为实时基于物理着色的主线——SSDO 是 SSAO 的提升版，真正把近距离的全局光照做了出来；SSR 更通用，思路是利用屏幕空间能看到的场景深度形成一层"壳"、直接对这层壳做光线追踪，只要一个效果用到的信息都在屏幕空间里理论上就能做（screen space ray tracing，不只屏幕空间的镜面反射）。

## 微表面 BRDF 的三项构成

* **微表面模型（microfacet model）**

    * > **定义**：微观上看表面是各种各样的微表面，它们朝向（法线）各不相同，法线的分布让渲染出的表面看起来各不相同；微表面 BRDF 由三项构成——**F 项**：Fresnel 项，决定从一个角度看过去有多少能量会被反射；**G 项**：shadowing-masking，微表面的自遮挡；**D 项**：微表面法线的分布，最重要的一项。

    * 为什么微表面模型合理：给一个入射方向、一个出射方向，若每个微表面都是镜面，只能是法线朝着半程向量（half vector）方向的那些微表面——它们的法线与 half vector 一致，才能把能量从 $\omega_i$ 反射到 $\omega_o$。

    * 于是 $D(h)$ 就是 NDF 这个函数在 half vector 方向上的取值；公式分母里的项是推导中间产生的归一化量。

## Fresnel 项

* **菲涅尔项（Fresnel term，F）**

    * > **定义**：有多大百分比的能量会被反射掉，这个比例由入射角决定。

    * 入射角接近掠射角（grazing angle，入射方向和法线几乎垂直）时反射最多；BRDF/光线传播是 reciprocal（可逆）的——眼睛看过去的方向接近掠射角时，看到的反射同样多，书和它背后的墙会出现非常明显的反射。

    * 绝缘体（dielectric，相对于导体的叫法，如水面、镜子、玻璃）：从正上方看下去很少能量被反射、基本会看透过去；从掠射角斜着看会出现大量反射——站在河边往远处的水面看，会看到反射出很多天。

    * 导体（金属）：基本同样垂直看反射少、掠射看多，但有时会出现反常现象——反射率先突然变少又变多；而且金属整体反射的能量高很多，垂直看金属表面也有百分之九十几的反射。

    * 精确公式要考虑光线的极化（s 极化、p 极化的综合效果相加除以二）、两种介质（如空气与物体表面）各自的折射率以及入射角、折射角——都能算但太复杂；实际用的是 split sum 讲过的那个简单估计。

    * 估计式（$R_0$ 为基础反射率）：

    $$F(\theta) = R_0 + (1 - R_0)(1 - \cos\theta)^5$$

    * 验证：$\theta=90°$ 时 $\cos\theta=0$，$F=R_0+(1-R_0)=1$——掠射角反射率为 1；$\theta=0°$ 时右边第二项全为零，$F=R_0$——正对表面看反射的就是基础反射率。

    * $R_0$ 是基础反射率，注意它是 RGB 的、是一个颜色而非标量；取值与不同物质的折射率有关。这个估计很糙，但是很好用。

## 法线分布函数 NDF

* **法线分布函数（normal distribution function，NDF，D 项）**

    * > **定义**：描述各微表面法线在方向上如何分布的函数，是材质外观的总开关。

    * 分布集中（微表面法线变化不明显、朝向都差不多）→ 表面比较平坦，得出近似 glossy 的结果；非常非常集中 → specular 效果；分布往四面八方都有、杂乱无章 → 表面复杂、粗糙，结果类似 diffuse。

    * 有用的直观图像：把物体微观表面的高度上下拉伸（scale），所有面被拉得立起来、法线分布越来越开、微表面形成的沟壑越来越深——**粗糙的表面其实可以认为是由很多微表面形成的深沟**。

    * NDF 是二维的：法线的朝向是球面上的二维方向；法线不可能朝下，所以取半球。可视化时把半球投影成一个单位圆，Beckmann 与 GGX 投影后形状都差不多：中间有一个比较大的值，往两边不断衰减。

    * 常用模型只有两个：Beckmann 模型与 GGX 模型；还有更多模型，但那些模型对实时渲染来说代价太大，只有一些特殊场合在用（古墓丽影的雪地就在用更复杂的模型）。

    * > **易错点** ⚠️：NDF 的 normal 是"法线"，与统计学里的正态分布没有关系——正态分布的英文也叫 normal distribution，那里 normal 是"正态"，这里指"法线"，只是英文同形。

## Beckmann NDF 与坡度空间

* **Beckmann NDF**

    * 公式：

    $$D_{\mathrm{Beckmann}}(h) = \frac{e^{-\tan^2\theta_h / \alpha^2}}{\pi\,\alpha^2\cos^4\theta_h}$$

    * 它是法线方向 $h$ 的函数：$h$ 取半球上任何一个方向，描述这个方向上对应的值是多少；长得非常像高斯函数——中间值非常大，往两边衰减。

    * $\alpha$ 起高斯函数里 $\sigma$（标准差）的作用，描述法线的粗糙程度：值越小越不粗糙、表面越像镜面/光滑表面；越大越像 diffuse。

    * $\theta_h$ 是 $h$ 与正中间法线 $(0,0,1)$ 的夹角（球面参数化 $(\theta,\varphi)$ 里的 $\theta$）；公式只跟 $\theta$ 有关、跟 $\varphi$ 没有关系，NDF 图绕中心旋转不变——描述的是各向同性（isotropic）的结果。它能表示各向异性，但此处一律假设各向同性。

* **坡度空间（slope space）**

    * > **定义**：单位半球顶端的切平面；微表面法线方向与竖直宏观法线的夹角为 $\theta$，把这根法线延长到与切平面相交，交点到法线顶端的距离就叫 $\tan\theta$——这个切平面就是 slope space。

    * 为什么用 $\tan^2\theta_h$ 而不是 $\theta_h^2$：高斯函数的 support（覆盖范围）是无限大的；在 slope space 里一路往外走、走到再远，也一定对应一个有限的、在 90° 之内的角度（角度不断增加的极限是 90°）——定义无限大的函数，仍保证不可能出现面朝下的微表面。

    * 反过来：若直接在角度 $\theta$ 上定义高斯，support 无限大意味着 $\theta$ 超过 90° 之后仍有值——可能出现朝下的微表面，这就不好了。

    * > **易错点** ⚠️：slope space 能保证的只是"微表面的法线不朝下"；它并不能保证掠射角过来的反射光不被微表面挡住——这种情况有可能出现，怎么解决正是 G 项（shadowing-masking）要处理的问题。

* **归一化**

    * 分母里的 $\pi$、$\alpha^2$、$\cos^4\theta_h$ 都是在推导中为保证归一化性质产生的系数。

    * NDF 必须在投影立体角（projected solid angle）下积分为 1：把半球投影成一个单位圆后，要在覆盖 $[-1,1]\times[-1,1]$ 的圆盘上积分为 1，而不是在球面上积分为 1；等价理解——在球面上是 NDF 和 $\cos\theta$ 项放在一起积分等于 1。

## GGX 与 GTR

* **GGX（Trowbridge-Reitz，TR）**

    * GGX 又叫 Trowbridge-Reitz 模型——全名念起来比较长，人们简称 TR，叫 GGX 也行，它们是一回事。

    * 标志性特点是长尾（long tail）：Beckmann 高斯式衰减，刚过 45° 就差不多衰减到零；GGX 也会很快衰减，但衰减到一定程度后速度放慢，一路衰减到 grazing angle（90°）仍然不怎么是零——尾巴一直甩到 90° 那儿。

| 对比 | Beckmann | GGX |
| :--- | :--- | :--- |
| 曲线衰减 | 高斯式，45° 附近几乎衰减到零 | 先快后慢，长尾拖到 90° |
| 高光边缘 | 非常尖锐的过渡，戛然而止 | 明显的过渡带，柔和地渐隐 |
| 粗糙表面的其余区域 | 基本全黑 | 保留类似 diffuse 的余光 |
| 工业界趋势 | 渐渐被取代 | 越来越多用，artist 觉得更自然 |

    * 视觉对应：曲线峰值对应高光、衰减段是高光的渐渐消逝——Beckmann 的高光马上消失；GGX 的高光边缘不怎么消失，很慢地变成一个比较低的值，高光周围会期待看到类似光晕（halo）的现象。

    * 几条问答结论：两者耗时上没有特别大差别；不能说"GGX 高光范围更广"——高光大小取决于分布集不集中，GGX 也可以表示小的高光，只是在相同 roughness 下过渡更明显；金属与非金属的效果其实都不错。

* **广义 Trowbridge-Reitz（generalized Trowbridge-Reitz，GTR）**

    * > **定义**：迪士尼动画工作室（WDAS）的 Brent Burley 对 GGX 的进一步拓展，目的是更长的尾巴；GGX 的这个拓展与迪士尼 principled BRDF 都出自他一人。

    * 引入参数 $\gamma$ 控制尾巴长度：$\gamma=2$ 时就是 GGX；$\gamma$ 取得更小，尾巴就更长；$\gamma$ 取得超级大（如 10 或更大），结果靠近 Beckmann。

    * GTR 相当于把 Beckmann 和 GGX 又结合到一块，把两个理论统一了起来，并且还可以继续往外延伸。

## Shadowing-Masking 项

* **shadowing-masking 项（又称几何项 geometry term，G 项）**

    * > **定义**：处理微表面之间自遮挡的项——一些微表面会挡住另外一些微表面；没有正式的中文名字，工业界叫法特别乱（也有人反过来说 masking-shadowing term）。

| 出发方向 | 现象 | 名称 |
| :--- | :--- | :--- |
| 从光照出发 | 入射光被其他微表面挡住 | shadowing |
| 从眼睛出发 | 一些微表面反射的光到不了眼睛 | masking |

    * 两个现象本质上一样，统称 shadowing-masking；引入它是为了考虑由于遮挡产生的变暗（darkening）——最终看到的结果肯定不如算出来的那么亮。

    * 遮挡在掠射角最严重：一部分微表面法线朝上、反射方向也没错，却因为被其他微表面挡住而接不到光；光路可逆，从这个方向看过去一个道理——光在半路被挡住，眼睛接收不到。

    * 函数形状：没有任何遮挡时它什么事也不做、结果为 1；掠射角时剧烈减少、一直减少到零。

    * 为什么必须有（以渲染一个球为例）：垂直入射时 Fresnel 只给出基础反射率 $F_0$，没问题；掠射角在球的侧面边缘，$F$ 基本为 1，若不考虑几何项（$G=1$），剩下法线分布 $D$ 也是正常函数——问题出在分母：（法线·入射方向）（法线·出射方向）两个点积在掠射时至少有一个非常接近零，整个函数除以接近零的值会变得巨大——没有几何项，球的整个外圈就是白的，显然不符合物理。

    * > **易错点** ⚠️：球边缘变亮的两个来源要分清——Fresnel 在掠射角趋于 1 是物理事实，没问题；真正把结果推成"巨大"的是分母里趋近于零的 $\cos$ 点积，压住它的是 G 项。

    * Smith shadowing-masking 项：在"法线服从某种统计学分布（即给定了 NDF）"的假设基础上推出对应的项；通常还做一步额外工作——把 shadowing 和 masking 两件事拆开、认为互不相关（事实上有关系，即做了独立性假设），拆开后一份跟观察方向有关、一份跟光照方向有关，各管各的。

    * 把 GGX 与 Beckmann 分别代进去，预测出的形状都差不多：垂直入射基本不起作用（只要微表面法线不朝下，垂直看过去就没有遮挡问题）；掠射角上发生剧烈遮挡，会让整个 BRDF 的值变得非常小，最后也变到零。

    * 几何项里用的方向是 half vector。

## 能量损失与 Kulla-Conty 近似

### 白炉测试

* **白炉测试（white furnace test）**

    * > **定义**：用各处 radiance 都一样的均匀环境光照亮物体、背景同色；不损失能量的 BRDF，应当让物体在任何 roughness 下都"隐身"于背景之中。

    * 现象：D、G、F 三项都考虑对了之后仍不行——把同一材质按 roughness 从小到大排成一排渲染，从左到右越来越暗；抛光（最左）与哑光（最右）的白金整体颜色应该差不多，总不能一做成哑光白金就暗成那样。

    * 测试设置：均匀环境光照（注意不是全局光照）下，roughness 非常低时物体每点反射的颜色与背景一致、什么也看不到；增大 roughness，能量损失的现象非常明显地出现——材质在变、光照什么都没动，若能量一直收对就不该如此。

* **能量去哪了**

    * 根因：roughness 越大，法线分布得越开、面越粗糙，沟壑越严重；一条光线打到微表面上，它的反射光更容易被其他微表面挡住——被挡住的反射光自然看不到，能量就损失了。

    * 本质是**多次弹射**的问题：越粗糙的表面，光线在微表面之间多次弹射的可能性与占比越大；而微表面模型只考虑一次 bounce（弹一次就被看到），丢的能量自然就越多。

    * 准确的方法 2016 年就有：真正在微表面上做一个类似光线追踪的东西、把多次弹射算出来——非常慢，离线渲染都认为太慢，实时更没法接受；实时用近似，但"补回多次弹射丢失的能量"这个基本思想不会错。

### Kulla-Conty 的构造

* **Kulla-Conty 近似**

    * > **定义**：现在工业界非常常用的经验性方法，补全微表面（其实任意的 BRDF 都可以）由于多次散射损失的能量——丢多少，补多少。

    * 基本观察：一束反射光只有两种可能——没被其他微表面挡住（出表面，看得到）；被微表面挡住（看不到，且必然发生后续更多次弹射，直到它能够离开表面）。**"被遮挡"和"发生下次弹射"是完完全全一样的概念。**

    * 第一步算丢了多少：假设所有方向的入射 radiance 都是 1（rendering equation 里 $L$ 是常数不用考虑）、各向同性（把方位角积掉），把 BRDF 乘 $\cos$ 在整个半球上积分，得到 uniform 全 1 radiance 下单次弹射真正能离开表面、被观察到的总能量：

    $$E(\mu_o) = \int_{\omega_i \in \Omega} f(\omega_i,\omega_o)\cos\theta_i\,\mathrm{d}\omega_i = \int_0^{2\pi}\int_0^1 f(\mu_i,\mu_o)\,\mu_i\,\mathrm{d}\mu_i\,\mathrm{d}\phi_i$$

    * 换元 $\mu=\cos\theta$：立体角微元 $\sin\theta\,\mathrm{d}\theta\,\mathrm{d}\phi$ 与被积的 $\cos\theta$ 凑成 $\mu\,\mathrm{d}\mu$（差一个符号，翻转积分限即可），$\mu$ 从 0 到 1。这个值介于 0 和 1 之间，且跟观察方向有关——固定不同观察方向积出的值很有可能不一样。

    * 单次弹射没考虑到、被遮挡掉的能量立刻得出：一定是 $1 - E(\mu_o)$。

    * 第二步设计补能量的 BRDF：要保证可逆性（reciprocity——交换输入、输出方向结果一样），所以写了一项 $1-E(\omega_o)$ 就要按对称性配上 $1-E(\omega_i)$，两个因子乘起来再乘归一化量 $c$，让整个积分最终等于多次反射造成的能量损失：

    $$f_{ms}(\omega_i,\omega_o) = \frac{\bigl(1 - E(\omega_o)\bigr)\bigl(1 - E(\omega_i)\bigr)}{\pi\,\bigl(1 - E_{avg}\bigr)}$$

    * 其中 $E_{avg}$ 是 $E$ 在 $\mu$ 上再做一次加权平均（乘上 $\mu$ 积分、除以权重的空积分）得到的数：

    $$E_{avg} = 2\int_0^1 E(\mu)\,\mu\,\mathrm{d}\mu$$

    * 验证只要一行：中间用上恒等式 $\int_0^1 (1-E(\mu))\,\mu\,\mathrm{d}\mu = \frac{1-E_{avg}}{2}$，把 $f_{ms}$ 对入射半球积出来正好是 $1-E(\omega_o)$——丢掉的那部分能量；它加上原来的能量，能量守恒。

### 预计算打表

* **预计算表**

    * 为什么打表：$E$ 本身已是一个二重积分，$E_{avg}$ 还要在 $\mu$ 上再积一次，现场算非常难，而最后要的其实只是一个数；与 split sum 同一第一反应——对一个很复杂、不知道有没有解析解的积分做预计算或打表。

    * $E$ 只依赖两个数：观测方向 $\mu_o$，以及 roughness（BRDF 本身太复杂，但用的哪个 BRDF 模型自己知道，用 roughness 描述它/NDF 就够了）——对 $(\mu, \text{roughness})$ 的不同组合各自预计算出一个积分值，打成一张二维表，问题解决。

    * 可视化里的那张热力图不要当成普通的图——它就是打的表本身（为算出损失能量而预计算），跟要补的那项多次弹射 BRDF 一点关系都没有。

| | split sum 的预计算图 | Kulla-Conty 的预计算表 |
| :--- | :--- | :--- |
| 共同点 | 都是二维表 | 都是二维表 |
| 算的是什么 | 环境光下该怎样对物体做 shading | 一次弹射能出去多少能量 $E$ |
| 与多次散射的关系 | 没考虑单次还是多次散射 | 专门补多次散射丢的能量，加在 BRDF 上 |

    * > **易错点** ⚠️：这张表不跨 BRDF 通用——不同的 BRDF 就算 roughness 相同，算出来的 $E_{avg}$ 也不是一回事，表自然不一样；也别跟 split sum 的预计算图混为一谈（上表）。

    * 实时渲染真的会算这个多次弹射：Kulla-Conty 就是让实时用的——BRDF 公式不过加了一项，没有任何需要现场计算的东西，唯一要预计算的一张表已打好；就算给一个点光源照亮相对粗糙的微表面材质，仍会损失能量、仍能通过这种方式补上。

    * 效果：补回去后那排球不再异常变暗；左边（低 roughness）补得少——多次反射的能量在总 BRDF 里占比小，不补没关系；右边粗糙表面很大一部分能量要经过多次反射才能离开物体表面，补上之后才算得对。

### 颜色项

* **把颜色加回去**

    * 颜色意味着吸收：能看到颜色就是因为有一部分光被吸收了；吸收是"该损失"的材质属性，但颜色毕竟意味着额外的能量损失——从一开始积分 $E$ 就得不到 1，问题变得更困难。

    * 拆分思想：先考虑没有颜色的情况，按前面的方法把整个能量算对；然后再单独考虑由于颜色的吸收造成的额外能量损失，算出最终要乘上去的颜色。

    * 平均菲涅尔项 $F_{avg}$：不管入射角多大，平均每一次反射有百分之多少的能量被反射掉——把 Fresnel 乘上 $\cos$ 在球面上积分、除以空积分；对有颜色的物体，这个值小于 1：

    $$F_{avg} = \frac{\displaystyle\int_0^1 F(\mu)\,\mu\,\mathrm{d}\mu}{\displaystyle\int_0^1 \mu\,\mathrm{d}\mu}$$

    * 能量分类的关键：**能出去的能量就不会参与到后续的多次弹射中；只有出不去的那部分（$1-E_{avg}$）才参与到后续更多 bounce 中间**。直接能看到的能量是 $F_{avg}\cdot E_{avg}$；每多弹一次，能量多乘一个 $F_{avg}(1-E_{avg})$，最后出去的那一次再乘 $F_{avg}E_{avg}$：

    ```text
    一束光入射
      └─ 反射（平均反射掉 F_avg）
           ├─ 出表面（占 E_avg）──────────────────> 直接看到: F_avg·E_avg
           └─ 没出去（占 1-E_avg）→ 再次反射（F_avg）
                ├─ 出表面（占 E_avg）────────────> 弹两次看到: F_avg·(1-E_avg)·F_avg·E_avg
                └─ 没出去（占 1-E_avg）→ 再反射 → ……
                     前 k 次都没出去、最后一次反射后出去:
                     [F_avg·(1-E_avg)]^k · F_avg·E_avg
    ```

    * 把 $k$ 从 0 到无穷的所有可能性加起来（等比级数求和），得到经典的**颜色项**：

    $$\sum_{k=0}^{\infty} F_{avg}E_{avg}\bigl[F_{avg}(1-E_{avg})\bigr]^k = \frac{F_{avg}E_{avg}}{1 - F_{avg}(1-E_{avg})}$$

    * 把这个颜色项乘到前面不带颜色的多次弹射 BRDF 上，就得到最终结果；这些都是 RGB 三维向量，通道与通道之间单独算。

    * 效果：金属本身有颜色、roughness 大的情况下本会异常变暗；补上之后看起来没有能量损失、整体仍是黄的——剩下的能量损失都是它该有的（材质本身的吸收），而不是没考虑多次反射造成的。

    * > **提示**：推导的复杂程度和使用的复杂程度完全是两码事——用起来非常简单，最后就是在原本单次弹射的 BRDF 基础上再加一个多次弹射的 BRDF；它绝对是一个 hack（不是从物理式子推出来的、也没有真的让光线在微表面中间弹射），但"把能量补上"的目的达成了，基本上很接近物理，图形学上可以接受。

## 微表面与 diffuse 的关系

* **反模式：diffuse 加 microfacet**

    * 做法：看 microfacet BRDF（特别是 roughness 大的情况下）有点偏暗，就不管能量损失、直接加上一个 diffuse——即常见的"经典"写法，计算机视觉里为识别材质属性用得特别多。

    * 为什么错：微表面模型本来就把物体解释成微表面，分布既然是某种分布、就已经在模型里面考虑了，哪来的 diffuse？如果这个表面又是 microfacet 又是 diffuse，那它算什么——解释不了。

    * 两条硬伤：第一，这样做没有任何物理依据；第二，绝对保证不了能量守恒——保证不了能量守恒，就会搞出一些会发光的 BRDF，之后再去全局光照就会暴露。

    * 与 Kulla-Conty 一对比更清楚：能量损失对不同角度是不一样的、对不同 roughness 也不一样，加一个固定的 diffuse 非常不合理；Kulla-Conty 才是准确的做法。

    * 退一步说：如果有办法让你简单地加一个 diffuse、并且还能保证能量守恒，那就不错、可以接受——这是有人在做的，只不过这些方法当时还没有被发表出来。

* **microfacet 能否表示 diffuse**

    * 可以：只要把表面设计得足够粗糙，同时又考虑 multiple bounces（多次弹射，即 Kulla-Conty 那套能量补偿），这种情况下的结果已经非常像 diffuse 表面了。

    * 最原始的、只算一次 bounce 的 microfacet 不行。

## LTC：多边形光源下的解析着色

### 问题定位

* **线性变换余弦（Linearly Transformed Cosines，LTC）**

    * > **定义**：解决"用一个多边形光源去照亮某一个点、这个点是微表面模型的 BRDF，得出的 shading 结果（没有阴影的那种）是什么"的方法——不需要采样，给光源立刻就能算出来。

| | Split Sum | LTC |
| :--- | :--- | :--- |
| 面对的光源 | 环境光 | 多边形（面）光源 |
| 基本思路 | 把环境光预处理、拆开，提前算 | 把 BRDF lobe 线性变换成余弦，光源跟着一起变 |

    * 它跟 split sum 是两码事：split sum 做环境光下的 shading（预处理、拆出来提前处理掉）；LTC 解决的是多边形面光源这另一回事。

    * 没有 LTC 的做法：在多边形光源上取很多采样点、跟当前 shading point 连线；不考虑连线中间会不会与场景相交就不算阴影，要阴影再做一次 shadow test——不管怎么样都需要采样。

    * 适用范围有限制：基本上，凡是能用所谓 lobe——那种光滑的、往外衰减的简单形状——描述的 BRDF 按说都可以；论文发表时主要针对 GGX 这一种法线分布，Beckmann 或别的分布原理上也可以。

    * 它不管阴影：只考虑 shading；放一个物体正好挡住星形光源一半这种情况它就吃不消。后续有工作先算 shading、再单独算 shadow（类似 shadow map 那种做法，不过是采样的），意义就没那么大了。

### 核心思想

* **lobe（瓣）**

    * > **定义**：BRDF 本来是输入、输出两个方向的四维函数（输入两维、输出两维）；固定了观察方向，剩下的反射分布画出来是花瓣一样的一个形状，就叫 lobe——严格定义是 BRDF 的二维切片（2D slice）。

    * > **易错点**：花瓣形状看着像三维，其实是二维——固定输入的两维，输出当然是两维的，画出来才呈那个花瓣的形状。

* **把 lobe 变成余弦**

    * 核心想法非常简单：BRDF lobe 可以通过某一种线性变换，变成朝上的、正中间多两边少的余弦函数的形状。

    * 变换必须对**所有的方向**做同一个变换：球面上任何一个方向 $\omega_i$ 都变成 $\omega_i'$——多边形光源所覆盖的那些方向也跟着变，四边形光源的四个顶点方向变成新的四个方向，围出一个变形了的多边形光源。

    * 等价关系：**用变形后的面积光源去照亮"余弦"，就相当于用原来的面积光源照亮原来的 BRDF**——一回事，积分结果不变。

    * 好处：原本"任意 BRDF × 任意光源在光源覆盖立体角内做渲染方程的积分"不知道结果、不好算；变换之后 BRDF 那一项固定成 cos，多边形光源变换后还是多边形光源——问题变成"固定 cos 下对任意多边形光源积分"，而这个积分有解析解，套公式直接出结果。

    * 假设：多边形光源内部是 uniform 的——它发出来的光一样、对这个点的 radiance 是同一个数（光源上不同位置发出不同光的情况论文后来有办法解决，这里先按均匀假设）。

    ```text
    任意 BRDF lobe（斜着的花瓣） ----> 余弦 lobe（朝上，中间高、两边低）
    多边形光源 P 的各顶点方向   ----> 新的顶点方向，围出变形后的光源 P'
    等价：用变形光源 P' 照亮余弦 == 用原光源 P 照亮原 BRDF（积分结果不变）
    ```

### 变量替换推导

* **推导步骤**

    * 起点：$L_i$ 是同一个数、可以提到渲染方程外面；把 BRDF 和 cos 合在一块记作通用函数 $F(\omega_i)=f_r(\omega_i,\omega_o)\cos\theta_i$，$P$ 是多边形光源覆盖的立体角区域：

    $$L_o(\omega_o)=L_i\int_P f_r(\omega_i,\omega_o)\cos\theta_i\,\mathrm{d}\omega_i=L_i\int_P F(\omega_i)\,\mathrm{d}\omega_i$$

    * 记号约定：任何的 cos 都可以通过 $M$ 变换成这个 BRDF lobe；反过来说，lobe 经过 $M$ 的逆变换 $M^{-1}$ 就变成 cos（一回事，只是记号问题）。

    * 方向上做线性变换，单位球面上的点变换后不能保证还在单位球面上（长度会变），要归一化才是方向：

    $$\omega_i=\frac{M\,\omega_i'}{\lVert M\,\omega_i'\rVert}$$

    * > **易错点**：方向不要弄反——原本的 BRDF 是经过 $M^{-1}$ 变成余弦的；也就是说，新的方向经过 $M$ 再归一化，会变回原来的方向 $\omega_i$。

    * 变量替换后积分要对 $\mathrm{d}\omega_i'$ 才好解，把 $\mathrm{d}\omega_i$ 写成 $\mathrm{d}\omega_i'$ 要引入雅可比（Jacobian）行列式 $\lvert J\rvert$：

    $$L_o=L_i\int_{P'}\cos\theta_i'\,\lvert J\rvert\,\mathrm{d}\omega_i'$$

    * $P'$ 是原多边形 $P$ 的各顶点方向经过同一变换之后围出来的新区域，$\theta_i'$ 是新方向的极角；得到的就是一个对 cos 的积分——可以直接解出来。

    * 整个方法本质上只做了一次变量替换：任意 BRDF 被换到 cos，同时光源覆盖的区域一起变换；等价于用一个多边形光源去照亮一个 cos 的材质，而这个积分有解析解。

### 预计算与边界

* **矩阵 M 的来源**

    * 不同观察方向看出射的 lobe 肯定长得不一样——每一种可能的 lobe 都得有一个变换到 cos 的矩阵；论文的做法是**预计算**：对一些常见的 BRDF、从不同的位置看过去，提前把这些"lobe 转 cos"的矩阵都算出来，运行时直接拿来用。

    * M 本身怎么算：最简单的办法是不用解析地算，而是通过优化方法来算——随便给一个初始值，通过优化让变换的结果对上最后要的那个 cos。

* **效果与几条边界**

    * 效果非常不错；多边形不要求是凸的——星形这种肯定可以做；游戏里那些大型的面光源，可以非常快地算出任何一个点对应的 shading。

    * 光源不均匀（内部本身有图案或贴了纹理、不同方向的 $L_i$ 不一样）时，LTC 就不是一个准确的解了——但还是一个不错的近似。

    * 各向异性的表面可以用：一根光线打进去，不同的入射方位角对应不同的 BRDF；但给定一个观察方向，无论如何还是对应一种形状的 BRDF lobe（可能长得像椭圆），把这种形状映射到 cos 上就可以了。

    * 离线渲染可以用它代替采样面积光，但没必要：离线里其他地方都在做光线追踪，非要把这一块省了没什么意义；LTC 的价值在实时渲染——解析解（最后能推出一个公式、套公式得出结果，不用数值地去解），非常快。

    * cos 不是一维的吗：cos 本质上是在球面上仅依赖 $\theta$、不依赖 $\varphi$ 的函数；仍可以把它显示在球面上、当成一个 2D 函数来看。

    * LTC 是 Unity Research 的工作，得到了广泛的采用，大家都觉得是非常不错的工作。

## 迪士尼原则 BRDF

### 为什么需要它

* **微表面模型表示不了真实材质**

    * 微表面模型很强（补上 diffuse 短板、连多次散射都没问题），但并不擅长表示真实的材质：拿实测出来的物体表面 BRDF 看，找不到什么微表面模型的参数能对应得上——fit 不了实测数据。

    * 典型例子——刷了清漆的木头桌子：木头各个位置有不同 diffuse albedo 但都可按 diffuse 理解；刷一层清漆（有一定厚度、本身不吸收光、没颜色）后，光被劈成两路——又有一个明显的高光，底下又是明显的 diffuse；微表面模型绝对解释不了，顶多解释其中一层。

    ```text
    入射光
      |-- 一部分：在平坦的清漆上表面被直接反射（菲涅尔）--> 形成明显的高光
      `-- 另一部分：折射进入清漆层（清漆无色、不吸光）
            |-- 往下走，最终碰到木头
            `-- 在木头里以 diffuse 方式向外走出 --> 明显的 diffuse 底色
    ```

    * 如果微表面可以较好地描述一层材质，把这些材质互相叠起来会产生完全不同的新材质；世界上的真实材质千变万化——微表面模型表示不了所有的东西。

* **物理量对艺术家不友好**

    * PBR 材质的参数正常都是跟物理量相关的东西：金属的折射率得理解成复数 $n-ik$——要有 $n$ 和 $k$ 两个数才能定义；艺术家不知道 $n$ 是什么、$k$ 是什么、调起来有什么范围，乱调可能出现非常严重的后果——毁灭性打击。

    * artist friendly（对艺术家友好）非常重要：能提升艺术家快速生成场景、调出各种材质的速度——在工业界这直接是一个省钱的过程，有实际意义。

### 设计原则与十个参数

* **迪士尼原则 BRDF（Disney principled BRDF）**

    * > **定义**：迪士尼为"艺术家可以直接指挥（art directable）"而设计的 BRDF；它并不要求在物理上正确，只在一定程度上保证物理正确性——实时渲染本来就不讲究完全物理，大家基本还认为它是 physically based 的。

    * 原则一，直观而不是物理：不应该用物理的量，应该用艺术家挂在嘴边的直接量（"我希望它看起来更平一些""哪个地方看起来更饱和一些"）。

    * 原则二，参数越少越好：不希望 BRDF 框架变得复杂麻烦，能少一个参数就少一个。

    * 原则三，参数从 0 到 1：给艺术家一个拖动条——最左最小、最右最大；对应的物理意义可能是从 0 到 0.005 这种东西，但为了方便就是一个 zero to one；为营造特殊效果允许把范围推到小于 0 或大于 1（艺术家认为有必要时）。

    * 原则四，怎么调都不崩：不能某一种参数跟另一个参数组合到某种情况就程序崩溃或结果难看；所有参数组合在一起都应得出靠得住的结果。

    * 它的公式非常复杂，很多情况下建立在拟合方法上、是经验性模型；有开放的源代码，想用直接拿去用。

    * 参数表展示各参数从 0 到 1 能做出来的效果，但仍不是模型能表示的全部——很多不同的效果还可以叠在一块；这些参数已经不是基于物理的参数，全部从 0 拖到 1。

| 参数 | 调到 0 | 调到 1 | 它管什么 |
| :--- | :--- | :--- | :--- |
| subsurface | 普通 diffuse | 比 diffuse 还平 | 次表面散射的 BRDF 近似 |
| metallic | 最不像金属（塑料球） | 最像金属（金属球） | 金属性 |
| specular | 没有镜面反射，只剩 diffuse | 镜面反射拉满 | 相当于布林-冯（Blinn-Phong）模型里的 $k_s$ |
| specularTint | 高光无色 | 高光染上底材的颜色 | 镜面反射项的颜色 |
| roughness | 完全光滑（全是镜面） | 完全粗糙（没有镜面） | 粗糙程度，和 Beckmann 一致 |
| anisotropic | 完全各向同性 | 完全各向异性 | 各向异性程度（"像刷过一样"） |
| sheen | 没有绒毛 | 绒毛拉满，掠射角泛白起雾 | 表面沿法线长的绒毛层 |
| sheenTint | 绒毛效果偏白 | 偏向底材的颜色 | 绒毛效果的染色 |
| clearcoat | 没有清漆层 | 清漆层效果最大 | 透明涂层（糖衣） |
| clearcoatGloss | 清漆表面坑坑洼洼（磨砂） | 清漆表面是镜面 | 清漆层的光滑程度 |

* **参数解读**

    * subsurface（次表面散射）：光线能进入物体、并从另外一个地方打出去；表述成 BRDF 就是对次表面散射的近似——能给出比 diffuse 还要平的效果，好像球被按扁了（diffuse 是法线冲向光源的地方最亮、往两边逐渐衰减）。

    * specular：控制有多少镜面反射的内容，相当于布林-冯模型里的 $k_s$；specularTint 规定镜面反射项反映的颜色——是无色的镜面反射，还是偏向底材规定的物体颜色（之前 $k_s$ 只当一个数，这里相当于给镜面反射上了颜色；tint 是工业界常用的"规定一个颜色"的概念）。

    * roughness：跟 Beckmann 那套完全一样、没有任何区别，就是粗糙程度——最不粗糙时一切可镜面反射，最粗糙时没有任何镜面反射。

    * anisotropic：材质的各向异性程度，从完全各向同性到完全各向异性——像刷过一样的那种效果。

    * sheen：非常重要的概念，动画、实时渲染、离线渲染都非常有用——即天鹅绒（velvet）的思路：表面本身沿法线方向长出一层绒毛，最明显的效果是在掠射角上看起来像有雾化效果（从侧面看，物体外一圈泛白）。

    * sheenTint：与 sheen 配套——这层绒毛造成的效果是偏白还是偏向底材定义的颜色。

    * clearcoat 与 clearcoatGloss：透明涂层（coat，跟糖衣一样）及清漆层的光滑程度——gloss 是反过来的粗糙程度；清漆上层表面是镜面还是坑坑洼洼的磨砂，决定观感。

    * > **提示**：这些参数是设计来一块儿共同运作、混着用的——sheenTint 一行展示的本身就是"先把 sheen 调到最大、再调 sheenTint 是 0 还是 1"的效果。

### 优劣与适用性

* **参数空间（parameter space）**

    * > **定义**：所有参数各自取不同的值得到结果所张成的空间；参数空间的维度就是参数的个数——这里是十维。

    * 参数空间越大越容易造成冗余：不同的参数组合可能给出基本上相同的结果——类比优化问题里不希望最优值陷入某个 local 最小值，各个 local 范围内参数的不同组合可能已给出差不多的结果。

* **好处**

    * 设计来就是让人能看懂这些参数是干什么的、方便控制——达到 artist friendly；参数组合非常强大，可以用一个模型描述很多很多不同类型的材质。

    * 参数空间大、表示能力强：近几年很多人改用迪士尼这套模型去分析场景中的材质（分析出来的就是迪士尼这些材质参数）或拿去做训练——此前用 microfacet+diffuse 当正向模型（forward model）是"不是办法的办法"（只算一次 bounce、不加 diffuse 的 microfacet 很难 fit 真实场景里的物体）；迪士尼的大参数空间更容易表示实际物体的材质。

* **坏处**

    * 实现非常复杂；实践更多是通过拟合一些 PBR 材质得来的（具体怎么做要花费的时间实在太多）；好在开源的实现到处都是，随便搜一下就是。

* **不基于物理要紧吗**

    * 它牺牲了一些物理准确性（已经没有那些物理参数了），但它拟合的就是能量守恒的模型——不考虑拟合误差的话，本身好像就是能量守恒的；实时渲染本来就不怎么讲究完全物理（VSSM 里那些聪明但不严谨的做法同理）。

    * 学术界与工业界的差别：学术界做 light transport 的文章，要求结果是 unbiased 的（期望上与真实结果、与 path tracing 一样）；而工业界大家都在做 denoise，一做降噪无偏性质就破坏了——不必拿"不是基于物理"这个性质来否定这个非常好的模型。

* **游戏引擎为什么不用**

    * LTC 是针对微表面模型的；split sum 做 shading 时把 Fresnel 项拆成"基础反射率 $F_0$ 加一个简单的过渡曲线"，也建立在 $F\cdot G\cdot D$ 除以归一化常数的微表面结构上——迪士尼没这回事，之前那些东西就全都没办法拿来用了，整套得重新算。

    * 参数空间这么大、公式真写出来会非常麻烦，计算起来肯定比较费——所以它不太适用于实时渲染。

## 非真实感渲染 NPR

### 定位与真实感根基

* **非真实感渲染（non-photorealistic rendering，NPR）**

    * > **定义**：在**快速（fast）**与**可靠（reliable）**两点都做到的基础上做的风格化（stylization）——原神、塞尔达这类把渲染结果做成卡通风格的渲染；photorealistic 是 photo+realistic 造出的词，"像照片一样真实"，non-photorealistic 即"非真实感"。

    * 各种基于神经网络的风格化方法（StyleGAN 这一类）没被用到实时渲染里，就是因为它们或多或少不能满足 fast 和 reliable 两者之一，甚至两种都不满足。

    * 因此 NPR 一定是一种轻量级的解决方式：正常情况下就是在 shader 里做一些简单的、但看起来很聪明的处理，把风格化做好。

* **真实感是 NPR 的出发点**

    * photorealistic 是真实感图形渲染的最高境界：渲染结果跟真实照片分不开——要正确的光照、正确的阴影、正确的材质……所有东西集合在一块才叫真实感。

    * 人的皮肤这类渲染已经可以做到极致：一张从正中间划竖线、一半真实照片一半渲染结果的对比图广为流传，后来连作者（UCSD 的 Henrik Wann Jensen，光子映射 photon mapping 与 BSSRDF——次表面散射——的发明者）本人都记不得哪一半是渲染的，这个问题永远不可能得到回答了。

    * 虚幻引擎 4 最近放出了整套人脸编辑系统，还是不错的，但仍很难说能以假乱真——真实感的成果用在实时渲染中间涉及各种简化。

    * NPR 的研究思路通常从真实的渲染出发：先拿到一个真实感渲染的结果，然后通过观察决定在哪些地方做什么样的变化——哪些地方强调、哪些地方简化，把它变成 NPR 的效果；**NPR 和真实感渲染绝对不应该分开来看**。

### 应用与风格化要素

* **应用面**

    * 艺术：艺术家画的东西显然不是现在各种着色模型做出来的。

    * 可视化：NPR 渲染的爪子该有高光有高光、外面轮廓描一圈，看得非常清楚。

    * 说明与指示：各种工程图和说明书（很多说明书上的示意图是拿正交投影画的，为了让人看得清楚）；发动机里冷热两部分混合的示意图这类，NPR 有时比真实的 photorealistic 渲染更能看清楚问题。

    * 教育：小朋友的画大量色块、非常有自己的风格，但能很明确地看出在干什么。

    * 娱乐：Pixar 的《汽车总动员》（Cars）——第一部用光线追踪做的动画——和各种后续，车子高度风格化。

    * 跟实时渲染最接近的应用在游戏和动漫：游戏如原神、塞尔达、《莱莎的炼金工房 2》（人物是 3D、有自己的着色与光照，但用的不是真实感那套——皮肤不是皮肤的着色，是卡通的皮肤）；动漫如今几乎全部是"渲染 + 一部分人工工作"协同做出来的（《进击的巨人》第四季：风格化的点光源照亮与投影是 NPR，但它仍保留了很多与 photorealistic 相关的东西——脸的右半没有直接接收光照却有别处过来的光、下颚投影到脖子上）。

* **从游戏画面反推风格化要素**

    * 《异度之刃 2》同一位女主（焰与光）能观察到：头发有一圈很明显"描"出来的效果；草整个是一块一块的、不像真实草叶根根分明；头发整个像带有渐变的一块色块，很多东西被简化掉了；颜色上更多考虑平滑过渡、不是平常 shading 那么夸张；向光那块整个很平整、背光那块暗很多，中间有一条比较明显的分界线但有点糊。

    * 美式风格（无主之地）：人物肢体旁边有各种各样的边缘；大量应用色块；在人物不同位置上打各种各样的线（排线）。

    * 动手前基本思路要立住：把"我要看到的这种效果"转换成"我要在渲染中做哪些操作"——"给人物描边"这种说法笼统且不科学，得分析这个边缘在渲染中到底意味着什么、什么是边缘、怎么找到、怎么在它外面加粗；NPR 里做任何一种效果都要经过这样的分析，分析得好结果才能做得更好。

## 描边：边的类型与实现路线

* **边的四种类型**

    * > **定义**：要对物体描边，就得先定义什么是边；这个分类看图观察就能得到，跟图形学没什么关系、顶多跟几何沾一点边——但先有了这个研究，后面才能做描边。

| 标记 | 名称 | 判定 | 例子 |
| :---: | :--- | :--- | :--- |
| B | boundary / border（边界） | 只属于一个面、不被其他面共享的边 | 打开的盖子最外圈那条边 |
| C | crease（折痕） | 两个面弯折相连的地方，不一定在物体外边界上 | 盖子的折线、盒身的折线 |
| M | material boundary（材质边界） | 两种不同材质之间的分界，描不描取决于风格 | 条纹材质与两侧正弦纹理材质的交界 |
| S | silhouette（轮廓边） | 在物体外一圈轮廓上，并且由多个面共享 | 盒身前面与后面共享的那条竖线 |

    * silhouette 的定义非常细致：第一，得在物体的外面一圈轮廓上——物体中间的肯定不是；第二，得是**由多个面共享**的边——盒身那条竖线由前、后两个面共享，是 S；盖子打开后最外圈那条边只属于盖子自己的一个面（正反两面算同一个面）、不被其他面共享，记 B 不记 S。

    * 盒身中间那条折线是 C 不是 S：它确实是两个面共享，但并不出现在物体本身的外边界上；S 可以理解为 C 的子集——折痕既然这么定义至少得连接两个面，只不过折痕还可能出现在物体中间；也可以这样理解 S：它首先得是 C，另外在图上它一边是这个物体、另一边是另外一个物体。

* **路线一：用 shading 找 grazing angle**

    * 前提：物体几乎所有部件都是封闭的——所谓 watertight（密不透风）；先不想打开盖子那种情况。

    * 聪明的观察：silhouette 边对应两个面——一个面被你看到、另一个面不被你看到，才会在侧面形成这条边；shading 时沿面往上走，面会渐渐变得跟视线相平——观察方向和它的法线几乎垂直（$n\cdot v\approx 0$，夹角接近 90°）的点就在 silhouette 边上，这种掠射（grazing angle）的地方基本上就是轮廓边。

    * 实现：渲染时判断观察方向与 shading normal 的夹角，设一个阈值，接近 90° 就认为在轮廓边上、把这点点成黑；阈值不同效果不同——夹角超过 60° 就算边缘的话容忍度高、更多点被认为是边缘、结果更粗。

    * 阈值化（thresholding）：对一维函数应用阶跃函数（step function）——超过某个值就是 1、小于就是 0；如果用的不是严格的 step 而是类似 sigmoid 形状的 smoothstep，就可以做出过渡带的效果。

    * 问题：不同位置描出来的边粗细不一样——判断的是两个角度的关系，并没有在图像上给它固定粗细；法线变化平缓的地方边粗、尖锐的地方边细，这种简单处理可能并不好。

* **路线二：把背面往外扩一圈**

    * 朴素想法：做一个比原模型稍微大一点点的模型，放在原模型背后渲染成黑的——直接做出描边效果。

    * 更聪明的实现：渲染物体时知道哪些面正向着你、哪些面背向着你；物体是 watertight 的，背后一定有一个能覆盖同样区域的背面——把所有背面的面每一个往外扩一圈（背面渲染出来的三角形都会大一些），并把背面渲染的结果直接指定成黑的；从正面看，露出在物体轮廓外面的就是背面扩出来的那圈黑边——不需要再造一个新模型。

    * 优化空间：三角形一扩会多出一个角，可以切掉或做成圆角过渡；扩的方式可以选任何一条边往外扩一个固定距离，或者让背面的面沿顶点的法线往外扩一圈——后者能保证更均匀的外面一圈。

    * 这是几何层面做的事情，工业界基本上都在用，挺容易的。

* **路线三：在图像上做后期处理**

    * 思路：先生成没有描边的正常渲染结果，再通过后期图像处理在图像上找边缘、把边缘标上颜色；英雄联盟的技术文档说过他们就是这么做的。

    * 图上找边退化为"给你一张图，怎么把边界找出来"的经典问题，经典方法是 Sobel detector（注意与随机数序列的 Sobol（-bol）完全是两个事情，别搞混）。

    * Sobel kernel（3×3 加权平均 filter）：

    ```text
    +1    0    -1
    +2    0    -2
    +1    0    -1
    ```

    * 读 kernel：左边一列全正、右边一列全负、中间一列全零，中间一行的权重放大到 2，方向性明显——竖着基本没变化、横着变化非常强烈；一个点周围 3×3 很平滑（极端情况值全一样）时，1 跟 -1 抵、2 跟 -2 抵，结果是零；刚好有一条竖线（缝左侧白、右侧黑）时，白的大值乘正权重、黑的小值乘负权重，差被进一步拉大——竖线被提取出来。

    * kernel 换一个方向就能提取另一个方向（水平方向）的边缘；两者自然结合，图像中所有边缘就都找到了。

    * 与早期图像处理的锐化（sharpen）是同一个道理：模糊是把图像变糊，锐化是先找到边界（高频的东西）再把它们加回原图、强调边界——这里是找到边界之后描上颜色、加回原来的图像。

    * 快得惊人：任何一个点应用一个 3×3 的 filter。

    * 没有必要只在最后的渲染图上找边界：渲染过程有很多辅助信息（法线图、深度图等各种图像空间信息）都可以给找边提供指导——鞋上的褶皱对深度来说显然不是边界，对法线来说却明显是边界；综合在一块考虑不会漏掉边界，还能让结果更干净（具体怎么综合不展开）。

* **三条路线汇总**

| 路线 | 核心做法 | 特点 |
| :--- | :--- | :--- |
| shading 判定 | 视线与法线夹角接近 90° 即涂黑，配合阈值 / smoothstep | 快；但线条粗细随法线变化快慢而变，无法保证均匀 |
| 几何外扩 | 背面三角形整体外扩一圈、渲成黑色，正面盖住中间 | 不需要新模型；工业界普遍采用 |
| 图像后处理 | 正常渲染后用 Sobel 等找边缘并上色，可结合法线、深度图 | 灵活；英雄联盟技术文档声称采用此路 |

## 色块与素描风格

* **色块：阈值化与量化**

    * 想要大量色块而非平滑过渡：对正常 shading model 算出来的结果做阈值化——比如高光的能量超过了某个值（如 1.5）就认为它所有的值都是这个值；不超过这个值的取另外一种值（注意不是零，本来就是零的地方当然还是零）——高光是非常明显的一块、非高光的 diffuse 区域是另一块颜色、照不到的地方完全黑。

    * 在哪里做都行：可以在 shading 的过程中、中间算出什么值就直接做；也可以等最后生成了结果图、不管中间做了什么其他处理之后在图像上做——一样没有关系。

    * 阈值化可以不是二值化，多级的叫量化（quantization）：颜色本来是连续的，平时量化到 0~255 共 256 个级别；这里做得更狠——比如 0 到 10 连续变化的数，0~1 对应一种颜色、1~5 对应另一种、5~10 又是另一种；壶的 diffuse shading 结果、水果图都按值所处范围给不同颜色。

    * 更进一步，不同的部分可以应用不同的阈值化或量化方法：可以只把 diffuse 给风格化（diffuse 的颜色分成几个色块、specular 该怎么做怎么做）；也可以 diffuse 不做、specular 做；还可以决定不同的地方到底要不要描边——不同类型的渲染结果自由组合。

    * 这个事情挺不严谨、想怎么操作就怎么操作——因为 NPR 首先是 artist driven：为了营造艺术感，不要求算的东西到底对还是不对。

* **素描：用排线密度画明暗**

    * 做素描效果先问"素描是什么"：基本思想是通过打格子（排线）用格子的密度营造明暗——暗的地方（如手心）很多横线竖线挤在一个很小的范围里、密度大、看起来偏黑；过渡带格子密度中等；很亮的地方根本不打格子。

    * 要做的事：把每个点表示的明暗程度反着转换成"如果要素描应该给什么密度"，并希望每一个点单独进行操作。

    * 还要保证笔触连续的感觉：不能让每个点孤立计算——先设计一组本身笔触就连续、有着不同密度的纹理（单一方向的可以，带两个方向的也行，稀疏的设计成两方向也没关系）；根据每个 shading point 最后算出的明暗，决定在哪一个纹理上去找。

    * 纹理本身定义在物体表面上：表面挨得比较近、颜色又差不多的两点，就会在纹理上相距比较近的地方去找——保证了一定的笔触连续性；相邻点之间存在密度过渡时，相当于在这一张图这个位置找、下一张图在旁边一个位置找，也挺连续。

    * > **易错点** ⚠️：画素描跟实际渲染的重大区别——不管物体离多远多近，笔触密度只应跟 shading 最后的结果有关；如果只用同一组纹理渲染，物体往远处推时 texture 贴在物体表面、跟着 UV 被缩小，图变小密度就变，会显得越来越暗——这不是想要的。

    * 解决办法：做 mipmap——对每一种固定密度的图都做一份**把图像缩小的同时并不改变它的密度**的 mipmap；不管离多远，查对应 mipmap 层级上对应的位置，仍然得到相同的格子密度，素描风格的效果就做出来了。

    * 素描纹理能不能用 procedural（程序化纹理生成）：行，暂时思考不到什么问题；但程序化的生成方式往往不太好控制——生成简单的 pattern 就行，复杂的 pattern 可能够呛。

    * 还有把各种纹理拼起来等各种各样的神奇操作，不再展开。

## NPR 的心法

* **心法**

    * 最困难的绝对不是最后用什么公式把效果实现出来（那是最简单的事情），而是一个**翻译过程**：艺术家希望做到什么效果 → 立刻反应出渲染过程中要操作哪些量——这才是最重要的分析、NPR 里最有趣的东西（例：想描边 → 总结出"shading 的时候，grazing angle 的那些地方就是边缘"这种聪明规律）。

    * 尽量不要想着抄别人的技术：这样有趣的分析过程自己解决多好，而且还有自己的风格——这样设计出来的东西各不相同。

    * 想做到一个什么效果，就多和 artist 交流，看能不能把它反映到渲染的过程中去——落到"要操作哪些量"上。

    * NPR 其实一定程度上就在做 if else：不只反映在阈值化那种层面（超过某个值怎么样、否则怎么样）；更多情况下——没有一种方法对任何一个场景都适用，每个场景可能需要不同的风格化方法，甚至是不同的角色、同一个角色身上不同的部位（见过专门设计人物鼻尖投影出来的影子、让它看起来更符合二次元要求的工作）——这是对的，艺术的种类千变万化，大量时间精力要花在这上面，但挺值、非常有趣。

    * NPR 做得好不好，一定程度上取决于 photorealistic 模型（NPR 之前的那个模型）做得好不好，并不是只在后期做这些 if else 的风格化就完事了——典型例子布料：布料的 BRDF 与微表面那套模型（GGX、Beckmann 这些）完全不一样，所以丝绸、天鹅绒这些东西给出的结果才不一样、特别是在高光上；先有一个准确的布料 BRDF 模型再去分析怎么风格化，结果会更准；一上来就当成 microfacet 渲染、指望通过后期处理做到风格化，可能就很难——NPR 本身是生活的抽象，也希望它一定程度上和生活中真实出现的东西有一定的相似程度，再加上抽象的成分。

    * **NPR 和 photorealistic 绝对不应该分开来看**；NPR 之后还有各种各样的东西（比如对全局光照做风格化），同样贯彻这一点。
