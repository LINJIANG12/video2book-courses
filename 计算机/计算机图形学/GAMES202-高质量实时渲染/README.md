# GAMES202：高质量实时渲染（14 讲）

GAMES202 是闫令琪的高质量实时渲染课：实时阴影、实时环境光照与预计算、实时全局光照、基于物理的实时着色、实时光线追踪与前沿展望。课程讨论的是「在 16 毫秒预算内怎么近似离线渲染的物理正确结果」。14 集整编为 5 册、6 篇主题笔记。

- **原视频**：[GAMES202-高质量实时渲染](https://www.bilibili.com/video/BV1YK4y1T7yY/) — Bilibili，BV1YK4y1T7yY
- **全 14 集**，已产出 5 册模块全书、6 篇复习笔记、28 份逐字稿
- **内容覆盖**：P03（Lecture3 Real-time Shadows） 因原视频无中文字幕暂未整编；其余分集与全 28 块完整成稿

## 怎么学
- **先复习 GAMES101 的渲染方程与 BRDF**，否则实时近似看不懂。
- **阴影部分抓 PCF/PCSS/VSSM 的演进**（本课缺 P03，可先看笔记 02 的整理）。
- **环境光照抓住预计算与球谐/PRT**。
- **实时 GI 对比 SSGI/RSM/LPV 等方案**。
- **实时光追理解降噪与采样预算**。
