# GAMES106：现代图形绘制流水线原理与实践（13 讲）

GAMES106 讲现代图形绘制流水线：多概率着色（multi-probability shading）、性能分析、几何处理与模型减面、纹理生成与压缩、着色器优化、LOD 技术与流水线新进展。课程把「一帧画面怎么从场景变成像素」按阶段拆开，并教你怎么定位性能瓶颈。13 集整编为 3 册、5 篇主题笔记。

- **原视频**：[GAMES106-现代图形绘制流水线原理与实践](https://www.bilibili.com/video/BV1Uo4y1J7ie/) — Bilibili，BV1Uo4y1J7ie
- **全 13 集**，已产出 3 册模块全书、5 篇复习笔记、17 份逐字稿
- 全 17 块已完整成稿

## 怎么学
- **先建立流水线全局图**：应用 → 几何 → 光栅 → 像素 → 输出。
- **多概率着色理解「按概率采样 + 重建」的思路**。
- **性能分析学会看 GPU 计数器**，定位瓶颈比盲目优化重要。
- **几何处理与减面配合工具练**。
- **纹理压缩与着色器优化按平台差异对照**。
