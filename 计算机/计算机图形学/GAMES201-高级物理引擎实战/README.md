## 怎么学
- **两种视角先分清**：拉格朗日（粒子）与欧拉（网格），后面都是它们的组合。
- **MPM 是课程核心**：粒子携材质量、网格算受力，把两边优点合起来。
- **有限元抓住「能量 → 力」与拓扑优化思路**。
- **高性能部分配合 Taichi 代码练**：并行循环、稀疏数据结构。
- **每讲代码自己跑一遍**，物理引擎是写出来的。
