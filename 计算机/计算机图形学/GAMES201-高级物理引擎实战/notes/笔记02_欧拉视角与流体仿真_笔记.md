# 欧拉视角与流体仿真

## 欧拉视角与材料导数

* **拉格朗日视角（Lagrangian view）**

    * > **定义**：采样点跟着材料一起移动，回答"我这一小包材料现在怎么样了"。

    * 粒子随波逐流、随材料在空间中移动，记录自己的位置和速度，也可以记录温度等其他属性。

    * 关键是 sensor（传感器）：可以把它想象成一个个小的流体粒子，随着流体或固体在空间中移动。

* **欧拉视角（Eulerian view）**

    * > **定义**：采样点在空间中完全不动，回答"材料正以什么速度穿过我这个点"。

    * 直观图景：在水里插很多根桩，桩永远不动，但每一根桩都知道自己周围的水流流速。

* **材料导数（material derivative）**

    * > **定义**：联系欧拉视角与拉格朗日视角的导数算子：$\frac{D}{Dt}=\frac{\partial}{\partial t}+\mathbf{u}\cdot\nabla$；符号用大写 D，不用偏微分 $\partial$ 或小写 d。

    * $\frac{\partial}{\partial t}$ 项是"欧拉分量"：采样点在空间中不动，物理量随时间变化的那部分。

    * $\mathbf{u}\cdot\nabla$ 项是移动带来的变化：物理场在空间中本来就有梯度 $\nabla$，材料以速度 $\mathbf{u}$ 移动，由移动带来的变化率就是这一项。

    * 温度计绑在粒子上的例子：$\frac{DT}{Dt}=\frac{\partial T}{\partial t}+\mathbf{u}\cdot\nabla T$——粒子不动温度也会变，粒子移动再带来另一份变化。

    * 别名很多：advective derivative、Lagrangian derivative、particle derivative；统一叫 material derivative 即可，名字太多反而容易混淆。

    * 对速度本身也能求：$\frac{Du_x}{Dt}=\frac{\partial u_x}{\partial t}+\mathbf{u}\cdot\nabla u_x$——速度的变化率里出现了速度自己，即速度的变化受速度影响。

## 不可压缩 N-S 方程与算子分裂

* **不可压 N-S 方程（Navier–Stokes equation）**

    * > **定义**：$\frac{D\mathbf{u}}{Dt}=-\frac{1}{\rho}\nabla p+\nu\nabla^2\mathbf{u}+\mathbf{g}$，说的是流体里一小包材料的速度对时间的导数有三个成分。

    * 压强梯度项 $-\frac{1}{\rho}\nabla p$：压强在空间分布不均匀时，压强差对这包材料产生力、使其加速。

    * 粘性项 $\nu\nabla^2\mathbf{u}$：图形学里一般直接忽略——希望流体越不"黏"越好，越不黏，各种涡旋等炫酷效果越突出。

    * 重力项 $\mathbf{g}$：处理非常简单，往往就是给速度场直接加一个 $\mathbf{g}$；去掉粘性项后，方程里真正要对付的只剩压强和重力。

* **不可压缩条件（incompressibility）**

    * > **定义**：速度场必须处处无散度：$\nabla\cdot\mathbf{u}=0$。

    * 判定逻辑：有散度意味着局部材料净流入或净流出，流体被压缩或延伸、密度发生变化，与不可压缩假设矛盾。

* **算子分裂（operator splitting）**

    * > **定义**：把一个关于时间的 PDE 拆成若干个部分，使每一个部分都非常简单。

    * 对流部分：把原方程右端项忽略，取 $\frac{D\mathbf{u}}{Dt}=0$，只考虑速度场的移动。

    * 外力部分：$\frac{\partial\mathbf{u}}{\partial t}=\mathbf{g}$，直接给速度场加重力加速度。

    * 投影部分：$\frac{\partial\mathbf{u}}{\partial t}=-\frac{1}{\rho}\nabla p$，同时附上 $\nabla\cdot\mathbf{u}=0$ 的约束。

* 一个时间步内速度场依次过三道手续，这就是求解不可压 N-S 方程的骨架：

```text
u(t) ──advection──► u* ──外力──► u** ──projection──► u(t+Δt)   （∇·u = 0）
```

* 三步各自的含义：

    * advection（对流）：通过当前速度场求出下一时间步速度场的初始版本 u*——不考虑外力与压强，只考虑速度场的移动。

    * 外力：在 u* 之上加外力，得到 u**。

    * projection（投影）：即使 u 本身无散，经过 advection 和外力的修改后 u** 可能产生散度，需要加一个压强的作用把散度抹平；这个压强不能随便取，必须满足"加上之后新速度场散度为零"。

## 网格数据结构与插值

* **均匀网格（regular grid）**

    * > **定义**：把空间分成均匀 cell 的表示方式——二维是正方形，三维是六面体。

    * 欧拉法不一定非用网格：三角网格、三维四面体网格、甚至"永远不动的粒子"都能搭一套欧拉法的方程，只是都更复杂；均匀网格是最简单的选择。

    * 最简单的存法是全部存在 cell 中心（横向、纵向都与 cell 左下角偏移 0.5 个 cell）：在 Taichi 里直接开 `ti.Vector`／`ti.f32` 的场，shape 与 cell 网格大小一模一样——一个 cell 对应一份压强或速度采样。

* **交错网格（staggered grid）**

    * > **定义**：把横向速度 $u$、纵向速度 $v$、压强 $p$ 存在 cell 不同位置的网格——$u$ 存竖边、$v$ 存横边、$p$ 仍存 cell 中心。

```text
      v       v       v       v
      +-------+-------+-------+
      |       |       |       |
      u   p   u   p   u   p   u
      |       |       |       |
      +-------+-------+-------+
      |       |       |       |
      u   p   u   p   u   p   u
      |       |       |       |
      +-------+-------+-------+
      |       |       |       |
      u   p   u   p   u   p   u
      |       |       |       |
      +-------+-------+-------+
      v       v       v       v

      u（横向速度）存竖边上  —— 4x3 个采样
      v（纵向速度）存横边上  —— 3x4 个采样
      p（压强）存 cell 中心 —— 3x3 个采样
```

    * 数量要点：$3\times3$ 的网格，$u$ 场是 $4\times3$ 的数组、$v$ 场是 $3\times4$ 的数组——每个方向只有 3 个格子却有 4 条边，是"植树问题"式的加一减一；压强不受影响。

    * 好处：做各种有限差分时优势明显，特别是能避免 checkerboard pattern（棋盘格模式）这一很坏的现象。

* **双线性插值（bilinear interpolation）**

    * > **定义**：已知正方形四个顶点上的值，用对角矩形面积做加权平均，重建正方形内任意一点的值。

```text
        +-------------+-------------+
        |             |             |
        |      A      |      B      |
        |             |             |
        +-------------+P------------+
        |             |             |
        |      C      |      D      |
        |             |             |
        +-------------+-------------+
```

    * 做法：过待求点 P 作横竖两条辅助线，把正方形切成四块小矩形 A、B、C、D；每个角点的权重等于与它成对角的那块小矩形的面积，P 的值就是四个角点的数值分别乘上各自对角矩形的面积再相加。

    * 自洽校验：P 越靠近某个角点，与该角点成对角的那块就越大、该角点权重就越大，插值结果自然越接近它；四块小矩形面积之和恰为整个正方形，权重天然归一。

    * 适用边界：物理场本身几乎连续、没有跳变时，双线性插值能干非常好的工作；流体里也可用双三次插值（bicubic interpolation），但最近不太流行——双线性非常容易实现，大部分情况下效果已经挺好。

## 对流：半拉格朗日与高阶格式

### 半拉格朗日对流

* **半拉格朗日对流（semi-Lagrangian advection）**

    * > **定义**：求下一时间步 $x$ 点的新值时，把 $x$ 沿当前速度场向后推移一个 $\Delta t$ 得到历史位置，在旧场的历史位置上做一次双线性插值，插值结果就是新值。

    * 前提假设：速度场在空间中每一点恒定、且从来不变——因此可以把 $x$ 看成一个拉格朗日粒子：它上一时间步位于历史位置，且速度不变。

    * 实现骨架：

```text
for I in new_x 的所有下标:
    p ← backtrace(I)                  # 时间倒放，沿当前速度场回溯一个 Δt
    new_x[I] ← 双线性插值(旧场 x, p)   # 在历史位置上采样旧场
```

    * 得名缘由：网格本身不动（欧拉的那一半），求值时却假想一个跟着材料走的粒子（拉格朗日的那一半），"半拉格朗日"由此得名。

    * 定位：各种对流 scheme 里最简单的一种——非常稳定、实现非常容易，但数值粘性高，场会越转越糊。

* **对流 scheme 的取舍**

| 方案 | 优点 | 代价 |
| :--- | :--- | :--- |
| semi-Lagrangian | 非常稳定，实现非常容易 | 数值粘性高，场会越转越糊 |
| MacCormack / BFECC | 基本消除变糊问题，边界保得住 | 要做三次对流，还要配合 clipping |

    * 谱系：semi-Lagrangian 最简单；MacCormack 与 BFECC 是它的升级版本，两者本质非常类似、一般不做严格区分；近年的 BiMocq（2019）也是很有意思的新 scheme；particle advection 则把物理量记在粒子上，属于混合欧拉-拉格朗日视角，变种很多。

* **直线回溯的误差**

    * 误差根源：真实速度场经常变化，材料实际沿曲线移动、路径可能非常复杂；沿直线回溯会得到偏离后的结果——差之毫厘、谬以千里。

    * 现象：旋转速度场里平流一张太极图标（把它当温度场、假设温度不扩散，理应整体转圈保持原样），最简单的直线回溯会让图标越转越小——每次回溯路径不准，会取到一个"更远一点"的值，每平流一次图标就缩一点；同时越来越模糊。

### 回溯的精度升级

* **回溯（backtrace）的本质**

    * 求"上一时间步的位置"是一个初值问题（initial value problem）——一个数值 ODE，可以用数值分析的标准手段提高精度。

* **一阶 forward Euler 回溯**

    * 做法：$p_{t-\Delta t}=p_t-\mathbf{u}(p_t)\,\Delta t$——直接用当前点的速度回退一整步。

    * 负号来源：往历史方向推、把物理模拟倒着重新播放；若往未来推则应为正号——式中的负号全部由 going back 导致。

* **RK2（显式中点法）**

    * 做法：先把 $p$ 往回回放 $0.5\Delta t$ 得到两帧之间的中间点，在中间点采样一次速度，再用这个速度回放整个 $\Delta t$。

    * 为什么中点更好：近似一个区间上的值，用开头或结尾都不如用中间——若区间上方是线性函数，取中间正好取准。

    * 效果：换成 RK2 后，越转越小的问题基本消失（越来越糊是另一个问题，另想办法）。

* **更高阶与取舍**

    * RK3 与 RK2 在演示里基本没有区别；很少情况下才必须用 RK4。

    * 更高阶格式的通用做法：往回多走几步、多采样几个中间点，把得到的速度做加权平均——权值有专门的推导方法，不是随便写的。

    * 代价：格式越复杂，计算量越大，同样存在取舍。

| 回溯格式 | 做法 | 实际建议 |
| :--- | :--- | :--- |
| 一阶 forward Euler | 直接用当前点的速度回退一整步 | 最简单；旋转场里图标会越转越小 |
| RK2（显式中点法） | 先回放半步取中点速度，再用它回放一整步 | 一般已经够了 |
| RK3 / RK4 | 多次回溯、多点采样，速度加权平均 | RK3 与 RK2 效果接近；很少情况才必须用 RK4 |

### 数值黏性与误差补偿

* **数值粘性（numerical viscosity）**

    * 成因：双线性插值做加权平均，本来 sharp 的变化被平均抹糊——一个位置左边是 0、右边是 1，中间取一次值就得到 0.5。

    * 后果链：速度场变糊等于出现 numerical diffusion → 能量衰减 → 流体不再 energetic、看起来非常"黏"，转一会儿图案基本看不清。

* **MacCormack / BFECC**

    * > **定义**：调用三次 semi-Lagrangian 对流、把往返偏差补偿回来的高阶对流格式；BFECC 全名 Back and Forth Error Compensation and Correction，文献里与 MacCormack 混用，本质相同。

    * 流程：

```text
x*      = A(x)            # 正向对流一步，A 即 semi-Lagrangian 对流
x**     = A(x*, -Δt)      # 用 -Δt 把 x* 再搬回去
err     = (x - x**) / 2   # 往返一趟的偏差取一半，即对流误差的估计
x_final = x* + err        # 用误差把 x* 补回来，作为最终结果
```

    * 原理：若无误差，场往前推 $\Delta t$ 再往回推 $\Delta t$ 应与原场一模一样；实际不一样，差值的一半就是对 advection error 的估计。

    * 效果：基本没有变糊问题——圆的边界基本保得住，运动部分仍稍有变化，但比 semi-Lagrangian 好很多很多。

    * > **易错点** ⚠️：MacCormack 的修正本身可能导致 overshooting，在边界处产生类似吉布斯现象的波纹状 artifact——写 MacCormack 一定要配合 clipping；去掉 clipping 立刻能看到不满意的效果。

## 压力投影与泊松方程

* **投影（projection）**

    * > **定义**：求一个合适的标量压强场 $p$，使 $-\frac{\Delta t}{\rho}\nabla p$ 施加到速度场之后，速度场变成无散度的场。

    * 推导链：对投影方程 $\frac{\partial\mathbf{u}}{\partial t}=-\frac{1}{\rho}\nabla p$ 做时间离散，得 $\mathbf{u}^*=\mathbf{u}-\frac{\Delta t}{\rho}\nabla p$，并要求 $\nabla\cdot\mathbf{u}^*=0$。

    * 对等式两边同时求散度：左边正好是 u* 的散度、等于零被消掉；散度算符是线性算符、可以塞进右边；移项得 $\nabla^2 p=\frac{\rho}{\Delta t}\nabla\cdot\mathbf{u}$。

* **泊松方程（Poisson equation）**

    * > **定义**：形如 $\nabla^2 p=f$ 的方程；流体模拟里右端项 $f=\frac{\rho}{\Delta t}\nabla\cdot\mathbf{u}$，一般不为零。

    * $f=0$ 时称为拉普拉斯方程（Laplace equation）。

    * > **易错点**：有的书把泊松方程写成 $\Delta p=f$，这个 $\Delta$ 是 Laplace 算子（可写作 $\nabla^2$，或两个倒三角点乘 $\nabla\cdot\nabla$ 的形式），与 $\Delta t$、$\Delta x$ 里表示差分（difference）的 $\Delta$ 完全不是一回事；本课程用 $\nabla^2$ 而不用 $\Delta$，避免歧义。

    * 落到网格：物理量都存在背景网格上，要建立离散方程近似连续方程——即线性方程组 $A\mathbf{p}=\mathbf{b}$，$A$ 来自拉普拉斯算子，$b$ 来自速度场的散度。

## 泊松方程的离散化

### 五点差分与散度

* **五点差分格式（five-point stencil）**

    * > **定义**：用 $p$ 自己加上周围四个点、共五个点的值，近似 $p$ 在 $(i,j)$ 点的拉普拉斯。

$$
(\nabla^2 p)\Big|_{i,j}\approx\frac{p_{i+1,j}+p_{i-1,j}+p_{i,j+1}+p_{i,j-1}-4\,p_{i,j}}{\Delta x^2}
$$

    * 推导思路：把散度的推导反着用一遍——先算四条边上的压强梯度（上面那个 cell 的压强减下面那个 cell 的压强、再除以 $\Delta x$），再对这四个"边上的梯度"按数流量的方式求散度，化简即得；负的 $4p_{i,j}$ 加周围四点，又是五个点。

* **散度的离散**

    * 直观含义：一个 cell 里速度场的散度，说的是这个格子里流入或者流出流体的量——流出为正、流入为负。

    * 在交错网格上就是"数流量"：每条边对流体的贡献是边长乘法向速度（如 $\Delta x\times u_{i+\frac12,j}$），流出的加、流入的减，再除以格子的面积 $\Delta x^2$。

$$
(\nabla\cdot u)\Big|_{i,j}\approx\frac{u_{i+\frac{1}{2},\,j}-u_{i-\frac{1}{2},\,j}+v_{i,\,j+\frac{1}{2}}-v_{i,\,j-\frac{1}{2}}}{\Delta x}
$$

    * 交错网格的好处在这里体现得淋漓尽致：每条边上的法向速度刚好都存在该在的位置上，散度就是"数一数四条边进出了多少流体"——四个采样点、一加一减、一个 $1/\Delta x$。

    * > **易错点** ⚠️：抄这两个离散公式时千万别丢归一化因子——散度整体带 $1/\Delta x$、拉普拉斯整体带 $1/\Delta x^2$；只抄"邻居加减"、忘掉分母是最常见的错。

* **线性系统的规模**

    * $n\times m$ 的网格：$p$ 有 $nm$ 个采样点（未知数），$b$ 有 $nm$ 个方程，$A$ 是 $(nm)\times(nm)$ 的矩阵；三维则是 $(nmk)\times(nmk)$ 个元素——非常大，但稀疏。

### 边界条件

* **空气邻居（开放边界条件）**

    * 处理：把空气 cell 里的 $p$ 认为是零，方程里对应的项直接换成零——压强为零，即 Dirichlet 型的条件。

* **固体邻居**

    * 物理含义：固体意味着流体在这一面上的法向速度一定是零；速度永远是零，则这一面的压强差（压强的梯度）也就永远是零。

    * 方程修改两件事：把固体那一侧邻居的贡献去掉；同时把中心系数从 4 减成 3——穿过固体那条边的贡献，随着这条边是固体一起没有了。

    * 直观图像：固体面相当于一面"镜子"，面两边的压强相等，固体侧邻居的取值和中心自己重合，四个邻居变三个，系数自然从 4 变成 3。

| 邻居是什么 | 物理含义 | 对方程的修改 |
| :--- | :--- | :--- |
| 空气（开放边界） | 压强为零（Dirichlet 型） | 空气 cell 的 $p$ 直接取 0 代入 |
| 固体 | 面上法向速度为零，面上压强梯度为零 | 去掉固体侧邻居的贡献，中心系数 4 变 3 |

## 线性系统的解法

### 直接法与迭代法

* **解法器两大类**

| 维度 | 直接法（direct solver） | 迭代法（iterative solver） |
| :--- | :--- | :--- |
| 怎么给解 | 一次性把解算出来 | 先得到一个解的估计，在其上不断改进 |
| 代表 | PARDISO | Gauss-Seidel、Jacobi、SOR、共轭梯度等 |
| 适用 | 系统不太大时省事、稳定 | 大系统；可搭配预条件加速 |

    * 直接法的代表 PARDISO：把矩阵的系数形式构造出来喂给它，就稳定地解出来，省事且性能不低。

* **解法器的组合**

    * > **定义**：一个好的线性解法器通常由很多不同的 solver 组合而成。

    * 图形学解泊松方程的一般做法：共轭梯度（conjugate gradients）+ multigrid 做 preconditioner + multigrid 每一层用 damped Jacobi 做 smoothing + 最底下最小的一层用 PARDISO 这种直接法直接解掉——这基本是图形学求泊松方程的标配。

* **十大算法的插曲**

    * 某期刊评选的"20 世纪最重要的十大算法"里有四个都能用来解线性方程组：Krylov 子空间迭代法、矩阵分解、FFT（解泊松方程）、快速多极子方法（做 preconditioner）。

    * 单纯形法（解线性规划）也可以用来解刚体模拟；Monte Carlo / MCMC 可以用作渲染——同一批算法在各领域都有好应用。

### 矩阵的存储

* **矩阵 $A$ 的性质**

    * 三维模拟里每一个 voxel 都要在 $A$ 里占一行，$A$ 可能非常大；通常它是稀疏的（sparse），运气再好一点还对称、正定——合起来叫对称正定（SPD）。

* **稠密矩阵（dense matrix）**

    * 最简单的存法：$A$ 比较小时可行；但不 scalable——$1024\times1024$ 还存得下，一百万个 voxel 或 pixel 就存不下了。

* **稀疏矩阵（sparse matrix）**

    * 可行原因：$A$ 的每一行可能有一百万个元素，但其中很可能只有十个非零，其余全是零、不用存；存储格式有很多种，如 CSR、COO。

* **matrix-free（不存 A）**

    * > **定义**：根本不存 $A$ 的 entry、需要时在线把值算出来的表示方式；对流体模拟里的泊松方程，图形学里一般就不存 $A$。

    * 对存储最高效：不需要存 entry，能省很多内存。

    * 对计算也有好处：从内存里 fetch data 也是计算的一部分，现代体系结构里 memory bandwidth 和 FLOPs 比起来是非常昂贵的资源——内存很慢、CPU 很快；"在线算出来"还是"预存好了去取"两种设计各有优劣。

### 共轭梯度法

* **共轭梯度法（conjugate gradients，CG）**

    * > **定义**：Krylov 子空间解法器（Krylov subspace solvers）中最知名的变形，基本上是最有效的线性系统解法器之一。

    * 缩写辨析：这个 CG 与 Computer Graphics 的 CG 不是一个 CG；图形学里有时还用 CR（conjugate residuals）和 GMRES，很少很少的情况会用到 BiCGStab；一开始掌握 CG 就可以——它在很多情况下已经足够。

    * 实现非常容易，也就十几行代码；一开始理解不了没有关系——把代码抄好，solver 基本上就是 work 的；拿到结果再慢慢研究它为什么会是这个结果。

* **CG 算法骨架**

```text
初始：算出残差 r（r = b - A x），取定初始搜索方向 p
      （注意：这里的 p 是 search direction，不是压强！）

循环：
  (1) 估计一个步长 alpha：x 沿 p 方向走多远，能更接近真解
  (2) x <- x + alpha * p           更新解的估计
  (3) r <- b - A x                 x 更新了，残差 r 也得跟着更新
  (4) 若 r 已经足够小 -> break，此时的 x 就是解
  (5) 估计一个 beta
  (6) p <- 用 r 和 beta * p 组合出新的搜索方向
回到 (1)
```

    * 本质：在一个 Krylov 子空间里做能量最小化；$\alpha$、$\beta$ 为什么这么取需要比较深入的理解。

    * 入门材料：《An Introduction to the Conjugate Gradient Method Without the Agonizing Pain》——免费挂在作者主页；作者写它的动机是自己看了很多共轭梯度教程、一个都没看懂，干脆自己写了一个；一开始理解不了 CG 很正常，它本身就是很 counterintuitive 的东西。

### 条件数与暖启动

* **条件数（condition number）**

    * 前置概念：特征值与特征向量——非零向量 $x$ 满足 $Ax=\lambda x$，即 $A$ 作用在 $x$ 上不改变方向、只把长度缩放 $\lambda$ 倍；一个矩阵可以有很多个特征值。

    * > **定义**：$\kappa(A)=\dfrac{\lambda_{\max}}{\lambda_{\min}}$——最大特征值除以最小特征值（这是对 SPD 矩阵的常用定义，其他地方可能见到别的定义，但总体结论不变）。

    * 直观理解：矩阵作用到一个向量上，在一些方向把它拉得非常长、另一些方向压得非常短，这个矩阵就"非常厉害"、condition number 就会非常大。

    * 核心结论：condition number 越小，迭代法收敛得越快。

* **暖启动（warm starting）**

    * > **定义**：把上一步解出的压强场拿来当作这一步压强线性系统的初始猜测，以减少收敛需要的迭代次数。

    * 依据：初始猜测已经和真正的解非常接近时，需要的迭代次数自然少；流体模拟里可以假设上一步与这一步的压强场差别不大。

    * 适用边界：这个 trick 对 Jacobi、Gauss-Seidel 或者共轭梯度都非常好用，但对 multigrid 就不太好使——直观猜测是 multigrid 的 preconditioner 会 distort（扭歪）解空间。

    * 反面教材的价值：压强场没解好（只跑固定的、很少的迭代次数）→ 投影后速度场有散度 → 流体体积不断缩小；压强解得准 → 速度场无散 → 体积不增不减。

### 预条件

* **预条件（preconditioning）**

    * > **定义**：解 $Ax=b$ 时左右各乘一个可逆矩阵 $M$ 的逆，转为等价系统 $M^{-1}Ax=M^{-1}b$，使新系统的条件数更小、或特征值聚集（eigenvalue clustering）更好。

    * 特征值聚集正是共轭梯度解法器决定收敛迭代次数的一个 metric。

    * 为什么不能取 $M=A$：能让 $M=A$ 就意味着能 invert 这个 $A$，那根本就不需要 preconditioner 了——正是因为 $A$ 的逆算不出来，才需要做预条件；$M$ 一般取与 $A$ 近似、而且很容易求逆的矩阵。

    * 形式自由：preconditioner 不一定要能写成一个矩阵的形式——只要是一个 general 的 linear operator 就可以，例如快速多极子方法同样可以用作 preconditioner。

* **常见预条件子**

    * Jacobi preconditioner：对角阵直接把对角线上的元素逐个取倒数就得到逆；有的地方也叫 diagonal preconditioner。

    * incomplete Cholesky（不完全 Cholesky 分解）：Bridson 的流体书里讲了用它做预条件的 PCG（preconditioned conjugate gradients，预条件共轭梯度）。

    * multigrid：收敛非常快的 preconditioner，本质是在近似地 invert $A$；现在基本是图形学做压力投影的标配——容易实现，效果非常非常好。

## 多重网格与 MGPCG

* **多重网格（multigrid）**

    * > **定义**：把残差（residual）做多分辨率处理、在多个尺度上消灭残差的解法器。

    * 动机：五点差分每次只"看到"一个 cell 和它周围四个 cell，能看见的非常少；而速度场的散度可能是 very large scale、low frequency 的东西——低频散度是只盯着五个格子的局部算子 capture 不住的。

    * 流程：

```text
最细网格 ──smoothing──► 残差 ──restriction（4 格并 1 格）──► 更粗网格
更粗网格 ──smoothing──► 残差 ──restriction────────────────► 更粗网格
   ……一层层向下，直到最粗一层：方程已经非常小
最粗一层 ──► direct solver（如 PARDISO）直接解掉（偷懒也可以叠很多次 Jacobi）
然后逐层 prolongation，把粗层解出的修正插值送回细层
```

    * 设计空间：有 restriction、prolongation，有 V-cycle、W-cycle 等好多种递归方式；smoother 可以用 Gauss-Seidel、Jacobi、damped Jacobi——好的解法器由简单的解法器组合而成，smoother 也不例外；每一层做多少次 smoothing 迭代需要设计；coarse grid 和边界条件怎么处理（比如 Galerkin coarsening 这类技巧）还有很多话题。

    * 层数取舍：层数太少，最 coarse 一层的 voxel 数目会非常多、解起来很慢；层太多、粗化过头，又会逐渐失去对原来问题的把握。一般做法：不断 coarsen，直到最 coarse 一层的未知量数目能被 direct solver 高效解决时，就不再继续。

    * 地位：如果在 regular grid 上解泊松方程，multigrid 基本少不了——现在要发一篇 SIGGRAPH、解泊松方程不用 multigrid，别人都会质疑性能是不是有问题。

    * 参考材料：《A Multigrid Tutorial》；图形学论文《A Parallel Multigrid Poisson Solver for Fluids Simulation on Large Grids》——不是最早的一篇，但非常容易读懂。

* **MGPCG（multigrid preconditioned conjugate gradients）**

    * > **定义**：把 multigrid 用作 CG 的 preconditioner 得到的解法器；multigrid 很少单独拿来当 solver 用，一般都是这样组合。

    * 实测表现（三维泊松求解示例）：MGPCG 只需要六个 iteration，就能把 residual 从一个非常大的数缩到非常小的数；关掉 multigrid、用裸 CG 解同一个系统，二十个 iteration 还没解完。

    * 复杂度规律：写得好的 multigrid，residual 基本上是迭代一次少一个数量级——不管系统有多大，迭代次数通常是固定的（十次量级）；裸 CG 的迭代次数可以认为随线性系统的边长线性增长。系统规模越大，用 multigrid 的收益就越好。

    * 代价：用了 MGPCG 之后每个 iteration 也会贵很多，但减少的迭代数量能够抵消单次迭代变贵的成本——所以解泊松方程基本上都用 MGPCG。

| | MGPCG | 裸 CG |
| :--- | :--- | :--- |
| residual 下降速度 | 迭代一次约降一个数量级 | 明显更慢 |
| 迭代次数与规模的关系 | 基本是常数（十次量级） | 随系统边长线性增长 |
| 单次迭代成本 | 更贵 | 更便宜 |

## 时间步全景与能量损失

* **一个 time step 的全景**

    * 图形学里，欧拉流体每个 time step 其实就两个关键操作：advection（"移动"流体场）与 projection（保证速度场是 divergence-free 的、无散）。

    * advection 唯一关键的事：用好的 scheme 让 numerical viscosity（数值黏性）或 numerical diffusion 尽量小——数值黏性高的话，流体本身不黏也会变得很黏；可以采用 MacCormack、BFECC，还可以用 particle advection。

    * projection 的必要性：速度场无散，流体的体积才得以保持；压强解得不好（例如只迭代十次就掐掉），速度场就会有散度，体积就会放大或缩小、看起来很奇怪。要把速度场迭代到无散，需要很好的线性 solver——通常就是 MGPCG。

    * 因果链：压强解得准 → 投影后速度场无散 → 体积不增不减。

    * 实现注意：做 incompressible 的 Eulerian solver 一般来说没有显式格式——显式没法做 incompressible（除非走涡量那条路）。

* **stable fluid demo 的定位**

    * Taichi 里社区大神写的可交互流体 demo，用 semi-Lagrangian advection 加 Jacobi projection——好处是比较容易实现。

    * 缺点：还是有一点点黏，压强也不是完全无损——很猛地拖会看到体积被压缩或膨胀的现象。

    * 改进方向：把平流改成 MacCormack，把压强求解至少换成 conjugate gradients。

* **投影的能量损失**

    * 机理：原始速度场做一次 advection 之后，得到的场里既有有散度的分量、也有无散的分量；projection 把有散度的那个分量投影掉——这一投影，动能就会有损失。

    * 等价说法：动能损失等价于在系统里引入了 numerical viscosity；或者说速度场的 vorticity（涡量）被丢掉了一部分——丢掉了就得想办法恢复。

```text
常规做法：
  advection ─────────────────► projection
                                （有散分量在这里被投影掉，动能损失）

Advection-Reflection：
  advection(前一半) ─► projection(能量无损，把状态"搬"过去) ─► advection(后一半) ─► projection
                                                                      （损失小很多）
```

* **IVOCK**

    * 通过重建被丢掉涡量的速度场，来降低流体的数值黏性（SIGGRAPH 2015 的工作）。

* **Advection-Reflection solver**

    * > **定义**：不把散度分量一次性 project 掉——在 advection 的中间先做一次对能量没有损失的 projection、把状态"搬"过去，然后做剩下的一半 advection，这样最后那一次 projection 的能量损失就会小很多（SIGGRAPH 2018 的工作）。

    * 工程友好：如果已经有 multigrid 和一个好的 pressure projection solver，稍微改改代码可能五行就能实现，而且效果非常惊人。

## 进阶话题：水模拟与界面

* **气体模拟与水模拟的界线**

    * 前述整套流程（semi-Lagrangian 平流、压力投影等）全部可以认为是气体的模拟——气体模拟一般也叫烟雾模拟。

    * 模拟水就得有一个水和气体的界面：在这个界面上，压强满足 Dirichlet 边界条件——压强为零；怎么 handle 流体界面、怎么 capture 界面的变化，要用 level set。

    * level set 最权威的书是《Level Set Methods and Dynamic Implicit Surfaces》（Osher、Fedkiw），对图形学背景的读者不算友好；可以看 Fedkiw 早期发在 SIAM 上的 level set 论文——那是该理论在图形学里比较简化版的应用。

* **两相流体模拟（two-phase fluid simulation）**

    * 直观案例：一瓶矿泉水开盖倒过来，水流出的过程中还有空气要进去；做 one-phase 模拟，水会直接往下流、没有空气进去，非常不自然；做 two-phase 就会有空气进去，效果非常有趣。

    * 可参考用 stream function 做两相流体模拟的工作（Ando、Thuerey、Wojtan）。

* **边界条件的精度**

    * 前述固体边界处理只有以 voxel 为单位的精度；如果边界正好在 voxel 内部划了一刀怎么办——需要更精细的 solid-fluid coupling（变分框架一类的处理）。

    * 系统深入学习欧拉流体模拟的标准书是 Robert Bridson 的《Fluid Simulation for Computer Graphics》——边界条件等内容的完整推导在里面讲得非常细。

## 泊松问题的求和视角

* **万有引力作为泊松问题**

    * 引力势场满足一个关于密度的泊松方程；任意两点之间的受力就是这个势场的梯度——把梯度运算代入基础解的求和系统，就得到平方反比公式。

$$
\mathbf{F}(x_i)=\sum_{j} m_i\,m_j\,\frac{x_j-x_i}{\lvert x_j-x_i\rvert^{3}}
$$

    * 整体再乘一个常数系数；方向沿两个粒子之间的连线。

    * 量纲逻辑：梯度把 $1/r$ 变成 $1/r^2$；写成矢量时方向要除以 $r$ 做归一化，分母就多出一个 $r$，所以是 $r^3$——正对应"平方反比、沿连线方向"。

    * 复杂度：$N$ 个粒子对 $M$ 个点求力，直接求和需要 $O(N\cdot M)$ 的时间；两者同量级时就是 $O(N^2)$——标度很差，需要快速方法降标度。

* **快速多极展开（Fast Multipole Method，FMM）**

    * > **定义**：把 $O(N^2)$ 的求和问题在线性时间里算完的一类快速求和方法，被誉为 20 世纪十大算法之一。

## 多极展开

* **二维复数形式**

    * 用复数表达坐标，二维泊松方程的基础解求和写作 $\phi(z)=\sum_{j}q_j\log(z-z_j)$；其实部就是要求的势函数解，$\log\lvert z\rvert$ 就是二维情况下的格林函数。

* **多极展开（multipole expansion）**

    * > **定义**：一团电荷在远处的势 = "位于中心、带总电量 $Q$ 的等效点电荷的势" + 一串几何收敛的高阶修正项 $q_k$。

$$
\phi(z)=Q\log z+\sum_{k=1}^{p}\frac{q_k}{z^{k}}
$$

    * 推导图景：考虑一个圆及其在远处 $z$ 点引发的势，在圆心处做泰勒展开；圆心附近很多电荷各自对零点展开再全部加起来——第一部分像来自零点一个带了更大电荷的"等效电荷"，第二部分的高阶项来自这团电荷的形状。

    * 收敛性：高阶项是几何收敛的——离得越远收敛越快，取很少几阶就够用。

    * 物理对应：展开的各阶系数与电多极子 exactly 对应——第一项是电单极子（monopole），下一项是电偶极子（dipole），第 $n$ 项对应电 $2^n$ 极子；三维笛卡尔展开得到 monopole、quadrupole、octupole（八极）等。

    * > **易错点** ⚠️：别把多极展开当成万金油——核要先满足退化核（degenerate kernel）的引理条件才能被展开；好在通常源于物理应用的核（高斯核、热核、格林函数、万有引力核）都能过关，但不是任意的核都行。

## 树代码

* **树代码（tree code）**

    * > **定义**：利用多极展开把 $O(N^2)$ 求和加速到 $O(N\log N)$ 的算法；也叫 Barnes-Hut——tree code 就是 Barnes-Hut 发明的，是一回事。

    * 第一步：把空间里的众多电荷做网格划分；在每个格子的中心点计算 $Q$ 和 $q_k$，使得离这个格子较远处的场可以被这组展开近似。

    * 第二步：不断逐层往上抽象——把格子的展开卷到上一层格子，一层层卷上去，最后得到一个特别粗的网格，里面存的 $Q$、$q_k$ 代表该格子全部电量对应的泰勒展开形式。

    * 查询：求空间中任意一点的势时，通过树状结构的遍历走到叶节点——离叶节点近的格子用直接求和公式计算；距离变远后远场基本比较平滑，就用格子中心记录的泰勒展开去近似远场势的影响，一层层往外直到最粗糙的解析度。

    * 复杂度：每个目标点约 $O(\log N)$ 的累加量，总计算量 $O(N\log N)$。

## 多极展开的三种变换

* **M2M（multipole-to-multipole）**

    * > **定义**：把一个以 $z_1$ 为中心的 multipole 展开"搬家"到新中心 $z_2$，得到新的 $Q$ 与各阶系数 $b_k$，使同样的远场势能被新展开精确表达。

    * 方法：对原展开公式在 $z_2$ 处重新做泰勒展开、重写公式；新形态与原型同构——都有一个代表总电量的 $Q$、一串高阶余项，收敛性同样是几何收敛。

    * $b_k$ 是 $q_k$ 的泛化：第一项是"每个子团的总电量 × 位移的 $k$ 次幂 ÷ $k$"；$b_k$ 自己的高阶项由原来那些 $q_k$ 直接推导计算出来。

    * 电子是特殊的 multipole：它的 $q_0$ 就是自己带的电量、所有 $q_k$ 项都是零；从 $s$ 个已知 multipole 构造新 multipole 时，每个旧 multipole 就又相当于一个电子。

```python
# （伪代码）
class Multipole:
    center: complex        # 展开中心在哪
    terms:  list[complex]  # q0, q1, ..., qp：总电量与各阶高阶项（复数）

# 源电荷（电子）是特殊的 Multipole：
#   center = 电荷自己的坐标；q0 = 它自己带的电量；其余 qk = 0

def m2m(q_list):                       # q_list: 一组子 multipole
    center_new = weighted_sum(m.center for m in q_list)   # 新中心：子中心的加权和
    q0_new     = sum(m.terms[0] for m in q_list)          # 新 q0：所有子 q0 之和
    bk_new     = [compute_bk(q_list, center_new, k) for k in range(1, P + 1)]
    return Multipole(center_new, [q0_new] + bk_new)
```

* **M2L（multipole-to-local）**

    * > **定义**：把一个离目标点 $z$ 比较远、以 $c$ 为中心的 multipole 展开，转换成离 $z$ 很近、以 $z_1$ 为中心的 local 展开；local 可以形象地想象成一个局部邻域上的插值函数。

$$
\phi(z)=b_0+\sum_{l=1}^{p}b_l\,(z-z_1)^{l}
$$

    * $b_0$ 不是别的，就是它中心处的电势值（potential 值）；要 $z$ 点的电势，就是"$z_1$ 处的电势 + 一个高阶扰动"。

    * 收敛性：$z-z_1$ 是一个很微小的量（小于半径），而 $b_l$ 的量级由 $(z_1-c)$ 的幂次控制、比值小于一——所以这一串又是几何收敛。

    * > **易错点** ⚠️：M2M 与 M2L 的分界就在"目标点离谁近"——展开的两端都离目标点远，用 M2M 搬家；要把远处的展开安放到离目标点很近的位置，就是 M2L。

* **L2L（local-to-local）**

    * > **定义**：把 local 展开的中心从 $z_0$ 转移到 $c_2$，使原来范围内的点都能被新中心的 local 准确表达——本质只是一个坐标变换。

    * 做法：把 $a_k(z-z_0)^k$ 的形式变到 $b_k(z-c_2)^k$ 的形式——展开、移项、合并同类项；计算上有一个 Horner scheme，用动态规划的思路加速这一串系数的计算。

    * 复杂度并不比 M2M 简单多少：形式上只是写成了一个 $b_k$，但这个 $b_k$ 代表"这么一坨东西"；到了三维，式子里还会出现二项式系数（binomial coefficients）一大坨。

    * 实践建议：能不做 L2L 就不做，用插值的办法替代。

## FMM 的线性时间

* **两个视角的抽象**

    * multipole expansion 实际是在对几何做粗化（coarsening）——把电荷的分布粗化成一个带高阶信息的点；local expansion 实际是在做插值；FMM 的整个流程就是"先粗化、再插值"。

* **上行（bottom-up）：$O(N)$**

    * 从电子出发：在格子的中心点算出 $Q$、$q_k$ 和中心坐标 $c$；再把格子上的这些信息聚合到上一层格子。

    * 三维情况下每往上一层格子数缩小到八分之一，遍历过的格子总数 $N+\frac{N}{8}+\frac{N}{64}+\cdots=O(N)$；每个格子上的计算量大约是 $c^p$（$p$ 是展开截断的阶数，是个小常数）——上行的计算复杂度是线性的。

* **下行（top-down）：$O(N)$**

    * 下行要经历 M2L 和 L2L 两种变换；关键事实：对每一个格子来说，与它相对应的 multipole 数量是有限的——它并不累加所有的 multipole，只累加在自己这一层上、和它"相对来说是 multipole"的那些格子。

    * 每个格子做两件事：从父节点继承 local 并把它转变到自己这个格点中心上来；在本层累加对自己来说是 multipole 的贡献。每格计算量是常数时间（大约也是 $c^p$），而格子总数一样是 $N+\frac{N}{8}+\frac{N}{64}+\cdots=O(N)$——下行时间也是线性。

* **收尾与完整管线**

    * 近邻贡献用直接求和补上（P2P），每点常数时间。

```text
[上行 bottom-up]
粒子源 ──P2M──▶ 最细层格子(记下 Q 与 q_k) ──M2M──▶ 粗一层 ──M2M──▶ ……
          逐层向上卷，格子数 N + N/8 + N/64 + …… = O(N)

[转折]
在最粗层：M2L —— 把这一层上"对面"的远场 multipole 变成 local

[下行 top-down]
最粗层 local ──L2L──▶ 粗一层 local ──L2L──▶ …… ──▶ 最细层 local ──L2P──▶ 目标点
目标点结果 ＝ local 值 ＋ 相邻格子的直接求和（P2P）
```

* **树代码与 FMM 的差别**

| | 树代码（tree code） | 快速多极展开（FMM） |
| :--- | :--- | :--- |
| 远场贡献怎么来 | 每个目标点逐层向外、逐格累加 | 父节点先聚合，经 M2L 与 L2L 一次性继承 |
| 单个目标点的成本 | 约 $O(\log N)$ | $O(1)$（约 $c^p$） |
| 总复杂度 | $O(N\log N)$ | $O(N)$ |

* **结构对照**

    * 这个在空间多分辨率上 bottom-up 与 top-down 的组织方式，和多重网格法（multigrid）有异曲同工之妙。

## 插值替代与三维推广

* **用插值绕开最恶心的变换**

    * 做法：父节点不去计算 local，先在父节点的那几个 box 节点上用 multipole 的方法算出远场贡献；要计算目标点时，通过双线性插值（三维是三线性插值）把贡献插值过来——因为远场足够平滑，所以认为插值可行；然后再累加本层远场的贡献，全部计算落在格点上。

    * 收益：M2L、L2L 都不用做了，只要做 M2M 就行——能减少很多公式（当然 M2M 还是得做的）。

    * 实现警告：原版变换的公式代码非常难写、bug 不好修（公式实在太复杂，换一个人都修不了），连熟练的实现者也不可能在一天内写完整套公式。

* **三维展开的两种形式**

    * 三维的泰勒展开可以在笛卡尔坐标系（Cartesian space）下完成，也可以在球谐坐标系下展开；在球谐坐标系下展开得到的，就是原始的 fast multipole method。

    * 三维加速细节：做 L2L 还是 M2L 变换时，为了加快计算，两个球谐展开要先做一个对齐——旋转到半径方向上再做转换，这样系数会算得更快。

    * 参考材料：Greengard 的《A Short Course on Fast Multipole Methods》——Greengard 正是 FMM 这个算法的发现者，这份 short course 写得相当好。

## 边界元方法

* **边界元方法（Boundary Element Method，BEM）**

    * > **定义**：把一个带边界条件的偏微分方程，转化成积分方程的数值方法；它求解的是拉普拉斯方程。

    * 数学基础：有势无源的场有一个非常有意思的性质——它的所有属性被边界处的值唯一决定：在边界 $\Gamma_1$ 上知道法向导数 $\partial\phi/\partial n$、在边界 $\Gamma_2$ 上知道 $\phi$ 的值，剩下整个场里所有的数值就都确定了；这个确定可以通过一个解析的表达式得到——边界积分方程（已可写成离散形式）。

* **数值特点**

    * 矩阵是稠密的：每一个点都来自其他所有点的作用。

    * 条件数通常很好：用 Krylov 子空间的迭代法（如 BiCGStab）求解，通常在常数次迭代里就能找到解；真正的开销在每一次迭代里的稠密矩阵向量乘。

    * 半解析（semi-analytic）：当对边界的划分精细到一定程度，它给出的答案几乎就是解析解——不用特别细致的边界元划分，就已经可以得到很好的答案。

* **与 multigrid 的复杂度对比**

    * 设二维 full domain 有 $N^2$ 个自由度：multigrid 常数时间内收敛，总计算量约 $O(N^2)$；边界元呢——$N^2$ 的域只有边界、约 $N$ 个 element，迭代法常数次收敛，但每一次迭代要用 $O(N^2)$ 的时间做稠密矩阵向量乘，总计算量还是 $O(N^2)$，与 multigrid 打平手（前提是 multigrid 用 matrix-free 的方式实现）。

    * 到了三维：full domain 是 $N^3$，multigrid 总共 $O(N^3)$；边界元这时候有 $N^2$ 个 element，稠密矩阵乘的代价是 $O(N^4)$ 的计算——即使常数次收敛，总共也是 $O(N^4)$，永远无法战胜 multigrid。

    * 破局：回到积分求和本身，用快速多极展开以 matrix-free 的形式计算"矩阵乘向量"这一步——二维 $O(N)$、三维 $O(N^2)$，都打败 multigrid。

| 方法 | 二维总计算量 | 三维总计算量 |
| :--- | :--- | :--- |
| multigrid 解偏微分方程 | $O(N^2)$ | $O(N^3)$ |
| 边界元 + 稠密矩阵向量乘 | $O(N^2)$（打平手） | $O(N^4)$（完败） |
| 边界元 + FMM 快速求和 | $O(N)$ | $O(N^2)$ |

* **典型应用**

    * 波浪：用 N–S 方程求解要把整个 simulation domain 体积化、需要很多计算单元；用边界元在边界上求势方程（或者说伯努利方程），得到的物理虽然没有 N–S 表达的那么复杂，但势流方程已经是对 N–S 很好的一个近似——它只是假设流场无粘、而且流速本身是一个场；这种情况下能求解出复杂波浪运动的形态，而远处波浪的形态对很多应用已经是核心研究任务。

    * 声压：通过边界元求解 Helmholtz 方程，在已知物体外形时可以计算它周围任意范围内的声压——比如物体以一定速度飞行过程中产生的噪音、可被探测声音的影响范围。

## 涡方法

* **涡方法（vortex method）**

    * > **定义**：以涡量为基础组织的流体求解方法；湍流（涡流）的计算来自一个矢量的泊松方程——先通过求解矢量泊松方程得到流函数（stream function），再对流函数施加 curl（旋度）算子得到速度场。

    * 与快速求和的接口：这个速度场反过来又能写成一个求和问题——于是快速求和又可以用来求解涡流。

    * 守恒性对比：以速度为基础的 N-S 方程容易做到动量守恒，但很多时候很难做到涡量守恒；用以涡量为基础的 solver 就比较容易涡量守恒——涡量就是流体里打圈的那一部分，把涡量守恒住，流体里打圈的部分就能保住，流体效果就会更好。

* **涡环穿越（leapfrogging）**

    * > **定义**：两个涡环（vortex ring）一旦产生运动，会做一种"你中有我、我中有你"的交叠上升。

    * N–S 方程路线的代价：需要很多自由度——$512^2$ 的网格、比较高级的高阶时间积分方案、solver 要很多很多行 C++（即使用 Taichi 来写也有很多行）才能差不多模拟出这个 leapfrog；而且最后两个环还是很快就融合了。

    * 涡方法路线：时间积分方法可以简单到就是一个前向欧拉（forward Euler）；整个计算中只有 4 个自由度——4 个涡点，准确说是 $4\times3$ 个坐标分量；C++ 大概百来行，Taichi 七八十行（还算上了可视化），刨掉初始化两个涡的位置，核心大概 40 行左右。

    * > **结论**：同一个涡环穿越，N–S 方程要 $512^2$ 的网格加高阶时间积分，涡方法只要 4 个涡点加前向欧拉、约 40 行代码——差距就在自由度的组织方式上。

* **涡方法遇上固体边界**

    * 总思路：求解边界积分方程——在边界上找一个涡分布（或者按之前的说法，一个"电荷分布"）；要区分做粘性流还是无粘流两种情况。

    * 无粘流：只要求法向不穿透——在边界上布一层"电荷"，它引入一个势流场（potential flow），这个势流场刚好可以 cancel 掉边界处那些本来会穿透的速度；立的方程是：这些边界源产生的势流场点乘法线方向 $n_i$，正好等于负的、已知的速度点乘 $n$。

    * 粘性流：再多解一个额外的方程——沿着边界再找一个涡片（vortex sheet），它引入的速度场刚好能 cancel 切向（tangent）方向上的分量。

    * 涡量释放：在一个纯粒子的方法里不太好做热扩散——所以可能要通过随机游走（random walk），或者通过一些能量总和不变的扩散方式，把边界上求出来的涡量 emit 到周围的流场里去；这样就能形成卡门涡街。

    * 本质：在这个框架里，固体边界本质上是一个涡的源（vortex source）——无滑移边界条件会不断"搓出"涡片，再把它们释放进流场。

    * 每个时间步的时序：n 时刻所有涡粒子已知、速度已知 → 先做对流，把涡粒子走一下 → 从涡粒子里面求出一个速度场 → 这个速度在边界上一定不是严格满足的 → 把边界上的速度点乘切向或点乘法向，得到要 cancel 的量 → 由边界处的"电子"引发的势流场、或者说边界上 vortex sheet 引发的速度场来 cancel → 电荷场不用管（它就是个势流场，无限延伸）→ 剩下那个 vortex 再以热扩散的形式把涡量扩散到系统里，emit 出新的涡粒子。

    * 简化捷径：对二维圆柱和给定的来流速度，这个边界分布是有解析表达式的——按它去 seed 涡，出来的就是卡门涡街（各种湍流、turbulent，非常炫）。

## 三种求和与黑盒复用

* **三种求和**

    * 电场力与万有引力：势场在 $x$ 点的梯度；求和核与半径平方成反比、与质量成正比，方向沿着距离的方向——梯度运算里可以消掉一个 $r$。

    * 边界元中的核：对每一个遍历的 $j$，拿 $x_i-x_j$ 方向的梯度去点乘 $j$ 处的法线 $n_j$——这一点乘会让 kernel 变得很不一样，所以要专门考虑它怎么求。

    * Biot–Savart：它很像万有引力的公式，只不过用的是叉乘的形式。

* **黑盒 `computeGravity` 的复用**

    * 接口：给定一些电子源或重力源 $S$（$n$ 个带质量的粒子），返回所有目标点位置处的受力。

    * 复用求边界积分：把 $\nabla G(x_i-x_j)\cdot n_j$ 按坐标拆成三个分量（$G$ 为格林函数）：$n_j^{x}\partial_x G+n_j^{y}\partial_y G+n_j^{z}\partial_z G$；从原来的源 $S$ 构造出三组不同的源——把每个源自己原有的带电量乘以它当初法线的 $x$（或 $y$、$z$）分量；对这三组源分别调用 `computeGravity`，把第一个结果的 $x$ 分量、第二个结果的 $y$ 分量、第三个结果的 $z$ 分量加起来，就得到了边界积分那个式子的求和值。

    * 复用求 Biot–Savart：把每个涡点的强度当作"电量"喂给 `computeGravity`，把返回的力向量整体旋转 90°，得到的就是 Biot–Savart 速度——旋度核与梯度核只差一个 90° 旋转；对 $j$ 的遍历全部发生在黑盒内部。

## P³M

* **P³M**

    * > **定义**：通过混合偏微分方程的视角和 summation 的视角得到的快速求和方法；注意到的关键事实是每一种 summation 其实都对应着一个偏微分方程。

    * 算法五步：

        * 有一堆粒子，做 particle-to-grid（P2G）操作，把粒子 spread 到网格上，得到一个平滑层。

        * 计算高频场：把每个粒子减掉它从平滑层里插值出来的那个值，就得到它的高频分量。

        * 在网格上解泊松方程（用 multigrid 就可以），求解平滑的场，得到流函数或势函数。

        * 对流函数或势函数求 curl、求梯度，得到平滑的速度分量。

        * 粒子上最终的湍流速度分量由两部分组成：先插值出平滑的速度分量，再对它附近区域的高频分量做直接求和——注意这里是直接求和、不是快速求和，因为只算近邻。

    * 复杂度与实现难度：整个过程中每一步都是线性的，最后得到的就是一个线性时间的求和算法；并且它比快速多极展开要简单得多——用到已经开发的那些工具就足以写出一个 P³M 算法。

    * 边界条件：可以认为是零——所有的粒子被 spread 到很小的一块区域上，把边界放得足够远就行；因为有高频分量的直接累加兜底，这样是不会损失精度的。

    * 精度：随着 correction range（校正范围）的增加，误差能够到达小于 1% 的水平；在合适设置下甚至到了 0.01% 这个量级。

## 与核无关的快速求和

* **与核无关（kernel independent）的快速求和**

    * > **定义**：用"两个圈的等效电荷"去逼近一个源电荷的远场作用的快速求和方法——不依赖核的具体形式。

    * 构造：有一个电子（源电荷）时，构造两个圈把它包住；外圈的 $p_j$ 这些点上，要求出来自 $q_i$ 的直接求和的贡献——这是已知的、要达到的数值目标；然后假设这些数值是由内圈上一些未知的电子电量给出的。

    * 求解：内圈与外圈之间的核 $k_{kj}$ 是已知的——一旦内圈和外圈的形状确定，$k_{kj}$ 就是一个确定的矩阵；外圈的目标值已知，要解的是内圈电荷 $\sigma_k$——这其实是一个局部的（locally）小矩阵求逆过程。

    * 电荷数：每个圈上放多少个电荷随意、多多益善——电荷越多可能越准确；实践中差不多一百个就够了。

## 快速求和的应用全景

* **方程覆盖**

    * 能够被快速求和方法求解的方程：泊松方程、拉普拉斯方程、Helmholtz 方程，还有边界元方法。

| 领域 | 快速求和能干什么 |
| :--- | :--- |
| 宇宙学 | 预测星体运动；辅助搜寻暗物质 |
| 静电场/分子动力学 | 每步计算分子间静电力；支撑肿瘤研究、靶向药设计、新冠受体结合位点分析 |
| 电磁 | 舰船等形体设计：评估雷达可探测半径、反向优化隐身外形 |
| 声学 | 声压分布：飞行器噪音影响范围、高架隔音带布置、汽车与飞机外形降噪、影院回响设计 |
| 势流（potential flow） | 飞机机翼设计、波浪计算 |
| 湍流/涡 | 涡方法（vortex method） |

* **暗物质的逻辑**

    * 名字酷炫、逻辑不神秘：观测到一块区域的质量估计、并知道它在怎么运行后，借助仿真分析看计算出来的轨迹是否真的符合观察——如果差异很大，说明存在没有看到的质量，这就是搜寻暗物质的推理方式。

* **静电场的特殊性**

    * 静电场和万有引力具有完全一样的泊松方程——正负号不一样，但形式完全一样。

    * 分子尺度上静电作用力是主要的作用力：分子动力学软件里每一个时间步计算分子静电作用力是十分核心的任务；新冠疫情期间就用这样的方法分析新冠病毒与 ACE2 受体最好的结合位点。

* **声学离生活最近**

    * urban planning：建高架经过居民区时，通过声压分布在高架上适当放隔离带、隔音板，得到弱化噪音的最优方案。

    * vehicle shape design：大到飞机、小到一辆车，外形都可以通过降低声压的方法优化降噪；还能做影院设计——找出构造声音回响的最佳方案。
