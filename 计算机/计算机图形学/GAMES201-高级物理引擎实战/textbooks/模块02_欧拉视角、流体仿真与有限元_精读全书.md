### 从拉格朗日到欧拉：在水里插桩看流速

之前几讲，我们一直在拉格朗日视角里打转。回忆一下拉格朗日视角是什么：它的粒子是随波逐流的，会跟着材料在空间里移动；这些采样点往往会记录自己的位置和速度，也可以记录温度之类的其他属性。它的关键就是 sensor——传感器，你可以把它想象成一个个小的流体粒子，随着流体或固体在空间中移动。

今天我们讲欧拉视角。欧拉视角的特点请记住一句话：**采样点在空间中是完全不动的**。它回答的问题是：在我这个点这里，材料正以什么样的速度穿过我？直观的理解是：你可以在水里插很多根桩，这些桩永远不动，但每一根桩都知道自己周围的水流流速。

> **定义**：拉格朗日视角——采样点跟着材料走，回答"我这一小包材料现在怎么样了"；欧拉视角——采样点固定在空间中，回答"材料正以什么速度穿过我这个点"。

直观的图景就到这里，下面进入稍微复杂一点的公式部分。今天会讲一点点数学，但不会讲特别多——这门课主要还是侧重直观上的推导。我们偶尔会提到有限体积、有限差分、有限元之类的基础知识，但只讲最为直观的那部分，不会深入很深的数值格式（numerical scheme）理论。想深入学习欧拉流体模拟的话，可以看这本书：《Fluid Simulation for Computer Graphics》，作者 Robert Bridson——流体模拟领域无人不知、无人不晓的大佬级人物，我自己也是看这本书入门的。顺便说一句，张心欣师兄就是这位大佬的学生，名师出高徒。今天这一讲，我们只是快速过一下欧拉法流体模拟的内容。

### 材料导数：连接两种视角的桥梁

要介绍的概念叫 material derivative，材料导数。它联系着欧拉视角和拉格朗日视角。它的符号一般用大写的 D，也就是 $\frac{D}{Dt}$，而不是偏微分符号 $\partial$ 或小写的 d。

材料导数有两个部分。当你求一个物理量的 $\frac{D}{Dt}$ 时：

$$\frac{D}{Dt} = \frac{\partial}{\partial t} + \mathbf{u} \cdot 
abla$$

直观上是什么意思？material derivative 的前提是采样点随着材料一起移动。那这个跟着材料走的采样点，它物理量上的变化有两个成分：

- 第一个成分：假设你即使不动，这个物理量也会改变——这就是 $\frac{\partial}{\partial t}$ 项。可以说它是材料导数里的"欧拉分量"：空间中不动，随着时间改变而改变。
- 第二个成分：材料移动导致的变化。物理场在空间中本来就有关于空间的变化率，也就是它的梯度 $
abla$；材料以速度 $\mathbf{u}$ 移动，于是由移动带来的变化率就是 $\mathbf{u} \cdot 
abla$。

最常见的例子是温度的变化。把温度计绑在粒子上：粒子不动，温度也会变，这是 $\frac{\partial T}{\partial t}$（大 T 是 temperature，小 t 是时间）；粒子移动还会带来另一份变化，即 $\mathbf{u} \cdot 
abla T$：

$$\frac{DT}{Dt} = \frac{\partial T}{\partial t} + \mathbf{u} \cdot 
abla T$$

material derivative 还有很多名字：advective derivative、Lagrangian derivative、particle derivative……名字非常多。这门课里我们统一就叫它 material derivative——不要引入特别多的名字，不然会比较 confusing。

有的时候也会对速度本身求材料导数。比如对速度的 x 分量去求，直接套用公式就可以了：

$$\frac{D u_x}{Dt} = \frac{\partial u_x}{\partial t} + \mathbf{u} \cdot 
abla u_x$$

只不过可能有点绕：速度的变化率里又出现了速度自己——$\mathbf{u} \cdot 
abla$ 作用在 $u_x$ 上，也就是说速度的变化本身受速度的影响。

### 不可压缩 N-S 方程：三项贡献与零散度

接下来是不可压缩的 N-S 方程（Navier–Stokes 方程）。它有很多变种，这里介绍一个比较简单的版本。看起来好像很复杂，但大家不用担心——它说的其实是：流体里的一小包材料，其速度关于时间的导数有三个成分：

$$\frac{D\mathbf{u}}{Dt} = -\frac{1}{\rho}
abla p + 
u
abla^2\mathbf{u} + \mathbf{g}$$

- **压强梯度项** $-\frac{1}{\rho}
abla p$：一小包材料，如果压强在空间中的分布不均匀，压强差就会对它产生力，使它加速。
- **粘性项** $
u
abla^2\mathbf{u}$：这一项在图形学里一般直接忽略。因为我们希望流体的效果越不"黏"越好——越不黏，各种涡旋、各种看起来非常炫酷的效果就越突出。所以这一项大家其实不用考虑。
- **重力项** $\mathbf{g}$：g 就是重力加速度。

去掉粘性项之后，方程里真正要对付的就只剩压强和重力了，而重力那一步非常简单，往往就是给速度场直接添加一个 $\mathbf{g}$。

再看不可压缩条件。既然是不可压缩流体，就意味着速度场不能有散度：

$$
abla \cdot \mathbf{u} = 0$$

为什么？如果速度场有散度，局部就会由于材料的过度流入或者流出，导致这部分的流体被压缩或者延伸；被压缩或者延伸的后果，就是密度会变化——而我们这边是不可压缩流体，密度不该变。所以速度场的散度必须是零。

> **定义**：不可压缩条件——速度场处处无散度（$
abla\cdot\mathbf{u}=0$）。有散度就意味着局部材料净流入或净流出，流体被压缩或拉伸、密度发生变化，这与不可压缩假设矛盾。

### 算子分裂与时间步的三步走

实际情况中，怎么求解这个不可压 N-S 方程？看起来很复杂，但我们一旦把它分开、分成好几份，它就不再复杂了。

首先要做一个叫 operator splitting（算子分裂）的操作。这个名字听起来很复杂，它的严格定义可以去翻那本书里的 more details，但大家只要知道：operator splitting 就是把一个关于时间的 PDE 拆成若干个部分，使得每一个部分都非常简单——这就是它直观的含义。

怎么拆？分三步走。首先把 advection 这一部分提取出来：把原方程的右端项忽略掉、认为右端项是零，得到

$$\frac{D\mathbf{u}}{Dt} = 0$$

再把 $\mathbf{g}$ 这一部分考虑进去：

$$\frac{\partial \mathbf{u}}{\partial t} = \mathbf{g}$$

这一步非常非常简单，往往就是给你的速度场直接添加一个重力加速度。最后，把关于压强的贡献考虑进去，并且把速度场散度为零的条件也放进来：

$$\frac{\partial \mathbf{u}}{\partial t} = -\frac{1}{\rho}
abla p, \qquad 
abla \cdot \mathbf{u} = 0$$

接下来我们分别讲第一步（advection）和第三步（projection）——中间那一步太简单了，顺带就做了。

对拆出来的这三部分做时间离散化，对每一个 time step，我们就有了三步：

```text
   u(t) ──advection──►  u*  ──外力──►  u**  ──projection──►  u(t+Δt)   （∇·u = 0）
```

读图：一个时间步内，速度场依次过三道手续——先顺着速度场把场搬一遍，再叠加上外力，最后用压强把散度抹平。

1. **advection（对流）**。听起来是个很高大上的词，其实含义非常简单：移动我们的流体的场。也就是通过当前的速度场，求解出下一个时间步速度场的一个初始版本 u*——这个初始版本没有考虑外力、也没有考虑压强，只考虑速度场的移动。
2. **外力**。在刚才求出来的速度 u* 的基础之上加上外力，得到 u**——两个 star。
3. **projection（投影）**。即使 u 本身没有散度，经过 advection 和外力的修改之后，u** 自己可能会产生一些散度。怎么办？再进行一步 projection，给它加上一个压强的作用。注意这个压强不能随便取：它必须满足"加上这个压强之后，新的速度场散度是零"。

### 把物理量存在哪：均匀网格与交错网格

有了三步流程，接下来得考虑一下到底怎么表示我们的速度场——这牵扯到数据结构。

欧拉法模拟流体不一定非要用网格：可以用三角网格，三维里可以用四面体网格，真愿意的话，你甚至可以用"永远不动的粒子"来搭一套欧拉法的方程——都行，只是这些方法都比较复杂。今天讲一个非常简单的：regular grid，均匀网格。均匀网格在二维里就是正方形，三维里就是六面体。

把空间分成很多个均匀的正方形 cell（cell 就是"细胞"的意思），比如一个 3×3 的网格一共 9 个 cell。问题来了：每个 cell 自己还是有一块面积的，速度的横向分量、纵向分量以及压强，到底存在哪儿呢？

最简单的做法是全部存在 cell 的中心——横向、纵向都与 cell 的左下角偏移 0.5 个 cell。这样在 Taichi 里分配速度场和压强场的时候非常省事：直接开 `ti.Vector`／`ti.f32` 的场就行，它的 shape 其实就和你的 cell 网格的大小一模一样——你有一个 cell，就有一个压强或者速度的采样。

稍微更复杂一些的方法是 staggered grid（交错网格）：把速度的横向分量、纵向分量以及压强，存在 cell 的不同的地方——横向速度存在竖边上，纵向速度存在横边上，压强仍然存在 cell 中心。

```text
      v       v       v       v
      +-------+-------+-------+
      |       |       |       |
      u   p   u   p   u   p   u
      |       |       |       |
      +-------+-------+-------+
      |       |       |       |
      u   p   u   p   u   p   u
      |       |       |       |
      +-------+-------+-------+
      |       |       |       |
      u   p   u   p   u   p   u
      |       |       |       |
      +-------+-------+-------+
      v       v       v       v

      u（横向速度）存在竖边上     —— 4x3 个采样
      v（纵向速度）存在横边上     —— 3x4 个采样
      p（压强）存在 cell 中心    —— 3x3 个采样
```

读图：同一套 3×3 网格，三种物理量各存各的位置；u 和 v 的数组比 p 各多出一行或一列——这正是"存到边上"的代价。

这里要稍微注意一下数个数：网格是 3×3，横向速度场却是一个 4×3 的数组，纵向速度场是一个 3×4 的数组。虽然每个方向只有 3 个格子，但存到边上的话，你其实有 4 条边——我记得小学的时候学过一个"植树问题"，专门研究这种加一减一的事情，算是童年回忆了。压强就不用担心，它还是存在 cell center，不用担心。

那 staggered grid 有什么好处呢？后面我们算各种有限差分的时候，它就会有很多的好处，特别是它能够避免一个叫做 checkerboard pattern（棋盘格模式）的很坏的事情。关于 checkerboard pattern，大家有兴趣的话可以去看前面提到的那本书。

### 双线性插值：从离散采样到连续场

虽然我们在每一个 cell 里都加了采样点、能知道那一点的速度，但 cell 里除了这些点以外，几乎所有的地方都是没有数值的。那怎么办？我们要在 cell 里所有的地方把速度的横向分量、纵向分量定义出来——这就需要用到插值技术。

常见的插值方法是双线性插值（bilinear interpolation）。有些书上也会讲，流体里可能用双三次插值（bicubic interpolation），但最近好像不是特别流行——大家一般直接上双线性：它非常容易实现，而且在大部分情况下效果也挺好。

什么是双线性插值？假设我们知道一个正方形四个顶点上的值——比如黄、绿、粉、蓝四个点——怎么用这四个值，重建出正方形里任意一点的值呢？

```text
        +-------------+-------------+
        |             |             |
        |      A      |      B      |
        |             |             |
        +-------------+P------------+
        |             |             |
        |      C      |      D      |
        |             |             |
        +-------------+-------------+
```

读图：过待求点 P 作横竖两条辅助线，正方形被切成四块小矩形 A、B、C、D。每个角点的权重，等于与它成对角的那块小矩形的面积：左下角点的权重是 B 的面积，右下角点的是 A 的面积，左上角点的是 D 的面积，右上角点的是 C 的面积。

做法其实很直观：先把待求点关于每一个顶点的"距离"算出来——这里的距离用的是面积度量，也就是待求点与对角线那个点形成的矩形面积。待求点的数值，就是四个角点的数值分别乘上各自对角矩形的面积，再加起来。比如黑点的数值 = 黄点的数值 × 黄色矩形面积 + 蓝点的数值 × 蓝色矩形面积 + 绿点的数值 × 绿色矩形面积 + 粉点的数值 × 粉色矩形面积——说到底就是一个简单的加权平均，其实还是很容易理解的。P 越靠近某个角点，与该角点成对角的那块就越大、该角点的权重就越大，插值结果自然越接近它；四块小矩形的面积加起来恰好是整个正方形，权重天然归一。

做了这一步以后，虽然我们只是在空间里很少的离散点上存了数值采样，但通过双线性插值，就能得到空间里几乎所有点的数值近似。假设我们的物理场本身几乎是连续的、没有跳变，那双线性插值还是能够干非常好的工作的。

### 对流：移动流体的材料

接下来讲 advection。所谓 advection，就是移动流体的材料。

说到 advection，它有非常非常多不同的 schemes，不同的 scheme 其实在数值粘性、稳定性、性能和复杂程度之间做不同的取舍。最简单的是我们下面第一个要讲的 semi-Lagrangian advection（半拉格朗日对流）：它非常稳定，但数值粘性也比较高——什么叫数值粘性，我们后面会演示。稍微复杂一点的方法是 MacCormack 或 BFECC，它们是 semi-Lagrangian 的升级版本。最近还有一些新的 scheme，比如曲子怡同学和张心欣师兄提出的 BiMocq，也是很有意思的 scheme，是 2019 年一篇很好的 paper，大家可以去看一看。还有 particle advection：虽然我们是用欧拉网格表示背景的速度场，但可以把很多物理量记在粒子上面——这个方法在后面讲到混合欧拉-拉格朗日视角的时候再提，它其实也有很多很多的变种。

今天我们就讲最简单的 semi-Lagrangian advection，以及 MacCormack 或 BFECC——这两者本质上非常类似，基本上只有一些细微的差别，大家一般也不做严格的区分。

| 方案 | 优点 | 代价 |
| :--- | :--- | :--- |
| semi-Lagrangian | 非常稳定，实现起来非常容易 | 数值粘性高，场会越转越糊 |
| MacCormack / BFECC | 基本消除变糊问题，边界保得住 | 要做三次对流，还要配合 clipping |

#### 半拉格朗日：回到过去再采样

什么是 semi-Lagrangian advection？假设我们要求下一个时间步 x 点的速度，并且知道上一个时间步的速度场。进一步假设速度场在空间中每一点都是恒定的、并且它从来不变——那问题就非常非常简单：把 x 点的位置沿着时间、沿着当前的速度场向后推移一个 Δt，就得到了 x 这一个点在上一个时间步的位置。

你可以把 x 看成一个拉格朗日的粒子：它上一个时间步在那个位置，下一个时间步跑到了 x 这里。那这一个时间步 x 的速度是多少？非常简单：在上一个时间步、在这个历史位置上做一次双线性插值，就得到这个粒子在上一个时间步的速度；由于假设这个粒子的速度不变，这个值就是下一个时间步 x 点的速度。

实现起来其实非常非常的容易。如果要对物理量 x 做 semi-Lagrangian 对流、把结果存在 new_x 里面，就去 loop over new_x 里所有的下标，把 new_x[I] 设成"旧场 x 在它历史上位置的双线性插值"。这里需要一个 backtrace 函数：所谓 backtrace，就是把时间倒着播放——倒着播放我们就能回到历史，求出 x 这一个点在上一个时间步的位置；然后在上一个时间步去求 x 的值，就得到了这个时间步的物理量。可能有点绕，但直观上还是比较容易理解的。

```text
for I in new_x 的所有下标:
    p ← backtrace(I)                    # 时间倒放，沿当前速度场回溯一个 Δt
    new_x[I] ← 双线性插值(旧场 x, p)      # 在历史位置上采样旧场
```

读图：每个新值都来自"旧场在历史位置"的采样——网格本身不动（欧拉的那一半），求值时却假想了一个跟着材料走的粒子（拉格朗日的那一半），"半拉格朗日"由此得名。

#### 误差演示：越转越小的太极图

但是这个假设会导致很多问题。我们的速度场并不是一个恒定的值，它会经常变；那实际上 x 在速度场里移动，轨迹并不一定是沿着一条直线，它可能是沿着一条曲线，material parcel 的实际移动路径可能非常非常复杂。沿直线回溯，你可能会得到一个偏离后的结果：比如你如果这次这个粒子在 x，你会计算出它上一个时间步的位置在红色的点，但实际上它可能是在绿色的点——那你就差之毫厘、谬以千里了。

在讲怎么解决之前，我们先来演示一下这个误差会产生一个什么样的效果。演示的代码现在已经在 GitHub 上面了，大家可以去论坛里点这个链接，或者直接到 GAMES201 的 release 里面，下载到刚才演示的这几个程序。

演示里我们一开始有一张太极的图标，然后加一个旋转的速度场，让这坨流体顺时针旋转。太极图标表示的是一个温度场：白色表示高温度，黑色表示低温度；我们假设这个温度场本身是不会 diffusion 的。那么温度场就应该只是随着流体的旋转整体转圈、保持原样，我们当然不希望它随流体的旋转变得越来越小——那实际上是数值误差。但如果用最简单的、只做一次直线 trace back 的 semi-Lagrangian scheme，你就会看到太极图标越转越小、越来越小。这就是误差导致的：每次 trace back 的时候，你的路径都不准确，你其实会取到一个"更远一点"的值，于是每做一次 advection，图标就缩一点。当然还有一个问题：图标会越来越模糊。越来越糊的问题我们后面再解决，先解决越转越小的问题。

#### 更准的回溯：从一阶欧拉到中点法

怎么办呢？我们其实有更好的 backtrace 方法。这其实就变成了一个 initial value problem——一个数值 ODE，学过数值分析的同学应该都知道该怎么处理。

刚才演示用的其实是一阶的 forward Euler：要求 p 在上一个时间步的位置，就把 p 减掉"p 在当前时间步的速度"乘上 Δt：

$$p_{t-\Delta t} = p_t - \mathbf{u}(p_t)\,\Delta t$$

注意这里的负号：是因为我们在往历史方向推、把物理模拟倒着重新播放；如果是往未来推的话，这就应该是一个正号。这个式子里所有的符号，都是由于我们在 going back 而导致的。

那怎么得到一个更精确的 estimation 呢？其实直观上也非常容易：用 RK2，或者叫显式中点法。做法是：先把 p 往回回放 0.5 个 Δt，就得到一个两帧之间的中间点；然后我们在这个中间点的地方采样一个速度；再用这个速度去回放整个 Δt 的位置。

为什么中点更好？你要近似一个区间上的值，可以用开头的值，也可以用结尾的值，但最好的还是用中间的值——如果你这个区间上方的数值是一个线性函数的话，取中间正好取得准。

代码里可以改一改 scheme 的参数：刚才 RK 是 1，我们把它换成 2。你可以看到 backtrace 函数里面有一坨 `ti.static`——`ti.static` 其实就是在编译期做一些判断：当 RK 是 2 的时候，我们就是在用中点法进行向后的追踪、向历史的追踪。换成 RK2 再跑：越转越小的问题基本没有了。虽然它还是越来越糊，但越来越糊是另外一个问题，我们先把越转越小解决掉。

一般来说，RK2 有的时候已经够了。我们也可以试试 RK3——演示里 RK3 基本上和 RK2 没有什么区别。再往上的升级版格式更复杂一点：往回多走几步、多采样几个中间点——比如先往回走 0.5Δt 得到一个 p₁，在 p₁ 处采样一次得到一个速度，再用这个速度回放一次得到 p₂，再采样一次，最后把之前得到的这些速度做一个加权平均，得到对真实速度的估计。这个权值不是随便写的，是有技巧的，有专门的推导方法，大家可以自己去研究。

| 回溯格式 | 做法 | 实际建议 |
| :--- | :--- | :--- |
| 一阶 forward Euler | 直接用当前点的速度回退一整步 | 最简单；旋转场里图标会越转越小 |
| RK2（显式中点法） | 先回放半步取中点速度，再用它回放一整步 | 一般已经够了 |
| RK3 / RK4 | 多次回溯、多点采样，速度加权平均 | RK3 与 RK2 效果接近；很少情况下才必须用 RK4 |

当然，随着你的格式越来越复杂，你的计算量也会变得越来越大——这边同样有一个取舍。

#### 越来越糊：数值粘性从哪来

刚才讲到，semi-Lagrangian 会越转越糊。为什么会越来越糊呢？还记得我们之前讲过的双线性插值吗？由于我们在做插值的时候会做加权平均，平均了以后，本来很 sharp 的一个变化就变糊了：你本来一个位置左边是 0、右边是 1，你在中间取一次值，就得到 0.5——这个场就会很自然地变糊。

演示里那个不太看得清的图案，其实是一个黑白的颜色场；如果说大家是在速度场上做这个操作的话，一旦变模糊，就说明你产生了数值粘性：速度场在模拟的过程中出现了 numerical diffusion，而这个 diffusion 会导致能量衰减。能量衰减以后，流体就不再像之前看起来那么 energetic，看起来就会非常"黏"——转一会儿之后，图案基本就看不清了。

#### MacCormack 与 BFECC：把误差补回来

解决变糊的问题，就要用到一个稍微高级一点的格式：BFECC，或者叫 MacCormack。BFECC 的全名叫 Back and Forth Error Compensation and Correction——来回各推一次，把误差补偿回来。它们的想法非常简单，很多文献里这两个名字是混着用的；我们底下这段代码写的其实是 MacCormack，但你可以认为它本质上就是 BFECC。

MacCormack 会调用三次 semi-Lagrangian advection——代码里的 x* 就是我们刚才的半拉格朗日结果。流程是：先把 x 正向对流一步，得到 x*；再把 x* 反过来做一次对流——这次传给它 −Δt——得到 x**。理论上来说，如果我们的 semi-Lagrangian 对流没有任何误差，那么把场往前推一个 Δt、再往后推一个 Δt，x** 应该和 x 一模一样。但实际上它不一样。为什么不一样？因为存在 advection error。把它俩做差、再取个 1/2，就得到我们对 advection error 的一个估计；用这个误差把 x* 补回来，就得到 x_final——它就是最后的速度场。

```text
x*      = A(x)            # 正向对流一步，A 就是 semi-Lagrangian 对流
x**     = A(x*, -Δt)      # 用 -Δt 把 x* 再搬回去
err     = (x - x**) / 2   # 往返一趟的偏差取一半，即对流误差的估计
x_final = x* + err        # 用误差把 x* 补回来，作为最终结果
```

效果怎么样？把 scheme 换成 MacCormack 之后，基本上就没有变糊的问题了：按一下空格暂停可以看到，圆的边界这部分基本没有变糊，运动的部分还是稍微有点变化，但和 semi-Lagrangian 比起来已经好了很多很多。回头看 semi-Lagrangian 的对比：特别是圆的边界，已经糊得非常厉害；再转一会儿，那块区域就基本看不清了。

还有一个地方你要小心：MacCormack 的修正本身，可能会导致 advection scheme 产生 overshooting，带来一些 artifacts。所以代码里有一个 clipping——做完 MacCormack 之后，我们要防止它产生一些非常大的值。为什么会产生非常大的值呢？因为它会根据你的 advection error，在边界上产生一些像吉布斯现象那样的问题；如果你不去做这个 guarding 的话，它就会导致产生 artifact。演示里把 clipping 去掉，立刻就能看到一些看起来不太令人满意的波纹状的 artifact。所以大家记得：如果写 MacCormack 的话，一定要记得做一下 clipping。这些代码都在 advection.py 里面，大家可以下载下来自己玩一玩。

> **易错点**：MacCormack / BFECC 的修正项可能让数值超出原场的合理范围（overshooting），在边界处产生类似吉布斯现象的波纹状 artifact，因此必须配合 clipping 使用。

### 投影：求一个压强场，让速度场无散度

advection 讲完了，接下来讲 projection。

projection 其实非常简单。它主要要做的事是：求出一个合适的标量场 p，使得把 p 的梯度施加到速度场上之后，速度场变成一个没有散度的场。

我们用有限差分把投影这一步在空间上展开。假设投影后的速度场叫 u*，对上一步得到的方程 $\frac{\partial \mathbf{u}}{\partial t} = -\frac{1}{\rho}
abla p$ 做离散：

$$\frac{\mathbf{u}^* - \mathbf{u}}{\Delta t} = -\frac{1}{\rho}
abla p$$

把 Δt 从 u* 减 u 的分母上移到右边来：

$$\mathbf{u}^* = \mathbf{u} - \frac{\Delta t}{\rho}
abla p$$

当然，我们要满足 $
abla \cdot \mathbf{u}^* = 0$。

接下来对等式两边同时求散度。为什么两边同时求散度呢？因为求了散度以后，左边正好就是 u* 的散度——它是零，这样就把 u* 消掉了；右边，散度算符是一个线性算符，可以把它塞进去：

$$0 = 
abla \cdot \mathbf{u} - \frac{\Delta t}{\rho}\,
abla^2 p$$

再做最后一步移项，得到：

$$
abla^2 p = \frac{\rho}{\Delta t}\,
abla \cdot \mathbf{u}$$

也就是说，我们需要求出一个 p，它的"梯度的散度"等于 ρ 除以 Δt、再乘上 u 的散度。

这个形式非常非常常见，它叫做泊松方程（Poisson equation）：把右端项记成 f，方程经常写成

$$
abla^2 p = f$$

> **提示**：有的书把泊松方程写成 Δp = f，但这个 Δ 和 Δt、Δx 里的 Δ 完全不是一回事——它不是 p 的差分，而是 Laplace 算子，有时写作 $
abla^2$，有时写成两个倒三角点乘的形式（$
abla \cdot 
abla$）。本课里 Δt、Δx 已经被用来表示差分（difference），所以我们不用 Δ 来表示 Laplace 算子，避免歧义。

如果 f 等于零，这个方程又被称为拉普拉斯方程（Laplace equation）。但我们这门课里 f 一般不是零——因为我们是用泊松方程去求解速度场的压强、来投影这个速度场的，f 就是方程右端的那一项 $\frac{\rho}{\Delta t}
abla \cdot \mathbf{u}$。

最后要做的事情：还记得我们的物理量都是存在一个背景的网格上面的吗？那么我们要建立一个离散的方程，来近似这么一个连续的方程——也就是建立一个线性方程组，它的形式是

$$A \mathbf{p} = \mathbf{b}$$

那么 A 和 b 分别是怎么定义的呢？既然方程是 $
abla^2 p = f$，我们首先要看的，就是怎么用有限差分来近似 p 的拉普拉斯算子。

> **结论**：projection 把"速度场必须无散度"这个约束，转化成一个关于压强场的泊松方程 $
abla^2 p = \frac{\rho}{\Delta t}
abla \cdot \mathbf{u}$；解出 p 之后，用 $-\frac{\Delta t}{\rho}
abla p$ 修正速度场，散度即被抹平。

## 欧拉视角（下）：把压力泊松方程建好、解好
> 对应块：BLK08 | 覆盖分集：P04下 | 块标题（分集名）：《Lecture 4 欧拉视角》

先从一个看着有点吓人的公式说起：拉普拉斯算子作用在压强 $p$ 上、在 $(i,j)$ 点的取值。为什么是这么一坨复杂的东西？推导放在后面，眼下只要记住一件事就够用了——然后我们会看到，这几个点拼出来的，是一个"非常非常大"的线性方程组 $A p = b$。把这道方程建对、再把它解快，正是欧拉视角流体模拟里压力投影的全部硬骨头。这一讲就把这件事从头到尾讲透：五点差分、边界条件、共轭梯度、预条件、多重网格，最后回到全景收个总账。

### 五点差分与散度：把泊松方程落到网格上

拉普拉斯算子在 $(i,j)$ 点的取值，只要记住：它用 $p$ 自己加上周围的四个点，一共**五个点**的值，来近似 $p$ 在这一点的拉普拉斯——这个叫 five-point stencil（五点差分格式）。为什么偏偏长这样，后面推导时会看得很清楚。

还有一块要离散的是速度场 $u$ 的散度。它同样简单：用 $u$ 周围的四个采样点的值就能算出来，下一节就讲为什么。

两块积木拼起来，就是一个线性方程组 $A p = b$：$b$ 来自速度场的散度，$A$ 来自拉普拉斯算子。这个线性系统的规模不小——如果网格是 $n \times m$，那么 $p$ 有 $nm$ 个采样点（未知数），$b$ 也有 $nm$ 个方程，$A$ 就是 $(nm) \times (nm)$ 的矩阵；三维的话，$A$ 有 $(nmk) \times (nmk)$ 个元素。它其实是一个**非常非常大**的矩阵，好在它是稀疏的。至于这个 $A$ 到底怎么表示、怎么存，后面会专门讲。

> **提示**：抄这两个离散公式的时候，千万别丢掉归一化因子——散度整体带一个 $1/\Delta x$，拉普拉斯整体带一个 $1/\Delta x^2$。只抄"邻居加减"、忘掉分母，是最常见的错。

### 散度怎么来：在 staggered grid 上数流量

散度在直观上是什么意思？一个 cell 里速度的散度，说的是这个格子里流入或者流出流体的量：流出为正，流入为负。

那怎么求出一个格子的净流出速率呢？还记得之前讲过的 staggered grid 吗——用了它之后，速度的横向分量记在 cell 的两条**竖边**上，纵向分量记在两条**横边**上。看右边这条竖边：边上记的速度是 $u_{i+\frac{1}{2},\,j}$，流体正以这个速度往外流。这条边对整个 cell 流体进出量的贡献，就是 $\Delta x \times u_{i+\frac{1}{2},\,j}$——边长乘上流速。左边的竖边是流进来的，得减掉；横着的上下两条边也是一样，流出去的加上、流进来的减掉。这么一加一减，净流出量就出来了；再除以格子的面积（正方形格子就是 $\Delta x^2$），得到的就是这个格子里速度场的散度：

$$(
abla \cdot u)\Big|_{i,j} \approx \frac{u_{i+\frac{1}{2},\,j} - u_{i-\frac{1}{2},\,j} + v_{i,\,j+\frac{1}{2}} - v_{i,\,j-\frac{1}{2}}}{\Delta x}$$

四个采样点、一加一减、一个 $1/\Delta x$——staggered grid 的好处在这里体现得淋漓尽致：每条边上的法向速度刚好都存在该在的位置上，散度就是"数一数四条边进出了多少流体"。

### 拉普拉斯怎么来：先算边上的梯度，再求散

压强的拉普拉斯算子怎么算？非常类似，把刚才的推导反着用一遍。要求 cell 中间这个点的压强拉普拉斯，可以先把四条**边**上的压强梯度算出来：比如一条横边上的梯度，就是这条边上面那个 cell 的压强减去下面那个 cell 的压强、再除以 $\Delta x$；四条边的梯度都能这么算出来。然后对这四个"边上的梯度"求散度——做法和上一节数流量一模一样。做完这个操作，再进行一点点化简，就得到：

$$(
abla^2 p)\Big|_{i,j} \approx \frac{p_{i+1,j} + p_{i-1,j} + p_{i,j+1} + p_{i,j-1} - 4\,p_{i,j}}{\Delta x^2}$$

负的 $4\,p_{i,j}$，加上周围这些 cell 的值——数一数，又是五个点。

### 边界条件：邻居是空气还是固体

现在问题来了：如果邻居不是流体呢？假设流体只有左边两列，第三列是一个固体——方程就得修改，这就是边界条件的问题。邻居是空气和是固体，是两种完全不同的情况。

邻居是**空气**的话，这叫开放边界条件，处理起来非常容易：把空气 cell 里的 $p$ 认为是零，方程里对应的项直接换成零就可以了——压强为零，也就是 Dirichlet 型的条件。

邻居是**固体**，含义就不一样了。固体意味着什么？意味着流体在这一面上的法向速度一定是零。速度永远是零，那这一面的压强差——也就是压强的梯度——也就永远是零。所以如果发现某个 cell 有一面和固体相邻，要做两件事：首先，把固体那一侧邻居的贡献去掉；除了去掉它，还得把中心的系数从 4 减成 3——因为穿过固体那条边的贡献，也随着这条边是固体一起没有了。完整的推导，可以去看之前提到过的 Robert Bridson 那本流体书（《Fluid Simulation for Computer Graphics》），里面讲得非常细，这里由于时间关系就不继续深入了。

> **提示**：给一个直观图像——固体面相当于一面"镜子"，面两边的压强相等，于是固体侧邻居的取值和中心自己重合，四个邻居变三个，系数自然从 4 变成 3。

| 邻居是什么 | 物理含义 | 对方程的修改 |
|:---|:---|:---|
| 空气（开放边界） | 压强为零（Dirichlet 型） | 空气 cell 的 $p$ 直接取 0 代入 |
| 固体 | 面上法向速度为零，面上压强梯度为零 | 去掉固体侧邻居的贡献，中心系数 4 变 3 |

### 解 Ax=b：从"20 世纪十大算法"说起

方程建好了：$A p = b$。那么这个非常大型的线性方程组，怎么解呢？

先看一个有意思的插曲。有个期刊评选过"20 世纪最重要的十大算法"——这是仁者见仁、智者见智的事，但这十个算法我觉得还挺有意思。其中加粗了四个，它们有个共同特点：**都可以用来解线性方程组**。今天要讲的 Krylov 子空间迭代法（Krylov subspace iteration method）就是其中之一，历史非常悠久。除了用迭代法解线性系统，你还可以去做矩阵分解（matrix decomposition），把矩阵 factorize 出来；如果要解泊松方程，还可以用快速傅里叶变换（FFT）；还可以用快速多极子方法（fast multipole method）去做 preconditioner。你看，$Ax = b$ 这么一个线性方程组，背后有这么多的学问。

顺便说一句，十大算法里的单纯形法（simplex method，解线性规划的）其实也可以用来解刚体模拟；Monte Carlo / MCMC 也可以拿来用作渲染。图形学里用到这些算法的地方很多；反过来说明，这些算法确实在各个领域都有很好的应用。

回到解线性系统本身。解法有很多种，先分两大类：

| | 直接法（direct solver） | 迭代法（iterative solver） |
|:---|:---|:---|
| 怎么给解 | 一次性把解算出来 | 先得到一个解的估计，在其上不断改进 |
| 代表 | PARDISO | Gauss-Seidel、Jacobi、SOR、共轭梯度…… |
| 适用 | 系统不太大时省事、稳定 | 大系统；可搭配预条件加速 |

直接法里最有名的就是 PARDISO，大家也非常喜欢用它：只要把矩阵的系数形式构造出来喂给它，它就给你很稳定地解出来，省事而且性能也不低——系统比较小、不是特别大的时候还是很管用的。迭代法的变种就多了：Gauss-Seidel、Jacobi 这两个非常常用，还有 SOR 之类的其他迭代解法器，其中 damped Jacobi 我们之前已经讲过了。今天主要讲的，是预条件共轭梯度（preconditioned conjugate gradients），它属于 Krylov 子空间解法器中的一种。

这边要提一句：一个好的线性解法器，通常是由很多不同的 solver **组合**出来的。比如图形学里解泊松方程，一般的做法是：用共轭梯度（conjugate gradients），配 multigrid 做 preconditioner，multigrid 的每一层用 damped Jacobi 做 smoothing，最底下最小的一层用 PARDISO 这种直接法直接解掉——这基本上已经是图形学里求泊松方程的标配了。这里面的名词后面都会讲到，现在只要记住一件事：**solver 之间是可以组合的**。

### 矩阵 A 怎么存：稠密、稀疏，还是干脆不存

现在问题来了：我们怎么去表示这个 $A$？三维流体模拟里 $A$ 可能非常非常大——每一个 voxel 都得在 $A$ 里占一行。不过通常来说，如果你运气好的话，$A$ 有一些好性质：它通常是稀疏的（sparse）；运气再好一点，它还是对称的、并且正定——合起来叫对称正定（SPD）。

怎么存 $A$？它说白了就是个二维数组，有三种搞法。

第一种，最简单：把它存成一个稠密矩阵（dense matrix）。这在 $A$ 比较小的时候是 work 的，但不是特别 scalable——比如 $1024 \times 1024$ 你还存得下，如果你有一百万个 voxel（或者一百万个 pixel），你就存不下了，根本没有空间存它。

第二种：用稀疏矩阵（sparse matrix）来存 $A$。为什么可行？因为虽然 $A$ 的每一行可能有一百万个元素，但其中很可能只有十个是非零的，其余全部是零——全是零的元素就不用存了。稀疏矩阵的存储格式有很多很多种，CSR、COO 之类，这里不具体展开。

第三种，是图形学里常见的搞法：**不存 $A$**。什么意思？这叫 matrix-free，通常是对存储来说最高效的方法——由于不需要存 $A$ 的 entry，能省很多内存。对计算也有好处：大家不要觉得计算就只是加减乘除这种公式计算，从内存里 fetch data 也是计算的一部分。现代计算机体系结构里，memory bandwidth 和 FLOPs 比起来是非常昂贵的资源——内存很慢，CPU 很快（第九讲讲高性能物理模拟时会展开这一点）。于是你就要权衡：到底是在线把这个值算出来，还是预先算好放在内存里、每次去取——两种设计在不同情况下各有优劣。

对流体模拟里的泊松方程来说，一般来说大家是不存的，直接用 matrix-free 的方法表示 $A$。

> **结论**：图形学解泊松方程的默认姿势是 matrix-free——既省内存，也迎合"访存贵、计算便宜"的现代硬件现实。

### 共轭梯度法：十几行代码，先抄下来跑通

接下来讲 Krylov 子空间解法器（Krylov subspace solvers）——基本上是最有效的线性系统解法器之一，底下有很多很多变形。最知名的变形叫共轭梯度法（conjugate gradients），一般缩写成 CG——注意，跟 Computer Graphics 的 CG 不是一个 CG。图形学里除了 CG，有时还会用 CR（conjugate residuals），还有 GMRES，很少很少的情况会用到 BiCGStab。一开始的话，掌握 CG 就可以了，因为 CG 确实在很多情况下已经足够。

想学更多，有一本书：*An Introduction to the Conjugate Gradient Method Without the Agonizing Pain*——共轭梯度"无痛"教程。这本书写得非常好，出来几十年了，而且免费，作者直接把它挂在自己的主页上，大家可以下载来看。虽然他声称"无痛"，但你真要把它啃下来还是费点时间——我自己之前看的时候，说实话也费了一些时间，并不像他说的那样完全无痛。不过这标题也不算标题党：学习嘛，总是要有一点痛苦的，他只是帮你把痛苦减轻一点。

这本书还有个很坦白的来历。作者自己说，他写这本书的动机，是一开始看了很多共轭梯度的教程，一个都没看懂，最后干脆自己写了一个教程。所以如果你一开始理解不了共轭梯度在干什么，完全不用担心——大家都理解不了，这本身就是一个很 counterintuitive 的东西。

好消息是：共轭梯度实现起来非常容易，也就十几行代码。一开始没法理解没有关系，把这十几行代码记好或者抄好，你的 solver 基本上就是 work 的；等你拿到结果，再慢慢研究它为什么会是这个结果。

大概讲一讲这个算法在干什么：

```text
初始：算出残差 r（r = b - A x），取定初始搜索方向 p
      （注意：这里的 p 是 search direction，不是压强！）

循环：
  (1) 估计一个步长 alpha：x 沿 p 方向走多远，能更接近真解
  (2) x <- x + alpha * p           更新解的估计
  (3) r <- b - A x                 x 更新了，残差 r 也得跟着更新
  (4) 若 r 已经足够小 -> break，此时的 x 就是解
  (5) 估计一个 beta
  (6) p <- 用 r 和 beta * p 组合出新的搜索方向
回到 (1)
```

这里的 $p$ 是沿着解的搜索方向（search direction），和刚才压强的 $p$ 不是一个东西；$x$ 是对当前解的一个估计。每一轮循环里，先估计 $x$ 应该加上多少份 $p$（也就是 $\alpha$），使得 $x$ 能够更接近我们的解；更新了 $x$ 之后，按 $r = b - Ax$ 的定义，残差 $r$ 也得更新；更新完一看，如果 $r$ 已经足够小，就中断；否则再估计一个 $\beta$，用 $\beta p$ 和 $r$ 去更新出下一步的搜索方向，进入下一轮循环——这是一个不断迭代的过程。

至于 $\alpha$、$\beta$ 为什么这么取，需要比较深入的理解。直观上来讲，它是在一个 Krylov 子空间里做能量最小化，还是很有意思的一个过程，那本书里讲得非常清楚。至于 Krylov 子空间到底是什么，这里就不继续深入了。

### 条件数：迭代法快慢的标尺

说到迭代法解线性方程组，它的收敛速度（convergence rate）和一个指标联系非常密切——condition number（条件数）。这就涉及矩阵的特征系统，我们回顾一下什么是特征值与特征向量。

如果有一个非零向量 $x$，使得

$$A x = \lambda x$$

也就是说，$A$ 作用在 $x$ 上面，不改变 $x$ 的方向，只把长度缩放 $\lambda$ 倍——那么 $\lambda$ 就是 $A$ 的一个特征值，$x$ 就是 $A$ 的一个特征向量。一个矩阵可以有很多很多个特征值。

condition number 是什么？对这个矩阵的最大特征值除以最小特征值：

$$\kappa(A) = \frac{\lambda_{\max}}{\lambda_{\min}}$$

直观上怎么理解？这个矩阵如果作用到一个向量上面，在一些方向把它拉得非常长，在另一些方向又把它压得非常短，你就会觉得这个矩阵看起来"非常厉害"——它的 condition number 就会非常大。当然这是直观的理解。要注意，condition number 有很多很多种定义，我们这里采用的是通常对 SPD 矩阵的定义，你在其他地方可能会看到别的定义。但总体结论是不变的：**condition number 越小，收敛得越快**。

### 暖启动：拿上一帧的压强当初始猜测

另一个能提高迭代解法器收敛速度的 trick，叫 warm starting（暖启动）。概念很简单：如果解这个线性系统的时候，你的初始猜测（initial guess）已经和真正的解非常接近，那需要的迭代次数自然就少。

流体模拟里的 warm starting 是这么做的：这个线性系统解的是**每一步的压强场**。我们做一个假设——上一步的压强场，和这一步的压强场差别不是特别大。那怎么办？把上一步的压强场拿过来，当作这一步压强场的初始猜测，然后开始迭代。这样在某些情况下能显著减少收敛需要的迭代次数。

实际用下来的经验是：这个 trick 对 Jacobi、Gauss-Seidel 或者共轭梯度都非常非常好用，但对 multigrid 就不太好使。具体原因我没有研究过，直观上的猜测是：multigrid 的 preconditioner 会 distort（扭歪）你的解空间。

这边来演示一下。这是我很早之前写的一个求解器 demo，有一个参数叫 `warm_starting`。把它关掉，只跑固定的、很少的 Jacobi 迭代次数（当然远远没迭代到收敛），你会看到流体的体积在不断缩小。为什么体积会缩小？就是因为压强场没解好：压强场解好的话，经过投影之后速度场是无散的，无散的速度场体积就不会放大或者缩小；压强场解得不好，速度场就会有散度，体积就会放大或者缩小。把 warm starting 开起来，很少的迭代次数就能把压强场解到非常准，速度场就更接近无散，体积就保持住了，效果就会更好。

> **结论**：压强解得准，投影后的速度场才无散；速度场无散，体积才不增不减。这条因果链到总结时还会再用一次。

### 预条件：找一个近似又好逆的 M

condition number 越大，迭代法需要的时间就越长、迭代次数就越多。有没有办法让 $A$ 的 condition number 变小一点？$A$ 本身是动不了的，但技巧是有的——这叫做 preconditioning（预条件）。

解 $Ax = b$ 的时候，如果 $M$ 是一个可逆矩阵，那么 $Ax = b$ 其实等价于

$$M^{-1}A\,x = M^{-1}b$$

就是把方程左右两边各乘上一个 $M^{-1}$ 而已。为什么这会有帮助？因为有的时候，$M^{-1}A$ 的 condition number 会比 $A$ 自己的更小，或者说它的 eigenvalue clustering（特征值聚集）比 $A$ 自己更好——特征值聚集正是共轭梯度解法器决定收敛迭代次数的一个 metric，这个可以去看之前那本 CG 的书。

这边有个问题：有同学会问，为什么不直接让 $M = A$ 呢？这其实是很有意思的一个问题。如果 $M = A$，方程就变成了 $x = M^{-1}b$——那根本就不用解了。但为什么不能这么做？因为一旦你能让 $M = A$，就意味着你能 invert 这个 $A$ 了，那你根本就不需要 preconditioner 了。**正是因为 $A$ 的逆算不出来，我们才需要做 preconditioning**。所以一般来说，$M$ 取的是一个和 $A$ 近似的、而且很容易求逆的矩阵。

哪些矩阵容易求逆呢？对角阵——直接把对角线上的元素逐个取倒数，就得到了它的逆。于是就有了 Jacobi preconditioner，有的地方也叫 diagonal preconditioner。还有的地方会用 incomplete Cholesky（不完全 Cholesky 分解）——Robert Bridson 那本流体的书里，就讲了用它做预条件的 PCG。

今天我们主要讲的是 multigrid（多重网格）：它是一个收敛非常快的 preconditioner，其实是在近似地 invert $A$。现在 multigrid 基本上已经成为图形学里做压力投影的标配了，大家还是要能够实现它——它很容易实现，而且效果非常非常好。

最后提醒一句：preconditioner 不一定要能写成一个矩阵的形式。只要你有一个 fast multipole method，同样可以把它用作 preconditioner——只要它是一个 general 的 linear operator 就可以。

### 多重网格：在多个尺度上消灭残差

multigrid 为什么能又快又好地近似 invert $A$？大家想：如果只在原来的网格上建立方程，我们的拉普拉斯离散是关于一个 cell 和它周围四个 cell 的 five-point stencil——每一次做这个算子，它能"看到"的 cell 非常少，只有五个。但很多时候你会发现，速度场的散度可能是一个 very large scale、low frequency 的东西——这种低频的散度，一个只盯着五个格子的局部算子是 capture 不住的。

怎么办？搞一个 multi-resolution（多分辨率）的方法：把 residual（余量）不断地做 restriction——把四个格子合并成一个格子；然后在合并后的格子上再做 smoothing；再算 residual，再做 restriction……这样建立起一系列的网格，从最细的网格一直到最粗的网格。到了最粗那层，线性系统已经非常小了。小的系统怎么解比较快？之前还提到过：用 direct solver（比如 PARDISO）；当然如果你懒，直接在这个小系统上叠很多次 Jacobi，那也没有问题。

一句话概括 multigrid 的 idea：把 residual 做一个 multiresolution 的处理，使得我们可以在**多个尺度上消灭 residual**。

```text
最细网格 ──smoothing──► 残差 ──restriction（4 格并 1 格）──► 更粗网格
更粗网格 ──smoothing──► 残差 ──restriction───────────────► 更粗网格
   ……一层层向下，直到最粗一层：方程已经非常小
最粗一层 ──► direct solver 直接解掉
然后逐层 prolongation，把粗层解出的修正插值送回细层
```

multigrid 的设计空间非常大：有 restriction、prolongation，有 V-cycle、W-cycle 等好多种不同的递归方式，大家可以去看推荐的资料。smoother 可以用 Gauss-Seidel，可以用 Jacobi，可以用 damped Jacobi——好的解法器是由简单的解法器组合起来的，smoother 也不例外，可以是各种各样。还有层数的选择：层数太少，最 coarse 那一层的 voxel 数目会非常多，解起来很慢；层太多、粗化过头，又会逐渐失去对原来问题的把握——这里有个 trade-off。一般大家的搞法是：不断做 coarsen，直到最 coarse 一层的未知量数目能够被 direct solver 高效解决的时候，就不再继续 coarsen。最底层的 solver 用暴力 Jacobi（我刚才说的偷懒方法）或者 direct solver 都行。此外，每一层做多少次 smoothing 迭代需要设计，coarse grid 和边界条件怎么处理（比如 Galerkin coarsening 这类技巧）——后面的话题还有很多很多，我们就不展开了。

说这么多，其实你要实现起来并不难，我们有参考的实现，Taichi 里也有 multigrid 的例子。一般来说，如果你在 regular grid 上解泊松方程，multigrid 基本是少不了的：现在你要发一篇 SIGGRAPH，解泊松方程不用 multigrid，别人都会质疑你这个性能是不是有问题。

推荐两个材料：一个是 *A Multigrid Tutorial*，非常好的一个教程；另一个是图形学里的一篇多重网格论文——不是最早的一篇，但非常容易读懂：*A Parallel Multigrid Poisson Solver for Fluids Simulation on Large Grids*。

### MGPCG：图形学解泊松方程的标配

multigrid 很少单独拿来当 solver 用，一般大家都是把它用作 CG 的 preconditioner，这样最后得到的东西就叫 multigrid preconditioned conjugate gradients——MGPCG。

我们来跑一跑（Taichi 自带的 `mgpcg_advanced` 示例，是一个三维泊松方程求解器）。输出里每个 iteration 就是一次共轭梯度迭代。用了 MGPCG，只需要**六个 iteration**，就可以把 residual 从一个非常大的数缩到非常小的一个数。当然，用 MGPCG 之后每个 iteration 也会贵很多，但总体来说，减少的迭代数量还是能够抵消单次迭代变贵的成本——所以大家解泊松方程基本上都用 MGPCG。

我把它现场改一改给大家看：这个示例里有一个 `use_multigrid` 参数，把它改成 false、关掉 multigrid，只用裸的 CG 解同样的一个系统。可以看到，residual 掉落的速度明显变慢了——这已经二十个 iteration 了，还没解完。我也不让它跑了，再跑下去可能到下课也收敛不了。

multigrid 有一个性质：写得好的话，residual 基本上是**迭代一次少一个数量级**。所以不管系统有多大，multigrid 的迭代次数通常是固定的——比如迭代十次，CG 加 multigrid 基本就能收敛。而裸 CG 的迭代次数，一般来说可以认为随线性系统的边长线性增长。所以系统规模越大，用 multigrid 的收益就越好。

| | MGPCG | 裸 CG |
|:---|:---|:---|
| residual 下降速度 | 迭代一次约降一个数量级 | 明显更慢 |
| 迭代次数与规模的关系 | 基本是常数（十次量级） | 随系统边长线性增长 |
| 单次迭代成本 | 更贵 | 更便宜 |

这个 example 其实很简单，用了维度无关编程：把里面的 `dimension` 改成 2，就是一个二维的 multigrid；改成 3，就是三维的。当然，前面说过 multigrid 的设计可以非常非常复杂——这个示例是一个高度简化版的 multigrid，所有地方都用了最简单的方案，方便大家理解它在干啥。

### 收个总账：一个时间步就是平流加投影

讲了这么多，其实都在讲欧拉视角的流体模拟。图形学里，对于每一个 time step，其实就两个关键操作：**advection** 和 **projection**。

advection 就是"移动"流体场。这里唯一关键的事情：要用一个好的 advection scheme，让它的 numerical viscosity（数值黏性）或者 numerical diffusion 尽量小。数值黏性高的话，流体本身不黏也会变得很黏，看起来就没有那些很刺激的效果——图形圈里大家还是喜欢看雷诺数比较大的流体模拟。要找数值黏性比较小的 scheme，可以采用 MacCormack，可以用 BFECC，还可以用 particle advection——particle advection 后面我们会讲到。

第二个关键操作是 projection：保证速度场是 divergence-free 的，也就是无散。为什么必须无散？因为速度场无散，流体的体积才得以保持。还记得刚才那个 demo 吗？如果压强解得不好，比如只迭代十次就把迭代掐了，得到的压强解就不准确，速度场就会有散度；有散度，流体就不能保持自己的体积，看起来就会很奇怪。当然，要把速度场迭代到无散，需要一个很好的线性 solver——通常大家用的就是 MGPCG。

这里顺便提一下：Taichi 里有一个叫 stable fluid 的 demo，是社区大神写的一个流体模拟 demo，一个可以交互的演示，大家可以玩一玩。我没记错的话，它用的是 semi-Lagrangian advection 加上 Jacobi projection。用 semi-Lagrangian 加 Jacobi 也有好处——比较容易实现；但大家可以看到，它还是有一点点黏，压强也不是完全无损的：你很猛地去拖一拖，会看到体积有被压缩或者膨胀的现象。有兴趣的话可以把它改一改：把平流改成 MacCormack，然后把压强求解至少换成 conjugate gradients。

### 被丢掉的能量与涡量：两篇值得动手的论文

advection 和 projection 各自内部要做好，它们俩**怎么组合**也很有讲究。这里介绍一个问题：原始的速度场做一次 advection 之后，得到的速度场里，既有有散度的分量，也有无散的分量。接着做 projection，把有散度的那个分量投影掉——这一投影，动能就会有损失。动能损失了，等价于在系统里引入了 numerical viscosity；或者说，速度场的 vorticity（涡量）被丢掉了一部分。丢掉了，你就得想个办法把它恢复出来。

```text
常规做法：
  advection ─────────────────► projection
                                （有散分量在这里被投影掉，动能损失）

Advection-Reflection：
  advection(前一半) ─► projection(能量无损，把状态"搬"过去) ─► advection(后一半) ─► projection
                                                                      （损失小很多）
```

这条路线推荐两篇文章。第一篇是张心欣师兄的 IVOCK（SIGGRAPH 2015，*Restoring the Missing Vorticity in Advection-Projection Fluid Solvers*），挺有意思的一篇文章：通过重建被丢掉涡量的速度场，来降低流体的数值黏性。

第二篇叫 Advection-Reflection solver（SIGGRAPH 2018，*An Advection-Reflection Solver for Detail-Preserving Fluid Simulation*），idea 是：既然 advection 之后做 projection 会丢掉一部分能量，那我不把散度分量一次性 project 掉——我在 advection 的中间先做一次对能量没有损失的 projection，把这个点给它移到那儿；然后做剩下的一半 advection；这样最后那一次 projection 的能量损失就会小很多。

这篇 paper 大家可以去尝试实现一下——它非常容易实现。如果你已经有一个 multigrid，再加上一个好的 pressure projection solver，稍微改改代码，可能五行代码就能实现它，而且效果非常非常的惊人。这是 SIGGRAPH 2018 里我觉得非常好的一篇 paper：既容易实现，效果又好，paper 里的推导也很有意思。作业如果做有兴趣，可以实现一下，我觉得收获会很多。

今天这一讲，讲泊松方程与它的快速解法。先自嘲一句：看了上一讲的课件，还能留存到今天的同学，已经挺不容易了——所以今天的目标，还是那四个字，通俗易懂。

之前我们解泊松方程，走的都是偏微分方程的路子：剖区域、离散、求解。今天换一个视角——讨论开空间的泊松问题，用基础解积分的形式来看待它。别小看这个视角的转换：它一路通向被誉为"20 世纪十大算法之一"的快速多极展开。人们究竟利用了怎样的思想、怎样的分析方法，才能在线性时间里算完一个 $O(N^2)$ 的求和问题？这个问题，值得一步步拆开看。

### 从万有引力说起：一个 O(N²) 的求和

这样的泊松问题，很多同学高中就已经接触过了——万有引力。我们通常说：引力势场满足一个关于密度的泊松方程；而任意两点之间的受力，就是这个势场的梯度。把梯度运算代入基础解的求和系统，就得到了高中时非常熟悉的万有引力公式：力与距离的平方成反比，方向沿着两个粒子之间的连线，前面还乘一个系数，与质量成正比。

$$\mathbf{F}(x_i)\;=\;\sum_{j}\; m_i\, m_j\;\frac{x_j - x_i}{\lvert x_j - x_i\rvert^{3}}\qquad(\text{整体再乘一个常数系数})$$

梯度把 $1/r$ 变成 $1/r^2$；写成矢量时，方向除以 $r$ 做归一化，分母就多出一个 $r$，所以是 $r^3$——正对应"平方反比、沿连线方向"。

现在盯着这个求和表达式看：如果万有引力系统中有 $N$ 个粒子，要对 $M$ 个点求力，直接求和需要 $O(N\cdot M)$ 的时间；两者同量级时就是 $O(N^2)$。这个标度（scaling）很差，所以我们需要快速的方法来降低它的标度。这样一类方法，就叫做快速多极展开（Fast Multipole Method，FMM）——它被誉为 20 世纪十大算法之一。它究竟用了怎样的思想，使得人们能够在线性时间里计算这个 $O(N^2)$ 的求和？我们一步步分解来看。

### 用复数看二维泊松：把一团电荷缩成一个点

先把维度降下来。为了简化、让概念清晰地传达，我们从二维的泊松方程和它的基础解讲起。为了方便，用复数来表达坐标：

$$\phi(z)\;=\;\sum_{j} q_j\,\log\bigl(z - z_j\bigr)$$

这个求和表达式的实部，就是我们要的势函数解；而 $\log\lvert z\rvert$，就是二维情况下的格林函数。

现在考虑一个圆，以及它在远处 $z$ 点引发的势。在圆心处做泰勒展开，会直接得到这样一个关系：$z$ 点的势，等于这个电荷的带电量在零点处产生的势，加上一个高阶项。接下来是关键一步——想象在靠近零点的地方有很多很多带电的电荷，它们对 $z$ 点的作用都对零点做泰勒展开，然后把所有式子加起来。总势可以拆成两个部分：

- 第一部分，就好像是来自零点的一个带了更大电荷的"等效电荷"，对 $z$ 点的势作用；
- 第二部分是一些高阶项，来自这团电荷的形状。

抽象成公式：大 $Q$ 是零点附近所有电荷电量的总和，$q_k$ 是做完泰勒展开后得到的各阶高阶项，

$$\phi(z)\;=\;Q\,\log z\;+\;\sum_{k=1}^{p}\frac{q_k}{z^{k}}$$

后面这一串高阶项是几何收敛的——离得越远收敛越快，取很少几阶就够用（具体的系数符号约定不影响这里的讨论，抓住结构就够了）。

> **定义**：多极展开（multipole expansion）——一团电荷在远处的势，等于"位于中心、带总电量 $Q$ 的等效点电荷的势"，加上一串几何收敛的高阶修正项 $q_k$。这几阶修正里，编码的是这团电荷"形状"的信息。

### 树代码：第一次加速到 O(N log N)

有了多极展开，立刻可以得到一个 $O(N\log N)$ 的算法，它就是所谓的树代码（tree code）。做法分两步。

第一步，把空间里的众多电荷做网格划分；在每个格子的中心点计算 $Q$ 和 $q_k$，使得离这个格子较远处的场，可以被这组 $Q$、$q_k$ 近似。第二步，不断逐层往上抽象：把格子的展开卷到上一层格子，一层层卷上去，最后得到一个特别粗的网格——里面存的 $Q$、$q_k$，代表着所有属于这个格子的电量所对应的泰勒展开形式。

现在想求空间中任意一点的电势或重力势，怎么办？通过树状结构的遍历走到叶节点：离叶节点近的格子，用直接求和公式计算；距离变远之后，因为远场基本上是比较平滑的，就用那些记录在格子中心点处的泰勒展开去近似远场势的影响——一层层往外，直到最粗糙的那一级解析度上的 $Q$、$q_k$。这样得到的远场计算是相当精准的。因为要对每一个格子做 $O(\log N)$ 次这样的计算，所以总计算量是 $O(N\log N)$。

有同学问：这种类似八叉树的近似方法，有的地方叫 tree code，有的地方叫 Barnes-Hut，还有很多很多别的名字——它们是一个东西吗？

是一个东西，全都是一个东西。事实上 tree code 就是 Barnes-Hut 发明的——或者说，发现的。

### M2M：让多极展开搬家

知道了 $O(N\log N)$ 的树代码，怎么再往前一步、得到线性时间的算法？这一步是关键。

假设在 $z_1$ 中心处有一团电子云，我们已经统计出它的 $Q$ 和 $q_k$，它能精确估计远场 $z$ 处的电势。要问的是：如何通过这团电子云的 $Q$、$q_k$，直接构造出另外一个中心 $z_2$ 处的 $Q$、$q_k$，使得 $z$ 点的势同样能被 $z_2$ 处的展开精确表达？这就是把一个 multipole 转移到新的中心去，所以叫 multipole-to-multipole（M2M）变换。

方法本身不复杂：既然有了 $z_1$ 处电势的计算公式，就对它在 $z_2$ 处重新做泰勒展开、重写公式，得到一个新形态：

$$\phi(z)\;=\;Q\,\log(z - z_2)\;+\;\sum_{k=1}^{p}\frac{b_k}{(z - z_2)^{k}}$$

回想多极展开的原型，会发现两者形式同构：都有一个大的 $Q$，代表所有电子电量的和；都有一串高阶余项（原来的 $q_k$，现在记作 $b_k$）；收敛性同样都是几何收敛。

那 $b_k$ 到底是什么？它是 $q_k$ 的一个泛化。看 $b_k$ 的第一项：每个子团的总电量乘上位移的 $k$ 次幂再除以 $k$。回想当初从电子算 $q_k$，第一项是关于各电荷 $q_j$ 的一个和——把每个子团当作一个带电单元代进去，这两项正好对上；$b_k$ 还有自己的高阶项，由原来那些 $q_k$ 直接推导计算出来。

形象地说：电子就是一种十分特殊的 multipole——它带电量 $q$（它的 $q_0$ 就是它自己带的电量），所有 $q_k$ 项都是零。直接套用 $b_k$ 的计算公式，就能复现"从电子累加到一个点"的多极展开。而当我们从 $s$ 个已知的 multipole 去构造一个新的 multipole 时，每一个已知的 multipole 就又相当于一个电子：用它的总电量加上其余高阶项（rest of terms），去计算新展开的 $b_k$；注意 $b_k$ 第一项里的 $Q$，是这些小电子云所带的总电量。这样一种操作，实际上就是把 multipole 直接 translate 到了一个新的 multipole 身上。

刚才可能讲得有点迷糊，用代码的形式把整个过程再展开一遍。一个 multipole 的结构包含两个重要信息：它的展开中心在哪；以及一串 $q_k$ 项——在我们讨论的范围内，它们是复数，表达它的所有高阶项。

```python
# （伪代码）
class Multipole:
    center: complex        # 展开中心在哪
    terms:  list[complex]  # q0, q1, ..., qp：总电量与各阶高阶项（复数）

# 源电荷（电子）是一个特殊的 Multipole：
#   center = 电荷自己的坐标；q0 = 它自己带的电量；其余 qk = 0

def m2m(q_list):                       # q_list: vector[Multipole]
    # 1) 新的中心坐标：对各子 multipole 的中心做加权和
    center_new = weighted_sum(m.center for m in q_list)
    # 2) 新的 q0：所有子 multipole 的 q0 之和
    q0_new = sum(m.terms[0] for m in q_list)
    # 3) 高阶项：k = 1..p，逐阶调用 compute_bk 公式
    bk_new = [compute_bk(q_list, center_new, k) for k in range(1, P + 1)]
    return Multipole(center_new, [q0_new] + bk_new)
```

到这里，"从电子到 multipole"以及"从 multipole 到 multipole"的转变程序，我们就都构造出来了。

### M2L：把远场翻译成近场的"插值"

知道了如何把 multipole 转变为另一个 multipole，接下来有一个变得十分有趣的问题：如果在中心为 $c$ 的地方我们有了 multipole 展开——它能告诉我们任意一个 $z$ 点处准确的电势——那么如何把它转换成一个离 $z$ 距离很小、以 $z_1$ 为中心的 local 展开？

注意，这里不是 M2M。M2M 要求的是两个 multipole 都离目标点 $z$ 比较远；而现在的这个问题，是要把一个离 $z$ 比较远的 multipole，转化到离 $z$ 很近的地方、以 $z_1$ 为中心的 local。

> **易错点**：M2M 与 M2L 的分界就在"目标点离谁近"。展开的两端都离目标点远，用 M2M 搬家；要把远处的展开安放到离目标点很近的位置，就是 M2L。

这个 local 可以形象地想象成一个插值：一个局部邻域上的插值函数，使得 $z$ 附近的势函数能够很准确地被 $z_1$ 处的多项式表达出来。做完该做的数学，就得到这样的公式：local 的第一项 $Q\log(z_1 - c)$ 加上多极项的贡献——它实际上就是电势在这一处的值（一个 potential 值）；要 $z$ 点的电势，就是"$z_1$ 处的电势 + 一个高阶扰动"：

$$\phi(z)\;=\;b_0\;+\;\sum_{l=1}^{p} b_l\,(z - z_1)^{l}$$

由于 $z - z_1$ 是一个很微小的量（小于半径），而 $b_l$ 的量级由 $(z_1 - c)$ 的幂次控制，比值小于一——所以这一串又是几何收敛。local 的结构也就清楚了：记录自己的中心在哪里，外加一串系数 $b_0,\ldots,b_p$；其中 $b_0$ 不是别的，就是它中心处的电势值。

### L2L：只是坐标变换，公式却不轻

下一个问题：如果已经有一个 local 展开——它能表达自己半径范围内所有点的势——怎么把它转变成一个以 $c_2$ 为中心的 local，使得原来范围内的点都能被新中心的 local 准确表达？

其实这只是一个坐标变换：要把 $a_k(z - z_0)^k$ 的形式变到 $b_k(z - c_2)^k$ 的形式。这个事情，学完初中数学就能做了——展开、移项、合并同类项而已。计算上有一个叫 Horner scheme 的方法，用动态规划的思路加速这一串系数的计算。

到这儿相信有的同学会有一个问题：M2M 看起来也是一个中心的转移，L2L 也是中心转移，为什么 L2L 就比较简单，M2M 的形式会稍微复杂一点？

其实都差不多，没有简单多少。L2L 形式上只是写成了一个 $b_k$，但这个 $b_k$ 代表的是"这么一坨东西"；到了三维，式子会更加恶心——里面会出现二项式系数（binomial coefficients）那一大坨。

所以我的建议是：能不做 L2L 就不做，用插值的办法替代，构造一个插值就行了。这个替代方案，等讲完复杂度再展开。

### 多极子不是新发明：单极、偶极与八极

有同学问：这里说的 multipole，和物理里的电多极子之间有对应关系吗？

有，而且是 exactly 的对应关系：$b_0$ 是电单极子（monopole），$b_1$ 是电偶极子（dipole），以此类推，$b_n$ 就对应电 $2^n$ 极子——你都可以这样想象。

三维情况下，我们的方程是 $1/r$（准确说是 $1/r_{ij}$）。如果在笛卡尔坐标系下对它做泰勒展开，得到的一系列"极"——monopole、quadrupole、octupole（八极）……就分别对应物理上的那些概念。

### 上行与下行：线性时间是怎么来的

把刚才的整套操作再抽象一次，会看得更清楚：multipole expansion 实际上是在对几何做粗化（coarsening）——把电荷的分布粗化成一个带高阶信息的点；local expansion 实际上是在做插值。FMM 的整个流程，就是"先粗化、再插值"。

先看上行（bottom-up）。从电子出发：在格子的中心点算出 $Q$、$q_k$ 和中心坐标 $c$；再把格子上的 $Q$、$q_k$、$c$ 聚合到上一层格子。三维情况下，每往上一层格子数缩小到八分之一，总共会遍历过的格子数是

$$N+\frac{N}{8}+\frac{N}{64}+\cdots\;=\;O(N)$$

而每个格子上的计算量大约是 $c^p$（$p$ 是展开截断的阶数，是个小常数）。所以上行的计算复杂度是线性的。

再看下行（top-down）。下行要经历 M2L 和 L2L 两种变换。注意 M2L 的一个关键事实：对每一个格子来说，与它相对应的 multipole 数量是有限的——它并不去累加所有的 multipole，只需要累加在自己这一层上、和它"相对来说是 multipole"的那些格子。以一个黑色格子为例：围着它的那圈虚线格子是它的远场，这些远场对它的作用通过谁来完成？两件事：第一，从它的父节点去继承 local，并把父节点的 local 转变到自己这个格点中心上来；第二，在自己相应的这一层上，累加对自己来说是 multipole 的贡献。这样，每个格子的计算量是常数时间（大约也是 $c^p$），而这样的格子总共有多少呢？一样是 $N + N/8 + N/64 + \cdots$——所以下行时间总共也是 $O(N)$。

把树代码和 FMM 摆在一起，区别会更直观。要对 $x_1$、$x_2$ 两个点计算势值：树代码里，$x_1$ 要累加 1、2、3、4、5、6 这些格子对它的作用，$x_2$ 仍然要把这六个格子累加一遍——每个点约 $O(\log N)$ 的累加量，总复杂度 $O(N\log N)$。而 FMM 里，计算 $x_1$ 的所有贡献分两步：第一步，红框那个父节点格子上早已聚合好的、来自 1、2、3 号格子的贡献，通过 L2L 变换直接先拿过来；第二步，再累加本层远场 4、5、6 这三个节点的贡献。每一步都是常数时间。

| | 树代码（tree code） | 快速多极展开（FMM） |
| :--- | :--- | :--- |
| 远场贡献怎么来 | 每个目标点逐层向外、逐格累加 | 父节点先聚合，经 M2L 与 L2L 一次性继承 |
| 单个目标点的成本 | 约 $O(\log N)$ | $O(1)$（约 $c^p$） |
| 总复杂度 | $O(N\log N)$ | $O(N)$ |

> **结论**：上行粗化 $O(N)$，下行插值 $O(N)$，近邻直接求和每点常数——这就是 FMM 能成为线性时间复杂度算法的原因。

### 用插值偷懒，绕开最恶心的变换

前面这些 local-to-local 的变化式十分复杂，可以考虑一个更简单的情形：如果父节点不去计算 local，取而代之，在父节点的那几个 box 节点上，先用 multipole 的方法算出来自 1、2、3 号格子的贡献；等要计算 $x$ 的时候，通过一个双线性插值（三维就是三线性插值）先把这个贡献插值过来——因为远场足够平滑，所以认为插值是可行的——这不就等于已经拿到了来自 1、2、3 的贡献吗？然后再去累加 4、5、6 的贡献，并且把这些都计算在格子的格点上。这样就避免了 L2L 那套比较复杂的计算。我再说一遍这个流程：在父节点处用 multipole 的方法算 1、2、3 的贡献；往里先插值；插完值再算 4、5、6 的贡献；全部落在格点上。

说句实在话：那套公式的代码写出来也很恶心，可能有很多 bug 都不好修——公式实在太恶心了，换一个人都修不了。胡渊鸣昨天还打算自己看看能不能一天之内实现一遍，写着写着发现公式实在太多，一天肯定写不出来。所以大家一定要知道：这是一个连胡渊鸣都不可能在一天内写完的东西。

最后再把这张全图过一遍，它给了我们一个很好的总览视角：从 source particle 开始，先做 P2M 变换；然后做 M2M；然后 M2L；然后 L2L；最后 L2P；在目标粒子周围，再累加来自其他粒子的直接贡献。先是 bottom-up，再是 top-down——这就是整个快速多极展开的走法。

```text
[上行 bottom-up]
粒子源 ──P2M──▶ 最细层格子(记下 Q 与 q_k) ──M2M──▶ 粗一层 ──M2M──▶ ……
          逐层向上卷，格子数 N + N/8 + N/64 + …… = O(N)

[转折]
在最粗层：M2L —— 把这一层上"对面"的远场 multipole 变成 local

[下行 top-down]
最粗层 local ──L2L──▶ 粗一层 local ──L2L──▶ …… ──▶ 最细层 local ──L2P──▶ 目标点
目标点结果 ＝ local 值 ＋ 相邻格子的直接求和(P2P)
```

读图：左路自底向上，把电荷信息"粗化"成各层的 multipole；右路自顶向下，把远场影响"插值"回每个格子的 local；最后近邻用直接求和补上细节。

你大概已经发现，这个计算结构和多重网格法（multigrid）有异曲同工之妙——同样存在空间多分辨率上 bottom-up 与 top-down 的组织方式。

### 到了三维：球谐展开与一份 short course

前面一直拿二维说事。到了三维，泰勒展开可以以两种形式完成：一种是在笛卡尔坐标系（Cartesian space）下展开；另一种是在球谐坐标系下展开。在球谐坐标系下展开，得到的就是原始的 fast multipole method。

想看更多细节，推荐一份 A Short Course on Fast Multipole Methods——它是 Greengard 写的，而 Greengard 正是 FMM 这个算法的发现者，所以这份 short course 写得相当好。

有同学顺势问：是不是任意的势函数都可以用多极展开？这个问题就有意思了——它关系到"什么样的核才能被展开"。那份 short course 里有讨论，还有一个引理的证明：首先你这个核要满足一个条件，才能进行展开；满足这种条件的核，我们叫做退化核（degenerate kernel）。通常源于物理应用的这些核，我们可以认为都是能被展开的——包括高斯核、热力学的核、我们的格林函数、万有引力的核。至于任意的核能不能展开，就要去套那个引理验证一下——不是任意的。

> **提示**：别把"多极展开"当成万金油。核要先通过退化核（degenerate kernel）的引理检验；好在源自物理的核——高斯核、热核、格林函数、引力核——都过关。

### 这些方法都在哪里干活

快速多极展开有一批很有趣、也很有分量的应用。

**宇宙学与暗物质。** 最直接的应用是计算引力、以及重力场各种信息的变化：除了帮我们在宇宙学（cosmology）方面预测星体的运动，还有人用它来搜寻暗物质（dark matter）。这名字很酷炫，逻辑却不神秘：当我们观测到一些带有星体的质量、或者对一块区域有了质量估计，并且知道它在怎么运行时，就可以借助仿真分析的办法，看计算出来的轨迹是否真的符合观察到的现象——如果差异很大，说明存在我们没有看到的质量，这不就是所谓的暗物质吗？拿 fast multipole method 当关键词搜论文，真的会搜到一批 dark matter 的工作。

**静电场与分子动力学。** 静电场（electrostatics）和万有引力具有完全一样的泊松方程——这里我要强调一下：正负号不一样，但形式完全一样。它除了能在给定物体表面电荷分布时算出静电场的势与方向，还有一件更重要的事：在分子与分子之间、在分子尺度上，静电作用力是主要的作用力。因此它被用进分子动力学分析——在分子动力学软件里，每一个时间步计算分子静电作用力，是十分核心的任务；而分子动力学分析，又有助于人们做肿瘤方面的研究、做靶向药的设计。新冠疫情期间，人们就用这样的方法来分析新冠病毒与 ACE2 受体最好的结合位点在哪里。很多同学可能都不知道，原来泊松方程在这里扮演着如此重要的角色。

**声学与电磁。** 有了 Helmholtz 方程的求解，就可以算声场：比如在某个位置放一个扬声器，计算整个范围内声压的分布。电磁（electromagnetics）方向同样如此：设计某种舰体时，通过电磁场的分析找出它可能被雷达探测到的半径，再反向优化它的形体设计，使它尽可能达到更好的隐蔽性。声学与电磁这两件事，都来自对 Helmholtz 方程的求解。

### 边界元方法：把偏微分方程变成积分方程

接下来是一个十分重要的应用：边界元方法（Boundary Element Method，BEM）。

边界元求解的是一个拉普拉斯方程。这个方程告诉我们：整个场里是"有势无源"的。而有势无源的场有一个非常有意思的性质——它的所有属性，被边界处的值唯一决定。比如在边界 $\Gamma_1$ 上我们知道 $\partial\phi/\partial n$（法向导数），在边界 $\Gamma_2$ 上我们知道 $\phi$ 的值，那么剩下整个场里所有的数值就都确定了。而这个确定，可以通过一个解析的表达式得到——这个表达式就是边界积分方程（这里已经把它写成了离散形式）。

所以边界元做的事情是：把一个带边界条件的偏微分方程，转化成一个积分方程。

这个积分方程有一个特点：矩阵是稠密的——因为每一个点都来自其他所有点的作用。但通常它的条件数很好：如果用一个 Krylov 子空间的迭代法去求解这个积分方程，通常在常数次迭代里就能找到它的解。

> **提示**：稠密不等于难解。边界元的条件数通常很好，迭代次数是常数；真正的开销在每一次迭代里的稠密矩阵向量乘。

稠密矩阵的开销，可以拿多重网格法来对比一下。设二维 full domain 有 $N^2$ 个自由度：multigrid 在常数时间内收敛，总计算量大约是 $O(N^2)$；边界元呢？$N^2$ 的域只有边界，所以大约有 $N$ 个 element；用 BiCGStab 这样的迭代法，它可以在常数时间内收敛，但每一次迭代要用 $O(N^2)$ 的时间做稠密矩阵向量乘——所以总计算量还是 $O(N^2)$，和 multigrid 打平手（前提是 multigrid 用 matrix-free 的方式实现）。到了三维，情况就糟糕了：full domain 是 $N^3$，multigrid 总共 $O(N^3)$；边界元这时候有 $N^2$ 个 elements，稠密矩阵乘的代价是 $O(N^4)$ 的 computation——即使它能在常数时间内收敛，总共也是 $O(N^4)$，永远无法战胜 multigrid。

| 方法 | 二维总计算量 | 三维总计算量 |
| :--- | :--- | :--- |
| multigrid 解偏微分方程 | $O(N^2)$ | $O(N^3)$ |
| 边界元 + 稠密矩阵向量乘 | $O(N^2)$（打平手） | $O(N^4)$（完败） |
| 边界元 + FMM 快速求和 | $O(N)$ | $O(N^2)$ |

最后一行怎么来的？回到积分求和本身：原来那一步是"矩阵乘以向量"，如果用之前推导的快速多极展开，以 matrix-free 的形式、用 FMM 去计算这个结果——那么在 2D 我们就是 $O(N)$，打败了多重网格法；在 3D 就是 $O(N^2)$，也打败了多重网格法。

边界元还有一个十分有趣的性质：它是半解析的（semi-analytic）。当对边界的划分精细到一定程度，它给出的答案几乎就是解析解；换句话说，不用特别细致的边界元划分，就已经可以得到很好的答案。

用边界元可以求解哪些问题？比如波浪。对一个模拟区域（simulation domain），如果用 N–S 方程的方法来求解，需要把整个 domain 体积化，这就需要很多很多的计算单元；而如果用边界元的方法在边界上求势方程（或者说伯努利方程），得到的物理虽然没有 N–S 方程所表达的那么复杂，但要知道，势流方程已经是对 N–S 方程很好的一个近似了——它只是假设流场无粘，而且流速本身是一个场。这种情况下，我们可以求解出复杂波浪运动的形态。对很多应用来讲，波浪——特别是远处波浪的形态——已经是很核心的研究任务，所以在这种情况下，使用边界元求解显然是更明智的。

再比如声压。通过边界元求解前面说的 Helmholtz 方程：在已知一个物体外形的时候，就可以在它周围任意范围内计算声压。算声压有什么好处？可以知道它在以一定速度飞行的过程中所产生的噪音、所产生的可被探测的声音，影响范围是多少。

### 涡方法：四个涡点的涡环穿越

在图形学以及很多相关领域，我们很关心的还有湍流，也就是涡流的计算。涡流来自一个矢量的泊松方程：先通过求解一个矢量泊松方程，得到流函数（stream function）；再对流函数施加 curl（旋度）算子，得到速度场。而这个速度场反过来又能写成一个求和问题——于是快速求和又可以用来求解涡流。

求解涡流这个问题特别有意思。看这样一个案例：两个涡环（vortex ring）一旦产生运动，会做一种"你中有我、我中有你"的交叠上升，也就是 leapfrogging。

想通过 N–S 方程去捕捉这个现象，其实十分痛苦：需要很多自由度——我用了 $512^2$ 的网格，要用比较高级的高阶时间积分方案，solver 可能要很多很多行 C++ 代码（即使用太极来写也有很多行），才能差不多模拟出这个 leapfrog；而且最后两个环还是很快就融合了。

现在换成涡方法直接来写：时间积分方法可以简单到就是一个前向欧拉；整个计算中只有 4 个自由度——4 个涡点，准确说是 $4\times 3$ 个坐标分量。代码量呢？C++ 大概百来行；太极里行数更少，七八十行——还算上了可视化，刨掉初始化两个涡的位置那些，核心大概 40 行左右。就这么点代码，我们就能捕捉出这个复杂的运动现象；而同样的现象，通过 N–S 方程的求解要花很大的力气才能做到。

> **结论**：同一个涡环穿越，N–S 方程要 $512^2$ 的网格加高阶时间积分，涡方法只要 4 个涡点加前向欧拉、约 40 行代码——差距就在自由度的组织方式上。

### 涡方法遇上固体边界：卡门涡街从哪来

有同学问：涡方法如何处理固体边界？

答案是：求解边界积分方程。回到边界元的那套视角——我们要在边界上找一个涡分布（或者按之前的说法，一个"电荷分布"）。这里要区分两种情况：你要做粘性流还是无粘流。

**无粘流**：只要求法向不穿透。所以要在边界上找出一个"电子"分布——你可以想象在边界上布一层电荷——它能 introduce 一个速度场、一个势流场（potential flow），这个势流场刚好可以 cancel 掉边界处那些本来会穿透的速度。立的方程就是：这些边界源产生的势流场，点乘法线方向 $n_i$，正好等于负的、已知的速度点乘 $n$。

**粘性流**：再多解一个额外的方程——沿着边界再找一个涡片（vortex sheet），它 introduce 的速度场，刚好能 cancel 切向（tangent）方向上的分量。

求出来的这层边界涡强度，接下来怎么办？在一个纯粒子的方法里不太好做热扩散，所以可能要通过随机游走（random walk），或者通过一些能量总和不变的扩散方式，把边界上求出来的涡量 emit 到周围的流场里去。这样，就能形成卡门涡街了。

> **提示**：在这个框架里，固体边界本质上是一个涡的源（vortex source）：无滑移边界条件会不断"搓出"涡片（vortex sheet），再把它们释放进流场。

把这个流程按时序走一遍：假设 $n$ 时刻所有涡粒子已知、速度已知——先做对流，把涡粒子走一下；然后从涡粒子里面求出一个速度场。这个速度在边界上不是严格满足的（或者说，一定不是严格满足的），于是有一个分量要被 cancel 掉——把边界上的速度点乘切向或点乘法向，就得到要 cancel 的量。这个量由谁来 cancel？由边界处的"电子"引发的势流场，或者说边界上的 vortex sheet 引发的速度场来 cancel。求出这两样之后：电荷场不用管，它就是个势流场，无限延伸；剩下那个 vortex，再通过热扩散的形式，把它上面的涡量扩散到系统里去——就 emit 出了新的涡粒子。

顺着这个思路，胡渊鸣补了一句：这其实就是写一个普通的 vortex solver，然后在边界上以某种方式不断 seed 涡，应该也能搞出一个卡门涡街。确实——对二维圆柱和给定的来流速度，这个边界分布是有解析表达式的，找一下就能找到，按它去 seed，出来的就是卡门涡街。而且卡门涡街特别炫，各种湍流、各种 turbulent。

顺带一个真事：之前课程作业里，有一位同学用 LBM 写了卡门涡街，还被中科院物理所拿去写了一篇科普文章，很有意思。

### 三种求和与一个黑盒

到这里差不多可以总结一下了。我们总共有这么几种 summation 是要求解的：

1. **电场力与万有引力**：就是势场在 $x$ 点的梯度。求和核与半径平方成反比、与质量成正比，方向沿着距离的方向——梯度运算里可以消掉一个 $r$。
2. **边界元中的核**：要对每一个遍历的 $j$，拿 $x_i - x_j$ 方向的梯度，去点乘 $j$ 处的法线 $n_j$。这一点乘会让 kernel 变得很不一样，所以要专门考虑它怎么求。
3. **Biot–Savart**：它很像万有引力的公式，只不过用的是叉乘的形式。

现在问题来了。如果给大家一个 routine，叫 `computeGravity`——给定一些电子源或重力源 $S$，即 $n$ 个带质量的粒子，它就能告诉你所有目标点位置处的引力，也就是受力。把这个 routine 当作 black box，怎么去求剩下两种求和？

**边界积分的做法**，课上直接讲透。含 $n_j$ 的那个东西，可以按坐标拆成三个分量（把格林函数记作 $G$）：

$$
abla G(x_i - x_j)\cdot n_j\;=\;n_j^{x}\,\partial_x G\;+\;n_j^{y}\,\partial_y G\;+\;n_j^{z}\,\partial_z G$$

于是这样来做：从原来的源 $S$ 构造出三个不同的源——把每个 $s_i$ 自己原有的带电量，乘以它当初法线的 $x$ 分量（或 $y$ 分量、$z$ 分量），得到三组新源；对这三组不同的源分别做 `computeGravity` 操作；然后分别把第一个结果的 $x$ 分量、第二个结果的 $y$ 分量、第三个结果的 $z$ 分量加起来——实际上就得到了对边界积分那个式子的求和值。

中间具体的过程，希望同学们自己拿支笔写一写，很容易就能想通，这是很显然的。

至于 Biot–Savart 怎么来做，就留给大家作为一个家庭作业了。注意：我们是对 $j$ 遍历的。这主要是一个数学公式的推导与转化过程，实现起来不用，拿支笔推一下就行；做了的话，也欢迎在论坛上和其他同学分享分享。

### P³M：把偏微分方程视角和求和视角混起来

剩下的两种快速求和方法，一种叫 P³M，一种叫与核无关（kernel independent）的快速求和。先讲 P³M。

P³M 的观点比较 ingenious（巧）：我们通过混合偏微分方程的视角和 summation 的视角，得到 P³M 这个方法。注意到的关键事实是：每一种 summation，其实都对应着一个偏微分方程。

于是可以这样干：如果有一些粒子，先做 particle-to-grid（P2G）操作，把粒子 spread 到网格上；然后在这个网格上解一个泊松方程，得到流函数或势函数；对它施加梯度或 curl——这时得到的是一个平滑的场。注意，这个场包含了所有粒子的贡献；但是它没有细节——近场的值被网格抹平了。

接下来要考虑的，就是如何把这些细节加回来。加回来的方法很有意思：先把平滑的场插值出来，再对周围累加高频分量带来的影响，就可以把细节加回来。

把算法正式摆出来：

1. 有一堆粒子，做 particle-to-grid，得到一个平滑层；
2. 计算高频场：把每个粒子减掉它从平滑层里插值出来的那个值，就得到它的高频分量；
3. 在网格上解泊松方程（用 multigrid 就可以），求解平滑的场，得到流函数或势函数；
4. 对流函数或势函数求 curl、求梯度，得到平滑的速度分量；
5. 粒子上最终的湍流速度分量由两部分组成：先插值出平滑的速度分量，再对它附近区域的高频分量做直接求和——注意这里是直接求和，不是快速求和，因为只算近邻。

这样的一种计算，由于整个过程中每一步都是线性的，最后得到的就是一个线性时间的求和算法；并且它比快速多极展开要简单得多——用到课程到上一节为止已经开发的那些工具和能力，应该就足以写出一个 P³M 算法。

有同学问：第三步用 multigrid 应该就可以吧？边界条件怎么处理？

就用 multigrid。而且 P³M 不用专门操心边界条件——边界条件可以认为是零。所有的粒子被 spread 到很小的一块区域上，把边界放得足够远就行了。为什么这样可以？因为最后有高频分量的直接累加兜底——这样是不会损失精度的。

效果如何？计算时间确实达到了线性——蓝线是 $O(N)$，绿线是 $O(N^2)$。精度方面，随着 correction range（校正范围）的增加，误差能够到达小于 1% 的水平；在图示的这一档设置下，甚至到了 0.01% 这个量级。

### 与核无关的快速求和：两圈等效电荷

最后一种，是与核无关（kernel independent）的快速求和方法。它的视角是这样的：当我有一个电子（源电荷）时，构造两个圈把它包住。

在外圈的 $p_j$ 这些点上，我们要求出来自 $q_i$ 的直接求和的贡献——这是已知的、要达到的数值目标。然后假设这些数值，是由内圈上一些未知的电子电量给出的——要问的是：内圈的电荷量要是多少，才能在外圈上给出这样一个势分布？

内圈与外圈之间的核 $k_{kj}$ 是已知的——一旦内圈和外圈的形状确定，$k_{kj}$ 就是一个确定的矩阵；外圈的目标值 $p_j$ 也是已知的；要解的是内圈电荷 $\sigma_k$。所以这其实是一个矩阵求逆的过程，而且是局部的（locally）一个小矩阵求逆。

每个圈上放多少个电荷？随意，多多益善——电荷越多，你可能越准确。实践中差不多一百个就够了。

解析（思路）：正文说过，Biot–Savart"很像万有引力的公式，只不过用的是叉乘的形式"；而涡方法的速度场是流函数经 curl 算子得到的，引力是势经梯度算子得到的——旋度核与梯度核只差一个 90° 旋转。于是：把每个涡点的强度当作"电量"喂给 `computeGravity`，把返回的力向量整体旋转 90°，得到的就是 Biot–Savart 速度；对 $j$ 的遍历全部发生在黑盒内部。

### 有限元是干啥的：伽辽金方法

有限元方法（FEM）其实是伽辽金（Galerkin）方法里的一种。什么是伽辽金方法？就是一种把强形式（strong form）PDE 转化为弱形式（weak form）的方法。

> **定义**：强形式就是"每一点都成立"的 PDE。它是一个连续的形式，在空间里每一个点都成立——你大概能感觉到，这在计算机里不太容易实现，因为计算机只有有限的存储和有限的计算，没办法做这种连续的表示。弱形式则是：把强形式的残差项用一个测试函数（test function）$w$ 加权，然后积分。

在有限元里，连续的 PDE 会一步一步经过变换，变成一套离散的线性系统；然后大家就可以用自己最喜欢的线性系统求解器——比如共轭梯度、多重网格（multigrid）——去求解这个有限元系统。今天公式稍微有点多，后面肯定会讲得口干舌燥，但大家别怕：经过计算机图形学的简化，有限元基本就这么几个套路，正好一到五步。

```text
强形式 PDE（每一点都成立，连续，计算机没法直接表示）
  │ ① 上测试函数 w：乘起来、积分 → 弱形式
  ▼
弱形式（残差 × w，全域积分恒为零）
  │ ② 分部积分：把梯度挪出来，消掉 u 身上的二阶导数
  │ ③ 散度定理：体积分 → 边界积分，顺手得到诺伊曼边界条件的显式形式
  ▼
化简后的弱形式
  │ ④ 离散化：连续场 = 基函数的加权组合（本讲只用线性基函数）
  ▼
线性系统 K u = f（K：刚度矩阵；f：荷载向量）
  │ ⑤ 求解线性系统：共轭梯度、多重网格……随你挑
  ▼
解 u
```

读图说明：左边一列是每一步的产物，右边是这一步用的手段——有限元的推导翻来覆去就是这条流水线。

最后得到的矩阵一般叫 stiffness matrix（刚度矩阵），但它不一定真是"刚度"——很多时候它有别的物理意义，并不总是一个"刚性"的东西；除了矩阵还有一个右端项，叫 load vector（荷载向量）。最后一步求解线性系统非常重要——因为很多其他的离散化方法其实也是伽辽金方法，比如物质点法（MPM）：它的思想和 FEM 非常非常像，只不过 MPM 里没有显式的元素，它叫 element-free Galerkin，无元素伽辽金。

### 从泊松方程开始

第一个离散化的例子，从大家最熟悉的二维标量泊松方程讲起。泊松方程是啥大家应该还记得：我有一个标量场 $u$，对它求一次梯度、再求一次散度，在整个空间里等于零：

$$
abla\cdot(
abla u) = \Delta u = 0 \quad \text{in } \Omega$$

这个区域是一个正方形，有四条边。这个问题里我们假设三条边是狄利克雷（Dirichlet）边界——直接指定 $u$ 在边界上这一点的值，用 $f(x)$ 表示；下面一条边是诺伊曼（Neumann）边界——不直接指定 $u$ 的值，而是指定 $u$ 的导数的值，当然要和边界上的法向量做一次点乘，用 $g(x)$ 表示。狄利克雷边界条件一般叫第一类边界条件，诺伊曼边界条件叫第二类边界条件。到这儿为止，这还是一个连续的问题。

接下来用网格把区域分成很多很多个小的部分。图形学里大家比较喜欢规则的（regular）四边形网格。有同学会问：如果我把一条对角线连起来，会得到两个三角形、一个三角形网格，可不可以？完全可以。实际上很多时候大家更喜欢三角形网格——它可以很容易地做网格密度的渐变（adaptivity）；而且我这边展示的是方形的边界，如果边界是一个圆形或者其他形状，你可能会更想用三角形网格，因为它能更好地贴合边界。不过今天这一讲，所有涉及数字的部分，我们都用正方形的元素来表示。

数一数：这里分了 3×3 = 9 个元素；自由度存在每一个元素的四个顶点上，所以我们有 4×4 = 16 个自由度——用 16 个浮点数来表示这个场。具体怎么表示，后面会提到。

这有啥用？其实有很多用。光是一个标量泊松方程，你就可以用来解流体模拟里面的压力投影——这是它最常见的用处。当然，图形学里做流体一般用 FEM 用得比较少，更常用的是有限差分（finite difference）和有限体积（finite volume）。

### 强形式怎么变成弱形式

接下来看怎么离散化它。第一步，把强形式转换成弱形式。怎么个转换法？

我们想象有一个任意的二维标量函数 $w(x)$——测试函数，把它和强形式乘起来，在整个区域 $\Omega$ 上做一个积分。于是有这么一个关系式：PDE 在每一点都成立，当且仅当对于任意的测试函数 $w$，这个积分都等于零。

从左往右推非常好理解：如果左边这一项永远都是零，那不管 $w$ 是什么，乘上一个零都是零，再积分还是零。但从右往左，就需要一点想象力了：假如存在一个点，拉普拉斯算子作用上去不是零，那我们总可以想方设法构造出来一个测试函数 $w$，使得积分不等于零——所以"对任意 $w$ 积分恒为零"就逼着强形式处处成立。当然，这个构造只是直观上的，真要从数学分析上严格证明，还是要下一番功夫的。

接下来我们要把强形式里的二阶导数去掉。技巧叫分部积分——或者你不叫它分部积分也行，叫乘积的求导公式。看右边这一项：$w$ 乘上 $
abla u$，要算它的散度。求导数其实就是两项：要么先给 $w$ 求导、点乘 $u$ 的导数；要么 $w$ 乘上 $u$ 的二阶导数（Laplacian）：

$$
abla\cdot(w\,
abla u) = 
abla w\cdot
abla u + w\,\Delta u$$

把这个恒等式在区域上积分，左边那一项用散度定理变成边界积分——而它是零，因为测试函数在边界上取零，这是弱形式里的标准约定——所以可以直接把这一项踢掉，得到：

$$\int_\Omega w\,\Delta u\,dx = -\int_\Omega 
abla w\cdot
abla u\,dx$$

于是"$\Delta u = 0$"当且仅当"对任意 $w$：$\int_\Omega 
abla w\cdot
abla u\,dx = 0$"。有人会问：你这儿不还是有二阶导数吗？别急，把它也请出去——含二阶导数的那个项是一个散度的形式：一块体积里散度的积分，等于边界上这个向量函数和法向量点乘、绕边界积分一圈，这就是散度定理。用了散度定理以后，在二维里，一边是面积分，另一边是沿着边界的线积分。最终得到弱形式：

$$\int_\Omega 
abla w\cdot
abla u\,dx = \oint_{\partial\Omega} w\,(
abla u\cdot n)\,ds$$

边界积分里那个 $
abla u\cdot n$，正是刚才提到的诺伊曼边界条件——先记下，处理边界条件的时候会用到。

### 基函数：用 16 个浮点数表示连续场

刚才讨论的全部都局限在连续空间里。接下来，我们用一系列离散的函数去表示连续的函数。

先看一维。假设有一组基函数 $\varphi_0,\varphi_1,\varphi_2,\varphi_3$，定义域从原点到某一个点：$\varphi_0$ 和 $\varphi_3$ 只有右半边或左半边，$\varphi_1$ 和 $\varphi_2$ 两边都有——用的是最简单不过的线性基函数。所谓离散化，就是：

$$u(x) = \sum_i u_i\,\varphi_i(x)$$

直观上很容易理解：把这些基函数按系数加权（或者说 scale 一下）再求和，得到的其实是一个分段线性（piecewise linear）的 $u$ 函数。它在很多时候已经能够做得挺好的了，是很好的近似。

这门课专注在线性基函数上。有同学说我这边能不能用更 fancy 的、不喜欢直线，把它换成曲线？完全可以，那样整个系统会变得更复杂一些。又有同学问：你说这么复杂，这东西不就是线性插值吗？对，它确实就是线性插值——如果把 $u_i$ 理解成第 $i$ 个点上的值，那两点之间的值确实是线性插值出来的。一维里面是线性插值，大家可以推导出来二维里面是什么——就是双线性插值；三维里面就是三线性插值。图形学里一般情况下，linear、bilinear、trilinear 插值就够了；有些文章会用高阶的，也可以，但相对来说比较少。

> **易错点**：双线性插值虽然叫 bilinear——关于 $x$ 是线性的、关于 $y$ 也是线性的——但它是把 $x$ 方向的 linear 和 $y$ 方向的 linear 乘起来的，所以关于 $(x,y)$ 整体是一个二次函数（里面有 $xy$ 项），并不是完全"线性"的。

二维的基函数长啥样？如果是三角形网格，基函数大概就是所谓的"帐篷函数"（tent function）——非常像一个帐篷：每一面都是三角形，中间（顶点处）最高，相邻顶点上全部为零。这组图我是从 COMSOL 的网站上找来的，实在没有精力自己画，画图实在太费时间。COMSOL 是商业 FEM 软件，它那篇介绍 FEM 的文章写得非常好，图都非常精美——一方面是介绍 FEM，一方面也是宣传自己的软件——课程结束后大家可以去看看。

这里有一个关键观察：大部分基函数的支撑是互不相交的——刚才一维的例子里 $\varphi_1$、$\varphi_2$ 有一段是重合的，但大部分情况下不重合。这有什么意义？不重合，对应的线性系统里那个元素就是零；重合，就是非零。既然大部分基函数互不重合，说明线性系统里大部分元素是零——你得到的线性系统，是一个稀疏的线性系统。

回到我们最喜欢的四边形元素——工工整整、方方正正的长方形元素。这时候要用一点想象力去 visualize 基函数：二维里它就是双线性插值的基函数，可以理解成一个"曲面版的帐篷函数"——还是一个帐篷，但它有四个面，每一个面是一个曲面，而不是三角形帐篷那种平面。为什么是曲面？就是上面说的那个易错点：双线性函数关于 $(x,y)$ 本质上是二次的，所以面是弯的。比如 $u_{1,1}$ 这一点的形函数，肯定和刚才一样：周围八个点上面都是零，中间一个点上面是一。

顺便统一一下叫法。我刚才说漏了嘴，用了"形函数"这个词——它其实就是基函数（basis function）。这个领域里有些地方术语不太规范，有些同行有强迫症，必须这里用 shape function、那里用 basis function，我们就不做明显的区分了；我个人比较喜欢叫基函数。

### 从弱形式到 Ku = f

回忆一下我们想求什么：找一个 $u$，使得弱形式对任意 $w$ 成立——右边是散度定理搞来的，左边是分部积分来的。既然 $u(x)$ 可以写成基函数的加权求和，那最简单的就是 substitution：把离散化的 $u$ 替换进弱形式。注意只换左半边，右半边（边界积分）先不动，后面有别的处理方法。

$w$ 怎么办？$w$ 本来是任意的，但 $w$ 也是由基函数线性组合出来的，所以只要取任意一个基函数当作 $w$ 就可以了——不需要取遍所有的 $w$，取一组线性无关的基函数就够了。这一步可能得稍微想一下，但还是比较容易想通的：不取基函数的话，反正它们也线性相关。

把 $w$ 换成 $\varphi_i$ 之后，再做一步非常有意思的事情：把未知数 $u_j$ 从积分里提取出来——这就是一步比较 trivial 的交换顺序。于是左边变成：

$$\sum_j \left(\int_\Omega 
abla\varphi_i\cdot
abla\varphi_j\,dx\right) u_j = \oint_{\partial\Omega} \varphi_i\,(
abla u\cdot n)\,ds$$

左边这么一整坨括号和 $u$ 是没有关系的，知道了基函数它就是一个常数项；右边我们后面会用诺伊曼边界条件给它推出来。写成矩阵形式就是：

$$K u = f$$

$Ku=f$ 其实就是 $Ax=b$ 在有限元里的一个别名，它就是一个线性系统。有限元里这三个字母都有自己的名字：$K$ 一般叫 stiffness matrix，刚度矩阵；$u$ 叫自由度（degree of freedom），或者叫解向量；$f$ 叫 load vector，荷载。这几个名字更像是在解固体小形变时会用到的术语，但大家习惯了，我们就照用——记住 $K$、$u$、$f$ 这三个名字就行。

那 $K$ 的元素是啥？就是：

$$K_{ij} = \int_\Omega 
abla\varphi_i\cdot
abla\varphi_j\,dx$$

我们用的基函数简单，这个积分不难算——用一些更难的基函数时，大家会用高斯求积（Gaussian quadrature）；我们这边手动积分一下完全没有关系。

算给你看。假设中间这个点是 $i$，$\varphi_i$ 就是一个帐篷函数。由于基函数的支撑有限——只在周围四格里面非零，更远的地方全部是零——我们只需要考虑它周围四个元素上的积分。$i=j$ 时，就是两个相同帐篷的梯度做点乘再积分，算出来是 8/3；$j$ 是旁边的点时，算出来是 −1/3，周围邻居全算出来都是 −1/3。当然这里面还有像 $dx$（网格尺度）这样的因子，我们就忽略掉了；再整体 scale 一下，就得到一个九点的拉普拉斯（Laplacian）算子 stencil——中间是 8，周围全是 −1：

```text
九点格式（有限元，双线性基函数）        五点格式（有限差分）
      -1   -1   -1                        0    1    0
      -1    8   -1                        1   -4    1
      -1   -1   -1                        0    1    0
```

读图说明：两个都是作用在中心点上的拉普拉斯离散权重，左边来自有限元，右边来自有限差分。

还记得我们之前用有限差分推过一个五点的拉普拉斯 stencil 吗——中间 −4，四个邻居是 1（正负号的问题大家一般也不 care）。你会发现，同一个算子用不同的方式离散化，可能得到不同的 stencil。图形学里做流体一般更多用有限差分或有限体积，所以五点那个 stencil 用得多一些，中间 8、周围 −1 的九点反而用得比较少。但是泊松方程作为推有限元的例子非常好——它真是最简单的、不能再简单了。

### 边界条件怎么塞进去

还记得吗，弱形式右端项里那个 $
abla u\cdot n$，我们一直没有讨论。现在就把边界条件的问题解决掉。

狄利克雷边界条件（第一类）非常容易：直接把相关的 $u_i$——也就是边界上那些自由度——的值设置成给定的 $f(x_i)$，其中 $x_i$ 就是那个自由度所在点的坐标。为什么可以这么干？用线性插值的方式理解的话，那一点上的值本来就应该等于 $f$ 的值。

诺伊曼边界条件（第二类）稍微复杂一些：把 $g$ 塞到右端项里，荷载向量 $f$ 里就会出现一个非零的 entry。在固体力学里，这一项一般叫 traction，中文叫面力——就是"你施加给它的力"。所以有时候大家会说"我推一个弹性材料，其实是给它施加了一个诺伊曼边界条件"，乍一听让人摸不着头脑：明明是一个推力，怎么就变成诺伊曼边界条件了？从上面这个地方就能看出来。

力学里这两类边界条件的直观图像：固体的某个地方钉了个钉子、把它固定在平面上——这个点的位移被指定了——这就是第一类边界条件；加一个弹簧在那儿拖拽，就是第二类边界条件。

> **提示**：load vector 中文叫"荷载"。荷、载两个字还都是多音字，我就乱读了，反正大家知道说的是右端项 $f$ 就行。

| 边界条件 | 又叫 | 指定什么 | 有限元里怎么处理 | 固体里的直观 |
| :--- | :--- | :--- | :--- | :--- |
| 狄利克雷（Dirichlet） | 第一类 | $u$ 本身的值 | 直接把边界自由度设成 $f(x_i)$ | 钉钉子，固定位移 |
| 诺伊曼（Neumann） | 第二类 | $
abla u\cdot n$（梯度点乘法向） | 塞进右端，荷载向量里出现非零项 | 施加面力（traction），推一下 |

### 线性弹性：柯西动量方程的离散化

接下来讲一个稍微复杂一点的有限元离散化：线性弹性。它是从柯西（Cauchy）动量方程推出来的：

$$\rho\,\frac{D v}{D t} = 
abla\cdot\sigma + \rho\,g$$

这个方程其实很好理解：左边是速度的拉格朗日导数，也就是加速度——本质就是 $F=ma$，或者说 $a = F/m$；右边的 $\rho g$ 就是 $F=ma$ 里重力那一项；中间稍微有点难理解：要算柯西应力张量（Cauchy stress tensor）的散度。$\sigma$ 是一个二阶张量——三维里是 3×3 的张量（其实就是一个对称的矩阵），二维里就是 2×2；$g$ 是体积力，或者说重力加速度。

我们先把它大刀阔斧地简化一把：首先考虑准静态（quasi-static）过程，速度是零；或者说就是一个微小形变——根本没有刚体移动，只有微小的形变；然后密度认为不变，把 $\rho$ 那一项去掉；也没有重力、没有体积力。全部去掉以后，就得到最简单的形式：

$$
abla\cdot\sigma = 0$$

说到准静态，我想起一个笑话。我本科是学计算机的，在姚班，隔壁同学有学数学的、有学物理的。有一次可能前一天写代码写得太长，起床落枕了，脖子很疼。我跟室友说：我这个脖子的疼痛感，是随着脖子转动的速度成正比的。他上来就来了一句：那你以后可以准静态转动脖子。什么叫准静态？就是说你虽然在转，但你每时每刻的速度都近似为零——转得非常非常慢。我每次看到 quasi-static，都会想起这段经历。

这边的自由度还是记作 $u$，但这一次它是 displacement（位移）：一个点在施加外力以后会有形变，形变之后的位置和原来的位置之间有一个差，这个差就是位移。

> **易错点**：这个 $u$ 和之前讲"最简单的三角形 FEM"时用的不是一个东西。那时候那个比较"山寨"，根本就没提它是怎么推出来的，用的是 $\varphi(x)$——新位置关于旧位置（material space 位置）的映射；这边我们不用那个，用的是新位置减去旧位置得到的位移。注意区分。

你会发现这个方程里好像没有出现自由度 $u$？因为 $\sigma$ 其实是 $u$ 的一个线性函数，中间有一套非常复杂（但线性）的映射，后面会展开。有同学会问：这到底是拉格朗日的还是欧拉的？它其实是 infinitesimal（无穷小）的形变——根本就没有移动——所以说它是拉格朗日还是欧拉，没有太大意义。我还是想提这一点，因为很多搞图形学的同学会觉得"我用了网格，我就是欧拉的方法"，但其实并不一定：拉格朗日还是欧拉，并不是根据你用网格还是用粒子来区分的。

### index notation：让张量散度看得清楚

刚才说，柯西应力张量的散度可能不太容易理解——说实话，一个 3×3 张量的散度一开始是什么意思，你还是要想一下的。这边引入一套新的符号系统，叫 index notation，非常有用，后面推 MPM 的时候也会用到。

做法：用 $\alpha$、$\beta$、$\gamma$ 这一坨希腊字母来表示下标。我们一般考虑三维问题，只有 $x$、$y$、$z$ 三个轴，就用 $x_\alpha$ 统一表示：$\alpha=0$ 就是 $x$，$\alpha=1$ 就是 $y$，$\alpha=2$ 就是 $z$——当然从 1 开始编号也行，取决于你的习惯。然后，用一个逗号来表示求偏导数：

$$\sigma_{\alpha\beta,\gamma} = \frac{\partial\,\sigma_{\alpha\beta}}{\partial x_\gamma}$$

记住了：逗号后面的那个下标表示求导。这么做以后，原来那个向量方程的第 $\alpha$ 个分量就可以写得清清楚楚：

$$\rho\,\frac{D v_\alpha}{D t} = \sum_\beta \sigma_{\alpha\beta,\beta} + \rho\,g_\alpha$$

内力那一项就是：应力张量的 $\alpha\beta$ 分量，关于 $\beta$ 求导，再对 $\beta$ 求和。

你可能听说过爱因斯坦求和约定：一个下标出现两次，就隐含一次求和。但这边我们不用隐式求和，把所有的求和全部用 $\Sigma$ 写出来，这样更清楚一些——出现两个 $\alpha$、两个 $\beta$ 的时候，到底是对两个都求和还是只对一个求和，对初学者来说不是很友好，显式写出来就没歧义了。

### 同样的套路：测试函数、分部积分、散度定理

现在用有限元去离散化它。注意，这和刚才的泊松方程比起来稍微复杂一点点：泊松是一个标量的 PDE，这边是一个张量（向量）的 PDE；而且刚才泊松的 $u$ 是直接出现在方程里的，这边还有一个 mapping 把 $u$ 映到 $\sigma$——所以先在 $\sigma$ 上面推，后面再讲怎么把 $u$ 替换上去。

首先，还记得第一步是什么吗？伽辽金方法：上测试函数。这次要注意，测试函数是矢量测试函数——从二维平面映到一个二维向量——乘上去之后要关于 $\beta$ 求和，然后再积分。为什么要上测试函数？有了两项之后，我们就可以分部积分了，或者用乘积的求导公式。

用 index notation 看，分部积分会更清楚：那一项里求导的 $\beta$，要么塞给左边的 $w$，要么塞给右边的 $\sigma$——口诀就是 $d(uv) = u\,dv + v\,du$，微积分的时候学过的。分部积分之后，边界那一项我们知道是零，删掉；再用散度定理，把体积分彻底换成边界上的面（线）积分：

$$\int_\Omega w_{\alpha,\beta}\,\sigma_{\alpha\beta}\,d\Omega = \oint_{\partial\Omega} w_\alpha\,\sigma_{\alpha\beta}\,n_\beta\,ds$$

后面的套路和泊松一模一样：把连续的 $u$ 替换成用基函数支撑起来的离散函数；再把测试函数 $w$ 换成基函数——我们不需要测所有的 $w$，只要测比较有代表性的那几个，有代表性的 $w$ 就是基函数。$u$ 塞进来的时候注意，只换左半部分，右半部分是边界上的面力（traction），先保持原样。

但这时候左边还是一个关于 $\sigma$ 的式子，并不是关于 $u$ 的方程，还不太好直接放进线性系统。接下来要做的事情，就是把 $\sigma$ 和 $u$ 的关系确定下来，把 $\sigma$ 消掉——消掉之后，左边很容易就能变成 $Ku=f$ 的样子。

### 应变、应力与那句关键结论

$u$ 怎么一步步到 $\sigma$？中间有一条链。

displacement 本身就是度量形变的一个东西；但要得到"局部的形变"，还得再求一次导数。对位移 $u$ 求梯度：$u$ 虽然是一个三维向量，但求完梯度就变成一个 3×3 的矩阵，或者说二阶张量。这门课里所有的 strain（应变），你都可以把它理解成"局部形变"这么个东西。对位移的梯度做一个对称化，就得到应变张量：

$$\varepsilon_{\alpha\beta} = \frac{1}{2}\left(u_{\alpha,\beta} + u_{\beta,\alpha}\right)$$

也就是 $u$ 的第 $\alpha$ 个分量对 $\beta$ 求导，加上 $u$ 的第 $\beta$ 个分量对 $\alpha$ 求导，取个平均。

有了应变，再经过本构关系，就得到柯西应力张量：

$$\sigma = \lambda\,\operatorname{tr}(\varepsilon)\,I + 2\mu\,\varepsilon$$

这里的 $\lambda$ 和 $\mu$ 就是之前提到过的拉梅参数（Lamé parameters），在图形学里模拟弹性物体的时候非常非常常见。这一项如果看起来非常 confusing，可以用 index notation 再简化一下：$\lambda\operatorname{tr}(\varepsilon) I$ 里那个单位矩阵会写成 $\delta_{\alpha\beta}$——Kronecker delta，$\alpha$ 和 $\beta$ 相等的时候等于 1，不相等的时候等于 0——它对应的就是 identity matrix。

说了这么多，其实这些都不重要。重要的是一句话：

> **结论**：$\sigma$ 是 $u$ 的 linear function。从位移到应变、再到应力的整条链都是线性的，这一句撑起了下面整个线性系统。

### 组装刚度矩阵：8×8 从哪来

$\sigma$ 是 $u$ 的线性函数，加上前面的弱形式，我们其实还是可以推出 $Ku=f$。但这一次，要把 $u$ 从左边提出来得下一番功夫：它不是说直接可以提出来，中间还要经过 strain-displacement matrix（应变-位移矩阵）和 stress-strain matrix（应力-应变矩阵）两步处理，才能得到真正的 $K$。所以真正的弹性 FEM，它的 $K$ 是要组装（assemble）起来的，还不是特别容易。

稀疏结构也比泊松那边复杂。如果没有边界条件，每一个 $u$ 的分量会和多少个其他的分量发生关系？也就是说，$K$ 的一行里有多少个非零项？其实非常多，就是因为中间那套变换的对应关系有点复杂。二维里，中间这个点和周围 3×3 个节点有关系，每个节点有两个分量，所以一行有 18 个 entry；三维里更复杂：每一个顶点会和周围 8 个 boxel（体素）有关系，8 个 boxel 涉及 3×3×3 = 27 个顶点，每个顶点上面又有 3 个分量，所以一共 81 个 non-zero entries——要把这 81 项都写出来，还不是一件容易的事情。

| 维度 | 一行里的非零项 | 怎么数出来的 |
| :--- | :--- | :--- |
| 二维 | 18 | 周围 3×3 个节点 × 每节点 2 个分量 |
| 三维 | 81 | 周围 8 个体素共 3×3×3=27 个顶点 × 每顶点 3 个分量 |

那 $K$ 到底长啥样？我们接下来揭开它的神秘面纱。一般大家讨论的是单个元素的单元刚度矩阵（element stiffness matrix）$K^e$。四边形元素有 4 个顶点、每顶点 2 个分量，所以它是一个 8×8 的矩阵——8 个不同的基本项做排列组合得到的。这个矩阵大家一般是打表的。我很久以前手动推过这 8×8 里面的一两项，挺累的；一般大家就是你抄我、我抄你，把这个 8×8 矩阵塞在你的代码里面，随时在硬盘的某个角落能把它找出来。

这个地方真要讲起来非常复杂，我就不细讲了。但大家要记住：从 $u$ 到 $\sigma$ 中间这个 non-trivial 的线性变换，导致了每个元素 8×8 的刚度矩阵。有了每个元素的刚度矩阵，我们就可以组装出真正的大 $K$。

组装过程想亲眼看一看的话：如果你会 MATLAB，可以去看一篇"99 行拓扑优化"的文章——用 MATLAB 写的拓扑优化实现，非常非常容易上手，它也会介绍拓扑优化。那正好，既然都讲到拓扑优化了，接下来我们就简单介绍一下拓扑优化是啥。

### 拓扑优化：最小柔顺度

介绍一个最最简单的拓扑优化问题：minimal compliance，最小柔顺度。

要最小化的东西叫 compliance（柔顺度），定义是：

$$C = u^\top K u$$

它其实是某一种形变的能量——如果你做机器学习，可能更喜欢叫它 loss function——衡量的就是这个物体形变的大小。约束有几个。首先得满足 $Ku=f$：你的位移得和荷载对应。然后你只有有限的材料：空间里有很多小格子，每个格子可以是 0（空）也可以是 1（填充）；实际做的时候，用 0 到 1 之间的连续数来表示这个格子到底是有材料还是没材料，再用一些 trick 让这个值要么接近 0、要么接近 1，把它推到两级上面——这样就把一个离散的优化问题表示成了连续的优化问题。还有一个体积限制：不是说整个空间都得填满。你想，如果不给你限制，最小化上面那个东西的最简单方式就是把整个空间全部填满；有了体积限制，你就得想想办法了。

光列一坨公式不是很直观，我们来看一个拓扑优化的 demo。这是一个交互程序，可以调分辨率：分辨率高了，求解时间会相应地变长，但得到的结果也会更好一些——我说的"更好"，也只是说它看起来更复杂、更好看。一般来说，大家会用 objective（就是上面那个 $u^\top K u$）来作为结果好坏的 measure。

拓扑优化在图形学里挺常用，为什么？因为它好看。倒不是说它在工程里没用——工程里大家更喜欢它省材料；但图形学里很多时候就是图一个好看。另外，3D 打印技术出来以后，拓扑优化一下子变得非常 popular：它优化出来的材料分布往往非常复杂，以前的增材制造方式往往造不出来，用 3D 打印就非常容易，什么材料都能打印。

demo 里我们在干啥？这里用了一个对称的技巧：演示里显示的其实只是结构的右半部分，左半部分和它完全对称。想象整个结构有两个底部的角点是固定的，中间加一个向下的力，然后问你：就给你这么多材料，不能把空间全部填满，只有 50% 的 volume 可以放材料，你怎么设计这个结构，使得柔顺度尽可能小？

demo 里还有好几种边界条件。刚才讲的是比较简单的把脚上固定；还有一种好像叫 MBB：固定左边——你可以想象左边是一面墙，要优化一个伸出来的结构，最右边可以挂个衣服什么的，比较直观，优化出来基本是一个像钳子一样的结构。还有边界条件三，是一个桥梁结构：把左下角、右下角固定住，给上面每一个点都施加一个向下的力——实际上就是一个桥梁的设计。我不知道现实中有没有人真的这么设计桥梁，但确实有些建筑是拓扑优化设计出来的——大家不要觉得拓扑优化是一个理论上的东西：它设计出来的结构往往非常具有美感，有一种"生物质感"，最近不是很流行环保、仿生这些设计嘛，很多设计师会用拓扑优化来设计建筑。

至于求解，solve FEM 还是要费一些功夫的。可以看到它在非常卖力地迭代——因为我们用的是共轭梯度（CG），没有加预条件，所以收敛速度并不是很快，特别是当你的结构还不清晰的时候。

如果你想了解 minimum compliance 拓扑优化，其实只有两个关键词：一个叫 SIMP，一个叫 OC。你只要记住这两个关键词，到文档里去找它们是啥就可以了。这个算法和之前推的有限元比起来非常容易理解，就是一个很简单的优化问题。限于时间关系，拓扑优化我就不继续讲太多了，大家可以去玩一玩这个 demo。

作业包里那个 PDF 会介绍 SIMP 和 OC，手把手教你把一个还不能跑的程序，一步步实现成一个能跑的拓扑优化，最后你能看到的就是刚才展示的效果。那个作业是 C++ 写的——早期 Taichi 还是一个 C++ 库，我后来实在没有找到时间用新版的 Python Taichi 重写，下次一定，这次是真的没有时间了。它是 MIT 计算机图形学的作业，我们在 MIT 那边讲课时也会用到：里面有一个两万行的作业框架文件，和一个只有 200 行的拓扑优化程序，代码可以在各种平台上不用装虚拟机就运行。

### 一台机器，十亿体素

说到拓扑优化，也不得不提我们之前做过的一个非常有意思的工作：如果把拓扑优化的分辨率推到非常高，会怎么样？

刚才演示的拓扑优化分辨率其实非常低，大概只有 100×200。图形学里大家很少用这么低的分辨率，一般至少是大几百乘大几百，或者几千乘几千。拓扑优化由于要解一个 FEM，分辨率之前一直都很难做高：矩阵非常大、和普通的比起来非常复杂，你还得给它设计一个 preconditioner，也不是特别容易。

所以我们做了这么一个工作，目的非常简单：把分辨率调到非常高，然后只给你一台电脑，去做拓扑优化、解 FEM，能达到一个什么样的效果。视频我传到 B 站上了（昨天晚上传的，应该刚审核通过），大家可以去看一看。它里面核心的部分就是一个高性能的 FEM solver。当时我们找了一台有 512 GB 内存的机器，在一台机器上面用 CPU 去做有限元求解，推到了超过 10 亿个 boxel（体素）的分辨率。

你可以想象：这个规模下，把 $K$ 矩阵存下来都存不下。那怎么办？高精度的情况下，大家往往会考虑 matrix-free 的搞法，因为你没法把这个矩阵存下来。你还得设计一个很好的 preconditioner，要不然根本收敛不了，或者要非常非常多次 CG 迭代才能收敛，效率非常低。这本质上就是一篇高性能计算的文章——有同学也说到这一点，确实：和传统的 graphics simulation 相比，它更像是"simulation 加高性能计算"。

视频里展示的是一个鸟嘴结构的拓扑优化。鸟嘴结构是干啥的？把一个面固定住，然后给鸟嘴的某些部分加力——鸟嘴得有用嘛，得够硬才能咬得动坚果、花生什么的，所以设计上面要加上这样一个条件。最后得到一个仿生设计。你可以去看一看有些鸟的化石，它们嘴部的内部结构和这个还有点像——不能说完全像，毕竟这个是在计算机里面进化出来的，不是在自然条件下进化出来的。

为什么不用 GPU？因为 GPU 没有这么多内存：现在 GPU 的显存可能只有 22G、24G，但我们整个系统跑起来大概要用到 300 多 G、将近 400 G 的内存。你也不要觉得 300 多 G、400 G 好像很多——之前有一篇 Nature 论文也做高分辨率的拓扑优化，我记得用了 500 台电脑、还有什么 8000 个 CPU core 才把它算出来；我们只用一台电脑、50 个 CPU core 就把它算出来了，分辨率和它也差不多。这还是挺有意思的一个工作。

最后补一个课上有人问的问题：FEM 能不能结合 multigrid？可以。如果你要看 FEM 加 multigrid，一定要看一下那篇我觉得还不错的文章——当然这个 multigrid 不像普通的 multigrid 那么容易，要把它写对真的很不容易；它的代码是开源的，是一个 C++ 的代码。
