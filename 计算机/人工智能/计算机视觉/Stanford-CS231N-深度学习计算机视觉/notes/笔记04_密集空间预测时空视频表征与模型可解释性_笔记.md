# 密集空间预测、时空视频表征与模型可解释性

## 现代视觉主干网络与工程优化策略

### 视觉变换器与空间序列化机制

* **视觉变换器（Vision Transformer，ViT）**

    * > **定义**：通过规则网格将二维连续图像切分为离散图像块序列，经线性投影转换为 Patch Tokens 并叠加位置嵌入后送入标准 Transformer 编码器提取特征的视觉骨干网络。

    * 分块投影机制：输入图像 $H \times W \times C$ 被切分为 $S \times S$ 个不重叠的局部网格图像块（如 $16 \times 16$ 像素/块）；每个图像块展平后通过线性全连接层映射为 $D$ 维连续向量（Patch Token）。

    * 空间位置嵌入：自注意力机制具备置换不变性，图像打散为序列后天然丢失二维空间拓扑结构；模型必须在每个 Patch Token 上叠加可学习的一维序列编号或二维平面坐标 $(x, y)$ 位置嵌入向量（Position Embeddings）。

    * 分类特征提取范式：
        * 类别标记法（Class Token）：在序列起始位置前置特殊可学习向量 `[CLS]`，经过多层全局自注意力交互汇聚全图全局判别特征，末端直接接入线性分类头输出类别概率。
        * 全局平均池化法（Global Average Pooling，GAP）：不引入额外标记，将末层输出的所有 Patch Tokens 沿空间序列维度进行全局平均池化后映射为类别概率。

    * 示意图解：


```text
      [ 原始输入图像 H x W x C ]
                 |
                 v 规则空间网格切分
      [ 图像块序列: S x S 个图像块 (如 16x16 像素/块) ]
                 |
                 v 线性投影 (展平后通过全连接层)
      [ 图像 Patch Tokens: 每个块映射为 D 维向量 ]
                 |
                 + <--- [ 叠加可学习的位置嵌入 (Position Embeddings) ]
                 |
      [ 最终输入序列: 包含空间位置编码的 Tokens ]
```


### 稳定训练与容量扩展组件

* **前置层归一化（Pre-LayerNorm，Pre-LN）**

    * > **定义**：将层归一化算子移至残差连接分支内部、保留无损恒等通信捷径的网络拓扑结构。

    * 数学公式：$x_{l+1} = x_l + \text{SubLayer}(\text{LayerNorm}(x_l))$。

    * 机理与对比：传统后置层归一化（Post-LN: $x_{l+1} = \text{LayerNorm}(x_l + \text{SubLayer}(x_l))$）在残差主干相加后执行归一化，破坏了 $x_{l+1} = x_l + F(x_l)$ 的严格恒等映射；Pre-LN 维持了贯穿深层的纯净梯度反向传播通路，消除了数值不稳定与梯度异常，支持极深模型从头平稳训练。

* **均方根归一化（Root Mean Square Normalization，RMSNorm）**

    * > **定义**：摒弃特征均值计算与居中偏移、仅依赖特征均方根进行缩放的计算高效型归一化方法。

    * 数学公式：
      $$\text{RMS}(x) = \sqrt{\frac{1}{d} \sum_{i=1}^d x_i^2}, \quad \bar{x}_i = \frac{x_i}{\text{RMS}(x)} \gamma_i$$

    * 硬件优化：移除了均值计算的显存同步与规约通信开销，在维持深层训练数值稳定性的同时显著提升硬件执行吞吐。

* **门控非线性前馈网络（SwiGLU MLP）**

    * > **定义**：在双层前馈网络基础上增加第三个独立投影矩阵与 Swish 激活构成的双线性门控前馈网络拓扑。

    * 数学公式：$\text{SwiGLU}(x) = \left( \text{Swish}(x W_1) \otimes x W_3 \right) W_2$，其中 $\otimes$ 代表逐元素相乘。

    * 参数与性能表现：工程实现中通常将隐藏层维度从标准 MLP 的 $4D$ 缩减为 $\frac{8}{3} D$ 以保持总参数量和计算量一致，凭借更高阶的非线性特征拟合能力获得更优表征性能。

* **混合专家架构（Mixture of Experts，MoE）**

    * > **定义**：将单一稠密前馈层替换为多个结构相同但参数独立的专家子网络池，并由门控路由器进行稀疏动态激活的条件计算架构。

    * 动态路由规则：门控路由器（Router）为输入的每个 Token 动态计算分配至各个专家的得分分布，仅指派给激活得分最高的 Top-$k$ 个专家（通常 $k=1$ 或 $k=2$）执行前向计算并加权聚合输出。

    * 容量扩展特性：专家数量 $E$ 为预设超参数；在几乎不增加单样本前向浮点运算量（FLOPs）的前提下，实现模型总参数容量的数量级跃升。

    * 示意图解：


```text
      输入 Token x ---> [ 门控路由器 Router ] ---> 计算各专家得分 Top-k 路由
                               |
            +------------------+------------------+
            | (激活权重 a1)                        | (激活权重 a2)
            v                                     v
       [ 专家 1 (MLP) ]                     [ 专家 2 (MLP) ]    [ 专家 3... 未激活 ]
            |                                     |
            +------------------+------------------+
                               v 加权求和
                          最终输出 Token
```

## 密集预测与对称语义分割体系

### 全卷积网络与稠密预测机制

* **语义分割（Semantic Segmentation）**

    * > **定义**：为输入图像中的每一个像素分配预定义类别标签、仅进行像素级语义归类而不区分同类不同个体的稠密预测任务。

    * 密集计算困境：若采用滑动窗口以像素为中心切块分类，相邻像素重叠感受野导致海量冗余前向传播，引发不可承受的算力灾难。

* **全卷积网络（Fully Convolutional Network，FCN）**

    * > **定义**：将传统分类网络末端全连接层彻底替换为卷积层、支持任意尺寸输入并端到端输出像素级类别对齐特征图的网络结构。

    * 架构拓扑：采用对称的“下采样编码—上采样解码”沙漏型结构；编码阶段通过步长卷积与池化压缩空间分辨率、扩增通道以捕获大感受野全局语义；解码阶段通过上采样算子恢复空间几何分辨率。

    * 逐像素交叉熵损失函数：
      $$L = -\frac{1}{H \times W} \sum_{i=1}^H \sum_{j=1}^W \log \left( \frac{e^{s_{i,j, y_{i,j}}}}{\sum_{c=1}^C e^{s_{i,j, c}}} \right)$$
      在全图所有空间坐标上计算类别 Softmax 交叉熵损失并求全图均值。

    * 示意图解：


```text
      输入全尺寸图像 [ H x W x 3 ]
             |
             v  下采样编码 (步长卷积/最大池化: 空间收缩，通道扩增，提取全局语义)
      高层紧凑特征图 [ (H/32) x (W/32) x C_deep ]
             |
             v  上采样解码 (逆转分辨率，补充细节，恢复空间排布)
      逐像素分类图 [ H x W x Num_Classes ]
```


### 空间上采样与几何特征恢复

* **固定无参数上采样算子（Fixed Parameter-Free Upsampling）**

    * 最近邻插值（Nearest Neighbor）：将低分辨率网格的各标量值直接复制填充到邻近高分辨率扩展网格（如 $2 \times 2$ 扩展为 $4 \times 4$），计算高效但重构边缘呈现明显马赛克阶梯效应。

    * 钉床法（Bed of Nails）：将低分辨率特征数值填入放大网格对应的左上角位置，其余扩展空缺位置全部填充零值。

    * 最大反池化（Max Unpooling）：编码器执行最大池化（Max Pooling）时同步记录每个池化窗口内最大值所在的坐标索引（Pooling Switches）；解码器执行反池化时，依照记录的坐标将激活值精准填回对应网格，其余位置填零；以极低内存开销精准还原强激活点的空间拓扑。

    * 示意图解：


```text
      最大池化 (记下最大值坐标):
      [ 1  2 ]  池化  ===>  [ 6  8 ]  (同时记录坐标:
      [ 6  3 ]              Switches: (2,1), (2,2))

      最大反池化 (按记录坐标还原，其余填零):
      [ 6  8 ]  反池化 ===> [ 0  0  0  0 ]
                            [ 6  0  0  8 ]
```


* **转置卷积（Transposed Convolution）**

    * > **定义**：将输入特征标量与可学习卷积核相乘后按预设步幅在输出画布滑动对齐累加的可微上采样操作（又称分数步长卷积，Fractional-Strided Convolution）。

    * 运算机理：低分辨率输入特征图中的每一个标量首先与整个可学习权重核相乘生成放大局部块；随后按预设步长在输出画布滑动；不同输入元素展开的输出重叠区域数值线性相加；权重全流程参与反向传播优化。

    * 示意图解：


```text
      输入特征:           [ a ]                 [ b ]
                           |                     |
      权重核乘积:   [ a*w1, a*w2, a*w3 ]   [ b*w1, b*w2, b*w3 ]
                           \                 /
      对齐相加:     [ a*w1, a*w2, a*w3 + b*w1, b*w2, b*w3 ]
```


### 跨层特征复用与 U-Net 拓扑

* **U-Net 架构**

    * > **定义**：由收缩编码路径与扩张解码路径构成对称 U 形拓扑，并通过跨层跳跃连接直接拼接多尺度底层特征的密集分割模型。

    * 跳跃连接机制（Skip Connections）：将编码器收缩路径各阶段的高分辨率浅层特征图直接复制，并沿通道维度拼接（Concatenate）到解码器对应分辨率的上采样特征图中。

    * 表征优势：深层特征语义丰富但边界模糊，浅层特征空间分辨率高但缺乏高阶语义；跳跃连接使解码器在恢复抽象语义的同时直接借用浅层保留的原生边缘骨架与坐标线索，在医学影像与精细工业分割中构成主流基线。

    * 示意图解：


```text
      编码器 (收缩路径)                               解码器 (扩张路径)
      [输入图像] ---------------- 跳跃连接 --------------> [高精度输出]
         | (下采样)                                          ^ (上采样)
      [浅层特征] ---------------- 跳跃连接 --------------> [融合特征]
         | (下采样)                                          ^ (上采样)
      [中层特征] ---------------- 跳跃连接 --------------> [融合特征]
         \                                                 /
          +--------> [最底层瓶颈特征 (全局上下文)] ---------+
```

## 目标检测演进与实例分割架构

### 单目标回归与多目标组合爆炸

* **单目标多任务回归（Single-Object Multi-Task Learning）**

    * > **定义**：在卷积骨干网络末端同时并行构建分类分支与连续坐标回归分支以定位单一目标的多任务架构。

    * 损失函数构建：分类头输出类别得分并通过 Softmax 计算交叉熵损失 $L_{cls}$；坐标回归头输出边界框四元组 $(x, y, w, h)$ 并计算 L2 或 Smooth L1 损失 $L_{box}$；总损失为加权和：$L_{total} = L_{cls} + \lambda L_{box}$。

    * 多目标组合爆炸瓶颈：画面中真实目标数量动态不定，固定的全连接输出层无法直接承载变长目标列表；若采用滑动窗口在连续空间、尺度与长宽比维度进行全图遍历搜索，候选空间将陷入维度灾难。

    * 示意图解：


```text
                          +---> 分类头 (全连接 + Softmax) ---> 类别得分 C
                          |     (损失: 交叉熵损失 L_cls)
      [输入图像] ---> [ CNN 骨干 ]
                          |
                          +---> 坐标回归头 (全连接) ----------> 四元组 (x, y, w, h)
                                (损失: L2 / Smooth L1 损失 L_box)
```


### 两阶段检测体系演进

* **区域卷积神经网络（Regions with CNN Features，R-CNN）**

    * > **定义**：利用无监督启发式算法在原图提取候选区域，并对每个候选框独立缩放进行卷积特征提取、分类与边界微调的两阶段检测架构。

    * 三步流程：
        * 区域提议：利用 Selective Search 算法基于颜色与纹理合并筛选约 2000 个候选边界框；
        * 特征提取：将各候选区域从原图中裁剪并强制各向异性缩放（Warp）至固定尺寸（如 $224 \times 224$），独立输入深度 CNN 提取特征；
        * 分类与回归：对特征向量利用支持向量机（SVM）判定类别，利用独立线性回归器微调坐标。

    * > **易错点**：⚠️ R-CNN 存在严重的单图重复计算瓶颈，单张图像包含 2000 个候选区域必须执行 2000 次完整的深度 CNN 前向计算，单张图像推理耗时长达数十秒，完全无法满足工业落地实时性需求。

* **快速区域卷积神经网络（Fast R-CNN）**

    * > **定义**：全图仅执行一次卷积前向提取全局共享特征图，再利用感兴趣区域池化将候选区域投影对齐为定长特征的两阶段架构。

    * 感兴趣区域池化（RoI Pooling）：将候选边界框映射至主干网络顶层共享特征图上，通过网格划分将任意尺寸的特征区域均匀量化为固定维度向量，彻底免除成百上千次重复的前向卷积计算。

* **更快区域卷积神经网络（Faster R-CNN）**

    * > **定义**：引入端到端可训练的区域提议网络（RPN）替换传统 Selective Search，实现候选框生成与目标识别全流程联合优化的两阶段检测器。

    * 区域提议网络（Region Proposal Network，RPN）：在共享特征图各空间网格预设具有不同尺度与长宽比的锚框（Anchors）；通过小卷积滑动窗口同时输出各锚框的前景/背景二分类置信度得分及初步坐标回归偏移量。

    * 串行两阶段流程：RPN 筛选出前 $k$ 个高质量候选区域（RoIs），经 RoI Pooling 或 RoIAlign 投影截取后送入下游分类器与边界框精细回归器，实现了完全端到端的联合训练。

    * 示意图解：


```text
      [ 整张输入图像 ] ---> [ 共享卷积主干 (如 ResNet) ] ---> [ 共享全局特征图 ]
                                                                   |
                  +------------------------------------------------+
                  v
         [ 区域提议网络 RPN ]
         (以锚框 Anchor 为基准，预测前景/背景得分及坐标粗调偏移)
                  |
                  v 筛选出高质量 RoIs
         [ RoI Pooling / RoI Align ]
                  |
                  v
         [ 目标分类器与边界框精细回归器 ] ---> 输出最终类别与精准边界框
```


### 单阶段极速检测与集合预测范式

* **YOLO（You Only Look Once）**

    * > **定义**：将目标检测重构为全图网格单次前向密集回归边界框与类别概率的单阶段检测架构。

    * 网格密集预测规则：输入图像划分为 $S \times S$ 规则网格（如 $7 \times 7$）；若某物体的几何中心落入特定网格，该网格专职负责预测该物体；每个网格并行预测 $B$ 个边界框（包含 $(x, y, w, h)$ 几何坐标及 Objectness Score 置信度得分）以及类别条件概率分布。

    * 极大值抑制（Non-Maximum Suppression，NMS）：基于置信度阈值过滤无效候选框；在同一类别内计算预测框之间的交并比（IoU），对与最高得分框重叠度高于设定阈值的冗余框进行抑制剔除，仅保留唯一置信度最高的检测框。推理速度达到数十乃至上百 FPS。

* **检测变换器（Detection Transformer，DETR）**

    * > **定义**：基于 Transformer 架构与匈牙利匹配算法、将目标检测直接形式化为无锚框集合预测（Set Prediction）的端到端架构。

    * 对象查询（Object Queries）：Transformer 解码端输入一组预设数量固定（如 $N=100$）的纯可学习嵌入向量，在自注意力层中相互感知抑制重叠检测，在交叉注意力层向全局图像编码特征探测指定空间位置是否存在目标。

    * 匈牙利二分图匹配（Hungarian Bipartite Matching）：模型并行输出 $N$ 个预测项，使用匈牙利算法与真实标注目标进行全局成本最小的二分图匹配；无真实物体对应的查询自动匹配至特殊的“背景（No Object）”标签；一对一端到端集合匹配彻底免除了人工设计先验锚框（Anchors）与 NMS 后处理。

    * 示意图解：


```text
      输入图像 ---> [ CNN 提取局部特征 ] ---> [ 展平为 Tokens ]
                                                    |
                                                    v
                                        [ Transformer Encoder ]
                                        (全序列全局特征交互融合)
                                                    |
                                                    v
      可学习对象查询 [ Object Queries ] ===> [ Transformer Decoder ]
      (如预设 N=100 个探测向量)                  (自注意力与交叉注意力交互)
                                                    |
                                                    v
                                        [ 前馈网络 FFN 并行输出 ]
                                        (直接输出 100 个预测结果: 类别 + 边界框)
```


### 实例分割与连续对齐机制

* **Mask R-CNN**

    * > **定义**：在 Faster R-CNN 分类与边界框回归分支之外并行引入轻量级小型全卷积网络分支、实现端到端像素级掩码预测的实例分割架构。

    * 分支并行拓扑：在检测头原有类别全连接分类分支与边界框回归分支基础上，并行接入小型全卷积（FCN）分支，为每个候选区域输出分辨率对齐的二进制 Sigmoid 像素掩码。

    * 示意图解：


```text
                                        +---> 分类分支 (全连接)
                                        |
      [ 候选区域 RoIAlign 特征图 ] --------+---> 边界框回归分支 (全连接)
                                        |
                                        +---> 掩码预测分支 (小型 FCN)
                                              (逐像素二进制 Sigmoid 输出)
```


* **感兴趣区域对齐（RoIAlign）**

    * > **定义**：摒弃最近邻坐标取整舍入、通过双线性插值在特征图上进行连续特征采样的空间对齐算子。

    * 机理与对比：传统 RoI Pooling 在将浮点候选框坐标映射至离散特征图网格及划分子网格时，执行强制整数取整（Round/Floor），引发严重的亚像素坐标错位累积，破坏掩码预测边界精度；RoIAlign 在整个映射与采样点计算中全程保持浮点连续坐标，利用双线性插值连续计算采样点特征值并执行池化，彻底实现了特征图与原图空间坐标的无损精确对齐。

## 决策机理反演与模型表征可视化

### 浅层权重映射与像素显著性分析

* **第一层卷积核直观映射（Conv1 Weights Visualization）**

    * > **定义**：将神经网络第一层卷积核的可学习参数线性归一化为可视彩色微图以观察初级表征特性的直观可视化方法。

    * 呈现特性：首层权重核尺寸为 $K \times K \times 3$，与输入 RGB 物理通道严格对齐；训练收敛后自发涌现出针对特定方向与频率的条带明暗边缘检测算子（类 Gabor 滤波器）以及鲜明的补色对比色块，高度拟合生物初级视皮层（V1 区）感受野特性；深层特征通道数达数百上千，权重无法直接投影为直观几何微图。

* **像素显著性图（Saliency Maps）**

    * > **定义**：冻结网络参数，计算目标类别未归一化得分关于底层输入图像各像素的偏导数绝对值以反映像素敏感度的空间归因图。

    * 数学定义：
      $$\text{Saliency}(i, j) = \max_{c \in \{R, G, B\}} \left| \frac{\partial S_c}{\partial I_{i, j, c}} \right|$$

    * 物理机理：导数 $\frac{\partial S_c}{\partial I_{i, j}}$ 严格量化了输入像素 $(i, j)$ 发生微小摄动时目标类别得分 $S_c$ 的瞬间响应斜率；偏导数绝对值极大的像素构成了模型判决的核心敏感区域；局限在于关注底层高频像素梯度，往往伴随大量离散孤立的高频噪点。

### 类激活映射机制与架构泛化

* **类激活映射（Class Activation Mapping，CAM）**

    * > **定义**：利用分类全连接层的权重对最后一个卷积层输出的特征图进行线性加权累加、生成粗粒度宏观区域定位热力图的方法。

    * 网络拓扑强约束：网络末端必须严格由“最后一个卷积层 $\to$ 全局平均池化层（GAP） $\to$ 最终分类全连接层”构成。

    * 代数推导与定义：
      $$S_c = \sum_k w_k^c \left( \frac{1}{Z} \sum_{i, j} A^k_{i, j} \right) = \frac{1}{Z} \sum_{i, j} \left( \sum_k w_k^c A^k_{i, j} \right)$$
      类别 $c$ 的激活热力图定义为：
      $$M_c(i, j) = \sum_k w_k^c A^k_{i, j}$$
      矩阵 $M_c$ 经双线性插值上采样至原图尺寸，呈现模型做出分类决策所依据的宏观主体区域。

    * 边界局限：若卷积与分类层之间存在多层感知机、密集跳跃或自注意力连接，CAM 的线性可交换性假设失效。

    * 示意图解：


```text
      最后一个卷积层特征图 A^k (K 个通道)
                   |
                   v 全局平均池化 (GAP)
      向量 F_k = (1/Z) * \sum_{i,j} A^k_{i,j}
                   |
                   v 全连接层权重 w_k^c 线性加权
      目标类别得分 S_c = \sum_k w_k^c * F_k
```


* **梯度加权类激活映射（Grad-CAM）**

    * > **定义**：利用目标类别得分关于任意指定卷积层特征图的反向传播梯度均值作为通道重要性权重、无侵入式适配任意卷积拓扑的可视化方法。

    * 通道权重计算公式：
      $$\alpha_k^c = \frac{1}{Z} \sum_{i} \sum_{j} \frac{\partial y^c}{\partial A^k_{i, j}}$$

    * 正向加权累加与激活截断：
      $$L_{\text{Grad-CAM}}^c = \text{ReLU} \left( \sum_k \alpha_k^c A^k \right)$$

    * > **注意**：此处必须施加 ReLU 激活截断，技术考量在于多分类决策中仅保留对提高当前类别得分 $y^c$ 具有正向促进增益的视觉特征；梯度为负的特征属于抑制性线索（多对应其他干扰类别），在生成热力图时坚决置零剔除。

    * 示意图解：


```text
      针对类别 c 的预测得分 y^c
                   |
                   v 反向传播计算梯度: \partial y^c / \partial A^k_{i,j}
      [ 梯度全局平均池化 ] ---> 得到特征图重要性权重 \alpha_k^c
                   |
                   v
      [ 对各特征图加权线性组合: \sum_k \alpha_k^c * A^k ]
                   |
                   v
      [ 施加 ReLU 激活 (仅保留正向促进特征) ] ---> 输出 Grad-CAM 定位热力图
```


### 自注意力权重空间投影

* **自注意力图空间投影（Self-Attention Map Visualization）**

    * > **定义**：直接提取视觉 Transformer 自注意力矩阵行向量渲染为图像块关联系数、无需反向导数计算即可直观解释模型交互逻辑的方法。

    * 固有可解释性机制：自注意力矩阵 $A = \text{Softmax}\left(\frac{Q K^T}{\sqrt{d_k}}\right)$ 的每一行天然度量了特定查询 Token 与全图所有其余键 Tokens 之间的相关性权重；提取类别标记 `[CLS]` 在末层各注意力头对所有图像 Patch Tokens 的注意力分布并重排为二维网格，可直接渲染出高语义一致性的决策热力图。

## 视频时空张量建模与基线融合范式

### 四维时空张量与采样切片策略

* **四维时空张量（4D Spatio-Temporal Tensor）**

    * > **定义**：沿物理时间轴有序堆叠连续图像帧构成的高维视频数据计算表征。

    * 张量数学形式：$X \in \mathbb{R}^{C \times T \times H \times W}$，其中 $C$ 为通道数（RGB 彩色为 3），$T$ 为时序连续帧数，$H$ 与 $W$ 分别为帧平面的空间高度与宽度。

    * 硬件吞吐与存储瓶颈：标准清晰度（SD）视频每分钟约消耗 1.5 GB 存储；$1920 \times 1080$ 高清（HD）原始视频流每分钟高达 10 GB；海量吞吐导致 GPU 显存无法一次性吞入长视频并驻留中间反向传播激活值。

    * 示意图解：


```text
      [ 静态 2D 图像 ]                          [ 动态时空视频张量 ]
      高度 H x 宽度 W x 通道 C                  时间 T x 高度 H x 宽度 W x 通道 C
      ┌───────────┐                            ┌───────────┐
      │           │                            │  帧 t+2   │
      │   RGB     │                            ├───────────┼───────────┐
      │   图像    │                            │  帧 t+1   │  沿时间轴 │
      └───────────┘                            ├───────────┼───────────┼───────────┐
       (单一静态空间切片)                       │   帧 t    │ 连续帧堆叠│ 形成 4D 体积│
                                               └───────────┴───────────┴───────────┘
```


* **时空压缩与片段级推理（Clip-Level Sampling & Aggregation）**

    * 时空降采样：时间维度抽样降帧（如由 30 fps 下采样至 5 fps），空间维度缩放裁剪（如缩减至 $112 \times 112$ 或 $224 \times 224$），一段 3.2 秒视频片段经压缩后体积可缩小至几百 KB。

    * 片段截取与集成推理：训练时以滑动窗口截取短视频片段（Clips，如固定 16 或 32 帧）作为基本计算单元；测试推理时在长视频中均匀抽取若干个片段（如 10 个片段）分别送入网络前向预测，对各个片段的输出类别概率分布求算术平均得出整段视频的最终分类决策。

### 单帧基线先验与帧间早期/晚期融合

* **单帧 2D CNN 基线（Single-Frame 2D CNN Baseline）**

    * > **定义**：完全忽略帧间时序关联、将视频抽样帧作为独立静态图像分别送入 2D CNN 分类并将预测分数全量取平均的基准方法。

    * Sports-1M 基准表现：在涵盖 487 种细粒度体育动作的数据集上，单纯单帧基线的 Top-5 分类准确率高达 77.7%。

    * > **易错点**：⚠️ 单帧分类器高准确率源自强大的**场景背景与静态姿态先验**（如湖面场景强关联“划船”、特定弓步姿势强关联“击剑”），模型无需捕捉动态轨迹即可命中正确标签；其本质缺陷在于无法区分依赖时序因果的动作（如“举起杠铃”与“放下杠铃”、“跌倒”与“站立”），容易造成对模型动作理解能力的虚假误判。

* **晚期融合架构（Late Fusion）**

    * > **定义**：输入的 $T$ 帧图像各自独立通过权重共享的 2D CNN 主干提取特征图，直至网络最末端才在时间维度进行特征聚合的架构。

    * 聚合方案：
        * 展平拼接全连接：将 $T$ 个高层特征图展平拼接为长度 $T \cdot D \cdot H \cdot W$ 的向量送入全连接层，参数量随帧数 $T$ 线性暴增且无法适应变长视频；
        * 时间维度池化（Temporal Pooling）：在时间轴上执行全局平均池化或最大池化，压缩为单一紧凑特征 $D \times H \times W$ 后经线性层分类。

    * > **易错点**：⚠️ 晚期融合导致**运动信息的深层丢失**。深层卷积与池化高度抽象出语义类别概念，对精细空间坐标位移不再敏感；底层像素级的微观位移轨迹在浅层未进行跨帧交互，到达深层时已被不可逆地平滑抹除。

    * 示意图解：


```text
      [ 晚期融合架构 (Late Fusion) ]
      帧 1 ──> [ 2D CNN ] ──> 特征图 1 ──┐
      帧 2 ──> [ 2D CNN ] ──> 特征图 2 ──┼──> [ 时间全局池化 ] ──> 紧凑特征 ──> 分类得分
      ...                                 │   (在前向最末端才聚合,
      帧 T ──> [ 2D CNN ] ──> 特征图 T ──┘    底层的细微运动线索早已丢失)
```


* **早期融合架构（Early Fusion）**

    * > **定义**：在网络输入端直接将 $T$ 帧图像沿通道维度拼接堆叠为三维输入矩阵、首层采用大核 2D 卷积一步完成时间维折叠的架构。

    * 第一层卷积配置：输入张量重塑为 $3T \times H \times W$，第一层 2D 卷积核尺寸相应设为 $k_h \times k_w \times 3T$，直接一步投影至特征维度 $D$，后续全由标准 2D 卷积层处理。

    * > **易错点**：⚠️ 早期融合具有**过于贪心（Too Greedy）**的缺陷。在网络第一层即彻底折叠了时间轴，后续计算全盘退化为静态 2D 卷积，无法构建“局部运动基元 $\to$ 部件轨迹 $\to$ 整体复合活动”的深层时空层级抽象；卷积权重与特定帧绝对绑定，完全丧失时间平移等变性。

    * 示意图解：


```text
      [ 早期融合架构 (Early Fusion) ]
      全部 T 帧图像 ──> 强行堆叠为通道维 [ 3T x H x W ] ──> [ 第一层大卷积核 ] ──> [ 标准 2D CNN ] ──> 分类得分
                                                            (第一步即彻底折叠时间轴)
```

## 时空三维卷积与光流解耦双流体系

### 三维卷积核运算与时间平移等变性

* **3D 卷积运算（3D Convolution）**

    * > **定义**：卷积核在二维空间网格与一维时间轴上同步执行立体滑动窗口内积求和的三维张量特征提取操作（慢融合范式，Slow Fusion）。

    * 卷积核立体尺寸：$K \in \mathbb{R}^{C_{\text{in}} \times k_t \times k_h \times k_w}$，具备独立的物理时间深度 $k_t$。

    * 运算机理：卷积核不仅在空间平面 $(H, W)$ 上滑动，同时沿时间轴 $T$ 连续滑动步进计算局部时空内积。

    * 示意图解：


```text
      2D 卷积操作 (空间滑动, 时间全覆盖或无时间)       3D 卷积操作 (时空立体滑动)
                空间高度 H                                       空间高度 H
              ┌─────────────┐                                  ┌─────────────┐
      空间宽度│             │                        空间宽度 W│   ┌─────┐   │
        W     │  [ 核 khxkw]│                          ┌───────┼───│核   │───┼───────┐
              └─────────────┘                          │       │   │kt*kh│   │       │
            (仅在 2D 平面内移动)                       │       └───│ *kw │───┘       │ 时间轴 T
                                                       └───────────┼─────┼───────────┘
                                                                   └─────┘ (时空三维连续滑动)
```


* **时间平移等变性（Temporal Translation Equivariance）**

    * > **定义**：当输入动作模式在时间轴上发生平移时，输出特征响应在时间维度产生相应等量平移的代数性质。

    * 早期融合机理局限：2D 早期融合卷积核时间跨度绑定全序列长度，输入动作若发生在第 1 秒由前段通道权重计算，若发生在第 10 秒则前段权重无法滑动复用，必须由后段通道权重重新拟合，不具备时间平移等变性。

    * 3D 卷积机理优势：时间核大小局部化（如 $k_t = 3$），核沿时间轴滑动计算；无论动作发生在视频的开头、中间或末尾，滑动到该时间区间的同一组 3D 卷积核均能激发出完全相同的特征响应，实现权重高度复用与优异的时序泛化。

### C3D 拓扑与时空融合范式对比

* **C3D（Convolutional 3D）架构**

    * > **定义**：将二维 VGG 拓扑全面升维至三维时空空间的深层三维卷积动作识别网络。

    * 网络超参数规范：全网统一采用 $3 \times 3 \times 3$ 时空小卷积核（时间步幅 1、空间步幅 1、时空对称填充 1）；交替堆叠 $2 \times 2 \times 2$ 3D 最大池化层（除首层池化时间步幅为 1 以保留初始时序分辨率外，后续层时空各维度均减半）。

    * 算力开销代价：在单次前向传播中，AlexNet 仅需 0.7 GFLOPs，2D VGG-16 为 13.6 GFLOPs，而时空三维化的 C3D 算力激增至 39.5 GFLOPs（接近 VGG-16 的 3 倍）。

* **时空融合范式对比**

    | 融合范式 | 时间轴处理策略 | 空间轴处理策略 | 时间平移等变性 | 计算开销与参数效率 |
    | :--- | :--- | :--- | :--- | :--- |
    | **晚期融合 (Late Fusion)** | 前期保留时间维度，最末端全局池化压缩 | 逐帧独立通过 2D CNN 渐进构建 | 差（末端无时序顺序感知） | 参数量小，但深层丢失底层运动细节 |
    | **早期融合 (Early Fusion)** | 第一层 2D 卷积将时间轴作为通道完全折叠 | 后续全由普通 2D CNN 渐进构建 | **无**（时间参数无法滑动复用） | 参数量小，但无法学习分层时序特征 |
    | **3D 慢融合 (Slow Fusion)** | 利用 3D 卷积与池化在全网逐层平滑收缩 | 利用 3D 卷积与池化在全网逐层平滑收缩 | **具备严格的时间平移等变性** | **计算极其昂贵**（GFLOPs 呈倍数激增） |

### 光流场表征与双流解耦网络

* **生物视觉运动感知与光流场（Optical Flow Field）**

    * 点动生物实验启示：人类仅凭关节点反光白点在暗室中的运动轨迹即可在几十毫秒内识别复杂动作，证实生物视皮层中运动（Motion）与外观（Appearance）由解耦的独立通路处理。

    * > **定义**：光流是指空间运动物体在观察成像平面上的像素瞬时速度矢量，描述极短时间间隔内第 $t$ 帧像素 $(x, y)$ 在第 $t+1$ 帧中的位移矢量 $(x + dx, y + dy)$。

    * 数学张量形式：$F(x, y) = (dx, dy)$，由水平位移场 $dx$ 与垂直位移场 $dy$ 构成双通道密集二维矢量矩阵，基于光学强度恒定假设求解。

* **双流卷积网络（Two-Stream Network）**

    * > **定义**：将视频显式解耦为单帧静态空间流与多帧密集光流时间流、双塔独立提取特征并在末端晚期融合的动作识别架构。

    * 双塔架构配置：
        * 空间流（Spatial Stream）：输入单张静态 RGB 图像，利用 ImageNet 预训练的 2D CNN 提取场景环境与静态物体特征；
        * 时间流（Temporal Stream）：将连续 10 帧位移光流沿通道堆叠为包含 $10 \times 2 = 20$ 通道的输入张量，由另一个 2D CNN 专职提取运动位移轨迹；
        * 决策融合：两路网络在分类输出端对预测概率执行晚期加权求和，输出最终动作分类。

    * 基准表现与抗噪机理：在 UCF-101 动作识别基准上，单纯时间流（光流）模型的分类准确率大幅超越空间流（RGB）模型；其物理机理在于光流场彻底剔除了复杂的静态环境纹理（如墙壁、观众席），迫使网络全量拟合人体运动矢量几何，显著抑制了对背景环境的过拟合。

    * 示意图解：


```text
      原始视频片段
         │
         ├── [ 抽取单帧静态 RGB 图像 ] ────> [ 空间外观流 2D CNN ] ──> 外观分类概率 ──┐
         │                                                                           ├──> 晚期加权融合 ──> 最终动作预测
         └── [ 预先计算连续多帧密集光流 ] ──> [ 时间运动流 2D CNN ] ──> 运动分类概率 ──┘
             (堆叠 10 帧水平+垂直位移, 共 20 通道)
```

## 长期时序表征与架构膨胀演进

### 循环卷积网络与时空状态记忆

* **级联循环神经网络（CNN + RNN / LSTM）**

    * > **定义**：使用 2D/3D 卷积网络抽取各视频短片段高阶语义向量、输入循环神经网络在隐状态中递归累积长程时序记忆的级联模型。

    * 任务范式：支持整段长视频序列的多对一动作分类，以及逐帧动作切分与事件预测的多对多时序标注。

* **循环卷积网络（Convolutional LSTM，ConvLSTM）**

    * > **定义**：将传统 LSTM 中的所有全连接矩阵乘法全部替换为空间二维卷积算子、在时序传递中严格维持特征图二维空间拓扑的循环网络。

    * 数学公式：$\mathcal{H}_t = \tanh(W_{hh} * \mathcal{H}_{t-1} + W_{xh} * \mathcal{X}_t + b)$，其中 $*$ 代表空间卷积，输入 $\mathcal{X}_t$ 与隐状态 $\mathcal{H}_t$ 均为维持空间网格的三维张量 $C \times H \times W$。

    * 工业扩展瓶颈：沿时间轴存在严格的不可切分串行计算依赖，无法在现代 GPU 集群上充分实现横向并行化训练。

### 非局部时空自注意力机制

* **非局部神经网络（Non-Local Neural Networks）**

    * > **定义**：将自注意力机制拓展至四维时空张量空间、支持任意空间与时序激活点在单层前向中实现全局瞬时交互的即插即用注意力模块。

    * 计算流程：输入特征张量 $X \in \mathbb{R}^{C \times T \times H \times W}$，通过 $1 \times 1 \times 1$ 3D 卷积分别投影为时空 Query、Key 与 Value；Query 与 Key 矩阵相乘计算全时空点积并通过 Softmax 归一化生成注意力权重图 $A$；与 Value 矩阵相乘加权聚合后，经 $1 \times 1 \times 1$ 卷积投影并与输入张量 $X$ 执行恒等残差跳跃相加输出特征张量 $Y$。

    * 结构协同：以残差形式无缝插入 3D ResNet 主干中，在保留局部时空卷积归纳偏置的同时，赋予网络捕获超长距离时空协同依赖的能力。

    * 示意图解：


```text
      输入特征张量 X [ C x T x H x W ]
         │
         ├── 1x1x1 3D卷积 W_θ ──> 时空 Query ──┐
         │                                     ├──> 矩阵相乘求内积 ──> 时空 Softmax ──> 注意力权重图 A
         ├── 1x1x1 3D卷积 W_φ ──> 时空 Key   ──┘                                             │
         │                                                                                   ▼
         ├── 1x1x1 3D卷积 W_g ──> 时空 Value ────────────────────────────────────────── 矩阵相乘加权
         │                                                                                   │
         │                                                                                   ▼
         │                                                                       1x1x1 3D卷积投影 W_z
         │                                                                                   │
         └───[ 恒等残差跳跃连接 ]──────────────────────────────────────────────────────────── 逐元素相加 (+)
                                                                                             │
                                                                                             ▼
                                                                                   输出特征 Y [ C x T x H x W ]
```


### 膨胀卷积网络与权重响应等价性定理

* **膨胀 3D 卷积网络（Inflated 3D ConvNet，I3D）**

    * > **定义**：将成功的 2D 卷积网络架构及其在图像数据集上预训练的权重参数沿时间维度复制膨胀、无损迁移为 3D 视频模型的架构设计方法。

    * 权重时间膨胀数学初始化：设二维卷积核权重为 $W_{\text{2D}} \in \mathbb{R}^{C_{\text{out}} \times C_{\text{in}} \times k_h \times k_w}$，膨胀为时间深度为 $k_t$ 的三维卷积核 $W_{\text{3D}}$：
      $$W_{\text{3D}}(:, :, \tau, :, :) = \frac{1}{k_t} W_{\text{2D}}, \quad \forall \tau \in \{1, 2, \dots, k_t\}$$
      偏置保持不变：$b_{\text{3D}} = b$。

    * 示意图解：


```text
      2D 静态卷积核 (尺寸: kh x kw)
      ┌─────────────┐
      │ 2D 图像权重 │
      │    W_2D     │
      └─────────────┘
             │
             ▼ [ 权重膨胀操作: 沿时间轴连续复制 kt 份, 并除以 kt ]
      ┌─────────────┬─────────────┬─────────────┐
      │ W_2D / kt   │  W_2D / kt  │  W_2D / kt  │  --> 3D 卷积核 (尺寸: kt x kh x kw)
      └─────────────┴─────────────┴─────────────┘
```


* **I3D 权重膨胀响应等价性定理**

    * > **定义**：向膨胀初始化的 3D 卷积层输入一段连续静止视频切片时，其前向响应输出在代数上与原始 2D 卷积对单帧静态图像的输出严格恒等。

    * 代数恒等性推导证明：
        * 设输入连续 $k_t$ 帧静止视频帧满足 $I_\tau(u, v) = I(u, v), \forall \tau \in \{1, \dots, k_t\}$；
        * 2D 卷积在静态图像 $I$ 上的局部响应输出为：$y_{\text{2D}} = \sum_{u, v} W_{\text{2D}}(u, v) I(u, v)$；
        * 3D 卷积前向响应输出展开为：
          $$y_{\text{3D}} = \sum_{\tau=1}^{k_t} \sum_{u, v} W_{\text{3D}}(\tau, u, v) I_\tau(u, v) = \sum_{\tau=1}^{k_t} \sum_{u, v} \left(\frac{1}{k_t} W_{\text{2D}}(u, v)\right) I(u, v)$$
        * 由于内层求和与时间索引 $\tau$ 无关，提取公因子求和：
          $$y_{\text{3D}} = \left(\sum_{\tau=1}^{k_t} \frac{1}{k_t}\right) \cdot y_{\text{2D}} = \left(k_t \cdot \frac{1}{k_t}\right) \cdot y_{\text{2D}} = 1 \cdot y_{\text{2D}} = y_{\text{2D}}$$
        * 加上偏置恒有 $y_{\text{3D}} + b = y_{\text{2D}} + b$。证毕。

    * > **注意**：权重初始化必须除以 $k_t$ 的物理必然性在于：若不除以时间步长 $k_t$，沿时间维度的 $k_t$ 次线性累加将使输出激活值幅值直接放大 $k_t$ 倍，破坏在 2D 预训练模型中精确校准的均值与方差平衡，引发后续非线性激活层（如 ReLU、Softmax）的数值饱和与梯度消失；除以 $k_t$ 严格保障了前向激活信号的能量守恒。

### 视频自监督预训练与多模态基座

* **视频掩码自编码器（Video MAE）**

    * > **定义**：将 Vision Transformer 拓展至时空网格、通过超高比例随机图块掩码与像素重建实现无监督表征学习的自监督模型。

    * 超高掩码率机制：视频时间轴存在极高的时序信息冗余，模型采用高达 90% ~ 95% 的空间-时间图块掩码率（Masking Ratio）；解码器仅凭残存 5% ~ 10% 的极稀疏时空图块重建完整时空像素流，迫使骨干网络建立对物理动力学时序演化规律的高阶表征。

    * 识别基准突破：在 Kinetics-400 动作识别基准上，Top-1 准确率由早期传统模型的约 60% 跨越式跃升至现代自监督预训练大模型的 90% 以上。

* **视频多模态基座大模型（Video Foundation Models）**

    * > **定义**：将视频时空特征与音频频谱、自然语言指令映射至统一潜空间、支持多种开放下游任务的统一视觉时空模型。

    * 综合推理任务拓展：除动作分类外，全面支持细粒度时空动作定位（Spatio-temporal Detection）、视觉引导的声音源分离（Visually-guided Audio Separation）以及第一人称视角的具身交互推理。
