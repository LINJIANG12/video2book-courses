咱们之前聊过处理图像时 Transformers 是怎么用的。咱们把图像切成一个个图像块，说白了，这就构成了一个序列，对吧？就是图像被切成了 S x S 或者比如 3x3 的图像块，每个图像块都变成我们说的 token。Token 通常就是一种线性投影，把图像重塑成向量，基本上就是一个 D 维向量。你看在这张幻灯片上，但既然图像变成了图像块，什么变得关键？咱们丢掉了什么？主要是位置信息，也就是图像的二维位置，对吧？这就是为什么我们要引入位置嵌入。具体做法有很多，比如把序列号设为 1、2、3，或者用 xy 坐标的二维形式。把这两部分加起来生成新 token，然后像往常一样送入 Transformer 层，经过自注意力和层归一化，还有 MLP 里讲过的，以及上周提到的那些内容。最后输出层会生成输出向量，供各种应用使用。

计算机视觉的主要应用之一就是分类。咱们从图像分类说起。在图像分类里，关键是要能以某种方式编码，或者生成能代表该类别的输出结果。我们常加一个 token 进去，这是个特殊输入，维度一样，但它是可学习的参数。输出空间里这个 token 代表的值最后会变成类别，也就是概率向量，所以是个 C 维向量，代表各类别的概率。我们管它叫类别 token（class token）。这是一种基础做法，用视觉 Transformers 做图像分类。这是最标准的方式，图像分类。不过 Transformers 不只用于分类，还能做很多其他任务，今天咱们讲几个。

还有，上周咱们聊了另一种 Transformer 变体，它处理 N 个 token。拿到这些 token 后，我们直接进 Transformer 层。大家应该还记得上次咱们聊了多层 Transformers 结构。之前提过，这里要加位置嵌入。图像是整体输入的，不像语言是序列数据，所以不用做掩码。毕竟我们不能用到未来的信息。最终 Transformers 会给出输出结果，每个输入对应一个向量图像块。另一种训练方式是不用单独的 class token，直接拿输出结果经过池化层，就能得到代表 C 个类别的概率向量。我讲了两种方案：一种是用 class token，另一种是取所有输出 token 做池化或投影，得到类别向量。监督方式跟之前说的一样，就是反向传播，定义损失函数，比如二元交叉熵、软标签、最大损失这些。这就是视觉 Transformers。简单来说，视觉 Transformers 就是这样。多年来这种架构在各种不同应用中基本没变，现在很多现代架构都用到了这些组件，跟咱们讲的很像。

不过幻灯片里还有一些优化措施，就是上周讲的那些。我花几分钟快速过一下，咱们聊聊这些，我想让你们明白，有很多调整和优化能提升性能，让 Transformers 训练更稳定。其中一个就是残差连接。这个层归一化基本上是在残差连接外面，也就是说这里得到的结果都要做归一化，但这不影响我们像 ResNet 那样保留恒等映射，对吧？所以解决办法是引入层归一化，通常把它放在前面，一个在自注意力之后，另一个在 MLP 层之前。这样既有归一化，又保留了恒等映射。还有其他归一化方法，比如 RMS 归一化，也就是均方根归一化。这其实是一种非常基础的归一化，不使用每个特征的均值来做归一化，但这让训练更稳定。再说这些方法都被实证证明是更好的选择。尽管有理由解释它们为何有效，但采用它们的主要原因通常只是它们能让训练过程更稳定。

另一种选择是不用简单的 MLP，而是用 SwiGLU MLP，也就是所谓的门控非线性。除了 W1 和 W2 这两个权重矩阵，我们再加上第三个，从而构成一种门控非线性。它的作用是增加可训练参数，而且不只是增加参数，更是为小架构带来更好的非线性。即使我们把隐藏层的值设为 8 再除以 3，参数量保持不变，但效果更好，学习高维非线性。这就是在起作用。

在这一层里，最后一部分是混合专家（MoE），现在很常用。就是现在这些很现代的架构不再只用一组 MLP 层，而是可以有多组 MLP 层，每个都是一个专家。具体做法是通过一个路由器把 tokens 分派到专家中的 A 个关。这样一来，实际激活的专家其实很少。不过话分说回来，它这么做是为了增加参数数量，帮我们学到更鲁棒的模型，计算量却没怎么增加。这些 MLP 都是并行的，所以我们可以并行运行多个专家。就像我刚才讲的，现在所有的大语言模型还有那些现代模型都在用这些技术。目前我们知道的这些语言模型都在用这类调整手段。

以上就是我刚才提到的所有调整方法的总结。这有点像偏置项，不对，它是一个完全独立的可训练的参数。你可以训练一个前馈网络，或者只用一个线性投影，把它转换成概率向量。所以它不是那种加减法。另外别忘了你这里有这么多，就是这里的自注意力网络，对吧？就是这些层。这些自注意力层主要是在融合信息，在所有 tokens 和这个 class token 之间建立注意力关联。所以当你在进行监督时，损失函数就会介入，它会代表 class token，也就是类概率向量。

那么问题是，如果存在好的直觉，不同的专家在做什么？问得好，因为它们是并行训练的，且初始化各不相同。所以它们往往会去学习某一个方面或者相关的，也许有时甚至非常相关的方面。但这只是增加了算力和参数，让网络在确实需要学习时去学习不同的内容。如果它确实必须学习，例如如果你要覆盖多个概率分布，那么借助这些 MoE，你通常就有能力把数据的这些模式分离出来。

那么问题是，专家的数量是不是一个超参数？是的，绝对是，它是一个超参数。据我所知，它通常是预先设定好的，不一定要过度微调它们。但没错，它们都是超参数，对，它们确实存在。

那么为什么把层归一化前置能帮到我们呢？学习恒等变换。来看这个架构，你能实现任意形式的恒等吗？毕竟残差连接之后特征值就变了，因为有归一化，特征值永远不会有恒等，对吧？因为紧接着就是层归一化，所以我们把它加进来。

咱们常用的另一种办法是别给每个像素跑网络，而是训练一个网络：输入是图像，然后直接输出整张像素图，也就是分割图。不是单个标签，而是一堆标签组成的矩阵，对吧？这样咱们就搞定分割任务了。要解决这个问题，我们需要在输入端设置一个和图像尺寸相同的成行，而且输出端也需要某种形式的膨胀层。不能用全连接层这些结构，因为现在我们是在生成图像。正因如此，我们需要特别处理，要让网络保持膨胀状态。这通常就是我们所说的全卷积神经网络，或者叫 FCN。

全卷积神经网络确实是个很好的思路，但有个需要注意的地方。有个问题：这些图像很大，这些层也会变得非常大，需要优化的参数极多，尤其在早期我们还没有强大 GPU 的时候。这对训练算法来说是个瓶颈，一个问题，一个挑战。正因如此，算法逐渐演变成从全尺寸图像开始处理，在分辨率方面我们通过下采样操作，让卷积的空间分辨率越来越小；然后到中间某处分辨率会很低，但与此同时通道数变得很多；然后从那里我们再回到与图像相同的尺寸去生成输出像素。而为了做到这一点，下采样我们知道怎么做，对吧？下采样很简单，我们讲过了，我们讲过池化操作、步长卷积，还有其他几种，也就是这里可以运用到的步骤或操作。但在上采样这边，我们其实并不知道该怎么做上采样，对吧？因为我们没有反池化，也没有反向步幅卷积这类操作。正因如此，我们不得不发明一些能逆转下采样的新操作。

咱们简单说说上采样是怎么处理的。上采样其实不难，可以用反池化操作。方法有好几种，比如最近邻法。拿 2x2 来举例，比如把 2x2 矩阵扩到 4x4，直接复制就行，就是给每个位置找低分辨率里最近的值；或者用钉床法，上采样后只保留角点那个值，复制数据，其余填 0，过几层卷积后这些数值就开始变化了。出现如果在编码端用最大池化，我们可以记下最大值的位置，被选中的那些，然后复制数据就在反池化，也就是最大反池化那个阶段，最大值就是在那里确定的。简单说，编码时存好这些位置，解码上采样时再复用这些坐标。

但这里有个大问题，对吧？边界框的组合方式太多了，而且这算法扩展性太差。你看 2014 年以前发表的那些文献，大家当时都在研究这个。关于如何寻找区域，研究很多。这些区域里包含物体的概率比较高，也就是区域提议（region proposals）。只要能找到区域提议，问题就简单多了，我可以用之前讲过的方法，对吧？对图像来说，如果我们有了区域提议，咱们直接把这个图像块切出来，跑一遍卷积神经网络就行，对吧？在图像块上跑卷积神经网络来分类，顺便把边界框再微调一下。所以先分类，不对，是分类，然后把边界框调整，把目标检测出来。咱们既能给框分类，要是坐标得微调一下也能处理。这就是所谓的 R-CNN 算法。虽然它有点毛病，但确实管用，这是早期的算法之一。2014 年发表在 CVPR 上，这特别慢，因为每个框都得跑一遍完整的卷积神经网络。

不过有个问题：咱们可以这样做，与其按原来的方式处理，不如换个思路，在每个框里跑卷积神经网络。因为卷积能保留空间信息，对吧？它们要么下采样要么上采样，咱们总能追踪到它们在像素空间里的位置，对吧？所以这时候咱们不再分别运行卷积神经网络，而是直接对整张图做一次大卷积。现在特征图里就有了区域对应整张图。咱们看看这些区域在上面跑个小 CNN，生成输出。对于这两个想要的输出，先是框的偏移量，比如边界框要不要微调，或者是物体属于哪一类。咱们快速过一下这个 CNN，你可以用卷积神经网络做些基础算法，比如检测物体和它的边界框之类的。

关键问题是提议区域的数量是不是预先定好的？简短回答：是的，我也简单讲讲区域提议网络（RPN）。算法很简单，对吧？第一种是把提议区域的边界框直接画在图像上，第二种是把它放在卷积神经网络的特征图上。两者都会输出类别标签，以及用于优化检测位置的偏移量。但这意味着咱们得先处理边界框，咱们得先有个区域提议，再用一个区域提议网络来告诉咱们该在图像的哪儿找。关于怎么构建区域提议网络 RPN，已经有研究了。这里我们就随机启动，用 CNN，我们尝试在图像不同位置随机启动，再经过一层层卷积，我们细化那些更可能含有物体的区域，因为我们有物体的标签和位置，所以能监督这个过程。然后每个还会细化边界框坐标。基本上区域提议网络做的就是细化这些框，每个高概率还有物体的框底，以及框输出框，也就是对框的校正。坐标和这些维度的细节我都略去了，留给你们课后自己看，免得在这个算法上花太多时间。

重点来了，回到你刚才的问题。我们通常会选出概率最高的前 k 个区域作为候选，它们包含物体的概率最高，所以被选为这张图的候选区域。这是一张简单的图像，只有一个物体，所以大部分区域都集中在这个物体周围。但通常情况并非如此，所以在很多场景下区域候选会有不同的设置，这样能选出概率更高的不同物体等等。讲完 R-CNN 和 Fast/Faster R-CNN 后我想说，大家最好花点时间把细节吃透，自己动手算一遍会很有帮助。但现在这类算法 R-CNN、Mask R-CNN 已经不再用了，因为它们计算量非常大。了解我们如何走到这一步很重要，但这些算法出于种种原因如今已经不常用了一。原因之一是我们需要两个独立网络：一个区域提议网络，还有一个分类和边界框细化网络。也就是说检测每张图片里的物体，至少得跑两遍，对吧？这也是为什么在这些之后有了新进展，开始采用单阶段的方法。

比如目标检测器 SSD，其中最火的一个叫 YOLO。如果你做过计算机视觉，那你肯定听过 YOLO，即便到现在，尽管它是重度卷积网络，至少它的早期版本，在很多工业应用里 YOLO 都被用作基础。目标检测 YOLO 检测速度快，性能极佳。咱们简单聊聊 YOLO 是怎么检测物体的。它只需对图像做一次扫描，就能生成所有边界框。它把图像划分成 S x S 的网格，比如这里网格大小就是 7x7。对于网格里的每个单元格，它通过全卷积网络输出物体出现在该位置的概率，还有边界框的修正参数。它会生成 B 个边界框用来修正框内的物体，同时它还会输出物体类别的概率。比如如果 B=2，就只会生成两个概率不同的边界框。它会同时对所有边界框做这样的处理。所以基本上就是同一个网络为每个框生成输出，也就是边界框，它会为物体生成许多不同的候选。

正如我所说过的，每个框都对应一个概率。在这个例子里，概率是用每个框中边的粗细来表示的。有了这些边界框和物体概率，我们就可以做阈值处理，然后做后续的筛选。谢谢。论文里用了非极大值抑制（NMS）算法，细节我就不展开了，主要是一些结合阈值处理的算法，用来筛选出那些概率最高。这就是一个简单的实现用法。谢谢。目标检测，这确实非常有用。有时间的话去研究一下 YOLO 的代码库，它有很多不同的新版本，它被广泛应用于医学、机器人领域，以及许多工业应用中。

问题来了，我们怎么得到这第二张图背后的直觉又是什么？正如我所说，每个网格我们都会生成 B 个边界框。比如这个我们生成了两个，其他所有网格也都生成两个，这也是一个概率向量，每个框都关联着其中存在目标的概率。把这些图像块的结果全加起来，就会得到很多框。现在每个框都关联着一个概率，对吧？好。

咱们接着往下讲。目标检测领域有个比较新的方法叫 DETR，检测 Transformer，它完全基于 Transformer。这用到了咱们上周聊过、今天刚提的自注意力和交叉注意力模块。这些模块能帮我们生成检测目标和边界框。这其实不算老，论文是 2020 年的，这大概是 5 年前的事了。虽然现在已经过时，没人拿来做实际项目，但它很好地演示了怎么用 Transformers 做目标检测。咱们这儿做的基本就跟之前讲的一样：先把图像切成图像块，再送进卷积神经网络生成 tokens；接着按我刚才说的给图像块加上位置嵌入。这些就是我们要输入的 tokens，也就是喂给 Transformer Encoder 的数据。Transformer Encoder 里又是一堆自注意力、层归一化还有 MLP 层，过好几层之后才生成输出 tokens。接下来要生成边界框，这正是这个算法巧妙的地方，它把 Encoder

输出的 tokens 作为 Transformer Decoder 的输入。在 Decoder 里，我们还定义了一些查询（queries）。这些查询本身也是可训练的参数。比如说如果我输入 5 个、4 个或者 10 个、20 个查询，我想获得的就是相应的结果。在这张图里最多检测出 20 个目标。然后再通过自注意力机制在 Transformer Decoder 开头的这些层，以及与 Encoder 的交叉注意力输出结果。所以就是交叉注意力和自注意力这些网络层，它为每个查询生成输出值，这些值经过前馈网络（FFN）处理生成类别标签和边界框。这跟我们前面讲的很像，或者有时候它会直接说这里没有目标。检测完成后，输出结果包含边界框及其对应的类别。

问题来了：所有可能的框都要输入 Transformer 吗？不会。这里输入的是可训练参数用来表示查询，相当于你在问：我希望在这个位置检测到一个对象。输入的是查询，对吧？所以输入里并没有框。这部分属于输出，负责生成类别标签和框坐标。所以关键问题是这些查询是否准确代表了我们想找的东西，及其在图中的位置。在这种情况下，我们要找的目标由预定义的类别标签决定。这些标签本身就是输出的一部分，所以监督信号来自类别标签。我们有一个类别概率向量，跟之前讲的其他算法一样，对吧？这样算法就知道该去识别哪些类别了。再看看输出部分，这些输出也是受监督的。你还记得吧，咱们用的是真实框的 L2 损失，也就是 L2 范数，对吧？所以在查询阶段我们没给任何提示，没告诉它该找什么、去哪找，不管针对哪个对象。整个训练过程其实都在做反向传播，只要算出损失或误差，系统就会把结果反向传播回去。总之处在初始阶段或这一环节，我们并没有预先设定任何内容。

问题是这样：查询就是要给我最多 9 个对象？没错，基本就是这个意思。借助自注意力和交叉注意力，模型会生成输出 tokens，再经 FFN 转为类别和框坐标。接着说操作。你的问题是那些查询是不是图像块？不是图像块，它们是可训练参数的查询，输入它们是为了生成输出。每个输入都会产生一个值作为输出，这个值会转为类别和框坐标。再说一次，关键是搞清楚这个对象查询到底是什么。它们是可学习的参数，你初始化它们，让网络去找到最优解。这些就是它们的取值，也就是输出。问题是有没有规律决定哪个 FFN 对应哪个框？答案是否定的，没有任何机制阻止网络，我是说我们并没有刻意去限制它阻止网络生成多个输出。但别忘了那里有很多自注意力和交叉注意力层，它们之间其实是在互相作用的。这样每个查询都会匹配到一个输出层，所以它生成的和输出并不完全一样。我们也能控制如何去监督这些前馈网络 FFN。

所以你的问题是训练里有没有用到图像分割或像素级分割？这个算法不需要片段级或像素级的分割，它只依赖类别标签和边界框来做监督。不过有了像素级分割，你总能把它转成边界框为了训练这个算法嘛，对吧？但这其实不是必须的。所以问题是能不能泛化到没见过的物体？没见过是指新类别吗？这类全监督算法通常不行。因为你在生成类别概率向量，没法向内最后给新类别加点东西，而事先并不知道还有其他类别，对吧？所以全监督网络通常搞不定新物体，我们可以有背景或无物体。你看这里有无物体的标签，这类算法有很多扩展，常用语零样本学习。零样本学习就是没有训练样本也能理解新事物。这个先不展开。如果场景里的物体比你查询的还多会怎样？也就是你拿什么当查询输入，对吧？问得好，它通常会挑出置信度最高的物体，也就是置信度最高的边界框。这时候你通常得增加几个查询才能检测出更多物体，对吧？课后有任何问题我都在这儿答疑，不过咱们还有好多话题要讲，我得确保都过一遍，至少你们能熟悉这些主题。

好，接着目标检测。咱们回到之前的问题：怎么用这类算法做实例分割？其实没那么难。咱们之前聊过讲 CNN 算法时，现在图像上跑 CNN，再用区域提议网络输出边界框。接着把这些框转化为类别标签和更精准的框，对吧？这就是咱们聊到的有了 R-CNN 等基础。现在可以升级为 Mask R-CNN，它还能生成掩码。基本上还是咱们之前说的那个架构。现在咱们可以再多拿一个输出，让它支持多任务，顺便生成掩码。预测以前我们做的是图像区域提议，区域提议 CNN 输出类别标签和边界框坐标，现在加一层卷积在像素级生成这个物体的掩码。掩码大小可以和输入图像一样大。用全卷积网络时，这一层输出的通常就是这个。拿到那个小框，就能得到对应物体的掩码。比如椅子，框的位置不同，还有床、图里的人、婴儿。这是 R-CNN 的扩展，我们把它叫做 Mask R-CNN。用 Mask R-CNN 的话检测各种物体的效果其实相当不错。这些都是我们可以训练算法去识别的已知物体，而且市面上有很多目标检测器的 API 和开源版本供你探索。这里有一些链接和资源。这些就是简单来说，它汇总并总结了我们想讲解的一些任务。

我想强调几种评估、理解和可视化的方法，神经网络其实挺重要的。其中一个是咱们讲讲显著性（saliency）。很多场景下你得知道哪些像素是关键。比如医疗应用里你要判断有没有肿瘤，得看图像的哪些部分实际上是肿瘤。因为要自动化的话，没人在意知不知道有没有肿瘤，大家更关心肿瘤在图像里的位置，对吧？所以最简单的做法是训练一个前馈网络，神经网络生成这个值或者类别标签（狗）。不过我们可以这样做，在我演示之前，这种情况下为了训练这个网络，我们一直在对它求导。神经网络抱歉是权重，对损失求导，或者算出类别得分对权重的梯度，好去更新权重，对吧？现在我要看每个像素，看看改变像素值会怎样，改变像素值会对狗的得分产生多大影响，对吧？啥意思？我刚才解释的是导数的含义，对吧？所以这基本上就是梯度的含义。所以如果我算得分对像素值的梯度，不再是权重，就能把这些梯度可视化。把这些可视化就说明这些像素是关键，要在这张图上把它分类成狗，这些像素就是关键。所以只要改了像素值，目标得分就会变，对吧？这就是咱们之前聊过的梯度的基本定义。这是一种办法，把它用在网络训练过的不同物体上。结果就是这样，所以这是理解显著性的一种方式，很多情况下都很管用。

但有时候关键不在于最底层的像素值，你想看看每个类别的激活机制是怎么运作的。这就引出了类激活映射（CAM）算法，或者两分钟后讲的 Grad-CAM。它们是理解 CNNs 最常用的一类算法，它也能用于其他架构。不过针对 Transformers，我们有了更好的理解方式，这点上节课讲过。所以每个卷积层通常都会做池化，从而生成特征图。接着特征图被转化为分数，在于权重值挂钩。从数学上看，我们其实可以把类别分数写成加权求和的形式。这意味着你能追溯类别预测的来源，一路追溯到特征图，还有空间中的具体位置。因为卷积层在图像空间里也有对应映射，对吧？通过卷积所有操作间的空间一致性能帮我们一路追溯回图像空间。总之，咱们看看特征图就能明白每个类别的激活值是怎么影响图像里那些具体位置的。有了这个基础，把权重和之前在特征值上学到的权重相乘，就能得到一些类别激活值。这意味着我现在能把结果映射回图像空间。只要还在卷积空间里，我就能一路回溯到图像，为每个类别生成这样的映射图：宫殿式、教堂、祭坛和修道院。我们可以针对不同的类别生成各自的激活映射图。这些就是权重，也就是卷积层里那些像素或区域，正是它们推高了这些特定类别的得分。其他情况也一样，比如针对单个物体的类别激活映射图。但这里有个问题：我们只能对最后一个卷积层这么做，因为这是唯一可行的方式。就像咱们刚才算的那样，只能用到最后一个卷积层。

为了解决这个问题，有个叫 Grad-CAM 的算法变体，也就是梯度加权类激活映射。算法基本一样，只是我们需要据此计算相应的权重。咱们选一个在类别层面产生了激活的层，去算它的梯度，而不是光做计算。咱们不直接算 W 和特征的乘积，而是回溯梯度，用梯度来定权重，然后用它来代替权重。它是该层之前所有权重和梯度的总和，然后咱们据此加权，再用 ReLU 只让正值通过，咱们从正力开始。这也能在整个图像空间里完整展示。

之前聊过 CAM，它只用在最后一个卷积层。你想这么做也行，但通常不可行，因为大多数 CNN 末尾不止一个卷积层，对吧？中间总有些全连接之类的操作。所以要把类别激活传回卷积层，如果中间还有别的操作，我们常会用到梯度和权重。简单来说，用聚合的梯度给特征图加权，就能做可视化了。他们为每个对象生成热力图，这是讲 CNN 的。

不过我们上周聊过 Transformers 对吧？上次课讲过，它们本身就自带激活图。还记得 Justin 展示的那个语言矩阵吗？每个输出词都对应一组针对输入的注意力权重。像素也一样，我们能在像素空间生成这些图，直观展示 y_t 的特征。有了 ViT 和 Transformers 这就简单多了，直接就能看出注意力权重。但 CNN 通常得靠 Grad-CAM 这类算法。话说回来，我确实完成了一项原本以为搞不定的任务。今天和下节课的主题是视频理解。谢谢。
