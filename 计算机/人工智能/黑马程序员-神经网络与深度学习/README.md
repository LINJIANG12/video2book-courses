## 怎么学

- **先跑通一条训练闭环，再回头补理论**：张量 → 自动微分 → 线性回归 → 神经网络，这条线走完，后面的损失函数与优化器才有落点。
- **张量部分别只看，敲一遍**：创建方式、类型转换、五类索引、reshape/view/transpose/permute、cat/stack，都是后面读代码的前提。
- **自动微分按「一次更新 → 循环迭代 → detach → 线性回归」四步推**，重点理解梯度归属与「只能对标量求导」这条约束。
- **把优化器看成同一个公式的四种改法**：原式 → 动量法 → AdaGrad/RMSProp → Adam，对照指数移动加权平均看每一步在修什么毛病。
- **三个案例都要完整跑**：手机价格分类练 ANN 全流程，CIFAR10 练卷积/池化与张量形状推演，歌词生成练词嵌入、滑动窗口与逐词生成。
- **参数量与形状自己先算**：每搭一个网络先手算各层输出形状与总参数，再用代码核对，比背 API 有用。
