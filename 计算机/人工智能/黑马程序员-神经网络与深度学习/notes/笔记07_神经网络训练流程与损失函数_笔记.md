# 神经网络训练流程与损失函数

## 深度学习案例的四步骨架

### 四步与六步的对应

   * **深度学习案例流程（deep learning pipeline）**

       * > **定义**：准备数据 → 搭建神经网络 → 模型训练 → 模型测试，共四步。

       * 机器学习案例是六步：准备数据 → 数据预处理 → 特征工程 → 模型训练 → 模型测试 → 评估。

       * 深度学习把数据预处理与特征工程交给网络自己完成，所以比机器学习少两步，只留四步。

   * **搭建与训练的分界**

       * 搭建神经网络是第二步，模型训练是第三步；反向传播属于第三步，不属于搭建。

       * 搭建阶段只写正向传播；反向传播要等损失函数与优化方法接上之后，才在训练循环里出现。

### 搭建神经网络三步

   * 定义一个类，继承 `nn.Module`。

   * 在 `__init__` 中先写 `super().__init__()` 初始化父类成员，再搭隐藏层与输出层；参数初始化也放在这里。

   * 在 `forward` 中定义前向传播：把 `__init__` 里定好的层依次取出来，往里面传数据，一节一节走完。

   * > **提示**：创建对象时先走 `__init__`（父类初始化、搭层、初始化参数），数据喂进去再走 `forward` 做预测，两个方法都由 PyTorch 调用。

## 类与方法的重写

### nn.Module 与两个方法

   * `nn` 是 Neural Network 的缩写；搭自己的网络类，第一件事是继承 `nn.Module`。

   * 只需重写两个方法：`__init__` 负责搭层与初始化参数，`forward` 负责前向传播。

   * > **定义**：`forward` 做的事，就是把 `__init__` 中定好的层依次取出来，把数据一节一节往前传，从输入层经隐藏层直到输出层。

   * 反向传播是从输出层逐层往回更新参数，方向与前向相反，不属于搭建环节。

### forward 的调用方式

   * `forward` 没有双下划线，不是魔法方法，但用法与魔法方法一致：模型实例化后由底层自动调用，代码里不写 `my_model.forward(data)`。

   * 名字必须是 `forward`，因为底层按名字查找；改了名字就找不到这个方法。

   * > **易错点**：`forward` 这个名字一个字都不能改；`TODO` 注释前的井号也不能省，省了直接报错，它本质上是注释里的关键词。

### 参数初始化的取舍

   * 这一版把初始化写出来，是为了知道这个位置本来该做什么、规定的初始化方式长什么样。

   * 实际开发只搭层、不写初始化：底层默认会初始化，CNN、RNN 的层同样如此。

## 结构图的读法

### 输入层与偏置

   * **输入层**

       * 输入层不用搭：喂进来几个特征，它自动就是几维，代码里不会出现“输入层”这一行。

   * **偏置（bias）**

       * 图上每层后面的 `+1` 是偏置，不是多出来的一个神经元；一个神经元的输出，是上一层输入各自乘权重求和，再加上自己的偏置。

       * 算 `nn.Linear` 第一个参数时不能把 `+1` 算进去：偏置由本层加权时自己加上，不是上一层传下来的输入。

       * > **易错点**：本层也有自己的 `+1`，但它只服务本层；下一层数输入维度时，数的仍是本层神经元个数，不是“神经元个数 + 1”。

### 三层维度对照

| 层 | 输入维度 | 输出维度 | 代码写法 |
| :--- | :--- | :--- | :--- |
| 隐藏层 1 | 3 | 3 | `nn.Linear(3, 3)` |
| 隐藏层 2 | 3 | 2 | `nn.Linear(3, 2)` |
| 输出层 | 2 | 2 | `nn.Linear(2, 2)` |

   * 输入 3 个特征、两个隐藏层分别 3 与 2 个神经元、输出层 2 个神经元，整个架构记作 3-3-2-2。

   * 隐藏层 2 的每个神经元接上层 3 个神经元，所以 3 进 2 出；输出层每个神经元只接上层 2 个神经元，所以 2 进 2 出。

   * 全连接层的变量名实战只有两个词：FC（fully connected）或 linear；输出层习惯命名 `out` 或 `output`，读代码的人一眼能认出是最后一层。

### 初始化与激活的搭配

   * **隐藏层 1：Xavier 正态 + Sigmoid**

       * 规定用标准化的 Xavier，即 `xavier_normal_`；“标准化”指正态分布，不是均匀分布，名字里写着 normal。

       * 激活规定用 Sigmoid；Sigmoid 不是输出层专利，用在隐藏层只是效果好与不好的问题，选它取决于想让这一层输出什么形态，不取决于这层是不是最后一层。

   * **隐藏层 2：Kaiming 正态 + ReLU**

       * 规定 `kaiming_normal_` 配 ReLU。

       * 若按真实开发自选，隐藏层优先 ReLU 配 Kaiming，不必犹豫。

   * **输出层：Softmax**

       * 多分类输出层一定是 Softmax，把各类别分数映射成概率。

       * 输出层的权重初始化未作规定。

   * 每层各配一个激活函数，三层共三个；输入层与特征数相关，不做激活，不用设置。

## 参数量计算与验证

### 全连接层参数量公式

$$\text{本层参数量} = \text{本层神经元数量} \times (\text{上层神经元数量} + 1)$$

   * 公式里的 `+1` 是偏置，每个神经元都配一个，不能漏。

   * 单个神经元的参数 = 上层神经元个数个权重 $w$ + 1 个偏置 $b$；隐藏层 1 的一个神经元是 3 个 $w$ 加 1 个 $b$，共 4 个。

| 层 | 神经元个数 | 每个神经元的参数 | 本层合计 |
| :--- | :--- | :--- | :--- |
| 隐藏层 1 | 3 | 3 个 $w$ + 1 个 $b$ = 4 | 12 |
| 隐藏层 2 | 2 | 3 个 $w$ + 1 个 $b$ = 4 | 8 |
| 输出层 | 2 | 2 个 $w$ + 1 个 $b$ = 3 | 6 |

   * 逐层代入公式：$3\times(3+1)=12$、$2\times(3+1)=8$、$2\times(2+1)=6$，合计 26，整个模型的参数总量就是 26 个。

   * > **注意**：公式只对全连接层成立，因为只有全连接层“本层每个神经元与上层所有神经元都相连”才成立乘法；CNN 的卷积核是共享的，RNN 的结构也不同，参数量算法都不一样。

   * > **易错点**：输入特征不是参数。5×3 里的 3 是样本特征数，是喂进来的数据；$W$、$B$ 才是要训练的参数，数参数量时不能把输入特征数算进去。

### torchsummary 校验

   * 调用 `summary(my_model, input_size=(5, 3))`：第一个参数是模型对象，第二个是输入数据的完整维度，不是单个样本的三个特征。

   * 输出表只看三列：层名、输出形状、参数量；表尾 `Total params` 为 26，`Trainable params` 也是 26。

   * 两者以后可能不同：例如总共 200 个参数、实际只训练 150 个（冻住一部分不动）。入门阶段有多少训多少。

   * 安装方式有四种：Anaconda Prompt 执行 `pip install torchsummary`；PyCharm 的 Terminal 先 `cd ../` 再 `cd day04` 后安装；File → Settings → Project → Python Interpreter 点加号搜索安装；对报红的 `import torchsummary` 按 `Alt + Enter` 选 “Install package”。

   * > **提示**：`Alt + Enter` 安装的唯一前提是包名拼对；名字错了，PyCharm 给不出安装项。

### named_parameters 对号入座

   * 用 `for name, param in my_model.named_parameters(): print(name, param, end="\n\n")` 把每层名字与参数成对打印，`end="\n\n"` 让每组之间空一行。

   * 权重矩阵形状是“本层神经元数 × 上层神经元数”：`linear1.weight` 为 3×3、`linear2.weight` 为 2×3、`linear3.weight` 为 2×2，偏置分别为 3、2、2 个。

   * `bias` 的初值全为 0，来自初始化时的 `nn.init.zeros_`。

   * 挨个数一遍：3×3 得 9 加 3 个偏置是 12；2×3 得 6 加 2 个偏置是 8；2×2 得 4 加 2 个偏置是 6；合计 26，与 `summary` 报的数一致。

### 参数量汇报顺序

   * 先报结构再算数：输入 3 个特征、两个隐藏层 3 与 2 个神经元、输出层 2 个神经元，架构 3-3-2-2；然后逐层算 12、8、6，合计 26。

   * 上来就说“上一层 3 个、3 加 1 是 4、这层 12 个”，听的人不知道在说哪张网，先给结构数字才落得下去。

## 前向传播的代码骨架

### 完整类定义

```python
import torch
import torch.nn as nn


class ModelDemo(nn.Module):
    def __init__(self):
        super().__init__()

        self.linear1 = nn.Linear(3, 3)
        self.linear2 = nn.Linear(3, 2)
        self.out = nn.Linear(2, 2)

        nn.init.xavier_normal_(self.linear1.weight)
        nn.init.zeros_(self.linear1.bias)
        nn.init.kaiming_normal_(self.linear2.weight)
        nn.init.zeros_(self.linear2.bias)

    def forward(self, x):
        x = torch.sigmoid(self.linear1(x))
        x = torch.relu(self.linear2(x))
        x = torch.softmax(self.out(x), dim=-1)
        return x
```

   * `__init__` 第一行固定写 `super().__init__()`，先把继承来的父类成员初始化完，再搭自己的层，这一行没有商量余地。

   * `nn.init` 是 PyTorch 的初始化模块；`xavier_normal_` 对权重做正态初始化，`zeros_` 把偏置置零，Kaiming 用 `kaiming_normal_`。

   * 输出层写成 `self.out`，参数量统计里仍显示为第三层 `Linear(2, 2)`。

### 分解版与合并版

   * 分解版：先 `x = self.linear1(x)` 做加权求和，再 `x = torch.sigmoid(x)` 做激活，两行对应图上“加权求和 + 激活”两个动作。

   * 合并版：把第一行的结果直接塞进激活函数的括号，写成 `x = torch.sigmoid(self.linear1(x))`，一行顶两行；实际开发清一色用合并版。

   * 中间结果全部复用同名变量 `x`：进去是 `x`，覆盖之后仍叫 `x`，下一步只认最新的值，不另起 $x_1$、$x_2$。

   * 三层激活依次是 `torch.sigmoid`、`torch.relu`、`torch.softmax`，最后 `return x`。

### dim 参数的含义

   * `dim=-1` 表示最后一个维度；对二维数据，`dim=1` 与 `dim=-1` 等价，写哪个都行。

   * 实际含义是按行计算，一条样本一条样本地算：Softmax 只把同一条样本在各个类别上的分数归一化，跨行归一没有意义。

   * 传进 5 行 3 列、每行一条样本，输出为 5 行 2 列；行数是样本数全程不变，列数被每层的输入特征数卡住，从 3 到 3、到 2、再到 2。

   * > **提示**：`forward` 返回的 $x$ 对应前向传播图里的 $z$；这一步只把输入推到 $z$，损失、梯度、参数更新都不在搭建范围内。

## 模型训练的最小闭环

### train 函数的位置

   * `def train()` 与 `class` 平级、顶格写，不缩进到类里；它是**用**模型的，不是模型的**一部分**。

   * 入门版训练函数只做三件事：创建模型对象、创建数据集样本、调用模型拿到输出；`main` 里只留一句 `train()`。

   * > **易错点**：把 `train` 写成类方法（`my_model.train()`）是语义错误——搭层才是模型自己的血肉，训练是从外面发起的动作。

### 建对象与喂数据

```python
my_model = ModelDemo()
print(my_model)

data = torch.randn(size=(5, 3))
output = my_model(data)
```

   * 打印模型对象会列出每一层：`Linear(in_features=3, out_features=3, bias=True)` 这样的结构，层名与数字都是自己写的，不是框架生成的。

   * `torch.randn` 生成标准正态分布的随机数，`size=(5, 3)` 是五行三列，即五条样本、每条三个特征；没设随机种子，每次数值都不同。

   * `data.shape` 为 `torch.Size([5, 3])`；`data.requires_grad` 为 `False`，刚生成的张量默认不挂梯度。

   * 模型对象后面挂括号传数据就是调用模型，底层自动转去执行 `forward`；返回值形状是 5 行 2 列。

   * 输出每行两个数相加为 1，因为最后一层接 Softmax；屏幕上只显示两位小数，截断后看着像 0.99，真实值相加为整 1。

### 输出为何自带梯度

   * `data.requires_grad` 是 `False`，`output.requires_grad` 却是 `True`：数据进了 `forward`，一路乘需要更新的 $W$、加 $B$，PyTorch 记下这条计算链并把结果标成需要梯度。

   * `requires_grad` 只表示张量参不参与求导，与数值对错无关；这个 `True` 是给反向传播留的接口。

   * 这一轮只跑了前向，26 个参数一个都没动，所以只是测试，不是训练。

### 训练循环

   * 一轮完整动作：前向传播用 26 个参数把输入算成预测值 → 算损失看与标签差多少 → 反向传播把 26 个参数全都改一遍。

   * 再前向、再算损失、再反向，循环往复；每转一轮参数就往真实规律靠近一点，损失降不下去即模型训出来了。

   * “训练 N 轮”就是把这一整套动作重复 N 遍，每轮特征不变，变的只有权重。

### 批次维与特征维

   * `summary` 表里输出形状写作 `[-1, 3]`、`[-1, 2]`，`-1` 占的是批次维：传 5 行就是 5，传 500 行就是 500，由框架自动推断。

   * 行是样本数，随便改；列是特征数，网络一旦定死就不能改——`Linear(3, 3)` 要求输入特征数必须是 3，喂六行五列直接报错。

   * 想收五列，就要把层定义里的第一个 3 改成 5，网络结构与权重数量跟着变。

## 损失函数的定位与家谱

### 定义与别名

   * **损失函数（loss function）**

       * > **定义**：衡量模型拟合情况好坏的函数，方式是比较网络输出（预测值）与真实值（标签）之间的差异。

       * 本质是一个打分器：分数越低，拟合越好；它把差异换算成一个可比较、可优化的数。

       * 预测值是特征经加权求和 $Wx+b$ 再过激活函数得到的结果；标签（target value）就是目标值。

   * **四个别名**

       * `loss` 叫损失函数，`cost` 叫代价函数，`objective` 叫目标函数，`error` 叫误差函数，口语中还叫成本函数。

       * 这些名字说的是同一件东西，不是四个不同概念；命名分散源于各机构各自研发、没有统一命名。

### 分类与回归的分支

   * 分类：多分类交叉熵 `CrossEntropyLoss`（公式内含 softmax，是多分类主力）、二分类交叉熵 `BCELoss`（只分两类，配 sigmoid 使用）。

   * 回归：MAE（平均绝对误差）、MSE（均方误差，mean squared error，不是“平均平方”）、Smooth L1（揉合前两者特点的改进版）。

   * > **提示**：Smooth L1 是把 MAE 与 MSE 的特点揉在一起的升级版，真要用时比两者更好一点；RMS 那一族不在入门范围内。

## 多分类交叉熵

### 公式与符号链

   * **多分类交叉熵（Cross Entropy Loss）**

       * > **定义**：多分类交叉熵等于 softmax 加上一次损失计算，公式内部默认包含 softmax 这个动作。

       * 直接后果：模型后面接多分类交叉熵时，`forward` 最后一步的 softmax 可以不写，代码直接写到全连接层输出。

       * 公式为 $Loss = -\sum_i y_i \log\big(S(F(x_i))\big)$。

       * 符号：$x_i$ 是第 $i$ 个样本（$i$ 从 1 到 $n$，共 $n$ 个）；$F(x)=WX+B$ 是加权求和，即样本属于各类别的预测分数；$S(\cdot)$ 是激活函数，把分数映射成概率；$\log$ 是求对数；$y_i$ 是样本属于某类别的真实概率，只取 0 或 1；$\sum$ 与负号是先把所有类别累加、再整体取负，保证损失为正。

       * 执行顺序：加权求和 → 激活映射成概率 → 取对数 → 乘真实概率 → 所有类别累加 → 取负；一个样本走一遍，$n$ 个样本得到 $n$ 个结果，代码里默认再取平均。

       * `reduction` 默认值是 `'mean'`，所以算出的是平均损失，不是所有样本损失的简单堆叠。

### 数值示例

   * 某样本加权求和输出 0.12 这样的分数，过 softmax 得到 0.1、0.7、0.2 三个概率，相加为 1；分数是中间产物，概率才是最终答案。

   * 标签为 `010`（真实类别是第二个），代入公式得 $Loss=-(0\times\log 0.1 + 1\times\log 0.7 + 0\times\log 0.2)=-\log 0.7$。

   * 乘 0 的类别被彻底忽略，真正参与计算的只有真实类别那一项；损失不关心错误类别分到多少概率，只盯正确类别的概率给了多大。

   * > **提示**：$-\log p$ 在 $p$ 越接近 1 时越小，所以最小化 $-\log p$ 等同于把正确类别的预测概率往 1 推，只是前者能算出一个可求导、可优化的数值。

   * 一句话表述：最小化正确类别所对应的预测概率的对数的负值。

### 代码四步

```python
import torch
import torch.nn as nn

y_true = torch.tensor([[0, 1, 0], [1, 0, 0]], dtype=torch.float)  # 也可写索引 [1, 0]
y_pred = torch.tensor([[0.1, 0.8, 0.1], [0.7, 0.2, 0.1]],
                      dtype=torch.float, requires_grad=True)

criterion = nn.CrossEntropyLoss()
loss = criterion(y_pred, y_true)
print(loss)  # 1.0283
```

   * 四步固定：设置真实值、设置预测值、创建损失函数、计算损失。

   * 真实值 `[0,1,0]` 的 1 落在第二位，按从 0 开始的索引是 1 号类；`[1,0,0]` 是 0 号类；也支持直接写类别索引 `[1, 0]`，两种写法等价。

   * `dtype` 必须指定成 `torch.float`，整型张量进不了这套运算；预测值必须开 `requires_grad=True`，否则梯度传不回去。

   * 输出 `1.0283` 不等于把 0.8、0.7 直接代入 $-\log$ 再取平均：传进去的数被当成 softmax 之前的分数，先重新映射成概率，再取对数、再对两个样本平均。

   * > **提示**：手动模拟时预测值不必凑成和为 1，写 0.7、0.2、0.3 也照样能跑，底层自己处理；真实训练时这些数来自网络输出，不会出现这种情况。

## 二分类交叉熵

### 公式与两个分支

   * **二分类交叉熵（Binary Cross Entropy，BCE）**

       * > **定义**：$L=-\big[y\log\hat{y}+(1-y)\log(1-\hat{y})\big]$，$y$ 是样本属于某类别的真实概率（只取 0 或 1），$\hat{y}$ 是该类别的预测概率。

       * $y=0$：左边 $0\times\log\hat{y}$ 归零，只剩 $-\log(1-\hat{y})$，只看“它不是这一类”算得准不准。

       * $y=1$：右边 $(1-1)\log(1-\hat{y})$ 归零，只剩 $-\log\hat{y}$。

       * 两条看似分开的曲线本质是同一公式的两个分支，走哪支由真实标签是 1 还是 0 决定；形式上与逻辑回归推导出的式子一致。

   * **与多分类的关键差别**

       * 多分类公式含 softmax，所以激活可以省；二分类公式里没有 sigmoid，做二分类时 sigmoid 必须手写。

       * PyTorch 中对应 `nn.BCELoss()`；实际工程里二分类场景相对少，记住“公式不含 sigmoid、用时自己补”即可。

### 代码与形状

```python
y_true = torch.tensor([0, 1, 0], dtype=torch.float)
y_pred = torch.tensor([0.69, 0.54, 0.26],
                      dtype=torch.float, requires_grad=True)

criterion = nn.BCELoss()
loss = criterion(y_pred, y_true)
```

   * 真实值是一维 `[0, 1, 0]`，代表三个样本分别是 0 类、1 类、0 类；预测值也是三个数，每个数是一个样本属于正类的概率，即 sigmoid 的输出。

   * 形状差异来自任务本身：多分类是一个样本一整组分数，用嵌套中括号包成二维；二分类是一个样本一个概率，三个数就是三组独立判断。

   * 结果 `0.6962` 可手算核对：三项分别是 $-\log(1-0.69)=1.171$、$-\log 0.54=0.616$、$-\log(1-0.26)=0.301$，相加 2.088 再除以 3，得 0.6962，说明 `reduction='mean'` 确实在起作用。

   * > **注意**：`loss` 带计算图时不能直接 `loss.numpy()`，要先断开梯度写 `loss.detach().numpy()`；只打印值不打印类型时屏幕上仍是 `tensor`，容易误判。

### 多分类与二分类的分工

| 对比项 | 多分类 | 二分类 |
| :--- | :--- | :--- |
| 输出层激活函数 | softmax | sigmoid |
| 损失函数 | `nn.CrossEntropyLoss()` | `nn.BCELoss()` |
| 公式里是否含激活 | 含 softmax | 不含 sigmoid |
| 代码里还要不要手写激活 | 可以不写 | 必须写 |
| 预测值形状 | 每个样本一组分数 | 每个样本一个概率 |
| 底层默认归约 | `reduction='mean'` | `reduction='mean'` |

   * 一句话：一个省掉 softmax，一个补上 sigmoid；写模型时最后一步要不要加激活，按接的是哪种损失决定。

   * 损失函数永远只做一件事：拿一个真实值、一个预测值，还一个越小越好的数。

## 回归损失

### MAE

   * **平均绝对误差（Mean Absolute Error，MAE）**

       * > **定义**：$MAE=\frac{1}{n}\sum_{i=1}^{n}|y_i-\hat{y}_i|$，真实值减预测值取绝对值，全部相加再除以样本数。

       * 真实减预测还是预测减真实都无所谓，外面套了绝对值。

       * PyTorch 中叫 `nn.L1Loss()`，别名 L1 loss。

       * 性质：走 L1 正则化那套思路，能把权重压到 0；50 列特征中 30 列权重被压成 0，参与计算的特征就只剩 20 列，数据变稀疏。因此常作为正则项嵌进别的 loss，不单独上场。

       * 缺陷在零点：L1 图像是直线，零点不可导，梯度下降在那儿算不下去；若零点恰是最小值，可能直接跳过去。

   * **数值演示**

       * 真实值 `[2.0, 2.0, 2.0]`、预测值 `[1.0, 1.0, 1.9]`：差值为 1、1、0.1，相加 2.1，除以 3 得 0.7。

       * 实际打印约 `0.6999999`，因为小数用近似表示；末位差异与环境或版本有关，但若跑出 3 则一定是代码写错。

       * > **提示**：多分类手动给预测值时和不必为 1，因为数据是自己编的；“和为 1”的约束只有经过 softmax 才成立。

### MSE

   * **均方误差（Mean Squared Error，MSE）**

       * > **定义**：$MSE=\frac{1}{n}\sum_{i=1}^{n}(y_i-\hat{y}_i)^2$，与 MAE 只差一个平方。

       * 也叫 L2 loss、欧式距离；PyTorch 里是 `nn.MSELoss()`。

       * > **易错点**：PyTorch 没有 `nn.L2Loss()`；`L2 loss` 只是习惯叫法，写 MSE 只能写 `nn.MSELoss()`。

       * 平方会放大异常值：100 与 1 的差用绝对值是 99，用平方接近 1 万；值一下变得更离散，模型更容易被异常值影响。

       * 缺陷：预测值与目标值相差很大时梯度容易爆炸。梯度若是 1 万，学习率 0.01 乘出来也是 100，一步把 $W$ 减掉 100。

       * 同组数据 `[2.0,2.0,2.0]` 与 `[1.0,1.0,1.9]`：$1+1+0.01=2.01$，除以 3 约 0.67。

       * 也常作为正则项充当惩罚系数，用来抑制其他公式的过拟合。

### Smooth L1

   * **平滑 L1（Smooth L1）**

       * > **定义**：分段函数 $L=0.5x^2$（$|x|<1$）、$L=|x|-0.5$（其他），$x$ 是预测值与目标值的差。

       * 形状：中间一段抛物线，两侧是斜率固定的直线，三者在 $x=\pm1$ 处函数值与导数都连续。

       * 减 0.5 是为了接上：$0.5\times1^2=0.5$，$|1|-0.5=0.5$，不会跳空。

       * 本质：中间有平方是 L2，外侧没有平方是 L1，所以是 L1 与 L2 的综合，也可说是在 L1 基础上加了平滑系数。

       * 两件事同时解决：中间 L2 解决 L1 零点不平滑、不可导、可能错过最小值；外侧 L1 解决 L2 遇离群点梯度爆炸，差多大梯度就多大，不翻倍上涨。

       * PyTorch 中叫 `nn.SmoothL1Loss()`。

   * **数值演示**

       * 两个差值 1 卡在分段点，按外侧算 $1-0.5=0.5$；差值 0.1 落在中间，算 $0.5\times0.01=0.005$；三项合计 1.005，除以 3 得 0.335。

### 三种损失的同组数据对照

| 损失函数 | 同一组数据下的结果 |
| :--- | :--- |
| MAE（L1） | 0.7 |
| MSE（L2） | 0.67 |
| Smooth L1 | 0.335 |

   * > **提示**：三个数摆在一起只是看同一组预测值在不同定义下差多少，它们不是同一把尺子，不能拿去做“谁更准”的排名。

   * 选型：回归优先 Smooth L1，多分类优先交叉熵，二分类用 BCE；真正动手写得最多的是交叉熵与 BCE，而不是 Smooth L1。

## 梯度下降与权重更新

### 权重更新公式

$$W_{new} = W_{old} - \eta \frac{\partial L}{\partial W}$$

   * $\eta$ 读 eta，是学习率；$\partial$ 读 partial 或 round，是偏导；$\Delta$ 才是德尔塔；$\prod$ 是连乘。

   * 梯度的方向是函数增长最快的方向，反方向就是下降最快的方向，所以是减去学习率乘梯度，而不是加。

   * 梯度下降属于网络优化，目的是寻找损失函数的最小值；另一条思路是正规方程法，但它要求矩阵必须有逆，没有逆就算不下去。

### 学习率的两难

   * 学习率太小，下降太慢，训练时间成本直接上升；太大，下降太快，容易震荡、跳过最优解，甚至进入无限循环。

   * 学习率一开始就写死并不好：希望前期大一点降得快，后期降下来慢慢贴近最小值，于是有等间隔调整、指定间隔调整、指数间隔调整三种策略。

   * 传统梯度下降三个绕不过去的问题：平缓区域梯度接近 0、一步挪不了多少；鞍点（一个方向像谷底、另一个方向像坡顶）；局部最小值（掉进小坑出不来，后面还有更深的坑）。

   * 光靠权重更新公式解决不了这三个问题，后续方法是动量法、AdaGrad、RMSProp、Adam 四种优化器，加三种学习率策略，共七种。

## epoch、batch size 与 iteration

### 三个概念

   * **epoch（训练轮数）**：训练集完整过一遍算一轮。

   * **batch size（批次大小）**：每个批次的样本数量，也就是每次反向传播更新权重用多少条数据。

   * **iteration（迭代次数）**：用一个 batch 做一次参数更新算一次，一批一迭代；有多少批就有多少 iteration。

   * 一个 epoch 内部：batch 1 反向传播更新一次 → batch 2 更新一次 → …，几批就是几次参数更新。

   * 手算一：训练 100 轮、共 100 条数据、每批 16 条；`100 ÷ 16` 得 6 批余 4 条，最后 4 条单独成一批，每轮 7 批，100 轮共 700 个 iteration。

   * 手算二：5 万样本、每批 256 条；`50000 ÷ 256 ≈ 195.3`，四舍五入 196，一个 epoch 196 个 iteration，训练 10 轮共 1960 个。

### 批次数的整除公式

$$\text{批次数} = \left\lfloor \frac{N + B - 1}{B} \right\rfloor$$

   * Python 里写 `(N + B - 1) // B`，`//` 是整除；能整除时它等价于 `N // B`，不用分两种情况写。

   * 套 5 万与 256：`(50000 + 256 - 1) // 256` 结果就是 196。

   * 未整除时批次数为 $N \div B + 1$、整除时为 $N \div B$，分页公式一个式子覆盖两种情形。

### 四种梯度下降

   * 根本区别只在 batch size：全梯度下降 BGD 把整个训练集的 N 条当成一批，全部训完才更新一次；随机梯度下降 SGD 每次只拿 1 条，更新最频繁。

   * 小批量梯度下降 Mini-batch 取 B 条且 $1<B<N$：取 1 条退化成 SGD，取全部退化成 BGD。

   * 随机平均梯度下降每次取 1 条，但与历史梯度求均值：第二次用第二个梯度与第一个的均值，第三次再与上次的均值求均值；初期可能不准，后期越来越准。

## 反向传播

### 定义与方向

   * **反向传播（Back Propagation，BP）**

       * > **定义**：利用损失 error 值，从后往前，结合梯度下降逐层求导，依次完成参数更新。

       * 正向传播（前向传播）：数据从输入层经隐藏层到输出层，从左往右把结果算出来。

       * 更新顺序与正向相反：先更新最后一层，再逐层往前传递。

       * 为什么必须逐层：拿到损失后算不了第一层的参数，因为损失式子里没有第一层的权重，只有最后一层的输出，只能先算最后一层再一节一节往前剥。

### 参数分组与更新顺序

   * 26 个参数按组数：靠近输入的一组每个节点 3 个输入加 1 个偏置共 4 个、共 3 个节点，12 个；中间一组每个 4 个、共 2 个节点，8 个；靠近输出一组每个 2 个输入加 1 个偏置共 3 个、共 2 个节点，6 个。

   * 更新顺序反过来：先更最后那 6 个，再更中间 8 个，最后才轮到最前面 12 个。

   * 越往前越难更，因为路越多：靠近输出的权重倒推基本只有一条链；靠近输入的权重，上一层每个神经元都跟它相连，每条连接都是一条路。

   * > **提示**：隐藏层比输出层难更的根本原因是路径变多，不是公式变复杂——同一份梯度要从多个输出节点传回来再累加。

### 链式法则

$$\frac{\partial Y}{\partial X} = \frac{\partial Y}{\partial A} \cdot \frac{\partial A}{\partial B} \cdot \frac{\partial B}{\partial X}$$

   * 写成分数看，前一项分母 $A$ 与后一项分子 $A$ 约掉、$B$ 与 $B$ 约掉，剩下的正好是 $\partial Y/\partial X$。

   * > **提示**：约分只是帮助记忆的直观写法，真正保证成立的是链式法则本身——复合函数对自变量的导数等于沿途每一段导数连乘。

   * 这个“一段一段往回乘”的动作叫梯度传播；反向传播就是利用链式法则，沿网络把梯度从后往前传下去，对各节点权重做更新。

### 前向手算

   * 每个神经元只做两件事：对上一层输出加权求和（外加偏置）得 $net$，把 $net$ 送进激活函数得 $out$；前向传播就是把这两步沿层一遍遍重复。

   * 偏置实际当成“输入恒为 1”的权重加进去，所以式子里总有一个 $\times 1$。

   * 隐藏层：$net_{h1}=0.15\times0.05+0.20\times0.10+0.35\times1=0.3775$，过 sigmoid 得 $out_{h1}\approx0.5933$；$H_2$ 用 $w_3$、$w_4$ 与同一偏置得 $out_{h2}\approx0.5969$。

   * 输出层输入是隐藏层的 $out$：$net_{o1}=w_5\cdot out_{h1}+w_6\cdot out_{h2}+b_2$，激活后 $out_{o1}\approx0.7514$；$O_2$ 用 $w_7$、$w_8$ 与 $b_2$ 得 $out_{o2}\approx0.7729$。

   * 平方损失两项各占一半：$E_{total}=\frac{1}{2}(t_1-out_{o1})^2+\frac{1}{2}(t_2-out_{o2})^2$，$t_1=0.01$、$t_2=0.99$；左边 $0.5496/2=0.2748$，右边 $0.0471/2=0.0236$，合计 0.2984。

   * > **易错点**：0.2984 是总损失，不是某一个输出的误差；对 $out_{o1}$ 求导时只有左边一项有关，右边是常数、导数为 0，把两项一起求导是这里最容易犯的错。

### 单权重三段链

   * 求 $\partial E_{total}/\partial w_5$ 不能一步得出：损失里没有 $w_5$，只有 $out_{o1}$，$out_{o1}$ 由 $net_{o1}$ 激活而来，$net_{o1}$ 里才有 $w_5$，所以拆三段。

$$\frac{\partial E_{total}}{\partial w_5}=\frac{\partial E_{total}}{\partial out_{o1}}\cdot\frac{\partial out_{o1}}{\partial net_{o1}}\cdot\frac{\partial net_{o1}}{\partial w_5}$$

   * 第一段：$1/2$ 与外层平方求导下来的 2 抵消，内层 $(t_1-out_{o1})$ 对 $out_{o1}$ 求导是 $-1$，得 $out_{o1}-t_1=0.7514-0.01=0.7414$。

   * 第二段是 sigmoid 导数 $\sigma'(x)=\sigma(x)(1-\sigma(x))$，直接代 $out_{o1}$：$0.7514\times(1-0.7514)=0.1868$。

   * 第三段对 $w_5$ 求导，其余项为常数，剩下自己的系数 $out_{h1}=0.5933$，把正向算出的结果搬过来即可。

   * 三段连乘 $0.7414\times0.1868\times0.5933\approx0.0822$ 才是梯度；梯度不是某一个偏导，而是整条链上所有偏导的乘积。

   * 更新：$w_5$ 初值 0.40、学习率 0.5，则 $w_5^{新}=0.40-0.5\times0.0822=0.3589$；这一步只更新了一个参数。

### 隐藏层权重的多路径

   * $w_6$ 最好办：前两段链路不变，第三段换成 $out_{h2}$。

   * $w_1$ 的路更长：$E_{total}\to out_{o1}\to net_{o1}\to out_{h1}\to net_{h1}\to w_1$，每往前一层链上多两段。

   * 而且 $w_1$ 不止一条路：从 $O_2$ 也能走回 $E_{total}\to out_{o2}\to net_{o2}\to out_{h1}\to net_{h1}\to w_1$。

   * > **易错点**：两条路都通且都要算；$w_1$ 被两个输出节点共用，梯度是两条路径贡献之和，只挑一条等于把另一份梯度丢了。

   * 网络越深，同一权重被复用的次数越多，反传要走全的路径也越多；难的不是公式，是路径要一条条走完再累加。

### 一轮训练的完整含义

   * $w_1$ 到 $w_8$ 全部更新完后，拿同一批特征配上新权重与新偏置，再前向算一遍得到新损失，再反向传一遍更新一轮。

   * 一轮训练 = 一次前向（算出损失）+ 一次反向（算出梯度、更新全部参数）；训练 N 轮就是把这一整套重复 N 遍，每轮特征不变，变的只有权重。

   * 前向与反向的分工：前向拿特征从左往右把结果算出来，反向拿损失从右往左结合 $W_{新}=W_{旧}-\eta\cdot\text{梯度}$ 把每个参数更新掉；一个负责算，一个负责改。

## 神经网络的优缺点

### 优点

   * 精度高、性能优于其他机器学习方法，某些领域已超过人：3 个特征进来、隐藏层写成 512 个神经元，网络就能基于这 3 个特征抽出 512 组信息、生成 512 组权重与偏置。

   * 可以近似任意非线性函数：激活函数把非线性加进来，二分类、多分类都能做。

   * 学界业界都热，框架与库多，有大量现成 API 可直接用。

### 缺点

   * 黑箱：$W$、$B$ 能打印出来，但解释不了为什么是这个值、中间经历了什么、三层为什么比两层好；不像 K-means 有 SSE 加肘部法定 K，也没有“训练集测试集 7:3 或 8:2”“学习率 0.01 到 0.0001”这类能背下来的规律，几层、每层几个神经元全得试。

   * 训练时间长、需要大量算力；网络结构复杂，超参要调。

   * 小数据集上表现不好、容易过拟合：模型太复杂，一条数据也能被它提出一堆“脏”规律；解决过拟合最直观的办法是正则化。

   * 工程做法：先搭两三层、每层少来几个神经元的简单网络，再慢慢加、慢慢测；经验是神经元个数从前层往后层逐渐递减，第一层最多，越往后越少，这是经验之谈，不是定理。

   * 一句话记：优点精度高、应用场景广；缺点黑箱、不适用于小数据集。
