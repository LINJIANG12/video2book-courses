# 激活函数与参数初始化

## Sigmoid

* **Sigmoid**

    * > **定义**：把任意实数压到 $0$ 到 $1$ 之间的激活函数，是二分类输出层与浅层网络的默认选择。

    * 输入大致落在 $-6$ 到 $6$ 之间才有反应，变化真正明显的是 $-3$ 到 $3$。

    * 值域 $0$ 到 $1$，对称中心在 $0.5$，输出绕着 $0.5$ 上下分布。

    * 导数值落在 $0$ 到 $0.25$；$0.25$ 是它能给出的最大斜率，在最陡的地方梯度也只有四分之一。

    * 反向传播时梯度一层层连乘，几层之后就小得没法看，是梯度消失的典型来源。

    * 输出全是正数：一个负得很厉害的加权和输进去，出来是 $0.00$ 几，仍然是正的；正负在输出端被抹平，网络只知道“有多大”不知道“朝哪边”，所谓 Sigmoid 没有考虑负样本说的就是这个。

    * 主要用途：浅层网络，以及二分类的输出层。

## Tanh

* **Tanh**

    * > **定义**：以 $0$ 为中心、把任意实数映射到 $-1$ 到 $1$ 的激活函数，补上了 Sigmoid 抹掉负半边的缺口。

    * 公式：$\tanh(x) = \frac{e^{x} - e^{-x}}{e^{x} + e^{-x}} = \frac{1 - e^{-2x}}{1 + e^{-2x}}$，两种写法等价，后一种指数只剩一项，推极限更顺手。

    * 式中的 $x$ 是上一层加权求和的结果，可正可负、可大可小，要问的是它往两端跑时停在哪里。

    * 上界：$x$ 越来越大时 $e^{-2x}$ 迅速掉向 $0$，分子变成 $1$、分母也是 $1$，一比一得 $1$。

    * 下界：$x$ 负得越来越狠时 $e^{-2x}$ 反过来暴涨，前面那个 $1$ 只是零头可以不看，分子剩下 $-e^{-2x}$、分母剩下 $e^{-2x}$，约掉得 $-1$。

    * 边界：约在 $-3$ 到 $3$ 之间还有明显反应，真正变化快的是 $-1$ 到 $1$，超过 $\pm 3$ 之后曲线几乎是平的。

* **Tanh 的导数**

    * $\frac{d}{dx}\tanh(x) = 1 - \tanh^{2}(x)$，即 $1$ 减去它自己的平方，推导过程不必记，结论要记牢。

    * 求最大值：把 $\tanh x$ 记为 $A$，式子成了 $1 - A^{2}$，对 $A$ 求导得 $-2A$，令它等于 $0$ 只有 $A = 0$ 一个解，代回得 $1 - 0^{2} = 1$。

    * $A^{2}$ 永远非负，$1 - A^{2}$ 不会超过 $1$；只要 $x$ 有限它又大于 $0$，所以导数范围是 $(0, 1]$，习惯写成 $0$ 到 $1$。

    * 最大值 $1$ 出现在 $x = 0$ 那一点。

    * > **易错点**：“导数最大是 $1$”不能理解成“导数恒等于 $1$”——它只在原点取到 $1$，往两边迅速往下掉，$|x| > 3$ 之后基本就是 $0$。

    * 两侧趋零正是软肋：两头都平，梯度就没了，深层网络照样梯度消失；它比 Sigmoid 强，但没有跳出这个坑。

* **与 Sigmoid 的速度比较**

    * 参数更新公式 $w \leftarrow w - \eta \cdot \frac{\partial L}{\partial w}$，梯度是乘在学习率后面的那一项：它是 $1$ 这一步就迈得大，是 $0.25$ 就只迈四分之一步，步子大则走到终点需要的步数少。

    * 导数上限对照：Sigmoid 是 $0.25$，Tanh 是 $1$，在各自最佳状态下 Tanh 的梯度上限是 Sigmoid 的四倍，收敛更快、迭代次数更少。

    * > **易错点**：比较必须各自取极值，不能随手挑一个横坐标——“Tanh 一定比 Sigmoid 快”是错话，正确说法是“Tanh 的梯度上限更高”；若某任务里 Tanh 的梯度长期稳定在 $0.1$、Sigmoid 稳定在 $0.25$，反而是 Sigmoid 效率高。

    * 适用层位：隐藏层，且只建议浅层——不超过五层的网络；再深，两侧导数趋零的问题会一层层累积，照样训不动。

    * 输出层不接手 Tanh，那还是 Sigmoid 的活。

| 项目 | Sigmoid | Tanh |
| :--- | :--- | :--- |
| 值域 | 0~1 | -1~1 |
| 对称中心 | 0.5 | 0 |
| 有效区间 | -6~6（-3~3 明显） | -3~3（-1~1 明显） |
| 导数范围 | 0~0.25 | 0~1 |
| 收敛速度 | 慢 | 快 |
| 主要用途 | 浅层、输出层 | 隐藏层（浅层） |

## ReLU

* **ReLU**

    * > **定义**：$\mathrm{ReLU}(x) = \max(0, x)$，负数一律变 $0$、正数原样保留，是目前用得最多的隐藏层激活函数。

    * 图像：左边是贴着横轴的一条线，右边是 $y = x$ 这条斜线，中间在原点拐个弯。

    * 立场：只认正样本，更加重视正信号，负信号直接忽略；负的加权和进来输出是 $0$，这部分信息全丢。

    * 默认行为就是这样，确实需要保留负区间的信息要用它的几个变体。

* **ReLU 的导数**

    * 负区间是常数 $0$，导数为 $0$；正区间是 $y = x$，导数为 $1$。

    * 导数只有 $0$ 或 $1$ 两个取值，不存在 $0.5$、$0.7$、$0.8$ 这种中间值。

    * 为什么永远是 $1$：正区间里 $\max$ 取到的就是 $x$ 本身，斜率天然是 $1$；负区间取到的是常数 $0$，斜率天然是 $0$，压根走不到介于 $0$ 和 $1$ 之间的状态。

    * > **提示**：$x = 0$ 这个拐点上导数不存在，工程实现里统一按 $0$ 处理；它只影响一个点，对训练没有实际影响。

### 三项优势

* **收敛更快**

    * Tanh 的导数上限虽然也是 $1$，但实际训练中大量点落在 $0.2$、$0.3$、$0.4$ 上；ReLU 在正区间是实打实的 $1$，一步是一步。

* **计算量小**

    * Sigmoid 每算一次都要 $1/(1+e^{-x})$，指数、除法都得上；ReLU 只做一次比较，两边根本不是一个量级的运算。

* **梯度不衰减**

    * Sigmoid 的梯度上限 $0.25$，五层传下来是 $0.25^{5}$，小到可以忽略；ReLU 的 $1$ 无论乘多少次方还是 $1$，十层、一百层都不变形，梯度消失在这里被按住。

    * 它在正区间没有饱和：$x$ 再大，斜率还是 $1$。

* **输出稀疏**

    * 一部分神经元输出为 $0$，等于在做特征筛选：本来 $20$ 列特征参与，筛着筛着只剩 $7$ 列。

    * 特征少了模型跟着变简单，参数之间的相互依存关系也被削弱，过拟合的压力就小一些。

### 神经元死亡

* **神经元死亡（Dead ReLU）**

    * > **定义**：神经元长期落在负区间，梯度恒为 $0$，权重再也得不到更新，输出永久固定为 $0$，等于从网络里被摘掉。

    * 成因：训练往前推进时权重在变、输入分布也在变，总会有一部分输入落进负半轴；落进去的神经元梯度是 $0$，代进 $w \leftarrow w - \eta \cdot 0$，权重原地不动，而且永远不动。

    * 后果：权重不更新，这个神经元的输出就固定成 $0$，之后无论喂什么都是 $0$。

* **设计的两面性**

    * 本质是同一个设计的两面：用“负区间梯度为零”换来了稀疏和高效，代价是一旦长期落在负区间就再也活不过来。

    * 同一个设计翻过来就是死穴——正区间不饱和带来的深层可用性，和负区间梯度为零带来的永久失活，是同一套规则的两种后果。

## ReLU 的负区间变体

### 负区间留缝

* **LeakyReLU**

    * > **定义**：负区间不再归零、改为给 $0.01x$ 的 ReLU 变体，让负样本保留一条小缝。

    * 公式：$\mathrm{LeakyReLU}(x) = x$（$x > 0$），$\mathrm{LeakyReLU}(x) = 0.01x$（$x \le 0$）。

    * 机理：负的时候把原来的值缩小一百倍，无限接近 $0$ 但没有变成 $0$，梯度也就不是 $0$，神经元不会被判死刑。

* **0.01 的来历**

    * $0.01$ 是 ReLU 的作者定的，不是必须遵守的常数；它和学习率的常用区间（$0.01$ 到 $0.001$）是同一个量级，按这个量级给系数效率通常比较合适。

    * 与正则化的类比：ReLU 像 L1，不听话的权重直接砍成 $0$、不要了；LeakyReLU 像 L2，给一个系数把值压得很小很小、但值还在——一个是删除，一个是削弱。

### 斜率可调的两个变体

* **PReLU**

    * 负区间的斜率当成参数，给多少就是多少，$0.0001$ 也行，$0.02$ 也行。

* **RReLU**

    * 负区间斜率每次随机取。

* **命名重叠**

    * LeakyReLU、PReLU、RReLU 干的是同一件事，名字起这么多是因为深度学习不是一家公司做的，多家机构、多个团队各做各的，各自给自己的方法起名，凑到一起就成了一词多义。

    * 同类的例子是损失函数：loss、cost function、代价函数、成本函数，说的是同一个东西。

    * 实际用的时候不用纠结：要么 ReLU（不考虑负样本），要么 LeakyReLU（默认 $0.01$），要自己指定斜率就用 PReLU。

## Softmax

* **Softmax**

    * > **定义**：Sigmoid 在多分类上的推广，把输出层的线性结果映射到 $0$ 到 $1$，并保证同一组类别的概率加起来等于 $1$，最后取最大的那个作为预测类别。

    * 公式：$\mathrm{softmax}(z_i) = \frac{e^{z_i}}{\sum_{j=1}^{n} e^{z_j}}$，$z_i$ 是第 $i$ 个类别拿到的线性输出，即上一层加权求和的结果；分子是它自己的指数，分母是全部类别指数的和。

    * 算法：分母对所有类别都一样，变的只有分子；$z_1=1$、$z_2=2$、$z_3=3$、$z_4=4$、$z_5=5$ 时，每个类别都是自己的 $e^{z_i}$ 去除以 $e^{1}+e^{2}+e^{3}+e^{4}+e^{5}$。

    * 指数干两件事：把任意实数变成正数，概率不可能为负；它单调递增，原来大的 $z$ 归一化之后概率仍然最大，排序不会被弄乱。

    * 分母再做一次归一，这组数就天然满足“非负且和为 $1$”。

    * 与 if-else 的关系：Sigmoid 是二选一的 if-else，三选一、四选一当然也能层层嵌套地写，Softmax 干的事就是把这个嵌套摊平，一次给出每个类别的概率。

    * 算例：四类 A、B、C、D 给出 $0.1$、$0.3$、$0.5$、$0.1$，和为 $1$，$0.5$ 最大，这个样本就判给 C 类。

### 输出端的形态

* **网络结构中的位置**

    * 网络末端先给出每个类别一个线性输出 $z_1$ 到 $z_{10}$，经 softmax 归一化后得到 $p_1$ 到 $p_{10}$，满足 $p_1 + p_2 + \cdots + p_{10} = 1$。

    ```text
    [ input ] --> [ hidden layer ] --> z1  z2  ...  z10
                                            |
                                            v
                                    softmax normalize
                                            |
                                            v
                              p1 + p2 + ... + p10 = 1
                                            |
                                            v
                               argmax(pi) -> predicted class
    ```

* **判定的读法**

    * 最后取 $\arg\max(p_i)$ 作为预测类别，输出端摆 $10$ 个数就对应 $10$ 个类别。

    * 十个类别里若最大项占约 $0.74$，剩下九个全加一起才 $0.26$，判给 $0.74$ 对应的那一类没有悬念。

### dim 的语义

* **dim 参数**

    * `dim` 的含义是“把哪一个维度压掉”，不是“第几行”或“第几列”。

    * 一维张量只有一个方向，`dim=0` 就是沿这唯一的轴归一，几个数加起来是 $1$。

    * 判断方法：写完 `dim=k`，看第 $k$ 个下标在结果里消失了，剩下的下标就是结果保留的方向。

| 写法 | 压掉哪个维度 | 归一结果 |
| :--- | :--- | :--- |
| `dim=0` | 第 0 维（行索引） | 每一列的元素相加为 1 |
| `dim=1` | 第 1 维（列索引） | 每一行的元素相加为 1 |

* **结果验算**

    * 验证：打印出来的概率直接相加看是不是 $1$；想手算就把整串数字复制进系统计算器，带加号的算式会被直接算出来。

    * 把其中一个 $0.7$ 改成 $0.6$，总和立刻少 $0.1$，差一点都不行。

## 激活函数选型

* **激活函数的作用**

    * 给神经元加上非线性，这样它才有能力把不同类别分开；记住这一句，剩下的就是位置问题——这个激活函数放在哪一层。

* **输入层**

    * 不选。它接的是原始特征，不承担激活的职责，选什么没有意义。

### 隐藏层优先级

* **尝试顺序**

    * ReLU → LeakyReLU（默认 $0.01$）→ PReLU / RReLU → Tanh → Sigmoid，从左往右依次尝试，全都不行就换思路。

    * ReLU 不行（比如负样本里也带着重要信息）就退到 LeakyReLU；嫌 $0.01$ 不合适，用 PReLU 自己定，或者 RReLU 随机取。

    * Tanh 排在 Sigmoid 前面：梯度上限 $1$ 对 $0.25$，而且以 $0$ 为中心，比 Sigmoid 的 $0.5$ 中心更好用。

* **一句话特点**

    * Sigmoid：映射到 $0$~$1$，导数 $0$~$0.25$；梯度消失明显，适合浅层，多用于二分类输出层。

    * Tanh：映射到 $-1$~$1$，以 $0$ 为中心，导数 $0$~$1$；收敛比 Sigmoid 快，用于隐藏层且限于浅层。

    * ReLU：$\max(0, x)$，只考虑正样本；导数非 $0$ 即 $1$，计算量小、收敛最快、缓解梯度消失，用于隐藏层尤其深层，缺点是神经元死亡。

    * Softmax：多分类，把多个输出变成和为 $1$ 的概率，取最大者为结果，用于多分类输出层。

### 输出层按任务

* **二分类**

    * 用 Sigmoid，输出一个 $0$ 到 $1$ 的概率。

* **多分类**

    * 用 Softmax，输出一组和为 $1$ 的概率，取最大。

* **回归**

    * 用 Identity（$f(x) = x$，什么都不做）；这个了解就行，用神经网络做纯回归的场景很少，绝大多数是分类。

| 位置 | 选择 | 说明 |
| :--- | :--- | :--- |
| 隐藏层 | ReLU → Leaky ReLU → PReLU / RReLU → Tanh → Sigmoid | 从左往右依次尝试，全都不行就换思路 |
| 输出层（二分类） | Sigmoid | 输出 0~1 的单个概率 |
| 输出层（多分类） | Softmax | 输出一组和为 1 的概率 |
| 输出层（回归） | Identity | $f(x)=x$，很少用 |
| 输入层 | 不选 | 与输入特征有关，不承担激活职责 |

## 参数初始化的目的

* **参数初始化（Parameter Initialization）**

    * > **定义**：给每一层、每一个神经元身上挂的 $W$ 和 $B$ 指定初始值的过程，这些值一开始总得给一个，不能空着。

    * 它同时管着三件事：会不会一上来就梯度消失或者梯度爆炸、收敛得快不快、以及网络到底能不能学到不同的东西。

### 梯度量级

* **梯度消失**

    * 权重设得很小，比如每层都是 $0.01$，数据往前传时每过一层就乘一次，五层下来是 $0.01^{5}$，也就是 $10^{-10}$ 这个量级。

    * 梯度同样是一层层乘下去的，乘到最后变得非常非常小。

* **梯度爆炸**

    * 权重是 $10$、每层都是 $10$，$10^{5} = 100000$，乘出来的数非常大，梯度一路被放大。

    * 两条链路的层数完全一样，唯一差别是每层乘的那个系数：小于 $1$ 的系数连乘会指数级衰减，大于 $1$ 的系数连乘会指数级膨胀。

    ```text
    x --[x0.01]--> h1 --[x0.01]--> h2 --[x0.01]--> h3 --[x0.01]--> h4 --[x0.01]--> y   => 0.01^5 = 1e-10
    x --[x10]----> h1 --[x10]----> h2 --[x10]----> h3 --[x10]----> h4 --[x10]----> y   => 10^5    = 100000
    ```

### 收敛速度

* **更新公式**

    * $W_{\text{new}} = W - \eta \cdot g$，其中 $\eta$ 是学习率，$g$ 是梯度。

    * 学习率固定不变时，梯度 $g$ 越大，一次更新迈出的步子越大，模型收敛得越快。

* **与激活函数的连带关系**

    * ReLU 求导之后值不是 $1$ 就是 $0$，只要这一层没被截断，梯度就原样往下传；tanh 的导数最大值也才到 $1$，绝大多数位置还要更小，梯度传得更“足”收敛自然更快，这也是优先用 ReLU 的一条理由。

### 打破对称性

* **同值初始化的后果**

    * 一层 5 个神经元接同一组输入 $x_1$、$x_2$、$x_3$，每个神经元都有自己的 $W = (w_1, w_2, w_3)$ 和一个 $B = b$，这样才能和三个特征一一对上。

    * 一旦这五组 $W$ 和 $B$ 全都一模一样，输入一样、权重一样、偏置一样，算出来的结果必然一样。

    * 结果一样意味着五个神经元做的事情完全重合，等于拿同一批数据算了五回；往后传下去是五份一样的数，做预测五个神经元给出的答案还是同一个，摆五个和摆一个没有区别。

    * 更麻烦的是初始化一样，它们后续收到的梯度也一模一样，每次更新迈出的步子相同，训练多少轮都还是同一条心。

* **破对称的要求**

    * 初始化时必须保证这五个神经元的权重和偏置各不相同，让它们各自去抓不同的特征信息。

    * 哪怕这一层生成的全是 $1$、下一层全是 $2$、再下一层全是 $3$，只要同一层内部的值互相不同，结合相同的输入也能学出不同的东西来。

* **三个目的的分量**

    * 前两个是“值的量级”问题，第三个是“值要彼此不同”的问题；七种方案里真正区分优劣的，正是第三条。

    ```text
    输入  x1  x2  x3      （同一组特征，五个神经元共用）

    神经元 1   W = (w1, w2, w3)   B = b
    神经元 2   W = (w1, w2, w3)   B = b
    神经元 3   W = (w1, w2, w3)   B = b
    神经元 4   W = (w1, w2, w3)   B = b
    神经元 5   W = (w1, w2, w3)   B = b
                                  |
                                  v
                   五个输出完全相同 —— 同一批数据算了五遍
    ```

## 初始化方案与 API

* **`torch.nn.init`**

    * > **定义**：PyTorch 里全部参数初始化方案的统一入口，每个函数都长成 `nn.init.xxx_`。

    * `nn` 是 neural network，神经网络；`init` 是 initialization，初始化，合起来就是“神经网络的初始化”。

    * 函数名基本就是把方案名直接搬过来：均匀分布 `uniform`、正态分布 `normal`、全零 `zeros`、全一 `ones`、固定值 `constant`、凯明 `kaiming`、泽维尔 `xavier`。

    * 末尾那个下划线是 PyTorch 的原地操作约定：直接改写传进去的那个张量本身，而不是另外返回一份新的。

    * 凯明和泽维尔各自都有正态、均匀两个版本，于是七种方案落成了九个函数。

| 方案 | API | 取值 |
| :--- | :--- | :--- |
| 均匀分布 | `nn.init.uniform_` | 默认 $U(0,1)$，可改为 $[-\frac{1}{\sqrt{D}},\ \frac{1}{\sqrt{D}}]$ |
| 正态分布 | `nn.init.normal_` | $N(0,1)$，均值和标准差可调 |
| 全零 | `nn.init.zeros_` | 全部为 0 |
| 全一 | `nn.init.ones_` | 全部为 1 |
| 固定值 | `nn.init.constant_` | 全部为指定值 |
| 凯明·正态 | `nn.init.kaiming_normal_` | $N(0,\text{std})$，$\text{std}=\sqrt{2/n_{in}}$ |
| 凯明·均匀 | `nn.init.kaiming_uniform_` | $[-\text{limit},\ \text{limit}]$，$\text{limit}=\sqrt{6/n_{in}}$ |
| 泽维尔·正态 | `nn.init.xavier_normal_` | $N(0,\text{std})$，$\text{std}=\sqrt{2/(n_{in}+n_{out})}$ |
| 泽维尔·均匀 | `nn.init.xavier_uniform_` | $[-\text{limit},\ \text{limit}]$，$\text{limit}=\sqrt{6/(n_{in}+n_{out})}$ |

### 均匀分布与正态分布

* **均匀分布（Uniform）**

    * 权重在区间里均匀随机地取，默认区间是 $0$~$1$。

    * 常用区间是 $[-\frac{1}{\sqrt{D}},\ \frac{1}{\sqrt{D}}]$，其中 $D$ 是“输入数量”，具体指**当前层的上一层**有几个神经元。

    * 为什么取上一层而不是当前层：当前层是做输出的，只有它的上一层才是给它喂输入的。

    * 每一层的 $D$ 都取自己上一层的大小，不是全网络共用一个数：$3 \to 5 \to 5 \to 2$ 的结构里，第一个隐层取 $3$，第二个隐层取 $5$，输出层取 $5$。

* **正态分布（Normal）**

    * 默认是均值为 $0$、标准差为 $1$ 的高斯分布，函数名 `normal_`；按住 Ctrl 点进函数签名能看到 `mean` 和 `std` 两个参数，改它们就行。

    * 与均匀分布在使用上几乎是一回事，都是随机取值，只是随机的方式从“平着铺开”变成了“中间密、两边稀”。

### 定值三种

* **全零（`zeros_`）**

    * 全部为 $0$，是这五种简单方案里用得最多的。

    * 最常见的角色不是给权重用的，而是给偏置用的：有些时候压根不考虑偏置，就把偏置项全部设成零，权重再换别的方案去初始化。

* **全一（`ones_`）**

    * 全部为 $1$，除打破不了对称性外还多一条毛病：每层都乘 $1$ 再累加，激活值在网络中会指数增长，最后造成梯度爆炸。

* **固定值（`constant_`）**

    * 全部为指定值；固定值的英文是 constant，不是 for。

    * 三种定值方案的优缺点完全相同：优点是实现简单，不用考虑什么分布、什么区间；缺点是打破不了对称性。

## 凯明初始化

* **凯明初始化（Kaiming Initialization）**

    * > **定义**：专为 ReLU 及其变体设计的初始化方案，按输入维度把值的范围缩放好，使梯度保持稳定。

    * 又名“何初始化”，因为提出它的作者姓何——何凯明，师从汤晓鸥。

    * 两个版本：`kaiming_normal_` 与 `kaiming_uniform_`，记法就是“在均匀、正态的单词前面加上 `kaiming_`”。

    * 正态版从均值为 $0$、标准差为 std 的分布里抽样，均匀版从 $[-\text{limit},\ \text{limit}]$ 里取。

    * 两个式子的差别只在分子：一个是 $2$，一个是 $6$。

* **为什么是 2 和 6**

    * 这两个数不好推，是试验出来的；神经网络中间到底做了哪些事我们其实不知道，所以它被称为黑盒子。

    * 常见的做法是：认为某个环节、某个参数或某个公式不 OK，做大量训练，发现针对某几个参数优化之后拟合效果确实好了很多，就可以拿这批数据去发论文；凯明就是这么来的。

    * 使用上直接调 API，但底层必须清楚：正态是从 $0$ 到 std 之间抽样，均匀是从 $-\text{limit}$ 到 $\text{limit}$ 之间取，std 和 limit 各自怎么算。

### 取值公式

* **正态版**

    * $\text{std} = \sqrt{\frac{2}{n_{in}}}$，从 $N(0, \text{std})$ 抽样。

* **均匀版**

    * $\text{limit} = \sqrt{\frac{6}{n_{in}}}$，从 $[-\text{limit},\ \text{limit}]$ 取值。

* **配套与层位**

    * 只要用 ReLU，就优先用凯明；它就是专门针对 ReLU 及其变体做的一种设计，考虑到了 ReLU 的特性，按输入维度缩放后能让梯度保持稳定。

    * 正态版还是均匀版都可以；深层网络（十层以上）必须用凯明或泽维尔。

### n_in 的取法

* **$n_{in}$ 的语义**

    * 指“当前层接收到的输入个数”，也就是上一层有多少个神经元，而不是字面意义上的“输入层有几个神经元”。

    * 输入层和输入维度是两码事，只有最左边那一层两个说法才碰巧重合。

    * > **易错点**：以 $3 \to 5 \to 5 \to 2$ 的结构为例，第一个隐层的输入是 $3$、第二个隐层是 $5$、输出层也是 $5$；用凯明时每一层各拿自己的这个数去算，不能拿输入层的 $3$ 一以贯之。

* **逐层算例**

    * 一个 $3$ 个神经元的层后面接一个 $5$ 个神经元的层，后者的输入就是 $3$；再往后接的那一层，输入就是 $5$。

## 泽维尔初始化

* **泽维尔初始化（Xavier Initialization）**

    * > **定义**：同时把输入维度和输出维度算进尺度的初始化方案，适合 sigmoid、tanh 这类非 ReLU 激活，能解决梯度消失。

    * 单词念泽维尔，Xavier，音标 /ˈzeɪviər/，不是“希维尔”。

    * API 更好记：把凯明那行的 `kaiming` 换成 `xavier`，其他一模一样。

    * 适用场景上对 ReLU 这类函数表现就不好了。

* **与凯明的差别**

    * 凯明只看输入，泽维尔除了输入还要看输出。

    * 单看公式，不过就是把输出那一项从分母里拿掉、系数再调一调；但真要把这个改动验证成“更好”，需要大量实验。

    * 凯明很可能正是因为泽维尔对 ReLU 支持不够友好，才专门针对这个问题做出的改进。

### 取值公式

* **正态版**

    * $\text{std} = \sqrt{\frac{2}{n_{in} + n_{out}}}$。

* **均匀版**

    * $\text{limit} = \sqrt{\frac{6}{n_{in} + n_{out}}}$。

* **两个维度的定义**

    * $n_{in}$ 是当前层接收的、上一层的神经元数量；$n_{out}$ 是当前层输出的、要传给下一层的数量。

    * 说白了就是“这一层进几个、出几个，两个数加起来”。

* **逐层算例**

    * $3 \to 5 \to 5 \to 2$ 的结构：$3$ 进 $5$ 出的那一层加起来是 $8$；$5$ 进 $5$ 出的是 $10$；$5$ 进 $2$ 出的是 $7$；每层算每层自己的，别串。

## 方案对比与选用

| 方案 | 能否打破对称性 | 优点 | 缺点 | 适用场景 |
| :--- | :--- | :--- | :--- | :--- |
| 均匀分布（随机） | 能 | 每个神经元拿到的值都不同，天然破除对称性 | 取值范围不当会引出梯度问题 | 浅层网络、结构简单的模型 |
| 正态分布 | 能 | 随机性同样能破对称 | 取值范围不当会引出梯度问题 | 浅层网络、结构简单的模型 |
| 全零 | 不能 | 操作简单 | 不能打破对称性 | 几乎不使用；只用于偏置 |
| 全一 | 不能 | 操作简单 | 不能打破对称性，还会让激活值在网内一路放大造成梯度爆炸 | 测试时临时固定用 |
| 固定值 | 不能 | 操作简单 | 不能打破对称性 | 调试、测试时固定用 |
| 凯明 | 能 | 专为 ReLU 及变体设计，能对输入维度做缩放、保持梯度稳定 | 对非 ReLU 激活效果一般 | ReLU 及变体；深层网络（十层以上） |
| 泽维尔 | 能 | 能解决 sigmoid、tanh 的梯度消失 | 对 ReLU 这类函数表现不佳 | sigmoid、tanh；深层网络 |

### 按对称性分堆

* **破不了对称的三个**

    * 全零、全一、固定值：整层都是同一个值，不用考虑什么分布、什么区间，所以实现简单。

    * 每个神经元还是由同一套 $W_1$、$W_2$、$W_3$ 加一个 $B$ 组成，你的这些值和我的这些值一模一样，对称性在这里就破不了；特征一样，算出来的结果自然也一样。

    * 全一还多一条：每层都乘 $1$ 再累加，激活值在网络中会指数增长，最后造成梯度爆炸。

* **能破对称的四个**

    * 均匀分布（随机）、正态分布、凯明、泽维尔：一旦随机，你我的 $W$ 就不一样，算出来的结果也不一样。

    * 随机的问题在于取值范围，范围选不当照样会引出梯度问题。

    * 这恰好解释了凯明和泽维尔存在的意义：它们不是“更随机”，而是把随机的范围按输入维度（泽维尔还要加上输出维度）算好了。

### 四条判断

| 情形 | 选择 |
| :--- | :--- |
| 激活函数是 ReLU 及其变体 | 凯明（正态版、均匀版都行） |
| 激活函数是 sigmoid、tanh 等非 ReLU | 泽维尔 |
| 浅层网络（两层、三层，五层以内） | 随机初始化，或者正态分布 |
| 深层网络（十层以上） | 凯明或泽维尔 |

* **激活函数定方案**

    * ReLU 优先凯明，因为 ReLU 用得最多，凯明又是为它量身定做的；非 ReLU 就交给泽维尔。

* **网络深度定方案**

    * 两层、三层、五层以内，用随机初始化或者正态分布完全够，不一定非得请出凯明和泽维尔——这两个方案本来就是为深层准备的，浅层硬用也能跑，只是没必要。

    * 一旦到了深层，就必须在凯明和泽维尔之间选，不能再随手随个机就完事。

### 三种必须掌握

* **凯明**

    * 排第一，因为 ReLU 用得最多。

* **泽维尔**

    * 除了 ReLU 之外的基本都归它。

* **全零**

    * 专门给偏置用。

* **一句话收口**

    * 权重要么凯明、要么泽维尔，偏置全零。

* **三个条件反射问答**

    * 参数初始化的目的是什么：防止梯度消失或梯度爆炸、提高收敛速度、打破对称性。

    * 七种方案分别是谁：按能不能打破对称性分两堆，破不了的三个是全零、全一、固定值，能破的四个是随机（均匀分布）、正态分布、凯明、泽维尔。

    * 到底怎么选：ReLU 用凯明，非 ReLU 用泽维尔，浅层随机，深层凯明或泽维尔。

## 代码落地要点

* **先建层再初始化**

    * 先 `import torch.nn as nn`；初始化是挂在某一层的权重上的，没有层就没有 $W$ 和 $B$ 可初始化。

    * 每个神经元的标准动作是先做加权求和、再过激活函数，而“选哪种初始化”本来就是和激活函数配套决定的（凯明配 ReLU、泽维尔配 sigmoid/tanh），所以得先有一个神经元、先有一层，才谈得上给它配方案。

    * 输入层不用管：它只负责拿着特征往里对接，本身没有激活函数，也不参与这里的讨论；建隐藏层或者输出层都行。

* **`nn.Linear` 的参数**

    * `nn.Linear(5, 3)` 的两个位置参数分别是 `in_features` 和 `out_features`。

    * 别把它抄成 `in_features: 5`——那个冒号是类型注解的写法，写成冒号会直接报错；要写就写等号 `in_features=5`，这两个参数本来由程序自动接收，正常不需要手写。

    * $5$ 和 $3$ 只是随手定的；每层有多少个神经元、总共几层都是自己定的，没有什么硬性规定，三层为什么不如两层、七个神经元为什么不如五个，这些全是测出来的。

### 打印与观察

* **`.data` 的作用**

    * `print(linear.weight)` 打出来的不只是数值，后面还挂着一句 `requires_grad=True`，意思是这块张量要自动计算梯度，也就是自动微分。

    * 加上 `.data` 就只打印数值本身：`print(linear.weight.data)`、`print(linear.bias.data)`。

* **每次运行结果不同**

    * 这一轮是 $0.22$、$0.91$，下一轮变成 $0.49$、$0.9$，再跑一次又成了 $0.7$、$0.04$，这正是随机初始化该有的样子——每次都会重新抽一遍。

    * 要在两个方案之间比数值差异，盯着几行数字是看不出名堂的；把这些值画成折线图，分布上的区别一眼就出来了。

* **判断标准**

    * 真正的判断标准只有一条：第一行和第二行的数是不是不一样，也就是第一个神经元和第二个神经元的权重是不是不同；不同，对称性就破了，这一层才有意义。

    * 别纠结“哪种看着更顺眼”：凯明的正态版和均匀版生成出来的数值差别还挺明显，但那是分布形状的差别，不是高下之分。

### 矩阵形状

* **为什么是 3 行 5 列**

    * 全连接层的定义是上一层的每个神经元都要和下一层的每个神经元建立连接，$5$ 个输入、$3$ 个神经元，于是排成 $3$ 行 $5$ 列，而不是 $5$ 行 $3$ 列。

    * 偏置不是一列数据，而是每行末尾的一个数，一共 $3$ 个。

* **行与列各是什么**

    * 横行是“神经元”，竖列是“输入”：第 $1$ 行就是第 $1$ 个神经元针对 $5$ 个输入的 $5$ 个权重，它要和这 $5$ 个输入分别相乘再求和，最后加上自己那一个偏置 $b_1$。

    * > **提示**：看权重矩阵要看行，不要看列；一行对应一个神经元的一整套参数，这正是“每个神经元都有自己的 $W$ 和 $B$”在代码里的样子。

    ```text
                 x1     x2     x3     x4     x5    |   b
              +------------------------------------+--------+
    输出 1    | w11    w12    w13    w14    w15    |  b1    |  ->  y1
    输出 2    | w21    w22    w23    w24    w25    |  b2    |  ->  y2
    输出 3    | w31    w32    w33    w34    w35    |  b3    |  ->  y3
              +------------------------------------+--------+
    ```

### 注释与复用

* **注释必须对齐代码**

    * 这些代码都是从上一个函数复制来的，函数名改了、里面的注释没跟上，就会出现“代码是全零、注释写着固定值”这种事；注释不能瞎写，得和代码死死对齐。

* **偏置不必单写**

    * `weight` 和 `bias` 的初始化套路完全一致，写两遍没有意义；以后真正用得最多的，其实就是 `nn.init.zeros_(linear.bias)` 这一行。
