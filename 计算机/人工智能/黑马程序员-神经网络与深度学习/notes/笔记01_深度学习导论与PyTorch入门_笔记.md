# 深度学习导论与PyTorch入门

## 人工智能与机器学习基础

### 三层概念关系

* **人工智能（Artificial Intelligence，AI）**

    * > **定义**：用计算机模拟人类，让机器像人那样理性地思考和行动，核心动作是「仿制」。

    * 机器学习与深度学习都是实现人工智能的途径，不是与 AI 并列的两套东西。

* **机器学习（Machine Learning，ML）**

    * > **定义**：给定大量数据，让算法从数据中找出公式与规律的方法。

    * 它是实现人工智能的一种途径；特征是人工设计、人工筛选。

* **深度学习（Deep Learning，DL）**

    * > **定义**：基于多层神经网络的机器学习方法，是机器学习的一个分支，也是神经网络的纵向技术延伸。

    * 「纵向」指往层数上叠：把隐藏层从一层变成多层，原理不变；因此深度学习通常直接叫多层神经网络。

* **关系与区别**

    * 关系是包含：机器学习包含深度学习，深度学习的范围更小。

    * 区别在特征工程由谁来做：人做是机器学习，算法做是深度学习。

    * > **易错点**：问「关系」答包含，问「区别」答特征工程由谁做；不要把包含说成并列，也不要把特征工程的归属说反。

### 机器学习的固定流程

* **六个步骤**

    * 加载数据 → 数据预处理 → 特征工程 → 模型训练 → 模型预测 → 模型评估。

    * 步骤固定，项目之间的差距集中在两件事：用什么字段、调什么参数。

    * 字段组合、框架（如 XGBoost）、调优方式（网格搜索加交叉验证）与参数都给定时，一个项目半小时就能跑完；时间主要耗在试特征和调参上。

* **特征工程**

    * 特征工程核心有五步，已经玩过其中两步：特征提取与特征预处理。

    * 归一化把值映射到 0 到 1：$x' = \dfrac{x - x_{\min}}{x_{\max} - x_{\min}}$；它只看最大值与最小值，容易被离群点把区间拉歪。

    * 标准化用该列的均值与标准差：$x' = \dfrac{x - \mu}{\sigma}$；它比归一化稳，深度学习中更常用，对应 `StandardScaler`。

* **三类任务与指标**

    * 机器学习日常做分类、回归、聚类；聚类多用在项目初期，公司通常已有成熟分群方案，KMeans 实际很少遇到，除非公司或整个行业从零开始做。

    * 分类出现最多、回归其次；分类指标要熟悉精确率、召回率、F1 值、AUC 值。

### 深度学习与机器学习的流程差异

* **流程对照**

    * 机器学习：输入 → 人工特征提取 → 分类/回归 → 输出。

    * 深度学习：输入 → 算法自动提取特征（隐藏层）→ 分类/回归 → 输出。

    * 两条流水线的输入输出一致，唯一被替换的是「特征提取」的执行者。

* **能力边界**

    * 机器学习擅长结构化表格，可解释性较强，很多环节能靠公式推导。

    * 深度学习擅长图像、语音这类高维数据，可解释性弱，隐藏层是黑盒子。

    * 机器学习在图像、文本上能力偏弱，弱在特征必须靠人挑，所以要分别用 CNN、RNN 做进阶。

| 对比项 | 机器学习 | 深度学习 |
| :--- | :--- | :--- |
| 特征工程 | 人工设计、人工筛选 | 算法自动提取 |
| 流程 | 加载、预处理、特征工程、训练、预测、评估 | 同样是加载、预处理、训练、预测、评估，特征由隐藏层生成 |
| 可解释性 | 较强，很多环节能靠公式推导 | 较弱，隐藏层是黑盒子 |
| 擅长数据 | 结构化表格 | 高维数据，如图像、语音 |
| 典型任务 | 分类、回归、聚类 | 图像分类、文本生成、语音分析 |

## 深度学习的技术版图

### 两条技术主线

* **卷积神经网络（Convolutional Neural Network，CNN）**

    * > **定义**：以卷积运算提取图像特征的神经网络，主要处理图像。

    * 层结构为输入层 → 卷积层 → 池化层（pooling）→ 全连接层 → 输出层，中间三段属于隐藏层。

    * 卷积层用卷积核（滤波器）在图像上滑动，得到一个特征图（feature map）；池化层负责降维；全连接层做最后的映射。

    * 它在图像分类、目标检测等任务上用得很广，解决的正是传统神经网络处理不了的复杂图像问题。

* **循环神经网络（Recurrent Neural Network，RNN）**

    * > **定义**：专门处理序列数据的深度学习模型，文本、语音、时间序列都算序列。

    * 层结构为词嵌入层 → 循环网络层 → 全连接层；词嵌入层把词映射成数值向量，是最难的一层。

    * 它在自然语言处理、语音合成上有优势，是处理动态数据的关键技术；后续变体有 LSTM、GRU。

* **人工神经网络（Artificial Neural Network，ANN）**

    * > **定义**：由输入层、隐藏层、输出层组成的全连接网络，是 CNN 与 RNN 共同的底座。

    * CNN 往上进阶是计算机视觉（Computer Vision，CV），RNN 往上对应自然语言处理（Natural Language Processing，NLP）。

### 课程骨架与数据约定

* **学习顺序**

    * 先张量，再人工神经网络，再卷积神经网络，最后循环神经网络。

    * 全连接层是 CNN 与 RNN 的汇合点，所以必须先单独学 ANN。

* **数据形状**

    * 图像用 HWC 描述：H 是高、W 是宽、C 是通道；`32×32×3` 表示高宽各 32 像素、RGB 三通道。

    * 层处理时吃 CHW：把 `32×32×3` 变成 `3×32×32`，即三张 32×32 的图分别对应 R、G、B；转换由张量函数完成。

* **课程定位**

    * AI 三要素是数据、算法、算力：数据是落地的地基，算法是训练模型的指导方法，算力是撑住训练与推理的计算资源。

    * 整套课程按基础能力、技术基建、核心工程、前沿扩展四块设计；神经网络与深度学习属于技术基建，给的是算法这一项。

## 神经网络发展史

### 人工智能的四个阶段

* **专家系统**

    * 听行业专家的判断，专家怎么说就怎么做。

    * 1962 年 IBM 的亚瑟·萨缪尔（Arthur Samuel）做的跳棋程序战胜人类高手，是这一阶段的标志。

    * 图灵测试是最早的人工智能设想：隔屋用键盘问答，判断对面是人还是机器，通过率 30% 以上即认为通过。

* **统计模型**

    * 用大量数据让算法把公式与规律找出来，不再依赖专家拍脑袋；这一阶段就是机器学习。

* **神经网络**

    * 2012 年 AlexNet 是深度学习开山之作；2016 年 AlphaGo 战胜李世石，让大众开始关注这件事。

    * AlphaGo 靠的是强化学习思路：找一条最短路径以拿最大奖励，加上计算机算力远超人类算步。

* **Transformer 与 AIGC**

    * Transformer 出来后直接导出 AIGC：A 是 AI，G 是 Generator（生成），C 是 Content（内容），合起来是 AI 生成内容。

    * 文生图、文生视频都属于 AIGC；DeepSeek、豆包这类问答产品，本质是 AIGC 的文本生成，是一个 QA 系统。

```text
专家系统（听专家的，1962 年跳棋程序战胜人类高手）
        │
        ▼
统计模型（机器学习：给大量数据，从数据里找规律）
        │
        ▼
神经网络（2012 年 AlexNet、2016 年 AlphaGo，靠算力起飞）
        │
        ▼
Transformer（自然语言处理，直接导出 AIGC：AI 生成内容）
```

### 神经网络的关键节点

* **神经元模型（1943）**

    * MP 模型模拟生物神经元：输入做加权求和，再与阈值比较，超过阈值就激活。

    * 加权求和加阈值激活这两个动作，后来一直没有变。

* **感知机（1958）**

    * 感知机是线性分类器，能画一条直线把两类样本分开。

    * 缺陷是参数不可训练、连接方式固定，只能处理线性可分问题，最典型的是分不开异或。

    * > **易错点**：最早期的感知机连接方式固定、参数不可训练，没有「学」的能力，只能解决线性可分问题；别把它和后面带反向传播的 BP 网络混为一谈，名字里都带「神经网络」，但一个是死的连接，一个是能调的权重。

* **反向传播（1986）**

    * BP（Back Propagation）让误差从输出层逐层回传到输入层，沿途调整权重。

    * 它解决多层前馈网络的训练问题，使网络能通过增加层数提升处理复杂任务的能力。

* **深度网络（2012 前后）**

    * CNN 用卷积提取图像特征，RNN 用循环结构处理序列数据。

    * 深度学习处理图像识别、语音识别这类任务的能力，从这一阶段开始铺开。

* **生成式大模型（2022）**

    * 生成式大模型登场，大模型时代正式开启。

| 阶段 | 年份 | 代表成果 | 关键点 |
| :--- | :--- | :--- | :--- |
| 神经元模型 | 1943 | MP 模型 | 模拟生物神经元：加权求和 + 阈值激活 |
| 感知机 | 1958 | 感知机学习算法 | 线性分类器；参数不可训练，处理不了异或 |
| 反向传播 | 1986 | BP 算法 | 误差反传、逐层调权，解决多层前馈网络训练 |
| 深度网络 | 2012 前后 | CNN、RNN | 卷积提取图像特征、循环处理序列数据 |
| 生成式大模型 | 2022 | 生成式大模型 | 大模型时代正式开启 |

### 演进主线与算力卡点

* **能力叠加主线**

    * MP 模型把神经元形式化，感知机把形式化神经元用于分类，BP 让多层结构可训练。

    * CNN 与 RNN 把特征提取交给网络自己完成，生成式大模型把能力推到通用生成。

    * 每一步都在前一步的表达能力上再叠一层，不是推翻重来。

* **BP 的算力卡点**

    * 1986 年 BP 发表后没有立刻流行，卡点是算力：当时算力不够，对图像、语音这类复杂数据的处理能力也弱。

    * 人工智能等于数据加算法加算力；零几年算力上来，深度学习开始复兴。

    * 2012 年 AlexNet 在 ImageNet 图像识别挑战赛上取得巨大成功，CNN 随之走红，一直延伸到今天的 CV。

* **后续推动**

    * 一几年 NLP 起来，推动 AIGC；它主要处理序列数据，给一个字就能围绕它往下生成。

    * 规律是如果没有算力卡着，AI 的发展会提前很多年。

## 从生物神经元到人工神经元

### 生物神经元的结构

* **四个部件**

    * 细胞体负责处理信号，树突负责接收信号。

    * 轴突把信号输出到下一个神经元，突触是神经元之间的连接点。

    * 四件部件合在一起，神经网络才具备分布式存储与高效处理的能力。

* **信号传递**

    * 树突接收其他神经元的信号，细胞体处理，轴突输出，突触把信号交给下一个神经元。

    * 传递靠电信号；输入信号超过阈值，神经元被激活，人做出反应。

```text
生物神经元                      人工神经元
-----------                     -------------
树突（接收信号）       ───►     输入 x0, x1, ...
细胞体（处理信号）     ───►     加权求和 Σ(wi·xi) + bias
轴突（输出信号）       ───►     激活函数 f 处理
突触（连接下一个）     ───►     输出传给下一层
```

### 人工神经元的抽象

* **四个动作的对应**

    * 树突接收对应输入 $x_0, x_1, \dots$。

    * 细胞体处理对应加权求和 $\sum w_i x_i + b$，其中 $b$ 是偏置（bias）。

    * 轴突输出对应激活函数 $f$ 处理，突触连接对应输出传给下一层。

    * 生物网络处理完做出反应，对应人工网络经过 $f$ 得到最终结果；这个 $f$ 就是激活函数。

* **一个神经元只做两件事**

    * 第一件是加权求和：输入各自乘权重再相加，再加偏置 $b$。

    * 第二件是激活函数：把加权求和的结果映射成一个概率，整个动作与逻辑回归很像。

* **激活函数不可省略**

    * 没有激活函数，整个网络只剩加权求和；一层层叠加仍然是一堆线性运算，只能处理线性问题。

    * 加了激活函数才有概率，神经元才能做分类；因此深度学习既能做分类，也能做回归。

    * > **易错点**：「多层非线性变换」里的非线性不是指层与层之间的连接方式，而是每层后面那道激活函数；「多层」才对应层数。

```text
x0 ──× w0 ──┐
x1 ──× w1 ──┼──► 加权求和 Σ(wi·xi) + b ──► 激活函数 f ──► 输出
x2 ──× w2 ──┘
```

## 人工神经网络的结构

### 三层结构与深度

* **三种层**

    * 输入层只有一层，输出层只有一层；隐藏层可以有 N 层，也可以一层都没有。

    * 网络有多「深」，看的就是隐藏层的层数，不是神经元的个数。

* **输入层的神经元数**

    * 输入层神经元个数等于特征数：一行样本有几列，输入层就有几个神经元。

    * 工资预测的例子：年龄、学历、工作年限、考试成绩四项特征，输入层就是四个神经元。

* **层的判定**

    * 一列叫一层，一层里可以有多个神经元；纵向叠几个层就是几层。

    * > **易错点**：画了三个神经元不代表三层。三个圈并排是同一层里的三个节点；三层是三个纵向的层，每层哪怕只有一个神经元也算三层，但每层只放一个属于有瑕疵的搭法，正常每层至少两个神经元。

```text
输入层        隐藏层 1     隐藏层 2     隐藏层 3       输出层
  ○ ────────►  ○ ────────►  ○ ────────►  ○ ────────►  ○
  ○ ────────►  ○ ────────►  ○ ────────►  ○ ────────►  ○
  ○ ────────►  ○ ────────►  ○ ────────►  ○ ────────►  ○
  ○ ────────►  ○ ────────►  ○ ────────►  ○ ────────►  ○
（神经元个数=特征数）  ←──── 深度 = 隐藏层的层数 ────→
```

### 全连接层

* **定义与写法**

    * > **定义**：本层每一个神经元都与上一层的全部神经元相连，这种层叫全连接层（fully connected layer，FC）。

    * 代码里通常用 `Linear` 表示，也有人写 `FC`；`Linear` 用得多一些。

* **特征抽取效果**

    * 上一层 4 个特征，本层写 100 个神经元，算法就从这 4 个特征里抽出 100 个特征；写 1000 个就抽 1000 个，写多少抽多少。

    * 抽取方式不可知，抽取了谁也不可知，看到的全部是数值。

* **深层的作用**

    * 一般规律是越深表达能力越强；但具体几层、每层几个神经元要看需求，没有公式可以算。

## 前向传播与反向传播

### 正向传播

* **定义**

    * 数据（特征）从输入层进入，逐层向前传递：输入层 → 隐藏层 → 输出层，这个从左往右的过程叫正向传播。

    * 正向传播一路算到预测值，拿到结果后才能计算损失。

* **加权求和的本质**

    * 一个神经元要跟前一层每个神经元做加权求和，加权求和本质上就是多元线性回归：$y = w^{T}X + b$。

    * 写成 $wx + b$、$kx + b$ 都可以，转置符号只是形式。

### 反向传播

* **定义**

    * 训练时误差从输出层往回传，一层一层传到输入层，沿途调整权重，这个过程叫反向传播（Back Propagation，BP）。

    * 方向与正向传播相反：先算损失，再自后向前逐层回传，更新每一层的 $w$ 和 $b$。

* **迭代闭环**

    * 正向传播得到预测值 → 与真实值比较算出损失 → 损失自动求导得到梯度 → 反向传播拿梯度更新权重。

    * 更新完再做一次正向传播，再算损失、再更新；一轮一轮下去，参数越来越接近正确值，拟合效果越来越好。

* **感知机为什么需要 BP**

    * 感知机只能正向传播，不能从后向前算，不能更新参数，所以拟合情况非常差。

    * 反向传播解决的正是「参数怎么调」这件事；这个阶段最难的地方是反向传播，其次是词嵌入层。

```text
正向传播：特征 x ──▶ 输入层 ──▶ 隐藏层 ──▶ 输出层 ──▶ 预测值

反向传播：预测值 ──▶ 算损失 ──▶ 自后向前逐层回传 ──▶ 更新每层的 w 和 b
```

### 参数量估算

* **单个神经元**

    * 前层 5 个神经元，本神经元需要 5 个 $w$ 加 1 个 $b$，共 6 个参数；前层 6 个就是 7 个。

    * 口诀：前层每个神经元对应一个 $w$，本神经元自己再加一个 $b$。

* **整层与整网**

    * 一层里有几个这样的神经元，就把单神经元的参数量再乘几。

    * B 是十亿：1B 是 10 亿个参数，1.5B 是 15 亿，7B 是 70 亿。

    * 这些数字就是一层一层、一个神经元一个神经元加出来的。

### BP 网络与深度学习的边界

* **BP 网络**

    * BP 网络有一个隐藏层，也可以叫「具备一层隐藏层的神经网络结构」。

    * 它解决多层前馈网络的训练问题，使网络能处理非线性映射任务。

* **深度学习**

    * 深度学习在 BP 网络基础上继续增加隐藏层，同时提升计算能力；那些 $H_1, H_2, \dots, H_n$ 就代表一层层隐藏层。

    * 两者的区别不在有没有反向传播，而在隐藏层到底有几层。

## 深度学习的特点

### 多层非线性变换

* **深与层数**

    * 深度学习的「深」指层数多：输入层之后一层层隐藏层叠上去，最后到输出层。

    * 每一层里有一批神经元，每个神经元固定做两步：先加权求和，再把结果送进激活函数。

* **非线性为什么必要**

    * 如果每层只做加权求和，几层叠起来仍是线性变换：$W_2(W_1x) = (W_2W_1)x$，两层等价于一层，叠二十层也还是一层。

    * 真正让「深」有意义的是每层后面那道激活函数：它把线性输出掰弯，网络才有能力拟合复杂边界。

* **分类与回归的统一**

    * 激活函数把输出解释成「属于某一类的概率」，同一个框架既能做回归，也能做分类。

### 自动提取特征

* **执行者换了**

    * 机器学习阶段是人看数据、想业务、挑特征、试组合，一轮一轮筛。

    * 深度学习阶段特征由算法自己从原始数据里提取，喂进去的是像素、文本或数值，网络在训练中把有用的组合找出来。

* **靠连接方式实现**

    * 每个神经元都和前一层的所有神经元相连，这就是「全连接」这个名字的由来。

    * 全连接不是形容词，说的是连接关系上的全连接。

### 大数据与计算能力

* **两个前提**

    * 深度网络通常需要大量标注数据，还需要强大的计算资源；条件不成立，深度网络就转不起来。

    * 这一条与算法本身的性质关系没那么紧，更多是硬件和数据层面的条件。

* **CPU 与 GPU**

    * CPU 一般 8 核 16 线程或 16 核 24 线程，核数就这些；GPU 的核数能到几百甚至上千。

    * 深度网络里大量运算是同构的矩阵运算，正好吃「核多」的结构，所以训练要往显卡上放。

    * > **提示**：GPU 的核与 CPU 的核不是同一把尺子。CPU 的核是能独立执行复杂指令的通用核心，GPU 的核是大量结构简单、专做并行算术的单元；核数不能直接比大小，但「并行度远高于 CPU」成立。

* **代码里的开关**

    * `device='cuda'` 把任务放到 GPU 上跑，`device='cpu'` 在 CPU 上跑；前提是驱动装好、环境配好。

    * 目前大多数练习还在 CPU 上做，后面会专门讲怎么把任务搬到 GPU。

* **算力成本**

    * 一块 A100 级别显卡报价十万到十五万，显存 80G 的版本能到二十万；H100 性能更强，价格更高。

    * 十几块卡插上去，光显卡就是两百多万，还没算整机、电费和机房。

### 可解释性差

* **黑箱的成因**

    * 模型内部怎么运作相对不透明：一层层神经元里谁激活了谁、哪个权重起决定作用，只能看到输入和最终输出，中间过程看不到。

    * 根源在于特征由算法自己提取，提取过程没有解析公式可循，只能靠实验和训练结果说话。

* **调参只能靠试**

    * 为什么三层不如五层、为什么第一层神经元调一调拟合效果就好很多，这些都没有公式，只能测出来。

    * 拿 K-means 对照：K 取几个还能靠 SSE 加肘部法看拐点，深度学习连这种「看拐点」的抓手都少，基本只能凭经验找。

* **经验规则**

    * 设计网络时越靠前的浅层神经元要多一些，往后逐层递减；大多数情况下前边多、后边少。

    * 这是开发经验，不是定理。

* **四特点对应四问**

    * 多层非线性变换回答「网络长什么样」，自动提取特征回答「特征从哪来」。

    * 大数据和计算能力回答「跑起来靠什么」，可解释性差回答「代价是什么」。

| 特点 | 回答的问题 |
| :--- | :--- |
| 多层非线性变换 | 网络长什么样——隐藏层多层堆叠，每层加权求和后再过非线性激活 |
| 自动提取特征 | 特征从哪来——算法自己学，神经元与前一层全连接 |
| 大数据和计算能力 | 跑起来靠什么——大量标注数据和 GPU 算力 |
| 可解释性差 | 代价是什么——中间层是封装的黑箱，只能靠实验试，难以用公式推导 |

## 常见深度学习模型

### 差异都在隐藏层

* **共同结构**

    * 各种网络摆在一起，输入层和输出层长得都差不多，真正不一样的是隐藏层。

    * 卷积网络用卷积和池化，循环网络用循环结构；不同网络的区别主要发生在这段里。

* **CNN 的层序**

    * 输入层 → 卷积层 → 池化层 → 全连接层 → 输出层；卷积层、池化层、全连接层都属于隐藏层。

    * 卷积层提取局部特征，池化层降维，全连接层做最后的映射。

* **RNN 的层序**

    * 词嵌入层 → 循环网络层 → 全连接层；循环结构把前面的信息带到后面。

    * RNN 主要处理文本，也能处理语音；语音要先转成频谱图再变成数值。

### 各模型的能力

* **卷积神经网络**

    * 主要做图像分类、目标检测、图像分割。

    * 目标检测用于无人驾驶、自动泊车；把非目标认成目标是这类任务没做好的典型表现。

* **循环神经网络**

    * 主要做文本处理，也能做语音；是处理动态数据的关键技术。

* **自编码器**

    * 属于无监督这一路，任务是降维。

* **生成对抗网络（Generative Adversarial Network，GAN）**

    * 主要做图像生成和视频合成；早些年用得多，现在相对少一些。

* **Transformer**

    * 主要做自然语言处理：机器翻译、文本生成这一类。

    * 它与循环网络最大的不同是摒弃传统递归，改用自注意力机制。

    * 底层分编码器、解码器、输入层三块；现在大多数大模型都围绕编码与解码这两层在做。

| 模型 | 主要处理 | 典型任务 |
| :--- | :--- | :--- |
| 卷积神经网络（CNN） | 图像 | 图像分类、目标检测、图像分割 |
| 循环神经网络（RNN） | 文本、语音 | 文本处理；语音先转频谱图再处理 |
| 自编码器 | 无监督 | 降维 |
| 生成对抗网络（GAN） | 图像、视频 | 图像生成、视频合成 |
| Transformer | 自然语言 | 机器翻译、文本生成，核心是自注意力机制 |

### 名称与计算图辨析

* **Transformer 不是 TensorFlow**

    * > **易错点**：TensorFlow 是计算框架，解决「用什么工具搭模型」；Transformer 是模型架构，解决「把模型搭成什么样」。两者不在一个层面上，名字接近纯属巧合。

    * 后续 NLP 阶段重点讲 Transformer，TensorFlow 不作为课程内容。

* **静态图与动态图**

    * TensorFlow 1.x 生成静态图：执行流程构建完，训练结束之前中间不能改。

    * PyTorch 生成动态图：可以边生成边修改；调试时想插打印、想改一层结构，动态图随手就改，静态图得从头再来。

## 应用场景

### 计算机视觉

* **四类主干任务**

    * 图像分类，例如人脸识别、物体检测。

    * 目标检测，例如自动驾驶里的行人检测。

    * 面部识别与图像生成；老照片修复、灰度上色、让人物动起来都属于图像生成。

* **精度来自像素级特征**

    * 程序基于局部像素点提特征；人眼分不出的双胞胎，在像素层面的细微差异其实很大，所以人脸识别能区分。

### 自然语言处理

* **序列数据**

    * > **定义**：后边的数据对前面的数据有依赖，顺序变了含义就变了，前面的内容会成为理解后面内容的上下文。

    * 文本是典型序列数据：「我爱你」与「你爱我」三个字完全相同，顺序一换，一个是表白一个是被表白。

* **上下文决定理解**

    * 同一句「在公司」，前面说的是去广州出差，听者想到广州的校区；前面说的是在北京上课，听者想到北京的办公楼。

    * 机器翻译难在要理解语义：「我去我不去」加语气能听出去还是不去，打成文字就是六个字。

    * 「小明骑车一把把把把住了」这句话，光一个「把」字就足够让翻译崩溃。

* **两类常见任务**

    * 情感分析：基于评论预测好评还是差评，社交媒体监控、产品评论分析都是这个路子。

    * 星级可以刷，文本内容才藏着真实态度。

    * 文本生成：AI 写作、新闻生成；给一个主题让它写多少字的小说，就是这一类。

* **传统特征工程的样本**

    * 电力负荷预测的原始数据只有时间、负荷两列；从时间里拆出小时 24 个、月份 12 个、前 1/2/3 小时 3 个、昨天同一时刻 1 个，合计 40 个字段。

    * 传统做法靠可视化看特征分布差异，差异大的拿来当训练字段。

    * 深度学习里基本见不到 `Series`、`DataFrame` 这套，值直接进网络；但字段怎么拆的设计思路要留在脑子里。

* **序列依赖的直觉**

    * 明天的股票价格与今天直接相关，与昨天也相关但弱一些，越往前权重越低。

    * 这个「越往前权重越低」的直觉，后面讲动量法（Momentum）时还会用到。

### 推荐系统

* **推荐依据**

    * 推荐系统基于用户历史的评分和行为，推荐相似的电影。

    * 过去点过什么、评过什么、看过什么都是输入，模型据此决定下一条推什么。

* **产品形态**

    * 产品里的「猜你喜欢」就是这一类推荐。

### 多模态大模型

* **一个模型接所有任务**

    * 以前的模型大概率只处理一种东西：有的专门处理文本，有的专门处理视频，有的专门处理音频。

    * 多模态大模型要把所有任务接过来，用一个模型就够。

    * 通义千问做通用文本、通义法睿做法律、通义点金做金融股票，就是过去按垂直领域分家的样子；通义点金目前还是半成品，没有实际落地。

* **Agent**

    * 多模态大模型里的核心词是 Agent（智能体）；一个模型底下可以挂各种智能体，不同智能体有不同侧重点，各管一摊。

* **四方向结论**

    * 计算机视觉、自然语言处理、推荐系统、多模态大模型；前三个跑了很多年，第四个正在起势。

## 张量

### 定义与维度

* **张量（tensor）**

    * > **定义**：张量是多维数组的统一称呼；0 维是标量，1 维是向量，2 维是矩阵，3 维及以上统称高阶张量。

    * 标量是只有大小没有方向的单值，如 `a = 10`；向量可以理解成一列数；矩阵是二维的表。

    * 到了深度学习里这些统统叫张量，只是维数不同，不用再纠结「这是标量还是向量」，看维度就行。

* **高维数据的常见维数**

    * 图像是三维：高、宽、通道，HWC 三个轴。

    * 文本一般用二维更多一些。

    * 语音基本也是多维高维数据，通过频谱图技术转成数值。

### 数值约束

* **只能放数值**

    * 张量中只能是数值；布尔值会被当成 1 和 0 处理，字符串会直接报错。

    * 底层「抽特征」抽来抽去都是从一堆数字里按公式凑数字，原料只有数字。

* **浮点要求**

    * 后面搭各种层时，张量的数值要设成浮点型；整型也处理不了，`float` 是硬要求。

    * > **易错点**：「只能数值」不是建议是硬约束；文本、类别这些非数值的东西，必须先转成数字（比如词表里的序号）才能进张量。

### 形状变换

* **常用函数**

    * `reshape` 重构形状，`transpose` 转置，`permute` 换轴顺序。

    * `view` 按内存连续的方式重塑，`squeeze` / `unsqueeze` 删掉或增加长度为 1 的维度。

    * `is_contiguous` 判断内存是否连续。

* **HWC 转 CHW**

    * 图像是 HWC，网络要 CHW；`32×32×3` 要变成 `3×32×32`，即三张 32×32 的图分别对应 R、G、B。

    * 这一堆 API 不用一次全记牢，先分清哪些优先掌握、哪些会用就行、哪些了解即可。

### 降维的两种含义

* **池化层的降维**

    * 池化是在高、宽两个方向上压缩，减少特征图的空间尺寸。

* **喂给全连接层前的降维**

    * ANN 只能处理二维数据；把 CNN、RNN 的多维输出喂给全连接层之前，要把多维数据摊平成二维，好让 `Linear` 层接得住。

    * > **提示**：两种降维名字一样，作用的位置不同；池化发生在特征图内部，摊平发生在进入全连接层之前。

## PyTorch 框架

### 定位与核心能力

* **是什么**

    * > **定义**：PyTorch 是基于 Python 语言的深度学习框架，核心动作是把数据封装成张量。

    * 它提供灵活且高效的工具，用来构建、训练、部署机器学习和深度学习模型。

    * 它广泛用于学术研究和工业界，在计算机视觉、自然语言处理、强化学习上用得较多。

* **nn 模块**

    * 神经网络英文是 neural network，简称 nn；要玩的很多模型、很多损失函数，就是 `nn.` 一路点出来。

    * `nn.Linear(3, 5)` 表示上层有 3 个神经元、这一层有 5 个神经元，一行就把这层网络搭好。

* **为什么要练熟张量函数**

    * 无论 ANN、CNN 还是 RNN，底层处理数据都用张量；张量函数不熟，后面写案例会很痛苦。

    * 后续案例平均代码约 200 行：线性回归七八十行，ANN 约 150 行，CNN 约 180 行（含注释），RNN 约 220 行。

### 自动微分

* **本质是求导**

    * > **定义**：自动微分就是自动求导；它本身只是算导数的工具，真正让它有意义的是与反向传播配合，把梯度落到参数上。

    * 给 $y = 2x^2$，$x = 10$ 代入得 $2 \times 100 = 200$；对 $x$ 求导得 $4x$，$x = 10$ 时代入等于 40。

* **梯度更新**

    * 更新公式 $w_{\text{新}} = w_{\text{旧}} - \alpha \cdot \nabla_W L$，其中 $\alpha$ 是学习率。

    * $\nabla_W L$ 是损失函数对权重的梯度，也就是损失函数的求导。

    * 初始权重 10、梯度 40、学习率 0.01 时，$w_{\text{新}} = 10 - 0.01 \times 40 = 9.6$，权重往下走了一步。

    * 正常学习率在 $10^{-3}$ 到 $10^{-4}$ 之间，即 0.001 到 0.0001；学习率越大迭代次数越少、更新越快，越小更新越慢。

* **训练闭环**

    * 正向传播拿预测值，与真实值比较算出损失；损失函数自动求导得到梯度，反向传播拿梯度更新权重。

    * 更新完再正向传播，进入下一轮；这样转很多轮，模型的拟合情况就会好很多。

```text
正向传播 ──▶ 预测值 ──▶ 与真实值比较，算出损失
   ▲                          │
   │                          ▼
更新参数 ◀── 反向传播 ◀── 自动求导（梯度）
```

### 动态图、GPU 与跨平台

* **动态计算图**

    * 动态意味着可以边计算边生成，而不像 TensorFlow 那样图生成以后就只能那个样子。

    * 调试时想插一句打印、想改一层结构，动态图随手就改，静态图得从头再来。

* **GPU 加速**

    * PyTorch 可以切到 GPU 上跑，比如 CUDA；参数是 `device='cuda'`。

* **多场景与跨平台**

    * 图像、文本、音频、视频这些场景都能做。

    * Windows、Mac、Linux 三个平台都支持。

### 安装与环境

* **安装命令**

    * 默认源直接执行 `pip install torch`。

    * 网速慢时在 `pip install` 后面加 `-i <国内镜像源地址>`，挂一个国内镜像源。

* **三种安装方式**

    * 找到 Anaconda 程序组，右键「更多」，以管理员身份运行，在里面执行 `pip install torch`。

    * 打开 PyCharm 左侧 Terminal；如果报 failed 之类，点双箭头选 Command（新开一个 session），它默认进入当前工程目录，在这里执行安装。

    * File → Settings → Project → PyCharm Interpreter，点加号搜 torch 然后 Install；这条路联网搜包，网速不好可能搜不出来，搜不出来跟关键词无关，就是网速。

* **沙箱的坑**

    * `conda env list` 能看装了哪些沙箱。

    * 如果当前不在 base 下，`pip install torch` 会把包装进当前沙箱；换到 base 用时就找不到。

    * 有多个沙箱时先 `conda activate myenv1` 切过去；更省事的做法是把其他沙箱全删掉，只留 base。

```bash
pip install torch                    # 默认源
pip install torch -i <国内镜像源地址>   # 网速慢时挂国内镜像源
```

## 深度学习框架演进

### 从 Torch 到 PyTorch

* **Torch**

    * 底层是 C 和 C++，高校用得多；教材迭代需要时间，所以高校里留存较多。

    * 特点是 API 复杂、无 GPU 支持、手动实现网络；搭网络要自己关联谁和谁连，算得也慢。

* **Theano**

    * 在 Torch 之后把 API 变简单，并开始支持多 GPU。

* **MXNet 与 TensorFlow**

    * MXNet 是亚马逊的，属于一几年那一代，与 TensorFlow、PyTorch 同期。

    * TensorFlow 是谷歌的，1.x 用静态图、API 复杂；正常来讲本来应该是 TensorFlow 的天下。

* **PyTorch**

    * 2016 年 Facebook 正式发布，Facebook 现改名 Meta。

    * 特点是动态图、API 简单、生态友好；它站在巨人肩膀上开始建，但没有直接争市场，而是从高校打起。

| 框架 | 归属 | 特点 |
| :--- | :--- | :--- |
| Torch | — | C/C++ 底层，高校用得多，API 复杂，无 GPU 支持，手动实现网络 |
| Theano | — | API 变简单，开始支持多 GPU |
| MXNet | 亚马逊 | 一几年那一代，与 TensorFlow、PyTorch 同期 |
| TensorFlow | 谷歌 | 1.x 静态图、API 复杂；2.x 集成 Keras、支持动态图 |
| PyTorch | Facebook（现 Meta） | 2016 年发布，动态图、API 简单，生态友好 |

### TensorFlow 的两个弊端与补救

* **两个弊端**

    * 第一是静态图：计划定死就得这么做，中间不能改。

    * 第二是 API 太复杂：用起来麻烦，学习与改动成本都高。

* **高校策略**

    * PyTorch 跟知名高校合作；学生在学校学的是 API 简单、支持动态图的新东西。

    * 毕业进企业后发现公司框架老套，就会推动公司更新迭代；等工作一两年成了骨干，话语权更重，推动力更强。

    * 就这样一步一步蚕食 TensorFlow 的市场，慢慢做大。

* **TensorFlow 2.x 的补救**

    * 2.x 把 API 变简单，集成了 Keras，并从 2.x 开始支持动态图；1.x 不支持动态图。

    * 但市场上已经有框架能做的事，大多数公司会选第一个；补救之后买账率和认可度也没那么高。

* **当下的格局**

    * TensorFlow 还有公司在用，但不多；很多公司正慢慢往 PyTorch 切。

    * 昇思、百度飞桨（PP-飞桨）也在同一生态里，但真正天天在底下当主力的还是 PyTorch。

### 两框架对比

* **计算图**

    * PyTorch 用动态图，可以边生成边修改；TensorFlow 1.x 用静态图，构建后训练结束前不能改。

    * TensorFlow 2.x 开始支持动态图，但市场认可度已经被 PyTorch 抢先建立。

* **API 与调试**

    * PyTorch 的 API 简单直接；TensorFlow 的 API 复杂繁琐。

    * 调试时想插一句打印、想改一层结构，动态图随手就改，静态图得从头再来。

| 对比项 | PyTorch | TensorFlow |
| :--- | :--- | :--- |
| 计算图 | 动态图，边生成边改 | 静态图，构建后训练结束前不能改 |
| API 风格 | 简单直接 | 复杂繁琐 |
| 调试体验 | 灵活，随时可改 | 改动成本高 |
| 企业使用 | 目前居多 | 仍有，但占比下降 |

    * 目标是让网络看着图片把它分到十类里的某一类。

### 歌词生成案例

* **数据与词表**

    * 周杰伦歌词一共 5819 条；jieba 切词后去重，得到 5703 个词。

    * 5703 个词生成序号，把词映射成对应的数值（词向量），再拿来做预测。

* **生成方式**

    * 给一个种子词和一个长度，比如「星星」加 50，就围绕「星星」生成 50 个词，凑成一段歌词。

    * 换成「分手」「太阳」也可以；种子词必须在 5703 个词里，词表里没有的词（比如「AI」）做不到。

    * 本质是 AIGC：输入种子和长度，模型一个词一个词往外写。

```text
5819 条歌词
    │  jieba 切词
    ▼
分词结果 ──► 去重 ──► 5703 个词
                         │
                         ▼
                  词 → 序号 → 向量（词嵌入层）
                         │
种子词 + 生成长度 ──► 循环网络逐词预测 ──► 全连接层 ──► 下一个词
```

### 学习路线与产出

* **四块路线**

    * 深度学习框架 PyTorch → 深度学习基础（BP 神经网络、激活函数、损失函数）→ 卷积神经网络 → 循环神经网络，最后用案例实战演练。

    * 时间安排：PyTorch 约两天，ANN 两天多，CNN 一天多，RNN 压轴。

* **四个亮点**

    * 从会用到懂原理；CNN 和 RNN 双模态覆盖。

    * 打牢人工神经网络基础；项目案例贯穿全程。

* **案例分档**

    * 入门级是 Python 实现线性回归、逻辑回归，练手的同时理解算法的使用场景。

    * 进阶级是 CNN 图像分类和 RNN 文本生成。

* **学完的收获**

    * 掌握神经网络基础知识，比如激活函数、梯度下降；掌握 PyTorch，能构建神经网络结构。

    * 掌握卷积神经网络，能用 PyTorch 搭 CNN 做图像识别；掌握循环神经网络，能用 PyTorch 搭 RNN 做文本生成。

* **前置地基**

    * 没有 Python 基础先学第一套；有基本语法但面向对象、生成器、数据结构与算法不熟先学第二套。

    * 没有数据分析基础先学第三套（Linux、MySQL、numpy、pandas）；有数据分析基础但数据挖掘不熟先学第四套（分类、回归、聚类）。
