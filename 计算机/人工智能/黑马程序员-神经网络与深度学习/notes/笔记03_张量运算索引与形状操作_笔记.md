# 张量运算、索引与形状操作

## 基本运算与两种乘法

### 逐元素基本运算

* **四则运算与取反（add / sub / mul / div / neg）**

    * `add` 是加法、`subtract`（`sub`）是减法、`multiply`（`mul`）是乘法、`divide`（`div`）是除法、`neg` 取相反数，全部逐元素执行。

    * 每个函数都有带下划线与不带下划线两版：`add` 返回新张量，`add_` 直接修改原张量；要保留原数据用前者，确定不再需要原数据再用后者。

    * 张量与标量运算时，标量逐个作用于张量的每个元素：`T1 + 10` 是每个元素都加 10，不是只加第一个。

* **点乘（element-wise multiplication）**

    * > **定义**：两个张量对应位置的元素一对一相乘，结果形状与原张量相同。

    * 条件：两个张量的形状必须完全一致，行数与列数都要对上，差一个维度就做不了。

    * 写法：`t1 * t2` 或 `t1.mul(t2)`，两者等价。

    * 例：两行三列 `[[1,2,3],[4,5,6]]` 与自身点乘，得 `[[1,4,9],[16,25,36]]`。

    * 形状不一致的报错按维度定位：`(2,3)` 与 `(3,3)` 在 `dimension 0` 报 `The size of tensor a (2) must match the size of tensor b (3)`；`(2,3)` 与 `(2,4)` 在 `dimension 1` 报 `a (3) must match b (4)`。

    * > **易错点**：`*` 在张量里是逐元素相乘，不是矩阵乘法；矩阵乘法要换成 `@`，两者不通用。

### 矩阵乘法与点积

* **矩阵乘法（matrix multiplication）**

    * > **定义**：左矩阵 A 的列数等于右矩阵 B 的行数时才能相乘；结果的行数等于 A 的行数，列数等于 B 的列数。

    * 判据记「前列后行」：前一个的列数对上后一个的行数，光看形状就能判断能否相乘。

    * 高维张量看最后两个维度是否满足「前列等于后行」，实际使用以二维矩阵为主。

    * 计算规则：结果第 i 行第 j 列等于 A 的第 i 行与 B 的第 j 列对应相乘再求和。

    * 例：`A = [[1,2,3],[4,5,6]]`、`B = [[1,2],[3,4],[5,6]]`，结果为 `[[22,28],[49,64]]`；左上角 `1×1 + 2×3 + 3×5 = 22`，右下角 `4×2 + 5×4 + 6×6 = 64`。

    * 写法：`t1 @ t2` 或 `t1.matmul(t2)`；`mat` 是 matrix，`mul` 是 multiply，拼起来就是矩阵乘法。

* **一维点积（dot）**

    * `dot` 只接受一维张量，两个二维张量用 `dot` 会报 `1D tensors expected, but got 2D and 2D tensors`。

    * 两个一维张量 `[1,2,3]` 与 `[4,5,6]` 做 `dot` 得标量 `32`，即 `1×4 + 2×5 + 3×6`。

    * 这里的 D 指 dim（维度），一维写作 `1D`。

* **两种乘法的对比**

    * 运算符、形状要求、结果形状与另一写法见下表。

    * > **易错点**：同一对张量在形状凑巧合适时，`*` 与 `@` 都能跑，但结果完全不同；这种不报错的差异最难查。

| 对比项 | 点乘 | 矩阵乘法 |
| :--- | :--- | :--- |
| 运算符 | `*` | `@` |
| 形状要求 | 两个张量形状完全一致 | 左矩阵列数 = 右矩阵行数 |
| 结果形状 | 与原张量相同 | A 的行数 × B 的列数 |
| 另一写法 | `mul()` | `matmul()`；一维可用 `dot()` |
| 一句话记法 | 对应元素相乘 | 前列后行 |

## 常用运算函数

### dim 的方向口径

* **维度方向（dim）**

    * > **定义**：`dim` 指定运算沿哪一轴进行，决定按行还是按列合并。

    * `dim=0` 按列：竖着跨过多行，把同一列的元素并成一个，结果长度等于列数。

    * `dim=1` 按行：横着扫过一行，把同一行的元素并成一个，结果长度等于行数。

    * 两行三列 `[[1,2,3],[4,5,6]]`：`sum(dim=0)` 得 `[5,7,9]`，`sum(dim=1)` 得 `[6,15]`。

    * > **易错点**：`dim=0` 对应的是列，`dim=1` 对应的是行，与「0 是第一个维度、第一个维度是行」的直觉相反，要按列记。

    ```text
    dim=0：竖着跨行合并          dim=1：横着跨列合并
      1  2  3                      1 + 2 + 3  →   6
      +  +  +                      4 + 5 + 6  →  15
      4  5  6
      ↓  ↓  ↓                      结果 [6, 15]
      5  7  9
    结果 [5, 7, 9]
    ```

* **不写 dim 的整体口径**

    * 不写 `dim` 时，函数把张量所有元素当成一个整体处理：`sum()` 得 `21`，`max()` 得 `6`。

    * 整体求和可以用两个行和相加验证：`6 + 15 = 21`。

### 聚合函数

* **求和（sum）**

    * 支持 `dim`：`dim=0` 按列得 `[5,7,9]`，`dim=1` 按行得 `[6,15]`，不写 `dim` 得标量 `21`。

* **最大值（max）**

    * 带 `dim` 时同时返回两路结果：`values` 是最大值，`indices` 是最大值所在位置；看 `values` 就够。

    * `dim=0` 得 `values=[4,5,6]`、`indices=[1,1,1]`；`dim=1` 得 `values=[3,6]`、`indices=[2,2]`；不写 `dim` 得 `6`。

* **最小值（min）**

    * 取最小值，支持 `dim`；日常使用频率低于 `max`。

* **平均值（mean）**

    * 只接受浮点型或复数型输入；整型 `Long` 直接报 `mean(): could not infer output dtype`，因为整型装不下小数。

    * 转类型：定义时写 `dtype=torch.float`；`float` 默认就是 `float32`，不必写全。

    * 两行三列浮点张量：`mean(dim=0)` 得 `[2.5000,3.5000,4.5000]`，`mean(dim=1)` 得 `[2.,5.]`，`mean()` 得 `3.5000`。

    * > **提示**：神经网络底层全是浮点张量，`mean` 拒收整型正好暴露了这个前提；遇到就转类型。

### 逐元素数学函数

* **N 次幂（pow）**

    * `t1.pow(2)` 对每个元素求平方；`t1 ** 3` 求立方，`**` 后写几就是几次方。

    * `**` 能完全替代 `pow`，函数名不必单独记。

* **平方根（sqrt）**

    * 只开平方根，签名里只有 `self`，没有传递「开几次方」的参数。

    * > **易错点**：`sqrt` 开不了三次方，需要任意次方根时它做不到。

* **自然指数（exp）**

    * 计算 e 的 n 次幂，n 是张量里的每个元素；e 约等于 2.7183，元素为 1 时结果是 2.7183。

* **对数族（log / log2 / log10）**

    * `log` 以 e 为底，`log2` 以 2 为底，`log10` 以 10 为底，三者都只接 `self`。

    * `log2(8) = 3`，即 2 的 3 次方等于 8；看到「以 2 为底八的对数」，翻成「2 的几次方是 8」。

### 函数取舍

* **支持 dim 的聚合函数**

    * `sum`、`max`、`min`、`mean` 四个支持 `dim`，能按行或按列聚合。

* **只做逐元素计算的函数**

    * `pow`、`sqrt`、`exp`、`log`、`log2`、`log10` 没有 `dim` 参数，只能对整个张量逐元素计算。

* **实际出场频率**

    * 常用的是 `sum`、`max`、`mean`，再加一个可用 `**` 顶替的 `pow`；`min` 用得少，`mean` 在词嵌入层案例还会用到。

    * `exp`、`log`、`log10`、`sqrt` 知道用途即可，不必背签名。

| 函数 | 作用 | 支持 dim |
| :--- | :--- | :--- |
| `sum` | 求和 | 支持 |
| `max` | 最大值，同时返回位置 `indices` | 支持 |
| `min` | 最小值 | 支持 |
| `mean` | 平均值，只收浮点型 | 支持 |
| `pow` | N 次幂 | 不支持 |
| `sqrt` | 平方根 | 不支持 |
| `exp` | e 的 n 次幂 | 不支持 |
| `log` / `log2` / `log10` | 以 e / 2 / 10 为底的对数 | 不支持 |

## 索引操作

### 索引的基本写法

* **下标结构（张量[行, 列]）**

    * > **定义**：逗号前是行索引，逗号后是列索引，`:` 表示该维度全部取。

    * 索引从 0 起：第 1 行的索引是 0，第 5 行的索引是 4。

    * 只写一个下标时它落在行上，列自动全取：`T1[1]` 是第二行所有列。

* **随机数据准备**

    * `torch.randint(low, high, size)`：`low` 是能取到的最小值，`high` 是上界且取不到，`size` 是形状。

    * 五乘五示例张量为 `[[6,9,9,2,8],[7,8,5,8,4],[7,4,3,9,5],[6,1,4,2,8],[1,2,5,7,6]]`，行、列索引都从 0 数。

    * `torch.manual_seed(24)` 固定随机数序列，保证每次生成的张量完全一致；不固定则每次结果都变。

### 简单行列索引

* **取整行**

    * `T1[1]` 取第二行全部列，结果是一维张量；`T1[1, :]` 效果相同。

    * 五列张量上，`T1[1]` 得到 `[7,8,5,8,4]`。

* **取整列**

    * `T1[:, 2]` 取所有行的第三列，得到 `[9,5,3,4,5]`。

    * 同一个数字 `2` 放在逗号前是第三行，放在逗号后是第三列，位置决定含义。

    * > **易错点**：`T1[1]` 是第二行所有列，`T1[:, 1]` 是所有行的第二列，两者不是同一件事。

### 列表索引

* **逐位配对取散点**

    * > **定义**：中括号里第一个列表是行索引，第二个列表是列索引，两边按位置一一配对，配出一对就是一个元素。

    * `T1[[0, 1], [1, 2]]` 取 `(0,1)` 与 `(1,2)` 两个点，结果 `[9,5]`，不是两行两列四个数。

    * 错法是把两组索引当交叉组合：`[0,1]` 行 × `[1,2]` 列会得 `9、9、8、5` 四个数，与逐位配对结果不同。

* **两组索引长度必须相等**

    * 行索引给两个、列索引给三个，配对配不齐，直接报 `IndexError`。

    * 列表索引配的是「点」不是「块」：行索引列表有几个元素，列索引列表就得有几个元素。

* **嵌套中括号取整块**

    * 在行索引外面再套一层中括号：`T1[[[0], [1]], [1, 2]]`，`0` 配整组列索引 `1、2`，`1` 也配 `1、2`，得两行两列 `[[9,9],[8,5]]`。

    * 这种写法运行时会给警告，表示不推荐、后续版本可能调整；结果正常输出，但实战中不必这么写。

### 范围索引

* **切片结构（起点:终点:步长）**

    * 与 Python 列表、字符串切片一致：终点不包含，起点省略表示从头开始，终点省略表示取到末尾，步长省略表示 1。

    * `T1[:3, :2]` 取第 0～2 行、第 0～1 列，得三行两列 `[[6,9],[7,8],[7,4]]`。

* **起点到末尾**

    * `T1[1:, :2]` 从第二行取到最后一行，列取前两列，得四行两列 `[[7,8],[7,4],[6,1],[1,2]]`。

    * `[:3]` 与 `[0:3]` 等价，`[:2]` 与 `[0:2]` 等价，省略的起点就是 0。

* **带步长跳取**

    * `T1[1::2, ::2]` 取索引 1、3 两行（第 2、4 行）与索引 0、2、4 三列（第 1、3、5 列），得 `[[7,5,4],[6,4,8]]`。

    * `1::2` 读作「从索引 1 开始、步长 2」，`::2` 读作「从头到尾、步长 2」；`0::2` 与 `::2` 完全等价。

    * > **提示**：「奇数行」「偶数列」指索引的奇偶，不是第几行第几列的序号；索引从 0 起，第 2 行的索引是 1。

### 布尔索引

* **布尔张量当筛子**

    * > **定义**：条件算出的布尔张量作为筛子，长度与被筛维度一致，`True` 位保留、`False` 位丢弃。

    * 手写布尔值必须先包成张量：`T1[torch.tensor([True, False, False, True, True])]` 留下第 0、3、4 行。

    * 真实场景用条件生成掩码，分三步：`T1[:, 2]` 取第三列，`> 5` 得布尔张量，`T1[掩码]` 筛行。

    * 五乘五张量第三列为 `[9,5,3,4,5]`，`T1[T1[:, 2] > 5]` 只留下第一行 `[6,9,9,2,8]`。

* **冒号位置决定筛行还是筛列**

    * `T1[T1[:, 2] > 5]` 筛的是行：掩码来自第三列，`True` 对应的整行留下。

    * `T1[T1[2] > 5]` 里的 `2` 没有冒号，取的是第三行；掩码在这一行上逐元素判断，最后按位置筛出索引 0、3 两行，结果是 `[[6,9,9,2,8],[6,1,4,2,8]]`。

    * > **易错点**：两个写法只差一个冒号一个逗号，结果天差地别；`T1[掩码]` 筛行，`T1[:, 掩码]` 筛列，掩码写在第几个位置就筛第几维。

* **歧义题的两种断法**

    * 题面「第二行大于五的列数据」有两种理解，两种都成立。

    * 断法一 `T1[:, T1[1] > 5]`：先求第二行哪些列大于 5，再拿这个掩码筛所有行，得五行三列 `[[6,9,2],[7,8,8],[7,4,9],[6,1,2],[1,2,7]]`。

    * 断法二 `T1[1, T1[1] > 5]`：只在第二行内部挑大于 5 的元素，得 `[7,8,8]`。

    * 遇到题面歧义时，把能想到的几种理解都写成代码跑出来，不纠缠出题意图。

### 多维索引

* **轴的层级**

    * 轴是方括号的嵌套层级：最外层是 0 轴，往里一层是 1 轴，再往里是 2 轴；去掉 `tensor(...)` 外那对小括号，只看中括号缩进就能数清。

    * 形状 `(2, 3, 4)` 读作「两个 3 行 4 列的矩阵」：0 轴管有几个矩阵（长度 2），1 轴管每个矩阵有几行（长度 3），2 轴管每行有几个数（长度 4）。

    * 同一层里平级的块全归同一个轴：1 轴不是「第几行」，而是「每个矩阵里那一层行」；轴说的是层级，不是序号。

* **在指定轴上取第一份**

    * 三维张量 `T2` 的两层分别为 `[[3,4,6,5],[8,8,8,3],[4,9,6,7]]` 与 `[[2,8,8,5],[6,5,1,4],[2,7,3,3]]`。

    * `T2[0]`：`0` 落在 0 轴，取第一个 3×4 矩阵，形状 `(3,4)`。

    * `T2[:, 0]`：0 轴全取、`0` 落在 1 轴，取每个矩阵的第一行，形状 `(2,4)`，结果为 `[[3,4,6,5],[2,8,8,5]]`。

    * `T2[:, :, 0]`：0、1 轴全取、`0` 落在 2 轴，取每行第一个数，形状 `(2,3)`，结果为 `[[3,8,4],[2,6,2]]`。

    * > **提示**：在某一根轴上只取一个索引，那一维会被压掉；结果比原形状少一维，看形状变化比背结果可靠。

* **多维索引的做法**

    * 先在脑子里定位「要在哪根轴上取第几个」，把 `0` 放到那个位置，其余轴写 `:` 全取。

    * 不要背 `T2[0]` 与 `T2[:, 0]` 各是什么，把轴数清楚后写出来自然是对的。

### 五类索引的分级

* **日常必用的三类**

    * 简单行列、范围（切片）、多维这三类要会：它们覆盖读一行、读一列、切一块、从三维数据里挑一份的日常操作。

* **看得懂即可的两类**

    * 列表索引会取散点即可，嵌套整块写法了解；范围索引加步长基本能替代列表索引。

    * 布尔索引会读会写即可；机器学习中特征由网络自动提取，不必像 pandas 那样手写条件筛样本。

| 索引方式 | 典型写法 | 要求 |
| :--- | :--- | :--- |
| 简单行列 | `T1[1]`、`T1[:, 2]` | 必须会：逗号前是行、逗号后是列 |
| 范围（切片） | `T1[:3, :2]`、`T1[1::2, ::2]` | 必须会：起点、终点加步长 |
| 多维 | `T2[0]`、`T2[:, :, 0]` | 必须会：先数轴，再落索引 |
| 列表 | `T1[[0, 1], [1, 2]]` | 会取散点即可，嵌套写法了解 |
| 布尔 | `T1[T1[:, 2] > 5]` | 会读会写，实战用得少 |

## 形状操作

### reshape

* **改形（reshape）**

    * > **定义**：在保证张量数据不变的前提下改变维度，转换成指定形状。

    * 唯一前提是元素总数不变：`(2,3)` 共 6 个元素，可改成 `(3,2)`、`(1,6)`、`(6,1)`；改成 `(2,5)` 需要 10 个元素，直接报错。

    * 「数据不变」指张量展平成一维后元素顺序不变：按行重排 `6 9 9 2 8 7` 顺序不变，按列重排会变成 `6 2 9 8 9 7`，顺序被打乱。

    ```text
    原始 (2, 3)                展平顺序 6 9 9 2 8 7
        6  9  9
        2  8  7

    按行重排 (3, 2)            展平顺序 6 9 9 2 8 7   与原始一致
        6  9
        9  2
        8  7

    按列重排 (3, 2)            展平顺序 6 2 9 8 9 7   顺序被打乱
        6  2
        9  8
        9  7
    ```

* **形状的读取**

    * `T1.shape` 返回 `torch.Size([2, 3])`，2 是行、3 是列；`shape` 可当序列用，`shape[0]` 是行数、`shape[1]` 是列数、`shape[-1]` 是最后一维。

    * > **提示**：f-string 里两个表达式塞进同一个大括号会当成元组，`f"{T1.shape[0], T1.shape[1]}"` 输出 `(2, 3)`；要输出 `2, 3` 得拆成两个大括号并用逗号连接。

### unsqueeze 与 squeeze

* **升维（unsqueeze）**

    * > **定义**：在指定轴上增加一个长度为 1 的维度，数据本身不动，只是在某一层外面多包一层中括号。

    * 两行三列 `(2,3)`：`dim=0` 得 `(1,2,3)`，`dim=1` 得 `(2,1,3)`，`dim=2` 得 `(2,3,1)`。

    * 可插入的位置只有 0、1、2 三处；`dim=3` 报 `IndexError: Dimension out of range`，因为中间没有未知维度可填。

    * 典型用途是多通道图片：三通道图片形状为 `HWC`（高、宽、通道），在前面用 `unsqueeze` 加一个 `N` 批量维，`N=5` 表示五张图。

    * 升维的动机：模型过简单时容易欠拟合，增加特征数可以改善，升维是朝这个方向的动作。

* **降维（squeeze）**

    * `squeeze()` 删除所有长度为 1 的维度，不是只删一个：`(2,1,3,1,1)` 一次变成 `(2,3)`。

    * > **注意**：`squeeze` 删的是所有长度为 1 的轴，调用时不用传参。

    * > **易错点**：`unsqueeze` 的 `dim` 最大只能写原张量的维数（两维张量最多写到 2），再大就越界；它只能插在已有轴的两端或相邻位置之间。

### transpose 与 permute

* **换轴（transpose）**

    * 签名只有 `dim0` 和 `dim1` 两个参数，一次只能交换两个维度，加不了第三个。

    * 返回新张量，原张量不变：`(2,3,4)` 做 `transpose(0, 1)` 得 `(3,2,4)`，原张量仍是 `(2,3,4)`。

    * 交换首尾用 `transpose(0, 2)`，`(2,3,4)` 得 `(4,3,2)`；写 `-1` 指最后一维，`transpose(0, -1)` 等价。

* **任意重排（permute）**

    * 参数写成 `*dims` 可变参数，一次可重排所有轴，轴号一个个写进去，不用套元组或列表。

    * 读法：按输出位置的顺序，写出每个位置取自原张量的哪一轴。`(2,3,4)` 要得 `(4,2,3)`，就取原 2 轴放第 0 位、原 0 轴放第 1 位、原 1 轴放第 2 位，写 `permute(2, 0, 1)`。

    * 轴号写负数也能跑，但一般用正数，好算且不易绕晕。

### view 与连续性

* **连续张量（contiguous tensor）**

    * > **定义**：内存中的存储顺序与张量中显示的逻辑顺序一致，称为连续；与数值大小、数值是否相邻无关。

    * 例：内存存 `6 9 9 2 8 7`，张量也显示 `6 9 9 / 2 8 7`，展平后一致，连续；内存存 `6 9 9 2 8 7`，张量显示 `6 2 / 9 8 / 9 7`，展平后是 `6 2 9 8 9 7`，不一致，不连续。

    * `is_contiguous()` 判断是否连续，`contiguous()` 按显示顺序重排内存，把不连续张量变成连续。

* **view 的限制**

    * `view` 只能修改连续张量的形状；`T1.view(3, 2)` 之后仍是连续的，因为只是把同一串数据重新划行。

    * `transpose` 或 `permute` 处理过的张量多半不连续：`(2,3)` 做 `transpose(0, 1)` 得 `(3,2)`，显示为 `[[6,2],[9,8],[9,7]]`，`is_contiguous()` 返回 `False`。

    * 对不连续张量调用 `view` 报 `RuntimeError: view size is not compatible with input tensor's size and stride`，并提示 `Use .reshape(...) instead`。

    * 救法：先 `contiguous()` 再 `view`，即 `T3.contiguous().view(2, 3)`。

* **view 的取舍**

    * 遇到不连续张量又必须改形状有两条路：换 `reshape`、`transpose`、`permute` 绕开连续性限制；或先 `contiguous()` 变连续再 `view`。

    * `view` 的价值是提前暴露错误：不连续就直接报错，问题当场解决；`reshape` 等函数不报错，隐问题被藏到训练阶段，排查成本更高。

    * 想要安全用 `view`，想要简单用前面几个函数，几种方式各有利弊，建议都掌握。

### 形状操作的分工

* **现阶段常用的一组**

    * `reshape` 改形状、`unsqueeze` / `squeeze` 升降维、`transpose` / `permute` 换轴，这一组是当前写代码的主力。

* **先留印象的一组**

    * `view` / `is_contiguous` / `contiguous` 在深度学习部分用得少，到 CV 阶段才密集出现；先记住用途，用到时再翻。

| 函数 | 作用 | 现阶段 |
| :--- | :--- | :--- |
| `reshape` | 数据不变，改成指定形状 | 马上要用 |
| `unsqueeze` / `squeeze` | 指定轴加一个长度为 1 的维度 / 删掉所有长度为 1 的维度 | 马上要用 |
| `transpose` | 一次交换两个轴 | 马上要用，后面也常出现 |
| `permute` | 一次任意重排所有轴 | 马上要用 |
| `view` / `is_contiguous` / `contiguous` | 改连续张量的形状 / 判连续 / 变连续 | 先留印象，CV 阶段才密集出现 |

## 拼接操作

### cat

* **沿维拼接（cat）**

    * > **定义**：把多个张量按指定维度拼接起来，不改变维度数；二维拼二维，结果仍是二维。

    * 两个 `(2,3)`：`dim=0` 得 `(4,3)`，把 t2 的两行接在 t1 下面；`dim=1` 得 `(2,6)`，把 t2 的每一行接在 t1 同一行后面。

    * `cat` 收的是张量列表，一次拼两个、三个都行，`torch.cat([t1, t2, t3], dim=0)` 同样成立。

* **形状匹配规则**

    * 除拼接维外，其他维度必须一致：`(2,3)` 与 `(2,4)` 按 `dim=0` 拼报 `Sizes of tensors must match except in dimension 0`，它期望 3、拿到 4。

    * 拼接维本身允许不同：`(2,3)` 与 `(5,3)` 按 `dim=0` 拼得 `(7,3)`；`(2,3)` 与 `(2,6)` 按 `dim=1` 拼得 `(2,9)`。

* **合法 dim 的范围**

    * `cat` 的输出维度数等于输入维度数，合法 `dim` 只能落在已有维度范围内；两个二维张量用 `dim=2` 报 `Dimension out of range (expected to be in range of [-2, 1], but got 2)`。

    * 二维张量的 `dim=1` 与 `dim=-1` 指向同一位置，效果相同；负数从最后一维往回数，`-1` 是最后一维，`-2` 是第 0 维。

    * > **易错点**：`cat` 的规则是「除拼接维之外必须一致」，不是「形状必须一致」；拼接维恰恰是允许不同的那一维，别记反。

### stack

* **新维拼接（stack）**

    * > **定义**：在指定位置插入一个新维度，并沿该维度连接一系列张量，输出比输入多一维。

    * 输入形状必须完全相同，`cat` 留的「拼接维可以不同」的口子在这里不存在；两个 `(2,3)` 才能拼。

    * 新维度长度永远等于参与拼接的张量个数；`dim` 指定插入位置，原维度按顺序往后让位。

* **三个 dim 的配对方式**

    * 取 `t1 = [[6,9,9],[2,8,7]]`、`t2 = [[8,5,8],[4,7,4]]`。

    * `dim=0` 得 `(2,2,3)`：`result[0]` 是完整 t1，`result[1]` 是完整 t2。

    * `dim=1` 得 `(2,2,3)`：`result[0] = [t1 第 0 行, t2 第 0 行]`，`result[1] = [t1 第 1 行, t2 第 1 行]`，形状与 `dim=0` 相同但内容重排。

    * `dim=2` 得 `(2,3,2)`，逐个元素配对，结果为 `[[[6,8],[9,5],[9,8]],[[2,4],[8,7],[7,4]]]`。

    * `dim=3` 报 `Dimension out of range`；若真能拼，输出形状会是 `(2,3,2,?)`，那个未知维度没东西可填。

    ```text
    dim=0：最外层套一层中括号
        [ t1 , t2 ]                         → (2, 2, 3)

    dim=1：新维度插在原第 0 维之后，逐行配对
        result[0] = [ t1 第 0 行 , t2 第 0 行 ]   → (2, 2, 3)
        result[1] = [ t1 第 1 行 , t2 第 1 行 ]

    dim=2：新维度插在最里面，逐元素配对
        result[i][j] = [ t1[i][j] , t2[i][j] ]    → (2, 3, 2)
    ```

* **shape 相同不代表内容相同**

    * `stack(dim=0)` 与 `stack(dim=1)` 的输出形状都可能是 `(2,2,3)`，光看 shape 分不出区别，必须看元素怎么配对。

    * > **易错点**：`dim=2` 时输出是 `(2,3,2)` 而不是 `(2,2,3)`；记「插在哪一位」比记形状可靠。

### cat 与 stack 的对比

* **核心区别**

    * `cat` 沿已有维度接长，维度数不变；`stack` 在指定位置插新维度，维度数加一。

    * `cat` 只要求除拼接维外的其他维度一致，`stack` 要求所有输入形状完全相同。

* **选用建议**

    * 日常更常用 `cat`，它把数据组合到一起且不改变维度，顾虑少。

    * `stack` 使用频率较低，但必须看得懂，避免遇到别人的写法时不认识。

| 对比项 | cat | stack |
| :--- | :--- | :--- |
| 维度数 | 不变 | 增加一维 |
| 输入形状要求 | 除拼接维度外，其他维度必须一致 | 所有维度必须完全一致 |
| 新维度长度 | 没有新维度 | 等于参与拼接的张量个数 |
| 合法 dim | 已有的维度，越界报错 | 0 到输出维度数减一，中间不能有未知维度 |
| 使用频率 | 更高 | 较低，但必须看得懂 |

## 自动微分与参数更新

### 求导与反向传播

* **自动微分（automatic differentiation）**

    * > **定义**：PyTorch 内置的 `torch.autograd` 模块，职责只有一件——求导；给它公式，它算导数。

    * 支持任意计算图的自动梯度计算：乘、加等运算一步步搭起关系网，PyTorch 记下每一步，在结果上调一次 `backward` 就能算出整条链的导数。

    * 接口记两个词：`backward` 是求导，`grad` 是梯度。

* **正向传播与反向传播**

    * 正向传播是从特征一路算到预测值的这一段；正向传播结束后才有损失函数。

    * > **定义**：反向传播是拿到结果、算出损失函数的梯度以后，结合更新公式去更新权重的这一整段动作，也叫 BP 算法。

    * 自动微分与反向传播是两码事：自动微分等于求导，反向传播是「求导 + 按公式更新权重」的完整流程。

### 参数更新公式

* **权重与偏置的更新**

    * 记号：X 是特征，W 是权重，B 是偏置；简化公式为 $y = wx + b$，按矩阵写是 $y = XW^{T} + b$。

    * 权重更新：$w_{\text{新}} = w_{\text{旧}} - \eta \cdot \frac{\partial loss}{\partial w}$，其中 $\eta$ 是学习率，最后一项是损失函数对权重的导数。

    * 偏置更新：$b_{\text{新}} = b_{\text{旧}} - \eta \cdot \frac{\partial loss}{\partial b}$，形式与权重那条一样。

* **梯度的本质**

    * 严格说，梯度是损失函数对每个参数分别求偏导后排成的向量；只有一个参数时它是普通导数，参数一多每个分量各有一个偏导。

    * 日常说「梯度就是导数」够用，但要知道它其实是一组偏导。

    * 实际开发中大多数情况可以把偏置设为全零矩阵，相当于 $y = wx$ 不考虑 b，所以常听到的只有 W 的更新式。

### 损失函数与计算图

* **均方误差（mean squared error，MSE）**

    * M 是 mean（平均），S 是 square（平方），合起来是均方误差；算法是所有误差的平方和除以样本数。

    * 定义式为 $MSE = \frac{1}{n}\sum_{i=1}^{n}(z_i - y_i)^2$。

    * 均方根误差在 MSE 基础上再开平方根。

* **计算图的流程**

    * X 乘 W（乘法），再加 B（加法），得到 Z（预测值）；Z 与 Y（真实值）一起算 MSE，得到 loss。

    * 对 loss 调 `backward` 得梯度 grad，代入更新公式得新的 W、B，再带着新权重回到乘法，进入下一轮。

    ```text
    X（特征） ──► 乘法：X × W ──► 加法：加 B ──► Z（预测值）
                      ▲                ▲
                      │                │
                   W（权重）         B（偏置）

    Z 与 Y（真实值） ──► MSE(Z, Y) ──► loss ──► backward ──► grad
                                                                │
                                                                ▼
                              W新 = W旧 - η × grad，B新 = B旧 - η × grad
                                                                │
                                                                └──► 回到乘法
    ```

    * 一轮一轮迭代，每轮都用当前梯度更新权重，逐步逼近真实关系。

### detach

* **自动微分与 numpy 的冲突**

    * 张量一旦允许自动微分、被求导之后，就不允许直接转成 numpy。

* **分离（detach）**

    * `detach` 相当于拷贝一份张量，拷贝出来的这一份就可以转 numpy。

    * 需要把被求导的张量转成 numpy 时，先 `detach` 再转。
