# 词嵌入与RNN

## 词向量与词汇表

### 语义的数值化

   * 同一串字符在不同上下文里承担的词性、语义都不同：一个"把"字可以在同一句里分别当量词、动词和名词"车把"，"我去我不去"光看字面判断不了到底去还是不去。

   * 机器只看到字符串时连"这是几个意思"都分不出来，所以第一步不是建模，而是把字转化为数值；有了数值，才能分析这一组值和那一组值之间的关系。

   * **词向量（Word Vector）**

       * > **定义**：用一组固定长度的数值表示一个词，数值的个数就是词向量的维度。

       * 128 维就是用 128 个数值来表示这个词；4 维、8 维、10 维、256 维的做法完全一样，只是规模不同。

### 词向量表与初始化

   * **词向量表（Word Vector Table）**

       * > **定义**：左边一列是词、右边一片是数的二维表，每一行存一个词对应的词向量。

       * 行数等于词的数量，列数等于词向量维度：100 个词、每词 128 维就是 $100 \times 128$，3 个词、每词 4 维就是 $3 \times 4$。

       * 表里的数值在初始化时随机生成，每次执行都不一样；具体生成成什么不用管，底层有公式在算这件事。

       * 生成时按词在语料中出现的先后顺序安排，相邻出现的词关联性最大；看到 cat，下一个大概率给出与它关系最近的词。

       * 词向量表把"语义上的远近"变成"数值上的关系"，这层关系靠训练一点点长出来。

   * **随机初始化**

       * > **定义**：直接为每个词生成一组随机数值作为初始词向量。

       * 它是最省事的一条路，也是每次运行结果都不同的原因。

   * **词到向量（word to vector）**

       * > **定义**：把单词转换成向量的过程，`to` 表示"到、转换"，`vector` 表示向量。

       * 初始化的第二条路是加载预训练的词向量，拿现成的来初始化，就属于这一范畴。

       * 怎么把单词转成向量属于更绕的一层，此处先拿来用。

       * 词嵌入层把索引映射为词向量这一步，正式名字也是词到向量。

### 词汇表

   * **词汇表（Vocabulary）**

       * > **定义**：记录词与唯一索引对应关系的字典，用索引作键、词作值。

       * 示例：0 对应 cat，1 对应 meat，2 对应 on，依次往下排。

       * 5703 个词的语料，索引从 0 数到 5702。

       * 没有词汇表就不知道总共有多少个词、cat 排第几个、on 排第几个、以及某个词到底存不存在。

   * **索引映射**

       * > **定义**：词嵌入层实际接收的是词的索引，把索引换成对应的词向量。

       * 标准词向量不是拿词来转，而是拿索引来转：把 0 号词转成它的向量、1 号词转成它的向量。

       * 词向量有两种给法——词直接对应向量、词的索引对应向量，实际采用后者。

       * 训练就是通过这样一条条索引，去学词与词之间的联系和关系。

### 上下文与生成

   * RNN 的输入不是词汇表、也不是词，而是词向量；整个处理基于词向量完成，再根据上下文生成下一个序列的输出。

   * 上下文指上一时刻的隐藏状态加当前时刻的输入。

   * **AIGC**

       * > **定义**：每一步预测下一个词的索引，再回词汇表把该索引对应的词取出来接到序列后面。

       * 例：预测出这个位置应该是索引 66，就回词汇表找 66 对应的词并显示出来。

## 词嵌入层 API

### nn.Embedding 的参数

   * **词嵌入层（nn.Embedding）**

       * > **定义**：PyTorch 的词嵌入层，本质是一张按行取值的词向量表——索引进去，对应的那一行向量出来。

       * 第一个参数是词的数量，确切说是词表大小；第二个参数是词向量的维度。

       * `nn.Embedding(10, 4)` 表示 10 个词、每个词转成 4 维；歌词生成案例是 `nn.Embedding(5703, 128)`，5703 个词、每词 128 维。

       * 表里的数值初始化时是随机的，之后跟着训练走。

   * **同类层 API 对照**

       * 全连接层是 `Linear`，卷积层是 `Conv2d`，池化层里用得最多的是最大池化 `MaxPool2d`，词嵌入层是 `Embedding`。

### 分词

   * 语料进入嵌入层之前先分词；中文分词用结巴分词器（`jieba`），安装命令 `pip install jieba`。

   * 结巴分词器有三种切词方式，此处先用第一种 `jieba.lcut`，它专门切中文。

   * 分词会把标点也切成独立的词：逗号、句号各占一个，词表大小因此把标点算在内。

   * 分词质量并非万能：正常切法会把"北京""冬奥"切开，而"不去"这类词可能被切成两个字；反过来"一把、把、把、把住"这种多身份的字反而切得开。

   * 重复出现的词（如"的"）有两种处理：只保留一个，或按原顺序全部保留，两种方案都能走。

   * > **提示**：分词器的好坏直接决定词表的质量；词表错了，后面的索引、词向量、预测全都跟着错。

### 建表与索引

   * 建表前先做 unique words 去重，把重复词剔除再建表；若直接把分词结果丢进去，重复出现的"的"会各占一行。

   * 建层时第一个参数写 `len(words)` 而不是写死数字，句子长度变化时能自适应。

   * 取索引用 `enumerate`：把列表扔进去，一次给出索引和值，效果等同于手写 `i = 0` 再逐次 `i += 1`，但更高效。

   * Python 没有 `i++` 这种自增写法，自增要写 `i += 1`。

   * `embedding` 要的是张量，索引必须先用 `torch.tensor(...)` 包成 tensor 再传入。

### 五步调用

   * 五步依次是：定义一句话、`jieba.lcut` 分词、创建 `nn.Embedding`、用 `enumerate` 取每个词的索引、把索引转成张量送进嵌入层取词向量。

```python
import torch
from torch import nn
import jieba


def dm01():
    text = "北京冬奥的进度条已经过半，不少外国运动员在完成自己的比赛后踏上归途。"
    words = jieba.lcut(text)
    embedding = nn.Embedding(len(words), 4)
    indices = [i for i, word in enumerate(words)]
    vectors = embedding(torch.tensor(indices))
    for i, word in enumerate(words):
        print(word, "\t\t", vectors[i])


if __name__ == '__main__':
    dm01()
```

   * 同一句话两次运行，同一个词的向量数值会变（初始化随机），但词与词的关联关系不变。

   * 打印词与向量时用两个 `\t` 做缩进对齐；中文宽度不一致，部分行对不齐属正常现象。

## 序列建模

### 序列数据

   * **循环神经网络（Recurrent Neural Network，RNN）**

       * > **定义**：主要处理序列数据的网络；序列数据指后边的数据对前边的数据有依赖。

       * 典型序列数据：天气预测、股市分析、文本分析、文本生成。

       * 文本顺序不可交换："我爱你"和"你爱我"表达的意思完全不一样，顺序一颠倒意思就变了，所以要用循环网络来建模序列关系。

   * RNN 由三层组成：词嵌入层把每个词生成对应维度的词向量；循环网络层根据词向量算下一个词；输出层把结果输出。

### 单神经元的循环复用

   * 按词数铺神经元时，句子一长神经元数量就跟着涨：一句话十几个词就要十几个，丢一段诗、一段文本要更多，到底要多少个事先算不出来。

   * 解法是同一个神经元重复使用：第一次传"我"，第二次把它预测出的词传回去，第三次传"你"，词不断循环地喂进同一个神经元，"循环神经网络"由此得名。

   * 这一个神经元每次都结合上一次的隐藏状态和本次输入，得到本次隐藏状态与本次输出；连接不同时间步、结合上下文语义，这就是记忆功能。

   * 隐藏状态一步步往下传：$h_1$ 预测 $y_1$、$h_2$ 预测 $y_2$、$h_3$ 预测 $y_3$，一路接下去。

```text
  按词数铺神经元（数量随句子长度爆炸）
  x1="我" ──▶ [神经元] ──▶ y1
  x2="爱" ──▶ [神经元] ──▶ y2
  x3="你" ──▶ [神经元] ──▶ y3

  同一个神经元循环使用（数量恒为一个）
  x1="我" ──▶ [同一神经元] ──▶ h1 ──▶ y1="爱"
  x2="爱" ──▶ [同一神经元] ──▶ h2 ──▶ y2="你"
  x3="你" ──▶ [同一神经元] ──▶ h3 ──▶ y3="，"
```

### 三层职责

   * 三层接力完成从一句话到下一个词的转换，词嵌入层负责把词变成数，循环网络层负责让数带上时间，输出层负责把时间还原成词。

   * 输出层通常给出的是词汇表中词的概率分布：输出的是一排概率，用来告诉外面"到底是哪个词"。

| 层 | 作用 |
| :--- | :--- |
| 词嵌入层 | 把词，或者词的索引，转换为词向量的表示 |
| 循环网络层 | 逐步处理词向量，生成每个时间步的隐藏状态 |
| 输出层（全连接层） | 通过线性变换，把隐藏状态映射为词汇表中词的概率分布 |

## 前向计算

### 两次加权求和

   * **隐藏状态（Hidden State）**

       * > **定义**：当前时间步承载历史信息的向量表示，由上一时刻的隐藏状态与当前输入共同算出。

       * 公式为 $h_t = \tanh\left(W_{ih}x_t + b_{ih} + W_{hh}h_{t-1} + b_{hh}\right)$。

       * $W_{ih}$、$b_{ih}$ 是输入数据的权重与偏置，$x_t$ 是当前时刻的输入，$W_{ih}x_t + b_{ih}$ 是输入这一路的加权求和。

       * $W_{hh}$、$b_{hh}$ 是输入隐藏状态的权重与偏置，$h_{t-1}$ 是上一次的隐藏状态，$W_{hh}h_{t-1} + b_{hh}$ 是另一路加权求和。

       * 两路相加后整体过一遍 $\tanh$，得到的值就是当前时刻的隐藏状态 $h_t$。

   * **输出（Output）**

       * > **定义**：当前时刻的预测向量，由隐藏状态再做一次加权求和得到。

       * 公式为 $y_t = W_{hy}h_t + b_y$，$W_{hy}$ 是输出权重、$b_y$ 是输出偏置。

       * 整件事说穿了就是两次加权求和：上一次隐藏状态加当前输入得 $h_t$，再拿 $h_t$ 做第二次加权求和得 $y_t$。

### 激活与初始状态

   * RNN 底层默认的激活函数是 $\tanh$：在常见深度学习算法里它是唯一默认用 $\tanh$ 的，其余底层一般选 ReLU；它比较老，从最初一路传到现代，底层就默认成了 $\tanh$。

   * 第一个时间步没有"上一次的隐藏状态"，初始化一个全零的 $h_0$ 先假设它存在。

   * 一次前向的机制分三步：接收输入（隐藏状态加输入元素）、更新隐藏状态（得到 $h_1$）、输出计算（把 $h_1$ 变成 $y_1$）。

### 词表概率输出

   * $y_t$ 是词汇表映射输出的一个向量，这个向量经过全连接层，得到最终的预测结果 $\hat{y}_t$。

   * $\hat{y}_t$ 里每个元素，代表当前时刻生成词汇表中每个词的得分；词表有多少个词，$\hat{y}_t$ 就有多少个元素值。

   * 5703 个词就是 5703 个得分，最终取概率最大的那个词作为本步结果。

   * 每生成一个词就再预测下一次哪个词概率最大，拼接、拼接、拼接，得到最终结果，这就是 AIGC 的生成方式。

   * 运算量大在这里：5703 个词每次往下预测，都要把全部概率算一遍。

## 文本生成

### 单步推进

   * 初始词直接充当 $x_t$；没有上一次隐藏状态就初始化全零 $h_0$，由 $h_0$ 与初始词算出 $h_1$，再由 $h_1$ 得出输出 $o_1$，取概率最大的词作为下一个词。

   * 下一个词回灌：把上一步输出当本次输入，把上一步隐藏状态当"上一次的隐藏状态"，算出新隐藏状态与新输出，再取最大。

   * 示例链条：M 进去得 A，A 进去得 C，C 进去得 H；每一步都是完整的一次前向传播，重复到生成完整句子或达到指定长度。

   * 生成长度可指定：给一个起始词，再给 50 个词，就是生成 50 个词后结束。

```text
  h0(全零) + M ──▶ h1 ──▶ o1 ──▶ 取最大 ──▶ A
                                              │
      ┌───────────────────────────────────────┘
      ▼
  h1 + A ──▶ h2 ──▶ o2 ──▶ 取最大 ──▶ C
                                        │
      ┌─────────────────────────────────┘
      ▼
  h2 + C ──▶ h3 ──▶ o3 ──▶ 取最大 ──▶ H
                                        │
                                        ▼
                              继续，直到满 50 个词
```

### 词表约束

   * 起始词必须在词表里：5703 个词的词表里有"星星""分手"，都可以直接起手。

   * 词表里没有的词（如"AI"）放进去会直接报错，因为去词表里根本找不到这个词。

## nn.RNN 循环网络层

### 三个关键参数

   * **循环网络层（nn.RNN）**

       * > **定义**：PyTorch 中按时间步循环处理序列的层，单步行为是"上一次隐藏状态加本次输入，得到本次隐藏状态与本次输出"。

       * `input_size` 是输入数据的维度，即词向量的维度——把一个词转成多少个数字。

       * `hidden_size` 是隐藏层的维度，即隐藏状态向量有多长。

       * `num_layers` 是隐藏层的层数，即这个 RNN 有几层在处理。

   * 三个参数配套创建层只需一行：`nn.RNN(input_size=128, hidden_size=256, num_layers=1)`。

   * 源码里另有两个默认值：`num_layers` 默认 1，`nonlinearity` 默认激活函数是 `tanh`。

   * `num_layers` 一般取 1；取 2 表示两层大脑接力——第一层先处理，第二层再深加工。

| 参数 | 含义 | 演示取值 |
| :--- | :--- | :--- |
| `input_size` | 输入数据的维度，也就是词向量的维度 | 128 |
| `hidden_size` | 隐藏状态向量的维度 | 256 |
| `num_layers` | 隐藏层的层数，默认 1 | 1 |

### 一次前向

   * 传入 `x`（本次输入）与 `h_0`（上一时刻的隐藏状态），返回 `output` 与 `h_1`（当前时刻的隐藏状态）。

   * 不管序列展开多长，每一步做的都是同一件事：基于上一次的隐藏状态和本次的输入，得到本次的隐藏状态和本次的输出。

   * 对外形态是"给两个、回两个"，中间没有显式的箭头；底层公式与接口的差别在于——公式讲的是内部怎么算，接口讲的是外面怎么调用。

```text
   x   ──┐
         ├──►  nn.RNN  ──┬──►  output
   h_0 ──┘               └──►  h_1
```

### 四个张量的形状

   * 规律一：凡是隐藏状态（`h_0`、`h_n`），第一个维度都是层数，后面跟着批大小与隐藏维度。

   * 规律二：凡是与序列打交道的（`x`、`output`），第一个维度都是句子长度，后面跟着批大小与那一时刻的向量维度。

   * `h_n` 与代码里拿到的"当前时刻的隐藏状态"是同一个东西；`h_n` 是站在整条序列角度起的名字，指最后一个时间步的隐藏状态。

   * `output` 收集了所有时间步的输出，第一维因此回到句子长度；`h_1` 只关注最后一帧，第一维是层数。

   * `output` 最后一维是 `hidden_size`（演示中 256），不是 `input_size`。

| 张量 | 形状 | 三个维度依次表示 | 演示取值 |
| :--- | :--- | :--- | :--- |
| `x` | `(seq_len, batch, input_size)` | 句子长度、批大小、词向量维度 | `(5, 32, 128)` |
| `h_0` | `(num_layers, batch, hidden_size)` | 隐藏层层数、批大小、隐藏状态维度 | `(1, 32, 256)` |
| `output` | `(seq_len, batch, hidden_size)` | 句子长度、批大小、输出向量维度 | `(5, 32, 256)` |
| `h_n` | `(num_layers, batch, hidden_size)` | 隐藏层层数、批大小、隐藏状态维度 | `(1, 32, 256)` |

### 形状的语义

   * `input_size=128` 读作"每看一个词进来 128 个细节"；`hidden_size=256` 读作"能存下多少条剧情线索"，值越大记住的越多。

   * 256 不是"脑子的大小"，而是"脑容量"——当前时刻愿意花多少精力去记；它给这份记忆活跃度定了个向量长度。

   * `x` 的 `(5, 32, 128)` 读作"32 个人，每人看 5 帧新画面，每帧 128 个细节"。

   * `h_0` 的 `(1, 32, 256)` 读作"32 个人各自对上一部片子记住了多少"，是看新片之前脑子里的存量。

   * `h_0` 第一个数必须等于建层时的 `num_layers`，`x` 最后一个数必须等于 `input_size`，两边的批大小必须是同一批。

   * > **易错点**：128 与 256 别搞混——128 是每次输入的长度，管"看进来多少"；256 是能记住多少，管"存下来多少"。

### 四步调用

   * 四步依次是：创建循环网络层、造本次输入 `x`、造上一时刻的隐藏状态 `h_0`、调用一次拿回 `output` 与 `h_1`。

```python
import torch
import torch.nn as nn

rnn = nn.RNN(input_size=128, hidden_size=256, num_layers=1)

x = torch.randn(size=(5, 32, 128))
h_0 = torch.randn(size=(1, 32, 256))

output, h_1 = rnn(x, h_0)
print(output.shape)   # torch.Size([5, 32, 256])
print(h_1.shape)      # torch.Size([1, 32, 256])
```

   * 调用后 `output` 打印为 `torch.Size([5, 32, 256])`，`h_1` 打印为 `torch.Size([1, 32, 256])`。

   * 形状记混时回到那句话换算：几帧、几个人、每帧多少细节、脑子里存下多少。
