# 强化学习基础：问题设定、基本概念与贝尔曼公式

## 课程脉络与学习定位

* **知识体系两板块**

    * 强化学习基础原理分为两列：左列是**基础的工具**（基本概念 → 贝尔曼公式 → 贝尔曼最优公式），右列是**算法和方法**（值迭代/策略迭代 → 蒙特卡洛 → 随机近似 → 时序差分 → 值函数近似 → 策略梯度 → actor-critic），后面的章节都踩在前面的章节之上。

    * 重要性体现在不同方面：越靠前的章节重要性体现在**基础性**，越靠后的章节重要性体现在**前沿性与实践性**。

* **学习心态与时间预算**

    * 强化学习原理有两个特点：**数学性强**——只凭直观讲解理解不深刻，理解了背后的数学才能 360 度无死角解释算法；**系统性强**——后面章节一定以前面章节为基础，跳过基本概念直接学 Q-learning、policy gradient 会云里雾里。

    * 时间预算参考：线上全部内容约 10 小时；学到一半停下来理解清楚、不带问题往前走，时间翻倍到 20 小时；需要补相关基础知识，再翻倍到 40 小时（10 天、每天 4 小时可以完成）。

* **贯穿全课程的算法骨架**

    * 值迭代 / 策略迭代 / 截断策略迭代是第一批求解最优策略的算法：截断策略迭代是前两者的统一化表达，值迭代和策略迭代是它的两个极端；它们都是**迭代式**算法，每个迭代步骤包含 **policy update** 与 **value update** 两个子步骤——先估计当前策略的值（策略评价），再根据值改进策略。

    * 这种"值和策略不断交替迭代"的思想贯穿所有强化学习算法，只是具体形式不同；蒙特卡洛方法是第一个**不需要模型**的方法（没模型要学的是随机变量的期望值，没有模型要有数据，什么都没有就学不了）。

    * 时序差分方法中涉及两个策略：**behavior policy** 生成经验数据，**target policy** 是被改进、希望收敛到最优策略的目标策略；两者相同是 on-policy，可以不同是 off-policy（好处是可以用之前、别的策略生成的数据来学习）。

* **强化学习的终极目标**

    * 强化学习的终极目标就是**求解最优策略**；评价策略靠 state value，求 state value 靠贝尔曼公式，找最优策略靠贝尔曼最优公式——这是前三章的主线。

## 网格世界问题设定

* **grid-world example（网格世界例子）**

    * 全课程通用的直观例子：机器人在网格中寻找目标区域；每个小网格分三类——**accessible**（可进入，白色）、**forbidden**（禁区，黄色）、**target area**（目标区域）；网格世界有边界，机器人只能在相邻块之间移动，**不能斜向移动**。

    * 强化学习在这个例子里的任务是让机器人找到一条好路径到达目标；好路径的直观标准：尽可能避免进入 forbidden area、不要有无意义的拐弯（绕路再回来）、不要试图超越边界（撞墙）。

* **禁区进入规则的设定**

    * 交互行为理论上可以任意定义（比如撞墙弹到任意方向），因为这只是仿真；但实际当中不能任意定义，实际是机器人物理地移动。

    * forbidden area 有两种设定：第一种虽是禁区但**可以进入，进入会被惩罚**；第二种物理上无法进入。课程采用第一种——它更一般化也更难（排除状态会让搜索更容易），且允许出现"穿过禁区反而是到目标的最近路径、agent 冒险穿过禁区"这类有意思的行为。

## 状态、动作与状态转移

* **state（状态）与 state space（状态空间）**

    * > **定义**：state 描述的是 agent 相对于环境的状况（status）；在网格世界当中，state 指的就是位置（location）。

    * $s_1, s_2, \ldots, s_9$ 这些字母是**索引**，真正对应的状态是二维平面上的位置；更复杂的问题里状态还可能对应速度、加速度等信息。

    * > **定义**：状态空间就是把所有状态 $s_i$ 放到一起得到的集合，记作 $\mathcal{S}=\{s_i\}$——这里的"空间"就是一个集合（set）。

* **action（动作）与 action space（动作空间）**

    * 网格世界共有 5 个动作：$a_1$ 向上、$a_2$ 向右、$a_3$ 向下、$a_4$ 向左、$a_5$ 原地不动。

    * > **定义**：动作空间 $\mathcal{A}$ 是把所有 action 放到一起得到的集合。

    * action space 是**和状态依赖的**：不同状态的 action space 不一样，所以要写成 $\mathcal{A}(s_i)$——它是 $s_i$ 的一个函数。

* **state transition（状态转移）**

    * > **定义**：state transition 指的是 agent 采取一个 action 时从一个 state 移动到另一个 state 的过程，它定义了 agent 和环境的一种交互行为。

    * 例子：在 $s_1$ 采取 $a_2$（向右）跳到 $s_2$；在 $s_1$ 采取 $a_1$（向上）会撞到边界被弹回来，下一个状态还是 $s_1$。

* **表格表示的局限与条件概率**

    * state transition 可以用**表格（tabular）**表示：每行对应一个状态、每列对应一个 action，任何状态、任何 action 在表里都有定义；但表格**只能表示 deterministic（确定性）情况**——一个动作对应多个可能状态时表格无法表达。

    * 更一般的方法是**state transition probability（状态转移概率）**，用条件概率描述：确定性情形 $p(s_2 \mid s_1, a_2) = 1$、$p(s_i \mid s_1, a_2) = 0\ (i \neq 2)$；随机性情形（比如刮风）同样可以描述：$p(s_2 \mid s_1, a_2) = 0.5$、$p(s_5 \mid s_1, a_2) = 0.5$——概率形式更一般化，随机的状态转移也能用它描述。

## 策略

* **policy（策略）**

    * > **定义**：policy 告诉 agent——如果处在一个状态，应该 take 哪一个 action；它是强化学习当中独有的概念。

    * 直观上用箭头表示（每个状态一个箭头）；基于策略加状态转移，从不同格子出发会得到不同的 path，即 **trajectory（轨迹）**。

* **用条件概率表达策略**

    * $\pi$ 在强化学习中统一指策略（不是圆周率）；$\pi$ 是条件概率，指定任何状态下任何 action 的概率，例如确定性策略：$\pi(a_2 \mid s_1) = 1$，其它 action 概率为 0。

    * 一个状态所有 action 的概率之和必须等于 1；且**对每一个状态都要有它的策略**，不能只给一个状态定策略。

    * 随机性（stochastic）策略：比如 $\pi(a_2 \mid s_1) = 0.5$、$\pi(a_3 \mid s_1) = 0.5$，其它 action 概率为 0——虽然书写时省略，但要清楚**每一个 action 都有概率，只不过可能是 0**。

* **策略的表示与执行**

    * 策略可以用表格表示：每行对应一个状态、每列对应一个 action，确定性和随机性情况都能描述；编程时就是用一个数组或矩阵来表示。

    * 执行随机策略的方法：从 0 到 1 做一次均匀分布的随机采样得到 $x$，$x$ 落在 $0 \sim 0.5$ 就采取 $a_2$、落在 $0.5 \sim 1$ 就采取 $a_3$——按概率大小划分 $[0,1]$ 区间，动作被执行的频率自然等于它的概率。

## 奖励

* **reward（奖励）**

    * > **定义**：reward 是 agent 采取一个动作之后得到的一个实数（标量）；正数代表**鼓励**该行为，负数代表**惩罚**该行为。

    * reward 设为 0 代表没有 punishment——在一定程度上，没有惩罚就是鼓励。

    * 可以反过来用正数代表惩罚、负数代表鼓励：正数代表鼓励时 agent 希望得到越来越多正数；正数代表惩罚时 agent 会去最小化惩罚——两种写法优化方向等价，是数学技巧。

* **网格世界的奖励设计**

    * 试图逃出边界：$r_{\text{bound}} = -1$；进入 forbidden area：$r_{\text{forbid}} = -1$；到达 target area：$r_{\text{target}} = +1$；其它所有行动（普通移动、原地不动等）reward 都是 0。

    * reward 可以理解为 **human-machine interface**（人机接口）——我们与机器交互的手段：通过设计 reward 引导 agent 不出界、不进禁区、尽量到目标区，**我们通过设计 reward 来实现我们的目标**。

* **奖励的概率表示**

    * reward 也可以用表格表示（每行一个状态、每列一个 action），但表格只能表示确定性情形——一个状态一个动作**一定**得到确定 reward。

    * 一般化表示用条件概率：$p(r = -1 \mid s_1, a_1) = 1$、$p(r \neq -1 \mid s_1, a_1) = 0$——确定性只是随机性的特例；真正随机的 reward 例如"努力学习一定会得到正 reward，但具体值不确定"，条件概率描述的就是这种分布。

## 轨迹、回报与折扣

* **trajectory（轨迹）**

    * > **定义**：trajectory 是一个 state-action-reward 链：从初始状态出发，take action 得 reward、跳到下一状态，持续到结束。

    * 例：$s_1 \xrightarrow{a_2, r=0} s_2 \xrightarrow{a_3, r=0} \cdots \xrightarrow{} s_9(\text{target}, r=+1)$；轨迹包含状态、action、reward 三部分。

* **return（回报）**

    * > **定义**：return 是针对一条 trajectory 而言的，把沿着这条轨迹所得到的所有 reward 加起来。

    * 数学上刻画"策略好坏"就靠比较 return：不进禁区的轨迹 return 为 $+1$，进禁区的轨迹 return 为 $0$——return 大的策略好；只有能评估策略，才能在当前策略不好时判断下一个策略是否更好、从而不断改进。

* **discount rate（折扣率）与 discounted return（折扣回报）**

    * 到达 target 后策略仍持续运行（一直得到 $+1, +1, +1 \ldots$），轨迹是**无限长**的，直接求和 return 会**发散**。

    * 引入 discount rate $\gamma$（0 到 1 之间的数），得到 discounted return：

    $$G_t = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \gamma^3 R_{t+4} + \cdots$$

    * 当 $\gamma < 1$ 时，$\gamma^3$ 之后的无穷数列 $1 + \gamma + \gamma^2 + \cdots = \frac{1}{1-\gamma}$，发散的求和变成有限值。

    * 折扣的第二个作用是**平衡远近未来的 reward**：$\gamma \to 0$ 时远期 reward 很快衰减，值主要依赖最初得到的 reward；$\gamma \to 1$ 时远期 reward 衰减慢、积累大。**减小 $\gamma$ 会让策略更近视**（注重最近 reward），**$\gamma$ 大则更远视**（注重长远 reward）——通过控制 $\gamma$ 可以控制 agent 学到的策略。

## 回合与持续任务

* **episode（回合）与 terminal state（终止状态）**

    * > **定义**：伴随 terminal state 的 trajectory 称为一个 episode（也叫 trial，"试"的意思）——从起点出发沿轨迹走到目标就停下来。

    * 一个 episode 通常都是**有限步**，这样的任务称为 **episodic tasks**；有些任务**没有 terminal state**，agent 与环境的交互永远持续，称为 **continuing tasks**——现实中找不到永远持续的任务，时间足够长的任务会近似当作 continuing tasks。

* **两类任务的统一处理**

    * 统一方法一：把 target state 当作特殊的 **absorbing state（吸收态）**——状态转移概率上，当前在 target 时不论采取什么 action 都回到该状态（或修改 action space 只剩"留在原地"），并且之后所有 reward 全为 0。

    * 统一方法二：把 target state 当作**普通的状态**——它也有策略，策略好就一直留在那收集正 reward，策略不好还可能跳出来；课程采用第二种，它更一般化（目标不区别对待、当一般状态学习），代价是耗费更多搜索。

## 马尔可夫决策过程

* **MDP 的三要素**

    * **集合（sets）**：状态集合（state space）、动作集合（action space）、reward 集合——从 $s$ 出发 take action $a$ 得到的 reward 一定来源于一个集合。

    * **概率分布（probability distribution）**：state transition probability（在 $s$ 采取行动跳到 $s'$ 的概率）、reward probability（在 $s$ take $a$ 得到 $r$ 的概率）。

    * **policy**：在状态 $s$ 下，策略告诉你采取 action $a$ 的概率是多少。

* **Markov property（马尔可夫性质）**

    * > **定义**：Markov 性质也叫 **memoryless property（无记忆性）**，即**和历史无关**。

    * 表达式：$p(S_{t+1} \mid S_t, A_{t+1}) = p(S_{t+1} \mid S_0, A_1, S_1, \ldots, S_t, A_{t+1})$——不管之前的历史，只要现在在 $S_t$、take $A_{t+1}$，跳到 $S_{t+1}$ 的概率就完全确定；同理，在 $S_t$ take $A_t$ 得到的 reward 也与历史无关。

* **MDP 三个关键词的记忆法**

    * **Markov** 对应 Markov property（memoryless property）；**decision** 对应 policy（decision 就是决定，决定就是策略）；**process** 对应从什么状态跳到什么状态、采取什么 action 等，由 sets 和 probability distribution 描述。

* **Markov process 与 MDP 的关系**

    * 网格世界可以画成图：每个圆对应一个状态，边对应采取 action 后的转移，边上的数字是转移概率（例如 $s_1$ 以 0.5 到 $s_2$、以 0.5 到 $s_3$）。

    * 这个图描述的是 **Markov process（马尔可夫过程）**；两者的关系：**如果 policy 确定了，policy 就和整个系统融为一体，MDP 自然就变成了马尔可夫过程**。

## Return 为什么重要：三个策略的定量对比

* **实验设置**

    * 三个策略环境完全相同，只在 $s_1$ 处的选择不同：策略 1 向下走、策略 2 向右走、策略 3 以 50% 概率向右、50% 概率向下；其它状态策略相同。直观上策略 1 最好（不进禁区）、策略 2 最差（必然进禁区）、策略 3 居中。

    * 从 $s_1$ 出发分别计算 discounted return：

    | 策略 | return | 直观判断 |
    | :--- | :--- | :--- |
    | 策略 1（向下） | $\dfrac{\gamma}{1-\gamma}$ | 最好，不进 forbidden area |
    | 策略 3（各 50%） | $-0.5 + \dfrac{\gamma}{1-\gamma}$ | 居中，有一定概率进去 |
    | 策略 2（向右） | $-1 + \dfrac{\gamma}{1-\gamma}$ | 最差，必然进去 |

    * 计算逻辑：策略 1 先得 0、到目标后一直 $+1$，提出 $\gamma$ 后数列求和得 $\frac{\gamma}{1-\gamma}$；策略 2 多了进入禁区的 $-1$；策略 3 两条轨迹的 return 各乘概率 0.5 再相加。

    * **数学上的不等式和直观一致**——建立数学与直觉关系的关键纽带就是 return。

* **从 return 到 expectation 的过渡**

    * 策略 3 的 return 严格来说已不是 return 的基本概念——return 针对一条轨迹定义，而这里对两条轨迹做的是**求平均值**，求平均就是求 **expectation**——这正是接下来 state value 的雏形。

## Bootstrapping：从自己出发迭代出答案

* **bootstrapping（自举）**

    * 设 $v_i$ 表示从 $s_i$ 出发的 return。把 $v_1 = r_1 + \gamma r_2 + \gamma^2 r_3 + \gamma^3 r_4 + \cdots$ 提出 $\gamma$，括号里正是 $v_2$，于是 $v_1 = r_1 + \gamma v_2$；同理 $v_2 = r_2 + \gamma v_3$、$v_3 = r_3 + \gamma v_4$、$v_4 = r_4 + \gamma v_1$。

    * 直观含义：从 $s_1$ 出发跳到 $s_2$，先得到 $r_1$；后面路还长，但知道从 $s_2$ 出发得到的 return 一定是 $v_2$——**一个状态的 value 依赖于其它状态的 value**。

    * > **定义**：Bootstrapping 就是我从自己出发，然后不断地迭代，得到我要的结果——虽然要求解 $v$ 却还要事先知道 $v$，看似死循环，实际有解。

    * 词源：bootstrap 本意是鞋帮上的带子；引申出的讽刺义是"拉着鞋带想把自己拉上天"这种异想天开；现代含义即"从自己出发不断迭代得到结果"。

* **矩阵形式与求解**

    * 把 $v_1, \ldots, v_4$ 的关系式整理成矩阵向量形式（注意 $v_2, v_3, v_4, v_1$ 的顺序要恢复）：

    $$v = r + \gamma P v$$

    * $v$ 是未知量；$r$ 是 immediate reward（已知）；$\gamma$ 已知；$P$ 矩阵已知（对应策略加状态转移）。移项求逆：

    $$v = (I - \gamma P)^{-1} r$$

    * 这个公式（针对简单确定性情形）实际上就是贝尔曼公式；matrix-vector form 非常有用——单看某一个式子不行，把所有式子组合到一起就容易求解和理解 state value。

## State Value 的正式定义

* **符号与随机变量**

    * 单步过程：$S_t$（当前状态）take $A_t$ 得到 $R_{t+1}$、跳到 $S_{t+1}$；$t$ 指当前时刻，$t+1$ 指下一时刻。有时也把 reward 写成 $R_t$（在 $S_t$ 采取 $A_t$ 得到的 reward 记作 $R_t$），两者无本质区别，只是习惯，一般写成 $R_{t+1}$。

    * $S$、$A$、$R$ **全是大写**代表它们是 **random variable（随机变量）**，可以做 expectation 等操作；单步过程推广到多步得到 **multi-step trajectory**，其 discounted return 用大写 $G_t$ 表示——因为各项都是随机变量，$G_t$ 也是随机变量。

    * 过程中每次跳跃由哪个概率决定：在 $S_t$ 采取什么动作由 **policy** 决定；得到什么 reward 由 **reward probability** 决定；跳到哪个状态由 **state transition probability** 决定。

* **state value（状态值）**

    * > **定义**：state value 就是 $G_t$ 的 expectation（期望值），即 $v_\pi(s) = \mathbb{E}[G_t \mid S_t = s]$——这是一个 **conditional expectation**（条件期望），当前状态要取具体值 $s$；全称 state-value function，记作 $v_\pi(s)$。

    * 它是 $s$ 的函数：从不同 $s$ 出发轨迹不同、discounted return 不同、求平均也不同。

    * 它也是**策略的函数**：本可写成 $v(s, \pi)$，为简单起见把 $\pi$ 放到下标写成 $v_\pi(s)$；不同策略得到不同轨迹、不同 return、进而不同的 state value。

    * "value" 不仅是一个数值，也代表**价值**：状态 value 大说明该状态有价值——从它出发会得到更多 return。

* **return 与 state value 的区别**

    * > **定义**：Return 是针对**单个 trajectory** 求的；state value 是对**多个 trajectory** 得到的 return 再求平均值。

    * 边界：如果一切都是确定性的、从某状态出发只能得到一条 trajectory，那么该状态的 return 和 state value 就一样。

* **用 state value 评价三个策略**

    * $\pi_1$、$\pi_2$ 下从 $s_1$ 出发只有唯一一条轨迹，state value 就等于该轨迹的 return；$\pi_3$ 有两条轨迹，state value 是两条轨迹 return 的平均值（概率乘到前面，即 expectation 的求法）。

    * 结果：$v_{\pi_1}$ 最大、$v_{\pi_2}$ 最小、$v_{\pi_3}$ 居中——state value 一登场，"评估策略"就有了正式的数学载体。

## 贝尔曼公式：推导与结构

* **Return 的拆分**

    * 把 discounted return 提出 $\gamma$，可以拆成两部分：

    $$G_t = R_{t+1} + \gamma\, G_{t+1}$$

    * 含义：$t$ 时刻能得到的 return，等于**立即拿到的 immediate reward**，加上**从下一时刻出发能得到的 return**（乘 discount rate）。

* **两个期望各个击破**

    * 两边取期望（期望对加号可拆开）：$v_\pi(s) = \mathbb{E}[R_{t+1} \mid S_t = s] + \gamma\, \mathbb{E}[G_{t+1} \mid S_t = s]$。

    * 第一项是 immediate reward 的均值：在状态 $s$ 有多个 action 可选，take $a$ 的概率是 $\pi(a \mid s)$，take 了 $a$ 得到 $r$ 的概率是 $p(r \mid s, a)$，按期望定义把概率乘取值全加起来：

    $$\mathbb{E}[R_{t+1} \mid S_t = s] = \sum_{a} \pi(a \mid s) \sum_{r} p(r \mid s, a)\, r$$

    * 第二项是 future reward 的均值：从 $s$ 出发跳到各 $s'$ 的概率加权 $v_\pi(s')$；其中"已知在 $s$ 条件下的期望"可以去掉条件 $s$——因为已经知道下一个状态是 $s'$，就不用关心之前处在什么状态，这个性质就是 **Markov 性质（memoryless）**。

    * 从 $s$ 跳到 $s'$ 的概率要把所有 action 上的概率加起来：$p_\pi(s, s') = \sum_{a} \pi(a \mid s)\, p(s' \mid s, a)$，于是 $\mathbb{E}[G_{t+1} \mid S_t = s] = \sum_{s'} p_\pi(s, s')\, v_\pi(s')$。

* **贝尔曼公式（Bellman equation）**

    * 代回两个期望得到 elementwise form：

    $$v_\pi(s) = \sum_{a} \pi(a \mid s) \Big[ \sum_{r} p(r \mid s, a)\, r + \gamma \sum_{s'} p(s' \mid s, a)\, v_\pi(s') \Big]$$

    * 简洁形式：$v_\pi(s) = r_\pi(s) + \gamma \sum_{s'} p_\pi(s, s')\, v_\pi(s')$，其中 $r_\pi(s)$ 是 immediate reward 的均值。

    * 它在干什么：描述**不同状态的 state value 之间的关系**——左边是 $s$ 的 state value，右边是 $s'$ 的 state value；式子包含两项：第一项 immediate reward 的 mean，第二项 future reward 的 term。

    * > **易错点** ⚠️：贝尔曼公式不是"一个"式子——它对状态空间中**所有**状态都成立，$n$ 个状态就有 $n$ 个式子，靠联立才能解出 state value；千万不要以为贝尔曼公式只有书上写的那一个式子。

    * > **易错点** ⚠️：右边出现了正是要算的 $v_\pi(s')$，看似死循环；求解靠 bootstrapping——把 $n$ 个式子联立起来解。

* **公式依赖什么**

    * $\pi(a \mid s)$ 就是 **policy**——贝尔曼公式**依赖策略**，不同策略得到不同 state value。

    * $p(r \mid s, a)$ 和 $p(s' \mid s, a)$ 是 **dynamic model（dynamic environment model，环境模型）**；知道模型时直接求解贝尔曼公式，不知道模型时也能求 state value——那就是 model-free reinforcement learning 的算法。

## 贝尔曼公式的例子：手写与求解

* **确定性策略例子**

    * 手写方法：不必硬套复杂公式，直观地看图就能写——$s_1$ 出发先得到 immediate reward $0$，跳到 $s_3$，所以 $v_\pi(s_1) = 0 + \gamma\, v_\pi(s_3)$；$s_2, s_3, s_4$ 类似，得到线性方程组。

    * 解方程组、代入 $\gamma = 0.9$ 得各状态 state value：

    | 状态 | $s_1$ | $s_2$ | $s_3$ | $s_4$ |
    | :--- | :---: | :---: | :---: | :---: |
    | state value | $9$ | $10$ | $10$ | $10$ |

    * 解读：state value 代表状态的**价值**，价值高值得往那个方向走；$s_2, s_3, s_4$ 离 target area 近所以价值高，$s_1$ 离得远所以是 9。算出 state value 之后下一步就可以改进策略，慢慢得到最优策略。

* **随机性策略例子**

    * $s_1$ 有两个方向可走（各 0.5 概率），手写：$v_\pi(s_1) = 0.5\,(-1 + \gamma v_\pi(s_2)) + 0.5\,(0 + \gamma v_\pi(s_3))$；解出 $s_1$ 的 state value 为 $8.9$（$s_2, s_3, s_4$ 仍为 $10$）。

    * $8.9 < 9$——**光靠比较 state value 就能比出两个策略的优劣**：这个策略没有上一个策略好。

## 矩阵-向量形式与两种求解方法

* **matrix-vector form（矩阵-向量形式）**

    * 给状态编号 $s_1$ 到 $s_n$，第 $i$ 个状态的贝尔曼公式为 $v_\pi(s_i) = r_\pi(s_i) + \gamma \sum_{j=1}^{n} p_\pi(s_i, s_j)\, v_\pi(s_j)$，全部装进一个式子：

    $$v_\pi = r_\pi + \gamma P_\pi v_\pi$$

    * $v_\pi$ 是向量 $(v_\pi(s_1), \dots, v_\pi(s_n))^\top$；$r_\pi$ 的每个分量是各状态 immediate reward 的均值；$P_\pi$ 是矩阵，元素 $[P_\pi]_{ij}$ 表示**从 $s_i$ 跳到 $s_j$ 的概率**，称为 **state transition probability matrix（状态转移概率矩阵）**。

    * 例：单向确定性策略下 $r_\pi$ 第一个分量是 0、$P_\pi$ 第一行只有 $s_1 \to s_3$ 为 1；两方向随机策略下 $r_\pi$ 第一个分量是 $0.5 \times (-1) + 0.5 \times 0$、$P_\pi$ 第一行 $s_1 \to s_2$ 和 $s_1 \to s_3$ 各为 0.5。

* **closed-form solution（解析解）**

    * 移项求逆得：

    $$v_\pi = (I - \gamma P_\pi)^{-1} r_\pi$$

    * 表达式很优美，但**实际当中不使用**——状态空间大时矩阵维数大，求逆计算量太大。

* **iterative solution（迭代解）**

    * 迭代格式：

    $$v_{k+1} = r_\pi + \gamma P_\pi v_k$$

    * 用法：第 0 步**随便猜**一个 $v_0$（比如全 0），代到右边算出 $v_1$，再代出 $v_2$、$v_3$……得到序列 $v_0, v_1, v_2, \ldots$；可以证明 **$k \to \infty$ 时 $v_k$ 收敛到真实的 $v_\pi$**（证明思路：定义 $v_k$ 与 $v_\pi$ 之间的误差 $\delta_k$，证明 $\delta_k \to 0$）。

## 策略评估

* **policy evaluation（策略评估）**

    * > **定义**：给定策略 $\pi$，通过列出并求解贝尔曼公式得到 $v_\pi$，用以评价该策略的好坏，这一过程称为 policy evaluation。

    * 它是强化学习当中非常关键的问题、非常基础的工具——**只有能评价一个策略好不好，才能进一步改进它，最后找到最优策略**。

* **评价效果的直观例证**

    * 好策略（不出界、不撞墙、不进禁区）：算出的 state value **全部为正数**，且**靠近 target area 的状态 state value 大、离得越远越小**。

    * 有两个策略只差两个格子的方向（一个往下走、一个往右走），最后算出的 state value **完全相同**——**不同的策略能够得到相同的 state value**。

    * 差策略：无论在哪个格子都向右走的策略，算出的 state value **全是负数**；随机生成的、常撞墙进禁区的策略，state value 也和直觉一致地差——计算 state value 就能**定量**评价策略好坏。

## Action Value

* **action value（动作值）**

    * > **定义**：$q_\pi(s, a) \triangleq \mathbb{E}[G_t \mid S_t = s,\ A_t = a]$——从当前状态 $s$ 出发、take action $a$ 之后所得到的 return 的 average；它是一个 state-action pair 的函数，同时依赖策略 $\pi$。

    * 与 state value 的区别：state value 是从一个**状态**出发的 average return；action value 是从一个**状态出发并且选择了一个 action**之后的 average return。

    * 为什么要关注它：策略说的是"在一个状态选什么 action"，选择依据就是 action value——action value 大意味着选那个 action 能得到更多 reward，就去选它。

* **state value 与 action value 的互相计算**

    * 从 state value 到 action value（state value 是各 action value 按策略的加权平均）：

    $$v_\pi(s) = \sum_{a} \pi(a \mid s)\, q_\pi(s, a)$$

    * 从 state value 算 action value（贝尔曼公式右边的长串正是 $q_\pi$）：

    $$q_\pi(s, a) = \sum_{r} p(r \mid s, a)\, r + \gamma \sum_{s'} p(s' \mid s, a)\, v_\pi(s')$$

    * 两个式子是一个硬币的两面：知道一个状态所有 action value，求平均得到该状态的 state value；知道所有状态的 state value，就能求出所有 action value。

* **手算示例**

    * 确定性情形直接写：$q_\pi(s_1, a_2) = -1 + \gamma\, v_\pi(s_2)$（往右得 $-1$，跳到 $s_2$）；$q_\pi(s_1, a_3) = 0 + \gamma v_\pi(s_3)$（往下得 0，跳到 $s_3$）。

    * > **易错点** ⚠️：策略没选的 action，很多人以为它的 action value 是 0——这不对。action value 的定义里 action 是被强制指定的，和策略选不选它无关；没被选的 action 的 action value 照样存在、照样可算，而且未来选 action 靠的正是比较**所有** action 的 action value、挑最大的那个（策略改进的思想）。

* **计算 action value 的两种途径**

    * 第一种：先求解贝尔曼公式得到 state value，再按上面的表达式从 state value 算出 action value（依赖模型）。

    * 第二种：**不经过 state value、直接计算 action value**——比如通过数据的方式，可以不依赖模型。

* **用 action value 改进策略**

    * 例子：当前策略在 $s_1$ 往右走进禁区（不太好）；算出 $s_1$ 的 5 个 action 的 action value 后发现 $a_3$（往下走）最大，就构造新策略——对 $a = a^*$ 概率为 1、其它概率为 0（一定选 $a^*$）——新策略绕开了禁区。

    * 直观解释：action value 本身代表 action 的价值，选 action value 大的 action 意味着之后能得到更多 reward，策略自然好。

    * 数学上的疑问：这个例子太简单（其它状态的策略恰好已是最优）；如果其它状态的策略都不是最优的，在 $s_1$ 选 action value 最大的是否仍能得到最优 action？答案：**只要一遍一遍地做、不断迭代（每个状态都选 action value 最大的 action），最后一定趋向最优策略**——这超出了直观理解的范围，需要数学工具，即贝尔曼最优公式。

## 贝尔曼最优公式

* **最优策略与最优 state value 的定义**

    * 先定义"更好"：两个策略 $\pi_1$、$\pi_2$，若**对所有状态 $s$** 都有 $\pi_1$ 的 state value 大于等于 $\pi_2$ 的，则 $\pi_1$ 比 $\pi_2$ 好。

    * > **定义**：若对任意状态 $s$ 都有 $v_{\pi^*}(s) \geq v_{\pi}(s)$（$\pi$ 为任意其它策略），则称 $\pi^*$ 为最优策略（optimal policy）；对应的 $v_{\pi^*}$ 称为最优 state value（optimal state value）。

    * 定义之后必须回答的问题：最优策略**是否存在**（会不会只存在"某些状态上赢、另一些状态上输"的策略）？**是否唯一**？是 **stochastic 还是 deterministic**？**怎么得到**？——把贝尔曼最优公式研究透了，这些问题全都能回答。

* **贝尔曼最优公式（Bellman optimality equation）的形式**

    * 它是贝尔曼公式的特殊情况：在贝尔曼公式前面加上 $\max_\pi$——

    $$v(s) = \max_{\pi} \; \big[ r_\pi + \gamma P_\pi v \big]$$

    * elementwise 形式（在原贝尔曼公式外套 $\max_\pi$，右边长串可缩写成 $q(s,a)$）：

    $$v(s) = \max_{\pi} \sum_{a} \pi(a \mid s) \Big[ \sum_{r} p(r \mid s, a)\, r + \gamma \sum_{s'} p(s' \mid s, a)\, v(s') \Big]$$

    * 加了 $\max_\pi$ 之后 $\pi$ **不再是给定的**——右边**嵌套了一个优化问题**：要先解决这个优化问题、求出最优的 $\pi$，再代回式子。

    * 已知与未知：已知的是模型对应的概率、reward、$\gamma$；要求解的是 $v$；普通贝尔曼公式里 $\pi$ 一定给定，而贝尔曼最优公式里 $\pi$ 必须求解——相当于一个式子要求两个未知量。

    * > **提示**：贝尔曼最优公式既 elegant（形式简洁，却能同时刻画最优策略和最优 state value）又 tricky（右边镶嵌了最优化问题，求解和理解都不直观）。

* **处理右边 max 的两个小例子**

    * 例一：$x = \max_{a} \{ 2x - 1 - a^2 \}$。分两步：先求右边对 $a$ 的最优值（$-a^2$ 非正，$a = 0$ 时最大，最优值为 $2x - 1$）；再把达到最优值的 $a$ 代回去，$x = 2x - 1$ 解得 $x = 1$、$a = 0$。这个思路可以直接放到求解贝尔曼最优公式中。

    * 例二：给定 3 个 $q$ 值 $q_1, q_2, q_3$，求权重 $c_1, c_2, c_3$ 使 $c_1 q_1 + c_2 q_2 + c_3 q_3$ 最大，约束为 $c_1 + c_2 + c_3 = 1$ 且各 $c_i \geq 0$（这些约束来自**系数就是概率 $\pi$**）。设最大值是 $q_3$，最优解是 $c_3 = 1$、$c_1 = c_2 = 0$。

    * 例二的数学解释：由 $c_1 + c_2 + c_3 = 1$ 得 $q_3 = (c_1 + c_2 + c_3) q_3 = c_1 q_3 + c_2 q_3 + c_3 q_3 \geq c_1 q_1 + c_2 q_2 + c_3 q_3$——因为 $q_3$ 最大，每一项把 $q_3$ 换成 $q_1$ 或 $q_2$ 只会变小或不变，所以不论权重怎么取都超不过 $q_3$，等号恰在 $c_3 = 1$ 时取到。

* **核心结论**

    * > **定义**：当右边的 $q$ 值确定之后，$\max_\pi$ 项的最优值就等于**最大的那个 $q$ 值**；取到最优值的 $\pi$ 是——对 $a^*$（对应最大 $q$ 值的 action）概率为 1、对其它 action 概率为 0。

    * 直观解释：$c_3$ 是 $q_3$ 的权重，$q_3$ 最大就把所有权重全部押上去，总和才最大。

    * 这把"每个状态都选 action value 最大的 action"这个贪心直觉，从"看起来合理"变成了"数学上严格成立"的第一步；由此贝尔曼最优公式的求解、解的存在性与唯一性可以一层层打开。
