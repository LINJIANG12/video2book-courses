# 动态规划求解：贝尔曼最优性、值迭代与策略迭代

## 不动点与收缩映射

* **不动点（fixed point）**

    * > **定义**：映射 $f$ 若满足 $f(x^*)=x^*$，则 $x^*$ 是一个不动点——点经过映射又回到自身、不再移动。

    * 标量例：$f(x)=0.5x$ 时 $x=0$ 是不动点，因为 $0=0.5\times 0$。
    * 向量例：$f(x)=Ax$（$A$ 为矩阵）在矩阵范数小于 1 时，不动点同样是 0。

* **收缩映射（contraction mapping）**

    * > **定义**：函数满足 $\|f(x_1)-f(x_2)\|\le\gamma\|x_1-x_2\|$ 且 $\gamma<1$——任意两点的像之间的距离，比两点本来的距离乘一个小于 1 的因子还要近。

    * 判定例：$f(x)=0.5x$ 提出公因子 0.5，$\gamma$ 取任何小于 1 的数都成立，是收缩映射。
    * 向量判定：$f(x)=Ax$ 在矩阵范数小于 1 时是收缩映射。
    * 名称由来：映射后两点互相靠拢，即"收缩"（contractive）。

* **收缩映射定理（contraction mapping theorem）**

    * 前提：$f$ 是收缩映射，不关心 $f$ 的具体表达式。
    * 存在性：$x=f(x)$ 一定存在不动点 $x^*$。
    * 唯一性：该不动点唯一。
    * 可求解性：从任意 $x_0$ 出发按 $x_{k+1}=f(x_k)$ 迭代，$k$ 趋向无穷时 $x_k$ 收敛到 $x^*$；实际只需有限步即可得到满意结果。
    * 收敛速度：指数收敛。
    * 适用面：一切形如 $x=f(x)$ 的求解问题都能用它。

## 贝尔曼最优公式的解及其最优性

* **化简形式 $v=f(v)$**

    * 机理：固定 $v$ 求 $\max_\pi$，解出的策略必是 $v$ 的函数，把右边整体记作 $f(v)$，贝尔曼最优公式化为 $v=f(v)$。
    * $f(v)$ 是向量，每个分量对应逐状态的贝尔曼最优表达式。
    * 表达式有两种形式：逐元素形式（elementwise form）与矩阵—向量形式（matrix-vector form），前者用于实现与编程、后者用于理论分析。

* **求解结论**

    * 关键事实：$f$ 满足 $\|f(v_1)-f(v_2)\|\le\gamma\|v_1-v_2\|$，$\gamma$ 就是折扣率——此前规定 $\gamma<1$ 的伏笔在此兑现，故 $f$ 是收缩映射。
    * 存在性：贝尔曼最优公式的解 $v^*$ 一定存在。
    * 唯一性：$v^*$ 唯一。
    * 可解性：迭代 $v_{k+1}=f(v_k)$ 即可求出 $v^*$，$v_k$ 收敛到 $v^*$。

* **解的最优性**

    * 设 $\pi^*$ 是固定 $v^*$ 后解 $\max$ 得到的策略，则 $v^*=r_{\pi^*}+\gamma P_{\pi^*}v^*$ 恰是 $\pi^*$ 对应的贝尔曼公式，于是 $v^*=v_{\pi^*}$——贝尔曼最优公式是一个特殊的贝尔曼公式，只是它对应的策略特殊：是最优策略。
    * 最优性支撑：任何其它策略得到的 state value 都没有 $v^*$ 大；$\pi^*$ 因 $v_{\pi^*}=v^*$ 达到最大而是最优策略。
    * $\pi^*$ 的形态：在每个状态对 action value 最大的动作 $a^*$ 给概率 1、其余动作概率全 0——既是确定性策略（deterministic）又是贪婪策略（greedy）。

    * > **易错点** ⚠️：最优的 state value 唯一，但对应这个最优 state value 的最优策略不一定唯一。

## 最优策略由什么决定

* **决定因素**

    * 规则：最优策略与最优 state value 由三样决定——reward 的设计 $r$、折扣率 $\gamma$、系统模型（概率 $p$）；模型一般难以改变，实际可拧的旋钮是 $r$ 与 $\gamma$。
    * 求解贝尔曼最优公式，就是在已知 $p$、$r$、$\gamma$ 的条件下解出最优策略与最优 state value。

* **$\gamma$ 由大到小：从远视到极度短视**

    * 基准（$\gamma=0.9$，出界 $-1$、进 forbidden area $-1$、到 target $+1$）：最优策略直接穿过 forbidden area 而不绕行——穿过去虽有即时惩罚，长远 return 比绕大圈更大。
    * $\gamma$ 降到 0.5：策略改为绕大圈避开 forbidden area。机理：$\gamma$ 大时 agent 远视、重视未来的 reward；$\gamma$ 小时未来 reward 打折非常厉害，agent 近视，return 大小主要由近期 reward 决定。
    * $\gamma=0$：在 $G_t=R_{t+1}+\gamma R_{t+2}+\gamma^2R_{t+3}+\cdots$ 中后续项全为 0，return 退化为 immediate reward，策略极度短视（extremely short-sighted），只选 immediate reward 最大的动作，很多状态到不了 target area；例外是紧邻 target 的格子仍会走进 target——正奖励大于原地不动的 $-1$ 惩罚。

* **加重惩罚：拧另一个旋钮**

    * 仅把 forbidden area 的奖励从 $-1$ 加重到 $-10$（$\gamma$ 仍为 0.9）：策略绕开 forbidden area；$\gamma$ 从 0.9 变 0.5 时同样避开。
    * 即"让 agent 避开 forbidden area"这个目的，调 $\gamma$ 或加重惩罚两条路都通。

| 改动的量 | 改动内容 | 最优策略的行为 |
| :--- | :--- | :--- |
| $\gamma$ | $0.9\to 0.5$ | 从穿过 forbidden area 改为绕大圈避开 |
| $\gamma$ | 降到 $0$ | 极度短视，很多状态到不了目标 |
| $r$ | forbidden 由 $-1$ 加重到 $-10$ | 即便 $\gamma=0.9$ 也绕开 forbidden area |

* **reward 仿射变换 $ar+b$：最优策略不变**

    * 规则：所有 reward 改为 $ar+b$ 后最优策略不变；新旧贝尔曼最优公式的解满足 $v'=a\,v^*+b$，由 $v'$ 求出的 action value 也呈同样变换。
    * 机理：选最优策略只看 action value 的相对值、不看绝对值——原值 1、2、1 变成 100、200、100 仍选 200 那个。
    * 边界：加偏置 $b$ 时，隐含的 $r_{otherstep}=0$（从一个白格走到另一个白格无奖惩）也要同样加 $b$。

* **$\gamma$ 是隐形的每步惩罚**

    * 规则：白格之间 reward 为 0 时策略也不会绕远路——直接到达得到 $1,\ \gamma\cdot1,\ \gamma^2\cdot1,\ldots$；绕路则正奖励前面多出 0、整体多乘一个 $\gamma$ 的幂，state value 变小，所以自然选最短路径。
    * > **提示**：不需要靠"每步负奖励"去阻止绕路，折扣因子 $\gamma$ 本身就惩罚了绕路——晚到一步，未来的正奖励多乘一个小于 1 的因子。

## 值迭代

* **值迭代（value iteration）**

    * > **定义**：求解贝尔曼最优公式的迭代算法 $v_{k+1}=\max_\pi(r_\pi+\gamma P_\pi v_k)$，是 model-based 的强化学习算法。

    * 每轮两步：policy update——给定 $v_k$ 求解优化问题得 $\pi_{k+1}$；value update——把 $\pi_{k+1}$ 代回，由 $v_k$ 一步求出 $v_{k+1}$。
    * 初值：$v_0$ 任意选取（如全 0）。
    * 停止判据：$v_k-v_{k-1}$ 小于一个很小的数（如 0.001）即认为收敛——再往下怎么努力都没法改变了。
    * 理论依据：收缩映射定理，指数收敛。

    * > **易错点** ⚠️：$v_k$ 不是 state value。若方程左右都是 $v_k$，它才是贝尔曼公式对应的 state value，但左边是 $v_{k+1}$；$v_k$ 只是任意的一个值向量——这也是"值迭代"这个名字的由来。

* **逐元素形式**

    * policy update：由 $v_k$ 算出每个 $(s,a)$ 的 $q_k(s,a)$，新策略取 $q_k$ 最大的动作 $a_k^*$（概率 1、其余 0），是确定性 greedy 策略，只寻求最大的 q-value。
    * value update：$v_{k+1}(s)=\max_a q_k(s,a)$，新值就是最大的那个 $q_k$。
    * 一轮迭代的流程：

    ```text
    v_k ──> 算出所有 q_k(s,a) ──> 找最大 q_k ──┬─> policy update：greedy 策略 π_{k+1}
                                              └─> value  update：v_{k+1}(s) = 最大 q_k ──> 下一轮
    ```

* **实现要点与实例**

    * 必备能力：给定 $v$ 能算出全部 $q$（q-table）——编程时不一定真存这张表，但这个计算能力必须有。
    * 实例：简单网格世界从全 0 初值出发，第一步多数状态已达最优、个别状态未达最优，第二步补齐——两步迭代即找到最优策略；问题复杂时需要更多迭代步。

## 策略迭代

* **策略迭代（policy iteration）**

    * > **定义**：从任意初始策略 $\pi_0$（可以是很不好的策略）出发，交替执行策略评估与策略改进直到收敛的 model-based 算法。

    * policy evaluation（策略评估，PE）：给定 $\pi_k$，求解它对应的贝尔曼公式得 $v_{\pi_k}$——以此评估该策略。
    * policy improvement（策略改进）：给定 $v_{\pi_k}$ 求解 max 优化问题得 $\pi_{k+1}$，必有 $v_{\pi_{k+1}}\ge v_{\pi_k}$——新策略一定不比旧策略差，故名改进。

* **策略评估的两种解法**

    * 闭式解（closed-form solution）：理论可用，但涉及矩阵求逆，不常用。
    * 迭代解（iterative solution）：先给一个初始猜测 $v_{\pi_k}^{(0)}$，按 $v_{\pi_k}^{(j+1)}=r_{\pi_k}+\gamma P_{\pi_k}v_{\pi_k}^{(j)}$ 迭代至收敛，是常用方式。
    * 结构特点：策略迭代是大的迭代算法，其中策略评估这一步内嵌一个小的迭代算法。

* **收敛性**

    * 直观：每轮都有 policy improvement，$v_{\pi_0}$ 不好、$v_{\pi_1}$ 好一点、$v_{\pi_2}$ 更好，逐步逼近；而最好的就是贝尔曼最优公式的解 $v^*$。
    * 数学结果：$k$ 趋于无穷时 $v_{\pi_k}$ 一定收敛到 optimal state value，策略也收敛到一个最优策略。
    * 证明基础：策略迭代的收敛证明用到了值迭代的收敛结果。

* **逐元素实现**

    * 评估步：初始猜测任意，内层迭代至 $v_{\pi_k}^{(j)}$ 收敛即得 $v_{\pi_k}$。
    * 改进步：遍历所有状态与动作，由 $v_{\pi_k}$ 求 $q_{\pi_k}$，新策略取最大 $q_{\pi_k}$ 对应的动作（与值迭代的选法相同）；得 $\pi_{k+1}$ 后回到评估步循环。

* **实例与现象**

    * 两格子小例：初始策略全往左；一次迭代（评估 + 改进）即得最优策略——左格往右、target 格不动；问题简单时一个 iteration 就够，复杂时需多个。
    * $5\times5$ 网格大例（$r_{forbidden}=-10$）：中间过程的策略多不好，到第十轮收敛为最优——从任何一点出发都能到达目标区域，且避开 forbidden area。
    * 规律：接近目标的状态策略先变好，远离目标的状态策略后变好。直观原因：某状态选 greedy action 的意义严重依赖其它状态的策略——周围有能到达目标的策略时，本状态的新策略也能到达；最优性从目标附近一圈一圈向外扩散。

## 值迭代与策略迭代的对照

| 对比项 | 值迭代 | 策略迭代 |
| :--- | :--- | :--- |
| 出发点 | 初始值 $v_0$（任意值），没有初始策略 | 初始策略 $\pi_0$（可能不好） |
| 每轮两步 | policy update + value update | policy evaluation + policy improvement |
| 对值的处理 | 每轮只做一步值更新，不解贝尔曼方程 | 内层迭代把 $v_{\pi_k}$ 解到收敛 |
| 值的身份 | $v_k$ 不是 state value，只是任意值 | $v_{\pi_k}$ 是当前策略真实的 state value |
| 收敛依据 | 收缩映射定理（指数收敛） | 证明用到了值迭代的收敛结果 |
| 关系 | 同为截断策略迭代的两个极端 | 同为截断策略迭代的两个极端 |

* 驱动机制相同：两个算法的策略更新都由"选最大 q 值的 greedy 动作"驱动，区别只在每轮对值的处理深度。

## 截断策略迭代

* **截断策略迭代（truncated policy iteration）**

    * > **定义**：值迭代与策略迭代的一般化推广——策略评估的内层迭代只执行有限 $j$ 步，把 $v_{\pi_k}^{(j)}$ 直接当作新值投入下一步策略改进。

    * 谱系：$j=1$ 退化为值迭代；$j=\infty$ 退化为策略迭代；中间任何有限的 $j$ 都是截断策略迭代。
    * 命名缘由：从第 $j$ 步到无穷的那些内层迭代全部被截断。

    ```text
    初始 v_{πk}^(0)
      ├─ 迭代 1 步 ──> v_{πk}^(1)           ← 值迭代取这里
      ├─ 迭代 j 步 ──> v_{πk}^(j)           ← 截断策略迭代取这里
      └─ 迭代 ∞ 步 ──> v_{πk}^(∞) = v_{πk}  ← 策略迭代取这里
    ```

* **为什么截断可行**

    * 收敛结果：内层迭代的初始值取 $v_{\pi_{k-1}}$ 时，可证 $v_{\pi_k}^{(j+1)}$ 一定比 $v_{\pi_k}^{(j)}$ 大——算一次也增大、算 $j$ 次也增大，无须无穷多步。
    * 值的排序：从同一起点出发，截断策略迭代每轮的值介于两者之间——比值迭代的 $v_k$ 好，比策略迭代的 $v_{\pi_k}$ 稍差，三者都收敛到 $v^*$。
    * 伪代码：与策略迭代一模一样，唯一区别是把"判断 state value 是否收敛"改成"判断内层迭代是否执行够了指定次数"；截断参数可事先设为 1、2、100、1000 等任意值。

    * > **注意**：策略迭代只在理论上存在——它要求计算无穷多步；实际中即便用"$v_{\pi_k}^{(j)}$ 与 $v_{\pi_k}^{(j-1)}$ 误差足够小就停止"，计算的仍是有限步，所以实际想执行策略迭代时，它一定是迭代的、截断的。

## 蒙特卡洛估计的基本思想

* **从 model-based 到 model-free**

    * 值迭代与策略迭代在本课程中统称 model-based reinforcement learning；更准确的说法应是 dynamic programming（动态规划）方法。
    * 注意：近年兴起的 MBRL（model-based reinforcement learning）研究的是用数据估计出一个模型、再基于模型做强化学习，与本课程的用法不是一回事，只是沿用了宽泛叫法。
    * 蒙特卡洛方法是课程中第一次出现的 model-free 方法；思路是把策略迭代中依赖模型的部分替换成不需要模型的部分。

* **蒙特卡洛估计（Monte Carlo estimation）**

    * > **定义**：凡是需要做大量采样和实验、然后用实验结果来进行近似的方法。

    * 抛硬币例：$X=+1$（正面）、$X=-1$（反面）。model-based 路线：已知分布 0.5/0.5，按定义 $E[X]=0.5\times(+1)+0.5\times(-1)=0$；局限在于这么精确的概率分布（模型）往往无法知道。
    * model-free 路线：投掷 $N$ 次得 $x_1,\ldots,x_N$，用平均 $\bar{x}=\frac{1}{N}\sum_{j=1}^{N}x_j\approx E[X]$；$N$ 小时近似不精确，$N$ 增大越来越精确。
    * 理论支撑：大数定理（Law of Large Numbers）。对 $N$ 个 iid（independent and identically distributed）样本有 $E[\bar{x}]=E[X]$、$\mathrm{Var}[\bar{x}]=\frac{1}{N}\mathrm{Var}[X]\xrightarrow{N\to\infty}0$——$\bar{x}$ 是无偏估计，且 $N$ 增大时收敛到期望。
    * 用在这里的原因：state value 与 action value 的定义本来就是 expectation，即 mean estimation 问题，不需要模型。

## MC Basic

* **MC Basic**

    * > **定义**：把策略迭代中基于模型的模块替换为蒙特卡洛估计，得到的最简单的基于蒙特卡洛的 model-free 强化学习算法。

    * 每轮两步：policy evaluation——对**所有** $(s,a)$，从该组合出发按当前策略生成很多 episode，对 episode 的 discounted return 求平均，估计 $q_{\pi_k}(s,a)$；policy improvement——选 action value 最大的动作作为新策略（与策略迭代的改进步一模一样）。
    * 与策略迭代的唯一区别在评估步：策略迭代先求 state value 再转成 action value；MC Basic 直接通过数据得到 $q_{\pi_k}$。
    * 不先估 state value 的原因："从 state value 转到 action value"这一步依赖模型，肯定不行；所以直接把 action value 估计出来。
    * 收敛性：与策略迭代结构相同、只差估计 action value 的方法，收敛性仍能保证。
    * 定位：有用但不实用——效率比较低；价值在于清晰揭示"怎么把 model-based 变成 model-free"这一最核心的思想，后续更高效的算法（数据利用效率更高、去掉难实现的假设）都是它复杂化的产物。

    * > **提示**：没有模型的时候得有数据，没有数据的时候得有模型——反正总得有一个。数据在统计或概率里叫 sample，在强化学习里有一个特殊的名字：experience（经验）。

* **核心替换：用期望的定义替代依赖模型的计算**

    * 求 $q_{\pi_k}$ 的两条路：依赖模型——先求出 $v_{\pi_k}$，再利用已知模型求出 $q_{\pi_k}$；不依赖模型——按定义 $q_{\pi_k}(s,a)=E[G_t\mid S_0=s,\ A_0=a]$，用采样均值 $q_{\pi_k}(s,a)\approx\frac{1}{N}\sum_{i=1}^{N}g_i(s,a)$ 近似。
    * $G_t$ 是随机变量，$g(s,a)$ 是它的一次采样。

* **算例要点**

    * 规模示例：9 个状态 × 5 个动作 = 45 个 state-action pair，每个 $(s,a)$ 从出发采 $n$ 条轨迹求平均，共需 $45n$ 条轨迹。
    * 采样次数判定：policy 与环境都是 deterministic 时，不管采样多少次轨迹都相同，每个 $(s,a)$ 采一次即可；policy 是 stochastic 的、或环境 stochastic 时，不同次采样得到不同轨迹，需多次采样求平均。
    * 实例表现：一次迭代即找到最优策略——例子本身简单，且该状态邻域的 state 的 policy 已达最优。

## episode 长度：探索的半径

* **长度不足的后果**

    * 规律：episode length 短时，只有离目标比较近的状态才能在这么短的步骤内找到目标、得到正确策略；随 length 增大，离目标越来越远的状态陆续变好。
    * 例中表现：length=1 时只有紧邻目标的状态 value 为正、策略正确，其余状态 value 全 0；length=2 时多两个状态正确，但出现"看似正确实则随机"的状态——几个动作的 action value 都是 0，只是刚好随机选了其中一个，value 为 0 说明它根本没到达目标（到达需要 3 步）；length=3 时该状态 value 变正、策略正确。
    * 后段表现：length=14 时从某角落需整整 14 步才能到达目标的状态 value 转正、策略正确；length=15 时最后一个未到达的状态也到达；length=30 或 100 时策略基本不变，只有 optimal state value 的估计值还在变化，length 很大时估计值与真值基本一样。
    * 判定方式：某状态的 value 是否为正——为正说明它的策略能到达目标（到达目标才会得到正奖励）。

    * > **注意**：value 为 0 的状态即使策略看起来是对的，也是随机产生的——它根本没有到达过目标。

* **长度的选取**

    * 理论上 episode 越长 return 估计越精确、最好无穷长；但网格世界这类没有终止条件的问题，若不人为设置长度会一直持续下去。
    * 边界：length 必须足够长，让所有状态都有机会到达目标；同时不需要无限长，足够充分地长就可以，具体问题具体分析。
    * 直观理解：episode length 可以理解为探索半径的长度——半径够不到的目标，从该状态出发的策略一定是错的；半径能探测到目标，就知道该往哪个方向走。

## 数据利用与 MC Exploring Starts

* **visit（访问）**

    * > **定义**：episode 当中每出现一次某个 state-action pair，就称为对这个 pair 的一次 visit。

    * MC Basic 采用 initial-visit：对一个 episode 只考虑最开头那个 $(s,a)$，用整条 episode 的 return 估计它的 $q$——episode 里其余数据被浪费。
    * 推广思路：从 episode 中任意被访问的 pair 起，截出它后面的一段当作新 episode，估计该 pair 的 action value——一条 episode 能喂多个 $(s,a)$，数据利用充分。
    * 两种变体：every-visit——只要访问到就截段估计，同一 pair 第一次、第三次出现都用；first-visit——只用第一次出现，之后再出现不再使用其后面部分。

* **更新时机与 GPI**

    * MC Basic 的做法：把从一个 $(s,a)$ 出发的所有 episode 全部收集齐、求 average return 再改进——等待的过程浪费时间。
    * 更高效做法：得到一个 episode 就立刻用它的 return 估计 action value，不停不等，马上改进一次策略——一个 episode 改进一次。
    * 可行性依据：单条 episode 估计显然不精确但没有关系——与截断策略迭代"评估不做满无穷步仍有效"是同一思想。

    * > **定义**：generalized policy iteration（GPI）——不是一个具体的算法，而是一大类算法、一种思想架构：在 policy evaluation 与 policy improvement 之间不断切换，且 policy evaluation 不需要非常精确地把 value 估计出来；值迭代、策略迭代、截断策略迭代与蒙特卡洛算法都能落进这个框架。

* **MC Exploring Starts**

    * > **定义**：MC Basic 的推广，在"更高效利用数据"与"更高效更新策略"两个方向上让计算效率更高的蒙特卡洛算法。

    * 实现技巧：从 episode 后端倒推计算 return——已知后段的 return $g$ 时，$g\leftarrow r+\gamma g$（$r$ 为前一 pair 的 immediate reward）即得前一个 pair 的 return，逐对倒推，避免把后面所有 reward 重复加一遍。
    * exploring 的含义：从每一个 $(s,a)$ 出发都要有 episode——若恰有一个 pair 没被访问，就可能漏掉那个 action，而它恰恰可能是最优的，得不到最优策略。
    * starts 的含义：覆盖每个 $(s,a)$ 有两种途径——从它开始一个 episode（start），或其它 episode 能经过它（visit）；visit 依赖策略与环境、无法确保，所以只能用"确保从每一个 $(s,a)$ 开始都有一个 episode"这个办法。
    * 边界：exploring starts 重要且必要，但在实际当中难以实现（例如要把真实机器人搬运到每个起点、设置好程序），理论与实际之间存在 gap；去掉该条件的出路是 soft policies，对应算法为 MC ε-Greedy（具体机制长文未说明）。
