# 值函数近似与深度强化学习

## 表格表示的局限与函数近似的动机

   * **表格表示（tabular representation）**

       * > **定义**：把 state value 或 action value 全部存进表里——$q_\pi(s,a)$ 是以 $s$、$a$ 为两个索引的二维表，$v_\pi$ 对应一个一维表；编程时实际重组为向量、矩阵或数组。

       * 优点：非常直观，分析起来简单。

       * 缺陷一（存储）：无法处理非常大的 state space 或 action space；状态空间连续时更处理不了——离散化总有 dilemma：网格太密处理吃力，太疏又不能很好近似连续空间。

       * 缺陷二（泛化）：必须把每个 state-action pair 全都访问到才能估计出值；数量太多时不可能全访问，很多状态的值就估计不到。

   * **值函数近似（value function approximation）**

       * > **定义**：用一个带参数 $w$ 的函数去拟合 $v_\pi(s)$，即 parameterized function，$w$ 是参数。

       * 两个好处：一是节省存储——只存维数很低的 $w$，不用存每个状态的值；二是泛化能力——不用访问所有状态，相邻状态的值也能被较准地估计出来。

## 三个算法各自估计什么

| 算法 | 与值函数近似结合后估计什么 |
| :--- | :--- |
| 时序差分方法 | 一个给定策略的 state value $v_\pi$ |
| Sarsa | 一个策略的 action value $q_\pi$ |
| Q-learning / Deep Q-learning | 最优 action value $q^*$ |

## 曲线拟合例子：从离散点到一条曲线

   * **特征向量（feature vector）与参数向量（parameter vector）**

       * 设 $n$ 个状态 $s_1,\dots,s_n$，每个状态对应一个 state value，即一串离散的点；状态太多时全部存储内存代价大，于是想用一条曲线把点串起来——曲线对应的参数个数非常少。

       * 最简单用直线 $as+b$ 拟合，写成两个向量相乘的形式：

       $$\hat v(s,w) = \phi^T(s)\,w$$

       * $w$ 叫参数向量，$\phi$ 叫特征向量；$\hat v$ 中的 hat 表示估计，$v$ 表示对值的近似。此形式下 $\hat v$ 对 $w$ 是**线性**的。

   * **代价与权衡**

       * 只需保存 $w$（两个参数）即可表示所有状态的值——先算 $\phi(s)$，再乘 $w$ 得 $\hat v$，极大节省内存。

       * 代价是**近似不那么精确**：点本来不严格在一条直线上，估计值与真值有较大差距——这正是叫 approximation 的原因。

       * 提高阶数：二阶曲线 $\hat v = as^2+bs+c$ 同样可写成 $\phi^T(s)w$，$\phi$ 和 $w$ 维数增加、存储变多，但拟合精度可能提高。此时函数对 $s$ 是非线性的，对参数仍线性——非线性都放进了 feature vector 里。

       * 核心权衡：**参数多少与拟合精度之间的 tradeoff**，这条线贯穿整个值函数近似，包括神经网络。

   * **泛化能力的机理**

       * 表格形式：某 episode 访问了 $s_2$ 只更新 $s_2$ 的值，未访问的 $s_1$、$s_3$ 纹丝不动。

       * 函数形式：访问 $s_2$ 后**改变的不是 $s_2$ 的值而是 $w$**；$w$ 一变整条函数曲线都变，于是 $s_1$、$s_3$ 虽未被访问，值也跟着变了。

       * > **定义**：泛化能力——只访问部分状态，相邻状态的值自然也能较准确地被估计出来。

## 目标函数：误差按什么权重平均

   * **目标函数**

       * 给定策略 $\pi$，找最优的 $w$ 使 $\hat v$ 尽可能接近 $v_\pi$——这本质是一个 policy evaluation 问题。路径：先估计 state value，再推广到 action value，再得到最优策略。

       * 找最优 $w$ 分两步：第一步正式定义目标函数，第二步优化它。

       $$J(w) = \mathbb{E}\left[\left(v_\pi(s) - \hat v(s,w)\right)^2\right]$$

       * $s$ 是随机变量，必有概率分布——expectation 本质是求平均，问题就变成：**对所有状态怎么个平均法**。有两种选取。

   * **平均分布（uniform distribution）**

       * 把所有状态视为 equally important，各占权重 $1/n$：

       $$J(w) = \frac{1}{n}\sum_{i=1}^{n}\left(v_\pi(s_i) - \hat v(s_i,w)\right)^2$$

       * 即所有状态估计误差的平方和再求平均。

       * 问题：它假设所有状态平等，但实际不一定——比如目标是到达目标状态，则目标附近的状态更重要，应给更大权重（权重大意味着估计误差更小）。

   * **平稳分布（stationary distribution，$d_\pi$）**

       * 值函数近似实际使用的分布。它描述 long-run behavior：按策略与环境交互非常多次后达到平稳状态，此时 agent 在每个状态出现的概率确定，$d_\pi(s)$ 即该概率。

       * 代入后目标函数为：

       $$J(w) = \sum_{s} d_\pi(s)\left(v_\pi(s) - \hat v(s,w)\right)^2$$

       * $d_\pi(s)$ 扮演权重：被访问概率大的状态，希望它的估计误差更小。它满足每处 $\ge 0$ 且总和为 1。

       * 又称 steady-state distribution 或 limiting distribution（极限分布）；在值函数近似与后面的 policy gradient 中定义目标函数时都会出现。

   * **平稳分布的计算与仿真**

       * 数值近似：跑一个很长的 episode，用比值 $n_\pi(s)/\text{episode 总步数}$ 近似 $d_\pi(s)$；随步数增多各比值趋于平稳。例中最常被访问的状态比值收敛到约 0.7。

       * 精确计算：$d_\pi$ 是状态转移矩阵 $P_\pi$（贝尔公式 matrix-vector form $v_\pi = r_\pi + \gamma P_\pi v_\pi$ 中的矩阵）**左边特征值等于 1 的特征向量**；算出上述状态的值为 0.72，与仿真的 0.7 基本一致。

## 梯度下降与真值的两次替换

   * **真实梯度（true gradient）**

       * 要 minimize 目标函数，用梯度下降：

       $$w_{k+1} = w_k - \alpha_k \nabla_w J(w_k)$$

       * 把求导移进 expectation 并整理，得 true gradient：

       $$\nabla_w J(w) = \mathbb{E}\left[\left(v_\pi(s) - \hat v(s,w)\right)\nabla_w \hat v(s,w)\right]$$

   * **随机梯度（stochastic gradient）**

       * true gradient 要算 expectation，实际中用随机梯度代替——去掉 expectation，随机变量全部用采样 $s_t$ 代替（求导产生的系数 2 并入 $\alpha$）：

       $$w_{t+1} = w_t + \alpha_t \left(v_\pi(s_t) - \hat v(s_t, w_t)\right)\nabla_w \hat v(s_t, w_t)$$

       * 问题：式中的 $v_\pi(s_t)$ 是待求的真值，**我们不知道它**——此算法实际不可用，必须替换。

   * **替换一：蒙特卡洛（MC + 值函数近似）**

       * 用从 $s_t$ 出发的 episode 沿途 reward 的折现和 $g_t$（discounted return）代替 $v_\pi(s_t)$——这正是蒙特卡洛的基本思想。

   * **替换二：TD learning（TD + 值函数近似）**

       * 用 TD target $r_{t+1} + \gamma \hat v(s_{t+1}, w_t)$ 代替 $v_\pi(s_t)$；TD target 减 $\hat v(s_t,w_t)$ 即 **TD error**：

       $$w_{t+1} = w_t + \alpha_t \left[r_{t+1} + \gamma \hat v(s_{t+1}, w_t) - \hat v(s_t, w_t)\right]\nabla_w \hat v(s_t, w_t)$$

       * 这就是 TD learning with value function approximation：对 episode 的每一步，用采到的 sample 更新 $w$；它是梯度下降算法，minimize 前面的目标函数。

## 函数近似器的选择

   * **选择范围**

       * 线性函数：以前非常广泛使用，$\hat v(s,w) = \phi^T(s)w$，$\hat v$ 是 $w$ 的线性函数；关键在于**怎么选取 feature vector**（如基于多项式）。

       * 神经网络：目前非常广泛使用；不必知道表达式，输入 $s$ 输出 $\hat v(s,w)$，参数 $w$，是 $w$ 的**非线性**函数。

   * **TD-Linear（线性情况的算法）**

       * 线性情况下梯度特别好算：$\nabla_w \hat v(s,w) = \phi(s)$，即特征向量本身。代入 TD 更新式得：

       $$w_{t+1} = w_t + \alpha_t \left[r_{t+1} + \gamma \phi^T(s_{t+1})w_t - \phi^T(s_t)w_t\right]\phi(s_t)$$

       * 这个算法叫 **TD-Linear**。

       * 劣势：需要选取合适的 feature vector，需要对问题有很好的理解，且即使理解好也难选出鲁棒的特征——这是线性近似逐渐被神经网络取代的重要原因（类似传统机器学习被深度学习取代）。

       * 优势一：理论性质能被较好地分析（非线性神经网络的理论性质很难分析）；通常做法是先理解简单的线性问题，帮助理解复杂问题。

       * 优势二：表征能力不弱——表格表示可以看成线性近似的一个特殊情况。

   * **表格是线性近似的特例**

       * 取 one-hot 特征向量 $\phi(s) = e_s$（只有 $s$ 对应分量为 1，其余全 0），则 $\hat v(s,w) = e_s^T w = w(s)$——$\hat v$ 就退化成一个一维表格，查对应位置的元素即可。

       * 把 $\phi(s_t)=e_{s_t}$ 代入 TD-Linear 更新式：只有 $w$ 中 $s_t$ 位置的元素被更新，单个元素的更新法则与 tabular TD **一模一样**（把 $w$ 换成 $v$ 就是之前的算法）。

       * > **结论**：tabular TD 算法 = TD-Linear 取 one-hot 特征向量的特例；表格并没有消失，只是函数近似大框架里的一个成员。

## 用曲面拟合 grid-world 的 state value

   * **问题设置**

       * 5×5 网格共 25 个状态，给定探索性策略（每个状态对 5 个 action 各取概率 0.2），要估计该策略的 state value——policy evaluation 问题。tabular 要存 25 个值，TD-Linear 用很少的参数就能较好近似。

       * 直观工具：把二维表格画成三维曲面，曲面最低点对应网格 $(1,5)$，值为 $-4.5$，是全图最小 state value。目标：让函数对应的曲面与真实 state value 的复杂曲面越接近越好。

       * 数据（无模型，靠数据）：**500 个 episode，每个 500 步**，每集出发的 state-action pair 均匀随机选取。

   * **由平面到高阶曲面**

       * 基准：先用 tabular TD 跑一遍，得到的曲面与真值曲面非常接近，误差随 episode 增多逐渐减小到 0。

       * 平面：取 $\phi(s) = [1,\ x,\ y]^T$，则 $\hat v = w_1 + w_2 x + w_3 y$ 是三维空间中的平面。结果**趋势正确**（左小右大）但很多点不准，收敛误差**不是 0**——真实是复杂曲面，平面只能找到最优平面。

       * 二次曲面：$\phi(s) = [1,\ x,\ y,\ x^2,\ y^2,\ xy]^T$，趋势正确且有些地方比平面好（如最小值点）。

       * 三次曲面：再加入 $x^3, y^3$，肉眼上已和真实曲面非常接近，收敛误差也较小。

| 特征向量 | 对应曲面 | 拟合效果 |
| :--- | :--- | :--- |
| $[1, x, y]$ | 平面 | 趋势正确，很多点不准，收敛误差不为 0 |
| $[1, x, y, x^2, y^2, xy]$ | 二次曲面 | 趋势正确，部分位置优于平面 |
| 再加入 $x^3, y^3$ | 三次曲面 | 肉眼接近真实曲面，收敛误差较小 |

   * **边界**

       * 参数越多拟合通常越好，但参数太多就与 tabular 无异。

       * 线性情况下**不是**参数一直加就能把误差减到 0——函数结构已定，还是线性函数。这也是广泛使用神经网络的原因：**神经网络理论上可以近似任何非线性函数**。

## 三个目标函数与故事线的严谨性

   * **故事线**

       * 目标函数 → 梯度下降 → 梯度里有未知真值 $v_\pi(s_t)$ → 用 TD target 替换 → 得到算法。这条线直观易懂，但**数学上不严谨**：第（4）步的替换可能有数学问题。

       * 严格结论：该算法**并不是在 minimize 最初的目标函数，而是在 minimize 另一个**（projected Bellman error）。讲不严谨的故事是因为直接给真目标函数太复杂。

   * **三个目标函数**

       * 第一个（squared error 的加权形式）：$J(w) = \left\| \hat v - v_\pi \right\|_D^2$，其中 $\|x\|_D^2 = x^T D x$，$D$ 的对角元就是 $d_\pi$。

       * 第二个（Bellman error）：$v_\pi$ 满足贝尔曼公式，若 $\hat v = v_\pi$ 则 $\hat v$ 也应满足 $\hat v = T_\pi(\hat v)$（$T_\pi$ 为右端算子）；实际可能不相等，就 minimize：

       $$\left\| \hat v - T_\pi(\hat v) \right\|_D^2$$

       * 第三个（projected Bellman error）：在 Bellman error 基础上多乘一个**投影矩阵**，把误差投影到“$\hat v$ 随 $w$ 改变所能组成的空间”——因为 $\hat v$ 与 $v_\pi$ 可能因函数结构限制永远不相等（如平面永远无法逼近复杂曲面），投影后误差最优值可以为 0。

       * > **结论**：TD-Linear 实际是在 minimize projected Bellman error，而不是最初那个 squared objective function。

## Sarsa 与值函数近似

   * **更新式**

       * 估计的是**一个策略的 action value** $q_\pi$（policy evaluation）；把 TD 算法里的 $\hat v(s_t)$ 换成 $\hat q(s_t,a_t)$ 即得：

       $$w_{t+1}=w_t+\alpha_t\big[r_{t+1}+\gamma\,\hat q(s_{t+1},a_{t+1};w_t)-\hat q(s_t,a_t;w_t)\big]\nabla_w\hat q(s_t,a_t;w_t)$$

       * 再与 **policy improvement** 结合，即可搜索最优策略。

   * **伪代码流程（每个 episode、每一步）**

```text
① 生成数据：在 s_t 按 ε-greedy 策略选 a_t，交互得 r_{t+1}, s_{t+1}；
   再在 s_{t+1} 按当前策略确定 a_{t+1}
② value update：用上面的 Sarsa 更新式更新参数 w
③ policy update：计算 s_t 处各 action 的 q 值，
   给最大的那个较大的概率，其它较小的概率（ε-greedy）
```

       * > **易错点** ⚠️：更新的不是 $\hat q(s_t,a_t)$ 这个函数值本身，而是它的**参数** $w$——这是与 tabular Sarsa 唯一的区别。

       * 细节差别：tabular 下比较各 action 的 q 值直接**索引**表格；函数形式必须把 $s$ 与每个 $a$ 逐个代进函数**算一遍函数值**再比较。

   * **线性近似实例**

       * 取 $\hat q=\varphi^T w$，任务是从起点到目标：沿概率大的方向确实能到达目标；部分状态的策略不好也无妨——目的**不是**找所有状态所有 action 的最优策略。

       * 收敛过程：reward 从较负逐渐增大；episode 长度因初期策略不好而较长，最后减短并收敛。

## Q-learning 与值函数近似

   * **与 Sarsa 的唯一区别**

       * TD target 带 maximization，且不再用 $a_{t+1}$：

       $$r_{t+1}+\gamma\max_{a\in\mathcal A}\hat q(s_{t+1},a;w_t)$$

       * 这与 tabular Q-learning 的 TD target 一致；估计的是最优 action value $q^*$。

   * **实现要点**

       * 先给 **on-policy** 版本（流程与 Sarsa 一致：采 sample、更新参数 $w$、ε-greedy 更新策略）；后面 Deep Q-learning 再给 **off-policy** 版本——Q-learning 两者皆可，错开呈现便于看清两种实现。

   * **线性近似实例**

       * 同样 $\hat q=\varphi^T w$，任务从起点找到达目标的好路径：最后的策略比较好；reward 由负快速收敛到较大值，episode length 也快速收敛到较短的正确路径。

## Deep Q-learning（DQN）

   * **定位**

       * > **定义**：Deep Q-learning 又称 DQN（Deep Q-network，原论文的叫法）；称之为 Deep Q-learning 是为了突出它是 **Q-learning 的一个变种**。

       * 它是最早也最成功地把深度神经网络引入强化学习的算法（“最早”打折扣——此前已有人引入但不那么成功）。

       * 成功的两点：应用上在一系列游戏控制中达到人类水平；方法上提出的关键技术被后续很多方法广泛使用。神经网络扮演的角色本质上就是一个 **nonlinear function**。

   * **为什么不用现成的 Q-learning + 函数近似**

       * 直接把 $s,a$ 输入网络输出 $\hat q$、套用之前公式也可以，但那需要对神经网络做**非常底层的运算**：手动算梯度、直接改参数。而神经网络工具包已成熟，是**黑盒**——送入数据即可自动选择合适的参数与底层算法训练。所以要换成 DQN 的做法。

   * **目标函数**

       $$J(w)=\mathbb{E}\Big[\big(R_{t+1}+\gamma\max_{a}\hat q(S_{t+1},a;w)-\hat q(S_t,A_t;w)\big)^2\Big]$$

       * 括号里就是 **Q-learning 的 TD error**；TD target 对应 **Bellman optimality error**——Bellman optimality equation 左右两边在 expectation 意义上应相等，达到最优时 error 为 0，这就是选此 loss 的依据。

   * **双网络技巧（把一个 $w$ 变成两个）**

       * 难点：目标函数里**两处含 $w$**——对前一个求梯度简单，对后一个复杂。DQN 的做法：把整个 TD target 记作 $y$，**假设 $y$ 里的 $w$ 是常数**，则 $J(w)$ 只是 $w$ 的函数，梯度就好求了。

       * 为实现它引入两个 network：**main network**（参数 $w$，一直被更新——有新采样就更新）与 **target network**（参数 $w_T$，不一直更新，隔一段时间把 main network 的 $w$ 赋值过来）。

       * 逻辑：$w_T$ 固定不动 → 更新 $w$ 一段时间 → 用新 $w$ 赋给 $w_T$ → 再固定 $w_T$ 继续，交替进行，最终两者都收敛到最优。

       * 梯度只对 main network 那一个 $\hat q$ 求取；target network 一侧没有梯度（被当作常数）。

```text
replay buffer ──均匀采样──▶ (s,a) ──▶ main network：   q̂(s,a;w)    （每次训练都更新）
      │
      └──(s',·)──▶ target network：y_T = r + γ max_a q̂(s',a;w_T) （隔一段时间由 w 赋值）

(y_T − q̂) ──▶ loss ──▶ 梯度只回传到 main network 的 w，不穿过 target network
```

   * **经验回放（experience replay）**

       * > **定义**：replay buffer 是存放历史 experience sample 的集合，每个元素为 $(s,a,r,s')$（从 $s$ 执行 $a$ 得 reward $r$ 跳到 $s'$）；训练时不按时序使用，而是把全部 sample 混在一起从中取用——经验再用一次，故称“回放”。

       * 采样要求：必须服从 **uniform distribution（均匀分布）**，每个数据点被抽到的概率相同。

       * 为什么必须：目标函数里有随机变量 $R, S', S, A$，求 expectation 需要知道分布；$R, S'$ 由系统模型决定，关键是 $(S,A)$——把 $(S,A)$ 当作**一个**随机变量（像二维平面上一个点对应两个坐标），它要服从分布 $d$。做 optimization 就绕不开这个分布。

       * 为什么均匀：用其它分布（如高斯加权）需要**先验知识**（知道谁重要）；没有先验就一视同仁，全部概率相同。

       * 数学要求分布均匀、采集却有时序和相关性的矛盾怎么解：不按先后顺序使用——把 sample 打散后均匀采样，从而**打破不同 sample 之间的 correlation**。

   * **表格版 Q-learning 与经验回放的三问三答**

       * tabular Q-learning 没有 experience replay，为什么不需要：它根本不涉及 $(s,a)$ 的 distribution；只有要求按一定分布（如均匀）使用数据时才需要打散重采。

       * 为什么 DQN 就涉及：两类方法在做**不同的事**——值函数近似这一大类在做 **optimization**，目标函数是含 $(S,A)$ 的 expectation，必然涉及其分布；tabular Q-learning 是在求解 **Bellman 最优公式**（每个 $(s,a)$ 一个方程，联立求解），不涉及分布。

       * tabular 能不能用 experience replay：**可以**——tabular Q-learning 是 off-policy 的，不管数据怎么来的，给我什么 $(s,a)$ 就更新对应 q。而且有好处：同一 sample 可被反复采到，样本更 **efficient**；按时序用完即丢是浪费。

       * > **提示**：之前 tabular Q-learning 仿真一个 episode 跑 10 万步其实不必要——只要每个 state-action pair **被访问到一次**即可（确定性环境下访问多次与一次没区别；随机环境另当别论），配合 replay 可反复利用这一次经验。

   * **伪代码（off-policy 版本）**

       * off-policy：假设已有 behavior policy $\pi_b$ 产生大量 sample 放入 replay buffer。每个 iteration：

```text
每一个 iteration：
    ① 从 replay buffer 中随机、均匀地采样一批 experience
    ② 用 target network 计算出 y_T
       （网络输入是 s 和 a，输出是 q̂；期望输出是 y_T）
    ③ 把输入 (s,a) 与希望输出 y_T 送入网络训练一次，
       更新 main network 的参数 w
    ④ 更新 w 达到 C 次后，把 w 赋给 w_T（更新 target network）

如此循环往复，构成整个算法的 loop。
```

       * **澄清一（为什么没有 policy update）**：因为 off-policy——数据由 behavior policy 提供，不需要新策略再去生成数据；也可以在所有 q 算完后一次性算一次 policy 即得最优策略（非要加 policy update 那条也没用）。

       * **澄清二（为什么不用推导出的梯度更新式）**：那个式子太底层，可以指导生成算法，但实际要遵循神经网络**批量训练**的黑盒特性来高效训练。

       * **澄清三（与 DQN 原文网络不同）**：本讲简化版网络输入 $s,a$、输出单个 $\hat q(s,a)$——比较 5 个 action 需要固定 $s$ 前向 **5 次**；原文网络输入 $s$、一次前向直接输出 $\hat q(s,a_1),\dots,\hat q(s,a_5)$，计算更高效，但需要更多训练技巧。明白算法本质后可以修改推广，不必恐慌。原文印象中是 on-policy 的，本讲给的是 off-policy 版本。

## DQN 实例：数据量的边界

   * **实验设置**

       * 任务升级：要找到**所有** state-action pair 的 optimal action value（不是只找一条从起点到目标的好路径）；$q^*$ 估计出来后 optimal greedy policy 立刻可得到。

       * 只用**一个 episode**（由探索性 behavior policy 生成，每个 action 概率均 0.2），且只有 **1000 步**——是 tabular Q-learning 例子里 10 万步的 1%。

       * 网络是**浅层**的：虽然叫 Deep Q-learning，拟合时很多时候根本不需要深——仅 3 层（输入层、一个隐藏层、输出层），隐藏层只有 100 个 neuron。

   * **1000 步的结果**

       * 1000 步的 episode 基本把**所有 state-action pair 都访问到了**（有的多有的少，无妨）；训练后输出的策略就是**最优**策略。

       * 收敛过程：TD error（loss）收敛到 0；与 ground truth 比较的 state value error 也收敛到 0。

       * 只需很少数据就得到相同结果的原因：一是值函数近似本身有较强的**泛化能力**；二是用了 **experience replay**，经验被反复利用、效率高。

   * **故意挑战：只给 100 步**

       * 100 步的轨迹很不理想，很多 state-action pair 没被访问到；用它训练，最后策略也很差。

       * 值得注意的现象：TD error 与 loss **是收敛的**，但 state value 的 error **没有收敛到 0**，结果不正确。

       * > **易错点** ⚠️：loss 收敛 $\neq$ 结果正确。神经网络总能拟合你喂给它的数据；数据覆盖不到的地方，拟合得再好也是错的。

       * 结论：再强大的算法也得有好的数据——巧妇难为无米之炊。
