# 无模型方法：蒙特卡洛、随机近似与时序差分

## Soft Policy 与探索条件的消除

   * **Soft policy（软策略）**

       * > **定义**：对每一个 action 都有可能去选择的策略，属于随机性（stochastic）策略。

       * 策略分两类：确定性（deterministic）策略，如 greedy 策略；随机性（stochastic）策略，如 soft policy 与 ε-greedy。

       * 引入 soft policy 的目的：去掉 MC Exploring Starts 算法中「episode 必须从每一个 state-action pair 出发各来一遍」的条件——一条足够长的探索性 episode 就能访问到所有 $(s,a)$，只需从一个或几个 $(s,a)$ 出发即可覆盖其余。

---

## ε-Greedy 策略

   * **ε-Greedy 策略（ε-greedy policy）**

       * > **定义**：在状态 $s$ 下，给 greedy action $a^*$ 一个最大的选择概率，给其余每个 action 一个相同小概率的随机策略。

       * 概率公式：

$$
\pi(a\mid s)=
\begin{cases}
1-\varepsilon+\dfrac{\varepsilon}{|\mathcal A(s)|}, & a=a^* \\[2mm]
\dfrac{\varepsilon}{|\mathcal A(s)|}, & a\neq a^*
\end{cases}
$$

       * 参数含义：$\varepsilon$ 是 $0$ 到 $1$ 之间的正数，$|\mathcal A(s)|$ 是状态 $s$ 对应的 action 个数。

       * 数值例：$|\mathcal A(s)|=5$、$\varepsilon=0.2$ 时，四个非 greedy action 各分得 $0.2/5=0.04$，greedy action 得到 $1-0.16=0.84$。

       * 保序性质：只要 $\varepsilon$ 在 $0$ 到 $1$ 之间，greedy action 的概率 $1-\varepsilon+\varepsilon/|\mathcal A(s)|$ 始终大于任一其它 action 的概率 $\varepsilon/|\mathcal A(s)|$——最大概率始终留给 greedy action。

       * $\varepsilon=0$ 时退化为 greedy 策略：探索性弱、充分利用性强；$\varepsilon=1$ 时退化为均匀分布：探索性最强、充分利用性最弱（5 个 action 时每个概率均为 $0.2$）。

---

## 探索与利用

   * **Exploitation（充分利用）**

       * > **定义**：利用已知的 action value 信息，选择当前已知的、能带来更多 reward 的 action。

   * **Exploration（探索）**

       * > **定义**：怀疑当前信息不完备，去尝试其它 action，执行后可能发现其 action value 其实也非常好。

       * ε-greedy 的作用就是平衡这一对矛盾：$\varepsilon$ 的取值直接决定天平往哪边倒——$\varepsilon$ 大偏探索，$\varepsilon$ 小偏利用。

## MC ε-Greedy 算法

### 算法构造

   * **MC ε-Greedy 算法（MC ε-Greedy）**

       * > **定义**：把 ε-greedy 嵌入蒙特卡洛框架、从而去掉 exploring starts 条件的算法，结构与 MC Exploring Starts 基本一致。

       * 与 MC Exploring Starts 只有两个区别：其一，policy improvement 一步不再在所有策略的集合 $\Pi$ 中求解，而只在 ε-greedy 策略集合 $\Pi_\varepsilon$（$\varepsilon$ 事先给定）中求解，所得最优策略就是把最大概率给 greedy action、其余 action 各分相同小概率；其二，估计 action value 用 every-visit。

       * 用 every-visit 的原因：episode 可能非常长，很多 state-action pair 被访问了很多次，若用 first-visit 只取其中一次做估计，是浪费。

       * 换策略的收益：使用 ε-greedy 后就不再需要 exploring starts 条件。

### 探索能力实测

   * **ε 大时的探索效果**

       * $\varepsilon=1$（均匀分布）时，25 个状态、每个状态 5 个 action 共 125 个 state-action pair，仅一条 100 万步的 episode 就能让每个 pair 被访问约七八千次。

       * 一条 trajectory 就能完成大量探索：agent 靠选其它 action 的小概率从被困的位置走出来，逐步访问到几乎所有 state 与 action。

   * **ε 小时的探索效果**

       * ε 较小时探索能力弱：即使 episode 长到 1 万步，仍有一些 action 未被访问；100 万步时访问次数分布非常不均匀。

       * 但相比纯 greedy，小 ε 仍保留一定探索能力。

### 最优性代价

   * **Consistent（一致）**

       * > **定义**：一个 ε-greedy 策略与一个 greedy 策略在每一状态上「最大概率的选择方向相同」的关系。

       * 所有与最优 greedy 策略 consistent 的 ε-greedy 策略，随 $\varepsilon$ 增大 state value 越来越小；$\varepsilon=0.5$ 时很多地方的 state value 已变成负数（例如 target area 因大概率误入 forbidden area 而从最大值跌为负值）。

       * MC ε-Greedy 在 $\varepsilon=0.1$ 时求出的最优 ε-greedy 策略与真正的最优策略 consistent，转成 greedy 后恰好就是最优 greedy 策略；$\varepsilon=0.2$ 或 $0.5$ 时转成 greedy 后便不再是最优策略。

       * > **易错点** ⚠️：consistent 说的是两个策略「最大概率的方向一致」，不等于两个策略相同；ε-greedy 策略可以与 greedy 策略 consistent，但两者 state value 可相差很远。

       * 实践技巧：把 $\varepsilon$ 设得比较小，或让它从大逐渐减小趋向 0——前期探索性强，后期所得策略接近最优 greedy 策略。

## 均值估计的增量式算法

   * **增量式均值估计（incremental mean estimation）**

       * > **定义**：用迭代方式求期望——来一个采样就算一步，不必等所有数据到齐再求平均。

       * 把前 $k$ 个采样的平均记作 $w_{k+1}=\frac{1}{k}\sum_{i=1}^{k}x_i$（$w_k$ 是前 $k-1$ 个的平均），可建立相邻两步的迭代关系：

$$
w_{k+1}=w_k-\frac{1}{k}\left(w_k-x_k\right)
$$

       * 验证：$w_1=x_1$ 时 $w_2=x_1$，$w_3=\frac{1}{2}(x_1+x_2)$，归纳可得 $w_{k+1}$ 恒等于前 $k$ 个采样的平均值。

       * 优势：第 $k$ 步只需上一步结果与新采样即可得到正确的平均数，早期不精确的 $w_k$ 也可先用（有总比没有强），随数据增多逐渐逼近 $\mathbb E[X]$。

       * 推广：把系数 $1/k$ 换成一般正数 $\alpha_k$ 后，写不出显式平均的形式，但当 $\alpha_k$ 满足一定条件时 $w_k$ 仍能逼近 $\mathbb E[X]$——这正是 RM 算法要回答的问题。

## 随机近似与 Robbins-Monro 算法

### 问题设定

   * **随机近似（Stochastic Approximation，SA）**

       * > **定义**：一大类随机迭代算法，特指用来做方程求解或优化问题、且不需要知道方程或目标函数表达式（也不知道其导数或梯度表达式）的算法。

       * 「随机」指算法涉及对随机变量的采样；SA 的信息来源是数据而非表达式——有模型时不需要数据，没模型时就得有数据，二者必有其一。

       * 求解优化问题可化为方程问题：$\min J(w)$ 的必要条件是 $\nabla J(w)=0$（$J$ 只有一个极值时为充要条件），令 $g(w)=\nabla J(w)$ 即得 $g(w)=0$ 形式；$g(w)=c$ 型方程把 $c$ 移到左边同样化归。

       * 典型场景类比神经网络：$y=g(w)$ 是一个黑盒函数，表达式未知，问题是输入什么样的 $w$ 能得到输出 $0$。

### 算法形式

   * **Robbins-Monro 算法（Robbins-Monro algorithm，RM 算法）**

       * > **定义**：用含噪音的测量迭代求解 $g(w)=0$ 的根 $w^*$ 的随机近似算法，是 SA 领域开创性工作；SGD 与均值估计算法都是它的特殊情况。

       * 迭代式：

$$
w_{k+1}=w_k-a_k\,\tilde g(w_k),\qquad \tilde g(w_k)=g(w_k)+\eta_k
$$

       * $\tilde g$ 是 $g$ 的带噪音观测：$\eta_k$ 是噪音，$a_k$ 是系数；算法把 $g$ 当黑盒，只依赖输入的 $w$ 序列与测得的 $\tilde g$ 序列。

```text
    w_k ──► 黑盒 g(·)（表达式未知）──► y = g(w_k)
                                     │ 加噪音 η_k
                                     ▼
    w_{k+1} = w_k − a_k·ḡ_k ◄── 可测量输出 ḡ_k = g(w_k) + η_k
```

### 收敛直观

   * **为什么 RM 会收敛**

       * 以 $g(w)=\arctan w$（真解 $w^*=1$）为例，取 $w_1=3$、$a_k=1/k$：每次把当前函数值乘以系数作为水平位移往回跳，$w_k$ 一步步靠近 $w^*$。

       * 机理分两种情况：$w_k>w^*$ 时 $g(w_k)>0$，减去正数使 $w_{k+1}$ 变小、往回退；$w_k<w^*$ 时 $g(w_k)<0$，减去负数使 $w_{k+1}$ 变大、往前走——两种情况都更接近 $w^*$。

       * 黑盒视角：输出大于 0 就调小 $w$，输出小于 0 就调大 $w$，调到输出等于 0 为止；RM 的精髓在于回答了「每次该调多少」——减去 $a_k$ 乘以 $g$。

## RM 算法的收敛性定理

### 三个条件

   * **收敛性定理（with probability 1）**

       * > **定义**：当三个条件都满足时，RM 算法的 $w_k$ 以概率 1（with probability 1，w.p.1）收敛到 $g(w)=0$ 的解 $w^*$。

       * 收敛方式是概率意义的收敛而非常规收敛，因为 $w_k$ 涉及随机变量采样；强化学习论文中的证明普遍使用 w.p.1。

       * 条件一（关于 $g$）：$c_1\le\nabla g(w)\le c_2$——导数有正的下界意味着曲线递增，$g(w)=0$ 的解存在且唯一；梯度有上界排除曲线趋陡导致发散的情形。该条件对应优化中的凸性：$\nabla g$ 再求一次导得 Hessian matrix，其大于零即 $J$ 是凸的（convex）。

       * 条件二（关于系数）：$\sum a_k=\infty$ 且 $\sum a_k^2<\infty$。

       * 条件三（关于噪音）：$\eta$ 均值为 0、方差有界；常见情形是 $\eta$ 从某分布 iid 采样，天然满足，且不要求高斯噪声。

### 步长条件的解读

   * **平方和有限 $\sum a_k^2<\infty$**

       * 意味着 $a_k$ 最终一定收敛到 0：只要 $a_k$ 不趋于 0（哪怕保持一个极小常数），无穷多项相加必趋于无穷。

       * 保护的目标：把迭代式改写为 $w_{k+1}-w_k=-a_k\tilde g(w_k)$，$a_k\to 0$ 使相邻两步之差趋于 0——$w_k$ 收敛后不再持续波动。

   * **和为无穷 $\sum a_k=\infty$**

       * 意味着 $a_k$ 收敛到 0 但不能太快（若几步后恒为 0，求和就不是无穷）。

       * 保护的目标：把各步迭代式左右分别相加、中间项抵消，得 $w_\infty-w_1=-\sum_{k=1}^{\infty}a_k\tilde g(w_k)$——若 $a_k$ 之和有界，则 $w^*-w_1$ 必须有界，初始值就不能随便选；和为无穷保证 $w_1$ 离 $w^*$ 多远都能收敛过来。

   * **合格系数与实践取值**

       * $a_k=1/k$ 同时满足两个条件：$\sum 1/k=\infty$（调和级数发散），$\sum 1/k^2$ 收敛于常数。

       * 反例：$g(w)=w^3-5$ 不满足梯度有上界（梯度 $3w^2$ 随 $w\to\infty$ 趋于无穷），迭代可能发散——三个条件缺一不可。

       * 实践中不让 $a_k$ 趋向 0，而取一个很小的常数：$1/k$ 使后期新数据几乎不起作用，取小常数让未来进来的数据仍然有用。

       * > **提示**：理论条件保证「无限长时间里能收敛」，实践取小常数是为了「新数据永远还有话语权」，取舍看问题本身。

## 用 RM 算法解均值估计

   * **均值估计作为特殊的 RM 算法**

       * > **定义**：取 $g(w)=w-\mathbb E[X]$，求解 $g(w)=0$ 即得 $w^*=\mathbb E[X]$；用采样构造测量 $\tilde g=w-x$，代入 RM 算法即得增量式均值估计算法。

       * 测量可分解为 $g(w)$ 与噪音之和：$\tilde g=\underbrace{(w-\mathbb E[X])}_{g(w)}+\underbrace{(\mathbb E[X]-x)}_{\eta}$。

       * 噪音条件天然满足：$\eta=\mathbb E[X]-x$ 均值为 0（采样无偏）、方差即 $X$ 的方差（有界）。

       * 代入后的算法为 $w_{k+1}=w_k-\alpha_k(w_k-x_k)$；当 $\alpha_k$ 满足平方和有限、和为无穷时收敛到 $\mathbb E[X]$——这就回答了「$\alpha_k\neq 1/k$ 时还能否收敛」的问题。

       * 存在一个关于更一般 stochastic sequence 收敛性的定理（选学）：它可用来证明 RM 定理、直接分析均值估计问题，推广后还能证明 Q-learning 与 TD learning 的收敛性。

## 随机梯度下降

### 问题与三层递进

   * **随机梯度下降（Stochastic Gradient Descent，SGD）**

       * > **定义**：求解含期望的目标函数 $\min_w J(w)=\mathbb E[f(w,X)]$ 的优化算法，用单个采样上的梯度（stochastic gradient）代替真实梯度进行迭代。

       * 三层包含关系：

```text
RM 算法（求解方程 g(w) = 0）
  └── SGD 是它的特殊情况（g 取成目标函数的梯度）
        └── 均值估计算法又是 SGD 的特殊情况（目标函数取成到样本的距离）
```

       * 目标函数特点：$J$ 含 expectation 与随机变量 $X$，$X$ 的概率分布给定但未知；梯度可移入期望内部：$\nabla J(w)=\nabla\,\mathbb E[f(w,X)]=\mathbb E[\nabla_w f(w,X)]$（expectation 本质是求和，求导符号进出无区别）。

   * **三种求解方法的递进**

       * 梯度下降（Gradient Descent，GD）：$w_{k+1}=w_k-\alpha_k\nabla J(w_k)$，沿梯度反方向下降，$\alpha_k$ 称为步长；但梯度里的 expectation 无法直接计算（有模型可求，无模型用数据）。

       * 批量梯度下降（Batch Gradient Descent，BGD）：对随机变量采样 $n$ 次求平均来近似 expectation——蒙特卡洛的基本思想；问题是每更新一次 $w_k$ 都要采很多样。

       * 随机梯度下降（SGD）：$w_{k+1}=w_k-\alpha_k\nabla f(w_k,x_k)$，把 BGD 的 $n$ 设成 1，只用一个样本；随机梯度与真实梯度之间满足 $\nabla f(w_k,x_k)=\nabla J(w_k)+\text{error}$。

### 例子与收敛

   * **示例：目标函数 $f(w,X)=\frac{1}{2}\lVert w-X\rVert^2$**

       * 梯度为 $\nabla_w f=w-X$；最优解由 $\mathbb E[\nabla_w f]=\mathbb E[w-X]=0$（$w$ 非随机、期望是其自身）得 $w^*=\mathbb E[X]$。

       * 该问题的 GD 为 $w_{k+1}=w_k-\alpha_k\,\mathbb E[w_k-X]$（梯度含期望）；SGD 为去掉期望用单采样代替：

$$
w_{k+1}=w_k-\alpha_k(w_k-x_k)
$$

       * 这个 SGD 恰是均值估计算法——把「求 $\mathbb E[X]$」描述成优化问题后殊途同归。

   * **SGD 收敛：它是特殊的 RM 算法**

       * 证明思路：优化问题的必要条件 $\nabla J(w)=0$ 化为 $g(w)=\nabla J(w)$ 的求根问题；RM 所需的测量 $\tilde g$ 就是 stochastic gradient，代回 RM 迭代式即得 SGD——其收敛性直接套用 RM 的结论。

       * 收敛条件三条：$f$ 严格凸（$w$ 为向量时上下界为矩阵）；$a_k$ 和为无穷、平方和有限；采样 iid。满足时 $w_k$ w.p.1 收敛到 $w^*$。

   * **SGD 的收敛行为：远像 GD，近才随机**

       * 定义随机梯度与真实梯度的相对误差（relative error）$\delta_k$（分子为两者之差的绝对值，分母为真实梯度的绝对值）。

       * 利用最优解处 $\mathbb E[\nabla f(w^*,X)]=0$ 与中值定理，在 $f$ 二阶导为正的假设下可得分母下界 $c\,|w_k-w^*|$，于是

$$
\delta_k\;\le\;\frac{\bigl|\nabla f(w_k,x_k)-\mathbb E[\nabla f(w_k,X)]\bigr|}{c\,|w_k-w^*|}
$$

       * 结论：$w_k$ 离 $w^*$ 远时分母大、relative error 小，SGD 行为与 GD 类似、朝目标方向快速收敛；$w_k$ 靠近 $w^*$ 时上界变大，才显出较大随机性。

       * 二维仿真印证：100 个采样点跑 SGD，先是朝目标方向快速接近，接近目标后轨迹才出现随机摆动。

## 无随机变量形式的 SGD

   * **另一副面孔的问题描述**

       * > **定义**：SGD 也常出现在不含任何随机变量与 expectation 的形式中：$J(w)=\frac{1}{n}\sum_{i=1}^{n}f(w,x_i)$，其中 $\{x_i\}$ 只是一组给定的实数，不是任何随机变量的采样。

       * 对该问题的 GD 每次要用全部 $n$ 个 $x_i$；数据集大时每次只能取一个 $x_k$，算法形式与 SGD 相同——但它究竟算不算 SGD、$x_k$ 该怎么取，需要澄清。

       * 解决思路：手动引入一个随机变量 $X$——定义在这组数上、取每个数的概率均为 $1/n$（均匀分布），则 $\frac{1}{n}\sum_{i=1}^{n}f(w,x_i)=\mathbb E[f(w,X)]$，该问题随即化为标准的 SGD 问题。

       * 由此回答取法问题：$x_k$ 必须从集合中随机抽取而非排序后按序取，且因为是随机抽取，同一个数可能被反复用到。

## BGD、MBGD 与 SGD 的对比

   * **三种方法的分工**

       * > **定义**：三者面对同一优化问题，区别只在每次用多少数据计算梯度：BGD 用全部 $n$ 个采样求平均；mini-batch 梯度下降（Mini-batch Gradient Descent，MBGD）随机抽取的 $m$ 个（集合 $I_k$）求平均；SGD 只随机抽取 1 个。

       * | 算法 | 每次使用的数据 | 直观特点 |
         | :--- | :--- | :--- |
         | BGD | 全部 $n$ 个采样求平均 | 最接近真实期望，数据开销最大 |
         | MBGD | 随机抽取的 $m$ 个求平均 | 随机性居中，灵活高效 |
         | SGD | 随机抽取的 1 个 | 最简洁，随机性最大 |

       * MBGD 囊括两端：$m=1$ 时退化为 SGD，batch 很大时接近 BGD；它用更多数据平均掉噪音，随机性比 SGD 小，又不用全部数据，比 BGD 灵活高效。

       * > **易错点** ⚠️：$m=n$ 时 MBGD 也不完全等于 BGD——两者样本量相同，但 MBGD 是随机（有放回式）抽取，可能出现某采样被抽多次、有的没被抽到；差别在抽样方式，不在数量。

   * **均值估计例子中的速度对比**

       * 目标函数取 $J(w)=\frac{1}{2n}\sum_{i=1}^{n}\lVert w-x_i\rVert^2$（系数 2 为求导时抵消），梯度为 $\nabla J(w)=\frac{1}{n}\sum_{i=1}^{n}(w-x_i)$。

       * 三个算法唯一区别在梯度的后半段：BGD 得 $w_{k+1}=w_k-\alpha_k(w_k-\bar x)$；MBGD 用抽取的 $m$ 个样本的平均；SGD 用单个 $x_k$。

       * 取 $\alpha_k=1/k$ 时：BGD 一步到位直接等于 $\bar x$；MBGD 介于两者之间（先求小组平均）；SGD 最慢（每次只有一个数，靠多步慢慢平均），但整体收敛速度仍然不慢。

## 时序差分学习的定位与热身例子

   * **TD learning 的位置**

       * > **定义**：Temporal-Difference Learning（时序差分学习，TD learning）是课程中第二个 model-free 方法（第一个是蒙特卡洛），从算法形式看是增量式（incremental）的，而蒙特卡洛是非增量式（non-incremental）的。

       * 本章脉络：先估计 state value 的 TD 算法，再是估计 action value 的 Sarsa 及其变形（Expected Sarsa、n-step Sarsa），最后是直接估计 optimal action value 的 Q-learning。

       * 术语歧义：TD learning 可指本章所有算法这一大类；也可特指最早那个估计 state value 的经典算法。

       * 与前后章节的关系：上一章的随机近似、SGD、RM 算法是本章的地基；下一章 Value Function Approximation 基于本章的 TD 方法，把表格（tabular）表示换成函数表示，Deep Q-learning 将在那里出现。

   * **三个热身例子（用 RM 算法求解）**

       * 例一：求 $w=\mathbb E[X]$，取 $g(w)=w-\mathbb E[X]$、测量 $\tilde g=w-x$，得 $w_{k+1}=w_k-\alpha_k(w_k-x_k)$。

       * 例二：求 $w=\mathbb E[v(X)]$，测量改为 $v(x)$，得 $w_{k+1}=w_k-\alpha_k\big(w_k-v(x_k)\big)$。

       * 例三：求 $w=\mathbb E[R+\gamma v(X)]$，同时需要 $R$ 与 $X$ 的采样，得

$$
w_{k+1}=w_k-\alpha_k\Big(w_k-\big[r+\gamma v(x)\big]\Big)
$$

       * 例三的记号有意对应强化学习：$R$ 对应 reward、$\gamma$ 对应 discount rate、$v$ 对应 state value、$X$ 对应状态——它与后面的 TD 算法形式非常相似。

## TD 算法：估计给定策略的 state value

   * **TD 算法（估计 state value 的 TD 算法）**

       * > **定义**：用策略 $\pi$ 产生的经验数据（experience）估计该给定策略的 state value 的算法，即 model-free 条件下的 policy evaluation。

       * 数据形式：一条按序展开的 experience，集合中每个元素是三元组 $(s_t,\ r_{t+1},\ s_{t+1})$，全部由给定策略 $\pi$ 产生。

```text
s0 --r1--> s1 --r2--> s2 ... st --r(t+1)--> s(t+1) ...
```

       * 更新式（只更新当前访问到的 $s_t$）：

$$
v_{t+1}(s_t) = v_t(s_t) - \alpha_t\Big[v_t(s_t) - \big(r_{t+1} + \gamma\, v_t(s_{t+1})\big)\Big]
$$

       * 隐含的第二式：$v_{t+1}(s)=v_t(s),\ s\neq s_t$——当前时刻没被访问的状态，其估计值保持不动。

       * 结构：左边是新估计，右边第一项 $v_t(s_t)$ 是旧估计（current estimate / old estimate），第二项是修正项；$\alpha_t$ 是针对状态 $s_t$ 的系数。

       * > **易错点** ⚠️：这个 TD 算法只做 policy evaluation——估计给定策略的 state value；它不能估计 action value，也不能直接搜索最优策略。估计 action value 并结合策略改进靠后面的 Sarsa 等算法。

---

## TD Target 与 TD Error

   * **TD target（时序差分目标）**

       * > **定义**：修正项中括号里的 $r_{t+1}+\gamma v_t(s_{t+1})$，记作 $\bar v_t$——算法把 $v(s_t)$ 朝它的方向改进。

       * 严格验证：把算法等价变形为 $v_{t+1}(s_t)-\bar v_t=(1-\alpha_t)\big(v_t(s_t)-\bar v_t\big)$；因 $\alpha_t$ 是小正数，$0<1-\alpha_t<1$，故 $\big|v_{t+1}(s_t)-\bar v_t\big|\le\big|v_t(s_t)-\bar v_t\big|$——每一步 $v(s_t)$ 都离 $\bar v_t$ 更近。

   * **TD error（时序差分误差）**

       * > **定义**：当前估计与 target 之差 $\delta_t=v_t(s_t)-\big[r_{t+1}+\gamma v_t(s_{t+1})\big]$。

       * 名称由来：差的两端分处两个时刻（$t$ 与 $t+1$），「时序差分」的「时序」即指此。

       * 第二重意义：刻画 $v_t$ 与真值 $v_\pi$ 的差距。把式中的 $v$ 全部换成 $v_\pi$ 得 $\delta_{\pi,t}$，对其求期望恰为 0——这正是 state value 的定义式；所以 $v_t=v_\pi$ 时 $\delta_t$ 在期望意义下为 0，$\delta_t\neq 0$ 说明 $v_t$ 尚未到达 $v_\pi$。

       * 第三重意义：TD error 是一种 innovation（新信息）——误差的存在说明当前估计不准确，恰好可以用它来改进当前估计。

---

## TD 算法的数学本质与收敛性

   * **TD 算法在求解贝尔曼公式**

       * > **定义**：TD 算法本质上是在没有模型的情况下求解贝尔曼公式（之前讲贝尔曼公式时的解析解与迭代解都依赖模型）。

       * 所求解的是一个更简洁的贝尔曼公式——由 state value 定义直接拆分而来，有时称 Bellman expectation equation：

$$
v_\pi(s) = E\big[R_{t+1} + \gamma v_\pi(S_{t+1})\big]
$$

       * 用 RM 算法求解它：令 $g(v(s))=v(s)-E[R+\gamma v_\pi(S')]=0$，测量为 $\tilde g=v(s)-[r+\gamma v_\pi(s')]$，代入得 $v_{k+1}(s)=v_k(s)-\alpha_k\big[v_k(s)-(r+\gamma v_\pi(s'))\big]$——与 TD 算法只差两处。

       * 两处修正其一（采样方式）：RM 推导要求对同一 $s$ 反复采样，TD 改为直接沿一条 trajectory 走，轨迹访问到 $s$ 就更新、没访问到就不动，一条轨迹即可更新所有状态。

       * 两处修正其二（未知真值）：把 $v_\pi(s')$ 替换为当前估计 $v_k(s')$；虽然单点估计不准，但每个状态都在被不断修正，最终所有状态都收敛到 $v_\pi$。

   * **收敛定理与学习率**

       * 收敛结果：$v_t(s)\to v_\pi(s)$（对给定策略做 policy evaluation），条件是

$$
\sum_t \alpha_t(s) = \infty, \qquad \alpha_t(s) \ge 0, \qquad \alpha_t(s) \to 0
$$

       * 求和趋于无穷的本质含义：每一个状态都应被访问很多次乃至无穷次（状态未被访问时其 $\alpha_t(s)$ 记 0）；实际中「很多次」就够。

       * 理论要求 $\alpha_t\to 0$，实践通常取很小的常数（如 0.00 几）：条件不再满足，但这样很久之后的经验仍能派上用场。

       * 求得 state value 只是完成 policy evaluation，要与 policy improvement 相结合才能搜索最优策略。

## TD 与蒙特卡洛的对比

   * **五个维度的对照**

       * | 比较维度 | TD learning | MC learning |
         | :--- | :--- | :--- |
         | 更新时机 | online：拿到 $r_{t+1}$、跳到 $s_{t+1}$ 就立刻更新 | offline：必须等 episode 结束才能算 return 再更新 |
         | 能处理的任务 | episodic 和 continuing 都可以 | 只能 episodic |
         | 是否 bootstrapping | 是：基于旧的估计加新信息得到新估计 | 否：直接用 return 作为估计值 |
         | variance | 比较小（涉及的随机变量少） | 比较高（一个 episode 引入大量随机变量） |
         | bias | 有偏（依赖初始估计），数据多了逐渐消除 | 无偏（expectation 直接等于真值） |

       * online/offline 的后果：TD 因为在线更新，能处理任务不停止、一直持续下去的 continuing task（此时不能等它停下来）；MC 是 offline 的，只能处理 episodic task。

       * bootstrapping 的含义：先有一个初始猜测，基于它加上新信息得到新猜测；MC 不涉及任何先前估计，直接用当前 episode 算出的 return 作估计。

       * variance 差距的直观度量：episode 长 100、每状态 5 个 action 时，可能的 episode 有 $5^{100}$ 种走法，MC 只用其中一个样本估计，variance 自然大；TD 每步只涉及 reward 与下一状态（Sarsa 再加一个 action）等少数随机变量。

       * bias 的来源与消除：TD 的 bootstrapping 把初始估计的不准带入估计过程造成 bias，但随数据增多会被抵消、最终收敛到正确值；MC 无偏但方差高。

## Sarsa 算法

   * **Sarsa**

       * > **定义**：把 TD 算法从估计 state value 换成估计 action value 的算法——对每个 $(s,a)$ 估计 $q_\pi(s,a)$，结构与 TD 算法完全一致。

       * 出发点：改进策略需要的是 action value（哪个 action 的 value 大就选哪个），而 TD 算法不能估计 action value，Sarsa 可以。

       * 数据是五元组经验 $(s_t,\ a_t,\ r_{t+1},\ s_{t+1},\ a_{t+1})$；更新式：

$$
q_{t+1}(s_t, a_t) = q_t(s_t, a_t) - \alpha_t\Big[q_t(s_t, a_t) - \big(r_{t+1} + \gamma\, q_t(s_{t+1}, a_{t+1})\big)\Big]
$$

       * 同样隐含：当前时刻访问的是 $(s_t,a_t)$ 就更新它的 $q$，其它未访问的 $q$ 保持不动。

```text
TD   :  (s_t) --------------r(t+1)--------------> (s_(t+1))
                     更新对象: v(s_t)

Sarsa:  (s_t, a_t) ---r(t+1)---> (s_(t+1), a_(t+1))
                     更新对象: q(s_t, a_t)
```

       * 名字来源：State-Action-Reward-State-Action 五个单词的首字母缩写，恰是其用到的五个数据量。

       * 数学本质：Sarsa 求解的是一个用 action value 表达的贝尔曼公式（刻画不同 action value 之间的关系）：

$$
q_\pi(s,a) = E\big[R_{t+1} + \gamma q_\pi(S_{t+1}, A_{t+1})\big]
$$

       * 收敛性与 TD 算法定理一致：$q_t(s,a)\to q_\pi(s,a)$，条件主要针对学习率 $\alpha_t$；得到的仍是给定策略的 action value，要得最优策略还需结合 policy improvement。

---

## 完整 Sarsa：与策略改进结合

   * **结合后的算法（通常说的 Sarsa）**

       * > **定义**：把 Sarsa 的 policy evaluation 与 policy improvement 相互迭代得到的算法——大多数场合提到的 Sarsa 即指这个结合体。

```text
对每一个 episode:
    初始化 s, 按 π 采样 a
    while 当前状态不是 target state:
        执行 a_t, 观测 r_(t+1), 跳到 s_(t+1)
        在 s_(t+1) 按当前策略采样 a_(t+1)
        # 步骤一: q value update (policy evaluation)
        q(s_t,a_t) ← q(s_t,a_t) - α·[q(s_t,a_t) - (r_(t+1) + γ·q(s_(t+1),a_(t+1)))]
        # 步骤二: policy update (policy improvement)
        按 ε-greedy 基于 q 更新策略 π
        s_t ← s_(t+1), a_t ← a_(t+1)
```

       * 每轮流程：执行 $a_t$ 得 $r_{t+1}$、跳到 $s_{t+1}$，在 $s_{t+1}$ 再按策略采样一次得 $a_{t+1}$，凑齐五元组后更新 $q$，随后立刻做策略更新。

       * 策略更新用 ε-greedy 而非纯 greedy：不给 greedy action 概率 1，留小概率给其它 action，以尽可能访问到更多 $(s,a)$。

       * 与 policy iteration 的关系：policy iteration 中 policy evaluation 要算准需无穷步，实际只算一步或几步就切换到策略更新——Sarsa 正是这种思想，基于 generalized policy iteration（GPI）。

   * **例证：从特定起点到目标**

       * 任务类型差异：只求从一个特定状态（如左上角）出发到达目标的路径，不要求每个状态都最优——这与此前求所有状态最优策略的网格世界任务不同，实际中很常见。

       * 结果：从初始的不太好策略出发，Sarsa 学到的策略沿概率大的方向确实能到达目标；但许多其它状态未达最优。

       * 局限的可能成因：最优路径可能藏在未探索过的地方——只跑 500 个 episode 时这是有可能的；要找到所有状态的最优策略就必须探索所有 state-action pair。

       * 学习曲线两个观察：total reward 随策略改进而增大但不超过 0（ε-greedy 总会带进一些负 reward）；episode length 从最初几百步降到几十步。

## Expected Sarsa

   * **Expected Sarsa**

       * > **定义**：Sarsa 的变形，唯一区别在 TD target——把 $q_t(s_{t+1},a_{t+1})$ 换成对下一状态所有 action 按策略求期望：

$$
\bar{q}_t = r_{t+1} + \gamma \sum_{a} \pi(a \mid s_{t+1})\, q_t(s_{t+1}, a)
$$

       * 关键观察：这个期望求出来就是 $s_{t+1}$ 对应的 state value $v_\pi(s_{t+1})$，不再是一个 action value——TD target 变成 $r_{t+1}+\gamma v_t(s_{t+1})$。

       * 本质区别：Sarsa 需要采样 $a_{t+1}$，Expected Sarsa 不再需要 $a_{t+1}$。

       * 代价与收益各占一边：计算量更大（要算求和式）；但少采样一个随机变量，随机性减少。

       * 数学本质：仍在求解贝尔曼公式，只是把对 $A_{t+1}$ 的期望收进了 $v_\pi(S_{t+1})$ 里、在外层才对 $S_{t+1}$ 求期望：

$$
q_\pi(s, a) = \mathbb E\Big[R_{t+1} + \gamma\, v_\pi(S_{t+1})\Big], \qquad v_\pi(s_{t+1}) = \sum_a \pi(a \mid s_{t+1})\, q_\pi(s_{t+1}, a)
$$

       * 实验效果：网格世界（固定起点到目标）任务中，Expected Sarsa 学到的策略沿概率大的方向能到达目标；随学习进行每个 episode 的 reward 越来越大、到达目标所需步数越来越少。

---

## n-step Sarsa

   * **return 的多种分解**

       * action value 的基本定义：$q_\pi(s,a)=\mathbb E[G_t\mid S_t=s, A_t=a]$，即之后沿任何 trajectory 所得 return 的平均。

       * return 可以按「先取几步 immediate reward、其余汇总进一个 $q_\pi$」的方式做多种等价分解：

$$
G_t^{(1)} = R_{t+1} + \gamma\, q_\pi(S_{t+1}, A_{t+1})
$$

$$
G_t^{(2)} = R_{t+1} + \gamma R_{t+2} + \gamma^2 q_\pi(S_{t+2}, A_{t+2})
$$

$$
G_t^{(n)} = R_{t+1} + \gamma R_{t+2} + \cdots + \gamma^{n-1} R_{t+n} + \gamma^{n} q_\pi(S_{t+n}, A_{t+n})
$$

$$
G_t^{(\infty)} = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \cdots
$$

       * 关键对应：$G_t^{(1)}$ 对应 Sarsa，$G_t^{(\infty)}$ 对应蒙特卡洛，中间的 $G_t^{(n)}$ 对应 n-step Sarsa；这些 $G$ 全部等价，只是分解方式不同。

   * **一个算法覆盖两个极端**

       * > **定义**：n-step Sarsa 把 Sarsa 与蒙特卡洛统一在同一框架内：$n=1$ 即 Sarsa，$n=\infty$ 即蒙特卡洛，$n$ 取其它值即为折中。

       * 所求解的式子：$q_\pi(s,a)=\mathbb E\big[R_{t+1}+\gamma R_{t+2}+\cdots+\gamma^{n-1}R_{t+n}+\gamma^{n}q_\pi(S_{t+n},A_{t+n})\big]$；对应的随机逼近算法为

$$
q_{t+n}(s_t, a_t) = q_{t+n-1}(s_t, a_t) - \alpha_t\Big[q_{t+n-1}(s_t, a_t) - \big(\text{TD target}\big)\Big]
$$

       * 与 Sarsa、Expected Sarsa 的不同仍只在 TD target 一处；$n=1$ 时 TD target 退化为 $r_{t+1}+\gamma q_t(s_{t+1},a_{t+1})$。

       * $n=\infty$ 极端验证：取 $\alpha_t\equiv 1$，式子里前后两个 $q$ 相互抵消，$q_{t+1}$ 直接等于一整条 return 之和——这就是蒙特卡洛算法。

   * **数据、等待与 bias/variance**

       * 数据需求是折中的：Sarsa 只要 5 个数据 $(s_t,a_t,r_{t+1},s_{t+1},a_{t+1})$ 即可更新；蒙特卡洛要等 episode 结束的全部数据；n-step Sarsa 在 5 个之外还需再往后若干步的测量。

       * 更新时机的「等」：$t$ 时刻后边这些测量尚不存在，必须等到 $t+n$ 时刻所有需要的测量齐了才能更新（更新式左边是 $q_{t+n}$）——所以它既不是 offline 也不是 online，或者说是一种特殊的 online 方法。

       * | $n$ 的取值 | 性能倾向 | variance | bias |
         | :--- | :--- | :--- | :--- |
         | $n$ 较大 | 接近蒙特卡洛方法 | 比较大 | 比较小 |
         | $n$ 较小 | 接近 Sarsa | 比较小 | 比较大 |

       * $n$ 较小时较大的 bias 由初始猜测引起，随数据增多慢慢消失；它仍是 policy evaluation，要与 policy improvement 相结合才能搜索最优策略。

## Q-learning

   * **Q-learning**

       * > **定义**：直接估计 optimal action value 的 TD 算法——不需要在 policy evaluation 与 policy improvement 两步之间交替运行，因为直接把最优的 action value 估计了出来。

       * 更新式（结构与 Sarsa 一致，唯 TD target 不同）：

$$
q_{t+1}(s_t, a_t) = q_t(s_t, a_t) - \alpha_t\Big[q_t(s_t, a_t) - \big(r_{t+1} + \gamma \max_a q_t(s_{t+1}, a)\big)\Big]
$$

       * TD target 的区别：Q-learning 对 $a$ 求 maximization；Sarsa 是在 $s_{t+1}$ 处按当时策略选择一个 $a$，不做优化。

       * 数学本质：它求解的不是给定策略的贝尔曼公式，而是贝尔曼最优方程：

$$
q(s, a) = \mathbb E\Big[R_{t+1} + \gamma \max_a q(S_{t+1}, a)\Big]
$$

       * 该方程与之前贝尔曼最优方程的两点不同：含 expectation；基于 action value 而非 state value——但它仍是贝尔曼最优方程。

       * 解出的 $q$ 不是任何一个策略的 $q$ 值，而是最优的 $q$ 值，对应的策略就是最优策略。

       * 之所以两页就能讲完，是因为 RM 算法、SGD、TD 方法、Sarsa 已做了全部铺垫；直接看 Q-learning 会冒出「为什么长这样、什么是 TD target」等一连串问题。

---

## On-Policy 与 Off-Policy

   * **两个策略与算法分类**

       * > **定义**：behavior 策略（behavior policy）与环境交互、生成 experience；target 策略（target policy）是一直被更新的那个策略，最终要变成最优策略。两者相同称 on-policy，不同称 off-policy。

       * off-policy 的直接好处：可以从别人之前积累的经验中直接学习；典型用法是让探索性极强的 behavior policy 覆盖所有 state-action pair，从而估准每个 $(s,a)$ 的 action value——若必须用 target policy（greedy 或 ε-greedy）亲自采数据，探索性弱、难以覆盖所有 $s$ 和 $a$。

       * 该分类不针对 Q-learning 一家：所有强化学习算法都存在这个分类问题。

       * 判断工具有二：一看算法在数学上解决什么问题（贝尔曼公式还是贝尔曼最优公式）；二看算法实施时需要哪些东西才能跑起来（哪些量依赖哪个策略产生）。

   * **Sarsa 是 on-policy**

       * 数学面：Sarsa 求解给定策略的贝尔曼公式，式子处处都是这个给定的策略——五元组中 $r_{t+1}$ 与 $s_{t+1}$ 由 $p(r\mid s,a)$、$p(s'\mid s,a)$ 决定、与任何策略无关，但第 5 个量 $a_{t+1}$ 是在 $s_{t+1}$ 按策略 $\pi_t$ 采样得到的，这个 $\pi_t$ 就是 behavior policy。

       * target 面：Sarsa 估计的正是 $\pi_t$ 的 action value，再用它改进 $\pi_t$ 得 $\pi_{t+1}$——$\pi_t$ 既是 behavior policy 又是 target policy。

```text
    πt ──生成──> experience ──估计──> qπt ──改进──> πt+1
     ▲                                            │
     └────────────────────────────────────────────┘
```

   * **蒙特卡洛方法也是 on-policy**

       * 流程自证：用策略 $\pi$ 生成 trajectory，用这条轨迹的 return 估计 $q_\pi$，再用估计值改进 $\pi$——$\pi$ 既是 behavior policy 又是 target policy。

       * on-policy / off-policy 是对所有强化学习算法的分类，不限于 TD 算法。

   * **Q-learning 是 off-policy**

       * 数学面：Q-learning 求解贝尔曼最优公式，而最优公式不涉及任何策略（虽然它对应最优策略，但式子里显式不含策略）——方程里没有策略，谁来生成数据就可以灵活安排。

       * 实施面：所需测量是 $s_t,a_t,r_{t+1},s_{t+1}$ 这 4 个（$r_{t+1}$、$s_{t+1}$ 与策略无关）；策略出现在从 $s_t$ 出发按某策略得到 $a_t$——这是 behavior 策略；而 target 策略是「每到一个状态看哪个 action 的 $q$ 大就选哪个」，$q$ 收敛到最优时 target 策略也收敛到最优策略——两个策略不同。

## Q-learning 的两种版本

   * **on-policy 版本**

       * > **定义**：强行让 Q-learning 的 behavior policy 与 target policy 相同所得的版本（「相同」是「不同」的特殊情形）。

       * 与 Sarsa 几乎一模一样，唯一区别是把 $q_t(s_{t+1},a_{t+1})$ 换成在 $s_{t+1}$ 处按当前 ε-greedy 策略对 $a$ 求期望的那一项；策略更新仍用 ε-greedy。

       * 流程闭环：策略生成数据、数据得到 $q$、$q$ 改进策略、改进后的策略再生成数据——同一策略既采数据又被更新，故为 on-policy。

   * **off-policy 版本**

       * > **定义**：设一个专门的 behavior 策略 $\pi_b$ 生成 experience，任务是根据已有经验寻找最优策略；$q$ 的更新与 on-policy 版本完全相同，target 策略 $\pi_t$ 的更新改为 Greedy。

       * target 策略用 Greedy 而非 ε-greedy 的原因：ε-greedy 是为了拿它去生成数据时保有探索性；而 $\pi_t$ 根本不参与生成数据（那是 $\pi_b$ 的事），直接 Greedy 即可——随 $q$ 估计越来越准，$\pi_t$ 收敛到最优策略。

```text
    πb ──生成──> experience ──更新──> qt ──Greedy──> πt
  (只管采数据)                  (不断逼近最优 q)   (只管当策略)
```

   * **实验：behavior policy 探索性有多重要**

       * 任务是找到每一个状态的最优策略（与 Sarsa 实验的固定起点任务不同）；ground truth 为最优策略与 optimal state value。

       * behavior policy 取均匀采样策略（5 个 action 各 0.2 概率、探索性强），跑 100 万步每个 state-action pair 都被访问很多次；用 off-policy 的 Q-learning 学出的策略与 ground truth 基本一致，估计过程中各策略的 state value 与最优 state value 之差的模也从有距离降到几乎为零。

       * 反例系列：behavior policy 取 $\varepsilon=0.5$ 但大体向右走的策略，100 万步后仍有许多 state-action 未被访问，学得的策略离最优差距明显；$\varepsilon=0.1$ 的策略探索更弱、结果更差；另一个小 ε 的非定向策略同样误差较大。

       * > **结论**：off-policy 给了把「采数据」和「学策略」分开的自由，但数据质量仍由 behavior policy 决定——探索性不足，再好的学习算法也救不回来。

## TD 算法的统一形式

   * **统一表达式**

       * > **定义**：本章所有 TD 算法都可写成同一形式：

$$
q_{t+1}(s_t, a_t) = q_t(s_t, a_t) - \alpha_t\Big[q_t(s_t, a_t) - \bar{q}_t\Big]
$$

       * 基本思路：让 $q_t$ 接近 TD target $\bar q_t$；两者之差就是 TD error，算法的目标就是减小 TD error。

       * 所有 TD 算法的不同点只在 $\bar q_t$ 一处：

       * | 算法 | TD target $\bar{q}_t$ | 求解的公式 |
         | :--- | :--- | :--- |
         | Sarsa | $r_{t+1} + \gamma q_t(s_{t+1}, a_{t+1})$ | 贝尔曼公式 |
         | n-step Sarsa | $r_{t+1} + \gamma r_{t+2} + \cdots + \gamma^{n-1} r_{t+n} + \gamma^{n} q_t(s_{t+n}, a_{t+n})$ | 贝尔曼公式 |
         | Expected Sarsa | $r_{t+1} + \gamma \sum_a \pi(a \mid s_{t+1})\, q_t(s_{t+1}, a)$ | 贝尔曼公式 |
         | Q-learning | $r_{t+1} + \gamma \max_a q_t(s_{t+1}, a)$ | 贝尔曼最优公式 |
         | 蒙特卡洛 | $r_{t+1} + \gamma r_{t+2} + \cdots$（一整条 return） | action value 的定义 |

       * 蒙特卡洛也能装进统一式子：取 $\alpha_t=1$，系数 1 省略后式内 $q_t-q_t$ 相互抵消，$q_{t+1}$ 直接等于那条完整的 return；它可看成 n-step Sarsa 的特殊情况。

       * 数学问题也统一：它们都是求解贝尔曼公式或贝尔曼最优公式的随机逼近（stochastic approximation）算法；贝尔曼公式 expectation 里的那些东西，实际上就对应算法里的 TD target。

       * 与经典方法的关系：值迭代和策略迭代是**基于模型**求解贝尔曼公式与贝尔曼最优公式，TD 方法是**没有模型**求解同样的公式——两者由此对应起来。

       * 从求解给定策略的贝尔曼公式到搜索最优策略：把 policy evaluation 与 policy improvement 相结合即可；Q-learning 因为直接解贝尔曼最优公式而无需这种结合。

       * off-policy 性质的重要性延伸：Deep Q-learning 把神经网络与 TD 算法结合时选择 Q-learning，其 off-policy 性质在其中发挥了重要作用。
