## 从 ε-Greedy 到 Robbins-Monro：去掉探索条件，走向随机近似
> 对应块：BLK06 | 覆盖分集：P20-P23 | 块标题（分集名）：《第5课-蒙特卡洛方法（MC Epsilon-Gr》

上一讲的 MC Exploring Starts 算法虽然漂亮，但留着一个让人不舒服的条件：exploring starts——episode 必须从每一个 state-action pair 出发各来一遍。这一讲的前半部分，我们就来把这个条件去掉，办法是引入 soft policy，具体用的工具叫 ε-greedy。讲完这个，蒙特卡洛这一章就收尾了。后半部分我们按下暂停键，提前补一块背景知识——随机近似（Stochastic Approximation）与随机梯度下降（Stochastic Gradient Descent），它是下一讲 Temporal-Difference Learning 的地基。

### 去掉 exploring starts：引入 soft policy

什么是 soft policy？简而言之，就是它对每一个 action 都有可能去做选择。

我们之前提到过，policy 其实分为两种：第一种是确定性的（deterministic）policy，我们常说的 greedy policy 就是 deterministic 的；还有一种是随机性的（stochastic）policy，soft policy 以及后面要介绍的 ε-greedy 都是 stochastic policy。

为什么引入 soft policy 就能去掉 exploring starts？回想一下那个条件为什么讨人嫌：我们要求从每一个 $(s,a)$ 出发都有一条 episode。而现在，如果我从一个 state-action pair 出发，后边的 episode 特别特别长——因为它是探索性的——实际上我能够确保任何一个 $s$ 和 $a$ 都能被这个 episode 访问到。这样的话，我不需要从每一个 $(s,a)$ 都出发了，我只要从一个或者几个出发，就能够覆盖到其它的。

那么这里边 soft policy 我们要用什么呢？就是 ε-greedy policy。当然，soft policy 不仅仅包括 ε-greedy，但我们这里重点关注的就是它。

### ε-greedy：给每个 action 一点机会

在一个状态 $s$ 下，它有一个 greedy action $a^*$，对应的 $q_\pi(s,a^*)$ 是最大的。ε-greedy 的做法是：给这个 greedy action 一个最大的选择概率，给其它不是 greedy 的 action 各一个相同的小概率：

$$
\pi(a\mid s)=
\begin{cases}
1-\varepsilon+\dfrac{\varepsilon}{|\mathcal A(s)|}, & a=a^* \\[2mm]
\dfrac{\varepsilon}{|\mathcal A(s)|}, & a \neq a^*
\end{cases}
$$

这个式子猛地看起来比较复杂，但实际上非常简单。这里边的 $\varepsilon$ 是从 0 到 1 的一个正数，$|\mathcal A(s)|$ 就是状态 $s$ 所对应的 action 的个数。

举个例子：在 grid-world example 当中，每一个状态所对应的 action 个数等于 5。如果我们选 $\varepsilon=0.2$，那么 $\varepsilon/|\mathcal A(s)| = 0.2/5 = 0.04$，也就是有四个非 greedy 的 action，它们的概率都分别是 0.04；剩下的那个 greedy action 的概率是 $1-0.16=0.84$。

通过这个例子可以看到：greedy action 有最大的概率被选择，但其它 action 也有比较小的概率可以被选到。

这里有一个性质：选择 greedy action 的概率始终比其它任何一个 action 的概率都要大。这个验证起来比较简单——只要 $\varepsilon$ 是从 0 到 1 的数，$1-\varepsilon+\varepsilon/|\mathcal A(s)|$ 就始终大于 $\varepsilon/|\mathcal A(s)|$。意思就是：我虽然给了其它 action 一些正数的概率、可能会去选择它们，但我把最大的概率还是留给了 greedy action。

### exploration 与 exploitation 的天平

我们为什么要用 ε-greedy？就是因为它能够去平衡 exploitation 和 exploration。这两个单词比较绕口，但我相信大家在学习强化学习的时候会经常听到，这里详细介绍一下。

**exploitation** 指的是什么呢？字面的翻译是"剥削"，它实际上应该是充分利用的意思。比如我在一个状态下有很多个 action，其中有的 action 我此时此刻知道它的 action value 是比较大的——我知道这些信息，那么下一个时刻我就应该去采取那个 action，我相信未来能得到更多的 reward。这个就称为充分的利用。

**exploration** 是什么？就是我现在虽然知道那个 action 能给我带来很多 reward，但是说不定现在的信息是不完备的，说不定我应该去探索一下其它的 action——执行完之后我可能发现，其它 action 的 action value 其实也是非常好的。这个就叫探索。

对于 ε-greedy 这个策略，$\varepsilon$ 的取值直接决定天平往哪边倒：

| $\varepsilon$ 的取值 | 策略退化成什么 | 探索性 | 充分利用性 |
| :---: | :---: | :---: | :---: |
| $\varepsilon=0$ | greedy | 弱一些 | 强一些 |
| $\varepsilon=1$ | 均匀分布 | 更强 | 更弱一些 |

如果 $\varepsilon=0$，很显然 greedy action 的概率项等于 0、其它项等于 1，这时候 ε-greedy 就变成了 greedy——探索会弱一些，但充分利用会强一些。

如果 $\varepsilon=1$，那这时候对每一个 action 的选择概率全都相同了，所以变成了一个均匀分布。还是刚才那个例子：5 个 action，$\varepsilon/|\mathcal A(s)| = 1/5 = 0.2$，剩下的概率也不难计算，也是 0.2——5 个 action 每一个的选择概率都是 0.2。这时候的探索性会更强，充分利用性会更弱一些。

### 把 ε-greedy 嵌进蒙特卡洛：MC ε-Greedy 算法

介绍了 ε-greedy，那怎么把它和我们正在研究的基于蒙特卡洛的强化学习问题结合在一起呢？实际上非常简单。

先回顾 MC Basic 和 MC Exploring Starts 这两个算法里的 policy improvement 步骤：第一步先求出 $q_{\pi_k}$，然后求解一个优化问题得到新的策略。之前其实没有强调，但我们在求解这个优化问题的时候，这个 $\pi$ 应该是在**所有可能的策略**当中去做选择——所有可能的策略组成的集合我们用大 $\Pi$ 来表示。求解出来最优的策略是什么？就是 greedy policy。

现在要做的事很简单：把 ε-greedy 嵌入到这个算法当中。怎么嵌？就是在求解这个优化问题的时候，我不是在所有策略里面去找，而只是在大 $\Pi_\varepsilon$ 里边去找——大 $\Pi_\varepsilon$ 代表所有的 ε-greedy 策略，这里的 $\varepsilon$ 是事先给定的。那这时候所得到的最优策略其实也不难得到：就是把最大的概率仍然给 greedy action，但是给其它所有的 action 一个相同的、比较小的概率。

这样我们就得到了 **MC ε-Greedy** 这个算法。它和 MC Exploring Starts 基本上是一模一样的，只有两个区别：

- policy improvement 那一步用的策略不同：MC Exploring Starts 里用的是 greedy 策略，这里用的是 ε-greedy 策略；
- 估计 action value 时用的是 every-visit。为什么要用 every-visit？因为这时候可能会有一个非常长的 episode，如果只用 first-visit，很多 state-action pair 实际上被访问了很多次，但我只用了它的一次去做 action value 的估计，实际上是有些浪费的，所以要用 every-visit。

它的伪代码和 MC Exploring Starts 的伪代码一模一样，除了上述两点。那为什么要费这个劲换策略？就是因为通过使用 ε-greedy 这样一个策略，我们就不需要 exploring starts 这个条件了。

### ε 的两个极端：探索性到底有多强

嘴上说 ε-greedy 有探索性还不够，我们用例子看看它的探索性究竟有多强。

**先看 $\varepsilon=1$，也就是探索性最大的情形。**这时候 policy 实际上变成了一个均匀分布：每个状态有 5 个 action，每一个都给了 0.2 的概率。从一个状态出发，根据这个策略生成 episode：

- 只有 100 步的话，已经探索到了不少的 state；
- 1000 步的话，基本上所有的 state 还有它们相应的 action 都被探索到了；
- 1 万步的话，探索的次数会更多；
- 100 万步的时候，我们统计每一个 state-action pair 被访问的次数：一共有 25 个状态、每个状态 5 个 action，所以一共 125 个 state-action pair。可以看到，虽然只有一个 episode，但每一个 state-action pair 都被访问了很多次——七八千次。

这个例子非常明显地说明：当 $\varepsilon$ 比较大的时候，探索性是比较强的。那我自然就不再需要 exploring starts 这个条件了——我不需要从每一个 $(s,a)$ 出发各有一条 episode，我只要从某一些 $(s,a)$ 出发，就能覆盖到其它所有的 $(s,a)$。

在这个基础之上再看一个动态的过程，更直观：一个 agent 根据这个 ε-greedy 策略在环境里不断探索。最开始它从一个状态出发，基本上被困在那个地方了，因为周围难以出去——但它一直在那里探索，靠着选其它 action 的小概率，真的从那个地方出来了，又跑到别的地方去看看能不能再往前走。到目前为止基本上所有的 state 都访问到了，但有一些 action 还没有被访问到，最后那些 action 也被访问到了。所以这个例子更直观地展示了它的探索性：一条 trajectory 实际上就探索了很多。

**再看 $\varepsilon$ 比较小的情形。**很自然，它的探索能力是比较弱的。100 步的时候，访问的 state 还是比较少的，因为它对 greedy action 的偏好是比较强的；即使到了 100 步、1000 步、1 万步，还是有一些 action 没有被访问到。即使把 episode 的长度变成 100 万步，访问次数会呈现出非常不均匀的分布：有的 state-action pair 被访问的次数非常多，有的则比较少。但是不管怎么说，相比 greedy 来说，它还是有一定的探索能力的。

### 实战一遍：探索换来的好处与付出的代价

看到 ε-greedy 确实有探索能力了，接下来用 ε-greedy 结合蒙特卡洛这个算法去实际求解一个例子，看看它能给我们带来什么样的最优策略。

在这个例子当中，每一个 iteration 我们这么做：用当前的 ε-greedy 策略生成一个 episode——这个 episode 是非常长的，有 100 万步——然后用这一个 episode 去更新所有 state-action pair 相对应的 action value 以及策略。我为什么这么做？就是想通过这个例子展示一下：这个算法确实避开了 exploring starts 这个条件——只要这个 episode 足够长，即使它从一个 state-action pair 出发，它仍然能够访问所有其它的 state-action pair。

结果怎么样？最初的一个策略显然是不好的：它在每一个状态都有相同的概率去选择所有的 action。用这个策略生成一个 100 万步长的 episode，然后更新策略，得到第二个策略——这个策略还是不太好的，有些点它还是会保持不动。再用第二个策略生成一个 100 万步长的 episode，再去更新策略，得到第三个策略。这最后一个策略，如果我们只去看概率最大的那个 action，会发现相对来说已经比较合理了：起码从任何一点出发，它都能够到达目标。但是它们会穿过障碍物，所以从这个意义上讲，它还不是最优的——我们知道最优的策略应该是绕过障碍物到达目标。

所以总而言之：ε-greedy 确实通过它的探索性得到了一些好处，但它付出的牺牲就是最优性。

那实际当中怎么平衡？可以设置一个比较小的 $\varepsilon$ 的值。当 $\varepsilon$ 趋向于 0 的时候，ε-greedy 就接近于 greedy，所以用这个算法找到的最优 ε-greedy 策略，也就接近于最优的 greedy 策略。实际当中我们也可以让 $\varepsilon$ 逐渐减小：比如开始的时候 $\varepsilon$ 比较大，它有比较强的探索能力；然后让 $\varepsilon$ 逐渐趋向于 0，最后所得到的策略又有比较好的最优性。后面还有一组例子专门来说明这一点。

### ε 不能太大：最优性会被吃掉

ε-greedy 的最优性到底是怎么被吃掉的？我们给出一组策略，逐个求解它们的贝尔曼公式、算出 state value 来看。

第一个策略，$\varepsilon=0$，实际上是一个 greedy 的策略，并且它是这个情况下最优的一个策略，它对应的 state value 是最高的。

第二个策略和第一个策略是什么关系？它们是 **consistent（一致的）**。为什么这么说？比如在某一个地方，第一个策略要往上走；在第二个策略当中，它在这个地方最大的概率也是往上走，但与此同时，它给其它的 action 也留了一些比较小的概率。这个就被称为 consistent。这时候解算出来的 state value 明显比第一个要小——为什么？就是因为它在很多地方采取了不该采取的措施。

如果我们进一步地增大 $\varepsilon$，会发现 state value 变得更小；当 $\varepsilon=0.5$ 的时候，很多地方的 state value 都已经变成了负数。

我们知道，state value 其实可以用来衡量一个策略到底好还是不好——最优策略的定义实际上就是基于 state value 的：最优的策略是有最大的 state value。所以结论就是：虽然这里所有的策略都和最优的 greedy 策略保持一致（consistent），但它们的最优性变得越来越差。

这里面有一个很典型的例子：target area 在最优的策略里面，它的值是最大的；但是当 $\varepsilon$ 比较大的时候，它反而变成最小的值、负数的值。为什么？就是因为在 target area 这个地方，策略有比较大的概率进到 forbidden area，会得到非常多的负 reward。

> **易错点**：consistent 说的是两个策略"最大概率的方向一致"，不是说两个策略相同。ε-greedy 策略可以和 greedy 策略 consistent，但它们的 state value 可以差得很远。

接下来再用 MC ε-Greedy 算法去求解一组例子，这里有一个很有意思的结论，希望大家能够掌握。问题还是那个 grid world，我先直接给出它的最优策略——是一个 greedy 的策略——以及相对应的 optimal state value。然后我们用 MC ε-Greedy 算法、设置 $\varepsilon=0.1$，算法最后给我们的结果是这样的一个策略：它和刚才那个最优的策略有一个很重要的关系——**consistent**。简而言之就是：任意选择一个状态，比如最优策略在某处要往右走，那么 MC ε-Greedy 求出的策略在该处最大的概率也是往右走。

这个一致性是非常重要的。为什么？因为用 MC ε-Greedy 得到 optimal ε-greedy 策略之后，我肯定要把它用到实际当中去；但实际当中我不会再带着这个 $\varepsilon$，我会把它转成所对应的 greedy 策略。这个 greedy 策略，我希望它和最优策略是相同的。当 $\varepsilon=0.1$ 的时候，我的愿望成真了：把它转成 greedy，它真的就是这个最优的 greedy 策略。

但是当 $\varepsilon=0.2$ 的时候，大家看它求出的最优 ε-greedy 策略，就完全和最优 greedy 策略没有什么太大关系了——如果你转过去的话，它们俩就是不一样的。类似地，如果 $\varepsilon=0.5$，所得到的最优策略转成 greedy 之后，也不再是最优的 greedy 策略。

所以这组例子告诉我们：如果你想用 MC ε-Greedy，那你的 $\varepsilon$ 不能太大。或者说，实际中的一个技巧就是：最开始的时候 $\varepsilon$ 总是比较大、探索性比较强，最后 $\varepsilon$ 逐渐减小到 0，然后就可以得到一个最优的策略。

到这里，蒙特卡洛这一章的内容就全部介绍完了。回顾一下这一章：最开始我们是通过 motivating example 来介绍蒙特卡洛的方法——不需要模型，怎么样用数据去估计一个 expectation——然后把这个方法应用到了强化学习当中，提出了 3 种算法。这 3 个算法之间有非常强的关系：最开始的算法是最简单的，然后逐渐地越来越复杂，效率也越来越高；最后我们给了大量的例子，说明了 ε-greedy 的一些性质。说实话，这一讲的录制是我有史以来最花时间的一次，内容比较庞杂、有的地方逻辑性也比较强，反反复复录了很多遍，就是希望能给大家呈现一个比较好的效果，让大家学习的时候少一些疑问、多一些顺畅。

### 均值估计的另一种解法：增量与迭代

先回顾 mean estimation 这个问题：考虑随机变量 $X$，我们的目标是求出它的期望 $\mathbb E[X]$；我们有一些 iid 的采样 $x_i,\ i=1,\dots,n$，怎么用这些采样来估计期望呢？把这些采样求平均值，得到的 $\bar x$ 就认为是 expectation 的一个近似值。这实际上上节课都已经讲过了，也是蒙特卡洛方法的基本思路；同时我们也知道，当有足够多的数据时，平均数会逐渐收敛到真实的 expectation。

为什么这次课又要关注 mean estimation？就是因为强化学习当中其实有非常多的 expectation——除了 state value 这些定义之外，之后大家会明白还有很多——这时候我们都要用数据去进行估计，所以会再一次研究这个问题。

下面有一个新的问题：我们能**怎么来计算**这个平均数 $\bar x$？大家听了这个问题可能感觉不着边际——怎么计算？这不很简单吗，相加除以 $n$ 不就完了？这实际上是一种方法，实际上我们有两种方法：

- 第一种就是相加除以 $n$。它的问题是什么？如果有很多这样的数据——因为它是采样得到的——那我得等很久，等所有数据全收集到一起之后我再求平均。
- 第二种方法相对来说就能克服这个问题：它是一种增量式的（incremental）、迭代式的（iterative）方法。基本思路就是：来几个我就先计算几个，这样的效率会更高一点。

我们来详细看第二种方法。针对前 $k$ 个采样 $x_1$ 一直到 $x_k$ 求一个平均，把这个平均记作 $w_{k+1}$——它等于 $\frac{1}{k}\sum_{i=1}^{k}x_i$。这里写成 $w_{k+1}$ 而不是 $w_k$，是为了之后形式上简洁一些（相应的 $w_k$ 就是前 $k-1$ 个 $x_i$ 的平均数）。我们要做的事，是建立起 $w_{k+1}$ 和 $w_k$ 之间的关系——让 $w_{k+1}$ 能够通过 $w_k$ 表示出来：

$$
w_{k+1}=\frac{1}{k}\sum_{i=1}^{k}x_i
=\frac{1}{k}\Big(\underbrace{\sum_{i=1}^{k-1}x_i}_{=(k-1)\,w_k}+x_k\Big)
=\frac{k-1}{k}w_k+\frac{1}{k}x_k,
$$

简单整理一下，把式子单独拎出来：

$$
w_{k+1}=w_k-\frac{1}{k}\left(w_k-x_k\right).
$$

这样我们就得到了一个迭代式的算法：比如上个时刻我已经计算出来 $w_k$ 了，那么这个时刻来了一个新采样 $x_k$，我直接通过这个式子就可以得到新的 $w_{k+1}$——不需要再把前面 $k$ 个 $x_i$ 全部加起来然后再求平均。

那这个式子到底对不对？我们代进去验证一下。最开始有一个 $x_1$，把 $x_1$ 给到 $w_1$。然后 $w_2$ 等于什么？根据公式，$w_2 = w_1 - \frac{1}{1}(w_1 - x_1)$——$w_1$ 是 $x_1$，所以后面括号里是 0，于是 $w_2 = x_1$，这正是第一个采样的平均。再把 $w_2=x_1$ 代进去算 $w_3$，最后得到 $\frac{1}{2}(x_1+x_2)$，正是前两个采样的平均。再往下代就不再详细代了，同样可以得到 $w_4=\frac{1}{3}(x_1+x_2+x_3)$，最后一直归纳到 $w_{k+1}=\frac{1}{k}\sum_{i=1}^{k}x_i$。这样我们就得到了一个求平均数的迭代式算法。

这个算法的优势就是：在第 $k$ 步，我不需要把前面所有的 $x_i$ 全部加起来再求平均，只要通过这一步计算，就可以得到一个新的、正确的平均数。当然，求平均数的操作本身比较简单，可以有很多方法；这里通过这个例子想说明的是这样一种思路——它代表了一种**增量式的计算思想**。

在一开始的时候，$w_k$ 因为数据量比较小，难以非常精确地逼近 $\mathbb E[X]$。但是**有总比没有强**——总比我一直等、等到最后才能得到一个平均数要强。而且在这个过程当中，虽然 $w_k$ 不精确，它也可以用到其它任务当中去；随着数据量越来越大，$w_k$ 也会越来越精确地逼近 $\mathbb E[X]$。

这个算法还可以进一步推广。刚才的系数实际上是 $1/k$，现在把这个系数替换成一个正数 $\alpha_k$。如果是 $1/k$，我们刚才验证过，$w_1, w_2, w_3,\dots$ 这样迭代下去，能显式地写出它们确实就是平均数；但如果 $\alpha_k$ 不是 $1/k$，就写不成那种形式了——那这时候 $w_k$ 是否还能逐渐逼近 $\mathbb E[X]$ 呢？实际上是可以的，当 $\alpha_k$ 满足一些条件的时候就可以，之后我们会详细介绍。

另外，通过这些例子引入这个算法，我还想说明一点：这个算法实际上就是一种特殊的 Stochastic Approximation 算法，也是一种特殊的 Stochastic Gradient Descent 算法。下节课我们看到 Temporal-Difference Learning 的算法时，到时候我们也不会吃惊——因为那些算法和这个算法有非常类似的形式。这节课把这类算法学会了之后，会为下节课奠定非常好的基础。

### 随机近似与 RM 算法要解的问题

前面反复提到了随机近似（stochastic approximation，简称 SA），它究竟是什么？首先，SA 代表了一大类算法——什么样的算法呢？stochastic iterative algorithm，随机的并且是迭代的这种算法。"随机"是说它里边会涉及到对随机变量的采样。SA 特指的是：要进行**方程的求解**或者是**优化问题**的这一类算法。能够做方程求解和优化问题的算法有很多，比如说 gradient descent 这种梯度下降或者梯度上升的方法。那 SA 的优势或者特点是什么？**它不需要知道方程或者目标函数的表达式**，那自然也不知道它的导数或者梯度的表达式。我不知道这些，怎么样进行求解？这个可能猛地一听很奇怪——我求解一个方程，我连这个方程长什么样子都不知道？是的，待会大家就会明白这是怎么一回事。

Robbins-Monro 算法（简称 RM 算法）是随机近似这个领域非常具有开创性的一个工作。我们常用的随机梯度下降（SGD），是 RM 算法的一种特殊情况；前面通过例子介绍的那个 mean estimation 算法，实际上也是一种特殊的 RM 算法。

下面来看 RM 算法要解决的问题。我们要求解这样一个方程：

$$
g(w)=0,
$$

其中 $w$ 是要求解的未知量，$g$ 是一个函数。简单起见，我们都考虑标量的情况，$w$ 和 $g$ 全都是标量。

首先要说，这个问题看似简单，但是它非常有用，因为它广泛存在。一个比较典型的例子就是做优化：比如我要优化一个目标函数 $J(w)$，怎么优化呢？一般而言，我都是求解这样一个方程——$J(w)$ 的梯度等于 0。梯度等于 0 是 $J(w)$ 达到最大或者最小的一个**必要条件**，它并不是充分条件；但是在很多情况下，我们能够找到局部的极值。或者说，当 $J(w)$ 只有一个极值的时候，这就变成了充分必要条件。总而言之，这种优化问题也可以写成 $g(w)=0$ 的形式，这时候 $g(w)$ 指的就是梯度。另外，如果我们面临的是 $g(w)=c$、右边是一个常数，那我可以把 $c$ 移到左边，变成一个新的 $g(w)$，仍然可以化成 $g(w)=0$ 这种形式。

那怎么样求解 $g(w)=0$？实际上有两种情况。第一种情况，$g$ 的表达式是知道的——这时候有很多种方法可以求解，如果 $g$ 是某种特殊的函数，甚至都有相应的专门算法。而我们这里要考虑的，是一个非常有意思的情况：**$g$ 函数的表达式我根本不知道**。大家可能会说：$g$ 的表达式不知道，我怎么求解呢？实际上大家可以想想神经网络：$y=g(w)$，我现在有一个神经网络，输入是 $w$，输出是 $y$——它里边实际上就是 $g(w)$ 这样一个函数。常见的全连接神经网络，大家知道，它就是做一个函数的近似，神经网络里面所谓的表达式我们是不知道的。所以我现在的问题就是：我输入什么样的 $w$，能够得到一个 0 的输出呢？就是这样一个问题。而这样一个问题，就可以用 RM 算法来求解。

### 黑盒、噪音与数据：RM 算法的运行方式

RM 算法是一个迭代式的算法。我们的目标是求解 $g(w)=0$，假设最优解是 $w^*$。对 $w^*$ 的第 $k$ 次估计记作 $w_k$，那么第 $k+1$ 次的估计是：

$$
w_{k+1}=w_k-a_k\,\tilde g(w_k),
$$

后面这部分又进一部分为两个零件：第一个是 $a_k$，是一个系数；第二个是 $\tilde g$，这是一个函数。$\tilde g$ 的表达式也很简单，它实际上就是

$$
\tilde g(w_k)=g(w_k)+\eta_k,
$$

其中 $\eta_k$ 是一个噪音。所以 $\tilde g$ 是什么？**$\tilde g$ 是 $g$ 的一个观测，但是是带有噪音的观测。**

在这个算法当中，我们实际上把函数 $g(w)$ 当作了一个黑盒——我们确实不知道它的表达式是什么。算法总需要一些信息，那它所需要的信息实际上就是**数据**：输入的 $w$ 的序列，还有测量到的 $\tilde g$ 的序列。整个过程用图来看：

```text
          w_k ──────► ┌───────────────┐
                      │   黑盒 g(·)   │ ──► y = g(w_k)   （表达式未知）
                      └───────────────┘            │
                                                   │ + 噪音 η_k
                                                   ▼
          w_{k+1} ◄── w_{k+1} = w_k − a_k·ḡ_k ◄── 可测量输出 ḡ_k = g(w_k) + η_k
```

读图：输入 $w$ 之后，黑盒给出 $y=g(w)$，但这个 $y$ 我不能直接测量，还要再加上一个噪音，我能测量到的是 $\tilde g$。最开始我输入 $w_1$，得到 $\tilde g_1$，然后代入更新式得到 $w_2$；再把 $w_2$ 输入，得到 $\tilde g_2$，代入得到 $w_3$……这样迭代下去，所以最后这边有一个 $w$ 的序列，那边也有一个 $\tilde g$ 的序列，RM 算法就是通过这样一种方式来求解的。

这里其实又体现了那种哲学的思想：**我们没有模型的时候，就得有数据。**这里边的模型就是指函数的表达式。这和我们前面介绍的基于模型的强化学习和不基于模型的强化学习是一样的：我有模型的时候就不需要数据；你没模型了，你就得有数据——反正你总得有一个。

### 一个直观例子：RM 为什么会收敛

刚才我们说 RM 确实能找到那个解，下面来分析它为什么能够找到。为了分析 RM 算法的收敛性，我们分两部分：第一部分先再给一个例子，通过这个例子直观地看一下它为什么会收敛；第二部分是给出一个严格的数学结论。这里先看直观的部分。

这个例子里，$g(w)$ 等于一个反 tangent 函数（arctan），要求解的就是 $g(w)=0$。把这个函数画出来：横轴是 $w$，纵轴是 $g(w)$；因为它是 arctan 函数，曲线上面是 $\pi/2$、下面是 $-\pi/2$，它的真实解在 $w^*=1$。

我们用 RM 算法来求解这个问题：初始值给 $w_1=3$，系数 $a_k=1/k$；为了简单起见，噪音不考虑——本来算法里测量的是带噪音的 $\tilde g$，现在直接就是 $g(w)$。结果是这样的：从 $w_1$ 出发，第一步计算出 $g(w_1)$，这个函数值的高度乘以一个数就等于一段水平距离，$w_1$ 减去这一段就跳到 $w_2$；然后再计算 $g(w_2)$，再把这一段高度乘以一个数，跳到 $w_3$……一直这样下去，就走到了 $w^*$。

通过这个例子可以非常明显地看到：$w_{k+1}$ 总是比 $w_k$ 更接近于 $w^*$。为什么？分两种情况：

- 如果 $w_k > w^*$，那么 $g(w_k) > 0$，更新式要减去一个正数，所以得到的 $w_{k+1}$ 一定比 $w_k$ 小，往回退，就更接近 $w^*$ 了；
- 如果 $w_k < w^*$，那么 $g(w_k) < 0$，减去一个小于 0 的数就是加上一个数，所以 $w_{k+1}$ 比 $w_k$ 更大，往前走，也更接近 $w^*$。

这就是直观的一个例子，告诉大家 RM 算法为什么会收敛。

其实还可以从黑盒的视角再看一遍这个思路：我给一个 $w$，看一下输出；我发现这个输出大于 0，那怎么办呢？我就把 $w$ 调小一点，这样输出就会小一点；一直小、小、小，小到输出等于 0 的时候，我这个 $w$ 就停止了。就是这么简单。但是这里边主要的精髓在于：我每次调小，**得小多少**？这个就是 RM 算法给出的答案——减去 $a_k$ 乘以 $g$。

## 随机近似与随机梯度下降：从 Robbins-Monro 定理到 SGD
> 对应块：BLK07 | 覆盖分集：P24-P28 | 块标题（分集名）：《第6课-随机近似与随机梯度下降（Robbins-》

前面的例子已经比较直观地解释了 RM 算法为什么能收敛，这一部分我们给出严格的数学描述——一个收敛性定理。这一块相对数学化，不感兴趣可以直接跳过去，但里面有不少有意思的东西：尤其是对步长系数的那组条件，你未来学 Temporal-Difference Learning 的时候还会经常看到，所以有余力的话，非常建议你仔细读一下这一部分。

### RM 算法的收敛性定理

这个定理说的是：针对 RM 算法

$$w_{k+1}=w_k-a_k\tilde g(w_k),\qquad \tilde g(w_k)=g(w_k)+\eta_k$$

如果下面这三个条件都满足了，那么 $w_k$ 就会收敛到 $w^*$，而 $w^*$ 就是 $g(w)=0$ 的那个解。

首先说收敛的方式：这里说的收敛叫 **with probability 1**，简称（w.p.1）。你以后学强化学习、看强化学习的论文，凡是涉及到证明的，或多或少都会有这个 with probability 1。为什么？因为这里的 $w_k$ 不是一个普通的数，它涉及到随机变量的采样，所以它的收敛不是常规意义上的收敛，而是概率意义上的收敛。关于这部分可以参考一些资料——我这本书现在这个版本里还没有，未来的附录当中会把这一部分添加进去。

三个条件各管一头：第一个是关于 $g(w)$ 的梯度，第二个是关于系数 $a_k$，第三个是关于测量误差 $\eta$。下面逐个解读。

#### 条件一：$g(w)$ 的梯度既有下界又有上界

$$c_1 \le 
abla g(w) \le c_2$$

如果 $g$ 和 $w$ 都是标量，那这就是个导数条件：要求一条曲线的导数是正数，那这条曲线一定是递增的。曲线递增时，$g(w)=0$ 的解肯定存在并且唯一——它一定会穿过零线，有一个点、有一个解。另外一边，gradient 还要小于某个正数，也就是梯度有界。不应该出现的情况是：曲线随着 $w$ 的增大在某一点趋向于无穷，梯度也跟着趋向于无穷——如果出现这种情况，算法在收敛过程中有可能逐渐发散掉。

可能有同学会说：这个条件也太强了吧，递减的就不行了吗？没错，递减的就不行，这里必须要求递增。那这个条件为什么还说可以接受呢？回想之前提到的优化问题：要 minimize 一个 objective function $J(w)$，方法就是求解它的梯度等于 0，优化问题就转成了求解 $g(w)=0$ 的方程问题。现在再要求 $g(w)$ 的梯度大于 $c_1$，意味着什么？意味着要再求一次导，也就是对 $J$ 求二次导，得到的是一个 Hessian matrix。Hessian matrix 是正的矩阵，意味着这个函数是凸的（convex）。所以这个性质实际上对应一种凸性（convexity），相对来说是可以接受的。

#### 条件二：$\sum a_k=\infty$ 且 $\sum a_k^2<\infty$

这个条件又进一步分成两个：$a_k$ 的和应该等于无穷，$a_k$ 的平方和应该小于无穷。

先看平方和小于无穷是什么意思。如果 $a_k$ 最后不趋向于 0——比如它始终大于等于一个很小很小的数，0.000 几，不管多么小，只要它是个常数——无穷多个这样的 $a_k$ 相加，最后一定会趋于无穷。所以这个条件意味着 $a_k$ 最后一定会收敛到 0。

再看和等于无穷。它的意思是：$a_k$ 你确实要收敛到 0，但是不要收敛得太快。比如它经过两步就收敛到 0 了，之后全是 0，那你加起来肯定不是无穷。

这两个条件为什么长这样，下一节再掰开揉碎地讲——你在未来的 Temporal-Difference Learning 方法当中会经常看到它们，看论文、看书的时候也会经常碰到，值得详细解读一遍。

#### 条件三：噪声均值为 0、方差有界

第一个要求是 $\eta$ 的均值（mean）等于 0，第二个是它的方差（variance）有界。我们常见的一种情况是 $\eta$ 从某个概率分布当中 iid 地采样，这总是满足这个条件的。并且注意，$\eta$ 不要求是高斯噪声。

### 把条件二掰开揉碎

实际上这两个条件没有看起来那么难。我们逐个来看它到底在保护什么。

#### 平方和有限：让 $w_k$ 最后别再波动

把 RM 算法重新写一下——把 $w_k$ 从方程右边移到左边，左边就变成了 $w_{k+1}$ 和 $w_k$ 之间的差：

$$w_{k+1}-w_k=-a_k\tilde g(w_k)$$

如果 $a_k$ 最后趋向于 0，就意味着右边最后也趋于 0——当 $\tilde g$ 有界的时候，它肯定也趋向于 0。这个性质正是我们需要的：我们希望 $w_k$ 最后能够收敛，那么最后 $w_{k+1}$ 和 $w_k$ 之间最好不要再不断地波动了。

#### 和为无穷：让你可以放心地随便选 $w_1$

把 RM 算法的迭代式一个一个写出来：$k=1$ 时 $w_2=w_1-a_1\tilde g(w_1)$，$w_3=w_2-a_2\tilde g(w_2)$，这样一直写下去。把所有式子的左边全部加起来、右边全部加起来，中间再相互抵消，最后就能得到：

$$w_{\infty}-w_1=-\sum_{k=1}^{\infty}a_k\tilde g(w_k)$$

这个式子大家可以自己去推导一下，我留作一个作业。

这个式子说明了什么呢？如果 $w_k$ 最后能够收敛，左边那个 $w_\infty$ 就是 $w^*$；而 $w_1$ 是我们猜测的初始值。所以左边是真实解与初始猜测之差。假如 $a_k$ 的和是有界的、$\tilde g$ 也是有界的，那右边这一项自然也是有界的——这等于说 $w^*-w_1$ 必须是个有界的数。那我就不能随便选 $w_1$ 了：选一个离 $w^*$ 非常非常远的 $w_1$，这个式子就不成立了。

所以「和等于无穷」这个条件是干嘛的？它就是为了让我们放心地选 $w_1$——不管 $w_1$ 选得离 $w^*$ 有多远，最后它都能够收敛过来。

#### 什么样的 $a_k$ 合格：$1/k$ 是标准答案

那自然的一个问题是：什么样的 $a_k$ 能同时满足这两个条件？最为常见的就是 $a_k=1/k$——之前在 mean estimation 的例子当中其实已经提到了。它为什么合格？靠两条数学上的基本结论：

- $\sum_{k=1}^{n}\frac{1}{k}-\ln n$ 在 $n\to\infty$ 时趋于一个常数；而 $\ln n$ 最后趋向于无穷，所以 $\sum_{k=1}^{\infty}\frac{1}{k}=\infty$；
- $\sum_{k=1}^{\infty}\frac{1}{k^2}$ 是一个常数（收敛）。

这都是数列（number series）当中的一些基本结论，感兴趣可以查一下。总而言之，$1/k$ 同时满足两个条件。

#### 三条缺一不可：一个反例

在 RM 算法当中，三个条件如果有一个不满足，这个算法就有可能不再工作了。举个例子：$g(w)=w^3-5$。它不满足「$g(w)$ 的梯度有上界」这个条件——它的梯度是 $3w^2$，当 $w$ 趋于无穷时梯度也趋向于无穷，这在迭代时有可能导致发散。

另外还有一件实践中的事：虽然 $1/k$ 满足那两个条件，但我们实际当中不会让 $a_k$ 等于 $1/k$、或者让 $a_k$ 趋向于 0，而是会选择一个非常小的常数赋给 $a_k$。为什么？因为如果 $a_k=1/k$，当 $k$ 比较大的时候，后面进来的这些测量或数据起到的作用就非常非常小了；而实际问题往往比较复杂，我们希望未来进来的数据仍然能够有用，所以不让 $a_k$ 趋向于 0，而是让它趋向于一个非常小的数。

> **提示**：理论条件保证了「无限长的时间里能收敛」，实践取小常数是为了「新数据永远还有话语权」——两者不矛盾，取舍看问题本身。

### 用 RM 算法解均值估计问题

下面把 RM 算法应用到 mean estimation 这个问题当中去。还记得那个算法吗？就是这节课最开始介绍的 mean estimation 算法，当时 $\alpha_k$ 给的是 $1/k$。如果 $\alpha_k=1/k$，我们能显式地一步一步写出来：$w_{k+1}$ 确实就是前 $k$ 个 $x_i$ 的平均值。但如果 $\alpha_k$ 不是 $1/k$ 呢？实际上就没法写出这样一个显式的数了。那我们能不能证明 $w_{k+1}$ 最后仍然收敛到 $\mathbb{E}[X]$？当时我们留了一个问题、没办法分析，但现在可以了：证明这个算法是一个特殊的 RM 算法，它的收敛性自然就得到了。

来看它为什么是 RM 算法。考虑这样一个函数：

$$g(w)=w-\mathbb{E}[X]$$

$\mathbb{E}[X]$ 是随机变量的 expectation，是个常数，所以这就是一个「$w$ 减常数」的简单函数。如果我们能求解 $g(w)=0$，自然就得到 $w^*=\mathbb{E}[X]$，也就把 $X$ 的 expectation 求出来了。麻烦在于这个 expectation 我们是不知道的，但我们知道什么？我们可以对 $X$ 进行采样。所以测量取：

$$\tilde g = w - x$$

其中 $x$ 是对 $X$ 的一个采样。把它凑一下：$w-x$，后边加上一个 $\mathbb{E}[X]$ 再减去一个 $\mathbb{E}[X]$，把 $w-\mathbb{E}[X]$ 合并成 $g(w)$，把 $\mathbb{E}[X]-x$ 合并成 $\eta$：

$$\tilde g = \underbrace{(w-\mathbb{E}[X])}_{g(w)}+\underbrace{(\mathbb{E}[X]-x)}_{\eta}$$

$\mathbb{E}[X]$ 是我们要的量，$\eta$ 是测量带来的误差——而且它均值恰为 0（采样是无偏的）、方差就是 $X$ 的方差（有界），条件三天然满足。把 $\tilde g$ 的具体值代进 RM 算法：

$$w_{k+1}=w_k-\alpha_k(w_k-x_k)$$

这正是刚才给出的 mean estimation 算法。所以 mean estimation 算法实际上是一个 RM 算法，根据 RM 的性质：当 $\alpha_k$ 满足平方和小于无穷、和等于无穷时，它就是收敛的。

最后补充一个更复杂的定理，我标出来了，属于**选学内容**，很快过一遍：它是关于更一般的 stochastic sequence 收敛性的证明。我们之前介绍了 RM 定理但没有证明它，这个更古老的定理就可以用来证明 RM 定理；它也可以直接分析 mean estimation 问题；把它推广之后，还可以直接证明后面要讲的 Q-learning 和 TD learning 算法的收敛性。这完全是给力有所及的、或者特别感兴趣的同学准备的——我提醒你有这样一个东西在，你可以去关注一下；不感兴趣的直接跳过去。

### SGD 要解决什么问题

到这里前两部分介绍完了，简单回顾一下：第一部分给出了 mean estimation 算法——怎么样用迭代的方式求一个 expectation；第二部分给出了 RM 算法，经过学习相信大家也发现了，它的想法非常简单，也非常有用，因为 mean estimation 算法实际上是 RM 算法的一个特殊情况。接下来第三部分讲 stochastic gradient descent，简称 SGD，随机梯度下降。这个算法在强化学习还有很多机器学习领域应用非常非常广泛，所以非常重要。三者的关系是：SGD 是 RM 算法的一个特殊情况，而 mean estimation 算法又是 SGD 的一个特殊情况——

```text
RM 算法（求解方程 g(w) = 0）
  └── SGD 是它的特殊情况（g 取成目标函数的梯度）
        └── 均值估计算法又是 SGD 的特殊情况（目标函数取成到样本的距离）
```

也就是说，三层算法是逐层包含的：最底下是求期望，中间是求最优解，最上面是求方程的根。

SGD 要解决的是这样一个优化问题：

$$\min_w \; J(w)=\mathbb{E}[f(w,X)]$$

目标函数 $J$ 是 $w$ 的函数，$w$ 可以是一个参数或者一个变量，总之要优化 $w$ 让目标函数达到最小。这个目标函数的特点是：它含有 expectation 和随机变量——具体来说是函数 $f$ 的期望，$f$ 又是 $w$ 和 $X$ 的函数；$X$ 是一个随机变量，它的 probability distribution 已经给定了（当然我们是不知道的），expectation 就是对这个 $X$ 求的。我们的目标就是找到最优的 $w$，使目标函数达到最小。

求解这样一个问题有多种方法，下面给出三种——这三种方法是逐渐递进的，大家可以关注一下。

#### 第一步：梯度下降（GD）

先说明一点：我们的目标是最小化一个目标函数，所以用梯度下降；如果你的目标是最大化一个目标函数，你就要用梯度上升。这里考虑梯度下降的情况。

假设最优解是 $w^*$，第 $k$ 次我们对它有一个估计 $w_k$（可能是不准确的），然后在 $w_{k+1}$ 这一步去改进它：

$$w_{k+1}=w_k-\alpha_k
abla J(w_k)$$

就是沿着梯度的反方向去下降，自然可以更好地 minimize 目标函数。这里面的 $\alpha_k$ 被称为**步长**，控制沿梯度方向下降得快还是慢。这个算法非常基础、非常简单。

因为 $J$ 里含有 expectation，有一点值得说：外面这个梯度符号可以移到里边去——对 expectation 求梯度，就变成对 $f$ 求梯度再求 expectation：

$$
abla J(w)=
abla\,\mathbb{E}[f(w,X)]=\mathbb{E}[
abla_w f(w,X)]$$

这一点比较明显，因为 expectation 本质上就是一个求和，把求导符号从求和前面拿到里边（或者反过来）是没有区别的。

虽然很简单，问题也很明显：我要对梯度求一个 expectation，我不知道怎么办。两种出路：有模型，可以求出来；没有模型，用数据来求。

#### 第二步：用数据代替期望（BGD）

第二种方法就是 batch gradient descent，简称 BGD，批量梯度下降。思路非常简单：刚才不是要求 expectation 吗？没有模型就用数据——对里面的随机变量进行采样，采很多次、采 $n$ 次，最后求平均，用这个平均值来当作 expectation。这不就是我们之前学的蒙特卡洛方法的基本思想吗？把数据得到的平均值放进去，就是 BGD 算法。

思想很简单，但还是有问题：每更新一次 $w_k$，都要采样 $n$ 次或者很多次，这在实际当中可能还是不行。

#### 第三步：只用一个样本（SGD）

于是就来到了第三种方法：stochastic gradient descent，SGD，随机梯度下降。算法非常简洁：

$$w_{k+1}=w_k-\alpha_k
abla f(w_k,x_k)$$

注意，本来梯度里是 $X$，现在变成了 $X$ 的一个采样 $x_k$。

把 SGD 和前两种方法比较一下，可以理解得更清楚。相比 gradient descent：GD 用的是 true gradient，也就是那个 expectation；因为不知道，我们用一个量来代替它——这个量之所以叫 stochastic gradient，就是因为里面有一个随机量的采样 $x_k$。相比 batch gradient descent：实际上就是把 BGD 里的 $n$ 设成 1 就得到了 SGD。BGD 里采得越多，对 expectation 估计得越准，但需要的数据也越多；现在我干脆就用一个数据来代替。它的问题就是这个肯定不精确——那它究竟不精确到什么程度、会不会带来很大的问题、最后还能不能解决这个最优化问题？之后我们详细分析。

### 一个例子：从优化问题写出 SGD

下面用例子展示怎么用 SGD。考虑这样一个优化问题，目标函数是 $f(w,X)$ 的 expectation，其中 $f$ 取：

$$f(w,X)=\frac{1}{2}\lVert w-X\rVert^2$$

$\lVert\cdot\rVert$ 代表 norm——如果两个都是 vector，这就是它们距离的平方。直观上来说，我们希望 minimize $w$ 和 $X$ 之间的距离。对 $f$ 求梯度得到的是 $w-X$，这里不再详细推导，你可以停下来自己推一下，看梯度是不是确实是 $w-X$。

下面有三个练习，如果是在课堂上的话，我会停下来让大家练一下，这里直接讲答案。

第一个练习：证明这个问题的最优解 $w^*$ 就是 $X$ 的 expectation。推导如下：$J$ 要达到最小值，有一个必要条件——对 $J(w)$ 求梯度等于 0。把梯度符号移到期望里面，就是 $\mathbb{E}[
abla_w f(w,X)]=0$，而 $
abla_w f=w-X$，所以 $\mathbb{E}[w-X]=0$。$w$ 本身不是随机变量，它的 expectation 就是它自己，于是得到：

$$w^*=\mathbb{E}[X]$$

第二个练习：写出这个问题的 gradient descent 算法。就是 $w_{k+1}=w_k-\alpha_k
abla_w J(w_k)$，把 $f$ 的梯度算出来是 $w_k-X$，所以梯度是 $\mathbb{E}[w_k-X]$——一个含 expectation 的量。

第三个练习：写出 SGD 算法。其实很简单，把 expectation 去掉，直接用 $w_k-x_k$ 来代替：

$$w_{k+1}=w_k-\alpha_k(w_k-x_k)$$

这个过程大家也看到了：先知道 gradient descent、知道里面有个 expectation，然后把 expectation 去掉就直接得到 SGD。

这个算法看起来眼熟吗？$w_{k+1}=w_k-\alpha_k(w_k-x_k)$——实际上就是最开始介绍的 mean estimation 问题：有一个 $X$ 要求 $\mathbb{E}[X]$，把采样得到的 $x_i$ 一个一个放进这个算法，最后就能得到平均值、进而近似 expectation。在那时 $\alpha_k=1/k$，我们知道 $w_k$ 确实非常精确地等于前 $k$ 个 $x_i$ 的平均值；后来提到 $\alpha_k$ 不是 $1/k$ 时怎么办——现在我们知道了，这时候也能解决，因为这个算法是一个特殊的 SGD 算法。之前的问题是描述「求 $\mathbb{E}[X]$」，现在把它描述成一个优化问题——殊途同归。

### SGD 为什么收敛：它是一个特殊的 RM 算法

SGD 的基本思路是：从 GD 出发，里面的 expectation 不知道，干脆去掉，用一个采样来近似。这个采样有个名字，叫 stochastic gradient（前面那个 expectation 叫 true gradient），两者之间满足：

$$
abla f(w_k,x_k)=
abla J(w_k)+\text{error}$$

不管怎么样，stochastic gradient 不是准确的。那用它还能找到最优解 $w^*$ 吗？答案是肯定的。怎么证？

基本思想是：证明 SGD 实际上是一个特殊的 RM 算法。RM 算法我们已经了解了，想法比较简单；通过证明 SGD 是 RM 算法，而 RM 算法在一定条件下能收敛，我们就知道 SGD 在什么条件下能收敛。这个思路非常简洁。另一条路是不依赖 RM、直接证明 SGD 的收敛性，那个证明会非常非常复杂，我们不走那条路。

来看怎么证。SGD 要解决的是 minimize 目标函数 $J(w)$；这个优化问题可以转成一个 root-finding 问题——因为目标函数达到最优的一个必要条件是梯度等于 0。令 $g(w)=
abla J(w)$，求解最优问题就变成了求解方程 $g(w)=0$。这个方程怎么解？学了前面的部分就知道，完全可以用 RM 算法。用 RM 需要测量：$g(w)$ 的表达式不知道，但有测量 $\tilde g$——它就是 stochastic gradient，等于 $g(w)$ 加上噪音。对应的 RM 算法是：

$$w_{k+1}=w_k-a_k\tilde g(w_k)$$

把 $\tilde g$ 代进去，它就是 stochastic gradient——所以这个 RM 算法就是一个 SGD。反过来说，SGD 算法实际上是求解这样一个特殊问题的 RM 算法，它的收敛性就可以用 RM 算法的结论来分析。

因为 SGD 是特殊的 RM 算法，把前面 RM 的收敛条件套过来，就得到这样的结论：如果 SGD 满足下面三个条件，$w_k$ 最终就收敛到 $w^*$（with probability 1）：

- **条件一，关于 $f$ 的性质**：实际上是说 $f$ 是严格凸的，是一个 convexity 条件。注意 $f$ 是一个标量，这里假设 $w$ 也是标量，所以上下界也是标量；如果 $w$ 是向量，那上下界应该是矩阵才对。
- **条件二，关于系数 $a_k$**：基本上还是那两个式子——和等于无穷、平方和小于无穷。
- **条件三，关于采样**：要求采样是 iid。

在这种情况下，SGD 确实能收敛到 $w^*$。具体的证明可以参见书里。

### 离目标越远，越像梯度下降

分析了 SGD 为什么有效之后，来看它在收敛过程中一些非常有意思的行为。先问一个问题：SGD 是把 GD 当中的 true gradient 用 stochastic gradient 来代替，stochastic gradient 里是有随机性的，那会不会造成 SGD 的收敛过程也随机性很大？比如目标在 $w^*$ 这个地方，我从 $w_0$ 出发——虽然最后能收敛到 $w^*$，但有没有可能最开始朝完全相反的方向、或者很随机的方向走了非常远的路径，最后才到达 $w^*$？这是一个很重要的问题：如果 SGD 确实有这个性质，说明这个算法不特别好。索性它没有——我们来分析一下。

分析的工具是 relative error（相对误差），用 $\delta_k$ 表示（为了简单，假设所有量都是标量）：

$$\delta_k=\frac{\bigl|
abla f(w_k,x_k)-\mathbb{E}[
abla f(w_k,X)]\bigr|}{\bigl|\mathbb{E}[
abla f(w_k,X)]\bigr|}$$

分子上有两项：第一项是 stochastic gradient，第二项是 true gradient，所以分子就是这两个梯度的差的绝对值；分母是 true gradient 的绝对值。它定义了随机梯度与真实梯度之间的相对误差。

基于它，我们能得到一个蛮有意思的结论：**当 $w_k$ 离 $w^*$ 非常远的时候，SGD 呈现出来的行为和 GD 非常类似，因为 relative error 比较小；当 $w_k$ 离 $w^*$ 比较近的时候，SGD 才会呈现出比较大的随机性。**这是一种比较良好的性质。下面看怎么得到它。

首先注意到 $w^*$ 是最优解，所以 $\mathbb{E}[
abla f(w^*,X)]=0$。既然它是 0，把它加到分母当中不影响任何事情。于是分母变成 $\bigl|\mathbb{E}[
abla f(w_k,X)]-\mathbb{E}[
abla f(w^*,X)]\bigr|=\bigl|\mathbb{E}[
abla f(w_k,X)-
abla f(w^*,X)]\bigr|$。这一步看起来有点突兀，实际上用到了**中值定理**：对函数 $f(x_1)-f(x_2)$，一定可以写成某点导数 $f'(x_3)$ 乘以 $x_1-x_2$。我们这里做的就是这件事——为什么要引入中值定理？就是想让 $w_k-w^*$ 这一项出现。这样一处理，式子里出现了对 $f$ 求二阶导。

下面做一个假设：$f$ 的二阶导是一个正数（大于 0）。代到分母里做一些简单处理：因为 $w_k-w^*$ 没有 random variable，可以从 expectation 里提取出来，变成两项；乘积的绝对值可以写成绝对值的乘积；第一项由假设知道它大于等于 $c$。所以分母满足：

$$\bigl|\mathbb{E}[
abla f(w_k,X)-
abla f(w^*,X)]\bigr|\;\ge\; c\,|w_k-w^*|$$

把这个下界代回 relative error 的分母（分子不变），就得到：

$$\delta_k\;\le\;\frac{\bigl|
abla f(w_k,x_k)-\mathbb{E}[
abla f(w_k,X)]\bigr|}{c\,|w_k-w^*|}$$

大家可能觉得这个式子有点复杂，没关系，它实际上非常简洁：分子是随机梯度与真实梯度的绝对误差，分母里的 $c\,|w_k-w^*|$ 正是 $w_k$ 距离 $w^*$ 的距离。从这个式子就能明显看出来：假设 $w^*$ 在那里，当 $w_k$ 距离 $w^*$ 比较远的时候，分母比较大，如果分子有限，relative error 一定比较小——也就是 stochastic gradient 和 true gradient 比较接近，这时的 SGD 实际上和 GD 非常类似，会大致朝目标的方向去接近。相反，如果 $w_k-w^*$ 比较小，整个上界就会比较大——$w_k$ 已经跑到 $w^*$ 的附近了，这时候可能确实存在一些随机性。

### 用一个二维仿真亲眼看看

理论说完了，看一个例子。在二维平面上定义一个点的位置，用 $X$ 表示；在一个边长为 20、中心在坐标原点的正方形区域里随机采样 100 组点——它们真实的 expectation $\mathbb{E}[X]$ 就等于 $(0,0)$。用这 100 组点跑刚才的 mean estimation 算法 $w_{k+1}=w_k-\alpha_k(w_k-x_k)$，看看收敛过程呈现出什么样的行为。

结果图里：小的黑色圆圈点全都是采样的点，真实的 mean 在原点那里。红色曲线就是 SGD 算法：从最开始假设的 mean 位置出发，先收敛到大致的目标方向，然后逐渐接近真实的 expectation。除了 SGD，图里还有其它几条曲线，现在暂时不用关注——它们属于 mini-batch gradient descent，之后会介绍。

通过这个图可以明显看到两点：第一点，最开始估计离目标非常非常远（$w_k$ 离 $w^*$ 很远），但 SGD 呈现出来的不是朝这边、朝那边非常随机的收敛方式，而是仍然朝着大概的目标方向快速收敛；第二点，当它接近目标的时候，就会呈现出一些随机性。这和我们刚才的理论分析是一致的：离得远时像 GD，离得近时才露出随机性。

### 另一副面孔：不含随机变量的问题描述

到目前为止，SGD 的所有内容基本介绍完了。下面介绍 SGD 另外一个常见的 problem formulation。这部分很有意思、也非常 tricky——为什么 tricky？如果你没有意识到这个问题，你可能反而会被搞晕；但如果你平时遇到了这个问题、不明白为什么会是这样，看了这部分你会恍然大悟。

之前的 problem formulation 里有 random variable：目标函数含 expectation，expectation 里有一个随机变量 $X$。但你在学 SGD 时如果看其它的材料，或多或少、或者一定会遇到另一个 formulation，其中**不包含任何随机变量**：

$$J(w)=\frac{1}{n}\sum_{i=1}^{n}f(w,x_i)$$

这里函数 $f$ 以 $w$ 和 $x$ 为参数，$x$ 可能取 $n$ 个不同的值，对这 $n$ 个函数值求一个平均。注意：这个 $x$ 组成的集合就是一组数，它**不是任何随机变量生成的采样**，反正就是一组实数。

对这个问题，gradient descent 方法肯定可以写出来：

$$w_{k+1}=w_k-\alpha_k\cdot\frac{1}{n}\sum_{i=1}^{n}
abla_w f(w_k,x_i)$$

实际当中这个集合可能比较大，每次只能从里面拿到一个 $x_i$，那怎么执行算法？把前面那个求平均直接用 $x_k$ 来代替就行。这个算法看起来和 SGD 非常类似——但是，它究竟是不是 SGD 呢？这个问题的描述里就是一组 $x_i$，没有涉及任何随机的量，也没有 expectation。这是第一个问题。

第二个问题：我每次要从这组数里拿一个出来当 $x_k$，那该怎么拿？是把 $x_i$ 从小到大排列？还是随便以什么顺序排好了一个一个拿？还是应该随机地从里面拿？随机拿的话按什么概率分布拿？能不能重复用一些数，还是必须不能重复？会有一系列问题。下面来回答。

思路是：**手动地引入一个 random variable**，让这个不涉及随机变量的问题变成涉及随机变量的问题。做法是：定义一个随机变量 $X$ 定义在这个集合上——原来它可能就是随便的一组数，不一定是任何随机变量产生的，但我硬是定义这样一个随机变量——它取其中任何一个数的概率是 $1/n$，也就是在上面均匀分布。这时候再看目标函数：根据 expectation 的定义，

$$\frac{1}{n}\sum_{i=1}^{n}f(w,x_i)=\mathbb{E}[f(w,X)]$$

那么求解这个问题的刚才那个算法，自然也就是 SGD 的算法了。所以这里的思路就是：它本来没有随机变量，我通过强行引入一个随机变量，把它转化成一个可以用 SGD 求解的问题描述。

当然最关键的就是 $x_k$ 究竟应该怎么取。现在就清楚了：你应该从这个集合当中**随机地抽取**，而不应该排序；而且因为是随机抽取，这些数有可能被反复用到。之前那一串疑问，一下子全都变得非常清晰了。

### BGD、MBGD、SGD 三者对比

这部分我们还在继续介绍 SGD，但会把它和另外两个大家经常碰到的算法——batch gradient descent 和 mini-batch gradient descent——进行比较。

研究的问题仍然是：有一个目标函数 $J(w)$，有一组采样、假设有 $n$ 个 $x_i$，要用这批数据去优化目标函数。三种方法分别是：BGD（B 指 batch）、MBGD（mini-batch gradient descent）、还有之前给出的 SGD。区别在于每次用多少数据：

- **BGD**：每次用到全部 $n$ 个采样，在这个基础上求平均。这可以说是最接近真实的 expectation。
- **MBGD**：不用全部采样。比如采样一共 100 万个，mini-batch 每次只用 100 个或者 1000 个，随机地从 100 万个当中选取一组数，这个集合称为 $I_k$；假设这一组有 $m$ 个数，就在这组数据上求平均。
- **SGD**：随机采样出一个来，得到 stochastic gradient。

| 算法 | 每次使用的数据 | 直观特点 |
| :--- | :--- | :--- |
| BGD | 全部 $n$ 个采样求平均 | 最接近真实期望，数据开销最大 |
| MBGD | 随机抽取的 $m$ 个（集合 $I_k$）求平均 | 随机性居中，灵活高效 |
| SGD | 随机抽取的 1 个 | 最简洁，随机性最大 |

三个算法的思想都比较简单明了，而且 MBGD 可以认为囊括了 BGD 和 SGD：当 mini-batch 非常小、每次只有一个（$m=1$）的时候，MBGD 就变成 SGD；当每次的 batch 比较大的时候，它就接近于 BGD。

直观上来说，MBGD 会比 SGD 的随机性更小一些，因为它用更多的数据去平均，会把噪音等测量平均掉；相比 BGD，MBGD 用的数据又比较少，所以随机性相对来说大一些，但因为它不需要把所有数据都用上，所以更加灵活高效。

这里有一个比较有意思的、大家很容易出错的点：当 MBGD 的 $m=n$ 时，**MBGD 不完全等于 BGD**。为什么？虽然这时候两者都用到了 $n$ 个采样，但 BGD 用的是全部 $n$ 个采样，而 MBGD 是在 $n$ 个采样当中随机抽取的——可能一个采样被抽了好几次、而有的采样没被抽到，这是有可能的。所以它们之间有非常微小的差别。这种差别在很多情况下大家都忽略不计，但我还是希望大家能够从数学上明白它们之间的这种微小差别。

> **易错点**：$m=n$ 只让 MBGD「用满」了样本量，没有改变它「随机有放回抽取」的本质——它和 BGD 差在抽样方式上，不差在数量上。

### 用均值估计的例子把三个算法算一遍

下面用一个例子例证这三个算法。例子就是最开始考虑的 mean estimation 问题：有 $n$ 个 sample，要对它们求一个平均值 $\bar{x}$。求平均值实际上可以等价成一个优化问题——目标是：

$$J(w)=\frac{1}{2n}\sum_{i=1}^{n}\lVert w-x_i\rVert^2$$

求它的极小值。注意这里有一个 2，这个 2 并不是说有 $2n$ 个数据，而是待会求梯度的时候这个 2 和求导出来的 2 会抵消掉。具体来说，$J(w)$ 对 $w$ 求梯度：

$$
abla J(w)=\frac{1}{n}\sum_{i=1}^{n}(w-x_i)$$

这个大家可以自己验证一下。有了这个梯度，三个算法很快就能写出来——它们的唯一区别都在梯度那一块的后半段：

- **BGD**：$
abla J$ 里 $w_k$ 加了 $n$ 次再求平均还是 $w_k$，$x_i$ 加了 $n$ 次求平均就是 $\bar{x}$，所以 $w_{k+1}=w_k-\alpha_k(w_k-\bar{x})$；
- **MBGD**：后半段是从中抽取的 $m$ 个 sample 求平均所得到的；
- **SGD**：只抽取一个 sample，所以就是 $x_k$。

更进一步，如果取 $\alpha_k=1/k$，实际上可以把 $w_k$ 的显式形式求解出来。BGD 的情况下 $w_{k+1}$ 直接等于 $\bar{x}$——一步到位，因为它把所有的数据全都用到了。MBGD 相对来说会稍微慢一点，但比 SGD 快，因为它每次先求一个平均；SGD 相对来说更慢一些，因为它每次只有一个数，要慢慢地对这些数求平均。

再看仿真结果。还是那个设定：一个 $20\times 20$ 的区域，在里面均匀地采 100 个点，把这 100 个点的数据放到三个算法里，看它们的收敛情况。SGD 对应那条红线：可以看到它收敛得还是不慢的，直接会到达目标区域，然后慢慢收敛到目标——那个目标就是真实的平均值。紫线和蓝线分别对应 mini-batch gradient descent，区别是 batch size 不一样：紫线的 batch size 每次小一点，只有 5 个；蓝线有 50 个。可以看到紫线相比 SGD，是直接收敛到目标的附近然后再逐渐趋于目标；而蓝线一步到位，收敛到离目标已经非常非常近了。右图可以更清晰地看到：横轴是迭代次数，纵轴是到达目标的距离——batch 为 50 时基本上很快就非常接近目标了；SGD 相对慢一点，但收敛速度还是比较快的。

### 把三个算法串起来回顾

这次课的内容到这就介绍完了，做一个小结。

第一，**mean estimation**：问题是用一组数求它的 expectation。之前我们就简单地把这组数求平均来近似估计；这次我们知道了，其实可以用迭代的方式——得到一个采样就算一次，得到一个采样算一次，这样不用等所有采样全部拿到再计算，会更加高效。

第二，**RM 算法**（SA 领域非常经典的算法）：它解决的问题是——我有一个方程 $g(w)=0$，要求解它的根 $w^*$，但不知道 $g(w)$ 的表达式；我知道的是：给一个 $w$，能测出它的输出，而且这个输出是有噪音、有误差的，用 $\tilde g$ 表示。RM 算法就是：怎么样用这样的含噪音测量来估计 $w^*$。

第三，**SGD**：求解的是——有一个含 expectation 的目标函数，我可以知道它的梯度的一个采样，然后用这个 stochastic gradient 执行迭代，让 $w_k$ 趋于最优值 $w^*$。

这些算法和思路非常有用，体现在两个地方。第一，下一节我们将学习 Temporal-Difference Learning，到时候你看到那个算法就不会再吃惊了——因为那个算法和目前这些迭代算法其实有异曲同工之妙，这节课为下节课奠定了非常好的基础。第二，即便不谈 TD learning，这些算法本身也都是非常经典、非常有意思的优化算法，大家多多地了解，只有好处没有坏处。

这一讲现场点过的练习和作业如下，解析依据都能在正文里找到。

**课堂练习（针对目标函数 $J(w)=\mathbb{E}[f(w,X)]$，$f(w,X)=\frac{1}{2}\lVert w-X\rVert^2$）**，共三问：

1. 证明最优解 $w^*=\mathbb{E}[X]$。答：极小点的必要条件是 $
abla J(w)=0$；梯度移入期望得 $\mathbb{E}[w-X]=0$，而 $w$ 非随机、期望是其自身，故 $w=\mathbb{E}[X]$。
2. 写出该问题的 gradient descent 算法。答：$w_{k+1}=w_k-\alpha_k\,\mathbb{E}[w_k-X]$（梯度里含 expectation）。
3. 写出该问题的 stochastic gradient descent 算法。答：把期望去掉、用单个采样代替，$w_{k+1}=w_k-\alpha_k(w_k-x_k)$。

**推导作业**：把 RM 算法的迭代式逐个写出（$w_2=w_1-a_1\tilde g(w_1)$，$w_3=w_2-a_2\tilde g(w_2)$，……），左边全部相加、右边全部相加并相互抵消，导出 $w_{\infty}-w_1=-\sum_{k=1}^{\infty}a_k\tilde g(w_k)$，并据此说明「$\sum a_k=\infty$ 保证了 $w_1$ 可以任意选」。

### 三个热身例子：为什么 TD 长那个样子

在正式给算法之前，我们考虑几个例子，然后用上节课学到的 RM 算法来求解它们。讲这几个例子的目的，是建立起上节课和这节课的关系——待会学 TD 算法的时候你就不会觉得唐突，你会明白为什么 TD 算法会长那个样子。这部分不是必须的，如果你已经迫不及待想直接学 TD 算法，可以跳过去；但学了它会给后面打下比较好的基础。

#### 例一：最普通的均值估计

问题非常简单：要求解随机变量 $X$ 的期望（expectation），用 $w$ 表示这个期望值，手里有的是 $X$ 的一些采样，要用采样把期望求出来。这个问题有很多方法可以解，但我们专门用 RM 算法来解——过程上节课详细讲过，这里很快过一遍，不熟悉的一定要回上节课看。

思路是把求期望改写成求解方程。先定义函数：

$$g(w) = w - E[X]$$

求解 $g(w)=0$，解自然是 $w^* = E[X]$。现在能测量到的是 $X$ 的采样 $x$，那么 $w - x$ 实际上就是 $g(w)$ 的一次测量。做一点恒等变形，减去一个 $E[X]$ 再加上一个 $E[X]$，就可以写成 $g(w)$ 加上测量误差的形式：

$$w - x = g(w) + \big(E[X] - x\big)$$

根据 RM 算法 $w_{k+1} = w_k - \alpha_k \tilde{g}$，把 $\tilde{g}$ 代进去就是：

$$w_{k+1} = w_k - \alpha_k (w_k - x_k)$$

这就是上节课见过的均值估计算法。

#### 例二：期望里套一个函数

第二个例子稍微复杂一点，复杂在哪儿？刚才求的是 $w = E[X]$，现在多了一个函数 $v(X)$，要求的是：

$$w = E[v(X)]$$

思路和刚才一模一样。先写 $g(w) = w - E[v(X)]$，令它等于 0，解就是 $w^* = E[v(X)]$。现在实际能测量到的是 $v(x)$，也就是 $v(X)$ 的一个采样，把它记作 $\tilde{g}$，对应的 RM 算法就是：

$$w_{k+1} = w_k - \alpha_k \big(w_k - v(x_k)\big)$$

#### 例三：两个随机变量，长出 TD 的雏形

第三个例子也是最后一个，更复杂一点。复杂在：刚才只有一个随机变量，现在有 $R$ 和 $X$ **两个**随机变量，而且表达式复杂了一些——带了一个 $\gamma$，里面还嵌着一个函数 $v$：

$$w = E\big[R + \gamma v(X)\big]$$

思路还是和刚才一模一样，只不过这时既需要 $X$ 的采样，也需要 $R$ 的采样。把 $g(w)$ 写成 $g(w) = w - E[R + \gamma v(X)]$，要求的还是 $g(w) = 0$。能测到的 $\tilde{g}$ 就是：

$$\tilde{g} = w - \big[r + \gamma v(x)\big]$$

其中 $r$ 是 $R$ 的采样、$x$ 是 $X$ 的采样。代进 RM 算法：

$$w_{k+1} = w_k - \alpha_k \Big(w_k - \big[r + \gamma v(x)\big]\Big)$$

**这个表达式，待会大家看到 TD 算法的时候，会发现和它已经非常非常像了。** 所以到那时你就不会太惊讶：为什么那个表达式会长成那个样子？

有的同学可能已经有感觉了：为什么这里要用 $R$？为什么要用 $v$？为什么要用 $\gamma$？实际上我是有目的的——$R$ 对应的就是 reward，$\gamma$ 是 discount rate，$v$ 就是 state value，$X$ 对应的其实是状态。当然在例子里完全没有这些背景，你就把它当成一个简单的数学问题去理解就可以。

这三个例子越来越复杂，但都能用 RM 算法求解。待会所看到的 TD 算法，特别是和最后一个例子对应的算法，非常非常像。

### 期待已久的 TD 算法

现在正式介绍这节课的第一个 TD 算法。先明确它在干嘛：**求解 state value**——谁的 state value？一个**给定策略** $\pi$ 的 state value。为什么要求解它？因为求解出 state value 之后，就完成了 policy evaluation；再和 policy improvement 相结合，就可以去找最优的策略。我们先看第一步：怎么用 TD 算法做 policy evaluation。

有一个概念要先区分清楚：TD learning 既可以指**一大类**算法——今天这节课讲的所有算法全是 TD 算法，包括 Q-learning；但接下来讲的这个 TD 算法，是**最经典、最原始**的那一种，它就是来估计 state value 的，有一个非常明确的表达式。这时候它指的是一个特定的算法。这一点希望大家能区分开。

#### 数据长什么样

TD 算法是基于数据（不基于模型）来实现强化学习的。它要的数据是什么？就是所谓的 experience——写成的一长串形式：

```text
s0 --r1--> s1 --r2--> s2 ... st --r(t+1)--> s(t+1) ...
```

也可以写成集合的形式，集合里的每个元素是一个三元组 $(s_t,\ r_{t+1},\ s_{t+1})$。这些数据全部由给定的策略 $\pi$ 产生。TD 算法就是要用这些数据，来估计 $\pi$ 所对应的 state value。

#### 算法本身

期待已久的 TD 算法就是这个样子：

$$v_{t+1}(s_t) = v_t(s_t) - \alpha_t\Big[v_t(s_t) - \big(r_{t+1} + \gamma\, v_t(s_{t+1})\big)\Big]$$

先解释符号。$v(s)$ 里的 $s$ 是 state space 当中的**任何一个**状态——也就是说每个状态都要有一个 $v$，$v$ 用来近似 $v_\pi(s)$（$s$ 的 state value）。$v$ 在 $t$ 时刻带下标 $t$，代表 $t$ 时刻的估计值；$t+1$ 时刻就是 $t+1$ 时刻的估计值，它是在不断变化的。式子里的 $s_t$ 是什么？是在这个 episode（这段经验）里，$t$ 时刻**访问到**的那个状态——一个 agent 在环境当中一个时刻只能访问一个状态。

这个算法包括两部分：

- **第一部分**：$t$ 时刻我处在状态 $s_t$，有了一些数据，这时要更新 $s_t$ 所对应的 value——从 $v_t(s_t)$ 更新得到 $v_{t+1}(s_t)$，更新方式就是上面第一个式子：旧值减去后面那一长串。
- **第二部分**：$t$ 时刻我只访问了 $s_t$，所有其它状态都没被访问，它们的 $v$ 保持不动：

$$v_{t+1}(s) = v_t(s), \qquad s \neq s_t$$

第二个式子非常简单，平时看 TD 算法时你其实看不到它——它被隐含掉了。但我想写出来告诉大家：虽然隐含掉了，从数学上来讲还是有这样一个式子在。

#### 新估计 = 旧估计 + 修正项

把第一个式子拆开看：左边 $v_{t+1}(s_t)$ 是对 $s_t$ 的 value 的**新估计**；右边分两项——第一项 $v_t(s_t)$ 是 current estimate（也叫 old estimate，旧的估计），第二项是一个**修正项**，其中 $\alpha_t$ 是针对状态 $s_t$ 的系数，中括号里有几个有名字的量，下面分别介绍。

### TD target 与 TD error

理解这两部分，对深刻理解 TD 算法具有非常重要的作用，希望大家仔细听。

#### 为什么叫 TD target

中括号里的 $r_{t+1} + \gamma v_t(s_{t+1})$ 有个名字，叫 **TD target**。记作 $\bar{v}_t$。为什么叫 target（目标）？原因很简单：这个算法在做的事情，就是把 $v(s_t)$ 朝着 $\bar{v}_t$ 的方向去改进——到下一个时刻，$v(s_t)$ 会离 $\bar{v}_t$ 更近。所以 $\bar{v}_t$ 是它的目标值。

这不是口说的，可以验证。对原算法做等价变形：左边减一个 $\bar{v}_t$，右边也减一个 $\bar{v}_t$，整理得到：

$$v_{t+1}(s_t) - \bar{v}_t = (1 - \alpha_t)\big(v_t(s_t) - \bar{v}_t\big)$$

这个方程描述了 $v_t$ 与 $\bar{v}_t$ 之差随时间的变化：左边是 $t+1$ 时刻的差，右边是 $t$ 时刻的差乘上一个系数。对两边取绝对值，注意 $\alpha_t$ 是一个比较小的正数，所以 $1-\alpha_t$ 大于 0 同时小于 1，于是：

$$\big|v_{t+1}(s_t) - \bar{v}_t\big| \le \big|v_t(s_t) - \bar{v}_t\big|$$

说明下一个时刻 $v(s_t)$ 离 $\bar{v}_t$ 的距离**更近了**。所以这个算法就是把 $v(s_t)$ 朝着 $\bar{v}_t$ 的方向改进。理解了这一条，你就非常清晰地理解了 TD 算法在干什么。

#### TD error：时序差分的"时序"在哪

当前 value 和 target 之间的误差 $v_t(s_t) - \bar{v}_t$ 被称为 **TD error**，记作：

$$\delta_t = v_t(s_t) - \big[r_{t+1} + \gamma v_t(s_{t+1})\big]$$

首先它是一个 error，是两个量之差；同时这两个量分别处在**两个时刻**——$v_t(s_t)$ 在 $t$ 时刻，$r_{t+1} + \gamma v_t(s_{t+1})$ 里的量在 $t+1$ 时刻。为什么叫 Temporal Difference（时序差分）？为什么是"时序"？就是因为差在两个时刻之间。这是最直观的理解。

TD error 更深一层的意义：它不仅仅描述当前估计与 target 之间的误差，更能描述 $v_t$ 与 $v_\pi$ 之间的误差——$v_\pi$ 是我们要估计的真值，$v_t$ 是当前估计值。一句话概括：**当 $v_t = v_\pi$ 时，$\delta_t$ 应该等于 0；反过来，如果 $\delta_t$ 不等于 0，就说明 $v_t$ 还没到 $v_\pi$。**

为什么这么说？在 $\delta_t$ 的基础上定义 $\delta_{\pi,t}$——就是把式子里的 $v$ 全部替换成 $v_\pi$。为什么要这么干？因为我希望最后 $v$ 能收敛到 $v_\pi$，那我先把 $v$ 换成 $v_\pi$，看看会发生什么。对 $\delta_{\pi,t}$ 求期望：

$$E[\delta_{\pi,t}] = v_\pi(s_t) - E\big[R_{t+1} + \gamma v_\pi(S_{t+1})\big]$$

这个等于 0。为什么？这就是 state value 的定义：在 $t$ 时刻 $s_t$ 状态的 state value，等于 immediate reward 加上下一个状态的 $v_\pi$ 再求期望。所以当 $v_t = v_\pi$ 时，$\delta_t$ 就变成了 $\delta_{\pi,t}$，在期望的意义下等于 0；反过来说，如果 $\delta_t$ 不等于 0，说明 $v_t$ 和 $v_\pi$ 之间还有差距。所以 $\delta_t$ 能说明 $v_t$ 与 $v_\pi$ 之间的不一致。

TD error 还有第三重理解：它是一种 **innovation**，也就是新的信息。我现在对 $v_\pi$ 有一个估计，这个估计可能不准确；然后来了一个新的 experience，我把这个 experience 和我的估计联系到一起，算出了这个 error。为什么会有 error 存在？error 的存在就说明我当前的估计不准确——那正好，我可以用这个 error 来改进我当前的估计。所以它是一种新的、有用的信息。

> **易错点**：这一讲的 TD 算法只做一件事——估计给定策略的 state value（即 policy evaluation）。它**不能**估计 action value，也**不能**直接搜索到最优策略。在这个基础之上，接下来马上会介绍一系列 TD 算法，它们能估计 action value，并且和 policy improvement 相结合去搜索最优策略。所以这个 TD 算法虽然非常简单，但非常 fundamental——第一次介绍 TD 时不可能上来就给一个很复杂的算法，那样大家很难抓住最核心的思想。有了它做基础，后面的算法你会发现和它非常非常类似。

### TD 算法在数学上解决什么问题

刚才我们是直接把 TD 算法写出来给大家，然后帮大家理解。但它最开始为什么会设计成这个样子？它究竟在干嘛？从数学上说，**TD 算法在求解一个贝尔曼公式**——给定策略的贝尔曼公式。

有同学会问：介绍贝尔曼公式的时候不是已经给过算法了吗？当时给了 closed-form solution（解析解）还有 iterative solution（迭代解），为什么还要再求解一遍？区别在于：那时候的算法是**依赖模型**的，现在是**没有模型**的。用一句话来说就是：

> **结论**：TD 算法是在没有模型的情况下，求解贝尔曼公式。这一条希望大家能非常明确地抓住。

下面来证明这句话。第一步，引入一个新的贝尔曼公式。

#### 一个更简洁的贝尔曼公式

从 state value 最基本的定义出发：从 $s$ 出发得到的 state value，等于对 immediate reward 以及跳到下一个状态之后所得 return 求期望。这个期望可以拆成两项：$E[R]$ 和 $E[G]$，而 $E[G]$ 可以再进一步写——如果下一个状态是 $S'$，那么对它的 state value 求期望。于是 state value 的定义就化成：

$$v_\pi(s) = E\big[R_{t+1} + \gamma v_\pi(S_{t+1})\big]$$

这也是一个贝尔曼公式，而且比之前学的形式更简洁——没有那一堆求和符号。为什么？因为这里写成了期望的形式；把 expectation 展开写，就和之前的公式一模一样了。这个公式有时被称为 **Bellman expectation equation**，因为里面有一个 expectation。

我之所以介绍这个贝尔曼公式，就是因为 **TD 算法从本质上来讲，是来求解这样一个 equation 的**。下面我们就来求解它——用上节课介绍的 RM 算法。之后大家会看到，推导出来的算法和刚才的 TD 算法非常非常类似，也就明白了：TD 算法就是求解贝尔曼公式的一个 RM 算法。

#### 用 RM 算法解贝尔曼公式

照搬例子的套路。定义函数 $g(v(s))$（写成 $g(w)$ 大家可能更清晰，就是要求解 $g(w)=0$，只不过这里的 $w$ 有具体含义——它是 $v_\pi(s)$ 的估计值，所以用 $g(v(s))$ 这个稍微复杂一点的记号）：

$$g\big(v(s)\big) = v(s) - E\big[R + \gamma v_\pi(S')\big] = 0$$

它的解就是 $v_\pi(s)$。求解它需要采样：对 $R$ 的采样 $r$、对 $S'$ 的采样 $s'$。用这些采样组成 $\tilde{g}$：

$$\tilde{g} = v(s) - \big[r + \gamma v_\pi(s')\big]$$

它实际上就是 $g(v(s))$ 加上一个测量误差——这是 RM 算法非常典型的流程。代入 RM 算法的典型形式 $v_{k+1} = v_k - \alpha_k \tilde{g}$：

$$v_{k+1}(s) = v_k(s) - \alpha_k\Big[v_k(s) - \big(r + \gamma v_\pi(s')\big)\Big]$$

这个式子和 TD 算法非常非常像了，但有两个小问题。

**第一个问题：采样方式不一样。** 这里要**反复**得到 $r$ 和 $s'$ 的采样——我从 $s$ 出发得到 $r$ 跳到 $s'$，下个时刻**还从 $s$ 出发**再得到 $r$ 跳到 $s'$，因为要对着同一个 $s$ 反复采样。这和 TD 算法沿着 episode 按时序顺序访问是不一样的。解决办法：不用反复回到 $s$ 采样，而是直接用一条 trajectory（轨迹）——轨迹里如果恰巧访问到了 $s$，我就更新一下 $s$ 的值；没访问到 $s$，它对应的估计值就保持不动。这样一条 trajectory 就能对所有状态的 $v$ 进行更新。

**第二个问题：$v_\pi(s')$ 是未知的。** 计算 $v_{k+1}$ 时要用到 $s'$ 的真实状态值 $v_\pi(s')$，但这正是我要求的，怎么办？也很简单：把 $v_\pi(s')$ 替换成 $v_k(s')$，也就是 $s'$ 当前的一个估计值。

问题又来了：原来是 $v_\pi$ 时能收敛，现在换成一个不准确的 $v_k$，还能确保收敛吗？答案是肯定的。直观解释：把更新式对每个状态都写一份，那么每个状态都有自己的估计值；虽然此时此刻这个估计值不准确，但我在其它地方还会对这个估计值进行修正，不断地修正，最后**所有**状态的估计值都会收敛到 $v_\pi$。

这就是用 RM 算法求解贝尔曼公式的思路。当然这个思路相对来说还是直观一些，下面给出严格的收敛性分析。

### 收敛性与学习率怎么取

TD 算法严格的收敛结果是一个定理：$v_t(s)$ 最后会收敛到 $v_\pi(s)$，条件是对 $\alpha_t$ 的一个条件——学过 RM 算法或 SGD 的同学看到这个条件就会很熟悉：

$$\sum_t \alpha_t(s) = \infty, \qquad \alpha_t(s) \ge 0, \qquad \alpha_t(s) \to 0$$

定理的证明这里不再讲，感兴趣可以去看书里的细节。根据这个定理强调几点。

第一，定理说的是 state value 会收敛到**真实的** state value，所以 TD 算法本质上还是在做 policy evaluation，而且是针对一个给定策略的。那怎么改进策略、找到最优策略？强化学习的最终目的是找到最优策略，之后我们需要把 policy evaluation 和 policy improvement 相结合才可以。

第二，关于 $\alpha_t$ 的条件怎么理解。第一个式子（求和趋于无穷）的本质意思是：**每一个状态都应该被访问很多次，或者无穷次**。为什么？因为每个状态被访问时，它对应的 $\alpha_t(s)$ 就是一个正数；当前 trajectory 访问的是其它状态时，这个状态的 $\alpha_t(s)$ 就是 0。所以 $\alpha_t(s)$ 的求和等于无穷，意味着它被访问了很多次。实际当中"很多次"就够了。

第三，第二个条件理论上要求 $\alpha_t$ 收敛到 0，但实际当中我们通常让 $\alpha_t$ 取一个很小的**常数**，比如 0.00 几。这时候条件当然就不满足了，为什么还这么做？因为实际当中情况复杂，我们希望很久之后得到的经验仍然能派上用场；相反，如果 $\alpha_t$ 最后趋向于 0，很久之后的经验就没用了。所以只把它设成一个很小的数，但不让它收敛到完全是 0。

### TD 与 MC 的优劣对比

接下来把 TD learning 和之前介绍的 MC learning 加以比较。MC 是课程当中第一个 model-free 的方法，TD 是第二个，它们各有什么优劣势？一个一个讲。（比较的表里我还写了 Sarsa——它是接下来马上要讲的算法，可以直接估计 action value，表达式和刚才的 TD 算法基本上是一模一样的，所以直接拿过来一起比。）

| 比较维度 | TD learning | MC learning |
| :--- | :--- | :--- |
| 更新时机 | online：拿到 $r_{t+1}$、跳到 $s_{t+1}$ 就立刻更新 | offline：必须等 episode 结束才能算 return 再更新 |
| 能处理的任务 | episodic 和 continuing 都可以 | 只能 episodic |
| 是否 bootstrapping | 是：基于旧的估计加新信息得到新估计 | 否：直接用 return 作为估计值 |
| variance | 比较小（涉及的随机变量少） | 比较高（一个 episode 引入大量随机变量） |
| bias | 有偏（依赖初始估计），数据多了逐渐消除 | 无偏（expectation 直接等于真值） |

**online 与 offline。** TD 是 online 的：现在得到了一个 reward、跳到了下一个状态，就立刻可以用这些信息更新当前的估计。MC 是 offline 的：虽然我在采样，但不可能立刻用——必须一直采下去，等到 episode 结束之后，才能计算从当前状态到最后这个 return 是多少，再用 return 作为估计值。正因为 TD 是 online 的，它能处理 **continuing task**（任务不会停止、一直持续下去的场景，这时必须在线更新，因为不能等它停下来）；当然它也能处理 episodic task，两类都可以。实际当中不存在一直持续下去的任务，但你可以想象它是一个非常长的任务。而 MC 因为是 offline 的，只能处理 episodic task。在这两方面，TD learning 略胜一筹。

**bootstrapping 是什么意思。** 就是说我之前对一个状态的 state value 已经有了一个初始的猜测，然后基于这个初始的猜测、再加上一些新的信息，得到一个新的猜测。MC 不是 bootstrapping：它直接根据当前的 episode 算出 return，就用这个 return 直接作为 value 的估计值，不涉及之前的估计。

**variance 为什么 TD 小、MC 大。** TD 算法过程中涉及的随机变量比较少：从当前状态出发，得到一个关于 reward 的采样，再得到一个关于下一个状态的采样（如果是 Sarsa，还会对下一个时刻的 action 再采样一次），总体来说随机变量少，只用一次采样的话 variance 就比较低。MC 需要一整个 episode——第一步有一个 reward、第二步有一个 reward，很多个随机变量进来，而只用这一次采样，variance 自然高。举个直观的例子：假如 episode 长度是 100，每经过一个 state 有 5 个 action 可以选择，那么一共实际上有 $5^{100}$ 个 episode——我从当前出发随机采样，可能会有 $5^{100}$ 种走法，但 MC 只用其中一个 episode 的数据来估计，你可以想象它的 variance 会比较大。

**但 TD 的均值是有偏的。** 随机变量有两个性质：variance 和 expectation（mean）。TD 虽然 variance 小，但因为它是 bootstrapping、依赖于初始的估计，如果初始估计不准确，这个不准确的估计会进入估计过程造成 bias。当然，随着越来越多的数据进来，这个 bias 会被抵消掉，最后能收敛到正确的估计值。相反，MC 虽然方差高，但它不涉及任何初始值，对它求 expectation，就直接等于真实的 action value 或 state value——所以它是无偏估计。

> **提示**：这一小节虽然只是全课八个小节当中的一个，但它的内容、分量，还有它揭示的 TD 方法的很多性质和思想，都非常非常重要，希望大家已经比较好地理解了。接下来在此基础之上再介绍四个算法。

### Sarsa：把 TD 从 state value 搬到 action value

接下来的四个算法是 Sarsa、Expected Sarsa、n-step Sarsa——从名字就能看出它们是一类的，都是 Sarsa 基本算法的变形——最后再介绍 Q-learning。Sarsa 及其变形做的事情是：给定一个策略，估计出 action value，也就是做 policy evaluation，再结合 policy improvement 就能找到最优策略；Q-learning 则直接求解 optimal action value，从而直接找到最优的策略。

为什么要 Sarsa？回到刚才的处境：上一小节的 TD 算法估计的是给定策略的 state value，但我们要改进策略的时候，需要估计的是 **action value**——哪个 action value 大就选哪一个作为新的策略。TD 算法不能估计 action value，而 Sarsa 可以直接估计。

#### 算法形式：换个对象而已

没有模型，所以要有数据（experience）。假设有这样一个集合，每个时刻 $t$ 对应的经验是五个元素：$s_t,\ a_t,\ r_{t+1},\ s_{t+1},\ a_{t+1}$。有了数据，用这个算法更新：

$$q_{t+1}(s_t, a_t) = q_t(s_t, a_t) - \alpha_t\Big[q_t(s_t, a_t) - \big(r_{t+1} + \gamma\, q_t(s_{t+1}, a_{t+1})\big)\Big]$$

其中 $q(s,a)$ 是 $q_\pi(s,a)$ 的估计值，$q_t$ 是 $t$ 时刻的估计。这个式子和刚才的 TD 算法**一模一样**，除了什么？除了刚才估计的是 $v(s_t)$，现在换成了 $q(s_t, a_t)$：刚才是对每一个状态 $s$ 求 $v_\pi(s)$，现在是对每一个 $(s,a)$ 求 $q_\pi(s,a)$。做这个简单的替换，就得到了新算法。同样也有一条隐含的规则：当前时刻访问的是 $(s_t, a_t)$，就更新它的 $q$；其它没被访问的 $q$ 保持不动。

```text
TD   :  (s_t) --------------r(t+1)--------------> (s_(t+1))
                     更新对象: v(s_t)

Sarsa:  (s_t, a_t) ---r(t+1)---> (s_(t+1), a_(t+1))
                     更新对象: q(s_t, a_t)
```

读图说明：TD 用三元组经验更新状态的值，Sarsa 多取一个 $a_{t+1}$，用五元组经验更新"状态-动作对"的值，其余结构完全一致。

**为什么叫 Sarsa？** 其实很简单：它是 **S**tate **a**ction **r**eward **s**tate **a**ction 这五个单词的首字母缩写。换个角度说，这个算法用到的数据就是 $s_t, a_t, r_{t+1}, s_{t+1}, a_{t+1}$ 这五样，取首字母正好是 S-a-r-s-a。

#### Sarsa 在解什么数学问题

刚才 TD learning 求解了一个贝尔曼公式，Sarsa 也是求解一个贝尔曼公式，只不过形式又有所不同：

$$q_\pi(s,a) = E\big[R_{t+1} + \gamma q_\pi(S_{t+1}, A_{t+1})\big]$$

和之前所有贝尔曼公式不同的在于：它是用 **action value** 来表达的，而不是基于 state value。所以这个贝尔曼公式刻画的是不同 action value 之间的关系，但本质上都是一样的，它也是贝尔曼公式。详细的分析可以到书里看。

它的收敛性和刚才 TD 算法的定理也是一模一样的：$q_t(s,a)$ 会收敛到 $q_\pi(s,a)$，条件主要是针对学习率 $\alpha_t$ 提出的。不管怎么样，这个定理告诉我们：$q_t$ 收敛到的是 $q_\pi$——所以还是给定一个策略、估计它的 action value，为了得到最优的策略，还需要把这个过程和一个 policy improvement 相结合才可以。

### 完整的 Sarsa：与策略改进结合

把 Sarsa 的 policy evaluation 步骤和 policy improvement 结合起来，结合之后的算法也被称为 Sarsa——实际上大多数情况下大家听到 Sarsa，指的就是这两个结合之后的算法。它的伪代码简要过一遍：

```text
对每一个 episode:
    初始化 s, 按 π 采样 a
    while 当前状态不是 target state:
        执行 a_t, 观测 r_(t+1), 跳到 s_(t+1)
        在 s_(t+1) 按当前策略采样 a_(t+1)      # Sarsa 需要的五元组齐了
        # 步骤一: q value update (policy evaluation)
        q(s_t, a_t) ← q(s_t, a_t) - α·[q(s_t, a_t) - (r_(t+1) + γ·q(s_(t+1), a_(t+1)))]
        # 步骤二: policy update (policy improvement)
        按 ε-greedy 基于 q 更新策略 π
        s_t ← s_(t+1), a_t ← a_(t+1)
```

几点说明。到达目标之前每一轮做的事是：在 $s_t$ 根据当前策略 take action $a_t$，得到 reward $r_{t+1}$，跳到下一个状态 $s_{t+1}$；在下一个状态再根据那里的策略进行一次 action 采样，得到 $a_{t+1}$——这就凑齐了 Sarsa 所需要的 experience。然后做 q value 的 update（也就是 policy evaluation），算 $\pi_t$ 对应的 q 值；在这之后**立刻**做 policy update。更新方式是 q value 谁大就选谁，但用的是一个 **ε-greedy** 的策略——不会给 greedy action 1 的概率，而是给一个比较大的概率，同时仍然给其它 action 留比较小的概率；然后就用这个新策略去生成新的 experience，不断迭代。

有一个细节：之前的网格世界任务里到达目标可以一直执行策略、不需要停；现在我们更关注的是从一个状态出发怎么到达目标，所以可以到目标之后强行停下来，也可以不停，区别不是很大。

这个算法有两个步骤，这里要强调一下它们和我们之前理解的 policy iteration 的关系。还记得 policy iteration 吗？它也分两步——policy evaluation 和 policy improvement，每个 iteration 都包含这两步；但要把 policy evaluation 算准，需要无穷步。实际当中我可能只计算一步或者几步，实际上完全没得到精确的 value，但也会立刻切换到策略的更新。Sarsa 正是这种思想——更新了 q value 之后立刻进行策略更新，虽然只执行了一下、并没有得到很准确的 action value。这基于 **generalized policy iteration**（GPI）的想法。另外，策略更新的不是一个 greedy 策略而是一个 ε-greedy 策略，这样能尽可能访问到更多的 $(s,a)$，找到更优的策略。

> **提示**：这一讲讲了两部分——第一部分是给定一个策略怎么求解相对应的贝尔曼公式，得到 Sarsa 这个迭代算法；第二部分是怎么把 policy evaluation 和 policy improvement 相结合找到最优策略。希望大家能明白这里最复杂的式子（那个迭代的式子）是来干嘛的：它是来做 policy evaluation、求 action value 的。这是它最最核心的想法。明白了这个 idea，剩下的其实就很简单了——整个算法看起来稍微复杂一点，只是因为还需要迭代改进策略、还需要让策略是 ε-greedy 的。总而言之，抓住核心思想，明白每一部分在做什么事情。

### 一个例证：从特定起点走向目标

下面通过一个例子来例证 Sarsa。任务是这样的：从一个**特定的状态**出发，找到从这个状态到达目标状态的路径。

注意这个任务和到目前为止介绍的所有任务（网格世界的任务）是不一样的。之前所有网格世界的任务是要找出**每一个状态**的最优策略；这里不关注每一个状态，只关注从**一个特定状态**（这个例子里是左上角那个状态）出发、到达目标的策略或路径。这在实际当中是非常常见的。所以未来大家学习的时候要能区分开：是要找从一个特定状态出发的情况，还是要找所有状态的最优策略。

用 Sarsa 最后找到的最优策略，是从一个初始的、不好的策略开始得到的。初始状态从左上角出发，沿着这个策略概率比较大的方向走，还是能够到达目标的，说明达到了我们的目的。但很多其它状态，正像刚才说的，其实还没有达到最优。

那有没有可能它找到的这条路径虽然能到达目标，却不是最短的、不是最优的，而真正的最优恰好藏在那些没有探索过的地方？**这是有可能的。** 所以问题就在于：你是想找到所有状态的最优策略，还是只想找到一个可行的路径就可以？想找到所有状态的最优策略，就必须去探索所有的 state-action pair。而在这个任务当中，我们只进行了 500 次探索——一共 500 个 episode。

这里有一张图，也是课程当中第一次介绍这种图，我稍微着重介绍一下：

- **横坐标**是 episode index，一共 500 个 episode，最开始的在左边，随着策略不断改进，重新采集得到的 episode 依次往右排。
- **第一个图的纵坐标**是沿着每个 episode 得到的 total reward。最开始 reward 是比较负的——因为最开始的策略不好，可能往墙上撞、或者进到 forbidden area，很多负 reward 进来。随着策略不断改善，reward 也越来越大。但没有超过 0——到达目标应该是正数，为什么不是 0？就是因为用的是 ε-greedy 策略，它或多或少还是会有负的 reward 进来。
- **第二个图的纵坐标**是 episode length。最开始 episode 长度比较长，因为初始策略不好，可能走了很久才"瞎猫碰到死耗子"刚好碰到 target area——最开始要几百步才能到达目标；随着不断改进，沿着策略几十步就可以到达目标了。

## TD 方法大家族：Expected Sarsa、n-step Sarsa 与 Q-learning
> 对应块：BLK09 | 覆盖分集：P33-P36 | 块标题（分集名）：《第7课-时序差分方法（Expected Sars》

刚刚我们介绍了 Sarsa。相比最开始介绍的 TD 算法，大家也看到了，Sarsa 和 TD 算法形式基本上是一模一样的，只有两点区别：第一，Sarsa 是直接来估计 action value；第二，我们把 Sarsa 和 policy improvement 步骤相结合，这样就得出了一个能够搜索最优策略的算法。

下面我们再介绍 Sarsa 的两个变形：一个叫 Expected Sarsa，一个叫 n-step Sarsa。相对来说，它们的重要性没有 Sarsa 那么高，但我也想把它们放到这里来讲。为什么呢？**从一个经典的算法出发，然后去做推广和改进，这是做研究的一个非常常见的思路。**大家可以看一下，我们怎么样从经典的 Sarsa 出发，得到更多的算法——这个过程中你能体会到"推广"本身是怎么发生的。

### 从 Sarsa 到 Expected Sarsa：把 $a_{t+1}$ 换成期望

Expected Sarsa 的算法和 Sarsa 几乎一样：第二个式子还是一样的，第一个式子基本上也是一样的，唯一的区别就在 TD target 这一个地方——这边是一个 expectation，是对这个 $a$ 求期望：

$$\bar{q}_t = r_{t+1} + \gamma \sum_{a} \pi(a \mid s_{t+1})\, q_t(s_{t+1}, a)$$

这个期望写开就是上面这个表达式：在 $s_{t+1}$ 我有很多个 $a$ 的选项可以选择，我选择每个 $a$ 的概率是 $\pi(a \mid s_{t+1})$，选择 $a$ 之后的值是 $q_t(s_{t+1}, a)$，按期望的定义加权求和就得到了它。

> **关键观察**：这个期望求出来，实际上就是 $s_{t+1}$ 所对应的 **state value** $v_\pi(s_{t+1})$，而不再是一个 action value。

所以相比 Sarsa，区别就是 TD target：Sarsa 里是 $r_{t+1} + \gamma q_t(s_{t+1}, a_{t+1})$，Expected Sarsa 里变成了 $r_{t+1} + \gamma v_t(s_{t+1})$——**Sarsa 需要 $a_{t+1}$，Expected Sarsa 不再需要 $a_{t+1}$**。这是它们的本质区别。

代价与收益各占一边：相比 Sarsa，它的计算量要求更大，因为要计算那个求和式；但因为去掉了 $a_{t+1}$，不再需要对 $a_{t+1}$ 进行采样，所以涉及的随机变量个数减少了，随机性也就减少了。

#### 它在解决什么数学问题

Expected Sarsa 究竟在解决一个什么样的数学问题？我们知道 Sarsa 是在求解一个贝尔曼公式，Expected Sarsa 一样，也是在求解一个贝尔曼公式，只不过这个贝尔曼公式的形式稍微发生了一些变化——区别就是在刚才没有 expectation 的地方多了一个 expectation：

$$q_\pi(s, a) = \mathbb{E}\Big[R_{t+1} + \gamma\, v_\pi(S_{t+1})\Big], \qquad v_\pi(s_{t+1}) = \sum_a \pi(a \mid s_{t+1})\, q_\pi(s_{t+1}, a)$$

注意这里的层次：对 $A_{t+1}$ 的期望被收进了 $v_\pi(S_{t+1})$ 里面，$S_{t+1}$ 是在外边才求期望的。这个式子大家看起来就很清晰了：$q_\pi(s,a)$ 表示我从 $(s,a)$ 出发，action value 等于 immediate reward 加上 $\gamma$ 乘以下一个状态的 state value，最外层再求一个期望。这仍然是一个贝尔曼公式。

我们同样可以把 Expected Sarsa 应用到之前提到的网格世界例子当中：任务是从某个固定状态出发，最后找到到达目标的轨迹或策略。根据 Expected Sarsa 得到的最后策略，如果沿着概率比较大的方向走，确实能够到达目标，就能解决问题。同样的，因为这里我们只需要找到从这个状态出发到目标的路径，其它状态它们的策略可能不是最优的，但这并不是我们所关心的。学习过程的曲线也符合预期：随着逐渐学习，每个 episode 收集到的 reward 越来越大，到达目标所需要的步数也越来越少。

### n-step Sarsa：把 Sarsa 和蒙特卡洛装进同一个框架

下面来介绍 n-step Sarsa。你可以认为它是 Sarsa 的一个变形，也可以认为是它的一个推广。为什么这么说？因为 **n-step Sarsa 把 Sarsa 和蒙特卡洛两种方法都包含在内了**。大家听了之后可能会吃惊：蒙特卡洛方法和 TD 方法是截然不同的两个方法，为什么好像能够被揉在一起、统一在一起呢？实际上是可以的。我们来看一看 n-step Sarsa 究竟是怎么回事。

#### return 的多种分解

首先复习一下 action value 的基本定义：我从 $s$ 出发 take action $a$，它的 action value 就等于之后沿着任何一个 trajectory 我所得到的 return，再求一个平均：

$$q_\pi(s, a) = \mathbb{E}\left[G_t \mid S_t = s, A_t = a\right]$$

这个 return 的写法其实比较关键——return 有很多种写法。我们来看第一种分解：

$$G_t^{(1)} = R_{t+1} + \gamma\, q_\pi(S_{t+1}, A_{t+1})$$

也就是说，我只考虑这个时刻所得到的 immediate reward，然后下个时刻之后的所进行为全部汇总成一个 $q_\pi$ 的形式。

新的知识来了——它可以写成第二种分解：

$$G_t^{(2)} = R_{t+1} + \gamma R_{t+2} + \gamma^2 q_\pi(S_{t+2}, A_{t+2})$$

$t+1$ 时刻的 immediate reward 算进来，$t+2$ 时刻的也算进来，再之后的所有 reward 全部汇总成一个新的 $q_\pi$，它是 $(S_{t+2}, A_{t+2})$ 的函数。按照这样一个思路下去，我们就可以分解成第 $n$ 种形式：

$$G_t^{(n)} = R_{t+1} + \gamma R_{t+2} + \cdots + \gamma^{n-1} R_{t+n} + \gamma^{n} q_\pi(S_{t+n}, A_{t+n})$$

如果 $n$ 趋向于无穷，我们就得到了 $G_t^{(\infty)}$：

$$G_t^{(\infty)} = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \cdots$$

直加加到最后，就没有 $q_\pi$ 了，后边全部都是不同时刻所得到的 immediate reward。

> **关键对应**：$G_t^{(1)}$ 对应的就是 Sarsa；$G_t^{(\infty)}$ 对应的就是蒙特卡洛；中间那个 $G_t^{(n)}$ 对应的就是 n-step Sarsa。另外注意，所有带上标的这些 $G$ **全部都是等价的**，只不过它们分解的方式不同。

#### 一个算法覆盖两个极端

现在把第一种分解 $G_t^{(1)}$ 代到 action value 的定义里边，就得到一个式子；把右边写开，大家看得眼熟吗？实际上这就是我们之前介绍的 Sarsa 所在求解的那个贝尔曼公式。而如果把 $G_t^{(\infty)}$ 代进去，右边就变成了一整条 return 的期望：我在采样的时候，就沿着一条 trajectory 把所有的 reward 加起来得到 return，用这个 return 来近似 $q_\pi$——这个思路就是蒙特卡洛的思路。

于是我们就知道了：用第一种分解就得到了 Sarsa 这个算法，用第无穷种分解就得到了蒙特卡洛（MC）这个算法，中间会有一个折中的算法，实际上就是 n-step Sarsa——我既不是 1 也不是无穷，我就是 $n$。当然，这个 $n$ 可以是 1，可以是无穷，也可以是其它的数。它最后求解的式子就是：

$$q_\pi(s, a) = \mathbb{E}\Big[R_{t+1} + \gamma R_{t+2} + \cdots + \gamma^{n-1} R_{t+n} + \gamma^{n} q_\pi(S_{t+n}, A_{t+n})\Big]$$

求解这个式子的随机逼近算法就是：

$$q_{t+n}(s_t, a_t) = q_{t+n-1}(s_t, a_t) - \alpha_t\Big[q_{t+n-1}(s_t, a_t) - \big(\text{TD target}\big)\Big]$$

和前面 Sarsa 包括 Expected Sarsa 的不同之处，仍然只在 TD target 这一处。我们验证一下两个极端：

- **$n = 1$**：TD target 就变成 $r_{t+1} + \gamma q_t(s_{t+1}, a_{t+1})$——这正是 Sarsa 所用的 TD target。
- **$n = \infty$**：选取 $\alpha_t \equiv 1$，这个系数 1 就可以不用写了。式子里有一个 $q$、后边又有一个 $q$，这俩就抵消了，里面那项负负得正，所以最后得到的 $q_{t+1}$ 就等于后面所有这些采样的总和——当然 $n$ 等于无穷时后面那个 $q_\pi$ 也没了，就是一串 immediate reward 一直加到最后。这就是蒙特卡洛算法。

所以通过这个推导我们也知道了：直接改变 $n$，让它等于 1 或者等于无穷，这个算法就直接变成了 Sarsa 或者变成了蒙特卡洛的方法。

#### 数据、等待与 bias/variance

下面对 n-step Sarsa 的一些性质进行分析。首先我们要明确：**所有的算法都需要数据**。之前介绍的 Sarsa 需要什么呢？需要那 5 个数据 $(s_t, a_t, r_{t+1}, s_{t+1}, a_{t+1})$——在 $t$ 时刻我能得到这 5 个数据，就可以直接用。另一个极端，蒙特卡洛方法需要无穷多个、或者一直等到 episode 结束的所有数据，才能计算 $t$ 时刻 $s_t$ 所对应的 action value。n-step Sarsa 自然就是一个折中：我既不能只用这 5 个就来计算，也不需要等到后面所有数据都有了——在这 5 个之外，我还需要再往后若干步的测量才可以。

那它面临的问题是什么呢？就是我在 $t$ 时刻实际上还不知道后边这些测量。怎么办呢？我只能等。说到"等"，其实大家就明白了：因为 n-step Sarsa 在 $n$ 比较大的时候是比较接近蒙特卡洛方法的，而蒙特卡洛就需要等——在 $t$ 时刻虽然有些数据，但我不能立刻去更新，必须要等到 episode 结束，用后边所有的经验才能去更新，这就是我们之前说蒙特卡洛方法是 offline 的原因。那么 n-step Sarsa 实际上**既不是 offline 也不是 online，或者说它是一种特殊的 online 方法**。为什么？因为我需要等到 $t+n$ 时刻，才能对 $s_t, a_t$ 所对应的 $q$ 值进行更新——写到更新式里，左边是 $q_{t+n}$，右边是 $q_{t+n-1}$ 减去 $\alpha_t$ 乘上误差。到那一刻，我所有需要的测量才都已经有了。所以它在实现的时候会需要这样一个"等数据到齐"的技巧。

因为蒙特卡洛方法和 Sarsa 实际上是 n-step Sarsa 的两个极端情况，所以很自然地，n-step Sarsa 的性质也是 Sarsa 和蒙特卡洛方法的一个混合性质：

| $n$ 的取值 | 性能倾向 | variance | bias |
| :--- | :--- | :--- | :--- |
| $n$ 较大 | 接近蒙特卡洛方法 | 比较大 | 比较小 |
| $n$ 较小 | 接近 Sarsa | 比较小 | 比较大 |

关于 variance 和 bias，我们在前面比较 TD、Sarsa 还有蒙特卡洛方法的时候已经有比较详细的解释，这里就不再展开。只需补一句：$n$ 较小时那个比较大的 bias 是由初始的猜测所引起的，随着数据越来越多，这个 bias 会慢慢消失掉，但它的 variance 比较小。

最后一点：前面介绍的 n-step Sarsa 算法，实际上还是在做 **policy evaluation**——你给我一个策略，我能估计出来它的 action value。那么为了得到最优的策略，我们可以把它和 policy improvement 相结合，就类似前面介绍的 Sarsa 一样，就能去进行策略的搜索。

### Q-learning 登场

到目前为止我们把 Sarsa 介绍完了。Sarsa 本质上是来估计一个给定策略的 action value，然后把它和 policy improvement 相结合，在两者之间相互迭代，得到一个求解最优策略的算法。下面我们就来到 Q-learning——**万众瞩目的时刻**。Q-learning 是非常非常经典的一种算法，直到今天也在被广泛使用，当然指的是 Deep Q-learning，也就是 Q-learning 的一个变形。

Q-learning 和 Sarsa 的主要区别在于什么呢？从数学上来讲：**它是直接估计 optimal action value**。所以它不需要在 policy evaluation 和 policy improvement 这两步之间来回交替运行——因为它直接就把最优的 action value 估计出来了。

#### 算法本身：只有 TD target 变了

直接把 Q-learning 的算法给出来。其实它和前面 Sarsa 的算法是非常类似的。先看第二个式子：当前时刻如果不是 trajectory 访问到的那个 $(s_t, a_t)$，那么对应的 $q$ 值保持不变。再看第一个式子，对当前访问的 $(s_t, a_t)$ 更新：

$$q_{t+1}(s_t, a_t) = q_t(s_t, a_t) - \alpha_t\Big[q_t(s_t, a_t) - \big(r_{t+1} + \gamma \max_a q_t(s_{t+1}, a)\big)\Big]$$

从结构上来讲和前面的 Sarsa 一模一样，唯一不同的就是 TD target 发生了变化：Q-learning 的 TD target 里是对 $a$ 求 **maximization**；相比之下，Sarsa 的 TD target 里是在 $s_{t+1}$ 处按照当时的策略**选择**一个 $a$，而不是对 $a$ 进行优化。

#### 它在求解贝尔曼最优方程

Q-learning 在数学上解决什么问题？前面介绍 Sarsa 和 TD 方法的时候，每一个算法我们都告诉大家它在解决什么数学问题：Sarsa 是在求解一个（给定策略的）贝尔曼方程。而 Q-learning 不一样了，**它不是在求解一个贝尔曼方程**——不是"你给我一个策略，它对应的贝尔曼方程是什么，我求出它的 action value"，不是的。**它是在求解一个贝尔曼最优方程**：

$$q(s, a) = \mathbb{E}\Big[R_{t+1} + \gamma \max_a q(S_{t+1}, a)\Big]$$

这个贝尔曼最优方程和我们之前所介绍的贝尔曼最优方程不太一样：第一，它有 expectation；第二，它不是基于 state value 而是基于 action value。但它仍然是贝尔曼最优方程（为什么是这样，可以到书里去看）。在这里大家只要知道：Q-learning 实际上就是在求解这样一个贝尔曼最优公式。它最后得到的 $q$ 值不是哪一个策略的 $q$ 值，而是**最优的 $q$ 值**——当然，这个最优的 $q$ 值对应的就是最优的那个策略。

我们刚才实际上只用了两页，就把 Q-learning 的基本信息介绍完了：前面一页介绍了算法是什么，这一页介绍了它在解决什么样的数学问题。你可能会很吃惊：什么？Q-learning 就这样？万众瞩目的——**实际上就是这样**。后面我们还会介绍 Q-learning 很多非常有意思的性质，也会用例子来说明，但基本信息就是这两页。

为什么会这么少呢？就是因为我们之前做了非常多的铺垫：上一章介绍的随机梯度下降、这一章前面介绍的 Sarsa、以及用于估计 state value 的 TD 方法，那些都已经讲得非常详细了。你了解了那些再来看 Q-learning，它就会非常简单。相反，如果你直接来看 Q-learning，就会冒出一系列问题：为什么这个算法长成这个样子？什么是 TD target？什么是 TD error？所以我建议你起码要回到这次课的开头，把 TD 方法、Sarsa 方法好好了解之后再来看 Q-learning。

### behavior 策略与 target 策略：on-policy 与 off-policy

了解了 Q-learning 的算法仅仅是开始，下面介绍它的性质。第一个性质就是 off-policy 和 on-policy 的区分。当然这并不是针对 Q-learning 的——实际上**所有的强化学习算法**都存在这样一个分类问题，我们就借着介绍 Q-learning 这次机会把这两个概念引入进来。

首先我们要说：在强化学习当中其实存在**两个策略**：

- **behavior 策略**（behavior policy）：它和环境进行交互，生成 experience；
- **target 策略**（target policy）：它是我们一直在更新的那个策略，最后它会变成我们想要的最优策略。

其实我们之前讲 Sarsa、TD 方法的时候都已经涉及到了，只是没有明确地提出来，现在把它明确提出来。基于这两个策略，就可以把强化学习算法分成两大类：

> **定义**：behavior 策略和 target 策略**相同**，就叫 on-policy；**不同**，就叫 off-policy。

on-policy 就是：我用这个策略来和环境交互得到 experience，同时我再改进这个策略，改进完了之后我再用改进后的策略和环境交互。off-policy 就是：我用一个策略来和环境交互得到大量的经验，然后用这些经验去不断地改进**另一个**策略，那个策略最后会收敛到一个最优的策略。

那可以不同意味着它既可以相同又可以不同——所以 off-policy 会带来一些额外的好处。最直接的好处就是：我们可以从**别人之前积累的经验**当中直接学习——他们采取他们自己的策略积累了一些经验，我们拿过来就能用。一个比较典型的情形是：behavior policy 是一个探索性非常强的策略，能够探索到所有的 state-action pair，基于这种探索性，我们就能非常好地估计出每一个 $(s,a)$ 的 action value。相反，如果必须用 target policy 同时作为 behavior policy 去生成经验，因为 target policy 可能是 Greedy 的或者 $\varepsilon$-Greedy 的，探索性就比较弱，可能就很难探索到所有的 $s$ 和 $a$，进而难以估计出所有 $(s,a)$ 的最优值。

### 逐个判断：Sarsa、蒙特卡洛、Q-learning 各归哪类

给你一个强化学习算法，怎么判断它究竟是 on-policy 还是 off-policy？这个问题如果你明白了其实就很简单，不明白的话可能就比较让人迷惑。判断的时候有两个工具可以帮我们：

1. **看这个算法在数学上究竟解决什么问题**。前面介绍 Sarsa、TD、Q-learning 的时候，我们都说了它们分别在解决贝尔曼公式或者贝尔曼最优公式——理解了这一点，对判断非常有好处。
2. **看算法实施的时候需要哪些东西才能跑起来**。根据那些东西，就可以判断它究竟是 on-policy 还是 off-policy。

下面用这两个工具看三个算法。

#### Sarsa 是 on-policy

先给结论：Sarsa 是 on-policy，它的 behavior policy 和 target policy 是相同的。

第一个工具：Sarsa 在数学上求解的是一个**给定策略的贝尔曼公式**。这里边的 $R$ 是当 $(s,a)$ 给定时满足 $p(r \mid s,a)$ 的随机量，下一个时刻的状态满足 $p(s‘ \mid s,a)$，再下一时刻状态上采取的 action 则是按给定策略 $\pi$ 采样的——注意，整个式子里处处都是这个给定的策略。第二个工具：看它的算法需要什么数据。Sarsa 之所以叫 Sarsa，就是因为它用到了 $s_t, a_t, r_{t+1}, s_{t+1}, a_{t+1}$ 这 5 个量。其中，如果 $s_t, a_t$ 给定了，那么 $r_{t+1}$ 和 $s_{t+1}$ 实际上**和任何策略都没有关系**——它俩全都是由 $p(r \mid s,a)$ 和 $p(s’ \mid s,a)$ 这两个概率决定的（我们不知道这两个概率，所以通过采样的方式获得，但总而言之它们和策略没关系）。但是第 5 个量 $a_{t+1}$ 和策略有关系：它是在 $s_{t+1}$ 这个状态下根据策略 $\pi_t$ 采样得到的。很清楚了，**这个 $\pi_t$ 就是 behavior policy**，因为用到它来进行采样。

那 target policy 是什么？用到第一个工具：Sarsa 在估计 $\pi_t$ 所对应的 action value，我再用这个 action value 去更新 $\pi_t$、得到更好的策略。所以 $\pi_t$ **既是 behavior policy，又是 target policy**。这个过程可以画成一个环：

```text
    πt ──生成──> experience ──估计──> qπt ──改进──> πt+1
     ▲                                            │
     └────────────────────────────────────────────┘
```

读图：$\pi_t$ 自己生成数据（experience），用数据估计它的 action value，再用估计值改进它自己得到 $\pi_{t+1}$，改进后的策略回到起点继续生成下一轮数据——生成数据和被改进的是同一个策略，这正是 on-policy。

#### 蒙特卡洛方法也是 on-policy

直接给结论：基于蒙特卡洛的方法是 on-policy。注意，on-policy / off-policy 不仅仅是对 TD 算法的分类，**所有的强化学习算法**都有这样一个分类。

用两个工具来看。蒙特卡洛要解决的问题就是估计 action value：用一长串 episode，计算后面所得到的 return，把 return 作为 action value 的估计。所以很显然：我现在有一个策略 $\pi$，用 $\pi$ 生成一条 trajectory，用这条 trajectory 得到的 return 来近似估计 $q_\pi$，然后我得到的 $q_\pi$ 再来改进这个 $\pi$。这里边 $\pi$ 既是 behavior policy 又是 target policy——所以蒙特卡洛方法是 on-policy 的。

#### Q-learning 是 off-policy

第三个，Q-learning 是 on-policy 还是 off-policy？先给结论：**Q-learning 是 off-policy**。之前学的 Sarsa 和蒙特卡洛都是 on-policy，现在我们学到了第一个 off-policy 的算法。还是从两方面分析。

第一方面，看它解决的数学问题：Q-learning 求解的是**贝尔曼最优公式**。贝尔曼公式需要给定一个策略，然后求出该策略相对应的 action value 或者 state value；但贝尔曼最优公式**不涉及到任何策略**——它就是一个含有 $q$ 的等式。当然，贝尔曼最优公式所对应的是最优的策略，但式子里显式地并不含有任何策略。既然要解的方程里没有策略，那么谁来生成数据就成了一件可以灵活安排的事。

第二方面，看实施 Q-learning 需要什么测量：这里需要的就是 $s_t, a_t, r_{t+1}, s_{t+1}$ 这 4 个。如果 $s_t, a_t$ 给定，那么 $r_{t+1}$ 和 $s_{t+1}$ 不依赖于任何策略——和前面 Sarsa 的分析一样，它们分别由 $p(r \mid s,a)$ 和 $p(s' \mid s,a)$ 决定。那策略出现在哪？我需要从 $s_t$ 出发，**根据一个策略得到 $a_t$**——这个就是它的 behavior 策略。而它的 target 策略呢？我在计算 $q$，每到一个状态我看一看哪一个 action 的 $q$ 比较大，我就选那个 action——这个所对应的策略就是 target 策略。当 $q$ 逐渐收敛到最优 $q$ 值的时候，相对应的这个 target 策略也就收敛到了最优的策略。所以这里边的 behavior 策略和 target 策略是不同的——**Q-learning 是 off-policy**。接下来介绍 off-policy 的 Q-learning 具体怎么实施的时候，大家可能会看得更清楚。

### Q-learning 的两种版本：强行相同与各司其职

刚才说了，Q-learning 是 off-policy，behavior policy 和 target policy 可以不同；而"可以不同"意味着它也可以相同——相同实际上是不同的一种特殊情况。所以如果强行让 Q-learning 的 behavior policy 和 target policy 相一致，我就得到了一个 on-policy 的算法。下面分别给出它的 on-policy 版本和 off-policy 版本。

**on-policy 版本**：实际上和 Sarsa 是一模一样的，唯一的区别就在 $q$ value 这一部分——把 Sarsa 里的 $q_t(s_{t+1}, a_{t+1})$ 替换成了在 $s_{t+1}$ 处按当前 $\varepsilon$-Greedy 策略对 $a$ 求期望的那一项；策略更新仍然用 $\varepsilon$-Greedy。整个流程是：开始有一个策略，根据这个策略得到一些数据，通过这些数据得到 $q$ value，通过 $q$ value 得到一个改进的策略，再用改进的策略进一步得到数据。显然这里边这个策略既是用来生成数据的（behavior policy），同时又在不断地被更新（target policy）——所以这时候它是 on-policy。

**off-policy 版本**：假设我们有一个策略叫 $\pi_b$，下标 $b$ 代表 behavior。$\pi_b$ 用来生成一系列 experience，我们要解决的任务是：根据已经有的这些 experience，来寻找最优的策略。关注 $t$ 时刻得到的状态、action 和 reward 等，进行两个步骤：

- **第一步，update q value**：这和 on-policy 版本当中是一模一样的，就是典型的 Q-learning 更新，没什么好讲的；
- **第二步，update target policy**：这一步和 on-policy 不一样。刚才 on-policy 当中它是 $\varepsilon$-Greedy，现在变成了 **Greedy**——仍然是根据刚才得到的 $q$ value 来更新策略，但不再是 $\varepsilon$-Greedy 了。这个策略我们给它一个名字叫 $\pi_t$。

为什么这时候它是 Greedy 而不是 $\varepsilon$-Greedy 呢？就是因为：之前用 $\varepsilon$-Greedy，是待会要用这个策略去生成数据、希望它有一定的探索性，能访问到那些没有被访问过的 $s$ 和 $a$；而现在生成的这个策略 $\pi_t$ **根本不会拿去生成数据**——生成数据是 $\pi_b$ 的事。那为什么还要让它是 $\varepsilon$-Greedy 的？它直接是 Greedy 就行了。因为我们知道 Greedy 的策略会是最优的：随着 $q$ 的估计越来越准确，$\pi$ 的估计也会收敛到最优的策略。

这个过程的结构可以画出来：

```text
    πb ──生成──> experience ──更新──> qt ──Greedy──> πt
  (只管采数据)                  (不断逼近最优 q)   (只管当策略)
```

读图：$\pi_b$ 负责与环境交互产生经验，经验只用来更新 $q$；$\pi_t$ 从 $q$ 中用 Greedy 提取出来，不参与采数据——两个策略各司其职，所以很显然这是 off-policy 的情况。

### 网格世界实验：探索性有多重要

介绍完了 Q-learning 的算法和性质，下面用几个例子更好地说明这个算法。例子仍然是之前一直考虑的网格世界，但注意：**这里的任务是要找到每一个状态所对应的最优策略**——这和我们之前测 Sarsa 的那个例子是不一样的。在那里我们从最左上角那个固定的状态出发，找到一条到达目标的路径就行，不需要所有状态都找到最优策略。所以这里的任务和刚才那个任务是不一样的。**我也提醒大家去关注任务究竟是什么**，任务不同，做法和评价都不同。

先把 ground truth 给出来——也就是最优策略和最优的 optimal state value。待会用 Q-learning 算出来一个策略，看它和这个最优策略究竟是不是相同。

首先选定一个 behavior policy，用它产生很多数据。这里的 behavior policy 是一个**均匀采样的策略**：每个状态有 5 个 action，每个 action 都给 $0.2$ 的概率，它的探索性是比较强的。跑 100 万步，每一个 state-action pair 都被访问到很多次，所以数据是比较好的。既然数据是从 behavior policy 产生的，估计的时候肯定要用 **off-policy 的 Q-learning**。它最后给出的策略和 ground truth 基本上是一模一样的——只有一些小地方，比如 ground truth 里这个状态是向下、那个是向左，实际上没什么太大的区别。策略的最优性也可以从图上展示出来：估计过程中 Q-learning 给出一系列策略，每个策略都对应一个 state value，把它和最优 state value 作差再取模，就是纵坐标。最开始那个策略并不太好，和 optimal state value 还有一段距离；最后这个策略就已经很好了，基本上和 optimal state value 一模一样。

那如果 behavior policy 的探索性不强呢？针对我们这个问题——要在每一个 $(s,a)$ 都找到最优策略——最好当然要访问到所有的 $(s,a)$ 并且访问很多次，所以 behavior policy 最好是探索性强的。我们来看反例：假如用一个 $\varepsilon = 0.5$、但在每个状态都有比较大的概率向右走的策略，它的探索性明显不如均匀策略——100 万步之下，还有很多 state-action 根本就没有被访问到。用这样的数据做 Q-learning，最后得到的策略离最优策略还有比较大的差距。再考虑探索性更弱的，比如 $\varepsilon = 0.1$：几乎在每个状态它都有很大的概率向右走，所得到的数据更差，相应的最后策略也更差。还有一个策略虽然不是一直向右走，但 $\varepsilon$ 也比较小、探索性比较差，最后得到的策略同样有比较大的误差。

> **结论**：off-policy 给了我们把"采数据"和"学策略"分开的自由，但数据的质量仍然由 behavior policy 决定——探索性不足，再好的学习算法也救不回来。

### 万法归一：TD 算法的统一形式

这一节是对本讲所有 TD 算法的一个总结。你会发现，其实所有这些算法都非常相似。刚才介绍的所有 TD 算法，都可以用这样一个统一的表达式表达出来：

$$q_{t+1}(s_t, a_t) = q_t(s_t, a_t) - \alpha_t\Big[q_t(s_t, a_t) - \bar{q}_t\Big]$$

这里 $q_t(s_t, a_t)$ 是对 $(s_t, a_t)$ 这个 state-action pair 的 action value 的估计值；$\bar{q}_t$ 代表的就是 **TD target**。TD 算法的基本思路就是：让 $q_t$ 去接近 TD target——这也是为什么它叫 "TD target"，因为这个式子的作用就是让 $q_t$ 靠近它。它们俩之间的差距就叫 **TD error**：让 $q_t$ 接近 $\bar{q}_t$，目标自然就是减小 TD error。

那所有 TD 算法的不同点是什么呢？**它们只在 $\bar{q}_t$ 上不同**：

| 算法 | TD target $\bar{q}_t$ | 求解的公式 |
| :--- | :--- | :--- |
| Sarsa | $r_{t+1} + \gamma q_t(s_{t+1}, a_{t+1})$ | 贝尔曼公式 |
| n-step Sarsa | $r_{t+1} + \gamma r_{t+2} + \cdots + \gamma^{n-1} r_{t+n} + \gamma^{n} q_t(s_{t+n}, a_{t+n})$ | 贝尔曼公式 |
| Expected Sarsa | $r_{t+1} + \gamma \sum_a \pi(a \mid s_{t+1})\, q_t(s_{t+1}, a)$ | 贝尔曼公式 |
| Q-learning | $r_{t+1} + \gamma \max_a q_t(s_{t+1}, a)$ | 贝尔曼最优公式 |
| 蒙特卡洛 | $r_{t+1} + \gamma r_{t+2} + \cdots$（一整条 return） | action value 的定义 |

蒙特卡洛方法其实也可以用统一式子来代替：它的 TD target 就是 $r_{t+1} + \gamma r_{t+2} + \cdots$ 一直加到最后，没有 $q$ 项、全是 immediate reward——可以看成是 n-step Sarsa 的一个特殊情况。要把蒙特卡洛装进这个形式，只需把 $\alpha_t$ 设为 1：系数 1 就可以省略，式子里 $q_t$ 减 $q_t$ 两个就抵消掉了，最后的 $q_{t+1}$ 就直接等于 $\bar{q}_t$，也就是那条完整的 return。

除了统一的形式，它们在做的事情也可以统一地写出来：**都是在求解一些公式**——贝尔曼公式或者贝尔曼最优公式，相对应的算法就是求解这些公式的随机逼近（stochastic approximation）算法。比如 Sarsa 求解的是一个贝尔曼公式，当然这个贝尔曼公式和我们最开始介绍的不一样，因为它里面是用 action value 来表示的——这次课程我们其实介绍了很多贝尔曼公式的不同表达形式，它们实际上都是贝尔曼公式。现在大家可能也注意到了：**expectation 里边的那些东西，实际上就是对应算法里的 TD target**。需要强调的一点是：Q-learning 不是求解贝尔曼公式，而是求解贝尔曼最优公式，所以它是直接把最优的 $q$ value 求解出来，相对应得到的 policy 也就是最优的。

还有一点要强调：这些 TD 方法从本质上来说是求解**给定策略**的贝尔曼公式，那怎么让它搜索最优策略呢？其实就是把 policy evaluation 这一步和 policy improvement 相结合，就可以得到一个搜索最优策略的算法。蒙特卡洛方法其实求解的是那个最基本的式子——你可以说它是贝尔曼公式，实际上它是 action value 的最基本的定义。

### 全课回顾与下讲预告

最后做个小结，这个小结还是蛮重要的，希望大家回顾一下。我就顺着这章的脉络来讲：

- **motivating example** 那一节给了几个例子，把上节课学的 RM 算法应用来求解一些公式，所得到的算法和后面介绍的 TD 算法是非常类似的——那是全章的引子。
- 然后介绍了 **TD 算法**本身。这里有个说法上的提醒："TD 算法"有时候指本章所有的算法；但在那一节里，特指用来估计 state value 的那个算法。我们不仅给出了算法长什么样、它解决什么数学问题，还介绍了它很多基本性质——关于 TD 最基本思想的重要东西都在那一节，后面全部以它为基础，所以那一节非常重要。
- 之后过渡到 **Sarsa**。第一个感觉大家应该能感觉到：Sarsa 和 TD 算法从结构上来说基本上一模一样，只是把 state value 换成了 action value。在这一节里还介绍了很重要的东西：它不仅能做 policy evaluation，还可以和 policy improvement 相结合，实现最优策略的搜索。
- 在此基础上介绍了 Sarsa 的两个变形：**Expected Sarsa** 和 **n-step Sarsa**。n-step Sarsa 可以理解为变形，也可以理解为一种推广——它把 Sarsa 和蒙特卡洛统一了起来。
- 然后是 **Q-learning**。它和之前的区别就是：它在求解贝尔曼最优公式，直接求解 optimal action value。除了算法本身和它解决的数学问题——这两块我们只用两页就讲完了，因为前面奠定了非常好的基础——我们重点介绍了 **off-policy 和 on-policy**：Sarsa 和蒙特卡洛都是 on-policy，Q-learning 是 off-policy，我们也通过例子看了怎么用 off-policy 的 Q-learning 学出最优策略。

off-policy 这个性质是非常重要的。之后我们会学习 Deep Q-learning——为什么把神经网络和 TD 算法相结合的时候会选择 Q-learning 呢？Q-learning 的 off-policy 性质在其中发挥了非常重要的作用。

最后我还想强调一点：**所有这些算法都可以用一个统一的视角来看**。它们的表达式可以统一起来，唯一不同的就是 TD target；它们要解决的数学问题也可以统一起来——都是求解贝尔曼公式或贝尔曼最优公式的随机逼近算法。在这个意义上，TD 算法和我们之前介绍的值迭代、策略迭代其实就对应上了：值迭代和策略迭代是**基于模型**来求解贝尔曼公式和贝尔曼最优公式，现在我们是**没有模型**来求解同样的公式。

希望到此为止，大家对 TD learning 有了非常好的理解。下节课我们会进一步介绍 TD learning，但是会把这种基于表格的形式替换成基于函数的形式——到时候神经网络就会进来，最经典的 Deep Q-learning 也会登场。这次就是这样，我们下次再见。

### 表格表示的两个死穴

到目前为止，其实我们没有明说，但我们的 state value 和 action value **全部都假设是用表格的形式表达出来的**——不管是在贝尔曼公式还是之前的所有算法当中。

这个表格是什么意思？以 $q_\pi(s,a)$ 为例，它有两个索引：一个是 $s$，一个是 $a$，分别对应表格的横向和竖向，把 $q_\pi$ 的值填进去就是一个 q table。类似地，$v_\pi$ 对应的是一个一维的表格。编程的时候，我们实际上就是把这些表格重组成向量、矩阵或者数组。

用表格的好处是非常直观，分析起来也比较简单。但它的坏处很明显：**它没办法处理非常大的 state space 或 action space**，state space 是连续的时候表格显然更处理不了。有的同学可能会说，连续空间我可以用网格离散化——离散化总是存在问题：离散得很密，网格就太多，处理起来非常吃力；离散得很稀疏，又不能很好地近似那个连续空间。

还有一个问题就是**泛化能力**。所谓泛化能力就是：当你有很多 state-action pair，你必须全都访问到它们，才能估计出它们的值。但是数量太多了，不可能全部都访问到，那有很多状态你可能就估计不到它的值。

> **结论**：当 state space 或 action space 很大时，表格表示在**存储**和**泛化**两头都会出问题。函数近似引入之后，这两个问题就能被解决掉。

### 用一条曲线把离散的点串起来

下面通过一个例子介绍 value function approximation 的基本思想。

假设我们有 $n$ 个状态 $s_1, s_2, \dots, s_n$，$n$ 是 state space 里所有状态的个数。考虑最简单的情况：每个状态就是一条直线上的一个数值。每个状态 $s$ 又有一个 state value——如果图中的纵轴标的是 state value，那这些值就对应着一串**离散的圆点**。

现在的问题是：状态的个数非常非常多，要全部存储下来要花非常大的内存。那有没有可能，我用一条曲线把这些离散的点串起来，用这个曲线来代表这些点呢？为什么想用曲线？因为**曲线对应的参数个数是非常少的**——我只要存储比较少的参数，就能表示所有状态的 state value。

答案是肯定可以的。最简单的情况就是用一条直线来拟合这些点。直线的方程，如果横坐标是 $s$，就是 $as+b$，$a$ 和 $b$ 是两个参数。这个函数我用 $\hat v$ 来表示——$v$ 代表是对值的近似，hat 一般是代表估计的意思。

然后这个 $\hat v$ 是两个量的函数：第一个量是状态，第二个量是参数 $w$。$w$ 是怎么回事？我可以把 $as+b$ 写成两个向量相乘的形式：第一个向量包含 $s$，用 $\phi$ 表示；第二个向量包含参数，用 $w$ 表示。两个向量相乘显然还是得到 $as+b$，于是：

$$\hat v(s,w) = \phi^T(s)\,w$$

这里的 $w$ 叫 **parameter**（参数向量），$\phi$ 叫 **feature vector**（特征向量）。注意，在这个形式里，$\hat v$ 对 $w$ 是**线性**的关系。当然也可以成非线性关系，我们先从最简单的情况来考虑。

用这条直线拟合能带来什么好处？刚才用表格的形式，我们需要存储非常多个 state value；现在我们只要存储两个值就可以了——也就是 $w$ 对应的这两个值。为什么？我想找到 $v_\pi(s)$，现在手上有近似的 $\hat v(s,w)$：第一步，先计算 $\phi(s)$；第二步，把 $\phi^T(s)$ 乘以 $w$，就得到了 $\hat v$。所以我**只需要保存 $w$** 就行了，这极大地节省了内存。

但这个好处不是免费的，是有代价的：**近似不那么精确**。这些离散的点本来不是严格一条直线，你非要用一条直线去拟合，那在很多点上，估计出来的 $\hat v$ 和 $v_\pi(s)$ 还是有比较大的区别。这也是为什么这种方法叫 value function **approximation** 的原因——它是一种近似。

```text
  v_π(s) 真实值（离散点）          一条直线去拟合

  v │  ·        ·                 v │
    │     ·        ·                │        ___---···---___
    │  ·      ·                     │  · ---···   点偏离直线
    │     ·        ·  ·             │     ·        ·  ·
    └──────────────── s             └──────────────── s
      每个点都要单独存储              只存 w = (a, b) 两个参数
```

上图是这一步的核心画面：左边是表格表示——每个点都要单独存；右边是函数近似——存一条曲线（也就是 $w$），点与曲线之间的偏差就是"近似"的代价。

有同学说，直线拟合不准确，能不能用更高阶的曲线？答案当然是可以的。比如考虑二阶曲线：$\hat v = as^2 + bs + c$。它同样可以写成 $\phi^T(s)w$ 的形式，只不过这时 $\phi$ 和 $w$ 的维数增加了——意味着要存储更多的值，但拟合的精度有可能提高。

这里我还想提出一点：这时候这个函数对 $s$ 来说是一个**非线性**函数（有 $s^2$ 嘛），但它对参数 $a,b,c$ 来说**仍然是线性函数**——它的非线性都被放到了 feature vector 里边。所以针对 $w$ 来说，$\hat v$ 是线性的。当然我还可以用神经网络等来做一个非线性的拟合，那时 $\hat v$ 对 $w$ 来说就是非线性的了。

我们还可以继续增加曲线的阶数，用更复杂的曲线去拟合，好处是拟合得更准，坏处是需要更多的参数。

> **提示**：整条主线就是"参数多少"与"拟合精度"之间的权衡——这条权衡线会贯穿整个 value function approximation，包括后面的神经网络。

### 省内存是顺带的，泛化才是关键

把刚才几个例子总结一下。value function approximation 的 idea 其实很简单：**用一个带参数 $w$ 的函数去拟合 $v_\pi(s)$**，所以它被称为 parameterized function，$w$ 就是 parameter。

第一个好处是节省存储，前面已经说清楚了：本来要存非常多个 state value，现在只需要存 $w$，而 $w$ 的维数可能非常非常低。

第二个好处是泛化能力，我通过一个图给大家展示一下。假设 $s_1, s_2, s_3$ 是三个相邻的状态：

```text
   表格表示                         函数表示

   v                                v
   │  s1 ●                          │            ----/--  整条曲线抬了上去
   │                                │        ---
   │  s2 ● → ● (被更新)             │      /   s2 被访问，
   │                                │     │    更新的是 w，
   │  s3 ●                          │  s1 ●  s3 ●
   └──────────── s                  └──────────── s
   s1、s3 没被访问，值纹丝不动        s1、s3 没被访问，值也跟着变了
```

第一种情况用 table 的表达方式：最开始它们的值是这样，然后有一个 episode 访问到了 $s_2$，我就可以更新 $s_2$ 的 value，它跑到了新的位置。注意表格形式下，$s_1$ 和 $s_3$ **因为没被访问到，值保持不变**。

但如果用了函数，情况就变了。假设原来有一个函数（比如一条水平线），我访问了 $s_2$，发现它的值不应该是这个、应该是那个。改变的方式是什么？**我不是直接改变 $s_2$ 的值，我是改变 $w$**。$w$ 一变，整个函数就变了——它可能变成另一条曲线。于是虽然 $s_1$ 和 $s_3$ 没被访问到，但因为 $s_2$ 的更新改变了 $w$，$s_1$ 和 $s_3$ 的值**也跟着发生了变化**。

> **定义**：这就是泛化能力——不需要把所有状态全都访问到，只访问其中一些，相邻状态的值自然也能比较准确地被估计出来。这是 value function approximation 非常重要的一个优势。

### 目标函数：误差按什么权重平均

通过 motivating example，大家应该对 value function approximation 有了直观的理解，下面正式进入第二节。这一节在我们这次课当中非常重要，因为它揭示了方法的思想和很多概念细节；理解了它，后面第 3、4、5 个算法学起来就容易很多。

$v_\pi(s)$ 是真实的 state value，$\hat v$ 是它的估计值，我们的目标就是让估计值尽可能接近真值。当 $\hat v$ 的**结构**确定时——比如是直线、抛物线，或者某个确定结构的神经网络——剩下可以调节的就是 $w$。要做的就是找到最优的 $w$，使 $\hat v$ 尽可能接近 $v_\pi$。所以这个问题实际上就是一个 **policy evaluation** 的问题：你给我一个策略，我要找一个近似函数 $\hat v$ 尽可能接近它真实的 state value。之后我们再推广得到 action value，再推广得到怎么找最优策略——一步一步来。

怎么找最优的 $w$？两步：**第一步，把目标函数正式定义好；第二步，去优化它。**

目标函数是：

$$J(w) = \mathbb{E}\left[\left(v_\pi(s) - \hat v(s,w)\right)^2\right]$$

$w$ 是要优化的参数，expectation 后面是 state value **真值和估计值之间的误差**的平方。目标就是找到最优的 $w$ 去最小化它。

这里值得指出：$s$ 实际上是一个**随机变量**，随机变量一定有 probability distribution。那 $s$ 的概率分布是什么？换个角度问：expectation 本质上就是做 average，我对所有状态求平均——**这个平均应该怎么个平均法？** 这是一问的两问法。这个问题对很多初学者初次接触 value function approximation 时都比较迷惑，所以重点介绍一下。有两种方法。

#### 第一种：uniform distribution，大家一律平等

最直观、最容易想到的是 **uniform distribution（平均分布）**：把所有状态认为是 equally important，大家都是平等的，给每个人求平均时的权重都一样。一共 $n$ 个状态，每个人的权重就是 $1/n$。代入 expectation 的定义，把相同的概率提出来，就得到：

$$J(w) = \frac{1}{n}\sum_{i=1}^{n}\left(v_\pi(s_i) - \hat v(s_i,w)\right)^2$$

也就是**所有状态的估计误差的平方和，再求平均**。

虽然平均分布非常直观，但这里有一个问题：它假设所有状态平等、同等重要，**但实际上可能不是这么回事**。比如我的目标是从某一个状态出发到达目标状态，那目标状态和接近目标的那些状态其实是更重要的；相反，有些状态离目标非常非常远，就不太重要。我肯定希望给重要的状态更大的权重——更大的权重意味着什么？意味着它的估计误差会更小；不重要的状态权重小，即使误差比较大也没太大关系，反正我可能不会访问到它、或者很少访问到。

#### 第二种：stationary distribution，按被访问的概率加权

有了这个想法，就引入第二种概率分布：**stationary distribution**，这也是 value function approximation 方法实际使用的分布。它描述的是 **long-run behavior**：我从某一个状态出发，按照一个策略采取 action，不断地和环境交互，一直采取这个策略非常非常多次之后，就达到了一种**平稳的状态**——在那个平稳状态下，我可以告诉你 agent 在每一个状态出现的概率是多少。

用 $d_\pi$ 表示这个分布，$d_\pi(s)$ 就是在 $s$ 处的概率。它是概率分布，所以在每个 $s$ 上都大于等于 0，且总和等于 1。代入 expectation 的定义，目标函数写成：

$$J(w) = \sum_{s} d_\pi(s)\left(v_\pi(s) - \hat v(s,w)\right)^2$$

这里的 $d_\pi(s)$ 实际上扮演了**权重**的角色：某个状态的权重大，我就让它估计的误差更小。它还有一个含义：达到平稳状态之后，agent 出现在那个状态的概率、或者说那个状态被访问的概率。被访问的概率大，$d_\pi(s)$ 就大，就意味着我希望那个状态的估计误差比较小——这个逻辑是非常自然的。

> **定义**：stationary distribution 又称为 steady-state distribution 或 limiting distribution（极限分布，跑了非常多步之后的分布）。它在 value function approximation 这节课和下一节 policy gradient 当中都扮演非常重要的角色，特别是在定义 objective function 的时候就会出现它。

#### 一个例子：跑出来的平稳分布

下面通过一个例子来展示。这个例子有一个策略，它是一个**探索性的策略**：每一个 action 都有正的概率被选到，但也有比较大的概率选某一个特定的 action，所以它有一定的倾向——比如在某两个状态倾向向下、在某处倾向向右、在某处有比较大的概率保持原地不动。

我们让 agent 从一个状态出发，按照这个策略跑很多次。假设有一个非常长的 episode，它会访问每一个状态很多次。用 $n_\pi(s)$ 记状态 $s$ 被访问的次数，那么比值：

$$\frac{n_\pi(s)}{\text{episode 总步数}}$$

实际上可以来**近似 stationary distribution**。

我们跑一个 1000 步的 episode，横坐标是 episode 的步长，纵坐标就是上面这个比值。可以看到：访问不同状态得到的比值是不同的；开始的时候波动还比较大，但随着步数越来越多，**最后都趋向平稳**——所以什么叫 stationary、什么叫 long-run？就是跑很多次之后趋向平稳，每个比值都收敛到一个具体的值。

以最上面那条紫色的线（对应 $s_4$）为例：跑很多次之后，$s_4$ 被访问的次数除以整个 episode 的长度，最后趋向了一个比较大的比值。为什么它比较大？其实也容易理解：在每个状态，agent 都有比较大的概率选择某个特定的 action，而这些 action 刚好使得无论你从哪个点出发，都有比较大的概率跑到 $s_4$——所以跑了很多步之后，agent 在 $s_4$ 出现的概率比较大，大概等于 0.7。

> **提示**：其实不需要跑很多次，也能直接算出 $d_\pi(s)$——这就是图上那些星号（理论值）的含义。

$d_\pi(s)$ 满足这样一个式子：$d_\pi$ 是 $P_\pi$ **左边**的一个特征向量（eigenvector），对应的特征值（eigenvalue）等于 1。$P_\pi$ 是状态转移矩阵——大家还记得 $v_\pi = r_\pi + \gamma P_\pi v_\pi$ 吗？这是贝尔曼公式的 matrix-vector form，里面那个矩阵就是 $P_\pi$，每个元素代表 $s$ 到 $s'$ 的转移概率。具体到我们这个 2×2 的小例子，不难把 $P_\pi$ 写出来，然后计算它左特征值等于 1 的那个左特征向量——向量的每一个元素就分别对应每个状态在平稳状态下的概率。算出来 $s_4$ 对应的数值是 **0.72**，和刚才数值仿真跑出来的 0.7 基本一致。

stationary distribution 的内涵非常丰富，这里只是很快地介绍到这里，感兴趣可以到书里去看。

### 优化目标函数：梯度下降与两个替代

有了目标函数，下面去优化它。提到优化，我相信大家的第一反应应该是梯度方法——梯度下降或者梯度上升。这里是要 **minimize** 目标函数，所以用梯度下降。算法形式非常简单：

$$w_{k+1} = w_k - \alpha_k 
abla_w J(w_k)$$

那这个梯度究竟是什么呢？把目标函数的具体表达式代进去，把求梯度的符号移到 expectation 里边，再对 $(v_\pi(s)-\hat v(s,w))^2$ 求导——一个是误差项，一个是对 $\hat v$ 的梯度——稍微整理一下，把符号提到外边，就得到了**真实梯度（true gradient）**：

$$
abla_w J(w) = \mathbb{E}\left[\left(v_\pi(s) - \hat v(s,w)\right)
abla_w \hat v(s,w)\right]$$

但 true gradient 需要计算一个 expectation，实际当中怎么避免？很自然地，我们就想到用 **stochastic gradient（随机梯度）** 来代替 true gradient，相对应的算法是：

$$w_{t+1} = w_t + \alpha_t \left(v_\pi(s_t) - \hat v(s_t, w_t)\right)
abla_w \hat v(s_t, w_t)$$

就是把 expectation 去掉，把里面所有的 random variable 用采样 $s_t$ 代替。注意这里有个系数 2，实际上它和 $\alpha_k$ 合并到了一起，这样式子看起来更简洁。

到此为止，算法形式基本介绍完了——**但是只介绍了一半**。为什么？因为这里边涉及 $v_\pi(s_t)$，而我们不知道它——它恰恰是我们要**求**的数。所以这个算法在实际当中肯定是不能使用的。

不要慌，我们可以用其它的量来代替 $v_\pi(s_t)$。有两种方法：

**第一种：蒙特卡洛方法。** $v_\pi(s_t)$ 不知道，那就用 $g_t$ 来代替。$g_t$ 是什么？从 $s_t$ 出发有一个 episode，沿这个 episode 得到一系列 reward，把它们折现加起来得到的 discounted return 就是 $g_t$。用 $g_t$ 作为 $v_\pi(s_t)$ 的估计值——这不就是蒙特卡洛的基本思想吗？这样得到的算法，就是**蒙特卡洛 + value function approximation**。

**第二种：TD learning。** 我们前面介绍了两种 model-free 的方法，一个是蒙特卡洛，一个是 TD learning，所以很自然，第二个方法就是把 TD learning 和 value function approximation 相结合。具体来说，把 $v_\pi(s_t)$ 替换成 $r_{t+1} + \gamma \hat v(s_{t+1}, w_t)$——这就是它的 **TD target**；而 TD target 减去 $\hat v(s_t, w_t)$ 组合到一起，实际上就是它的 **TD error**。得到的算法就是：

$$w_{t+1} = w_t + \alpha_t \left[r_{t+1} + \gamma \hat v(s_{t+1}, w_t) - \hat v(s_t, w_t)\right]
abla_w \hat v(s_t, w_t)$$

这就是 **TD learning with value function approximation**。

这个算法的伪代码也给到了，其实没有什么好介绍的：对一个 episode，对里边的每一步，我们有一个 sample（$s_t$ 处的 reward、下一状态等），然后用这个 sample 去更新 $w$ 就可以了。它是一个梯度下降的算法，就可以去 minimize 前面那个 objective function。

> **提示**：这里我写的都是 in the general case——实际上还有一个 in the linear case。到现在我们还没讨论 $\hat v$ 应该怎么选，它有很多选择：线性的、非线性的等等。如果它是线性的，把 $\hat v$ 的具体表达式代进去，就得到 linear 情况下的算法——下面马上介绍。

到这里，优化的算法基本介绍完了，非常简单。想说的是：这个优化算法我们还是在做什么？**估计一个给定策略的 state value**。之后才会推广到估计 action value，再推广到怎么和 policy improvement 相结合，得到能搜索最优策略的算法。但不管怎么样，现在这个求解 state value 的算法非常关键，它能帮助我们理解 value function approximation 的核心思想。

### 函数近似器怎么选：线性与神经网络

多说几句 function approximator。要用一个函数 $\hat v$ 逼近 $v_\pi$，$\hat v$ 怎么选取？基本有两种方法。

**第一种是以前非常广泛使用的：线性函数。**

$$\hat v(s,w) = \phi^T(s)\,w$$

$\phi$ 是 feature vector，$w$ 是参数——motivating example 里直线和抛物线的例子就是它。$\hat v$ 是 $w$ 的线性函数，因为前面的 $\phi^T(s)$ 可以认为是系数。很重要的问题就是 **feature vector 怎么选取**——有多种选取方法，比如基于多项式的，motivating example 已经介绍了怎么基于多项式设计 feature vector，后面的例子还会给更多。

**第二种是目前非常广泛使用的：用神经网络来逼近。** 我不用知道这个神经网络的表达式，但是我可以输入一个 $s$，它就输出一个 $\hat v(s,w)$，参数就是 $w$。这个神经网络可以认为是 $w$ 的一个**非线性**函数。

#### 线性情况的算法：TD-Linear

如果 $\hat v$ 能写成 $\phi^T(s)w$，那它的梯度非常好算：

$$
abla_w \hat v(s,w) = \phi(s)$$

就是这个 feature vector 本身。把它代到刚才 TD + value function approximation 的算法里，得到：

$$w_{t+1} = w_t + \alpha_t \left[r_{t+1} + \gamma \phi^T(s_{t+1})w_t - \phi^T(s_t)w_t\right]\phi(s_t)$$

我们给这个算法起个名字，叫 **TD-Linear**。之后的例子里就会用它来展示 linear function approximation 的效果。

线性近似有什么优劣势？先说劣势：它最大的劣势是**需要选取合适的 feature vector**。这需要你对问题有非常好的理解，但很多时候即使理解很好，也很难选出鲁棒的、好的 feature vector。这也是 linear function approximation 慢慢被神经网络取代的一个重要原因——和传统机器学习被现在的深度学习取代的原因是类似的。

但它还是有两个好处。**第一，理论性质能被比较好地分析。** 如果用非线性的神经网络，理论性质基本就很难分析了。所以我们通常的做法——不仅仅在强化学习当中，很多领域都是这样——面对一个很难理解的问题，退而求其次，先理解一个稍微简单一点的问题；这个问题理解清楚了，能帮助理解更复杂的问题。过去对 linear function approximation 的研究非常多也比较透彻，理论结果也不少，课程里就不再展开。**第二，它有比较强的表征能力**——虽然不能近似实现所有的函数。

为什么说表征能力不弱？因为上一节课介绍的 tabular representation，实际上可以看成 linear function approximation 的一个**特殊情况**。在这个意义上，linear function approximation 把 tabular 和 value function approximation **统一**起来了。

#### 表格是线性近似的特例

怎么把表格装进线性框架？选取一个特殊的 feature vector：

$$\phi(s) = e_s$$

$e_s$ 是一个 one-hot 向量：所有分量全都是 0，只有对应 $s$ 位置的那一个量是 1。代到 $\hat v$ 里：

$$\hat v(s,w) = e_s^T w = w(s)$$

$w(s)$ 是向量 $w$ 当中对应 $s$ 位置的那个元素。所以这时候 $\hat v$ 就变成了一个向量、一个一维的表格——要找 $s$ 对应的 $\hat v$，直接去这个向量里查对应位置的值就行了。

再进一步，把 $\phi(s_t)=e_{s_t}$ 代到 TD-Linear 的更新式里，得到的算法和之前介绍的 tabular TD 算法**一模一样**。为什么？看更新式：$e_{s_t}$ 是一个向量，只有 $s_t$ 的位置等于 1、其它全是 0，所以 $w$ 当中**只有 $s_t$ 位置的元素被更新**，其它都没动。单独把 $s_t$ 那个元素拿出来，它的更新法则和之前的 tabular TD 完全一样——唯一的区别是之前算法里用 $v$、现在我们用 $w$，把 $w$ 换成 $v$ 就变回之前的算法了。

> **结论**：tabular TD 算法 = TD-Linear 取 one-hot feature vector 的特例。表格表示并没有消失，它只是函数近似这个大框架里的一个成员。

### 用平面和曲面拟合 grid-world 的 state value

下面给出几个直观的例子，帮助大家理解前面的思想。这些例子非常直观、有代表性。

仍然考虑 grid-world example：5×5 的网格，一共 25 个状态。给定一个策略（用箭头表示），它是一个**探索性的策略**：每个状态对 5 个 action 都有相同的概率 0.2。我们要做的，就是**估计这个策略对应的 state value**——每个状态都要算出来。这本质上是一个 policy evaluation 的问题。如果用基于表格的方法，肯定要存储 25 个 state value；下面用 TD-Linear 来算，大家会看到用比较少的参数，也能比较好地近似这 25 个 state value。

#### 先看 ground truth，再看拟合目标

state value 的真值可以先用基于模型、求解贝尔曼公式的方法得到，之后再用 TD-Linear 去比较，看它是不是真的能把 state value 很好地求出来。

这里非常重要也非常直观的一个工具是：**把二维的表格画成三维的曲面**。三维曲面的横轴、纵轴对应表格的行和列。比如曲面上最低的一个点，对应网格里的 $(1,5)$，它的值是 $-4.5$——这也是整个 state value 里最小的值。

所以 TD-Linear 的基本思想就是：我们要得到一个函数，函数对应一个曲面，**这个曲面和真实 state value 那个复杂曲面越接近越好**。这是一个最基本的 idea。为了实现这个目标，我们需要数据——我们没有模型，我们需要数据。这里的数据是：一共 **500 个 episode，每个 episode 有 500 步**，每个 episode 的出发 state-action pair 是随机选择的、服从均匀分布。

#### 基准：tabular TD 先跑一遍

首先用这些数据、用之前所学的 tabular TD algorithm（简称 TD table）算一下。它得到的最后 state value 绘出来的曲面，和刚才的真实三维曲面**非常接近**；从误差曲线也能看到，随着 episode 越用越多——直到 500 个——state value 估计的误差逐渐减小到 0。

#### 第一次尝试：用一个平面去拟合

用 TD-Linear 的第一步是建立 feature vector。思路就是我刚才说的：要建立一个函数，函数对应一个曲面。函数对应的曲面**最简单的情况就是平面**，所以我们选：

$$\phi(s) = [1,\ x,\ y]^T$$

这样 $\hat v(s,w) = \phi^T(s)w = w_1 + w_2 x + w_3 y$，显然在三维空间当中是一个平面，$w_1, w_2, w_3$ 是它的参数。（feature vector 里元素的顺序是可以调整的，没有关系。）

把刚才的 feature vector 代入 TD-Linear，跑出来的结果是这样的：**趋势是对的**——左边都是比较小的值，右边都是比较大的值；但在很多具体的点上，state value 的估计并不准确，最后虽然收敛了，收敛的误差**不是 0**。为什么？其实非常简单：真实的是一个很复杂的曲面，我现在就想用一个平面去拟合，那怎么可能百分之百拟合到呢？只能找到一个**最优的平面**，把这个拟合做到最好。

#### 升级：二次曲面、三次曲面

想拟合得更好，就不能再用平面了，要用更复杂的高阶曲面——对应的 feature vector 阶数更高、需要更多的 $w$ 参数。答案是肯定可以这么做的。选择：

$$\phi(s) = [1,\ x,\ y,\ x^2,\ y^2,\ xy]^T$$

相比刚才引入了 $x,y$ 的二次项，对应的 $\hat v$ 在三维空间里是一个二次曲面，可以设想它能比平面更好地拟合那个复杂的真实曲面。还可以进一步增加 feature vector 的维数和参数个数，比如把 $x,y$ 的三次方也放进来，对应一个三次曲面，拟合能力更强。

| 特征向量阶数 | 对应曲面 | 拟合效果 |
| :--- | :--- | :--- |
| $[1, x, y]$ | 平面 | 趋势正确，很多点不准，收敛误差不为 0 |
| $[1, x, y, x^2, y^2, xy]$ | 二次曲面 | 趋势正确，有些地方比平面更好 |
| 再加入 $x^3, y^3$ | 三次曲面 | 肉眼上看已和真实曲面非常接近，收敛误差也比较小 |

二次曲面拟合的结果：趋势也是正确的，并且有一些地方比刚才拟合得更好，比如那个最小的点。如果用三次曲面，拟合出来的效果更好——你肉眼上看，它和真实的 state value 曲面已经非常接近了；从具体数值上看，最后收敛的误差也比较小。

#### 参数不是越多越好

通过这几个例子，大家对 value function approximation 的思想应该有更好的理解了。大家也看到，基本上**用更多的参数就能得到更好的拟合效果**。但这里有一个 tradeoff：参数的个数不能很多——如果很多的话，最后就和 tabular 的情况没有什么区别了。

而且在 linear 的情况下，也**并不意味着不断增加参数个数就能把拟合误差减小到 0**。为什么？因为它毕竟还是一个线性函数，函数的结构已经在那里了，即使再增加参数也是不一定的。这也是为什么现在我们广泛使用神经网络的一个原因：**神经网络从理论上来说，可以近似任何一个非线性的函数**。

关于这些例子更多的解释、更多的例子以及 feature vector 的选择，可以到书里去看。

### 故事线很好懂，但数学上不严谨

最后对这一系列内容做一个小结。我们把 value function approximation 的基本思想捋一下——整个故事的故事线是这样的：

```text
  (1) 目标函数            J(w) = E[ (v_π(s) - v̂(s,w))^2 ]
        │                 真实值与估计值之差的平方、加权平均
        ▼
  (2) 梯度下降            w_{k+1} = w_k - α_k ∇_w J(w_k)
        │                 展开成随机梯度后：
        ▼
  (3) 问题出现            梯度里有 v_π(s_t) —— 我们不知道它！
        │
        ▼
  (4) 做替换              用 TD target 代替 v_π(s_t)：
                          r_{t+1} + γ v̂(s_{t+1}, w_t)
        │
        ▼
  (5) 得到算法            TD learning + value function approximation
                          （linear 情况就是 TD-Linear）
```

读图说明：从目标函数出发，用梯度下降优化；梯度里的真值 $v_\pi$ 不知道，就换成 TD target，于是得到了我们最终的算法——这条故事线非常直观，容易理解思路。

但我想说：**这个故事在数学上是不严谨的**。为什么？因为第 (4) 步那个替换，在数学上可能是有问题的。严格来说——我们稍后用几页的内容简要地说一下——基本的结论是：这个算法实际上**并不是在 minimize 这个 objective function，而是在 minimize 另外一个**。

那为什么我还用这个故事来讲？因为如果不用这个故事讲，这个问题就复杂了去了：要么直接给出算法，要么直接给出那个真正的目标函数，它们都是非常复杂的。所以对学习这门课的同学来说，一般了解这个故事线就行了；如果你特别感兴趣，再到书里去看理论方面的分析，那部分内容是比较丰富的。

#### 三个目标函数：从 squared error 到 projected Bellman error

我们快速过一下。实际上有多种 objective function。

**第一个**就是我们刚才给出来的，可以写成简洁的向量形式：

$$J(w) = \left\| \hat v - v_\pi \right\|_D^2$$

向量 $\hat v$ 和 $v_\pi$ 的每一个分量对应每一个状态，双竖线是向量求模，右下角的 $D$ 代表一个权重——$\|x\|_D^2 = x^T D x$，$D$ 的对角线元素就是 $s$ 所对应的分布，也就是那个 $d_\pi$。总而言之，这就是我们之前给出的 objective function。

**第二个**叫 **Bellman error**。我不是希望 $\hat v$ 逼近 $v_\pi$ 吗？$v_\pi$ 满足贝尔曼公式 $v_\pi = r_\pi + \gamma P_\pi v_\pi$；如果 $\hat v = v_\pi$，那 $\hat v$ 也应该满足 $\hat v = r_\pi + \gamma P_\pi \hat v$——这个右端可以写成一个算子 $T_\pi(\hat v)$。理论上来说两边应该相等，但实际当中它可能不相等。不相等，我就去 minimize 这个 error，得到的就是 Bellman error：

$$\left\| \hat v - T_\pi(\hat v) \right\|_D^2$$

**第三个**叫 **projected Bellman error**——这才是刚才那个算法真正要去 minimize 的量。它和 Bellman error 是一样的部分，只是多了一个投影矩阵（projection matrix）。这是什么意思？$\hat v$ 和 $v_\pi$ 这两个量可能**永远也不相等**——因为你使用的函数可能由于结构的原因，无法完全逼近 $v_\pi$。比如那个函数是一个平面，正如我们刚才例子当中所说的，永远无法逼近那个复杂曲面。那我可以把这个量乘以一个投影矩阵，投影到什么空间上去呢？投影到 "$\hat v$ 随 $w$ 改变所能组成的那个空间"上去——这时候这个 error 就可能等于 0 了，最优值可以是 0。

> **结论**：点到为止就是这样——我们介绍的 TD-Linear 算法，它实际上是在 minimize **projected Bellman error**，而不是最初那个 squared objective function。感兴趣的话，可以到书里去看更多的理论分析。

至此，value function approximation 的基本思想就介绍完了。下次课我们走出基于值的世界，去看基于策略的方法。

## 值函数近似落地：Sarsa、Q-learning 与 Deep Q-learning
> 对应块：BLK11 | 覆盖分集：P41-P45 | 块标题（分集名）：《第8课-值函数近似（Sarsa和Q-learni》

上一节的内容说实话还是比较多的——看一看 PPT 的页数你会发现，虽然只介绍了一节，赛程已经过半。这一节我们讲了 value function approximation：它的目标函数、它的算法、它的思想，还给出了比较多的例子，我相信大家现在已经有比较好的理解了。

接下来要介绍的三、四、五这三节是在干嘛？第二节其实主要在讲**思想**：给你一个策略 $\pi$，估计它的 state value。往下走，Sarsa 这一部分我们要估计的是 **action value**；Q-learning 和 Deep Q-learning 要估计的则是 **optimal action value**。把这条线记住，后面每一个算法在干什么，一眼就能定位。

| 算法 | 与值函数近似结合后估计什么 |
| :--- | :--- |
| 前一节的 TD 方法 | 一个策略的 state value $v_\pi$ |
| Sarsa | 一个策略的 action value $q_\pi$ |
| Q-learning / Deep Q-learning | 最优 action value $q^*$ |

### Sarsa 与值函数近似的结合

话不多说，直接上算法。Sarsa 和 value function approximation 相结合之后的算法是：

$$
w_{t+1}=w_t+\alpha_t\big[r_{t+1}+\gamma\,\hat q(s_{t+1},a_{t+1};w_t)-\hat q(s_t,a_t;w_t)\big]
abla_w\hat q(s_t,a_t;w_t)
$$

和刚才的 TD 算法是一模一样的——只不过我把刚才的 $v$ 换成了 $q$：刚才是 $\hat v(s_t)$，现在换成了 $\hat q(s_t,a_t)$，后面还带着参数 $w$。这个算法为什么设计成这个样子、它在干什么样的事情，这里就不需要再介绍了，因为第二节已经非常详细地介绍过了。

下面给出它的伪代码。值得指出的是，刚才那个算法实际上还只是在做 **policy evaluation**——你给我一个策略 $\pi$，我能估计出它的 action value。接下来我们把它和 **policy improvement** 相结合，这样就能够去搜索最优的策略。对每一个 episode，只要当前的状态 $s_t$ 还不是 target state，就做下面几步：

```text
① 生成数据：在 s_t 按 ε-greedy 策略选 a_t，与环境交互得到 r_{t+1}, s_{t+1}；
   再在 s_{t+1} 按当前策略确定 a_{t+1}
② value update：用上面的 Sarsa 更新式——注意更新的不是 q̂(s_t,a_t) 本身，
   而是它的参数 w
③ policy update：计算 s_t 处各 action 的 q value，给最大的那个较大的概率，
   其它 action 较小的概率（ε-greedy）
```

> **易错点**：我们并不是直接更新 $\hat q(s_t,a_t)$ 这个函数值，而是更新它的**参数** $w$。这是和之前 tabular 的 Sarsa 唯一的区别。

还有一个细节要注意：在之前 tabular 的情况下，要比较各 action 的 q 值，直接**索引**表格就可以；现在不行了，得把 $s$ 和对应的每个 $a$ 逐个代进函数里**算一遍函数值**，然后再做比较。

我们来看一个例子，把 Sarsa 和 linear function approximation 相结合，也就是 $\hat q=\varphi^T w$；具体的仿真参数可以到书里去看。任务还是那一个：从一个状态出发，到达目标状态。结果正如我们所料——沿着概率大的方向走，确实能到达目标状态；其它一些状态的策略不是很好，也没有关系，因为我们的目的**不是**找到所有状态、所有 action 的最优策略。左边可以看到收敛过程：最开始 reward 比较负，慢慢逐渐增大；最开始 episode 的长度也比较长，因为策略不好、要走很多弯路，最后长度逐渐减短并收敛。

刚刚这部分大家可能注意到了，非常短，只有 3 页。为什么？因为前面已经给我们打好了非常好的基础，所以这里不需要介绍过多的东西。

### Q-learning 与值函数近似的结合

同样地也是非常快。这个算法和刚才的 Sarsa 非常类似，唯一的区别就在这里：刚才没有这个 maximization，而且那个 $a$ 刚才是 $a_{t+1}$，现在 TD target 变成了

$$
r_{t+1}+\gamma\max_{a\in\mathcal A}\hat q(s_{t+1},a;w_t)
$$

如果大家对 tabular Q-learning 熟悉的话也知道，这一部分实际上就是它的 TD target。

伪代码上值得指出的是：我们先给一个 **on-policy** 的版本，后面介绍 Deep Q-learning 的时候再特意给一个 **off-policy** 的版本。因为 Q-learning 两者都可以——既可以 on-policy 也可以 off-policy——所以把这两个算法错开，大家就可以明白 on-policy 和 off-policy 分别应该怎么样去实现。流程和 Sarsa 那边一致：搜集 sample（在 $s_t$ 按当前策略 $\pi_t$ 得到 $a_t$，交互观察 $r_{t+1}, s_{t+1}$），然后更新**参数** $w$，最后用 ε-greedy 更新策略——把不同的 $a_t$ 代进去算 q value，哪个大给大概率，哪个不是最大就给小概率。

例子同样是 Q-learning 和 linear function approximation 相结合（$\hat q=\varphi^T w$），任务还是从起点找到到达目标的好路径。最后的策略也比较好；收敛过程上，最开始 reward 比较负，很快就收敛到比较大的值，episode length 开始因为策略不好比较长，慢慢地也很快收敛到比较短的正确路径上去。

### Deep Q-learning：为什么还需要一个新算法

下面我们就来到了 Deep Q-learning，非常经典的一个算法。这个算法的介绍是**可咸可淡**的——什么意思呢？我可以介绍得比较简单一点，给出算法你该怎么用就完了；但这里我会做比较细致的介绍，包括里边有很多的技巧、为什么要用这些技巧、这些技巧究竟在干什么，还是会非常有意思的，希望大家能够静下心来学一下。

Deep Q-learning 又被称为 DQN（Deep Q-network），DQN 是原论文当中就是这么叫的；Deep Q-learning 也是非常广泛使用的一种叫法。我们称其为 Deep Q-learning，是因为想突出**它是 Q-learning 的一个变种**。它是最早的、也是最成功的一个把深度神经网络引入到强化学习的算法——当然"最早"要打个折扣，因为在它之前已经有人把神经网络引入强化学习，但是并不那么成功。它取得成功主要在两个点上：**应用上**，它在一系列游戏的控制上达到了人类控制的水平；**方法上**，它使用了一些关键技术，这些技术在后面很多方法当中也被广泛地使用。神经网络在这里扮演的角色，从本质上来说，就是一个 nonlinear function。

在介绍之前我想先澄清一个问题。有的同学可能会说：刚才不是已经介绍了 Q-learning with function approximation 吗？为什么不能用那个算法，还要再介绍一个 Deep Q-learning？原因是这样：你画一个神经网络，输入 $s$ 和 $a$，参数是 $w$，输出 $\hat q$——用那个式子确实也可以。但这时候我需要对神经网络进行**非常底层的运算**：我要手动计算出它的梯度，然后直接对它的参数进行赋值修改。而现在神经网络的工具包已经非常成熟了，对我们很多人而言它就是一个**黑盒**——你把数据送进去，它能够选择非常合适的参数和非常底层的算法去做很好的训练。所以从这个角度来说，我们不再用那么底层的方法来做，而是用接下来介绍的 Deep Q-learning 的方法。

#### 目标函数从哪里来

要训练神经网络，我就需要一个 loss function，或者叫 objective function，这里对应的就是 $J(w)$。它是这样一个期望的平方：

$$
J(w)=\mathbb{E}\Big[\big(R_{t+1}+\gamma\max_{a}\hat q(S_{t+1},a;w)-\hat q(S_t,A_t;w)\big)^2\Big]
$$

这个式子如果大家对 Q-learning 比较熟悉的话不会陌生，因为括号里就是 **Q-learning 的 TD error**。而这个 TD target 实际上就对应了 **Bellman optimality error**。为什么这么说？Bellman optimality equation 的左边是 $q(s,a)$，右边是 $R_{t+1}$ 加上后面那一项——这是上一节课介绍基于表格的 Q-learning 时已经提到的：Q-learning 实际上就是在求解这样一个 Bellman optimality equation。那么式子两边在 expectation 的意义上应该相等，所以这个 error 在达到最优时应该等于 0。这就是我们为什么选择这样一个 loss function。

#### 梯度计算的技巧：把一个 w 变成两个网络

有了 objective function，下面就要优化。用什么方法？我相信大家的第一反应都应该是 gradient descent。但这里面有一个问题：怎么样去计算这个 objective 的 gradient？这个还是有一点 tricky 的，也是 Deep Q-learning 一个重点的贡献。

注意这里面有**两个地方含有 $w$**：一边有一个 $w$，另一边也有一个 $w$。对前一个 $w$ 计算梯度相对简单，就是对 $\hat q$ 求梯度；后一个就比较复杂了。Deep Q-learning 的做法是：把整个 TD target 那一项记作 $y$，$y$ 里边虽然包含 $w$，但我**假设 $y$ 里的 $w$ 是一个常数**——这时候 $J(w)$ 实际上就只是 $w$ 的一个函数了，求它的梯度就会相对简单。这就是它的基本思想。

为了实现这个技巧，Deep Q-learning 引入了**两个 network**（network 在这里就对应 function）：

- 第一个叫 **main network**，参数是 $w$，它一直在被更新——有新的采样进来 $w$ 就会更新；
- 第二个叫 **target network**，参数是 $w_T$，下标 T 代表 target。它**不是**一直更新的，而是隔一段时间之后，把 main network 的 $w$ 赋值过来。

有了两个网络，把目标函数里的 $q$ 和 $q$ 区分开，优化时的逻辑就是：先假设 $w_T$ 固定不动，计算对 $w$ 的梯度，然后去优化 $J$。有的同学可能会说：那这显然是不对的呀，本来那边是 $w$，你把它固定不动，那显然是错误的。但这里面的逻辑是这样的：我先假设有一个 $w_T$ 保持不动，然后去更新 $w$，更新一段时间得到新的 $w$（main network）；再用这个 main network 的参数去赋值给 $w_T$；然后基于新的 $w_T$ 保持不动，再继续更新 $w$。这样交替进行下去，最后 $w_T$ 和 $w$ 都能够收敛到最优的值。

基于这个 objective function 可以算出它的 gradient：**只有关于 main network 那一个 $\hat q$ 的梯度，target network 一侧的 $\hat q$ 就没有梯度了**——因为它被当作了常数。

```text
replay buffer ──均匀采样──▶ (s,a) ──▶ main network：   q̂(s,a;w)    （每次训练都更新）
      │
      └──(s',·)──▶ target network：y_T = r + γ max_a q̂(s',a;w_T) （隔一段时间由 w 赋值）

(y_T − q̂) ──▶ loss ──▶ 梯度只回传到 main network 的 w，不穿过 target network
```

读图：main network 负责被训练，target network 负责提供"固定的"目标 $y_T$；梯度只对 main network 求取，target network 的参数每隔一段时间从 main network 复制过来，如此交替。

#### 经验回放：是什么

除了使用两个网络的技巧，还有一个很重要的技巧，就是 **experience replay（经验回放）**。下面要回答两个问题：第一，经验回放**是什么**；第二，经验回放**为什么**——为什么要使用它。

我们在收集数据、收集 experience sample 的时候，一定是有**先后顺序**的；但是我们在使用这些 sample 的时候，不一定要按照它们的先后顺序——不是说谁先来就先使用谁。怎么使用呢？把所有数据全放到一个集合里，集合里每一个元素就是一个 experience sample：

$$
(s,a,r,s')
$$

即从 $s$ 出发 take action $a$，得到的 reward 是 $r$，跳到的下一个状态是 $s'$。这个集合有一个名字，叫做 **replay buffer**。

> **定义**：replay buffer 就是存放历史 experience sample 的集合；训练时不按时序使用，而是把它们全混到一起，从集合中拿一些样品出来训练——经验已经在那了，再把它用一次，这不就叫"回放"吗？

拿的时候要注意：一定要服从一个 **uniform distribution（均匀分布）**，也就是里边每一个数据点被拿到的概率应该相同。为什么必须要均匀分布？答案要依靠 objective function 来回答。

#### 经验回放：为什么必须、为什么要均匀采样

在这个 objective function 当中有几个随机变量：$R$、$S'$、$S$ 和 $A$。要对这些随机变量求 expectation，我需要知道它们的**分布**。$R$ 和 $S'$ 好办：当 $S$ 和 $A$ 给定了之后，它们服从系统的模型，这不需要过多讨论。关键在 $S$ 和 $A$ 上。

注意我们把 $(S,A)$ 当成一个**索引**、当成**一个**随机变量。什么意思呢？比如说我有 $n$ 个状态，每个状态有 5 个 action，那么每一个"状态-动作"组合怎么索引？我就可以用 $(s,a)$ 来索引，对应"哪个状态的哪个 action"。这就好像二维平面上的一个点：虽然它是一个点，但它对应了两个坐标 $x$、$y$。所以 $(S,A)$ 组成了一个随机变量，它要服从一个分布 $d$。

我们假设这个分布是**均匀分布**。有的同学可能会问：为什么要均匀分布呢？其它的分布行不行？比如高斯分布，我想给一些 $(S,A)$ 更大的权重、采样的时候更多次地用到它们？可以是可以，但问题在于：那样你就需要有**先验知识**——你要知道谁是重要的、谁不是重要的。如果你没有这个先验知识，那就要**一视同仁**，所有 $(S,A)$ 对应的概率都相同，这时候就是均匀分布。

现在问题就来了：数学上要求 $(S,A)$ 是均匀分布，但是我采集数据的时候它一定是有先后顺序的，并且是按照其它的概率分布采集的，这该怎么办呢？其实非常简单：我就不按照先后顺序使用就行了。用 experience replay 的方法，把所有的 sample 拿到一起打散，然后从里边**均匀地**采样——这样我就可以**打破不同 sample 之间的 correlation**。这就是为什么 experience replay 是必须的、为什么我们要进行均匀采样的数学原因。

#### 回看表格版 Q-learning：三个连环的问题

刚刚介绍了 experience replay 的技巧，下面不着急，我们再回顾一下之前学的基于表格的 Q-learning：那里边有没有 experience replay？下面会问几个问题，如果这几个问题你都能比较好地回答，说明你对 Q-learning——无论是 tabular 的形式还是基于 function 的形式——都有比较好的理解。

**第一个问题**：tabular Q-learning 当中是没有 experience replay 的，这很显然，我们之前没提过。为什么之前不需要，现在和值函数近似相结合却需要了呢？答案很简单：因为之前根本就没有涉及到 $(s,a)$ 的 **distribution**。只有当你要求它按照一定的 distribution 分布（比如均匀分布）的时候，我才需要把它打散再均匀采样；没有这个分布的要求，我肯定就不需要这么做了。

**第二个问题**紧接着就来：那为什么 Deep Q-learning 就会涉及到 $(s,a)$ 的 distribution，而 tabular Q-learning 就没有呢？答案在于**它们究竟在干嘛**——你要明白它们在干嘛。Deep Q-learning 当然是 value function approximation 的方法，这一大类方法都是在做 **optimization**：它要有一个 scalar 的 objective function，然后去做优化。这个 objective function 是一个 expectation，里边会涉及到很多东西，其中就包括 $(S,A)$——所以你要求解这个目标函数，里边肯定就要涉及到 $(S,A)$ 的分布，这个分布就出来了。相反，基于表格的 Q-learning 或者 TD 算法为什么不会有？因为它们在干嘛呢？tabular Q-learning 是在求解 **Bellman 最优公式**——对每一个 $(s,a)$ 都有一个式子，组成这一组式子，然后把它给求出来，就得到了最优的 action value。正是因为它们在做**不同的事情**，Deep Q-learning 才会涉及到 distribution，而 tabular 就不会。

**第三个问题**：虽然 experience replay 对 tabular Q-learning 不是必须的，那它**能不能用**呢？答案是可以的——即使你是基于表格的也可以这么用。为什么？因为 tabular Q-learning 也是 **off-policy** 的算法：off-policy 就是我不管你之前的策略是什么、你怎么得到这些数据的，你可以按时序按 episode 这样得到，也可以跳来跳去，都无所谓；反正你给我什么 $(s,a)$，我就去更新那个 $(s,a)$ 所对应的 q 就可以了。而且这么做还有好处：experience replay 可以让你的 sample 更加 **efficient**。为什么？因为你在 replay buffer 当中均匀采样，同一个 sample 是可能被采到很多次的，这样就可以充分地重复利用；而之前的 tabular Q-learning 是按时序来的，用完一次之前的经验就全丢掉了，在一定程度上是浪费的。

> **提示**：回想起我们之前 tabular Q-learning 的仿真例子，它一个 episode 要跑 10 万步。实际上根本不需要这么多步——只需要每一个 state-action pair **能被访问到**就可以了。因为那是确定性的环境，访问很多次和访问一次没什么太大区别（如果是 stochastic 的环境那是另当别论）。你只要能访问一次，然后可以反复用这一次的经验就行。

这几个问题介绍到这，我相信还是比较 tricky 的。我希望你能够明白；明白之后，你对 TD 算法还有 value function approximation 算法的理解会更加深刻。

### Deep Q-learning 的伪代码：off-policy 版本

思想和关键技术都有了，下面过一遍 Deep Q-learning 的 pseudocode。注意这个 pseudocode 是 **off-policy** 的版本——之前介绍 Q-learning 和 value function approximation 相结合（特别是 linear function）的时候，我们给的是 on-policy 的版本；为了区别开来，这里给 off-policy 的。当然 Deep Q-learning 也可以是 on-policy，因为这是 Q-learning，两者都可以。

因为它是 off-policy，我们假设已经有了一个策略 $\pi_b$——**behavior policy**，它产生了很多的 sample，把这些 sample 放到一个集合当中，也就是 replay buffer。然后每一个 iteration 做下面的事情：

```text
每一个 iteration：
    ① 从 replay buffer 当中随机地、均匀地采样一批 experience
    ② 对采样做进一步处理：用 target network 计算出 y_T
       （网络输入是 s 和 a，输出是 q̂；我期望的输出是 y_T，
         我希望 q̂ 能和 y_T 接近）
    ③ 把输入 (s,a) 和希望的输出 y_T 这一批数据全部送到
       神经网络里训练一次，更新 main network 的参数 w
    ④ 更新 w 达到 C 次之后，把 w 的值赋给 w_T（更新 target network）

如此循环往复，就构成了整个算法的 loop。
```

#### 几点澄清

**第一，为什么这里没有 policy update？** 为什么只是在做 value update？其实很简单，因为我们这里是 off-policy 的。如果是 on-policy，那你后面要加上一条：做 policy 的 update，然后在下一个 iteration 当中，你的新策略要去生成数据。但现在因为已经有数据了（由 behavior policy 提供），所以不需要这么做。当然你也可以非要在后面加上一条去更新策略，但那个策略是没用的——你完全可以在所有的 q 全部计算完之后，一次性地只计算一次 policy，就得到了最优的 policy。

**第二，为什么不用之前推导的那个梯度更新式？** 我们之前其实给了一个 policy update equation，还记得吗？就是有一个目标函数、里面有两个 $w$，固定一个 $w$ 求另一个 $w$ 的梯度，我们计算出来了一个梯度。为什么不用那个梯度？原因很简单，和最开始介绍 Q-learning 时提到的问题一样：那个算法是比较**底层**的，它可以指导我们去生成现在的这个算法，但我们要遵循神经网络现在**批量训练**的黑盒特性，去更好地、高效地训练神经网络。

**第三，我们的网络和 DQN 原文不一样，不要恐慌。** 我们这里网络的 input 和 output 与 DQN 原文是不一样的；而且印象里原文是 on-policy 的，我们这里给的是 off-policy 的。你明白了算法本质之后，其实可以做很多的修改，不用担心"我修改了，这个算法是不是就不灵了"。这正是我们要学习算法本质的一个很重要的目的：你深刻地理解了算法，你就可以去做修改、去做推广、去做创新。

具体到网络结构上的区别：

```text
本讲的简化版网络：  s,a ──▶ 网络 ──▶ q̂(s,a)
                                     （要比较 5 个 action 需要前向 5 次）

DQN 原文的网络：    s   ──▶ 网络 ──▶ q̂(s,a1), ..., q̂(s,a5)
                                     （一次前向直接拿到全部）
```

读图：两者都是在给定 $s$ 的情况下，要计算出它所对应的 5 个 action 的 q 值，然后在里边找最大值。用我们的简化版网络，需要固定 $s$，把 $a_1$ 送进去跑一次得到 $\hat q(s,a_1)$，再把 $a_2,a_3,a_4,a_5$ 全都送进去——要跑 5 次，得到结果之后再去求哪一个最大。而原文当中的神经网络在计算上更高效：输入 $s$，直接得到了这 5 个 $a$ 所对应的 q，不需要跑 5 次，立刻就能找到哪一个 q 是最大的。当然，原文的网络更高效，但也需要更多的训练技巧。

### 用例子检验 DQN：1000 步就够了吗

下面就用刚才的 pseudocode 跑几个例子看效果。这次的**任务**和之前不一样了：需要找到**所有** state-action pair 所对应的 optimal action value——注意这里不是说我从一个特定的状态出发、找到一个好路径到目标就行，而是所有的 state-action pair 都要估计出来。最优的 action value 估计出来之后，optimal greedy policy 立刻就能得到了。

问题的设置有几点：第一，这个仿真当中我们**只用了一个 episode** 来训练 Deep Q-learning，这个 episode 是由一个探索性的 behavior policy 得到的——待会大家会看到，这个策略就是对每一个 action 给的概率都是 0.2，全都相同。第二，这个 episode 只有 **1000 步**，相对来说数据量是比较少的——我们之前介绍 tabular Q-learning 的时候，那个例子也是一个 episode 但跑了 **10 万步**，现在只有它的 1%。我们看一看 Deep Q-learning 能不能用这么少的数据就得到相同的结果。第三，这里的神经网络是一个**浅层**神经网络：虽然叫 Deep Q-learning，但实际上做函数拟合的时候很多时候根本不需要是深的——这里只有 3 层，一个输入层、一个输出层、中间一个隐藏层，隐藏层只有 100 个 neuron。更多关于 minibatch 大小等等的细节可以到书里去看。

结果如何？用这个 behavior policy 从起点出发跑 1000 步，得到的这个 episode 里，基本上**所有的 state-action pair 全都被访问到了**——虽然有的访问多、有的访问少（如果继续加到 10 万步，就像之前 tabular case 一样每个 pair 都能访问很多次，但这里没有关系）。把数据送到刚才的 pseudocode 当中，最后输出的策略就是**最优**的策略。

再看收敛过程。横轴是 iteration 的 index：第一张图，纵轴是 TD error 或者 loss function，可以看到最后收敛到 0；第二张图，纵轴是 state value error——因为我们是知道 ground truth 的，可以用其它方法求解出这种设定下最优的 action value 或 state value，然后和 Deep Q-learning 每步给出来的 value 比较——可以看到最后也收敛到 0 了。

所以通过这个例子我想表达的意思是：我们**只需要很少的数据量，就可以得到相同的结果**。这是为什么呢？第一，基于 value function approximation 的方法本身就具有比较强的**泛化能力**，这我们之前已经提过了；第二，我们这里还用了 **experience replay**，经验会被反复用到，效率会比较高。

#### 故意挑战它：只给 100 步

我们再看一个例子。这个例子是什么？是我们**故意**要去 challenge 这个 Deep Q-learning：刚才 1000 步就可以了吗？那现在只给 100 步，看看还能不能给我们满意的结果。

同样是这个 behavior policy，如果它只跑 100 步，得到的轨迹其实是非常不理想的，因为很多的 state-action pair 都没有被访问到。那不出意外，用这样的数据去训练，最后得到的策略也是很差的一个策略。

如果我们看收敛过程，有一个非常值得注意的现象：首先对于 TD error 还有 loss function，**它是收敛了的**。但是这个收敛了，**并不代表**最后所得到的结果就是正确的——因为你只是让神经网络去逼近你给它的这些输入和输出，它总是能做到这一点的；但它很好地逼近了这些 sample，并不代表最后的结果就是理想的。从另一张图也能比较清晰地看到：横轴是 iteration，纵轴是 state value——虽然最后的 state value 也收敛了，但是 **error 没有收敛到 0**。

> **易错点**：loss 收敛 $ \neq $ 结果正确。神经网络总能拟合你喂给它的数据；数据本身覆盖不到的地方，拟合得再好也是错的。

通过这个例子我想告诉大家：再强大的算法，你得有好的数据；没有好的数据还是不行的，正所谓**巧妇难为无米之炊**。

### 策略梯度：把策略也从表格换成函数

各位同学，欢迎回来。这是我们的第 9 次课，这次要介绍非常重要的 **policy gradient** 方法。看课程的地图，经过长途跋涉我们已经来到了第九次课、第九章，基本上接近课程的尾声了。虽说快到最后了，但并不意味着内容不重要——恰恰相反，内容是越来越重要。为什么？因为 policy gradient 的方法，以及下节课要介绍的 actor-critic 方法，是现在最流行的、相对来说性能也比较好的方法。

这节课和上节课的关系是什么？上次课我们介绍了 value function approximation：action value 或者 state value，之前是用表格形式表达，现在可以用函数的形式来表达。这次课的思想有点类似：之前我们是用表格来表达**策略**，现在我们也可以用**函数**来表达策略。从上节课到这节课有一个跳跃：之前所有的方法都被称为 **value-based**，这次课以及下次课的方法都是 **policy-based**。什么意思呢？所谓 value-based，就是以 value 为核心——比如我估计一个策略的 action value，这是 policy evaluation；在这个基础上我选择更好的策略，再去采样，不断地迭代循环，这个过程中 value 发挥了非常重要的作用。而 policy-based 方法是**直接建立一个目标函数**，这个目标函数就是策略的一个函数，我通过优化这个目标函数就可以直接得到最优的策略。可以预告一下，下次课的 actor-critic 实际上是把 policy gradient 和基于 value function approximation 的这两种方法给结合起来，大家可以关注一下。

这次课的大纲是这样的：首先介绍 policy gradient 基本的思路——其实它的基本思路非常简单。先定义一个 **metric**，这个 metric 可以定义什么样的策略是最优的；有了 metric 之后就去做优化，最简单的方法就是**梯度上升**——要最大化这个 metric 那就梯度上升，要最小化就梯度下降；为了应用梯度的方法，首先要计算出来 metric 所对应的梯度是什么。之后给出梯度上升的方法，其中涉及一些技巧，我们会给出一个比较特别的、叫 **REINFORCE** 的算法——它是非常早期的 policy gradient 方法，但是非常经典；在此基础之上可以推广得到很多其它的、现在最流行的方法。

#### 函数形式的策略长什么样

到目前为止，其实我们所有的策略全都是用**表格**来表示的：有一些状态，每一个状态对应一行；有一些 action，每一个 action 对应一列。我想知道某一个状态下 take action $a_3$ 的概率是多少，直接去表格当中就能找到。表格的基本操作还是比较简单的：想访问一个量、或者想改变一个量，直接通过索引就可以实现。

下面我们把表格改成函数，这时候 $\pi$ 的写法也发生了改变：

$$
\pi(a\mid s,\theta)
$$

和之前很类似，唯一的就是后面多了一个 $\theta$——它是一个向量，用来表示 $\pi$ 这个函数里边的**参数**。现在用的最广泛的函数形式实际上就是**神经网络**：一个神经网络，参数是 $\theta$，输入是 $s$，输出是对应所有的 action 的概率，比如 $\pi(a_1\mid s,\theta)$ 一直到 $\pi(a_5\mid s,\theta)$——假如我有 5 个 action 的话。注意之前介绍 value function approximation 当中，value function 的参数我们用 $w$ 来表示；而 policy 这个函数的参数，我们用 $\theta$ 来表示。

用函数代替表格的好处，其实和之前介绍 value function approximation 是类似的：比如 state space 非常大、甚至状态是连续变化的（有无穷多个），这时候表格形式就比较乏力了，体现在**存储**上（要存非常多的数值），还有**泛化能力**上也不如函数形式。这里稍微说一下泛化是怎么回事：比如我要更新 $\pi(a\mid s)$，如果用表格的话，我必须**访问到** $s$ 和 $a$ 才能更新它；但如果用函数的话就不需要——我访问了 $(s,a)$ **旁边**的那个 $(s,a)$，因为改了那个点的数据，函数的参数也变了，会导致我现在感兴趣的这个 $(s,a)$ 也被更改掉。这就意味着我用更少的访问和数据，就能得到一个比较好的效果——这就是泛化能力，上节课介绍 value function approximation 的时候也介绍过。另外，$\pi$ 的写法其实可以有多种：你可以把竖线去掉，或者把 $\theta$ 放到下标上去，等等，都可以。

#### 表格与函数的三个基本不同点

用表格和函数来表示策略，区别是什么呢？基本上有 3 点。

**第一点：怎么定义一个最优的策略。** 如果用表格来表示策略，大家还记得最优策略的定义是什么吗？假如最优的策略是 $\pi^*$，那么它所对应的 state value 必须大于等于任何其它策略 $\pi$ 的 state value：

$$
v_{\pi^*}(s)\ge v_{\pi}(s),\qquad \forall\, \pi
$$

也就是 $\pi^*$ 的 state value 要比其它所有策略的 state value 都大。这是表格情况下最优策略的定义。如果是在函数情况下就会不同：这时候我们会定义一个 **scalar metric**、一个标量的目标函数，然后我们去优化这个目标函数。总而言之，它们因为对最优策略的**定义**不同，也会导致很多细节上不同。

**第二点：怎么获取一个 action 的 probability。** 用表格形式的话，我想知道在 $s$ take action $a$ 的概率，直接查表就可以了，非常简单。现在其实也很简单，只不过稍微麻烦一点：我不能直接去索引了，因为不是一个表格，我得**算一下**——比如它是神经网络，我得把 $s$ 输进去让它向前传播一次，得到 $\pi(a_1\mid s,\theta)$ 等等 $\pi(a_5\mid s,\theta)$，这样我才能得到它的概率是多少。

**第三点：怎么 update 一个策略。** 这一点和第二点比较类似。用表格的话，之前说过，$\pi(a\mid s)$ 我想改变它的值，直接去表格里面改变就可以了，非常直截了当。但用函数形式就不能这么做了：函数是用一个 $\theta$ 来表示的，你希望改变 $\pi(a\mid s)$，**不能直接赋值**了，只能通过一定的规则去改变 $\theta$，**间接地**改变 $\pi(a\mid s)$。

#### 基本思路：一个目标函数加一步梯度上升

下面简要地概述一下 policy gradient 的基本思路。第一个，我们需要有一个目标函数来定义最优的策略，这里就取 $J(\theta)$ 作为目标函数——具体它是什么，后面会详细地介绍。$\theta$ 就是策略所对应的参数：不同的策略、不同的参数，也就有不同的 $J(\theta)$ 值。我希望 $J(\theta)$ 能够被**最大化**，所对应的 $\theta$ 比如说是 $\theta^*$，它应该就是 $\max J(\theta)$ 的解。

有了目标函数之后就可以做优化，最简单的优化算法就是基于梯度的方法：

$$
\theta_{t+1}=\theta_t+\alpha\,
abla J(\theta_t)
$$

所以整个的思路其实非常非常简单。但是会有比较复杂的东西出现，出现在什么地方呢？第一个，我**怎么取这个目标函数**——你会发现这里面还是有一些学问的；第二个，我**怎么求解这个目标函数所对应的 gradient**——到时候大家就会知道一个非常著名的定理，叫 **policy gradient**（策略梯度定理），这里面也会有比较复杂的地方。这些所有的东西，这节课都会进行详细的介绍。
