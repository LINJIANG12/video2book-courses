# 强化学习的数学原理（54 讲）

一门把强化学习「数学这条线」讲透的完结课：不追算法框架的繁杂全家桶，而是沿「贝尔曼公式 → 动态规划 → 蒙特卡洛与时序差分 → 值函数近似 → 策略梯度与 Actor-Critic」的推导链路，从问题设定一路推到深度强化学习。每个概念都从公式出发讲清「为什么这样定义、为什么这样更新」，适合想打牢数学基础、看懂原始论文的学习者，也适合作为 RL 实战课之前的理论前置。

- **全 54 集**，已产出 3 册模块全书、5 篇复习笔记、13 份逐字稿

## 怎么学

- **贝尔曼公式是全课的「一」** → 笔记 01-02 把问题设定、贝尔曼期望/最优公式与动态规划（值迭代、策略迭代）讲透，后面所有算法都是「在不知道模型时近似地解同一个公式」
- **无模型方法抓「估计什么、怎么估计」** → 笔记 03 把蒙特卡洛与时序差分对比着学：偏与方差的取舍、on/off-policy、SARSA 与 Q-learning 的更新式差异
- **函数近似是通往深度的桥** → 笔记 04 讲线性近似到 Deep Q-learning，目标网络与经验回放的动机要和「不稳定性」绑在一起理解
- **策略方法按梯度推** → 笔记 05 从策略梯度定理推到 REINFORCE 再到 Actor-Critic，方差缩减（baseline、advantage）是推导主线
