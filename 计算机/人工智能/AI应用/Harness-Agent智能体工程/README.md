# Harness-Agent 新一代智能体工程（六层核心拆解与 LangChain 实战）

《Harness-Agent 新一代智能体工程》课程的完整整编版。课程提出并系统讲解 Harness 工程（给智能体套上缰绳的工程化方法）：以六层核心架构（上下文精细化、工具系统、执行编排、记忆状态、约束恢复、评估观测）为主线，配合两个落地项目实战；另附一整套 LangChain 补习篇，从模型调用一路讲到 RAG、数据库整合与结构化数据，适合想从「会调大模型」进阶到「会做智能体工程」的开发者。

## 怎么学

- **总论打底** → 先读第 1 篇笔记建立 Harness 工程与六层架构的整体认知
- **六层逐层啃** → 上下文精细化、工具/编排/记忆、约束恢复、评估观测各配一篇速查笔记
- **工程落地** → 主课的两个落地项目与高并发方案是面试与实战的重点
- **LangChain 补习** → 零基础从第 5 篇笔记入门，RAG、数据库、结构化数据按需查阅
