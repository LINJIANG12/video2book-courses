## 怎么学

课程主线遵循现代大模型应用工程的构建脉络：**底座接入与调用模式 → 可观测性与提示词工具 → 结构化输出与智能体 → 中间件拦截与持久记忆 → RAG 向量检索与知识库落地**。建议：

- **系统通读技术全景** → `textbooks/` 从卷一顺读到卷五，每册开头有导读、结尾有技术总结，成体系打牢底层概念
- **掌握统一模型调用与可观测性** → 重点研读模块 01 与 02，熟悉 `init_chat_model` 跨平台统一抽象与 LangSmith 生产级链路追踪
- **攻克智能体与工具调度闭环** → 重点研读模块 03，掌握 `@tool` 装饰器、Pydantic 参数校验与 Agent 自主调度闭环链路
- **中间件治理与持久化长期记忆** → 重点研读模块 04，掌握重试/脱敏/限流中间件、Node-style 钩子函数与基于 PostgreSQL 的记忆管理
- **RAG 检索增强与 Milvus 知识库落地** → 重点研读模块 05，打通文档切分加载、嵌入向量化与智能客服助手的端到端落地
- **考前/面试速查与架构复盘** → 直接查阅 `notes/` 目录下的 5 篇速查笔记，知识拓扑树支持直接导出为脑图
