# 20 种 Agentic AI 设计模式实战课

中英双语讲解的 Agentic AI 设计模式实战课。全课整编为一册，把 20 种智能体设计模式按「基础协作 → 进阶编排 → 生产级架构」的顺序串成一条线：既讲每种模式解决什么问题、何时该用，也讲韧性、限流、可观测性与成本控制等真正上线后才会遇到的工程问题。

- **原视频**：https://www.bilibili.com/video/BV1JGEB6WEss — Bilibili，BV1JGEB6WEss
- **22 集**，已产出 1 册模块全书、1 篇复习笔记、2 份逐字稿

## 怎么学

- **先看全景** → 从「导读与全景目录」入手，20 种模式先建立整体地图，再决定深挖哪几种
- **按需选模式** → 按协作、规划、工具使用、多智能体分工等场景对号入座，不必按顺序通读
- **盯住工程约束** → 「生产级韧性与控制架构」一节是本课区别于模式罗列的地方，务必细读
- **双语对照** → 术语中英并列出现，做笔记时保留英文原词，便于查英文文献与框架文档
