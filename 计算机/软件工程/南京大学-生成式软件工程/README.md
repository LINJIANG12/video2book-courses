## 怎么学

- **先建立新的能力坐标** → 从模块 01 前两章读起，弄懂「把会做事交给 AI」意味着什么、自己该把功夫花在哪
- **攻克上下文工程** → 提示词只是入口，真正的难点是注意力预算、上下文窗口与人机协作的边界
- **落到工程实践** → 需求挖掘与架构设计的完整来路，以真实演化作结
- **速查复盘** → 直接查阅 `notes/` 目录下的复习笔记
