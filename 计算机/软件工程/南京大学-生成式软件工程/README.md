## 怎么学

课程主线打通了现代 AI 编程辅助工具到底层计算机科学工程哲学的脉络：**编程范式变革与 Agent 生态 → 上下文机理与 Prompt 工程 → 现代 Git 仓库哲学与多智能体协作 → 软件工程演进与第一性原理**。建议：

- **理解 AI 时代工程师角色蜕变** → 重点研读模块 01，掌握从手写逐行代码到「带着 AI 做 AI 做不到的事」的核心能力迁移，以及 agent 生态的能力边界
- **攻克大模型上下文工程与计算本质** → 重点研读模块 02，吃透指令遵循、注意力机制、上下文污染与长期任务背后的工程陷阱
- **吃透现代软件仓库与版本控制哲学** → 重点研读模块 03，理解从「一个目录到 Git」的项目级时光回溯、快照与对象模型，以及 worktree 到悲观锁的 agent 时代版本管理
- **建立软件工程全局历史观** → 重点研读模块 04，从实时决策模型到 1968 年软件危机的诞生，再到瀑布、契约与 UML 攒下的智慧，把握对抗系统复杂度的终极武器
- **考前/面试速查与架构复盘** → 直接查阅 `notes/` 目录下的 4 篇速查笔记
