# 笔记05 移动端适配与优医问诊H5项目实战
## 视口与像素体系


### 视口三态与meta声明

* **布局视口（Layout Viewport）**
    * > **定义**：浏览器用来排版的画布宽度，默认980像素。
    * 未声明视口时按980像素排版再压缩进手机屏幕，字号细小且可横向晃动。
* **视觉视口（Visual Viewport）**
    * > **定义**：用户眼睛实际看到的区域宽度，即手机屏幕的CSS宽度，如375像素。
    * 未声明视口时视觉视口小于布局视口，页面呈现缩略全景形态。
* **理想视口（Ideal Viewport）与视口标签**
    * > **定义**：布局视口等于设备宽度的状态，一屏显示一屏内容。
    * 声明固定写法，`width=device-width`使布局视口等于设备宽度，`initial-scale=1.0`使初始缩放为1。
    * 标签必须放在`head`内，所有移动端页面先写该行再写其他代码。
    * 登录页在此基础上追加`maximum-scale=1.0`与`user-scalable=no`，禁止双指缩放顶错表单。
    * > **易错点**：页面发虚变形先查该行是否漏写，漏写则后续适配单位全部立不住。
    ```html
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    ```
    ```html
    <meta name="viewport" content="width=device-width, initial-scale=1.0, maximum-scale=1.0, user-scalable=no">
    ```
* **视口验证规则**
    * 加标签后页面顶满屏幕宽度，横向纹丝不动，纵向正常滚动。
    * 调试方法为`F12`切换设备工具栏，分别拨到375像素与320像素观察是否等比且无横向滚动条。

### 像素换算与设计稿取值

* **物理像素（Physical Pixel）**
    * > **定义**：屏幕硬件上真实存在的发光点，出厂定死。
    * iPhone 6横向750个发光点，物理分辨率宽度为750。
* **CSS像素（CSS Pixel）**
    * > **定义**：浏览器排版用的逻辑单位，`width:375px`即375个逻辑格子。
    * 标准PC显示器上一个逻辑格子对应一个发光点，手机上一个逻辑格子对应多个发光点。
* **设备像素比（Device Pixel Ratio，DPR）**
    * > **定义**：物理像素除以CSS像素的比值，描述屏幕细腻程度。
    * $$DPR = 物理像素 / CSS像素$$
    * iPhone 6/7/8横向750对应375，DPR为2；Plus系列横向1242对应414，DPR为3。
    * 二倍屏上1个CSS像素由2×2共4个物理像素渲染。
    *     ```text
    *     CSS像素1格由4发光点拼成
    *     +-----+-----+
    *     | 发光 | 发光 |
    *     +-----+-----+
    *     | 发光 | 发光 |
    *     +-----+-----+
    *     ```
* **二倍图（Retina Image）与一像素线**
    * 显示100逻辑像素宽的图片准备200物理像素宽的图，三倍屏准备300宽，大图小用。
    * 切图按原尺寸切，显示时收进一半宽度的盒子，二倍图自然成立。
    * `1px`边框在二倍屏实际占2个发光点，视觉偏粗，极致做法用媒体查询或`transform:scale(0.5)`压细。
* **设计稿基准（375逻辑宽度）**
    * 设计稿按750物理像素绘制，前端按375逻辑像素书写，中间差DPR等于2。
    * 375为iPhone 6/7/8逻辑宽度，覆盖320至430偏差较小，为国内移动端主流基准。
    * 实操规则为750稿量出数值除以二写入代码，量出按钮宽200写`width:100px`，量出字号32写`font-size:16px`。
    * 本项目首页设计稿宽度直接取375，插件视口宽度同样取375，两边对齐转换才成立。
    * > **易错点**：750数值直接写入代码则页面大一倍，每次量完先确认是否除以二。

## 视口单位与插件换算


### vw换算与插件翻译

* **视口宽度单位（Viewport Width，vw）**
    * > **定义**：将视口宽度等分为100份，`1vw`等于视口宽度的1%，像素值随视口自动伸缩。
    * 375宽手机上`1vw`等于3.75像素，414宽手机上`1vw`等于4.14像素。
    * $$目标vw = 设计稿px / 设计稿基准 * 100$$
    * 375基准下100像素宽按钮为`100/375*100=26.67vw`，320小屏自动算成85像素，430大屏自动算成115像素，占屏比例一致。
    * 宽高统一用vw计算，不宽用vw高用vh，否则横竖比例变化时图形被压扁。
* **视口高度单位（Viewport Height，vh）**
    * > **定义**：将视口高度等分为100份，`1vh`等于视口高度的1%。
    * `100vh`用于铺满一屏高度。
* **px转vw插件（PostCSS px to viewport）**
    * 作用为照常写px，保存时自动翻译成vw，属忠实翻译，不改属性名与注释。
    * 安装后将视口基准宽度`viewportWidth`改为375，转换精度保留2至4位小数。
    * 校验式为`1px=100/375vw≈0.2667vw`，`37.5px=10vw`，`12px=3.2vw`。
    * 日常流程为750稿量出数值除以二得CSS像素，照常写px并保存，插件自动转vw。
    * 宽高、间距、字号自动转vw；`1px`边框线靠最小转换阈值保留不转；`transform`位移按需决定是否转换。
    * 颜色、渐变角度、背景图路径一概不转，只转尺寸数值。
    * > **易错点**：基准配成750则算出vw小一半，页面整体缩水；忘记先除以二则插件忠实译出大一倍的vw，页面撑爆。
    ```css
    /* 手写 */
    .btn {
      width: 100px;
      height: 44px;
      font-size: 16px;
    }
    /* 保存后自动翻译 */
    .btn {
      width: 26.67vw;
      height: 11.73vw;
      font-size: 4.27vw;
    }
    ```
* **头部vw转换校验值**
    * 标题字号`20px`转为`5.3333vw`，搜索框高`38px`转为`10.1333vw`，左右内边距`12px`转为`3.2vw`，图标`24px`转为`6.4vw`。
    * 头部容器`padding:15px 12px 40px`转换后为`4vw 3.2vw 10.6667vw`量级。
    * `line-height:1`为无单位值，插件不触碰；转为`0.2667vw`的边框需警觉是否会渲染消失。

### 短边单位与长边单位

* **视口最小单位（Viewport Minimum，vmin）**
    * > **定义**：取视口宽高中较小者的百分之一，`1vmin`等于短边百分之一。
    * $$1vmin = min(1vw, 1vh)$$
    * 竖屏375×667时`100vmin`等于375，横屏667×375时`100vmin`仍等于375，恒跟短边。
    * `width:80vmin;height:80vmin`为横竖屏完整显示的正方形写法，启动页大圆与二维码占位适用。
    * `font-size:5vmin`使字号跟短边走，横竖屏观感一致。
    ```css
    .box {
      width: 80vmin;
      height: 80vmin;
      background-color: #16c2a3;
    }
    .title {
      font-size: 5vmin;
    }
    ```
* **视口最大单位（Viewport Maximum，vmax）**
    * > **定义**：取视口宽高中较大者的百分之一，`1vmax`等于长边百分之一。
    * $$1vmax = max(1vw, 1vh)$$
    * 竖屏375×667时`100vmax`等于667，横屏667×375时`100vmax`仍等于667，恒跟长边。
    * 适用于横竖屏铺满的大背景与大气装饰，短边方向配合`object-fit:cover`裁剪。
* **四单位对照**
    * 参照物永远是整个视口，不是父元素，小盒写`50vmin`大于父盒属正常现象。
    * 桌面端拖窄窗口时较小者由宽度切换为高度，尺寸跳动属跟随短边的正常表现。

    | 单位 | 基准 | 横竖屏翻转时 | 典型用途 |
    | :--- | :--- | :--- | :--- |
    | `vw` | 视口宽 | 基准跟宽度变 | 常规移动端适配 |
    | `vh` | 视口高 | 基准跟高度变 | 首屏高度 |
    | `vmin` | 短边 | 恒为短边 | 正方形、字号、圆 |
    | `vmax` | 长边 | 恒为长边 | 全屏背景、大装饰 |

## 根字号单位与脚本插件适配


### 相对单位基准

* **相对根元素字号单位（Root Em，rem）**
    * > **定义**：以文档根元素`html`的`font-size`为基准的相对单位，`1rem`等于根字号像素值。
    * 浏览器默认根字号16像素，未设置时`1rem`等于16像素，`0.875rem`等于14像素。
    * `width:10rem`在根16像素下等于160像素，全站只乘一次。
    ```css
    html {
      font-size: 16px;
    }
    .card {
      width: 10rem;
      font-size: 0.875rem;
    }
    ```
* **相对父元素字号单位（Em，em）**
    * > **定义**：以父元素字号为基准的相对单位，逐层累乘。
    * `body16px`下`p2em`等于32像素，其内`span2em`等于64像素，嵌套三层字号失控。
    * 整站适配用rem，em只留给首行缩进类局部场景。
    * > **易错点**：改父级字号则em全变而rem不动，卡片嵌套误用em导致字越套越大。
    *     ```text
    *     em累乘 vs rem只乘一次
    *     body16px -> p2em=32px -> span2em=64px
    *     html16px -> 任意处2rem=32px
    *     ```
* **等比缩放推导（750稿分10份）**
    * $$根字号 = 视口宽 / 划分份数$$
    * 750稿分10份，每份75像素；375宽手机根字号37.5像素，750宽屏根字号75像素。
    * 全站按根字号书写rem，稿上150像素按钮除以75得`2rem`，375手机下算出75像素，正好为稿子一半，比例一致。
    *     ```text
    *     750稿根75px -> 按钮150px=2rem
    *     375屏根37.5px -> 2rem=75px等比
    *     ```

### 动态脚本与换算插件

* **动态根字号脚本（Flexible Script）**
    * 核心动作为取`document.documentElement.clientWidth`，除以10，写回`html`行内`font-size`。
    * 页面进入先调一次防首屏闪默认值，再监听`resize`事件，横竖屏翻转与窗口拖动重算。
    * 除数10为团队约定，750稿下`1rem`等于75像素，心算方便；统一全站即可，7.5亦可。
    * 平板桌面1200宽时根字号过大，需封顶，超过750按750计算。
    * 登录页`flexible.js`必须在样式之前引入，否则先按默认字号闪一下再缩放。
    * 登录页配套版本须与375稿十等分对应，误用750旧版则全部错半拍。
    ```js
    function setRootFont() {
      const width = document.documentElement.clientWidth;
      const fontSize = width / 10;
      document.documentElement.style.fontSize = fontSize + 'px';
    }
    setRootFont();
    window.addEventListener('resize', setRootFont);
    ```
    ```js
    function setRootFont() {
      let width = document.documentElement.clientWidth;
      if (width > 750) width = 750;
      document.documentElement.style.fontSize = width / 10 + 'px';
    }
    ```
* **px转rem插件（PostCSS pxtorem）**
    * 源码照写px，编译产物自动带rem，源码可读性不变。
    * 安装命令为`npm install postcss-pxtorem --save-dev`，配置`postcss.config.js`。
    * `rootValue:75`必须与750除以10对齐，375稿则填37.5；`propList:['*']`表示全部属性参与换算。
    * 375登录页插件基准填37.5，`37.5px=1rem`，`44px=1.1733rem`，`16px=0.4267rem`。
    * 行内样式与`1px`细线不进换算，`minPixelValue`设为2或选择器黑名单`['.no-rem']`可保住细线，大屏下细线变粗属失配。
    * 校验标准为源码`width:150px`编译为`width:2rem`，375屏根37.5算出75像素即闭环。
    * VS Code类插件验证法为`login.css`手写`width:37.5px`保存，自动变`width:1rem`即配置正确。
    ```js
    module.exports = {
      plugins: {
        'postcss-pxtorem': {
          rootValue: 75,
          propList: ['*']
        }
      }
    };
    ```
    ```bash
    npm install postcss-pxtorem --save-dev
    ```

    | 参数 | 含义 | 常用值 |
    | :--- | :--- | :--- |
    | `rootValue` | `1rem`对应像素数 | 750稿填75，375稿填37.5 |
    | `propList` | 参与换算属性 | `['*']`全换 |
    | `selectorBlackList` | 不换算选择器 | `['.no-rem']`排除特定类 |

* **vw与rem选型对照**

    | 对比项 | vw方案 | rem方案 |
    | :--- | :--- | :--- |
    | 基准 | 视口本身 | 根字号 |
    | 换算 | `px/视口宽×100vw` | `px/根字号 rem` |
    | 适配手段 | 无需脚本 | 需脚本或媒体查询改根字号 |
    | 适用场景 | 纯移动端新项目 | 需兼容老机型、老项目 |

    * 首页用vw，登录页新开`login.html`练rem，两套插件基准与脚本隔离，不混用于同一页面。

## 首页头部与图标导航实现


### 工程准备与渐变头部

* **首页五块自顶向下骨架**
    * 顺序固定为头部问诊区、图标导航区、轮播横幅区、问诊选项卡区、底部固定切换栏。
    * 电商社交外卖移动页同属顶栏加内容加底栏骨架。
    *     ```text
    *     首页自顶向下
    *     home-header渐变绿+搜索框
    *     nav两行每行5入口
    *     banner轮播图
    *     tabs极速问诊/预约门诊
    *     tabbar首页/问诊/我的
    *     ```
* **项目目录与初始化**
    * 根目录只放`index.html`、`css/base.css`、`css/index.css`、`images/`静态修饰图、`uploads/`业务图，皮肤与数据隔离。
    * `base.css`完成清默认边距、统一`box-sizing:border-box`、设默认字体与浅灰底`#f6f7f9`、清列表符与链接下划线、图片垂直居中。
    * `box-sizing:border-box`为保命设置，vw下再让内边距外撑则320小屏必溢出。
    * 素材拷入后先用`img`逐张引用验证路径，路径问题越早暴露越好。
    *     ```text
    *     youyiwenzhen/
    *       index.html
    *       css/base.css + index.css
    *       images/皮肤 + uploads/业务图
    *     ```
    ```css
    * {
      margin: 0;
      padding: 0;

    }
    body {
      font-family: "PingFang SC", "Microsoft YaHei", sans-serif;

      list-style: none;

      text-decoration: none;
      color: inherit;
    ```

* **头部容器与渐变（Linear Gradient）**
    * 头部分三层为问候标题行、白色圆角搜索框、底部延伸的绿色渐变背景，先搭容器再填内容。
    * 渐变写在容器上，保证标题行与搜索框压住同一片连贯过渡，自上而下由`#2edf9e`至`#22c484`。
    * 底部内边距取`40px`，多留部分供导航白色卡片上浮覆盖，形成压界层次。
    * 容器写法为`background:linear-gradient(180deg,#2edf9e 0%,#22c484 100%)`配`padding:15px 12px 40px`。
    ```html
    <header class="home-header">
      <div class="title">
        <h1>优医问诊</h1>
        <a href="#" class="msg"></a>
      </div>
      <div class="search">
        <i></i>
        <span>搜医院、医生、疾病</span>
      </div>
    </header>
    ```
    ```css
    .home-header {
      background: linear-gradient(180deg, #2edf9e 0%, #22c484 100%);
      padding: 15px 12px 40px;
    }
    ```
* **标题行弹性布局（Flexbox）**
    * `display:flex`配`justify-content:space-between`与`align-items:center`实现左右两端对齐与垂直居中。
    * `h1`为整站唯一门面，字号`20px`白色加粗；消息图标`24px`见方，背景图`center/contain`完整呈现。
    * 背景简写斜杠前为位置后为尺寸，丢斜杠则`contain`被解析为重复方式，图消失。
    ```css
    .home-header .title {

      justify-content: space-between;
      align-items: center;

    .home-header .title h1 {
      font-size: 20px;
    ```

* **胶囊搜索框**
    * 白色长条高`38px`，圆角`19px`取高度一半即胶囊形，移动端搜索框按钮标签通用。

### 导航卡片与两行复用

* **上浮白色卡片**
    * 白色圆角卡片用负边距上浮压住头部绿色，`margin:-20px 12px 0`配`border-radius:10px`与`box-shadow:0 2px 8px rgba(0,0,0,0.06)`。
    * 负值只吃头部多留绿段，不盖搜索框；若盖住则头部留白须大于上浮负值。
    * 先留后压为卡片式常规配合，顺序不可反。
    *     ```text
    *     侧视: 绿头留白 -> 白卡负边距上浮覆盖
    *     上半压绿底 + 下半落灰底 = 焦点线
    *     ```
* **导航语义与五等分**
    * 导航用`ul`包5个`li`，`li`内`a`上图标下文字，图标`img`直引，文字`p`或`span`全站统一。
    * 一行5入口用容器`display:flex`，`li{flex:1}`自动均分，320至375等比变窄且内容居中。
    * `a`内部转纵向`flex-direction:column`配`align-items:center`，图标`48px`见方，文字`12px #333`配`margin-top:6px`。
    * 格子间不加`gap`与左右margin，均分格加内容居中即天然均匀，不出现末项掉行。

    ```css
    .banner {
      padding: 10px 11px 0;
    ```

    * `img`为行内替换元素，底部默认一条基线空隙，图片下多出几像素白边。
    * 通解为`vertical-align:middle`或转块级`display:block`，logo独占行与图标行通用。

### 横滑选项卡三选型

* **选项卡骨架（Tabs）**
    * 总容器`.tabs`下切换栏`.tabs-head`与内容区`.tabs-content`平级，头管点选，内容管卡片展示。
    * 切换栏用一排`a`，点选兼筛选跳转，高亮靠`active`类切换；先立父子关系再逐层细化。
    ```html

      <div class="tabs-head">
        <a class="active" href="#">关注</a>
        <a href="#">推荐</a>
        <a href="#">儿科</a>
        <a href="#">内科</a>
      </div>
      <div class="tabs-content"></div>
    </div>
    ```
* **三布局选型**
    * 数量固定3至5个用弹性均分`display:flex`加子项`flex:1`，数量一多即被压扁叠字。
    * 数量不固定用定宽横向滚动，子项定宽加父级`overflow-x:auto`，需隐藏滚动条，低端机略生硬。
    * 又想均分又怕加栏目用等分加滚动兜底，代码稍多且两套属性易冲突。
    * 本项目科室会增长，直接选定宽加横向滚动，为最常用移动端选项卡写法。

    | 布局方式 | 核心写法 | 适用场景 | 短板 |
    | :--- | :--- | :--- | :--- |
    | 弹性均分 | `display:flex`+子项`flex:1` | 数量固定3~5个 | 数量一多压扁叠字 |
    | 定宽横向滚动 | 子项定宽+父级`overflow-x:auto` | 数量不定需左右滑 | 需隐藏滚动条 |
    | 等分加滚动兜底 | 均分打底加超限滚动 | 兼顾美观与扩展 | 属性易冲突 |

* **定宽横滑四件套**
    * 父级不换行并允许横向滚动，`display:flex`配`overflow-x:auto`与`padding:0 11px`，背景白。
    * 子项`flex:none`定宽不收缩，`padding:10px 8px`，字号`14px`；选中态`active`变绿`#16c2a3`加粗`700`。
    * 只写flex不写`flex:none`则子项被强行压缩，六栏目挤一屏叠字。
    * 隐藏滚动条需`::-webkit-scrollbar{display:none}`配`scrollbar-width:none`。
    ```css
    .tabs-head {
      display: flex;
      overflow-x: auto;
      padding: 0 11px;
      background-color: #fff;
      scrollbar-width: none;
    }
    .tabs-head::-webkit-scrollbar {
      display: none;
    }
    .tabs-head a {
      flex: none;
      padding: 10px 8px;
      font-size: 14px;
      color: #333;
    }
    .tabs-head a.active {
      color: #16c2a3;
      font-weight: 700;
    }
    ```
    *     ```text
    *     视口小窗 -> 长条横滑
    *     [关注][推荐][儿科][内科]...>
    *     子项flex:none不压缩
    *     ```
* **选中指示线（Indicator）**
    * `a.active`加相对定位，`::after`画线，`left:50%`配`transform:translateX(-50%)`实现文字两字三字永居中。
    * 线宽`24px`高`3px`，`bottom:4px`，底色`#16c2a3`，圆角`2px`。
    * 固定`left:10px`凑位则换字数即歪；伪元素漏`content:""`则不渲染。
    ```css
    .tabs-head a.active {
      position: relative;
    }
    .tabs-head a.active::after {
      content: "";
      position: absolute;
      left: 50%;
      bottom: 4px;
      width: 24px;
      height: 3px;
      background-color: #16c2a3;
      border-radius: 2px;
      transform: translateX(-50%);
    }
    ```

### 粘性吸顶与固定吸底

* **粘性定位（Sticky Position）**
    * > **定义**：相对定位与固定定位的混合体，未到阈值随页面滚动，到阈值吸住不动。
    * 相对定位不脱标跟滚走，粘性阈值前不脱标到阈值吸住，固定始终脱标永远吸住。
    * 本处不用固定，因固定脱标需给父级补`padding-top`，粘性阈值前占位，改动最小。
    *     ```text
    *     relative不脱标跟滚走
    *     sticky阈值前占位+到值吸住
    *     fixed始终脱标永远吸住
    *     ```
* **吸顶三行写法**
    * `.tabs{position:sticky;top:0;z-index:10;background-color:#fff}`缺一不可。
    * `top:0`为纵向阈值，滚至距视口顶0吸住，写`10px`即距顶10像素吸住；`z-index:10`防卡片盖住选项卡。
    * 背景白必给，透明则卡片字穿底叠糊。
    * 只写`sticky`不写`top`等于没写，横向配`left`，纵向一律配`top`。
    ```css
    .tabs {
      position: sticky;
      top: 0;
      z-index: 10;
      background-color: #fff;
    }
    ```
* **粘性失效两边界**
    * 父级加`overflow:hidden`即失效，粘性相对最近滚动祖先工作，裁剪后算不出滚动距离，清浮动改用`clearfix`或弹性布局。
    * 父级高度不够即吸一下被带走，粘性只在父容器范围有效，`.content`需十几张卡片撑长。
    *     ```text
    *     .content父容器范围内吸住
    *     .tabs sticky top:0吸顶
    *     .card列表撑高 -> 父尽头被带走
    *     ```
* **底部固定栏（Tabbar）与固定定位（Fixed Position）**
    * 外层通栏固定，内层三选项等分，每选项图标上文字下居中，选中钩子`active`预留。
    * 标准写法为`position:fixed;left:0;bottom:0;width:100%`配`display:flex`，缺`left`与宽度则错位或塌成内容宽。
    * 三`.item`各`flex:1`自动等分，加四五项不改宽度；每项纵向`flex-direction:column`配`align-items:center`，`padding:6px 0 8px`，默认`11px #999`。
    * 图标字体图标`22px`配`line-height:1`，选中`active`只改色为`#16c2a3`，不加粗加背景。
    * 固定脱标需给`body`或内容区加等高`padding-bottom`，如栏高56像素即补56像素，否则末张卡片被压。
    * 全面屏手势区用`padding-bottom:constant(safe-area-inset-bottom)`配`env(safe-area-inset-bottom)`兜底，无刘海值为0。
    * 层级建议吸顶`z-index:10`，吸底`z-index:20`压住内容；底栏封装后登录页与我的页直接复用。
    ```html
    <div class="tabbar">
      <a class="item active" href="#">
        <i class="iconfont icon-home"></i>
        <span>首页</span>
      </a>
      <a class="item" href="#">
        <i class="iconfont icon-consult"></i>
        <span>问诊</span>
      </a>
      <a class="item" href="#">
        <i class="iconfont icon-mine"></i>
        <span>我的</span>
      </a>
    </div>
    ```
    ```css
    .tabbar {
      position: fixed;
      left: 0;
      bottom: 0;
      width: 100%;
      display: flex;
      background-color: #fff;
      border-top: 1px solid #eee;
      z-index: 20;
      padding-bottom: env(safe-area-inset-bottom);
    }
    .tabbar .item {
      flex: 1;
      display: flex;
      flex-direction: column;
      align-items: center;
      padding: 6px 0 8px;
      color: #999;
      font-size: 11px;
    }
    .tabbar .item.active {
      color: #16c2a3;
    }
    ```

    | 对比项 | 顶部粘性切换 | 底部固定切换 |
    | :--- | :--- | :--- |
    | 定位方式 | `sticky`加`top:0` | `fixed`加`bottom:0` |
    | 是否占位 | 占位 | 脱标，需补`padding-bottom` |
    | 层级建议 | `z-index:10` | `z-index:20`，压住内容 |

### 表单输入与按钮协议

* **表单容器与输入行**
    * 两行纵向为手机号行与验证码加按钮行，每行一条底边框线，不用四边大框。

    * 占位文本为框空时浅色提示字，一打字消失，不参与提交。
    * 容器`padding:0.2667rem 0.5333rem`，左右20像素给拇指让路，上下10像素；与头部同白底连下，不用外边距断开。

    ```html
      <div class="form-item">

    </form>
    ```
    ```css
    .form {
      padding: 0.2667rem 0.5333rem;

    }
    ```

### 第三方登录与固定真机

* **第三方模块位置与结构**
    * 沉底贴屏底，与表单拉大段距离，由带横线标题行与三圆形图标按钮组成。
    * 独立`div.other`下分`div.title`与`div.apps`，`apps`内三`a`各包一`img`，`a`管跳转授权，`img`管显示。
    * 外层`padding:0 16px`与表单对齐线一致，`margin-top:60px`压至下半区，不用绝对定位，防键盘顶飞按钮。
    * 图标`a`定`48px`见方，内`img width:100%;height:100%;display:block`跟走，改尺寸只改一处，圆底白图自带圆形，风格须统一。
    ```html
    <div class="other">
      <div class="title">第三方登录</div>
      <div class="apps">
        <a href="#"><img src="./images/qq.png" alt="QQ"></a>
        <a href="#"><img src="./images/wechat.png" alt="微信"></a>
        <a href="#"><img src="./images/weibo.png" alt="微博"></a>
      </div>
    </div>
    ```

    ```css
    .other {
      padding: 0 16px;
      margin-top: 60px;

    .other .apps {
      display: flex;
      justify-content: center;
      gap: 32px;
    ```

* **中间文字两边线装饰**
    * 标题`14px #999`居中，左右各`12px`呼吸空间，中间文字固定两边线条自适应一律伪元素加`flex:1`。
    * `.title{display:flex;align-items:center;gap:12px}`，`::before`与`::after{content:"";flex:1;height:1px;background-color:#e5e5e5}`。
    * 伪元素漏`content:""`不渲染；屏幕变宽窄线条自动伸缩，比算百分比省心。
    ```css
    .other .title {
      display: flex;
      align-items: center;
      gap: 12px;
      text-align: center;
      font-size: 14px;
      color: #999;
    }
    .other .title::before,
    .other .title::after {
      content: "";
      flex: 1;
      height: 1px;
      background-color: #e5e5e5;
    }
    ```

    | 部件 | 尺寸参数 | 布局手段 |
    | :--- | :--- | :--- |
    | 标题文字 | `14px`，`#999` | `text-align:center` |
    | 左右横线 | 高`1px`，`#e5e5e5` | 伪元素`flex:1`自适应 |
    | 图标按钮 | `48px×48px` | 父级`flex`居中加`gap:32px` |

* **登录页固定顶部与脱标补偿**
    * `.header{position:fixed;top:0;left:0;width:100%;height:44px;background-color:#fff;z-index:10}`，主体`.main{padding-top:44px}`让出塌陷高度。
    * 漏`width:100%`则缩成小条，漏`left:0`则部分机型错位几像素，漏背景则内容透底，漏层级则图片按钮盖字。
    *     ```text
    *     z=10 .header不透明标题栏
    *     z=0  .main滚动内容经背后过
    *     栏高44px -> 主体补padding-top:44px
    *     ```
    ```css
    .header {
      position: fixed;
      top: 0;
      left: 0;
      width: 100%;
      height: 44px;
      background-color: #fff;
      z-index: 10;
    }
    .main {
      padding-top: 44px;
    }
    ```
* **真机预览链路与三验**
    * 同一WiFi为前提，Live Server保持启动，端口一般5500，Windows用`ipconfig`取IPv4如`192.168.1.6`。
    * 地址格式为`http://`加电脑IP加冒号加端口加路径，如`http://192.168.1.6:5500/login.html`。
    * 客户端隔离打不开则手机开热点给电脑连；三验为顶栏滑动悬停、图标行居中且横线伸缩、按钮撑满且留白合稿。
    * 横屏看横线变长图标仍居中即弹性自适应成立。
    *     ```text
    *     电脑LiveServer:5500 <-> 同WiFi <-> 手机浏览器输地址
    *     http://192.168.1.6:5500/login.html
    *     ```
* **阶段三方案与三能力**
    * 流式加弹性为百分比宽加弹性盒，结构简单单列均分页面，本阶段主力实战统一用此。
    * 相对单位为根字号加媒体查询动态换算，适整体等比老项目混合终端。
    * 视口单位为视口宽直接换算，新项目轻量一处换算处处生效。
    * 三能力为视口声明打底、弹性分块定轴对齐流水线、真机同WiFi查IP拼地址滑一遍闭环。
    * 弹性流水线为先分块`header/main/other`，再定轴`flex-direction:row/column`，后对齐`justify-content+align-items+gap`。
    * 真机纵滑看固定头，横竖切看弹性伸缩，双指缩放看视口锁死。
    ```html
    <meta name="viewport" content="width=device-width, initial-scale=1.0, maximum-scale=1.0, user-scalable=no">
    ```
    *     ```text
    *     弹性三步: [1分块]划区 -> [2定轴]row/column -> [3对齐]主轴+侧轴+gap
    *     ```

    | 方案 | 核心手段 | 适用场景 |
    | :--- | :--- | :--- |
    | 流式加弹性布局 | 百分比宽加弹性盒 | 结构简单单列均分页面 |
    | 相对单位适配 | 根字号加媒体查询换算 | 整体等比老项目混合终端 |
    | 视口单位适配 | 视口宽直接换算 | 新项目轻量适配 |
