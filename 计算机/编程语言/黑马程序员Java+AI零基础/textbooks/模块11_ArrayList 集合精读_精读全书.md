### 数组的长度定死了，才有了集合

接下来咱们继续往下来学 Java 中第二个常见的 API——集合，ArrayList。

不过在说 ArrayList 之前，咱们还得从数组开始说起。数组我们并不陌生，在之前呢我们写过很多数组相关的代码。我们知道数组呢它就是一个容器，可以用来存储同种数据类型的多个值。但是数组本身其实呢还是有一点小弊端的。

注意了，兄弟们，我问大家一个问题：数组一旦定义完毕之后啊，它的长度是不可变的。那如果在这个数组当中，我要继续添加数据，那你怎么办？没有任何的办法。我只能再创建一个更长的数组，把原来的数据 1、2、3 放到新的大数组当中，然后再在它的后面去添加新的元素。那这样的代码呢，我可以写，但是写起来会非常的麻烦。

所以我就在思考了，在 Java 当中有没有存在这么一个容器，添加元素的时候可以自动扩容，删除元素的时候可以自动缩减呢？可长可短，伸缩灵活。当然是有，是谁呢？这就是我们今天要学习的集合。

> **定义**：集合就是一个长度可变的容器。一句话就可以理解。

那么在以后，如果说哥们要定义一个容器去存储多个数据，举个例子，比如说我要把我喜欢的所有的游戏用一个容器给存起来，那么在此时就可以直接使用集合。

在刚开始创建的时候呢，因为集合里面没有任何的元素，所以说它的长度就是 0。那么在后面每添加一个元素，集合就会自动地扩容，长度呢依次变成 1、2、3、4、5，每添加一个数据长度就会加一。那这个呢是添加，那删除呢？删除也是一样的道理。如果说我要删除一个元素，集合就会自动地缩减，长度变成 4。非常的方便。

> **结论**：集合让我们可以不再考虑容器长度的问题，只要直接操作数据本身就可以了。

在 Java 当中，集合呢是有很多很多种的——ArrayList、LinkedList、HashSet 等等。那么它们的区别呢，在后面咱们会挨个地学习。但是现在，我们先来学习 Java 当中用得最多的 ArrayList。

### 创建一个 ArrayList 对象：空参构造加泛型

想要创建 ArrayList 的对象，就要看它的构造方法。构造方法非常的简单，我们可以利用空参构造先去创建一个长度为 0 的、没有没有任何元素的集合，然后再通过里面的方法去操作集合里面的数据。

```java
// 创建一个长度为 0 的 ArrayList 集合
ArrayList list = new ArrayList();
```

但是呢有一个问题，注意了兄弟们：如果说代码仅仅是写成这个样子，它是有弊端的。

#### 不写泛型：什么都收得住，什么也读不懂

我问大家一个问题，就是通过上面这行代码，你能判断出在集合当中能存储什么类型的数据吗？

如果你不理解这个问题，我写个数组你就明白了：

```java
int[] arr = new int[3];
```

那么现在我再问你，你能判断出这个数组里面能存储什么类型的数据吗？当然我能判断出，不就是 int 类型的整数吗，对吧。好，那么此时你再看 `ArrayList list = new ArrayList()` 这行，现在你能判断出在集合当中能存储什么类型的数据吗？我判断不了。

也就是说通过这行代码，我没有限定在这个容器当中能存储什么类型的数据。那么现在就是，如果说没有进行限定，此时这个集合里面它可以存储任意数据类型的数据。任意到什么程度？我跟你说非常非常的任意。在这呢我可以添加字符串 "abc"，没有任何问题；那么在这个下面我还可以添加任意的对象——在这里呢我已经准备好了四个类：Cat、Dog、Student、Teacher，猫、狗、老师、学生，可以把它右键剪切，再点击包名粘贴过来。

```java
ArrayList list = new ArrayList();

list.add("abc");
list.add(new Student("张三", 18));
list.add(new Teacher("李四"));
list.add(new Cat("小猫", "白色"));
list.add(new Dog("小狗", "黑色"));

System.out.println(list);
```

右键 run，程序运行完毕。因为呢我们自己写的这个 Student、Teacher、Cat、Dog 呢没有做任何的处理，所以说直接打印的时候还是内存地址。但是你甭管它打印什么，你来看，1、2、3、4、5 共五个数据，它是不是全都添加到集合当中了呀。

那有的兄弟想你添加就添加呗，这不挺好的吗？我一个容器可以添加任意数据类型的数据。但是兄弟，你添加的时候是爽了，那我还要再把它给取出来呢，你就非常非常的头疼。

假设现在呢这里的添加的数据不是你写的，是别人写的。你根本就不知道 0 索引、1 索引、2 索引、3 索引、4 索引是什么类型的数据。那么现在我用 `list` 点上 `get(0)` 索引，那你告诉我，我用什么类型的变量去接收？我根本就不知道。那么在此时我就不得不用一个最大类型的变量，也就是用 `Object` 去接收。

为什么用它可以？因为 `Object` 是我们 Java 里面所有类的祖宗类，任意类型的对象我都可以赋值给 Object 类型的变量。这不就是一个多态吗？但是我想问大家，多态有没有弊端？它是有的。多态它无法使用子类的特有行为。那如果说你想要用子类的特有行为，那你只能向下转型。

但是呢，又因为这个添加是别人写的，我现在根本不知道 0 索引到底是什么数据类型的。那你在获取的时候，还要一个一个的去判断：`o instanceof String`，你是不是 String？如果是 String，我再进行强转；再往下我要把所有的情况全部写完，`else if` 我再去判断 `o instanceof Student`，你是不是 Student 类型？如果是 Student 类型，我再进行强转。

如果代码写成这样，那太麻烦了呀。我每获取一个数据，那我都要写这么一大段代码，那我还用集合干嘛呀？

所以为了解决这个问题，Java 呢给集合去添加了一个知识点，就叫做**泛型**。

> **结论**：泛型的作用，就是可以限定我集合当中存储的数据类型。

#### 泛型怎么写，JDK7 又帮你省了哪一步

泛型的书写格式呢其实非常的简单，就是一个尖括号。我们可以把那个数据类型呢，直接写在尖括号当中，这就可以了。

```java
// 现在要用泛型去限定在集合当中能存储什么类型的数据
ArrayList<String> list = new ArrayList<String>();
```

在写的时候你发现了没有，ArrayList 的这个类跟其他的类它不一样，后面呢你看这里它是不是有一个尖括号 E 呀。所以呢此时它相当于就是给你一个提醒：你在创建 ArrayList 对象的时候，记得要去写泛型。这个尖括号就是泛型。代码可以这么写——ArrayList，泛型直接写在类名的后面。你要在集合里面存储什么类型，那么在尖括号当中就写什么类型就可以了。

```java
ArrayList<String> list = new ArrayList<String>();
```

给集合起个名字叫 `list`，等于 `new ArrayList`，后面也得有一个泛型，这个尖括号也得写上 String。

好，那么此时我在添加的时候，它就只能添加字符串。如果说你添加其他的数据，比如说我 `add new` 一个 Student，你发现代码就直接报错了。鼠标悬停，你来看它有一个错误的提示：我现在要的是 String，但是你给我的是一个 Student，所以说代码直接报错。

```java
ArrayList<String> list = new ArrayList<String>();
list.add("abc");
list.add(new Student());   // 编译报错：需要 String，实际给了 Student
```

那么这样的好处呢？就是在下面我在获取 `get` 的时候，自动生成左边，你来看是不是就直接是 String 类型的呀？不需要你再去强转了。在这个下面我就可以直接去使用 String 这个里面的特有方法。

但是这个呢其实还不是我们最终的代码。因为呢在这个代码当中，你会发现它有一个重复的内容——什么内容？就是前面啊我已经写了一个尖括号了，那你后面再写一遍，感觉有点太麻烦了。

所以说呢在 JDK7 的时候，它有了一个新的规则，就是后面的泛型可以省略不写，但是尖括号必须保留。所以现在我们最终的代码是写成这个样子的：在前面我依旧去写泛型，起个名字 `list` 等于 `new ArrayList`，而后面我直接写一个尖括号就可以了，这个里面的内容默认跟前面去保持一致。

```java
ArrayList<String> list = new ArrayList<>();
```

那么这个就是我们现在最终的写法。

### 增删改查：一个集合的四类方法

这些方法呢总共是可以分成四类，分别是增、删、改、查，我们一个一个来看。

所谓增，其实呢说白了就是添加数据，它里面呢有两个方法：方法名字叫做 `add`，第一个 `add` 方法是一个参数的，它默认呢是表示把当前的元素添加到末尾；而第二个 `add` 方法是把当前的这个元素添加到指定的索引。

删除呢也有两个，我可以根据元素进行删除，也可以根据对应的索引来进行删除。

额外还有第三个，修改。就是我要把指定索引上的数据修改成一个新的数据。

额外最后还有一个，查询。查询呢分两种情况：第一种情况我要查询单个数据，此时呢可以利用 `get` 方法，把指定索引上的数据去获取出来；当然我还可以查询所有的数据。那查询所有不就是遍历吗？我可以通过 `get` 还有 `size` 这两个方法去遍历整个的集合。

| 类别 | 方法 | 一句话说明 |
| --- | --- | --- |
| 增 | `add(E e)` | 把元素添加到末尾 |
| 增 | `add(int index, E e)` | 把元素添加到指定索引 |
| 删 | `remove(Object o)` | 按元素内容删除，返回是否成功 |
| 删 | `remove(int index)` | 按索引删除，返回被删除的元素 |
| 改 | `set(int index, E e)` | 修改指定索引，返回被替换的元素 |
| 查 | `get(int index)` | 获取指定索引上的元素 |
| 查 | `size()` | 获取集合的长度 |

好，那么接下来就打开一下我们心爱的 IDEA，把它来做一个代码实现吧。因为是一个新的知识点，所以哥们又新建了一个包，叫做 A10ArrayListDemo，要演示的方法我也粘贴过来了。

### 添加：add 的两个重载

首先第一步跟刚刚一样，我们还是创建一个 ArrayList 集合的对象，`ArrayList` 泛型我指定一下存储的类型，那就是 String，存字符串，起个名字 `list` 等于 `new ArrayList`。

```java
ArrayList<String> list = new ArrayList<>();
```

#### 单参数 add：那个永远为 true 的返回值

添加有两个方法。第一个是一个参数的，它是把指定的数据添加到末尾；还有一个 `add` 方法是重载的，它是将数据添加到指定的索引当中。

我们先来看第一个，一个参数的。此时呢哥们只要用 `list` 去调用 `add` 方法，你发现一个参数的这个方法，它有一个返回值，是一个布尔类型的。其实呢它就表示我当前的元素是否添加成功，如果你是 `true` 就是添加成功，如果你是 `false` 就添加失败。

```java
ArrayList<String> list = new ArrayList<>();

list.add("AAA");
list.add("BBB");
list.add("CCC");

System.out.println(list);
```

右键 run，程序运行完毕，你发现每一个数据都添加进去了。而且呢，每次添加它都是默认放在末尾的。

回到代码当中我们继续。在刚刚呢我们看到了当前的这个方法呀它是有返回值的，我们用一个变量去接收一下，用鼠标点击方法名，自动生成左边，在这个下面呢我去打印一下，右键 run，程序运行完毕，你发现 `true`、`true`，就表示我当前的元素是添加成功的。

```java
ArrayList<String> list = new ArrayList<>();

boolean res1 = list.add("AAA");
boolean res2 = list.add("BBB");
boolean res3 = list.add("CCC");

System.out.println(res1);   // true
System.out.println(res2);   // true
System.out.println(res3);   // true
```

那说到这个地方，哥们我心里要好奇了，那这个方法什么时候会返回 false、添加失败呢？哥们不造不造？没关系，我们来看一下 Java 的源代码，按住 Ctrl 不松，用鼠标左键点一下 `add` 方法，跳一点点，完了之后你发现前两行代码呢我们先不用看，这个呢是添加的具体规则，主要是看第三行——你发现它是一直返回一个 `true`。那这个呢就表示，你前面的这个数据，我甭管你添加什么，我一定是能添加成功的。

那说到这个地方，哥们我好奇了呀，既然你每一次都能添加成功，那我为什么还有一个返回值呢？我直接写一个 `void`，没有返回值，这不就 OK 了吗？代码不更简单吗？为什么还要加一个返回值？

首先呢我们先来说一下结论哈，就是此时这一个 `add` 的方法，它呢在任意情况下都会添加成功，永远不会失败。

OK，那么 Java 为什么会这么去设计呢？其实呢是因为在 Java 当中，我是有很多很多的集合的，不仅仅只有你一个 ArrayList，我还有其他的一些集合。举个例子，比如说我们后面马上要学的那个 HashSet 的集合，那么这个集合呢它有一个特点，就是里面的元素要唯一。当我第一次添加 AAA 的时候，`add` 方法会返回 `true`；但是如果说我第二次再添加 AAA 的时候，它就会返回一个 `false`，因为你前面已经添加过了嘛，我数据要唯一不能重复。所以第二次的时候它就是一个 `false`。

所以 Java 之所以设计 ArrayList 这个 `add` 方法有一个返回值，其实呢并不是给当前 ArrayList 服务的，他这么设计的原因是要跟其他的集合保持统一。

这个呢其实也是我们之前讲面向对象的思想。兄弟你还记得吗？如果你忘了没关系，我们可以简单的回顾一下我们之前讲的内容。

我们曾经讲过一个知识点，叫做抽象类和抽象方法的意义。看这里有三个代码，上面的是一个父类 Animal，下面呢是两个子类，一个是 Cat，还有一个 Dog。那么现在呢，我是把吃 `eat` 那个方法，当作子类独有的方法。

在之前我们曾经讲过，在这种情况下呢就会引发一个问题：因为每一个子类呢有可能是不同的人写的，第一个人写 Cat，它有可能方法名起成 `aabc`，有形参无返回；那么第二个人在写 Dog 里面 `eat` 的时候，他有可能是名字叫做 `it`，有形参有返回。

所以呢如果说我们把这些共性的方法当作子类的特有行为，就有可能导致这样的问题：那么当代码写完之后以后，我想调用那个 `eat` 的方法了，就非常的麻烦了。我要调用猫吃的那个方法，我就要到猫里面去看；调用狗里面吃的方法，我就要到狗里面去看这个方法。那随着这样的子类写得越来越多越来越多，那我在调用这里 `eat` 的方法的时候，我就会非常的麻烦。

怎么解决的？有没有同学能打在弹幕当中回答？其实非常简单：我们就可以把这些方法呀作为一个抽象方法，抽取到父类当中。在这个里面我指定了 `eat` 的规则，那么这个规则包含了它的返回值、它的方法名，还有它的形参。那么此时写成抽象的，它有一个隐含的含义，就是我强制此类必须要按照这种格式来进行重写。那么此时此类你就不能自己再发散了，必须要按照我规定的这个格式来进行重写。

那么这样的好处呢？就是以后我在调用的时候，我就没必要一个子类一个子类的去看了，我是不是直接去看父类就可以了呀？下面所有子类的 `eat` 的方法，我就都知道该怎么去调用了。

那么现在呢我们看到的集合，其实呢也是遵守了这样的一个设计理念。在 Java 当中它不仅仅只有一个 ArrayList 的集合，集合有非常多非常多，在这里呢我罗列了六个。那你要知道集合它都是一个容器，它是不是都会有增、删、改、查这样的方法呀？

好，那么其中 `add` 这个方法，你觉得它会把它定义在子类当中，当做特有的行为吗？肯定不是。如果是当作特有的行为，就会产生我们刚刚所说的问题。所以此时 Java 呢会把那个 `add` 添加的方法去定义在父类当中，把它写成 `abstract` 抽象的。那么我子类在进行重写的时候，就要根据父类里面定义的规则来进行重写。只不过呢在这个完整的集合体系当中，它上面的呢不是那个父类，而是**接口**。

OK 好，那么这个体系呢咱们现在暂时先不用掌握，先混个眼熟就可以了。回到代码当中我们继续往下。

在刚刚呢咱哥们详细地去讲解了 `add` 返回值设计的理念，其实呢就是我们之前所讲的面向对象统一的思想。那么这些东西呢其实大家混个耳熟就可以了。现在最少最少需要你掌握的就是：我以后再调用 `add` 方法的时候，我忽略它的返回值，不用去管它。因为呢我们知道这个返回值的作用其实就是为了保证跟其他的集合去统一，你不管添加什么 ArrayList 它都返回一个 `true`。那既然是这样的话，你的返回值我就忽略，对我来讲没有用，对吧？代码我这么写，这就可以了。

> **结论**：ArrayList 的 `add` 方法，你不管添加什么，它都会添加成功，所以说呢我们在使用的时候忽略返回值，这就可以了。

#### 双参数 add：索引范围只能是 0 到长度

好，那么继续往下，它还有第二个小细节。

第二个 `add` 方法呢，它是可以把元素添加到指定的索引的位置，我们一起来写一写。

那么现在呢，假设我已经添加了三个数据了——AAA、BBB、CCC，右键 run 来运行。其中 0 索引呢是 AAA，1 索引是 BBB，2 索引是 CCC。那么现在我在添加的时候，我需要把 QQQ 去添加到 0 索引的位置。那代码怎么写呢？那我就这么写 `list.add()`。

注意这个方法呢它有两个形参：第一个形参就是那个索引，第二个形参就是你当前要添加的数据。这个方法它是 ArrayList 里面独有的方法，它是没有返回值的，是一个 `void` 的。

```java
ArrayList<String> list = new ArrayList<>();

list.add("AAA");
list.add("BBB");
list.add("CCC");

list.add(0, "QQQ");
```

右键 run，当当当当程序运行完毕，你发现 QQQ 有没有到 0 索引？有。那原来 0 索引上的数据呢？它是依次往后挪了一个位置。

```text
插入之前（集合里已有 AAA、BBB、CCC）

┌─────┬─────┬─────┐
│ AAA │ BBB │ CCC │
└─────┴─────┴─────┘
   0      1      2


执行 list.add(0, "QQQ") 之后

┌─────┬─────┬─────┬─────┐
│ QQQ │ AAA │ BBB │ CCC │
└─────┴─────┴─────┴─────┘
   0      1      2      3
```

读图：QQQ 落到了 0 索引，原来三个元素整体向右挪了一格，长度从 3 变成 4。

好，那么这个呢是第二个 `add` 方法。那么这个方法呢它里面也有一些小细节要注意。

就是说如果说集合的长度是 3，那么下面这个方法要添加索引的范围只能是 0~3，你不能写太多，写四写五写六，它就直接报错了。这什么意思呢？我们来试一试。

就是在这个里面我写 0 没问题，然后呢我写 3，右键 run，你发现 3 也 OK，它呢是加在了末尾。这是 0 索引、1 索引、2 索引、3 索引，相当于呢我就是添加了末尾。但是呢如果你写的是 4 索引，4 索引相当于就是跳过了这个位置，我直接添加到这，那程序就会直接报错了。写个 4，右键 run，程序运行完毕，你看 main 方法的第 39 行报错了，报错的原因是 `IndexOutOfBoundsException`，索引 4，你当前要添加的索引是 4，但是你集合的长度只有 3。

好，我们把这个细节呢去补充完整：如果说集合的长度是 3，那么下面方法要添加的索引的范围只能是 0~3。其中 0~2 是已经存在的索引，还有最后一个 3，相当于那就是把当前的元素添加到集合的末尾，在这种情况下其实呢就等同于一个参数的 `add` 方法。但是如果说要添加的索引超出了 0~3 这个范围，那么此时程序就会直接报错。

> **易错点**：不要死心眼儿啊。说我这个地方是 0~3 以后，所有的情况都是 0~3 啊，不是的。这个地方哥们写 0~3，只是在这个案例当中给你举个例子。那如果说我现在的元素呢是 DDD、EE，我这个集合的长度是 5 呢，那你这个地方的范围就是 0~5 了，对吧。要灵活一点。

### 删除：remove 的两个重载

继续往下，还有两个 `remove` 删除的方法，我们继续来。

我先来看第一个，叫做根据元素来进行删除，这个就非常的简单。我可以用 `list` 去点一下 `remove` 方法，你看这里它有两个：第一个是 `int index`，根据索引来进行删除，那么此时呢它会把被删除的元素给你来返回；还有第二个 `Object o`，它呢是根据元素进行删除。它返回的是什么？看这里它返回的是布尔，也就是说你当前的元素是否删除成功，删除成功返回 `true`，删除失败返回 `false`。

#### 按元素删：删不到就返回 false

我们先来看第一个，根据元素来进行删除。现在呢在我的集合当中是 AAA、BBB、CCC、QQQ，那现在呢我要把那个 QQQ 给删除，那我就直接写吧，自动生成左边，用一个变量 `res` 去接收一下，那么现在呢我去打印一下 `res`。

```java
ArrayList<String> list = new ArrayList<>();

list.add("AAA");
list.add("BBB");
list.add("CCC");
list.add("QQQ");

boolean res = list.remove("QQQ");

System.out.println(res);   // true
```

右键 run，程序运行完毕，你发现 `true`。`true` 是什么意思呢？那就表示我当前的这个 QQQ 我是删除成功的。

那说到这个地方，有很多同学又要疑问了，那我这个方法什么时候返回 false 啊？其实很简单，就是如果说你删除一个不存在的数据，它就会返回 `false`，来看这里是不是 `false` 小写的，QQQ 有没有删除？没有删啊。

所以呢哥们可以给他去写一些小细节：首先呢我们先写就是这个方法，它是根据元素的内容进行删除的。如果当前的元素是存在的，删除成功返回 `true`；但是如果当前的元素是不存在的，则删除失败，返回一个 `false`。

> **结论**：`remove(Object o)` 按元素内容删除，存在返回 `true`，不存在返回 `false`。

#### 按索引删：它把被删掉的元素还给你

好，那么继续往下，我把这段代码去注释掉，再来看第二个 `remove` 的方法，它呢是根据索引来进行删除的。那这个就非常的简单，我用 `list` 点上 `remove`，我去把 0 传递过去。那么在删除之前呢，我先去打印一下在集合当中的内容——注意了，这个跟这个打印出来的它是不一样的，这个是删除之前的，下面的是删除之后的。

```java
ArrayList<String> list = new ArrayList<>();

list.add("AAA");
list.add("BBB");
list.add("CCC");
list.add("QQQ");

System.out.println(list);        // 删除之前
list.remove(0);
System.out.println(list);        // 删除之后
```

右键 run，你来看程序运行完毕，你看 0 索引的 AAA 有没有删掉？删掉了。

那么这个方法呢它有一个返回值，它是把被删除的元素给你来返回。点击一下方法名自动生成左边，写一下 `res`，再去把 `res` 来做一个打印。右键 run，你来看 AAA，被删除的元素是不是返回了？

```java
String res = list.remove(0);
```

好，那么在这呢我们继续往下去写一下这个方法的小细节：就是它呀是根据索引进行删除的，它呢会把被删除的元素进行返回。

### 修改与查询：set、get、size

添加、删除我们都已经会了，那么接下来呢我们来看第三组，就是 `set` 修改的这个方法。把上面的代码呢我们全部的注释掉，只留一个添加的方法，好，那么现在呢我要来进行修改了。修改之前我同样的也是来打印一下 `list`。

那么在这个下面我要来进行修改，我要怎么修改？我要把 0 索引的数据 AAA 修改为 ZZZ。那你觉得怎么办呢？

#### set：被替换掉的元素会还给你

我用 `list` 点 `set`，它里面有两个参数：第一个参数就是你想要修改哪个索引，第二个参数就是新的元素。方法呢有一个返回值，它是把被替换的元素给你来返回。

```java
ArrayList<String> list = new ArrayList<>();

list.add("AAA");
list.add("BBB");
list.add("CCC");
list.add("QQQ");

System.out.println(list);        // 修改之前：AAA BBB CCC QQQ

String res = list.set(0, "ZZZ"); // 把 0 索引改成 ZZZ

System.out.println(res);         // AAA ← 被替换的元素
System.out.println(list);        // 修改之后：ZZZ BBB CCC QQQ
```

右键 run，你来看修改之前集合里面的是 AAA、BBB、CCC、QQQ，那么在下面它有两个输出语句。第一个 AAA 是什么？是不是那个被替换的元素啊？其实就是上面打印的 `res`，而下面的这个就是我修改完了之后集合里面的数据。

所以呢我们也可以来写一下这个方法的注意点：它就是把指定索引上的数据修改为新的数据，然后呢它会把被替换的元素来进行返回。

> **易错点**：其中呢要注意的是，其实呢跟刚刚一样，就是你修改的那个索引是不是要存在啊。如果说当前要修改的索引是不存在的，代码就会报错。

#### get 与 size：把集合整个走一遍

好，回到代码当中，这个呢就是我们第三组叫做修改的方法。好，那么继续往下，我们还有最后一组，就是那个查询。查询呢有两个，一个是 `get`，还有一个是 `size`。

其中 `get` 呢，它是原本的最纯正的那个查找的方法。因为呢它会根据索引去查找对应的元素，把那个查到的元素给你来进行返回。我们可以用 `list` 点上一个 `get` 方法，小括号里面呢可以写 0 索引，自动生成左边，写一个 `res`，再打印一下 `res`。

```java
String res = list.get(0);

System.out.println(res);         // AAA
```

那么现在呢相当于就是我查询了 0 索引上的数据，把这个数据给你来返回。右键 run，你看 0 索引上的 AAA 是不是我拿到了。好，那么这个呢是获取单个元素。

但是呢在查询的时候，还有一种情况，就是如果说我是想遍历呢？遍历我要获取到集合里面所有的元素，那这个时候怎么办？你光通过一个 `get` 就没有用了，你还得再结合下面的 `size` 方法。

> **易错点**：注意集合的长度，它不叫 `length`，它叫 `size`。

你要把这两个方法结合起来，那么就可以直接遍历。我们可以这么写，`list` 点上 `for i` 直接快速生成，一个回车。你看 `i` 从 0 索引开始小于 `list.size()`，跟我们之前遍历了一个数组是不是一模一样的。那么在循环的过程当中，这里的 `i` 它呢就是依次表示集合中的每一个索引，而我们下面要写的 `list.get(i)`，它呢其实就是依次获取集合中的每一个元素。

```java
for (int i = 0; i < list.size(); i++) {
    String s = list.get(i);
    System.out.println(s);
}
```

右键 run，你来看 AAA、BBB、CCC、QQQ 是不是每一个都拿出来了呀。

#### 遍历和直接打印集合，差的可不是一点

OK，好，那么当我们写完了这个遍历之后，每次呢都有很多同学感觉到一点小疑问，说那个阿伟啊，我这里的遍历跟下面直接打印一个集合，这两种方式我感觉是不一样的嘛。我都是把这个数据打印在控制台，那我为什么还要遍历呢？

你要来看兄弟，这两种写法它是有本质上的区别的。什么叫做遍历？遍历是打印吗？不是。遍历它是把容器里面的数据一个一个的拿出来。那至于拿出来之后，你是打印还是计算还是做其他的处理，这个都行，看你当前的需求想怎么干怎么干。

那么在我当前的这个代码当中，我是把它进行打印处理的，对吧？当然了，你还可以进行其他的什么计算呀，什么截取呀，什么替换呀，进行其他的各种各样的操作。但是下面的这个呢，直接打印集合，它呢是只能看一看集合当中有什么，在这种情况下呀，他是无法操作里面的每一个元素的。

> **结论**：这就是两段代码它最本质的区别。

### 集合里放不下 int：包装类登场

那么接下来呢我们也回到资料当中，把集合来做一个小结，看一看在这个知识点当中需要大家一定要掌握的内容到底有哪些。

在集合的这个章节当中，哥们其实需要大家掌握的就是以下的四个知识点。

第一个，我们要知道什么是集合，一句话就能说明白——集合呢其实就是一个长度可变的容器。

第二个，我们要知道那集合本身有什么样的特点呢？它的特点有两个。第一个就是长度可变；第二个特点要万分注意，就是集合它只能存储引用数据类型，你是不能存储基本数据类型的。

再往下第三个，我们要知道的就是如何创建一个集合的对象。这个呢其实非常的简单，我们就是利用空参构造，再结合泛型这种方式去创建集合的对象。在创建的时候呢，你在集合里面想要存储什么类型，就把这个数据类型写在尖括号，也就是泛型当中，这就可以了。

那再往下就是最后一个，我们要掌握集合里面常见的方法，它分为四类，分别是增删改查：增——添加 `add`；删除——`remove`；改——修改 `set`；查——查询 `get`。那么额外的还有一个要获取集合的长度，就是那个 `size`。

那这里咱们把"集合只能存引用数据类型"这件事再展开说说，因为这是最容易踩坑的地方。

#### 八种基本数据类型的包装类怎么对应

好，那么继续往下，它还有第二个小细节：就是在集合当中，它是无法直接添加基本数据类型的。

哎说到这里，兄弟你还记得什么是基本数据类型吗？从代码的角度来讲，就是 byte、short、int、long、float、double、char，还有 boolean。在集合当中，你是无法直接添加这样的基本数据类型的，在集合里面呢，它只能添加引用数据类型，那么这个引用数据类型，说白了其实呢就是对象。

好，那说到这个地方，有的兄弟感觉到疑问了，那你既然不能添加这种 1、2、3、4、5，那这集合好鸡肋啊。别忙，还没说完。就是如果说在集合当中，哥们一定要添加基本数据类型，那么可以转成其对应的包装类。

那说到这个地方又有一个新的概念，什么是包装类？这个呢我们在下一个视频当中我们会详细的讲解，现在呢先知道这么一个结论，这就可以了。

那咱们先认认脸。八种基本数据类型其实呢都有其对应的包装类，我们来看一下它的特点：其实啊就是把它的首字母变成大写。比如说 byte，它的包装类的名字就是 Byte；还有 short，就是 Short；long 就是 Long；float 就是 Float。

只不过呢它里面有两个特例：就是 int，它所对应包装类的名字叫做 Integer；还有这里的 char，它包装类的名字叫做 Character。只有这两个是特殊的，其他的全部都是遵守我们刚刚的规律，就是把首字母变成大写。

那么以 int 为例，代码我们就可以这么写：基本数据类型 `int a = 10`，而包装类我们就写 `Integer b = 10`，那么此时这里的 `b` 就可以添加到集合当中了。

```java
int a = 10;
Integer b = 10;      // b 可以添加到集合当中
```

#### 从内存角度看 Integer 到底是什么

好，那么代码呢其实非常的简单，但是这个包装类我该怎么去理解呢？不着急，我们还是从内存的角度啊去理解。

这段代码很简单，就简单的两行：第一个是基本数据类型，第二个是它所对应的包装类。那么跟之前一样啊，程序在启动的时候，就会把这个类的字节码文件加载到方法区，虚拟机开始调用 main 方法，main 方法加载进栈，开始执行里面的第一行代码。

```java
int a = 10;
Integer b = 20;
```

第一行代码 `int a = 10`：要注意这个呢是基本数据类型，所以说呢就是在栈里面声明了一个变量叫做 `a`，而这里的整数 10，它就是真实的存在变量 `a` 当中的。那么这个呢就是基本数据类型。

那么继续往下看下面的包装类。这里的包装类啊，其实就是 Java 已经写好的一个 Java 类，跟我们之前所写的 Student 呀、Teacher 呀、Dog 呀、Cat 呀，它没有任何的区别。只不过现在这个包装类它的名字叫做 Integer，它描述的是一个整数而已。它里面也有属性、有构造，还有其他的成员方法，只不过呢它的属性 `value` 是用 `final` 来进行修饰了。那这就表示呢说对象一旦创建之后，它里面的属性值是不能够发生改变的。

所以说呢这里的 `Integer b = 20`，它其实是一种简化的写法，这行代码它等同于下面就是 `Integer b = new Integer(20)`，小括号里面是 20。我把一个基本数据类型变成一个对象，在内存当中它就变成这样了：

```text
int a = 10;                Integer b = 20;
                            等价于 Integer b = new Integer(20);

   栈                              栈                      堆
┌────────────┐               ┌────────────┐        ┌──────────────────┐
│     a      │               │     b      │        │   Integer 对象   │
├────────────┤               ├────────────┤        ├──────────────────┤
│     10     │ ← 值就在变量里 │   0X0011   │──引用─▶│ value(final) = 20│
└────────────┘               └────────────┘        └──────────────────┘
```

读图：左边 `int` 的 10 直接躺在栈里的变量 `a` 中；右边 `new` 出来的对象在堆里，栈里的变量 `b` 只拿到它的内存地址 `0X0011`。

等号的左边就是在栈里面声明了一个局部变量叫做 `b`，而等号的右边它是有 `new` 关键字的，所以说呢就是在堆里面去创建了一个对象，里面的属性 `value` 赋值为 20，然后再把它的内存地址 0X0011 通过等号赋值运算符赋值给 `b`。

所以说呢包装类非常的好理解，其实呢就是把基本数据类型用对象包起来而已。那么一旦包起来，这样的好处呢？就是我们可以在 Integer 这个类当中去定义很多很多操作整数的方法，那么在以后我们直接调用这些方法就可以了，不需要我们自己再去写里面的逻辑了。

我们已经打开了 API 帮助文档，也已经找到了 Integer 这个类，往下拉往下拉往下拉，你来看在这个类里面，他定义了很多很多去操作整数的方法。那么在以后呢我们直接调就行了，不需要再去写里面的真实的业务逻辑了。

但是现在呢，关于 Integer 这个类里面的方法，我们暂时呢先不需要掌握。现在呢关于 Integer，我们只要知道它就是基本数据类型 int 的包装类，这就可以了。那如果说在以后我们要往集合里面去添加整数，你不要写 int，写 Integer，这就可以了。

> **结论**：到目前为止我们知道这些就行，至于 Integer 里面操作整数的那些方法，后面再学。

```java
    if (i == list.size() - 1) {     // 最后一个元素
```

那接下来我们开始来推导这个方法。这个方法的作用在刚刚呢我们已经粘贴过来了，其实呢就是根据 id 去查找学生的信息。那么这个时候你要来想，我形参写什么呢？我要完成这件事情需要什么才能完成，对吧？根据 id 查找学生的信息，那你要不要把 id 告诉我？要。那我这个 id 在哪找啊？你这个集合是不是也得告诉我呀？

OK 所以说方法的形参有两个，一个是我要查找的 id，还有一个就是我在哪找。继续往下，它的返回值要不要呢？题目当中已经明确的说了，你要返回索引，如果说不存在，你要返回 -1，所以说呢返回值它是一个 `int` 类型。

```java
public static int findStudent(String id, ArrayList<Student> list) {
    for (int i = 0; i < list.size(); i++) {
        Student stu = list.get(i);
        if (stu.getId().equals(id)) {
            return i;
        }
    }
    return -1;
}
```

好，那么接下来呢在这个循环当中，我们就可以来遍历集合，得到集合中的每一个元素。那么要注意的是，就是这里的每一个元素啊，其实就是学生对象，然后呢我们再去判断当前元素的 id，跟我要查找的 id 是否一致。

OK 所以说呢哥们就可以这么写，`list` 点上 `for i`，循环的过程当中 `i` 是表示每一个索引，`list.get`，那么此时我获取的才是里面的每一个元素，每一个元素又是一个学生对象，所以呢我可以通过一个变量 `stu` 来进行接收。

那么下面呢我们就可以来进行判断了。要注意，现在呢我判断的是引用数据类型 `id`，它是 `String`，你不能用那个 `==` 判断，我得用什么？在 String 里面我们曾经学习过一个方法，是不是那个 `equals` 啊？

```java
if (stu.getId().equals(id)) {
    return i;      // id 一致，把当前索引返回，方法结束
}
// 如果我当前集合里面的 id 跟我要查找的 id 是一样的，就直接 return i，方法结束
```

那么你来看，现在呢我是把多个方法写在一行了，这种写法在我们后面会经常的用到，它是什么意思呢？其实你这么来看要一步一步地看：`stu.getId()`，那么当这个方法运行完了之后，你得到的是什么？是不是学生的那个 id 啊？那个 id 是一个字符串类型，所以说当这段代码执行完毕之后，相当于呢我就是获取到了字符串类型的 id，然后我可以用这个字符串 id 再去调用 `equals` 方法。所以此时在这儿我能调用 `equals` 的原因，其实呢就是拿着前面的这个结果去调用 `equals` 方法。

那像这种写法叫做**链式编程**，其实呢说白了就是把多行代码写在一行当中。

好，那么这样的好处呢，就是可以少定义几个变量。因为你要这么想，如果说我不这么写的话，你要怎么办？我是不是要在这个上面先去用 `stu.getId()`，先用一个变量去记录一下，然后呢在判断里面再去用这个变量点 `equals`，再去跟那个 id 进行比较。那如果说哥们我英文不好，每一次起名字感觉非常的痛苦，对吧？那这个时候怎么办？那你就不要去定义这个变量了吗？直接用链式编程，这就可以了，用前面方法的结果直接调用后面的方法。非常的简单。

> **结论**：链式编程的核心逻辑，就是利用前一个方法的结果，继续调用后面的方法。

好，那么继续往下，我们继续写 `if` 里面的代码。如果我当前集合里面的 id 跟我要查找的 id 是一样的，那怎么办？此时我就直接 `return i`，方法结束，把当前的索引进行返回，这就OK了。

那么还有一种情况，就是当我循环结束了，我还没有找到你当前的 id，那这个时候怎么办？这个时候呢就表示要查找的 id 是不存在的，我就直接返回一个 -1，这就OK了。

在这个过程当中，一定要切记，你不能把那个 `return -1` 直接写在这个 `else` 当中。如果你写在这儿是什么意思呢？就是我刚找完 0 索引，0 索引没有，0 索引不是，我就认为你不存在——这不合理啊。什么时候才能说我当前的 id 在集合里面不存在？你是不是要把集合找完了，你才能说呀？所以 `return -1` 咱们只能把它写在循环的外面，因为只有循环结束了，才能表示我集合里面所有的数据才找完了。我们把这个注释呢去写全：就是只有当循环结束了，才表示集合里面所有的元素找完，在这个时候如果说还没有找到，才表示要查找的 id 是不存在的，我直接 `return -1`。

> **易错点**：`return -1` 必须写在循环外面，不能写在 `else` 里面。写在 `else` 里的意思是"刚找完 0 索引没有，就认为你不存在"，这不合理。
