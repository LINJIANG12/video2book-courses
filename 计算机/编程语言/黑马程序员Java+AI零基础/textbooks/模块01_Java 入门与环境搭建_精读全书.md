### 一门新课为什么挑在现在上线

我是黑马程序员阿伟。今天要宣布一件大事——新课《Java + AI：从入门到大神》，正式上线了。

这是一本面向普通人的 AI 教材，并且能修炼到达成的武功秘籍。这套课这次不只教你 Java 知识，还要教你**用 AI 去学 Java、用 AI 去做开发**，让 AI 成为你的超级大脑。

开课之前，我想先花三分钟把三个问题跟你讲清楚：2025 年，我们为什么一定要去学习 Java？学 Java 为什么一定要学 AI？Java 和 AI 这两者又是什么关系？

先从政策说起。2025 年 7 月 31 号，国家发布"人工智能+"新政策，大力推进人工智能规模化商业化应用，推动人工智能与各个行业深入整合，让目前大多数的传统项目进行智能化的升级。

那这个政策跟我们有什么关系呢？

这已经不是第一次了。早在 2015 年的时候，国家同样发布了"互联网+"。也正是因为有大方向的指引，才有了互联网蓬勃发展的 10 年。毫不夸张地讲兄弟们，目前 90% 的同学吃的基本上都是这个红利。那么现在，同样的风向又开始了。

那什么是人工智能呢？是机器学习、深度学习这些飘在天上的算法？还是图像识别、语音识别，又或者那些憨态可掬的机器人呢？

这些当然都是。但**更多的 AI 是跟各个行业深度融合、给各个行业赋能**。正如之前的互联网一样，互联网去改变了各个行业信息承载、交流的方式，那人工智能同样会推动各个行业的变革。

| 行业 | 从前的样子 | AI 进来之后 |
| --- | --- | --- |
| 电商 | 不知道自己穿这件衣服好不好看，只能买了就退，货物的成本和时间成本被大大推高 | 用 AI 虚拟试穿，把自己的数字人形象传上去让数字人穿一穿，还能更换不同背景，退货率降下来，商家成本也跟着降 |
| 物流 | 库存压着，周转慢 | AI 智能仓储管理系统，降低商品的库存率，提高周转率 |

诸如此类的场景还有很多。所以你看，AI 不是飘在天上的概念，它正在实打实地改造一个个行业。

### 为什么这波智能化升级的主力军是 Java 工程师

那么这样的技术革命，到底由谁来主导呢？必然是 Java。原因是三条。

第一，Java 是企业级项目的绝对主力。Oracle 官方数据显示，全球 90% 的传统企业都是基于 Java 去开发的。这些软件在进行智能化升级的时候，首选语言必然是原有的技术栈，也就是 Java，这样才能确保更好的稳定性、兼容性，从而平滑过渡。

第二，Java 工程师的规模是最大的，生态是最成熟的。Java 具有全球最庞大的开发者群体和高度成熟的技术生态，企业招聘更容易，人才供给非常充足。

第三，Java 工程师最懂企业的智能化升级要求。工程师既懂业务又懂 AI，而 Java 工程师因为长期耕耘在服务器端，是最懂项目业务的那批人。

这些判断并不是我们凭空臆想的。一份由大型 Java 平台提供商发起的调查显示，50% 的组织使用 Java 去构建 AI 功能；在以 Java 为中心的企业当中，AI 开发的使用量已经超过了 Python 和 JavaScript。GitHub Copilot 的 CEO 在受访时也明确表示，Java 语言很有可能在未来一年半的时间内，成为人工智能开发领域的 number one。

课程团队敏锐地把握住了这一趋势，早在 2024 年就与多家大厂深度合作，历经多版本迭代，共建出符合当下市场需求的 AI 智能应用开发 Java 课程，致力培养精通 Java 和 AI 的复合型人才。

> **结论**：从 2015 年的"互联网+"到 2025 年的"人工智能+"，AI 时代的风口已经到来。未来最大的机会、最赚钱的公司、最高薪的岗位，都将从这里诞生。如果你已经错过了互联网+，千万不要再错过人工智能+。

### 计算机语言到底是什么东西

那什么是计算机语言呢？

> **定义**：计算机语言就是人与计算机之间进行信息交流、沟通的一种特殊语言。简单理解就是计算机能听得懂的话。

举个例子。比如说哥们儿现在要看电脑上的这个视频了，你说怎么办？你能直接跟它喊吗？肯定不行。计算机听不懂人类的语言，它肯定一脸懵逼。我们只能通过计算机语言去告诉它，它听懂之后就会把这个视频给打开了。

说到这里，很多兄弟还是有一丝丝小疑惑：很多哥们儿会想，我平时也没有用计算机语言也能看视频啊，我用视频播放器不就可以了呀。

是的兄弟，你说的没错。但是你造吗？如果咱们把这个软件拆解开，你会发现，其实都是我们程序员提前写好的代码，而这些写好的代码就是计算机语言。只不过是程序员把这些计算机语言打包起来了，才形成各种各样的软件供我们使用。

所以等到咱们当上程序员了，其实就是写各种各样的软件供别人使用。

讲到这里，我相信大家已经能理解什么是计算机语言了。而 Java，就是众多计算机语言当中非常哇塞的一个。

### Java 能做什么，又为什么值得学

那为什么它非常哇塞呢？还得从 Java 能做什么开始说起。它能做的事情非常非常多：大数据开发、安卓移动端开发、游戏开发——大名鼎鼎的《我的世界》就有用 Java 开发出来的版本——当然还有最重要最重要的企业级服务器开发。

不管是大型、中型还是小型的公司，基本上都会有 Java 的岗位。多到什么程度？我们可以设想一下：如果我们把全世界用 Java 开发出来的软件全部删掉，那么兄弟，这个事儿就大了，全球都会引起一系列系统性的灾难。

金融体系（银行、证券、保险）、航空系统、医疗系统、教育系统，大多数的电商平台和社交网站，还有几乎所有的安卓 App，都会处于停摆状态。上到高层管控，下到我们衣食住行，都会受到非常大的影响。所以可想而知，Java 的应用之广泛，没有任何一款编程语言能跟 Java 去媲美。

当然，这个世界上没有完美的东西，Java 也有自身的缺点，这个在上一节当中曾经阐述过，这里就不多做赘述。

那而在当前的 AI 时代下，众多公司现有的项目都要进行智能化的升级，Java 又迎来了第二春。所以利用 Java 去开发智能化应用，是我们普通学历的兄弟能吃到 AI 红利的最好方式。

> **结论**：在学习完了 Java 之后，我们的就业方向尽可能不要去做一些传统的领域了，而是要往 AI 智能化应用发展，这样才能吃到当前的红利。

### JDK 是什么，从哪儿下、怎么装

在刚刚我们已经初步了解了 Java，但是哥们儿我就按捺不住内心的骚动，想要写代码来爽一下。

但是代码不是随随便便你想写就写的，咱哥们儿得先搭建环境、做一些准备工作。

为什么呀？你想啊，如果说哥们儿想要玩一把游戏，你能直接开始玩吗？不可能吧，是不是也得先到官网当中去下载安装包，安装之后才可以开始玩呀？Java 其实也是一样的。

所以请按捺住内心的骚动，咱哥们要先下载并安装相关的软件。要下载的软件叫做 JDK，全名叫做 Java Development Kit，翻译过来就是 Java 开发者工具包。

嘿嘿，开发者——这不就是咱们吗。

这里的 Oracle 呢，是一家公司的名字，它是全球前十的软件公司。在 2009 年 4 月份的时候，它用 74 亿收购了 Sun 公司，所以说现在 Java 的版权归属于 Oracle。咱哥们要到它的官方网站当中去下载。

```text
浏览器地址栏
    │
    ▼
Oracle 官网首页
    │
    └──► Products（产品，会拉出一个下拉框）
             │
             └──► Java
                    │
                    └──► Download Java
                           │
                           ├──► 最新的版本：JDK 25（LTS）
                           │
                           └──► 下方按操作系统分栏
                                  ├── Linux
                                  ├── Mac（苹果）
                                  └── Windows
                                        │
                                        ├──► 第一个链接：zip 压缩包 —— 不用管它
                                        ├──► 第二个链接：标准安装包
                                        └──► 第三个链接：exe 安装包 —— 点这个
```

只不过它的版本比较多，那你说我们该怎么选择呢？其中有几个非常重要的版本兄弟们需要记录一下：JDK 8、11、17、21，以及现在最新的 JDK 25。这些版本它是 LTS 版本，其他都是普通版本。

那什么是 LTS 版本呢？它是长期支持版本（Long Term Support）的意思，也就是说 Oracle 官方会长期维护这几个版本，有什么 bug、有什么问题，都会及时地修复。所以说这些版本相对比较稳定，也是企业开发的首选。

到目前为止，在企业当中 JDK 17 是用得最多的；但是我们现在在学习阶段，会用最新的长期支持版本 JDK 25。这样呢，除了企业里面用到的东西，我们也能学习到一些新的东西。

下载了对应的版本之后就可以直接安装了。安装非常简单，直接傻瓜式安装，点击下一步就可以了。只不过哥们儿我温馨提示两点：

**第一，安装的路径不要带有中文、空格或者一些特殊的符号。** 因为这些软件是老外编写的，对中文的支持还不够完美，如果你的路径当中有中文，以后使用的时候容易会出现一些问题。在选择路径的时候，你就写英文单词，或者是再加一些 1234 这样的数字就可以了。

**第二，以后我们会安装很多很多跟开发相关的工具，今天呢我们要至少安装两个**——一个就是现在的 JDK，还有一个就是我们下一个环节要装的心爱的 IDEA，类似这样的工具以后还会有很多。所以建议大家可以找一个文件夹统一管理，以后方便好找。

```text
E:\develop\            ← 所有跟开发相关的软件都放这一层
   ├── jdk\            ← JDK 安装目录
   │     └── bin\      ← bin 里面才是 java.exe 等可执行程序
   └── idea\           ← IDEA 安装目录
```

那么接下来咱们就把 JDK 的下载和安装演示一下：打开浏览器，在地址栏输入官方网址回车，点击 Products 往下拉，点击 Java，这时 Java 的下载页面就出来了，点击 Download Java。往下看，最新的 25 版本出现了，这就是 JDK 25，它是目前最新的最后一个长期支持版本。再往下是针对不同操作系统的安装包：Linux 的、Mac 苹果的、还有我们 Windows 的。如果你的电脑跟我一样是 Windows 版本，就选择第三个。

在下面会出现三个下载链接：第一个是一个 zip 压缩包，下面的两个才是我们标准的安装包，我们通常下载 EXE 就可以了，点击它就可以开始正常下载。

当然不需要同学们自己下载，在今天的资料当中我已经给大家准备好了：打开今天的资料 → 第一章 Java 初入门 → 资料文件夹 → 安装 JDK，里面安装包（就是我们刚刚下载的 EXE）和非常详细的安装教程文档都已经给大家提供好了。

接下来我们安装一下：双击打开安装包，稍等几秒钟，安装向导就弹出来了。点击"下一步"，注意这个界面会让我们选择安装路径。如果没有选择，默认是装到 C 盘的，这不是我想要的。在刚刚我们曾经说过什么，你还记得吧——所有跟开发相关的工具，我们尽可能都放在同一个文件夹当中，方便管理。所以我要点击这里的"更改"，在 E 盘 develop 这个文件夹里面新建一个文件夹叫 JDK，点击"确定"，安装路径就修改好了。再点击"下一步"，耐心等待，等进度条读满了就成功了。当我们看到这个界面，就表示 JDK 已经安装完成，点击"关闭"。

接下来验证一下是否安装成功：找到我们刚刚的 `E:\develop\jdk`，打开里面的 `bin` 文件夹，点击上面的输入框输入 `cmd` 回车，在这个黑窗口中输入命令：

```bash
java -version
```

看第一行输出 `java version "25..."`，正好说明我刚刚安装的就是 25。这个版本是 2025 年 9 月 16 号发布的 LTS 长期支持版本。当我们看到这些信息之后，就表示我们刚刚的 JDK 真的安装成功了。

现在请大家暂停一下，动手操作起来吧。

### 环境变量到底是什么

在刚刚我们已经安装了开发所需要用到的 JDK，接下来我们就要把 JDK 配置到环境变量当中。

其实直接配置环境变量是非常简单的，无非就是找到环境变量的位置，然后再复制粘贴保存，这不就完事儿了吗？但这不是哥们儿我想要的效果。

我想要咱们兄弟们能知道它是什么、为什么要配，这样你才能达到举一反三的目的。要不然你听完了跟着配完了，过两天你就忘了——那种知识不过脑子的感觉虽然很爽啊，咱哥们不要哈，咱哥们要知道它是什么、为什么要配。你知道这些了，我相信你的印象会更深。

所以接下来我会用一个小故事去穿插一下。先知道配置环境变量的作用、什么时候去配，然后再去实际的操作。开始来了哟。

假设哈，假设咱各位兄弟的电脑当中有很多的大片儿，比如说像金刚狼呀、钢铁侠呀这些。但是呢，这些片儿哥们儿我只想一个人自己看，我不想给别人看。那你说你怎么办？你能直接把它放到桌面上吗？肯定不行啊，别人如果在用你电脑的时候一下子就看到了呀，不安全。

所以一般来讲，咱兄弟们一般会把它放到一个很深很深的文件夹当中。但是这又会引来一个新的问题：时间长了，哥们儿我忘了怎么办？

很多兄弟想：那简单啊，哥们儿我把它记录在一个本子上，用到的时候翻一翻，这不就 O 了吗。

但是兄弟，如果我跟你说，不需要你自己记，咱们自己的电脑当中，它自带一个记录各种路径的表格，你会怎么想呢？

> **定义**：这个表格其实呢就是环境变量。所以所谓配置环境变量，其实就是把这些路径写到这个表格当中。

一旦记录了，好处就是：在以后不管你的电影放在哪儿，不管它的层级有多深，不管你还记不记得它的位置，哥们儿我随时随地都能够打开。因为 Windows 操作系统它会到环境变量当中去找你现在要打开的文件。

这里还要分清一个容易混的点：环境变量分为两种，上面的是自己用户的变量，下面的是系统级别的。

| 配置在哪 | 谁能用 |
| --- | --- |
| 上半部分：用户变量（自己用户的环境变量） | 只有我当前的这个用户能用 |
| 下半部分：系统变量（系统环境变量） | 电脑里如果有多个用户，就都可以使用了 |

所以呢我们可以把它配置到下面去。

所以说呢，一会我们要实际操作的步骤有以下的两步：**第一步**，咱哥们要把电影配置到环境变量当中；**第二步**，我要在任意的位置去打开这部电影。那怎么办呢？不着急，咱们挨个来操作一下。

### 亲手配一次：路径怎么填

在这里呢哥们儿已经准备好了几个电影，是放在 D 盘下的 QQ 目录里的 `resources\app\app_launch` 下面。现在我要把 `aaa.mp4` 去配置到环境变量当中。

**第一步，复制它的路径。** 右键点击 `aaa.mp4` → 选择"属性" → 点击"安全"，把它前面那一节路径 Ctrl+C 复制下来。

> **易错点**：注意复制的是不带自己名字的，也就是前面的这一节，别把文件名也带上。

**第二步，粘贴过去。** 打开我的电脑 → 右键空白处 → 点击"属性" → 找到"高级系统设置"。

> **提示**：我现在用的电脑是 Win 11，高级系统设置在这个位置；如果兄弟们电脑用的是 Win 10，那么它是在左上角，差不多在这个位置。但是不管你是 Win 10 还是 Win 11，点进来之后这个界面都是长得一样的。

在打开的窗口里选择"高级"，点右下角就能看到"环境变量"，点击它。找到这里的 Path，双击点开，或者是选中它点击右边的"编辑"，这都是可以的。你看这里是不是相当于就是一个表格，记录了好多好多的路径啊。那现在只要点击"新建"，把刚刚复制的路径 Ctrl+V 粘贴过来，点击确定、确定、确定。此时环境变量就已经配置成功了。

#### 命令行找不到文件时按什么顺序找

配完了要做第二步——打开。怎么打开？不要用鼠标在这里双击打开，我们要去找电脑里的黑屏窗口：按快捷键 Win + R，左下角就出现了一个运行窗口，在里面输入 `cmd` 回车，或者是点击这里的确定，一个黑屏的窗口就出现了，它也可以去操作我们的计算机。

它默认操作的是 C 盘下的 user 下的当前用户文件夹。我当前的电脑是叫"阿伟"，所以它默认操作的就是 `C:\Users\阿伟` 这个文件夹；那如果说你的电脑叫 admin，它默认操作的就是 `C:\Users\admin`。

那么如果我在后面直接写 `aaa.mp4`，表示我要打开这个文件，它会有几步操作：

```text
在任意目录输入  aaa.mp4  然后回车
        │
        ▼
① 先在当前文件夹里找 aaa.mp4
        │
        ├── 找到了 ─────────────────────► 直接打开，完事
        │
        └── 没找到
              │
              ▼
② 再到环境变量 Path 里，从上往下一条一条地找
        │
        ├── 第①条路径里有 aaa.mp4 吗？ ──有──► 打开，完事
        ├── 第②条路径里有 aaa.mp4 吗？ ──有──► 打开，完事
        ├── 第③条路径里有 aaa.mp4 吗？
        │           ...
        └── 一直找到最后一条，还是没有
              │
              ▼
   'aaa.mp4' 不是内部或外部命令，
   也不是可运行的程序或批处理文件。
```

看，这就是我自己准备的一个"原神启动"。那么这个呢，其实就是配置环境变量的目的。

那有同学想了，那如果说我没有配置环境变量，会出现一个什么样的问题呢？我们也可以来演示一下。QQ 目录的 `resources\app` 这个里面呢有一个 `qqq.mp4`，那你要注意，`qqq.mp4` 它不是在这个路径下的，它是在 app 这个路径下的（右键属性 → 安全，可以看到它的完整路径）。我们现在并没有把 app 这个路径去配置在环境变量当中，于是在环境变量当中输入 `qqq.mp4` 回车——你看，它就会报错：不是内部或外部命令，也不是可运行的程序等等一大堆。

简单理解就是：他在当前的这个位置里面没有找到 `qqq.mp4`，而且在环境变量当中也没有找到，所以说他就直接报错了。

> **结论**：配置其实非常简单，无非就是两步——第一步复制文件的路径，第二步把它保存到环境变量当中。一旦配置完毕，此时我就可以在任意的位置都可以打开配置的文件。因为他首先会在当前的文件夹里面找，如果没有，就会在环境变量里面一个一个从上往下挨个去找；如果你配了，那就能直接找到。

好了各位同学，大家动手操作一下。其实兄弟们如果学完这个知识点之后，你可以玩很多很多的骚操作：以后咱哥们如果说要在电脑里面藏点东西，你说这不就轻而易举了嘛，电影啊、游戏啊我都可以藏起来，而且电脑随便你查，干干净净什么都没有。一旦有时间，哥们就可以直接"原神启动"、"英雄联盟启动"、"Steam 启动"，你说对吧。

### 把 JDK 装进环境变量

在刚刚咱哥们已经学习完了环境变量，我们知道它其实就是操作系统里面的一个表格，用来记录各种软件的路径。现在我们要把 JDK 配置到环境变量当中，这样咱们就可以在任意位置都可以使用 JDK 了。

那要注意的是，现在我们真正要用到的软件不是 JDK 的安装根目录，而是它 `bin` 文件夹底下的 `java.exe`。所以我们要把 `java.exe` 的路径配置到环境变量当中：右键点击 `E:\develop\jdk\bin` 里的 `java.exe` → 选择"属性" → 点击"安全" → 把前面这一串 Ctrl+C 复制下来。

在配置的时候呢，咱哥们要注意，我们要比刚刚的步骤要多一步。

#### JAVA_HOME 与 Path 分别填什么

我们不要一上来就双击 Path 在这个里面配。

**先配 JAVA_HOME。** 在环境变量上半部分点击"新建"，变量名输入 `JAVA_HOME`，下面的变量值把刚刚复制的路径粘贴过来，只不过要把后面的 `bin` 删掉——这样才是我们真正 JDK 的安装路径，也就是 `E:\develop\jdk`。

> **提示**：配置 JAVA_HOME 其实是为了以后的软件去服务的，比如说 Maven 呀、IDEA 呀，用到的时候咱哥们就知道了。现在我们先配置一下。

**再配 Path。** 找到 Path 里面的那个路径，这个路径其实是之前我们安装 JDK 的时候它自动去配置的，这不是我想要的。我可以选中它，再点击右边的"删除"把它删掉，然后点击"新建"，把我们刚刚复制的路径粘贴在这个地方。

> **易错点**：注意了，这一次后面是**要加上 `bin` 的**，也就是 `E:\develop\jdk\bin`。

然后呢再去把它"上移"，上移、上移、上移，移动到最上面。

> **提示**：这样可以提高它的查找效率。因为它在查找路径的时候是从上往下一个一个去找的，它在查找的时候第一个就能找到了，下面就不需要再找了。

整理成一张表，这两个千万不要搞混：

| 变量 | 填什么 | 例子 | 作用 |
| --- | --- | --- | --- |
| `JAVA_HOME` | JDK 的安装路径，末尾**不带** `bin` | `E:\develop\jdk` | 留给以后的软件读，Maven、IDEA 都要用它 |
| `Path` | `java.exe` 的路径，末尾**带** `bin`，并且上移到最前面 | `E:\develop\jdk\bin` | 让系统在任意位置都能直接敲 `java -version` |

再点击确定、确定、确定，把它给关掉。

配置完了之后我们可以检查一下：按 Win + R，`cmd` 回车，在这个 `C:\Users\阿伟` 的路径下直接去执行 `java -version`，你看到它出了一大堆的文字，那么就表示我们的环境变量配置成功；而且我们可以用最一开始我们曾经输入的命令 `java -version` 去查看一下我们 JDK 的版本，看这里完全没有任何问题。

> **易错点**：如果说在座的兄弟们配置的时候出现了这么一个提示，比如说它说 `java` 不是内部或外部命令，也不是可运行的程序或者是批处理文件——出现这个就表示兄弟你的环境变量配置错了，你需要把它去删掉，重新搞一搞。

#### 为什么不用 %JAVA_HOME%\bin 那种写法

配完了之后呢，有很多兄弟会感觉到一丝丝的小疑问，说："阿伟呀，不对呀，我看到其他课程里面的那个 Path 不是这么配的呀，他是这么配的：`%JAVA_HOME%\bin`。"

其实呢这种方式跟我配置的是一样的。这里两个百分号它表示引用，相当于就是把上面 `JAVA_HOME` 后面的这个值给引用过来，再跟后面的 `\bin` 做一个拼接，你看实际的效果就是这样的：

```text
写法一（本课程采用）
  JAVA_HOME = E:\develop\jdk
  Path      = ...; E:\develop\jdk\bin
                        ↑
        完整路径直接写死，不依赖任何引用

写法二（% 引用）
  JAVA_HOME = E:\develop\jdk
  Path      = ...; %JAVA_HOME%\bin
                        ↑
        运行时先把 %JAVA_HOME% 展开成 E:\develop\jdk，再拼上 \bin
        最终效果和写法一完全一样
```

只不过呢，这种配置方式有一个小问题，就是部分的 Win 10 系统它会有一个 bug：电脑重启完了之后，你这个环境变量它就失效了。所以说呢，我们为了避免这个 bug，采取一个非常保险的方式，就是这种把完整路径配置在 Path 当中，这样几乎所有的 Win 10 系统都不会出现问题。所以呢，请兄弟们按照我这种方式进行配置就可以了。

现在呢就请大家暂停一下，把 JDK 配置一下吧。

### IDEA：为什么记事本写代码纯属"没苦硬吃"

在刚刚咱哥们儿已经安装了 JDK，并且也把它配置到了环境变量当中。那么其实呢，现在我们就可以结合 Windows 里面自带的记事本去写代码了。

但是如果哥们儿你真的这么干了，纯属于"没苦硬吃"，因为写代码太不方便了：

| 写代码时遇到什么 | Windows 记事本 | IntelliJ IDEA |
| --- | --- | --- |
| 有的单词我忘了 | 它不能给我提示 | 自动补全，少背很多键 |
| 单词写错了 | 也没有正确的提醒 | 会有红色波浪线的提示，当场就标出来 |
| 代码格式 | 还需要我自己手动去调整 | 特定格式的语句有快速的生成方式，一个回车直接生成，减少咱哥们的记忆 |
| 一些特殊的单词 | 也没有高亮的显示 | 语法高亮，一眼分辨关键字和普通标识符 |

所以我们要更换一个高级的开发工具——我们心爱的 IDEA，全称 IntelliJ IDEA。它是业内公认的 Java 开发最好用的工具，没有之一。而且更重要的是，现在几乎所有的企业都在使用它来写代码，老厉害了。

而且在心爱的 IDEA 当中，我们还可以安装 AI 的插件，利用 AI 去帮我们写代码、分析代码、修改错误，那个爽感不要不要的。

那么接下来我们就要来下载并安装心爱的 IDEA。登录 IDEA 的官方网站 `www.jetbrains.com.cn`，点击"开发者工具"，再点击"IntelliJ IDEA"，就会跳转到下载界面。此时我们就可以根据自己的操作系统，选择不同的版本去下载了。Windows、Mac、Linux 不同操作系统的安装包其实都可以下载，如果你跟我一样是 Windows 的，直接选择 Windows 再点击下载就可以了。

安装包同样不需要大家自己去下载，在今天的资料当中哥们儿已经给大家准备好了：Day01 资料文件夹 → 安装 IDEA，里面它的安装包、激活包，还有它的安装文档，全部都在这个地方。

下载完毕，傻瓜式安装，直接点击下一步。只不过呢，同样的规则：安装的时候最好不要有中文、不要有空格、不要有一些特殊的字符；最好把跟开发相关的所有软件都放在同一个文件夹当中，方便管理。

```text
E:\develop\            ← 所有跟开发相关的软件都放这一层
   ├── jdk\            ← JDK
   │     └── bin\      ←     里面的 java.exe 已配进 Path
   └── idea\           ← IDEA 这次也装在这儿
```

具体操作：打开浏览器，点击"开发者工具" → 选择"IntelliJ IDEA" → 点击"下载" → 选择 Windows → 点击下载。双击打开安装包，稍等一下，等它读到 100% 就 OK 了，好那么现在安装向导已经打开。点击"下一步"，在这个界面当中我们要去选择安装路径——还是一样的，我要把它安装到 E 盘 develop 文件夹里面，在里面新建一个文件夹，名字呢就叫做 idea，点击确定。

再点击"下一步"。这个界面兄弟们要注意了：勾选的时候，我们只要勾选一个地方，就是左上角这里"创建桌面快捷方式"，这就可以；其他所有的地方都不要去勾。再点击"下一步"，点击"安装"，稍等一下，等它的进度条读满了，就表示我们心爱的 IDEA 安装成功。你看这里提示"IntelliJ IDEA 已经成功安装到本机"，点击完成，回到桌面，看这里桌面当中出现了 IDEA 的图标，那这就表示我们 IDEA 安装成功了。

到这里，JDK 装好了，环境变量配好了，IDEA 也装好了。接下来我们就要真正地去用 IDEA，去写我们的平生第一个 Java 代码了。

## 从 Hello World 到 AI 助手：写好第一个 Java 程序
> 对应块：BLK02 | 覆盖分集：P07-P11 | 块标题（分集名）：《第1章-入门篇-06-HelloWorld》

IDEA 刚刚安装完毕，按捺不住内心的骚动，想写代码来爽一下。那我们就正式开始，写平生第一个 Java 程序——输出一个单词 `hello world`，跟这个世界打个招呼。哥们儿，我来啦。

### 为什么第一个程序总是 Hello World

写到这儿我好好奇啊：为什么输出的是 `hello world` 这个单词？我就不能输出一些其他的东西吗？比如阿伟好帅、阿伟 1 米 93、阿伟 GIGGI——这不比 hello world 强啊？

还真不是你随便改的。这个规矩来自 C 语言之父 Dennis Ritchie 编写的一本非常经典的 C 语言书籍《C 程序设计语言》，在这本书当中，第一个程序代码就是输出一段话 hello world。而 C 语言又是其他编程语言的鼻祖，所以后来出现的 Java、Python、C# 等等等等，都延续了这样的一个传统，把 hello world 当作是入门的第一个代码。

> **结论**：hello world 不是 Java 独创的规矩，是从 C 语言那边继承下来的入门传统。

我们利用心爱的 IDEA 编写这段代码，目的其实有两个：一是用一段最简单的代码去熟悉 IDEA 的基本使用——哥们我该如何创建、如何编写、如何运行、如何查看结果；二是知道写代码的时候代码整体的结构长什么样。在以后所有的 Java 程序里，我们其实都可以仿照 hello world 的格式来进行编写。

### 项目、包、文件：先把架子搭起来

说到 IDEA 的使用，一开始只要注意几个层级。

先说什么是项目。我们平时看到的所有的软件，在开发的时候它都叫做一个项目。比如说《原神》这个整个游戏，我就可以把它认为是一个项目。

项目有了，哥们就可以直接在里面写代码了吗？还不能。因为你要想，一个项目里面的代码是非常非常多的，成千上万个。那如果说成千上万个文件全都放在一块儿，以后你怎么办啊，找都没法找。

所以说在项目里面，我们会新建很多的包——就是文件夹，用来分门归类的。比如现在我就可以新建三个文件夹：动画、时间、文本，把动画相关的代码放在第一个包里面，把时间相关的放在第二个，把文本相关的放在第三个，方便管理。在包里面我们就可以新建后缀名为 `.java` 的文件，这样才正式开始真正的去编写代码。

```text
项目 Project ─── 一个软件在开发时的称呼，比如整个《原神》
   │
   └─ 包 Package ── 项目里的文件夹，用来分门别类
        │             动画 / 时间 / 文本，各归各的
        │
        └─ 文件 .java ─ 代码真正写在这里的地方
```

新建项目的界面上，我们只要注意两个点：第一个，给自己的项目起个名字（比如就叫 `hello world`，作为平生第一个项目）；第二个，把 `Add sample code` 前面的勾去掉——不要它给我们添加示例代码，所有的代码我要自己手写。

`location` 是问你项目保存在哪里，不管它直接默认就可以了；但如果要把位置改到 D 盘、E 盘、F 盘，点后面那个像文件夹的图标就可以任选。往下 `Build system` 保持默认的 IntelliJ，`JDK` 选我们刚刚装好的 JDK 24。点 Create，右下角的进度条耐心等它读满、消失，第一次登录就 OK 了。

第一次登录还会弹一个插件提示，问你要不要把它改成简体中文版。这个一般是不需要的，把它叉掉就可以了。有同学说英文界面看不懂——没关系，兄弟用着用着就熟了。我们经常操作的无非就那几个功能，而且更重要的是，以后在企业里面大家用的基本上都是英文版本的，你说你老用一个中文插件的，那不太合适对吧。

进入代码界面以后，有两块地方现在必须掌握：左边是项目结构区，以后一个完整项目里到底有哪些文件夹、文件夹里有哪些文件，全部在左边罗列出来；右边是文本编辑区，以后写代码就在右边这个区域书写。

```text
+-------------------------------------------------------+
| File  Edit  View  Run                     [Run]    |
+----------------------+--------------------------------+
| 项目结构区           | 文本编辑区                       |
|  src                 |   public class HelloWorld {      |
|   └ com.itheima      |   public static void main( ){    |
|      └ test          |     System.out.println("hi");    |
|        └ HelloWorld  |   }                              |
|                      | }                                |
+----------------------+--------------------------------+
| 控制台 Console                                       |
|   hello world                                         |
|   Process finished                                    |
+-------------------------------------------------------+
```

项目建好了，接下来是建包。包在 `src` 下面，`src` 就是源代码的意思，以后我们写的所有代码全部是在 src 这个文件夹里面的。右键 src → New → Package，给这个包也就是文件夹起个名字。

> **提示**：包名随便起，abc、bcd 都行。只不过在我们企业级开发当中，起包名一般会有一个规则，就是公司域名的反写。比如黑马学习，黑马的官方网站是 www.itheima.com，所以我要把这个域名反过来写：先写 com，再写 it、heima，www 就不要了，这叫做域名的反写；后面再加包的作用。现在哥们要写 hello world 是一个小练习，所以后面就叫 test，最终得到 `com.itheima.test`。

这里有个小技巧要记住：你现在新建的包其实是多级包。右键点击它 → Open in → Explore 打开本地目录，你会发现刚刚实际上在 src 里面新建了 com，com 里面有 itheima，itheima 里面有 test。多级包之间是用点来进行间隔的。

### 写出并运行第一段代码

在包里面右键 → New → Java Class，起个名字，回车。

> **易错点**：我们所写的代码，需要在这一对大括号里面。这一对大括号表示的是一个范围，你不能写在它外面，写在外面就出错了。

在编写代码的时候，没必要一个单词一个单词地写—we心爱的 IDEA 它有自动提示。首先我们先写 `psvm` 一个回车，你看这就生成了；然后再写 `sout` 再来一个回车，在小括号里面我就可以直接写上 hello world。

这几行代码具体是什么意思，这个不着急，下一个知识点会挨个跟大家讲解，现在先按照我的方式书写就可以了。

```java
package com.itheima.test;

public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("hello world");
    }
}
```

#### 三种运行方式

写完了我要运行，运行有三个地方：

- 右键空白处 → Run，选这里的 `HelloWorld.main`，点一下；等右下角进度条读满、消失，就 OK 了。
- 左边项目结构区里，类名前面有一个绿色小箭头，随便点击哪一个，点击一下，再选 Run HelloWorld、点 main，结果照样能看到。
- 右上角也有一个绿色小箭头，点一下，当前的程序也会直接运行。

运行之后出现的是控制台，程序的运行结果就在这里面。第一行不用管，那是程序的一些运行信息，比如说 JDK 的位置；从第二行开始就是我们程序运行的结果；第三行是说你这个程序运行结束了。所以说真正要看的是第二行。

那如果想换一个内容呢？比如我要输出"你好你好"，咱们只要把双引号当中的内容进行更改就可以了，右键一个运行，你看"你好你好"这就出来了。

#### 这一讲要掌握的知识点

利用 IDEA 编写我们第一个代码 Hello World，需要大家掌握的知识点有两个。

第一个是 IDEA 的基本使用：能知道如何新建一个项目、如何新建包、如何新建一个文件，并且在文件里面写代码。

第二个是 Hello World 这个程序本身。书写的时候你要跟我保证完全一致，每一个单词、每一个标点符号全部都要一样。

> **易错点**：特别是标点符号，所有的标点符号一定要是英文状态的。如果你是中文状态下的标点符号，那么程序它是有红色波浪线报错的。唯一能修改的地方就是双引号里面——如果说你想输出的结果不是 hello world，是其他的 abc、123 或者阿伟 gig，那么你可以改双引号里面，其他的地方请不要去修改。

### 把 IDEA 调成自己顺手的模样

在刚刚编写的时候有一内内的小不方便，所以接下来要对 IDEA 做一些设置：默认的主题是黑色的，晚上用还行，白天用时间长了眼睛会有点累；另外默认的字体太小了，我能不能变大一点呢？当然是可以的。除此之外还有提示忽略大小写，以及安装 AI 的插件。

要注意了，IDEA 所有的设置全部都在 settings 里面：点击左上角的四道杠把菜单打开，选择 settings。

**主题**。点开第一个 Appearance（外貌）里的 Appearance，在右边找到 Theme，默认的是 Dark 暗黑的主题，这不是我想要的。我个人比较喜欢 Win10 高亮的版本，但这里没有，所以点 `Get more themes` 去获取更多的主题，搜一搜叫 win10，找到 `Win10 Light` 点 install，一下子就设置完了，点 OK。

**字体**。同样的四道杠 → File → Settings，在上面直接搜索 `font` 回车。先点后面的下拉框，这里有好多好多的字体，一般来讲我们程序员比较喜欢用 Consolas 这个字体，找不到的话你也可以直接搜索 `CONS`，第一个就是。接下来大小我把它设置成 17，后面还有一个行间距，保持默认的 1.2 就可以了。点 OK，你发现字体是不是大一点了。

**提示忽略大小写**。IDEA 有一个非常好用的自动提示功能：写一个单词的时候，你没必要从头到尾全部写完，只要写前面的几个，它就会有提示，一个回车就给你自动补全。只不过默认情况下，它是严格按照大小写进行提示的——比如写 `Str` 它会把 String 这个单词给提示出来，但如果前面的 `str` 我写的是小写的，你发现它就没有提示了。

所以我就想，你能不能在提示的时候忽略大小写呢？当然必须的。到 settings → Editor → General → Code Completion，上面有一个 Match case（匹配的规则），把前面的勾给去掉，再点 OK。这样以后写单词的时候，不管是大写还是小写，它都可以给你正常的提示，这个非常的好。

### 注释：写给人看的说明

接下来我们要对这段代码做一个解读，期间会涉及到两个知识点：一个是注释，还有一个就是关键字，学完这两个我们就可以解释 hello world 这段代码了。

> **定义**：所谓注释，其实就是给代码添加的解释说明性的信息。

养成写注释的习惯之后，不管是写这种简单的代码，还是以后写复杂的代码，就算时间长了哥们你忘了当时是怎么写的了，或者是别人在看你代码的时候，都可以通过阅读注释一下子就能理解这段代码的含义。通过阅读注释快速理解代码的含义，这就是注释的作用。

只不过在以后咱们变成有经验的程序员了，就没必要每一行代码都写注释了，太麻烦。只需要给每一个独立的功能去写一下就可以了，目的就是告诉别人下面的这段代码是干什么的。

像现在这样直接写一段文字嘛，肯定不是的。注释一共有三种写法：单行注释、多行注释，还有文档注释。文档注释暂时用不上，先行忽略，咱们现在只要掌握前面两个格式就可以了。

- **单行注释**：前面写两个杠杠 `//`。
- **多行注释**：开头是杠星 `/*`，结尾是新杠 `*/`，中间你就随便写了，写多少都是可以的。

如果注释的内容比较多、一行写不下了，记得要在每一行的前面都加杠杠；当然呢你也可以用多行注释，这样显得更方便一些。

```java
// 第三行代码的作用是输出一段文本
// 文本的内容就是 hello world
// 如果要修改输出的内容
// 那么直接修改双引号里面就可以了
System.out.println("hello world");
```

#### 注释的四个小细节

学完之后忍不住再补充四个小细节：注释的颜色、注释的快捷键、还有注释的运行规则以及注释的嵌套。

**颜色**。默认注释是灰色斜体，哥们我看了不爽，有一种浑身蛋疼的感觉，就想能不能把它变正了，颜色改成像文本那样的绿色，看着会舒服一点。当然是可以的。到 File → Settings 里一个个来找：Editor → Color Scheme（颜色的样式）→ Language Defaults（语言默认），把 Comments 展开，里面会有三个。点击第一个 `Line comment`，下面直接一个跳转，那就表示它是单行注释的设置；上面 `Block comment` 点一下，跳转到了多行注释，那就知道它是多行注释的设置。

那就一个一个设吧。单行注释：在右边把斜体给去掉，颜色默认是 808080 那个灰色，点击一下就可以设置成自己想要的颜色了。再来点击上面的多行注释，一样的斜体去掉，颜色也改成 2C7A06，一个回车搞定。你发现唰的一下，这个颜色就好看多了。

> **提示**：设置颜色时咱们不能选红色。因为在 IDEA 当中，只有代码错误了、出现问题了才是红色。建议大家改成绿色就可以了。

**快捷键**。在刚刚书写注释的时候，前面的杠杠是哥们自己手写的，我觉得这不方便，IDEA 能不能帮我生成呢？当然是可以的。首先我要点击一下要注释的文字，按快捷键 `Ctrl` 加 `/`，你看前面自动生成了。单行注释的快捷键就是 `Ctrl + /`。

单行注释有多行注释是不是也有呢？比如说下面我注释的内容比较多，那怎么办？你要注意它的操作方式跟刚刚不一样：刚刚是用鼠标点多行注释，多行注释是你要选中这一段文本，选中之后按快捷键 `Ctrl + Shift` 加 `/`。所以多行注释的快捷键是 `Ctrl + Shift + /`。当然 IDEA 里面还有很多很多其他的快捷键，随着课程渐渐深入我们每一个都会说，到现在需要大家掌握这两个就 OK。

**运行规则**。注释的运行规则其实就是一句话：注释不会影响程序运行的结果，它仅仅是对代码的解释说明。什么意思呢？比如举个例子，我把第 24 行这段代码给注释掉，那你觉得这行代码还运行吗？它就不运行了，右键 run，程序运行完毕，你会发现结果没有。

> **结论**：注释不会影响程序的运行结果，它仅仅是对代码的解释说明。所以在注释里面随便写什么，想写什么写什么。

> **提示**：但尽量写跟代码相关的，跟代码无关的内容你就不要再写了。

**嵌套**。这个很好理解，就是说这个注释里面你不要再写其他注释了。比如上面是多行注释，我在多行注释的里面再去写一个多行注释，你发现什么？程序都不用运行，直接报红。

为什么？因为杠星它是多行注释的开头，它会找距离它最近的那个新杠为结尾——它一路找过去，看到了新杠，就把这一段认为是多行注释，而你剩下的这一块呢光有结尾、没有开头了。

但是呢如果是单行注释的话，它就没有这样的问题：在这儿写一个杠杠，下面也写一个杠杠，在单行注释里面我再加一个杠杠，你发现它没有任何问题，程序运行完之后结果还是 hello world。但是这种方式呢，阅读起来的时候感觉太难受了，我这个地方加一个杠杠没有任何意义对吧？所以说以后咱们写注释的时候你要切记一点，不管是单行注释还是多行注释，你就不要嵌套。

### 关键字，以及 Hello World 的逐行拆解

> **定义**：关键字其实就是被 Java 赋予了特定含义的英文单词。

在书写的时候，关键字有以下的几个特点：第一，关键字的字母全部都要小写；第二，常用的代码编辑器针对于关键字都有特殊的颜色标记，非常直观。比如说我们心爱的 IDEA，对于关键字就有高亮显示。

根据刚刚这两个规则，大家能不能看一看在这段代码当中哪些是关键字呢？给大家五秒钟的时间自己思考一下。答案是那些小写的、高亮的：`public`、`class`、`static`、`void`，这些都是 Java 中的关键字。

> **提示**：在 Java 当中，关键字一共会有 50 多个。这些关键字现在不需要背，因为每一个关键字它都包含了一个甚至多个知识点，你现在就算背上了也没什么用，随着课程渐渐深入都会一一地去学习。

那我们就开始学习第一个关键字 `class`。class 关键字它用于创建一个类，或者是叫做定义一个类。

> **定义**：类是 Java 项目最基本的组成单元。任意的一个 Java 项目，如果说你把它拆开，你会发现它就是由成千上万个类去组成的。

后面 HelloWorld 就是这个类的名字，简称类名。这个名字是咱们自己随便起的，你叫 hello world、你叫 ABC，其实都是可以的。但是咱们起名字的时候要有意义——你叫 ABC，别人也不知道你这个类里面是干嘛的；如果叫 hello world，这个时候别人就知道了，这是你练习的第一段代码。

类名的后面有一对大括号，这个大括号表示类的范围，表示所有的代码全部都要写在类的大括号当中，你不能写在外面，写在外面就报错了。

#### 三行代码逐个拆

接下来用一段跟刚刚略有区别的代码来做详细解释，类名改叫 `HelloWorld2`，方便区分：

```java
package com.itheima.test;

public class HelloWorld2 {
    public static void main(String[] args) {
        System.out.println("hello world");
    }
}
```

**第一行 `package com.itheima.test;`**。这个 package 其实也是一个关键字，它就表示我当前的类定义在哪个包下。怎么验证呢？右键点击 src → New → Package，我们再来新建一个包，比如说叫做 AAA，在 AAA 这个包里面我再新建一个类。你看它上面自动写的就是 `package AAA;`，就表示我当前的类是定义在 AAA 这个文件夹里面的。

这里还有个细节要注意：**你右键点击谁，就表示我要在哪个里面新建**。在刚刚哥们是右键点击的 src，所以说 AAA 是在 src 里面的；现在我要在 AAA 这个里面再新建，所以我就不能再右键 src 了，我要右键 AAA。另外，上面这段 `package` 代码不需要我们自己写，它是 IDEA 自动生成的。

**第二行 `public class HelloWorld2 {`**。第一个单词 `public`，这个关键字相对来讲有点复杂，我们后面再慢慢地解释；现在只要知道第一个关键字 class 的作用就行，它就表示定义一个类，而这个类是 Java 项目中最基本的组成单元。后面的 HelloWorld2 表示类的名字，简称类名。再往后这一对大括号就表示类的范围，所有的代码都需要写在这个大括号当中；如果你把代码写在大括号的外面，程序都不用运行，它就直接报错了。

> **提示**：随着后面课程的渐渐深入，你会发现这个大括号出现得会比较多——就算现在这个 Hello World 代码里，它都出现了两对大括号。以后很多兄弟往往分不清哪个大括号跟哪个大括号是一对，那其实有个小技巧：你可以点一下大括号的左边，跟它一对的那个大括号是不是就高亮显示了。

**第三行 `public static void main(String[] args)`**。它表示 Java 程序的主入口。当程序开始运行的时候，它会从主入口开始逐行往下运行。

这个其实也很好理解。比如说在这个里面我写很多很多的代码，我写五行代码：第一行打印 hello world，第二行打印 111，第二行下面 222、333、444，那你说程序的运行结果是什么？右键 run，你来看 hello world、1234——就是按顺序全出来了。为什么？因为它就是从程序的主入口开始，一行一行往下执行的。

在书写的时候，咱们要注意它是一个固定格式，你不能修改这个里面每一个单词、每一个符号，你都不能改动。

**第四行 `System.out.println("hello world");`**。这个在刚刚我们解释过，它就是一个输出语句，我们也叫做打印语句，它就表示将里面的内容输出到控制台。右键运行，下面这就是我们程序的控制台，hello world、1234 是不是全都输出出来了。

### AI 时代该怎么学：先看一个错误的示范

按照正常的节奏，接下来咱们要学习 Java 中的核心语法了。但是平时上课的时候跟很多兄弟接触，发现呢很多兄弟使用 AI 的方式不对：要么就是太过于依赖 AI，要么就是还没有完全把 AI 的能力使用出来。所以接下来在正式学习之前，咱们先通过两个小案例聊聊，每一个课程阶段我们到底该如何正确地使用 AI。

#### 一个错误的示范：贪吃蛇小游戏

注意哦兄弟们，下面是一个错误的演示。

使用 AI 的时候要注意了：首先要先去打开 AI 的对话框，在右边这个小风车点击一下，这儿有一个对话框，下面是输入框，我要 AI 帮我做什么，在下面跟它说话就可以了。在输入框的左下角有一个选项，点开有三块：第一个叫智能问答，就是以后我有什么不会的去问他；第二个叫做文件编辑，是用 AI 帮我们写代码的，可以把 AI 生成的代码自动同步到左边的文件当中；再往下还有一个叫做智能体，这个比较复杂，先不管，现在先知道前面两个的作用就可以了。在它的后面还有一个，就是选择大模型，一般来讲我们用 DeepSeek R1 或者千问3 都是可以的。

现在我就选择 DeepSeek R1，接下来用 AI 去写贪吃蛇小游戏。很多兄弟上来直接把需求就告诉 AI 了，比如说："利用 Java 的 Swing（Swing 呢是 Java 里面的一个技术）写一个贪吃蛇小游戏"，然后直接一个回车。稍等几秒钟，文件生成完毕，点击接受就可以了。

这个时候你来看左边有一个 SnakeGame，双击打开，这个就是贪吃蛇小游戏，所有的代码一共生成了差不多 200 行左右，看到 main 了，那就是程序的主入口了。右键 run 一运行——哦，它生成的代码出问题了。

没关系，我们可以把报错信息 Ctrl+C、Ctrl+V 粘贴过来，让 AI 帮我们自动地去修改，跟它说"刚刚生成的代码出错了，错误的信息在上面，请帮我修改"，一个回车。稍等几秒钟，错误修改完毕，点击接受。回到代码当中往下拉，找到 main 方法，右键 run——当当当当，程序就已经开始运行了，开始来玩一下吧。

代码是生成完了，哥们心里在想哇，这个 AI 好厉害呀。但是你要知道啊兄弟，看上去非常的爽，只不过呢它就是"空心萝卜绣花袍，中看不中用"。为什么呢？

在刚刚还记得吧，兄弟代码出错了，这是第一个问题——你不能保证它生成的代码一定是正确的。现在代码少、一个错误还好；如果你指望它一下子生成十几万行代码，几百个错误同时发生，想死的心都有，而且 AI 也无法同时处理那么多的错误。

额外呢还有第二个问题：现在如果我要进行版本迭代，去加一个非常简单的需求——把游戏背景修改成白色。那我现在还没有学习代码，我看不懂它，也不知道该怎么改，怎么办呢？还是交给 AI，说帮我把背景颜色修改成白色，回车。稍等几秒钟，哇哦兄弟你发现了吗？当我们修改一个简简单单的小功能的时候，它把这个代码又从头到尾全部生成了一遍，但是实际上我只要修改这一行代码就可以了。

那现在我先去看一看它有没有帮我修改成功，点击接受，右键再来运行，运行完毕你发现它确实已经修改成功了，只不过刚刚那个修改的动作太大太大了。那你要想啊兄弟，我现在要修改一个很小很小的地方，因为我什么都不会，我还是让 AI 帮我生成，AI 就从头到尾把整个游戏全都生成了一遍，你觉得这合理吗？肯定不合理啊。

现在这是一个很简单的小游戏，总共加起来也就 200 行代码；但是如果涉及到一些非常大的项目，动辄几万行、十几万行的代码，比如说像某东、某宝、B 站，你用 AI 生成一个试试？每次都要生成十几万行代码，想想都觉得它根本就行不通。

> **结论**：在以后我们学习的时候，咱们心里要有一个充分的认知——AI 只是咱们的一个助手。不要相信 AI，它有可能会出错，而且有的时候呢还答非所问。它只能给我们提供建议，你不能大面积地去使用它的代码。

那有兄弟会想了：再过几年，随着 AI 不断地发展，会不会一下子就能生成我想要的东西呢？你想得对，但是我要告诉你的是兄弟——就算 AI 生成的是正确的，那么也需要我们告诉 AI 你该怎么去干活。就像刚刚的贪吃蛇，如果说要生成的是那种业务一旦变得非常复杂的贪吃蛇，AI 生成出来的东西往往跟我们所想也不会一样。

简单来说，AI 它有自己的想法。平时如果说我是跟人去沟通，让另外一个人实现我的想法，还有可能发生我说 A 他做 B 呢，你更不要说 AI 了。所以指望 AI 一下子生成大型企业级的项目，是根本不可能的。

#### 一个正确的示范：彩票中奖判定

那现在我们已经知道 AI 的弊端了，我到底该如何正确地使用 AI 呢？我们通过第二个小案例来演示。

彩票中奖案例：在我们现实生活当中有很多种彩票，每一种彩票的规则都是不一样的，所以说第一步我们要先去指定彩票的规则。这个规则有可能很复杂，所以说我们要把复杂的规则按照正确的理解进行拆分，这个叫做**拆业务**，把它分成 1、2、3、4、5、6、7、8 步，然后呢再去逐个地实现，再去排查里面每一个 bug，最终运行程序。

因为咱们还没有开始学习业务呢，我们就稍微简单一点：

- 一开始生成一个七位的随机数，就认为这个随机数就是中奖的号码；
- 然后让用户键盘输入一个七位的数字，认为下面的是用户买的彩票；
- 接下来对比两者，看看中了多少个数字。

在 IDEA 里按照正确的方式去使用 AI。第一步先定规则；第二步叫做拆业务，其实就是把这个大的题目变成一步两步三步，每一步要拆分出来。

> **提示**：做每一步的时候，我们不需要把它 Ctrl+C、Ctrl+V 复制粘贴到对话框当中。直接在代码编辑区用注释的形式写下来，一个回车，通义灵码就会根据上面的注释跟你去生成代码。生成的代码是灰色的，那你要去审核这个代码——对不对？是不是我想要的？该学的知识点我还要学，没有学习的话，我根本就看不懂这个代码是什么意思。

第一步确认代码正确，按 Tab 确认表示是我要的。

**第二步**，键盘录入七位数表示用户购买的彩票。用鼠标点一下注释的后面，一个回车，自动生成的代码是我想要的，但它不完整，继续回车，给出一个提示"请输入七位的彩票号码"，然后用鼠标点一下红色的地方，按一下 `Alt` 加回车，这样第二步才算完成。

**第三步**，判断用户输入的彩票号码是否跟系统生成的彩票号码一致。同样地以一个回车让它给提示：`if` 我们还没学，但是呢英语当中它就是"如果"的意思，所以说它其实就是一个判断，用来判断用户输入的彩票号码跟真正的彩票号码是不是一致；如果说一致，就打印一句话"恭喜你中奖了"；那如果不一致呢，不一致继续提示咯，否则输出一段话"很遗憾你没有中奖"。右键 run 试一试吧，输入一个彩票号码 1234567，一个回车，它说"很遗憾没有中奖"。

> **结论**：说白了就是你不要上来就把所有的任务复制粘贴去交给 AI。咱们要先去定规则，拆业务，逐个实现、排除 bug，最终呢再去运行结果。这就是我们在基础和 web 阶段使用 AI 的方式。

#### 不同阶段，AI 的分量不一样

其实在这两个阶段，AI 对于我们的帮助还是以提高开发效率、减少记忆、辅助学习为主，还没有完全地去发挥 AI 的能力。但是越到后面，AI 的重要性就越大，特别是在项目阶段，AI 的重要性就会有质的飞跃。

项目阶段我们要结合 AI 去开发一些智能化的项目。比如说智能分析，分析财经新闻等各类数据；还有像 AI 客服，几乎所有类型的项目都可以接入这个模块。当然还有很多，比如说像智能搜索、智能扩写、智能生成，甚至是 AI 智能管家。

那什么是 AI 智能管家呢？举个例子：假设我手机上原本有这么多的 app，有了智能管家之后，在手机里面我就不需要这么多 app 了，一个 AI 项目就足够。如果说哥们要出去玩，要从北京到南京，我都不需要自己去找各个软件去订机票、订酒店了，AI 软件会按照你之前的习惯，自动地帮你订机票、订酒店、打车、制定旅游方案。如果真的有这样的项目，兄弟你会不会爱上它呢？哥们觉得那叫一个相当的哇塞啊。

> **结论**：这种智能体项目，就是目前我们使用 AI 的终极形态。

所以说在不同的阶段，我们使用 AI 的方式是不一样的：前面的阶段我们就是利用 AI 去提高开发效率、减少记忆、辅助学习；那么到了项目阶段，我们就要真正地去开发一些智能化的项目了。所以兄弟们，你只要做一件事，就是跟着我们课程的节奏一点一点来，这就欧啦。
