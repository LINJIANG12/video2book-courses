# 黑马程序员：Java 零基础全套（2026 版）

黑马程序员 2026 版 Java 零基础全套课，149 集按「入门篇 → 基础篇 → 面向对象篇 → API 篇」的顺序推进。课程先讲环境搭建与 JDK 配置，再依次过数据类型与变量、分支与循环、数组与数组算法、方法重载与 JVM 运行机制，并穿插归并、计数一类的算法训练；中段是全课重心——面向对象基础与对象内存模型、继承体系、多态与接口、内部类；后段落到实际开发最常用的字符串 API、StringBuilder 与 ArrayList 集合，以「文字版格斗游戏」这个综合项目收尾，最后补 Object、System 与包装类体系。

- **原视频**：https://www.bilibili.com/video/BV1TJxCzSEEZ — Bilibili，BV1TJxCzSEEZ
- **149 集**，已产出 13 册模块全书、16 篇复习笔记、52 份逐字稿

## 怎么学

- **前七章是地基** → 模块 01~06 覆盖环境、类型、分支循环、数组、方法与算法训练，零基础务必按顺序走完，**对象内存模型（模块 07、笔记 09）**是理解后面一切的关键，别跳
- **算法训练要动手** → 模块 04~06 与笔记 06、08 对应大量力扣、牛客网题型，看完题解一定要自己敲一遍，Java 的集合 API 只有写熟才用得出来
- **面向对象是分水岭** → 模块 07~09 与笔记 09~12 讲继承、多态、抽象类、接口与内部类，这五章决定你能不能读懂框架源码，也是面试最集中的部分，值得反复回看
- **API 篇是日常生产力的来源** → 模块 10、11 的字符串、StringBuilder 与 ArrayList 是写业务代码用得最多的三块，建议直接当工具手册用，笔记 13、14 按需查阅
- **用项目固化** → 模块 12 与笔记 15 是「文字版格斗游戏」完整实现，把前面所有概念串成一个能跑的程序，做完再回头看 OOP 那一段会通透很多
- **注意课程范围** → 原视频标题带「AI 智能应用开发」，但**本次产物只覆盖 Java 语言与集合基础**（到 Object/System/包装类为止），AI 部分尚未整编，后续产物齐备后再增量补入
