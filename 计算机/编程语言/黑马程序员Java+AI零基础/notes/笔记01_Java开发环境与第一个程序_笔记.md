# Java 开发环境与第一个程序

## 人工智能+ 的政策背景

* **"人工智能+" 政策**
    * > **定义**：2025 年 7 月 31 号国家发布的政策，大力推进人工智能规模化商业化应用，推动人工智能与各个行业深入整合，让目前大多数传统项目进行智能化升级。
    * 上游参照物是 2015 年国家发布的"互联网+"；正是因为有大方向指引，才有了互联网蓬勃发展的 10 年，目前大多数从业者吃的基本都是这个红利。
    * 边界：AI 不只是机器学习、深度学习这些算法，也不只是图像识别、语音识别和机器人；更多的是与各行业深度融合、给各行业赋能。

* **AI 改造行业的具体形态**

    | 行业 | 从前的样子 | AI 进来之后 |
    | :--- | :--- | :--- |
    | 电商 | 不知道自己穿这件衣服好不好看，只能买了就退，货物成本和时间成本被大大推高 | 用 AI 虚拟试穿，把自己的数字人形象传上去让数字人穿一穿，还能更换不同背景，退货率和商家成本一起降下来 |
    | 物流 | 库存压着，周转慢 | AI 智能仓储管理系统，降低商品的库存率，提高周转率 |

    * AI 不是飘在天上的概念，它正在实打实地改造一个个行业。

## Java 成为智能化升级主力军

* **三条依据**
    * Java 是企业级项目的绝对主力：Oracle 官方数据显示全球 90% 的传统企业都基于 Java 开发，这些软件智能化升级时首选语言必然是原有技术栈，才能确保更好的稳定性与兼容性，实现平滑过渡。
    * Java 工程师规模最大、生态最成熟：拥有全球最庞大的开发者群体和高度成熟的技术生态，企业招聘更容易，人才供给充足。
    * Java 工程师最懂企业的智能化升级要求：工程师既懂业务又懂 AI，而 Java 工程师长期耕耘服务器端，是最懂项目业务的那批人。

* **第三方数据佐证**
    * 一份由大型 Java 平台提供商发起的调查显示，50% 的组织使用 Java 去构建 AI 功能。
    * 在以 Java 为中心的企业当中，AI 开发的使用量已经超过了 Python 和 JavaScript。
    * GitHub Copilot 的 CEO 明确表示，Java 语言很有可能在未来一年半的时间内成为人工智能开发领域的 number one。

* **学习方向的选择**
    * 学完 Java 后就业方向尽可能不要停留在传统领域，要往 AI 智能化应用方向走，才能吃到当前的红利。
    * 用 Java 开发智能化应用，是普通学历的人吃到 AI 红利的最好方式。

## Java 之父与语言定义

* **James Gosling（Java 之父）**
    * 14 岁开始学编程；15 岁学了一年编程就已经是卡尔加里大学的兼职程序员，工作内容是分析卫星数据。
    * 40 岁推出 Java，因这一战绩获得加拿大的勋章、冯诺依曼奖，并入选计算机历史博物馆的荣誉。
    * 现任状况：已经退休，正在享受退休生活。

* **Java 的诞生**
    * Java 是 1995 年美国 Sun 公司推出的一门计算机语言。
    * Sun 公司全名是 Stanford University Network，即斯坦福大学网络公司。
    * 当年的 Java 之父 James Gosling 是 Sun 公司的副总裁。

* **计算机语言（computer language）**
    * > **定义**：人与计算机之间进行信息交流、沟通的一种特殊语言，即计算机能听得懂的话。
    * 计算机听不懂人类语言，只能通过计算机语言告诉它做什么，它听懂后才会执行。
    * 平时用的各种软件都是程序员提前写好的代码打包形成的；当上程序员，本质就是写软件供别人使用。

## JDK 与版本选择

* **JDK（Java Development Kit，Java 开发者工具包）**
    * > **定义**：编写 Java 代码前必须先下载安装的开发工具包。
    * 理由与装游戏同源：想玩一把游戏不能直接玩，得先到官网下载安装包，安装之后才能开始。
    * 现在真正要用到的不是 JDK 的安装根目录，而是它 `bin` 文件夹底下的 `java.exe`。

* **版权归属**
    * Oracle 是全球前十的软件公司。
    * 2009 年 4 月，Oracle 用 74 亿收购了 Sun 公司，因此现在 Java 的版权归属于 Oracle，要到 Oracle 官方网站下载。

* **官网下载路径**

    ```text
    浏览器地址栏
        │
        ▼
    Oracle 官网首页
        │
        └──► Products（产品，会拉出一个下拉框）
                 │
                 └──► Java
                        │
                        └──► Download Java
                               │
                               ├──► 最新的版本：JDK 25（LTS）
                               │
                               └──► 下方按操作系统分栏
                                      ├── Linux
                                      ├── Mac（苹果）
                                      └── Windows
                                            │
                                            ├──► 第一个链接：zip 压缩包 —— 不用管它
                                            ├──► 第二个链接：标准安装包
                                            └──► 第三个链接：exe 安装包 —— 点这个
    ```

* **LTS 版本（Long Term Support，长期支持版本）**
    * > **定义**：Oracle 官方长期维护的版本，有 bug、有问题都会及时修复，因此相对比较稳定，也是企业开发的首选。
    * 属于 LTS 的版本是：JDK 8、JDK 11、JDK 17、JDK 21，以及现在最新的 JDK 25；其余都是普通版本。
    * 企业当中 JDK 17 用得最多；学习阶段用最新的长期支持版本 JDK 25，这样既能覆盖企业里用的东西，也能学到新东西。
    * JDK 25 的发布日期是 2025 年 9 月 16 号。

* **安装注意事项**
    * 安装路径不要带中文、空格或特殊符号；这些软件是老外编写的，对中文支持不够完美，路径含中文以后容易出问题。选路径时写英文字母，或再加 1234 这样的数字。
    * 以后会安装很多开发相关工具，建议找一个文件夹统一管理，方便查找。

    ```text
    E:\develop\            ← 所有跟开发相关的软件都放这一层
       ├── jdk\            ← JDK 安装目录
       │     └── bin\      ← bin 里面才是 java.exe 等可执行程序
       └── idea\           ← IDEA 安装目录
    ```

* **安装与验证**
    * 双击安装包后点击"下一步"，在选择安装路径这一步点"更改"，在 develop 文件夹里新建 `jdk` 子文件夹，确认后继续"下一步"，进度条读满即安装完成。
    * 验证：找到 `E:\develop\jdk` 下的 `bin` 文件夹，点击上方输入框输入 `cmd` 回车，在黑窗口中执行 `java -version`。

    ```bash
    java -version
    ```

    * 第一行输出 `java version "25..."` 就说明装的确实是 25，也说明 JDK 安装成功。

## 环境变量

* **环境变量（environment variable）**
    * > **定义**：操作系统自带的一个记录各种路径的表格；配置环境变量就是把这些路径写到这个表格当中。
    * 类比：私藏的大片放在很深的文件夹里，时间久了会忘；电脑自带一张记录路径的表格，就随时随地能打开。
    * 一旦记录了，不管文件放在哪儿、层级多深、你还记不记得位置都能找到，因为 Windows 操作系统会到环境变量当中去找你要打开的文件。
    * 运行时查找分两步：先在当前文件夹找，找不到再到环境变量 Path 里从上往下一条一条找；直到最后一条也没有，才报"不是内部或外部命令"。

    ```text
    在任意目录输入  aaa.mp4  然后回车
            │
            ▼
    ① 先在当前文件夹里找 aaa.mp4
            │
            ├── 找到了 ─────────────────────► 直接打开，完事
            │
            └── 没找到
                  │
                  ▼
    ② 再到环境变量 Path 里，从上往下一条一条地找
            │
            ├── 第①条路径里有 aaa.mp4 吗？ ──有──► 打开，完事
            ├── 第②条路径里有 aaa.mp4 吗？ ──有──► 打开，完事
            ├── 第③条路径里有 aaa.mp4 吗？
            │           ...
            └── 一直找到最后一条，还是没有
                  │
                  ▼
       'aaa.mp4' 不是内部或外部命令，
       也不是可运行的程序或批处理文件。
    ```

* **用户变量与系统变量**

    | 配置位置 | 谁能用 |
    | :--- | :--- |
    | 上半部分：用户变量（自己用户的环境变量） | 只有当前这个用户能用 |
    | 下半部分：系统变量（系统环境变量） | 电脑里如果有多个用户，就都可以使用 |

    * JDK 相关配置要配到下半部分的系统变量当中。

* **配置步骤**
    * 第一步复制路径：右键目标文件 → "属性" → 点击"安全"，把它前面那一节路径 Ctrl+C 复制下来。
    * 第二步粘贴保存：打开我的电脑 → 右键空白处 → "属性" → "高级系统设置" → 选择"高级" → 点右下角"环境变量" → 找到 Path，双击点开或选中后点右边"编辑" → "新建" → Ctrl+V 粘贴 → 三次确定。
    * 边界：Win 11 的高级系统设置在右侧位置，Win 10 在左上角；不论 Win 10 还是 Win 11，点进来之后的界面都一样。
    * 打开方式：按 Win + R，输入 `cmd` 回车，或点"确定"打开黑窗口；不要用鼠标双击文件。
    * 黑窗口默认操作的目录是 C 盘 user 下的当前用户文件夹，例如当前用户叫"阿伟"就是 `C:\Users\阿伟`，叫 admin 就是 `C:\Users\admin`。

* **JAVA_HOME 与 Path 的分工**

    | 变量 | 填什么 | 例子 | 作用 |
    | :--- | :--- | :--- | :--- |
    | `JAVA_HOME` | JDK 的安装路径，末尾**不带** `bin` | `E:\develop\jdk` | 留给以后的软件读，Maven、IDEA 都要用它 |
    | `Path` | `java.exe` 的路径，末尾**带** `bin`，并上移到最前面 | `E:\develop\jdk\bin` | 让系统在任意位置都能直接敲 `java -version` |

    * 操作顺序：先在环境变量上半部分新建 `JAVA_HOME`，变量值粘贴 `bin` 之前的路径；再把 Path 中安装 JDK 时自动生成的那一项删掉，重新"新建"粘贴带 `bin` 的完整路径。
    * 配完 Path 后要点"上移"把它移到最上面，因为查找是从上往下一个一个找的，排在最前第一个就能命中，可提高查找效率。
    * 验证：Win + R → `cmd` 回车，直接执行 `java -version`，输出一大堆文字就说明配置成功。

* **两种 Path 写法的取舍**

    ```text
    写法一（直接写完整路径）
      JAVA_HOME = E:\develop\jdk
      Path      = ...; E:\develop\jdk\bin
                        ↑
        完整路径直接写死，不依赖任何引用

    写法二（% 引用）
      JAVA_HOME = E:\develop\jdk
      Path      = ...; %JAVA_HOME%\bin
                        ↑
        运行时先把 %JAVA_HOME% 展开成 E:\develop\jdk，再拼上 \bin
        最终效果和写法一完全一样
    ```

    * 两个百分号表示引用，把 `JAVA_HOME` 的值引用过来再与后面的 `\bin` 拼接，展开后的最终效果与直接写完整路径完全一样。
    * 选写法一的理由：部分 Win 10 系统存在 bug，重启之后这种引用式环境变量会失效；把完整路径配置在 Path 中几乎所有 Win 10 系统都不会出问题。

> **易错点**：复制路径时只复制到最后一个文件夹为止，不要把文件名一起带上。
> **易错点**：如果出现 `java` 不是内部或外部命令，也不是可运行的程序或批处理文件的提示，说明环境变量配错了，需要删掉重新配。

## IDEA 开发工具

* **IntelliJ IDEA**
    * 全称 IntelliJ IDEA，是业内公认的 Java 开发最好用的工具，没有之一。
    * 现在几乎所有企业都在用它写代码。
    * 可以在其中安装 AI 插件，用 AI 帮我们写代码、分析代码、修改错误。

* **为什么不用 Windows 自带记事本**

    | 写代码时遇到什么 | Windows 记事本 | IntelliJ IDEA |
    | :--- | :--- | :--- |
    | 有的单词我忘了 | 不能给提示 | 自动补全，少背很多键 |
    | 单词写错了 | 没有正确的提醒 | 会有红色波浪线的提示，当场就标出来 |
    | 代码格式 | 还需要自己手动去调整 | 特定格式的语句有快速生成方式，一个回车直接生成 |
    | 一些特殊的单词 | 没有高亮的显示 | 语法高亮，一眼分辨关键字和普通标识符 |

* **下载与安装**
    * 登录 `www.jetbrains.com.cn` → 点击"开发者工具" → 点击"IntelliJ IDEA" → 进入下载界面，按操作系统选择版本；Windows、Mac、Linux 都有安装包。
    * 安装路径同样不要有中文、空格、特殊字符，并放进统一的开发工具文件夹，最终落在 `E:\develop\idea`。
    * 勾选项只勾左上角"创建桌面快捷方式"这一处，其他所有地方都不要勾。
    * 出现"IntelliJ IDEA 已经成功安装到本机"的提示即安装成功，桌面出现图标可作确认。

* **常用设置入口**
    * 所有设置都在 settings 里：点击左上角四道杠把菜单打开，选择 settings。
    * 主题：Appearance → Appearance → Theme，默认是 Dark 暗黑主题；点 `Get more themes` 搜 `win10`，找到 `Win10 Light` 点 install。
    * 字体：四道杠 → File → Settings，搜索 `font`，字体选 Consolas（搜 `CONS`，第一个就是），大小设为 17，行间距保持默认的 1.2。
    * 忽略大小写提示：settings → Editor → General → Code Completion → 把 Match case 前面的勾去掉；默认情况下写 `Str` 会提示出 String，写小写 `str` 就没有提示，去掉勾之后大小写都能正常提示。

* **AI 插件**
    * IDEA 自带的 AI Chat 是收费的，价格较贵，一般不用它。
    * 免费的替代是阿里的通义灵码或字节的 MarsCode。
    * Plugins 页面右边有两个选项：Marketplace 是应用市场，以后要下载的插件都在这里搜；Installed 表示已成功安装的插件。
    * 安装：在 Marketplace 里直接用拼音搜"通义灵码"或搜 MarsCode → `Install` → accept → 等进度条读满消失 → OK。
    * 安装成功后右边多出一个小风车图标，那就是通义灵码；第一次使用要登录，点阿里云账号登录会弹出二维码，用支付宝扫即可，不需要重新注册。

## 项目、包与文件

* **三个层级**

    ```text
    项目 Project ─── 一个软件在开发时的称呼，比如整个《原神》
       │
       └─ 包 Package ── 项目里的文件夹，用来分门别类
            │             动画 / 时间 / 文本，各归各的
            │
            └─ 文件 .java ─ 代码真正写在这里的地方
    ```

    * 项目（Project）指一个软件在开发时的称呼，比如整个游戏就是一个项目。
    * 包（Package）就是项目里的文件夹，用来分门归类；一个项目里代码成千上万个，全堆在一处以后根本没法找。
    * 文件是后缀名为 `.java` 的文件，代码真正写在这里面。

* **新建项目**
    * 要注意两点：给自己的项目起个名字；把 `Add sample code` 前面的勾去掉，不要示例代码，所有代码自己手写。
    * `location` 问的是项目保存在哪里，默认即可；要改到其他盘就点后面那个像文件夹的图标。
    * `Build system` 保持默认的 IntelliJ，`JDK` 选装好的那个 JDK，点 Create 后等右下角进度条读满、消失即可。
    * 第一次登录会弹提示要不要改成简体中文版，一般不需要，叉掉即可；企业里大家用的基本上都是英文版本。

* **界面布局**

    ```text
    +-------------------------------------------------------+
    | File  Edit  View  Run                     [Run]    |
    +----------------------+--------------------------------+
    | 项目结构区           | 文本编辑区                       |
    |  src                 |   public class HelloWorld {      |
    |   └ com.itheima      |   public static void main( ){    |
    |      └ test          |     System.out.println("hi");    |
    |        └ HelloWorld  |   }                              |
    |                      | }                                |
    +----------------------+--------------------------------+
    | 控制台 Console                                       |
    |   hello world                                         |
    |   Process finished                                    |
    +-------------------------------------------------------+
    ```

    * 左边是项目结构区，完整项目里有哪些文件夹、文件夹里有哪些文件都在这里罗列。
    * 右边是文本编辑区，以后写代码就在这里书写。
    * 下方是控制台（Console），程序的运行结果在里面。

* **包的位置与命名**
    * 包建在 `src` 下面，`src` 就是源代码的意思，以后写的所有代码都在这个文件夹里；操作是右键 src → New → Package。
    * 包名随便起，abc、bcd 都行；企业级开发中一般按公司域名的反写来起，先写 com，再写 it、heima，www 省略，后面再加包的作用；练习场景得到 `com.itheima.test`。
    * 多级包之间用点来间隔，实际在磁盘上是嵌套文件夹：右键包 → Open in → Explore 可以看到 src 里新建了 com，com 里有 itheima，itheima 里有 test。
    * 建文件：在包里面右键 → New → Java Class，起个名字回车。

> **易错点**：代码必须写在一对大括号里面，这一对大括号表示一个范围，不能写在它外面，写在外面就出错。

## Hello World 程序

* **为什么第一个程序总是 Hello World**
    * 这个规矩来自 C 语言之父 Dennis Ritchie 编写的经典书籍《C 程序设计语言》，书中第一个程序代码就是输出一段话 hello world。
    * C 语言又是其他编程语言的鼻祖，所以后来的 Java、Python、C# 都延续了把 hello world 当入门第一个代码的传统。
    * 用它练手有两个目的：一是用最简单的代码熟悉 IDEA 的基本使用（如何创建、编写、运行、查看结果）；二是知道写代码时代码整体结构长什么样。
    * 以后所有的 Java 程序都可以仿照 hello world 的格式来编写。

* **完整结构与代码生成**

    ```java
    package com.itheima.test;

    public class HelloWorld {
        public static void main(String[] args) {
            System.out.println("hello world");
        }
    }
    ```

    * IDEA 有自动提示，不用一个单词一个单词写：先写 `psvm` 回车即生成主方法，再写 `sout` 回车即生成打印语句，在小括号里直接写内容。

* **三种运行方式**
    * 右键空白处 → Run，选这里的 `HelloWorld.main` 点一下，等右下角进度条读满消失。
    * 左边项目结构区里类名前面有一个绿色小箭头，点一下选 Run HelloWorld，再选 main。
    * 右上角也有一个绿色小箭头，点一下当前程序直接运行。

* **控制台的读法**
    * 第一行是程序的一些运行信息，比如 JDK 的位置，不用管。
    * 第二行开始是程序运行的结果，第三行说明这个程序运行结束了；真正要看的是第二行。
    * 想换输出内容，只需把双引号当中的内容更改，再右键运行即可。

> **易错点**：整段代码要跟标准写法完全一致，每一个单词、每一个标点符号都要一样；所有标点符号必须是英文状态，中文标点会导致红色波浪线报错。唯一可以修改的地方是双引号里面，其余地方都不要改。

## 注释

* **注释（comment）**
    * > **定义**：给代码添加的解释说明性的信息。
    * 作用：通过阅读注释快速理解代码的含义——自己时间久了忘了当初怎么写的，或者别人看你代码时，都能一下子读懂。
    * 边界：变成有经验的程序员后没必要每行都写注释，只给每一个独立的功能写一下，目的是告诉别人下面这段代码是干什么的。

* **三种写法**
    * 单行注释：前面写两个杠杠 `//`。
    * 多行注释：开头是杠星 `/*`，结尾是新杠 `*/`，中间写多少都可以。
    * 文档注释暂时用不上，先行忽略；当前只需掌握前两种格式。

    ```java
    // 第三行代码的作用是输出一段文本
    // 文本的内容就是 hello world
    // 如果要修改输出的内容
    // 那么直接修改双引号里面就可以了
    System.out.println("hello world");
    ```

    * 注释内容多、一行写不下时，要在每一行前面都加杠杠；也可以直接用多行注释，更方便。

* **颜色与快捷键**
    * 默认注释是灰色斜体，可以改成和文本一样的绿色：File → Settings → Editor → Color Scheme → Language Defaults → 展开 Comments，里面有 Line comment（单行）和 Block comment（多行）两项，分别去掉斜体并改颜色，例如改成 `2C7A06`。
    * 不能选红色，因为在 IDEA 中只有代码出错、出现问题时才是红色，注释改成绿色即可。
    * 单行注释快捷键是 `Ctrl` + `/`；多行注释快捷键是 `Ctrl` + `Shift` + `/`，且操作方式不同——要先用鼠标选中这一段文本，再按快捷键。

* **运行规则与嵌套**
    * 运行规则：注释不会影响程序的运行结果，它仅仅是对代码的解释说明；把某一行代码注释掉，那行代码就不运行，右键 run 后结果里就没有它了。
    * 因此注释里面可以随便写什么，但尽量写跟代码相关的，跟代码无关的内容就不要写。
    * 嵌套：注释里面不要再写其他注释。在多行注释里再写一个多行注释会直接报红——杠星会去找距离它最近的新杠作为结尾，把那一段认作多行注释，剩下的部分只有结尾没有开头。
    * 单行注释里再写单行注释技术上不报错，但阅读起来非常难受，也没有意义。
    * 结论：不管是单行注释还是多行注释，都不要嵌套。

## 关键字与类

* **关键字（keyword）**
    * > **定义**：被 Java 赋予了特定含义的英文单词。
    * 书写特点之一：所有字母全部都要小写。
    * 书写特点之二：常用代码编辑器对关键字都有特殊的颜色标记，非常直观；IDEA 对关键字就有高亮显示。
    * 判定方法：在这段代码中那些小写的、高亮的就是关键字，即 `public`、`class`、`static`、`void`。
    * 数量与记忆策略：Java 中关键字一共 50 多个，现在不需要背；每个关键字都包含一个甚至多个知识点，现在背上了也没用。

* **类（class）**
    * > **定义**：Java 项目最基本的组成单元；任意一个 Java 项目拆开看，就是由成千上万个类组成的。
    * `class` 关键字用于创建一个类，也就是定义一个类。
    * 关键字后面紧跟的就是类名，由自己随便起，理论上叫 hello world 或叫 ABC 都行，但起名字要有意义——叫 ABC 别人不知道这个类是干嘛的，叫 hello world 别人就知道这是练习的第一段代码。
    * 类名后面有一对大括号，表示类的范围，所有代码都要写在这对大括号当中，写在外面就报错。
    * 配对技巧：大括号出现得多、分不清哪两个是一对时，点一下左边的大括号，跟它一对的那个大括号就会高亮显示。

## 逐行拆解程序结构

* **package 声明**
    * `package` 本身也是关键字，表示当前这个类定义在哪个包下。
    * 验证方式：右键 src → New → Package 新建一个叫 AAA 的包，在 AAA 里面新建一个类，文件上会自动出现 `package AAA;`。
    * 右键点击谁，就表示要在哪个里面新建：右键 src 则 AAA 建在 src 里面，要在 AAA 里新建就得右键 AAA，不能再右键 src。
    * 这段 `package` 代码不需要自己写，是 IDEA 自动生成的。

* **类声明**
    * `public class HelloWorld2 {` 中第一个单词 `public` 这个关键字相对复杂，后面再解释；当前只需知道 `class` 表示定义一个类。
    * 后面的 `HelloWorld2` 是类名，再往后那一对大括号表示类的范围，代码写在外面程序都不用运行就直接报错。

* **主方法 main**
    * > **定义**：`public static void main(String[] args)` 表示 Java 程序的主入口，程序开始运行时从主入口开始逐行往下运行。
    * 顺序性很直观：在里面写五行代码分别打印不同内容，运行结果就按书写顺序全部出现。
    * 书写时是一个固定格式，里面每一个单词、每一个符号都不能改动。

* **输出语句**
    * `System.out.println("hello world");` 是输出语句，也叫打印语句，表示把里面的内容输出到控制台。
    * 效果：右键运行，下方控制台里 hello world、1234 全都输出出来。

## AI 辅助编程的错误用法

* **对话框与选项**
    * 打开方式：点击右边的小风车图标，出现对话框，下方是输入框，直接在里面说话说明要 AI 做什么。
    * 输入框左下角的选项有三个：智能问答用于问不懂的问题；文件编辑用于让 AI 写代码，可把生成的代码自动同步到左边的文件；智能体较复杂先不管。
    * 输入框后面是选择大模型，一般用 DeepSeek R1 或千问 3 都可以。

* **贪吃蛇案例暴露的两个问题**
    * 常见错误做法是一上来就把需求丢给 AI——比如"利用 Java 的 Swing 写一个贪吃蛇小游戏"——然后直接回车，生成约 200 行代码；代码出错就把报错信息 Ctrl+C、Ctrl+V 粘贴过去让 AI 自动修改。
    * 问题一：不能保证 AI 生成的代码一定正确。现在代码少、一个错误还好；如果指望它一次生成十几万行代码、几百个错误同时发生，AI 无法同时处理那么多错误。
    * 问题二：修改一个小需求（比如把游戏背景改成白色）时，AI 会把代码从头到尾全部重新生成一遍，而实际上只需要修改一行代码。
    * 放到大项目里就彻底行不通：如果涉及动辄几万行、十几万行代码的项目，每次都要重新生成十几万行代码，根本不可行。
    * Swing 是 Java 里面的一个技术；生成的代码里出现 `main` 说明那才是程序主入口。

* **结论性认知**
    * AI 只是咱们的一个助手，不要相信它——它有可能会出错，有的时候还答非所问。
    * AI 只能提供建议，不能大面积地去使用它的代码。
    * 即使 AI 生成的是正确的，也仍然需要我们告诉它该怎么干活；AI 有自己的想法，人跟人沟通都可能出现"我说 A 他做 B"，更不要说 AI。
    * 指望 AI 一下子生成大型企业级的项目是根本不可能的。

## AI 辅助编程的正确用法

* **先定规则再拆业务**
    * 彩票中奖案例第一步是先指定彩票规则；现实中每种彩票规则都不一样，规则可能很复杂，所以要按正确的理解把复杂规则拆分，这叫做拆业务。
    * 把大题目分成 1、2、3、4、5、6、7、8 步，再逐个实现，再排查里面每一个 bug，最终运行程序。
    * 简化后的三步是：先生成一个七位的随机数，认为它就是中奖号码；再让用户键盘输入一个七位的数字，认为这是用户购买的彩票；然后对比两者，看中了多少个数字。

* **在编辑器里逐步生成**
    * 不需要把代码 Ctrl+C、Ctrl+V 复制粘贴到对话框；直接在代码编辑区用注释的形式把每一步写下来，一个回车，通义灵码就会根据上面的注释生成代码。
    * 生成的代码是灰色的，要逐行审核：对不对、是不是想要的、该学的知识点还要学，没学的话根本看不懂这段代码是什么意思。
    * 审核确认后按 Tab 表示接受这是我想要的。
    * 提示不完整时继续回车，让它补全；出现"请输入七位的彩票号码"这类红色提示处，按 `Alt` + 回车完成这一步。
    * 第三步判断用 `if`，`if` 还没学，但英语里就是"如果"的意思，它就是一个判断：一致就打印"恭喜你中奖了"，不一致就输出"很遗憾你没有中奖"。
    * 演示时输入的号码是 1234567，运行结果是"很遗憾没有中奖"。

* **阶段差异**
    * 基础和 web 阶段用 AI 的目的是提高开发效率、减少记忆、辅助学习，方式就是先定规则、拆业务、逐个实现、排除 bug，最终运行结果。
    * 项目阶段 AI 的重要性会有质的飞跃，要结合 AI 开发智能化项目，例如智能分析（分析财经新闻等各类数据）、AI 客服、智能搜索、智能扩写、智能生成，以及 AI 智能管家。
    * AI 智能管家的形态是：手机里不再需要装那么多 app，一个 AI 项目就足够；从北京到南京出行，AI 会按照你之前的习惯自动订机票、订酒店、打车、制定旅游方案。
    * 这种智能体项目就是目前使用 AI 的终极形态。
