## P12 Lecture 12 Containers-cn

方框和指针表示法是在我们的环境图中表示列表的一种方式。我们需要一种符号的原因是，顺序数据实际上可以变得相当复杂。这是因为封闭属性。如果组合数据值的方法满足这个封闭属性，那么组合的结果本身可以使用相同的方法再次组合。

如果我可以把项目放在一个列表中，我应该能够把那个列表放在另一个列表中。封闭是强大的，因为它允许我们创建分层结构。分层结构由部分组成，这些部分本身又由部分组成，以此类推。这是一种非常有用的方式来表示世界上各种事物。

这里的重点是列表可以包含其他列表作为元素，除了其他任何东西。这意味着我们需要一种方法来追踪包含什么。这就是我们使用方框和指针表示法的地方。

在环境图中，列表被表示为一行带有索引标签的相邻方框，每个方框对应一个元素。每个方框要么包含一个原始值，要么指向一个复合值。

如果我只是说：
```python
pair = [1, 2]
```
我会在我的环境图中写下这个，将名称 `pair` 绑定到一个包含 1 和 2 的列表。这些角落的小数字只是列表的索引。由于列表有两个元素，我们看到两个相邻的方框。

对于一个更复杂的例子，嵌套列表被绑定到一个包含一个列表、一个列表和另一个列表的列表，而这第三个列表本身包含了列表，而其中有各种各样的东西，甚至还有一个函数。

让我们逐步了解屏幕上的所有内容。嵌套列表是一个包含三个元素的列表，所以我们看到它绑定到三个相邻的矩形上。嵌套列表的每个元素实际上都是另一个列表，这就是为什么我们看到指向复合值的指针的原因。列表是复合值，函数是复合值。任何具有多个部分的东西都将使用指向该物体某种表示的箭头来表示。

这里我们看到索引 0 处的元素只是一个包含 1 和 2 的列表。索引 1 处的元素是空列表。这里我们看到空列表。而索引 2 处的元素本身是一个包含两个其他列表的列表。这就是我们看到这种层次结构的原因，其中这是由部分组成的，而这些部分又由部分组成。原始值 3、`False` 和 `None` 可以直接写入方框中。同样，函数也可以。我们按照以前编写函数的方式编写，使用一个小箭头表示它被包含在这个列表的索引 1 处，而这个列表又包含在这个列表中。

切片是一种你可以对列表和范围等序列执行的操作。

比如说，我已经有一个 `odds` 序列：`3, 5, 7, 9, 11`，而我想要的是得到 5 和 7。这些是索引为 1 和 2 的元素。我可以得到索引 1 和 2，然后我可以在列表推导中使用它：
```python
[odds[i] for i in range(1, 3)]
```
记住，范围 1 到 3 给我 1 和 2，但不包括 3。这是选择出 5 和 7 的一种方式，这个列表的一个子列表。

切片是用一种更简洁的方式表示这个的记号。它做的是同样的事情，但不需要你输入那么多。你只需写 `odds`，然后在方括号中说我想从 1 到 3：
```python
odds[1:3]
```
它遵循和范围相同的规则：索引包括下限，但不包括上限。

现在有一些额外的灵活性。就像如果你在范围内省略了一个边界一样，如果你省略了开始的数字，它将从列表的最开始开始。因此，`odds[:3]` 给我索引 0、1 和 2。我也可以省略结束，它会一直到最后。如果我想从索引 1 开始，那我就跳过索引 0 的 3，得到 `5, 7, 9, 11` 的所有元素：
```python
odds[1:]
```
你甚至可以跳过开头和结尾，然后你会得到原始列表中的所有元素：
```python
odds[:]
```
这些带有冒号的方括号被称为切片操作符。切片总是创建新的值。

这里有一些例子。我有数字，这是一个列表，然后我分三次对它进行切片。我得到的环境图包括四个不同的列表。注意，数字通过切片保持不变。但是，当我切出 1 时，说我想从开头一直到但不包括索引 1，我得到了一个新的列表，其中包含值 1。中间给了一个有 8 和 2 的第三个列表。然后从索引 2 到结尾的所有内容给了一个有 2 和 8 的第四个列表。

处理容器值通常涉及迭代你感兴趣的列表或字典中的所有值。但是有一些内置函数可以帮助我们更有效的执行此操作，特别是有几个执行序列聚合的函数。这些是接受可迭代参数并将它们聚合成为单个值的函数。

我只是要给你展示一下 Python 3 中实际的文档，帮你理解它是如何工作的。

有一个内置函数叫做 `sum`，它接受可迭代参数，比如一个列表：
```python
sum(iterable, /, start=0)
```
这种表示法并不意味着你在调用它时要写方括号。相反，这是 Python 文档中用来表示第二个参数是可选的。你可以只用一个参数调用 `sum` 一个列表，它会对值求和；或者你可以用两个参数调用，一个是值的列表，另一个是起始值，然后它会遍历可迭代对象中的所有值，并将它们加到起始值上。

这里说的是：返回数字的可迭代对象的和（而不是字符串），再加上参数 `start` 的值，它默认为 0。当可迭代对象为空时，返回 `start`。

把 2、3、4 加起来得到 9：
```python
sum([2, 3, 4])
```
把 2、3、4 再加一下。对字符串不起作用。

这个起始值是干啥的？如果我从 5 开始，那我就加 5、2、3、4：
```python
sum([2, 3, 4], 5)
```
那有啥用呢？比如你要加一些不只是数字的值。要开始，必须提供该类型的值。记住，我可以将 `[2, 3]` 添加到列表中得到一个更长的列表。以同样的方式，我可以对包含 `[2, 3]` 以及 `[4]` 的列表求和，只要我从一开始就有一个列表：
```python
sum([[2, 3], [4]], [])
```
如果我没有从一个列表开始，我会尝试将这个列表添加到数字 0，这是不可能的。这就是如果我没有提供起始值而进行求和会发生什么。但由于我一开始提供了一个空列表，然后我加入了 `[2, 3]`，然后我加了个 `[4]`，最后我得到了一个列表 `[2, 3, 4]`。

`max` 有两种形式。你可以传递一个可迭代对象，比如一个列表，还可以传递一个可选的键函数，它会返回最大值；或者你可以传递多个不同的参数，比如一堆数字，再加上一个键函数，然后它会去借些函数的最大值。它说用一个参数返回它的最大项，那是你传进去的列表的一个元素；用两个或更多的参数，返回最大的那个参数。

一个范围的最大值，到 5 为止是 4：
```python
max(range(5))
```
或者我可以传递参数：
```python
max(0, 1, 2, 3, 4)
```
那样也能达到同样的效果。

这个 `key` 函数是怎么回事？文档没告诉我，但其实发生的是，它对你考虑的每个元素应用一个函数，并根据调用这些函数的返回值实际计算出最大值。

你可以问：如果我关心的是某个代数表达式，比如 $7 - x - 4 \times (x - 2)$，从 0 到 9 的范围内最大值是多少？这是一个抛物线，最大值恰好在 3。如果我将这个指定为我的关键函数，那么它将告诉我在此范围内调用这个函数的输出的最大值是 3。如果我将这个函数应用于数字 3，那么我得到 8；但如果我将它应用于 2，我会得到一个更小的值；如果我把它应用到 4 或 5 或 6 或 7，我也将得到一个较小的结果。这就是为什么它给我返回值 3 的原因。

这里有第三个叫做 `all`。`all` 接受一个可迭代对象，如果在调用 `bool` 函数时可迭代对象的每个元素都返回 `True`，则返回 `True`；如果可迭代对象为空，则返回 `True`。

这个 `bool` 函数是什么？`bool` 告诉我一个值是 `True` 还是 `False`。5 是一个真值，`True` 也是一个真值，即使是 -1 也是一个真值；但是 0 不是一个真值，它是一个假值。同样，`'hello'` 是一个真值，而空字符串是一个假值。在我们讲述布尔上下文时，我们就学过这些。

关于 `all`，假设我有个范围是 5，然后我想问，对于范围内的 $x$，$x$ 是否小于 5：
```python
[x < 5 for x in range(5)]
```
我会得到 `[True, True, True, True, True]`。`all` 的目标是将它们聚合在一起，并告诉我它们是否都为真。我不必传递给它一个布尔值列表，我可以把数字列表 0、1、2、3 和 4 传给它，然后它会告诉我 `False`，因为 0 是假的，这些并不都是真值。

这是三个操作序列的内置函数。还有 `min` 和 `any`，它们是 `max` 和 `all` 的补充。

字符串是一种抽象，是文本数据的表示。我称它们为抽象，因为我们不关心它们究竟是如何编码的，但它们确实代表信息。它们可以表示数字，而我们写数字的方式都可以用字符串表示。我们有科学计数法，有一些小数点，所有这些都只是以某种方式告诉我们信息的字符串。它们可以表示语言：正如想象力赋予事物形态，诗人的笔将它们转化为形状，并赋予虚无一个具体的居所和一个名字。我觉得莎士比亚写《仲夏夜之梦》的时候，他是在谈论计算机科学和抽象。

你还可以使用字符串来表示程序。这是一个定义 curry 函数的字符串：Python 源文件就是字符串。如果我把这个放到一个源文件中并执行它，那么我就定义了 curry 函数。顺便说一下，如果我启动 Python 并创建完全相同的字符串：

curry = 'def curry(f): return lambda x: lambda y: f(x, y)'

它只是一个字符串，但如果我执行这个字符串，那么我刚刚定义了 `curry`。如果我用之前只是个字符串的东西来加工函数，事实上我可以把数字加在一起。

关于字符串的一些细节，你可能在课程中已经发现了，但我现在会重复一遍。有三种不同的方法来写一个字符串：我可以用单引号，我可以用双引号。它们是一样的，除了如果你在双引号字符串中间放一个撇号，它也能正常工作；如果你在单引号字符串中间这么做，那么它会结束字符串。不必只在字符串中输入英文字符，输入中文也可以。单引号和双引号的字符串是等效的。

三引号字符串可以跨越多行。我经常用它们来写文档字符串，因为很多时候文档字符串会延伸到多行，当你添加文档测试时。当我评估这个多行字符串时，它在最后显示的内容都适应一行。发生的事情是它使用了一个特殊的符号来编码一行的结束和另一行的开始，这就是换行。每当你在行内看到一个反斜杠，它转义了后面的字符，而这意味着这两个字符在字符串中实际上只是一个字母序列中的一部分，就是这个反斜杠和后面的字符在一起。而这个 `\n` 的意思是换行，也就是开始新的一行。

字符串是序列。长度和元素选择操作与你期望的类似。Berkeley 的长度是 8，这意味着有 8 个字母，每个字母都被称为一个字符。元素选择有相同的索引方案：0、1、2、3，但结果可能不是你想象的那样。你得到的是一个字符串，即使你选择的是一个字符。列表不是这样工作的：如果你有一个数字列表，并选择索引为 3 的元素，你会得到一个数字，而不是一个列表；但对于字符串，你得到的是一个字符串，但只有一个元素，只有一个字符。

对于字符串，`in` 和 `not in` 与其他序列类型有一点不同。不要只在这串字母里找单个字母，可以找整个单词。如果我说 `'here' in "Where's Waldo?"`，那它会告诉我是真的。如果我说 234 在这里，尽管 2、3 和 4 是挨着的，它还是会说是假的。如果我在这里找列表，那也是假的。在列表里，你只能一个元素一个元素找，但在字符串里，你可以找连续的字母。这是因为在处理字符串时，你更关心整个单词，而不只是单个字母。字符串是一种特殊的抽象，它在很多方面像序列，但它的行为与其他序列有些许不同。

Python 中的字典是一种内置数据类型，用于存储键值对。键（key）用于查找某个值，而对应的值即为你查找的内容。在代码中以及作为值显示时，它们的书写方式都使用花括号和冒号来分隔键和值。

咱们来看看：将名称 `numerals` 分配给字典的这个语句，实际上是用三对逗号分隔的键值对构建一个新的字典，每对之间都用逗号分隔：
```python
numerals = {'I': 1, 'V': 5, 'X': 10}
```
在这个特定的字典中，所有的键都是字符串，所有的值都是数字，但不一定非得这样。你可以使用数字或字符串作为键或值。

创建了 `numerals` 之后，我最常做的操作就是根据键查找特定的值。现在有了字典，我们使用与列表相同的项目查找语法，但我们不能只是放一个索引进去，就像我想要索引为 0 的元素一样，这将给我一个键错误（KeyError）。对于字典，我可以在方括号中放入的唯一值以查找它们的是键。我可以查找 `'V'`，这给我数字 5，对应于 `'V'`；我还可以查找 `'X'`，但我不能查找 `'X'` 射线，因为它不在里面。我也不能按它们的值查找键。也许你想查找数字 5 的键，但那也不起作用。字典只能单向操作。

字典也是序列。特别是，它们是键的序列。所以如果我用数字建一个列表，我就能看到所有的键。这意味着我可以在 `for` 语句中使用数字来遍历所有的键。

那如果我想遍历所有的值呢？事实证明这也是可能的，使用以下语法：
```python
numerals.values()
```
然后你需要这些括号。得到的东西看起来有点奇怪，它说字典的值是 `[1, 5, 10]`。这是一种序列的类型，尽管它不是一个列表。你不能像列表一样做任何事情，但你能做很多事情。比如说，你可以把它们加在一起，或者你可以使用 `for` 语句迭代每一个。如果出于某种原因你真的需要一个列表，你可以在 `numerals.values()` 上调用 `list`，这将给你一个普通的列表，而不是字典值，这是一种仅与字典相关的特殊序列，就像范围是一种仅与整数相关的特殊序列一样。

字典可以构建为空元素、一个项目或多个项目，就像我们所看到的那样。同样适用于值本身可以是任意复杂的情况。就像列表中的元素可以是另一个列表一样，字典中的值也可以是一个列表。就像这样，除了我需要实际在那里放一个引号，而且你可以让一个值是一个列表，另一个值是一个字符串，那将完全可以。

现在，如果我们把这个东西称为 $d$，我可以获得键为 1 的元素，我也可以获得键为 3 的元素。我还可以弄清楚有多少个元素，两个，正描述了有两个键的事实。与这些键对应的值的长度可能不同。这个值有两个元素，因为它是一个列表。这个值有多少个元素？它是一个有五个字母的字符串。

关于字典键有两个重要限制：
首先，你不能重复使用一个键。如果我说 1 是第一个，1 也是第二个，那么我得到的将是一个只有 1 的字典。如果我想要将一个键与两个不同的值关联起来，我应该有一个键与这些值的列表相关联。
第二个限制是键本身不能是列表或字典。这会导致出现错误：不可哈希的类型列表（unhashable type: 'list'）。不可哈希是计算机科学中的一个技术术语，我很想教给你，但我得留点东西给 61B，所以你可以在那里学到，或者你也可以在互联网上阅读相关内容。我遇到这个错误的原因是我尝试使用列表作为键，在 Python 中是不允许的。同样，我不能把字典当做键，我会得到相同的错误。但把字典当做值是完全没问题的。任何东西都可以是一个值，这些限制只适用于键。

再次强调一下，字典是键值对的集合。字典的键不能是列表或字典，而且两个键不能相等。对于任何给定的键，最多只能有一个值。第一个限制与 Python 字典的基础实现相关；第二个限制是字典抽象的一部分，即它应该为你提供关键字的值。如果一个关键字重复了，那么就不会有关键字的值，因为会有两个。字典的核心就是找到特定关键字的一个值。如果你想为一个关键字关联多个值，可以将它们存储在一个序列中，比如一个列表。

你也可以使用字典推导式构建字典。这是一个复合表达式，你可以在其中写下关键字的样子和值的样子，然后你写下一些迭代表达式作为源，它会给你一个序列，从中构建关键字值对。你可以筛选其中的一些。为了知道如何构建键和值，你可以为这个迭代表达式中的每个元素取一个名字。

关于过滤表达式的最后部分是可选的，所以有一个简短版本的省略了这一部分。这是一个表达式，它通过添加一个以当前帧为父帧的框架并创建一个空的结果字典的评估过程来评估为一个新的字典。然后在完全评估表达式之前，我们填充这个字典。对于通过评估此迭代表达式获得的可迭代值中的每个元素，将名字绑定到来自第一步的新帧中的元素。名字现在有一个值，是这个序列中的一个值。然后，如果过滤表达式评估为真值，将键表达式的值与值表达式的值配对，添加到结果字典中。

咱们来看一下字典推导式：
```python
{x * x: x for x in [1, 2, 3, 4, 5] if x > 2}
```
这句话的意思是：对于 1, 2, 3, 4, 5 中大于 2 的每个 $x$，$x$ 的平方与 $x$ 相关联。$x$ 将被绑定到 1；$x$ 不大于 2，那个会被跳过。2 也是一样。但 3 大于 2，所以我们从 3 的平方到 3 添加了一个键值对，这就是我们在输出中看到的。我们还对 4 和 5 做同样的操作，最终得到一个通过评估这个大字典推导式映射各种数字到它们的平方根的字典。

值得试着在一个例子中使用其中一个。我们开始吧：实现 `index` 函数，该函数接受一系列键、一系列值和一个两参数匹配函数。它返回一个从键到列表的字典，在该字典中，每个键 $k$ 对应的列表包含所有值 $v$，使得 `match(k, v)` 是一个真值。

当你说明一个从键到列表的字典时，意味着字典中的每个条目都将有其中之一的键，关联的值将是一个列表。在这个例子中构建一个具有所有这些键 7、9、11 的字典，这就是我们在该例子中看到的。值取自提供的列表，范围从 30 到 50，但每个键对应的列表只包含此范围的元素，对于这些元素，该函数返回一个真值。

这个函数是为了给定一个键和一个值，只有在键可以整除值的情况下才返回 `True`，如果值是键的倍数。这是为了返回一个字典，其中 7 作为键，对应于在此范围内所有 7 的倍数的列表，对于 9 和 11 也是如此。

这是字典推导的一个自然应用。实际上，我们要的键已经以键列表的形式提供给我们了，所以实际上并没有太多的工作要做，以便找出键的表达式，它只是 $k$。这个 $k$ 必须与键匹配，但我也可以使用一个不同的字母。看起来 $k$ 是一个基于这个描述的好选择。

那么，我们如何构建一个匹配键 $k$ 的值列表中所有值的列表呢？这就是列表推导的一个例子：
```python
def index(keys, values, match):
    """返回一个字典，将 keys 中的每个键映射到 values 中满足 match(key, value) 的值列表。"""
    return {k: [v for v in values if match(k, v)] for k in keys}
```
