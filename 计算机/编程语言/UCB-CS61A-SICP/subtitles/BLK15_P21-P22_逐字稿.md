# 字符串表示

在面向对象编程的比喻中，我们说一个对象应该表现得像它要表示的那种数据。而其中一个方面就是，一个对象应该知道如何向世界展示自己，或者生成自己的字符串表示。

而字符串很重要。它们不仅是人类用来彼此交流的自然语言中的描述，也是编程语言中的描述。你可以把一个表达式放在一个字符串中。

所以在 Python 中，这种区别已经内置到语言中。所有对象都有两种字符串表示：一种被称为 `str` 字符串，它被设计成对人类可读；相比之下，`repr` 字符串被设计成对 Python 解释器可读。也就是说，它应该是一个表达式，Python 语言中的一个表达式。

现在，很多时候 `str` 和 `repr` 字符串是相同的，因为 Python 被设计成一种人们可以阅读的语言。所以，很多表达方式与一个人试图传达相同思想时可能写下的形式完全相同。在任何情况下，明晰都是第一位的。但有时它们会有所不同，让我们看一个例子。

首先，我们将考虑对象的 `repr` 字符串。有一个名为 `repr` 的内置函数，它将一个 Python 表达式作为字符串返回，该表达式会评估为一个相等的对象。如果我在 `repr` 上调用帮助，这就是我在语言内看到的内容：`repr` 可以被调用在任何对象上，它会生成一个字符串，而且它应该返回对象的规范字符串表示。对于大多数对象类型，文档中说，对对象的 `repr` 调用 `eval` 会给你一个与原始对象等价的对象。

对值调用 `repr` 的结果正是你在交互式会话中看到的内容，这就是 Python 在你评估的表达式正下方打印出来的内容。如果我计算这个表达式，它代表着 $10^{12}$，规范的字符串表示是 1，然后是 2，然后是 12 个 0，然后是一个小数点，然后是一个 0。而这就是显示出来的东西。如果你调用 `repr` 对 $10^{12}$ 的结果进行打印，同样的东西也会被显示出来。

现在，有些对象没有一个简单的 Python 可读字符串，无法写下一个表达式很容易捕捉到某个对象的一切，或者一个等于原始对象的表达式。这通常对于复合对象如函数或类是真的。内置的 `min` 函数就不能用一个表达式写下。所以，相反，当你调用 `min` 的 `repr` 时，你看到的是这个代理，它使用尖括号来表示这实际上根本不是一个 Python 表达式。这只是一些标准的人类可读的描述，因为生成一个 Python 表达式实际上是行不通的。

对象的 `str` 字符串可能是不同的。人类可解释的字符串也很有用，因此我们希望我们的程序能够生成它们，因为程序通常需要与用户进行一些通信。

这里有一个例子。有一个 `fractions` 模块是标准库的一部分，它有一个 `Fraction` 类。一个分数是由分子和分母构建的。分数的表示只是对类本身的调用，就像你在第一次构建分数时所做的那样。但这不是人类书写分数的方式，人们书写分数就像这样。

所以 `str` 是一个内置函数，它接受任何对象，返回一个字符串，其中字符串是原始对象的一些人类可解释的表示。对表达式值调用 `str` 的结果是当你实际调用 `print` 函数时 Python 打印出来的内容。所以，如果我打印 `half`，我会看到 `1/2`。现在，注意这个有引号，因为这是一个字符串，而这只是当你打印字符串时发生的事情：字符串的内容。

好的，让我们试一下。

```python
from fractions import Fraction
half = Fraction(1, 2)
```

从 `fractions` 模块导入 `Fraction`，这使我可以访问这个类，并将其示例绑定到名称 `half`。现在 `half` 是一个分数。`half` 的 `repr` 字符串就是那样的。如果我打印 `half`，我会看到 `1/2`。`half` 的 `str` 字符串是 `'1/2'`。

现在，如果我评估 `half` 的 `repr` 字符串，我会得到这个分数。这是一个不同的对象，但它是等价的，对吧？如果我评估字符串 `'1/2'`，事实证明这是一个有效的 Python 表达式。在这种情况中，那只是一种巧合而已，你得到的不是一个分数，它是一个浮点数。`1/2` 实际上只是为了让人类能够理解。

我们可以通过在字符串上尝试它们来更多地了解包装器和胶水函数。这是一个字符串：

```python
s = 'Hello, World'
```

当我评估 `s` 时会发生什么？我看到了那个字符串。这就是当我打印出 `s` 的包装器时发生的事情，一样的事情。

现在，如果我打印 `s`，引号会消失吗？这正是当我获取 `s` 的 `str` 时看到的，因为 `s` 的 `str` 就是 `s`。现在，如果我只调用 `s` 的 `repr` 会发生什么？我看到引号中有引号。那里发生了什么？`repr` 给我的是一个字符串，如果我评估它，我会得到原始字符串。

如果我调用 `s` 的包装器的包装器的包装器会怎样？我会得到一团糟。那里发生了什么？这不仅是引号内的引号，而是引号内的引号内的引号内的引号。而且，Python 必须使用反斜杠来指示哪些引号真正结束字符串，哪些不是。那些细节并不重要。

重要的是，如果我评估、评估、评估 `s` 的 `repr` 的 `repr` 的 `repr` 的结果，我会得到 `s`。现在，如果我一开始就评估 `s` 呢？我会得到一个错误。`Hello, World` 不是一个有效的 Python 表达式。当我在它周围加上引号时，它就变得有效了。所以，如果我评估 `s` 的 `repr`，一切都没问题。但我不能评估 `s` 或 `s` 的字符串，因为我这里的内容不是有效的 Python。

Python 中的 f-strings 是一项功能，允许你在字符串字面量中生成各种表达式的字符串。这是 Python 中首选的字符串插值方法。这是什么？字符串插值涉及评估字符串字面量，这是带有引号的一些文本，但也包含表达式，这些表达式被评估并成为字符串的一部分。并且在构建涉及一些预定义文本以及评估某些表达式的字符串时使用字符串插值。

你以前可以通过字符串连接来实现这一点。例如，如果你想编写一个包含 $\pi$ 的字符串，你可能会将以 `pi` 开头的字符串与包含 $\pi$ 的数字的字符串以及带有省略号的另一个字符串相加。当然，你可以在较大的表达式中使用此表达式的结果，例如将其打印出来。

字符串插值是生成此字符串的另一种替代方式，它更快且更简洁，使用 Python 中的 f-string 功能。我们将它们称为 f-strings，因为在引号之前有一个 `f`。f-字符串的特殊之处在于，它们可以包含大括号内的其他表达式，并对这些表达式进行求值。

因此，你可以编写你想要的文本，以及你想要在字符串中进行评估和包含的表达式。这是一个字符串字面量，但其值为 $\pi$，而不是字符 `pi` 嵌入其中。同样，这只是评估为一个字符串，因此，我可以将它嵌入到较大的表达式中，例如将其打印出来。

评估 f-string 字面量的结果包含每个子表达式值的 `str` 字符串。我们马上会看一些例子。而子表达式是在当前环境中评估的，这意味着你可以用连接构建的任何内容，也可以用字符串插值构建。

这里有一个 f-字符串，这只是内容：`2 + 2 = {2 + 2}` 将被像普通字符串一样评估。但如果我在它的某部分周围加上花括号，那么这就被视为 Python 表达式，会被评估，然后嵌入到生成的字符串中。如果没有 `f`，你就只会得到一个普通的字符串，其中包含花括号。

在 f-字符串中，可以在这里使用任意表达式，并且它可以引用当前环境。例如，`abs` 被定义了。如果由于某种原因我改变了 `abs` 的含义，现在它是内置的 `float` 函数，那么计算相同的表达式将使用 `abs` 的当前值。任何合法的 Python 表达式都可以放在这里。如果我真的想的话，我可以写一些复杂的 lambda 表达式来得到 4。

对于在字符串内部以及如何使用花括号有一些详细的限制，这些都是你想学的。在这门课程中，它们并不是必须的内容，只是因为它们是与 Python 特定的非常低级的细节有关。但是这个包含表达式的字符串字面量的一般概念，被称为字符串插值，在许多不同的编程语言中都存在。

我说过，评估 f-string 表达式的结果是子表达式值的 `str` 字符串。所以，如果我们有一个对象 `half`，它有一个不同的 `str` 和 `repr`。这里是 `repr` 字符串，这是 `str` 字符串。构建 f-字符串时会发生什么？

```python
f'half of half is {half * half}'
```

你得到的是 `str` 字符串，而不是 `repr` 字符串。如果你真的想要 `repr` 字符串，你可以直接调用这个上面的 `repr`，然后你就能得到它。

子表达式的评估就像在 Python 的任何其他地方一样，它们可能有副作用。如果我有一个列表，里面有 9、8、7，然后我构建一个字符串：

```python
f'{s.pop()} {s.pop()} {s}'
```

那么这些表达式会按顺序求值。这个是 7，这个是 8，现在 `s` 里只剩下数字 9 了。

# 多态函数

多态函数是一种适用于许多不同数据类型的函数。`str` 和 `repr` 就是很好的例子，因为你真的可以传递任何类型的对象给内置的 `str` 和 `repr` 函数。而且，它们总是应该做正确的事情。

这怎么可能呢？根本的想法是，`repr` 只是要求它的参数显示自己。在 Python 中，这是通过使用一个特殊的方法名来实现的。这是一个特殊的名称，因为它对应于一个内置函数。但这个一般的想法——你可以有一个函数，只是询问参数要做什么，当然适用于 Python 语言之外。

封装特别是指调用一个名为 `__repr__` 的零参数方法，以便在其参数上获取它返回的封装字符串。所以，我可以在 `half` 上调用 `repr`，这是分数 1/2，或者我可以调用它的方法。调用方法是在类中查找的，所以真正知道如何为分数生成 `repr` 字符串的是分数类，不是 `repr` 函数。

同样的，`str` 调用一个零参数方法，相应地称为 `__str__`，另一个特殊方法名。所以我如果想的话，可以直接调用这个方法，这会生成表示分数的 `str` 字符串。

这里有一个非常重要的思想：你可以编写一个像 `str` 或 `repr` 这样的函数，实际上它根本没有太多的逻辑。它只是推迟到传入的参数上，通过调用一个带有特定名称的方法来决定要执行什么操作。

那么，我们来看看 `repr` 和 `str` 到底是如何实现的。原来情况比我描述的稍微复杂一些。与其只调用其参数上的 `repr` 方法，而是忽略了一个名为 `__repr__` 的实例属性。`repr` 函数内部只调用了一个名为 `__repr__` 的类属性。

我该如何实现呢？以下哪个函数定义对应于一个名为 `repr` 的函数，它接受某个参数，查找名为 `__repr__` 的类属性并调用它？这里有五个选项，只有一个做我描述的事情。想一想吧，我会在 3、2、1 告诉你答案。

这个能够跳过实例属性，或者通过查找参数的类型来忽略它们，这样你就得到了类。因此，请求类的 `__repr__` 属性肯定会得到一个类属性。现在，它是一个作为函数的类属性。而且，该函数不是绑定方法，因为他是在类上查找的。所以，你必须明确传入 `x`，以便在特定参数 `x` 上调用这个类属性。我们马上会看一个例子。

`str` 也很复杂，甚至比 `repr` 更复杂。被忽略的实例属性叫做 `__str__`。如果在类上根本没有 `__str__` 属性，那么调用 `str` 只会返回 `repr` 返回的内容。所以，默认情况下它们是相同的。只有在你明确地让他们不同的情况下，他们才会不同。

我们在这里使用一个重要的概念，这就是接口的概念。当我第一次谈到面向对象编程时，我说这个隐喻的核心是对象会相互传递消息。这就是他们互动的方式。现在，语言中的机制是他们只是查找属性或方法，这就是他们进行通信的方式，这就是传递消息的概念。传递消息就是这个隐喻，查找属性实际上是我们为了在消息传递中执行操作而进行的。现在，属性查找规则是以一种特殊的方式设计的。

它们允许不同的数据类型通过具有相同的属性名称来响应相同的消息。而共享消息，即存在于许多不同类上并引起这些不同类相同行为的属性名称，是一种强大的抽象方法。

这就是我们将其称为接口的东西。一个接口是一组共享的消息和一些规范，告诉你它们应该做什么、代表着什么。

举个例子，实现 `__repr__` 和 `__str__` 方法，并使这些方法分别返回 Python 可解释和人类可读的字符串的类。

接口不一定要内置到语言中，尽管这个是这样。如果你曾经只是定义了一堆类，它们都有相同的方法，而且所有这些方法做相似的事情，那么你就创建了一个接口。

所以，让我们看看是否可以构建一个展示这个接口的类。

我们已经看到有一个内置的分数类，咱们来搞个类似的东西。我会称之为比率，这样我们就能把它们区分开来。创建比率的方式很简单，只需传入一个分子和一个分母：

```python
class Ratio:
    def __init__(self, n, d):
        self.numer = n
        self.denom = d
```

如果我们希望 `Ratio` 类的实例能够显示自己，我们需要定义一个包装方法：

```python
    def __repr__(self):
        return 'Ratio({0}, {1})'.format(self.numer, self.denom)
```

它将返回一个字符串，字符串是 `Ratio`，后面跟着括号。在这里，我们的字符串中有两个不同的空隙，我们使用字符串的格式化方法来填充它们。`self.numer` 填充到第一个或 $0$ 索引的空隙，`self.denom` 填充到第二个。

现在，如果我们想要一个可读的字符串，就像分数的例子一样，我们只需写 $0$ 除以 $1$，或者再次写 $0$ 是分子，$1$ 是分母：

```python
    def __str__(self):
        return '{0}/{1}'.format(self.numer, self.denom)
```

现在，我们可以创建一个比例：$\frac{1}{2}$。打印出一半，我们将得到可读的版本；直接显示 $\frac{1}{2}$，我们将得到 Python 表达式。

```python
>>> half = Ratio(1, 2)
>>> print(half)
1/2
>>> half
Ratio(1, 2)
```

Python 语言中有一个特别的话题，那就是特殊的方法名。在 Python 中，有一些名字是特殊的，因为它们具有某种内置行为，而且它们的写法总是一样的：它们总是以两个下划线开始和结束。

所以，当你看到一个名字周围有两个下划线时，那只是表明它具有某种特殊行为，它与内置对象系统以某种方式进行交互。

例如，我们看到的第一个是 `__init__`。这个方法很特殊，因为他在对象构造时会自动调用。除此之外，它只是一个普通的方法。

`__repr__` 在之前的视频中有讨论过。这是一个被调用以生成表示对象的字符串的方法，也是在交互式 Python 会话中用于显示值的方法。

那么，`__add__` 呢？那是一个新的方法。这是一个两参数的方法，用于将一个对象添加到另一个对象中。

有一个叫做 `__bool__` 的参数方法，另一个叫做 `__float__`。这个用于将对象转换为 `True` 或 `False`，告诉你它的布尔值；而 `__float__` 尝试将对象转换为实数。

所以，例如，如果我将 $0$、$1$ 和 $2$ 分别设置为 $0$、$1$ 和 $2$，然后加上 $1$ 和 $2$，我会得到 $3$。如果我调用 `bool` 在 $0$ 上，我会得到 `False`；而在 $1$ 上，我会得到 `True`。而这个 `bool` 函数正好给你在布尔上下文中放置这些对象时会得到的行为，比如条件语句。

现在，可以重新编写整个语句序列。我可以缩写为 $1 + 2$，或者 $1$ 加 $2$；然后使用特殊方法名将 $1$ 和 $2$ 相加，或者使用该特殊方法名将 $0$ 和 $1$ 转换为布尔值。

因此，内置语法和内置函数之间存在对应关系，以及这些特殊方法名实际上是执行工作的。

这是另一个例子：使用接口以允许用户定义的对象与 Python 内置系统进行交互。因此，Python 是非常可扩展的。您可以创建一个新类，并通过重写特殊方法名 `__add__` 来能够使用加号将该类的实例相加。

当你将两个用户定义的类的实例相加时会发生什么呢？发生的事情是你调用了 `__add__`，或者还有另一个叫做 `__radd__` 的方法，我马上告诉你这方面的情况。这实际上执行了加法操作。再说一遍，我们只是在问这些对象：“你们怎么把自己加在一起？”

所以，如果我们想扩展我们的比例类以便能够相加比例，这是完全可能的。我可以加一个 $\frac{1}{3}$ 和一个 $\frac{1}{6}$，得到一个 $\frac{1}{2}$，无论是使用加号，还是使用实际执行加法的方法。在 Python 中，这两个表达式是等价的。现在人们几乎总是使用这个，因为它更容易阅读。这样做的目的只是允许我们使用方法定义语法，以覆盖在两个对象之间使用加号时发生的情况。

你还可以使用 `__radd__`。`__radd__` 和 `__add__` 之间的区别在于，这里是加号右侧的参数，而这里是左侧的参数。

对于数字来说，加法是可交换的。所以，它们的顺序无关紧要，这两个函数是等价的。但你可以想象在一些情况，你可能想要发明一种不可交换的加法，因此使用 `__radd__` 是可能的。

我不会逐个介绍每个特殊名称及其与 Python 内置功能的对应关系，但这在之前已经完成了，记在 Python 文档中，也在这个名为 *Dive Into Python 3* 的在线教材中。

但让我们看看是否可以在我们的比例类中添加加法。我们定义一个 `__add__` 方法，它接收 `self` 和 `other` 参数。它的作用就是计算结果的分子和分母。

所以，两个相加比例的分子是第一个的分子乘以第二个的分母，再加上第一个的分母乘以第二个的分子。分母是分母的乘积。

如果我们想把这个比例缩小为两个互质的整数，那么我们必须计算 $n$ 和 $d$ 的最大公约数，然后我们可以返回 $n$ 除以 $g$ 和 $d$ 除以 $g$ 的比例。

最大公约数是什么呢？我们在课程前面确实谈到过这个。计算它的一种方法是说：当 $n$ 不等于 $d$ 时，我们重新绑定 $n$ 和 $d$ 为 $n$ 和 $d$ 的最小值和 $n$ 减去 $d$ 的绝对值，顺序不定。

```python
def gcd(n, d):
    while n != d:
        n, d = min(n, d), abs(n - d)
    return n
```

所以现在我们可以取 $12$ 和 $8$ 的最大公约数，得到 $4$。我们还可以将 $\frac{1}{3}$ 和 $\frac{1}{6}$ 的比例相加：

```python
>>> Ratio(1, 3) + Ratio(1, 6)
Ratio(1, 2)
```

描述树中的所有不同树通常涉及到术语“节点”。节点是树内的一个位置或位置。它总是另一棵树本身，但使用“节点”这个术语时，考虑到与其他节点的相对位置，这样想可能就没那么有趣了。

每个节点都有一个标签，并且每个节点还有相对于其他节点的配置。3 是 2 的父节点，2 是 3 的子节点。顶部节点是根节点，就像我刚刚做的那样，人们经常使用标签来指代位置。不是说带有标签 2 的节点是带有标签 3 的节点的子节点，通常人们会随意说 2 是 3 的子节点。但实际上，拥有这种家族关系的是节点，它们的标签只是数字而已。

路径是一系列节点的序列，其中每个元素都是前一个节点的父节点或子节点。所以，它们在树状图中相连。最常见的路径是从根到叶子的路径，但也可以有其他类型的路径。

我们能够使用数据抽象处理树，但也可以使用 Python 的对象系统。一棵树有一个标签和一系列的分支，每个分支也是一棵树。我们可以通过定义一个树类，其中包含一个带有标签和分支列表的构造函数来表述这一点，默认情况为空。

我们设置标签，我们检查对于每个分支，该分支是否是一棵树。然后我们分配 `self.branches`。在这里，我们制作一个分支列表，以保留一个副本，并将分支转换为列表，如果它是其他类型。

这是使用数据抽象的定义，非常相似，但有一些重要的区别。现在我们正在使用对象系统，我们定义如何构建一棵树，但我们不必明确定义如何从构建的树中获取不同的属性。在数据抽象中，我们写下了构造函数和选择器。在这里，我们写下构造函数，而选择器是隐式的。`self.label` 将给出标签，`branches` 将给出分支。

更重要的是，在使用数据抽象时，我们必须想出一种将这些部分、标签和分支组合在一起的方法。在这种情况中，我们决定将它们都放在一个长列表中。但我们本可以做些别的事情：把它们放在一对中，把它们放在一个字典中。不管我们做了什么，我们都必须想出一种方法，使用选择器函数将这些部分提取回来。

当我们使用 Python 的对象系统时，我们不必对如何将这些部分组合成一个整体做任何决定。我们总是选择相同的方式：每个部分都是一个属性，一个对象通过它们名称访问所有的属性。

因此，使用对象系统的定义稍微简单一些，但使用树实例就像使用树数据抽象一样。
