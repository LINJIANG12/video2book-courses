接下来是课程内容。我们要讨论表达式。

表达式描述一个计算并评估为一个值。

现在，表达式不是计算机科学特有的东西。数学家们很久以前就开始描述如何组合不同的数字。他们发明了很多用表达式描述计算的方法。为了将两个数字相加，你通过在两个数字之间添加这个加号来表达；除法完全不同，你把一个数字放在另一个上面；为了表示平方根，你把一个数字放在一个小房子里；要取角的正弦，你写 $\sin$，不是 sine，sine 写起来太长了，就写 $\sin$。还有很多其他方式可以表示如何组合不同的值。

原来其中一种是对所有其他方式的泛化，而且这就是我们所需要的。这就是函数调用符号：$f(x)$ 或者 $f(x, y)$ 等等。

所以，作为计算机科学家，我们不再使用所有这些不同形式的表示计算、带下标、上标和竖线。我们将使用函数调用符号来写下所有的东西。

我的观点是所有表达式都可以使用函数调用符号。为此，我将启动 Python 并向您展示。

我通过输入 `python3` 来启动 Python，这将为我提供一种非常新版本的编程语言解释器。现在，一个解释器提供了一个提示，等待我输入一个表达式，然后显示它的值。

所以我在输入这里的表达式：
```python

```
现在包含两个通过加法组合在一起的不同值。显示的值是通过将这两个数字相加得到的。

而且 Python 是一个相当强大的计算器。我可以将多个数字相乘，我甚至可以用括号嵌套，我可以除法。有一个特殊的表示法，如果我想在最后加在一起，用来表示将某物立方。它会很快地为我计算出来。这是一个表达式，这是它的值。

那函数调用表达式呢？调用表达式有一个特殊的形式。你要给出一个要调用的函数的名称，这里是 `max` 函数，然后你写下一些表达式，这些表达式会给你 `max` 要应用的值。2 和 4 的最大值是多少？是 4。
-2 和 50000 的最小值是多少？别搞疯了，所以是 -2。

这些被称为调用表达式：一些函数，然后一些括号，你看到这些用逗号分隔的其他表达式。这是一个调用表达式。

现在，我说过一切都可以用调用表达式来表示，包括乘法、除法和加法等。所以除了加号，它是用来在两个表达式之间相加的，还有一个叫做 `add` 的函数。

现在，它并不总是可用的。我必须写这个导入语句才能访问 `add` 和 `mul`：
```python

```
这只是一个小小的机制。我只是做一次。现在我可以使用调用表达式将 2 和 3 相加：
```python

```
我可以将 2 和 3 相乘，得到 6：
```python

```

现在调用表达式真是个奇妙的东西。例如，它们可以通过使用很多逗号将多个值组合在一起。1、2、3、4 和 5 中的最大值是多少？那是 5。

它们还可以嵌套在彼此之内。我可以把 4 和 6 相乘的结果加 2，然后再乘以这个结果。我已经把 2 加到 4 和 6 相乘的结果上，但我说过我要再用某个数乘以这个结果。那试着把 3 和 5 相加的结果吧：
```python

```

在调用表达式中，你不需要记住操作的顺序。只要表达式的嵌套结构告诉你，在加法之前会先进行哪些乘法就行了。所以你必须先将 4 和 6 相乘，然后再加 2。在使用这些中缀运算符连接不同的值时，生活并不那么简单，因为你必须知道乘法在加法之前执行，以了解表达式的计算方式。

在这门课程中，我们非常支持调用表达式。我们想要确切地了解它是如何工作的。

首先，让我们谈谈调用表达式的结构或解剖。

总是有括号存在。整个东西都是一个调用表达式，其中包括其他表达式。在开括号之前的所有内容都被称为运算符子表达式。通过“子表达式”，我指的只是它是一个表达式中的表达式。操作数在括号内由逗号分隔。运算符和操作数也是表达式。现在这些都是非常简单的表达式：数字 2、数字 3 或者名字叫 `add`。它们会被计算为值：数字 2、数字 3、将两个数字相加的函数。

调用表达式的评估方式始终相同。这是一个评估过程。现在编程语言的工作方式是通过应用评估过程来解释您的表达式。它们只是按照程序一遍又一遍地应用相同的过程。

调用表达式的过程是这样的：按顺序评估运算符，然后评估操作数字表达式。然后您从运算符中得到一个函数，从操作数中获取参数，然后将该运算符的值作为函数应用于操作数的值。所以首先评估所有子表达式，然后应用一个函数。所有这一切都是为了将 2 和 3 相加。

我们之所以这样详细的讲解，是为了观察到相同的评估过程可以多次用于评估更复杂的嵌套表达式。

这是我们之前在解释器中尝试过的嵌套调用表达式。现在，Python 就像魔术一样说了 208。它已经评估了整个东西。那是怎么做到的？它只是应用了那个评估过程。

它说：这是一个调用表达式，我看到括号。因此我必须评估运算符，那就是乘法的函数。我必须评估第一个操作数，这是另一个调用表达式。所以它再次应用相同的过程。相同的过程说，我要评估运算符，那就是 `add` 函数；我要评估操作数 2，它只是数字 2；然后我会评估 `mul(4, 6)`，这是另一个调用表达式。幸运的是，我有一个评估调用表达式的过程。就是这样：我评估运算符和操作数字表达式，以得到将数字 4 和数字 6 相乘的函数。由于我现在已经评估了所有操作数，我可以将乘法应用于 4 和 6，得到 24。这就是该表达式的值。

现在我已经评估了这个子表达式的所有操作数，这意味着我可以将函数 `add` 应用于 2 和 24，以得到 26。

到目前为止，我评估了一个操作数，我已经评估了运算符。但在我开始乘法之前，我仍然需要评估最后的运算对象。这意味着我必须弄清楚添加 3 和 5 是什么。那是另一个调用表达式。我找到运算对象和运算符，评估到添加函数、3 和 5，将 3 和 5 相加得到 8。将 26 乘以 8，得到 208。

这个图表被称为表达式树。这就是计算机在评估这个嵌套调用表达式时发生的一切的插图。这里要观察的重要一点是表达式的评估顺序。在正确的时间提供正确的信息：你必须已经弄清楚这个东西等于 26，这个东西等于 8，然后才知道要乘在一起以完成计算。

这也只是相同过程一遍又一遍的插图——评估调用表达式的过程。整个事情就是一个表达式树，那被称为操作数字表达式。这是那个非常子表达式的值。我只是把这个东西复制到这里，然后我按照流程计算了它的值 26。这也是传递给 `mul` 的第一个参数。一个参数总是一个值，而这个值 $26 \times 8$ 就得到了 208，整个表达式的值。

在这门课上，定义函数是你要做的最重要的事情之一。在我讲解定义函数的细节之前，让我们花点时间欣赏一下这一刻。

我在第一天告诉过你，这门课程的核心就是抽象，今天我们学习的是抽象的工具。赋值是一种简单的抽象方式，因为你可以将名称绑定到值上。当然，抽象是将复杂的东西命名，并将其作为一个整体对待，而不用担心所有的细节。

函数定义是一种更强大的抽象方式，因为你将名称绑定不仅仅仅是一个简单的值，而是整个表达式、语句或一系列语句。真正复杂的东西，我们给它一个名字，并将其作为一个整体对待，而不用担心它的细节。

今天我们要定义的函数非常简单，但很快它们会变得更加复杂。定义函数的方式是使用 `def` 语句，看起来像这样。

这是一个通用版本：你写 `def`，这是 Python 中的一个关键字，然后给函数起个名字，并列出它的形式参数。这些参数将是指向传递到函数的参数值的名称。然后冒号，缩进下一行，编写函数的主体，在最简单的情况下只是 `return`，然后是一个在每次调用函数时被评估的返回表达式。

在 `def` 和冒号之间的这行顶部被称为函数签名。而它最重要的作用是通过列出形式参数告诉你函数需要多少个参数，每个参数将被绑定到一个参数值。我们马上就会看到它是怎么工作的。

函数体是指在第一行之后缩进的所有内容，它定义了函数的功能。所以在最简单的形式中，它只是一个 `return` 关键字，后面跟着一个返回表达式，而表达式描述了一个计算过程，每次调用函数时都会被评估。

这个 `def` 语句是一个两行语句，定义了一个新的函数。评估 `def` 语句有个步骤，这就是执行的步骤：

首先，每次有一个 `def` 语句时，我们都会创建一个新的函数，而且该函数的签名在第一行给出。
第二件事是我们设置该函数的主体，也就是实际执行的代码，为第一行之后的所有内容。
最后，我们将给定的名称绑定到我们在当前环境的框架中创建的新函数上。记得那些框架吗？我们会谈很多关于那些的。

这是 `def` 语句的执行过程，总是一样的。最重要的部分在这里：第二点说我们将函数的主体设置为第一行之后的所有缩进的部分。它并没有说我们实际执行那个主体。
