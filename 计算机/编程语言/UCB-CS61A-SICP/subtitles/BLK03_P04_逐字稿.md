每个斐波那契数都与它的索引关联，即在斐波那契数列中的位置。因此，我们通常称之为第0个斐波那契数、第1个、第2个、第3个、第4个、第5个，以此类推。所以第5个斐波那契数是 5。它可能在这个序列中的第6位，但我们把这个称为第0个斐波那契数，因为它是 0。这只是一种惯例。

这里有一个函数，它接受 $n$，即我们想要斐波那契数列中第 $n$ 个数的位置或索引，然后计算 $n \ge 1$ 时的第 $n$ 个斐波那契数。它通过跟踪各种值并执行 `while` 语句来实现这一点。

在设计迭代函数时，要考虑的最重要的事情之一是你需要跟踪的信息，为了执行迭代。在这种情况下，为了计算下一个斐波那契数是前一个和当前数的和，我们需要跟踪这些斐波那契数是什么。

所以我们从序列的开始开始。第0和第1个斐波那契数分别是 0 和 1。然后我们还需要跟踪我们在序列中的位置，这就是我们在这里使用 $k$ 的方式，$k$ 用来跟踪索引。在执行这个 `while` 语句的整个过程中，$k$ 会告诉我们 Fibonacci 数与名字 `curr`（当前值）相关联。

此刻的 Fibonacci 数是第1个，就是这个 $0^{\text{th}}$, $1^{\text{st}}$。但当我们执行这个 `while` 语句时，$k$ 会改变，`curr` 也会改变，而 $k$ 将告诉我们 `curr` 对应的是哪个 Fibonacci 数。

好的，这里说的是 $k < n$。我们将重新绑定 `pred` 和 `curr`，使它们成为序列中的下两个数字。所以，前一个数与当前数相关联，计算出一个新的当前值。在这里，我们使用斐波那契数列的定义：下一个斐波那契数是当前数和它的前一个数的和。我们将其绑定为新的当前斐波那契数，其索引比之前大 1。这就是为什么我们将其绑定为 $k + 1$ 的原因。

`while` 语句的结构允许我们执行这个计算多次，直到找到第 $n$ 个斐波那契数为止。因此，我们一直做，直到 $k < n$ 为止。这意味着最后 $k = n$，因为我们每次只是将 $k$ 加 1。找到第 $n$ 个斐波那契数，我们将其绑定到 `curr`，然后返回它。

在这个例子的环境图中：我们在调用 `fib` 函数的本地框架中跟踪名称 `pred`、`curr`、$n$ 和 $k$。$n$ 永远不会改变。所以如果我们要找第 5 个斐波那契数，也就是 5，那么一开始 $n$ 就是 5，`pred` 和 `curr` 就是 0 和 1，$k$ 就是 1。这些名称每次完成执行时绑定的值是什么，我们都知道。

所以第一次循环，我们将重新绑定 `pred` 和 `curr`，它们将是序列中的下两个数字。然后说，现在 `curr` 指向第 $k$ 个斐波那契数，其中 $k$ 是第 2 个斐波那契数。就是这样。然后我们再次执行 `while` 语句的主体，将 `pred` 和 `curr` 向上移动，并同时改变 $k$。我们将重复这个过程 4 次。

现在 $k = n$，所以不是 $k < n$ 的情况。我们完成了执行 `while` 语句，然后返回 `curr`，这是第 5 个斐波那契数 5。

这是一个讨论问题：如果在 `fib` 的主体中，我进行了以下更改呢？我将 `pred` 和 `curr` 绑定到 1 和 0，而 $k = 0$。这个 `fib` 的替代定义和原来的定义一样还是不同？

这仍然是对于每个大于或等于 1 的 $n$ 的正确的 `fib` 实现，就像我们旧的定义一样。但它更好，因为它可以正确计算第 0 个 Fibonacci 数。找到一个特定的输入值，在这种情况下，这比旧的更好。

特别是，如果 $n$ 是 0，那么当前值是 0，这是第 0 个斐波那契数。当我们到达 `while` 语句时，$k$ 将是 0，$n$ 将是 0。因此，循环体将永远不会执行，并且将返回 0，这是第 0 个斐波那契数。太好了，我们之前就没做到这一点。

但是如果 $n = 5$ 呢？我们从 `curr` 为 0 开始。然后我们实际上会执行 `while` 语句的主体 5 次，而不是 4 次，因为我们从 $k = 0$ 开始，而不是 $k = 1$。所以，`curr` 将为 0，然后是 1，1，2，3，5，我们仍然会得到第 5 个斐波那契数。

咱们聊聊在编程语言中控制语句的作用吧。

控制语句（比如 `if` 和 `while`）与函数不同，它们控制哪些代码部分执行以及执行多少次。但也许我们可以只用函数来实现同样的控制？咱们来研究一下。试着写一个能完成与 `if` 语句相同功能的函数。

这是一个 `if` 语句的特定格式和执行规则：四个条件语句，每个子句按顺序考虑。考虑到一个从句时，我们要做的评估标头的表达式是否存在。如果它是一个真值，或者我们在 `else` 中，那么我们执行 suite 并跳过其余的从句。

所以，这是 `if` 从句和 `else` 从句。如果这是真的，那么我们执行这个并跳过这个；如果这是假的，那么我们不执行这个，发现我们在 `else` 条件中，并执行这个。所以，`if` 标头表达式控制着是执行 if suite 还是 else suite。但我们总是选择其中一个，永远不会两者都执行。

如果我们要写一个函数，比如说有一个 `if_` 函数，它接受一个条件表达式、一个 if 代码块和一个 else 代码块，我们难道不能就这样写我们的代码吗？

首先，这在 Python 中是不存在的，但我觉得我们可以尝试实现类似的东西。它的作用是如果条件为真，它将返回 if 代码块的值；如果条件为假，那么它将返回 else 代码块的值。

那我们怎么实现呢？咱们就用咱们已经讨论过的条件语句来实现它吧。

```python
def if_(c, t, f):
    if c:
        return t
    else:
        return f
```

如果 `c` 是 True，咱们就返回 `t` 的值，否则返回 `f` 的值，或者传入 `c`, `t`, `f`。听起来不错。现在，咱们不再需要写 `if` 和冒号，也不用记得缩进是多少，只要在咱们想要的地方使用这个 `if_` 函数，然后按照咱们的方式写所有的代码。

但是有个问题。问题在于调用表达式的求值规则与条件语句相当不同。这个调用表达式的求值是通过评估运算符和操作数表达式，然后将函数 `if_` 应用于这些操作数的值。

在什么情况下，使用 `if` 语句和使用 `if_` 调用表达式会有所不同呢？

让我给你看看。这是我的 `if_` 函数。一开始我们不会用它，我们只会专注于编写一个函数计算 $x$ 的实数平方根，其中 $x$ 可以是复数或正数。只有当 $x$ 为正数时，$x$ 的平方根的实部才是非零的。对于正数 $x$，内置的平方根函数将给我们提供平方根。对于复数 $x$，比如说，$-4$ 的平方根是多少？$-4$ 的平方根是 $2i$。而且是虚数，2 就是虚部，实部是 0。

所以我们写一个简单的函数：如果 $x \ge 0$，就返回 $x$ 的平方根；否则，我们有一个复数，我们根本不会对 $x$ 调用平方根，相反，我们只是说实部是 0，因为整个平方根是虚数。

咱们来执行这个。我们让内置的平方根函数告诉我们 16 的平方根是 4，但内置函数会告诉我们 $-16$ 的平方根是个错误。我们不想要那种行为。相反，我们想知道对于正数，平方根的实部是 4；而对于复数，它是 0，因为整个平方根是虚数。

这个实现挺好的，因为当 $x$ 是 0 的时候，它计算了平方根；在另一种情况下，它会跳过并返回 0。

如果我们取这个 `if` 语句的组成部分，将其转换为对我们的 `if_` 函数的调用呢？

```python
def real_sqrt(x):
    return if_(x >= 0, sqrt(x), 0)
```

如果 $x \ge 0$，那么我们想要取 $x$ 的平方根，否则我们要返回 0。我们可以返回这个结果，并用一个调用替换这个条件语句。

这里将会发生的是，它会对这三个东西调用 `if_`，它们作为 `c`, `t` 和 `f` 传入。如果 `c` 成立，那么我需要返回 `t`，否则我返回 `f`。现在，我有一个非常方便的实现实数平方根的方法，而且所有都能在一行内完成。

让我们看它的运行。内置平方根仍然只对正数有效，但是我的函数 `real_sqrt` 给我提供了结果和错误。

发生了什么？当我们用调用表达式替换条件语句时，我们有了不同的评估规则。在评估这个过程中，我们先确定我们要调用的函数以及我们在执行主体之前调用它的所有三个参数。所以我们发现 $x$ 不大于 0。我们尝试计算平方根，在我们讨论 0 或者其他内容之前，由于对负数进行了平方根运算，我们就遇到了一个错误。

调用表达式不允许你跳过对调用表达式的部分进行评估。相反，在函数被调用之前，所有部分都会被始终进行评估。这与控制语句不同，控制语句实际上会选择执行语句的哪些部分以及跳过哪些部分。这就是它们存在于编程语言中而不仅仅是函数的原因。

有一些表达式允许 Python 解释器跳过评估某些子表达式。让我们快速看一下其中的一些例子。

逻辑运算符 `and` 和 `or` 表现出一种称为短路的行为。这是如何评估某个表达式和另一个表达式的方式，我们将其称为左和右，但这是只是占位符。

首先评估 `and` 左边的子表达式。如果它是一个 False 值，那么整个表达式就评估为那个 False 值。否则，你要评估右边的表达式，而整个表达式的值就是右边表达式的值。所以，如果这是假的，整个都是假的；如果这是真的而这是假的，整个就是假的；如果这是真的而这也就是真的，那么整个就是真的。而且这些值不一定只是真和假，它们可以是 Python 中的任何值，因为每个 Python 值都是真值或假值。

所以，根据这个评估规则，`2 and 3` 会被评估为 3。

评估 `or` 表达式：评估左侧的子表达式，如果它是一个真值，那么整个析取就是真的，所以你完成了，整个表达式的值就是它；否则，你评估右侧的这个表达式，那就是整个表达式的值。

这有什么用呢？让我们看几个例子。比如说，我想写一个函数 `has_big_sqrt(x)`，告诉我某个 $x$ 是否有一个非常大的平方根。返回 $x$ 的平方根是否大于 10。我随便选了个 10，只是因为我想要一个简单的例子。

假设这是程序的一部分，我对平方根的实部感兴趣。所以如果 $x$ 是复数，我不想让程序崩溃，我只想知道 $x$ 的平方根的实部是否很大。我可以写：

```python
x > 0 and sqrt(x) > 10
```

当我运行这段代码时，`has_big_sqrt(1)` 告诉我：1 不是，1000 是，$-1000$ 不是，因为其平方根的实部是 0。而重要的部分是这没有崩溃，即使我有一个表达式，其子表达式取负数的平方根。这永远不会被计算，因为 `and` 的工作方式：一旦确定 $x$ 不大于 0，它就完成了整个表达式的求值。

让我们用 `or` 进行一个例子。你可以做除法，你甚至可以除以一个非常大的数字。但如果一个数变得太大，那么你就不能再用 1 除以它了。$10 \times 100$ 并不算太大。但是 $10^{100}$，那就很大了，但它还不能算太大，我可以用 1 除以它。但是 $10^{1000}$ 呢？那是一个非常非常大的数字，而且我不能用 1 除以它，否则就会得到 0，失去所有真正发生的精度。应该是一个小数点，后面跟着 1000 个 0，然后是一个 1。Python 不是那样工作的，大多数其他编程语言也不是。只有一个很小的数，你可以表示它而不被四舍五入到 0。

假设我有一个定义，用来判断某个数是否合理，即它不太大，以至于你不能除以它并仍然得到一个非零的数。我可以简单地说 $1 / n \ne 0$ 吗？但是如果我传递 $n = 0$，这就将导致崩溃。而 0 是一个完全合理的数字，只是不能在这个特定的测试上运行。

所以如果 $n = 0$ 或者 $1 / n \ne 0$，意味着它不太大，以至于被四舍五入为 0，我可能会写 $n$ 是合理的。那么在这里 0 是合理的吗？当然。10 是合理的吗？是的。而且，你知道，这个大数仍然是合理的。唯一不合理的数字是当我进行指数运算得到 $10^{10000}$ 时，那就像一个荒谬的数字，不是一个合理的数字。

重要的是所有这些都没有崩溃，包括传入的 $n$ 是 0。我们没有计算 $1 / n$，因为我们首先检查了 $n = 0$。由于这是真的，整个表达式就是真的。这就是为什么这种短路行为在 Python 中以及许多其他编程语言中都很有用的原因，它是一种控制的形式。

编程语言的高阶函数是一种特性，它允许我们按照我刚刚描述的那样设计函数，通过表达计算的非常一般的方法。让我给你展示一下我的意思。

我们想要做的是通过定义接受参数的函数来概括模式，从而给我们返回这些模式的具体实例。作为一个一般的例子，让我们看看如何根据它们的长度计算几何形状的面积。

这里有三种形状：正方形、圆形、六边形。每种形状的相关长度分别是正方形的边长、圆形的半径和六边形的边长。每个图形的面积都可以简单表示为 $r^2$、$\pi r^2$ 和 $\frac{3\sqrt{3}}{2} r^2$。

那么我们要做的，就是看看这三个公式有什么共同之处，以及是什么使它们特定于特定的形状。这些常数 $1$、$\pi$ 和 $\frac{3\sqrt{3}}{2}$，是我们感兴趣的形状所特有的，其余的只是关于如何计算形状的面积。所以，如果我们在类似的相关问题中找到这种共同的结构，我们就可以共享实现。

好的，我们实际做一下。我们要写一些关于泛化的代码。我们可以通过返回 $r \times r$ 来定义边长为 $r$ 的正方形的面积函数；我们可以通过返回 $r \times r \times \pi$ 来定义半径为 $r$ 的圆的面积。$\pi$ 是什么？从数学库中我们可以导入常数 $\pi$。然后我们可以计算边长为 $r$ 的六边形的面积，即 $r \times r \times 3 \times \frac{\sqrt{3}}{2}$。

现在我们开始搞起。我们可以计算边长为 10 的六边形的面积，它会告诉我们它略小于 260，这很好。它还会告诉我们，边长为 $-10$ 的六边形的面积是一样的，这有点不对。

那么我们要怎么解决这个问题呢？让我给你展示一些东西，它叫做断言语句。它以关键字 `assert` 开头，后面是一个表达式，这是一个布尔上下文。如果该表达式的值为假，那么每当用户运行 Python 程序时，都会打印出一个错误消息。所以 $3 > 2$，这应该总是为真的。如果不是，那么数学就出了点问题。当这个断言语句执行，并且这是一个真值时，什么都不会发生。但是如果我说的实际上是错误的，那么我会得到一个断言错误和我打印出的消息。

所以我们可以在这里放一个断言语句：`assert r > 0`。如果那不是真，就发送一条消息：“长度必须是正数”。现在这样修复了正方形的情况。而且我们还需要确保在圆形面积和六边形面积中 $r$ 是正数。我可以复制这一行，然后我可以粘贴到这里，再粘贴到这里。但这样我就会重复自己，而且我不应该重复自己，约翰告诉我。

对此我们要怎么办呢？我们可以通过提取它们共有的部分（即 $r \times r$）对这三个例子进行泛化，还有一个断言语句“长度必须是正数”。

我们要定义一个名为 `area` 的函数，它接受一个长度，还有一个形状常数。它给我们提供了我们感兴趣的形状的面积：

```python
def area(r, shape_constant):
    assert r > 0, '长度必须是正数'
    return r * r * shape_constant
```

那么这一切有什么意义呢？

首先，我们表明函数是第一类值，意味着它们可以作为参数传递，可以作为返回值返回，就像编程语言中的任何其他值一样。

高阶函数是这样一个函数，它可以做这些事情：接受另一个函数作为参数，或者返回一个函数。

现在，高阶函数很有用，因为它们能够表达计算的一般方法——如何将事物相加，而不用担心我正在相加的是什么。它们从我们的程序中消除了重复，因为我们只需要定义一次主动求和。

最后，我们可以在函数之间分离关注点。我们希望每个函数只负责一个任务。拥有高阶函数可以使这些任务成为非常通用的计算方法，或者它们的函数——它们作为参数或返回值——可以更具体。
