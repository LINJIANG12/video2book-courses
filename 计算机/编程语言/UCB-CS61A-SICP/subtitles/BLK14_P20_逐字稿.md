转到一个新的主题，继承。

这是 Python 对象系统的一个新特性，几乎每个对象系统和编程语言都存在这个特性。

继承是将多个类关联在一起的一种方法，因为并非每个类都孤立存在。有时，一个类只是与另一个类相似，我们希望表达这种关系。

因此，在使用继承时，你应该考虑的最常用例是当你有两个相似的类，它们在专业化程度上有所不同。专业化的类可能具有与通用类相同的所有属性，以及一些特殊情况的行为。

在 Python 中，你在语法上表达这一点的方式，除了具有一个带有名称和一组语句的类语句外，你还可以在括号中放入一个基类，而基类就是这个类继承的内容。

因此，从概念上讲，通过这个类语句创建的子类与其基类共享所有属性。子类可能会覆盖某些继承的属性，以稍微更改其行为，但未更改的任何内容保持不变。

使用继承时，当我们编写现有类的子类时，我们只需指定这个子类与基类有何不同，其他一切保持不变。

在设计面向对象编程时，另一件需要考虑的事情是何时使用继承，而不是使用组合。

什么是组合？那就是一个对象将另一个对象作为属性。而且这也是一种非常常见的模式。面向对象编程在我们遵循这个隐喻时表现得很出色。也就是说，我们把对象像现实世界中的真实物体一样对待，这有助于我们清晰地思考它们。

继承最适合表示 is-a 关系，意味着支票账户是账户类型的一种。支票账户是账户的一种特定类型，所以支票账户自然继承自账户，并因此具有该账户的所有属性。

组合：当一个对象将另一个对象作为属性时，最适合表示 has-a 关系。例如，银行拥有一组它管理的银行账户。那么在这种情况下，一个银行有一个账户列表作为属性，但银行不会继承自账户，账户也不会继承自银行。它们之间是相关的，因为一个对象将另一个对象作为属性，但根据继承的定义，它们不是相关的。
