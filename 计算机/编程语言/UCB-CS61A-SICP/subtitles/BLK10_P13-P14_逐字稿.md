## P13 Lecture 13 Data Abstraction-cn

维护抽象屏障的目的是为了能够更改数据表示而无需重写整个程序。

让我们深入探讨一下数据表示的这个概念。

数据是什么？某种表示有理数意味着什么？

我们需要确保构造函数和选择器函数一起工作，以指定正确的行为。

除非它的行为像一个有理数，否则你就没有有理数的表示。

行为条件可能会这样写：
如果我们用分子 $n$ 和分母 $d$ 构建有理数 $x$，那么应该成立：
$$\frac{\text{numer}(x)}{\text{denom}(x)} = \frac{n}{d}$$

这里我们将构造函数与选择器以及它们之间的操作关联起来。

数据抽象使用选择器和构造函数来定义行为。这就是数据抽象的整个概念。如果满足行为条件，那么表示就是有效的。

所以，与数据抽象相关的关键基本思想是：你可以通过它的行为来识别某种数据，而不一定是通过你如何构建它，或者实现构造函数和选择器的方式。

所以，让我们回顾一下我们的例子。我们有一个相等度量以及打印有理数的方法，所有这些都不假设有关表示本身的任何内容，只假设构造函数和选择器存在。

在这个抽象屏障下面的构造函数和选择器是通过列表实现有理数。

所以，我可以定义 $x$ 和 $y$：
```python
x = rational(1, 2)
y = rational(3, 8)
```
我应该说 $\frac{1}{2}$ 和 $\frac{3}{8}$ 吧。

那么，当我打印将 $x$ 和 $y$ 相乘的结果时会发生什么？我得到的是 $\frac{3}{16}$。

我应该能够改变我的表示方式，而所有这一切仍然能够正常工作。

所以，我们开始吧。不再使用列表将 $n$ 和 $d$ 耦合在一起，我们将使用一个函数：

```python
def rational(n, d):
    def select(name):
        if name == 'n':
            return n
        elif name == 'd':
            return d
    return select
```

我们将找到一个名为 `select` 的函数，它接受一个名称作为参数。如果该名称是 `'n'`，那么它将返回分子；否则，如果名称是 `'d'`，它将返回分母。

还有什么？我们不会担心那些其他情况。我们只需从 `rational` 函数中返回 `select` 函数。

现在，构造函数和选择器必须是彼此的补充，也就是说，当你用 `rational` 构造函数构造某物时，你可以使用 `numer` 函数选择其分子：

```python
def numer(x):
    return x('n')

def denom(x):
    return x('d')
```

所以如果 $x$ 是调用 `rational` 的结果，那么它是一个选择函数，我可以在 `'n'` 上调用它以获取分子。同样，我调用 $x$ 在 `'d'` 上以获取分母。

让我们再试一下我们的例子：
将 $x, y$ 设置为 $\frac{1}{2}$ 和 $\frac{3}{8}$。我接着打印了将 $x$ 和 $y$ 相乘的结果，得到了 $\frac{3}{16}$。

我们真的改变了什么吗？当然改变了，因为现在 $x$ 是一个函数。

所以，这是一种表示的变换，导致了另一种有效的有理数表示，与我们之前的代码一样有效，但使用了完全不同的机制来跟踪分子和分母。

请注意，我们仅使用了函数就实现了这一点。实际上，我们根本不需要内置的列表数据类型。

那么，当我们中有理数实现为函数时，到底发生了什么呢？

我们定义了构造函数和选择器。而正是这个函数，选择函数，代表了有理数。它是通过构造函数返回的，这是一个高阶函数。而选择器只是调用由调用有理数而得到的函数，以获得分子。

通过在另一个函数内定义一个函数，我们能够引用封闭作用域中的 $n$ 和 $d$。因此，我们返回的这个选择函数携带了我们稍后想要访问的分子和分母，作为其父级作用域的一部分。

让我们来看一个更简单的例子。我们把 $x$ 设为有理数 $(3, 8)$：
```python
x = rational(3, 8)
```
然后我们询问 $x$ 的分子，应该是 3：
```python
numer(x)
```

环境图看起来是这样的：
有理数的分子和分母被定义了。然后我们对 3 和 8 调用有理数，这创建了一个选择函数，其父帧是 f1 帧，其中 $n$ 和 $d$ 被绑定。返回并绑定到 $x$：$x = \text{rational}(3, 8)$。

一旦有了 $x$，我们可以询问它的分子，这创建了一个新的帧，其中 $x$ 被绑定到选择函数。`numer` 的主体说我们应该在 `'n'` 上调用 $x$，所以在第三帧 f3 中，`name` 绑定到 `'n'`，执行 `select` 的主体。`name` 是 `'n'`，所以它返回 $n$。

看这里，我们发现 `name` 为 `'n'`，但在当前帧未定义。如果我们在父级 f1 中查找，$n$ 绑定到 3，所以返回 3。

数据抽象，一种新的抽象方法。

开始吧。大多数值在某种意义上都是复合值，它们将不同的对象组合在一起，以便创建具有多个部分的对象。比如日期，它有年、月和日组合在一起成为一个整体；或者地理位置，会有纬度和经度。

抽象数据类型让我们将复合对象作为一个单元来操作。这是一种抽象的形式。它的作用是允许我们隔离使用数据的程序的两个部分。

我们想要区分数据的表示方式和数据的操作方式。通过这样做，我们将程序中的关注点分开，分为两个不同的领域，而且我们可以改变其中一个而不影响另一个。

因此，数据抽象是一种方法论，函数通过其强制在数据的表示和使用之间建立一个抽象屏障。

现在，所有的程序员在某个时候都会使用复合数据，但只有优秀的程序员才会拥抱数据抽象，为了使他们的程序更具模块化。而且，你很快就会成为一位优秀的程序员。

让我们看一个例子：有理数。然后我们会看到数据抽象是什么意思。

有理数可以表示为一个分子除以一个分母，其中分子和分母都是整数。而且由于我们可以精确表示整数，这给了我们分数的精确表示。

因此，一对整数让我们能够准确地告诉你我们有什么样的分数，比如 $\frac{1}{3}$。但是一旦我们真正把 1 除以 3，我们就会得到一个浮点数，这不是一个精确的表示，而是通过二进制展开的有限近似。

所以我们想要分开分子和分母，不是让一个除以另一个，而是要有一个复合数据类型。

所以我们假设可以将有理数分解如下：
我们有一个函数 `rational`，它接受 $n$ 和 $d$，一个分子和一个分母，它们都是整数，并返回一个复合数据类型，一个有理数 $x$。

我们还有另一个函数 `numer(x)`，它返回有理数 $x$ 的分子。同样，我们有一个 `denom(x)` 函数，它返回分母。

我们有一种将分子和分母组合在一起的方法，然后我们有一种选择这两个部分的方法。这被称为构造函数，它构建一个新值，这是一个抽象数据类型的实例。这些是选择器，它们是那些得到整数部分的函数。

接下来，我们可以写一些操作有理数的其他函数，比如把它们加在一起，或者把它们相乘。

让我们来看一下。为了让你记得，如果我们想要把 $\frac{2}{3}$ 和 $\frac{5}{3}$ 相乘，我们得到 $\frac{10}{9}$。

为什么呢？两个有理数相乘的通用公式是结果的分子是第一个和第二个的分子的乘积：
$$\frac{n_1}{d_1} \times \frac{n_2}{d_2} = \frac{n_1 \cdot n_2}{d_1 \cdot d_2}$$
分母是分母的乘积。

将两个有理数相加稍微复杂一些：
$$\frac{2}{3} + \frac{5}{7} = \frac{2 \cdot 7 + 5 \cdot 3}{3 \cdot 7} = \frac{29}{21}$$

怎么得到这个？一般说来，如果我们有两个有理数，那么我们将第一个的分子乘以第二个的分母，将这个与第二个的分子乘以第一个的分母相加，这就是我们的新分子；新的分母是我们要相加的第一个和第二个有理数的分母的乘积：
$$\frac{n_1}{d_1} + \frac{n_2}{d_2} = \frac{n_1 \cdot d_2 + n_2 \cdot d_1}{d_1 \cdot d_2}$$

所以现在我们有了如何乘和加有理数的公式。

怎么写能做到这一点的代码呢？我们会用构造函数和选择器来写。

这是一个函数，它将两个有理数 $x$ 和 $y$ 相乘：
```python
def mul_rational(x, y):
    return rational(numer(x) * numer(y), denom(x) * denom(y))
```
它返回一个新的有理数，其分子是输入的分子之积，分母是输入的分母之积，就像我们的公式说的那样。

我们看到，我们已经用构造函数创建了一个新的有理数，并且我们用选择器选择了我们在完成这个公式所需要的 $x$ 和 $y$ 的部分。

同样，我们可以写一个将两个有理数相加的函数：
```python
def add_rational(x, y):
    nx, dx = numer(x), denom(x)
    ny, dy = numer(y), denom(y)
    return rational(nx * dy + ny * dx, dx * dy)
```
我们为它们的分子和分母取了名字，因为我们在表达式中多次使用它们，然后我们返回一个遵循右侧公式的有理数。

再写一个函数让我们真正处理有理数，那就是等于有理数。如果 $x$ 和 $y$ 是相同的数字，它就返回 `True`：
```python
def eq_rational(x, y):
    return numer(x) * denom(y) == numer(y) * denom(x)
```
现在，我们不能简单地比较它们的部分，因为 $\frac{1}{2}$ 和 $\frac{2}{4}$ 都是相同的有理数。所以为了确定 $x$ 和 $y$ 是否相等，我们将第一个的分子乘以第二个的分母，然后检查是否等于第二个的分子乘以第一个的分母。

你在那里看到的是，我们已经用三个函数定义了所有操作有理数的方式。这些函数实现了有理数的抽象数据类型。这意味着我们所有对数字的操作都是用这些函数来写的。

我们甚至还没有定义这些函数，但由于我们知道这些是我们用来访问有理数的部分或创建新有理数的工具，我们可以用这些函数来写其他函数，然后稍后实现它们。

抽象屏障将程序的不同部分分开，使每个部分只需了解程序的其余部分的很少内容。这些分隔非常重要，因为它们允许您对程序的一部分进行更改，而其他部分可以利用这些更改，而无需以任何方式中断或创建不一致。

让我们谈谈我们在这节课上一直在开发的有理算术系统的抽象屏障。

程序中有一部分使用有理数进行计算。我实际上想知道 $\frac{1}{2} \times \frac{1}{3}$ 是多少。在这些情况下，我们实际上将有理数视为完整的数据值。它们只是表示某个数字，我们不在乎怎么做，我们只是想知道当你把这些东西相乘时会发生什么。

为了做到这一点，我们使用数据抽象的一部分，其中包括有理数的某些函数：有理数相加、有理数相乘、有理数相等，都是接受有理数并对它们进行操作的东西，可能返回新的有理数。使用这些函数并不意味着你需要了解有理数是如何表示的。

现在我们进入下一层，不仅看看这些算术运算符的使用，而是查看创建有理数或实现有理数操作的程序的部分。它们将有理数视为一个分子和一个分母配对。它们可能不需要知道这种配对的确切方式，它们需要知道有理数有一个分子和一个分母，这两个事物可以被选择；它们需要知道通过将分子和分母组合在一起来创建一个新的有理数。

所有这些都是使用称为有理数、分子和分母的函数来完成的。我在那里画了一条非常粗的线来表示一个抽象屏障。这个屏障表示使用有理数进行计算的任何东西应该只能使用这些函数，并且不应该使用不同层次的函数。

这样，我们编写的程序对我们使用的表示尽量少做假设，而是遵循程序员所设定的抽象。

如果我们从那个层次再往下走呢？程序的某些部分实现了有理数的选择器和构造器。有理数、数值和分母的这些实现，将有理数视为两个元素的列表。它们了解它们的整个数据值即由分子和分母组成，然后我们有了更详细的细节：分子和分母通过列表粘在一起。为此，我们使用列表字面量和元素选择。

再次，有一个抽象屏障。如果我们从事创建有理数或实现有理数操作的业务，我们不应该知道我们在底层使用列表，我们不应该越过这个抽象屏障直接使用列表字面量或元素选择。如果我们的程序是基于有理数的数字和分母的，那么稍后对这些函数的更改将在整个程序中传播。

例如，我们可以开始以最简形式表示每个分数。

每一大行都是一个抽象屏障。在编写大程序的一部分时，你应该知道它应该使用适合你尝试完成的任务的抽象级别。你保持在不越过这些边界的情况下，将来修改程序会更容易。

一对由两个值组成，以一种方式捆绑在一起，使你可以将它们视为一个单元、一个整体，尽管有两个部分。

表示一对事物的方法有很多种，但我们首先会使用一个名为列表的内置数据类型。

我可以写下这行代码：
```python
pair = [1, 2]
```
打开括号，1，2，关闭括号。

这里我们有一个被称为列表字面值的东西，它创建了一个包含 1 和 2 作为两个值的新列表。由于列表中有两个值，我们将其称为一对。当我显示这一对时，我看到它的内容就像字面值一样写：列表文字是方括号中以逗号分隔的表达式。

一旦我有了一个列表，它是列表文字的值，我可以通过所谓将该列表解包为不同值来访问列表中的元素：
```python

```
通过说 `x, y = pair`，我将 $x$ 绑定到第 0 个元素，$y$ 绑定到第 1 个元素。

之后，如果我查看 $x$ 绑定到什么，我会看到 1；$y$ 绑定到什么，我会看到 2。那是因为那是我创建的列表的内容。

现在我们有一种方法将值捆绑在一起，然后再拆分它们，这被称为解包列表。

通过元素选择运算符访问列表元素的另一种方式是使用方括号，再次使用方括号。

这些方括号与这个不同，尽管它们肯定是相关的。这只是在它之前没有任何东西的方括号，而这个在它之前有一些表达式。

当你在一个表达式后面有方括号时，那就涉及从值中选择一个元素，它在方括号的左边：
```python

```
`pair` 是一个列表值，它的 0 号元素是 1，它的第 1 个元素是 2。使用选择运算符进行元素选择是访问列表中的另一种方式。

还有一个做同样事情的函数，正如我们在 Python 中多次看到的那样，每个操作符都有一些功能，其中大多数在一个叫做 `operator` 的模块中。元素选择操作符称为 `getitem`，全是一个词。可以快速说，因为都是一个词：

`getitem(pair, 0)` 给我配对列表的第 0 个元素，那就是 1；`getitem(pair, 1)` 会给我值 2。这是一个元素选择函数或 `getitem` 函数。

现在我们对列表有了基本介绍，到目前为止，我们已经使用它们来创建配对。

那有什么用呢？有理数就是一对整数：分子和分母。

这里是有理数抽象数据类型的构造函数的定义：
```python
def rational(n, d):
    return [n, d]
```
这是一个接受分子和分母的函数。我们需要一种表示这一对东西的方式，我们将使用一个列表。我们通过返回包含 $n, d$ 的列表来构造表示 $\frac{n}{d}$ 的有理数。这构建了一个列表，我们将其用作有理数。

列表可以包含任何东西，它们不一定只包含整数，但我们正在使用它来表示分子和分母都应该是整数的有理数。

现在，假设 $x$ 是由有理构造器创建的，我们如何获取分子呢？
```python
def numer(x):
    return x[0]

def denom(x):
    return x[1]
```
我们只需访问第 0 个元素，而分母是索引为 1 的元素。为了实现我们想要的，也就是选择有理数的分母，我们将在这里从列表中选择一个项目。

让我向你展示数据抽象为何有用的第一个例子。回想一下，我们在有理数中实现了乘法。

这里有一个例子：$\frac{2}{3} \times \frac{3}{5}$。
你得到什么？把分子相乘得到 6，把分母相乘得到 15。答案不是 $\frac{6}{15}$，而是 $\frac{2}{5}$。

为什么呢？我们有 $\frac{6}{15}$，但它们不是相对质数。通过将分子和分母都乘以 $\frac{1}{3}$，我们可以将分数化简为最简形式。这给我们一个等价的分数 $\frac{2}{5}$，更简单一些。

我们这样做的原因是，为了保持整数小，这样它们更容易查看和理解。

那么 $\frac{2}{5} + \frac{1}{10}$ 呢？我们可以对前面用于将有理数相加的相同过程进行应用，然后我们得到 $\frac{1}{2}$。

那为什么是 $\frac{1}{2}$ 呢？通过交叉相乘和相加，我们得到：
$$\frac{2 \cdot 10 + 1 \cdot 5}{5 \cdot 10} = \frac{25}{50}$$
这是 20，这是 5，我们把它们加在一起得到 25；50 是 $5 \times 10$。然后我们可以通过将分子和分母都乘以 25 的倒数来将其化简为最简形式，最后得到 0.5。

我们要如何修改我们的实现来做到这一点？这是个想法：加法和乘法其实一开始就是正确的，错误的是我们对有理数的定义。有理数应该总是以最简形式或两个互质整数表示的东西。

我能做的一件事是导入一个计算最大公约数的函数。在之前的讲座中，我向你展示了如何编写一个执行此操作的函数，但它也恰好内置在 Python 中：
```python
from fractions import gcd
```

```python
def rational(n, d):
    g = gcd(n, d)
    return [n // g, d // g]
```

这可以通过计算分子和分母的最大公约数来实现。在这种情况之下——

是 3，另一种情况下是 25。

然后返回一个包含分子和分母的对，它们分别被最大公约数除以，以确保它们是互质的。

我们在这里使用整数除法，因为我们知道最大公约数均等地除以 $n$ 和 $d$。这是最大公约数的一个特性，它是一个除数，它均等地除尽这些数字。

所以我们计算了最大公约数。我们改变了构造函数。我们不必对 `add_rational`、`mul_rational`、`print` 或任何其他东西进行任何更改，因为我们一直在使用数据抽象，这意味着一切都是根据这个构造函数定义的。所以，改变这个构造函数也会改变所有其他函数的行为。而这是一件好事。
