## P26 Lecture 28 Scheme-cn

迄今为止，你已经学到了关于函数和数据的知识，这是编程的实质。实际上，你已经掌握了 Python 语言的基础知识。

所以现在是时候转向一门新的语言——Scheme。通过学习 Scheme，我们会发现许多关于一种编程语言的理念很容易迁移到另一种语言。而 Scheme 是一种较早的语言，在 Python 的创造过程中产生了很大的影响。因此，我们要了解它的历史、它的美丽，也要看看哪些理念可以自然地从一种语言传递到另一种语言。然后我们会发现这其中有很多。

Scheme 是一种叫做 Lisp 的语言的方言。而 Lisp 是今天仍在使用中最古老的两种编程语言之一。它无疑是增长最快的最古老的编程语言，因为越来越多的人对使用 Lisp 创新应用感到兴奋。

人们对 Lisp 有什么评价？Alan Kay，面向对象编程的发明者，说这是有史以来设计的最伟大的单一编程语言。我最喜欢的科幻小说作者说，它是唯一一种美丽的计算机语言。Brian Harvey 曾经告诉我，这是上帝的编程语言。即使是 xkcd 似乎也喜欢它：Lisp 已经有半个多世纪的历史，但它依然散发着完美的光辉。我想知道这个循环是否会永远继续，每一代新的程序员都重新发现 Lisp 的艺术。“这些是你父亲的括号。更文明时代的优雅武器。”希望这让你对学习一门新的编程语言感到兴奋。

Lisp 的美在于它的简单性。整个语言可以在一天内学会。然而，它可以用来构建像我们在本课程中见过的那么复杂的程序，或者比那更复杂的程序。

以下是基础知识。Scheme 程序由表达式组成。可以是原始的，比如 `2`，或 `3.3`，或 `true`，或 `+` 是一个原始表达式，或 `quotient`（执行除法）等。

有各种组合。所以，一个组合看起来像是一个开括号，然后是一些其他表达式，然后是一个闭括号。通过这种方式，我们可以表示 10 和 2 的商，即 10 除以 2 等于 5。或者我们可以通过组合来表示不是真的就是假，等等。

数字是自我评估的，但符号绑定到值。调用表达式看起来像组合，它们以运算符开头，后跟零个或多个操作数，全部都在括号中。这与 Python 的语法有点不同。通常，我们会将运算符放在外面，但这里我们将其放在里面。

那么让我们看一些例子。如果在 Scheme 提示符处我输入开括号、`quotient`、`10`、`2`、闭括号，那么我得到 5。

`quotient` 是内置的整数除法过程的名称。在 Python 中我们称之为函数，在 Scheme 中它们被称为过程，但它们本质上是一样的。

你可以嵌套调用表达式。我可以求商是多少：将 8 和 7 相加的结果是 15，除以 5 得 3。

如果我愿意，我可以以任何我认为合适的方式将这些调用表达式分散在多行中。这是使用缩进使表达更清晰的典型方式。这表示我要加两个东西：这个子表达式的结果和这个子表达式的结果。这就是它们在相同级别缩进的原因。Scheme 解释器根本不关心缩进。这些存在是为了使程序对人来说尽可能可读。

组合可以跨越多行。空格不重要，换行也不重要。重要的是你要闭合你打开的括号。阅读这个的方法是说我们正在将两个东西相加。第一个是两个事物的乘积：第一个是 3，然后我们需要将 2 乘以 4 得到 8，然后将 3 和 5 相加得到 8，这再次是 8；将它们相加得到 16，再乘以 3 得到 48。下面呢？我从 10 减去 7 得到 3，然后加上 6，所以我得到了 9。9 加 48 等于 57。所以，整个表达式的计算结果是 57。

让我们做一些更多的演示。这里是一个 Scheme 提示。我可以计算 2，我可以计算 1、2、3 和 4 的和是 10。如果我把什么都加在一起会发生什么？你觉得呢？我可以把 1、2、3 和 4 相乘得到 24，或者我可以什么都不相乘，只乘以 1。

我可以将 2、2、2、2、3、3、3 相乘得到 864，而且我可以嵌套这个过程。如果我想要的话，比方说减去 1：我会用括号把整个式子括起来，放一个新的运算符在前面。而且我不仅可以减法，还可以除法、加法或者再次乘法，任何我想做的操作。结果将按照正常的调用表达式过程进行计算。首先评估运算符和操作数，然后将过程应用于参数。这和评估 Python 一样，但这次我们把括号放在稍微不同的地方。

除了这些内置的算术过程（比如加法），还有各种其他内置的过程。我可以询问某物是否是一个数字。3 是一个数字，加号不是一个数字。我可以询问某个数字是否为 0。2 不是 0，这就是我们得到 `false` 的原因，但 0 是 0，这就是我们得到 `true` 的原因。如果我真的从 2 减去 2，最后得到的是 0，这是真的。我们还可以评估某物是否为整数。2.2 不是，但 2 是。

现在，这些问号只是名字的一部分。名字是整数问号，而问号之所以存在是为了帮助你弄清楚这个过程的作用。所以就像在任何编程语言中一样，我们想使用能帮助我们记住事物将要做什么的名字。而这个整数问号名称是一个很好的提醒，它基于其参数的内容返回 `false` 或 `true`。

那么我是如何执行所有这些 Scheme 代码的呢？我下载了什么吗？当然可以下载一个解释器，或找到嵌入到网页中的在线解释器。我们会为您提供两者的指引。但在这种情况下，我没有使用这两者之一。相反，我一直在使用这门课程的第四个项目中的实现。所以，在项目 4 中，您将构建一个实现 Scheme 解释器的 Python 程序。运行一次，你就能评估 Scheme。而且你会通过实际编写执行所需的不同过程的代码来做到这一点，以便执行 Scheme 过程。这就是所谓的评估器。所以学习这门新语言的一个目的是学习一门语言，以便我们能够理解如何为其构建解释器。

我们还没有学习完整个 Scheme 语言。目前我们只了解调用表达式，但还有其他类型的表达式。所以它们被称为特殊形式。在 Scheme 中，特殊形式是任何不是调用表达式的组合。

例如，有一个 `if` 表达式，它有特定的语法，所以它看起来又像一个组合，除了它有这个特殊的关键字 `if` 作为第一个子表达式，然后有一个谓词、一个结果和一个替代，它们都是表达式。为了评估这个，我们首先评估谓词表达式，然后基于它是真还是假，决定是评估结果还是替代项。所以，结果就像是 Python 中 `if` 语句的套件，而替代项则是条件语句中 `else` 子句的套件。

`and` 和 `or` 也是特殊形式。因为虽然它们有许多不同的表达式，我们将在逻辑上将它们组合起来，但它们可能并不都会被评估。因为你可以在不评估其中一些的情况下，确定一堆事物的 `and` 是真还是假。在进行项目时，你可以查看这方面的详细信息，该项目将涉及构建一个 Scheme 解释器。

一个重要的特殊形式是如何将新值绑定到符号。这是通过 `define` 完成的。我们定义一些符号作为某个表达式的值。为了做到这一点，我们评估表达式，然后将其绑定到符号。所以，如果我定义 $\pi$ 为 3.14，那么我可以在将来的表达式中使用 $\pi$ 这个符号。所以符号 $\pi$ 在全局框架中绑定到 3.14。是的，Scheme 适用于我们在 Python 中使用的相同的环境模型。

你还可以使用 `define` 表达式定义一个具有稍微不同语法的新过程。这样你就知道在 `define` 之后有括号时，你正在定义一个过程。这个组合并不是一个调用表达式。相反，它给出了新过程的名称，然后是它的形式参数。然后之后我们需要主体。那么这看起来怎么样呢？一个例子是，我们可以定义绝对值过程，它接受我们称之为 $x$ 的某个参数。每次调用 `abs` 时，它会评估这个主体表达式，即说如果 $x < 0$，那么我们返回 $-x$；否则，我们返回 $x$。

所以这是这个 `if` 表达式的谓词、结果和备选项。如果我取 3 的绝对值，我输入 -3，我会得到 3。这样就创建了一个过程，并在当前环境的第一个框架中将符号 `abs` 绑定到该过程。因为我们在全局环境中，所以它在那里被绑定。

让我们自己定义一些过程。我们可以定义平方某个数的意义是将其乘以它自己：

```scheme
(define (square x) (* x x))
```

然后我们可以平方 16 得到 256。

我们可以定义求 $x$ 和 $y$ 的平均值的意义。记住，换行是可以的，完全由我们决定如何缩进或排列事物。假设我们要将 $x$ 和 $y$ 相加，然后将结果除以 2：

```scheme
(define (average x y)
  (/ (+ x y) 2))
```

在 Scheme 中要小心关闭括号，因为我们希望形成良好的组合。这个 `define` 结束了，然后我可以求平均值。我们做 3 和 7，我们得到 5。

现在在 Scheme 中，我们已经知道如何评估调用表达式。调用表达式可以包含其他调用表达式。在 Scheme 中定义递归函数是可以的。其实，它们无处不在。

让我们定义如何计算 $x$ 的平方根。我们怎么做呢？我们有一堆更新。所以让我们定义一个更新函数，它接受一个猜测，然后如果需要，为我们提供一个更好的猜测。这个更好的猜测是什么呢？如果猜测的平方已经等于我们要计算平方根的那个数字，那么我们实际上根本不需要更好的猜测。在这一点上我们最好停止递归。所以这是一个基本情况。我们将简单地将该猜测作为更新的值返回，因为我们完成了。否则，我们需要更好的猜测。那么我们如何得到更好的猜测呢？我们将使用古老的巴比伦方法进行更新，这比以前的更有用，通过对当前猜测和将 $x$ 除以当前猜测得到的结果进行平均。

所以我们会关闭除法，关闭平均值，关闭更新，关闭条件判断，关闭定义。为了实际上取平方根，我们会从猜测值为 1 开始并进行更新，然后更新、一直更新，直到猜测的平方实际上等于 $x$。关闭定义。现在我们可以取 256 的平方根得到 16。

所以我们已经使用了语言的许多特性。我们在这里定义了一个平方根，在这里我们定义了更新。像 Python 这样的方案是词法作用域的。因此，在这个内部函数的主体内，我们可以引用外部函数的形参 $x$ 的名称。

`lambda` 表达式在 Scheme 中创建新的过程。因此，`lambda` 表达式评估为匿名过程。它们具有以下特殊形式的语法：我说 `lambda`，然后我在括号中写下形式参数，然后我给出过程的主体。`lambda` 在 Scheme 中非常重要。

所以这里有两个定义加 4 过程的不同等效表达式，并将其绑定到名称 `plus4`。我可以直接使用我们之前看到唯一定义过程的语法，或者我可以直接定义 `plus4` 绑定到接受 $x$ 并返回加 $x$ 和 4 的过程。

这些可以随意组合。Scheme 是完全灵活的。所以在调用表达式中，我可以有一个运算符本身就是一个组合。例如，我可以编写一个过程，将 $x$、$y$ 和 $z$ 的平方相加应用于 1、2 和 3，得到 $1 + 2 + 9 = 12$。

现在我要谈谈另外三种特殊形式。这些将在实验和讨论中涵盖，并将在下一个项目的作业中出现。所以你最终会接触到它们，但我现在会提前给你一个预览，只是让你知道接下来会发生什么。首先我们将讨论 `cond`，然后开始。

`cond` 特殊形式，其中 `cond` 缩写为 condition，类似于在 Python 中有 `elif` 子句，或一个大的 `if`、`elif`、`elif`、`elif`、`else` 语句。因此在 Python 中你可以有一个语句带有多个不同的子句，只要你以一个 `if` 开头，然后最后可以有一个可选的 `else`。而且你可以通过在 Scheme 中仅使用 `if`，并使最后的结果表达式中有另一个 `if`，其结果表达式中的 `if` 有另一个 `if`，来实现相同的结果。所以你实际上不需要任何新的特殊形式。

如果你有很多 `elif`，那么这个嵌套的想法有点烦人，这就是为什么有 `cond` 的原因。

这是一个在 Scheme 中做同样事情的例子。`cond` 的表达式的其余部分是一对成对的条件，然后是如果该条件为真要执行的操作。

所以这表示：如果 $x > 10$，那么打印 `big`；否则，如果 $x > 5$，打印 `medium`；否则，输出 `small`。

就像在 Python 中一样，`else` 情况是可选的，但只能有一个，并且必须位于最后。这两者都具有相同的特性，即无论 $x$ 的值如何，只会打印一件事。如果 $x$ 是 12，则它既大于 10 又大于 5，但只会打印 `big`，因为 $x > 10$ 是在触发 $x > 5$ 的条件之前的条件。

同样的道理也适用于这里。

现在，一个组合的表达式确实有一个值。因此，如果我不是打印，而是说我想要一个表达式，其值取决于 $x$ 的值，可以是 `big`、`medium` 或 `small`，那么我会这样写。

我可以对该值执行一些操作，例如，我可以将其打印出来。现在，这两个表达式是等效的，它们将打印大、中或小之一。但我认为这个更短，因为它只有一个打印，而不是三个。

所以这就是 `cond`。你仍然可以使用 `if`。实际上，通常的做法是：如果你只是在两个选项之间选择，那么你使用 `if`；如果超过两个，那么你使用 `cond`。

`begin` 特殊形式将多个表达式合并为一个表达式。`begin` 特殊形式的值就是其最后一个子表达式的值。而使用 `begin` 的原因是，你可以在计算所需结果之前执行一些操作，比如一段时间内打印，或者将某些符号定义为特定值。

在这里有一个 Python 的例子，在 `if` 子句的语句块中我打印了两次，`else` 子句同理。

在 Scheme 中你该怎么做呢？你需要用到 `begin`。这里有一些条件，第一个条件是如果 $x > 10$，我想要既打印 `big` 又打印 `guy`。

但在 Scheme 中这里只有一个表达式的空间。因此，`begin` 表达式允许你放置任意多个子表达式，它们都会被评估。

顺便说一下，由于这里只有两种选择，使用 `if` 会更自然一些。你可以随意缩进或换行。所以这是一个等效的表达式，它只是说：如果 $x > 10$，那么打印 `big` 和打印 `guy`；否则，打印 `small` 和打印 `fry`。

最后，我们将讨论 `let`。

`let` 有点像 `define`，但不同之处在于它只是临时地将符号绑定到一个表达式的值，然后这些绑定就消失了。

在 Python 中没有真正的等价物，但我们可以通过展示一个 Python 示例及其 Scheme 等价物，使用 `let` 表达式来讨论它们之间的差异。

假设你想计算一个直角三角形的斜边长度，它的两条直角边分别是 3 和 $2 + 2 = 4$。所以这将是一个 3, 4, 5 的三角形，这个表达式 $c$ 应该给我们 5。

也许在这个程序中，我真正关心的只是确保 $c$ 被绑定到 5。但是如果我写这个 Python 代码，$a$ 和 $b$ 仍然在这里被绑定。这可能是一件好事，如果你打算再次使用它们；但也可能有点糟糕，如果它们在之前已经被使用，现在你已经覆盖了它，或者你只想使用尽可能少的名称。

这里是如何在 Scheme 中实现相同的事情。但是区别在于，在我们定义了 $c$ 之后，$a$ 和 $b$ 在这里并没有绑定。它们只是临时绑定以计算 $c$ 的值，然后这些绑定就消失了。

这是它的工作原理：我们将 $c$ 定义为整个 `let` 表达式的结果，其中 `let` 表达式的值是末尾的内容，在这种情况是 $\sqrt{a^2 + b^2}$。但在那之前，你有机会进行临时绑定。

`let` 表达式真的只有两个部分：绑定——这是它们开始的地方，这是它们结束的地方；然后是值表达式，就在这里。而绑定本身是一对：第一件事必须是一个符号，第二件事可以是任何表达式，将被评估以便将该符号绑定到一个值。

所以这就像在这里有一对小的定义，只是 $a$ 和 $b$ 的绑定在你计算出 $c$ 的值后立即消失。

在任何有许多大小和复杂性的 Scheme 代码中，`let` 经常被使用。通常在 Scheme 中，`define` 被用于那些真正永久的事物，就像你想定义一个新的过程，这样你就可以多次调用它，或者你想定义一些常量，比如 $\pi$。否则，大多数 Scheme 代码并不进行大量的定义；相反，如果你需要跟踪一些临时信息，你可以使用 `let` 来做到这一点。

而这主要是一种风格约定，但这是有一些很好的理由的，那就是你不必担心定义任何你以后不需要的东西。你可以简单地说：我想让 $c$ 持续存在，但 $a$ 和 $b$ 只是临时存在为了计算 $c$，现在我们不再需要它们了。

Let's look at an example of a Scheme program that draws Sierpinski's triangle using lots of the features of Scheme that we've seen so far.

When you start Scheme, you can immediately start adding numbers together. But there's also some built-in drawing facilities in the version of Scheme that we distribute with the homework assignments for this course.

So, for example, you can say:
```scheme
(forward 100)
```
And this `forward` procedure tells a little turtle to walk forward 100 units. Let's rearrange a bit so that we can move the turtle some more.

Other commands include turning right by 90 degrees:
```scheme
(right 90)
```
Going forward again, or in fact, you could also go backward. And the turtle can not only turn right, but also turn left.

Now, all of this interacts with the Scheme language that we've already defined. So I could build a procedure to draw a line that moves forward 50:
```scheme
(define (line) (forward 50))
```
And then I can draw a line, and another line, and take a right turn. I could also define a procedure that does something twice, by doing it once and doing it again:
```scheme
(define (twice fn) (fn) (fn))
```
So if I twice draw a line, then it'll draw two lines.

And all of this could also be stored in a file. Typically, what you store in the file are the procedure definitions. So there's what a line is, there's what `twice` is.

Perhaps not just twice, we'd want to repeat something many times. Repeat $k$ times some procedure means calling that procedure—we're going to do it at least once. And if it's the case that $k > 1$, then we have to keep going. So we'll repeat $k - 1$ times using that same procedure:
```scheme
(define (repeat k fn)
  (fn)
  (if (> k 1)
      (repeat (- k 1) fn)))
```

I could load all those by naming the file:
```scheme
(load "turtle.scm")
```
Then I'll take a right turn to point ourselves down, and we can repeat three times drawing a line, or twice more we could draw a line.

Or, we could repeat five times some custom procedure that we define using a lambda expression. `repeat` takes a procedure of zero arguments, so I say `lambda` takes zero arguments, and each time it's called, I'd like to go forward 50 and then take a right turn of 144 degrees:
```scheme
(repeat 5 (lambda () (forward 50) (right 144)))
```

Cool! Let's quit and start over so we get a fresh canvas.

Now that I can repeat, I can draw, for example, a triangle. But I don't want a triangle that's just a boring old triangle that always has a line as its edge. I want an arbitrary edge, so I'll use a function to define what it means to draw the edge of the triangle.

But the triangle always involves repeating three times a procedure that first draws the edge, and then takes a turn of 120 degrees:
```scheme
(define (tri fn)
  (repeat 3 (lambda () (fn) (lt 120))))
```
So if I load this file and draw a triangle with lines as the edge, I'll get a regular triangle.

But I'd like to draw Sierpinski's triangle. Let me tell you about Sierpinski's triangle.

Sierpinski's triangle has some recursive depth $d$, and also some side length $k$. It's a triangle, but drawing the edge of this triangle involves making a choice. If $d$ is 1, then we just draw a line of length $k$. Otherwise, we draw a leg of Sierpinski's triangle with $d > 1$, which is going to be mutually recursive with this procedure `sierpinski` that I've just defined:
```scheme
(define (sier d k)
  (tri (lambda ()
         (if (= d 1)
             (fd k)
             (leg d k)))))
```

The `leg` also takes in $d$ and $k$, but it does the drawing work. And here's what it looks like: you draw Sierpinski's triangle, but half the size and with a depth of one less:
```scheme
(sier (- d 1) (/ k 2))
```
Then, without drawing a line, you move to the end of where this leg should go. Which means you have to pick your pen up, go forward $k$, and then put your pen back down so you can draw some more of Sierpinski's triangle:
```scheme
(penup)
(fd (/ k 2))
```
