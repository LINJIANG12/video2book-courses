好的，对于第一个问题：列表 $s$ 中具有最小绝对值的元素的索引是什么？我们从这个例子开始尝试解决。

这里是 $s$。最小绝对值并不是 $s$ 的最小值，但实际上，使用 `key=abs` 的情况下，它也不是 $s$ 的最小值。这会给我这个中具有最小绝对值的元素，它不会给我最小的绝对值。所以如果我的目标是真的得到最小的绝对值，我需要先对每个元素调用 `abs`，然后再取最小值。我可以通在 $s$ 上映射 `abs` 来实现：

```python
min(map(abs, s))
```

所以现在我有了最小的绝对值。我能做什么呢？我可以找到所有的索引，其中该索引处的元素的绝对值等于这个最小绝对值，等于 2。

至于查找具有该绝对值的所有元素不同，这可以通过列表推导来实现。如果我想知道所有元素 $x$：

```python
[x for x in s if abs(x) == min_abs]
```

那将给我 2 和 -2。但这并不是我的目标，我的目标是找到索引。为此，我需要遍历不是 $s$ 的 `for x in s`，而是 `len(s)` 的范围，这为 $s$ 的所有索引值提供。然后我们相应地调整这个表达式。实际上，我们只想要索引值。我们还想要相应地调整这个表达式：我们想知道 $s[i]$ 的绝对值是否等于最小绝对值。

```python
[i for i in range(len(s)) if abs(s[i]) == min(map(abs, s))]
```

这将给我数字 2 和 4。

所以，这个问题有一个两行的解决方案。每当我使用列表推导时，我也可以使用 `map` 和 `filter` 内置函数。所以我可以通过首先定义一个过滤函数来重写这个，该函数接受某个索引并告诉我它是否是我想保留的索引之一：

```python
f = lambda i: abs(s[i]) == min(map(abs, s))
```

然后，如果我使用 $f$ 来过滤相同范围的索引：

```python
filter(f, range(len(s)))
```

我几乎得到我想要的，但这是一个过滤对象。如果我真的想要一个列表，那么我会调用列表，并且得到同样正确的结果：

```python
list(filter(f, range(len(s))))
```

所以，我本可以用这个表达式替换这个表达式，得到同样的结果。

好的，让我们继续下一个问题：列表 $s$ 中两个相邻元素的最大和是多少？

这里我们使用的是之前的 $s$。我们应该得到 6。有两种合理的方法可以做到这一点。首先要考虑的是索引。范围 `len(s)` 将给我所有的索引，但 `range(len(s) - 1)` 将给我几乎所有的索引。这里是一个范围。如果我遍历几乎所有的索引，只留下最后一个，然后计算 $s[i] + s[i+1]$，那么我对每对相邻元素都求和了两次。而且我略过最后一个是因为没有加 1 对于最后一个元素。这就是为什么我使用这个缩短的范围。

好的，这只是给我相邻元素和的全部内容。如果我想知道最大的那个，那么我应该只是在那个上调用 `max`。所以，聚合函数还有另一种用法来完成这项工作。

```python
max([s[i] + s[i+1] for i in range(len(s) - 1)])
```

好的，下一个问题：每个元素是否等于 $s$ 中的某个其他元素？

这里是一个 $s$ 的例子。解决这个问题的一种方法是：专注于某个特定的索引。假设索引 1 的 $s[i]$ 是 3。就是这样。通过构建一个除了这个之外的所有内容的列表，我们可以弄清楚 3 是否出现在其他地方。$s[:i]$ 给我从头到 4 的所有东西，但不包括 3；$s[i+1:]$ 给我 3 之后的所有东西。所以如果我把它们加在一起，我会得到除了那个 3 之外列表中的所有东西。我们并没有完全摆脱所有的 3，我们只是摆脱了索引 $i$ 处的元素。我可以询问 $s[i]$ 是否在这个新列表中，这个新列表中没有元素 $i$。而它是，这意味着 3 在其他地方也出现过。

现在我们有一个表达式来检查索引 $i$ 处的元素是否在列表中的其他位置出现，我们可以对所有 $i$ 进行检查。以下都是真的吗？这个表达式 $s[i]$ 在 $s$ 的其余部分中（不包括 $i$），对于范围在 `len(s)` 内的每个 $i$ 都成立：

```python
all([s[i] in s[:i] + s[i+1:] for i in range(len(s))])
```

让我把所有东西写在一行上，正确地不忘了最后的括号，这样你就能明白发生了什么。这是解决这个问题的一种方式。

但也有其他方法来思考同样的事情。比方说，我们不想关注索引，我们只想看看值本身。一个有用的表达方式是：对于 $s$ 中的每个 $y$，如果 $y == 3$，告诉我由多少个 3。我可以通过取这个长度来得到有多少个 3；或者作为另一种选择，我可以收集 1 而不是 3，然后得到总和，以便找出有多少个 3。

但我们不关心有多少个 3，我们关心的是任何特定值有多少个。所以我们可以将相同的表达式写成列表推导的一部分。我觉得这个可能会变得很长。在这里，我们希望每个 $x$ 都不是 3，而是在 $s$ 中的每个 $x$。这些 2 代表什么？这意味着有两个 4，有两个 3，有两个 2，而这有点多余。有两个 3，有两个 2，有两个 4。

如果我们想确保每个都大于 2，一种方法是说它们都大于 1：

```python
all([len([y for y in s if y == x]) > 1 for x in s])
```

另一种方法是计算它们全部，找到其中的最小值，并确保该最小值大于 1：

```python
min([len([y for y in s if y == x]) for x in s]) > 1
```

现在你知道它们都大于 1。只有两种表达相同的方式。

我们在音频这里做的就是数 $x$ 在 $s$ 中出现的次数。实际上，原来已经有这个功能了。我只是说 `s.count(3)`，它就会告诉我有多少个 3。所以，我可以简化一下。我想知道对于 $s$ 中的每个 $x$，$s.\text{count}(x)$ 是多少。它会告诉我最小的计数是 2：

```python
min([s.count(x) for x in s]) > 1
```

由于这些都大于 1，我们知道每个元素都等于 $s$ 中的另一个元素。也许这是解决这个问题最简单的方式。

这是一个经典的练习：创建一个包含有序链接 $s$ 和 $t$ 所有元素的链接。所以如果我有序的 $s$ 和有序的 $t$，我如何创建有序的 $s$ 和 $t$ 呢？这将基于这两个构建一个新的链表。

所以，这是我们的链表类：接受一个第一个和一个其余的参数。默认情况下，其余的参数为空。

那么我们如何检查某物是否有序呢？1, 3, 4 是有序的，1, 4, 3 不是。好的，在这里我们将使用递归。检查前两个元素是否有序，并确保之后的所有元素也都是有序的。

如果 $s$ 是 `Link.empty` 或者 `s.rest` 是 `Link.empty`，那么这个东西肯定是有序的，因为他只有 0 或 1 个元素，没有足够的元素来无序。如果 `s.first > s.rest.first` 的情况下，即索引为 0 的元素大于索引为 1 的元素，那它们就不是有序的：

```python
def ordered(s):
    if s is Link.empty or s.rest is Link.empty:
        return True
    elif s.first > s.rest.first:
        return False
    else:
        return ordered(s.rest)
```

如果你不知道它是有序的，也不知道它是无序的，但你知道前两个元素是有序的，那么你必须检查其余所有元素：返回 `ordered(s.rest)`。

如果允许使用键函数来告诉你真正想要考虑排序的值，那么情况就变得更有趣了。我们是按照那些值的顺序进行排序吗？还是我们在检查对这些值调用 `abs` 的结果的顺序？所以 $\text{abs}(1)$ 是 1，$\text{abs}(-3)$ 是 3，$\text{abs}(4)$ 是 4。1, 3, 4 是有序的。所以，使用关键函数 `abs` 时，这是正确的。

我们使用它的方式与 `sorted`、`min` 或 `max` 中使用 `key` 的方式很相似。我们需要添加第二个参数。默认情况下，它只有恒等函数（identity function），但是如果你传入 `abs`，那么那就是我们应该检查的条件：`key(s.first) > key(s.rest.first)` 是否成立。

好吧，这将处理绝对值的情况，但我们希望这足够通用，可以处理任何可能的键函数。所以我们只需要用 `key` 替换 `abs`。这意味着默认情况下，它将采用恒等函数，但如果你想的话，它可以采用 `abs` 函数并应用它：

```python
def ordered(s, key=lambda x: x):
    if s is Link.empty or s.rest is Link.empty:
        return True
    elif key(s.first) > key(s.rest.first):
        return False
    else:
        return ordered(s.rest, key)
```

合并，返回一个排序过的列表，其中包含排序过的 $s$ 和 $t$ 的元素。

```python
def merge(s, t):
    """Return a sorted list with the elements of sorted s & t.

    >>> a = Link(1, Link(5))
    >>> b = Link(1, Link(4))
    >>> merge(a, b)
    Link(1, Link(1, Link(4, Link(5))))
    """
    if s is Link.empty:
        return t
    elif t is Link.empty:
        return s
    elif s.first <= t.first:
        return Link(s.first, merge(s.rest, t))
    else:
        return Link(t.first, merge(s, t.rest))
```

所以，当我合并 1、5 和 1、4 时，我得到了 1、1、4、5。

如果 $s$ 是 `Link.empty`，那么合并的结果应该就是 $t$ 中的所有内容。

如果 $t$ 是 `Link.empty`，但 $s$ 不是，那么我认为合并的结果应该是 $s$ 中的所有内容。

现在我们知道 $s$ 和 $t$ 都有元素，所以我们可以比较 `s.first` 和 `t.first`。如果它们相等，放在哪个顺序都无关紧要。所以我们只需放置小于或等于，但如果我们放置小于也是正确的。

在这里，我们将创建一个以最小元素 `s.first` 开始的新链表，其后是 $s$ 中的其他所有元素和 $t$ 中的所有元素的合并版本。这个结果包含了 $s$ 中的所有内容，这是第一个，还有其他的，而且它包含了所有的 $t$。

否则，如果 `t.first` 是最小的元素，那么它应该是结果的第一个元素。我们仍然需要 $s$ 中的所有元素，同时也需要 $t$ 的其余部分。

那就是原地合并了。

```python
def merge_in_place(s, t):
    """Return a sorted list with the elements of sorted s & t.

    >>> a = Link(1, Link(5))
    >>> b = Link(1, Link(4))
    >>> merge_in_place(a, b)
    Link(1, Link(1, Link(4, Link(5))))
    >>> a
    Link(1, Link(1, Link(4, Link(5))))
    >>> b.rest.first
    5
    """
    if s is Link.empty:
        return t
    elif t is Link.empty:
        return s
    elif s.first <= t.first:
        s.rest = merge_in_place(s.rest, t)
        return s
    else:
        t.rest = merge_in_place(s, t.rest)
        return t
```

这里的想法是我们从 a 和 b 开始，我们调用了原地合并，得到了 a 和 b 中所有元素的排序顺序，但我们从未调用 `Link`。

事实上，实现几乎与这个几乎相同。基本情况是相同的，但不是调用 `Link`，而是需要改变 $s$。所以 `s.first` 不变，但 `s.rest` 是……

那会是什么样子呢？不是返回一个新的 `Link`，而是我们将返回 $s$，但我们会改变 `s.rest` 以包含 `s.rest` 和 $t$ 中的所有内容。

同样，如果 $t$ 有最小的元素，那么我们将返回它。但我们会改变它的 `rest`，以确保它包含 $s$ 和 `t.rest` 中的所有内容。
