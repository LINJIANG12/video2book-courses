数据库以结构化的表格形式存储数据。而数据库管理系统是一些最重要、最广泛使用和最有趣的大型软件应用之一。组织在其数据库管理系统上花费了大量资金，也有一些出色的开源项目。

数据库组织其包含的数据的方式是通过表格，这些表格是记录的集合。这些记录是表中的行，它们为表中的每一列都有一个值。

那么这个表中的记录会是什么呢？有一个是伯克利的，一个是剑桥的，一个是明尼阿波利斯的。这些是行或记录。列描述有关这些地方的信息。

所以，这是一个表，有列和行。一列有一个名称，这不是顶部的记录，这只是列的名称。列的名称告诉你该列中包含哪个记录属性。足够简单。通常每列都与某种值关联。这些都是字符串。每行都有每列的值。

结构化查询语言可能是最广泛使用的编程语言之一。它是一种编程语言，用于从现有表中生成新表，然后操作其内容，添加和删除行的。

SQL 是一种声明式编程语言。在 SQL 中，以及像 Prolog 这样的其他声明性语言中，程序是对期望结果的描述，而解释器则负责找出如何生成这个结果。相比之下，命令式语言的程序是对计算过程的描述，而解释器执行和评估该过程的规则。

这门课程很大程度上是关于预测当你写程序时解释器会做什么。但在声明性语言中，这实际上更加棘手。特别是在 SQL 中，可能有多种方法来执行计算，以计算由 SQL 查询描述的结果。

数据库管理系统通常会尝试选择最快的方法，但这也取决于数据。因此，这改变了程序员与程序评估之间的关系，因为事情可能变得不太可预测。写程序的过程通常较为简单，因为无需详细描述执行和评估的步骤。这由数据库管理系统决定。
