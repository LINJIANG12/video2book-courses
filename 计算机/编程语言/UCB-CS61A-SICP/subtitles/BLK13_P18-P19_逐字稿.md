## P18 Lecture 18 Objects-cn

面向对象编程是当今在开发大型软件时组织程序的主导范式。它对编程语言的设计产生了巨大影响，包括 Python 和许多其他语言。它构建在我们已经讨论过的数据抽象和变异的思想基础上。

这就是故事的背景。我们需要将非常复杂的大型程序组织成小的模块化组件，这样可以分别编写、测试和思考，因为人类一次只能处理那么多的复杂性。

我们通过数据抽象来实现这一点，但面向对象编程将这个想法推进了一步，通过捆绑多个信息片段，就像数据抽象一样，和相关行为。

因此，一个对象代表着世界上的某个东西，比如一个日期，不仅存储表示该日期所需的所有信息，还可以执行类似日期的操作，比如确定该日期是星期几。

面向对象编程的理念是，你考虑你的程序以及它执行的所有计算，不是作为一个长长的信息列表，然后是在该列表上操作的函数，而是一堆不同的对象彼此交互。

每个对象都会跟踪自己的信息。所以，每个对象都有自己的本地状态，随着时间的推移可能会发生变化。因此，尽管这并非必须，但在面向对象编程中通常涉及到变异。

但当变异发生时，它不会发生在某个全局列表中，该列表跟踪程序中的所有信息。相反，正在更改的信息属于特定的对象。

每个对象都应该知道如何管理自己的本地状态，这意味着它会跟踪允许进行的更改。你与对象交互的方式是使用所谓的方法，这是一种特定于该类型对象的函数。

多个对象可能都是属于共同类的实例，这是一种对象类型。所以，你可以有许多不同的列表，它们都表现相同。不同的类可能相互关联。Python 和许多其他编程语言内置了专门的语法和词汇来支持这个隐喻。

类定义了特定类型对象的行为。对象是类的实例，这意味着每个对象都有一个类型，即它的类。创建对象时，它将永远具有该类。

然后有一个方法的概念。方法是使用点表达式在对象上调用的函数，例如，如果我有一个列表 `s`，我可以写 `s.append(5)`。`append` 是方法，它在列表 `s` 上调用，参数是 5，这将 5 放入列表 `s` 中。

方法与函数的区别在于，函数通常在全局框架中定义，可以在任何值上调用，而方法特定于特定对象。因此，我不能在任何东西上调用 `append`，但我可以在 `s` 上调用它，因为 `s` 知道如何进行附加。

我们来看一个内置类：`list` 类。实际上，我们一直在像调用函数一样调用 `list`，但它是一个类。在可迭代对象上调用 `list` 会创建一个新的 `list` 对象。在 Python 中，这通常是真实的，如果你有一个类，并且像调用函数一样调用它，那么你正在创建该类的一个新实例。所以，列表的实例就是一个列表。在这种情况下，是一个包含 0、1 和 2 的列表。

如果我问 `s` 的类型是什么，我会看到它是 `list` 类，这和我只是键入 `list` 时看到的结果相同。而且，问题不在于列表本身，而在于描述与列表相关的所有可能行为的类。

列表类定义了有关列表如何工作的所有内容，如方法、列表上的加法和乘法的运作方式，以及列表上的项目分配和查找的运作方式。因此，决定元素在开头是元素 0 而不是元素 1 是列表类的责任。

除了使用内置类，我们还可以定义自己的类，然后创建这些类的实例来构建新类型的对象。一个类描述了其实例的行为。比如说，我们想要表示银行账户，并且我们想要将与银行账户相关的信息捆绑在一起，比如账户余额和账户持有人，以及与银行账户相关的行为，比如存钱和取钱。

假设现在我们将 `Account.interest` 更改为 0.05。这是一个类属性赋值语句，将其更改为 0.05。

最后，我们可以检查每个实例的利率。Tom 的账户的利率是 0.05，这刚刚因为这个类属性赋值语句而改变。Jim 仍然有一个利率是一个特殊情况，0.08。通过分配给类，你不会抹掉所有特殊情况，它们仍然存在。

在对象上调用方法是与对象交互的主要方式。方法调用与函数调用不同，因为它们涉及到点表达式。

使用点表示法调用方法，看起来像这样：你编写一些表达式，然后是一个点，然后是一个名称。表达式可以是任何有效的 Python 表达式。因此，你可能会编写一些复杂的内容来选择你要查找方法的对象。但名称只需是一个简单的名字，如 `deposit`、`withdraw`、`append` 等。

该表达式的值是通过在该表达式的值对象中查找名称而计算的属性值。首先，你必须评估这个表达式，以获取点表达式的对象。然后你可以查找属性名称，然后你可以调用这个方法。

`tom_account.deposit` 时，现在实际上这个调用表达式的结构是运算符位置有一个点表达式。整个事情只是一个常规的调用表达式。但是点表达式首先被评估，因为它是运算符子表达式。它给你一个知道它正在向 `tom_account` 存款的方法。然后你可以将 10 作为参数传递。

所以这里右边是我们上次定义的账户类和一些如何使用它的示例。它只有三个方法：`__init__`、`deposit` 和 `withdraw`。通常不直接调用 `__init__`，而是在创建账户类实例时自动发生。而 `deposit` 和 `withdraw` 则使用方法调用表达式调用，就像我们在幻灯片上看到的那样。

如果我为 Alan 创建一个账户，当然可以像这样存入款项。如果我存款两次，效果是累积的。

但我说过，`deposit` 本身就是一个表达式。在评估时，我们发现一个绑定方法，即 `Account.deposit`。

成为绑定方法意味着什么呢？这意味着 `self` 参数已经填充好了。这是一个将会向 Alan 的账户存款的方法。

为了看看它是如何工作的，让我创建第二个账户。它的余额为 0，而 A 在我的两次存款后现在的余额为 10。

如果我分配名字 `f` 存到 A 的账户，然后我调用 `f`，我正在向 Alan 的账户存款。如果我存款两次，我们会发现我们最初的余额从 10 变为 30，实际上是 A 账户的余额增加了。而 B 账户的余额根本没有变化，因为我们一直在向 A 存款。

即使这个调用表达式没有提到 A，它实际上也隐式地涉及到了，因为 `f` 是一个绑定方法，用于向 A 存款。在更长的程序上下文中，这有时可能是有用的。例如，我可以创建一个映射对象，其中我正在映射的函数是向 A 的账户存款。

然后我可以决定要存多少：10 到 20 怎么样？到目前为止，我还没有进行任何存款，因为映射对象是惰性求值的迭代器。但是如果我要求下一个 `m`，那么实际上它将把 10，即此范围内的第一个元素，存入 A 的账户。

所以现在是 40。接下来，我们会存入 51，然后 63，然后 76 等等。

通过映射，这是一个 `a.deposit` 函数，它是一个绑定方法。它的行为类似于一个函数，除了我们已经填写入了 `self`。因此，当我们调用它时，只需传入一个金额。

绑定方法是函数也是类属性，其中 `self` 参数已经填充为类的一个实例。

让我们回顾一下所有的术语。

所有对象都有属性，这些属性是名称-值对，可以通过名称查找。类是一种类型，这是对象的一类。类本身也是对象，因此，它们也有属性。

实例属性是类的一个实例的属性，而类属性是类本身的属性，仍然可以从实例访问。

类属性同时也是一个函数，就是一个方法。在 Python 对象系统中，函数是对象，绑定方法也是对象。它们只是一个曾经是类属性的函数，并且已经将其第一个参数 `self` 绑定到类的实例。

点表达式将求值为绑定方法，对于那些是函数的类属性。如果我写“实例.方法名”，我得到一个通过其名称查找的绑定方法。它起初是一个函数，但然后实例被填充为第一个参数。因此，在调用这个绑定方法时，我只需传入其余的参数。

Python 区分函数和绑定方法。我们从课程开始就一直在创建函数，而绑定方法将函数与将调用该方法的对象紧密地结合在一起。因此，对象和函数绑在一起就形成了绑定方法。

如果我使用类查找方法，我只会得到一个函数。但如果我使用账户类的实例查找方法，那么我就会得到一个绑定方法。

这种区别很重要，因为有两种不同的方法来调用这个存款函数：一种是将其作为函数调用，在这种情况下，我需要传递 `self` 和 `amount` 这两个参数；另一种，也是更常见的方法，是将其作为绑定方法调用，其中 `tom_account.deposit` 会自动填充 `self` 参数，因此我只需传递 `amount`。
