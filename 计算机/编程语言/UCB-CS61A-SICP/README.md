# UC Berkeley CS61A：《计算机程序的结构与解释》精翻

伯克利大学 CS61A 课程的中文精翻配版（2024 季），讲的是 SICP 的主线。课程从过程抽象与环境模型讲起，经数据抽象与对象系统，进入符号计算与 Scheme 解释器实现，最后落到声明式编程范式、SQL 与树形算法，把「程序如何组织」这件事讲透。

- **原视频**：https://www.bilibili.com/video/BV16J4m1u7xP — Bilibili，BV16J4m1u7xP
- **37 集**，已产出 4 册模块全书、5 篇复习笔记、26 份逐字稿

## 怎么学

- **过程抽象打底** → 模块 01 讲闭包、高阶函数、环境模型与递归计算，这是全课的思维底座
- **数据抽象** → 模块 02 讲可变状态、对象系统与算法效率，注意消息传递与时间顺序的差异
- **动手写解释器** → 模块 03 讲符号数据与求值器、语法分析器的实现，务必跟着敲一遍 Scheme 代码
- **换个范式看问题** → 模块 04 对比命令式与声明式，用 SQL 与树形递归重新表述同一类计算
- **复盘** → `notes/` 下的笔记按抽象层次组织，适合按主题串联回顾
