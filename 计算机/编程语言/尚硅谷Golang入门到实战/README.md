# 尚硅谷：Golang 入门到实战教程

尚硅谷的 Golang 系统课，388 集把 Go 语言从「为什么现在还需要一门静态语言」讲到能独立写出并发服务。前半程按语言主线推进：变量与类型、运算符与位运算、流程控制、函数包与错误处理、数组切片与 map，再到结构体、方法与接口构成的面向对象（配合记账与客户管理两个完整小项目）；中段进入文件操作、JSON 序列化、单元测试，再把并发（协程、管道、锁）、反射与 Socket 网络编程串成一条主线；后段用 Redis + 即时通讯聊天室做综合实战，最后补齐线性表、排序、栈与二叉树等数据结构与算法。

- **原视频**：https://www.bilibili.com/video/BV1ME411Y71o — Bilibili，BV1ME411Y71o
- **388 集**，已产出 15 册模块全书、28 篇复习笔记、155 份逐字稿

## 怎么学

- **先跑通工具链** → 模块 01、02 讲开发环境、编译运行与编码规范，Go 的工程体验和静态类型语言不同，务必先把这套规矩立起来
- **语言地基** → 模块 02~06 覆盖类型系统、运算符与位运算、流程控制、函数包错误处理、数组切片与 map，其中**切片与 map 的底层差异**（笔记 09、11）是 Go 面试与实际踩坑的高发区，务必动手验证
- **Go 的面向对象不是类** → 模块 07、08 与笔记 12~16 讲结构体、方法、接口、多态与类型断言，注意笔记 16 用记账与客户管理系统两个完整项目把这一段串起来，比看概念有效得多
- **并发是这门课的分水岭** → 模块 10、11 讲协程、管道、锁、反射与 Socket，配合笔记 18~21 逐个过；`select`、channel 方向和竞态这三处是全书最值得反复看的部分
- **实战闭环** → 模块 12、13 用 Redis + 聊天室把并发、网络与数据结构串成一个完整项目，笔记 22~25 按「消息协议 → 登录校验 → 在线管理与群发」分四步拆解，照着走一遍即可打通
- **补算法** → 模块 14、15 与笔记 26~28 覆盖稀疏数组、队列、链表、排序、栈与二叉树，这是全课最后一段，也最接近面试与实际工程的算法需求，建议考前单独拎出来刷
