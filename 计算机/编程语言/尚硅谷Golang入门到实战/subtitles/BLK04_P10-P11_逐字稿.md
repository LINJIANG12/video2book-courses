但是到了后期，我们做项目的时候，在后期做项目的时候，这个时候我们就会在 Linux 下面做 Go 开发。所以我把这几句话给大家点出来，不然的话有些同学可能就会有压力，说：“老师，我 Linux 没有学啊，我都不知道，那我就压力太大了。”所以我小结一下，把这几句话写到这里来：

我们会讲解、会说明在 Windows 下、在 Linux 下、在 Mac 下如何安装 VSCode 开发工具，并且还会讲解如何在这三个系统下安装 Go 的 SDK 并做开发，和如何开发 Go 程序。但是为了大家学习方便，我们前期以 Windows 为主，选择在 Windows 下面开发 Go，这样子大家学习起来比较方便。但是有一点，到了后期，到我们真正开始讲项目时，讲项目和讲区块链的时候，就会使用 Linux 系统了。

让大家知道我们安排的时候在哪个系统下面讲，原因是什么，我都给大家说了。因为你实际上在 Windows 下面做开发，开发了过后在上传到 Linux，其实也是一样的，完全是一样的。在实际开发中也可以在 Windows 下面开发好程序，然后部署到 Linux 系统下，这都是可以的，因为它们的核心语法是一样的。所以我把这个知识点给大家点出来，让大家做到心中有数，不至于非常迷茫。
