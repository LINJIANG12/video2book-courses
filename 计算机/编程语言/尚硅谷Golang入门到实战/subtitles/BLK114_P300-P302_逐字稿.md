
把这部分包裹起来之后，这里有一个问题：你在不停地往服务器端发送，写了一句再发送，现在没法退出。所以我们在这里应该做一个判断，当用户输入的内容是 exit 关键字的时候就退出：

```go
// 如果用户输入的是 exit 就退出
if strings.Trim(line, " \r\n") == "exit" {
    fmt.Println("客户端退出...")
    break
}
```

问大家，如果我直接拿 `line == "exit"` 这样写对不对？有没有问题？
哪里写错了？逻辑上这样写是不行的。因为在读取终端输入的时候，字符串本身是带了 `\n` 或 `\r\n` 的。所以你在比较的时候，应该先把 `line` 进行一个处理，把换行符去掉。大家还记不记得怎么去掉？

非常简单，使用 `strings.Trim`：

```go
line = strings.Trim(line, " \r\n")
```

对 `line` 中的 `\r`、`\n` 以及空格进行截取去除，然后再来判断是否等于 `exit`。如果要使用 `strings` 包，我们还需要在上面引入 `strings` 包。

```go
// 客户端循环输入与退出逻辑
for {
    line, err := reader.ReadString('\n')
    if err != nil {
        fmt.Println("readString err =", err)
    }
    
    // 如果用户输入 exit，就退出
    line = strings.Trim(line, " \r\n")
    if line == "exit" {
        fmt.Println("客户端退出...")
        break
    }
    
    // 发送给服务器端，补上换行符
    _, err = conn.Write([]byte(line + "\n"))
    if err != nil {
        fmt.Println("conn.Write err =", err)
    }
}
```
