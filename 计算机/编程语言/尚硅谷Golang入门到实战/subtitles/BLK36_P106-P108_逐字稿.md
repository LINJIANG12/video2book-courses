现在我们开始分析，代码从这里开始执行。首先执行 $i = 0$。在内存里面，我们就发现有一个变量 $i$ 的值。紧接着，$i < 4$ 是成立的，于是乎进入到这里，$j = 0$。

$j = 0$ 之后，$j < 10$ 成立，进到循环体。$j == 2$ 吗？不等于 2，于是乎不进行 continue，就输出。此时此刻，在终端就会输出：

$j=0$ 完了之后，继续到 $j++$。$j++$ 完了之后变成 1。1 再来判断，$1 < 10$ 成立，又进行判断 $j == 2$ 吗？不等于 2，于是再输出，这个时候就输出：
$j=1$

$j=1$ 输出完，再进行 $j++$ 变成 2。关键点来了：$2 < 10$ 成立，这时 $j == 2$。一旦 $j == 2$，注意听讲，这时 continue 了。一旦 continue，下面这句话就不会被执行。

同学们好。下面我们接着来讲解 Go 语言的跳转控制语句 goto。首先我们来看一下 goto 是什么。听这个名字大家能猜出来是什么吧？goto 就是跳转到哪里去、到哪里去的意思。goto 这个语句其实用得最多的还是像在汇编语言里面用得比较多，像这种高级语言里面，goto 这种语法用得比较少。

为什么这么说呢？我们先来看一下 goto 的一个基本介绍。大家看，Go 语言里面 goto 语句可以无条件地转移到程序中指定的行。那这就意味着说它可以乱跳，只要你给它一个标签，你就可以指定跳转到某个地方去，这是它的第一个特点。

第二个大家注意一下，goto 语句通常与条件语句配合使用，用来实现条件转移、跳出循环体等功能。也就是说它一般和 `if` 语句配合。但是注意看这里，在 Go 程序设计中，我们的设计者，包括我们本身这种开发程序员，一般都不太主张使用 goto 语句。甚至有一段时间，在行业里面就说 goto 语句是一种不好的设计，因此有些语言就直接不让用 goto 了。后边人们发现其实 goto 语句本身并没有错，而是使用者的问题，因此有些高级语言又恢复了 goto，比如像 Java，它也是支持 goto 的。所以说不是语言本身的问题，而是人的问题，包括 Go 语言也是支持 goto 的。

但是很多程序员包括一些设计语言的专家也认为，尽量避免使用 goto。不是说不能用，而是尽量避免使用 goto。为什么呢？因为 goto 语句容易造成程序的流程混乱，使理解和调试程序产生困难。所以说我在这里讲 goto 语句，主要是有几点要告诉大家：第一，Go 语言是支持 goto 的；第二，goto 可以实现条件转移、跳出循环，只要给它一个标签，它就可以跳到指定位置；第三，我建议大家能不用 goto 就不用 goto。至少我们讲完这个 goto 之后，面试官问你 Go 语言里面可不可以用 goto，你不要说根本就不支持，这就错了。它是支持的，但是你可以话锋一转，告诉面试官说我们尽量不要用 goto，除非迫不得已可以用一下，一般情况下就不要用 goto 了，因为 goto 容易造成程序流程的混乱。这就是 goto 的一个基本介绍。

下面我们来看一下 goto 的基本语法：

```go
goto label
...
label: 表达式/语句
```

goto 的基本语法是这样子的：你给一个 label，当然这个 label 大家看到是你自定义的，也就是说只要满足标识符的定义规则，你就可以写，后面有个冒号。goto 就是说，当我们的程序执行到 goto 的时候，它发现你后面跟了一个 label，即一个标签，它就会跳过中间的代码，这边的代码它就不执行了。不管你的代码有多少，直接就不执行了，直接从 goto 这一行跳转到这个 label 的位置开始执行。

它的一个流程图也比较简单，是这样子的：代码从这里开始执行，执行到 statement 1，假设执行到 statement 1 这个代码块里面你有一个 goto 语句，比如说你这儿有一个 `goto label3`，如果写了一个 `goto label3`，那么整个代码就直接从这里到这儿来了，也就是说这边的代码就不执行了。其实并不难，对不对？它就是跳转到哪里。

那么我们把 goto 的基本介绍和基本语法整理一下笔记：

### 跳转控制语句-goto

#### 1. 基本介绍
1. Go 语言的 goto 语句可以无条件地转移到程序中指定的行。
2. goto 语句通常与条件语句配合使用。可用来实现条件转移，跳出循环体等功能。
3. 在 Go 程序设计中一般不主张使用 goto 语句，以免造成程序流程的混乱，使理解和调试程序产生困难。

#### 2. 基本语法
```go
goto label
...
label: statement
```

#### 3. goto 的流程图
代码顺序执行，当遇到 goto label 时，直接跳转到 label 对应的位置继续执行。

有了前面这三点知识基础之后，我们来一个快速入门案例。现在我们来写一段代码来说明一下 goto 的使用。老规矩，我们在 `chapter05` 里面新建一个文件夹，叫 `gotodemo`。在这个文件夹里面，我们新建一个文件叫 `main.go`。

老规矩，我们来写一下代码：

```go
package main

import (
	"fmt"
)

func main() {
	// 演示 goto 的使用
	fmt.Println("ok1")
	fmt.Println("ok2")
	fmt.Println("ok3")
	fmt.Println("ok4")
	fmt.Println("ok5")
	fmt.Println("ok6")
	fmt.Println("ok7")
}
```

假如我们不做控制，它是不是就从 ok1 一直执行到 ok7？这个没问题吧。那假如我在 ok5 这个地方加了一个 label：

```go
package main

import (
	"fmt"
)

func main() {
	fmt.Println("ok1")
	goto label1
	fmt.Println("ok2")
	fmt.Println("ok3")
	fmt.Println("ok4")
label1:
	fmt.Println("ok5")
	fmt.Println("ok6")
	fmt.Println("ok7")
}
```

这个名字是根据你的需要来设置的。这个地方我在 ok1 后面写了一个 `goto label1`。这样子会出现一个什么情况呢？当我们的代码执行到这一行 `goto label1` 的时候，这里的代码，就是 ok2、ok3、ok4 这三句代码就会被跳过，不再执行了，它直接从这里一下就跳转到 label1 下面这个语句开始执行。

我们来看看是不是这样子的。保存一下，看代码没有毛病，我们来运行一下：

```bash
cd ../gotodemo
go run main.go
```

我们看代码的执行效果，发现 ok1 执行了过后直接就是 ok5。为什么？因为它直接就跳过了这么几句代码，直接跳过去了。

这里编辑器还会有个警告：unreachable code。意思就是说下面这部分代码是执行不了的。一般情况下 goto 会配合一个 `if` 语句，即满足什么条件再 goto。比如我们这里有个变量 `n := 30`，一般会跟 `if` 配合使用：

```go
package main

import (
	"fmt"
)

func main() {
	n := 30
	fmt.Println("ok1")
	if n > 20 {
		goto label1
	}
	fmt.Println("ok2")
	fmt.Println("ok3")
	fmt.Println("ok4")
label1:
	fmt.Println("ok5")
	fmt.Println("ok6")
	fmt.Println("ok7")
}
```

在大于 20 的情况下，我们再去执行这个 goto 语句。这样写完了之后就没有警告了。因为一般来说不会说没有条件就去执行一个 goto，往往是有一个条件来做的。在这样一个情况下，如果 `n = 10`，那当然就不用 goto 了，因为它不满足这个条件，不进到这个 `if` 语句，自然就不会 goto，那就是按正常流程执行，输出依然是 ok1 到 ok7 正常执行。但是如果在输入的时候这个 `n` 是 30，30 大于 20，这个时候它就会执行 goto，这三句话就会被跳过。

所以说我刚才讲过，goto 一般来讲会跟 `if` 语句配合使用，因为你不可能无缘无故地就 goto 到一个 label 里面去。关于 goto 的一个基本演示我们就介绍到这里。最后记住老师的一句话：尽量避免使用 goto，除非迫不得已。

这个讲完了过后，我们再来讲最后一个跳转控制语句：return。

return 在这里我不想介绍得太多，为什么呢？return 会使用在方法或者函数中，它表示跳出所在的方法或者函数。关于 return 的详细介绍，我是准备放在函数的时候详细介绍。这里我就先提一下，因为 return 毕竟也是用来控制流程的，所以放在这里说一下比较合适。

return 是使用在函数或方法中的，它表示跳出或者结束所在的方法或函数。看一个简单的例子，比如在 `main` 函数里面，我们有一个 `for` 循环，`for` 循环里面我做了一个判断：如果 `i == 3`，我就 `return`。那么这个 `return` 表示什么意思呢？这个 `return` 就是表示结束或者跳出这个 `main` 函数，那就相当于说是结束这个程序了。如果你的 `return` 是放在 `main` 函数的，那就表示整个程序结束；如果是放在别的函数，比如前面有个 `test` 函数，那就表示跳出那个函数。
