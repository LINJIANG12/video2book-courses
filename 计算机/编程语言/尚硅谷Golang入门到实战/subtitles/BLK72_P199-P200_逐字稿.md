我们来看一下方法和函数的区别。

我认为方法和函数的区别主要是三个方面。第一个就是调用方式不一样。函数的调用方式直接通过函数名，然后传实参就可以了。方法的调用方式，首先得有一个变量，当然这个变量应该是和方法绑定的类型的变量才可以，然后传入实际参数。这个在前面已经说过了。

第二点，对于普通函数，接收者为值类型的时候，就不能将指针类型的数据传入，反之亦然。这句话什么意思呢？就是说如果是一个函数，它如果是值类型，你就只能传值类型；它如果是指针类型，你就只能传指针类型。

我们来看一个案例来说话。新建一个文件夹，叫做 `method_vs_function`，看看它们之间的区别在哪里，新建 `main.go`。

假设现在有一个结构体叫 `Person`：

```go
type Person struct {
    Name string
}
```

我给它一个字段叫 `Name`。假设这里写了一个函数叫 `test01`：

```go
func test01(p Person) {
    fmt.Println(p.Name)
}
```

这里定义了一个 `Person` 类型，然后输出 `p.Name`。现在在 `main` 函数里面定义一个 `Person`：

```go
p := Person{"tom"}
```

在调用这个函数的时候：

```go
test01(p)
```

因为这里是结构体类型，并不是指针类型，因此传的就是 `p`。运行之后它的结果就是 tom，是正确的。但是因为这里写的是 `Person`，你就不能传地址：

```go
test01(&p)
```

你传地址的话就直接报错了，代码肯定是不对的。

如果这里有一个函数 `test02`，它是一个指针：

```go
func test02(p *Person) {
    fmt.Println(p.Name)
}
```

它是指针，在调用 `test02` 的时候，就只能传一个地址：

```go
test02(&p)
```

传一个地址给指针类型，它跑起来结果也是 tom。因为它是指针类型，你就必须传指针，如果你传 `test02(p)`，它也会报错。

所以这里就有一个严格的规定，即反之亦然：如果它是指针，你就只能传地址；它如果是值类型，你就只能传值。

但是我们要说的是，方法不一样。比如给 `struct` 写一个方法，接收者为值类型，可以直接用指针类型的变量调用该方法；反过来也是一样，如果接收者是指针类型，也可以用值类型的变量调用。

给 `Person` 定义两个方法：

```go
func (p Person) test03() {
    p.Name = "jack"
    fmt.Println("test03() =", p.Name)
}
```

这里直接写的是值类型，不是指针类型。在调用的时候，它是给 `Person` 这种类型绑定的一个方法，我这样调用：

```go
p.test03()
```

肯定是没问题的，输出 jack。但是你会发现，这样调用它也可以：

```go
(&p).test03()
```

给 `p` 取了一个地址，然后调用 `test03` 也可以。为什么呢？因为编译器做了一个优化。虽然传了一个地址，也能调用 `test03`，但是传进去之后，这个地方仍然是进行了一个值拷贝。

在 `main` 函数中打印：

```go
fmt.Println("main() p.Name =", p.Name)
```

用 `p.test03()` 调用，因为是值拷贝，内部修改为 jack 肯定不会影响到外面的 tom，所以输出 tom。

但有些同学不能理解的是，通过 `(&p).test03()` 传了一个地址过去，调用完了之后再次打印，它仍然还是 tom。因为这只是形式上穿了一个地址，其实它在这种方式传递的时候，`p` 仍然是一个值拷贝，对外面这个 `p` 仍然是不会生效的。从形式上看是传入了地址，但是本质仍然是值拷贝，因为方法接收者写的是值类型。编译器在做优化的时候，仍然把它改成了值拷贝的形式，语法上又支持这种写法。

同样，反过来也是一样。如果有一个 `test04`，把它改成一个指针类型：

```go
func (p *Person) test04() {
    p.Name = "mary"
    fmt.Println("test04() =", p.Name)
}
```

它也可以通过值类型或者地址来调用这个方法。

按照正规的方法来调用，应该这样调：

```go

```

因为是指针，所以传一个地址进去。调用完了之后，因为按照标准方法去调用，它又是指针，所以 `p.Name` 肯定被改掉了，`mary` 就会直接影响到外面的 `p`。

而且它还支持这种写法，直接：

```go

```

也可以。这种写法等价于 `(&p).test04()`，底层的编译器给我们做了一个优化处理。说明这样调用的效果跟上面是一样的，仍然会修改外面的值。

对于普通的函数，如果接收者是值类型，就不能将指针类型传给它，反之亦然。但是如果定义一个方法，接收者为值类型，可以用指针类型的变量去调用该方法，也可以用值类型调用；反过来接收者是指针类型也是一样。最终决定权在于方法定义的地方到底是值类型还是指针类型，到底是进行地址拷贝还是值拷贝，取决于这个位置到底是值类型还是引用类型，这才是关键，而不在于调用形式。

```go
type Visitor struct {
    Name string

}

func (visitor *Visitor) showPrice() {
    if visitor.Age >= 90 || visitor.Age <= 8 {
        fmt.Println("考虑到安全，不要玩耍")
        return
    }
    if visitor.Age > 18 {

    } else {
        fmt.Printf("游客的名字为 %v 年龄为 %v 免费\n", visitor.Name, visitor.Age)
    }
}
```
