我们再来看第四个。第四个方法它是这样要求的：给 Person 结构体添加一个 getSum 方法，可以计算两个数的和，并且返回结果。注意，这是有个新的东西，有返回值了。前面我们举的三个方法其实都没有返回值，现在有返回值了。来看这个案例怎么说。

也非常之简单，我们把它包起来，明白？包起来过后，我们把这个改成 getSum。这里边他要传两个数，那一个叫 n1，一个叫 n2，没问题。但是他有一个返回结果，返回结果这个结果写到屁股后边就行了。当然如果你有多个返回值，怎么样？括起来写就行了，能理解吧？因为这里面我只有一个返回值，因此我就写一个 int 就行了。

好的，那现在这个就简单了。我们这里边不输出了，因为他要把这个结果返回去，就 `return n1 + n2`，完事。

```go
func (p Person) getSum(n1 int, n2 int) int {
    return n1 + n2
}
```

那这个时候注意听，因为你这个方法这个结果是返回去，而没有在自身的函数体内输出，因此我们在调用的时候得需要有个结果来接收：

```go
res := p.getSum(10, 20)
fmt.Println("res=", res)
```

代码写完。我们跑一下，同学们，跑一下，走。我们运算过后，我们发现它的结果跟我们想象的是一样的，看到没有？OK，`res=30`。

也就是说其实这个也很简单，就是你把这个 10 和 20 传给了我们的 n1 和 n2，然后它运算过后把这个结果返回给这个 int，你接收了。

这个地方我们可以看到，我们在这一块、在这个方法里面并没有去使用这个 p，它也没有报错，对不对？也就是说这个 p 其实你用也可以，不用也行。那这个 p 仍然还是这个 p，是吧？还是这个 p，能理解这意思吧？注意它的一个用法，同学们。
