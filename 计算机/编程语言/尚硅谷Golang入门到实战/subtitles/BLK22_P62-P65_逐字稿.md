那么老规矩，我们还是把逻辑运算的注意事项和细节给大家讲一讲。大家看到，我们这个逻辑与还有一个名字叫做短路与，我不知道有同学有没有听过这个东西。

什么叫做短路与呢？就是逻辑与有一个特点，它有什么特点呢？它是这样子的：如果第一个条件已经为 false 了，那么第二个条件它就不会判断。这个其实也能想得通，因为大家都知道，逻辑与是两个条件都为真，就是两边都为真才会真。但它第一个条件已经为假的话，第二个条件就没有必要判断了，它就放弃判断，最终结果就为 false。这就是短路。就是说第一个条件为假，第二个条件就不判断了。

还有一种就是我们说的叫短路或。逻辑或它也叫短路或。为什么叫短路或呢？它是这样子的：如果第一个条件就已经为真了，第二个条件它也不会判断，最终为真。为什么呢？因为你第一个条件为真，第二个条件为真还是为假，已经不对整个结果有影响了。第一个为真，第二个条件你为真或者为假，最终结果都为真，因此它就放弃判断。明白这个意思吗？

赋值运算符简单的讲，就是将某个运算后的值赋给指定的变量。这句话其实很有含义的。什么叫运算后的值呢？比如说加减乘除，对吧？或者是一个函数返回的值，或者就是一个变量的值，或者是一个常量值都可以。反正就是把一个值交给一个变量，那么这个就叫赋值运算，就要用赋值运算来进行操作。

在我们的 Golang 里面，赋值运算符有哪些呢？在这整理一下。最简单的就是一个等号，这是最简单的赋值运算，它是将一个表达式的值赋给一个左值。比如说 $c = a + b$，就是将 $a + b$ 的表达式结果赋给 $c$，简单吧？

再比如说像这种，这个我们叫做复合运算符。那么这个地方，`+=`、`-=`、`*=`、`/=`、`%=` 是什么意思呢？就这样子的。你比如说 $c += a$ 就等价于 $c = c + a$。它是一种简写，明白我的意思吧？其它的依此类推我就不一一说了，比如说 $c *= a$ 就等于 $c = c * a$。相当于说它把这个简写了一次。如果我们这个表达式特别复杂，这样写就特别简单。其它依此类推，这是赋值运算符的分类。
