这道题相对来说比前面两道题要稍微麻烦一点，但是也不是很难。我们先看一下这个题的要求：有一堆桃子，猴子第一天吃掉了其中的一半，并再多吃了一个。以后猴子每天都吃其中的一半，然后再多吃一个。到第十天的时候，再想吃的时候（这个时候还没有吃），发现只有一个桃子了。问最初共有多少桃子？也就是说，说白了就是求第一天有多少桃子，第一天还没有吃的时候有多少桃子。

我们先把这个题拿过来，做一个分析，这是我们的练习题三：

思路分析：通过题目的要求，我们发现在这里有一句话说，到第十天想吃的时候只有一个桃子了。那我们得出一个结论，第十天只有一个桃子。问题来了，它第九天有多少个桃子呢？它是反过来推的。意思就是说，我现在不知道第一天有多少个，但是我知道最后这一天，也就是第十天有一个桃子。那反过来，第九天有几个桃子？

第九天其实应该等于第十天的桃子数量加上一个1，括起来，再乘以一个2。为什么这么讲呢？如果第九天有这么多桃子，第九天它吃的时候，先吃掉一半，然后再吃掉一个，不就变成第十天的桃子了吗？这就是倒着推过来的。要求前一天的桃子，实际上是它下一天桃子的数量加1乘以2。

规律已经找到了：第n天的桃子数量，假设用peach表示，它应该等于下一天的桃子数量加上一个1，括起来，再乘以一个2就可以了：
$$\text{peach}(n) = (\text{peach}(n + 1) + 1) \times 2$$

因为它是从最后一天往前推，所以是 $n + 1$。规律找到之后，下面我们就可以走代码了。

当然，我们这个 $n$ 的范围是有要求的，它的范围是1到10之间。如果我们想写的更完整一点，可以这样写：如果 $n > 10$ 或者 $n < 1$，不在这个范围，就直接提示它一句话：“输入的天数不对”，然后返回0，表示没有得到正确的数量。

```go
package main

import (
	"fmt"
)

func peach(n int) int {
	if n > 10 || n < 1 {
		fmt.Println("输入的天数不对")
		return 0
	}
	if n == 10 {
		return 1
	} else {
		return (peach(n + 1) + 1) * 2
	}
}

}
```

下面我们再来看第五个细节。第五个细节老师要讲的就是这个点：基本数据类型和数组默认都是值传递，即进行值拷贝，在函数内修改不会影响到原来的值。这地方要注意哪一点呢？就是这个点有点意思。

基本数据类型是值传递，这个很好理解。但是数组，基本数据类型还有数组，都是值传递。值传递其实就是进行的值拷贝，在函数内修改不会影响到原来的值。有些同学就说了：“老师，那个数组不是我们现在还没学吗？那你这先提这个干什么呢？”因为我们有些听视频的同学是有编程基础的。在其他的编程语言里面，这个数组往往都是引用类型的，比如 Java。Java 其实在传递的时候它是引用传递，所以它在函数内是可以修改到函数外的数组。但是同学们注意，再强调一点：在 Go 语言里面，基本数据类型和数组都是值传递，也就是说它不是引用传递，那么在函数内修改不会影响到原来的值。我给它举个例子说明一下。因为数组大家还没有去使用过，所以这个地方我先把这个结论抛给大家，讲到数组的时候我们再举例。我现在举一个基本数据类型的案例，其实前面已经讲过了，只是在这再把它系统地说一遍。

```go
package main

import "fmt"

func test02(n1 int) {
	n1 = n1 + 10
	fmt.Println("test02() n1 =", n1)
}

func main() {
	var num int = 20
	test02(num)
	fmt.Println("main() num =", num)
}
```

我在主函数里面定义了一个变量 `num = 20`，传给了 `test02` 里面的 `n1`。那么根据前面咱们讲解的函数调用的机制而言，会开辟一个新的栈，叫 `test02` 这个栈，里面会有一个新的变量 `n1`，因此这个 `n1` 的变化不会影响到外面。也就是说它们两个是独立的。根据前面函数调用机制就可以把这个搞清楚，只是我在这再把它系统地说了一遍。

跑起来看一下效果，这个时候你会看到两个值是完全不一样的。`test02` 里面加了一个 10，变成了 30，但是 `main` 函数里面的仍然是 20。这也就是说明这个概念：传到这里面它进行了一个值拷贝。所谓值拷贝就是说，它会把 `num` 的 20 拷贝给 `test02` 里面的 `n1`，它们两个是不同的变量。它把 20 拷贝给 `n1` 之后，在函数内加 10 改变的是 `test02` 里面的 `n1`，因此对这个 `num` 没有任何影响。基本数据类型包括数组，它是一种值拷贝的方式来进行参数传递的。

第六点，我们再来看。如果我们真的希望函数内的变量能够修改函数外的变量，可以传入地址。函数内以指针的方式来操作变量，这是可以的。从效果上来看，类似于引用传递。因为现在我们还没有讲过引用传递的其他数据类型，比如说 map、切片，现在还没办法举这个案例，所以我现在只能先用指针的方式来达到一种引用传递的效果，就是直接传地址的方式来改变外面的值。

第七点也是非常重要的：在 Go 函数里面它不支持函数的重载。

它不支持函数重载。为什么要单独提这一句话？因为有很多的编程语言里面它是支持函数重载的。那什么叫函数重载？对于我们初学者还没有太多的认识，我举个例子。比如说大家看，这是个 test03，你就不能这样写。我这样写简单一点，写 test02 吧。很多编程语言里面可以函数名相同，然后形参不同，比如说我多一个形参：

```go

}

func test02(n1 int, n2 int) {
}
```

很多编程语言里面，test02 和这里的 test02，它们通过形参不同，形参的个数或者数据类型不同可以区分。但是我告诉大家，在 Go 语言里面它不允许这样写。因为这个现象，就是两个 test02，大家看到的，注意，尤其是初学者可以注意一下。这是 test02，这个也叫 test02。有很多语言里面它支持函数名相同，但是只要你形参的个数或者数据类型不相同，它就认为这个是正确的，它认为是不同的函数。

但是我告诉大家，这种写法，这个所谓的重载，在 GoLang 语言里面它是不支持的。你保存一下，它马上就会报错。大家看，它马上就会报错。为什么呢？因为后面我们会讲，在 Go 语言里面它是支持可变参数的，而且它还有一个叫做空接口的东西，其实它完全可以达到这种效果。也就是说 Go 语言里面它是用另外一种形式来实现这种函数重载的，能理解我的意思吗？
