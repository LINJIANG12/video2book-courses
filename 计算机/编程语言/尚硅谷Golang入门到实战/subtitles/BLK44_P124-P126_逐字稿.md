现在再给大家介绍一下 Go 函数里面的匿名函数。

大家都知道，匿名函数在很多编程语言里面其实都是有的。所谓匿名函数就是没有名字的函数。一般情况下我们的函数都是有名儿的，那什么时候我们会用到没有名字的函数呢？Go 支持匿名函数，如果某个函数只是希望使用一次，就可以考虑使用匿名函数，这是第一个应用场景。当然，匿名函数也可以实现多次调用，待会儿我们再具体说。

匿名函数使用方式有这么两种：第一种方式是在定义匿名函数时就直接使用；第二种是将匿名函数赋给一个变量，此时这个变量就变成了函数变量，然后再通过该变量来调用匿名函数。就是这么两种用法。

现在我先把前面的这两种讲解过后，再回头说全局匿名函数。

我们来讲一下 Go 语言里面的匿名函数。

### 基本介绍

匿名函数就是没有名字的函数。

匿名函数的调用方式：

第一种方式：在定义匿名函数时就直接调用。这时只能调用一次，调过了再想调没有机会了，因为没有给它名字，也没有把这个匿名函数给一个变量，那就用不了了。这种方式匿名函数只能调用一次。有时还真有这样的需求，就是我们并不希望定义一个函数，而是想调一次就完事，这个时候匿名函数就可以用了。

第二种方式：把匿名函数赋给一个变量，然后再调用。

我们来举例演示第一种调用方式。新建一个文件夹 `funcdemo06`，写一个文件叫 `main.go`。

我们来看第一种方式：在定义时就直接调用。

假设有这么一个情况，求两个数的和，使用匿名函数的方式完成：

```go
package main

import (
	"fmt"
)

func main() {
	// 在定义匿名函数时就直接调用，这种方式匿名函数只能调用一次

	// 案例演示：求两个数的和，使用匿名函数的方式完成
	res1 := func (n1 int, n2 int) int {
		return n1 + n2
	}(10, 20)

	fmt.Println("res1=", res1)
}
```

这里面没有函数名，直接写形参 `n1 int, n2 int`，返回一个 `int`。没有函数名怎么调呢？直接括号括起来，在后面传参就行了。我们用一个变量 `res1` 来接收。

这就是匿名函数在定义时同时就完成了调用。怎么体现出定义的？前面这部分就是定义。怎么体现出调用的？后面传参了，传了具体的数值 10 和 20。这相当于在定义这个匿名函数的时候同时就调用了它。形参 10 会给到 `n1`，20 会给到 `n2`，进行计算后把结果返回给 `res1`。

我们运行一下：`go run main.go`。可以看到 `res1` 确实等于 30。这就是匿名函数在定义时直接调用的一个经典案例。

还有一种方式，就是将匿名函数赋给一个变量，然后通过该变量来调用匿名函数。这也是一种用法。

我们再来看，求两个数的差，把它交给一个变量 `a`：

```go
// 将匿名函数 func (n1 int, n2 int) int 赋给变量 a
// 则 a 的数据类型就是函数变量/函数类型
// 此时，我们可以通过 a 完成调用
a := func (n1 int, n2 int) int {
	return n1 - n2
}

res2 := a(10, 30)
fmt.Println("res2=", res2)
```

这句话的意思就是将匿名函数赋给了 `a` 这个变量。此时此刻 `a` 这个变量其实就已经是一个函数了，它是个函数变量，`a` 的数据类型就是函数类型。我们可以通过 `a` 完成调用。

我们调用 `a(10, 30)`，把 10 传给 `n1`，把 30 传给 `n2`，返回的结果赋给 `res2`。此时 `res2` 就等于 -20。

这个时候 `a` 就可以反复调用。但是大家知道，这个 `a` 可不是函数名，不能理解成函数名。如果用这个 `a` 反复调用也是可以的，比如：

```go
res3 := a(90, 30)
fmt.Println("res3=", res3)
```

此时 `res3` 就应该等于 60。运行一下，`res3` 等于 60，代码就 OK 了。

这是匿名函数的第二种用法：将定义的匿名函数交给一个变量，再通过变量完成调用。一般在 `main` 里面是定义不了函数的，单独定义函数语法通不过；但是通过这种方式，就可以在一个函数里面再定义一个函数了，它还是有它的价值的。在某些情况下，我们用这种方式也可以完成一些特殊的需求。

### 全局匿名函数

如果我们将匿名函数赋给一个全局变量，那此时此刻，这个匿名函数就称为全局匿名函数，可以在整个程序中有效。

给大家演示一下全局匿名函数：

```go
package main

import (
	"fmt"
)

var (
	// fun1就是一个全局匿名函数
	Fun1 = func (n1 int, n2 int) int {
		return n1 * n2
	}
)

func main() {
	// 全局匿名函数的使用
	res4 := Fun1(4, 9)
	fmt.Println("res4=", res4)
}
```

因为 `Fun1` 是一个全局变量，把匿名函数交给这个全局变量，此时此刻 `Fun1` 就代表一个全局匿名函数，可以在任何地方使用，在整个程序都是有效的。当然这个时候变量名首字母要大写才是全局有效。

调用时用 `res4 := Fun1(4, 9)`，运行输出应该是 36。这就是全局匿名函数的使用。
