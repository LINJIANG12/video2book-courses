我们再来给大家介绍一下在Go语言函数里面的一个关键字，叫defer。defer听这个名字它是一个延时的意思。为什么在Go语言里面增加了defer这个关键字呢？这个词是非常有用的。在函数中，程序员经常需要创建资源。这块我们现在还没学创建资源，但是我可以先给大家介绍一下。比如后面我们去打开一个数据库的连接，或者打开一个文件句柄、锁等等，这些都是资源。

为了在函数执行完毕后及时释放资源，Go的设计者提供了一个defer延时机制。也就是说，你只要加上一个defer，你的函数在执行完毕过后，它一定会把你指定的资源关闭，或者说defer后面的语句在函数执行完毕过后它会去执行，就这么一个意思。

我举一个快速入门案例来加深一下大家对它的认识。我们先把函数中的defer做一个基本介绍。

在函数里面使用defer最主要的目的，就是在函数执行完毕后及时释放资源，我们可以用defer来完成这个功能。

我们来一个快速入门案例。我们写一段代码，重点是分析这段代码会运行出什么效果。

```go
package main

import (
	"fmt"
)

func sum(n1 int, n2 int) int {
	// 当执行到defer时，会先将defer后面的语句压入到一个独立的栈（defer栈）中，暂时不执行
	defer fmt.Println("ok1 n1=", n1)
	defer fmt.Println("ok2 n2=", n2)

	res := n1 + n2
	fmt.Println("ok3 res=", res)
	return res
}

func main() {
	res := sum(10, 20)
	fmt.Println("res=", res)
}
```

现在我们要研究一下这几句话分别是怎么输出的。通过这个，我们就来认识到defer它是怎么来执行的。

这段案例执行的顺序是这样子的：首先它调用sum。当我们的代码执行到defer的时候，编译器或者说我们的系统会将defer后面的语句压入到一个独立的栈中。我们姑且把这个叫做defer栈，它暂时不会执行。

当执行到defer时，会把defer后面的语句压入到独立的栈中。当函数执行完毕后，再从defer栈中取出，按照先入后出的方式出栈，然后执行。

也就是说，谁先进去反而后执行。这两个defer语句先不会执行，当函数执行完毕后，再从defer栈按照先入后出的方式出栈来执行。谁先入栈就后出。第一句defer先入栈，它就后出来；第二句defer后入栈，它就先出来。

defer栈全部都执行完毕后，再回到主函数，把这个值返回给res，第四句执行输出：

最后的顺序就是：
第一步输出`ok3 res= 30`
第二步输出`ok2 n2= 20`
第三步输出`ok1 n1= 10`
第四步输出`res= 30`
