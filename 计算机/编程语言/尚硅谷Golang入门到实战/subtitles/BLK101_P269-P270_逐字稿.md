同学们，我们来看下一个案例。

下一个案例就是刚才我们讲的一个很经典的案例。Golang能够充分发挥多CPU模式的优势，那么在Golang程序中，如何去设置运行的CPU数目呢？

这里我们要看一个包。在Golang里面提供了一个叫 runtime 的运行时包。这个运行时包里面有两个比较重要的函数。第一个函数是 `NumCPU`，听这个名字就知道是什么了，它能够检测你当前系统里面有多少个CPU，这是第一个。第二个函数可以根据你的需求，来设置整个Go程序去使用几个CPU。重点就是这两个。

我们把 runtime 包打开看一下手册。runtime 包提供了Go运行时环境的互操作，比如控制Go协程的函数，也包括反射包和底层的一些类型信息，后面还会用到。

这里面有几个函数，我们来看一下。其中第一个是 `NumCPU`，`NumCPU` 返回本地机器的逻辑CPU个数，也就是逻辑CPU的个数，不一定是真实的物理CPU颗数。比如有些物理上真正只有两个CPU，但是逻辑上变成了四个CPU，也有可能。

还有一个是 `GOMAXPROCS`，这个是用来设置可同时执行的最大CPU数。意思是说，你可以把所有的CPU全部设置进去，也可以保留一个CPU。比如韩老师的机器有四个逻辑CPU，但是在这个程序里面我只想用三个，另外一个要保留下来给别的程序用。因为如果全部占光了，可能别的程序瞬间就跑不起来了。所以这个根据实际情况来定。

我们来看一下代码，来试一下。我们建一个新的文件夹，叫做 `cpuDemo`，做一个CPU的测试。

新建一个文件 `main.go`，代码如下：

```go
package main

import (
	"fmt"
	"runtime"
)

func main() {
	cpuNum := runtime.NumCPU()
	fmt.Println("cpuNum=", cpuNum)

	// 可以自己设置使用多少个CPU
	runtime.GOMAXPROCS(cpuNum - 1)
}
```

注意 `NumCPU` 后面的 CPU 全部是大写的。`GOMAXPROCS` 也全是大写的，看清楚了。

有些时候，默认会把所有的CPU都用上。但有些时候可能想预留一个CPU，就可以自己设置使用多少个CPU。写法很直接：`runtime.GOMAXPROCS(cpuNum - 1)`，预留一个留给系统自己用，这样就设置成功了。

我们来运行一下这段代码。在命令行切换目录到 `cpuDemo`，执行 `go run main.go`。看一下结果，显示目前确实是有四个逻辑CPU。

关于Golang的版本还有一点要说明：在Go 1.8以后，默认让程序运行在多核上，通常不用专门去设置 `GOMAXPROCS`，因为1.8以后会自动使用多核。Go语言本身就默认支持多核并发，所以不需要额外设置。但是在Go 1.8以前，是需要手动设置一下的，这样可以更高效地利用CPU。我们当前使用的版本是1.9，所以通常可以不用去设置。

关于怎么去使用和设置CPU就先介绍到这里。
