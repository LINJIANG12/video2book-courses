## switch 分支控制

### 基本介绍

switch 语句用于基于不同条件执行不同动作。每一个 case 分支都是唯一的，从上到下逐一测试，直到匹配为止。在 Go 语言中，匹配项后面不需要加 break。

### 基本语法

它的基本语法是：

```go
switch 表达式 {
case 表达式1, 表达式2, ...:
    语句块1
case 表达式3, 表达式4, ...:
    语句块2
// 这里可以有多个 case
default:
    语句块
}
```

一提到表达式，就意味着这个地方只要是返回一个值就可以了。在 Go 语言里面，任何有值的都可以称之为表达式。`case` 的意思就是当表达式等于表达式 1 或者等于表达式 2 时——这也是一个变化，传统的 switch-case 结构中，case 后面只能有一个表达式，但是在 Go 语言里面它是可以匹配多个的，用逗号隔开。只要这个表达式的值匹配到表达式 1 或者匹配到表达式 2，它就执行对应的语句块。执行完毕后，后面没有 break 语句，直接退出 switch。Go 语言之所以没有 break，是因为它认为大多数情况下都需要 break，所以默认就加上了。如果表达式的值不匹配表达式 1，也不匹配表达式 2，就看匹不匹配表达式 3 或者表达式 4。如果成立就执行对应语句块，以此类推。如果一个都没有匹配到，就执行 default 里面的语句块。这就是它的基本语法。

### switch 流程图

看流程图有个好处，就是一目了然。

代码从这里开始执行，会计算一个表达式。如果这个表达式计算出来之后，先跟第一个 case 比较（可以有表达式 1，也可以用逗号隔开有表达式 2、表达式 3 等等）。如果这个表达式匹配到这里面的值了，就为真；如果匹配上就为真，为真就执行语句块 1。执行完毕后，直接结束 switch 语句，然后继续执行其他代码。结束 switch 语句之后，如果下面有代码还要继续执行，是退出 switch 这个控制结构，而不是退出程序。

如果为假，也就是表达式不匹配这里的值，就去看第二个 case。又跟这里的表达式进行匹配，如果匹配成功，执行语句块 2，然后退出。如果又没有匹配成功，以此类推，向下继续匹配。如果都没有匹配到，直接执行 default 语句块。default 是最后的一个选择，执行完毕后同样结束 switch 语句然后退出。

我们对上图做说明和总结：

1. switch 执行的流程是：先执行表达式，计算其值，得到值之后和后面 case 表达式的值进行比较。如果相等就匹配到了，然后执行对应的 case 语句块，执行完毕后退出（结束）switch 控制结构。
2. 如果 switch 的表达式的值没有和任何 case 的表达式匹配成功，则执行 default 语句块，执行后退出 switch 控制流程。
3. Go 语言的 case 后的表达式可以有多个，使用逗号间隔。
4. Go 语言中的 case 语句块不需要写 break，因为默认就会有。即在默认情况下，当程序执行完一个 case 语句块后，就直接退出该 switch 控制结构。
