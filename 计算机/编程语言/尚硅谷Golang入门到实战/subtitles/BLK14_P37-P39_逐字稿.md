现在我们再来看一下Go语言的浮点类型。浮点类型就是我们所说的小数类型。我们来具体看看小数类型它的使用情况是什么样子的。

小数类型也叫浮点型。

小数类型就是用于存放小数的，比如像1.2、0.23，或者是负的1.911等等，都可以放在小数类型里面去。

基本介绍说完后，我们来做一个案例演示。比如我想存放一个人的工资或者存放一个小数，看一下怎么去使用它。

老规矩，我们复制一份已有的项目，把文件夹的名字改一下，改成 `08floatdemo`。把 `main.go` 里面的内容先清理一下，把框架留下来。

演示小数类型的使用：比如我们要存放一个价格，商品的价格 price：

```go
var price float32 = 89.12
fmt.Println("price=", price)
```

这就是小数类型的基本使用。我们把它打印出来，运行一下。进入到目录中 `go run main.go` 执行，可以看到 `price=89.12`，这就是浮点型的一个基本使用。

下面给大家说一下Go语言中小数类型的分类。

在Go语言中小数类型分类有这么两类：一个叫单精度，一个叫双精度。单精度类似于其他语言里面的 float，双精度类似于其他编程语言里面的 double。但是在Go中它不叫 double，它是根据后面这个数字来进行区分的：32位就是单精度，64位就是双精度。32位占用的存储空间是4个字节，64位占用的存储空间是8个字节。

这两个占用的空间不一样，最主要的区别是在于它们表示的数的范围和表示的精度不一样。单精度和双精度主要区别是在于表示的范围不一样和精度不一样。单精度的表示范围较小，而双精度的表示范围大了很多。

针对这个分类，我们做几点说明：

第一点，我们要明白浮点数在机器中存放的形式。这里做一个简单的介绍，大家做个了解即可，不需要深入去研究。浮点数在机器中存放的形式是：符号位加指数位加尾数位。这就意味着浮点数都是有符号位的，也就是说浮点数都是有符号的。

我举个例子，比如我们写两个负数：

```go
var num1 float32 = -0.000089
var num2 float64 = -780966509.09
fmt.Println("num1=", num1, "num2=", num2)
```

运行一下看一下效果。在输出的时候它会使用科学计数法来显示，相当于 $7.80966509 \times 10^8$ 这种形式，说明它是带有符号位的。

第二个细节，尾数部分可能丢失，造成精度损失。浮点数为什么能表示这么大的一个范围？其实它只是把指数位和尾数位记下来，记录的是一个大概的值。如果一个数很大，它其实记录了前面一部分，尾数位可能就会造成精度损失。存一个数字进去后，输出出来的情况可能跟想象的不一样。大家在脑海中要始终有一根弦：使用浮点数时可能会有精度损失。

我们来演示一个精度可能损失的案例：

```go
var num3 float32 = -123.0000901
var num4 float64 = -123.0000901
fmt.Println("num3=", num3, "num4=", num4)
```

执行一下看效果。大家可以看到，运行完了之后，前面 `float32` 这个数的精度好像被损失了，它记录下来是 `-123.00009`，把后面的 `01` 给拿掉了；而 `64` 位的这个却原封不动地保存了我们的数值。

通过这个案例应该得出两个结论：
1. 浮点数有可能会造成精度损失。
2. `float64` 的精度比 `float32` 要准确。

因此，如果我们将来要表示一个精度更准确的数，应该选用 `float64`。

第三个需要大家知道的是：浮点型存储分三个部分——符号位、指数位、尾数位，在存储过程中精度可能会损失。刚才的案例已经充分说明了这个特点。
