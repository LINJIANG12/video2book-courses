同学们，我们再来看一下 Golang 里面的布尔类型，bool 类型。

布尔类型其实在各个编程语言里面都有。它是干什么的呢？它就是用来表示真或者是假的一个变量。在 Go 里面布尔类型汉字叫布尔，其实翻过来 bool 也是一样的。布尔类型在 Go 语言里面只允许取两个值，一个是 true，一个是 false，其它的值都不能取。比如像别的语言也有可能取一个正数、取一个负数，像有些编程语言里面还可以取空，对不对？在我们的 Golang 里面，布尔类型只能是 true 或者 false，这一点大家一定要注意，别的值给它了它会报错。

第二个，布尔类型它是占用一个字节，也就是说它在内存空间里面占用一个字节。布尔类型主要是用在逻辑运算，比如用在流程控制里面的判断真或者是假。在后面我们讲流程控制的时候，有个 if 或者是 for 循环控制的时候，会用到布尔类型。

下面给同学们来介绍一下 Golang 基本数据类型的转换。

Golang 的基本数据类型转换跟其他编程语言真有些区别，大家注意一下区别在什么地方。首先看下，Golang 和 Java、C 不同，Go 在不同类型的变量之间赋值时需要显式转换。它需要显式转换，言外之意就是说 Golang 中数据类型不能够自动转换。也就是说，比如我们把一个低精度的给一个高精度也不可以，当然反过来就更不行了。因为一般的编程语言，比如像 Java，把一个低精度的数交给一个高精度，它是自动转换的；把一个高精度交给一个低精度，是强制转换。但是 Golang 中，它的数据类型不管是低精度到高精度，还是高精度到低精度，都要显式转换，也就是所谓的强制转换。所谓显式转换就是要强制转换，这是 Golang 基本数据类型转换时一个非常重要的特色，必须显式转换，而不能自动转换。

我们先写一下：基本数据类型的相互转换。

首先做了一个基本介绍，刚才说了这样几句话：强调的就是说需要显式转换，而且它不能够自动转换，这是它的一个特点。不管你是低精度到高精度，还是高精度到低精度，都需要显式转换。

第二个看它的基本语法。转换的基本语法是这样子的：表达式 `T(v)`。T 就是数据类型，就是你要转成什么数据类型；v 就是那个变量。T 就是数据类型，比如 `int32`、`int64`、`float32` 等等，这个 T 就是你想把它转成什么数据类型；v 就是你的具体变量，你要把谁转成什么类型，就是那个变量。

下面就来几个案例入门，来一个案例演示。

打开 VS Code，新建一个包叫 `transtype`，写一个文件叫 `main.go`。演示 Golang 中基本数据类型的转换：

```go
package main
import (
	"fmt"
)

func main() {
	var i int32 = 100
	// 希望将 i 转成 float 类型
	var n1 float32 = float32(i)
	var n2 int8 = int8(i)
	var n3 int64 = int64(i)

	fmt.Printf("i=%v n1=%v\n", i, n1)
	fmt.Printf("n2=%v\n", n2)
	fmt.Printf("n3=%v\n", n3)
}
```

这里有一个数据类型 `i`，`int32` 的值，给它一个 100。现在要把 `i` 转成一个 `float`，比如希望将 `i` 转成一个 `float32` 类型。如果直接写 `var n1 float32 = i`，这个时候是转换不过去的，它会报错：`cannot use i (type int32) as type float32 in assignment`。也就是不能分配给，assignment 是分配或者赋值的意思，不能把一个 `int32` 类型交给一个 `float32`。那怎么办呢？转一下就行，类型写在前面，把它包起来：`float32(i)`，这样就可以了。输出的值一个是 100，这里也是 100，都转成 100 了。但是 `n1` 的类型是 float 类型，把 `i` 转成了一个 `float32` 交给了 `n1`。

同样，如果把 `i` 转成一个低精度的，比如 `var n2 int8 = i`，这个也不行。`i` 是个 `int32`，直接交给它也是错的，一样的道理，也要转，写成 `int8(i)` 就行。这就是说把 `i` 转成了 `int8` 交给了 `n2`。

这种基本用法就是这么简单，前面写上 type，后面写上你要转换的那个变量即可。你想把 `i` 转成什么类型，前面就写什么类型，也就是这两个是要一致的。

再举一个例子。有些同学说把 `int32` 交给 `int64` 是不是就不用转了？同样要转。比如有一个 64 位的 `int64`，把 `i` 交给 `int64`，在很多编程语言里面是可以的，因为可以理解成是低精度到高精度。很多语言是可以这样理解的。但是这个在 Go 里面也不好使，不管你是向高精度还是低精度，都要显式转换。如果直接写，仍然报错：`cannot use i (type int32) as type int64 in assignment`，也是不允许的。你仍然要转换，把 `int64` 拷过来，写成 `int64(i)`，这样就可以了。

这就是 Golang 基本数据类型转换的一个基本案例演示。
