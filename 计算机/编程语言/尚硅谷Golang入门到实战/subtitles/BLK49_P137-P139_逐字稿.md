我们接着来看一下 Golang 时间和日期相关函数的后续内容。

在编程时，我们经常会用到时间相关的常量。例如最通常的情况下，可能会让程序休眠。在休眠时会用到一个函数叫 `Sleep`。使用 `Sleep` 休眠时需要指定休眠多长时间，这里就会用到时间常量。

这个时间常量是 `time` 这个类型里面的常量。常见的常量有：小时（`Hour`）、分钟（`Minute`）、秒（`Second`）、毫秒（`Millisecond`）、微秒（`Microsecond`）以及纳秒（`Nanosecond`）。

它们之间的单位关系是：1 小时等于 60 分钟，1 分钟等于 60 秒，1 秒等于 1000 毫秒，1 毫秒等于 1000 微秒，1 微秒等于 1000 纳秒。因此纳秒是最小的。

这些常量在手册中的定义可以在 `time` 包中查看。在 `time` 包里有一个 `Duration` 类型，表示两个时间点经过的时间。在这个类型下就定义了刚才看到的这几个常量值。

了解了这几个常量值之后，它们的作用是在程序中可以获取指定时间单位的时间。例如想获取 100 毫秒，就可以用 `100 * time.Millisecond` 来获取。

如果有人问能不能用 1 秒除以 10 得到 100 毫秒？这是不行的。因为 1 除以 10 会变成浮点小数，浮点数是无法直接作为整型参数传递的。这就是为什么 Golang 的设计者要设置这么多时间常量的根本原因。在需要休眠一段时间等场景中，这些常量非常实用。

常量的作用是在程序中可以获取到指定时间的时间单位，比如 100 毫秒。我们结合 `Sleep` 来演示一下时间常量的使用。

需求如下：每隔 1 秒钟打印一个数字，打印到 100 时就退出。可以通过 `for` 循环来实现：

```go
var i int = 0
for {
    i++
    fmt.Println(i)
    // 休眠
    time.Sleep(time.Second)
    if i == 100 {
        break
    }
}
```

运行程序可以看到，每隔 1 秒就会输出一个数字。

如果需求发生变化，要求每隔 0.1 秒（即 100 毫秒）打印一个数字，打印到 100 时退出。如果直接写 `time.Sleep(time.Second * 0.1)`，编译器会报错，提示浮点数不能传给整型参数。此时就可以使用毫秒常量：0.1 秒等于 100 毫秒，因此写作 `100 * time.Millisecond`：

```go
time.Sleep(100 * time.Millisecond)
```

这样就解决了问题。通过设置不同的时间常量，可以精准指定所需的时间间隔。

在时间和日期中，还有两个相当重要的方法：一个是 Unix 时间戳，另一个是 Unix 纳秒时间戳。

在编程时，如果想获取一些随机的数字，比如后续要用到数学函数 `rand`，如果不设置随机种子，每次获取的随机数都是相同的。这时就可以用 Unix 时间戳作为种子。Unix 时间戳获取的是从 1970 年 1 月 1 日 0 时 0 分到现在的秒数；而 Unix 纳秒时间戳获取的是从 1970 年 1 月 1 日 0 时 0 分到现在的纳秒数，变化频率更快、更加随机。

在手册中查看 `time.Time` 类型的方法，可以看到：
- `Unix() int64`：返回从 1970 年 1 月 1 日 UTC 到当前时间的秒数。
- `UnixNano() int64`：返回从 1970 年 1 月 1 日 UTC 到当前时间的纳秒数。

这两个方法只能在 `time.Time` 类型的变量上调用。使用示例：

```go
now := time.Now()
fmt.Printf("unix时间戳=%v unix纳秒时间戳=%v\n", now.Unix(), now.UnixNano())
```

通过当前时间对象调用 `Unix()` 即可获取秒级时间戳，调用 `UnixNano()` 即可获取纳秒级时间戳。
