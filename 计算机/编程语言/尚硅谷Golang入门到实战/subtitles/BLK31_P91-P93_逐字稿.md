首先我们来看第一个，循环条件是返回一个布尔值的表达式。什么意思呢？就是说这个循环条件，它一定是一个返回布尔值的表达式，不能是返回别的东西。比如返回一个整数或者返回一个小数，那就不对了。它是一个循环条件，因此它返回的一定是一个布尔值。不管你的循环条件有多么的复杂，我只要求你的循环条件一定是一个真或者是一个假，这一点请同学们一定要重视，否则你的代码编译不过去。这是第一点需要注意的。

第一点，首先我们要保证循环条件它返回的是一个布尔值，这点是必须的。因为你是一个真和假的判断，你不能给我返回一个整数或者小数，那不可能，所以一定是返回一个布尔值，这点大家一定要重视。当然你这个循环条件可能比较复杂，可能是一个综合的，比如说 $a$ 大于多少并且小于多少，这是可以的。但不管你多复杂，循环条件最终会返回一个布尔值。

第二点，for 循环的第二种使用方式有些人也喜欢用，他就直接在这儿写个循环条件，然后把循环的执行语句写到这里面去，把循环变量初始化和变量迭代写在其他位置。

紧接着我们看 for 循环使用注意的第三个地方。for 循环除了上面的第二种写法，还有第三种写法，就是什么都不写。for 后面没有任何的内容，就是一个空的，里面把循环执行语句写到这。其实这种写法等价于这种写法，而且大家看出来没有，这种写法一定是一个死循环，因为这个地方它没有判断条件，所以说这个地方一定是个死循环。

有些同学会问这种写法有什么用处呢？这种写法就是一种语法现象，别看到别人这么写就说人家语法错了。因为有很多的编程语言里面是不允许这样写的，比如 Java 里面你这样写一定是错的，但是 Golang 里面它这样写是对的。它这边就相当于是写了个死循环。

这种写法通常需要配合 break 语句来使用。当满足某个条件的时候，我就退出这个 for 循环。因为 break 语句大家还没有用，那我们先相当于是硬生生地给大家写了个死循环在这里。

这种写法等价于 `for ;;`，而且它是一个无限循环。什么叫无限循环？就是永远退不出来。这时通常需要配合一个 break 语句使用。

比方说我们来演示 for 循环的第三种写法：

```go
var k int = 1
for {
    if k <= 10 {
        fmt.Println("ok~~", k)
    } else {
        break
    }
    k++
}
```

如果你敢直接这么写：

```go
for {
    fmt.Println("ok~~")
}
```

这就是一个死循环，这种死循环就成立了。它就会不停地输出 `ok~~`。

这个时候你怎么终止它？其实非常简单，一是叉掉这一个窗口；第二种也不用那么麻烦，直接按 Ctrl+C 就退出来了。

写死循环往往会配合 break 使用。break 是什么意思呢？break 就是终止的意思。我想用这种方式来输出十句，可能这样写：当什么什么条件满足时就跳出这个 for 循环。

这里的 break 就是退出或者叫跳出整个 for 循环。如果没有 break 就继续往下走：如果这个条件满足他就输出，输出完了过后就 `k++`，完了过后又去判断，如果 $k$ 还小于等于 10 继续输出，直到什么时候 $k$ 不小于等于 10 的时候，它就 break 了。

你看这种写法也是可以的，我们再来给大家演示一下，跑起来，输出 `ok~~ 1` 到 `ok~~ 10`。这种写法完全等价于：

```go
for ;; {

        fmt.Println("ok~~", k)
    } else {
        break
    }
    k++
}
```
