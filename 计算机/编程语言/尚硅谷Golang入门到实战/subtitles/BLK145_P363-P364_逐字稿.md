紧接着我们来做一件事情。什么呢？大家看这里，人家说了要从 `startNumber` 开始走，那也就是说此时此刻我们这两个指针要同步地往下移动。我移动到什么位置呢？移动到你指定的 `startNumber` 这个地方去。那我们应该移动几次呢？显然我应该移动 `startNumber - 1` 次。

为什么要减一次呢？因为你本身已经在第一个位置了嘛。比如说我要从第二号开始走，其实我只要移动一次就行了，因为你本身已经在一号了。所以说我们现在要开始移动到 `startNumber`。注意听这句话怎么写，思路要很清晰：先移动到，让，让


让 first 移动，移动到哪里去呢？移动到 startNo。当然有同学说，老师你这个时候为什么不去设置一个辅助节点呢？我可以不要了，因为反正我要把它全部干掉。你要设一个辅助节点，让 first 节点不动也没有意义，因为将来 first 也会被干掉的。first 最后也会被干掉，你让它不动也没有用，可能第一个干掉的就是它。所以 first 节点这个时候再设置一个辅助节点没有用了，因为 helper 已经是辅助节点了。所以我们删除的时候就以 first 为准。注意听这句话，后面我们删除时，删除小孩，就以 first 为准。走完了过后 first 指向谁就删掉谁，就以它为准。

现在代码就很简单了。走几步？

```java
for (int i = 1; i <= startNo - 1; i++) {
    // ...
}
```

我就移动这么多次，移动 $\text{startNo} - 1$ 次。如果有同学这样写的话，如果这写的是 0，那你再把等号去掉也是一样的，无所谓，看你是怎么理解的。我觉得写成从 1 开始、小于等于它减 1，可能大家看起来轻松一点，也可以。

然后 `i++`，开始移动。注意，移动的时候是 first 和 helper 都要移动，那就是：

```java
first = first.getNext();

```

它们一起移动。当这句话走完了以后，你们可以想象，比如说数两下，它自己数一次，所以它就相当于移动到 2 了。移动到 2 之后，helper 就移动到 1 了。

现在移动到这个位置了，紧接着开始数 $m$ 下。数 $m$ 下其实也是移动的意思，紧接着再移动 $m$ 次。第五步，继续移动，开始数 countNum 下，然后就删除 first 指向的那个小孩。

这一定是个循环。因为无论数多少下，最后只留一个人，所以它一定是个循环，while 循环来了。大家看能不能跟上思路。怎么是个循环呢？因为你不是删一个小孩就走，你要删到剩最后一个小孩，所以肯定是用循环干掉的。

开始数 countNum 下，其实也是移动 $\text{countNum} - 1$ 次，因为它自己要数一下，所以不能移动 countNum 下，而是移动 $\text{countNum} - 1$ 下。这段代码和刚才很像：

```java
for (int i = 1; i <= countNum - 1; i++) {
    first = first.getNext();
    helper = helper.getNext();
}
```

这个地方是一个考大家的重点，稍微好一点的公司可能会问这些东西。循环移动完之后，现在可以干掉它了。也就是说这个时候代码已经走到这儿了，它数两下，一、二，这两个指针分别移动到位。现在相当于 3 号要被干掉，怎么删掉它？非常简单，删除 first 指向的小孩节点。

首先让 first 往前走一步：

```java
first = first.getNext();
```

走一步过后，紧接着让：

```java
helper.setNext(first);
```

这句话怎么理解呢？相当于 first 原来在这里，它先往前移动一下，紧接着让 helper 的 next 指针指向 first，其实 3 号节点就被干掉了。

干掉的时候，你应该把它的信息输出一下，说明谁出圈了：

```java
System.out.printf("小孩%d出圈\n", first.getNo());
```

其实就是 first 那个节点的 no。

那问题来了，这个地方如果没有退出条件，它会死循环，不会停止。什么时候代表整个处理完了，只留下最后那个小孩，咱们就不要再删了？大家想一想，根据刚才这个逻辑一直走，只有一个条件，最后只剩下一个小孩了。只剩下一个小孩会形成什么情况呢？就是你的 first 和 helper 相等了。大家要有想象能力，剩两个的时候再删一个，first 再一移动不就又指向 helper 了吗？所以什么时候退出呢？就是只留一个小孩的时候，我们可以加一个判断：

```java
if (helper == first) {
    break;
}
```

说明圈子中只有一个小孩了。如果把这个小孩也删掉就相当于整条链表置空了，我们这里加一个判断，如果 `helper == first`，那么这个时候就 break。

break 之后，留下的最后一个小孩把它也输出出来。最后留在圈里的小孩是谁打印出来，把最后这个 first 的编号打印出来就可以了。
