先来看一下什么叫做标识符。标识符，标识就是标示一个变量，或者是一个函数，或者是一个包什么的，都叫标识；符就是符号，对不对？所以说我这总结两句话：Golang 中对各种变量、方法或者函数等命名时使用的字符序列，我们称之为标识符。说白了，使用的字符序列就是一个字符串。凡是可以自己取名的地方，我们都可以叫标识符。比如说最简单的例子，我们定义一个变量：

```go

```

这个 `num` 就是一个标识符。你再比如说，我定义一个人的名字：


哪几点呢？第一个：标识符是由26个英文字母的大小写（英文字母可以是大写的，也可以是小写的）、0到9的数字，还可以包含下划线组成，只能包含这么一些字符。大家要有一个基本认识，它是由英文字母、数字或者下划线组成的，这是第一个。

第二个，数字不能开头。比如说，你定义了一个变量 `var num int`，这个是 OK 的，是对的，是可以的。但是如果你在这个 `num` 前面写了一个数字，比如这样写了一个：

```go

```

这个就是错误的，因为违反了不能以数字打头的规定。

第三个，Golang 中严格区分大小写。区分大小写的意思是什么呢？我写个例子。比如说我这里有这么两个变量：

```go
var num int = 10
var Num int = 20
```

在 Golang 中，认为 `num` 和大写的 `Num` 是两个不同的变量。也就是虽然都是这几个字母，但是一个首字母小写，一个大写，它就认为这两个是不同的变量，不认为是重名的。

我们通过代码来演示一下。我们新建一个文件 `main.go`：

```go
package main
import "fmt"

func main() {
    var num int = 10
    var Num int = 20
    fmt.Printf("num=%v Num=%v\n", num, Num)
}
```

这时首先我们可以看到编译是没有报错的，这说明它认为这两个变量是不同的。而且输出的值，第一个输出的是10，第二个输出的是20。运行 `go run main.go`，我们可以看到这边分别输出了10和20。所以在这个地方大家要有认识，它们是两个不同的变量。

我们再来看下一个需要掌握的规则：标识符中不能含空格。怎么个意思呢？就是说你不能这么干：

```go

```

你不能说有一个变量叫 `a b c` 中间带空格，这是错的。这样你一保存，马上报错，它会提示语法错误，syntax error。标识符中不能含有空格，因此这样写是错的。

第五点，下划线 `_` 本身在 Go 中是一个特殊的字符，称为空标识符，用于占位。它可以代表任何其他的标识符，但是它对应的值会被忽略，比如忽略某个返回值。大家还记不记得我们在讲基本数据类型转换的时候，曾经用过下划线？这个下划线代表忽略、占位。但是它本身不能直接当做一个普通的标识符来使用。如果你直接这样写：


我们先来给大家做一个运算符的基本介绍。运算符是一种特殊的符号，用以表示数据的运算、赋值或者是比较。

在我们的 Go 语言里面，它的运算符主要分成六大类：

第一大类，算术运算符。说白了就是加、减、乘、除、取模等等。

赋值运算符就是把运算的结果赋给另外一个变量操作。比如我们见到的 `=`、`+=`、`-=` 或者 `*=` 等等，后面再具体说。

比较运算符，一般就是判断两个数相不相等，或者是两个数是不是不相等，或者大于、大于等于、小于、小于等于，这样的一些比较运算，也叫关系运算。有些人喜欢把比较运算叫做关系运算，也可以。

逻辑运算符，重点就是三个：或、与、非，即逻辑与、逻辑或、逻辑非。

还有就是位运算。比如后面我们学的位与、位或、位异或、位左移、位右移，就是所说的位运算。但是位运算往往跟二进制相关，因此位运算我们会放在最后讲，讲完二进制之后再回头讲位运算。

还有其他运算符。在 Go 语言里面有两个特殊的运算符，一个是取址运算符，一个是取值运算符，这是跟指针相关的。

同学们可能会问：老师，怎么没有三元运算符？很多同学如果有编程经验，学过编程语言的话，都知道有一个运算符叫三元运算符。告诉大家，在 Go 语言里面没有三元运算符，它的三元运算符被拿掉了。如果要使用三元运算符的效果，它使用的是 `if...else` 这种语句来实现的。所以在 Go 语言里面是没有三元运算符的。
