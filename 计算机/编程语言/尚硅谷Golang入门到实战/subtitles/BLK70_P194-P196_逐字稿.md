我们再看第四点，同学们注意听。方法的访问控制的规则和函数是一样的，即方法名首字母小写只能在本包访问；方法名的首字母大写，那么就可以在本包或者其他包访问。这块我就不再多说了，因为以前我们讲过案例。你要记住，如果 print 是小写的，那么 print 方法其实只能在这个 main 包里面用，别的地方用不了。如果你把它改成大写的 Print，那么这个方法就相当于变成一个公开的方法，在其他包也可以去调用这个类型的 Print 方法。

我们再看第五个细节。如果一个类型实现了 String 这个方法，那么在 `fmt.Println` 输出的时候，就会默认调用这个变量的 String 方法进行输出。也就是说如果你去实现了这个方法，当调用输出的时候，它会直接调用 String 这个方法。这个也很有用，比如我们在输出日志的时候，或者输出一个结构体的信息，就可以用这种方式来解决，很轻松。以后就不用每次都写那么长的一段代码，直接把它封装到 String 方法里面就可以。

我给大家做个案例。我们来写一下：比如现在有一个结构体叫 Student。学生里面有名字：`Name string`；学生还有年龄：`Age int`。

```go

    str := fmt.Sprintf("Name=[%v] Age=[%v]", stu.Name, stu.Age)
    return str
}
```

我传一个 stu 变量进来和 Student 绑定，最好直接用指针绑定。用指针是因为待会儿就不用每次都传一个副本过来，不划算，所以直接实现它的指针类型就完了。方法名叫 String，返回一个 string。在里面我们可以把它的信息取出来，比如 `Name=[%v]`。如果同学们学过 Java 的话，其实就知道 Java 里面也有一个方法叫 toString，和这个很相似。再加上 `Age=[%v]`，输出 Student 里面的 Name 和 Age，注意把 str 返回去。

这个时候当我们在输出 Student 变量的时候，它就会默认调用这个方法。怎么证明呢？先定义一个 Student 变量：

```go

```

因为人家是指针，所以你传个地址。如果你不传地址直接传 stu，就相当于把这个结构体的字段和名字按默认方式输出出来，它肯定不会去调 String 这个方法。这时它就是按照原先的方式把结构体输出来。你要让它调用 String 方法，因为这儿是指针，再传一个地址符 `&` 就行了。这时它就会去找到指针类型里面的 String 方法并调用它，返回一个字符串，最后输出这个字符串。
