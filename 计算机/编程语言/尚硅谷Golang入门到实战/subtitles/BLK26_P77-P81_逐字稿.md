我们来看一下分支控制。刚才我们讲了顺序控制，现在我们来看一下分支控制。在 Golang 里面，分支控制用得最多的叫 `if-else`。

分支控制的基本介绍：让程序有选择地执行。分支控制在 Golang 里面有三种形式：第一种，我们称之为单分支；第二种，我们称之为双分支；第三种，我们叫多分支。

分支控制就是让程序有选择地执行。有下面三种形式：
1. 单分支
2. 双分支
3. 多分支

我们先来看第一种，单分支控制。所谓的单分支，它的基本语法是这个样子的：
```go
if 条件表达式 {
    执行代码块
}
```
这里面写上我们的条件表达式。什么叫条件表达式？就是它会返回一个真或者假的一个表达式。任何有值的我们都叫表达式，而条件表达式返回的是一个真或者是一个假。

当条件表达式为真时，就会执行代码块里面的内容。这是第一个要注意的。

第二个注意：这一对花括号，或者叫大括号，必须有。就算你只写一行代码，这个大括号也要有。有很多语言规定如果只有一行执行语句，可以不带大括号，但是我们的 Golang 语句要求必须带上这一对大括号，即使你只有一条执行语句。

基本语法就是这些，注意事项也是这些。我们来做一个案例，给大家实际地应用一下。

请大家编写一个程序，可以输入人的年龄。如果该同志的年龄大于 18，则输出“你的年龄大于18岁，要对自己的行为负责”。

这里面大家看到有一个词叫“如果”。如果就是假设的意思，这里面其实就有 `if` 的含义在里边了。作为程序员，你就是要把这段逻辑用程序实现。别人把需求告诉你了，你要干的事情就是经过你的处理把它变成代码，这就是我们编程要做的一个核心的事。

我们来分析一下。首先看到年龄，作为程序员应该马上反应过来，这个地方应该有一个变量来表示年龄，比如：

原先是一段纯的汉字，经过我们分析已经靠近我们的代码了。分析完了之后，代​​码实现。为了好管理，我们新建一个文件夹叫 `chapter05`，这是我们的第 05 章。现在我们新建一个文件夹，姑且把它叫做 `ifdemo`。在这个地方新建一个文件，姑且叫 `main.go`。为了节省一点时间，我们还是从这边拿一个程序的架构拿过来用一用，放到我们的 `chapter05` 里面去。

我们先看这段代码，来分析一下：
```go
package main

import (
    "fmt"
)

func main() {
    // 分析思路
    // 1. 接收一个人的年龄，定义一个变量
    var age int
    // 2. 从控制台接收一个输入
    fmt.Println("请输入年龄:")
    fmt.Scanln(&age)
    // 3. 判断
    if age > 18 {
        fmt.Println("你的年龄大于18岁，要对自己的行为负责")
    }
}
```

注意，在 Golang 里面，这个地方是不用写括号的，不要多此一举。直接把条件表达式往这一放就可以了。如果大于 18 就提示这句话；如果小于，它没有做别的要求，所以我们的代码就算完成了。

我们来运行一下。进入到我们编译运行 Golang 的位置，在 `ifdemo` 里面。输入：
