下面我们接着看第十个。第十个也是用得非常多的。如果我们进行字符串的比较，有两种方式：第一种就是两个等号，两个等号是可以来判断两个字符串是否相等的，但是两个等号在判断的时候是区分字母大小写的。也就是说，等号要求内容和字母大小写都要相同才是为真。但是有时候我们在比较的时候不想区分字母的大小写，这时请使用 strings 包里面的 EqualFold 函数。这个函数是不区分大小写的。也就是说，这里有个 "abc"，有个大写的 "ABC"，它会返回真；但是如果用两个等号去判断，它就返回假。一个区分大小写，一个不区分大小写，EqualFold 是不区分大小写的。

来看案例：

```go
// 不区分大小写的字符串比较(==是区分字母大小写的)
b := strings.EqualFold("abc", "Abc")
fmt.Printf("b=%v\n", b) // true

fmt.Println("结果", "abc" == "Abc") // false
```

我们可以看到 b 返回 true。因为 EqualFold 不区分大小写，看效果，b 返回 true。但是如果这样写：`"abc" == "Abc"`，这个输出结果是真还是假？它为假。因为两个等号是区分字母大小写的，所以它会返回一个 false，除非完全相同。跑起来，确实是 false。这个时候用等号来判断，它认为这两个是不等的，因为它是区分大小写的。一个首字母是小写的 a，一个是大写的 A，自然就不相同了。

这也提醒大家，如果将来做密码校验的时候，你要不要区分大小写？如果要区分大小写，就用等号；如果不区分大小写，用 EqualFold 就可以。
