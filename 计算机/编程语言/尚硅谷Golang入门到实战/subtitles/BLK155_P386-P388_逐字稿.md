下边我们接着来讲二叉树。二叉树这里面我们重点给大家讲一下前序遍历，还有中序遍历和后序遍历的概念，我们做一个介绍。

什么叫二叉树呢？二叉树是这样子的一个概念：一个节点，我们前面讲的一个节点只有指向下一个节点。但是有些情况下，我们这一个节点可能会有两个指针，甚至有些地方是有三个都有可能。如果说我们每一个节点都有一个左指针和一个右指针，它的下一个节点又有一个左指针和右指针，那么这个我们就把它称作为二叉树。

我们来看它的一个关系，比如说这个就是第一层、第二层、第三层、第四层，它们的关系可以这样理解：最上面这个 A，我们把它叫做根节点。如果说我们在遍历的时候，要从根节点开始遍历。B 下面有两个节点 D 和 E，我们就可以这样写，D 的父节点是 B，它的上一个父节点是 A。你看这还有一句话：C 是 F 和 G 的父节点，是 A 的子节点。父子的关系就很明显。

如果看这一句话：A、E、F、G 没有子节点，我们就称为叶节点。假设是没有的，称为叶节点。

我们根据这个来构建一个简单的二叉树，我们来遍历一下，主要是看二叉树的遍历。有时候面试官会问你什么叫前序遍历，什么叫后序遍历，什么叫中序遍历，他会大概问一下它的含义是什么，我们来讲一个小案例。

现在我们使用前序、中序和后序遍历对下面的二叉树进行遍历。现在二叉树长的是这样子的：有一个 Hero 节点，它左边指向一个英雄，这个下面就没有子节点了，我构建得比较简单；它的右节点指向另外一个节点，这个节点下面它的右节点又还有一个林冲；要求分别用前序、中序还有后序对我们的这一个二叉树进行遍历，要求完成这么一个案例。一般来说这种是比较简单的，它主要考察点就是什么是前序、中序、后序。

我简单说一下什么叫前序。前序指的是先把根节点的内容输出来，再去输出左边的子树，再去输右边的子树，这个我们称之为前序。中序就是指的先把根节点的左边全部遍历出来，再显示根节点，再显示根节点右边的子树，这个叫中序。后序是什么呢？后序是先遍历它的左子树，然后再遍历它右边的子树，然后再遍历它的根节点，这个就叫后序遍历。其实就这么一点概念。

```go
	}
```
```go
}
```
