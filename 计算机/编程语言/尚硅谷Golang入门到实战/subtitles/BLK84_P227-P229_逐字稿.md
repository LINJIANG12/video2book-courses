```go
func TypeJudge(items ...interface{}) {
	for index, x := range items {
		switch x.(type) {
		case bool:
			fmt.Printf("第%v个参数是 bool类型，值是%v\n", index, x)
		case float32:
			fmt.Printf("第%v个参数是 float32类型，值是%v\n", index, x)
		case float64:
			fmt.Printf("第%v个参数是 float64类型，值是%v\n", index, x)
		case int, int32, int64:
			fmt.Printf("第%v个参数是 整数类型，值是%v\n", index, x)
		case string:
			fmt.Printf("第%v个参数是 string类型，值是%v\n", index, x)
		default:
			fmt.Printf("第%v个参数类型不确定，值是%v\n", index, x)
		}
	}
}
```

熟练开发工程师一天等多少钱？这个大致有个范围的。比如一个比较成熟的、比较有经验的工程师，一般来说每一天的薪水，我们假设按工作日，假设他是两万块钱，你折到每一天是多少钱？大概算下来一千块钱。一千块钱的话，你可能还有些什么其他开销，就多算一点，比如说算一千一。这个我整个工时量算出来是多少人、多少天。比如我这是二十个人，要二十天完成，那就是 $20 \times 20$ 再乘以这一千、一千一。这就是人工费，这是我的成本。

我有一个同学也有点意思。以前我教Java是06年带的一个学生，他是北京人，一上课的时候就天天睡觉，一睡觉他流哈喇子。他流哈喇子吧，他有时候还打呼噜，让我受不了。我就跟他说：“朋友，我们聊聊。你睡觉……”因为他们就是混的，以混为主，知道吗？把这个培训当成一个大幼儿园。我也不敢说他，因为长到一米九，你知道吗？真的很高，他以前是干保安的。我也不敢说他。他每次还说：“韩老师，你讲课讲得可好了，我就是听不懂。”这不气人吗？

说完了，我说：“我们聊聊，你到后面去睡。我有一个要求，你睡觉在后面不要让人发现，而且尽量不要发出声音好不好？”他还是比较配合我，很给老师面子。后面找工作找不着，找了一个月还找不着。有一天他打电话给我：“韩老师，我找到工作了。”我说：“你还不错啊。”我很吃惊啊。怎么找到工作呢？他说：“明天我就要出差了。而且公司给我配备了一个IBM笔记本，而且工资是八千。”那个时候八千不错。我说：“你怎么要出差呢？”他说：“我要到新疆有一个油田叫塔里木……我忘是哪个油田，是新疆一家油田。去了过后，”他说，“去了一呆呆一年，呆一年。”实在什么人去呢，你知道吗？他终于找到一份工作，我说你去成长吧。虽然他没怎么听，但是基本功还是有的。去了过后，他说后面大概干了十个月提前回来了，他找我还吃饭。“韩老师，我去了过后存了不少钱。”“为什么？你不是挺爱花钱的吗？”“实在花不出去那边。”吃饭别人管，睡觉住宿费也不用掏了。那个地方又不怎么通网，他就自己说存了一点钱。回来现在还可以，你看现在也成长起来了。

我真是发现一点，同学们，真的坚持很重要。我好多个学生我都已经完全觉得不太可能了，人家扛下来了。现在动辄项目经理，还动不动说这句话：“韩老师，我现在招了几个新来的，技术可差了。”其实他当时真的差得多，我都不想说了。

我们做实施工程师大家尽量先暂时不要去干实施工程师，等到以后想旅游全中国的时候可以去考虑。

维护阶段一般来说没有专业人员。它一般是这样子的：用户发现问题了，他把这个问题返回给一个对接的人，肯定这边会对应一个对接的人。发现问题就会对接，对接这边就进行调试、修改。所以这个项目就是这么一个流程。好，我就简单地讲到这里。
