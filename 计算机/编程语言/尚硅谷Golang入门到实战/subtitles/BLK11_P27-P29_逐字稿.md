这次我写一个叫做 `@硅谷`，追加到另外一个叫比如 `abc2.txt` 去。一回车，又产生一个文件，这个文件里面就是 `@硅谷`。这两种方式大家都注意学习一下。第一种我用的是绝对路径的方式来创建文件，然后我又用了一个相对路径的方式来创建我们的文件，两种都 OK。

有了文件过后，我们现在再来学习一下怎么用 DOS 指令来复制或者移动文件。我们先来看复制文件。

现在我有这么一个需求，我想把 `abc.txt` 文件拷贝到 `test200` 目录下面来。比如我想把这个文件拷贝到这个地方来，你看我的指令怎么写：

```bat
copy abc.txt d:\test200
```

拷贝 `abc.txt` 文件，然后到哪里去呢？写个绝对路径写清楚，我们要把它拷贝到 D 盘下面去 `test200`，回车，复制了。有这个文件了没有呢？打开看一下。找到我们的 `test200`，是不是有个文件了？而且里面应该是有 `hello` 吧，没问题，这是叫做拷贝。

拷贝的时候，你也可以指定文件名。我想拷贝到这的时候，我不想再叫 `abc.txt` 了，我想叫 `ok.txt` 行不行？也可以：

```bat
copy abc.txt d:\test200\ok.txt
```

这就相当于说是自个儿来命名了，把 `abc.txt` 文件拷贝的时候同时重新命名叫 `ok.txt` 文件，能理解吗？又来了一个，也是一样的内容。这是两种方式：第一种就是拷贝的时候使用原来的名字，拷贝时使用原文件名；第二种就是拷贝时重新指定名字。两种方式大家可以任选。

还有一种叫做移动，移动就是我们所说的剪切。在这儿拷贝完了过后原先的文件还是有的，这个 `abc.txt` 还有；但是移动就相当于说整个把它剪过去了。我给大家演示一下这个功能。

此时此刻我们 `dir`，我们现在是在 `abc100` 这个文件目录下面，比如现在我想把 `abc.txt` 剪切到 F 盘去。我想把这个 `abc.txt` 文件直接剪到 F 盘下面去，剪过去，相当于说把这个文件拿掉了，把这个文件直接扔到这边去，这叫剪切，剪切就是移动的意思。这个指令怎么玩？非常简单：

```bat
move abc.txt f:\
```

它叫 `move`，然后 `abc.txt` 这个文件，我要把它移动到 F 盘下面去。后面的这个文件名你写也可以，不写也可以，不写就保持原先的文件名；写了的话就剪切的时候同时改名。回车，移动了一个文件。

看一下，此时此刻 `dir`，我们发现 `abc.txt` 已经没有了，但是在 F 盘下面有没有呢？看一下效果。在我们的 F 盘，你会看到有了一个新的 `abc.txt` 文件，就是你刚才剪过来的，对不对？这就是给大家说的剪切的指令，这就是你要剪切的文件，这个就是剪切到哪里去。

还有一个就是删除文件。如果这个文件不想要了，你想把它删除，怎么删除呢？简单，一个指令就搞定了。比方说 `dir`，我想把 `abc2.txt` 删掉：

```bat
del abc2.txt
```

注意，这个命令可以补全，比如你看我输入 `ab`，一种方式是一个一个手敲，特别累而且还容易出错；还有一种方式是用 Tab 键全部补全，这样比较快。删掉了，再来看 `dir`，没有了。这个就是删除一个文件：`del` 文件名带上就行了。

同样这个地方老师用的就是相对路径，因为我就直接在这个目录下面删的。如果你用绝对路径也可以写得很清楚，比如我要在 D 盘去删一个 F 盘的文件，我也可以在后面把这个路径写清楚，也能把它删掉，明白吧？这是删除一个文件。

那如果删除所有文件呢？就直接改一个指令：

```bat
del *.txt
```

它也可以用星号。比如说 `del *.txt`，那就是说把所有 `.txt` 后缀的文件全部删掉。这个我就不演示了，找不到是因为我目前下面一个文件都没有，所以它提示找不到；如果有的话就会全部删掉。这个指令就是用来删除全部文件的。

不要轻易使用这个指令，这个指令一旦删掉过后真的文件就没有了。有些同学在用的时候很随意，工作很随意，他就写个星号，结果把文件全都删掉了。删掉过后很多同学说老师怎么回事我这文件都没有了。如果是重要的文件，那我告诉你你就哭去吧，项目经理没准还会让你卷铺盖卷走人，你把重要文件给删了怎么办？所以大家一定要小心慎用这个删除。
