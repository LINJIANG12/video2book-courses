这个就是我们自定义错误的一个用法。它可以把我们自定义错误信息输出，并且我们还可以终止这个程序。

这里是我们的一段核心代码：

```go
// 函数去读取一个配置文件 init.config 的信息
// 如果文件名传入不正确，我们就返回一个自定义的错误
func readConfig(name string) (err error) {
	if name == "config.ini" {
		// 读取...
		return nil
	} else {
		// 返回一个自定义错误
		return errors.New("读取文件错误..")
	}
}
```

哪里的核心自定义，老师写得很清楚，就这句话很关键。它返回的类型，返回的数据类型是一个 error 类型的。

```go
func test02() {

	if err != nil {
		// 如果读取文件发生错误，就输出这个错误，并终止程序
		panic(err)
	}
	fmt.Println("test02()继续执行...")
}
```
