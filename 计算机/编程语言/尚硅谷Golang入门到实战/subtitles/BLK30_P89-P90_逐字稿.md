所有讲 switch 分支结构的老师都会提一下 switch 和 if 的比较。因为 switch 和 if 确实是非常相似。其实甚至我可以这么讲，在 Golang 里面，switch 和 if 的区别其实已经比较小了。为什么这么讲？因为大家也看到，在前面讲细节的第七个细节，大家还有印象吗？第七个细节我在这儿讲过。你看，switch 后边它其实本身就可以当 if-else 来使用了。你看这里，它直接什么条件都不要，甚至它在里面也可以做范围的判断。因此我们说 Golang 里面的 switch 和 if 其实区别已经不大了。

但是如果我们的面试官问到 switch 和 if 的比较，同学们也可以简单地聊一下。我这样总结了两句话：如果判断的具体数值不多，而且符合是整数、浮点数、字符、字符串这几种基本数据类型，建议使用 switch，因为简洁高效。

什么意思呢？比如说我们去判断，打个比方，我们判断就像刚才说的，就只有春夏秋冬，就这么几个季节，它的范围就是有限的，就具体的几个值，不多，这个时候用 switch 还是比较高效的。比如说你写个坦克大战，坦克大战的运动方向就是上下左右，你可以用这种按键，比如向上的光标就是向上走，因为它的方向就四个嘛，所以这时用 switch 比较高效。也就是说判断是具体的数值，而且不太多的情况下，我们可以用 switch。

其他情况，如果是对一个区间的判断，和结果为布尔值类型的判断，我们建议用 if，因为 if 的使用范围还是要比 switch 要广泛一点。比如涉及到一组范围的判断，还是建议用 if，因为它更灵活、更方便，因为它就是做这个事儿的。

最后我们总结一句话，什么话呢？具体数值的判断，而且是有限几个数值，我们用 switch；如果是对于区间的判断，或者结果是一个布尔值类型的判断，我们建议用 if。说白了就是，具体的几个值用 switch，区间判断用 if，这样会比较清楚一点。

关于 switch 和 if 的比较，我们就讲到这个位置。我把这个给同学们放到笔记里面去。

switch 和 if 的一个比较。我给它来一个标题三。刚才老师总结了它们大概什么时候用 switch，什么时候用 if。总结了什么情况下使用 switch，什么情况下使用 if。其实这两句话还是比较管用的，一般的面试官只要听到你这么说，也就知道你明白了。具体的数值不多的情况下，咱们用 switch。如果说是区间的一个判断，比如成绩，打个比方，刚才判断了三四种情况，是优秀还是优良还是及格，其实用 if 这种判断更合理一点，因为它是一个区间的判断。还有就是一个布尔值，比如我判断他是一个男的还是一个女的，或者是判断我们的连接是不是已经拿到了。比如判断 if 我们有一个数据库的连接得到没有，它返回一个 bool 值，这样情况下，我们也可以考虑使用 if 语句。相对来说，if 的使用范围还是比 switch 要广泛一点。关于 switch、if 的比较我们就说到这儿。
