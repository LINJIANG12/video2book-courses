刚才讲的数组的使用都是面上的东西，没有深入到内存。现在来看一下数组的定义和数组内存布局，数组在内存里面到底长什么样子，它是怎么分布的。这点对于把数组彻底掌握非常重要。

数组定义是这样子的：`var` 关键字、数组名，这边有数组的大小和数据类型。比如说刚才用的：

```go
var a [5]int
```

a 就是一个数组的名称，5 代表数组最多存放 5 个数据，int 代表数组能够存放的数据类型是什么。

赋初值就是 `a[0]` 代表给第一个元素赋初值，`a[1]` 代表给第二个元素赋初值。前面已经讲过就不再多说，这里重点想给大家画一下数组在内存里面的布局图。

数组定义和布局，这是第二个标题。数组在内存的布局比较重要，通过一段代码来给大家画图。新建一个文件夹叫 `array_demo02`，新建一个文件 `main.go`。


来看内存布局，写一个例子。为了容易画出来，定义这么一个数组，存放 int 类型：

```go
var intArr [3]int
```

这个数组大小定稍微小一点，定太大了画图比较麻烦，定一个可以存放 3 个数据的数组。

其实这个数组定完之后，它本身也有默认的值。也就是说这地方不用赋初值，其实已经有默认值了。当定义完数组后，其实数组的各个元素已经有默认值了，默认值就是 0。可以打印给大家看一下：

```go
fmt.Println(intArr)
```

先不给它赋初值，先让大家看到定义过后会是什么样子。cd 到 `array_demo02`，执行 `go run main.go` 跑起来。可以看到这里面有 3 个元素，它们都是 0，也就是 `[0 0 0]`。

究竟这个东西在内存里面怎么布局的？把这段代码放在 Excel 表里面，画一个内存图。

当代码执行完 `var intArr [3]int` 这句话过后，在内存里面会出现这么一个东西：有个叫 `intArr` 的变量。因为它是值类型，所以在这个地方会有一个数组。里面存放 3 个数据，这块空间就分配好了，而这个空间里面每一个元素也有了，默认就是 0。`intArr` 就指向了这个位置。因为它是值类型，直接指过去关联上了。

能不能看一下 `intArr` 它的地址是什么？可以。数组名它的地址就是数组的首地址。往深了研究一下这句话：

```go
fmt.Printf("intArr 的地址=%p\n", &intArr)
```

用 `%p` 输出，取一下它的地址看是什么东西。执行一把，可以看到它的地址是这个。

`intArr` 指向了这个地址，这个地址就是数组的首地址，就在这个地方。而且还有一点，数组的首地址其实就是第一个元素的地址。

总结一下：
第一点，数组的地址可以通过数组名来获取，也就是 `&intArr` 就可以了。
第二点，数组的第一个元素的地址就是数组的首地址。

证明一下，来看第一个元素的地址，也就是 `&intArr[0]`。它的地址也输出出来：

```go
fmt.Printf("intArr[0] 的地址=%p\n", &intArr[0])
```

如果要取地址的话得加 `&` 符号；如果不加 `&` 符号就直接把值取出来了。看第一个元素的地址是不是跟数组的首地址是一样的。保存看效果，可以看到两个是完全相同的。这是数组的地址，这是第一个元素的地址，它们是同一个。

这个也可以理解，就像小朋友排队，排在第一个的同学，他既是第一个同学的地址，同时也是整个队列里面的首地址。完全是这样子的。

再思考一下，打出第二个元素的地址：

```go
fmt.Printf("intArr[1] 的地址=%p\n", &intArr[1])
```

大家猜一下是多少？其实不用猜，第二个元素的地址其实就是第一个元素的地址基础上加上这个元素占用的字节数。第二个元素的地址就是第一个元素的地址加上数组类型占用的字节数。比如说 int 是占 8 个字节，因此可以推出来这个元素一定是前面这个元素加一个 8 就行了。根据这个情况来说，下一个元素就应该是 `0xc04204a0a8`。为什么敢这么肯定？因为它是按照连续分布的，而一个元素是一个 int，一个 int 占 8 个字节，所以一定是前面元素加一个 8。

看效果，完全没问题。上面是 `a0`，这个是 `a8`，就是在基数上加了一个 8。后面依次类推，如果要找下一个地址，在这个基础上再加一个 8。

看第三个元素，地址也输出出来：

```go
fmt.Printf("intArr[2] 的地址=%p\n", &intArr[2])
```

看效果，第一个是 0 加一个 8；在 `a8` 的基础上再加一个 8 就是 `b0` 了，因为它是十六进制的。$8 + 8 = 16$，十六进制就进位，a 变 b，8 变 0，成了 `b0`。

通过这个地方还可以看到一个非常重要的特性：数组元素的地址其实是连续的，这也是 Go 语言里面的一个特点。有些高手以前做开发时讲过一个方法，想快速定位一个值，最快的方法就是在地址上加，在这个地址上加一个 8 就马上取得下一个元素的地址然后取值，速度是最快的。用地址的方式来取值速度是最快的，但是要找到它的规律。
