下面我们再来看后面的几个转义字符。

换行符 `\n`：
```go
fmt.Println("hello\nworld")
```
`\n` 代表换行，也就是输出 hello 之后，换行再输出 world。执行之后，确实是在 hello 之后换行输出 world。

再来看输出反斜杠 `\\`。比方说，在这里有一个路径：
```go
fmt.Println("D:\\GoWorks\\src\\...")
```
如果直接输出单个斜杠，编译器会报错，提示 character escape 有问题，因为它不知道单个斜杠是什么意思。如果想把斜杠输出，因为单个斜杠会被当做转义符，所以需要写两个斜杠：第一个是转义符，第二个才是真正要输出的路径分隔符。加上之后运行，输出的就是单个斜杠。第一个斜杠用来告诉编译器，后面的斜杠当做普通字符输出。

再来看双引号 `\"`。比方说我们假设要输出这样一句话，想把内容用双引号引起来：
```go
fmt.Println("tom说:\"I love you\"")
```
有时候我们希望输出的字符串里面带有双引号。如果直接写双引号，会导致语法解析错误。老规矩，使用转义符 `\"`。运行之后，就会把双引号输出出来：`tom说:"I love you"`。

最后看回车符 `\r`。`\r` 代表回车。举个例子：
```go
fmt.Println("天龙八部雪山飞狐\r张飞")
```
我们运行一下看看效果。输出的内容是：`张飞八部雪山飞狐`。

为什么不是天龙八部雪山飞狐张飞呢？原因是回车代表先输出前面的内容，回车之后不换行，而是从当前行的最前面、顶头开始输出后面的“张飞”，覆盖掉以前的内容。相当于顶头从最前面重新输出，原先有什么内容就被覆盖了。

回车表示从当前行的最前面顶头开始输出，覆盖掉以前的内容。

在输出张飞的时候，张飞就会在当前行最前面输出，替换掉以前的内容。替换掉谁呢？天龙。因为张三刚好也是两个汉字，就把你替换了，对不对？那如果说是“张飞厉害”，那会怎么样呢？张飞厉害就会替换“天龙八部”这四个，因为刚好四个字，对不对？所以说这样子就会替换成这个东西。运行一下，这也就是“张飞厉害雪山飞狐”。我就讲到这里，就是替换。
