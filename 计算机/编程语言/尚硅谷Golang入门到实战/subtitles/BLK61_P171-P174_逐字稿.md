下面我们再来介绍一种用 for-range 的方式来遍历二维数组。怎么用它来遍历呢？其实道理也是一样的，那就用这种方式。

首先，`for`，我们先把它的 $i$ 遍历出来，然后这边有一个值。注意，这个地方这个值其实就是里面的一组一维数组，大家能理解吗？

```go
for i, v := range arr3 {
    for j, v2 := range v {
        fmt.Printf("arr3[%v][%v]=%v\t", i, j, v2)
    }
    fmt.Println()
}
```

对谁进行遍历呢？对 `arr3`。那我问大家一个问题，这个时候这个 `v` 是什么？这个 `v` 是不是就是里面的一个一个的一维数组啊？你们可以打印出来看一下。比如说我在这里 `fmt.Println` 打印出来 `v`，你们可以看一下。其实每一个 `v` 目前来说都是一个一维数组。

此时此刻，我们再把这句话放进去。放进去过后，我们把它格式化一下，这样写：`arr3[%v][%v]=%v\t`。这个 $i$ 就是它的第一个中括号里面的值，$j$ 就是它第二个中括号里面的值，然后 `v2` 就是这个元素对应的值了。看清楚没有？

map 在 Go 语言里面其实就是一个数据结构。官方把它叫映射，实际上它本质就是一个集合。我们来看一下 map 的一个基本介绍。

map 是 key-value 的一个数据结构，又称为字典或者关联数组，类似于其他编程语言的集合。大家有学过其他编程语言就知道，有一种数据结构叫集合。它通过一个 key 可以找到对应的 value。这个在编程中是经常使用到的。map 其实就是 key-value 的一个数据结构，通过 key 可以找到对应的值，在实际开发中用得比较多。比如说我去保留一个学生信息，或者存储一个学生信息，key 用学生的编号，value 可以用学生的名字。这样就可以非常方便地把学生的信息管理起来。

前面也是一个关键字叫 `var`，然后是 map 的变量名称，后边这个 `map` 是一个关键字，它是固定的。中括号里面写上 key 的数据类型是什么，后面写上 value 的数据类型是什么，非常简单。

还有一点，slice、map 还有 function 是绝对不可以做 key 这种数据类型的。就是说你不可以把 slice、map 或者 function 做一个 key。为什么呢？因为官方的解释是说没法用等号来判断。言外之意就是说将来 key-value 主要是用来做判断，就是你有没有存在这个 key。大家记住两个原则：第一个就是 key 可以的数据类型其实挺多的，像 bool、数字、string、指针、channel 都可以，或者是这几个类型也可以，但是用得最多的就是 int 和 string。slice、map、function 这几种数据类型是绝对不可以做 key 的。把这个稍微有一个印象就可以了。
