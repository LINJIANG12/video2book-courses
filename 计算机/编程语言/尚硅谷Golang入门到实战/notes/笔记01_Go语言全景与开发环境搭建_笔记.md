## Go 能做什么

* **学习方向与应用领域的区别**
    * 学习方向指学完 Go 可能从事什么工作，应用领域指 Go 实际能做什么事情
    * 应用领域归纳为三块：区块链技术的应用、后台的服务应用、云计算和云服务

* **区块链研发工程师**
    * > **定义**：区块链（Block Chain，BT）是一种分布式账本技术，核心思想是去中心化
    * 区块链主流的开发语言就是 Golang
    * 技术特点：去中心化、公开透明，每一个人都可以参与数据库的记录
    * 虚拟货币与金融领域用得比较多
    * 学完 Go 再去学区块链技术，顺序是通的，区块链用的主流编程语言就是 Golang

* **服务器端开发**
    * 目前服务器端主要用 C、C++ 偏多一点
    * 只要是 C 和 C++ 能做的事情，Go 都可以做，而且做得更好
    * 典型活儿：日志处理、数据打包、文件系统
    * Go 的三个主要设计者之一 Ken Thompson 同时是 C 语言的设计者，Go 后面在某些方面把 C 的设计理念做了优化
    * 新浪、搜狐、腾讯这样的站并发下来就是几百万，Go 处理大并发非常强
    * 美团后台流量的支撑程序就是用 Go 语言写的

* **后台服务对语言的双重要求**

    | 后台环节 | 对语言的要求 | Go 的对应能力 |
    | :--- | :--- | :--- |
    | 排序、推荐、搜索 | 运算能力要强，响应速度要快 | 数据处理能力比较强 |
    | 负载均衡、缓存、容错、按条件分流 | 能扛住大并发 | 处理大并发比较强 |

* **游戏后台的数据通道**
    * 玩家点一下砍到一个人，同组队友能立刻看到这个动作，靠后台的数据通道在撑着
    * 现在很多游戏软件的后台、尤其是数据通道这块，用 Go 开发得比较多
    * 案例：《仙侠道》后台的通信与做数据通道这一块用 Go 语言

* **分布式云计算**
    * 盛大云 GrandCloud 是经典案例
    * 京东后台的消息推送服务以及分布式文件系统，后台全部都是用 Go 语言做的。

* **云计算和云服务**
    * CDN（Content Delivery Network，内容分发网络）解决的是让用户就近地、快速地获取到内容，也就是访问网站更快
    * 盛大云提供这样的服务，可以用 Go 语言来建一个 CDN 的网络服务
    * 京东每天购买量、用户量都非常庞大，消息推送和分布式文件系统都要用云计算技术

* **Go 工程师的行情**

    | 招聘岗位上的标注 | 说明 |
    | :--- | :--- |
    | 2万 - 3万 | Go 语言工程师的常见档位 |
    | 1万8 - 3万5 | 同一批岗位里反复出现的区间 |
    | 1万8 | 起步较低的一档 |
    | 面议 | 比如京东商城这类岗位，面议下来一般都不会低 |

    * 做 Java、PHP、.NET、C++ 开发的人已经非常多，而 Go 工程师在中国还比较少
    * 谁先占领这块商机，谁将来就可能成为这方面的专家
    * 等到大家都开始学 Go 的时候再来学就晚了，因为竞争会很激烈

* **Gopher 吉祥物**
    * Go 语言的吉祥物叫 Gopher，是一只金花鼠，不是土拨鼠
    * 由 Go 语言的一位设计者罗布·派克（Rob Pike）的妻子画出来并取名

## 学这门课的七条约定

* **要高效、要愉快，更要踏实**
    * 目标是讲一遍就能听个 80%、90%，后面再把作业做一做，核心编程基本能拿下
    * 争取一个月或者一个半月之内，把 Go 比较常规的语法和用法都学到位
    * 学东西不能太痛苦，天天这个听不懂那个听不懂，慢慢就不愉快，不愉快就会放弃
    * 每一天都要有目标，学完了要达到什么目标，自己心里必须规划一下

* **先整体框架，再细节**
    * 上来的时候不要把细节扣得太厉害，先把整体框架、这个东西是什么了解了，再一步步往里深入

* **培养用到什么就能快速学起来的能力**
    * 这是实际工作里真正需要的能力
    * 讲过的内容工作中 80% 以上都用得上，剩下 20% 没接触过的靠现场学习能力补
    * 讲课会带大家看手册、遇到问题教怎么调试、遇到技术难题从几个方面下手把它拿下

* **先 know-how，再 know-why**
    * 计算机编程是一门工科，实践性很强
    * 工科的特点：不一定把东西搞得很明白，但你能做出来，这跟数学、物理不一样
    * 有时候你做出来了，不一定知道为什么
    * 天天想为什么却不动手，那就永远不知道为什么

* **软件编程是做中学**
    * 不是会了再做，而是做了才会
    * 作业先自己做，不要等答案；写不出完整代码，也要写一部分思路或者伪代码把思路理一理

* **该囫囵吞枣的时候就囫囵吞枣**
    * 有些知识点理解得不是很到位时可以先往下学，比如后面讲指针会涉及到内存
    * 学到某个位置可能突然就恍然大悟了，就像练武功实战时被人家打几下才明白原来那一招怎么出

* **琢磨设计者怎么想，而不是我认为应该怎么做**
    * Go 的大括号必须写在上一行，也就是行尾风格

    ```go
    func main() {
    	fmt.Println("Hello World")
    }
    ```

    * Go 要求大括号写到上一行，是因为它默认会在每行末尾补一个分号，大括号另起一行等于把函数头和函数体切开了，所以过不了。
    * for 循环也不加小括号

    ```go
    for i := 0; i < 10; i++ {
    }
    ```

    * Go 这么设计是因为它的设计者认为一个问题最好只有一个解决方案，为了强制这门语言保持简洁，不允许你写成另一种风格
    * 重点应该放在逻辑的处理上，而不是语法的本身

## 快速掌握新技术的方法论

* **学新东西的两个由头**
    * 一是在项目开发中遇到了一个需求，需要解决某个问题，这种最多
    * 二是有别的动机，比如你想跳槽，想学个新技术

* **第一步：先问一句为什么需要它**
    * 第一个动作不是去翻文档，而是先拿现有技术试一试

    ```text
       有需求
         │
         ▼
      现有技术能解决吗？
         ├── 能，且够好 ──────────────▶ 用它，收工
         ├── 能，但不够好 ──▶ 痛点浮出水面 ──▶ 技术缺口
         │                                    │
         └────────────────────────────────────┘
                                              ▼
                                  自然引出「新技术」
    ```

    * 需求 → 传统方案能用但不好 → 技术缺口 → 新技术，这条路径是顺的。
    * 学一样新东西有障碍，往往不是因为它难，而是因为你不知道它是被造出来解决什么的。
    * 老例子：05 年、06 年门户网站一打开就是整个页面连图片一起加载，很多人只看上面一块就关了，流量、带宽、计算机资源全浪费；用传统 `iframe` 框架能解决但不够好，于是引出 Ajax 技术

* **第二步：原理和基本语法，先别抠细节**
    * 快速入门阶段要解决两个问题：把原理搞清楚，把基本语法搞清楚
    * 不要涉及到任何细节问题

* **第三步：做一个 Hello World 级的快速入门案例**
    * 要极其简单，简单到 Hello World 那个级别
    * 只让你了解这个新技术或知识点的基本使用方式，不含任何细节

* **第四步：研究技术细节**
    * 只掌握了原理、基本语法和一个简单案例，根本没办法解决项目里真正遇到的问题
    * 细节关注三件事：怎么使用更规范、有没有使用陷阱、使用时要注意什么
    * 技术细节特别考察一个程序员的能力，有经验和没经验的程序员在细节上完全不是一个水平
    * 细节是最耗时间也最值钱的地方：一个程序员用了一年这个技术可能了解了 10 个细节，用两年又多增加了 10 个

    ```text
      为什么要学 ──▶ 原理 ──▶ 基本语法 ──▶ 快速入门 ──▶ 技术细节 ──▶ 回到项目解决问题
       （很便宜）                                        （★ 最耗时、最值钱）
    ```

* **T 字型能力结构**
    * 横是体系和框架感，大面都要知道
    * 纵是技术细节，哪里需要深入就往纵向往里扎，越挖越深永无止境
    * 程序员月薪 3000 的也有 3 万的，区别就在这个 T 的两根竖线上

    ```text
      ════════════════════════════════════════════════════
           │        │        │        │        │         │     ← 横：体系 / 框架感
      ════════════════════════════════════════════════════   大面都要知道
                         │
                         │
                         │                                   ← 纵：技术细节
                         │                                      越挖越深，永无止境
                         │
                         │
    ```

## 程序与编译

* **程序**
    * > **定义**：程序 = 为了让计算机执行某些操作或解决某个问题，而编写的一系列有序指令的集合

    ```text
      人跟人：   [老板] ──口述──▶ [秘书]                      靠自然语言就能指挥

      人跟机器：[老板] ──口述──▶ [计算机]  ✗ 听不懂

      程序员：  [程序员] ──写源码──▶ [main.go] ──编译──▶ [main.exe] ──▶ [计算机逐条执行]
                                                                        能听懂
    ```

* **人直接指挥计算机做不到**
    * 秘书是老板的雇员，老板可以给她下指令，比如"把我说的内容记下来""把内容打印出来""把内容传真给某某公司"，靠自然语言就能指挥
    * 老板对着计算机说这些话现在的计算机听不懂，而且这些话也太复杂了。

* **编译这一步不能省**
    * 源码不能直接交给电脑执行，还差一步——编译
    * 把 `main.go` 进行编译处理会得到一个二进制可执行文件 `main.exe`
    * 计算机执行这个 `main.exe`，就把里面的事情做完了

* **学编程的本质**
    * 学说白了就是学怎么写这一块——写出来，交给电脑执行
    * 电脑可以是 Windows，也可以是 Linux、苹果
    * 发文件、打印文件、上传下载、操作数据库，都是这么来的

* **为什么学 Go**
    * Go 是区块链最主流的编程语言
    * Go 是当前最具发展潜力的语言
    * Go 是 Google 公司创造的语言，它是 Google 的一个产品，也是 Google 现在主推的语言
    * 国外 Google、CoreOS 这些公司都开始用了；国内青云、阿里、小米、京东都在开始大规模地用 Golang 开发云计算产品

## Go 的设计者与诞生背景

* **Ken Thompson**
    * Unix 操作系统的最主要设计者，C 语言的主要发明人
    * 1983 年就拿到了计算机行业最高奖图灵奖，98 年又拿到美国国家技术奖，还是美国工程院院士
    * B、C、Go 三门语言的主要发明人都是他

* **罗伯·派克（Rob Pike）**
    * 贝尔实验室的人，Unix 系统开发的主要成员，跟 Thompson 是好朋友
    * UTF-8 编码主要由他创造
    * Go 的金花鼠吉祥物就是他老婆设计的

* **Robert Griesemer**
    * 谷歌浏览器里的 JavaScript 引擎是他设计出来的
    * Java 里的 HotSpot 编译器也是他协助设计的

* **创造 Go 的三个初衷**
    * 编程语言的发展落后于硬件，不能充分发挥多核、多 CPU 的优势
    * 软件系统越来越复杂、维护成本越来越高：编程不够优雅、风格不统一、计算能力不够、处理大并发不够好
    * 现有的语言各有短板：C、C++ 速度确实非常快但编译慢且有内存泄漏的可能；Python、PHP 开发效率高但速度不够快
    * 目标风格：风格统一、计算能力足够强、还能处理大并发，而且非常简洁高效，兼顾编译语言的速度与脚本语言的开发速度

* **发展简史**

    ```text
      2007        2009            2015          2017        2018
       │            │               │             │           │
       ▼            ▼               ▼             ▼           ▼
     三位工程师    首发 1.0        1.5 ★         1.8 / 1.9    1.10
     开始设计      11月10日      去掉最后残余     陆续发布    发布
                                 的 C 代码
                              （里程碑）
    ```

    * 2007 年派克、Thompson、Robert 三个人开始设计这门新语言
    * 2009 年 11 月 10 日发布第一个版本
    * 2015 年的 1.5 是一个里程碑式版本，它把最后残余的那部分 C 代码彻底拿掉了。

* **选用的版本**
    * 讲课用 1.9.2
    * 没用最新的，是因为 18 年刚出来的版本还不算稳定
    * 1.9 是目前各大公司采用比较多、比较成熟的稳定版

## Go 语言的七个特点

* **Go = C + Python**
    * Go 语言既有静态编译语言的安全和性能，又有动态语言开发和维护的高效率
    * 静态编译语言像 C，速度很快、安全性和性能都强；动态语言像 Python，开发效率高

    $$
    \text{Go} = \text{C} + \text{Python}
    $$

* **从 C 继承来的那一套**
    * 继承内容包括表达式的语法、控制结构、基础数据类型、参数传值，还有指针
    * Go 语言里是有指针的，同时保留了 C 语言一样的编译执行方式，并且弱化了指针
    * Go 的写法习惯是变量写在前面、数据类型写在后头，`num *int` 就是"num 这个变量，类型是指针，指向 int"

    ```go
    func testPtr(num *int) {
        *num = 20
    }
    ```

    * `Ptr` 是 pointer 的简写，用 `*` 符号取得指针所指向的值再赋值

* **包（package）**
    * Go 引入包是用来组织程序结构的，后面的项目实际上以包的形式来管理
    * Go 语言的每一个文件都要属于一个包，而不能单独存在；不属于任何包是编译不过去的。
    * 用了 `fmt` 本身是一个包，所以还得 import 一个包，不然同样编译不过去

    ```go
    package main

    import "fmt"

    func sayOk() {
        fmt.Println("ok")
    }
    ```

* **垃圾回收（Garbage Collection，GC）机制**
    * C 语言里内存回收要程序员自己管，稍微不注意就内存泄漏，而内存泄漏很快就能把内存吃光
    * Go 引入垃圾回收，程序员只关注业务逻辑，不再关注怎么回收内存，直接用就行

* **天然的并发**
    * Go 刚开始设计的时候就是冲着有效利用多核、多 CPU 去的。
    * 语言层面就直接支持并发，引入了一个叫 goroutine 的概念，可以非常轻松地实现大并发、高效利用多核
    * 它基于 CSP（Communicating Sequential Processes）并发模型执行
    * 支持上千、上万个并发都属小儿科
    * > **提示**：当然前提是用得得当

* **管道通信机制（channel）**
    * 解决 goroutine 之间的相互通信问题，用的就是 channel 这个管道

* **函数可以返回多个值**
    * 传统编程语言只有一个返回值，要返回两个得用数组把它们封装起来再返回
    * Go 直接支持返回多个值，参数是两个 int，返回值列表就写两个 int

    ```go
    func getSumAndSub(n1 int, n2 int) (int, int) {
        sum := n1 + n2
        sub := n1 - n2
        return sum, sub
    }
    ```

    * > **提示**：注意这两行里没有分号。Go 语句后面不用带分号，其实是编译器会自动给你带上分号，所以不要画蛇添足了。

* **切片（slice）与 defer**
    * 切片可以理解成动态数组，有点像 Java 里的集合概念
    * `defer` 关键字用于延时执行——函数执行完毕之后，再去执行 `defer` 里面的这些语句
    * `defer` 是为了在函数中能够及时、方便地回收资源

## 开发工具选型

| 工具 | 特点 |
| :--- | :--- |
| **Visual Studio Code（VS Code）** | 微软出品，跨苹果、Windows、Linux 三大平台；默认支持 Go 语法高亮，装 Go 插件后有智能提示，还能直接编译运行 |
| **Sublime Text** | 免费，支持语法高亮；但用到一定次数会提示你购买，比较烦人，不买也能继续用 |
| **Vim / Vi** | 非常强大的文本编辑工具，Linux、Unix 下的常客，程序员中使用广泛 |
| **Emacs** | 号称"编辑神器"，不只是编辑工具，还能当集成开发环境，Linux、Unix 环境常用 |
| **Eclipse** | 本身是个平台，装什么插件就能开发什么；装上 GoEclipse 插件就能做 Go 开发 |
| **LiteIDE** | 中国人自己开发的 Go 专用 IDE，免费，网上一搜就能下载 |
| **JetBrains 系** | PhpStorm、WebStorm、PyCharm 都能用来开发 Go，但需要装 Go 插件，而且都是付费产品 |

* **选型的顺序：先文本工具，后高级 IDE**
    * 建议先用 VS Code 或 Vim 这种文本工具，等你对 Go 语言有一定了解之后，再换更高级的 IDE
    * 原因一：能更深刻地理解 Go 语言技术，培养代码感；打开高级工具一点就"啪"一堆东西全出来，对刚开始学 Go 的同学没有任何好处
    * 原因二：有利于公司面试，面试可能直接给你一张纸让你用笔写程序
    * > **易错点** ⚠️：不能因为高级工具什么都能点出来，就以为自己会了——可能连 `println` 这个函数都写不出来

* **智能提示长什么样**
    * 装了 Go 插件之后打一个 `fmt.`，可用的函数马上就全列出来了。

## VS Code 的下载与三平台安装

* **下载页的两层选择**
    * 第一层按操作系统选：Windows、Linux、Mac
    * 第二层按格式和位数选
    * Windows 有 installer 和 zip 两种：installer 是 exe 文件双击安装，zip 是解压就能用的。
    * Linux 分好几种格式：`.deb` 是 Ubuntu 用的，`.rpm` 是红帽、Fedora、SUSE 那一类，`.tar.gz` 就是压缩包，解压完直接能用
    * Mac 只有一个版本，没得选
    * > **提示**：判断 32 位还是 64 位的小技巧：点开计算机 → 属性 → 系统类型，这里写着 64 就说明你是 64 位系统；选错了装上不好使

* **Windows 安装要点**
    * 下载完会得到一个 `VSCodeSetup` 开头的安装文件
    * 点"我接受"下一步；安装路径建议专门找一个目录，不要装 C 盘
    * 有一个"添加到 PATH（重启后生效）"，把它勾上，VS Code 就被加到 PATH 这个环境变量里去了，可以直接用
    * 装完把启动文件发送到桌面做个快捷方式
    * 先建一个专门存放 Go 代码的文件夹，用"打开文件夹"选到它，它就会把这个文件夹当作你的工作区打开
    * 用着的时候老在底下弹那些提示，直接叉掉就行，叉一次之后就不会再提示了。
    * > **易错点**：卸载路径是控制面板 → 程序和功能 → 输入 `M` 过滤（M 开头的多半都是微软的产品）→ 找到 Microsoft Visual Studio Code → 卸载；卸载完记得刷新一下控制面板列表

* **Linux 安装要点**
    * 用虚拟机装的 Linux，具体是 Ubuntu，安装包是 AMD 64 位
    * 因为是虚拟机，多一个步骤：用 Xftp 把 Windows 侧下载好的安装包传输到 Ubuntu 系统下面
    * 建议把 VS Code 装到 `/opt` 这个目录下
    * 拷贝时会提示权限不够，切换成 root 用户：`su root`，输入 root 密码后再拷贝
    * 解压得到一个蓝色文件夹，进去 `ls` 能看到一个绿色的可执行文件 `code`，类似 Windows 下的 `Code.exe`，用 `./code` 运行

    ```bash
    su root
    cd /opt
    tar -zxvf code-stable-x64-1536817294.tar.gz
    ```

* **Mac 安装要点**
    * Mac 下只有一个版本，是一个 zip 文件，解压就能使用
    * > **易错点** ⚠️：Mac 系统默认没有启动 SSH 服务，所以必须先启动一下才能远程传文件；Mac 本身是装了 SSH 服务的，只是默认不开机自动启动，没启动会直接提示连不上

    ```bash
    sudo launchctl list | grep ssh
    sudo launchctl load -w /System/Library/LaunchDaemons/ssh.plist
    ```

    * 查到有记录就说明服务是起来的；服务停掉后查不到这一项，再连会提示连接失败
    * 解压 `unzip VSCode` 得到一个 `.app` 文件，这就是可执行的文件，双击就能打开
    * 在 Finder 里逐层进入磁盘 → 用户 → 具体用户 → VSCode 文件夹，双击就起来了。

* **为什么前期以 Windows 为主**
    * 很多同学对 Windows 系统更熟悉一些，选它可以减轻学习压力
    * 在 Windows 下做 Go 开发、在 Linux 下做 Go 开发、还是在 Mac 下做开发，本质没什么区别，因为基本的核心语法是一样的。
    * 实际开发中还有很多人是在 Windows 上把程序写好，然后上传到 Linux 上部署
    * 后期真正开始讲项目、讲区块链的时候才会用 Linux

## Go 的 SDK

* **SDK**
    * > **定义**：SDK（Software Development Kit）是软件开发工具包，里面包含了对应开发语言的各类工具，主要是编译工具和一堆 API
    * 没有 SDK 你就只能写源代码，写完了也跑不起来
    * 光有播放器没用，你得有可执行文件；光有源代码没用，你得有编译它的工具
    * 工作里有人问"Go 语言的 SDK 是什么意思"，答软件开发工具包

* **下载来源与版本**
    * 一般都是到 Go 语言的官方网站 `golang.org` 下载，但这个网站有可能访问不到
    * 能翻墙就去官网下，不会翻墙可以去国内的 Golang中国 网站下载
    * 打开官网你会看到当前最新版本是 **1.9.2**，也就是目前使用的版本

* **版本的两层选择**

    ```text
                         Go SDK 下载列表
                                 |
           +---------------+-------+-------+-----------+----------+
           |               |               |           |          |
         Darwin           Unix          Linux      Windows      source
        (苹果机)        (FreeBSD等)   (Ubuntu/CentOS)            (源码包)
           |               |               |           |
        .pkg / .tar.gz   同样两种格式   386 / amd64 / arm   386 / amd64
                                   ↓                 ↓
                              32位 / 64位        .msi / .zip
                              arm 不要下          32位 / 64位
    ```

    * 第一层先按操作系统分（Darwin 就是苹果的操作系统），第二层按包格式和位数分
    * `386` 代表 32 位，`amd64` 就是 64 位操作系统
    * `.pkg` 是图形化安装包，`.tar.gz` 是解压缩就能用的，推荐用 `.tar.gz`
    * Windows 下的 `.msi` 相当于 `.exe` 那种 setup 形式的安装，`.zip` 是解压即可使用，推荐用 zip
    * Linux 下 `386.tar.gz` 对应 32 位系统，`amd64.tar.gz` 对应 64 位系统，旁边的 `arm` 版本不要去下——CPU 体质跟我们不一样，下了你也用不了。
    * 最后的 source 是源码包，Go 语言的源码是开源的、直接给用户可以看到

* **安装注意事项（三平台通用）**
    * 安装路径不要带中文，不要有特殊字符，最好就是纯英文，也不要有空格
    * 建议装在专门的目录下，习惯放 D 盘的 `programs` 目录下；Linux 下习惯放 `/opt`，Mac 下习惯放用户目录下的 `go_dev`
    * Windows 下安装基本是傻瓜式的，解压就能使用；解压完那个 zip 文件就没用了，可以删掉，解压完你会得到一个 `go` 文件夹，这个 `go` 目录就是 SDK
    * Windows 下安装包有 285MB，机器慢的话要等一会儿

* **SDK 的目录结构**

    | 目录 | 里面是什么 |
    | :--- | :--- |
    | `api` | 一堆 API |
    | `bin` | 三个指令：`go.exe`、`godoc.exe`、`gofmt.exe` |
    | `doc` | 文档 |
    | `src` | Go 语言的源代码 |

* **`bin` 里的三个 exe**
    * `go.exe`：Go 的运行和编译器，这是最重要的一个；Go 程序写完以后用它来编译和运行代码，既可以编译成可执行文件，也可以直接用 `go run` 当脚本跑
    * `godoc.exe`：用来生成文档的
    * `gofmt.exe`：对你的代码进行格式化
    * 如果学过 Java，`go.exe` 有点类似于 `java` 和 `javac` 的角色

* **Linux 与 Mac 的安装流程**
    * Linux 上查系统位数：`uname -a`，输出里有 64 就是 64 位系统，看不到 64 一般来说就是 32 位
    * Linux 解压：`tar -zxvf go...`，注意命令和参数之间都有空格，这个文件比较大，解压会有点慢
    * Mac 解压：`tar -zxvf go1.9.2.darwin-amd64.tar.gz`，`.tar.gz` 在苹果机下面同样是压缩文件，解压就能用
    * 两边解压完目录结构跟 Linux 下是一模一样的，都有 `bin`，里面是三个绿色的可执行文件
    * 解压完 `cd` 进 `go` 目录再 `cd bin`，执行 `./go version` 能看到版本信息就证明 SDK 安装成功

## 环境变量

* **Windows 找程序的顺序**
    * 先在当前目录下找有没有这个可执行程序
    * 找不到，再到环境变量 `Path` 指定的目录里找
    * 还是找不到，就报"不是内部或外部命令，也不是可运行的程序或批处理文件"
    * 在 `bin` 目录能运行、退出来就找不到，原因就是这么简单

* **环境变量**
    * > **定义**：环境变量的作用，就是把 `go` 所在的路径定义到环境变量中，让系统帮我们去找这个程序，从而在任何目录下都能执行 `go` 指令
    * 不配的话只能在安装的那个目录下使用，这显然不合理——将来源代码不一定放在 `bin` 目录下面，可能在 C 盘、可能在 F 盘

* **配置入口与作用域**
    * 路径：计算机 → 属性 → 高级系统设置 → 环境变量
    * 用户变量只针对当前用户生效，系统变量针对所有用户都生效
    * 显然配到系统变量比较好，对所有用户都能用上

* **三个变量分别填什么**

    | 变量名 | 变量值 | 说明 |
    | :--- | :--- | :--- |
    | `GOROOT` | Go 的安装路径，比如 `D:\programs\go` | 指定 SDK 安装路径，Go 装在哪儿就填哪儿 |
    | `Path` | 在已有值**末尾**加一个分号，然后 `%GOROOT%\bin` | 不新建，点"编辑"追加 |
    | `GOPATH` | 你自己的工作目录，比如 `D:\goproject` | Go 项目的工作路径 |

    * `GOROOT` 是新建的，变量值直接写 Go 的安装路径；不能写什么你就照抄，装在 F 盘照抄 D 盘就找不到了。
    * `Path` 系统本身已经有了，所以不要新建，要点"编辑"去追加——人家已经有了，你再去建一个没有道理
    * `%GOROOT%` 是去引用刚才定义的那个 `GOROOT` 变量，`\bin` 表示在后面再加一个 `bin` 路径，因为实际上的编译程序是在 `bin` 目录下
    * `GOPATH` 是新建的，它指的是将来 Go 项目放在哪个目录，这个跟 Java 不一样，Java 没有这个
    * `GOPATH` 这么重要，是因为编译器在编译的时候会用到这个路径，它会生成一系列的 `.a` 文件或者 `.exe` 文件
    * 配完最后一定要点确定

* **Linux 与 Mac：编辑 `/etc/profile`**
    * `/etc/profile` 就相当于 Windows 的环境变量配置文件，在里面加上三个变量：`GOROOT` 是安装目录，`PATH` 是可执行文件的路径，`GOPATH` 是工作目录
    * 编辑这个文件需要 root 权限，用 `vim` 或 `vi` 编辑（vi 和 vim 一样，vim 有颜色好看一点）

    ```bash
    export GOROOT=/opt/go
    export PATH=$PATH:$GOROOT/bin
    export GOPATH=$HOME/go_project
    ```

    * `PATH` 这行千万不要打空格，Linux 下面不允许多余空格，不然它不识别
    * `$PATH` 代表引入它原先的路径，不写这句等于把以前 PATH 里原有的东西全冲掉了；冒号相当于在后面接上一段，把带 `bin` 的路径拼上去，相当于累加了一个路径
    * 直接写 `/opt/go` 也可以，但不划算——上面已经定义了 `GOROOT`，何必再抄一遍，专业的写法就是直接引用 `$GOROOT`
    * Mac 下 `GOROOT` 指向 `/Users/用户名/go_dev/go`
    * Mac 用 `vi` 编辑 `/etc/profile` 会提示这是 read-only 文件，不用管，保存时加一个叹号就行：`wq!`，叹号代表强制保存

* **生效的前提：重开终端或注销**
    * Windows 下配完环境变量后，必须把原来那个控制台关掉、重新打开一个新开的 DOS 终端
    * Linux 和 Mac 下配完需要注销、重新登录，不需要重启；注销的本质就是让系统去重新读一遍 `/etc/profile`
    * > **易错点** ⚠️：**配置环境变量后必须重新打开一次终端（Linux/Mac 下注销重登），不然你会发现不生效**

* **环境搭建成功的判断标准**
    * 只要你在不同目录下都能执行 `go version`，就说明 Go 开发环境搭建成功
    * 正常输出形如 `go version go1.9.2 windows/amd64`，说明版本是 1.9.2、AMD CPU 的 64 位操作系统
    * 如果没看到这个界面，说明安装还有问题，想想是不是路径里有中文，按步骤重新走一遍
