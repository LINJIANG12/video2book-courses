## 程序的编写、编译与运行回顾

* **SDK 与三个环境变量**
    * > **定义**：SDK 就是软件开发工具包（Software Development Kit），做 Go 开发首先要安装并配置好这个 SDK，没有 SDK 就没法开发
    * `GOROOT` 用来指定 Go SDK 安装在哪个目录
    * `Path` 指定 SDK 下面的 `bin` 目录

    | 指令 | 作用 |
    | :--- | :--- |
    | `go.exe` | 编译和运行，比如 `go run` 一个 Go 源码 |
    | `gofmt.exe` | 格式化 |
    | `godoc.exe` | 文档相关，用得比较少 |

    * > **结论**：`GOPATH` 是 Go 的工作目录，所有项目的源代码都统一存放在这个目录下面

* **三步走**
    * 第一步编写，就是写源代码
    * 第二步编译，对应指令 `go build`，编译完会生成一个二进制的可执行文件
    * 第三步运行有两种形式：直接运行可执行文件（Windows 下直接运行 `.exe`，Linux 或 Mac 下用斜杠接上可执行文件）；不编译直接 `go run`，慢的原因是它底层其实还是做了编译工作，只不过没有留下 `.exe` 文件

* **六条编写规则**

    ```go
    func main() {
        // 语句
    }
    ```

    * Go 文件以 `.go` 结尾
    * Go 程序区分大小写
    * 语句后不需要带分号
    * 定义的变量或者 import 的包必须使用，不用就会报错
    * 不要把多条语句放在同一行，否则会报错
    * 大括号成对出现，而且风格是跟函数放在同一行的，不能把大括号写到下一行

* **最容易踩的坑**
    * > **易错点**：对初学者来说最容易出错的地方是拼写错误——文件名或路径写错、`l` 别写成 `1`、分号该没有的没有、中英文符号混淆（比如该输英文括号结果输了中文括号），都同样编译不过去
    * > **注意**：写代码的时候里面所有的字符都应该是英文字符，不能切换成中文输入

## 变量与内存

* **为什么需要变量**
    * 一个程序其实就是一个世界
    * 现实生活中有什么，我们的程序里就可以用相应的变量来表示
    * 变量是程序的基本组成单位，无论用哪种高级语言，变量都是程序的组成单位

* **变量**
    * > **定义**：变量相当于内存中的一个数据存储空间
    * 人有大脑，计算机就有内存；变量一旦运行起来，它就存在内存里
    * 可以把变量当成一个房间的门牌号，通过门牌号找到房间；通过变量就可以访问到变量的值
    * 变量表示内存中的一个存储区域，这个区域有自己的名称（变量名）和自己的类型（数据类型）

    ```text
    代码执行到 var i int 这一行时

       ┌───────────────────────────────────────────────┐
       │                    内存                          │
       │                                               │
       │    ┌────────────────────────┐                  │
       │    │   一块数据存储区域       │   内容：0        │
       │    └───────────▲────────────┘                  │
       │                │ 直接关联                       │
       │             变量名 i                            │
       │                                               │
       │    i = 10  →  通过名字 i 找到这块空间            │
       │                →  把里面的 0 重新赋值为 10        │
       │                                               │
       │    fmt.Println(...)  →  输出 i，得到 i = 10      │
       └───────────────────────────────────────────────┘
    ```

    * 所有代码要运行起来必须加载到内存，代码实际上是在内存里面才能运行的。
    * `var i int` 没有赋值时其实有一个默认值为 0，紧接着做了 `i = 10`，计算机就通过 `i` 这个变量名找到这块空间，把 0 重新赋值成 10

* **变量的三部曲**
    * 声明变量（也叫定义变量，这两种说法基本等同）
    * 赋值
    * 使用
    * 三步缺一不可，有时候可以把第一步和第二步放在一起一步走完

    ```go
    var i int
    i = 10
    fmt.Println("i =", i)
    ```

* **变量的三要素**
    * > **定义**：一个变量由三要素构成——变量名、变量的值、变量的数据类型，三者缺一不可。
    * 变量名必须有；变量要有值，这是必须要素；变量还有一个数据类型

## 变量的三种使用方式

* **指定类型**

    ```go
    var i int
    fmt.Println("i=", i)
    ```

    * 声明后如果不赋值，就会使用默认值，输出是 `i=0`
    * 逗号代表先把 `"i="` 输出出来，再把 `i` 的值输出，相当于把两段拼在一起输出

* **类型推导**

    ```go
    num := 10.11
    fmt.Println("num=", num)
    ```

    * 根据值自行判断变量类型，编译器会进行类型推导
    * 给一个 `10` 就是整数类型，给一个字符串就是字符串类型
    * 动态编程语言都有这个特点，Java 在新的特性里面也加入了类型推导

* **省略 var 关键字**

    ```go
    name := "tom"
    fmt.Println("name=", name)
    ```

    * 下面这种写法跟上面那句是等价的

    ```go
    var name string
    name = "tom"
    ```

    * 也就是说上面两句可以合在一起写成一句：声明的时候同时赋了值，还把 `var` 关键字也省略了。
    * > **易错点**：**省略 `var` 的时候冒号绝对不能省**，去掉冒号就变成普通的赋值了，而变量根本没声明过，直接赋值违反"先定义再使用"的原则。

## 多变量声明

* **函数内的三种写法**

    ```go
    var n1, n2, n3 int
    ```

    * 这就相当于 `n1`、`n2`、`n3` 都是 `int`，没有赋值所以输出的时候三个都是 0
    * 如果这几个变量类型不一样，可以直接这么写

    ```go
    var n1, name, n3 = 100, "tom", 888
    ```

    * 这里是一一对应的关系：`n1` 对应 `100`，`name` 对应 `"tom"`，`n3` 对应 `888`
    * 同样可以使用类型推导

    ```go
    n1, name, n3 := 100, "tom", 888
    ```

    * 因为有冒号等号在，这代表声明，所以前面的 `var` 就去掉了。
    * > **易错点**：**上面已经声明过的变量，不能在同一作用域里再声明一次**，编译器会直接报重复定义的错

* **全局变量的两种写法**

    ```go
    var n1 = 100
    var n2 = 200
    var name = "jack"
    ```

    * 设计者觉得这样写有点麻烦，一般会改写成一次性声明的形式

    ```go
    var (
        n3    = 300
        n4    = 900
        name2 = "mary"
    )
    ```

    * > **定义**：所谓全局变量，就是在函数外定义的变量；`main` 是一个函数，在 Go 中函数外部声明的变量都可以叫做全局变量
    * 这两种方式是等价的，后面这种在实际开发中用得比较多
    * 如果没有用到 `fmt` 包里面的任何方法，编译器就会报错，因为 import 进来的包没有被使用

## 变量的变化、重名与零值

* **重新赋值的两个限制**
    * 变化只能发生在这个区域里面，不能出了这个范围
    * 类型不能发生变化

    ```go
    var i int = 10
    i = 30
    i = 50
    fmt.Println("i =", i)
    ```

    * 这是没问题的，原先 `i` 等于 10，现在改成 30，再改成 50 都行
    * > **结论**：连续赋值以后**以最后一个值为准**，`i` 最后被改成了 50，所以输出的是 50
    * 能不能改成 `1.2` 呢？不行，会报错，编译器会告诉你这个 `1.2` 字面量要被截断成一个整数，而这是不允许的。
    * > **易错点**：**变量可以重新赋值，但只能在同一个区域、同一类型范围内**，你不能把一个 `int` 悄悄改成 `float`

* **同一个作用域里变量不能重名**
    * 作用域暂时这么理解就行：在同一个函数里，或者在同一个代码块里
    * 前面已经有了一个 `i`，再来一句 `var i int = 50`，编译器直接报 redeclared
    * 写 `i := 99` 也不行，因为 `:=` 这一句其实包含了"定义"和"赋值"两个部分

    ```go
    i := 99
    ```

    * > **结论**：不能重名这件事，**写 `var` 报错，写 `:=` 也报错**；但如果在不同的作用域里，是可以有相同名字的。
    * > **易错点**：同一个包里不能有两个 `main` 函数，否则提示"重复声明"，解决办法是把先前那个 `main` 先注释掉

* **零值与各类默认值**
    * > **定义**：当程序员没有赋值时，变量就会保留这个默认值，这个默认值叫零值

    | 类型 | 默认值 |
    | :--- | :--- |
    | 整型 | `0` |
    | 浮点型 | `0` |
    | 字符串 | 空串 |
    | 布尔值 | `false` |

    * 基本数据类型包括以后要讲的复杂数据类型都有零值
    * `%v` 表示按照变量的值输出，这样看起来更明确
    * 如果按 `%f` 输出，看到的是 `0.0`，其实它就是 0

    ```go
    var a int
    var b float32
    var c float64
    var isMarried bool
    var name string

    fmt.Printf("a=%v b=%v c=%v isMarried=%v name=%v", a, b, c, isMarried, name)
    ```

## 声明、初始化与赋值

* **声明变量**

    ```text
    var 变量名 数据类型
    ```

    * `var a int` 从概念上就是声明了一个变量，变量的名字叫 `a`
    * `var num1 float32` 声明了一个单精度小数，变量名叫 `num1`

* **初始化变量**
    * 在声明变量的时候就给值，这就叫声明并初始化
    * 声明时直接赋值可以省略数据类型

    ```go
    var b = 400
    ```

    * 能省是因为这个时候用到了类型推导

* **给变量赋值**
    * 变量赋值指的是先声明、再给值
    * 声明时没给值默认是 0，但有可能这个 0 并不是你需要的，所以可以在后面重新给它赋值
    * > **结论**：**声明**是起名字定类型，**初始化**是声明的同时就给值，**赋值**是声明之后再改值

* **加号的两副面孔**

    ```go
    var i = 1
    var j = 2
    var r = i + j // 做加法运算
    fmt.Println("r =", r)

    var str1 = "hello "
    var str2 = "world"
    var res = str1 + str2 // 做拼接操作
    fmt.Println("res =", res)
    ```

    * 当加号两边都是数值型的时候，它就叫加法运算，输出 `r = 3`
    * 如果两边都是字符串类型，它就叫字符串拼接，输出 `hello world`

## Go 的数据类型

* **两大块**

    ```text
    Go 数据类型
    │
    ├─ 基本数据类型
    │   ├─ 数值型
    │   │   ├─ 整数类型  int / int8 / int16 / int32 / int64
    │   │   │             uint / uint8 / uint16 / uint32 / uint64（无符号）
    │   │   │             byte —— 就是一个字节
    │   │   └─ 浮点类型  float32（4 字节，单精度）
    │   │                 float64（8 字节，双精度）
    │   ├─ 布尔类型      bool —— 只有 true 和 false
    │   └─ 字符串类型    string
    │
    └─ 派生 / 复杂数据类型
        ├─ 指针 *        ├─ 数组      └─ 结构体
        ├─ 管道 chan     ├─ 函数      └─ 切片 slice
        └─ 接口 interface             └─ map
    ```

    * 这种划分跟很多传统的编程语言都是一样的
    * 结构体用得非常多，有点类似于别的编程语言里面的 class，Go 里没有类了，用结构体来替代
    * 函数在 Go 里也是一种数据类型
    * map 有点类似于别的编程语言里面的集合，Java 里有 `HashMap`，而 Go 里的集合比较单纯没有那么复杂，别的编程语言那一堆集合在 Go 里就一个 `map`

* **两个没归到基本类型里的**
    * `complex`——复数
    * `rune`——它是 `int32` 的别名，`rune` 和 `int32` 可以认为是等价的，但还不完全等价
    * > **提示**：`rune` 在存放的时候是用 Unicode 的码值来存放的，所以在处理字符串里面有中文的情况时一般会用它来保存

* **字符串是基本数据类型**
    * Go 里面字符串被归结为基本数据类型，官方手册的基础部分点进去以后也把 `string` 归结为基本数据类型
    * Java 的字符串本质上其实是一个类，可能被归到复杂数据类型里去
    * > **定义**：**字符串就是一串固定长度的字符连接起来的字符序列**
    * > **提示**：传统的字符串是由字符组成的，而 **Go 的字符串是由字节组成的**，是一个一个字节连起来的。

## 整数类型

* **有符号的范围怎么算**

    | 类型 | 位数 | 占用字节 | 表示范围 |
    | :--- | :--- | :--- | :--- |
    | `int8` | 8 位 | 1 字节 | $-128 \sim +127$ |
    | `int16` | 16 位 | 2 字节 | $-2^{15} \sim 2^{15}-1$ |
    | `int32` | 32 位 | 4 字节 | $-2^{31} \sim 2^{31}-1$ |
    | `int64` | 64 位 | 8 字节 | $-2^{63} \sim 2^{63}-1$ |

    * 8 就代表一个字节占用一个字节，16 占两个字节，32 占四个字节，64 占八个字节
    * 第一位是专门用来表示符号的：如果是 0 就表示正数，是 1 就表示负数，余下的位才用来表示数本身的值

    $$
    \text{范围} = -2^{7} \;\sim\; 2^{7}-1
    $$

    * > **结论**：**占用存储空间不一样，直接导致它能表示的数的范围不一样**

* **为什么负数比正数多一个**
    * 0 和 1 如果全部取 0 就会出现一个正 0，还有一个负 0，可是正 0 和负 0 其实都是 0
    * 二进制把这个负 0 借了一位，用这个负数多了一位，所以负数会比正数多一个

* **越界会报错**

    ```go
    var c int8 = -128
    ```

    * `-128` 确实能输出来，但再小一位给一个 `-129` 就报 `-129 overflows`
    * 正数也一样，127 是最大范围，变成 128 依然报 `overflows`
    * > **结论**：**用整数的时候一定要注意它的范围**，超出这个范围这个地方就一定会出问题

* **无符号的范围**

    ```go
    var k uint8 = 0
    ```

    * 无符号没有符号位，第一位也可以用来表示数值
    * 最小值是全部取 0，整个就等于 0；最大值是全部取 1，算出来就是 255
    * `uint8` 取 0 没问题，取 `-1` 会报 overflow，取 255 没问题，取 256 报 `overflows`
    * > **结论**：**做开发的时候要根据你表示数的范围来选取合适的数据类型**，是有符号的还是无符号的，要跟数据本身的范围相关

* **四个老熟人**

    | 类型 | 是否有符号 | 位数与占用 | 特点 |
    | :--- | :--- | :--- | :--- |
    | `int` | 有符号 | 32 位系统占 4 个字节，64 位系统占 8 个字节 | Go 的整型默认声明为 `int` 类型 |
    | `uint` | 无符号 | 32 位系统 4 个字节，64 位系统 8 个字节 | 不能存负数 |
    | `rune` | 有符号 | 类似 `int32` | 表示一个 Unicode 码，处理带中文的字符串特别有用 |
    | `byte` | 无符号 | 8 位，等价于一个无符号的 `uint8` | 一般可以存 0 到 255，存单个字母字符时选用 |

* **整型使用的五个细节**
    * 区分有符号和无符号就是看前面有没有写这个 `u`，写了 `u` 就是无符号的。
    * 想要表示一个整数而且不带负数、希望范围大一点，就应该选择无符号的。
    * Go 的整型默认声明为 `int` 类型

    ```go
    fmt.Printf("n1 的类型是 %T", n1)
    ```

    * `%T` 而且是大写的 `T` 代表 type，运行一下会看到 `n1 的类型是 int`
    * `int` 到底是多少，根据实际情况来，32 位系统就相当于 `int32`，64 位系统就相当于 `int64`
    * 保小不保大：在保证程序正确运行的前提下，尽量使用占用空间较小的数据类型

    ```go
    fmt.Printf("n2 的类型是 %T，n2 占用的字节数是 %d\n", n2, unsafe.Sizeof(n2))
    ```

    * `%d` 表示输出一个整数，`unsafe.Sizeof(n2)` 是 `unsafe` 这个包里的一个函数，可以返回变量占用的字节数
    * 要用它得引入 `unsafe` 包，不引入就报 `undefined: unsafe`

    ```go
    import (
    	"fmt"
    	"unsafe"
    )
    ```

    * > **提示**：引多个包推荐用引包块的方式，这种写法显得简洁，专业的 Go 开发工程师都喜欢这种
    * > **定义**：**`bit` 是计算机中最小的存储单位，`byte` 是计算机中的基本存储单位，而一个 `byte` 等于 8 个 `bit`**

## 浮点类型

* **分类**

    | 类型 | 占用字节 | 精度 |
    | :--- | :--- | :--- |
    | `float32` | 4 个字节 | 单精度 |
    | `float64` | 8 个字节 | 双精度 |

    * 单精度类似其他语言里的 `float`，双精度类似其他语言里的 `double`
    * 在 Go 里不叫 `double`，而是根据后面这个数字来区分：32 位就是单精度，64 位就是双精度
    * 占用空间不一样，最主要的区别在于它们表示的数的范围和表示的精度不一样

* **机器里的存放形式**
    * 浮点数在机器中存放的形式是"符号位 + 指数位 + 尾数位"
    * 这意味着浮点数都是有符号位的，也就是说浮点数都是有符号的

    ```go
    var num1 float32 = -0.000089
    var num2 float64 = -780966509.09
    fmt.Println("num1=", num1, "num2=", num2)
    ```

    * 输出的时候它会用科学计数法来显示，相当于 $7.80966509 \times 10^8$ 这种形式

* **尾数位会丢，精度会损失**

    ```go
    var num3 float32 = -123.0000901
    var num4 float64 = -123.0000901
    fmt.Println("num3=", num3, "num4=", num4)
    ```

    * 浮点数能表示这么大的范围，是因为它只是把指数位和尾数位记下来，记录的是一个大概的值
    * `float32` 把数值记录成 `-123.00009`，把后面的 `01` 给拿掉了；`float64` 却原封不动地保存了我们的数值
    * > **结论**：**浮点数有可能会造成精度损失**，`float64` 的精度比 `float32` 要准确，要表示精度更准确的数应该选用 `float64`
    * > **注意**：使用浮点数时可能会有精度损失，脑海中要始终有这一根弦

* **浮点类型的四个细节**

    ```go
    var price float32 = 89.12
    ```

    * Go 的浮点类型有固定的范围和位长，它不再受操作系统的影响
    * > **易错点**：**Go 里面没有 `float` 也没有 `double`，它只有 `float32` 和 `float64`**
    * Go 的浮点型默认声明为 `float64`

    ```go
    num5 := 1.1
    fmt.Printf("num5 的类型是 %T\n", num5)
    ```

    * 常量有两种表示形式，第一种是十进制数形式
    * 十进制里面整数部分的 `0` 可以去掉但小数点必须要有，`.123` 就等价于 `0.123`
    * > **提示**：看到别人写 `.123` 不要大惊小怪说人家写错了，这是个简写；不过正式开发中尽量还是把这个 0 带上

    ```go
    num8 := 5.1234e2
    ```

    * 第二种是科学计数法，`5.1234e2` 等价于乘以 10 的 2 次方，相当于乘以 100，输出是 `512.34`
    * 用大写的 `E` 也可以，`5.1234E2` 和它是一样的值
    * `5.1234e-2` 相当于除以 10 的 2 次方，算出来是 `0.051234`
    * > **结论**：**通常情况下应该使用 `float64`，因为它比 `float32` 更精确**，这是一个约定俗成的要求

## 字符与字节

* **Go 没有字符类型**
    * Golang 没有专门的字符类型这种数据类型
    * 如果要存储单个的字符比如字母，一般用 `byte` 来保存
    * > **提示**：`byte` 的范围是 0 到 255，最经典的就是 ASCII 码里面的字符；**数字这个时候保存的时候是按字符来算的，不是真正的一个数，它是字符**

* **直接输出打出来的是码值**

    ```go
    var c1 byte = 'a'
    var c2 byte = '0'
    fmt.Println("c1=", c1)
    fmt.Println("c2=", c2)
    ```

    * 输出的是 97 和 48，跟我们想的不一样
    * > **解释**：**当我们直接输出这个 `byte` 值时，输出的就是它对应的字符的码值**
    * 在计算机里面每一个字符其实也对应一个数字，可以把它理解成一张 ASCII 码表

* **想看到字符得用格式化输出**

    ```go
    fmt.Printf("c1=%c c2=%c\n", c1, c2)
    ```

    * `%c` 就是告诉编译器把 `c1` 按字符的形式输出，`c2` 也按字符形式输出，这次输出的就是 `a` 和 `0`

* **汉字存不进 byte**

    ```go
    var c3 byte = '北'
    fmt.Printf("c3=%c\n", c3)
    ```

    * 编译器报错 `constant 21271 overflows byte`，"北"对应的码值其实是 21271，是一个 Unicode 的十进制码
    * 溢出相当于说存不进去，换一个能保存它的类型就行，换成 `int` 就没有问题了。
    * > **结论**：**ASCII 表中的字符可以直接用 `byte` 保存**；**码值大于 255 的可以考虑用 `int` 类型来保存**，再好一点还可以用 `uint`，`uint` 表示的范围更大

* **字符类型使用的六个细节**
    * 字符常量是用单引号括起来的，比如 `'a'` 就是字符常量，也叫字面量
    * "中"的 Unicode 编码十进制是 20013，所以汉字用 `byte` 是存不进去的。

    ```go
    var c4 int = 22269
    fmt.Printf("c4=%c\n", c4)
    ```

    * > **定义**：**在 Go 中，字符的本质是一个整数，直接输出时是该字符对应的 UTF-8 编码的码值**
    * 也可以直接给变量赋一个数值，然后按 `%c` 输出该数值对应的 Unicode 字符；`'x'` 对应的数字是 120，输出就是 `x`

    ```go
    var n1 = 10 + 'a'
    fmt.Println("n1=", n1)
    ```

    * 字符可以参与运算，因为本质是整数，**运算时是按照码值运算的**，`'a'` 的码值是 97，10 + 97 就是 107
    * > **提示**：有些程序员会专门利用字符可以运算的特性来完成业务逻辑，比如想从 `'a'` 得到所有英文字母，就可以逐一地加 1 再按字符输出

* **从 ASCII 升级到 UTF-8**

    ```text
      存 储 方向                              读 取 方向

      字符  ──►  码值  ──►  二进制  ──► 存储   二进制 ──► 码值 ──► 字符 ──► 显示
              (查编码表)                              (查编码表)

      ★ 不按字符输出时，直接显示的就是码值本身
    ```

    * 计算机最早是美国人用的，最初 ASCII 码就足够了
    * 随着计算机普及，中国人、日本人、朝鲜人、韩国人也要用计算机，ASCII 码表示的字符不足以表示其他国家的文字
    * 升级过程中真的有好几个编码，比如 GB2312、GBK，最后到今天用得最多的就是 UTF-8 编码
    * ASCII 码里 `'a'` 是 97，在 Unicode 码里仍然是 97，说明 UTF-8 编码是兼容 ASCII 码的。
    * > **定义**：**UTF-8 是 Unicode 码的一种实现**
    * 在 UTF-8 里面英文字母是一个字节，它的汉字是三个字节来存储
    * Go 把编码统一成 UTF-8，强制你用 UTF-8，编程过程中就不会有乱码的问题了。

## 布尔类型

* **只认 true 和 false**
    * 布尔类型各个编程语言都有，是**用来表示真或者假的变量**
    * 在 Go 里布尔类型只允许取两个值：`true` 和 `false`，其他的值都不能取

    ```go
    var b = false
    fmt.Println("b=", b)
    ```

    * 别的语言里可能取一个正数、取一个负数，有些编程语言里还可以取空
    * 布尔类型占用一个字节
    * 布尔类型主要用于逻辑运算，用在流程控制里的判断真或者假

* **两个细节**

    ```go
    fmt.Println("b 占用的空间 =", unsafe.Sizeof(b))
    ```

    * 用 `unsafe` 包里的 `Sizeof` 可以验证它占用的存储空间就是一个字节，用这个方法需要引入 `unsafe` 包
    * 写 `b = 1` 马上会报一个编译错误 `cannot use 1 as type bool`
    * > **结论**：**不可以用于 0 或非 0 的整数来替代 `false` 或 `true`，这一点和 C 语言不一样**，强转也不行

## 字符串

* **编码**

    ```go
    var address string = "北京长城 110 hello world"
    fmt.Println(address)
    ```

    * Go 的字符串是由单个字节连接起来的，用 UTF-8 编码来标识 Unicode 文本
    * Go 统一使用 UTF-8 编码以后，乱码问题尤其是中文乱码就不会再来困扰程序员了。

* **不可变**

    ```go
    var str = "hello"
    str[0] = 'a'
    ```

    * Go 的字符串是不可变的，字符串一旦赋值就不能改
    * 保存之后马上报错 `cannot assign to str[0]`，不能修改这个 `string` 的第 0 个元素

* **双引号与反引号**

    ```go
    str2 := "abc\n"
    ```

    * 双引号里面如果出现转义符会被识别，而且如果里面有特殊字符比如再出现一个双引号，必须得转义才能输出，很麻烦
    * 开发中字符串里往往含有一些特殊字符，这时可以用反引号

    ```go
    str3 := `
    package main
    import "fmt"

    func main() {
        fmt.Println("hello")
    }
    `
    fmt.Println(str3)
    ```

    * 在 Golang 中，支持用反引号把字符串括起来，字符串就会以原生的形式输出，包括换行和特殊字符
    * 有特殊字符也不识别，直接把它当成一个普通文本，按原先的格式输出，包括制表符也输出来了。
    * > **提示**：反引号在电脑键盘的最左边，波浪号 `~` 的位置，ESC 下面那个键
    * 这种写法还有个好处：防止攻击，还可以输出我们的源代码

* **拼接**

    ```go
    str := "hello " + "world"
    str += " haha"
    ```

    * 编程时不可避免地要对字符串进行拼接，比如用 `for` 循环拼接一个大的字符串，这时候用加号就可以了。
    * 当两边都是字符串时，Go 在解析加号时就会把它解析成拼接操作

* **一行太长时分行写**

    ```go
    str4 := "hello " +
    	"world " +
    	"hello " +
    	"world "
    ```

    * > **结论**：这种语法一定要**把加号写在行末再换行**
    * > **解释**：因为 **Golang 会默认在行尾加一个分号**，它在行尾看到加号，就不会在当前行末尾加分号；换到下一行编译器在每一行末尾都加了一个分号，代码自然就错了，会报无效的加法

## 基本数据类型之间的转换

* **必须显式转换**
    * Go 和 Java、C 不同：Go 在不同类型的变量之间赋值时需要显式转换，不能自动转换
    * 把低精度给高精度不行，反过来就更不行；Java 那种低精度到高精度自动转换的规则在 Go 里不存在。

| 赋值写法 | 结果 |
| :--- | :--- |
| `var n1 float32 = i`（`i` 是 `int32`） | 报 `cannot use i (type int32) as type float32 in assignment` |
| `var n1 float32 = float32(i)` | 通过 |
| `var n2 int8 = i` | 报 `cannot use i (type int32) as type int8 in assignment` |
| `var n2 int8 = int8(i)` | 通过 |
| `var n3 int64 = i` | 报 `cannot use i (type int32) as type int64 in assignment` |
| `var n3 int64 = int64(i)` | 通过 |

    * > **结论**：**不管你是向高精度还是向低精度，都要显式转换**，前面写上你想转成的类型，后面写上你要转换的那个变量，这两个必须一致

* **基本语法**

    ```text
    T(v)
    ```

* **转换的是值，变量本身原地不动**

    ```go
    var i int32 = 100
    var n3 int64
    n3 = int64(i)
    fmt.Printf("i type is %T\n", i)
    ```

    * 执行完 `n3` 拿到了 `100` 的 64 位版本，可 `i` 依然是 `int32`
    * 变量的类型是编译期就定死的东西，不会因为一次转换悄悄搬家
    * > **易错点**：Go 的类型转换是表达式级别的，产出的是一个新值，不像 C 那种"就地改变变量类型"的写法；转换完要回头确认的是**目标变量的类型**，而不是源变量

* **装不下的数不会拦你，只会溢出**

    ```go
    var num1 int64 = 999999
    var num2 int8 = int8(num1)

    fmt.Println("num2 =", num2)
    ```

    * 把 `int64` 转成 `int8` 编译时不会报错，因为类型都对得上
    * 但它挡不住数值装不下，这段代码安静地跑出了一个 `63`
    * 编译器不会帮你检查数值范围；转换照样执行，结果不可预期
    * > **结论**：**不要什么都强转**，强制把一个大数交给一个小数据类型就是主动制造溢出，范围只能靠自己把关

* **常量的越界和变量的越界**

    ```go
    var n3 int8
    n3 = 128
    ```

    * 类型匹配但 `128` 是个常量，编译器在编译期就能判断 `int8` 最大只到 127，直接拒绝，报 `constant 128 overflows int8`
    * 编译不通过就把变量的类型范围扩大一点，声明成能容纳 128 的类型

    ```go
    var n1 int32 = 12
    var n4 int8
    n4 = int8(n1) + 127
    ```

    * 类型完全匹配所以编译通过，但 `12 + 127 = 139` 早就冲出 `int8` 的天花板了，跑出来是 `-117`
    * 编译器查不出这种"运行时才知道会不会越界"的情况，于是按溢出处理
    * > **结论**：**常量的越界，编译期就拦；变量算出来的越界，编译器看不见，只能靠溢出处理**

* **表达式结果的类型由操作数决定**

    ```go
    var n1 int32 = 12
    var n2 int64
    var n3 int8

    n2 = n1 + 20 // 错误
    n3 = n1 + 20 // 错误
    ```

    * `20` 是个无类型常量，会自动被推导成 `int32`，所以整个表达式的类型还是 `int32`
    * 报错是 `cannot use n1 + 20 (variable of type int32) as int64 value`
    * 改法

    ```go
    n2 = int64(n1) + 20
    n3 = int8(n1) + 20
    ```

    * > **提示**：Go 是一种强制、简洁的语言，它不搞隐式提升，想赋过去就得显式转换

## 基本类型与 string 的相互转换

* **第一条路：`fmt` 包的 Sprintf**

    ```go
    str = fmt.Sprintf("%d", num1)
    str = fmt.Sprintf("%f", num2)
    str = fmt.Sprintf("%t", b)
    str = fmt.Sprintf("%c", myChar)
    ```

    | 格式 | 含义 |
    | :--- | :--- |
    | `%v` | 默认格式输出 |
    | `%d` | 十进制整数输出 |
    | `%f` | 小数部分、无指数部分输出 |
    | `%t` | 按 bool 值输出 |
    | `%q` | 带单引号的字面值形式 |

    * `Sprintf` 根据 format 参数生成格式化的字符串，并返回该字符串
    * `%f` 默认按小数、无指数的形式输出，小数位补满了六位，`23.456` 输出成 `23.456000`，想控制精度可以写成 `%.*f` 之类去指定保留多少位
    * bool 对应的是 `%t`，别写 `%b`，`%b` 是输出二进制的。
    * `%q` 会把值用引号括起来显示，`true` 变成 `"true"`，字符串尤其清楚
    * > **易错点** ⚠️：**每条输出后面记得加 `\n`**，不然几条结果挤在一行，屏幕上一团乱麻很难看
    * > **结论**：第一条路的核心就是按值的类型挑对应的格式动词，把格式和值一起塞给 `Sprintf`，返回的就是字符串

* **第二条路：`strconv` 的 Format 系列**

    | 函数 | 参数 |
    | :--- | :--- |
    | `FormatBool` | 只要转的值一个参数，最简单 |
    | `FormatInt` | （要转的值，base），base 写 2 就是二进制，写 10 就是十进制 |
    | `FormatFloat` | （要转的值，格式 fmt，prec 精度，小数位宽） |
    | `Itoa` | int to ASCII 的缩写，直接把一个 int 转成字符串 |

    ```go
    str = strconv.FormatInt(int64(num3), 10)
    str = strconv.FormatFloat(num4, 'f', 10, 64)
    str = strconv.FormatBool(b2)
    str = strconv.Itoa(num5)
    ```

    * `FormatFloat` 的 `fmt` 参数写 `'f'` 是常规小数输出、写 `'e'` 是科学计数法；`prec` 是小数点后面保留多少位；最后那个 64 表示这个数是 `float64` 类型的。
    * `Itoa` 要的是 `int`，传 `int64` 会报错，要写成 `strconv.Itoa(int(num6))`
    * > **结论**：两条路的产物都是字符串，区别只是第一条路靠格式动词控制形态（顺手还能限定精度），第二条路靠每个函数自己的参数，实际开发里建议优先用第一条

* **`strconv` 的 Parse 系列**

    | 函数 | 参数 | 返回 |
    | :--- | :--- | :--- |
    | `ParseBool` | 字符串 | `value bool` 和 `error` |
    | `ParseInt` | 字符串、`base` 按几进制解析（2 是二进制、10 是十进制、16 是十六进制）、`bitSize` 结果的位宽（0 / 8 / 16 / 32 / 64） | `value int64` 和 `error` |
    | `ParseFloat` | 字符串、`bitSize`（一般就是 32 或者 64） | `value float64` 和 `error` |

    * 这些函数返回的是两个值：第一个是解析出来的值，第二个是一个 `error`
    * 我只想要值，所以用逗号加下划线把 `error` 忽略掉

    ```go
    b, _ = strconv.ParseBool(str)
    n1, _ = strconv.ParseInt(str2, 10, 64)
    f1, _ = strconv.ParseFloat(str3, 64)
    ```

    * `bitSize` 手册上写得很清楚：指定结果必须能无溢出地容纳该整型
    * 写之前一定先把三个参数都写全，漏了第三个编辑器会立刻提示不能赋值给 64 位的变量
    * > **易错点**：手册上写"写 0 就是 `int`"，但实际写 0 接不上，别去赌它，老老实实用 64 接住然后再转成想要的类型
    * > **结论**：`ParseInt` 返回的是 `int64`，`ParseFloat` 返回的是 `float64`，所以接收变量只能声明成这两个类型；要 `int32`、`float32` 或者 `int` 就拿到之后再转一次

    ```go
    n2 := int(n1)
    var i32 int32 = int32(n1)
    var f32 float32 = float32(f1)
    ```

* **转换不成功时会被悄悄塞默认值**

    ```go
    var str4 string = "hello"
    var n3 int64
    n3, _ = strconv.ParseInt(str4, 10, 64)
    ```

    * 跑一下它不报错，`n3` 的类型确实还是 `int64`，可是它的值是 **0**
    * 原因很简单：`"hello"` 压根没法转成一个整数，Go 就给你填了个默认值
    * 变量原先已经有个值的情况下，**它会变成 0，原先的值被直接抹掉了**
    * float 转不成功是 0，bool 转不成功是 false，哪怕变量原本就是 `true`，转完之后也会变成 `false`
    * > **结论**：**只要转换没成功，目标变量就被重置成该类型的默认值**——整型是 0，bool 是 false，跟你之前放进去什么值没有任何关系
    * > **易错点**：注意那个下划线！我们把 `error` 丢掉了，如果不丢，你本来是可以从错误信息里看出转换失败的，工程上真的需要区分成功与失败时别急着把 error 一把扔掉

## 指针

* **值类型：变量直接就是那个值**

    ```text
            ┌──────────────────────────────┐
            │  这块空间里存着：10          │
            │  这块空间的地址：0xc000010014│  ← 这就是 &i
            └──────────────────────────────┘
                        ▲
                        │
                      变量 i
    ```

    * 对于基本数据类型来说，变量存的就是值，也叫值类型
    * 变量 `i` 直接就和这块空间关联在一起了，`i` 取出来就是 10，因为它本身"就是"这一块

* **指针类型变量存的是一个地址**

    ```go
    var ptr *int = &i
    ```

    * `ptr` 是一个指针变量；类型是 `*int`，说明它是一个指向 int 的指针
    * 星号就是用来区分的——没有星号 `ptr` 就只是个整数，带上星号它就是个指针
    * `ptr` 本身的值是 `&i`，也就是 `i` 的那个地址

    ```text
      ┌──────────────────────────────┐
      │  ptr 自己那块空间             │
      │  地址：0xc000010030           │  ← &ptr
      │  内容：0xc000010014           │  ← 存的是「一个地址」
      └──────────────────────────────┘
                    │
                    │ 顺着这个地址找过去
                    ▼
      ┌──────────────────────────────┐
      │  这块空间里存着：10          │
      │  地址：0xc000010014           │
      └──────────────────────────────┘
    ```

    * `ptr` 是一格抽屉，抽屉里放的不是值，是一张写着门牌号的纸条；顺着纸条走过去，才找到真正的东西
    * 比喻：你租了个房子，房子里住着人，房子本身一定有个门牌号；`i` 就是那个房子，`&i` 就是它的门牌号，指针 `ptr` 是你手里攥着的那张写着门牌号的纸条
    * `ptr` 的值和 `&i` 是同一个 `0xc...`

    ```go
    fmt.Printf("i 的地址=%v\n", &i)
    fmt.Printf("ptr=%v\n", ptr)
    fmt.Printf("ptr 的地址=%v\n", &ptr)
    ```

    * > **易错点**：**指针变量自己也占一块空间、也有自己的地址**，因为你要存一个地址总得找个地方把它存下来
    * 至于它的内容存了什么跟别的变量没有本质区别：`i` 那块空间里存的是 `100`、`200` 这样的值，`ptr` 那块空间里存的是一个地址

* **取出指针所指向的值用星号**

    ```go
    fmt.Printf("ptr 指向的值 = %v", *ptr)
    ```

    * 只写 `ptr`：取出 `ptr` 存的那个地址
    * 写 `*ptr`：先取出 `ptr` 里存的地址，再顺着这个地址把值取回来，输出就是 `10`

* **通过指针改掉原来的值**

    ```go
    var num int = 9
    fmt.Printf("num 的地址=%v\n", &num)

    var ptr *int
    ptr = &num
    *ptr = 10
    fmt.Printf("num=%v\n", num)
    ```

    ```text
      第 1 步：num 这块空间，存着 9，地址 0xc000010014

      第 2 步：执行 ptr = &num 之后

      ┌──────────────────────────┐
      │ ptr 的空间：存 0xc000010014│  ← 一个地址，指向上面那块
      └──────────────────────────┘
                │
                ▼
      ┌──────────────────────────┐
      │ 那块空间：存着 9          │  ← 就是 num 的家
      └──────────────────────────┘

      第 3 步：*ptr = 10 —— 星号解引用，走到那块空间，把 9 改写成 10

      第 4 步：再输出 num，它已经是 10 了
    ```

    * `*ptr` 不是一个凭空造出来的副本，它指的就是 `num` 住的那个空间，往那儿写 `num` 跟着变

* **三个判断对错的题**

    ```go
    var a int = 300
    var ptr *int
    ptr = a   // 错
    ```

    * 把一个值塞给了指针变量，指针变量要的是地址，写成 `ptr = &a` 才对。

    ```go
    var a int = 300
    var ptr *float32
    ptr = &a   // 错
    ```

    * 指针是有类型的，一个指向 `float32` 的指针变量能接收的必须是 `float32` 的地址，你给它一个 `int` 的地址就是类型不匹配

    ```go
    var a int = 300
    var b int = 400
    var ptr *int

    ptr = &a   // 对
    *ptr = 100 // a 跟着变成 100

    ptr = &b   // 对，ptr 从此不再指向 a
    *ptr = 200 // b 变成 200，a 一动不动
    ```

    * 最终结果是

    $$
    a = 100,\quad b = 200,\quad *ptr = 200
    $$

    * > **结论**：**一个指针同一时刻只指向一个地方**，`ptr = &b` 这一句执行完，`ptr` 里存的地址就被覆盖了，它跟 `a` 的关系彻底断掉

* **两条要背下来的细节**
    * 所有值类型都对应有指针类型，形式就是在原类型前面加一个星号

    | 值类型 | 对应的指针类型 |
    | :--- | :--- |
    | `int` | `*int` |
    | `float32` | `*float32` |
    | `float64` | `*float64` |

    * > **结论**：值类型包括基本数据类型（int 系列、float 系列、`bool`、`string`）、数组、结构体
    * > **提示**：面试官很爱问"Go 里的值类型有哪些"，这个必须张口就来，基本数据类型、数组、结构体，**结构体也是值类型这一点特别容易漏**

## 值类型与引用类型

* **两大类**

    ```text
      值类型                          引用类型
      ─────                          ────────
      基本数据类型                    指针
      数组                           切片
      结构体                         map
                                     管道（channel）
                                     接口
    ```

    * > **结论**：这两大类一定要分清楚，面试和实际开发中都用得上

* **差别在哪儿**
    * 值类型：变量直接存储值，内存通常在栈中分配
    * 引用类型：变量存储的是一个地址，那个地址对应的空间才真正存值，内存通常在堆区分配；当没有任何变量引用这个地址时，该地址对应的数据空间就成了垃圾，这时会由 GC 来回收

* **栈区和堆区**

    ```text
      ┌──────────────────────────────────────┐
      │              一整块内存               │
      │  ┌─────────────┐   ┌───────────────┐  │
      │  │   栈区       │   │    堆区       │  │
      │  │  连续、固定  │   │ 动态、按需分配 │  │
      │  │             │   │               │  │
      │  │  值类型      │   │  引用类型      │  │
      │  │  通常在这里  │   │  通常在这里    │  │
      │  └─────────────┘   └───────────────┘  │
      │  （此外还有代码区等等，先不多说）      │
      └──────────────────────────────────────┘
    ```

    * Go 里有编译逃逸分析，所以值类型也有可能被分配到堆区，比如一个基本值类型它的值在别的函数里还要用，就有可能逃逸到堆上；反过来引用类型也有可能落在栈区
    * 栈和堆本身就是逻辑上的概念，很多编程语言里早就只是一个逻辑划分，Go 主要是**根据一个变量的使用时间有多长来决定放哪儿**——生命周期长的放堆区，短的就近放
    * > **提示**：先记大体概念，别抠得太死，等在具体代码里用到的时候再结合实际情况分析
