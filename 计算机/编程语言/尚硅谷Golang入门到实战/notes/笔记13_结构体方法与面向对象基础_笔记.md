# 结构体方法与面向对象基础

## 方法的概念

   * **方法（Method）**

       * > **定义**：作用在指定数据类型上的函数，也就是与某个数据类型绑定的函数。

       * 方法与函数的用法基本相同，但概念上有区别，区别就在方法多出的一段小括号 `(receiver type)`。

       * 只要是用 `type` 定义或声明的自定义类型都可以有方法，不限于 `struct`，`int`、`float32` 的自定义类型同样可以。

       * 结构体只提供字段，行为要靠方法补上，比如人说话、跑步、算术。

       * > **提示**：要记住两点——方法是跟数据类型相互绑定的；自定义类型都能有方法，而不只是结构体。

   * **方法与类型绑定的含义**

       * 绑定在 `Person` 上的 `test`，只能被 `Person` 这种数据类型的变量调用。

       * 也可以反过来说：`A` 结构体有一个方法叫 `test`。

---

## 方法的声明语法

   * **声明形式**

```go
func (receiver type) methodName(参数列表) (返回值列表) {
    方法体
    return
}
```

       * `type` 是方法要绑定的数据类型，具体类型根据实际情况定，不一定是结构体。

       * `receiver` 是这个类型的一个变量或实例，方法名按标识符命名规则写。

       * 参数列表相当于函数的形参列表；返回值列表可以有多个，还能给返回值命名。

       * > **注意**：有返回值列表就一定会有 `return`；没有 `return`，返回值列表就应该没有。

   * **接收者名字的含义**

       * 接收者的名字相当于形参，谁调用它这个名字就代表谁，调用时会被替换成调用者的一个副本。

       * 名字可以随意取，只要方法体内同步改掉即可。

       * 名字后面的类型不能随意改，类型一改方法就绑定到别的类型上去了，不再属于原来的类型。

       * > **提示**：真实开发应给接收者起有意义的名字，不要写 `a`、`b`、`c`、`d` 或 `p`，写 `person` 更严谨，别人一读就懂，作用类似 Java 里的 `this`。

## 方法的调用规则

   * **只能通过绑定类型的变量调用**

```go
type Person struct {
    Name string
}

func (p Person) test() {
    fmt.Println("test() name=", p.Name)
}

func main() {
    var p Person
    p.test()      // 名字为空，因为没赋值
    p.Name = "tom"
    p.test()      // 输出 tom
}
```

       * 直接调用会报 `undefined: test`，因为接收者无从传进来。

       * 用别的类型的变量调用会报 `type Dog has no field or method test`。

       * > **易错点**：既不能直接调用，也不能用其他类型的变量调用，这两种写法都是错的。

   * **接收者是调用者的副本**

       * 把接收者改成 `Jackie` 后打印，方法内输出 `Jackie`，主函数里仍输出 `tom`。

       * 结构体传参默认是值拷贝，方法内的修改不会影响调用者，除非传的是地址。

## 方法调用时的传参机制

   * **调用者自己也被传进去**

       * > **定义**：调用方法时，谁调用它，这个调用者变量本身也作为一个实参传进方法里。

       * `n1`、`n2` 和调用者 `p` 三者在调用瞬间全部按值拷贝进方法自己的数据空间。

```text
 main 栈                              getSum 栈
 +-------------------------------+   +--------------------------------+
 | n1 : 10                       |   | n1 : 10      (值拷贝)          |
 | n2 : 20                       |-->| n2 : 20      (值拷贝)          |
 | p  : [ Name : "tom" ]         |   | p  : [ Name:"tom" ] (值拷贝)  |
 +-------------------------------+   +--------------------------------+
           |                                      |
           |                                      | return n1 + n2  =>  30
           +<-------------------------------------+
           v
     res := 30
     fmt.Println("res=", res)  ==>  res = 30
```

       * 值类型做值拷贝，引用类型做地址拷贝。

       * 整个过程不停在拷贝，机制与函数几乎一致，唯一不同就是调用者自己也被拷了一份。

   * **运算读的是方法栈里的副本**

```go
type Circle struct {
    radius float64
}

func (c Circle) area() float64 {
    return 3.14 * c.radius * c.radius
}

func main() {
    var c Circle
    c.radius = 4.0
    res := c.area()          // 50.24
    fmt.Println("面积是", res)
}
```

       * `c.radius` 取的是 area 栈里那份 `c` 的字段，不是 main 栈里的，尽管值一样。

       * 方法返回后它自己的数据空间销毁，主函数执行完毕后内存全部释放。

       * > **易错点**：两个 `c` 是两份独立数据，不是同一个。这个细节不清楚，看别人项目代码时就会处处产生歧义。

## 方法的五个细节

   * **结构体是值类型**

       * 结构体类型是值类型，方法调用时遵守值类型的传参规则，做值拷贝。

   * **想改结构体就绑指针**

       * 要在方法中修改结构体变量的值，就通过结构体指针来处理；工程上通常更多地绑定结构体指针类型。

       * 原因是绑值类型要拷贝整个结构体，绑指针类型只拷一个地址，传输效率更高。

```go
func (c *Circle) area2() float64 {
    return 3.14 * c.radius * c.radius
}

var c Circle
c.radius = 5.0
res2 := (&c).area2()      // 78.5，标准写法
res2 = c.area2()         // 等价写法
```

       * 标准访问字段写法是 `(*c).radius`，写 `c.radius` 是编译器自动加取地址后的等价形式。

       * 在方法里改 `c.radius`，外面的 `c` 会跟着变，因为传进来的是地址而不是整个结构体的副本。

       * > **提示**：写法一样、机制已变。形式上相同，底层机制已经完全不同，这就是编译器优化带来的迷惑。

```text
值接收者（默认）                     指针接收者
main 栈                              main 栈
+----------------------------+       +----------------------------+
| c --> [ radius : 6.0 ]     |       | c --> [ radius : 6.0 ]     |
+----------------------------+       +-------------+--------------+
         |                                       |
         |  值拷贝（两份，互不影响）              | 地址拷贝（同一份）
         v                                       v
area2 栈                             area2 栈
+----------------------------+       +----------------------------+
| c --> [ radius : 6.0 ]     |       | c : (只存一个地址)          |
+----------------------------+       +----------------------------+
方法里改 c.radius，外面不变           方法里改 c.radius，外面跟着变
```

   * **方法也能挂在非结构体的自定义类型上**

```go
type integer int

func (i integer) print() {
    fmt.Println("i =", i)
}

func (i *integer) change() {
    *i = *i + 1
}
```

       * `var i integer; i = 10; i.print()` 输出 `i = 10`，方法照样能挂在整数类型上。

       * `i.change()` 之后 `i` 变成 `11`，因为指针接收者做的是地址拷贝，修改直接作用于原变量。

   * **方法名的首字母决定外部能不能调**

       * 与函数的访问控制一致：首字母小写只能在本包访问，首字母大写则本包和其他包都能访问。

   * **实现了 String，fmt.Println 会自动调用**

```go
type Student struct {
    Name string
    Age  int
}

func (stu *Student) String() string {
    str := fmt.Sprintf("Name=[%v] Age=[%v]", stu.Name, stu.Age)
    return str
}
```

       * 用指针接收者实现，输出时传 `&stu`，结果是 `Name=[tom] Age=[20]`。

       * 不传地址直接传 `stu` 不会调用 `String`，会按默认方式把结构体字段打出来。

       * 没有实现 `String` 时输出的只是地址，实现了就用 `String` 完成输出。

## 方法的四种基础形态

   * **不接参数也不返回值**

```go
func (p Person) speak() {
    fmt.Println(p.Name, "是一个goodman")
}
```

       * 调用 `p.speak()` 直接打印，最简单的方法形态。

   * **不接参数但方法体内可以运算**

```go
func (p Person) jisuan() {
    res := 0
    for i := 1; i <= 1000; i++ {
        res += i
    }
    fmt.Println(p.Name, "计算的结果是=", res)
}
```

       * 结果是 `500500`；方法体内加减乘除、取模都可以，和函数一样。

       * 接收者也可以完全不用，只为了标明是谁算的才把名字打出来。

   * **接收参数**

```go
func (p Person) jisuan2(n int) {
    res := 0
    for i := 1; i <= n; i++ {
        res += i
    }
    fmt.Println(p.Name, "计算的结果是=", res)
}
```

       * `p.jisuan2(10)` 结果是 `55`；要接收多个参数在后面照常并列写。

   * **有返回值**

```go
func (p Person) getSum(n1 int, n2 int) int {
    return n1 + n2
}

res := p.getSum(10, 20)   // res = 30
fmt.Println("res=", res)
```

       * 有返回值时调用方必须准备一个变量接收；多个返回值就用括号括起来。

       * 接收者在这个方法里完全没用到也不会报错，用不用都行。

## 方法与函数的区别

   * **调用方式不同**

       * 函数直接用函数名传实参调用。

       * 方法必须先有一个绑定类型的变量，再用这个变量调用。

   * **普通函数的形参类型必须严格对应**

       * 普通函数接收值类型就不能传指针，接收指针类型就必须传指针，反之亦然。

```go
func test01(p Person)  { fmt.Println(p.Name) }
func test02(p *Person) { fmt.Println(p.Name) }

p := Person{"tom"}
test01(p)        // 正确，输出 tom
test01(&p)       // 报错
test02(&p)       // 正确，输出 tom
test02(p)        // 报错
```

   * **方法由接收者类型说了算**

       * 接收者是值类型可以直接用指针变量调用，反过来接收者是指针类型也可以用值变量调用。

       * `(&p).test03()` 形式上传了地址，本质仍是值拷贝，方法内改 `p.Name` 不影响外部。

       * `p.test04()` 形式上传的是值，本质仍是地址拷贝，方法内改 `p.Name` 外部跟着变。

       * | 场景 | 写法 | 结果 |
         | --- | :--- | :--- |
         | 普通函数，形参为值 | `test01(p)` | 正确 |
         | 普通函数，形参为值 | `test01(&p)` | 报错 |
         | 普通函数，形参为指针 | `test02(&p)` | 正确 |
         | 普通函数，形参为指针 | `test02(p)` | 报错 |
         | 方法绑值类型 | `p.test03()` | 正确，值拷贝 |
         | 方法绑值类型 | `(&p).test03()` | 正确，本质仍是值拷贝 |
         | 方法绑指针类型 | `(&p).test04()` | 正确，地址拷贝 |
         | 方法绑指针类型 | `p.test04()` | 正确，本质仍是地址拷贝 |

       * > **结论**：是值拷贝还是地址拷贝，只看方法绑的是值类型还是指针类型，跟调用处怎么写无关。

       * > **易错点**：面试常问「通过这个方法改了字段，外面那个变量变没变」，90% 的人会说变了，其实没变，因为接收者写的是值类型。

## 面向对象编程三部曲

   * **三个步骤**

       * | 步骤 | 做什么 | 要点 |
         | --- | :--- | :--- |
         | 第一步 | 声明结构体 | 把结构体的名称确定下来 |
         | 第二步 | 编写结构体字段 | 根据需求把字段及字段类型定下来 |
         | 第三步 | 编写结构体方法 | 确定它有哪些方法 |

       * 完整顺序是：先定义结构体，确定字段，再写方法，最后调用。

   * **学生信息一句话输出**

```go
type Student struct {
    Name   string
    Gender string
    Age    int
    Id     int
    Score  float64
}

func (student *Student) say() string {
    info := fmt.Sprintf("student的信息 name=[%v] gender=[%v] age=[%v] id=[%v] score=[%v]",
        student.Name, student.Gender, student.Age, student.Id, student.Score)
    return info
}
```

       * 给值换行时逗号保留在上一行，每一行都要有逗号，包括最后一行。

   * **盒子体积**

```go
type Box struct {
    len    float64
    width  float64
    height float64
}

func (box *Box) getVolume() float64 {
    return box.len * box.width * box.height
}
```

       * 长宽高都用 `float64`，体积是三者相乘；结构体字段之间不需要打逗号。

       * > **提示**：字段名 `width` 容易少敲一个字母变成 `dth`，编译器会第一时间指出来。

   * **景区门票**

```go
type Visitor struct {
    Name string
    Age  int
}

func (visitor *Visitor) showPrice() {
    if visitor.Age >= 90 || visitor.Age <= 8 {
        fmt.Println("考虑到安全，不要玩耍")
        return
    }

    if visitor.Age > 18 {
        fmt.Printf("游客的名字为 %v 年龄为 %v 收费 20元\n", visitor.Name, visitor.Age)
    } else {
        fmt.Printf("游客的名字为 %v 年龄为 %v 免费\n", visitor.Name, visitor.Age)
    }
}
```

       * 年龄 `>= 90` 或 `<= 8` 直接 `return`，方法没有返回值所以是裸 `return`。

       * 大于 18 收费 20 元，其余情况免费。

```go
var v Visitor
for {
    fmt.Println("请输入你的名字")
    fmt.Scanln(&v.Name)
    if v.Name == "n" {
        fmt.Println("退出程序")
        break
    }

    fmt.Println("请输入你的年龄")
    fmt.Scanln(&v.Age)

    v.showPrice()
}
```

       * `Scanln` 要传地址 `&v.Name`、`&v.Age`；方法绑在 `*Visitor` 上，循环里赋的字段能被方法直接读到。

## 结构体实例的八种写法

   * **方式一：创建结构体本身**

       * 按字段顺序直接赋值：

         ```go
         var stu1 = Student{"小明", 18}
         stu2 := Student{"小明~", 20}
         ```

       * 把字段名和字段值写在一起：

         ```go
         var stu3 = Student{
             Name: "jacky",
             Age:  20,
         }

         stu4 := Student{
             Age:  30,
             Name: "mary",
         }
         ```

       * 按位置赋值完全依赖字段的定义顺序，顺序一调整所有按位置写的代码都会错位。

       * 类型不同时编译器会在类型层面拦下来；字段类型碰巧相同时就只能靠眼睛看。

       * > **易错点**：带字段名的写法不依赖字段顺序，结构体字段顺序变化后这段代码依然正确，这才是真正该用的写法。

       * 四个实例一起输出得到 `{小明 18} {小明~ 20} {jacky 20} {mary 30}`。

   * **方式二：创建结构体的指针**

       * 在方式一每种写法前面各加一个 `&`：

         ```go
         var stu5 *Student = &Student{"小王", 29}
         stu6 := &Student{"小王~", 39}
         var stu7 = &Student{
             Name: "小李",
             Age:  49,
         }
         stu8 := &Student{
             Age:  19,
             Name: "小李~",
         }
         ```

       * 指针变量不写类型也可以，编译器会自动判断出它就是一个指针。

       * > **易错点**：方式一是把结构体本身赋给变量，方式二是把结构体的指针赋给变量，两者完全不是一回事。

```text
方式一：变量直接指向数据空间
   stu1 ─────────────────────► [ Name="小明" | Age=18 ]


方式二：变量先存一个地址，再由地址指向数据空间
   stu5 ──► 0xADDR ─────────► [ Name="小王" | Age=29 ]
          ↑
    这里多出来的一层，就是 & 造出来的
```

       * 用起来感觉没差别，是因为编译器把 `Student` 和 `*Student` 的字段访问合并处理了。

       * 直接打印指针会每个前面多一个 `&`，得到 `&{小王 29} &{小王~ 39} &{小李 49} &{小李~ 19}`。

       * 加取值符号 `*stu5` 后地址符消失，输出又变回 `{小王 29}`。

## 工厂模式

   * **Go 没有构造函数**

       * > **定义**：Go 的结构体没有构造函数，获取实例通常用工厂模式解决，工厂模式相当于以前构造函数的功能。

       * 结构体首字母大写时，导入所在包后可以直接在其他包创建实例，没有任何问题。

       * 首字母改成小写后在别的包就创建不了实例，报 `cannot refer to unexported name`，即不可导出。

       * 现实需求是既想让名称首字母小写保住封装性，又想在别的包创建实例，这就需要工厂模式。

   * **用工厂方法开一个入口**

```go
package model

type student struct {
    Name  string
    Score float64
}

func NewStudent(n string, s float64) *student {
    return &student{
        Name:  n,
        Score: s,
    }
}
```

       * 本包使用自己的小写 `student` 完全没有问题，返回出去的是指针。

       * 调用方直接 `stu := model.NewStudent("tom~", 88.8)` 就拿到了实例，`NewStudent` 首字母大写因而公开可调。

       * 跨包导入要从 `src` 目录下面一级一级写，斜杠方向不能反；忘了引包报 `undefined: Student`，引了没用报 `imported and not used`。

       * 跨包运行要走到 `main` 包目录，执行的路径是 `go run main/main.go`。

   * **小写字段用取值方法封装**

       * 字段首字母改成小写后，外部访问报 `has no field or method Score, but does have score`；改成小写访问又报 `stu.score undefined (cannot refer to unexported field score)`。

```go
// GetScore 对外公开，取出内部私有的 score 字段
func (s *student) GetScore() float64 {
    return s.score
}
```

       * `GetScore` 首字母大写所以能在别处被调用，方法体运行在定义它的包里，所以能合法访问 `s.score`。

       * 调用方拿值：`fmt.Println(*stu)` 去掉地址符，`stu.GetScore()` 正常拿到成绩。

       * 这就是 Go 里的封装写法，后面会大量遇到。

## 标识符可见性

   * **可见性以包为单位**

       * 只要代码位于定义它的包内部，标识符首字母大写还是小写都能直接访问。

       * 跨包访问时只有首字母大写的标识符才可见，结构体类型名、字段名、方法名适用同一规则。

       * 工厂方法返回 `*student`，取值方法必须绑在指针接收者上，`stu` 才能调到它。

   * **指针访问字段的简化**

       * 标准写法是 `(*stu).Name`，写 `stu.Name` 是因为编译器底层对指针访问字段默认加了取值操作。

       * 指针接收者拿到的是地址拷贝，方法体内的标准写法是 `(*s).score`，写成 `s.score` 是等价形式。

## 方法练习题

   * **不带参数的图形与面积**

```go
type MethodUtils struct {
}

func (mu MethodUtils) print() {
    for i := 1; i <= 10; i++ {
        for j := 1; j <= 8; j++ {
            fmt.Print("*")
        }
        fmt.Println()
    }
}

func (mu MethodUtils) print2(m int, n int) {
    for i := 1; i <= m; i++ {
        for j := 1; j <= n; j++ {
            fmt.Print("*")
        }
        fmt.Println()
    }
}

func (mu MethodUtils) area(len float64, width float64) (float64) {
    return len * width
}
```

       * 外层循环控制行数、内层控制列数，打完一行用 `Println` 换行。

       * `mu.print2(2, 6)` 打成 2 行 6 列，`mu.print2(5, 20)` 打成 5 行 20 列。

       * `mu.area(2.5, 8.7)` 返回 `21.75`；只有一个返回值时括号写不写都行。

       * > **结论**：方法对应的结构体可以一个字段都没有。

func (mu *MethodUtils) judgeNumber(number int) {

func (mu *MethodUtils) print3(n int, m int, key string) {

   * **计算器加减乘除**

       * 分四个方法实现：

         ```go
         type Calculator struct {
             Num1 float64
             Num2 float64
         }

         func (cal *Calculator) getSum() float64 {
             return cal.Num1 + cal.Num2
         }

         func (cal *Calculator) getSub() float64 {
             return cal.Num1 - cal.Num2
         }
         ```

       * 一个方法用 `switch` 实现：

         ```go
         func (cal *Calculator) getResult(operator byte) float64 {
             var res float64
             switch operator {
             case '+':
                 res = cal.Num1 + cal.Num2
             case '-':
                 res = cal.Num1 - cal.Num2
             case '*':
                 res = cal.Num1 * cal.Num2
             case '/':
                 res = cal.Num1 / cal.Num2
             default:
                 fmt.Println("运算符输入有误")
             }
             return res
         }
         ```

       * 运算符类型用 `byte`；结果先给默认值 `0.0`，输入有误时保留 `0.0` 返回。

       * `Num1` 为 1.2、`Num2` 为 2.2 时，加得 `3.4`、减得 `-1.0`、乘得 `2.64`。
