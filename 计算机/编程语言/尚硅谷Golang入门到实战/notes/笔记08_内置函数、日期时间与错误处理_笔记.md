# 内置函数、日期时间与错误处理

## 系统函数与内置函数

* **系统函数**

    * > **定义**：系统函数是 Golang 的设计者事先给我们准备好的——他认为我们经常要用到的东西已经封装成一个函数，不需要我们再写。

    * 字符串在程序中使用得非常频繁，常用的字符串函数一共 21 个，分布在 `strconv`、`strings` 等包里。

* **内置函数（内建函数）**

    * > **定义**：`len`、`make`、`copy`、`delete`、`close`、`panic`、`recover`、`print` 这类叫内置函数，不在任何包里，不需要引包直接就能用。

    * 在手册里搜 `builtin` 就能查到全部内置函数。

* **len 返回的是字节数**

    * > **定义**：`len` 返回传入值的长度，长度取决于具体类型，最常用的就是计算字符串或数组的长度。

      ```go
      str := "hello"
      fmt.Println("str length=", len(str)) // 5

      str2 := "hello北京"
      fmt.Println("str2 length=", len(str2)) // 8
      ```

    * 字母、数字这类 ASCII 码字符占一个字节；Golang 的编码是 UTF-8，**一个汉字占三个字节**，所以 `5 + 3 = 8`。

    * > **结论**：`len` 是按字节返回的；如果按字符返回应该是 6。

    * `len` 除了统计字符串，也可以统计数组的大小。

* **遍历含中文的字符串先转 rune 切片**

    * 字符串含中文时直接按下标遍历会乱码，因为它是按字节取、一个汉字被截成了三段。

      ```go
      str2 := "hello北京"

      r := []rune(str2)
      for i := 0; i < len(r); i++ {
          fmt.Printf("字符=%c\n", r[i])
      }
      ```

    * `[]rune(str2)` 把字符串转成 `rune` 切片，转完后循环代码不用变，中文就能正常输出。

    * > **易错点**：不能写成 `str := []rune(str2)`，`str` 这个名字已经定义成字符串、数据类型已经定了，再转成 `rune` 切片会类型不匹配；换一个名字（如 `r`），下面循环那里也要一起换成 `r`。

* **new 与 make**

    * > **定义**：内建函数 `new` 分配内存，其第一个实参为**类型**，返回值是指向该类型的新分配的零值的指针。

    * 普通赋值是一个变量直接关联到存数据的空间：

      ```text
              num1  (类型 int)
              ┌────────────────────────┐
              │   值 = 100             │
              │   地址 = 0xc000010250  │   ← &num1 就是这个地址
              └───────────┬────────────┘
                          │  变量直接关联到存放数据的那块空间
                          ▼
              ┌────────────────────────┐
              │          100           │
              └────────────────────────┘
      ```

    * `num2 := new(int)` 则是**一层一层套下来**的：

      ```text
         num2  (类型 *int)
         ┌──────────────────────────────────────────┐
         │  值  = 0xc000010250  ← 它本身就是地址   │
         │  地址 = 0xc0000160b0  ← &num2           │
         └───────────────────┬──────────────────────┘
                             │ num2 指向这里
                             ▼
             ┌──────────────────────────────────┐
             │  存放的内容 = 0xc000010250        │ ← 也是一个地址
             │  这块空间的地址 = 0xc0000160b0    │
             └───────────────────┬──────────────┘
                                 │ 这个地址又指向
                                 ▼
             ┌──────────────────────────────────┐
             │              0                   │ ← new 分配的零值
             └──────────────────────────────────┘
      ```

    * > **定义**：`new` 做的事情可以概括成两段——先分配一块空间装上该类型的零值，再分配一块空间把这个地址放进去，然后让变量指向这块空间。

    * `num2` 的类型是 `*int`，它的值是它指向的那个空间的地址，`&num2` 是它自身的地址，最终指向的空间里默认是 `0`。

    * 用 `*num2 = 100` 就能改掉它指向的值；改完之后两处地址和 `num2` 的类型都不会变，它始终是 `*int`。

    * > **易错点**：打印出的地址每次运行都可能不一样，这是正常的——地址由系统分配，程序员没办法指定它分配到某个地方。

    * `new` 主要是给**值类型**分配内存（`int`、`float32`，后面还有 `struct`）；`make` 同样能分配内存，但主要是给**引用类型**分配，比如 `channel`、`map`、`slice`。

## 字符串常用函数

* **字符串与整数互转**

    * > **定义**：`strconv.Atoi` 把字符串转成 `int`；转不成功时会返回一个 `error`，可以据此做校验。

      ```go
      n, err := strconv.Atoi("123")
      if err != nil {
          fmt.Println("转换错误，错误的原因是：", err)
      } else {
          fmt.Println("转换的结果是：", n)
      }
      ```

    * `nil` 是零值，`err != nil` 就说明转换失败；`"hello"` 转不了，错误信息是 `invalid syntax`。

    * > **提示**：利用这个特性可以做数据类型校验，比如要求用户输入数字字符串，他不输就验证出来并给出提示。

    * > **定义**：`strconv.Itoa` 把整数转成字符串，必定能转所以没有 `err`。

      ```go
      str := strconv.Itoa(12345)
      fmt.Printf("值=%v 类型=%T\n", str, str) // 值=12345 类型=string
      ```

* **字符串与字节切片互转**

    * `b := []byte("hello")` 把字符串转成 byte 切片，常用于把字符串写进二进制文件；输出的是对应的 ASCII 码值 `104 101 108 108 111`。

    * `str := string([]byte{97, 98, 99})` 把字节切片转成字符串，输出 `abc`——因为 `'a'`、`'b'`、`'c'` 的 ASCII 码值分别是 97、98、99。

* **进制转换**

    * > **定义**：`strconv.FormatInt` 把一个 `int64` 的值按指定 `base` 转成字符串，`base` 可以写 2、8、16。

      ```go
      str := strconv.FormatInt(123, 2)
      fmt.Printf("123对应的二进制=%v\n", str)   // 1111011

      str = strconv.FormatInt(123, 16)
      fmt.Printf("123对应的十六进制=%v\n", str) // 7b
      ```

    * 要八进制把 `16` 改成 `8` 即可。

* **查找子串与统计次数**

    * > **定义**：`strings.Contains` 判断字符串 `s` 是否包含子串 `substr`，包含返回真，否则返回假。

      ```go
      b := strings.Contains("seafood", "foo")  // true
      b = strings.Contains("seafood", "mary") // false
      ```

    * > **易错点**：第一次写时报错是因为没有引 `strings` 包，用了新包就必须先引进来。

    * > **定义**：`strings.Count` 统计字符串 `s` 中有几个指定的子串。

      ```go
      var str string = "cheese"
      var count = strings.Count(str, "e") // 4
      ```

    * 找 `"se"` 返回 1，找 `"u"` 返回 0；可以用来统计一篇文章里某个关键词出现了几次。

* **字符串比较**

    * | 写法 | 是否区分大小写 | `"abc"` 与 `"Abc"` 的结果 |
      | :--- | :--- | :--- |
      | `a == b` | 区分 | `false` |
      | `strings.EqualFold(a, b)` | 不区分 | `true` |

    * 两个等号要求内容和字母大小写都相同才为真；`strings.EqualFold` 不区分大小写。

    * 做密码校验时可以据此选择：要区分大小写就用等号，不区分就用 `EqualFold`。

* **查找位置与替换**

    * > **定义**：`strings.Index` 返回子串在字符串中第一次出现的下标，没有则返回 -1。

      ```go
      index := strings.Index("NLT_abc", "abc") // 4
      ```

    * 因为没有时返回 -1，所以它也能顺带判断串里有没有这个子串；找最后一次出现用 `strings.LastIndex`。

      ```go
      index := strings.LastIndex("go golang go", "golang") // 3
      ```

    * > **定义**：`strings.Replace` 把指定的子串替换成另一个子串，最后一个参数 `n` 指定要替换几个，`-1` 表示全部替换。

      ```go
      str := strings.Replace("go go hello", "go", "北京", 1)   // 北京 go hello
      str = strings.Replace("go go hello", "go", "北京", -1) // 北京 北京 hello
      ```

    * 要换两个就把 `n` 写成 2；这个位置也可以传一个字符串变量，不一定非得是常量。

    * > **结论**：替换完**原串不变**，返回的是一个替换后的新串。

* **拆分与大小写转换**

    * > **定义**：`strings.Split` 按指定的字符把字符串拆分成字符串数组。

      ```go
      str := "hello,world,ok"
      strArr := strings.Split(str, ",")
      fmt.Printf("len=%v\n", len(strArr)) // 3
      ```

    * 拆出 `hello`、`world`、`ok` 三个元素，下标分别是 0、1、2；分隔符也可以传字符串变量。

    * 和 `Replace` 一样，`Split` **不会改变原字符串**，它拿到的是值拷贝，得到的是一个新数组。

    * `strings.ToLower` 全部转小写、`strings.ToUpper` 全部转大写：

      ```go
      str := "goLang Hello"
      str = strings.ToLower(str) // golang hello
      str = strings.ToUpper(str) // GOLANG HELLO
      ```

    * > **易错点**：`Replace` 和 `Split` 把结果交给**新变量**时原串不变；而 `ToLower`/`ToUpper` 如果把返回值**直接交回原来的变量名**，原变量就被改变了——就看你怎么用。

* **修剪空白与前后缀判断**

    * > **定义**：`strings.TrimSpace` 去掉字符串左右两边的空格。

      ```go
      str := "   hello   "
      str = strings.TrimSpace(str)
      fmt.Printf("str=%q\n", str) // "hello"
      ```

    * 用 `%q` 会用一对双引号把它引起来打印，两边有没有空格看得更清楚。

    * > **定义**：`strings.Trim` 去掉字符串左右两边**指定的**字符，第二个参数写上要去掉哪些字符。

      ```go
      str := " ! hello ! "
      str = strings.Trim(str, " !")
      fmt.Printf("str=%q\n", str) // "hello"
      ```

    * > **易错点**：`Trim` 只去左右两边的，**中间的去不掉**；只写 `" "` 就相当于只去掉左右两边的空格，前面的叹号会保留。

    * 只去左边用 `strings.TrimLeft`，只去右边用 `strings.TrimRight`。

    * > **定义**：`strings.HasPrefix` 判断字符串是否以某个字符串开头，`strings.HasSuffix` 判断是否以指定的字符串结尾，符合返回 `true`，否则返回 `false`。

      ```go
      b := strings.HasPrefix("ftp://abc.com", "ftp")   // true
      b = strings.HasPrefix("http://abc.com", "ftp") // false
      ```

## 时间和日期函数

* **time 包与 Time 类型**

    * > **定义**：Golang 里时间和日期相关的函数都放在 `time` 包中，该包提供时间的显示和测量用的函数。

    * > **定义**：`Time` 类型（`time.Time`）是 `time` 包里定义的、专门用于表示时间的数据类型。

    * > **定义**：`time.Now()` 返回当前时间，类型是 `time.Time`。

      ```text
      2019-05-18 10:14:15.123456789 +0800 CST m=+0.000000001
      ```

    * 输出后面带了一堆时区和纳秒数，实际使用时往往要再做处理。

    * `Time` 本身是一个结构体，手册里能看到它有很多方法：`Unix`、`UnixNano`、`Equal`、`Before`、`After`，以及 `Year`、`Month`、`Day`、`Hour`、`Minute`、`Second`。

* **取年月日时分秒**

      ```go
      fmt.Printf("年=%v\n", now.Year())
      fmt.Printf("月=%v\n", now.Month())
      fmt.Printf("日=%v\n", now.Day())
      fmt.Printf("时=%v\n", now.Hour())
      fmt.Printf("分=%v\n", now.Minute())
      fmt.Printf("秒=%v\n", now.Second())
      ```

    * `now.Month()` 返回的是英文的 `May`，用 `int(now.Month())` 强转一下就得到数字 `5`。

* **格式化的两种方式**

    * 方式一是直接用 `Printf` 输出；想拿到字符串就用 `Sprintf`——`Sprintf` 返回字符串，`Printf` 直接输出。

      ```go
      dateStr := fmt.Sprintf("当前年月日 %d-%d-%d %d:%d:%d",
          now.Year(), now.Month(), now.Day(),
          now.Hour(), now.Minute(), now.Second())
      ```

    * 函数比较长时允许换行，但换行时上一行末尾一定要留逗号；间隔符可以自己设，中划线、空格都行。

    * > **易错点**：这里必须用 `Sprintf`，不能写成 `printf`，因为要的是格式化之后的结果字符串。

    * 方式二是用 `time.Time` 自己提供的 `Format` 方法：

      ```go
      timeStr := now.Format("2006-01-02 15:04:05")
      fmt.Printf("timeStr=%v\n", timeStr)
      ```

    * > **结论**：这个 layout 是**基于一个参考时间**定义的——2006 年、1 月、2 日、15 时、04 分、05 秒；各数字都不重复，所以才能区分得开，`"01"` 是月、`"2006"` 是年。

    * 可以自由组合：只想要年月日写 `"2006-01-02"`，只想要时分秒写 `"15:04:05"`，只想要月份写 `"01"`。

* **时间常量**

    * > **定义**：这些常量都是 `time` 包里 `Duration` 类型下的常量，`Duration` 表示两个时间点之间经过的时间。

      | 常量 | 对应的时间单位 |
      | :--- | :--- |
      | `time.Hour` | 小时 |
      | `time.Minute` | 分钟 |
      | `time.Second` | 秒 |
      | `time.Millisecond` | 毫秒 |
      | `time.Microsecond` | 微秒 |
      | `time.Nanosecond` | 纳秒 |

    * 换算关系：1 小时 = 60 分钟，1 分钟 = 60 秒，1 秒 = 1000 毫秒，1 毫秒 = 1000 微秒，1 微秒 = 1000 纳秒，纳秒是最小的单位。

    * 用来让程序休眠的场景：

      ```go
      var i int = 0
      for {
          i++
          fmt.Println(i)
          // 休眠
          time.Sleep(time.Second)
          if i == 100 {
              break
          }
      }
      ```

    * > **易错点**：`time.Second` 是整型常量，`time.Second * 0.1` 一做运算就变成浮点数，而 `Sleep` 要的 `Duration` 是整型，浮点数压根传不进去。

    * 这也正是 Go 要摆出这一整套时间常量的原因：需要表达一个时长时，永远在挑一个合适的整数单位去乘，而不是拿现成的秒去做四则运算。

    * 0.1 秒等于 100 毫秒，换个单位写就顺了：`time.Sleep(100 * time.Millisecond)`。

* **Unix 时间戳与纳秒时间戳**

    * > **定义**：`Unix()` 返回从 1970 年 1 月 1 日 UTC 那一刻到当前时间经过的**秒数**；`UnixNano()` 返回同一段距离，单位换成**纳秒**。

      ```go
      now := time.Now()
      fmt.Printf("unix时间戳=%v unix纳秒时间戳=%v\n", now.Unix(), now.UnixNano())
      ```

    * 秒级时间戳是个十来位的整数，纳秒级的那个数大得多、末尾几位每次刷新都在跳。

    * > **结论**：拿时间戳当随机种子是非常常见的写法——不设置随机种子时每次拿到的随机数都一模一样，用 Unix 甚至 Unix 纳秒时间戳当种子就能拿到每轮都不同的值。

* **用时间戳给函数计时**

      ```go
      func test03() {
          str := ""
          for i := 0; i < 100000; i++ {
              str += "hello" + strconv.Itoa(i)
          }
      }

      func main() {
          // 在执行 test03 前，先获取到当前的 unix 时间戳
          start := time.Now().Unix()
          test03()
          end := time.Now().Unix()
          fmt.Printf("执行 test03 耗费时间为 %v 秒\n", end-start)
      }
      ```

    * 要领是在调用前后各取一次时间戳，相减就是耗时；`strconv.Itoa` 把整数转成字符串，这里每循环一次就在 `str` 后面接一段 `"hello"` 加上 `i` 的字符串形式。

    * 这套用法可以直接迁到判断排序方法快不快、网络爬虫抓一页内容耗时多少等场景。

    * > **提示**：想要更精准就把前后都换成 `UnixNano()`，相减得到纳秒数，粒度会细很多。

    * 这也是面试或选人时一个客观标准：让两三个候选人各写一个函数，用这套方式跑一遍，谁的代码更高效一目了然。

## 错误处理

* **panic 的默认行为**

    * 除以零是最简单的反例：`res := num1 / num2` 在 `num2` 为 0 时，错误原因直接报 `integer divide by zero`，紧接着就是一个 `panic`。

    * 运行器会同时报出两处行号——出错的那一行和调用它的那一行，说明从调用处进入、在出错处炸掉。

    * > **定义**：`panic` 字面意思是"恐慌"，在 Go 里代表一种**致命的错误**——一旦触发，程序直接退出、崩溃，后面所有代码都不再有机会执行。

    * 但很多时候想要的恰恰相反：即使这里出错也希望后面的代码继续执行，并且能给出一个预警机制。

* **不用 try-catch-finally**

    * Go 追求简洁优雅，不支持传统的 `try-catch-finally` 语法，认为这一套容易造成程序混乱。

    * Go 用的是三个关键字：`defer`、`panic` 和 `recover`。

    * > **结论**：发生错误时抛出 panic，在 `defer` 中通过 `recover` 这个内建函数捕获异常，再正常处理，三者结合使用。

* **defer 加 recover**

      ```go
      defer func() {
          err := recover() // recover() 内置函数，可以捕获到异常
          if err != nil {  // 说明捕获到错误
              fmt.Println("err=", err)
          }
      }()
      ```

    * 这段要放在会出错的那个函数**开头**。

    * `defer` 后面跟的是一条语句也可以是一个函数调用，这里写的是匿名函数加调用——匿名函数不需要参数也没有返回值，外层加一对括号直接执行。

    * 函数体里两件事：`err := recover()` 把捕获到的错误接到 `err` 上；`if err != nil` 判断是否捕获到错误。

    * 执行流程是 `defer` 把这个函数压进 defer 栈，等函数执行完毕或发生异常时调用它，把异常交给 `recover`，`recover` 拿到后再判断。

    * 加完这段后错误信息被打印出来，程序**继续往下走**，`main` 里后面的代码照样执行；换成循环加一秒休眠，效果就是下面的代码每隔一秒还在正常运行。

    * 两种写法完全等价：

      ```go
      defer func() {
          if err := recover(); err != nil {
              fmt.Println("err=", err)
          }
      }()
      ```

    * > **提示**：分开写逻辑更清晰，但合起来写也得会，因为 `if` 前面可以带一个语句。

* **错误处理带来的两个好处**

    * 第一个好处是进行错误处理后程序不会轻易挂掉。

    * 第二个好处是加入预警代码可以让程序更加健壮——在 `if err != nil` 分支里已经知道错误发生了，就可以在这里把错误信息发送给管理员（比如发邮件给 `admin@sohu.com`）。

    * 预警代码或通知代码应该写在 `recover` 判断出错误之后的那个分支里；至于怎么发邮件、发短信是后面要讲的其他技术。

* **自定义错误**

    * 需求有两个：错误信息由自己定义，发生错误之后主动放弃执行。

    * 有些错误是致命的，比如读取一个配置文件根本没读取到，下面代码执行还有什么意义，这时就适合用自定义错误。

    * > **定义**：`errors.New` 会返回一个 `error` 类型的值，仅此而已；`panic` 可以接收一个空接口类型的参数，自然也能接收 `error` 类型的变量，把错误信息输出出来并**退出程序、终止程序**。

      ```go
      func readConfig(name string) (err error) {
          if name == "config.ini" {
              // 读取...
              return nil
          } else {
              // 返回一个自定义错误
              return errors.New("读取文件错误..")
          }
      }

      func test02() {
          err := readConfig("config.ini")
          if err != nil {
              // 如果读取文件发生错误，就输出这个错误，并终止程序
              panic(err)
          }
          fmt.Println("test02()继续执行...")
      }
      ```

    * 返回列表里可以给变量名称，所以签名写成 `(err error)`；`nil` 就表示没有错误。

    * 文件名传对时返回 `nil`，判断不成立，`test02()继续执行...` 和 `main` 下面的代码都正常执行。

    * 文件名换成 `config2` 就走进 `else` 分支，返回自定义错误；`err` 不等于 `nil`，于是触发 `panic`。

    * > **易错点** ⚠️：`panic` 一执行程序就终止，`test02` 里"继续执行"那句和 `main` 下面那句都不会输出。

    * > **结论**：两套错误处理思路可以对照着记——走 `defer` + `recover` 是"程序不崩、继续往下跑"；走 `errors.New` + `panic` 是"错误信息我自己定义，并且我主动终止程序"。选哪一条取决于这个错误是不是致命的。
