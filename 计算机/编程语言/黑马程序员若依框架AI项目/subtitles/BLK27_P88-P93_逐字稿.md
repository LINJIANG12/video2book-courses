Hello，各位同学，既我们顺利完成设备屏幕端的功能测试，并了解了支付出货的流程之后，现在让我们把目光转向设备屏幕的 Java 后端源码。我将为大家简单介绍源码结构，方便各位老铁课下自学和阅读源码。

我们项目同样采用了主流技术栈，由 Spring Boot 作为后端框架，它为我们提供了快速开发的能力。MyBatis-Plus 作为数据访问层的工具，它简化了数据库的操作。

目前项目中仅实现了设备管理模块。这个模块的核心功能是根据设备编号获取售货机的商品列表，这是设备屏幕端正常工作的基础，也就是我们刚才在屏幕端 H5 页面查看的一个一个商品，还有它每一个售价。

下面带各位老铁简单看一下源码，回到 IDEA 当中。我们找到设备的 controller，把它打开，全屏一下。

兄弟们看一下，该方法就是来接收设备的编号，查询 `SkuVO`，也就是包装后的商品列表。具体的实现细节，我们来看一下 service，来找 service 的接口，我们再来看一下 service 的方法实现。

在该实现当中，我们先来看第一步，根据设备编号来查询商品列表。这里调用了 `baseMapper`。那什么是 `baseMapper` 呢？有没有知道的小伙伴们？其实这个 `baseMapper` 就是 `SkuMapper`。在 service 当中，我们这边可以叫做 `baseMapper`，调用了 `findSkuByInnerCode`。那么这个方法是我们自定义的 SQL 方法，咱们来看一下，按住 Ctrl 键，点击。

当前方法就是根据设备的编号来查询货道的商品信息，以及商品的库存总量。这里涉及到多表查询。首先第一张表，它查询的是商品表。紧接着，它关联查询了货道表。注意，这个货道表是作为一张虚拟表，将结果跟商品进行关联的。那么这张虚拟表做了什么事呢？咱们来分析一下，往右拉一下。

首先它根据设备编号来查询当前设备的所有货道信息，并判断一下 `sku_id > 0`。这大于 0 是什么意思？表示货道已经关联了商品，如果没有关联商品的话，默认值就是 0。也就是说通过前两个条件，我们就可以获取到指定设备关联商品的货道信息。然后根据 `sku_id` 进行分组，就是根据商品进行分组，拿到商品的 ID 和商品的库存容量。然后将这个返回的结果作为一张虚拟表，跟 sku 表进行内连接查询，那么就会返回商品的 ID、商品的名称、商品的图片、价格、商品类型的 ID、商品的单位（比如说净含量），还有商品的库存容量。

最后，我们根据商品的库存量进行了排序，库存量大的商品，排名就会靠前。那么这条 SQL 语句做什么事呢？给兄弟们简单画张图。

首先我们根据设备编号，统计了有关联商品的货道，比如说 1-1 关联商品冰红茶，2-1 也关联商品，同样的也是冰红茶。我们就会对同样的商品进行分组统计，获得这一个商品的信息，但库存量是这两个货道累加的和。比如说 1-1 的货道剩下 5 件，2-1 的货道剩下 7 件，那么我们统计后的结果冰红茶还剩下 12 件商品。在屏幕端，同一件商品我们只会显示一张图片，然后将所有商品库存量最高的排名靠前，我们优先让消费者购买库存最高的商品。这一点兄弟们能接受吧？具体效果稍后给兄弟们来进行演示。

Mapper 层我们就简单分析完了，再回到 service 当中。拿到商品以后，接下来我们根据设备编号来查询智能售货机。我们查询售货机的目的是来看看这哥们有没有关联的策略，就是这个 policy。首先我们给它设置一个初始化的折扣率，比如说 100%，表示无折扣，就是不打折。接下来我们需要判断一下，如果策略存在的话，折扣给它设置过来，比如说我们上小节设置的九折，那么这个 discount 就为 90 了。

拿到这个 90 以后，我们需要对所有商品进行遍历。遍历的目的是需要计算出商品的真实价格。所谓的真实价格，就是根据折扣率计算后的价格。这里我们可以拿到商品的原有价格乘以折扣率，比如说乘以 90，然后需要除以 100%，就可以拿到它的真实价格了。

拿到真实价格以后，我们需要做一个判断。如果真实的价格，也就是我们的实际价格小于原价格，那么我们就需要对 `SkuVO` 设置为打折的标记，否则设置不打折。这样的话，售货机的屏幕端就可以做出 CSS 样式，打折的商品我们可以给它增加特殊的标记，而没有打折的商品，咱们就原样输出即可。设置完毕以后，我们就返回 `SkuVO` 的 list 集合。返回结果以后，controller 就把数据响应到前端，那么屏幕的 H5 就可以展示商品列表了。这一点兄弟们能接受吧？

目前我们此设备的货道只关联了 1-1 到 1-6 的商品。那么接下来，我们给 2-1 关联一下康师傅冰红茶这件商品。关联以后，我们给它补上库存。此时这件商品的库存应该最高了，所以稍后我们在查询时，康师傅冰红茶的排序应该是排在第一位的。好的，给兄弟们玩一下。

回到帝可得管理系统，我们给最后一台设备的货道 2-1 来添加康师傅冰红茶，点击确定，同步到数据库当中。OK，已经关联商品了。
