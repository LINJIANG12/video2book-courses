# 数据分析：Pandas核心数据结构与清洗分组

## 库依赖与交互开发环境

### 依赖选型与安装规范

* **数据分析工具库（Python Data Analysis Library，Pandas）**

    * > **定义**：基于底层高性能多维数组构建的开源结构化数据分析与预处理第三方扩展库。

    * 底层依赖：核心计算与连续内存存储依托多维数组（NumPy ndarray）实现，在此之上封装标签化表格与序列体系。

    * 版本选型约束：官方版本 `3.0.1` 与轻量级前端框架 Streamlit 存在底层接口不兼容现象，技术选型锁定为兼容稳定的 `2.3.3` 版本。

    * 安装命令：在联网终端通过包管理工具执行精确版本约束安装 `pip install pandas==2.3.3`。

    * 模块导入规范：代码中遵循业内通行标准命名规范，将顶级模块导入并赋予别名 `import pandas as pd`。

### 交互开发环境特性与状态机制

* **表达式输出捕获（Expression Output Capturing）**

    * > **定义**：交互式笔记本单个单元格在执行完毕后默认仅捕获并渲染最后一行表达式求值结果的解释器特性。

    * 规则：在同一单元格内罗列多个变量或格式化字符串时，前序求值结果会被静默覆盖，控制台仅呈现末行内容。

    * 格式化精度：浮点型均值展示使用格式化后缀 `:.2f` 实现四舍五入保留两位有效小数。

    * > **易错点**：⚠️ 在单个单元格中若需完整输出多行运算结果，必须显式调用内置函数 `print()` 逐行包裹，否则前序计算结果将无法在界面展示。

* **数据显示配置（Display Options）**

    * > **定义**：控制数据表在交互式控制台中渲染行数与折叠阈值的全局运行时参数。

    * 全量展示配置：执行 `pd.set_option('display.max_rows', None)` 解除最大行数限制，强制展开数据表中的所有记录行。

    * 局部调试配置：执行 `pd.set_option('display.min_rows', 30)` 将截断折叠阈值调整为 30 行，在控制台中对称展现前 15 行与末尾 15 行。

* **常驻内核状态断裂（Kernel Context Reset）**

    * > **定义**：交互式运行环境依赖后台常驻进程（Kernel）维系内存变量，导致代码注释与执行状态不同步的运行机制。

    * 缓存留存行为：直接注释单元格中的配置代码并重新执行，无法抹除已写入解释器内存的运行时参数，重置环境必须手动关闭并重启内核（Restart Kernel）。

    * 依赖断裂异常：内核重启将彻底清空运行内存；若跳过顶部导入单元格直接单独触发下游分析单元格，将抛出 `NameError: name 'pd' is not defined`。

    * 恢复规则：重启内核后必须自顶向下按物理顺序依次执行前置依赖单元格，确保模块导入与数据表变量预先载入内存。

## 核心数据容器体系

### 二维数据表

* **二维数据表（DataFrame，df）**

    * > **定义**：由若干具备相同行索引的一维序列沿列轴向横向对齐拼接而成的二维表格型数据结构。

    * 物理组织维度：由横向延伸的记录行（Row）、纵向展开的业务属性列（Column）以及行标识（Index）共同构成。

    * 双重轴向约束：行方向对应 `axis=0`，向下延伸受行索引 `index` 约束；列方向对应 `axis=1`，横向展开受表头标签 `columns` 约束。

    * 默认索引规则：未显式指定自定义索引时，系统自动分配从 `0` 开始递增的非负整数序列（`0, 1, 2, ...`）。

    * 构造形态分类：

        | 构造方式 | 数据载体特征 | 列名判定来源 | 适用场景 |
        | :--- | :--- | :--- | :--- |
        | 列表嵌套字典 | 外层列表，内层元素为字典 | 自动提取内层各字典的键（Key）作为列标签 | 解析承接 Web API 或 NoSQL 返回的 JSON 列表 |
        | 字典嵌套列表 | 外层字典，各 Value 均为等长列表 | 字典的键直接映射为对应列标签 | 特征管道按列批量拼接组装 |
        | 二维列表结合 columns | 外层列表，内层为等长列表或元组 | 无法自动推断，必须显式传入 `columns=[...]` | 承接关系型数据库底层游标行记录集 |
        | 自定义 index 参数 | 任意构造形态中注入 `index=[...]` | 覆盖默认整数，绑定业务标签为行索引 | 以工号、日期、订单主键标识行的表格 |

* **表格结构探查属性（DataFrame Attributes）**

    * > **定义**：用于无侵入式检视二维数据表物理维度、标签与存储形态的只读实例属性集合。

    * 属性调用规则：均为数据表属性访问，调用时末尾严禁添加方法圆括号。

    * 核心属性特征：
        * `index`：返回包含当前行索引标签的序列对象，支持调用 `.tolist()` 转化为原生列表。
        * `columns`：返回包含当前所有列字段标签的 `Index` 对象，支持调用 `.tolist()` 转为原生列表。
        * `values`：剥离表头与行索引，返回底层纯数据矩阵，类型为 `numpy.ndarray`。
        * `size`：返回数据表内单元格标量元素的总物理个数，数值等于行数乘以列数。
        * `dtypes`：返回各列各自存储的数据类型映射；文本字符串因底层限制统一映射为通用对象类型 `object`，整型映射为 `int64`。
        * `shape`：返回二维几何维度的元组，格式固定为 `(行数, 列数)`。

### 一维序列

* **一维序列（Series，s）**

    * > **定义**：带有显式行索引标签且具备严格顺序结构的一维均质数据数组。

    * 容器依赖关系：属于独立的一维数据结构，既可作为二维数据表的构成列存在，亦可脱离二维表单独实例化与矢量化运算。

    * 实例化形态：
        * 基础列表构造：传入原生列表，系统自动绑定从 `0` 开始的默认整数索引。
        * 显式索引构造：传入数据列表的同时指定 `index=[...]` 绑定业务标签。
        * 字典转化构造：传入键值对字典，字典的键自动转为行索引，字典的值转为对应序列值。
        * 数据表抽取构造：从二维表中抽取特定单一字段，生成继承原表行索引的序列对象。

    * 核心属性表现：
        * `dtype`：以单数形式返回该序列的唯一数据类型（如 `dtype('int64')`），区别于数据表的复数形式 `dtypes`。
        * `shape`：返回单元素一维元组 `(行数,)`，第二维度留空，区别于数据表的二元元组。
        * `index`、`values`、`size`：分别返回该序列绑定的行索引对象、底层一维 NumPy 数组以及元素标量总数。

* **单列字段访问语法（Column Access Syntax）**

    * > **定义**：从二维数据表中垂直截取特定属性并降维为一维序列的表达式规则。

    * 字典键访问法：采用方括号包裹列名字符串 `df['列名']`，属于工程推荐的标准访问规范。

    * 属性点访问法：采用对象属性语法 `df.列名` 直接提取序列对象。

    * > **易错点**：⚠️ 生产开发中应避免使用 `df.列名` 语法。当字段名包含空格、特殊字符，或者与数据表内置属性及方法（如 `count`、`shape`、`size`）重名时，点语法会优先解析为内置成员导致数据访问失效；方括号语法 `df['列名']` 具备绝对的安全语法边界。

* **列向量化运算（Vectorized Arithmetic）**

    * > **定义**：依托底层 C 语言数组基于索引自动对齐并逐元素并行执行的数学运算机制。

    * 原生迭代对比：原生 Python 统计单科极值与均值需构建 `for` 循环遍历字典列表并维护中间临时列表，存在控制流与变量开销；Pandas 提取序列后直接调用内置算子 `.max()`、`.min()`、`.mean()` 即可一步完成向量化聚合。

## 数据输入输出与字段投影

### 外部文件输入输出接口

* **持久化交互接口规范（I/O API Specification）**

    * > **定义**：负责将外部介质数据反序列化为内存表格，或将内存表格状态序列化持久化至磁盘的成对方法族。

    * 方法命名法则：负责读取并实例化的外部加载器统一命名为模块顶级函数 `pd.read_<格式>()`；负责持久化写出的序列化工具统一命名为表格实例方法 `df.to_<格式>()`。

    * 常见交互格式对齐：

        | 场景介质 | 读取函数（Read） | 写入方法（To） | 底层驱动与依赖特征 |
        | :--- | :--- | :--- | :--- |
        | 逗号分隔纯文本 | `pd.read_csv()` | `df.to_csv()` | 内置解析引擎，无需额外驱动包 |
        | Excel 工作簿 | `pd.read_excel()` | `df.to_excel()` | 依赖外部解析引擎模块 `openpyxl` |
        | 结构化 JSON 串 | `pd.read_json()` | `df.to_json()` | 内置文本流解析引擎 |
        | 超文本表格标签 | `pd.read_html()` | `df.to_html()` | 解析 HTML 内部的 `<table>` 节点标签 |
        | 关系型数据库查询 | `pd.read_sql()` | `df.to_sql()` | 基于数据库连接游标执行查询与持久化 |

    * Excel 驱动缺失异常：调用 `pd.read_excel()` 或 `df.to_excel()` 操作 `.xlsx` 工作簿时，若环境缺少引擎驱动将抛出驱动缺失异常，需在终端执行 `pip install openpyxl` 补齐依赖。

### 字段投影与持久化参数控制

* **字段投射加载（Column Projection Loading）**

    * > **定义**：在物理数据读取阶段通过参数显式声明目标字段，丢弃冗余列以节约内存的优化机制。

    * 参数语法：在调用 `pd.read_csv()` 时传入参数 `usecols=['字段1', '字段2', ...]`。

    * 性能机理：未被声明的非关键列在底层文件流解析阶段即被丢弃，避免将全量庞大数据载入内存占用资源。

* **源头截断读取（Source Row Limiting）**

    * > **定义**：在文件解析阶段通过行数阈值限定读取规模以加速验证的参数。

    * 规则：在调用 `pd.read_csv()` 时传入参数 `nrows=n`，仅将外部数据源的前 `n` 行解析为数据表，降低巨型文件的磁盘 I/O 开销。

* **派生列广播机制（Derived Column Broadcasting）**

    * > **定义**：通过两个同维度列向量进行算术运算，生成全新业务列并挂载回原表的列扩展操作。

    * 语法示范：`df['销售金额'] = df['销售数量'] * df['单价']`。

    * 计算过程：系统依据相同行索引对齐两侧序列，在底层逐元素相乘，将计算结果封装为新序列挂载至数据表最右侧。

* **写出行索引控制（Index Persistence Control）**

    * > **定义**：控制是否将数据表内存行索引序号序列化持久化至外部文本文件的参数。

    * 默认写出缺陷：`df.to_csv()` 默认设置 `index=True`，会将无表头的行索引序号（`0, 1, 2...`）写出为文件第一列，导致 CSV 首行出现前置逗号 `,`，重读时退化为未命名列 `Unnamed: 0`。

    * 规范约束：在持久化纯业务流水至外部 CSV 时，必须显式声明 `df.to_csv('路径', index=False)` 剥离内存索引。

## 数据切片查询与条件过滤

### 宏观概览与切片选择机制

* **样本切片与结构信息探查（Data Inspection Methods）**

    * > **定义**：用于在不遍历全量数据的前提下快速验证表头映射、边界记录及数值分布的探查方法集。

    * `head(n=5)`：默认返回数据集的前 5 行记录，传入整数参数 `n` 可截取前 `n` 行，常用于核对表头对齐与字段映射。

    * `tail(n=5)`：默认返回数据集的末尾 5 行记录，传入整数参数 `n` 可截取末尾 `n` 行，常用于排查文件尾部截断、空行或汇总附录。

    * `describe()`：针对数值型列进行集中统计汇总，返回包含 8 项核心指标的汇总表：
        * `count`：各数值字段非空（Non-Null）有效记录的总行数。
        * `mean`：该列所有有效数值的算术平均值，衡量集中趋势。
        * `std`：样本标准偏差，衡量数据的离散波动程度。
        * `min` 与 `max`：物理极小值与极大值，用于排查负数单价或录入峰值等业务异常。
        * `25%`、`50%`、`75%`：下四分位数、中位数与上四分位数；中位数抗极端值干扰，各分位数反映排序后的物理位次分布。
        * 业务解读约束：纯数字构成的业务编码标识（如订单号）虽能计算出均值和分位数，但在业务上无统计意义，统计应聚焦物理度量字段。

    * `info()`：输出立体的表结构元数据，包含总行数、索引区间范围（如 `RangeIndex: 0 to 999`）、列序号、字段标签、非空有效计数（Non-Null Count）、各列底层物理类型（Dtype）及内存占用预估。

* **列选择降维规则（Column Slicing Rules）**

    * > **定义**：依据传入列标签的数据结构决定返回对象维度的语法规则。

    * 单列降维：传入单一字符串列名 `df['列名']`，数据结构降维并返回一维 `Series`。

    * 多列保维：传入由多个列名构成的嵌套列表 `df[['列1', '列2']]`，返回包含指定列子集的二维 `DataFrame`。

* **行切片选择机制（iloc 与 loc）**

    * > **定义**：基于物理行序号或表面索引标签进行水平数据提取的专用访问器。

    * 访问器机制对比：

        ```text
        +---------------------------------------------------------------+
        |                 iloc 与 loc 边界规则对比                       |
        +---------------------------------------------------------------+
        | 属性访问器 | 定位依据                       | 切片区间闭合规则 |
        +------------+--------------------------------+-----------------+
        | iloc       | 底层绝对物理行号 (0-indexed)   | 前闭后开 [a, b) |
        | loc        | 显式行索引标签 (Index Label)   | 两端皆闭 [a, b] |
        +---------------------------------------------------------------+
        ```

    * `iloc` 切片规则：语法为 `df.iloc[start:stop:step]`，仅认物理位置；无论表面索引是否为自定义字符串或乱序编码，均截取第 `start` 行至第 `stop-1` 行。

    * `loc` 切片规则：语法为 `df.loc[start_label:stop_label:step]`，依据显式标签检索；当且仅当数据表存在对应名称的索引时生效，起始标签与结束标签对应的行均被完整保留。

    * 自定义索引差异验证：使用 `index_col='订单号'` 加载数据表后，`df.iloc[0:5]` 正常返回前 5 行；而 `df.loc[0:5]` 会因无法找到名为 0 与 5 的索引标签而抛出 `KeyError`。

    * > **易错点**：⚠️ 当数据表采用系统默认的 `0, 1, 2...` 整数索引时，`df.loc[0:5]` 返回包含索引 0 到 5 的共 6 行数据，而 `df.iloc[0:5]` 仅返回物理第 0 到 4 行共 5 行数据。

### 条件过滤与复合逻辑组合

* **布尔条件过滤（Boolean Indexing）**

    * > **定义**：利用返回布尔型序列的逻辑表达式筛选数据表并仅保留结果为 `True` 的记录行的机制。

    * 基础语法骨架：$$\text{DataFrame}[\text{布尔条件表达式}]$$

    * 基础数值比较：直接使用原生比较运算符（`>`、`<`、`>=`、`<=`、`==`、`!=`）构建过滤条件，如 `df[df['销售数量'] >= 10]`。

* **集合与区间过滤方法（Membership and Interval Filtering）**

    * > **定义**：用于高效匹配离散枚举值集合或连续数值区间的高级序列过滤算子。

    * 离散集合过滤 `isin()`：传入包含候选值的列表，判定单元格值是否存在于集合中（等价于 SQL 的 `IN` 算子），语法为 `df[df['产品类别'].isin(['食品', '图书'])]`。

    * 连续区间过滤 `between()`：筛选落在数值上下界区间的记录行，语法为 `df[df['单价'].between(left, right, inclusive='both')]`。

    * 区间闭合参数 `inclusive` 取值规则：
        * `'both'`（默认值）：数学闭区间 $[left, right]$，两端边界均包含在内。
        * `'left'`：左闭右开区间 $[left, right)$，包含左侧最小值，排除右侧最大值。
        * `'right'`：左开右闭区间 $(left, right]$，排除左侧最小值，包含右侧最大值。
        * `'neither'`：纯开区间 $(left, right)$，两端边界数值均被严格排除。

* **多条件逻辑组合规则（Multiple Conditions Logic）**

    * > **定义**：将多个独立的布尔子条件通过逻辑运算符串联实现的复合数据过滤。

    * 逻辑与筛选：表示多条件同时成立，语法为 `df[(子条件1) & (子条件2)]`。

    * 逻辑或筛选：表示满足任一条件即成立，语法为 `df[(子条件1) | (子条件2)]`。

    * > **易错点**：⚠️ 复合过滤存在两大约束：连接符必须使用按位位运算符 `&` 与 `|`，严禁使用 Python 原生英文逻辑词 `and` 与 `or`；且每个独立子条件必须强制使用小括号 `()` 严格包裹。因 Python 中位运算符的优先级高于比较运算符，省略括号将导致比较算式先与相邻数值进行按位运算，进而破坏布尔逻辑并抛出 `TypeError` 或 `ValueError`。

## 数据清洗全流程

### 缺失值诊断与处置

* **缺失值占位符（Not a Number，NaN）**

    * > **定义**：在数据表与序列中表示浮点型及通用有效业务数据留白的专用系统占位符。

    * 产生根源：表单非必填项未输入、网络传输数据包丢弃、多表外连接未命中关联键等场景均会形成缺失。

* **缺失值探查（Missing Value Inspection）**

    * > **定义**：对全表单元格逐个执行非空校验并输出同形状布尔矩阵的诊断操作。

    * 诊断算子：调用 `df.isna()`（或功能等价的 `df.isnull()`），存在有效值处返回 `False`，检测到 `NaN` 空洞处返回 `True`。

* **缺失值物理剔除（Missing Value Dropping）**

    * > **定义**：将检测到缺失空洞的记录行或字段列物理移出当前数据集的清洗方法。

    * 语法方法：`df.dropna(axis=0)`。

    * 轴向控制行为：
        * 默认行剔除（`axis=0`）：在行方向（纵向）扫描，只要某一行内包含任意一个 `NaN`，整行数据被完全剔除。
        * 字段列剔除（`axis=1`）：在列方向（横向）扫描，只要某一列内存在缺失值，整列字段被完全抹除，保留所有行的其余有效数据。

    * 不可变性约束：`dropna()` 遵循函数式不可变设计，调用后不会原地修改原数据表，必须通过显式重新赋值 `df = df.dropna()` 或声明新变量接纳清洗结果。

* **缺失值填充推断（Missing Value Imputation）**

    * > **定义**：在保留完整记录行的前提下利用常数标量或相邻时序有效值修补数据空洞的操作。

    * 固定标量填充：调用 `df.fillna(value)` 将所有缺失处统一置换为业务占位符（如 `--`、类别标签）或均值、0 等数值。

    * 前向顺延填充：调用 `df.ffill()`（Forward Fill），缺失单元格自动沿用其物理上一行（前一个有效位置）的数值进行顺延填补。

    * 后向回溯填充：调用 `df.bfill()`（Backward Fill），缺失单元格自动抓取其物理下一行（后一个有效位置）的数值进行回溯填补。

* **缺失值处置权衡原则（Missing Handling Trade-offs）**

    * > **定义**：根据缺失样本占比及其对业务分布影响程度选择删除或填充的决策准则。

    * 极低占比处置：缺失值属于偶然出现的极个别样本时，剔除后对整体统计体量与分布无实质干扰，优先采用 `dropna()` 剔除以保证数据纯度。

    * 显著占比处置：缺失值占比达到 20% 至 30% 甚至更高时，大面积物理删除会导致样本量锐减并破坏分析结论，严禁直接删除，必须结合业务上下文采用均值、众数、默认值或前后时序推断稳健填充。

### 重复数据检测与去重控制

* **重复记录检测（Duplicate Detection）**

    * > **定义**：基于整行全字段或指定主键子集对比扫描并输出布尔标记序列的操作。

    * 核心方法：`df.duplicated(subset=[...])`。

    * 判定范围机制：
        * 全字段判定：无参数调用 `df.duplicated()` 时，严格对比每一行的所有列，每一列取值完全相同才标记为重复。
        * 主键子集判定：传入 `subset=['订单号']` 锁定特定业务主键，只要主键相同即判定为重复，忽略自增编号等辅助字段的干扰。

    * 副本标记机理：数据自上而下扫描时，特定值首次出现被记录为有效基准并返回 `False`；第二次及后续再次遭遇该值时被标记为副本并返回 `True`。

* **物理去重与保留策略（Deduplication and Retention Policy）**

    * > **定义**：依据设定的业务主键依据与保留规则物理抹除重复行的数据治理方法。

    * 核心方法：`df.drop_duplicates(subset=[...], keep=...)`。

    * `keep` 参数策略规则：
        * `'first'`（默认值）：保留该组重复数据中最先出现的物理首行，剔除后续所有冗余副本，适用于常规业务流水。
        * `'last'`：保留该组重复数据中最后出现的物理末行，抹除此前出现的所有行，适用于存在状态流转需捕获最新终态的场景。
        * `False`：双杀抹除，只要记录存在重复，该组所有关联行一条不留全部物理删除，适用于清理无法辨别真伪的录入冲突脏数据。

### 业务异常纠偏与格式归一化

* **业务约束异常治理（Business Logic Anomaly Handling）**

    * > **定义**：针对取值合乎语法但违背客观现实或业务规则的异常记录进行的定位与修复。

    * 异常定位：通过布尔比较表达式直接筛选，如 `df[df['单价'] < 0]` 检出负数单价。

    * 剔除路径：基于检索出的异常行索引执行物理删除 `df.drop(index=df[df['单价'] < 0].index)`。

    * 绝对值纠偏路径：若负号属于上游采集或前端解析误加且数值本身真实有效，调用矢量化绝对值方法 `df['单价'] = df['单价'].abs()` 完成批量修正，避免直接删除导致销售总额统计遗漏。

* **文本矢量化清洗（Vectorized String Replacement）**

    * > **定义**：利用字符串访问器对序列内每个元素的内容执行子串全局模式置换的清洗机制。

    * 标准语法：调用 `.str` 访问器执行 `df['列名'] = df['列名'].str.replace('/', '-')`，将全列混杂的斜杠日期统一替换为破折号标准格式。

    * > **易错点**：⚠️ 严禁直接调用 `Series.replace('/', '-')`。`Series` 的顶级方法 `replace()` 默认执行**全单元格完全值匹配**，仅当单元格内字符恰好仅为单个 `'/'` 时才触发替换，无法深入长字符串内部进行局部子串置换；局部子串替换必须依托 `.str.replace()` 访问器展开。

## 多维数值排序

### 单列数值排序

* **数值排序与索引排序（Values vs Index Sorting）**

    * > **定义**：区分以行/列索引标签为基准还是以具体字段数值为基准重新排列行顺序的排序算子。

    * 算子功能对比：`sort_index()` 专门基于行或列的索引标签进行排位；`sort_values()` 则依据二维表内部具体字段的内容展开业务排序。

* **单列排序与方向缺省（Single Column Sorting）**

    * > **定义**：依据单一指定字段的大小顺序对整张数据表记录进行重新排列的操作。

    * 核心语法：`df.sort_values(by='字段名', ascending=True)`。

    * 参数缺省规则：参数 `ascending` 意为升序，其缺省默认值为 `True`（数值从小到大排列）；若需执行降序排列（从大到小），必须显式赋值 `ascending=False`。

### 多列级联排序与布尔广播

* **多列级联排序机制（Multi-column Cascading Sort）**

    * > **定义**：在第一排序维度取值完全相同时依次激活次级排序规则的多指标主次排序仲裁。

    * 仲裁物理流程：

        ```text
        +---------------------------------------------------------------+
        |                    多列级联排序仲裁流程                        |
        +---------------------------------------------------------------+
        | 乱序记录行                                                    |
        |     |                                                         |
        |     v                                                         |
        | 第一排序字段 (by 列表首项)                                    |
        |     +---> 数值互不相同 ----> 直接确定该行物理排位             |
        |     |                                                         |
        |     +---> 数值完全相同 ----> 激活第二排序字段 (by 列表次项)   |
        |                                 |                             |
        |                                 +---> 依第二字段升/降序排位   |
        +---------------------------------------------------------------+
        ```

    * 列表传参映射：通过列表向 `by` 传入排定优先级的多个字段名，同时向 `ascending` 传入形状严格对应的布尔列表，如 `df.sort_values(by=['单价', '销售数量'], ascending=[True, False])` 代表单价升序且同价商品按销量降序。

* **方向布尔广播简写（Boolean Scalar Broadcasting）**

    * > **定义**：当多列级联排序的各维度排序方向完全一致时，由单个布尔标量自动扩展至所有维度的语法糖。

    * 广播规则：无需书写 `ascending=[False, False]`，直接简写为 `ascending=False`，所有在 `by` 列表中声明的列将统一继承降序排序规则。

## 数据分组聚合与统计分析

### 分组计算模型与基础运算

* **分组聚合模型（Split-Apply-Combine Model）**

    * > **定义**：将数据表依据特定分类特征切分为子集，对各子集独立施加统计函数，最终整合输出聚合报表的计算模式。

    * 三阶段执行流转：
        1. 拆分（Split）：根据一个或多个特征列中的离散取值，将原始数据表横向拆散为多个独立的虚拟数据组。
        2. 应用（Apply）：针对每个独立的子集并行施加指定的聚合统计算子计算局部标量。
        3. 合并（Combine）：将所有子集的计算结果按原分组维度汇总拼接为单一报表对象。

    * 基础聚合函数体系：

        | 统计类型 | 对应 Pandas 方法 | 功能说明 |
        | :--- | :--- | :--- |
        | 求和 | `sum()` | 计算分组内指定数值列的总物理和 |
        | 计数 | `count()` | 统计分组内指定列的非空（Non-Null）有效记录数 |
        | 最大值 | `max()` | 提取分组内指定列的最大极限数值 |
        | 最小值 | `min()` | 提取分组内指定列的最小极限数值 |
        | 平均值 | `mean()` | 计算分组内指定列的算术平均值 |

* **单列分组与全表聚合机制（Single Column Grouping）**

    * > **定义**：以单一分类字段为切分依据执行统计计算的标准调用。

    * 全表默认聚合：直接执行 `df.groupby('产品类别').count()` 时，未被指定分组依据的其他所有列均会被计算并在结果表中展开输出。

    * 目标列截取：通过方括号显式锁定计算列，如 `df.groupby('产品类别')['订单号'].count()`，返回以类别为索引、以订单总数为值的 `Series` 对象。

    * 中间态对象：执行 `df.groupby('产品类别')['销售金额']` 尚未调用聚合算子时，输出为 `SeriesGroupBy` 中间过渡对象，代表数据已切分就绪并等待施加具体计算。

* **计数统计中的缺失值规避（Missing Values in Count）**

    * > **定义**：由于聚合计算默认跳过缺失单元格导致计数值少于实际业务样本的计算偏差现象。

    * 偏差机理：`count()` 方法仅统计非空记录；若在分组计数时指定了包含 `NaN` 的非主键字段（如客户所在城市），该组的计数值将漏掉包含空洞的行。

    * 规避准则：统计分组下的订单量或记录总行数时，必须明确挑选主键标识列（如订单号）或无缺失字段作为统计对象，或在分组前完成缺失数据清洗。

* **衍生列构建后聚合（Derived Aggregation）**

    * > **定义**：当业务所需汇总指标在原表中不存在时，先执行列向量运算派生新字段再触发分组聚合的分析链路。

    * 业务实现流：原始数据仅有单价与数量时，先执行 `df['销售金额'] = df['单价'] * df['销售数量']` 生成衍生列，随后调用 `df.groupby('产品类别')['销售金额'].sum()` 完成品类销售额汇总。

### 多维高级聚合与结构转换

* **单列多指标聚合（Single-column Multi-metric Aggregation）**

    * > **定义**：对同一业务度量列一次性施加多个不同统计函数并输出多列表格的聚合方法。

    * 列表传参语法：调用 `agg()`（或全拼 `aggregate()`）并传入统计函数名字符串列表，如 `df.groupby('产品类别')['单价'].agg(['mean', 'max', 'min'])`。

    * 返回结构形态：返回以分组字段为行索引、以各聚合函数名为列标签的结构化二维 `DataFrame`。

* **多列异构字典映射聚合（Heterogeneous Dictionary Mapping）**

    * > **定义**：通过键值对字典为不同字段分别绑定不同统计函数的复合多维聚合机制。

    * 字典传参语法：直接对分组对象调用 `agg()` 并传入字典配置，如：

        ```python
        df.groupby('产品类别').agg({
            '销售数量': 'sum',
            '销售金额': 'sum',
            '单价': 'mean'
        })
        ```

    * 配置规则：字典的 Key 为待计算的目标字段名，Value 为分配给该字段的统计方法名字符串或方法列表，支持对单列同时配置多算子如 `{'单价': ['mean', 'max', 'min']}`。

* **聚合结果字典化输出（Result Dictionary Conversion）**

    * > **定义**：将分组统计计算生成的序列或表格直接转化为 Python 原生字典结构的方法。

    * 转换调用：在聚合链式表达式末端追加 `.to_dict()`，如 `df.groupby('产品类别')['销售金额'].sum().to_dict()`。

    * 业务价值：将分析计算产物直接转化为标准原生键值对，供下游 Web API 视图、缓存服务或业务逻辑直接调用。

## 数据可视化基础

### 绘图管线与折线图绘制

* **数据可视化工具库（Matplotlib Visualization Library）**

    * > **定义**：Python 数据科学生态中支持静态、动态及交互式图表生成的底层核心开源绘图库。

    * 安装命令：在终端执行包管理命令 `pip install matplotlib`，安装后模块文件落入 Python 环境的 `site-packages` 目录。

    * 常用子模块规范：工程上最常调用的是其绘图子模块 `pyplot`，业内统一遵循别名规范 `import matplotlib.pyplot as plt`。

* **折线图绘制最小闭环（Line Plot Minimal Pipeline）**

    * > **定义**：从坐标点集输入到图形渲染完成由三步构成的标准执行流程。

    * 执行三步闭环：
        1. 数据准备：构建横坐标序列 `x` 与对应的纵坐标数值序列 `y`。
        2. 曲线绘制：调用 `plt.plot(x, y)` 将二维离散坐标点连接绘制成线。
        3. 图形渲染：调用 `plt.show()` 弹出交互式窗口或在前端单元格中内嵌展示图表。

    * 数据波动特征：若 `x` 与 `y` 的变化率恒定（如均为 1 至 24），绘制出的为平滑斜直线；若利用随机数生成波动起伏的 `y` 序列，渲染结果呈现为折角起伏的标准折线图。

* **坐标轴维度一致性约束（Axis Dimension Consistency）**

    * > **定义**：绘图函数强制要求输入的横坐标点集与纵坐标点集的物理长度必须完全相等的底层校验规则。

    * 异常触发场景：当横轴 `x` 长度为 24，而纵轴 `y` 因切片或采集遗漏长度为 23 时，调用 `plt.plot(x, y)` 会直接导致程序崩溃。

    * 异常报错签名：抛出 `ValueError: x and y must have same first dimension, but have shapes (24,) and (23,)`。

    * 排查规范：在调用绘图算子前，调用 `len()` 或 `.shape` 检查两轴输入序列的第一维度长度是排查渲染异常的前提。
