# 2026南京大学：操作系统原理（蒋炎岩）（30 讲）

南京大学蒋炎岩老师 2026 年最新录制的旗舰操作系统课程。以“状态机（State Machine）”为核心视角，从零构建现代计算机系统的底层图景；跨越应用程序、C 语言运行时、操作系统内核与硬件指令集的边界，深度涵盖多处理器并发控制、异构计算与现代协程、持久化文件系统崩溃一致性、容器隔离与智能时代的系统演进。

- **全 30 集**，已产出 10 册模块全书、8 篇复习笔记

## 怎么学

课程主线遵循现代操作系统的分层与核心支柱：**程序状态机与系统调用 → C 语言底层运行时与动态链接 → 多处理器并发与同步互斥 → 异构并行与现代协程 → 存储 I/O 与崩溃一致性 → 虚拟化与系统安全**。建议：

- **确立状态机视角的系统思维** → 重点研读模块 01~03，理解程序从纯计算状态机到通过系统调用与外界环境发生作用的根本跃迁
- **吃透 C 语言底层运行时与装载** → 重点研读模块 04，搞懂链接器、加载器、ELF 结构与操作系统调试原语（ptrace/gdb）
- **攻克多处理器并发编程死穴** → 重点研读模块 05，深入自旋锁、互斥锁、条件变量与信号量的硬件内存屏障及并发 Bug 防范
- **掌握存储系统与崩溃一致性** → 重点研读模块 08~09，理解从机械硬盘/SSD 到日志型文件系统（Journaling）与数据库 WAL 的崩溃恢复哲学
- **考前/面试速查与架构复盘** → 直接查阅 `notes/` 目录下的 8 篇深度速查笔记，知识拓扑树支持直接导入 Markmap 生成导图
