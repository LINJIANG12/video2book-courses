## 怎么学

课程主线遵循现代操作系统的分层与核心支柱：**程序状态机与系统调用 → 进程与地址空间 → C 语言底层运行时与动态链接 → 多处理器并发与同步互斥 → 异构并行与现代协程 → 存储 I/O 与崩溃一致性 → 虚拟化与系统安全**。建议：

- **确立状态机视角的系统思维** → 重点研读模块 01~02，理解程序从纯计算状态机到通过系统调用与外界环境发生作用的根本跃迁，以及硬件视角（复位、中断、固件）里操作系统真正的立足点
- **吃透进程模型与地址空间** → 重点研读模块 03，搞懂 fork/execve/exit 的生命周期与 mmap 建立的地址空间；模块 04 接着讲文件描述符、终端与 UNIX Shell 如何把操作系统对象组织成可用世界
- **打通 C 语言底层运行时与装载** → 重点研读模块 05~06，从系统调用之上垒起 C 标准库（printf、malloc），再理解链接器、加载器与 ELF 结构
- **攻克多处理器并发编程死穴** → 重点研读模块 07~09，从互斥的原理与工程化（原子指令、futex）到条件变量、信号量、并发 Bug 防范，再到并行算法、协程与 SIMD/GPU 异构计算
- **掌握存储系统与崩溃一致性** → 重点研读模块 10~11，从 I/O 设备寄存器模型与驱动，到块设备、文件系统实现（superblock/FAT/inode/日志）与崩溃一致性
- **考前/面试速查与架构复盘** → 直接查阅 `notes/` 目录下的 8 篇深度速查笔记
