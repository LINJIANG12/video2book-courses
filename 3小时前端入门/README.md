# 3小时前端入门（23 讲）

这是一门篇幅紧凑的 Web 前端快速入门课，用 23 集把 HTML5、CSS3 与 JavaScript 的核心语法串起来。课程从页面结构、选择器与盒模型讲起，随后进入 JavaScript、DOM 和响应式布局，适合先建立完整的前端知识骨架，再继续深入框架与工程化。

- **原视频**：[3小时前端入门教程（HTML+CSS+JS）](https://www.bilibili.com/video/BV1BT4y1W7Aw) — Bilibili，BV1BT4y1W7Aw
- **全 23 集**，已产出 6 册模块全书、3 篇复习笔记

## 怎么学

这门课节奏快、覆盖面完整，重点不是一次背完所有 API，而是尽快建立“结构、样式、行为”三层协作的直觉。

- **先走通三层结构** → 模块 01 学 HTML，模块 02~03 学 CSS，模块 04~05 学 JavaScript 与 DOM，按这个顺序建立完整页面模型
- **边学边写页面** → HTML 标签、CSS 盒模型和 DOM 操作都建议在浏览器里即时验证，不要只读代码
- **用笔记做二次整理** → `notes/` 的 3 篇分别覆盖 HTML5、CSS3 和 JavaScript/DOM，适合学完后快速复盘
- **最后看响应式** → 模块 06 把移动端适配与前端体系收束起来，是在基础语法之后理解现代页面组织方式的入口
