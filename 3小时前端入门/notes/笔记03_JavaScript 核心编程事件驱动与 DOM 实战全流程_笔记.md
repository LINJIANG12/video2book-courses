# JavaScript 核心编程、事件驱动与 DOM 实战全流程

## 语言定位与脚本导入机制

### 脚本语言定位与技术分工

* **JavaScript（JavaScript，JS）**

    * > **定义**：一种运行于客户端浏览器与服务端环境中的轻量级、解释型、面向对象的脚本语言。

    * 核心功能为监听用户行为、发起网络请求并动态修改文档对象模型结构，使静态页面获得即时交互能力。

    * 宿主环境涵盖客户端浏览器与 Node.js 服务端运行时；在浏览器端是唯一官方支持的前端交互脚本语言。

    * 与 Java 语言没有任何技术血缘关系，两者设计哲学、语法规范与底层运行环境完全独立。

* **前端三层协作模型（Web Front-End Three-Tier Architecture）**

    * > **定义**：HTML、CSS 与 JavaScript 之间结构、表现与行为解耦并协同工作的工程分工体系。

    * HTML 负责页面骨架搭建与文档语义内容；CSS 负责视觉表现、色彩与盒模型布局；JavaScript 充当行为神经系统，驱动页面动态反馈。

    * 协作关系模型：

        ```text
        +-------------------------------------------------------------+
        |                     JavaScript (行为与交互)                  |
        |          监听用户点击 / 异步请求数据 / 动态修改 DOM 元素        |
        +-------------------------------------------------------------+
                                      | 驱动控制
        +-------------------------------------------------------------+
        |                        CSS (表现与视觉)                     |
        |            色彩 / 字体 / 盒模型 / 浮动与定位几何布局         |
        +-------------------------------------------------------------+
                                      | 依托渲染
        +-------------------------------------------------------------+
        |                       HTML (结构与内容)                     |
        |               语义化标签 / 页面骨架与基础文档流              |
        +-------------------------------------------------------------+
        ```

### 脚本引入方式与执行时序

* **内部内联式脚本（Internal Script）**

    * > **定义**：直接在 HTML 文档的 `<script>` 标签对内部编写 JavaScript 代码的引入方式。

    * 放置位置允许位于 HTML 的 `<head>` 区域或 `<body>` 区域内部。

    * 适用场景为极短的测试逻辑、实验配置或特定页面初始化脚本。

* **外部引入式脚本（External Script）**

    * > **定义**：将业务逻辑抽离为独立的 `.js` 扩展名文件，通过 `<script src="...">` 标签链接导入的工程组织方式。

    * 纯 JavaScript 独立文件内部严禁包含 `<script>` 标签，只保留原生代码语句。

    * 标准写法示例：`<script src="./js/myscript.js"></script>`。

    * 适用场景为生产环境工程化开发，实现结构与逻辑的代码解耦与跨页面复用。

    * > **易错点**：⚠️ 当 `<script src="..."></script>` 用于引入外部独立脚本时，其标签体内部严禁编写任何 JavaScript 代码，标签体内的所有内容会被浏览器完全忽略。

* **同步阻塞执行时序（Synchronous Blocking Timing）**

    * > **定义**：浏览器解析 HTML 文档时遇到脚本标签立即暂停 DOM 构建，优先加载并执行脚本的线性处理机制。

    * 浏览器从上至下按物理行扫描文档；遇到 `<head>` 内联脚本即刻执行；遇到外链脚本立即挂起 DOM 解析并建立网络请求，待文件下载且执行完毕后才继续向下解析 `<body>` 结构。

* **控制台输出与模态交互（I/O Functions）**

    * > **定义**：JavaScript 提供的用于开发调试日志打印与用户即时通知的原生输入输出接口。

    * `console.log()`：在浏览器开发者工具（F12）的 Console 控制台输出变量状态与执行追踪信息，属于非阻塞静默日志。

    * `alert()`：弹出带有“确定”按钮的原生模态警告对话框。

    * > **注意**：`alert()` 具有强代码阻塞性，在用户点击“确定”按钮解除弹窗前，整页渲染、后续代码执行与事件交互全部处于挂起冻结状态。

| 引入模式 | 语法格式 | 放置位置 | 适用场景 |
| :--- | :--- | :--- | :--- |
| 内部内联式 | `<script> 代码 </script>` | `<head>` 或 `<body>` | 短段实验验证、页面临时脚本 |
| 外部引入式 | `<script src="./path/file.js"></script>` | `<head>` 或 `<body>` 底端 | 生产工程标准、代码解耦与复用 |

## 变量声明机制与数据类型体系

### 变量声明关键字与作用域模型

* **传统变量声明（var）**

    * > **定义**：ECMAScript 早期规范中用于开辟内存空间并声明存储标识符的关键字。

    * 作用域层级为函数作用域（Function Scope），不受条件分支或循环体花括号 `{}` 的约束。

    * 具备变量提升（Hoisting）特性，声明语句会被静默提升至当前作用域顶部，容易产生未初始化访问的逻辑隐患与全局变量污染。

    * 在现代 Web 前端工程中属于遗留语法，坚决避免在日常业务中继续使用。

* **现代块级变量声明（let）**

    * > **定义**：现代 ECMAScript 规范中引入的受限于块级作用域且值可被二次修改的变量声明关键字。

    * 严格绑定在当前块级作用域（Block Scope，即由 `{}` 包裹的代码块）内部，代码块外不可访问。

    * 彻底解决变量越界穿透与变量污染问题，属于日常变量声明的首选方式。

* **常量锁定声明（const）**

    * > **定义**：用于声明具有块级作用域且在初始化绑定后不可重新赋值的常量标识符关键字。

    * 声明时必须赋予初始值，且后续不能执行二次重新赋值操作。

    * 用于声明数学常量、不可变系统配置参数或固定对象引用；尝试二次赋值将直接抛出运行时类型错误（TypeError）。

| 声明关键字 | 变量值二次修改 | 作用域层级 | 变量提升现象 | 工程推荐度 |
| :--- | :--- | :--- | :--- | :--- |
| `var` | 允许 | 函数作用域 | 存在提升风险 | 淘汰（避免使用） |
| `let` | 允许 | 块级作用域 | 遵循块级绑定 | 强烈推荐（常规首选） |
| `const` | **禁止** | 块级作用域 | 遵循块级绑定 | 强烈推荐（固定值首选） |

### 基础数据类型与空值语义

* **数值类型（Number）**

    * > **定义**：涵盖整数、浮点数小数、正负数值的统一数字数据类型。

    * 不在底层细分整型或浮点型，`5` 与 `3.14` 统一属于 Number 类型，降低数值计算的语法成本。

* **文本字符串类型（String）**

    * > **定义**：由成对的单引号 `''` 或双引号 `""` 包裹的字符序列文本载体。

    * 支持容纳汉字、英文字符、符号以及空文本 `""`；通过加号 `+` 可执行字符串拼接。

* **未定义空态（undefined）**

    * > **定义**：表示变量已被声明开辟了内存空间但尚未完成初始化赋值的系统默认原始状态。

    * 主要由 JavaScript 运行引擎自动派发生成。

    * 常见触发条件：变量仅声明未赋值（`let x;`）、访问对象未定义属性、函数内部缺失显式 `return` 语句。

    * 语义表达该位置变量目前尚未就绪，未来异步流程或后续计算可能会写入有效值。

* **显式空对象指针（null）**

    * > **定义**：由开发者在代码逻辑中主动赋予的用于指示空对象引用的原始值。

    * 必须由开发者显式书写赋值（`let obj = null;`），运行环境不会自动产生。

    * 常见使用场景：清空引用类型变量的内存指针、向函数实参明确传递“此处无需有效对象”。

    * 语义表达该位置确定没有任何对象实体，明确终结引用。

    * 空值生命周期模型：

        ```text
        [变量声明阶段] ----(未分配实质内容)----> undefined (自然空态：已开辟未初始化)
                                                    ^
                                                    | 函数无返回值 / 访问未定义属性
                                                    |
        [逻辑赋值阶段] ----(人为刻意清空)------> null      (人为置空：明确声明空对象指针)
        ```

## 程序控制流与迭代机制

### 条件分支语句与逻辑判定

* **单向决策分支（if）**

    * > **定义**：当圆括号内的条件表达式求值为真时驱动内部代码块执行的条件控制入口。

    * 条件表达式在求值时会被隐式转换为布尔值；条件成立执行 `{}` 代码，不成立直接跳过。

    * 在单一条件结构中必须存在且只能存在一个 `if` 入口。

* **后备检查分支（else if）**

    * > **定义**：前置条件判定为假时依次触发的后续级联检查分支。

    * 允许在 `if` 之后串联零个或多个 `else if` 检查块，自上而下匹配首个为真的代码块执行并跳出整个条件流。

* **默认兜底分支（else）**

    * > **定义**：当控制流中所有的 `if` 与 `else if` 条件全判定为假时必须执行的终极保底出口。

    * 在一个完整条件分支链中最多只能出现一个 `else`，无需书写判断条件括号。

* **比较与逻辑运算符（Comparison & Logical Operators）**

    * > **定义**：用于对数值大小、布尔真假及复合区间进行运算比对的语法操作符。

    * 比较操作符包含 `>`、`<`、`>=`、`<=`、`===`；逻辑与 `&&` 要求两端子表达式均为 `true` 时整体才为 `true`。

    * > **易错点**：大于号 `>` 在边界值相等时判定为 `false`。判定包含临界点（如满 18 岁）时，必须使用大于等于 `>=`，避免出现 `18 > 18` 判定为假导致的逻辑死角。

### 循环迭代语句与死循环防范

* **三段式计步循环（for）**

    * > **定义**：将计数器初始化、边界条件判定与步进更新集成在头部的紧凑型循环控制结构。

    * 语法格式：`for ( 初始化表达式 ; 循环条件判断 ; 迭代器更新 ) { 循环体 }`。

    * 执行序列：首先执行一次初始化；每次入循环前计算条件，为真进入循环体；循环体执行结束触发步进更新（如 `i++`），随后重新判断条件。

    * 适用场景为循环次数已知或具有确定边界长度的遍历任务。

* **条件驱动循环（while）**

    * > **定义**：只要圆括号内的条件判断表达式为真即重复执行循环体内部代码的控制结构。

    * 头部仅接收一个条件表达式；迭代器自增或状态改变必须在循环体内手动书写。

    * 适用场景为循环次数不固定、依赖外部异步状态或等待特定事件触发的轮询任务。

    * > **易错点**：⚠️ `while` 循环体内部如果遗漏手动步进语句（如 `count++`），循环判断条件将永远处于 `true` 状态，触发死循环（Infinite Loop）。死循环会导致浏览器主线程被彻底独占卡死，页面无响应，CPU 占用率飙升，最终只能强制终止浏览器进程。

### 循环跳转与中断控制

* **循环强行截断（break）**

    * > **定义**：无视后续未执行的循环轮次，立即终止并彻底跳出当前循环体的控制关键字。

    * 执行后直接转移至循环闭合花括号之后的第一行语句，后续计步器与代码均不再执行。

* **当前轮次跳过（continue）**

    * > **定义**：中断当前单次轮次的执行，提前跳过本次循环体中剩余语句并直接推进至迭代器步进的控制关键字。

    * 执行后立即计算迭代器递增，并重新开始下一轮的条件判断，不终止整体循环结构。

## 函数抽象与作用域隔离

### 函数声明定义与显式调用

* **函数（Function）**

    * > **定义**：一段封装了特定计算或业务任务、具备独立命名并可被重复调用的独立代码块。

    * 标准语法格式：`function 函数名(形参1, 形参2) { 代码块; return 结果; }`。

    * 核心价值在于消除冗余代码、实现逻辑复用，并作为事件驱动模型中的事件回调载体。

* **显式函数调用（Function Invocation）**

    * > **定义**：通过函数名后紧跟英文圆括号 `()` 的语法触发函数体代码运行的操作。

    * > **易错点**：声明函数仅是将代码片段封装存储在内存空间中并绑定标识符，函数本身绝不会自动执行；若要执行其内部逻辑，必须通过圆括号 `()` 显式调用。

* **函数返回值（return）**

    * > **定义**：立即终止当前函数的执行，并将后随表达式计算结果移交回函数调用位置的输出出口。

    * 区别于 `console.log()` 的控制台打印；`return` 是向程序运行时交付数据，供外部变量接收或链式传递。

    * 函数体若未显式书写 `return` 语句，执行完毕后的默认返回值为 `undefined`。

### 参数传递与数据绑定

* **形参占位机制（Parameter）**

    * > **定义**：在声明函数时写在头部圆括号内部用于在函数内部充当局部占位符的变量标识符。

    * 多个形参之间使用英文逗号 `,` 分隔；形参只在当前函数作用域内部有效。

* **实参动态绑定（Argument）**

    * > **定义**：在显式调用函数时传入圆括号内部的实际数据值。

    * 函数调用时，实参按照位置顺序一对一赋值绑定到对应的形参上，驱动函数内部产出差异化结果。

### 作用域模型与访问单向隔离

* **全局作用域（Global Scope）**

    * > **定义**：在所有函数外部声明的变量所归属的全局上下文环境。

    * 全局变量在页面整个生存周期中均可被访问，可在任何嵌套函数的内部向上查找并直接读取。

* **局部作用域（Local Scope）**

    * > **定义**：在函数体花括号 `{}` 内部声明的变量所归属的独立隔离执行环境。

    * 局部变量生命周期仅存在于函数执行期间，函数执行完毕后即被销毁。

    * 作用域遵循单向透视隔离规则：内部作用域可以向上访问外部全局变量；外部执行环境无法穿透进入函数作用域访问局部变量。

    * 在函数外部强行访问局部变量会直接中断程序并抛出引用异常：`Uncaught ReferenceError: xxx is not defined`。

    * 作用域访问透视关系：

        ```text
        +-----------------------------------------------------------+
        | 全局作用域 (Global Scope)                                 |
        |   let global_var = "全局变量";                            |
        |                                                           |
        |   +---------------------------------------------------+   |
        |   | 局部作用域 (Local Scope)                          |   |
        |   |   let local_var = "局部变量";                     |   |
        |   |                                                   |   |
        |   |   可访问: global_var (向上单向透视查找)            |   |
        |   |   可访问: local_var                               |   |
        |   +---------------------------------------------------+   |
        |                                                           |
        |   可访问: global_var                                      |
        |   无法访问: local_var ---> 抛出 ReferenceError 错误       |
        +-----------------------------------------------------------+
        ```

## 事件驱动体系与交互绑定

### 交互事件分类与触发时机

* **鼠标交互事件（Mouse Events）**

    * > **定义**：由用户物理移动或点击鼠标设备派发的瞬态文档交互事件。

    * `onclick`：鼠标左键点击某个元素时触发。应用场景包括按钮提交、弹窗打开、链接跳转。

    * `onmouseover`：鼠标指针移动到元素几何区域上方时触发。应用场景包括下拉菜单悬浮展示、图片高亮。

    * `onmouseout`：鼠标指针完全移出元素几何区域时触发。应用场景包括悬浮面板收起、恢复初始状态。

* **表单焦点与输入事件（Form Input Events）**

    * > **定义**：由表单控件获得光标、失去焦点或内容变更时派发的交互行为事件。

    * `onfocus`：元素获得光标焦点时触发。应用场景包括输入框高亮高仿激活、弹出输入提示面板。

    * `onblur`：元素失去光标焦点时触发。应用场景包括表单数据格式实时校验、隐藏即时建议浮层。

    * `onchange`：表单元素的值发生改变且失去光标焦点时触发。应用场景包括下拉列表选项切换联动。

    * `onselect`：输入框或文本域中的文本内容被光标选定时触发。应用场景包括快捷划词复制。

| 事件属性名 | 触发条件时机 | 典型业务场景 |
| :--- | :--- | :--- |
| `onclick` | 鼠标点击元素瞬间 | 按钮提交、弹窗触发 |
| `onmouseover` | 鼠标移动至元素上方 | 悬浮菜单展开、元素高亮 |
| `onmouseout` | 鼠标离开元素区域 | 菜单收回、恢复默认样式 |
| `onfocus` | 元素获得光标焦点 | 输入框获得输入激活状态 |
| `onblur` | 元素失去光标焦点 | 表单离焦格式即时校验 |
| `onchange` | 值发生变更并失去焦点 | 选项切换、级联选择器 |
| `onselect` | 框内文本被划词选定 | 快捷复制、字数统计 |

### 事件绑定途径与技术选型

* **HTML 行内属性绑定（Inline Event Handler）**

    * > **定义**：直接在 HTML 标签属性内部书写事件属性并将处理函数调用赋给属性值的绑定方式。

    * 语法格式：`<button onclick="click_event()">按钮</button>`。

    * 同一 HTML 标签允许同时声明多个不同事件属性（如 `<input onfocus="f()" onblur="b()">`）。

    * > **易错点**：在 HTML 属性中绑定函数时，属性值必须显式包含调用圆括号（如 `onclick="click_event()"`）。若遗漏圆括号写成 `onclick="click_event"`，事件发生时浏览器不会执行函数调用。

* **DOM 对象属性赋值绑定（DOM Property Event Handler）**

    * > **定义**：在 JavaScript 中获取 DOM 元素对象后，直接对其事件属性（如 `node.onclick`）赋一个处理函数的绑定方式。

    * 常采用匿名函数（Anonymous Function）直接赋值：`btn.onclick = function() { ... };`。

    * 优势在于将事件调度移入 JS 文件，避免污染全局命名空间，但同一个事件属性后赋值的函数会覆盖前一个函数。

* **事件监听器方法（addEventListener）**

    * > **定义**：现代 W3C 标准推荐的通过 DOM API 为指定节点注册事件监听器的接口规范。

    * 语法格式：`element.addEventListener('click', callback)`。

    * 参数特征：首参数为事件类型字符串，**必须省略 `on` 前缀**（例如传入 `'click'` 而非 `'onclick'`）；次参数为回调函数。

    * 具名函数传递规范：当传入具名函数时，必须传递函数名引用自身（如 `clickEvent`）。

    * > **易错点**：⚠️ 向 `addEventListener` 传递具名函数时严禁在函数名后添加圆括号。若写成 `element.addEventListener('click', clickEvent())`，JS 解析引擎会在注册监听器阶段立即执行该函数，并将执行后的返回值（通常为 `undefined`）传给监听器，导致用户触发事件时完全无法响应。

## 文档对象模型与节点操控

### 文档对象模型与树状层级

* **文档对象模型（Document Object Model，DOM）**

    * > **定义**：浏览器将 HTML 纯文本标记解析映射为内存中具有严格层级亲属结构的对象树的编程接口。

    * 页面中一切组成部分皆被抽象为对象；对象的**属性**对应状态数据（如文本、颜色、尺寸），对象的**方法**对应执行动作（如查询、增删、样式变动）。

* **DOM 节点分类（DOM Tree Node Types）**

    * > **定义**：DOM 树上不同职能与层级的数据实体分类。

    * 文档节点（Document Node）：整棵 DOM 树的唯一顶层入口与根节点，即全局的 `document` 对象。

    * 元素节点（Element Node）：文档中所有的 HTML 标签实体（如 `<html>`、`<body>`、`<div>`、`<table>`）。

    * 属性节点（Attribute Node）：嵌套在元素标签体内部的修饰键值对（如 `id`、`class`、`src`）。

    * 文本节点（Text Node）：标签对之间包裹的实际字符内容，位于树结构的末端叶子位置。

    * DOM 树层级结构：

        ```text
                                [ document ] (根文档节点)
                                     |
                                 <html> (根元素)
                                     |
                    +----------------+----------------+
                    |                                 |
                 <head>                            <body>
                    |                                 |
                 <title>                     +--------+--------+
                    |                        |                 |
             "网页标题" (文本)             <h1>              <a> (href="#")
                                             |                 |
                                      "主标题" (文本)     "超链接" (文本)
        ```

### 元素节点检索查询接口

* **按唯一标识符查询（getElementById）**

    * > **定义**：依据元素标签的 `id` 属性字符串获取单一精准 DOM 节点的方法。

    * 语法格式：`document.getElementById('box1')`。

    * 返回值类型为单个 Element 对象；由于 ID 在文档流中具有唯一性，直接返回目标引用，不存在集合包装。

* **按样式类名批量查询（getElementsByClassName）**

    * > **定义**：依据元素身上标注的 class 样式类名获取全部匹配节点的检索方法。

    * 语法格式：`document.getElementsByClassName('box2')`。

    * 返回值类型为 `HTMLCollection` 类数组集合；无论页面中匹配项有多少个（哪怕只有 1 个），必须使用索引下标（如 `[0]`）提取目标节点。

* **按 HTML 标签名批量查询（getElementsByTagName）**

    * > **定义**：依据 HTML 标签名称批量抓取页面全部对应标签节点的方法。

    * 语法格式：`document.getElementsByTagName('div')`。

    * 返回值类型为 `HTMLCollection` 集合，按文档流物理顺序排列，需使用 `[index]` 索引解构。

* **按 Name 属性批量查询（getElementsByName）**

    * > **定义**：依据 HTML 标签的 `name` 属性值获取对应节点集合的方法。

    * 语法格式：`document.getElementsByName('gender')`。

    * 返回值类型为 `NodeList` 集合，主要用于单选框、复选框等表单组元素的批量提取。

| 检索接口 | 接收参数类型 | 返回值数据类型 | 返回特征与解构要求 |
| :--- | :--- | :--- | :--- |
| `getElementById` | ID 字符串 | 单个 Element 节点 | 精确定位唯一对象，直接访问 |
| `getElementsByClassName` | 样式类名字符串 | `HTMLCollection` 集合 | 类数组，必须通过 `[index]` 解构 |
| `getElementsByTagName` | HTML 标签名字符串 | `HTMLCollection` 集合 | 类数组，按出现顺序索引提取 |
| `getElementsByName` | 属性名字符串 | `NodeList` 集合 | 用于表单组件，类数组结构 |

### 元素内容更新与内联样式控制

* **HTML 解析式内容属性（innerHTML）**

    * > **定义**：用于获取或覆盖重写元素标签内部全部 HTML 结构标记与文本的 DOM 节点属性。

    * 赋值语法：`element.innerHTML = '<span>内容</span>'`。

    * 行为特征：会对字符串中包含的 HTML 标签标记进行完整语法解析，将其转换为真实的子 DOM 节点并完成渲染。

    * > **易错点**：`innerHTML` 是节点的**属性**而非方法，严禁写成函数调用式的 `element.innerHTML(...)`，必须使用赋值操作符 `=` 直接赋给字符串。

* **纯文本内容属性（innerText）**

    * > **定义**：用于获取或覆盖重写元素标签内部可见纯文本字符的 DOM 节点属性。

    * 赋值语法：`element.innerText = '纯文本内容'`。

    * 行为特征：忽略 HTML 标签语义，将赋值字符串中的尖括号等标记原封不动当作纯文本直接显示在页面上，不构建任何子 DOM 节点。

* **内联样式对象控制（style）**

    * > **定义**：挂载在元素节点上的用于读取或动态注入行内 CSS 样式的配置对象。

    * 赋值语法：`element.style.color = 'red'; element.style.fontSize = '20px';`。

    * > **提示**：CSS 规则中以短横线连接的属性名称（如 `font-size`、`background-color`），在 JavaScript 中必须统一转换为**驼峰命名法**（如 `fontSize`、`backgroundColor`），这是因为短横线 `-` 会被 JavaScript 解释器解析为减法操作符。

### 文档树进阶管理接口

* **节点创建与追加挂载（createElement & appendChild）**

    * > **定义**：在内存中动态生成全新的元素节点并将其挂载插入到指定父容器子节点末尾的接口。

    * `document.createElement('tagName')`：依据指定标签名在内存中构建一个未挂载的空元素节点。

    * `parentNode.appendChild(childNode)`：将构建好的新节点追加挂载至目标父节点的内部最后位置。

* **父级协调删除机制（removeChild）**

    * > **定义**：由父节点调用并将指定子节点从当前 DOM 树中永久移除的接口方法。

    * DOM 树规范规定：节点自身无法执行“自我销毁”操作；若要移除某一节点，必须首先向上找到其父节点，由父节点调用 `parentNode.removeChild(childNode)` 执行卸载。

* **属性操控与拓扑遍历（Attribute & Traversal APIs）**

    * > **定义**：用于对标签属性进行显式读写以及在树层级中定向移动的辅助接口集合。

    * 属性控制：`element.getAttribute('attrName')` 读取属性值；`element.setAttribute('attrName', 'value')` 动态写入自定义或内置属性。

    * 拓扑遍历：通过 `node.parentNode` 访问直接父节点，通过 `node.children` 访问子元素集合，通过 `node.nextElementSibling` 访问后紧邻的兄弟元素节点。

## 动态表格增删改查综合实战

### 表格骨架与排版样式布局

* **表格语义结构标记（Table Markup）**

    * > **定义**：使用 `<table>` 容器、表头行 `<tr><th>` 与数据单元格 `<td>` 构建的标准多列数据展现骨架。

    * 容器标记必须显式声明 `id="table"`，确保脚本可直接通过 `getElementById("table")` 稳定提取单一容器对象，规避按标签名检索返回集合必须索引取值的越界风险。

    * 结构由顶层操作区（新增按钮）、表头区（姓名、联系方式、操作列）以及数据行组成。

* **表格工业级排版样式（Table Industrial Styling）**

    * > **定义**：消除单元格缝隙并规范内边距与对齐方式的完整 CSS 规则集。

    * 核心排版样式规范：

        ```css
        table {
            width: 100%;             /* 宽度撑满容器并实现自适应缩放 */
            border-collapse: collapse;/* 合并单元格默认分离的双重边框，消除间隙 */
            margin-top: 20px;         /* 与上方新增按钮维持隔离边距 */
        }
        th, td {
            border: 1px solid #ddd;   /* 铺设 1 像素浅灰色实线单线边框 */
            text-align: center;       /* 单元格内文字统一水平居中 */
            padding: 8px;             /* 设置 8 像素内边距撑开单元格呼吸空间 */
        }
        th {
            background-color: #ddd;   /* 表头区域背景填灰色以强化层级标识 */
        }
        button {
            margin-left: 5px;         /* 并列按钮设置左外边距以消除黏连 */
        }
        ```

### 动态行新增与单元格构建

* **行节点动态追加（insertRow）**

    * > **定义**：DOM 为表格对象封装的用于在指定行索引位置插入空行 `<tr>` 节点的方法。

    * 追加位置计算规则：通过 `table.rows.length` 获取当前表格存在的总物理行数；将该长度值直接作为索引参数传入 `table.insertRow(length)`，即可精确将新行追加挂载在表格的物理末端。

    * 索引动态模型：

        ```text
        table.rows: [
          0: <tr> <th>姓名</th> <th>联系方式</th> <th>操作</th> </tr>
          1: <tr> <td>罗大富</td> ... </tr>
        ]  ==> table.rows.length = 2

        table.insertRow(2)  ==> 新行精准挂载在索引 2 的位置（末尾追加）
        ```

* **列单元格拆分与按钮注入（insertCell）**

    * > **定义**：在新建行节点内部指定列索引位置构建 `<td>` 单元格并注入交互内容的操作。

    * 拆分创建三列：`row.insertCell(0)` 创建姓名列；`row.insertCell(1)` 创建联系方式列；`row.insertCell(2)` 创建操作列。

    * 初始内容赋权：姓名列与联系方式列赋默认占位文本（`"未命名"` 与 `"无联系方式"`）。

    * 操作列通过 `innerHTML` 模板注入带有点击事件的按钮 HTML 字符串：`'<button onclick="deleteRow(this)">删除</button><button onclick="editRow(this)">编辑</button>'`。

### 触发源回溯与节点安全移除

* **事件触发源上下文（this）**

    * > **定义**：在 HTML 行内事件属性中作为实参传入时直接指向当前触发事件的 DOM 元素对象本身的上下文标识符。

    * 写法示例：`<button onclick="deleteRow(this)">删除</button>`。

    * 在回调函数 `deleteRow(button)` 接收后，`button` 参数即稳定持有被点击按钮的真实 DOM 引用，解决无法定位具体操作行的痛点。

* **双亲节点级联回溯删除（Double parentNode Traversal）**

    * > **定义**：通过 DOM 包含层次从按钮出发连续回溯两次 `parentNode` 锁定目标行并实施移除的算法模式。

    * 回溯链路：第一层 `button.parentNode` 定位到按钮所在的 `<td>` 单元格；第二层 `button.parentNode.parentNode` 定位到包裹单元格的 `<tr>` 数据行。

    * 级联删除语法：`row.parentNode.removeChild(row);`。

    * 回溯与删除拓扑模型：

        ```text
        [button] (触发源: this)
           │  .parentNode
           ▼
          [td]   (操作单元格)
           │  .parentNode
           ▼
          [tr]   (整行节点 row)
           │  .parentNode
           ▼
        [tbody / table] (父容器) ──.removeChild(row)──> 移除整行
        ```

### 单元格回填编辑与边界防护

* **行内单元格集合提取（row.cells）**

    * > **定义**：行节点原生携带的用于以数字索引直接提取内部所有单元格 `<td>` 的属性集合。

    * 提取语法：`let nameCol = row.cells[0]; let phoneCol = row.cells[1];`。

* **初值回填弹窗交互（prompt with defaultValue）**

    * > **定义**：利用浏览器原生输入对话框收集用户数据并预填充原内容的交互方案。

    * 语法格式：`prompt(message, defaultValue)`。

    * 将当前单元格内容作为第二参数传入：`prompt("请输入名字", nameCol.innerHTML)`。弹窗出现时直接带出原有的数据，方便用户在此基础上进行编辑修改。

* **空值拦截与输入保护（Input Validation & Trim Guard）**

    * > **定义**：对弹窗返回值进行非空判断以防止有效数据被意外覆盖清空的保护机制。

    * 判定条件：`inputName !== null && inputName.trim() !== ""`。

    * 当用户点击“取消”按钮时，`prompt()` 返回 `null`；当用户未输入任何字符按确定时返回空字符串 `""`。必须同时过滤这两种无效状态，仅在输入有效非空字符时才允许覆盖 `nameCol.innerHTML`，确保原有表格数据的安全性与程序健壮性。
