# HTML结构与CSS页面布局体系

## 网页核心技术体系与开发环境

### 前端核心技术分工

* **超文本标记语言（HyperText Markup Language，HTML）**
    * > **定义**：用于定义网页结构和内容的标记语言，构筑页面的基础骨架。
    * 职能范围：声明标题、段落、列表、表格、多媒体嵌入与超链接等内容载体。
    * 渲染机制：浏览器解析 HTML 标签树并完成初始文档结构的排版与绘制。

* **层叠样式表（Cascading Style Sheets，CSS）**
    * > **定义**：用于控制网页外观、视觉样式与空间布局的样式表语言。
    * 职能范围：控制元素颜色、字体字阶、间距轮廓、对齐网格与界面动效。
    * 调试方式：在浏览器开发者工具（快捷键 `F12`）的“元素（Elements）”面板右侧样式面板中实时查看与修改 CSS 规则。

* **JavaScript（JavaScript，JS）**
    * > **定义**：用于为网页注入交互能力、动态逻辑与数据通信的脚本语言。
    * 职能范围：负责数据动态校验、弹窗交互、异步无刷新数据加载与用户行为响应。

* **网页呈现与职能协同**
    * 协同机理：HTML 提供静态骨架，CSS 实施精装美化，JavaScript 驱动动态交互。
    * 关系图示：
        ```text
        +-------------------------------------------------------------+
        |                           网页呈现                          |
        +-------------------------------------------------------------+
        |  HTML (结构与内容)  : 搭建骨架，定义标题、段落、图像与超链接 |
        |  CSS  (样式与布局)  : 美化外观，定义按钮色彩、文字字阶与栅格 |
        |  JS   (交互与逻辑)  : 驱动行为，实现数据校验、动效与异步通信 |
        +-------------------------------------------------------------+
        ```

### 开发环境与扩展配置

* **Visual Studio Code（Visual Studio Code，VS Code）**
    * > **定义**：微软开发的轻量级代码编辑器，前端工程的核心集成开发环境。
    * 环境配置：安装时勾选“将‘通过 Code 打开’操作添加到 Windows 资源管理器文件上下文菜单”与“添加到系统 PATH”，支持在项目目录终端直接通过 `code .` 挂载工作区。
    * 快捷键映射：扩展面板快捷键为 `Ctrl+Shift+X`；代码行注释快捷键为 `Ctrl + /`。

* **前端核心扩展插件**
    * `Chinese (Simplified) Language Pack`：提供 VS Code 原生界面的简体中文语言本地化支持。
    * `HTML CSS Support`：在编写 HTML 与 CSS 时提供智能类名补全与样式属性提示。
    * `Live Server`：启动本地热更新开发服务器，文件保存即触发浏览器毫秒级重载。
    * `Auto Rename Tag`：修改 HTML 成对标签的开始标签或结束标签时，自动同步重命名闭合端的另一端标签。

## HTML文档骨架与语法规范

### 文档类型与基础骨架

* **文档类型声明（Document Type Declaration，`<!DOCTYPE html>`）**
    * > **定义**：位于文档首行的标准声明，告知浏览器采用最新的 HTML5 标准规范进行页面解析与渲染。
    * 作用机理：防止浏览器进入怪异模式（混杂模式），确保现代标准语法与盒模型的准确渲染。

* **根元素（Root Element，`<html>`）**
    * > **定义**：HTML 文档的最外层根节点容器，包裹页面除文档类型声明外的所有元素。
    * 核心属性：`lang="zh-CN"` 声明页面基础自然语言为简体中文，辅助搜索引擎与翻译工具。

* **文档头部（Head，`<head>`）**
    * > **定义**：承载文档元数据（Metadata）、页面编码与外部资源依赖的配置容器。
    * 内部节点：
        * `<meta charset="UTF-8">`：声明文档采用 UTF-8 字符集编码，避免文本乱码。
        * `<meta name="viewport" content="width=device-width, initial-scale=1.0">`：声明移动端视口宽度与设备物理宽度等宽，基准缩放比为 1.0。
        * `<title>`：定义浏览器标签页与窗口栏所显示的页面标题。
        * `<link>` 与 `<style>`：用于挂载外部样式表与内部样式定义。
    * 呈现边界：除 `<title>` 显示在标签栏外，`<head>` 内部声明的所有元数据均不直接在正文视口中渲染。

* **文档主体（Body，`<body>`）**
    * > **定义**：承载页面在浏览器可视窗口中渲染展现的所有可见内容的容器。
    * > **注意**：所有文本、多媒体、排版结构与交互控件必须编写在 `<body>` 标签内部，写在外部会导致解析容错异常或渲染错位。

* **骨架快捷生成机制**
    * 生成规则：基于 Emmet 语法引擎，在空白 `.html` 文件首行输入英文半角感叹号 `!` 后按 `Tab` 键或回车，即可瞬间生成工业级标准 HTML5 骨架。

### 标签语法与分类

* **双标签（Double Tags）**
    * > **定义**：由开始标签 `<tag>` 与带有反斜杠的结束标签 `</tag>` 成对组合构成的元素结构。
    * 语法形态：`<开始标签 属性="值">包裹内容</结束标签>`。
    * 适用边界：用于承载具体文本内容或嵌套其他子级结构，例如 `<h1>`、`<p>`、`<a>`、`<div>`。

* **单标签（Single Tags / Empty Tags）**
    * > **定义**：无需闭合结束标签、自成一体独立闭合的单体元素结构。
    * 语法形态：`<单标签名 属性="值">`。
    * 适用边界：内部无需包裹任何文本内容，专用于在页面上生成独立排版符号或功能控件，例如 `<input>`、`<br>`（换行）、`<hr>`（水平分割线）、`<img>`。

### 标签属性与解析规则

* **标签属性（Attribute）**
    * > **定义**：书写在开始标签内部、用于描述元素特征、提供补充参数或控制运行行为的键值对配置项。
    * 语法格式：`属性名="属性值"`，紧跟在标签名称后，多属性之间以空格隔开；属性值推荐使用英文半角双引号包裹。
    * 大小写敏感准则：HTML 属性名称对大小写不敏感；属性值（尤其是路径字符串）对大小写高度敏感。
    * > **易错点**：⚠️ HTML 属性名大小写不敏感，但引用的资源路径与属性值严格区分大小写，大小写不匹配会导致静态资源 404 加载失败。

* **全局属性与专用属性**
    * 全局属性：几乎所有可见标签均支持的通用属性。
        * `id`：定义全页面范围内的唯一标识符，常用于 `<label>` 绑定、锚点定位及脚本选择。
        * `class`：定义样式类名，支持空格分隔多个类名以实现多重规则挂载。
        * `style`：用于在标签本体直接写入内联 CSS 规则。
    * 专用属性：仅针对特定标签生效的专有配置项，例如超链接的 `href`、图像的 `src` 与 `<form>` 的 `action`。

## 常用文本与排版元素

### 标题与段落

* **标题元素（Heading，`<h1>`~`<h6>`）**
    * > **定义**：用于组织页面文本内容逻辑层级的六级标题标签体系。
    * 渲染特征：从 `<h1>` 至 `<h6>` 字阶尺寸与笔画字重依次递减，自带加粗与上下外边距，属于独占整行的块级元素。

* **段落元素（Paragraph，`<p>`）**
    * > **定义**：用于包裹自然排版大段普通正文文本的容器。
    * 渲染特征：默认字重渲染；段落上下自动生成垂直外边距；HTML 源代码中的多次换行与连续空白字符会被浏览器合并折叠为单个空格。

### 文本格式化与语义强调

* **粗体元素（`<b>` 与 `<strong>`）**
    * 视觉表现：两者均将目标文本渲染为粗体字重。
    * 语义差异：`<b>`（Bold）仅提供纯视觉粗体；`<strong>` 赋予文本结构层面的重要性语义强调，更易被屏幕阅读器与搜索引擎捕获。

* **斜体元素（`<i>` 与 `<em>`）**
    * 视觉表现：两者均将目标文本以倾斜字体渲染。
    * 语义差异：`<i>`（Italic）偏向纯视觉字体倾斜；`<em>` 表达语言语调的强调语义。

* **修饰线条元素（`<u>` 与 `<s>`）**
    * 下划线（Underline，`<u>`）：在文本底边缘添加一条连续下划线。
    * 删除线（Strikethrough，`<s>`）：在文本正中添加贯穿水平删除线，常用于标注失效的原价或废弃数据。

### 列表与表格

* **无序列表（Unordered List，`<ul>`）**
    * > **定义**：用于组织无明确先后次序、彼此地位平等的并列条目的列表容器。
    * 嵌套结构：外层为 `<ul>`，内部直接嵌套列表项 `<li>`（List Item）；浏览器默认在每个列表项左侧渲染实心圆点项目符号。

* **有序列表（Ordered List，`<ol>`）**
    * > **定义**：用于组织具备严格先后逻辑或递进次序条目的列表容器。
    * 嵌套结构：外层为 `<ol>`，内部直接嵌套 `<li>` 列表项；浏览器默认在每个列表项前自动标注递增的阿拉伯数字序号。

* **数据表格（Table，`<table>`）**
    * > **定义**：由行与列交叉构成的二维数据结构化网络容器。
    * 标签拓扑层级：
        * `<table>`：定义整个表格的最外层根容器；添加 `border="1"` 属性可显式开启网格边框。
        * `<tr>`（Table Row）：定义表格的行容器。
        * `<th>`（Table Header）：定义表头单元格，通常位于首行，文字默认加粗且水平居中。
        * `<td>`（Table Data）：定义普通数据单元格，承载表格的具体数值或内容。
    * 层次拓扑图：
        ```text
        +-------------------------------------------------------------+
        |  table (表格根容器)                                          |
        |  +-------------------------------------------------------+  |
        |  |  tr (第1行: 表头行)                                    |  |
        |  |  +-----------------+-----------------+-------------+  |  |
        |  |  | th (列表头1)    | th (列表头2)    | th ...      |  |  |
        |  |  +-----------------+-----------------+-------------+  |  |
        |  +-------------------------------------------------------+  |
        |  +-------------------------------------------------------+  |
        |  |  tr (第2行: 数据行)                                    |  |
        |  |  +-----------------+-----------------+-------------+  |  |
        |  |  | td (数据单元格) | td (数据单元格) | td ...      |  |  |
        |  |  +-----------------+-----------------+-------------+  |  |
        |  +-------------------------------------------------------+  |
        +-------------------------------------------------------------+
        ```

## 超链接与多媒体资源

### 超链接与跳转行为

* **超链接元素（Anchor，`<a>`）**
    * > **定义**：用于实现页面间跨域跳转、当前页面内锚点定位或激活外部协议资源的行内双标签。
    * `href` 属性（Hypertext Reference）：
        * 取值类型：外部绝对 URL、站内相对路径、电子邮箱协议或电话拨号指令。
        * 占位用法：若当前无需真实跳转，填写 `#` 可充当空锚点并阻止页面刷新。
    * `target` 属性：
        * `_self`：默认值，在当前浏览器窗口或标签页中打开并覆盖原页面。
        * `_blank`：在全新独立的浏览器窗口或空白新标签页中打开。
        * `_parent`：在当前框架的上一层直接父级窗口中打开。
        * `_top`：跳出所有框架嵌套层级，在顶层主窗口中完全打开目标页面。

### 图像与媒体加载

* **图像元素（Image，`<img>`）**
    * > **定义**：用于在网页中嵌入位图或矢量图资源的单标签行内块元素。
    * `src` 属性（Source）：指定待渲染图像文件的物理相对路径、绝对路径或网络地址。
    * `alt` 属性（Alternative Text）：
        * 触发条件：当图片路径拼写错误、本地文件丢失或网络超时导致资源加载中断时显示。
        * 价值定位：为视障用户屏幕阅读器提供无障碍语音朗读支持，并在资源失效时提供文本优雅降级。
    * `width` 与 `height` 属性：直接在 HTML 标签中定义图像渲染的像素尺寸；若仅设置单侧尺寸，另一侧依据原图宽高比自动等比缩放；若同时设置不成比例的双侧尺寸会导致图像拉伸变形。

## HTML表单与交互控件

### 表单容器与提交机制

* **表单容器（Form，`<form>`）**
    * > **定义**：包裹各类输入控件、收集用户交互数据并统一组织向服务器发送请求的根级容器。
    * `action` 属性：指定表单提交触发时，数据所发送的目标服务器 API 接口 URL；在无真实后端的开发阶段，必须配置为 `action="#"` 作为占位锚点以防页面异常跳转。
    * `method` 属性：规定提交数据时所采用的 HTTP 传输协议方法，常用值为 `get`。

### 输入控件类型与状态

* **输入元素（Input，`<input>`）**
    * > **定义**：依据 `type` 属性值呈现不同交互逻辑与视觉形态的核心单标签输入控件。
    * `type="text"`：单行纯文本输入框。
        * `placeholder` 属性：输入框未获得输入时的浅灰色占位提示文本，键入内容时自动隐匿，清空后自动复原，不作为真实数据提交。
        * `value` 属性：输入框内部预设的真实有效值，表单提交时该值会随字段一同上传给后端。
    * `type="password"`：密码掩码输入框，用户输入的字符自动被黑圆点或星号遮蔽，杜绝明文窥视。
    * `type="radio"`：单选框控件。
        * 互斥机制：同一业务逻辑组内的所有单选框，必须配置完全相同的 `name` 属性值（如 `name="gender"`），浏览器方能识别并建立互斥单选池。
        * > **注意**：同一组单选控件若未赋予相同的 `name` 属性，会导致所有选项均可被同时独立勾选，丧失单选意义。
    * `type="checkbox"`：多选复选框控件，允许用户在一个选项池中勾选零个、一个或多个条目；同一逻辑组建议配置相同 `name` 属性（如 `name="hobby"`）。
    * `type="submit"`：表单提交触发按钮，点击后自动收集当前所在 `<form>` 内部所有带有 `name` 属性的控件数据并打包提交；浏览器默认文案为“提交”，设置 `value="自定义文字"` 可覆写按钮文案。

### 文本标注与字段绑定

* **标注元素（Label，`<label>`）**
    * > **定义**：为表单输入控件提供文本描述并扩展鼠标点击热区范围的行内标注标签。
    * 绑定机制：`<label for="控件ID">` 的 `for` 属性值必须与目标 `<input id="控件ID">` 的 `id` 属性严格完全一致；点击标注文本即可自动让目标输入框获得输入焦点或切换勾选状态。
    * 映射示意：
        ```text
        +-------------------------------------------------------------+
        |  <label for="username"> 用户名 </label>                     |
        |         │                                                   |
        |         └── 逻辑指向相同的唯一标识 ────────────────┐         |
        |                                                    ▼        |
        |  <input type="text" id="username" name="username"> [ 输入框 ]|
        +-------------------------------------------------------------+
        ```

* **`id` 与 `name` 的定位边界**
    * `id` 属性：全页面范围内具有绝对唯一性，专职负责被 `<label>` 绑定或供 CSS/JavaScript 精确寻址。
    * `name` 属性：表单数据打包发送至后端接口时的字段键名（Key），并在单选框中承担逻辑互斥分组判定。

## CSS核心语法与引入方式

### 语法规则与声明块

* **CSS 样式规则（Style Rule）**
    * > **定义**：由定位目标元素的选择器（Selector）与紧随其后花括号包裹的声明块（Declaration Block）构成的样式准则。
    * 声明范式：每条样式声明必须采用 `属性名: 属性值;` 的键值对格式；冒号用于分隔属性与值，每条声明末尾必须以英文半角分号 `;` 闭合。
    * 注释语法：采用 `/* 注释内容 */` 围栏包裹，注释内容不参与浏览器渲染。

### 样式表引入方式

* **内联样式（Inline Style，行内样式）**
    * > **定义**：直接写入目标 HTML 标签原生 `style` 属性内部的单体样式声明。
    * 适用边界：仅适用于临时局部调试或针对极少数个别特异元素的微调；样式与 HTML 结构重度交织，无法跨标签复用，维护成本极高。

* **内部样式表（Internal Style Sheet）**
    * > **定义**：集中书写在 HTML 文档 `<head>` 区域内部 `<style>` 双标签中的样式块。
    * 适用边界：初步实现当前单文档内结构与样式的解耦，适用于独立单页面练习或轻量级 Demo，但无法跨物理文件复用。

* **外部样式表（External Style Sheet）**
    * > **定义**：将 CSS 规则完全抽离至独立的 `.css` 纯文本文件，并在 HTML `<head>` 中通过 `<link>` 标签链接引入的标准组织形态。
    * 语法格式：`<link rel="stylesheet" href="样式文件相对路径">`；`rel="stylesheet"` 声明文件类型为样式表，`href` 寻址外部文件。
    * 核心价值：彻底实现结构与样式的工程解耦，一份样式文件可被全站数十上百个页面共享复用与浏览器缓存，全站视觉变更只需维护单一样式源文件。

* **引入方式对比表**
    | 引入方式 | 书写位置 | 核心语法特征 | 适用场景 |
    | :--- | :--- | :--- | :--- |
    | **内联样式** | 目标 HTML 开始标签内 | 标签原生 `style` 属性直接赋值 | 临时调试或极个别特异元素微调 |
    | **内部样式表** | 文档 `<head>` 区域内 | 嵌套在 `<style>` 双标签中 | 单页面练习或独立 Demo |
    | **外部样式表** | 独立的 `.css` 物理文件 | `<head>` 中通过 `<link>` 标签引入 | 商业项目与跨页面样式复用规范 |

### 样式引入优先级

* **样式覆盖准则**
    * 优先级链条：在常规无权重干预条件下，引入方式的优先级从高到低为：`内联样式 > 内部样式表 > 外部样式表`。
    * 覆盖机制：高优先级引入方式中的同名属性规则无条件覆盖低优先级规则；低优先级引入方式中的规则无法反向越级。

## CSS选择器体系与匹配机制

### 基础选择器

* **元素选择器（Type Selector / 标签选择器）**
    * > **定义**：直接使用 HTML 标签名作为标识符的基础选择器。
    * 匹配规则：全员通选，页面中所有对应名称的标签全部无差别命中并应用声明规则。

* **类选择器（Class Selector）**
    * > **定义**：以英文半角句点 `.` 作为前缀标识、通过匹配 HTML 标签的 `class` 属性值定位元素的选择器。
    * 匹配规则：允许多个不同的 HTML 元素共用同一个类名；单个标签允许在 `class` 属性中使用空格分隔挂载多个类名；Emmet 展开语法为 `标签.类名`。

* **ID 选择器（ID Selector）**
    * > **定义**：以英文井号 `#` 作为前缀标识、通过匹配 HTML 标签的 `id` 属性值定位元素的选择器。
    * 匹配规则：在规范 HTML 架构中，同一个 `id` 在当前文档中必须保持全局唯一，专用于单一特定节点的排版控制；Emmet 展开语法为 `标签#ID名`。

* **通用选择器（Universal Selector，通配符选择器）**
    * > **定义**：使用单个星号 `*` 声明、无条件命中页面中所有 HTML 元素的选择器。
    * 适用场景：常用于页面样式初始化，例如统一定制全站中文字体族或基准粗细。

### 结构与层级选择器

* **子元素选择器（Child Combinator，`>`）**
    * > **定义**：使用尖括号 `>` 连接前后两个选择器、严格仅命中父元素直接内部第一代亲生子节点的层级选择器。
    * 匹配边界：仅精准作用于父容器第一层级子节点，对深层嵌套的孙代或更深代际元素完全不生效。

* **后代选择器（Descendant Combinator，空格）**
    * > **定义**：使用单个空格连接各级选择器、命中目标父元素内部所有符合条件的各层级后代节点。
    * 匹配边界：后代选择器在作用范围上包含子代选择器；无论层级深浅（子代、孙代、重孙代），全部无差别选中。

* **基础选择器特异性权重基准**
    * 权重层级：在基础选择器体系中，优先级满足 `ID选择器 > 类选择器 > 元素选择器`。带有高特异性类名的选择器会覆盖低特异性的纯标签选择器规则。

### 相邻兄弟选择器

* **相邻兄弟选择器（Adjacent Sibling Combinator，`+`）**
    * > **定义**：使用加号 `+` 连接两个同级元素选择器、选中紧跟在指定目标元素之后的第一个平级兄弟节点的选择器。
    * 匹配规则：遵循“同级紧跟、单向向下”准则；位于指定元素上方的兄弟节点、非直接紧邻的兄弟节点均无法被命中。

### 伪类与伪元素

* **伪类选择器（Pseudo-classes，`:`）**
    * > **定义**：以单冒号 `:` 为前缀、用于捕捉 HTML 元素特定交互瞬态、激活状态或在父容器中文档序列位次的选择器。
    * 核心类型：
        * `:hover`：捕捉鼠标指针悬停在元素上方时的交互瞬态。
        * `:active`：捕捉鼠标在元素上按下但尚未释放时的物理激活瞬态。
        * `:first-child`：命中其父容器内部排列在第一位的首个子元素。
        * `:nth-child(n)`：传入整数序号或公式，精准命中其父容器内部第 $n$ 个指定序列的子元素。

* **伪元素选择器（Pseudo-elements，`::`）**
    * > **定义**：以双冒号 `::` 为前缀、在 DOM 树之外凭空构造看不见的虚拟占位节点并施加样式控制的选择器。
    * 核心代表：
        * `::before`：在宿主元素实际文本内容的最前端注入虚拟节点，必须配合 `content` 属性。
        * `::after`：在宿主元素实际文本内容的最末尾注入虚拟节点，必须配合 `content` 属性。
    * 空间插入机制：
        ```text
        +-----------------------------------------------------------+
        |                      伪元素插入机制                       |
        +-----------------------------------------------------------+
        |  [ ::before 虚拟节点 ] -> 实际文本内容 -> [ ::after 虚拟节点 ] |
        +-----------------------------------------------------------+
        ```

## 文本排版与元素显示模式

### 字体与文本属性

* **基础文本与字体属性**
    * `color`：定义文本前景色，支持色彩英文单词（如 `aqua`）、十六进制代码（如 `#ff0000`）或 RGB 格式（`rgb(255, 0, 0)`）。
    * `font-size`：定义文本字阶尺寸，支持标准像素数值（如 `16px`、`26px`）或相对语义关键字（如 `larger`）。
    * `font-family`：定义文字字体族；中文字体名称（如 `"楷体"`、`"微软雅黑"`）在声明中必须用半角引号包裹。
    * `font-weight`：定义字体笔画字重粗细，支持 `normal`（常规）、`bold`（加粗）、`bolder`（特粗）。
    * `line-height`：定义垂直基准行高，消除紧密堆积带来的压抑感，调节段落阅读的呼吸感与留白空间。

* **字体复合属性（`font`）**
    * > **定义**：允许在单行声明中通过空格分隔同时赋值字重、尺寸与字体族的简写复合属性。
    * 语法范式：`font: font-weight font-size font-family;`，例如 `font: bolder 50px "楷体";`。

### 元素显示模式三态

* **块级元素（Block-level Elements）**
    * 排布规则：始终强制另起新行渲染，默认横向撑满父级容器的整行宽度（100%）。
    * 尺寸控制：可自由显式设定 `width` 与 `height`，完全支持内外边距。
    * 嵌套能力：可容纳其他块级元素与行内元素；典型标签：`<div>`、`<h1>`~`<h6>`、`<p>`、`<ul>`、`<ol>`、`<li>`、`<table>`、`<form>`。

* **行内元素（Inline Elements）**
    * 排布规则：与其他行内元素水平并排在同一行，遇满才自动折行，不主动起行。
    * 尺寸控制：无法直接通过 CSS 设置宽高，其物理宽度与高度完全由内部文本及内容被动撑开。
    * 嵌套规则：严禁包裹块级元素，仅允许容纳其他行内元素或纯文本；典型标签：`<span>`、`<a>`、`<strong>`、`<em>`、`<b>`、`<i>`。

* **行内块元素（Inline-block Elements）**
    * 排布规则：与其他行内元素并排排列在同一行，遇到父级边界时自动折行。
    * 尺寸控制：可自由显式设定 `width` 与 `height`，完全支持内外边距。
    * 嵌套能力：可容纳其他行内或块级元素；典型标签：`<img>`、`<input>`。

* **显示模式三态对比表**
    | 显示模式 | 典型代表标签 | 排布规则与独占特性 | 宽高与内外边距可控性 | 容器嵌套容纳能力 |
    | :--- | :--- | :--- | :--- | :--- |
    | **块级元素** | `div`, `p`, `h1`-`h6` | 始终自起新行，横向独占整行 | 可自由显式设定宽高，完全支持内外边距 | 可容纳块级元素与行内元素 |
    | **行内元素** | `span`, `<a>` | 水平并排在同一行，不主动起行 | 无法直接设置宽高，尺寸由内容撑开 | 严禁容纳块级，仅容纳文本或行内 |
    | **行内块元素** | `img`, `input` | 水平并排在同一行，边界自动折行 | 可自由显式设定宽高，完全支持内外边距 | 可自由容纳行内或块级元素 |

### 显示模式转换机制

* **`display` 属性模式转换**
    * > **定义**：通过调整 `display` 属性的取值，打破并重置 HTML 标签原生排版显示特性的机制。
    * 取值规则：
        * `display: inline;`：转换为行内模式，失去显式宽高控制能力，与周围元素同行并排。
        * `display: inline-block;`：转换为行内块模式，既保留同行并排陈列特性，又获得宽高与内外边距的直接控制权。
        * `display: block;`：转换为块级模式，强制独占整行并支持宽高尺寸设定。
        * `display: none;`：将元素从屏幕渲染树中彻底移除，元素既不可见也不占据任何地面物理空间。

## 盒子模型与空间尺寸控制

### 盒模型组成结构

* **CSS 盒子模型（Box Model）**
    * > **定义**：浏览器渲染引擎将页面中所有 HTML 元素抽象解析为由内向外四层矩形结构的物理空间测算模型。
    * 四大组成区域：
        1. 内容区域（Content）：盒子的核心内核，文字或图像的承载区，由 `width` 与 `height` 直接控制尺寸。
        2. 内边距（Padding）：内容区域外围、边框内壁之间的空白缓冲区，受容器背景颜色浸润，由 `padding` 属性控制。
        3. 边框（Border）：包裹内边距的物理实体外轮廓线条，直接决定盒子可见外轮廓，由 `border` 属性控制。
        4. 外边距（Margin）：边框外层用于推离相邻兄弟盒子或视口边缘的透明空白距离，由 `margin` 属性控制。
    * 盒模型结构图：
        ```text
        +-----------------------------------------------------------+
        |                          margin (外边距)                   |
        |   +---------------------------------------------------+   |
        |   |                      border (边框)                 |   |
        |   |   +-------------------------------------------+   |   |
        |   |   |                  padding (内边距)          |   |   |
        |   |   |   +-----------------------------------+   |   |   |
        |   |   |   |          content (核心内容)       |   |   |   |
        |   |   |   +-----------------------------------+   |   |   |
        |   |   +-------------------------------------------+   |   |
        |   +---------------------------------------------------+   |
        +-----------------------------------------------------------+
        ```

### 边框属性与方向控制

* **边框复合属性（`border`）**
    * 简写范式：`border: 宽度 样式 颜色;`，例如 `border: 5px solid yellowgreen;`。
    * 边框线型（`border-style`）：
        * `solid`：标准连续实线边框。
        * `dashed`：短划线断续组成的虚线边框。
        * `dotted`：微小圆点密集连接的点线边框。
        * `double`：两条平行细实线组成的双实线边框。
    * 单向与分项控制：支持针对单一方向的复合属性（`border-top`、`border-right`、`border-bottom`、`border-left`）以及微观属性（如 `border-left-width`、`border-left-style`、`border-left-color`）。

### 四值顺时针顺延规则

* **四值顺时针旋转赋值法**
    * 旋转基准：以 12 点钟方向的顶部（Top）为起点，沿顺时针方向旋转循环：上 $\to$ 右 $\to$ 下 $\to$ 左。
    * 赋值规则：
        * 传入四个值：`上 右 下 左`（顺时针一周）。
        * 传入三个值：`上 左右 下`（左侧缺省自动取对面的右侧值）。
        * 传入两个值：`上下 左右`（下方缺省取上方，左侧缺省取右侧）。
        * 传入一个值：`上下左右` 四向数值统一。
    * 数值单位约束：
        * 数值为 `0` 时可安全省略单位（写作 `0`）。
        * 数值非 0 时必须严格显式声明长度单位（如 `10px`）。
        * > **易错点**：⚠️ 非 0 的尺寸数值若遗漏 `px` 单位（例如误写为 `padding: 10 0 20;`），整条声明会被浏览器解析引擎判定为语法错误并全盘抛弃忽略。
    * 统一步长：该顺延机制完全统一适用于 `padding`、`margin`、`border-width`、`border-style` 与 `border-color`。

### 内外边距排版控制

* **内边距（Padding）**
    * 排版机理：向外撑开内容与边框内壁的间隔，防止内容挤压贴边，背景颜色全额延伸至内边距区域。

* **外边距（Margin）**
    * 排版机理：外边距是完全透明的物理缓冲区，用于在当前盒子的外边框与视口边界或其他相邻兄弟盒子的边框之间维持距离隔离。

## 浮动机制与布局流重构

### 网页布局模式演进

* **五大常见排版方案**
    * 标准流（Normal Flow，文档流）：浏览器默认排版基准，块级自上而下竖排独占行，行内自左向右横排折行。
    * 浮动（Float）：传统 CSS 横向并排核心手段，打破标准流竖排限制。
    * 定位（Position）：跳脱文档流，基于坐标系实现空间重叠与固定悬停。
    * 弹性盒（Flexbox）与网格（Grid）：现代一维轴线与二维网格自适应响应式布局系统。
    * 布局本质：在屏幕空间上对一系列矩形盒子进行尺寸测算与摆放。

### 浮动机制与微观间隙

* **行内块微观缝隙缺陷（Whitespace Bug）**
    * 缺陷机理：将元素设为 `display: inline-block;` 并排显示时，HTML 源代码标签之间的换行符或空格会被浏览器解析渲染为约 4 至 8 像素的物理空白间隙，导致多盒子无法严丝合缝紧贴，容易引发百分比总宽超限而跌落换行。

* **浮动无缝贴合机制**
    * 核心优势：设置浮动的元素相互之间完全紧密贴靠，元素之间不保留任何微观空白间隙；父容器宽度充足时同行并排，父容器宽度不足时多出的盒子自动换行紧贴排列。
    * 相对边界：浮动仅相对于其直接父元素展开，浮动盒子只在其父元素内部有效区域游弋，绝不溢出父级边界。
    * 基础语法：`float: left;`（左浮动）、`float: right;`（右浮动）、`float: none;`（默认不浮动）。

### 浮动物理特性

* **浮动三大核心物理特性**
    * 脱标（脱离标准流）：元素施加浮动后瞬间腾空脱离标准文档流，在地表失去全部物理占位空间；后续标准流元素感知前方为空，立即主动上移填补其原本留下的地面地基。
    * 一行显示，顶部对齐：多个浮动盒子沿指定浮动方向依次紧密并排陈列，且在水平线上始终严格保持顶端基准对齐。
    * 激活行内块特性：任何元素（含行内元素 `<span>`、`<a>`）设置浮动后，无需书写 `display: inline-block;` 即可直接显式赋予 `width` 与 `height` 并完整生效。

### 高度坍塌与清除浮动

* **父元素高度坍塌（Height Collapse）**
    * 坍塌成因：父容器未显式设置固定高度（高度设计上应由子元素自然撑开），其内部子元素全部施加浮动而脱标升空；父容器在地表失去标准流内容支撑而误判自身为空，物理高度瞬间缩水归零（0px）。
    * 破坏表现：父容器背景色消失，边框被压缩为单条水平细线，后续标准流元素强制上移并穿插卡入左右浮动盒子的缝隙中间，破坏整体版面结构。
    * 坍塌机理图：
        ```text
        +-----------------------------------------------------------+
        |               父元素高度坍塌的机理与破坏表现              |
        +-----------------------------------------------------------+
        |  .father (未设高度, 误以为内部无子元素, 实际高度缩为 0px) |
        +-----------------------------------------------------------+
               ^                                      ^
               | (子盒子脱标腾空)                      | (子盒子脱标腾空)
          [ .left-son ]                          [ .right-son ]
          (飘浮在半空)                            (飘浮在半空)
        -------------------------------------------------------------
          地面标准流文本: 失去地面支撑，强行上移穿插至浮动盒之间
        ```

* **闭合清除浮动方案**
    * 方案一：父容器添加 `overflow: hidden;`
        * 解决机理：在父元素声明 `overflow: hidden;` 触发块格式化上下文（Block Formatting Context，BFC）；BFC 规定在测算容器高度时浮动子元素必须全额计入空间统计，从而自适应撑开父容器高度。
        * 适用边界：单行简明高效；但若子容器存在需要有意溢出显示的下拉子菜单或悬停提示框时，溢出内容会被强行裁剪切除。
    * 方案二：父容器伪元素清除法（Clearfix）
        * 代码实现：
            ```css
            .father::after {
                content: "";
                display: table;
                clear: both;
            }
            ```
        * 协同机理：
            1. `::after` 在父容器内容的物理最末尾虚拟生成看不见的伪节点；
            2. `content: "";` 保持注入的伪节点内容为空；
            3. `display: table;` 将该虚拟节点转换为具有块级特征的表格格式化上下文；
            4. `clear: both;` 严厉声明该虚拟节点左右两侧绝对不允许存在任何浮动元素，强制该虚拟节点下沉排挤至所有浮动盒子的最底端；作为父容器最后一个物理子节点，其自然将父容器下边界推至最底，实现高度自适应闭合。
