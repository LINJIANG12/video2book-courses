# Stanford CS231N：深度学习与计算机视觉（18 讲）

斯坦福大学计算机视觉与深度学习的传世经典名课，由李飞飞（Fei-Fei Li）教授携手顶级教学团队打造。课程从视觉识别与线性分类器讲起，深入反向传播与卷积神经网络（CNN）架构演进，系统展开注意力机制、Vision Transformer、目标检测与语义分割，并前沿拓展至大规模分布式训练、自监督表征、生成模型（Diffusion/GAN）、三维几何视觉、图文多模态与具身机器人学习。理论推导扎实、视觉体系完备，是计算机视觉领域不可替代的入门与进阶全景教材。

## 怎么学

课程主线遵循视觉表征的层次演进：**线性分类与优化 → 深度神经网络与 CNN → 时序建模与视觉 Transformer → 密集预测与时空视频 → 分布式系统与前沿生成/具身智能**。建议：

- **系统通读视觉全景** → `textbooks/` 从卷一顺次读到卷五。模块划分将连续的 18 讲有机聚合成 5 册连贯教材，每册开头有系统导读、结尾有技术演进总结
- **吃透卷积与反向传播数学推导** → 研读模块 01 与 02，结合笔记 01、02。深入理解计算图的链式法则局部梯度流转，以及卷积核感受野、步长、填充与现代 CNN 架构演进的工程取舍
- **掌握现代视觉架构与检测分割** → 重点研读模块 03 与笔记 03、04。从 RNN 图像描述、Self-Attention 到 ViT（Vision Transformer），再到两阶段与单阶段目标检测、FCN 语义分割与特征图可视化（CAM/Grad-CAM）
- **拓展前沿多模态、生成与具身智能** → 重点研读模块 04、05 与笔记 05、06、07。涵盖工业级 GPU 集群并行训练、自监督 Pretext 任务、Diffusion 生成扩散模型、3D 点云与 NeRF 神经辐射场，以及机器人模仿强化学习与以人为本的 AI
- **考前突击与全局复盘** → 直接看 `notes/`。7 篇复习笔记提炼了核心公式、模型对比表与高频工程要点，每篇开头的知识拓扑树可直接导出为脑图
- **核对讲师原话与课堂细节** → `subtitles/` 提供全部 18 讲的逐字清洗转录稿，适合定向检索特定概念、参数设置或讲师课堂板书细节
