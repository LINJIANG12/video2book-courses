# 数据库系统（DBMS）（28 讲）

国内高校经典「数据库系统概论」式的数据库原理课，前两集先用 IT 行业总览与信息系统中的数据存储、商务智能建立背景，随后从绪论、关系模型与 SQL 一路讲到安全性、完整性、关系数据理论与范式、数据库设计、数据库编程、查询处理与优化。全 28 集、约 24.9 小时，主线是建立从数据组织、模式约束到实现与性能优化的完整原理框架。它与本仓的「MySQL数据库入门到大牛」互补而非重复：那门 199 讲课侧重从安装到优化的工具与工程实践，本课专注数据库原理与理论。

- **原视频**：[《数据库系统（DBMS）》](https://www.bilibili.com/video/BV1Le4y1o7v5/) — Bilibili，BV1Le4y1o7v5
- **全 28 集**，已产出 10 册模块全书、8 篇复习笔记、31 份逐字稿

## 怎么学

- **先读第 1~3 册建立共同语言**：前导、绪论与关系模型先打底，第 4 册的 SQL 才有明确的操作对象。
- **把关系代数当作全课工具**：从第 3 册的基础运算，到第 8 册的模式设计与第 10 册的查询处理，都要能用它拆解问题。
- **第 7 册范式是理论高点**：按「数据依赖 → 候选码 → 范式 → 模式分解」串读，别只背各范式定义。
- **第 10 册查询优化最难，值得留到最后**：先顺着查询处理流程理解关系代数如何落到可执行查询，再读优化策略与代价判断，并回看第 3 册。
- **想动手时接上「MySQL数据库入门到大牛」**：用那门课在本地安装 MySQL、练 SQL、跑索引和事务案例，本课负责解释这些做法背后的原理，两边对着读。
