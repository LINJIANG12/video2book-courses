# 数据库系统（DBMS）（28 讲）

国内高校经典「数据库系统概论」式的数据库原理课：先用 IT 行业总览与信息系统中的数据存储建立背景，再从绪论、关系模型与关系代数一路讲到 SQL 语言、数据库安全性与完整性、关系数据理论与范式、数据库设计、数据库编程，最后落到关系查询的处理与优化。全 28 集、约 24.9 小时，主线是建立从数据组织、模式约束到实现与性能优化的完整原理框架。它与本仓的「MySQL数据库入门到大牛」互补而非重复：那门 199 讲课侧重从安装到优化的工具与工程实践，本课专注数据库原理与理论。

- **原视频**：[《数据库系统（DBMS）》](https://www.bilibili.com/video/BV1Le4y1o7v5/) — Bilibili，BV1Le4y1o7v5
- **全 28 集**，已产出 8 册模块全书、11 篇复习笔记、31 份逐字稿

## 怎么学

- **前两册打底，别跳**：第 1 册把「为什么要有数据库系统」讲透（数据怎么组织、文件系统的局限、三级模式），第 2 册把二维表与关系代数讲成后面所有章节的工具。
- **第 3 册是全课操作主线**：数据定义 → 单表查询 → 多表三条路 → 更新与视图，按能写出来的顺序读，SQL 的手感就建立在这里。
- **第 4 册是「谁来用、用得合不合法」**：安全性管身份与权限，完整性管数据本身合不合语义，断言与触发器把判断变成行动，两条线要对着读。
- **第 5 册是理论高点**：按「一张表为什么也有问题 → 函数依赖 → 候选码 → 1NF/2NF/3NF → BCNF → 多值依赖与 4NF → 公理系统与闭包」串读，别只背范式定义；末尾那道从函数依赖判 3NF 的大题是检验是否真懂的标准件。
- **第 6 册按六个阶段走一遍完整设计**：概念结构（E-R 图）→ 逻辑结构（E-R 图转关系模式）→ 物理结构（索引与存取路径），再读第 6 册末的精简版把考试重点串一遍。
- **第 7~8 册留到最后**：先看嵌入式 SQL、存储过程与 ODBC 怎么把数据库接进程序，再读查询处理流程、代数优化与物理优化——那时你已经知道查询从哪来，优化才有意义。
- **想动手时接上「MySQL数据库入门到大牛」**：用那门课在本地装 MySQL、练 SQL、跑索引和事务案例，本课负责解释这些做法背后的原理，两边对着读。
