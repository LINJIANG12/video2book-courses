# 南京大学：科研筑基（结丹期教授亲授）（12 讲）

南京大学计算机系青年教授结合自身成长历程倾囊相授的科研方法论与学术心法。课程打破传统的说教套路，直击研究生阶段最核心的痛点：如何打破思维定势、如何从零找到真正有价值的研究问题、如何撰写并发表高质量学术论文，以及如何在科研高压与焦虑中建立健康的身心秩序与学术志业。

## 怎么学

课程主线遵循科研人员成长的内在逻辑：**认知重塑与选题破局 → 学术表达与执行效能 → 身心秩序与学术守正**。建议：

- **破除科研迷茫与选题困境** → 重点研读模块 01，建立「问题远比方法重要」的第一性原理，学会通过解禁想象力与矛盾识别锁定高质量课题
- **攻克学术写作与汇报难关** → 重点研读模块 02，掌握自顶向下的学术叙事技巧、论文 Story 架构与学术报告的吸引力法则
- **重构科研生活节奏与抗压心法** → 重点研读模块 03，理解「玩得好与科研做得好绝不冲突」的平衡之道，建立可持续的学术生命周期
- **复习回顾与行动对照** → 定期通读 `notes/` 目录下的 3 篇速查笔记，对照其中的误区与行动清单反思自身研究状态
