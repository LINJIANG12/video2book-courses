# 耶鲁大学：情绪管理（35 讲）

耶鲁大学公开课以社会情感学习（SEL）为主线，讲解情绪如何影响注意力、决策、人际关系、身心健康与创造力，并进一步介绍情绪测量、思维调节、正念、积极自我对话、共情理解和情绪共调节。课程最后把个人调节方法延伸到家庭、学校和领导力场景，强调通过对话、策略与跟进建立支持情绪发展的环境。

## 怎么学

**先建立情绪与学习、生活之间的因果地图**。从课程引入部分开始，区分情绪对注意力、决策、关系、身心健康和创造力的不同影响，避免把“情绪管理”理解成压抑情绪。

**学习测量与调节方法时区分觉察、解释和行动**。重点掌握情绪识别、情绪测量、呼吸与计划、积极自我对话、思维重塑和正念的适用边界。

**理解共情时同时关注行为与情感的差异**。不要从单一行为推断他人的内在状态，观察情绪共调节如何在对话中帮助对方提高情绪能力。

**把课程方法迁移到真实关系与组织场景**。练习对话的五个步骤——管理情绪、提高情绪、集思广益、制定策略、结束并跟进——并思考如何在学校和家庭中建立关怀文化。

**复习时用两篇笔记串联理论与应用**。第一篇聚焦自我觉察、测量与调节，第二篇聚焦共情、干预和情绪友好环境；需要核对具体研究或案例时，再查 3 份逐字稿。
