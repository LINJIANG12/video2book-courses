# 专门关系运算（六）：选择与投影的形式化规约与行列切分机理

## 1. 核心概念与本质内涵：从二维矩阵视角解构关系运算

传统的集合运算（并、差、交、笛卡尔积）仅从平面集合的角度对关系进行整体操作，未充分利用关系二维表独有的“行（元组）”与“列（属性）”结构特征。

在关系代数中，**专门的关系运算**正是针对二维表格的几何空间结构而设计的。其中最基础、最核心的一对正交运算是**选择（Selection）**与**投影（Projection）**：
- **选择（Selection, $\sigma$）**：在二维表空间中进行**水平方向（Horizontal）的切分**，提取满足条件的行；
- **投影（Projection, $\pi$）**：在二维表空间中进行**垂直方向（Vertical）的切分**，提取指定的列并执行集合去重。

```text
               二维表矩阵的行列正交切分机制
             
         属性列 1     属性列 2     属性列 3     属性列 4
      +------------+------------+------------+------------+
行 1  |            |  ████████  |            |  ████████  |  <── 满足谓词 F
      +------------+------------+------------+------------+
行 2  |            |            |            |            |  <── 不满足条件 (丢弃)
      +------------+------------+------------+------------+
行 3  |            |  ████████  |            |  ████████  |  <── 满足谓词 F
      +------------+------------+------------+------------+
                         ▲                        ▲
                         │                        │
                      【投影提取列 2】          【投影提取列 4】
```

## 2. 选择运算（Selection, $\sigma$）的形式化定义与执行机理

### 2.1 形式化定义

选择又称为限制（Restriction）。它是在关系 $R$ 中选择满足给定逻辑条件的诸元组，记作：

$$\sigma_F(R) = \{t \mid t \in R \land F(t) = \text{'真'}\}$$

- **算子符号**：希腊字母 $\sigma$（Sigma）；
- **下标谓词 $F$**：指逻辑选择条件，它是一个命题公式，取值为“真”或“假”；
- **谓词 $F$ 的结构**：由属性名、比较运算符（$=, \neq, <, \le, >, \ge$）和常量/属性构成的原子项，通过逻辑运算符（非 $\neg$、与 $\land$、或 $\lor$）连接而成。

### 2.2 特征与工程对应

1. **维度特征**：选择运算只改变关系的**基数（元组行数）**，绝对不改变关系的**目（属性列数）**；
2. **SQL 工程映射**：在 SQL 语言中，选择运算对应于 `SELECT * FROM R WHERE <F>` 中的 **`WHERE` 子句过滤机制**。

---

## 3. 投影运算（Projection, $\pi$）的形式化定义与集合去重

### 3.1 形式化定义

投影运算是在关系 $R$ 中选择若干属性列组成新的关系，记作：

$$\pi_A(R) = \{t[A] \mid t \in R\}$$

- **算子符号**：希腊字母 $\pi$（Pi）；
- **下标 $A$**：为 $R$ 中的属性名列表（或属性列序号集合），$A \subseteq U$；
- **$t[A]$ 的含义**：表示元组 $t$ 在属性列集 $A$ 上的分量集合。

### 3.2 投影运算的核心纪律：自动消除重复元组

> **易错点**：投影运算在去除了原关系的主码列后，剩余属性列的组合极可能出现数值完全相同的行。

- 依据关系模型的基本定义，**关系是一个纯数学集合，集合中绝不允许存在重复元素**；
- 因此，形式化关系代数中的投影运算隐含着一条刚性规则：**投影完成后必须自动剔除重复元组（Deduplication）**；
- **SQL 工程映射**：关系代数的 $\pi_A(R)$ 在 SQL 中严格对应于带显式去重标记的查询语句：
  ```sql
  SELECT DISTINCT A FROM R;
  ```
  （若不加 `DISTINCT`，SQL 默认的 `SELECT A FROM R` 产出的是保留重复行的多重集 Multiset，不属于纯正的关系代数投影）。

## 4. 典型例题与深度演算

设学生关系 `Student` 包含如下数据：

```text
关系 Student:
+--------+--------+--------+-----+------------+
|  Sno   | Sname  |  Ssex  | Sage|   Sdept    |
+--------+--------+--------+-----+------------+
| 202601 | 李  强 |   男   |  20 | 计算机系   |
| 202602 | 王  芳 |   女   |  19 | 信息管理   |
| 202603 | 张  伟 |   男   |  21 | 计算机系   |
| 202604 | 赵  敏 |   女   |  20 | 软件工程   |
| 202605 | 孙  杰 |   男   |  20 | 计算机系   |
+--------+--------+--------+-----+------------+
```

### 演算 1：单选择运算
**查询计算机系所有年龄大于 20 岁的学生**：
- 关系代数表达式：
  $$\sigma_{\text{Sdept} = \text{'计算机系'} \land \text{Sage} > 20}(\text{Student})$$
- 运算结果：
  ```text
  +--------+--------+--------+-----+------------+
  |  Sno   | Sname  |  Ssex  | Sage|   Sdept    |
  +--------+--------+--------+-----+------------+
  | 202603 | 张  伟 |   男   |  21 | 计算机系   |
  +--------+--------+--------+-----+------------+
  ```

### 演算 2：单投影运算
**查询全校学生的所有系别**：
- 关系代数表达式：
  $$\pi_{\text{Sdept}}(\text{Student})$$
- 运算结果（注意：计算机系出现 3 次，但投影必须自动去重）：
  ```text
  +------------+
  |   Sdept    |
  +------------+
  | 计算机系   |
  | 信息管理   |
  | 软件工程   |
  +------------+ (基数为 3，非 5)
  ```

### 演算 3：选择与投影复合运算
**查询计算机系所有男生的姓名与年龄**：
- 复合表达式：
  $$\pi_{\text{Sname}, \text{Sage}}(\sigma_{\text{Sdept} = \text{'计算机系'} \land \text{Ssex} = \text{'男'}}(\text{Student}))$$
- 运算推导步骤：
  1. 先进行行选择，过滤出满足条件的三条记录（李强、张伟、孙杰）；
  2. 再进行列投影，仅抽取 `Sname` 和 `Sage` 两列：
  ```text
  +--------+-----+
  | Sname  | Sage|
  +--------+-----+
  | 李  强 |  20 |
  | 张  伟 |  21 |
  | 孙  杰 |  20 |
  +--------+-----+
  ```

## 5. 随堂巩固自测

### 自测题 1（单项选择题）
设有关系 $R(A, B, C)$，包含 100 条元组，其中属性 $B$ 均取不同的值。若执行运算 $\pi_{A, C}(R)$，则所得新关系的元组数量 $K$ 满足的范围是（ ）
A. $K = 100$  
B. $K \le 100$  
C. $K \ge 100$  
D. $K = 0$  

**【答案】**：B  
**【解析】**：由于 $B$ 属性取值互不相同，原关系中元组互异。但投影 $\pi_{A, C}(R)$ 丢弃了属性 $B$，剩余属性 $(A, C)$ 的取值可能存在多行完全一致的情况。投影运算必须消除重复元组，因此结果集元组数至多为 100，即 $K \le 100$。故选 B。

---

### 自测题 2（代数表达书写题）
设有关系模式：  
`Student(Sno, Sname, Ssex, Sage, Sdept)`  
`Course(Cno, Cname, Cpno, Ccredit)`  
请写出查询“学分（Ccredit）大于 3 分的课程名（Cname）和课程号（Cno）”的形式化关系代数表达式。

**【参考答案】**：
$$\pi_{\text{Cname}, \text{Cno}}(\sigma_{\text{Ccredit} > 3}(\text{Course}))$$
*(注：根据投影属性次序无关性，$\pi_{\text{Cno}, \text{Cname}}$ 亦视为完全正确)*。
