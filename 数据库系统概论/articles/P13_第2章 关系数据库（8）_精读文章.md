# 专门关系运算（八）：象集概念、除运算形式化求解与全称量词表达

## 1. 核心概念与本质内涵：全称量词查询的理论克星

在关系数据库的日常查询中，有一类具有极高业务重要性但代数表达难度最高的场景——**包含全称量词（$\forall$，“全部”、“所有”、“每个”）的查询**。
例如：
- “查询选修了**全部**课程的学生姓名”；
- “查询采购了供应商 $S_1$ 提供的**所有**零件的工程项目编号”；
- “查询掌握了某技术栈中**全部**必修语言的应聘者名单”。

在关系代数中，专门用于求解此类全称量词包含关系的运算就是**除运算（Division, $\div$）**。除运算是关系代数中概念最抽象、推导步骤最严密的高阶算子。

---

## 2. 核心数学前置概念：象集（Image Set, $Z_x$）

要真正理解并正确计算除运算，必须先彻底掌握**象集（Image Set）**的形式化定义。

### 2.1 象集的形式化定义

设关系模式为 $R(X, Z)$，其中 $X$ 和 $Z$ 是两个互不相交的属性组（$X \cup Z = U_R$ 且 $X \cap Z = \varnothing$）。

给定关系 $R$ 中属性组 $X$ 上的一个具体取值 $x$（$x \in \pi_X(R)$），定义 **$x$ 在关系 $R$ 中的象集**，记作 $Z_x$，其形式化集合为：

$$Z_x = \{t[Z] \mid t \in R \land t[X] = x\}$$

### 2.2 象集的物理直观理解

> **通俗理解**：象集就是把关系表按照 $X$ 列的值进行“分组”，在某一个组内，$X$ 的值固定为 $x$。此时，**在这一组中与该 $x$ 搭配共存的所有 $Z$ 属性分量的取值集合**，就是 $x$ 的象集 $Z_x$。

```text
关系 R:
+----+----+
| A  | B  |
+----+----+
| a1 | b1 |  \
| a1 | b2 |  ── A 取值 a1 时，搭配的 B 值有 {b1, b2, b3}，故 B_(a1) = {b1, b2, b3}
| a1 | b3 |  /
+----+----+
| a2 | b1 |  \
| a2 | b2 |  ── A 取值 a2 时，搭配的 B 值有 {b1, b2}，故 B_(a2) = {b1, b2}
+----+----+
| a3 | b1 |  ── A 取值 a3 时，搭配的 B 值仅有 {b1}，故 B_(a3) = {b1}
+----+----+
```

## 3. 除运算（Division, $\div$）的形式化定义与标准求解四步法

### 3.1 形式化定义

给定关系 $R(X, Y)$ 和关系 $S(Y, Z)$，其中 $X, Y, Z$ 为属性组。关系 $R$ 除以关系 $S$ 的结果是一个以 $X$ 为属性组的新关系，记作：

$$R \div S = \{t_r[X] \mid t_r \in R \land \pi_Y(S) \subseteq Y_x\}$$

其中 $Y_x$ 为 $x = t_r[X]$ 在关系 $R$ 中的象集。

### 3.2 除运算语义解读

> **本质判定条件**：一个 $x$ 能否作为除运算的结果输出，**充要条件是：该 $x$ 在 $R$ 中的象集 $Y_x$，必须完全包含（$\supseteq$）关系 $S$ 在公共属性 $Y$ 上的所有投影取值集合（$\pi_Y(S)$）**！

---

### 3.3 标准求解四步法则 (The 4-Step Algorithm)

计算任何复杂的除运算 $R \div S$，严格按以下四个标准化步骤执行即可确保 100% 正确：

```text
[第 1 步: 确定结果属性组]
 寻找在 R 中存在但在 S 中不存在的属性组 X = U_R - U_S。
 结果关系的属性集合必然是 X。
         │
         ▼
[第 2 步: 计算目标基准集]
 提取关系 S 在公共属性 Y 上的投影集合: Target = π_Y(S)。
         │
         ▼
[第 3 步: 穷举被除数的象集]
 遍历 R 在 X 列上的每一个不同取值 x，逐一列出其对应的象集 Y_x。
         │
         ▼
[第 4 步: 集合包含性真值校验]
 逐一比对: Target ⊆ Y_x 是否成立？
 若成立，则将 x 收入最终结果表；若不成立，则剔除。
```

## 4. 典型例题与深度演算

设有被除数关系 $R$ 和除数关系 $S$ 如下：

```text
关系 R:                     关系 S:
+----+----+----+            +----+----+
| A  | B  | C  |            | B  | C  |
+----+----+----+            +----+----+
| a1 | b1 | c1 |            | b1 | c1 |
| a1 | b2 | c2 |            | b2 | c2 |
| a1 | b3 | c3 |            +----+----+
| a2 | b1 | c1 |
| a2 | b2 | c2 |
| a3 | b1 | c1 |
| a4 | b2 | c2 |
+----+----+----+
```

### 执行推导过程：

1. **第 1 步：确定结果属性组**
   - $R$ 的属性集为 $(A, B, C)$，$S$ 的属性集为 $(B, C)$；
   - 结果属性组 $X = \{A, B, C\} - \{B, C\} = \{A\}$。结果表仅包含一列属性 $A$。
2. **第 2 步：计算目标基准集**
   - 公共属性为 $(B, C)$；
   - 目标集合 $\text{Target} = \pi_{B, C}(S) = \{(b1, c1), (b2, c2)\}$。
3. **第 3 步：求 $R$ 中各 $A$ 取值的象集 $(B, C)_A$**
   - 当 $A = a1$ 时：$(B, C)_{a1} = \{(b1, c1), (b2, c2), (b3, c3)\}$；
   - 当 $A = a2$ 时：$(B, C)_{a2} = \{(b1, c1), (b2, c2)\}$；
   - 当 $A = a3$ 时：$(B, C)_{a3} = \{(b1, c1)\}$；
   - 当 $A = a4$ 时：$(B, C)_{a4} = \{(b2, c2)\}$。
4. **第 4 步：包含性比对（$\text{Target} \subseteq (B, C)_{A}$）**
   - 对 $a1$：$\{(b1, c1), (b2, c2)\} \subseteq \{(b1, c1), (b2, c2), (b3, c3)\}$，**满足包含**，入选！
   - 对 $a2$：$\{(b1, c1), (b2, c2)\} \subseteq \{(b1, c1), (b2, c2)\}$，**完全相等，满足包含**，入选！
   - 对 $a3$：漏掉了 $(b2, c2)$，不满足，剔除！
   - 对 $a4$：漏掉了 $(b1, c1)$，不满足，剔除！

### 最终计算结果：
$$R \div S = \begin{array}{|c|} \hline A \\ \hline a1 \\ a2 \\ \hline \end{array}$$

## 5. 随堂巩固自测

### 自测题 1（单项选择题）
设有学生选课关系 $SC(Sno, Cno)$ 与课程关系 $C(Cno)$，其中 $C$ 包含了全校所有的 3 门必修课号。若要查询“选修了全部必修课的学生学号”，最精确的关系代数运算是（ ）
A. $SC \Join C$  
B. $SC \div C$  
C. $\pi_{Sno}(SC) \times C$  
D. $\pi_{Sno}(SC) - C$  

**【答案】**：B  
**【解析】**：本题属于典型的全称量词包含问题。$SC(Sno, Cno) \div C(Cno)$ 的求解过程会抽取每个学生 $Sno$ 的选课象集 $Cno_{Sno}$，只要该学生的选课集合包含了 $C$ 中的全部课程号，其学号就会被保留。故选 B。

### 自测题 2（实战求解题）
设有某公司员工技能掌握表 `Skill(EmpNo, Tech)` 与项目硬性技能要求表 `Req(Tech)`：
```text
表 Skill:                   表 Req:
+-------+------------+      +------------+
| EmpNo |    Tech    |      |    Tech    |
+-------+------------+      +------------+
|  E01  | Java       |      | Java       |
|  E01  | SQL        |      | SQL        |
|  E01  | Docker     |      +------------+
|  E02  | Java       |
|  E02  | Python     |
|  E03  | Java       |
|  E03  | SQL        |
+-------+------------+
```
请通过除运算求出完全满足项目技能要求的员工工号（写出详细步骤）。

**【参考答案与步骤推导】**：
1. **结果属性列**：$\{EmpNo, Tech\} - \{Tech\} = \{EmpNo\}$；
2. **目标技能集合**：$\pi_{Tech}(Req) = \{\text{'Java'}, \text{'SQL'}\}$；
3. **求各员工技能象集**：
   - $Tech_{E01} = \{\text{'Java'}, \text{'SQL'}, \text{'Docker'}\}$；
   - $Tech_{E02} = \{\text{'Java'}, \text{'Python'}\}$；
   - $Tech_{E03} = \{\text{'Java'}, \text{'SQL'}\}$；
4. **比对包含性**：
   - 对 $E01$：$\{\text{Java}, \text{SQL}\} \subseteq \{\text{Java}, \text{SQL}, \text{Docker}\}$ $\implies$ 满足！
   - 对 $E02$：缺 $\text{SQL}$ $\implies$ 不满足！
   - 对 $E03$：$\{\text{Java}, \text{SQL}\} \subseteq \{\text{Java}, \text{SQL}\}$ $\implies$ 满足！
5. **最终结果**：员工工号为 **E01 和 E03**。
