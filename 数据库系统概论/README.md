## 怎么学

这门课的特点是**推导多、公式多**：关系代数、函数依赖、范式分解都需要动笔。长文里保留了完整的推导演算过程，建议对照教材边读边写：

- **按章节复习** → `textbooks/` 的 11 册与教材章节一一对应，学到第几章就翻第几册
- **查具体例题** → `articles/` 里按 `PXX_` 编号找对应讲次，例题解析更细
- **公式阅读** → 关系代数与规范化部分含行内公式，用 Typora 打开前请先开启「内联公式」，否则会显示成 `$…$` 源码

SQL、关系代数与规范化这三块是考试与面试的高频区，模块 03 与模块 06 值得反复读。
