## 大语言模型架构演进与现代设计选择
> 对应块：BLK03 | 覆盖分集：P03上 | 块标题（分集名）：《Lecture 3_ Architectures》

模型架构（Architecture）在很大程度上一直笼罩着一层让人摸不着头脑的迷雾。我们可能都曾设想过，要是能单纯依靠 VC 维（Vapnik-Chervonenkis Dimension）这类简洁优雅的统计学习理论工具，就能直接推导并指导整个大模型架构的设计，那该多好。但工业界与学术界的工程现实并非如此。理解模型架构最彻底的途径，是亲自去训练大量模型，穷尽不同的结构排列；然而由于算力与时间预算的客观约束，任何人都不可能完全覆盖现有的高维设计空间。

因此，更为务实的路径是从经验主义与综述视角出发，观察前人所做出的技术取舍。通过横向比对主流有效架构，我们将发现：某些设计在现代大模型中已经收敛为近乎固定的行业共识，而另一些超参数则可以在宽泛的区间内自由调整且不损伤模型表现。理解现代 Transformer 架构演进，本质上就是厘清从标准 Vanilla Transformer 出发，哪些微观组件被替换、为何替换，以及哪些宏观设计经受住了工程时间的检验。

### 架构设计空间与经验主义认知路径

#### 理论工具局限与经验归纳方法

在面对语言模型架构时，理论推演往往无法提供精细到特定模块能否带来困惑度收益的先验判断。学习架构设计，主要依赖于对前人大量实证探索的系统性梳理。通过广泛观察模式，归纳出具备强鲁棒性的工程实践。

这种认知方式与小规模消融实验互为补充：一方面需要借助大规模工业级报告了解前沿收敛态，另一方面需在受限资源下验证机制间的协同效应。由于当前公开文献极少能完整披露工业级大模型的全部实现细节，建立这种跨模型的设计对比直觉至关重要。

#### 经典基准与现代架构核心差异

以原始 Vanilla Transformer 为基准，整个演进脉络清晰可见。原始设计包含一系列标准选择：使用基于正弦与余弦函数的绝对位置编码、在非线性前馈网络中使用 ReLU 激活函数、以及在残差连接之后进行层归一化的 Post-LN 拓扑。

```text
Vanilla Transformer 结构：
Input -> [Positional Encoding (Sin/Cos)] -> [Attention] -> [Post-LN] -> [Residual Add] 
      -> [MLP (ReLU)] -> [Post-LN] -> [Residual Add]

现代 Transformer 典型结构（以 LLaMA/PaLM 脉络为例）：
Input -> [Pre-RMSNorm] -> [RoPE-Attention] -> [Residual Add] 
      -> [Pre-RMSNorm] -> [SwiGLU-MLP]     -> [Residual Add]
```

现代大语言模型（包括主流开源基础模型如 LLaMA 系列及其衍生模型）对上述核心组件进行了系统性替换：
- 归一化层前置于非残差分支（Pre-Norm），并普遍转向 RMSNorm；
- 位置编码全面转向旋转位置编码（Rotary Position Embedding, RoPE）；
- 前馈网络全面由标准非线性映射转向门控线性单元（如 SwiGLU）。

### 激活函数与前馈网络门控机制

#### 门控线性单元机制与 SwiGLU

门控线性单元（Gated Linear Unit, GLU）及其变体已成为现代语言模型前馈网络层（MLP/FFN）的绝对主流配置。在以 PaLM 和 LLaMA 为代表的现代网络中，SwiGLU 得到了最广泛的应用。

在标准 MLP 中，隐藏状态仅通过单个线性变换后接入非线性激活函数，再经由第二层线性变换投射回模型维度：

$$\text{MLP}(x) = \sigma(x W_1) W_2$$

而在门控单元中，网络引入了并行的门控分支。以 SwiGLU 为例，输入向量分别通过两个独立的权重矩阵计算，其中一个分支经过 Swish（或称 SiLU）激活后作为门控信号，与另一分支进行逐元素相乘（Hadamard 积），最后再进行线性降维：

$$\text{SwiGLU}(x) = \left( \text{Swish}(x W) \odot x V \right) W_2$$

> **结论**：虽然具体的非线性激活函数存在多种选择，但门控机制（Gating）本身的存在是带来性能跃升的关键。门控机制赋予了网络动态调节信息流动的能力，在近乎不增加额外推理延迟的前提下，能够稳定带来显著的损失下降。

#### 参数守恒约束下的维度缩放法则

引入门控机制带来了一个不可忽视的参数量膨胀问题。标准两层 MLP 仅包含两个投影矩阵 $W_1 \in \mathbb{R}^{d \times d_{ff}}$ 与 $W_2 \in \mathbb{R}^{d_{ff} \times d}$；而门控结构引入了额外的矩阵 $V \in \mathbb{R}^{d \times d_{ff}}$，使参数矩阵数量由两个增至三个。

为了在对比实验或模型设计中控制总参数量与浮点运算量（FLOPs）严格对齐，必须对前馈维度的隐藏层宽度进行缩减：

```text
标准 MLP 参数构成（隐藏维度 d_ff）：
矩阵 W1: d * d_ff
矩阵 W2: d_ff * d
总参数量 = 2 * d * d_ff

门控 MLP 参数构成（隐藏维度 d_ff'）：
矩阵 W:  d * d_ff'
矩阵 V:  d * d_ff'
矩阵 W2: d_ff' * d
总参数量 = 3 * d * d_ff'

令两者参数对齐：
3 * d * d_ff' = 2 * d * d_ff  =>  d_ff' = (2/3) * d_ff
```

> **提示**：将门控前馈网络的输出维度缩小为原标准的 $\frac{2}{3}$，是业内通行的参数对齐经验法则。这一缩放确保了引入门控分支的增益完全来自于架构拓扑与表示能力的提升，而非单纯依靠参数规模扩张。

#### 经验验证证据与非门控变体

门控结构的优越性在早期的严密消融实验中得到了反复验证。Noam Shazeer 在提出 GLU 变体的研究中，通过多次重复训练以及严格的误差棒（Error Bar）分析证明，在参数量严格对齐（应用 $\frac{2}{3}$ 缩放）的前提下，GLU 各类变体（如 SwiGLU、GEGLU）的表现几乎无一例外、一致性地优于传统的非门控激活结构。这部分收益在计算效率上近乎是免费获取的。

后续的研究，包括 Google 在 2020 年针对 T5 架构进行的大规模系统性架构消融对比（Narang et al., 2020），进一步在预训练损失及下游任务评测中证实了这一结论的稳健性。

当然，这并不代表门控结构是唯一的合法路径。例如 GPT-3 依然沿用了传统的非门控设计，而 Nemotron-340B 则选用了平方 ReLU（Squared ReLU，即 $\text{ReLU}(x)^2$）。这些模型同样展示出了卓越的性能。然而纵观全局演进，未采用门控机制的现代模型已属少数特例，GLU 体系提供了最为稳固且具备一致性的收益。

### 残差连接拓扑与并行模块评估

#### 串行与并行计算拓扑

在标准 Transformer 块设计中，多头自注意力机制（MHA）与前馈网络（MLP）是严格串行级联执行的。隐藏状态首先经过注意力层及其残差连接，更新后的特征再输入至 MLP 模块及其残差连接。

```text
串行结构（Serial Block）：
x_norm1 = LayerNorm(x)
attn_out = Attention(x_norm1)
x_mid = x + attn_out
x_norm2 = LayerNorm(x_mid)
mlp_out = MLP(x_norm2)
x_out = x_mid + mlp_out

并行结构（Parallel Block）：
x_norm = LayerNorm(x)
attn_out = Attention(x_norm)
mlp_out = MLP(x_norm)
x_out = x + attn_out + mlp_out
```

从系统底层与硬件执行的角度审视，串行结构引入了强制的时序依赖性：计算设备必须等待注意力分支完全计算完毕后，才能启动 MLP 的前向计算。为了打破这一计算瓶颈，社区探索了并行化 Transformer 块拓扑。这一思路最早在开源复现模型 GPT-J 中被广泛推广，随后被 Google 的 PaLM 大规模采用，Cohere 的部分模型亦吸纳了此类设计。

在并行架构中，注意力与 MLP 接收相同的归一化输入，两者的计算完全解耦并可以并发执行，最终将两者的输出向量相加后统一合并回残差流。

#### 系统收益与表征能力损耗权衡

并行拓扑在系统实现上极具吸引力：
- **算子融合与显存访问优化**：两个分支可以共享同一次 LayerNorm/RMSNorm，原本分散的投影矩阵乘法可以在底层融合为一个超大矩阵乘法，显著提高 GPU/TPU 的算力利用率；
- **吞吐量提升**：在 PaLM 论文报告中，该设计使硬件计算利用率（Model FLOPs Utilization）提升了约 15%，且在当时的实验中声称未见显著性能损失。

然而，随后的工业界实践呈现出明确的逆转趋势。近两年的主流架构几乎完全放弃了并行结构，回归到经典的串行形式。

> **结论**：并行拓扑在逻辑上等价于将网络的有效深度缩减了一半。虽然提升了 15% 的系统利用率，但破坏了多层特征在串行残差流中的渐进式抽象能力，带来了隐性的表示能力折损。随着现代深度学习系统对串行 Transformer 的底层编译、算子融合以及流水线优化已经足够极致，牺牲模型质量换取微弱系统吞吐的方案不再具备工程吸引力。

### 现代架构共识特征横截面

#### 核心架构组件状态收敛对比

下表总结了现代大语言模型在微观组件选型上的主流共识分布：

| 架构设计维度 | 经典 Vanilla Transformer | 现代主流方案（LLaMA/Mistral 等） | 历史探索与小众变体 |
| :--- | :--- | :--- | :--- |
| **归一化算子** | LayerNorm（含均值与方差） | RMSNorm（仅缩放方差，剔除均值） | LayerNorm |
| **归一化位置** | Post-LN（残差相加之后） | Pre-LN（置于非残差分支前端） | Pre-LN + Post-LN 混用 |
| **子层连接拓扑** | 串行级联（Attention -> MLP） | 串行级联（Attention -> MLP） | 并行拓扑（GPT-J、PaLM、Cohere） |
| **前馈激活函数** | 标准非门控 ReLU / GELU | 门控线性单元（SwiGLU） | 平方 ReLU（Nemotron-340B） |
| **位置编码机制** | 绝对正弦/余弦位置编码 | 旋转位置编码（RoPE） | 学习型绝对编码、相对偏置（T5/ALiBi） |

#### 微观变动与宏观稳定边界

回顾上述演化历程，不难发现一个核心结论：自 Vaswani 等人提出原始论文以来，密集自注意力模型的主干骨架展现出了极强的生命力。

所谓现代模型的诸多改进，大多局限在微观局部：归一化算子选用 RMSNorm 还是标准 LayerNorm、线性变换层是否保留偏置（Bias）项、归一化前置还是后置、以及 MLP 内部是否增加门控。相较于整个架构设计空间的潜在可能性，这些改动在数学本质上都是极为细微的局部修正。而在密集注意力范畴之外的彻底重构（如状态空间模型 SSM 等），则是另一套独立的范式。

### 位置依赖建模与旋转位置编码

#### 注意力机制的位置无关性与编码演进

自注意力机制的数学核心是内积运算。设查询向量集合为 $Q$，键向量集合为 $K$：

$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{Q K^T}{\sqrt{d_k}}\right) V$$

由于矩阵相乘的每一项仅取决于对应位置向量的内积，如果不显式引入位置信息，自注意力机制具备天然的置换不变性（Permutation Invariance）。随意打乱输入序列的词序，模型计算出的注意力分布除了行和列相应重排外，内部数值完全不变。因此，位置编码是序列模型成立的必要前置条件。

位置编码的发展经历了四个典型阶段：
1. **绝对正弦余弦编码**：原始 Transformer 借鉴傅里叶变换的思路，通过固定频率的三角函数为每个绝对索引分配一个位置向量，并直接与词向量相加。其直觉在于理论上可以从不同频率的正弦余弦分量中解构出相对位置。
2. **可学习绝对位置嵌入（Learned Absolute Embedding）**：如 GPT-2 所示，为每个离散位置索引初始化一个独立的连续向量，随模型联合训练。这种方式直接退化为绝对坐标查找，缺乏外推能力。
3. **相对位置偏置（Relative Position Bias）**：如 T5、Chinchilla 以及 ALiBi。这类方法不再将位置编码作为向量注入到词表表征中，而是直接作用于注意力计算，根据两个 Token 之间的相对距离 $(i - j)$ 向注意力打分矩阵添加偏置偏移。虽然严格实现了相对性，但它破坏了嵌入向量直接通过内积交互的几何纯粹性。
4. **旋转位置编码（RoPE, Rotary Position Embedding）**：由苏剑林提出，最初在开源复现模型 GPT-J 中被采用。2024 年以后的现代大模型几乎无一例外地转向了 RoPE 这一主导方案。

#### 旋转位置编码的相对几何构造

RoPE 坚守了一个纯粹的假设：模型对语言序列的理解应当只取决于词语之间的相对距离，而非它们在序列中所处的绝对物理位置。无论是位于句首还是句尾，只要单词 "A" 与单词 "Apple" 的相对距离一致，注意力计算产生的交互结果就应当保持恒定。

在形式化定义中，我们希望构建一个映射函数 $f$，它接收词向量与绝对索引作为输入，并满足其内积只依赖于词向量内容及相对差值：

$$\langle f(x, i), f(y, j) \rangle = g(x, y, i - j)$$

现有的早期方案均未严密契合该目标：
- 绝对位置嵌入显然违反相对不变性；
- 相对位置偏置无法拆解为独立的嵌入内积；
- 正弦余弦嵌入在直接与词嵌入相加后，在展开内积时会产生词向量与绝对位置向量之间的交叉项（Cross-terms）：
  $$\langle x + p_i, y + p_j \rangle = \langle x, y \rangle + \langle x, p_j \rangle + \langle p_i, y \rangle + \langle p_i, p_j \rangle$$
  其中的绝对位置交叉项破坏了严格的相对性，使得模型依然能反推出绝对坐标。

RoPE 利用了几何内积对于**正交旋转变换（Orthogonal Rotation）的不变性**。在二维平面中，任意旋转矩阵 $R(\theta)$ 满足正交性 $R(\theta)^T = R(-\theta)$，且具有角度可加性：$R(\theta_1)^T R(\theta_2) = R(\theta_2 - \theta_1)$。

```text
二维平面旋转几何直觉：

情况 A：
Pos 0: "We"   -> 旋转角度 0 * θ = 0
Pos 1: "know" -> 旋转角度 1 * θ = θ
相对夹角 = θ - 0 = θ

情况 B（整体向后平移 2 个位置）：
Pos 2: "We"   -> 旋转角度 2 * θ
Pos 3: "know" -> 旋转角度 3 * θ
相对夹角 = 3θ - 2θ = θ
```

在上述二维示例中，如果我们将单词对应的语义向量按其绝对位置索引 $m$ 逆时针旋转 $m\theta$：
- 位置 0 的单词旋转 $0$ 个单位，位置 1 的单词旋转 $1$ 个单位，夹角差为 $\theta$；
- 若序列平移至位置 2 和位置 3，单词分别旋转 $2\theta$ 与 $3\theta$，两者之间的相对夹角依然保持为 $\theta$。

当两者进行内积运算时，旋转角度直接相减，绝对索引 $m$ 与 $n$ 相互抵消，计算结果自然只剩下相对差值 $(m - n)$。

#### 高维空间正交分解与多频带设计

在二维空间中，旋转方向仅有顺时针与逆时针之分；但在 $d$ 维向量空间中，旋转流形具备无穷多个自由度。RoPE 采取了工程上最简练且有效的高维推广方案：**将 $d$ 维向量空间正交分解为 $\frac{d}{2}$ 个独立的二维子空间**。

对于给定的隐藏状态向量，将其每两个连续分量组合为一个二维向量，并在各自的二维子平面内分别执行旋转：

$$R_{\Theta, m}^d = \text{diag}\left( R(\theta_1 m), R(\theta_2 m), \dots, R(\theta_{d/2} m) \right)$$

其中每个二维子空间被赋予了不同的基频 $\theta_k$：
- **低频分量**：$\theta_k$ 极小，向量随位置变化旋转极为缓慢，用以捕获长距离、宏观上下文的依赖关系；
- **高频分量**：$\theta_k$ 极大，向量随步长剧烈旋转，用以对极小邻域（如词序是否直接相邻）提供高灵敏度的位置分辨能力。

将所有二维切片旋转完毕并拼接，便构成了完整的 $d$ 维 RoPE 变换。

#### 相对约束下的内积分解与注意力注入机制

在实际工程实现中，RoPE 并不是直接在最底层的词嵌入层（Word Embedding）上执行，而是在计算自注意力时，动态注入到查询向量（Query）和键向量（Key）上。

设第 $i$ 个位置的 Query 为 $q_i = x_i W_q$，第 $j$ 个位置的 Key 为 $k_j = x_j W_k$。RoPE 的作用过程可以写为：

$$\tilde{q}_i = q_i R_i, \quad \tilde{k}_j = k_j R_j$$

计算两者的注意力打分：

$$\langle \tilde{q}_i, \tilde{k}_j \rangle = (q_i R_i) (k_j R_j)^T = q_i R_i R_j^T k_j^T = q_i R_{i - j} k_j^T$$

> **提示**：从计算实现来看，将旋转变换表示为稀疏分块对角矩阵与向量的乘法，等价于将向量元素按奇偶分量重组，分别与预先根据位置 ID 生成的正弦和余弦值进行逐元素相乘并求和。由于旋转运算是通过**乘法**施加的，而不是正弦余弦编码那样的加法，它彻底杜绝了词向量与位置向量之间的多项式交叉项。

#### 变体演进与小模型存储权衡

RoPE 的数学优雅性使其成为现代大模型的事实标准。然而在边缘端或极端轻量化模型的设计中，依然衍生出了微调变体。例如 Gemma 2 探索的比例旋转位置编码（Proportional RoPE, P-RoPE）。

P-RoPE 的核心逻辑在于：既然低频维度的旋转变化极为缓慢，在参数量或隐藏维度极小（如几十维或极小隐层）的紧凑模型中，保存和计算全部维度的旋转特征会占据宝贵的激活值显存（Activation Memory）。因此，P-RoPE 选择**仅对向量的前部关键坐标进行旋转**，冻结其余坐标不施加旋转。这种差异本质上是针对极限算力与存储约束下的工程裁剪。

### 超参数空间分布与搜索维度

当跳出抽象的理论模型，进入实际代码编写与实例化阶段时，工程实现将不可避免地面对一个极高维度的超参数空间：
- **维度与结构参数**：隐藏层维度 $d$、前馈层隐藏维度 $d_{ff}$、注意力头数 $h$ 与键值头数、网络层数 $L$（模型应该设计得更深还是更宽）；
- **词表与输入配置**：词表大小 $V$（Vocabulary Size）；
- **正则化体系**：在处理海量 Token 规模的训练体系下，是否仍需配置权重衰减（Weight Decay）？Dropout 的比例应该设为多大，还是完全将其归零？

对于初涉大模型研发的学习者而言，这一庞大的高维参数组合往往令人望而生畏。但若仔细审视过去数年间所有成功模型的开源技术报告与配置规范，就会发现人类工程实践所真正验证过的有效解空间极其收敛。理解前人如何在深度、宽度与模块比例之间做出权衡，是避开盲目网格搜索、高效构建现代大语言模型的核心捷径。

## Transformer 架构超参数共识、训练稳定性干预与轻量化注意力设计
> 对应块：BLK04 | 覆盖分集：P03下 | 块标题（分集名）：《Lecture 3_ Architectures》

在着手搭建一个现代 Transformer 语言模型时，我们往往会面对琳琅满目的超参数选项：隐藏维度、层数、前馈层倍率、注意力头维度、词表大小……初学者常常会感到迷茫，认为训练好一个大模型需要做极其昂贵且无止境的网格搜索。但如果你去翻阅近几年业界发布的顶级技术报告，会发现一个极具启发性的现象：大家的架构选择出奇地保守和一致，甚至已经收敛出了几条通用的经验法则。比如前馈层的中间维度为什么几乎所有人都不假思索地设为模型维度的 4 倍？为什么会有 2.67 或者 3.5 这种看似随意的数字？这种收敛究竟是理论推导的必然，还是工程系统的妥协？

事实证明，架构设计从来不是孤立的数学游戏，而是模型表达能力与底层硬件体系结构之间深度博弈的产物。深入解构这些超参数背后的实证边界、训练稳定性干预手段，以及推理场景下为突破内存墙而诞生的轻量化注意力机制，能够帮助我们建立起一套严整的现代语言模型架构观。

### 核心架构超参数的经验法则与权衡空间

在深入具体算子之前，我们先梳理控制模型宏观结构的三组关键超参数：前馈层扩展比率、注意力头维度与模型纵横比。这些参数直接决定了模型参数在注意力机制与前馈网络之间的分配，以及在计算资源给定时如何分配深度与宽度。

#### 前馈层扩展比率与门控单元修正

前馈网络（Feed-Forward Network, FFN / MLP）中第一个矩阵乘法的输出维度与模型隐藏维度之间的比例，即 $W_1$ 与 $W_2$ 矩阵在中间维度的扩张倍数：

$$\alpha_{\text{FFN}} = \frac{d_{\text{ff}}}{d_{\text{model}}}$$

这个比例直接控制着前馈层的参数容量与特征丰富度。在非门控的标准 Transformer（如原始 GPT-2、GPT-3）中，业界普遍遵循的经验法则是：

$$\alpha_{\text{FFN}} \approx 4$$

这个 4 倍经验法则在实证中表现得异乎寻常地好。然而翻阅现代模型的配置，我们会看到很多偏离 4 的数值，这些看似极端的例外反而从反面印证了参数分配的守恒逻辑。

第一个核心变体是门控线性单元（Gated Linear Unit, GLU，如 SwiGLU）。标准的双层 MLP 仅包含两个投影矩阵 $W_{\text{gate/up}}$ 与 $W_{\text{down}}$，输入 $x$ 经过变换：

$$\text{FFN}_{\text{standard}}(x) = \text{Activation}(x W_1) W_2$$

其参数量大约为 $2 \times d_{\text{model}} \times d_{\text{ff}}$。但在 GLU 结构中，为了引入门控分支，前馈层由三个矩阵构成：

$$\text{FFN}_{\text{GLU}}(x) = (\text{Activation}(x W_{\text{gate}}) \odot (x W_{\text{up}})) W_{\text{down}}$$

在 $d_{\text{model}}$ 不变的前提下，GLU 的参数量直接膨胀了 1.5 倍（变为 $3 \times d_{\text{model}} \times d_{\text{ff}}$）。为了在对比或替换时保持 MLP 的参数总量和计算量守恒，必须对中间维度进行缩放修正，将其缩小到原来的 $2/3$：

$$\alpha_{\text{GLU}} = 4 \times \frac{2}{3} \approx 2.67$$

因此，在技术报告中凡是看到 2.5 到 2.67 之间的前馈乘数，本质上都是应用了这种针对 GLU 三矩阵结构的 $2/3$ 参数守恒修正。

也有团队在此基础上作出了更偏向 MLP 的激进选择。例如 LLaMA 团队在研发过程中认为，模型采用的高效注意力机制（如后续讨论的 GQA）在注意力部分节省了大量开销，因此可以有意识地让架构更侧重 MLP 的知识存储能力。他们在 2.67 的基准上又乘以了一个约 1.33 的经验乘数，将最终比例定在：

$$\alpha_{\text{LLaMA}} \approx 2.67 \times 1.33 \approx 3.5$$

综合来看，所有主流模型的中间层倍率只有两种收敛路径：非 GLU 模型稳定在 4，而 GLU 变体则严格落在 2.6 左右或 3.5 附近。

```text
+-------------------------------------------------------------------------+
|                  前馈层中间维度乘数经验分布与演进路径                   |
+-------------------------------------------------------------------------+

标准双矩阵 MLP (ReLU/GELU)         门控三矩阵 MLP (SwiGLU)
[ W_up -> Act -> W_down ]      [ (W_gate * W_up) -> W_down ]
           │                                 │
           ▼                                 ▼
      乘数基准: 4.0                    参数量守恒修正 (x 2/3)
                                             │
                                             ▼
                                     收敛区间 A: ~2.67
                                             │
                                             ├─> LLaMA 侧重 MLP (x 1.33)
                                             │   │
                                             │   ▼
                                             │   收敛区间 B: ~3.5
                                             │
                                             └─> 极端系统级探索: T5 v1 (64.0)
                                                 └──> 最终回归: T5 v1.1 (~2.5)
```
前馈层乘数的演进展示了参数量守恒修正与工程侧重之间的平衡。

与绝大多数保守遵循上述区间的团队相比，Google 的 T5 模型是一个极度激进但极具启发性的案例。T5 团队放弃了 4 倍经验法则，直接采用了惊人的 64 倍乘数。这一决策背后的论证完全建立在系统底层硬件利用率上：在现代张量加速芯片（TPU/GPU）上，矩阵乘法的尺寸越大，算术强度越高，计算核心的硬件吞吐与并发效率就利用得越充分。然而，极端过大的前馈层会导致显存与激活值负担剧增。这一故事最耐人寻味的点睛之笔在于：当 Google 推出改进版模型 T5 v1.1 时，他们悄悄放弃了 64 倍的激进设定，重新回归到了标准的 2.5 倍乘数。

从实证角度看，Kaplan 等人（2020）在关于神经缩放定律（Neural Scaling Laws）的经典论文中，对前馈比例进行过严格受控的参数扫描消融实验。实验揭示了一个重要的性能形态：前馈乘数存在一个非常平坦宽阔的“最优盆地”（basin）。从大约 1 开始，一直延伸到 10 附近，模型相对于最优损失的性能差异微乎其微。只有当这个比例极端错误地超过 10 甚至达到 100 时，损失才会呈二次方急剧恶化。

> **结论**：前馈乘数的容错区间极宽。默认的 4 倍（标准 MLP）或 2.67 / 3.5 倍（GLU 变体）已经稳稳坐落在损失盆地的最低点附近，无需耗费算力在此处进行细粒度微调。

#### 注意力头维度与模型维度的匹配规律

多头注意力机制（Multi-Head Attention, MHA）引入了两个关键超参数：头数 $h$ 与单个头的特征维度 $d_{\text{head}}$。在业界构建模型的标准实践中，几乎所有人都会遵循一条对称性原则：

$$h \times d_{\text{head}} = d_{\text{model}} \quad \Longrightarrow \quad \frac{h \cdot d_{\text{head}}}{d_{\text{model}}} \approx 1$$

即确保所有注意力头的特征维度之和恰好等于模型的总隐藏维度。虽然在数学上完全可以独立设定头维度，使投影矩阵映射到任意总维度空间，但纵观绝大多数顶级模型，这一比值都高度锚定在 1 附近（除 T5 与 UL2 等少数 Google 早期模型外）。消融实验表明，头维度同样是一个容错率极高的超参数，在 1 附近的合理安全区内微调并不会对模型最终的拟合能力产生颠覆性影响。

#### 纵横比在表达能力与系统并行间的权衡

在对模型进行规模化缩放（Scaling）时，核心问题在于：增加的参数量和计算预算应该分给“深度”（层数 $L$）还是“宽度”（模型维度 $d_{\text{model}}$）？这由模型的纵横比（Aspect Ratio）决定：

$$\text{Aspect Ratio} = \frac{d_{\text{model}}}{L}$$

纵观 GPT-3、LLaMA 等现代大语言模型，它们的纵横比几乎无一例外地收敛在 100 附近（即模型隐藏维度大约是层数的 100 倍）：

$$d_{\text{model}} \approx 100 \times L$$

这一收敛并非偶然，而是理论表达能力与底层分布式硬件并行特性博弈后的平衡点：

```text
+-------------------------------------------------------------------------+
|                  纵横比 (d_model / L) 的系统与算法权衡                  |
+-------------------------------------------------------------------------+

      极深架构 (L 极大, 纵横比 << 100)        极宽架构 (d_model 极大, 纵横比 >> 100)
    ┌─────────────────────────────────┐    ┌─────────────────────────────────┐
    │ 理论优势: 串行表征深度与层级抽象 │    │ 理论劣势: 浅层难以捕捉深层抽象  │
    │ 系统瓶颈: 必须采用流水线并行(PP) │    │ 系统优势: 易于单机张量并行(TP)  │
    │           引入气泡与跨节点通信   │    │           规整矩阵切分与高带宽  │
    └─────────────────────────────────┘    └─────────────────────────────────┘
                     │                                      │
                     └───────────────┬──────────────────────┘
                                     ▼
                        工程平衡点: 纵横比 ≈ 100
                    (在表达深度与张量并行效率间兼得)
```
纵横比体现了分布式并行开销与神经网络深层表达能力之间的折中。

当模型做得极深时，单张 GPU 无法容纳所有层，必须沿深度方向拆分层，采用流水线并行（Pipeline Parallelism, PP）。流水线并行伴随着严重的“流水线气泡”（Pipeline Bubble），需要极其繁复的激活值排队与跨节点通信调度，是工程部署上极力避免处理的复杂方案。相反，当模型做得相对较宽时，我们可以直接利用高速卡间互联（如 NVLink）进行张量并行（Tensor Parallelism, TP），在单机内部将矩阵按行或列规整切分，通信开销低且调度极其简单。

Tay 等人针对一系列架构变体开展的大规模消融研究进一步证实：在深度与宽度的不同权衡中，真正主导模型性能表现的核心变量是总浮点计算量（FLOPs）。只要总 FLOPs 持续增加，无论深度和宽度在合理范围内如何分配，模型性能都能稳定提升。既然纵横比存在一个宽泛的安全区，工程上就理应毫不犹豫地优先选择系统硬件利用率最高、最易于张量并行的架构配置（即纵横比落在 100 左右）。

#### 词汇表规模演进与度量准则

词汇表大小（Vocabulary Size, $V$）在不同代际与应用场景的模型之间呈现出极其清晰的分水岭：

| 模型分类 | 典型词表大小 | 设计目标与约束 | 典型代表 |
| :--- | :--- | :--- | :--- |
| **早期单语模型** | $\approx 30{,}000$ (30k) | 仅针对纯英文语料建模，最小化输出投影开销 | 早期开源英文模型、GPT-2 |
| **现代生产级多语言模型** | $100{,}000 \sim 200{,}000$ (100k~200k) | 全球多语言覆盖、降低多语言压缩比、代码及特殊符号支持 | LLaMA 3、GPT-4、Gemma 等 |

词表向十万级以上的膨胀受到两大力量的驱动：其一是多语言与多模态的现实需求，必须用庞大的词表覆盖广泛的 Unicode 字符与离散视觉 token；其二是神经缩放定律的推力——越大的模型容量，越能有效支撑并利用大词表带来的长程信息压缩增益。

在评估不同词表规模的模型时，容易产生度量混淆：两个使用完全不同分词器（Tokenizer）的模型，能否直接比较困惑度（Perplexity, PPL）？

答案是：**基于 token 的困惑度绝对不能跨分词器直接比较**。因为大词表分词器往往具有更高的压缩比，一个 token 可能对应 3 到 4 个字节，而小词表分词器一个 token 可能仅对应 1 到 2 个字节。每个 token 承载的信息量完全不对等，直接比较 token 级别的交叉熵损失没有物理意义。

正确的度量标准是使用**每字节比特率（Bits Per Byte, BPB）**。语言建模在本质上是对字符串序列概率分布的建模。只要输入的原始字符序列保持固定且未被截断，且分词器具备完备的无损编码能力（现代基于字节的 BPE 分词器均能无损覆盖任意字节流），我们以该序列的**总字节数**作为统一分母进行归一化：

$$\text{BPB} = \frac{\mathcal{L}_{\text{total\_loss}}}{\ln 2 \times N_{\text{bytes}}}$$

困惑度与 BPB 在信息论层面互为对偶，但在跨分词器对比的场景下，唯有以字节长度统一归一化的 BPB 是严格、公平且自洽的度量准则。

#### 权重衰减与正则化的底层优化作用

在经典的机器学习入门课程中，正则化手段（如 Dropout 与权重衰减 Weight Decay）的唯一职责是防止模型对训练集产生过拟合（Overfitting）。但在现代大语言模型的预训练中，出现了一个反直觉的现象。

在计算受限的超大规模语言模型训练场景下，海量网络语料的规模往往远超总训练预算的承载上限。我们通常只对语料库进行**单遍遍历（Single-pass SGD / Adam）**，模型在整个生命周期内根本不会重复看到同一批数据。在单遍遍历下，经验表明优化器几乎不会真正“记住”训练集细节，**过拟合几乎根本不是一个需要考虑的问题**。实测中，训练集损失与验证集损失几乎完全重叠在对角线上。

既然不存在过拟合，我们是否应该彻底废除 Dropout 与权重衰减？
- **Dropout** 确实已被现代顶级大模型全面弃用：它不仅破坏了优化收敛过程，而且极难与大规模并行系统高效兼容。
- **权重衰减（Weight Decay）** 却依然被几乎所有先进模型（如 LLaMA 系列）广泛保留并重度使用。

这一反直觉现象的根源在于：**在大规模语言模型中，权重衰减的作用机制已经从“正则化”演变成了“优化器辅助算子”**。

在单遍训练中，改变权重衰减强度并不会改善“过拟合差距”（因为差距本来就是零）。但当我们将权重衰减与**学习率衰减（Learning Rate Schedule）**结合时，更强的权重衰减运行虽然在训练初期起步较慢，但在学习率逐步退火的后期阶段，最终能收敛到显著更优的损失绝对值。权重衰减通过持续对参数施加向原点的收缩力，动态调整了参数的有效范数，改变了优化器在参数流形上的有效步长与曲率探索能力。它本质上是一种提升优化终点质量的手段，而非传统意义上的防止记忆机制。

### 深度模型训练稳定性与 Softmax 极值控制

随着单次预训练的算力投入飙升至数百万乃至上千万美元，模型架构设计的核心战场已经从单纯追求微小的表达能力增益，全面转向了**训练稳定性（Training Stability）**。

在超大规模分布式训练中，一旦模型在中途遭遇不可逆的数值崩溃、梯度爆炸或频繁的损失尖峰（Loss Spikes），整个训练进程可能就此报废。导致数值崩溃的高危病灶高度集中在同一个非线性算子上——**Softmax**。

Softmax 的数学定义中内嵌了两个极具数值危险性的操作：
1. **指数运算 $\exp(x)$**：任何略大的输入都会瞬间导致浮点数上溢，产生 `Inf` 或 `NaN`；
2. **归一化分母除法**：极小的分母会导致除法溢出，进而产生失控的梯度反传。

在 Transformer 架构内部，恰好存在两处不可避免的 Softmax 危险区：
- **输出端 Softmax（Output Softmax）**：将残差流映射至上万甚至数十万维度的词表概率分布；
- **注意力端 Softmax（Attention Softmax）**：在每个注意力头内部对键值点积打分矩阵进行归一化。

针对这两处危险区，业界提炼出了一套标准而优雅的稳定性干预手段。

```text
+-------------------------------------------------------------------------+
|                  Transformer 两大 Softmax 危险区与稳定化干预            |
+-------------------------------------------------------------------------+

  危险区 1: Attention Softmax (输入维度: 序列长度 n)
  [ Q, K ] ──> [ RMSNorm (QK-Norm) ] ──> [ QK^T / sqrt(d) ] ──> [ Soft-Cap (可选) ] ──> Softmax
               ▲ 防止点积范数失控                        ▲ 硬截断极值范围
  
  危险区 2: Output Softmax (输入维度: 词表大小 V)
  [ 残差流 u ] ──> [ 词表投影 ] ──> log(Z) 约束 ──> [ + z-loss 正则化 ] ──> Softmax 交叉熵
                                   ▲ 惩罚 (log Z)^2 远离 0
```
稳定化干预针对注意力和输出层两处数值极值，分别从输入归一化和损失惩罚两端施加约束。

---

#### 输出端对数配分函数约束与 z-loss 正则化

在模型输出端，我们计算目标 token 的对数概率以构建交叉熵损失：

$$\log p_i = u_i - \log Z, \quad \text{其中 } Z = \sum_{j=1}^{V} \exp(u_j)$$

其中 $u$ 是残差流经输出无偏置投影后的 logits，而 $Z$ 是配分函数（Partition Function）。尽管残差流输出 $u$ 本身在残差连接与层归一化保护下表现平稳，但第二项 $\log Z$ 却潜藏着巨大的数值风险。词表维度 $V$ 高达十万级，$Z$ 作为指数项之和，极易在训练动态中剧烈膨胀或急剧收缩，引发单精度浮点运算的数值溢出。

由于 Softmax 具有平移不变性（Shift Invariance），在所有 logits 上同时加上或减去一个常数标量 $c$，最终的输出概率分布完全保持不变。整个系统在数学上是过参数化的，这意味着我们完全可以在不改变概率输出的前提下，人为操纵 $\log Z$ 的绝对大小。

为了将 $\log Z$ 钉死在数值稳定的原点附近（即希望 $Z \approx 1 \Longrightarrow \log Z \approx 0$），Jacob Devlin 等人在 2014 年率先提出、后续被 Baichuan、OLMo、DCLM 等现代开源大模型广泛采用的技巧是 **z-loss**。我们在主交叉熵损失之外，额外引入一个辅助正则化惩罚项：

$$\mathcal{L}_{\text{z-loss}} = c_{\text{z}} \cdot (\log Z)^2$$

$$\mathcal{L}_{\text{total}} = \mathcal{L}_{\text{CE}} + \mathcal{L}_{\text{z-loss}}$$

当配分函数偏离 1 时，$(\log Z)^2$ 会产生强烈的二次梯度回传，迫使网络主动平移输出 logits，消除配分函数的绝对偏移。实测证明，这一看似极其轻量的辅助损失项，能够极其显著地抑制输出端在长期预训练过程中的数值漂移与偶发尖峰。

---

#### 注意力矩阵乘尺度控制与 QK-Norm

解决了输出端问题，更大的退化风险存在于注意力机制本身。标准的 Pre-LN 注意力层中，输入向量先经过 Pre-LayerNorm，再经线性投影得到查询向量 $Q$ 与键向量 $K$，随后执行点积并缩放：

$$\text{Attn\_Scores} = \frac{Q K^T}{\sqrt{d_{\text{head}}}}$$

随着网络层数加深与学习率推高，投影矩阵 $W_Q$ 和 $W_K$ 输出的向量范数可能不受控地持续漂移。当 $Q$ 与 $K$ 的点积幅值变得极大时，送入 Softmax 的 logits 会产生巨大的极值差，导致 Softmax 的输出退化为接近 one-hot 的尖锐分布。这不仅会导致注意力机制丧失对上下文多样性特征的聚合能力（即注意力退化），还会导致反向传播时梯度剧烈震荡。

解决这一问题的核心直觉极其朴素：**如果一个地方容易产生数值不稳定性，就在计算之前为其加上归一化**。这正是 **QK-Norm** 的核心思想。

在将 $Q$ 和 $K$ 送入矩阵乘法计算点积之前，分别对其独立施加一层无参数学习的均方根归一化（RMSNorm）：

$$Q_{\text{norm}} = \text{RMSNorm}(Q), \quad K_{\text{norm}} = \text{RMSNorm}(K)$$

$$\text{Attn\_Scores} = \frac{Q_{\text{norm}} K_{\text{norm}}^T}{\sqrt{d_{\text{head}}}}$$

通过这一干预，$Q_{\text{norm}}$ 与 $K_{\text{norm}}$ 的各个分量被严格束缚在均值为 1 的稳定尺度上，点积矩阵的输入尺度得到了数学上的严格受控。

> **提示**：QK-Norm 最初源于多模态大模型领域（如 Idefics、Chameleon 等）。多模态模型由于需要同时吞吐文本与高动态范围的视觉特征，注意力点积极其脆弱，研究者发现 QK-Norm 能完美稳固其训练。随后这一技巧被开源语言模型界迅速采纳，目前已成为几乎所有顶尖大模型的标准工业配置。

大量消融运行表明，QK-Norm 不仅不会损害模型的拟合与表达能力，反而由于消除了注意力的极端方差，允许训练团队将全局学习率（Learning Rate）设置得更高，进而收敛到更优的模型性能。

---

#### 注意力对数几率截断与 Soft-Capping

与 QK-Norm 相比，另一种更偏向 Google 风格的硬性干预手段是 **Logit Soft-Capping**，该方案被系统性地部署在 Gemma 2、Gemma 3 及 Gemma 4 等模型中。

QK-Norm 是通过归一化间接控制输入尺度，而 Logit Soft-Capping 则是直接对进入 Softmax 之前的 logits 施加显式的双曲正切函数（$\tanh$）有界截断：

$$\text{logits}_{\text{capped}} = \text{cap} \cdot \tanh\left(\frac{\text{logits}}{\text{cap}}\right)$$

由于 $\tanh$ 的输出严格被限制在 $(-1, 1)$ 之间，因此无论点积计算出的原始值多么极端，经过软截断后的 logits 绝对值被强制钉死在 $[-\text{cap}, +\text{cap}]$ 的刚性区间内。

```text
+-------------------------------------------------------------------------+
|                  Logit Soft-Capping 响应曲线特征与权衡                  |
+-------------------------------------------------------------------------+

              logits_capped
                    ^
               +cap ┼─────────────────── 渐近线: 输出永远不超出 cap
                    │                 . :
                    │              . '
                    │           . '
                    │        . '   <── 线性敏感区: logits 较小时正常响应
                    │     . '
                    │  . '
               -cap ┼'────────────────── 渐近线: 压制极端点积爆炸
                    │
                    └─────────────────────────> 原始点积 logits
```
Soft-Capping 虽能杜绝数值爆炸，但在渐近区强行压缩了高置信度梯度的表达空间。

Nvidia 等机构的研究人员对这些稳定性干预措施进行了系统性的受控消融对比，得出了明确的结论：
- 单纯采用 Logit Soft-Capping 虽然能绝对保证数值不溢出，但由于它在饱和区强制压缩了 logits 的峰值，剥夺了模型在注意力分布中表达极端确定性（即以极高置信度聚焦于单一关键 token）的能力，往往会导致下游评测任务发生可测量的性能衰减。
- 相比之下，**QK-Norm 从根源上保证了数值尺度的平稳，同时完全保留了分布的相对动态范围**，表现显著优于单纯的 Soft-Capping。

### 注意力机制架构演进与长上下文开销优化

本讲聚焦于标准密集全注意力（Dense All-by-All Attention）体系下的架构干预。在长上下文时代，推动注意力机制发生最深远变革的，不是训练阶段的算法设计，而是**部署与在线推理服务（Serving）阶段的系统资源成本**。

#### 推理自回归生成与 KV Cache 内存墙瓶颈

在宏观系统层面，大模型的服务成本取决于两项核心资源的消耗：
1. **浮点运算量（FLOPs）**：系统完成的前向计算规模；
2. **显存访问量（Memory Access / Bandwidth）**：在 GPU 高速显存（HBM）与片上缓存（SRAM）之间吞吐的数据字节数。

这两者的比值定义了系统的**算术强度（Arithmetic Intensity）**：

$$\text{Arithmetic Intensity} = \frac{\text{FLOPs}}{\text{Bytes of Memory Access}}$$

在**训练或预填充（Pre-fill）阶段**，所有输入 token 是完整已知的，整个序列可以完全并行化计算。注意力机制的矩阵乘法维度大（批次 $\times$ 序列长度 $\times$ 隐藏维度），算术强度极高。系统处于典型的计算受限（Compute-bound）状态，GPU 核心能够被充分利用。

但一旦进入**自回归解码（Autoregressive Generation）阶段**，为了向用户逐字输出回答，我们无法在时间轴上并行：系统必须先生成第 $t$ 个 token，将其追加到历史序列中，才能计算第 $t+1$ 个 token。

为了避免每一步都从头重新计算历史所有 token 的 $K$ 与 $V$ 投影，系统必须引入**键值缓存（KV Cache）**，将历史所有步骤计算出的 Key 和 Value 矩阵保存在显存中。生成新 token 时，仅需计算当前这单个 token 的 Query，并与缓存的历史 Key/Value 进行增量点积交互。

```text
+-------------------------------------------------------------------------+
|                  自回归增量生成时的访存与算力失衡                       |
+-------------------------------------------------------------------------+

每步仅生成 1 个 Token:
  [ 新 Query (仅 1 个向量) ] 
              │
              ▼
  点积计算量: 极小 (仅与当前步骤相关, O(d))
  显存访存量: 极大 (必须将历史全部 n 个 token 的 K, V 完整载入 SRAM!)
              │
              ▼
  ┌─────────────────────────────────────────────────────────────┐
  │  GPU 算力核心 (Tensor Cores) 处于饥饿空转状态               │
  │  瓶颈完全卡在 HBM 显存带宽传输上 (Memory-Bandwidth Bound)   │
  └─────────────────────────────────────────────────────────────┘
```
自回归增量生成的单步计算极小，但必须通读全量缓存，导致严重的内存带宽受限。

KV Cache 虽然节省了重复计算的 FLOPs，却将系统推向了严重的**内存带宽受限（Memory-bandwidth bound）**深渊。在增量生成阶段，随着历史序列长度 $n$ 持续增加，为了仅仅完成当前单个 token 的小矩阵乘法，系统在每一个生成步都必须将过去所有缓存的 Key 和 Value 从显存完整搬运至片上计算单元一次。

此时系统的访存规模变成了 $\mathcal{O}(B \cdot n \cdot d)$，而计算量仅为 $\mathcal{O}(B \cdot d)$。算术强度出现断崖式暴跌，正比于：

$$\text{Arithmetic Intensity} \propto \frac{1}{\frac{n}{d} + 1}$$

对于小模型或长上下文生成场景，$\frac{n}{d}$ 项居高不下，算术强度极度恶化。GPU 强大的矩阵计算核心大部分时间在空转等待显存搬运数据，推理吞吐被完全钉死在显存带宽墙上。

---

#### 共享键值缓存的多查询与分组查询注意力

为了打破推理阶段的内存带宽墙，业界对注意力机制内部的头结构进行了结构性重塑。

在原始的多头注意力（MHA）中，每个注意力头都拥有专属独立的 Query、Key 和 Value 投影：如果有 $h$ 个 Query 头，显存中就必须同时保存 $h$ 组 Key 和 $h$ 组 Value 缓存。

为了最大化压缩 KV Cache 带来的显存带宽开销，Shazeer 提出了**多查询注意力（Multi-Query Attention, MQA）**：保留全部 $h$ 个独立的 Query 头，但强行让所有 Query 头**共享单一一组 Key 和 Value**（即全局只有 1 个 Key 头和 1 个 Value 头）。

```text
+-------------------------------------------------------------------------+
|        多头 (MHA)、多查询 (MQA) 与分组查询 (GQA) 的头结构拓扑对比        |
+-------------------------------------------------------------------------+

多头注意力 (MHA):
  Queries:  [Q1]  [Q2]  [Q3]  [Q4]  [Q5]  [Q6]  [Q7]  [Q8]
             │     │     │     │     │     │     │     │
  Keys:     [K1]  [K2]  [K3]  [K4]  [K5]  [K6]  [K7]  [K8]
  Values:   [V1]  [V2]  [V3]  [V4]  [V5]  [V6]  [V7]  [V8]  (KV 缓存量: 8 份)

多查询注意力 (MQA):
  Queries:  [Q1]  [Q2]  [Q3]  [Q4]  [Q5]  [Q6]  [Q7]  [Q8]
             └─────┴─────┴─────┼─────┴─────┴─────┴─────┘
  Keys:                       [K1]
  Values:                     [V1]                          (KV 缓存量: 仅 1 份!)

分组查询注意力 (GQA, 此处分为 2 组):
  Queries:  [Q1]  [Q2]  [Q3]  [Q4]        [Q5]  [Q6]  [Q7]  [Q8]
             └─────┴─────┬─────┘           └─────┴─────┬─────┘
  Keys:                 [K1]                          [K2]
  Values:               [V1]                          [V2]  (KV 缓存量: 2 份)
```
MHA、MQA 与 GQA 展示了在多头独立性与键值共享之间的不同折中方案。

MQA 的工程收益是立竿见影的：KV Cache 的显存占用和每步访存量被直接暴力压缩到了原来的 $1/h$（例如从 32 头压缩至 1 头，访存量下降近 97%），算术强度提升了接近 $h$ 倍，服务吞吐量大幅暴涨。

但 MQA 的硬币反面极其沉重：强行让所有 Query 关注相同的 Key/Value 空间，严重扼杀了注意力机制捕捉复杂多样依赖关系的表达能力，下游任务的准确率出现显著恶化。

我们需要一个既能保留绝大部分推理加速优势、又能保住模型性能的折中点，这就是如今风靡业界的**分组查询注意力（Grouped-Query Attention, GQA）**。

GQA 将 $h$ 个 Query 头均匀划分为 $g$ 个组（Group），每组内部的多个 Query 头共享该组唯一的 Key 和 Value 头。
- 当 $g = h$ 时，GQA 退化为传统的 MHA；
- 当 $g = 1$ 时，GQA 退化为极端的 MQA；
- 当 $1 < g < h$（例如 32 个 Query 头配置 8 组 KV 头）时，系统处于绝佳的黄金平衡点。

实证评测表明，从全量 MHA 切换到 GQA（例如 8:1 的压缩比），模型的下游性能几乎与 MHA 处于同一条水平线上，肉眼几乎难以分辨性能损失；而在推理服务阶段，KV Cache 的开销却被压缩到了八分之一。这一极其有利的帕累托最优权衡，正是 LLaMA 2/3、Mistral 等几乎所有当今主流开源大模型无一例外转向 GQA 的根本原因。

---

#### 滑动窗口与密集注意力交替的混合长上下文架构

当模型的上下文窗口从 4k 推进到 32k、128k 甚至百万级别时，即便使用了 GQA，二次方复杂度的全局全注意力矩阵在计算量与缓存总量上依然会失控。

早期的 GPT-3 曾探索过一种经典机制——**滑动窗口注意力（Sliding Window Attention, SWA）**，或称带状矩阵注意力（Band-diagonal Attention）。在全注意力中，每个 token 都能访问历史的所有位置；而在 SWA 中，每个 token 被施加了一个固定的局部感知窗口（例如只看最近的 4096 个 token）：

$$\text{Attn}(i, j) = 0, \quad \forall j < i - w$$

单纯采用全量 SWA 固然将单层计算和缓存开销压制到了线性复杂度 $\mathcal{O}(n \cdot w)$，但付出的代价是模型彻底丧失了在远距离进行单步直接精确寻址的能力。

为了兼顾长程精确关联与极低显存开销，过去一年中开源界最活跃、最主流的架构演进范式，是构建**全注意力与局部注意力的周期性交替混合架构（Hybrid Attention Patterns）**。

```text
+-------------------------------------------------------------------------+
|                  全注意力与滑动窗口交替混合架构层次流动                 |
+-------------------------------------------------------------------------+

  第 4 层 (全局层): [ 全局密集全注意力 (Dense Full Attention) ] ──> 汇聚全局全局上下文
                               ▲
  第 3 层 (局部层): [ 滑动窗口局部注意力 (Sliding Window Attn) ]
                               ▲
  第 2 层 (局部层): [ 滑动窗口局部注意力 (Sliding Window Attn) ]
                               ▲
  第 1 层 (局部层): [ 滑动窗口局部注意力 (Sliding Window Attn) ] ──> 仅处理局部精细特征
```
局部层与周期性全局层的交替堆叠，使局部信息能通过深层残差网络逐级间接泛化至全局。

典型的代表（如 Cohere Command A、Llama 系列及部分最新开源架构）普遍采用类似的拓扑结构：例如**每 4 层网络中，仅设置 1 层全局密集全注意力，其余 3 层全部采用廉价的局部滑动窗口注意力**。

这种设计的信息流动机制非常精妙：底层 3 层的局部注意力以极低的计算与缓存代价处理局部 token 语法与短语交互；当特征流向第 4 层全局注意力时，各局部的压缩信息被一次性全局广播与汇聚；随着网络层级不断向后推进，高层的局部注意力通过残差流直接承接了下层全注意力层注入的全局信息，从而在宏观上获得了跨越数十万 token 的长程上下文感知力，同时将绝大部分层级的 KV Cache 与矩阵乘法开销压缩到了固定窗口内。

这一混合演进思想在业界还在持续衍生出更多变体：
- **位置编码混合**：例如在局部滑动窗口层保留旋转位置编码（RoPE），而在长程全局层直接放弃显式位置编码（NoPE），将全局信息视作集合交互；
- **跨机制混合**：例如 Qwen 2.5 等前沿架构在探索将全注意力层与状态空间模型（Gated Delta SSM，门控增量状态空间模型）按类似 1:3 的比例交替堆叠，用非 Transformer 机制彻底替换掉代价昂贵的局部层。

无论具体实现形态如何变化，纯粹的全局全注意力架构在超长上下文场景下已不再是唯一解，**“密集全局注意力 + 高效局部/线性状态层”的混合架构**已然成为现代前沿大模型兼顾性能与成本的确定性演化方向。

### 架构工程设计的系统协同与经验收敛

回顾全篇剖析的各项架构决策，现代 Transformer 的设计演化清晰地展现出两大底层逻辑：

1. **超参数的容错盆地与系统主导性**：
   从 4 倍（或 GLU 2.67/3.5 倍）的前馈扩展乘数，到严格锚定为 1 的头维度比率，再到收敛于 100 左右的模型纵横比——这些看似玄学的超参数并非处于锋利的刀刃之上，而是普遍存在一个宽阔平坦的低损失盆地。只要选择落入安全区内，模型的最终表达能力几乎仅由总算力（FLOPs）决定。因此，在超参数设定的十字路口，**永远应该优先倒向有利于底层硬件系统吞吐、有利于分布式并行实现（如规整张量并行）的选项**。

2. **从训练到推理的全生命周期开销优化**：
   在训练端，面对数百万美元的稳定性风险，我们利用 z-loss 压制输出配分函数漂移，利用 QK-Norm 将注意力点积输入严格归一化至稳定尺度，从而消除损失尖峰并换取更大的学习率空间；在推理端，面对自回归解码带来的内存带宽墙，我们从单纯的 MHA 演进到兼顾性能与访存吞吐的 GQA，再进一步在长上下文场景下引入滑动窗口与全注意力交替堆叠的混合模式。

理解这些深植于系统底层、经由海量实证淬炼而成的共识法则与干预手段，能够让我们在从零构建或调优现代大语言模型时，避开盲目的试错与注水，在表达能力与工程可行性之间做出最稳健的技术决断。

## 现代语言模型进阶架构：线性时间注意力与专家混合网络
> 对应块：BLK05 | 覆盖分集：P04 | 块标题（分集名）：《Lecture 4_ Attention Alt》

课件已经同步上传到课程网站与代码仓库。在上一讲中，我们系统讨论了标准 Transformer 的底层机制以及如何调整其各组成部件来搭建现代语言模型。这一讲我们将探讨更为进阶的架构设计思路，重点解决现代模型在大规模扩展时遇到的两处核心瓶颈：一是通过注意力模块的架构级重构，将计算复杂度降低至关于序列长度的线性依赖，以支持数百万乃至上千万 token 的长上下文；二是通过专家混合网络（Mixture of Experts，MoE）重构多层感知机（MLP）部分，在固定算力预算下显著提升模型参数容量与硬件利用率。

---

### 长上下文计算瓶颈与常规优化边界

#### 前馈计算与注意力开销的渐近分流

现代大语言模型的应用场景正在迅速向超长上下文（Context Length）演进。无论是将整个知识库、代码仓库注入提示词，还是构建需要维护长期记忆与复杂调用轨迹的自主代理系统，顶尖的大模型都在以对数尺度持续拉大上下文窗口。

在计算资源消耗上，Transformer 内部的前馈网络（Feed-Forward Network / MLP）与自注意力机制（Self-Attention）呈现出完全不同的缩放规律。在短序列场景下，前馈网络占据了整网计算开销的大头，其计算量随序列长度 $N$ 呈线性增长 $\mathcal{O}(N)$；而标准自注意力机制包含所有位置两两之间的全连接交互（All-to-All Interaction），其计算与内存开销随序列长度呈现二次方爆炸 $\mathcal{O}(N^2)$。

```text
计算量 (FLOPs)
  ^
  |                                  / 全局注意力 Attention: O(N^2)
  |                                 /
  |                                /
  |                               /
  |                              /
  |                             /
  |    ------------------------+--------------------
  |                           /  前馈网络 Feed-Forward: O(N)
  |                          /
  |                         /
  |                        /
  +--------------------------------------------------> 序列长度 (Sequence Length N)
  0                      临界翻转点
```

> **读图说明**：短序列工况下前馈网络的计算占比居于主导；随着序列长度越过临界翻转点，自注意力机制的二次方计算量急剧攀升，最终彻底主导整网开销。

#### 局部注意力与系统常数因子优化

在不改变基础二次方理论复杂度的前提下，工程实践中通常采用两类手段来压制注意力开销：

第一类是局部注意力（Local Attention）与全局注意力的混合编排。例如在深层网络中采用分层设计，每八层仅部署一层计算全量交互的全局自注意力，其余七层全部限制在较窄窗口的局部自注意力内，以此控制计算总开销。

第二类是基于系统工程优化的常数因子压缩。在计算机系统的实战中，常数因子往往决定了算法的真实生死。标准 PyTorch 实现的注意力计算受限于显存搬运开销，有效计算吞吐通常仅维持在每秒 30 到 40 TFLOPS；而 FlashAttention 通过分块重组与核函数融合，避免了显存中对 $N \times N$ 显式注意力矩阵的物理实例化，直接最小化高带宽内存（HBM）与片上静态随机存储器（SRAM）之间的数据搬运，在几乎所有常用序列长度下实现了近乎翻倍的吞吐表现。

> **结论**：常数因子的系统级优化非常强劲，但无法改变渐近复杂度的物理边界。当上下文长度推升至 500 万到 1000 万 token 规模时，硬件层面的访存优化依然无法抵消 $\mathcal{O}(N^2)$ 的累积计算墙，必须探索时间复杂度随序列长度线性增长的注意力替代方案。

### 线性时间注意力与循环对偶结构

#### 乘法结合律与二次复杂度消除

让注意力机制突破二次方限制的底层数学支点非常简洁，即矩阵乘法的结合律。

在标准自注意力计算中，设序列长度为 $N$，查询矩阵 $Q \in \mathbb{R}^{N \times d_k}$，键矩阵 $K \in \mathbb{R}^{N \times d_k}$，值矩阵 $V \in \mathbb{R}^{N \times d_v}$。经典计算流程需要首先计算两两交互的内积矩阵：

$$A = \text{softmax}\left(\frac{Q K^T}{\sqrt{d_k}}\right) \in \mathbb{R}^{N \times N}$$

$$\text{Output} = A V \in \mathbb{R}^{N \times d_v}$$

该过程中 $Q K^T$ 的矩阵乘法直接引入了 $N^2 d_k$ 的计算开销。若暂时略去非线性的归一化函数 $\text{softmax}$，注意力计算退化为纯粹的矩阵连续相乘：

$$\text{Output} = (Q K^T) V$$

利用矩阵乘法的结合律，调整运算执行次序：

$$\text{Output} = Q (K^T V)$$

```text
经典计算顺序 (Q K^T) V:
  [ N x dk ] x [ dk x N ] ---> [ N x N ] (巨大中间矩阵，O(N^2 * dk))
  [ N x N ]  x [ N x dv ] ---> [ N x dv ]

结合律结合次序 Q (K^T V):
  [ dk x N ] x [ N x dv ] ---> [ dk x dv ] (固定尺寸中间特征，O(N * dk * dv))
  [ N x dk ] x [ dk x dv ] ---> [ N x dv ]
```

> **读图说明**：调整括号结合位置后，序列长度 $N$ 从二次方项中解耦。隐藏维度 $d_k, d_v$ 通常在几千到几万之间，而上下文长度 $N$ 动辄数百万。因此以 $N \cdot d_k \cdot d_v$ 替代 $N^2 \cdot d_k$，计算开销彻底变为随 $N$ 严格线性增长。

#### 状态累加机理与训练推理对偶性

改变矩阵乘法顺序后的线性注意力，在因果自回归（Causal）解码场景下展现出与循环神经网络（Recurrent Neural Network，RNN）完全等价的表述形态。

在因果遮蔽约束下，当前位置只能与历史键值交互。线性注意力在时间步 $t$ 的输出可以写成增量更新的形式：

$$S_t = S_{t-1} + K_t^T V_t, \quad S_t \in \mathbb{R}^{d_k \times d_v}$$

$$Y_t = Q_t S_t, \quad Y_t \in \mathbb{R}^{1 \times d_v}$$

式中 $S_t$ 即为固定尺寸的自回归隐状态矩阵。这一等价性揭示了线性注意力的核心物理属性——训练与推理的双重对偶性（Duality）：
- **训练阶段（并行视角）**：可以采用稠密矩阵相乘的形式，利用现代加速卡的高度张量并行能力，避免 RNN 传统训练中串行逐步展开的梯度回传瓶颈；
- **推理阶段（循环视角）**：无需保留庞大的 KV 缓存（KV Cache），仅需在每个时间步维护固定体积的状态矩阵 $S_t$ 并持续前传，显存占用与计算开销恒定，非常契合流式部署。

在开源工业界，MiniMax M1 模型便落地了这一理念。该模型采用了 7:1 的混合分层配置，即连续部署 7 层线性注意力后插入 1 层完整的 Softmax 注意力，在百万级长上下文中保持了优异的吞吐与长文本综合性能。

#### 遗忘门控与状态空间模型扩展

单纯的线性注意力存在明显的表达力短板：它在所有时间步盲目地将 $K_t^T V_t$ 累加到状态中，导致历史信息随时间步单调无限积聚。这一现象与早年长短期记忆网络（LSTM）所面临的问题类似——模型不仅需要学会记录，更需要学会遗忘。

状态空间模型（State-Space Models，SSM）家族中的 Mamba 与 Mamba 2 便是在线性注意力基础上引入了输入依赖的遗忘门控机制：

$$S_t = \gamma_t S_{t-1} + K_t^T V_t$$

$$Y_t = Q_t S_t + D_t V_t$$

其中门控系数 $\gamma_t$ 仅仅取决于当前输入的 token 特征 $x_t$，本身并不依赖历史隐藏状态 $S_{t-1}$。正是因为门控不具备状态递归依赖，系统依然能够通过关联扫描（Associative Scan）算法将其组织成高效的并行矩阵算子，从而完整保留训练高度并行、推理恒定状态的对偶特性；而末项 $D_t V_t$ 则作为残差直通分支，使当前时间步的局部信息能够直接投射至输出层。Nemotron-3 等模型便利用交替堆叠 Mamba 2 与全注意力的方案，在大幅降低长文本推理延迟的同时保持了模型质量。

#### 投影擦除机制与门控 Delta 网络

在 Mamba 的单衰减门控之上，Gated DeltaNet 进一步引入了第二输入门控 $\beta_t$ 以及来自经典 Delta 规则的显式正交投影擦除操作。

在更新内部记忆时，若简单将新信息叠加进去，历史残留的相关方向仍然会干扰检索。Gated DeltaNet 的状态演进逻辑可以表示为：

$$S_t = S_{t-1} \left(I - \beta_t K_t^T K_t\right) + \beta_t V_t^T K_t$$

式中 $K_t$ 经过归一化，项 $(I - \beta_t K_t^T K_t)$ 构成了一个正交投影算子。该结构在几何层面的直观机理是：在向模型状态中写入关于当前键 $K_t$ 的新值之前，首先沿着 $K_t$ 的方向将历史状态矩阵中已存储的信息投影并擦除掉，随后再执行新特征的写入；而输入门控 $\beta_t$ 充当了写入抑制阀，当 $\beta_t = 0$ 时模型完全跳过当前时间步的信息输入。

> **提示**：此类投影擦除更新在历史上曾被不同领域的研究者反复重新发现。无论是元学习中的递归最小二乘算法、快速权重编程器（Fast Weight Programmers），还是近期的测试时训练（Test-Time Training，TTT），其底层数学更新形式最终都殊途同归地收敛到了这一投影机制。

Qwen-3.5 与其前身 Qwen-Next 便大规模采用了 3:1 的门控 DeltaNet 与全注意力混合架构，在极长上下文评测中展现出相较于标准全注意力模型更陡峭的推理吞吐优势。

#### 混合层配比与长程表示衰减规律

将线性时间模块与全注意力层混合堆叠时，二者的比例对模型能力存在显著的非线性影响。字节跳动 Seed 团队与加州大学圣克鲁兹分校（UCSC）联合进行的对照消融实验揭示了这一核心规律：

```text
检索准确率 / 任务表现
  ^
  |  Full Attention 基准线: --------------------------------
  |  低比例 RNN/线性层:   ======================\
  |                                               \
  |                                                \ 临界衰减点
  |                                                 \
  |                                                  \
  |  纯 RNN / 纯线性架构:                             \-------
  +---------------------------------------------------------->
  0% (全 Softmax 注意力)                         100% (全线性层)
```

> **读图说明**：在低比例混合阶段，模型能够近乎无损地匹配全注意力基线表现；一旦线性层占比越过临界比例，对于长上下文多跳推理、关联检索与问答等任务，综合指标将发生剧烈下挫。

这一现象的物理本质在于固定状态容量与海量信息熵之间的矛盾。无论状态空间模型的更新公式设计得多么精巧，其内部维护的状态矩阵 $S_t \in \mathbb{R}^{d_k \times d_v}$ 的物理体积始终是恒定有限的；而外部输入上下文包含的信息量随序列长度无限线性扩张。将无限的信息流硬性压缩至固定维度的隐状态中，必然会导致深层特征的不可逆丢失。

### 极轻量检索式稀疏注意力机制

#### 动态索引器与二次方开销解耦

除了完全抛弃 Softmax 的线性注意力路线外，工业界开辟出的另一条高效长上下文路径是基于轻量索引的动态稀疏注意力。DeepSeek 在其架构探索中提出的动态稀疏注意力（DeepSeek Attention / DSA）便是这一思想的代表。

DSA 并不试图将计算转化为连续状态递推，而是将完整的二次方自注意力拆解为“粗筛索引”与“细粒度局部全计算”两个阶段：

```text
输入序列 Tokens (N 个，超长序列)
   │
   ├───────────────┐
   ▼               ▼
查询向量 Q        键向量 K
   │               │
   └───────┬───────┘
           ▼
┌────────────────────────────────────────┐
│ 轻量化索引器 Indexer (极低维度 / 低精度) │
│ 计算 Q_idx * K_idx^T，通过 ReLU 激活    │
│ 复杂度仍为 O(N^2)，但常数因子极小       │
└──────────────────┬─────────────────────┘
                   ▼
       Top-k 位置粗筛 (筛选出极小集合 k << N)
                   │
                   ▼
┌────────────────────────────────────────┐
│ 精细全注意力计算 Full Attention Engine  │
│ 仅在 Top-k 激活位置上计算完整的 QK^T V  │
│ 复杂度为 O(k^2)，完全解耦序列总长度 N   │
└────────────────────────────────────────┘
                   ▼
                输出特征
```

> **读图说明**：索引器保留全局两两交互以确保视野完整，但通过极端压缩隐藏维度让计算常数极其微小；后续的昂贵高精度多头交互被严格限制在 $k$ 个候选位置内。

面对“若索引器本身仍需遍历所有 token 导致复杂度仍为二次方，系统究竟如何获益”的疑问，核心在于两阶段解耦带来的常数级暴降：
1. 索引器仅执行低维投影，其矩阵通道数远低于主干网络维度，甚至可以采用低精度数值格式运行；
2. 即使索引计算具有二次方特征，主干中真正消耗大宗显存与算力的精细 Softmax 注意力被严格限定在固定常数 $k$ 的范围内，计算量为 $\mathcal{O}(k^2)$，彻底摆脱了总长度 $N$ 的二次方制约。

#### 两阶段训练策略与长序列迁移适配

在模型生命周期中，若从随机初始化阶段便挂载不可微的 Top-k 离散索引器，系统的梯度回传与特征学习将变得异常不稳定且计算浪费。工业界采用的成熟工程范式是阶段化适配：

```text
[阶段一: 短文本密集预训练]
标准稠密 Transformer 主干网络 
(在常规短上下文如 4K 窗口下充分训练，固化底层语言语义表示)
            │
            ▼
[阶段二: 长上下文扩展预训练]
嵌入轻量化闪电索引器 (DSA Indexer)
(在 32K~128K 长序列持续预训练，主干适应动态 Top-k 稀疏路由)
            │
            ▼
[阶段三: 对齐与后训练]
指令微调 (SFT) 与强化学习 (RL)
(全流程继承稀疏长文本推理能力)
```

GLM-5 与 DeepSeek-V3.2 的消融实验表明，在短上下文预训练模型的基础上直接插入索引器进行长序列扩展，只需耗费极小比例的二次算力，即可使稀疏注意力模型的长程关联检索能力迅速逼近全量 Softmax 注意力。同时，由于选择逻辑在索引层完成，主干上的全精度计算规避了直接在全网推行低精度（如 FP4）自注意力时容易诱发的数值上溢与下溢风险。

### 专家混合网络的核心动机与设计维度

#### 容量扩展与浮点计算量解耦

如果说长上下文注意力改造关注的是序列维度 $N$ 的效率，那么专家混合网络（MoE）关注的则是通道宽度维度的高效扩展。

在标准 Transformer 结构中，多层感知机（MLP）占据了模型近三分之二的静态参数量。传统稠密模型若想提升知识储备，必须同比例增加隐藏层维度，这会导致前向传播与反向传播中的单 token 计算浮点运算量（FLOPs）线性激增。

MoE 的核心物理构想，是以条件计算（Conditional Computation）打破参数量与单步计算成本的强绑定：

```text
标准稠密 MLP:
  输入 x ---> [ 单个庞大 MLP 核心 (参数量 W, 计算量 C) ] ---> 输出 y

专家混合网络 MoE:
              ┌───> [ 专家 FFN_1 (参数量 W) ] ───┐
              ├───> [ 专家 FFN_2 (参数量 W) ] ───┤
  输入 x ───> 路由 ┼───> [ 专家 FFN_3 (参数量 W) ] ───┼──> 加权聚合输出 y
  (Router)    └───> [ 专家 FFN_4 (参数量 W) ] ───┘
                    (总参数量 4W，每次仅激活 1 个，计算量 C)
```

> **读图说明**：模型整体参数量扩增至 4 倍，但每个输入 token 在推理与训练时仅路由至选定的局部专家，单步计算成本与原先单个前馈网络完全一致。

Google 的 Switch Transformer 以及 AI2 的 OLMoE 开源研究均在严格受控的基准测试中证实：在消耗完全相同训练浮点预算的约束下，提升专家稀疏度能带来测试损失（Validation Loss）的平稳单调下降。相同下游基准性能下，稀疏 MoE 模型的训练收敛速度比等效稠密模型快接近一倍。

#### 专家路由范式与候选选择策略

在将 token 分发给专家的过程中，存在两类对立的设计范式：
1. **Token 选择专家（Token Choice）**：每个 token 自主评估所有专家并挑出匹配度最高的 $k$ 个；
2. **专家选择 Token（Expert Choice）**：每个专家依据自身偏好设定容量上限，反向挑选最契合的 token。

OLMoE 的对照实验表明，尽管专家选择机制在负载均衡上具有天然的确定性，但在最终验证集损失与下游任务通用基准上，Token 选择 Top-k 范式展现出了压倒性的收敛稳定性与精度优势，因而成为了目前业界的统一标准。

在主流架构中，路由器通常由极小参数量的线性投影矩阵构成。设输入向量为 $u \in \mathbb{R}^d$，专家总数为 $N_e$，专家路由权重矩阵为 $W_r \in \mathbb{R}^{d \times N_e}$。路由器首先计算内积亲和度得分，并通过 Softmax 输出概率分布：

$$H(u) = u W_r$$

$$P = \text{softmax}(H(u))$$

模型从中提取得分最高的前 $k$ 个专家索引并进行权重归一化，仅激活对应专家：

$$G = \text{Top-k}(P, k)$$

$$\text{Output} = \sum_{i \in \text{Top-k}} \frac{P_i}{\sum_{j \in \text{Top-k}} P_j} \cdot \text{FFN}_i(u)$$

除线性投影外，学术界还探索过哈希路由（基于输入指纹进行固定映射，效果欠佳）、强化学习多臂老虎机路由（优化方差过大、收敛缓慢）以及线性指派优化（计算全局匹配开销过高，无法适应海量 token 流）。轻量线性内积配比启发式约束最终在系统吞吐与建模表达力之间取得了最佳平衡。

#### 共享专家与细粒度切分拓扑

早期的经典 MoE 架构（如 GShard 与 Switch Transformer）倾向于切分数量较少但单体参数巨大的专家模块（例如 8 或 16 个专家）。DeepSeek MoE 架构则首创并确立了现代细粒度专家（Fine-grained Experts）与常驻共享专家（Shared Experts）相结合的拓扑结构。

```text
输入特征流 u
  │
  ├─── 共享通路 (绕过路由器，无条件全量激活)
  │     ▼
  │   [ 共享专家 Shared Expert 1 ]
  │   [ 共享专家 Shared Expert 2 ] ─── 抽取全局通用常识表示
  │     │
  │     └──────────────┐
  └─── 路由通路        │
        ▼              ▼
     [ 路由器 Router (Top-k 细粒度选择) ]
        │
        ├───> 细粒度专家 Expert_a
        ├───> 细粒度专家 Expert_b ─── 学习高阶专用模式
        │
        └──────────────┼─────────────── 加权求和
                       ▼
                   最终聚合输出
```

> **读图说明**：共享专家对所有输入无差别生效，沉淀句法、通用语义等底层常识；细粒度路由专家则各自高度特化，处理差异化领域特征。

消融实验清晰证实了这一结构的工程价值：当把传统的粗粒度大专家进一步细拆为微型单元，并剥离出常驻的共享专家时，模型在知识密集型问答评测（如 TriviaQA、Natural Questions）中的表现出现了跃升。该模式避免了多个独立专家在训练中重复学习通识特征，将稀疏专家的宝贵容量完全释放给了专门化表征。

### 稀疏路由的训练困境与启发式平衡

#### 离散决策不可微与专家坍缩

稀疏 MoE 最严峻的挑战发生在反向传播过程中。为了换取计算稀疏性，模型在训练时同样只能激活 $k$ 个专家，这使得 Top-k 离散操作在数学上不可微，并且梯度无法传导至未被激活的绝大多数专家。

直接采用纯粹的梯度下降训练这类离散门控网络，会导致灾难性的“专家坍缩（Expert Collapse）”或“专家饥饿（Expert Starvation）”现象：

```text
初始化阶段: 各专家性能存在微小随机抖动
                │
                ▼
正反馈循环建立: 路由器略微偏向某个初始表现较好的专家
                │
                ▼
累积强化偏差: 该专家获得绝大多数训练 Token，梯度频繁更新，能力迅速增强；
              其余未被激活的专家长期缺乏数据滋养，表现持续停滞
                │
                ▼
彻底坍缩极限: 整个网络退化为极少数专家承担 99% 以上的流量，
              系统退化为小容量稠密模型，海量外部参数彻底闲置报废
```

早期研究曾尝试引入加性高斯噪声或乘法抖动来打破平衡以增强探索，但这些随机性注入方法往往恶化了长程训练动态，现代架构更倾向于直接引入确定性的辅助均衡损失。

#### 概率质量惩罚与辅助均衡损失

为了强制平衡各专家的工作负载，Switch Transformer 设计了一套极其精巧的辅助均衡损失函数。设当前批次内共有 $T$ 个 token，专家总数为 $N_e$，辅助损失定义为：

$$\mathcal{L}_{\text{balance}} = \alpha N_e \sum_{i=1}^{N_e} f_i P_i$$

式中两项具有完全不同的微积分意义：
- $f_i$ 是当前批次中实际被路由指派给专家 $i$ 的 token 比例（离散硬统计量）：

$$f_i = \frac{1}{T} \sum_{t=1}^T \mathbb{I}(\text{token } t \text{ 被分配至专家 } i)$$

- $P_i$ 是当前批次中路由器分配给专家 $i$ 的总概率质量（连续可微变量）：

$$P_i = \frac{1}{T} \sum_{t=1}^T P_i(u_t)$$

该损失函数并非从凸优化第一性原理推导而来，其本质机理可以通过对路由器输出可微变量 $P_i$ 求偏导来透视：

$$\frac{\partial \mathcal{L}_{\text{balance}}}{\partial P_i} = \alpha N_e f_i$$

> **机理剖析**：由于 $f_i$ 记录了分配给专家 $i$ 的实际 token 数量，若专家 $i$ 成为热门专家，$f_i$ 显著变大，回传给 $P_i$ 的惩罚梯度就越陡峭，在反向传播中强行压低路由器对该专家的亲和度评分；反之，若某专家陷入饥饿状态，$f_i \to 0$，针对该专家的抑制梯度彻底消失，从而为冷门专家创造重新被激活的通道。

OLMoE 在其消融实验中完整展示了剥离该损失的恶果：当完全关闭辅助均衡损失时，所有 token 迅速坍缩流向两三个特定专家，验证集损失剧烈恶化；一旦引入该损失，token 分布立刻呈现出平整均匀的利用形态。

#### 设备拓扑感知与无辅助损失演进

在跨多机多卡训练 MoE 模型时，专家通常被分散打散在不同的物理计算节点上。若仅在纯数学层面控制每个专家的 token 比例，仍然可能出现特定计算节点（Device）上的全部专家同时处于高负载、其余物理卡闲置的硬件不平衡状态。

因此，DeepSeek-V2 等工业级模型在专家级平衡损失之外，额外引入了设备级辅助平衡损失（Per-device Load Balancing Loss）：

$$\mathcal{L}_{\text{device}} = \beta N_d \sum_{d=1}^{N_d} f'_d P'_d$$

式中 $N_d$ 为物理设备总数，$f'_d$ 与 $P'_d$ 为映射至该物理设备上全部专家的流量汇聚比例与累计概率质量，确保硬件维度的满负荷对称运行。

尽管辅助损失成功稳定了训练，但它本质上属于人为干预的多任务优化目标，强加的均匀分布假设在一定程度上削弱了专家自主专门化的潜力。为此，DeepSeek-V3 提出了一种无辅助损失平衡（Aux-loss-free Balancing）架构：完全移除静态辅助损失项，转而在路由器内部为每个专家维护一个动态偏置项 $b_i$。系统在训练过程中依据滑动时间窗内监测到的实际设备队列负载，在线微调各专家的偏置门限，配合 Sigmoid 与局部 Softmax 的混合加权机制，实现了零超额损失约束下的高水准动态负载自适应平衡。

### 专家并行的工程落地与稳定性控制

#### 激活值通信瓶颈与潜空间投影

在大规模集群上部署 MoE 时，数据并行受限于全局批量大小（Batch Size）的物理极限，张量模型并行受限于注意力多头等内部切分点的颗粒度，而专家并行（Expert Parallelism）开辟了一个全新的并行正交维度。每个专家模块是一个天然解耦的独立子网络，可以被切分放置在独立的显卡或计算节点上。

然而，专家并行直接引入了昂贵的跨节点激活值通信开销。当一个 token 被路由判定属于远端机器上的专家时，该 token 的完整激活向量必须通过网络拓扑发送过去，经专家计算后再将输出向量传回（All-to-All 集体通信操作）。

```text
传统专家并行通信流程:
  残差流激活向量 u (隐藏维度 d, 尺寸巨大)
  ───────────────────────────────────────> 跨卡网络带宽耗尽 (All-to-All 瓶颈)

Nemotron-4 潜空间降维投影通信方案:
  残差流激活向量 u (高维)
          │
          ▼
  [ 降维线性映射 Down-Projection ] ───> 低维潜向量 (维度 d_low << d)
                                              │
                                              ▼ (通信数据量缩减至 1/4 ~ 1/8)
                                       跨卡 All-to-All 极速网络传输
                                              │
                                              ▼
                                 [ 升维恢复投影 Up-Projection ] ───> 注入远端专家
```

> **读图说明**：对于无需跨卡移动的本地共享专家，保留完整高维表示以保障推理质量；对于必须通过跨机互联通信的路由专家激活流，先进行局部低维压缩再发出通信包，彻底解开跨卡集群的网络带宽瓶颈。

#### 动态队列与无丢弃计算架构

在早期 MoE 运行框架中，每个专家为防止自身内存爆炸，会设定严格的接收容量上限（Capacity Factor）。一旦分配给该专家的 token 数量溢出队列长度，多余的 token 将被系统静默丢弃（Token Dropping）——即直接跳过前馈计算，由残差连接原样透传。

这种静默丢弃在工业落地中引发了严重的确定性与安全性隐患：
- **推理随机性与用户串扰**：在多租户并发服务中，如果其他并发请求的输入偶然命中了某特定专家导致队列打满，系统将直接丢弃当前用户的 token 计算，引发相同输入在不同并发状态下输出结果质量不一致的问题；
- **训练信息损坏**：训练阶段关键语义 token 的随机丢弃会导致梯度估计产生不可控的系统性偏差。

现代高性能 MoE 运行时系统（以 Megablocks 为代表）通过重构底层 GPU 稀疏矩阵运算核心，引入了块对角（Block-diagonal）与非规则分块稀疏通用矩阵乘法（Sparse GEMM），在底层算子层面原生支持变长输入的直接高效执行，彻底摒弃了人为补齐与截断丢弃逻辑，实现了全生命周期的无丢弃（Drop-free）确定性计算。

#### 路由器数值精度与微调过拟合控制

由于路由器核心包含指数与除法运算（Softmax），数值稳定性构成了 MoE 训练的另一处重灾区：

> **易错点**：全网推行低精度混合训练（如 FP16 或 BF16）时，路由器对极端 Logits 极为敏感，微小的溢出均会诱发门控概率剧烈震荡，导致训练损失曲线频繁突发尖刺（Spikes）。

成熟的工程解法包括：
1. **强制提升路由器计算精度**：将门控亲和度计算及 Softmax 归一化严格固化在 FP32 精度空间内运行；
2. **挂载正则化 Z-Loss**：对门控输入的原始 Logits 施加均方约束，通过惩罚过大的未归一化分值来压制数值溢出风险：

$$\mathcal{L}_z = \gamma \cdot \frac{1}{T} \sum_{t=1}^T \left(\log \sum_{i=1}^{N_e} \exp(H_i(u_t))\right)^2$$

在下游微调场景下，MoE 模型极易发生严重的过拟合。由于其静态总参数量庞大，在样本量有限的数据集（如 GLUE 基准）上若微调所有专家，训练集与验证集的性能差距会急剧拉大。实践中最为行之有效的轻量干预策略是：在下游微调阶段冻结全部或绝大部分稀疏路由专家，仅微调共享专家、非 MoE 前馈层或全注意力层。

#### 稠密模型升级复用的技术演变

在开源 MoE 发展的过渡时期，学术界与工业界曾广泛探索过升级复用（Upcycling）技术。其出发点在于避免从零预训练 MoE 的高昂风险：
1. 选取一个已充分收敛的高质量稠密基座模型；
2. 将稠密模型中的 MLP 权重直接复制多份，作为各个专家的初始权重；
3. 随机初始化路由门控矩阵，随后在小规模数据上开启适应性持续预训练。

MiniCPM 团队曾将 2.4B 的稠密模型通过 Upcycling 升级为 13.4B 的 MoE 模型，获得了近乎无痛的能力跨越；早期开源代表 Qwen-1.5-MoE 同样采用了从 1.8B 稠密主干进行 Upcycling 初始化的路线。

> **结论**：Upcycling 是特定历史阶段算力受限下的巧妙折中方案。随着现代 MoE 架构训练基础设施与负载均衡技术的彻底成熟，业界当前已普遍转向直接从零初始化进行原生的端到端全量 MoE 预训练，以最大化释放专家的分化潜能。

### 现代高能架构综合范式演进

#### 细粒度专家与潜变量注意力协同

剖析现代前沿开源大模型的架构演进轨迹（以 DeepSeek 系列为标杆），可以看到架构优化的终极方向并非孤立调整某一部件，而是将注意力侧的显存优化与前馈网络侧的容量扩展进行深度系统级协同。

下表总结了三代代表性 MoE 演进路线的关键特性：

| 架构代际 | 专家组织拓扑 | 负载均衡策略 | 注意力机制形态 |
| :--- | :--- | :--- | :--- |
| **初代标准范式**（DeepSeek-V1 / Switch 等） | 初步细粒度专家 + 少量共享专家 | 经典 Top-k 路由 + 单一专家级辅助均衡损失 | 标准多头自注意力（MHA） |
| **系统协同范式**（DeepSeek-V2） | 2 个常驻共享专家 + 大规模细粒度专家 | 专家级损失 + 跨物理设备通信均衡损失 | 多头潜在注意力（MLA）初次引入 |
| **极简全能范式**（DeepSeek-V3） | 高比例细粒度切分 + 常驻共享通道 | 无辅助损失平衡（动态偏置调节） | 深度优化版 MLA + 解耦式 RoPE 坐标系 |

在 DeepSeek-V2 与 V3 中扮演核心角色的多头潜在注意力（Multi-head Latent Attention，MLA），其本质是将注意力键值（KV）对进行低秩潜空间压缩：
- 摒弃传统每个时间步独立缓存高维 Key 和 Value 矩阵的常规做法；
- 通过投影矩阵将隐藏状态先压缩为一个低维潜变量向量 $C_t^{KV}$，推理时仅对这一低维向量维护 KV 缓存；
- 在实际计算注意力时，再通过解耦映射还原出运算所需的特征，从而在显存层面缩减了数倍的缓存体积占用；
- 针对旋转位置编码（RoPE）无法与低秩压缩矩阵直接融合的难题，MLA 单独开辟出不受低秩投影约束的显式位置维度，实现了几何位置感知与缓存极致压缩的统一。

#### 多标记预测机制与投机解码集成

在模型训练与推理的顶层任务设计上，现代前沿架构还集成了多标记预测（Multi-Token Prediction，MTP）机制。传统自回归语言模型严格遵循单步预测范式，即在时间步 $t$ 仅计算并预测第 $t+1$ 个 token 的交叉熵损失；而在挂载 MTP 的架构中，主干网络顶层外挂了若干轻量化预测头，使其在每个时间步同时对未来连续的多个 token（例如 $t+1, t+2$）进行联合建模推断。

从统计学习视角来看，多标记预测强制底层隐藏表征编码更长周期的上下文依赖结构，有助于压制局部短视规划偏差；从系统部署视角来看，随模型主干联合训练出来的多个前瞻预测头，在推理服务阶段天然构成了零显存开销的内置投机解码引擎（Speculative Decoding Engine），可以在无需引入额外小型草稿模型的前提下，实现自回归文本生成吞吐的显著提升。

### 本讲提到的题目

#### 上下文长度翻倍下的前馈与注意力浮点开销估算

在讨论自注意力与前馈网络的计算开销分流时，我们分析了当输入序列长度显著增长时网络不同模块的算力缩放行为。

**题干**：
已知某语言模型的单层前馈网络计算量满足 $C_{\text{FFN}} = 8 N d^2$（式中 $N$ 为上下文序列长度，$d$ 为隐藏层维度），单层标准自注意力计算量满足 $C_{\text{Attn}} = 4 N d^2 + 2 N^2 d$。若将当前输入的上下文长度 $N$ 从 4,000 扩展至 64,000（扩大至 16 倍），请推导说明前馈网络与自注意力的二次方项分别扩张了多少倍，并由此解释长文本架构为何必须实施注意力机制替代。

**解析依据**：
根据正文中前馈计算线性增长 $\mathcal{O}(N)$ 与注意力计算二次方爆炸 $\mathcal{O}(N^2)$ 的渐近分析：
1. **前馈网络部分**：$C_{\text{FFN}}$ 与 $N$ 严格呈一次正比关系。当 $N \to 16 N$ 时，前馈计算量变为 $8 (16 N) d^2 = 16 \cdot C_{\text{FFN}}$，即计算量恰好扩张 16 倍；
2. **自注意力二次方项**：项 $2 N^2 d$ 与 $N$ 呈二次方关系。当 $N \to 16 N$ 时，该项变为 $2 (16 N)^2 d = 256 \cdot (2 N^2 d)$，即该项计算量直接膨胀了 $16^2 = 256$ 倍。

**答案**：
前馈网络计算量扩张 16 倍，自注意力机制中的二次方项计算量剧烈膨胀 256 倍。这直观证明了随着上下文长度向数万至数百万级别拓展，二次方注意力开销将迅速击穿硬件显存与算力极限，因此必须采用线性时间注意力或轻量索引稀疏化方案将其约束在关于 $N$ 的线性阶内。

## 现代 Transformer 架构演进与设计权衡
> 对应块：BLK22 | 覆盖分集：P21上 | 块标题（分集名）：《Lecture 3_ Architectures》

聊起模型架构（Architecture），老实说，在很长一段时间里这都是个让人摸不着头脑的领域。我们大概都曾经幻想过，要是只需掌握一点 VC Dimension（Vapnik-Chervonenkis 维数）之类的经典统计学习理论，就能像推导数学定理一样严格导出最优网络架构，那该多轻松。但现实完全不是这回事。

理解架构最好的办法，永远是你亲自去写代码、训练模型，在 GPU 集群上尝试不同的组合方案。这也是我们动手构建大语言模型的核心意义所在。然而，现实中没有任何人或机构拥有无限的算力和时间去穷尽整个高维设计空间。退而求其次的次优解，就是从整个工业界与学术界的集体试错经验中学习——拉远视角，审视那些被反复验证有效的模型，看看大家究竟做了哪些选择。我们会发现一个极其清晰的规律：在所有能够稳定运行并取得优异表现的现代架构中，某些核心设计与超参数是高度趋同甚至完全固定的，而另一部分细节则可以宽泛调整而不显著影响最终性能。

回顾从 Vaswani 等人最初提出 Transformer 到 GPT-3 这一时期，业内经历了漫长且发散的探索阶段，当时并没有一个公认的黄金标准。直到 LLaMA 发布，大家惊叹于其出色的表现，纷纷转向训练自己的“类 LLaMA”架构。最近几年的演进主线更是清晰：一方面是通过重构计算拓扑让千亿参数规模的训练更加稳定，杜绝中途梯度爆炸；另一方面则是通过位置编码与注意力机制的重构，支持越来越长的上下文依赖。

架构绝不是象牙塔里推导出的数学艺术品，而是一组为了迎合物理现实而做出的复杂工程权衡。它不仅要能高效拟合海量数据并具备良好的外推泛化能力，还必须严格契合 GPU 硬件的物理特性，确保吞吐最大化，并且在长达数月的训练周期中绝不崩溃。所有这些看似并不优雅的结构变体，本质上都是这些工程硬约束直接固化在模型代码中的印记。

### 归一化位置与残差连接机制

在最初的 Transformer 论文中，作者团队在绝大多数构件的设计上都做出了极富远见的决策，唯独在归一化层（Layer Normalization）的放置位置上，后来的实践证明存在显著缺陷。围绕这一位置的调整，奠定了现代架构稳定性的第一块基石。

```text
Post-Norm (原始 Transformer 结构):
x ───┬───> [ Multi-Head Attention ] ───> (+) ───> [ LayerNorm ] ───┬───> [ Feed-Forward ] ───> (+) ───> [ LayerNorm ] ───> 输出
     │                                    ▲                        │                            ▲
     └────────────────────────────────────┘                        └────────────────────────────┘

Pre-Norm (现代主流结构):
x ───┬───> [ LayerNorm ] ───> [ Multi-Head Attention ] ───> (+) ───┬───> [ LayerNorm ] ───> [ Feed-Forward ] ───> (+) ───> 输出
     │                                                      ▲       │                                             ▲
     └──────────────────────────────────────────────────────┘       └─────────────────────────────────────────────┘
```
上图展示了 Post-Norm 与 Pre-Norm 在 Transformer 单层内部的数据流向差异：Post-Norm 将归一化置于残差相加之后的主干流上，而 Pre-Norm 则将归一化移至分支计算前端，保持残差主干直通。

#### 残差路径归一化与 Pre-Norm 范式

在原始 Transformer 中，LayerNorm 位于所谓的残差路径（Residual Path）上。输入张量 $x$ 沿着残差流向前传递，在分支上完成注意力或前馈网络（FFN）计算后，分支增量直接加回残差流，紧接着在每个子模块末尾执行一次 LayerNorm。这种设计被称为 Post-Norm，更准确的称谓应当是 Residual Norm，因为归一化算子直接拦截了主干残差流。

现代密集自回归语言模型几乎全盘推翻了这种做法，一致转向 Pre-Norm 结构。在 Pre-Norm 中，LayerNorm 被移到了残差流外部，严格置于多头注意力和 FFN 的计算分支之前。输入向量在进入注意力或前馈矩阵运算前先做归一化，而计算出的增量则直接累加回未经归一化的残差主干上。

现代模型中极罕见的例外是 OPT-350M。开源模型 OPT 的整体实现存在不少历史包袱和工程瑕疵，而 OPT-350M 更是其中极其特殊的反例——它在残差流内部保留了 Post-LayerNorm，这也成为该模型在深层扩展时训练不稳定的重要诱因之一。

#### 纯净残差流与梯度反向传播

学界最初探索 Pre-Norm 的动机，主要是希望能去掉训练初期脆弱的学习率预热（Warmup）阶段。然而后续研究很快发现，即使改用 Pre-Norm，在千亿规模大模型训练中完全省去预热依然会导致优化不稳定。Pre-Norm 真正不可替代的价值，在于彻底解决了深层网络中的梯度衰减与梯度爆炸问题。

> **定义**：纯净残差流（Clean Residual Stream）是指在 Transformer 深度堆叠过程中，主干残差路径上不设置任何非线性变换、缩放或统计归一化算子，使底层输入能够无损直通顶层，顶层梯度亦能无阻碍直达底层。

从数学机理审视，在 Pre-Norm 架构下，第 $l$ 层的输出状态 $x_{l+1}$ 满足：

$$x_{l+1} = x_l + F(\text{Norm}(x_l))$$

将整个网络从第 $l$ 层向顶层 $L$ 递归展开，可得：

$$x_L = x_l + \sum_{k=l}^{L-1} F(\text{Norm}(x_k))$$

当模型通过反向传播计算损失 $\mathcal{L}$ 对浅层状态 $x_l$ 的梯度时，根据链式法则：

$$\frac{\partial \mathcal{L}}{\partial x_l} = \frac{\partial \mathcal{L}}{\partial x_L} \left( I + \frac{\partial}{\partial x_l} \sum_{k=l}^{L-1} F(\text{Norm}(x_k)) \right)$$

括号中的单位矩阵 $I$ 构成了一条完美的无阻碍直通路径（Highway）。无论网络堆叠到几十层还是上百层，反向传播的梯度都能以接近常数级的规模直接穿透到底层，保证了浅层参数得到充分更新。

反观 Post-Norm 架构，每经过一个子层，主干状态都被强制施加一次统计归一化：

$$x_{l+1} = \text{Norm}(x_l + F(x_l))$$

在反向传播过程中，每一层都必须连续乘上 LayerNorm 的雅可比矩阵。该雅可比矩阵会随着网络深度的加深而急剧扭曲梯度的范数。Salazar 与 Yuan 的早期对比研究表明，Post-Norm 在训练深层 Transformer 时会频繁遭遇极高幅度的梯度尖峰（Gradient Spikes），导致优化器步长失控、损失函数震荡甚至数值发散；而 Pre-Norm 则在初始化阶段就能保持梯度的稳定传播，从根源上平抑了尖峰的频率与强度。

#### 外部 Post-Norm 与双重归一化拓展

既然核心原则是“保持残差流纯净”，那么归一化层是否必须位于计算分支的最前端？答案是否定的。只要归一化算子不截断主干残差流，将其置于分支计算之后同样完全成立。

近期部分前沿模型（例如 Grok、Gemma 2 以及 OLMo 2）探索了位于残差流外部的 Post-Norm 变体。其计算拓扑为：输入直接进入注意力或 FFN 分支，在计算完成后对分支输出增量执行归一化，随后再将归一化后的增量累加回残差主干。

此外，还有一些模型采用了更为保守的双重归一化（Double Norm）策略：在计算分支的输入端放一个 LayerNorm，完成计算后在分支输出端再追加一个 LayerNorm。

> **提示**：在大模型工程实践中存在一条被反复证实的经验规律：一旦在深层模型训练中遭遇难以定位的数值下溢、溢出或损失震荡，在注意力机制内部（如 QK-Norm）或计算分支两端额外增加归一化算子，几乎总是能够立竿见影地平抑数值波动并恢复训练稳定性。

### 归一化算子演进与硬件算术强度

确定了归一化层在宏观拓扑中的位置后，微观算子本身的数学定义与硬件执行效率成为了进一步优化的核心靶点。

#### 从 LayerNorm 到 RMSNorm

标准 LayerNorm 的数学运算包含均值中心化、方差缩放以及仿射变换：

$$\mu = \frac{1}{d} \sum_{i=1}^d x_i, \quad \sigma^2 = \frac{1}{d} \sum_{i=1}^d (x_i - \mu)^2$$

$$\text{LN}(x) = \frac{x - \mu}{\sqrt{\sigma^2 + \epsilon}} \odot \gamma + \beta$$

其中 $d$ 为隐藏层维度，$\gamma$ 与 $\beta$ 分别为可学习的缩放与偏置参数，$\epsilon$ 为防止除以零的微小常数。

RMSNorm（Root Mean Square Layer Normalization）则做出了激进的简化：它完全舍弃了均值计算与减法中心化步骤，同时去掉了加性偏置项 $\beta$，仅仅依据激活值的均方根（RMS）进行缩放归一化：

$$\text{RMS}(x) = \sqrt{\frac{1}{d} \sum_{i=1}^d x_i^2 + \epsilon}$$

$$\text{RMSNorm}(x) = \frac{x}{\text{RMS}(x)} \odot \gamma$$

从统计表示能力来看，LayerNorm 具有平移不变性与缩放不变性，自由度严格高于 RMSNorm。如果纯粹从理论表达能力出发，并没有非用 RMSNorm 不可的数学依据。然而，在涵盖数百亿参数的自回归语言建模任务中，大量实证数据证明：舍弃均值偏移并没有造成任何可被检测到的困惑度（Perplexity）或下游任务表现损失。

#### 算术强度与内存带宽瓶颈

既然两者建模能力完全对等，为何全行业所有主流现代大模型几乎无一例外转向了 RMSNorm？这一抉择的核心驱动力来自于硬件与系统层面的协同考量。

> **定义**：算术强度（Arithmetic Intensity）指算法在硬件上执行时，所完成的浮点运算量（FLOPs）与访问内存数据量（Memory Access Bytes）的比值，即 $\text{FLOPs}/\text{Byte}$。

现代 GPU（如配有 Tensor Core 的计算加速卡）拥有极其庞大的峰值计算能力，但将数据从高带宽板载显存（HBM）搬运至计算核心片上高速缓存（SRAM）的带宽却相对狭窄。衡量计算任务效率的根本法则，在于尽可能保持计算单元的高负载，避免让 GPU 处于“等待内存搬运数据”的饥饿状态。

```text
计算类型特性对比:
┌─────────────────┬───────────────────┬──────────────────────────────────────────┐
│ 操作类型        │ 算术强度级别      │ 性能瓶颈特征                             │
├─────────────────┼───────────────────┼──────────────────────────────────────────┤
│ 矩阵乘法 (GEMM) │ 极高 (Compute)    │ 算力受限：数据载入片上后重复利用，GPU 满载│
│ 统计归一化 (Norm)│ 极低 (Memory-Bound)│ 带宽受限：大量显存读写，计算单元严重空闲 │
└─────────────────┴───────────────────┴──────────────────────────────────────────┘
```

这里展现出一个极具冲击力的系统级工程反差：
在整个 Transformer 的前向与反向传播中，归一化操作所消耗的浮点运算量，仅仅占据全系统总运算量的约 0.17%。然而，因为其算术强度极低，必须在全维度上对庞大的激活值进行规约和逐元素访存，在实际运行耗时中，这类统计归一化操作往往占据了高达 25% 的端到端执行时间。

在激活值维度巨大或批处理吞吐极高的工作负载中，显存读写延迟几乎主导了归一化层的耗时。RMSNorm 去掉了均值统计、减法和偏置相加，直接减少了在快慢内存之间的数据往返次数与流水线中断。

Dehghani 等人在 2020 年系统评估架构变体的论文中明确指出，在 1B 参数规模的模型上，仅通过将 LayerNorm 替换为 RMSNorm，每秒处理步数（Steps per Second）就获得了可观的吞吐增长；同时由于方差计算中省去了减均值带来的数值舍入误差，训练稳定性与下游指标甚至略有微幅正向收益。这在工程上属于典型的“零代价系统优化”。

#### 线性层偏置项剥离

与去掉归一化偏置项逻辑一致的另一项通用演进，是彻底剥离 Transformer 内部所有线性映射层（Linear Projections）的偏置向量 $b$。

在原始 Transformer 中，Query、Key、Value 投影矩阵、注意力输出投影矩阵以及两层前馈网络均包含偏置项 $xW + b$。然而，现代主流开源模型（包括 LLaMA 系列等）几乎全部将模型改写为无偏置（Bias-Free）形式：

$$y = xW$$

这种设计的首要考量同样是系统优化：偏置相加同样属于算术强度极低的显存读写密集型操作，将其完全剔除能够简化算子融合（Kernel Fusion）并略微提升吞吐。此外，在长序列上下文和超深层结构中，累积的静态偏置往往容易诱发特定隐层维度的数值漂移，移除偏置在工程实践中被证明有助于巩固训练稳定性。

### 前馈网络与门控激活函数

多层感知机（MLP）作为 Transformer 块内部参数量占比最大的组成部分，承担着事实知识存储与跨通道特征融合的关键职能。这一模块的核心演化体现在从传统单一标量非线性激活，全面跃迁为双通道的门控线性单元。

#### 激活函数演变与门控原语

在深度学习早期，ReLU 函数 $\max(0, x)$ 凭借其计算极简与正区间梯度不饱和的特性被广泛采用。随后，GPT-3、BERT 等模型普及了 GELU（高斯误差线性单元）：

$$\text{GELU}(x) = x \Phi(x) = x P(X \le x), \quad X \sim \mathcal{N}(0, 1)$$

GELU 在零点左侧引入了平滑的负向微小凹陷，使得负区间的输入依然保有非零梯度，改善了复杂表征空间中的优化动态。即便是更激进的探索，如 Nemotron-340B 使用的平方 ReLU（$\text{ReLU}^2$），在特定规模下也证明能够稳定工作。

然而，架构领域最强大的构建原语之一，始终是门控机制（Gating Mechanism）。与其依赖固定形态的非线性标量变换，不如引入一个可学习的门控通道，对主通道的信息流动实施动态调节。

#### GLU 系列结构变体

门控线性单元（Gated Linear Unit, GLU）的基本构想，是在前馈层输入端构建两条并行的线性投影，其中一条经过非线性激活后作为“门控信号”，与另一条数据流进行逐元素点乘（Hadamard 积），最后通过第三个线性层映射回原始维度。

```text
标准双层 MLP (ReLU):
x ───> [ W1 投影 ] ───> [ ReLU 激活 ] ───> [ W2 投影 ] ───> 输出

门控线性单元 (GLU 变体):
x ───┬───> [ W_gate 投影 ] ───> [ 激活函数 σ ] ───┐
     │                                            ▼
     └───> [ W_up 投影 ]   ─────────────────────> (⊗) 逐元素乘 ───> [ W_down 投影 ] ───> 输出
```
上图对比了传统两矩阵 MLP 与三矩阵 GLU 的计算分支拓扑：GLU 通过将上投影分支与非线性门控分支进行逐元素相乘，构建了动态特征过滤机制。

依据门控分支采用的不同非线性激活函数 $\sigma$，GLU 衍生出多种具体变体：

1. **ReGLU**：门控函数采用 ReLU：
   $$\text{FFN}_{\text{ReGLU}}(x) = (\text{ReLU}(x W_{\text{gate}}) \otimes (x W_{\text{up}})) W_{\text{down}}$$
2. **GEGLU**：门控函数采用 GELU：
   $$\text{FFN}_{\text{GEGLU}}(x) = (\text{GELU}(x W_{\text{gate}}) \otimes (x W_{\text{up}})) W_{\text{down}}$$
3. **SwiGLU**：门控函数采用 Swish（又称 SiLU，即 $x \cdot \text{sigmoid}(\beta x)$，通常 $\beta=1$）：
   $$\text{FFN}_{\text{SwiGLU}}(x) = (\text{Swish}(x W_{\text{gate}}) \otimes (x W_{\text{up}})) W_{\text{down}}$$

在工业界阵营分布上，Google 体系（例如 T5、Gemma 系列）长期青睐 GEGLU；而 PaLM 以及以 LLaMA 为代表的现代开源模型生态，则全面收敛于 SwiGLU。实证对比显示，GEGLU 与 SwiGLU 之间的表现差距极小，真正产生本质跨越的是“门控机制本身的存在”。

#### 参数对齐与三分之二经验法则

引入门控机制带来了一个不容忽视的结构性变化：原本的单层前馈网络只需两个权重矩阵（上升投影 $W_1$ 与下降投影 $W_2$），而 GLU 必须引入第三个矩阵（门控投影 $W_{\text{gate}}$）。如果不调整中间维度，前馈模块的参数量将直接激增 50%。

为了在评估模型改进时剔除“参数量膨胀”带来的虚假增益，必须对网络超参数执行严格的参数对齐。

> **结论**：在保持模型总参数量与传统四倍隐藏维度（$4d$）的双层 FFN 严格一致的前提下，采用 GLU 结构时必须将前馈隐层维度 $d_{\text{ff}}$ 缩减为原维度的三分之二：
> $$d_{\text{ff}} \approx \frac{2}{3} \times 4d = \frac{8}{3}d$$

Noam Shazeer 在 2020 年提出 GLU 变体的奠基性论文中，严格贯彻了这一“三分之二法则”，在控制总浮点计算量与参数量完全守恒的条件下进行了大量的控制变量与误差棒（Error Bars）实验。Narang 等人在 Google T5 体系上的大规模对比实验同样印证了这一结论：无论是在预训练交叉熵损失上，还是在下游综合语言理解指标上，经过参数对齐的 SwiGLU 均显著且稳定地碾压非门控基线。

### 块级执行时序与层间拓扑

除了子层内部的算子改造，整个 Transformer 块（Block）在更高维度的宏观串并行拓扑结构上，也经历过激烈的探索与实践检验。

#### 串行执行与并行层的提出

标准 Transformer 块采用串行执行模式：输入张量必须先完整通过多头注意力机制，求和加回残差流后，再作为输入送入前馈网络进行二次计算：

$$x_1 = x + \text{Attention}(\text{LN}(x))$$

$$x_2 = x_1 + \text{FFN}(\text{LN}(x_1))$$

从现代高性能计算系统的角度审视，串行拓扑构成了一条刚性的时序依赖链：GPU 在执行前馈计算之前，必须完全等待注意力分支的所有点积与投影计算落盘，这在底层流水线上制造了一定的气泡（Bubble）。

为了打破这种执行瓶颈，开源社区在 GPT-J 模型中率先尝试了并行层（Parallel Layers）拓扑。随后，Google 在千亿规模的 PaLM 模型中激进地全面采用了该架构：

$$x_{\text{out}} = x + \text{Attention}(\text{LN}(x)) + \text{FFN}(\text{LN}(x))$$

```text
并行层执行拓扑 (Parallel Block):
               ┌───> [ Multi-Head Attention ] ───┐
x ───> [ LN ] ─┤                                 ├───> (+) ───> 输出
               └───> [ Feed-Forward Network ] ───┘      ▲
▲                                                       │
└───────────────────────────────────────────────────────┘
```
上图描绘了并行层的计算拓扑：Attention 与 FFN 接收经由同一个 LayerNorm 归一化后的相同输入并同时计算，计算结果合并相加后一次性累加回残差流。

并行层在系统底层带来了极大的优化空间：
1. Attention 与 FFN 可以共享同一个输入归一化算子，省去了一次完整的低算术强度访存。
2. 两个子模块的前向输入矩阵乘法（$W_q, W_k, W_v$ 以及 $W_{\text{gate}}, W_{\text{up}}$）在底层可以直接融合成一个极大的 GEMM 算子，极大幅度推高了 Tensor Core 的吞吐利用率。
PaLM 官方技术报告曾高调指出，并行层拓扑为其带来了约 15% 的端到端训练速度提升，且声称未观察到明显的性能下降。

#### 表达能力瓶颈与拓扑收敛

然而，历史实践给出了更严苛的检验。在过去两年的架构演进中，除了极少数深受 Google 早期技术栈影响的模型（如早期 Cohere 系列）之外，全行业新发布的高水平自回归模型几乎无一例外重返传统的串行结构。

这一技术回退背后的深层逻辑主要有两点：

1. **表达能力折损**：将注意力机制与 FFN 从串联改为并联，在数学本质上等同于将模型的有效表征深度直接腰斩。串行结构允许 FFN 基于经过注意力动态聚合后的上下文表征进行非线性特征重组；而并行结构强制两者基于完全相同的上一层静态表征进行计算，破坏了深层语义逐层抽象的层次化机制。
2. **底层算子优化的平替**：随着 FlashAttention 及其后续算子融合内核的突破性进展，串行 Transformer 块中注意力部分的延迟被大幅压缩，使得并行拓扑带来的系统加速收益从最初诱人的 15% 衰减至边际微弱的水平。

Google 自身在后续推出的新一代模型（如 Gemma 系列）中默默回归串行拓扑，这构成了工业界用脚投票的明确信号：为了微不足道的系统吞吐收益去牺牲模型的表征深度，在千亿规模预训练中是一笔并不划算的交易。

### 序列位置依赖与旋转位置嵌入

自注意力机制的数学核心是集合间的点积内积运算：

$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$

这一运算本质上具备置换不变性（Permutation Invariance）。若不显式引入任何位置信息，随意打乱输入序列中词元的先后顺序，注意力输出仅仅随之发生对应的位置置换，模型本身完全无法感知词与词之间的时序与语法距离。如何向模型注入位置依赖，是整个 Transformer 架构演变最剧烈、也最关键的阵地。

#### 位置编码演进脉络

在漫长的探索周期中，学界涌现出三种代表性路线：

1. **正弦/余弦绝对位置编码（Vaswani 等人）**：利用不同频率的三角函数生成确定性的静态位置向量，直接与输入的词嵌入向量按元素相加。其直觉来源于连续信号的傅里叶分解，试图通过固定函数恢复相对距离。然而，由于编码直接与词向量做加法，展开注意力点积时会不可避免地产生词向量与位置编码之间的四项混合交叉污染项（Cross-terms）。
2. **可学习绝对位置嵌入（GPT-3 等）**：为序列中每个绝对索引位置初始化一个独立的可学习参数向量。这种方法不仅同样存在交叉项干扰，而且存在致命的外推硬上限——模型完全无法泛化推理超过训练阶段设定的最大序列长度。
3. **相对位置偏置（T5、Chinchilla、ALiBi 等）**：放弃在底层嵌入做文章，而是直接在计算完成的注意力分数矩阵上叠加一个与相对距离相关的偏置矩阵（Bias）。这种方案严格符合相对性原则，但在底层实现上无法分解为标准的内积形式，破坏了标准 GEMM 矩阵乘法，且给显存占用和推理阶段的 KV 缓存复用带来了沉重开销。

#### 二维旋转几何与内积相对性

旋转位置嵌入（Rotary Position Embedding, RoPE）彻底统一了这一领域。RoPE 最初由中国研究者苏剑林在个人技术博客（科学空间）中推导并在 RoFormer 论文中正式发布。这一设计随后被开源复现模型 GPT-J 敏锐采纳并大放异彩，最终随着 LLaMA 成为全球大模型基础设施的标准配置。

RoPE 的数学推导诉求极其纯粹：寻找一个作用于 Query 和 Key 向量的变换函数 $f(x, m)$，使得变换后的两个向量在绝对位置 $m$ 与 $n$ 处的内积，仅仅取决于词向量本身以及两者的相对位置差 $m - n$：

$$\langle f_q(x_m, m), f_k(x_n, n) \rangle = g(x_m, x_n, m - n)$$

为了满足这一严苛约束，RoPE 引入了高维几何中最为优雅的数学工具——正交旋转。

> **结论**：向量内积在刚性正交旋转变换下具有天然的不变性。如果我们在二维平面上将位置为 $m$ 的向量逆时针旋转 $m\theta$ 角度，将位置为 $n$ 的向量旋转 $n\theta$ 角度，则两者之间的夹角仅由相对旋转角差 $(m - n)\theta$ 决定。

```text
二维平面上的旋转位置示意:
               y 轴
               │
               │         /  x_n 旋转后 (位置 n, 角度 n·θ)
               │        /
               │       / 相对夹角差: (m - n)·θ
               │      / ───┐
               │     /     │
               │    /      ▼
               │   /       /  x_m 旋转后 (位置 m, 角度 m·θ)
               │  /       /
               │ /       /
               │/_______/_____________ x 轴
              (0, 0)
```
上图展示了 RoPE 在单个二维子空间内的几何原理：无论词元在序列整体中的绝对坐标平移到何处，两者旋转后的几何相对角度差始终保持为 $(m - n)\theta$。

在二维情况下，旋转操作由标准的二维旋转正交矩阵实现：

$$R_{\theta, m} = \begin{pmatrix} \cos(m\theta) & -\sin(m\theta) \\ \sin(m\theta) & \cos(m\theta) \end{pmatrix}$$

计算两个旋转后向量的内积：

$$\langle R_{\theta, m} x_m, R_{\theta, n} x_n \rangle = x_m^T R_{\theta, m}^T R_{\theta, n} x_n = x_m^T R_{\theta, n-m} x_n$$

绝对位置 $m$ 与 $n$ 在矩阵乘法中通过三角恒等变换完美对消，仅保留下相对位移 $n - m$。

#### 高维正交分解与多频旋转实现

高维欧几里得空间中的旋转流形极其复杂。RoPE 采用了一种极其直截了当且工程鲁棒的降维化归方案：将一个 $d$ 维的注意力头向量，两两配对切分成 $d/2$ 个独立的二维正交子空间。

在每个子空间中，分别施加不同基频的旋转矩阵：

$$R_{\Theta, m}^d = \begin{pmatrix} 
R_{\theta_1, m} & 0 & \dots & 0 \\
0 & R_{\theta_2, m} & \dots & 0 \\
\vdots & \vdots & \ddots & \vdots \\
0 & 0 & \dots & R_{\theta_{d/2}, m}
\end{pmatrix}$$

基频序列遵循指数衰减规则：

$$\theta_i = 10000^{-2(i-1)/d}, \quad i \in \{1, 2, \dots, d/2\}$$

这种多频设计蕴含着精妙的物理意义：
- **高频子空间**（$\theta$ 很大）：随着位置微幅前移，旋转角度剧烈翻转，这使得高频维度对极其临近的相对位移异常敏感，专注于编码局部语法依从与相邻词元搭配；
- **低频子空间**（$\theta$ 极小）：即便跨越数千个 Token，旋转角度也仅累积微小变化，这为长程上下文依赖提供了平滑的距离感知标尺。

在工程代码实现中，我们绝不需要实例化一个庞大的稀疏对角旋转矩阵去做矩阵乘法。由于该矩阵高度结构化，可以用广播逐元素相乘与交替符号翻转来实现：

$$R_{\Theta, m} x = x \odot \cos(m\Theta) + \tilde{x} \odot \sin(m\Theta)$$

其中 $\tilde{x} = (-x_2, x_1, -x_4, x_3, \dots, -x_d, x_{d-1})$。

> **易错点**：RoPE 仅作用于自注意力计算中的 Query 与 Key 向量，绝对不能施加在 Value 向量上。Value 向量负责传递未经旋转扭曲的语义内容本身；若对 Value 施加位置旋转，将破坏加权求和后的线性重构性质。

#### 前沿变体与设计边界

近期社区针对特定边缘场景提出了多种微调方案，例如仅旋转向量前部高频坐标的比例化 RoPE（Proportional RoPE, p-RoPE）。其设计初衷在于极低维度的微型边缘模型中，激活值显存受限严重，通过冻结低频坐标来节省计算与缓存开销。

但对于现代主流中大型语言模型而言，全维度的标准 RoPE 依然拥有绝对的统治地位。它不仅具备严密的相对位置内积可分解性，而且因为消除了传统加法位置编码的交叉项干扰，为后续扩展到数十万、上百万 Token 的超长上下文外推（如 YaRN、NTK-Aware 缩放）奠定了无与伦比的数学基础。

## 密集 Transformer 架构超参数权衡、训练稳定性与注意力演进
> 对应块：BLK23 | 覆盖分集：P21下 | 块标题（分集名）：《Lecture 3_ Architectures》

当我们真正坐下来动手配置一个大语言模型时，最先迎面扑来的往往不是那些玄妙的理论概念，而是一长串看似随意、实则暗藏玄机的超参数。你随便翻开几篇顶级大模型的技术报告就会发现一个有趣的现象：在绝大多数核心超参数的设定上，整个工业界展现出了惊人的一致性。大家嘴上可能很少讨论为什么非得这么设，但在实际工程代码里，几乎所有人都在默默遵守着同一套“不言自明”的经验法则。

这并不是因为我们已经从理论上严格证明了这些数值的最优性。相反，在超参数的高维空间里，几乎没有任何团队拥有足够的算力去跑穷尽式的网格搜索。我们现在所看到的这套架构基准，本质上是整个社区在数以万亿计的 Token 训练中试错沉淀出来的工程共识。在这些参数周围，往往存在着一个极其宽阔的性能“安全盆地”——只要你不踩进那些会导致数值爆炸或吞吐暴跌的极端禁区，模型对具体数值的微小漂移表现出了惊人的容忍度。

但与这种参数层面的宽容形成鲜明对照的，是现代大模型在训练稳定性与推理效率上的极端严苛。随着单次训练运行的成本飙升至数百万甚至上千万美元，任何一次中途不可逆的损失震荡或梯度崩溃，都意味着真金白银的彻底蒸发；而在部署阶段，自回归解码所遭遇的内存带宽墙，又逼迫我们必须重新审视注意力机制的物理实现。这一讲我们将系统拆解这些支配现代密集 Transformer 的底层法则：从宏观维度的权衡、预训练正则化的直觉颠覆，到数值稳定性的防御工事，再到受推理硬件重构的注意力演进路径。

### 宏观架构超参数与经验法则

在搭建模型的主干网络时，最先需要敲定的是几个控制网络几何形态的核心比例：前馈网络展开多大、注意力头怎么切分、模型应该做深还是做宽，以及分词词表容纳多少词元。这些参数共同构成了模型的静态骨架。


#### 前馈网络扩展比例与门控对齐

在前馈神经网络（Feed-Forward Network, FFN）或者通常所称的 MLP 模块中，第一个核心决策就是第一次矩阵乘法的输出维度（即中间隐藏层维度 $d_{\text{ff}}$）与模型主干维度 $d$ 之间的比例。这个比例本质上控制着参数在注意力与非线性变换之间的分配权重，直接决定了单个 MLP 层的特征丰富程度与表征容量。

对于最经典的非门控 MLP（如标准 Transformer 中的两层线性变换配合 ReLU 或 GELU），整个工业界存在一个出奇统一且好用的经验法则：中间维度应当设为模型隐藏维度的 4 倍，即 $d_{\text{ff}} = 4d$。这一比例在早期的大量受控实验中展现出了极高的鲁棒性。

然而，随着门控线性单元（Gated Linear Unit, GLU）及其变体（如 SwiGLU、GEGLU）在现代大模型中的普及，参数配比迎来了第一次关键修正。我们在前面讨论过，标准的 MLP 仅包含两个权重矩阵（上升投影 $W_1$ 与下降投影 $W_2$），其参数总量为：

$$P_{\text{standard}} = 2 \times d \times d_{\text{ff}}$$

而在 GLU 结构中，为了实现门控分支与特征分支的逐元素相乘，必须引入第三个矩阵（通常称为门控矩阵 $W_{\text{gate}}$）：

$$P_{\text{GLU}} = 3 \times d \times d_{\text{ff}}$$

如果我们希望在引入 GLU 结构的同时，严格保持 MLP 的参数总量和计算 FLOPs 与原先的 4 倍标准结构对齐，就必须对中间维度进行等比例压缩。两者的等量代换关系为：

$$3 \times d \times d_{\text{ff}}^{\text{GLU}} = 2 \times d \times (4d) \implies d_{\text{ff}}^{\text{GLU}} = \frac{8}{3}d \approx 2.67d$$

> **结论**：为了在参数量不变的前提下获得门控机制带来的表达增益，GLU 系列变体普遍应用了 $\frac{2}{3}$ 的维度修正因子。因此在现代采用 SwiGLU 的模型中，前馈层的扩展比例普遍收敛在 2.5 至 2.67 的窄区间内。

在这一基准之上，业界也衍生出了一些耐人寻味的变体。以 Llama 2 为例，其研发团队认为注意力部分引入了更为高效的共享机制，因此他们选择适度放大 MLP 的参数比重。他们在这个基准比例之上额外乘以了一个经验性的系数 1.33：

$$d_{\text{ff}}^{\text{Llama}} \approx \frac{8}{3}d \times 1.33 \approx 3.5d$$

这使得 Llama 系列的模型结构在权重分配上更明显地向 MLP 倾斜。如果你通读过去几年的主流论文，会发现一个清晰的分水岭：对于 GLU 架构，其前馈扩展系数要么落在 2.6 左右（严格参数对齐），要么落在 3.5 附近（强调 MLP 容量）；而对于非 GLU 模型，则几乎毫无例外地钉死在 4。

与大多数模型团队在架构选择上的高度保守不同，Google 在设计 T5 时做出过一次极其激进的探索。他们完全抛弃了 4 倍经验法则，直接将前馈扩展乘数推到了惊人的 64 倍以上。Google 团队当时给出了一个典型的系统工程论证：在底层硬件（尤其是 TPU/GPU）上，矩阵乘法的尺寸越大，计算核心的张量加速单元利用率（GEMM 吞吐）就越高。将单层的矩阵做得极其庞大，能够最大化硬件的硬件算术饱和度。虽然 T5 的初代版本确实证明了这种激进配置在数学上能够跑通，但实证研究很快揭示了其局限性。

在 Kaplan 等人 2020 年那篇开创性的神经缩放定律（Neural Scaling Laws）论文中，研究人员针对前馈扩展比例进行过严格的受控消融扫描。实验表明，损失函数与扩展倍数之间呈现出一个明显的“平坦盆地”（Basin）：从乘数 1 开始一直延伸到大约 10，模型的验证损失几乎没有显著变化，处于该区间内的任何数值距离绝对最优解的差距都微乎其微。但只要乘数进一步越过 10 向 100 攀升，损失曲线就会开始呈现二次方急剧恶化。

> **提示**：激进的超大前馈乘数虽然在系统底层提升了单次矩阵乘法的硬件吞吐，但在模型总计算量（FLOPs）的利用效率上却极度不划算。T5 演进史的一个画龙点睛之笔在于：在随后的改进版本 T5 v1.1 中，Google 最终放弃了 64 倍的超大矩阵，默默回归到了主流的 2.5 到 2.67 倍标准区间。这从反面印证了 4 倍及 $\frac{8}{3}$ 规则的高度稳健性。

#### 注意力头维度与隐藏层配比

另一个被全行业普遍接受但在直觉上略显武断的超参数，是多头自注意力（Multi-Head Attention, MHA）中的单头特征维度 $d_k$ 与头数 $h$ 的分配方案。

在数学定义上，我们完全可以随意独立调整单个注意力头的维度大小与模型总维度 $d$ 之间的比例。但在实际工程中，几乎所有现代架构都严格遵循如下守恒约束：

$$h \times d_k = d \implies d_k = \frac{d}{h}$$

也就是说，无论设置多少个并行注意力头，所有头的特征维度之和必须恰好等于模型的隐藏层总维度。

如果我们将所有头的投影拼接后的总维度与隐藏层维度之比定义为一个无量纲系数：

$$\rho_{\text{head}} = \frac{h \cdot d_k}{d}$$

审视当代几乎所有顶级模型，你会发现这个比值几乎全部严格恒定在 $\rho_{\text{head}} \approx 1$。除了早期 Google 的个别探索模型（如 T5 和 UL2 曾允许头维度与总维度解耦）之外，绝大部分团队都将其作为不可逾越的默认前提。

针对该比例的大量消融实验再次表明，这也是一个容错率极高的超参数。在 1 附近同样存在着相当宽裕的缓冲区间，只要单头维度 $d_k$ 落在对硬件计算友好的尺寸上（例如现代 GPU 深度优化的 64 或 128），微小的配比变化对下游表征能力的影响完全可以忽略不计。

#### 纵横比与硬件并行化权衡

如果说前馈比例和头维度还只是局部的尺寸分配，那么模型深度（网络层数 $L$）与模型宽度（隐藏层维度 $d$）之间的权衡，就是直接决定模型整体轮廓的宏观命题。在模型扩展理论中，这一比值被称为纵横比（Aspect Ratio）：

$$r_{\text{aspect}} = \frac{d}{L}$$

当你决定将一个模型从 7B 扩充到 70B 时，究竟是应该堆叠更多的层数，还是应该把每一层拉得更宽？在早期的理论探讨中，人们曾设想过各种极端的构型，但一旦将目光投向现役的所有顶级大模型（如 GPT-3、Llama 家族、Qwen 等），就会发现一个清晰的收敛区间：现代大模型的隐藏层维度与层数之比，几乎无一例外地落在大约 100 附近（$d / L \approx 100$）。例如一个 40 层的模型，其宽度通常会设定在 4096 左右。

这种几何收敛背后的根本驱动力，是**模型理论表达能力**与**底层硬件分布式并行特性**之间的一场深度博弈：

- **深度方向的并行阻碍**：从理论表征视角来看，增加网络深度往往能带来更强的层次化特征抽取能力。但从系统工程来看，网络过深是分布式系统工程师的噩梦。当单张 GPU 显存无法容纳整个模型时，深度方向的切分只能依赖流水线并行（Pipeline Parallelism, PP）。流水线并行本质上是将不同层分配给不同设备串行流水执行，这不仅引入了极其复杂的跨节点激活值通信，更致命的是会在流水线填充和排空阶段造成大量 GPU 算力空转（即所谓的流水线气泡 Bubble）。这是超大规模训练中所有人都在极力规避的损耗。
- **宽度方向的硬件亲和**：相比之下，在宽度方向上进行横向切分则要成熟和高效得多。利用张量并行（Tensor Parallelism, TP），我们可以在单层内部直接将矩阵乘法切分到多个 GPU 上并行计算，最后通过一次高速的 All-Reduce 聚合。只要节点内部配备了 NVLink 等高带宽互联互通机制，张量并行的拓展效率极高，且完全不存在时间线上的气泡停顿。

系统层面的现实约束促使我们倾向于更宽的架构，而表征层面的非线性需求又要求网络必须保持足够的深度。两者拉锯妥协的结果，最终稳定在了 100 这一基准线上。

> **结论**：Levine 等人针对架构变体展开的大规模实验进一步表明，在固定的总计算量（FLOPs）预算下，无论你如何在合理范围内微调深度与宽度的具体配比，主导最终模型能力的核心决定性变量始终是总 FLOPs 本身。在 $d/L \approx 100$ 的安全区内，架构设计的第一准则应当是服务于硬件的系统吞吐与并行效率，而非纠结于那些难以量化的表达能力假说。

#### 词表规模演进与分词度量对偶

在宏观参数列表中，词汇表大小（Vocabulary Size, $V$）在过去几年中经历了一次跨越式的结构重塑。

在开源模型的早期探索阶段，大部分模型（如早期 LLaMA 1）本质上都是以英语为绝对核心的单语系统。对于单一语言而言，由于字符组合与常用词汇形态相对有限，一个约 32,000（32k）大小的词表就足以实现极高的新词覆盖率与极低的切分碎片率。

然而随着多语言处理能力的刚性需求以及以 GPT-4 为代表的现代生产级系统出现，词表大小迅速扩容到了 100k 至 200k（10 万至 20 万词元）的量级。例如 Google 的各类模型普遍采用了极大尺寸的词表，而 Llama 3 及后续开源衍生架构也纷纷将词表基准拔高到了 128k 左右。这一演进主要受到两大因素驱动：

- **语言空间覆盖**：在多语言混合场景下，较小的词表会导致非英语语种被粉碎成大量极短的字节碎片，不仅严重拉长了推理序列长度，而且加剧了注意力二次方开销。大词表能为非主流语言和代码保留更完整的高阶词元，显著压缩序列物理长度。
- **参数规模的 Scaling 规律**：现代缩放定律研究表明，随着模型总参数量和训练 Token 量的成倍扩张，模型拥有足够的容量去学习和区分更大维度的嵌入矩阵。大词表在总参数量中的占比被稀释，不会再像小模型时代那样造成参数浪费。

在多模态扩展场景中，这一趋势更为激进。若要直接利用离散 Tokenizer 对连续图像特征进行量化分词，图像空间所需要的状态覆盖面远非文本可比，通常需要挂载独立且词表更为庞大的专用视觉分词器。

```text

│ 分词方案 A (细粒度 32k 词表):                                           │
│ 切分为 3 个 Token: ["Trans", "form", "er"]                              │
│ 计算 Cross-Entropy: 累加 3 个 Token 损失 ──► 困惑度 PPL_A 受 N=3 归一化  │
```

上图揭示了不同分词器之间困惑度（Perplexity）不可比的本质：细粒度与粗粒度分词产生的 Token 数量完全不同，导致其对数似然的平均分母存在固有偏差；只有回归到底层固定的字节总数归一化（BPB），才能建立绝对客观的评估桥梁。

这里引出了一个在模型对比评估中极其经典的技术问题：当我们更换了一个分词器，模型的困惑度（Perplexity, PPL）发生了变化，这种比较究竟是否有效？

语言建模本质上是在对一个固定符号序列的联合概率分布进行生成式建模。如果两个分词器产生的 Token 序列长度完全不同，传统的“每个 Token 的平均交叉熵损失”（即困惑度）就会彻底失去对比基准——粗粒度分词器虽然单个 Token 的预测难度变大，但其总 Token 数显著变少，直接拿两者的困惑度数值对比无异于比较苹果和橘子。

> **定义**：每字节比特数（Bits Per Byte, BPB）是指语言模型在预测测试集文本时，平均压缩每个原始字符字节所需的二进制信息量（比特）。其计算公式为：
> $$\text{BPB} = \frac{\mathcal{L}_{\text{total}}}{N_{\text{bytes}} \cdot \ln 2}$$
> 其中 $\mathcal{L}_{\text{total}}$ 是模型在整个文本上产生的总负对数似然（以自然常数 $e$ 为底），$N_{\text{bytes}}$ 是该文本未经切分时的 UTF-8 原始总字节数。

只要测试文本是固定且完整的（现代现代子词分词器均能无损编码任意字节流，不丢弃信息），无论底层模型采用 32k 还是 128k 词表，以字节总数 $N_{\text{bytes}}$ 作为统一归一化常数的 BPB 比较永远是绝对有效且对齐的。困惑度与每字节比特数互为对偶表征，在评估不同分词方案的真实建模能力时，必须统一换算为 BPB 才有衡量价值。

### 预训练正则化假象与优化器动力学

在传统的统计机器学习乃至经典的计算机视觉深度学习训练中，正则化（Regularization）永远处于核心地位：为了防止参数过拟合于训练集，我们通常需要设计繁复的 Dropout、数据增强或早停策略。但在大语言模型的无监督预训练中，这一套底层直觉遭遇了剧烈颠覆。

#### 单遍遍历与计算受限下的无过拟合现象

当我们启动一个超大规模基础模型的预训练时，手头拥有的语料库（涵盖整个互联网抓取的文本、代码、图书等）动辄达到数万亿甚至数十万亿 Token。在极其有限的物理算力预算和时间成本约束下，整个预训练周期通常只能够支撑对全部语料库进行**单次遍历（Single-Pass / Single-Epoch）**。

在单遍随机梯度下降（SGD / AdamW）的过程中，模型在整个生命周期中几乎永远不会两次看到同一条完全相同的训练样本。

```text

验证损失 (Validation Loss)
   ▲

   │                             /
   │                            /
   │                           /
   │                          /  单遍 SGD 轨迹 (严格落在 x = y 直线上)
   │                         /
   │                        /
   │                       /
   │                      /
   │                     /
   │                    /
   │                   /

```
上图展示了在单遍遍历预训练中，模型的验证损失与训练损失高度重合于 $y=x$ 对角线上：因为模型从未见过重复数据，且优化器在海量数据流中不具备深度记忆能力，过拟合缺口（Generalization Gap）在预训练阶段根本不存在。

严谨的理论与实证分析均表明：在海量未重复的数据流上，单次遍历的自适应优化器根本不可能发生传统意义上的“过度记忆”或“拟合噪声”。在计算受限的预训练场景中，过拟合几乎从来不是一个需要被严肃对待的工程障碍。实际上，许多顶级训练团队在监控训练大盘时甚至只关注训练损失的下降趋势，因为在单遍扫描下，验证损失与训练损失几乎总是完全重合于 $y = x$ 的直线上。

#### 权重衰减的优化器协同机理

在这一事实背景下，我们可以顺理成章地提出一个疑问：在既然预训练阶段根本不会过拟合，我们是否应该彻底放弃所有的正则化手段？

现实的工业界实践再次给出了反直觉的答案：

- **Dropout 的全面退场**：在现代主流大模型的预训练报告中，Dropout 机制几乎已被全线废弃。正如大家在实际消融中所见，Dropout 的随机屏蔽操作会极其严重地破坏梯度的平滑性，与 AdamW 等自适应优化器的动量累积机制严重冲突，直接拉低优化效率。
- **权重衰减的坚定保留**：令人惊讶的是，几乎所有顶级模型（包括各类高水平开源及闭源模型）在训练配置中都极其坚定地保留了较高强度的权重衰减（Weight Decay）。

既然不存在过拟合，保留权重衰减的意义何在？

多项严谨的优化机理研究揭示了一个关键技术事实：在现代大模型预训练中，**权重衰减的本质并不是正则化工具，而是一种直接参与塑造优化器动力学的几何调节手段**。

如果在单遍训练中仅仅对比不同权重衰减强度下的泛化缺口，你会发现它们对验证损失与训练损失的相对差异毫无影响（两者均落在对角线上）。但当我们考察权重衰减与**学习率衰减调度（Learning Rate Schedule）**的协同效应时，真正的魔力才显现出来。

```text
权重衰减与学习率退火协同作用下的收敛曲线:
损失 (Loss)
   ▲
   │  无权重衰减 (或弱衰减) ── 起步快，但后期收敛平台较高
   │  ───────────────────────────────┐
   │                                 └─────────────────────
   │
   │  高强度权重衰减 ────────── 起步稍慢，但随退火收敛至极低损失
   │  - - - - - - - - - - - - - - - - - - ┐
   │                                      └- - - - - - - - - - ● (更优最优点)
   └─────────────────────────────────────────────────────────────► 训练步数 (Steps)
```
上图展示了权重衰减与学习率退火协同工作时的训练轨迹差异：虽然高强度权重衰减在初期由于向零收缩的约束导致损失下降略慢，但在配合学习率退火进入训练末期时，能够引导优化器收敛到平坦且深度更优的极小值区域。

当模型在训练后程逐步降低学习率时，高强度的权重衰减持续对参数施加向坐标原点的向心收缩力。这种收缩效应抑制了权重模长的无节制膨胀，等效于维持了网络内部各层的有效学习率（Effective Learning Rate），使得优化器能够以更加稳定和充沛的动量逃离尖锐的局部极小值，最终收敛至泛化表现更佳的平坦盆地。

> **易错点**：绝不能将权重衰减简单等同于防止过拟合的 $L_2$ 惩罚项。在固定学习率下，它的收益往往并不明显；只有当它与动态学习率调度策略协同推进时，其优化器加速与稳定收敛的特性才能被彻底释放。这也是许多模型在训练中唯一被允许与学习率进行动态联动调整的超参数。

### 训练稳定性干预与数值爆炸防御

在当代千亿参数大语言模型的工程现实中，最具灾难性的风险绝不是最终的模型困惑度比预期高了 0.1，而是在耗资数百万美元的训练运行推进到第 70% 时，监控大盘突然出现无法自愈的梯度爆炸与损失尖峰（Spikes）。一旦模型权重被无效的极端梯度污染，往往直接导致整个训练进程彻底发散瘫痪。

因此，现代架构演进的重心已经从“追求微弱的理论表达能力上限”全面转向了“构建极其坚固的训练数值稳定性防御机制”。而在整个 Transformer 网络中，不稳定性的最大温床正是**全连接层末端**与**注意力核心**这两处关键的 Softmax 运算。

Softmax 算子天然具备两大对数值极不友好的数学特性：
1. **指数运算的激进放大**：$e^x$ 面对微小的输入偏离就会迅速走向数值溢出（Overflow）；
2. **除法归一化的极端敏感**：分母累加和一旦逼近极小值，极易引发浮点数下溢（Underflow）或除以零崩溃。

针对这两处危险地带，工业界发展出了三项极具代表性的稳定性防御措施。

```text
Transformer 训练稳定性三大防御干预布局:
                             输入残差流
                                 │
                 ┌───────────────┴───────────────┐
                 ▼                               ▼
       [ 稳定性干预 2: QK-Norm ]        [ 稳定性干预 3: Logit Soft-Capping ]
       Q ──► [ RMSNorm ] ──┐            (可选替代表现截断方案)
                           ├──► (Q K^T / sqrt(d)) ──► [ C * tanh(x / C) ]
       K ──► [ RMSNorm ] ──┘                                 │
                 │                                           ▼
                 └───────────────────────────────► [ Softmax 归一化 ]
                                                             │
                                                             ▼
                                                    [ 输出残差流 ]
                                                             │
                                                             ▼
                                                    [ 线性输出头 Logits u ]
                                                             │
                                                             ▼
                                                [ 稳定性干预 1: Z-loss ]
                                                惩罚项: α * (log Z)^2
```
上图系统标定了现代架构针对数值不稳定性的三大核心防御布局：输出层通过 Z-loss 约束配分函数偏移，自注意力内部通过 QK-Norm 将点积前特征模长恒定在标准尺度，或通过 Logit Soft-Capping 施加严格的有界软截断。

#### 输出层配分函数发散与 Z-loss 正则化

我们首先剖析模型输出端的预测概率计算。在生成下一个 Token 时，语言模型将顶层残差流的输出向量投影为词表维度的无界得分（Logits）向量 $u \in \mathbb{R}^V$。第 $i$ 个词元的预测概率通过 Softmax 给出：

$$p_i = \frac{\exp(u_i)}{\sum_{j=1}^V \exp(u_j)} = \frac{\exp(u_i)}{Z}$$

其中 $Z = \sum_{j=1}^V \exp(u_j)$ 被称为配分函数（Partition Function）。在训练计算交叉熵损失时，我们关注的是其对数概率：

$$\log p_i = u_i - \log Z$$

在这里，第一项 $u_i$ 本身是由残差流直接线性变换而来的激活值，只要网络主干运行稳定，$u_i$ 的尺度通常表现良好。但第二项 $\log Z$ 却极其脆弱：如果输出层 Logits 整体漂移偏大，经过指数累加后 $Z$ 会迅速发散；而如果 Logits 普遍偏小，导致 $Z$ 趋近于 0，$\log Z$ 又会走向负无穷大。这两种极端浮点数波动都会直接摧毁梯度的反向传播。

为了控制这种发散，我们利用 Softmax 的**平移不变性（Shift Invariance）**：对于任意标量常数 $c$，如果给所有 Logits 同时加上 $c$，Softmax 的输出概率保持不变：

$$\frac{\exp(u_i + c)}{\sum_{j=1}^V \exp(u_j + c)} = \frac{\exp(u_i) \cdot e^c}{\sum_{j=1}^V \exp(u_j) \cdot e^c} = \frac{\exp(u_i)}{Z}$$

但此时新的配分函数变为 $Z' = Z \cdot e^c$。这意味着 Softmax 表达式本身是过参数化的，我们完全可以在不改变概率分布形态的前提下，将 $Z$ 约束在数值最安全的平衡点附近——即让 $Z \approx 1$，从而促使 $\log Z \approx 0$。

基于这一洞察，Jacob Devlin 等人在 2014 年的一项研究中率先提出了一种极其精巧的辅助正则化项：**Z-loss**。我们在模型的主交叉熵损失 $\mathcal{L}_{\text{CE}}$ 之外，直接追加一项对 $\log Z$ 偏离零的二次惩罚：

$$\mathcal{L}_{\text{total}} = \mathcal{L}_{\text{CE}} + \alpha \cdot (\log Z)^2$$

其中 $\alpha$ 是一个极小的调节超参数（通常设为 $10^{-4}$ 左右）。

> **定义**：Z-loss 正则化是指在语言模型训练损失中显式引入配分函数对数平方项 $\alpha (\log Z)^2$，迫使输出层 Softmax 的归一化常数维持在 1 附近，从根本上杜绝由于 Logits 尺度漂移引起的数值下溢与溢出发散。

这一技术随后在 Google 的 PaLM 模型中被重新引入并大放异彩，证明了其在稳定数百亿乃至数千亿参数规模训练时的强大工程威力。如今，包括 DCLM、OLMo 等众多现代高水准开源基础模型，均将 Z-loss 视为保障输出层数值绝对安全的标配防火墙。

#### 注意力内部尺度漂移与 QK-Norm

解决了输出端之后，我们转向另一个更容易滋生退化现象的核心阵地：注意力机制内部的归一化。

在标准的多头自注意力机制中，输入特征经过 Pre-LayerNorm 之后，通过线性投影生成 Query 矩阵 $Q$ 与 Key 矩阵 $K$。这两个张量直接相乘并除以缩放因子 $\sqrt{d_k}$，随后送入 Softmax：

$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{Q K^T}{\sqrt{d_k}}\right) V$$

在深层网络中，虽然单层输入端存在 Pre-Norm，但随着层数加深，投影矩阵 $W_Q$ 与 $W_K$ 的参数范数依然可能会在长期训练中发生隐蔽的无界漂移。一旦未受直接约束的 $Q$ 和 $K$ 向量范数变得极大，其内积点积值除以 $\sqrt{d_k}$ 之后依然会远超常规尺度。

这会导致进入 Softmax 的分数差异被极度拉大，Softmax 输出急剧退化为一个接近独热编码（One-Hot）的极端尖锐分布。这种现象被称为**注意力退化（Attention Collapse）**。此时几乎所有的注意力权重都被极少数甚至单一位置独占，而其余位置的局部梯度直接归零，伴随而来的往往是突如其来的严重梯度尖峰。

面对这种内部失控，现代大模型工程的一条核心原则被再次唤醒：**如果系统的某处内部出现不稳定性，最直接有效的办法就是就地引入一个 Normalization 算子将其框住。**

这就是 **QK-Norm** 的核心思想。它的实现异常简洁且优雅：在计算 Query 与 Key 的点积之前，我们直接在每个注意力头内部，对 $Q$ 和 $K$ 向量各自单独施加一次无偏置的归一化算子（通常选用计算高效的 RMSNorm）：

$$\tilde{Q} = \text{RMSNorm}(Q), \quad \tilde{K} = \text{RMSNorm}(K)$$

$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{\tilde{Q} \tilde{K}^T}{\sqrt{d_k}}\right) V$$

这一操作使得送入内积运算的每个特征向量都被强制约束在严格恒定的单位模长尺度附近，送入 Softmax 的点积值被天然限制在一个完全可控的数值包络线内。

```text
从 Pre-Norm 到 QK-Norm 的归一化演进轨迹:
阶段 1 (早期): 仅在主干残差流前端设置 Pre-Norm
[ x ] ──► [ LayerNorm ] ──► [ Attention / FFN 分支 ] ──► (+) ──► 残差主干

阶段 2 (过渡期): 模块计算分支内部增设激活后 Norm
[ x ] ──► [ LayerNorm ] ──► [ 线性投影 ] ──► [ 激活函数 ] ──► [ LayerNorm ] ──► 输出

阶段 3 (现代标配): 深入注意力子构件内部施行 QK-Norm
Query ──► [ 线性投影 ] ──► [ RMSNorm ] ──┐
                                         ├──► [ Q K^T 点积 ] ──► 锁定数值尺度
Key   ──► [ 线性投影 ] ──► [ RMSNorm ] ──┘
```
上图展示了归一化算子在网络架构内部的纵深渗透历程：从最初仅仅驻守在主干残差流的门禁，到逐步渗透至分支非线性激活之后，最终直接前移并锁定在注意力点积的核心输入源头。

> **结论**：QK-Norm 最早诞生于多模态大模型领域。在 Idefics、Chameleon 等多模态系统的训练中，由于图像与文本模态表征尺度的巨大悬殊，注意力极易发生崩溃，研究人员率先验证了 QK-Norm 的卓越稳定效能。随后纯文本开源语言模型迅速跟进。实证表明，QK-Norm 几乎完全不损害下游基准表现，却能够彻底杜绝深层注意力的数值脱缰，甚至允许我们适度提高优化器的学习率以加速训练。它已毫无争议地成为现代大型密集语言模型的标准构件。

#### 极端极值截断与 Logit Soft-Capping

与 QK-Norm 通过规范输入特征模长来间接保护 Softmax 不同，Google 在其 Gemma 系列（包括 Gemma 2、Gemma 3 等）中主推了一种更为强硬的直接干预手段：**Logit Soft-Capping（对数得分软截断）**。

其设计逻辑非常直白：既然担心送入 Softmax 的得分过大，那就在数据进入 Softmax 的那一刻，强行对原始未归一化的得分布局进行非线性物理截断。具体而言，利用有界的双曲正切函数（$\tanh$）将所有超出预设阈值的极值平滑压缩回安全区间内：

$$\text{logits}_{\text{capped}} = C \cdot \tanh\left(\frac{\text{logits}}{C}\right)$$

其中 $C$ 是预先固定的硬截断上限（在 Gemma 的注意力层中通常设为 $C = 50$ 或 $C = 30$）。由于 $\tanh(x) \in (-1, 1)$，经过该公式变换后，所有的 Logits 被严格锁死在 $(-C, C)$ 的闭区间内，在数学上彻底切断了输入值发散的物理可能性。

这种粗暴但直接的干预措施究竟带来了怎样的得失？NVIDIA 的研究人员曾针对各类稳定性干预措施展开过详尽的横向受控消融对比，得出了一组极具启发性的结论：

| 稳定性干预技术 | 对抗数值爆炸能力 | 对下游模型表现影响 | 核心优势与主要缺陷 |
| :--- | :--- | :--- | :--- |
| **无干预基线** | 极弱（易突发梯度尖峰崩溃） | 基准表现 | 存在极高的不可自愈训练崩溃隐患 |
| **QK-Norm** | 极强（从源头规范向量尺度） | 无损甚至略有提升 | 彻底平抑点积漂移，允许调高学习率 |
| **Logit Soft-Capping** | 绝对安全（强制硬边界截断） | 轻度负面影响（质量微幅下降） | 截断极值阻碍了高置信信号表达，属于防御性妥协 |

> **提示**：Logit Soft-Capping 虽然提供了一条绝对牢固的数值安全网，但其代价也是显而易见的。当模型本应在某些上下文下以极高的确定性输出置信预测时，$\tanh$ 强行压平了高得分区域的梯度响应，压制了模型表达极端确定性概率分布的能力，最终在部分下游基准上造成了一定程度的指标劣化。因此，行业内绝大多数开源模型依然将 QK-Norm 作为首选，仅将 Soft-Capping 视作特定场景下的保守补充方案。

### 推理瓶颈驱动的注意力架构演进

在完成模型的训练之后，我们的战场瞬间转移到了生产部署环境。在大模型落地的真实业务场景中，每一次用户交互都在产生真金白银的推理成本。此时驱动架构演变的核心矛盾，不再是训练稳定性，而是**底层硬件物理带宽对自回归解码过程的严酷制约**。

#### 自回归解码内存瓶颈与 KV Cache 算术强度

为了理解为什么现代注意力架构会发生剧变，我们必须从计算机体系结构的底层切入，审视模型在运行期间所面对的两种核心资源开销：
1. **计算量（FLOPs）**：浮点运算次数，由 GPU 内部成千上万个 Tensor Core 负责消化；
2. **内存访问量（Memory Access Bytes）**：在显存（HBM）与片上高速缓存（SRAM/寄存器）之间搬运数据（权重、激活值、KV 缓存）所消耗的带宽与时间。

这两者的比值被定义为**算术强度（Arithmetic Intensity）**，即 $\frac{\text{FLOPs}}{\text{Byte}}$。硬件能够跑满理论计算吞吐的前提，是当前任务具备足够高的算术强度。

在模型的**预填充阶段（Prefill / Prompt Processing）**，用户的输入 Prompt 被作为一个整体打包输入。此时模型可以像训练时一样在整个序列长度上进行高度并行的矩阵乘法。由于输入是完整的二维矩阵（批次大小 $B \times$ 序列长度 $S$），单次显存读取权重能够被多次并发复用，算术强度极高，GPU 能够轻而易举地跑满其张量计算单元。

```text
自回归解码阶段逐 Token 迭代下的显存墙:
当前正在生成 Token t:
┌────────────────────────────────────────────────────────────────────────┐
│ 高带宽显存 (HBM)                                                       │
│ ┌──────────────────────┐   ┌─────────────────────────────────────────┐ │
│ │ 全部模型权重矩阵 W    │   │ 历史积累的庞大 KV Cache (t-1 个 Token)  │ │
│ └──────────┬───────────┘   └────────────────────┬────────────────────┘ │
└────────────┼────────────────────────────────────┼──────────────────────┘
             │ (每次生成 1 个 Token)              │ (必须全量加载回片上)
             │ 必须将数十 GB 权重全量搬运一次       │ 显存搬运量随上下文持续膨胀
             ▼                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│ GPU 片上核心 (SRAM / Tensor Core)                                      │
│ 仅对当前单一 Query 向量进行轻量级计算 (计算量微不足道，计算单元大部分时间空转等待数据) │
└────────────────────────────────────────────────────────────────────────┘
结论: 解码吞吐完全被显存带宽锁死 (Memory-Bound)，算术强度暴跌！
```
上图描绘了自回归生成阶段极其恶劣的“显存墙”瓶颈：为了计算当前唯一的新 Token，GPU 被迫在每个时间步将全量权重与持续扩张的庞大 KV Cache 从高带宽显存中完整搬运一遍，导致硬件算力被严重闲置。

然而，一旦进入**自回归解码生成阶段（Decoding）**，局面彻底恶化。由于因果语言建模的固有依赖链，我们必须先生成当前位置的 Token，才能将其作为输入去预测下一个 Token，这一过程只能逐步串行推进。

为了避免每个时间步重复计算前面所有历史 Token 的 Query 与 Key 投影，标准实践必须引入 **KV Cache（键值缓存）**机制：将历史所有 Token 对应的 Key 向量与 Value 向量缓存在 GPU 显存中。在生成第 $t$ 个 Token 时，我们只需计算当前单个 Token 的 Query，并将其与显存中历史所有的 Key 进行点积，再对历史所有的 Value 进行加权求和，最后将当前计算出的这一个新 Key 和 Value 追加进缓存中。

KV Cache 虽然彻底消除了历史上千次重复矩阵乘法的计算量，但在自回归解码中，总内存访问模式发生了根本性扭曲。在每一个解码步中：
- 矩阵乘法的输入退化为单行向量（批次大小 $B \times 1$）；
- 为了完成这微不足道的向量乘法，GPU 必须在每一个生成步，把整个模型数十 GB 的权重参数从 HBM 完整加载进片上 SRAM 一次；
- 更致命的是，GPU 还必须将当前序列之前积累的全部庞大 KV Cache 也从 HBM 完整读取一遍。

在自回归解码阶段，系统的算术强度急剧暴跌。其算术强度大致正比于：

$$\text{Arithmetic Intensity}_{\text{decode}} \propto \frac{1}{\frac{N}{d} + \frac{1}{B}}$$

其中 $N$ 是当前上下文长度，$d$ 是隐藏维度，$B$ 是批次大小。对于长序列或者由于显存受限而无法组建大批次（Small Batch）的场景，第一项 $\frac{N}{d}$ 会迅速占据主导。GPU 内部强悍的计算核心在 90% 以上的时间里都在无聊地等待数据从显存搬运过来，整个系统被无情地锁死在**内存带宽瓶颈（Memory-Bound）**中。

#### 从多查询注意力到分组查询注意力

既然显存带宽成为了决定推理延迟与服务并发吞吐的命门，降低需要在 HBM 中读写的 KV 数据体积就成为了全行业压倒一切的诉求。

在标准的多头注意力（MHA）中，如果有 $h$ 个注意力头，每个头都拥有完全独立的一组 Key 矩阵和 Value 矩阵。这意味着在显存中必须维护 $h$ 份完整的 KV Cache。

Noam Shazeer 率先打破了这一设计定式，提出了**多查询注意力（Multi-Query Attention, MQA）**。MQA 做出了最激进的精简：保留所有 $h$ 个独立的 Query 头，但让所有这些头在内部**完全共享单一的一组 Key 和 Value 向量**。

```text
MHA、GQA 与 MQA 头结构与 KV Cache 显存占用对比:
(以 8 个 Query 头为例)

多头注意力 (MHA, 传统标准):
Q:  [Q0] [Q1] [Q2] [Q3] [Q4] [Q5] [Q6] [Q7]  ──► 8 组独立 Query
K:  [K0] [K1] [K2] [K3] [K4] [K5] [K6] [K7]  ──► 8 组独立 Key Cache   (显存占用: 100%)
V:  [V0] [V1] [V2] [V3] [V4] [V5] [V6] [V7]  ──► 8 组独立 Value Cache

分组查询注意力 (GQA, 现代最优折中):
Q:  [Q0  Q1]  [Q2  Q3]  [Q4  Q5]  [Q6  Q7]  ──► 8 组 Query，分为 4 组
K:    [K0]      [K1]      [K2]      [K3]    ──► 仅 4 组共享 Key Cache (显存占用: 50% 或更低)
V:    [V0]      [V1]      [V2]      [V3]    ──► 仅 4 组共享 Value Cache

多查询注意力 (MQA, 极端精简):
Q:  [Q0] [Q1] [Q2] [Q3] [Q4] [Q5] [Q6] [Q7]  ──► 8 组独立 Query
K:  [                   K0                 ]  ──► 全局仅 1 组 Key Cache   (显存占用: 12.5%)
V:  [                   V0                 ]  ──► 全局仅 1 组 Value Cache
```
上图直观展示了三种注意力范式在 Key 与 Value 头复用上的拓扑差异：MHA 各自独立，MQA 全局单头，而 GQA 在两者之间构建起弹性的分组共享通道。

MQA 带来的系统红利是极其震撼的：KV Cache 的物理显存占用瞬间被压缩到了原本的 $\frac{1}{h}$（在典型 32 头模型中直接暴降 96% 以上），每次解码读取显存的压力被大幅击穿，算术强度成倍飙升。但这一激进剪裁的代价同样惨重：强迫所有头共用同一套 Key/Value，极大地削弱了模型在捕捉多种不同子空间关联时的表达容量，下游学术与逻辑基准出现了肉眼可见的明显下滑。

为了在“极高系统效率”与“强大学术表达力”之间找到完美的黄金分割点，**分组查询注意力（Grouped-Query Attention, GQA）**应运而生。

GQA 引入了一个灵活的分组机制：我们将总计 $h$ 个 Query 头均匀划分为 $G$ 个组，在组内共享同一份 Key 和 Value 头，使得总的 KV 头数减少为 $G$（其中 $1 < G < h$）。
- 当 $G = h$ 时，退化为传统的 MHA；
- 当 $G = 1$ 时，演化为极端的 MQA；
- 典型配置通常选用 8:1 或 4:1 的比例（例如 32 个 Query 头配置 8 个或 4 个 KV 头）。

```text
MHA、MQA 与 GQA 下游精度与推理耗时 Pareto 前沿:
下游任务表现 (Downstream Performance)
   ▲
   │            GQA (帕累托最优解: 耗时接近 MQA, 表现近乎持平 MHA)
   │               ●
   │              / \
   │  MHA ●──────/   \
   │      │           \
   │      │            \
   │      │             \
   │      │              ● MQA (推理极快，但表现严重受损)
   │      │
   │      ▼
   │  缩小模型规模折中线 (精度大幅崩塌)
   └─────────────────────────────────────────────────────────────► 单样本推理延迟 (Latency)
   0 (理想原点)
```
上图揭示了 GQA 确立行业统治地位的核心 Pareto 收益曲线：通过小幅削减冗余的 KV 头数，GQA 以接近 MQA 的极限推理延迟保留住了 MHA 绝大部分的下游性能，击败了传统的缩放折中方案。

> **结论**：实证评估表明，注意力头中的 Key 和 Value 存在着大量的跨头冗余。GQA 展现出了一条极其优越的 Pareto 前沿——仅仅保留少数几个（如 8 个）KV 组，就足以维系 MHA 近乎 100% 的下游建模精度，同时却将推理阶段的 KV Cache 显存开销与带宽争抢削减了 75% 至 87.5% 以上。这使得现代模型（如 Llama 2/3、Mistral、Qwen 等）几乎全线将 GQA 作为标准底层架构。

在更前沿的探索中，DeepSeek-V2 等模型进一步推出了**多头潜在注意力（Multi-Head Latent Attention, MLA）**。MLA 跳出了单纯的离散头聚合逻辑，通过低秩投影矩阵将 Key 与 Value 在显存中压缩为一个低维的隐空间潜在向量（Latent Vector），并在计算时动态解压。这为突破 KV Cache 显存墙提供了又一条极具启发性的技术路线。

#### 超长上下文下的局部与全局混合架构

伴随着现代大模型向 32k、128k 乃至 100 万 Token 上下文窗口推进，密集全注意力机制那令人绝望的二次方计算复杂度（$\mathcal{O}(S^2)$）与显存占用，再次演变为不可承受之重。即使配备了 GQA，当序列长度膨胀上百倍时，KV Cache 的总体积依然会撑爆集群显存。

为此，业界的演进主线开始将目光投向了**局部稀疏与全局注意力的交替混合范式**。而其中最成熟、落地最广泛的构件，正是**滑动窗口注意力（Sliding Window Attention, SWA）**。

SWA 并不是一个全新的概念，早在 GPT-3 的前身工作中，研究人员就曾探索过带状局部注意力矩阵。但在过去一年里，开源社区在如何将全局注意力与局部滑动窗口深度杂交上，形成了一套极其成熟的工业套路：

```text
局部滑动窗口与全注意力层间交替堆叠结构 (以 Cohere Command A 范式为例):
层级 L (顶层)    [ 全局自注意力 Full Attention ] ──► 具备整个上下文视野，融合长程线索
                    ▲
层级 L-1        [ 滑动窗口注意力 SWA (窗口 W) ] ──► 仅看局部 W 个 Token，极低显存与计算
                    ▲
层级 L-2        [ 滑动窗口注意力 SWA (窗口 W) ] ──► 仅看局部 W 个 Token，信息沿深度上浮
                    ▲
层级 L-3        [ 滑动窗口注意力 SWA (窗口 W) ] ──► 仅看局部 W 个 Token
                    ▲
层级 L-4 (底层)  [ 全局自注意力 Full Attention ] ──► 阶段性注入全局交互锚点
```
上图展现了现代超长上下文模型普遍采用的交替堆叠拓扑：大部分层采用受限窗口的低廉 SWA，每隔固定层数（如 4 层）插入一层全局 Full Attention，局部信息在逐层前传过程中自然实现跨窗口语义聚合。

以 Cohere Command A 以及近期诸多主流长文本模型为例，其典型的网络宏观拓扑为：**在每 4 个连续层中，前 3 层采用廉价的滑动窗口注意力（每个 Token 仅能关注局部窗口内的相邻 Token），而第 4 层则挂载全尺寸的 Full Attention**。

这种混合设计之所以能够在大幅降本的同时维持出色的长文本召回能力，其核心机理在于深层网络的感受野扩展：
- 浅层的滑动窗口虽然在单层内只能观察局部结构，但信息随着残差流逐层向上传播时，高层的局部神经元实际上已经间接融合了前几层传递过来的上下文拓扑；
- 周期性插入的全局全注意力层则扮演了“长程通信中枢”的角色，负责在全序列尺度上打通远端依赖；
- 这种混合机制成功将绝大多数层的二次方显存与计算负担削减为线性复杂度（$\mathcal{O}(S \cdot W)$），极大地压制了超长上下文推理的服务成本。

在位置编码的配合上，各家模型展现出了不同的设计哲学：
- **混合嵌入设计**：部分激进模型在滑动窗口层甚至直接剥离了位置编码（No PE），将长程注意力视作纯粹的集合交互，仅依靠短程序列自身的物理因果顺序提供位置感知；
- **全量 RoPE 协同**：而如 Llama 3、Gemma 2、OLMo 2 等模型，则统一在全局层与局部滑动层均施加经过长距离缩放标定的标准 RoPE，确保相对位置几何特征在各层间的一致性。

更宽广的视野在于，这种“将廉价层与全注意力层周期性交错”的架构思路正成为全行业的共识。例如最新的 Qwen 2.5 混合模型，将这种交替思路推向了新的境界：它并没有在廉价层使用滑动窗口，而是交替引入了基于状态空间模型（State Space Model, SSM）的门控 Delta 状态网络（Gated DeltaNet）作为廉价层，同样构建起了每隔若干层部署一层全局全注意力的混合拓扑。

## 注意力替代机制与混合专家架构深度解析
> 对应块：BLK24 | 覆盖分集：P22 | 块标题（分集名）：《Lecture 4_ Attention Alt》

今天的课件之前没挂出来，现在已经上传到课程网站与 GitHub。我们在上一讲系统讨论了标准 Transformer 的基础构造，以及如何通过调整各种微观组件——例如 RMSNorm、旋转位置编码 RoPE 以及 SwiGLU 激活函数——来搭建现代大型语言模型。从这一讲开始，我们要切入更进阶、更复杂的架构设计前沿。

本讲聚焦于突破标准 Transformer 固有瓶颈的两条核心演进路径。第一条路径是修改注意力模块：探索注意力机制的替代方案，通过底层的算法重构与架构革新来支持超长上下文，将计算与显存复杂度对序列长度的依赖从二次方压低至线性。第二条路径是修改前馈网络（MLP）模块：引入混合专家（Mixture of Experts, MoE）机制，在给定的算力预算约束下大幅提升硬件计算利用率，撬动原本数倍甚至数十倍的模型参数容量。这两大思想共同构成了当代前沿大语言模型架构创新的基石。

### 长上下文的计算瓶颈与结合律重排

#### 自注意力机制的二次复杂度困境

当前语言模型领域对长上下文窗口（Context Window）的需求正经历爆发式增长。无论是把整套代码库、海量专业文献直接喂进上下文以扩充模型的事实知识库，还是构建需要长时间多轮环境交互、保留完整状态轨迹的自主智能体（Agent），都需要极大规模的上下文承载能力。回顾近几年顶级工业级大语言模型的发展脉络，模型的上下文长度呈现出清晰的对数级线性增长趋势，从最初的 2k、4k 飙升至数百万乃至千万级 Token。

然而，支持如此巨大的上下文窗口面临着极端的算力与显存屏障。在一个标准 Transformer 层中，前向传播与反向传播的计算开销主要由两部分承担：前馈网络（Feed-Forward Network, FFN）与自注意力模块（Self-Attention）。这两部分在序列长度 $N$ 扩展时的计算增长规律存在根本性差异：

- **前馈网络部分**：每个 Token 经过线性投影与激活函数时的运算完全独立，不涉及跨位置的 Token 交互。其计算量严格随序列长度 $N$ 呈线性增长，即计算复杂度为 $O(N)$。在处理常规短序列（如几千 Token）时，FFN 占据了模型主要的浮点计算量（FLOPs）。
- **自注意力机制部分**：每个 Token 必须与序列中所有其他位置的 Token 进行全对全（All-to-All）连接与点积交互，生成一个 $N \times N$ 的稠密注意力矩阵。其计算量与显存占用严格随序列长度 $N$ 呈二次方增长，即计算复杂度为 $O(N^2)$。

```text
计算开销 (FLOPs)
   ^
   |                                     / 自注意力 (All-to-All Attention, O(N^2))
   |                                    /
   |                                   /
   |                                  /
   |                                 /
   |                                /
   |            -------------------/-------- 前馈网络 (FFN, O(N))
   |           /                  /
   |          /                  /
   |         /                  /
   |        /                  /
   |       /                  /
   |      /                  /
   +---------------------------------------------> 序列长度 (N)
   (短序列阶段: FFN 开销为主)     (长序列阶段: Attention 成为绝对瓶颈)
```

上图展示了随着序列长度增长，自注意力开销与前馈网络开销的相对演化轨迹。当序列长度从数千扩展到数十万、数百万时，二次方复杂度的注意力计算量会发生灾难性的指数膨胀，迅速反超并彻底淹没 FFN 的线性增长开销。

为抑制全注意力昂贵的二次方开销，工程界最初摸索出了几种基础调控工具。一种是局部注意力与全局注意力的混合编排（Local Attention Hybrid）：例如每八个 Transformer 层中仅设置一层全局全注意力层，其余七层全部采用固定窗口高度受限的局部注意力，从而将大部分网络层的主干注意力开销降为线性。

另一种极具代表性的技术是底层系统级工程优化。许多受传统理论导向计算机科学训练的人，往往容易盲目执念于大 $O$ 渐近符号（例如究竟是线性还是二次方），却严重低估了常数因子（Constant Factors）在硬件落地中的决定性作用。FlashAttention 便是这一思想的典范：它并没有改变注意力计算在数学上的二次方复杂度 $O(N^2)$，但它通过极度巧妙的分块算法重组，将注意力矩阵的中间计算完全限制在 GPU 片上高带宽的静态随机存取内存（SRAM）中，消除了在显存（HBM）中显式物化存储 $N \times N$ 庞大注意力矩阵的显存传输瓶颈。

> **结论**：FlashAttention 是一种纯粹在常数因子层面上做到极致的系统创新。它将原生 PyTorch 下仅有 30~40 TFLOPS 的注意力算力利用率翻倍提升，并解决了中间矩阵撑爆显存的问题。但面对 500 万到 1000 万 Token 的极端超长序列，仅靠常数因子的优化终将触碰硬件物理极限。我们必须从算子数学形式出发，寻找时间与显存依赖均严格呈线性 $O(N)$ 的注意力替代方案。

#### 乘法结合律重排与线性注意力

过去探索线性时间复杂度的研究走过不少弯路，但近年已收敛出一套在大规模模型与生产环境中得到充分实战验证的成熟范式。理解所有有效线性注意力机制的第一性原理起点，就是基础代数中的**乘法结合律**（Associative Property of Multiplication）。

考虑标准自注意力算子的矩阵记法。设序列长度为 $N$，输入特征投影后的 Query、Key、Value 矩阵分别为：
$$Q \in \mathbb{R}^{N \times d_K}, \quad K \in \mathbb{R}^{N \times d_K}, \quad V \in \mathbb{R}^{N \times d_V}$$

在常规计算流程中，Query 和 Key 首先进行全位置点积运算，经过 Softmax 行归一化后与 Value 矩阵相乘：
$$\text{Attention}(Q, K, V) = \text{Softmax}\left(Q K^T\right) V$$

在这个公式中，$Q K^T$ 产生了庞大的 $N \times N$ 矩阵，其点积矩阵乘法的运算量为 $O(N^2 d_K)$，随后的加权求和运算量为 $O(N^2 d_V)$。正是 Softmax 算子的存在，把 $Q$ 与 $K^T$ 紧紧绑在了一起，强制执行了从左至右的括号优先级，即 $(Q K^T) V$。

现在，我们做一个大胆的理论剥离：如果暂时忘掉 Softmax，或者将这一归一化行映射直接替换为无 Softmax 的线性内积（甚至设其为恒等变换），那么根据矩阵乘法的结合律，我们便获得了自由重排括号优先级的权利：
$$(Q K^T) V \equiv Q (K^T V)$$

```text
标准二次方注意力计算流向:
  Q (N x d_K) x K^T (d_K x N)  ===>  Attention Matrix (N x N)  [代价: O(N^2 * d_K)]
                                               |
                                     (经过 Softmax 归一化)
                                               |
                                               v
                                     Softmax(QK^T) (N x N) x V (N x d_V)  ===>  Output (N x d_V) [代价: O(N^2 * d_V)]

线性结合律重排计算流向 (无 Softmax):
  K^T (d_K x N) x V (N x d_V)  ===>  State S (d_K x d_V)  [代价: O(N * d_K * d_V)]
                                               |
                                               v
                                     Q (N x d_K) x S (d_K x d_V)  ===>  Output (N x d_V) [代价: O(N * d_K * d_V)]
```

上图对比了传统自注意力与结合律重排后的计算流向。重排括号后的矩阵乘法计算量发生了本质蜕变：
1. 第一步先计算 $K^T V$：矩阵维度为 $(d_K \times N) \times (N \times d_V)$，结果是一个独立的特征交互状态矩阵 $S \in \mathbb{R}^{d_K \times d_V}$。该步矩阵乘法的计算复杂度为 $O(N \cdot d_K \cdot d_V)$。
2. 第二步计算 $Q (K^T V)$，即 $Q S$：矩阵维度为 $(N \times d_K) \times (d_K \times d_V)$，结果为输出矩阵 $Y \in \mathbb{R}^{N \times d_V}$。该步矩阵乘法的计算复杂度同样为 $O(N \cdot d_K \cdot d_V)$。

> **定义**：**线性注意力（Linear Attention）**指通过移除或线性化 Softmax 归一化，利用乘法结合律将计算次序调整为 $Q(K^T V)$，从而使总体计算复杂度对序列长度 $N$ 呈严格线性依赖 $O(N \cdot d_K \cdot d_V)$ 的注意力变体。

在现代大语言模型中，隐藏维度与头维度 $d_K, d_V$ 通常处于几千到几万的量级，属于固定维度的常数项，没有任何模型设计者会在隐藏层中设置百万级的坐标维度；而序列长度 $N$ 却动辄攀升至数百万。消除 $N^2$ 依赖项、转为由固定特征维度主导计算，是超长序列计算效率的根本转折点。

#### 稠密并行形式与循环递推形式的数学对偶

括号重排带来的惊喜不仅在于消除了二次方复杂度，更在于它揭示了注意力机制与循环神经网络（RNN）之间深刻的数学等价性。

观察结合律重排后右侧的矩阵乘积 $K^T V$。如果沿着序列的时间步从左向右依次遍历上下文，每一项可以写成向量外积的逐步累加：
$$K^T V = \sum_{t=1}^N k_t v_t^T$$
其中 $k_t \in \mathbb{R}^{d_K \times 1}$ 是第 $t$ 步的键列向量，$v_t^T \in \mathbb{R}^{1 \times d_V}$ 是第 $t$ 步的值行向量。

这意味着我们完全不必一次性写出全量输入的大型稠密矩阵，而是可以定义一个在时间步间持续前传的固定尺寸状态矩阵 $S_t \in \mathbb{R}^{d_K \times d_V}$，写成标准的增量循环形式：
$$S_t = S_{t-1} + k_t v_t^T$$
$$y_t = S_t q_t \quad (\text{或 } q_t^T S_t)$$

上述稠密并行矩阵乘法形式与逐步循环递推形式在数学上是严格等价的。这一等价性赋予了线性注意力极为罕见的“双重红利（Duality）”：

| 运行场景 | 采用计算形式 | 系统工程优势 |
| :--- | :--- | :--- |
| **模型训练阶段** | 稠密矩阵形式 $Q(K^T V)$ | 具有完全的全局跨时间步可并行性，能够满负荷榨干 GPU 的矩阵乘法硬件（Tensor Core）吞吐 |
| **在线推理阶段** | 循环递推形式 $S_t = S_{t-1} + k_t v_t^T$ | 状态矩阵 $S$ 大小固定不变，单步生成只需常量显存与 $O(1)$ 时间，无需缓存线性膨胀的 KV Cache |

尽管线性注意力具备如此完美的数学性质，但完全由线性算子构成的机制存在致命的表达能力短板：缺乏 Softmax 的非线性竞争与局部锐化，模型在复杂模式匹配与高精度联想回忆任务中性能严重受损。

因此，工业界的真实落地全面转向了**混合架构（Hybrid Architecture）**。一个极具代表性的大规模实战案例是 MiniMax-01。该模型采用了 7:1 的混合设计——连续 7 层采用线性注意力层，搭配 1 层具有完整 Softmax 的稠密二次方注意力层。在这种设计下，模型绝大部分网络层维持了对序列长度的线性依赖，在处理极端长文本时保持极低计算开销，同时依靠周期性穿插的全注意力层保住复杂的语言建模与推理能力，在基准测评中表现出抗衡顶级前沿模型的强劲竞争力。

> **易错点**：截至目前，工业界前沿从未有任何厂商成功部署过 100% 全线性的注意力大模型。所有的生产级线性方案无一例外都是与全 Softmax 注意力交替互补的混合架构。

### 状态空间模型与门控递归机制

#### 门控机制与 Mamba-2 的输入依赖衰减

虽然基础线性注意力的循环形式具备优异的复杂度特性，但其更新机制过于朴素：
$$S_t = S_{t-1} + k_t v_t^T$$

该公式最大的缺陷在于，它把历史信息无条件、不加衰减地永远向后累加。从早期长短期记忆网络（LSTM）的发展经验中我们早就得知，构建一个优秀的序列循环系统的核心灵魂，不仅在于知道该记什么，更在于**知道何时该把信息向后传、何时该果断遗忘并归零**。

为了给无状态约束的线性注意力注入自适应的遗忘能力，Albert Gu 与 Tri Dao 等人提出了状态空间模型（State Space Model, SSM）家族（包括著名的 Mamba 与 Mamba-2）。尽管 Mamba 系列最初是从深奥的连续状态空间微分方程理论推导而来，但如果仔细审视其底层的计算算子与张量流转，它本质上就是**为线性注意力加入门控衰减项的优雅扩展**。

Mamba-2 的核心状态转移方程引入了输入驱动的门控标量或对角矩阵 $\gamma_t$：
$$S_t = \gamma_t S_{t-1} + k_t v_t^T$$

这里的关键设计准则在于：$\gamma_t$ 是一个严格**仅依赖于当前输入 $x_t$** 的门控变量，即 $\gamma_t = \sigma(W_\gamma x_t)$，它绝对不能与隐藏状态 $S_{t-1}$ 发生依赖。

> **提示**：为什么门控 $\gamma_t$ 必须独立于历史状态 $S$？
> 一旦门控变量依赖于先前的隐藏状态 $S_{t-1}$，时间步之间的计算将形成不可解开的串行马尔可夫链，导致并行前缀扫描（Parallel Prefix Scan）和矩阵结合律彻底失效，系统将倒退回传统 RNN 无法并行训练的泥潭。只要门控项严格仅依赖输入 $x_t$，就能在训练时利用并行分块矩阵乘法保持极高吞吐，同时在推理时无缝切换为逐步循环递归。

除了核心的状态衰减更新，Mamba-2 在输出映射层还补充了一处架构细节：在输出 $y_t$ 中引入了直通残差项：
$$y_t = q_t S_t + D \odot v_t$$

这里的 $D$ 是一个可学习的直通调制门控向量。引入 $D \odot v_t$ 的直觉在于，当前时间步的输入值向量 $v_t$ 对当前词预测往往包含极高价值的即时特征。通过跳过状态矩阵 $S_t$ 直接旁路注入输出端，相当于为注意力输出提供了一条局部残差连接。

工业界已在大规模模型中成功应用了这一思想。例如 NVIDIA 发布的开源前沿模型 Nemotron-3，便将 Mamba-2 作为轻量级循环层与注意力层进行交替混编。即使在 200k 的超长上下文窗口下，Nemotron-3 仍能保持令人惊叹的极高推理吞吐量。

#### Gated DeltaNet 与基于键投影的联想擦除

能否沿着输入依赖门控的设计思想继续推进，构建出表达能力更逼近全注意力的递归架构？

这引出了当前应用极广的状态空间模型变体——**Gated DeltaNet**。如果说 Mamba-2 解决的是记忆衰减问题，那么 Gated DeltaNet 解决的则是记忆覆盖与定向擦除问题。

Gated DeltaNet 在状态更新中引入了第二个门控 $\beta_t$。$\beta_t \in [0, 1]$ 本质上是一个“写入门控（Write Gate / No-input Gate）”：当 $\beta_t \to 0$ 时，模型明确指示不将当前时间步的任何新信息注入隐藏状态，起到保持状态纯净的作用。

更具突破性的是源自 DeltaNet 的“定向擦除更新方向”。在朴素门控中，状态更新仅做线性加权（类似于 $(1-\beta_t)S_{t-1} + \beta_t v_t k_t^T$）。而 Gated DeltaNet 采取了一种更为精确的投影算子机制：
$$S_t = \gamma_t \left( I - \beta_t k_t k_t^T \right) S_{t-1} + \beta_t v_t k_t^T$$

```text
Gated DeltaNet 状态更新几何投影机理:
                     +----------------------------------------+
                     |      旧历史状态矩阵 S_{t-1}            |
                     +----------------------------------------+
                                         |
                                         v
                     +----------------------------------------+
                     | 键投影擦除算子: (I - \beta_t * k_t*k_t^T)| ===> 沿 k_t 方向消除已有记忆
                     +----------------------------------------+
                                         |
                                         v
                         衰减与剥离后的状态: \gamma_t * S'_{t-1}
                                         |
                                         + <--- 写入新键值对: \beta_t * v_t * k_t^T
                                         |
                                         v
                     +----------------------------------------+
                     |      新生成状态矩阵 S_t                |
                     +----------------------------------------+
```

上图清晰展示了 Gated DeltaNet 的更新流向。算子中的蓝色项 $(I - \beta_t k_t k_t^T)$ 扮演着几何投影器的角色。它的物理直觉非常明确：当模型决定在当前时间步为键 $k_t$ 写入新值信息时，不仅要把新知识写进去，更要在已有记忆状态中**将所有之前沿该键 $k_t$ 方向写入的历史旧信息正交投影并剥离清除**。

这种更新方向并非凭空臆造。在深度学习历史上，类似的更新机制在不同领域被不同学者基于完全不同的原则独立发明过数次：
- 在元学习（Meta-Learning）中求解在线最小二乘回归时，该更新形式会自然涌现；
- 在 Jürgen Schmidhuber 提出的快速权重程序员（Fast Weight Programmers）以及测试时训练（Test-Time Training, TTT）架构中，研究者从联想记忆梯度下降的第一性原理推导出的核心算子，与 DeltaNet 完全一致。

在工程实践上，阿里巴巴开源的 Qwen 2.5 系列及其前导模型 Qwen-Next 便深度采纳了该架构。Qwen-Next 采用了 **3:1 的 Gated DeltaNet 与全注意力混合架构**（即 3 层 Gated DeltaNet 穿插 1 层全注意力）。实测表明，随着上下文长度飙升，Qwen-Next 的解码吞吐量显著拉开与传统稠密模型 Qwen 2 的差距，且在语言基准测试中几乎毫无性能折损。

#### 循环架构与全注意力的混合策略评估

为了厘清混合架构中各组件的性能边界，字节跳动 Seed 团队与加州大学圣克鲁兹分校（UCSC）曾针对 Mamba-2、Gated DeltaNet 等各类状态空间架构在不同层数混合比例下的表现进行过严格的对照实验：

```text
模型性能 (长上下文基准 / 准确率)
   ^
   |  ====================================================== 全注意力基准线 (Full Attention)
   |
   |  [低混合比例区间: 3:1 或 7:1]    [性能断崖临界点]     [纯循环极限]
   |  ----------------------\
   |  (Gated DeltaNet / Mamba-2) \
   |                              \
   |                               \
   |                                \
   |                                 \
   |                                  \------------------- 100% 纯 RNN / 纯 SSM
   +--------------------------------------------------------------> 非全注意力层占比 (从左至右逐层增加)
```

该实验揭示了两个极具指导意义的客观规律：
1. **适度混合无损性**：在低混合比例下（例如保持四分之一或八分之一的全注意力层，其余为 Gated DeltaNet 或 Mamba-2），模型在长上下文检索、通用常识与代码任务上的表现极为稳健，几乎与全注意力模型重合。
2. **临界衰减与纯线性崩溃**：一旦非全注意力层的比例突破某个临界阈值，长上下文性能便会呈现断崖式下跌；当完全切换为 100% 纯线性循环架构时，多跳问答（Multi-hop QA）与深层语义检索能力严重滑坡。

针对线性时间注意力与全注意力的关系，这里需要廓清一个极易混淆的技术细节：循环形式与并行形式的等价性，指的是从**无 Softmax 的线性形式**向**递归状态形式**的转化是精确等价的；但**去掉全注意力中的 Softmax 行归一化**这一步本身，是不可逆的、有损的结构变化。

> **结论**：有限尺寸的状态矩阵 $S$ 构成了信息压缩的瓶颈。面对百万级上下文，如果要求状态空间维度保持极小，就绝不可能将全部长程依赖信息无损压缩进固定容量的矩阵中。这就是为什么单靠纯粹的递归模型无法彻底取代标准 Transformer，而必须采用混合架构来平衡表达力与系统效率。

### 动态稀疏注意力机制

#### 轻量级索引器与 Top-K 筛选机制

除了改换门庭走向类似 RNN 的线性循环架构，工业界探索出的另一条截然不同的长上下文路线是：**依然坚守 Softmax 注意力的全量表达能力，但在空间上施加极端的动态稀疏性（Dynamic Sparse Attention, DSA）**。

在 DeepSeek-V2 与 DeepSeek-V3.2 中，研究团队引入了 DeepSeek Attention（DSA）。它的核心哲学不是去计算全量 Token 的注意力，而是建立一套两段式过滤流水线：
1. **轻量级索引初筛**：面对庞大的历史上下文序列，先通过一个极低复杂度的“索引器（Indexer）”，从全量 Token 中粗筛出一个极小的候选子集；
2. **局部全精度注意力**：针对初筛挑出的这个规模远小于全局序列的 Top-K 紧凑子集，执行高精度的标准二次方 Softmax 注意力计算。

```text
Token 输入序列 (长度 N, N 可达数十万至百万)
        |
        +-----------------------------------+
        |                                   |
        v                                   v
[轻量投影生成低维 Q_idx, K_idx]      [标准投影生成高维 Q, K, V]
        |                                   |
        v                                   |
[计算轻量内积并过 ReLU 激活]                |
        |                                   |
        v                                   |
[Top-K 空间离散筛选算子]                     |
        |                                   |
        v (选出高相关性 K 个 Token 索引)     |
        +-----------------> [抽取对应位置的 K, V]
                                   |
                                   v
                       [仅对 K 个子集执行标准 Softmax 注意力]
                                   |
                                   v
                             注意力输出结果
```

上图展示了 DSA 算子的两阶段前向流程。在第一阶段，索引器先计算降维后的 $Q$ 与 $K$ 的内积，过一遍 ReLU 激活层，并结合前序 Token 的局部信息生成权重，输出各个历史位置的激活倾向值；随后通过 Top-K 选择算子，精准截取排名靠前的稀疏索引。在第二阶段，仅抓取被命中索引对应的 Key 与 Value，完成标准的多头加权聚合。

#### 复杂度本质与两阶段预训练工程策略

一个自然引发的敏锐质疑是：索引器为了在全体历史 Token 中找出前 $K$ 个最相关的位置，难道其内积操作不依然要把所有 Token 全都遍历一遍吗？它在渐近时间复杂度上难道不依然是二次方 $O(N^2)$ 吗？

答案是：**索引器在形式上确实是二次方的，但它的常数因子（Constant Factors）被压缩到了极致**。
- **极低的特征维度**：索引器使用的 $Q$ 和 $K$ 维度非常小，其投影权重矩阵 $W$ 极为轻量，计算内积所需的 FLOPs 仅为常规注意力的极小零头；
- **低精度计算支持**：索引器仅负责粗排序而无需高精度的数值微调，可以使用 FP8 甚至 FP4 低位宽浮点数高速执行；
- **高阶运算的真实截断**：真正消耗海量算力的多头投影、高维 Value 向量加权聚合以及反向传播梯度流，其运算规模被严格限制在常数 $K$ 的范围内。由于 $K$ 可以人为钉死在一个较小常数，昂贵的多头全注意力实际上变成了一个对超短上下文的局部运算。

更精妙的是该架构在工程训练层面的落地策略。由于 Top-K 筛选是非连续、不可微的离散操作，若从零开始（From Scratch）带着索引器进行全量预训练，梯度震荡将极其棘手。

工业界采取的最佳工程实践是**两阶段训练法**：
1. **短上下文基础预训练**：第一阶段完全不使用索引器，按照最标准的稠密 Transformer 进行高质量的基础模型预训练；
2. **长上下文持续预训练拓展**：在进入长上下文扩展阶段（Continued Pretraining）时，再将这套轻量索引器接入架构中，在较小的算力代价下微调模型，使其迅速适应 Top-K 的动态稀疏路由策略。

这一策略在大规模实战中展现了极其惊人的效果。DeepSeek-V3.2 全面采用 DSA 架构，不仅在预填充（Prefill）阶段实现了极高的吞吐扩展，而且在自回归解码（Decoding）阶段的算力消耗极具优势，在各类前沿评测中紧咬甚至超越了闭源顶流模型。智谱 AI 的 GLM-5 同样成功应用了 DSA 方法，其消融实验表明，经过长文本阶段微调的 DSA 架构，即便在以苛刻著称的长文本单键检索测试中，也几乎完全复现了全注意力的检索准确率，同时大幅减轻了硬件基础设施的承载负担。

### 混合专家架构的设计空间与路由算法

#### 参数中心视角与稀疏激活红利

如果说对注意力模块的改造是为了破解长上下文的二次方开销，那么对前馈网络（FFN/MLP）的改造——**混合专家架构（Mixture of Experts, MoE）**——则是为了在固定算力预算下无限拔高模型容量的终极武器。

理解 MoE 最朴素的心智模型，就是把它看作**一种计算效率更高的 MLP 替代品**。在标准 Transformer 块中，输入经过多头注意力与归一化后，进入一个庞大的稠密 FFN 层。这里是整个网络进行高强度、密集信息转换的核心场所。

MoE 的思路非常纯粹：假设我们不仅不打算缩小这个 FFN，反而希望拥有更多的参数（因为深度学习 scaling law 坚信参数规模越大模型越强），但又绝不愿为更多的参数支付线性增长的 FLOPs 算力开销。解决方案是：把一个原本巨大的 FFN 复制或拆解为 $E$ 个结构相同但权重独立的“专家（Experts）”，并为其配置一个轻量级的动态路由器（Router）。

```text
标准稠密 Transformer FFN:
   输入 Token ---> [ 巨大稠密 FFN 层 (全量参数参与计算) ] ---> 输出 Token

混合专家 (MoE) 架构:
                    +---> [ 专家 0 (FFN) ]
                    |
                    +---> [ 专家 1 (FFN) ] (被路由选中) ----\
   输入 Token ----> |                                        +---> 加权求和输出
    (经路由器选择)  +---> [ 专家 2 (FFN) ]                    |
                    |                                        |
                    +---> [ 专家 3 (FFN) ] (被路由选中) ----/
```

上图对比了稠密 FFN 与 MoE 的计算形态。在右侧的 MoE 结构中，总参数量扩大了数倍，但在任意单个 Token 的前向与反向传播中，路由器依据输入特征仅激活其中的前 $K$ 个专家（通常 $K=1$ 或 $K=2$）。这意味着，**我们在承受等同于单个前馈网络算力开销的前提下，获得了整个专家集群的参数容量**。

Google 的 Fedus 等人于 2022 年在 Switch Transformer 论文中确立了这一经验法则：当严格锁定单步计算的激活参数量（即 FLOPs 恒定），仅仅通过增加后台专家的数量，语言建模在测试集上的交叉熵损失就会呈现单调平滑的持续下降。

这一现象在随后的开源研究中被反复证实。AI2 发布的开源 OLMoE 报告指出，在同等训练 FLOPs 计算预算下，训练一个 MoE 模型的收敛速度比等效质量的稠密模型整整快约 2 倍。早期 DeepSeekMoE 以及 Qwen 1.5 MoE 的实证研究更展示了一个震撼的行业事实：一个仅有 27 亿激活参数的微型 MoE 模型，其多任务理解基准评测全面超越了当时一众 70 亿参数的经典稠密模型。从海外的 Llama 4、GPT-OSS，到国内的 DeepSeek、Qwen、MiniCPM，MoE 已经成为所有参数突破一定规模的大模型无可争议的标配选择。

此外，MoE 在底层系统设计中开辟了一个极具价值的维度——**专家并行（Expert Parallelism, EP）**：
- 传统的数据并行（Data Parallelism）受制于批次大小（Batch Size）的物理吞吐边界；
- 模型张量并行（Tensor Parallelism）受制于单节点内复杂的层内切分与通信带宽；
- 而在 MoE 中，由于各专家在计算上完全独立，每个专家构成了天然无依赖的并行分块。我们可以将不同的专家直接散布在集群中不同的物理 GPU 设备上，仅通过网络动态路由激活值，从而极大释放了集群扩展空间。

#### 路由决策机制与 Token-Choice 范式

MoE 的核心灵活性源于其路由机制。设计一个工业级 MoE 系统，首先需要在宏观设计空间中确立路由分发的基本范式。

首先是路由切换的粒度：**现代大模型无一例外将路由粒度钉死在 Token 级别**。每个 Token 在流经每一层时独立做路由决策。路由器绝不是在文章级别去猜测“这是一篇医学文献还是法律合同”，它在最底层的词元级感知局部模式，每个 Token 都有其专属的专家激活组合。

其次是路由决策的主被动关系：
- **Token 选择专家（Token-Choice）**：每个 Token 拿着自己的特征向量，由路由器打分，从中挑选出最契合的 Top-K 个专家送入计算池；
- **专家选择 Token（Expert-Choice）**：每个专家依据自身固定的容量槽位（Capacity），反向在批次中挑选自己最想处理的若干 Token。

尽管理论上 Expert-Choice 能天然保证各个专家的负载绝对均衡，但 OLMoE 等多项受控对照研究表明，**Token-Choice 在训练收敛性、验证集损失以及下游任务得分上均全面压制 Expert-Choice**。Token 选择专家更容易训练，也更契合自回归因果语言建模的时序特性，因而已成为当今工业界唯一的标准做法。

在具体的路由器数学实现上，主要存在四种技术流派：

| 路由技术路线 | 数学原理与工作机制 | 工业应用现状与评价 |
| :--- | :--- | :--- |
| **线性投影内积路由器 (Dot-Product Top-K)** | 输入向量 $u$ 与各专家的可学习权重向量计算内积，经过 Softmax 得到匹配得分 $S$，截取最高的前 $K$ 项作为门控权重 | **业界绝对共识**：Switch Transformer、GShard、Mixtral、DBRX、DeepSeek 等全线采用 |
| **输入哈希路由 (Hash-based Routing)** | 对输入特征做确定性哈希运算，映射至固定专家编号 | 仅作为理论消融基线，无法适应语义自适应需求，实际部署已废弃 |
| **强化学习路由 (RL / Multi-armed Bandit)** | 将路由决策建模为部分可观测的多臂老虎机策略，利用 REINFORCE 梯度更新 | 梯度方差极大、探索与利用开销过高，在大规模生产中已被证明得不偿失 |
| **全局线性指派路由 (Linear Assignment)** | 全局计算 Token 与专家的匹配代价矩阵，求解二分图最优指派 | 理论极其严谨优美，但求解指派算法的计算开销极大，完全无法在大规模分布式训练中落地 |

在主流的内积 Top-K 路由器中，其前向计算过程极为洗练。设输入为 $u$，专家编号为 $i \in \{1, \dots, N\}$，第 $i$ 个专家的路由打分由线性投影与 Softmax 决定：
$$s_i = \frac{e^{W_{g,i}^T u}}{\sum_{j=1}^N e^{W_{g,j}^T u}}$$
路由器挑取得分最高的 Top-K 项，将其余专家的门控直接置零，最终由被激活专家对其输出做加权求和：
$$y = \sum_{i \in \text{Top-K}} s_i \cdot \text{FFN}_i(u)$$

这一结构与前文解析的 DSA 机制高度同构：它们都在大容量候选池与稀疏执行之间，以轻量内积打分配合 Top-K 算子实现了高性价比的动态计算截断。

#### 细粒度专家划分与共享专家解耦

虽然标准的内积 Top-K 路由奠定了现代 MoE 的基石，但早期遵循 Google GShard 范式的模型通常采用“粗粒度专家”设定（例如总共设立 16 个体量庞大的专家，每次仅选 Top-2）。

DeepSeek 团队在 DeepSeekMoE 论文中指出了这种传统粗粒度设定的结构性缺陷：如果把每个专家都做得很大，每个专家在训练中都会不可避免地耗费自身宝贵的参数空间去重复学习那些全序列通用的基础语法与语言知识，导致各个专家的专业化分工严重受阻。

为此，DeepSeek 首创了如今被全行业普遍复刻的标准设计规范——**细粒度专家划分与共享专家解耦（Fine-grained & Shared Experts）**：
1. **细粒度切分**：将原本体量庞大的单一专家进一步切碎，构建出数量庞大但单个体积非常小巧的细粒度专家群（例如扩充为 64 或 128 个小型专家）；
2. **共享专家常驻**：在整个专家集群中，固定划分出若干个专用细粒度专家作为“共享专家（Shared Experts）”。共享专家绕过路由器，对序列中的所有 Token 始终保持无条件激活；
3. **路由专家特化**：其余细粒度专家作为路由专家，接受路由器的 Top-K 动态调度。

```text
DeepSeekMoE 细粒度与共享专家解耦架构:
                        +----------------------------------------+
                        |               输入 Token               |
                        +----------------------------------------+
                               |                            |
       (无条件旁路分支)        |                            | (路由调度分支)
                               v                            v
               +-------------------------------+   +-------------------+
               |      常驻激活的共享专家       |   |    Top-K 路由器   |
               | (处理基础通用表征, 不参与稀疏) |   +-------------------+
               +-------------------------------+            |
                               |                            v
                               |               +-----------------------+
                               |               | 选中的 Top-K 细粒度专家|
                               |               | (专门化处理特异性特征) |
                               |               +-----------------------+
                               |                            |
                               v                            v
                        +----------------------------------------+
                        |        求和汇聚生成最终 FFN 输出       |
                        +----------------------------------------+
```

上图展示了共享专家与细粒度路由专家的协同架构。其深层逻辑在于：将所有 Token 都需要经历的公用通用计算彻底剥离并卸载至共享专家上，从而使受路由调度的细粒度专家群能够从通用建模的沉重负担中解脱出来，专心聚焦于不同领域、不同知识模式的极致专门化建模。

DeepSeek 的详尽消融实验表明，在相同总参数与相同激活 FLOPs 的严苛前提下，将 16 个大专家切为细粒度小专家，并在其中加入共享专家，能让模型在 TriviaQA、Natural Questions 等复杂知识密集型下游问答任务上获得显著的性能跃升。随后的 Qwen 2.5、GLM-4 等主流模型均全面跟进并深度融合了这一设计。

> **提示**：在专家并行（EP）的分布式部署中，共享专家并不能带来多卡并行通信的算力节约。由于每个 Token 都必须穿过共享专家，工程上的标准解法是将共享专家的权重在集群中的每一张 GPU 设备上全量镜像复制一份，以此消除节点间传输共享激活值的集合通信开销。

### 混合专家架构的训练动态与系统工程

#### 路由崩溃与负载均衡辅助损失

初学 MoE 时，许多人容易对其工程落地产生极度悲观的直觉假定：既然系统在训练时仅激活 Top-K 个专家，这是一个典型的**不可微离散操作**；而且未被选中的专家在当前时间步得不到任何梯度流更新（具有典型的强化学习赌博机反馈特性）。在如此恶劣的优化环境下，模型到底是如何被稳定训练出来的？

这触及了 MoE 训练中最核心的病理现象——**专家坍缩（Expert Collapse），亦称专家饥饿（Expert Starvation）**。

在无约束条件下直接运行常规梯度下降，系统会陷入极度恶性的正反馈闭环（富者愈富现象）：
1. 初始阶段由于参数随机初始化的细微偏差，路由器可能轻微倾向于专家 0 和专家 1；
2. 这两个专家在初期被分发了稍多的 Token，从而在反向传播中获得了远比其他专家更丰富的监督梯度与调优迭代；
3. 反向传播更新进一步推高了路由器对这两个专家的置信概率；
4. 最终导致全网几乎所有 Token 疯狂涌向极个别热门专家，而其余绝大多数专家被彻底打入冷宫，在整个预训练生命周期中完全得不到训练，海量的稀疏参数被白白荒废。

```text
未加负载均衡时的专家坍缩 (Collapse):
   [专家 0] <=================== 承担 90% 以上 Token 流量 (严重过载)
   [专家 1] <========= 承担 8% 流量
   [专家 2] <- 0.5% (饥饿)
   [专家 3] <- 0.1% (完全废弃)

加入负载均衡辅助损失后的健康利用率:
   [专家 0] <==== 25% 均匀利用
   [专家 1] <==== 25% 均匀利用
   [专家 2] <==== 25% 均匀利用
   [专家 3] <==== 25% 均匀利用
```

早期研究者（如 Noam Shazeer 2017）曾试图通过在路由打分中注入输入依赖的高斯噪声来强行鼓励随机探索：
$$H(x) = x W_g + \text{StandardNormal}() \cdot \text{Softplus}(x W_{\text{noise}})$$
Fedus 等人随后也提出过均匀乘法扰动。但后来的大规模工业实战与消融实验戏剧性地表明：**去掉这些复杂的随机探索噪声，反而让模型的收敛质量更稳健、下游性能更好**。

真正解决专家坍缩并奠定工业标准的是一套基于**辅助损失（Auxiliary Loss / Balance Loss）**的启发式平衡机制。以 Switch Transformer 的经典型负载均衡损失为例，其损失函数定义为：
$$\mathcal{L}_{\text{balance}} = \alpha \cdot N \sum_{i=1}^N f_i P_i$$

其中：
- $N$ 是路由专家的总数；
- $\alpha$ 是控制均衡强度的辅助损失超参数权重；
- $f_i$ 是当前批次（Batch）中被实际派发给专家 $i$ 的 Token 频次比例（即离散选择频次统计量）；
- $P_i$ 是当前批次中路由器分配给专家 $i$ 的平滑预测概率质量均值。

这个损失函数初看非常反直觉。理解其精妙物理机制的唯一正确方式是**在反向传播中对其求偏导**。如果对平滑概率项 $P_i$ 求导，我们会得到：
$$\frac{\partial \mathcal{L}_{\text{balance}}}{\partial P_i} \propto f_i$$

> **结论**：对平滑预测概率 $P_i$ 的惩罚梯度强度，严格正比于该专家实际吸收的 Token 比例 $f_i$！
> 某个专家当前吞下的 Token 越多（$f_i$ 越大），系统施加在该专家路由概率上的向下打压惩罚就越严厉。正是这一机制在梯度空间强制拉平了各个专家的受宠程度。

在真实的超大规模分布式训练中，DeepSeek 等顶尖团队进一步将这一逻辑推向极致：他们不仅施加针对单个专家的负载均衡损失，更引入了**针对物理计算设备（Per-Device）的设备级负载均衡损失**。在多机多卡拓扑中，确保各张 GPU 卡承载的计算与通信总量维持绝对平衡，是防止集群产生“木桶短板”木桶效应的生命线。

尽管 DeepSeek-V3 在最新演进中已开始尝试利用无辅助损失（Aux-loss-free）的自适应偏置调整来减少对主目标的干扰，但辅助平衡的核心哲学始终未变。消融实验证明，彻底拔掉负载均衡损失会导致训练损失灾难性飙升，模型迅速退化为仅由两三个专家支撑的残疾架构。

最后必须指出，各专家被均衡激活后，并不意味着它们学会了人类直觉层面的高阶语义分工。对激活状态的可视化表明，不存在所谓“搞文学的专家”或“搞代码的专家”；路由器主要依据底层的词法、字符集模式（例如标点符号、数字序列、特定编程语言语法结构）对数据流进行低阶统计特征的分流。

#### 专家并行与跨节点通信压缩

将 MoE 真正推向千亿乃至万亿级规模的最后一块拼图是系统级并行工程。

在超大规模集群中，单一 GPU 绝无可能装下数百个庞大的专家参数。系统必须将不同的专家分配至不同的硬件节点上，依赖底层集合通信算子（All-to-All）在设备间进行跨卡跨节点的高频激活值传输。

然而，跨节点通信延迟极易成为屠杀系统吞吐的终极瓶颈。为缓解这一矛盾，工程界发展出了多套极为精妙的软硬件协同设计：
1. **残差流降维通信投影（Nemotron-3 实践）**：
   对于无需跨卡通信的本地常驻共享专家，让其维持高特征维度；而对于必须跨节点远距离传输给外部专家的激活向量，先在本地通过低维线性变换进行有损降维压缩，再打入 All-to-All 集合通信管道，接收节点拿到压缩向量后再升维还原送入对应专家。以极小的表征代价，直接击穿了分布式集群的通信开销天花板。
2. **硬件级结构化稀疏大矩阵乘法（Grouped GEMM）**：
   如果在一张 GPU 上顺序执行多个碎片化的微型矩阵乘法，会导致频繁的核函数启动开销（Kernel Launch Overhead）与极低的片上缓存命中率。现代底层系统（如 MegaBlocks）将同一设备上的多个专家计算与输入 Token 重排打包，深度映射为硬件原生支持的块对角（Block-diagonal）结构化大矩阵乘法，完全释放了 GPU Tensor Core 的峰值硬件算力。
3. **无丢弃架构（Drop-free Architecture）的普及**：
   在早期 MoE 框架中，为了防止某个热点专家队列被塞爆，系统为每个专家设定了硬性处理上限（Capacity Factor），超额的 Token 会被静默丢弃（Token Dropping），直接给推理注入了非确定性的输出漂移。现代主流实现已彻底摒弃丢弃机制，基于全动态的弹性路由实现了绝对的计算确定性。

#### 数值稳定性、下游微调与架构演进

在系统工程的收尾阶段，MoE 的架构调优还需要直面三大现实挑战：

**第一是数值稳定性与 Softmax 极性治理**。我们在上一讲反复告诫过：指数运算是危险的，除法运算是危险的，这意味着任何 Softmax 都是数值不稳定的高危震中。MoE 在路由器中再次引入了一个全新的 Softmax 结构，使得模型极易发生溢出。为此，工业界的标准防御手段是在全网推行 FP32 浮点精度的路由器打分，并在路由器优化中普遍引入 **z-loss 辅助正则项**：
$$\mathcal{L}_z = \frac{1}{T} \sum_{t=1}^T \left( \log \sum_{i=1}^N e^{s_{t,i}} \right)^2$$
z-loss 严惩过大的未经归一化的 Logits 数值，强行压制激活极值。OLMoE 的对照消融明确表明，引入 z-loss 是彻底抚平预训练损失曲线剧烈震荡的关键法宝。

**第二是下游小样本微调的严重过拟合陷阱**。MoE 虽然单步计算只激活少量参数，但其物理总参数量极其庞大。如果直接拿传统指令微调的几千条小样本去端到端微调所有专家，模型会在训练集上瞬间过拟合至损失归零，而验证集泛化损失急剧发散。
- **参数高效微调**：工程上最稳妥的策略是完全冻结所有专家 MLP 模块，仅微调共享注意力层或非 MoE 基础模块；
- **大数据强攻**：或者遵循“苦涩的教训（The Bitter Lesson）”，直接搜集数百万（如 140 万条以上）的高质量多样化微调语料，以充沛的数据流通量对全专家进行全局再训练。

**第三是冷启动阶段的升级复用技术（Upcycling）**。在早期算力紧缺的探索期，如何低成本获得一个高性能 MoE 模型？研发人员发明了升级复用：
- 直接拿一个已经预训练成熟的高质量稠密模型（Dense Model）；
- 将其全套权重镜像复制，把其中的 MLP 复制多份实例化为 $E$ 个专家；
- 随机初始化一个轻量路由器，挂接辅助损失后继续预训练。

MiniCPM 曾利用这一策略将 2.4B 稠密模型瞬间“升级复用”为 134 亿参数的高阶 MoE 模型，以极小的二次训练代价白捡了一大批综合性能增益；Qwen 团队早期在 Qwen 1.5A 2.7B MoE 上同样复现了该技巧。虽然目前主流前沿实验室已全面普及从零启动 MoE 预训练，但升级复用依然是中小型团队低成本扩充模型容量的经典工程解。

### 现代大语言模型前沿架构集成范式

回顾并串联前沿代表性模型（以 DeepSeek 家族演进为主线），我们可以清晰勾勒出当代大语言模型将上述机制深度缝合、协同进化的架构全景：

```text
现代前沿模型综合架构形态 (以 DeepSeek-V3 为代表):
+-------------------------------------------------------------------------+
| 多头潜在注意力 (Multi-Head Latent Attention, MLA)                       |
|   - 压缩 KV Cache 为低维潜在向量 c_t，极低显存驻留                        |
|   - 解耦位置编码通道以兼容 RoPE                                         |
+-------------------------------------------------------------------------+
                                    |
                                    v
+-------------------------------------------------------------------------+
| 混合专家模块 (Mixture of Experts, MoE)                                  |
|   - 细粒度专家群 (Fine-grained Experts, 数量众多)                       |
|   - 隔离常驻的共享专家 (Shared Experts, 吸收通用模式)                     |
|   - 无辅助损失自适应偏置平衡机制 (Aux-loss-free Load Balancing)          |
|   - 跨节点激活值通信降维压缩与无丢弃硬件协同                             |
+-------------------------------------------------------------------------+
                                    |
                                    v
+-------------------------------------------------------------------------+
| 多 Token 预测头 (Multi-Token Prediction, MTP)                           |
|   - 单步同时推测自回归预测未来多个时间步                                |
|   - 作为原生内置投机解码器 (Speculative Decoder) 倍增推理生成吞吐       |
+-------------------------------------------------------------------------+
```

上图概括了当前集大成的前沿大语言模型架构装配方案。其关键设计可以归结为三大支柱的紧密嵌合：
1. **在注意力端集成多头潜在注意力（MLA）**：不再直接缓存全量高维的 Key 与 Value，而是引入前置潜在压缩表征 $C$。在推理时系统仅需保存极小尺寸的 $C$ 向量作为 KV Cache，在解码瞬间动态投影解压出 $Q, K, V$。通过解耦非潜在位置编码维度妥善化解与 RoPE 旋转矩阵的冲突，实现了推理期显存占用的指数级削减。
2. **在前馈网络端集成深度特化的 MoE**：以共享专家托底通用模式，以海量细粒度专家承载特异性知识扩容，配合高精度无丢弃路由与自适应硬件并行策略，使模型在极低推理成本下展现出庞大参数集群的深厚涌现能力。
3. **在输出端集成多 Token 预测（MTP）**：打破“单步仅预测下一个 Token”的传统教条，单次前向同时密集预测未来多个 Token。这不仅在统计学上为骨干网络注入了更深远的长程因果自监督信号，更在系统层面原生化身一个零通信开销的投机解码器（Speculative Decoder），为自回归大模型的在线推理生成带来了成倍的吞吐加速。

无论是利用乘法结合律与状态空间构建的线性注意力，还是在特征空间施加极端截断的动态稀疏索引，抑或是在全网算力约束下极致榨取参数规模的混合专家，底层所贯穿的核心哲学始终如一：**在严苛的物理计算与显存极限面前，深刻利用代数对偶、统计稀疏性与软硬件协同设计，持续拓展机器智能的模型容量与上下文认知边界**。
